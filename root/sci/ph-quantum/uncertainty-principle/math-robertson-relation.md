# 🧮 Математичне виведення загального співвідношення невизначеностей Робертсона — Шредінгера

У квантовій механіці співвідношення невизначеностей Гайзенберга є не просто евристичною здогадкою чи вислідом конкретних мисленнєвий експериментів з приладами. Це сувора математична теорема лінійної алгебри у гільбертовому просторі (нім. *Hilbert-Raum*), яка випливає з некоммутативності самоспряжених операторів (лат. *operator* — той, хто діє). Якщо два фізичних оператори не комутують між собою, вони не мають спільного базису власних векторів, що унеможливлює існування квантового стану з одночасно точними значеннями обох величин.

У цій вставці наведено повне математичне виведення узагальненого співвідношення невизначеностей Говарда Персі Робертсона (1929) та Ервіна Шредінгера (1930) для двох довільних фізичних величин, аналіз роль квантової коваріації, а також доведено умови досягнення мінімального добутку невизначеностей.

## Математичний апарат: квантові стани та оператори

У формалізмі Дірака та фон Неймана квантовий стан системи описується нормованим вектором `|Ψ⟩` у комплексному гільбертовому просторі `H`. Умова нормування `⟨Ψ|Ψ⟩ = 1` гарантує, що сумарна ймовірність знайти систему у будь-якому з можливих станів дорівнює одиниці.

Фізичні спостережувані величини (координата, імпульс, енергія, момент імпульсу, спін) описуються лінійними самоспряженими (ермітовими) операторами `Â` та `B̂`. Властивість самоспряженості `Â⁺ = Â` є фізично принциповою: вона гарантує, що всі власні значення оператора (результати вимірювань) є дійсними числами, а власні вектори, що відповідають різним власним значенням, утворюють ортогональний базис у просторі станів.

Середнє очікуване значення (математичне сподівання) оператора `Â` у стані `|Ψ⟩` визначається як скалярний добуток:

```
⟨A⟩ = ⟨Ψ| Â |Ψ⟩        [середнє значення спостережуваної A]
```

Для характеристики статистичного розкиду (квантової дисперсії) результатів вимірювання величини `A` вводиться оператор відхилення від середнього:

```
ΔÂ = Â - ⟨A⟩ I         [оператор флуктуації, де I — одиничний оператор]
```

Оскільки `⟨A⟩` є дійсним числом для ермітового оператора, оператор флуктуації `ΔÂ` також є ермітовим: `(ΔÂ)⁺ = ΔÂ`. Квадрат середньоквадратичного відхилення (стандартне відхилення або квантова невизначеність `σ[A]`) визначається як математичне сподівання квадрата оператора флуктуації:

```
σ[A]² = ⟨Ψ| (ΔÂ)² |Ψ⟩
= ⟨Ψ| ΔÂ ΔÂ |Ψ⟩        [визначення дисперсії спостережуваної A]
```

Важливо підкреслити різницю між квантовою дисперсією `σ[A]` та класичною похибкою вимірювання. Класична похибка є наслідком недостатньої точності вимірювального приладу або недосконалості експерименту. Квантова дисперсія `σ[A]` існує навіть для ідеального вимірювального приладу і відображає фундаментальну ймовірнісну природу квантового стану: при проведенні серії ідентичних вимірювань на ансамблі однакових квантових систем результати будуть розподілені навколо середнього значення `⟨A⟩` із середньоквадратичним розкидом `σ[A]`.

## Доведення за допомогою нерівності Коші — Буняковського — Шварца

Для виведення загальної нерівності побудуємо два допоміжних вектори стану `|f⟩` та `|g⟩`, застосувавши оператори флуктуації `ΔÂ` та `ΔB̂` до вектора стану `|Ψ⟩`:

```
|f⟩ = ΔÂ |Ψ⟩            [допоміжний вектор для оператора A]
|g⟩ = ΔB̂ |Ψ⟩            [допоміжний вектор для оператора B]
```

Обчислимо квадрати норми (довжини) цих двох векторів у гільбертовому просторі, використовуючи властивість ермітовості операторів `ΔÂ` та `ΔB̂`:

```
⟨f|f⟩ = ⟨(ΔÂ Ψ)| (ΔÂ Ψ)⟩
= ⟨Ψ| (ΔÂ)⁺ ΔÂ |Ψ⟩
= ⟨Ψ| (ΔÂ)² |Ψ⟩ = σ[A]² [квадрат норми вектора f дорівнює дисперсії A]

⟨g|g⟩ = ⟨(ΔB̂ Ψ)| (ΔB̂ Ψ)⟩
= ⟨Ψ| (ΔB̂)⁺ ΔB̂ |Ψ⟩
= ⟨Ψ| (ΔB̂)² |Ψ⟩ = σ[B]² [квадрат норми вектора g дорівнює дисперсії B]
```

Для довільних двох векторів `|f⟩` та `|g⟩` у комплексному гільбертовому просторі виконується фундаментальна математична **нерівність Коші — Буняковського — Шварца** (нім. *Cauchy-Schwarzsche Ungleichung*), яка є геометричним узагальненням теореми про квадрат косинуса кута між векторами:

```
⟨f|f⟩ · ⟨g|g⟩ ≥ |⟨f|g⟩|² [нерівність Коші — Шварца]
```

Підставляючи вирази для норм через квантові дисперсії, отримуємо базове співвідношення між дисперсіями та скалярним добутком флуктуаційних векторів:

```
σ[A]² · σ[B]² ≥ |⟨f|g⟩|² [базова нерівність для дисперсій]
```

## Розклад скалярного добутку на симетричну та антисиметричну частини

Знайдемо скалярний добуток `⟨f|g⟩`:

```
⟨f|g⟩ = ⟨(ΔÂ Ψ)| (ΔB̂ Ψ)⟩
= ⟨Ψ| ΔÂ ΔB̂ |Ψ⟩         [скалярний добуток допоміжних векторів]
```

Операторний добуток `ΔÂ ΔB̂` не є ні суто ермітовим, ні суто антиермітовим. Проте будь-який операторний добуток можна тотожно розкласти на суму його симетричної частини (антикомутатора `{ΔÂ, ΔB̂}`) та антисиметричної частини (комутатора `[ΔÂ, ΔB̂]`):

```
ΔÂ ΔB̂ = (1 / 2) {ΔÂ, ΔB̂} + (1 / 2) [ΔÂ, ΔB̂] [тотожний розклад оператора]
```

де антикомутатор `{ΔÂ, ΔB̂} = ΔÂ ΔB̂ + ΔB̂ ΔÂ`, а комутатор `[ΔÂ, ΔB̂] = ΔÂ ΔB̂ - ΔB̂ ΔÂ`.

Зауважимо важливе математичне соотшення: оскільки середні значення `⟨A⟩` та `⟨B⟩` є скалярами, комутатор флуктуаційних операторів повністю збігається з комутатором вихідних фізичних операторів:

```
[ΔÂ, ΔB̂] = [Â - ⟨A⟩I, B̂ - ⟨B⟩I]
= [Â, B̂]               [зсув на скалярну матрицю не змінює комутатор]
```

Дослідимо алгебраїчні властивості середніх значень антикомутатора та комутатора:

1. **Антикомутатор є ермітовим оператором:** `{ΔÂ, ΔB̂}⁺ = (ΔÂ ΔB̂ + ΔB̂ ΔÂ)⁺ = ΔB̂ ΔÂ + ΔÂ ΔB̂ = {ΔÂ, ΔB̂}`. Тому його середнє значення у будь-якому стані є чисто дійсним числом `u`:
   ```
   u = ⟨Ψ| {ΔÂ, ΔB̂} |Ψ⟩ ∈ ℝ [дійсне число]
   ```

2. **Комутатор двох ермітових операторів є антиермітовим оператором:** `[Â, B̂]⁺ = (Â B̂ - B̂ Â)⁺ = B̂ Â - Â B̂ = -[Â, B̂]`. Тому його середнє значення є чисто уявним числом `i v`:
   ```
   ⟨Ψ| [Â, B̂] |Ψ⟩ = i v    [де v = -i ⟨[Â, B̂]⟩ ∈ ℝ — дійсне число]
   ```

Звідси середнє значення добутку `⟨f|g⟩` записується у вигляді суми дійсної та уявної частин:

```
⟨f|g⟩ = (1 / 2) ⟨{ΔÂ, ΔB̂}⟩ + (1 / 2) ⟨[Â, B̂]⟩
= (1 / 2) u + (i / 2) v [розклад на дійсну та уявну складові]
```

Квадрат модуля комплексного числа `z = x + i y` дорівнює сумі квадратів його дійсної та уявної частин `|z|² = x² + y²`. Оскільки дійсна та уявна частини є взаємно ортогональними у комплексній площині, ми отримуємо:

```
|⟨f|g⟩|² = (1 / 4) u² + (1 / 4) v²
= (1 / 4) |⟨{ΔÂ, ΔB̂}⟩|² + (1 / 4) |⟨[Â, B̂]⟩|² [квадрат модуля скалярного добутку]
```

## Узагальнене співвідношення Робертсона — Шредінгера

Підставляючи квадрат модуля скалярного добутку у нерівність Коші — Шварца, отримуємо **повне співвідношення невизначеностей Шредінгера (1930)**:

```
σ[A]² · σ[B]² ≥ (1 / 4) |⟨[Â, B̂]⟩|² + (1 / 4) |⟨{ΔÂ, ΔB̂}⟩|²
```

Ввівши квантову коваріацію (кореляційну функцію) двох величин `Cov(A, B) = (1 / 2) ⟨{ΔÂ, ΔB̂}⟩`, нерівність набуває витонченого вигляду:

```
σ[A] · σ[B] ≥ √( (1 / 4) |⟨[Â, B̂]⟩|² + Cov(A, B)² ) [нерівність Шредінгера]
```

Квантова коваріація `Cov(A, B)` вимірює кореляцію між флуктуаціями величин `A` та `B`. Якщо при відхиленні `A` вгору від середнього величина `B` також схильна відхилятися вгору, коваріація є додатною. Для стиснених квантових станів (англ. *squeezed states*), які широко використовуються у сучасній квантовій оптиці та лазерних інтерферометрах гравітаційних хвиль LIGO, кореляція між квадратурними компонентами дозволяє зменшити невизначеність однієї з величин нижче рівня нульових коливань за рахунок зростання коваріації та невизначеності спряженої величини.

Оскільки квадрат коваріації `Cov(A, B)² ≥ 0` є завжди невід'ємним для будь-якого стану, його відкидання лише посилює нерівність. В результаті ми отримуємо класичну **нерівність Робертсона (1929)**:

```
σ[A] · σ[B] ≥ (1 / 2) |⟨[Â, B̂]⟩| [загальне співвідношення Робертсона]
```

Це фундаментальний алгебраїчний результат квантової механіки: **якщо оператори `Â` та `B̂` не комутують (`[Â, B̂] ≠ 0`), фізичні величини `A` та `B` принципово не можуть мати одночасно точних значень у жодному квантовому стані!**

## Канонічна пара: Координата та Імпульс

Застосуємо загальну формулу Робертсона до канонічно спряжених величин: координати `x̂ = x` та імпульсу `p̂ = -i ℏ (∂ / ∂x)`.

Обчислимо діяння комутатора `[x̂, p̂]` на довільну вимірну хвильову функцію `ψ(x)`:

```
[x̂, p̂] ψ(x) = x (p̂ ψ) - p̂ (x ψ)
= x (-i ℏ (∂ψ / ∂x)) - (-i ℏ (∂(x ψ) / ∂x)) [підстановка виразу для p̂]
= -i ℏ x (∂ψ / ∂x) + i ℏ (ψ(x) + x (∂ψ / ∂x)) [правило Лейбніца для похідної добутку]
= i ℏ ψ(x) [скорочення взаємно знищуваних членів]
```

Оскільки це співвідношення виконується для будь-якої функції `ψ(x)`, операторний комутатор дорівнює:

```
[x̂, p̂] = i ℏ I         [канонічне комутаційне співвідношення Гейзенберга]
```

Середнє значення комутатора у будь-якому нормованому стані:

```
⟨[x̂, p̂]⟩ = i ℏ         [константа, що не залежить від стану]
```

Модуль середнього значення комутатора: `|⟨[x̂, p̂]⟩| = ℏ`.

Підставляючи цей результат у співвідношення Робертсона, отримуємо знаменитий **принцип невизначеності Гайзенберга — Робертсона**:

```
σ[x] · σ[p] ≥ (1 / 2) · ℏ = ℏ / 2 [фундаментальна нерівність координата-імпульс]
```

## Умова мінімального пакета (гаусові стани)

Нерівність Коші — Буняковського — Шварца `⟨f|f⟩ ⟨g|g⟩ ≥ |⟨f|g⟩|²` перетворюється на точну рівність тоді й лише тоді, коли вектори `|f⟩` та `|g⟩` є колінеарними (лінійно залежними), тобто один вектор є скалярним кратним іншого:

```
|g⟩ = c |f⟩             [умова рівності, де c ∈ ℂ — комплексне число]
```

Для мінімального пакета з нульовою коваріацією (`Cov(A, B) = 0`) комплексне число `c` мусить бути чисто уявною константою: `c = -i λ`, де `λ > 0` — дійсне число.

Підставивши вирази `|f⟩ = (x̂ - ⟨x⟩)|Ψ⟩` та `|g⟩ = (p̂ - ⟨p⟩)|Ψ⟩`, отримуємо диференціальне рівняння першого порядку для хвильової функції мінімального квантового пакета:

```
(p̂ - ⟨p⟩) ψ(x) = -i λ (x - ⟨x⟩) ψ(x)
-i ℏ (dψ / dx) - ⟨p⟩ ψ(x) = -i λ (x - ⟨x⟩) ψ(x) [диференціальне рівняння]
```

Перегрупувавши члени рівняння та розділивши змінні:

```
dψ / ψ = ( i ⟨p⟩ / ℏ - (λ / ℏ) (x - ⟨x⟩) ) dx [відокремлення змінних]
```

Інтегруючи обидві частини та визначаючи константу нормування з умови `∫ |ψ(x)|² dx = 1` (де `λ = ℏ / (2 σ_x²)`), отримуємо **Гаусів хвильовий пакет**:

```
ψ(x) = (1 / (2 π σ_x²)^(1/4)) · exp( - (x - ⟨x⟩)² / (4 σ_x²) + i ⟨p⟩ x / ℏ )
```

Для Гаусового хвильового пакета добуток невизначеностей досягає абсолютного теоретичного мінімуму:

```
σ[x] · σ[p] = ℏ / 2     [абсолютний мінімум невизначеності]
```

Будь-яка інша форма хвильового пакета (прямокутна, трикутна, лоренцова) має добуток невизначеностей строго більший за мінімальний: `σ[x] · σ[p] > ℏ / 2`.

## Інші важливі некомутуючі пари у фізиці

Співвідношення Робертсона — Шредінгера є універсальним інструментом і застосовується до багатьох фізичних систем:

### 1. Компоненти орбітального моменту імпульсу

Оператори векторного моменту імпульсу `L̂ = r̂ × p̂` задовольняють комутаційні співвідношення алгебри Лі групи обертань SO(3):

```
[L̂_x, L̂_y] = i ℏ L̂_z
[L̂_y, L̂_z] = i ℏ L̂_x
[L̂_z, L̂_x] = i ℏ L̂_y    [комутаційні співвідношення алгебри моменту]
```

Застосовуючи нерівність Робертсона до проєкцій `L_x` та `L_y`, отримуємо:

```
σ[L_x] · σ[L_y] ≥ (ℏ / 2) |⟨L_z⟩| [невизначеність проєкцій моменту імпульсу]
```

Це означає, що квантова система (наприклад, електрон в атомі) принципово не може мати фіксованого напрямку вектора моменту імпульсу в просторі. Якщо вектор задано точним значенням проєкції `L_z = m ℏ`, то поперечні складові `L_x` та `L_y` здійснюють квантові флуктуації навколо нуля, утворюючи прецесійний конус моменту.

### 2. Спінові оператори Паулі

Для фундаментальної частинки зі спіном `s = 1/2` (електрон, протон, нейтрино) спінові оператори визначаються через матриці Паулі `Ŝ_i = (ℏ / 2) σ_i`. Їхній комутатор `[Ŝ_x, Ŝ_y] = i ℏ Ŝ_z` веде до співвідношення:

```
σ[S_x] · σ[S_y] ≥ (ℏ / 2) |⟨S_z⟩| [невизначеність спінових компонент]
```

Якщо спін електрона повністю поляризований уздовж осі Z (тобто `⟨S_z⟩ = +ℏ/2`), то невизначеності спінових компонент уздовж перпендикулярних осей X та Y є максимальними: `σ[S_x] = σ[S_y] = ℏ / 2`.

### 3. Час життя стану та розширення спектральних ліній (енергія — час)

У квантовій механіці час `t` є зовнішнім параметром еволюції (параметром динамічної групи), а не ермітовим оператором у гільбертовому просторі. З цієї причини співвідношення невизначеності «енергія — час» виводиться через часову динаміку спостережуваних величин за методом Леоніда Мандельштама та Ігоря Тамма (1945).

Для довільного оператора `Â`, який не залежить від часу явно, його часова похідна визначається рівнянням руху Гейзенберга:

```
d⟨A⟩ / dt = (i / ℏ) ⟨[Ĥ, Â]⟩ [рівняння руху Гейзенберга для середнього значення]
```

Застосуємо співвідношення Робертсона до гамільтоніана `Ĥ` (оператора енергії) та оператора `Â`:

```
σ[H] · σ[A] ≥ (1 / 2) |⟨[Ĥ, Â]⟩|
= (ℏ / 2) |d⟨A⟩ / dt|   [підстановка з рівняння Гейзенберга]
```

Визначимо характерний час `Δt` як час, за який середнє значення величини `A` змінюється на величину свого стандартного відхилення: `Δt = σ[A] / |d⟨A⟩ / dt|`. Перегрупувавши члени нерівності, отримуємо **співвідношення Мандельштама — Тамма**:

```
σ[E] · Δt ≥ ℏ / 2       [теорема Мандельштама — Тамма (1945)]
```

Цей результат має пряме практичне застосування в атомній та ядерній фізиці: якщо збуджений стан атома чи нестабільна елементарна частинка має скінченний час життя `τ` (тобто `Δt ≈ τ`), то енергія цього стану не може бути визначена точно. Енергетичний рівень розмивається у смугу шириною `ΔE ≈ ℏ / τ`, що спостерігається в експерименті як природна ширина спектральної лінії (розподіл Брейта — Вігнера). Чим коротший час життя стану, тим ширшою є спектральна лінія випромінюваного фотона.
