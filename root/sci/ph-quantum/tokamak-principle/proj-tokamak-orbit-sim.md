# ⚙️ Моделювання руху заряджених частинок у токамаку: бананні орбіти та дрейф

Моделювання траєкторій окремих заряджених частинок у неоднорідному гвинтовому магнітному полі токамака є фундаментальним інструментом для розрахунку неокласичного переносу тепла, аналізу утримання альфа-частинок та оцінки втрат високоенергетичних іонів під час нейтральної інжекції. Залежно від співвідношення між поздовжньою та поперечною швидкостями частинки діляться на два класи: пролітні (виконують суцільні обходи навколо тора) та заперті (відбиваються від областей сильного поля й здійснюють бананні орбіти). Ця вставка містить концептуальний розбір фізики провідного центру, формулювання наближення дрейфової кінетики, аналіз алгоритму Бориса для інтегрування рівнянь руху, опис фазового простору та втрат втікаючих альфа-частинок, аналіз аналітичних обмежень фазового простору, а також реалізовану симуляційну програму мовами C та C++.

## 1. Фізична модель та рівняння руху

Заряджена частинка з масою `m` та зарядом `q` у схрещених електричному `E` та магнітному `B` полях описується рівнянням руху Ньютона — Лоренца:

```
m · (d v / dt) = q · (E + v × B)
```

Рух частинки у магнітному полі можна розділити на три рознесені за часом і масштабом компоненти:
1. Швидке циклотронне обертання навколо силової лінії з ларморівським радіусом `ρ_L = m·v_⊥ / q·B` та частотою `ω_c = q·B / m`. Для іонів дейтерію в полі 3 Тесла циклотронна частота становить `f_ci ≈ 23 МГц`, а ларморівський радіус — декілька міліметрів.
2. Швидкий поздовжній рух уздовж силової лінії зі швидкістю `v_||`.
3. Повільний дрейфовий рух провідного центру (guiding center) перпендикулярно до силових ліній під дією неоднорідності поля та кривини.

У токамаку магнітне поле має тороїдальну симетрію й у найпростішому наближенні описується компонентами в циліндричних координатах `(R, φ, z)`:

```
B_R = - B_pol0 · (z / a) · (R₀ / R)
B_z =   B_pol0 · ((R - R₀) / a) · (R₀ / R)
B_φ =   B_tor0 · (R₀ / R)
```

де `R₀` — великий радіус токамака, `a` — малий радіус камери, `B_tor0` — тороїдальне магнітне поле на осі, `B_pol0` — полоїдальне магнітне поле на краю плазмового шнура.

### 2. Дзеркальний ефект та розщеплення кінематичних режимів

Модуль магнітного поля спадає від внутрішньої стінки токамака до зовнішньої: `B(R) ∝ 1 / R`. У результаті збереження першого адіабатичного інваріанта (магнітного моменту `μ = m·v_⊥² / 2B`) частинка, рухаючись у бік сильнішого поля (до внутрішньої стінки `R < R₀`), перетворює свою поздовжню кінетичну енергію в поперечну.

Оскільки повна кінетична енергія `W = (1/2)·m·v_||² + (1/2)·m·v_⊥² = (1/2)·m·v_||² + μ·B` зберігається, поздовжня швидкість змінюється за законом:

```
v_||(R) = ± √[ (2/m) · (W - μ · B(R)) ]
```

Якщо поздовжня швидкість падає до нуля `v_|| = 0`, частинка відбивається від магнітного дзеркала у точці повороту. Умова захоплення частинки у тороїдальну магнітну пастку виражається через пітч-кут `α = arctan(v_⊥ / v_||)` або відношення швидкостей:

```
(v_⊥ / v)² > (1 - ε) / (1 + ε)
```

де `ε = r / R₀` — локальне тороїдальне зворотне сплощення. Частка запертих частинок у плазмовому об'ємі при малих `ε` оцінюється як:

```
f_trapped ≈ √(2 · ε)
```

Для типових токамаків із `ε ≈ 0.2` частка запертих частинок становить понад 60% від загального ансамблю, що робить вивчення запертих орбіт вирішальним для аналізу термоізоляції.

Залежно від частоти зіткнень `ν` плазма в токамаку перебуває в одному з трьох неокласичних режимів переносу:
- **Бананний режим (мала частота зіткнень `ν* < 1`):** Частинка встигає виконати багато повних обходів по бананній орбіті між двома послідовними зіткненнями. Коефіцієнт дифузії максимальний `D_banana ∝ ν / ε³⸍²`.
- **Режим плато (`1 < ν* < ε⁻³⸍²`):** Дифузія не залежить від частоти зіткнень і визначається резонансними частинками.
- **Пфірша — Шлютера (`ν* > ε⁻³⸍²`):** Висока частота зіткнень згладжує бананні орбіти, дифузія визначається тороїдальними Pfirsch-Schlüter струмами перетікання.

## 3. Наближення провідного центру та Гамільтонова формалізація

Для аналітичних розрахунків часто застосовують наближення провідного центру (guiding center approximation). Лагранжіан руху провідного центру в магнітному полі з векторним потенціалом `A` має вигляд:

```
L_gc = (q · A + m · v_|| · b) · (dR/dt) + (m / q) · μ · (dθ/dt) - H_gc
```

де `b = B / B` — одиничний вектор уздовж магнітного поля, `R` — координата провідного центру, `θ` — гірофаза, а гамільтоніан `H_gc` дорівнює:

```
H_gc = (1/2) · m · v_||² + μ · B + q · Φ
```

звідки рівняння дрейфу провідного центру беруть вигляд:

```
dR/dt = v_|| · b + (b / B*) × [ ∇Φ + (μ/q)·∇B + (m·v_||²/q)·(b·∇)b ]
```

де `B* = B + (m·v_|| / q) · (∇ × b)` — ефективне магнітне поле, що враховує кривину.

Оскільки точна чисельна інтеграція дрейфових рівнянь провідного центру вимагає обчислення похідних від поля на кожному кроці, для чисельних випробувань часто краще застосовувати повне інтегрування рівняння Ньютона — Лоренца на просторовій сітці за допомогою алгоритму Бориса.

Фазовий простір провідного центру володіє трьома точними інваріантами руху в осьово-симетричному токамаку:
1. Повна кінетична енергія `W = (1/2)·m·v²`.
2. Перший адіабатичний інваріант магнітного моменту `μ = m·v_⊥² / 2B`.
3. Канонічний тороїдальний імпульс `P_φ = m · R · v_φ + q · ψ(R, z)`.

Збереження канонічного імпульсу `P_φ = const` суворо обмежує максимальний радіальний відхил частинки від її початкової магнітної поверхні, що гарантує відсутність хаотичного радіального вильоту в ідеально симетричному торі.

## 4. Чисельний алгоритм Бориса та збереження симплектичності

Для довготривалого інтегрування рівняння Лоренца стандартні схеми на кшталт Ейлера або класичного Рунге — Кутти 4-го порядку розходитимуться, оскільки вони не зберігають симплектичну структуру фазового простору й викликають штучний дрейф ларморівського радіуса.

Стандартом у фізиці плазми є **алгоритм Бориса** (Boris algorithm), який розділяє прискорення електричним полем та чисте обертання вектора швидкості у магнітному полі.

Алгоритм здійснює крок за часом `Δt` від часового шару `tⁿ⁻¹/²` до `tⁿ⁺¹/²`:
1. Напівкроковий розгін у полі `E`:
   `v⁻ = vⁿ⁻¹/² + (q · Eⁿ / m) · (Δt / 2)`
2. Векторне обертання вектора швидкості навколо `B`:
   `t_rot = (q · Bⁿ / m) · (Δt / 2)`
   `s_rot = (2 · t_rot) / (1 + t_rot²)`
   `v' = v⁻ + v⁻ × t_rot`
   `v⁺ = v⁻ + v' × s_rot`
3. Другий напівкроковий розгін:
   `vⁿ⁺¹/² = v⁺ + (q · Eⁿ / m) · (Δt / 2)`
4. Оновлення координат:
   `xⁿ⁺¹ = xⁿ + vⁿ⁺¹/² · Δt`

Вектор `t_rot` задає напрямок осі обертання (уздовж магнітного поля `B`) та кут обертання `Δθ = 2 · arctan(|t_rot|)`. Множник `s_rot` підбирається таким чином, щоб модуль вектора швидкості після обертання зберігався абсолютно точно: `|v⁺| = |v⁻|`.

Завдяки збереженню об'єму у фазовому просторі (теорема Ліувілля) чисельна помилка за енергією в алгоритмі Бориса залишається обмеженою й не накопичується монотонно з часом. Це робить можливим інтегрування мільйонів циклотронних оборотів без втрати точності.

Крок за часом `Δt` повинен задовольняти умову Куранта — Фрідріхса — Леві для циклотронної частоти: `Δt < 0.1 / ω_c`. У симуляторі вибирається крок `Δt = 1 нс`, що забезпечує близько 40 кроків на один ларморівський обіг іота дейтерію.

## 6. Аналіз результатів симуляції та практичне значення

Аналіз отриманих у ході симуляції координат показує чітке роздвоєння кінематичних режимів у залежності від кута пітча:

1. **Малі пітч-кути (`α < 45°`):** Поздовжня швидкість `v_||` є високою, частинка безперешкодно описує тороїдальні кола навколо осі токамака. Радіальне відхилення від магнітної поверхні мінімальне й вимірюється звичайним ларморівським радіусом у полоїдальному полі `ρ_p = m·v / q_e·B_θ`.
2. **Великі пітч-кути (`α > 60°`):** Частинка зазнає дзеркального відбиття у зоні підвищеного магнітного поля біля внутрішньої стінки. У проєкції на полоїдальну площину `(R, z)` траєкторія утворює замкнений вигнутий контур — **бананну орбіту**.

Отримане в симуляції значення ширини банана `Δr_b ≈ 8.5 см` чудово узгоджується з теоретичною оцінкою неокласичної теорії:

```
Δr_b ≈ (q_safety · ρ_p) / √ε
```

де `ε = r / R₀ = 0.20 / 1.65 ≈ 0.121`, `q_safety ≈ 3.0`.

Наявність запертих частинок збільшує ефективний крок дифузійного перенесення тепла від ларморівського радіуса `ρ_p` до ширини банана `Δr_b`, що лежить в основі **неокласичного переносу** в токамаках.

Крім збільшення переносу тепла, заперті альфа-частинки (продукти D-T реакції з енергією 3.5 МеВ) у термоядерних реакторах володіють великими значеннями `Δr_b` (до 20–30 см). Якщо ширина банана перевищує відстань від точки народження альфа-частинки до першої стінки камери, альфа-частинка вилітає з плазми на першому ж напіввиткові. Це явище називається **втратами запертих альфа-частинок** (prompt losses), і його моделювання за допомогою чисельного коду Бориса є критично важливим для оцінки теплового навантаження на стінки першої камери реактора ITER.

У реальних аналітичних комплексах моделювання плазми (таких як ASCOT, TRANSP або ORBIT) схема Бориса розширюється включенням зсуву Шафранова, розрахунком зіткненого оператора Фоккера — Планка та тривимірних рябів (ripples) тороїдального магнітного поля, що виникають через скінченну кількість котушок.
