# 🧮 Релятивістська кінематика та збереження 4-імпульсу при народженні й анігіляції пар

Ця математична вставка містить строгі виведення релятивістського порога енергії для утворення електрон-позитронних пар у полях різних частинок-мішеней, доведення неможливості утворення пари одним фотоном у порожньому вакуумі, кінематику фотон-фотонного народження пар у астрофізиці, а також розрахунок квантовомеханічних правил відбору та часу життя для анігіляції позитронія.

## Неможливість народження пари одним фотоном у вакуумі

Розглянемо гіпотетичну реакцію перетворення одного фотона з 4-імпульсом `k^μ` на електрон-позитронну пару з 4-імпульсами `p_-^μ` та `p_+^μ` у порожньому вакуумі:

```
γ → e⁻ + e⁺
```

Закон збереження 4-імпульсу вимагає рівності вихідного та підсумкового 4-імпульсів:

```
k^μ = p_-^μ + p_+^μ
```

У чотиривимірному просторі Мінковського зі світлово-подібною метрикою `g_μν = diag(1, -1, -1, -1)` візьмемо квадрат 4-вектора з обох боків рівняння, використовуючи лоренц-інваріантний скалярний добуток `A^μ A_μ = (A⁰)² - A²`:

```
k^μ k_μ = (p_-^μ + p_+^μ) (p_-;μ + p_+;μ)
= p_-^μ p_-;μ + p_+^μ p_+;μ + 2 p_-^μ p_+;μ     [розкриття квадрата 4-імпульсів]
```

Підставимо відомі значення лоренцівських інваріантів для масивних частинок та фотона на масовій поверхні (on-shell):
- Для реального фотона маса спокою дорівнює нулю, тому `k^μ k_μ = 0`.
- Для електрона та позитрона `p_-^μ p_-;μ = m_e² c²` та `p_+^μ p_+;μ = m_e² c²`.

Отримуємо співвідношення:

```
0 = 2 m_e² c² + 2 p_-^μ p_+;μ                    [підстановка масових інваріантів]
= 2 m_e² c² + 2 (E_- E_+ / c² - p_- · p_+)       [розкриття скалярного добутку 4-векторів]
```

Виразимо скалярний добуток 3-імпульсів через кут `θ` між напрямками руху електрона та позитрона:

```
E_- E_+ / c² - |p_-| |p_+| cos(θ) = -m_e² c²     [перенесення сталих доданків]
```

Оскільки для релятивістських частинок з масою `m_e > 0` повна енергія виражається як `E = √(p² c² + m_e² c⁴) > |p| c`, оцінимо мінімальне можливе значення лівої частини рівняння за будь-яких кутів `θ` та імпульсів:

```
E_- E_+ / c² - |p_-| |p_+| cos(θ) ≥ E_- E_+ / c² - |p_-| |p_+|
> (|p_-| c) (|p_+| c) / c² - |p_-| |p_+| = 0
```

Отримали строгу алгебраїчну суперечність: ліва частина є строго додатною величиною `> 0`, тоді як права частина дорівнює від'ємній константі `-m_e² c² < 0`.

Альтернативно, можна виконати перетворення Лоренца у систему центру мас (СЦМ) сформованої електрон-позитронної пари, де за визначенням сумарний 3-імпульс дорівнює нулю `p_- + p_+ = 0`. У цій системі відліку сумарна енергія пари є суворо додатною і дорівнює принаймні двойній масі спокою `E_total = E_- + E_+ ≥ 2 m_e c² > 0`. Однак для початкового фотона умова `k = 0` означає, що його енергія також мала б дорівнювати нулю `E_γ = |k| c = 0`. Але фотон з нульовою енергією не існує (це відсутність випромінювання).

Висновок: народження пари фотоном у вакуумі без присутності зовнішнього поля третього тіла (ядра, електрона або іншого фотона) заборонене законами збереження 4-імпульсу.

## Розрахунок енергетичного порога в кулонівському полі ядра

Для здійснення процесу `γ + N → e⁻ + e⁺ + N'` необхідна присутність частинки-мішені (атомного ядра `N` з масою `M_N`), яка підхоплює імпульс віддачі `q_N`.

Обчислимо порогову енергію фотона `E_γ;thresh` у лабораторній системі відліку, де ядро початково перебувало у спокої.

4-імпульси до реакції:
- Фотона: `k^μ = (E_γ / c, k)`
- Ядра: `P_N^μ = (M_N c, 0)`

Сумарний 4-імпульс системи до реакції:

```
P_in^μ = k^μ + P_N^μ = (E_γ / c + M_N c, k)
```

Обчислимо лоренц-інваріантний квадрат 4-імпульсу до реакції (перша змінна Мандельштама `s = P_in^μ P_in;μ`):

```
s = (E_γ / c + M_N c)² - |k|²
= E_γ² / c² + 2 E_γ M_N + M_N² c² - E_γ² / c²    [оскільки для фотона |k| = E_γ / c]
= M_N² c² + 2 E_γ M_N                           [скорочення квадратів фотонної енергії]
```

На порозі реакції у системі центру мас усі утворені продукти (електрон, позитрон та ядро віддачі) народжуються у стані відносного спокою (`p_- = p_+ = P'_N = 0`). Тоді сумарний 4-імпульс системи після реакції в СЦМ дорівнює:

```
P_out^μ = ((2 m_e + M_N) c, 0)
```

Інваріантний квадрат 4-імпульсу після реакції на порозі:

```
s_thresh = P_out^μ P_out;μ
= ((2 m_e + M_N) c)²                             [піднесення 4-вектора до квадрата в СЦМ]
= (2 m_e + M_N)² c²                              [винесення константи c]
= 4 m_e² c² + 4 m_e M_N c² + M_N² c²             [розкриття квадрата суми трьох мас]
```

Завдяки лоренц-інваріантності величина `s` однакова в усіх інерціальних системах відліку, тому `s = s_thresh`:

```
M_N² c² + 2 E_γ M_N = M_N² c² + 4 m_e M_N c² + 4 m_e² c²
```

Віднімемо `M_N² c²` з обох частин рівняння та виразимо порогову енергію фотона `E_γ;thresh`:

```
2 E_γ;thresh M_N = 4 m_e M_N c² + 4 m_e² c²      [віднімання однакових масових членів M_N² c²]
E_γ;thresh = (4 m_e M_N c² + 4 m_e² c²) / (2 M_N) [ділення на коефіцієнт 2 M_N]
= 2 m_e c² · (1 + m_e / M_N)                     [винесення за дужки фактора 2 m_e c²]
```

Розглянемо граничні випадки цієї загальної формули:

1. **Важке ядро (`M_N >> m_e`):**
   Для ядра свинцю `²⁰⁸Pb` маса `M_N ≈ 208 × 931.5 МеВ ≈ 193.7 Ггв`. Відношення `m_e / M_N ≈ 0.511 МеВ / 193700 МеВ ≈ 2.6 × 10⁻⁶`.
   Поправка віддачі є нехтовно малою, і поріг дорівнює подвійній масі спокою електрона:
   
   ```
   E_γ;thresh ≈ 2 m_e c² = 2 · 0.510999 МеВ = 1.021998 МеВ
   ```

2. **Легке ядро або протон (`M_N = m_p ≈ 1836 m_e`):**
   Поправка `m_e / m_p ≈ 1 / 1836 ≈ 0.00054`. Порогова енергія становить:
   
   ```
   E_γ;thresh = 1.022 МеВ · (1 + 0.00054) = 1.02255 МеВ
   ```

3. **Триплетне народження на вільному електроні (`M_N = m_e`):**
   Якщо мішенню є вільний електрон `γ + e⁻ → e⁻ + e⁻ + e⁺`, маса мішені дорівнює масі електрона `M_N = m_e`.
   
   ```
   E_γ;thresh = 2 m_e c² · (1 + m_e / m_e) = 4 m_e c² ≈ 2.04399 МеВ
   ```
   Порогова енергія збільшується вдвічі, оскільки на порозі реакції три однакові частинки мають значний сумарний імпульс віддачі в лабораторній системі.

## Кінематика фотон-фотонного народження пар (процес Брейта — Вілера)

У фізиці високих енергій та астрофізиці можливий процес народження електрон-позитронних пар під час зіткнення двох реальних гамма-квантів у вакуумі:

```
γ₁ + γ₂ → e⁻ + e⁺
```

Знайдемо порогові умови для енергій двох фотонів `E₁` та `E₂`, які зіштовхуються під кутом `θ` у лабораторній системі відліку.

4-імпульси двох фотонів:
- `k₁^μ = (E₁ / c, k₁)`
- `k₂^μ = (E₂ / c, k₂)`

Інваріантний квадрат сумарного 4-імпульсу до реакції:

```
s = (k₁ + k₂)^μ (k₁ + k₂)_μ
= k₁^μ k₁;μ + k₂^μ k₂;μ + 2 k₁^μ k₂;μ            [розкриття скалярного квадрата суми 4-векторів]
= 0 + 0 + 2 (E₁ E₂ / c² - k₁ · k₂)               [підстановка нульових мас фотонів k₁² = k₂² = 0]
= 2 E₁ E₂ / c² · (1 - cos θ)                     [вираження скалярного добутку 3-векторів через кут θ]
```

На порозі реакції мінімальний квадрат маси утвореної електрон-позитронної пари становить `s_thresh = 4 m_e² c²`.

Зрівнюючи `s = s_thresh`, отримуємо загальну умову порогових енергій для фотон-фотонного народження пар:

```
2 E₁ E₂ / c² · (1 - cos θ) ≥ 4 m_e² c²          [прирівнювання інваріанта s до порога 4 m_e² c²]
E₁ E₂ · (1 - cos θ) ≥ 2 m_e² c⁴                 [скорочення двійки та множення на c²]
```

Аналіз окремих геометрій зіткнення:

1. **Лобове зіткнення (`θ = 180°`, `cos θ = -1`):**
   
   ```
   E₁ E₂ · (1 - (-1)) ≥ 2 m_e² c⁴               [підстановка cos(180°) = -1]
   = 2 E₁ E₂ ≥ 2 m_e² c⁴                        [спрощення дужки 1 - (-1) = 2]
   E₁ E₂ ≥ (m_e c²)² ≈ (0.511 МеВ)² ≈ 0.261 МеВ² [скорочення двійки]
   ```
   Якщо обидва фотони мають однакову енергію `E₁ = E₂`, порогова енергія для кожного з них становить `E_min = m_e c² = 0.511 МеВ`.

2. **Зіткнення гамма-кванта з фотоном реліктового випромінювання (CMB):**
   Середня енергія фотонів реліктового випромінювання Всесвіту з температурою `T = 2.725 K` становить `E₂ ≈ 2.7 k_B T ≈ 6.34 × 10⁻⁴ еВ`.
   Знайдемо порогову енергію гамма-кванта `E₁` при лобовому зіткненні з реліктовим фотоном:
   
   ```
   E₁ ≥ (m_e c²)² / E₂                           [вираження E₁ через порогову умову]
   = (0.511 × 10⁶ еВ)² / (6.34 × 10⁻⁴ еВ)
   ≈ 4.12 × 10¹⁴ еВ = 412 ТеВ
   ```
   Цей ефект створює **прозоростний поріг Всесвіту**: гамма-кванти надвисоких енергій (`E > 400 ТеВ`) не можуть долати міжгалактичні відстані, оскільки ефективно поглинаються реліктовим випромінюванням, перетворюючись на електрон-позитронні пари.

## Квантовомеханічні правила відбору при анігіляції позитронія

Розглянемо закони збереження симетрій при анігіляції зв'язаного стану електрон-позитронної пари (позитронія).

Власний стан позитронія описується квантовими числами:
- Орбітальним моментом `L`;
- Сумарним спіном `S` (`S = 0` для парапозитронія, `S = 1` для ортопозитронія);
- Повним моментом `J = L + S`;
- Зарядовою парністю `C` та просторовою парністю `P`.

Оператор зарядового спряження `C` змінює місцями електрон і позитрон, що еквівалентно обміну їхніх просторових координат (чинник `(-1)^L`), спінових станів (чинник `(-1)^(S+1)`) та знаку заряду. Загальна зарядова парність стану позитронія виражається формулою:

```
C = (-1)^(L + S)
```

Для фотонного стану з `n` фотонами зарядова парність дорівнює:

```
C(n γ) = (-1)^n
```

Оскільки електромагнітна взаємодія зберігає зарядову парність `C`, висуваємо умову `C(позитроній) = C(n γ)`:

```
(-1)^(L + S) = (-1)^n
```

Для основного стану позитронія (`L = 0`):

1. **Парапозитроній (`¹S₀`):** `L = 0`, `S = 0`.
   Зарядова парність `C = (-1)⁰⁺⁰ = +1`.
   Оскільки `C(n γ) = (-1)^n = +1`, кількість утворених фотонів `n` має бути строго **парним числом** (`n = 2, 4, 6, ...`).
   Найбільш імовірним є двофотонний розпад `e⁻ + e⁺ → 2γ`.

2. **Ортопозитроній (`³S₁`):** `L = 0`, `S = 1`.
   Зарядова парність `C = (-1)⁰⁺¹ = -1`.
   Оскільки `C(n γ) = (-1)^n = -1`, кількість утворених фотонів `n` має бути строго **непарним числом** (`n = 3, 5, 7, ...`).
   Двофотонний розпад строго заборонений законами збереження `C`-парності. Найбільш імовірним є трифотонний розпад `e⁻ + e⁺ → 3γ`.

Обчислимо імовірність розпаду парапозитронія `Γ_para` в першому порядку теорії збурень КЕД (формула Вілера):

```
Γ_para = (1 / 2) · α⁵ · (m_e c² / ħ)
```

Підставивши числові значення `α ≈ 1 / 137.036`, `m_e c² / ħ ≈ 7.763 × 10²⁰ с⁻¹`:

```
Γ_para ≈ 0.5 · (1 / 137.036)⁵ · 7.763 × 10²⁰ с⁻¹ ≈ 7.99 × 10⁹ с⁻¹
τ_para = 1 / Γ_para ≈ 1.25 × 10⁻¹⁰ с = 0.125 нс
```

Для ортопозитронія розрахунок імовірності розпаду `Γ_ortho` враховує тривимірний фазовий об'єм трьох вихідних фотонів (формула Оре — Пауелла):

```
Γ_ortho = (2 / 9 π) · (π² - 9) · α⁶ · (m_e c² / ħ)
```

Числове значення для часу життя ортопозитронія:

```
Γ_ortho ≈ 7.04 × 10⁶ с⁻¹
τ_ortho = 1 / Γ_ortho ≈ 1.42 × 10⁻⁷ с = 142 нс
```

Співвідношення часів життя `τ_ortho / τ_para ≈ 1136` відображає пригнічення трифотонного розпаду додатковим множником постійної тонкої структури `α`.
