# 📜 Історія відкриття формули Бальмера та сталі Рідберга

Розвиток спектроскопії водню охоплює півстолітній шлях наукових пошуків від перших оптичних вимірювань його випромінювання у XIX столітті до формування квантової механіки атома.

У другій половині XIX століття оптична спектроскопія перетворилася на один із найпотужніших методів фізичного та хімічного дослідження матерії. Завдяки роботам німецьких вчених Густава Кірхгофа та Роберта Бунзена було з'ясовано, що кожен хімічний елемент у газоподібному стані при нагріванні або під дією електричного розряду випромінює свій унікальний лінійчатий спектр, який слугує своєрідним «паспортом» елемента.

У 1868 році шведський фізик і астроном Андерс Йонас Онгстрем (Anders Jonas Ångström) опублікував свій знаменитий атлас сонячного спектра («Recherches sur le spectre solaire»), який містив виміряні з невиданою раніше прецизійністю довжини хвиль понад тисячі спектральних ліній. Серед них особливу увагу привертали чотири яскраві лінії у видимому діапазоні випромінювання розрідженого водню в газорозрядній трубці Ґейсслера. Ці лінії отримали позначення `H_α` (червона, 656.28 нм), `H_β` (блакитна, 486.13 нм), `H_γ` (синьо-фіолетова, 434.05 нм) та `H_δ` (фіолетова, 410.17 нм).

Попри точність експериментальних даних Онгстрема, фізична природа цих ліній залишалася абсолютно незбагненною таємницею. Наприкінці XIX століття панувала класична електродинаміка Джеймса Клерка Максвелла, за якою випромінювання світла вважалося наслідком електромагнітних коливань зарядів. Проте за класичною фізикою атом повинен був випромінювати суцільний безперервний спектр усіх частот, а електрон під дією радіаційного гальмування мав за частки секунди впасти на ядро. Реальний спектр водню демонстрував сувору дискретність і математичний порядок, пояснити який тогочасна фізика не мала жодних теоретичних можливостей.

## Емпіричний прорив Йоганна Бальмера (1885)

Вирішальний математичний прорив у цій загадці відбувся у 1885 році і надійшов із зовсім несподіваного боку. Його здійснив швейцарський математик і викладач геометричного креслення жіночої школи в Базелі Йоганн Якоб Бальмер (Johann Jakob Balmer), якому на момент публікації виповнилося 60 років. Бальмер не мав власної лабораторії і не проводив фізичних експериментів, але володів винятковим аналітичним розумом та захоплювався пошуком прихованих числових гармоній у природі.

За порадою свого колеги-фізика Едуарда Гаґенбаха, Бальмер звернув увагу на точні довжини хвиль чотирьох ліній водню з атласу Онгстрема. Підбираючи математичні комбінації цілих чисел, Бальмер помітив дивовижну закономірність: відношення довжин хвиль цих чотирьох ліній до точності у чотири значущі цифри відповідає відношенням простих квадратів цілих чисел.

У своїй історичній статті 1885 року «Зауваження щодо спектральних ліній водню» («Notiz über die Spectrallinien des Wasserstoffs»), опублікованій у часописі Annalen der Physik, Бальмер сформулював емпіричну формулу для довжин хвиль:

```
λ = h · (m² / (m² - n²))
```

де `n = 2`, параметр `m` приймає послідовні цілі значення `m = 3, 4, 5, 6` для чотирьох ліній відповідно, а стала пропорційності `h` дорівнювала `3645.6 × 10⁻¹⁰ м` (або `364.56 нм`).

Перевірка формули Бальмера для відомих ліній дала вражаючий збіг з експериментом Онгстрема:

- Для `m = 3` (`H_α`): `λ = 364.56 · (9 / 5) = 656.21 нм` (експеримент 656.28 нм, похибка менше `0.01%`);
- Для `m = 4` (`H_β`): `λ = 364.56 · (16 / 12) = 486.08 нм` (експеримент 486.13 нм);
- Для `m = 5` (`H_γ`): `λ = 364.56 · (25 / 21) = 434.00 нм` (експеримент 434.05 нм);
- Для `m = 6` (`H_δ`): `λ = 364.56 · (36 / 32) = 410.13 нм` (експеримент 410.17 нм).

Бальмер зробив сміливе передбачення: формула не є випадковим числовим збігом. Вона вказує на існування п'ятої лінії для `m = 7` (`λ = 397.0 нм`), шостої для `m = 8` (`λ = 388.9 нм`) і так далі, а константа `h = 364.56 нм` є граничною довжиною хвилі серії при `m → ∞`. Крім того, Бальмер припустив, що за іншими значеннями `n` (`n = 1, 3, 4...`) мають існувати інші цілі серії ліній водню. Незабаром астрономи виявили передбачені лінії у спектрах випромінювання гарячих білих зірок (зокрема Веги) та сонячних спалахів, що повністю підтвердило фундаментальну істинність формули Бальмера.

## Узагальнення Йоганнеса Рідберга (1888)

У 1888 році шведський фізик Йоганнес Рідберг (Johannes Rydberg) з Лундського університету проводив масштабні дослідження спектрів випромінювання лужних металів (літію, натрію, калію). Рідберг намагався знайти періодичний закон, який пов'язував би спектральні лінії елементів із їхнім місцем у таблиці Менделєєва.

Рідберг зробив два вирішальних алгоритмічних кроки:

1. Замість довжини хвилі `λ` він запропонував використовувати **хвильове число `ν̄ = 1 / λ`** (кількість просторових періодів хвилі на одиницю довжини). Це перетворило складні дробові співвідношення на лінійні віднімання.
2. Він виявив, що спектральні лінії більшості елементів групуються у серії, які описуються різницею двох математичних функцій — **спектральних термів**.

Переписавши формулу Бальмера для хвильового числа, Рідберг надав їй універсального та симетричного вигляду:

```
ν̄ = 1 / λ = R_∞ · (1 / 2² - 1 / m²)
```

де `R_∞ = 4 / h ≈ 1.097 × 10⁷ м⁻¹` — величина, яка отримала назву **стала Рідберга**.

Рідберг узагальнив цю формулу для переходів між довільними двома цілими числами `n₁` та `n₂` (де `n₂ > n₁`):

```
ν̄ = R_∞ · (1 / n₁² - 1 / n₂²)
```

Це співвідношення пророкувало існування цілого сімейства невідомих спектральних серій водню у невидимих діапазонах випромінювання:

- **Серія Лаймана (`n₁ = 1`)**: передбачена Рідбергом і виявлена Теодором Лайманом (Theodore Lyman) у 1906 році в глибокому ультрафіолеті.
- **Серія Пашена (`n₁ = 3`)**: відкрита Луїсом Пашеном (Louis Paschen) у 1908 році в інфрачервоному діапазоні.
- **Серія Брекета (`n₁ = 4`)**: відкрита Фредеріком Брекетом (Frederick Brackett) у 1922 році.
- **Серія Пфунда (`n₁ = 5`)**: відкрита Августом Пфундом (August Pfund) у 1924 році.
- **Серія Гемфрі (`n₁ = 6`)**: відкрита Кертісом Гемфрі (Curtis Humphreys) у 1953 році.

## Комбінаційний принцип Рітца (1908)

У 1908 році молодий швейцарський математичний фізик Вальтер Рітц (Walther Ritz) сформулював фундаментальний **комбінаційний принцип**: хвильове число будь-якої спектральної лінії хімічного елемента можна подати як різницю двох спектральних термів `ν̄ = T(n₁) - T(n₂)`. Для атома водню спектральний терм має просту форму `T(n) = R_∞ / n²`.

Принцип Рітца дав глибоку фізичну підказку: спектральні лінії є не первинними властивостями елемента, а лише **вторинними переходами** між більш фундаментальними внутрішніми квантовими станами атома — його енергетичними рівнями.

## Квантове пояснення Ніком Бором (1913)

Попри дивовижний успіх формул Бальмера, Рідберга та Рітца, протягом майже трьох десятиліть фізична природа константи `R_∞` залишалася повною загадкою. Вона сприймалася як підганяльний коефіцієнт пропорційності.

Вирішальний теоретичний прорив відбувся у 1913 році, коли 28-річний данський фізик Нільс Бор (Niels Bohr), працюючи в лабораторії Ернеста Резерфорда в Манчестері, опублікував свою революційну трилогію статей «Про будову атомів і молекул».

Бор об'єднав планетарну модель атома Резерфорда (важке позитивне ядро та легкий електрон) із квантовою гіпотезою Макса Планка та Альберта Ейнштейна. Бор висунув три квантові постулати:

1. **Існування стаціонарних станів**: електрон в атомі може перебувати лише у певних стаціонарних квантових станах із дискретними енергіями `E_n`, у яких він, наперекір класичній електродинаміці, зовсім не випромінює електромагнітних хвиль.
2. **Правило квантування моменту імпульсу**: орбітальний момент імпульсу електрона на коловій орбіті квантується за цілочисельним правилом:

```
L = m_e · v · r = n · ℏ     [де n = 1, 2, 3... та ℏ = h / (2π)]
```

3. **Умова частот переходів**: випромінювання або поглинутий квант світла має енергію, що дорівнює різниці енергій стаціонарних станів: `h · ν = E_n2 - E_n1`.

Комбінуючи правило квантування моменту з другим законом Ньютона для кулонівської сили `(m_e v² / r = e² / (4πε₀ r²))`, Бор теоретично вивів вираз для радіусів дозволених борівських орбіт:

```
r_n = n² · a₀ = n² · ((4 · π · ε₀ · ℏ²) / (m_e · e²))
```

де `a₀ ≈ 0.529 × 10⁻¹⁰ м` — **борівський радіус** основного стану водню.

Та вивів точну формулу для дискретних енергетичних рівнів:

```
E_n = - (m_e · e⁴) / (32 · π² · ε₀² · ℏ² · n²)
```

Звідси Бор вперше в історії фізики виразив сталу Рідберга через фундаментальні константи:

```
R_∞ = (m_e · e⁴) / (8 · ε₀² · h³ · c)
```

Коли Бор підставив у цю формулу виміряні у незалежних експериментах значення маси електрона `m_e`, його заряду `e`, сталої Планка `h`, електричної сталої `ε₀` та швидкості світла `c`, теоретично розраховане значення `R_∞` збіглося з емпіричною константою Рідберга з точністю вище `0.1%`. Це стало першим вирішальним доказом правильності квантової теорії та відкрило еру сучасної атомної фізики.
