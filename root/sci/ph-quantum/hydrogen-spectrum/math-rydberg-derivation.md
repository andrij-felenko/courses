# 🧮 Виведення сталі Рідберга та енергетичних рівнів з рівняння Шредінгера

Ця математична вставка містить точне квантовомеханічне виведення дискретного спектра енергії атома водню, аналітичний розв'язок тривимірного рівняння Шредінгера в центросиметричному кулонівському потенціалі та математичний вираз для сталої Рідберга.

У квантовій механіці задача про атом водню є єдиною точнісінько розв'язуваною тривимірною задачею для двох взаємодіючих тіл. Результати цього математичного виведення слугують базовим фундаментом для всієї атомної фізики, квантової хімії та теорії будови речовини.

## 1. Редукція задачі двох тіл та Гамільтоніан системи

Розглянемо замкнену двочастинкову систему, яка складається з ядра (протона або дейтерону) з масою `M` та зарядом `+Z·e` (для нейтрального атома водню `Z = 1`) і електрона з масою `m_e` та зарядом `-e`. 

Повний оператор Гамільтона цієї системи двох частинок у радіус-векторах ядра `r_n` та електрона `r_e` має вигляд:

```
H = - (ℏ² / (2M)) · ∇_n² - (ℏ² / (2m_e)) · ∇_e² + V(|r_e - r_n|)
```

де кулонівська потенціальна енергія взаємодії виражається класичним законом Кулона:

```
V(r) = - (Z · e²) / (4 · π · ε₀ · r)
```

де `r = |r_e - r_n|` — відстань між електроном і ядром.

Для розділення руху системи перейдемо від лабораторних координат `(r_n, r_e)` до координат центру мас `R_cm` та відносного радіус-вектора `r`:

```
R_cm = (M · r_n + m_e · r_e) / (M + m_e)
r = r_e - r_n
```

У цих нових змінних Гамільтоніан системи розпадається на суму двох незалежних операторів:

```
H = H_cm + H_rel
```

де `H_cm = - (ℏ² / (2M_tot)) · ∇_cm²` описує вільний поступальний рух центру мас із сумарною масою `M_tot = M + m_e`, а `H_rel` описує відносний рух частинки зі **скороченою масою `μ`**:

```
μ = (m_e · M) / (m_e + M) = m_e / (1 + m_e / M)
```

Повний хвильовий розв'язок подається у вигляді `Ψ_tot(R_cm, r) = exp(i K · R_cm) · Ψ(r)`. Поступальний рух центру мас є тривіальним випромінюванням вільної частинки, тому далі ми зосереджуємося виключно на рівнянні для відносного руху `H_rel Ψ(r) = E Ψ(r)`:

```
- (ℏ² / (2μ)) · ∇² Ψ(r) - (Z · e² / (4 · π · ε₀ · r)) · Ψ(r) = E · Ψ(r)
```

## 2. Сферичне розділення змінних та кутові сферичні гармоніки

Оскільки кулонівський потенціал `V(r)` володіє суворою сферичною симетрією (не залежить від кутів `θ` та `φ`), оператор Гамільтона `H_rel` комутує з оператором квадрата орбітального моменту `L²` та оператором проєкції моменту `L_z`:

```
[H_rel, L²] = 0,    [H_rel, L_z] = 0
```

Це означає, що квантові стани атома мають спільний набір власних функцій. У сферичній системі координат `(r, θ, φ)` оператор Лапласа `∇²` подається через радіальну та кутову частини:

```
∇² = (1 / r²) · (∂ / ∂r)(r² · ∂ / ∂r) - (L² / (ℏ² · r²))
```

Шукаємо стаціонарні хвильові функції у вигляді добутку радіальної функції `R(r)` та кутових сферичних гармонік `Y_lm(θ, φ)`:

```
Ψ_{n, l, m}(r, θ, φ) = R_{n, l}(r) · Y_{l, m}(θ, φ)
```

Сферичні гармоніки `Y_lm(θ, φ)` є власними функціями оператора `L²` із власними значеннями `l(l + 1) ℏ²`, де `l = 0, 1, 2...` — орбітальне квантове число. Підставляючи цей розклад у рівняння Шредінгера та скорочуючи на `Y_lm`, отримуємо **радіальне рівняння Шредінгера** для функції `R(r)`:

```
(1 / r²) · (d / dr)(r² · dR / dr) + [(2μ / ℏ²) · (E + (Z · e²) / (4πε₀r)) - (l(l + 1) / r²)] · R(r) = 0
```

Ввівши допоміжну радіальну функцію `u(r) = r · R(r)`, можна звести це рівняння до одновимірного вигляду зі зсунутим ефективним потенціалом `V_eff(r)`:

```
- (ℏ² / (2μ)) · (d²u / dr²) + V_eff(r) · u(r) = E · u(r)
```

де ефективний потенціал містить кулонівське притягання та відштовхувальний центробіжний бар'єр:

```
V_eff(r) = - (Z · e²) / (4 · π · ε₀ · r) + (l(l + 1) · ℏ²) / (2 · μ · r²)
```

## 3. Асимптотичний аналіз та безрозмірні змінні

Розглядаємо дискретний спектр зв'язаних станів з від'ємною енергією `E < 0`. Для переходу до безрозмірних величин введемо масштабний параметр довжини `α` та безрозмірний радіус `ρ`:

```
α² = - (8 · μ · E) / ℏ²
ρ = α · r
γ = (Z · e² · μ) / (4 · π · ε₀ · ℏ² · α)
```

Зауважимо, що енергія `E` виражається через масштабний параметр `α` як:

```
E = - (ℏ² · α²) / (8 · μ)
```

Переписавши радіальне диференціальне рівняння у безрозмірній змінній `ρ`, маємо:

```
(d²R / dρ²) + (2 / ρ) · (dR / dρ) + [- 1/4 + (γ / ρ) - (l(l + 1) / ρ²)] · R(ρ) = 0
```

Для знаходження фізично прийнятного розв'язку проведемо асимптотичний аналіз у граничних точках:

1. **Границя `ρ → ∞`**: у цій області члени `γ / ρ` та `l(l + 1) / ρ²` стають нескінченно малими порівняно з константою `1/4`. Рівняння спрощується до `d²R / dρ² - (1/4) R = 0`. Його загальний розв'язок `R(ρ) = A exp(- ρ / 2) + B exp(+ ρ / 2)`. Оскільки хвильова функція не повинна розбігатися на нескінченності (умова нормованості), ми зобов'язані покласти `B = 0`, що дає асимптотику `R(ρ) ~ exp(- ρ / 2)`.
2. **Границя `ρ → 0`**: центробіжний член `l(l + 1) / ρ²` домінує над іншими. Рівняння переходить у `d²R / dρ² + (2 / ρ) (dR / dρ) - (l(l + 1) / ρ²) R = 0`. Шукаючи розв'язок у формі степеня `R(ρ) ~ ρ^k`, отримуємо характеристичне рівняння `k(k + 1) = l(l + 1)`. Воно має два корені: `k = l` та `k = - (l + 1)`. Корінь `k = - (l + 1)` створює квадратично ненормовану інтегральну розбіжність ймовірності в центрі ядра, тому єдиним фізичним розв'язком є `R(ρ) ~ ρ^l`.

Враховуючи обидві асимптотики, шукаємо точний розв'язок радіального рівняння у вигляді добутку:

```
R(ρ) = ρ^l · exp(- ρ / 2) · w(ρ)
```

де `w(ρ)` — невідома гладка функція, яка описує відхилення від асимптотичної поведінки.

## 4. Вироджене гіпергеометричне рівняння та квантування енергії

Підставивши шукану форму `R(ρ)` у безрозмірне диференціальне рівняння та продиференціювавши добутки, отримуємо диференціальне рівняння для функції `w(ρ)`:

```
ρ · (d²w / dρ²) + [2(l + 1) - ρ] · (dw / dρ) + [γ - l - 1] · w = 0
```

Це рівняння належить до канонічного класу вироджених гіпергеометричних рівнянь Куммера:

```
z · (d²w / dz²) + (b - z) · (dw / dz) - a · w = 0
```

з параметрами `a = - (γ - l - 1)` та `b = 2l + 2`.

Загальним розв'язком цього рівняння є вироджена гіпергеометрична функція `w(ρ) = M(a, b, ρ)`, яка розкладається у степеневий ряд:

```
w(ρ) = 1 + (a / b) · ρ + (a(a + 1) / (b(b + 1) · 2!)) · ρ² + ...
```

Якщо коефіцієнт `a` не є від'ємним цілим числом, цей степеневий ряд містить нескінченну кількість членів. При `ρ → ∞` асимптотика нескінченного ряду `M(a, b, ρ)` поводиться як `exp(ρ)`. Підставивши це в `R(ρ) = ρ^l exp(- ρ / 2) w(ρ)`, ми б отримали радіальну функцію `R(ρ) ~ exp(+ ρ / 2)`, яка експоненційно зростає на нескінченності та ламає умову нормованості хвильової функції.

Єдиним способом забезпечити нормованість квантового стану є вимоги, щоб степеневий ряд обривався на скінченному члені, перетворюючись на поліном. Це відбувається тоді і тільки тоді, коли параметр `a` є цілим невід'ємним числом:

```
- a = γ - l - 1 = n_r      [де n_r = 0, 1, 2... — радіальне квантове число]
```

Визначимо **головне квантове число `n`** як суму радіального та орбітального квантових чисел плюс один:

```
n = n_r + l + 1      [отже n = 1, 2, 3...]
```

Оскільки `n_r ≥ 0` та `l ≥ 0`, головне квантове число `n` може приймати лише цілі додатні значення `n = 1, 2, 3...`, а для заданого `n` орбітальне квантове число обмежене зверху: `l = 0, 1, 2 ... n-1`.

Отже, умова існування зв'язаного нормованого квантового стану вимагає строгого виконання рівності:

```
γ = n
```

## 5. Точний вираз для сталих енергії та сталої Рідберга

Використовуючи квантову умову `γ = n`, підставимо її у визначення безрозмірного параметра `γ`:

```
n = (Z · e² · μ) / (4 · π · ε₀ · ℏ² · α)
```

Звідси виражаємо параметр масштабу `α`:

```
α = (Z · e² · μ) / (4 · π · ε₀ · ℏ² · n)
```

Тепер підставляємо знайдений вираз для `α` у формулу енергії `E = - (ℏ² α²) / (8 μ)`:

```
E_n = - (ℏ² / (8μ)) · [(Z · e² · μ) / (4 · π · ε₀ · ℏ² · n)]²
    = - (μ · Z² · e⁴) / (32 · π² · ε₀² · ℏ² · n²)
```

Виразивши зведену сталу Планка через звичайну сталу Планка `ℏ = h / (2π)`, отримуємо класичний вираз для енергетичних рівнів воднеподібного атома:

```
E_n = - (μ · Z² · e⁴) / (8 · ε₀² · h² · n²)
```

При переході електрона зі вищого стаціонарного стану `n₂` на нижчий стан `n₁` атом випромінює квант світла (фотон) із частотою `ν` та довжиною хвилі `λ`. За законом збереження енергії:

```
ΔE = E_n2 - E_n1 = h · ν = (h · c) / λ
```

Поділивши енергетичну різницю на `h · c`, отримуємо квантовомеханічну формулу для хвильового числа `ν̄ = 1 / λ`:

```
1 / λ = [(μ · Z² · e⁴) / (8 · ε₀² · h³ · c)] · (1 / n₁² - 1 / n₂²)
```

Порівнюючи цей теоретичний розрахунок з емпіричною формулою Бальмера — Рідберга `1 / λ = R_M Z² (1/n₁² - 1/n₂²)`, ми отримуємо точний квантовомеханічний вираз для **сталої Рідберга з урахуванням маси ядра**:

```
R_M = (μ · Z² · e⁴) / (8 · ε₀² · h³ · c)
```

Для гіпотетичного нескінченно важкого ядра (`M → ∞`, при цьому скорочена маса `μ = m_e`) ми отримуємо **фундаментальну сталу Рідберга `R_∞`**:

```
R_∞ = (m_e · e⁴) / (8 · ε₀² · h³ · c)
```

Цей результат є одним із найбільших триумфів математичної фізики XX століття: суто теоретичний розв'язок диференціального рівняння Шредінгера без жодних підганяльних параметрів дав чисельне значення константи `R_∞ = 1.097373 × 10⁷ м⁻¹`, яке з точністю до дев'ятого знака збігається з найточнішими експериментальними вимірюваннями оптичної спектроскопії.
