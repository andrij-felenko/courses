# 🔌 Квантові підсилювачі: параметр-залежні та надпровідникові архітектури

Узагальнений клас надпровідникових та оптичних квантово-обмежених підсилювачів працює безпосередньо на межі Хауса — Кейвса. Нижче розглянуто фізичні принципи роботи параметричних підсилювачів, їхні режими функціонування (фазозберігаючий та фазочутливий), порівняльні технічні характеристики різних архітектур та практичні інженерні правила їхньої інтеграції у кріогенні вимірювальні тракти.

## Загальний принцип параметричного підсилення

Класичний або квантовий параметричний підсилювач досягає підсилення слабкого сигналу шляхом періодичної модуляції одного з реактивних параметрів резонатора чи передавальної лінії — індуктивності `L` або ємності `C`. У квантовому режимі для надвисокочастотного (НВЧ) діапазону (4–8 ГГц) як нелінійний реактивний елемент без власних дисипативних втрат використовується тунельний джозефсонівський контакт або SQUID-петля (Josephson Junction / SQUID), нелінійна індуктивність яких залежить від магнітного потоку та протікаючого струму.

Підсилення є результатом трихвильового або чотирихвильового параметричного змішування квантів електромагнітного поля під дією сильної хвилі накачки з частотою `ω_p`.

У чотирихвильовому параметричному процесі два фотони накачки розпадаються на один фотон сигналу `ω_s` та один фотон холостої хвилі (idler) `ω_i`:

```
2 · ħ ω_p = ħ ω_s + ħ ω_i
```

У трихвильовому процесі один фотон накачки вищої частоти розпадається на фотон сигналу та фотон холостої хвилі:

```
ħ ω_p = ħ ω_s + ħ ω_i
```

## Два режими роботи: фазозберігаючий vs фазочутливий

Залежно від співвідношення частот сигналу `ω_s`, накачки `ω_p` та конфігурації вхідних кіл квантові параметричні підсилювачі функціонують у двох фундаментально різних режимах:

### 1. Вироджений / фазочутливий режим (Degenerate / Phase-Sensitive)

Накачка подається на подвоєній частоті сигналу `ω_p = 2 ω_s`, так що холоста хвиля збігається за частотою із сигналом (`ω_i = ω_s`). Підсилювач підсилює лише одну фазову квадратуру фазового простору `X_1` з коефіцієнтом підсилення `G`, при цьому стискаючи (подавлюючи) ортогональну квадратуру `X_2` у `1 / G` разів.

У фазочутливому режимі підсилювач **не додає жодного власного квантового шуму** до підсилюваної квадратури:

```
N_added,PS = 0
```

Це дозволяє реєструвати квадратурні амплітуди нижче стандартного вакуумного рівня, досягаючи стиснених станів поля. Використання фазочутливого режиму вимагає точної синхронізації фази накачки з фазою вхідного сигналу.

### 2. Невироджений / фазозберігаючий режим (Non-degenerate / Phase-Preserving)

Частота накачки зміщена від частоти сигналу (`ω_s ≠ ω_i`). Підсилювач однаково підсилює обидві квадратури фазового простору, зберігаючи початкову фазу вхідного сигналу без потреби у фазовій синхронізації з джерелом.

Згідно з теоремою Хауса — Кейвса, у цьому режимі підсилювач зобов'язаний змішувати вхідний сигнал із вакуумними флуктуаціями холостого каналу, що неминуче додає до сигналу на вході як мінімум половину кванта шуму:

```
N_added,PP ≥ ½
```

Еквівалентна шумова температура підсилювача `T_sys` у цьому режимі обмежена квантовою межею:

```
k_B T_sys ≥ ħ ω / ln(2)
```

Для частоти 6 ГГц квантова межа шумовій температурі становить `T_quantum ≈ 290 мК`.

## Основні класи надпровідникових квантових підсилювачів

1. **Резонаторний параметричний підсилювач Джозефсона (JPA — Josephson Parametric Amplifier):**
   Складається з високодобротного LC-резонатора, завантаженого SQUID-петлею (двома паралельними джозефсонівськими контактами). Перебудовується за частотою зовнішнім магнітним полем. Забезпечує високий коефіцієнт підсилення (`G ≥ 20 дБ`), але має вузьку смугу підсилення (`BW ~ 10–50 МГц`) та низьку потужність насичення (`P_1dB ~ -130 дБм`), що обмежує кількість одночасно зчитуваних кубітів.

2. **Параметричний підсилювач біжучої хвилі (TWPA — Traveling Wave Parametric Amplifier):**
   Являє собою довгу надпровідникову метаматеріал-лінію з сотень або тисяч послідовних SQUID-елементів та узгоджувальних ємностей. Надає широку смугу підсилення (`BW > 3–4 ГГц`) та підвищену потужність насичення (`P_1dB ~ -105 дБм`), що робить його ідеальним для мультиплексованого зчитування масивів надпровідникових кубітів у сучасних квантових процесорах.

3. **Підсилювачі на основі SQUID (Microstrip SQUID Amplifiers):**
   Використовують пряму зміну магнітного потоку у SQUID-петлі під дією струму вхідного мікросмужкового резонатора. Забезпечують підсилення у діапазоні 0.5–3 ГГц із шумом близько квантової межі, широко використовуються у вимірюваннях аксіонного темної матерії (експеримент ADMX).

## Порівняльна таблиця характеристик квантових підсилювачів

| Параметр | Значення для JPA | Значення для TWPA | Фізичний зміст |
| :--- | :--- | :--- | :--- |
| **Доданий шум `N_added`** | `0.5–0.7` квантів | `0.6–1.0` квантів | Кількість доданих фотонів шуму на вході |
| **Коефіцієнт підсилення `G`** | `15–25 дБ` | `15–20 дБ` | Відношення потужності виходу до входу |
| **Смуга підсилення `BW`** | `10–50 МГц` | `2–5 ГГц` | Частотна область збереження `G > 15 дБ` |
| **Потужність насичення `P_1dB`** | `-135...-125 дБм` | `-110...-100 дБм` | Поріг зниження підсилення на 1 дБ |
| **Потужність накачки `P_pump`** | `-80...-60 дБм` | `-60...-40 дБм` | Необхідна НВЧ-потужність генератора |
| **Гнучкість налаштування** | Магнітна перебудова | Смугова постійна | Спосіб зміни робочої частоти |

## Типові пастки та інженерні нюанси при інтеграції

> 🔧 **Навіщо це.** Кріогенні квантові підсилювачі є найпершою та найкритичнішою ланкою тракту зчитування квантових процесорів. Найменша помилка в ізоляції або термалізації зводить нанівець усі переваги квантово-обмеженого підсилення, насичуючи тракт тепловим шумом вищих температурних ступенів.

1. **Необхідність кріогенної фланцевої ізоляції:**
   Оскільки відбита від JPA хвиля накачки та холоста хвиля повертаються у вхідну лінію, між кубітом/джерелом та підсилювачем обов'язково встановлюють ферітові кріогенні циркулятори або вентилі з вхідним згасанням > 20 дБ на ступені 10–20 мК. Без ізоляції потужна хвиля накачки викликає незворотний Штарківський зсув частоти кубіта та його швидке дефазування.

2. **Захист від потужності накачки:**
   Сильна хвиля накачки TWPA або JPA не повинна потрапляти на вихідний транзисторний підсилювач HEMT, щоб не викликати його насичення. На виході квантового підсилювача застосовують смугові або загороджувальні НВЧ-фільтри високого порядку.

3. **Магнітне екранування:**
   Джозефсонівські контакти надзвичайно чутливі до зовнішніх флуктуючих магнітних полів. Зсув магнітного потоку на частки флюксона `Ф_0 = h / (2e)` змінює критичний струм contacts та збиває частоту підсилення. Підсилювачі поміщають у багатошарові екрани з мю-металу (µ-metal) та надпровідного алюмінію/ніобію.

4. **Термалізація атенюаторів вхідного тракту:**
   Атенюатори вхідної лінії зондування повинні бути ретельно припаяні до мідних холодопроводів кріостату розчинення (dilution refrigerator). Недотермалізований атенюатор створює гарячий тепловий шум Джонсона — Найквіста вищих температурних ступенів (4 К або 100 мК), який повністю перекриває квантовий поріг шуму на вході підсилювача.
