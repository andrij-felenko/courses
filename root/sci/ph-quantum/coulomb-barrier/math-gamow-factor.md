# 🧮 Виведення фактора Ґамова у ВКБ-наближенні

Ця математична вставка містить строге аналітичне виведення коефіцієнта підбар'єрної тунельної прозорості, фактора Ґамова, асимптотичних умов зшивання хвильових функцій та параболічної поправки Хілла — Уілера у квазікласичному наближенні Вентцеля — Крамерса — Бріллюена (ВКБ) для одновимірного та тривимірного кулонівського потенціалу.

---

### 1. Постановка квантово-механічної задачі та радіальне рівняння Шредінґера

Розглянемо відносний рух двох точкових позитивно заряджених ядер із зарядовими числами Z1 та Z2 і зведеною масою му = (m1 · m2) / (m1 + m2). В інерціальній системі центру мас кулонівська потенціальна енергія електростатичного відштовхування для відстаней r >= R (де R — сумарний радіус ядерного зіткнення) описується формулою:

```
V(r) = (Z1 · Z2 · e²) / (4п · eps0 · r)
```

Для частинки з повною кінетичною енергією E, яка є меншою за вершину кулонівського бар'єра V_B = V(R), тривимірне радіальне рівняння Шредінґера для парціальної хвилі з орбітальним моментом L має вигляд:

```
d²u_L / dr² + (2му / ℏ²) · [ E - V_eff(r) ] · u_L(r) = 0
```

```
V_eff(r) = V(r) + [ L · (L + 1) · ℏ² ] / (2 · му · r²)
```

де u_L(r) = r · R_L(r) — радіальна хвильова функція. Для s-хвиль з нульовим орбітальним моментом (L = 0) відцентровий потенціал зникає V_L(r) = 0, і ефективний потенціал зводиться до чисто кулонівського відштовхування V_eff(r) = V(r).

У класично забороненій області R <= r <= r_c кінетична енергія є від'ємною E < V(r), тому підбар'єрний хвильовий вектор каппа(r) є дійсною величиною:

```
каппа(r) = sqrt( 2му · (V(r) - E) ) / ℏ
```

Зовнішня класична точка повороту r_c визначається умовою рівності потенціальної та кінетичної енергії V(r_c) = E:

```
(Z1 · Z2 · e²) / (4п · eps0 · r_c) = E
```

```
=> r_c = (Z1 · Z2 · e²) / (4п · eps0 · E)
```

Умова застосовності квазікласичного наближення ВКБ полягає у малості просторової зміни довжини хвилі де Бройля на відстані самої довжини хвилі: d(лямбда) / dr << 1. Для кулонівського потенціалу ця умова виконується всюди під бар'єром, окрім вузьких окіл класичних точок повороту R та r_c, де хвильовий вектор прямує до нуля.

### 2. Квазікласичне наближення ВКБ та умови зшивання в точках повороту

У квазікласичному наближенні Вентцеля — Крамерса — Бріллюена (ВКБ) шукаємо розв'язок радіального рівняння Шредінґера у вигляді підбар'єрної підстановки u(r) = exp( (i/ℏ) · S(r) ). Розкладаючи дію S(r) у ряд за малим квазікласичним параметром ℏ, у першому наближенні отримуємо двокомпонентний підбар'єрний розв'язок:

```
u(r) = [ C1 / sqrt(каппа(r)) ] · exp( - int [від R до r] каппа(r') dr' ) + [ C2 / sqrt(каппа(r)) ] · exp( + int [від R до r] каппа(r') dr' )
```

У безпосередньому околі класичної точки повороту r = r_c квазікласична умова повільної зміни довжини хвилі порушується, оскільки каппа(r_c) = 0. Для зшивання розв'язків потенціал V(r) розкладають у ряд Тейлора поблизу точки повороту V(r) ≈ E + V'(r_c) · (r - r_c).

Точний розв'язок рівняння Шредінґера у лінійному потенціалі виражається через функції Ейрі Ai(x) та Bi(x), які задовольняють диференціальне рівняння d²y / dx² - x y = 0.

Асимптотичний розклад функції Ейрі Ai(x) у класично дозволеній області ліворуч від точки повороту (x < 0) має коливальний характер:

```
Ai(-x) ≈ [ 1 / (п^(1/2) · x^(1/4)) ] · sin( (2/3) · x^(3/2) + п/4 )
```

У класично забороненій області під бар'єром (x > 0) функція Ейрі спадає за строгою експонентою:

```
Ai(x) ≈ [ 1 / (2 · п^(1/2) · x^(1/4)) ] · exp( - (2/3) · x^(3/2) )
```

Використовуючи ці асимптотичні розклади функцій Ейрі для зшивання хвильових функцій на межах точки повороту r_c та ядерної стіни R, вираховують матрицю зшивання. Оскільки експоненціально зростаюча під бар'єром хвиля відсутня при самочинному тунелюванні назовні, відношення квадрата модуля амплітуди протунельованої хвилі при r > r_c до амплітуди падаючої хвилі при r < R визначає коефіцієнт підбар'єрної прозорості (імовірність тунелювання) P(E):

```
P(E) = exp( -2 · G )
```

```
G = int [від R до r_c] каппа(r) dr = [ sqrt(2му) / ℏ ] · int [від R до r_c] sqrt( V(r) - E ) dr
```

Величина G називається показником або фактором Ґамова. Фізичний зміст фактора Ґамова полягає у безрозмірній площі підквадратурної потенціальної стіни у фазовому просторі координата-імпульс.

Фазовий зсув підбар'єрної хвильової функції при проходженні точки повороту становить строго п / 4. Це додає додаткову постійну фазу п / 2 до повної хвилі при дворазовому зшиванні на внутрішній та зовнішній межах бар'єра. У квазікласичній теорії розсіювання цей фазовий зсув забезпечує точність ВКБ-наближення навіть для малих квантових чисел.

### 3. Точне тригонометричне інтегрування фактора Ґамова

Підставимо явний вираз для кулонівського потенціалу V(r) = Z1 Z2 e² / (4п eps0 r) у вираз для фактора Ґамова G та винесемо енергію E:

```
G = [ sqrt(2му) / ℏ ] · int [від R до r_c] sqrt( (Z1 Z2 e²) / (4п eps0 r) - E ) dr
  = [ sqrt(2му·E) / ℏ ] · int [від R до r_c] sqrt( (r_c / r) - 1 ) dr
```

Для обчислення цього визначеного інтеграла виконаємо тригонометричну заміну змінної r:

```
r = r_c · sin²(тета)
```

```
dr = 2 · r_c · sin(тета) · cos(тета) d(тета)
```

Визначимо нові межі інтегрування по куту тета:
При r = r_c маємо sin²(тета_2) = 1, отже тета_2 = п / 2.
При r = R маємо sin²(тета_1) = R / r_c, отже тета_1 = arcsin(sqrt(R / r_c)).

Підставимо підінтегральний вираз та підкореневе співвідношення:

```
sqrt( (r_c / r) - 1 ) = sqrt( (1 / sin²тета) - 1 ) = sqrt( cos²тета / sin²тета ) = cos(тета) / sin(тета)
```

```
(cos тета / sin тета) · (2 r_c sin тета cos тета d тета) = 2 r_c · cos²(тета) d(тета)
```

Використовуючи формулу пониження степеня для квадрата косинуса cos²(тета) = (1 + cos 2тета) / 2, знайдемо первісну:

```
int 2 r_c · cos²(тета) d(тета) = r_c · int (1 + cos 2тета) d(тета) = r_c · [ тета + (1/2) · sin(2тета) ]
                             = r_c · [ тета + sin(тета) · cos(тета) ]
```

Підставимо граничні значення кута тета від тета_1 до тета_2 = п/2:

Верхня межа (тета_2 = п/2): (п/2) + sin(п/2) · cos(п/2) = п/2.
Нижня межа (тета_1): тета_1 + sin(тета_1) · cos(тета_1).

Значення інтеграла I = r_c · [ (п/2) - тета_1 - sin(тета_1) · cos(тета_1) ].

Позначимо безрозмірне відношення енергії частинки E до висоти кулонівського бар'єра V_B як y:

```
y = E / V_B = R / r_c   (де 0 < y < 1)
```

```
sin(тета_1) = sqrt(y)
```

```
cos(тета_1) = sqrt(1 - y)
```

```
тета_1 = arcsin(sqrt(y))
```

Використовуючи тригонометричну тотожність (п/2) - arcsin(sqrt(y)) = arccos(sqrt(y)), отримуємо точний закритий вираз для інтеграла:

```
I = r_c · [ arccos(sqrt(y)) - sqrt(y) · sqrt(1 - y) ]
```

### 4. Точна аналітична формула фактора Ґамова та поправка на розмір ядра

Помножимо результат інтегрування I на передінтегральний множник sqrt(2му·E) / ℏ:

```
G = [ sqrt(2му·E) / ℏ ] · r_c · [ arccos(sqrt(y)) - sqrt(y) · sqrt(1 - y) ]
```

Підставимо значення точки повороту r_c = (Z1 Z2 e²) / (4п eps0 E) та врахуємо відносну швидкість частинок на нескінченності v = sqrt(2E / му):

```
[ sqrt(2му·E) / ℏ ] · [ (Z1 Z2 e²) / (4п eps0 E) ]
= [ sqrt(2му) / (ℏ · sqrt(E)) ] · [ (Z1 Z2 e²) / (4п eps0) ]
= [ (Z1 Z2 e²) / (4п eps0 ℏ) ] · [ sqrt(2му / E) ]
= [ (2 п Z1 Z2 e²) / (4п eps0 ℏ v) ]
```

Таким чином, точна формула фактора Ґамова для довільної енергії E < V_B набуває вигляду:

```
G = [ (п · Z1 · Z2 · e²) / (4п · eps0 · ℏ · v) ] · J(y)
```

```
J(y) = (2 / п) · [ arccos(sqrt(y)) - sqrt(y) · sqrt(1 - y) ]
```

Безрозмірна функція J(y) називається структурною поправкою на скінченний радіус ядра:
При E -> 0 (y -> 0): arccos(0) = п/2, тому J(0) = (2/п) · (п/2) = 1.
При E -> V_B (y -> 1): arccos(1) = 0, тому J(1) = 0 (підбар'єрне згасання повністю зникає, оскільки частинка перелітає над вершиною бар'єра).

Розкладемо функцію J(y) у ряд Тейлора поблизу y = 0 для малих енергій:

```
arccos(sqrt(y)) ≈ (п / 2) - sqrt(y)
```

```
sqrt(y) · sqrt(1 - y) ≈ sqrt(y) · (1 - y/2) ≈ sqrt(y) - (y^(3/2) / 2)
```

```
J(y) ≈ 1 - (4 / п) · sqrt(y) + (2 / 3п) · y^(3/2) + ...
```

Для більшості зоряних термоядерних реакцій y = E / V_B << 1, тому поправка J(y) ≈ 1, що дає класичний астрофізичний вираз Ґамова:

```
G ≈ (п · Z1 · Z2 · e²) / (4п · eps0 · ℏ · v) = п · ета
```

де ета = альфа Z1 Z2 (c / v) — безрозмірний параметр Зоммерфельда.

Виразивши швидкість через кінетичну енергію v = sqrt(2E / му), отримуємо універсальну залежність тунельної прозорості від енергії:

```
P(E) = exp( -b_G / sqrt(E) )
```

```
b_G = п · альфа · Z1 · Z2 · sqrt(2 · му · c²) ≈ 31.291 · Z1 · Z2 · sqrt( му_amu )   [кЕв^(1/2)]
```

Аналітична поправка на розмір ядра зменшує фактор Ґамова на величину delta_G = 4 ета sqrt(E / V_B). Це експоненціально збільшує підбар'єрну прозорість P(E) при енергіях, близьких до вершини бар'єра, на 1-2 порядки порівняно з точковою моделлю ядра Ґамова.

### 5. Квазістаціонарні стани та обчислення періоду коливань в ямі

У квантовій теорії ядерного розпаду Ґамова внутрішньоядерний рух описується квазістаціонарним станом із комплексною енергією E = E_r - i (Гамма / 2), де E_r — резонансна енергія рівня, а Гамма — повна ширина рівня.

Класичний період коливань частинки всередині потенціальної ями радіуса R зі швидкістю v_in = sqrt( 2 (E - V0) / му ) дорівнює:

```
T_class = 2 · int [від 0 до R] dr / v_in(r) = (2 · R) / v_in
```

Частота спроб пробою кулонівської стіни визначається як ню = 1 / T_class = v_in / (2 R). Повна енергетична ширина квазістаціонарного рівня Гамма виражається через тунельну прозорість:

```
Гамма = ℏ · лямбда = ℏ · ню · P(E) = [ (ℏ · v_in) / (2 R) ] · exp( -2 G )
```

Ця формула пов'язує макроскопічний період напіврозпаду ядра T_(1/2) = ℏ ln 2 / Гамма з квантово-механічною шириною збудженого стану Гамма.

Уявна частина комплексної енергії підпорядковується часовому рівнянню Шредінґера i ℏ (d psi / dt) = H psi. Ймовірність знайти частинку всередині ядра спадає за експоненціальним законом |psi(t)|² = |psi(0)|² exp( - Гамма t / ℏ ).

### 6. Параболічне наближення вершини бар'єра (Формула Хілла — Уілера)

Коли кінетична енергія частинки E знаходиться дуже близько до вершини кулонівського бар'єра (E ≈ V_B), класичне ВКБ-наближення стає незастосовним, оскільки дві точки повороту R та r_c зближуються і зливаються, а похідна потенціалу в точці повороту прямує до нуля V'(R) -> 0.

У цьому випадку вершину потенціального бар'єра поблизу r = R апроксимують перевернутою параболою гармонічного осцилятора:

```
V(r) ≈ V_B - (1/2) · му · омега_0² · (r - R)²
```

де омега_0 — ефективна частота параболічної вершини бар'єра, яка виражає кривину кулонівської стіни.

Точний розв'язок рівняння Шредінґера для параболічного потенціального бар'єра виражається через функції параболічного циліндра (функції Вебера D_ню(z)). Отриманий Двором Хіллом та Джоном Уілером розв'язок дає загальну квантову формулу прозорості бар'єра для будь-яких енергій (як під бар'єром E < V_B, так і над бар'єром E > V_B):

```
P_HW(E) = 1 / [ 1 + exp( 2п · (V_B - E) / (ℏ · омега_0) ) ]
```

Математичний аналіз граничних режимів Хілла — Уілера:
Глибоко під бар'єром (E << V_B) експонента у знаменнику є набагато більшою за одиницю exp( 2п (V_B - E) / (ℏ омега_0) ) >> 1. Формула спрощується до звичайного ВКБ-виразу P_HW(E) ≈ exp( -2п (V_B - E) / (ℏ омега_0) ).

Точно на вершині кулонівського бар'єра (E = V_B) експонента перетворюється на exp(0) = 1. Знаменник дорівнює 1 + 1 = 2, отже прозорість становить строго P_HW(V_B) = 1 / 2 = 50%.

Над бар'єром (E > V_B) експонента стає від'ємною і прямує до нуля, тому прозорість монотонно наближається до одиниці P_HW(E) -> 1. Однак через ефект квантового надбар'єрного відбиття частинка навіть при E > V_B має ненульову ймовірність відбитися від потенціального стрибка.

### 7. Вплив відцентрового бар'єра при ненульовому орбітальному моменті

Для реакцій зіткнення з ненульовим орбітальним моментом імпульсу L > 0 підбар'єрний показник Ґамова збільшується за рахунок додаткового відцентрового потенціалу V_L(r) = L(L+1) ℏ² / (2 му r²):

```
G_L = [ sqrt(2му) / ℏ ] · int [від R до r_c_L] sqrt( V_C(r) + V_L(r) - E ) dr
```

Розкладаючи підінтегральний корінь у ряд за малим відношенням відцентрового потенціалу до кулонівського, отримуємо відцентрову поправку для малих моментів L:

```
G_L ≈ G_(L=0) + delta_G_L
```

```
delta_G_L ≈ [ L · (L + 1) · ℏ ] / [ sqrt(2му · V_B) · R ] = [ L · (L + 1) ] / [ 2 · ета_B ]
```

де ета_B — параметр Зоммерфельда на вершині бар'єра.

Ця поправка призводить до додаткового експоненціального подавлення прозорості P_L(E) = P0(E) · exp( -2 delta_G_L ). Саме тому при низьких зоряних енергіях переважна більшість термоядерних реакцій протікає строго через s-хвильовий канал із L = 0.

Фізична причина цього подавлення полягає у тому, що відцентрова сила створює додатковий потенціальний бар'єр, який збільшує ефективну товщину класично забороненої області під бар'єром. Для p-хвиль з L = 1 висота додаткового стіни збільшується на кілька сотень кілоелектронвольт, що при низьких зоряних енергіях зменшує ймовірність тунелювання додатково у 10-100 разів порівняно з s-хвильовим злиттям.

#### Чисельний метод переносу матриць (Transfer Matrix Method)
Для довільного невизначеного профілю потенціального бар'єра V(r) прозорість обчислюють чисельно шляхом апроксимації бар'єра N прямокутними сходинками товщиною dr. Хвильова функція на кожному інтервалі описується комбінацією прямих та зворотних хвиль, а повна матриця переносу M = M_N · M_(N-1) ... M_1 зв'язує вхідні та вихідні амплітуди. Коефіцієнт прозорості дорівнює P(E) = 1 / |M_(11)|², що дозволяє враховувати надбар'єрний резонансний пробіг частинок із високою точністю.
