# 📋 Довідник параметрів кулонівського бар'єра та ядерних реакцій

Цей технічний довідник містить систематизоване зведення фізико-математичних формул, фундаментальних констант, алгоритмів обчислення підбар'єрної прозорості, а також емпіричні таблиці кулонівських бар'єрів та параметрів піку Ґамова для ключових термоядерних реакцій і альфа-розпадів у фізиці ядра й астрофізиці.

### 1. Фундаментальні фізичні константи та конверсійні множники

Під час розрахунків ядерних реакцій та кулонівського тунелювання використовуються фундаментальні константи, значення яких рекомендовані Міжнародним комітетом з даних для науки і техніки (CODATA 2022):

Першою константою є стала тонкої структури альфа. Вона є безрозмірною фундаментальною величиною, що визначає інтенсивність електромагнітної взаємодії. У ядерних розрахунках вона зв'язує квадрат елементарного заряду зі зведеною сталою Планка та швидкістю світла. Значення дорівнює альфа = e² / (4п eps0 ℏ c) = 1 / 137.035999177.

Другою константою є електростатична комбінована стала e² / (4п eps0). Вона визначає потенціальну енергію двох одиничних елементарних зарядів на відстані одиниці довжини. В ядерній фізиці для мікроскопічних відстаней у фемтометрах зручно використовувати розмірність МеВ · фм або кЕв · фм. Значення дорівнює e² / (4п eps0) = 1.439964 МеВ · фм = 1439.964 кЕв · фм.

Третьою константою є зведена стала Планка, помножена на швидкість світла ℏ c. Це фундаментальний квантовий множник, що зв'язує імпульс частинки з її довжиною хвилі де Бройля. Значення дорівнює ℏ c = 197.326980 МеВ · фм = 197326.98 кЕв · фм.

Четвертою константою є атомна одиниця маси в енергетичному еквіваленті 1 а.о.м. · c². Це масовий енергетичний еквівалент, встановлений за основою нейтрального атома вуглецю-12. Значення дорівнює 1 а.о.м. · c² = 931.494102 МеВ = 931494.1 кЕв. У цих одиницях маса протона становить m_p = 1.007276 а.о.м., маса дейтерію m_d = 2.014102 а.о.м., маса тритію m_t = 3.016049 а.о.м., маса гелію-3 m_3He = 3.016029 а.о.м., маса альфа-частинки m_alpha = 4.001506 а.о.м., а маса нейтрона m_n = 1.008665 а.о.м.

П'ятою константою є стала Больцмана k_B. Вона є фундаментальним термодинамічним перевідним множником від температури у Кельвінах до середньої кінетичної енергії частинок. Значення дорівнює k_B = 8.617333 · 10^(-5) еВ / К = 8.617333 · 10^(-8) кЕв / К. При характерній температурі центрального сонячного ядра T = 15.7 мільйонів Кельвінів середня теплова енергія іонів становить k_B T = 1.353 кЕв. При температурі термоядерного реактора T = 100 мільйонів Кельвінів теплова енергія сягає k_B T = 8.617 кЕв.

Шостою константою є ефективний параметр радіуса ядерного зіткнення r0. Геометричний радіус ядра у краплинній моделлі обчислюється як R = r0 · A^(1/3). У класичних розрахунках кулонівського бар'єра приймають r0 = 1.25 фм. Фізичний діапазон допустимих значень у літературі становить від 1.20 фм для важких ядер до 1.40 фм для найлегших нуклідів.

### 2. Систематичний реєстр аналітичних формул

#### Геометрія ядра та висота кулонівського бар'єра
Для двох зіштовхуваних ядер із зарядовими числами Z1, Z2 та масовими числами A1, A2:

Ефективна зведена маса системи у атомних одиницях маси розраховується як му_amu = (A1 · A2) / (A1 + A2).

Суммарний радіус ядерного зіткнення у фемтометрах розраховується за формулою R = r0 · ( A1^(1/3) + A2^(1/3) ).

Висота вершини кулонівського бар'єра у кілоелектронвольтах дорівнює V_B = (Z1 · Z2 · e²) / (4п · eps0 · R) = 1439.96 · Z1 · Z2 / R.

Зовнішня класична точка повороту у фемтометрах визначається положенням точки, у якій потенціальна енергія відштовхування дорівнює кінетичній енергії E: r_c = (Z1 · Z2 · e²) / (4п · eps0 · E) = 1439.96 · Z1 · Z2 / E.

Ширина підбар'єрного класично забороненого тунелю у фемтометрах обчислюється як різниця між точкою повороту та радіусом зіткнення: b = r_c - R.

#### Квантовий фактор Ґамова та підбар'єрна прозорість
Безрозмірний параметр Зоммерфельда характеризує відношення кулонівської потенціальної енергії відштовхування частинок на відстані довжини хвилі де Бройля до їхньої початкової кінетичної енергії: ета = (Z1 · Z2 · e²) / (4п · eps0 · ℏ · v) = альфа · Z1 · Z2 · (c / v).

Астрофізична стала Ґамова b_G є фундаментальною константою даної ядерної реакції з розмірністю кЕв^(1/2) і обчислюється як b_G = п · альфа · Z1 · Z2 · sqrt(2 · му · c²) = 31.291 · Z1 · Z2 · sqrt(му_amu).

Точна формула фактора Ґамова має вигляд G = п · ета · (2 / п) · [ arccos(sqrt(y)) - sqrt(y) · sqrt(1 - y) ], де y = E / V_B.

Низькоенергетична підбар'єрна прозорість у ВКБ-наближенні при кінетичній енергії значно меншій за висоту бар'єра E « V_B задається формулою P(E) = exp(-2 G) = exp(-2 п ета) = exp(-b_G / sqrt(E)).

#### Астрофізичний пік Ґамова та вікно реакції
Найімовірніша енергія термоядерної реакції в зоряній плазмі E0 у кілоелектронвольтах обчислюється за формулою E0 = ((b_G · k_B T) / 2)^(2/3) = 1.220 · (Z1² · Z2² · му_amu · T_6²)^(1/3), де T_6 — температура в мільйонах Кельвінів.

Ефективна ширина енергетичного вікна Ґамова delta_E у кілоелектронвольтах обчислюється як delta_E = 4 · sqrt( (E0 · k_B T) / 3 ) = 0.749 · (Z1 · Z2 · sqrt(му_amu) · T_6^5)^(1/6).

Показник експоненціального подавлення при енергії піку tau розраховується за формулою tau = 3 · E0 / (k_B T) = 42.48 · (Z1² · Z2² · му_amu / T_6)^(1/3), а прозорість дорівнює P(E0) = exp(-tau).

#### Астрофізичний S-фактор та екстраполяція перерізу
Для нерезонансних термоядерних реакцій ядерний переріз sigma(E) факторизується шляхом виділення кулонівської тунельної прозорості exp(-2п ета) та геометричної площини хвилі де Бройля 1/E:

sigma(E) = [ S(E) / E ] · exp( -2п · ета )

Астрофізичний S-фактор S(E) виражається у кЕв·барн (або МеВ·барн) і описує чисто ядерну частину взаємодії під кулонівським бар'єром. Оскільки S(E) змінюється дуже повільно при низьких енергіях, його розкладають у ряд Тейлора поблизу нульової енергії:

S(E) ≈ S(0) + S'(0) · E + (1/2) · S''(0) · E²

Експериментальне вимірювання S(0) дозволяє розраховувати швидкості реакцій в надрах зір при енергіях E0, де пряме прискорювальне вимірювання є неможливим через малість перерізів.

#### Плазмовий ефект електронного екранування (Debye-Hückel Screening)
У щільній зоряній плазмі або у металевих гратках міжатомні вільні електрони частково екранують позитивний заряд ядра. Це зменшує ефективну висоту кулонівського бар'єра на величину потенціалу екранування U_screen:

Потенціал екранування Дебая — Гюккеля обчислюється як U_screen = (Z1 · Z2 · e²) / (4п · eps0 · R_D), де R_D = sqrt( (eps0 · k_B T) / (e² · n_e) ) — дебаївський радіус екранування в плазмі з електронною густиною n_e.

Коефіцієнт підсилення термоядерного синтезу плазмою дорівнює f_screen = exp( U_screen / (k_B T) ). У центрі Сонця екранування підвищує швидкість протон-протонної реакції на 10-20%, а в білих карликах — у сотні разів.

lg( T_(1/2) , с ) = A + B / sqrt(E_alpha)

### 6. Резонансне підбар'єрне тунелювання та Бретей-Вігнеровські формули

У багатьох термоядерних реакціях (наприклад, 15N(p,alpha)12C або 3He(alpha,gamma)7Be) підбар'єрне тунелювання відбувається не за гладкою ВКБ-залежністю, а через дискретний збуджений стан складеного ядра.

У цьому випадку переріз взаємодії описується резонансною формулою Брейта — Вігнера:

sigma_res(E) = [ п / k² ] · [ (omega · Гамма_a · Гамма_b) / ( (E - E_res)² + (Гамма_total / 2)² ) ]

де E_res — енергія квантового резонансу, Гамма_a та Гамма_b — парціальні ширини вхідного та вихідного каналів, а Гамма_total — повна ширина рівня. При підбар'єрних енергіях парціальна ширина вхідного каналу Гамма_a(E) визначається підбар'єрною прозорістю Гамма_a(E) = Гамма_0 · P(E) = Гамма_0 · exp(-b_G / sqrt(E)).
