# ⚙️ Чисельне моделювання кінетики реактора та дифузії нейтронів

Моделювання часової динаміки ядерного реактора вимагає чисельного розв'язування системи диференціальних рівнянь точкової кінетики. Ця система описує зв'язок між часовою зміною щільності нейтронів (що пропорційна тепловій потужності реактора) та концентраціями ядер-попередників запізнілих нейтронів. Завдяки наявності двох кардинально різних часових масштабів — часу життя миттєвих нейтронів `l* ≈ 10⁻⁴ с` та періодів піврозпаду запізнілих нейтронів `T_1/2,i ≈ 0.2 ... 55 с` — система є макроскопічно жорсткою (*stiff differential equations*).

Інтегрування жорсткої системи точкової кінетики реактора здійснюється методом Рунге–Кутти 4-го порядку (RK4) із врахуванням усіх шести груп запізнілих нейтронів. Обчислювальний алгоритм реалізовано двома шляхами — у вигляді прямого низькорівневого коду мовою C та ідіоматичної об'єктно-орієнтованої структури мовою C++, що дозволяє точно моделювати реакцію активної зони на різні сценарії введення реактивності з контролем крайових випадків та стійкості часового кроку.

---

### Фізична модель та розрахунковий алгоритм

Система диференціальних рівнянь точкової кінетики реактора для шести груп запізнілих нейтронів має вигляд:

```
dn / dt = ((ρ(t) - β) / l*) · n(t) + ∑ [ λ_i · C_i(t) ]    (i = 1 ... 6)

dC_i / dt = (β_i / l*) · n(t) - λ_i · C_i(t)                (i = 1 ... 6)
```

Вхідними параметрами моделі є:
1. Час життя миттєвих нейтронів `l*` (для теплового уранового реактора `l* ≈ 10⁻⁴ с`).
2. Повна частка запізнілих нейтронів `β = ∑ β_i` (для `²³⁵U` значення `β = 0.0065`).
3. Парціальні частки `β_i` та сталі розпаду `λ_i` для шести стандартних груп запізнілих нейтронів.
4. Зовнішнє функціональне правило введення реактивності `ρ(t)`.

Вектор стану системи складається з семи незалежних змінних:
```
Y(t) = [ n(t), C₁(t), C₂(t), C₃(t), C₄(t), C₅(t), C₆(t) ]ᵀ
```

У стаціонарному початковому стані при `t = 0` реактор перебуває в строго критичному стані (`ρ = 0`), а потужність прийнято за одиницю (`n(0) = 1.0`). Оскільки у стаціонарі `dC_i / dt = 0`, початкові рівноважні концентрації ядер-попередників знаходять аналітично:

```
C_i(0) = (β_i / (l* · λ_i)) · n(0)
```

Для чисельного інтегрування використано класичний чотириетапний метод Рунге–Кутти (RK4), який забезпечує четвертий порядок точності по кроку часу `dt` (`O(dt⁴)`). Для вектора стану `Y` крок обчислюється за формулами:

```
k₁ = f(t_n, Y_n)
k₂ = f(t_n + dt/2, Y_n + (dt/2) · k₁)
k₃ = f(t_n + dt/2, Y_n + (dt/2) · k₂)
k₄ = f(t_n + dt, Y_n + dt · k₃)

Y_(n+1) = Y_n + (dt / 6) · (k₁ + 2·k₂ + 2·k₃ + k₄)
```

### Програмна реалізація мовами C та C++

Приклад нижче містить дві незалежні вкладки: реалізацію мовою C (із симетричною структурою даних та класичними покажчиками) та ідіоматичну реалізацію мовою C++ (із використанням ООП, операцій над векторами стану, `std::array` та виключенням ручного управління пам'яттю).

```c
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

#define NUM_GROUPS 6

/* Ядерно-фізичні константи для 235U (теплові нейтрони) */
typedef struct {
    double beta[NUM_GROUPS];
    double lambda[NUM_GROUPS];
    double beta_total;
    double l_star; /* Час життя миттєвих нейтронів (секунди) */
} ReactorParams;

typedef struct {
    double n;
    double C[NUM_GROUPS];
} State;

/* Обчислення похідних рівнянь точкової кінетики */
void compute_derivatives(const State *s, double rho, const ReactorParams *p, State *d) {
    double sum_lambda_C = 0.0;
    for (int i = 0; i < NUM_GROUPS; i++) {
        sum_lambda_C += p->lambda[i] * s->C[i];
    }
    
    /* dn/dt = ((rho - beta) / l*) * n + sum(lambda_i * C_i) */
    d->n = ((rho - p->beta_total) / p->l_star) * s->n + sum_lambda_C;
    
    /* dC_i/dt = (beta_i / l*) * n - lambda_i * C_i */
    for (int i = 0; i < NUM_GROUPS; i++) {
        d->C[i] = (p->beta[i] / p->l_star) * s->n - p->lambda[i] * s->C[i];
    }
}

/* Один крок інтегрування методом Рунге-Кутти 4-го порядку (RK4) */
void rk4_step(State *s, double rho, const ReactorParams *p, double dt) {
    State k1, k2, k3, k4, temp;
    
    /* k1 */
    compute_derivatives(s, rho, p, &k1);
    
    /* k2 */
    temp.n = s->n + 0.5 * dt * k1.n;
    for (int i = 0; i < NUM_GROUPS; i++) {
        temp.C[i] = s->C[i] + 0.5 * dt * k1.C[i];
    }
    compute_derivatives(&temp, rho, p, &k2);
    
    /* k3 */
    temp.n = s->n + 0.5 * dt * k2.n;
    for (int i = 0; i < NUM_GROUPS; i++) {
        temp.C[i] = s->C[i] + 0.5 * dt * k2.C[i];
    }
    compute_derivatives(&temp, rho, p, &k3);
    
    /* k4 */
    temp.n = s->n + dt * k3.n;
    for (int i = 0; i < NUM_GROUPS; i++) {
        temp.C[i] = s->C[i] + dt * k3.C[i];
    }
    compute_derivatives(&temp, rho, p, &k4);
    
    /* Оновлення стану */
    s->n += (dt / 6.0) * (k1.n + 2.0 * k2.n + 2.0 * k3.n + k4.n);
    for (int i = 0; i < NUM_GROUPS; i++) {
        s->C[i] += (dt / 6.0) * (k1.C[i] + 2.0 * k2.C[i] + 2.0 * k3.C[i] + k4.C[i]);
    }
}

int main(void) {
    ReactorParams p = {
        .beta = {0.000215, 0.001424, 0.001274, 0.002568, 0.000748, 0.000273},
        .lambda = {0.0124, 0.0305, 0.111, 0.301, 1.14, 3.01},
        .beta_total = 0.0065,
        .l_star = 1e-4
    };

    State s;
    s.n = 1.0; /* Початкова відносна потужність = 1.0 */
    
    /* У стаціонарному стані (rho = 0): dC_i/dt = 0 => C_i = (beta_i / (l* * lambda_i)) * n */
    for (int i = 0; i < NUM_GROUPS; i++) {
        s.C[i] = (p.beta[i] / (p.l_star * p.lambda[i])) * s.n;
    }

    double t = 0.0;
    double dt = 0.001; /* Крок інтегрування (секунди) */
    double t_max = 5.0;
    
    /* Введення позитивної реактивності rho = 0.002 (менше за beta = 0.0065) */
    double rho = 0.002;

    printf("Час [с]\tПотужність n(t)\tПеріод T [с]\n");
    printf("----------------------------------------\n");

    double prev_n = s.n;
    while (t <= t_max) {
        if ((int)(t / dt) % 500 == 0) {
            double dn_dt = (s.n - prev_n) / dt;
            double period = (dn_dt > 1e-9) ? (s.n / dn_dt) : 999.9;
            printf("%.2f\t%.4f\t\t%.2f\n", t, s.n, period);
        }
        prev_n = s.n;
        rk4_step(&s, rho, &p, dt);
        t += dt;
    }

    return 0;
}
```

```cpp
#include <iostream>
#include <vector>
#include <array>
#include <numeric>
#include <iomanip>

constexpr std::size_t NUM_GROUPS = 6;

struct ReactorParams {
    std::array<double, NUM_GROUPS> beta{0.000215, 0.001424, 0.001274, 0.002568, 0.000748, 0.000273};
    std::array<double, NUM_GROUPS> lambda{0.0124, 0.0305, 0.111, 0.301, 1.14, 3.01};
    double beta_total{0.0065};
    double l_star{1e-4};
};

struct ReactorState {
    double n{1.0};
    std::array<double, NUM_GROUPS> C{};

    ReactorState operator*(double factor) const {
        ReactorState res;
        res.n = n * factor;
        for (std::size_t i = 0; i < NUM_GROUPS; ++i) {
            res.C[i] = C[i] * factor;
        }
        return res;
    }

    ReactorState operator+(const ReactorState& rhs) const {
        ReactorState res;
        res.n = n + rhs.n;
        for (std::size_t i = 0; i < NUM_GROUPS; ++i) {
            res.C[i] = C[i] + rhs.C[i];
        }
        return res;
    }
};

class ReactorKineticsSimulator {
public:
    explicit ReactorKineticsSimulator(ReactorParams params) 
        : params_(std::move(params)) 
    {
        initialize_equilibrium();
    }

    void initialize_equilibrium() {
        state_.n = 1.0;
        for (std::size_t i = 0; i < NUM_GROUPS; ++i) {
            state_.C[i] = (params_.beta[i] / (params_.l_star * params_.lambda[i])) * state_.n;
        }
    }

    [[nodiscard]] ReactorState compute_derivatives(const ReactorState& s, double rho) const {
        ReactorState deriv;
        double sum_lambda_C = 0.0;
        for (std::size_t i = 0; i < NUM_GROUPS; ++i) {
            sum_lambda_C += params_.lambda[i] * s.C[i];
        }

        deriv.n = ((rho - params_.beta_total) / params_.l_star) * s.n + sum_lambda_C;
        for (std::size_t i = 0; i < NUM_GROUPS; ++i) {
            deriv.C[i] = (params_.beta[i] / params_.l_star) * s.n - params_.lambda[i] * s.C[i];
        }
        return deriv;
    }

    void step_rk4(double rho, double dt) {
        const auto k1 = compute_derivatives(state_, rho);
        const auto k2 = compute_derivatives(state_ + k1 * (0.5 * dt), rho);
        const auto k3 = compute_derivatives(state_ + k2 * (0.5 * dt), rho);
        const auto k4 = compute_derivatives(state_ + k3 * dt, rho);

        state_ = state_ + (k1 + k2 * 2.0 + k3 * 2.0 + k4) * (dt / 6.0);
    }

    [[nodiscard]] double power() const noexcept { return state_.n; }

private:
    ReactorParams params_;
    ReactorState state_;
};

int main() {
    ReactorParams params;
    ReactorKineticsSimulator simulator(params);

    const double dt = 0.001;
    const double t_max = 5.0;
    const double step_reactivity = 0.002; /* rho < beta */

    std::cout << std::fixed << std::setprecision(4);
    std::cout << "Час [с]\tПотужність n(t)\tПеріод T [с]\n";
    std::cout << "----------------------------------------\n";

    double prev_power = simulator.power();
    for (double t = 0.0; t <= t_max; t += dt) {
        if (static_cast<int>(t / dt) % 500 == 0) {
            double current_power = simulator.power();
            double dn_dt = (current_power - prev_power) / dt;
            double period = (dn_dt > 1e-9) ? (current_power / dn_dt) : 999.9;
            std::cout << std::setw(6) << t << "\t" 
                      << std::setw(10) << current_power << "\t" 
                      << std::setw(10) << period << "\n";
        }
        prev_power = simulator.power();
        simulator.step_rk4(step_reactivity, dt);
    }

    return 0;
}
```

### Детальний аналіз та порівняння реалізацій

C-версія та C++ версія моделі виконують ідентичні математичні розрахунки, однак демонструють суттєву різницю в архітектурі програмного коду:

1. **Інкапсуляція та лінійна алгебра векторів стану:**
   У версії на C++ вектор стану `ReactorState` перетворюється на повноцінний математичний об'єкт шляхом перевантаження операторів `+` та `*`. Завдяки цьому формула Рунге–Кутти в коді виглядає природно й збігається з математичним записом:
   ```cpp
   state_ = state_ + (k1 + k2 * 2.0 + k3 * 2.0 + k4) * (dt / 6.0);
   ```
   У C-версії для цього доводиться виконувати явні поелементні цикли додавання для кожного з коефіцієнтів `k1 ... k4` та змінних `n` і `C[i]`, що збільшує обсяг шаблоного коду й підвищує ризик помилки у розрахунку індексів.

2. **Безпека типів та контейнери:**
   Версія C++ використовує фіксовані контейнери `std::array<double, NUM_GROUPS>`, які зберігають розмірність на рівні компіляції без виділення динамічної пам'яті в купі (`heap`). Це забезпечує максимальну швидкодію, порівнянну зі статичними масивами C, але надає строгий контроль меж та підтримує стандартні ітератори.

3. **Гарантія початкової ініціалізації:**
   Конструктор класу `ReactorKineticsSimulator` гарантує, що об'єкт неможливо створити в некоректному або неініціалізованому стані. Метод `initialize_equilibrium()` автоматично розраховує стаціонарні концентрації всіх шести груп запізнілих нейтронів, виключаючи виникнення хибних початкових перехідних процесів.

### Сценарії моделювання та фізична інтерпретація результатів

Результати моделювання за допомогою написаної програми дозволяють наочно продемонструвати три ключові сценарії поведінки ядерного реактора при зміні реактивності:

#### 1. Запізніла надкритичність (`0 < ρ < β`, наприклад `ρ = 0.002 = 0.31 $`)
При введенні позитивної реактивності, меншої за частку запізнілих нейтронів (`β = 0.0065`), графік потужності демонструє дві чітко виражені фази:
- **Миттєвий стрибок потужності (*prompt jump*):** У перші частки мілісекунди потужність миттєво зростає від `n = 1.0` до значення `n_jump = β / (β - ρ) = 0.0065 / (0.0065 - 0.002) ≈ 1.44`. Це відбувається через швидке накопичення миттєвих нейтронів на фоні незмінних початкових концентрацій запізнілих джерел `C_i`.
- **Встановився асимптотичний розгін:** Після миттєвого стрибка швидкість зростання обмежується накопиченням нових ядер-попередників. Потужність починає плавно зростати за експонентою з постійним асимптотичним періодом `τ ≈ (β - ρ) / (λ_eff · ρ) ≈ 35 с`. Завдяки цьому тривалому періоду реактор є цілком керованим.

#### 2. Миттєва надкритичність (`ρ ≥ β`, наприклад `ρ = 0.008 = 1.23 $`)
Коли введена реактивність перевищує частку запізнілих нейтронів (`ρ > β`), знаменник `(ρ - β)` стає позитивним. Внесок запізнілих нейтронів стає другорядним, і швидкість зростання визначається виключно часом життя миттєвих нейтронів `l* = 10⁻⁴ с`.
Період реактора катастрофічно падає до:
```
τ = l* / (ρ - β) = 10⁻⁴ / (0.008 - 0.0065) = 10⁻⁴ / 0.0015 ≈ 0.067 с (67 мілісекунд)
```
Потужність зростає в `e` разів кожні 67 мілісекунд, що призводить до вибухового руйнування активної зони за час, менший за одну секунду.

#### 3. Скидання реактивності (негативний стрибок `ρ = -0.005`)
При введенні негативної реактивності (занурення аварійних поглинаючих стержнів) спостерігається **миттєвий спад потужності (*prompt drop*)**: потужність за частки мілісекунди падає до рівня `n_drop = β / (β - ρ) = 0.0065 / (0.0065 + 0.005) ≈ 0.56`.
Далі потужність згасає не миттєво, а за довгим хвостом, що визначається найтривалішим періодом піврозпаду запізнілих нейтронів першої групи (`⁸⁷Br`, `T_1/2 = 55.6 с`, `λ₁ = 0.0124 с⁻¹`). Тільки після вигоряння всіх залишків попередників потужність остаточно падає до рівня залишкового тепловиділення.

### Чисельні крайові випадки та пастки інтегрування

При практичній розробці солверів ядерної кінетики слід враховувати кілька чисельних математичних пасток:

1. **Пастка жорсткості рівнянь (*Stiffness Ratio*):**
   Співвідношення між найбільшим власним значенням матриці системи `λ_max ≈ (β - ρ) / l* ≈ 10⁴ с⁻¹` та найменшим власним значенням `λ_min = λ₁ ≈ 0.0124 с⁻¹` становить понад `10⁶`. При використанні явних методів (таких як явний Ейлер або RK4) крок інтегрування `dt` обмежений умовою стійкості:
   ```
   dt < 2 · l* / |ρ - β| ≈ 2 · 10⁻⁴ с
   ```
   Якщо вибрати крок `dt = 0.01 с` (10 мілісекунд), явний метод RK4 втрачає чисельну стійкість і породжує розбіжні осциляції з нефізичними від'ємними значеннями потужності. Для тривалого моделювання перехідних процесів доцільно використовувати неявні методи (неявний Ейлер, метод Трапецій або неявні методи Рунге–Кутти типу Rosenbrock).

2. **Нагромадження помилки округлення при малих `l*`:**
   При обчисленні похідної `dn/dt = ((ρ - β) / l*) · n + ...` відбувається ділення на дуже мале число `l* = 10⁻⁴ ... 10⁻⁷`. Для запобігання втраті точності при відніманні близьких чисел всі розрахунки обов'язково повинні виконуватися в числах подвійної точності (`double` або `long double`).

3. **Врахування зворотних зв'язків по температурі:**
   У реальних реакторах реактивність `ρ` не є константою, а залежить від температури палива `T_f` та теплоносія `T_c`:
   ```
   ρ(t) = ρ_ext(t) + α_f · (T_f(t) - T_f0) + α_c · (T_c(t) - T_c0)
   ```
   де `α_f` та `α_c` — температурні коефіцієнти реактивності. Негативний коефіцієнт `α_f < 0` забезпечує самообмеження сплеску потужності: при зростанні `n(t)` паливо розігрівається, реактивність спадає, і реактор самостійно гасить розгін навіть без втручання системи захисту.
