# 📋 Довідник ядерно-фізичних констант та параметрів критичності

Цей довідник містить зведені систематичні таблиці ядерно-фізичних констант для ізотопів, що діляться та відтворюють ядерне паливо, перерізи взаємодії нейтронів різних енергетичних груп, параметри шести груп запізнілих нейтронів, фізичні характеристики матеріалів-уповільнювачів, а також математичні формули перерахунку одиниць вимірювання реактивності.

Усі числові значення відповідають сучасним фундаментальним оціненим ядерним даним міжнародних бібліотек ENDF/B-VIII.0, JEFF-3.3 та JENDL-5 і застосовуються у нейрофізичних розрахунках критичності, оцінці паливних циклів та моделюванні динаміки ядерних реакторів.

### 1. Ядерно-фізичні характеристики ізотопів урану, плутонію та торію

У ядерній фізиці та реакторобудуванні ізотопи важких елементів поділяють на два фундаментальних класи:
1. **Ізотопи, що діляться тепловими нейтронами (*fissile nuclides*):** ядра з непарним числом нейтронів (`²³⁵U`, `²³⁹Pu`, `²³³U`), у яких при захопленні повільного нейтрона енергія спарування нуклонів перевищує бар'єр поділу `E_b`. Вони спроможні до ланцюгової реакції при будь-якій кінетичній енергії налітаючого нейтрона.
2. **Порогові та відтворювальні ізотопи (*fertile nuclides*):** ядра з парним числом нейтронів (`²³⁸U`, `²³²Th`), у яких енергія зв'язку приєднаного нейтрона є меншою за бар'єр поділу `E_b`. Вони діляться лише швидкими нейтронами з енергією, вищою за порогову (`E_n > 1.1 ... 1.2 МеВ`), але при захопленні теплових нейтронів перетворюються на відповідні дільні ізотопи (`²³⁸U + n → ²³⁹Pu`, `²³²Th + n → ²³³U`).

Нижче наведено константи взаємодії для теплових нейтронів (`E_n = 0.0253 еВ`, що відповідає найбільш імовірній швидкості `2200 м/с` за температури `20 °C`) та для швидких нейтронів спектра поділу (`E_n ≈ 2 МеВ`).

#### Означення та фізичний зміст параметрів:
- **`σ_f` (мікроскопічний переріз поділу):** ефективна площа ядра для реакції поділу, вимірюється в барнах (`1 барн = 10⁻²⁴ см²`). Характеризує ймовірність того, що налітаючий нейтрон викличе розкол ядра.
- **`σ_γ` (переріз радіаційного захоплення):** ймовірність того, що ядро захопить нейтрон без поділу, випромінивши гамма-квант (`(n, γ)`-реакція). Це паразитне поглинання, яке виводить нейтрон з ланцюгового циклу і перетворює `²³⁵U` на недільний `²³⁶U`.
- **`σ_s` (переріз пружного розсіяння):** ймовірність відскоку нейтрона від ядра зі зміною напрямку та частковою передачею кінетичної енергії.
- **`ν` (середнє число вторинних нейтронів на один поділ):** загальна кількість швидких нейтронів (миттєвих та запізнілих), випромінених в одному акті розколу ядра.
- **`η` (вихід нейтронів на один поглинутий нейтрон у паливі):** фундаментальний параметр розмноження, який враховує конкуренцію між поділом та паразитною радіаційною закупівлею:
  ```
  η = ν · (σ_f / (σ_f + σ_γ)) = ν / (1 + α)
  ```
  де `α = σ_γ / σ_f` — відношення перерізу захоплення до перерізу поділу.
  Умовою здійснення самопідтримуваної ланцюгової реакції у середовищі без витоку є `η > 1`. Для побудови реактора-примножувача (*breeder*), де на один спалений атом палива утворюється більше ніж один новий дільний атом плутонію або урану-233, необхідна виконання умови `η > 2`. Як видно з таблиці, для `²³⁹Pu` на швидких нейтронах `η = 2.92 > 2`, що робить швидкі реактори-примножувачі на плутонії надзвичайно ефективними.

### 2. Параметри шести груп запізнілих нейтронів для ²³⁵U

Запізнілі нейтрони випромінюються збудженими дочірніми ядрами (уламками поділу), які утворюються після бета-мінус розпаду первинних фрагментів розколу урану. Оскільки бета-розпад відбувається зі строго визначеними періодами піврозпаду, випромінювання запізнілих нейтронів розбивають на шість експериментально розрізнюваних енергетичних груп.

Для поділу ядра `²³⁵U` тепловими нейтронами загальна частка запізнілих нейтронів становить `β = 0.0065` (`0.65%` від загальної кількості вторинних нейтронів). Решта `99.35%` є миттєвими нейтронами.

|---|---|---|---|---|---|
| **1** | 55.60 | 0.0124 | 3.3 | 0.000215 | `⁸⁷Br` |
| **2** | 22.70 | 0.0305 | 21.9 | 0.001424 | `¹³⁷I`, `⁸⁸Br` |
| **3** | 6.22 | 0.1110 | 19.6 | 0.001274 | `⁸⁹Br`, `¹³⁸I`, `⁸⁸Rb` |
| **4** | 2.30 | 0.3010 | 39.5 | 0.002568 | `¹³⁹I`, `⁹⁰Br`, `⁸⁵As` |
| **5** | 0.61 | 1.1400 | 11.5 | 0.000748 | `¹⁴₀I`, `⁹¹Br` |
| **6** | 0.23 | 3.0100 | 4.2 | 0.000273 | `⁹²Br`, `¹⁴¹I` |
| **Разом**| **⟨T⟩ ≈ 12.7 с** | **⟨λ⟩ ≈ 0.078 с⁻¹**| **100.0%** | **β = 0.006500** | — |

#### Пояснення фізичного механізму запізнення:
Ядра-попередники (наприклад, бром-87 `⁸⁷Br` з періодом піврозпаду `55.6 с`) зазнають бета-розпаду у криптон-87 (`⁸⁷Kr*`). Якщо енергія збудження дочірнього ядра `⁸⁷Kr*` перевищує енергію зв'язку нейтрона у цьому ядрі (`S_n ≈ 5.5 МеВ`), воно миттєво (за час `10⁻¹⁶ с`) скидає «зайвий» нейтрон, перетворюючись на стабільний `⁸⁶Kr`. Отже, уся затримка випромінювання нейтрона визначається часом чекання бета-розпаду батьківського ядра `⁸⁷Br`.

Середній період піврозпаду запізнілих нейтронів обчислюється як зважене середнє:
```
⟨T⟩ = ∑ (β_i · T_1/2,i) / β ≈ 12.7 секунд
```

Ефективна стала розпаду `⟨λ⟩`:
```
⟨λ⟩ = β / ∑ (β_i / λ_i) ≈ 0.078 с⁻¹
```

Завдяки тому, що середній час чекання випромінювання запізнілих нейтронів становить понад 12 секунд, ефективний час життя одного покоління нейтронів у критичному реакторі збільшується від `10⁻⁴` секунди до `~0.1` секунди, що й дозволяє механічно регулювати реактивність установки.

Для інших важливих паливних ізотопів повні частки запізнілих нейтронів `β` становлять:
- `²³³U`: `β = 0.0026` (`0.26%`);
- `²³⁹Pu`: `β = 0.0021` (`0.21%`);
- `²³⁸U` (поділ швидкими нейтронами): `β = 0.0148` (`1.48%`);
- `²³²Th` (поділ швидкими нейтронами): `β = 0.0203` (`2.03%`).

Оскільки плутоній-239 має утричі меншу частку запізнілих нейтронів (`β = 0.0021`), ніж уран-235 (`β = 0.0065`), плутонієві активні зони мають вужчий діапазон безпечного запізнілого регулювання і вимагають більш швидходіючих систем управління та захисту (СУЗ).

### 3. Фізичні характеристики матеріалів-уповільнювачів

Уповільнювач призначений для скидання кінетичної енергії швидких нейтронів поділу (`2 МеВ`) до енергії теплової рівноваги з середовищем (`0.025 еВ`) за допомогою пружних зіткнень з ядрами.

Зменшення енергії нейтрона в одному пружному зіткненні з ядром маси `A` характеризується **середнім логарифмічним декрементом згасання енергії** `ξ`:

```
ξ = ⟨ln(E_before / E_after)⟩ = 1 + ( (A - 1)² / (2 · A) ) · ln( (A - 1) / (A + 1) )
```

Для ядер з масовим числом `A > 10` застосовують хороше наближення:
```
ξ ≈ 2 / (A + 2/3)
```

Середнє число пружних зіткнень `u`, необхідне для уповільнення нейтрона від енергії `E₀ = 2 МеВ` до теплової енергії `E_th = 0.025 еВ`:

```
u = ln(E₀ / E_th) / ξ = ln(2 · 10⁶ / 0.025) / ξ = ln(8 · 10⁷) / ξ ≈ 18.2 / ξ
```

| Матеріал | Атомна маса `A` | Декремент `ξ` | Переріз захоплення `σ_a` [барн] | Загальна кількість зіткнень від 2 МеВ до 0.025 еВ | Сповільнювальна здатність `ξ · Σ_s` [см⁻¹] | Коефіцієнт якості уповільнювача `(ξ · Σ_s) / Σ_a` |
|---|---|---|---|---|---|---|
| **Водень (¹H)** | 1 | 1.000 | 0.332 | 18 | 1.35 | 71 |
| **Дейтерій (²H)** | 2 | 0.725 | 0.0005 | 25 | 0.176 | 5670 |
| **Берилій (⁹Be)** | 9 | 0.207 | 0.0092 | 86 | 0.125 | 143 |
| **Вуглець (¹²C)** | 12 | 0.158 | 0.0035 | 114 | 0.060 | 192 |
| **Уран (²³⁸U)** | 238 | 0.0084| 2.68 | 2172 | 0.003 | 0.004 |

#### Критерії оцінки ефективності уповільнювачів:
1. **Сповільнювальна здатність (`ξ · Σ_s`):** добуток декременту `ξ` на макроскопічний переріз розсіяння `Σ_s = N_av · ρ_mat · σ_s / M_mat`. Вона визначає швидкість скидання енергії нейтронів в одиниці об'єму середовища. Звичайна легка вода (`H₂O`) має найвищу сповільнювальну здатність (`1.35 см⁻¹`), тому активні зони водо-водяних реакторів (ВВЕР, PWR) є найкомпактнішими за об'ємом.
2. **Коефіцієнт якості уповільнювача (*moderating ratio*, `(ξ · Σ_s) / Σ_a`):** відношення сповільнювальної здатності до макроскопічного перерізу поглинання теплових нейтронів `Σ_a`. Цей коефіцієнт показує, скільки нейтронів уповільнюється до того, як один нейтрон буде паразитно захоплений самими ядрами уповільнювача.
   - **Важка вода (`D₂O`):** має абсолютний рекорд якості (`5670`) завдяки мізерно малому захопленню нейтронів дейтерієм (`σ_a = 0.0005 барн`). Це дозволяє будувати реактори (типу CANDU) на природному незбагаченому урані (`0.7% ²³⁵U`).
   - **Графіт (`¹²C`):** має коефіцієнт якості `192`, що також дозволяє використовувати природний або слабозбагачений уран (реактори Magnox, РБМК).
   - **Звичайна вода (`H₂O`):** має відносно низький коефіцієнт якості (`71`) через високе поглинання нейтронів воднем (`σ_a = 0.332 барн`). Тому легковадні реактори фундаментально вимагають збагаченого урану (`2 ... 5% ²³⁵U`).

### 4. Одиниці вимірювання реактивності та формули перерахунку

Реактивність `ρ` характеризує відхилення ефективного коефіцієнта розмноження `k_eff` від критичного стану (`k_eff = 1`):

```
ρ = (k_eff - 1) / k_eff
```

У практичній ядерній інженерії використовують кілька систем вимірювання реактивності.

#### 1. Безрозмірна відносна реактивність (`Δk/k` та `% Δk/k`):
Виражає відносну зміну коефіцієнта розмноження.
```
1 % Δk/k = 0.01 Δk/k = 10⁻²
```

#### 2. Одиниця pcm (*per cent mille* — одна тисячна відсотка):
Використовується в європейській та розрахунковій практиці для опису малих змін реактивності.
```
1 pcm = 10⁻⁵ Δk/k = 0.001 % Δk/k = 10⁻³ % Δk/k
```
Приклад: якщо `k_eff` змінився від `1.00000` до `1.00250`, реактивність складає `ρ = 0.00250 / 1.00250 ≈ 0.002494` або `249.4 pcm`.

#### 3. Шкала доларів ($) та центів (¢):
Фізична шкала реактивності, нормована на ефективну частку запізнілих нейтронів `β` для даного палива:

```
ρ [$] = ρ / β
1 $ = β  (для ²³⁵U: 1 $ = 0.0065 = 650 pcm)
1 ¢ = 0.01 $ = 0.000065 = 6.5 pcm
```

#### Таблиця фізичних порогів у шкалі доларів:

| Реактивність `ρ` | Значення `k_eff` | Фізичний режим реактора | Динаміка потужності та керованість |
|---|---|---|---|
| **`ρ < 0 $`** | `k_eff < 1.000` | **Підкритичний** | Загасання ланцюгової реакції; реактор зупинено. |
| **`ρ = 0 $`** | `k_eff = 1.000` | **Стаціонарний критичний** | Потужність строго постійна у часі (`dn/dt = 0`). |
| **`0 < ρ < 1 $`** | `1.000 < k_eff < 1 + β` | **Запізніла надкритичність** | Керований розгін на запізнілих нейтронах (`τ ≈ 10 ... 100 с`). |
| **`ρ = 1 $`** | `k_eff = 1 + β` | **Поріг миттєвої критичності** | Реактор стає критичним на самих лише миттєвих нейтронах. |
| **`ρ > 1 $`** | `k_eff > 1 + β` | **Миттєва надкритичність** | Некерований вибуховий розгін (`τ < 0.001 с`). |

#### 4. Рівняння зв'язку та формули конвертації:
Для конвертації значення реактивності `ρ` із безрозмірної форми в долари та pcm застосовують співвідношення:

```
ρ [pcm] = ρ [безрозмірна] · 10⁵
ρ [$] = ρ [безрозмірна] / β
ρ [pcm] = ρ [$] · (β · 10⁵)
```

Для палива з `²³⁵U` (`β = 0.0065 = 650 pcm`):
- `1 $ = 650 pcm = 0.0065 Δk/k`;
- `1 ¢ = 6.5 pcm = 0.000065 Δk/k`;
- `100 pcm ≈ 0.1538 $ = 15.38 ¢`.

Використання шкали доларів є стандартом безпеки АЕС: операторові та автоматиці заборонено вводити позитивну реактивність, яка наближається до межі `1 $`, гарантуючи безпечний запас до миттєвої критичності.
