# 🧮 Математична теорія рівняння Шредінгера як задачі Штурма — Ліувілля

Математичний апарат одновимірного стаціонарного рівняння Шредінгера спирається на теорію лінійних диференціальних операторів другого порядку, засновану у XIX столітті французькими математиками Жаком Шарлем Франсуа Штурмом (Jacques Charles François Sturm) та Жозефом Ліувіллем (Joseph Liouville). У квантовій механіці стаціонарне рівняння Шредінгера виступає як спектральна задача на власні значення та власні функції для самоспряженого оператора у гільбертовому просторі квадровально інтегровних функцій `L²(ℝ)`. Ця вставка містить вичерпні математичні доведення дійсності власних значень енергії, ортогональності власних функцій, теореми про невиродженість станів в 1D, осциляційної теореми Штурма про вузли хвильової функції, варіаційного принципу та математичного формалізму квазікласичного наближення ВКБ.

## Канонічна форма Штурма — Ліувілля

Загальне однорідне диференціальне рівняння Штурма — Ліувілля другого порядку для невідомої функції `y(x)` на просторовому інтервалі `[a, b]` записується у вигляді:

```
- d/dx [ p(x) · dy/dx ] + q(x)·y(x) = λ · w(x)·y(x)      [загальна форма Штурма — Ліувілля]
```

де `p(x) > 0` — неперервно диференційовна додатна функція, `w(x) > 0` — неперервна додатна вагова функція, `q(x)` — дійсна потенціальна функція, а `λ` — спектральний параметр (власне значення).

Одновимірне стаціонарне рівняння Шредінгера для частинки масою `m` у потенціальному полі `V(x)` має вигляд:

```
- (ℏ² / (2·m)) · d²ψ(x)/dx² + V(x)·ψ(x) = E·ψ(x)      [рівняння Шредінгера]
```

Це рівняння повністю тотожне канонічній формі Штурма — Ліувілля при такому співвідношенні параметрів:

```
p(x) = ℏ² / (2·m)      [стала коефіцієнтна функція]
q(x) = V(x)             [потенціальна енергія частинки]
w(x) = 1                [одинична вагова функція]
λ = E                   [повна енергія як власне значення]
```

Оператор Гамільтона `Ĥ` визначається як лінійний диференціальний вираз:

```
Ĥ = - (ℏ² / (2·m)) · d²/dx² + V(x)      [оператор Гамільтона]
```

його областю визначення `D(Ĥ)` у комплексному гільбертовому просторі `L²(ℝ)` є соболєвський простір `H²(ℝ)` — сукупність двічі диференційовних функцій `ψ(x)`, які разом зі своїми першими тальними похідними належать до `L²(ℝ)` і задовольняють крайові умови нормування `∫₋∞⁺∞ |ψ(x)|² dx < ∞`.

## Скалярний добуток та самоспряженість Гамільтоніана

Скалярний добуток двох комплексних хвильових функцій `φ(x)` та `ψ(x)` у гільбертовому просторі `L²(ℝ)` визначається як інтеграл:

```
⟨φ, ψ⟩ = ∫₋∞⁺∞ φ*(x) · ψ(x) dx      [скалярний добуток у L²]
```

де зірочка `*` означає комплексне спряження. Оператор `Ĥ` є симетричним (ермітовим), якщо для довільних векторів `φ, ψ ∈ D(Ĥ)` виконується фундаментальна рівність:

```
⟨φ, Ĥψ⟩ = ⟨Ĥφ, ψ⟩      [умова симетричності оператора]
```

Доведемо цю рівність за допомогою дворазового інтегрування частинами:

```
⟨φ, Ĥψ⟩ = ∫₋∞⁺∞ φ*(x) · [ - (ℏ² / (2·m)) · d²ψ(x)/dx² + V(x)·ψ(x) ] dx
```

Розглянемо першу частину з другою похідною:

```
∫₋∞⁺∞ φ*(x) · ψ''(x) dx = [ φ*(x)·ψ'(x) ]|₋∞⁺∞ - ∫₋∞⁺∞ φ'*(x) · ψ'(x) dx      [перше інтегрування частинами]
```

Проінтегруємо другий член ще раз:

```
- ∫₋∞⁺∞ φ'*(x) · ψ'(x) dx = - [ φ'*(x)·ψ(x) ]|₋∞⁺∞ + ∫₋∞⁺∞ φ''*(x) · ψ(x) dx    [друге інтегрування частинами]
```

Для функцій із простору `L²(ℝ)` хвильові функції та їхні похідні прямують до нуля на нескінченності: `lim_{x → ±∞} ψ(x) = 0` та `lim_{x → ±∞} ψ'(x) = 0`. Отже, обидва позаінтегральні члени обнуляються:

```
[ φ*(x)·ψ'(x) - φ'*(x)·ψ(x) ]|₋∞⁺∞ = 0      [обнулення межевих членів]
```

Враховуючи, що потенціальна енергія `V(x)` є дійсною функцією `V*(x) = V(x)`, підстановка дає:

```
⟨φ, Ĥψ⟩ = ∫₋∞⁺∞ [ - (ℏ² / (2·m)) · φ''*(x) + V(x)·φ*(x) ] · ψ(x) dx = ⟨Ĥφ, ψ⟩      [доведення ермітовості]
```

З самоспряженості Гамільтоніана випливають чотири ключові теореми спектральної теорії.

### Теорема 1: Дійсність спектра енергії

Усі власні значення `E` самоспряженого оператора Гамільтона `Ĥ` є строго дійсними числами (`E ∈ ℝ`).

**Доведення:** Нехай `ψ(x) ≠ 0` є власною функцією оператора `Ĥ` з власним значенням `E`, тобто `Ĥψ = E·ψ`. Обчислимо скалярний добуток `⟨ψ, Ĥψ⟩` двома способами:

```
⟨ψ, Ĥψ⟩ = ⟨ψ, E·ψ⟩ = E · ⟨ψ, ψ⟩      [винесення комплексної константи з правого множника]
⟨Ĥψ, ψ⟩ = ⟨E·ψ, ψ⟩ = E* · ⟨ψ, ψ⟩     [винесення константи з лівого множника за нормою]
```

Оскільки оператор `Ĥ` є ермітовим, `⟨ψ, Ĥψ⟩ = ⟨Ĥψ, ψ⟩`. Віднімаючи один вираз від іншого, отримуємо:

```
(E - E*) · ⟨ψ, ψ⟩ = 0      [різниця власних значень]
```

Оскільки хвильова функція `ψ ≠ 0`, її норма `⟨ψ, ψ⟩ = ∫₋∞⁺∞ |ψ(x)|² dx > 0`. Отже:

```
E - E* = 0 ⇒ E = E* ⇒ E ∈ ℝ      [дійсність енергії]
```

### Теорема 2: Ортогональність власних функцій

Власні функції `ψₘ(x)` та `ψₙ(x)`, які відповідають різним власним значенням `Eₘ ≠ Eₙ`, є строго ортогональними.

**Доведення:** Розглянемо два рівняння для власних станів: `Ĥψₘ = Eₘ·ψₘ` та `Ĥψₙ = Eₙ·ψₙ`. Обчислимо скалярний добуток `⟨ψₙ, Ĥψₘ⟩`:

```
⟨ψₙ, Ĥψₘ⟩ = ⟨ψₙ, Eₘ·ψₘ⟩ = E☨ · ⟨ψₙ, ψₘ⟩
⟨Ĥψₙ, ψₘ⟩ = ⟨Eₙ·ψₙ, ψₘ⟩ = Eₙ* · ⟨ψₙ, ψₘ⟩ = Eₙ · ⟨ψₙ, ψₘ⟩      [оскільки E♙ дійсне]
```

Використовуючи симетричність `⟨ψₙ, Ĥψₘ⟩ = ⟨Ĥψₙ, ψₘ⟩`, маємо:

```
(Eₘ - Eₙ) · ⟨ψₙ, ψₘ⟩ = 0      [умова ортогональності]
```

За умовою `Eₘ ≠ Eₙ`, отже `E☨ - E♙ ≠ 0`. Це негайно вимагає:

```
⟨ψₙ, ψₘ⟩ = ∫₋∞⁺∞ ψₙ*(x) · ψₘ(x) dx = 0      [ортогональність функцій]
```

### Теорема 3: Невиродженість одновимірного дискретного спектра

Усі дискретні власні значення енергії `E` для одновимірного рівняння Шредінгера зв'язаних станів є строго невиродженими: кожному власному значенню `E` відповідає єдина з точністю до постійного множника хвильова функція.

**Доведення:** Припустимо протилежне: нехай значенню енергії `E` відповідають дві лінійно незалежні власні функції `ψ₁(x)` та `ψ₂(x)`. Обидві функції задовольняють рівняння:

```
ψ₁'' = (2m / ℏ²) · (V(x) - E) · ψ₁
ψ₂'' = (2m / ℏ²) · (V(x) - E) · ψ₂
```

Розглянемо визначник Вронського (вронськіан) цих двох функцій:

```
W(x) = W(ψ₁, ψ₂) = ψ₁(x) · ψ₂'(x) - ψ₁'(x) · ψ₂(x)      [визначник Вронського]
```

Знайдемо похідну вронськіана по `x`:

```
dW/dx = ψ₁'·ψ₂' + ψ₁·ψ₂'' - ψ₁''·ψ₂ - ψ₁'·ψ₂' = ψ₁·ψ₂'' - ψ₁''·ψ₂
```

Підставивши вирази для друге похідних:

```
dW/dx = ψ₁ · [ (2m/ℏ²)(V - E) ψ₂ ] - [ (2m/ℏ²)(V - E) ψ₁ ] · ψ₂ = 0      [dW/dx = 0]
```

Оскільки похідна `dW/dx = 0`, вронськіан є константою на всій осі `x`: `W(x) = const`.

Оскільки `ψ₁(x)` та `ψ₂(x)` належать до `L²(ℝ)`, вони прямують до нуля на нескінченності: `lim_{x → -∞} ψ₁(x) = 0` та `lim_{x → -∞} ψ₂(x) = 0`. Звідси випливає, що константа дорівнює нулю: `W(x) = 0` скрізь.

Рівність вронськіана нулю `ψ₁·ψ₂' - ψ₁'·ψ₂ = 0` означає:

```
ψ₂'/ψ₂ = ψ₁'/ψ₁ ⇒ d/dx (ln|ψ₂|) = d/dx (ln|ψ₁|) ⇒ ψ₂(x) = C · ψ₁(x)      [лінійна залежність]
```

Отже, функції `ψ₁` та `ψ₂` є лінійно залежними, що доводить невиродженість дискретного спектра у 1D.

### Теорема 4: Осциляційна теорема Штурма про нулі

Якщо власні значення дискретного спектра впорядковано за зростанням `E₀ < E₁ < E₂ < ... < Eₙ`, то власна функція основного стану `ψ₀(x)` не має жодного внутрішнього нуля, а власна функція `n`-го збудженого стану `ψₙ(x)` має точно `n` простих нулів на відкритому інтервалі `(a, b)`.

**Доведення (метод порівняння Штурма):**
Розглянемо дві дійсні власні функції `ψ₁(x)` та `ψ₂(x)`, що відповідають енергіям `E₁ < E₂`. Вронськіан цих функцій задовольняє диференціальне співвідношення:

```
dW(ψ₁, ψ₂)/dx = (2m / ℏ²) · (E₂ - E₁) · ψ₁(x) · ψ₂(x)      [зміна Вронськіана]
```

Нехай `xₐ` та `x_b` — два послідовних нулі функції `ψ₁(x)`, де `ψ₁(xₐ) = ψ₁(x_b) = 0`, і нехай `ψ₁(x) > 0` на інтервалі `(xₐ, x_b)`. Проінтегруємо зміну вронськіана від `xₐ` до `x_b`:

```
W(x_b) - W(xₐ) = (2m / ℏ²) · (E₂ - E₁) · ∫₈ᵇ ψ₁(x) · ψ₂(x) dx      [інтегральна формула]
```

Обчислимо значення Вронськіана на межах:
- У точці `xₐ`: `W(xₐ) = ψ₁(xₐ)·ψ₂'(xₐ) - ψ₁'(xₐ)·ψ₂(xₐ) = -ψ₁'(xₐ)·ψ₂(xₐ)`. Оскільки `ψ₁` зростає в `xₐ`, `ψ₁'(xₐ) > 0`.
- У точці `x_b`: `W(x_b) = -ψ₁'(x_b)·ψ₂(x_b)`. Оскільки `ψ₁` спадає в `x_b`, `ψ₁'(x_b) < 0`.

Якщо припустити, що `ψ₂(x)` не змінює знак на інтервалі `[xₐ, x_b]`, то знак лівої частини інтегрального співвідношення суперечить знаку правої частини. Отже, між будь-якими двома сусідніми нулями функції `ψ₁(x)` мусить лежати принаймні один нуль функції `ψ₂(x)` для вищої енергії `E₂ > E₁`.

Звідси випливає, що з кожним наступним рівнем енергії кількість внутрішніх вузлів збільшується рівно на одиницю.

## Варіаційний принцип Релея — Рітца

Варіаційний принцип є потужним аналітичним методом оцінки енергії основного стану `E₀` у ситуаціях, коли точний розв'язок рівняння Шредінгера невідомий.

Зазначимо функціонал енергії Релея для нормованої випробувальної функції `ψ_trial(x)`:

```
E[ψ_trial] = ⟨ψ_trial, Ĥ ψ_trial⟩ / ⟨ψ_trial, ψ_trial⟩      [функціонал Релея]
```

Розкладемо випробувальну функцію за точним точним ортонормованим базисом власних функцій `ψ_trial(x) = ∑♙ c♙ · ψ♙(x)`:

```
E[ψ_trial] = ( ∑♙ |c♙|² · E♙ ) / ( ∑♙ |c♙|² )      [розклад функціоналу]
```

Оскільки для всіх `n ≥ 0` виконується нерівність `E♙ ≥ E₀`:

```
E[ψ_trial] ≥ E₀ · ( ∑♙ |c♙|² ) / ( ∑♙ |c♙|² ) = E₀      [варіаційна нерівність]
```

**Теорема:** Обчислене середнє значення Гамільтоніана на будь-якій випробувальній функції `ψ_trial(x)` дає строго верхню оцінку для енергії основного стану: `E[ψ_trial] ≥ E₀`. Рівність досягається тоді й лише тоді, коли випробувальна функція тотожно збігається з точним розв'язком основного стану `ψ₀(x)`.

## Математичний формалізм квазікласичного наближення ВКБ

Для потенціалів `V(x)`, які повільно змінюються на масштабі довжини хвилі де Бройля, рівняння Шредінгера розв'язують асимптотичним методом Вентцеля — Крамерса — Бріллюена (ВКБ).

Представимо хвильову функцію через комплексний фазовий анзац від дії `S(x)`:

```
ψ(x) = exp( (i / ℏ) · S(x) )      [анзац методу ВКБ]
```

Обчислимо першу та другу похідні:

```
ψ'(x) = (i/ℏ) · S'(x) · exp( (i/ℏ) S(x) )
ψ''(x) = [ (i/ℏ) · S''(x) - (1/ℏ²) · (S'(x))² ] · exp( (i/ℏ) S(x) )
```

Підставивши ці похідні у рівняння Шредінгера `- (ℏ² / 2m) ψ'' + V(x) ψ = E ψ` та скоротивши експоненту, отримуємо нелінійне диференціальне рівняння першого порядку відносно дії `S(x)`:

```
(S'(x))² - i·ℏ · S''(x) = 2m · (E - V(x)) = p²(x)      [точное рівняння дій]
```

де `p(x) = √(2m(E - V(x)))` — класичний імпульс частинки.

Розкладемо функцію дії `S(x)` у асимптотичний ряд за малим параметром `ℏ`:

```
S(x) = S₀(x) + (ℏ / i) · S₁(x) + (ℏ / i)² · S₂(x) + ...      [розклад за степенями hbar]
```

Підставимо ряд у точно рівняння дій та прирівняємо коефіцієнти при однакових степенях `ℏ`:

### 1. Нульове наближення (порядок ℏ⁰):
```
(S₀'(x))² = p²(x) ⇒ S₀'(x) = ± p(x) ⇒ S₀(x) = ± ∫ p(x) dx      [гамільтон-якобієвська дія]
```

### 2. Перше наближення (порядок ℏ¹):
```
2 · S₀'(x) · S₁'(x) + S₀''(x) = 0 ⇒ S₁'(x) = - S₀''(x) / (2·S₀'(x)) = - p'(x) / (2·p(x))
```

Інтегруючи за координатою:

```
S₁(x) = - ½ · ln|p(x)| = ln( 1 / √|p(x)| )      [амплітудна поправка]
```

Збираючи нульове та перше наближення `ψ(x) ≈ exp((i/ℏ) S₀ - S₁)`, отримуємо квазікласичні розв'язки.

### Квазікласичні хвильові функції:

1. **У класично дозволеній області (`E > V(x)`):**
   ```
   ψ_WKB(x) = (C₁ / √p(x)) · exp( (i/ℏ) ∫ p(x) dx ) + (C₂ / √p(x)) · exp( -(i/ℏ) ∫ p(x) dx )      [осцилюючий розв'язок]
   ```
2. **У класично забороненій області (`E < V(x)`):**
   Позначаючи `p(x) = i · p̃(x)`, де `p̃(x) = √(2m(V(x) - E))`:
   ```
   ψ_WKB(x) = (D₁ / √p̃(x)) · exp( (1/ℏ) ∫ p̃(x) dx ) + (D₂ / √p̃(x)) · exp( -(1/ℏ) ∫ p̃(x) dx )      [загасаючий розв'язок]
   ```

### Формули зшивання Ейрі та правило квантування Бора — Зоммерфельда
У точках повороту `xₐ, x_b`, де `E = V(x)`, імпульс обнуляється `p(x) = 0`, і наближення ВКБ втрачає застосовність через розбіжність множника `1 / √p(x)`.

У околі точки повороту потенціал апроксимують лінійною функцією `V(x) - E ≈ g · (x - x₀)`, а рівняння Шредінгера зводиться до рівняння Ейрі `d²ψ/dz² - z·ψ = 0`, розв'язками якого є функції Ейрі `Ai(z)` та `Bi(z)`.

Зшиваючи асимптотики функцій Ейрі з ВКБ-розв'язками праворуч та ліворуч від точок повороту `xₐ` та `x_b`, отримуємо набік фази `π/4` на кожній точці повороту. Це дає узагальнене **правило квантування Бора — Зоммерфельда**:

```
∫ₐᵇ p(x) dx = ∫ₐᵇ √(2m(E - V(x))) dx = π · ℏ · ( n + ½ )      [правило квантування ВКБ]
```

Ця формула забезпечує високу точність розрахунку енергетичних рівнів `Eₙ` для високих квантових чисел `n ≫ 1`, а для квантового гармонічного осцилятора дає абсолютно точний аналітичний результат `Eₙ = ℏω(n + ½)` для всіх `n ≥ 0`.
