# ⚙️ Чисельне розв'язання рівняння Шредінгера методом Нумерова

Чисельне знаходження власних значень енергії та хвильових функцій одновимірного стаціонарного рівняння Шредінгера є однією з фундаментальних задач обчислювальної фізики. Складні потенціальні рельєфи `V(x)` (наприклад, агармонічні осцилятори, подвійні потенціальні ями у молекулах чи гетероструктури напівпровідників) не мають аналітичних розв'язків у елементарних функціях. У таких випадках рівняння Шредінгера розв'язують чисельно на просторовій сітці.

Метод Нумерова — це спеціалізований різницевий алгоритм високого ступеня точності (похибка 6-го порядку дискретизації `O(h⁶)` та глобальна похибка `O(h⁴)`), розроблений астрономом Борисом Нумеровим для лінійних диференціальних рівнянь другого порядку вида `y''(x) + k²(x)·y(x) = 0`, які не містять першої похідної. Ця вставка містить детальне виведення алгоритму Нумерова, порівняльний аналіз із методом Рунге — Кутти, опис поєднання його з методом стрільби для розв'язання задач на власні значення та повну робочу реалізацію мовами C та C++.

## Математичне виведення різницевої схеми Нумерова

Стаціонарне рівняння Шредінгера записується у канонічній формі:

```
d²ψ(x)/dx² + k²(x) · ψ(x) = 0      [канонічне рівняння без першої похідної]
```

де значення `k²(x)` визначається потенціалом `V(x)` та випробувальною енергією `E`:

```
k²(x) = (2·m / ℏ²) · (E - V(x))      [квадрат ефективного хвильового числа]
```

Розглянемо рівномірну просторову сітку з кроком `h`: `xₙ = x₀ + n·h`. Розкладемо хвильову функцію `ψ(x)` у ряд Тейлора навколо вузла `xₙ` у прямому та зворотному напрямках:

```
ψ(xₙ + h) = ψₙ + h·ψₙ' + (h²/2)·ψₙ'' + (h³/6)·ψₙ''' + (h⁴/24)·ψₙ⁽⁴⁾ + (h⁵/120)·ψₙ⁽⁵⁾ + O(h⁶)
ψ(xₙ - h) = ψₙ - h·ψₙ' + (h²/2)·ψₙ'' - (h³/6)·ψₙ''' + (h⁴/24)·ψₙ⁽⁴⁾ - (h⁵/120)·ψₙ⁽⁵⁾ + O(h⁶)
```

Додаючи ці два розклади, непарні похідні повністю скорочуються:

```
ψₙ₊₁ + ψₙ₋₁ = 2·ψₙ + h²·ψₙ'' + (h⁴ / 12) · ψₙ⁽⁴⁾ + O(h⁶)      [сумарний розклад Тейлора]
```

Виразимо четверту похідну `ψₙ⁽⁴⁾`. Для цього застосуємо оператор другої похідної до вихідного рівняння `ψ'' = -k²·ψ`:

```
ψ⁽⁴⁾ = d²/dx² (-k²·ψ) = - (d²/dx²)(k²·ψ)
```

Застосуємо для другої похідної добутку `(k²·ψ)` стандартну центрально-різницеву аппроксимацію 2-го порядку:

```
(d²/dx²)(k²·ψ)ₙ = ( k²♙₊₁·ψ♙₊₁ - 2·k²♙·ψ♙ + k²♙₋₁·ψ♙₋₁ ) / h² + O(h²)
```

Підставивши цей вираз у сумарний розклад Тейлора замість четвертої похідної:

```
ψₙ₊₁ + ψₙ₋₁ = 2·ψₙ - h²·k²♙·ψ♙ - (h⁴ / 12) · [ ( k²♙₊₁·ψ♙₊₁ - 2·k²♙·ψ♙ + k²♙₋₁·ψ♙₋₁ ) / h² ] + O(h⁶)
```

Збираючи члени з однаковими індексами `n+1`, `n` та `n-1` по різні боки рівності, отримуємо триточкову різницеву формулу Нумерова:

```
(1 + (h²/12)·k²♙₊₁) · ψ♙₊₁ = 2 · (1 - (5·h²/12)·k²♙) · ψ♙ - (1 + (h²/12)·k²♙₋₁) · ψ♙₋₁      [ітераційна схема Нумерова]
```

Ця формула є виключно ефективною: знаючи початкові значення `ψ₀` та `ψ₁`, ми можемо обчислити значення `ψ₂`, за ним `ψ₃` і так далі аж до кінця розрахункової сітки.

## Порівняльний аналіз з методом Рунге — Кутти 4-го порядку (RK4)

У загальних диференціальних рівняннях 2-го порядку використовують універсальний метод Рунге — Кутти 4-го порядку (RK4). Проте для стаціонарного рівняння Шредінгера метод Нумерова володіє суттєвими перевагами:

1. **Обчислювальна швидкість:** Алгоритм RK4 вимагає чотирьох обчислень правої частини рівняння на кожен крок сітки `h`. Схема Нумерова вимагає лише одного обчислення потенціалу `V(x)` на вузол, що робить її приблизно у 3–4 рази швидшою.
2. **Відсутність першої похідної:** Метод Нумерова обчислює безпосередньо саму хвильову функцію `ψ(x)` без необхідності зберігати та оновлювати вектор першої похідної `ψ'(x)`.
3. **Точність:** Локальна похибка схеми Нумерова дорівнює `O(h⁶)`, що на один порядок точніше за локальну похибку RK4 (`O(h⁵)`).

## Метод стрільби (Shooting Method) для пошуку власних значень

Для зв'язаного стану частинки у потенціальній ямі хвильова функція мусить прямувати до нуля на обох нескінченних межах: `ψ(-∞) = 0` та `ψ(+∞) = 0`.

На скінченній розрахунковій сітці `[x_min, x_max]` ставляться граничні умови Дирихле:

```
ψ(x_min) = 0,    ψ(x_max) = 0      [крайові умови Дирихле]
```

Для довільно обраного значення випробувальної енергії `E` початкова інтеграція від лівої межі `x_min` з початковими даними `ψ₀ = 0` та `ψ₁ = ε` дасть на правому кінці ненульову неузгодженість: `F(E) = ψ(x_max; E) ≠ 0`.

Завдання пошуку власних значень енергії зводиться до знаходження коренів нелінійного рівняння відносно змінної `E`:

```
F(E) = ψ(x_max; E) = 0      [спектральне рівняння неузгодженості]
```

Пошук кореня `E` виконується методом бісекції (ділення навпіл) або методом січних на інтервалі пошуку `[E_low, E_high]`.

Метод бісекції є ітераційним процес звуження інтервалу локалізації кореня. Якщо на межах випробувального інтервалу `[E_low, E_high]` неузгодженість має протилежні знаки `F(E_low) · F(E_high) < 0`, то за теоремою Больцано — Коші всередині інтервалу існує щонайменше один корінь `E_exact`. На кожній ітерації інтервал ділиться навпіл `E_mid = 0.5 · (E_low + E_high)`. Якщо `F(E_low) · F(E_mid) < 0`, то новий інтервал стає `[E_low, E_mid]`, інакше `[E_mid, E_high]`. Ітерації продовжуються до досягнення потрібної точності `|E_high - E_low| < tolerance`.

## Двонапрямлена інтеграція та точка зшивання (Matching Point)

Під час інтегрування у напрямку зростання `x` у класично забороненій області (`E < V(x)`), чисельні похибки округлення неминуче збуджують другу нефізичну експоненціально зростаючу гілку розв'язку `e⁺ⁿˣ`. Це призводить до чисельної нестійкості стрільби від одного кінця до іншого.

Щоб подолати цю нестійкість, у професійних обчислювальних пакетах використовують **двонапрямлену інтеграцію**:
1. **Інтеграція ліворуч-праворуч:** хвилю `ψ_L(x)` інтегрують від `x_min` до точки повороту `x_match`, де `V(x_match) = E`.
2. **Інтеграція праворуч-ліворуч:** хвилю `ψ_R(x)` інтегрують від `x_max` ліворуч до тої самої точки `x_match`.
3. **Умова гладкого зшивання:** у точці `x_match` вимагають рівності логарифмічних похідних обох хвильових функцій:

```
f(E) = (ψ_L'(x_match) / ψ_L(x_match)) - (ψ_R'(x_match) / ψ_R(x_match)) = 0      [умова зшивання логарифмічних похідних]
```

Цей підхід повністю усуває чисельну нестійкість розбіжних експонент, гарантуючи монотонне згасання підбар'єрних хвостів на обох межах розрахункової сітки.

## Нормування хвильових функцій та підрахунок вузлів

Отриманий після чисельного інтегрування вектор значень `ψ_n(x)` визначається з точністю до довільного масштабового множника. Для перетворення його на фізичну хвильову функцію виконують чисельне нормування за правилом Сімпсона або методом трапецій:

```
I_norm = ∫₋∞⁺∞ |ψ(x)|² dx ≈ ∑ᵢ 0.5 · ( |ψᵢ|² + |ψᵢ₊₁|² ) · h      [чисельний нормувальний інтеграл]
```

Після обчислення інтеграла кожен елемент вектора ділять на нормувальний множник: `ψ_norm(xᵢ) = ψ(xᵢ) / √I_norm`.

Для перевірки фізичної правильності знайденого стану алгоритм виконує підрахунок кількості знаків зміни функції `ψ(x)` (вузлів). Якщо функція містить менше або більше вузлів, ніж вимагає спектральний номер `n` за теоремою Штурма, розв'язувач автоматично коригує межі випробувального інтервалу енергії.

## Аналіз точності та вибір параметрів сітки

1. **Залежність похибки від кроку сітки:** Оскільки глобальна похибка схеми Нумерова становить `O(h⁴)`, зменшення кроку сітки `h` вдвічі зменшує похилку обчислення власного значення енергії у 16 разів. Для досягнення точності `10⁻⁶` зазвичай достатньо сітки із `1000` вузлів.
2. **Перевірка за кількістю вузлів:** Після знаходження хвильової функції `ψ♙` чисельний алгоритм обов'язково підраховує кількість внутрішніх знаків зміни `ψ(x)`. Згідно з осциляційною теоремою Штурма, `n`-й стан повинен мати точно `n` вузлів. Якщо число вузлів не збігається із заданим квантовим номером, інтервал стрільби `[E_low, E_high]` коригується.
