# 🧮 Математична модель потенціалу Корнелла та струнний потенціал КХД

Математичний опис взаємодії між кварком та антикварком на довільних відстанях спирається на феноменологічний потенціал Корнелла. Ця модель об'єднує результати теорії збурень КХД на малих відстанях та непертурбативні розрахунки гратчастої хромодинаміки на великих відстанях, надаючи аналітичний інструментарій для розрахунку спектроскопії адронів, енергій зв'язку та властивостей глюонних струн.

## Аналітичний вираз потенціалу Корнелла та фундаментальні параметри

У нерелятивістському наближенні потенціальну енергію взаємодії між важкою кварк-антикварковою парою (`c-cbar` для чармонію `J/ψ` або `b-bbar` для ботомонію `Υ`) як функцію просторового розділення `r` записують у вигляді:

```
V(r) = -a / r + K · r + C
```

де:
- `a = (4/3) · α_s` — безрозмірний коефіцієнт кулоноподібного одноглюонного обміну;
- `α_s` — ефективна біжуча констант сильного зв'язку КХД;
- `K` — коефіцієнт натягу глюонної струни (string tension);
- `C` — аддитивна константа, яка визначає нормування нульового рівня потенціальної енергії.

Коефіцієнт `4/3` при кулонівському доданку виникає як власне значення квадратичного оператора Казимира `C_F` для фундаментального представлення колірної групи симетрії `SU(3)_c`. Розрахунок оператора Казимира здійснюється через сумування за всіма вісьмома генераторами `T^a = λ^a / 2`:

```
C_F = (1 / N_c) · Tr( ∑_{a=1}^{8} T^a T^a ) = (N_c² - 1) / (2 · N_c)
```

Для числа кольорів `N_c = 3` отримаємо точне раціональне значення:

```
C_F = (3² - 1) / (2 · 3) = 8 / 6 = 4 / 3
```

Цей множник визначає інтенсивність хромоелектричного притягання у колірному синглетному стані. Для порівняння, у колірному октетному стані кварк-антикваркової пари власне значення оператора Казимира дорівнює `C_O = -1 / (2 N_c) = -1 / 6`, що відповідає слабкому відштовхуванню між частинками.

## Два фундаментальні фізичні режими потенціалу

Поведінка функціоналу `V(r)` розпадається на два чітко розмежовані фізичні режими залежно від масштабу просторового розділення `r`:

### 1. Короткі відстані (`r << 0.2 fm` або високі імпульси `Q² >> Λ_QCD²`)

На малих відстанях між кварками домінує пертурбативний кулоноподібний член `-a / r`. Силова дія описується аналогом закону Кулона для сильної взаємодії:

```
F(r) = -dV(r)/dr = -(4/3) · (α_s / r²)
```

З урахуванням однопетльової залежності константи сильного зв'язку від масштабу імпульсу `Q² ≈ 1 / r²`:

```
α_s(r) = 12π / ( (33 - 2 · n_f) · ln(1 / (r² · Λ_QCD²)) )
```

При наближенні кварків один до одного (`r → 0`) сила притягання спадає швидше ніж `1/r²` через логарифмічне зменшення `α_s(r)`. Це є математичним вираженням властивості асимптотичної свободи.

### 2. Великі відстані (`r >> 0.5 fm` або малі імпульси `Q² ~ Λ_QCD²`)

На великих відстанях кулонівський доданок спадає до нуля, і в потенціалі починає повністю домінувати лінійний член `K · r`. Сила притягання між кварками прямує до постійного значення, яке не залежить від відстані між ними:

```
F(r) = -dV(r)/dr → -K = const   [Постійна сила натягу глюонної струни]
```

Типове значення натягу струни `K`, отримане з чисельного фітування спектра мас важких мезонів та гратчастих розрахунків, становить:

```
K ≈ 1.0 GeV/fm ≈ 0.18 GeV² ≈ 1.6 · 10⁵ N
```

У макроскопічних одиницях вимірювання ця сила відповідає вазі вантажу масою близько 16 тонн, прикладеній до двох точкових частинок у субатомному об'ємі.

## Оператор петлі Вільсона та математичний критерій конфайнменту

Формальне математичне визначення потенціалу взаємодії між нескінченно важкими статичними кварками в операторному формалізмі КХД здійснюється за допомогою калібрувально-інваріантного оператора петлі Вільсона `W(C)`.

Розглянемо прямокутний контур `C` у чотиривимірному евклідовому просторі-часі з просторовим розміром `R` (відстань між кварком і антикварком) та часовим розміром `T` (часова еволюція системи). Оператор петлі Вільсона визначають як впорядковану вздовж контуру експоненту від глюонного калібрувального поля `A_μ^a(x)`:

```
W(C) = (1 / N_c) · Tr P exp( i · g ∮_C A_μ^a(x) T^a dx^μ )
```

де:
- `g` — константа зв'язку КХД (`g = √(4π α_s)`);
- `T^a` — генератори групи `SU(3)`;
- `P` — оператор впорядкування матриць уздовж контуру інтегрування `C`;
- `Tr` — шпур (слід) матриці за колірними індексами.

Енергія статичного потенціалу `V(R)` визначається через асимптотику вакуумного середнього значення петлі Вільсона `⟨W(C)⟩` при нескінченно великих часових інтервалах `T → ∞`:

```
V(R) = - lim_{T → ∞} (1 / T) · ln ⟨W(C)⟩
```

Математична природа фазового стану калібрувального поля визначається асимптотичним законом спадання вакуумного середнього `⟨W(C)⟩` при збільшенні площі контуру:

1. **Закон периметра (Perimeter Law):**
   У фазі без конфайнменту (наприклад, у КЕД або гарячій кварк-глюонній плазмі) вакуумне середнє спадає пропорційно периметру контуру `P(C) = 2T + 2R`:

```
⟨W(C)⟩ ∝ exp( -μ · (2T + 2R) )
```

   Підстановка у формулу для потенціалу дає:

```
V(R) = - lim_{T → ∞} (1 / T) · ( -μ · (2T + 2R) ) = 2μ = const
```

   Це означає, що енергія відокремлення зарядів на нескінченність є скінченною, тобто частини вільно розлітаються (стан деконфайнменту).

2. **Закон площі (Area Law):**
   У фазі конфайнменту вакуумне середнє спадає експоненціально від площі контуру `Area(C) = T × R`:

```
⟨W(C)⟩ ∝ exp( -K · (T × R) ) = exp( -K · Area(C) )   [Критерій Вільсона для утримання кольору]
```

   Обчислення граграниці дає лінійно зростаючий потенціал утримання:

```
V(R) = - lim_{T → ∞} (1 / T) · ln( exp(-K · R · T) ) = K · R   [Виведення лінійного потенціалу з закону площі]
```

Таким чином, закон площі для петлі Вільсона є строгим математичним критерієм наявності конфайнменту у КХД.

## Траєкторії Редже та струнна модель Намбу — Ґото

Історично першим експериментальним доказом існування лінійного потенціалу та натягу струни `K` було відкриття лінійних траєкторій Редже у фізиці адронів.

При побудові графічної залежності повного спіна адронів `J` від квадрата їхньої маси `M²` для родин мезонів та баріонів з однаковими внутрішніми квантовими числами спостерігається суворо лінійна залежність:

```
J(M²) = α₀ + α' · M²
```

де `α'` — універсальний нахил траєкторії Редже (`α' ≈ 0.9 GeV⁻²`), а `α₀` — точка перетину з віссю ординат.

Для математичного пояснення цієї залежності розглянемо класичну релятивістську струну Намбу — Ґото товщиною нуль із натягом `K` та довжиною `L`. Припустимо, що на кінцях струни розташовані безмасові кварк і антикварк, а сама струна обертається у площині навколо свого центра мас із кутовою швидкістю `ω`.

Швидкість руху елемента струни на відстані `r` від центра дорівнює `v(r) = ω · r`. Оскільки кінці струни рухаються зі швидкістю світла (`v(L/2) = c = 1`), кутова швидкість зв'язана з довжиною струни співвідношенням `ω = 2 / L`.

Повна маса (енергія) `M` обертальної струни обчислюється як інтеграл від релятивістської густини енергії:

```
M = 2 · ∫₀^{L/2} [ K / √(1 - v(r)²) ] dr = 2 · ∫₀^{L/2} [ K / √(1 - (2r/L)²) ] dr
```

Використовуючи заміну змінної `u = 2r / L`, інтеграл зводиться до табличного:

```
M = K · L · ∫₀¹ [ 1 / √(1 - u²) ] du = K · L · [ arcsin(u) ]₀¹ = (π / 2) · K · L   [Маса обертальної струни]
```

Повний кутовий момент (спін) `J` тієї ж обертальної струни обчислюється як інтеграл від моментів імпульсу її елементів:

```
J = 2 · ∫₀^{L/2} [ K · r · v(r) / √(1 - v(r)²) ] dr = 2 · K · (2/L) · ∫₀^{L/2} [ r² / √(1 - (2r/L)²) ] dr
```

Після заміни змінної `u = 2r / L`:

```
J = (K · L² / 4) · ∫₀¹ [ u² / √(1 - u²) ] du = (K · L² / 4) · (π / 4) = (π / 16) · K · L²   [Спін обертальної струни]
```

Тепер виключимо невідому довжину струни `L` з виразів для `M` та `J`. З формули для маси маємо `L = 2M / (π K)`. Підставляючи `L` у вираз для спіна `J`:

```
J = (π / 16) · K · ( 2M / (π K) )² = (π / 16) · K · ( 4 M² / (π² K²) ) = (1 / (2π · K)) · M²
```

Порівнюючи отриману залежність `J = (1 / (2π K)) · M²` з емпіричним рівнянням траєкторії Редже `J = α' · M²`, знаходимо точний математичний зв'язок між нахилом Редже `α'` та натягом глюонної струни `K`:

```
α' = 1 / (2π · K)   ==>   K = 1 / (2π · α')   [Зв'язок нахилу Редже з натягом струни]
```

Підстановка експериментального значення `α' ≈ 0.90 GeV⁻²` дає:

```
K = 1 / (2π · 0.90 GeV⁻²) = 1 / (5.655 GeV⁻²) ≈ 0.177 GeV² ≈ 0.90 GeV/fm
```

Це теоретичне виведення ідеально узгоджується з чисельними результатами гратчастої КХД, підтверджуючи струнну природу утримання кварків.

## Профіль хромоелектричного поля силової трубки

У континуальному наближенні глюонна струна являє собою циліндрично симетричний вихор хромоелектричного поля.

Просторовий розподіл поздовжньої компоненти хромоелектричного поля `E_z(ρ)` як функція радіальної відстані `ρ` від осі струни можна апроксимувати гауссовим профілем:

```
E_z(ρ) = E₀ · exp( - ρ² / (2 · R_₀²) )
```

де `E₀` — амплітуда поля на осі струни, а `R_₀ ≈ 0.4 fm` — характеристичний радіус ядра струни.

Густина енергії хромоелектричного поля `ε(ρ)` дорівнює:

```
ε(ρ) = (1 / 2) · E_z²(ρ) = (1 / 2) · E₀² · exp( - ρ² / R_₀² )
```

Повний натяг струни `K` отримується шляхом інтегрування густини енергії за поперечним перерізом струни:

```
K = ∫₀^∞ ε(ρ) · 2π ρ dρ = π · E₀² · ∫₀^∞ exp( - ρ² / R_₀² ) · ρ dρ = (π / 2) · E₀² · R_₀²
```

Використовуючи значення `K ≈ 1.0 GeV/fm` та `R_₀ ≈ 0.4 fm`, отримуємо напряженість хромоелектричного поля на осі струни `E₀ ≈ 1.26 GeV/fm`, що ілюструє гігантську концентрацію енергії всередині глюонної силової трубки.

## Розв'язок рівняння Шредінгера з потенціалом Корнелла

Для розрахунку спектра мас частинок зі зв'язаних важких кварків (`c-cbar` або `b-bbar`) розв'язують радіальне рівняння Шредінгера при відносній масі `m_r = m_q / 2`:

```
- [ħ² / (2 m_r)] · (d²u / dr²) + [ V(r) + ħ² l (l + 1) / (2 m_r r²) ] · u(r) = E · u(r)
```

де `u(r) = r · R(r)` — представлена радіальна хвильова функція, `l` — орбітальний кутовий момент.

Оскільки потенціал Корнелла містить суму кулонівського та лінійного додавань, аналітичний розв'язок у замкненому вигляді через елементарні функції відсутній. У квазікласичному наближенні (ВКБ) або за допомогою варіаційних методів власні значення енергії `E_n` для лінійного потенціалу `V(r) = K r` спадають за законом:

```
E_n ∝ ( (n + 3/4) · π · K / √(2 m_r) )^(2/3)
```

де `n = 0, 1, 2, ...` — головне квантове число.

Ця залежність енергетичних рівнів `E_n ∝ n^{2/3}` якісно відрізняється від кулонівського спектра атома водню (`E_n ∝ -1/n²`) та гармонічного осцилятора (`E_n ∝ n`), точно відтворюючи експериментальні відстані між збудженими рівнями чармонію `J/ψ`, `ψ'`, `ψ(3770)` та ботомонію `Υ(1S)`, `Υ(2S)`, `Υ(3S)`.
