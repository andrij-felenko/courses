# 🧮 Математичний апарат дифракційної ґратки: від Формули Гюйгенса до Роздільної здатності

Повний спектральний, хвильовий та динамічний опис дифракційної ґратки спирається на розрахунок скалярного дифракційного інтеграла Кірхгофа у наближенні Фраунгофера та підсумовування фазових зсувів між точковими джерелами вторинних хвиль за принципом Гюйгенса — Френеля.

Нижче наведено строгий математичний вивід основного рівняння ґратки, розподілу інтенсивності для `N` щілин, аналіз умов зникнення максимумів, вивід кутової дисперсії, хроматичної роздільної здатності за критерієм Релея, вільної спектральної області та аналіз ґратки в термінах Фур'є-оптики.

### 1. Математичний вивід основного рівняння дифракційної ґратки

Розглянемо плоску дифракційну ґратку з періодом `d`, що складається з `N` паралельних щілин. На ґратку падає плоска монохроматична електромагнітна хвиля з довжиною хвилі `λ` під кутом `θᵢ` відносно нормалі до поверхні ґратки.

#### 1.1. Геометрична різниця ходу

Розглянемо два паралельні промені, що падають на два сусідні елементи `A` та `B`, розташовані на відстані `d`:

- Відстань між хвильовим фронтом падаючої хвилі та точкою `B` перевищує відстань до точки `A` на величину:

```
ΔL_in = d · sin θᵢ
```

- Після дифракції під кутом `θₘ` відносно нормалі, хвиля від точки `A` долає додатковий шлях порівняно з хвилею від точки `B`:

```
ΔL_out = d · sin θₘ
```

- Повна оптична різниця ходу `ΔL` між двома інтерферуючими променями від сусідніх щілин дорівнює:

```
ΔL = ΔL_out + ΔL_in = d · (sin θₘ + sin θᵢ)
```

#### 1.2. Умова інтерференційного максимуму

Для того щоб два когерентні промені додавалися в однаковій фазі (конструктивна інтерференція), оптична різниця ходу `ΔL` повинна дорівнювати цілому числу довжин хвиль `m · λ`:

```
d · (sin θₘ + sin θᵢ) = m · λ     [Рівняння дифракційної ґратки]
```

де `m ∈ ℤ` (`m = 0, ±1, ±2, ...`) — порядок дифракційного максимуму.

При нормальному падінні світла (`θᵢ = 0`):

```
d · sin θₘ = m · λ
```

Оскільки значення синуса обмежене `|sin θₘ| ≤ 1`, максимальний можливий порядок дифракції `m_max` визначається співвідношенням періоду до довжини хвилі:

```
m_max = ⌊ d / λ ⌋
```

Якщо період ґратки менший за довжину хвилі (`d < λ`), існує лише нульовий порядок (`m = 0`), і ґратка працює як звичайне дзеркало або прозора пластина без спектрального розкладання.

### 2. Вивід розподілу інтенсивності світла для N щілин

Для розрахунку розподілу напруженості електричного поля `E(θ)` та інтенсивності `I(θ)` під кутом спостереження `θ` скористаємося наближенням дифракції Фраунгофера у далекій зоні.

#### 2.1. Амплітуда від однієї щілини

Напруженість електричного поля від однієї щілини шириною `a` під кутом `θ` визначається інтегруванням вторинних джерел уздовж координати щілини `x' ∈ [-a/2, +a/2]`:

```
E₁(θ) = (E₀ / a) · ∫_{-a/2}^{+a/2} exp(i · k · x' · sin θ) dx'
```

де `k = 2·π / λ` — хвильове число.

Обчислюємо інтеграл:

```
E₁(θ) = (E₀ / a) · [ exp(i · k · a/2 · sin θ) - exp(-i · k · a/2 · sin θ) ] / (i · k · sin θ)
= E₀ · sin( (π · a · sin θ) / λ ) / ( (π · a · sin θ) / λ )
```

Уводячи фазовий параметр однощілинної дифракції `β`:

```
β = (π · a · sin θ) / λ     [фазовий параметр щілини]
```

отримуємо амплітуду поля однієї щілини:

```
E₁(θ) = E₀ · (sin β / β)
```

#### 2.2. Сумування полів N щілин

Ґратка складається з `N` щілин, центри яких розташовані в точках `x_k = k · d` для `k = 0, 1, 2, ..., N - 1`. Фазовий зсув між електричними полями двох сусідніх щілин дорівнює `2·γ`, де:

```
γ = (π · d · sin θ) / λ     [міжнародний фазовий параметр ґратки]
```

Повне електричне поле `E_total(θ)` є комплексною сумою скінченної геометричної прогресії:

```
E_total(θ) = E₁(θ) · ∑_{k=0}^{N-1} exp(i · 2 · k · γ)
```

Застосовуємо формулу суми геометричної прогресії `∑_{k=0}^{N-1} q^k = (1 - q^N) / (1 - q)` для `q = exp(i · 2·γ)`:

```
∑_{k=0}^{N-1} exp(i · 2 · k · γ) = (1 - exp(i · 2 · N · γ)) / (1 - exp(i · 2 · γ))
```

Виносимо симетричні фазові множники з чисельника та знаменника:

```
1 - exp(i · 2 · N · γ) = exp(i · N · γ) · [ exp(-i · N · γ) - exp(i · N · γ) ] = -2 · i · exp(i · N · γ) · sin(N · γ)
```

```
1 - exp(i · 2 · γ) = exp(i · γ) · [ exp(-i · γ) - exp(i · γ) ] = -2 · i · exp(i · γ) · sin(γ)
```

Ділення чисельника на знаменник дає:

```
E_total(θ) = E₁(θ) · exp(i · (N - 1) · γ) · (sin(N · γ) / sin γ)
```

#### 2.3. Формула інтенсивності

Інтенсивність світла пропорційна квадрату модуля амплітуди поля `I(θ) = |E_total(θ)|²`:

```
I(θ) = I₀ · (sin β / β)² · (sin(N · γ) / sin γ)²     [Формула розподілу інтенсивності]
```

де:
- `I₀ = |E₀|²` — інтенсивність у центрі від однієї щілини;
- `(sin β / β)²` — **дифракційний множник однощілинної обвідної** (*single-slit diffraction factor*);
- `(sin(N · γ) / sin γ)²` — **мультипроменевий інтерференційний множник** (*multi-beam interference factor*).

#### 2.4. Граничний перехід у головних максимумах

У точках головних максимумів `γ = m · π` (`m ∈ ℤ`) чисельник `sin(N · m · π) = 0` та знаменник `sin(m · π) = 0`. Раскриваємо невизначеність `0/0` за правилом Лопіталя:

```
lim_{γ → m·π} (sin(N · γ) / sin γ) = lim_{γ → m·π} (N · cos(N · γ) / cos γ) = N · (-1)^{m·(N-1)} / (-1)^m = ± N
```

Отже, значення інтерференційного множника у головних максимумах дорівнює `N²`:

```
I_max = I₀ · N² · (sin β_m / β_m)²
```

Інтенсивність у головному максимумі зростає пропорційно квадрату кількості штрихів `N²`, оскільки амплітуди `N` хвиль складаються в однакових фазах (`E_total = N · E₁`).

### 3. Кутова та Лінійна Дисперсія

Кутова дисперсія `D_θ` визначає кутове розділення двох близьких спектральних ліній при зміні довжини хвилі `λ`:

```
D_θ = dθₘ / dλ
```

#### 3.1. Вивід кутової дисперсії

Диференціюємо рівняння дифракційної ґратки `d · (sin θₘ + sin θᵢ) = m · λ` по довжині хвилі `λ` (при постійному куті падіння `θᵢ`):

```
d · d(sin θₘ) = m · dλ
d · cos θₘ · dθₘ = m · dλ
```

Звідси отримуємо строгий вираз для кутової дисперсії:

```
D_θ = dθₘ / dλ = m / (d · cos θₘ)     [Кутова дисперсія]
```

Виразивши `cos θₘ` через синус за тригонометричною тотожністю `cos θₘ = √(1 - sin² θₘ)` та підставивши `sin θₘ = (m·λ / d) - sin θᵢ` (для `θᵢ = 0`):

```
D_θ = m / √(d² - m² · λ²)
```

#### 3.2. Лінійна дисперсія в фокальній площині

Якщо дифраговане світло фокусується об'єктивом із фокусною відстанню `F` на плоский фотодетектор, лінійне зміщення спектральної лінії `dx` дорівнює `dx = F · dθₘ`.

**Лінійна дисперсія** `D_x` становить:

```
D_x = dx / dλ = F · D_θ = (m · F) / (d · cos θₘ)
```

В інженерній практиці часто використовують обернену лінійну дисперсію `dλ / dx` (вимірюється в `нм/мм` або `Å/мм`), яка показує, який спектральний інтервал припадає на `1 мм` ширини детектора:

```
(dλ / dx) = (d · cos θₘ) / (m · F)
```

### 4. Хроматична роздільна здатність за критерієм Релея

**Хроматична роздільна здатність** `R` характеризує здатність оптичного приладу розділяти дві спектральні лінії з близькими довжинами хвиль `λ` та `λ + Δλ`:

```
R = λ / Δλ
```

#### 4.1. Формулювання критерію Релея

За критерієм Релея дві спектральні лінії однакової інтенсивності вважаються розрізненими, якщо центральний максимум дифракційної картини для довжини хвилі `λ + Δλ` збігається за кутом із першим інтенсивнісним мінімумом лінії `λ`.

#### 4.2. Математичний вивід R = m · N

1. Кутове положення головного максимуму порядку `m` для довжини хвилі `λ` відповідає фазовому параметру:

```
γ₁ = (π · d · sin θₘ) / λ = m · π
```

2. Перший мінімум інтерференційного множника `sin(N · γ)` праворуч від максимуму виникає тоді, коли чисельник перетворюється на нуль при ненульовому знаменнику, тобто коли фаза `γ` збільшується на `π / N`:

```
γ_min = m · π + π / N
```

3. Кутове положення максимуму порядку `m` для сусідньої лінії `λ + Δλ` відповідає фазі:

```
γ₂ = (π · d · sin(θₘ + dθ)) / (λ + Δλ) = m · π
```

Зауважимо, що для однієї й тієї ж кутової координати `θ_min` фазове значення для хвилі `λ + Δλ` збігається з фазою максимуму.

Зрівнюємо варіацію фази при зміні довжини хвилі `Δλ`:

```
dγ = |∂γ / ∂λ| · Δλ + |∂γ / ∂θ| · dθ = π / N
```

Оскільки для максимуму порядку `m` маємо `d · sin θₘ = m · λ`, то варіація фази по `λ` при фіксованому куті становить:

```
|dγ| = m · π · (Δλ / λ)
```

Прирівнюючи цю варіацію до відстані до першого мінімуму `π / N`:

```
m · π · (Δλ / λ) = π / N
```

Скорочуючи `π`, отримуємо сувору формулу роздільної здатності:

```
R = λ / Δλ = m · N     [Роздільна здатність дифракційної ґратки]
```

#### 4.3. Гранична роздільна здатність через світлову апертуру

Підставимо у формулу `R = m · N` вираз для порядку `m` з рівняння ґратки `m = (d · (sin θₘ + sin θᵢ)) / λ`:

```
R = (N · d · (sin θₘ + sin θᵢ)) / λ
```

Ураховуючи, що `W = N · d` є повною світловою шириною апертури ґратки:

```
R = W · (sin θₘ + sin θᵢ) / λ     [Апертурна формула роздільної здатності]
```

Цей результат має вирішальне фізичне значення: **теоретична межа роздільної здатності дифракційної ґратки визначається виключно її повною геометричною шириною `W` та кутами дифракції**, і не залежить від кількості штрихів `N` або періоду `d` окремо. Ґратка шириною `100 мм` з `600 lines/mm` у першому порядку дає точно таку ж роздільну здатність `R = 60 000`, як і ґратка шириною `100 мм` з `1200 lines/mm` (`N = 120 000`) у тому ж апертурному куті.

### 5. Вільна спектральна область (Free Spectral Range)

**Вільна спектральна область** (`Δλ_FSR`) визначає спектральний інтервал, у якому спектр порядку `m` не перекривається зі спектром сусіднього порядку `m + 1`.

Умова перекриття кутів дифракції для довгохвильової межі `λ + Δλ_FSR` порядку `m` та короткохвильової межі `λ` порядку `m + 1`:

```
d · (sin θ + sin θᵢ) = m · (λ + Δλ_FSR) = (m + 1) · λ
```

Розкриваючи дужки:

```
m · λ + m · Δλ_FSR = m · λ + λ
```

Звідси отримуємо вираз для вільної спектральної області:

```
Δλ_FSR = λ / m     [Вільна спектральна область]
```

Вільна область у частотному вираженні `Δν_FSR`:

```
Δν_FSR = c / (m · λ) = ν / m
```

При роботі у високих порядках дифракції (наприклад, `m = 50` у спектрометрах Ешелле) вільна спектральна область стає дуже вузькою (`Δλ_FSR = 500 нм / 50 = 10 нм`), що вимагає застосування додаткового крос-дисперсійного елемента (призми), розташованого перпендикулярно до штрихів ґратки.

### 6. Опис дифракційної ґратки в термінах Фур'є-оптики

У рамках формалізму Фур'є-оптики дифракційна ґратка описується комплексною функцією пропускання (амплітудно-фазовим транспарантом) `t(x)`.

#### 6.1. Амплітудна ґратка як згортка

Для нескінченної ґратки з періодом `d` та прозорими щілинами шириною `a` функція пропускання одного періоду є прямокутним імпульсом `rect(x / a)`:

```
rect(x / a) = 1 при |x| ≤ a/2, і 0 при |x| > a/2
```

Періодична ґратка скінченної ширини `W = N · d` описується згорткою решітки Дірака (гребінчастої функції `comb`) з прямокутним імпульсом щілини, помноженою на обмежувальну апертурну функцію `rect(x / W)`:

```
t(x) = [ ( ∑_{k=-∞}^{+∞} δ(x - k·d) ) ⊗ rect(x / a) ] · rect(x / W)
```

За теоремою про згортку, Фур'є-образ функції пропускання `T(f_x) = F{t(x)}` у просторовій частотній області `f_x = sin θ / λ` дорівнює добутку Фур'є-образів компонент:

```
T(f_x) = [ (1/d) · ∑_{m=-∞}^{+∞} δ(f_x - m/d) ] · [ a · sinc(a · f_x) ] ⊗ [ W · sinc(W · f_x) ]
```

де `sinc(u) = sin(π·u) / (π·u)`.

Цей результат тотожний раніше виведеній формулі інтенсивності:
- Дискретна сума дельта-функцій `δ(f_x - m/d)` дає вузькі головні максимуми при `f_x = m / d` (`d · sin θ = m · λ`);
- Множник `sinc(a · f_x)` формує однощілинну дифракційну обвідну;
- Згортка із `sinc(W · f_x)` визначає скінченну ширину кожного максимуму `δf_x = 1 / W`.

#### 6.2. Синусоїдальна фазова ґратка

Для прозорої фазової ґратки з гармонічним рельєфом товщини функція пропускання має вигляд:

```
t(x) = exp(i · m_p · sin(2·π · x / d))
```

де `m_p` — амплітуда фазової модуляції (в радіанах).

Використовуючи розклад Якобі — Ангера у ряд за функціями Бесселя першого роду `J_m`:

```
exp(i · m_p · sin(2·π · x / d)) = ∑_{m=-∞}^{+∞} J_m(m_p) · exp(i · 2·π · m · x / d)
```

Інтенсивність світла у порядку дифракції `m` дорівнює квадрату відповідного коефіцієнта Бесселя:

```
I_m = I₀ · [ J_m(m_p) ]²     [ККД синусоїдальної фазової ґратки]
```

Максимально можливий ККД дифракції у першому порядку (`m = 1`) для синусоїдальної фазової ґратки досягається при `m_p ≈ 1.84` радіан і становить `I₁ / I₀ = [J₁(1.84)]² ≈ 33.9%`, що втричі перевищує межу для амплітудних ґраток (`10.1%`).
