# 🧮 Математичний апарат хвильових аберацій Зайделя

Математичний апарат теорії аберацій описує відхилення реального розповсюдження світла від ідеальної параксіальної моделі через розклад функції хвильової аберації та променевих координат у степеневі ряди. Нижче наведено суворе математичне виведення хвильового абераційного полінома Зайделя, зв'язок між хвильовими та поперечними променевими абераціями, а також розрахункові умови компенсації сферичної аберації та хроматизму.

### 1. Параксіальне розкладення та виведення нелінійностей третіх порядків

Закон заломлення Снелла пов'язує кути падіння `θ₁` та заломлення `θ₂` на межі двох середовищ із показниками заломлення `n₁` та `n₂`:

```
n₁ · sin θ₁ = n₂ · sin θ₂     [Закон Снелла]
```

У параксіальній оптиці припускають, що кути `θ` є надзвичайно малими, тому застосовується лінійне наближення першого порядку `sin θ ≈ θ`. Ця модель дає ідеальне точкове зображення (параксіальний фокус Гаусса).

Проте для реальних лінз із кінцевою апертурою кути `θ` вимагають врахування наступних нелінійних членів розкладу Тейлора:

```
sin θ = θ - (θ³ / 6) + (θ⁵ / 120) - ...     [Розклад синуса в ряд Тейлора]
```

Якщо підставити цей розклад у рівняння заломлення променя на сферичній поверхні радіуса `R`, то нормаль до сфери в точці з координатним зміщенням `y` від оптичної осі утворює кут `α` з віссю, де `sin α = y / R`. 

Розкладаючи синус кута нормалі:

```
α ≈ (y / R) + (y³ / (6 · R³))     [Розклад кута нормалі сфери]
```

Підновлення цієї нелінійності у рівняння закону Снелла дає відхилення заломленого кута `u'`, яке містить кубічну поправку за координатами вхідної зіниці `y³` та висоти предмета поза віссю `H³`. Саме ці кубічні члени у розкладі кутів заломлення породжують **монохроматичні аберації третього порядку** (або аберації Зайделя).

### 2. Хвильова функція аберації W(H, ρ, φ) та полярний розклад

Нехай `W(H, ρ, φ)` — оптична різниця ходу (OPD, *Optical Path Difference*) між реальним викривленим хвильовим фронтом і порівняльною сферичною хвилею, що прямує до параксіальної точки зображення.

Координати задаються у нормованій безрозмірній формі:
- `H` — нормована висота точки предмета в полі зору (`0 ≤ H ≤ 1`);
- `ρ` — нормований радіус точки на вхідній або вихідній зіниці (`0 ≤ ρ ≤ 1`);
- `φ` — полярний кут точки на зіниці відносно меридіональної площини (площини, що проходить крізь оптичну вісь та точку предмета).

Оскільки оптична система має осьову обертальну симетрію, скалярна функція хвильового фронту `W` може залежати лише від скалярних добутків векторів поля `H` та зіниці `ρ`. Це означає, що `W` є функцією трьох фундаментальних симетричних інваріантів:
- `H²` — квадрат координати поля;
- `ρ²` — квадрат координати зіниці;
- `H · ρ · cos φ` — скалярний добуток векторів поля та зіниці.

Розклад хвильової функції `W` у степеневий ряд за цими трьома інваріантами до другого порядку включно (що відповідає четвертому порядку за координатами `H` та `ρ`) дає загальний вигляд хвильового абераційного полінома Зайделя:

```
W(H, ρ, φ) = W₀₄₀ · ρ⁴ + W₁₃₁ · H · ρ³ · cos φ + W₂₂₂ · H² · ρ² · cos² φ + W₂₂₀ · H² · ρ² + W₃₁₁ · H³ · ρ · cos φ
```

де коефіцієнти `W_nkm` описують п'ять класичних монохроматичних аберацій Зайделя:

1. **`W₀₄₀ · ρ⁴`** — **Сферична аберація** (*Spherical Aberration*): є повністю симетричною відносно кута `φ` і не залежить від координати поля `H`. Вона виникає навіть на самій оптичній осі (`H = 0`) і зростає пропорційно четвертому ступеню радіуса зіниці `ρ⁴`.
2. **`W₁₃₁ · H · ρ³ · cos φ`** — **Кома** (*Coma*): лінійно зростає з віддаленням від осі `H` і пропорційна кубу радіуса зіниці `ρ³`. Описує асиметричне спотворення похилих пучків світла.
3. **`W₂₂₂ · H² · ρ² · cos² φ`** — **Астигматизм** (*Astigmatism*): квадратично залежить від поля `H²` та квадрата зіниці `ρ²`. Вносить різницю фокусування для тангенціальних та сагітальних променів.
4. **`W₂₂₀ · H² · ρ²`** — **Кривина поля Зайделя / Петцваля** (*Field Curvature*): зсув фокальної площини вздовж осі пропорційно квадрату відстані від центра поля `H²`.
5. **`W₃₁₁ · H³ · ρ · cos φ`** — **Дисторсія** (*Distortion*): залежить від куба висоти поля `H³`, зміщує точкове зображення у фокальній площині без втрати його чіткості.

### 3. Диференціальний зв'язок між хвильовою аберацією W та поперечними абераціями (δx, δy)

Згідно з хвильовою теорією світла та принципом Гюйгенса — Френеля, світлові промені завжди перпендикулярні (нормальні) до хвильового фронту. Відхилення нормалі реального хвильового фронту від нормалі ідеальної порівняльної сфери визначає кутове відхилення променя.

Нехай `R` — радіус порівняльної сфери (відстань від вихідної зіниці до фокальної площини), а `n` — показник заломлення середовища у просторі зображень. Лінійні поперечні зміщення точки перетину променя з фокальною площиною `(δx, δy)` від параксіальної точки зображення обчислюються через частинні похідні хвильової функції `W`:

```
δx = - (R / n) · (∂W / ∂x)     [поперечна променева аберація вздовж осі X]
```

```
δy = - (R / n) · (∂W / ∂y)     [поперечна променева аберація вздовж осі Y]
```

де `x = ρ · cos φ` та `y = ρ · sin φ` — декартові координати точки на вихідній зіниці.

#### А. Математичний розрахунок сферичної аберації
Для сферичної аберації `W(x, y) = W₀₄₀ · (x² + y²)²`:

Обчислимо частинні похідні хвильової функції за координатами зіниці:

```
∂W / ∂x = W₀₄₀ · 2(x² + y²) · 2x = 4 · W₀₄₀ · (x² + y²) · x = 4 · W₀₄₀ · ρ³ · cos φ
```

```
∂W / ∂y = W₀₄₀ · 2(x² + y²) · 2y = 4 · W₀₄₀ · (x² + y²) · y = 4 · W₀₄₀ · ρ³ · sin φ
```

Підставляючи похідні у формули променевих аберацій, отримуємо поперечний радіус плями розмиття `δr`:

```
δr = √(δx² + δy²) = (4 · R / n) · W₀₄₀ · ρ³     [Поперечна сферична аберація]
```

Зв'язок між поперечною аберацією `δr` та поздовжнім абераційним зсувом фокуса `δs'` уздовж оптичної осі задається з геометричної подібності трикутників:

```
δr / δs' = y_m / R  ⇒  δs' = δr · (R / y_m)
```

де `y_m` — максимальний апертурний радіус лінзи. Підставляючи `δr`, отримуємо точний вираз поздовжньої сферичної аберації:

```
δs' = (4 · R² / (n · y_m)) · W₀₄₀ · ρ² = 8 · (f' / y_m)² · W₀₄₀ · ρ²     [Поздовжня сферична аберація]
```

Отже, поздовжній фокальний зсув сферичної аберації зростає квадратично від радіуса апертурної зони `ρ²`.

#### Б. Математичний розрахунок і геометрія плями коми
Для аберації коми хвильова функція дорівнює `W = W₁₃₁ · H · ρ³ · cos φ = W₁₃₁ · H · (x² + y²) · x`.

Обчислимо частинні похідні:

```
∂W / ∂x = W₁₃₁ · H · ( (x² + y²) + x · 2x ) = W₁₃₁ · H · (3x² + y²)
```

```
∂W / ∂y = W₁₃₁ · H · ( 2x · y )
```

Переходимо до полярних координат зіниці (`x = ρ · cos φ`, `y = ρ · sin φ`):

```
3x² + y² = 3ρ² cos² φ + ρ² sin² φ = ρ² (2 cos² φ + 1) = ρ² (1 + cos(2φ) + 1) = ρ² (2 + cos(2φ))
```

```
2xy = 2ρ² cos φ sin φ = ρ² sin(2φ)
```

Підставляючи ці вирази у рівняння променевих аберацій:

```
δx = - (R / n) · W₁₃₁ · H · ρ² · sin(2φ)     [поперечна кома по горизонталі]
```

```
δy = - (R / n) · W₁₃₁ · H · ρ² · (2 + cos(2φ))     [поперечна кома по вертикалі]
```

Ці дві параметричні формули описують коло у фокальній площині:

```
(δx)² + (δy - δy_center)² = R_ring²
```

де радіус кола від зони зіниці `ρ` дорівнює `R_ring = (R / n) · W₁₃₁ · H · ρ²`, а його центр зміщений від параксіальної точки зображення на відстань `δy_center = 2 · R_ring`.

Оскільки `R_ring ∝ ρ²`, сукупність усіх кілець від усіх зон апертури утворює каплеподібну пляму, вписану в сектор із дотичними лініями під кутом `θ_coma`:

```
sin(θ_coma / 2) = R_ring / (2 · R_ring) = 1 / 2  ⇒  θ_coma / 2 = 30°  ⇒  θ_coma = 60°
```

Кут розкриття кометичного хвоста аберації коми третього порядку завжди дорівнює строго `60°`.

Максимальний тангенціальний розмір плями коми `δy_t` (при `φ = 0°`) дорівнює:

```
δy_t = - (R / n) · W₁₃₁ · H · ρ² · (2 + 1) = - 3 · (R / n) · W₁₃₁ · H · ρ²
```

Максимальний сагітальний розмір плями коми `δy_s` (при `φ = 90°`) дорівнює:

```
δy_s = - (R / n) · W₁₃₁ · H · ρ² · (1) = - (R / n) · W₁₃₁ · H · ρ²
```

Звідси випливає фундаментальне співвідношення теорії Зайделя:

```
δy_t = 3 · δy_s     [Співвідношення тангенціальної та сагітальної коми]
```

### 4. Виведення умов ахроматизації та вибір фокусних відстаней

Оптична сила тонкої лінзи `Φ = 1 / f'` визначається показником заломлення `n` та геометричним фактором кривини поверхонь `K = (1 / R₁ - 1 / R₂)`:

```
Φ = (n - 1) · K     [Формула оптичної сили тонкої лінзи]
```

Для аналізу дисперсії візьмемо повний диференціал оптичної сили по показникові заломлення `n`:

```
dΦ = d(n - 1) · K = dn · K = (dn / (n - 1)) · (n - 1) · K = (dn / (n - 1)) · Φ
```

За визначенням число Аббе матеріалу `V_d` дорівнює:

```
V_d = (n_d - 1) / (n_F - n_C)     [Число Аббе]
```

де `dn = n_F - n_C` — різниця показників заломлення для водневих спектральних ліній `F` (`486.1 нм`) та `C` (`656.3 нм`).

Тоді зміна оптичної сили лінзи при переході від червоного до синього кольору дорівнює:

```
dΦ = Φ / V_d     [Хроматична зміна оптичної сили]
```

Для склеєного дублета з двох тонких лінз сумарна оптична сила дорівнює сумі оптичних сил компонентів:

```
Φ_sum = Φ₁ + Φ₂
```

Вимога ахроматизації означає, що сумарна оптична сила дублета має бути однаковою для синього та червоного променів, тобто її диференціал `dΦ_sum` повинен дорівнювати нулю:

```
dΦ_sum = dΦ₁ + dΦ₂ = (Φ₁ / V₁) + (Φ₂ / V₂) = 0     [Умова ахроматизації дублета]
```

Отримуємо систему двох лінійних алгебраїчних рівнянь відносно двох невідомих оптичних сил `Φ₁` та `Φ₂`:

```
1)  Φ₁ + Φ₂ = Φ_sum
2)  Φ₁ / V₁ + Φ₂ / V₂ = 0
```

Виразимо `Φ₂` з другого рівняння: `Φ₂ = - Φ₁ · (V₂ / V₁)`. Підставимо у перше рівняння:

```
Φ₁ - Φ₁ · (V₂ / V₁) = Φ_sum  ⇒  Φ₁ · (1 - V₂ / V₁) = Φ_sum  ⇒  Φ₁ · ((V₁ - V₂) / V₁) = Φ_sum
```

Звідси одержуємо точні вирази для розрахунку оптичних сил і фокусних відстаней двох лінз ахроматичного дублета:

```
Φ₁ = Φ_sum · (V₁ / (V₁ - V₂))     [Оптична сила позитивної кронової лінзи]
```

```
Φ₂ = - Φ_sum · (V₂ / (V₁ - V₂))    [Оптична сила негативної флінтової лінзи]
```

Оскільки для збирального об'єктива `Φ_sum > 0`, а матеріали вибираються так, щоб кронове скло мало значно вище число Аббе ніж флінтове (`V₁ > V₂`), перша лінза обов'язково є позитивною збиральною (`Φ₁ > 0`), а друга — негативною розсіювальною (`Φ₂ < 0`).
