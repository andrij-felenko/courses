Одиночний мікрофон, розміщений у просторі, реєструє лише локальні коливання тиску повітря у часі `p(t)`. Цей сигнал є скалярною величиною: мембрана реагує на миттєве стиснення й розрідження газу, але не містить жодної прямої інформації про те, звідки надійшла хвиля. Якщо в кімнаті одночасно лунає голос диктора з кута 0°, вуличний шум крізь вікно під кутом 90° та відлуння від задньої стіни, мікрофон видає їхню спільну адитивну суміш. Коли спектр завади перекривається зі спектром мови (діапазон 300–3400 Гц), жоден одновимірний часовий чи частотний фільтр не здатен розділити ці джерела без суттєвого спотворення корисного звуку.

Для виділення сигналу за просторовою ознакою необхідна просторова вибірка хвильового поля. Розмістивши в просторі кілька мікрофонів у відомих координатах, ми перетворюємо різницю відстаней від джерела до кожного сенсора на вимірювані часові затримки та фазові зсуви. Це дозволяє здійснювати просторову фільтрацію: підсилювати звук із цільового кута завдяки конструктивній інтерференції та деструктивно гасити шуми й відлуння з інших напрямків.

Еволюцію інженерних спроб реалізувати цю ідею — від механічних стетоскопічних рупорів Першої світової війни до сучасних цифрових мікроелектромеханічних ґраток — висвітлено у вставці [Історія акустичних масивів: від слухових труб до цифрових ґраток](root:ph-waves/mikrofonnyi-masyv/hist-acoustic-arrays.md).

## Фізика просторової вибірки акустичного поля

Звукова хвиля у тривимірному однорідному середовищі описується лінійним хвильовим рівнянням для акустичного тиску. Якщо джерело звуку розташоване на достатньо великій відстані від масиву (зона далекого поля Фраунгофера, де відстань `R > 2 D² / λ`, а `D` — найбільший габаритний розмір апертури масиву), сферичний хвильовий фронт на масштабах масиву вироджується в плоский.

Плоска монохроматична акустична хвиля з циклічною частотою `ω = 2π f` та хвильовим вектором `\vec{k}` створює в довільній точці простору `\vec{r} = [x, y, z]^T` коливання тиску:

```
p(\vec{r}, t) = P₀ · e^{j (ω t - \vec{k} · \vec{r})}
```

де `P₀` — комплексна амплітуда звукового тиску, `|\vec{k}| = k = ω / c = 2π / λ` — хвильове число, `c` — швидкість звуку в повітрі (приблизно 343 м/с за температури 20 °C), а `λ = c / f` — довжина акустичної хвилі.

Розглянемо лінійний масив (Uniform Linear Array, ULA), що складається з `M` однакових ненапрямлених мікрофонів, розташованих уздовж осі `X` з постійним мікрофонним кроком `d`. Координата `m`-го мікрофона (`m = 0, 1, ..., M - 1`) задається вектором:

```
\vec{r}_m = [m · d, 0, 0]^T
```

![Геометрія лінійного масиву](/root/sci/ph-waves/mikrofonnyi-masyv/img/array-interference-geometry.svg)
*Геометрія падіння плоскої звукової хвилі на лінійний мікрофонний масив: різниця ходу променя до сусідніх сенсорів зумовлює затримку приходу сигналу та відповідний фазовий набіг.*

Нехай плоский фронт хвилі надходить під кутом `θ` відносно акустичної нормалі до лінії масиву (кут `θ = 0°` відповідає перпендикулярному падінню, кути `θ = ±90°` — поздовжньому падінню вздовж осі масиву). Хвильовий вектор має вигляд:

```
\vec{k} = [k · sin(θ), k · cos(θ), 0]^T
```

Обчислимо скалярний добуток `\vec{k} · \vec{r}_m` для `m`-го сенсора:

```
\vec{k} · \vec{r}_m
= (k · sin(θ)) · (m · d) + (k · cos(θ)) · 0 + 0 · 0                 [скалярний добуток векторів]
= m · k · d · sin(θ)                                                [групування множників]
= m · (2π f / c) · d · sin(θ)                                       [підстановка k = 2π f / c]
```

Різниця геометричного шляху (різниця ходу променя) між нульовим опорним мікрофоном `M₀` та `m`-м мікрофоном `M_m` дорівнює:

```
Δr_m = m · d · sin(θ)
```

Звукова хвиля долає цю додаткову відстань за час затримки поширення `τ_m`:

```
τ_m = Δr_m / c = (m · d · sin(θ)) / c
```

Фазовий зсув сигналу на `m`-му мікрофоні відносно нульового на частоті `f` становить:

```
Δφ_m = ω · τ_m = 2π f · τ_m = (2π f · m · d · sin(θ)) / c
```

Сигнал на виході `m`-го мікрофона у часовій області є затриманою копією вихідного тиску з додаванням власного адитивного шуму тракту:

```
x_m(t) = s(t - τ_m) + n_m(t)
```

Просторова вибірка поля перетворює кутовий напрямок джерела `θ` на детермінований набір фазових або часових затримок між каналами. Задача пасивної локалізації полягає у зворотному перетворенні: виміряти взаємні затримки між мікрофонами й відновити просторові координати джерела звуку.

## Різниця часу приходу (TDoA) та кореляційне відбілювання

Для визначення просторового напрямку на невідомий широкосмуговий акустичний сигнал (наприклад, людську мову, шум гвинтів квадрокоптера чи постріл) використовують метод оцінки різниці часу приходу сигналу (Time Difference of Arrival, TDoA) між парами сенсорів.

Розглянемо пару мікрофонів `M₁` та `M₂`, рознесених на відстань `d`. Якщо джерело випромінює звуковий процес `s(t)`, канали реєструють:

```
x₁(t) = s(t) + n₁(t)
x₂(t) = s(t - τ₀) + n₂(t)
```

де `τ₀ = (d · sin(θ)) / c` — шукана затримка приходу між цією парою.

Класична взаємна кореляційна функція (Cross-Correlation) між двома сигналами визначається як інтеграл за часом:

```
R₁₂[τ] = ∫ x₁(t) · x₂(t + τ) dt
```

За теоремою Вінера-Хінчина взаємна кореляція може бути обчислена у частотній області через взаємну спектральну густину потужності (Cross-Power Spectral Density, CPSD):

```
G₁₂[f] = X₁[f] · X₂*[f]
R₁₂[τ] = ∫ G₁₂[f] · e^{j 2π f τ} df
```

де `X_m[f]` — комплексний спектр Фур'є сигналу `x_m(t)`, а `*` позначає комплексне спряження.

У вільному полі без перешкод взаємний спектр дорівнює `G₁₂[f] = G_ss[f] · e^{-j 2π f τ₀}`, де `G_ss[f]` — автоспектральна густина потужності джерела. У результаті зворотного перетворення кореляційна функція `R₁₂[τ] = R_ss[τ - τ₀]` являє собою автокореляцію джерела, зміщену на час `τ₀`.

![Конвеєр GCC-PHAT](/root/sci/ph-waves/mikrofonnyi-masyv/img/gcc-phat-cross-correlation.svg)
*Схема обробки сигналів за алгоритмом GCC-PHAT: амплітудне відбілювання взаємного спектра перетворює розмитий ревербераційний кореляційний відгук на гострий дельта-пік істинної затримки.*

### Чому звичайна кореляція руйнується у приміщеннях

У реальних умовах (кімната, салон автомобіля, міська вулиця) звук багаторазово відбивається від стін і перешкод. Кожен канал містить згортку джерела з імпульсною характеристикою кімнати (Room Impulse Response, RIR) `h_m(t)`:

```
x_m(t) = (h_m ∗ s)(t) + n_m(t)
```

Взаємний спектр набуває вигляду:

```
G₁₂[f] = H₁[f] · H₂*[f] · G_ss[f] + G_noise[f]
```

де `H_m[f]` — передавальна функція акустичного тракту.

Звичайна кореляція зазнає двох фундаментальних спотворень:
1. **Амплітудне розмиття:** Мова має високу концентрацію енергії на низьких частотах (основний тон 100–300 Гц та перші форманти). Автокореляція `R_ss[τ]` має ширину в кілька мілісекунд, що створює плаский і розмитий максимум, де похибка піку досягає десятків градусів.
2. **Хибні ревербераційні піки:** Відбиття від стін інтерферують між собою. Якщо кімнатний резонанс підсилює певне відлуння, вторинний кореляційний пік відбитої хвилі може виявитися вищим за пік прямого звуку, і система зафіксує хибний напрямок на стіну замість диктора.

### Алгоритм GCC-PHAT

Для усунення впливу форми сигналу та резонансів приміщення Кнапп і Картер у 1976 році запропонували ваговий фільтр фазового перетворення (Phase Transform, PHAT):

```
Ψ_PHAT[f] = 1 / |G₁₂[f]|
```

Нормований взаємний спектр зберігає виключно фазову інформацію:

```
G₁₂^PHAT[f]
= G₁₂[f] / |G₁₂[f]|                                                 [нормування на модуль взаємного спектра]
= (|G₁₂[f]| · e^{j θ₁₂[f]}) / |G₁₂[f]|                              [представлення через модуль і фазу]
= e^{j θ₁₂[f]}                                                      [відбілювання амплітудного спектра]
```

Для прямої хвилі з затримкою `τ₀` фазовий кут лінійно залежить від частоти `θ₁₂[f] = -2π f τ₀`. Тоді:

```
G₁₂^PHAT[f] = e^{-j 2π f τ₀}
```

Зворотне перетворення Фур'є дає ідеальну просторово-часову дельта-функцію Дірака:

```
R₁₂^PHAT[τ]
= ∫ e^{-j 2π f τ₀} · e^{j 2π f τ} df                                [зворотне інтегрування за частотою]
= ∫ e^{j 2π f (τ - τ₀)} df                                          [зведення фазових експонент]
= δ[τ - τ₀]                                                         [інтегральне представлення функції Дірака]
```

Оскільки фазові набіги відбитих хвиль розподілені за частотою псевдовипадково, при інтегруванні за широкою смугою частот вони взаємно гасяться у шумовий рівень, тоді як фаза прямого променя складається когерентно, формуючи різкий і стійкий пік у точці `τ = τ₀`.

Строге математичне виведення стійкості до відлуння, регуляризації та параболічної субдискретної інтерполяції наведено у вставці [Математичне виведення GCC-PHAT та відбілювання спектра](root:ph-waves/mikrofonnyi-masyv/math-gcc-phat-derivation.md).

Після оцінки затримки `τ_est` кут приходу сигналу для лінійної пари з відстанню `d` обчислюється тригонометрично:

```
sin(θ_est) = (c · τ_est) / d
θ_est = arcsin((c · τ_est) / d)
```

## Алгоритм формування променя «затримка та додавання» (Delay-and-Sum)

Локалізація напрямку є першим етапом роботи масиву. Другим етапом є просторова селекція: підсилення звуку, що надходить з виявленого кута `θ_target`, та придушення всіх інших просторових шумів.

Найпростішим і найнадійнішим методом просторової фільтрації є алгоритм формування променя «затримка та додавання» (Delay-and-Sum Beamformer, DSB).

![Структурна схема Delay-and-Sum](/root/sci/ph-waves/mikrofonnyi-masyv/img/delay-and-sum-beamformer.svg)
*Структура просторового фільтра Delay-and-Sum: компенсаційні часові затримки вирівнюють фази сигналів з цільового напрямку, забезпечуючи їхнє когерентне підсилення при сумуванні.*

### Принцип компенсації затримок

Якщо хвиля надходить під кутом `θ_target`, сигнал на `m`-му мікрофоні запізнюється на час `τ_m(θ_target) = (m · d · sin(θ_target)) / c`.

Для синхронізації каналів ми штучно вводимо у кожен `m`-й тракт компенсаційну затримку `Δ_m`:

```
Δ_m = -τ_m(θ_target) = -(m · d · sin(θ_target)) / c
```

Вихідний сигнал формувача променя `y(t)` обчислюється як зважена сума затриманих каналів:

```
y(t) = ∑ w_m · x_m(t + Δ_m) = ∑ w_m · x_m(t - τ_m(θ_target))
```

де `w_m` — просторові вагові коефіцієнти (вікно аподизації). За рівномірного зважування `w_m = 1 / M`.

### Коефіцієнт підсилення масиву (Array Gain) та енергетичний баланс

Оцінимо відношення сигнал/шум (Signal-to-Noise Ratio, SNR) на виході формувача променя у порівнянні з одиночним мікрофоном.

Нехай вхідний сигнал мікрофона складається з корисного звуку `s(t)` потужністю `P_s = E{s²(t)}` та просторово некорельованого білого шуму `n_m(t)` з однаковою дисперсією `σ_n² = E{n_m²(t)}`:

```
E{n_i(t) · n_j(t)} = σ_n² · δ_{ij}
```

Вхідне відношення сигнал/шум для одного мікрофона:

```
SNR_in = P_s / σ_n²
```

Після компенсації затримок сигнали від цільового джерела у всіх `M` каналах стають ідентичними й додаються синфазно (когерентно):

```
s_out(t) = (1 / M) · ∑ s(t) = (1 / M) · (M · s(t)) = s(t)
```

Потужність корисного сигналу на виході:

```
P_{s,out} = E{s_out²(t)} = E{s²(t)} = P_s
```

Шуми різних мікрофонів є некорельованими випадковими процесами, тому додаються некогерентно (за потужністю, а не за амплітудою):

```
n_out(t) = (1 / M) · ∑ n_m(t + Δ_m)
```

Дисперсія вихідного шуму:

```
σ_{n,out}²
= E{((1 / M) · ∑ n_m)²}                                              [визначення вихідної дисперсії шуму]
= (1 / M²) · ∑ E{n_m²}                                               [через некорельованість перехресні добутки дорівнюють нулю]
= (1 / M²) · (M · σ_n²)                                              [сума M однакових дисперсій]
= σ_n² / M                                                           [зменшення потужності шуму в M разів]
```

Вихідне відношення сигнал/шум становить:

```
SNR_out = P_{s,out} / σ_{n,out}² = P_s / (σ_n² / M) = M · (P_s / σ_n²) = M · SNR_in
```

Коефіцієнт підсилення масиву (Array Gain, AG) у децибелах дорівнює:

```
AG = 10 · log₁₀(SNR_out / SNR_in) = 10 · log₁₀(M)
```

Кожне подвоєння кількості мікрофонів у масиві збільшує SNR вихідного сигналу на `10 · log₁₀(2) ≈ 3.01 дБ`:
- 2 мікрофони: `+3.0 дБ`
- 4 мікрофони: `+6.0 дБ`
- 8 мікрофонів: `+9.0 дБ`
- 16 мікрофонів: `+12.0 дБ`

### Характеристична функція масиву (Array Factor)

Якщо акустична хвиля надходить з іншого, нецільового напрямку `θ`, компенсаційні затримки `Δ_m` не збігаються з фізичними затримками хвилі `τ_m(θ)`. Залишковий фазовий зсув між сусідніми елементами масиву на частоті `f` становить:

```
ψ = (2π f · d / c) · (sin(θ) - sin(θ_target))
```

Комплексний коефіцієнт передачі масиву як функції напрямку (Array Factor, `AF`) є сумою геометричної прогресії:

```
AF(ψ) = (1 / M) · ∑ e^{j m ψ} = (1 / M) · (sin(M · ψ / 2) / sin(ψ / 2))
```

Потужнісна просторова діаграма спрямованості (Beampattern):

```
B(θ, f) = |AF(ψ)|² = (1 / M²) · (sin²(M · ψ / 2) / sin²(ψ / 2))
```

Функція `B(θ, f)` досягає максимуму `1.0` (або `0 дБ`) при `θ = θ_target` (`ψ = 0`). При відхиленні від цільового напрямку значення швидко падає до першого нуля при `M · ψ / 2 = ±π`, що визначає ширину головної пелюстки просторового променя:

```
sin(θ_null) - sin(θ_target) = ± c / (M · d · f) = ± λ / (M · d) = ± λ / L
```

де `L = M · d` — повна фізична довжина (апертура) масиву.

Чим більша апертура масиву `L` відносно довжини хвилі `λ`, тим вужчим є головний промінь і тим вища просторова роздільна здатність системи.

## Просторовий аліасинг та вибір геометрії масиву

У часовій області теорема відліків Найквіста-Котельникова стверджує, що для однозначного відновлення сигналу частота дискретизації у часі повинна перевищувати подвійну максимальну частоту спектра: `f_s \ge 2 f_{max}`.

Масив мікрофонів здійснює дискретизацію хвильового поля у просторі з кроком просторової сітки `d`. Якщо цей крок є завеликим, виникає ефект просторового накладання спектрів (Spatial Aliasing).

![Просторове накладання спектрів та ґраткові пелюстки](/root/sci/ph-waves/mikrofonnyi-masyv/img/spatial-aliasing-grating-lobes.svg)
*Вплив відстані між мікрофонами d на діаграму спрямованості: перевищення критичного кроку d > λ/2 породжує хибні пелюстки ґратки (grating lobes) з підсиленням 0 dB у небажаних напрямках.*

### Критерій просторової дискретизації

Хвильове число просторової решітки `k_s = 2π / d`. Щоб уникнути періодичного накладання фазових просторових гармонік у видимому кутовому діапазоні `θ \in [-90°, +90°]`, просторовий крок між капсулями повинен задовольняти нерівність:

```
d \le λ / 2 = c / (2 · f_{max})
```

де `λ` — найкоротша довжина хвилі (відповідна найвищій частоті робочого діапазону `f_{max}`).

Якщо крок масиву `d > λ / 2`, у функції спрямованості `B(θ, f)` знаменник `sin(ψ / 2)` перетворюється на нуль не лише в основній точці `ψ = 0`, а й при `ψ = ±2π, ±4π, ...`. У цих кутах виникають так звані ґраткові пелюстки (grating lobes) — хибні бічні промені з коефіцієнтом підсилення `0 дБ`, невідрізнені від головного напрямку.

У такому стані масив стає просторово сліпим: сигнал, що надходить збоку крізь ґраткову пелюстку, сприймається системою як цільовий голос із напрямку `θ_target`.

Для повітряного середовища (`c = 343 м/с`) граничні відстані становлять:
- Для мовного діапазону (`f_{max} = 4000 Гц`, `λ = 8.58 см`): критичний крок `d \le 4.29 см`.
- Для широкосмугового аудіо (`f_{max} = 8000 Гц`, `λ = 4.29 см`): критичний крок `d \le 2.14 см`.
- Для ультразвукової локації (`f_{max} = 40 000 Гц`, `λ = 8.58 мм`): критичний крок `d \le 4.29 мм`.

### Геометрії мікрофонних масивів

Конфігурація розміщення мікрофонів визначає просторові можливості пеленгації та форму діаграми спрямованості.

![Порівняння геометрій мікрофонних масивів](/root/sci/ph-waves/mikrofonnyi-masyv/img/array-geometries-comparison.svg)
*Основні топології акустичних масивів: одновимірні лінійні ULA з конусом неоднозначності, двовимірні кільцеві UCA для кругового азимута та матричні URA для повної 3D пеленгації.*

1. **Лінійний масив (Uniform Linear Array, ULA):**
   - Сенсори розташовані на одній прямій лінії.
   - Має мінімальну кількість мікрофонів для заданої апертури `L = (M - 1) · d`.
   - **Фундаментальне обмеження:** конус невизначеності (Cone of Ambiguity). Лінійний масив симетричний відносно власної осі обертання: затримка `τ` однакова для кутів `θ` та `180° - θ`. Він не може відрізнити джерело спереду від джерела ззаду. Застосовується там, де задня півсфера закрита екраном або корпусом (телевізори, саундбари, ноутбуки).

2. **Кільцевий масив (Uniform Circular Array, UCA):**
   - `M` мікрофонів рівномірно розташовані по колу радіуса `R`.
   - Координати `m`-го сенсора: `x_m = R · cos(2π m / M)`, `y_m = R · sin(2π m / M)`.
   - Забезпечує безперервне кругове сканування площини азимута на всі `360°` без сліпих зон і дзеркальної невизначеності. Ширина головного променя є стабільною незалежно від кута приходу звуку. Ідеальний для розміщення у центрі кімнати (розумні колонки Amazon Echo, конференц-термінали Polycom).

3. **Матричний планарний масив (Uniform Rectangular Array, URA):**
   - Мікрофони розміщені у вузлах прямокутної двовимірної сітки `M_x × M_y`.
   - Дозволяє одночасно оцінювати як горизонтальний азимут `θ`, так і вертикальний кут місця (елевацію) `φ`.
   - Застосовується в акустичних камерах для візуалізації джерел шуму двигунів літаків та автомобілів.

4. **Нерегулярні та спіральні масиви (Aperiodic / Spiral Arrays):**
   - Сенсори розташовуються за логарифмічною або спіральною траєкторією (наприклад, спіраль Архімеда чи золотий переріз).
   - Нерівномірний крок між парами мікрофонів руйнує просторову періодичність решітки: окремі пари мають малий крок (захист від аліасингу на високих частотах), а крайні елементи утворюють велику апертуру (висока роздільність на низьких частотах). Це дозволяє суттєво розширити робочий діапазон масиву.

Повні структури даних, системи координат та таблиці розрахунку параметрів зафіксовано у вставці [Специфікація геометрії та векторів рулювання масивів](root:ph-waves/mikrofonnyi-masyv/api-array-geometry-spec.md).

## Повний алгоритм локалізації та формування променя на практиці

У практичних системах реального часу (DSP, мікроконтролери ARM Cortex-M/A, FPGA) конвеєр обробки звуку працює блоками (кадрами). Типова послідовність операцій:

1. **Кадрування та віконне зважування:** Аудіопотік розбивається на перекривні кадри розміром `N = 1024` відліки з перекриттям 50% (крок 512 відліків). Кожен канал множиться на вікно Ганна.
2. **Частотне перетворення (FFT):** Виконується пряме комплексне БПФ над кожним мікрофонним каналом.
3. **Попарний розрахунок GCC-PHAT:** Для всіх незалежних пар мікрофонів `(i, j)` обчислюється фазово відбілений взаємний спектр `G_{ij}^PHAT[k]` та зворотне БПФ, що формує вектори кореляційних відгуків `R_{ij}^PHAT[m]`.
4. **Просторове сканування (SRP-PHAT):** Для дискретної сітки кутів `θ ∈ [-90°, +90°]` з кроком 1° розраховується сумарна потужність скерованого відгуку (Steered Response Power):

```
SRP(θ) = ∑_{i=0}^{M-1} ∑_{j=i+1}^{M-1} R_{ij}^PHAT[τ_{ij}(θ)]
```

5. **Пошук екстремуму:** Знаходиться кут глобального максимуму `θ_opt = argmax SRP(θ)` з параболічним субдискретним уточненням.
6. **Просторова фільтрація Delay-and-Sum:** Сигнали каналів зміщуються у часі на `Δ_m = -(m · d · sin(θ_opt)) / c` за допомогою дробової лінійної інтерполяції та сумуються, формуючи очищений вихідний потік.

> 🔧 **Навіщо це.**
> У системах голосового керування (розумний будинок, робототехніка, автомобільні мультимедіа) мікрофонний масив з локалізатором джерела дозволяє «зафіксувати акустичний фокус» на особі, що віддає команду. Коли користувач каже «увімкни світло», мікрофонний масив за перші 100 мілісекунд визначає азимут мовця через GCC-PHAT, розвертає в його бік просторовий промінь Delay-and-Sum, придушуючи телевізор або шум вентилятора, і передає очищений сигнал у нейромережу розпізнавання мови (ASR), що підвищує точність розпізнавання з 60% до понад 95%.

Нижче наведено програмну реалізацію базового алгоритмічного конвеєра на C та C++.

```c
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

#define NUM_MICS 4
#define FRAME_LEN 512
#define SOUND_SPEED 343.0f
#define MIC_STEP 0.042f // крок 4.2 см

// Розрахунок різниці затримок між сусідніми мікрофонами для кута theta_deg
static float compute_tdoa_seconds(float theta_deg, float spacing, float c) {
    float rad = theta_deg * (3.14159265f / 180.0f);
    return spacing * sinf(rad) / c;
}

// Застосування фазування Delay-and-Sum над багатоканальним кадровим буфером
void apply_delay_and_sum(const float in[NUM_MICS][FRAME_LEN], float* out,
                         int len, float fs, float steer_deg) {
    float rad = steer_deg * (3.14159265f / 180.0f);

    for (int i = 0; i < len; i++) {
        out[i] = 0.0f;
    }

    for (int m = 0; m < NUM_MICS; m++) {
        float delay_sec = (float)m * MIC_STEP * sinf(rad) / SOUND_SPEED;
        float shift_samples = delay_sec * fs;
        int s_int = (int)floorf(shift_samples);
        float s_frac = shift_samples - (float)s_int;

        for (int i = 0; i < len; i++) {
            int idx = i + s_int;
            float sample = 0.0f;
            if (idx >= 0 && idx + 1 < len) {
                sample = (1.0f - s_frac) * in[m][idx] + s_frac * in[m][idx + 1];
            } else if (idx >= 0 && idx < len) {
                sample = in[m][idx];
            }
            out[i] += sample / (float)NUM_MICS;
        }
    }
}
```

```cpp
#include <vector>
#include <cmath>
#include <numbers>
#include <span>
#include <algorithm>

class DelayAndSumBeamformer {
public:
    DelayAndSumBeamformer(std::size_t numMics, float micSpacingMeters, float soundSpeed = 343.0f)
        : m_numMics(numMics), m_spacing(micSpacingMeters), m_c(soundSpeed) {}

    // Фазування променя для цільового кута в градусах
    [[nodiscard]] std::vector<float> processFrame(const std::vector<std::vector<float>>& multiChannelIn,
                                                  float samplingRate, float steerAngleDeg) const {
        const std::size_t frameLen = multiChannelIn[0].size();
        std::vector<float> output(frameLen, 0.0f);
        const float rad = steerAngleDeg * std::numbers::pi_v<float> / 180.0f;

        for (std::size_t m = 0; m < m_numMics; ++m) {
            const float delaySec = static_cast<float>(m) * m_spacing * std::sin(rad) / m_c;
            const float shiftSamples = delaySec * samplingRate;
            const int sInt = static_cast<int>(std::floor(shiftSamples));
            const float sFrac = shiftSamples - static_cast<float>(sInt);

            for (std::size_t i = 0; i < frameLen; ++i) {
                const int idx = static_cast<int>(i) + sInt;
                float sample = 0.0f;
                if (idx >= 0 && static_cast<std::size_t>(idx + 1) < frameLen) {
                    sample = (1.0f - sFrac) * multiChannelIn[m][idx] + sFrac * multiChannelIn[m][idx + 1];
                } else if (idx >= 0 && static_cast<std::size_t>(idx) < frameLen) {
                    sample = multiChannelIn[m][idx];
                }
                output[i] += sample / static_cast<float>(m_numMics);
            }
        }
        return output;
    }

private:
    std::size_t m_numMics;
    float m_spacing;
    float m_c;
};
```

## Фізичні неідеальності та адаптивні методи

У реальному середовищі ефективність мікрофонних масивів обмежується фізичними неідеальностями компонентів та середовища:

### 1. Фазовий і амплітудний розкид капсулів (Gain & Phase Mismatch)
Навіть якісні цифрові MEMS-мікрофони мають виробничий технологічний розкид чутливості ±1 дБ та фази ±2–5°. Цей розкид порушує точну синфазність при сумуванні каналів, обмежуючи максимальну теоретичну глибину придушення бічних шумів на рівні 25–30 дБ. Для усунення розкиду застосовують попереднє заводське калібрування масиву в безлунній камері за допомогою широкосмугового білого шуму, зберігаючи коригувальні комплексні коефіцієнти у незалежній пам'яті приладу.

### 2. Температурний дрейф швидкості звуку
Швидкість звуку в повітрі суттєво залежить від абсолютної температури газу `T` (у градусах Цельсія):

```
c(T) ≈ 331.3 · √(1 + T / 273.15) ≈ 331.3 + 0.606 · T  (м/с)
```

При зміні температури від 0 °C (`c = 331.3 м/с`) до +30 °C (`c = 349.5 м/с`) швидкість змінюється на 5.5%. Якщо алгоритм розраховує кут за фіксованою константою 343 м/с, систематична похибка пеленгації досягає 2–4 градусів. У прецизійних акустичних системах (наприклад, станціях виявлення БПЛА) обов'язково встановлюють цифровий термометр для динамічного оновлення параметра швидкості звуку в алгоритмі.

### 3. Близьке поле (Near-field effects)
Якщо джерело звуку розташоване на відстані, меншій за межу Фраунгофера `R < 2 D² / λ`, хвильовий фронт є сферичним, а не плоским. Затримки між капсулями перестають бути лінійною функцією синуса кута, а амплітуди на ближніх і дальніх мікрофонах помітно відрізняються через затухання хвилі за законом зворотних квадратів `1 / R²`.

У таких випадках вектор рулювання модифікують, враховуючи сферичну геометрію:

```
Δr_m(x, y, z) = \sqrt{(x - x_m)² + (y - y_m)² + (z - z_m)²} - R_0
```

Це дозволяє одночасно оцінювати як кутовий напрямок на джерело, так і відстань до нього в метрах (фокусування у 3D точці).

### 4. Адаптивні алгоритми (MVDR, LCMV, MUSIC)
Алгоритм Delay-and-Sum є неадаптивним (data-independent): його діаграма спрямованості фіксована для кожного кута. Якщо поруч із корисним диктором з'являється потужне когерентне джерело шуму (наприклад, вентилятор на куті +45°), масив Delay-and-Sum послабить його лише на величину бічної пелюстки (-13...-20 дБ).

Адаптивні формувачі променя (такі як фільтр Капона / MVDR — Minimum Variance Distortionless Response) аналізують просторову коваріаційну матрицю вхідних сигналів `\mathbf{R}_{xx} = E{\vec{x} \vec{x}^H}` і динамічно розраховують ваговий вектор:

```
\vec{w}_{MVDR} = (\mathbf{R}_{xx}^{-1} \cdot \vec{v}(\theta)) / (\vec{v}^H(\theta) \cdot \mathbf{R}_{xx}^{-1} \cdot \vec{v}(\theta))
```

Адаптивний фільтр зберігає одиничний коефіцієнт передачі на корисного диктора і водночас формує глибокий просторовий нуль (провал до -40...-60 дБ) точно в напрямку активного джерела завади.

Для надвисокої кутової роздільності застосовують методи класифікації сигнальних підпросторів, такі як MUSIC (Multiple Signal Classification) та ESPRIT (Estimation of Signal Parameters via Rotational Invariance Techniques). Вони розкладають коваріаційну матрицю на власні вектори, відокремлюючи сигнальний підпростір від шумового, що дозволяє розрізняти два близьких джерела звуку з кутовою відстанню, меншою за дифракційну межу Релея.
