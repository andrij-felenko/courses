# 🧮 Математичне виведення GCC-PHAT та відбілювання спектра

Узагальнена взаємна кореляція з фазовим перетворенням (Generalized Cross-Correlation with Phase Transform, GCC-PHAT) є фундаментальним методом оцінки різниці часу приходу сигналу (Time Difference of Arrival, TDoA) між парою просторово рознесених мікрофонів. У реальних замкнених приміщеннях прямий акустичний сигнал завжди супроводжується численними відбиттями від стін, підлоги й стелі (реверберацією), а також некорельованим навколишнім шумом.

Звичайна взаємна кореляція в таких умовах зазнає сильної дисперсії: енергетичний спектр сигналу спотворює форму кореляційного піка, а відлуння утворюють хибні локальні екстремуми, що перевищують прямий промінь. Метод GCC-PHAT усуває вплив амплітудного спектра та передавальної функції кімнати шляхом повного фазового відбілювання взаємної спектральної густини потужності, зводячи взаємну кореляцію до ідеальної просторово-часової дельта-функції Дірака.

## 1. Акустична модель сигналів у ревербераційному середовищі

Розглянемо акустичне джерело, що випромінює невідомий часовий сигнал `s(t)`. Звукова хвиля поширюється в однорідному повітряному середовищі зі швидкістю `c ≈ 343 м/с` і реєструється двома мікрофонами, розташованими у точках `\vec{r}_1` та `\vec{r}_2`.

Кожен мікрофонний канал сприймає прямий сигнал із відповідною затримкою поширення, суперпозицію відбитих хвиль, зумовлених імпульсною характеристикою приміщення (Room Impulse Response, RIR), а також адитивний шум сенсора й середовища:

```
x₁[t] = (h₁ ∗ s)[t] + n₁[t]
x₂[t] = (h₂ ∗ s)[t] + n₂[t]
```

Тут `∗` позначає операцію часової лінійної згортки, `h_m[t]` — імпульсна перехідна характеристика акустичного каналу від джерела до `m`-го мікрофона, а `n_m[t]` — адитивний стаціонарний шум.

Імпульсну характеристику `h_m[t]` можна розділити на складову прямого променя та нескінченний хвіст запізнілих ревербераційних відбиттів:

```
h₁[t] = α₁ · δ[t - t₁] + ∑ β₁,k · δ[t - t₁,k]
h₂[t] = α₂ · δ[t - t₂] + ∑ β₂,k · δ[t - t₂,k]
```

де `α_m` — коефіцієнт згасання прямого променя, `t_m` — абсолютний час добігання прямої хвилі, `β_{m,k}` та `t_{m,k}` — амплітуди й затримки `k`-го відбиття від поверхонь приміщення.

Шукана різниця часу приходу (TDoA) між прямими променями становить:

```
τ₀ = t₁ - t₂
```

Якщо акустичне поле спростити до умов відкритого простору (без реверберації, `h_m[t] = α_m · δ[t - t_m]`), отримаємо ідеалізовану модель затримки:

```
x₁[t] = s[t] + n₁[t]
x₂[t] = α · s[t - τ₀] + n₂[t]
```

де `α = α₂ / α₁` — відносне масштабне згасання амплітуди, а шуми `n₁[t]` і `n₂[t]` вважаються некорельованими між собою та з корисним сигналом `s[t]`:

```
E{s[t] · n₁[t - τ]} = 0
E{s[t] · n₂[t - τ]} = 0
E{n₁[t] · n₂[t - τ]} = 0
```

## 2. Обмеження класичної взаємної кореляції

Класична взаємна кореляційна функція (Cross-Correlation, CC) між двома дійсними сигналами `x₁[t]` та `x₂[t]` визначається інтегралом:

```
R₁₂[τ] = ∫ x₁[t] · x₂[t + τ] dt
```

За теоремою Вінера-Хінчина взаємна кореляція пов'язана з взаємною спектральною густиною потужності (Cross-Power Spectral Density, CPSD) `G₁₂[f]` через зворотне перетворення Фур'є:

```
G₁₂[f] = X₁[f] · X₂*[f]
R₁₂[τ] = ∫ G₁₂[f] · e^{j 2π f τ} df
```

де `X_m[f] = F{x_m[t]}` — комплексний спектр сигналу `x_m[t]`, а `*` позначає комплексне спряження.

Підставимо у вираз для `G₁₂[f]` спектри сигналів з урахуванням передавальних функцій каналів `H_m[f] = F{h_m[t]}`:

```
X₁[f] = H₁[f] · S[f] + N₁[f]
X₂[f] = H₂[f] · S[f] + N₂[f]
```

Обчислимо математичне сподівання взаємного спектра:

```
G₁₂[f]
= E{X₁[f] · X₂*[f]}                                                [визначення CPSD]
= E{(H₁[f]·S[f] + N₁[f]) · (H₂*[f]·S*[f] + N₂*[f])}                [підстановка моделей сигналів]
= H₁[f]·H₂*[f]·E{|S[f]|²} + H₁[f]·E{S[f]·N₂*[f]} + H₂*[f]·E{N₁[f]·S*[f]} + E{N₁[f]·N₂*[f]}  [розкриття дужок]
= H₁[f]·H₂*[f]·G_ss[f] + 0 + 0 + 0                                [некорельованість шумів і сигналу]
= H₁[f]·H₂*[f]·G_ss[f]                                             [кінцевий взаємний спектр]
```

де `G_ss[f] = E{|S[f]|²}` — автоспектральна густина потужності джерела звуку.

Для вільного поля без відлуння передавальні функції мають вигляд `H₁[f] = e^{-j 2π f t₁}` та `H₂[f] = e^{-j 2π f t₂}`. Тоді взаємний спектр набуває вигляду:

```
G₁₂[f]
= e^{-j 2π f t₁} · e^{+j 2π f t₂} · G_ss[f]                         [підстановка фазових затримок]
= G_ss[f] · e^{-j 2π f (t₁ - t₂)}                                   [групування експонент]
= G_ss[f] · e^{-j 2π f τ₀}                                          [означення затримки τ₀ = t₁ - t₂]
```

Зворотне перетворення Фур'є дає:

```
R₁₂[τ]
= ∫ G_ss[f] · e^{-j 2π f τ₀} · e^{j 2π f τ} df                     [зворотне перетворення Фур'є]
= ∫ G_ss[f] · e^{j 2π f (τ - τ₀)} df                               [групування за експонентою]
= R_ss[τ - τ₀]                                                      [автокореляція джерела зі зсувом]
```

Звідси видно дві фундаментальні проблеми класичної кореляції:
1. **Залежність від форми сигналу джерела:** Функція `R₁₂[τ]` є не гострою дельта-функцією, а автокореляційною функцією `R_ss[τ]` вихідного звуку. Якщо джерелом є людський голос із сильною низькочастотною формантною структурою або вузькосмуговий сигнал, функція `R_ss[τ]` має дуже широкий головний купол із бічними коливаннями. Це робить визначення положення максимуму вкрай неточним.
2. **Вплив реверберації приміщення:** У реальній кімнаті добуток `H₁[f] · H₂*[f]` містить множинні інтерференційні фазові набіги від відбитих хвиль. Зворотне перетворення породжує десятки вторинних піків, амплітуда яких при сильному відлунні може перевищити пік прямого променя `τ₀`.

## 3. Узагальнена взаємна кореляція (GCC) та ваговий фільтр PHAT

Щоб позбутися завад, Кнапп і Картер (Knapp & Carter, 1976) запропонували ввести вагову фільтраційну функцію `Ψ[f]` у частотній області перед виконанням зворотного перетворення Фур'є:

```
R₁₂^GCC[τ] = ∫ Ψ[f] · G₁₂[f] · e^{j 2π f τ} df
```

Існують різні варіанти вагового фільтра `Ψ[f]`:
- **Рот (Roth processor):** `Ψ_Roth[f] = 1 / G₁₁[f]` — мінімізує вплив передавальної характеристики першого каналу;
- **SCOT (Smoothed Coherence Transform):** `Ψ_SCOT[f] = 1 / √(G₁₁[f] · G₂₂[f])` — вирівнює спектри обох каналів;
- **PHAT (Phase Transform):** `Ψ_PHAT[f] = 1 / |G₁₂[f]|` — відбілює весь взаємний амплітудний спектр, залишаючи виключно чисту фазу.

Виведемо математичний вираз для GCC-PHAT. Запишемо комплексний взаємний спектр у тригонометричній або показниковій формі:

```
G₁₂[f] = |G₁₂[f]| · e^{j θ₁₂[f]}
```

де `|G₁₂[f]|` — амплітудний взаємний спектр, а `θ₁₂[f] = arg(G₁₂[f])` — фазовий спектр.

Застосуємо ваговий фільтр `Ψ_PHAT[f] = 1 / |G₁₂[f]|`:

```
G₁₂^PHAT[f]
= Ψ_PHAT[f] · G₁₂[f]                                                [зважування спектра]
= (1 / |G₁₂[f]|) · (|G₁₂[f]| · e^{j θ₁₂[f]})                         [підстановка модуля й фази]
= e^{j θ₁₂[f]}                                                      [скорочення модуля |G₁₂|]
= G₁₂[f] / |G₁₂[f]|                                                 [нормований спектр одиничної амплітуди]
```

Для сигналу у вільному полі `G₁₂[f] = G_ss[f] · e^{-j 2π f τ₀}` модуль дорівнює `|G₁₂[f]| = G_ss[f]`. Підставляючи у вираз PHAT, отримуємо:

```
G₁₂^PHAT[f]
= (G_ss[f] · e^{-j 2π f τ₀}) / G_ss[f]                               [підстановка чистого фазового зсуву]
= e^{-j 2π f τ₀}                                                    [повне скорочення спектральної потужності джерела]
```

Здійснюючи зворотне перетворення Фур'є, знаходимо функцію взаємної кореляції GCC-PHAT:

```
R₁₂^PHAT[τ]
= ∫ e^{-j 2π f τ₀} · e^{j 2π f τ} df                                [інтегрування нормованого спектра]
= ∫ e^{j 2π f (τ - τ₀)} df                                          [зведення експонент]
= δ[τ - τ₀]                                                         [інтегральне представлення дельта-функції Дірака]
```

Результатом є нескінченно гострий імпульс Дірака точно в точці істинної різниці затримки `τ = τ₀`.

## 4. Стійкість до реверберації: механізм розщеплення фази

З'ясуємо, чому фазове відбілювання PHAT настільки стійке до луни в приміщенні. За наявності реверберації імпульсна характеристика записується як прямий промінь плюс суперпозиція луни:

```
H₁[f] = α₁ · e^{-j 2π f t₁} + ∑ β₁,k · e^{-j 2π f t₁,k}
H₂[f] = α₂ · e^{-j 2π f t₂} + ∑ β₂,k · e^{-j 2π f t₂,k}
```

Взаємний спектр `G₁₂[f]` є нелінійною сумішшю синусоїдальних фазових набігів від прямого променя та всіх пар відбиттів. Звичайна кореляція зважує ці компоненти пропорційно амплітуді `|S[f]|² · |H₁[f] · H₂*[f]|`. Оскільки резонанси приміщення (кімнатні моди) на окремих частотах можуть підсилювати відбиті хвилі у 5–10 разів, звичайна кореляція часто обирає затримку відбиття замість прямого звуку.

Фільтр PHAT ділить кожну частотну складову на її сумарну енергію:
1. Резонансні піки кімнати та форманти мови повністю сплющуються до амплітуди `1.0`.
2. Фази відбиттів `t_{1,k} - t_{2,m}` розподілені по інтервалу `[0, 2π)` квазівипадково й некогерентно для різних частот `f`. При інтегруванні за частотою вони інтерферують деструктивно й утворюють рівномірний шумовий п'єдестал низької амплітуди.
3. Фазовий зсув прямого променя `-2π f τ₀` є абсолютно лінійним за частотою `f`. При зворотному інтегруванні всі частотні складові додаються строго когерентно (синфазно), формуючи домінуючий різкий пік.

## 5. Дискретна реалізація та субдискретна інтерполяція

На практиці обробка виконується над дискретними відліками часу з частотою дискретизації `f_s` і кроком `T_s = 1 / f_s`. Кадри довжиною `N` відліків переводяться у спектр через дискретне перетворення Фур'є (ДПФ / FFT):

```
X₁[k] = ∑ x₁[n] · w[n] · e^{-j 2π k n / N},    k = 0, ..., N - 1
X₂[k] = ∑ x₂[n] · w[n] · e^{-j 2π k n / N}
```

де `w[n]` — віконна функція (наприклад, вікно Ганна), що зменшує спектральне просочування.

Дискретний нормований взаємний спектр обчислюється з регуляризацією для уникнення ділення на нуль:

```
G₁₂[k] = X₁[k] · X₂*[k]
G₁₂^PHAT[k] = G₁₂[k] / (|G₁₂[k]| + ε)
```

де `ε > 0` — малий стабілізуючий коефіцієнт (зазвичай `10⁻⁶` від середньої спектральної потужності).

Дискретна взаємна кореляція обчислюється через зворотне ДПФ (IDFT / IFFT):

```
R₁₂^PHAT[m] = (1 / N) · ∑ G₁₂^PHAT[k] · e^{j 2π k m / N},    m = -N/2, ..., N/2 - 1
```

Дискретний індекс максимуму:

```
m_opt = argmax_m { R₁₂^PHAT[m] }
```

### Параболічна субдискретна інтерполяція

Оскільки джерело звуку може перебувати у довільному кутовому положенні, істинна затримка `τ₀` є неперервною величиною і рідко потрапляє точно на цілий відлік сітки `m_opt · T_s`. Для підвищення просторової точності застосовують параболічну апроксимацію піка за трьома сусідніми відліками: `y_{-1} = R[m_opt - 1]`, `y_0 = R[m_opt]`, `y_{+1} = R[m_opt + 1]`.

Апроксимуємо верхівку кореляційної кривої параболою `P(δ) = a·δ² + b·δ + c` відносно точки `m_opt` (`δ ∈ [-0.5, 0.5]`):

```
P(-1) = a - b + c = y_{-1}
P(0)  = c         = y_0
P(+1) = a + b + c = y_{+1}
```

Розв'язуючи систему рівнянь для коефіцієнтів `a` та `b`:

```
c = y_0
b = (y_{+1} - y_{-1}) / 2
a = (y_{+1} - 2·y_0 + y_{-1}) / 2
```

Максимум параболи знаходиться у точці, де похідна дорівнює нулю:

```
dP/dδ = 2a·δ + b = 0
δ_opt = -b / (2a)
```

Підставляючи вирази для `a` та `b`, отримуємо формулу субдискретного зсуву:

```
δ_opt = (y_{-1} - y_{+1}) / (2 · (y_{-1} - 2·y_0 + y_{+1}))
```

Уточнена різниця часу приходу сигналу становить:

```
τ_est = (m_opt + δ_opt) · T_s = (m_opt + δ_opt) / f_s
```

Ця аналітична інтерполяція знижує дисперсію помилки визначення кута пеленга у 3–8 разів без необхідності ресурсомісткої перебудови сітки з підвищеною частотою дискретизації.
