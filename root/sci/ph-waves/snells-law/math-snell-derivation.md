# 🧮 Математичне виведення закону Снелла з принципів Ферма, Гюйгенса та рівнянь Максвелла

Ця математична вставка містить суворе виведення закону заломлення світла з трьох фундаментальних теоретичних узагальнень: варіаційного принципу найменшого часу Ферма (з доведенням існування строгого мінімуму), хвильового принципу Гюйгенса через тангенціальну неперервність фаз та граничних умов класичної електродинаміки Максвелла, а також його застосування до сферичних поверхонь у параксіальній оптиці.

## 1. Детальний варіаційний аналіз за принципом Ферма

Принцип Ферма стверджує: світло поширюється між двома точками `A` і `B` уздовж траєкторії, яка мінімізує оптичну довжину шляху `L` та відповідно повний час проходження `T`.

Розглянемо двовимірну систему координат `(x, y)`. Плоска межа розділу двох однорідних ізотропних середовищ збігається з віссю `x` (`y = 0`).
- Точка випромінювання `A(0, a)` знаходиться у першому середовищі (`y > 0`), де фазова швидкість світла дорівнює `v₁ = c / n₁`.
- Точка спостереження `B(d, -b)` знаходиться у другому середовищі (`y < 0`), де фазова швидкість дорівнює `v₂ = c / n₂`.
- Промінь світла виходить з `A`, перетинає межу розділу в невідомій точці `P(x, 0)` і прямує до `B`.

Геометричні довжини відрізків `AP = s₁` та `PB = s₂` визначаються за теоремою Піфагора:

```
s₁(x) = √(x² + a²)
s₂(x) = √((d - x)² + b²)
```

Повний час руху світла `T(x)` є сумою часу проходження у першому та другому середовищах:

```
T(x) = s₁(x) / v₁ + s₂(x) / v₂
= (1 / v₁) · √(x² + a²) + (1 / v₂) · √((d - x)² + b²)
```

Для пошуку екстремуму знайдемо першу похідну `dT / dx`, застосувавши ланцюгове правило диференціювання складних функцій:

```
d/dx [√(x² + a²)] = (2x) / (2 · √(x² + a²)) = x / √(x² + a²)
d/dx [√((d - x)² + b²)] = (2 · (d - x) · (-1)) / (2 · √((d - x)² + b²)) = - (d - x) / √((d - x)² + b²)
```

Підставивши знайдені похідні у вираз для `dT / dx` і прирівнявши його до нуля (`dT / dx = 0`), отримуємо рівняння стаціонарної точки:

```
dT / dx = (1 / v₁) · (x / √(x² + a²)) - (1 / v₂) · ((d - x) / √((d - x)² + b²)) = 0
```

Проаналізуємо геометричний зміст співвідношень катетів до гіпотенуз у прямокутних трикутниках, утворених променями та нормаллю до межі (вертикальною віссю `y` при `x = const`):
- У трикутнику виходу `ΔAOP`: синус кута падіння `θ₁` (кут між променем `AP` і вертикальною нормаллю `y`) дорівнює протилежному катету `x`, поділеному на гіпотенузу `s₁ = √(x² + a²)`:

```
sin(θ₁) = x / √(x² + a²)
```

- У трикутнику входження `ΔPDB`: синус кута заломлення `θ₂` (кут між променем `PB` і вертикальною нормаллю) дорівнює протилежному катету `(d - x)`, поділеному на гіпотенузу `s₂ = √((d - x)² + b²)`:

```
sin(θ₂) = (d - x) / √((d - x)² + b²)
```

Підставивши значення синусів у рівняння стаціонарності `dT / dx = 0`, маємо:

```
(1 / v₁) · sin(θ₁) - (1 / v₂) · sin(θ₂) = 0     [умова стаціонарності часової функції]

sin(θ₁) / v₁ = sin(θ₂) / v₂                     [перенесення членів]
```

Замінивши фазові швидкості через абсолютні показники заломлення середовищ `v₁ = c / n₁` та `v₂ = c / n₂`, отримуємо класичне формулювання закону Снелла:

```
(n₁ / c) · sin(θ₁) = (n₂ / c) · sin(θ₂)

n₁ · sin(θ₁) = n₂ · sin(θ₂)                    [скорочення сталої c]
```

### Доведення строгого мінімуму часу (друга похідна)

Щоб довести, що знайдена стаціонарна точка відповідає саме найменшому часу (мінімуму), а не максимуму чи перегину, обчислимо другу похідну `d²T / dx²`:

```
d²T / dx² = d/dx [(1 / v₁) · (x / √(x² + a²))] - d/dx [(1 / v₂) · ((d - x) / √((d - x)² + b²))]
```

Диференціюючи дріб `x / √(x² + a²)` за допомогою правила частки `(u/v)' = (u'v - uv') / v²`, маємо:

```
d/dx [x / √(x² + a²)] = (1 · √(x² + a²) - x · (x / √(x² + a²))) / (x² + a²)
= (x² + a² - x²) / (x² + a²)^(3/2)
= a² / (x² + a²)^(3/2) > 0
```

Аналогічно для другого доданка (враховуючи знак мінус та похідну внутрішнього виразу `-1`):

```
d/dx [- (d - x) / √((d - x)² + b²)] = b² / ((d - x)² + b²)^(3/2) > 0
```

Сума двох строго додатних доданків дає результат `d²T / dx² > 0` для будь-яких фізичних значень `x`, `a`, `b`, `v₁`, `v₂`. Це математично суворо доводить, що заломлення світла за законом Снелла відповідає єдиному глобальному мінімуму часу проходження.

## 2. Виведення з хвильового принципу Гюйгенса та тангенціальної неперервності фаз

З точки зору хвильової оптики, плоска електромагнітна хвиля описується виразом для фази `Φ(r, t) = k · r - ω · t`, де `k` — хвильовий вектор, `ω` — кругова частота коливань.

Нехай плоский хвильовий фронт падає на плоску межу розділу `y = 0`. Хвильові вектори у першому та другому середовищах дорівнюють за модулем:

```
|k₁| = (2π · n₁) / λ₀ = (n₁ · ω) / c
|k₂| = (2π · n₂) / λ₀ = (n₂ · ω) / c
```

де `λ₀` — довжина хвилі у вакуумі, `ω` — частота випромінювання.

Розкладемо хвильові вектори на складові паралельно межі розділу (вздовж осі `x`) та перпендикулярно до неї (вздовж осі `y`):

```
k₁_x = |k₁| · sin(θ₁) = ((n₁ · ω) / c) · sin(θ₁)
k₂_x = |k₂| · sin(θ₂) = ((n₂ · ω) / c) · sin(θ₂)
```

Для того, щоб хвильове поле на межі розділу `y = 0` залишалося безперервним у будь-який момент часу `t` і в будь-якій точці `x`, фазовий набіг уздовж межі для падаючої та заломленої хвиль мусить бути строго однаковим. Якщо б `k₁_x ≠ k₂_x`, то при зміні координати `x` виникала б різниця фаз, яка з часом призводила б до руйнівної інтерференції та розриву хвильового фронту.

Отже, умова тангенціального фазового узгодження (гранична умова фази) вимагає:

```
k₁_x = k₂_x                                     [рівність тангенціальних складових]

((n₁ · ω) / c) · sin(θ₁) = ((n₂ · ω) / c) · sin(θ₂)

n₁ · sin(θ₁) = n₂ · sin(θ₂)                    [скорочення multiplier (ω / c)]
```

Цей хвильовий доказ показує, що закон Снелла є фундаментальною умовою збереження фазової безперервності електромагнітного поля на межі розділу двох прозорих середовищ.

## 3. Електродинамічний вивід із граничних умов Максвелла

У класичній електродинаміці поведінка світла описується рівняннями Максвелла. На межі розділу двох діелектриків без вільних зарядів та струмів граничні умови вимагають неперервності тангенціальних (паралельних до поверхні) складових векторів напруженості електричного поля `E` та магнітного поля `H`:

```
E_tan1 = E_tan2
H_tan1 = H_tan2
```

Запишемо падаючу хвилю `E_inc`, відбиту хвилю `E_refl` та заломлену хвилю `E_trans` у комплексній формі:

```
E_inc = E₀_i · exp(i · (k₁ · r - ω · t))
E_refl = E₀_r · exp(i · (k₁_r · r - ω · t))
E_trans = E₀_t · exp(i · (k₂ · r - ω · t))
```

Щоб співвідношення `E_inc_tan + E_refl_tan = E_trans_tan` виконувалося в кожній точці межі `y = 0` для всіх мовних інтервалів `t`, показники експонент мусять бути тотожно рівними у кожній точці `x`:

```
(k₁ · r)|_{y=0} = (k₁_r · r)|_{y=0} = (k₂ · r)|_{y=0}

k₁_x · x = k₁_r_x · x = k₂_x · x
```

Прирівнюючи `k₁_x = k₂_x`, маємо:

```
|k₁| · sin(θ₁) = |k₂| · sin(θ₂)
```

Оскільки модуль хвильового вектора в діелектрику пропорційний показникові заломлення `|k| = n · (ω / c)`, ця гранична умова Maxwell-рівнянь безпосередньо дає скалярний закон Снелла:

```
n₁ · sin(θ₁) = n₂ · sin(θ₂)
```

## 4. Параксіальне наближення для сферичних заломлюючих поверхонь

У практичній оптиці (розрахунок лінз і мікроскопів) заломлюючі поверхні є сферичними з радіусом кривизни `R`. Розглянемо промінь, що падає поблизу оптичної осі під малими кутами падіння `θ₁ << 1` (параксіальне наближення).

Для малих кутів тригонометричний синус замінюють першим членом разкладу Тейлора:

```
sin(θ) ≈ θ
```

Закон Снелла у параксіальному наближенні бере спрощену лінійну форму:

```
n₁ · θ₁ ≈ n₂ · θ₂
```

Нехай предметом є точка `S`, розташована на оптичній осі у першому середовищі на відстані `s` від вершини сферичної поверхні, а зображенням — точка `P` у другому середовищі на відстані `s'`. Розглядаючи прямокутні трикутники та кут `α` між радіусом кривизни `R` та оптичною віссю, підстановка параксіального закону Снелла дає фундаментальну формулу заломлення на сферичній поверхні:

```
n₁ / s + n₂ / s' = (n₂ - n₁) / R
```

Ця формула є математичною основою для виведення тонкої лінзи (формули шліфувальника лінз) та оптичної сили `Ф = (n₂ - n₁) / R`, доводячи, що параксіальний закон Снелла безпосередньо формує оптичні зображення у мікроскопах і телескопах.
