# 📋 Довідник стандартів колірного охоплення та хроматичних параметрів

Цей довідник містить систематизований опис фундаментальних параметрів, числових специфікацій, точних координат хроматичності первинних випромінювачів та функцій оптично-електронного й електронно-оптичного перетворення (OETF/EOTF) для ключових міжнародних стандартів колірного охоплення. Документ призначений для інженерів-оптиків, розробників дисплейних систем, спеціалістів із комп'ютерного зору та цифрової обробки зображень.

Для кожного стандарту наведено не лише підсумкові геометричні характеристики у просторах CIE 1931 та CIE 1976 UCS, а й детальний опис фізичної реалізації на рівні випромінювачів (люмінофори, світлодіоди, квантові точки, лазери), оптичних фільтрів, матриць перетворення та крайових умов застосування.

## 2. Фізичні та технічні специфікації стандартів

### 2.1. Стандарт sRGB / Rec. 709 (IEC 61966-2-1:1999)

Стандарт sRGB залишається еталонним колірним простором для стандартної чіткості, цифрових зображень у мережі Інтернет, систем операційного середовища та більшості офісних моніторів. Специфікація була розроблена в 1996 році спільними зусиллями Hewlett-Packard та Microsoft для узгодження відображення кольорів на ЕПТ-моніторах із люмінофорами P22 під стандартним кімнатним освітленням.

Фізична реалізація sRGB у моніторах традиційно спиралася на сині світлодіоди з білим люмінофором (W-LED на основі YAG:Ce). Спектр випромінювання такого підсвічування має гострий синій пік на довжині хвилі 450 нм та широкий розмитий жовтий горб люмінесценції. Через недостатню узкосмуговість зеленого й червоного світла світлофільтри рідкокристалічних матриць пропускають суміш довжин хвиль, що й обмежує вершини трикутника sRGB.

- **Координати первинних випромінювачів**:
  - `Red`:   `x = 0.6400`, `y = 0.3300`, `z = 0.0300`
  - `Green`: `x = 0.3000`, `y = 0.6000`, `z = 0.1000`
  - `Blue`:  `x = 0.1500`, `y = 0.0600`, `z = 0.7900`
- **Опорне біле джерело**: D65 (`x = 0.3127`, `y = 0.3290`).
- **Матриця пряма (Linear sRGB → XYZ D65)**:
```
[ X ]   [ 0.4124564  0.3575761  0.1804375 ]   [ R ]
[ Y ] = [ 0.2126729  0.7151522  0.0721750 ] · [ G ]
[ Z ]   [ 0.0193339  0.1191920  0.9503041 ]   [ B ]
```
- **Матриця обернена (XYZ D65 → Linear sRGB)**:
```
[ R ]   [  3.2404542 -1.5371385 -0.4985314 ]   [ X ]
[ G ] = [ -0.9692660  1.8760108  0.0415560 ] · [ Y ]
[ B ]   [  0.0556434 -0.2040259  1.0572252 ]   [ Z ]
```

Головне обмеження sRGB полягає в нездатності відтворити глибокі смарагдово-зелені, бірюзові та високонасичені помаранчеві відтінки, які регулярно зустрічаються в естетичній фотографії, природній природі та поліграфічному друку.

### 2.2. Стандарт Adobe RGB (1998)

Компанія Adobe Systems сформулювала специфікацію Adobe RGB у 1998 році з метою охопити максимальну кількість хроматичних відтінків, які здатні відтворювати офсетні друкарські машини колірної моделі CMYK (зокрема європейський стандарт ISO Coated та американський SWOP).

Основна відмінність Adobe RGB від sRGB полягає в значному зсуві зеленого первинного випромінювача в бік більшої насиченості та коротших довжин хвиль (`y = 0.7100` проти `y = 0.6000` в sRGB). Червоний і синій випромінювачі повністю збігаються з sRGB. Завдяки цьому охоплення охоплює близько 52.1% площі CIE 1931, додаючи критично важливі зелено-блакитні відтінки.

Для фізичної підтримки Adobe RGB у рідкокристалічних дисплеях застосовують спеціальні світлодіоди розширеного спектра — GB-r LED (синій і зелений випромінювачі з червоним люмінофором) або спеціальні вузькосмугові флуоресцентні люмінофори (KSF/PFS).

- **Координати первинних випромінювачів**:
  - `Red`:   `x = 0.6400`, `y = 0.3300`
  - `Green`: `x = 0.2100`, `y = 0.7100`
  - `Blue`:  `x = 0.1500`, `y = 0.0600`
- **Опорне біле джерело**: D65 (`x = 0.3127`, `y = 0.3290`).
- **Матриця пряма (Linear Adobe RGB → XYZ D65)**:
```
[ X ]   [ 0.5767309  0.1855540  0.1881852 ]   [ R ]
[ Y ] = [ 0.2973769  0.6273491  0.0752740 ] · [ G ]
[ Z ]   [ 0.0270340  0.0706872  0.9911085 ]   [ B ]
```

### 2.3. Стандарти DCI-P3 та Display P3

Колірне охоплення DCI-P3 було створене консорціумом Digital Cinema Initiatives (об'єднання провідних голлівудських кіностудій) у 2005 році як единий стандарт для цифрових кінопроекторів.

На відміну від sRGB та Adobe RGB, у DCI-P3 суттєво розширено червоний регіон спектра (`x = 0.6800` проти `0.6400`), що дає змогу передавати глибокі насичені червоні, малинові й помаранчеві відтінки кінематографічного рівня. Зелена вершина розташована між sRGB та Adobe RGB (`x = 0.2650, y = 0.6900`).

Існує два різновиди стандарту, які критично важливо розрізняти під час налаштування обладнання:

1. **DCI-P3 Theater (Кінотеатральний)**: використовує ксенонові або лазерні джерела світла з білою точкою `(x = 0.3140, y = 0.3510)` (зеленуватий відтінок температури близько 6300 K) та чистою чистою гамма-кривою `2.6`.
2. **Display P3 (Споживацький / Apple P3)**: збережено ті самі координати первинних кольорів `R, G, B`, але точку білого замінено на стандартне денне світло **D65** `(x = 0.3127, y = 0.3290)`, а передавальну функцію — на нелінійну криву sRGB. Це дає змогу комбінувати стандартний веб-контент із розширеним колірним охопленням на OLED-екранах та IPS-матрицях сучасних смартфонів і ноутбуків.

### 2.4. Стандарт ITU-R BT.2020 (Rec. 2020)

Рекомендація ITU-R BT.2020 є найширшим стандартизованим колірним простором для дисплеїв надвисокої чіткості (4K та 8K Ultra HD TV).

Головна оптична особливість Rec. 2020 полягає в тому, що всі три первинні випромінювачі є **строго монохроматичними випромінюваннями** (чистими спектральними лініями із шириною спектра менше 1 нм). Їхні точки лежать безпосередньо на спектральному локусі підкови CIE 1931:

- **Довжини хвиль та координати первинних кольорів**:
  - `Red`:   `λ = 630.0 нм` -> `x = 0.7080`, `y = 0.2920`
  - `Green`: `λ = 532.0 нм` -> `x = 0.1700`, `y = 0.7970`
  - `Blue`:  `λ = 467.0 нм` -> `x = 0.1310`, `y = 0.0460`
- **Опорне біле джерело**: D65 (`x = 0.3127`, `y = 0.3290`).

Фізичне формування таких кольорів вимагає використання трьохколірних полупровідникових лазерів (RGB Laser) або випромінювачів на базі квантових точок високої чистоти (Quantum Dot QD-OLED / QLED). Жодна традиційна світлодіодна чи люмінесцентна технологія з кольоровими фільтрами не здана сформувати хроматичності такого рівня насиченості. Охоплення Rec. 2020 становить **75.8%** від усієї площі хроматичної діаграми CIE 1931 та охоплює **99.9%** усіх реальних матеріальних кольорів природи.

- **Матриця пряма (Linear Rec. 2020 → XYZ D65)**:
```
[ X ]   [ 0.6369580  0.1446169  0.1688809 ]   [ R ]
[ Y ] = [ 0.2627002  0.6779981  0.0593017 ] · [ G ]
[ Z ]   [ 0.0000000  0.0280727  1.0609851 ]   [ B ]
```

### 2.5. Масив Поінтера (Pointer's Gamut, 1980)

Складений майклом Поінтером (Michael R. Pointer) у 1980 році на основі систематичних вимірювань 4083 зразків нелюмінесцентних поверхонь: реальних фарб, фабричних барвників, рослинних пігментів, тканин, мінералів та шкіри людини.

На відміну від трикутних просторів дисплеїв, Pointer's Gamut є нерегулярним об'ємним тілом. Його площа на площині хроматичностей становить близько **48.2%** від локусу CIE 1931. Він слугує фундаментальним критерієм для оцінки повноти колірного охоплення:
- Дисплеї `sRGB` відтворюють лише **69.4%** реальних поверхонь Поінтера (втрачаючи глибокі зелені та насичені червоно-коричневі відтінки).
- Дисплеї `Adobe RGB` відтворюють **86.2%**.
- Дисплеї `DCI-P3` відтворюють **85.5%**.
- Дисплеї `Rec. 2020` відтворюють **99.9%** матеріалів Поінтера.

## 4. Передавальні функції (OETF / EOTF / Gamma Curves)

Передавальні функції описують нелінійний зв'язок між нормованими цифровими кодами кольору `N ∈ [0, 1]` та фізичною лінійною інтенсивністю випромінювання екрана `L ∈ [0, 1]`.

### 4.1. Гамма-функція sRGB (IEC 61966-2-1)

Для запобігання появі східчастих градієнтів у темних тонах через обмежену 8-бітну дискретизацію, sRGB застосовує гібридну передавальну функцію з лінійним сегментом біля нуля та степеневою залежністю в решті діапазону.

Кодування (OETF — Opto-Electronic Transfer Function):
```
If C[linear] ≤ 0.0031308:
    C[srgb] = 12.92 · C[linear]
Else:
    C[srgb] = 1.055 · (C[linear] ^ (1 / 2.4)) - 0.055
```

Декодування на дисплеї (EOTF — Electro-Optical Transfer Function):
```
If C[srgb] ≤ 0.04045:
    C[linear] = C[srgb] / 12.92
Else:
    C[linear] = ((C[srgb] + 0.055) / 1.055) ^ 2.4
```

Усереднена ефектна гамма sRGB математично близька до ступеня `γ = 2.2`.

### 4.2. Функція розширеного динамічного діапазону PQ ST 2084 (HDR10)

Передавальна функція Perceptual Quantizer (PQ), стандартизована SMPTE ST 2084, розроблена на основі зорового порогу розрізнення яскравості Бартона (Barten's model). Вона дає змогу кодувати абсолютний діапазон яскравості від `0.0001 кд/м²` до `10 000 кд/м²` у 10-бітному чи 12-бітному представленні без бандингу.

Константи специфікації:
- `m₁ = 2610 / 16384 = 0.1593017578125`
- `m₂ = 2523 / 32 = 78.84375`
- `c₁ = 3424 / 4096 = 0.8359375`
- `c₂ = 2413 / 128 = 18.8515625`
- `c₃ = 2392 / 128 = 18.6875`

Математична формула обчислення декодованої відносної яскравості `Y ∈ [0, 1]` (`Y = L / 10000 кд/м²`) із цифрового коду `N ∈ [0, 1]`:

```
Y = ( max( N^(1/m₂) - c₁, 0 ) / ( c₂ - c₃ · N^(1/m₂) ) ) ^ (1/m₁)
```

## 5. Формули перетворення в рівноконтрастний простір CIE 1976 UCS (u', v')

Діаграма CIE 1931 `(x, y)` має високу геометричну нерівномірність: однакова еліптична похибка зорового розрізнення кольору (еліпси МакАдама) в зеленій зоні набагато більша за площею, ніж у синій чи червоній.

Для підвищення ізотропності у 1976 році CIE затвердила рівноконтрастну хроматичну площину `(u', v')`. Перетворення з координат `(x, y)` виконується за дробово-лінійними формулами:

```
u' = 4 · x / ( -2·x + 12·y + 3 )
v' = 9 · y / ( -2·x + 12·y + 3 )
```

Зворотний перехід з `(u', v')` у `(x, y)`:

```
x = 9 · u' / ( 6·u' - 16·v' + 12 )
y = 4 · v' / ( 6·u' - 16·v' + 12 )
```

У просторі `(u', v')` геометрія колірного охоплення є більш адекватною зоровому сприйняттю людини, тому сучасні специфікації дисплеїв (включаючи оцінку покриття Rec. 2020 та DCI-P3) обчислюють саме у координатах CIE 1976 UCS.
