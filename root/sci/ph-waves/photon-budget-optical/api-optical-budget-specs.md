# 📋 Довідник оптичних коефіцієнтів, квантової ефективності та специфікацій

При розрахунку фотонного бюджету оптичних систем інженеру необхідні точні довідкові дані про фізичні характеристики середовищ поширення, оптичних матеріалів, світлофільтрів та фотодетекторов. Навіть найточніший алгоритм видасть похибку, якщо вхідний коефіцієнт згасання або квантова ефективність виявиться взятою наумання.

У цьому довіднику зібрано фундаментальні фізичні константи, оптичні коефіцієнти прозорості середовищ, френелівські характеристики матеріалів, специфікації сучасних типів фотоприймачів та типові оптичні втрати компонентів для проведення системних розрахунків.

## 1. Фундаментальні фізичні константи

Фундаментальні константи фізики встановлюють строгі квантові та електродинамічні межі для оптичних систем. Стала Планка `h` пов'язує частоту електромагнітного випромінювання `ν` із дискретною енергією світлового кванта `E = h · ν = h · c / λ`. Це рівняння визначає, скільки фотонів міститься в одному джоулі світлової енергії.

Заряд електрона `e` є базовим множником для конверсії між фотонним потоком та електричним струмом у напівпровідникових фотодетекторах. Кожен згенерований фотоелектрон переносить заряд `e`, що дає змогу виражати коефіцієнт струмової чутливості фотодіода через квантову ефективність `S(λ) = (η_QE · e) / (h · ν)`.

Стала Больцмана `k_B` у поєднанні з абсолютною температурою `T` регулює середньоквадратичну дисперсію теплового шуму Джонсона — Найквіста в опорі навантаження `R_L`. Зведена стала Планка `ħ = h / (2π)` та хвильовий опір вакууму `Z_0 = √(μ_0 / ε_0) ≈ 376.73 Ом` задають межі взаємодії квантованого випромінювання з речовиною та площину розповсюдження плоских електромагнітних хвиль.

| Константа | Позначення | Точне значення | Одиниці вимірювання | Опис |
|---|---|---|---|---|
| Стала Планка | `h` | `6.62607015 · 10⁻³⁴` | Дж·с (J·s) | Квант дії |
| Зведена стала Планка | `ħ` | `1.054571817 · 10⁻³⁴` | Дж·с (J·s) | `h / (2π)` |
| Швидкість світла у вакуумі | `c` | `299 792 458` | м/с (m/s) | Точне значення за SI |
| Елементарний електричний заряд | `e` | `1.602176634 · 10⁻¹⁹` | Кл (C) | Заряд електрона |
| Стала Больцмана | `k_B` | `1.380649 · 10⁻²³` | Дж/К (J/K) | Термодинамічна константа |
| Диелектрична стала вакууму | `ε_0` | `8.8541878128 · 10⁻¹²` | Ф/м (F/m) | Електрична стала |
| Магнітна стала вакууму | `μ_0` | `1.25663706212 · 10⁻⁶` | Гн/м (H/m) | `4π · 10⁻⁷` |
| Хвильовий опір вакууму | `Z_0` | `376.730313668` | Ом (Ω) | `√(μ_0 / ε_0)` |

## 2. Спектифікація оптичних випромінювачів (Лазери та LED)

Параметри випромінювача визначають початкову оптичну потужність `P_tx` та спектральну ширину лінії `Δλ`. Вузькосмугові лазери DFB (Distributed Feedback) забезпечують монохроматичне випромінювання з шириною лінії `< 0.01 нм`, що мінімізує дисперсійні втрати, тоді як світлодіоди LED мають спектральну ширину `30–50 нм`, обмежуючи смугу зв'язку.

| Тип випромінювача | Довжина хвилі λ (нм) | Ширина спектра Δλ | Відносна інтенсивність шуму (RIN) | Оптична потужність P_tx |
|---|---|---|---|---|
| Світлодіод (LED) | 850 / 1310 | 30 – 50 нм | -120 дБ/Гц | 0.1 – 1.0 мВт (-10 ... 0 дБм) |
| Лазер з поверхневим випромінюванням (VCSEL) | 850 | 0.5 – 1.0 нм | -130 дБ/Гц | 1.0 – 5.0 мВт (0 ... +7 дБм) |
| Лазер Фабрі — Перо (FP-Laser) | 1310 / 1550 | 2.0 – 4.0 нм | -135 дБ/Гц | 5.0 – 20.0 мВт (+7 ... +13 дБм) |
| Лазер із розподіленим зворотним зв'язком (DFB) | 1310 / 1550 | < 0.01 нм | -155 дБ/Гц | 10.0 – 100.0 мВт (+10 ... +20 дБм) |
| Волоконний лазер із підсилювачем (EDFA Master) | 1550 | < 0.001 нм | -160 дБ/Гц | 0.5 – 5.0 Вт (+27 ... +37 дБм) |

## 3. Спектральні вікна прозорості та згасання в середовищах

Згасання оптичного випромінювання у волокнах та атмосфері залежить від довжини хвилі. Оптичне згасання є комбінацією трьох фундаментальних процесів: Релеївського розсіяння на флуктуаціях густини (пропорційного `1 / λ⁴`), молекулярного поглинання носіями зарядів чи коливаннями решітки та Мі-розсіяння на мікрокраплях аерозолів.

У волоконній оптиці на основі кварцового скла (Silica Glass) фундаментальний мінімум втрат спостерігається в C-діапазоні (`1530–1565 нм`), де згасання становить лише `0.18–0.20 дБ/км`. На коротших довжинах хвиль (O-band, 1310 нм) згасання зростає до `0.35 дБ/км` через Релеївське розсіяння, однак саме там хроматична дисперсія стандартного волокна G.652 обертається в нуль. Прибічна смуга E-band містить так званий «водяний пік» поглинання іонів гідроксилу `OH⁻` на довжині хвилі `1383 нм`, який у сучасних волокнах Low Water Peak (LWP) вдалося знизити до `0.28 дБ/км`.

### Фізичні класифікації волокон стандарту ITU-T

- **ITU-T G.652.D**: Стандартне одномодове волокно (SMF) без водяного піка (Zero Water Peak). Оптимальне для спектрального ущільнення CWDM та DWDM.
- **ITU-T G.655**: Волокно зі зміщеною ненульовою дисперсією (NZDSF), призначене для мінімізації чотирихвильового змішування (FWM) в оптичних підсилювачах EDFA.
- **ITU-T G.657.A2/B3**: Волокно, стійке до вигинів (Bending Loss Insensitive). Забезпечує збереження фотонного бюджету при малих радіусах вигину (до 7.5 мм) у кабельних мережах FTTH.

При поширенні світла у відкритій атмосфері (каналі FSO) основними джерелами загасання виступають середовищні аерозолі, серпанок, туман та атмосферні опади. У разі прозорого повітря згасання не перевищує `0.5 дБ/км`, проте при виникненні туману розмір мікрокрапель води стає порівнянним із довжиною хвилі світла, викликаючи нищівне розсіяння Мі з втратами понад `70–80 дБ/км`.

## 4. Оптичні матеріали та френелівські характеристики

При переході світла з повітря (`n_1 ≈ 1.0`) у скляне або напівпровідникове оптичне середовище з показником заломлення `n_2` виникає відбиття Френеля. Дисперсія показника заломлення обчислюється за рівнянням Сельмейєра `n²(λ) = 1 + ∑ (B_i · λ²) / (λ² - C_i)`.

Для звичайного скла N-BK7 або кварцу Fused Silica відбиття від однієї поверхні становить `3.3–4.0%` (втрата ~0.15 дБ на межу). Проте для високоефективних напівпровідникових оптичних матеріалів інфрачервоного діапазону — кремнію (Si) та германію (Ge) — показник заломлення сягає `3.48–4.04`, що призводить до катастрофічного френелівського відбиття в `30–36%` від кожної незахищеної поверхні (втрата понад `3.1–3.9 дБ` на елемент!).

| Матеріал | Показник заломлення n (на 633 нм) | Показник заломлення n (на 1550 нм) | Френелівське відбиття R (на межі з повітрям, 1550 нм) | Втрати на незахищеній лінзі (2 межі) |
|---|---|---|---|---|
| Кварцове скло (Fused Silica) | 1.457 | 1.444 | 3.30% | 0.29 дБ (6.49%) |
| Оптичне скло N-BK7 | 1.517 | 1.501 | 4.01% | 0.36 дБ (7.86%) |
| Сапфір (Al₂O₃, звичайний промінь) | 1.766 | 1.746 | 7.37% | 0.68 дБ (14.2%) |
| Цирконій кубічний (ZrO₂) | 2.158 | 2.132 | 13.04% | 1.27 дБ (24.4%) |
| Кремній (Silicon, Si) | 3.882 | 3.476 | 30.63% | 3.18 дБ (51.9%) |
| Германій (Germanium, Ge) | 4.003 | 4.035 | 36.29% | 3.92 дБ (59.4%) |

Для усунення паразитних френелівських втрат на поверхні оптики наносять тонкошарові інтерференційні просвітлювальні покриття (Anti-Reflective, AR):

1. **Одношарове MgF₂ покриття**: Товщиною `d = λ / (4·n_film)` зменшує відбиття скла N-BK7 до `1.2%`.
2. **Багатошарове просвітлення BBAR**: Завдяки чергуванню шарів з високим (TiO₂) та низьким (SiO₂) показником заломлення забезпечує `R < 0.25%` у широкому діапазоні довжин хвиль.
3. **Вузькосмугове покриття V-coating**: Настроєне на одну лазерну лінію, знижує відбиття до `R < 0.10%` (втрати менше 0.004 дБ на межу).

### Матричний формалізм четвертьхвильових покриттів

Інтерференція у багатошарових плівках розраховується через характеристичні матриці оптичних шарів. Для кожного шару з товщиною `d_k` та набігом фази `δ_k = (2π / λ) · n_k · d_k · cos(θ_k)` характеристична матриця має вигляд:

```
M_k = [ cos(δ_k)          (i / η_k) · sin(δ_k) ]
      [ i · η_k · sin(δ_k)  cos(δ_k)           ]
```

де `η_k = n_k · cos(θ_k)` для s-поляризації та `η_k = n_k / cos(θ_k)` для p-поляризації. Добуток матрицій каскаду `M_total = ∏ M_k` визначає амплітудні коефіцієнти відбиття `r` та пропускання `t`, що дає змогу точно проектувати спектральні профілі фільтрів.

Для комутації та регулювання фотонних потоків у волоконних мережах та лабораторних стендах застосовують дільники потужності, атенюатори та ізолятори.

### Керовані оптичні атенюатори (Variable Optical Attenuators, VOA)

Керовані атенюатори VOA використовують для дозованого послаблення фотонного потоку при проведення калібрувальних тестувань. За принципом дії поділяються на:
- **MEMS VOA**: Використовують мікроелектромеханічні дзеркала для зміщення променя. Діапазон ослаблення `0–40 дБ`, точність `0.1 дБ`, швидкість перемикання `< 2 мс`.
- **Рідкокристалічні LC VOA**: Керовані полярним електричним полем рідкі кристали змінюють кут поляризації. Забезпечують плавність регулювання без рухомих механічних частин.

### Невзаємні оптичні елементи (Ізолятори та Циркулятори)

- **Оптичний ізолятор (Optical Isolator)**: Застосовує ефект Фарадея для пропускання світла лише в одному напрямку. Захищає лазерні діоди від зворотного відбиття. Внесені втрати в прямому напрямку `< 0.4 дБ`, згасання у зворотному напрямку `> 42 дБ`.
- **Оптичний циркулятор (Optical Circulator)**: 3-портовий або 4-портовий прилад, що перенаправляє світло з порту 1 у порт 2, а з порту 2 — у порт 3. Внесені втрати між суміжними портами `< 0.6 дБ`, ізоляція непрохідних портів `> 50 дБ`.

## 6. Специфікації оптичних підсилювачів (EDFA та SOA)

У багатоклометрових волоконно-оптичних лініях зв'язку для компенсації згасання застосовують оптичні підсилювачі. Вони підвищують потужність сигналу без конверсії у електричний струм, однак додають шум спонтанного випромінювання (ASE, Amplified Spontaneous Emission).

| Параметр специфікації | Оптичний підсилювач EDFA | Напівпровідниковий підсилювач (SOA) | Раманівський підсилювач (Raman) |
|---|---|---|---|
| **Спектральний діапазон** | C-band (1530 – 1565 нм), L-band | 1280 – 1620 нм (будь-який) | Визначається довжиною хвилі накачки |
| **Коефіцієнт підсилення (Gain G)** | 20 – 40 дБ | 15 – 30 дБ | 10 – 20 дБ |
| **Насичена вихідна потужність** | +17 ... +23 дБм | +10 ... +15 дБм | +25 ... +30 дБм |
| **Коефіцієнт шуму (Noise Figure F_n)** | 4.5 – 6.0 дБ | 7.0 – 9.0 дБ | 0 ... -2 дБ (розподілений) |
| **Міжсимвольне спотворення** | Відсутнє (довгий час життя тау ≈ 10мс) | Наявне при високих швидкостях | Відсутнє |

## 7. Специфікації світлофільтрів, дзеркал та з'єднувачів

Оптичний тракт приймача включає інтерференційні дзеркала, спектральні фільтри та волоконні роз'єми, кожен з яких додає свій коефіцієнт згасання в загальну суму фотонного бюджету.

У високочутливих оптичних системах ключову роль відіграють узгоджувальні з'єднувачі. Волоконні коннектори з плоским поліруванням (FC/PC або LC/PC) утворюють повітряний проміжок між торцями волокон, створюючи паразитне зворотне відбиття (*Optical Return Loss*, `RL ≈ 40 дБ`). Для усунення цього ефекту в високошвидкісних системах застосовують коннектори з косим кутовим поліруванням торця 8° (FC/APC чи SC/APC), що спрямовує відбитий промінь у оболонку волокна й піднімає зворотне загасання до `RL > 60 дБ`.

| Оптичний елемент | Коефіцієнт пропускання T / відбиття R | Внесений коефіцієнт згасання (дБ) | Опис та застосування |
|---|---|---|---|
| Диелектричне лазерне дзеркало (HR) | `R > 99.9%` | 0.004 дБ | Високовідбивальне покриття для лазерних резонаторів |
| Захисне вікно з BBAR-просвітленням | `T > 99.5%` | 0.022 дБ | Вхідні апертури оптичних приладів |
| Поляризаційний дільник променя (PBS) | `T_p > 97%, R_s > 99%` | 0.13 дБ (p-поляризація) | Розділення p- та s-поляризованих компонентів |
| Інтерференційний bandpass-фільтр (FWHM 10нм) | `T_peak = 85 – 92%` | 0.36 – 0.70 дБ | Відсікання сонячного фонового випромінювання |

## 8. Порівняльні специфікації фотоприймачів

Вибір фотодетектора є ключовим інженерним рішенням, яке визначає еквівалентну шумову потужність (NEP), квантову ефективність `η_QE` та внутрішній коефіцієнт підсилення `M` оптичного приймача.

1. **PIN-фотодіоди**: Прості напівпровідникові структури без внутрішнього підсилення (`M = 1`). Відрізняються високою квантовою ефективністю (`> 85%`) та низьким темновим струмом (`< 2 нА`), однак чутливість обмежена тепловим шумом зовнішнього підсилювача TIA.
2. **Лавинні фотодіоди (APD)**: Завдяки високій зворотній напрузі зсуву електрони прискорюються у зоні високого поля й викликають ударну іонізацію, створюючи внутрішнє підсилення `M = 10–100`. Процес ударної іонізації є флуктуючим, що вносить фактор надлишкового шуму `F(M) = M·k + (1-k)·(2 - 1/M)`.
3. **Однофотонні лавинні діоди (SPAD)**: Працюють у режимі Ґейґера понаднормового пробою (`V_bias > V_breakdown`). Одиночний фотон викликає лавинний пробій струму до міліамперів (`M > 10⁵`), забезпечуючи підрахунок окремих фотонів із часовою точністю до `35 пс`.
4. **Фотоелектронні помножувачі (PMT)**: Вакуумні прилади, в яких фотоелектрон вибивається з фотокатода й підсилюється на каскаді динодів (`M = 10⁶`). Мають ультранизький темновий шум, але низьку квантову ефективність у ІЧ-діапазоні (`< 15%`).
5. **Суперпровідникові нанодротові детектори (SNSPD)**: Працюють при кріогенних температурах `0.8–2.8 K`. Одиночний фотон руйнує суперпровідний стан у тонкій нанодротині, створюючи локальний резистивний хотспот. Характеризуються найвищою квантовою ефективністю (`> 95%`), рекордно низьким темновим відліком (`< 1 cps`) та часовим джитером `< 10 пс`.

| Параметр специфікації | PIN-фотодіод (InGaAs) | Лавинний фотодіод (APD InGaAs) | SPAD (Si/InGaAs) | ФОУ (PMT Zworykin) | SNSPD (Напівпровідник-суперпровідник) |
|---|---|---|---|---|---|
| **Спектральний діапазон (нм)** | 900 – 1700 | 950 – 1650 | 400 – 1700 | 185 – 900 | 300 – 5000 |
| **Квантова ефективність η_QE** | 80 – 92% | 75 – 85% | 50 – 80% | 20 – 40% | 80 – 98% |
| **Коефіцієнт підсилення M** | 1 (без підсилення) | 10 – 100 | 10⁵ – 10⁶ (режим Ґейґера) | 10⁶ – 10⁷ | 10⁶ (квантовий перехід) |
| **Темновий струм / Темновий відлік** | 0.5 – 5 нА | 5 – 50 нА | 100 – 10 000 cps | 10 – 500 cps | 0.1 – 10 cps |
| **Фактор надлишкового шуму F(M)** | 1.0 | 2.5 – 4.5 (при M=20) | Незастосовне (дискретний) | 1.1 – 1.3 | 1.0 (відсутній) |

### Фізична декомпозиція коефіцієнта шуму (Noise Equivalent Power, NEP)

Потужність, еквівалентна шуму (`NEP`), визначає мінімальну оптичну потужність сигналу, за якої відношення сигнал/шум у смузі `1 Гц` дорівнює одиниці. Обчислюється за формулою:

```
NEP = (i_noise_density) / S(λ) = √(2 · e · I_dark + (4 · k_B · T / R_L)) / S(λ)
```

де `i_noise_density` — спектральна густина шуму струму (А/√Гц), а `S(λ)` — спектральна чутливість детектора (А/Вт).

## 9. Формули та таблиці переведення одиниць вимірювання потужності

У фотоніці та оптичному зв'язку потужність виражають у лінійних ватах (Вт) або логарифмічних децибел-міліватах (дБм).

Логарифмічна шкала зручна тим, що каскадне перемноження коефіцієнтів пропускання елементів `T_1 · T_2 · ... · T_n` замінюється простою арифметичною сумою втрат у децибелах `∑ L_dB,i`. Відношення між лінійною потужністю `P(Вт)` та логарифмічною `P(дБм)` описується рівняннями:

```
P(дБм) = 10 · lg( P(Вт) / 10⁻³ Вт ) = 10 · lg( P(мВт) )
P(Вт)  = 10⁻³ · 10^( P(дБм) / 10 )
```

## 10. Температурні коефіцієнти дрейфу та стабілізація

Оптичні параметри зазнають температурного дрейфу під впливом змін навколишнього середовища:

1. **Температурне зміщення довжини хвилі лазера**: Для напівпровідникових лазерних діодів DFB довжина хвилі зміщується зі швидкістю `dλ/dT ≈ +0.1 нм/°C` через зміну показника заломлення та розширення резонатора. Для стабілізації довжини хвилі застосовують термоелектричні модулі Пельтьє (TEC).
2. **Температурна деградація темнового струму**: Темновий струм PIN та APD фотодіодів подвоюється на кожні 8–10 °C зростання температури: `I_dark(T) = I_dark(20°C) · 2^((T - 20)/9)`.
3. **Термооптичний коефіцієнт лінз (`dn/dT`)**: Показник заломлення оптичного скла змінюється на `dn/dT ≈ (1 ... 3) · 10⁻⁶ K⁻¹`, що при суворих температурних перепадах зміщує фокусну площину приймальної апертури.

## 11. Закон збереження етендю (Etendue Conservation)

При розрахунку збору фотонів від розширених джерел світла або випромінювання ландшафту критичним параметром є геометричний фактор — етендю (*Etendue* `G`). Етендю визначається як добуток площі пучка `A` на тілесний кут охоплення `Ω`:

```
G = n² · ∫∫ cos(θ) dA dΩ = const
```

Згідно з інваріантом Лагранжа — Гельмгольца, етендю оптичної системи не може бути зменшена жодною лінзовою оптикою без втрати частини фотонів. Якщо етендю випромінювача перевищує етендю приймального волокна чи фотодетектора (`G_source > G_rx`), частка втрачених фотонів обчислюється як відношення `η_etendue = G_rx / G_source`.

## 13. Практична методичка розрахунку втрат для розробника

При проведенні підсумкового аудиту фотонного бюджету інженер підсумовує всі джерела загасання в децибелах за таблицею елементів:

```
Total_Loss_dB = L_geom + L_medium + ∑ L_optic_element + L_connector + L_aging
```

1. **L_geom (Геометричні втрати)**: Обчислюється як `10 · lg(A_spot / A_rx)`. Для волокна дорівнює 0 дБ при стиковці один-в-один.
2. **L_medium (Втрати середовища)**: Обчислюється як `α · z_km`. Для 10 км волокна C-band це `0.2 · 10 = 2.0 дБ`.
3. **∑ L_optic_element (Каскад оптики)**: Сума втрат усіх лінз, фільтрів, дзеркал. Для системи з 2 лінзами (AR) та 1 фільтром: `0.04 + 0.04 + 0.70 = 0.78 дБ`.
4. **L_connector (Втрати з'єднувачів)**: Додається `0.25 – 0.5 дБ` на кожен оптичний роз'єм.
5. **L_aging (Запас на старіння)**: Обов'язкова технологічна надбавка `1.5 – 3.0 дБ` для забезпечення надійності приладу протягом усього терміну служби.

## 14. Підсумкові інженерні правила зведення оптичного балансу

Для досягнення високої надійності оптичного каналу при використанні даних цього довідника слід дотримуватися чотирьох основних інженерних правил:

- **Правило 1 (Нормалізація довжин хвиль)**: Усі параметри пропускання `T(λ)` та чутливості `S(λ)` повинні берутися строго для робочої довжини хвилі випромінювача `λ_0`.
- **Правило 2 (Спектральний допуск)**: Смуга пропускання фільтра `FWHM` повинна бути у 2–3 рази ширшою за спектр лазера, щоб компенсувати температурний дрейф `dλ/dT`.
- **Правило 3 (Урахування найгіршого випадку)**: Розрахунок фотонного бюджету проводиться для максимальної робочої температури детектора (найвищий `I_dark`) та мінімальної оптичної потужності передавача `P_tx,min`.
- **Правило 4 (Контроль запасу)**: Вирахований `Link Margin` для надійних промислових систем повинен становити не менше `+3.0 дБ` для волоконних ліній та не менше `+6.0 дБ` для атмосферних ліній зв'язку.

Цей довідник надає повний спектр чисельних даних для точного системного розрахунку фотонного бюджету оптичних ліній різного призначення.
