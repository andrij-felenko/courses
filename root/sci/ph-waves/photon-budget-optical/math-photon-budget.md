# 🧮 Математичний апарат розрахунку фотонного бюджету та відношення сигнал/шум

Обчислення оптичного або фотонного бюджету вимагає переходу від неперервних фотометричних величин (потужності у ватах чи світлового потоку в люменах) до дискретного підрахунку квантів електромагнітного поля та їхньої статистики. Коли оптичний сигнал слабшає через згасання в середовищі чи розбіжність променя, фундаментальним обмеженням чутливості системи стає не просто поглинання світла, а флуктуації кількості зареєстрованих фотонів на тлі внутрішніх шумів детектора.

У цій вставці виведено повний математичний апарат розрахунку фотонного бюджету: від первинного потоку емісії квантів джерелом до підсумкового значення відношення сигнал/шум (SNR), коефіцієнта помилок (BER) та лінійного запасу каналу (Link Margin).

## 1. Конверсія оптичної потужності у фотонний потік

Світлове випромінювання на монохроматичній довжині хвилі `λ` складається з квантів, кожен з яких несе енергію `E_p`:

```
E_p = h · c / λ
```

де `h ≈ 6.626 · 10⁻³⁴ Дж·с` — стала Планка, `c ≈ 2.998 · 10⁸ м/с` — швидкість світла у вакуумі.

Якщо оптичне джерело випромінює безперервну потужність `P` (у ватах, Дж/с), то число випромінених фотонів за одну секунду (фотонний потік `Ф_p`, фотонів/с) обчислюється так:

```
Ф_p = P / E_p
Ф_p = P / (h · c / λ)
Ф_p = (P · λ) / (h · c)       [підстановка E_p = h · c / λ]
```

Для імпульсного джерела з енергією імпульсу `E_pulse` (Дж) та тривалістю імпульсу `τ` (с) середня потужність в імпульсі дорівнює `P_pulse = E_pulse / τ`. Кількість фотонів в одному імпульсі `N_p,tx` становить:

```
N_p,tx = E_pulse / E_p = (E_pulse · λ) / (h · c)
```

**Числовий приклад:** Для лазерного імпульсу з довжиною хвилі `λ = 1550 нм` (стандарт волоконного зв'язку DWDM) та енергією `E_pulse = 1 нДж` (`10⁻⁹ Дж`):

```
E_p = (6.626 · 10⁻³⁴ · 2.998 · 10⁸) / (1550 · 10⁻⁹)
E_p ≈ 1.282 · 10⁻¹⁹ Дж

N_p,tx = 10⁻⁹ / (1.282 · 10⁻¹⁹)
N_p,tx ≈ 7.80 · 10⁹ фотонів/імпульс
```

## 2. Коефіцієнти відбиття Френеля на оптичних межах

При проходженні світла крізь кожну незахищену межу двох прозорих середовищ із показниками заломлення `n₁` та `n₂` виникає френелівське відбиття. Для нормального падіння (кут падіння `θ = 0°`) коефіцієнт відбиття за потужністю `R` дорівнює:

```
R = ((n₁ - n₂) / (n₁ + n₂))²
```

Коефіцієнт пропускання межі `T_fresnel` становить:

```
T_fresnel = 1 - R = (4 · n₁ · n₂) / (n₁ + n₂)²
```

Якщо світло падає під довільним кутом `θ₁`, коефіцієнти відбиття розділяються для перпендикулярної (`s`) та паралельної (`p`) поляризацій (за законами Френеля):

```
sin θ₂ = (n₁ / n₂) · sin θ₁                         [закон Снелла]

R_s = |(n₁ · cos θ₁ - n₂ · cos θ₂) / (n₁ · cos θ₁ + n₂ · cos θ₂)|²
R_p = |(n₂ · cos θ₁ - n₁ · cos θ₂) / (n₂ · cos θ₁ + n₁ · cos θ₂)|²
```

Для неполяризованого світла усереднений коефіцієнт відбиття дорівнює `R_avg = (R_s + R_p) / 2`.

**Числовий приклад:** На незахищеній межі скло-повітря (`n₁ = 1.50`, `n₂ = 1.00`) при нормальному падінні:

```
R = ((1.50 - 1.00) / (1.50 + 1.00))² = (0.50 / 2.50)² = 0.20² = 0.04  (4.0%)
T_fresnel = 1 - 0.04 = 0.96  (96.0%)
```

Кожна лінза з двома незахищеними поверхнями пропускає лише `T_lens = 0.96 · 0.96 = 0.9216` (втрата 7.84% фотонів). Нанесення просвітлювального покриття (AR, *Anti-Reflective*) зменшує `R` до менш ніж `0.2%` на поверхню.

## 3. Об'ємне згасання в середовищі та розсіяння

Згасання інтенсивності випромінювання при проходженні скрізь однорідне поглинаюче та розсіювальне середовище завдовжки `z` описується законом Бугера — Ламберта — Бера:

```
P(z) = P(0) · e^(-α · z)
```

де `α` — повний коефіцієнт екстинкції (м⁻¹), який є сумою коефіцієнта поглинання `α_abs` та коефіцієнта розсіяння `α_scatt`:

```
α = α_abs + α_scatt
```

У волоконній оптиці та радіозв'язку коефіцієнт загасання зазвичай виражають у децибелах на кілометр (`A_dB`, дБ/км). Зв'язок між `A_dB` та натуральним коефіцієнтом `α` (м⁻¹) задається співвідношенням:

```
A_dB = (10 / ln 10) · (α · 1000) ≈ 4342.9 · α
α = (A_dB / 4342.9)
```

Частка фотонів `T_channel`, що пройшли відстань `z` (км):

```
T_channel = 10^(-(A_dB · z) / 10)
```

У чистих оптичних матеріалах (наприклад, кварцовому склі `SiO₂`) фундаментальним порогом прозорості в короткохвильовій області є **Релеївське розсіяння**, викликане замороженими мікроскопічними флуктуаціями щільності скла. Його коефіцієнт розсіяння залежить від довжини хвилі у четвертому ступені:

```
α_Rayleigh(λ) = k_R / λ⁴
```

Саме ця залежність пояснює, чому для далеких ліній волоконного зв'язку обрано спектральне вікно `λ = 1550 нм`: тут Релеївське розсіяння становить лише `~0.15 дБ/км`, тоді як на `λ = 850 нм` воно досягає `~2.5 дБ/км`.

## 4. Геометричні та апертурні втрати (Etendue)

При поширенні світла у вільному просторі (FSO, лідари, астрономія) промінь джерела розходиться. Нехай кут розбіжності променя становить `θ_div` (радіан). На відстані `z` радіус світлової плями `w(z)` дорівнює:

```
w(z) = w_0 + z · tan(θ_div)
```

де `w_0` — початковий радіус пучка на виході з передавача. Площа світлової плями становить `A_spot = π · w(z)²`.

Якщо приймальна лінза має вхідний апертурний радіус `r_rx` та площу `A_rx = π · r_rx²`, то при рівномірному розподілі інтенсивності геометричний коефіцієнт збору фотонів `η_geom` становить:

```
η_geom = min(1.0, A_rx / A_spot) = min(1.0, r_rx² / w(z)²)
```

У суворому оптичному аналізі зберігається інваріант **етендю** (геометричний фактор `G`, *Etendue*, від французького *étendue* — «простір, протяжність»):

```
G = A · Ω = const
```

де `A` — площа джерела/зіниці, `Ω` — тілесний кут випромінювання. Жодна ідеальна оптична система без розсіювальних елементів не може зменшити етендю пучка: спроба зфокусувати світло з широким кутом у малу пляму вимагає пропорційного збільшення апертурного кута прийому.

## 5. Перетворення фотонів у фотоелектрони та квантова ефективність

Фотодетектор перетворює зареєстровані фотони на фотоелектрони завдяки внутрішньому або зовнішньому фотоефекту. Основна характеристика детектора — **квантова ефективність** `η_QE` (*Quantum Efficiency*, `0 ≤ η_QE ≤ 1`), яка визначає ймовірність того, що один падаючий фотон створить один первинний електронно-дірковий пара носій заряду:

```
η_QE(λ) = N_e,primary / N_p,arrived
```

Альтернативним показником є **спектральна чутливість** детектора `R_resp` (Ампер/Ватт, А/Вт):

```
R_resp = (e · λ · η_QE) / (h · c) = (η_QE · λ [мкм]) / 1.2398
```

де `e ≈ 1.602 · 10⁻¹⁹ Кл` — заряд електрона.

Якщо детектор має внутрішнє лавинне підсилення `M` (наприклад, у лавинному фотодіоді APD, де `M ≈ 10..100`, або в ФЕП, де `M ≈ 10⁶`), то сумарне число носіїв на виході становить `N_e,total = M · η_QE · N_p,arrived`.

У лавинних фотодіодах сама процедура ударної іонізації є випадковим процесом, що вносить надлишковий шум (*excess noise*). Дисперсія підсиленого фотоструму збільшується у `F(M)` разів, де `F(M)` — **надлишковий шумовий фактор Макинтайра** (*McIntyre excess noise factor*):

```
F(M) = k_eff · M + (1 - k_eff) · (2 - 1/M)
```

де `k_eff` — відношення коефіцієнтів іонізації дірок та електронів (`k_eff ≈ 0.02..0.05` для кремнію, `k_eff ≈ 0.35..0.50` для InGaAs). Через надлишковий шум існує оптимальне значення коефіцієнта підсилення `M_opt`, вище якого зростання шуму лавини перевищує користь від приглушення теплового шуму підсилювача.

## 6. Джерела шумів та пуассонівська статистика

Число фотонів `N_p`, які прибувають на детектор за фіксований інтервал часу `Δt`, описується дискретним **пуассонівським розподілом** ймовірностей:

```
P(k) = (μ^k · e^(-μ)) / k!
```

де `μ = ⟨N_p⟩` — середнє число фотонів.

Головна властивість пуассонівського розподілу полягає в тому, що його дисперсія `σ²` строго дорівнює середньому значенню `μ`:

```
σ_shot,p² = ⟨N_p⟩
σ_shot,p = √(⟨N_p⟩)
```

Це визначає фундаментальний **дробовий шум фотонів** (*photon shot noise*). Після фотоелектричного перетворення дисперсія фотоелектронів дорівнює `σ_shot,e² = N_e = η_QE · N_p`.

Окрім дробового шуму корисного сигналу, у детекторі та електронному тракті виникають додаткові незалежні джерела шумів:

1. **Дробовий шум фонового випромінювання** (`N_bg` фонових фотонів від сонця, засвітки або паразитного розсіяння):
   `σ_bg² = η_QE · N_bg`

2. **Темновий струм детектора** (`I_dark`, А): генерує темнові електрони за час `Δt`:
   `N_dark = (I_dark · Δt) / e`
   `σ_dark² = N_dark`

3. **Тепловий шум Джонсона — Найквіста** в опірному навантаженні приймача `R_L` при абсолютній температуре `T` (К) у смузі частот `B` (Гц):
   Середній квадрат шумового струму: `i_thermal² = (4 · k_B · T · B) / R_L`
   де `k_B ≈ 1.381 · 10⁻²³ Дж/К` — стала Больцмана.
   Еквівалентна дисперсія теплових електронів за час `Δt = 1 / (2·B)`:
   `σ_thermal² = (4 · k_B · T · B · Δt²) / (e² · R_L)`

4. **Шум зчитування** підсилювача (`σ_read`, виражається в електронах середньоквадратичного шуму, `e⁻ RMS`).

Оскільки всі зазначені джерела шумів є статистично незалежними, їхні дисперсії додаються:

```
σ_total² = F(M) · (σ_shot,e² + σ_bg² + σ_dark²) + σ_thermal² + σ_read²
σ_total = √( F(M) · (η_QE · N_p + η_QE · N_bg + N_dark) + σ_thermal² + σ_read² )
```

## 7. Рівняння відношення сигнал/шум (SNR) та коефіцієнт помилок (BER)

Відношення сигнал/шум (*Signal-to-Noise Ratio*, SNR) за числом електронів задається співвідношенням амплітуди корисного сигналу до середньоквадратичного відхилення сумарного шуму:

```
SNR = N_e / σ_total
SNR = (η_QE · N_p) / √( F(M) · (η_QE · N_p + η_QE · N_bg + N_dark) + σ_thermal² + σ_read² )
```

У децибельному вираженні для амплітуди струму/числа фотонів:

```
SNR_dB = 10 · lg(SNR²) = 20 · lg(SNR)
```

Для цифрових систем зв'язку з двійковою маніпуляцією (OOK, *On-Off Keying*) коефіцієнт бітових помилок (*Bit Error Rate*, BER) обчислюється через фактор якості `Q`:

```
Q = (I_1 - I_0) / (σ_1 + σ_0)
```

де `I_1` та `I_0` — середні струми для логічної «1» та «0», а `σ_1`, `σ_0` — їхні відповідні середньоквадратичні шуми. За гауссівського наближення шумів:

```
BER = 0.5 · erfc(Q / √2)
```

Щоб досягти стандартного рівня помилок `BER = 10⁻⁹`, необхідно забезпечити `Q ≈ 6.0` (що відповідає `SNR_dB ≈ 15.6 дБ`).

### Квантова межа (Quantum Limit)
У ідеальній оптичній системі, де фонове освітлення відсутнє (`N_bg = 0`), темновий струм знехтувно малий (`N_dark → 0`), підсилення `M = 1` (`F = 1`), а електронні шуми відсутні (`σ_thermal = 0`, `σ_read = 0`), рівняння SNR спрощується до квантової межі:

```
SNR_quantum = N_e / √(N_e) = √(N_e) = √(η_QE · N_p)
```

Для виявлення імпульсного двопозиційного сигналу (OOK) з імовірністю помилки `BER = 10⁻⁹` в ідеальному квантовому режимі потрібно отримати в середньому лише **9.6 фотонів на логічну одиницю** (так звана квантова межа зв'язку).

## 8. Розрахунок децибельного балансу (Link Margin)

У практичній оптичній інженерії повний фотонний бюджет зручно обчислювати в децибелах відносно 1 мілівата (дБм, dBm):

```
P [дБм] = 10 · lg(P [мВт] / 1 мВт)
```

Повний баланс оптичної лінії описується лінійним алгебраїчним рівнянням:

```
P_rx [дБм] = P_tx [дБм] - L_trans [дБ] - L_channel [дБ] - L_geom [дБ] - L_rx [дБ]
```

де:
- `P_tx` — оптична потужність випромінювання джерела;
- `L_trans` — втрати у передавальній оптиці (введення в коліматор, френелівські межі);
- `L_channel = A_dB · z` — втрати в каналі поширення (волокно або атмосфера);
- `L_geom = -10 · lg(η_geom)` — геометричні втрати через расходимость променя;
- `L_rx` — втрати у приймальній оптиці (фільтри, лінзи, дільники);
- `P_rx` — підсумкова потужність, що досягає фотодетектора.

**Запас оптичної лінії (Link Margin, `M`):** різниця між отриманою потужністю `P_rx` та мінімально необхідною чутливістю приймача `P_req` для забезпечення заданої якості зв'язку (наприклад, `BER = 10⁻⁹` або `SNR ≥ 20 дБ`):

```
M [дБ] = P_rx [дБм] - P_req [дБм]
```

Якщо `M > 0 дБ`, оптичний канал є працездатним і має запас на деградацію компонентів та сезонні флуктуації середовища. Позитивний запас `M ≥ 3..6 дБ` вважається обов'язковим стандартом проектування надійних оптичних систем.

## 9. Рівняння лідарного фотонного бюджету (LiDAR Range Equation)

У лазерному локаторі (лідарі) оптичний сигнал долає шлях до цілі на відстань `R` і повертається назад після відбиття. Для дифузного (ламбертівського) об'єкта з коефіцієнтом відбиття `ρ_target` число повернених фотонів `N_p,rx` обчислюється за специфічним лідарним рівнянням:

```
N_p,rx = N_p,tx · (A_rx / (π · R²)) · ρ_target · η_opt · e^(-2 · α · R)
```

де:
- `N_p,tx` — число випромінених лазерних фотонів в імпульсі;
- `A_rx / (π · R²)` — геометричний тілесний кут перехоплення відбитого світла приймачем;
- `ρ_target` — альбедо (коефіцієнт дифузного відбиття) поверхні цілі;
- `η_opt` — сумарний коефіцієнт пропускання передавальної та приймальної оптики;
- `e^(-2 · α · R)` — дворезистивне згасання в атмосфері (туди й назад).

На відміну від прямих ліній зв'язку, де згасання поширення пропорційне `1/R²`, у лідарі для дифузних цілей число фотонів падає за законом **`1/R²` для площі плями та додатково `1/R²` для приймального кута**, що дає сумарне квадратне згасання від відстані `1/R²` при фіксованому куті або `1/R⁴` для точкових світлоповертачів. Це робить фотонний бюджет лідарів надзвичайно критичним на великих відстанях, вимагаючи застосування імпульсних лазерів гігаватної пікової потужності або фотодетекторів у режимі підрахунку поодиноких квантів (SPAD).

## 10. Бюджет фотонів у флуоресцентній мікроскопії

У флуоресцентній мікроскопії високої роздільної здатності (наприклад, STED, PALM/STORM чи двофотонній мікроскопії) розрахунок фотонного бюджету визначає граничну точність локалізації флуорофора та тривалість спостереження до настання **фотовигоряння** (*photobleaching*).

Молекула флуорофора, поглинувши збуджувальний фотон з довжиною хвилі `λ_ex`, переходить у збуджений стан `S₁` і з ймовірністю `Φ_fluo` (квантовий вихід флуоресценції, *quantum yield*) випромінює фотон флуоресценції на більшій довжині хвилі `λ_em` (зміщення Стокса).

Кількість зареєстрованих фотонів від однієї флуоресцентної мітки `N_em` становить:

```
N_em = N_ex · σ_abs · Φ_fluo · η_coll · T_filter · η_QE
```

де:
- `N_ex` — потік фотонів збуджувального лазерного пучка (фотонів/см²);
- `σ_abs` — переріз поглинання флуорофора (см²);
- `Φ_fluo` — квантовий вихід флуоресценції (зазвичай `0.2..0.9`);
- `η_coll = 0.5 · (1 - cos θ_max)` — геометрична ефективність збору світла мікрооб'єктивом із числовою апертурою `NA = n · sin θ_max`;
- `T_filter` — пропускання дихроїчного дзеркала та бар'єрного bandpass-фільтра.

Для високоапертурного масляного об'єктива (`NA = 1.4`, `n = 1.518`):

```
sin θ_max = 1.4 / 1.518 ≈ 0.9223 ⇒ θ_max ≈ 67.26°
cos θ_max ≈ 0.3865
η_coll = 0.5 · (1 - 0.3865) ≈ 0.3068  (30.68% від повного тілесного кута 4π)
```

Оскільки кожна молекула флуорофора витримує лише обмежену кількість циклів збудження до того, як незворотно руйнується внаслідок фотохімічного вигоряння (зазвичай `10⁴..10⁶` фотонів за час життя), суворий розрахунок фотонного бюджету єдиним чином визначає, скільки кадрів знімків можна отримати з одного біологічного зразка.

## 11. Матричний формалізм каскаду N оптичних елементів

При проектуванні складних оптичних приладів (мікроскопів, спектрометрів, космічних телескопів) оптичний тракт містить послідовність із `N` окремих елементів. Кожен `i`-й елемент характеризується своїм коефіцієнтом пропускання `T_i` (або втратами `L_i [дБ] = -10 · lg(T_i)`).

Повний коефіцієнт пропускання каскаду `T_cascade` обчислюється як добуток індивідуальних коефіцієнтів:

```
T_cascade = ∏ (T_i)       [для i від 1 до N]
```

У логарифмічній децибельній формі сумарні втрати оптичного каскаду `L_cascade [дБ]` дорівнюють простій сумі втрат кожного елемента:

```
L_cascade [дБ] = ∑ L_i [дБ]       [для i від 1 до N]
```

Якщо в каскаді присутні спектрально залежні елементи з кривими пропускання `T_i(λ)`, підсумкова ефективність становить:

```
T_cascade(λ) = ∏ T_i(λ)
```

Для світлового джерела зі спектральною густиною потужності `S(λ)` підсумковий фотонний потік, що досягає фотодетектора, обчислюється шляхом інтегрування спектра по всьому робочому діапазону довжин хвиль:

```
Ф_p,rx = ∫ (S(λ) · λ / (h · c)) · ∏ T_i(λ) dλ
```

Цей матрично-інтегральний формалізм дає змогу врахувати спектральне перекриття між джерелом випромінювання, смугою пропускання оптичних фільтрів та кривою квантової ефективності фотодетектора, забезпечуючи максимальну точність інженерних обчислень.

## 12. Покроковий приклад повного фотонного розрахунку каналу FSO

Розглянемо систему атмосферного оптичного зв'язку (FSO, *Free-Space Optics*) на відстані `z = 2.0 км`.

**Вихідні параметри:**
- Довжина хвилі: `λ = 1550 нм` (`E_p = 1.282 · 10⁻¹⁹ Дж`)
- Потужність лазера: `P_tx = 50 мВт` (`+17.0 дБм`)
- Передавальна оптика: 2 незахищені поверхні скло-повітря (`L_trans = 0.36 дБ`, `T_trans = 92.0%`)
- Розбіжність променя: `θ_div = 1.5 мрад` (радіус плями на 2 км: `w(z) ≈ 2000 · 0.0015 = 3.0 м`)
- Приймальна апертура: діаметр `D_rx = 100 мм` (`r_rx = 0.05 м`)
- Атмосферна прозорість (слабкий серпанок): `A_dB = 2.5 дБ/км` (на 2 км: `L_channel = 5.0 дБ`)
- Приймальний вузол: інтерференційний bandpass-фільтр `T_filter = 80%` (`L_rx = 0.97 дБ`)
- Фотодетектор: InGaAs PIN-діод, `η_QE = 85%`, `I_dark = 2 нА`, струм теплового шуму підсилювача `i_thermal = 1.5 пА/√Гц` у смузі `B = 125 МГц`.

**Покроковий обчислювальний тракт:**

```
1. Площа світлової плями на 2 км:
   A_spot = π · (3.0)² ≈ 28.27 м²

2. Площа приймальної лінзи:
   A_rx = π · (0.05)² ≈ 0.007854 м²

3. Геометричний коефіцієнт збору (η_geom):
   η_geom = A_rx / A_spot = 0.007854 / 28.27 ≈ 2.778 · 10⁻⁴
   L_geom = -10 · lg(2.778 · 10⁻⁴) ≈ +35.56 дБ

4. Сумарні втрати оптичної лінії (L_tot):
   L_tot = L_trans + L_channel + L_geom + L_rx
   L_tot = 0.36 + 5.0 + 35.56 + 0.97 = 41.89 дБ

5. Приймана оптична потужність на фотодіоді (P_rx):
   P_rx [дБм] = P_tx [дБм] - L_tot = +17.0 - 41.89 = -24.89 дБм
   P_rx = 10^(-24.89 / 10) мВт = 10^(-2.489) мВт ≈ 0.00324 мВт = 3.24 мкВт

6. Прийманий фотонний потік (Ф_p,rx):
   Ф_p,rx = P_rx / E_p = (3.24 · 10⁻⁶ Вт) / (1.282 · 10⁻¹⁹ Дж)
   Ф_p,rx ≈ 2.527 · 10¹³ фотонів/с

7. Число фотонів за один бітовий інтервал (Δt = 1 / (2·B) = 4 нс):
   N_p,bit = Ф_p,rx · Δt = 2.527 · 10¹³ · 4 · 10⁻⁹
   N_p,bit ≈ 101,080 фотонів/біт

8. Число генерувальних фотоелектронів (N_e):
   N_e = η_QE · N_p,bit = 0.85 · 101,080 ≈ 85,918 e⁻/біт

9. Шумовий розрахунок за один бітовий інтервал (Δt = 4 нс):
   σ_shot = √(N_e) = √(85,918) ≈ 293.1 e⁻
   N_dark = (I_dark · Δt) / e = (2 · 10⁻⁹ · 4 · 10⁻⁹) / (1.602 · 10⁻¹⁹) ≈ 50 e⁻
   σ_dark = √(N_dark) ≈ 7.07 e⁻
   i_thermal_total = i_thermal · √B = 1.5 · 10⁻¹² · √(125 · 10⁶) ≈ 16.77 нА
   σ_thermal = (i_thermal_total · Δt) / e = (16.77 · 10⁻⁹ · 4 · 10⁻⁹) / (1.602 · 10⁻¹⁹) ≈ 418.7 e⁻

10. Сумарний шум (σ_total):
    σ_total = √(σ_shot² + σ_dark² + σ_thermal²)
    σ_total = √(293.1² + 7.07² + 418.7²) = √(85,907 + 50 + 175,310)
    σ_total = √(261,267) ≈ 511.1 e⁻

11. Підсумкове відношення сигнал/шум (SNR):
    SNR = N_e / σ_total = 85,918 / 511.1 ≈ 168.1
    SNR_dB = 20 · lg(168.1) ≈ 44.51 дБ
```

Отримане значення `SNR = 44.51 дБ` значно перевищує поріг для `BER = 10⁻⁹` (`15.6 дБ`), що забезпечує лінійний запас каналу `M = 44.51 - 15.6 = +28.91 дБ`. Це гарантує надійну роботу лінії навіть під час виникнення густого туману, який додасть до 20 дБ додаткового згасання. Таким чином, розрахований фотонний бюджет дозволяє інженеру завчасно переконатися у працездатності оптичного тракту в найгірших експлуатаційних умовах.
