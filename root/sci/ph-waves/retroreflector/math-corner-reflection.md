# 🧮 Математична геометрія кутового відбивача та матриці відбиття

Ця математична вставка містить векторне та матричне виведення закону розвертання світлового променя у двовимірному та тривимірному кутових ретрорефлекторах, а також математичний аналіз кутових похибок відбитого пучка при неточності виготовлення прямого кута між гранями.

## 1. Векторна формула відбиття від довільної площини

Розглянемо геометричне поширення оптичного променя в тривимірному евклідовому просторі `ℝ³`. Нехай плоске дзеркало задається площиною, до якої побудовано одиничний вектор нормалі `n` (`|n| = 1`), спрямований убік напівпростору, з якого падає світловий промінь.

Падаючий світловий промінь визначається одиничним вектором напрямку `v_in` (`|v_in| = 1`). У будь-якій декартовій системі координат вектор `v_in` можна ортогонально розкласти на дві взаємно перпендикулярні складові: перпендикулярну до поверхні дзеркала (уздовж нормалі `n`) та паралельну поверхні дзеркала (у площині дзеркала):

```
v_perp = (v_in · n) · n      [перпендикулярна проєкція на нормаль n]
v_para = v_in - v_perp        [паралельна складова у площині дзеркала]
```

Згідно з класичним законом дзеркального відбиття, кут падіння дорівнює куту відбиття, а падаючий промінь, відбитий промінь і нормаль лежать у одній площині. У векторній формі це означає, що паралельна складова `v_para` зберігає свій напрямок та величину без змін, тоді як перпендикулярна складова `v_perp` змінює свій знак на протилежний:

```
v_out 
= v_para - v_perp                           [закон відбиття: інверсія нормальної складової]
= (v_in - (v_in · n) · n) - (v_in · n) · n   [підстановка складових v_para та v_perp]
= v_in - 2 · (v_in · n) · n                 [зведення подібних доданків]
```

Ця фундаментальна векторна формула описує дію дзеркала на напрямок променя.

Операцію відбиття можна записати в матричній формі за допомогою лінійного оператора Гаусгольдера. Нехай `I` — одинична матриця розміру `N × N`, а `n` — вектор-стовпець нормалі. Тоді матриця відбиття `R` має вигляд:

```
R = I - 2 · n · nᵀ                          [означення матриці відбиття]
```

Перевіримо дію матриці `R` на вектор `v_in`:

```
R · v_in 
= (I - 2 · n · nᵀ) · v_in                   [підстановка матриці R]
= I · v_in - 2 · n · (nᵀ · v_in)            [дистрибутивність множення матриці на вектор]
= v_in - 2 · (v_in · n) · n                 [тотожність I·v = v та скалярний добуток nᵀ·v]
```

Матриця відбиття `R` має три важливі алгебраїчні властивості:
1. Вона є ортогональною: `Rᵀ = R⁻¹`, що означає збереження довжини вектора (`|R · v| = |v|`) та кутів між векторами.
2. Вона є симетричною: `Rᵀ = R`, отже `R² = R · R = I` (повторне відбиття від того самого дзеркала повертає початковий вектор).
3. Її детермінант дорівнює `det(R) = -1`. Це свідчить про те, що дзеркальне відбиття змінює орієнтацію базису (перетворює праву трійку векторів на ліву).

## 2. Двовимірний кутовий відбивач (2D Corner Reflector)

Розглянемо двовимірну систему з двох перпендикулярних дзеркал у площині `xy`.

Нехай перше дзеркало лежить вздовж осі `y` (нормаль `n₁ = (1, 0)ᵀ`), а друге дзеркало лежить вздовж осі `x` (нормаль `n₂ = (0, 1)ᵀ`).

Побудуємо матриці відбиття для обох дзеркал:

```
R₁ 
= I - 2 · n₁ · n₁ᵀ                          [формула матриці відбиття для n₁]
= [ 1  0 ] - 2 · [ 1 ] · [ 1  0 ]           [підстановка одиничної нормалі n₁ = (1,0)ᵀ]
  [ 0  1 ]       [ 0 ]
= [ 1  0 ] - [ 2  0 ]                       [зовнішній векторний добуток n₁ · n₁ᵀ]
  [ 0  1 ]   [ 0  0 ]
= [ -1   0 ]                                [віднімання матриць]
  [  0   1 ]

R₂ 
= I - 2 · n₂ · n₂ᵀ                          [формула матриці відбиття для n₂]
= [ 1  0 ] - 2 · [ 0 ] · [ 0  1 ]           [підстановка одиничної нормалі n₂ = (0,1)ᵀ]
  [ 0  1 ]       [ 1 ]
= [ 1  0 ] - [ 0  0 ]                       [зовнішній векторний добуток n₂ · n₂ᵀ]
  [ 0  1 ]   [ 0  2 ]
= [  1   0 ]                                [віднімання матриць]
  [  0  -1 ]
```

Послідовна дія обох дзеркал на довільний вхідний вектор `v_in = (v_x, v_y)ᵀ` дає підсумкову матрицю відбиття `R_{2D}`:

```
R_{2D} 
= R₂ · R₁                                  [добуток матриць послідовних відбиттів]
= [  1   0 ] · [ -1   0 ]                   [підстановка матриць R₁ та R₂]
  [  0  -1 ]   [  0   1 ]
= [ -1   0 ]                                [скалярне множення елементів діагоналі]
  [  0  -1 ]
= -I₂                                       [інверсійна одинична матриця]
```

Підсумковий вектор напрямку `v_out`:

```
v_out 
= R_{2D} · v_in                             [дія підсумкової 2D матриці]
= -I₂ · (v_x, v_y)ᵀ                         [підстановка R_{2D} = -I₂]
= (-v_x, -v_y)ᵀ                             [множення вектора на -1]
= -v_in                                     [інверсія початкового вектора напрямку]
```

Висновок: Сукупна дія двох подвійних відбиттів від перпендикулярних дзеркал інвертує обидві компоненти вектора напрямку. Напрямок променя повертається на кут `180°` незалежно від початкового кута падіння в площині `xy`.

Звернемо увагу на детермінант підсумкової матриці: `det(R_{2D}) = det(R₂) · det(R₁) = (-1) · (-1) = +1`. Це означає, що два відбиття у площині є власне ортогональним перетворенням, еквівалентним чистому повороту на кут `180°` (двовимірна інверсія) без зміни киральності зображення.

## 3. Тривимірний тригранний куточок (3D Corner Cube)

У тривимірному просторі ретрорефлектор складається з трьох взаємно перпендикулярних дзеркал, розташованих вздовж координатних площин `yz`, `zx` та `xy`.

Одиничні нормалі до граней куточка мають вигляд:

```
n_x = (1, 0, 0)ᵀ     [нормаль до грані yz]
n_y = (0, 1, 0)ᵀ     [нормаль до грані zx]
n_z = (0, 0, 1)ᵀ     [нормаль до грані xy]
```

Відповідні матриці відбиття від кожної з трьох граней дорівнюють:

```
R_x = [ -1   0   0 ]                        [матриця відбиття від площини yz]
      [  0   1   0 ]
      [  0   0   1 ]

R_y = [  1   0   0 ]                        [матриця відбиття від площини zx]
      [  0  -1   0 ]
      [  0   0   1 ]

R_z = [  1   0   0 ]                        [матриця відбиття від площини xy]
      [  0   1   0 ]
      [  0   0  -1 ]
```

Якщо світловий промінь зазнає трьох послідовних відбиттів від усіх трьох граней куточка, то підсумкова матриця перетворення `R_{3D}` дорівнює:

```
R_{3D} 
= R_z · R_y · R_x                          [перемноження трьох координатних відбиттів]
= [ -1   0   0 ]                            [підсумкова інверсійна матриця]
  [  0  -1   0 ]
  [  0   0  -1 ]
= -I₃                                       [тривимірна мінус-одинична матриця]
```

Оскільки всі три діагональні матриці `R_x`, `R_y`, `R_z` перестановні (комутують між собою), порядок відбиття світла від граней куточка (наприклад, `x → y → z` або `z → x → y`) не змінює кінцевого результату.

Дія підсумкової матриці на довільний тривимірний вектор напрямку `v_in = (v_x, v_y, v_z)ᵀ`:

```
v_out 
= R_{3D} · v_in                             [дія підсумкової тривимірної матриці]
= -I₃ · (v_x, v_y, v_z)ᵀ                     [підстановка R_{3D} = -I₃]
= (-v_x, -v_y, -v_z)ᵀ                       [інверсія всіх трьох компонент вектора]
= -v_in                                     [початковий вектор інвертовано]
```

Всі три координатні компоненти вектора напрямку інвертуються. Промінь виходить строго антипаралельно вхідному напрямку у 3D просторі.

Оскільки `det(R_{3D}) = det(R_z) · det(R_y) · det(R_x) = (-1)³ = -1`, підсумкове тривимірне відбиття є невласним (змінює ліву трійку векторів на праву), інвертуючи зображення джерела.

## 4. Спектральний аналіз власні знаки та симетрії матриці R₃D

Матриця відбиття тригранного куточки `R_{3D} = -I₃` має важливі алгебраїчні й спектральні властивості, які визначають поведінку хвильового фронту під час оптичного розвертання:

1. **Власні значення та власні вектори:**
   Характеристичне рівняння матриці `R_{3D}` має вигляд:
   ```
   det(R_{3D} - λ · I₃) = det(-I₃ - λ · I₃) = (-1 - λ)³ = 0
   ```
   Усі три власні значення дорівнюють `λ₁ = λ₂ = λ₃ = -1`. Це свідчить про те, що будь-який вектор у `ℝ³` є власним вектором із власним значенням `-1`. На відміну від матриць чистого обертання навколо осі (де існує один власний вектор із `λ = +1`, який визначає нерухому вісь обертання), у 3D кутовому ретрорефлекторі **не існує виділеної осі обертання**. Повна просторова інверсія є повністю ізотропною відносно вершини куточка.

2. **Теорія груп і симетрія:**
   Операції дзеркального відбиття належать до ортогональної групи `O(3)`. Матриця одинарного відбиття `R_x` має `det(R_x) = -1` і належить до невласних елементів `O(3) \ SO(3)`. Подвійне відбиття у 2D куточку має `det(R_{2D}) = +1` і є елементом спеціальної ортогональної групи `SO(2)` (чистий поворот на 180°). Потрійне відбиття у 3D куточку має `det(R_{3D}) = -1` і є елементом просторової інверсії (англ. *parity inversion* чи *central inversion*).

Така групова симетрія гарантує, що ретрорефлектор повертає хвильовий фронт плоскої хвилі із збереженням її фазової структури незалежно від того, як пристрій орієнтований відносно джерела світла.

## 5. Аналіз кутової похибки при деформації граней (Spoilage Angle)

У реальному виробництві кути між гранями куточка не є ідеально рівними `90.000°`, а мають похибку `δθ`.

Розглянемо двовимірний куточок, у якому кут між дзеркалами дорівнює `90° + δθ`.

Нехай нормаль першого дзеркала `n₁ = (1, 0)ᵀ`, а нормаль другого дзеркала повернута на кут `90° + δθ`:

```
n₂ = (-sin(δθ), cos(δθ))ᵀ ≈ (-δθ, 1)ᵀ      [розклад Тейлора при малих δθ]
```

Простежимо перетворення вектора `v_in = (cos α, sin α)ᵀ`:

1. Після першого відбиття від `n₁`:
   ```
   v₁ = (-cos α, sin α)ᵀ                   [інверсія першої компоненти]
   ```
2. Після другого відбиття від `n₂`:
   ```
   v_out = v₁ - 2 · (v₁ · n₂) · n₂          [векторна формула відбиття від n₂]
   ```
   Обчислимо скалярний добуток:
   ```
   v₁ · n₂ = (-cos α) · (-δθ) + sin α · 1 = δθ · cos α + sin α   [скалярне множення векторів]
   ```
   Тоді компоненти `v_out`:
   ```
   v_out_x = -cos α - 2 · (δθ · cos α + sin α) · (-δθ) ≈ -cos α + 2 · δθ · sin α    [лінеаризація x]
   v_out_y = sin α - 2 · (δθ · cos α + sin α) · 1 ≈ -sin α - 2 · δθ · cos α        [лінеаризація y]
   ```

Знайдемо кут відхилення поверненого вектора `v_out` від ідеального антипаралельного напрямку `-v_in = (-cos α, -sin α)ᵀ`.

Використовуючи векторний добуток або розкладання синуса відхилення `ΔΦ`:

```
ΔΦ ≈ 2 · δθ                                [кутове відхилення у 2D куточку]
```

У тривимірному кутовому ретрорефлекторі із суцільного оптичного скла з показником заломлення `n`, якщо один із трьох двогранних кутів має похибку `δθ` від прямого кута, кутове відхилення вихідного променя на виході з призми дорівнює:

```
ΔΦ = 2 · √(2/3) · n · δθ ≈ 1.633 · n · δθ  [кутова розбіжність при похибці δθ]
```

Наприклад, для кутової призми з кварцового скла (`n = 1.46`) похибка виготовлення граней `δθ = 1` кутова секунда (`1″ = 4.85 · 10⁻⁶` рад) призводить до кутового розщеплення поверненого пучка на:

```
ΔΦ ≈ 1.633 · 1.46 · 1″ ≈ 2.38 кутових секунд (arcsec)   [підстановка n = 1.46]
```

Цей результат є основою для розрахунку та контрольованої «зіпсованості» (англ. *spoiling*) кутових призм у космічній геодезії, де кутову похибку граней свідомо закладають для розширення дифракційного конуса і компенсації швидкісної аберації світла.
