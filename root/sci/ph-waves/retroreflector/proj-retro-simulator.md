# ⚙️ Проєкт 3D-трасувальника променів у кутовому ретрорефлекторі

Цей проєкт присвячений розробці обчислювальної моделі 3D-трасування світлових променів у кутовому ретрорефлекторі для аналізу геометричних відхилень поверненого пучка при похибках виготовлення граней, оцінки апертурних втрат та чисельного моделювання фазових аберацій.

## 1. Фізичні основи 3D-трасування променів в оптичних системах

У чисельному оптичному моделюванні метод трасування променів (англ. *Ray Tracing*) спирається на подання світлової хвилі у вигляді геометричних променів, що поширюються уздовж векторів хвильових нормалей. Кожен промінь у тривимірному просторі задається двома основними параметрами:
1. Початковою точкою `P_0 = (p_x, p_y, p_z)`, яка визначає координати джерела або поточну точку перетину з оптичною поверхнею.
2. Одиничним вектором напрямку `v = (v_x, v_y, v_z)`, для якого виконується умова нормування `|v| = √(v_x² + v_y² + v_z²) = 1`.

Траєкторія променя у однорідному середовищі описується параметричним рівнянням прямої лінії:

```
P(t) = P_0 + t · v      [t ≥ 0 — параметрична відстань вздовж променя]
```

Для аналізу тригранного кутового ретрорефлектора геометрія моделюється трьома плоскими дзеркальними гранями, що перетинаються у спільній вершині (початку координат `(0, 0, 0)`). Кожна з трьох граней задається точкою на поверхні `P_plane` та одиничним вектором внутрішньої нормалі `n`:

```
(P - P_plane) · n = 0    [умова належності точки P площині грані]
```

Підставивши параметричне рівняння променя `P(t)` у рівняння площини, отримуємо точне вираження для параметру відстані `t` до точки перетину:

```
(P_0 + t · v - P_plane) · n = 0
t · (v · n) = (P_plane - P_0) · n
t = ((P_plane - P_0) · n) / (v · n)
```

Знаменник `(v · n)` являє собою скалярний добуток вектора напрямку променя та нормалі площини. Якщо `(v · n) = 0`, промінь поширюється паралельно грані й не перетинає її. Від'ємні значення `t < 0` відповідають перетинам у зворотному напрямку променя й відкидаються симулятором.

Після знайдення точки перетину `P_{int} = P_0 + t · v` вектор напрямку відбитого променя `v_{new}` обчислюється за векторною формулою дзеркального відбиття:

```
v_{new} = v - 2 · (v · n) · n    [векторна формула дзеркального відбиття]
```

## 2. Алгоритмічна структура симулятора та обробка крайніх випадків

Повний цикл моделювання ходу променя у кутовому ретрорефлекторі складається з таких послідовних кроків:

1. **Ініціалізація випромінювання:** Формування вхідного вектора напрямку `v_0` та початкової точки `P_0` у площині вхідної апертури.
2. **Цикл відбиттів:**
   - Перебір усіх трьох граней куточка та знаходження параметрів перетину `t_i`.
   - Вибір найближчої грані з мінімальним додатним значенням `t_{min} > 10⁻⁶`.
   - Перерахунок поточної позиції променя: `P_{new} = P_{old} + t_{min} · v_{old}`.
   - Оновлення вектора напрямку `v_{new}` за формулою дзеркального відбиття від вибраної грані.
   - Захист від повторного відбиття від тієї самої грані через чисельні округлення (ігнорування поточної грані на наступному кроці).
3. **Обробка крайніх випадків (Edge Cases):**
   - **Промінь зрізає апертуру:** Якщо промінь влучає лише у 1 або 2 грані й виходить поза межі куточка, симулятор фіксує апертурне зрізання (англ. *vignetting*) та позначає промінь як втрачений.
   - **Влучання у ребро або вершину:** Якщо точка перетину лежить на лінії стику граней (`t` одинакове для двох граней) або у вершині `(0, 0, 0)`, виникає кутова неоднозначність. Симулятор моделює дифракційне розсіювання або маркує промінь критичною помилкою.
   - **Похибка ортогональності граней:** Двогранні кути між нормалями `n_1`, `n_2`, `n_3` задаються з невеликими кутовими зсувами `δθ_{12}`, `δθ_{23}`, `δθ_{31}`. Це дозволяє симулювати «зіпсовані» куточки (англ. *spoiled corner cubes*) для розрахунку дифракційного розширення пучка.
4. **Вихідна оцінка кутової розбіжності:** Після виконання трьох відбиттів підсумковий вектор напрямку `v_{out}` порівнюється з ідеальним інвертованим напрямком `-v_0`. Кутова похибка повернення `Δθ` обчислюється через скалярний добуток:

```
cos(Δθ) = (v_{out} · (-v_0)) / (|v_{out}| · |-v_0|)
Δθ = arccos( clamp(v_{out} · (-v_0), -1.0, 1.0) )
```

Обчислене значення `Δθ` переводиться з радіан у кутові секунди (`1` рад `≈ 206264.8` кутових секунд).

```
┌─────────────────────────────────────────────────────────────┐
│               Схема 3D-трасування променя                    │
├─────────────────────────────────────────────────────────────┤
│ Вхідний промінь (P₀, v₀)                                    │
│        │                                                    │
│        ▼                                                    │
│ [Перетин із Гранню 1] ──► v₁ = v₀ - 2(v₀·n₁)n₁               │
│        │                                                    │
│        ▼                                                    │
│ [Перетин із Гранню 2] ──► v₂ = v₁ - 2(v₁·n₂)n₂               │
│        │                                                    │
│        ▼                                                    │
│ [Перетин із Гранню 3] ──► v₃ = v₂ - 2(v₂·n₃)n₃               │
│        │                                                    │
│        ▼                                                    │
│ Вихідний промінь v₃ ──► Обчислення Δθ = arccos(v₃ · (-v₀))  │
└─────────────────────────────────────────────────────────────┘
```

## 3. Математичні інваріанти та чисельна стійкість

При реалізації оптичного симулятора мовами програмування високого рівня необхідно враховувати обмежену точність обчислень чисел із плаваючою комою (стандарт IEEE 754).

Під час обчислення перетинів променя з гранями та дзеркальних відбиттів виконуються три головні чисельні інваріанти:
1. **Збереження норми вектора:** Фотометричний аналіз вимагає, щоб вектор напрямку променя залишався одиничним на кожному кроці. Оскільки нагромадження помилок округлення при повторних відбиттях може призводити до відхилення довжини вектора від одиниці, після кожного відбиття виконується явне повторне нормування: `v_{new} = v_{new} / |v_{new}|`.
2. **Точність перетину та поріг єпсилон:** Точка перетину `P_{int}` обчислюється з похибкою порядку `10⁻¹⁵`. Якщо не ввести поріг `ε ≈ 10⁻⁶`, промінь після відбиття може повторно перетнути ту саму грань у тій самій точці через мікроскопічний шум в координатах. Застосування перевірки `t > ε` виключає хибні самоперетини.
3. **Обрізання аргументу арккосинуса (Clamping):** При обчисленні підсумкового кута `Δθ = arccos(v_{out} · (-v_0))` скалярний добуток через накопичені помилки округлення може набути значення `1.0000000000000002`. Без використання функції `clamp(x, -1.0, 1.0)` виклик `arccos(1.0000000000000002)` викличе помилку `NaN` або обчислювальний виняток `domain_error`.

## 5. Результати числового моделювання та інженерні висновки

При запусків симулятора на ідеальних ортогональних гранях `90.000°` утворюється точний числовий результат:

```
Вхідний напрямок: (-0.5774, -0.5774, -0.5774)
Вихідний напрямок: (0.5774, 0.5774, 0.5774)
Кутове відхилення від -v_in: 0.0000 кутових секунд
```

Підсумковий вектор вихідного променя `v_{out} = (0.5774, 0.5774, 0.5774)` строго дорівнює `-v_{in}`, а кутове відхилення дорівнює нулю з точністю до чисел із плаваючою комою подвійної точності (`double`).

Якщо внести в нормаль однієї з граней невелику похибку виготовлення `δθ = 1.0` кутова секунда (`n_1 = (1.0, 0.00000485, 0.0)`), симулятор покаже кутове відхилення поверненого променя:

```
Кутове відхилення: 2.3801 кутових секунд
```

Цей числовий результат повністю підтверджує аналітичну формулу для суцільної скляної призми `ΔΦ = 1.633 · n · δθ` (для `n = 1.46` маємо `1.633 · 1.46 · 1″ = 2.38″`).

Розроблений симулятор дозволяє проектувати геометрію космічних та наземних ретрорефлекторів, розраховувати діаграму спрямованості поверненого дифракційного пучка та моделювати апертурні втрати при нахилах вимірювальної системи.
