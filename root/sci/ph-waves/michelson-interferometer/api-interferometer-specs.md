# 📋 Технічна специфікація та параметри інтерферометричної установки

Ця довідкова вставка містить інженерно-технічні специфікації, вибір матеріалів, параметри оптичних компонентів, допуски кутового й просторового юстування, оптико-електронні інтерфейси та зведені метрологічні рівняння, необхідні для проектування, складання, налаштування та калібрування прецизійних вимірювальних установок на основі інтерферометра Майкельсона.

---

### 1. Загальні принципи проектування та інтерфейси підсистем

При розробці лабораторних і промислових інтерферометрів Майкельсона оптична система розглядається як єдиний вимірювальний комплекс, що складається з чотирьох основних функціональних підсистем:

1. **Оптико-випромінювальна підсистема**: включає лазерне джерело, коліматорний телескоп із точковою діафрагмою (просторовим фільтром) для очищення моди лазерного випромінювання до чистої базової моди `TEM₀₀`, а також оптичний ізолятор (осередку Фарадея), що запобігає зворотному потраплянню відбитого променя у резонатор лазера.
2. **Інтерферометричне ядро**: оптичний вузол, що складається із прецизійного світлодільника, компенсаційної пластини та двох високовідбивних дзеркал. Цей вузол здійснює фізичне розділення хвильового фронту на два плечі, набіг різниці ходу та наступну когерентну суперпозицію.
3. **Механічна та прецизійна трансляційна підсистема**: забезпечує грубе та високоточне зміщення рухомого дзеркала. Вона об'єднує механічні мікрометричні супорти для початкового налаштування різниці плечей та п'єзоелектричні актюатори із замкненим контуром зворотного зв'язку для субнанометрового позиціонування.
4. **Оптико-електронна реєстраційна підсистема**: містить високошвидкісні фотодіоди або матричні CCD/CMOS-сенсори, аналогові малошумні підсилювачі, аналого-цифрові перетворювачі (АЦП) та цифрові контролери (на основі FPGA або мікроконтролерів) для квадратурного підрахунку інтерференційних смуг у реальному часі.

### 3. Матеріалознавство та температурна компенсація

Для мінімізації дрейфу нульової лінії інтерферометра, викликаного зміною температури навколишнього середовища, несучий каркас оптичного столу виготовляється зі спеціальних матеріалів із мінімальним коефіцієнтом лінійного теплового розширення (`α_TH`):

1. **Інвар (Invar 36)**: сплав заліза й нікелю (36% Ni) з коефіцієнтом теплового розширення `α_TH ≈ 1.2 · 10⁻⁶ K⁻¹`. Зміна температури на `ΔT = 1 K` для плеча довжиною `L = 20 см` викликає розширення `ΔL = L · α_TH · ΔT = 240 нм`, що відповідає зсуву на `0.76` інтерференційної смуги.
2. **Сітал / Зеродур (Zerodur / Sitall)**: склокерамічні матеріали з наднизьким тепловим розширенням `|α_TH| < 10⁻⁸ K⁻¹`. Застосовуються для виготовлення еталонних плато та підкладок дзеркал метрологічних інтерферометрів.
3. **Плавлений кварц (Fused Silica)**: володіє винятковою оптичною однорідністю, показником заломлення `n = 1.457` (на `632.8 нм`) та коефіцієнтом розширення `α_TH = 0.5 · 10⁻⁶ K⁻¹`.

| Матеріал | Показник заломлення `n` (`632.8 нм`) | Дисперсія `dn / dλ` (`мкм⁻¹`) | Термооптичний коефіцієнт `dn / dT` (`10⁻⁶ K⁻¹`) | Коефіцієнт розширення `α_TH` (`10⁻⁶ K⁻¹`) |
| :--- | :--- | :--- | :--- | :--- |
| **Крон BK7** | 1.5151 | -0.046 | +3.0 | 7.1 |
| **Плавлений кварц** | 1.4570 | -0.035 | +9.8 | 0.55 |
| **Важкий флінт SF11** | 1.7786 | -0.165 | +2.2 | 7.6 |
| **Сапфір (Al₂O₃)** | 1.7659 | -0.041 | +13.0 | 5.3 |

Окрім вибору матеріалів із низьким розширенням, у промислових вимірювальних системах застосовують пасивну та активну термостабілізацію. Пасивний захист включає розміщення оптичного ядра у герметичному металевому кожусі з теплоізоляційним шар-покриттям, що захищає прилад від конвекційних потоків повітря й локальних градієнтів температури. Застосування теплового кожуха збільшує постійну часу теплової релаксації установки з хвилин до кількох годин, вирівнюючи температурне поле.

### 4. Допуски кутового й просторового юстування

Оптичне юстування інтерферометра Майкельсона вимагає суворого дотримання кутових і просторових допусків для забезпечення високого контрасту (видності) інтерференційних смуг `V = (I_max - I_min) / (I_max + I_min) > 0.85`:

1. **Допуск на непаралельність дзеркал `M₁` та `M₂'` (режим кілець Гайдінгера)**:
   Кутове відхилення між дзеркалом `M₁` та уявним зображенням `M₂'` має задовольняти умову:

```
α < λ / (4 · D_beam)
```

   Для діаметра пучка `D_beam = 10 мм` та `λ = 632.8 нм` кут нахилу не повинен перевищувати `α < 15.8 мікрорадіан` (`0.0009°` або `3.26 кутових секунд`). Перевищення цього кута призводить до того, що кільця Гайдінгера деформуються і перетворюються на густу сітку смуг Фізо, що різко знижує контраст при інтегруванні по площі фотодетектора.

2. **Допуск на просторове суміщення плям**:
   Поперечний зсув центрів відбитих лазерних пучків `Δx_shift` у площині фотодетектора не повинен перевищувати `5 %` від діаметра пучка: `Δx_shift < 0.05 · D_beam`.

3. **Специфікація вимог до віброізоляції**:
   Оптична схема має бути змонтована на пасивній або активній пневматичній віброізольованій плиті з власною резонансною частотою підвісу `f_res < 1.5 Гц`. Рівень амплітуди мікросейсмічних вібрацій у діапазоні частот `10–100 Гц` не повинен перевищувати `1 нм`.

### 5. Калібрувальні співвідношення та формули метрологічних розрахунків

#### А. Вимірювання мікропереміщень дзеркала
Зсув рухомого дзеркала `ΔL` визначається за кількістю пройдених інтерференційних смуг `N` (переходів інтенсивності через максимум):

```
ΔL = N · (λ / 2)
```

При нецілому числі смуг мікропереміщення у квадратурному режимі (на лінійному схилі інтерференційної смуги біля `I = 2 I₁`) обчислюється за формулою:

```
ΔL(t) = (λ / 4π) · arcsin( (U(t) - U_mid) / U_amp )
```

де `U(t)` — поточна напруга фотодетектора, `U_mid = (U_max + U_min) / 2` — середня напруга зміщення, а `U_amp = (U_max - U_min) / 2` — амплітуда розмаху сигналу.

#### Б. Рефрактометричні вимірювання газів
Якщо у одне з плечей інтерферометра довжиною `L_cell` поміщають герметичну кювету і змінюють тиск газу від `0` (вакуум) до `P`, показник заломлення газу `n` розраховується за кількістю зміщених смуг `N_shift`:

```
n - 1 = (N_shift · λ) / (2 · L_cell)
```

Відносна похибка вимірювання показника заломлення при точності підрахунку смуг `δN = 0.01` та довжині кювети `L_cell = 100 мм` становить:

```
δ(n - 1) = (0.01 · 632.8·10⁻⁹) / (2 · 0.1) ≈ 3.16 · 10⁻⁸
```

#### В. Вимірювання товщини тонких прозорих плівок
При введенні прозорої плівки товщиною `d_film` з показником заломлення `n_film` під кутом падіння `i` до променя, товщина плівки виражається як:

```
d_film = (N_shift · λ) / ( 2 · ( √(n_film² - sin² i) - cos i ) )
```

### 6. Покроковий протокол юстування та діагностика несправностей

Для введення інтерферометра Майкельсона в експлуатацію виконують покроковий протокол юстування:

1. **Формування базової оптичної осі**: спрямувати лазерний промінь паралельно до поверхні оптичного столу за допомогою двох регульованих дзеркал.
2. **Встановлення світлодільника BS**: розмістити `BS` під кутом 45° до променя. Перевірити, що кут відбитого променя становить строго 90° ± 0.1°.
3. **Юстування еталонного дзеркала M₁**: встановити `M₁` у відбитому промені перпендикулярно до осі. Спостерігати відбиту пляму на діафрагмі лазера й поєднати її з вихідним отвором.
4. **Юстування рухомого дзеркала M₂**: встановити `M₂` у прохідному промені. Поставити компенсаційну пластину `C`.
5. **Суміщення плям на екрані**: за допомогою юстувальних гвинтів `M₂` сумістити дві відбиті плями на спостережному екрані до їх повного перекриття.
6. **Отримання інтерференційних смуг**: розширити пучок за допомогою коліматорної лінзи. Плавно обертати юстувальні гвинти `M₂` до появу широких смуг Фізо або кілець Гайдінгера.
