# 🧮 Математичний аналіз фазових зсувів та контрасту смуг

Математичний опис хвильових процесів у двопроменевому інтерферометрі Майкельсона ґрунтується на суворому розрахунку комплексної амплітуди електромагнітного поля після розділення світлового потоку на світлодільнику, проходження двох незалежних оптичних плечей та їхньої подальшої когерентної суперпозиції. 

У цій вставці наведено суворий математичний вивід оптичної різниці ходу, розподілу інтенсивності, амплітудних коефіцієнтів відбиття й передачі світлодільника з урахуванням граничних умов Френеля, теорії часткової часової та просторової когерентності, матричного методу Абелеса для тонких диелектричних плівок, а також геометричний розрахунок смуг рівного нахилу й рівної товщини.

---

### 1. Амплітудна матриця світлодільника та фазові зсуви Стокса

Розглянемо світлодільну пластину `BS` (напівпрозоре дзеркало 50:50). Позначимо через `r` та `t` амплітудні коефіцієнти відбиття та проходження при падінні світла з повітря на світлодільний шар (зовнішнє відбиття), а через `r'` та `t'` — коефіцієнти при відбитті та проходженні з боку скляної підкладки (внутрішнє відбиття).

Відповідно до рівнянь Френеля та закону збереження енергії (умові унітарності матриці розсіяння `S`), для ідеального світлодільника без поглинання виконуються **амплітудні співвідношення Стокса**:

```
r² + t · t' = 1
r' = -r
```

Знак мінус у співвідношенні `r' = -r` означає, що при відбитті від оптично густішого середовища (із зовнішнього боку) виникає додатковий зсув фази на `π` радіан (втрата півхвилі `λ / 2`), тоді як при відбитті зсередини підкладки фазовий зсув дорівнює нулю.

З точки зору хвильової матричної оптики, світлодільник описується симетричною унітарною матрицею зв'язку `M_BS`, яка пов'язує вхідні амплітуди полів `E_in1` та `E_in2` із вихідними амплітудами `E_out1` та `E_out2`:

```
[ E_out1 ] = [ t   r' ] · [ E_in1 ]
[ E_out2 ]   [ r   t  ]   [ E_in2 ]
```

Унітарність матриці `M_BS` гарантує збереження повної оптичної потужності в системі: `|E_out1|² + |E_out2|² = |E_in1|² + |E_in2|²`. У випадку 50:50 світлодільника амплітуди дорівнюють `r = 1 / √2` та `t = i / √2`, що вказує на фазовий зсув `π / 2` між відбитою та пройденою хвилями.

Нехай на світлодільник падає плоскополяризована монохроматична хвиля з комплексною амплітудою поля `E_in = E₀ · exp(i · (k·z - ω·t))`, де `k = 2π / λ` — хвильове число.

1. **Перша хвиля (Плече 1, довжина L₁)**:
   - Проходить крізь підкладку та світлодільний шар з коефіцієнтом `t`.
   - Проходить відстань `L₁` до дзеркала `M₁`, відбивається від нього з коефіцієнтом `r_M1 ≈ 1` (зсув фази `π`) та повертається до `BS`.
   - Відбивається від світлодільного шару зсередини з коефіцієнтом `r'`.
   - Комплексна амплітуда хвилі 1 на детекторі дорівнює:

```
E₁ = E₀ · t · exp(i · k · L₁) · (-1) · exp(i · k · L₁) · r'
   = -E₀ · t · r' · exp(i · 2 · k · L₁)             [втрата півхвилі при відбитті від M1]
   = E₀ · t · r · exp(i · 2 · k · L₁)               [граничне співвідношення Стокса: r' = -r]
```

2. **Друга хвиля (Плече 2, довжина L₂)**:
   - Відбивається від світлодільного шару зовні з коефіцієнтом `r` (зсув фази `π`).
   - Проходить відстань `L₂` до дзеркала `M₂`, відбивається від нього (`r_M2 ≈ 1`, зсув фази `π`) та повертається до `BS`.
   - Проходить крізь світлодільний шар з коефіцієнтом `t'`.
   - Комплексна амплітуда хвилі 2 на детекторі дорівнює:

```
E₂ = E₀ · r · exp(i · k · L₂) · (-1) · exp(i · k · L₂) · t'
   = -E₀ · r · t' · exp(i · 2 · k · L₂)             [втрата півхвилі при відбитті від M2]
```

Для симетричного 50:50 світлодільника амплітудні коефіцієнти рівні: `r = t = t' = 1 / √2`.

### 2. Точний вивід інтерференційного розподілу інтенсивності

Сумарне електричне поле у точці спостереження на екрані дорівнює сумі двох комплексних амплітуд:

```
E_total = E₁ + E₂
        = (E₀ / 2) · [ exp(i · 2 · k · L₁) - exp(i · 2 · k · L₂) ]     [підстановка амплітуд для r = t = 1/√2]
        = (E₀ / 2) · exp(i · 2 · k · L₁) · [ 1 - exp(i · 2 · k · (L₂ - L₁)) ] [винесення спільного множника]
```

Інтенсивність світла `I`, що реєструється фотодетектором, пропорційна квадрату модуля комплексної амплітуди `I = |E_total|²`:

```
I(ΔL) = E_total · E_total*
      = (E₀² / 4) · | 1 - exp(i · 2 · k · ΔL) |²    [де ΔL = L₂ - L₁]
      = (E₀² / 4) · [ 1 - exp(i · 2 · k · ΔL) ] · [ 1 - exp(-i · 2 · k · ΔL) ] [квадрат модуля комплексної величини]
      = (E₀² / 4) · [ 2 - 2 · cos(2 · k · ΔL) ]     [формула Ейлера: e^(ix) + e^(-ix) = 2 cos x]
      = (E₀² / 2) · [ 1 - cos(4π · ΔL / λ) ]        [підстановка k = 2π / λ]
      = E₀² · sin²(2π · ΔL / λ)                     [тригонометрична тотожність: 1 - cos(2x) = 2 sin²(x)]
```

Позначивши початкову інтенсивність джерела як `I₀ = E₀²`, вираз для інтенсивності набуває остаточного вигляду:

```
I(ΔL) = I₀ · sin²( (2π · ΔL) / λ )
```

З отриманої формули випливають фізичні умови інтерференції:
- **Інтерференційні мінімуми (темні смуги)**:
  `2 · ΔL = m · λ`  ===>  `ΔL = m · (λ / 2)`,  де `m = 0, ±1, ±2...`
- **Інтерференційні максимуми (світлі смуги)**:
  `2 · ΔL = (m + 1/2) · λ`  ===>  `ΔL = (m + 1/2) · (λ / 2)`,  де `m = 0, ±1, ±2...`

Один повний період зміни інтенсивності (від максимуму до максимуму) відповідає зміщенню рухомого дзеркала `M₂` на відстань `ΔL = λ / 2`.

### 3. Геометричний розрахунок смуг рівного нахилу та рівної товщини

#### А. Смуги рівного нахилу (кільця Гайдінгера)
Якщо дзеркала `M₁` та уявне зображення `M₂'` строго паралельні й розділені шар-проміжком товщиною `d = |L₂ - L₁|`, промені, що виходять під кутом `θ` до оптичної осі, мають різницю ходу:

```
Δs(θ) = 2 · d · cos θ
```

Повна фазова різниця для кута `θ`:

```
Δφ(θ) = (2π / λ) · 2 · d · cos θ + π
```

Максимуми формують концентричні кільця у фокальній площині збірної лінзи. Кутовий радіус `θ_m` `m`-го світлого кільця рахується від центру:

```
2 · d · cos θ_m = (m + 1/2) · λ
```

Використовуючи розклад косинуса для малих кутів `cos θ ≈ 1 - θ² / 2`, отримуємо:

```
2 · d · (1 - θ_m² / 2) = (m + 1/2) · λ
```

Звідси кутовий радіус `m`-го кільця дорівнює:

```
θ_m = √( (1 / d) · [ 2d - (m + 1/2) · λ ] )
```

У фокальній площині лінзи з фокусною відстані `f` лінійний радіус кільця `r_m = f · tg θ_m ≈ f · θ_m` задається співвідношенням:

```
r_m = f · √( (λ / d) · (m₀ - m) )
```

де `m₀ = 2d / λ` — порядок інтерференції у самому центрі картини (`θ = 0`).

Звідси випливає важливий наслідок для кроку кілець Гайдінгера: відстань між сусідніми кільцями `Δr_m = r_m - r_{m-1}` зменшується зі зростанням номера кільця `m`. Тобто кільця Гайдінгера розташовані густіше на периферії спостережної картини й більш рідко біля центру.

#### Б. Смуги рівної товщини (смуги Фізо)
Якщо дзеркала `M₁` та `M₂'` утворюють малий кут клина `α` (напрямленого вздовж осі `x`), товщина повітряного прошарку залежить від координати: `d(x) = d₀ + α · x`.

Різниця ходу при нормальному падінні `θ ≈ 0`:

```
Δs(x) = 2 · (d₀ + α · x)
```

Умова утворення світлих смуг:

```
2 · (d₀ + α · x_m) = (m + 1/2) · λ  ===>  x_m = ( (m + 1/2) · λ - 2 · d₀ ) / (2 · α)
```

Відстань між сусідніми паралельними смугами (крок смуг `Δx = x_{m+1} - x_m`) дорівнює:

```
Δx = λ / (2 · α)
```

Зменшення кута клина `α` розсуває смуги, а при `α → 0` система переходить у кільця Гайдінгера.

### 4. Контраст (видність) смуг та спектральна когерентність

Видність інтерференційних смуг (контраст за Майкельсоном) визначається як:

```
V = (I_max - I_min) / (I_max + I_min)
```

Для спектрально немонохроматичного джерела з розподілом інтенсивності за частотами `S(ν)` результуюча інтенсивність є результатом додавання інтенсивностей окремих спектральних компонент:

```
I(τ) = ∫₀^∞ S(ν) · [ 1 + cos(2π · ν · τ) ] dν
     = I_total + Re [ γ(τ) ]
```

де `τ = Δs / c = 2 · ΔL / c` — час затримки між плечима, а `γ(τ)` — **комплексний ступінь часової когерентності**:

```
γ(τ) = ( ∫₀^∞ S(ν) · exp(-i · 2π · ν · τ) dν ) / ( ∫₀^∞ S(ν) dν )
```

Згідно з **теоремою Вінера — Хінчина**, ступінь когерентності `γ(τ)` є фур'є-перетворенням спектральної густини випромінювання `S(ν)`. 

1. **Гаусовий спектральний профіль** (ширина спектра `Δν`):

```
V(τ) = |γ(τ)| = exp( -π · (Δν · τ)² / (4 · ln 2) )
```

Довжина когерентності `l_c`, на якій контраст спадає у `e` разів:

```
l_c = c · τ_c ≈ λ₀² / Δλ
```

2. **Двокомпонентний дублет** (дві вузькі лінії одинакової інтенсивності з частотами `ν₁` та `ν₂`, `Δν = |ν₁ - ν₂|`):

```
I(τ) = I₀ · [ 1 + cos(2π · ν_avg · τ) · cos(π · Δν · τ) ]
```

Видність смуг модулюється за законом огинаючої:

```
V(τ) = | cos(π · Δν · τ) | = | cos( (2π · ΔL · Δλ) / λ₀² ) |
```

Контраст періодично зникає до нуля при різниці плечей `ΔL = m · λ₀² / (2 · Δλ)` та відновлюється до максимуму `V = 1`, що дозволяє з високою точністю вимірювати спектральне розщеплення дублетів (наприклад, дублету натрію `589.0 нм` та `589.6 нм`).

3. **Просторова когерентність та протяжні джерела**:
Якщо джерело світла має скінченний кутовий розмір `Δθ_src`, різні точки джерела створюють кільця Гайдінгера різного радіуса. Повне зникання контрасту смуг через просторову некогерентність відбувається, коли різниця кутових радіусів кілець від крайніх точок джерела досягає половини ширини смуги. Вимога до кутового розміру джерела задається співвідношенням:

```
Δθ_src < √(λ / d)
```

Отже, при великих різницях плечей `d` для збереження високого контрасту смуг `V > 0.5` джерело світла має бути не лише спектрально вузьким (монохроматичним), а й просторово точковим.
