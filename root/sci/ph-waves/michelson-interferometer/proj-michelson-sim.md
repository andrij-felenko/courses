# ⚙️ Чисельне моделювання картини інтерферометра Майкельсона

Чисельне моделювання оптичних процесів в інтерферометрі Майкельсона є необхідним інструментом як для проектування прецизійних оптичних систем, так і для глибшого аналізу явищ хвильової оптики. На відміну від аналітичних розрахунків, які зазвичай обмежуються ідеальними плоскими або сферичними хвилями, комп'ютерна симуляція дає змогу враховувати реальний гаусовий профіль інтенсивності лазерних пучків, оптичні аберації, складний спектральний склад випромінювання (біле світло або декілька спектральних ліній), а також дробовий шум фотоприймачів та механічні вібрації.

У цій вставці наведено детальний математичний алгоритм чисельного розрахунку двовимірної картини освітленості, аналіз архітектури програмування оптичних моделей, а також повністю робочі та ідіоматичні програми мовами Python та C++. Програми виконують дискретизацію спостережного поля, обчислюють оптичну різницю ходу у кожній точці та будують інтерференційну картину як у вигляді консольної псевдографіки, так і з можливістю експорту даних у графічні формати.

### 1. Математична та алгоритмічна модель для розрахунку сітки pixel-by-pixel

Кожен піксель спостережного екрана з координатами `(x, y)` характеризується власною оптичною різницею ходу `Δs(x, y)` між двома розщепленими й зведеними хвилями.

Загальне співвідношення для різниці ходу з урахуванням відстані між дзеркалами `d₀ = |L₂ - L₁|`, кута клина `α` (нахил дзеркала `M₂` відносно `M₁` вздовж осі `x`), кута нахилу `β` (вздовж осі `y`), а також кривизни хвильового фронту (радіус `R` у параксіальному наближенні) виражається формулою:

```
Δs(x, y) = 2 · [ d₀ + α · x + β · y + (x² + y²) / (2 · R) ]
```

Розподіл інтенсивності світла у пікселі `(x, y)` обчислюється як результату додавання амплітуд двох хвиль із урахуванням гаусового профілю вхідного лазерного пучка радіусом `w₀`:

```
I(x, y) = I₀ · cos²( (π · Δs(x, y)) / λ ) · exp( -2 · (x² + y²) / w₀² )
```

де `exp( -2 · (x² + y²) / w₀² )` — амплітудне огинаюче згасання для основної моди `TEM₀₀` лазерного випромінювання.

Для моделювання частково когерентного світла або немонохроматичного випромінювання (наприклад, дублету жовтої лінії натрію `λ₁ = 589.0 нм` та `λ₂ = 589.6 нм`) підсумкова інтенсивність обчислюється як некогерентна сума інтенсивностей для кожної спектральної компоненти:

```
I_total(x, y) = ∑_k S(λ_k) · I(x, y, λ_k)
```

де `S(λ_k)` — ваговий коефіцієнт інтенсивності відповідної спектральної лінії.

Чисельне моделювання фур'є-спектрограм покладається на дискретне перетворення Фур'є (FFT). Синтезована інтерферограма `I(d_n)` обчислюється для наборів кроків різниці плечей `d_n = n · Δd`. Далі застосовується математичне вікно аподизації (наприклад, вікно Хеннінга або Нортона — Біра) для запобігання паразитного крайового розбризкування спектральних піків:

```
w(n) = 0.5 · [ 1 - cos( (2π · n) / N ) ]
```

Після множення інтерферограми на віконну функцію виконується швидке перетворення Фур'є, результати якого дають відновлений спектр випромінювання `S(ν)` з частотною роздільною здатністю `Δν = 1 / (N · Δd)`.

Окрім того, при моделюванні реальних експериментальних інтерферограм до обчисленої інтенсивності додається випадковий шумовий доданок. Дробовий фотонний шум розраховується за пуассонівським розподілом з дисперсією `σ_shot² = I`, а тепловий шум підсилювача додається як гаусовий білий шум із нульовим середнім значенням. Моделювання шуму дає змогу оцінювати граничну точність відновлення спектральних ліній при низьких рівнях сигналу.

### 2. Архітектура чисельного розрахунку та програмна реалізація

Для побудови ефективного алгоритму симуляції застосовується дискретизація спостережного екрана на регулярну сітку розміром `N × M` пікселів. 

При виборі кроку сітки `dx = W / N` та `dy = H / M` необхідно дотримуватися **критерію Найквіста — Шеннона**: крок сітки має бути як мінімум удвічі меншим за просторовий період найчастіших інтерференційних смуг `Δx = λ / (2 · α)`. Якщо крок сітки занадто великий, на згенерованому зображенні виникає паразитний ефект стробоскопічного спотворення (стробоскопічного аліасингу).

Нижче наведено робочі реалізації алгоритму двома мовами програмування:
1. **Python**: орієнтований на наочність, швидке прототипування та легку інтеграцію з науковими бібліотеками (NumPy / Matplotlib).
2. **C++**: орієнтований на максимальну обчислювальну продуктивність, строгий контроль пам'яті, багатопотокову обробку великих сіток та застосування сучасних стандартів C++17/C++20 (контейнери, `std::clamp`, RAII, багатопотоковість).

### 3. Фізичний аналіз та результати чисельного експерименту

Під час виконання програми генеруються два граничні фізичні режими роботи інтерферометричної установки:

1. **Режим смуг Фізо (клин `α = 25 мкрад`, `R = 10 м`)**:
   На екрані будується система строго паралельних вертикальних світлих і темних смуг. Просторовий крок смуг `Δx = λ / (2 · α)` при `λ = 632.8 нм` та `α = 25 мкрад` становить точно `12.65 мм`. При збільшенні кута клина `α` у два рази кількість смуг у полі зору подвоюється.

2. **Режим кілець Гайдінгера (`α = 0`, `R = 0.35 м`)**:
   На екрані формується система концентричних кілець Гайдінгера. Відстань між сусідніми кільцями зменшується при віддаленні від центра. При зміні різниці плечей `d₀` на `λ / 2` з центрального максимуму народжується нове кільце, що розширюється до периферії.

3. **Аналіз спектрального дублету Натрію**:
   Функція `simulate_duplet_interferogram` демонструє ефект «зникання та відновлення» контрасту смуг (*fringe beats*). Оскільки лінії натрію `589.0 нм` та `589.6 нм` відрізняються на `Δλ = 0.6 нм`, інтервал затримки між сусідніми мінімумами видності становить `d_beat = λ² / (2 · Δλ) ≈ 0.29 мм`. При зміщенні дзеркала на `0.29 мм` смуги повністю зникають, а при подальшому зміщенні на `0.58 мм` контраст знову відновлюється до максимуму.

4. **Експорт у графічний файл PGM**:
   Реалізований у C++ метод `exportPGM` генерує растровий файл у форматі Netpbm PGM, який можна відкрити у будь-якому графічному редакторі (GIMP, ImageJ, Photoshop). Це дає змогу будувати високодеталізовані моделі інтерференційних картин із роздільною здатністю `1024 × 1024` пікселів та вище.

При розробці високонавантажених обчислювальних алгоритмів оптичної симуляції на C++ слід звертати увагу на точність арифметики з плаваючою комою: зміщення плеча обчислюється у нанометрах (`10⁻⁹ м`), тоді як загальний оптичний шлях складає десятки сантиметрів (`10⁻¹ м`). Використання подвійної точності `double` є обов'язковим для запобігання втратам фазової точності при тригонометричних обчисленнях.

Крім того, при паралельних розрахунках великих 2D-масивів `2048 × 2048` пікселів рекомендується застосовувати багатопотокову обробку за допомогою OpenMP або стандарту C++17 `std::execution::par`, що дозволяє прискорити генерацію зображення в 4–8 разів на сучасних багатоядерних процесорах.
