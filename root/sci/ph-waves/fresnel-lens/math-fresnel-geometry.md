# 🧮 Математика зон, профілю фацетів та фазового узгодження лінзи Френеля

Геометричний розрахунок профілю лінзи Френеля полягає у визначенні кута нахилу поверхні `α(r)` для кожного кільцевого канавки-фацету, розміщеного на радіальній відстані `r` від оптичної осі. Головна математична мета розрахунку — забезпечити, щоб паралельний пучок світла, падаючи на вхідну площину лінзи, після заломлення на робочих похилих фацетах перетинав оптичну вісь в єдиній фокальній точці на відстані `f`.

### 1. Параксіальне виведення профілю схилу та похибка наближення

Розглянемо плоско-опуклу лінзу Френеля з показником заломлення `n`, що межує з повітрям (`n_air = 1.00`). Плоска сторона лінзи звернена до вхідного паралельного пучка світла, а профільні фацети розміщені на вихідній поверхні.

Промінь, що падає паралельно оптичній осі на висоті `r`, проходить крізь плоску вхідну поверхню під кутом 0° без відхилення. На вихідній поверхні промінь зустрічає похилу грань фацету під кутом `α` до внутрішньої нормалі цієї грані. Кут відхилення променя від початкового горизонтального напрямку позначимо як `θ(r)`. З геометрії трикутника фокусування кут `θ(r)` пов'язаний із фокусною відстанню `f` співвідношенням:

```
tan θ(r) = r / f
```

Для параксіальних променів, які проходять поблизу оптичної осі (`r ≪ f`), кут `θ` малий, тому `tan θ ≈ sin θ ≈ θ = r / f`.

Застосуємо закон Снелла на похилій межі «скло → повітря». Кут падіння променя на внутрішню нормаль грані дорівнює `α`, а кут виходу в повітря дорівнює `α + θ`. Отже, рівняння Снелла має вигляд:

```
n · sin α = 1.00 · sin(α + θ)
```

Розкриємо синус суми `sin(α + θ) = sin α · cos θ + cos α · sin θ`. Для малих кутів `θ` і `α` можна прийняти `cos θ ≈ 1`, `sin θ ≈ θ`, `sin α ≈ α`, `cos α ≈ 1`. Тоді маємо послідовне спрощення:

```
n · α = α + θ             [параксіальне наближення закону Снелла]
(n - 1) · α = θ           [перенесення α в ліву частину]
α(r) = θ / (n - 1)        [вираження кута нахилу фацету]
α(r) = r / ((n - 1) · f)  [підстановка θ = r / f]
```

Звідси випливає фундаментальний висновок: у параксіальному наближенні кут нахилу робочої грані фацету `α(r)` **лінійно зростає** з віддаленням від оптичної осі `r`. Центральний фасет (`r = 0`) є паралельним пласкій поверхні (`α = 0`), а крайній фасет на радіусі `R` має найбільший нахил.

Розкладемо різницю між точним кутом та параксіальним наближенням у степеневий ряд за параметром `(r / f)`:

```
α_paraxial(r) = (r / f) / (n - 1)
α_exact(r) = (r / f) / (n - 1) + (r / f)³ · (3n + 1) / (6 · (n - 1)² · n) + O((r / f)⁵)
δα(r) = α_exact(r) - α_paraxial(r) ≈ (r / f)³ · (3n + 1) / (6 · (n - 1)² · n)
```

Ця похибка `δα(r)` описує **параксіальну сферичну аберацію**: спрощена лінійна формула дає занижений кут нахилу на крайніх зонах, через що периферійні промені фокусуються далі за номінальний фокус `f`, розмиваючи точкову пляму.

### 2. Точний непораксіальний аберасферичний профіль

Для світлосильних лінз із великою числовою апертурою (High NA), де `r` порівнянне з `f`, параксіальні спрощення стають неприпустимими. Щоб усунути сферичну аберацію повністю, кут нахилу грані `α(r)` слід розраховувати точно за рівнянням Снелла без наближень.

Розкриємо точне рівняння `n · sin α = sin(α + θ)` відносно `tan α`:

```
n · sin α = sin α · cos θ + cos α · sin θ
n · tan α = tan α · cos θ + sin θ       [ділення обох частин на cos α]
tan α · (n - cos θ) = sin θ             [групування тангенсів]
tan α(r) = sin θ / (n - cos θ)          [точна формула кута грані]
```

Підставивши геометричні вирази через радіус `r` та фокус `f`:
`sin θ = r / √(r² + f²)`,  `cos θ = f / √(r² + f²)`, отримуємо остаточний вираз для точного тангенса кута грані кожної кільцевої зони:

```
tan α(r) = r / (n · √(r² + f²) - f)
```

Ця формула задає абсолютно аберасферичний профіль: кожне кільце лінзи Френеля має свій індивідуально розрахований нахил, що усуває сферичну аберацію для точкового джерела у фокусі.

Для довільного профілю вигнутої поверхні фацету `z(r)` (де `z` — глибина рельєфу) зв'язок із кутом нахилу задається похідною:

```
dz / dr = tan α(r) = r / (n · √(r² + f²) - f)
```

Інтегруючи цей вираз вздовж радіуса від `r_k` до `r_{k+1}`, отримуємо точну конічну твірну гіперболічного профілю для кожної кільцевої зони:

```
z(r) = z₀ + (√(r² + f²) - f) / (n - 1)    [гіперболічний профіль зони Френеля]
```

Гіперболічна твірна фацету забезпечує рівність оптичної довжини шляху всіх променів від вхідного плоскої хвильового фронту до фокальної точки `F`, що є прямою реалізацією принципу Ферма (найменшого часу).

### 3. Геометрія сходинок, ухил стінок та інтегральна світлосила

Кожна кільцева зона має радіальний крок `p` (pitch) та глибину канавки `h`. Зв'язок між ними задається формулою:

```
h(r) = p · tan α(r)
```

У практичному виробництві застосовують два підходи до нарізання зон:
1. **Постійний крок зон (`p = const`):** радіальний розмір усіх кілець однаковий (наприклад, `p = 0.5 мм`), але глибина канавки `h(r)` зростає від центра до периферії.
2. **Постійна глибина канавки (`h = const`):** глибина нарізки однакова по всій апертурі (наприклад, `h = 0.2 мм`), але крок зон `p(r)` зменшується до країв лінзи, стаючи дуже частим на периферії.

Вертикальна стінка сходинки між сусідніми фацетами має технологічний ухил (draft angle) `ψ` (зазвичай 1°–5°), необхідний для виймання виробу з прес-форми. Ця стінка не бере участі в корисному заломленні: світловий промінь, що падає на стінку, або блокується, або відбивається в довільному напрямку, створюючи паразитне розсіяне світло.

Локальний коефіцієнт геометричної ефективності фацету з урахуванням затінення стінкою задається формулою:

```
η_shadow(r) = 1 - (h(r) · tan(θ_i + ψ)) / p = 1 - tan α(r) · tan(θ_i + ψ)
```

де `θ_i` — кут падіння променя на лінзу. На периферії лінзи, де `h(r)` і `α(r)` великі, втрати на затінення стінками можуть сягати 15–25% від падаючого потоку.

Щоб обчислити загальну світлосилу (інтегральний коефіцієнт пропускання) лінзи Френеля радіуса `R`, проведемо інтегрування ефективної площі світлового отвору з урахуванням зонного затінення:

```
A_eff = 2π · ∫₀ᴿ r · η_shadow(r) · T_fresnel(r) dr
```

де `T_fresnel(r)` — коефіцієнт пропускання за формулами Френеля для неполяризованого світла:

```
T_fresnel(r) = 1 - 0.5 · [(sin²(α - α_out) / sin²(α + α_out)) + (tan²(α - α_out) / tan²(α + α_out))]
```

де `α_out = α + θ`. Інтегральні втрати складаються із суми геометричного затінення стінками та френелівського відбиття від поверхонь. Для акрилової лінзи (`n = 1.49`) з кутом охоплення 45° загальний інтегральний ККД становить близько 88–92%.

### 4. Умова фазового узгодження, спектральна смуга та дифракційний кіноформ

Якщо розмір канавки зменшити до мікронів, лінза переходить із режиму чистої геометричної рефракції в режим хвильової дифракції. Щоб монохроматична хвиля довжиною `λ` після проходження крізь сусідні зони не руйнувалася деструктивною інтерференцією, набіг фази між сусідніми мікросходинками має бути кратним `2π`.

Різниця оптичного шляху `ΔL` між променем, що пройшов крізь вершину канавки товщиною `h`, та променем у западині канавки крізь повітря дорівнює:

```
ΔL = (n - 1) · h
```

Відповідний набіг фази `Δϕ` становить:

```
Δϕ = (2π / λ) · (n - 1) · h
```

Вимагаючи `Δϕ = 2π · m` (де `m = 1, 2, 3...` — порядок дифракції), отримуємо **умову фазування кіноформа**:

```
h_kinoform = m · λ / (n - 1)
```

Для оптичного пластику PMMA (`n = 1.49`) та зеленого світла (`λ₀ = 550 нм`) при першому порядку дифракції (`m = 1`):

```
h_kinoform = 1 · 0.550 мкм / (1.49 - 1.00) = 1.122 мкм
```

Мікропрофільована лінза Френеля з глибиною канавок рівно `1.122 мкм` працює як **кіноформний дифракційний оптичний елемент** (DOE).

За умови відхилення довжини хвилі від розрахункової `λ ≠ λ₀` виникає фазовий розсоглас `ΔΦ(λ)`:

```
ΔΦ(λ) = 2π · [(n(λ) - 1) / (n(λ₀) - 1)] · (λ₀ / λ) - 2π
```

Дифракційна ефективність кіноформа в першому порядку дифракції залежить від довжини хвилі за функцією `sinc²`:

```
η_diff(λ) = sinc²(0.5 · ΔΦ(λ) / π) = [sin(0.5 · ΔΦ(λ)) / (0.5 · ΔΦ(λ))]²
```

Для спектрального діапазону видимого світла (400–700 нм) дифракційна ефективність кіноформа, розрахованого на 550 нм, залишається вищою за 85%, що робить кіноформні елементи високоефективними інструментами у спектральних та лазерних оптичних системах.
