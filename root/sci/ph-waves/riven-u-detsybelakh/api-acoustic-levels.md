# 📋 Стандартні опорні рівні, одиниці та вагові фільтри в акустиці й радіотехніці

Децибел стає абсолютною одиницею вимірювання лише за наявності фіксованого еталонного значення (опори), що позначається відповідним літерним суфіксом після позначення «дБ» або «dB». Без вказання опорного рівня або суфікса запис «рівень становить 40 дБ» позбавлений фізичного змісту і позначає лише безрозмірне співвідношення між двома величинами.

У цій довідковій вставці систематизовано стандартизовані опорні величини, правила маркування, математичні вирази для перерахунку та нормативні таблиці вагових коефіцієнтів згідно зі стандартами IEC 61672-1, ISO 226, ANSI S1.4 та рекомендаціями ITU.

### 1. Довідкова таблиця суфіксів децибельних шкал

| Одиниця | Опорна величина | Область застосування | Стандартна формула зв'язку |
|---|---|---|---|
| **dB SPL** | `p₀ = 20 мкПа = 2·10⁻⁵ Па` (у повітрі) | Акустика, шум довкілля, аудіологія | `L_p = 20 · log₁₀( p_rms / 20·10⁻⁶ )` |
| **dB SPL (гідро)** | `p₀ = 1 мкПа = 1·10⁻⁶ Па` (у воді) | Гідроакустика, сонари, підводний зв'язок | `L_p = 20 · log₁₀( p_rms / 10⁻⁶ )` |
| **dB SIL** | `I₀ = 10⁻¹² Вт/м² = 1 пВт/м²` | Інтенсивність звукових хвиль | `L_I = 10 · log₁₀( I / 10⁻¹² )` |
| **dB SWL (L_w)** | `W₀ = 10⁻¹² Вт = 1 пВт` | Акустична потужність джерел звуку | `L_w = 10 · log₁₀( W / 10⁻¹² )` |
| **dBm** | `P₀ = 1 мВт = 10⁻³ Вт` (на 50 або 600 Ом) | Радіотехніка, ВЧ, телефонія, оптичні мережі | `L_P = 10 · log₁₀( P_mW / 1.0 )` |
| **dBW** | `P₀ = 1 Вт` | Радіолокація, супутниковий зв'язок, передавачі | `L_P = 10 · log₁₀( P_watts / 1.0 )` |
| **dBu** | `V₀ = 0.7746 В` (ненавантажена напруга) | Професійна студійна аудіоапаратура | `L_v = 20 · log₁₀( V_rms / 0.7745967 )` |
| **dBV** | `V₀ = 1.0000 В` (строго 1 В RMS) | Споживча аудіоапаратура (Hi-Fi, RCA) | `L_v = 20 · log₁₀( V_rms / 1.0 )` |
| **dBµV** | `V₀ = 1 мкВ = 10⁻⁶ В` | Радіоприймачі, телебачення, ЕМС | `L_v = 20 · log₁₀( V_rms / 10⁻⁶ )` |
| **dBmV** | `V₀ = 1 мВ = 10⁻³ В` | Кабельне телебачення (CATV), широкосмугові мережі | `L_v = 20 · log₁₀( V_rms / 10⁻³ )` |
| **dBFS** | Повна шкала АЦП/ЦАП (Full Scale = 1.0) | Цифрова обробка сигналів (DSP), цифрові аудіоробочі станції | `L_fs = 20 · log₁₀( D / D_max )` |
| **dBi** | Ізотропний випромінювач (ідеальна сфера) | Коефіцієнт підсилення антен | `G_dBi = 10 · log₁₀( I_dir / I_iso )` |
| **dBd** | Напівхвильовий симетричний диполь | Коефіцієнт підсилення антен (`0 dBd = 2.15 dBi`) | `G_dBd = G_dBi − 2.15` |
| **dBr** | Довільний відносний робочий рівень | Телекомунікаційні тракти та випробування | `L_r = 10 · log₁₀( P / P_ref )` |
| **dBc** | Потужність несучого сигналу (Carrier) | Фазові шуми гетеродина, рівень гармонік | `L_c = 10 · log₁₀( P_spurious / P_carrier )` |

### 2. Специфікація та перерахунок стандартів в електроніці та аудіотракті

В аналоговому звукозаписі та комутації історично закріпилися два взаємно несумісні стандарти номінального лінійного рівня напруги:

1. **Професійний стандарт `+4 dBu` (студійне обладнання, роз'єми XLR / TRS):**
   * Номінальна середньоквадратична напруга: `V_rms = 0.7746 · 10^(+4/20) ≈ 1.228 В`;
   * Опорний рівень `0 dBu = 0.7746 В` спочатку відповідав напрузі на навантаженні 600 Ом при розсіюванні потужності 1 мВт (`0 dBm`), однак у сучасній апаратурі з високим вхідним опором (від 10 кОм і вище) `dBu` позначає ненавантажену напругу джерела (суфікс «u» походить від англ. *unloaded*).
2. **Побутовий споживчий стандарт `−10 dBV` (Hi-Fi техніка, телевізори, роз'єми RCA):**
   * Номінальна середньоквадратична напруга: `V_rms = 1.0 · 10^(−10/20) ≈ 0.3162 В`;
   * Опорний рівень `0 dBV = 1.0 В` є строгою метрологічною одиницею напруги.

Різниця між професійним та споживчим номінальними рівнями становить:

```
ΔV = 20 · log₁₀( 1.228 / 0.3162 ) = 4 dBu − (−7.78 dBu) = 11.78 дБ
```

Якщо підключити вихід споживчого програвача (`−10 dBV`) до входу професійного мікшера (`+4 dBu`), рівень сигналу буде заниженим майже на 12 дБ, що погіршить співвідношення сигнал/шум. Навпаки, подача професійного сигналу на побутовий вхід викличе перевантаження підсилювача та жорсткий нелінійний кліпінг.

### 3. Радіочастотні та антенні децибельні шкали

У радіотехніці та телекомунікаціях децибели використовуються для характеристики чутливості приймачів, потужності передавачів та коефіцієнтів підсилення антенних систем:

1. **Шкала потужності dBm та dBW:**
   * `0 dBm = 1 мВт = 10⁻³ Вт`;
   * `0 dBW = 1 Вт = 1000 мВт = +30 dBm`;
   * У ВЧ-трактах стандартним є хвильовий опір 50 Ом, де `0 dBm` створює напругу `V_rms = √(10⁻³ · 50) ≈ 0.2236 В` (223.6 мВ). У телевізійних кабельних мережах із хвильовим опором 75 Ом рівень `0 dBm` відповідає напрузі `V_rms = √(10⁻³ · 75) ≈ 0.2739 В`.
2. **Напруженість поля dBµV/m (дБ-мікровольт на метр):**
   * Застосовується в радіомоніторингу та оцінці електромагнітної сумісності (ЕМС);
   * Опорна напруженість електричного поля `E₀ = 1 мкВ/м = 10⁻⁶ В/м`. Рівень напруженості поля розраховується як `E_dB = 20 · log₁₀( E / 10⁻⁶ )`.
3. **Антенне підсилення dBi та dBd:**
   * **dBi (децибел відносно ізотропного випромінювача):** порівнює густину потоку енергії антени у головному пелюстку діаграми спрямованості з гіпотетичним ідеальним точковим джерелом, яке випромінює однаково в усіх напрямках простору (сферична діаграма);
   * **dBd (децибел відносно півхвильового диполя):** порівнює випромінювання з реальним напівхвильовим симетричним диполем у вакуумі. Оскільки власний коефіцієнт підсилення напівхвильового диполя відносно ізотропного випромінювача становить `2.15 dBi`, зв'язок між шкалами задається формулою:
   ```
   G_dBi = G_dBd + 2.15 дБ
   G_dBd = G_dBi − 2.15 дБ
   ```

### 4. Відмінність акустичних опорних рівнів у повітрі та воді

У повітряній акустиці поріг чутності `p₀ = 20 мкПа = 2·10⁻⁵ Па` на частоті 1 кГц відповідає середньому порогу здорового людського вуха. При цьому в повітрі за стандартних умов (`ρ = 1.204 кг/м³`, `c = 343 м/с`) питомий акустичний імпеданс середовища дорівнює `z_air = ρ · c ≈ 413 Па·с/м`. Відповідна порогова інтенсивність становить:

```
I₀,air = p₀² / z_air = (20·10⁻⁶)² / 413 ≈ 0.97·10⁻¹² Вт/м² ≈ 10⁻¹² Вт/м² = 1 пВт/м²
```

У гідроакустиці (морські дослідження, сонари підводних човнів, ехолоти) фізичні умови кардинально відрізняються:
1. Вода має набагато більшу густину (`ρ ≈ 1000 кг/м³`) та швидкість звуку (`c ≈ 1500 м/с`), тому акустичний імпеданс води становить `z_water ≈ 1.5·10⁶ Па·с/м` (у 3600 разів вище, ніж у повітрі);
2. Міжнародним гідроакустичним стандартом встановлено опорний тиск `p₀,water = 1 мкПа = 10⁻⁶ Па`.

Через це децибели SPL у повітрі та воді **не можна порівнювати безпосередньо**:
* Різниця за рахунок зміни опорного тиску: `20 · log₁₀( 20 мкПа / 1 мкПа ) = 20 · log₁₀(20) ≈ +26.02 дБ`;
* Різниця за рахунок зміни імпедансу середовища: `10 · log₁₀( z_water / z_air ) = 10 · log₁₀( 1.5·10⁶ / 413 ) ≈ +35.6 дБ`.

Звуковий тиск 100 дБ SPL у повітрі еквівалентний 126 дБ SPL у воді за тиском, а за густиною випромінюваної потужності акустичне джерело у воді з рівнем 161.6 дБ створює таку ж інтенсивність, як джерело 100 дБ у повітрі.

### 5. Цифрова шкала повної амплітуди dBFS та стандарт гучності LUFS

У цифрових аудіопроцесорах та АЦП значення відліків обмежені максимальною розрядністю (наприклад, 24-бітні цілі числа або 32-бітні числа з плаваючою комою в діапазоні від `-1.0` до `+1.0`). Опорний рівень `0 dBFS` (Decibels relative to Full Scale) позначає найбільшу можливу амплітуду синусоїди або прямокутного сигналу до виникнення переповнення:

* **Пікове значення (Peak dBFS):** амплітуда максимального цифрового відліку `D_max = 1.0` дорівнює `0 dBFS Peak`;
* **Середньоквадратичне значення (RMS dBFS):** за стандартом AES17 середньоквадратичний рівень повномасштабної синусоїди нормується як `0 dBFS RMS` (хоча ненормований чистий розрахунок квадрата синуса дає `-3.01 dBFS`).

Для вимірювання суб'єктивної гучності телерадіомовлення та стримінгових сервісів стандарт ITU-R BS.1770 / EBU R128 визначає шкалу **LUFS** (Loudness Units relative to Full Scale):
* Фільтрація K-зважуванням (K-weighting, каскад високочастотного поличного фільтра та обрізного ФВЧ);
* Енергетичне інтегрування з відсіканням пауз (гейтування на рівні `-10 LU` нижче середнього);
* Цільовий рівень мовлення: `-23 LUFS` (європейське телебачення EBU R128) або `-14 LUFS` (музичні платформи Spotify, YouTube).

### 7. Санітарні норми шуму та допустимий час акустичного навантаження

Тривалий вплив високого рівня звукового тиску призводить до необоротного пошкодження сенсорних волоскових клітин завитки внутрішнього вуха (професійна приглухуватість, англ. *Noise-Induced Hearing Loss*, NIHL).

Міжнародні стандарти охорони праці (NIOSH, OSHA, Директива ЄС 2003/10/EC) регламентують граничні дози акустичного навантаження. За стандартом NIOSH застосовується правило обміну в 3 дБ (англ. *3 dB Exchange Rate*): кожні додаткові 3 дБ подвоюють акустичну енергію, що скорочує безпечний час перебування в зоні шуму рівно вдвічі:

| Рівень шуму L_A [dBA] | Максимальний безпечний час за добу (NIOSH) | Еквівалентна акустична подія / джерело |
|---|---|---|
| **80 dBA** | 25 годин (без обмежень) | Шумне офісне приміщення, дзвінки, кондиціонери |
| **85 dBA** | **8 годин** (базова санітарна норма) | Інтенсивний автомобільний рух, механічний цех |
| **88 dBA** | 4 години | Газонокосарка, робота циркулярної пили |
| **91 dBA** | 2 години | Ручний фрезер, деревообробний верстат |
| **94 dBA** | 1 година | Мотоцикл без глушника, робота бетономішалки |
| **97 dBA** | 30 хвилин | Відбійний молоток на відстані 2 м |
| **100 dBA** | 15 хвилин | Вагон метро під час гальмування на станції |
| **103 dBA** | 7.5 хвилин | Конвеєрна штампувальна лінія заводу |
| **106 dBA** | 3.75 хвилини (225 секунд) | Робота ланцюгової бензопили на максимальних обертах |
| **110 dBA** | 1.4 хвилини (84 секунди) | Рок-концерт, танцювальний клуб біля порталів |
| **115 dBA** | 28 секунд | Сирена автомобіля швидкої допомоги (1 м) |
| **120 dBA** | 9 секунд | Пневматична клепка сталевих балок |
| **≥ 130 dBA** | **0 секунд (Заборонено без захисту)** | Поріг больового відчуття, зліт реактивного винищувача |
| **≥ 140 dBA** | **Миттєва акустична травма** | Постріл із вогнепальної зброї, піротехнічний вибух |

Ці нормативні співвідношення слугують інженерною основою для розрахунку захисних засобів (берушів, навушників із пасивним шумозаглушенням NRR/SNR), а також для конфігурації автоматичних систем моніторингу акустичної безпеки.
