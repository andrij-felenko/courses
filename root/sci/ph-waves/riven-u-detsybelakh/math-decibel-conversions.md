# 🧮 Математичний апарат децибельних шкал, некогерентне додавання та імпедансна корекція

Децибел є безрозмірною логарифмічною мірою відношення двох однойменних фізичних величин. Перехід від лінійної шкали до логарифмічної базується на фундаментальних властивостях логарифмічної функції, що дозволяє спрощувати мультиплікативні ланцюги передачі сигналів до простих адитивних операцій.

### 1. Алгебраїчні властивості логарифмічних перетворень

Логарифмування за основою 10 перетворює основні алгебраїчні операції над фізичними сигналами:

```
log₁₀( A · B ) = log₁₀(A) + log₁₀(B)          [добуток перетворюється на суму рівнів]
log₁₀( A / B ) = log₁₀(A) − log₁₀(B)          [ділення перетворюється на різницю рівнів]
log₁₀( Aⁿ ) = n · log₁₀(A)                    [степінь перетворюється на коефіцієнт масштабу]
log₁₀( 1 / A ) = −log₁₀(A)                    [обернена величина змінює знак децибелів]
```

Завдяки цим тотожностям наскрізний коефіцієнт передачі послідовного тракту з `N` каскадів (підсилювачів, кабелів, атенюаторів), кожен з яких має лінійний коефіцієнт підсилення за потужністю `k_p,i = P_out,i / P_in,i`, розраховується як проста арифметична сума децибельних підсилень:

```
K_p,total = k_p,1 · k_p,2 · ... · k_p,N
L_total = 10 · log₁₀( K_p,total )
= 10 · log₁₀( k_p,1 · k_p,2 · ... · k_p,N )   [логарифм добутку]
= 10 · ∑ log₁₀( k_p,i )                       [сума окремих логарифмів]
= ∑ L_i                                       [алгебраїчна сума децибельних коефіцієнтів]
```

### 2. Виведення формули для амплітудних величин та імпедансна корекція

Потужність електричного або акустичного сигналу завжди пропорційна квадрату амплітудної (польової) величини — напруги `V`, струму `I` або акустичного звукового тиску `p`.

Для електричного кола миттєва та середньоквадратична потужність розсіювання на активному опорі `R` визначається законом Джоуля — Ленца:

```
P = V_rms² / R = I_rms² · R
```

Нехай сигнал із напругою `V₁` діє на навантаженні `R₁`, створюючи потужність `P₁ = V₁² / R₁`, а опорний сигнал із напругою `V₀` діє на навантаженні `R₀`, створюючи потужність `P₀ = V₀² / R₀`. Розрахуємо точне децибельне відношення потужностей:

```
L = 10 · log₁₀( P₁ / P₀ )
= 10 · log₁₀( (V₁² / R₁) / (V₀² / R₀) )       [підстановка виразу потужності через напругу]
= 10 · log₁₀( (V₁ / V₀)² · (R₀ / R₁) )         [групування відношень напруг та опорів]
= 10 · log₁₀( (V₁ / V₀)² ) + 10 · log₁₀( R₀ / R₁ ) [розклад логарифма добутку]
= 20 · log₁₀( V₁ / V₀ ) + 10 · log₁₀( R₀ / R₁ )    [винесення степеня 2 перед логарифм: 10·2 = 20]
```

Звідси випливає фундаментальний висновок: формулу `L_v = 20 · log₁₀(V₁ / V₀)` можна застосовувати **лише тоді, коли опори однакові** (`R₁ = R₀`), оскільки в цьому випадку `R₀ / R₁ = 1`, а `10 · log₁₀(1) = 0`.

Якщо ж вимірювання напруги здійснюється між ланцюгами з різними хвильовими або навантажувальними опорами (наприклад, перехід із 50-омного кабелю на 75-омний або вимірювання високоомного входу підсилювача), обов'язково враховується **імпедансна поправка**:

```
ΔL_Z = 10 · log₁₀( R₀ / R₁ )
```

#### Акустичний аналог для плоских хвиль

В акустиці інтенсивність плоскої звукової хвилі `I` (густина потоку акустичної потужності у Вт/м²) пов'язана із середньоквадратичним звуковим тиском `p_rms` та питомим акустичним імпедансом середовища `z₀ = ρ · c`:

```
I = p_rms² / ( ρ · c ) = p_rms² / z₀
```

Рівень інтенсивності звуку становить:

```
L_I = 10 · log₁₀( I₁ / I₀ )
= 20 · log₁₀( p₁ / p₀ ) + 10 · log₁₀( z₀,ref / z₀,test )
```

У межах одного однорідного середовища (наприклад, у повітрі за стандартних умов, де `z₀ ≈ 415 Па·с/м = const`) імпедансний член зникає, тому рівень інтенсивності звуку `L_I` чисельно збігається з рівнем звукового тиску `L_p = 20 · log₁₀(p / p₀)`.

### 3. Додавання децибелів: некогерентні та когерентні джерела

При одночасному звучанні кількох джерел або підсумовуванні сигналів просте лінійне додавання децибелів є грубою фізичною помилкою. Характер підсумовування цілком визначається фазовою кореляцією (когерентністю) сигналів.

#### А. Некогерентні джерела (випадкова фаза, незалежний шум)

Якщо джерела звуку незалежні (різні музичні інструменти, шум транспорту, некорельовані шумові генератори), їхні миттєві взаємні фази розподілені рівномірно від `0` до `2π`. Інтерференційний член при усередненні за часом обнуляється:

```
⟨ p_total² ⟩ = ⟨ (p₁ + p₂ + ... + p_N)² ⟩
= ⟨ p₁² ⟩ + ⟨ p₂² ⟩ + ... + ⟨ p_N² ⟩ + 2 · ∑ ⟨ p_i · p_j ⟩ [розклад квадрата суми]
= ⟨ p₁² ⟩ + ⟨ p₂² ⟩ + ... + ⟨ p_N² ⟩ + 0      [взаємна кореляція некогерентних коливань дорівнює нулю]
= ∑ ⟨ p_i² ⟩                                  [підсумовуються середні квадрати тисків / енергії]
```

Оскільки інтенсивність прямо пропорційна середньому квадрату тиску, підсумовуються саме потужності (енергії):

```
I_total = ∑ I_i = I₀ · ∑ 10^( L_i / 10 )
```

Підставляючи сумарну інтенсивність у формулу децибелів, отримуємо **формулу енергетичного підсумовування некогерентних рівнів**:

```
L_total = 10 · log₁₀( ∑ 10^( L_i / 10 ) )
```

**Ключові окремі випадки некогерентного додавання:**

1. **Додавання двох однакових джерел (`L₁ = L₂ = L₀`):**
```
L_total = 10 · log₁₀( 10^(L₀/10) + 10^(L₀/10) )
= 10 · log₁₀( 2 · 10^(L₀/10) )                 [факторизація однакових доданків]
= 10 · log₁₀(2) + 10 · log₁₀( 10^(L₀/10) )      [розклад логарифма добутку]
= L₀ + 10 · 0.30103                            [обчислення десяткового логарифма 2]
= L₀ + 3.01 дБ                                  [підсумок: подвоєння енергії додає 3.01 дБ]
```

2. **Додавання `N` однакових некогерентних джерел:**
```
L_total = L₀ + 10 · log₁₀( N )
```
* При `N = 10` джерел: `L_total = L₀ + 10 · log₁₀(10) = L₀ + 10 дБ`.
* При `N = 100` джерел: `L_total = L₀ + 10 · log₁₀(100) = L₀ + 20 дБ`.

3. **Додавання двох джерел із суттєвою різницею рівнів (`ΔL = L₁ − L₂ ≥ 10 дБ`):**
```
L_total = 10 · log₁₀( 10^(L₁/10) + 10^(L₂/10) )
= 10 · log₁₀( 10^(L₁/10) · (1 + 10^(−ΔL/10)) ) [винесення множника 10^(L1/10)]
= L₁ + 10 · log₁₀( 1 + 10^(−ΔL/10) )            [розклад логарифма добутку]
```
При `ΔL = 10 дБ` додатковий внесок слабшого джерела становить:
```
ΔL_add = 10 · log₁₀( 1 + 10⁻¹ ) = 10 · log₁₀(1.1) ≈ 0.414 дБ
```
Якщо різниця між шумом обладнання та фоновим шумом приміщення перевищує 10 дБ, вплив фону складає менше ніж 0.5 дБ і ним зазвичай нехтують під час акустичних вимірювань.

#### Б. Когерентні джерела (фіксована фаза, синфазність)

Якщо два однакових джерела випромінюють когерентну гармонічну хвилю з фіксованою різницею фаз `Δφ`:

```
p_total(t) = P · cos(ω·t) + P · cos(ω·t + Δφ)
p_rms,total² = P_rms² + P_rms² + 2 · P_rms² · cos(Δφ) = 2 · P_rms² · (1 + cos(Δφ))
```

1. **Синфазні джерела (`Δφ = 0`, конструктивна інтерференція):**
```
p_total = 2 · p₁
L_total = 20 · log₁₀( 2 · p₁ / p₀ ) = L₁ + 20 · log₁₀(2) = L₁ + 6.02 дБ
```
Амплітуда тиску подвоюється, а сумарна інтенсивність зростає у чотири рази (`+6.02 дБ`), оскільки джерела синфазно взаємодіють через поле випромінювання.

2. **Протифазні джерела (`Δφ = π`, деструктивна інтерференція):**
```
p_total = p₁ − p₁ = 0
L_total = −∞ дБ
```
Відбувається взаємне повне гасіння звуку (принцип активного шумозаглушення).

### 4. Просторове затухання звуку за законом обернених квадратів

У вільному тривимірному просторі акустична потужність `W` точкового всеспрямованого джерела розподіляється по поверхні сфери радіуса `r`:

```
S(r) = 4 · π · r²
I(r) = W / S(r) = W / ( 4 · π · r² )
```

Зміна рівня інтенсивності та звукового тиску при переході від відстані `r₁` до відстані `r₂` виводиться логарифмуванням відношення інтенсивностей:

```
ΔL(r₁, r₂) = L_p(r₂) − L_p(r₁)
= 10 · log₁₀( I(r₂) / I(r₁) )
= 10 · log₁₀( ( W / (4·π·r₂²) ) / ( W / (4·π·r₁²) ) ) [підстановка закону площі сфери]
= 10 · log₁₀( (r₁ / r₂)² )                           [скорочення потужності W та коефіцієнта 4π]
= 20 · log₁₀( r₁ / r₂ )                             [винесення квадрата: 10·2 = 20]
= −20 · log₁₀( r₂ / r₁ )                            [властивість оберненого дробу]
```

При кожному **подвоєнні відстані** у вільному полі (`r₂ = 2 · r₁`):

```
ΔL = −20 · log₁₀(2) ≈ −20 · 0.30103 ≈ −6.02 дБ
```

Для протяжного лінійного джерела (довга колона автомобілів на магістралі, потяг) випромінювання має не сферичну, а циліндричну симетрію: площа циліндра `S(r) = 2·π·r·h`, тому `I(r) ∝ 1/r`. Спад рівня становить:

```
ΔL_line = −10 · log₁₀( r₂ / r₁ )
```
При подвоєнні відстані від магістралі рівень звуку падає лише на `-3.01 дБ`.

### 5. Пік-фактор (Crest Factor) та зв'язок між амплітудним і RMS рівнями

У цифрових аудіосистемах шкала `dBFS` прив'язана до максимально можливої амплітуди цифрової вибірки. Проте енергія сигналу визначається його середньоквадратичним значенням (RMS).

Відношення пікової амплітуди сигналу `V_peak` до його ефективного значення `V_rms` називається **пік-фактором** (англ. *Crest Factor*):

```
Q = V_peak / V_rms
C_dB = 20 · log₁₀( V_peak / V_rms )
```

Для різних форм сигналів пік-фактор набуває строго визначених значень:

1. **Гармонічний синусоїдальний сигнал:**
```
V_rms = V_peak / √2
C_dB = 20 · log₁₀( √2 ) = 10 · log₁₀(2) ≈ 3.01 дБ
```
Синусоїда з повною шкалою `0 dBFS Peak` має середньоквадратичний рівень `-3.01 dBFS RMS`.

2. **Прямокутний симетричний меандр:**
```
V_rms = V_peak
C_dB = 20 · log₁₀( 1.0 ) = 0.00 дБ
```

3. **Трикутний або пилкоподібний сигнал:**
```
V_rms = V_peak / √3
C_dB = 20 · log₁₀( √3 ) = 10 · log₁₀(3) ≈ 4.77 дБ
```

4. **Гаусовий білий шум та реальний музичний сигнал:**
Мовний або музичний аудіосигнал містить виражені короткочасні транзієнти (ударні інструменти, приголосні звуки), тому його пік-фактор становить від `12 дБ` до `20 дБ`. Саме тому в професійних студійних трактах номінальний рівень запису встановлюється на рівні `-18 dBFS` або `-20 dBFS`, залишаючи так званий динамічний запас (*Headroom*) для запобігання жорсткому цифровому кліпінгу піків.

### 6. Точний розрахунок опорної напруги для шкали dBu

Шкала `dBu` походить від телефонного стандарту потужності `0 dBm` (розсіювання 1 мВт на узгодженому навантаженні 600 Ом):

```
P₀ = 1 мВт = 10⁻³ Вт
R₀ = 600 Ом
```

Розрахуємо середньоквадратичну напругу `V₀`, яка створює цю потужність:

```
P₀ = V₀² / R₀
V₀² = P₀ · R₀ = 10⁻³ · 600 = 0.6 В²
V₀ = √( 0.6 ) ≈ 0.7745966692414834 В ≈ 0.7746 В
```

Різниця між опорним рівнем споживчої апаратури `0 dBV` (`V_ref = 1.0 В`) та професійним рівнем `0 dBu` (`V_ref = 0.7746 В`):

```
ΔL = 20 · log₁₀( 1.0 / 0.7745967 )
= 20 · log₁₀( 1.2909944 )
≈ 2.218487 дБ ≈ 2.22 дБ
```

Звідси отримуємо строгі точні формули зв'язку між `dBu` та `dBV`:

```
L_dBu = L_dBV + 2.218 дБ
L_dBV = L_dBu − 2.218 дБ
```

### 7. Передатна функція вагового фільтра A за стандартом IEC 61672-1

Стандарт IEC 61672-1 визначає вагову функцію A-зважування у частотній області через передатну функцію аналогового прототипу `H_A(s)` у комплексній площині Лапласа (`s = j·ω = j·2π·f`):

```
H_A(s) = K_A · s⁴ / [ (s + ω₁)² · (s + ω₂) · (s + ω₃) · (s + ω₄)² ]
```

Полюси фільтра задаються чотирма характерними круговими частотами:

```
f₁ = 20.6 Гц       →  ω₁ = 2π · 20.6 ≈ 129.434 рад/с   (подвійний дійсний полюс)
f₂ = 107.7 Гц      →  ω₂ = 2π · 107.7 ≈ 676.699 рад/с  (одинарний полюс)
f₃ = 737.9 Гц      →  ω₃ = 2π · 737.9 ≈ 4636.354 рад/с (одинарний полюс)
f₄ = 12194.0 Гц    →  ω₄ = 2π · 12194.0 ≈ 76617.162 рад/с (подвійний дійсний полюс)
```

Амплітудно-частотна характеристика `R_A(f) = |H_A(j·2π·f)|` набуває компактного алгебраїчного вигляду:

```
R_A(f) = ( 12194² · f⁴ ) / [ (f² + 20.6²) · √( (f² + 107.7²) · (f² + 737.9²) ) · (f² + 12194²) ]
```

Децибельне значення вагового коефіцієнта `A(f)` виражається з урахуванням нормувальної константи `+2.00 дБ`, що забезпечує точне значення `A(1000 Гц) = 0.00 дБ`:

```
A(f) = 20 · log₁₀( R_A(f) ) + 2.00  [дБ]
```

Для вагового фільтра C формула має спрощений вигляд (без проміжних полюсів `f₂` та `f₃`):

```
R_C(f) = ( 12194² · f² ) / [ (f² + 20.6²) · (f² + 12194²) ]
C(f) = 20 · log₁₀( R_C(f) ) + 0.06  [дБ]
```

Ці аналітичні вирази слугують математичним еталоном для проектування цифрових БІХ-фільтрів (IIR) під час обробки звукових масивів на мікроконтролерах та сигнальних процесорах.
