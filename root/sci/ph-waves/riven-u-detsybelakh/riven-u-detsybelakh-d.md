Людське вухо здатне вловлювати ледь чутний шелест листя, створюваний змінним тиском повітря всього у двадцять мікропаскалів (`0.00002 Па`), і водночас витримувати гуркіт реактивного двигуна на зльоті з тиском понад двадцять паскалів (`20 Па`). Якщо спробувати нанести цей колосальний діапазон на звичайний лінійний графік із міліметровими поділками, де тиску шепоту відповідає відрізок в один міліметр, то позначка больового порогу відсунеться на відстань одного кілометра. Лінійні шкали виявляються цілком непридатними для опису явищ із динамічним діапазоном у мільйон разів за амплітудою та в трильйон разів (`10¹²`) за потужністю. Природним інженерним і фізичним розв'язком цієї проблеми є перехід до логарифмічної шкали рівнів — децибелів.

### 1. Психофізичні витоки: закон Вебера — Фехнера та стиснення динамічного діапазону

Людські органи чуття — слух, зір, дотик — сформувалися в процесі біологічної еволюції як адаптивні сенсорні системи з нелінійним відгуком. Сенсорний апарат повинен одночасно мати надзвичайно високу чутливість до слабких сигналів у стані спокою та не зазнавати перевантаження чи механічного руйнування при потужних зовнішніх впливах навколишнього середовища.

У середині XIX століття німецький анатом і фізіолог Ернст Генріх Вебер (нім. *Ernst Heinrich Weber*, 1795–1878) провів серію фундаментальних психофізичних експериментів із визначення мінімального помітного приросту сили подразника `ΔS` (диференційного порогу розрізнення). Він з'ясував, що людське сприйняття реагує не на абсолютну величину доданого фізичного впливу, а на його відносне значення щодо початкового рівня подразника `S`:

```
ΔS / S = const = k_w
```

Константа `k_w` отримала назву дробу Вебера. Якщо людина тримає в руці вантаж масою 100 грамів, вона здатна відчути додавання лише 2 грамів (`ΔS/S = 0.02`). Проте якщо початкова маса становить 1 кілограм, додавання тих самих 2 грамів залишається абсолютно непоміченим: для виникнення нового відчуття потрібно додати вже 20 грамів.

Для слухового сприйняття сили звуку на середніх частотах дріб Вебера становить приблизно `k_w ≈ 0.1`–`0.26` (приріст акустичної інтенсивності приблизно на 10–26%), що майже точно відповідає зміні рівня звуку на `1 дБ`.

У 1860 році німецький фізик, філософ і психолог Густав Теодор Фехнер (нім. *Gustav Theodor Fechner*, 1801–1887) математично розвинув спостереження Вебера. Він сформулював гіпотезу, що елементарний крок суб'єктивного відчуття `dE` прямо пропорційний відносному приросту фізичного подразника `dS / S`. Інтегрування цього диференціального рівняння приводить до фундаментального **закону Вебера — Фехнера**:

```
dE = k · ( dS / S )                            [диференціальна форма гіпотези Фехнера]
E = k · ∫ ( 1 / S ) dS                         [інтегрування за силою подразника]
= k · ln( S / S₀ )                             [інтегрування з початковим порогом чутності S₀]
= k_d · log₁₀( S / S₀ )                        [перехід до десяткового логарифма: k_d = k · ln(10)]
```

Суб'єктивна сила відчуття `E` (гучність звуку, яскравість світла) зростає як логарифм від фізичної інтенсивності подразника `S`. Щоб звук суб'єктивно здався людині у два рази гучнішим, його фізичну енергію потрібно збільшити приблизно у десять разів.

Біологічний механізм цього логарифмічного компресування у внутрішньому вусі забезпечується складною біомеханікою завитки (лат. *cochlea*). Звуковий тиск через коливання барабанної перетинки та слухових кісточок передається на мембрану овального вікна і викликає біжучу хвилю вздовж базилярної мембрани. На цій мембрані розташований кортіїв орган із двома типами рецепторних клітин:

1. **Внутрішні волоскові клітини (ВВК):** безпосередньо генерують нервові імпульси, перетворюючи механічний вигин волосків у деполяризацію мембрани та виділення нейромедіатора в синаптичну щілину слухового нерва;
2. **Зовнішні волоскові клітини (ЗВК):** працюють як активні електромеханічні двигуни. Завдяки наявності моторного білка престину ЗВК здатні скорочуватися синхронно зі звуковою частотою, локально підсилюючи коливання базилярної мембрани при слабких звуках (до `+40–50 дБ`) та насичуючись при потужних звуках.

Цей активний біологічний підсилювач стискає колосальний зовнішній динамічний діапазон у 120 дБ (1 000 000 000 000 разів за потужністю) у значно вужчий робочий електричний діапазон рецепторного потенціалу нервових волокон (близько 30–40 дБ).

Історію створення перших логарифмічних вимірювальних одиниць, відмови від фізичного стандарту мідного кабелю та народження децибела в стінах лабораторій Bell Telephone детально розкрито у вставці [📜 Від стандартної милі кабелю до децибела: історія логарифмічних одиниць у телефонії](root:ph-waves/riven-u-detsybelakh/hist-bel-decibel-telephony.md).

> 🔧 **Навіщо це.**
> Логарифмічне стиснення в аудіотрактах дозволяє цифровим сигнальним процесорам (DSP) та аналоговим схемам відображати повний акустичний діапазон від тихого шуму кімнати до пострілу за допомогою компактної 16-бітної або 24-бітної сітки, запобігаючи втраті деталей у тихих фрагментах фонограми.

### 2. Означення децибела: енергетичні та амплітудні величини

Децибел (позначення **дБ** або **dB**) не є фізичною розмірною одиницею на зразок метра чи кілограма. Це безрозмірне співвідношення, десята частина більшої одиниці — **Бела** (англ. *Bel*, B), названої на честь винахідника телефона Александера Грема Белла. Префікс «деци-» походить від латинського слова *decimus* (десята частина).

#### Енергетичні величини (коефіцієнт 10)

Для величин, які безпосередньо несуть енергію або потужність — електричної потужності `P` (Вт), акустичної інтенсивності `I` (Вт/м²), повної звукової енергії `W` (Дж) чи густини енергії `w` (Дж/м³) — рівень у децибелах визначається як десятковий логарифм відношення вимірюваної величини до опорної, помножений на 10:

```
L_P = 10 · log₁₀( P / P₀ )  [дБ]
```

Множник 10 виникає через те, що один Бел дорівнює `log₁₀(P / P₀)`, а в одному Белі міститься рівно 10 децибелів (`1 Бел = 10 дБ`).

Коли потужність подвоюється (`P = 2 · P₀`), рівень зростає на:

```
L = 10 · log₁₀(2) ≈ 10 · 0.30103 ≈ +3.01 дБ ≈ +3 дБ
```

Збільшення потужності у 10 разів відповідає `+10 дБ`, у 100 разів — `+20 дБ`, а в один мільйон разів (`10⁶`) — `+60 дБ`.

#### Амплітудні (польові) величини (коефіцієнт 20)

У фізиці та електроніці вимірювальні прилади (осцилографи, вольтметри, мікрофони) частіше фіксують не саму потужність, а амплітудні (лінійні або польові) величини — електричну напругу `V`, силу струму `I`, напруженість поля `E` або змінний звуковий тиск `p`.

Потужність у будь-якій лінійній системі пропорційна квадрату амплітудної величини:

```
P = V² / R                                     [електрична потужність на опорі R]
I = p² / ( ρ · c )                             [акустична інтенсивність плоскої хвилі]
```

Якщо підставити квадрат амплітуди у базове означення децибела за умови однакових імпедансів джерела й приймача, показник степеня 2 виноситься за знак логарифма як множник:

```
L_V = 10 · log₁₀( V² / V₀² )
= 10 · log₁₀( (V / V₀)² )                      [об'єднання квадрата під логарифмом]
= 10 · 2 · log₁₀( V / V₀ )                     [винесення степеня: 10 · 2 = 20]
= 20 · log₁₀( V / V₀ )  [дБ]
```

![Співвідношення лінійних множників та децибелів](/root/sci/ph-waves/riven-u-detsybelakh/img/decibel-power-amplitude.svg)
*Квадратична залежність енергії від амплітуди подвоює децибельний множник: зростання напруги або тиску у 2 рази дає приріст +6.02 дБ, тоді як подвоєння потужності дає лише +3.01 дБ.*

Якщо напруга або звуковий тиск зростають у 2 рази (`V / V₀ = 2`), рівень збільшується на:

```
L = 20 · log₁₀(2) ≈ 20 · 0.30103 ≈ +6.02 дБ ≈ +6 дБ
```

Зростання амплітуди в 10 разів дає `+20 дБ`, у 100 разів — `+40 дБ`, а в 1000 разів — `+60 дБ`.

#### Критична пастка узгодження імпедансів

Формула з множником 20 є строго справедливою лише за умови рівності активних опорів або хвильових імпедансів середовищ (`Z₁ = Z₂`). Якщо вимірювання напруги здійснюється між ланцюгами з різними опорами (наприклад, перехід із 50-омного ВЧ-кабелю на 600-омну телефонну лінію), або звук переходить із повітря у воду, до результату обов'язково додається імпедансна поправка `10 · log₁₀(Z₂ / Z₁)`.

Повне математичне виведення імпедансних формул, закони некогерентного енергетичного додавання сигналів та векторної інтерференції хвиль викладено у вставці [🧮 Математичний апарат децибельних шкал, некогерентне додавання та імпедансна корекція](root:ph-waves/riven-u-detsybelakh/math-decibel-conversions.md).

### 3. Опорні рівні в електроніці, радіотехніці та звукозаписі

Без вказання еталонного значення децибел є лише відносним коефіцієнтом підсилення або ослаблення. Для перетворення децибелів на абсолютні шкали введено стандартизовані суфікси, що вказують на конкретну фізичну опору `P₀` або `V₀`.

![Стандартні опорні рівні в аудіо, радіозв'язку та цифровій обробці](/root/sci/ph-waves/riven-u-detsybelakh/img/reference-levels-scale.svg)
*Співвідношення шкал напруги та потужності: студійний стандарт +4 dBu (1.228 В) розташований на 11.79 дБ вище за споживчий побутовий рівень −10 dBV (0.316 В).*

#### Шкала dBm (децибели відносно 1 мілівата)

Шкала `dBm` є основним стандартом у радіотехніці, телекомунікаціях та НВЧ-електроніці. Опорною потужністю є рівно один міліват:

```
P₀ = 1 мВт = 10⁻³ Вт
L_dBm = 10 · log₁₀( P_mW / 1.0 )
```

* `0 dBm` = `1.0 мВт`;
* `+30 dBm` = `1000 мВт = 1.0 Вт` (`0 dBW`);
* `−30 dBm` = `1.0 мкВт` (рівень сигналу супутникового приймача).

Напруга, що відповідає рівню `0 dBm`, залежить від хвильового опору навантаження `R`:
* У класичній дротовій телефонії та студійній комутації навантаження дорівнює `600 Ом`. Напруга на такому опорі становить `V = √(0.001 · 600) = √0.6 ≈ 0.7746 В`;
* У високочастотній радіотехніці стандартним навантаженням є `50 Ом`. Напруга `0 dBm` на 50 Ом дорівнює `V = √(0.001 · 50) = √0.05 ≈ 0.2236 В`.

#### Шкали dBu та dBV (опорні рівні напруги в аудіо)

В сучасній аудіотехніці підсилювачі мають низький вихідний опір (долі ома) та високий вхідний опір (10–47 кОм), тому передача сигналу відбувається за напругою, без передачі максимальної потужності. Для таких кіл створено дві шкали напруги:

1. **dBu (децибел відносно 0.7746 В):** суфікс «u» вказує на ненавантажену напругу (*unloaded*). Опорна напруга `V₀ = 0.7745967 В` запозичена з 600-омного телефонного стандарту `0 dBm`, але застосовується незалежно від реального опору навантаження.
   Стандартом для професійного аудіообладнання (студійні пульти, балансні з'єднання XLR) є номінальний лінійний рівень **`+4 dBu`**, що відповідає середньоквадратичній напрузі:
   ```
   V_rms = 0.7746 · 10^(+4/20) ≈ 1.228 В
   ```
2. **dBV (децибел відносно строго 1.0 В RMS):** опорне значення становить рівно один вольт (`V₀ = 1.000 В`).
   Стандартом для побутової та споживчої техніки (Hi-Fi підсилювачі, телевізори, роз'єми RCA) є номінальний рівень **`−10 dBV`**:
   ```
   V_rms = 1.0 · 10^(−10/20) ≈ 0.3162 В
   ```

Різниця між професійним та споживчим стандартами виражається строгим числовим співвідношенням:

```
L_dBu = L_dBV + 20 · log₁₀( 1.0 / 0.7746 ) = L_dBV + 2.218 дБ
```

Звідси номінальний споживчий рівень `−10 dBV` у шкалі `dBu` становить `−10 + 2.218 = −7.78 dBu`. Зсув між професійним обладнанням (`+4 dBu`) та побутовим (`−7.78 dBu`) дорівнює `11.78 дБ`.

#### Шкала dBFS (цифрова повна шкала АЦП і ЦАП)

У цифровій обробці сигналів (DSP) значення аудіовідліків обмежені розрядністю перетворювача (наприклад, від `-32768` до `+32767` для 16-бітного звуку або від `-1.0` до `+1.0` для чисел із плаваючою комою).

Шкала **dBFS** (англ. *Decibels relative to Full Scale*) встановлює нульовий рівень `0 dBFS` як абсолютний цифровий максимум перетворювача. Усі робочі значення в цій шкалі є суто від'ємними (`−6 dBFS`, `−18 dBFS`, `−60 dBFS`). Будь-яка спроба перевищити `0 dBFS` призводить до миттєвого зрізання верхівок синусоїди (жорсткого цифрового кліпінгу) та появи різких непарних гармонік спотворення.

У професійному телерадіомовленні та студійному звукозапису встановлюється нормативний запас за перевантаженням (*Headroom*): аналоговий номінальний рівень `+4 dBu` калібрується на рівень **`−18 dBFS`** (європейський стандарт EBU R68) або **`−20 dBFS`** (американський стандарт SMPTE RP155). Це гарантує, що несподівані динамічні сплески сигналу не спричинять цифрового спотворення запису.

Повний зведений довідник усіх стандартизованих суфіксів (dBµV, dBW, dBi, dBc, LUFS) та нормативні таблиці їх застосування наведено у вставці [📋 Стандартні опорні рівні, одиниці та вагові фільтри в акустиці й радіотехніці](root:ph-waves/riven-u-detsybelakh/api-acoustic-levels.md).

### 4. Рівень звукового тиску (SPL) та акустична шкала

В акустиці звукова хвиля створює в повітрі мікроскопічні коливання тиску навколо середнього атмосферного тиску `P_atm ≈ 101 325 Па`. Змінна частина тиску називається **акустичним (звуковим) тиском** `p(t)`.

Оскільки середнє значення змінного тиску за повний період коливання дорівнює нулю, мірою інтенсивності звуку виступає його середньоквадратичне значення (RMS, лат. *radix media quadratica*):

```
p_rms = √( (1 / T) · ∫ p²(t) dt )
```

#### Опорний поріг чутності p₀

Міжнародним стандартом ISO 1683 для повітряного середовища встановлено опорний звуковий тиск:

```
p₀ = 20 мкПа = 20 · 10⁻⁶ Па = 2 · 10⁻⁵ Па
```

Ця величина відповідає середньому порогу чутності здорового вуха молодої людини на частоті максимальної чутливості 1000 Гц. Тиск `20 мкПа` створює на барабанній перетинці силу всього у кілька піконьютонів, що зміщує молекули повітря на відстань, меншу за діаметр атома водню!

Формула **рівня звукового тиску** (англ. *Sound Pressure Level*, **SPL**):

```
L_p = 20 · log₁₀( p_rms / p₀ ) = 20 · log₁₀( p_rms / (20·10⁻⁶ Па) )  [дБ SPL]
```

Опорна інтенсивність звуку (густина потоку акустичної потужності) у повітрі становить `I₀ = 10⁻¹² Вт/м²` (1 піковат на квадратний метр).

![Шкала рівнів звукового тиску та фізичні еквіваленти](/root/sci/ph-waves/riven-u-detsybelakh/img/sound-pressure-level-scale.svg)
*Діапазон сприйняття звуку людиною: від опорного порогу чутності 0 дБ SPL (20 мкПа) до больового порогу 130 дБ SPL (63.2 Па) та миттєвої акустичної травми 140 дБ SPL (200 Па).*

#### Некогерентне додавання джерел звуку

Якщо в приміщенні одночасно працюють два однакових некорельованих верстати, кожен із яких створює шум `80 дБ SPL`, сумарний рівень шуму становитиме не `160 дБ`, а лише **`83 дБ SPL`**.

Оскільки взаємна фаза хвиль від незалежних джерел змінюється хаотично, їхні звукові тиски підсумовуються енергетично (через суму середніх квадратів):

```
p_total² = p₁² + p₂²                          [енергетичне підсумовування квадратів тиску]
L_total = 10 · log₁₀( 10^(80/10) + 10^(80/10) ) [переведення рівнів у лінійні потужності]
= 10 · log₁₀( 2 · 10⁸ )                        [додавання однакових доданків: 10⁸ + 10⁸ = 2·10⁸]
= 80 + 10 · log₁₀(2)                           [розклад логарифма добутку]
= 83.01 дБ SPL                                 [обчислення десяткового логарифма 2: 10 · 0.30103]
```

Щоб збільшити рівень шуму на `10 дБ` (що сприймається людиною як подвоєння гучності), кількість однакових некогерентних джерел необхідно збільшити у **10 разів** (`80 дБ + 10 дБ = 90 дБ` від десяти верстатів).

### 5. Частотна корекція та психоакустика: криві A, B, C та Z

Людське вухо має неоднакову чутливість до різних частот. У 1933 році американські акустики Гарві Флетчер (англ. *Harvey Fletcher*) та Вейлдон Менсон (англ. *Wildon A. Munson*) експериментально виміряли сімейство **кривих рівної гучності** (англ. *Equal-Loudness Contours*), які згодом були стандартизовані у нормативі ISO 226.

На низьких частотах (20–100 Гц) чутливість слуху різко падає: чистий тон частотою 30 Гц стає ледь чутним лише при рівні близько `60 дБ SPL` (`0.02 Па`), тоді як на частоті 3000 Гц поріг чутності становить близько `−3 дБ SPL` (вухо надзвичайно чутливе через природний акустичний резонанс слухового каналу).

![Стандартизовані вагові криві сприйняття звуку](/root/sci/ph-waves/riven-u-detsybelakh/img/frequency-weighting-curves.svg)
*Частотні характеристики вагових фільтрів IEC 61672-1: крива A повторює нелінійність вуха при низьких рівнях гучності (40 фон), різко послаблюючи низькі частоти, крива C є майже пласкою, а крива Z має нульову корекцію.*

Для об'єктивного вимірювання шуму за допомогою приладів (шумомірів) було введено стандартизовані вагові частотні фільтри (IEC 61672-1):

#### Фільтр A-weighting (позначення dBA або дБА)

Фільтр A є інвертованою кривою рівної гучності на рівні 40 фон (рівень тихої розмови). Він різко послаблює низькі частоти (на частоті 20 Гц ослаблення становить `-50.5 дБ`, на 100 Гц — `-19.1 дБ`), проходить через нуль на частоті 1 кГц (`0.0 дБ`) і має невеликий підйом `+1.2 дБ` у діапазоні 2–4 кГц.

Шкала **dBA** є загальноприйнятим світовим стандартом для санітарно-гігієнічної оцінки виробничого, транспортного та побутового шуму, оскільки вона найточніше корелює з ризиком ураження слухового апарату людини.

#### Фільтр C-weighting (позначення dBC або дБС)

При високих рівнях звуку (понад 100 дБ SPL) чутливість людського вуха вирівнюється по всьому частотному діапазону. Фільтр C моделює криву сприйняття на рівні 100 фон і має практично пласку АЧХ від 31.5 Гц до 8 кГц (спад на 20 Гц становить лише `-6.2 дБ`).

Шкала **dBC** використовується для вимірювання низькочастотного технологічного гулу (двигуни суден, компресорні станції), пікових ударних шумів, вибухів та контролю басової складової концертних акустичних систем.

#### Фільтр Z-weighting (позначення dBZ або дБZ)

Лінійний фільтр (англ. *Zero-weighting*), який має строго пласку амплітудно-частотну характеристику (`0.0 дБ`) у смузі від 10 Гц до 20 кГц із допуском `±1.5 дБ`. Застосовується для точних наукових та інженерних вимірювань фізичного звукового поля.

### 6. Програмні алгоритми логарифмічних перетворень та DSP

У сучасних мікропроцесорних шумомірах та аудіоінтерфейсах цифрова обробка звукового сигналу виконується за стандартизованим конвеєром:

1. **Нормалізація вибірок АЦП:** перетворення цілочисельного коду мікрофона у миттєвий звуковий тиск `p[n]` у Паскалях на основі заводського калібрувального коефіцієнта чутливості (наприклад, `-26 dBFS/Pa`);
2. **Цифрова фільтрація A/C:** пропускання масиву вибірок через каскад із трьох цифрових біквадратних секцій другого порядку (IIR Biquad), розрахованих методом білінійного z-перетворення аналогового прототипу;
3. **Експоненційне часове усереднення (Fast / Slow):** розрахунок ковзного середньоквадратичного значення квадрата тиску з часовою сталою `τ = 125 мс` (Fast) або `τ = 1000 мс` (Slow);
4. **Логарифмування:** перетворення результуючого тиску в децибели `L_p = 20 · log₁₀(p_rms / 20·10⁻⁶)`.

Повну програмну реалізацію фільтрів A-weighting, експоненційного детектора та швидких апроксимацій логарифма на C та ідіоматичному C++ наведено у практичній вставці [⚙️ Програмний модуль децибельних розрахунків, зважування A/C та обробки SPL](root:ph-waves/riven-u-detsybelakh/proj-decibel-dsp.md).

Нижче показано базовий приклад перетворення напруги та розрахунку SPL на мовах C та C++:

:::tabs
```c
#include <math.h>
#include <stdio.h>

#define P0_SPL_PA 20.0e-6
#define V0_DBU    0.7745966692

/* Розрахунок рівня звукового тиску в дБ SPL */
double calculate_spl(double p_rms_pa) {
    if (p_rms_pa <= 0.0) return -INFINITY;
    return 20.0 * log10(p_rms_pa / P0_SPL_PA);
}

/* Розрахунок рівня напруги в dBu */
double voltage_to_dbu(double v_rms) {
    if (v_rms <= 0.0) return -INFINITY;
    return 20.0 * log10(v_rms / V0_DBU);
}

int main(void) {
    double p_talk = 0.02; /* 0.02 Па = 20 мПа (розмова) */
    double v_line = 1.228; /* 1.228 В (+4 dBu) */

    printf("Звуковий тиск %.3f Па = %.2f дБ SPL\n", p_talk, calculate_spl(p_talk));
    printf("Напруга %.3f В = %.2f dBu\n", v_line, voltage_to_dbu(v_line));
    return 0;
}
```
```cpp
#include <cmath>
#include <iostream>
#include <limits>

namespace acoustics {

inline constexpr double p0_spl_pa = 20.0e-6;
inline constexpr double v0_dbu    = 0.7745966692;

[[nodiscard]] constexpr double calculate_spl(double p_rms_pa) noexcept {
    if (p_rms_pa <= 0.0) {
        return -std::numeric_limits<double>::infinity();
    }
    return 20.0 * std::log10(p_rms_pa / p0_spl_pa);
}

[[nodiscard]] constexpr double voltage_to_dbu(double v_rms) noexcept {
    if (v_rms <= 0.0) {
        return -std::numeric_limits<double>::infinity();
    }
    return 20.0 * std::log10(v_rms / v0_dbu);
}

} // namespace acoustics

int main() {
    constexpr double p_talk = 0.02; // 0.02 Па = 20 мПа (розмова)
    constexpr double v_line = 1.228; // 1.228 В (+4 dBu)

    std::cout << "Звуковий тиск " << p_talk << " Па = " 
              << acoustics::calculate_spl(p_talk) << " дБ SPL\n";
    std::cout << "Напруга " << v_line << " В = " 
              << acoustics::voltage_to_dbu(v_line) << " dBu\n";
    return 0;
}
```

### 7. Інженерні підводні камені та типові помилки розрахунків

Робота з логарифмічними величинами вимагає строгого дотримання фізичних меж застосування формул. Найбільш поширеними помилками в інженерній практиці є:

1. **Плутанина множників 10 та 20:** Застосування коефіцієнта 20 до енергетичних спектрів (наприклад, до спектральної густини потужності PSD, Вт/Гц) або коефіцієнта 10 до напруги АЦП.
   * *Правило:* якщо величина квадратична за фізичною суттю (потужність, енергія, дисперсія `σ²`, інтенсивність) — множник **10**; якщо лінійна (тиск, напруга, струм, амплітуда переміщення) — множник **20**.
2. **Арифметичне додавання децибелів:** Спроба складати рівні шуму як лінійні числа (`85 дБ + 85 дБ = 170 дБ`). Децибели можна додавати суто як енергії через логарифм суми експонент.
3. **Ігнорування різниці імпедансів:** Прямий перерахунок напруг у децибели потужності без урахування опору ланцюга. Напруга 1.0 В на опорі 50 Ом виділяє потужність `20 мВт` (`+13 dBm`), тоді як та сама напруга 1.0 В на опорі 600 Ом виділяє лише `1.67 мВт` (`+2.2 dBm`).
4. **Неправильне тлумачення пік-фактора у цифровій шкалі dBFS:** Синусоїдальний сигнал з піком `0 dBFS` має потужність `−3.01 dBFS RMS`. Прямокутний меандр із піком `0 dBFS` має потужність `0.0 dBFS RMS`. При калібруванні АЦП за різними типами сигналів нерозуміння пік-фактора призводить до систематичної похибки вимірювання у 3 дБ.
