# 📋 Інтерфейс та специфікація типів розрахунку добротності (Q-Factor API)

Ця довідкова вставка містить детальний програмний контракт, специфікацію типів даних, межі застосовності та порівняльні специфікації добротності для різноманітних фізичних систем: від механічних демпферів до оптичних та надпровідних резонаторів.

## 1. Повний порівняльний аналіз добротностей у фізичних системах

Добротність `Q` є безрозмірним індикатором ефективності збереження енергії. Нижче наведено розширений порівняльний аналіз робочих частот `f₀`, типових значень добротності `Q`, ключових фізичних механізмів втрат та часових констант згасання `τ = Q / (π f₀)` для найпоширеніших резонаторів у фізиці та інженерії.

| Фізична система | Робоча частота `f₀` | Діапазон `Q` | Головний механізм втрат | Час згасання `τ` |
|---|---|---|---|---|
| **Автомобільний амортизатор** | `1 … 3 Гц` | `1.2 … 2.5` | В'язке тертя мастила у поршні | `0.1 … 0.5 с` |
| **Акустичний струнний інструмент** | `100 … 1000 Гц` | `100 … 800` | Випромінювання звукових хвиль, внутрішнє тертя дерева | `0.1 … 2 с` |
| **Електричний LC-контур** | `100 кГц … 100 МГц` | `30 … 300` | Омичний опір провідників, поверхневий скін-ефект | `10 … 500 мкс` |
| **Кварцовий резонатор (AT-cut)** | `1 … 50 МГц` | `10⁴ … 5×10⁵` | Термоеластична дисипація (TED), акустичне витікання | `1 … 100 мс` |
| **MEMS-кремнієвий резонатор** | `10 кГц … 1 МГц` | `10⁴ … 10⁷` | Термоеластичні втрати, опір залишкового газу | `0.1 … 100 с` |
| **НВЧ надпровідний резонатор** | `1 … 10 ГГц` | `10⁹ … 10¹¹` | Поверхневий опір куперівських пар, магнітні флюксоїди | `0.1 … 10 с` |
| **Оптичний мікрорезонатор (WGM)** | `200 ТГц (1.5 мкм)` | `10⁸ … 10¹²` | Поглинання в матеріалі, шероховатість поверхні | `0.1 … 10 мкс` |

### Деталізований фізичний розбір крайових режимів

Розглянемо фізичні особливості поведінки математичного ядра при обробці граничних та нетипових режимів роботи в симуляторах та вимірювальних приладах:

1. **Низька добротність (`Q < 0.5`, перезагашений режим):**
   При `Q < 0.5` (що відповідає безрозмірному коефіцієнту загасання `ζ > 1`) система взагалі втрачає коливальний характер руху. Диференціальне рівняння не має уявних коренів, і відгук перетворюється на аперіодичний спад двох експонент. Поняття смуги резонансу `Δf = f₀ / Q` та логарифмічного декременту втрачають фізичний зміст. Обчислювальне ядро повертає статус `Q_STATUS_OVERDAMPED` та виставляє прапор попередження.

2. **Надвисока добротність (`Q > 10⁸`):**
   Для кварцових, надпровідних та оптичних резонаторів час згасання `τ` вимірюється секундами або хвилинами (мільйони чи мільярди періодів). При обчисленні огинаючої `e^(−π f₀ t / Q)` стандартні 32-бітні числа з плаваючою комою (`float`) швидко втрачають точність під час накопичення фази. Для запобігання втраті значущих розрядів обчислення вимагають використання 64-бітних (`double`) або 80-бітних чисел.

3. **Нелінійність добротності (залежність від амплітуди):**
   У реальних матеріалах при великих амплітудах виникає дисипація за законом Дюїнґа або насичення магнітного осердя. У таких випадках добротність не є сталою величиною і виражається як функція амплітуди `Q(A)`.

## 2. Архітектура програмного модуля та обробка помилок

Обчислювальний модуль розрахунку добротності розроблено з урахуванням сучасних вимог до надійності вбудованого ПЗ, симуляційних ядер та автоматизованих тестових стендів. Модуль працює у строго детермінованому режимі без динамічного виділення пам'яті.

Вхідні параметри проходять триступеневу валідацію:
- **Перевірка фізичної допустимості:** Маса, жорсткість, індуктивність, ємність та опір повинні бути strictly додатними величинами (`> 0`). Передачі нульових або від'ємних значень перехоплюються на рівні вхідного контракту, повертаючи відповідну помилку `INVALID_PARAMETER` або `std::unexpected`.
- **Розрахунок коефіцієнта загасання:** Модуль автоматично вираховує безрозмірний коефіцієнт демпфування `ζ = 1 / (2Q)`. Якщо обчислений коефіцієнт вказує на відсутність осциляцій (`ζ >= 1`), повертається статус аперіодичного руху та нульовий час експоненційного згасання.
- **Чисельна перевірка переповнення:** При роботі з високочастотними оптичними резонаторами (`f₀ > 10¹⁴ Гц`) значення степенів експонент перевіряються на вихід за межі представлення типом `double`.

Крім того, модуль надає допоміжні функції перерахунку між різними представленнями втрат: переведення добротності `Q` в логарифмічний декремент `δ = π / Q`, кут діелектричних втрат `tan δ = 1 / Q`, та ширину смуги половинної потужності `Δf = f₀ / Q`.

## 3. Деталізована специфікація вхідних і вихідних полів API

Для забезпечення високої надійності програмної інтеграції нижче наведено вичерпний розбір полів структур даних API:

### Поля структури `q_mech_params_t` (Механічний домен)
- **`mass_kg` (`double`):** Інертна маса осцилятора у кілограмах (кг). Вимагається `mass_kg > 0.0`. Малі значення (наприклад, у MEMS `10⁻⁹ кг`) передаються без втрати точності.
- **`stiffness_nm` (`double`):** Пружна жорсткість зв'язку у ньютонах на метр (Н/м). Вимагається `stiffness_nm > 0.0`.
- **`damping_c_nsm` (`double`):** Коефіцієнт в'язкого тертя демпфера у ньютон-секундах на метр (Н·с/м). Визначає силу опору `F = −c·v`.

### Поля структури `q_el_params_t` (Електричний домен)
- **`resistance_ohm` (`double`):** Активний опір втрат у омах (Ом). У послідовній схемі відповідає `R_loss`, у паралельній — `R_p`.
- **`inductance_henry` (`double`):** Індуктивність котушки у генрі (Гн).
- **`capacitance_farad` (`double`):** Ємність конденсатора у фарадах (Ф).

### Поля вихідної структури `q_result_t`
- **`q_factor` (`double`):** Обчислена безрозмірна добротність `Q`.
- **`f0_hz` (`double`):** Резонансна частота системи у герцах (Гц).
- **`bandwidth_3db_hz` (`double`):** Ширина смуги пропускання за рівнем −3 дБ (`Δf = f₀ / Q`).
- **`damping_ratio_zeta` (`double`):** Безрозмірний коефіцієнт демпфування `ζ = 1 / (2Q)`.
- **`decay_time_tau_sec` (`double`):** Часова константа експоненційного спаду амплітуди `τ = Q / (π f₀)`.
- **`status` (`q_status_t`):** Перелічуваний код результату виконання розрахунку (`Q_STATUS_OK`, `Q_STATUS_OVERDAMPED` тощо).

## 4. Практичні рекомендації з вибору типу розрахунку та інтеграції

При проектуванні симуляційних систем розробник має вибирати функцію API залежно від доступних фізичних даних:

1. **Якщо відома геометрія та фізичні деталі (маса, пружина, опір):**
   Використовуйте функції `q_calc_mechanical()`, `q_calc_electrical_series()` або `q_calc_electrical_parallel()`. Вони виконують прямий розрахунок власної частоти та добротності з компонентів.

2. **Якщо відома термодинаміка чи Чисельне розсіювання енергії за період:**
   Використовуйте універсальну функцію `q_calc_from_energy()`. Вона приймає запасену енергію `W` та дисиповану енергію `ΔW_цикл`, обчислюючи `Q = 2π W / ΔW_цикл`. Цей метод є єдиним можливим при скінченноелементному аналізі (FEM / ANSYS / COMSOL), де з модального розрахунку відомі поля напружень та теплові втрати.

3. **Гарантії швидкодії та пам'яті:**
   Усі функції API гарантовано не виконують викликів `malloc()` або `new`, мають постійний час виконання `O(1)` та є повністю безпечними для потоків (*thread-safe*).

## 5. Обчислення енергетичної добротності та граничні випадки

Функція `q_calc_from_energy()` розраховує добротність безпосередньо з балансу енергій. Вона приймає два значення: `w_stored_joules` (запасену енергію `W`) та `w_lost_per_cycle_joules` (втрачену енергію за один період `ΔW`).

Якщо передана втрачена енергія дорівнює нулю або є від'ємною (`ΔW <= 0`), що фізично відповідає неможливій системі з від'ємним згасанням або генератором без джерела накачування, функція повертає помилку `Q_STATUS_INVALID_PARAM`.

Якщо втрачена енергія перевищує запасену в `2π` разів (`ΔW >= 2π W`), добротність падає нижче одиниці (`Q < 1.0`). У разі `ΔW >= 4π W` (що відповідає `Q <= 0.5`) осцилятор потрапляє у критичний або перезагашений режим. Обчислювальне ядро виставляє статус `Q_STATUS_OVERDAMPED` та повертає нульовий час експоненційного дзвону.
