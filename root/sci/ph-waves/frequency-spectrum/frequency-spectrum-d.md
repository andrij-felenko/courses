# Частотний спектр

<preknowlist>
- [Синусоїда](root:ph-waves/sine-wave) — чиста гармонічна хвиля однієї частоти, базовий елемент лінійних коливань.
- [Амплітуда й частота](root:ph-waves/amplitude-frequency) — базові параметри періодичного процесу: розмах та темп повторення.
- [Суперпозиція хвиль](root:ph-waves/wave-superposition) — принцип додавання коливань у лінійних середовищах.
- [Фаза](root:ph-waves/phase) — положення точки на циклі коливання та часовий зсув між процесами.
</preknowlist>

Датчик вібрації, встановлений на корпусі промислового турбоагрегату, видає складний електричний сигнал: на екрані осцилографа видно заплутану зубчасту криву з розмахом амплітуди до 12 g та гострими хаотичними сплесками. Дивлячись лише на зміщення в часі, неможливо з'ясувати, що саме відбувається всередині машини: чи це дисбаланс масивного ротора на частоті обертання 50 Гц, чи зношування зубців редуктора на частоті зачеплення 1250 Гц, чи локальний відкол на внутрішньому кільці кулькового підшипника, що генерує мікроудари з частотою 382 Гц. У часовій області всі ці процеси щомиті накладаються в одне сумарне число, маскуючи фізичну причину неполадки.

Щоб локалізувати дефект або відфільтрувати сигнал, сумарне коливання необхідно розкласти на елементарні фізичні складові — чисті синусоїди, кожна з яких має власну незмінну частоту, амплітуду та початкову фазу. Цей розклад перетворює заплутану часову форму на набір чітких стовпчиків, де кожна механічна деталь чи радіостанція постає на власній позиції. Перехід від часової картини до частотного вмісту становить фундамент хвильової фізики, акустики, радіотехніки та квантової теорії.

## Фізичний зміст спектра та базис гармонік

Будь-який коливальний процес, що розгортається в часі, можна описати функцією зміщення `x(t)`. Проте в лінійних фізичних середовищах — пружних струнах, акустичних резонаторах, електричних LC-контурах чи оптичних хвилеводах — різні форми коливань поводяться принципово неоднаково.

Чому базисом для розкладу складних процесів обрано саме синусоїдальні функції? Причина полягає в фундаментальній властивості лінійних стаціонарних систем (LTI — Linear Time-Invariant). Лінійне диференціальне рівняння руху з постійними коефіцієнтами:

```
m·(d²x / dt²) + γ·(dx / dt) + k·x = f(t)
```

має гармонічні експоненти `e^{i ω t}` (а отже, `sin(ω t)` та `cos(ω t)`) своїми **власними функціями**. Якщо на вхід такої системи подати синусоїдальний сигнал частоти `ω`, на виході в усталеному режимі завжди виникає синусоїда **тієї самої частоти** `ω` — змінюються винятково її амплітуда та початкова фаза. Жодна інша форма хвилі цією властивістю не володіє: прямокутний імпульс або трикутна хвиля при проходженні крізь резонатор спотворюють свій профіль до невпізнання, оскільки їхні складові зазнають різного підсилення та фазового зсуву.

![Ліворуч — зубчаста хвиля в часі; праворуч — той самий сигнал як три вертикальні стовпчики на частотах f, 2f, 3f, заввишки 1, 0.5, 0.3](/root/sci/ph-waves/frequency-spectrum/img/time-vs-freq.svg)
*Два погляди на один фізичний процес: форма хвилі в часі фіксує миттєве зміщення, а частотний спектр розкриває внутрішню структуру амплітуд і гармонік.*

Розклад періодичного коливання на суму гармонічних коливань називають **частотним спектром** (лат. *spectrum* — образ, видиво). Кожна окрема синусоїдальна складова зветься **гармонікою** (гр. *harmonikos* — співзвучний, злагоджений). Найнижча частота повторення `f₀ = 1 / T₀`, де `T₀` — період повного коливання, є **основною частотою** (або першою гармонікою), а складові з частотами `2f₀, 3f₀, 4f₀, ...` — вищими гармоніками або обертонами.

### Тригонометричний ряд Фур'є

Жозеф Фур'є 1822 року математично довів, що будь-яку періодичну функцію `x(t) = x(t + T₀)`, яка задовольняє умови Діріхле (має скінченну кількість розривів першого роду та скінченну кількість екстремумів на періоді, а також є абсолютно інтегровною), можна подати у вигляді нескінченної тригонометричної суми:

```
x(t) = (a₀ / 2) + ∑_{n=1}^∞ [aₙ·cos(n·ω₀·t) + bₙ·sin(n·ω₀·t)]
```

де `ω₀ = 2π / T₀ = 2π·f₀` — основна кругова частота коливання.

Знаходження амплітудних коефіцієнтів `a₀, aₙ, bₙ` спирається на **ортогональність** (гр. *orthogonios* — прямокутний) тригонометричної системи функцій на інтервалі періоду `[0, T₀]`. Інтеграл добутку двох гармонік різних частот `n ≠ m` тотожно обнуляється:

```
∫₀^{T₀} cos(n·ω₀·t)·cos(m·ω₀·t) dt = 0           [n ≠ m: взаємна ортогональність косинусів]
∫₀^{T₀} sin(n·ω₀·t)·sin(m·ω₀·t) dt = 0           [n ≠ m: взаємна ортогональність синусів]
∫₀^{T₀} cos(n·ω₀·t)·sin(m·ω₀·t) dt = 0           [для будь-яких цілих n і m]
```

Коли ж індекси збігаються (`n = m`), інтеграл квадрата синуса чи косинуса дає рівно половину періоду `T₀ / 2`:

```
∫₀^{T₀} cos²(n·ω₀·t) dt = ∫₀^{T₀} (1/2)·[1 + cos(2·n·ω₀·t)] dt
                        = (1/2)·T₀ + 0
                        = T₀ / 2                 [середнє значення cos² на періоді дорівнює 1/2]
```

Помноживши вихідне рівняння для `x(t)` на `cos(k·ω₀·t)` або `sin(k·ω₀·t)` та проінтегрувавши обидві частини по періоду, завдяки ортогональності всі доданки ряду, крім доданка з `n = k`, зникають:

```
a₀ = (2 / T₀) · ∫₀^{T₀} x(t) dt                  [подвоєна середня стала складова сигналу]
aₙ = (2 / T₀) · ∫₀^{T₀} x(t)·cos(n·ω₀·t) dt      [косинусна проекція n-ї гармоніки]
bₙ = (2 / T₀) · ∫₀^{T₀} x(t)·sin(n·ω₀·t) dt      [синусна проекція n-ї гармоніки]
```

Історично питання про те, чи розкладає людське вухо та фізичні прилади складний звук на такі гармоніки, викликало запеклі наукові дебати, які вирішили лише в другій половині XIX століття — про це детально розповідають [досліди Гельмгольца та суперечка про сприйняття тембру](root:ph-waves/frequency-spectrum/hist-helmholtz.md).

### Комплексна форма ряду Фур'є

За формулою Ейлера `e^{i·θ} = cos(θ) + i·sin(θ)` тригонометричний ряд записується в компактній експоненційній формі, яка усуває необхідність тримати окремо синуси та косинуси:

```
x(t) = ∑_{n=-∞}^∞ cₙ·e^{i·n·ω₀·t}
```

де комплексний спектральний коефіцієнт `cₙ` обчислюється через єдиний комплексний інтеграл:

```
cₙ = (1 / T₀) · ∫₀^{T₀} x(t)·e^{-i·n·ω₀·t} dt
```

Для дійсного фізичного сигналу `x(t)` коефіцієнти ряду задовольняють умову ермітової симетрії `c₋ₙ = cₙ*` (де `*` позначає комплексне спряження). Зв'язок між комплексною та тригонометричною формами однозначний:

```
c₀ = a₀ / 2                                      [стала складова]
cₙ = (aₙ - i·bₙ) / 2                             [для додатних частот n > 0]
c₋ₙ = (aₙ + i·bₙ) / 2                            [для від'ємних частот n < 0]
```

Поняття «від'ємної частоти» у комплексній формі — це математичний еквівалент обертання вектора на комплексній площині за годинниковою стрілкою. Сума двох взаємно спряжених векторів `cₙ·e^{i·n·ω₀·t} + c₋ₙ·e^{-i·n·ω₀·t}` завжди дає суто дійсне гармонічне коливання `aₙ·cos(n·ω₀·t) + bₙ·sin(n·ω₀·t)`.

## Амплітудний та фазовий спектри

Сума синуса та косинуса однакової частоти `aₙ·cos(n·ω₀·t) + bₙ·sin(n·ω₀·t)` являє собою одну зміщену синусоїду. Перетворимо її до канонічного вигляду «амплітуда — фаза»:

```
aₙ·cos(n·ω₀·t) + bₙ·sin(n·ω₀·t)
= √(aₙ² + bₙ²) · [ (aₙ / √(aₙ² + bₙ²))·cos(n·ω₀·t) + (bₙ / √(aₙ² + bₙ²))·sin(n·ω₀·t) ] [винесення амплітудного множника Aₙ]
= Aₙ · [ cos(φₙ)·cos(n·ω₀·t) + sin(φₙ)·sin(n·ω₀·t) ]                                   [заміна катетів на cos(φₙ) та sin(φₙ)]
= Aₙ · cos(n·ω₀·t - φₙ)                                                                [формула косинуса різниці аргументів]
```

Звідси випливають дві фундаментальні характеристики кожної гармоніки:
1. **Амплітуда гармоніки** `Aₙ`:

```
Aₙ = √(aₙ² + bₙ²) = 2·|cₙ|       [для n ≥ 1]
A₀ = a₀ / 2 = c₀                 [стала складова]
```

2. **Початкова фаза гармоніки** `φₙ`:

```
φₙ = arctan2(bₙ, aₙ) = -arg(cₙ)
```

Повний опис сигналу в частотній області складається з двох графіків:
- **Амплітудний спектр** показує розподіл амплітуд `Aₙ` за гармоніками (частотами `n·f₀`). Він визначає енергетичний внесок кожної складової та тембральне забарвлення хвилі.
- **Фазовий спектр** відображає початкові фази `φₙ` кожної гармоніки. Фазові співвідношення визначають точну форму сигналу в часі (наприклад, чи додаються піки гармонік синхронно, створюючи гострий імпульс, чи розмиті по періоду).

![Синтез меандру з гармонік та ефект Гіббса](/root/sci/ph-waves/frequency-spectrum/img/fourier-synthesis.svg)
*Послідовне додавання гармонік: 1-ша гармоніка задає гладкий контур; 3-тя, 5-та та 7-ма роблять вершину пласкою, а фронти крутими. Біля розривів виникає характерна пульсація Гіббса.*

### Дискретний спектр періодичних сигналів проти неперервного спектра імпульсів

Спектр періодичного процесу є **дискретним (лінійчастим)**: ненульові значення зосереджені винятково у вузьких точках — гармоніках `f = n·f₀`. Відстань між сусідніми спектральними лініями дорівнює частоті повторення:

```
Δf = 1 / T₀ = f₀
```

Що станеться зі спектром, якщо періодичний процес замінити одним поодиноким імпульсом тривалості `τ`? Фізично це еквівалентно спрямуванню періоду повторення до нескінченності: `T₀ → ∞`.

Коли період `T₀` зростає, основна частота `f₀ = 1 / T₀` зменшується, і спектральні лінії починають збігатися все щільніше. У границі `T₀ → ∞` крок сітки частот стає нескінченно малим `Δf → df`, дискретна сума Фур'є перетворюється на неперервний інтеграл, а дискретні коефіцієнти переходять у **спектральну густину амплітуди** `X(f)`:

```
X(f) = ∫_{-∞}^∞ x(t)·e^{-i·2π·f·t} dt            [пряме інтегральне перетворення Фур'є]
x(t) = ∫_{-∞}^∞ X(f)·e^{i·2π·f·t} df             [зворотне інтегральне перетворення Фур'є]
```

![Дискретний спектр періодичного сигналу та неперервний спектр імпульсу](/root/sci/ph-waves/frequency-spectrum/img/discrete-vs-continuous.svg)
*Зі зростанням періоду T₀ спектральні лінії ущільнюються під незмінною огинаючою sinc; для одиночного імпульсу (T₀ → ∞) дискретний гребінець переходить у суцільний неперервний спектр.*

Розмірність спектральної густини `X(f)` для одиночного імпульсу відрізняється від амплітуди періодичного сигналу: це амплітуда на одиницю смуги частот (наприклад, `В / Гц` або `Па·с`).

## Зв'язок форми сигналу в часі та ширини його спектра

Між властивостями сигналу в часовій області та поведінкою його спектра в частотній області існує суворий взаємозв'язок, що випливає з операцій математичного аналізу: гладкість сигналу визначає швидкість спадання гармонік, а тривалість імпульсу задає ширину смуги частот.

### Гладкість функції та швидкість спадання спектра

Швидкість, з якою коефіцієнти `aₙ, bₙ` спадають зі зростанням номера гармоніки `n → ∞`, безпосередньо вказує на ступінь гладкості функції `x(t)`. З інтегрування частинами:

```
cₙ = (1 / T₀) · ∫₀^{T₀} x(t)·e^{-i·n·ω₀·t} dt
   = [ x(t)·e^{-i·n·ω₀·t} / (-i·n·ω₀·T₀) ]₀^{T₀} + (1 / (i·n·ω₀·T₀)) · ∫₀^{T₀} x'(t)·e^{-i·n·ω₀·t} dt  [інтегрування частинами: u=x(t), dv=e^{-i·n·ω₀·t}dt]
```

Якщо функція `x(t)` має розриви першого роду (стрибки), перший доданок не обнуляється на границях розриву, даючи спадання порядку `1 / n`. Якщо функція неперервна, перший доданок зникає, і інтегрування повторюють для похідної `x'(t)`:

1. **Розрив функції `x(t)` (стрибки амплітуди: меандр, пилка):**
   Коефіцієнти гармонік спадають як `1 / n` (швидкість `-20 дБ / декада` або `-6 дБ / октава`). Спектр широкий, містить велику частку високочастотних складових.
2. **Функція неперервна, але її перша похідна `x'(t)` має розриви (злами форми: трикутна хвиля):**
   Коефіцієнти спадають як `1 / n²` (`-40 дБ / декада` або `-12 дБ / октава`). Енергія вищих гармонік спадає швидко.
3. **Функція має `k` неперервних похідних, а `(k+1)`-ша похідна зазнає розривів:**
   Спадання коефіцієнтів відбувається зі швидкістю `1 / n^{k+1}`.
4. **Нескінченно гладка функція (наприклад, гаусовий імпульс `x(t) = e^{-α·t²}`):**
   Спектр спадає швидше за будь-який поліном — експоненційно `X(f) ∝ e^{-β·f²}`.

![Гладкість сигналу в часі та швидкість спадання спектра](/root/sci/ph-waves/frequency-spectrum/img/shapes-spectra-comparison.svg)
*Порівняння трьох класів сигналів: розрив амплітуди формує спадання 1/n; розрив похідної дає 1/n²; гранично короткий імпульс дає нескінченний рівномірний спектр.*

### Аналітичний розбір канонічних форм

Розрахуємо точні коефіцієнти Фур'є для ключових фізичних сигналів:

#### 1. Симетричний прямокутний сигнал (меандр)
Розглянемо періодичний прямокутний сигнал амплітудою `±A` з періодом `T₀`, центрований так, що `x(t) = +A` при `t ∈ [0, T₀/2)` та `x(t) = -A` при `t ∈ [T₀/2, T₀)`.

Оскільки `x(-t) = -x(t)`, функція є непарною, тож усі косинусні коефіцієнти `aₙ = 0` та `a₀ = 0`.
Обчислимо синусні коефіцієнти `bₙ`:

```
bₙ = (2 / T₀) · [ ∫₀^{T₀/2} A·sin(n·ω₀·t) dt + ∫_{T₀/2}^{T₀} (-A)·sin(n·ω₀·t) dt ]  [розбиття інтеграла за півперіодами]
   = (2A / T₀) · [ (-cos(n·ω₀·t) / (n·ω₀)) |_{0}^{T₀/2} - (-cos(n·ω₀·t) / (n·ω₀)) |_{T₀/2}^{T₀} ]  [первісна від синуса]
   = (2A / (n·2π)) · [ (1 - cos(n·π)) - (cos(n·π) - cos(2n·π)) ]                      [підстановка меж інтегрування]
   = (A / (n·π)) · [ 1 - 2·cos(n·π) + 1 ]                                              [зведення подібних, cos(2nπ)=1]
   = (2A / (n·π)) · [ 1 - (-1)ⁿ ]                                                      [властивість cos(nπ)=(-1)ⁿ]
```

Аналіз виразу `1 - (-1)ⁿ`:
- Якщо `n` парне (`n = 2, 4, 6, ...`), то `(-1)ⁿ = 1`, звідки `bₙ = 0`.
- Якщо `n` непарне (`n = 1, 3, 5, ...`), то `(-1)ⁿ = -1`, звідки `bₙ = 4A / (n·π)`.

Ряд Фур'є меандру містить **винятково непарні гармоніки**:

```
x(t) = (4A / π) · [ sin(ω₀·t) + (1/3)·sin(3·ω₀·t) + (1/5)·sin(5·ω₀·t) + (1/7)·sin(7·ω₀·t) + ... ]
```

Амплітуда першої гармоніки становить `4A / π ≈ 1.273·A` (вона на 27.3% перевищує пікову висоту самого прямокутника), а відносні амплітуди спадають за гармонічним законом: `1, 1/3, 1/5, 1/7, 1/9, ...`.

#### 2. Ефект Гіббса на розривах
Якщо обірвати нескінченний ряд Фур'є меандру на скінченній кількості гармонік `N`, виникає хвилеподібна пульсація навколо точки розриву сигналу. Зі збільшенням `N` частота цих коливань зростає, вони притискаються ближче до стрибка, проте максимальна висота першого викиду **не прямує до нуля**.

Гранична амплітуда перельоту при `N → ∞` становить:

```
lim_{N→∞} x_N(t_max) = (2A / π) · ∫₀^π (sin(u) / u) du ≈ 1.17898·A
```

Висота викиду над полицею прямокутника дорівнює `1.17898·A - A = 0.17898·A`, що складає рівно **8.95%** від величини повного перепаду амплітуди `2A`. Це явище зветься **ефектом Гіббса**. Воно означає, що точкова збіжність ряду Фур'є біля розривів не є рівномірною: намагання передати ідеальний прямокутний перепад крізь систему зі скінченною смугою пропускання неминуче породжує викиди амплітуди та високочастотний брязкіт (англ. *ringing*).

#### 3. Симетрична трикутна хвиля
Для трикутного сигналу розмахом `±A`, що є неперервною функцією зі зламами, розклад Фур'є набуває вигляду:

```
x(t) = (8A / π²) · [ sin(ω₀·t) - (1/9)·sin(3·ω₀·t) + (1/25)·sin(5·ω₀·t) - (1/49)·sin(7·ω₀·t) + ... ]
```

Тут коефіцієнти спадають пропорційно квадрату номера гармоніки `1 / n²`. Третя гармоніка становить лише `1/9 ≈ 11.1%` від першої, а п'ята — лише `1/25 = 4.0%`. Через відсутність стрибків ефект Гіббса тут не виникає зовсім.

#### 4. Пилкоподібний сигнал
Пилкоподібна хвиля, що лінійно зростає від `-A` до `+A` протягом періоду `T₀` і миттєво спадає вниз, має несиметричний стрибок. Її розклад містить **всі без винятку гармоніки** (і парні, і непарні):

```
x(t) = (2A / π) · [ sin(ω₀·t) - (1/2)·sin(2·ω₀·t) + (1/3)·sin(3·ω₀·t) - (1/4)·sin(4·ω₀·t) + ... ]
```

Коефіцієнти спадають як `1 / n`, а наявність парних гармонік свідчить про відсутність півхвильової симетрії форми.

#### 5. Одиночний прямокутний імпульс та дельта-функція Дірака
Для поодинокого прямокутного імпульсу амплітуди `A` і тривалості `τ`, розташованого в інтервалі `[-τ/2, τ/2]`, інтеграл Фур'є обчислюється аналітично:

```
X(f) = ∫_{-τ/2}^{τ/2} A·e^{-i·2π·f·t} dt                               [означення перетворення Фур'є для прямокутника]
     = A · [ e^{-i·2π·f·t} / (-i·2π·f) ] |_{-τ/2}^{τ/2}                [первісна від комплексної експоненти]
     = A · [ e^{i·π·f·τ} - e^{-i·π·f·τ} ] / (i·2π·f)                   [підстановка симетричних меж -τ/2 та +τ/2]
     = A · [ 2i·sin(π·f·τ) ] / (i·2π·f)                                [формула Ейлера: e^{iu} - e^{-iu} = 2i·sin(u)]
     = A·τ · [ sin(π·f·τ) / (π·f·τ) ]                                  [виділення площі імпульсу A·τ та нормування аргументу]
     = A·τ · sinc(π·f·τ)                                               [означення функції sinc(u) = sin(u)/u]
```

Спектральна густина описується кардинальним синусом `sinc(u) = sin(u) / u`. Центральний пік на нульовій частоті дорівнює площі імпульсу `X(0) = A·τ`. Спектр уперше перетинає нуль у точках, де аргумент синуса дорівнює `±π`:

```
π·f·τ = ±π  ⇒  f = ± 1 / τ
```

Ширина головного пелюстка спектра за першими нулями становить `Δf = 2 / τ`. Звідси випливає класичне **співвідношення невизначеності** для коливань та хвиль:

```
Δt · Δf ≈ 1
```

Чим коротший імпульс у часовій області (`Δt` мале), тим ширший діапазон частот займає його спектр (`Δf` велике), і навпаки: монохроматичний сигнал нескінченної тривалості (чистий синус) займає нескінченно вузьку смугу — одну частотну точку.

Граничним випадком є **дельта-імпульс Дірака** `δ(t)` — математична модель нескінченно вузького сплеску нескінченної висоти з одиничною площею: `∫_{-∞}^∞ δ(t) dt = 1`. Його спектральна густина дорівнює константі на всіх частотах:

```
X_δ(f) = ∫_{-∞}^∞ δ(t)·e^{-i·2π·f·t} dt = e^0 = 1
```

Дельта-імпульс містить абсолютно всі частоти Всесвіту з однаковою амплітудною густиною та нульовою фазою. Саме тому короткий удар молотка по механічній конструкції збуджує в ній одночасно всі власні коливальні моди (резонанси), дозволяючи виміряти весь спектр власних частот системи за один відгук.

## Енергетика коливань та інженерне застосування

Перехід між часовою та частотною областями зберігає фундаментальні фізичні інваріанти, передусім повну енергію системи.

### Теорема Парсеваля (енергетичний баланс)

Згідно з теоремою Парсеваля, середня потужність періодичного коливання, обчислена шляхом інтегрування квадрата сигналу за часом, тотожно дорівнює сумі потужностей усіх окремих спектральних гармонік:

```
P = (1 / T₀) · ∫₀^{T₀} x²(t) dt                       [середня потужність сигналу в часовій області]
  = (a₀ / 2)² + (1/2) · ∑_{n=1}^∞ (aₙ² + bₙ²)         [ортогональність тригонометричного ряду Фур'є]
  = ∑_{n=-∞}^∞ |cₙ|²                                  [сума квадратів модулів у комплексній формі]
```

Для неперіодичного імпульсу з неперервним спектром виконується інтегральна рівність Релея:

```
E = ∫_{-∞}^∞ |x(t)|² dt = ∫_{-∞}^∞ |X(f)|² df
```

Величину `|X(f)|²` називають **спектральною густиною енергії** (англ. *Energy Spectral Density* — ESD), а для стаціонарних випадкових процесів — **спектральною густиною потужності** (англ. *Power Spectral Density* — PSD). Теорема Парсеваля гарантує, що жоден перерозподіл енергії між частотами не здатний змінити сумарний енергетичний баланс лінійного процесу.

### Лінійна фільтрація у спектральному представленні

У часовій області дія лінійного фільтра або коливального середовища на сигнал описується складною операцією згортки з імпульсною характеристикою `h(t)`: `y(t) = ∫ x(τ)·h(t - τ) dτ`.

У частотній області, за теоремою про згортку, ця операція спрощується до звичайного **поточкового множення**:

```
Y(f) = H(f) · X(f)
```

де `H(f) = |H(f)|·e^{i·θ(f)}` — комплексна частотна передавальна характеристика фільтра:
- Модуль `|H(f)|` зветься амплітудно-частотною характеристикою (АЧХ) і показує коефіцієнт підсилення чи послаблення кожної частоти.
- Аргумент `θ(f)` зветься фазо-частотною характеристикою (ФЧХ) і задає фазовий зсув, що накладається на кожну гармоніку.

![Лінійна фільтрація та нелінійні гармонічні спотворення](/root/sci/ph-waves/frequency-spectrum/img/filtering-and-thd.svg)
*Зліва: лінійний фільтр послаблює гармоніки за передавальною кривою H(f), не створюючи нових ліній. Справа: нелінійність підсилювача спотворює чистий синус, породжуючи гармоніки 2f₁, 3f₁ та спотворення THD.*

Лінійні фільтри поділяють за їхньою дією у спектрі:
- **Фільтр низьких частот (ФНЧ):** пропускає гармоніки нижче частоти зрізу `f_c` та пригнічує високочастотний шум.
- **Фільтр високих частот (ФВЧ):** відсікає постійну складову та повільні дрейфи.
- **Смуговий фільтр:** виділяє окрему спектральну смугу (наприклад, канал радіоприймача).
- **Режекторний (загороджувальний) фільтр:** вирізає одну заваду (наприклад, наведення електромережі 50 Гц або 60 Гц).

### Нелінійні спотворення та коефіцієнт гармонік (THD)

Якщо середовище або тракт обробки сигналу втрачає лінійність (наприклад, підсилювач заходить у режим насичення або пружина підвісу деформується поза межами закону Гука), виникають **нелінійні спотворення**.

Нехай передавальна характеристика ланки має слабку нелінійність: `y(t) = α·x(t) + β·x²(t) + γ·x³(t)`. Якщо на вхід подати ідеально чистий гармонічний сигнал `x(t) = A·cos(ω₁·t)`, на виході виникнуть додаткові спектральні складові:

```
x²(t) = A²·cos²(ω₁·t) = (A²/2) · [1 + cos(2·ω₁·t)]       [поява постійної складової та 2-ї гармоніки]
x³(t) = A³·cos³(ω₁·t) = (A³/4) · [3·cos(ω₁·t) + cos(3·ω₁·t)] [підсилення 1-ї та поява 3-ї гармоніки]
```

Чистий одночастотний сигнал після проходження нелінійної ланки «обростає» шлейфом паразитичних вищих гармонік на кратних частотах `2f₁, 3f₁, 4f₁, ...`.

Кількісним мірилом чистоти тракту є **коефіцієнт гармонійних спотворень** (THD — Total Harmonic Distortion):

```
THD = √( A₂² + A₃² + A₄² + ... ) / A₁
```

де `A₁` — амплітуда основної гармоніки, а `A₂, A₃, ...` — амплітуди вищих паразитичних гармонік.

У практичній інженерії [коефіцієнт гармонічних спотворень (THD)](root:hw-analog/harmonic-distortion) часто виражають у відсотках або переводять у [децибели](root:hw-analog/decibels): `THD_{дБ} = 20·log₁₀(THD)`. Високоякісні звукові підсилювачі мають THD < 0.01% (-80 дБ), тоді як перевантажений тракт може видавати THD > 10% (-20 дБ), що сприймається вухом як хрип і різке металеве забарвлення звуку.

> 🔧 **Навіщо це.** Спектральний аналіз усуває необхідність вгадувати причину фізичного явища. В акустиці та аудіотехніці спектр дає змогу вирівняти АЧХ приміщення за допомогою параметричного еквалайзера. У вібродіагностиці машин поява лінії на частоті обертання сепаратора підшипника свідчить про руйнування вузла за місяці до його аварійної зупинки. У радіозв'язку спектральний розподіл дозволяє ущільнювати сотні незалежних каналів в одному кабелі чи ефірі (FDM/OFDM). В оптиці спектр поглинання зірок розкриває їхній хімічний склад на відстані мільйонів світлових років.

Практичні тонкощі обчислення спектра, вибору часових вікон та усунення спектрального витоку розкрито у вставці про [швидке перетворення Фур'є (FFT)](root:ph-waves/frequency-spectrum/proj-fft-spectrum.md).

## Дискретний розрахунок спектра на C та C++

Для оцифрованого сигналу, поданого масивом із `N` дискретних відліків `x[0], x[1], ..., x[N-1]` з інтервалом дискретизації `Δt = 1 / f_s`, спектр розраховують за алгоритмом швидкого перетворення Фур'є (FFT Кулі-Тьюкі).

Нижче наведено повні реалізації спектрального аналізатора: обчислення комплексного спектра, знаходження амплітуд і фаз кожної гармоніки, пошук домінуючої частоти та розрахунок коефіцієнта спотворень THD.

```c
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

#ifndef M_PI
#define M_PI 3.14159265358979323846
#endif

typedef struct {
    double real;
    double imag;
} Complex;

typedef struct {
    double *freqs;       /* масив частот для кожного біна (Гц) */
    double *magnitudes;  /* амплітудний спектр */
    double *phases;      /* фазовий спектр (радіани) */
    size_t num_bins;     /* кількість бінів: N / 2 + 1 */
    double fundamental_freq;
    double thd_percent;
} SpectrumResult;

/* Реверс бітів для перестановок на місці */
static size_t bit_reverse(size_t index, size_t log2n) {
    size_t result = 0;
    for (size_t i = 0; i < log2n; ++i) {
        if ((index >> i) & 1) {
            result |= (size_t)1 << (log2n - 1 - i);
        }
    }
    return result;
}

/* Ітеративний Radix-2 FFT (in-place) */
void fft_radix2_c(Complex *data, size_t n) {
    size_t log2n = 0;
    while (((size_t)1 << log2n) < n) log2n++;

    /* 1. Біт-реверсивна перестановка */
    for (size_t i = 0; i < n; ++i) {
        size_t rev = bit_reverse(i, log2n);
        if (i < rev) {
            Complex temp = data[i];
            data[i] = data[rev];
            data[rev] = temp;
        }
    }

    /* 2. Обчислення метеликів за ярусами */
    for (size_t s = 1; s <= log2n; ++s) {
        size_t m = (size_t)1 << s;
        size_t m2 = m >> 1;
        double theta = -2.0 * M_PI / (double)m;
        Complex wm = { cos(theta), sin(theta) };

        for (size_t k = 0; k < n; k += m) {
            Complex w = { 1.0, 0.0 };
            for (size_t j = 0; j < m2; ++j) {
                Complex u = data[k + j];
                Complex t = {
                    w.real * data[k + j + m2].real - w.imag * data[k + j + m2].imag,
                    w.real * data[k + j + m2].imag + w.imag * data[k + j + m2].real
                };
                data[k + j].real = u.real + t.real;
                data[k + j].imag = u.imag + t.imag;
                data[k + j + m2].real = u.real - t.real;
                data[k + j + m2].imag = u.imag - t.imag;

                /* Оновлення множника w */
                double next_w_real = w.real * wm.real - w.imag * wm.imag;
                w.imag = w.real * wm.imag + w.imag * wm.real;
                w.real = next_w_real;
            }
        }
    }
}

/* Повний аналіз спектра дійсного масиву відліків */
SpectrumResult* analyze_spectrum_c(const double *signal, size_t n, double sample_rate) {
    if ((n & (n - 1)) != 0 || n == 0) return NULL; /* N має бути степенем двійки */

    Complex *buf = (Complex*)malloc(n * sizeof(Complex));
    if (!buf) return NULL;

    /* Застосування вікна Ганна для усунення витоку спектра */
    double win_sum = 0.0;
    for (size_t i = 0; i < n; ++i) {
        double w = 0.5 * (1.0 - cos(2.0 * M_PI * (double)i / (double)(n - 1)));
        buf[i].real = signal[i] * w;
        buf[i].imag = 0.0;
        win_sum += w;
    }

    fft_radix2_c(buf, n);

    size_t num_bins = n / 2 + 1;
    SpectrumResult *res = (SpectrumResult*)malloc(sizeof(SpectrumResult));
    res->num_bins = num_bins;
    res->freqs = (double*)malloc(num_bins * sizeof(double));
    res->magnitudes = (double*)malloc(num_bins * sizeof(double));
    res->phases = (double*)malloc(num_bins * sizeof(double));

    double df = sample_rate / (double)n;
    size_t peak_bin = 1;
    double max_mag = 0.0;

    for (size_t k = 0; k < num_bins; ++k) {
        res->freqs[k] = (double)k * df;
        double re = buf[k].real;
        double im = buf[k].imag;
        double raw_mag = sqrt(re * re + im * im);

        /* Нормування амплітуди */
        double mag = (2.0 * raw_mag) / win_sum;
        if (k == 0 || k == n / 2) mag /= 2.0;

        res->magnitudes[k] = mag;
        res->phases[k] = atan2(im, re);

        if (k > 0 && k < n / 2 && mag > max_mag) {
            max_mag = mag;
            peak_bin = k;
        }
    }

    res->fundamental_freq = (double)peak_bin * df;

    /* Розрахунок THD відносно основної знайденої гармоніки */
    double harmonic_sum_sq = 0.0;
    for (size_t h = 2; h <= 10; ++h) {
        size_t h_bin = h * peak_bin;
        if (h_bin < num_bins) {
            double h_mag = res->magnitudes[h_bin];
            harmonic_sum_sq += h_mag * h_mag;
        }
    }
    res->thd_percent = (max_mag > 1e-9) ? (sqrt(harmonic_sum_sq) / max_mag) * 100.0 : 0.0;

    free(buf);
    return res;
}

void free_spectrum_result_c(SpectrumResult *res) {
    if (res) {
        free(res->freqs);
        free(res->magnitudes);
        free(res->phases);
        free(res);
    }
}
```

```cpp
struct SpectrumResult {

    std::vector<double> phases;
    double fundamental_freq{0.0};
    double thd_percent{0.0};
};

class SpectrumAnalyzer {
public:
    explicit SpectrumAnalyzer(size_t fft_size) : size_(fft_size) {
        if ((size_ & (size_ - 1)) != 0 || size_ == 0) {
            throw std::invalid_argument("FFT size must be a power of two");
        }
        precompute_window();
    }

    [[nodiscard]] SpectrumResult analyze(std::span<const double> signal, double sample_rate) const {
        if (signal.size() < size_) {
            throw std::invalid_argument("Signal size is smaller than analyzer FFT size");
        }

        std::vector<std::complex<double>> buffer(size_);
        for (size_t i = 0; i < size_; ++i) {
            buffer[i] = signal[i] * window_[i];
        }

        fft_in_place(buffer);

        const size_t num_bins = size_ / 2 + 1;
        SpectrumResult result;
        result.freqs.resize(num_bins);
        result.magnitudes.resize(num_bins);
        result.phases.resize(num_bins);

        const double df = sample_rate / static_cast<double>(size_);
        size_t peak_bin = 1;
        double max_mag = 0.0;

        for (size_t k = 0; k < num_bins; ++k) {
            result.freqs[k] = static_cast<double>(k) * df;
            double mag = 2.0 * std::abs(buffer[k]) / window_sum_;
            if (k == 0 || k == size_ / 2) {
                mag /= 2.0;
            }

            result.magnitudes[k] = mag;
            result.phases[k] = std::arg(buffer[k]);

            if (k > 0 && k < size_ / 2 && mag > max_mag) {
                max_mag = mag;
                peak_bin = k;
            }
        }

        result.fundamental_freq = static_cast<double>(peak_bin) * df;

        // Обчислення коефіцієнта гармонік THD для гармонік 2..10
        double harm_energy = 0.0;
        for (size_t h = 2; h <= 10; ++h) {
            if (const size_t h_bin = h * peak_bin; h_bin < num_bins) {
                harm_energy += result.magnitudes[h_bin] * result.magnitudes[h_bin];
            }
        }
        result.thd_percent = (max_mag > 1e-9) ? (std::sqrt(harm_energy) / max_mag) * 100.0 : 0.0;

        return result;
    }

private:
    size_t size_;
    std::vector<double> window_;
    double window_sum_{0.0};

    void precompute_window() {
        window_.resize(size_);
        window_sum_ = 0.0;
        for (size_t i = 0; i < size_; ++i) {
            // Вікно Ганна
            window_[i] = 0.5 * (1.0 - std::cos(2.0 * std::numbers::pi * static_cast<double>(i) / static_cast<double>(size_ - 1)));
            window_sum_ += window_[i];
        }
    }

    static void fft_in_place(std::span<std::complex<double>> data) {
        const size_t n = data.size();
        // 1. Біт-реверсивна перестановка
        for (size_t i = 1, j = 0; i < n; ++i) {
            size_t bit = n >> 1;
            for (; j & bit; bit >>= 1) {
                j ^= bit;
            }
            j ^= bit;
            if (i < j) {
                std::swap(data[i], data[j]);
            }
        }

        // 2. Яруси метеликів
        for (size_t len = 2; len <= n; len <<= 1) {
            const double ang = -2.0 * std::numbers::pi / static_cast<double>(len);
            const std::complex<double> wlen(std::cos(ang), std::sin(ang));
            for (size_t i = 0; i < n; i += len) {
                std::complex<double> w(1.0, 0.0);
                for (size_t k = 0; k < len / 2; ++k) {
                    const size_t p = i + k;
                    const size_t q = p + len / 2;
                    const auto u = data[p];
                    const auto v = data[q] * w;
                    data[p] = u + v;
                    data[q] = u - v;
                    w *= wlen;
                }
            }
        }
    }
};
```
