# 🧮 Вивід оптичної різниці ходу та формули Ері для тонкої плівки

Математичний опис інтерференції в тонкій плівці спирається на суворий розрахунок різниці фаз між світловими хвилями, що відбиваються від її верхньої та нижньої меж. Для повного розуміння явища необхідно розглянути як спрощену двопроменеву модель (яка чудово працює при слабкому відбитті від меж), так і точну багатопроменеву модель Ері, що враховує нескінченний ряд послідовних внутрішніх відбитків усередині плівки, а також граничні умови електродинаміки Максвелла.

### 1. Електродинамічні граничні умови та рівняння Френеля

Світлова хвиля є векторним електромагнітним полем, для якого на межі двох середовищ мають виконуватися граничні умови Максвелла. На безперервній межі розділу двох ізотропних середовищ тангенціальні компоненти векторів напруженості електричного поля `E_t` та напруженості магнітного поля `H_t` мають залишатися неперервними (без стрибків).

Розглянемо плоску електромагнітну хвилю, що падає з середовища 1 (показник заломлення `n₁`) на плівку з показником заломлення `n₂` під кутом `θ₁`. За законом Снелла, кут заломлення `θ₂` дорівнює:

```
n₁ · sin θ₁ = n₂ · sin θ₂
```

Залежно від орієнтації вектора електричного поля `E` відносно площини падіння (яка містить промінь і нормаль до поверхні), розрізняють s-поляризацію (вектор `E` перпендикулярний до площини падіння) та p-поляризацію (вектор `E` лежить у площині падіння).

Амплітудні коефіцієнти відбиття Френеля `r` визначаються відношенням відбитої амплітуди до падаючої:

```
Для s-поляризації:
r_s = (n₁ · cos θ₁ - n₂ · cos θ₂) / (n₁ · cos θ₁ + n₂ · cos θ₂)

Для p-поляризації:
r_p = (n₂ · cos θ₁ - n₁ · cos θ₂) / (n₂ · cos θ₁ + n₁ · cos θ₂)
```

Зауважимо важливий знак у формулі Френеля: коли світло падає з оптично менш густого середовища у густіше (`n₁ < n₂`), знак амплітудного коефіцієнта `r_s` стає від'ємним. У комплексній формі це означає множення амплітуди на `exp(i·π) = -1`, тобто скачкоподібну зміну фази відбитої хвилі на `π` radians. У разі відбиття від оптично менш густого середовища (`n₁ > n₂`), коефіцієнт `r_s` залишається додатним, що відповідає нульовій зміні фази.

### 2. Строгий вивід геометричної оптичної різниці ходу

Розглянемо однорідну плоскопаралельну плівку товщиною `d` з показником заломлення `n₂`, розміщену між середовищем 1 (показник `n₁`) та середовищем 3 (показник `n₃`). На верхню межу плівки падає плоска монохроматична світлова хвиля з довжиною хвилі у вакуумі `λ₀` під кутом падіння `θ₁`.

Хвиля розщеплюється на першій межі у точці `A`:
1. **Промінь 1'** відбивається від першої межі під кутом `θ₁` безпосередньо у середовище 1.
2. **Заломлений промінь** поширюється усередині плівки під кутом `θ₂` до точки `B` на нижній межі, відбивається від неї, повертається до точки `C` на верхній межі та заломлюється назовні у середовище 1 як **промінь 2'**.

Обчислимо геометричні довжини шляхів обох променів до спільного хвильового фронту `AD`, проведеного перпендикулярно до вихідних променів із точки `A` на промінь 2' (де точка `D` — основа перпендикуляра):

```
Шлях променя 2' усередині плівки:
S_film = AB + BC

З прямокутних трикутників усередині плівки:
AB = BC = d / cos θ₂
S_film = 2 · d / cos θ₂

Оптична довжина шляху променя 2':
L₂ = n₂ · S_film = 2 · n₂ · d / cos θ₂
```

За час, поки промінь 2' долає шлях `AB + BC` усередині плівки, промінь 1' проходит у середовищі 1 відстань `AD`:

```
Відстань між точками падіння A та виходу C на верхній межі:
AC = 2 · d · tan θ₂

Відстань AD у першому середовищі:
AD = AC · sin θ₁ = 2 · d · tan θ₂ · sin θ₁

Оптична довжина шляху променя 1':
L₁ = n₁ · AD = 2 · n₁ · d · tan θ₂ · sin θ₁
```

Тепер знайдемо геометричну оптичну різницю ходу `Δ_geom = L₂ - L₁`:

```
Δ_geom = (2 · n₂ · d / cos θ₂) - (2 · n₁ · d · tan θ₂ · sin θ₁)

Підставимо закон Снелла n₁ · sin θ₁ = n₂ · sin θ₂:
Δ_geom = (2 · n₂ · d / cos θ₂) - (2 · n₂ · d · tan θ₂ · sin θ₂)
       = 2 · n₂ · d · (1 / cos θ₂ - sin² θ₂ / cos θ₂)
       = 2 · n₂ · d · ((1 - sin² θ₂) / cos θ₂)
       = 2 · n₂ · d · (cos² θ₂ / cos θ₂)
       = 2 · n₂ · d · cos θ₂
```

Отриманий вираз `Δ_geom = 2 · n₂ · d · cos θ₂` є фундаментальною основою геометричної оптики тонких плівок.

### 3. Повна різниця фаз із урахуванням граничних фазових стрибків

Крім геометричного шляху, фаза відбитої хвилі змінюється безпосередньо під час відбиття на межах середовищ. Згідно з рівняннями Френеля для тангенціальних компонент електромагнітного поля:

- Коли світло відбивається від оптично **густішого** середовища (`n_вхід < n_відбиття`), вектор електричного поля `E` змінює свій напрямок на протилежний. Це означає скачкоподібну зміну фази хвилі на `Δφ = π`, що еквівалентно зміні оптичного шляху на півхвилі `± λ₀ / 2`.
- Коли світло відбивається від оптично **менш густого** середовища (`n_вхід > n_відбиття`), фаза хвилі залишається незмінною (`Δφ = 0`).

Сумарна оптична різниця ходу `Δ` з урахуванням граничних умов виглядає так:

```
Δ = 2 · n₂ · d · cos θ₂ ± (λ₀ / 2)  [при n₁ < n₂ > n₃  або  n₁ > n₂ < n₃]
Δ = 2 · n₂ · d · cos θ₂             [при n₁ < n₂ < n₃  або  n₁ > n₂ > n₃]
```

Відповідно, повна різниця фаз двох відбитих хвиль `δ` дорівнює:

```
δ = (2·π / λ₀) · Δ = (4·π · n₂ · d · cos θ₂ / λ₀) ± π
```

Умови для екстремумів інтенсивності відбитого світла:

```
Конструктивна інтерференція (максимум відбиття):
Δ = m · λ₀

Деструктивна інтерференція (мінімум відбиття):
Δ = (m + 1/2) · λ₀
(де m = 0, 1, 2, 3... — порядок інтерференції)
```

При нормальному падінні (`θ₁ = 0`, `cos θ₂ = 1`) умови максимуму та мінімуму відбиття для мильної плівки у повітрі (`n₁ = 1`, `n₂ > 1`, `n₃ = 1`) набувають особливо простого вигляду:

```
Максимум відбиття:
2 · n₂ · d = (m + 1/2) · λ₀

Мінімум відбиття:
2 · n₂ · d = m · λ₀
```

### 4. Точна багатопроменева інтерференція: Формула Ері

Коли промінь падає на плівку, частина енергії відбивається, а частина проходить усередину. Усередині плівки хвиля зазнає багаторазових внутрішніх відбитків від верхньої та нижньої меж.

Позначимо амплітудні коефіцієнти відбиття та проходження Френеля на межах 1–2 та 2–3:
- `r₁₂` — коефіцієнт відбиття при переході з середовища 1 у 2.
- `r₂₁ = -r₁₂` — коефіцієнт відбиття з середовища 2 у 1.
- `r₂₃` — коефіцієнт відбиття з середовища 2 у 3.
- `t₁₂` та `t₂₁` — коефіцієнти проходження крізь межу.

За теоремою Стокса про обратність світлових променів, коефіцієнти зв'язані співвідношенням `t₁₂ · t₂₁ = 1 - r₁₂²`.

Амплітуди послідовних відбитих хвиль, що виходять у перше середовище, утворюють нескінченну послідовність:

```
E₁' = E₀ · r₁₂
E₂' = E₀ · t₁₂ · r₂₃ · t₂₁ · exp(-i · β)
E₃' = E₀ · t₁₂ · r₂₃ · r₂₁ · r₂₃ · t₂₁ · exp(-i · 2·β)
E₄' = E₀ · t₁₂ · r₂₃³ · r₂₁² · t₂₁ · exp(-i · 3·β)
...
де β = 4·π · n₂ · d · cos θ₂ / λ₀ — набіг фази за один подвійний прохід плівки.
```

Сумарна амплітуда відбитої хвилі `E_R` дорівнює сумі нескінченної геометричної прогресії зі знаменником `q = r₂₁ · r₂₃ · exp(-i·β) = -r₁₂ · r₂₃ · exp(-i·β)`:

```
E_R = E₁' + E₂' + E₃' + ...
    = E₀ · [r₁₂ + t₁₂·t₂₁·r₂₃ · exp(-i·β) / (1 - r₂₁·r₂₃ · exp(-i·β))]

Використавши r₂₁ = -r₁₂  та  t₁₂·t₂₁ = 1 - r₁₂²:
E_R = E₀ · [ (r₁₂ + r₂₃ · exp(-i·β)) / (1 + r₁₂·r₂₃ · exp(-i·β)) ]
```

Коефіцієнт відбиття за енергією `R = |E_R / E₀|²` обчислюється множенням комплексного виразу на його комплексно-спряжений:

```
R = (r₁₂² + r₂₃² + 2·r₁₂·r₂₃·cos β) / (1 + r₁₂²·r₂₃² + 2·r₁₂·r₂₃·cos β)
```

Це і є класична **формула Ері**.

Аналогічно, сумарна амплітуда пропущеної хвилі `E_T` у третє середовище дорівнює:

```
E_T = E₀ · [ t₁₂ · t₂₃ · exp(-i·β/2) / (1 + r₁₂·r₂₃ · exp(-i·β)) ]
```

Коефіцієнт проходження за енергією `T`:

```
T = (n₃ · cos θ₃ / (n₁ · cos θ₁)) · |E_T / E₀|²
  = (t₁₂² · t₂₃²) / (1 + r₁₂²·r₂₃² + 2·r₁₂·r₂₃·cos β)
```

У разі відсутності поглинання світла у матеріалі плівки сума енергетичних коефіцієнтів строго задовольняє закон збереження енергії:

```
R + T = 1
```

### 5. Різкість смуг та параметр Finesse у резонаторах Фабрі-Перо

Для симетричної плівки у повітрі (`n₁ = n₃ = 1`, `r₂₃ = -r₁₂ = -r`), формула Ері спрощується до стандартного вигляду через параметр різкості (Finesse):

```
R = (4·r² · sin²(β/2)) / ((1 - r²)² + 4·r² · sin²(β/2))
  = (F · sin²(β/2)) / (1 + F · sin²(β/2))

де F = (2·r / (1 - r²))² — коефіцієнт різкості Фабрі-Перо.
```

Параметр різкості `F` визначає ширину інтерференційних максимумів пропущення:

```
Ширина максимуму на піввисоті (FWHM):
δβ = 4 / √F

Спектральне розділення интерферометра Фабрі-Перо:
δλ = λ₀² / (2 · n₂ · d · F)
```

Формула Ері показує фундаментальну різницю між двопроменевою та багатопроменевою інтерференцією:
1. При малих коефіцієнтах відбиття меж (`r² ≪ 1`, як для мильної плівки або чистого скла у повітрі) вираз наближається до гармонічного закону двопроменевої інтерференції `R ≈ 2·r² · (1 - cos β)`. Інтерференційні смуги є широкими, плавно-синусоїдальними.
2. При високих значеннях відбиття (`r² → 1`, як у диелектричних дзеркалах або дзеркальних інтерферометрах) значення `F` стає величезним (`F > 1000`). Спектр відбиття є сукупністю надзвичайно вузьких та гострих інтерференційних піків, що використовується в оптичних резонаторах лазерів, квантовій нанофотоніці та світлофільтрах високого розрізнення.

### 6. Точний вивід кілець Ньютона для сферичної поверхні

У класичному наближенні геометрії кілець Ньютона товщина зазору вважається параболічною `d(r) = r² / (2·R)`. Зробимо точний вивід з урахуванням точної сферичної дуги лінзи радіуса `R`.

Рівняння кола радіуса `R` з центром у точці `(0, R)`:

```
x² + (y - R)² = R²
r² + y² - 2·R·y + R² = R²
2·R·y - y² = r²
y = R - √(R² - r²)
```

Оскільки товщина зазору `d(r)` дорівнює цій висоті `y`, розкладемо квадратний корінь у ряд Тейлора за малим параметром `(r/R)² ≪ 1`:

```
d(r) = R · [1 - √(1 - (r/R)²)]
     = R · [1 - (1 - 1/2 · (r/R)² - 1/8 · (r/R)⁴ - ...)]
     = r² / (2·R) + r⁴ / (8·R³) + ...
```

Для більшості оптичних вимірювань поправкою вищих порядків `r⁴ / (8·R³)` можна знехтувати, проте при високих номерах кілець `m > 50` вона стає відчутною і має враховуватися при апроксимації спектрометричних даних.

Підставляючи точне розкладання в умову темного кільця `2·d(r) = m·λ₀`:

```
rₘ² / R + rₘ⁴ / (4·R³) = m · λ₀

Звідси точніший вираз для радіуса m-го темного кільця:
rₘ ≈ √(m · λ₀ · R) · [1 - m · λ₀ / (8 · R)]
```

Ця поправка демонструє, що з віддаленням від центра відстань між сусідніми кільцями Ньютона зменшується трохи швидше, ніж передбачає параболічне наближення.
