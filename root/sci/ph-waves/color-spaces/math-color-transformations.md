# 🧮 Математичний апарат перетворення колірних просторів та метрики ΔE

Математична обробка колірних просторів ґрунтується на послідовних лінійних (матричних) та нелінійних (степеневих, логарифмічних) перетвореннях векторів у тривимірному евклідовому просторі.

Для забезпечення точності відтворення кольору між різними фізичними пристроями (сканерами, дисплеями, принтерами) використовують концепцію **простору зв'язку профілів** (Profile Connection Space — PCS), в ролі якого зазвичай виступають апаратно-незалежні простори **CIE XYZ 1931** або **CIELAB**.

У цьому розділі наведено суворий математичний апарат усіх ключових перетворень колірних координат, лінеаризації, хроматичної адаптації Бредфорда та формули обчислення метрик зорової відмінності `ΔE`.

## 1. Гамма-декомпандування та лінеаризація sRGB

Значення пікселів у цифрових зображеннях sRGB подаються у вигляді 8-бітних цілих чисел `(R_8bit, G_8bit, B_8bit) ∈ [0 .. 255]`. Вони є гама-корегованими (нелінійними), оскільки оптимізовані для ефективного квантування динамічного діапазону людського зору.

Проте будь-які фізичні та геометрічні обчислення (альфа-блендинг, масштабування, розрахунок освітлення) вимагають роботи з **лінійними фізичними величинами**, пропорційними інтенсивності фотонного потоку. Пряме додавання чи множення нелінійних значень призводить до викривлення енергетичного балансу та затемнення градієнтів.

Першим кроком є нормування 8-бітних цілих значень до безрозмірного інтервалу `[0.0 .. 1.0]`, після чого виконується зворотне електрооптичне перетворення (EOTF — Electro-Optical Transfer Function):

```
C_srgb = C_8bit / 255.0

C_linear = C_srgb / 12.92                        [якщо C_srgb ≤ 0.04045]
C_linear = ((C_srgb + 0.055) / 1.055)^2.4       [якщо C_srgb > 0.04045]
```

де `C` відповідає кожному з трьох каналів `R`, `G`, `B`.

Параметр `12.92` та тангенціальний зсув `0.055` розраховані так, щоб лінійна ділянка `C_srgb / 12.92` плавно і без розриву похідної переходила у степеневу функцію `((C_srgb + 0.055) / 1.055)^2.4` у точці `C_srgb = 0.04045`. Усереднений коефіцієнт цієї комбінованої функції точно дорівнює стандартному показнику гамми `γ ≈ 2.2`.

## 2. Лінійне матричне перетворення sRGB Linear → CIE XYZ (Джерело D65)

Перехід від лінійних апаратних координат `(R_linear, G_linear, B_linear)` до тристимулів стандартного спостерігача CIE 1931 `(X, Y, Z)` є афінним зміною базису у тривимірному векторному просторі.

Матриця перетворення `M_sRGB_to_XYZ` розраховується на основі хроматичних координат первинних випромінювачів sRGB та опорної білої точки `D65` (`x_w = 0.3127, y_w = 0.3290`):

```
[ X ]   [ 0.4124564  0.3575761  0.1804375 ]   [ R_linear ]
[ Y ] = [ 0.2126729  0.7151522  0.0721750 ] · [ G_linear ]
[ Z ]   [ 0.0193339  0.1191920  0.9503041 ]   [ B_linear ]
```

Зворотне перетворення від тристимульних координат CIE XYZ до лінійних компонентів sRGB виконується за допомогою оберненої матриці `M_XYZ_to_sRGB = M_sRGB_to_XYZ⁻¹`:

```
[ R_linear ]   [  3.2404542 -1.5371385 -0.4985314 ]   [ X ]
[ G_linear ] = [ -0.9692660  1.8760108  0.0415560 ] · [ Y ]
[ B_linear ]   [  0.0556434 -0.2040259  1.0572252 ] · [ Z ]
```

Абсолютні тристимульні значення опорного білого для стандартного джерела освітлення `D65` (денне світло з колірною температурою `6504 K`) у просторі CIE XYZ становлять:

```
X_w = 0.95047
Y_w = 1.00000
Z_w = 1.08883
```

Зверніть увагу, що значення `Y_w` за визначенням нормується до `1.00000` (або `100.0` у відсотковому вираженні).

## 3. Фізика та матричний апарат хроматичної адаптації Бредфорда (D65 ↔ D50)

При переході від екранів та комп'ютерної графіки (де стандартом освітлення є `D65`) до поліграфічного друку та оцінки фарб (де міжнародним стандартом ISO 3664 є джерело `D50` з колірною температурою `5000 K`) спектральний склад опорного білого змінюється від холодно-блакитного до тепло-жовтуватого.

Якщо просто порівняти координати XYZ без коригування, нейтральний білий колір екрана на папері виглядатиме сильно жовтим. Людська зорова система володіє властивістю **хроматичної адаптації**: мозок автоматично «перекалібровує» чутливість колбочок під колір навколишнього освітлення, продовжуючи сприймати білий папір як нейтрально білий.

Для математичної імітації зорової адаптації використовують **перетворення Бредфорда** (Bradford Chromatic Adaptation Transform). Просте діагональне масштабування фон Кріса у просторі XYZ дає хроматичні артефакти. Перетворення Бредфорда спочатку переводить вектор `(X, Y, Z)` у спеціальний спектрально-вузький рецепторний простір Бредфорда `(ρ, γ, β)` за допомогою матриці `M_BF`:

```
[ ρ ]   [  0.8951000  0.2664000 -0.1614000 ]   [ X ]
[ γ ] = [ -0.7502000  1.7135000  0.0367000 ] · [ Y ]
[ β ]   [  0.0389000 -0.0685000  1.0296000 ]   [ Z ]
```

Після цього у просторі Бредфорда обчислюються коефіцієнти діагонального масштабування відносно координат білої точки джерела `D65` та білої точки цільового освітлення `D50` (`X_w=0.9642, Y_w=1.0000, Z_w=0.8249`):

```
k_ρ = ρ_D50 / ρ_D65 = 1.0583
k_γ = γ_D50 / γ_D65 = 0.9808
k_β = β_D50 / β_D65 = 0.7511
```

Результуюча матриця хроматичної адаптації `M_adapt` утворюється як добуток трьох матриць:

```
M_adapt = M_BF⁻¹ · diag(k_ρ, k_γ, k_β) · M_BF
```

Числове значення підсумкової матриці адаптації Бредфорда для переходу `D65 → D50` дорівнює:

```
[ X_D50 ]   [  1.0478112  0.0228866 -0.0501269 ]   [ X_D65 ]
[ Y_D50 ] = [  0.0295424  0.9904844 -0.0170491 ] · [ Y_D65 ]
[ Z_D50 ]   [ -0.0092345  0.0150436  0.7521316 ]   [ Z_D65 ]
```

## 4. Математичний апарат нелінійного простору CIELAB (L*a*b*)

Перетворення з апаратно-незалежного простору CIE XYZ у рівномірно-перцептивний простір CIELAB виконується відносно координат опорного білого `(X_w, Y_w, Z_w)`.

Для стискання динамічного діапазону застосовують нелінійну кубічну функцію `f(t)`:

```
f(t) = t^(1/3)                      [якщо t > (6/29)^3 ≈ 0.008856]
f(t) = (841/108)·t + 4/29           [якщо t ≤ 0.008856]
```

Лінійна ділянка `(841/108)·t + 4/29` застосовується для дуже малих значень `t ≤ 0.008856`. Поточковий коефіцієнт `841/108 = (1/3) · (29/6)²` є першою похідною функції `t^(1/3)` у точці переходу `t₀ = (6/29)³`, що забезпечує гладкість і неперервність похідної функції `f(t)` по всій області визначення.

Координати `L*`, `a*`, `b*` обчислюються за формулами:

```
L* = 116 · f(Y / Y_w) - 16
a* = 500 · [ f(X / X_w) - f(Y / Y_w) ]
b* = 200 · [ f(Y / Y_w) - f(Z / Z_w) ]
```

Координата `L*` вимірює перцептивну світлоту. Коефіцієнт `500` при обчисленні `a*` та `200` при обчисленні `b*` підбиралися емпірично для того, щоб компенсувати різну чутливість ока вздовж оппонентних axes «зелений-червоний» та «синій-жовтий».

Зворотне перетворення з CIELAB у CIE XYZ здійснюється за допомогою оберненої функції `f⁻¹(y)`:

```
Y = Y_w · f⁻¹( (L* + 16) / 116 )
X = X_w · f⁻¹( (L* + 16) / 116 + a* / 500 )
Z = Z_w · f⁻¹( (L* + 16) / 116 - b* / 200 )

де f⁻¹(y) = y³                      [якщо y > 6/29]
   f⁻¹(y) = (y - 4/29) · (108/841)  [якщо y ≤ 6/29]
```

## 5. Математичний апарат простору Oklab та Oklch

Простір Oklab, розроблений Бйорном Оттоссоном у 2020 році, усунув математичний недолік зсуву колірного тону у синій зоні, властивий CIELAB.

Математична структура Oklab складається з трьох кроків:

**Крок 1.** Перехід від CIE XYZ до короткохвильових рецепторних сигналів `(L_cone, M_cone, S_cone)` за допомогою матриці `M₁`:

```
[ L_cone ]   [  0.8189330101  0.3618667424 -0.1288597137 ]   [ X ]
[ M_cone ] = [  0.0329845436  0.9293118715  0.0361456387 ] · [ Y ]
[ S_cone ]   [  0.0482003018  0.2643662691  0.6338517070 ]   [ Z ]
```

**Крок 2.** Нелінійне кубічне стискання рецепторних сигналів:

```
l′ = ∛(L_cone)
m′ = ∛(M_cone)
s′ = ∛(S_cone)
```

**Крок 3.** Формування ортогональних оппонентних координат `(L, a, b)` за допомогою матриці `M₂`:

```
[ L ]   [  0.2104542553  0.7936177850 -0.0040720468 ]   [ l′ ]
[ a ] = [  1.9779984951 -2.4285922050  0.4505937099 ] · [ m′ ]
[ b ]   [  0.0259040371  0.7827717662 -0.8086758033 ] · [ s′ ]
```

Для переходу від декартових координат Oklab `(L, a, b)` до полярних координат Oklch `(L, C, h)` застосовують фундаментальні формули перетворення декартової системи координат у циліндричну:

```
C = √(a² + b²)                      [Хрома або насиченість]
h = atan2(b, a) · (180 / π)         [Кут тону в градусах 0° .. 360°]
```

Якщо значення кута `h` виходить від'ємним (`h < 0`), до нього додають `360.0°`.

## 6. Еволюція та математика метрик колірної відмінності ΔE

Метрика `ΔE` кількісно виражає відносну зорову відмінність між двома колірними векторами.

### 1. Метрика ΔE_ab (CIE 1976)
Визначається як звичайна евклідова відстань у просторі CIELAB:

```
ΔE_ab = √[ (L₁* - L₂*)² + (a₁* - a₂*)² + (b₁* - b₂*)² ]
```

Через нерівномірність CIELAB значення `ΔE_ab = 2.0` у синій зоні сприймається як ледь помітна зміна, тоді як у жовтій зоні — як чітка відмінність.

### 2. Метрика CIEDE2000 (ΔE_00)
Щоб компенсувати нерівномірність CIELAB, у 2000 році CIE затвердила формулу CIEDE2000 (`ΔE_00`). Вона вводить вагові коефіцієнти світлоти `S_L`, хроми `S_C` та тону `S_H`, а також поворотний член `R_T` для корекції відхилень у синій зоні:

```
ΔE_00 = √[ (ΔL′ / (k_L·S_L))² + (ΔC′ / (k_C·S_C))² + (ΔH′ / (k_H·S_H))² + R_T · (ΔC′ / (k_C·S_C)) · (ΔH′ / (k_H·S_H)) ]
```

Обчислення CIEDE2000 вимагає понад 30 математичних операцій, включаючи обчислення середніх кутів тону та корекцію розривів при переході через 0°/360°.

### 3. Метрика ΔE_OK (Oklab)
Завдяки високій рівномірності простору Oklab, метрика `ΔE_OK` повертається до чистої евклідової відстані без жодних важких вагових коефіцієнтів:

```
ΔE_OK = √[ (L₁ - L₂)² + (a₁ - a₂)² + (b₁ - b₂)² ]
```

Поріг сприйняття `1 JND` у просторі Oklab строго відповідає значенню `ΔE_OK ≈ 0.02` по всьому колірному охопленню.
