# 🧮 Ряд Фур'є та інтегральні норми несинусоїдних хвиль

Аналітичне виведення ряду Фур'є та точний розрахунок інтегральних характеристик (діючого значення RMS, середнього випрямленого значення, коефіцієнтів форми та пік-фактора) дають строге математичне пояснення тому, чому симетричні сигнали втрачають парні гармоніки, як гладкість форми хвилі визначає швидкість спадання її спектра, чому виникає непереборний викид Гіббса коло розривів і як навантаження поглинає енергію кожної окремої гармоніки за теоремою Парсеваля.

### Тригонометричний ряд Фур'є та правила симетрії

Будь-яку періодичну функцію `f(t)` з періодом `T` (і круговою частотою `ω = 2π / T`), яка задовольняє умови Діріхле (є кусково-неперервною та має скінченну кількість локальних екстремумів на періоді), можна подати у вигляді ортогонального тригонометричного ряду:

```
f(t) = a₀ + ∑[n=1..∞] (aₙ · cos(n·ω·t) + bₙ · sin(n·ω·t))
```

Коефіцієнти ряду визначаються через інтеграли Ейлера — Фур'є за повний період `[-T/2, T/2]` або `[0, T]`:

```
a₀ = (1 / T) · ∫[−T/2 .. T/2] f(t) dt               [постійна складова / середнє значення]

aₙ = (2 / T) · ∫[−T/2 .. T/2] f(t) · cos(n·ω·t) dt   [амплітуди косинусних гармонік]

bₙ = (2 / T) · ∫[−T/2 .. T/2] f(t) · sin(n·ω·t) dt   [амплітуди синусних гармонік]
```

Геометрична симетрія функції кардинально спрощує обчислення коефіцієнтів завдяки властивостям парності:

1. **Непарна функція** (`f(−t) = −f(t)`): інтеграл від добутку непарної функції на парний косинус по симетричному інтервалу тотожно дорівнює нулю. Звідси всі `a₀ = 0` та `aₙ = 0`. Ряд містить виключно синуси:

```
a₀ = 0
aₙ = 0
bₙ = (4 / T) · ∫[0 .. T/2] f(t) · sin(n·ω·t) dt     [інтегрування за пів періоду]
```

2. **Парна функція** (`f(−t) = f(t)`): аналогічно, усі синусні коефіцієнти `bₙ = 0`. Ряд містить лише постійну складову та косинуси:

```
bₙ = 0
aₙ = (4 / T) · ∫[0 .. T/2] f(t) · cos(n·ω·t) dt
```

3. **Напівхвильова антисиметрія** (`f(t + T/2) = −f(t)`): коли від'ємна півхвиля є дзеркальною копією додатної, зміщеною на пів періоду. Інтегрування добутку показує, що для всіх **парних** `n` (`n = 2, 4, 6...`) підінтегральний вираз скорочується до нуля:

```
a[2k] = 0
b[2k] = 0   де k ∈ ℕ                                [усі парні гармоніки зникають]
```

### Аналітичне виведення коефіцієнтів для симетричного меандру

Розглянемо симетричний двополярний меандр з амплітудою `A`, періодом `T` та нульовою постійною складовою, визначений на інтервалі `[−T/2, T/2]`:

```
f(t) = −A,  якщо t ∈ [−T/2, 0)
f(t) = +A,  якщо t ∈ (0, T/2]
```

Оскільки функція є непарною (`f(−t) = −f(t)`), коефіцієнти `a₀ = 0` та `aₙ = 0`. Обчислимо коефіцієнти `bₙ`:

```
bₙ = (4 / T) · ∫[0 .. T/2] A · sin(n·ω·t) dt
   = (4A / T) · [ −cos(n·ω·t) / (n·ω) ] |[0 .. T/2]          [первісна від sin(kx) є −cos(kx)/k]
   = (4A / (n·ω·T)) · [ 1 − cos(n·ω·T / 2) ]                 [підстановка нижньої та верхньої меж]
   = (4A / (2π·n)) · [ 1 − cos(n·π) ]                        [підстановка ω·T = 2π]
   = (2A / (n·π)) · [ 1 − (−1)ⁿ ]                            [значення cos(n·π) = (−1)ⁿ]
```

Аналізуємо вираз `[1 − (−1)ⁿ]`:
- Якщо `n` парне (`n = 2k`): `1 − 1 = 0`, отже `b[2k] = 0`.
- Якщо `n` непарне (`n = 2k + 1`): `1 − (−1) = 2`, отже `b[2k+1] = 4A / ((2k+1)·π)`.

Підставляючи коефіцієнти у вихідний ряд, отримуємо канонічний спектральний розклад меандру:

```
f_sq(t) = (4A / π) · ( sin(ωt) + (1/3)·sin(3ωt) + (1/5)·sin(5ωt) + (1/7)·sin(7ωt) + ... )
```

Амплітуди гармонік спадають як `1/n` (зі швидкістю −20 дБ на декаду частоти). Це прямий наслідок стрибкоподібних розривів функції першого роду (кінцеві стрибки амплітуди `2A` за нульовий час).

### Аналітичне виведення коефіцієнтів для пилкоподібного сигналу

Розглянемо непарний пилкоподібний сигнал з амплітудою розмаху від `−A` до `+A` на інтервалі `[−T/2, T/2]`:

```
f(t) = (2A / T) · t,   t ∈ (−T/2, T/2)
```

Функція є непарною, отже `a₀ = 0` та `aₙ = 0`. Для коефіцієнтів `bₙ` застосуємо інтегрування частинами (`∫ u dv = u·v − ∫ v du`), поклавши `u = t`, `dv = sin(n·ω·t) dt`:

```
bₙ = (2 / T) · ∫[−T/2 .. T/2] ((2A / T) · t) · sin(n·ω·t) dt
   = (4A / T²) · ∫[−T/2 .. T/2] t · sin(n·ω·t) dt
   = (4A / T²) · [ −t · cos(n·ω·t) / (n·ω) |[−T/2 .. T/2] + (1 / (n·ω)) · ∫[−T/2 .. T/2] cos(n·ω·t) dt ]   [інтегрування частинами]
   = (4A / T²) · [ −(T/2 · cos(n·π) − (−T/2)·cos(−n·π)) / (n·ω) + 0 ]                                        [інтеграл від косинуса за період дорівнює 0]
   = (4A / T²) · [ −(T · cos(n·π)) / (n·ω) ]                                                                [зведення подібних доданків]
   = −(4A / (n·ω·T)) · (−1)ⁿ                                                                                 [підстановка cos(n·π) = (−1)ⁿ]
   = −(2A / (n·π)) · (−1)ⁿ                                                                                   [підстановка ω·T = 2π]
   = (2A / (n·π)) · (−1)ⁿ⁺¹                                                                                  [внесення знака мінус у степінь]
```

Остаточний ряд Фур'є для пилкоподібної хвилі містить **як парні, так і непарні** гармоніки:

```
f_saw(t) = (2A / π) · ( sin(ωt) − (1/2)·sin(2ωt) + (1/3)·sin(3ωt) − (1/4)·sin(4ωt) + ... )
```

На відміну від симетричного меандру, пилкоподібний сигнал не має напівхвильової антисиметрії `f(t + T/2) ≠ −f(t)`, тому його спектр насичений абсолютно всіма цілими кратними частоти `f₀`. Амплітуди гармонік спадають зі швидкістю `1/n` (−20 дБ/дек) через розрив при поверненні пилки (flyback).

### Аналітичне виведення коефіцієнтів для трикутної хвилі

Розглянемо симетричну трикутну хвилю з амплітудою `A`, періодом `T`, обрану парною (`f(−t) = f(t)`):

```
f(t) = A · (1 − 4·|t| / T),   t ∈ [−T/2, T/2]
```

Функція парна і симетрична відносно нуля, тому `bₙ = 0` та `a₀ = 0`. Обчислимо `aₙ` через двократне інтегрування частинами:

```
aₙ = (4 / T) · ∫[0 .. T/2] A · (1 − 4t/T) · cos(n·ω·t) dt
   = (4A / T) · [ (1 − 4t/T) · sin(n·ω·t)/(n·ω) |[0 .. T/2] + (4 / (n·ω·T)) · ∫[0 .. T/2] sin(n·ω·t) dt ]  [перше інтегрування частинами]
   = (4A / T) · [ 0 + (4 / (n·ω·T)) · [ −cos(n·ω·t) / (n·ω) ] |[0 .. T/2] ]                                [підстановка меж: sin(0)=0 та sin(nπ)=0]
   = (16A / (n²·ω²·T²)) · [ 1 − cos(n·π) ]                                                                 [обчислення другої первісної]
   = (16A / (4π²·n²)) · [ 1 − (−1)ⁿ ]                                                                      [підстановка ω·T = 2π]
   = (4A / (π²·n²)) · [ 1 − (−1)ⁿ ]                                                                        [скорочення коефіцієнтів]
```

Для парних `n` вираз дорівнює 0. Для непарних `n = 1, 3, 5...` вираз дає `8A / (π² · n²)`:

```
f_tri(t) = (8A / π²) · ( cos(ωt) + (1/9)·cos(3ωt) + (1/25)·cos(5ωt) + (1/49)·cos(7ωt) + ... )
```

Оскільки сама трикутна функція є неперервною скрізь (розрив має лише її перша похідна `f'(t)`), амплітуди її гармонік спадають як `1/n²` (−40 дБ на декаду частоти). Третя гармоніка становить лише 11.1% від основної (порівняно з 33.3% у меандру), а п'ята — лише 4%.

### Ряд Фур'є для прямокутної імпульсної послідовності довільної шпаруватості

Нехай уніполярний імпульсний сигнал має амплітуду `A`, період `T`, тривалість високого рівня `t_h` та коефіцієнт заповнення `D = t_h / T`. Для симетричного розташування імпульсу навколо нуля `[-t_h/2, t_h/2]`:

```
f(t) = A,   t ∈ [−t_h / 2, t_h / 2]
f(t) = 0,   в решті інтервалу періоду
```

1. Постійна складова:
```
a₀ = (1 / T) · ∫[−t_h/2 .. t_h/2] A dt
   = (A / T) · t_h
   = D · A                                            [постійна напруга пропорційна заповненню]
```

2. Косинусні коефіцієнти:
```
aₙ = (2 / T) · ∫[−t_h/2 .. t_h/2] A · cos(n·ω·t) dt
   = (2A / T) · [ sin(n·ω·t) / (n·ω) ] |[−t_h/2 .. t_h/2]
   = (4A / (n·ω·T)) · sin(n·ω·t_h / 2)
   = (2A / (n·π)) · sin(n·π·D)                        [підстановка ω·T = 2π та t_h/T = D]
   = 2·A·D · ( sin(n·π·D) / (n·π·D) )
   = 2·A·D · sinc(n·π·D)                              [спектральна огинаюча sinc(x)]
```

Амплітуди гармонік модулюються функцією `sinc(n·π·D)`. Якщо номер гармоніки `n` дорівнює шпаруватості `S = 1/D` (або кратному значенню `k/D`), аргумент синуса стає `k·π`, і ця гармоніка повністю зникає (`aₙ = 0`):
- При `D = 0.5` (меандр, `S = 2`) зникають усі парні гармоніки `n = 2, 4, 6...`.
- При `D = 0.25` (`S = 4`) зникають гармоніки `n = 4, 8, 12...`.
- При `D = 0.1` (`S = 10`) зникають гармоніки `n = 10, 20, 30...`.

### Спектр трапецієподібного імпульсу та частоти зламу

У реальних цифрових колах прямокутний імпульс має скінченний час наростання та спаду `t_r`, перетворюючись на симетричну трапецію з тривалістю площини `t_h` та часом переходу `t_r`.

Подвійне диференціювання трапецієподібного сигналу за часом перетворює похилі фронти на пари дельта-функцій Дірака протилежного знака. Застосування теореми про похідну ряду Фур'є дає коефіцієнти:

```
cₙ = 2·A·D · sinc(n·π·D) · sinc(n·π·(t_r / T))
```

Спектр трапеції має дві характерні **частоти зламу** (точки перегину асимптотичної огинаючої на логарифмічній шкалі Боде):
1. **Перший злам** на частоті `f₁ = 1 / (π · t_h)`: до цієї точки амплітуди гармонік приблизно сталі (горизонтальна полиця постійної складової). Після `f₁` спектр спадає зі швидкістю **−20 дБ на декаду** (`1/n`), оскільки сигнал сприймається як прямокутний.
2. **Другий злам** на частоті `f₂ = 1 / (π · t_r)`: після цієї частоти починає діяти другий множник `sinc(n·π·t_r/T)`. Спадання спектра прискорюється до **−40 дБ на декаду** (`1/n²`).

Це виведення наочно доводить фундаментальне правило електромагнітної сумісності (EMC): збільшення часу наростання `t_r` зміщує другу частоту зламу `f₂` вліво, пригнічуючи високочастотні завади у радіодіапазоні на десятки децибел без зміни форми самого робочого імпульсу.

### Явище Гіббса та збіжність ряду Фур'є біля розривів

При синтезі ступінчастого прямокутного сигналу зі скінченної кількості гармонік `N` виникає математичний парадокс, відкритий Джозаєю Віллардом Гіббсом у 1899 році.

Якщо ми підсумуємо перші `N` непарних гармонік меандру:

```
S_N(t) = (4A / π) · ∑[k=0..N-1] ( sin((2k+1)·ω·t) / (2k+1) )
```

поблизу точки стрибка напруги `t = 0` сума коливань завжди дає характерний високочастотний сплеск (хвильове перерегулювання).

Зі збільшенням кількості гармонік `N → ∞` частота цих коливань зростає, а їхня ширина стискається до точки розриву, але **висота піка не прямує до нуля**. Вона прямує до строго фіксованої границі, що виражається через інтеграл синуса (інтегральний синус `Si(x)`):

```
lim[N→∞] S_N(t_peak) = (2A / π) · ∫[0 .. π] (sin(x) / x) dx
                     = (2A / π) · Si(π)
                     ≈ (2A / π) · 1.851937
                     ≈ 1.17898 · A
```

Оскільки стрибок функції становить `A` від нуля, перерегулювання дорівнює:

```
δ = (1.17898 − 1.0) / 2 = 0.08949   (8.949% від повної висоти перепаду)
```

Це означає, що будь-яка апаратна система зі скінченною смугою пропускання частот (фільтр низьких частот), яка пропускає перші `N` гармонік і різко зрізає вищі, неминуче продемонструє фізичний дзвін (ringing) з амплітудою близько 9% від перепаду напруги.

### Теорема Парсеваля та розподіл енергії по гармоніках

Теорема Парсеваля встановлює фундаментальний міст між часовим та частотним представленням енергії: **повна потужність сигналу дорівнює сумі потужностей усіх його окремих ортогональних гармонік**:

```
P_total = V_rms² = a₀² + (1 / 2) · ∑[n=1..∞] (aₙ² + bₙ²)
```

Розрахуємо енергетичний баланс для симетричного меандру з амплітудою `A`:

1. Повна діюча потужність у часовій області:
```
P_total = V_rms² = A²
```

2. Потужність, що переноситься першою (основною) гармонікою (`n = 1`, амплітуда `b₁ = 4A/π`):
```
P₁ = (1 / 2) · b₁² = (1 / 2) · (4A / π)² = (8 / π²) · A² ≈ 0.81057 · A²   (81.06%)
```

3. Потужність третьої гармоніки (`n = 3`, амплітуда `b₃ = 4A / (3π)`):
```
P₃ = (1 / 2) · (4A / (3π))² = (8 / (9π²)) · A² ≈ 0.09006 · A²             (9.01%)
```

4. Потужність п'ятої гармоніки (`n = 5`):
```
P₅ = (1 / 2) · (4A / (5π))² = (8 / (25π²)) · A² ≈ 0.03242 · A²            (3.24%)
```

Підсумовуючи перші три гармоніки:

```
P₁ + P₃ + P₅ = (81.06% + 9.01% + 3.24%) = 93.31% від повної енергії хвилі.
```

Перші п'ять непарних гармонік (до 9-ї включно) зосереджують понад 95.7% усієї енергії меандру. Це пояснює, чому для якісної передачі цифрового прямокутного імпульсу смуга тракту повинна пропускати щонайменше до п'ятої гармоніки тактової частоти.

### Аналітичний розрахунок середнього, RMS, коефіцієнта форми та пік-фактора

Енергетичний зміст сигналу на резистивному навантаженні `R` визначається інтегралом миттєвої потужності:

```
P_avg = (1 / T) · ∫[0 .. T] (v(t)² / R) dt
      = (1 / R) · [ (1 / T) · ∫[0 .. T] v(t)² dt ]    [винесення сталого опору R]
      = V_rms² / R                                    [означення діючої напруги V_rms]
```

Обчислимо точні інтегральні характеристики для основних форм хвиль:

#### 1. Синусоїдний сигнал `v(t) = A·sin(ωt)`

- Середнє випрямлене значення:
```
V_avg_rect = (2 / T) · ∫[0 .. T/2] A · sin(ωt) dt
           = (2A / T) · [ −cos(ωt) / ω ] |[0 .. T/2]
           = (2A / (ω·T)) · (1 − cos(π))
           = (2A / (2π)) · 2
           = (2 / π) · A ≈ 0.6366 · A
```

- Середньоквадратичне (RMS) значення:
```
V_rms² = (1 / T) · ∫[0 .. T] A² · sin²(ωt) dt
       = (A² / T) · ∫[0 .. T] (1 − cos(2ωt)) / 2 dt   [тригонометрична тотожність sin²(x)]
       = (A² / (2T)) · [ t − sin(2ωt)/(2ω) ] |[0 .. T]
       = (A² / (2T)) · T
       = A² / 2
V_rms  = A / √2 ≈ 0.7071 · A
```

- Коефіцієнт форми `k_f` та пік-фактор `k_c`:
```
k_f = V_rms / V_avg_rect = (A / √2) / ((2/π)·A) = π / (2·√2) ≈ 1.1107
k_c = V_peak / V_rms = A / (A / √2) = √2 ≈ 1.4142   (3.01 дБ)
```

#### 2. Симетричний прямокутний сигнал (меандр `±A`)

```
V_avg_rect = A
V_rms²     = (1 / T) · ∫[0 .. T] (±A)² dt = A²
V_rms      = A
k_f        = A / A = 1.0000
k_c        = A / A = 1.0000   (0.00 дБ)
```

#### 3. Трикутний та пилкоподібний сигнали (розмах `±A`, функція на півперіоді `v(t) = (2A/T)·t`)

- Середнє випрямлене:
```
V_avg_rect = (2 / T) · ∫[0 .. T/2] (2A/T)·t dt = (4A / T²) · [ t² / 2 ] |[0 .. T/2] = (4A / T²) · (T² / 8) = A / 2 = 0.5000 · A
```

- Середньоквадратичне значення:
```
V_rms² = (2 / T) · ∫[0 .. T/2] ((2A / T)·t)² dt
       = (8A² / T³) · [ t³ / 3 ] |[0 .. T/2]          [первісна від квадрата координати]
       = (8A² / T³) · (T³ / 24)
       = A² / 3
V_rms  = A / √3 ≈ 0.5774 · A
```

- Коефіцієнти:
```
k_f = (A / √3) / (A / 2) = 2 / √3 ≈ 1.1547
k_c = A / (A / √3) = √3 ≈ 1.7321   (4.77 дБ)
```

#### 4. Уніполярний ШІМ-імпульс (`0 .. A`, коефіцієнт заповнення `D`)

```
V_avg = (1 / T) · ∫[0 .. D·T] A dt = D · A

V_rms² = (1 / T) · ∫[0 .. D·T] A² dt = (A² / T) · (D · T) = D · A²
V_rms  = A · √D

k_c = V_peak / V_rms = A / (A · √D) = 1 / √D
```

При малих коефіцієнтах заповнення (`D = 0.01` або 1%) пік-фактор зростає до `k_c = 1 / √0.01 = 10` (20 дБ). Це означає, що пікова напруга вдесятеро перевищує діючу, вимагаючи від силових напівпровідникових ключів десятикратного запасу за напругою та струмом порівняно з еквівалентною тепловою потужністю постійного струму.
