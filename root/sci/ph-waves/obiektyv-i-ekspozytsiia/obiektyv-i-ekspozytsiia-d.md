## Фізична природа оптичної експозиції та світлосила об'єктива

Термін експозиція (від латинського *expositio* — виставлення напоказ, дія світла) в оптиці та фотоніці визначає поверхневу густину світлової енергії, що падає на світлочутливу площину сенсора за час зйомки. Кількісно фотометрична експозиція `H` (у системі SI вимірюється в люкс-секундах, `лк · с`) є інтегралом миттєвої освітленості `E_v` матриці за часом накопичення заряду `t_exp`:

```
H = E_v · t_exp    [фотометрична експозиція для стаціонарного освітлення]
```

Освітленість `E_v` у площині зображення формується об'єктивом, який збирає світловий потік від просторової сцени з яскравістю `L` (вимірюється в канделах на квадратний метр, `кд / м²`). Здатність об'єктива пропускати світловий потік визначається його вхідною оптичною зіницею та фокусною відстанню.

Обмеження світлових пучків здійснює апертурна діафрагма (від грецького *diaphragma* — перегородка та латинського *apertura* — отвір) — механічна або фіксована кругла перешкода, встановлена всередині оптичної схеми. Оптичне зображення діафрагми через передню групу лінз у просторі предметів називається вхідною зіницею (entrance pupil) діаметром `D`.

Геометрична світлосила об'єктива кількісно описується діафрагмовим числом `N` (F-number):

```
N = f / D
= f_opt / D_pupil    [діафрагмове число об'єктива]
```

де `f` — ефективна фокусна відстань об'єктива, а `D` — фізичний діаметр вхідної зіниці.

У мікроскопічній та волоконній оптиці замість діафрагмового числа використовують числову апертуру `NA` (Numerical Aperture):

```
NA = n · sin(θ_max)
≈ 1 / (2 · N)        [зв'язок числової апертури з діафрагмовим числом у повітрі]
```

де `n` — показник заломлення середовища (`n = 1.0` для повітря), а `θ_max` — максимальний апертурний напівкут світлового конуса.

Оскільки площа отвору вхідної зіниці пропорційна квадрату її діаметра `A_pupil = π · D² / 4`, а площа зображення, на яку проектується фіксований кутовий сектор простору, пропорційна квадрату фокусної відстані `f²`, просторова густина світлового потоку (освітленість `E`) на оптичній осі сенсора обернено пропорційна квадрату діафрагмового числа:

```
E_v ∝ (D / f)²
= 1 / N²             [залежність освітленості сенсора від діафрагмового числа]
```

Через квадратичну залежність стандартний ряд діафрагмових чисел будується як геометрична прогресія зі знаменником `√2 ≈ 1.414`:

```
f/1.0 → f/1.4 → f/2.0 → f/2.8 → f/4.0 → f/5.6 → f/8.0 → f/11 → f/16 → f/22
```

Кожен крок у цьому ряді (званий повним ступенем або 1 EV стопом) змінює площу вхідного отвору рівно вдвічі, що призводить до двократного збільшення або зменшення світлового потоку, який досягає матриці.

### Механічна конструкція ірисової діафрагми та дифракційні промені

У змінних об'єктивах апертурний отвір формується ірисовою діафрагмою, що складається з кількості рухомих металевих пелюсток `k` (зазвичай від 5 до 9). Форма отвору являє собою багатокутник. 

При зйомці точкових джерел світла на закритих діафрагмах прямі ребра пелюсток викликають дифракцію Фраунгофера, утворюючи характерні дифракційні промені (зіркоподібні промені навколо ліхтарів):
- Якщо кількість пелюсток `k` є **парною** (наприклад, `k = 6` або `8`), промені від протилежних паралельних ребер накладаються один на одного, утворюючи рівно `k` дифракційних променів;
- Якщо кількість пелюсток `k` є **непарною** (наприклад, `k = 7` або `9`), дифракційні картини від кожного ребра не збігаються, формуючи подвійну кількість променів: `2 · k` (14 або 18 променів).

Для усунення дифракційних артефактів та отримання ідеально круглого розмиття поза зоною різкості (боке) сучасні об'єктиви оснащують заокругленими пелюстками (Circular Aperture Blades), які зберігають форму кола при будь-якому положенні приводу.

У реальних багатолінзових об'єктивах частина світла втрачається на френелівське відбиття від меж скло-повітря та на поглинання в товщі оптичного скла. Для точного обліку енергетичних втрат використовують фотометричне діафрагмове число `T-stop` (transmission stop):

```
T = N / √τ           [фотометричний T-stop з урахуванням коефіцієнта пропускання τ]
```

де `τ` — інтегральний коефіцієнт оптичного пропускання об'єктива (для сучасних просвітлених багатокомпонентних систем `τ ≈ 0.85 … 0.95`). Повний математичний вивід зв'язку освітленості матриці з яскравістю сцени та числовим значенням апертури наведено у вставці [Математичний аналіз глибини різкості та фотометрії сенсора](root:ph-waves/obiektyv-i-ekspozytsiia/math-dof-and-hyperfocal.md).

## Час накопичення заряду та оптико-електронна витримка

Витримка (час експонування, `t_exp`) задає тривалість інтервалу часу, протягом якого світловий потік падає на світлочутливі елементи сенсора та генерує вільні носії заряду.

У сучасних напівпровідникових CMOS-матрицях із пікселями на основі 4T-транзисторів (Pinned Photodiode) фотодіод інтегрує фотострум `I_ph`, пропорційний потоку фотонів:

```
Q_photo = I_ph · t_exp
= (R_ph · Φ_opt) · t_exp    [накопичений фотоелектричний заряд у потенціальній ямі]
```

де `R_ph` — спектральна струмова чутливість кремнію (вимірюється в `А / Вт`), а `Φ_opt` — падаючий оптичний потік на активну площу пікселя.

Керування часом інтеграції в електронних сенсорах здійснюється двома принципово різними способами:

1. **Глобальний затвор (Global Shutter)**: Усі пікселі матриці одночасно скидають накопичений паразитичний заряд, одночасно починають інтеграцію світла на інтервал `t_exp` і одночасно передають накопичені зарядові пакети в захищені від світла внутрішні комірки пам'яті пікселя (Storage Node). Забезпечує геометрично неспотворене відображення високошвидкісних об'єктів, що обертаються чи рухаються з великим прискоренням.
2. **Порядковий затвор (Rolling Shutter)**: Рядки сенсора скидаються та зчитуються послідовно один за одним із часовим зсувом `Δt_row = t_frame / H_lines`. Хоча кожен окремий рядок інтегрує світло точно протягом заданого часу `t_exp`, верхні й нижні рядки кадру фіксують стан сцени в різні фізичні моменти часу. При швидкому панорамуванні або русі об'єктів це викликає артефакти дисторсії: вертикальні лінії нахиляються, кола перетворюються на еліпси, а обертові пропелери зазнають просторового розриву (хвильовий ефект).

### Фізичне обмеження на змаз зображення (Motion Blur)

При русі об'єкта зі швидкістю `v_obj` у площині спостереження на робочій відстані `s` його оптична проекція зміщується по сенсору зі швидкістю `v_img = M · v_obj = (f / s) · v_obj`, де `M` — масштаб поперечного оптичного збільшення.

Зсув зображення точкового джерела на сенсорі за час експозиції становить:

```
Δx_blur = v_img · t_exp
= (f / s) · v_obj · t_exp    [величина оптичного змазу на поверхні сенсора]
```

Щоб змаз руху не перевищував розміру одного фізичного пікселя `p_pix` (тобто не спричиняв деградації просторової роздільної здатності системи), граничний час витримки повинен задовольняти строгу нерівність:

```
t_exp ≤ (p_pix · s) / (f · v_obj)    [критерій субпіксельної чіткості динамічної сцени]
```

Для камери з пікселем `3.45 мкм`, фокусною відстанню `16 мм`, що знімає дрон на відстані `10 м`, який рухається поперечно зі швидкістю `20 м/с`, максимально допустима витримка становить:

```
t_max = (3.45 · 10⁻⁶ · 10) / (0.016 · 20)    [підстановка параметрів пікселя та швидкості]
= 3.45 · 10⁻⁵ / 0.32                         [обчислення чисельника та знаменника]
= 1.078 · 10⁻⁴ с ≈ 1/1000 с                  [ділення та округлення до стандартного ряду]
```

## Аналогове та цифрове підсилення (ISO Gain) і квантовий шум

Після завершення інтервалу інтеграції `t_exp` накопичений фотодіодом заряд `Q_photo` передається на вузол плаваючого дифузійного переходу (Floating Diffusion — FD). Вузлова ємність `C_fd` перетворює заряд на вихідну напругу:

```
V_signal = Q_photo / C_fd    [напруга вузла перетворення заряду]
```

Коефіцієнт перетворення заряду в напругу (Conversion Gain) зазвичай становить від `20` до `100 мкВ / e⁻`.

Отримана напруга надходить на аналоговий підсилювач із програмованим коефіцієнтом передачі (PGA — Programmable Gain Amplifier) перед оцифруванням у блоці АЦП:

1. **Аналогове підсилення (Analog Gain, G_ana)**: Масштабує низькорівневу напругу безпосередньо в аналоговому тракті перед входом АЦП. Аналогове підсилення множить як корисний фотосигнал, так і власний шум фотодіода, але піднімає рівень сигналу вище порогу шумів квантування та шумів компараторів АЦП.
2. **Цифрове підсилення (Digital Gain, G_dig)**: Виконує арифметичне множення вихідних двійкових кодів АЦП на числовий множник. Цифрове підсилення не додає нової фізичної інформації, не покращує співвідношення сигнал/шум і зменшує кількість градацій яскравості (призводить до постеризації).

Загальна чутливість за шкалою ISO задається добутком:

```
ISO = ISO_base · G_ana · G_dig    [еквівалентна чутливість системи]
```

де `ISO_base` — базова чутливість матриці при одиничному підсиленні (`G_ana = 1.0`), яка визначається квантовою ефективністю кремнію (QE) та розміром активної площі пікселя.

### Формування шуму та співвідношення сигнал/шум (SNR)

Сумарне число електронів на виході пікселя та відповідне співвідношення сигнал/шум описується моделлю, що враховує фундаментальні фізичні джерела флуктуацій:

```
SNR = N_e / √(N_e + I_dark · t_exp + σ_read² + σ_adc² / G_ana²)    [співвідношення сигнал/шум]
```

де:
- `N_e` — середнє число зібраних фотоелектронів;
- `√(N_e)` — пуассонівський фотонний дробовий шум (Photon Shot Noise), зумовлений дискретною квантовою природою світла;
- `I_dark · t_exp` — накопичений тепловий заряд темнового струму (Dark Current Shot Noise);
- `σ_read` — адитивний шум зчитування схеми пікселя (тепловий шум Джонсона та флікер-шум 1/f транзистора скидання);
- `σ_adc` — шум квантування АЦП.

Зі зростанням аналогового підсилення `G_ana` внесок шуму АЦП нівелюється, проте максимальний реєстрований заряд пікселя падає пропорційно `1 / G_ana`. Внаслідок цього ефективний динамічний діапазон (Dynamic Range — DR) матриці лінійно зменшується на 1 EV на кожен ступінь підвищення ISO:

```
DR(ISO) = DR_base - log₂(ISO / ISO_base)    [деградація динамічного діапазону з ростом ISO]
```

При базовій ємності потенційної ями (Full Well Capacity) `FWC = 20 000 e⁻` та шумі зчитування `σ_read = 2.0 e⁻` базовий динамічний діапазон становить `DR_base = 20 · log₁₀(20 000 / 2.0) = 80 дБ` (або `13.3 EV`). При підвищенні підсилення до ISO 1600 (`16x`) динамічний діапазон стискається до `9.3 EV`.

## Закон взаємозамінності та експозиційне число (EV)

Закон взаємозамінності (закон Бунзена–Роско, сформульований Робертом Бунзеном та Генрі Роско у 1855 році) стверджує, що однаковий фотометричний відгук світлочутливого матеріалу або детектора досягається при сталій величині експозиції `H = E_v · t_exp`, незалежно від того, формується вона високою освітленістю за короткий проміжок часу чи низькою освітленістю за тривалий інтервал:

```
E₁ · t₁ = E₂ · t₂ = const    [класичний закон взаємозамінності Бунзена–Роско]
```

У фотохімічних емульсіях закон взаємозамінності зазнає відхилення (ефект Шварцшильда) через розпад нестабільних сублітентних центрів срібла при слабкому світлі або рекомбінацію носіїв при надкоротких спалахах. У кремнієвих сенсорах закон взаємозамінності виконується строго в широкому діапазоні тривалостей (`10⁻⁵ … 10⁰ с`), обмежений зверху накопиченням темнового струму, а знизу — швидкістю керуючих драйверів затвора.

### Розрахунок експозиційного числа (Exposure Value — EV)

Для однозначного опису комбінацій діафрагми та витримки в 1954 році німецьким інженером Фрідріхом Декелем (розробником затворів Compur) було запропоновано логарифмічну шкалу експозиційних чисел (EV).

Базове експозиційне число `EV` визначається як логарифм за основою 2 від відношення квадрата діафрагмового числа до часу витримки:

```
EV = log₂(N² / t_exp)    [базове експозиційне число для чутливості ISO 100]
```

Для довільного значення світлочутливості `ISO` експозиційне число нормалізується до еталонного значення ISO 100 (`EV₁₀₀`):

```
EV₁₀₀ = log₂(N² / t_exp) - log₂(ISO / 100)    [нормалізоване експозиційне число]
```

Зв'язок між експозиційним числом та фотометричною яскравістю об'єкта зйомки `L` (у `кд / м²`) визначається рівнянням калібрування експонометрів за стандартом ISO 2720:

```
2^(EV₁₀₀) = (L · 100) / K    [зв'язок EV з яскравістю сцени]
```

де `K` — калібрувальна константа вимірювача відбитого світла (стандартне значення `K = 12.5 … 14.0 кд · с / м²`).

Детальний огляд еволюції методів сенситометрії, логарифмічних характеристичних кривих Юртера–Дріффілда та створення стандарту APEX (Additive System of Photographic Exposure) викладено у вставці [Історія сенситометрії та стандартизації експозиційних чисел](root:ph-waves/obiektyv-i-ekspozytsiia/hist-exposure-standards.md).

| Світлова ситуація в реальному середовищі | Освітленість поверхні, лк | Яскравість сцени `L`, кд/м² | Експозиційне число `EV₁₀₀` | Типова комбінація (ISO 100) |
|---|---|---|---|---|

| Похмурий день / глибока тінь | `2 500` | `200` | `+11` | `f/4.0`, `1/125 с` |

## Кружок розмиття, глибина різкості (DoF) та гіперфокальна відстань

При формуванні зображення ідеально різкими на сенсорі відображаються лише ті точки простору предметів, які лежать у точній геометричній площині фокусування на відстані `s`. Промені від точок, розташованих ближче або далі від цієї площини, перетинаються попереду або позаду площини сенсора. У результаті замість нескінченно малої точки на сенсор проектується розбіжний або збіжний конус променів, утворюючи пляму кінцевого діаметра — кружок розмиття (Circle of Confusion — CoC).

![Геометрія глибини різкості, кружок розмиття (CoC) та гіперфокальна відстань](/root/sci/ph-waves/obiektyv-i-ekspozytsiia/img/dof-geometry-coc.svg)
*Хід променів при дефокусуванні: утворення кружка розмиття c на площині сенсора від точок, розташованих на ближній D_n та дальній D_f межах різкості.*

Доки діаметр кружка розмиття `c` не перевищує граничного порогу сприйняття людського ока або просторового розміру пікселя сенсора, зображення сприймається різким.

У класичній фотографії допустимий діаметр кружка розмиття визначається за формулою Цейса як відношення діагоналі кадру `d_sensor` до роздільної здатності стандартного спостерігача:

```
c_photo = d_sensor / 1500    [допустимий кружок розмиття для друку та візуального огляду]
```

Для повнокадрового сенсора `36 × 24 мм` (`d = 43.3 мм`) величина `c ≈ 0.029 мм` (`29 мкм`). У системах комп'ютерного зору та машинної інспекції, де аналіз ведеться на рівні окремих пікселів, поріг встановлюють значно жорсткішим:

```
c_cv = (1.0 … 2.0) · p_pix    [кружок розмиття на рівні піксельної сітки матриці]
```

Для пікселя розміром `3.45 мкм` допустимий кружок становить `c = 3.45 … 6.9 мкм`.

### Розрахунок меж глибини різкості та гіперфокальної відстані

Глибина різкості (Depth of Field — DoF) — це просторовий діапазон уздовж оптичної осі в просторі предметів, у межах якого всі об'єкти відображаються з розмиттям, меншим або рівним `c`.

Гіперфокальна відстань `H` (від грецького *hyper* — над, понад та латинського *focus* — вогнище) визначається як дистанція фокусування, при якій далека межа глибини різкості віддаляється в нескінченність (`D_f = ∞`):

```
H = f² / (N · c) + f
≈ f² / (N · c)       [гіперфокальна відстань об'єктива]
```

Якщо об'єктив сфокусовано на довільну дистанцію `s`, ближня межа різкості `D_n` та дальня межа `D_f` обчислюються за виведеними з геометричної оптики формулами:

```
D_n = (s · H) / (H + (s - f))    [ближня межа різко зображуваного простору]
```

```
D_f = (s · H) / (H - (s - f))    [дальня межа різко зображуваного простору]
```

Повна глибина різкості `ΔD` становить:

```
ΔD = D_f - D_n
= (2 · s · H · (s - f)) / (H² - (s - f)²)
≈ (2 · s² · N · c) / f²    [повна глибина різкості при s ≪ H]
```

Коли об'єктив сфокусовано строго на гіперфокальну відстань `s = H`, підстановка дає:
- Ближня межа: `D_n = H / 2`;
- Дальня межа: `D_f = ∞`.

Це фундаментальне правило використовується в ширококутних камерах дронів, автомобільних відеореєстраторах та екшн-камерах із фіксованим фокусом (Fixed Focus): встановивши фокус на `H`, інженери отримують різке зображення всього простору від `H / 2` до нескінченності без використання рухомих моторів автофокусування.

### Частотно-контрастна характеристика (MTF) та дифракційна межа

Якість оптичного зображення кількісно описується просторовою передавальною функцією модуляції (Modulation Transfer Function — MTF), яка вимірює здатність об'єктива передавати контраст деталей різної просторової частоти (вимірюється в парах ліній на міліметр, `lp / mm`).

При зміні діафрагмового числа `N` на криву MTF впливають два протидіючі фізичні механізми:
1. **Геометричні аберації (сферична аберація, кома, астигматизм)**: найбільш інтенсивні на відкритій діафрагмі (`f/1.4 … f/2.0`). Крайові промені заломлюються з похибкою, що розмиває точку зображення та знижує контраст на високих просторових частотах.
2. **Дифракційне розмиття на круглій зіниці**: зростає при закритті діафрагми (`f/11 … f/22`). Точкове джерело світла через дифракцію перетворюється у фокальній площині на дифракційну картину Ейрі. Фізичний діаметр центрального диска Ейрі `d_Airy` (до першого темного кільця) дорівнює:

```
d_Airy = 2.44 · λ · N    [діаметр дифракційного диска Ейрі]
```

Для зеленого світла (`λ = 550 нм = 0.55 мкм`):
- При `f/2.8`: `d_Airy = 2.44 · 0.55 · 2.8 = 3.76 мкм`;
- При `f/8.0`: `d_Airy = 2.44 · 0.55 · 8.0 = 10.74 мкм`;
- При `f/16`: `d_Airy = 2.44 · 0.55 · 16.0 = 21.47 мкм`.

Гранична дифракційна частота зрізу просторового контрасту становить:

```
ν_cutoff = 1 / (λ · N)    [дифракційна межа просторової частоти]
```

Для `f/2.8` межа `ν_cutoff ≈ 650 lp/mm`, тоді як для `f/16` вона падає до `113 lp/mm`. Точка перетину дифракційного обмеження та геометричних аберацій задає так зване оптимальне діафрагмове число (sweet spot) об'єктива — зазвичай у діапазоні від `f/4.0` до `f/8.0`.

## Віньєтування та оптичні аберації в комп'ютерному зорі

Віньєтуванням (від французького *vignette* — віньєтка, орнаментальне обрамлення) називають просторовий спад освітленості зображення від оптичного центра кадру до його периферійних кутів.

![Закон спадання освітленості cos⁴ θ, геометрія похилих пучків та віньєтування](/root/sci/ph-waves/obiektyv-i-ekspozytsiia/img/vignetting-cos4-law.svg)
*Геометрія похилих променів і чотири фізичні множники закону природного віньєтування cos⁴ θ.*

Фізично виділяють три незалежні механізми виникнення віньєтування:

1. **Природне віньєтування (Natural Vignetting — закон `cos⁴ θ`)**: Фундаментальне геометричне явище, що виникає при падінні похилого пучка променів під кутом `θ` до оптичної осі. Спад освітленості є добутком чотирьох тригонометричних множників `cos θ`:
   - Вихідна зіниця при спостереженні під кутом `θ` проектується як еліпс із малою піввіссю, зменшеною в `cos θ` разів (ефективна площа зменшується: `A(θ) = A₀ · cos θ`);
   - Відстань від вихідної зіниці до краю сенсора зростає як `r(θ) = d / cos θ`. За законом обернених квадратів освітленість падає пропорційно `1 / r² = cos² θ / d²`;
   - Кут падіння променів на плоску поверхню сенсора становить `θ`. За [законом косинуса Ламберта](root:ph-waves/lambert-cosine-law) площа перетину пучка площиною сенсора розширюється, що дає ще один множник `cos θ`.
   
   Сумарний спад освітленості на краю сенсора під кутом `θ` описується точним законом:

   ```
   E(θ) = E₀ · cos⁴ θ    [закон природного спадання освітленості]
   ```

   Для ширококутного об'єктива з напівкутом поля зору `θ = 35°` освітленість кутів падає до `cos⁴(35°) ≈ (0.8192)⁴ = 0.45` (втрата 55% світла, або `-1.15 EV`).

2. **Оптичне та механічне віньєтування (Optical/Mechanical Vignetting)**: Фізичне зрізання похилих світлових пучків краями оправи передньої чи задньої лінзи об'єктива, блендою або різьбовими фільтрами. Проявляється сильніше на відкритих діафрагмах (`f/1.4 … f/2.8`) і практично повністю зникає при діафрагмуванні до `f/8.0`.
3. **Піксельне віньєтування (Pixel Vignetting)**: Зниження ефективності збору світла мікролінзами сенсора. Оскільки кремнієві фотодіоди розташовані на дні технологічних колодязів металізації (у FSI-сенсорах), світлові промені, що падають під кутом головного променя (Chief Ray Angle — CRA), більшим за `25° … 30°`, частково блокуються металевими шинами або зазнають повного внутрішнього відбиття в мікролінзі. Якщо об'єктив не оптимізований під CRA сенсора (Lens CRA ≠ Sensor CRA), на краях зображення виникає не лише затемнення, а й викривлення передачі кольору (Color Shading / Crosstalk).

### Вплив на алгоритми комп'ютерного зору та калібрування

Нерівномірність освітленості та оптичні аберації (сферична аберація, кома, хроматизм, описані в [Оптичні аберації](root:ph-waves/optical-aberrations)) деструктивно впливають на роботу систем просторового аналізу:
- **Детектори локальних ознак (SIFT, ORB, FAST)**: Локальні градієнти яскравості на краях кадру затухають, що призводить до відсікання контрольних точок за порогом контрастності;
- **Фотометричне 3D-сканування та фотометричне стерео**: Спад яскравості на краях хибно інтерпретується як зміна орієнтації нормалей поверхні предмета;
- **Сегментація та виявлення дефектів**: Створюються хибні контури низької яскравості на однорідних фонах.

Для компенсації віньєтування перед обробкою застосовують площинне калібрування (Flat-Field Correction — FFC):

```
I_corrected(x, y) = ((I_raw(x, y) - I_dark(x, y)) / (I_flat(x, y) - I_dark(x, y))) · Mean(I_flat - I_dark)
```

де `I_flat` — еталонний кадр, знятий на рівномірно освітленій інтегруючій сфері або дифузному калібраторі, а `I_dark` — темновий кадр сенсора.

## Автоматичне керування експозицією (AEC/AGC) у вбудованих системах

Вбудовані системи технічного зору, процесори обробки сигналів зображення (ISP) та мікроконтролери камерних модулів використовують замкнені цифрові контури автоматичного регулювання експозиції (AEC — Auto Exposure Control) та підсилення (AGC — Auto Gain Control).

![Архітектура контуру автоматичного керування експозицією (AEC/AGC)](/root/sci/ph-waves/obiektyv-i-ekspozytsiia/img/aec-control-loop.svg)
*Схема замкненого цифрового контуру AEC/AGC: збір статистики яскравості, розрахунок похибки регулювання та пріоритетний розподіл між витримкою і підсиленням.*

### Архітектура контуру керування та збір статистики

1. **Модуль збору просторової статистики (Luminance Statistics)**: Кадр ділиться на сітку блоків `M × N` (наприклад, `16 × 16` зон). Для кожної зони обчислюється яскравість `Y_block = 0.299·R + 0.587·G + 0.114·B` або будується 256-рівнева гістограма яскравості.
2. **Зважена середня яскравість (Center-Weighted Metering)**: Для запобігання помилкам експозиції через яскраве небо або локальні відблиски застосовується вагове просторове маскування:

   ```
   Y_current = (∑ w_ij · Y_ij) / (∑ w_ij)    [зважена яскравість кадру]
   ```

   де `w_ij` — коефіцієнти просторового пріоритету (центральні блоки мають у 4–8 разів більшу вагу, ніж периферійні).
3. **Обчислення похибки та логарифмічного зсуву `ΔEV`**:

   ```
   Error = Y_target - Y_current
   ΔEV = log₂(Y_target / max(Y_current, ε))    [необхідна зміна експозиційного числа]
   ```

   Цільове значення яскравості `Y_target` для 8-бітного діапазону (`0 … 255`) зазвичай вибирається рівним `118` (що відповідає 18% коефіцієнту відбиття еталонної сірої карти за шкалою гамма-корекції `sRGB` з `γ = 2.2`: `255 · (0.18)^(1/2.2) ≈ 118`).
4. **Регулятор із зоною нечутливості (Deadband Filter)**: Якщо `|Error| < Deadband` (наприклад, `±3` рівні яскравості), параметри не змінюються. Це усуває паразитичне тремтіння яскравості (flicker) між сусідніми кадрами.

### Пріоритетний розподіл параметрів (Exposure vs Gain Scheduling)

При зміні освітленості регулятор розподіляє потрібну експозицію між витримкою `t_exp` та підсиленням `Gain` за строгим пріоритетним алгоритмом:

- **Денний режим (надлишок світла)**: Підсилення зафіксоване на мінімальному значенні `Gain = 1.0` (ISO 100). Регулятор варіює лише час витримки від `1/32000 с` до `1/1000 с`.
- **Нормальний режим**: При подальшому падінні світла витримка збільшується до граничного значення проти змазу руху `t_max_motion` (наприклад, `1/120 с` або `1/60 с`). Підсилення залишається мінімальним (`Gain = 1.0`), забезпечуючи максимальний динамічний діапазон і нульовий шум.
- **Сутінковий режим**: Коли витримка досягла порогу `t_max_motion`, вона фіксується, а контур починає нарощувати аналогове підсилення `G_ana` від `1.0` до максимального апаратного ліміту (наприклад, `16.0` або `64.0`).
- **Нічний режим (екстремальна темрява)**: Якщо аналогове підсилення вичерпано, система дозволяє подовження витримки до міжфазового інтервалу кадрової частоти `1/FPS` і, за крайньої потреби, вмикає цифрове підсилення `G_dig`.

### Захист від мерехтіння освітлення (Anti-Flicker)

Штучне освітлення від газорозрядних та дешевих світлодіодних ламп пульсує з подвоєною частотою живильної електромережі: `100 Гц` (для мережі 50 Гц у Європі та Україні) або `120 Гц` (для мережі 60 Гц у США). Період пульсації становить `T_flicker = 10.0 мс` або `8.333 мс`.

Якщо час інтеграції `t_exp` не є кратним `T_flicker`, рядки сенсора при порядковому зчитуванні зафіксують різну фазу світлового імпульсу, що породить рухомі світлі й темні горизонтальні смуги по всьому кадру.

Для придушення мерехтіння алгоритм квантує час експонування дискретними кроками:

```
t_exp ∈ { k · (1 / (2 · f_grid)) } = { 10.0 мс, 20.0 мс, 30.0 мс, … }    [для 50 Гц мережі]
```

Повний працюючий програмний модуль контролера експозиції та підсилення мовами C та ідіоматичною C++20 наведено у вставці [Модуль автоматичного регулювання експозиції та підсилення AEC/AGC](root:ph-waves/obiektyv-i-ekspozytsiia/proj-aec-agc-controller.md).

> 🔧 **Навіщо це.**
> У системах стереоскопічного технічного зору автономних роботів та дронів (наприклад, стереопара на базі двох сенсорів Sony IMX296/OV9281) розсинхронізація експозиції навіть на `0.2 EV` або різниця в часі початку інтеграції на `100 мкс` руйнує роботу алгоритму напівглобального зіставлення блоків (Semi-Global Matching — SGM). Лівий і правий кадри отримують різні локальні градієнти яскравості, внаслідок чого функція ціни різниці інтенсивностей (Census Transform / SAD) продукує хибні карти глибини з дірками та артефактами фантомних перешкод. Для надійної навігації обидві камери обов'язково переводять у режим апаратного веденого запуску (Hardware Trigger), а контур автоекспозиції обчислює єдиний спільний вектор параметрів `{t_exp, Gain}` за комбінованою статистикою обох матриць одночасно.
