# 🧮 Математичний аналіз глибини різкості та фотометрії сенсора

Математичний апарат розрахунку оптичних систем дозволяє аналітично встановити зв'язок між геометрією заломлення світлових променів, просторовими межами різко зображуваного простору та фотометричною густиною енергії на поверхні кремнієвого сенсора. Нижче наведено послідовні строгі виведення рівняння освітленості сенсора через яскравість сцени, формул ближньої й дальньої меж глибини різкості (DoF), гіперфокальної відстані, їхніх макроскопічних наближень та хвильового оптимуму діафрагми.

## Фотометричне рівняння освітленості в площині сенсора

Розглянемо дифузний елемент поверхні об'єкта площею `dA_o` з ламбертівською яскравістю `L` (вимірюється в `кд / м²` або `Вт / (ср · м²)` у радіометричних одиницях), розташований на оптичній осі на відстані `d_o` від об'єктива.

Світловий потік `dΦ_o`, випромінюваний елементом `dA_o` у напрямку вхідної зіниці об'єктива діаметром `D`, визначається інтегруванням яскравості по тілесному куту `dΩ_p`, під яким вхідна зіниця видна з точки об'єкта:

```
dΩ_p = A_pupil / d_o²         [означення тілесного кута]
= (π · (D / 2)²) / d_o²       [площа круглої зіниці радіусом D/2]
= (π · D²) / (4 · d_o²)       [піднесення до квадрата]
```

Випромінений світловий потік:

```
dΦ_o = L · dA_o · dΩ_p                      [закон випромінювання дифузного джерела]
= L · dA_o · (π · D²) / (4 · d_o²)          [підстановка тілесного кута dΩ_p]
```

З урахуванням коефіцієнта оптичного пропускання об'єктива `τ`, світловий потік, що проходить крізь оптичну систему та падає на спряжений елемент зображення площею `dA_i` у площині сенсора, становить:

```
dΦ_i = τ · dΦ_o                             [облік втрат на поглинання та відбиття]
= τ · L · dA_o · (π · D²) / (4 · d_o²)      [підстановка виразу dΦ_o]
```

Освітленість елемента сенсора `E` визначається як відношення світлового потоку до площі зображення `dA_i`:

```
E = dΦ_i / dA_i                                             [означення освітленості]
= τ · L · (dA_o / dA_i) · (π · D²) / (4 · d_o²)             [підстановка виразу для dΦ_i]
```

Відношення площ елементів `dA_o / dA_i` пов'язане з лінійним оптичним збільшенням `M = h_i / h_o = d_i / d_o` через квадрат масштабу:

```
dA_i / dA_o = M²
dA_o / dA_i = 1 / M² = d_o² / d_i²                          [геометричне масштабування площ]
```

Підставляючи вираз для відношення площ в рівняння освітленості, отримуємо скорочення відстані до предмета `d_o`:

```
E = τ · L · (d_o² / d_i²) · (π · D²) / (4 · d_o²)           [підстановка dA_o / dA_i]
= (τ · π · L / 4) · (D / d_i)²                              [скорочення квадрата відстані d_o²]
```

Виразимо відстань до зображення `d_i` через фокусну відстань `f` та збільшення `M`. З формули тонкої лінзи `1/d_o + 1/d_i = 1/f` маємо:

```
d_i = f · (1 + M)                                           [відстань від лінзи до сенсора]
```

Підставляємо `d_i` та вводимо діафрагмове число `N = f / D`:

```
E = (τ · π · L / 4) · (D / (f · (1 + M)))²                  [підстановка d_i = f · (1 + M)]
= (τ · π · L) / (4 · (f / D)² · (1 + M)²)                   [винесення відношення (f / D)²]
= (τ · π · L) / (4 · N² · (1 + M)²)                         [введення діафрагмового числа N = f / D]
```

Для дистанцій зйомки, значно більших за фокусну відстань об'єктива (`d_o ≫ f`), оптичне збільшення прямує до нуля (`M → 0`, `1 + M ≈ 1`), звідки отримуємо канонічну фотометричну формулу для нескінченно віддалених об'єктів:

```
E₀ = (τ · π · L) / (4 · N²)                                 [осьова освітленість для віддаленої сцени]
```

### Врахування похилих пучків (виведення закону cos⁴ θ)

Якщо світловий пучок падає на сенсор під кутом `θ` до оптичної осі, виникають чотири послідовні геометричні зміни:
1. Проекція вхідної зіниці на напрямок пучка зменшує її видиму площу: `A_eff(θ) = A_pupil · cos θ`;
2. Проекція елемента поверхні предмета `dA_o` на промінь зору дає множник: `cos θ`;
3. Відстань від вихідної зіниці до точки сенсора зростає: `d_i(θ) = d_i / cos θ`, що за законом обернених квадратів дає спад `1 / d_i(θ)² = cos² θ / d_i²`;
4. Проекція падаючого конуса променів на площину матриці за законом Ламберта дає множник `cos θ`.

Перемножуючи всі складові, отримуємо:

```
E(θ) = E₀ · cos θ · cos² θ · cos θ                          [перемноження чотирьох факторів кута]
= E₀ · cos⁴ θ                                               [закон природного спадання освітленості]
```

## Строге геометричне виведення меж глибини різкості (DoF)

Нехай оптична система з фокусною відстанню `f` та діаметром зіниці `D = f / N` сфокусована на предмет, розташований на відстані `s`. Площина сенсора встановлена на відстані `d_i`, яка визначається формулою тонкої лінзи:

```
d_i = (f · s) / (s - f)                                     [положення площини сенсора]
```

Розглянемо об'єкт, розташований ближче площини фокусування на дистанції `D_n < s`. Промені від нього сходяться за сенсором у площині `d_i,n`:

```
d_i,n = (f · D_n) / (D_n - f)                               [положення зображення ближньої точки]
```

Оскільки `D_n < s`, то `d_i,n > d_i`. Конус променів, що сходиться до точки `d_i,n`, перетинає площину сенсора `d_i`, утворюючи круглу пляму розмиття діаметром `c`.

З подібності трикутників, утворених вихідною зіницею діаметром `D` та збіжним конусом променів:

```
c / D = (d_i,n - d_i) / d_i,n                               [відношення подібності конусів]
= 1 - (d_i / d_i,n)                                         [почленне ділення на d_i,n]
```

Виразимо відношення `d_i / d_i,n`:

```
d_i / d_i,n = ((f · s) / (s - f)) / ((f · D_n) / (D_n - f)) [підстановка виразів d_i та d_i,n]
= (s · (D_n - f)) / (D_n · (s - f))                         [скорочення спільного множника f]
```

Підставляємо це відношення у рівняння для `c / D`:

```
c / D = 1 - (s · (D_n - f)) / (D_n · (s - f))               [підстановка відношення відстаней]
= (D_n · (s - f) - s · (D_n - f)) / (D_n · (s - f))         [зведення до спільного знаменника]
= (D_n · s - D_n · f - s · D_n + s · f) / (D_n · (s - f))   [розкриття дужок у чисельнику]
= (f · (s - D_n)) / (D_n · (s - f))                         [взаємне знищення D_n · s]
```

Враховуючи, що `D = f / N`:

```
(c · N) / f = (f · (s - D_n)) / (D_n · (s - f))             [підстановка D = f / N]
c · N · D_n · (s - f) = f² · (s - D_n)                      [множення обох частин на знаменники]
D_n · (c · N · (s - f) + f²) = f² · s                       [групування членів із D_n]
```

Введемо позначення гіперфокальної складової `H_0 = f² / (N · c)` (звідки `f² = H_0 · N · c`):

```
D_n · (c · N · (s - f) + H_0 · N · c) = H_0 · N · c · s     [підстановка f² = H_0 · N · c]
D_n · ((s - f) + H_0) = H_0 · s                             [скорочення спільного множника c · N]
D_n = (s · H_0) / (H_0 + (s - f))                           [точна формула ближньої межі різкості]
```

### Виведення дальньої межі різкості `D_f`

Для об'єкта, розташованого далі площини фокусування на відстані `D_f > s`, промені сходяться перед сенсором у площині `d_i,f < d_i`:

```
d_i,f = (f · D_f) / (D_f - f)                               [положення зображення дальньої точки]
```

Після точки фокуса промені розходяться і на площині сенсора утворюють кружок розмиття `c`. З подібності трикутників:

```
c / D = (d_i - d_i,f) / d_i,f                               [відношення подібності трикутників]
= (d_i / d_i,f) - 1                                         [почленне ділення на d_i,f]
```

Підставляючи значення `d_i` та `d_i,f`:

```
c / D = (s · (D_f - f)) / (D_f · (s - f)) - 1               [підстановка спряжених відстаней]
= (s · D_f - s · f - D_f · s + D_f · f) / (D_f · (s - f))   [зведення до спільного знаменника]
= (f · (D_f - s)) / (D_f · (s - f))                         [скорочення членів s · D_f]
```

Аналогічно підставляючи `D = f / N` та `H_0 = f² / (N · c)`:

```
(c · N) / f = (f · (D_f - s)) / (D_f · (s - f))             [підстановка D = f / N]
c · N · D_f · (s - f) = f² · (D_f - s)                      [множення на знаменники]
D_f · (f² - c · N · (s - f)) = f² · s                       [групування членів із D_f]
D_f · (H_0 - (s - f)) = H_0 · s                             [скорочення c · N після підстановки f²]
D_f = (s · H_0) / (H_0 - (s - f))                           [точна формула дальньої межі різкості]
```

## Гіперфокальна відстань та асимптотична поведінка

Дальня межа `D_f` прямує до нескінченності (`D_f → ∞`), коли знаменник у формулі перетворюється на нуль:

```
H_0 - (s - f) = 0                                           [умова нульового знаменника]
s = H_0 + f                                                 [перенесення компонентів]
= f² / (N · c) + f ≡ H                                      [строге означення гіперфокалу H]
```

Оскільки в більшості практичних завдань `f² / (N · c) ≫ f`, часто використовують наближення:

```
H ≈ f² / (N · c)                                            [інженерна формула гіперфокальної відстані]
```

Підставимо `s = H` у формулу для ближньої межі `D_n` (вважаючи `s - f ≈ H`):

```
D_n(s = H) = (H · H) / (H + H)                              [підстановка s = H у формулу D_n]
= H² / (2 · H)                                              [додавання в знаменнику]
= H / 2                                                     [скорочення H]
```

Отже, фокусування на відстань `H` забезпечує різкість у діапазоні від `H / 2` до `∞`.

## Загальна глибина різкості (DoF) та асиметрія просторового розподілу

Повна глибина різко зображуваного простору `ΔD` є різницею між дальньою та ближньою межами:

```
ΔD = D_f - D_n                                              [означення повної глибини різкості]
= (s · H) / (H - (s - f)) - (s · H) / (H + (s - f))         [підстановка формул D_f та D_n]
= (s · H · (H + s - f) - s · H · (H - s + f)) / (H² - (s - f)²) [зведення до спільного знаменника]
= (s · H · (2 · (s - f))) / (H² - (s - f)²)                 [спрощення чисельника]
= (2 · s · H · (s - f)) / (H² - (s - f)²)                   [точна формула повної глибини різкості]
```

Якщо відстань зйомки значно менша за гіперфокальну (`s ≪ H`), то `(s - f)² ≪ H²`, що дає класичне інженерне наближення:

```
ΔD ≈ (2 · s · H · s) / H²                                   [наближення s - f ≈ s та H² ≫ s²]
= (2 · s²) / H                                              [скорочення H]
= (2 · s² · N · c) / f²                                     [підстановка H = f² / (N · c)]
```

### Коефіцієнт асиметрії розподілу різкості

Просторова глибина різкості розподіляється нерівномірно відносно площини фокусування `s`. Відстань від передньої межі до фокуса `ΔD_front = s - D_n`, а від фокуса до дальньої межі `ΔD_rear = D_f - s`.

Обчислимо їхнє співвідношення:

```
ΔD_front = s - (s · H) / (H + (s - f))                      [відстань від передньої межі до фокуса]
= (s · (s - f)) / (H + (s - f))                             [зведення до спільного знаменника]

ΔD_rear = (s · H) / (H - (s - f)) - s                       [відстань від фокуса до дальньої межі]
= (s · (s - f)) / (H - (s - f))                             [зведення до спільного знаменника]
```

Відношення передньої частини DoF до задньої:

```
ΔD_front / ΔD_rear = ((s · (s - f)) / (H + (s - f))) / ((s · (s - f)) / (H - (s - f))) [ділення частин]
= (H - (s - f)) / (H + (s - f))                             [скорочення чисельника s · (s - f)]
```

- При макрозйомці (`s ≪ H`): відношення прямує до `H / H = 1` — глибина різкості ділиться строго порівну: `50%` попереду та `50%` позаду об'єкта.
- При помірних дистанціях (`s ≈ H / 3`): відношення дорівнює приблизно `(H - H/3) / (H + H/3) = (2/3) / (4/3) = 1/2` — `1/3` DoF лежить попереду предмета і `2/3` DoF позаду.
- При наближенні до гіперфокалу (`s → H`): передня частина займає `H/2`, а задня прямує до `∞`.

## Глибина різкості в макрозйомці через масштаб збільшення `M`

При зйомці дрібних об'єктів з близької відстані (`s ≈ 2·f`, де збільшення `M ≈ 1.0`) використання відстаней `s` та `H` стає незручним. Виразимо глибину різкості безпосередньо через збільшення `M = f / (s - f)`:

```
s - f = f / M                                               [відстань фокусування через збільшення]
s = f · (1 + M) / M                                         [повна відстань до предмета]
```

Підставляючи ці вирази у формулу для `ΔD` з урахуванням `H = f² / (N · c)`:

```
ΔD_macro = (2 · N · c · (1 + M)) / M²                       [макроскопічна формула глибини різкості]
```

Ця формула демонструє важливий фізичний закон макрооптики: при фіксованому масштабі збільшення `M` та заданій діафрагмі `N` глибина різкості **не залежить від фокусної відстані об'єктива**. Об'єктив `50 мм` та об'єктив `100 мм` при однаковому масштабі `M = 0.5` на діафрагмі `f/8` забезпечують абсолютно однакову просторову глибину різкості, хоча робоча відстань до предмета у стоміліметрового об'єктива буде вдвічі більшою.

## Хвильовий оптимум діафрагми (баланс розмиття та дифракції)

У реальній системі сумарна пляма розмиття точки `c_total` на сенсорі є згорткою геометричного дефокусування `c_geom` та хвильового дифракційного диска Ейрі `d_Airy`:

```
c_total² ≈ c_geom² + d_Airy²                                [квадратичне додавання розмиттів]
```

Виразимо складові через діафрагмове число `N` при поздовжньому зміщенні предмета від площини фокусування на величину `Δz`:

```
c_geom = (f² · Δz) / (N · s²)                               [геометричне дефокусування]
d_Airy = 2.44 · λ · N                                       [дифракційний діаметр диска Ейрі]
```

Сумарна функція розмиття набуває вигляду:

```
c_total²(N) = ((f² · Δz) / s²)² · (1 / N²) + (2.44 · λ)² · N²
```

Мінімум цієї функції за змінною `N` визначається взяттям похідної та прирівнюванням її до нуля:

```
d(c_total²) / dN = - 2 · ((f² · Δz) / s²)² · (1 / N³) + 2 · (2.44 · λ)² · N = 0
N⁴ = ((f² · Δz) / s²)² / (2.44 · λ)²
N_opt = √((f² · Δz) / (2.44 · λ · s²))                      [оптимальне діафрагмове число системи]
```

Це співвідношення дає інженерний орієнтир для налаштування систем машинної інспекції: надмірне закриття діафрагми для отримання DoF не покращує якість, якщо дифракційне розмиття перевищує геометричне розмиття дефокусу.

## Покроковий числовий розрахунок для промислової системи технічного зору

**Вихідні параметри оптичної інспекції друкованих плат:**
- Сенсор: Sony IMX264 (формат `2/3"`, роздільна здатність `2448 × 2048`, розмір пікселя `p_pix = 3.45 мкм`);
- Допустимий кружок розмиття: `c = 1.5 · p_pix = 1.5 · 3.45 · 10⁻⁶ м = 5.175 · 10⁻⁶ м` (`5.175 мкм`);
- Об'єктив: фокусна відстань `f = 25 мм = 0.025 м`, встановлена діафрагма `N = 4.0` (`f/4.0`);
- Робоча дистанція до конвеєра: `s = 350 мм = 0.35 м`.

**Крок 1. Розрахунок гіперфокальної відстані `H`:**

```
H = f² / (N · c)                                            [формула гіперфокальної відстані]
= (0.025)² / (4.0 · 5.175 · 10⁻⁶)                           [підстановка числових значень]
= 0.000625 / 0.0000207                                      [обчислення степенів і добутків]
= 30.193 м                                                  [значення гіперфокальної дистанції]
```

**Крок 2. Розрахунок ближньої межі різкості `D_n`:**

```
s - f = 0.35 - 0.025 = 0.325 м                              [зсув від фокуса]
D_n = (s · H) / (H + (s - f))                               [формула ближньої межі]
= (0.35 · 30.193) / (30.193 + 0.325)                        [підстановка числових значень]
= 10.5676 / 30.518                                          [проміжні обчислення]
= 0.34627 м = 346.27 мм                                     [ближня межа DoF]
```

**Крок 3. Розрахунок дальньої межі різкості `D_f`:**

```
D_f = (s · H) / (H - (s - f))                               [формула дальньої межі]
= (0.35 · 30.193) / (30.193 - 0.325)                        [підстановка числових значень]
= 10.5676 / 29.868                                          [проміжні обчислення]
= 0.35381 м = 353.81 мм                                     [дальня межа DoF]
```

**Крок 4. Розрахунок сумарної глибини різкості `ΔD`:**

```
ΔD = D_f - D_n                                              [означення інтервалу DoF]
= 353.81 - 346.27                                           [віднімання значень меж]
= 7.54 мм                                                   [сумарна глибина різкості]
```

**Крок 5. Перевірка наближеної формули:**

```
ΔD_approx = (2 · s² · N · c) / f²                           [інженерна формула DoF]
= (2 · (0.35)² · 4.0 · 5.175 · 10⁻⁶) / (0.025)²             [підстановка параметрів]
= (2 · 0.1225 · 4.0 · 5.175 · 10⁻⁶) / 0.000625              [обчислення чисельника і знаменника]
= 5.0715 · 10⁻⁶ / 0.000625                                  [ділення]
= 0.00811 м = 8.11 мм                                       [результат наближеного розрахунку]
```

Похибка наближеної формули на дистанції `350 мм` становить лише `7%`, що підтверджує коректність застосування інженерного співвідношення для аналізу мікроелектронної оптики.
