# 🧮 Матричний формалізм та фазовий аналіз інтерферометра Маха — Цендера

Опис хвильових процесів у складному двопроменевому інтерферометрі потребує суворого математичного апарату, що враховує амплітуди, фазові набіги та унітарне перетворення електромагнітного поля на кожному оптичному елементі. Ця вставка містить повний математичний вивід матриці переносу інтерферометра Маха — Цендера, аналіз інтенсивностей на вихідних детекторах, розрахунок фазової чутливості, інтегрування спектральної когерентності та квантово-механічний розрахунок ймовірностей у вимірюванні без взаємодії та ефекті Хонга — Оу — Манделя.

### 1. Операторна матриця розділювача пучка (Beam Splitter)

Розглянемо симетричний безвтратний світлодільник із коефіцієнтом розщеплення 50:50. Нехай на світлодільник падають два монохроматичні електромагнітні поля з комплексними амплітудами `E_in,1` та `E_in,2`. Закон збереження енергії та вимога унітарності оптичного перетворення вимагають, щоб матриця розділювача `M_BS` належила до спеціальної унітарної групи `SU(2)` і задовольняла умову `M_BS† · M_BS = I`.

Застосовуючи граничні умови Френеля для діелектричного покриття, зв'язок між вхідними та вихідними амплітудами поля записується у вигляді:

```
[ E_out,1 ] = 1/√2 · [ 1   i ] · [ E_in,1 ]
[ E_out,2 ]          [ i   1 ]   [ E_in,2 ]
```

де `i = √(-1)` — уявна одиниця, яка відповідає фазовому зсуву на `π/2` (або 90°) при відбитті хвилі від діелектичного покриття світлодільника. 

Доведемо сувору унітарність матриці `M_BS`:

```
M_BS† · M_BS 
= 1/√2 · [ 1  -i ] · 1/√2 · [ 1   i ]
         [ -i  1 ]          [ i   1 ]
= 1/2 · [ 1 + (-i)·i   i + (-i)·1 ]
        [ -i + 1·i     (-i)·i + 1 ]
= 1/2 · [ 2  0 ] 
        [ 0  2 ]
= [ 1  0 ]
  [ 0  1 ]                                   [унітарність підтверджено]
```

Для несиметричного світлодільника з амплітудними коефіцієнтами відбиття `r` та пропущення `t` матричне перетворення узагальнюється у формі:

```
M_BS = [  t    r  ]
       [ r'   t' ]
```

Умова унітарності для несиметричного випадку дає три фундаментальні співвідношення:
1. `|t|² + |r|² = 1` (збереження енергії в першому каналі).
2. `|r'|² + |t'|² = 1` (збереження енергії у другому каналі).
3. `r* · t' + t* · r' = 0` (взаємна ортогональність вихідних станів).

Звідси випливає, що різниця фаз між відбитою та пройденою хвилею на будь-якому безвтратному світлодільнику завжди дорівнює суворо `π/2` або `90°`.

### 2. Загальна матриця переносу інтерферометра

Інтерферометр Маха — Цендера складається з послідовності чотирьох оптичних перетворень:
1. Перший світлодільник `M_BS1`.
2. Фазовий набіг у плечах A та B, описуваний діагональною матрицею фазового зсуву `P(φ_A, φ_B)`.
3. Відбиття від двох плоских дзеркал `M_M`.
4. Другий світлодільник `M_BS2`.

Запишемо оператори кожного з цих етапів:

```
P(φ_A, φ_B) = [ e^(i·φ_A)      0     ]      [фазові набіги у плечах A та B]
              [    0      e^(i·φ_B) ]

M_M = [ 0   i ]                             [відбиття від ідеальних дзеркал]
      [ i   0 ]
```

Повний оператор перетворення інтерферометра `U` є добутком матриць елементів у зворотному порядку руху світла:

```
U = M_BS2 · M_M · P(φ_A, φ_B) · M_BS1
```

Обчислимо добуток двох центральних матриць плечей та дзеркал:

```
M_M · P(φ_A, φ_B)
= [ 0   i ] · [ e^(i·φ_A)      0     ]
  [ i   0 ]   [    0      e^(i·φ_B) ]
= [    0       i·e^(i·φ_B) ]
  [ i·e^(i·φ_A)     0      ]
```

Тепер помножимо результат на матриці світлодільників `M_BS2` та `M_BS1`:

```
U = 1/2 · [ 1   i ] · [    0       i·e^(i·φ_B) ] · [ 1   i ]
          [ i   1 ]   [ i·e^(i·φ_A)     0      ]   [ i   1 ]
```

Перемножуючи ліву та центральну матриці:

```
[ 1   i ] · [    0       i·e^(i·φ_B) ]
[ i   1 ]   [ i·e^(i·φ_A)     0      ]
= [ -e^(i·φ_A)   i·e^(i·φ_B) ]
  [ i·e^(i·φ_A)  -e^(i·φ_B)  ]
```

Тепер перемножимо результат із правою матрицею `M_BS1`:

```
U = 1/2 · [ -e^(i·φ_A)   i·e^(i·φ_B) ] · [ 1   i ]
          [ i·e^(i·φ_A)  -e^(i·φ_B)  ]   [ i   1 ]
= 1/2 · [ -e^(i·φ_A) - e^(i·φ_B)     -i·e^(i·φ_A) + i·e^(i·φ_B) ]
        [ i·e^(i·φ_A) - i·e^(i·φ_B)  -e^(i·φ_A) - e^(i·φ_B)     ]
```

Винесемо спільний фазовий множник `e^(i·(φ_A + φ_B)/2)` та введемо різницю фаз `Δφ = φ_A - φ_B`:

```
U = i · e^(i·(φ_A + φ_B)/2) · [  sin(Δφ/2)   -cos(Δφ/2) ]
                              [  cos(Δφ/2)    sin(Δφ/2) ]
```

Матриця `U` має чітку тригонометричну структуру матриці повороту в дійсному просторі, що підтверджує збереження нормалізації хвильових функцій.

### 3. Розрахунок інтенсивностей на вихідних детекторах

Нехай лазерне випромінювання подається лише на один вхід інтерферометра `E_in = [ E₀, 0 ]ᵀ`. Комплексні амплітуди полів на виходах дорівнюють:

```
[ E_out,1 ] = U · [ E₀ ]
[ E_out,2 ]       [ 0  ]

E_out,1 = i · E₀ · e^(i·(φ_A + φ_B)/2) · sin(Δφ/2)
E_out,2 = i · E₀ · e^(i·(φ_A + φ_B)/2) · cos(Δφ/2)
```

Інтенсивність світла `I`, реєстрована фотодетекторами, пропорційна квадрату модуля комплексної амплітуди `I = |E|²`:

```
I₁ = |E_out,1|² = I₀ · sin²(Δφ/2) = (I₀ / 2) · (1 - cos Δφ)
I₂ = |E_out,2|² = I₀ · cos²(Δφ/2) = (I₀ / 2) · (1 + cos Δφ)
```

Додавши інтенсивності двох каналів:

```
I₁ + I₂ = (I₀ / 2) · (1 - cos Δφ + 1 + cos Δφ) = I₀
```

Це доводить суворе збереження енергії: світло лише перерозподіляється між двома детекторами залежно від різниці фаз `Δφ`.

### 4. Фазова чутливість, квадратура та дробовий шум (Shot Noise)

Крутизна зміни інтенсивності за фазою виражає фазову чутливість оптичного датчика:

```
dI₁ / d(Δφ) = (I₀ / 2) · sin Δφ
dI₂ / d(Δφ) = - (I₀ / 2) · sin Δφ
```

Максимум крутизни досягається при `sin Δφ = ±1`, тобто коли різниця фаз дорівнює:

```
Δφ_0 = π/2 + k·π     (де k ∈ ℤ)             [квадратурна робоча точка]
```

У цій точці `I₁ = I₂ = I₀ / 2`, а мала зміна фази `δφ ≪ 1` викликає максимально лінійну зміну вихідного сигналу:

```
δI₁ ≈ (I₀ / 2) · δφ
```

Гранична чутливість обмежена дробовим шумом фотодетектору (*shot noise*), який обумовлений дискретністю фотонів. Середньоквадратичний флуктуаційний струм фотодіода з чутливістю `R_resp` у смузі частот `B` дорівнює:

```
i_shot = √(2 · e · R_resp · (I₀ / 2) · B)
```

Прирівнюючи корисний фотострум `i_sig = R_resp · (I₀ / 2) · δφ` до дробового шуму `i_shot`, отримуємо **фундаментальну дробово-шумову межу вимірювання фази**:

```
δφ_min = √( 2 · e · B / (R_resp · I₀) ) = 1 / √(N_photon)
```

де `N_photon` — кількість фотонів, що проходять крізь інтерферометр за час вимірювання. Це співвідношення відоме як **стандартна квантова межа** (*Standard Quantum Limit*, SQL).

### 5. Спектральна когерентність та інтегрування для широкого спектра

Для неелементарного спектрального джерела із розподілом інтенсивності `S(ω)` вихідна інтенсивність є інтегралом від оптичних компонент:

```
I_total(ΔL) = ∫₀^∞ S(ω) · (I₀ / 2) · (1 + cos(ω · ΔL / c)) dω
```

Якщо спектр лазера має гауссівський профіль шириною `Δω` з центрованою частотою `ω₀`:

```
S(ω) = S₀ · exp(- (ω - ω₀)² / (2·Δω)²)
```

то підсумкова інтенсивність набуває вигляду:

```
I_total(ΔL) = (I₀ / 2) · [ 1 + exp(- (ΔL / L_c)²) · cos(ω₀ · ΔL / c) ]
```

де `L_c = c / Δω` — довжина когерентності джерела. Видимість інтерференційної картини згасає за гауссівським законом:

```
V(ΔL) = exp(- (ΔL / L_c)²)
```

Якщо різниця шляхів перевищує довжину когерентності (`ΔL > L_c`), контраст прямує до нуля (`V → 0`), і інтерференційні смуги розмиваються.

### 6. Квантовий аналіз: ефект Хонга — Оу — Манделя (HOM) та нерозрізнені фотони

У квантовій оптиці оператори народження та анігіляції фотонів на світлодільнику перетворюються за законом:

```
a_out,1 = 1/√2 · (a_in,1 + i · a_in,2)
a_out,2 = 1/√2 · (i · a_in,1 + a_in,2)
```

Розглянемо двофотонний стан `|1, 1⟩_in`, коли на обидва входи світлодільника одночасно подається по одному нерозрізненному фотону:

```
|1, 1⟩_in = a_in,1† · a_in,2† |0⟩
```

Виразивши вхідні оператори через вихідні:

```
a_in,1† = 1/√2 · (a_out,1† - i · a_out,2†)
a_in,2† = 1/√2 · (-i · a_out,1† + a_out,2†)
```

Обчислимо добуток операторів на вакуумному стані `|0⟩`:

```
a_in,1† · a_in,2†
= 1/2 · (a_out,1† - i · a_out,2†) · (-i · a_out,1† + a_out,2†)
= 1/2 · [ -i · (a_out,1†)² + a_out,1† · a_out,2† - (a_out,2† · a_out,1†) - i · (a_out,2†)² ]
= -i / 2 · ( (a_out,1†)² + (a_out,2†)² )
```

Оскільки вихідні оператори комутують `[a_out,1†, a_out,2†] = 0`, перехресні члени `a_out,1† · a_out,2†` повністю скорочуються!

Таким чином, вихідний стан квантового поля дорівнює:

```
|ψ_out⟩ = -i / √2 · |2, 0⟩ - i / √2 · |0, 2⟩
```

Цей результат є знаменитим **ефектом Хонга — Оу — Манделя** (*Hong-Ou-Mandel effect*): два нерозрізненні фотони, потрапляючи на 50:50 світлодільник з різних входів, **ніколи не виходять у різні канали**. Вони завжди групуються разом (*photon bunching*) і виходять дуплетом або повністю у перший канал `|2, 0⟩`, або повністю у другий канал `|0, 2⟩`.

### 7. Квантове вимірювання без взаємодії (протокол Еліцура — Вайдмана)

У квантово-механічному описі стан поодинокого фотона задається вектором у двовимірному гілбертовому просторі шляхів `|ψ⟩ = c₁|1⟩ + c₂|2⟩`, де `|1⟩` відповідає верхньому плечу A, а `|2⟩` — нижньому плечу B.

Вхідний фотон у стані `|1⟩` проходить через перший світлодільник `M_BS`:

```
|ψ_1⟩ = M_BS · |1⟩ = (1/√2) · |1⟩ + (i/√2) · |2⟩
```

Якщо в плечі 1 (плече A) знаходиться поглинаючий об'єкт (бомба з імовірністю поглинання 1):
- З ймовірністю `P_explode = |1/√2|² = 1/2` (50%) фотон рухається плечем A, поглинається бомбою та викликає вибух.
- З ймовірністю 50% фотон рухається плечем B, уникаючи бомби. Стан хвильової функції піддається редукції (колапсу):

```
|ψ_2⟩ = |2⟩
```

Фотон у стані `|2⟩` досягає другого світлодільника `M_BS2`:

```
|ψ_out⟩ = M_BS2 · |2⟩ = (i/√2) · |1⟩ + (1/√2) · |2⟩
```

Обчислимо ймовірності реєстрації фотона детекторами D₁ та D₂ у разі, якщо бомба НЕ вибухнула:

```
P(D₁) = |i/√2|² = 1/2   (відносно стану |ψ_2⟩)
P(D₂) = |1/√2|² = 1/2   (відносно стану |ψ_2⟩)
```

Враховуючи початкову ймовірність потрапляння у стан `|ψ_2⟩` (50%), підсумкові абсолютні ймовірності трьох наслідків складають:

1. **Вибух бомби:** `P_explode = 1/2` (50%).
2. **Фотон зареєстровано на D₂ (інтерференційний максимум відсутності бомби):** `P(D₂) = 1/2 · 1/2 = 1/4` (25%). Результат невизначений, оскільки D₂ міг спрацювати й у порожньому інтерферометрі.
3. **Фотон зареєстровано на D₁ (деструктивний мінімум у порожньому інтерферометрі):** `P(D₁) = 1/2 · 1/2 = 1/4` (25%).

Оскільки у порожньому інтерферометрі спрацьовування детектора D₁ математично заборонене (`I₁ = 0`), спрацьовування D₁ **стовідсотково гарантує наявність бомби у плечі A**, хоча жоден фотон не був нею поглинутий.

Якщо замість одного світлодільника застосувати каскад із `N` світлодільників із високим коефіцієнтом пропущення (використовуючи **квантовий ефект Зенона**), імовірність виявлення об'єкта без вибуху можна наблизити до 100%:

```
P_success = cos^(2N)(π / (2N)) ────> 1      (при N ────> ∞)
```

Це доводить, що квантова інтерферометрія дозволяє отримувати інформацію про стан об'єктів у просторі з нульовим енергетичним впливом на сам об'єкт.
