# 📋 Специфікація та оптичний інтерфейс цифрового рефрактометра

Цифровий рефрактометр — прецизійний оптико-електронний прилад для вимірювання абсолютного показника заломлення `n_D` рідких, напівтвердих та газоподібних середовищ на основі визначення граничного кута повного внутрішнього відбиття або відносної інтенсивності відбитого світла на ПЗЗ-лінійці (CCD/CMOS сенсорі).

Прилад застосовується в хімічній, фармацевтичній, харчовій та нафтопереробній промисловості для безперервного потокового або лабораторного контролю чистоти речовин, масової частки сухих речовин (шкала Brix) та ідентифікації складу розчинів.

## 1. Принцип дії та оптична геометрія приладу

Вимірювання базується на явищі повного внутрішнього відбиття на межі розділу між оптично щільною вимірювальною призмою з високим показником заломлення `n_prism` (наприклад, штучний сапфір `n_prism = 1.76800` при `589.3` нм) та досліджуваним середовищем із невідомим показником заломлення `n_sample` (`n_sample < n_prism`).

Випромінювання від монохроматизованого світлодіода (LED, `λ = 589.3` нм — жовта лінія D натрію) спрямовується через призму на межу розподілу під різними кутами. Промені, кут падіння яких менший за граничний кут `θ_c`, частково заломлюються та проникають у пробу. Промені з кутом падіння, більшим за `θ_c`, зазнають повного внутрішнього відбиття й потрапляють на 2048-елементну оптичну лінійну ПЗЗ-матрицю.

На ПЗЗ-матриці формується чітка межа «світло/тінь». Позиція цієї межі (номер граничного пікселя `K_shadow`) однозначно пов'язана з граничним кутом `θ_c` співвідношенням:

```
sin(θ_c) = n_sample / n_prism
```

звідки показник заломлення досліджуваної проби обчислюється як:

```
n_sample = n_prism · sin( θ_base + (K_shadow - K_zero) · Δθ_pixel )
```

де:
- `n_prism` — показник заломлення вимірювальної сапфірової призми (`1.76800` при `589.3` нм);
- `θ_base` — калибрований базовий оптичний кут позиціонування сенсорної лінійки (радіани);
- `K_zero` — піксельний індекс калібрувального нуля (чиста дистильована вода при `20.00 °C`);
- `Δθ_pixel` — кутовий розмір одного пікселя matrix sensor (`3.15 · 10⁻⁵` рад/піксель).

Оптичний тракт приладу розрахований так, щоб мінімізувати вплив каламутності проби та наявності завислих часток. Оскільки вимірювання відбувається виключно на межі розділу середовища та призми на глибині проникнення згасаючої (еванесцентної) хвилі порядку половини довжини хвилі (`~300` нм), рефрактометр здатний точно вимірювати показник заломлення непрозорих, густих або забарвлених рідин, таких як нафта, сиропи, молоко чи концентровані пасти.

## 2. Метрологічні та вимірювальні характеристики

Нижче наведено канонічні метрологічні та оптико-механічні параметри лабораторних і промислових рефрактометрів відповідно до вимог міжнародного стандарту ISO 17025 та фармакопеї USP <831>.

| Параметр | Значення / Діапазон | Одиниці | Примітка / Умови |
| :--- | :--- | :--- | :--- |
| **Діапазон вимірювання nD** | `1.30000 ... 1.70000` | nD (лінія Na 589.3 нм) | Абсолютний показник заломлення |
| **Шкала Brix** | `0.00 ... 100.00` | % Brix | Масова частка цукрози у воді |
| **Роздільна здатність nD** | `0.00001` (1·10⁻⁵) | nD | Дискретність цифрового зчитування |
| **Точність вимірювання nD** | `±0.00004` | nD | За термостатування `20.00 ± 0.02 °C` |
| **Точність шкали Brix** | `±0.02` | % Brix | Для водних розчинів цукрів |
| **Джерело випромінювання** | Світлодіод (LED), `λ = 589.3 ± 0.5` нм | нм | Вбудований інтерференційний фільтр |
| **Матеріал призми** | Синтетичний сапфір (`n = 1.768`) | — | Твердість 9 за Моосом, хімічна інертність |
| **Матеріал корпусу комірки** | Нержавіюча сталь AISI 316L / Хастеллой | — | Стійкість до агресивних кислот і лугів |
| **Термокомпенсація (ATC)** | `-10.0 ... +80.0` | °C | Автоматична за допомогою Pt1000 / NTC |
| **Об'єм проби** | `0.1 ... 0.3` | мл | Мінімальна крапля на сапфіровій призмі |
| **Час відклику** | `< 1.5` | секунди | Від моменту внесення проби до стабілізації |

Конструкція оптичної комірки виготовляється із хімічно інертних матеріалів. Штучний сапфір оптичної призми володіє твердістю `9` за шкалою Мооса, що запобігає появі подряпин при очищенні поверхні серветками або при контакті з абразивними суспензіями. Корпус вимірювальної чаші виконується з корозійностійкої нержавіючої сталі AISI 316L або титанового сплаву, що дозволяє працювати з концентрованими кислотами, лугами та органічними розчинниками.

## 3. Математика субпіксельного детектування та температурної компенсації

Для досягнення високої точності вимірювання `±0.00004` nD на ПЗЗ-лінійці застосовують алгоритм субпіксельної логічної обробки профілю інтенсивності `I[k]`.

Алгоритм містить три послідовних кроки:

Перший крок — згладжування шуму та фільтрація. Профіль інтенсивності `I[k]` фільтрується дискретним ядром Ґаусса для усунення високочастотного оптичного шуму, викликанного темновим струмом фотодіодів та дрібними пилинками на оптичних поверхнях.

Другий крок — чисельне диференціювання профілю інтенсивності. Похідна `dI / dk ≈ (I[k+1] - I[k-1]) / 2` визначає точку максимального градієнта переходу між освітленою та затіненою ділянками сенсора.

Третій крок — параболічна субпіксельна інтерполяція. Точна позиція екстремуму `K_shadow` обчислюється через вершину апроксимаційної параболи по трьох сусідніх пікселях навколо максимуму похідної:

```
K_shadow = k_max + 0.5 · (dI_left - dI_right) / (dI_left - 2 · dI_center + dI_right)
```

Завдяки такій субпіксельній математичній обробці роздільна здатність визначення граничного кута зростає у `10-15` разів порівняно з цілим кроком піксельної сітки.

### Алгоритми температурної компенсації (ATC)

Оскільки показник заломлення більшості рідин суттєво зменшується зі зростанням температури через теплове розширення та зменшення густини (`dn/dT < 0`), виміряне значення `nD(T)` необхідно зводити до еталонної температури `20.00 °C`:

```
nD(20 °C) = nD(T) + α · (T - 20.0)
```

Для водних розчинів цукрози використовують офіційну поліноміальну температурну компенсацію стандарту ICUMSA (International Commission for Uniform Methods of Sugar Analysis, SPS-3):

```
Δn(T) = a₁ · (T - 20) + a₂ · (T - 20)² + a₃ · (T - 20)³

де:
a₁ = +0.000105
a₂ = +0.00016
a₃ = -0.000000012
```

Для нафтопродуктів та органічних розчинників (бензол, толуол) температурний коефіцієнт становить `dn/dT ≈ -0.00045 ... -0.00065` K⁻¹ відповідно до стандарту ASTM D1218.

Для підтримки прецизійної термостабілізації вимірювальна чаша приладу оснащується вбудованим напівпровідниковим модулем Пельтьє та платиновим термометром опору Pt1000. Вбудований цифровий ПІД-регулятор підтримує температуру сапфірової призми з точністю `±0.01 °C` у діапазоні від `+10 °C` до `+80 °C`, усуваючи температурні градієнти всередині проби.

## 4. Цифровий промисловий інтерфейс Modbus RTU / RS-485

Для передачі вимірювальних даних у промислові системи автоматизації (АСУ ТП, PLC, SCADA) прилад надає послідовний фізичний інтерфейс RS-485 із гальванічною розв'язкою `2.5` кВ та підтримкою протоколу Modbus RTU (8-N-1, швидкості 9600–115200 бод).

Рефрактометр працює в режимі Modbus Slave. Період оновлення регістрів становить `100` мс (10 Вимірів на секунду).

### Карта регістрів Modbus (Holding Registers, Read Function 0x03)

| Адреса (Decimal) | Назва регістру | Тип даних | Опис та одиниці |
| :--- | :--- | :--- | :--- |
| `40001 - 40002` | `n_D_raw` | IEEE 754 Float32 | Некомпенсований показник заломлення при поточній `T` |
| `40003 - 40004` | `n_D_20` | IEEE 754 Float32 | Показник заломлення, приведений до `20.00 °C` |
| `40005 - 40006` | `Brix_comp` | IEEE 754 Float32 | Концентрація цукрози (% Brix) з термокомпенсацією |
| `40007` | `Temperature` | Int16 (`0.01 °C`) | Поточна температура призми (наприклад, `2534` = `25.34 °C`) |
| `40008` | `Optical_Signal_Quality` | Uint16 (`0 ... 100`) | Контрастність та якість межі світло/тінь (%) |
| `40009` | `Status_Flags` | Uint16 (Bitmap) | Bit 0: Оптичне забруднення; Bit 1: Помилка T; Bit 2: Out of range |
| `40010 - 40011` | `CCD_Shadow_Pixel` | IEEE 754 Float32 | Субпіксельний індекс межі світло/тінь `K_shadow` |

Байтовий порядок для 32-бітних чисел Float32 відповідає стандарту Big-Endian (CDAB або ABCD залежно від конфігураційного прапорця в меню приладу).

### Структура кадру JSON (Ethernet REST API / MQTT Telemetry)

Для інтеграції з сучасними IoT-платформами та лабораторними інформаційними системами (LIMS) прилад оснащений Ethernet-контролером, який передає телеметрію у форматі JSON через протоколи MQTT або HTTP POST:

```json
{
  "sensor_id": "REFR-SAPH-9942",
  "firmware_version": "v2.4.1",
  "timestamp_utc": "2026-08-17T15:20:00Z",
  "measurement": {
    "n_D_raw": 1.33302,
    "n_D_20": 1.33299,
    "brix_percent": 0.02,
    "temperature_celsius": 20.25,
    "signal_contrast_pct": 98.5
  },
  "diagnostics": {
    "prism_dirty": false,
    "temperature_stable": true,
    "ccd_pixel_shadow": 1024.43,
    "led_current_ma": 20.0
  }
}
```

Диагностичне поле `prism_dirty` активується, якщо коефіцієнт контрастності межі світло/тінь опускається нижче `60%`, що сигналізує операторові про необхідність промивки сапфірової призми від залишкових відкладень.

## 5. Таблиця еталонних вимірювальних рідин при 20.0 °C

Для періодичної повірки, градуювання та метрологічного калібрування рефрактометрів використовують сертифіковані стандартні зразки рідких речовин із високим ступенем хімічної чистоти та відомим показником заломлення.

Процедура нульового калібрування виконується за допомогою свіжоперегнаної дистильованої води (`n_D = 1.33300` при `20.00 °C`). Процедура калібрування діапазону (Span Calibration) здійснюється за допомогою сертифікованих розчинів цукрози або еталонних олій.

| Речовина / Калібрувальний еталон | Показник заломлення nD (20 °C) | Температурний коефіцієнт dn/dT (K⁻¹) | Галузь застосування |
| :--- | :--- | :--- | :--- |
| **Повітря сухо (1 атм)** | `1.00027` | `-0.0000009` | Перевірка нуля газів |
| **Дистильована вода (H₂O)** | `1.33300` | `-0.000100` | Базове калібрування нуля (0 Brix) |
| **Розчин цукрози 10% Brix** | `1.34780` | `-0.000115` | Перевірка харчових рефрактометрів |
| **Розчин цукрози 50% Brix** | `1.42010` | `-0.000185` | Контроль сиропів та соків |
| **Етанол (95% мас.)** | `1.36140` | `-0.000400` | Контроль спиртової промисловості |
| **Кварцове скло (Fused Silica)** | `1.45840` | `+0.000010` | Твердий оптичний еталон |
| **Гліцерин (99.5%)** | `1.47400` | `-0.000220` | Перевірка середньої області шкали |
| **Бензол (C₆H₆)** | `1.50110` | `-0.000640` | Нафтохімічні вимірювання |
| **Альфа-бромнафталін** | `1.65700` | `-0.000480` | Рідина високого заломлення |
| **Еталон Каргілла (Cargille High nD)** | `1.70000` | `-0.000420` | Верхня межа сапфірової призми |

При вимірюванні речовин із високим показником заломлення (`n > 1.65`) необхідно використовувати імерсійні рідини з високою оптичною густиною (наприклад, альфа-бромнафталін чи рідини Каргілла), щоб забезпечити оптичний контакт між пробою та сапфіровою призмою без повітряних прошарків.

Регулярний метрологічний контроль вимірювальної комірки гарантує стабільну роботу рефрактометра у промислових лініях протягом багатьох років без втрати точності.
