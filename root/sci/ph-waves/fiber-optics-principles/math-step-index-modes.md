# 🧮 Математика розрахунку апертури, V-числа та модового складу

Математична теорія оптичних волокон описує умови утримання електромагнітного випромінювання всередині двошарової скляної структури, кількісні межі вводу світла, міжмодове розширення імпульсів та перехід від багаторазових траєкторій геометричних променів до дискретних хвильових мод. Нижче наведено послідовні математичні виведення ключових співвідношень волоконної оптики.

---

### 1. Виведення числової апертури та критичного кута вводу

Розглянемо торець волокна із плоским зрізом, зануреного у зовнішнє середовище з показником заломлення `n₀` (для повітря `n₀ = 1`). Серцевина має показник `n₁`, оболонка — `n₂`, причому `n₁ > n₂`.

Світловий промінь падає на торець волокна під кутом `θ₀` до оптичної осі. За законам Снелла на торцевій межі «зовнішнє середовище–серцевина»:

```
n₀ · sin θ₀ = n₁ · sin θ₁
```

Усередині серцевини промінь поширюється під кутом `θ₁` до осі й падає на бокову межу «серцевина–оболонка». Кут падіння на бокову межу дорівнює `α = 90° − θ₁`.

Для того щоб світло не витікало в оболонку, а повністю відбивалося назад у серцевину, кут `α` мусить бути не меншим за критичний кут повного внутрішнього відбиття `θc`:

```
sin α = sin(90° − θ₁) = cos θ₁ ≥ sin θc
```

З закону Снелла для межі «серцевина–оболонка» критичний кут `θc` визначається як:

```
sin θc = n₂ / n₁
```

Отже, умова утримання світла набуває вигляду:

```
cos θ₁ ≥ n₂ / n₁
```

Використовуючи основну тригонометричну тотожність `sin² θ₁ + cos² θ₁ = 1`, знайдемо граничне значення синуса кута заломлення `sin θ₁`:

```
sin θ₁ = √(1 − cos² θ₁)                  [тригонометрична тотожність: sin² + cos² = 1]
≤ √(1 − (n₂ / n₁)²)                      [умова відбиття: cos θ₁ ≥ n₂ / n₁]
= √((n₁² − n₂²) / n₁²)                   [зведення під спільний знаменник n₁²]
= √(n₁² − n₂²) / n₁                      [винесення знаменника n₁ з-під кореня]
```

Підставимо це значення у вираз для вхідного кута на торці `n₀ · sin θ₀ = n₁ · sin θ₁`:

```
n₀ · sin θ₀_max = n₁ · (√(n₁² − n₂²) / n₁)   [підстановка sin θ₁ у закон Снелла]
= √(n₁² − n₂²)                              [скорочення показника n₁]
```

Якщо зовнішнім середовищем є повітря (`n₀ = 1`), ми отримуємо формулу для **числової апертури** (*Numerical Aperture*, `NA`):

```
NA = sin θ₀_max = √(n₁² − n₂²)
```

Або через відносну різницю показників заломлення `Δ = (n₁² − n₂²) / (2 · n₁²)`:

```
NA = n₁ · √(2 · Δ)          [за умови Δ « 1]
```

### 2. Математичний розрахунок міжмодової дисперсії в ступінчастому волокні

У ступінчастому волокні довжиною `L` найкоротший шлях долає аксіальний промінь, що йде вздовж осі (`θ₁ = 0`). Час його прольоту:

```
t_min = L / v₁ = L · n₁ / c
```

де `v₁ = c / n₁` — швидкість світла в матеріалі серцевини.

Найдовший шлях долає граничний зигзагоподібний промінь, що падає під критичним кутом `α = θc`. Фізична довжина його геометричної траєкторії дорівнює `L / sin θc = L · (n₁ / n₂)`. Час його прольоту:

```
t_max = (L · (n₁ / n₂)) / v₁             [відстань зигзага поділено на швидкість v₁]
= (L · n₁ / c) · (n₁ / n₂)               [підстановка швидкості v₁ = c / n₁]
= L · n₁² / (c · n₂)                     [перемноження показників у чисельнику]
```

Міжмодова часова затримка (розширення імпульсу `Δt`) на довжині `L` дорівнює різниці `t_max − t_min`:

```
Δt = t_max − t_min                       [різниця часу прибуття найповільнішого та найшвидшого променів]
= (L · n₁ / c) · (n₁ / n₂ − 1)           [винесення спільного множника L · n₁ / c]
= (L · n₁ / c) · ((n₁ − n₂) / n₂)        [зведення дужки до спільного знаменника]
```

З урахуванням того, що `n₁ ≈ n₂`, отримаємо практичну наближену формулу міжмодової дисперсії на одиницю довжини:

```
Δt / L ≈ (n₁ / c) · Δ          [де Δ = (n₁ − n₂) / n₁]
```

**Числовий приклад:** Для волокна із `n₁ = 1.48` та `n₂ = 1.46` (`Δ ≈ 0.0135`):

```
Δt / L = (1.48 / (3 · 10⁸ м/с)) · 0.0135  [підстановка n₁ = 1.48, c = 3·10⁸ м/с, Δ = 0.0135]
≈ 6.66 · 10⁻¹¹ с/м                       [обчислення у секундах на метр]
= 66.6 нс/км                             [переведення у наносекунди на кілометр]
```

Це означає, що без градієнтного профілювання або переході до одномодового режиму вузький імпульс розмивається на `66.6 нс` кожні `1 км`, що обмежує передачу даних символьною швидкістю порядку десятків мегабіт на секунду.

### 3. Хвильові рівняння Максвелла у циліндричних координатах

Для детального математичного аналізу модового складу розглянемо електромагнітне поле в циліндричній системі координат `(r, φ, z)`, де вісь `z` збігається з віссю волокна.

У монохроматичному режимі на частоті `ω` поздовжні компоненти електричного та магнітного полів `E_z` та `H_z` задовольняють скалярне рівняння Гельмгольца:

```
∂²E_z / ∂r² + (1/r) · ∂E_z / ∂r + (1/r²) · ∂²E_z / ∂φ² + (k²·n²(r) − β²) · E_z = 0
```

де `k = 2π / λ = ω / c` — хвильове число у вакуумі, `β` — поздовжня константа поширення хвилі вздовж осі `z`.

Застосовуючи метод відокремлення змінних у вигляді `E_z(r, φ, z) = R(r) · cos(m·φ) · exp(i·(ω·t − β·z))`, розв'язок радіального рівняння `R(r)` виражається через класичні функції Бесселя першого роду `J_m(u · r / a)` у серцевині (`r ≤ a`) та модифіковані функції Бесселя другого роду `K_m(w · r / a)` в оболонці (`r > a`).

Поперечні параметри поперечного хвильового числа `u` та `w` визначаються співвідношеннями:

```
u = a · √(k² · n₁² − β²)                 [поперечне хвильове число у серцевині]
w = a · √(β² − k² · n₂²)                 [поперечне хвильове число в оболонці]
```

Сума квадратів параметрів `u` та `w` визначає безрозмірний параметр **нормованої частоти** `V`:

```
V² = u² + w² = a² · k² · (n₁² − n₂²)
```

Отже:

```
V = k₀ · a · NA                          [означення нормованої частоти V через хвильове число k₀]
= (2π / λ) · a · √(n₁² − n₂²)            [підстановка k₀ = 2π / λ та NA = √(n₁² − n₂²)]
```

#### Гранична умова одномодового режиму
Зшивання неперервних дотичних компонент полів `E_z`, `E_φ`, `H_z`, `H_φ` на межі серцевина–оболонка (`r = a`) дає системне характеристичне рівняння для константи поширення `β`. 

Для слабонапрямлених волокон (*weakly-guiding fibers*, для яких `Δ « 1`) Девід Ґлоґе (*David Gloge*, 1971) показав, що моди можна згрупувати у лінійно-поляризовані моди `LP_lm`.

Для фундаментальної моди `LP₀₁` (яка відповідає хвилі `HE₁₁`) параметри при `V → 0` не мають точки відсічки. Проте для першої вищої моди `LP₁₁` (`TE₀₁` / `TM₀₁` / `HE₂₁`) умова відсічки `w = 0` спрощується до характеристичного рівняння:

```
J₀(u) = 0
```

Перший додатний корінь функції Бесселя `J₀` дорівнює:

```
u = V_c = 2.40483... ≈ 2.405
```

Отже, волокно є строго одномодовим за умови `V < 2.405`.

### 4. Розрахунок фазової та групової швидкостей і хроматичної дисперсії

Швидкість перенесення оптичної енергії імпульсом визначається **груповою швидкістю** `v_g`, яка пов'язана з константою поширення `β(ω)` співвідношенням:

```
v_g = dω / dβ = c / n_g
```

де `n_g` — ефективний груповий показник заломлення хвилеводної моди:

```
n_g = n − λ · (dn / dλ)
```

Часова затримка імпульсу `τ_g` на одиницю довжини волокна становить:

```
τ_g = 1 / v_g = (1 / c) · (dβ / dk)
```

Параметр **хроматичної дисперсії** `D` виражає зміну часової затримки на одиницю спектральної ширини джерела `dλ`:

```
D = dτ_g / dλ = −(2π · c / λ²) · (d²β / dω²)
```

Утиліта аналізу розкладає `D` на дві суми:

```
D = D_mat + D_wave
```

де матеріальна дисперсія `D_mat` обчислюється через другу похідну рівняння Зельмейєра:

```
D_mat = −(λ / c) · (d²n / dλ²)
```

а хвилеводна дисперсія `D_wave` обчислюється через нормовані хвилеводні параметри `b(V) = (β²/k² − n₂²) / (n₁² − n₂²)` за наближеною формулою Ґлоґе:

```
D_wave ≈ −(n₂ · Δ / (c · λ)) · V · (d²(V·b) / dV²)
```

### 5. Емпірична формула Маркузе для діаметра плями модового поля (MFD)

У строго одномодовому волокні світлове поле фундаментальної моди `HE₁₁` проникає в оболонку й описується Гаусовим розподілом інтенсивності. Ефективний радіус оптичної плями `w₀` (радіус модового поля, *Mode Field Radius*, MFR) обчислюється за відомою емпіричною формулою Дітріха Маркузе (*Dietrich Marcuse*):

```
w₀ / a = 0.65 + 1.619 / (V^1.5) + 2.879 / (V^6)          [за умови 1.2 ≤ V ≤ 2.4]
```

де `a` — геометричний радіус скляної серцевини, `V` — параметр нормованої частоти.

**Приклад розрахунку:** Для волокна із `a = 4.1 мкм` та `V = 2.1` на довжині хвилі 1310 нм:

```
w₀ / a = 0.65 + 1.619 / (2.1^1.5) + 2.879 / (2.1^6)  [підстановка V = 2.1 в емпіричну формулу Маркузе]
= 0.65 + 1.619 / 3.043 + 2.879 / 85.766              [обчислення степенів V^1.5 та V^6]
= 0.65 + 0.532 + 0.033 = 1.215                       [підсумовування трьох доданків]
```

Отже, радіус світлової плями дорівнює `w₀ = 4.1 · 1.215 ≈ 4.98 мкм`, що відповідає діаметру модового поля `MFD = 2 · w₀ ≈ 9.96 мкм`. Це означає, що понад `20%` оптичної потужності поширюється за межами скляної серцевини всередині оболонки.

#### Фізичний зміст та застосування діаметра модового поля
Діаметр модового поля `MFD` є важливішим практичним параметром одномодового волокна, ніж чисто геометричний діаметр серцевини `2a`. Саме від `MFD` залежать втрати на стикування двох волокон: при радіальному зміщенні осей двох волокон `d` втрати на вношення `IL_splice` обчислюються за формулою Гейса–Маркузе:

```
IL_splice = −10 · lg( exp( −(d / w₀)² ) ) = 4.343 · (d / w₀)²          [в децибелах]
```

Отже, що більший радіус плями `w₀`, то менш чутливим є стик волокна до мікроскопічного юстувального зсуву осей при зварюванні.
