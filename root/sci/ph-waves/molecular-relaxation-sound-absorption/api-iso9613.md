# 📋 Інтерфейс та специфікація бібліотеки розрахунку поглинання звуку (ISO 9613-1)

Ця довідкова вставка містить детальний програмний контракт, специфікацію типів даних, межі застосовності та повний опис API програмної бібліотеки для обчислення атмосферного поглинання звуку відповідно до міжнародного стандарту **ISO 9613-1**.

## 1. Сфера застосування та фізичний контракт параметрів

Бібліотека розроблена для інтеграції в обчислювальні ядра симуляторів довкілля, геоінформаційні системи (ГІС), системи розрахунку шумових карт навколо аеродромів та промислових об'єктів, акустичні процесори концертних залів, а також у прошивку вбудованих ультразвукових локаторів і парктроніків.

Програмний інтерфейс гарантує математичну та фізичну точність обчислень у межах визначеного стандартом діапазону вхідних параметрів. Всі вхідні аргументи проходять строгу перевірку перед виконанням розрахунку.

| Параметр | Позначення у коді | Граничний діапазон | Оптимальний діапазон стандарту | Одиниці вимірювання |
|---|---|---|---|---|
| **Частота звуку** | `frequency_hz` | `50.0 … 100000.0` | `50.0 … 10000.0` | Гц (Hz) |
| **Температура повітря** | `temperature_c` | `-20.0 … +50.0` | `-20.0 … +50.0` | градуси Цельсія (°C) |
| **Відносна вологість** | `relative_humidity` | `0.0 … 100.0` | `10.0 … 100.0` | відсотки (%) |
| **Атмосферний тиск** | `pressure_kpa` | `10.0 … 200.0` | `50.0 … 120.0` | кілопаскалі (кПа) |

### Деталізований фізичний розбір крайніх випадків

Розглянемо фізичні особливості поведінки алгоритму та рекомендації щодо обробки крайніх режимів роботи у реальних обчислювальних системах:

1. **Субнульові температури (`temperature_c < 0.0 °C`):**
   При температурах нижче точки замерзання води (`0 °C`) водяна пара в атмосфері може перебувати у стані насичення над рідкою переохолодженою водою або над поверхнею льоду. Стандарт ISO 9613-1 за замовчуванням обчислює парціальний тиск водяної пари над водою. У реальних умовах сильного морозу (нижче `-10 °C`) це може призводити до невеликої переоцінки вмісту вологи. Для арктичних застосувань рекомендується застосовувати коефіцієнт сублімації льоду.

2. **Високочастотний та ультразвуковий межі (`frequency_hz > 100 кГц`):**
   На частотах понад 100 кГц коефіцієнт поглинання звуку у повітрі стає надзвичайно великим (перевищує 3000 дБ/км, або 3 дБ/м). На цих частотах додатковий дисипативний внесок починають вносити обертальна релаксація азоту та дифузійні процеси міжмолекулярного розсіювання, які не враховуються у стандартному рівнянні ISO 9613-1. При обчисленнях на частотах вище 100 кГц бібліотека повертає розраховане значення, але виставляє застережний прапор попередження.

3. **Розріджена атмосфера та високогір'я (`pressure_kpa < 50 кПа`):**
   Зі зменшенням барометричного тиску `p_a` (наприклад, у гірській місцевості або в авіації на висотах 3000–10000 метрів) середня довжина вільного пробігу молекул зростає, а частота міжмолекулярних зіткнень пропорційно падає. Це призводить до зменшення частот релаксації кисню та азоту, зміщуючи піки поглинання в область нижчих частот.

## 2. Структури даних API та заголовки інтерфейсів (C / C++)

Програмний інтерфейс розроблено за принципами мінімального зв'язування (low coupling) та відсутності прихованого стану. Нижче наведено інтерфейсні оголошення структур даних та функцій мовами C та C++.

:::tabs
```c
/* iso9613_api.h — C-інтерфейс бібліотеки ISO 9613-1 */
#ifndef ISO9613_API_H
#define ISO9613_API_H

#include <stddef.h>

#ifdef __cplusplus
extern "C" {
#endif

/* Коди помилок виконання */
typedef enum {
    ISO9613_SUCCESS = 0,
    ISO9613_ERROR_NULL_POINTER = -1,
    ISO9613_ERROR_INVALID_FREQUENCY = -2,
    ISO9613_ERROR_INVALID_TEMPERATURE = -3,
    ISO9613_ERROR_INVALID_HUMIDITY = -4,
    ISO9613_ERROR_INVALID_PRESSURE = -5
} iso9613_error_t;

/* Вхідна структура атмосферних умов */
typedef struct {
    double temperature_c;    /* Температура повітря у °C */
    double relative_humidity;/* Відносна вологість у % (0.0 .. 100.0) */
    double pressure_kpa;     /* Барометричний тиск у кПа */
} iso9613_atmosphere_t;

/* Деталізований результат розрахунку */
typedef struct {
    double alpha_total_db_km;/* Сумарне поглинання у дБ/км */
    double alpha_total_db_m; /* Сумарне поглинання у дБ/м */
    double alpha_classical;  /* Внесок в'язкості та теплопровідності (дБ/км) */
    double alpha_oxygen;     /* Внесок релаксації кисню O2 (дБ/км) */
    double alpha_nitrogen;   /* Внесок релаксації азоту N2 (дБ/км) */
    double fr_oxygen_hz;     /* Частота релаксації кисню (Гц) */
    double fr_nitrogen_hz;   /* Частота релаксації азоту (Гц) */
} iso9613_result_t;

/* Обчислення поглинання для однієї частоти */
iso9613_error_t iso9613_calculate_single(
    double frequency_hz,
    const iso9613_atmosphere_t* env,
    iso9613_result_t* result
);

/* Пакетне обчислення для масиву частот (векторизоване) */
iso9613_error_t iso9613_calculate_spectrum(
    const double* frequencies_hz,
    double* results_db_km,
    size_t count,
    const iso9613_atmosphere_t* env
);

#ifdef __cplusplus
}
#endif

#endif /* ISO9613_API_H */
```
```cpp
// iso9613_api.hpp — C++20 Обгортка бібліотеки ISO 9613-1
#ifndef ISO9613_API_HPP
#define ISO9613_API_HPP

#include "iso9613_api.h"
#include <expected>
#include <span>
#include <vector>

namespace iso9613 {

using Atmosphere = iso9613_atmosphere_t;
using Result = iso9613_result_t;
using Error = iso9613_error_t;

class Calculator {
public:
    // Обчислення для одного значення частоти
    [[nodiscard]] static std::expected<Result, Error> 
    calculate(double frequency_hz, const Atmosphere& env) noexcept {
        Result res{};
        Error err = iso9613_calculate_single(frequency_hz, &env, &res);
        if (err == ISO9613_SUCCESS) {
            return res;
        }
        return std::unexpected(err);
    }

    // Пакетне обчислення для спектральних смуг
    static Error calculate_batch(
        std::span<const double> freqs,
        std::span<double> out_db_km,
        const Atmosphere& env
    ) noexcept {
        return iso9613_calculate_spectrum(
            freqs.data(), 
            out_db_km.data(), 
            std::min(freqs.size(), out_db_km.size()), 
            &env
        );
    }
};

} // namespace iso9613

#endif /* ISO9613_API_HPP */
```

## 3. Специфікація контрактів методів та семантика викликів

Опишемо детальний порядок взаємодії з функціями бібліотеки, гарантії валідності аргументів та правила обробки виняткових ситуацій.

### 3.1. Функція `iso9613_calculate_single`

**Призначення:** Обчислює деталізований компонентний розклад поглинання звуку (з окремим виділенням класичного внеску Стокса — Кірхгофа, релаксації кисню та релаксації азоту) для одного конкретного значення частоти.

**Вхідні аргументи та валідація:**
1. `frequency_hz` (double): Частота акустичних коливань у Гц. Перевіряється умова `frequency_hz > 0.0`. Якщо значення `<= 0.0`, функція перериває виконання і повертає код `ISO9613_ERROR_INVALID_FREQUENCY`.
2. `env` (const iso9613_atmosphere_t*): Вказівник на структуру з параметрами навколишнього середовища. Перевіряється на `NULL`. Перевіряються допустимі межі температури, вологості та тиску.
3. `result` (iso9613_result_t*): Вихідний вказівник на структуру, куди записуються результати обчислень. Якщо вказівник є `NULL`, функція повертає `ISO9613_ERROR_NULL_POINTER`.

**Коди повернення та їх семантика:**
- `ISO9613_SUCCESS` (`0`): Обчислення успішно виконані, всі поля структури `result` заповнені валідними дійсними числами.
- `ISO9613_ERROR_NULL_POINTER` (`-1`): Один із переданих вказівників має значення `NULL`.
- `ISO9613_ERROR_INVALID_FREQUENCY` (`-2`): Передано від'ємну чи нульову частоту.
- `ISO9613_ERROR_INVALID_TEMPERATURE` (`-3`): Температура перевищує границі допустимого фізичного діапазону (`<-50 °C` або `>+100 °C`).
- `ISO9613_ERROR_INVALID_HUMIDITY` (`-4`): Відносна вологість є від'ємною або більшою за 100%.

### 3.2. Функція `iso9613_calculate_spectrum`

**Призначення:** Виконує високопродуктивне пакетне обчислення коефіцієнтів поглинання для масиву спектральних частот (наприклад, для 31 третьоктавної смуги від 20 Гц до 20 кГц).

**Вхідні аргументи:**
- `frequencies_hz` (const double*): Вказівник на масив вхідних частот у Гц.
- `results_db_km` (double*): Вказівник на вихідний масив, куди записуються розраховані коефіцієнти у дБ/км.
- `count` (size_t): Кількість елементів у масивах.
- `env` (const iso9613_atmosphere_t*): Вказівник на структуру атмосфери.

**Архітектура внутрішньої оптимізації продуктивності:**
Пакетна функція застосовує інваріантне винесення обчислень з циклу. Оскільки атмосферні параметри (`T`, `RH`, `p_a`) є однаковими для всього спектра частот, такі важкі математичні операції як обчислення насиченого тиску водяної пари `p_sat` (через дробовий степінь `pow()`), молярної концентрації `h` та частот релаксації `f_rO2` і `f_rN2` виконуються **строго один раз на початку функції**. Для кожного елемента масиву у внутрішньому циклі залишається виконати лише базові арифметичні операції додавання, множення та ділення, що дозволяє компілятору повністю векторизувати цикл із використанням інструкцій AVX2 чи NEON.

## 4. Гарантії потокобезпеки, обсяг ресурсів та сумісність ABI

Програмний інтерфейс розроблено з урахуванням суворих вимог до надійності та продуктивності у високонавантажених обчислювальних системах:

1. **Гарантія повної потокобезпеки (Thread-Safety & Reentrancy):**
   Усі функції API є повністю чистими (reentrant) і не володіють внутрішнім прихованим станом. Вони не використовують глобальних змінних, статичних буферів чи локального пам'яті потоку (Thread-Local Storage). Будь-яка кількість паралельних потоків виконання може одночасно викликати функції обчислення без виникнення гонитви даних (data race) і без потреби у блокуваннях чи м'ютексах.

2. **Гарантія відсутності динамічного виділення пам'яті (Zero Allocation):**
   Бібліотека не виконує жодного виклику функцій системного розподільника пам'яті (`malloc`, `free`, `realloc`, `calloc`, `new`, `delete`). Усі обчислення виконуються виключно у регістрах процесора та на стеку викликаючого потоку. Це робить бібліотеку ідеальною для використання у системах реального часу (Real-Time Systems), прошивках мікроконтролерів без операційної системи (Bare-Metal), а також у середовищах із забороною динамічної пам'яті (Safety-Critical Software за стандартами DO-178C / ISO 26262).

3. **Точність та обробка чисел з плаваючою комою (Floating-Point Behavior):**
   Обчислення виконуються з подвійною точністю (стандарт IEEE 754 `double`). Алгоритм захищений від виникнення денормалізованих чисел (subnormal numbers) та ділення на нуль при роботі з абсолютно сухим повітрям (`RH = 0%`).

4. **Дотримання ABI та стандарту ISO 9613-1:**
   Двійковий інтерфейс (ABI) відповідає стандартній угоді про виклики C (C calling convention). Модуль сумісний з усіма сучасними компіляторами (GCC, Clang, MSVC, ICC) і підтримує стабільне зв'язування як у вигляді статичної, так і динамічної бібліотеки (`.so`, `.dll`, `.dylib`).
