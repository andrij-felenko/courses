# 🧮 Виведення коефіцієнта поглинання звуку: класична в'язкість, теплопровідність та двостанна релаксація

Ця математична вставка містить суворий аналітичний вивід коефіцієнта поглинання звуку в газі. Вона охоплює класичне гідродинамічне згасання Стокса — Кірхгофа на основі лінеаризованих рівнянь Нав'є — Стокса та феноменологічну теорію двостанної молекулярної релаксації.

## 1. Лінеаризовані рівняння гідродинаміки в'язкого газу

Розглянемо малі акустичні збурення у газі з рівноважною густиною `ρ₀`, тиском `p₀` та температурою `T₀`. Позначимо відхилення як `ρ' = ρ - ρ₀`, `p' = p - p₀`, `T' = T - T₀`, а вектор швидкості середовища як `v`. Усі відхилення вважаються малими величинами першого порядку порядку малості, що дозволяє знехтувати нелінійними членами на зразок `(v·∇)v` чи `ρ'·v`.

Система фундаментальних рівнянь суцільного середовища складається з трьох рівнянь збереження:

1. Рівняння неперервності, яке виражає закон збереження маси для стисливого середовища у диференціальній формі:

```
∂ρ'/∂t + ρ₀·(∇·v) = 0      [лінеаризоване рівняння неперервності]
```

2. Рівняння руху Нав'є — Стокса, яке виражає закон збереження імпульсу з урахуванням зсувної в'язкості `μ` та об'ємної (другої) в'язкості `μ_b`:

```
ρ₀·(∂v/∂t) = -∇p' + μ·∇²v + (μ_b + (1/3)·μ)·∇(∇·v)      [лінеаризоване рівняння Нав'є — Стокса]
```

У цьому рівнянні перший член праворуч `-∇p'` відповідає пружним силам градієнта тиску, другий член `μ·∇²v` описує в'язкий опір зсуву між суміжними шарнірами газу, а третій член `(μ_b + (1/3)·μ)·∇(∇·v)` описує дисипацію при об'ємному розширенні та стисненні.

3. Рівняння припливу тепла, яке описує закон збереження енергії з урахуванням теплопровідності Фурьє `κ`:

```
ρ₀·C_v·(∂T'/∂t) + p₀·(∇·v) = κ·∇²T'      [лінеаризоване рівняння теплопровідності]
```

де `C_v` — питома теплоємність при постійному об'ємі, `κ` — коефіцієнт теплопровідності. Член `p₀·(∇·v)` описує роботу стиснення газу, а `κ·∇²T'` — теплообмін між нагрітими зонами стиснення та охолодженими зонами розрідження.

## 2. Виведення класичного поглинання Стокса — Кірхгофа

Шукаємо розв'язок системи лінеаризованих рівнянь у вигляді плоскої гармонічної хвилі, яка поширюється уздовж осі `x`:

```
p'(x, t) = P₀·exp[ i·(k·x - ω·t) ]      [анзац плоскої гармонічної хвилі]
```

Через наявність дисипативних процесів (в'язкості та теплопровідності) хвильове число `k` є комплексною величиною:

```
k = (ω / c) - i·α      [комплексне хвильове число]
```

Дійсна частина `Re(k) = ω / c` визначає фазову швидкість поширення хвилі `c`, а уявна частина `Im(k) = -α` визначає просторовий коефіцієнт поглинання `α` (у Неперах на метр, Np/м).

Підставляючи анзац плоскої хвилі у рівняння Нав'є — Стокса для поздовжніх коливань (`∇×v = 0`), отримуємо прямого зв'язку між акустичним тиском і швидкістю частинок газу:

```
i·ω·ρ₀·v_x = i·k·p' + ((4/3)·μ + μ_b)·k²·v_x      [зв'язок тиску та швидкості з урахуванням в'язкості]
```

Звідси виражаємо ефективну в'язкісну поправку до акустичного тиску:

```
p' = (ρ₀·ω / k)·v_x - i·k·((4/3)·μ + μ_b)·v_x      [ефективний тиск із в'язким напруженням]
```

Аналогічно, підставляючи вираз для температури з рівняння теплопровідності та використовуючи термодинамічне співвідношення для ідеального газу `p' = ρ₀·R·T' + R·T₀·ρ'`, знаходимо термодинамічний зв'язок між тиском і густиною з урахуванням незворотного теплообміну:

```
p' = c₀²·ρ' - i·ω·(γ - 1)·(κ / (ρ₀·C_p))·ρ'      [комплексний зв'язок p'(ρ') через теплопровідність]
```

де `c₀ = √(γ·R·T₀)` — ідеальна адіабатична швидкість звуку, `γ = C_p / C_v` — показник адіабати.

Комбінуючи в'язкісний та тепловий внески у дисперсійне рівняння `k² = ω² / (p'/ρ')` і приймаючи припущення слабкого згасання (`α << ω/c`), розкладаємо комплексний корінь у ряд Тейлора за малими дисипативними параметрами:

```
k² = (ω² / c₀²) · [ 1 + i·ω·( ((4/3)·μ + μ_b)/(ρ₀·c₀²) + (γ - 1)·κ/(ρ₀·C_p·c₀²) ) ]   [дисперсійне рівняння]
```

Виділяючи уявну частину `α = -Im(k)`, отримуємо точну класичну формулу Стокса — Кірхгофа для коефіцієнта поглинання:

```
α_classical = (ω² / (2·ρ₀·c₀³)) · [ (4/3)·μ + μ_b + (γ - 1)·(κ / C_p) ]   [коефіцієнт класичного поглинання]
```

Розглянемо чисельні значення для сухого повітря за нормальних атмосферних умов при `T = 20 °C` (293.15 K) та тиску `p₀ = 101.325 кПа`:
- Рівноважна густина повітря: `ρ₀ = 1.204 кг/м³`
- Швидкість звуку: `c₀ = 343.2 м/с`
- Динамічна в'язкість: `μ = 1.825 × 10⁻⁵ Па·с`
- Коефіцієнт теплопровідності: `κ = 0.0257 Вт/(м·К)`
- Показник адіабати: `γ = 1.400`
- Питома теплоємність при постійному тиску: `C_p = 1005 Дж/(кг·К)`

Підставляючи ці чисельні параметри у формулу Стокса — Кірхгофа (без урахування об'ємної в'язкості `μ_b`):

```
α_classical / f² ≈ 1.61 × 10⁻¹¹  Np / (м·Гц²)      [чисельне значення для повітря]
```

У практичних одиницях децибел на кілометр (`1 Np/м = 8685.89 дБ/км`):

```
a_classical(f) ≈ 1.40 × 10⁻⁷ · f²  дБ/км      [класичне поглинання у дБ/км]
```

На частоті `f = 1 кГц` класичне поглинання становить лише `0.00014 дБ/км`, що є нехтувально малою величиною і підтверджує необхідність урахування молекулярної релаксації.

## 3. Математика молекулярної релаксації

Для двоатомних молекул (`N₂` та `O₂`) загальна внутрішня енергія складається з поступальної `E_trans`, обертальної `E_rot` та коливальної `E_vib`. Поступальні та обертальні ступені вільності приходять у термодинамічну рівновагу за кілька зіткнень (`10⁻⁹ с`), тоді як обмін енергією з коливальним ступенем вільності описується кінетичним рівнянням Мандельштама — Леонтовича для внутрішньої релаксуючої змінної:

```
d E_vib / dt = - (E_vib - E_eq(T)) / τ      [рівняння релаксації Мандельштама-Леонтовича]
```

де `E_eq(T)` — рівноважна коливальна енергія при даній поступальній температурі `T`, `τ` — характеристичний час молекулярної релаксації.

У гармонічному акустичному полі з частотою `ω` коливання поступальної температури `T'(t) = T'₀·exp(-i·ω·t)` викликають коливання коливальної енергії з фазовою затримкою:

```
E_vib'(t) = (C_vib · T'(t)) / (1 - i·ω·τ)      [динамічна коливальна енергія]
```

де `C_vib = dE_eq/dT` — коливальна частина теплоємності, яка визначається формулою Ейнштейна для квантового гармонічного осцилятора:

```
C_vib = R · (Θ_v / T)² · [ exp(Θ_v / T) / (exp(Θ_v / T) - 1)² ]   [формула Ейнштейна для теплоємності]
```

Для кисню `O₂` характеристична температура коливань становить `Θ_v = 2239 К`, для азоту `N₂` — `Θ_v = 3374 К`.

З урахуванням скінченної швидкості обміну енергією ефективна питома теплоємність газу при постійному об'ємі стає комплексною функцією частоти коливань:

```
C_v(ω) = C_v∞ + C_vib / (1 - i·ω·τ)      [комплексна теплоємність при постійному об'ємі]
```

де `C_v∞` — теплоємність за високих частот (`ω·τ >> 1`), коли коливальні ступені «заморожені» і не встигають брати участь у теплообміні.

Підстановка комплексної теплоємності у вираз для комплексної швидкості звуку `c²(ω) = (γ(ω)·R·T₀)` дає:

```
c²(ω) = c₀² · [ 1 + (i·ω·τ · Δc² / c₀²) / (1 - i·ω·τ) ]   [комплексна швидкість звуку]
```

де `Δc² = c∞² - c₀²` — дисперсія швидкості звуку між низькочастотною `c₀` та високочастотною `c∞` границями.

Виділяючи уявну частину комплексного хвильового числа `α_relax = -Im(ω / c(ω))`, отримуємо формулу релаксаційного поглинання на один метр:

```
α_relax(f) = (π · (γ - 1) · C_vib / C_p) · (f / c) · [ (2 · (f / f_r)) / (1 + (f / f_r)²) ]   [поглинання на метр]
```

де `f_r = 1 / (2·π·τ)` — характеристична частота релаксації, на якій згасання досягає максимуму.

## 4. Аналіз релаксаційного піку та згасання на довжину хвилі

Введемо безрозмірний коефіцієнт поглинання на один шарнір (або на довжину хвилі `λ = c / f`):

```
μ_abs = α_relax · λ = α_relax · (c / f)      [поглинання на довжину хвилі]
```

Підставляючи вираз для `α_relax`, отримуємо симетричну релаксаційну функцію:

```
μ_abs(f) = (2 · μ_max) · [ (f / f_r) / (1 + (f / f_r)²) ]   [безрозмірна крива релаксації]
```

де максимальне значення поглинання на довжину хвилі досягається точно при `f = f_r`:

```
μ_max = (π / 2) · ((γ - 1) · C_vib / C_p)      [максимальне поглинання на довжину хвилі]
```

Графічний та фізичний аналіз цієї залежності показує три граничні режими:

1. **Низькочастотна границя (`f << f_r`, тобто `ω·τ << 1`):**
   Коливання тиску відбуваються настільки повільно, що коливальний ступінь вільності встигає повністю прийти у термодинамічну рівновагу на кожному кроці. Поглинання на метр зростає як квадрат частоти: `α_relax ∝ f² / f_r`.

2. **Релаксаційний пік (`f = f_r`, тобто `ω·τ = 1`):**
   Час періоду хвилі збігається з часом релаксації. Фазовий зсув між тиском і густиною сягає максимуму `Δφ = π/4`. Втрати енергії на кожен цикл коливань досягають абсолютного максимуму.

3. **Високочастотна границя (`f >> f_r`, тобто `ω·τ >> 1`):**
   Коливання відбуваються настільки швидко, що молекули взагалі не встигають обмінятися енергією з коливальними моди (ступінь вільності «виключений»). Поглинання на метр виходить на константне насичення: `α_relax → const`.

У загальному випадку для суміші газу з кількома релаксуючими компонентами (`O₂` та `N₂`) повне поглинання дорівнює сумі класичного внеску та релаксаційних внесків кожного газу:

```
α_total(f) = α_classical(f) + α_relax,O2(f) + α_relax,N2(f)   [сумарне поглинання]
```

Саме цей математичний вираз покладено в основу стандартної алгоритмічної моделі ISO 9613-1.
