# 🧮 Математичний апарат колориметрії: дискретизація спектральних інтегралів, тристимульні матриці та CCT

Ця математична вставка містить строгі алгебраїчні та аналітичні виведення співвідношень колориметрії: від безперервного інтегрування спектральної густини потужності до дискретних сум, перетворення матриць між просторами RGB та XYZ, обчислення координат у рівномірних колірних просторах `u', v'`, хроматичної адаптації фон Кріза та математичних алгоритмів розрахунку корельованої колірної температури (CCT) і відхилення `Δ[uv]`.

## 1. Спектральні інтеграли та їх дискретизація

Фундаментальне рівняння колориметрії пов'язує безперервний спектральний розподіл потужності джерела світла `S(λ)` (у ватах на квадратний метр на нанометр, Вт/(м²·нм)) із тристимульним вектором `(X, Y, Z)` стандарту CIE 1931:

```
X = k · ∫ S(λ) · x̄(λ) dλ    [інтегрування від λ = 380 нм до 780 нм]
Y = k · ∫ S(λ) · ȳ(λ) dλ    [інтегрування від λ = 380 нм до 780 нм]
Z = k · ∫ S(λ) · z̄(λ) dλ    [інтегрування від λ = 380 нм до 780 нм]
```

Нормувальний коефіцієнт `k` обирається залежно від оптичного режиму вимірювання:

- **Абсолютна фотометрія (яскравість Y у кд/м² або потік у люменах):**
  Коефіцієнт `k` дорівнює максимальній світловій ефективності монохроматичного випромінювання на довжині хвилі 555 нм:
  ```
  k = K[m] = 683.002 лм/Вт    [максимальна світлова віддача денного зору]
  ```

- **Відносна колориметрія (відбите світло від поверхні, нормування Y = 100):**
  Коефіцієнт `k` нормує відбиття ідеально білого дифузного розсіювача під еталонним ілюмінантом `S[ref](λ)` (наприклад, `D65` або `A`):
  ```
  k = 100 / ∫ S[ref](λ) · ȳ(λ) dλ
  ```

У реальних вимірювальних приладах (спектрорадіометрах) спектр вимірюється неперервно, а реєструється у вигляді дискретного масиву відліків із кроком `Δλ` (зазвичай `Δλ = 1 нм` або `Δλ = 5 нм`). Для обчислення інтегралів використовується формула методом трапецій або пряме сумування Рімана:

```
X = k · ∑ S(λ[i]) · x̄(λ[i]) · Δλ    [дискретна сума по всіх i від 380 до 780 нм]
Y = k · ∑ S(λ[i]) · ȳ(λ[i]) · Δλ    [дискретна сума по всіх i від 380 до 780 нм]
Z = k · ∑ S(λ[i]) · z̄(λ[i]) · Δλ    [дискретна сума по всіх i від 380 до 780 нм]
```

Якщо табульовані значення спектральних функцій чутливості `x̄(λ[i])`, `ȳ(λ[i])`, `z̄(λ[i])` вже помножені на крок `Δλ` та нормувальний коефіцієнт `k`, обчислення зводяться до трьох скалярних добутків векторів у пам'яті контролера.

## 2. Перетворення матриць між просторами RGB та XYZ

Експериментальні дані Райта та Гілда описувалися у просторі первинних монохроматичних джерел `R` (700.0 нм), `G` (546.1 нм) та `B` (435.8 нм). Лінійне перетворення між вектором `(R, G, B)` та тристимульним вектором `(X, Y, Z)` стандарту CIE 1931 задається строгою матрицею `M[RGB->XYZ]`:

```
[ X ]   [ 0.49000  0.31000  0.20000 ]   [ R ]
[ Y ] = [ 0.17697  0.81240  0.01063 ] · [ G ]
[ Z ]   [ 0.00000  0.01000  0.99000 ]   [ B ]
```

Зворотне перетворення від уявних координат `XYZ` до первинних фізичних джерел `RGB` здійснюється за допомогою оберненої матриці `M⁻¹[RGB->XYZ]`:

```
[ R ]   [  2.36461  -0.89654  -0.46807 ]   [ X ]
[ G ] = [ -0.51517   1.42641   0.08876 ] · [ Y ]
[ B ]   [  0.00520  -0.01441   1.00920 ]   [ Z ]
```

Другий рядок матриці прямого перетворення (`0.17697 + 0.81240 + 0.01063 = 1.00000`) нормований так, щоб сума коефіцієнтів для `Y` точно дорівнювала одиниці, що підтверджує прямий зв'язок `Y` із фотометричною яскравістю.

## 3. Нормування та геометрія хроматичних просторів

Для розділення кількісного світлового потоку `Y` та якісних характеристик кольору здійснюється проекція тривимірного вектора на площину `X + Y + Z = 1`. Координати хроматичності `(x, y, z)` обчислюються за формулами:

```
x = X / (X + Y + Z)    [відносна частка червоної складової]
y = Y / (X + Y + Z)    [відносна частка зеленої складової]
z = Z / (X + Y + Z)    [відносна частка синьої складової]
```

Оскільки за визначенням `x + y + z = 1`, третя координата повністю визначається двома першими:

```
z = 1 - x - y
```

Якщо відомі 2D-координати хроматичності `(x, y)` та яскравість `Y`, відновлення вихідного 3D-вектора `(X, Y, Z)` виконується за формулами:

```
X = (x / y) · Y
Y = Y
Z = ((1 - x - y) / y) · Y
```

### Рівномірний колірний простір CIE 1976 UCS (u', v')

Головним недоліком діаграми CIE 1931 `(x,y)` є її геометрична нерівномірність: однакова відстань `Δ = √[(Δx)² + (Δy)²]` у зеленій зоні відповідає малим, майже непомітним змінам кольору, тоді як у синій та червоній зонах така ж відстань викликає величезне зорове відхилення (еліпси Мак-Адама).

Для усунення цього викривлення CIE у 1976 році стандартизувала рівномірний колірний простір (Uniform Chromaticity Scale — UCS) з координатами `(u', v')`:

```
u' = 4X / (X + 15Y + 3Z) = 4x / (-2x + 12y + 3)
v' = 9Y / (X + 15Y + 3Z) = 9y / (-2x + 12y + 3)
```

Зворотне перетворення від `(u', v')` до `(x, y)` має вигляд:

```
x = (27u') / (18u' - 12v' + 36)
y = (12v') / (18u' - 12v' + 36)
```

У просторі `(u', v')` евклідова відстань `Δu'v' = √[(Δu')² + (Δv')²]` значно краще пропорційна суб'єктивному відчуттю колірної відмінності ока.

## 4. Математичне обчислення корельованої колірної температури (CCT)

Колірна температура планківського випромінювача описується законом випромінювання Планка:

```
S(λ, T) = (c₁ / λ⁵) / (exp(c₂ / (λ · T)) - 1)
```

де `c₁ = 3.741771 × 10⁻¹⁶ Вт·м²`, `c₂ = 1.4388 × 10⁻² м·К`, `T` — температура в Кельвінах.

Інтегрування спектра Планка `S(λ, T)` при різних температурах `T` дає неперервну криву у просторі хроматичностей — **лінію чорного тіла (Planckian Locus)**.

### Наближена формула МакКамі (McCamy Approximation)

Для швидкого обчислення корельованої колірної температури (CCT) за відомими координатами `(x, y)` без чисельного пошуку на кривій Планка використовується кубічне наближення МакКамі (McCamy, 1992):

```
n = (x - 0.3320) / (0.1858 - y)    [нормована хроматична відстань]
CCT(n) = 449.0 · n³ + 3525.0 · n² + 6823.3 · n + 5520.33    [температура в Кельвінах]
```

Формула МакКамі забезпечує точність кращу за 99% для діапазону температур від 2000 K до 12500 K.

### Метод Робертсона (Robertson's Method)

Для точних світлотехнічних розрахунків метод Робертсона спирається на табульовані значення 30 точок температури `T[i]` уздовж лінії чорного тіла від 1000 K до нескінченності. Для кожної точки `T[i]` визначено координати `(u[i], v[i])` та кутовий коефіцієнт наклону ізотемпературної лінії `d[i] = -1 / m[i]`:

```
d[i] = - ( (u[i+1] - u[i-1]) / (v[i+1] - v[i-1]) )
```

Для колірної точки випромінювача `(u_s, v_s)` обчислюється ортогональна відстань `d_s` до кожної ізотемпературної лінії:

```
d_s(i) = (v_s - v[i]) - d[i] · (u_s - u[i])
```

Знаходиться пара сусідніх точок `T[i]` та `T[i+1]`, між якими знак `d_s` змінюється з плюс на мінус. Потім виконується лінійна інтерполяція:

```
CCT = T[i] + (d_s(i) / (d_s(i) - d_s(i+1))) · (T[i+1] - T[i])
```

### Строгий алгоритм Охно та відхилення Δ[uv]

Для сучасних LED вимірювань у стандарту NIST використовується метод трикутної інтерполяції Охно (Yoshi Ohno). Шукається температура `T`, при якій точковий вектор `(u'_src, v'_src)` у просторі CIE 1976 UCS знаходиться найближче до лінії Планка `(u'_p(T), v'_p(T))`.

Відхилення від лінії чорного тіла `Δ[uv]` (Duv) визначається як ортогональна відстань до точки мінімуму:

```
Duv = ± √[ (u'_src - u'_p(T))² + (v'_src - v'_p(T))² ]
```

Знак `Duv` приймається додатним (`Duv > 0`), якщо точка розміщена вище лінії чорного тіла (зелений/жовтуватий відтінок), і від'ємним (`Duv < 0`), якщо точка розміщена нижче лінії (рожевий/маджентовий відтінок). Величина `|Duv| < 0.005` вважається нормою для високоякісного білого освітлення.

## 5. Математична модель адаптації фон Кріза та індексу CRI

Обчислення індексу кольоропередачі CRI спирається на модель хроматичної адаптації ока фон Кріза (von Kries chromatic adaptation model).

Оскільки випробовуване джерело та еталонне джерело можуть мати невеликі відмінності хроматичності, око адаптується до кожної білої точки. Для приведення координат відбиття випробовуваного джерела `(u_i, v_i)` до еталонного `(u_r, v_r)` застосовується матрична трансформація фон Кріза:

```
c_i = (4 - u_i - 10v_i) / v_i
d_i = (1.708v_i + 0.404 - 1.481u_i) / v_i
```

Адаптовані координати `(u_r,i, v_r,i)` обчислюються як:

```
u_r,i = (10.872 + 0.404 · (c_r / c_s) · c_i - 4 · (d_r / d_s) · d_i) / (16.518 + 1.481 · (c_r / c_s) · c_i - (d_r / d_s) · d_i)
v_r,i = 5.520 / (16.518 + 1.481 · (c_r / c_s) · c_i - (d_r / d_s) · d_i)
```

Потім виконується перетворення координат у простір CIE 1964 `W*U*V*`:

```
W* = 25 · Y^(1/3) - 17
U* = 13 · W* · (u - u_0)
V* = 13 · W* · (v - v_0)
```

Колірне зсунення `ΔE[i]` обчислюється як евклідова відстань між векторами зразків для еталонного та випробовуваного джерела:

```
ΔE[i] = √[ (U*_test - U*_ref)² + (V*_test - V*_ref)² + (W*_test - W*_ref)² ]
```

Окремий індекс кожного зразка `R[i]` обчислюється як:

```
R[i] = 100 - 4.6 · ΔE[i]
```

Коефіцієнт 4.6 підібраний так, щоб стандартна тепло-біла люмінесцентна лампа типу Deluxe мала індекс `R[a] = 50`.
