# 📋 Структури даних і каталог коефіцієнтів дисперсії оптичного скла

Контракт інтерфейсу та каталог оптичних матеріалів є ключовою складовою частиною програмних комплексів трасування променів (геометричної оптики), комп'ютерного моделювання оптичних систем (CAD) та розрахунку розповсюдження хвильових фронтів у лазерній оптиці. Для опису дисперсійних властивостей матеріалу у прозорому спектральному діапазоні недостатньо зберігати лише одне числове значення показника заломлення `n`. Оптичний розрахунок вимагає завантаження спектральних констант, наборів резонансних коефіцієнтів Зельмейєра, термооптичних коефіцієнтів `dn/dT` та меж температурної та механічної стійкості.

Нижче наведено специфікацію спектральних ліній, структури даних мовами C та C++, схему обміну даними у форматі JSON та довідковий каталог із фізичними коефіцієнтами для основних типів оптичних стекол та кристалів.

### 1. Фізична специфікація фраунгоферових спектральних ліній

Для забезпечення єдиного стандарту вимірювань у світовій оптичній індустрії (каталоги Schott, Sumita, Ohara, Hoya) усі параметри заломлення та коефіцієнти дисперсії прив'язують до строго визначених монохроматичних довжин хвиль поглинання або випромінювання атомарних елементів. 

Використання природних точок атомних переходів водороду, натрію, ртуті, гелію та цезію дає змогу уникнути похибок відкалібрування приладів. Основні спектральні лінії умовно поділяють на три групи:

1. **Короткохвильова (ультрафіолетова та синя) група**:
   - `i-лінія` (`0.365015 мкм`) — спектральна лінія випромінювання ртуті (Hg). Використовується як вимірювальний стандарт межі прозорості у ближньому ультрафіолеті для оптичної літографії.
   - `h-лінія` (`0.404656 мкм`) — лінія випромінювання ртуті. Задає межу синьо-фіолетової ділянки видимої області.
   - `g-лінія` (`0.435834 мкм`) — синя лінія ртуті. Використовується для розрахунку часткових відносних дисперсій `P_{g,F}` та проектування апохроматичних об'єктивів.
   - `F-лінія` (`0.486133 мкм`) — блакитно-зелена лінія атомарного водню (серія Бальмера, перехід з `n=4` на `n=2`). Є основним опорним стандартом синього краю видимої області при обчисленні середньої дисперсії `(n_F - n_C)` та числа Аббе `V_d`.

2. **Основна (зелено-жовта) опорна група**:
   - `e-лінія` (`0.546074 мкм`) — зелена лінія випромінювання ртуті. У багатьох європейських та японських стандартах (ISO) є головним описовим опорним значенням `n_e` та числа Аббе `V_e = (n_e - 1) / (n_F' - n_C')`.
   - `d-лінія` (`0.587562 мкм`) — жовта лінія гелію (He). Входить до американського та німецького класичного стандарту `n_d` для обчислення основи числа Аббе `V_d`.
   - `D-дублет` (`0.589293 мкм`) — дублетна лінія поглинання натрію (Na). Історичний стандарт, який у сучасних каталогах замінено на монохроматичну гелієву `d-лінійку` через відсутність розщеплення.

3. **Довгохвильова (червона та інфрачервона) група**:
   - `C-лінія` (`0.656273 мкм`) — червона лінія Бальмера атомарного водню (перехід з `n=3` на `n=2`). Задає червону межу при розрахунку числа Аббе.
   - `r-лінія` (`0.706519 мкм`) — червона лінія гелію.
   - `s-лінія` (`0.852110 мкм`) — лінія ближнього інфрачервоного діапазону цезію (Cs).
   - `t-лінія` (`1.013980 мкм`) — інфрачервона лінія ртуті. Використовується для проектування оптичних систем нічного бачення та ІЧ-спектрометрів.

### 2. Класифікація та родинні групи оптичних стекол

Сучасні оптичні стекла поділяють на дві великі категорії — **крони** (*Crown glasses*) та **флінти** (*Flint glasses*), які у діаграмі Аббе `(n_d` проти `V_d)` утворюють чітко розмежовані області.

#### Кронові стекла (Crown, V_d > 50 для n_d < 1.60 або V_d > 55 для n_d > 1.60)
Крони характеризуються низьким показником заломлення та слабкою оптичною дисперсією (високим числом Аббе). До цієї групи належать:
- `Borosilicate Crown` (наприклад, `N-BK7`) — найпоширеніше оптичне скло на основі оксидів кремнію та бору. Володіє високою однорідністю, низькою бульбашковістю та високим хімічним опором.
- `Barium Crown` (`BaK`) — містить оксид барію для підвищення показника заломлення без істотного зниження числа Аббе.
- `Lanthanum Crown` (`LaK`) — високозаломлююче скло з вмістом рідкісноземельного оксиду лантану (`n_d ≈ 1.65`–`1.75`), що дозволяє проектувати компактні лінзи з малою кривиною поверхонь.
- `Fluorite Crown` / `Phosphate Crown` (`FK`, `PK`) — особливі флуоритні стекла з дуже високим числом Аббе (`V_d > 75`) та особливим ходом часткової дисперсії, що робить їх незамінними для апохроматичних телескопів.

#### Флінтові стекла (Flint, V_d < 50)
Флінти мають високий показник заломлення та високу дисперсійну здатність.
- `Dense Flint` (`SF` від німецького *Schwerflint*, наприклад, `N-SF11`, `SF6`) — важкі флінтові стекла з високим вмістом оксиду свинцю або титану (`n_d ≈ 1.7`–`1.9`, `V_d ≈ 20`–`30`).
- `Lanthanum Flint` (`LaF`) — лантанові флінти з високим показником заломлення.
- `Barium Flint` (`BaF`) та `Light Flint` (`LF`) — проміжні типи стекол для корекції сферохроматичних аберацій.

Префікс `N-` у назвах стекол Schott вказує на екологічно безпечний склад без використання токсичних оксидів свинцю та миш'яку (*Non-lead/arsenic*).

### 3. Часткова відносна дисперсія та розрахунок апохроматів

Окрім загального числа Аббе `V_d`, для розрахунку корекції вторинного спектра в об'єктивах використовують **часткову відносну дисперсію** `P_{x,y}`. Вона виражає відношення різниці показників заломлення на двох конкретних довжинах хвиль до середньої дисперсії `(n_F - n_C)`:

```
P_{g,F} = (n_g - n_F) / (n_F - n_C)
```

Для більшості стандартних оптичних стекол існує лінійна залежність між частковою дисперсією `P_{g,F}` та числом Аббе `V_d` (так звана «нормальна пряма»):

```
P_{g,F} ≈ 0.6438 - 0.001682 · V_d
```

Матеріали, які відхиляються від цієї нормальної прямої (значна величина `ΔP_{g,F}`), називаються **стеклами з аномальною частковою дисперсією**. До них належать кристали флюориту (`CaF₂`) та крони з вмістом фосфатів та фтору (`N-FK51A`). Поєднання стандартного скла та скла з аномальною частковою дисперсією дозволяє будувати апохроматичні дуплети та триплети, у яких повністю усувається колірне розфокусування трьох довжин хвиль.

### 4. Термооптичні коефіцієнти та температурне зміщення `dn/dT`

При зміні температури оптичного елемента показник заломлення змінюється внаслідок двох протилежних фізичних ефектів:
1. Зменшення густини речовини при тепловому розширенні (зменшує `n`).
2. Зсув УФ-смуги поглинання у довгохвильовий бік при нагріванні (підвищує `n`).

Температурний коефіцієнт показника заломлення `dn / dT` (вимірюється у `10⁻⁶ / К`) задається формулою Schott:

```
dn / dT = [ (n² - 1) / (2 · n) ] · [ D₀ + 2 · D₁ · ΔT + D₂ · ΔT² + E₀ + 2 · E₁ · ΔT / (λ² - λ_TK²) ]
```

Для більшості крон-стекол `dn/dT` є позитивним (`+3`–`+5 · 10⁻⁶ / К`), тоді як для флюориту `CaF₂` коефіцієнт від'ємний (`-10.6 · 10⁻⁶ / К`), що дозволяє створювати атермалізовані оптичні системи, збережувані фокус при коливаннях температури навколишнього середовища.

```c
#define GLASS_CATALOG_H

#include <stddef.h>
#include <stdbool.h>

#ifdef __cplusplus
extern "C" {
#endif

/* Довжини хвиль спектральних ліній Фраунгофера у мікрометрах */
#define LAMBDA_I_UM 0.365015  /* Ртуть i */
#define LAMBDA_H_UM 0.404656  /* Ртуть h */
#define LAMBDA_G_UM 0.435834  /* Ртуть g */
#define LAMBDA_F_UM 0.486133  /* Водень F */
#define LAMBDA_E_UM 0.546074  /* Ртуть e */
#define LAMBDA_D_UM 0.587562  /* Гелій d */

#define LAMBDA_R_UM 0.706519  /* Гелій r */

    DISPERSION_FORMULA_SELLMEIER1 = 1, /* 6-параметричне рівняння Зельмейєра */

    DISPERSION_FORMULA_HARTMANN   = 3  /* Емпірична формула Хартманна */

/* Коефіцієнти Зельмейєра: B1, B2, B3 (безрозмірні) та C1, C2, C3 (мкм²) */
typedef struct {
    double B1, B2, B3;
    double C1, C2, C3;
} SellmeierCoefficientsC;

    double D0; /* Постійний коефіцієнт (10^-6 / K) */

    double D2; /* Квадратичний температурний коефіцієнт */
    double E0; /* УФ-термічний зміщувач */
    double E1; /* ІЧ-термічний зміщувач */
} ThermoOpticCoefficientsC;

/* Повний двійковий паспорт оптичного матеріалу */
typedef struct {
    const char* material_name;     /* Строкове ім'я матеріалу (наприклад "N-BK7") */
    const char* glass_code;        /* 6-значний індекс (наприклад "517642") */
    const char* supplier;          /* Виробник (Schott, Ohara, Hoya) */
    DispersionFormulaType formula; /* Тип дисперсійного рівняння */
    SellmeierCoefficientsC sellmeier; /* Набір коефіцієнтів Зельмейєра */
    ThermoOpticCoefficientsC thermo;  /* Термооптичні параметри */
    double n_d;                    /* Каталожний показник заломлення на лінії d */
    double V_d;                    /* Каталожне число Аббе V_d */
    double density_g_cm3;          /* Питома густина скла (г/см³) */
    double lambda_min_um;          /* УФ-межа прозорості (мкм) */
    double lambda_max_um;          /* ІЧ-межа прозорості (мкм) */
} GlassMaterialSpecC;

/* Функція обчислення показника заломлення n(lambda) за паспортом C-структури */
double glass_calculate_n(const GlassMaterialSpecC* glass, double lambda_um);

/* Функція обчислення числового значення числа Аббе V_d */
double glass_calculate_v_d(const GlassMaterialSpecC* glass);

#ifdef __cplusplus
}
#endif

#endif /* GLASS_CATALOG_H */
```

```cpp
#ifndef GLASS_CATALOG_HPP
#define GLASS_CATALOG_HPP

#include <string>
#include <string_view>
#include <array>
#include <vector>
#include <optional>
#include <cmath>
#include <stdexcept>

namespace optics {

enum class SpectralLine {
    i_Mercury,
    h_Mercury,
    g_Mercury,
    F_Hydrogen,
    e_Mercury,
    d_Helium,
    C_Hydrogen,
    r_Helium,
    s_Cesium,
    t_Mercury
};

constexpr double get_wavelength_um(SpectralLine line) noexcept {
    switch (line) {
        case SpectralLine::i_Mercury:  return 0.365015;
        case SpectralLine::h_Mercury:  return 0.404656;
        case SpectralLine::g_Mercury:  return 0.435834;
        case SpectralLine::F_Hydrogen: return 0.486133;
        case SpectralLine::e_Mercury:  return 0.546074;
        case SpectralLine::d_Helium:   return 0.587562;
        case SpectralLine::C_Hydrogen: return 0.656273;
        case SpectralLine::r_Helium:   return 0.706519;
        case SpectralLine::s_Cesium:   return 0.852110;
        case SpectralLine::t_Mercury:  return 1.013980;
    }
    return 0.587562;
}

struct SellmeierParams {
    std::array<double, 3> B{}; // Амплітудні безрозмірні коефіцієнти
    std::array<double, 3> C{}; // Квадрати резонансних хвиль (мкм²)
};

struct ThermoOpticParams {
    double D0{0.0};
    double D1{0.0};
    double D2{0.0};
    double E0{0.0};
    double E1{0.0};
};

class OpticalMaterial {
private:
    std::string m_name;
    std::string m_supplier;
    SellmeierParams m_sellmeier;
    ThermoOpticParams m_thermo;
    double m_n_d_catalog{1.5};
    double m_v_d_catalog{60.0};
    double m_lambda_min_um{0.35};
    double m_lambda_max_um{2.50};

public:
    OpticalMaterial(std::string name, std::string supplier,
                    SellmeierParams sellmeier, ThermoOpticParams thermo = {})
        : m_name(std::move(name)), m_supplier(std::move(supplier)),
          m_sellmeier(sellmeier), m_thermo(thermo) 
    {
        m_n_d_catalog = calculate_n(get_wavelength_um(SpectralLine::d_Helium));
        m_v_d_catalog = calculate_v_d();
    }

    [[nodiscard]] std::string_view name() const noexcept { return m_name; }
    [[nodiscard]] std::string_view supplier() const noexcept { return m_supplier; }

    // Обчислення показника заломлення n(lambda)
    [[nodiscard]] double calculate_n(double lambda_um) const {
        if (lambda_um < m_lambda_min_um || lambda_um > m_lambda_max_um) {
            // Екстраполяційне затискання або обробка меж
        }
        const double l2 = lambda_um * lambda_um;
        double sum = 0.0;
        for (std::size_t i = 0; i < 3; ++i) {
            const double denom = l2 - m_sellmeier.C[i];
            if (std::abs(denom) < 1e-12) {
                throw std::domain_error("Помилка: довжина хвилі збігається з резонансом Зельмейєра!");
            }
            sum += (m_sellmeier.B[i] * l2) / denom;
        }
        return std::sqrt(1.0 + sum);
    }

    // Перша похідна dn/dlambda за формулою центральних різниць
    [[nodiscard]] double calculate_dn_dlambda(double lambda_um, double h = 1e-4) const {
        return (calculate_n(lambda_um + h) - calculate_n(lambda_um - h)) / (2.0 * h);
    }

    // Друга похідна d^2n / dlambda^2
    [[nodiscard]] double calculate_d2n_dlambda2(double lambda_um, double h = 1e-4) const {
        const double n_plus  = calculate_n(lambda_um + h);
        const double n_zero  = calculate_n(lambda_um);
        const double n_minus = calculate_n(lambda_um - h);
        return (n_plus - 2.0 * n_zero + n_minus) / (h * h);
    }

    // Обчислення числа Аббе V_d
    [[nodiscard]] double calculate_v_d() const {
        const double n_d = calculate_n(get_wavelength_um(SpectralLine::d_Helium));
        const double n_F = calculate_n(get_wavelength_um(SpectralLine::F_Hydrogen));
        const double n_C = calculate_n(get_wavelength_um(SpectralLine::C_Hydrogen));
        return (n_d - 1.0) / (n_F - n_C);
    }
};

} // namespace optics

#endif // GLASS_CATALOG_HPP
```
