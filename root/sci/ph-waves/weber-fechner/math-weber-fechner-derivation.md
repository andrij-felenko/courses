# 🧮 Виведення та математичний апарат закону Вебера–Фехнера

Ця вставка містить строге математичне виведення логарифмічного закону Фехнера з емпіричного пропорційного відношення Вебера, деталізує інтегрування диференціального рівняння психофізики, виведення сталих граничних умов, аналіз квантового шуму Поассона (закон Роза–Де Вріса), інформаційно-теоретичну оптимізацію каналу зв'язку та доведення граничного переходу між степенним законом Стівенса і логарифмом Фехнера.

## 1. Від дифракції порогу до диференціального рівняння

Вихідним пунктом є емпіричний закон Вебера, який стверджує, що поріг розрізнення `ΔI` пропорційний початковій інтенсивності стимулу `I`:

```
ΔI / I = k_W
```

де `k_W` — константа Вебера.

Густав Фехнер висунув постулат, що кожен мінімальний приріст відчуття `ΔS`, який відповідає порогу розрізнення `ΔI`, є константою `c` для даного аналізатора:

```
ΔS = c
```

Поєднуючи ці два вирази через коефіцієнт пропорційності `k = c / k_W`, отримуємо скінченно-різницеве співвідношення:

```
ΔS = k · (ΔI / I)
```

Переходячи від скінченно-малих приростів `ΔI` та `ΔS` до нескінченно малих диференціалів `dI` та `dS` в припущенні неперервності відчуття, отримуємо основне диференціальне рівняння психофізики:

```
dS = k · (dI / I)
```

## 2. Інтегрування диференціального рівняння

Для знаходження абсолютної величини відчуття `S(I)` необхідно інтегрувати обидві частини диференціального рівняння:

```
∫ dS = ∫ k · (1 / I) dI
```

Застосовуємо властивості невизначеного інтеграла:

```
S = k · ln(I) + C      [первісна від 1/I дорівнює натуральному логарифму ln(I)]
```

де `C` — довільна стала інтегрування, `ln` — натуральний логарифм (основа `e ≈ 2.71828`).

Щоб знайти значення сталої `C`, скористаємося фізичною граничною умовою порогу чутливості. Існує мінімальна інтенсивність стимулу `I₀` (абсолютний поріг сприйняття), нижче якої рецептори не генерують нервових імпульсів, і суб'єктивне відчуття дорівнює нулю:

```
S(I₀) = 0
```

Підставляємо граничну умову `I = I₀` та `S = 0` у виведений вираз:

```
0 = k · ln(I₀) + C
= C = -k · ln(I₀)      [перенесення доданка в ліву частину]
```

Підставимо отримане значення для `C` у загальне рішення:

```
S = k · ln(I) - k · ln(I₀)
= k · (ln(I) - ln(I₀))    [винесення спільного множника k за дужки]
= k · ln(I / I₀)          [властивість логарифма: ln a - ln b = ln(a / b)]
```

Отже, остаточна формула закону Вебера–Фехнера має вигляд:

```
S = k · ln(I / I₀)
```

## 3. Фізичне походження дробу Вебера: дробовий шум Поассона та закон Роза–Де Вріса

Виникнення співвідношення Вебера має глибоку фізичну природу, пов'язану зі статистикою квантів світла або іонів, що потрапляють на рецептор. Потік фотонів з середньою інтенсивністю `N` підпорядковується розподілу Поассона. Для поассонівського процесу середньоквадратичне відхилення (шум) `σ_N` дорівнює квадратному кореню з середнього числа фотонів:

```
σ_N = √N
```

Щоб детектор (наприклад, одиночна паличка сітківки) міг надійно відрізнити приріст сигналу `ΔN` від фонового шуму, приріст повинен перевищувати флуктуації фону на деяку величину сигналу-до-шуму `k_SNR`:

```
ΔN ≥ k_SNR · σ_N
= ΔN ≥ k_SNR · √N
```

Поділивши обидві частини на `N`, отримуємо відносний поріг розрізнення за законами квантової оптики — **закон Роза–Де Вріса (Rose-DeVries law)**:

```
ΔN / N = k_SNR / √N
```

Закон Роза–Де Вріса показує, що при дуже низькій освітленості (сутінковий зір) відносний поріг розрізнення спадає обернено пропорційно квадратному кореню з інтенсивності `ΔI / I ∝ 1 / √I`.

Однак при середній та високій освітленості домінуючим джерелом шуму стає не квантовий шум падаючого світла, а нейронний внутрішньоклітинний шум, амплітуда якого пропорційна середньому рівня деполяризації або частоті спайків `σ_neu ∝ N`. Заставивши нейронний шум `σ_neu = k_neu · N`, умова детектування набуває вигляду:

```
ΔN ≥ k_SNR · (k_neu · N)
= ΔN / N = k_SNR · k_neu = k_W
```

Таким чином, закон Вебера `ΔI / I = k_W` є прямою математичною наслідком переходу сенсорної системи від режиму обмеження зовнішнім квантовим шумом (закон Роза–Де Вріса) до режиму обмеження внутрішнім мультиплікативним нейронним шумом.

## 4. Інформаційно-теоретична оптимізація каналу за Шенноном

Розглянемо сенсорну систему як канал зв'язку з вхідним сигналом `X` (фізичний стимул) та вихідним сигналом `Y = f(X)` (частота нервових імпульсів). Припустимо, що канал має дисперсію шуму, яка зростає квадратично з величиною сигналу (мультиплікативний шум):

```
σ²_Y(x) = k² · x²
```

За теорією інформації Шеннона, пропускна здатність каналу (взаємна інформація `I(X; Y)`) максимізується тоді, коли дифференціальна ентропія вихідного сигналу `H(Y)` є максимальною при заданих обмеженнях. Для обмеженого діапазону значень `[Y_min, Y_max]` максимум ентропії досягається при рівномірному розподілі ймовірностей вихідного сигналу `p(y) = const`.

За правилом перетворення щільності ймовірності випадкової величини `p_Y(y) = p_X(x) / |f'(x)|`:

```
p_Y(y) = p_X(x) / (df/dx) = const
= df/dx ∝ p_X(x)
```

Якщо розподіл інтенсивностей природних стимулів у довкіллі має зворотну пропорційність `p_X(x) ∝ 1 / x` (закон Джеффріса для масштабних величин), отримуємо:

```
df/dx = k / x
```

Інтегруючи це диференціальне рівняння, отримуємо оптимальну функцію перетворення:

```
f(x) = k · ln(x) + C
```

Отже, логарифмічна характеристика закону Вебера–Фехнера є математично оптимальною функцією перетворення, яка максимізує передачу інформації через біологічний нейронний канал в умовах природного розподілу довкілля та мультиплікативного шуму.

## 5. Перехід до десяткових логарифмів та децибел

У прикладних галузях (акустика, оптика, радіотехніка) зручніше використовувати десяткові логарифми `log₁₀`. Перехід від натурального логарифма до десяткового здійснюється за формулою зміни основи логарифма:

```
ln(x) = log₁₀(x) / log₁₀(e)
≈ 2.30258 · log₁₀(x)
```

Підставляючи це у вираз для відчуття:

```
S = k · 2.30258 · log₁₀(I / I₀)
= K · log₁₀(I / I₀)       [де K = 2.30258 · k]
```

Прикладом застосування цього співвідношення є шкала рівня звукового тиску в децибелах (SPL, Sound Pressure Level). Оскільки акустична потужність або інтенсивність звуку `I` пропорційна квадрату звукового тиску `P²` (`I ∝ P²`), вираз для рівня гучності `L` у децибелах набуває вигляду:

```
L = 10 · log₁₀(I / I₀)
= 10 · log₁₀(P² / P₀²)
= 20 · log₁₀(P / P₀)     [властивість логарифма: log(a²) = 2 · log(a)]
```

де `P₀ = 20 µPa` — стандартний поріг чутливості людського вуха на частоті 1 кГц.

## 6. Зв'язок між степенним законом Стівенса та логарифмом Фехнера

Степенний закон Стівенса задається формулою:

```
S = A · (I / I₀)ⁿ - A
```

Покажемо, що логарифмічний закон Фехнера є граничним випадком степенного закону Стівенса, коли показник степеня `n` прямує до нуля (`n → 0`).

Скористаємося розкладом показникові функції в ряд Тейлора поблизу нуля для виразу `xⁿ = e^(n · ln x)`:

```
xⁿ = e^(n · ln x)
= 1 + n · ln(x) + (n · ln x)² / 2! + ...   [розклад e^u = 1 + u + u²/2! + ...]
```

Для малих `n` обмежимося першими двома членами розкладу:

```
xⁿ ≈ 1 + n · ln(x)
```

Підставимо цей розклад у степенний закон Стівенса для `x = I / I₀`:

```
S = A · (1 + n · ln(I / I₀)) - A
= A + A · n · ln(I / I₀) - A               [розкриття дужок]
= (A · n) · ln(I / I₀)                     [скорочення A та -A]
```

Позначивши `k = A · n`, у граничному переході при `n → 0` маємо:

```
lim_{n → 0} S = k · ln(I / I₀)
```

Математичний аналіз доводить, що логарифмічна характеристика стиснення є природною нижньою огинаючою родини степенних функцій. Саме тому для сенсорних органів із сублінійною відповіддю (`n < 1`, наприклад яскравість та гучність) логарифм є чудовим математичним наближенням у широкому діапазоні інтенсивностей.
