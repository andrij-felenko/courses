# ⚙️ Чисельне моделювання та спектральний аналіз ланцюжка зв'язаних осциляторів

Ця практична вставка містить аналіз чисельних методів інтегрування систем звичайних диференціальних рівнянь зв'язаних осциляторів, покрокову математичну схему симплектичного алгоритму Верле (Velocity Verlet), реалізацію мовами C та C++, метод розрахунку повної механічної енергії та алгоритм модальної проекції для спектрального аналізу.

## 1. Фундаментальні проблеми числового інтегрування консервативних систем

При чисельному розв'язанні диференціальних рівнянь руху зв'язаних осциляторів `M · ẍ + K · x = 0` правильний вибір чисельного інтегратора є найважливішим фактором, від якого залежить фізична точність і стійкість усього розрахунку.

Стандартні класичні методи числового інтегрування, такі як явний метод Ейлера першого порядку або класичний метод Рунге — Кутти 4-го порядку (RK4), розроблялися для загальних диференціальних рівнянь і не враховують специфічну гамільтонову структуру механічних коливальних систем.

Якщо застосувати явний метод Ейлера:

```
x(t + Δt) = x(t) + v(t) · Δt
v(t + Δt) = v(t) + a(t) · Δt
```

то на кожному кроці за часом виникає невелика систематична помилка чисельного інтегрування. У фазовому просторі координата-імпульс `(x, p)` ця помилка приводить до штучного розширення фазового об'єму (порушення фундаментальної теореми Ліувілля). Фізично це діє як штучна від'ємна дисипація (енергетичний дрейф): полна механічна енергія системи `E(t) = T(t) + V(t)` починає монотонно й експоненційно зростати із часом `dE/dt > 0`. В результаті вже за кілька десятків періодів коливань симульовані маси штучно розгойдаються до нескінченності, абсолютно спотворивши фізичну картину.

Навіть високоточний метод Рунге — Кутти 4-го порядку (RK4), який демонструє чудові результати на коротких інтервалах часу, не є симплектичним. На тривалих інтервалах симуляції (тисячі періодів коливань) чисельна енергія в системі RK4 починає монотонно спадати або зростати через наявність несимметричних вищих членів у розкладі Тейлора.

Спроба притиснути цей дрейф зменшенням кроку `Δt` у класичних методах лише відтерміновує катастрофу, істотно збільшуючи час обчислення. Для довготривалого симулювання консервативних коливальних систем у фізиці та інженерії застосовують спеціальний клас чисельних методів — **симплектичні інтегратори**.

Симплектичні інтегратори точно зберігають пуанкареївські інваріанти фазового простору та фазовий об'єм. Вони гарантують, що обчислена чисельна енергія системи не дрейфує до нескінченності, а лише здійснює мікроскопічні обмежені коливання навколо точного значення протягом як завгодно тривалого часу симуляції.

Найпопулярнішим і найефективнішим симплектичним інтегратором другого порядку точності для механічних та молекулярних систем є **алгоритм Верле зі швидкостями (Velocity Verlet)**.

## 2. Математична схема та покроковий розбір алгоритму Velocity Verlet

Алгоритм Velocity Verlet розкладено на чотири послідовні підкроки, які виконуються на кожному кроці за часом `Δt`:

1. **Оновлення координат мас у просторі:**
   На першому підкроці координата кожного осцилятора оновлюється на новий момент часу `t + Δt` з урахуванням поточної швидкості та прискорення:
   ```
   x_i(t + Δt) = x_i(t) + v_i(t) · Δt + (1/2) · a_i(t) · Δt²
   ```

2. **Проміжне (напівкрокове) оновлення швидкостей:**
   Швидкість кожного осцилятора перераховується на середину часового інтервалу `t + Δt/2`:
   ```
   v_i(t + Δt/2) = v_i(t) + (1/2) · a_i(t) · Δt
   ```

3. **Обчислення нових векторів сил та прискорень у нових позиціях `x(t + Δt)`:**
   Використовуючи оновлені координати `x_i(t + Δt)`, обчислюємо нові пружні та демпфувальні сили, що діють на кожне тіло, після чого знаходимо нове прискорення:
   ```
   a_i(t + Δt) = F_i(x(t + Δt), v(t + Δt/2)) / m_i
   ```

4. **Остаточне оновлення швидкостей на повний крок:**
   Швидкість кожного осцилятора оновлюється від напівкрокового значення до кінця інтервалу `t + Δt`:
   ```
   v_i(t + Δt) = v_i(t + Δt/2) + (1/2) · a_i(t + Δt) · Δt
   ```

Для 1D ланцюжка з `N` мас із жорсткістю пружин `K` та коефіцієнтом загасання `c` сумарна сила `F_i`, що діє на `i`-ту масу від двох сусідніх мас у ланцюжку:

```
F_i = −K · (x_i − x_{i-1}) − K · (x_i − x_{i+1}) − c · v_i
```

Для крайніх мас `i = 0` та `i = N-1` враховуються закріплені межові умови (`x = 0` на нерухомих стінах).

Обов'язковою умовою чисельної стійкості алгоритму є дотримання критерію Куранта — Фрідріхса — Леві (CFL): крок інтегрування `Δt` повинен бути суттєво меншим за найменший період коливань у системі:

```
Δt < 0.2 / ω_max
```

де `ω_max = 2 · √(K / m)` — максимальна власна частота ланцюжка.

## 3. Детальний аналіз реалізації мовою C

У реалізації процедурною мовою C структура `CoupledChainC` містить сукупність динамічних масивів для збереження мас `masses`, позицій `pos`, швидкостей `vel` та прискорень `acc`. 

Функція `chain_create()` здійснює виділення пам'яті за допомогою `malloc()` та `calloc()`, після чого перевіряє коректність усіх виділених вказівників. Якщо будь-який із викликів повертає `NULL`, функція виконує коректне звільнення раніше виділеної пам'яті й повертає код помилки `NULL`, що виключає витоки пам'яті.

Внутрішня функція `compute_accelerations()` виконує обхід усіх мас ланцюжка від `0` до `N-1`. Для крайніх мас застосовується обробка граничних умов: якщо маса перебуває на лівому краї (`i == 0`), зсув лівого сусіда приймається рівним нулю (`left_pos = 0.0`), що відповідає нерухомій стіні. Аналогічно для правої межі (`i == N-1`) зсув правого сусіда приймається рівним нулю (`right_pos = 0.0`).

Функція `chain_total_energy()` обчислює суму кінетичної та потенціальної енергії. Кінетична енергія підраховується як `1/2 · m_i · v_i²` для кожної маси. Потенціальна енергія розраховується як сума потенціальних енергій деформації всіх пружин: `1/2 · K · (x_i − x_{i-1})²`, включаючи ліву стіну та останню пружину, що з'єднує масу `N-1` із правою стіною.

:::tabs
:::code proj-coupled-sim/c/coupled_sim.c
:::code proj-coupled-sim/cpp/coupled_sim.hpp
η(t) = Tᵀ · M · x(t)
```

Нижче наведено приклад виконавчої програми мовою C++, яка ініціалізує симуляцію двох зв'язаних мас, відхиляє першу масу `x1 = 1.0` і виводить у консоль значення координат, повної енергії та проекцій на нормальні моди.

```cpp
#include <iostream>
#include <iomanip>

int main() {
    constexpr double mass = 1.0;
    constexpr double spring_k = 4.0;
    constexpr double dt = 0.005;
    constexpr double total_time = 10.0;

    CoupledChainCPP sim(2, mass, spring_k, 0.0);
    sim.set_initial_displacement(0, 1.0); // Відхилення маси 1

    std::cout << std::fixed << std::setprecision(4);
    std::cout << "Час t\tx1\tx2\tМода q1\tМода q2\tПовна енергія E\n";
    std::cout << "---------------------------------------------------------\n";

    const size_t steps = static_cast<size_t>(total_time / dt);
    for (size_t step = 0; step <= steps; ++step) {
        if (step % 100 == 0) {
            auto pos = sim.positions();
            double q1 = pos[0] + pos[1]; // Синфазна мода
            double q2 = pos[0] - pos[1]; // Протифазна мода
            
            std::cout << step * dt << "\t" 
                      << pos[0] << "\t" 
                      << pos[1] << "\t" 
                      << q1 << "\t" 
                      << q2 << "\t" 
                      << sim.total_energy() << "\n";
        }
        sim.step(dt);
    }

    return 0;
}
```

Результати моделювання підтверджують два важливі фізичні факти:
1. Повна механічна енергія системи за відсутності демпфування зберігається з точністю до `10⁻⁶` протягом всього розрахунку завдяки симплектичним властивостям алгоритму Верле.
2. Синфазна та протифазна моди `q₁` та `q₂` коливаються як два абсолютно незалежні синусоїдальні осцилятори з частотами `ω₁ = √(k/m)` та `ω₂ = √((k + 2k_c)/m)`.

## 6. Практичні рекомендації щодо числової оптимізації

При чисельному симулюванні великих 2D та 3D систем зв'язаних осциляторів (наприклад, молекулярна динаміка у матеріалознавстві з мільйонами атомів) застосовують такі оптимізаційні підходи:

1. **Векторизація SIMD (AVX-512 / ARM Neon):** Оновлення координат і швидкостей у циклах є повністю незалежним для кожного елемента, що дозволяє процесору обробляти по 4–8 мас одночасно за один такт.
2. **Паралелізація OpenMP / CUDA:** Обчислення внутрішніх сил від сусідніх мас розпаралелюється між ядрами графічного процесора (GPU).
3. **Використання алгоритмів швидкого перетворення Фур'є (FFT):** Проектування часового ряду `x_i(t)` на спектральну область за допомогою FFT дозволяє миттєво знаходити всі власні частоти системи без трудомісткої матричної діагоналізації `O(N³)`.
