# ⚙️ Інженерний розрахунок загасання звуку за стандартом ISO 9613-1

Дана практична вставка присвячена програмній реалізації алгоритму розрахунку коефіцієнта атмосферного поглинання звуку `α` (вираженого у дБ/м та дБ/км) відповідно до міжнародного стандарту ISO 9613-1:1993, а також обчисленню загальних втрат рівнів звукового тиску (SPL) на довільних відстанях від джерела акустичного випромінювання.

## 1. Архітектурне проектування алгоритму

Інженерний модуль розрахунку атмосферного поглинання приймає чотири фізичні параметри навколишнього середовища:
1. `temperature_c` — температура повітря у градусах Цельсія (°C).
2. `pressure_kpa` — атмосферний тиск у кілопаскалях (кПа).
3. `relative_humidity_pct` — відносна вологість у відсотках (%).
4. `frequency_hz` — частота звукової хвилі у Гертцах (Гц).

Процес розрахунку розбито на чотири строго послідовні обчислювальні етапи:
1. **Обчислення вологості:** Розрахунок відносного тиску насиченої пари `p_sat` та молярної концентрації водяної пари `h`.
2. **Обчислення частот релаксації:** Обчислення частот релаксації для молекул кисню `f_r,O` та азоту `f_r,N` з урахуванням виявленого Кнудсеном каталітичного впливу водяної пари.
3. **Обчислення складових загасання:** Розрахунок трьох окремих дисипативних внесків (класичного термов'язкого Стокса–Кірхгофа, релаксації кисню `O₂` та релаксації азоту `N₂`).
4. **Акустична сума та дистанційні втрати:** Обчислення підсумкового значення `α` та розрахунок рівня звукового тиску (SPL) на відстані `r` з одночасним урахуванням геометричного сферичного розходження `20·log10(r/r0)` та атмосферного поглинання `α·r`.

```
           Параметри середовища: (T, p, hr, f)
                            │
                            ▼
              1. Концентрація вологи h(T, p, hr)
                            │
                            ▼
           2. Частоти релаксації f_r,O та f_r,N
                            │
                            ▼
        3. Складові α_cl, α_vib,O, α_vib,N (ISO 9613-1)
                            │
                            ▼
     4. Загасання: α (дБ/м) + 20·log10(r/r0) (геометрія)
```

## 3. Обробка даних датчиків та зчитування метеопараметрів

У реальних автономних акустичних системах (наприклад, станціях моніторингу шуму або комплексах акустичної розвідки) метеорологічні параметри зчитуються з цифрових датчиків середовища (наприклад, Bosch BME280 або Sensirion SHT31) по шині I2C / SPI.

Процес зчитування та підготовки даних включає три обов'язкові етапи:
1. **Низькочастотна фільтрація (Експоненціальне згладжування):** Щоб уникнути стрибків коефіцієнта поглинання `α` через шуми вимірювань датчиків, зчитані параметри проходять через цифровий фільтр першого порядку:

```
T_smooth[k] = (1 − β) · T_smooth[k−1] + β · T_sensor[k]
```

де `β ≈ 0.05..0.1` — коефіцієнт згладжування.

2. **Оцінка похибки вимірювань:** Похибка датчика температури у `±0.5 °C` або вологості у `±3%` створює варіацію розрахованого коефіцієнта поглинання `α` до `±1.5 дБ/км` на частоті 4 кГц. У критичних системах оцінюється інтервал невизначеності `[α_min, α_max]`.

3. **Інтегрування по неоднорідній атмосфері:** Для похилих траєкторій (наприклад, при локації авіаційних об'єктів) атмосфера розбивається на вертикальні шари завтовшки `Δz = 50..100 м`, для кожного з яких вираховується власне значення `α(z)` за відповідними значеними температури й тиску.

## 4. Інтеграція в аудіорушії та цифрову обробку сигналів (DSP)

У процесі створення акустично точних тривимірних аудіосимуляторів (наприклад, ігрових рушіїв Unreal Engine / Unity, авіаційних тренажерів або систем віртуальної реальності) атмосферне поглинання моделюється як мінімально-фазовий FIR або IIR цифровий фільтр.

### 4.1. Обчислення амплітудно-частотної характеристики (АЧХ) фільтра
Для заданої відстані від слухача `r` та коефіцієнта поглинання `α(f)` передавальна функція атмосфери за амплітудою визначається співвідношенням:

```
H_abs(f) = 10^(− α(f) · r / 20)
```

Ця коефіцієнтна характеристика визначає бажане загасання для кожної спектральної складової. Наприклад, якщо на частоті 8 кГц поглинання становить 68 дБ/км, а відстань до джерела звуку є `500 м`, то амплітудне ослаблення складе `34 дБ`, що відповідає коефіцієнту передачі `H_abs(8000) = 10^(−34 / 20) ≈ 0.0199`.

### 4.2. Синтез цифрового фільтра зваженої компенсації
Оскільки повне перезавантаження коефіцієнтів FIR-фільтра при безперервній зміні відстані джерела створює значне навантаження на ЦП, аудіорушії використовують паралельні банк-фільтри (наприклад, 1/3-октавні біквадратні IIR-фільтри) або інтерполяційну схему перемикання між 4 зурахованими FIR-шаблонами для різних відстаней.

```
Вхідний аудіопотік ---> [ Блок FFT ] ---> [ Множення на H_abs(f) ] ---> [ IFFT ] ---> Вихідний аудіопотік
```

Застосування алгоритму Overlap-Add (OLA) або Overlap-Save (OLS) дозволяє реалізувати спектральну фільтрацію без виникнення артифактів та клацань (clicks / pops) під час динамічної зміни метеоумов чи дистанції.

### 4.3. Октавний та третиноктавний розрахунок загасання
Для багатьох практичних інженерних розрахунків акустичного шуму (наприклад, розрахунку рівня шуму від аеропортів за нормами ICAO або оцінки шуму вітроелектростанцій) джерело звуку вимірюється не на окремих монохроматичних частотах, а у смугах 1/1 та 1/3 октави.

Для обчислення коефіцієнта загасання у 1/3-октавній смузі із центральною частотою `f_c` стандарт ISO 9613-1 регламентує використання коефіцієнта поглинання на центральній частоті смуги `α(f_c)`, коли ширина смуги є невеликою. Однак на високих частотах (понад 4 кГц), де `α(f)` стрімко зростає у межах однієї смуги, обчислюють інтегральне середоквадратичне значення поглинання по нижній `f_lower = f_c / 2^(1/6)` та верхній `f_upper = f_c · 2^(1/6)` межах смуги:

```
α_band(f_c) = − (1 / r) · 10 · log10 [ (1 / Δf) · ∫ [f_lower..f_upper] 10^(− α(f)·r / 10) df ]
```

Цей розрахунок гарантує, що при моделюванні спектрального шуму високі частоти на межах смуг не створюють штучних викривлень акустичної потужності.

## 5. Моделювання акустичних променів у неоднорідній атмосфері

При поширенні звуку на великі відстані (понад 1 км) реальна атмосфера не є однорідною. Температура, вологість та вітер змінюються за висотою. Для врахування цих змін застосовують чисельний променевий трасування (Ray Tracing).

### 5.1. Диференціальні рівняння променя
Траєкторія звукового променя `r(s)` у неоднорідній атмосфері з градієнтом температури `T(z)` описується рівнянням геометричної акустики Ейконала. Швидкість звуку залежить від висоти `c(z) = 331.3 · √(1 + z / 273.15)`. Промінь згинається у бік шарів із меншою швидкістю звуку (закон Снеліуса у шаруватому середовищі):

```
cos(θ(z)) / c(z) = const
```

де `θ(z)` — кут нахилу променя до горизонталі. При нічній інверсії температури промені згинаються до землі, утворюючи інверсійний хвилевод.

### 5.2. Чисельне інтегрування загасання вздовж променя
Під час чисельного інтегрування траєкторії променя крок за кроком `Δs` накопичене поглинання вираховується як:

```
Total_Attenuation_dB = ∑ α(f, T(z_i), p(z_i), h_r(z_i)) · Δs_i
```

Це дозволяє точно моделювати чутність літаків, вибухів та промислових об'єктів з урахуванням висотного профілю атмосфери.

## 6. Обчислювальна складність та апаратна оптимізація

При реалізації розрахунку поглинання за ISO 9613-1 на вбудованих платформах без апаратного блоку обчислень із плаваючою комою (FPU), таких як ARM Cortex-M0/M3 або 8-бітні мікроконтролери AVR, виклики трансендентних функцій `pow()` та `exp()` створюють високе обчислювальне навантаження.

### 6.1. Аналіз профілювання обчислювальних циклів
Профілювання виконання базового алгоритму на 32-бітному мікроконтролері ARM Cortex-M4F (з FPU, частота 168 МГц) дає такі часові характеристики:
- Повний розрахунок вологості й частот релаксації `f_r,O`, `f_r,N`: **~320 тактів процесора** (~1.9 мкс).
- Розрахунок поглинання `α` для однієї частоти: **~180 тактів процесора** (~1.1 мкс).
- Розрахунок спектра з 31 третиноктавної смуги: **~2100 тактів процесора** (~12.5 мкс).

На мікроконтролерах без FPU (ARM Cortex-M3) час обчислення зростає приблизно в 8–10 разів через програмну емуляцію операцій із плаваючою комою (`soft-float`).

### 6.2. Оптимізація із застосуванням фіксованої коми (Fixed-Point Arithmetic)
Для платформ без FPU формули релаксації переводять у формат з фіксованою комою `Q16.16` або `Q8.24`. Таблиці експонент `exp(-x)` підміняють аппроксимацією Паде або квадратичною інтерполяцією за 64 вузлами, що зменшує час обчислення в 6 разів і дозволяє виконувати розрахунок у мікросекундних таймерах переривань RTOS.

## 7. Калібрування та польові акустичні вимірювання

Для верифікації програмного розрахунку на реальних вимірювальних трасах застосовують акустичні калібратори та вимірювальні мікрофони 1-го класу (за стандартом IEC 61672-1).

Процедура польового калібрування включає:
1. **Вимірювання фонового акустичного шуму довкілля:** Визначення порогу чутливості мікрофона у відсутності тестового сигналу.
2. **Випромінювання тестового широкосмугового акустичного сигналу (рожевий шум або свип-сигнал):** Випромінювання сигналу з каліброваного випромінювача з відомою звуковою потужністю `L_w`.
3. **Вимірювання спектра на відстанях 10 м та 500 м:** Розрахунок різниці рівнів тиску `ΔL(f) = L_p(10m) − L_p(500m)`.
4. **Віднімання геометричного розходження:** `Atten_exp(f) = ΔL(f) − 20 * log10(500 / 10)`.

Порівняння отриманих експериментальних втрат `Atten_exp(f)` із теоретичними значеннями `α_ISO(f) * 490m` показує розбіжність не більше `±0.8 дБ` у діапазоні 500 Гц – 4 кГц при стабільних метеоумовах.

## 8. Практичні інженерні пастки та крайові випадки

1. **Екстраполяція за межі температур.** Формули ISO 9613-1 розроблені для температур від -20 °C до +50 °C. Застосування алгоритму для кріогенних або високотемпературних умов створює значну похибку через зміну фізичних констант релаксації.
2. **Нульова вологість (`h_r → 0`).** При розрахунках абсолютно сухого повітря (`h_r = 0`) частота релаксації азоту спадає до `f_r,N ≈ 9 Гц`, а кисню до `f_r,O ≈ 24 Гц`. Це зміщує піки поглинання в інфразвукову область, через що поглинання на чутних частотах несподівано зменшується порівняно з вологим повітрям.
3. **Геометричні втрати проти атмосферних.** На малих відстанях (до 50 м) переважає геометричне сферичне розходження (втрата 6 дБ за кожне подвоєння відстані). На великих відстанях (понад 500 м) і високих частотах (понад 2 кГц) поглинання повітря починає перевищувати геометричні втрати й стає головним чинником деградації акустичного сигналу.
