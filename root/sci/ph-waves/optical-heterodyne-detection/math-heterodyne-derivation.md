# 🧮 Виведення рівнянь оптичного гетеродина, квантової межі та теореми Зігмана

Ця математична вставка містить суворий аналітичний вивід рівнянь фотоструму биття, спектральної щільності шумів, коефіцієнта сигнал/шум у квантовій межі, матричний вивід балансного детектування, просторове інтегрування гаусових променів та виведення просторового інтеграла Зігмана для кутової розбудови хвильових фронтів.

### 1. Електромагнітні поля, вектор Пойнтінга та виведення фотоструму биття

Світлова хвиля описується векторами напруженості електричного поля `E(r,t)` та магнітного поля `H(r,t)`. Перенесення енергії хвилею у середовищі з показником заломлення `n` задається вектором Пойнтінга `S = E × H`. Модуль середнього за часом вектора Пойнтінга визначає оптичну інтенсивність випромінювання `I` (Вт/м²):

```
I = ⟨ |S| ⟩ = ½ · n · ε₀ · c · |E₀|²
```

де `ε₀ = 8.854×10⁻¹² Ф/м` — електрична стала, `c = 2.998×10⁸ м/с` — швидкість світла у вакуумі, `E₀` — амплітуда електричного поля.

Розглянемо дві монохроматичні коаксіальні світлові хвилі з однаковим напрямком поляризації:

1. **Сигнальна хвиля** (*signal wave*):

```
E⛛(r, t) = E₀⛛(r) · cos(ω⛛ · t + φ⛛(t))
```

2. **Опорна хвиля гетеродина** (*local oscillator wave*):

```
Eₗ(r, t) = E₀ₗ(r) · cos(ωₗ · t + φₗ(t))
```

де `ω⛛ = 2π·f⛛` та `ωₗ = 2π·f⛛` — колові оптичні частоти (порядок `10¹⁵ рад/с`), `φ⛛` та `φₗ` — фази хвиль.

Обидва світлові пучки спрямовуються на фотодетектор. Загальна напруженість електричного поля у будь-якій точці фоточутливої поверхні дорівнює сумі полів:

```
E_total(r, t) = E⛛(r, t) + Eₗ(r, t)
```

Закон квантового фотоефекту описує генерацію фотоструму `i(t)` внаслідок поглинання фотонів та народження носіїв заряду (електрон-діркових пар). Мгновенний фотострум пропорційний інтегралу інтенсивності по площі фотодетектора `A`:

```
i(t) = (e · η / h · ν) · ∬_A I_total(r, t) dA
```

де `e = 1.602×10⁻¹⁹ Кл` — заряд електрона, `η` — квантова ефективність (частка фотонів, що створюють фотоелектрони), `h = 6.626×10⁻³⁴ Дж·с` — стала Планка, `ν` — середня оптична частота фотонів.

Введемо спектральну чутливість фотодіода `R_resp = (e · η) / (h · ν)` (А/Вт). Загальна потужність світла на детекторі дорівнює:

```
P_total(t) = ∬_A ½ · n · ε₀ · c · (E⛛(r,t) + Eₗ(r,t))² dA
```

Розкриємо квадрат суми електричних полів у кожній точці поверхні:

```
(E⛛(r,t) + Eₗ(r,t))² = E⛛²(r,t) + Eₗ²(r,t) + 2 · E⛛(r,t) · Eₗ(r,t)
```

Застосуємо тригонометричні тотожності квадрантів та добутків косинусів:

```
E⛛²(t) = ½ · E₀⛛² + ½ · E₀⛛² · cos(2ω⛛·t + 2φ⛛)           [квадрат сигнальної хвилі]
Eₗ²(t) = ½ · E₀ₗ² + ½ · E₀ₗ² · cos(2ωₗ·t + 2φₗ)           [квадрат хвилі гетеродина]
2·E⛛·Eₗ = E₀⛛·E₀ₗ · cos((ω⛛ - ω◗)t + (φ⛛ - φ◗))
        + E₀⛛·E₀◗ · cos((ω⛛ + ω◗)t + (φ⛛ + φ◗))          [перехресний інтерференційний член]
```

Напівпровідниковий фотодіод має смугу частотного відгуку `B_det` (порядок `10⁹...10¹⁰ Гц`), яка на чотири порядки менша за оптичні частоти `2ω⛛`, `2ω◗` та `ω⛛ + ω◗` (~400 ТГц). Усі високочастотні коливання усереднюються інерцією фотодетектора до нуля:

```
⟨ cos(2ω⛛·t) ⟩ = 0,   ⟨ cos(2ω◗·t) ⟩ = 0,   ⟨ cos((ω⛛ + ω◗)t) ⟩ = 0
```

У результаті фотострум спрощується до суми трьох компонент:

```
i(t) = i_DC_signal + i_DC_LO + i_IF(t)
```

де:
- `i_DC_signal = R_resp · P⛛` — постійний фотострум сигналу;
- `i_DC_LO = R_resp · Pₗ` — постійний фотострум гетеродина;
- `i_IF(t)` — змінний фотострум биття на проміжній частоті `ω_IF = |ω⛛ - ω◗| = 2π·f_IF`:

```
i_IF(t) = 2 · R_resp · ∬_A ½ n ε₀ c E₀⛛(r) E₀ₗ(r) dA · cos(ω_IF · t + Δφ(t))
```

Вважаючи поперечні профілі хвиль узгодженими, інтеграл перетворюється на геометричне середнє оптичних потужностей:

```
i_IF(t) = 2 · R_resp · √(P⛛ · Pₗ) · cos(ω_IF · t + Δφ(t))
```

де `Δφ(t) = φ⛛(t) - φ◗(t)` — фазовий зсув між лазерними променями.

Пікова амплітуда струму биття дорівнює:

```
I_IF_peak = 2 · R_resp · √(P⛛ · Pₗ)
```

Середньоквадратична (RMS) амплітуда змінного фотоструму становить:

```
I_IF_rms = I_IF_peak / √2 = √2 · R_resp · √(P⛛ · Pₗ)
```

Електрична потужність сигналу биття, що виділяється на навантаженні `R_load`, дорівнює:

```
P_signal = I_IF_rms² · R_load = 2 · R_resp² · P⛛ · Pₗ · R_load
```

### 2. Повний математичний розрахунок шумів та доведення квантової межі

У реальному гетеродинному фотоприймачі діють чотири незалежні джерела електричних шумів.

#### 1. Дробовий шум (Shot noise)

Дробовий шум виникає через квантову флуктуацію кількості поглинутих фотонів та згенерованих фотоелектронів. Відповідно до теореми Шотткі, спектральна щільність потужності струмового дробового шуму (А²/Гц) дорівнює:

```
S_shot(f) = 2 · e · I_total_DC
```

Оскільки потужність гетеродина значно перевищує потужність сигналу (`Pₗ >> P⛛`), сумарний постійний струм дорівнює `I_total_DC ≈ I_LO = R_resp · Pₗ`. Середній квадрат струму дробового шуму у смузі `B` становить:

```
⟨i_shot²⟩ = 2 · e · R_resp · Pₗ · B
```

#### 2. Тепловий шум (Thermal noise)

Тепловий шум (найменується також шумом Джонсона-Найквіста) виникає внаслідок хаотичного теплового руху носіїв заряду в опорі навантаження `R_load` при температурі `T`. Спектральна щільність теплового струмового шуму становить:

```
S_thermal(f) = (4 · k_B · T) / R_load
```

де `k_B = 1.380649×10⁻²³ Дж/К` — стала Больцмана. Середній квадрат струму теплового шуму у смузі `B` дорівнює:

```
⟨i_thermal²⟩ = (4 · k_B · T / R_load) · B
```

#### 3. Відносний шум інтенсивності гетеродина (RIN)

Шум RIN описує флуктуації потужності випромінювання лазера гетеродина навколо середнього значення `⟨(δPₗ)²⟩ = RIN · Pₗ² · B`. Спектральна щільність шуму інтенсивності дорівнює:

```
S_RIN(f) = RIN · I_LO² = RIN · R_resp² · Pₗ²
```

Середній квадрат струму шуму RIN у смузі `B` становить:

```
⟨i_RIN²⟩ = RIN · R_resp² · Pₗ² · B
```

#### 4. Власний шум трансімпедансного підсилювача (Amplifier noise)

Шум електронного підсилювача описується еквівалентним струмовим шумом `i_amp` (А/√Гц) та напруговим шумом `e_amp` (В/√Гц):

```
⟨i_amplifier²⟩ = ( i_amp² + (e_amp / R_load)² ) · B
```

#### Розрахунок коефіцієнта сигнал/шум (SNR)

Загальний коефіцієнт сигнал/шум (SNR) визначається відношенням електричної потужності сигналу проміжної частоти до сумарної потужності всіх шумів:

```
SNR = ⟨i_IF_rms²⟩ / ( ⟨i_shot²⟩ + ⟨i_thermal²⟩ + ⟨i_RIN²⟩ + ⟨i_amplifier²⟩ )
```

Підставимо всі вирази у формулу:

```
SNR = (2 · R_resp² · P⛛ · Pₗ) / [ (2·e·R_resp·Pₗ + (4·k_B·T / R_load) + RIN·R_resp²·Pₗ² + i_amp_total²) · B ]
```

Проаналізуємо поведінку SNR при збільшенні потужності гетеродина `Pₗ`:

1. **Область теплового шуму (`Pₗ < P_threshold`)**: при малих потужностях гетеродина знаменник визначається сталим тепловим шумом `4·k_B·T / R_load`. Оскільки чисельник зростає лінійно з `Pₗ`, значення SNR монотонно збільшується пропорційно потужності гетеродина.
2. **Квантова область дробового шуму (`P_threshold << Pₗ << P_RIN_limit`)**: при збільшенні `Pₗ` до кількох міліват дробовий шум `2·e·R_resp·Pₗ` починає повністю домінувати над тепловим шумом та шумами підсилювача:

```
2 · e · R_resp · Pₗ >> (4·k_B·T / R_load) + i_amp_total²
```

У цій області чисельник і знаменник містять множник `Pₗ` у першому ступені, який скорочується:

```
SNR_shot = (2 · R_resp² · P⛛ · Pₗ) / (2 · e · R_resp · Pₗ · B) = (R_resp · P⛛) / (e · B)
```

Підставимо спектральну чутливість `R_resp = (η · e) / (h · ν)`:

```
SNR_shot = ( (η · e / h · ν) · P⛛ ) / (e · B) = (η · P⛛) / (h · ν · B)
```

Враховуючи, що кількість фотонів сигнального поля `N_photons`, які прибувають за інтервал інтегрування `τ = 1 / B`, дорівнює `N_photons = P⛛ / (h · ν · B)`, отримуємо фундаментальну **квантову межу гетеродинного детектування**:

```
SNR_shot = η · N_photons
```

Цей красивий математичний висновок доводить, що за умови домінування дробового шуму гетеродина коефіцієнт сигнал/шум виражається просто як добуток квантової ефективності фотодіода `η` на кількість сигнальних фотонів `N_photons`. Для ідеального детектора з `η = 1.0` SNR строго дорівнює кількості фотонів сигналу.

### 3. Матричний аналіз балансного змішувача 2×2 та пригнічення RIN

Розглянемо симетричний 50:50 волоконний куплер (або призму-світлодільник) з двома вхідними портами (сигнал `E⛛` та гетеродин `Eₗ`) і двома вихідними портами (`E_out1` та `E_out2`).

Матричне рівняння зв'язку комплексних амплітуд оптичного поля через унітарну матрицю розсіяння `S` має вигляд:

```
[ E_out1 ] = [ s₁₁  s₁₂ ] · [ E⛛ ]
[ E_out2 ]   [ s₂₁  s₂₂ ]   [ Eₗ ]
```

Для ідеального безвтратного 50:50 світлодільника з фазовим зсувом `π/2` при відбитті матриця розсіяння задається виразом:

```
S = 1/√2 · [ 1    i ]
           [ i    1 ]
```

де `i = √(-1)` — уявна одиниця, що відповідає фазовому зсуву на 90°.

Обчислимо комплексно-спряжені амплітуди полів на вихідних портах:

```
E_out1(t) = 1/√2 · ( E⛛(t) + i · Eₗ(t) )
E_out2(t) = 1/√2 · ( i · E⛛(t) + Eₗ(t) )
```

Знайдемо інтенсивності світла на виході обох портів `I_out = |E_out|² = E_out · E_out*`:

```
|E_out1|² = ½ · (E⛛ + i·Eₗ) · (E⛛* - i·Eₗ*)                                [квадрат модуля комплексної напруженості]
          = ½ · ( |E⛛|² + |Eₗ|² + i · (Eₗ·E⛛* - E⛛·Eₗ*) )                   [розкриття дужок із врахуванням i·(-i) = 1]
          = ½ · ( |E⛛|² + |Eₗ|² + 2 · |E⛛||Eₗ| · sin(ω_IF·t + Δφ) )          [зведення комплексно-спряженої різниці до синуса]
```

 Аналогічно для другого порту:

```
|E_out2|² = ½ · (i·E⛛ + Eₗ) · (-i·E⛛* + Eₗ*)                                [квадрат модуля комплексної напруженості]
          = ½ · ( |E⛛|² + |Eₗ|² - i · (Eₗ·E⛛* - E⛛·Eₗ*) )                   [розкриття дужок із врахуванням i·(-i) = 1]
          = ½ · ( |E⛛|² + |Eₗ|² - 2 · |E⛛||Eₗ| · sin(ω_IF·t + Δφ) )          [зведення комплексно-спряженої різниці до синуса]
```

Зверніть увагу на знак перед інтерференційним членом: у першому порту він має знак `+`, а у другому — знак `-`. Інтерференційні члени перебувають у суворій протифазі (`180°`).

Обчислимо фотоструми двох ідентичних фотодіодів PD1 та PD2:

```
I₁(t) = ½ · R_resp · [ P⛛ + Pₗ(t) + 2·√(P⛛Pₗ) · sin(ω_IF·t + Δφ) ]
I₂(t) = ½ · R_resp · [ P⛛ + Pₗ(t) - 2·√(P⛛Pₗ) · sin(ω_IF·t + Δφ) ]
```

Врахуємо, що потужність гетеродина містить флуктуації інтенсивності `Pₗ(t) = P̄ₗ + δPₗ(t)`.

При відніманні струмів у балансному вузлі `I_bal(t) = I₁(t) - I₂(t)`:

```
I_bal(t) = ½ · R_resp · [ (P⛛ + P̄ₗ + δPₗ(t) + 2·√(P⛛Pₗ)·sin(...)) 
                        - (P⛛ + P̄ₗ + δPₗ(t) - 2·√(P⛛Pₗ)·sin(...)) ]
```

Додавання та віднімання компонент дає:

```
I_bal(t) = 2 · R_resp · √(P⛛ · Pₗ) · sin(ω_IF · t + Δφ(t))
```

Результати балансного віднімання:
1. Постійні складові потужності `P⛛` та `P̄ₗ` повністю взаємно знищуються: `P̄ₗ - P̄ₗ = 0`.
2. Шум інтенсивності гетеродина `δPₗ(t)` повністю взаємно знищується: `δPₗ(t) - δPₗ(t) = 0`.
3. Корисний змінний фотострум биття подвоюється: `2·√(P⛛Pₗ) - (-2·√(P⛛Pₗ)) = 4·√(P⛛Pₗ) · ½ = 2·√(P⛛Pₗ)`.

Матричний вивід доводить, що балансне детектування є математично ідеальним способом пригнічення шуму RIN та постійного зсуву струму.

### 4. Просторовий інтеграл гетеродинного змішування Гаусових променів

У реальних оптичних та волоконних системах лазерні пучки мають **гаусов профіль інтенсивності** (основна мода `TEM₀₀`).

Розподіл амплітуди електричного поля гаусового променя з перетяжкою радіуса `w₀` дорівнює:

```
E₀(r) = E_zero · exp( - r² / w₀² )
```

Обчислимо просторовий інтеграл гетеродинного змішування двох гаусових променів із радіусами перетяжок `w_s` (сигнал) та `w_LO` (гетеродин), що падають коаксіально на поверхню детектора:

```
γ_spatial = ∬_A E₀⛛(r) · E₀ₗ(r) r dr dθ / √( ∬_A E₀⛛² r dr dθ · ∬_A E₀ₗ² r dr dθ )
```

Підставимо гаусові експоненти:

```
γ_spatial = ( ∫₀^∞ exp( - r² · (1/w_s² + 1/w_LO²) ) r dr ) / √( (∫₀^∞ exp(-2r²/w_s²) r dr) · (∫₀^∞ exp(-2r²/w_LO²) r dr) )
```

Використовуючи стандартний табличний інтеграл `∫₀^∞ exp(-a · r²) r dr = 1 / (2a)`:

1. Чисельник:

```
∫₀^∞ exp( - r² · (w_s² + w_LO²) / (w_s² · w_LO²) ) r dr = ½ · (w_s² · w_LO²) / (w_s² + w_LO²)
```

2. Знаменник:

```
√[ (½ · w_s² / 2) · (½ · w_LO² / 2) ] = √[ (w_s² · w_LO²) / 16 ] = ¼ · w_s · w_LO
```

Поділивши чисельник на знаменник:

```
γ_spatial = [ ½ · (w_s² · w_LO²) / (w_s² + w_LO²) ] / [ ¼ · w_s · w_LO ]
          = (2 · w_s · w_LO) / (w_s² + w_LO²)
```

Аналіз отриманого коефіцієнта просторового збігу `γ_spatial`:
- При однаковій ширині променів (`w_s = w_LO`): `γ_spatial = (2 · w_s²) / (2 · w_s²) = 1.0` (100% ефективність змішування).
- Якщо один з променів удвічі ширший за інший (`w_LO = 2 · w_s`): `γ_spatial = (2 · w_s · 2w_s) / (w_s² + 4w_s²) = 4 / 5 = 0.8` (втрата 20% ефективності змішування).

Ця формула задає правило розрахунку оптичних узгоджувальних лінз у гетеродинному приймачі: розміри плям гетеродинного та сигнального лазерів на поверхні фотодіода повинні бути максимально близькими.

### 5. Доведення Антенної теореми Зігмана через перетворення Фур'є

Розглянемо оптичне гетеродинне детектування у найзагальнішому тривимірному випадку.

Нехай поля сигналу `E⛛(x,y)` та гетеродина `Eₗ(x,y)` задані в апертурній площині фотодетектора. Відповідно до оптичної теореми Парсеваля, просторові когерентні властивості поля у дальній зоні (або у фокальній площині лінзи) зв'язані з апертурою двовимірним перетворенням Фур'є:

```
Ẽ(k_x, k_y) = ∬_A E(x, y) · exp( -i · (k_x · x + k_y · y) ) dx dy
```

де `k_x = k · sin θ_x`, `k_y = k · sin θ_y` — поперечні компоненти хвильового вектора.

Ефективна площа апертури детектора `A_det` виражається через просторовий інтеграл інтенсивності:

```
A_det = ( | ∬_A Eₗ(x,y) dx dy |² ) / ( ∬_A |Eₗ(x,y)|² dx dy )
```

Прийнятний тілесний кут поля зору `Ω_fov` визначається інтегралом за кутовими просторовими частотами у дальній зоні:

```
Ω_fov = ∬ ( |Ẽₗ(k_x, k_y)|² / |Ẽₗ(0,0)|² ) dθ_x dθ_y = (λ² / A_det)
```

Перемноживши ефективну площу апертури `A_det` на тілесний кут прийому `Ω_fov`:

```
A_det · Ω_fov = A_det · (λ² / A_det) = λ²
```

Отримано строге математичне доведення **антенної теореми Зігмана**:

```
A_det · Ω_fov = λ²
```

Фізичний зміст теореми Зігмана: оптичний гетеродинний приймач є незмінно одномодовим фотонним пристроєм. Добуток його ефективної вхідної площі на тілесний кут поля зору фундаментально обмежений квадратом довжини хвилі світла `λ²`. Усі спроби розширити кут огляду когерентного лідара чи томографа неминуче призводять до зменшення ефективної апертури збору світла.
