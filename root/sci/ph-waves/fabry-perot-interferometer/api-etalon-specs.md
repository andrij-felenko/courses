# 📋 Технічні параметри та інженерний розрахунок еталонів Фабрі — Перо

Цей технічний довідник містить інженерні специфікації, формули розрахунку допусків, аналіз крайових випадків та параметри вибору оптичних еталонів Фабрі — Перо для застосування у спектроскопії надвисокої роздільності, лазерному будівництві, волоконно-оптичних мережах зв'язку та космічних вимірювальних приладах.

---

### 1. Конструктивні типи еталонів Фабрі — Перо

За способом фіксації геометричного проміжку оптичні еталони поділяються на три основні інженерні категорії:

1. **Суцільний (монолітний) еталон (*Solid Etalon*)**:
   - Являє собою плоскопаралельну пластину з прозорого диелектрика (кварцеве скло `SiO₂`, сапфір `Al₂O₃`, фторид кальцію `CaF₂`, монокристалічний кремній `Si`), на обидві поверхні якої напилено напівпрозорі високовідбивальні покриття.
   - *Фізичний механізм*: Проміжок заповнений твердим диелектриком із показником заломлення `n > 1`. Геометрична товщина `d` виготовляється із точністю до кількох нанометрів методом прецизійного оптичного полірування.
   - *Переваги*: Виняткова механічна міцність, абсолютна монолітність, відсутність потреби у первинному чи потокувому юстуванні, стійкість до сильних вібрацій і ударних навантажень.
   - *Недоліки*: Чутливість до температурних коливань через термічне розширення матеріалу підкладки `α` та термооптичну залежність показника заломлення `dn / dT`.

2. **Повітряний еталон з прецизійними проставками (*Air-Spaced Etalon*)**:
   - Складається з двох окремих оптичних пластин (підкладок), розділених прецизійним кільцем або трипошковими інварними/церодюровими розпірками (*spacers*) з нульовим коефіцієнтом термічного розширення.
   - *Фізичний механізм*: Внутрішній проміжок заповнений повітрям або вакуумований (`n = 1.0`). Оптичний шлях визначається висотою точних розпірок.
   - *Переваги*: Відсутність хроматичної дисперсії внутрішнього середовища, висока променева міцність (відсутність об'ємного поглинання), можливість термо- або бароперенастроювання резонансної частоти шляхом зміни тиску газу.
   - *Недоліки*: Чутливість до пилу та механічних деформацій корпусу, потреба у прецизійній юстувальній оправі.

3. **Сканувальний п'єзоелектричний еталон (*Scanning Tunable Etalon*)**:
   - Повітряний ресонатор, у якому товщина проміжку `d` динамічно змінюється за допомогою п'єзокерамічних трубчастих актуаторів (PZT), закріплених на одній із пластин.
   - *Переваги*: Плавне електричне переналаштування центральної частоти пропускання у межах усієї області вільної дисперсії (FSR) із частотою оновлення до кількох кілогерц.

### 3. Детальний розрахунок бюджету різкості та геометричних допусків

Теоретична різкість `F_R`, що визначається лише коефіцієнтом відбиття дзеркал `R`, на практиці завжди обмежується конструктивними недосконалостями еталона. **Ефективна різкість `F_eff`** визначається комбінацією чотирьох незалежних фізичних чинників:

```
1 / (F_eff)² = 1 / (F_R)² + 1 / (F_D)² + 1 / (F_P)² + 1 / (F_θ)²
```

#### 3.1. Різкість відбиття (`F_R`)
Визначається коефіцієнтом відбиття високовідбивальних покриттів:

```
F_R = (π · √R) / (1 - R)
```

#### 3.2. Різкість від дефектів площинності поверхонь (`F_D`)
Якщо поверхня дзеркала має локальні сферичні або випадкові відхилення від ідеальної площини величиною `δd = λ / N` (де `N` — дільник площинності хвильового фронту, наприклад `N = 100` для `λ / 100`):

```
F_D = N / 2
```

*Приклад розрахунку*: Для дзеркал із площинністю `λ / 100` обмеження різкості становить `F_D = 50`. Навіть якщо напилити дзеркала з `R = 0.99` (`F_R = 312`), ефективна різкість не перевищить `F_eff ≈ 49`. Це означає, що напилювати покриття з `R > 0.95` на пластини з площинністю гіршою за `λ / 50` є недоцільним.

#### 3.3. Різкість від непаралельності граней (`F_P`)
Якщо поверхні дзеркал утворені клином із кутом `α` (у радіанах), варіація товщини по світловому апертурному діаметру `D` дорівнює `δd_par = D · α`:

```
F_P = λ / (2 · n · D · α)
```

Для забезпечення різкості `F_P ≥ 100` на апертурі `D = 25 мм` при `λ = 633 нм` кут рассиметризації не повинен перевищувати `α ≤ 1.26 × 10⁻⁷ рад` (близько `0.026` кутових секунд).

#### 3.4. Різкість від кутової розбіжності пучка (`F_θ`)
При освітленні еталона пучком із конусним кутом розбіжності `Ω` (в стерадіанах):

```
F_θ = (2 · π) / (m · Ω)
```

де `m` — порядок інтерференції (`m = 2 · n · d / λ`).

### 4. Термостабільність та температурне дрейфування частоти

Температурна зміна резонансної частоти `ν₀` суцільного або повітряного еталона визначається похідною:

```
dν / dT = -ν₀ · [ α + (1 / n) · (dn / dT) ]
```

де:
- `α = (1 / L) · (dL / dT)` — лінійний коефіцієнт термічного розширення (КТР) проставки або підкладки,
- `dn / dT` — термооптичний коефіцієнт середовища всередині ресонатора.

Для суцільного еталона з плавленого кварцу (`α = 0.55 × 10⁻⁶ K⁻¹`, `dn / dT = 10 × 10⁻⁶ K⁻¹` при `1550 нм`):
```
dν / dT ≈ -193.4 ТГц · [ 0.55e-6 + (1 / 1.444) · 10e-6 ] ≈ -1.44 ГГц/K
```
Це означає, що зміна температури всього на `0.1 K` зміщує пік пропускання на `144 МГц`, що перевищує напівширину піку високодобротного еталона. Для компенсації цього дрейфу суцільні еталони вміщують у прецизійні термостати з точністю стабілізації `±0.001 K`.

Для повітряних еталонів на проставках із **Церодюру (Zerodur)** або **ULE (Ultra-Low Expansion glass)** КТР становить `|α| < 10⁻⁸ K⁻¹`, а для повітря `dn / dT ≈ -0.9 × 10⁻⁶ K⁻¹`, що забезпечує природну температурну стабільність на два порядки вищу.

### 5. Покриття, променева міцність та оптичні матеріали

Вибір покриттів та матеріалів підкладки визначає довговічність та робочий діапазон еталона:

1. **Багатошарові диелектричні покриття**:
   Сформовані іонно-променевим напиленням (IBSD). Володіють порогом променевого пошкодження (Laser Induced Damage Threshold, LIDT) понад `10 Дж/см²` у наносекундному імпульсному режимі та `10 МВт/см²` у неперервному режимі.
2. **Захищені металеві покриття (срібло, золото, алюміній)**:
   Застосовуються для надширокосмугових еталонів, де диелектричні покриття не працюють. Мають суттєво нижчий поріг пошкодження (`LIDT < 0.5 Дж/см²`) та внутрішні втрати на поглинання `1...3%`.
3. **Оптична чистість матеріалів підкладок**:
   - *Плавлений кварц Suprasil 300*: відсутність поглинання ОН-груп у діапазоні `1380 нм` та `2200 нм`.
   - *Сапфір (Al₂O₃)*: екстремальна механічна твердість та теплопровідність для високопотужних лазерів.

### 6. Інженерний покроковий алгоритм вибору еталона

При проектуванні оптичного спектрометра або оптичного фільтра вибір еталона здійснюється у такій послідовності:

1. **Визначення FSR**: За необхідною смугою пропускання без перекриття порядків вибрати товщину `d`:
   ```
   d = c / (2 · n · FSR_ν)
   ```
2. **Розрахунок необхідної різкості `F`**: За заданою спектральною роздільною здатністю `δλ`:
   ```
   F = FSR_λ / δλ
   ```
3. **Вибір коефіцієнта відбиття `R`**: Визначити початковий `R` за формулою `F_R = π · √R / (1 - R)`.
4. **Визначення вимог до полірування**: Підібрати допуск площинності `N = 2 · F`.
5. **Розрахунок температурного бюджету**: Обчислити максимально допустиме відхилення температури `ΔT_max = FWHM_ν / |dν / dT|`.
