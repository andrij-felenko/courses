# 🧮 Виведення рівняння маятника, еліптичні інтеграли та фазовий портрет

Ця вставка містить суворий математичний апарат теорії маятника: виведення нелінійного диференціального рівняння руху з рівнянь Ейлера-Лагранжа, детальний розрахунок точного періоду коливань довільної амплітуди через повні еліптичні інтеграли першого роду, степеневі розклади та глибокий аналіз фазового простору з траєкторією сепаратриси.

### 1. Виведення рівняння руху з аналітичної механіки Лагранжа

Для класичного математичного маятника масою `m` на жорсткому важелі чи нерозтяжній нитці довжини `L` у постійному полі тяжіння з прискоренням `g` єдиним ступенем вільності є кут відхилення від нижньої вертикалі `θ(t)`. Вибір кутової координати замість декартових `(x, y)` автоматично враховує геометричний зв'язок `x² + y² = L²`, що позбавляє нас від потреби шукати невідому силу натягу нитки `T` на етапі складання рівнянь руху.

Перейдемо від декартових координат до кутової координати `θ`:

```
x = L · sin(θ)
y = −L · cos(θ)
```

Диференціюючи за часом `t` (позначаючи часову похідну `d/dt` крапкою над величиною), отримуємо компоненти вектора швидкості:

```
ẋ = L · θ̇ · cos(θ)
ẏ = L · θ̇ · sin(θ)
```

Кінетична енергія матеріальної точки `T_kin` визначається квадратом повної швидкості:

```
T_kin = (1/2) · m · (ẋ² + ẏ²)
= (1/2) · m · L² · θ̇² · (cos²(θ) + sin²(θ))      [використано тотожність sin²θ + cos²θ = 1]
= (1/2) · m · L² · θ̇²
```

Потенціальна енергія `V` відраховується від найнижчої точки рівноваги `y = −L`, де `V = 0`:

```
V = m · g · (y − (−L))
= m · g · L · (1 − cos(θ))
```

Функція Лагранжа (лагранжіан) `L_lagr = T_kin − V` підсумовує енергетичний стан осцилятора:

```
L_lagr(θ, θ̇) = (1/2) · m · L² · θ̇² − m · g · L · (1 − cos(θ))
```

Рівняння Ейлера-Лагранжа для узагальненої координати `θ` встановлює динамічний баланс узагальненого імпульсу та узагальненої сили:

```
d/dt (∂L_lagr / ∂θ̇) − ∂L_lagr / ∂θ = 0
```

Обчислимо частинні похідні лагранжіана:

```
∂L_lagr / ∂θ̇ = m · L² · θ̇                    [узагальнений кутовий імпульс P_θ]
d/dt (∂L_lagr / ∂θ̇) = m · L² · θ̈              [часова похідна кутового імпульсу]
∂L_lagr / ∂θ = −m · g · L · sin(θ)           [обертальний момент сили тяжіння]
```

Підставивши знайдені похідні в канонічну форму Ейлера-Лагранжа, отримуємо:

```
m · L² · θ̈ − (−m · g · L · sin(θ)) = 0
m · L² · θ̈ + m · g · L · sin(θ) = 0
```

Скоротивши спільний множник `m · L²` (момент інерції точки відносно осі підвісу), дістаємо фундаментальне нелінійне диференціальне рівняння другого порядку:

```
θ̈ + (g / L) · sin(θ) = 0
```

Позначивши `ω₀ = √(g/L)` як власну кругову частоту нескінченно малих коливань, дістаємо стандартний вигляд диференціального рівняння маятника:

```
θ̈ + ω₀² · sin(θ) = 0
```

### 2. Перший інтеграл руху та закономірності збереження енергії

Отримане диференціальне рівняння не містить явно часу `t`, що свідчить про наявність закону збереження енергії. Помножимо обидві частини рівняння на углову швидкість `θ̇`:

```
θ̇ · θ̈ + ω₀² · θ̇ · sin(θ) = 0
```

Використовуючи правило диференціювання складеної функції, згорнемо обидва доданки під спільну похідну по часу:

```
d/dt [ (1/2) · θ̇² ] + d/dt [ −ω₀² · cos(θ) ] = 0
d/dt [ (1/2) · θ̇² − ω₀² · cos(θ) ] = 0
```

Інтегрування за часом дає константу збереження енергії `E'`:

```
(1/2) · θ̇² − ω₀² · cos(θ) = E' = const
```

Помноживши це рівняння на `m · L²`, бачимо, що константа `E'` з точністю до зсуву описує повну механічну енергію `E = m · L² · E' + m · g · L`:

```
E = (1/2) · m · L² · θ̇² + m · g · L · (1 − cos(θ))
```

Припустимо, що в початковий момент часу `t = 0` маятник відхилили на початкову амплітуду `θ₀` і відпустили зі стану спокою (`θ(0) = θ₀`, `θ̇(0) = 0`). Оскільки у крайній точці кінетична енергія дорівнює нулю, константа `E'` дорівнює:

```
E' = −ω₀² · cos(θ₀)
```

Підставивши це значення назад, отримуємо алгебраїчний зв'язок між угловою швидкістю `θ̇` та поточним кутом відхилення `θ`:

```
(1/2) · θ̇² = ω₀² · (cos(θ) − cos(θ₀))
θ̇² = 2 · ω₀² · (cos(θ) − cos(θ₀))
```

Використавши тотожність для різниці косинусів `cos(A) − cos(B) = 2 · sin²(B/2) − 2 · sin²(A/2)`, перепишемо вираз під коренем:

```
cos(θ) − cos(θ₀) = 2 · ( sin²(θ₀/2) − sin²(θ/2) )
```

Звідси модуль і знак углової швидкості для будь-якої точки коливальної траєкторії становлять:

```
θ̇ = ± 2 · ω₀ · √( sin²(θ₀/2) − sin²(θ/2) )
```

### 3. Точний період коливань через еліптичні інтеграли Якобі

Для обчислення періоду коливань виділимо диференціал часу `dt` з рівняння углової швидкості. Беремо знак «+», що відповідає руху маятника від нижнього положення рівноваги `θ = 0` до максимального відхилення `θ = θ₀`:

```
dt = dθ / ( 2 · ω₀ · √( sin²(θ₀/2) − sin²(θ/2) ) )
```

Повний період коливання `T` складається з чотирьох однакових чвертей руху (від 0 до `θ₀`, від `θ₀` до 0, від 0 до `−θ₀`, і від `−θ₀` до 0):

```
T = 4 · ∫₀^{θ₀} dθ / ( 2 · ω₀ · √( sin²(θ₀/2) − sin²(θ/2) ) )
T = (2 / ω₀) · ∫₀^{θ₀} dθ / √( sin²(θ₀/2) − sin²(θ/2) )
```

Цей інтеграл є невлестивим у верхній межі, оскільки знаменник перетворюється на нуль при `θ = θ₀`. Для приведення його до канонічного вигляду Якобі зробимо тригонометричну замінужно-допоміжну змінну `ϕ`:

```
sin(θ/2) = sin(θ₀/2) · sin(ϕ)
```

Позначивши безрозмірний модуль еліптичного інтеграла як `k = sin(θ₀/2)` (де `0 ≤ k < 1` для закритих коливальних траєкторій):

```
sin(θ/2) = k · sin(ϕ)
```

Візьмемо диференціали від обох частин цієї рівності:

```
(1/2) · cos(θ/2) · dθ = k · cos(ϕ) · dϕ
dθ = 2 · k · cos(ϕ) · dϕ / cos(θ/2)
```

Виразимо `cos(θ/2)` через нову змінну `ϕ`:

```
cos(θ/2) = √( 1 − sin²(θ/2) ) = √( 1 − k² · sin²(ϕ) )
```

Отже, вираз для диференціала `dθ` набуває вигляду:

```
dθ = 2 · k · cos(ϕ) · dϕ / √( 1 − k² · sin²(ϕ) )
```

Знаменник початкового інтеграла підставляється так:

```
√( k² − k² · sin²(ϕ) ) = k · √( 1 − sin²(ϕ) ) = k · cos(ϕ)
```

Визначимо нові межі інтегрування для змінної `ϕ`:
- Якщо `θ = 0`, то `sin(ϕ) = 0`, звідси `ϕ = 0`.
- Якщо `θ = θ₀`, то `sin(ϕ) = 1`, звідси `ϕ = π/2`.

Підставляємо всі компоненти в формулу періоду:

```
T = (2 / ω₀) · ∫₀^{π/2} [ 2 · k · cos(ϕ) · dϕ / √( 1 − k² · sin²(ϕ) ) ] / [ k · cos(ϕ) ]
T = (4 / ω₀) · ∫₀^{π/2} dϕ / √( 1 − k² · sin²(ϕ) )
```

Інтегральний вираз у дужках є канонічним **повним еліптичним інтегралом першого роду** `K(k)`:

```
K(k) = ∫₀^{π/2} dϕ / √( 1 − k² · sin²(ϕ) )
```

Ураховуючи, що період малих ізохронних коливань становить `T₀ = 2·π / ω₀ = 2·π·√(L/g)`, остаточне точне співвідношення для періоду коливань маятника будь-якої амплітуди бере вигляд:

```
T(θ₀) = (4 / π) · T₀ · K(sin(θ₀/2))
```

### 4. Розклад еліптичного інтеграла у степеневий ряд та формула Борди

Оскільки еліптичний інтеграл `K(k)` не виражається через елементарні функції, для практичних розрахунків використовують його розклад у нескінченний біноміальний ряд за степенями модуля `k`:

```
(1 − k² · sin²(ϕ))⁻¹/² = 1 + (1/2) · k² · sin²(ϕ) + (3/8) · k⁴ · sin⁴(ϕ) + (15/48) · k⁶ · sin⁶(ϕ) + ...
```

Почленне інтегрування кожного доданка від 0 до `π/2` за допомогою стандартних інтегралів Волліса `∫₀^{π/2} sin²ⁿ(ϕ) dϕ = (π/2) · (2n − 1)!! / (2n)!!` дає точний степеневий ряд для `K(k)`:

```
K(k) = (π/2) · [ 1 + (1/4) · k² + (9/64) · k⁴ + (225/2304) · k⁶ + (11025/147456) · k⁸ + ... ]
```

Підставивши модуль `k = sin(θ₀/2)`, отримуємо розклад для відношення періоду `T(θ₀)` до гармонічного періоду `T₀`:

```
T(θ₀) / T₀ = 1 + (1/4) · sin²(θ₀/2) + (9/64) · sin⁴(θ₀/2) + (225/2304) · sin⁶(θ₀/2) + ...
```

Для невеликих і помірних амплітуд кут `sin(θ₀/2)` можна розкласти за формулою Тейлора `sin(x) ≈ x − x³/6`. Підстановка дає практичну формулу Борди:

```
T(θ₀) ≈ T₀ · [ 1 + (1/16) · θ₀² + (11/3072) · θ₀⁴ ]
```

Аналіз поправки розкриває нелінійну природу маятника:
- При `θ₀ = 10°` (`0.1745` рад) поправка становить `(1/16) · 0.1745² ≈ 0.19%`.
- При `θ₀ = 30°` (`0.5236` рад) поправка досягає `1.71%`.
- При `θ₀ = 60°` (`1.0472` рад) точне збільшення періоду становить `7.31%`.
- При `θ₀ = 90°` (`π/2` рад) період зростає на `18.03%`.
- При `θ₀ = 179°` період прямує до безкінечності, оскільки маятник зупиняється у верхній нестійкій точці.

### 5. Геометрія фазового простору та точний розв'язок на сепаратрисі

Фазовий портрет маятника побудовано в координатах «кут відхилення `θ` — кутова швидкість `ω = θ̇`». Структура фазового простору є періодичною по `θ` з періодом `2π` і розділяється на три виразні топологічні області.

1. **Особливі точки стійкої рівноваги (центри):** знаходяться в точках `(2πn, 0)`. Навколо них розташовані замкнені фазові траєкторії — **лібрації** (коливання), де енергія `E < 2·m·g·L`.
2. **Особливі точки нестійкої рівноваги (сідла):** розташовані в точках `((2n+1)π, 0)`. Вони відповідають верхньому вертикальному положенню маятника.
3. **Сепаратриса:** фазова крива, що з'єднує сусідні сідлові точки й відокремлює лібрації від **ротацій** (нескінченного обертання в один бік при `E > 2·m·g·L`).

Рівняння сепаратриси відповідає критичній енергії `E = 2·m·g·L` (або `E' = ω₀²`):

```
(1/2) · θ̇² − ω₀² · cos(θ) = ω₀²
θ̇² = 2 · ω₀² · (1 + cos(θ)) = 4 · ω₀² · cos²(θ/2)
```

Звідси рівняння траєкторії на сепаратрисі має вигляд:

```
θ̇_сеп = ± 2 · ω₀ · cos(θ/2)
```

Проінтегруємо це диференціальне рівняння з початковою умовою `θ(0) = 0` при `t = 0`:

```
∫₀^{θ} dθ / cos(θ/2) = 2 · ω₀ · ∫₀^{t} dt
```

Взявши стандартний інтеграл від секанса `∫ d x / cos(x) = ln| tan(x/2 + π/4) |`:

```
2 · ln( tan(θ/4 + π/4) ) = 2 · ω₀ · t
tan(θ/4 + π/4) = exp(ω₀ · t)
```

Виразимо кут `θ` через експоненціальну функцію часу:

```
θ_сеп(t) = 4 · arctan( exp(ω₀ · t) ) − π
```

Цей солітонноподібний розв'язок (так звана «кінк-хвиля») показує, що маятник стартує з нижнього положення і безкінечно довго наближається до верхньої нестійкої точки `θ = π`, досягаючи її лише у границі `t → ∞`. Це математично доводить, що період руху вздовж сепаратриси є нескінченним.
