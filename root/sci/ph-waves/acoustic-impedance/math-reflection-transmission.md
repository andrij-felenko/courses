# 🧮 Виведення коефіцієнтів відбиття й проходження на акустичній межі

Коли акустична хвиля поширюється в одному середовищі й досягає плоского кордону з іншим, відбувається перерозподіл енергії: частина хвилі відбивається назад, а частина проходить далі. Строгий математичний розрахунок амплітуд відбитої й прохідної хвиль спирається на два фундаментальні фізичні закони — закон збереження імпульсу (безперервність акустичного тиску) та закон нерозривності середовища (безперервність нормальної коливальної швидкості). Нижче наведено повне виведення коефіцієнтів для тиску, інтенсивності, коефіцієнта стоячої хвилі, наклонного падіння хвиль та вхідного імпедансу чвертьхвильового шару.

### 1. Рівняння плоских хвиль у двох середовищах

Розглянемо перпендикулярне (нормальне) падіння плоскої монохроматичної акустичної хвилі з першого середовища (з питомим акустичним імпедансом `z₁ = ρ₁ · c₁`) на плоску межу розділу з другим середовищем (з імпедансом `z₂ = ρ₂ · c₂`). Розташуємо вісь `x` перпендикулярно до межі, встановивши початок координат `x = 0` прямо на межі двох середовищ.

У першому середовищі (`x < 0`) існують дві хвилі: падна хвиля `p_i`, що рухається в напрямку зростання `x`, та відбита хвиля `p_r`, що рухається проти осі `x`. У другому середовищі (`x > 0`) існує лише прохідна хвиля `p_t`, що рухається праворуч.

У комплексній формі комплексні амплітуди надлишкового тиску для цих хвиль записуються так:

```
p_i(x, t) = Ai · exp(j·(ωt − k₁·x))
p_r(x, t) = Ar · exp(j·(ωt + k₁·x))
p_t(x, t) = At · exp(j·(ωt − k₂·x))
```

Тут `Ai`, `Ar`, `At` — комплексна амплітуда падної, відбитої та прохідної хвиль відповідно; `ω` — циклічна частота; `k₁ = ω / c₁` та `k₂ = ω / c₂` — хвильові числа у першому та другому середовищах.

Оскільки для біжучої плоскої хвилі зв'язок між надлишковим тиском `p` та коливальною швидкістю частинок `v` визначається співвідношенням `p = z · v`, з урахуванням напрямку поширення хвиль можемо записати комплексні коливальні швидкості:

```
v_i(x, t) = (Ai / z₁) · exp(j·(ωt − k₁·x))          [рух праворуч: +x]
v_r(x, t) = −(Ar / z₁) · exp(j·(ωt + k₁·x))         [рух ліворуч: −x, мінус через напрямок]
v_t(x, t) = (At / z₂) · exp(j·(ωt − k₂·x))          [рух праворуч: +x]
```

Знак мінус у виразі для `v_r` є ключовим: оскільки відбита хвиля рухається проти напрямку падної, стиск середовища в ній створює потік частинок, напрямлений у бік `-x`.

### 2. Крайові умови на межі розділу `x = 0`

Суцільність макроскопічного середовища та відсутність нескінченних сил на межі розділу `x = 0` вимагають виконання двох крайових умов у будь-який момент часу `t`:

1. **Безперервність акустичного тиску:** сумарний тиск зліва від межі має дорівнювати сумарному тиску справа (інакше на нескінченно тонку межу діяла б незкомпенсована сила, створюючи нескінченне прискорення):

```
p_i(0, t) + p_r(0, t) = p_t(0, t)
```

2. **Безперервність коливальної швидкості:** нормальна швидкість зміщення частинок зліва від межі має дорівнювати швидкості справа (інакше на межі виникли б порожнини або розриви середовища):

```
v_i(0, t) + v_r(0, t) = v_t(0, t)
```

Підставляючи комплексні вирази для тиску та швидкостей при `x = 0` і скорочуючи спільний часовий множник `exp(j·ωt)`, отримуємо систему двох алгебраїчних рівнянь для амплітуд:

```
Ai + Ar = At                                      [рівняння 1: безперервність тиску]
(Ai − Ar) / z₁ = At / z₂                          [рівняння 2: безперервність швидкості]
```

### 3. Алгебраїчний вивід коефіцієнтів тиску R та T

Визначимо амплітудний коефіцієнт відбиття за тиском `R` та коефіцієнт проходження за тиском `T` як відношення відповідних комплексних амплітуд до амплітуди падної хвилі:

```
R = Ar / Ai
T = At / Ai
```

Поділимо обидва рівняння системи на `Ai`:

```
1 + R = T                                         [із рівняння 1]
1 − R = T · (z₁ / z₂)                             [із рівняння 2]
```

Підставимо вираз `T = 1 + R` у друге рівняння й виведемо `R`:

```
1 − R = (1 + R) · (z₁ / z₂)      [підстановка T = 1 + R]
z₂ · (1 − R) = z₁ · (1 + R)      [помножили обидві частини на z₂]
z₂ − z₂·R = z₁ + z₁·R            [розкрили дужки]
z₂ − z₁ = z₁·R + z₂·R            [перегрупували доданки]
z₂ − z₁ = R · (z₂ + z₁)          [винесли R за дужки]
R = (z₂ − z₁) / (z₂ + z₁)        [отримали коефіцієнт відбиття]
```

Тепер підставимо знайдений вираз для `R` у формулу `T = 1 + R`:

```
T = 1 + (z₂ − z₁) / (z₂ + z₁)
T = ((z₂ + z₁) + (z₂ − z₁)) / (z₂ + z₁)
T = (2 · z₂) / (z₂ + z₁)         [отримали коефіцієнт проходження]
```

Зверніть увагу: коефіцієнт проходження за тиском `T` може бути більшим за одиницю, якщо `z₂ > z₁` (наприклад, при переході з повітря у воду `T ≈ 2`). Це не порушує закон збереження енергії, адже густина енергії та інтенсивність залежать не лише від тиску, а й від імпедансу середовища.

### 4. Інтенсивність та енергетичні коефіцієнти

Середня за періодом інтенсивність (густина потоку акустичної енергії) плоскої хвилі дорівнює:

```
I = |A|² / (2 · z)
```

Обчислимо інтенсивності падної `I_i`, відбитої `I_r` та прохідної `I_t` хвиль:

```
I_i = |Ai|² / (2 · z₁)
I_r = |Ar|² / (2 · z₁)
I_t = |At|² / (2 · z₂)
```

Визначимо енергетичний коефіцієнт відбиття (потоковий коефіцієнт відбиття) `R_I` як відношення відбитої інтенсивності до падної:

```
R_I = I_r / I_i = |Ar|² / |Ai|² = R²
R_I = [ (z₂ − z₁) / (z₂ + z₁) ]²
```

Визначимо енергетичний коефіцієнт проходження `T_I` як відношення прохідної інтенсивності до падної:

```
T_I = I_t / I_i = (z₁ / z₂) · (|At|² / |Ai|²) = (z₁ / z₂) · T²
T_I = (z₁ / z₂) · [ (2 · z₂) / (z₂ + z₁) ]²
T_I = (4 · z₁ · z₂) / (z₂ + z₁)²
```

Перевіримо виконання закону збереження енергії на межі:

```
R_I + T_I = [ (z₂ − z₁)² + 4·z₁·z₂ ] / (z₂ + z₁)²
          = [ z₂² − 2·z₁·z₂ + z₁² + 4·z₁·z₂ ] / (z₂ + z₁)²
          = [ z₂² + 2·z₁·z₂ + z₁² ] / (z₂ + z₁)²
          = (z₂ + z₁)² / (z₂ + z₁)² = 1
```

Сума енергетичних коефіцієнтів завжди дорівнює точно одиниці (`R_I + T_I = 1`), що повністю підтверджує строгість виведення.

### 5. Граничні значення та коефіцієнт стоячої хвилі (КСХ)

Розглянемо три класичні граничні випадки акустичних меж:

1. **Ідеально жорстка стінка (`z₂ → ∞`):**
```
R = lim_{z₂→∞} (z₂ − z₁) / (z₂ + z₁) = +1
T = lim_{z₂→∞} (2·z₂) / (z₂ + z₁) = 2
R_I = 1,   T_I = 0
```
Хвиля повністю відбивається у фазі. Амплітуда тиску на межі подвоюється (`p = 2·Ai`), а коливальна швидкість дорівнює нулю (`v = 0`).

2. **Абсолютно м'яка межа / відкритий кінець (`z₂ → 0`):**
```
R = lim_{z₂→0} (z₂ − z₁) / (z₂ + z₁) = −1
T = lim_{z₂→0} (2·z₂) / (z₂ + z₁) = 0
R_I = 1,   T_I = 0
```
Хвиля повністю відбивається в протифазі (зсув фази на 180°). Надлишковий тиск на межі дорівнює нулю (`p = 0`), а коливальна швидкість подвоюється (`v = 2·Ai / z₁`).

3. **Ідеальне узгодження імпедансів (`z₂ = z₁`):**
```
R = 0,   T = 1,   R_I = 0,   T_I = 1
```
Відбиття повністю відсутнє; вся акустична енергія безшкодно переходить у друге середовище.

У разі часткового відбиття (`0 < |R| < 1`) інтерференція падної та відбитої хвиль у першому середовищі утворює змішану хвильову картину з максимумами й мінімумами тиску:

```
p_sum(x) = Ai · [ exp(−j·k₁·x) + R · exp(+j·k₁·x) ]
```

Максимальна амплітуда тиску спостерігається у вузлах, де падаюча й відбита хвиля додаються у фазі: `p_max = |Ai| · (1 + |R|)`. Мінімальна амплітуда — де вони знаходяться у протифазі: `p_min = |Ai| · (1 − |R|)`.

Відношення максимального тиску до мінімального називається **коефіцієнтом стоячої хвилі (КСХ, або SWR):**

```
SWR = p_max / p_min = (1 + |R|) / (1 − |R|)
```

Якщо `R = 0`, то `SWR = 1` (чиста біжуча хвиля). Якщо `|R| = 1`, то `SWR → ∞` (чиста стояча хвиля).

### 6. Наклонне падіння плоскої хвилі та акустичний закон Снелліуса

Якщо біжуча хвиля падає на плоску межу під кутом `θ₁` до нормалі, кут проходження `θ₂` у другому середовищі визначається акустичним законом Снелліуса:

```
sin(θ₁) / c₁ = sin(θ₂) / c₂
```

Крайові умови вимагають безперервності сумарного тиску та **нормальної компоненти** коливальної швидкості частинок (`v_n = v · cos θ`). Це приводить до кутово-залежних коефіцієнтів відбиття й проходження:

```
R(θ₁) = (z₂ · cos θ₁ − z₁ · cos θ₂) / (z₂ · cos θ₁ + z₁ · cos θ₂)
T(θ₁) = (2 · z₂ · cos θ₁) / (z₂ · cos θ₁ + z₁ · cos θ₂)
```

Якщо швидкість звуку в другому середовищі більша за швидкість у першому (`c₂ > c₁`), існує **критичний кут падіння `θ_crit = arcsin(c₁ / c₂)`**. При падінні під кутом `θ₁ > θ_crit` кут `θ₂` стає комплексним (`cos θ₂ = −j · √(sin²θ₁ · (c₂/c₁)² − 1)`), що призводить до появи в другому середовищі неоднорідної (згасаючої) хвилі, яка затухає експоненційно вздовж нормалі. У цьому режимі відбувається **повне внутрішнє акустичне відбиття** (`|R(θ₁)| = 1`), а фазовий зсув відбитої хвилі змінюється від 0 до 180° залежно від кута.

### 7. Вхідний імпеданс чвертьхвильового трансформатора

Для узгодження двох середовищ із імпедансами `z₁` та `z₂` часто використовують проміжний шар товщиною `d` із імпедансом `z_m`. Розрахуємо вхідний акустичний імпеданс `z_in` такого шару, навантаженого на середовище `z₂`.

Застосовуючи теорію довгих ліній до акустичного шару, вираз для вхідного імпедансу на передній межі шару має вигляд:

```
z_in = z_m · [ (z₂ + j · z_m · tan(k_m · d)) / (z_m + j · z₂ · tan(k_m · d)) ]
```

Тут `k_m = 2π / λ_m` — хвильове число в узгоджувальному шарі.

Якщо товщина шару дорівнює чверті довжини хвилі (`d = λ_m / 4`), аргумент тангенса стає дорівнювати:

```
k_m · d = (2π / λ_m) · (λ_m / 4) = π / 2
```

Оскільки `tan(π / 2) → ∞`, поділимо чисельник і знаменник виразу на `j · tan(k_m · d)` і перейдемо до границі:

```
z_in = z_m · [ (z₂ / (j·tan) + z_m) / (z_m / (j·tan) + z₂) ]
z_in = z_m · [ (0 + z_m) / (0 + z₂) ]
z_in = (z_m)² / z₂
```

Ця формула показує інвертувальну властивість чвертьхвильового шару: вхідний імпеданс дорівнює квадрату імпедансу шару, поділеному на імпеданс навантаження.

Щоб забезпечити ідеальне узгодження з першим середовищем, вимагаємо, щоб вхідний імпеданс шару дорівнював імпедансу першого середовища (`z_in = z₁`):

```
z₁ = (z_m)² / z₂
(z_m)² = z₁ · z₂
z_m = √(z₁ · z₂)
```

Таким чином, для повного усунення відбиття на обраній частоті імпеданс чвертьхвильового шару має дорівнювати геометричному середньому імпедансів двох межових середовищ, а його товщина — чверті довжини хвилі в цьому шарі.
