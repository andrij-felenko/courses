# 📋 Акустичні властивості матеріалів та формули імпедансу

Цей довідник містить детальні систематизовані таблиці питомих акустичних імпедансів `z₀ = ρ · c`, густини `ρ`, швидкості звуку `c` та коефіцієнтів загасання для газів, рідин, біологічних тканин, п'єзоматеріалів та конструкційних сплавів при стандартних фізичних умовах (`T = 20 °C`, `P = 101.325 кПа`), а також повний математичний довідник еквівалентних акустико-електричних кіл.

Довідник призначений для практичного розрахунку акустичних хвилеводів, розробки чвертьхвильових узгоджувальних шарів для медичних ультразвукових датчиків, розрахунку звукоізоляції в аерокосмічній галузі, проектування гідролокаторів та системи шумозаглушення.

### 1. Фізична природа та вимірювання акустичного імпедансу

Питомий акустичний імпеданс середовища `z₀` є внутрішньою фундаментальною характеристикою речовини, яка визначає, який надлишковий акустичний тиск `p` необхідно прикласти до середовища для створення у ньому частинкового коливального руху зі швидкістю `v`. У разі поширення плоскої біжучої хвилі імпеданс дорівнює добутку густини середовища на швидкість звуку `z₀ = ρ · c`.

З фізичної точки зору акустичний імпеданс є геометричним середнім двох ключових механічних властивостей середовища — його інертності (моделюється густиною `ρ`) та його поздовжньої жорсткості (моделюється модулем об'ємної пружності `K` для рідин і газів або модулем поздовжньої деформації `M = K + (4/3)·G` для твердих тіл):

```
z₀ = √(ρ · K)        [для рідин і газів]
z₀ = √(ρ · M)        [для твердих суцільних тіл]
```

Один Райл (MKS Rayl) відповідає середовищу, в якому надлишковий тиск у 1 Паскаль створює коливальну швидкість частинок 1 метр за секунду. У газах імпеданс вимірюється сотнями Райл, у рідинах та м'яких тканинах — мільйонами Райл (МРайл), а у твердих металах і п'єзокераміці — десятками мільйонів Райл.

### 2. Довідкові параметри газів

Газові середовища характеризуються найменшим акустичним імпедансом через низьку густину та високу стисливість. Швидкість звуку в ідеальному газі не залежить від тиску, але суттєво зростає з підвищенням температури та зменшенням молярної маси газу. Зміна температури повітря від `0 °C` до `30 °C` зменшує імпеданс майже на `5%`, що необхідно враховувати при точних акустичних вимірюваннях на відкритому повітрі.

### 7. Зведені формули імпедансу та акустико-електричні аналогії

В акустиці з зосередженими параметрами (коли розміри елементів системи значно менші за довжину хвилі `L << λ`) геометричні елементи середовища описуються через еквівалентні акустичні опори, індуктивності й ємності.

#### Визначення базових імпедансних величин:

1. **Питомий акустичний імпеданс (Specific Acoustic Impedance):**
Формула описує опір локального об'єму середовища поширенню плоскої біжучої хвилі:
```
z₀ = p / v = ρ · c = √(ρ · K)    [Па·с/м, або Райл]
```

2. **Акустичний імпеданс перерізу або труби (Acoustic Impedance):**
Формула пов'язує надлишковий тиск `p` із повною об'ємною швидкістю потоку `U = v · S` через переріз площею `S`:
```
ZA = p / U = p / (v · S) = z₀ / S = (ρ · c) / S    [Па·с/м³]
```

3. **Механічний імпеданс поршня чи мембрани (Mechanical Impedance):**
Формула пов'язує повну механічну силу `F = p · S`, діючу на мембрану, з її лінійною швидкістю `v`:
```
ZM = F / v = (p · S) / v = z₀ · S = ρ · c · S      [Н·с/м, або кг/с]
```

#### Елементи еквівалентних акустичних кіл:

1. **Акустична маса (Acoustic Mass / Inertance):**
Моделює інерцію повітряного стовпа у вузькій трубці чи шийці резонатора довжиною `L` і перерізом `S`. Ефективна довжина `L'` враховує приєднану масу повітря обабіч отвору (`L' = L + 0.8 · d`, де `d` — діаметр):
```
MA = (ρ · L') / S                                   [кг/м⁴]
Реактивний акустичний опір маси: X_MA = ω · MA = ω · (ρ · L') / S
```

2. **Акустична гнучкість / ємність (Acoustic Compliance):**
Моделює пружні властивості стиснутого повітря в закритому об'ємі `V`. Вона діє як акустичний конденсатор, накопичуючи потенціальну енергію стиску:
```
CA = V / (ρ · c²) = V / K                           [м⁵/Н, або м³/Па]
Реактивний акустичний опір гнучкості: X_CA = −1 / (ω · CA) = −(ρ · c²) / (ω · V)
```

3. **Акустичний активний опір втрат (Acoustic Resistance):**
Описує безповоротне розсіювання акустичної енергії в тепло за рахунок в'язкого тертя у вузьких капілярах (закон Пуазейля) та за рахунок випромінювання звуку у вільний простір:
```
RA_visc = (8 · η · L) / (π · r⁴)                    [Па·с/м³  (в'язкий опір у трубі радіуса r)]
RA_rad  = (ρ · c · k²) / (2 · π)                    [Па·с/м³  (опір випромінювання пульсуючої сфери)]
```

4. **Повний комплексний імпеданс резонатора:**
```
ZA(ω) = RA + j · [ ω · MA − 1 / (ω · CA) ]          [Па·с/м³]
 Модуль імпедансу:   |ZA| = √[ RA² + (ω·MA − 1/(ω·CA))² ]
 Зсув фази:         φ = arctan[ (ω·MA − 1/(ω·CA)) / RA ]
```

5. **Резонансна частота резонатора Гельмгольца:**
Умова акустичного резонансу відповідає рівності нулю реактивної частини імпедансу (`X_MA + X_CA = 0`):
```
ω₀ = 1 / √(MA · CA) = 1 / √[ ((ρ · L') / S) · (V / (ρ · c²)) ]
ω₀ = c · √(S / (L' · V))
f₀ = (c / (2 · π)) · √(S / (L' · V))                [Гц]
```

### 8. Співвідношення та конвертація одиниць вимірювання

- `1 MKS Rayl = 1 Па·с/м = 1 Н·с/м³ = 1 кг/(м²·с)`
- `1 CGS Rayl = 1 дин·с/см³ = 10 MKS Rayl = 10 Па·с/м`
- `1 МРайл (Megarayl) = 10⁶ Па·с/м = 10⁶ кг/(м²·с)`
- Перехід від акустичного імпедансу до механічного: `ZM = ZA · S²`
- Перехід від питомого імпедансу до акустичного: `ZA = z₀ / S`
- Перехід від питомого імпедансу до механічного: `ZM = z₀ · S`
