# 🧮 Математичний вивід рівняння Вебстера та імпедансу експоненційного рупора

Цей математичний документ містить строгий вивід одномірного хвильового рівняння Вебстера для труб зі змінним поперечним перерізом, його розв'язок для експоненційного профілю через перетворення Клейна-Гордона, точне виведення критичної частоти зрізу та розрахунок комплекснозначного вхідного акустичного імпедансу для нескінченного й скінченного рупорів.

### 1. Перші принципи: рівняння руху та нерозривності у трубі змінного перерізу

Розглянемо поширення акустичної хвилі вздовж осі `x` у трубі, площа поперечного перерізу якої неперервно змінюється за законом `S(x)`. Припустимо, що частота хвилі задовольняє умову `λ ≫ √(S(x))`, завдяки чому хвильовий фронт можна вважати плоским, а тиск `p(x, t)` та коливальну швидкість частинок `v(x, t)` — однорідними за перерізом.

Застосуємо фундаментальні закони гідродинаміки до малого елемента об'єму повітря довжиною `dx` між перерізами `x` та `x + dx`:

1. **Динамічне рівняння руху (Закон Ньютона):**
Маса повітря в елементі дорівнює `dm = ρ₀ · S(x) · dx`, де `ρ₀` — середня густина непорушеного середовища. Сила тиску, що діє на цей елемент вздовж осі `x`, дорівнює `F = −S(x) · (∂p / ∂x) · dx`.
Рівняння руху `dm · (∂v / ∂t) = F` після скорочення на `S(x) · dx` набуває вигляду:

```
ρ₀ · (∂v / ∂t) = −∂p / ∂x
```

2. **Рівняння нерозривності (Збереження маси):**
Масовий потік повітря, що входить у переріз `x`, дорівнює `q_in = ρ₀ · S(x) · v(x, t)`. Потік, що виходить через `x + dx`, дорівнює `q_out = ρ₀ · S(x + dx) · v(x + dx, t)`. Різниця між потоками змінює густину повітря всередині елемента об'єму `V = S(x) · dx`:

```
−∂/∂x [ S(x) · v(x, t) ] · dx = S(x) · (∂ρ / ∂t) · dx
```

Використовуючи адіабатичне рівняння стану газу `dp = c² · dρ` (де `c` — швидкість звуку в вільному середовищі), отримуємо:

```
∂ρ / ∂t = (1 / c²) · (∂p / ∂t)
```

Підставляючи це значення у рівняння нерозривності й скорочуючи на `dx`, дістаємо:

```
(1 / S(x)) · ∂/∂x [ S(x) · v(x, t) ] = −(1 / (ρ₀ · c²)) · (∂p / ∂t)
```

### 2. Вивід одномірного хвильового рівняння Вебстера

Щоб виключити коливальну швидкість `v(x, t)` і отримати єдине диференціальне рівняння для тиску `p(x, t)`, продиференціюємо рівняння нерозривності за часом `t`:

```
(1 / S(x)) · ∂/∂x [ S(x) · (∂v / ∂t) ] = −(1 / (ρ₀ · c²)) · (∂²p / ∂t²)
```

Підставимо у ліву частину вираз для `∂v / ∂t` з рівняння руху (`∂v / ∂t = −(1 / ρ₀) · (∂p / ∂x)`):

```
(1 / S(x)) · ∂/∂x [ S(x) · (−1 / ρ₀) · (∂p / ∂x) ] = −(1 / (ρ₀ · c²)) · (∂²p / ∂t²)
```

Множачи обидві частини на `−ρ₀`, отримуємо **хвильове рівняння Вебстера**:

```
(1 / S(x)) · ∂/∂x [ S(x) · (∂p / ∂x) ] = (1 / c²) · (∂²p / ∂t²)          [Рівняння Вебстера]
```

Розкриваючи похідну добутку у лівій частині `∂/∂x [ S(x) · ∂p/∂x ] = S(x) · (∂²p / ∂x²) + (dS / dx) · (∂p / ∂x)`, перепишемо рівняння у розгорнутій формі:

```
∂²p / ∂x² + (1 / S(x)) · (dS / dx) · (∂p / ∂x) = (1 / c²) · (∂²p / ∂t²)
```

### 3. Математичний аналіз експоненційного профілю

Для експоненційного рупора закон зміни площі задається співвідношенням:

```
S(x) = S₀ · e^(m·x)
```

де `S₀` — площа горла при `x = 0`, а `m` — показник розширення (постійна рупора, м⁻¹).

Похідна площі дорівнює `dS / dx = m · S₀ · e^(m·x) = m · S(x)`. Логарифмічна похідна є строго постійною величиною у кожній точці:

```
(1 / S(x)) · (dS / dx) = m = const
```

Підставляючи цю константу в рівняння Вебстера, дістаємо диференціальне рівняння з постійними коефіцієнтами:

```
∂²p / ∂x² + m · (∂p / ∂x) = (1 / c²) · (∂²p / ∂t²)
```

Шукаємо розв'язок для монохроматичної хвилі з коловою частотою `ω` у вигляді `p(x, t) = P(x) · e^(j·ω·t)`. Позначивши вільне хвильове число `k = ω / c`, отримуємо звичайне диференціальне рівняння для просторової амплітуди тиску `P(x)`:

```
d²P / dx² + m · (dP / dx) + k² · P = 0
```

Щоб усунути першу похідну `dP / dx`, застосуємо математичну підстановку Ліувіля (перетворення Клейна-Гордона):

```
P(x) = ψ(x) · e^(−m·x / 2)
```

Обчислимо першу та другу похідні `P(x)`:

```
dP / dx = (dψ / dx − (m / 2) · ψ) · e^(−m·x / 2)
d²P / dx² = (d²ψ / dx² − m · (dψ / dx) + (m² / 4) · ψ) · e^(−m·x / 2)
```

Підставимо ці похідні назад у диференціальне рівняння:

```
(d²ψ / dx² − m · dψ/dx + (m²/4) · ψ) + m · (dψ/dx − (m/2) · ψ) + k² · ψ = 0
```

Доданки з першою похідною `m · dψ/dx` взаємно знищуються! Звівши подібні члени при `ψ`, отримуємо класичне рівняння Гельмгольца для перетвореної функції `ψ(x)`:

```
d²ψ / dx² + (k² − m² / 4) · ψ = 0
```

### 4. Критична частота зрізу та дисперсійне співвідношення

Властивості розв'язку фундаментально залежать від знаку ефективного квадратного хвильового числа `γ² = k² − m² / 4`.

Позначиємо **критичне хвильове число зрізу** як `k_c = m / 2`.
Відповідно, **критична колова частота зрізу** дорівнює:

```
ω_c = k_c · c = m · c / 2
```

а **критична частота зрізу `f_c`** у Герцах становить:

```
f_c = ω_c / (2·π) = m · c / (4·π)          [Частота зрізу експоненційного рупора]
```

Розглянемо два фізичні режими поширення:

#### Режим 1: Низькі частоти (`f < f_c`, або `k < m / 2`)
Величина `k² − m²/4 = −α² < 0` є строго від'ємною, де `α = √((m²/4) − k²) = (m/2) · √(1 − (f/f_c)²)`.
Рівняння для `ψ(x)` набуває вигляду `d²ψ / dx² − α² · ψ = 0`.
Його загальний розв'язок: `ψ(x) = C₁ · e^(−α·x) + C₂ · e^(+α·x)`.
Отже, тиск у рупорі дорівнює:

```
p(x, t) = [ C₁ · e^(−(m/2 + α)·x) + C₂ · e^(−(m/2 − α)·x) ] · e^(j·ω·t)
```

Усі хвильові рішення є дійсними експонентами без уявного фазового множника за простором! Це означає, що **хвиля не біжить, фазове зсунення відсутнє, а звукова енергія експоненційно згасає уздовж рупора (еванесцентна хвиля)**. Активне випромінювання потужності дорівнює нулю.

#### Режим 2: Високі частоти (`f > f_c`, або `k > m / 2`)
Величина `k² − m²/4 = β² > 0` є додатною, де `β = √(k² − (m²/4)) = k · √(1 − (f_c/f)²)`.
Рівняння для `ψ(x)` перетворюється на рівняння гармонічного осцилятора `d²ψ / dx² + β² · ψ = 0`.
Розв'язок для хвилі, що біжить у напрямку плюс `x`: `ψ(x) = C · e^(−j·β·x)`.
Амплітуда тиску дорівнює:

```
p(x, t) = C · e^(−m·x / 2) · e^(j·(ω·t − β·x))
```

Хвиля поширюється вздовж рупора з ефективним хвильовим вектором `β`. Оскільки `β < k`, **фазова швидкість хвилі `c_p` у рупорі перевищує швидкість звуку у вільному повітрі**:

```
c_p = ω / β = (k · c) / (k · √(1 − (f_c/f)²)) = c / √(1 − (f_c/f)²)
```

При `f → ∞` фазова швидкість прямує до `c`, а при `f → f_c` прямує до нескінченності.

### 5. Точний вивід вхідного імпедансу нескінченного рупора

Знайдемо коливальну швидкість частинок `v(x, t)` у рупорі для режиму поширення (`f > f_c`). Для цього продиференціюємо вираз тиску `p(x, t)` за `x` і скористаємося динамічним рівнянням `ρ₀ · (∂v / ∂t) = −∂p / ∂x`:

```
∂p / ∂x = −[ (m / 2) + j·β ] · C · e^(−m·x / 2) · e^(j·(ω·t − β·x)) = −[ (m / 2) + j·β ] · p(x, t)
```

Оскільки `∂v / ∂t = j·ω·v`, отримуємо:

```
j·ω·ρ₀ · v(x, t) = [ (m / 2) + j·β ] · p(x, t)
```

Звідси відношення тиску до коливальної швидкості (питомий акустичний імпеданс `z_in = p / v`) у будь-якому перерізі нескінченного рупора дорівнює:

```
z_in = (j·ω·ρ₀) / [ (m / 2) + j·β ]
```

Помноживши чисельник і знаменник на комплексно-спряжений вираз `(m/2) − j·β` та врахувавши, що `(m/2)² + β² = k² = (ω/c)²`, дістаємо:

```
z_in = (j·ω·ρ₀) · [ (m / 2) − j·β ] / (ω / c)² = ρ₀ · c · [ (β / k) + j · (m / (2·k)) ]
```

Підставляючи `β / k = √(1 − (f_c/f)²)`, та `m / (2·k) = k_c / k = f_c / f`, отримуємо остаточну формулу **питомого вхідного імпедансу**:

```
z_in(f) = ρ₀ · c · [ √(1 − (f_c / f)²) + j · (f_c / f) ]          [для f ≥ f_c]
```

Розділивши питомий імпеданс на площу горла `S₀`, визначаємо **комплексний акустичний імпеданс горла `Z_in`**:

```
Z_in(f) = (ρ₀ · c / S₀) · [ √(1 − (f_c / f)²) + j · (f_c / f) ]
```

Аналіз отриманого виразу:
1. **Активна частина (Опір випромінювання `R_in`):**
   `R_in = Re(Z_in) = (ρ₀·c / S₀) · √(1 − (f_c/f)²)`.
   При `f < f_c` active resistance `R_in = 0` (енергія не випромінюється). При `f ≫ f_c` опір випромінювання виходить на постійну горизонтальну асимптоту `R_in → ρ₀·c / S₀`.
2. **Реактивна частина (Акустична маса `X_in`):**
   `X_in = Im(Z_in) = (ρ₀·c / S₀) · (f_c / f)`.
   Реактивна маса має індуктивний (інерційний) характер, спадаючи обернено пропорційно частоті.

### 6. Матриця передачі (ABCD-параметри) для скінченного експоненційного рупора

Для рупора скінченної довжини `L` з площею горла `S₀` та гирла `S_L = S₀ · e^(m·L)` зв'язок між акустичним тиском і об'ємною швидкістю `U = v · S` у горлі (`p₁, U₁`) та в гирлі (`p₂, U₂`) задається за допомогою матриці передачі чотириполюсника:

```
[ p₁ ]   [ A   B ] [ p₂ ]
[ U₁ ] = [ C   D ] [ U₂ ]
```

Параметри матриці передачі експоненційного сегмента для `f > f_c` мають вигляд:

```
A = e^(m·L / 2) · [ cos(β·L) + (m / (2·β)) · sin(β·L) ]
B = j · (ρ₀·c / S_L) · (k / β) · e^(m·L / 2) · sin(β·L)
C = j · (S₀ / (ρ₀·c)) · (k / β) · e^(−m·L / 2) · sin(β·L)
D = e^(−m·L / 2) · [ cos(β·L) − (m / (2·β)) · sin(β·L) ]
```

Вхідний імпеданс горла скінченного рупора з урахуванням довільного навантаження гирла `Z_L = p₂ / U₂` обчислюється як:

```
Z_in = (A · Z_L + B) / (C · Z_L + D)
```

Якщо гирло є відкритим і випромінює у вільний простір, імпеданс навантаження `Z_L` дорівнює імпедансу випромінювання поршня у нескінченному екрані радіуса `r_L = √(S_L / π)`:

```
Z_L(f) ≈ (ρ₀·c / S_L) · [ (1 − J₁(2·k·r_L) / (k·r_L)) + j · (H₁(2·k·r_L) / (k·r_L)) ]
```

де `J₁` — функція Бесселя першого роду, а `H₁` — функція Струве першого порядку. Варіювання частоти викликає періодичну зміну `Z_L`, що при `Z_L ≠ ρ₀·c / S_L` формує згасаючі резонансні пульсації вхідного опору горла.
