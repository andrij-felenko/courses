# 🧮 Математична теорія когерентності: взаємна когерентність, теорема Вінера — Хінчина та теорема Ван Ціттерта — Церніке

Математичний апарат теорії когерентності описує статистичні кореляційні зв'язки між флуктуаціями хвильових полів у різних точках простору та в різні моменти часу. Оскільки реальні хвильові процеси зазнають високочастотних флуктуацій, детектори вимірюють не миттєві значення вектора напруженості поля, а його часове усереднення.

### Комплексний аналітичний сигнал та усереднення

Для суворого опису реальної дісної величини хвильового поля `E(r, t)` (наприклад, напруженості електричного поля світлової хвилі або звукового тиску) у фізиці використовують комплексний аналітичний сигнал `V(r, t)`. 

Нехай реальний процес виражається через дійсну амплітуду `A(r, t)`, центральну частоту `ω₀` та фазові флуктуації `φ(r, t)`:

```
V(r, t) = A(r, t) · exp(i · (ω₀·t − k·r + φ(r, t)))      [комплексний аналітичний сигнал]
```

Дійсне фізичне поле відновлюється як реальна частина цього сигналу: `E(r, t) = Re[V(r, t)]`. Перехід до комплексної форми дає змогу розділити швидкі осциляції на несучій частоті `ω₀` та повільні зміни амплітуди й фази.

Математична процедура часового усереднення за час відгуку детектора `T_det` визначається інтегралом:

```
⟨ f(t) ⟩ = (1 ÷ T_det) · ∫ f(t) dt      [часове усереднення на інтервалі T_det]
```

Для стаціонарних та ергодичних випадкових процесів таке часове усереднення повністю еквівалентне статистичному усередненню за ансамблем реалізацій: `⟨f(t)⟩ = E[f(t)]`.

Оскільки більшість фізичних приймачів (око, фотодіод, матриця камери) є квадратичними за амплітудою полів, вимірювана інтенсивність хвилі `I(r)` виражається як часове середнє від квадрата модуля комплексної амплітуди:

```
I(r) = ⟨ V(r, t) · V*(r, t) ⟩ = ⟨ |V(r, t)|² ⟩      [вимірювана інтенсивність поля]
```

### Функція взаємної когерентності та комплексний ступінь когерентності

Для двох точок простору `r₁` та `r₂` у моменти часу `t + τ` та `t` вводиться фундаментальна **функція взаємної когерентності** (mutual coherence function) `Γ₁₂(τ)`:

```
Γ₁₂(τ) = ⟨ V(r₁, t + τ) · V*(r₂, t) ⟩      [визначення функції взаємної когерентності]
```

Ця функція є статистичною мірою кореляції між хвильовим полем у першій точці, взятим із часовим зсувом `τ`, та хвильовим полем у другій точці.

#### Основні математичні властивості функції `Γ₁₂(τ)`:

1. **Функція самокогерентності:** Якщо обидві точки збігаються (`r₁ = r₂`), функція `Γ₁₁(τ)` описує автокореляцію поля в одній точці простору в різні моменти часу.
2. **Значення при нульовій затримці (`τ = 0`):** У мить `τ = 0` значення функції самокогерентності дорівнює усередненій інтенсивності поля у відповідній точці простору:
   ```
   Γ₁₁(0) = ⟨ |V(r₁, t)|² ⟩ = I₁      [інтенсивність у точці P₁]
   Γ₂₂(0) = ⟨ |V(r₂, t)|² ⟩ = I₂      [інтенсивність у точці P₂]
   ```
3. **Ермітова симетрія:** При одночасній заміні просторових точок місцями та зміні знака часової затримки `τ` функція взаємної когерентності переходить у своє комплексне спряження:
   ```
   Γ₂₁(−τ) = Γ₁₂*(τ)      [властивість ермітової симетрії]
   ```

Щоб позбутися залежності від абсолютних інтенсивностей хвиль і виділити чисто фазовий зв'язок, функцію взаємної когерентності нормують на квадратний корінь із добутку інтенсивностей. Так отримують **комплексний ступінь когерентності** `γ₁₂(τ)`:

```
γ₁₂(τ) = Γ₁₂(τ) ÷ √(Γ₁₁(0) · Γ₂₂(0)) = Γ₁₂(τ) ÷ √(I₁ · I₂)      [комплексний ступінь когерентності]
```

За математичною нерівністю Коші — Буняковського — Шварца для кореляційних функцій випадкових процесів, модуль комплексного ступеня когерентності завжди задовольняє суворе обмеження:

```
0 ≤ |γ₁₂(τ)| ≤ 1      [градієнт когерентності]
```

Фізична інтерпретація цих границь є такою:
- **`|γ₁₂(τ)| = 1` (повна когерентність):** фази хвиль у точках `r₁` та `r₂` строго пов'язані детермінованим співвідношенням. Інтерференційні смуги мають максимально можливий контраст.
- **`0 < |γ₁₂(τ)| < 1` (часткова когерентність):** існує частковий фазовий зв'язок між хвилями, однак флуктуації фази спричиняють часткове змивання контрасту смуг.
- **`|γ₁₂(τ)| = 0` (повна некогерентність):** фази у двох точках флуктують абсолютно незалежно. Будь-який кореляційний зв'язок відсутній, інтерференційні смуги повністю зникають.

### Докладне виведення інтенсивності суміші та видності смуг

Розглянемо математичне додавання двох хвильових полів `V₁(t)` та `V₂(t)` у точці спостереження на екрані. Поле від першого джерела проходить оптичний шлях із часовим запізненням `τ₁`, а від другого — з запізненням `τ₂`.

За принципом суперпозиції, сумарне комплексне поле у точці спостереження дорівнює:

```
V(t) = V₁(t + τ₁) + V₂(t + τ₂)      [суперпозиція комплексних полів]
```

Обчислимо вимірювану приймачем підсумкову інтенсивність `I = ⟨ V(t) · V*(t) ⟩`:

```
I = ⟨ (V₁(t + τ₁) + V₂(t + τ₂)) · (V₁*(t + τ₁) + V₂*(t + τ₂)) ⟩      [розкриття комплексної дужки]
```

Розкриваючи добуток усередині знака часового усереднення, отримуємо чотири окремі доданки:

```
I = ⟨ V₁(t+τ₁)·V₁*(t+τ₁) ⟩ + ⟨ V₂(t+τ₂)·V₂*(t+τ₂) ⟩ + ⟨ V₁(t+τ₁)·V₂*(t+τ₂) ⟩ + ⟨ V₁*(t+τ₁)·V₂(t+τ₂) ⟩
```

Перші два доданки за визначенням є інтенсивностями `I₁` та `I₂` кожного променя окремо. Третій та четвертий доданки виражаються через функцію взаємної когерентності `Γ₁₂` із часовим зсувом `τ = τ₂ − τ₁`:

```
I = I₁ + I₂ + Γ₁₂(τ₂ − τ₁) + Γ₁₂*(τ₂ − τ₁)
```

Оскільки сума будь-якого числа та його комплексного спряження дорівнює подвоєній дісній частині (`z + z* = 2 · Re[z]`), маємо:

```
I = I₁ + I₂ + 2 · Re[ Γ₁₂(τ) ]      [формула інтерференції через функцію взаємної когерентності]
```

Підставляючи вираз для комплексного ступеня когерентності `Γ₁₂(τ) = √(I₁·I₂) · γ₁₂(τ)`, отримуємо загальну формулу для інтенсивності суперпозиції двох частково когерентних хвиль:

```
I = I₁ + I₂ + 2 · √(I₁ · I₂) · Re[ γ₁₂(τ) ]      [основне рівняння частково когерентної інтерференції]
```

Представивши комплексне число `γ₁₂(τ)` у тригонометричній формі через його модуль `|γ₁₂(τ)|` та фазу `φ₁₂(τ) − ω₀·τ`:

```
Re[ γ₁₂(τ) ] = |γ₁₂(τ)| · cos(φ₁₂(τ) − ω₀·τ)
```

отримуємо кінцевий вираз для розподілу інтенсивності на екрані:

```
I = I₁ + I₂ + 2 · √(I₁ · I₂) · |γ₁₂(τ)| · cos(φ₁₂(τ) − ω₀·τ)
```

Звідси легко знайти максимальне значення інтенсивності `I_max` (косинус дорівнює +1) та мінімальне значення `I_min` (косинус дорівнює −1):

```
I_max = I₁ + I₂ + 2 · √(I₁ · I₂) · |γ₁₂(τ)|
I_min = I₁ + I₂ − 2 · √(I₁ · I₂) · |γ₁₂(τ)|
```

Обчислимо формулу видності (контрасту) смуг Майкельсона `V = (I_max − I_min) ÷ (I_max + I_min)`:

```
I_max − I_min = 4 · √(I₁ · I₂) · |γ₁₂(τ)|           [різниця максимумів і мінімумів]
I_max + I_min = 2 · I₁ + 2 · I₂                     [сума максимумів і мінімумів]
```

Ділячи різницю на суму, отримуємо:

```
V = (4 · √(I₁ · I₂) · |γ₁₂(τ)|) ÷ (2 · (I₁ + I₂))
  = (2 · √(I₁ · I₂) ÷ (I₁ + I₂)) · |γ₁₂(τ)|         [загальна формула видності смуг]
```

У найважливішому практичному випадку, коли інтенсивності двох пучків однакові (`I₁ = I₂ = I₀`), вираз під дужками перетворюється на 1, і ми отримуємо пряму рівність:

```
V = |γ₁₂(τ)|      [видність смуг дорівнює модулю ступеня когерентності]
```

Це доводить, що вимірювання контрасту інтерференційних смуг дає прямий експериментальний доступ до модуля функції кореляції хвильових полів.

### Теорема Вінера — Хінчина та часова когерентність

Часова когерентність тісно пов'язана зі спектральним складом хвильового випромінювання. Розглянемо функцію самокогерентності `Γ₁₁(τ) = ⟨ V(t + τ) · V*(t) ⟩`.

За **теоремою Вінера — Хінчина** (Wiener–Khinchin theorem), для стаціонарного випадкового процесу функція самокогерентності `Γ₁₁(τ)` та спектральна густина потужності `S(ν)` утворюють пару взаємних фур'є-перетворень:

```
Γ₁₁(τ) = ∫ S(ν) · exp(i · 2πν · τ) dν      [зворотне фур'є-перетворення спектра]
S(ν) = ∫ Γ₁₁(τ) · exp(−i · 2πν · τ) dτ      [пряме фур'є-перетворення кореляції]
```

Звідси випливає, що розливка спектрального профілю `S(ν)` повністю визначає закон спадання часової когерентності зі зростанням затримки `τ`.

#### 1. Лоренців спектральний профіль

Лоренців профіль виникає при природному радіаційному розширенні спектральних ліній або при зіткненнях атомів у газах під тиском:

```
S(ν) = S₀ ÷ (1 + 4 · (ν − ν₀)² ÷ (Δν)²)      [лоренцева спектральна лінія]
```

Обчислюючи зворотне фур'є-перетворення від лоренцевого профілю за теоремою про лишки в комплексній площині, отримуємо експоненціальний закон спадання самокогерентності:

```
|γ₁₁(τ)| = exp(−2π · Δν · |τ|)      [згасання когерентності для лоренцевої лінії]
```

Час когерентності `τ_c` визначається як момент, у який модуль когерентності зменшується в `e` разів:

```
2π · Δν · τ_c = 1
τ_c = 1 ÷ (2π · Δν)      [час когерентності для лоренцевого профілю]
```

#### 2. Гауссів спектральний профіль

Гауссів профіль спектральної лінії виникає внаслідок доплерівського розширення через хаотичний тепловий рух випромінюючих атомів у газі:

```
S(ν) = S₀ · exp(−4·ln(2) · (ν − ν₀)² ÷ (Δν)²)      [гаусова спектральна лінія]
```

Фур'є-перетворення гаусової функції дає знову гаусову функцію у часовій області:

```
|γ₁₁(τ)| = exp(−π² · (Δν)² · τ² ÷ (4·ln(2)))      [згасання когерентності для гаусової лінії]
```

Час когерентності `τ_c` для гаусової спектральної лінії за рівнем `1/e` становить:

```
τ_c = √(2 · ln(2) ÷ π) ÷ Δν ≈ 0.664 ÷ Δν      [час когерентності для гаусового профілю]
```

В обох випадках виконується фундаментальне співвідношення невизначеності для часу когерентності та спектральної ширини: `τ_c · Δν ≈ 1`.

### Теорема Ван Ціттерта — Церніке: математичне виведення

Теорема Ван Ціттерта — Церніке описує виникнення просторової когерентності при поширенні випромінювання від некогерентного протяжного джерела.

Розглянемо плоске площинне некогерентне джерело `S` у площині `(ξ, η)` з розподілом інтенсивності `I(ξ, η)`. На великій відстані `R` від джерела розташована площина спостереження `(x, y)`.

Кожен крихітний елемент поверхні джерела `dξ dη` випромінює сферичну хвилю з випадковою фазою. Комплексне поле в точці `P₁(x₁, y₁)` від елемента джерела дорівнює:

```
dV₁(t) = A(ξ, η, t) · (exp(i · k · R₁) ÷ R₁) dξ dη      [поле від елемента джерела]
```

де `R₁ = √((x₁ − ξ)² + (y₁ − η)² + R²)` — відстань від елемента джерела до точки `P₁`.

Оскільки випромінювання різних елементів некогерентного джерела є статистично незалежним (`⟨A(ξ₁, η₁) · A*(ξ₂, η₂)⟩ = 0` при `ξ₁ ≠ ξ₂`), інтегрування перехресних членів дає нуль. Обираючи наближення Фраунгофера (`R >> ξ, η, x, y`), різницю відстаней можна розкласти в ряд:

```
R₁ − R₂ ≈ ((x₂ − x₁)·ξ + (y₂ − y₁)·η) ÷ R      [параксіальне наближення різниці ходу]
```

Інтегруючи по всій поверхні некогерентного джерела, отримуємо функцію просторової взаємної когерентності:

```
Γ₁₂(0) = (exp(i·ψ) ÷ R²) · ∫∫ I(ξ, η) · exp(−i · k · (Δx·ξ + Δy·η) ÷ R) dξ dη
```

де `Δx = x₁ − x₂`, `Δy = y₁ − y₂`, `k = 2π / λ`, а `ψ` — загальний фазовий множник.

Нормуючи цей вираз на повну інтенсивність джерела, отримуємо теорему Ван Ціттерта — Церніке для нормованого комплексного ступеня просторової когерентності:

```
γ₁₂(0) = (∫∫ I(ξ, η) · exp(−i · k · (Δx·ξ + Δy·η) ÷ R) dξ dη) ÷ (∫∫ I(ξ, η) dξ dη)
```

Словесне формулювання теореми: **комплексний ступінь просторової когерентності полів у двох точках віддаленого некогерентного джерела дорівнює нормованому двовимірному фур'є-перетворенню від розподілу інтенсивності на поверхні цього джерела**.

#### Окремий випадок: Кругле рівномірно освітлене джерело

Для круглого джерела радіуса `a` з постійною інтенсивністю `I₀` (наприклад, диска зірки кутового діаметра `θ = 2a / R`) двовимірне фур'є-перетворення у полярних координатах інтегрується через функцію Бесселя першого роду першого порядку `J₁(x)`:

```
|γ₁₂(0)| = | 2 · J₁(x) ÷ x |      [ступінь когерентності для круглого джерела]
x = π · d · θ ÷ λ₀
```

де `d = √(Δx² + Δy²)` — відстань між двома точками спостереження `P₁` та `P₂` на екрані.

Перший нуль функції Бесселя `J₁(x) = 0` розташований у точці `x = 3.8317`. Звідси знаходимо критичну відстань між точками `d_c`, при якій просторова когерентність вперше спадає до нуля (`|γ| = 0`):

```
π · d_c · θ ÷ λ₀ = 3.8317
d_c = 3.8317 · λ₀ ÷ (π · θ) = 1.2197 · λ₀ ÷ θ ≈ 1.22 · λ₀ ÷ θ      [радіус просторової когерентності]
```

Ця фундаментальна формула є математичною основою роботи двопроменевих оптичних та радіоастрономічних інтерферометрів.

### Квантові кореляційні функції Глаубера

У квантовій оптиці електричне поле описується не комплексною функцією, а оператором напруженості електричного поля `E(+)(r, t)` та `E(-)(r, t)`.

Рой Глаубер визначив квантову кореляційну функцію першого порядку через нормально впорядковане середнє квантовомеханічних операторів:

```
G⁽¹⁾(r₁, t₁; r₂, t₂) = ⟨ Tr( ρ · E(-)(r₁, t₁) · E(+)(r₂, t₂) ) ⟩      [квантова кореляція 1-го порядку]
```

де `ρ` — оператор щільності квантового стану поля.

Квантова кореляційна функція другого порядку (кореляція інтенсивностей) визначається як:

```
G⁽²⁾(r₁, t₁; r₂, t₂; r₂, t₂; r₁, t₁) = ⟨ E(-)(r₁, t₁) · E(-)(r₂, t₂) · E(+)(r₂, t₂) · E(+)(r₁, t₁) ⟩
```

Нормована квантова кореляційна функція другого порядку в одній точці простору `g⁽²⁾(τ)` виражається через оператори народження `a†` та знищення `a` фотонів у моді поля:

```
g⁽²⁾(τ) = ⟨ a†(t) · a†(t + τ) · a(t + τ) · a(t) ⟩ ÷ ⟨ a†(t) · a(t) ⟩²      [квантова кореляція інтенсивностей]
```

Для нульової затримки `τ = 0` через оператор кількості фотонів `n̂ = a† a` ця формула набуває вигляду:

```
g⁽²⁾(0) = ⟨ n̂ · (n̂ − 1) ⟩ ÷ ⟨ n̂ ⟩² = ( ⟨n̂²⟩ − ⟨n̂⟩ ) ÷ ⟨n̂⟩²      [квантова статистика фотонів при τ=0]
```

Розглянемо три фундаментальні квантові стани полів:

1. **Фоківський стан з фіксованою кількістю фотонів `|N⟩`:**
   ```
   ⟨n̂⟩ = N,  ⟨n̂²⟩ = N²
   g⁽²⁾(0) = (N² − N) ÷ N² = 1 − 1 ÷ N
   ```
   Для однофотонного стану (`N = 1`): `g⁽²⁾(0) = 0`. Це доводить, що одиночний фотон не може розщепитися й викликати одночасне спрацьовування двох детекторів.

2. **Когерентний стан Глаубера `|α⟩` (ідеальний лазер):**
   Пуассонівський розподіл фотонів: `⟨n̂²⟩ = ⟨n̂⟩² + ⟨n̂⟩`.
   ```
   g⁽²⁾(0) = ( ⟨n̂⟩² + ⟨n̂⟩ − ⟨n̂⟩ ) ÷ ⟨n̂⟩² = 1      [пуассонівська статистика лазера]
   ```

3. **Теплове або хаотичне випромінювання (Бозе — Ейнштейнівський розподіл):**
   Дисперсія кількості фотонів: `⟨n̂²⟩ = 2 · ⟨n̂⟩² + ⟨n̂⟩`.
   ```
   g⁽²⁾(0) = ( 2·⟨n̂⟩² + ⟨n̂⟩ − ⟨n̂⟩ ) ÷ ⟨n̂⟩² = 2      [теплове фотонне групування]
   ```

Цей математичний апарат утворює міцний мост між класичною оптикою Френеля — Майкельсона та сучасною квантовою інженерією.
