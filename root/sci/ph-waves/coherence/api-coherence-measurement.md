# 📋 Довідник параметрів, методів та приладів вимірювання когерентності

Цей довідник містить систематизований опис фізичних параметрів, номенклатури величин, методів вимірювання, специфікацій джерел випромінювання та інженерного контракту обладнання для оцінки часової і просторової когерентності хвильових полів.

### 1. Номенклатура фізичних величин та параметрів когерентності

Вимірювання та аналіз когерентності спирається на чітку систему математичних і фізичних параметрів, що описують часову узгодженість, просторову структурованість та квантово-статистичні характеристики випромінювання.

У таблиці нижче зведено основні номенклатурні величини, їхні зв'язки з іншими параметрами та фізичний зміст у прикладних оптичних і радіофізичних вимірюваннях.

| Величина | Позначення | Формула зв'язку | Одиниці | Фізичний зміст |
| :--- | :--- | :--- | :--- | :--- |
| **Центральна довжина хвилі** | `λ₀` | `λ₀ = c ÷ ν₀` | нм, мкм, м | Середня довжина хвилі випромінювання у середовищі |
| **Ширина спектра (довжина)** | `Δλ` | `Δλ = (λ₀² ÷ c) · Δν` | нм, пм | Ширина спектральної лінії на піввисоті (FWHM) |
| **Ширина спектра (частота)** | `Δν` | `Δν = c · Δλ ÷ λ₀²` | Гц, МГц, THz | Спектральна смуга частот |
| **Час когерентності** | `τ_c` | `τ_c ≈ 1 ÷ Δν = λ₀² ÷ (c · Δλ)` | с, пс, фс | Час, протягом якого хвиля зберігає пам'ять про фазу |
| **Довжина часової когерентності**| `L_c` | `L_c = c · τ_c ≈ λ₀² ÷ Δλ` | м, мм, мкм | Довжина хвильового цуга в середовищі |
| **Кутовий розмір джерела** | `θ` | `θ = d_src ÷ R` | рад, кутові секунди | Кут, під яким джерело видно з точки спостереження |
| **Радіус просторової когерентності**| `r_c` | `r_c = 1.22 · λ₀ ÷ θ` | мм, мкм | Відстань між точками фронту, де `|γ| ≈ 0.88` |
| **Площа когерентності** | `A_c` | `A_c = π · r_c² ≈ λ₀² ÷ Ω` | мм², мкм² | Площа поперечного перерізу з фазовою узгодженістю |
| **Ступінь когерентності** | `|γ₁₂(τ)|` | `|γ₁₂(τ)| = |Γ₁₂(τ)| ÷ √(I₁ · I₂)` | безрозмірна (`0..1`) | Модуль нормованої взаємної кореляційної функції |
| **Видність смуг (контраст)** | `V` | `V = (I_max − I_min) ÷ (I_max + I_min)` | безрозмірна (`0..1`) | Контраст інтерференційних смуг на детекторі |
| **Кореляція 2-го порядку** | `g⁽²⁾(τ)` | `g⁽²⁾(τ) = ⟨I(t)·I(t+τ)⟩ ÷ ⟨I(t)⟩²` | безрозмірна | Квантова статистична кореляція фотонів |

#### Фізичні правила перерахунку параметрів

1. **Залежність довжини когерентності від середовища:** При поширенні хвилі у середовищі з показником заломлення `n` фазова швидкість зменшується до `v = c / n`. Відповідно, довжина когерентності у середовищі зменшується: `L_c(n) = L_c(вакуум) / n`. Час когерентності `τ_c` при цьому залишається незмінним, оскільки визначається шириною спектра `Δν`.
2. **Співвідношення між геометричною та спектральною когерентністю:** Повна когерентність визначається як добуток ступеня часової когерентності `γ_t(τ)` на ступінь просторової когерентності `γ_s(r₁₂, 0)`. Загальний комплексний ступінь когерентності факторнізується: `γ₁₂(τ) = γ_s(r₁₂, 0) · γ_t(τ)`.

### 2. Специфікація та класифікація джерел випромінювання

Параметри когерентності істотно відрізняються залежно від фізичного механізму випромінювання. Джерела поділяють на три основні класи:
- **Теплові та некогерентні джерела (спонтанне випромінювання):** мають широкий спектр `Δλ`, дуже малу довжину когерентності `L_c` (мікрони) та гаусову статистику фотонів з ефектом групування `g⁽²⁾(0) = 2`.
- **Суперлюмінесцентні джерела (SLD):** мають високу просторову когерентність (легко вводяться в одномодове волокно), але низьку часову когерентність (широкий спектр `Δλ ≈ 30–80 нм`). Вони є ідеальними для оптичної когерентної томографії (OCT) та волоконно-оптичних гіроскопів.
- **Лазерні джерела (вимушене випромінювання):** мають високу монохроматичність, довжину часової когерентності від сантиметрів до сотень кілометрів та пуассонівську статистику `g⁽²⁾(0) = 1`.

У таблиці нижче наведено типові паспортні значення параметрів когерентності для комерційних джерел випромінювання.

| Джерело випромінювання | Центральна `λ₀` | Ширина спектра `Δλ` | Довжина когерентності `L_c` | Час когерентності `τ_c` | Статистика `g⁽²⁾(0)` |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Сонячне світло (видиме)** | 550 нм | ~300 нм | ~1.0 мкм | ~3.3 фс | 2.0 (теплове) |
| **Лампа розжарювання** | 800 нм | ~400 нм | ~1.6 мкм | ~5.3 фс | 2.0 (теплове) |
| **Світлодіод (LED)** | 633 нм | ~30 нм | ~13 мкм | ~45 фс | 2.0 (гаусове) |
| **Суперлюмінесцентний діод (SLD)**| 840 нм | ~50 нм | ~14 мкм | ~46 фс | 2.0 (низькокогерентне) |
| **Газоразрядна натрієва лампа** | 589 нм | ~0.6 нм | ~0.58 мм | ~1.9 пс | 2.0 (теплове) |
| **Лазерний діод (мультимодовий)** | 650 нм | ~1.5 нм | ~0.28 мм | ~0.93 пс | ~1.1–1.5 |
| **He-Ne лазер (одномодовий)** | 632.8 нм | ~0.002 нм (1.5 ГГц)| ~20 см | ~0.67 нс | 1.0 (когерентне) |
| **DFB одночастотний лазер** | 1550 нм | ~10⁻⁶ нм (100 кГц)| ~3 км | ~10 мкс | 1.000 (когерентне) |
| **Однофотоне джерело (квантове)**| 780 нм | ~0.01 нм | ~60 мм | ~200 пс | 0.00 (антигрупування) |

### 3. Класифікація вимірювальних схем та оптичних інтерферометрів

#### 3.1. Вимірювання часової когерентності (Інтерферометрія Майкельсона)

Метод інтерферометра Майкельсона базується на діленні вхідної хвилі на два промені з наступним введенням контрольованої часової затримки `τ = Δx / c` за допомогою рухомого дзеркала.

- **Фізична схема:** Вхідний пучок світла ділиться напівпрозорим дзеркалом (Beam Splitter 50:50) на два пучки. Перший пучок відбивається від нерухомого дзеркала `Д₁`, другий — від рухомого дзеркала `Д₂`, зсунутого на відстань `Δd`. Рекомбіновані пучки спрямовуються на фотодетектор.
- **Різниця ходу:** `Δx = 2 · Δd`.
- **Алгоритм обчислення видності:**
  1. Сканується позиція рухомого дзеркала `Δd` з кроком, значно меншим за `λ₀ / 4`.
  2. Вираховується локальна огинаюча інтенсивності `I_max(Δx)` та `I_min(Δx)`.
  3. Обчислюється видність смуг: `V(Δx) = (I_max(Δx) − I_min(Δx)) ÷ (I_max(Δx) + I_min(Δx))`.
- **Визначення довжини когерентності:** За довжину когерентності `L_c` приймається відстань `Δx`, на якій видність смуг зменшується у `e` разів від свого максимального значення при нульовій різниці ходу `V(0)`.
- **Фур'є-спектроскопія:** Комплексний спектральний склад випромінювання `S(ν)` обчислюється як пряме швидке перетворення Фур'є (FFT) від отриманої інтерферограми.

#### 3.2. Вимірювання просторової когерентності (Метод двох щілин Янга)

Метод застосовується для вимірювання радиуса просторової когерентності `r_c` хвильового фронту.

- **Фізична схема:** У непрозорому екрані роблять дві паралельні вузькі щілини, відстань між якими `d` можна регулювати (або використовують набір масок із різними значеннями `d`).
- **Методика вимірювання:**
  1. На екрані спостереження вимірюється контраст інтерференційних смуг `V(d)` для кожної маски.
  2. Будується графічна залежність `V(d)` від відстані між щілинами.
  3. Значення `d`, при якому видність спадає до `0.88` або `0.5`, визначає радіус просторової когерентності `r_c`.
- **Відновлення кутового розміру джерела:** За теоремою Ван Ціттерта — Церніке, виміряна крива `V(d)` дає змогу розрахувати кутовий розмір джерела `θ = 1.22 · λ₀ / d_zero`, де `d_zero` — відстань першого нуля видності.

#### 3.3. Вимірювання квантової кореляції 2-го порядку (Схема HBT)

Схема Хенбері Брауна — Твісса вимірює статистичні кореляції інтенсивностей для визначення типу випромінювання та квантових властивостей джерела.

- **Апаратний склад:**
  - Напівпрозорий світлодільник 50:50.
  - Два однофотонні аварійні фотодіоди (SPAD), що працюють у режимі рахунку фотонів.
  - Оптичні затримкові лінії.
  - Часово-цифровий перетворювач (TDC / Time-Correlator) з часовою роздільністю від 1 до 10 пікосекунд.
- **Методика вимірювання:**
  1. Детектор 1 реєструє фотон і надсилає сигнал «Start» на часовий корелометр.
  2. Детектор 2 реєструє наступний фотон і надсилає сигнал «Stop».
  3. Будується гістограма розподілу кількості відліків `N(τ)` від часу затримки `τ`.
  4. Нормуванням гістограми на випадковий фоновий рівень обчислюється `g⁽²⁾(τ)`.

### 4. Специфікація систем оптичної когерентної томографії (OCT)

Оптична когерентна томографія (OCT) є однією з найважливіших медичних й інженерних технологій, що спирається на низку параметрів когерентності.

У таблиці нижче наведено специфікацію параметрів сучасних систем OCT різного типу.

| Параметр OCT | Формула розрахунку | TD-OCT (Time-Domain) | SD-OCT (Spectral-Domain) | SS-OCT (Swept-Source) |
| :--- | :--- | :--- | :--- | :--- |
| **Джерело світла** | — | Суперлюмінесцентний діод (SLD) | Широкосмуговий SLD | Перестроювальний лазер (Swept Laser) |
| **Центральна довжина `λ₀`** | — | 840 нм / 1310 нм | 840 нм / 1060 нм | 1060 нм / 1310 нм |
| **Аксиальна роздільність `Δz`** | `Δz = (2·ln2 ÷ π) · (λ₀² ÷ Δλ)` | 10 – 15 мкм | 3 – 7 мкм | 5 – 10 мкм |
| **Поперечна роздільність `Δx`** | `Δx = 1.22 · λ₀ ÷ NA` | 15 – 20 мкм | 10 – 15 мкм | 10 – 15 мкм |
| **Глибина сканування `z_max`** | `z_max = λ₀² ÷ (4 · n · δλ)` | 2 – 3 мм | 1.5 – 2.5 мм | 5 – 12 мм |
| **Швидкість сканування** | А-сканів на секунду | 400 – 2000 Гц | 20,000 – 150,000 Гц | 100,000 – 1,000,000 Гц |
| **Динамічний діапазон (SNR)**| `10·log₁₀(P_signal / P_noise)` | 90 дБ | 105 дБ | 110 дБ |

#### Ключові інженерні залежності у системах OCT:

1. **Незалежність аксиальної та поперечної роздільності:** Аксиальна роздільність `Δz` залежить **виключно** від ширини спектра джерела `Δλ` (часової когерентності). Поперечна роздільність `Δx` залежить від числової апертури об'єктива `NA` (просторової когерентності та фокусування). Це дає змогу отримувати високу роздільність у глибину без звуження поля зору.
2. **Вплив хроматичної дисперсії:** Поширення низькокогерентного випромінювання через біологічні тканини чи лінзи супроводжується хроматичною дисперсією середовища, що розширює хвильовий цуг і погіршує аксиальну роздільність `Δz`. Для компенсації дисперсії в опорне плече інтерферометра вводять дисперсійно-узгоджені скляні блоки або застосовують цифрову фазову компенсацію.

### 5. Контракт інтерфейсу конфігурації вимірювального комплексу (JSON Schema)

Для керування вимірювальними комплексами оцінки когерентності застосовується структурований JSON-контракт конфігурації апаратури.

```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "title": "CoherenceMeasurementConfig",
  "type": "object",
  "properties": {
    "system_id": { "type": "string" },
    "source": {
      "type": "object",
      "properties": {
        "type": { "type": "string", "enum": ["laser", "led", "sld", "thermal"] },
        "wavelength_center_nm": { "type": "number", "minimum": 200.0, "maximum": 2000.0 },
        "spectral_fwhm_nm": { "type": "number", "minimum": 0.0001 }
      },
      "required": ["type", "wavelength_center_nm", "spectral_fwhm_nm"]
    },
    "michelson_stage": {
      "type": "object",
      "properties": {
        "max_stroke_mm": { "type": "number" },
        "step_size_nm": { "type": "number" },
        "velocity_mm_s": { "type": "number" }
      },
      "required": ["max_stroke_mm", "step_size_nm"]
    },
    "detector": {
      "type": "object",
      "properties": {
        "sampling_rate_hz": { "type": "number" },
        "integration_time_us": { "type": "number" },
        "dynamic_range_bits": { "type": "integer" }
      },
      "required": ["sampling_rate_hz", "integration_time_us"]
    }
  },
  "required": ["system_id", "source", "michelson_stage", "detector"]
}
```

Приклад реального екземпляра конфігураційного файла для оптичного корелометра:

```json
{
  "system_id": "COH-LAB-2026-V4",
  "source": {
    "type": "sld",
    "wavelength_center_nm": 1310.0,
    "spectral_fwhm_nm": 60.0
  },
  "michelson_stage": {
    "max_stroke_mm": 20.0,
    "step_size_nm": 50.0,
    "velocity_mm_s": 1.0
  },
  "detector": {
    "sampling_rate_hz": 100000.0,
    "integration_time_us": 10.0,
    "dynamic_range_bits": 16
  }
}
```

Цей контракт гарантує відтворюваність експериментальних даних і дає змогу автоматизувати процес вимірювання часової та просторової когерентності в лабораторних й промислових умовах.
