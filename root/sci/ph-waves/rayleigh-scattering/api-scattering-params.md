# 📋 Довідник параметрів розсіяння світла та портів спектрального розрахунку

У цій вставці зібрано системні параметри, фізичні константи, порівняльні специфікації режимів розсіяння електромагнітного випромінювання та структури даних для чисельного розрахунку оптичного згасання в атмосфері Землі та волоконних світловодах.

### 1. Класифікація та межі застосовності режимів розсіяння світла

Режим взаємодії оптичного випромінювання з речовиною визначається безрозмірним **параметром розміру** `x`, який пов'язує радіус частинки `a` із довжиною світлової хвилі `λ` у середовищі:

```
x = 2 · π · a / λ
```

За залежністю від параметра `x` оптичні явища розсіяння поділяються на три фундаментальні категорії, кожна з яких описується власним математичним апаратом:

#### А. Релеєвський режим (`x ≪ 0.1`)
Застосовується у випадках, коли розмір частинок або оптичних неоднорідностей є набагато меншим за довжину хвилі (`a ≪ λ / 10`). Головною фізичною рисою є квазістаціонарний характер поляризації частинки та сувора симетрія дипольного випромінювання.
- **Спектральна залежність**: інтенсивність розсіяного світла пропорційна `λ⁻⁴`.
- **Кутова фазова функція**: симетрична відносно екватора `P(θ) = (3/4) · (1 + cos² θ)`.
- **Поляризація**: при розсіянні неполяризованого світла під кутом `90°` ступінь лінійної поляризації досягає 100%.

#### Б. Режим Мі (`0.1 ≤ x ≤ 10`)
Виникає при взаємодії світла з частинками, розмір яких сумірний із довжиною хвилі (`a ≈ λ`). Фазові затримки електромагнітної хвилі в різних точках об'єму частинки призводять до складної внутрішньої інтерференції.
- **Спектральна залежність**: слабка залежність від довжини хвилі (від `λ⁻²` до `λ⁰`), що пояснює білястий колір хмар, туману та пилових завіс.
- **Кутова фазова функція**: виражена асиметрія з різким переважанням розсіяння прямо вперед (індикатриса має вузький передній пік).
- **Поляризація**: низька або осцилююча залежно від кута й параметра розміру.

#### В. Режим геометричної оптики (`x ≫ 10`)
Спостерігається на макроскопічних об'єктах (`a ≫ 10·λ`), де хвильовими ефектами можна знехтувати, а поширення світла описується законами відбиття, заломлення Френеля та геометричного трасування променів.

Нижче наведено порівняльну специфікацію фізичних параметрів для різних режимів розсіяння:

| Режим розсіяння | Параметр розміру `x` | Залежність інтенсивності `I(λ)` | Кутовий розподіл `P(θ)` | Ступінь поляризації (під 90°) | Приклади середовищ |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Релеєвське** (*Rayleigh*) | `x ≪ 0.1` (`a ≪ λ`) | `∝ λ⁻⁴` | Симетричний: `1 + cos² θ` | 100% (лінійна) | Молекули газів (`N₂`, `O₂`), флуктуації в склі |
| **Режим Мі** (*Mie*) | `0.1 ≤ x ≤ 10` (`a ≈ λ`) | `∝ λ⁻⁰·⁵…λ⁻¹` | Сильно витягнутий вперед | Низький (0…20%) | Аерозолі, пил, туман, хмари, молочна емульсія |
| **Геометрична оптика** | `x ≫ 10` (`a ≫ λ`) | `∝ λ⁰` (незалежно) | Промені відбиття/заломлення | Закони Френеля | Дощові краплі, зеренця піску, лінзи |
| **Комбінаційне (Раман)** | `x ≪ 0.1` (молекулярне) | `∝ (λ₀ ± Δλ)⁻⁴` | Квазіізотропний | Часткова | Оптичні фонони, зсув частоти молекулярних коливань |
| **Мандельштама — Бріллюена** | `x ≪ 0.1` (акустичне) | `∝ λ⁻⁴` | Двокомпонентний дублет | Лінійна | Акустичні гіперзвукові хвилі (акустичні фонони) |

### 2. Спектральні константи релеєвського розсіяння в атмосфері Землі

Нижче наведено таблицю нормативних показників розсіяння світла у сухому атмосферному повітрі при стандартній міжнародній атмосфері (ISA: тиск `P₀ = 1013.25 гПа`, температура `T₀ = 288.15 K`, числова концентрація молекул `N_s = 2.547 · 10²⁵ м⁻³`).

Значення показника заломлення обчислені за формулою Едлена, а ефективні перерізи — з урахуванням фактора анізотропії Кабанна `F_K = 1.054`:

| :--- | :--- | :--- | :--- | :--- | :--- |
| **380** | Ультрафіолет A | 2.793 | `1.472 · 10⁻²⁶` | 0.3749 | 0.3187 |
| **400** | Фіолетовий | 2.784 | `1.181 · 10⁻²⁶` | 0.3008 | 0.2557 |
| **450** | Синій | 2.766 | `7.334 · 10⁻²⁷` | 0.1868 | 0.1588 |
| **532** | Зелений (лазер) | 2.747 | `3.635 · 10⁻²⁷` | 0.0926 | 0.0787 |
| **550** | Жовто-зелений (пик) | 2.744 | `3.161 · 10⁻²⁷` | 0.0805 | 0.0684 |
| **632.8** | Червоний (He-Ne) | 2.734 | `1.761 · 10⁻²⁷` | 0.0449 | 0.0381 |
| **780** | Близький ІЧ | 2.724 | `7.632 · 10⁻²⁸` | 0.0194 | 0.0165 |
| **1064** | Інфрачервоний (Nd:YAG)| 2.716 | `2.158 · 10⁻²⁸` | 0.0055 | 0.0047 |

Аналіз даних таблиці показує, що при переході від ультрафіолетового краю видимого діапазону (`380 нм`) до телекомунікаційного інфрачервоного (`1550 нм`) коефіцієнт об'ємного розсіяння в повітрі зменшується більш ніж у 300 разів. Саме тому інфрачервоні системи нічного бачення та лазерні лідари дають значно більшу дальність дії в умовах атмосферного серпанку.

Детальний аналіз наведених табличних даних дозволяє виявити важливу фізичну закономірність для проектування оптико-електронних приладів спостереження та лазерного дальнометрування:

1. **Спектральний контраст атмосфери**: У фіолетовому діапазоні (`400 нм`) оптична товщина чистої атмосфери в зеніті досягає `τ_R = 0.2557`. Це означає, що понад 22% енергії ультрафіолетового й короткохвильового видимого випромінювання розсіюється повітряним стовпом, створюючи яскравий атмосферний вуаль (серпанок), який суттєво знижує просторовий контраст зображень.
2. **Перевага інфрачервоних лазерних систем**: На довжині хвилі лазера на алюмо-ітрієвому гранаті `Nd:YAG` (`1064 нм`) коефіцієнт об'ємного розсіяння становить лише `0.0055 км⁻¹`, що у 55 разів менше, ніж для фіолетового світла. Це пояснює високу завадостійкість лазерних дальномірів та оптичних систем зв'язку у напівпровідниковому й інфрачервоному діапазонах.

### 3. Фактори анізотропії та деполяризації Кабанна (`F_K`)

Більшість молекул атмосферних газів не є сферично симетричними. Наприклад, двоатомні молекули азоту `N₂` та кисню `O₂` мають витягнуту геометричну форму, що спричиняє анізотропію їхньої електричної поляризованості: поляризованість вздовж осі молекули відрізняється від поляризованості у поперечному напрямку.

У результаті розсіяне під кутом `90°` неполяризоване світло має незначну частку неполяризованого випромінювання (деполяризацію). Для врахування цієї анізотропії у формули розсіяння вводять **коефіцієнт деполяризації Кабанна** `F_K`:

```
F_K = (6 + 3 · ρ_n) / (6 - 7 · ρ_n)
```

де `ρ_n` — коефіцієнт деполяризації для неполяризованого падаючого світла.

Нижче наведено експериментально виміряні значення параметрів деполяризації для основних компонентів сухий земної атмосфери на довжині хвилі `532 нм`:

| Газ | Молярна частка в повітрі (%) | Коефіцієнт деполяризації `ρ_n` | Фактор Кабанна `F_K` |
| :--- | :--- | :--- | :--- |
| **Азот (`N₂`)** | 78.084% | 0.0210 | 1.039 |
| **Кисень (`O₂`)** | 20.946% | 0.0580 | 1.111 |
| **Аргон (`Ar`)** | 0.934% | 0.0000 (ідеальна сфера) | 1.000 |
| **Вуглекислий газ (`CO₂`)**| 0.042% | 0.0780 | 1.154 |
| **Сухе атмосферне повітря**| 100.000% | 0.0279 | 1.054 |

З таблиці видно, що аргон, володіючи повністю заповненою електронною оболонкою та сферичною симетрією, має строго нульовий коефіцієнт деполяризації (`F_K = 1.000`). Натомість вуглекислий газ `CO₂` володіє найбільшою анізотропією поляризованості серед усіх основних компонентів атмосфери (`F_K = 1.154`).

Розглянемо детальніше фізичний механізм виникнення деполяризації Кабанна. Коли світлова хвиля падає на анізотропну молекулу, наведений індукований дипольний момент `p` не збігається за напрямком із вектором електричного поля падаючої хвилі `E₀`. Замість цього зв'язок між векторами описується тензором поляризованості другого рангу:

```
p_i = α_ij · E_j
```

Через хаотичну орієнтацію молекул у газі усереднений по всіх напрямках тензор дає дві незалежні складові розсіяного поля: скалярне (ізотропне) розсіяння та анізотропне розсіяння (тензорне). Скалярне розсіяння утворює повністю поляризовану компоненту під кутом 90°, тоді як тензорне розсіяння створює неполяризовану компоненту Кабанна. У точних атмосферних розрахунках нехтування цим ефектом призводить до систематичної помилки визначення оптичної товщини на 5.4%.

### 4. Релеєвське розсіяння в оптичних волокнах (плавлений кварц `SiO₂`)

У технології волоконно-оптичного зв'язку релеєвське розсіяння відіграє фундаментальну роль. На відміну від газів, де розсіяння відбувається на рухомих молекулах, у твердому склі розсіювачами є **заморожені флуктуації густини та хімічного складу**, які зафіксувалися у структурі аморфного плавленого кварцу `SiO₂` під час охолодження витягнутого волокна з розплаву при температурі скловання (`T_g ≈ 1400 °C`).

Коефіцієнт згасання в одномодовому волокні за рахунок релеєвського розсіяння виражається емпіричною формулою:

```
α_fiber(λ) = A_R / λ⁴   [дБ / км, де λ в мкм]
```

де `A_R` — коефіцієнт розсіяння Релея для конкретної марки кварцевого волокна (`A_R ≈ 0.75…0.82 дБ · мкм⁴ / км`).

Нижче наведено порівняльну таблицю згасання в стандартному одномодовому волокні SMF-28 у різних оптичних вікнах прозорості:

| Телеком-вікно | Довжина хвилі `λ` (нм) | Релеєвське згасання `α_R` (дБ/км) | Поглинання `OH⁻` та інфрачервоний хвіст (дБ/км) | Повне втрати у волокні (дБ/км) |
| :--- | :--- | :--- | :--- | :--- |
| **Оригінальне (O-band)** | 1310 | 0.278 | 0.042 | **0.320** |
| **Розширене (E-band)** | 1383 | 0.223 | 0.027 (Low-Water Peak) | **0.250** |
| **Смуга C (C-band)** | 1550 | 0.140 | 0.050 (мінімум загасання) | **0.190** |
| **Довгохвильове (L-band)**| 1625 | 0.116 | 0.094 (зростання ІЧ-поглинання) | **0.210** |

З даного аналізу випливає ключовий інженерний висновок: довжина хвилі `1550 нм` обрана для магістрального зв'язку тому, що вона знаходиться у точці ідеального компромісу: розсіяння Релея вже впало до `0.14 дБ/км`, а багатофононне інфрачервоне поглинання кварцевої ґратки ще не почало стрімко зростати.

Варто підкреслити, що заморожені флуктуації в оптичному волокні мають двояку природу. Перша складова — це термодинамічні флуктуації густини чистого плавленого кварцу `SiO₂`, які фундаментально залежать від температури скловання `T_g` та ізотермічної стисливості розплаву. Друга складова виникає при легуванні серцевини волокна діоксидом германію `GeO₂` для підвищення показника заломлення. Флуктуації локальної концентрації `GeO₂` створюють додаткове мікроскопічне розсіяння. Зменшення швидкості витягування волокна та оптимізація профілю легування дозволяють знизити коефіцієнт `A_R` до рекордних значень `0.68 дБ · мкм⁴ / км` у сучасних ультранизьковтратних волокнах (Ultra-Low Loss Fibers, ULL).

### 5. Інтерфейсні специфікації та структури даних для програмних моделей

Нижче наведено приклад інтерфейсного контракту C++ для передачі параметрів атмосферного розсіяння у модулях чисельного моделювання радіаційного переносу випромінювання (наприклад, у системах класу MODTRAN, LibRadtran або 6S).

Даний інтерфейс розроблено з урахуванням сучасних вимог до розробки високоефективного оптичного софту:
- Використання концепції об'єктно-орієнтованого поліморфізму для підтримки різних моделей атмосфери (US Standard 1976, Tropical, Midlatitude Summer);
- Застосування семантики переміщення та контейнерів `std::vector` для високої швидкодії при роботі із деталізованими спектральними сітками (понад 10 000 довжин хвиль);
- Обов'язкове використання атрибутів `[[nodiscard]]` та `noexcept` для запобігання втратам результатів розрахунку.

```cpp
#ifndef RAYLEIGH_SCATTERING_API_HPP
#define RAYLEIGH_SCATTERING_API_HPP

#include <cstdint>
#include <vector>
#include <string>

namespace AtmosphericOptics {

/**
 * @brief Структура фізичних параметрів атмосферного шару
 */
struct AtmosphericLayerProfile {
    double altitude_km;            ///< Висота шару над рівнем моря (км)
    double pressure_hpa;           ///< Атмосферний тиск (гПа)
    double temperature_k;          ///< Температура (К)
    double molecular_density_m3;   ///< Концентрація молекул (м^-3)
    double relative_humidity_pct;  ///< Відносна вологість (%)
};

/**
 * @brief Результати спектрального розрахунку розсіяння Релея
 */
struct RayleighScatteringOutput {
    double wavelength_nm;          ///< Довжина хвилі (нм)
    double cross_section_cm2;      ///< Ефективний переріз розсіяння (см^2)
    double volume_coeff_km1;       ///< Об'ємний коефіцієнт розсіяння (км^-1)
    double optical_depth;          ///< Зенітна оптична товщина шару
    double depolarization_factor;  ///< Фактор деполяризації Кабанна F_K
};

/**
 * @brief Інтерфейс калькулятора розсіяння Релея
 */
class IRayleighCalculator {
public:
    virtual ~IRayleighCalculator() = default;

    /**
     * @brief Розрахунок профілю оптичної товщини для заданого спектрального діапазону
     * @param layers Вектор атмосферних шарів
     * @param wavelengths_nm Вектор довжин хвиль для розрахунку
     * @return Вектор розрахованих результатів для кожної довжини хвилі
     */
    [[nodiscard]] virtual std::vector<RayleighScatteringOutput> compute_profile(
        const std::vector<AtmosphericLayerProfile>& layers,
        const std::vector<double>& wavelengths_nm) const = 0;
};

} // namespace AtmosphericOptics

#endif // RAYLEIGH_SCATTERING_API_HPP
```

Даний контракт використовується при розробці сучасних оптико-електронних систем, лазерних дальномірів, лідарів атмосферного зондування та модулів фотометричної корекції супутникових знімків у дистанційному зондуванні Землі.
