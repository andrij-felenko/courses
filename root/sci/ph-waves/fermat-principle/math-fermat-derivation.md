# 🧮 Варіаційне числення та рівняння ейконала в принципі Ферма

Ця математична вставка містить строгий аналітичний апарат варіаційного числення для принципу Ферма. У ній наведено вивід систем диференціальних рівнянь світлових променів у неоднорідному середовищі, детальний математичний розбір першої та другої варіацій оптичного шляху для дзеркал різної кривизни, аналіз точок каустики та розбудову короткохвильової границі рівняння Гельмгольца до рівняння ейконала.

## Варіаційна формулювання оптичного шляху

Нехай траєкторія світлового променя задається тривимірним радіус-вектором `r(s) = (x(s), y(s), z(s))`, де `s` — природний параметр (довжина дуги траєкторії, виміряна вздовж кривої). Елемент довжини дуги задається квадратним диференціалом:

```
ds² = dx² + dy² + dz² = |dr/ds|² ds²
```

Звідси випливає фундаментальна тотожність для одиничного дотичного вектора `u = dr/ds`:

```
|u|² = |dr/ds|² = (dx/ds)² + (dy/ds)² + (dz/ds)² = 1
```

Оптична довжина шляху (Optical Path Length, OPL) `L` для траєкторії між фіксованими початковою точкою `A = r(s₀)` та кінцевою точкою `B = r(s₁)` у середовищі з безперервно змінним показником заломлення `n(r)` визначається як функціонал:

```
L[r] = ∫[s₀ to s₁] n(r(s)) ds
```

Варіаційний принцип Ферма стверджує, що реальна траєкторія світлового променя становить стаціонарну точку функціонала `L[r]`. Це означає, що перша варіація функціонала `δL` повинна дорівнювати нулю для довільних гладких варіацій траєкторії `δr(s)`, які обнуляються на кінцях `δr(s₀) = δr(s₁) = 0`:

```
δL = δ ∫[s₀ to s₁] n(r(s)) ds = 0
```

Для аналітичного виводу рівнянь руху параметризуємо траєкторію довільним скалярним параметром `t ∈ [t₀, t₁]`. Тоді `r = r(t)`, а елемент довжини дуги записується через похідну за параметром `r' = dr/dt`:

```
ds = |r'| dt = sqrt(x'² + y'² + z'²) dt
```

Підінтегральна функція Лагранжа `F(r, r')` для оптичного шляху набуває вигляду:

```
F(r, r') = n(r) · |r'| = n(x, y, z) · sqrt(x'² + y'² + z'²)
```

Стаціонарність функціонала `L[r] = ∫ F(r, r') dt` за варіаційним численням вимагає виконання векторного рівняння Ейлера — Лагранжа для підінтегральної функції `F`:

```
d/dt ( ∂F / ∂r' ) - ∂F / ∂r = 0
```

Обчислимо градієнти функції `F` за компонентами швидкості `r'` та координатами `r`:

1. Частинна похідна за похідною радіус-вектора `r'`:

```
∂F / ∂r' = n(r) · ∂/∂r' ( sqrt(r' · r') ) = n(r) · ( r' / sqrt(r' · r') ) = n(r) · ( r' / |r'| ) = n(r) · dr/ds
```

2. Частинна похідна за радіус-вектором координати `r`:

```
∂F / ∂r = |r'| · ∇n(r) = (ds / dt) · ∇n(r)
```

Підставимо отримані похідні у векторне рівняння Ейлера — Лагранжа:

```
d/dt ( n(r) · dr/ds ) - (ds / dt) · ∇n(r) = 0
```

Перейдемо від довільного параметра `t` назад до природного параметра довжини дуги `s` за допомогою співвідношення `d/dt = (ds/dt) · d/ds`. Поділивши усе рівняння на скалярний множник `ds/dt`, отримуємо остаточне векторне диференціальне рівняння світлового променя:

```
d/ds ( n(r) · dr/ds ) = ∇n(r)
```

Це диференціальне рівняння другого порядку описує траєкторію світла у будь-якому неоднорідному оптичному середовищі. Позначивши канонічний оптичний імпульс як `p = n(r) · dr/ds`, його можна переписати у вигляді двох зв'язаних диференціальних рівнянь першого порядку:

```
dr / ds = p / n(r)
dp / ds = ∇n(r)
```

## Строгий вивід закону Снеліуса та аналіз другої похідної

Розглянемо двовимірну геометрію заломлення на плоскому інтерфейсі `y = 0`, що розділяє два однорідні середовища з показниками заломлення `n₁` (при `y > 0`) та `n₂` (при `y < 0`).

Фіксоване джерело світла `A` перебуває у точці `(0, a)` при `a > 0`. Фіксований приймач `B` перебуває у точці `(d, -b)` при `b > 0`. Промінь перетинає межу розділу у точці `P(x, 0)`.

```
                  y
                  |
     A(0, a)      |
        \         |
      s₁ \        |  Середовище 1 (n₁)
          \       |
-----------P(x,0)-+----------------------- x (межа розділу y = 0)
            \     |
             \ s₂ |  Середовище 2 (n₂)
              \   |
               B(d, -b)
```

Геометричні довжини відрізків шляху у першому та другому середовищах:

```
s₁(x) = sqrt(a² + x²)
s₂(x) = sqrt(b² + (d - x)²)
```

Повний оптичний шлях `L(x)` як функція координати точки перетину `x`:

```
L(x) = n₁ · sqrt(a² + x²) + n₂ · sqrt(b² + (d - x)²)
```

Для знаходження екстремуму обчислимо першу похідну оптичного шляху за зміщенням `x`:

```
dL/dx = n₁ · [ x / sqrt(a² + x²) ] - n₂ · [ (d - x) / sqrt(b² + (d - x)²) ]
```

З прямокутних трикутників тригонометричні синуси кутів між променями та нормаллю до межі визначаються співвідношеннями:

```
sin θ₁ = x / sqrt(a² + x²)
sin θ₂ = (d - x) / sqrt(b² + (d - x)²)
```

Прирівнюючи першу похідну до нуля `dL/dx = 0`, отримуємо класичний закон Снеліуса:

```
n₁ · sin θ₁ - n₂ · sin θ₂ = 0      ⇒      n₁ · sin θ₁ = n₂ · sin θ₂
```

Для перевірки характеру стаціонарної точки обчислимо другу похідну `d²L/dx²`:

```
d²L/dx² = n₁ · d/dx [ x / sqrt(a² + x²) ] - n₂ · d/dx [ (d - x) / sqrt(b² + (d - x)²) ]
```

Застосовуючи правило дифференціювання частки двох функцій:

```
d/dx [ x / sqrt(a² + x²) ] = ( sqrt(a² + x²) - x · (x / sqrt(a² + x²)) ) / (a² + x²)
= ( (a² + x²) - x² ) / (a² + x³) / ² = a² / (a² + x³) / ²
```

Аналогічно для другого додатка:

```
d/dx [ (d - x) / sqrt(b² + (d - x)²) ] = -b² / (b² + (d - x)²)³ / ²
```

Підставляючи ці вирази у другу похідну, отримуємо:

```
d²L/dx² = n₁ · [ a² / (a² + x³) / ² ] + n₂ · [ b² / (b² + (d - x)²)³ / ² ]
```

Оскільки геометричні параметри `a > 0`, `b > 0`, а показники заломлення `n₁ > 0`, `n₂ > 0`, кожен доданок у виразі другої похідної є строго додатним для будь-якого `x ∈ [0, d]`:

```
d²L/dx² > 0
```

Додатність другої похідної строго доводить, що заломлений промінь за законом Снеліуса відповідає **строгому локальному мінімуму** оптичної довжини шляху та часу поширення.

## Друга варіація та класифікація стаціонарних точок

Загальний вираз для другої варіації оптичного шляху `δ²L` при зміщенні траєкторії `δr(s)` визначає типу стаціонарності принципу Ферма:

```
δ²L = (1/2) ∫ [ P(s) · (d/ds δr)² + Q(s) · (δr)² ] ds
```

де коефіцієнти `P(s)` та `Q(s)` залежать від кривизни середовища та відбиваючих поверхонь.

Розглянемо три фундаментальні геометрії відбиття світла:

### 1. Плоске дзеркало
Для плоскої відбивної поверхні друга варіація є строго додатною `δ²L > 0`. Будь-яке мале відхилення траєкторії від закону відбиття збільшує оптичний шлях. Це випадок локального мінімуму.

### 2. Еліптичне дзеркало між фокусами
Розглянемо еліпс із фокусами `F₁` та `F₂`. За геометричним означенням еліпса, сума відстаней від будь-якої точки `P` на поверхні еліпса до його фокусів є постійною величиною:

```
F₁P + PF₂ = 2a = const
```

Якщо джерело міститься у фокусі `F₁`, а приймач — у фокусі `F₂`, світло, відбившись від *будь-якої* точки еліптичного дзеркала, долає абсолютно однакову оптичну довжину шляху `L = 2a`.

У цьому випадку перша варіація `δL = 0` і друга варіація `δ²L = 0` для усіх точок дзеркала. Це випадок **нейтральної стаціонарності (виродженого мінімуму)**.

### 3. Сферичне увігнуте дзеркало великої кривизни
Якщо увігнуте сферичне дзеркало вписане всередину еліпса (має більшу кривизну, ніж еліптична поверхня у точці торкання), реальний шлях відбиття променя між фокусами має другу варіацію:

```
δ²L < 0
```

Це означає, що реальний світловий промінь, який підпорядковується закону відбиття, рухається за траєкторією **локального максимуму** часу поширення порівняно із сусідніми альтернативними точками на дзеркалі.

Точки, у яких друга варіація змінює знак або обнуляється, називаються *спряженими точками* (сопряженные точки), а їхнє геометричне місце утворює огинаючу родини променів — **каустику**. При проходженні каустики світлова хвиля отримує додаткову фазову зсув на `π/2` (індекс Маслова / фаза Гуї).

## Зв'язок із рівнянням ейконала у короткохвильовому наближенні

Повноцінне обґрунтування принципу Ферма у хвильовій оптиці випливає з аналізу короткохвильової границі скалярного хвильового рівняння Гельмгольца:

```
∇²E + k₀² · n²(r) · E = 0
```

де `E(r)` — амплітуда електричного поля, `k₀ = ω / c = 2π / λ₀` — вакуумне хвильове число, `λ₀` — довжина хвилі світла у вакуумі.

У наближенні геометричної оптики (короткохвильове наближення, коли `λ₀ → 0`, а `k₀ → ∞`), розв'язок рівняння Гельмгольца шукають у формі комплексної хвилі:

```
E(r) = A(r) · exp( i · k₀ · S(r) )
```

де `A(r)` — повільно змінювана дійсна амплітуда, а `S(r)` — дійсна скалярна функція, яка називається **ейконалом** (фазовим фронтом).

Обчислимо градієнт та лапласіан поля `E(r)`:

1. Градієнт поля:

```
∇E = ( ∇A + i · k₀ · A · ∇S ) · exp( i · k₀ · S )
```

2. Лапласіан поля:

```
∇²E = ∇ · (∇E) = [ ∇²A + 2i · k₀ · (∇A · ∇S) + i · k₀ · A · ∇²S - k₀² · A · |∇S|² ] · exp( i · k₀ · S )
```

Підставимо вираз для `∇²E` назад у хвильове рівняння Гельмгольца і розділимо усе рівняння на спільний експоненціальний множник `exp(i k₀ S)`:

```
[ ∇²A + i · k₀ · ( 2 ∇A · ∇S + A ∇²S ) - k₀² · A · |∇S|² ] + k₀² · n²(r) · A = 0
```

Згрупуємо члени за степенями великого параметра `k₀`:

```
k₀² · A · [ n²(r) - |∇S|² ] + i · k₀ · [ 2 ∇A · ∇S + A ∇²S ] + ∇²A = 0
```

У границі геометричної оптики, коли `k₀ → ∞`, найвагомішим є доданок найвищого порядку при `k₀²`. Щоб рівняння виконувалося тотожно, коефіцієнт при `k₀²` повинен дорівнювати нулю. Це дає фундаментальне **рівняння ейконала**:

```
|∇S|² = (∂S/∂x)² + (∂S/∂y)² + (∂S/∂z)² = n²(r)
```

Модуль градієнта ейконала в кожній точці простору дорівнює показникові заломлення середовища: `|∇S| = n(r)`.

Поверхні постійного значення ейконала `S(r) = const` є геометричними хвильовими фронтами. Оскільки світлові промені за визначенням є нормалями до хвильових фронтів, напрямок дотичного вектора променя `dr/ds` збігається з напрямком градієнта ейконала `∇S`:

```
n(r) · dr/ds = ∇S
```

Візьмемо похідну від цього співвідношення уздовж довжини дуги променя `s`:

```
d/ds ( n · dr/ds ) = d/ds ( ∇S ) = ( dr/ds · ∇ ) ∇S = ( (1/n) ∇S · ∇ ) ∇S = (1/n) · (∇S · ∇) ∇S
```

Використовуючи векторну тотожність для градієнта квадрата модуля поля `(∇S · ∇) ∇S = (1/2) ∇(|∇S|³)` та підставляючи рівняння ейконала `|∇S|² = n²`:

```
(∇S · ∇) ∇S = (1/2) ∇(n²) = n · ∇n
```

Підставивши цей результат назад, отримуємо:

```
d/ds ( n · dr/ds ) = (1/n) · (n · ∇n) = ∇n
```

Таким чином, короткохвильова границя хвильового рівняння Гельмгольца через рівняння ейконала доводить повну математичну еквівалентність хвильової теорії світла та варіаційного принципу Ферма `δ ∫ n ds = 0`.
