# Оптика: лінза, фокусна відстань, поле зору

<preknowlist>
- [Закон Снелла](root:ph-waves/snells-law) — зв'язок кутів падіння та заломлення світла через показники заломлення середовищ.
- [Показник заломлення](root:ph-waves/refractive-index) — оптична густина середовища та фазова швидкість електромагнітної хвилі.
- [Оптична дисперсія](root:ph-waves/optical-dispersion) — залежність показника заломлення скла від довжини хвилі світла.
</preknowlist>

На конвеєрі автоматизованого монтажу друкованих плат промислова камера з матрицею формату `1/2.8"` (розмір `5.18 × 3.89 мм`, піксель `2.8 мкм`) інспектує якість паяння SMD-компонентів розміром `0.4 × 0.2 мм` (корпус 0402) з робочої відстані `300 мм`. Якщо інженер встановить об'єктив із фокусною відстанню `16 мм` замість розрахункових `25 мм`, поле зору камери (Field of View — FOV) розшириться з `62 мм` до `97 мм`. Через це зображення мікрочіпа на сенсорі зменшиться з 16 пікселів до 10 пікселів, просторова роздільна здатність (IFOV) впаде нижче порогу надійного розпізнавання мікротріщин, а 30% робочого поля охопить зайву конвеєрну стрічку замість контрольованої плати. Точний розрахунок оптичної системи — від заломлення на криволінійних поверхнях лінзи до геометричного узгодження кута зору з фізичним розміром світлочутливої матриці — є критичною вимогою як для проектування фотооб'єктивів, так і для систем технічного зору, дронів та тепловізійних пірометрів.

## Фізична природа заломлення та параксіальне наближення Гауса

Оптична лінза (від латинського *lens* — сочевиця, через схожість форми двовпуклого скла з насінням сочевиці) є прозорим однорідним тілом, обмеженим двома заломлюючими поверхнями, щонайменше одна з яких має сферичну або асферичну кривину. Зміна напрямку поширення світла в лінзі підпорядковується фундаментальному [закону Снелла](root:ph-waves/snells-law):

```
n₁ · sin(θ₁) = n₂ · sin(θ₂)
```

де `n₁` та `n₂` — абсолютні [показники заломлення](root:ph-waves/refractive-index) контактуючих середовищ, а `θ₁` та `θ₂` — кути між світловим променем і геометричною нормаллю до поверхні в точці падіння.

Коли світловий промінь падає на криволінійну границю розділу, просторова орієнтація нормалі безперервно змінюється від центра до периферії лінзи. У результаті промені, що падають на різній відстані від осі, заломлюються під різними кутами.

Прямий розрахунок ходу довільного світлового променя через точні тригонометричні рівняння призводить до нелінійних залежностей. Через це пучок променів, випущений із точкового джерела, після проходження сферичної поверхні не перетинається строго в одній геометричній точці — виникає сферична аберація (детальніше фізичні механізми аберацій описано в [Оптичні аберації](root:ph-waves/optical-aberrations)).

Щоб оптична система створювала ідеальне стигматичне зображення (де кожна точка предмета відображається у вигляді математичної точки зображення), розглядають параксіальну область (від грецького *para* — поруч і латинського *axis* — вісь). Параксіальне наближення, розроблене Карлом Фрідріхом Гаусом у 1841 році, накладає дві фізичні умови:
1. Кути `θ` між променями та головною оптичною віссю є настільки малими (`θ < 10°` або `θ < 0.17` рад), що тригонометричні функції замінюються першим членом ряду Тейлора: `sin(θ) ≈ θ`, `tan(θ) ≈ θ`, `cos(θ) ≈ 1`.
2. Висота падіння променя `h` є значно меншою за радіус кривини поверхні `R` (`h ≪ R`), що дозволяє знехтувати поздовжнім сагітальним прогином сферичного сегмента `δ ≈ h² / (2·R)`.

У параксіальному наближенні заломлення світла на одиничній сферичній поверхні радіусом `R`, що розділяє середовища з показниками `n₁` та `n₂`, описується інваріантним співвідношенням:

```
n₁ / s + n₂ / s'
= (n₂ - n₁) / R      [інваріант заломлення на сферичній поверхні]
```

де `s` — відстань від вершини сферичної поверхні до точкового джерела світла (предмета), а `s'` — відстань від вершини до точки перетину заломленого променя з віссю (дійсного або уявного зображення).

Величина `(n₂ - n₁) / R` називається заломлюючою силою сферичної межі (позначається `Φ` і вимірюється у діоптріях, `м⁻¹`). Якщо поверхня опукла в бік падаючого променя (`R > 0`), заломлююча сила є додатною, і поверхня збирає промені до оптичної осі; якщо поверхня увігнута (`R < 0`), заломлююча сила від'ємна, і пучок стає розбіжним.

## Формула тонкої лінзи та просторове формування зображення

Тонкою лінзою називають оптичний елемент, геометрична осьова товщина якого між вершинами передньої та задньої поверхонь є знехтовно малою порівняно з радіусами кривини поверхонь та відстанями до предмета й зображення. У тонкій лінзі обидві вершини поверхонь умовно зливаються в одну точку — оптичний центр лінзи `O`.

Якщо скласти інваріанти заломлення для передньої сферичної поверхні (радіус `R₁`) та задньої поверхні (радіус `R₂`), виключивши проміжне зображення всередині скла, отримуємо канонічну формулу тонкої лінзи (Gaussian lens formula):

```
1 / d_o + 1 / d_i
= 1 / f              [канонічна формула тонкої лінзи]
```

де:
- `d_o` (object distance, відстань до предмета) — відстань уздовж оптичної осі від предмета до оптичного центра лінзи `O`;
- `d_i` (image distance, відстань до зображення) — відстань уздовж оптичної осі від оптичного центра `O` до площини сфокусованого зображення;
- `f` (focal length, фокусна відстань) — відстань від оптичного центра `O` до головного фокуса лінзи `F`.

Поняття головного оптичного фокуса (від латинського *focus* — вогнище, домашній вівтар, термін введений Йоганном Кеплером у 1604 році через концентрацію сонячної теплової енергії в одній точці) визначається з граничних умов:
- Задній головний фокус `F₂`: точка на осі, де збираються промені, що падають на лінзу паралельним пучком із нескінченно віддаленого джерела (`d_o → ∞`, звідки `1/d_o → 0` і `d_i = f`).
- Передній головний фокус `F₁`: положення точкового джерела на осі, промені від якого після проходження крізь лінзу виходять строго паралельно до оптичної осі (`d_i → ∞`, звідки `d_o = f`).

Для симетричного середовища (наприклад, лінза, оточена повітрям з обох боків) передня та задня фокусні відстані є строго однаковими за абсолютною величиною: `|f₁| = |f₂| = f`.

### Правило знаків Декарта

Для однозначності геометричних та аналітичних розрахунків у фізичній оптиці діє стандартне декартове правило знаків (Cartesian sign convention):
1. Світло поширюється зліва направо вздовж додатної осі `Z`.
2. Оптичний центр лінзи `O` приймається за початок координат `(0, 0)`.
3. Відстань до предмета `d_o` є додатною (`d_o > 0`), якщо реальний предмет розташований зліва від лінзи (у просторі предметів).
4. Відстань до зображення `d_i` є додатною (`d_i > 0`), якщо дійсне зображення формується праворуч від лінзи (у просторі зображень). Якщо промені після лінзи розбігаються, а їхні уявні продовження перетинаються зліва від лінзи, зображення є уявним, і відстань вважається від'ємною (`d_i < 0`).
5. Фокусна відстань `f` є додатною (`f > 0`) для збиральних (опуклих) лінз і від'ємною (`f < 0`) для розсіювальних (увігнутих) лінз.
6. Радіус кривини поверхні `R` є додатним (`R > 0`), якщо центр кривини `C` лежить праворуч від поверхні (опукла поверхня для світла, що йде зліва), і від'ємним (`R < 0`), якщо центр кривини лежить зліва від поверхні (увігнута поверхня).

### Лінійне збільшення та трасування головних променів

Поперечне (лінійне) оптичне збільшення `M` (Magnification) визначається як відношення лінійної висоти сформованого зображення `h_i` до фізичної висоти предмета `h_o`:

```
M = h_i / h_o
= - d_i / d_o        [лінійне оптичне збільшення]
```

Знак мінус у формулі показує просторову орієнтацію:
- Якщо `M < 0`, зображення є дійсним і перевернутим (інвертованим) відносно предмета.
- Якщо `M > 0`, зображення є уявним і прямим (неперевернутим).
- Якщо `|M| > 1`, зображення є збільшеним; якщо `|M| < 1` — зменшеним; при `|M| = 1` — рівним за масштабом.

Для графічної побудови положення та розміру зображення використовують три характерні головні параксіальні промені, показані на фігурі:
1. **Паралельний промінь**: виходить із вершини предмета `B`, рухається паралельно до головної оптичної осі до площини лінзи, після заломлення проходить строго через задній головний фокус `F₂`.
2. **Центральний промінь**: виходить із точки `B` і проходить через оптичний центр лінзи `O`. Оскільки дотичні площини передньої та задньої поверхонь у вершинах є паралельними, тонка лінза в центрі еквівалентна нескінченно тонкій плоскопаралельній пластинці, і промінь проходить крізь центр без кутового чи лінійного відхилення.
3. **Фокальний промінь**: виходить із точки `B`, проходить через передній головний фокус `F₁` до площини лінзи і після заломлення поширюється паралельно до оптичної осі.

Точка перетину цих трьох променів (або їхніх уявних зворотних продовжень) однозначно задає координати вершини сформованого зображення `B'`.

## Формула шліфувальника лінз (Lensmaker's Equation)

Фокусна відстань лінзи `f` не є довільною константою — вона визначається виключно геометрією її поверхонь та показником заломлення матеріалу. Рівняння, що зв'язує радіуси кривини поверхонь із фокусною відстанню, називається формулою шліфувальника лінз (Lensmaker's equation), виведеною Едмундом Галлеєм у 1693 році.

![Заломлення світлових променів на двох сферичних поверхнях лінзи](/root/sci/ph-waves/optyka-linza-fokusna-vidstan-pole-zoru/img/lensmaker-surfaces.svg)
*Параметри формули шліфувальника лінз: радіуси кривини R₁ і R₂, товщина d та центри кривини C₁ і C₂.*

Для тонкої лінзи з показником заломлення скла `n`, розміщеної у зовнішньому середовищі з показником `n_med`, формула шліфувальника має вигляд:

```
1 / f
= (n / n_med - 1) · (1 / R₁ - 1 / R₂)   [формула шліфувальника лінз]
```

Якщо лінза працює у повітрі (`n_med ≈ 1.0`), рівняння спрощується:

```
1 / f
= (n - 1) · (1 / R₁ - 1 / R₂)
```

Оптичну силу лінзи позначають літерою `D` (або `Φ`) і вимірюють у діоптріях (від грецького *dioptra* — інструмент для вимірювання кутів та висот). Одна діоптрія (`1 дптр = 1 м⁻¹`) відповідає оптичній силі лінзи з фокусною відстанню рівно `1 метр`:

```
D = 1 / f
```

Строге покрокове геометричне виведення цієї формули з балансу кутів закону Снелла та аналіз впливу осьової товщини скла `t` у товстих лінзах наведено у вставці: [Виведення формули шліфувальника лінз із закону Снелла](root:ph-waves/optyka-linza-fokusna-vidstan-pole-zoru/math-lensmaker-derivation.md).

### Геометричні типи лінз та знаки радіусів

Залежно від знаків радіусів кривини `R₁` та `R₂`, розрізняють шість базових типів лінз:

| Тип лінзи | Геометрія передньої поверхні `R₁` | Геометрія задньої поверхні `R₂` | Оптична сила `D` | Призначення |
|---|---|---|---|---|
| Двовпукла (Biconvex) | `R₁ > 0` (опукла) | `R₂ < 0` (опукла) | `D > 0` (збиральна) | Лупи, об'єктиви, конденсори |
| Плоско-опукла (Plano-convex) | `R₁ > 0` (опукла) | `R₂ = ∞` (плоска) | `D > 0` (збиральна) | Фокусування лазерів, коліматори |
| Додатний меніск (Meniscus convex) | `R₁ > 0` (опукла) | `R₂ > 0` (`R₁ < R₂`) | `D > 0` (збиральна) | Окуляри, коригувальні меніски |
| Двоввігнута (Biconcave) | `R₁ < 0` (увігнута) | `R₂ > 0` (увігнута) | `D < 0` (розсіювальна) | Зменшувальні системи, лінзи Барлоу |
| Плоско-увігнута (Plano-concave) | `R₁ = ∞` (плоска) | `R₂ > 0` (увігнута) | `D < 0` (розсіювальна) | Розсіювання пучків, телескопи |
| Від'ємний меніск (Meniscus concave) | `R₁ > 0` (опукла) | `R₂ > 0` (`R₁ > R₂`) | `D < 0` (розсіювальна) | Корекція польових аберацій |

Особливим різновидом оптичних лінз із сегментованою ступінчастою поверхнею є [лінза Френеля](root:ph-waves/fresnel-lens), де за рахунок видалення внутрішнього пасивного шару скла зберігається профіль кривини при мінімальній товщині та масі.

Історичний шлях розвитку лінзової оптики від давньоассирійських кристалів до сучасної матричної оптики висвітлено у вставці: [Історія розвитку лінзової оптики: від кристала Німруда до матричної оптики](root:ph-waves/optyka-linza-fokusna-vidstan-pole-zoru/hist-lens-optics.md).

## Матричний метод параксіальної оптики (ABCD-матриці)

У сучасних обчислювальних алгоритмах трасування променів та автоматизованого проектування оптичних систем геометричний розрахунок заломлення на багатьох поверхнях записують у компактній матричній формі. Стан довільного світлового променя в площині, перпендикулярній до оптичної осі, задається двовимірним вектором-стовпцем:

```
r = [ y ]
    [ θ ]
```

де `y` — висота променя над оптичною віссю (у міліметрах), а `θ` — параксіальний кут нахилу променя до осі (у радіанах).

Перенесення променя крізь будь-який оптичний проміжок або заломлюючий елемент описується лінійним перетворенням за допомогою матриці передачі променя розміром 2×2 (Ray Transfer Matrix або ABCD-матриця):

```
[ y_out ]   [ A   B ]   [ y_in ]
[ θ_out ] = [ C   D ] · [ θ_in ]
```

Для тонкої лінзи з оптичною силою `D = 1/f` висота променя при проходженні крізь площину лінзи не змінюється (`y_out = y_in`), а кут нахилу змінюється пропорційно висоті падіння (`θ_out = θ_in - y_in / f`). Відповідна матриця тонкої лінзи має вигляд:

```
M_lens = [  1     0 ]
         [ -1/f   1 ]
```

Поширення променя у вільному однорідному просторі на відстань `L` описується матрицею трансляції:

```
M_space = [ 1   L ]
          [ 0   1 ]
```

Повний оптичний тракт від площини предмета (відстань `d_o`) крізь тонку лінзу фокусної відстані `f` до площини зображення (відстань `d_i`) представляється послідовним множенням трьох матриць:

```
M_total
= M_space(d_i) · M_lens(f) · M_space(d_o)
```

Обчислюючи добуток матриць:

```
M_total
= [ 1 - d_i/f     d_o + d_i - (d_o · d_i)/f ]
  [ -1/f          1 - d_o/f                 ]
```

Умова стигматичного фокусування вимагає, щоб усі промені, випущені з однієї точки предмета під довільними кутами `θ_in`, зійшлися в одній точці зображення `y_out` незалежно від `θ_in`. Це означає, що матричний елемент `B` повинен строго дорівнювати нулю:

```
B = d_o + d_i - (d_o · d_i) / f = 0
```

Розділивши цю рівність на добуток `d_o · d_i · f`, знову отримуємо канонічну формулу тонкої лінзи Гауса: `1/d_o + 1/d_i = 1/f`. При цьому діагональний елемент `A` дорівнює `1 - d_i/f = - d_i/d_o = M`, тобто безпосередньо задає лінійне оптичне збільшення системи.

## Кутове поле зору (Field of View — FOV)

Кутовим полем зору (Field of View — FOV) оптичної системи називають максимальний просторовий кут конуса або піраміди, в межах якого промені від об'єктів потрапляють на світлочутливу поверхню сенсора або фотоплівки та беруть участь у формуванні чіткого зображення.

![Геометрія кутового поля зору FOV для сенсора камери та об'єктива](/root/sci/ph-waves/optyka-linza-fokusna-vidstan-pole-zoru/img/sensor-fov-geometry.svg)
*Кутове поле зору FOV: взаємозв'язок розміру сенсора d, фокусної відстані f та робочої дистанції WD.*

Розглянемо оптичну систему з фокусною відстанню `f`, сфокусовану на нескінченно віддалений об'єкт (`d_o → ∞`). При цьому площина фотосенсора розміщена строго у задній фокальній площині об'єктива на відстані `d_i = f`.

Якщо лінійний розмір світлочутливої зони сенсора дорівнює `d` (це може бути фізична ширина `w`, висота `h` або діагональ матриці `diag`), то промені від крайніх точок сенсора проходять через оптичний центр лінзи `O` під кутом `θ / 2` до оптичної осі. З прямокутного трикутника тангенс половини кута зору дорівнює:

```
tan(FOV / 2) = (d / 2) / f = d / (2 · f)
```

Взявши арктангенс від обох частин і помноживши на два, отримуємо базову формулу кутового поля зору:

```
FOV = 2 · arctan(d / (2 · f))
```

Оскільки світлочутливі матриці прямокутні, поле зору розраховують окремо для трьох геометричних осей:
- **Горизонтальний кут (HFOV)**: обчислюється за фізичною шириною сенсора `w`:
  ```
  HFOV = 2 · arctan(w / (2 · f))
  ```
- **Вертикальний кут (VFOV)**: обчислюється за фізичною висотою сенсора `h`:
  ```
  VFOV = 2 · arctan(h / (2 · f))
  ```
- **Діагональний кут (DFOV)**: обчислюється за діагоналлю матриці `diag = √(w² + h²)`:
  ```
  DFOV = 2 · arctan(√(w² + h²) / (2 · f))
  ```

Виробники споживчої фототехніки та відеокамер у рекламних специфікаціях за замовчуванням вказують саме діагональний кут `DFOV`, оскільки він є найбільшим за числовим значенням. Проте для інженерних розрахунків систем комп'ютерного зору, робототехніки та безпілотників першочергове значення мають горизонтальний `HFOV` та вертикальний `VFOV` кути.

### Вплив кінцевої відстані фокусування: ефект «дихання фокусу»

Якщо об'єкт спостереження знаходиться на кінцевій відстані `d_o` (робоча відстань WD — Working Distance), то відповідно до формули тонкої лінзи відстань від об'єктива до сенсора `d_i` має збільшитися, щоб сфокусувати промені:

```
d_i = (f · d_o) / (d_o - f)
= f · (1 + M)        [збільшення відстані до сенсора при фокусуванні]
```

де `M = d_i / d_o` — оптичне збільшення системи.

Оскільки світлочутлива матриця віддаляється від оптичного центра лінзи на відстань `d_i > f`, кут, під яким краї матриці бачать об'єктив, зменшується. Фактичне (ефективне) поле зору на кінцевій відстані стає вужчим, ніж розраховане за номінальною фокусною відстанню:

```
FOV_eff = 2 · arctan(d / (2 · d_i))
= 2 · arctan(d / (2 · f · (1 + M)))
```

Цей ефект зміни поля зору під час перефокусування з далеких об'єктів на близькі в кінематографії та машинному зорі називають **диханням фокусу** (Focus Breathing). При макрозйомці з масштабом `1:1` (`M = 1`), відстань `d_i = 2·f`, і реальне кутове поле зору зменшується майже вдвічі порівняно з фокусуванням на нескінченність.

Лінійні розміри спостережуваної сцени (Field Width `W` та Field Height `H`) на робочій дистанції `WD` (де `WD = d_o`) пов'язані з розмірами сенсора прямим геометричним відношенням подібності трикутників:

```
W / w = H / h = d_o / d_i = 1 / M
```

Звідси фізична ширина зони огляду на відстані `WD` дорівнює:

```
W = 2 · WD · tan(HFOV / 2)
```

А для підбору необхідної фокусної відстані `f` об'єктива під відому ширину зони контролю `W` та робочу дистанцію `WD` застосовують обернену інженерну формулу:

```
f = (WD · w) / (W + w)
```

## Діафрагми, зіниці та фотометричне віньєтування

Кутове поле зору і світлосила оптичної системи обмежуються не тільки габаритами матриці, а й фізичними оправами лінз та внутрішніми діафрагмами.

В оптичній системі розрізняють:
1. **Апертурна діафрагма (Aperture Stop)**: фізична кругла перегородка (або регульована пелюсткова діафрагма), яка обмежує поперечний переріз світлового пучка, що проходить крізь оптичну систему від осьової точки предмета.
2. **Вхідна зіниця (Entrance Pupil)**: оптичне зображення апертурної діафрагми через оптичні елементи, розташовані перед нею. Вхідна зіниця визначає світловий конус, який об'єктив здатний прийняти від предмета.
3. **Вихідна зіниця (Exit Pupil)**: оптичне зображення апертурної діафрагми через оптичні елементи, розташовані за нею. З вихідної зіниці світловий конус падає на фотоматрицю.
4. **Польова діафрагма (Field Stop)**: фізична межа, яка обмежує кутове поле зору. У цифрових камерах польовою діафрагмою виступає фізична рамка кремнієвого кристала світлочутливої матриці.

### Падіння освітленості за законом четвертого косинуса

Світловий потік, що падає на матрицю під кутом `θ` до оптичної осі, зазнає природного геометричного ослаблення. Освітленість `E(θ)` у точці сенсора під кутом `θ` зменшується за канонічним законом четвертого косинуса:

```
E(θ) = E₀ · cos⁴(θ)
```

Фізична природа цього спаду складається з трьох незалежних геометричних факторів:
1. Відстань від вихідної зіниці до точки сенсора на краю кадру зростає як `L = f / cos(θ)`, що через закон обернених квадратів дає коефіцієнт `1 / L² ∝ cos²(θ)`.
2. Площа вихідної зіниці, видима з похилого напрямку, зменшується через проекційне скорочення на коефіцієнт `cos(θ)`.
3. Площа поверхні пікселя, на яку падає світловий потік, нахилена до променя під кутом `θ`, що дає ще один множник `cos(θ)`.

Для ширококутних об'єктивів із кутом `FOV = 90°` (`θ_max = 45°`) величина `cos⁴(45°) = (1/√2)⁴ = 0.25`. Це означає, що на краях кадру освітленість падає до 25% від центральної (втрата 2 ступенів експозиції), що створює помітне затемнення кутів кадру — віньєтування (Vignetting).

## Глибина різкості (DOF) та гіперфокальна відстань

Жодна реальна лінза не здатна одночасно сфокусувати об'єкти, розташовані на різних відстанях від камери. Промені від точок, розташованих ближче або далі за точну площину фокусування `d_o`, формують на матриці розмиті плями замість точок.

Діаметр цієї плями називають **кружком нерізкості** (Circle of Confusion — `c`). Якщо діаметр кружка нерізкості не перевищує фізичного розміру одного-двох пікселів сенсора (для формату Full Frame стандартно приймають `c ≈ 0.03 мм`, для APS-C — `c ≈ 0.02 мм`, для `1/2.8"` — `c ≈ 0.003 мм`), людське око та алгоритми комп'ютерного зору сприймають зображення як різке.

Просторовий інтервал уздовж оптичної осі, в межах якого всі об'єкти виглядають різкими, називається **глибиною різкості** (Depth of Field — DOF).

Гіперфокальною відстанню `H` (Hyperfocal Distance) називають таку дистанцію фокусування, при якій задня межа глибини різкості сягає оптичної нескінченності:

```
H = f² / (N · c) + f
```

де `f` — фокусна відстань, `N = f / D_aperture` — діафрагмове число (f-number, наприклад `f/2.8`, `f/8`), а `c` — допустимий кружок нерізкості.

Якщо об'єктив сфокусовано на гіперфокальну відстань `H`, то весь простір від `H / 2` до нескінченності `∞` знаходиться у зоні різкого зображення. Це правило використовується в камерах спостереження, автомобільних відеореєстраторах та дронах для забезпечення постійної різкості без використання механізму автофокусування.

## Сенсори, оптичні формати та роздільна здатність

Фізичні розміри світлочутливої матриці камер визначають площу збору фотонів та просторовий кут зору для заданого об'єктива. У сучасній цифровій електроніці для позначення розмірів матриць використовують традиційну дюймову номенклатуру (Optical Formats), яка має історичне походження.

![Порівняння оптичних форматів сенсорів зображення](/root/sci/ph-waves/optyka-linza-fokusna-vidstan-pole-zoru/img/sensor-formats-comparison.svg)
*Оптичні формати світлочутливих матриць від 1/4" до Full Frame: фізичні габарити, діагоналі та кроп-фактори.*

### Історичний парадокс дюймових позначень матриць

Позначення формату сенсора у вигляді дробів дюйма (наприклад, `1/2"`, `1/2.8"`, `1/3"`, `1"`) не означає фізичний розмір світлочутливої діагоналі матриці в дюймах. Ця система маркування виникла у 1950-х роках для вакуумних передавальних телевізійних трубок типу Відікон (Vidicon).

У трубці Відікон діаметром `1 дюйм` (`25.4 мм`) через скляну колбу, електродні сітки та краеві спотворення корисне плоске фоточутливе поле в центрі мішені мало прямокутну форму з діагоналлю лише близько `16 мм` (приблизно дві третини від зовнішнього діаметра скляної колби). Коли на зміну вакуумним трубкам прийшли твердотільні напівпровідникові матриці (CCD та CMOS), виробники зберегли маркування «оптичного формату», щоб інженери могли використовувати оптику для відповідних вакуумних камер.

Таким чином, для сенсора формату `1"` діагональ становить не `25.4 мм`, а `15.86–16.0 мм`. Для довільного дробового формату `1/k"` діагональ розраховується з емпіричного правила:

```
diag ≈ 16 / k  [мм]
```

Кроп-фактор (Crop Factor, `CF`) визначається як відношення діагоналі еталонного повного кадру (Full Frame `36 × 24 мм`, діагональ `43.27 мм`) до діагоналі досліджуваного сенсора:

```
CF = 43.2666 / diag_sensor
```

Еквівалентна фокусна відстань (EFL — Equivalent Focal Length) для повного кадру показує, який об'єктив на повнокадровій камері дасть такий самий кут зору:

```
f_equiv = f · CF
```

Наприклад, об'єктив `f = 6 мм` на сенсорі `1/2.8"` (`CF = 6.68`) забезпечує кут зору, еквівалентний об'єктиву `40 мм` на Full Frame камері.

### Миттєве поле зору пікселя (IFOV) та просторова роздільна здатність

Поле зору всієї матриці (FOV) визначає межі охоплення сцени, але не визначає мінімальний розмір дефекту, який здатна розрізнити оптична система. Для цього розраховують миттєве кутове поле зору одного пікселя — IFOV (Instantaneous Field of View).

Якщо фізичний розмір (пітч) одного світлочутливого елемента матриці дорівнює `p` (наприклад, `p = 3.45 мкм = 0.00345 мм`), то кутовий розмір конуса, який бачить окремий піксель крізь об'єктив із фокусною відстанню `f`, дорівнює:

```
IFOV = p / f         [у радіанах]
```

Оскільки кут `IFOV` надзвичайно малий, його виражають у мілірадіанах (`мрад`, де `1 мрад = 10⁻³ рад`):

```
IFOV [мрад] = (p [мкм] / f [мм])
```

На відстані `L` від камери один піксель проектується на площину об'єкта у вигляді квадратної ділянки з лінійним розміром GSD (Ground Sample Distance або просторова роздільна здатність на об'єкті):

```
GSD = IFOV · L = (p · L) / f
```

Наприклад, дрон із тепловізійною камерою з розміром пікселя `p = 17 мкм` та фокусною відстанню `f = 19 мм` летить на висоті `L = 100 м`. Значення `IFOV = 17 / 19 = 0.895 мрад`. Лінійна роздільна здатність на землі становитиме `GSD = 0.895 × 10⁻³ × 100 м = 0.0895 м = 8.95 см/піксель`.

Для надійного автоматичного виявлення дефекту (наприклад, тріщини друкованого провідника) у машинному зорі застосовують емпіричний критерій Найквіста-Джонсона: розмір контрольованого елемента повинен покриватися щонайменше 3–4 пікселями матриці (`Розмір дефекту ≥ 3.5 · GSD`).

### Пірометрія та оптичний показник візування (D:S Ratio)

У безконтактних оптичних вимірювачах температури (інфрачервоних пірометрах і тепловізорах) оптична система фокусує теплове інфрачервоне випромінювання на термоелектричний або піроелектричний детектор. Головною характеристикою такої системи є оптичний показник візування — відношення відстані до діаметра плями вимірювання `D:S` (Distance-to-Spot ratio).

Показник `D:S` (наприклад, `50:1`, `75:1`, `12:1`) означає, що на відстані `D` від приладу чутлива зона оптичної системи утворює пляму діаметром `S`, з якої збирається 90–95% вхідної теплової енергії.

Діаметр плями вимірювання `S` на відстані `L` розраховується з урахуванням вхідної апертури об'єктива `d_lens`:

```
S(L) = d_lens + L / (D:S)
```

Кутовий розхил конуса візування пірометра пов'язаний з показником `D:S` співвідношенням:

```
θ_pyro = 2 · arctan(1 / (2 · (D:S)))
```

Для пірометра з `D:S = 50:1` та апертурою `d_lens = 20 мм` на дистанції `L = 1500 мм` пляма вимірювання становитиме `S = 20 + 1500 / 50 = 50 мм`. Якщо нагрітий компонент на платі має розмір лише `10 мм`, пірометр усереднить температуру компонента з холодною фоновою текстолітовою платою, показавши занижену на десятки градусів температуру.

## Практичний інженерний розрахунок оптичної системи

Розглянемо практичний алгоритм вибору оптики та сенсора для інспекційної станції автоматичного контролю геометрії автомобільних деталей:
- Контрольована деталь: блок циліндрів шириною `W_field = 400 мм` та висотою `H_field = 300 мм` (формат сцени 4:3).
- Фіксована робоча дистанція (відстань від об'єктива до деталі): `WD = 1200 мм`.
- Вимога до метрологічної точності: розпізнавання відхилення розміру `Δx = 0.2 мм`.

**Крок 1. Визначення мінімальної роздільної здатності матриці.**
За критерієм дискретизації Найквіста один мінімальний елемент `Δx` має містити щонайменше 2 пікселі (`GSD ≤ 0.1 мм/піксель`).
Необхідна кількість пікселів по горизонталі:
```
N_x = W_field / GSD = 400 мм / 0.1 мм = 4000 пікселів
```
Необхідна кількість пікселів по вертикалі:
```
N_y = H_field / GSD = 300 мм / 0.1 мм = 3000 пікселів
```
Повна роздільна здатність сенсора: `4000 × 3000 = 12 Мп`.

**Крок 2. Вибір сенсора та розрахунок збільшення.**
Обираємо промисловий сенсор формату `1/1.1"` (наприклад, Sony IMX540) з роздільною здатністю `4128 × 3008 пікселів`, розміром пікселя `p = 2.74 мкм` та фізичними розмірами матриці `w = 11.31 мм`, `h = 8.24 мм` (діагональ `diag = 14.0 мм`).

Оптичне лінійне збільшення системи становить:
```
M = w / W_field = 11.31 мм / 400 мм = 0.028275
```

**Крок 3. Розрахунок необхідної фокусної відстані об'єктива.**
За формулою зв'язку фокусної відстані з робочою дистанцією та масштабом:

```
f = (WD · M) / (1 + M)
= (1200 · 0.028275) / (1 + 0.028275)  [підстановка числових значень WD та M]
= 33.93 / 1.028275                     [обчислення чисельника та знаменника]
≈ 33.00 мм                             [ділення та заокруглення до найближчого значення]
```

Зі стандартного ряду промислових об'єктивів (25 мм, 35 мм, 50 мм) найближчим стандартним значенням є об'єктив `f = 35 мм`.

**Крок 4. Перевірка фактичного поля зору та робочої дистанції з об'єктивом 35 мм.**
Для об'єктива `f = 35 мм` та матриці `w = 11.31 мм`:
```
HFOV = 2 · arctan(11.31 / (2 · 35)) = 2 · arctan(0.16157) = 18.36°
VFOV = 2 · arctan(8.24 / (2 · 35)) = 2 · arctan(0.11771) = 13.43°
DFOV = 2 · arctan(14.00 / (2 · 35)) = 2 · arctan(0.20000) = 22.62°
```
Фактична робоча дистанція для покриття поля `W = 400 мм`:
```
WD_actual = (W_field · f) / w + f = (400 · 35) / 11.31 + 35 = 1238 мм + 35 мм = 1273 мм
```
Фактична просторова роздільна здатність на об'єкті:
```
GSD = (p · WD_actual) / f = (0.00274 мм · 1273 мм) / 35 мм = 0.0997 мм/піксель
```
Отримане значення `GSD = 0.0997 мм < 0.1 мм` повністю задовольняє вихідну метрологічну вимогу інспекції деталі.
