# 🧮 Виведення формули шліфувальника лінз із закону Снелла

Математичне обґрунтування геометрії тонкої та товстої лінзи базується на послідовному застосуванні [закону Снелла](root:ph-waves/snells-law) на двох криволінійних межах розділу оптичних середовищ. Мета цього виведення — встановити аналітичний зв'язок між оптичною силою лінзи `1/f`, радіусами кривини її передньої та задньої поверхонь `R₁` і `R₂`, власним показником заломлення скла `n` та показником заломлення навколишнього середовища `n_med` у параксіальному наближенні Гауса.

## Заломлення світла на одиничній сферичній поверхні

Розглянемо сферичну границю розділу двох прозорих середовищ із [показниками заломлення](root:ph-waves/refractive-index) `n₁` (зліва) та `n₂` (справа). Центр сферичної поверхні `C` лежить на головній оптичній осі, а радіус її кривини дорівнює `R`. Вершина поверхні (точка перетину з оптичною віссю) позначається як `V`.

Точкове джерело світла `P` розташоване на оптичній осі на відстані `s` перед вершиною `V` (у середовищі `n₁`). Промінь, випущений із точки `P` під кутом `α` до оптичної осі, падає на сферичну поверхню в точці `M` на висоті `h` від осі. Нормаль до поверхні у точці `M` проходить через центр кривини `C` і утворює з оптичною віссю кут `φ`.

Кут падіння `θ₁` утворюється між променем `PM` та нормаллю `MC`. За теоремою про зовнішній кут трикутника `PMC`:

```
θ₁ = α + φ
```

Після заломлення на межі розділу промінь поширюється в середовищі `n₂` під кутом `θ₂` до нормалі `MC` і перетинає головну оптичну вісь у точці дійсного зображення `P'` на відстані `s'` за вершиною `V`. Заломлений промінь утворює з віссю кут `β`. З трикутника `MP'C` кут `φ` є зовнішнім:

```
φ = θ₂ + β
```

Звідси кут заломлення `θ₂` виражається через кути `φ` та `β`:

```
θ₂ = φ - β
```

Запишемо точний [закон Снелла](root:ph-waves/snells-law) для точки падіння `M`:

```
n₁ · sin(θ₁) = n₂ · sin(θ₂)
```

## Параксіальне наближення Гауса

У параксіальній оптиці розглядаються лише промені, які утворюють малі кути з головною оптичною віссю (`α, β, φ, θ₁, θ₂ ≪ 1` рад). Для таких кутів тригонометричні функції розкладаються в ряд Тейлора і замінюються їхніми лінійними наближеннями:

```
sin(θ) ≈ θ
tan(θ) ≈ θ
cos(θ) ≈ 1
```

Підставляючи кути `θ₁ = α + φ` та `θ₂ = φ - β` у лінеаризований закон Снелла `n₁ · θ₁ ≈ n₂ · θ₂`, отримуємо:

```
n₁ · (α + φ) = n₂ · (φ - β)
```

Розкриваючи дужки та групуючи доданки з кутами променів `α`, `β` та кутом нормалі `φ`:

```
n₁ · α + n₂ · β
= (n₂ - n₁) · φ      [перенесення n₁·φ праворуч та n₂·β ліворуч]
```

Опустимо перпендикуляр із точки падіння `M` на оптичну вісь. Висота перпендикуляра дорівнює `h`, а дуговий прогин сферичного сегмента `δ = V - X` для малих висот є величиною другого порядку малості (`δ ≈ h² / (2·R)`), якою в нульовому наближенні нехтують. Отже, кути виражаються через тангенси прямокутних трикутників:

```
α ≈ tan(α) = h / s
β ≈ tan(β) = h / s'
φ ≈ tan(φ) = h / R
```

Підставимо ці вирази у рівняння балансу заломлення:

```
n₁ · (h / s) + n₂ · (h / s') = (n₂ - n₁) · (h / R)
```

Скорочуючи обидві частини рівняння на ненульову висоту падіння `h`, отримуємо фундаментальне інваріантне рівняння заломлення на одиничній сферичній поверхні:

```
n₁ / s + n₂ / s'
= (n₂ - n₁) / R      [скорочення спільного множника h]
```

## Послідовне заломлення на двох поверхнях лінзи

Розглянемо лінзу з власного матеріалу з показником заломлення `n`, розміщену у середовищі з показником `n_med` (для повітря `n_med = 1`). Лінза обмежена двома сферичними поверхнями з радіусами кривини `R₁` (передня) та `R₂` (задня), а її осьова товщина між вершинами `V₁` та `V₂` дорівнює `t`.

### Заломлення на першій поверхні

Світло падає з навколишнього середовища `n_med` на першу поверхню з радіусом кривини `R₁`. Предмет знаходиться на відстані `s₁` перед першою вершиною `V₁`. Перша поверхня формує проміжне зображення на відстані `s₁'` за вершиною `V₁`:

```
n_med / s₁ + n / s₁'
= (n - n_med) / R₁      [заломлення на передній сферичній межі]
```

### Заломлення на другій поверхні

Проміжне зображення, сформоване першою поверхнею, виступає джерелом (предметом) для другої поверхні. Відстань від цього проміжного предмета до другої вершини `V₂` визначається з урахуванням геометричної товщини лінзи `t`:

```
s₂ = -(s₁' - t)
```

Знак мінус виникає через те, що промені сходяться до другої поверхні, утворюючи віртуальний предмет усередині оптичного матеріалу.

На другій поверхні світло виходить зі скла з показником `n` у зовнішнє середовище `n_med`, заломлюючись на кривизні `R₂`:

```
n / s₂ + n_med / s₂'
= (n_med - n) / R₂      [заломлення на задній сферичній межі]
```

Підставимо `s₂ = -(s₁' - t)`:

```
-n / (s₁' - t) + n_med / s₂'
= -(n - n_med) / R₂      [винесення мінуса з різниці показників]
```

## Наближення нескінченно тонкої лінзи

Для тонкої лінзи товщина `t` уздовж оптичної осі є знехтовно малою порівняно з радіусами кривини та відстанями до предмета й зображення (`t ≪ R₁, R₂, s₁, s₂'`). Покладаючи `t → 0`, маємо `s₁' - t ≈ s₁'`. Рівняння для другої поверхні набуває вигляду:

```
-n / s₁' + n_med / s₂'
= -(n - n_med) / R₂      [граничний перехід при товщині t -> 0]
```

Додамо почленно рівняння для першої та другої поверхонь:

```
(n_med / s₁ + n / s₁') + (-n / s₁' + n_med / s₂')
= (n - n_med) / R₁ - (n - n_med) / R₂
```

Члени з проміжною відстанню `n / s₁'` взаємно скорочуються, що усуває залежність від внутрішнього ходу променів у склі:

```
n_med / s₁ + n_med / s₂'
= (n - n_med) · (1 / R₁ - 1 / R₂)      [винесення спільного множника (n - n_med)]
```

Розділимо обидві частини рівності на показник заломлення навколишнього середовища `n_med`:

```
1 / s₁ + 1 / s₂'
= (n / n_med - 1) · (1 / R₁ - 1 / R₂)  [ділення на n_med]
```

Якщо предмет знаходиться на нескінченній відстані (`s₁ → ∞`), то `1 / s₁ → 0`. Промені, що падають паралельним пучком, фокусуються в задньому фокусі лінзи, тобто відстань до зображення стає рівною фокусній відстані лінзи `s₂' = f`:

```
1 / f
= (n / n_med - 1) · (1 / R₁ - 1 / R₂)  [підстановка умови фокусування s₁ -> ∞]
```

Для лінзи, розташованої у повітрі (`n_med ≈ 1.0003 ≈ 1`), формула набуває свого канонічного вигляду — формули шліфувальника лінз:

```
1 / f
= (n - 1) · (1 / R₁ - 1 / R₂)          [спрощення для повітряного середовища n_med = 1]
```

Одночасно, зіставляючи вираз із формулою для довільних `s₁` (позначимо `d_o` — відстань до об'єкта) та `s₂'` (позначимо `d_i` — відстань до зображення), отримуємо канонічну формулу тонкої лінзи Гауса:

```
1 / d_o + 1 / d_i = 1 / f
```

## Урахування кінцевої товщини: формула товстої лінзи

Якщо товщина лінзи `t` є порівнянною з радіусами поверхонь (реальні товсті лінзи, меніски, конденсори), то нехтувати величиною `t` не можна.

Розглянемо точний вираз для додавання заломлень на двох поверхнях без наближення `t = 0`:

```
1 / s₁ + (n / n_med) / s₁' = (n / n_med - 1) / R₁
-(n / n_med) / (s₁' - t) + 1 / s₂' = -(n / n_med - 1) / R₂
```

Аналітичний розв'язок системи для паралельного пучка на вході (`s₁ → ∞`) дає повну формулу оптичної сили товстої лінзи:

```
1 / f
= (n - 1) · (1 / R₁ - 1 / R₂) + ((n - 1)² · t) / (n · R₁ · R₂)  [точна формула товстої лінзи]
```

Звідси видно, що товщина лінзи `t > 0` вносить додатний або від'ємний корекційний внесок залежно від знаків радіусів кривини `R₁` та `R₂`. У товстій лінзі фокусна відстань `f` відраховується не від геометричного центра лінзи, а від відповідних головних площин (Principal Planes) `H₁` та `H₂`.

Положення передньої головної площини `H₁` відносно першої вершини `V₁` та положення задньої головної площини `H₂` відносно другої вершини `V₂` визначаються співвідношеннями:

```
h₁ = -(f · (n - 1) · t) / (n · R₂)
h₂ = -(f · (n - 1) · t) / (n · R₁)
```

Завдяки введенню еквівалентних площин `H₁` та `H₂`, складна оптична система з довільної кількості товстих лінз у параксіальній зоні зводиться до еквівалентної тонкої лінзи, для якої зберігається стандартне рівняння Гауса `1/d_o + 1/d_i = 1/f`.
