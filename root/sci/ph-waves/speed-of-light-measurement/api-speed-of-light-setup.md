### 2. Специфікація оптоелектронних та оптичних вузлів установки

#### 2.1. Оптичне джерело випромінювання (Лазерна головка)
- **Тип джерела:** Одночастотний гелій-неоновий (He-Ne) лазер із активною термокомпенсацією резонатора або напівпровідниковий лазерний діод із волоконним виводом.
- **Довжина хвилі у вакуумі:** `632.816 нм` (помаранчево-червоний спектр) або `850.00 нм` (ближній ІЧ-діапазон).
- **Вихідна оптична потужність:** `5.0 мВт` (Class 3R laser product згідно з IEC 60825-1).
- **Ширина спектральної лінії випромінювання:** `< 1.0 МГц` (для He-Ne лазера) або `< 10.0 МГц` (для лазерного діода з зовнішнім резонатором).
- **Поляризація:** Лінійна, поляризаційне відношення `> 500:1`, орієнтація вектора напруженості електричного поля `E` вертикальна.
- **Діаметр вихідного пучка (на рівні 1/e²):** `1.20 мм`, кутова розбіжність пучка `< 1.0 кутової мінути`.

#### 2.2. Просторовий фільтр та коліматор пучка (Beam Expander)
- **Тип схеми:** Кеплерова оптична система із мікроскопічним об'єктивом та точковою діафрагмою (pinhole).
- **Діаметр точкової діафрагми:** `25.0 мкм` (виготовлена з прецизійного штучного рубіна).
- **Коефіцієнт розширення пучка:** `1:10` (вихідний діаметр пучка `12.0 мм`).
- **Якість хвильового фронту:** Відхилення від сферичності не більше `λ / 10` по всій робочій апертурі `12 мм`.

#### 2.3. Електрооптичний модулятор (Комірка Поккельса)
- **Модуляційний кристал:** Ніобат літію (`LiNbO₃`) або дейтерований калію дигідрофосфат (`DKDP`) із поздовжнім електрооптичним ефектом.
- **Полухвильова напруга (`V_π`):** `220 В` при довжині хвилі `λ = 632.8 нм`.
- **Смуга частот модуляції:** Від DC до `200 МГц` при нерівномірності АЧХ не більше `± 1.0 дБ`.
- **Коефіцієнт оптичної контрастності модуляції:** `> 200:1`.
- **Ємність електроду модулятора:** `12.0 пФ`, вхідний хвильовий опір драйвера `50 Ом`.

#### 2.4. Світлодільні оптичні елементи (Beam Splitter Cubes)
- **Конструкція:** Неполяризаційний світлодільний куб (NPBS), складений із двох гіпотенузних призм зі скла `N-BK7`.
- **Коефіцієнт розщеплення по потужності:** `50.0% : 50.0% ± 0.5%` для s- та p-поляризацій.
- **Просвітлювальне покриття (AR-coating):** Багатошарове діелектричне покриття на усіх гранях з коефіцієнтом відбиття `R < 0.2%` на `λ = 632.8 нм`.
- **Точність прямого кута граней:** `< 5 кутових секунд`.

#### 2.5. Фотодетекторний модуль (Avalanche Photodiode, APD)
- **Тип фотодіода:** Кремнієвий лавинний фотодіод (Si APD) із вбудованим термоелектричним охолоджувачем Пельтьє та терморезистором зворотного зв'язку.
- **Діапазон спектральної чутливості:** `400–1100 нм`, пікова спектральна чутливість `0.55 А/Вт` на `800 нм`.
- **Максимальний коефіцієнт лавинного підсилення (`M`):** `100` при зсувній напрузі `180 В`.
- **Час наростання імпульсу (`t_rise`):** `< 300 пс`.
- **Еквівалентна потужність шуму (NEP):** `< 0.02 пВт / √Гц`.
- **Темновій струм:** `< 0.5 нА` при температурі кристала `-10 °C`.

#### 2.6. Таймер часових інтервалів (Time-to-Digital Converter, TDC)
- **Архітектура:** Багатокаскадна затримкова лінія з верньєрною інтерполяцією та внутрішнім фазовим автопідстроюванням частоти (PLL).
- **Найменша ціна поділу (LSB):** `5.0 пс` (`5 · 10⁻¹² с`).
- **Сквозний розкид вимірювання (RMS jitter):** `< 8.0 пс`.
- **Кількість вимірювальних каналів:** `2` (Канал 1 — Старт, Канал 2 — Стоп).
- **Мертвий час між вимірюваннями:** `< 50.0 нс`.
- **Інтерфейс передачі даних:** USB 3.0 / PCIe з підтримкою потокового виводу часових міток.

### 3. Розрахунок оптичного потужнісного бюджету та співвідношення сигнал/шум

Для забезпечення високої точності визначення часу прольоту світлового імпульсу необхідно розрахувати потужність оптичного сигналу, що повертається на фотодетектор APD, та оцінити співвідношення сигнал/шум (SNR).

Початкова вихідна потужність лазера `P_0 = 5.0 мВт`.

Проходячи крізь оптичний тракт, світло зазнає втрат на кожному елементі:
1. Просторовий фільтр та розширювач пучка: коефіцієнт пропускання `T_exp = 0.85` (втрата `15%`).
2. Електрооптичний модулятор Поккельса: коефіцієнт пропускання `T_pock = 0.90` (втрата `10%`).
3. Первинний світлодільник NPBS: ділення потужності навпіл `T_bs1 = 0.50` (втрата `50%`).
4. Поширення у повітрі на відстань `2L = 200 м`: коефіцієнт прозорості атмосфери `T_atm = 0.98` (втрата `2%`).
5. Відбиття від віддаленого ретрорефлектора: коефіцієнт відбиття `R_retro = 0.95` (втрата `5%`).
6. Вторинне проходження крізь світлодільник NPBS: `T_bs2 = 0.50` (втрата `50%`).

Результуюча оптична потужність `P_det`, що падає на фотокатод APD, обчислюється як добуток:

```
P_det = P_0 · T_exp · T_pock · T_bs1 · T_atm · R_retro · T_bs2
= 5.0 мВт · 0.85 · 0.90 · 0.50 · 0.98 · 0.95 · 0.50
= 5.0 мВт · 0.0889
= 0.4446 мВт = 444.6 мкВт
```

При чутливості APD `S_0 = 0.5 А/Вт` та коефіцієнті лавинного підсилення `M = 100` вихідний фотострум сигналу дорівнює:

```
I_photo = P_det · S_0 · M
= 444.6 мкВт · 0.5 А/Вт · 100
= 22.23 мА
```

Сумарний квадрат дробового та теплового шуму вимірювального тракту при ширині смуги `B = 500 МГц` та омирувальному навантаженні `R_L = 50 Ом` становить:

```
I_noise = √(2 · e · (I_photo + I_dark) · M² · F · B + (4 · k_B · T · B) / R_L)
≈ 1.42 мкА
```

Співвідношення сигнал/шум по струму дорівнює:

```
SNR = I_photo / I_noise = 22.23 мА / 1.42 мкА ≈ 15654 (або 83.9 дБ)
```

Таке високе значення SNR гарантує мінімальний часовий флуктуаційний дрейф (часовий тригерний джитер `< 2 пс`).

| **Джитер таймера TDC** | Випадкова | Дискретність лічильника часу | `± 5.0 пс` | `± 1.5 · 10⁻⁵` | Статистичне усереднення `N = 10000` |
| **Кутове неузгодження променя** | Систематична | Косинусна похибка нахилу тракту | `± 0.5 кут. мін`| `± 4.0 · 10⁻⁶` | Прецизійна автоколімація оптичної осі |
| **Власна фазова затримка APD** | Систематична | Температурний зсув затримки APD | `± 10.0 пс` | `± 3.0 · 10⁻5` | Диференціальний метод (Start-Stop) |

Результуюча розрахована відносна розширена невизначеність вимірювання швидкості світла (при коефіцієнті покриття `k = 2`, рівень довіри 95%) становить:

```
U_rel(c) = √((1.0 · 10⁻⁵)² + (9.5 · 10⁻⁷)² + (1.5 · 10⁻⁵)² + (3.0 · 10⁻⁵)²) ≈ 3.5 · 10⁻⁵
```

### 5. Регламент та покроковий чек-лист юстування оптичного тракту

1. **Встановлення співвісності (Coaxial Alignment Procedure):**
   - Встановити лазерне джерело та автоколіматор на віброізольованому оптичному столі з пневматичною підвіскою.
   - За допомогою двох трьохкоординатних юстувальних дзеркал спрямувати лазерний пучок уздовж поздовжньої осі вимірювального рейка з точністю не гірше `0.1 мм` по всій довжині.
   - Перевірити круглість сечення пучка за допомогою CCD-профілометра.

2. **Юстування просторового фільтра (Spatial Filter Tuning):**
   - Встановити мікрооб'єктив `10x` і юстувати точкову діафрагму `25 мкм` у його фокальній площині за допомогою мікрометричних гвинтів уздовж осей `X, Y, Z`.
   - Досягти максимального значення коефіцієнта пропускання та симетричного гауссового розподілу інтенсивності у вихідному пучку.

3. **Налаштування світлодільника (Beam Splitter Calibration):**
   - Встановити куб `NPBS` під кутом `45.0° ± 0.1°` до вхідного пучка.
   - Перевірити рівність інтенсивностей розділених променів на опорному та вимірювальному фотодіодах (співвідношення `50.0% : 50.0% ± 0.5%`).

4. **Фокусування на віддаленому ретрорефлекторі:**
   - Юстувати трипельпризму (ретрорефлектор) на кінці вимірювальної бази `L`.
   - Переконатися, що відбитий промінь повертається строго паралельно вхідному зі зміщенням не більше `0.2 мм`.

5. **Калібрування електроніки часового тракту (Zero-Baseline Calibration):**
   - Подати на вхід таймера TDC два сформованих імпульси від одного світлодільника (нульова база `L = 0`) для вимірювання власної апаратної затримки схеми (`t_zero`).
   - Віднімальна нульова заправка `t_zero` підлягає обов'язковому обліку при підрахунку підсумкового часу прольоту: `t_actual = t_measured - t_zero`.

6. **Метрологічний моніторинг навколишнього середовища:**
   - Увімкнути автоматичний запис покази каліброваних датчиків температури (похибка `± 0.05 °C`), атмосферного тиску (похибка `± 0.1 гПа`) та відносної вологості (похибка `± 1.0 %`).
   - Програмою обчислення поправок у реальному часі перераховувати поточне значення показника заломлення повітря `n_air(T, P, H)` за модифікованою формулою Едлена.

### 6. Правила техніки безпеки при роботі з лазерним випромінюванням

1. Експериментальна установка відноситься до лазерних виробів класу `Class 3R`. Випромінювання на довжині хвилі `632.8 нм` з потужністю `5 мВт` становить небезпеку для органів зору при прямому попаданні незахищеного ока у лазерний пучок.
2. Усі оператори та дослідники під час юстування та вимірювань зобов'язані носити сертифіковані захисні оптичні окуляри з оптичною щільністю `OD > 4` на довжині хвилі `600–700 нм`.
3. Категорично забороняється розміщувати на шляху поширення лазерного променя дзеркальні годинники, ювелірні вироби чи незакріплені відбиваючі предмети.
4. На вхідних дверях лабораторії має бути встановлене автоматичне світлове табло «Працює лазер!» та попереджувальні знаки лазерної небезпеки.
