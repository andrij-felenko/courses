# 🧮 Математичний аналіз та розрахункові моделі вимірювання швидкості світла

Ця математична вставка містить строгі дедуктивні виведення, геометричні розрахунки, спектральний аналіз модульованих сигналів та хвильові модельні рівняння, що лежать в основі класичних і сучасних експериментальних методів вимірювання швидкості світла. Усі математичні вирази представлено у стандартному текстовому форматі без використання LaTeX-розмітки, із дотриманням строгого вирівнювання обчислювальних кроків та квадрантних пояснень кожного алгебраїчного перетворення.

### 1. Астрономічна геометрія Ремера та орбітальна кінематика

Математичний опис часового запізнення в експерименті Оле Ремера спирається на тривимірну кінематику двох зв'язаних кеплерівських орбіт у геліоцентричній системі координат із центром у Сонці. 

Позначимо через `R_E` радіус колової орбіти Землі (`1.495978707 · 10¹¹ м`), а через `R_J` — середній радіус орбіти Юпітера (`7.785 · 10¹¹ м`). Період обертання Землі навколо Сонця становить `T_E = 1 рік` (`365.25 доби`), а кутова швидкість земної орбіти становить `ω_E = 2π / T_E ≈ 1.991 · 10⁻⁷ рад/с`. Період обертання Юпітера `T_J ≈ 11.86 року`, відповідна кутова швидкість `ω_J = 2π / T_J ≈ 1.678 · 10⁻⁸ рад/с`.

Період обертання найближчого великого супутника Іо навколо Юпітера є строго постійною величиною `T₀ = 42.4593 години` (`152 853.5 секунди`). Нехай `t_k` — момент часу `k`-го виходу Іо з конуса тіні Юпітера.

Відстань `D(t)` між Землею та Юпітером у довільний момент часу `t` визначається за теоремою косинусів для планарного трикутника Сонце — Земля — Юпітер:

```
D(t) = √(R_E² + R_J² - 2 · R_E · R_J · cos(ω_E · t - ω_J · t))
```

Оскільки кутова швидкість Землі значно перевищує кутову швидкість Юпітера (`ω_E >> ω_J`), за один короткий період обертання Іо `T₀` кутовий зсув Юпітера є нехтовно малим. Зміна відстані між планетами `ΔD` за один період `T₀` визначається проекцією вектора орбітальної швидкості Землі `v_E = ω_E · R_E ≈ 29.78 км/с` на напрямок оптичного променя:

```
ΔD = D(t + T₀) - D(t) ≈ - v_E · T₀ · sin(α)
```

де `α` — кут між векторним напрямком від Землі на Юпітер та вектором миттєвої орбітальної швидкості Землі.

Спостережуваний спостерігачем на Землі проміжок часу `T_obs` між послідовними затемненнями супутника дорівнює власному фізичному періоду `T₀` плюс затримка світла за рахунок зміни відстані `ΔD / c`:

```
T_obs = T₀ + ΔD / c
= T₀ - (v_E · T₀ / c) · sin(α)        [підстановка наближення ΔD ≈ - v_E · T₀ · sin(α)]
= T₀ · (1 - (v_E / c) · sin(α))       [винесення спільного множника T₀ за дужки]
```

При інтегруванні цієї різниці протягом пів року (від точки найменшої відстані у сполученні, коли Земля перебуває між Сонцем і Юпітером, до точки найбільшої відстані у протистоянні, коли Земля і Юпітер знаходяться по різні боки від Сонця) сумарний накопичений геометричний шлях збільшується на діаметр орбіти Землі `ΔD_total = 2 · R_E`.

Сумарний накопичений часовий зсув `Δt_total` виражається відношенням:

```
Δt_total = (2 · R_E) / c
```

Підставляючи виміряне Ремером значення `Δt_total ≈ 1320 с` (22 хвилини) та тогочасну оцінку радіуса орбіти Землі `R_E ≈ 1.40 · 10¹¹ м`, виводимо значення швидкості:

```
c = (2 · 1.40 · 10¹¹ м) / (1320 с)
= 2.80 · 10¹¹ / 1320                  [перемноження чисельника 2 · 1.40 · 10¹¹]
= 212 121 212 м/с ≈ 2.12 · 10⁸ м/с    [ділення на 1320 с, похибка ~29%]
```

З сучасним точно зафіксованим значенням радіуса астрономічної одиниці `R_E = 1.495978707 · 10¹¹ м` та часовою затримкою `Δt_total = 997.73 с`:

```
c = (2 · 1.495978707 · 10¹¹ м) / (997.73 с)
= 2.991957414 · 10¹¹ / 997.73          [подвійний орбітальний радіус Землі]
= 299 792 458 м/с                      [абсолютний збіг із сучасним значенням SI]
```

### 2. Спектральна Фур'є-модуляція світлового потоку в методі зубчастого колеса Фізо

У наземному модуляторному експерименті Армана Фізо світловий потік зазнає періодичного переривання прямокутними зубцями колеса. Математичний опис цього процесу вимагає застосування гармонічного розкладу Фур'є для періодичних імпульсних послідовностей.

Розглянемо функцію оптичного пропускання `T(φ)` зубчастого колеса із `N` однаковими зубцями та однакової ширини проміжками як функцію кута обертання `φ`. Період зубчастого рельєфу по куту становить `Ф_p = 2π / N`. Ширина проміжку дорівнює ширині зубця: `ΔФ = π / N`.

Функція пропускання `T(φ)` є симетричною меандровою функцією із значеннями `1` (відкритий проміжок) та `0` (закритий зубець). Її розклад у ряд Фур'є містить лише непарні гармоніки:

```
T(φ) = 1/2 + ∑ [від k=1 до ∞] (2 / (π · (2k - 1))) · sin((2k - 1) · N · φ)
```

При обертанні колеса зі сталою кутовою швидкістю `ω = 2π · ν` (де `ν` — частота обертання в герцах) кут обертання залежить від часу як `φ(t) = ω · t`.

Прямий світловий потік після проходження крізь колесо має інтенсивність:

```
I_out(t) = I₀ · T(ω · t)
```

Світловий імпульс долає відстань `2L` до віддаленого дзеркала і повертається через час прольоту `τ = 2L / c`. При зворотному проходженні крізь те саме колесо інтенсивність вихідного сигналу дорівнює добутку функцій пропускання в момент випромінювання `t - τ` та в момент повернення `t`:

```
I_rec(t) = I₀ · T(ω · (t - τ)) · T(ω · t)
```

Спостерігач в окулярі бачить усереднену за часом інтенсивність `<I_rec>`, оскільки людське око виступає інтегруючим фотодетектором із часом усереднення `T_obs ≈ 0.1 с`:

```
<I_rec> = (1 / T_obs) · ∫ [від 0 до T_obs] I_rec(t) dt
```

Підставляючи розклад Фур'є та інтегруючи добуток тригонометричних гармонік (ураховуючи ортогональність синусних функцій різних частот), отримуємо середня інтенсивність як функцію затримки `τ`:

```
<I_rec>(τ) = I₀ · (1/4 + 1/2 · ∑ [від k=1 до ∞] (2 / (π · (2k - 1)))² · cos((2k - 1) · N · ω · τ))
```

Умова першого мінімуму (повної темряви в окулярі) відповідає від'ємній півхвилі для першої фундаментальної гармоніки (`k = 1`), тобто `cos(N · ω · τ) = -1`:

```
N · ω · τ = π
```

Замінюючи `ω = 2π · ν` та `τ = 2L / c`:

```
N · (2π · ν) · (2L / c) = π
= 4 · π · N · L · ν / c                [перемноження числових коефіцієнтів]
⇒ 4 · N · L · ν / c = 1               [скорочення спільного множника π]
⇒ c = 4 · N · L · ν                    [вираження c через параметри установки]
```

Узагальнена умова для `m`-го затемнення (де `m = 1, 2, 3...` — номер мінімуму інтенсивності):

```
N · (2π · ν_m) · (2L / c) = (2m - 1) · π
⇒ c = (4 · N · L · ν_m) / (2m - 1)     [розв'язання відносно c]
```

### 3. Динаміка кутового відхилення у дзеркальній системі Фуко — Майкельсона

У лабораторній схемі Леона Фуко та Альберта Майкельсона вимірювання швидкості світла зводиться до вимірювання малого кутового зміщення поверненого оптичного променя.

Нехай світло від джерела `S` відбивається від плоского дзеркала `R`, що обертається з кутовою швидкістю `ω = 2π · ν`, прямує до увігнутого дзеркала `M` радіуса `R_m = L`, відбивається під прямим кутом і повертається до дзеркала `R`.

Нехай `r` — відстань від джерела `S` до обертового дзеркала `R`, а `L` — базова відстань між `R` та `M`.

За час двохідного прольоту світла `τ = 2L / c` обертове дзеркало встигає повернутися на кут:

```
Δθ = ω · τ = (2 · ω · L) / c
```

Згідно із законом відбиття світла, при повороті дзеркала на кут `Δθ` нормаль до поверхні повертається на `Δθ`, а відбитий промінь повертається на подвійний кут:

```
ΔΨ = 2 · Δθ = (4 · ω · L) / c
```

Зсув плями світла `Δx` на вимірювальний шкалі, розміщеній на відстані `r` від дзеркала `R`, становить:

```
Δx = r · tan(ΔΨ) ≈ r · ΔΨ             [малі кути ΔΨ << 1 рад: tan(ΔΨ) ≈ ΔΨ]
= (4 · r · ω · L) / c                  [підстановка значення ΔΨ = 4 ω L / c]
```

Звідси виражаємо швидкість світла:

```
c = (4 · r · ω · L) / Δx
```

Для восьмигранної призми Майкельсона з радіусом грані `R_p` та кутом між суміжними гранями `α = 2π / 8 = 45° = π / 4` умова стаціонарного (нерухомого) зображення полягає у тому, що призма за час прольоту `τ` має повернутися точно на кут `α`:

```
ω · τ = α
⇒ (2π · ν) · (2L / c) = π / 4          [підстановка ω = 2π ν та τ = 2L / c]
⇒ (4π · ν · L) / c = π / 4             [перемноження коефіцієнтів у лівій частині]
⇒ c = 16 · ν · L                       [скорочення π та множення обох частин на 4 c]
```

Зразок числового розрахунку для установки Майкельсона 1926 року (`L = 35 373.7 м`, `ν = 528.25 Гц`):

```
c = 16 · (528.25 с⁻¹) · (35 373.7 м)
= 8452.0 · 35 373.7                    [перемноження 16 · 528.25]
= 299 796 000 м/с ≈ 299 796 км/с        [обчислення добутку]
```

### 4. Електродинаміка об'ємних резонаторів та фазово-групове співвідношення

У металевому циліндричному резонаторі з радіусом `R` та довжиною `L` вектор електромагнітного поля задовольняє диференціальне рівняння Гельмгольца:

```
∇² E + (ω / c)² · E = 0
```

Для модових коливань `TE_mnl` (трансверсально-електричних) потенціал поля розкладається у функції Бесселя `J_m(x)`. Резонансна частота `ν_mnl` визначається формулою:

```
ν_mnl = (c / (2π)) · √((x'_mn / R)² + (l · π / L)²)
```

де `x'_mn` — `n`-й нуль похідної функції Бесселя `J'_m(x) = 0`.

Для модального коливання `TE₀₁₁` перший нуль похідної функції Бесселя першого порядку дорівнює `x'_01 ≈ 3.83171`.

Виражаємо швидкість світла у вакуумі через виміряну частоту `ν_011` та геометрію резонатора:

```
c = (2π · ν_011) / √((3.83171 / R)² + (π / L)²)
```

З урахуванням скінченної провідності стінок `σ` (через що скін-шар `δ = √(2 / (μ₀ · σ · ω))` трохи змінює ефективний об'єм резонатора), фундаментальна формула набуває виправленого вигляду:

```
c_vac = c_meas · (1 + δ / (2 · R) · A_geometric)
```

У середовищах із оптичною дисперсією необхідно чітко розрізняти фазову `v_p` та групову `v_g` швидкості. Фазова швидкість монохроматичної хвилі дорівнює:

```
v_p = ω / k = c / n(ω)
```

Групова швидкість огинаючої імпульсу (хвильового пакета) виражається похідною:

```
v_g = dω / dk = c / (n(ω) + ω · (dn / dω))
```

У металевих хвилеводах або плазмі фазова швидкість може перевищувати швидкість світла у вакуумі (`v_p > c`), проте групова швидкість `v_g`, яка переносить енергію та інформацію, завжди залишається строго меншою за `c`.

### 5. Спеціальна теорія відносності та інваріантність c

У спеціальній теорії відносності швидкість світла у вакуумі `c` є граничною швидкістю передачі сигналів та інваріантом відносно перетворень Лоренца.

Якщо у інерціальній системі відліку `S'` світловий імпульс поширюється зі швидкістю `u' = c`, то у системі `S`, яка рухається відносно `S'` зі швидкістю `v`, релятивістська формула додавання швидкостей дає:

```
u = (u' + v) / (1 + (u' · v) / c²)
= (c + v) / (1 + (c · v) / c²)        [підстановка u' = c у релятивістську формулу]
= (c + v) / (1 + v / c)                [скорочення c у знаменнику: (c · v) / c² = v / c]
= (c + v) / ((c + v) / c)              [зведення знаменника до спільного дробу (c + v) / c]
= c                                    [скорочення однакового чисельника й знаменника (c + v)]
```

Це математично підтверджує, що швидкість світла у вакуумі однакова в усіх інерціальних системах відліку, що й дозволило зафіксувати її як абсолютний фундаментальний метрологічний еталон `c ≡ 299 792 458 м/с`.
