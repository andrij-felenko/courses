# 📋 Довідник граничних умов, модових частот та коефіцієнтів відбиття

Цей довідник містить систематичні таблиці граничних умов, формули резонансних частот для механічних, акустичних та електромагнітних резонаторів різних геометрій, а також повні розрахункові співвідношення для коефіцієнта стоячої хвилі (КСХ / SWR), коефіцієнта відбиття та втрат неузгодження.

Довідник призначений для швидкого розрахунку параметрів стоячих хвиль у фізичних та інженерних задачах: від налаштування музичних інструментів та проектування звукоізоляції приміщень до розрахунку високовольтних фідерних ліній і НВЧ-резонаторів.

### 1. Класифікація граничних умов та фазові зсуви при відбиванні

При досягненні межі двох середовищ хвиля зазнає відбивання, характер якого залежить від відносного співвідношення імпедансу середовища поширення `Z₀` та імпедансу межі `Z_L`.

Якщо імпеданс межі перевищує імпеданс середовища (`Z_L > Z₀`), відбита хвиля зберігає або змінює фазу залежно від того, яке саме хвильове поле розглядається. У таблиці нижче наведено систематизований зсув фаз та розташування вузлів і пучностей для двох взаємопов'язаних полів (наприклад, тиску та швидкості в акустиці або напруги та струму в електродинаміці).

| Тип середовища | Гранична умова | Імпеданс межі | Фазовий зсув `Δφ` | Коефіцієнт відбиття `Γ` | Стан на межі (Поле 1) | Стан на межі (Поле 2) |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **Механічна струна** | Нерухоме закріплення | `Z_L → ∞` | `180° (π)` | `−1.0` | Вузол зміщення (`u = 0`) | Пучність натягу |
| **Механічна струна** | Вільний кінець (кільце) | `Z_L → 0` | `0°` | `+1.0` | Пучність зміщення (`2A`) | Вузол натягу |
| **Акустична труба** | Затворений кінець (стінка) | `Z_A → ∞` | `0°` (для тиску) | `+1.0` (тиск) | Пучність акуст. тиску (`p`) | Вузол швидкості (`v = 0`) |
| **Акустична труба** | Відкритий кінець | `Z_A → 0` | `180°` (для тиску) | `−1.0` (тиск) | Вузол акуст. тиску (`p = 0`) | Пучність швидкості (`v`) |
| **Лінія передачі (RF)** | Коротке замикання (КЗ) | `Z_L = 0` | `180°` (напруга) | `−1.0` (напруга) | Вузол напруги (`V = 0`) | Пучність струму (`I`) |
| **Лінія передачі (RF)** | Холостий хід (ХХ) | `Z_L → ∞` | `0°` (напруга) | `+1.0` (напруга) | Пучність напруги (`V`) | Вузол струму (`I = 0`) |
| **Лінія передачі (RF)** | Узгоджене навантаження | `Z_L = Z₀` | Немає відбиття | `0.0` | Біжуча хвиля | Біжуча хвиля |

Важливе інженерне правило: **вузол одного поля завжди збігається з пучністю дуального поля**. Наприклад, у закритому кінці акустичної труби коливальна швидкість повітря дорівнює нулю (вузол швидкості), проте скачки тиску там максимальні (пучність тиску). У короткозамкненому кінці коаксіального кабелю напруга дорівнює нулю (вузол напруги), але струм сягає пікового значення (пучність струму).

### 2. Формули власних частот та модових спектрів резонаторів

Власні частоти стоячих хвиль визначаються геометричними розмірами резонатора та швидкістю поширення хвилі `v` у середовищі (`v = √(T/μ)` для механічної струни, `v = c` для акустичних та електромагнітних хвиль).

#### А. Напівхвильовий резонатор (Оба кінці однакового типу)
*Фізичні системи:* струна із затиснутими кінцями, труба відкрита з обох кінців, труба закрита з обох кінців, двопровідна лінія замкнена з обох боків.
- **Умова існування стоячої хвилі:** Довжина резонатора `L` повинна вміщувати ціле число півхвиль: `L = n · (λ / 2)`.
- **Формула довжин хвиль:**
  ```
  λ[n] = 2·L / n   [де n = 1, 2, 3, 4, ...]
  ```
- **Формула резонансних частот:**
  ```
  f[n] = n · (v / (2·L)) = n · f₁   [де f₁ = v / 2L — основна частота]
  ```
- **Характер спектра:** Спектр містить **усі без винятку цілочисельні гармоніки** (основний тон `f₁`, друга гармоніка `2·f₁`, третя `3·f₁`, четверта `4·f₁` тощо). Це створює багатий та гармонійний тембр струнних і духових музичних інструментів.

#### Б. Чвертьхвильовий резонатор (Кінці різного типу)
*Фізичні системи:* органна труба закрита з одного кінця і відкрита з іншого, органола, чвертьхвильовий шлейф лінії передачі, слуховий прохід людини.
- **Умова існування стоячої хвилі:** Довжина резонатора `L` повинна вміщувати непарне число чвертей хвилі: `L = (2·n − 1) · (λ / 4)`.
- **Формула довжин хвиль:**
  ```
  λ[n] = 4·L / (2·n − 1)   [де n = 1, 2, 3, 4, ...]
  ```
- **Формула резонансних частот:**
  ```
  f[n] = (2·n − 1) · (v / (4·L)) = (2·n − 1) · f₁   [де f₁ = v / 4L — основна частота]
  ```
- **Характер спектра:** Спектр містить **виключно непарні гармоніки** (`f₁`, `3·f₁`, `5·f₁`, `7·f₁`...). Усі парні гармоніки повністю пригнічені геометричними граничними умовами.

#### В. Прямокутний тривимірний резонатор (3D Cavity / Акустика приміщення / НВЧ)
*Фізичні системи:* концертні зали та дикторські кабіни (моди приміщення — «стоячі гули»), об'ємні металеві резонатори НВЧ-генераторів (магнетронів), оптичні резонатори.
- **Загальна формула модових частот:**
  ```
  f[l, m, n] = (v / 2) · √[ (l / L_x)² + (m / L_y)² + (n / L_z)² ]
  ```
  де `L_x, L_y, L_z` — внутрішні геометричні розміри резонатора вздовж трьох осей, а `l, m, n = 0, 1, 2, 3...` — цілочисельні модові індекси. Індекси показують кількість півхвиль, що вкладаються вздовж відповідної осі.

#### Г. Кругла мембрана / Циліндричний акустичний резонатор
*Фізичні системи:* шкіра барабана, мембрана конденсаторного мікрофона, циліндричний об'ємний резонатор.
- **Формула частот власних коливань:**
  ```
  f[m, n] = (v / (2·π·R)) · α[m, n]
  ```
  де `R` — радіус мембрани, `m` — кількість вузлових діаметрів, `n` — кількість вузлових кіл, а `α[m, n]` — `n`-й нуль функції Бесселя першого роду порядку `m` (`J_m(α) = 0`).
  - `α[0, 1] ≈ 2.4048` (основна мода мембрани `f₀₁ = 0.3827 · v / R`)
  - `α[1, 1] ≈ 3.8317` (`f₁₁ = 0.6099 · v / R`)
  - `α[2, 1] ≈ 5.1356` (`f₂₁ = 0.8174 · v / R`)
  - `α[0, 2] ≈ 5.5201` (`f₀₂ = 0.8788 · v / R`)

На відміну від струни, спектр круглої мембрани є **негармонійним** (співвідношення частот не є цілими числами), тому ударні інструменти з мембраною мають шумовіший, нефіксований висотний тон.

### 3. Таблиця коефіцієнта стоячої хвилі (КСХ / SWR) та параметрів узгодження

Коефіцієнт стоячої хвилі по напрузі (КСХН / VSWR) характеризує ступінь неузгодження навантаження з лінією передачі і визначається через модуль коефіцієнта відбиття `|Γ|`:

```
SWR = (1 + |Γ|) / (1 − |Γ|)
```

Модуль коефіцієнта відбиття `|Γ|` виражається через імпеданс лінії `Z₀` та комплексний імпеданс навантаження `Z_L`:

```
|Γ| = | (Z_L − Z₀) / (Z_L + Z₀) |
```

Параметри втрат на відбиття (Return Loss, `RL`) та частка пропущеної і відбитої потужності розраховуються за формулами:

```
RL = −20 · log₁₀(|Γ|)   [дБ]
P_відб / P_пад = |Γ|²
P_проп / P_пад = 1 − |Γ|²
```

### 4. Фізичні аналоги стоячих хвиль у різних областях

Завдяки універсальності хвильового рівняння, стоячі хвилі в механіці, акустиці, електродинаміці та квантовій фізиці описуються тотожними математичними структурами.

| Параметр / Явище | Механічна струна | Акустичний резонатор | Електромагнітна лінія (RF) | Квантовий атом (Бор/Шредінгер) |
| :--- | :--- | :--- | :--- | :--- |
| **Хвильове поле 1** | Зміщення `u(x, t)` | Акустичний тиск `p(x, t)` | Напруга `V(x, t)` | Хвильова функція `Ψ(r, t)` |
| **Хвильове поле 2** | Сила натягу `F(x, t)` | Коливальна швидкість `v(x, t)` | Струм `I(x, t)` | Густина ймовірності `\|Ψ\|²` |
| **Характеристичний імпеданс** | `Z = √(T₀·μ)` | `Z_A = ρ·c` | `Z₀ = √(L / C)` | `Z_q = ℏ / m` |
| **Умова Вузла Поля 1** | Закріплений кінець (`u=0`) | Відкритий кінець (`p=0`) | Коротке замикання (`V=0`) | Вузлова поверхня (`Ψ=0`) |
| **Умова Пучності Поля 1** | Вільний кінець (`u=max`) | Закритий кінець (`p=max`) | Холостий хід (`V=max`) | Максимум електронної хмари |
| **Квантування частот** | `f_n = n·v / 2L` | `f_n = n·c / 2L` | `f_n = n·c / 2L` | `E_n = −13.6 eV / n²` |

### 5. Інженерні методи ліквідації небажаних стоячих хвиль

У високочастотних та високовольтних радіофізичних системах стоячі хвилі є шкідливим явищем, оскільки пучності напруги спричиняють електричний пробій ізоляції, а відбита потужність розсіюється у вигляді тепла на вихідних каскадах передавачів. Для усунення стоячих хвиль застосовують спеціальні методи узгодження імпедансу навантаження `Z_L` з хвильовим імпедансом лінії `Z₀`:

1. **Чвертьхвильовий трансформатор імпедансу:**
   Між лінією з імпедансом `Z₀` та навантаженням `Z_L` вставляють відрізок лінії довжиною `L = λ / 4` з хвильовим імпедансом `Z_m`:
   ```
   Z_m = √( Z₀ · Z_L )   [імпеданс чвертьхвильового трансформатора]
   ```
   Такий трансформатор перетворює опір `Z_L` точно в `Z₀`, завдяки чому з лівого боку трансформатора стояча хвиля повністю зникає (`SWR = 1.0`).

2. **Шлейфове узгодження (Stub matching):**
   На визначеній відстані від навантаження паралельно до основної лінії підключають короткозамкнений або відкритий відрізок лінії (шлейф), який створює реактивну провідність, протилежну за знаком реактивності навантаження.

3. **Акустичні та оптичні поглиначі:**
   Для запобігання утворенню стоячих хвиль у приміщеннях (безлунні камери) стіни покривають клиноподібними поглиначами з пористого матеріалу, чий акустичний імпеданс плавно змінюється від імпедансу повітря `ρ·c` до високого згасання в глибині матеріалу.
