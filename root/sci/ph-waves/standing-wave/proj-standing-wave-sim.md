# ⚙️ Проєктна вставка: симуляція стоячих хвиль та відбивання від меж

Моделювання стоячих хвиль дає змогу побачити на екрані фундаментальні хвильові процеси, які важко зафіксувати в реальному лабораторному експерименті: динамічне виникнення нерухомих вузлів під час зустрічі двох імпульсів, інверсію фази при відбиванні від жорсткого закріплення, збереження фази при вільному кінці, перекачування локальної енергії та утворення частково стоячих хвиль при неузгодженій межі.

---

### Задача та математична основа FDTD (Finite-Difference Time-Domain)

Одновимірне лінійне хвильове рівняння описує зміщення струни або тиск у газовому стовпі `u(x, t)` залежно від координати `x` та часу `t`:

```
∂²u / ∂t² = v² · (∂²u / ∂x²)
```

Для чисельного розв'язання цього рівняння застосуємо метод скінченних різницях у часовій області (**FDTD**, англ. *Finite-Difference Time-Domain*). Розіб'ємо одновимірний простір довжиною `L` на `N` рівновіддалених вузлів із кроком `dx = L / (N - 1)`, а час — на дискретні інтервали `dt`. Позначимо зміщення у вузлі `i` на часовому кроці `n` як `u[i][n]`.

Замінивши другі частинні похідні симетричними центральними скінченними різницями другого порядку точності, отримуємо різницеве рівняння:

```
(u[i][n+1] − 2·u[i][n] + u[i][n−1]) / dt² = v² · (u[i+1][n] − 2·u[i][n] + u[i−1][n]) / dx²
```

Виразимо шукане зміщення на наступному часовому кроці `u[i][n+1]` через відомі значення на поточному `n` та попередньому `n-1` кроках:

```
u[i][n+1] = 2·u[i][n] − u[i][n−1] + C² · (u[i+1][n] − 2·u[i][n] + u[i−1][n])   [явна схема FDTD]
```

Тут безрозмірний коефіцієнт `C = v · dt / dx` зветься **числом Куранта** (Courant number). Щоб обчислювальна схема була числово стійкою і розв'язок не прямував до нескінченності, мусить суворо виконуватися **умова Куранта — Фрідріхса — Леві (CFL)**:

```
C = v · dt / dx ≤ 1.0   [умова стійкості Куранта]
```

Фізичний зміст умови CFL полягає в тому, що чисельна швидкість поширення інформації по сітці `dx / dt` повинна бути не меншою за фізичну швидкість хвилі `v`. Якщо обрати крок `dt` занадто великим, обчислювальна схема спробує передати хвилю швидше, ніж дозволяє сітка, що призведе до миттєвого вибуху чисельної нестійкості.

### Математична реалізація граничних умов

У FDTD-симуляторах граничні умови задаються шляхом спеціального розрахунку крайніх вузлів сітки `u[0]` та `u[N-1]`:

1. **Жорстко закріплений кінець (Вузол зміщення):** Оскільки точка середовища на межі закріплена наглухо, її зміщення залишається тотожно нульовим для всіх моментів часу:
   ```
   u[0][n+1] = 0,   u[N-1][n+1] = 0
   ```
2. **Вільний кінець (Пучність зміщення):** На вільному кінці відсутня повертальна сила, тому просторова похідна зміщення дорівнює нулю `∂u / ∂x = 0`. У скінченно-різницевому вигляді це означає рівність зміщення крайньої точки та її сусідки:
   ```
   u[N-1][n+1] = u[N-2][n+1]
   ```
3. **Частково відбивальна межа (Неузгоджене навантаження):** Якщо межа характеризується коефіцієнтом відбиття `|Γ| < 1`, зміщення граничного вузла моделюється через комбінацію запізнювальної падаючої та відбитої хвилі або за допомогою зосередженого опору навантаження `Z_L`.

### Чисельне визначення коефіцієнта стоячої хвилі (КСХ / SWR)

Для розрахунку КСХ після завершення симуляції програма аналізує сформований масив обвідної `envelope[i]`. Алгоритм знаходить глобальний максимум `V_max` та локальний мінімум `V_min` у сталому режимі:

```
V_max = max(envelope[i])
V_min = min(envelope[i] для i у стаціонарній зоні)
```

Якщо `V_min` наближається до нуля (ідеальна стояча хвиля), значення КСХ прямує до нескінченності `SWR → ∞`. Для запобігання діленню на нуль у програмі вводять мале число `ε = 1e-6`:

```
SWR = V_max / (V_min + ε)
```

Модуль коефіцієнта відбиття `|Γ|` обчислюється зворотним перетворенням:

```
|Γ| = (SWR − 1) / (SWR + 1)
```

Це дає змогу чисельно оцінити якість узгодження віртуального навантаження безпосередньо з вихідних даних сітки.

### Обчислення повної чисельної енергії сітки

Для контролю збереження енергії у FDTD-схемі на кожному часовому кроці обчислюється сума кінетичної та потенціальної енергій усіх комірок:

```
E_кін = (1/2) · μ · dx · ∑_(i=1)^(N-2) [ (u[i][n+1] − u[i][n]) / dt ]²
E_пот = (1/2) · T₀ · (1/dx) · ∑_(i=0)^(N-2) [ u[i+1][n] − u[i][n] ]²
```

У недисипативній чисельній системі сума `E_кін + E_пот` повинна залишатися строго константною з точністю до `O(dt²)`.

### Пастки та інженерні нюанси чисельного моделювання

1. **Порушення умови Куранта (`C > 1.0`):** Запрограмувати схему так, що `C = 1.05`, здається незначною зміною, проте в чисельних експериментах це призводить до вибухового росту амплітуди. За кілька десятків кроків обчислень зміщення переходять у значення `NaN` (Not a Number). Завжди контролюйте `dt ≤ dx / v`.
2. **Чисельна дисперсія сітки:** У дискретній FDTD-сітці фазова швидкість чисельної хвилі залежить від її частоти та кроку сітки `dx`. Високочастотні гармоніки біжать повільніше за низькочастотні, що призводить до «розмивання» гострих хвильових фронтів. Для точного моделювання стоячих хвиль довжина хвилі `λ` мусить покриватися щонайменше 15–20 дискретними комірками (`λ / dx ≥ 20`).
3. **Паразитні відбиття на межах обчислювальної області:** Якщо ваша мета — змоделювати вільне поширення хвилі без утворення стоячих візерунків, звичайна зупинка сітки на вузлі `N-1` розцінюватиметься системою як жорстке або вільне закріплення і неминуче згенерує стоячу хвилю. Для запобігання відбиттям застосовують поглинальні граничні умови (Mur ABC) або розмиті поглинальні шари (PML — Perfectly Matched Layers).
4. **Вибір методу інтегрування за часом:** Для високої точності збереження повної енергії стоячої хвилі без чисельного згасання використовують симплектичні схеми типу Верле (Leapfrog / Velocity Verlet), які точно зберігають фазовий об'єм симуляції.
