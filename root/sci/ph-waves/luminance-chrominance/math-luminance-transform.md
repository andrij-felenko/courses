# 🧮 Математичні основи яскравості та матричних перетворень колірності

Математична теорія розділення колірного сигналу спирається на функціональний аналіз спектральної густини випромінювання, інтегрування за кривими фотометричної чутливості людського ока та лінійне перетворення простору стимулів у афінний ортогональний базис «яскравість — колірні координати». Цей файл розкриває виведення коефіцієнтів фотометричної яскравості для стандартів BT.601, BT.709 та BT.2020, математичну різницю між лінійною яскравістю та гама-корегованою світлотою (Luma), а також формули квантування й масштабування матриць YCbCr у 8-бітному та 10-бітному цифровому поданні.

## Фізико-математичне визначення фотометричної яскравості

Світловий потік `Φ_v` (у люменах), що сприймається людським оком від джерела із спектральною густиною випромінювання `P(λ)` (у ватах на нанометр), визначається інтегральним згортанням спектра з функцією відносної спектральної світлової ефективності моноптичного (денного) зору `V(λ)`:

```
Φ_v = K_m · ∫ P(λ) · V(λ) dλ
```

де:
- `K_m ≈ 683` лм/Вт — максимальна світлова віддача монохроматичного випромінювання на довжині хвилі `555` нм;
- `V(λ)` — нормована безрозмірна функція стандарту CIE 1931, що дорівнює `1.0` на довжині хвилі `555` нм та прямує до нуля на межах видимого діапазону (`380` нм та `780` нм).

У колориметричній системі CIE 1931 XYZ три стимули `X`, `Y`, `Z` визначаються інтегруванням спектра `P(λ)` із трьома стандартними функціями додавання кольорів `x̄(λ)`, `ȳ(λ)`, `z̄(λ)`:

```
X = K_m · ∫ P(λ) · x̄(λ) dλ
Y = K_m · ∫ P(λ) · ȳ(λ) dλ     [де ȳ(λ) ≡ V(λ)]
Z = K_m · ∫ P(λ) · z̄(λ) dλ
```

Головною математичною властивістю системи CIE XYZ є те, що друга координата `Y` вибрана так, щоб вона строго збігалася з фотометричною яскравістю світлового потоку. Координати `X` та `Z` відповідають за колірність та не несуть інформації про абсолютну яскравість.

## Математичний зв'язок між системами RGB та CIE XYZ

Будь-яка аддитивна система відтворення кольору (дисплей, кінескоп, проектор) визначається трьома опорними точками кольоровості первинних випромінювачів (Червоного `R`, Зеленого `G`, Синього `B`) та опорною точкою білого кольору `W` у хроматичних координатах `(x, y)` системи CIE 1931.

Хроматичні координати `(x, y)` пов'язані з `(X, Y, Z)` співвідношеннями нормування:

```
x = X / (X + Y + Z)
y = Y / (X + Y + Z)
z = 1 - x - y
```

Перехід від лінійних координат `RGB` до координат `XYZ` здійснюється через лінійне матричне перетворення `M`:

```
┌   ┐   ┌             ┐ ┌   ┐
│ X │   │ X_r X_g X_b │ │ R │
│ Y │ = │ Y_r Y_g Y_b │ · │ G │
│ Z │   │ Z_r Z_g Z_b │ │ B │
└   ┘   └             ┘ └   ┘
```

Оскільки вимога до координати `Y` полягає у вираженні повної фотометричної яскравості, другий рядок матриці `M` визначає вагові коефіцієнти `W_r`, `W_g`, `W_b` для суми яскравостей окремих каналів:

```
Y = W_r · R + W_g · G + W_b · B
```

причому за нормуванням білого кольору `(R = 1, G = 1, B = 1 ⇒ Y = 1)` сума коефіцієнтів строго дорівнює одиниці:

```
W_r + W_g + W_b = 1.0
```

## Математичне виведення коефіцієнтів для BT.601, BT.709 та BT.2020

Різні стандарти відеовиробництва використовують різні фізичні люмінофори та спектральні первинні кольори. Розрахунок вагових коефіцієнтів виконується шляхом розв'язання системи лінійних алгебраїчних рівнянь, що зв'язують хроматичні координати первинних кольорів із точкою білого.

### 1. Виведення для стандарту ITU-R BT.601 (SDTV)

Стандарт BT.601 базується на первинних кольорах американського стандарту NTSC (1953) та європейського EBU Tech 3213:
- Червоний `R`: `x_r = 0.67`, `y_r = 0.33`
- Зелений `G`: `x_g = 0.21`, `y_g = 0.71`
- Синій `B`: `x_b = 0.14`, `y_b = 0.08`
- Точка білого `D65`: `x_w = 0.3127`, `y_w = 0.3290`

Розв'язок системи для вираження `Y` дає точні вагові коефіцієнти:

```
W_r = 0.2990
W_g = 0.5870
W_b = 0.1140
```

Отже, рівняння яскравості SDTV приймає вигляд:

```
Y = 0.2990·R + 0.5870·G + 0.1140·B
```

### 2. Виведення для стандарту ITU-R BT.709 (HDTV / sRGB)

Стандарт BT.709 прийнятий для телебачення високої чіткості 1080p та моніторів комп'ютерів. Він використовує світлодіоди та люмінофори з іншими спектральними піками:
- Червоний `R`: `x_r = 0.64`, `y_r = 0.33`
- Зелений `G`: `x_g = 0.30`, `y_g = 0.60`
- Синій `B`: `x_b = 0.15`, `y_b = 0.06`
- Точка білого `D65`: `x_w = 0.3127`, `y_w = 0.3290`

Оскільки зелений первинний колір у BT.709 є насиченішим та ближчим до спектрального піку `555` нм, його вага у формуванні яскравості зросла до 71.5%:

```
W_r = 0.2126
W_g = 0.7152
W_b = 0.0722
```

Рівняння яскравості HDTV:

```
Y = 0.2126·R + 0.7152·G + 0.0722·B
```

### 3. Виведення для стандарту ITU-R BT.2020 / BT.2100 (UHDTV 4K/8K / HDR)

Стандарт BT.2020 розроблений для відео надвисокої чіткості з широким колірним охопленням (Wide Color Gamut):
- Червоний `R`: `x_r = 0.708`, `y_r = 0.292` (монохроматичний лазер `630` нм)
- Зелений `G`: `x_g = 0.170`, `y_g = 0.797` (монохроматичний лазер `532` нм)
- Синій `B`: `x_b = 0.131`, `y_b = 0.046` (монохроматичний лазер `467` нм)

Вагові коефіцієнти для BT.2020:

```
W_r = 0.2627
W_g = 0.6780
W_b = 0.0593
```

## Лінійна яскравість Y проти нелінійної світлоти Y' (Luma)

У реальних інженерних відеосистемах матричні перетворення виконуються не над лінійними сигналами інтенсивності `RGB`, а над гама-корегованими сигналами `R'G'B'`.

Гама-корекція стискає динамічний діапазон відповідно до степеневої характеристики дисплеїв та нелінійності сприйняття зору Стівенса (де відчуття світлості пропорційне кубічному кореню від фізичної інтенсивності):

```
R' = R^(1/γ)
G' = G^(1/γ)
B' = B^(1/γ)
```

де значення `γ ≈ 2.2` для NTSC/PAL або складніша передавальна функція передачі (EOTF) стандарту sRGB / BT.709 із лінійною ділянкою біля нуля:

```
R' = 12.92 · R,                  якщо R ≤ 0.0031308
R' = 1.055 · R^(1/2.4) - 0.055,  якщо R > 0.0031308
```

Світловий сигнал `Y'`, який формується як лінійна комбінація гама-корегованих компонентів, називається **ахроматичною світлотою** або **Luma**:

```
Y' = W_r · R' + W_g · G' + W_b · B'
```

### Математичний аналіз помилки нелінійності (Non-constant Luminance Problem)

Оскільки степенева функція піднесення до степеня не є лінійною `(a + b)^n ≠ a^n + b^n`, справжня відновлена фізична яскравість `(Y')^γ` не дорівнює істинній лінійній яскравості `Y`:

```
Y = W_r · R + W_g · G + W_b · B
≠ (W_r · R' + W_g · G' + W_b · B')^γ = (Y')^γ
```

Ця розбіжність призводить до того, що колірнорізницеві канали `Cb` та `Cr` несуть у собі частину інформації про яскравість. Під час субдискретизації 4:2:0 ця відкинута частина яскравісного сигналу втрачається, що викликає затемнення та артефакти розмиття на висококонтрастних насичених межах (наприклад, на межі між яскраво-червоним та зеленим об'єктами).

У стандарті **BT.2020 Constant Luminance (CL)** висунуто математичну альтернативу: спочатку обчислювати лінійну яскравість `Y`, а потім піддавати гама-корекції саме її `Y' = Y^(1/γ)`. Це усуває витік яскравості в колірні канали, але вимагає значно складніших обчислювальних блоків у мікросхемах.

## Побудова та нормування колірнорізницевих сигналів Cb та Cr

Після формування `Y'` будуються два різницеві сигнали відносно синього та червоного кольорів:

```
B' - Y' = B' - (W_r·R' + W_g·G' + W_b·B') = (1 - W_b)·B' - W_r·R' - W_g·G'
R' - Y' = R' - (W_r·R' + W_g·G' + W_b·B') = (1 - W_r)·R' - W_g·G' - W_b·B'
```

Область значень змінної `B' - Y'` становить `[-(1 - W_b), +(1 - W_b)]`.
Область значень змінної `R' - Y'` становить `[-(1 - W_r), +(1 - W_r)]`.

Щоб нормувати ці діапазони до симетричного інтервалу `[-0.5, +0.5]`, їх множать на нормувальні масштабові коефіцієнти `K_b` та `K_r`:

```
K_b = 0.5 / (1 - W_b)
K_r = 0.5 / (1 - W_r)

Cb = K_b · (B' - Y')
Cr = K_r · (R' - Y')
```

### 1. Нормування для стандарту BT.601 (`W_r = 0.299`, `W_b = 0.114`)

```
K_b = 0.5 / (1 - 0.114) = 0.5 / 0.886 ≈ 0.56433
K_r = 0.5 / (1 - 0.299) = 0.5 / 0.701 ≈ 0.71327

Cb = 0.56433 · (B' - Y') = -0.16874·R' - 0.33126·G' + 0.50000·B'
Cr = 0.71327 · (R' - Y') =  0.50000·R' - 0.41869·G' - 0.08131·B'
```

### 2. Нормування для стандарту BT.709 (`W_r = 0.2126`, `W_b = 0.0722`)

```
K_b = 0.5 / (1 - 0.0722) = 0.5 / 0.9278 ≈ 0.53891
K_r = 0.5 / (1 - 0.2126) = 0.5 / 0.7874 ≈ 0.63494

Cb = -0.11457·R' - 0.38543·G' + 0.50000·B'
Cr =  0.50000·R' - 0.45415·G' - 0.04585·B'
```

## Матрична форма та квантування в 8-бітному цифровому відео

У прямому матричному вигляді для нормованих сигналів `R', G', B' ∈ [0.0, 1.0]` пряме перетворення BT.601 записується так:

```
┌    ┐   ┌  0.29900   0.58700   0.11400 ┐ ┌    ┐
│ Y' │   │                              │ │ R' │
│ Cb │ = │ -0.16874  -0.33126   0.50000 │ · │ G' │
│ Cr │   │  0.50000  -0.41869  -0.08131 │ │ B' │
└    ┘   └                              ┘ └    ┘
```

Зворотна матриця для відновлення `R', G', B'`:

```
┌    ┐   ┌ 1.00000   0.00000   1.40200 ┐ ┌    ┐
│ R' │   │                             │ │ Y' │
│ G' │ = │ 1.00000  -0.34414  -0.71414 │ · │ Cb │
│ B' │   │ 1.00000   1.77200   0.00000 │ │ Cr │
└    ┘   └                             ┘ └    ┘
```

### Дискретизація та обмежений діапазон (Limited Range / Studio Swing)

У цифрових 8-бітних відеосистемах рівні `0` та `255` зарезервовані для сигналів системної синхронізації та захисту від зрізання амплітуди під час фільтрації.

Специфікація визначає два режими квантування:
1. **Full Range (Full Swing / PC Range):** `Y`, `Cb`, `Cr` займають увесь діапазон `[0, 255]`. Використовується в кодеку JPEG та комп'ютерній графіці.
2. **Limited Range (Studio Swing / TV Range):**
   - Компонента яскравості `Y_8bit` квантується в діапазоні `[16, 235]` (всього `220` рівнів квантування);
   - Колірнорізницеві компоненти `Cb_8bit` та `Cr_8bit` квантуються в діапазоні `[16, 240]` із центром у `128` (всього `224` рівні квантування).

Точні формули переведення з нормованого `R'G'B' ∈ [0.0, 1.0]` у 8-бітний ограниченний YCbCr (BT.601):

```
Y_8bit  = 16  + 219 · ( 0.29900·R' + 0.58700·G' + 0.11400·B' )
Cb_8bit = 128 + 224 · ( -0.16874·R' - 0.33126·G' + 0.50000·B' )
Cr_8bit = 128 + 224 · (  0.50000·R' - 0.41869·G' - 0.08131·B' )
```

У розгорнутому вигляді для цілочисельних вхідних даних `R, G, B ∈ [0, 255]`:

```
Y_8bit  = 16  + ( 65.481·R + 128.553·G +  24.966·B ) / 255
Cb_8bit = 128 + ( -37.797·R -  74.203·G + 112.000·B ) / 255
Cr_8bit = 128 + ( 112.000·R -  93.786·G -  18.214·B ) / 255
```

Зворотні формули для відновлення `R, G, B ∈ [0, 255]` із 8-бітного `YCbCr`:

```
Y' = Y_8bit - 16
u  = Cb_8bit - 128
v  = Cr_8bit - 128

R = saturate_u8( 1.164383·Y' + 1.596027·v )
G = saturate_u8( 1.164383·Y' - 0.391762·u - 0.812968·v )
B = saturate_u8( 1.164383·Y' + 2.017232·u )
```

де `saturate_u8(x) = max(0, min(255, round(x)))` — операція затискання (clamping).

Ці формули утворюють математичний фундамент усіх апаратних блок-схем обробки кольору у GPU, відеокодерах та цифрових дисплеях.
