# ⚙️ Чисельне моделювання вимушених коливань та розрахунок АЧХ на C та C++

У цій вставці описано розробку програмного алгоритму чисельного моделювання вимушених коливань загасного осцилятора під дією зовнішньої періодичної сили. Ми розглянемо теорію симплектичних інтеграторів, реалізуємо метод Верле у швидкостях (*Velocity Verlet*), виконаємо частотне сканування (покрокову зміну частоти збудження ω) та побудуємо амплітудно-частотну характеристику (АЧХ) системи для автоматичного чисельного визначення резонансного піку й добротності Q.

### 1. Теоретичні основи чисельного інтегрування коливальних систем

Диференціальне рівняння вимушених коливань має вигляд:

```
m·ẍ + c·ẋ + k·x = F₀ · cos(ω·t)
```

Для обчислення стану системи на комп'ютері рівняння зводять до системи двох диференціальних рівнянь першого порядку відносно зміщення x(t) та швидкості v(t):

```
dx/dt = v(t)
dv/dt = a(t) = (F₀ · cos(ω·t) − c·v(t) − k·x(t)) / m
```

Перша думка, яка спадає на думку початківцю — застосувати простий явний метод Ейлера:
- `x[n+1] = x[n] + v[n] · dt`
- `v[n+1] = v[n] + a[n] · dt`

Проте для коливальних систем метод Ейлера категорично **непридатний**. Метод Ейлера є несимплектичним інтегратором першого порядку точності O(dt). На кожному кроці він вносить штучну додатну похибку у фазовий об'єм системи, через що виникає числове «саморозкачування» (енергія системи зростає як e^(const · dt · t) навіть при відсутності зовнішньої сили). Для загасного осцилятора це призводить до викривлення резонансного піку, а для ідеального осцилятора — до вибухоподібного зростання амплітуди до нескінченності.

Для чисельного моделювання коливань застосовують класи симплектичних інтеграторів. Найкращим балансом між обчислювальною складністю, швидкістю та точністю є **метод Верле у швидкостях** (*Velocity Verlet*).

#### Вивід схеми Верле у швидкостях

Розкладемо координату x(t + dt) та x(t − dt) у ряд Тейлора поблизу точки t:

```
x(t + dt) = x(t) + v(t)·dt + (1/2)·a(t)·dt² + (1/6)·b(t)·dt³ + O(dt⁴)
x(t − dt) = x(t) − v(t)·dt + (1/2)·a(t)·dt² − (1/6)·b(t)·dt³ + O(dt⁴)
```

Додавши ці два рівняння, дістаємо класичну позиційну схему Верле:

```
x(t + dt) = 2·x(t) − x(t − dt) + a(t)·dt² + O(dt⁴)
```

Зверніть увагу: члена третього порядку (1/6)·b(t)·dt³ повністю взаємно скоротилися! Це забезпечує точність схеми за координатою O(dt²). 

Щоб позбутися потреби зберігати попередню позицію x(t − dt) і мати явний доступ до швидкості v(t) на кожному кроці (що необхідно для обчислення кінетичної енергії та сили в'язкого тертя −c·v), схему переписують у формі **Верле у швидкостях**:

1. Оновлення координати на основі поточної швидкості та прискорення:
   ```
   x(t + dt) = x(t) + v(t)·dt + (1/2)·a(t)·dt²
   ```
2. Обчислення нового прискорення a(t + dt) з використанням нової координати x(t + dt):
   ```
   a(t + dt) = ( F₀·cos(ω·(t + dt)) − c·v(t) − k·x(t + dt) ) / m
   ```
3. Оновлення швидкості на основі напівсуми старого та нового прискорення:
   ```
   v(t + dt) = v(t) + (1/2)·(a(t) + a(t + dt))·dt
   ```

Цей метод точно зберігає фазовий об'єм, не має числового дрейфу енергії при малих dt і забезпечує високу стабільність амплітуди при моделюванні тривалих перехідних процесів.

Метод Верле у швидкостях є неявним щодо швидкості, але для в'язкого тертя −c·v система алгебраїчних рівнянь розв'язується в явному вигляді, що дозволяє виконувати розрахунок одного кроку всього за 4 арифметичні операції.

### 2. Архітектура та алгоритм частотного сканера АЧХ

Для чисельної побудови амплітудно-частотної характеристики (АЧХ) застосовують двостадійну схему моделювання для кожної дискретної частоти збудження:

```
                  ┌─────────────────────────────────────────────────────────┐
                  │                 Початок симуляції                       │
                  └────────────────────────────┬────────────────────────────┘
                                               │
                                               ▼
                  ┌─────────────────────────────────────────────────────────┐
                  │ Phase 1: Перехідний процес (t < t_settle)               │
                  │ Пропускаємо згасання власних коливань e⁻ᵞᵗ             │
                  └────────────────────────────┬────────────────────────────┘
                                               │
                                               ▼
                  ┌─────────────────────────────────────────────────────────┐
                  │ Phase 2: Вимірювання сталого режиму (t_settle..t_end)  │
                  │ Шукаємо max(|x(t)|) протягом кількох повних періодів    │
                  └────────────────────────────┬────────────────────────────┘
                                               │
                                               ▼
                  ┌─────────────────────────────────────────────────────────┐
                  │ Запис точки АЧХ (ω, A(ω)) та перехід до ω + dω         │
                  └────────────────────────────┬────────────────────────────┘
```

#### Розрахунок параметрів часу симуляції

1. **Час встановлення сталого режиму (`t_settle`)**. Перехідний процес визначається темпом загасання γ = c / (2m). Амплітуда власних коливань зменшується за законом e⁻ᵞᵗ. Щоб вільні коливання згасли щонайменше у 400 разів (до рівня менше 0.25% від початкового), час пропускання має становити:
   ```
   t_settle ≥ 6 / γ = (12 · m) / c
   ```
2. **Час вимірювання сталевої амплітуди (`t_measure`)**. Щоб гарантовано захопити пікове значення синусоїди, вимірювання слід проводити протягом щонайменше 10–20 повних періодів коливань T = 2·π / ω₀:
   ```
   t_measure ≥ 20 · (2·π / ω₀)
   ```

Використання адаптивного розрахунку часових інтервалів дозволяє суттєво прискорити обчислення: для низькодобротних систем `t_settle` зменшується автоматично, тоді як для високодобротних систем алгоритм виділяє достатній часовий ресурс для повного згасання перехідних бить.

### 4. Покроковий розбір коду C та C++

Розглянемо ключові відмінності двох архітектурних реалізацій:

1. **Інкапсуляція стану**: У версії C++ фізичні параметри осцилятора та методи обчислення об'єднано у клас `DrivenOscillatorSimulator`. Методи позначено атрибутом `[[nodiscard]]`, що запобігає випадковому ігноруванню поверненого результату обчислень.
2. **Динамічне виділення пам'яті**: Резервування вектора `result.reserve(...)` у C++ запобігає зайвим повторним виділенням пам'яті в купі під час збереження точок АЧХ.
3. **Пошук максимуму АЧХ**: У версії C++ пошук резонансного піку виконується через стандартний алгоритм `std::max_element` із лямбда-компаратором, що виключає написання явних ручних циклів.

### 5. Пастки чисельного моделювання резонансу

Під час розробки симулятора резонансу початківці найчастіше припускаються трьох типових помилок:

1. **Помилка 1: Недостатній час пропускання перехідного процесу (`t_settle`)**. 
   Якщо вимірювати максимум амплітуди одразу з моменту включення сили (t = 0), у системі присутня згасна власна складова на частоті ω_d. Відбувається взаємодія (інтерференція) між власною та збуджувальною частотою, що призводить до [биттів](root:ph-waves/beats). На графіку АЧХ з'являються несправжні паразитні піки, а чисельна амплітуда може виявитися завищеною на 30–50%. Для запобігання цьому `t_settle` має становити не менше (5…6) / γ.

2. **Помилка 2: Занадто великий крок за часом (`dt`)**. 
   Крок чисельного інтегрування dt пов'язаний із частотою системною умовою стійкості Куранта-Фрідріхса-Леві. Для інтегратора Верле крок має задовольняти обмеження:
   ```
   dt ≤ 0.1 / ω_max
   ```
   Якщо вибрати `dt` занадто великим (наприклад, `dt = 0.05` при `ω = 10 рад/с`), на один період коливань припадатиме лише 12 дискретних точок. Чисельна схема згладжуватиме піки синусоїди, і обчислена амплітуда виявиться суттєво заниженою.

3. **Помилка 3: Неадекватна дискретизація частоти (`dw`) для високодобротних систем**. 
   При високій добротності Q = 1000 ширина резонансного піку на рівні половинної потужності становить Δω = ω₀ / Q = 10 / 1000 = 0.01 рад/с. Якщо крок частотного сканування задати рівним `dw = 0.1 рад/с`, сканер просто «проскочить» повз резонансний пік шириною 0.01 рад/с, і зареєстрована амплітуда на АЧХ виявиться в десятки разів меншою за реальну. Для високодобротних осциляторів крок сканування має підбиратися адаптивно за умовою:
   ```
   dw ≤ Δω / 10 = ω₀ / (10 · Q)
   ```
