# 🧮 Математичний вивід вимушених коливань, АЧХ та ФЧХ

У цій математичній вставці наведено строгий алгебраїчний вивід рівняння руху вимушеного осцилятора під дією зовнішньої гармонічної сили, розрахунок амплітудно-частотної (АЧХ) та фазово-частотної (ФЧХ) характеристик за допомогою комплексного методу Ейлера, аналіз енергетичного балансу та кінематичного збудження основи.

### 1. Постановка задачі та канонічне диференціальне рівняння

Розглянемо механічну систему, що складається з точкової маси m, яка рухається уздовж однієї осі x під дією трьох фундаментальних сил. По-перше, це відновлювальна сила пружини, яка підпорядковується закону Гука й пропорційна зміщенню маси з точки рівноваги. По-друге, це сила в'язкого тертя рідкого або газового демпфера, яка спрямована проти руху й пропорційна швидкості. По-третє, це зовнішня періодична збуджувальна сила, яка змінюється за косинусоїдальним законом із постійною амплітудою та частотою.

Згідно з другим законом Ньютона, сума всіх сил, що діють на тіло, дорівнює добутку його маси на прискорення:

```
m·ẍ + c·ẋ + k·x = F₀ · cos(ω·t)
```

Для приведення рівняння до зручного канонічного вигляду поділимо всі його члени на масу m. Це дозволяє виділити характеристики власної частоти та згасання осцилятора:

```
ẍ + 2·γ·ẋ + ω₀²·x = f₀ · cos(ω·t)
```

У цьому канонічному диференціальному рівнянні використовуються такі загальноприйняті фізичні позначення:
- Параметр `ω₀ = √(k / m)` являє собою власну колову частоту коливань осцилятора у відсутності тертя та зовнішніх сил (вимірюється у радіанах за секунду).
- Параметр `γ = c / (2m)` описує коефіцієнт або темп загасання вільних коливань під дією тертя (вимірюється у зворотних секундах 1/с).
- Параметр `f₀ = F₀ / m` являє собою нормовану амплітуду прискорення, що створюється зовнішньою збуджувальною силою (вимірюється у метрах за секунду в квадраті м/с²).

### 2. Метод комплексних амплітуд

Диференціальне рівняння другого порядку з гармонічною правою частиною можна розв'язувати у дійсних функціях, пропонувати тригонометричні підстановки й розгортати косинуси та синуси сум. Проте значно витонченішим, коротшим і простішим є комплексний метод Ейлера.

Замінимо дійсну збуджувальну силу F₀·cos(ω·t) комплексною функцією `f̂(t) = f₀ · e^(i·ω·t)`. Згідно з формулою Ейлера `e^(i·ω·t) = cos(ω·t) + i·sin(ω·t)`, дійсна сила є просто дійсною частиною Re(f̂(t)) цієї комплексної функції. Завдяки лінійності диференціального оператора дійсна координата x(t) шуканого руху буде дорівнювати дійсності частині Re(x̂(t)) комплексної функції x̂(t).

Будемо шукати частинний розв'язок усталеного вимушеного режиму у вигляді комплексної гармонічної хвилі з невідомою комплексною амплітудою X̂:

```
x̂(t) = X̂ · e^(i·ω·t)
```

Обчислимо першу та другу похідні від цієї комплексної функції за часом t, пам'ятаючи, що похідна від експоненти дає множник i·ω:

```
ẋ̂(t) = i·ω · X̂ · e^(i·ω·t)
ẍ̂(t) = (i·ω)² · X̂ · e^(i·ω·t) = −ω² · X̂ · e^(i·ω·t)
```

Підставимо отримані вирази для похідних у нормоване канонічне диференціальне рівняння:

```
−ω² · X̂ · e^(i·ω·t) + 2·γ·i·ω · X̂ · e^(i·ω·t) + ω₀² · X̂ · e^(i·ω·t) = f₀ · e^(i·ω·t)
```

Оскільки часовий множник `e^(i·ω·t)` є строго відмінним від нуля у будь-який момент часу, винесемо його за дужки й скоротимо обидві частини рівняння. В результаті диференціальне рівняння повністю перетворюється на просте алгебраїчне рівняння відносно комплексної амплітуди X̂:

```
X̂ · [ (ω₀² − ω²) + i·2·γ·ω ] = f₀
```

Виразивши звідси комплексне число X̂, дістаємо аналітичну формулу комплексної амплітуди вимушеного осцилятора:

```
X̂ = f₀ / [ (ω₀² − ω²) + i·2·γ·ω ]
```

### 3. Розрахунок АЧХ та ФЧХ

Запишемо комплексне число X̂ у показниковому вигляді через його модуль A(ω) та аргумент −φ(ω): `X̂ = A(ω) · e^(−i·φ(ω))`. Тут A(ω) представляє дійсну фізичну амплітуду коливань маси, а кут φ(ω) описує фазове відставання відгуку осцилятора від збуджувальної сили.

#### 1. Дійсна амплітуда (АЧХ)

Дійсна амплітуда коливань A(ω) визначається модулем комплексної амплітуди X̂. Модуль частки двох комплексних чисел дорівнює частці їхніх модулів:

```
A(ω) = |X̂| = f₀ / | (ω₀² − ω²) + i·2·γ·ω |
```

Модуль комплексного числа вида `z = a + i·b` обчислюється як корінь квадратний із суми квадратів дійсної та уявної частин `|z| = √(a² + b²)`:

```
A(ω) = f₀ / √( (ω₀² − ω²)² + 4·γ²·ω² )
```

Отримана функція A(ω) є підсумковою амплітудно-частотною характеристикою (АЧХ) вимушених коливань. Вона показує, як амплітуда установленого руху залежить від частоти зовнішньої сили.

#### 2. Фазовий зсув (ФЧХ)

Фазовий кут φ(ω) дорівнює аргументу знаменника комплексної амплітуди. Аргумент комплексного числа визначається відношенням уявної частини до дійсної:

```
tg(φ(ω)) = Im(знаменника) / Re(знаменника) = (2·γ·ω) / (ω₀² − ω²)
```

Беручи арктангенс від обидвох частин рівняння, отримуємо фазово-частотну характеристику (ФЧХ):

```
φ(ω) = arctg( (2·γ·ω) / (ω₀² − ω²) )
```

Проаналізуємо фізичні межі для кута фазового зміщення:
- На дуже низьких частотах (ω → 0) знаменник наближається до ω₀², що дає `tg(φ) → 0` і `φ → 0`. Це означає, що маса рухається абсолютно синхронно із силою.
- На точній власній частоті (ω = ω₀) знаменник (ω₀² − ω²) звертається в нуль. Оскільки чисельник 2·γ·ω є додатним, тангенс прямує до нескінченності `tg(φ) → ∞`, що відповідає куту `φ = π/2 (90°)`!
- На дуже високих частотах (ω → ∞) знаменник стає від'ємним і прямує до −∞, що дає `tg(φ) → −0` у другій чверті, тобто `φ → π (180°)`. Координата осцилятора рухається у протифазі до сили.

### 4. Знаходження точної резонансної частоти

Для знаходження резонансної частоти ω_р, на якій амплітуда A(ω) досягає свого абсолютного максимуму, дослідимо функцію A(ω) на екстремум. Оскільки чисельник f₀ є постійною величиною, максимум амплітуди відповідає мінімуму підкореневого виразу у знаменнику:

```
g(ω) = (ω₀² − ω²)² + 4·γ²·ω²
```

Візьмемо першу похідну від функції g(ω) по частоті ω і прирівняємо її до нуля:

```
dg/dω = 2 · (ω₀² − ω²) · (−2·ω) + 8·γ²·ω = 0
```

Винесемо спільний множник `4·ω` за дужки, пам'ятаючи, що для ненульових частот `ω ≠ 0`:

```
4·ω · [ −(ω₀² − ω²) + 2·γ² ] = 0
```

Розкривши дужки всередині виразу, маємо:

```
ω² − ω₀² + 2·γ² = 0
```

```
ω² = ω₀² − 2·γ²
```

Взявши квадратний корінь, дістаємо точну формулу для резонансної частоти амплітуди зміщення:

```
ω_р = √( ω₀² − 2·γ² )
```

Звернувши увагу на цю формулу, можна зробити важливий фізичний висновок: за наявності тертя (γ > 0) резонансна частота завжди лежить трохи нижче за власну частоту вільних коливань ω₀. Якщо демпфування стає занадто великим (`2·γ² ≥ ω₀²`), підкореневий вираз стає від'ємним, резонансний пік зникає взагалі, а крива АЧХ стає монотонно спадною.

#### Максимальне значення резонансної амплітуди

Підставивши вираз для резонансної частоти `ω_р² = ω₀² − 2·γ²` назад у формулу АЧХ, обчислимо пикову амплітуду:

```
g(ω_р) = (2·γ²)² + 4·γ²·(ω₀² − 2·γ²) = 4·γ⁴ + 4·γ²·ω₀² − 8·γ⁴ = 4·γ²·(ω₀² − γ²)
```

Взявши квадратний корінь, дістаємо точний вираз для максимальної амплітуди на резонансі:

```
A_макс = A(ω_р) = f₀ / ( 2·γ · √(ω₀² − γ²) )
```

Для систем із малим загасанням (γ « ω₀) підкореневий корінь `√(ω₀² − γ²) ≈ ω₀`, що дає наближену співвідношення:

```
A_макс ≈ f₀ / (2·γ·ω₀) = (f₀ / ω₀²) · (ω₀ / (2·γ)) = A_стат · Q
```

де `A_стат = f₀ / ω₀² = F₀ / k` являє собою статичне зміщення маси під дією постійної сили F₀, а `Q = ω₀ / (2·γ)` — безрозмірна добротність системи.

### 5. Енергетичний баланс та середня потужність на резонансі

Миттєва потужність P(t), яка передається від зовнішнього джерела у коливальну систему, обчислюється як добуток миттєвої сили F(t) на миттєву швидкість v(t) = ẋ(t):

```
F(t) = F₀ · cos(ω·t)
v(t) = ẋ(t) = −A·ω · sin(ω·t − φ) = A·ω · sin(φ − ω·t)
```

Скориставшись тригонометричною формулою синуса різниці `sin(α − β) = sin(α)·cos(β) − cos(α)·sin(β)`, перепишемо швидкість у вигляді:

```
v(t) = A·ω · [ sin(φ)·cos(ω·t) − cos(φ)·sin(ω·t) ]
```

Помноживши силу F(t) на швидкість v(t), маємо вираз для миттєвої потужності:

```
P(t) = F₀·A·ω · [ sin(φ)·cos²(ω·t) − cos(φ)·sin(ω·t)·cos(ω·t) ]
```

Проінтегруємо цей вираз за один період коливань T = 2·π / ω для знаходження середньої потужності P_сер. Середнє значення `cos²(ω·t)` за період дорівнює `1/2`, а середнє значення добутку `sin(ω·t)·cos(ω·t)` за період дорівнює `0`. В результаті отримуємо:

```
P_сер = (1/2) · F₀ · A · ω · sin(φ)
```

Підставивши вирази для A(ω) та sin(φ) = (2·γ·ω) / √( (ω₀² − ω²)² + 4·γ²·ω² ), маємо формулу середньої поглинаної потужності:

```
P_сер(ω) = ( F₀² · γ · ω² ) / ( m · [ (ω₀² − ω²)² + 4·γ²·ω² ] )
```

Дослідження цієї функції показує, що максимум середньої поглинаної потужності припадає **суворо на власну частоту ω = ω₀**, незалежно від величини загасання! На частоті ω = ω₀ кут фазового зсуву дорівнює `φ = 90°`, тому `sin(φ) = 1`, а середня потужність досягає свого абсолютного максимуму:

```
P_сер_макс = F₀² / (4 · m · γ) = F₀² / (2 · c)
```

Це доводить важливий фізичний факт: саме на точній частоті ω₀ збуджувальна сила діє строго у фазі зі швидкістю руху, передаючи у систему максимально можливий потік енергії для компенсації втрат на тертя.

### 6. Кінематичне збудження основи (Transmissibility)

У багатьох практичних інженерних ситуаціях (наприклад, у підвісці автомобіля при русі по нерівній дорозі або при віброізоляції високоточного обладнання) сила прикладається не безпосередньо до маси, а здійснюється кінематичне хитання основи за законом `y(t) = Y₀ · cos(ω·t)`.

Рівняння руху маси у відносних координатах `x_rel = x − y` має вигляд:

```
m·ẍ_rel + c·ẋ_rel + k·x_rel = m · ω² · Y₀ · cos(ω·t)
```

Коефіцієнт передачі вібрації (Transmissibility, TR) описує відношення амплітуди сили, що передається на підлогу, до амплітуди зовнішньої сили збудження:

```
TR = √( (1 + (2·γ·ω / ω₀²)²) / ( (1 − (ω/ω₀)²)² + (2·γ·ω / ω₀²)² ) )
```

Аналіз цієї характеристики показує дві принципові зони:
1. При низьких частотах (`ω < √2 · ω₀`) коефіцієнт передачі `TR > 1`. Система підсилює вхідну вібрацію, досягаючи максимального розкачування на резонансній частоті.
2. При високих частотах (`ω > √2 · ω₀`) коефіцієнт передачі `TR < 1`. Підвіска починає працювати як ефективний віброізолятор, захищаючи споруду від високочастотних поштовхів.
