# 🧮 Повний векторний розрахунок еванесцентного поля, вектора Пойнтінга та проходження FTIR

Для повного фізико-математичного осмислення еванесцентних полів необхідно здійснити пряме векторне виведення рівнянь поля з фундаментальної системи рівнянь Максвелла, розрахувати просторовий розподіл вектора Умова — Пойнтінга та вивести комплексні фазові співвідношення Френеля. Цей документ надає вичерпний розрахунок комплексного хвильового вектора, векторних компонент електричного й магнітного полів для обох поляризацій, аналітичний доказ відсутності нормального потоку енергії в середньому за часом, розрахунок просторового зсуву Гуса — Хенхен методом стаціонарної фази та виведення коефіцієнта тунелювання у тришаровій системі порушеного повного внутрішнього відбиття (FTIR).

---

### 1. Рівняння Максвелла та виведення хвильового рівняння

У вихідному однорідному, ізотропному, немагнітному діелектричному середовищі без вільних електричних зарядів (`ρ = 0`) та струмів провідності (`j = 0`) система диференціальних рівнянь Максвелла у SI має вигляд:

```
∇ × E = - ∂B / ∂t
∇ × H = ∂D / ∂t
∇ · D = 0
∇ · B = 0
```

Матеріальні співвідношення для лінійного прозорого середовища з відносною діелектричною проникністю `ε` та відносною магнітною проникністю `μ = 1` зв'язують вектори індукції та напруженості:

```
D = ε · ε₀ · E = n² · ε₀ · E
B = μ₀ · H
```

де `n = √ε` — абсолютний показник заломлення середовища, `ε₀` — електрична стала, `μ₀` — магнітна стала.

Застосуємо оператор ротора `∇ ×` до першого рівняння Максвелла:

```
∇ × (∇ × E) = - ∂(∇ × B) / ∂t = - μ₀ · ∂²D / ∂t² = - μ₀ · ε₀ · n² · (∂²E / ∂t²)
```

Використовуючи відому векторну тотожність `∇ × (∇ × E) = ∇(∇ · E) - ∇²E` та враховуючи відсутність об'ємного заряду (`∇ · E = 0`), отримуємо векторне хвильове рівняння:

```
∇²E - (n² / c²) · (∂²E / ∂t²) = 0
```

де `c = 1 / √(ε₀ · μ₀)` — швидкість світла у вакуумі.

Для монохроматичного поля з часовою залежністю `exp(-i · ωt)` часова похідна дає `∂²E / ∂t² = -ω² · E`, що перетворює хвильове рівняння на однорідне векторне рівняння Гельмгольца:

```
∇²E + k² · E = 0
```

де `k = n · k₀ = n · (ω / c) = (2π · n) / λ₀` — модуль хвильового вектора у середовищі, `λ₀` — довжина хвилі у вакуумі.

### 2. Граничні умови та комплексна нормальна компонента

Розглянемо плоску межу розділу двох середовищ `z = 0`. 
- Нижній півпростір `z < 0` зайнято середовищем 1 з показником заломлення `n₁`;
- Верхній півпростір `z > 0` зайнято середовищем 2 з показником заломлення `n₂ < n₁`.

Нехай плоска монохроматична хвиля падає з першого середовища під кутом `θ₁` до нормалі `z`. Площина падіння збігається з площиною `xz`.

Граничні умови Максвелла вимагають строгої неперервності тангенціальних компонент векторів напруженості електричного та магнітного полів у кожній точці межі `z = 0` у будь-який момент часу `t`:

```
E[1x](x, y, 0, t) = E[2x](x, y, 0, t)
E[1y](x, y, 0, t) = E[2y](x, y, 0, t)
H[1x](x, y, 0, t) = H[2x](x, y, 0, t)
H[1y](x, y, 0, t) = H[2y](x, y, 0, t)
```

Це можливе лише у тому випадку, коли фазові множники падаючої, відбитої та заломленої хвиль збігаються уздовж усієї поверхні `z = 0`. Отже, тангенціальна компонента хвильового вектора у другому середовищі `k[2x]` строго дорівнює тангенціальній компоненті у першому середовищі:

```
k[2x] = k[1x] = k₁ · sin θ₁ = k₀ · n₁ · sin θ₁
```

У другому середовищі повне хвильове число дорівнює `k₂ = k₀ · n₂`. Дисперсійне співвідношення для плоскої хвилі зв'язує тангенціальну та нормальну компоненти хвильового вектора у втором середовищі:

```
k[2x]² + k[2z]² = k₂² = (k₀ · n₂)²
```

Виразимо квадрат нормальної компоненти `k[2z]²`:

```
k[2z]² = k₂² - k[2x]² = k₀² · (n₂² - n₁² · sin² θ₁)
```

Розглянемо випадок, коли кут падіння перевищує критичний поріг `θ₁ > θ_c = arcsin(n₂ / n₁)`. Оскільки `sin θ₁ > n₂ / n₁`, вираз у дужках стає від'ємним: `n₂² - n₁² · sin² θ₁ < 0`.

Отже, нормальна компонента хвильового вектора `k[2z]` стає чисто уявною величиною:

```
k[2z] = ± i · κ_z
κ_z = k₀ · √(n₁² · sin² θ₁ - n₂²) = (2π / λ₀) · √(n₁² · sin² θ₁ - n₂²)
```

Підставивши комплексний хвильовий вектор `k₂ = (k₀ · n₁ · sin θ₁, 0, -i · κ_z)` у загальний вираз для комплексної напруженості електричного поля заломленої хвилі `E₂(x, z, t) = E₀₂ · exp(i(k[2x] · x + k[2z] · z - ωt))`, маємо:

```
E₂(x, z, t) = E₀₂ · exp(i(k₀ · n₁ · sin θ₁ · x + (-i · κ_z) · z - ωt))
E₂(x, z, t) = E₀₂ · exp(-κ_z · z) · exp(i(k₀ · n₁ · sin θ₁ · x - ωt))
```

Знак плюс перед `i · κ_z` відкидається з фізичних міркувань, оскільки вираз `exp(+κ_z · z)` означав би необмежене зростання амплітуди поля при віддаленні від межі `z → +∞`, що суперечить закону збереження енергії.

Отриманий розв'язок описує **еванесцентну (згасаючу) хвилю**:
1. Уздовж поверхні розділу (вісь `x`) хвиля поширюється як гармонічна біжуча хвиля з фазовою швидкістю `v[ph] = ω / k[2x] = c / (n₁ · sin θ₁) < c / n₂`.
2. Перпендикулярно до поверхні розділу (вісь `z`) амплітуда поля згасає за експоненційним законом `exp(-κ_z · z)` без фазового зміщення.

### 3. Векторний аналіз поля для s- та p-поляризацій

З рівнянь Максвелла випливає, що вектор магнітного поля зв'язаний з електричним полем співвідношенням:

```
H₂ = (1 / (μ₀ · ω)) · (k₂ × E₂)
```

Розглянемо векторні компоненти для двох базових ортогональних поляризацій.

#### А. Перпендикулярна поляризація (s-поляризація, TE-хвиля)
Вектор напруженості електричного поля має лише `y`-компоненту: `E₂ = (0, E[y2], 0)`.

```
E[y2](x, z, t) = E₀_s · exp(-κ_z · z) · exp(i(k[1x] · x - ωt))
```

Обчислимо векторний добуток `k₂ × E₂`, де `k₂ = (k[1x], 0, -i · κ_z)`:

```
i   j     k
k[1x]  0  -i·κ_z  = (i · κ_z · E[y2],  0,  k[1x] · E[y2])
0   E[y2]   0
```

Звідси компоненти вектора напруженості магнітного поля `H₂`:

```
H[x2](x, z, t) = (i · κ_z / (μ₀ · ω)) · E₀_s · exp(-κ_z · z) · exp(i(k[1x] · x - ωt))
H[y2](x, z, t) = 0
H[z2](x, z, t) = (k[1x] / (μ₀ · ω)) · E₀_s · exp(-κ_z · z) · exp(i(k[1x] · x - ωt))
```

#### Б. Паралельна поляризація (p-поляризація, TM-хвиля)
У випадку TM-поляризації вектор напруженості магнітного поля має лише `y`-компоненту: `H₂ = (0, H[y2], 0)`.

```
H[y2](x, z, t) = H₀_p · exp(-κ_z · z) · exp(i(k[1x] · x - ωt))
```

Застосовуючи рівняння `∇ × H = ∂D / ∂t = -i · ω · ε₂ · ε₀ · E₂`, отримуємо компоненти електричного поля:

```
E[x2](x, z, t) = (i · κ_z / (ω · ε₂ · ε₀)) · H₀_p · exp(-κ_z · z) · exp(i(k[1x] · x - ωt))
E[y2](x, z, t) = 0
E[z2](x, z, t) = (k[1x] / (ω · ε₂ · ε₀)) · H₀_p · exp(-κ_z · z) · exp(i(k[1x] · x - ωt))
```

У випадку TM-поляризації вектор електричного поля має дві складові `E[x2]` та `E[z2]`, зсунуті по фазі на `90°` (через уявну одиницю `i`), що означає еліптичну поляризацію поля у площині падіння.

#### В. Комплексні коефіцієнти проходження Френеля $t_s$ та $t_p$
Амплітуди полів на самій межі `z = +0` виражаються через комплексні коефіцієнти проходження Френеля:

```
t_s = (2 · n₁ · cos θ₁) / (n₁ · cos θ₁ + i · √(n₁² · sin² θ₁ - n₂²))
t_p = (2 · n₁ · cos θ₁) / (n₂ · cos θ₁ + i · (n₁ / n₂) · √(n₁² · sin² θ₁ - n₂²))
```

Модуль коефіцієнта `|t_s|` монотонно зменшується зі зростанням кута падіння, тоді як модуль `|t_p|` при кутах, близьких до критичного `θ₁ ≈ θ_c`, може досягати значень `|t_p| > 1`. Це викликає підсилення нормальної компоненти електричного поля `E_z` безпосередньо у найближчому приповерхневому шарі.

### 4. Вектор Пойнтінга та відсутність нормального випромінювання

Усереднений за часом вектор густини потоку енергії Пойнтінга `⟨S⟩` для гармонічних електромагнітних полів обчислюється як:

```
⟨S⟩ = (1 / 2) · Re(E₂ × H₂*)
```

де `H₂*` — комплексно-сопряжений вектор магнітного поля.

#### А. Нормальна компонента `⟨S_z⟩`
Розглянемо нормальну компоненту вектора Пойнтінга для s-поляризації:

```
⟨S_z⟩ = (1 / 2) · Re(E[x2] · H[y2]* - E[y2] · H[x2]*)
```

Оскільки `E[x2] = 0`, маємо:

```
⟨S_z⟩ = - (1 / 2) · Re(E[y2] · H[x2]*)
```

Підставимо вирази для `E[y2]` та `H[x2]*`:

```
E[y2] = E₀_s · exp(-κ_z · z) · exp(i(k[1x] · x - ωt))
H[x2]* = (- i · κ_z / (μ₀ · ω)) · E₀_s* · exp(-κ_z · z) · exp(-i(k[1x] · x - ωt))

E[y2] · H[x2]* = - i · (κ_z / (μ₀ · ω)) · |E₀_s|² · exp(-2 · κ_z · z)
```

Враховуючи, що уявне число `i` під знаком дійсної частини `Re()` дає нуль:

```
⟨S_z⟩ = (1 / 2) · Re(i · (κ_z / (μ₀ · ω)) · |E₀_s|² · exp(-2 · κ_z · z)) = 0
```

**Строгий фізичний висновок:** нормальний потік енергії в середньому за часом дорівнює **точно нулю** (`⟨S_z⟩ = 0`). Енергія не витікає у друге середовище безповоротно, а лише здійснює реактивні зворотно-поступальні коливання крізь межу `z = 0` з частотою `2ω`.

#### Б. Тангенціальна компонента `⟨S_x⟩`
Обчислимо поздовжній потік енергії вздовж межі розділу:

```
⟨S_x⟩ = (1 / 2) · Re(E[y2] · H[z2]*)
```

Підставивши сопряжену компоненту `H[z2]* = (k[1x] / (μ₀ · ω)) · E₀_s* · exp(-κ_z · z) · exp(-i(k[1x] · x - ωt))`:

```
⟨S_x⟩ = (1 / 2) · (k[1x] / (μ₀ · ω)) · |E₀_s|² · exp(-2 · κ_z · z)
⟨S_x⟩ = (n₁ · sin θ₁ / (2 · μ₀ · c)) · |E₀_s|² · exp(-2 · κ_z · z) > 0
```

Тангенціальний потік енергії є строго додатним (`⟨S_x⟩ > 0`). Еванесцентне поле переносить електромагнітну енергію вздовж поверхні розділу, спадаючи за інтенсивністю з глибиною як `exp(-2 · κ_z · z)`.

### 5. Густина електромагнітної енергії та групова швидкість

Обчислимо об'ємну густину електромагнітної енергії `w(z)`, накопичену в еванесцентній зоні:

```
w(z) = (1 / 4) · (ε₂ · ε₀ · |E₂|² + μ₀ · |H₂|²)
```

Підставляючи компоненти поля для s-поляризації:

```
|E₂|² = |E₀_s|² · exp(-2 · κ_z · z)
|H₂|² = (|H_x|² + |H_z|²) = (|E₀_s|² / (μ₀² · ω²)) · (κ_z² + k[1x]²) · exp(-2 · κ_z · z)
```

Враховуючи, що `κ_z² + k[1x]² = (k₀ · n₁ · sin θ₁)² - (k₀ · n₁ · sin θ₁)² + (k₀ · n₁ · sin θ₁)² + κ_z²`, середня густина енергії дорівнює:

```
w(z) = (1 / 2) · ε₀ · n₁² · sin² θ₁ · |E₀_s|² · exp(-2 · κ_z · z)
```

Повний інтеграл густини енергії по усьому півпростору `z > 0` дає накопичену поверхневу енергію:

```
W_total = ∫[0 to ∞] w(z) dz = (w(0) / (2 · κ_z)) = (d_p / 2) · w(0)
```

Групова швидкість переносу енергії `v_g` уздовж межі виражається як відношення інтегрального потоку Пойнтінга до інтегральної енергії:

```
v[g,x] = (∫[0 to ∞] ⟨S_x⟩ dz) / (∫[0 to ∞] w(z) dz) = c / (n₁ · sin θ₁)
```

Це доводить, що групова швидкість переносу енергії еванесцентної хвилі уздовж межі точно дорівнює її фазовій швидкості `v[ph,x]`.

### 6. Тензор напружень Максвелла та поверхневий тиск

Для розрахунку оптичних сил, які діють на діелектричні наночастинки в еванесцентному полі, застосовується усереднений за часом тензор напружень Максвелла `T[ij]`:

```
T[ij] = (1 / 2) · Re(ε₂ · ε₀ · E_i · E_j* + μ₀ · H_i · H_j* - (1 / 2) · δ[ij] · (ε₂ · ε₀ · |E|² + μ₀ · |H|²))
```

Нормальна компонента тензора напружень `T[zz]` на межі `z = +0` визначає поверхневий тиск світла:

```
T[zz] = (1 / 4) · ε₀ · |E₀|² · (n₂² - n₁² · sin² θ₁) < 0
```

Оскільки `T[zz] < 0`, оптичний тиск еванесцентної хвилі орієнтований від другого середовища до межі — світлове поле створює притягальну нормальну силу (*attraction gradient force*), яка притискає діелектричні наночастинки до поверхні.

### 7. Обчислити просторовий зсув Гуса — Хенхен методом стаціонарної фази

Згідно з виведенням Курта Артмана (*Kurt Artmann*, 1948), поздовжнє просторове зміщення `D_GH` відбитого світлового пучка скінченної ширини обчислюється як похідна від фазового зсуву Френеля `φ` за тангенціальним хвильовим числом `k_x`:

```
D_GH = - dφ / dk_x = - (1 / (k₁ · cos θ₁)) · (dφ / dθ₁)
```

Використовуючи вираз для фази відбиття Френеля при s-поляризації `tan(φ_s / 2) = - κ_z / (k₁ · cos θ₁)`, обчислимо похідну `dφ_s / dθ₁`:

```
dφ_s / dθ₁ = (2 · n₁ · sin θ₁) / √(n₁² · sin² θ₁ - n₂²)
```

Підставляючи похідну у формулу Артмана, отримуємо вираз для просторового зсуву Гуса — Хенхен для s-поляризації:

```
D[GH,s] = (λ₀ / π) · (tan θ₁ / √(n₁² · sin² θ₁ - n₂²)) = 2 · d_p · tan θ₁
```

Для p-поляризації аналогічний розрахунок дає додатковий коефіцієнт підсилення, залежний від відношення показників заломлення:

```
D[GH,p] = D[GH,s] / (sin² θ₁ - (n₂ / n₁)² · cos² θ₁)
```

Цей розрахунок підтверджує, що фізичне зміщення відбитого пучка `D_GH` на межі двох середовищ прямо пропорційне глибині проникнення еванесцентного поля `d_p`.

### 8. Поперечний зсув Імбера — Федорова для еліптичної поляризації

При відбитті кругово або еліптично поляризованого світла виникає додатковий зсув відбитого пучка у напрямку, перпендикулярному до площини падіння `xz` — уздовж осі `y`.

Вперше передбачений Федором Федоровим (1955) та виміряний Крістіаном Імбером (1972), поперечний зсув `D_IF` обчислюється через спіновий кутовий момент фотонів `σ = ±1`:

```
D_IF = ∓ (λ₀ / π) · (cos θ₁ · cot θ₁) / √(n₁² · sin² θ₁ - n₂²)
```

Зсув Імбера — Федорова розкриває ефект Холла для фотонів: геометричний зсув траєкторії виникає через збереження повного кутового моменту поля при його взаємодії з приповерхневим еванесцентним полем.

### 9. Фазові зсуви Френеля та ромб Френеля

При повному внутрішньому відбитті амплітуди відбитого електричного поля за модулем точно дорівнюють амплітудам падаючого поля (`|r_s| = 1`, `|r_p| = 1`). Проте комплексні коефіцієнти відбиття Френеля набувають фазових зсувів `δ_s` та `δ_p`.

Комплексні коефіцієнти відбиття Френеля при `θ₁ > θ_c` можна подати у формі:

```
r_s = exp(i · δ_s)
r_p = exp(i · δ_p)
```

Аналітичний розрахунок фазових зсувів для обох поляризацій дає:

```
tan(δ_s / 2) = - √(n₁² · sin² θ₁ - n₂²) / (n₁ · cos θ₁)
tan(δ_p / 2) = - n₁ · √(n₁² · sin² θ₁ - n₂²) / (n₂² · cos θ₁)
```

Різниця фазових зсувів між паралельною та перпендикулярною поляризаціями `Δδ = δ_p - δ_s` виражається формулою:

```
tan(Δδ / 2) = (cos θ₁ · √(n₁² · sin² θ₁ - n₂²)) / (n₁ · sin² θ₁)
```

У ромбі Френеля світло падає під таким кутом `θ₁`, щоб при кожному з двох послідовних повних внутрішніх відбиттів різниця фаз становила точно `Δδ = 45°` (`π / 4`). У результаті двох відбиттів сумарна різниця фаз досягає `90°` (`π / 2`), що перетворює лінійно поляризоване світло на кругово поляризоване.

### 10. Розрахунок тунелювання світла у тришаровій системі (FTIR)

Розглянемо тришарову систему з двома паралельними межами розділу `z = 0` та `z = d`:
- Середовище 1 (`z < 0`): скло `n₁`;
- Середовище 2 (`0 ≤ z ≤ d`): повітряний зазор `n₂ < n₁`;
- Середовище 3 (`z > d`): скло `n₃ = n₁`.

Застосуємо граничні умови неперервності компонент полів на двох межах. Коефіцієнт проходження за інтенсивністю `T(d) = |t|²` виражається через амплітудну матрицю переносу:

```
T(d) = 1 / (1 + A · sinh²(κ_z · d))
```

де `sinh(x) = (exp(x) - exp(-x)) / 2` — гіперболічний синус, а амплітудний чинник `A` для s-поляризації дорівнює:

```
A_s = (n₁² · cos² θ₁ + κ_z² / k₀²)² / (4 · n₁² · cos² θ₁ · (κ_z² / k₀²))
```

Для p-поляризації амплітудний чинник `A_p` має вигляд:

```
A_p = (n₁² · cos² θ₁ / n₂⁴ + κ_z² / (k₀² · n₁²))² / (4 · (n₁² · cos² θ₁ / n₂⁴) · (κ_z² / (k₀² · n₁²)))
```

При товстому зазорі `d >> d_p` (коли `κ_z · d >> 1`), маємо `sinh(κ_z · d) ≈ (1 / 2) · exp(κ_z · d)`, що дає асимптотичне спрощення:

```
T(d) ≈ (4 / A) · exp(-2 · κ_z · d)
```

Це доводить, що коефіцієнт оптичного тунелювання експоненційно спадає зі зростанням товщини зазору `d` з тією самою просторовою константою `2 · κ_z`, що й інтенсивність вільної еванесцентної хвилі.
