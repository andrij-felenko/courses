# ⚙️ Чисельне моделювання еванесцентного поля та оптичного тунелювання

Чисельне моделювання електромагнітних полів на межі оптичних середовищ є базовим інструментом сучасної нанофотоніки, інтегральної оптики та біосенсорики. На відміну від звичайних плоскопаралельних світлових хвиль у вільному просторі, еванесцентна хвиля має двовимірну просторову структуру: вона біжить вздовж межі розділу й одночасно експоненційно згасає вглиб оптично менш щільного середовища. 

У цьому матеріалі розглянуто суворий математичний алгоритм чисельного розрахунку просторового розподілу напруженості електричного поля, метод матриць переносу для обчислення тунельного коефіцієнта проходження у тришаровій оптичній системі (FTIR), аналіз чисельної стабільності та порівняння ефективності програмних реалізацій мовами C++ та Python.

---

### 1. Математичне формулювання симуляційної моделі

Для побудови чисельної моделі розглянемо тришарову оптичну систему:
- **Середовище 1 (`z < 0`):** вхідна скляна призма з показником заломлення `n₁`;
- **Середовище 2 (`0 ≤ z ≤ d`):** проміжний зазор (повітря або флюїд) товщиною `d` з показником заломлення `n₂ < n₁`;
- **Середовище 3 (`z > d`):** вихідна скляна призма з показником заломлення `n₃ = n₁`.

Коли кут падіння `θ₁` у першому середовищі перевищує критичний кут `θ_c = arcsin(n₂ / n₁)`, нормальна компонента хвильового вектора у другому середовищі стає чисто уявною:

```
κ_z = k₀ · √(n₁² · sin² θ₁ - n₂²) = (2π / λ₀) · √(n₁² · sin² θ₁ - n₂²)
```

де `k₀ = 2π / λ₀` — хвильове число у вакуумі.

#### Дискретизація просторової сітки
Для візуалізації двовимірного розподілу інтенсивності поля у площині падіння `xz` задається прямокутна сітка координат з розмірами `N_x × N_z`. Поперечна координата `x` змінюється у межах від `0` до `L_x` (де `L_x` вимірюється у довжинах хвиль `λ₀`), а нормальна координата `z` відповідає глибині проникнення у друге середовище від `0` до `z_{max} = 3 · d_p`.

Комплексна напруженість електричного поля `E(x, z)` у вузлах сітки для перпендикулярної поляризації (s-поляризація) обчислюється як:

```
E_y(x, z) = E₀ · exp(-κ_z · z) · exp(i · k[1x] · x)
```

де `k[1x] = k₀ · n₁ · sin θ₁` — тангенціальне хвильове число, однакове для всіх трьох середовищ.

Локальна інтенсивність поля `I(x, z)`, яка реєструється оптичними детекторами або камерами мікроскопа, обчислюється як квадрат модуля комплексної амплітуди:

```
I(x, z) = |E_y(x, z)|² = E₀² · exp(-2 · κ_z · z)
```

#### Метод матриць переносу для FTIR
Для обчислення коефіцієнта проходження `T(d)` крізь зазор товщиною `d` застосовується метод характеристичних матриць (Transfer Matrix Method, TMM). Для кожного середовища `m` визначається нормальна компонента хвильового вектора `k[mz]` та оптична адмітанс-матриця `p_m`:

```
p_m = n_m · cos θ_m  (для s-поляризації)
p_m = cos θ_m / n_m  (для p-поляризації)
```

Матриця переносу зазору `M` товщиною `d` зв'язує тангенціальні компоненти полів на вхідній (`z = 0`) та вихідній (`z = d`) межах:

```
M = [ cos(k[2z] · d)          (-i / p₂) · sin(k[2z] · d) ]
    [ -i · p₂ · sin(k[2z] · d)   cos(k[2z] · d)          ]
```

Оскільки у випадку ПВВ `k[2z] = -i · κ_z`, тригонометричні функції перетворюються на гіперболічні:

```
cos(-i · κ_z · d) = cosh(κ_z · d)
sin(-i · κ_z · d) = -i · sinh(κ_z · d)
```

Підставляючи гіперболічні функції у матрицю переносу та обчислюючи коефіцієнт проходження `T = |t|²`, отримуємо аналітичну формулу проходження:

```
T(d) = 1 / (1 + A · sinh²(κ_z · d))
A = (p₁² - p₂²)² / (4 · p₁² · p₂²)
```

### 2. Чисельна стабільність та крайові випадки

Під час реалізації алгоритму на ЕОМ необхідно враховувати кілька важливих чисельних та фізичних крайових випадків:

1. **Граничний випадок `θ₁ → θ_c + 0` (наближення до критичного кута):**
   При наближенні кута падіння до критичного значення підкореневий вираз `(n₁² · sin² θ₁ - n₂²)` прямує до нуля. Це призводить до того, що `κ_z → 0`, а глибина проникнення прямує до нескінченності `d_p → ∞`. На практиці чисельна сітка повинна динамічно адаптувати свій розмір `z_{max}`, оскільки нерухома сітка з фіксованим `z_{max}` не зможе вмістити шар згасання.
2. **Випадок широкого зазору `d >> d_p` (обчислювальний оверфлоу):**
   При `d > 10 · d_p` значення гіперболічного синуса `sinh(κ_z · d)` досягає величин порядка `e¹⁰ ≈ 22000`, а його квадрат `sinh²` сягає `10⁸`. При подальшому збільшенні `d` прямолінійне обчислення `sinh` у 32-бітній арифметиці з плаваючою комою може викликати переповнення регістрів (overflow). Для забезпечення чисельної стабільності при великих `d` виконується асимптотичний перехід до логарифмічної форми:
   ```
   ln T(d) ≈ ln(4 / A) - 2 · κ_z · d
   ```
3. **Випадок нульового зазору `d → 0`:**
   При `d = 0` дві скляні призми зливаються в один суцільний медиум без меж розділу. Гіперболічний синус перетворюється на нуль `sinh(0) = 0`, і коефіцієнт проходження стає строго рівним `T(0) = 1.0` (100%), що відповідає повній відсутності відбиття.

### 3. Детальний аналіз алгоритму та структура обчислень

Для точного чисельного моделювання утиліта реалізує обчислювальний конвеєр із чотирьох етапів:

- **Етап А: Валідація фізичних параметрів.** Програма приймає показники заломлення середовищ `n₁`, `n₂`, `n₃`, довжину хвилі лазера `λ₀` у нанометрах та кут падіння `θ₁` у градусах. Виконується перевірка базової вимоги `n₁ > n₂`. Якщо умову порушено, обчислення перериваються з видачею помилки. Далі розраховується критичний кут `θ_c` та перевіряється умова `θ₁ > θ_c`.
- **Етап Б: Обчислення комплексного хвильового вектора.** Програма виражає хвильове число у вакуумі `k₀ = 2π / λ₀`, тангенціальне хвильове число `k_x = k₀ · n₁ · sin θ₁` та коефіцієнт згасання `κ_z = k₀ · √(n₁² · sin² θ₁ - n₂²)`. На основі `κ_z` визначається глибина проникнення `d_p = 1 / κ_z` та глибина згасання інтенсивності `d_I = d_p / 2`.
- **Етап В: Табулювання просторового профілю поля.** Виконується розрахунок відносної амплітуди `E(z) / E₀ = exp(-z / d_p)` та відносної інтенсивності `I(z) / I₀ = exp(-2z / d_p)` для дискретного набору точок `z` від `0` до `3 · d_p` з кроком `0.5 · d_p`.
- **Етап Г: Обчислення тунелювання FTIR та згасання у децибелах.** Програма розраховує коефіцієнти проходження `T_s(d)` та `T_p(d)` для серії зазорів `d` від `0` до `1000 нм` для обох поляризацій світла, а також виражає оптичні втрати атенюатора у децибелах: `Att(d) = -10 · log₁₀(T(d))`.

### 4. Інженерний допуск та аналіз технологічних похибок

При проектуванні реальних фотонних інтегральних схем та оптичних атенюаторів важливе значення має аналіз чутливості проходження `T(d)` до випадкових технологічних відхилень ширини зазору `δd` (технологічний допуск при виготовленні літографічних зазорів):

```
|dT / dd| = 2 · κ_z · A · sinh(κ_z · d) · cosh(κ_z · d) / (1 + A · sinh²(κ_z · d))²
```

Максимальна абсолютна чутливість `|dT / dd|_{max}` спостерігається при ширинах зазору `d ≈ d_p / 2`. Для робочої довжини хвилі `λ₀ = 632.8 нм` та зазору `d = 150 нм` технологічна варіація ширини зазору всього у `5 нм` призводить до зміни проходження на `~12%`. Це вимагає застосування високоточних п'єзоактюаторів у лабораторних установках.

### 6. Оцінка інженерної практичності реалізацій

Порівняння C++ та Python реалізацій демонструє їхні специфічні сфери застосування в інженерній оптиці:

- **C++20 (Апаратно-оптимізоване чисельне ядро):** 
  Реалізація на C++20 є ідеальною для включення до складу управляючого програмного забезпечення оптичних вимірювальних приладів, спектрометрів та мікроскопів у реальному часі. Використання статичної типографіки, відсутність динамічного виділення пам'яті у циклі та низькорівнева оптимізація обчислення трансендентних функцій (`std::exp`, `std::sinh`) дозволяють виконувати мільйони обчислень точок сітки за секунду. Це дозволяє здійснювати автоматичне підлаштування кута падіння лазерного пучка у TIRF-мікроскопах під час зйомки зі швидкістю понад 100 кадрів на секунду.

- **Python 3 / NumPy (Лабораторне швидке прототипування):**
  Реалізація на Python із використанням векторизованих масивів NumPy є стандартом для швидкого наукового аналізу даних та моделювання перед проведенням фізичного експерименту. Одноразовий векторизований розрахунок усього масиву зазорів `gaps_nm` виконується на C-рівні у бібліотеці NumPy без використання повільних інтерпретованих циклів Python. Вона легко інтегрується з бібліотеками візуалізації Matplotlib для побудови двовимірних карт полів та графіків згасання.

### Фізичні висновки чисельного моделювання

1. **Асиметрія поляризацій в FTIR:** Чисельний розрахунок показує, що коефіцієнт проходження для `p`-поляризації (`T_p`) є строго більшим за коефіцієнт проходження для `s`-поляризації (`T_s`) при однакових ширинах зазору. Це пояснюється наявністю нормальної компоненти електричного поля `E_z` у `p`-хвилі, яка підсилює поверхневу поляризацію границь.
2. **Висока селективність куплера:** Зміна ширини зазору від `100 нм` до `400 нм` зменшує тунелювання світла від `65%` до менш ніж `3%` (втрати зростають на `> 13 dB`). Цей стрімкий експоненційний спад лежить в основі роботи високоточних п'єзоелектричних наноактюаторів та оптичних атенюаторів волоконних ліній зв'язку.
