### 1. Довідкова таблиця акустичних властивостей матеріалів

Акустичні властивості речовин залежать від їхнього мікроскопічного агрегатного стану, фазового складу, температури та тиску. Наведена нижче таблиця містить довідкові значення акустичних констант матеріалів за стандартних умов (температура `t = 20°C`, атмосферний тиск `p = 101.325 кПа`), якщо для конкретного рядка не вказано інше значення.

Для газів і рідин наведено єдину поздовжню швидкість акустичних хвиль стиску `c`. Для тривимірних суцільних твердих тіл наведено три характеристики:
1. **Поздовжня швидкість `c_L`** — швидкість хвилі стиску в суцільному безмежному масиві матеріалу.
2. **Поперечна швидкість `c_S`** — швидкість зсувної хвилі, частинки якої коливаються перпендикулярно до напрямку поширення.
3. **Стрижнева швидкість `c_rod`** — швидкість поздовжньої хвилі в тонкому стрижні, діаметр якого набагато менший за довжину акустичної хвилі.

#### Аналіз фізичних класів матеріалів у таблиці

Акустичні властивості речовин визначаються балансом між інертністю (густиною `ρ`) та пружною жорсткістю міжмолекулярних зв'язків. Розглянемо фізичні особливості кожного класу:

1. **Газові середовища:** Характеризуються низькою густиною (`0.08–6.0 кг/м³`) та малим питомим імпедансом (`0.0001–0.0009 МРайл`). Надегкі гази, такі як водень та гелій, мають високу швидкість звуку (понад `900–1200 м/с`) через малу молярну масу `M`. Важкі багатоатомні гази, такі як гексафторид сірки `SF₆`, демонструють уповільнене поширення хвилі (`152 м/с`) через високу густину та малий показник адіабати `γ = 1.09`.
2. **Рідини:** У рідинах швидкість звуку лежить у межах `1100–1900 м/с`, а імпеданс досягає `0.9–2.4 МРайл`. Винятком є рідка ртуть, висока густина якої (`13546 кг/м³`) забезпечує екстремальний для рідин імпеданс `19.64 МРайл`. У дистильованій воді при підвищенні температури від `0°C` до `100°C` спостерігається нелінійний максимум швидкості звуку при `74°C`, що пояснюється термодинамічною перебудовою тетраедричної сітки водневих зв'язків.
3. **Біологічні тканини:** Більшість м'яких тканин людини (м'язи, кров, внутрішні органи) за акустичними властивостями дуже близькі до води (`c ≈ 1540–1580 м/с`, `z₀ ≈ 1.6 МРайл`). Це дозволяє ультразвуковим хвилям легко проходити крізь межі м'яких тканин без сильного відбиття. Натомість кісткова тканина володіє значно вищою поздовжньою швидкістю (`3500–4000 м/с`) та імпедансом (`6.3–8.0 МРайл`), що створює сильну акустичну тінь при медичному УЗД-обстеженні.
4. **Полімери та деревина:** Полімери мають відносно низькі швидкості зсувних хвиль (`c_S ≈ 500–1300 м/с`) та високий коефіцієнт згасання звуку через в'язкопружні втрати. Деревина демонструє виражену анізотропію: вздовж волокон швидкість звуку в 3–4 рази вища, ніж у поперечному напрямку.
5. **Метали та кристали:** Тверді кристалічні тіла володіють найвищими швидкостями та імпедансами. В монокристалі алмазу завдяки екстремальній жорсткості міжкристалічних зв'язків C-C та малій атомарній масі вуглецю поздовжня швидкість звуку досягає рекордного значення `18 000 м/с`.

#### Анізотропія швидкості звуку у монокристалах та тензор Крістоффеля

У монокристалах швидкість звуку залежить від кристалографічного напрямку поширення хвилі (вектора напрямних косинусів `n⃗ = (n_x, n_y, n_z)`). Поширення акустичних хвиль в анізотропних середовищах описується **тензором Крістоффеля**:

```
Γ_ik = C_ijkl · n_j · n_l
```

де `C_ijkl` — тензор модулів пружності 4-го рангу, який у загальному випадку триклинної симетрії містить 21 незалежну пружну константу, а для кубічної симетрії (кремній, германій, алмаз) скорочується до 3 незалежних констант (`C₁₁`, `C₁₂`, `C₄₄`).

Швидкості трьох можливих акустичних хвиль (однієї квазіпоздовжньої та двох квазіпоперечних) знаходяться як власні значення матриці Крістоффеля з кубічного рівняння:

```
det( Γ_ik − ρ · c² · δ_ik ) = 0
```

Для монокристала кремнію (`Si`, кубічна ґратка, `ρ = 2330 кг/м³`):
* Вздовж кристалографічної осі `[100]` поздовжня швидкість становить `c_L = √(C₁₁ / ρ) ≈ 8430 м/с`.
* Вздовж кристалографічної осі `[111]` поздовжня швидкість становить `c_L = √((C₁₁ + 2·C₁₂ + 4·C₄₄)/(3·ρ)) ≈ 9370 м/с`.
Ця анізотропія обчислюється у мікроелектромеханічних системах (МЕМС), де акустичні резонатори орієнтують строго за визначеними кристалографічними напрямками пластини.

#### Коефіцієнти відбиття акустичної енергії на межах матеріалів

На межі двох середовищ із питомими імпедансами `z₁` та `z₂` коефіцієнт відбиття акустичного тиску за нормального падіння хвилі задається формулою `R_p = (z₂ − z₁) / (z₂ + z₁)`. Частка відбитої енергії дорівнює `R_E = R_p²`.

Розглянемо три характерні межі розділу:
* **Межа «Повітря (0.000413 МРайл) — Вода (1.479 МРайл)»:** `R_p ≈ (1.479 − 0.000413) / (1.479 + 0.000413) ≈ 0.99944`. Частка відбитої енергії становить `R_E = 0.99944² ≈ 0.9989` (`99.89%`). Водна поверхня поводиться як майже ідеальне акустичне дзеркало для повітряної хвилі.
* **Межа «Сталь (46.63 МРайл) — Вода (1.479 МРайл)»:** `R_p ≈ 0.9385`, `R_E ≈ 88.1%`. Для передачі ультразвукового сигналу зі сталевого перетворювача у воду використовують проміжні узгоджувальні чвертьхвильові шари з імпедансом `z_match = √(z₁ · z₂) ≈ 8.3 МРайл`.
* **Межа «М'язи (1.643 МРайл) — Жирова тканина (1.334 МРайл)»:** `R_p ≈ 0.1039`, `R_E ≈ 1.08%`. Більша частина ультразвукової енергії безперешкодно проходить глибше у тіло пацієнта.

Міжнародний стандарт ISO 2533 задає параметри стандартної атмосфери Землі залежно від геометричної та геопотенціальної висоти `h`. В авіаційній та ракетно-космічній техніці швидкість звуку використовується для обчислення числа Маха `Ma = v / c`.

Зміна швидкості звуку з висотою описується п'ятьма температурними шарами атмосфери:
1. **Тропосфера (0 – 11 км):** температура падає з градієнтом `−6.5°C` на кожний кілометр висоти. Швидкість звуку монотонно зменшується від `340.29 м/с` до мінімуму `295.07 м/с`.
2. **Тропопауза (11 – 20 км):** ізотермічний шар із постійною температурою `−56.5°C`. Швидкість звуку залишається строго постійною: `295.07 м/с`.
3. **Стратосфера (20 – 50 км):** температура зростає до `−2.5°C` завдяки поглинанню сонячного ультрафіолету озоновим шаром. Швидкість звуку збільшується до `329.80 м/с`.
4. **Мезосфера (50 – 80 км):** температура знову падає до `−74.5°C`. Швидкість звуку знижується до `282.54 м/с`.

### 3. Нормативні коефіцієнти стандарту ISO 9613-1 та формули CIPM-81

Для прецизійних розрахунків у сухому й вологому повітрі стандарт ISO 9613-1 задає співвідношення між мольною часткою водяної пари `h_m` (вираженою у відсотках) та швидкістю звуку `c`:

```
c = 331.45 · √( (T / 273.15) · (1 + h_m · (γ_v / γ_a − 1) · (M_a / M_v)) )
```

де значення базових констант визначено з високою точністю:

| Константа / Параметр | Символ | Фізичне значення | Одиниці вимірювання |
| :--- | :---: | :---: | :---: |
| **Універсальна газова стала** | `R` | 8.314462618 | Дж / (моль · К) |
| **Молярна маса сухого повітря** | `M_a` | 28.96546 · 10⁻³ | кг / моль |
| **Молярна маса водяної пари (H₂O)**| `M_v` | 18.01528 · 10⁻³ | кг / моль |
| **Показник адіабати сухого повітря**| `γ_a` | 1.4003 | безрозмірна |
| **Показник адіабати водяної пари**| `γ_v` | 1.3301 | безрозмірна |
| **Стандартний атмосферний тиск** | `p₀` | 101325 | Па |
| **Температура плавлення льоду** | `T₀` | 273.15 | К |

Апроксимаційний поліном 5-го степеня для обчислення мольної частки пари `h_m` через відносну вологість `RH` (%) та термодинамічну температуру `T` (К):

```
p_sat / p₀ = 10^( K_1 + K_2·(1 − T₀/T) + K_3·log10(T/T₀) + K_4·(1 − T/T₀) )
```

Коефіцієнти рівняння насичення вологи Ентоні-Осборна:

```
K_1 = −10.79586
K_2 = +5.02808
K_3 = +1.50474 · 10⁻⁴
K_4 = −0.42873 · 10⁻³
```

Стандарт CIPM-81 (Міжнародного бюро мір і ваг) додає до цього розрахунку компенсацію молярної частки вуглекислого газу `x_CO2` (вираженої у проміле, ppm), оскільки зростання вмісту `CO₂` від базових 400 ppm до 2000 ppm зменшує показник адіабати суміші й змінює швидкість звуку на `0.1 м/с`.

### 4. Специфікація програмного інтерфейсу C/C++ бібліотеки `libacoustics`

Нижче наведено специфікацію контрактів типів даних, функцій та класів C/C++ бібліотеки обчислення акустичних параметрів `libacoustics`. C-інтерфейс розроблено для інтеграції з низькорівневими драйверами вбудованих систем, а C++20 інтерфейс забезпечує узагальнений викликовий шар для високорівневих застосунків.

Обчислювальні функції бібліотеки задовольняють вимогам реентрабельності (`thread-safe`), не використовують глобального стану й не виконують динамічного виділення пам'яті під час виклику.

```cpp
/**
 * @file acoustics_api.hpp
 * @brief Modern C++20 header-only wrapper for acoustic property computations
 */

#pragma once

#include <expected>
#include <string_view>
#include <span>
#include <array>
#include <concepts>

namespace acoustics::api {

enum class Status : int32_t {
    Success = 0,
    NullPointer = -101,
    OutOfRange = -102,
    MathDomain = -103
};

struct MaterialSpec {
    std::string_view name;
    double density_kg_m3;
    double longitudinal_speed_m_s;
    double transverse_speed_m_s;
    
    [[nodiscard]] constexpr double specific_impedance() const noexcept {
        return density_kg_m3 * longitudinal_speed_m_s;
    }
};

class MaterialDatabase {
public:
    [[nodiscard]] static constexpr std::expected<MaterialSpec, Status> 
    find_by_name(std::string_view name) noexcept {
        for (const auto& mat : kStandardMaterials) {
            if (mat.name == name) {
                return mat;
            }
        }
        return std::unexpected(Status::OutOfRange);
    }

    [[nodiscard]] static constexpr std::span<const MaterialSpec> 
    all_materials() noexcept {
        return kStandardMaterials;
    }

private:
    static constexpr std::array<MaterialSpec, 6> kStandardMaterials{{
        {"Air_20C", 1.204, 343.2, 0.0},
        {"Water_20C", 998.2, 1482.3, 0.0},
        {"Seawater_20C", 1025.0, 1522.0, 0.0},
        {"Aluminum_D16", 2700.0, 6320.0, 3130.0},
        {"Steel_Structural", 7850.0, 5940.0, 3220.0},
        {"Diamond_C", 3520.0, 18000.0, 12300.0}
    }};
};

} // namespace acoustics::api
```

#### Опис типів даних та кодів повернення C API

* `acoustics_air_config_t` — вхідна структура параметрів повітряного середовища. Вимагає завдання температури у Кельвінах (`temp_k > 0`), статичного тиску в Паскалях (`pressure_pa > 0`), відносної вологості у відсотках (`humidity_rh` у межах від 0 до 100) та концентрації CO₂ в ppm.
* `acoustics_prop_result_t` — результуюча структура, яка заповнюється функцією розрахунку. Містить три обчислені фізичні величини: швидкість звуку `speed_m_s` (м/с), питомий імпеданс `specific_imp_rayl` (Па·с/м) та розраховану густину вологого повітря `density_kg_m3` (кг/м³).
* `ACOUSTICS_ERR_NULL_POINTER` (-101) — повертається у випадку, коли один із переданих вказівників на структури дорівнює `NULL`.
* `ACOUSTICS_ERR_RANGE` (-102) — повертається, якщо температура або тиск виходять за фізично допустимі межі застосовності поліноміальних моделей стандарту.
* `ACOUSTICS_ERR_MATH_DOMAIN` (-103) — повертається при виникненні числа із плаваючою крапкою поза допустимим математичним доменом (наприклад, спробі обчислити корінь із від'ємного тиску).

#### Покрокове керівництво з інтеграції бібліотеки у програмні проекти

1. **Ініціалізація структур:** Перед викликом обчислювальної функції користувач виділяє екземпляр конфігураційної структури `acoustics_air_config_t` на стеку та заповнює параметри даними з термометра й барометра.
2. **Перевірка поверненого статусу:** Кожен виклик C API повертає `acoustics_status_t`. Програма виклику повинна обов'язково перевіряти статус на рівність `ACOUSTICS_SUCCESS` перед читанням полів результуючої структури.
3. **C++20 інтеграція:** Для C++ проектів використовується заголовочний файл `acoustics_api.hpp`. Завдяки `std::expected` код не генерує винятків і може безпечно компілюватися прапорцями `-fno-exceptions` для мікроконтролерів ARM Cortex-M та RISC-V.
4. **Гарантії потокобезпеки:** Оскільки жодна з обчислювальних функцій `libacoustics` не використовує статичних чи глобальних змінних стану, виклики функцій розрахунку можна виконувати паралельно у багатьох потоках без використання блокувальних примітивів синхронізації (м'ютексів).

### 5. Метрологічне калібрування та стандарти фазового вимірювання

У метрології акустичних вимірювань для калібрування ультразвукових дальномірів та витратомірів використовуються еталонні рідини з прецизійно виміряною швидкістю звуку:

1. **Дистильована дегазована вода:** Своєрідний первинний стандарт. При температурі `20.00°C` (з термостатуванням `±0.01°C`) швидкість звуку становить `1482.34 ± 0.05 м/с`.
2. **Водно-спиртові суміші:** Використовуються для створення градуювальних середовищ із заданим температурним коефіцієнтом швидкості `dc/dt`. При концентрації етанолу `17.4%` за масою швидкість звуку у суміші досягає максимуму і практично не залежить від малих коливань температури коло `25°C`.
3. **Вимірювання методом затримки фази (Phase-delay method):** У прецизійних інтерферометрах імпульс випромінюється на двох близьких частотах `f₁` та `f₂`. Визначення різниці фаз `Δφ` дозволяє усунути неоднозначність підрахунку цілого числа хвиль і вимірювати швидкість звуку з відносною похибкою до `10⁻⁵` (`0.001%`).
