# 🧮 Математичне виведення швидкості звуку з рівнянь гідродинаміки та теорії пружності

Математична природа поширення звукового збурення полягає у виникненні хвильового рівняння з перших принципів збереження маси, імпульсу та стану речовини. Ця вставка містить повне виведення формули швидкості звуку в суцільному рідкому чи газоподібному середовищі з одновимірних рівнянь Ейлера та нерозривності, розбір термодинамічних похідних, виведення потенціалу швидкості, закону збереження акустичної енергії, а також математичне виведення швидкостей поздовжніх і поперечних хвиль у тривимірному ізотропному твердому тілі з рівнянь Нав'є-Коші.

### 1. Ейлерів та Лагранжів підходи до опису акустичного суцільного середовища

У механіці суцільних середовищ існують два математичні підходи до опису руху:
* **Підхід Лагранжа:** стежить за траєкторією кожної окремої матеріальної частинки з початковою координатою `a` як за функцією часу: `x = x(a, t)`.
* **Підхід Ейлера:** фіксує нерухому просторову точку `x` і вивчає поле тиску `p(x, t)`, густини `ρ(x, t)` та швидкості `v(x, t)`, які змінюються у цій точці з часом.

Для малого акустичного коливання зручніше використовувати підхід Ейлера. Розглянемо одновимірний потік стисливого ідеального (безв'язкого) флюїду вздовж осі `x`.

Динаміка такої системи задається двома фундаментальними рівняннями механіки суцільних середовищ:

1. **Рівняння нерозривності (закон збереження маси):**

```
∂ρ / ∂t + ∂(ρ · v) / ∂x = 0
```

Це рівняння стверджує, що зміна маси всередині малого фіксованого об'єму викликана виключно вхідним і вихідним потоком речовини через його межі.

2. **Рівняння Ейлера (другий закон Ньютона для елементарного об'єму рідини або газу):**

```
ρ · (∂v / ∂t + v · ∂v / ∂x) = −∂p / ∂x
```

Ліва частина задає масу одиниці об'єму, помножену на її повне (субстанційне) прискорення `Dv/Dt = ∂v/∂t + v·∂v/∂x`, а права частина відповідає результуючій силі тиску, що діє на протилежні грані елементарного об'єму.

#### Крок 1: Метод малих збурень та лінеаризація

Нехай у незбуреному стані середовище перебуває у спокої із однорідною густиною `ρ₀`, постійним тиском `p₀` та відсутністю макроскопічного потоку (`v₀ = 0`). При проходженні слабкої звукової хвилі поля набувають малих відхилень:

```
ρ(x, t) = ρ₀ + ρ'(x, t),    де |ρ'| ≪ ρ₀
p(x, t) = p₀ + p'(x, t),    де |p'| ≪ p₀
v(x, t) = v'(x, t),         де |v'| ≪ c
```

Підставимо ці вирази у рівняння нерозривності:

```
∂(ρ₀ + ρ') / ∂t + ∂((ρ₀ + ρ') · v') / ∂x = 0
```

Оскільки `ρ₀ = const`, її похідна за часом дорівнює нулю. Розкриваючи просторову похідну добутку, маємо `ρ₀ · (∂v' / ∂x) + ∂(ρ' · v') / ∂x`. Величина `ρ' · v'` є добутком двох малих відхилень (другий порядок малості), тому в лінійній акустиці нею можна знехтувати:

```
∂ρ' / ∂t + ρ₀ · (∂v' / ∂x) = 0                       [1: лінеаризоване рівняння нерозривності]
```

Тепер підставимо розклад збурень у рівняння руху Ейлера:

```
(ρ₀ + ρ') · (∂v' / ∂t + v' · ∂v' / ∂x) = −∂(p₀ + p') / ∂x
```

У лівій частині доданок `v' · (∂v' / ∂x)` має другий порядок малості по відношенню до `∂v' / ∂t`, а доданок `ρ' · (∂v' / ∂x)` також є квадратично малим. У правій частині похідна постійного фонового тиску `∂p₀ / ∂x = 0`. Відкидаючи квадратичні доданки, дістаємо лінеаризоване рівняння Ейлера:

```
ρ₀ · (∂v' / ∂t) = −∂p' / ∂x                          [2: лінеаризоване рівняння Ейлера]
```

#### Крок 2: Рівняння стану середовища та зв'язок тиску з густиною

Тиск у флюїді зв'язаний із густиною через термодинамічне рівняння стану `p = p(ρ)`. Для малих акустичних відхилень розкладемо функцію `p(ρ)` у ряд Тейлора коло рівноважної густини `ρ₀`:

```
p(ρ) = p(ρ₀) + (dp / dρ)₀ · (ρ − ρ₀) + (1/2) · (d²p / dρ²)₀ · (ρ − ρ₀)² + ...
```

Враховуючи лише лінійний доданок і помічаючи, що `p − p₀ = p'`, а `ρ − ρ₀ = ρ'`, отримуємо:

```
p' = (dp / dρ)₀ · ρ'
```

Позначимо квадрат коефіцієнта пропорційності через `c²`:

```
c² = (dp / dρ)₀
```

Звідси отримуємо прямий зв'язок між надлишковим акустичним тиском `p'` та акустичним збуренням густини `ρ'`:

```
p' = c² · ρ'   ⇒   ρ' = p' / c²                      [3: термодинамічний зв'язок]
```

#### Крок 3: Отримання одновимірного хвильового рівняння

Підставимо зв'язок `ρ' = p' / c²` у лінеаризоване рівняння нерозривності [1]:

```
(1 / c²) · (∂p' / ∂t) + ρ₀ · (∂v' / ∂x) = 0
```

Продиференціюємо це рівняння за часом `t`:

```
(1 / c²) · (∂²p' / ∂t²) + ρ₀ · (∂²v' / (∂t ∂x)) = 0    [4]
```

Тепер продиференціюємо лінеаризоване рівняння Ейлера [2] за просторовою координатою `x`:

```
ρ₀ · (∂²v' / (∂x ∂t)) = −∂²p' / ∂x²                   [5]
```

За теоремою Шварца про рівність мішаних похідних для неперервних функцій маємо `∂²v' / (∂t ∂x) = ∂²v' / (∂x ∂t)`. Підставляючи вираз [5] у рівняння [4], отримуємо:

```
(1 / c²) · (∂²p' / ∂t²) − ∂²p' / ∂x² = 0
```

Переносячи просторову похідну в праву частину, маємо канонічне **одновимірне акустичне хвильове рівняння**:

```
∂²p' / ∂t² = c² · (∂²p' / ∂x²)
```

Це рівняння описує поширення хвилі тиску в довільному напрямку зі швидкістю `c`:

```
c = √( dp / dρ )
```

### 2. Потенціал швидкості та закон збереження акустичної енергії

Для тривимірного середовища лінеаризоване рівняння Ейлера набуває векторного вигляду:

```
ρ₀ · (∂v⃗' / ∂t) = −∇p'
```

Враховуючи, що ротор градієнта дорівнює нулю (`∇ × (∇p') = 0`), вихровість акустичного поля швидкості за відсутності в'язкості залишається нульовою: `∇ × v⃗' = 0`. Отже, безвихрове поле акустичної швидкості можна виразити через скалярний **потенціал швидкості `Φ(x⃗, t)`**:

```
v⃗' = ∇Φ
```

Підставляючи вираз для `v⃗'` у лінеаризоване рівняння Ейлера, знаходимо зв'язок між акустичним тиском та потенціалом швидкості:

```
p' = −ρ₀ · (∂Φ / ∂t)
```

Підстановка потенціалу швидкості `Φ` у тривимірне рівняння нерозривності дає тривимірне хвильове рівняння для потенціалу:

```
∂²Φ / ∂t² = c² · ∇²Φ,    де ∇² = ∂²/∂x² + ∂²/∂y² + ∂²/∂z²  [Лапласіан]
```

#### Виведення закону збереження акустичної енергії

Помножимо лінеаризоване рівняння Ейлера `ρ₀ · (∂v⃗' / ∂t) = −∇p'` скалярно на `v⃗'`, а лінеаризоване рівняння нерозривності `(1 / (ρ₀·c²)) · (∂p' / ∂t) + ∇ · v⃗' = 0` помножимо на `p'`. Додаючи отримані рівняння, маємо:

```
v⃗' · (ρ₀ · ∂v⃗' / ∂t) + p' · ((1 / (ρ₀·c²)) · ∂p' / ∂t) + v⃗' · ∇p' + p' · (∇ · v⃗') = 0
```

Використовуючи тотожність `∇ · (p' · v⃗') = v⃗' · ∇p' + p' · (∇ · v⃗')` та згортаючи похідні за часом, отримуємо **диференціальну форму закону збереження акустичної енергії**:

```
∂w / ∂t + ∇ · I⃗ = 0
```

де `w` — повна густина акустичної енергії, а `I⃗` — вектор густини потоку акустичної енергії (вектор Умова):

```
w = w_k + w_p = (1/2) · ρ₀ · |v⃗'|² + (1 / (2 · ρ₀ · c²)) · p'²
I⃗ = p' · v⃗'
```

### 3. Обчислення термодинамічних похідних для ізотермічного та адіабатичного процесів

Значення похідної `dp / dρ` залежить від того, який термодинамічний режим реалізується при проходженні хвилі.

#### Ізотермічний режим (Ньютон)

Для ізотермічного процесу температура газу вважається незмінною (`T = const`). Рівняння стану ідеального газу має вигляд:

```
p = (R · T / M) · ρ
```

Обчислимо похідну за густиною при постійній температурі:

```
(dp / dρ)_T = R · T / M = p / ρ
```

Звідси ізотермічна швидкість звуку за Ньютоном:

```
c_iso = √( p / ρ ) = √( R · T / M )
```

#### Адіабатичний режим (Лаплас)

При швидкозмінних акустичних коливаннях теплообмін між сусідніми шарами газу відсутній (`dQ = 0`), тому процес є адіабатичним (ізоентропійним, `S = const`). Рівняння адіабати Пуассона має вигляд:

```
p = C · ρ^γ,    де C = const, γ = Cp / Cv
```

Обчислимо частинну похідну за густиною при постійній ентропії:

```
(dp / dρ)_s = C · γ · ρ^(γ − 1) = γ · (C · ρ^γ) / ρ = γ · (p / ρ)
```

Таким чином, адіабатична швидкість звуку за Лапласом становить:

```
c_adb = √( γ · p / ρ ) = √( γ · R · T / M )
```

Оскільки показник адіабати для будь-яких газів більший за одиницю (`γ > 1`), адіабатична швидкість завжди перевищує ізотермічну: `c_adb = √γ · c_iso`.

### 4. Математичне виведення хвиль у тривимірному ізотропному твердому тілі

У суцільному твердому тілі елементарний об'єм описується вектором зміщення `u⃗(x, y, z, t) = (u_x, u_y, u_z)`. На відміну від газів, у твердому тілі виникають як нормальні, так і дотичні напруження, які описуються симетричним тензором напружень `σ_ij` та тензором малих деформацій `ε_ij = (1/2) · (∂u_i/∂x_j + ∂u_j/∂x_i)`.

Для ізотропного середовища узагальнений закон Гука пов'язує тензор напружень із тензором деформацій через сталі Ляме `λ` та `μ`:

```
σ_ij = λ · (∇ · u⃗) · δ_ij + 2 · μ · ε_ij
```

де `δ_ij` — символ Кронекера, `∇ · u⃗ = div(u⃗) = ε_kk` — об'ємна деформація (дивергенція зміщення), `μ = G` — модуль зсуву.

#### Рівняння руху Нав'є-Коші

Підставляючи закон Гука в другий закон Ньютона для суцільного середовища `ρ · (∂²u_i / ∂t²) = ∂σ_ij / ∂x_j`, отримуємо векторне **рівняння Нав'є-Коші**:

```
ρ · (∂²u⃗ / ∂t²) = (λ + μ) · ∇(∇ · u⃗) + μ · ∇²u⃗
```

де `∇` — оператор градієнта, `∇ · u⃗` — дивергенція, а `∇²` — векторний оператор Лапласа.

#### Розклад Гельмгольца вектора зміщення

За теоремою Гельмгольца, будь-яке гладке векторне поле `u⃗` можна подати у вигляді суми градієнта скалярного потенціалу `φ` та ротора бездивергентного векторного потенціалу `A⃗`:

```
u⃗ = ∇φ + ∇ × A⃗,    де ∇ · A⃗ = 0
```

Підставимо розклад Гельмгольца у векторне рівняння Нав'є-Коші:

```
ρ · (∂²(∇φ + ∇ × A⃗) / ∂t²) = (λ + μ) · ∇(∇²φ) + μ · ∇²(∇φ + ∇ × A⃗)
```

Враховуючи тотожності векторного аналізу `∇(∇²φ) = ∇²(∇φ)` та міняючи порядок диференціювання за часом і простором, згрупуємо доданки під операторами градієнта `∇` та ротора `∇ ×`:

```
∇ [ ρ · (∂²φ / ∂t²) − (λ + 2μ) · ∇²φ ] + ∇ × [ ρ · (∂²A⃗ / ∂t²) − μ · ∇²A⃗ ] = 0
```

Оскільки скалярне й векторне поля є лінійно незалежними, це рівняння виконується тоді й лише тоді, коли кожна дужка дорівнює нулю окремо.

Це дає два незалежних диференціальних хвильових рівняння:

1. **Хвильове рівняння для скалярного потенціалу φ (Поздовжня P-хвиля):**

```
∂²φ / ∂t² = c_L² · ∇²φ,    де c_L = √( (λ + 2μ) / ρ )
```

2. **Хвильове рівняння для векторного потенціалу A⃗ (Поперечна S-хвиля):**

```
∂²A⃗ / ∂t² = c_S² · ∇²A⃗,    де c_S = √( μ / ρ )
```

#### Зв'язок між швидкісними коефіцієнтами та модулем Юнга E

Виразимо сталі Ляме `λ` та `μ` через модуль Юнга `E` (модуль поздовжньої пружності) та коефіцієнт Пуассона `ν` (коефіцієнт поперечного стиску):

```
μ = G = E / (2 · (1 + ν))
λ = (E · ν) / ((1 + ν) · (1 − 2ν))
λ + 2μ = (E · (1 − ν)) / ((1 + ν) · (1 − 2ν))
```

Підставляючи ці співвідношення у вирази для швидкостей, дістаємо підсумкові математичні формули:

* **Поздовжня швидкість у безмежному середовищі (`c_L`):**

```
c_L = √[ (E · (1 − ν)) / (ρ · (1 + ν) · (1 − 2ν)) ]
```

* **Поперечна швидкість зсуву (`c_S`):**

```
c_S = √[ E / (2 · ρ · (1 + ν)) ] = √( G / ρ )
```

* **Поздовжня швидкість у тонкому стрижні (`c_rod`):**
Для тонкого стрижня бічні напруження дорівнюють нулю (`σ_yy = σ_zz = 0`), що спрощує закон Гука до одновимірного виразу `σ_xx = E · (∂u_x / ∂x)`. Векторне рівняння руху вироджується в одновимірне хвильове рівняння зі швидкістю:

```
c_rod = √( E / ρ )
```

Оскільки коефіцієнт Пуассона реальних матеріалів лежить у межах `0 < ν < 0.5`, математично доведено, що поздовжня хвиля в безмежному середовищі завжди поширюється швидше за хвилю у стрижні та швидше за поперечну зсувну хвилю:

```
c_L > c_rod > c_S
```

Цей строгий математичний висновок лежить в основі всієї сучасної сейсмології, акустичної дефектоскопії та ультразвукової матеріалознавчої діагностики.

### 5. Граничні умови та математичний розв'язок хвильового рівняння Релея

На вільній межі розділу твердого тіла з вакуумом (`z = 0`) нормальні та дотичні напруження мають дорівнювати нулю: `σ_zz = 0`, `σ_xz = 0`, `σ_yz = 0`.

Шукаючи розв'язок у вигляді поверхневої хвилі, яка експоненціально затухає вглиб середовища (`exp(−q·z)` для P-компоненти та `exp(−s·z)` для S-компоненти), підстановка потенціалів у граничні умови дає знамените **характеристичне рівняння Релея**:

```
η⁶ − 8·η⁴ + 8·(3 − 2·ξ²)·η² − 16·(1 − ξ²) = 0
```

де `η = c_R / c_S` — відношення швидкості хвилі Релея до поперечної швидкості, а `ξ = c_S / c_L` — відношення поперечної швидкості до поздовжньої.

Для матеріалу з коефіцієнтом Пуассона `ν = 0.25` відношення швидкостей становить `ξ = 1 / √3 ≈ 0.577`. Дійсний корінь рівняння Релея дорівнює:

```
η = c_R / c_S ≈ 0.9194
```

Отже, швидкість поверхневої хвилі Релея в ізотропному матеріалі становить приблизно `92%` від швидкості поперечної хвилі і не залежить від частоти коливань за відсутності покриттів, що робить хвилі Релея недисперсійними на пласкій вільній поверхні.
