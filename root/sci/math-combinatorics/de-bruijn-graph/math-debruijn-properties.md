# 🧮 Математичні властивості та теорема BEST для графів де Брейнена

Ця вставка містить строгий математичний аналіз орієнтованих графів де Брейнена `B(k, n)`: формальні означення, топологічні параметри, спектральні властивості матриці суміжності, двоїстість між Ейлеровими та Гамільтоновими циклами, а також точне виведення кількості послідовностей де Брейнена за теоремою BEST.

## 1. Алгебраїчне означення та алгебра зсувів

Нехай `Σ = {α₀, α₁, ..., αₖ₋₁}` — скінченний алфавіт потужності `|Σ| = k ≥ 2`, а `n ≥ 1` — ціле число, що задає порядок графа.

Орієнтований граф де Брейнена `B(k, n) = (V, E)` визначається так:

1. **Множина вершин `V`** складається з усіх можливих слів (впорядкованих послідовностей) довжиною `n - 1` над алфавітом `Σ`:

```
V = Σⁿ⁻¹ = { u = (u₁, u₂, ..., uₙ₋₁) | uᵢ ∈ Σ }
```

Кількість вершин у графі дорівнює:

```
|V| = kⁿ⁻¹
```

2. **Множина орієнтованих ребер `E`** складається з усіх слів довжиною `n` над алфавітом `Σ`:

```
E = Σⁿ = { e = (e₁, e₂, ..., eₙ) | eᵢ ∈ Σ }
```

Кількість ребер у графі дорівнює:

```
|E| = kⁿ
```

Орієнтоване ребро `e = (a₁, a₂, ..., a♙)` виходить із вершини-префікса `u = (a₁, a₂, ..., a♙₋₁)` і входить у вершину-суфікс `v = (a₂, a₃ ..., a♙)`:

```
u = (a₁, a₂, ..., a♙₋₁)  ──[ e = (a₁, a₂, ..., a♙) ]──>  v = (a₂, a₃, ..., a♙)
```

Операція переходу від `u` до `v` являє собою **циклічний лівий зсув** із вилученням старшого символу `a₁` та додаванням нового молодшого символу `a♙` справа. Це відображення задається алгебраїчним оператором зсуву `σ: Σⁿ⁻¹ × Σ → Σⁿ⁻¹`, де `σ((u₁, ..., uₙ₋₁), x) = (u₂, ..., uₙ₋₁, x)`.

## 2. Ступені вершин, сильна зв'язність та діаметр

Граф де Брейнена `B(k, n)` має унікальні симетричні топологічні характеристики:

1. **Ейлеровість та регулярність ступенів.**
Для кожної вершини `u = (u₁, u₂, ..., uₙ₋₁) ∈ V`:
- Існує рівно `k` вихідних ребер, оскільки новий символ `a♙` на правому краї можна вибрати `k` способами: `deg⁺(u) = k`.
- Існує рівно `k` вхідних ребер, оскільки попередній вилучений символ `a₁` на лівому краї міг бути вибраний `k` способами: `deg⁻(u) = k`.

Оскільки вхідний ступінь кожної вершини дорівнює її вихідному ступеню (`deg⁺(u) = deg⁻(u) = k`), граф `B(k, n)` є **балансованим орграфом** і, відповідно, **Ейлеровим графом**.

2. **Петлі (Self-loops).**
Вершина `u` має самопетлю (ребро `(u, u)`) тоді й лише тоді, коли всі символи слова `u` однакові: `u = (α, α, ..., α)`. У графі `B(k, n)` існує рівно `k` самопетель, які відповідають ребрам `(α, α, ..., α)`.

3. **Сильна зв'язність та діаметр.**
Граф `B(k, n)` є сильно зв'язаним: для будь-яких двох вершин `u = (u₁, ..., uₙ₋₁)` та `w = (w₁, ..., wₙ₋₁)` існує орієнтований шлях від `u` до `w`.

Довжина найкоротшого шляху між довільною парою вершин не перевищує `n - 1`. Справді, послідовно подаючи символи вершини-призначення `w₁, w₂, ..., w♙₋₁` як вхідні символи зсуву, ми досягнемо вершини `w` рівно за `n - 1` кроків переходу:

```
(u₁, u₂, ..., u♙₋₁) → (u₂, ..., u♙₋₁, w₁) → (u₃, ..., w₁, w₂) → ... → (w₁, w₂, ..., w♙₋₁)
```

Отже, **діаметр графа `diam(B(k, n))` дорівнює `n - 1`**. Це найменший можливий діаметр для орграфа з рівно `kⁿ⁻¹` вершинами та максимальним вихідним ступенем `k`, який досягає теоретичної межі Мура для орієнтованих графів.

## 3. Оператор лінійного графа та ізоморфізм L(B(k, n-1))

Лінійним графом (англ. *Line Graph*) орієнтованого графа `G = (V, E)` називається граф `L(G)`, вершинами якого є ребра `E(G)`, а орієнтовані ребра в `L(G)` відповідають впорядкованим парам суміжних ребер `(e₁, e₂)` у `G`, де кінець `e₁` збігається з початком `e₂`.

**Фундаментальна теорема про лінійний граф де Брейнена:**
Граф де Брейнена порядку `n` є ізоморфним лінійному графу від графа де Брейнена порядку `n - 1`:

```
B(k, n) ≅ L( B(k, n - 1) )
```

**Доведення.**
1. Множина вершин `B(k, n)` дорівнює `Σⁿ⁻¹`. Множина вершин `L(B(k, n - 1))` дорівнює множині ребер `B(k, n - 1)`, яка за означенням є `Σⁿ⁻¹`. Множини вершин збігаються.
2. Ребро у `B(k, n)` — це слово `(a₁, a₂, ..., a♙) ∈ Σⁿ`, яке з'єднує `(a₁, ..., a♙₋₁)` із `(a₂, ..., a♙)`.
3. У `B(k, n - 1)` це відповідає двом суміжним ребрам `e₁ = (a₁, ..., a♙₋₁)` та `e₂ = (a₂, ..., a♙)`, які зустрічаються у спільній вершині `(a₂, ..., a♙₋₁)`.
4. Впорядкована пара суміжних ребер `(e₁, e₂)` у `B(k, n - 1)` утворює єдине орієнтоване ребро у `L(B(k, n - 1))`.
5. Отже, відображення `f: E(L(B(k, n - 1))) → E(B(k, n))` є взаємно однозначним бієктивним ізоморфізмом графів.

З цієї властивості випливає фундаментальна двоїстість між Ейлеровими та Гамільтоновими циклами:

1. Ребра в графі `B(k, n - 1)` відповідають вершинам у графі `B(k, n)`.
2. Ейлерів цикл у графі `B(k, n - 1)` проходить через кожне ребро `B(k, n - 1)` рівно один раз.
3. Отже, Ейлерів цикл у `B(k, n - 1)` точно відповідає **Гамільтоновому циклу** у `B(k, n)`, який відвідує кожну вершину `B(k, n)` рівно один раз.

Це дає виключний обчислювальний наслідок: хоча пошук Гамільтонового циклу в довільних графах є NP-повною задачею, у графах де Брейнена Гамільтонів цикл знаходять за лінійний час `O(kⁿ)` шляхом побудови Ейлерового циклу в попередньому графі `B(k, n - 1)`.

## 4. Виведення кількості циклів за теоремою BEST

Теорема BEST (de Bruijn, van Aardenne-Ehrenfest, Smith, Tutte) визначає кількість орієнтованих Ейлерових циклів `EULER(G)` у балансованому сильно зв'язаному орграфі `G = (V, E)`:

```
EULER(G) = t_r(G) · ∏_{v ∈ V} (deg⁺(v) - 1)!
```

де `t_r(G)` — кількість орієнтованих остових дерев з коренем у довільно вибраній вершині `r` (орієнтованих до кореня `r`).

Застосуємо теорему BEST до графа `B(k, n)`:

1. Вхідний ступінь кожної вершини `deg⁺(v) = k`.
2. Факторіальний множник для кожної з `|V| = kⁿ⁻¹` вершин дорівнює:

```
(deg⁺(v) - 1)! = (k - 1)!
```

3. Добуток факторіалів по всіх вершинах становить:

```
∏_{v ∈ V} (deg⁺(v) - 1)! = [ (k - 1)! ]^{kⁿ⁻¹}
```

4. За матричною теоремою про дерева (Tutte's Matrix Tree Theorem) кількість орієнтованих остових дерев у `B(k, n)` обчислюється через головний мінор матриці Лапласа `L = D - A` і дорівнює:

```
t_r( B(k, n) ) = k^{kⁿ⁻¹ - n}
```

5. Підставляючи ці значення у формулу BEST, отримуємо кількість орієнтованих Ейлерових циклів у `B(k, n)`:

```
EULER( B(k, n) ) = k^{kⁿ⁻¹ - n} · [ (k - 1)! ]^{kⁿ⁻¹}
                 = [ k · (k - 1)! ]^{kⁿ⁻¹} / kⁿ
                 = (k!)^{kⁿ⁻¹} / kⁿ
```

Оскільки кожна замкнена послідовність де Брейнена довжиною `kⁿ` еквівалентна Ейлеровому циклу у `B(k, n)` з точністю до вибору початкового ребра та його орієнтації, підсумкова кількість еквівалентних послідовностей дорівнює саме `(k!)^{kⁿ⁻¹} / kⁿ`.

Для двійкового алфавіту `k = 2` кількість послідовностей де Брейнена дорівнює:

```
N(2, n) = (2!)^{2ⁿ⁻¹} / 2ⁿ = 2^{2ⁿ⁻¹ - n}
```

Наприклад:
- Для `n = 3`: `N(2, 3) = 2^{2² - 3} = 2¹ = 2` цикли (послідовності `00011101` та `00010111`).
- Для `n = 4`: `N(2, 4) = 2^{2³ - 4} = 2⁴ = 16` унікальних циклічних послідовностей.
- Для `n = 5`: `N(2, 5) = 2^{2⁴ - 5} = 2¹¹ = 2048` послідовностей.

## 5. Спектральні властивості матриці суміжності

Матриця суміжності `A` графа `B(k, n)` має розмірність `kⁿ⁻¹ × kⁿ⁻¹`. Елемент `A[i, j] = 1`, якщо існує ребро з вершини `i` до `j`, і `0` в іншому випадку.

Характеристичний многочлен матриці суміжності `A` графа `B(k, n)` має вигляд:

```
det(λI - A) = λ^{kⁿ⁻¹ - 1} · (λ - k)
```

Звідси випливає спектр власних значень матриці `A`:
1. **Головне власне значення `λ₀ = k`** має кратність `1`. Воно відповідає правому власному вектору з усіх одиниць `(1, 1, ..., 1)ᵀ`, що відображає `k`-регулярність графа.
2. **Нульове власне значення `λ = 0`** має кратність `kⁿ⁻¹ - 1`.

Оскільки майже всі власні значення дорівнюють нулю, матриця `A` є сильно нільпотентною відносно відхилень від середнього. Зокрема, `n - 1`-а степінь матриці суміжності задовольняє тотожність:

```
Aⁿ⁻¹ = kⁿ⁻² · J
```

де `J` — матриця з усіх одиниць розміру `kⁿ⁻¹ × kⁿ⁻¹`. Це означає, що з будь-якої вершини до будь-якої іншої вершини існує рівно `kⁿ⁻²` орієнтованих шляхів довжиною `n - 1`. Це математично доводить ідеальну змішуваність (англ. *mixing time*) та розширювальні властивості графа де Брейнена.

## 6. Марковські ланцюги та рівномірність розподілу

Якщо розглядати випадкове блукання (англ. *random walk*) на графі де Брейнена `B(k, n)`, де з кожної вершини перехід по будь-якому з `k` вихідних ребер обирається з рівною ймовірністю `p = 1/k`, ми отримуємо однорідний Марковський ланцюг зі скінченною множиною станів `V`.

Властивості цього Марковського ланцюга:
1. **Стаціонарний розподіл:** Стаціонарна ймовірність кожної вершини `v ∈ V` є строго рівномірною:
```
π(v) = 1 / |V| = 1 / kⁿ⁻¹
```
2. **Час змішування (Mixing Time):** Завдяки властивості `Aⁿ⁻¹ = kⁿ⁻² J` марковський ланцюг досягає точного стаціонарного розподілу `π` усього за `n - 1` кроків, незалежно від початкового стану.
3. **Автокореляційна функція:** Для будь-якої послідовності де Брейнена `S` довжиною `L = kⁿ` автокореляція `R(τ)` для будь-якого нецілого зсуву `τ ≢ 0 (mod L)` задовольняє умові:
```
R(τ) = ∑_{i=0}^{L-1} S[i] · S[i + τ] = -1
```
Це означає, що послідовності де Брейнена володіють ідеальними білими шумоподібними спектральними характеристиками, аналогічними ідеальній бінарній псевдовипадковій послідовності (PRBS).

## 7. Ранг матриці Лапласа та розширювальні властивості

Орієнтований лапласіан графа `L_G = D - A`, де `D = k · I` — діагональна матриця степенів вершин, а `A` — матриця суміжності `B(k, n)`.

Характеристичний многочлен лапласіана:

```
det(μI - L_G) = det((μ - k)I + A) = (μ - k)^{kⁿ⁻¹ - 1} · μ
```

Власні значення матриці Лапласа `L_G`:
- `μ₀ = 0` з кратністю `1` (відповідає зв'язності графа).
- `μ₁ = μ₂ = ... = μ_{kⁿ⁻¹ - 1} = k` з кратністю `kⁿ⁻¹ - 1`.

Оскільки друге найменше власне значення лапласіана (алгебраїчна зв'язність, або константа Фідлера) дорівнює `μ₁ = k`, граф де Брейнена володіє надзвичайно високим спектральним зазором (англ. *spectral gap*). Це математично доводить, що граф є чудовим експандером: будь-яке підмножина вершин `S ⊂ V` має велику межу суміжних вершин, що унеможливлює утворення «вузьких шийок» (англ. *bottlenecks*) при передачі даних у мережі.
