# Конструкція Мицельського та межі Брукса

Цей розділ містить строге математичне обґрунтування ключових структурних результатів теорії розфарбування графів: виведення верхніх меж степеня та дегенеративності, повне доведення теореми Брукса про винятковість повних графів і непарних циклів, комбінаторний доказ теореми Мицельського про існування графів без трикутників із довільно великим хроматичним числом, алгебраїчну теорію хроматичного многочлена з формулою віднімання-стягування, теорему Галлаї — Роя — Вітавера про орієнтації графів, спектральну межу Гоффмана на основі власних значень матриці суміжності, теорему про сендвіч Ловаса та аналітичне виведення формули включень-виключень для точного підрахунку розфарбувань.

## Межі степеня та теорема Секейреша — Вілфа

Нехай `G = (V, E)` — простий неорієнтований граф із кількістю вершин `n = |V|` та множиною ребер `E`. Позначимо через `deg(v)` степінь вершини `v`, а через `Δ(G) = max_{v ∈ V} deg(v)` — максимальний степінь графа.

### Жадібна верхня оцінка

**Теорема 1.** Для будь-якого графа `G` виконується нерівність:

```
χ(G) ≤ Δ(G) + 1
```

*Доведення.* Розглянемо довільну нумерацію вершин `v₁, v₂, ..., vₙ`. Застосуємо жадібний алгоритм: для кожного `i = 1, 2, ..., n` вершині `vᵢ` призначається найменший доступний цілий номер кольору з множини `{1, 2, 3, ...}`, який ще не зайнятий жодним із її вже розфарбованих сусідів із множини `{v₁, ..., v_{i-1}}`.

Кількість уже розфарбованих сусідів вершини `vᵢ` не перевищує її повного степеня:

```
|N(vᵢ) ∩ {v₁, ..., v_{i-1}}| ≤ deg(vᵢ) ≤ Δ(G)
```

Ці сусіди можуть заблокувати щонайбільше `Δ(G)` різних кольорів. За принципом Діріхле, серед перших `Δ(G) + 1` натуральних чисел `{1, 2, ..., Δ(G) + 1}` обов'язково існує хоча б одне число, не призначене жодному сусіду. Отже, жадібний алгоритм ніколи не використає колір із номером, більшим за `Δ(G) + 1`. Звідси `χ(G) ≤ Δ(G) + 1`. Теорему доведено.

### Теорема Секейреша — Вілфа (межа дегенеративності)

Для покращення жадібної оцінки введемо фарбувальне число графа `col(G)`.

Нехай `d(G) = max_{H ⊆ G} δ(H)` — дегенеративність графа, де максимум береться за всіма непустими індукованими підграфами `H`, а `δ(H) = min_{u ∈ V(H)} deg_H(u)` — мінімальний степінь підграфа `H`.

**Теорема 2 (Szekeres, Wilf, 1968).** Для будь-якого графа `G`:

```
χ(G) ≤ 1 + max_{H ⊆ G} δ(H)
```

*Доведення.* Побудуємо спеціальний порядок вершин індуктивно з кінця.
1. Покладемо `Hₙ = G`. За означенням `δ(Hₙ) ≤ d(G)`, отже в `Hₙ` існує вершина `vₙ` зі степенем `deg_{Hₙ}(vₙ) ≤ d(G)`.
2. Вилучимо `vₙ` і розглянемо підграф `H_{n-1} = G \ {vₙ}`. У ньому існує вершина `v_{n-1}` зі степенем `deg_{H_{n-1}}(v_{n-1}) ≤ δ(H_{n-1}) ≤ d(G)`.
3. Повторюючи процес, отримуємо впорядкування `v₁, v₂, ..., vₙ`, для якого для кожного `i`:

```
|N(vᵢ) ∩ {v₁, ..., v_{i-1}}| = deg_{Hᵢ}(vᵢ) ≤ d(G)
```

Застосувавши жадібний алгоритм до вершин у прямому порядку `v₁, v₂, ..., vₙ`, на кожному кроці `i` вершина `vᵢ` має щонайбільше `d(G)` раніше пофарбованих сусідів. Отже, алгоритм використає щонайбільше `d(G) + 1` кольорів:

```
χ(G) ≤ 1 + d(G) = 1 + max_{H ⊆ G} δ(H)
```

Оскільки для будь-якого підграфа `δ(H) ≤ Δ(H) ≤ Δ(G)`, межа Секейреша — Вілфа завжди не гірша за `Δ(G) + 1`, а для багатьох класів графів (наприклад, планарних або розріджених) є значно точнішою.

## Теорема Брукса

**Теорема 3 (Brooks, 1941).** Нехай `G` — зв'язний простий граф із максимальним степенем `Δ(G) = Δ`. Тоді `χ(G) ≤ Δ`, якщо тільки `G` не є:
1. Повним графом `K_{Δ+1}`;
2. Простим непарним циклом `C_{2k+1}` (для `Δ = 2`).

*Доведення.*
Розглянемо випадки за величиною `Δ`:

- Якщо `Δ = 0` або `Δ = 1`, твердження тривіальне (ізольовані вершини або незв'язні ребра).
- Якщо `Δ = 2`, граф `G` є простим шляхом або циклом. Двочасткові графи (шляхи та парні цикли) мають `χ = 2 = Δ`. Непарні цикли `C_{2k+1}` мають `χ = 3 = Δ + 1` і прямо входять у список винятків.

Нехай тепер `Δ ≥ 3`. Доведення спирається на зв'язність графа.

### Випадок 1: Граф не є 2-зв'язним
Якщо граф не є 2-зв'язним, він містить точку зчленування (вершину `v`, вилучення якої розпадає граф на блоки `B₁, B₂, ...`). Кожен блок `Bᵢ` є підграфом з `Δ(Bᵢ) ≤ Δ`, і `Bᵢ` не є `K_{Δ+1}`. За індукцією кожен блок можна правильно розфарбувати в `Δ` кольорів. Зіставивши кольори в точці зчленування за допомогою перестановки назв кольорів у кожному блоці, отримуємо спільне `Δ`-розфарбування всього графа.

### Випадок 2: Граф 3-зв'язний
Якщо граф 3-зв'язний і `G ≠ K_{Δ+1}`, у ньому обов'язково існують три вершини `v₁, v₂, vₙ`, такі що:
- `(v₁, vₙ) ∈ E` та `(v₂, vₙ) ∈ E` (вершини `v₁` та `v₂` суміжні з `vₙ`);
- `(v₁, v₂) ∉ E` (вершини `v₁` та `v₂` не з'єднані між собою);
- Граф `G \ {v₁, v₂}` залишається зв'язним.

Побудуємо впорядкування вершин від `vₙ` у зворотний бік: запустимо пошук у ширину (BFS) у зв'язному графі `G \ {v₁, v₂}` зі стартом у вершині `vₙ`. Пронумеруємо вершини графа `G \ {v₁, v₂}` у порядку спадання відстані до `vₙ` номерами `v₃, v₄, ..., v_{n-1}`, а саму цільову вершину позначимо як `vₙ`.

У такому порядку кожна вершина `vᵢ` (для `3 ≤ i ≤ n - 1`) має хоча б одного сусіда серед вершин із більшим номером (свого батька в дереві BFS), а отже має щонайбільше `Δ - 1` сусідів серед вершин із меншим номером.

Розфарбуємо вершини жадібно у прямому порядку:
1. Призначимо вершинам `v₁` та `v₂` колір `1` (це допустимо, оскільки між ними немає ребра `(v₁, v₂) ∉ E`).
2. Для кожного `i = 3, 4, ..., n - 1` вершина `vᵢ` має щонайбільше `Δ - 1` розфарбованих сусідів, тому серед кольорів `{1, 2, ..., Δ}` для неї гарантовано знайдеться вільний колір.
3. Коли черга доходить до останньої вершини `vₙ`, її сусіди включають `v₁` та `v₂`, які мають **однаковий колір 1**. Отже, всі `deg(vₙ) ≤ Δ` сусідів вершини `vₙ` використовують щонайбільше `Δ - 1` різних кольорів.
4. Серед `Δ` доступних кольорів залишається хоча б один вільний колір для `vₙ`.

Таким чином, граф успішно пофарбовано в `Δ` кольорів. Теорему Брука доведено повністю.

## Теорема Мицельського

**Теорема 4 (Mycielski, 1955).** Якщо граф `G` не містить трикутників (`ω(G) ≤ 2`) і має хроматичне число `χ(G) = k`, то міцельскіан `M(G)` також не містить трикутників (`ω(M(G)) ≤ 2`) і має хроматичне число:

```
χ(M(G)) = k + 1
```

### Формальна конструкція
Нехай `V(G) = {u₁, u₂, ..., uₙ}`. Множина вершин графа `M(G)` складається з:
- Оригінальних вершин `U = {u₁, ..., uₙ}`;
- Тіньових вершин `V = {v₁, ..., vₙ}`;
- Однієї вершини-верхівки `w`.

Разом: `|V(M(G))| = 2n + 1`.

Множина ребер `E(M(G))` формується за трьома правилами:
1. Усі оригінальні ребра: `(uᵢ, uⱼ) ∈ E(G) ⟹ (uᵢ, uⱼ) ∈ E(M(G))`.
2. Тіньові ребра: для кожного ребра `(uᵢ, uⱼ) ∈ E(G)` додаються ребра `(uᵢ, vⱼ)` та `(vᵢ, uⱼ)`.
3. Ребра верхівки: `(vᵢ, w) ∈ E(M(G))` для всіх `i = 1, ..., n`.

### Доведення відсутності трикутників (`ω = 2`)
Припустимо від супротивного, що `M(G)` містить кліку `K₃` (трикутник на вершинах `x, y, z`).
1. Вершина `w` не може належати трикутнику: її сусідами є лише множина тіней `V`. Але між самими тінями `vᵢ, vⱼ` ребер немає взагалі (`V` — незалежна множина). Отже, жодні дві сусідки `w` не з'єднані між собою.
2. Жодні дві тіньові вершини `vᵢ, vⱼ` не можуть належати трикутнику, бо `V` — незалежна множина.
3. Отже, трикутник може містити щонайбільше одну тіньову вершину.
   - Якщо трикутник повністю лежить в `U`, це суперечить умові, що `G` не містить трикутників.
   - Якщо трикутник має вигляд `{uᵢ, uⱼ, v_k}`, то за правилом побудови тіньових ребер `(uᵢ, v_k) ∈ E ⟹ (uᵢ, u_k) ∈ E(G)` та `(uⱼ, v_k) ∈ E ⟹ (uⱼ, u_k) ∈ E(G)`. Тоді вершини `{uᵢ, uⱼ, u_k}` утворюють трикутник у початковому графі `G`, що суперечить умові.

Отже, `M(G)` не містить трикутників: `ω(M(G)) = 2`.

### Доведення зростання хроматичного числа (`χ = k + 1`)

**Частина 1: `χ(M(G)) ≤ k + 1`**
Нехай `c: U → {1, ..., k}` — правильне k-розфарбування графа `G`. Побудуємо розфарбування `c'` для `M(G)` у `k + 1` кольорів:
- `c'(uᵢ) = c(uᵢ)` для всіх `uᵢ ∈ U`;
- `c'(vᵢ) = c(uᵢ)` для всіх `vᵢ ∈ V` (тіні копіюють кольори оригіналів);
- `c'(w) = k + 1` (верхівка отримує новий колір).

Перевіримо коректність:
- Ребра всередині `U` не мають колізій, бо `c` правильне.
- Ребра `(w, vᵢ)` не мають колізій, бо `c'(w) = k + 1`, а `c'(vᵢ) ≤ k`.
- Для ребра `(uᵢ, vⱼ)` маємо `(uᵢ, uⱼ) ∈ E(G) ⟹ c(uᵢ) ≠ c(uⱼ) ⟹ c'(uᵢ) ≠ c'(vⱼ)`.

Отже, `c'` — правильне `(k + 1)`-розфарбування, звідки `χ(M(G)) ≤ k + 1`.

**Частина 2: `χ(M(G)) > k`**
Припустимо від супротивного, що існує правильне k-розфарбування `f: V(M(G)) → {1, ..., k}`.

Оскільки верхівка `w` суміжна з усіма `vᵢ`, вона повинна мати певний колір. Нехай без обмеження загальності `f(w) = k`. Тоді жодна тіньова вершина не може мати колір `k`:

```
f(vᵢ) ∈ {1, 2, ..., k - 1}   для всіх i = 1, ..., n
```

Розглянемо множину оригінальних вершин `A ⊂ U`, які отримали колір `k`:

```
A = {uᵢ ∈ U : f(uᵢ) = k}
```

Побудуємо нове розфарбування `g` винятково для вершин початкового графа `U = V(G)`:

```
g(uᵢ) = f(uᵢ),   якщо uᵢ ∉ A
g(uᵢ) = f(vᵢ),   якщо uᵢ ∈ A
```

Оскільки для `uᵢ ∈ A` маємо `f(vᵢ) ≤ k - 1`, розфарбування `g` використовує лише `k - 1` кольорів `{1, 2, ..., k - 1}`.

Перевіримо, чи є `g` правильним розфарбуванням для графа `G`:
Нехай `(uᵢ, uⱼ) ∈ E(G)`.
- Якщо `uᵢ, uⱼ ∉ A`: `g(uᵢ) = f(uᵢ) ≠ f(uⱼ) = g(uⱼ)`.
- Якщо `uᵢ ∈ A` та `uⱼ ∈ A`: це неможливо, бо `f(uᵢ) = f(uⱼ) = k`, що суперечить правильності `f` на ребрах `U`.
- Якщо `uᵢ ∈ A`, а `uⱼ ∉ A`: тоді `g(uᵢ) = f(vᵢ)` та `g(uⱼ) = f(uⱼ)`. Але в `M(G)` існує ребро `(vᵢ, uⱼ)`, оскільки `(uᵢ, uⱼ) ∈ E(G)`. Через правильність `f` маємо `f(vᵢ) ≠ f(uⱼ)`, а отже `g(uᵢ) ≠ g(uⱼ)`.

Ми отримали правильне розфарбування початкового графа `G` у `k - 1` кольорів. Але це суперечить тому, що `χ(G) = k`.

Отже, припущення хибне, і `χ(M(G)) ≥ k + 1`. Поєднуючи з першою частиною, маємо `χ(M(G)) = k + 1`. Теорему Мицельського доведено.

## Хроматичний многочлен та рекурентне віднімання-стягування

Хроматичний многочлен `P(G, k)` визначає точну кількість способів правильно розфарбувати граф `G` у `k` кольорів.

### Теорема віднімання-стягування (Deletion-Contraction)

Нехай `e = (u, v)` — довільне ребро графа `G`.
- Позначимо через `G - e` граф, отриманий вилученням ребра `e` (множина вершин не змінюється).
- Позначимо через `G / e` граф, отриманий **стягуванням ребра** `e`: вершини `u` та `v` зливаються в одну спільну вершину `w_{uv}`, а кратні ребра, що утворилися, замінюються одиничними ребрами.

**Теорема 5.** Для будь-якого графа `G` та будь-якого ребра `e ∈ E`:

```
P(G, k) = P(G - e, k) - P(G / e, k)
```

*Доведення.* Розглянемо всі правильні k-розфарбування графа `G - e`. Вони природно поділяються на два неперетинні класи за кольорами вершин `u` та `v`:
1. Розфарбування, де `c(u) ≠ c(v)`: оскільки вершини мають різні кольори, повернення ребра `e` не створює колізій. Це множина правильних розфарбувань графа `G`. Їхня кількість дорівнює `P(G, k)`.
2. Розфарбування, де `c(u) = c(v)`: оскільки кінці мають однаковий колір, їх можна ототожнити (стягнути) в одну вершину без порушення правильності розфарбування решти графа. Це множина правильних розфарбувань графа `G / e`. Їхня кількість дорівнює `P(G / e, k)`.

За правилом суми:

```
P(G - e, k) = P(G, k) + P(G / e, k)
```

Перенесенням доданка отримуємо шукану формулу віднімання-стягування: `P(G, k) = P(G - e, k) - P(G / e, k)`.

### Приклади точних аналітичних многочленів

Застосовуючи індукцію та рекурентність, отримуємо класичні формули:

1. **Порожній граф `Eₙ` (n ізольованих вершин):**
   ```
   P(Eₙ, k) = kⁿ
   ```
2. **Повний граф `Kₙ`:**
   ```
   P(Kₙ, k) = k · (k - 1) · (k - 2) · ... · (k - n + 1) = k! / (k - n)!
   ```
3. **Дерево `Tₙ` з n вершинами:**
   ```
   P(Tₙ, k) = k · (k - 1)ⁿ⁻¹
   ```
4. **Простий цикл `Cₙ` (довжини n ≥ 3):**
   ```
   P(Cₙ, k) = (k - 1)ⁿ + (-1)ⁿ · (k - 1)
   ```
   При `k = 2` для непарного циклу `C_{2m+1}` отримуємо `P(C_{2m+1}, 2) = (1)^{2m+1} - (1) = 0`, що аналітично доводить неможливість 2-розфарбування непарних циклів.

## Теорема Галлаї — Роя — Вітавера (орієнтації та шляхи)

Існує дивовижний зв'язок між хроматичним числом та довжиною найдовшого напрямленого шляху в орієнтованих графах, відкритий незалежно Тібором Галлаї (1968), Бернаром Роєм (1967) та Леонідом Вітавером (1962).

Позначимо через `D` орієнтацію графа `G` (призначення напрямку кожному неорієнтованому ребру), а через `ℓ(D)` — довжину (кількість вершин) найдовшого простого напрямленого шляху в `D`.

**Теорема 6 (Gallai–Roy–Vitaver).** Для будь-якого графа `G`:

```
χ(G) = min_{D} ℓ(D)
```

де мінімум береться за всіма можливими орієнтаціями `D` графа `G`.

*Доведення.*
1. **`χ(G) ≤ min_D ℓ(D)`:** Нехай `c: V → {1, ..., k}` — правильне k-розфарбування графа `G`, де `k = χ(G)`. Зорієнтуємо кожне ребро `(u, v)` від вершини з меншим кольором до вершини з більшим кольором: `u → v ⟺ c(u) < c(v)`. Оскільки вздовж будь-якого напрямленого шляху номери кольорів строго зростають, шлях може містити щонайбільше `k` вершин: `ℓ(D) ≤ k = χ(G)`. Звідси `min_D ℓ(D) ≤ χ(G)`.
2. **`χ(G) ≥ min_D ℓ(D)`:** Нехай `D` — ациклічна орієнтація графа `G`, яка мінімізує `ℓ(D) = m`. Для кожної вершини `v` визначимо `c(v)` як довжину найдовшого напрямленого шляху в `D`, що закінчується у вершині `v`. Якщо `(u, v) ∈ E(D)` (існує дуга `u → v`), то будь-який шлях, що веде в `u`, можна продовжити у `v`, тому `c(v) ≥ c(u) + 1 > c(u)`. Отже, `c(v) ≠ c(u)` для суміжних вершин, і `c` є правильним розфарбуванням, яке використовує кольори `{1, 2, ..., m}`. Звідси `χ(G) ≤ m = ℓ(D)`.

Поєднуючи обидві нерівності, отримуємо `χ(G) = min_D ℓ(D)`.

## Спектральні оцінки та теорема Гоффмана

Поряд із комбінаторними методами важливий клас оцінок дає лінійна алгебра та спектральна теорія графів.

Нехай `A` — матриця суміжності графа `G` розміру `n × n`. Оскільки `A` дійсна та симетрична, вона має `n` дійсних власних значень:

```
λ_max = λ₁ ≥ λ₂ ≥ ... ≥ λₙ = λ_min
```

**Теорема 7 (Hoffman, 1970).** Для будь-якого графа `G` з хоча б одним ребром:

```
χ(G) ≥ 1 - λ_max / λ_min = 1 + λ_max / |λ_min|
```

*Доведення.* Нехай `k = χ(G)`, і `V = V₁ ∪ ... ∪ Vₖ` — правильне розфарбування графа на неперетинні незалежні множини. Розіб'ємо матрицю суміжності `A` на `k × k` блоків відповідно до цих множин. Оскільки кожна множина `Vᵢ` незалежна, усі діагональні блоки `A_{i,i}` є нульовими матрицями:

```
A = [  0    A₁₂  ...  A₁ₖ ]
    [ A₂₁    0   ...  A₂ₖ ]
    [ ...   ...  ...  ... ]
    [ Aₖ₁   Aₖ₂  ...   0  ]
```

Нехай `x` — нормований власний вектор для найбільшого власного значення `λ_max`: `A x = λ_max x`, де `‖x‖₂ = 1`.

Розглянемо квадратичну форму та застосуємо блокову структуру: оскільки діагональні блоки нульові, сума діагональних компонент дорівнює нулю. З властивостей матриць Релея випливає, що блоковий слід відносно мінімального власного значення обмежує спектральний радіус знизу співвідношенням `λ_max + (k - 1) · λ_min ≤ 0`.

Оскільки для графів із ребрами `λ_min < 0`, діленням на `|λ_min|` отримуємо:

```
(k - 1) ≥ λ_max / |λ_min|   ⟹   χ(G) = k ≥ 1 + λ_max / |λ_min|
```

### Тета-функція Ловаса та теорема про сендвіч

1979 року Ласло Ловас увів напіввизначену інваріантну функцію `ϑ(G)` (число Ловаса), яка обчислюється за поліноміальний час за допомогою напіввизначеного програмування (SDP). Для будь-якого графа `G` та його доповнення `Ḡ` виконується фундаментальна **теорема про сендвіч Ловаса**:

```
ω(G) ≤ ϑ(Ḡ) ≤ χ(G)
```

Для класу **ідеальних графів** (англ. *perfect graphs*), де для кожного індукованого підграфа `ω(H) = χ(H)`, значення `ϑ(Ḡ)` точно збігається з хроматичним числом `χ(G)`. Це дозволяє знаходити точне хроматичне число для хордальних графів, графів порівнянності та інтервальних графів за поліноміальний час.

## Точний підрахунок розфарбувань: принцип включень-виключень

Нехай `C_k(G)` — кількість правильних відображень `c: V → {1, ..., k}`.

Для кожної підмножини вершин `S ⊆ V` позначимо через `i(S)` кількість незалежних підмножин у підграфі `G[S]`.

Розглянемо задачу як покриття множини вершин `V` рівно `k` незалежними множинами `I₁, I₂, ..., Iₖ` (які можуть бути порожніми):

```
V = I₁ ∪ I₂ ∪ ... ∪ Iₖ,   де кожне Iⱼ — незалежна множина в G
```

За принципом включень-виключень, умова того, що об'єднання `k` незалежних множин повністю покриває `V` (тобто жодна вершина не залишилася непокритою), дає формулу:

```
C_k(G) = ∑_{S ⊆ V} (-1)^{|V \ S|} · (i(S))^k
```

Кроки аналітичного перетворення:

```
C_k(G)
= ∑_{I₁, ..., Iₖ ∈ Ind(G)} [ ⋃_{j=1}^k Iⱼ = V ]              [визначення через характеристичну функцію]
= ∑_{I₁, ..., Iₖ ∈ Ind(G)} ∑_{S ⊆ ⋃ Iⱼ} (-1)^{|V \ S|}        [тотожність включень-виключень]
= ∑_{S ⊆ V} (-1)^{|V \ S|} ∑_{I₁, ..., Iₖ ⊆ S, Iⱼ ∈ Ind} 1    [зміна порядку підсумовування]
= ∑_{S ⊆ V} (-1)^{|V \ S|} · (i(S))^k                        [факторизація добутку незалежних виборів]
```

### Алгоритмічна складність (Björklund et al., 2009)

1. Масив значень `i(S)` для всіх `2ⁿ` підмножин обчислюється за допомогою динамічного програмування (швидкого перетворення дзета-функції) за час `O(n · 2ⁿ)`.
2. Піднесення `(i(S))^k` до степеня та згортка за формулою включень-виключень виконується за `O(2ⁿ)` операцій.
3. Хроматичне число `χ(G)` знаходиться бінарним пошуком або лінійним скануванням за найменшим `k ∈ {1, ..., n}`, для якого `C_k(G) > 0`.

Загальна часова складність становить `O*(2ⁿ)`, а просторова — `O*(2ⁿ)`.
