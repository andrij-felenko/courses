# 🧮 Спектральний зазор, кондуктанс та ефективний опір у графах

Ця математична вставка розгортає суворий алгебраїчний та спектральний апарат аналізу випадкових блукань на скінченних неорієнтованих графах. Вона формалізує доведення існування стаціонарного розподілу, швидкість збіжності через спектральний зазор, нерівність Чигера та точний зв'язок часових характеристик блукання з ефективним опором електричних кіл.

## 1. Матриця переходів та стаціонарний розподіл

Нехай `G = (V, E)` — зв'язний неорієнтований граф без петльових ребер та кратності, де `|V| = n`, `|E| = m`. Позначимо через `A` матрицю суміжності розміру `n × n`, де `A_{uv} = 1`, якщо `{u, v} ∈ E`, і `A_{uv} = 0` в протилежному випадку. Позначимо через `D` діагональну матрицю степенів вершин, де `D_{uu} = d(u) = ∑_v A_{uv}`.

Випадкове блукання описується однорідним марківським ланцюгом зі скінченним простором станів `V`. Матриця переходів `P` визначається як:

```
P = D⁻¹ · A
```

Для кожної пари вершин `u, v ∈ V` елемент матриці `P_{uv}` задає ймовірність переходу з вершини `u` у вершину `v` за один крок:

```
P_{uv} = 1 / d(u)   якщо {u, v} ∈ E
P_{uv} = 0          якщо {u, v} ∉ E
```

Оскільки граф невиважений і неорієнтований, матриця `P` є правостохастичною: сума елементів у кожному рядку дорівнює 1.

```
∑_{v ∈ V} P_{uv} = ∑_{v ~ u} 1 / d(u) = d(u) / d(u) = 1
```

Розподіл ймовірностей перебування блукача у вершинах графа на кроці `t` задається вектором-рядком `π⁽ᵗ⁾ = (π⁽ᵗ⁾(v₁), ..., π⁽ᵗ⁾(vₙ))`. Еволюція розподілу підпорядковується матричному рівнянню:

```
π⁽ᵗ⁾ = π⁽⁰⁾ · Pᵗ
```

Вектор-рядок `π` називається **стаціонарним розподілом**, якщо він задовольняє умову нерухомої точки:

```
π · P = π      при сумарній нормі ∑_{v ∈ V} π(v) = 1
```

### Теорема (Форма стаціонарного розподілу)
Для будь-якого зв'язного неорієнтованого графа `G` стаціонарний розподіл існує, є єдиним і для кожної вершини `v ∈ V` дорівнює:

```
π(v) = d(v) / (2m)
```

### Доведення (Пряма перевірка умови стаціонарності)
Обчислимо `v`-ту компоненту вектора `π · P`:

```
(π · P)_v = ∑_{u ∈ V} π(u) · P_{uv}
          = ∑_{u ~ v} (d(u) / (2m)) · (1 / d(u))      [підстановка π(u) та P_{uv}]
          = ∑_{u ~ v} 1 / (2m)                        [скорочення d(u)]
          = d(v) / (2m)                              [сумування по d(v) сусідах]
          = π(v)
```

Оскільки сума степенів усіх вершин `∑_{v ∈ V} d(v) = 2m`, умова нормування виконується строго: `∑_v π(v) = ∑_v d(v)/(2m) = 1`. Теорему доведено.

### Детальний баланс (Оборотність)
Випадкове блукання на неорієнтованому графі задовольняє рівняння **детального балансу**:

```
π(u) · P_{uv} = (d(u) / (2m)) · (1 / d(u)) = 1 / (2m)
π(v) · P_{vu} = (d(v) / (2m)) · (1 / d(v)) = 1 / (2m)
```

Отже, `π(u) · P_{uv} = π(v) · P_{vu}` для всіх `u, v ∈ V`. Це означає, що марківський ланцюг є оборотним у часі (reversible).

## 2. Спектральний аналіз та симетризація

Матриця `P = D⁻¹ A` загалом не є симетричною (`P_{uv} ≠ P_{vu}`, якщо `d(u) ≠ d(v)`). Проте її можна симетризувати за допомогою подібного перетворення через матрицю `D¹/²`.

Визначимо нормалізовану матрицю суміжності `N`:

```
N = D⁻¹/² · A · D⁻¹/² = D¹/² · P · D⁻¹/²
```

Елементи матриці `N` мають вигляд `N_{uv} = A_{uv} / √(d(u) · d(v))`. Матриця `N` є дійсною та симетричною (`Nᵀ = N`), тому за спектральною теоремою вона має `n` дійсних власних значень та ортонормований базис власних векторів.

Пов'язана з нею нормалізована матриця Лапласа `L_norm` визначається як `L_norm = I - N = D⁻¹/² (D - A) D⁻¹/²`. Власні значення `L_norm` дорівнюють `μ_i = 1 - λ_i`.

Оскільки матриці `P` та `N` є подібними (`P = D⁻¹/² N D¹/²`), вони мають **тотожний спектр власних значень**:

```
1 = λ₁ ≥ λ₂ ≥ λ₃ ≥ ... ≥ λₙ ≥ -1
```

- Найбільше власне значення `λ₁ = 1`. Відповідний правий власний вектор `P` є одиничним вектором `1 = (1, 1, ..., 1)ᵀ`, а лівий власний вектор є вектором стаціонарного розподілу `π`.
- Для нормалізованої матриці `N` власний вектор для `λ₁ = 1` дорівнює `v₁ = D¹/² 1 = (√d(v₁), √d(v₂), ..., √d(vₙ))ᵀ`.

### Відношення Релея для другого власного значення
Друге за величиною власне значення `λ₂` можна виразити через **відношення Релея** (Rayleigh Quotient) для векторів, ортогональних першому власному вектору `v₁`:

```
λ₂ = max_{x ⊥ v₁, x ≠ 0} (xᵀ N x) / (xᵀ x)
```

Розписавши квадратичну форму `xᵀ N x` через різниці компонент векторів на ребрах графа, отримуємо зв'язок із квадратичним відхиленням:

```
1 - λ₂ = min_{f: ∑_v f(v)² d(v) = 1, ∑_v f(v) d(v) = 0} ∑_{(u,v) ∈ E} (f(u) - f(v))²
```

Ця характеристика показує, скільки «енергії» потрібно витратити, щоб створити відхилення від стаціонарного стану `π`.

### Ледаче випадкове блукання (Lazy Walk)
Якщо граф є дводольним, матриця `P` має власне значення `λₙ = -1`, що призводить до періодичних осциляцій і відсутності збіжності. Щоб гарантувати неперіодичність, вводять **ледаче блукання** з матрицею переходів:

```
P_lazy = (I + P) / 2
```

Власні значення `P_lazy` дорівнюють `μ_i = (1 + λ_i) / 2`. Оскільки `-1 ≤ λ_i ≤ 1`, усі власні значення `P_lazy` є строго невід'ємними: `1 = μ₁ > μ₂ ≥ ... ≥ μₙ ≥ 0`.

## 3. Спектральний зазор та час перемішування (Mixing Time)

Визначимо **спектральний зазор** (spectral gap) `γ` як:

```
γ = 1 - λ₂
```

де `λ₂` — друге за величиною власне значення матриці `P` (для ледачого блукання `λ₂ = max_{i ≥ 2} |λ_i|`).

Відстань за повною варіацією (Total Variation Distance) між поточним розподілом `π⁽ᵗ⁾` та стаціонарним розподілом `π` визначається як:

```
d_TV(π⁽ᵗ⁾, π) = (1/2) · ∑_{v ∈ V} |π⁽ᵗ⁾(v) - π(v)|
```

### Теорема (Експоненційна збіжність до стаціонарного стану)
Для ледачого випадкового блукання на зв'язному графі `G` з початковим розподілом `π⁽⁰⁾` норма різниці падає експоненційно зі швидкістю, що визначається спектральним зазором:

```
|| D⁻¹/² (π⁽ᵗ⁾ - π) ||₂ ≤ (1 - γ)ᵗ · || D⁻¹/² (π⁽⁰⁾ - π) ||₂
```

### Доведення (Спектральний розклад)
Розкладемо вектор `x⁽⁰⁾ = D⁻¹/² π⁽⁰⁾` за ортонормованим базисом власних векторів `{v₁, v₂, ..., vₙ}` матриці `N`:

```
x⁽⁰⁾ = ∑_{i=1}ⁿ c_i · v_i
```

Оскільки `v₁ = D¹/² 1 / √(2m)` відповідає `λ₁ = 1`, коефіцієнт `c₁ = ⟨x⁽⁰⁾, v₁⟩ = ∑_u (π⁽⁰⁾(u) / √d(u)) · (√d(u) / √(2m)) = 1 / √(2m)`. Перший додаток `c₁ v₁ = D⁻¹/² π`.

Множення на `Pᵗ` відповідає застосуванню `Nᵗ` до `x⁽⁰⁾`:

```
D⁻¹/² π⁽ᵗ⁾ = Nᵗ · x⁽⁰⁾ = c₁ v₁ + ∑_{i=2}ⁿ c_i · (λ_i)ᵗ · v_i
```

Віднімаючи стаціонарну компоненту `c₁ v₁ = D⁻¹/² π`, отримуємо:

```
D⁻¹/² (π⁽ᵗ⁾ - π) = ∑_{i=2}ⁿ c_i · (λ_i)ᵗ · v_i
```

Беручи евклідову норму `L₂` та використовуючи ортонормованість базису `{v_i}`:

```
|| D⁻¹/² (π⁽ᵗ⁾ - π) ||₂² = ∑_{i=2}ⁿ c_i² · (λ_i)²ᵗ
                         ≤ (λ₂)²ᵗ · ∑_{i=2}ⁿ c_i²
                         = (1 - γ)²ᵗ · || D⁻¹/² (π⁽⁰⁾ - π) ||₂²
```

Вилучаючи квадратний корінь з обох частин, отримуємо шукану оцінку. Теорему доведено.

### Визначення часу перемішування (Mixing Time)
Час перемішування `t_mix(ε)` — це кількість кроків, необхідна для досягнення відстані `d_TV ≤ ε`:

```
t_mix(ε) ≤ (1 / γ) · ln((2m) / ε)
```

Це доводить, що для графів із великим спектральним зазором `γ = Ω(1)` (експандери) час перемішування є логарифмічним від кількості вершин: `t_mix = O(log n)`.

## 4. Нерівність Чигера (Cheeger Inequality)

Кондуктанс (або стала Чигера) графа `G` вимірює наявність «вузьких шийок» (bottlenecks). Для підмножини вершин `S ⊂ V` визначимо її об'єм `vol(S) = ∑_{v ∈ S} d(v)` та межу `∂S = {{u, v} ∈ E : u ∈ S, v ∉ S}`.

Кондуктанс множини `S` та всього графа `G` задається формулами:

```
Ф(S) = |∂S| / vol(S)
Ф(G) = min_{S ⊂ V: 0 < vol(S) ≤ m} Ф(S)
```

### Теорема Чигера для графів (Alon — Milman, Jerrum — Sinclair)
Спектральний зазор `γ = 1 - λ₂` пов'язаний із кондуктансом `Ф(G)` двосторонньою нерівністю:

```
γ / 2 ≤ Ф(G) ≤ √(2γ)
```

- Ліва нерівність `γ ≤ 2 Ф(G)` означає: якщо граф має малу вузьку шийку (`Ф(G) → 0`), спектральний зазор неодмінно малий (`γ → 0`), і випадкове блукання застрягає всередині множини `S`.
- Права нерівність `Ф(G) ≤ √(2γ)` гарантує: якщо спектральний зазор великий (`γ > 0`), граф не містить жодної вузької шийки, і блукання перемішується геометрично швидко.

## 5. Дуальність із електричними колами та ефективний опір

Розглянемо граф `G = (V, E)` як електричну мережу, де кожне ребро `{u, v}` є резистором з опором `R_{uv} = 1` Ом (провідність `C_{uv} = 1`).

Подамо від зовнішнього джерела струм величиною `I` у вершину `u` (джерело) та відберемо струм `I` з вершини `v` (стік). За законами Ома та Кірхгофа у кожній вершині `x ∈ V` виникає електричний потенціал `V(x)`.

Закон Ома для ребра `{x, y}` задає струм `I_{xy} = (V(x) - V(y)) · C_{xy}`. Перше правило Кірхгофа для вершини `x ≠ u, v` має вигляд:

```
∑_{y ~ x} (V(x) - V(y)) = 0
```

Функція потенціалу `V(x)`, що задовольняє цю умову, є **гармонічною функцією** на графі.

### Ефективний опір (Effective Resistance)
Ефективний опір `R_eff(u, v)` між вершинами `u` та `v` визначається як різниця потенціалів `V(u) - V(v)` при проходженні одиничного струму `I = 1` А через мережу:

```
R_eff(u, v) = V(u) - V(v)    при I = 1 A
```

### Часові характеристики: Hit Time та Commute Time
- **Hit Time `H(u, v)`**: очікувана кількість кроків випадкового блукача з початкової вершини `u` до першого досягнення вершини `v`.
- **Commute Time `C(u, v)`**: очікуваний час виходу з `u`, відвідування `v` та повернення назад у `u`:

```
C(u, v) = H(u, v) + H(v, u)
```

### Фундаментальна теорема Тетта — Дойч-Снелла (Tet — Doyle — Snell)
Для будь-якої пари вершин `u, v` у неорієнтованому графі `G` час комутації строго дорівнює добутку подвоєної кількості ребер на ефективний опір:

```
C(u, v) = 2m · R_eff(u, v)
```

### Доведення (Метод електричних потенціалів)
Нехай `H(x, v)` — час досягнення вершини `v` з `x`. Для `x ≠ v` за обчисленням математичного сподівання першого кроку:

```
H(x, v) = 1 + ∑_{y ~ x} (1 / d(x)) · H(y, v)
```

Помноживши на `d(x)` та перенісши доданки:

```
d(x) = d(x) · H(x, v) - ∑_{y ~ x} H(y, v) = ∑_{y ~ x} (H(x, v) - H(y, v))
```

Це рівняння тотожне першому правилу Кірхгофа для вершини `x`, у яку впорскується струм величиною `I(x) = d(x)`.

За принципом суперпозиції електричних полів:
1. Подамо струм `I(x) = d(x)` у кожну вершину `x ∈ V`, а з вершини `v` відберемо сумарний струм `∑_x d(x) = 2m`. Потенціал у вершині `u` відносно `v` дорівнюватиме `V₁(u) = H(u, v)`.
2. Тепер обернемо процес: подамо струм `2m` у вершину `u`, а з кожної вершини `x` відберемо струм `d(x)`. Потенціал у вершині `u` відносно `v` дорівнюватиме `V₂(u) = H(v, u)`.

Додавши два стани суперпозиції, отримуємо:
- У вершину `u` подається струм `d(u) + (2m - d(u)) = 2m` А.
- З вершини `v` відбирається струм `(2m - d(v)) + d(v) = 2m` А.
- У всіх інших вершинах `x ≠ u, v` чистий струм дорівнює `d(x) - d(x) = 0` А.

Сумарна різниця потенціалів дорівнює `V₁(u) + V₂(u) = H(u, v) + H(v, u) = C(u, v)`.
Оскільки за лінійністю закону Ома різниця потенціалів при струмі `2m` А дорівнює `2m · R_eff(u, v)`, маємо:

```
C(u, v) = H(u, v) + H(v, u) = 2m · R_eff(u, v)
```

Теорему доведено.

## 6. Межі часу покриття (Cover Time)

Час покриття `C(G)` — це очікувана кількість кроків, необхідна випадковому блукачу для відвідування **кожної** вершини графа `G` при найгіршому виборі початкової вершини:

```
C(G) = max_{u ∈ V} E [ min { t : ∀ v ∈ V, ∃ s ≤ t, X_s = v | X₀ = u } ]
```

### Верхня межа Чандра — Рагхавана — Разо — Смоленського — Тіварі (1989)
Нехай `T` — довільне остовне (кістякове) дерево графа `G`. Тоді час покриття обмежується сумою часів комутації вздовж ребер деревного остова:

```
C(G) ≤ ∑_{(u,v) ∈ T} C(u, v) = 2m · ∑_{(u,v) ∈ T} R_eff(u, v)
```

Оскільки для будь-якої пари вершин `R_eff(u, v) ≤ R_span` (де `R_span` — максимальний ефективний опір між вершинами), а сума опорів уздовж дерева за законами послідовного з'єднання обмежується `n - 1`, отримуємо універсальну верхню межу:

```
C(G) ≤ 2m · (n - 1) < 2m · n ≤ n³
```

Для будь-якого зв'язного графа з `n` вершинами час покриття задовольняє сувору асимптотичну межу:

```
C(G) = O(n³)
```

Для найгіршого випадку (граф «Леденець» L_n, що складається з кліки `K_{n/2}` та шляху `P_{n/2}`) час покриття становить точно `Θ(n³)`. Для повного графа `K_n` час покриття становить `Θ(n log n)` (за аналогією з задачею про купони), а для простого циклу `C_n` — `Θ(n²)`.
