# 🧮 Виведення чисел Каталана через твірні функції

Числа Каталана `C[n] = 1, 1, 2, 5, 14, 42, 132, …` зустрічаються у сотнях комбінаторних задач: від кількості правильних дужкових послідовностей і побудови бінарних дерев пошуку до розбиттів охоплюючих многокутників на трикутники, маршрутизації шляхів Дика на двовимірній сітці та розставлення дужок у добутках матриць. Пряме комбінаторне виведення явної формули `C[n] = (1 / (n + 1)) · C(2n, n)` є винятково складним: воно вимагає штучних геометричних побудов, таких як принцип відбиття Андре для шляхів, що не перетинають діагональ, або методу кругових перестановок Ране.

Твірні функції пропонують радикально інший, систематичний шлях. Вони перетворюють важку квадратичну рекурентність на звичайне рівняння другого степеня для формального степенного ряду. У цьому розборі ми крок за кроком виведемо явну формулу для `C[n]`, розв'яжемо алгебраїчну неоднозначність вибору знака та застосуємо узагальнену біноміальну теорему Ньютона для дробового показника степеня.

### 1. Комбінаторний зміст і квадратична рекурентність

Зрозуміємо першоджерело рекурентного зв'язку на прикладі бінарних дерев. Нехай `C[n]` позначає кількість різних вкорінених бінарних дерев із `n` внутрішніми вузлами. 

Порожнє дерево відповідає `n = 0`, і такий стан єдиний: `C[0] = 1`. Якщо дерево має `n ≥ 1` вузлів, то один вузол обов'язково є коренем. Решта `n - 1` вузлів розподіляються між лівим та правим піддеревами. Якщо в лівому піддереві розміщено `k` вузлів (де `k` може набувати будь-якого значення від `0` до `n - 1`), то у правому піддереві залишається рівно `n - 1 - k` вузлів.

Оскільки вибір лівого та правого піддерев відбувається незалежно, за правилом множення комбінаторики кількість дерев із фіксованим розміром лівого піддерева `k` дорівнює добутку `C[k] · C[n - 1 - k]`. Сумуючи за всіма можливими варіантами розщеплення `k`, отримуємо фундаментальну квадратичну рекурентність:

```
C[0] = 1
C[n] = C[0]·C[n-1] + C[1]·C[n-2] + C[2]·C[n-3] + … + C[n-1]·C[0]   (для n ≥ 1)
```

Записана через загальний знак суми, ця рекурентність має вигляд:

```
C[n] = ∑ C[k] · C[n - 1 - k]    (сума по k від 0 до n - 1)
```

Ця формула є точним комбінаторним відображенням згортки послідовності самішої з собою. Кожен новий член залежить від усіх попередніх членів одразу, що унеможливлює розв'язання задачі простим методом ітерацій чи лінійної алгебри.

### 2. Складання рівняння для твірної функції

Ввівши звичайну тверну функцію `C(x) = ∑ C[n] · xⁿ = C[0] + C[1]·x + C[2]·x² + …`, ми хочемо виразити всю нескінченну систему рекурентних співвідношень через одну алгебраїчну тотожність відносно `C(x)`.

Розглянемо квадрат ряду `C(x)²`. За правилом Коші множення формальних степеневі рядів, коефіцієнт при `xᵐ` в утвореному ряду є дискретною згорткою:

```
C(x)² = (C[0] + C[1]·x + C[2]·x² + …) · (C[0] + C[1]·x + C[2]·x² + …)
```

Розпишемо коефіцієнти при перших степенях `x`:

```
При x⁰:  C[0]·C[0] = 1·1 = 1                                         [квадрат вільного члена]
При x¹:  C[0]·C[1] + C[1]·C[0]                                       [сума добутків згортки для n = 1]
При x²:  C[0]·C[2] + C[1]·C[1] + C[2]·C[0]                           [сума добутків згортки для n = 2]
При xᵐ:  ∑ C[k] · C[m - k]       (сума по k від 0 до m)              [загальний член дискретної згортки]
```

Порівняємо коефіцієнт при `xᵐ` у ряду `C(x)²` із нашою рекурентною формулою для `C[n]`. Видно, що коефіцієнт при `xᵐ` відповідає виразу для `C[m + 1]`. Тобто сума згортки утворює `C[n]`, але зі зсувом індексу на одиницю!

Щоб компенсувати цей зсув індексів, домножимо квадрат твірної функції `C(x)²` на `x`:

```
x · C(x)² = C[0]·C[0]·x + (C[0]·C[1] + C[1]·C[0])·x² + (C[0]·C[2] + C[1]·C[1] + C[2]·C[0])·x³ + …
```

Тепер коефіцієнт при `xⁿ` у ряду `x · C(x)²` точно дорівнює `C[n]` для всіх `n ≥ 1`. Єдиний член, якого бракує до повної твірної функції `C(x)`, — це вільний член `C[0] = 1` при `x⁰`.

Додавши `C[0] = 1` до обох частин, ми отримуємо точну функціональну тотожність:

```
C(x) = 1 + x · C(x)²
```

Це дивовижне перетворення: нескінченна система нелінійних співвідношень для чисел `C[n]` згорнулася у замкнене квадратне рівняння відносно однієї змінної функції `C(x)`!

### 3. Алгебраїчний розв'язок і критерій вибору знака

Перенесемо всі доданки в один бік і запишемо отримане рівняння у стандартній формі квадратного рівняння відносно невідомої `y = C(x)`:

```
x · C(x)² - C(x) + 1 = 0
```

Коефіцієнтами цього квадратного рівняння є `a = x`, `b = -1`, `c = 1`. Обчислимо дискримінант:

```
D = b² - 4·a·c = (-1)² - 4 · x · 1 = 1 - 4·x
```

За стандартною формулою розв'язання квадратного рівняння отримуємо два формальні корені:

```
C(x) = (1 ± √(1 - 4·x)) / (2·x)
```

Виникає фундаментальне алгебраїчне питання: який саме з двох знаків (`+` чи `-`) відповідає справжній твірній функції комбінаторної послідовності?

З точки зору алгебри формальних рядів, твірна функція `C(x) = C[0] + C[1]·x + …` у точці `x = 0` повинна приймати значення `C(0) = C[0] = 1`. Обчислимо границю обох гілок розв'язку при `x → 0`.

**Дослідження гілки зі знаком «плюс»:**

```
lim [x → 0] (1 + √(1 - 4·x)) / (2·x)
```

При `x → 0` чисельник прямує до `1 + √1 = 2`, тоді як знаменник прямує до `0`. Отримуємо:

```
lim [x → 0] C₊(x) = 2 / 0 = ∞
```

Ця гілка розбігається в точці `0` і не має розкладу в степеневий ряд із вільним членом 1. Вона є стороннім алгебраїчним коренем, що виник унаслідок ділення на `x`.

**Дослідження гілки зі знаком «мінус»:**

```
C(x)
= ((1 - √(1 - 4·x)) · (1 + √(1 - 4·x))) / (2·x · (1 + √(1 - 4·x)))    [домноження чисельника й знаменника на спряжений вираз]
= (1 - (1 - 4·x)) / (2·x · (1 + √(1 - 4·x)))                          [різниця квадратів: (1 - √A)(1 + √A) = 1 - A]
= (4·x) / (2·x · (1 + √(1 - 4·x)))                                    [спрощення чисельника: 1 - 1 + 4x = 4x]
= 2 / (1 + √(1 - 4·x))                                               [скорочення спільного множника 2x]
```

Тепер обчислимо границю при `x → 0`:

```
lim [x → 0] 2 / (1 + √(1 - 4·x)) = 2 / (1 + √1) = 2 / 2 = 1
```

Значення границі точно дорівнює `C[0] = 1`. Отже, єдиним математично й комбінаторно правильним розв'язком є функція:

```
C(x) = (1 - √(1 - 4·x)) / (2·x)
```

### 4. Розклад у ряд за допомогою біноміальної теореми Ньютона

Щоб отримати точну формулу для коефіцієнта `C[n]`, нам потрібно розкласти функцію `√(1 - 4·x) = (1 - 4·x)^(1/2)` у нескінченний степеней ряд. Для цього скористаємося узагальненою біноміальною теоремою Ньютона для довільного дійсного показника `α = 1/2`:

```
(1 + z)^α = ∑ C(α, k) · zᵏ    (сума по k від 0 до ∞)
```

де біноміальний коефіцієнт для дробового аргументу `α` визначено як:

```
C(α, k) = α · (α - 1) · (α - 2) · … · (α - k + 1) / k!
```

Підставимо у цю формулу `z = -4·x` та `α = 1/2`:

```
(1 - 4·x)^(1/2) = ∑ C(1/2, k) · (-4·x)ᵏ = ∑ C(1/2, k) · (-1)ᵏ · 4ᵏ · xᵏ
```

Розписавши окремо перший член для `k = 0`, який дорівнює `1`, детально проаналізуємо коефіцієнти для `k ≥ 1`. Обчислимо добуток у чисельнику біноміального коефіцієнта `C(1/2, k)`:

```
C(1/2, k)
= (1/2) · (1/2 - 1) · (1/2 - 2) · … · (1/2 - k + 1) / k!     [означення біноміального коефіцієнта для α = 1/2]
= (1/2) · (-1/2) · (-3/2) · … · (-(2k - 3)/2) / k!             [обчислення різниць (1 - 2j)/2]
= (-1)^(k - 1) · (1 · 3 · 5 · … · (2k - 3)) / (2ᵏ · k!)       [винесення (-1/2)^(k-1) та (1/2) за дужки]
```

Вираз `1 · 3 · 5 · … · (2k - 3)` є добутком усіх непарних чисел до `2k - 3` (так званим подвійним факторіалом `(2k - 3)!!`). Щоб перетворити його на звичайний факторіал, помножимо чисельник і знаменник на добуток усіх пропущених парних чисел `2 · 4 · 6 · … · (2k - 2)`:

```
1 · 3 · 5 · … · (2k - 3)
= (1 · 2 · 3 · 4 · … · (2k - 2)) / (2 · 4 · 6 · … · (2k - 2))     [доповнення до повного факторіала парними множниками]
= (2k - 2)! / [2^(k - 1) · (1 · 2 · 3 · … · (k - 1))]              [винесення двійки з кожного парного множника]
= (2k - 2)! / [2^(k - 1) · (k - 1)!]                               [згортання добутку у факторіал (k-1)!]
```

Підставимо це перетворення назад у формулу біноміального коефіцієнта `C(1/2, k)`:

```
C(1/2, k)
= (-1)^(k - 1) · (2k - 2)! / [2ᵏ · k! · 2^(k - 1) · (k - 1)!]     [підстановка розкладу непарного добутку]
= (-1)^(k - 1) · (2k - 2)! / [2^(2k - 1) · k! · (k - 1)!]         [групування степенів двійки: 2^k * 2^(k-1) = 2^(2k-1)]
```

Тепер підставимо обчислений коефіцієнт `C(1/2, k)` у загальний член степенного ряду `C(1/2, k) · (-1)ᵏ · 4ᵏ`:

```
C(1/2, k) · (-1)ᵏ · 4ᵏ
= [(-1)^(k - 1) · (2k - 2)! / (2^(2k - 1) · k! · (k - 1)!)] · (-1)ᵏ · 2^(2k)    [підстановка C(1/2, k) та 4^k = 2^(2k)]
= (-1)^(2k - 1) · 2^(2k) / 2^(2k - 1) · (2k - 2)! / (k! · (k - 1)!)             [перегрупування знаків та степенів двійки]
= -1 · 2 · (2k - 2)! / (k! · (k - 1)!)                                          [спрощення: (-1)^(2k-1) = -1, 2^(2k)/2^(2k-1) = 2]
= -2 · (1 / k) · C(2k - 2, k - 1)                                                [виділення біноміального коефіцієнта C(2k-2, k-1)]
```

Таким чином, розклад нескінченного радикала `√(1 - 4·x)` у степеней ряд має вигляд:

```
√(1 - 4·x) = 1 - ∑ [2 / k · C(2k - 2, k - 1)] · xᵏ    (сума по k від 1 до ∞)
```

### 5. Точна формула для чисел Каталана

Тепер підставимо отриманий розклад радикала назад у твірну функцію `C(x) = (1 - √(1 - 4·x)) / (2·x)`:

```
C(x)
= (1 - [1 - ∑ (2 / k · C(2k - 2, k - 1)) · xᵏ]) / (2·x)     [підстановка розкладу radікала]
= (∑ (2 / k · C(2k - 2, k - 1)) · xᵏ) / (2·x)               [разом з 1 - 1 = 0 та взаємним знищенням мінусів]
= ∑ (1 / k · C(2k - 2, k - 1)) · xᵏ⁻¹                       [ділення на 2x: скорочення двійки та зменшення степеня]
```

Зробимо стандартну заміну індексу підсумовування `n = k - 1` (що еквівалентно `k = n + 1`). При цьому нижня межа `k = 1` переходить у `n = 0`, а показник степеня `xᵏ⁻¹` стає `xⁿ`:

```
C(x) = ∑ [1 / (n + 1) · C(2n, n)] · xⁿ    (сума по n від 0 до ∞)
```

Порівнюючи коефіцієнти при однаковій степені `xⁿ` в отриманому ряду та вихідному означенні `C(x) = ∑ C[n] · xⁿ`, ми доходимо до точної явної формули для `n`-го числа Каталана:

```
C[n] = (1 / (n + 1)) · C(2n, n)
```

Розписавши біноміальний коефіцієнт `C(2n, n) = (2n)! / (n! · n!)`, формулу можна записати через факторіали:

```
C[n] = (2n)! / ((n + 1)! · n!)
```

### 6. Перевірка та числовий приклад

Проведемо числову перевірку отриманої формули для перших п'яти членів послідовності.

**Для n = 0 (порожня структура):**
```
C[0] = (1 / (0 + 1)) · C(0, 0) = 1 · 1 = 1
```

**Для n = 1 (один вузол або пара дужок "()"):**
```
C[1] = (1 / 2) · C(2, 1) = (1 / 2) · 2 = 1
```

**Для n = 2 (два вузли, 2 варіанти "()()", "(())"):**
```
C[2] = (1 / 3) · C(4, 2) = (1 / 3) · 6 = 2
```

**Для n = 3 (три вузли, 5 варіантів дерев та дужок):**
```
C[3] = (1 / 4) · C(6, 3) = (1 / 4) · 20 = 5
```

**Для n = 4 (чотири вузли, 14 варіантів):**
```
C[4] = (1 / 5) · C(8, 4) = (1 / 5) · 70 = 14
```

Звіримо обчислення з початковою рекурентністю для `n = 4`:

```
C[4]
= C[0]·C[3] + C[1]·C[2] + C[2]·C[1] + C[3]·C[0]
= 1·5 + 1·2 + 2·1 + 5·1
= 5 + 2 + 2 + 5 = 14
```

Значення повністю збігаються. Алгебра твірних функцій не просто розв'язала нелінійне співвідношення, а зв'язала складну комбінаторику з класичною теорією степеней рядів Ньютона.
