# 🧮 Математична асимптотика й формула Ейлера — Маклорена

Ця вставка містить строге математичне виведення асимптотичного розкладу гармонічних чисел через підсумовування Ейлера — Маклорена, теорію многочленів Бернуллі та точні оцінки залишку.

## 1. Інтегральні межі гармонічного ряду та геометрична оцінка

Основним інструментом аналізу скінченної суми `H[n] = sum_{k=1}^n (1/k)` є зіставлення її з площею під графіком спадної гладкої функції `f(x) = 1/x` на проміжку від `1` до `n + 1`.

Геометричний зміст цього порівняння полягає в тому, що кожне число `1/k` можна представити як площу прямокутника з основою `1` (від `x = k` до `x = k + 1`) та висотою `1/k`. Оскільки функція `f(x) = 1/x` є монотонно спадною на проміжку `[1, ∞)`, для кожного цілого `k ≥ 1` і для всіх `x ∈ [k, k + 1]` виконується сувора нерівність:

```
1/(k + 1) ≤ 1/x ≤ 1/k
```

Проінтегрувавши цю нерівність по `x` від `k` до `k + 1`, ми отримуємо оцінку площі криволінійної трапеції між двома прямокутними сходинками:

```
int_k^{k+1} (1/(k+1)) dx ≤ int_k^{k+1} (1/x) dx ≤ int_k^{k+1} (1/k) dx

1/(k + 1) ≤ int_k^{k+1} (1/x) dx ≤ 1/k
```

Просумуємо ці нерівності по всіх `k` від `1` до `n - 1` для лівої частини та від `1` до `n` для правої частини. У результаті такого підсумовування проміжні інтеграли об'єднуються у суцільний інтеграл від `1` до `n`:

```
sum_{k=1}^{n-1} int_k^{k+1} (1/x) dx ≤ sum_{k=1}^{n-1} (1/k)

int_1^n (1/x) dx ≤ H[n] - 1/n
```

Звідси отримуємо фундаментальну подвійну інтегральну оцінку для `H[n]`:

```
int_1^{n+1} (1/x) dx < H[n] < 1 + int_1^n (1/x) dx

ln(n + 1) < H[n] < 1 + ln(n)
```

Ці нерівності безпосередньо доводять два критично важливих асимптотичних факти:
1. Асимптотичний порядок зростання `H[n]` є точно логарифмічним і дорівнює `Θ(ln n)`.
2. Різниця `H[n] - ln n` утворює строго обмежену послідовність, чиї значення лежать у вузькому інтервалі між `0` та `1`.

## 2. Існування та математичні властивості сталої Ейлера — Маскероні

Дослідимо більш детально послідовність різниць `d[n] = H[n] - ln n`. Наша мета — довести, що ця послідовність монотонно спадає та обмежена знизу, з чого за теоремою Вейєрштрасса випливає існування скінченної границі.

Розглянемо різницю двох послідовних членів `d[n] - d[n+1]`:

```
d[n] - d[n+1]
= (H[n] - ln n) - (H[n+1] - ln(n + 1))    [підстановка означення d[n]]
= ln(n + 1) - ln n - 1/(n + 1)            [скорочення однакових доданків H[n]]
= int_n^{n+1} (1/x) dx - 1/(n + 1)         [представлення різниці логарифмів як інтеграла]
```

Оскільки на відрізку `[n, n + 1]` значення функції `1/x` є строго більшими за значення на правому кінці `1/(n + 1)` для всіх внутрішніх точок `x < n + 1`, площа під кривою `int_n^{n+1} (1/x) dx` є строго більшою за площу прямокутника `1/(n + 1)`. Отже, маємо:

```
d[n] - d[n+1] > 0   ⇒   d[n] > d[n+1]
```

Цим викладом доведено, що послідовність `d[n]` строго монотонно спадає зі зростанням `n`. Крім того, з нижньої інтегральної оцінки `H[n] > ln(n + 1) > ln n` випливає, що `d[n] > 0` для всіх фіксованих `n`.

За теоремою про граничний перехід для монотонної й обмеженої послідовності, існує скінченна границя:

```
lim_{n → ∞} (H[n] - ln n) = γ
```

Число `γ ≈ 0.57721566490153286060...` називають сталою Ейлера — Маскероні.

Завдяки цьому ми отримуємо перше асимптотичне наближення гармонічного числа з похибкою порядку `O(1/n)`:

```
H[n] = ln n + γ + O(1/n)
```

## 3. Многочлени Бернуллі та формула інтегрування частинами

Для отримання точного виведення формули підсумовування Ейлера — Маклорена розглянемо періодичні функціональні поправки на основі **многочленів Бернуллі** `B_k(x)`.

Многочлени Бернуллі визначаються через генеричну функцію:

```
(t · e^{x·t}) / (e^t - 1) = sum_{k=0}^∞ B_k(x) · (t^k / k!)
```

Перші кілька многочленів Бернуллі мають вигляд:
- `B_0(x) = 1`
- `B_1(x) = x - 1/2`
- `B_2(x) = x² - x + 1/6`
- `B_3(x) = x³ - (3/2)x² + (1/2)x`
- `B_4(x) = x⁴ - 2x³ + x² - 1/30`

Числа Бернуллі `B_k` є значеннями многочленів у точці `x = 0`: `B_k = B_k(0)`.
Важливою властивістю многочленів Бернуллі є їхнє диференціювання:

```
d/dx B_k(x) = k · B_{k-1}(x)
```

Розглянемо періодизований многочлен першого порядку `P_1(x) = B_1(x - ⌊x⌋) = x - ⌊x⌋ - 1/2` для дробової частини числа `x`.

Застосуємо інтегрування частинами до інтеграла від похідної `f'(x)` на відрізку `[k, k + 1]`:

```
int_k^{k+1} (x - k - 1/2) f'(x) dx
= [(x - k - 1/2) f(x)]_k^{k+1} - int_k^{k+1} f(x) dx
= (1/2) f(k + 1) - (-1/2) f(k) - int_k^{k+1} f(x) dx
= (f(k) + f(k + 1)) / 2 - int_k^{k+1} f(x) dx
```

Просумувавши цей вираз по всіх `k` від `1` до `n - 1`, ми отримуємо першу точну формулу Ейлера — Маклорена:

```
sum_{k=1}^n f(k) = int_1^n f(x) dx + (f(1) + f(n)) / 2 + int_1^n P_1(x) f'(x) dx
```

Ця формула точно виражає відхилення дискретної суми від інтеграла через інтеграл від першої похідної з періодичною пилкоподібною вагою `P_1(x)`.

## 4. Покрокове алгебраїчне виведення членів розкладу для f(x) = 1/x

Продовжуючи інтегрування частинами для вищих похідних `f''(x), f'''(x), ...` із застосуванням вищих многочленів Бернуллі `P_k(x) = B_k(x - ⌊x⌋)`, отримуємо загальну формулу підсумовування Ейлера — Маклорена:

```
sum_{k=1}^n f(k) = int_1^n f(x) dx + (f(1) + f(n)) / 2 + sum_{m=1}^p (B_{2m} / (2m)!) · (f^{(2m-1)}(n) - f^{(2m-1)}(1)) + R_p
```

Застосуємо цей загальний апарат до нашої конкретної функції `f(x) = 1/x`.
Обчислимо послідовність її похідних непарного порядку:

```
f(x)       = x⁻¹
f'(x)      = -1 · x⁻²
f''(x)     = 2 · x⁻³
f'''(x)    = -6 · x⁻⁴
f^{(4)}(x) = 24 · x⁻⁵
f^{(5)}(x) = -120 · x⁻⁶
```

У загальному вигляді для довільного непарного порядку похідна дорівнює: `f^{(2m-1)}(x) = -(2m - 1)! · x^{-2m}`.

Підставимо отримані формули для похідних у загальну формулу підсумовування.

**Крок 1. Обчислення інтеграла та трапецієподібного члена:**

```
int_1^n (1/x) dx = ln n - ln 1 = ln n

(f(1) + f(n)) / 2 = (1 + 1/n) / 2 = 1/2 + 1/(2n)
```

**Крок 2. Обчислення поправок першого порядку (m = 1):**
Для `m = 1` маємо `B_2 = 1/6` та першу похідну `f'(x) = -1/x²`:

```
(B_2 / 2!) · (f'(n) - f'(1))
= (1/12) · (-1/n² - (-1/1²))               [підстановка B_2 = 1/6 та f'(x) = -1/x²]
= -1/(12n²) + 1/12                         [розкриття дужок]
```

**Крок 3. Обчислення поправок другого порядку (m = 2):**
Для `m = 2` маємо `B_4 = -1/30` та третю похідну `f'''(x) = -6/x⁴`:

```
(B_4 / 4!) · (f'''(n) - f'''(1))
= (-1/720) · (-6/n⁴ - (-6/1⁴))              [підстановка B_4 = -1/30 та f'''(x) = -6/x⁴]
= (1/120) · (1/n⁴ - 1)                      [скорочення 6/720 = 1/120]
= 1/(120n⁴) - 1/120                         [розкриття дужок]
```

**Крок 4. Обчислення поправок третього порядку (m = 3):**
Для `m = 3` маємо `B_6 = 1/42` та п'яту похідну `f^{(5)}(x) = -120/x⁶`:

```
(B_6 / 6!) · (f^{(5)}(n) - f^{(5)}(1))
= (1/30240) · (-120/n⁶ + 120)              [підстановка B_6 = 1/42 та f^{(5)}(x) = -120/x⁶]
= -1/(252n⁶) + 1/252                       [скорочення 120/30240 = 1/252]
```

**Крок 5. Акумуляція та групування сталих констант:**

Зберемо всі незалежні від `n` сталі додатки в один нескінченний числовий ряд:

```
C = 1/2 + 1/12 - 1/120 + 1/252 - ...
```

Якщо зіставити цей вираз із точним границею `lim_{n→∞} (H[n] - ln n) = γ`, стає очевидно, що дана нескінченна сума констант у точності дорівнює сталій Ейлера — Маскероні `γ`.

**Крок 6. Формування фінального асимптотичного ряду:**

Об'єднуючи залишені залежні від `n` члени, отримуємо класичний асимптотичний розклад Ейлера:

```
H[n] = ln n + γ + 1/(2n) - 1/(12n²) + 1/(120n⁴) - 1/(252n⁶) + O(1/n⁸)
```

## 5. Розбіжність асимптотичного ряду та оптимальне утримання членів

Отриманий асимптотичний ряд володіє важливою математичною особливістю: він є *асимптотичним*, але *фактично розбіжним* при `m → ∞` для будь-якого зафіксованого значення `n`.

Це пояснюється асимптотичною поведінкою парних чисел Бернуллі при великих `m`. За формулою Ейлера через дзета-функцію:

```
|B_{2m}| = 2 · (2m)! / (2π)^{2m} · ζ(2m) ≈ 2 · (2m)! / (2π)^{2m}
```

Через наявність факторіала `(2m)!` у чисельнику, коефіцієнти при `1/n^{2m}` зростають швидше за будь-який степінь `n^{2m}`. Тому для будь-якого фіксованого `n` при збільшенні кількості доданків `m` члени ряду спочатку зменшуються, досягають мінімуму при `2m ≈ 2π n`, а потім починають нескінченно зростати.

Щоб отримати максимальну точність обчислення, розклад зупиняють начлені з мінімальним модулем. Це називають **правилом оптимального утримання** (англ. *optimal truncation rule*).

Для комп'ютерних обчислень у форматі `double` (64 біти, 53 біти мантиси) мінімальний похибковий доданковий поріг досягається:
- При `n = 10`: достатньо взяти 3 члени (`1/(120n⁴)`), що дає похибку менше `10⁻⁶`.
- При `n = 100`: 3 члени дають похибку `10⁻¹³`.
- При `n ≥ 1000`: 3 члени дають похибку менше `10⁻¹⁵`, що повністю покриває точність системних розрахунків.

## 6. Застосування до узагальнених гармонічних чисел ступеня s

Формула Ейлера — Маклорена аналогічно застосовується до узагальнених гармонічних чисел `H[n, s] = sum_{k=1}^n (1/k^s)` для довільного дійсного степеня `s > 1`.

При підставленні `f(x) = x^{-s}` отримуємо асимптотичне розкладання через дзета-функцію Рімана `ζ(s)`:

```
H[n, s] = ζ(s) - 1/((s - 1)n^{s-1}) + 1/(2n^s) - s/(12n^{s+1}) + O(1/n^{s+3})
```

Ця загальна формула дає можливість обчислювати часткові суми ряду `1/k^s` для будь-яких степенів `s` за `O(1)` операцій, що є критично важливим для аналізу дисперсій та вищих моментів у ймовірнісній аналітиці структур даних.
