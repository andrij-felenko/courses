# 🧮 Математичні формулювання та межі оцінок задачі комівояжера

Математична теорія задачі комівояжера (TSP) спирається на дискретну оптимізацію, опуклий аналіз та теорію поліедрів. Щоб перетворити комбінаторну задачу пошуку найкоротшого замкненого обходу на форму, доступну для математичного аналізу та обчислювальних солверів, її записують як задачу цілочислового лінійного програмування (Integer Linear Programming, ILP). Традиційні формулювання відрізняються кількістю змінних, кількістю обмежень та геометричною якістю їх лінійних релаксацій.

---

## 1. Цілочислові формулювання задачі комівояжера

Нехай `G = (V, E)` — повний орієнтований або неорієнтований граф із множиною вершин `V = {0, 1, ..., n-1}` та вагою ребер `w[i][j] ≥ 0`. Булеві змінні `x[i][j] ∈ {0, 1}` задають рішення: зміна `x[i][j] = 1` вказує, що орієнтоване ребро `(i, j)` входить до складу замкненого гамільтонового циклу, а `x[i][j] = 0` означає відсутність цього ребра у маршруті.

Головне завдання математичної модель полягає в тому, щоб забезпечити виконання двох фундаментальних умов:
1. Кожна вершина повинна мати точно один вхід і один вихід (умова ступеня).
2. Маршрут не повинен розпадатися на кілька ізольованих замкнених підциклів (субтурів).

---

### 1.1. Формулювання Міллера-Таккера-Земліна (MTZ)

Формулювання MTZ (Miller-Tucker-Zemlin, 1960) вирішує проблему підмаршрутів шляхом введення додаткових безперервних змінних `u[i] ∈ R` для кожної вершини `i ∈ {1, ..., n-1}`. Змінна `u[i]` за змістом означає порядковий номер відвідування вершини `i` у маршруті, починаючи з базової вершини `0` (для якої приймається `u[0] = 0`).

Цільова функція задає мінімізацію сумарної довжини обраного маршруту:

```
min ∑_{i=0}^{n-1} ∑_{j=0, j≠i}^{n-1} w[i][j] · x[i][j]
```

Основні обмеження входу та виходу гарантують, що з кожної вершини виходить точно одне ребро і в кожну вершину входить точно одне ребро:

```
∑_{j=0, j≠i}^{n-1} x[i][j] = 1,  ∀ i ∈ V    [точно один вихід із вершини i]
∑_{i=0, i≠j}^{n-1} x[i][j] = 1,  ∀ j ∈ V    [точно один вхід у вершину j]
```

Обмеження усунення підмаршрутів (Subtour Elimination Constraints) задаються для всіх пар вершин `i, j ∈ {1, ..., n-1}` при `i ≠ j`:

```
u[i] - u[j] + n · x[i][j] ≤ n - 1    [обмеження MTZ]
```

Проаналізуємо математичну дію обмеження MTZ у двох можливих випадках:

- **Випадок 1: Ребро `(i, j)` ВХОДИТЬ до маршруту (`x[i][j] = 1`).**
  Несумісність спрощується до вигляду:
  `u[i] - u[j] + n · 1 ≤ n - 1`, що після перенесення доданків дає:
  `u[j] ≥ u[i] + 1`.
  Це означає, що порядковий номер наступної відвіданої вершини `j` за формою обов'язково більший за порядковий номер попередньої вершини `i` принаймні на `1`.

- **Випадок 2: Ребро `(i, j)` НЕ ВХОДИТЬ до маршруту (`x[i][j] = 0`).**
  Несумісність набуває вигляду:
  `u[i] - u[j] ≤ n - 1`.
  Оскільки всі порядкові номери лежать у межах від `1` до `n-1`, максимальна можлива різниця `u[i] - u[j]` не перевищує `n - 2`, тому дана умова виконується тривіально і не накладає жодних обмежень на змінні `u`.

Доведемо неможливість утворення ізольованих підциклів у формулюванні MTZ:
Припустимо протилежне: нехай існує ізольований підцикл довжиною `k` вершин, що не містить початкову вершину `0`. Позначимо ці вершини у порядку обходу як `v[1], v[2], ..., v[k], v[1]`. Для кожного з `k` ребер цього підциклу виконується `x[v[m], v[m+1]] = 1`.
Запишемо обмеження MTZ для кожного ребра підциклу:

```
u[v[1]] - u[v[2]] + n ≤ n - 1
u[v[2]] - u[v[3]] + n ≤ n - 1
...
u[v[k]] - u[v[1]] + n ≤ n - 1
```

Додамо всі `k` нерівностей між собою. У лівій частині всі змінні `u[v[m]]` повністю скоротяться через протилежні знаки. Отримаємо:

```
k · n ≤ k · (n - 1)
k · n ≤ k · n - k
k ≤ 0
```

Оскільки довжина підциклу `k ≥ 2`, ми отримали суперечність `k ≤ 0`. Отже, існування ізольованих підциклів є математично неможливим.

Формулювання MTZ вимагає лише `O(n²)` змінних та `O(n²)` обмежень. Це робить його компактним та зручним для безпосереднього введення в універсальні солвери лінійного та цілочислового програмування. Проте головним недоліком формулювання MTZ є слабка лінійна релаксація: заміна умов цілочисловості `x[i][j] ∈ {0, 1}` на безперервний інтервал `x[i][j] ∈ [0, 1]` дає нижню межу цільової функції, яка є дуже далекою від реальної оптимальної довжини маршруту.

### 1.2. Формулювання Данціга-Фалкерсона-Джонсона (DFJ)

Формулювання DFJ (Dantzig-Fulkerson-Johnson, 1954) засноване на геометричному підході до теорії розрізів графа і не використовує додаткових змінних порядкових номерів `u[i]`.

Замість цього для кожної власної підмножини вершин `S ⊂ V` такої, що `2 ≤ |S| ≤ n - 1`, вводиться обмеження усунення підмаршрутів:

```
∑_{i ∈ S} ∑_{j ∈ S, j≠i} x[i][j] ≤ |S| - 1    [підмножина S не може містити цикл]
```

Еквівалентна форма запису за допомогою поняття **розрізу графа** `δ(S)` (множини ребер, які з'єднують вершину з підмножини `S` з вершиною за межами `S`):

```
∑_{i ∈ S} ∑_{j ∉ S} x[i][j] ≥ 1              [з підмножини S має виходити принаймні одне ребро]
```

Математичний зміст обмеження розрізу є винятково прозорим: будь-яка множина міст `S` повинна бути з'єднана з рештою графа принаймні одним вихідним ребром у рамках замкненого обходу.

Головна алгебраїчна та обчислювальна складність формулювання DFJ полягає в кількості обмежень. Кількість можливих власних підмножин `S` дорівнює `2ⁿ - 2`. Для `n = 50` міст це число перевищує `10¹⁵` обмежень, що унеможливлює створення повної системи нерівностей у пам'яті комп'ютера.

Сучасні розв'язувачі (такі як Concorde, CPLEX або Gurobi) долають цю проблему за допомогою алгоритму **гілок і розрізів** (Branch and Cut):
1. Спочатку розв'язують лінійну релаксацію задачі з обмеженнями степенів вершин без обмежень DFJ.
2. Якщо отриманий розв meзок містить ізольовані підцикли, за допомогою алгоритму пошуку мінімального розрізу (наприклад, алгоритму Стоера-Вагнера або алгоритму Фorda-Фалкерсона за час `O(V³)`) знаходять підмножину `S`, для якої обмеження порушено.
3. Знайдену нерівність DFJ (так звану «січну площину») динамічно додають до моделі й повторюють лінійне програмування.

Лінійна релаксація формулювання DFJ дає надзвичайно точну нижню межу (так звану релаксацію Хелда-Карпа), зазор цілісності (integrality gap) якої для метричних задач за гіпотезою Хелда-Карпа не перевищує `4/3`.

## 2. Нижні межі оцінки довжини оптимального маршруту

Для ефективної роботи точних алгоритмів (метод гілок і меж, алгоритм A*) критично важливо вміти за поліноміальний час обчислювати точні нижні межі (Lower Bounds) оптимальної довжини маршруту `OPT`. Чим більшою є нижня межа, тим більше неефективних гілок дерева пошуку алгоритм може відсікти на ранніх етапах.

---

### 2.1. Нижня межа 1-дерева (1-Tree Lower Bound)

Концепція `1-дерева` (1-tree), запропонована Хелдом та Карпом, базується на релаксації умов гамільтонового циклу через теорію кістякових дерев.

Визначення `1-дерева`:
Оберемо довільну виділену вершину `v ∈ V` (наприклад, вершину `0`). `1-деревом` називається граф, що складається з:
1. Мінімального кістякового дерева (MST) на множині вершин `V \ {v}`.
2. Двох найкоротших ребер, що з'єднують виділену вершину `v` з вершинами підграфа `V \ {v}`.

Строге математичне доведення нижньої межі `1-дерева`:

```
1. Нехай C* — оптимальний гамільтонів цикл у графі G з вагою OPT.
2. Розглянемо структуру циклу C*: кожна вершина має степінь 2. З виділеної вершини v виходить точно 2 ребра.
3. Вилучимо з циклу C* вершину v та два ребра, які з нею сполучені.
   Множина вершин V \ {v} залишається зв'язаним шляхом, який проходить через всі n-1 вершин, тобто є кістяковим деревом для підграфа V \ {v}.
4. За визначенням, вага мінімального кістякового дерева MST(V \ {v}) не перевищує вагу будь-якого іншого кістякового дерева на V \ {v}, зокрема й вилученого шляху:
   weight(MST(V \ {v})) ≤ OPT - w(e1_cycle) - w(e2_cycle).
5. Сума двох найкоротших ребер min_edge1(v) + min_edge2(v), що виходять з v, за визначенням не перевищує вагу двох ребер циклу w(e1_cycle) + w(e2_cycle).
6. Додавши нерівності, отримуємо:
   weight(1-Tree_min) = weight(MST(V \ {v})) + min_edge1(v) + min_edge2(v)
                     ≤ OPT.
```

Вага мінімального `1-дерева` обчислюється за поліноміальний час `O(E log V)` за допомогою алгоритму Прима або Краскала.

Якщо кожна вершина у збудованому мінімальному `1-дереві` має степінь точно `2`, це `1-дерево` є гамільтоновим циклом і, отже, є точним оптимальним розв meзком TSP. Якщо ж деякі вершини мають степінь `1` або більше `2`, Хелд і Карп розробили метод ітеративного оновлення ваг вершин (Held-Karp Volume Algorithm / Subgradient Optimization), який піднімає нижню межу до значення лінійної релаксації DFJ.

## 3. Математичний аналіз алгоритму Крістофідеса-Сердюкова

Алгоритм Крістофідеса-Сердюкова є еталоном апроксимаційного аналізу в комбінаторній оптимізації. Розглянемо детальний математичний розбір доведення коефіцієнта апроксимації `1.5`.

Теорема: *Для будь-якого екземпляра метричної TSP алгоритм Крістофідеса-Сердюкова знаходить гамільтонів цикл C за поліноміальний час такий, що `w(C) ≤ 1.5 · OPT`.*

Кроки математичного доведення:

### Крок 3.1: Оцінка ваги мінімального кістякового дерева `T`

Розглянемо оптимальний гамільтонів цикл `C*` з вагою `OPT`. Вилучення одного довільного ребра з `C*` перетворює його на лінійний кістяковий шлях, який є окремим випадком кістякового дерева. Оскільки `T` є МІНІМАЛЬНИМ кістяковим деревом на всьому графі `G`, його вага не може перевищувати вагу цього шляху:

```
weight(T) ≤ OPT    [Лема 1]
```

### Крок 3.2: Оцінка ваги мінімального досконалого паросполучення `M`

Позначимо через `O ⊆ V` множину вершин, що мають непарний степінь у дереві `T`. За лемою про рукостискання (сума степенів усіх вершин графа є парною і дорівнює `2|E|`), кількість вершин з непарним степенем `|O|` обов'язково є **парним числом**.

Розглянемо оптимальний цикл `C*` та виконаємо його скорочення (Shortcutting) тільки на вершинах множини `O`. Завдяки нерівності трикутника, довжина утвореного циклу `C*_O` на вершинах `O` не перевищує довжину вихідного циклу `C*`:

```
weight(C*_O) ≤ weight(C*) = OPT
```

Оскільки `|O|` є парним числом, цикл `C*_O` складається з парної кількості ребер. Ми можемо розбити ребра циклу `C*_O` на два альтернативні незалежні досконалі паросполучення `M1` та `M2` на множині вершин `O`.

Оскільки `M1` та `M2` не мають спільних ребер і утворюють у сумі цикл `C*_O`, маємо:

```
weight(M1) + weight(M2) = weight(C*_O) ≤ OPT
```

Оскільки мінімальне за вагою досконале паросполучення `M` на вершинах `O` за визначенням має вагу, не більшу за вагу будь-якого іншого паросполучення на `O`, отримуємо:

```
weight(M) ≤ min(weight(M1), weight(M2))
```

З того, що сума двох додатних чисел `weight(M1) + weight(M2) ≤ OPT`, їхній мінімум не може перевищувати половину суми:

```
weight(M) ≤ 0.5 · OPT    [Лема 2]
```

### Крок 3.3: Підсумовування та скорочення вершин

Об'єднаємо ребра дерева `T` та паросполучення `M` у мультиграф `H = T ∪ M`.
Сумарна вага мультиграфа `H`:

```
weight(H) = weight(T) + weight(M)
         ≤ OPT + 0.5 · OPT
         = 1.5 · OPT
```

У графі `H` степінь кожної вершини `v ∈ V` дорівнює `deg_T(v) + deg_M(v)`:
- Якщо вершина `v` мала ПАРНИЙ степінь у `T`, то `v ∉ O`, тому `deg_M(v) = 0`, і степінь у `H` залишається парним.
- Якщо вершина `v` мала НЕПАРНИЙ степінь у `T`, то `v ∈ O`, тому `deg_M(v) = 1`, і сумарний степінь `deg_T(v) + 1` стає парним.

Оскільки у графі `H` кожна вершина має парний степінь, за теоремою Ейлера у графі `H` існує Ейлерів цикл `E_H` тієї самої ваги `weight(H)`.

Побудова гамільтонового циклу `C` шляхом проходження Ейлерового циклу `E_H` та заміни повторних відвіданих вершин прямими переходами (Shortcutting) за нерівністю трикутника задовольняє:

```
weight(C) ≤ weight(E_H) = weight(H) ≤ 1.5 · OPT
```

Теорему доведено.

## 4. Теорема про неможливість поліноміальної апроксимації загальної TSP

Якщо в графі **не виконується** нерівність трикутника, загальну задачу комівояжера неможливо апроксимувати з будь-яким постійним коефіцієнтом `α > 1`, якщо тільки `P ≠ NP`.

Строге математичне доведення методом звідності від задачі Гамільтонового циклу:

```
1. Припустимо протилежне: існує поліноміальний алгоритм A, який для будь-якого графа знаходить TSP-маршрут C такий, що:
   weight(C) ≤ α · OPT,   де α ≥ 1 — довільна константа або поліном від n.

2. Візьмемо довільний неупорядкований граф G = (V, E) з n вершинами (екземпляр NP-повної задачі гамільтонового циклу).

3. Побудуємо за поліноміальний час повний зважений граф K_n = (V, E', w):
   w(u, v) = 1,          якщо (u, v) ∈ E
   w(u, v) = α · n + 2,   якщо (u, v) ∉ E

4. Запустимо апроксимаційний алгоритм A на графі K_n:
   - Якщо граф G має гамільтонів цикл, то OPT = n · 1 = n.
     Тоді алгоритм A поверне маршрут C з вагою:
     weight(C) ≤ α · OPT = α · n.

   - Якщо граф G НЕ має гамільтонового циклу, будь-який гамільтонів цикл у K_n змушений використати принаймні одне ребро з вагою (α · n + 2).
     Тоді вага будь-якого маршруту в K_n становить принаймні:
     weight(C) ≥ (n - 1) · 1 + (α · n + 2) = α · n + n + 1 > α · n.

5. Отже, порівнявши значення weight(C) із порогом α · n, ми можемо точного за поліноміальний час визначити, чи існує у вихідному графі G гамільтонів цикл.
6. Оскільки задача гамільтонового циклу є NP-повною, знаходження такого алгоритму A означає P = NP.
```

Цей результат підкреслює фундаментальну роль нерівності трикутника: саме геометричні властивості метрики перетворюють задачі з абсолютно неапроксимовного класу на задачі з ефективними поліноміальними гарантіями точності.
