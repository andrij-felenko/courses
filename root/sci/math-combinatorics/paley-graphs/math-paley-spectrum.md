# 🧮 Спектральний аналіз графів Пейлі та характерні суми

Спектральні характеристики графів Пейлі, їхні сильно регулярні параметри, зв'язок із матрицями конференційного зв'язку Адамара, група автоморфізмів, пропускна здатність за Ловасом, нерівності перемішування та властивості псевдовипадкового розширення повністю визначаються гармонійним аналізом над скінченними полями Галуа `F_q`, де ортогональний базис власних векторів утворюється адитивними характерами поля, а власні значення матриці суміжності точно обчислюються через квадратичні суми Гауса.

## Структура скінченного поля F_q та дуальні групи характерів

Нехай `q = pᵏ` — степінь непарного простого числа `p`, для якої виконується конгруенція `q ≡ 1 (mod 4)`. Поле Галуа `F_q` містить `q` елементів. Мультиплікативна група поля `F_q* = F_q \ {0}` є циклічною групою порядку `q - 1`.

Для побудови спектральної теорії графа Пейлі `P_q = (V, E)` із множиною вершин `V = F_q` необхідно ввести два взаємно пов'язані типи гомоморфізмів — мультиплікативні та адитивні характери.

### 1. Мультиплікативний квадратичний характер (символ Лежандра)

Мультиплікативний характер поля `F_q` — це гомоморфізм із мультиплікативної групи `F_q*` у коло одиничних комплексних чисел `ℂ*`. Оскільки порядок групи `q - 1` є парним, існує єдиний характер порядку 2, який називається квадратичним характером `χ: F_q → {-1, 0, 1}`. За критерієм Ейлера для довільного елемента `x ∈ F_q*`:

```
χ(x) = x^((q - 1)/2)
```

Характер набуває таких значень:
- `χ(x) = +1`, якщо `x` є квадратом ненульового елемента поля (квадратичний лишок, `x ∈ Q`);
- `χ(x) = -1`, якщо `x` не є квадратом (квадратичний нелишок, `x ∈ N`);
- `χ(0) = 0` за домовленістю для нуля поля.

Оскільки порядок поля задовольняє умову `q ≡ 1 (mod 4)`, показник `(q - 1)/2` є парним числом `2m`. Це призводить до фундаментальної тотожності для елемента `-1`:

```
χ(-1) = (-1)^((q - 1)/2) = (-1)^(2m) = 1
```

Рівність `χ(-1) = 1` означає, що елемент `-1` завжди є квадратичним лишком у `F_q`. Завдяки мультиплікативності характеру `χ(-x) = χ(-1) · χ(x) = χ(x)`, що ґарантує симетричність умови суміжності: різниця `x - y` є квадратом тоді й лише тоді, коли різниця `y - x` є квадратом. Це робить граф `P_q` неорієнтованим.

Кількість квадратичних лишків точно дорівнює кількості квадратичних нелишків:

```
|Q| = |N| = (q - 1) / 2
```

Сума значень нетривіального характеру по всіх елементах поля є нульовою:

```
∑_{x ∈ F_q} χ(x) = 0
```

### 2. Адитивні характери та слід у базове поле

Адитивна група поля `(F_q, +)` є векторним простором розмірності `k` над простим полем `F_p ≅ ℤ_p`. Канонічний слід (trace) елемента `x ∈ F_q` у базове поле `F_p` задається сумою автоморфізмів Фробеніуса:

```
Tr(x) = x + xᵖ + x^(p²) + ... + x^(p^(k-1))
```

Слід є `F_p`-лінійною функцією: для будь-яких `x, y ∈ F_q` та `c ∈ F_p` виконуються рівності `Tr(x + y) = Tr(x) + Tr(y)` та `Tr(c · x) = c · Tr(x)`.

Для кожного фіксованого елемента `a ∈ F_q` адитивний характер `ψ_a: F_q → ℂ` визначається як експоненційний вираз:

```
ψ_a(x) = exp( (2 π i · Tr(a · x)) / p )
```

Адитивні характери задовольняють співвідношення гомоморфізму: `ψ_a(x + y) = ψ_a(x) · ψ_a(y)` та `ψ_a(x) · ψ_b(x) = ψ_{a + b}(x)`. При `a = 0` характер `ψ_0(x) = 1` для всіх `x` є тривіальним.

Простір функцій `F_q → ℂ` наділений стандартним ермітовим скалярним добутком:

```
⟨f, g⟩ = (1 / q) · ∑_{x ∈ F_q} f(x) · g(x)̄
```

Обчислимо скалярний добуток двох довільних адитивних характерів `ψ_a` та `ψ_b`:

```
⟨ψ_a, ψ_b⟩
= (1 / q) · ∑_{x ∈ F_q} ψ_a(x) · ψ_b(x)̄     [за означенням скалярного добутку функцій]
= (1 / q) · ∑_{x ∈ F_q} ψ_a(x) · ψ_{-b}(x)   [комплексне спряження в одиничному колі]
= (1 / q) · ∑_{x ∈ F_q} ψ_{a - b}(x)         [лінійність індексу характеру]
= 1, якщо a = b; інакше 0                    [ортогональність характерів абелевої групи]
```

Отже, множина `{ψ_a | a ∈ F_q}` утворює ортонормований базис розмірності `q` у просторі комплекснозначних функцій на вершинах графа.

## Група автоморфізмів та алгебраїчні симетрії

Граф Пейлі `P_q` має високий рівень симетрії, який формалізується через групу його автоморфізмів `Aut(P_q)`.

Розглянемо напівпрямий добуток афінних перетворень поля `F_q`:
1. **Зсуви (трансляції):** Для будь-якого елемента `b ∈ F_q` перетворення `T_b(x) = x + b` зберігає різницю між вершинами:
   ```
   T_b(x) - T_b(y) = (x + b) - (y + b) = x - y
   ```
   Отже, різниця `T_b(x) - T_b(y)` є квадратом тоді й лише тоді, коли `x - y` є квадратом. Це доводить, що трансляції є автоморфізмами графа, що забезпечує **вершинну транзитивність** (vertex-transitivity): будь-яку вершину можна перевести в будь-яку іншу вершину графа.
2. **Множення на ненульові квадрати:** Для будь-якого елемента `a ∈ Q` перетворення `M_a(x) = a · x` зберігає характер різниці:
   ```
   χ(M_a(x) - M_a(y)) = χ(a · (x - y)) = χ(a) · χ(x - y) = 1 · χ(x - y) = χ(x - y)
   ```
   Оскільки для будь-яких двох суміжних із нулем вершин `s₁, s₂ ∈ Q` існує елемент `a = s₂ · s₁⁻¹ ∈ Q`, такий що `M_a(s₁) = s₂`, граф Пейлі є **реберно транзитивним** (edge-transitive) та дугово транзитивним (arc-transitive).
3. **Автоморфізми Фробеніуса:** Якщо `q = pᵏ`, відображення `σ(x) = xᵖ` зберігає властивість бути квадратом, оскільки `(xᵖ)^((q-1)/2) = (x^((q-1)/2))ᵖ = (±1)ᵖ = ±1`.

Група перетворень `{x ↦ a² · σⁱ(x) + b | a ∈ F_q*, b ∈ F_q, 0 ≤ i < k}` утворює підгрупу групи автоморфізмів графа Пейлі порядку `k · q · (q - 1) / 2`. За теоремою Леонарда Карліца (Leonard Carlitz, 1960), для всіх простих порядків `q = p > 5` повна група автоморфізмів `Aut(P_p)` точно збігається з цією афінною групою.

## Матриці конференційного зв'язку та зв'язок з матрицями Адамара

Квадратичний характер `χ` дозволяє побудувати матрицю Якобсталя `Q` розміру `q × q`, де `Q_{x, y} = χ(x - y)`. Матриця суміжності графа Пейлі `A` та матриця суміжності його доповнення `Ā` пов'язані з `Q` лінійним співвідношенням:
```
Q = A - Ā = 2 · A - (J - I)
```
де `I` — одинична матриця, а `J` — матриця з усіх одиниць.

Оскільки `χ(0) = 0`, діагональ матриці `Q` складається з нулів, а всі позадіагональні елементи дорівнюють `±1`. Матриця конференційного зв'язку Пейлі (conference matrix) `S` порядку `q + 1` будується шляхом обрамлення матриці `Q` одиничним рядком і стовпцем:
```
S = [ 0   1 ... 1 ]
    [ 1           ]
    [ :     Q     ]
    [ 1           ]
```

Оскільки `q ≡ 1 (mod 4)`, матриця `S` є симетричною (`Sᵀ = S`) і задовольняє фундаментальне матричне рівняння ортогональності:
```
S · Sᵀ = S² = q · I_{q + 1}
```

За конструкцією Реймонда Пейлі II типу, з матриці `S` будується симетрична матриця Адамара `H` розміру `2(q + 1) × 2(q + 1)`:
```
H = [ S + I    S - I ]
    [ S - I   -S - I ]
```

Перевіримо умову ортогональності для блочної матриці `H`:
```
H · Hᵀ
= [ (S+I)² + (S-I)²    (S+I)(S-I) - (S-I)(S+I) ]  [множення блочних матриць]
= [ (S² + 2S + I) + (S² - 2S + I)            0 ]  [розкриття квадратів блоків]
= [ 2 S² + 2 I                                0 ]  [скорочення перехресних членів ±2S]
= [ 2(q I + I)                                0 ]  [підстановка тотожності S² = q I]
= 2(q + 1) · I_{2(q+1)}                           [точна матриця Адамара порядку 2(q+1)]
```

Цей алгебраїчний зв'язок пояснює, чому спектральні та комбінаторні властивості графів Пейлі безпосередньо транслюються в оптимальні коди виправлення помилок та ортогональні базиси для цифрової обробки сигналів.

## Діагоналізація матриці суміжності

Матриця суміжності `A` графа Пейлі `P_q` має розмір `q × q`, де рядки та стовпці взаємно однозначно відповідають елементам поля `x, y ∈ F_q`.

За означенням графа Пейлі елементи матриці задаються як:
```
A_{x, y} = 1, якщо (x - y) ∈ Q; інакше 0
```

Оскільки індикатор належності ненульового елемента `s ≠ 0` до множини квадратичних залишків `Q` дорівнює `(1 + χ(s)) / 2`, елемент матриці для `x ≠ y` можна подати через характер:
```
A_{x, y} = (1 + χ(x - y)) / 2
```
На діагоналі графа петель немає, тому `A_{x, x} = 0`.

Розглянемо дію оператора суміжності `A` на вектор `v_a ∈ ℂ^q`, координати якого дорівнюють значенням адитивного характеру `(v_a)_x = ψ_a(x)` для всіх `x ∈ F_q`.

Обчислимо `x`-ту координату результуючого вектора `A · v_a`:

```
[A · v_a]_x
= ∑_{y ∈ F_q} A_{x, y} · ψ_a(y)                 [множення рядка x матриці на вектор]
= ∑_{s ∈ Q} ψ_a(x - s)                          [заміна змінної y = x - s, де s ∈ Q]
= ∑_{s ∈ Q} ψ_a(x) · ψ_a(-s)                    [властивість гомоморфізму характеру]
= ψ_a(x) · ∑_{s ∈ Q} ψ_a(-s)                    [винесення множника ψ_a(x), незалежного від s]
```

Оскільки сума `∑_{s ∈ Q} ψ_a(-s)` є скаляром, який не залежить від координати `x`, вектор `v_a` є власним вектором матриці `A`, а відповідне власне значення `λ_a` дорівнює:

```
λ_a = ∑_{s ∈ Q} ψ_a(-s)
```

Це доводить, що базис адитивних характерів поля Галуа повністю діагоналізує матрицю суміжності графа Пейлі.

## Точне обчислення спектра через суми Гауса

Для обчислення власного значення `λ_a` підставимо аналітичний вираз для індикатора множини `Q` через характер `χ`:

```
λ_a
= ∑_{s ∈ F_q*} ((1 + χ(s)) / 2) · ψ_a(-s)       [аналітичний вираз індикатора Q]
= (1/2) · ∑_{s ≠ 0} ψ_a(-s) + (1/2) · ∑_{s ≠ 0} χ(s) · ψ_a(-s)  [лінійність суми]
```

Проаналізуємо дві складові цієї суми окремо для кожного значення індексу `a ∈ F_q`.

### 1. Головне власне значення (a = 0)

Для нульового характеру `ψ_0(s) = 1` для всіх `s ∈ F_q`:
- перша сума: `∑_{s ≠ 0} 1 = q - 1`;
- друга сума: `∑_{s ≠ 0} χ(s) = 0`, оскільки кількість лишків дорівнює кількості нелишків.

Підставляючи ці значення:
```
λ_0
= (1/2) · (q - 1) + (1/2) · 0                   [підстановка сум при a = 0]
= (q - 1) / 2                                   [степінь регулярності k графа]
```
Власний вектор `v_0 = (1, 1, ..., 1)ᵀ` відповідає регулярному степеню `k = (q - 1)/2` і має кратність 1 за теоремою Перрона — Фробеніуса для зв'язних регулярних графів.

### 2. Нетривіальні власні значення (a ≠ 0)

Коли `a ≠ 0`, характер `ψ_a` є нетривіальним.
Обчислимо першу суму:
```
∑_{s ≠ 0} ψ_a(-s) = (∑_{s ∈ F_q} ψ_a(-s)) - ψ_a(0) = 0 - 1 = -1
```

Друга сума містить добуток характерів і являє собою суму Гауса `G(χ, ψ_a)`:
```
S_a = ∑_{s ≠ 0} χ(s) · ψ_a(-s)
```

Зробимо заміну змінної підсумовування `t = -a · s`. Оскільки `a ≠ 0`, коли `s` пробігає всі елементи `F_q*`, змінна `t` також пробігає всі елементи `F_q*`. Тоді `s = -t / a = -a⁻¹ · t`.

Підставляючи `s` у суму:
```
S_a
= ∑_{t ≠ 0} χ(-a⁻¹ · t) · ψ_1(t)                [заміна змінної t = -a · s]
= χ(-a⁻¹) · ∑_{t ≠ 0} χ(t) · ψ_1(t)             [мультиплікативність характеру χ]
= χ(-1) · χ(a⁻¹) · G(χ, ψ₁)                     [розклад мультиплікативного характеру]
= 1 · χ(a) · G(χ, ψ₁)                           [оскільки χ(-1) = 1 та χ(a⁻¹) = χ(a)]
= χ(a) · G(χ, ψ₁)                               [вираз через базову суму Гауса]
```
де `G(χ, ψ₁) = ∑_{t ∈ F_q*} χ(t) · exp( (2 π i · Tr(t)) / p )` — класична квадратична сума Гауса над полем `F_q`.

Обчислимо модуль квадратичної суми Гауса, перемноживши її зі своїм комплексним спряженням:
```
|G(χ, ψ₁)|²
= G(χ, ψ₁) · G(χ, ψ₁)̄                           [добуток комплексного числа на спряжене]
= (∑_{u ≠ 0} χ(u) · ψ₁(u)) · (∑_{v ≠ 0} χ(v)̄ · ψ₁(-v))  [комплексне спряження характеру]
= ∑_{u ≠ 0} ∑_{v ≠ 0} χ(u / v) · ψ₁(u - v)      [об'єднання сум і мультиплікативність]
```

Зробимо заміну `u = v · w`, де `w` пробігає `F_q*`:
```
|G(χ, ψ₁)|²
= ∑_{w ≠ 0} χ(w) · ∑_{v ≠ 0} ψ₁(v · (w - 1))   [факторизація подвійної суми]
```
Внутрішня сума `∑_{v ≠ 0} ψ₁(v · (w - 1))` дорівнює:
- `q - 1`, якщо `w = 1` (оскільки `ψ₁(0) = 1`);
- `-1`, якщо `w ≠ 1` (сума нетривіального характеру без нуля).

Підставляючи це у вираз:
```
|G(χ, ψ₁)|²
= χ(1) · (q - 1) + ∑_{w ≠ 0, 1} χ(w) · (-1)     [розділення випадку w = 1]
= 1 · (q - 1) - ( (∑_{w ∈ F_q*} χ(w)) - χ(1) )  [доповнення до повної суми характеру]
= (q - 1) - (0 - 1)                             [сума характеру по полю дорівнює 0]
= q - 1 + 1                                     [спрощення арифметики]
= q                                             [точний квадрат норми суми Гауса]
```

Оскільки `q ≡ 1 (mod 4)`, квадратична сума Гауса є суто дійсним числом (бо `χ(-1) = 1` забезпечує збіг суми зі своїм комплексним спряженням), тому:
```
G(χ, ψ₁) = √q
```

Підставляючи значення складових у вираз для `λ_a`:
```
λ_a
= (1/2) · (-1) + (1/2) · χ(a) · √q              [підстановка значень сум у формулу власного значення]
= (-1 + χ(a) · √q) / 2                          [зведення до спільного знаменника]
```

Оскільки `a ∈ F_q*` пробігає рівно `(q - 1)/2` квадратичних залишків (`χ(a) = 1`) та `(q - 1)/2` квадратичних нелишків (`χ(a) = -1`), ми отримуємо повний спектр матриці суміжності `A(P_q)`:

1. **Головне власне значення:** `k = (q - 1)/2` із кратністю `1` (власний вектор `(1, 1, ..., 1)ᵀ`).
2. **Додатне власне значення:** `r = (-1 + √q)/2` із кратністю `(q - 1)/2` (для всіх `a ∈ Q`).
3. **Від'ємне власне значення:** `s = (-1 - √q)/2` із кратністю `(q - 1)/2` (для всіх `a ∈ N`).

## Сильно регулярні параметри та алгебра Бозе — Меснера

Матриця суміжності `A` регулярного графа `G` степеня `k` на `v` вершинах описує сильно регулярний граф `srg(v, k, λ, μ)` тоді й лише тоді, коли вона задовольняє операторне співвідношення:
```
A² = k · I + λ · A + μ · (J - I - A)
```
де `I` — одинична матриця, а `J` — матриця з усіх одиниць.

Перепишемо це рівняння у формі:
```
A² - (λ - μ) · A - (k - μ) · I = μ · J
```

На підпросторі векторів, ортогональних до вектора всіх одиниць `1 = (1, 1, ..., 1)ᵀ`, матриця `J` діє як нуль: `J · v = 0`. Тому будь-яке нетривіальне власне значення `θ` матриці `A` має бути коренем характеристичного многочлена:
```
θ² - (λ - μ) · θ - (k - μ) = 0
```

За теоремою Вієта сума та добуток коренів цього многочлена задовольняють співвідношення:
```
r + s = λ - μ
r · s = -(k - μ)
```

Перевіримо ці співвідношення для знайдених власних значень `r = (-1 + √q)/2` та `s = (-1 - √q)/2`:

Обчислимо суму коренів:
```
r + s
= ((-1 + √q)/2) + ((-1 - √q)/2)                 [підстановка значень r і s]
= (-1 + √q - 1 - √q) / 2                        [зведення до спільного знаменника]
= -2 / 2                                        [скорочення радикалів]
= -1                                            [сума коренів дорівнює -1]
```

Обчислимо добуток коренів:
```
r · s
= ((-1 + √q)/2) · ((-1 - √q)/2)                 [підстановка значень r і s]
= ((-1)² - (√q)²) / 4                           [формула різниці квадратів]
= (1 - q) / 4                                   [обчислення квадратів]
= -(q - 1) / 4                                  [винесення знака мінус]
```

Звідси отримуємо замкнену систему лінійних алгебраїчних рівнянь для параметрів `λ` і `μ`:
```
λ - μ = -1
k - μ = (q - 1) / 4
```

Оскільки `k = (q - 1)/2`:
```
μ
= k - (q - 1)/4                                 [вираження μ з другого рівняння]
= (q - 1)/2 - (q - 1)/4                         [підстановка значення k]
= (q - 1) / 4                                   [кількість спільних сусідів для несуміжних вершин]
```

```
λ
= μ - 1                                         [вираження λ через μ]
= (q - 1)/4 - 1                                 [підстановка значення μ]
= (q - 1 - 4) / 4                               [зведення до спільного знаменника]
= (q - 5) / 4                                   [кількість спільних сусідів для суміжних вершин]
```

Це аналітично доводить, що граф Пейлі `P_q` є сильно регулярним графом із параметрами:
```
srg(q, (q - 1)/2, (q - 5)/4, (q - 1)/4)
```

В алгебрі асоціативних схем Бозе — Меснера (Bose-Mesner algebra) ортогональні проєктори `E_0, E_1, E_2` на три власні підпростори матриці суміжності `A` виражаються як:
```
E_0 = (1 / q) · J
E_1 = ((q - 1)/(2 q)) · I + ((-1 + √q)/(2 q √q)) · A + ((-1 - √q)/(2 q √q)) · (J - I - A)
E_2 = ((q - 1)/(2 q)) · I + ((-1 - √q)/(2 q √q)) · A + ((-1 + √q)/(2 q √q)) · (J - I - A)
```
Ці проєктори задовольняють тотожності `E_i · E_j = δ_{ij} E_i` та `E_0 + E_1 + E_2 = I`, що робить схему відношень графа Пейлі формально самодвоїстою (self-dual association scheme).

## Пряме комбінаторне виведення через суми Якобсталя

Кількість спільних сусідів двох довільних вершин `x` та `y` можна також обчислити безпосередньо в полі `F_q` без переходу до спектра. Нехай `N(x, y)` — кількість вершин `z ∈ F_q \ {x, y}`, які з'єднані одночасно з `x` та `y`.

Вершина `z` суміжна з `x` тоді й лише тоді, коли `z - x ∈ Q`, що еквівалентно умові `(1 + χ(z - x))/2 = 1`. Відповідно:

```
N(x, y) = ∑_{z ≠ x, y} ((1 + χ(z - x)) / 2) · ((1 + χ(z - y)) / 2)
```

Розкриємо дужки під знаком суми:
```
N(x, y)
= (1/4) · ∑_{z ≠ x, y} [ 1 + χ(z - x) + χ(z - y) + χ(z - x) · χ(z - y) ]  [розподільний закон]
= (1/4) · [ ∑_{z ≠ x, y} 1 + ∑_{z ≠ x, y} χ(z - x) + ∑_{z ≠ x, y} χ(z - y) + J(x, y) ]  [розділення на окремі суми]
```
де `J(x, y) = ∑_{z ≠ x, y} χ((z - x)(z - y))` — квадратична сума Якобсталя.

Оцінимо кожну з чотирьох сум:
1. `∑_{z ≠ x, y} 1 = q - 2`, оскільки виключено рівно дві вершини.
2. `∑_{z ≠ x, y} χ(z - x) = (∑_{w ∈ F_q} χ(w)) - χ(0) - χ(y - x) = 0 - 0 - χ(y - x) = -χ(y - x)`.
3. `∑_{z ≠ x, y} χ(z - y) = (∑_{w ∈ F_q} χ(w)) - χ(0) - χ(x - y) = -χ(x - y) = -χ(y - x)` (оскільки `χ(-1) = 1`).
4. Для обчислення суми Якобсталя зробимо заміну `z - y = w`, позначивши `d = y - x ≠ 0`:
   ```
   J(x, y)
   = ∑_{w ≠ 0, d} χ(w · (w + d))                [зсув індексу підсумовування]
   = ∑_{w ≠ 0, d} χ(w²) · χ(1 + d · w⁻¹)        [винесення квадрата w² за дужки]
   = ∑_{w ≠ 0, d} 1 · χ(1 + d · w⁻¹)            [оскільки χ(w²) = 1 для всіх w ≠ 0]
   = ∑_{u ≠ 0, -1} χ(1 + u)                     [заміна змінної u = d · w⁻¹]
   = (∑_{t ∈ F_q} χ(t)) - χ(0) - χ(1)           [заміна t = 1 + u]
   = 0 - 0 - 1                                  [сума характерів по полю дорівнює 0]
   = -1                                         [значення суми Якобсталя]
   ```

Підставляючи всі чотири компоненти:
```
N(x, y)
= (1/4) · [ (q - 2) - χ(y - x) - χ(y - x) - 1 ]  [підстановка обчислених сум]
= (1/4) · [ q - 3 - 2 · χ(y - x) ]               [арифметичне спрощення]
= (q - 3 - 2 · χ(y - x)) / 4                     [загальна формула для спільних сусідів]
```

Аналізуємо два взаємовиключні випадки:
- Якщо вершини `x` та `y` суміжні (`x ~ y`), різниця `y - x ∈ Q`, отже `χ(y - x) = 1`:
  ```
  λ = (q - 3 - 2(1)) / 4 = (q - 5) / 4
  ```
- Якщо вершини `x` та `y` несуміжні (`x ≁ y`), різниця `y - x ∈ N`, отже `χ(y - x) = -1`:
  ```
  μ = (q - 3 - 2(-1)) / 4 = (q - 1) / 4
  ```

Цей результат повністю узгоджується зі спектральним виведенням через власні значення.

## Оцінка Гофмана, тета-функція Ловаса та пропускна здатність Шеннона

Теорема Гофмана про відношення власних значень (Hoffman's ratio bound) встановлює строгу верхню межу для числа незалежності `α(G)` будь-якого `k`-регулярного графа `G` на `v` вершинах через його мінімальне власне значення `s = λ_{min}`:

```
α(G) ≤ (v · (-s)) / (k - s)
```

Для графа Пейлі `P_q`:
- кількість вершин `v = q`;
- степінь графа `k = (q - 1) / 2`;
- найменше власне значення `s = (-1 - √q) / 2`.

Обчислимо знаменник виразу `k - s`:
```
k - s
= ((q - 1) / 2) - ((-1 - √q) / 2)               [підстановка значень k і s]
= (q - 1 + 1 + √q) / 2                          [спрощення чисельника]
= (q + √q) / 2                                  [зведення подібних]
= (√q · (√q + 1)) / 2                           [винесення спільного множника √q]
```

Обчислимо чисельник виразу `v · (-s)`:
```
v · (-s)
= q · ( -(-1 - √q) / 2 )                        [підстановка v = q та значення s]
= q · ((1 + √q) / 2)                            [розкриття мінуса в дужках]
= (q · (√q + 1)) / 2                            [перестановка множників]
```

Знаходимо їхнє відношення:
```
α(P_q)
≤ [ (q · (√q + 1)) / 2 ] / [ (√q · (√q + 1)) / 2 ]  [підстановка чисельника й знаменника]
= q / √q                                            [скорочення однакових дробів]
= √q                                                [точна верхня межа Гофмана]
```

Оскільки граф Пейлі є самодоповнюваним (`P_q ≅ P̄_q`), число кліки `ω(P_q)` тотожно дорівнює числу незалежності:
```
ω(P_q) = α(P_q) ≤ √q
```

У 1979 році Ласло Ловас (László Lovász) ввів напіввизначений інваріант `ϑ(G)` (тета-функція Ловаса), який задовольняє теорему сендвіча:
```
ω(G) ≤ ϑ(Ḡ) ≤ χ(G)
α(G) ≤ ϑ(G) ≤ χ(Ḡ)
```

Для сильно регулярного графа `srg(v, k, λ, μ)` із власними значеннями `k, r, s` тета-функція Ловаса обчислюється точно за формулою:
```
ϑ(G) = (v · (-s)) / (k - s)
```
Для графа Пейлі це дає абсолютне значення:
```
ϑ(P_q) = √q
```

Особливий фундаментальний випадок виникає, коли порядок поля є точним квадратом `q = p²` (наприклад, `q = 9, 25, 49, 81, 121, 169`). Тоді підполе `F_p ⊂ F_{p²}` утворює повний підграф (кліку) у графі `P_{p²}` розміру точно `p = √q`.
Справді, для будь-яких двох елементів `x, y ∈ F_p` їхня різниця `x - y` належить базовому полю `F_p*`. Кожен елемент `F_p*` є квадратом у розширенні `F_{p²}`: для будь-якого `c ∈ F_p*` виконується `c^( (p² - 1)/2 ) = ( c^(p - 1) )^((p + 1)/2) = 1^((p + 1)/2) = 1`, тобто `χ(c) = 1`.

Отже, для `q = p²` число кліки досягає теоретичного максимуму:
```
ω(P_{p²}) = α(P_{p²}) = ϑ(P_{p²}) = p = √q
```
Це дає точне аналітичне значення нуль-похибкової пропускної здатності Шеннона (Shannon zero-error capacity) для графового каналу зв'язку Пейлі `C(P_{p²}) = p`.

Натомість, коли `q = p` є простим числом, число кліки `ω(P_p)` є значно меншим за `√p`. Довгий час найкращою оцінкою була межа Берджесса `ω(P_p) = O(p^(1/4 + ε))`. У 2021 році Брендон Гансон і Гіоргіс Петрідіс (Brandon Hanson, Giorgis Petridis) за допомогою поліноміального методу та розширень Степанова довели строгу межу для простих полів:
```
ω(P_p) ≤ √(p / 2) + 1
```

## Теорема Вейля та аксіома розширення першого порядку

Аксіома розширення першого порядку `A_{s, t}` вимагає, щоб для будь-яких двох неперетинних множин вершин `U = {u₁, ..., uₛ}` та `W = {w₁, ..., w_t}` існувала вершина `z ∈ F_q \ (U ∪ W)`, яка є суміжною з усіма `u_i ∈ U` та несуміжною з усіма `w_j ∈ W`.

Кількість таких вершин-свідків `N(U, W)` виражається точним аналітичним поліномом через характер `χ`:
```
N(U, W) = ∑_{z ∉ U ∪ W} ∏_{i=1}^s ((1 + χ(z - u_i)) / 2) · ∏_{j=1}^t ((1 - χ(z - w_j)) / 2)
```

Розкриваючи добуток, головний член суми утворюється одиницями й дорівнює:
```
(1 / 2^(s + t)) · ∑_{z ∉ U ∪ W} 1 = (q - s - t) / 2^(s + t)
```

Решта доданків являють собою суми характерів від добутків лінійних множників вигляду `∑_{z} χ(f_I(z))`, де `f_I(z) = ∏_{k ∈ I} (z - x_k)` — многочлен степеня `m = |I| ≤ s + t` із простими коренями.

Фундаментальна теорема Андре Вейля (Andre Weil, 1948) про оцінку сум характерів для одновимірних алгебраїчних кривих над скінченними полями стверджує, що якщо многочлен `f(X)` не є повним квадратом у `F_q[X]`, то:
```
| ∑_{x ∈ F_q} χ(f(x)) | ≤ (deg(f) - 1) · √q
```

Застосовуючи нерівність трикутника до всіх `2^(s + t) - 1` нетривіальних сум у розкладі `N(U, W)`:
```
| N(U, W) - (q / 2^(s + t)) | ≤ (1 / 2^(s + t)) · ∑_{m=1}^{s+t} binom(s+t, m) · (m - 1) · √q + (s + t) / 2^(s + t)
```

Підсумовуючи біноміальні коефіцієнти, отримуємо строгу асимптотичну оцінку:
```
| N(U, W) - q · 2^{-(s + t)} | ≤ (1/2) · ( (s + t - 2) · √q + 1 )
```

Умова існування хоча б одного свідка `N(U, W) ≥ 1` гарантовано виконується, коли головний член перевищує максимальну похибку Вейля:
```
q / 2^(s + t) > (1/2) · (s + t) · √q
```
Звідси отримуємо достатню умову порядку поля:
```
q > (s + t)² · 2^(2(s + t))
```

Це доводить, що графи Пейлі детерміновано задовольняють усі аксіоми розширення логіки першого порядку для довільного фіксованого розміру `k = s + t`, будучи універсальними псевдовипадковими структурами.

## Порівняння з розширювачами Рамануджана та випадковими графами

Спектральне відношення графа Пейлі визначає його розширювальні властивості. Друге за модулем власне значення матриці суміжності `λ(P_q) = max(|r|, |s|) = (1 + √q)/2`.

Нормоване власне значення відносно регулярного степеня `k = (q - 1)/2` дорівнює:
```
λ(P_q) / k = ((1 + √q)/2) / ((q - 1)/2) = (1 + √q) / (q - 1) = 1 / (√q - 1)
```

При зростанні порядку поля `q → ∞` це відношення асимптотично спадає як `O(1 / √q) → 0`.

Для порівняння:
1. **Випадковий граф Ердеша — Реньї `G(q, 1/2)`:** має степінь `d ≈ q/2` та друге власне значення `λ₂ = (1 + o(1)) · √q`, що дає асимптотично таке саме спектральне перемішування `O(1 / √q)`.
2. **Розріджені графи Рамануджана (LPS, Маргуліс):** мають фіксований сталий степінь `d = O(1)` і досягають теоретичної межі Алона — Боппани `λ₂ ≤ 2√(d - 1)`.
3. **Графи Пейлі `P_q`:** є **щільними розширювачами** (dense expanders) зі степенем `d = Θ(q)`. Вони мають значно сильніше спектральне стиснення `λ₂ / d = O(1 / √q)` порівняно зі сталими розрідженими графами, що робить їх ідеальними для задач дерандомізації з експоненціальною швидкістю збіжності випадкових блукань.
