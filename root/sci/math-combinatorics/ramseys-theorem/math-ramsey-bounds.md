# 🧮 Математичний апарат числа Рамсея: виведення меж та точні доведення

Ця вставка містить строгі математичні виведення фундаментальних меж для чисел Рамсея, алгебраїчний апарат імовірнісного методу Пола Ердеша, застосування Локальної леми Ловаса, узагальнення на багатокольорові графи й гіперграфи, а також доведення скінченної теореми Рамсея з нескінченної через топологічний аргумент компактності.

## 1. Рекурсивна нерівність та верхня межа Ердеша — Секереша

Нехай `R(r, s)` — число Рамсея для двох кольорів (червоного та синього), тобто мінімальне число вершин `n`, таке що будь-яка розмальовка ребер повного графа `Kₙ` містить червоний кліковий підграф `Kᵣ` або синій кліковий підграф `K⛛`.

### Теорема (Нерівність Ердеша — Секереша)
Для будь-яких цілих чисел `r ≥ 2` та `s ≥ 2` виконується нерівність:

```
R(r, s) ≤ R(r - 1, s) + R(r, s - 1)
```

### Доведення
Розглянемо повний граф `Kₙ` з кількістю вершин:

```
n = R(r - 1, s) + R(r, s - 1)
```

Нехай ребра графа `Kₙ` довільним чином розфарбовані у два кольори: червоний та синій. Виберемо довільну вершину `v ∈ V(Kₙ)`. Сукупність усіх інших `n - 1` вершин розбивається на дві диз'юнктні множини:

- `V_R` — множина вершин, з'єднаних з `v` червоними ребрами;
- `V_B` — множина вершин, з'єднаних з `v` синіми ребрами.

Загальна кількість ребер, що виходять з вершини `v`, дорівнює кількості решти вершин графа:

```
|V_R| + |V_B|
= n - 1            [розбиття множини вершин без v]
= R(r - 1, s) + R(r, s - 1) - 1   [підстановка значення n]
```

За принципом Діріхле (знаменитим принципом шухляд), виконується принаймні одна з двох нерівностей:
1. `|V_R| ≥ R(r - 1, s)`
2. `|V_B| ≥ R(r, s - 1)`

Розглянемо випадок 1: нехай `|V_R| ≥ R(r - 1, s)`. Оскільки підграф, індукований множиною вершин `V_R`, має принаймні `R(r - 1, s)` вершин, за визначенням числа Рамсея він обов'язково містить:
- Або синій підграф `K⛛` — у цьому разі ми вже знайшли шуканий синій граф `K⛛` у вихідному `Kₙ`;
- Або червоний підграф `K_{r-1}`. Якщо ми додамо вершину `v` до вершин цього `K_{r-1}`, оскільки `v` з'єднана з усіма вершинами `V_R` червоними ребрами, ми отримаємо повний червоний підграф `Kᵣ`.

Розглянемо випадок 2: нехай `|V_B| ≥ R(r, s - 1)`. Аналогічно, індукований підграф на множині `V_B` містить:
- Або червоний підграф `Kᵣ` — шуканий червоний граф знайдено;
- Або синій підграф `K_{s-1}`, який разом з вихідною вершиною `v` дає повний синій підграф `K⛛`.

Усі можливі логічні випадки вичерпано, отже `R(r, s) ≤ R(r - 1, s) + R(r, s - 1)`. Доведення повністю завершено.

---

### Наслідок (Біноміальна верхня межа)
Для всіх позитивних цілих чисел `r ≥ 1` та `s ≥ 1` виконується точна оцінка через біноміальний коефіцієнт:

```
R(r, s) ≤ C(r + s - 2, r - 1)
```

де `C(n, k) = n! / (k! · (n - k)!)` позначено кількість комбінацій з `n` по `k`.

### Доведення (Математична індукція за сумою n = r + s)

База індукції: для `r = 1` маємо `R(1, s) = 1` та `C(s - 1, 0) = 1`. Для `s = 1` маємо `R(r, 1) = 1` та `C(r - 1, r - 1) = 1`. Базові умови справджуються для всіх `s` та `r`.

Індукційний крок: припустимо, що твердження є істинним для всіх пар `(r', s')` таких, що `r' + s' < r + s`. За теоремою Ердеша — Секереша та тотожністю Паскаля для додавання біноміальних коефіцієнтів:

```
R(r, s)
≤ R(r - 1, s) + R(r, s - 1)                      [рекурсивна нерівність Ердеша-Секереша]
≤ C(r + s - 3, r - 2) + C(r + s - 3, r - 1)      [за припущенням математичної індукції]
= C(r + s - 2, r - 1)                           [алгебраїчна тотожність Паскаля]
```

Для діагональних чисел Рамсея `R(k, k)` підстановка `r = s = k` дає:

```
R(k, k)
≤ C(2k - 2, k - 1)
= (2k - 2)! / ((k - 1)! · (k - 1)!)
≈ 4ᵏ⁻¹ / √(π · (k - 1))                          [асимптотична формула Стірлінга n! ≈ √(2πn)(n/e)ⁿ]
= O(4ᵏ / √k)
```

Таким чином, класична верхня межа зростає експоненціально з основою 4.

## 2. Нижня імовірнісна межа Пола Ердеша

Для доведення існування розфарбування без монохроматичного підграфа `Kₖ` Пол Ердеш запропонував розглянути імовірнісну модель на випадкових графах.

### Теорема (Нерівність Ердеша 1947)
Якщо для цілих чисел `n` та `k` виконується нерівність:

```
C(n, k) · 2^(1 - C(k, 2)) < 1
```

то число Рамсея задовольняє оцінку `R(k, k) > n`. Звідси асимптотично випливає:

```
R(k, k) > 2^(k / 2) = (√2)ᵏ
```

### Доведення
Розглянемо ймовірнісний простір `Ω` усіх двокольорових розфарбувань ребер повного графа `Kₙ`. Кількість ребер у `Kₙ` дорівнює `M = C(n, 2)`. Кожне ребро розфарбовується у червоний або синій колір незалежно з ймовірністю `p = 1/2`. Загальна кількість рівноймовірних конфігурацій дорівнює `2^M`.

Нехай `S` — довільно вибрана підмножина з `k` вершин графа `Kₙ`. Кількість ребер між вершинами `S` дорівнює `C(k, 2)`.

Ймовірність того, що всі ребра підграфа на множині `S` мають червоний колір, дорівнює:

```
P(S є червоним Kₖ) = (1/2)^C(k, 2) = 2^(-C(k, 2))
```

Аналогічно, ймовірність того, що `S` є синім `Kₖ`, дорівнює `2^(-C(k, 2))`. Оскільки ці дві події є диз'юнктними при `k ≥ 2`, ймовірність того, що підграф на `S` є монохроматичним (червоним або синім), дорівнює сумі ймовірностей:

```
P(S є монохроматичним Kₖ)
= 2 · 2^(-C(k, 2))              [сума ймовірностей для червоного та синього]
= 2^(1 - C(k, 2))               [показникова властивість: 2¹ · 2⁻ˣ = 2¹⁻ˣ]
```

Загальна кількість різних підмножин з `k` вершин у графі з `n` вершин дорівнює `C(n, k)`. Позначимо через `E_S` подію, що підмножина `S` утворює монохроматичний `Kₖ`. За нерівністю Буля (Union Bound) для ймовірності об'єднання скінченного числа подій:

```
P(існує хоч один монохроматичний Kₖ у Kₙ)
= P(⋃_{S} E_S)
≤ ∑_{S} P(E_S)                                  [нерівність Буля Union Bound]
= C(n, k) · 2^(1 - C(k, 2))
```

Якщо виконується умова `C(n, k) · 2^(1 - C(k, 2)) < 1`, то ймовірність того, що випадково вибраний граф **містить** монохроматичний `Kₖ`, є строго меншою за 1. Отже, ймовірність протилежної події — існування розфарбування **без** жодного монохроматичного `Kₖ` — є строго більшою за нуль:

```
P(жоден Kₖ не є монохроматичним) > 0
```

Якщо ймовірність множини сприятливих розфарбувань більша за нуль, у ймовірнісному просторі `Ω` обов'язково існує принаймні один такий граф. Звідси безпосередньо випливає, що `R(k, k) > n`.

Щоб отримати асимптотичний вираз, застосуємо верхню оцінку для біноміального коефіцієнта `C(n, k) ≤ nᵏ / k!`:

```
C(n, k) · 2^(1 - C(k, 2))
≤ (nᵏ / k!) · 2^(1 - k(k-1)/2)
= (nᵏ / k!) · 2^(1 + k/2 - k²/2)
```

Покладемо `n = 2^(k/2)`. Тоді `nᵏ = (2^(k/2))ᵏ = 2^(k²/2)`. Підставляючи `n` у нерівність:

```
(2^(k²/2) / k!) · 2^(1 + k/2 - k²/2)
= (1 / k!) · 2^(1 + k/2)
```

Для будь-якого `k ≥ 3` значення виразу `(1 / k!) · 2^(1 + k/2) < 1`. Отже, при `n = 2^(k/2)` умова теореми справджується, що доводить нерівність `R(k, k) > 2^(k/2)`.

## 3. Застосування Локальної леми Ловаса (Lovász Local Lemma)

Звичайна нерівність Буля (Union Bound) передбачає найгірший випадок, коли події `E_S` можуть перекриватися довільним чином. У 1975 році Ласло Ловас (угор. *Lovász László*) та Пал Ердеш розробили **Локальну лему Ловаса** (LLL), яка дозволяє обходити обмеження Union Bound для залежних подій з обмеженим ступенем залежності.

### Теорема (Симетрична Локальна Лема Ловаса)
Нехай `A₁, A₂, ..., A_m` — випадкові події у ймовірнісному просторі, такі що кожна подія `A_i` взаємно незалежна від сукупності всіх інших подій, крім принаймні `d` подій (де `d` — максимальний ступінь залежності). Якщо існує таке `p ∈ [0, 1)`, що `P(A_i) ≤ p` для всіх `i`, та виконується нерівність:

```
e · p · (d + 1) ≤ 1
```

де `e ≈ 2.71828` — основа натурального логарифма, то ймовірність того, що жодна з подій `A_i` не відбудеться, є строго більшою за нуль:

```
P(⋂_{i=1}^{m} Ā_i) > 0
```

### Застосування до чисел Рамсея R(3, k)
Застосування LLL до позадіагональних чисел Рамсея `R(3, k)` дозволяє отримати кращу нижню межу, ніж стандартний імовірнісний метод. Подія `A_S` означає, що підмножина `S` з 3 вершин утворює червоний трикутник `K₃`, а подія `B_T` означає, що підмножина `T` з `k` вершин утворює синій `K⛛`.

Двома незалежними оцінками подій та застосуванням LLL доводиться, що існує постійна константа `c > 0`, така що:

```
R(3, k) ≥ c · (k / log k)²
```

Цей результат продемонстрував, що Локальна лема Ловаса є потужним інструментом для розрахунку чисел Рамсея у випадках, коли підструктури мають різну асиметрію.

## 4. Багатокольорові графи та гіперграфи

Теорема Рамсея природним чином узагальнюється на випадок `c` кольорів та на `k`-однорідні гіперграфи.

### Багатокольорові числа Рамсея
Для `c` кольорів число `R(q₁, q₂, ..., q_c)` визначається як найменше `n`, таке що кожна розмальовка ребер `Kₙ` у `c` кольорів містить для деякого кольору `i ∈ {1, ..., c}` монохроматичний кліковий підграф `K_{q_i}` відповідного кольору.

Рекурсивна верхня межа для `c` кольорів має вигляд:

```
R(q₁, q₂, ..., q_c)
≤ 2 - c + ∑_{i=1}^{c} R(q₁, ..., q_i - 1, ..., q_c)
```

Зокрема, для трьох кольорів та пошуку трикутників `R(3, 3, 3)` маємо:

```
R(3, 3, 3) ≤ 3 · R(2, 3, 3) - 1 = 3 · 6 - 1 = 17
```

Точне значення `R(3, 3, 3) = 17` було доведено Грінвудом і Глісоном у 1955 році шляхом конструювання єдиного графа без трикутників у трьох кольорах на 16 вершинах (сформованого за допомогою скінченного поля `GF(16)`).

### Гіперграфові числа Рамсея
Нехай `K_n^(k)` — повний `k`-однорідний гіперграф на `n` вершинах, ребрами якого є всі підмножини з `k` вершин. Число `R_k(r, s)` — це мінімальне `n`, таке що будь-яке 2-розфарбування гіперребер `K_n^(k)` містить монохроматичний гіперграф `K_r^(k)` першого кольору або `K_s^(k)` другого кольору.

Для `k = 2` ми отримуємо класичні графові числа Рамсея `R_2(r, s) = R(r, s)`. Для `k ≥ 3` числа зростають вежами експонент (англ. *tower of exponentials*):

```
R₃(r, s) ≤ 2^(2^(c · (r + s)))
```

де висота вежі експонент залежить від розмірності гіперребра `k`.

## 5. Нескінченна теорема Рамсея та аргумент компактності

Нескінченна версія теореми є більш фундаментальною і стверджує, що для будь-якої розмальовки ребер нескінченного повного графа існує нескінченний монохроматичний підграф.

### Теорема (Нескінченна теорема Рамсея)
Нехай `V` — зліченна нескінченна множина, а `[V]²` — множина всіх двоэлементних підмножин `V` (ребер нескінченного повного графа). Для будь-якої розмальовки `c: [V]² → {1, 2}` існує нескінченна підмножина `H ⊆ V`, така що всі ребра `[H]²` мають однаковий колір.

### Аргумент компактності (Виведення скінченної теореми з нескінченної)
Покажемо, що з нескінченної теореми Рамсея безпосередньо випливає існування скінченного числа `R(r, s)`.

Доведення від супротивного. Припустимо, що для деякої пари `(r, s)` скінченне число Рамсея `R(r, s)` не існує. Це означає, що для кожного натурального `n ≥ 1` існує розмальовка `c_n` ребер графа `Kₙ`, яка **не містить** ані червоного `Kᵣ`, ані синього `K⛛`.

Побудуємо нескінченне дерево розмальовок `T`:
1. Корінь дерева `T` відповідає порожній розмальовці.
2. На рівні `n` вершинами дерева є всі розмальовки ребер `Kₙ`, які не містять монохроматичного `Kᵣ` або `K⛛`.
3. Батьком розмальовки `c_n` на рівні `n` є її обмеження `c_{n-1}` на перші `n - 1` вершин.

Оскільки кількість різних розмальовок графа `Kₙ` дорівнює `2^C(n, 2)` (скінченне число), кожен рівень дерева `T` є скінченним. За нашим припущенням, дерево `T` містить нескінченну кількість вершин.

За **лемою Кеніга про дерево** (англ. *Kőnig's Tree Lemma*), будь-яке нескінченне дерево з скінченним степенем кожної вершини містить принаймні один нескінченний шлях від кореня.

Цей нескінченний шлях визначає розмальовку ребер **нескінченного** повного графа `K_∞`. За конструкцією, жодне скінченне обмеження цієї розмальовки на рівні `n` не містить червоного `Kᵣ` чи синього `K⛛`.

Проте за нескінченною теоремою Рамсея граф `K_∞` обов'язково містить нескінченну монохроматичну підмножину `H`. Вибравши `r` вершин з `H` (якщо колір червоний) або `s` вершин з `H` (якщо колір синій), ми отримуємо скінченний монохроматичний `Kᵣ` або `K⛛`. Це суперечить тому, що жодна скінченна підмножина не містить таких підграфів.

Отримане суперечність доводить, що число `R(r, s)` обов'язково існує і є скінченним для будь-яких `r` та `s`.
