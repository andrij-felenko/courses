# Практикум: Будівник фактор-множин на C++17

Розуміння того, як математичні абстракції перетворюються на реальний код, дозволяє глибше осягнути природу відношень еквівалентності та розбиття множин на неперетинні класи. У цьому практичному проєкті ми розглянемо реалізацію алгоритму побудови фактор-множини на базі стандарту C++17. Наш скрипт демонструватиме 5-компонентну структуру, що відображає класичний математичний підхід до класифікації даних.

## П'ятикомпонентна структура алгоритму

Для того, щоб перетворити довільну початкову множину на фактор-множину за певним відношенням еквівалентності, ми маємо чітко розділити логіку на п'ять складових:

1. **Базова множина (Domain).** Це наша вхідна колекція елементів, яку ми збираємось класифікувати. У коді вона найчастіше представлена як вектор або інший стандартний контейнер.
2. **Предикат еквівалентності (Equivalence Relation).** Функція або лямбда-вираз, що приймає два елементи та повертає булеве значення: "істина", якщо елементи еквівалентні, і "хибність" в іншому разі.
3. **Клас еквівалентності (Equivalence Class).** Контейнер, який зберігатиме всі елементи, що пов'язані між собою нашим предикатом.
4. **Фактор-множина (Quotient Set).** Контейнер вищого порядку, що містить у собі сформовані класи еквівалентності. Жоден клас не повинен бути порожнім, і їхній перетин має бути порожнім.
5. **Алгоритм розбиття (Partitioning Engine).** Процедура, яка проходить по всіх елементах базової множини, перевіряє їх через предикат та розподіляє по відповідних класах усередині фактор-множини.

## Реалізація на C++17

Нижче наведено практичний приклад коду, що ілюструє цю 5-компонентну структуру. Ми використовуємо лямбда-вирази та сучасні контейнери зі стандартної бібліотеки.

```cpp
#include <iostream>
#include <vector>
#include <functional>
#include <string>
#include <algorithm>

// 3. Клас еквівалентності: просто вектор елементів
template<typename T>
using EquivalenceClass = std::vector<T>;

// 4. Фактор-множина: вектор класів еквівалентності
template<typename T>
using QuotientSet = std::vector<EquivalenceClass<T>>;

// 5. Алгоритм розбиття
template<typename T>
QuotientSet<T> build_quotient_set(
    const std::vector<T>& domain, // 1. Базова множина
    const std::function<bool(const T&, const T&)>& is_equivalent // 2. Предикат еквівалентності
) {
    QuotientSet<T> quotient;
    
    for (const auto& element : domain) {
        bool placed = false;
        
        // Шукаємо існуючий клас, до якого належить поточний елемент
        for (auto& eq_class : quotient) {
            // Беремо представника класу (завжди перший елемент)
            if (is_equivalent(eq_class.front(), element)) {
                eq_class.push_back(element);
                placed = true;
                break;
            }
        }
        
        // Якщо елемент не підійшов до жодного класу, створюємо новий
        if (!placed) {
            quotient.push_back({element});
        }
    }
    
    return quotient;
}

// Приклад використання
struct Student {
    std::string name;
    int group_number;
};

int main() {
    // 1. Базова множина
    std::vector<Student> students = {
        {"Олексій", 101}, {"Марія", 102}, {"Іван", 101},
        {"Олена", 103}, {"Дмитро", 102}, {"Анна", 101}
    };
    
    // 2. Предикат еквівалентності: два студенти в одній групі
    auto same_group = [](const Student& a, const Student& b) {
        return a.group_number == b.group_number;
    };
    
    // Побудова фактор-множини
    QuotientSet<Student> q_set = build_quotient_set(students, same_group);
    
    // Вивід результатів
    for (size_t i = 0; i < q_set.size(); ++i) {
        std::cout << "Клас " << i + 1 << " (Група " << q_set[i].front().group_number << "):\n";
        for (const auto& student : q_set[i]) {
            std::cout << "  - " << student.name << "\n";
        }
    }
    
    return 0;
}
```

## Розбір коду

Розглянемо детальніше, як працює запропонована реалізація.

Ми починаємо з визначення псевдонімів типів `EquivalenceClass` та `QuotientSet` за допомогою ключового слова `using`. Це не лише покращує читабельність коду, але й явно відображає математичні концепти на структури даних C++. Клас еквівалентності — це просто вектор елементів типу `T`, а фактор-множина — це вектор таких векторів.

Серцем нашого скрипта є шаблона функція `build_quotient_set`. Вона приймає базову множину (вектор елементів) та предикат еквівалентності (обгорнутий у `std::function`). Функція ітерується по кожному елементу базової множини. Для кожного елемента алгоритм перевіряє наявні класи у фактор-множині. Оскільки всі елементи в одному класі є еквівалентними між собою (завдяки транзитивності відношення еквівалентності), нам достатньо порівняти поточний елемент лише з одним "представником" класу. У нашій реалізації таким представником завжди виступає перший елемент вектора (`eq_class.front()`).

Якщо предикат повертає істину, елемент додається до поточного класу, і алгоритм переходить до наступного елемента базової множини. Якщо ж елемент не виявляється еквівалентним представникам жодного з існуючих класів, він утворює новий, власний клас еквівалентності, який додається до загальної фактор-множини.

У функції `main` ми тестуємо наш будівельник на масиві студентів. Наша мета — розбити студентів на класи за номером їхньої групи. Предикат еквівалентності `same_group` визначений як лямбда-вираз, що порівнює поля `group_number`. Результатом роботи програми стане групування студентів, де кожен клас еквівалентності містить лише студентів з однаковим номером групи.

Цей скрипт демонструє, що фактор-множина — це не просто абстрактна математична концепція, а цілком практичний інструмент класифікації, який легко реалізувати засобами сучасної мови програмування. Такий підхід може бути використаний для будь-яких типів даних і будь-яких відношень еквівалентності.

## Оцінка продуктивності та альтернативи

Запропонований алгоритм розбиття працює досить прямолінійно. Для кожного нового елемента він перевіряє наявні класи, що в найгіршому випадку вимагає порівняння з кожним уже створеним класом. Якщо базова множина складається з `N` елементів, а всі елементи виявляються унікальними (утворюючи `N` різних класів), складність алгоритму складе O(N^2). Для невеликих масивів даних така швидкодія є цілком прийнятною, і код залишається максимально прозорим та легким для розуміння.

Однак, якщо ми працюємо з величезними обсягами даних, варто звернути увагу на більш ефективні структури. Наприклад, структура даних "Система неперетинних множин" (Disjoint-Set Data Structure, також відома як Union-Find) дозволяє знаходити класи еквівалентності та об'єднувати їх майже за константний час O(1). Інший варіант — використання хеш-таблиць (наприклад, `std::unordered_map` у C++), де ключем буде виступати хеш від властивості еквівалентності, що також забезпечує швидкість пошуку класу за час, близький до O(1).

Незважаючи на існування більш швидких методів, наша базова 5-компонентна реалізація ідеально підходить для навчальних цілей, оскільки вона буквально перекладає математичне означення фактор-множини та алгоритму розбиття на мову програмування крок за кроком.
