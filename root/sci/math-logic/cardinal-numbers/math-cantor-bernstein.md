# 🧮 Теорема Кантора — Бернштейна — Шредера: конструкція бієкції

Теорема Кантора — Бернштейна — Шредера стверджує один із найважливіших структурних результатів сучасної теорії множин: якщо множину `A` можна ін'єктивно вкласти в множину `B`, а множину `B` можна ін'єктивно вкласти в множину `A`, то між `A` та `B` існує взаємно однозначна відповідність (бієкція).

У термінах потужностей це означає, що відношення нестрогого кардинального порядку `|A| ≤ |B|` має властивість антисиметричності:

```
(|A| ≤ |B|) ∧ (|B| ≤ |A|) ⟹ |A| = |B|
```

Без цієї теореми порівняння нескінченних потужностей було б непевним: ми могли б мати ситуацію, коли дві множини взаємно вкладаються одна в одну без склеювань, але жодної повної взаємно однозначної відповідності між ними побудувати неможливо. Теорема гарантує, що така патологія виключена.

Нижче наведено строгий аналіз двох класичних методів доведення: конструктивного розбиття на ланцюжки предків та алгебраїчного пошуку нерухомої точки за теоремою Тарського — Кнастера, а також два детальні геометричні приклади.

### Чому наївна композиція зазнає поразки

Нехай задано дві довільні множини `A` та `B`, а також дві ін'єкції:

```
f: A → B    [∀ x₁, x₂ ∈ A: f(x₁) = f(x₂) ⟹ x₁ = x₂]
g: B → A    [∀ y₁, y₂ ∈ B: g(y₁) = g(y₂) ⟹ y₁ = y₂]
```

Перший природний порух думки — спробувати застосувати композицію `g ∘ f: A → A` або `f ∘ g: B → B`. Проте відображення `g(f(A))` є лише звуженням множини `A` до деякої її власної підмножини `A' = g(f(A)) ⊆ A`. Хоча функція `g ∘ f` ін'єктивна, вона не покриває залишок `A \ g(f(A))`. Ми маємо бієкцію між `A` та внутрішнім образом `A'`, але це не дає прямої бієкції між `A` та всією множиною `B`.

Справжня складність полягає в тому, що образ `f(A)` може залишати порожні «береги» в `B`, а образ `g(B)` — порожні «береги» в `A`. Завдання полягає в тому, щоб розрізати множини `A` та `B` на такі частини, де відображення `f` та `g⁻¹` ідеально доповнюють одне одного без накладок і прогалин.

### Конструкція через ланцюжки предків

Для довільного елемента `x ∈ A` визначимо його повний родовід прообразів, рухаючись назад настільки далеко, наскільки дозволяють функції `f` та `g`.

Оскільки `f` та `g` ін'єктивні, кожен елемент має **не більше одного** безпосереднього прообразу. Побудуємо ланцюжок:
- Якщо `x ∉ g(B)`, елемент `x` не має предка в `B`. Його родовід зупиняється на першому кроці в `A`.
- Якщо `x ∈ g(B)`, існує єдиний елемент `y₀ = g⁻¹(x) ∈ B`.
- Якщо `y₀ ∉ f(A)`, родовід зупиняється на елементі `y₀` в `B`.
- Якщо `y₀ ∈ f(A)`, існує єдиний елемент `x₁ = f⁻¹(y₀) ∈ A`, і процес продовжується далі.

Відтак для будь-якого елемента `x ∈ A` та будь-якого елемента `y ∈ B` їхній родовід потрапляє рівно в одну з чотирьох взаємно виключних категорій:

1. **Клас `A_A` (ланцюжки з початком в A)**: послідовність предків обривається через скінченну кількість кроків на деякому елементі з множини `A \ g(B)`. Цей елемент «народився» в `A` і потрапив до системи без попередників із `B`.
2. **Клас `A_B` (ланцюжки з початком в B)**: послідовність предків обривається через скінченну кількість кроків на деякому елементі з множини `B \ f(A)`. Цей елемент «народився» в `B` і прийшов до `A` через ланцюг переходів.
3. **Клас `A_∞` (нескінченні ланцюжки)**: послідовність предків ніколи не обривається, простягаючись нескінченно назад углиб чергування `A` та `B`.
4. **Клас `A_O` (замкнені цикли)**: послідовність предків замикається у скінченну петлю (можливо лише у випадку, якщо множини містять циклічні орбіти відображень).

Об'єднаємо нескінченні та циклічні ланцюжки в один загальний клас `A_inf = A_∞ ∪ A_O`. Отримуємо розбиття множини `A` на три попарно неперетинні підмножини:

```
A = A_A ∪ A_B ∪ A_inf    [A_A ∩ A_B = ∅, A_A ∩ A_inf = ∅, A_B ∩ A_inf = ∅]
```

Аналогічно множина `B` розбивається на відповідні три класи:

```
B = B_A ∪ B_B ∪ B_inf    [B_A ∩ B_B = ∅, B_A ∩ B_inf = ∅, B_B ∩ B_inf = ∅]
```

Дослідимо дію функцій `f` та `g` на цих класах:
- Якщо елемент `x ∈ A_A`, то його образ `f(x)` має родовід, що починається на тому самому елементі в `A \ g(B)`, оскільки застосування `f` лише подовжує ланцюг на один крок вперед. Отже, `f` переводить `A_A` у `B_A`. Більше того, кожен елемент `y ∈ B_A` має предка в `A`, тому `f(A_A) = B_A`. Через ін'єктивність `f` це відображення є повною бієкцією `A_A ↔ B_A`.
- Якщо елемент `x ∈ A_inf`, то додавання одного кроку вперед через `f` переводить нескінченний або циклічний родовід у нескінченний або циклічний родовід. Відтак `f(A_inf) = B_inf`, що дає бієкцію `A_inf ↔ B_inf`.
- Якщо елемент `y ∈ B_B`, то його образ `g(y)` належить до `A_B`. Функція `g` переводить `B_B` бієктивно на `A_B`. Отже, обернене відображення `g⁻¹: A_B → B_B` є коректно визначеною повною бієкцією `A_B ↔ B_B`.

Об'єднуючи ці три взаємно однозначні частини, задаємо результуючу функцію `h: A → B`:

```
h(x) = f(x),     якщо x ∈ A_A ∪ A_inf
h(x) = g⁻¹(x),   якщо x ∈ A_B
```

Функція `h` визначена для кожного елемента `A`, є ін'єктивною (бо образи різних класів не перетинаються в `B`) і сюр'єктивною (бо `B_A ∪ B_B ∪ B_inf = B`). Отже, `h: A → B` — шукана бієкція.

### Алгебраїчне доведення через теорему Тарського — Кнастера

Існує інший, витончений підхід, який уникає покрокового аналізу ланцюжків і спирається на теорію ґраток та [теорему Тарського — Кнастера про нерухому точку](root:math-logic/tarski-knaster-theorem).

Розглянемо булеан `P(A)` — множину всіх підмножин `A`, упорядковану відношенням включення `⊆`. Пара `(P(A), ⊆)` є повною ґраткою, де точна верхня межа довільної родини підмножин є їхнім об'єднанням, а точна нижня межа — їхнім перетином.

Визначимо відображення `Φ: P(A) → P(A)` формулою:

```
Φ(X) = A \ g(B \ f(X))
```

Перевіримо монотонність оператора `Φ`. Нехай `X ⊆ Y ⊆ A`:
1. `f(X) ⊆ f(Y)` [прямий образ зберігає включення]
2. `B \ f(Y) ⊆ B \ f(X)` [взяття доповнення обертає порядок включення]
3. `g(B \ f(Y)) ⊆ g(B \ f(X))` [прямий образ через g зберігає включення]
4. `A \ g(B \ f(X)) ⊆ A \ g(B \ f(Y))` [друге доповнення повертає прямий порядок включення]

Отже, з `X ⊆ Y` випливає `Φ(X) ⊆ Φ(Y)`. Оператор `Φ` є монотонним на повній ґратці `(P(A), ⊆)`. За теоремою Тарського — Кнастера множина нерухомих точок оператора `Φ` є непорожньою повною підґраткою, і зокрема існує найбільша нерухома точка:

```
U = ⋃ { X ⊆ A | X ⊆ Φ(X) }
Φ(U) = U
```

Рівність `Φ(U) = U` означає:

```
U = A \ g(B \ f(U))
```

Звідси негайно отримуємо розбиття:
- `A \ U = g(B \ f(U))`
- Оскільки `g` ін'єктивна, звуження `g` на підмножину `B \ f(U)` є бієкцією між `B \ f(U)` та `A \ U`.
- Отже, обернене відображення `g⁻¹` є коректною бієкцією між `A \ U` та `B \ f(U)`.
- Звуження `f` на `U` є бієкцією між `U` та `f(U)`.

Оскільки `A = U ∪ (A \ U)`, а `B = f(U) ∪ (B \ f(U))`, функція:

```
h(x) = f(x),     якщо x ∈ U
h(x) = g⁻¹(x),   якщо x ∈ A \ U
```

є бездоганною бієкцією між `A` та `B`.

### Приклад 1. Відрізок [0, 1] та інтервал (0, 1)

Розглянемо замкнений відрізок `A = [0, 1]` та відкритий інтервал `B = (0, 1)`.

**Крок 1. Задаємо ін'єкції:**
- `f: [0, 1] → (0, 1)`, `f(x) = x/3 + 1/3`. Образ `f(A) = [1/3, 2/3] ⊂ (0, 1)`.
- `g: (0, 1) → [0, 1]`, `g(y) = y`. Образ `g(B) = (0, 1) ⊂ [0, 1]`.

**Крок 2. Знаходимо точки зупинки:**
- `A \ g(B) = [0, 1] \ (0, 1) = {0, 1}` — рівно дві точки.
- `B \ f(A) = (0, 1) \ [1/3, 2/3] = (0, 1/3) ∪ (2/3, 1)`.

**Крок 3. Ланцюжки родоводу для крайових точок:**
Точки `0` та `1` утворюють зліченні послідовності образів під дією `(g ∘ f) = f`:
- Ланцюг точки `0`: `0 → 1/3 → 4/9 → 13/27 → … → (1 - 3⁻ⁿ)/2 → …`
- Ланцюг точки `1`: `1 → 2/3 → 7/9 → 20/27 → … → (1 + 3⁻ⁿ)/2 → …`

Позначимо множину всіх елементів цих двох ланцюжків як `S = {fⁿ(0), fⁿ(1) | n ≥ 0}`. Усі інші точки відрізка `[0, 1]` належать до класу `A_B` або `A_inf`, де родовід не закінчується в `{0, 1}`.

**Крок 4. Підсумкова бієкція:**

```
h(x) = x/3 + 1/3,  якщо x ∈ S
h(x) = x,         якщо x ∈ [0, 1] \ S
```

Функція `h` зсуває лише зліченну підмножину точок `S` углиб інтервалу, залишаючи всі інші точки нерухомими, що встановлює конструктивну бієкцію без жодного наближення.

### Приклад 2. Квадрат і відкритий круг на площині

Розглянемо замкнений квадрат `K = [-1, 1] × [-1, 1]` та відкритий одиничний круг `D = {(x, y) ∈ ℝ² | x² + y² < 1}`.

Побудова прямої бієкції між квадратом і кругом за допомогою неперервних функцій неможлива через топологічні причини (крайові точки та зв'язність). Проте за теоремою Кантора — Бернштейна достатньо вказати дві елементарні геометричні ін'єкції:

1. **Вкладення круга в квадрат `g: D → K`**: тотожне включення `g(x, y) = (x, y)`. Оскільки круг радіуса 1 повністю лежить усередині квадрата зі стороною 2, функція `g` є очевидною ін'єкцією.
2. **Вкладення квадрата в круг `f: K → D`**: масштабування квадрата з коефіцієнтом стиснення `1/3`:
   ```
   f(x, y) = (x/3, y/3)
   ```
   Максимальна відстань від початку координат до точки образу дорівнює `√( (1/3)² + (1/3)² ) = √2 / 3 ≈ 0.471 < 1`. Образ квадрата повністю поміщається всередині відкритого круга `D`.

Оскільки існують ін'єкції `f: K → D` та `g: D → K`, за теоремою Кантора — Бернштейна існує бієкція `h: K → D`. Потужність замкненого квадрата дорівнює потужності відкритого круга: `|K| = |D| = c`.

### Незалежність від аксіоми вибору

Винятково важливо підкреслити логічний статус теореми Кантора — Бернштейна в аксіоматичній системі Цермело — Френкеля (ZF).

Багато фундаментальних тверджень про потужності (наприклад, трихотомія кардиналів: для будь-яких двох множин обов'язково виконується `|A| ≤ |B|` або `|B| ≤ |A|`) **потребують** [аксіоми вибору](root:math-logic/axiom-of-choice) і є еквівалентними їй (теорема Гартогса). Без аксіоми вибору можуть існувати множини з непорівнюваними потужностями.

Натомість теорема Кантора — Бернштейна доводиться в **чистій системі ZF без аксіоми вибору**. Розбиття на ланцюжки предків та оператор Тарського — Кнастера використовують лише явні, конструктивні операції взяття прообразів та об'єднання множин. Якщо дві множини взаємно вкладаються одна в одну, вони мають однакову потужність у будь-якій моделі теорії множин, незалежно від статусу аксіоми вибору.
