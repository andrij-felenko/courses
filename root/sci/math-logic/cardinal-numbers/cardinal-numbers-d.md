# Кардинальні числа (потужність)

<preknowlist>

- [Зліченні та незліченні множини](root:math-logic/countable-sets) — нумерація елементів натуральними числами та вихід за межі зліченності.
- [Діагональний метод Кантора](root:math-logic/cantor-diagonal) — техніка конструювання елемента, відмінного від кожного члена довільного зліченного списку.
- [Порядкові числа (ординали)](root:math-logic/ordinal-numbers) — форма цілком упорядкованих множин та драбина трансфінітних кроків.
- [Принцип повного впорядкування](root:math-logic/well-ordering-principle) — можливість вишикувати будь-яку множину в порядок із найменшим елементом у кожній частині.

</preknowlist>

Уявіть пастуха, який не володіє лічбою і не знає назв чисел, але щовечора мусить перевірити, чи все його стадо повернулося з пасовища до загороди. Пастух кладе біля вузького проходу кошик і, впускаючи кожну вівцю, кидає в нього рівно один камінець. Якщо вранці під час виходу на пасовище кожній тварині дістається рівно один камінець із кошика, і наприкінці ані камінців у кошику, ані овець біля воріт не лишається, пастух твердо знає: стадо ціле, жодна тварина не загубилася.

Для цього висновку не потрібні ані абстрактні поняття чисел, ані процес послідовної лічби: достатньо встановити пряме парне зіставлення між елементами однієї сукупності та елементами іншої. Поки сукупності скінченні, лічба «один, два, три» і парне зіставлення завжди йдуть пліч-о-пліч, приводячи до однакового результату. Проте для нескінченних сукупностей покроковий перелік ніколи не завершується у часі. Єдиним математично бездоганним методом визначити, чи однакові за обсягом дві нескінченні множини, виявляється саме пастухів метод парного зіставлення.

### Порівняння без лічби: принцип бієкції

Нехай задано дві довільні множини `A` та `B`. Функціональне правило `f`, яке кожному елементу `x ∈ A` зіставляє єдиний елемент `f(x) ∈ B`, класифікують за трьома фундаментальними властивостями:

1. **Ін'єкція** (лат. *in-* — «в», *jacere* — «кидати»): відображення, яке різні елементи переводить у різні образи:
   ```
   ∀ x₁, x₂ ∈ A: x₁ ≠ x₂ ⟹ f(x₁) ≠ f(x₂)    [жодна пара не склеюється в один образ]
   ```
2. **Сюр'єкція** (фр. *sur-* від лат. *super* — «над, на», *jacere* — «кидати»): відображення, образ якого повністю накриває множину `B` без залишку:
   ```
   ∀ y ∈ B  ∃ x ∈ A : f(x) = y              [кожен елемент B має хоча б один прообраз]
   ```
3. **Бієкція** (лат. *bi-* — «двічі», *jacere* — «кидати, спрямовувати») або взаємно однозначна відповідність: відображення, яке є одночасно і ін'єктивним, і сюр'єктивним. Кожен елемент `A` отримує рівно одного партнера в `B`, і кожен елемент `B` має рівно одного партнера в `A`.

Якщо між множинами `A` та `B` можна побудувати хоча б одну бієкцію, такі множини називають **рівнопотужними** або **еквіпотентними** (лат. *aequus* — «рівний», *potentia* — «сила, спроможність») і позначають це як `A ~ B`. Спільну характеристику розміру, що є інваріантом відносно бієкцій, називають **кардинальним числом** або **потужністю** множини (лат. *cardinalis* — «головний, стрижневий», від *cardo* — «дверна завіса, вісь»).

Відношення рівнопотужності є повноцінним відношенням еквівалентності:
- воно рефлексивне: `A ~ A` за допомогою тотожного відображення `id(x) = x`;
- воно симетричне: якщо `f: A → B` — бієкція, то обернена функція `f⁻¹: B → A` також є бієкцією (`A ~ B ⟹ B ~ A`);
- воно транзитивне: якщо `f: A → B` та `g: B → C` — бієкції, то їхня композиція `(g ∘ f): A → C` є бієкцією (`A ~ B ∧ B ~ C ⟹ A ~ C`).

Для скінченних множин відношення рівнопотужності повністю збігається з рівністю кількості елементів: будь-яка множина з 5 елементів рівнопотужна будь-якій іншій множині з 5 елементів. Проте під час переходу до нескінченностей виникає фундаментальний феномен: нескінченна множина може бути рівнопотужною своїй власній строгій підмножині.

Розглянемо множину всіх натуральних чисел `ℕ = {0, 1, 2, 3, …}` та множину парних чисел `2ℕ = {0, 2, 4, 6, …}`. Геометрично здається, що парних чисел удвічі менше, ніж усіх натуральних. Проте функція `f(n) = 2n` задає пряму бієкцію:

```
ℕ:   0    1    2    3    4    …    n    …
     ↕    ↕    ↕    ↕    ↕         ↕
2ℕ:  0    2    4    6    8    …   2n    …
```

Жодне натуральне число не лишається без пари, і кожне парне число знаходить свого єдиного партнера. Звідси випливає рівність потужностей: `|ℕ| = |2ℕ|`.

Ріхард Дедекінд у 1888 році використав цей факт для загального означення: **множина називається нескінченною за Дедекіндом**, якщо вона рівнопотужна деякій своїй власній строгій підмножині.

Аналогічно, множина цілих чисел `ℤ = {0, 1, -1, 2, -2, …}` бієктивно зіставляється з `ℕ` за допомогою функції:
```
f(n) = 2n,        якщо n ≥ 0
f(n) = -2n - 1,   якщо n < 0
```

Навіть множина всіх раціональних дробів `ℚ` (усі можливі дроби `p/q`) виявляється рівнопотужною натуральним числам: розгортаючи пари `(p, q)` у двовимірну таблицю та обходячи її змійкою за діагоналями, ми отримуємо послідовну нумерацію кожного дробу без повторень. Усі такі множини мають однаковий розмір і називаються [зліченними множинами](root:math-logic/countable-sets).

Проте чи всі нескінченності є зліченними? [Історія відкриття нескінченностей вищого ґатунку Ґеорґом Кантором, його драматичне листування з Дедекіндом та запеклий опір Леопольда Кронекера](root:math-logic/cardinal-numbers/hist-cantor-cardinals.md) розкриває, як аналіз неперервного відрізка зруйнував багатовікову віру в існування єдиної нескінченності.

### З двох ін'єкцій у бієкцію: теорема Кантора — Бернштейна

Якщо побудувати пряму двосторонню бієкцію між множинами складно, розміри множин порівнюють за допомогою односторонніх ін'єкцій. Кажуть, що потужність множини `A` не перевищує потужність множини `B` (записують `|A| ≤ |B|`), якщо існує ін'єкція `f: A → B`. Це означає, що множину `A` можна повністю вкласти в `B` без склеювання елементів.

Для скінченних чисел нерівності `a ≤ b` та `b ≤ a` автоматично тягнуть за собою рівність `a = b`. Але для нескінченних множин ситуація значно тонша: наявність ін'єкцій `f: A → B` та `g: B → A` означає лише те, що `f(A) ⊆ B` та `g(B) ⊆ A`. Образ `f(A)` може не накривати всю множину `B`, залишаючи в ній порожній залишок `B \ f(A)`, а образ `g(B)` може залишати залишок `A \ g(B)`. Пряма композиція відображень не дає бієкції.

Те, що з двох взаємних ін'єкцій завжди можна скомпонувати точну бієкцію, стверджує фундаментальна **теорема Кантора — Бернштейна — Шредера** (сформульована Кантором, доведена Феліксом Бернштейном у 1897 році та незалежно Ернстом Шредером).

![Побудова взаємно однозначної відповідності за теоремою Кантора-Бернштейна через розбиття на ланцюжки прообразів.](/root/sci/math-logic/cardinal-numbers/img/cantor-bernstein.svg)

*Теорема Кантора — Бернштейна. Кожен елемент відстежується назад за ланцюжком прообразів. Множина розпадається на три класи: ланцюжки з початком в A, ланцюжки з початком в B та нескінченні ланцюжки. Для перших береться пряме f, для других — обернене g⁻¹.*

Конструкція Бернштейна ґрунтується на відстеженні предків кожного елемента:
1. Для довільного `x ∈ A`, якщо він належить образу `g(B)`, існує єдиний прообраз `y₀ = g⁻¹(x) ∈ B`.
2. Якщо `y₀` належить образу `f(A)`, існує єдиний прообраз `x₁ = f⁻¹(y₀) ∈ A`.
3. Продовжуємо розмотувати цей родовід назад, доки це можливо.

Оскільки `f` та `g` ін'єктивні, предки визначаються однозначно. Усі елементи множини `A` розпадаються на три взаємно неперетинні класи:
- `A_A`: ланцюжок предків обривається через скінченну кількість кроків у множині `A \ g(B)` (елемент народився в `A`);
- `A_B`: ланцюжок предків обривається через скінченну кількість кроків у множині `B \ f(A)` (елемент народився в `B`);
- `A_∞`: ланцюжок предків нескінченний назад або зациклюється.

Аналогічно множина `B` розбивається на класи `B_A`, `B_B` та `B_∞`. Пряма функція `f` відображає `A_A` бієктивно на `B_A`, а `A_∞` — на `B_∞`. Обернена функція `g⁻¹` відображає `A_B` бієктивно на `B_B`. Об'єднуючи ці частини, отримуємо підсумкову бієкцію `h: A → B`:

```
h(x) = f(x),     якщо x ∈ A_A ∪ A_∞
h(x) = g⁻¹(x),   якщо x ∈ A_B
```

[Повне доведення теореми через класифікацію ланцюжків предків та еквівалентне алгебраїчне доведення через нерухому точку монотонного оператора за теоремою Тарського — Кнастера](root:math-logic/cardinal-numbers/math-cantor-bernstein.md) показують, чому ця конструкція є повністю конструктивною і не потребує аксіоми вибору.

Завдяки цій теоремі доведення рівнопотужності замкненого відрізка `[0, 1]` та відкритого інтервалу `(0, 1)` стає тривіальним: достатньо вказати ін'єкцію вкладення `(0, 1) ⊆ [0, 1]` та ін'єкцію стиснення `[0, 1] → (0, 1)` вигляду `f(x) = x/2 + 1/4`. Оскільки обидві ін'єкції існують, `|[0, 1]| = |(0, 1)|`.

### Що таке кардинал: від класів еквівалентності до початкових ординалів

Ми встановили, коли дві множини мають однакову потужність. Але **чим є саме кардинальне число** як самостійний математичний об'єкт у теорії множин?

Перша історична спроба (підхід Готлоба Фреґе та Бертрана Рассела) полягала в тому, щоб визначити кардинал множини `A` як клас усіх множин, рівнопотужних `A`. За цим означенням число `2` — це «сукупність усіх двоелементних множин», а зліченна потужність — «сукупність усіх зліченних множин». Проте в строгій аксіоматиці ZFC сукупність усіх зліченних множин є занадто всеосяжною: вона утворює власний клас, а не множину. Оперувати такими класами як звичайними об'єктами неможливо через загрозу парадоксів типу парадоксу Рассела.

Остаточне, бездоганне вирішення проблеми дав Джон фон Нейман у 1920-х роках, спираючись на [порядкові числа (ординали)](root:math-logic/ordinal-numbers).

Нагадаємо, що ординал за фон Нейманом — це транзитивна множина, цілком упорядкована відношенням належності `∈`. Кожен ординал є множиною всіх менших за себе ординалів:
```
0   = ∅
1   = {0}
2   = {0, 1}
…
ω   = {0, 1, 2, 3, …}
ω+1 = {0, 1, 2, …, ω}
ω·2 = {0, 2, 4, …, 1, 3, 5, …}
```

Ординали вимірюють *тип порядку*. Проте різні ординали можуть мати абсолютно однаковий розмір: між ординалами `ω`, `ω+1`, `ω·2`, `ω²`, `ω^ω` існують прямі бієкції — усі вони є зліченними множинами потужності `|ℕ|`.

Фон Нейман запропонував вибрати серед усіх рівнопотужних ординалів **найперший, мінімальний ординал** і вважати його канонічним представником цієї потужності:

> **Кардинальне число (кардинал)** — це такий ординал `κ`, який неможливо бієктивно зіставити з жодним строго меншим за нього ординалом `α < κ`. Такий ординал називають **початковим ординалом** (англ. *initial ordinal*).

Перевіримо цю конструкцію:
- Усі скінченні ординали `0, 1, 2, 3, …` є початковими ординалами, оскільки скінченну множину з `n` елементів неможливо бієктивно відобразити на `m < n`. Тому скінченні кардинали тотожні натуральним числам.
- Ординал `ω` є початковим ординалом: жодне скінченне число `n < ω` не рівнопотужне `ω`. Отже, `ω` — це перший нескінченний кардинал.
- Ординал `ω+1` **не є кардиналом**, бо існує бієкція між `ω+1` та меншим ординалом `ω` (зсув `0 ↦ ω, n+1 ↦ n`).
- Ординали `ω·2`, `ω²`, `ω^ω`, `ε₀` також не є кардиналами, бо всі вони зліченні й бієктивні `ω`.
- Першим ординалом, який неможливо бієктивно зіставити з `ω`, є `ω₁` — множина всіх зліченних ординалів. Це перший незліченний кардинал.

Завдяки [принципу повного впорядкування](root:math-logic/well-ordering-principle), який спирається на [аксіому вибору](root:math-logic/axiom-of-choice), будь-яку множину можна цілком упорядкувати, а отже, зіставити їй ізоморфний ординал. Найменший ординал у цьому класі й стає точним кардинальним числом цієї множини.

### Кардинальна арифметика: додавання, множення, піднесення до степеня

Оскільки кардинали вимірюють потужності множин, арифметичні дії над ними визначаються через стандартні теоретико-множинні операції:

1. **Додавання `κ + λ`**: потужність диз'юнктного (неперетинного) об'єднання:
   ```
   |A| + |B| = |A ⊎ B|    [де A ∩ B = ∅]
   ```
2. **Множення `κ · λ`**: потужність декартового добутку пар:
   ```
   |A| · |B| = |A × B|    [де A × B = {(a, b) | a ∈ A, b ∈ B}]
   ```
3. **Піднесення до степеня `κ^λ`**: потужність множини всіх функцій із `B` в `A`:
   ```
   |A|^|B| = |A^B|        [де A^B = {f: B → A}]
   ```

Для скінченних множин ці правила повністю повторюють шкільну арифметику: `2 + 3 = 5`, `2 · 3 = 6`, `2³ = 8`. Проте для нескінченних кардиналів додавання та множення зазнають дивовижного виродження.

#### Теорема Гессенберґа та поглинання

Для будь-яких нескінченних кардиналів `κ` та `λ` за наявності аксіоми вибору діє фундаментальний закон:

```
κ + λ = max(κ, λ)
κ · λ = max(κ, λ)
```

Це твердження спирається на теорему Ґергарда Гессенберґа (1906), яка доводить, що для будь-якого нескінченного кардинала `κ` виконується рівність `κ · κ = κ`. Пари ординалів `(α, β) ∈ κ × κ` упорядковують за канонічним порядком максимумів `max(α, β)`, що дозволяє без залишку розгорнути квадрат `κ × κ` у лінію довжини `κ`.

Звідси випливає, що звичайне додавання чи множення нескінченних множин ніколи не збільшує потужність:
- Додавання зліченної множини до континууму не змінює континууму: `c + ℵ₀ = c`.
- Множення континууму на зліченну множину: `c · ℵ₀ = c`.
- Кількість точок на площині `ℝ²`, у тривимірному просторі `ℝ³` або в скінченновимірному `ℝⁿ` точно дорівнює кількості точок на відрізку `[0, 1]`: `c · c = c`.

#### Піднесення до степеня та теорема Кантора

Єдиною операцією, яка дозволяє переступити поріг поточної нескінченності й отримати строго більшу множину, є піднесення до степеня.

Розглянемо множину всіх функцій `f: A → {0, 1}`. Кожна така функція є характеристичним вектором деякої підмножини `S ⊆ A` (значення 1 вказує на належність елемента до `S`, а 0 — на відсутність). Відтак множина функцій `{0, 1}^A` природно ізоморфна булеану `P(A)` — множині всіх підмножин `A`:

```
|P(A)| = 2^|A|
```

Чи може булеан множини мати таку саму потужність, як вихідна множина? **Теорема Кантора** дає категоричну негативну відповідь:

```
2^κ > κ    [для будь-якого кардинала κ]
```

Доведення здійснюється від супротивного через діагональний метод. Припустимо, що існує сюр'єкція `f: A → P(A)`, яка кожному елементу `x ∈ A` зіставляє деяку підмножину `f(x) ⊆ A`. Побудуємо діагональну підмножину `D`:

```
D = {x ∈ A | x ∉ f(x)}    [елементи, які не належать своїм образам]
```

Оскільки `D ⊆ A`, а функція `f` сюр'єктивна, в `A` повинен існувати елемент `d ∈ A` такий, що `f(d) = D`. Перевіримо належність `d ∈ D`:
- Якщо `d ∈ D`, то за означенням множини `D` маємо `d ∉ f(d) = D` — суперечність.
- Якщо `d ∉ D`, то `d ∉ f(d)`, отже за означенням `D` маємо `d ∈ D` — знову суперечність.

Отримане протиріччя доводить, що жодної сюр'єкції (а тим паче бієкції) між множиною та її булеаном існувати не може. Отже, потужність множини підмножин завжди строго перевищує потужність самої множини:

```
|ℕ| < |P(ℕ)| < |P(P(ℕ))| < |P(P(P(ℕ)))| < …
```

Цей ланцюг не має верхньої межі: у математиці не існує «множини всіх множин» і не існує абсолютного максимального кардинала.

### Сходи нескінченностей: Алеф-ієрархія та Бет-ієрархія

Оскільки кардинальні числа утворюють цілком упорядкований ланцюг, їх класифікують за допомогою двох фундаментальних ієрархій.

![Ієрархії Алеф і Бет: початкові ординали проти послідовного взяття булеана.](/root/sci/math-logic/cardinal-numbers/img/cardinal-hierarchies.svg)

*Сходи нескінченностей. Алеф-ієрархія лічить усі можливі початкові ординали крок за кроком. Бет-ієрархія будується через взяття степенів 2^κ. Гіпотеза континууму запитує, чи збігаються перший алеф ℵ₁ та перший бет ℶ₁.*

#### 1. Алеф-ієрархія (ℵ)
Літерою «алеф» (івр. א — перша літера єврейської абетки) позначають повний перелік усіх нескінченних кардиналів у порядку їхнього природного зростання:
- `ℵ₀` (алеф-нуль) — найменший трансфінітний кардинал, потужність зліченних множин `ℕ, ℤ, ℚ`.
- `ℵ₁` (алеф-один) — найменший незліченний кардинал (початковий ординал `ω₁`, що містить у собі всі зліченні ординали).
- `ℵ₂` (алеф-два) — найменший кардинал, строго більший за `ℵ₁`.
- Для будь-якого ординала `α`: `ℵ_(α+1)` є наступним початковим ординалом після `ℵ_α`.
- Для будь-якого граничного ординала `λ`: `ℵ_λ = sup {ℵ_α | α < λ}`.

#### 2. Бет-ієрархія (ℶ)
Літерою «бет» (івр. ב — друга літера єврейської абетки) позначають кардинали, отримані шляхом послідовної ітерації операції булеана:
- `ℶ₀ = ℵ₀` — початковий зліченний рівень.
- `ℶ₁ = 2^ℶ₀ = 2^ℵ₀ = c` — потужність **континууму** (множини дійсних чисел `ℝ`, точок відрізка `[0, 1]`, точок площини `ℝ²`).
- `ℶ₂ = 2^ℶ₁ = 2^c` — потужність множини всіх підмножин дійсних чисел `P(ℝ)` або множини всіх функцій `ℝ → ℝ`.
- `ℶ_(α+1) = 2^ℶ_α` — наступний рівень вежі булеанів.
- `ℶ_λ = sup {ℶ_α | α < λ}` для граничного ординала `λ`.

#### Гіпотеза континууму та незалежність

Порівняння Алеф- та Бет-ієрархій ставить одне з найглибших питань математичної логіки: **чи існує проміжний кардинал між `ℵ₀` та `2^ℵ₀`?** Тобто чи є потужність континууму найменшою можливою незліченною потужністю:

```
ℵ₁ = ℶ₁ = 2^ℵ₀ ?
```

Твердження про те, що `2^ℵ₀ = ℵ₁`, називають [гіпотезою континууму (CH)](root:math-logic/continuum-hypothesis). Її узагальнення для всіх ординалів `2^ℵ_α = ℵ_(α+1)` називають узагальненою гіпотезою континууму (GCH).

Ґеорґ Кантор присвятив десятки років спробам довести гіпотезу континууму, проте відповідь виявилася принципово несподіваною:
- У 1938 році Курт Ґедель побудував конструктивну модель `L` і довів, що гіпотезу континууму **неможливо спростувати** в системі ZFC (вона несуперечлива з аксіомами).
- У 1963 році Пол Коен розробив [метод форсингу](root:math-logic/cohen-forcing) і довів, що гіпотезу континууму **неможливо довести** в системі ZFC.

Гіпотеза континууму є незалежною від стандартної аксіоматики теорії множин: існують самоузгоджені математичні світи, де `2^ℵ₀ = ℵ₁`, і рівноправні світи, де `2^ℵ₀ = ℵ₂`, `ℵ₁₀₀` чи навіть `ℵ_(ω+1)`.

### Обчислювальний вимір: розрив між програмами та задачами

Теорія кардинальних чисел встановлює фундаментальні, неподоланні межі для комп'ютерних наук та теорії алгоритмів.

![Розрив потужностей між зліченною множиною програм та континуумом задач.](/root/sci/math-logic/cardinal-numbers/img/uncomputable-gap.svg)

*Кардинальний розрив. Усі можливі тексти комп'ютерних програм утворюють зліченну множину ℵ₀. Простір усіх математичних задач розпізнавання має потужність континууму 2^ℵ₀. Звідси випливає неминучість алгоритмічно нерозв'язних проблем.*

Зіставимо два світи:

1. **Множина всіх комп'ютерних програм.** Будь-який алгоритм (на C, C++, Python, асемблері чи машині Тюрінга) є скінченною послідовністю символів у скінченній абетці `Σ`. Множина всіх скінченних слів `Σ*` є зліченною. Отже, потужність простору всіх можливих програм завжди дорівнює:
   ```
   |Програми| = ℵ₀
   ```
2. **Множина всіх задач розпізнавання.** Найпростіший тип алгоритмічних задач — це задачі розпізнавання властивостей натуральних чисел (предикати `f: ℕ → {0, 1}`). Кожна така задача однозначно визначається нескінченною послідовністю бітів `{0, 1}^ℕ`. Потужність множини всіх таких задач дорівнює потужності континууму:
   ```
   |Задачі| = 2^ℵ₀ = c
   ```

Оскільки за теоремою Кантора `ℵ₀ < 2^ℵ₀`, між програмами та задачами неможливо встановити навіть сюр'єктивне відображення:

```
ℵ₀ < 2^ℵ₀ = c
```

Цей кардинальний розрив має приголомшливий наслідок: **програм незрівнянно менше, ніж задач**. Якщо зіставити кожній можливій програмі задачу, яку вона здатна розв'язати, майже 100% задач залишаться без жодної програми. Алгоритмічно нерозв'язні проблеми (зокрема класична проблема зупинки Тюрінга чи десята проблема Гільберта) — це не прикрі винятки чи екзотичні аномалії, а переважна більшість усього простору математичних проблем.

### Символьний розрахунок кардиналів у коді

В автоматизованих системах верифікації та комп'ютерної алгебри трансфінітні кардинали моделюють за допомогою алгебраїчних типів даних, де правила спрощення виразів зашиваються у вигляді явних функцій редукції.

Нижче наведено зіставлення реалізацій символьного рушія кардинальної арифметики мовами C та C++.

```c
#include <stdio.h>
#include <stdint.h>
#include <stdbool.h>

typedef enum {
    CARD_FINITE,
    CARD_ALEPH,
    CARD_BETH
} CardinalKind;

typedef struct {
    CardinalKind kind;
    uint64_t index; /* числове значення для FINITE, індекс для ALEPH/BETH */
} Cardinal;

static inline Cardinal make_finite(uint64_t n) {
    return (Cardinal){.kind = CARD_FINITE, .index = n};
}

static inline Cardinal make_aleph(uint64_t idx) {
    return (Cardinal){.kind = CARD_ALEPH, .index = idx};
}

static inline Cardinal make_beth(uint64_t idx) {
    return (Cardinal){.kind = CARD_BETH, .index = idx};
}

static inline Cardinal make_continuum(void) {
    return make_beth(1);
}

/* Порівняння кардиналів: -1 (a < b), 0 (a == b), 1 (a > b) */
int compare_cardinals(Cardinal a, Cardinal b) {
    if (a.kind == CARD_FINITE && b.kind == CARD_FINITE) {
        if (a.index < b.index) return -1;
        if (a.index > b.index) return 1;
        return 0;
    }
    if (a.kind == CARD_FINITE) return -1;
    if (b.kind == CARD_FINITE) return 1;

    /* ℵ₀ тотожний ℶ₀ */
    if (a.index == 0 && b.index == 0) return 0;

    if (a.kind == b.kind) {
        if (a.index < b.index) return -1;
        if (a.index > b.index) return 1;
        return 0;
    }

    if (a.kind == CARD_ALEPH && b.kind == CARD_BETH) {
        return -1;
    }
    return 1;
}

/* κ + λ = max(κ, λ) для трансфінітних */
Cardinal add_cardinals(Cardinal a, Cardinal b) {
    if (a.kind == CARD_FINITE && b.kind == CARD_FINITE) {
        return make_finite(a.index + b.index);
    }
    return (compare_cardinals(a, b) >= 0) ? a : b;
}

/* κ · λ = max(κ, λ) для трансфінітних ненульових */
Cardinal mul_cardinals(Cardinal a, Cardinal b) {
    if ((a.kind == CARD_FINITE && a.index == 0) ||
        (b.kind == CARD_FINITE && b.index == 0)) {
        return make_finite(0);
    }
    if (a.kind == CARD_FINITE && b.kind == CARD_FINITE) {
        return make_finite(a.index * b.index);
    }
    return (compare_cardinals(a, b) >= 0) ? a : b;
}

/* Піднесення до степеня κ^λ */
Cardinal pow_cardinals(Cardinal base, Cardinal exp) {
    if (exp.kind == CARD_FINITE && exp.index == 0) return make_finite(1);
    if (base.kind == CARD_FINITE && base.index == 0) return make_finite(0);
    if (base.kind == CARD_FINITE && base.index == 1) return make_finite(1);

    if (base.kind == CARD_FINITE && exp.kind == CARD_FINITE) {
        uint64_t res = 1;
        for (uint64_t i = 0; i < exp.index; ++i) res *= base.index;
        return make_finite(res);
    }

    /* 2^ℵ_α = ℶ_(α+1), 2^ℶ_β = ℶ_(β+1) */
    if (base.kind == CARD_FINITE && base.index >= 2) {
        return make_beth(exp.index + 1);
    }

    if (compare_cardinals(base, exp) <= 0) {
        return make_beth(exp.index + 1);
    }

    return base;
}
```

```cpp
#include <iostream>
#include <variant>
#include <cstdint>
#include <string>
#include <compare>

namespace math {

struct Finite { uint64_t value; };
struct Aleph  { uint64_t index; };
struct Beth   { uint64_t index; };

class Cardinal {
public:
    using Storage = std::variant<Finite, Aleph, Beth>;

    constexpr Cardinal(uint64_t val) : data_(Finite{val}) {}
    constexpr Cardinal(Storage s) : data_(s) {}

    static constexpr Cardinal aleph(uint64_t idx) { return Cardinal(Aleph{idx}); }
    static constexpr Cardinal beth(uint64_t idx)  { return Cardinal(Beth{idx}); }
    static constexpr Cardinal continuum()         { return Cardinal(Beth{1}); }

    [[nodiscard]] const Storage& raw() const noexcept { return data_; }

    [[nodiscard]] std::string str() const {
        return std::visit([](const auto& v) -> std::string {
            using T = std::decay_t<decltype(v)>;
            if constexpr (std::is_same_v<T, Finite>) {
                return std::to_string(v.value);
            } else if constexpr (std::is_same_v<T, Aleph>) {
                return "Aleph_" + std::to_string(v.index);
            } else if constexpr (std::is_same_v<T, Beth>) {
                return (v.index == 1) ? "c" : ("Beth_" + std::to_string(v.index));
            }
        }, data_);
    }

    friend auto operator<=>(const Cardinal& a, const Cardinal& b) noexcept {
        return std::visit([](const auto& x, const auto& y) -> std::strong_ordering {
            using Tx = std::decay_t<decltype(x)>;
            using Ty = std::decay_t<decltype(y)>;

            if constexpr (std::is_same_v<Tx, Finite> && std::is_same_v<Ty, Finite>) {
                return x.value <=> y.value;
            } else if constexpr (std::is_same_v<Tx, Finite>) {
                return std::strong_ordering::less;
            } else if constexpr (std::is_same_v<Ty, Finite>) {
                return std::strong_ordering::greater;
            } else if constexpr (std::is_same_v<Tx, Ty>) {
                return x.index <=> y.index;
            } else if constexpr (std::is_same_v<Tx, Aleph> && std::is_same_v<Ty, Beth>) {
                if (x.index == 0 && y.index == 0) return std::strong_ordering::equal;
                return std::strong_ordering::less;
            } else {
                if (x.index == 0 && y.index == 0) return std::strong_ordering::equal;
                return std::strong_ordering::greater;
            }
        }, a.data_, b.data_);
    }

    friend bool operator==(const Cardinal& a, const Cardinal& b) noexcept {
        return (a <=> b) == 0;
    }

private:
    Storage data_;
};

inline Cardinal operator+(const Cardinal& a, const Cardinal& b) {
    if (std::holds_alternative<Finite>(a.raw()) && std::holds_alternative<Finite>(b.raw())) {
        return Cardinal(std::get<Finite>(a.raw()).value + std::get<Finite>(b.raw()).value);
    }
    return (a >= b) ? a : b;
}

inline Cardinal operator*(const Cardinal& a, const Cardinal& b) {
    if ((std::holds_alternative<Finite>(a.raw()) && std::get<Finite>(a.raw()).value == 0) ||
        (std::holds_alternative<Finite>(b.raw()) && std::get<Finite>(b.raw()).value == 0)) {
        return Cardinal(0);
    }
    if (std::holds_alternative<Finite>(a.raw()) && std::holds_alternative<Finite>(b.raw())) {
        return Cardinal(std::get<Finite>(a.raw()).value * std::get<Finite>(b.raw()).value);
    }
    return (a >= b) ? a : b;
}

inline Cardinal pow(const Cardinal& base, const Cardinal& exp) {
    if (std::holds_alternative<Finite>(exp.raw()) && std::get<Finite>(exp.raw()).value == 0) return Cardinal(1);
    if (std::holds_alternative<Finite>(base.raw()) && std::get<Finite>(base.raw()).value == 0) return Cardinal(0);
    if (std::holds_alternative<Finite>(base.raw()) && std::get<Finite>(base.raw()).value == 1) return Cardinal(1);

    if (std::holds_alternative<Finite>(base.raw()) && std::holds_alternative<Finite>(exp.raw())) {
        uint64_t b = std::get<Finite>(base.raw()).value;
        uint64_t e = std::get<Finite>(exp.raw()).value;
        uint64_t res = 1;
        for (uint64_t i = 0; i < e; ++i) res *= b;
        return Cardinal(res);
    }

    if (std::holds_alternative<Finite>(base.raw()) && std::get<Finite>(base.raw()).value >= 2) {
        if (std::holds_alternative<Aleph>(exp.raw())) return Cardinal::beth(std::get<Aleph>(exp.raw()).index + 1);
        if (std::holds_alternative<Beth>(exp.raw()))  return Cardinal::beth(std::get<Beth>(exp.raw()).index + 1);
    }

    if (base <= exp) {
        if (std::holds_alternative<Aleph>(exp.raw())) return Cardinal::beth(std::get<Aleph>(exp.raw()).index + 1);
        if (std::holds_alternative<Beth>(exp.raw()))  return Cardinal::beth(std::get<Beth>(exp.raw()).index + 1);
    }

    return base;
}

} // namespace math
```
