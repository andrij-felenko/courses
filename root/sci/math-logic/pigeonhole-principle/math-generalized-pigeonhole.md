# 🧮 Узагальнений, нескінченний та мірний принцип Діріхле

Ця вставка розгортає математичну строгість принципу Діріхле від базового дискретного твердження до дискретного узагальнення, теорії нескінченних множин, теорії міри, геометрії чисел Бліхфельдта, доведення теореми про степені вершин у графах, ергодичної теореми повернення Пуанкаре, виведення леми про накачування (Pumping Lemma) та нерівностей у теорії Рамсея. Вона містить суворі доведення від супротивного, аналіз потужностей та виведення рекурентних меж для чисел Рамсея.

## 1. Дискретне узагальнення: стельова та підлогова форми

У базовій формі принцип розглядає випадок, коли об'єктів лише на один більше, ніж комірок (`n = k + 1`). Узагальнена форма дає точний нижній та верхній рівень наповнення комірок для будь-яких натуральних `n` та `k`.

### Твердження 1 (Стельова форма)
Якщо `n` об'єктів розміщено у `k` комірках (де `n, k ∈ ℕ`, `k ≥ 1`), то принаймні одна комірка містить не менше ніж `⌈n / k⌉` об'єктів, де `⌈x⌉` — функція «стелі» (найменше ціле число, більше або рівне `x`).

### Доведення (від супротивного)
Позначимо через `cᵢ` кількість об'єктів у `i`-тій комірці для `i = 1, 2, ..., k`.
Сума всіх об'єктів по всіх комірках дорівнює `n`:

```
c₁ + c₂ + ... + cₖ = n
```

Припустимо протилежне: кожна комірка містить строго менше ніж `⌈n / k⌉` об'єктів.
Оскільки `cᵢ` є цілими числами, умова `cᵢ < ⌈n / k⌉` еквівалентна нерівності:

```
cᵢ ≤ ⌈n / k⌉ - 1      [для всіх i = 1, ..., k]
```

Просумуємо цю нерівність по всіх `k` комірках:

```
c₁ + c₂ + ... + cₖ  ≤  k · (⌈n / k⌉ - 1)
```

За властивістю функції стелі для будь-якого дійсного числа `x` виконується нерівність `⌈x⌉ < x + 1`. Підставимо `x = n / k`:

```
k · (⌈n / k⌉ - 1)  <  k · ((n / k + 1) - 1)    [властивість стелі: ⌈x⌉ < x + 1]
                   =  k · (n / k)               [спрощення: +1 - 1 = 0]
                   =  n                         [скорочення множника k]
```

Отримуємо строгу суперечність:

```
n  =  c₁ + c₂ + ... + cₖ  <  n
```

Твердження `n < n` є хибним. Отже, припущення некоректне, і принаймні одна комірка містить `≥ ⌈n / k⌉` об'єктів. `■`

### Числовий приклад дискретного узагальнення

Розглянемо колоду з 52 гральних карт, яка ділиться на 4 масті (комірки). Порахуємо мінімальну кількість карт `n`, яку потрібно витягнути з колоди, щоб гарантувати наявність принаймні `m = 5` карт однієї масті.

За узагальненим принципом Діріхле ми хочемо гарантувати, що `⌈n / 4⌉ ≥ 5`.
Найменше `n`, яке задовольняє цю умову:

```
n = 4 · (5 - 1) + 1 = 17 карт
```

Якщо витягнути 16 карт, вони можуть розподілитися рівномірно по 4 карти кожної масті (`16 = 4 × 4`), і жодної масті з 5 картами не буде. Але 17-та карта неминуче переповнить одну з мастей до 5 карт!

### Твердження 2 (Двоїста підлогова форма)
Якщо `n` об'єктів розміщено у `k` комірках, то принаймні одна комірка містить не більше ніж `⌊n / k⌋` об'єктів, де `⌊x⌋` — функція «підлоги» (найбільше ціле число, менше або рівне `x`).

### Доведення
Аналогічно, якби кожна комірка містила `≥ ⌊n / k⌋ + 1` об'єктів, то загальна сума елементів була б:

```
c₁ + c₂ + ... + cₖ  ≥  k · (⌊n / k⌋ + 1)
                   >  k · ((n / k - 1) + 1)     [властивість підлоги: ⌊x⌋ > x - 1]
                   =  n                         [спрощення та скорочення]
```

Що знову дає суперечність `n > n`. `■`

## 2. Принцип Діріхле у теорії графів: Степені вершин

Прямим результатом принципу комірок у теорії графів є класична теорема про степені вершин.

### Теорема (Рівність степеней двох вершин)
У будь-якому простому графі `G = (V, E)` з кількістю вершин `|V| = n ≥ 2` (без петель та кратних ребер) принаймні дві вершини мають **абсолютно однаковий степінь** (кількість суміжних ребер).

### Доведення (за принципом Діріхле)

У простому графі з `n` вершинами можливими значеннями степеня довільної вершини є цілі числа з множини `{0, 1, 2, ..., n - 1}`. 

Всього є `n` можливих значень степеня (комірок). Розглянемо два випадки:

1. **Випадок 1: У графі немає ізольованих вершин (жодна вершина не має степеня 0).**
   Тоді можливими значеннями степеня для кожної з `n` вершин є числа з множини `{1, 2, ..., n - 1}`.
   Кількість можливих значень степенів (комірок) дорівнює `n - 1`.
   Кількість вершин (об'єктів) дорівнює `n`.
   За принципом Діріхле (`n > n - 1`), принаймні дві вершини потрапляють у ту саму комірку, тобто мають однаковий степінь!

2. **Випадок 2: У графі є принаймні одна ізольована вершина `v` зі степенем `deg(v) = 0`.**
   Оскільки вершина `v` не з'єднана з жодною іншою вершиною, максимальний можливий степінь будь-якої іншої вершини в графі не може перевищувати `n - 2` (вона може бути з'єднана щонайбільше з рештою `n - 2` вершинами).
   Отже, можливими значеннями степенів для всіх `n` вершин є числа з множини `{0, 1, ..., n - 2}`.
   Кількість можливих значень степенів (комірок) знову дорівнює `n - 1`.
   Кількість вершин (об'єктів) дорівнює `n`.
   За принципом Діріхле (`n > n - 1`), принаймні дві вершини мають однаковий степінь!

Узагальнюючи обидва випадки, двох вершин зі степенями `0` та `n - 1` не може існувати одночасно у простому графі. Отже, кількість дійсних комірок завжди дорівнює `n - 1`, і для `n` вершин колізія є неминучою. `■`

## 3. Нескінченний принцип Діріхле та потужності множин

Коли множини стають нескінченними, принцип Діріхле перетворюється на твердження про кардинальні числа (потужності множин).

### Теорема (Скінченне розбиття нескінченної множини)
Нехай `X` — нескінченна множина, а `Y` — скінченна множина. Якщо `f: X → Y` — довільне відображення, то існує принаймні один елемент `y ∈ Y`, для якого прообраз (волокно) `f⁻¹({y}) = { x ∈ X | f(x) = y }` є нескінченною множиною.

### Доведення
Подамо множину `X` у вигляді скінченного об'єднання прообразів елементів з `Y`:

```
X = ⋃_{y ∈ Y} f⁻¹({y})
```

Припустимо протилежне: для кожного `y ∈ Y` множина `A_y = f⁻¹({y})` є скінченною.
Скінченне об'єднання скінченних множин завжди є скінченною множиною. Оскільки `Y` скінченна (нехай `|Y| = k`), сумарна потужність `X` була б:

```
|X| = ∑_{y ∈ Y} |A_y|  <  ∞
```

Це прямо суперечить тому, що `X` — нескінченна множина. Отже, принаймні один прообраз `A_y` мусить бути нескінченним. `■`

### Нескінченна теорема Рамсея
Аналогом принципу Діріхле для нескінченних графів є нескінченна теорема Рамсея.

Якщо ребра повного нескінченного зліченного графа `K_ω` (вершинами якого є натуральні числа `ℕ`) розфарбувати у 2 кольори, то у графі неодмінно знайдеться **нескінченний підграф**, усі ребра якого мають один і той самий колір.

Побудова монохроматичної нескінченної множини вершин спирається на послідовне застосування нескінченного принципу Діріхле:
1. Обираємо першу вершину `v₁`. Вона має зліченну кількість ребер.
2. За принципом Діріхле, зліченна кількість ребер, розфарбована у 2 кольори, містить нескінченну кількість ребер одного кольору (наприклад, червоного).
3. Залишаємо лише нескінченну множину вершин `V₁`, з'єднаних з `v₁` червоними ребрами.
4. Обираємо `v₂ ∈ V₁` і повторюємо процес.
5. Наприкінці отримуємо нескінченну послідовність вершин `v₁, v₂, v₃, ...`, ребра між якими утворюють монохроматичний нескінченний підграф.

### Кардинальне узагальнення (Теорема про потужності)
Нехай `κ` та `λ` — кардинальні числа, причому `κ > λ`. Якщо множину потужності `κ` розбити на `λ` підмножин, то принаймні одна з підмножин має потужність `κ`. 

Особливо важливим у комбінаториці є випадок, коли зліченну множину `ℕ` розбивають на скінченну кількість частин: принаймні одна частина буде зліченною.

## 4. Неперервний принцип Діріхле та Теорема повернення Пуанкаре

Принцип Діріхле можна узагальнити з підрахунку елементів на вимірні множини (довжину, площу, об'єм або імовірнісну міру) та динамічні системи.

### Теорема (Про перекриття вимірних множин)
Нехай `(E, Σ, μ)` — простір із мірою, причому `μ(E) > 0`. Нехай `A₁, A₂, ..., Aₖ ∈ Σ` — вимірні підмножини `E`. Якщо сума мір множин `Aᵢ` задовольняє нерівність:

```
∑_{i=1}^{k} μ(Aᵢ)  >  (m - 1) · μ(E)
```

для деякого натурального `m ≥ 1`, то існує точка `x ∈ E`, яка належить щонайменше `m` різним множинам `Aᵢ`.

### Доведення через інтегрування індикаторів
Введемо індикаторні функції `1_{Aᵢ}(x)`, які дорівнюють `1`, якщо `x ∈ Aᵢ`, і `0`, якщо `x ∉ Aᵢ`.
Розглянемо функцію `N(x)`, яка рахує, скільком множинам належить точка `x`:

```
N(x) = ∑_{i=1}^{k} 1_{Aᵢ}(x)
```

Проінтегруємо `N(x)` по множині `E` відносно міри `μ`:

```
∫_E N(x) dμ  =  ∫_E ( ∑_{i=1}^{k} 1_{Aᵢ}(x) ) dμ    [підстановка означення N(x)]
             =  ∑_{i=1}^{k} ∫_E 1_{Aᵢ}(x) dμ       [лінійність інтеграла Лебега]
             =  ∑_{i=1}^{k} μ(Aᵢ)                   [означення інтеграла індикатора]
```

За умовою теореми `∑ μ(Aᵢ) > (m - 1) · μ(E)`. Отже:

```
∫_E N(x) dμ  >  (m - 1) · μ(E)
```

Припустимо протилежне: не існує точки `x ∈ E` з `N(x) ≥ m`. Це означає, що для всіх `x ∈ E` цілочисельне значення `N(x) ≤ m - 1`.
Тоді інтеграл обмежений зверху:

```
∫_E N(x) dμ  ≤  ∫_E (m - 1) dμ  =  (m - 1) · μ(E)
```

Отримуємо суперечність `(m - 1) · μ(E) < ∫ N(x) dμ ≤ (m - 1) · μ(E)`.
Отже, множина точок `{ x ∈ E | N(x) ≥ m }` має додатну міру, і така точка `x` існує. `■`

Зокрема, якщо на одиничному квадраті площею 1 розкласти 5 фігур загальною площею 4.2, то за цією теоремою принаймні одна точка буде покрита щонайменше `⌈4.2 / 1⌉ = 5` фігурами!

### Теорема повернення Пуанкаре (Аналог принципу комірок у динаміці)
У динамічних системах, що зберігають міру (наприклад, замкнена фізична система зі збереженням фазового об'єму), принцип Діріхле лежить в основі **теореми повернення Пуанкаре**: для будь-якої множини додатної міри `A` майже кожна точка `x ∈ A` повертається в область `A` нескінченно багато разів під дією відображення збереження міри `T`.

Доведення розглядає послідовність прообразів `A, T⁻¹(A), T⁻²(A), ...`. Оскільки фазовий простір має скінченну міру, а міра кожного прообразу дорівнює `μ(A) > 0`, нескінченна сума мір перевищить об'єм фазового простору. За принципом Діріхле для мір принаймні два прообрази `T⁻ⁿ(A)` та `T⁻ᵐ(A)` (де `n < m`) перекриються, що негайно дає точка повернення у початковий стан.

## 5. Принцип Діріхле у геометрії чисел: Теорема Бліхфельдта

У 1914 році дансько-американський математик Ганс Фредерік Бліхфельдт (*Hans Frederik Blichfeldt*) довів неперервно-геометричний аналог принципу Діріхле для решіток.

### Теорема Бліхфельдта
Нехай `S ⊂ ℝᵈ` — вимірна область в евклідовому просторі `ℝᵈ`, об'єм якої `Vol(S) > 1`. Тоді існують дві **різні** точки `x, y ∈ S`, різниця яких є цілочисельним вектором:

```
x - y = p ∈ ℤᵈ       [де p ≠ (0,0,...,0)]
```

### Доведення через розбиття простору

Розглянемо покриття простору `ℝᵈ` замощенням з одиничних кубів `C_u = u + [0, 1)ᵈ`, де `u ∈ ℤᵈ` — цілочисельні вектори зсуву.

1. Позначимо через `S_u = S ∩ C_u` перетин області `S` з `u`-тим кубом.
2. Сумарний об'єм області `S` дорівнює сумі об'ємів її перетинів: `Vol(S) = ∑_{u ∈ ℤᵈ} Vol(S_u) > 1`.
3. Зсунемо кожен шматок `S_u` на вектор `-u` в один базовий одиничний куб `C₀ = [0, 1)ᵈ`: покладемо `S_u' = S_u - u ⊂ C₀`.
4. Зсув не змінює об'єм: `Vol(S_u') = Vol(S_u)`.
5. Отже, сума об'ємів зсунутих шматків у базовому кубі дорівнює: `∑_{u ∈ ℤᵈ} Vol(S_u') = Vol(S) > 1`.
6. Оскільки сума об'ємів множин `S_u'` перевищує об'єм самого базового куба `Vol(C₀) = 1`, за неперервним принципом Діріхле принаймні два різних шматки `S_{u₁}'` та `S_{u₂}'` (де `u₁ ≠ u₂`) мусять перекриватися!
7. Існування точки перекриття `z ∈ S_{u₁}' ∩ S_{u₂}'` означає, що існують точки `x ∈ S_{u₁}` та `y ∈ S_{u₂}`, такі що `z = x - u₁ = y - u₂`.
8. Звідси отримуємо: `x - y = u₁ - u₂ = p ∈ ℤᵈ`. Оскільки `u₁ ≠ u₂`, маємо `p ≠ 0`. `■`

## 6. Принцип Діріхле у теорії автоматів: Лема про накачування

У теорії формальних мов та автоматів принцип Діріхле виступає математичним підґрунтям **леми про накачування (Pumping Lemma)** для регулярних мов.

### Теорема (Лема про накачування)
Нехай `L` — регулярна мова, яка розпізнається детермінованим скінченним автоматом (DFA) з `p` станами. Тоді будь-яке слово `w ∈ L` довжиною `|w| ≥ p` можна розкласти на три частини `w = xyz`, що задовольняють умови:
1. `|y| ≥ 1` (центральна частина невироджена);
2. `|xy| ≤ p` (перші дві частини розміщені в межах `p` символів);
3. `∀ k ≥ 0:  xyᵏz ∈ L` (слово можна "накачувати" скільки завгодно разів).

### Доведення через принцип Діріхле

Нехай автомат має множину станів `Q = {q₀, q₁, ..., q_{p-1}}`, де `|Q| = p`.

Розглянемо слово `w = a₁ a₂ ... a_n ∈ L` довжиною `n ≥ p`.

Під час зчитування слова `w` автомат проходить послідовність з `n + 1` станів:

```
s₀, s₁, s₂, ..., s_n      (де s₀ = q_start, s_k = δ(s_{k-1}, a_k))
```

Розглянемо перші `p + 1` станів у цієї послідовності:

```
s₀, s₁, s₂, ..., s_p
```

Маємо `p + 1` елементів у послідовності станів (об'єкти) та лише `p` різних станів у множині `Q` (комірки).

За принципом Діріхле, принаймні два стани у цій послідовності збігаються! Тобто існують такі індекси `0 ≤ i < j ≤ p`, що:

```
s_i = s_j
```

Оскільки `s_i = s_j`, автомат потрапляє у той самий стан двічі. Це означає, що відрізок слова між позиціями `i` та `j` утворює **замкнений цикл у графі станів**:

- Частина `x = a₁ ... a_i` переводить автомат зі стартового стану `s₀` у стан `s_i`.
- Частина `y = a_{i+1} ... a_j` переводить автомат зі стану `s_i` знову у стан `s_i` (цикл).
- Частина `z = a_{j+1} ... a_n` переводить автомат зі стану `s_i` у фінальний приймальний стан `s_n`.

Оскільки `y` є циклом у точці `s_i`, ми можемо проходити цей цикл `k` разів (для будь-якого `k ≥ 0`), і слово `x yᵏ z` все одно приведе автомат у той самий приймальний стан `s_n`.

Отже, `xyᵏz ∈ L` для всіх `k ≥ 0`. `■`

## 7. Алгебраїчні межі в теорії Рамсея

Принцип Діріхле є першим кроком у ланцюгу доведень теорії Рамсея. Число Рамсея `R(r, s)` визначається як найменше число вершин `n`, таке що будь-який граф із `n` вершинами містить або кліку розміру `r`, або незалежну множину розміру `s`.

### Рекурентна верхня межа (Теорема Паша-Рамсея)
Для будь-яких цілих `r, s ≥ 2`:

```
R(r, s)  ≤  R(r - 1, s) + R(r, s - 1)
```

### Доведення (за принципом Діріхле)
Покладемо `n = R(r - 1, s) + R(r, s - 1)`. Розглянемо довільний граф `G` з `n` вершинами та його 2-розфарбування ребер (червоний/синій).

Фіксуємо довільну вершину `v ∈ V(G)`. Степінь вершини `v` дорівнює `n - 1`:

```
n - 1  =  R(r - 1, s) + R(r, s - 1) - 1
```

Усі `n - 1` ребер, інцидентних `v`, розділені на дві комірки: `V_red` (сусіди по червоних ребрах) та `V_blue` (сусіди по синіх ребрах).
За узагальненим принципом Діріхле, або `|V_red| ≥ R(r - 1, s)`, або `|V_blue| ≥ R(r, s - 1)`.

- **Випадок 1:** `|V_red| ≥ R(r - 1, s)`. За означенням числа Рамсея, підграф на `V_red` містить або синю кліку розміру `s` (тоді задача розв'язана), або червону кліку розміру `r - 1`. Додавши вершину `v` до цієї червоної кліки, отримуємо червону кліку розміру `r`.
- **Випадок 2:** `|V_blue| ≥ R(r, s - 1)`. Симетрично дає синю кліку розміру `s`.

Отже, `R(r, s) ≤ R(r - 1, s) + R(r, s - 1)`. `■`

З цієї рекурентності за індукцією негайно випливає загальна верхня оцінка через біноміальний коефіцієнт:

```
R(r, s)  ≤  C(r + s - 2, r - 1)
```

Для діагональних чисел Рамсея `R(k, k)` це дає верхню межу `R(k, k) ≤ C(2k-2, k-1) ≈ 4ᵏ / √(πk)`.

### Імовірнісна нижня межа Ердеша (1947)
Використовуючи імовірнісний метод (який є неперервним аналогом принципу Діріхле на просторах імовірностей), Пал Ердеш довів, що якщо:

```
C(n, k) · 2^(1 - C(k, 2))  <  1
```

то `R(k, k) > n`. Звідси випливає фундаментальна нижня оцінка:

```
R(k, k)  >  2^(k / 2)
```

Оцінки `2^(k/2) < R(k, k) ≤ 4ᵏ` показують, що точний розмір впорядкованих структур зростає експоненціально, і принцип Діріхле є першим ключем до їх розкриття.
