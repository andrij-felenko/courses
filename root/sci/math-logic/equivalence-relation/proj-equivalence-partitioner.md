# Практика: Побудова класів еквівалентності через Disjoint Set Union

У програмуванні часто виникає задача: дано велику множину елементів і набір попарних відношень еквівалентності (наприклад, "комп'ютер A з'єднаний з комп'ютером B", "комп'ютер B з'єднаний з C"). Нам потрібно швидко розбити всі елементи на класи еквівалентності (наприклад, щоб дізнатися, чи можуть комп'ютери A і C зв'язатися між собою), і робити це динамічно, в міру надходження нових зв'язків. Найефективніша структура даних для цього — **Система неперетинних множин** (Disjoint Set Union, DSU, або Union-Find).

DSU ідеально відображає математичне поняття класів еквівалентності. Кожен клас представляється деревом, а корінь дерева є тим самим "представником" класу.

### 1. Постановка задачі

Ми маємо множину з N елементів, пронумерованих від 0 до N-1. Відношення еквівалентності спочатку тривіальне: кожен елемент еквівалентний лише сам собі (рефлексивність). Потім ми отримуємо пари (u, v), які означають u ≡ v. Завдяки транзитивності та симетричності, ці зв'язки розповсюджуються. Після додавання всіх зв'язків нам потрібно вивести всі класи еквівалентності.

### 2. Структура DSU (Union-Find)

Клас `EquivalencePartitioner` використовує масив `parent` для зберігання батька кожного елемента. Якщо `parent[i] == i`, то елемент `i` є коренем (представником) свого класу. Масив `rank` (або розмір дерева) використовується для оптимізації об'єднання.

### 5. Аналіз складності

Алгоритм Union-Find з двома евристиками (стиснення шляху та об'єднання за рангом) є неймовірно швидким. Амортизована складність кожної операції пошуку або об'єднання становить `O(α(N))`, де `α` — обернена функція Аккермана. Для будь-якого практичного розміру множини (навіть більше за кількість атомів у Всесвіті), значення `α(N)` не перевищує 5. Це означає, що алгоритм працює фактично за константний час `O(1)`. Таким чином, загальний час розбиття множини на класи для M зв'язків становить `O(M)`. Це ілюструє, як абстрактна математична концепція транзитивності перетворюється на одну з найоптимальніших структур даних в інформатиці.
