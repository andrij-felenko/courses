# 🧮 Алгебраїчна геометрія булевого куба: метрика Хеммінга, розфарбування та склеювання підкубів

Оцінка булевих функцій від `n` змінних є геометричною операцією розфарбовування вершин `n`-вимірного двійкового гіперкуба `𝔹^n = {0, 1}^n`, де логічні зв'язки та операції мінімізації відповідають об'єднанню суміжних геометричних граней.

## 1. Метричний простір гіперкуба та відстань Хеммінга

Вхідний простір будь-якої булевої функції від `n` змінних формально задається декартовим степенем двозначної множини:

```text
𝔹^n = {0, 1}^n = { (x_1, x_2, ..., x_n) | x_i ∈ {0, 1} }
```

Множина `𝔹^n` складається з `2^n` векторів. Геометрично ці вектори утворюють множину вершин одиничного `n`-вимірного куба в евклідовому просторі `ℝ^n`. Для `n=1` це відрізок між точками `0` та `1`; для `n=2` — квадрат з вершинами `(0,0)`, `(0,1)`, `(1,0)`, `(1,1)`; для `n=3` — тривимірний куб з 8 вершинами.

### Вага та метрика Хеммінга
Для аналізу структури куба вводяться дві фундаментальні числові характеристики:

1. **Вага Хеммінга** вектора `x = (x_1, ..., x_n)`, що позначається `wt(x)`, — це сума його координат у `ℝ` (кількість одиниць у двійковому записі):

```text
wt(x) = ∑_{i=1}^n x_i
```

2. **Відстань Хеммінга** між двома вершинами `x, y ∈ 𝔹^n`, що позначається `d_H(x, y)`, — це кількість позицій, у яких координати векторів різняться. Алгебраїчно відстань Хеммінга виражається через вагу побітового додавання за модулем 2 (XOR):

```text
d_H(x, y) = wt(x ⊕ y) = ∑_{i=1}^n (x_i ⊕ y_i)
```

Функція `d_H(x, y)` задовольняє всі три аксіоми метричного простору:
- **Невід'ємність та тотожність**: `d_H(x, y) ≥ 0`, причому `d_H(x, y) = 0` тоді й лише тоді, коли `x = y`.
- **Симетричність**: `d_H(x, y) = d_H(y, x)`.
- **Нерівність трикутника**: для будь-яких `x, y, z ∈ 𝔹^n` виконується `d_H(x, z) ≤ d_H(x, y) + d_H(y, z)`.

Дві вершини `x` та `y` називаються **суміжними** (з'єднаними ребром гіперкуба), якщо відстань між ними дорівнює одиниці: `d_H(x, y) = 1`. Загальна кількість ребер у графі `n`-куба дорівнює `n · 2^{n-1}`.

## 2. Булева функція як характеристична функція підмножини

Будь-яка логічна функція `f: 𝔹^n → {0, 1}` розбиває вершини гіперкуба на два неперетинні класи:
- **Множина істинності (одиничні мінтерми)**: `T_1(f) = f^{-1}(1) = { x ∈ 𝔹^n | f(x) = 1 }`.
- **Множина хиби (нульові мінтерми)**: `T_0(f) = f^{-1}(0) = { x ∈ 𝔹^n | f(x) = 0 }`.

Геометрично обчислення таблиці істинності еквівалентне двоколірному розфарбуванню вершин куба: кожна вершина з `T_1(f)` фарбується умовним зеленим кольором (істина), а з `T_0(f)` — синім або червоним (хиба).

Тоді базові логічні типи набувають геометричного змісту:
- **Тавтологія** (`f ≡ 1`): множина `T_1(f) = 𝔹^n` містить усі `2^n` вершин (куб повністю зафарбований).
- **Суперечність** (`f ≡ 0`): множина `T_1(f) = ∅` порожня.
- **Випадкова функція**: множина `T_1(f)` є власною непорожньою підмножиною вершин `0 < |T_1(f)| < 2^n`.

## 3. Алгебраїзація логічних операцій над полями ℝ та GF(2)

Замість табличного зіставлення значення булевих виразів можна обчислювати аналітично, використовуючи два різні алгебраїчні апарати: арифметику дійсних чисел `ℝ` та скінченне поле Галуа `GF(2) = ( {0, 1}, ⊕, · )`.

### Арифметичне представлення над полем ℝ
Відобразивши булеві значення `{0, 1}` у підмножину дійсних чисел, логічні зв'язки записуються через стандартні операції додавання, віднімання та множення:

```text
V(¬ x)     = 1 - x
V(x ∧ y)   = x · y
V(x ∨ y)   = x + y - x · y
V(x ⊕ y)   = x + y - 2 · x · y
V(x ⇒ y)   = 1 - x + x · y
V(x ⇔ y)   = 1 - x - y + 2 · x · y
V(x ↑ y)   = 1 - x · y
V(x ↓ y)   = 1 - x - y + x · y = (1 - x) · (1 - y)
```

Цей поліноміальний запис дозволяє обчислювати значення виразів без умовних операторів та будувати неперервні релаксації дискретних логічних задач у задачах штучного інтелекту та оптимізації.

### Поліноміальне представлення над полем GF(2)
У полі Галуа `GF(2)` додавання є операцією `XOR` (`x ⊕ y = (x + y) mod 2`), а множення — кон'юнкцією (`x · y`). Будь-яка булева функція однозначно подається поліномом Жегалкіна (алгебраїчною нормальною формою ANF):

```text
f(x_1, ..., x_n) = ⊕_{I ⊆ {1,...,n}} a_I · ( ∏_{i ∈ I} x_i ),   де a_I ∈ {0, 1}
```

## 4. Теорія підкубів та геометричне склеювання

Найважливішим інструментом логічної мінімізації є поняття `k`-вимірного підкуба (грані).

### Означення підкуба
Нехай кортеж `σ = (σ_1, σ_2, ..., σ_n)`, де кожен символ `σ_i ∈ {0, 1, *}`. Символ `*` позначає невизначену (вільну) координату.
Якщо кортеж `σ` містить рівно `k` зірочок (`0 ≤ k ≤ n`) та `n - k` фіксованих бітів `{0, 1}`, він задає `k`-вимірний підкуб `C(σ) ⊆ 𝔹^n`:

```text
C(σ) = { x ∈ 𝔹^n | ∀ i ∈ {1,...,n}: (σ_i ≠ *) ⇒ (x_i = σ_i) }
```

- Підкуб розмірності `k=0` містить `2^0 = 1` вершину (окремий мінтерм).
- Підкуб розмірності `k=1` містить `2^1 = 2` суміжні вершини (одне ребро).
- Підкуб розмірності `k=2` містить `2^2 = 4` вершини (двовимірна грань / квадрат).
- Підкуб розмірності `k=n` — це весь гіперкуб `𝔹^n`.

### Ізоморфізм між підкубами та елементарними кон'юнкціями (імплікантами)
Кожному `k`-вимірному підкубу `C(σ)` взаємно однозначно відповідає елементарна кон'юнкція з `n - k` літералів:
- якщо `σ_i = 1`, у кон'юнкцію входить літерал `x_i`;
- якщо `σ_i = 0`, у кон'юнкцію входить літерал `¬ x_i`;
- якщо `σ_i = *`, змінна `x_i` випадає з кон'юнкції (елімінується).

Наприклад, у тривимірному просторі `𝔹^3` підкуб `C(1, *, 0)` складається з двох вершин `(1, 0, 0)` та `(1, 1, 0)`. Йому відповідає кон'юнкція `x_1 ∧ ¬ x_3` довжиною `3 - 1 = 2` літерали.

### Теорема про геометричне склеювання (Consensus Theorem)
Два `k`-вимірні підкуби `C_1(σ^{(1)})` та `C_2(σ^{(2)})` називаються **суміжними**, якщо їхні вектори `σ^{(1)}` та `σ^{(2)}` збігаються в усіх позиціях, крім рівно однієї фіксованої координати `j`, де `σ_j^{(1)} = 0`, а `σ_j^{(2)} = 1`.

**Теорема.** Об'єднання двох суміжних `k`-вимірних підкубів `C_1` та `C_2` утворює `(k+1)`-вимірний підкуб `C_{1,2}`, у якому координата `j` замінюється на `*`:

```text
C(σ_1, ..., 0, ..., σ_n) ∪ C(σ_1, ..., 1, ..., σ_n) = C(σ_1, ..., *, ..., σ_n)
```

Алгебраїчно це відповідає закону склеювання булевої алгебри:

```text
A · ¬ x_j ∨ A · x_j = A · (¬ x_j ∨ x_j) = A · 1 = A
```

де `A` — кон'юнкція решти `n - k - 1` спільних літералів.

Саме цей процес послідовного попарного злиття суміжних підкупів розмірності `k` у підкуби розмірності `k+1` лежить в основі алгоритмів мінімізації на картах Карно та в табличному методі Куайна — Мак-Класкі.

## 5. Гармонійний аналіз: розклад Фур'є — Уолша на булевому кубі

Глибший математичний погляд на оцінку булевих функцій дає спектральний аналіз. Для цього значення істинності перекодовують з `{0, 1}` у мультиплікативну групу `{-1, 1}` за формулою `χ(x) = (-1)^x`:
- `0 ↦ +1` (False)
- `1 ↦ -1` (True)

Тоді функція набуває вигляду `f: {-1, 1}^n → {-1, 1}`. Множина всіх таких функцій утворює `2^n`-вимірний гільбертів простір над `ℝ` зі скалярним добутком:

```text
⟨f, g⟩ = 2^{-n} ∑_{x ∈ {-1, 1}^n} f(x) · g(x)
```

Базисом цього простору є сімейство характерів Уолша — функцій парності для кожної підмножини індексів `S ⊆ {1, ..., n}`:

```text
χ_S(x) = ∏_{i ∈ S} x_i
```

Будь-яка функція `f` однозначно розкладається в ортогональний ряд Фур'є:

```text
f(x) = ∑_{S ⊆ {1,...,n}} \hat{f}(S) · χ_S(x)
```

де коефіцієнти Фур'є обчислюються як `\hat{f}(S) = ⟨f, χ_S⟩`.

З рівності Парсеваля `∑_{S} \hat{f}(S)^2 = 1` випливає, що спектральні ваги розподілені на підмножинах змінних. Коефіцієнт `\hat{f}(∅)` виражає зміщення функції (кореляцію з константою), а `\hat{f}({i})` визначає чутливість та вплив (influence) окремої змінної `x_i` на фінальний результат функції. Цей апарат є ключовим інструментом сучасної криптографії при проектуванні S-блоків шифрування, стійких до лінійного криптоаналізу.
