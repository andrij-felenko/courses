# 🧮 Пренексна форма та сколемізація: Квантори під контролем

Пренексна нормальна форма виносить усі квантори на початок формули, а сколемізація замінює квантори існування `∃` на відповідні функціональні залежності (функції Сколема).

## Математична інтуїція: Винесення змінних на поверхню

Логіка першого порядку дозволяє нам формулювати надзвичайно складні вирази, де квантори загальності (`∀`) та існування (`∃`) переплітаються з логічними зв'язками, знаходячись глибоко всередині формули. Така вкладеність робить автоматичне доведення теорем жахіттям.

Пренексна нормальна форма (ПНФ) пропонує геометричну реорганізацію формули. Уявіть, що формула — це будівля. ПНФ виносить усі квантори "на фасад" (утворюючи кванторний префікс), залишаючи саму логічну серцевину (матрицю) всередині, вільною від будь-яких кванторів.

Алгебраїчно це нагадує винесення спільного множника за дужки. Ми використовуємо еквівалентності для "протягування" кванторів через логічні оператори:
- `¬ (∀ x P(x)) ≡ ∃ x (¬ P(x))`
- `¬ (∃ x P(x)) ≡ ∀ x (¬ P(x))`
- `(∀ x P(x)) ∧ Q ≡ ∀ x (P(x) ∧ Q)` (за умови, що `x` не є вільною змінною в `Q`).

Шляхом перейменування змінних (щоб уникнути колізій) та застосування цих правил, будь-яку формулу можна перетворити на еквівалентну їй у пренексній формі: `Q₁ x₁ Q₂ x₂ ... Qₙ xₙ  M`, де `Qᵢ` — квантори, а `M` — безкванторна матриця.

## Сколемізація: Усунення екзистенційної невизначеності

Навіть після зведення до ПНФ, квантори існування створюють проблеми. Вони стверджують: "існує такий елемент `y`, що...". Але який саме? Сколемізація — це блискучий алгебраїчний трюк, який каже: якщо такий `y` існує, давайте просто назвемо його конкретним ім'ям або введемо функцію, яка його генерує.

Якщо квантор `∃ y` не знаходиться в області дії жодного квантора загальності, ми замінюємо змінну `y` на нову константу `c` (константа Сколема). Ми просто "фіксуємо" цей існуючий елемент.

Але якщо `∃ y` йде після `∀ x` (наприклад, `∀ x ∃ y P(x, y)`), це означає, що для кожного `x` існує свій, можливо унікальний `y`. Геометрично це залежність вибору `y` від значення `x`. Сколемізація вирішує це, замінюючи `y` на нову функцію `f(x)` (функція Сколема), яка для кожного `x` явно повертає цей існуючий `y`.

Формула перетворюється на `∀ x P(x, f(x))`. Квантор `∃` зникає!

## Наочний розбір перетворення

Візьмемо твердження: "Кожна людина має матір". 
Логічно: `∀ x (Людина(x) → ∃ y (Жінка(y) ∧ Мати(y, x)))`.

Крок 1: Зведення до ПНФ.
Вираз `→` перепишемо через диз'юнкцію: `∀ x (¬ Людина(x) ∨ ∃ y (Жінка(y) ∧ Мати(y, x)))`.
Тепер витягнемо `∃ y` наперед (оскільки `y` не входить у першу частину):
`∀ x ∃ y (¬ Людина(x) ∨ (Жінка(y) ∧ Мати(y, x)))`.
Це наша пренексна форма.

Крок 2: Сколемізація.
Квантор `∃ y` знаходиться всередині `∀ x`. Отже, існування `y` залежить від `x`. Введемо функцію Сколема `m(x)`, що концептуально означає "функція, яка повертає матір для `x`".
Ми викидаємо `∃ y` і замінюємо всі входження `y` на `m(x)`:
`∀ x (¬ Людина(x) ∨ (Жінка(m(x)) ∧ Мати(m(x), x)))`.

Тепер наша формула містить лише квантори загальності. Оскільки всі змінні неявно пов'язані квантором загальності, ми можемо взагалі відкинути `∀ x` для цілей автоматичного доведення, залишаючи суто алгебраїчну структуру, готову для обробки.

## Висновок для інженерної логіки

Сколемізація не зберігає логічну еквівалентність у строгому сенсі — вона зберігає *здійсненність* (satisfiability). Якщо вихідна формула мала модель, то сколемізована формула також має модель (і навпаки). Цього абсолютно достатньо для методів спростування, таких як метод резолюцій. Завдяки пренексній формі та сколемізації алгоритми автоматичного доведення можуть працювати з формулами як з простими масивами даних, не заплутуючись у складних ієрархіях вкладених кванторів.
