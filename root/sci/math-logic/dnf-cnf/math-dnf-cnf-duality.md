# 🧮 Математична двоїстість та межі стиснення ДНФ і КНФ

Ця вставка містить алгебраїчні виведення, доведення теорем єдиності досконалих нормальних форм, математичне обґрунтування принципу двоїстості Де Моргана, алгоритмічну теорію імплікантів, булеве диференціювання та експоненційні нижні оцінки складності представлення логічних функцій. Без розгляду цих фундаментальних доведень неможливо збагнути математичну межу, яка відділяє поліноміальне спрощення комбінаторних схем від експоненційної непрохідності у задачах дискретної оптимізації.

## 1. Алгебраїчна структура та принцип двоїстості

Нехай `B = {0, 1}` — двоелементна булева алгебра `⟨B, ∧, ∨, ¬, 0, 1⟩`, де операції кон'юнкції (`∧`), диз'юнкції (`∨`) та заперечення (`¬`) задовольняють фундаментальні аксіоми:
1. Комутативності: `x ∧ y = y ∧ x`, `x ∨ y = y ∨ x`.
2. Асоціативності: `(x ∧ y) ∧ z = x ∧ (y ∧ z)`, `(x ∨ y) ∨ z = x ∨ (y ∨ z)`.
3. Дистрибутивності: `x ∧ (y ∨ z) = (x ∧ y) ∨ (x ∧ z)`, `x ∨ (y ∧ z) = (x ∨ y) ∧ (x ∨ z)`.
4. Ідемпотентності: `x ∧ x = x`, `x ∨ x = x`.
5. Нейтральних елементів: `x ∧ 1 = x`, `x ∨ 0 = x`, `x ∧ 0 = 0`, `x ∨ 1 = 1`.
6. Доповнення: `x ∧ ¬x = 0`, `x ∨ ¬x = 1`.

Булевою функцією від `n` змінних називається відображення `f: Bⁿ → B`.

### Визначення 1.1 (Двоїста функція)
Для довільної булевої функції `f(x₁, x₂, ..., xₙ)` двоїстою функцією називається функція `f*(x₁, x₂, ..., xₙ)`, яка отримується шляхом заперечення як значення функції, так і всіх її аргументів:

```
f*(x₁, x₂, ..., xₙ) = ¬f(¬x₁, ¬x₂, ..., ¬xₙ)
```

### Теорема 1.1 (Принцип двоїстості Де Моргана)
Якщо булева формула `F` побудована виключно з використанням операцій `∧`, `∨` та заперечень над змінними, то формула `F*` для двоїстої функції отримується з `F` шляхом взаємної заміни операцій `∧` на `∨`, `∨` на `∧`, констант `0` на `1` та `1` на `0`.

**Доведення.** Проведемо доведення індукцією за структурою виразу `F`.

*База індукції:*
1. Для тотожної функції `f(x) = x`:
```
f*(x) = ¬(¬x) = x
```
2. Для константи `f(x) = 0`:
```
f*(x) = ¬(0) = 1
```

*Індкуційний крок:*
Нехай теорема виконується для виразів `G` та `H`. Розглянемо складний вираз `F = G ∧ H`. За визначенням двоїстої функції:

```
F*(x)
= ¬F(¬x)
= ¬(G(¬x) ∧ H(¬x))          [підстановка F = G ∧ H]
= ¬G(¬x) ∨ ¬H(¬x)          [закон Де Моргана: ¬(A ∧ B) = ¬A ∨ ¬B]
= G*(x) ∨ H*(x)            [за визначенням G* та H*]
```

Аналогічно для диз'юнкції `F = G ∨ H`:

```
F*(x)
= ¬F(¬x)
= ¬(G(¬x) ∨ H(¬x))          [підстановка F = G ∨ H]
= ¬G(¬x) ∧ ¬H(¬x)          [закон Де Моргана: ¬(A ∨ B) = ¬A ∧ ¬B]
= G*(x) ∧ H*(x)            [за визначенням G* та H*]
```

Отже, операції `∧` та `∨` є повністю дуальними щодо заперечення. Принцип двоїстості гарантує, що будь-яка тотожність у ДНФ має двоїсте відображення у КНФ. ∎

## 2. Канонічні досконалі форми: теореми існування та єдиності

### Визначення 2.1 (Мінтерм та Макстерм)
Нехай `α = (α₁, α₂, ..., αₙ) ∈ {0, 1}ⁿ` — фіксований двійковий вектор.
* **Мінтермом (елементарною кон'юнкцією максимальної довжини)** `m_α(x)` називається кон'юнкція всіх `n` літералів:

```
m_α(x₁, ..., xₙ) = x₁^{α₁} ∧ x₂^{α₂} ∧ ... ∧ xₙ^{αₙ}
```

де `xⁱ = x`, якщо `i = 1`, та `xⁱ = ¬x`, якщо `i = 0`. Мінтерм `m_α` дорівнює `1` тоді й лише тоді, коли `(x₁, ..., xₙ) = α`.

* **Макстермом (елементарним диз'юнктів максимальної довжини)** `M_α(x)` називається диз'юнкція всіх `n` літералів:

```
M_α(x₁, ..., xₙ) = x₁^{1 - α₁} ∨ x₂^{1 - α₂} ∨ ... ∨ xₙ^{1 - αₙ}
```

Макстерм `M_α` дорівнює `0` тоді й лише тоді, коли `(x₁, ..., xₙ) = α`.

### Теорема 2.1 (Існування та єдиність ДДНФ)
Будь-яка булева функція `f(x₁, ..., xₙ)`, яка не є тотожнім нулем (`f ≢ 0`), володіє єдиним (з точністю до порядку доданків) представленням у вигляді досконалої диз'юнктивної нормальної форми (ДДНФ):

```
f(x₁, ..., xₙ) = ∨_{α ∈ {0,1}ⁿ: f(α) = 1} m_α(x)
```

**Доведення.**
*1. Існування:* Позначимо через `G(x)` вираз `∨_{α: f(α) = 1} m_α(x)`. Перевіримо рівність `G(β) = f(β)` для довільного вектора `β ∈ {0, 1}ⁿ`.

Випадок 1: Якщо `f(β) = 1`, то у диз'юнкцію `G` входить мінтерм `m_β`. Оскільки `m_β(β) = 1`, загальне значення `G(β) = 1 ∨ ... = 1 = f(β)`.

Випадок 2: Якщо `f(β) = 0`, то мінтерм `m_β` відсутній у складових `G`. Усі інші мінтерми `m_α` (де `α ≠ β`) на векторі `β` дорівнюють `0` (бо існує принаймні одна координата `i`, де `αᵢ ≠ βᵢ`). Отже, `G(β) = 0 ∨ 0 ∨ ... ∨ 0 = 0 = f(β)`.

*2. Єдиність:* Нехай `f` представлена двома ДДНФ з множинами мінтермів `S₁` та `S₂`. Якщо існує мінтерм `m_γ ∈ S₁ \ S₂`, то на векторі `γ` перша ДДНФ видає значення `1`, а друга — `0`, що суперечить рівносильності. Отже, `S₁ = S₂`. ∎

### Теорема 2.2 (Існування та єдиність ДКНФ)
Будь-яка булева функція `f(x₁, ..., xₙ)`, яка не є тотожньою одиницею (`f ≢ 1`), володіє єдиним представленням у вигляді досконалої кон'юнктивної нормальної форми (ДКНФ):

```
f(x₁, ..., xₙ) = ∧_{α ∈ {0,1}ⁿ: f(α) = 0} M_α(x)
```

**Доведення.** Застосуємо результат Теореми 2.1 до двоїстої функції `¬f(x)`. Оскільки `¬f(α) = 1` тоді й лише тоді, коли `f(α) = 0`, за законами Де Моргана заперечення ДДНФ функції `¬f` перетворюється на ДКНФ функції `f`:

```
f(x)
= ¬(¬f(x))
= ¬( ∨_{α: f(α)=0} m_α(x) )
= ∧_{α: f(α)=0} ¬m_α(x)          [закон Де Моргана]
= ∧_{α: f(α)=0} M_α(x)          [бо ¬m_α(x) = M_α(x)]
```
Отже, ДКНФ будується за наборами хибності функції `f`. ∎

### Покроковий приклад: Мажоритарна функція MAJ₃(x, y, z)

Побудуємо канонічні ДДНФ та ДКНФ для мажоритарної функції трьох змінних, яка дорівнює `1` тоді й лише тоді, коли принаймні дві змінні дорівнюють `1`.

Таблиця істинності:
- `(0,0,0) ⇒ 0`  [Макстерм M₀ = x ∨ y ∨ z]
- `(0,0,1) ⇒ 0`  [Макстерм M₁ = x ∨ y ∨ ¬z]
- `(0,1,0) ⇒ 0`  [Макстерм M₂ = x ∨ ¬y ∨ z]
- `(0,1,1) ⇒ 1`  [Мінтерм m₃ = ¬x ∧ y ∧ z]
- `(1,0,0) ⇒ 0`  [Макстерм M₄ = ¬x ∨ y ∨ z]
- `(1,0,1) ⇒ 1`  [Мінтерм m₅ = x ∧ ¬y ∧ z]
- `(1,1,0) ⇒ 1`  [Мінтерм m₆ = x ∧ y ∧ ¬z]
- `(1,1,1) ⇒ 1`  [Мінтерм m₇ = x ∧ y ∧ z]

За Теоремою 2.1, ДДНФ складається з 1-наборів (m₃, m₅, m₆, m₇):

```
SDNF(MAJ₃) = (¬x ∧ y ∧ z) ∨ (x ∧ ¬y ∧ z) ∨ (x ∧ y ∧ ¬z) ∨ (x ∧ y ∧ z)
```

За Теоремою 2.2, ДКНФ складається з 0-наборів (M₀, M₁, M₂, M₄):

```
SKNF(MAJ₃) = (x ∨ y ∨ z) ∧ (x ∨ y ∨ ¬z) ∧ (x ∨ ¬y ∨ z) ∧ (¬x ∨ y ∨ z)
```

Склеюванням мінтермів у ДДНФ отримуємо мінімальну ДНФ:

```
SDNF(MAJ₃)
= [(¬x ∧ y ∧ z) ∨ (x ∧ y ∧ z)] ∨ [(x ∧ ¬y ∧ z) ∨ (x ∧ y ∧ z)] ∨ [(x ∧ y ∧ ¬z) ∨ (x ∧ y ∧ z)]  [групування спільних множників]
= (y ∧ z) ∨ (x ∧ z) ∨ (x ∧ y)                                                            [склеювання: (¬x ∧ A) ∨ (x ∧ A) = A]
```

Аналогічно, склеюванням макстермів отримуємо мінімальну КНФ:

```
SKNF(MAJ₃) = (x ∨ y) ∧ (x ∨ z) ∧ (y ∨ z)
```

## 3. Математичні межі стиснення: експоненційний роздув розміру

Хоча ДДНФ та ДКНФ є канонічними, їхній розмір завжди дорівнює `N · 2ⁿ` літералів, де `N` — кількість наборів істинності/хибності. Звичайні (скорочені) ДНФ та КНФ дозволяють склеювати мінтерми/макстерми для зменшення виразу. Виникає питання: чи завжди існує коротка ДНФ або КНФ?

### Теорема 3.1 (Експоненційна нижня оцінка для функції парності)
Розглянемо булеву функцію парності (Parity Function) від `n` змінних, яка дорівнює `1` тоді й лише тоді, коли кількість одиниць у вхідному векторі є непарною:

```
PARITY_n(x₁, x₂, ..., xₙ) = x₁ ⊕ x₂ ⊕ ... ⊕ xₙ
```

Будь-яка ДНФ або КНФ, що тотожно представляє `PARITY_n`, містить не менше ніж `2ⁿ⁻¹` елементарних кон'юнктів (або диз'юнктів), а її загальний розмір є строго експоненційним `Ω(n · 2ⁿ⁻¹)`.

**Доведення.**
Розглянемо довільний кон'юнкт `C` у ДНФ функції `PARITY_n`.

1. Припустимо, що кон'юнкт `C` містить `k < n` літералів (тобто принаймні одна змінна `xᵢ` відсутня у `C`).
2. Оскільки `xᵢ` відсутня, значення кон'юнкта `C` не залежить від `xᵢ`. Це означає, що якщо `C` дорівнює `1` на деякому векторі `α = (α₁, ..., αᵢ₋₁, 0, αᵢ₊₁, ..., αₙ)`, то він також дорівнює `1` на векторі `α' = (α₁, ..., αᵢ₋₁, 1, αᵢ₊₁, ..., αₙ)`.
3. Проте вектори `α` та `α'` відрізняються значенням рівно однієї змінної `xᵢ`. Отже, один із цих векторів має парну кількість одиниць, а інший — непарну!
4. Це означає, що `PARITY_n(α) ≠ PARITY_n(α')`. Отже, кон'юнкт `C` видає значення `1` на векторі, де функція дорівнює `0`, що утворює суперечність.
5. Таким чином, жоден кон'юнкт не може містити менше ніж `n` літералів. Кожен кон'юнкт у ДНФ функції `PARITY_n` зобов'язаний бути мінтермом максимальної довжини `n`.
6. Оскільки функція `PARITY_n` дорівнює `1` рівно на половині з усіх `2ⁿ` можливих вхідних векторів, кількість 1-наборів дорівнює `2ⁿ⁻¹`.
7. Оскільки жодні два різні мінтерми довжини `n` не можуть бути склеєні між собою, мінімальна ДНФ мусить містити рівно `2ⁿ⁻¹` кон'юнктів.

Аналогічне міркування для КНФ над 0-наборами дає точну нижню оцінку у `2ⁿ⁻¹` диз'юнктів. ∎

### Наслідок 3.1 (Експоненційна розбіжність ДНФ та КНФ)
Існують сімейства булевих функцій, які мають строго лінійний або поліноміальний розмір у ДНФ, але вимагають експоненційного розміру у КНФ (і навпаки).

Розглянемо функцію `F_k(x₁, y₁, x₂, y₂, ..., x_k, y_k)`, сформульовану у ДНФ як:

```
F_k = (x₁ ∧ y₁) ∨ (x₂ ∧ y₂) ∨ ... ∨ (x_k ∧ y_k)
```

Розмір цієї ДНФ є строго лінійним: `k` кон'юнктів довжини `2` (разом `2k` літералів).

Однак при застосуванні дистрибутивності для побудови КНФ необхідно вибрати по одному літералу з кожного кон'юнкта:

```
F_k = ∧_{(l₁, l₂, ..., l_k) ∈ {x₁,y₁} × ... × {x_k,y_k}} (l₁ ∨ l₂ ∨ ... ∨ l_k)
```

Отримане КНФ містить рівно `2ᵏ` диз'юнктів, де кожен диз'юнкт має довжину `k`. Загальний розмір КНФ дорівнює `k · 2ᵏ`.

Цей результат показує, що прямолінійне еквівалентне зведення з ДНФ у КНФ призводить до нездоланного експоненційного роздуву.

## 4. Прості імпліканти та теорема Блейка — Квайна

Для ефективного стиснення ДНФ використовується теорія імплікантів.

### Визначення 4.1 (Імплікант та Простий імплікант)
* Елементарна кон'юнкція `C` називається **імплікантом** булевої функції `f`, якщо з істинності `C` випливає істинність `f` (тобто `C ⇒ f` або `C ∧ ¬f = 0`).
* Імплікант `C` називається **простим імплікантом (prime implicant)**, якщо жодна кон'юнкція `C'`, отримана з `C` вилученням хоча б одного літерала, вже не є імплікантом `f`.

### Теорема 4.1 (Теорема Блейка — Квайна)
Скорочена ДНФ булевої функції `f`, яка утворена диз'юнкцією **усіх** її простих імплікантів, є повністю еквівалентною вихідній функції `f`. Будь-яка мінімальна ДНФ (за кількістю літералів чи кон'юнктів) може бути отримана зі скороченої ДНФ шляхом вилучення лишкових простих імплікантів.

**Алгоритми побудови простих імплікантів:**
1. **Операція обобщеного склеювання (Consensus Operation):**
```
(A ∧ x) ∨ (B ∧ ¬x) = (A ∧ x) ∨ (B ∧ ¬x) ∨ (A ∧ B)
```
2. **Операція поглинання (Absorption):**
```
A ∨ (A ∧ B) = A
```

Послідовне застосування обобщеного склеювання до всіх пар кон'юнктів з подальшим вилученням поглинутих кон'юнктів гарантовано будує повний набір простих імплікантів функції за кінцеву кількість кроків.

## 5. Алгебра булевих похідних (Boolean Derivatives)

Для аналізу чутливості ДНФ/КНФ формул до зміни конкретної змінної вводиться поняття булевої похідної (Boolean Differential Calculus):

### Визначення 5.1 (Булева похідна)
Булевою похідною функції `f(x₁, ..., xᵢ, ..., xₙ)` по змінній `xᵢ` називається булева функція, яка дорівнює `1` тоді й лише тоді, коли зміна значення `xᵢ` змінює значення всієї функції `f`:

```
∂f / ∂xᵢ = f(x₁, ..., xᵢ=1, ..., xₙ) ⊕ f(x₁, ..., xᵢ=0, ..., xₙ)
```

**Властивості булевої похідної:**
1. Похідна `∂f / ∂xᵢ` не залежить від самої змінної `xᵢ`.
2. Якщо `∂f / ∂xᵢ ≡ 0`, функція є фіктивно залежною від `xᵢ` (змінну можна вилучити з усіх термів ДНФ/КНФ).
3. При використанні КНФ-формул у верифікації апаратних схем, булева похідна використовується для генерування вхідних тестових векторів для виявлення статичних та динамічних коротких замикань (Stuck-at Faults).

### Теорема 4.2 (Математичне обґрунтування кодування Цейтіна)
Нехай `F` — булева формула, що містить `N` операцій. Існує КНФ-формула `F_Tseytin` над вихідними змінними та `N` допоміжними змінними така, що:
1. `F_Tseytin` є рівновиконуваного вихідній формулі: `F` виконувана ⇔ `F_Tseytin` виконувана.
2. Кількість диз'юнктів у `F_Tseytin` не перевищує `4N`, а загальна кількість літералів є `O(N)`.

**Доведення.** Для кожного внутрішнього оператора `v = A ∘ B` (де `∘ ∈ {∧, ∨, →, ≡}`) у синтаксичному дереві формули `F` вводиться нова булева змінна `y_v` та до форми додаються диз'юнкти, що кодують еквівалентність `y_v ≡ (y_A ∘ y_B)`.

Наприклад, для оператора кон'юнкції `y = a ∧ b`:
```
(y ≡ (a ∧ b))
= (y → (a ∧ b)) ∧ ((a ∧ b) → y)         [вираження ≡ через імплікації →]
= (¬y ∨ (a ∧ b)) ∧ (¬a ∨ ¬b ∨ y)       [усунення імплікацій: A → B ≡ ¬A ∨ B]
= (¬y ∨ a) ∧ (¬y ∨ b) ∧ (¬a ∨ ¬b ∨ y)   [дистрибутивність ∨ відносно ∧]
```
Отримуємо рівно 3 диз'юнкти малого розміру. Для диз'юнкції `y = a ∨ b`:
```
(y ≡ (a ∨ b))
= (¬a ∨ y) ∧ (¬b ∨ y) ∧ (a ∨ b ∨ ¬y)   [аналогічний розклад диз'юнкції]
```
Загальна КНФ будується як кон'юнкція кодувань усіх вузлів та одиничного диз'юнкта для кореневого вузла `y_root`. Оскільки кожен вузол породжує не більше 4 диз'юнктів, загальний розмір `F_Tseytin` дорівнює `O(N)`, що завершує доведення. ∎
