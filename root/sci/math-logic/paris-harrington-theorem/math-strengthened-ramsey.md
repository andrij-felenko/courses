# 🧮 Математичний апарат підсиленого принципу Рамсея

Строге доведення теореми Паріса — Гаррінгтона спирається на синтез класичної комбінаторики, топологічної компактності, теорії швидкозростаючих функцій та теорії моделей формальної арифметики Пеано.

## Формалізація принципу Рамсея та умови великих множин

Нехай `X` — скінченна або нескінченна підмножина натуральних чисел `ℕ = {1, 2, 3, ...}`. Позначимо через `[X]ⁿ` множину всіх `n`-елементних підмножин `X`:

```
[X]ⁿ = { S ⊆ X : |S| = n }
```

Розфарбуванням (або партицією) множини `[X]ⁿ` у `c` кольорів називається функція `K: [X]ⁿ → {1, 2, ..., c}`.

Підмножина `H ⊆ X` називається **монохроматичною** (або однорідною відносно розфарбування `K`), якщо всі її `n`-елементні підмножини зафарбовані в один і той самий колір під дією `K`:

```
∃ k ∈ {1, ..., c}  ∀ S ∈ [H]ⁿ ( K(S) = k )
```

**Означення (Велика множина):** Скінченна множина натуральних чисел `H ⊂ ℕ` називається **великою** (або відносно великою, англ. *relatively large*), якщо кількість її елементів не менша за її найменший елемент:

```
|H| ≥ min(H)
```

Зауважимо: якщо `H = {x₁, x₂, ..., xₖ}` впорядковано за зростанням `x₁ < x₂ < ... < xₖ`, то умова великої множини означає `k ≥ x₁`.

### Формулювання принципу Паріса — Гаррінгтона (PH)

Для будь-яких натуральних чисел `n ≥ 1`, `m ≥ 1` та `c ≥ 1` існує таке натуральне число `N = PH(n, m, c)`, що для будь-якого розфарбування `K: [{1, 2, ..., N}]ⁿ → {1, 2, ..., c}` існує монохроматична підмножина `H ⊆ {1, 2, ..., N}`, яка задовольняє дві умови:
1. `|H| ≥ m` (стандартна вимога розміру);
2. `|H| ≥ min(H)` (вимога великої множини).

## Доведення істинності в ℕ через нескінченну теорему Рамсея та компактність

Доведемо, що твердження PH є істинним у стандартній моделі `ℕ`. Доведення складається з двох кроків: застосування нескінченної теореми Рамсея та аргументу компактності (леми Кеніга про нескінченне дерево).

### Крок 1: Нескінченна теорема Рамсея

Нехай `K: [ℕ]ⁿ → {1, 2, ..., c}` — довільне розфарбування `n`-елементних підмножин нескінченної множини `ℕ`. За нескінченною теоремою Рамсея існує **нескінченна** монохроматична підмножина `H_∞ ⊆ ℕ`.

Доведення цього факту здійснюється математичною індукцією за розмірністю `n`:
- База індукції (`n = 1`): розфарбування окремих елементів `K: ℕ → {1, ..., c}` розбиває нескінченну множину `ℕ` на `c` класів еквівалентності. За узагальненим принципом Діріхле для нескінченних множин принаймні один із `c` класів є нескінченним. Цей клас і формує шукану підмножину `H_∞`.
- Індукційний крок (`n > 1`): припускаємо істинність для `n - 1`. Зафіксуємо елемент `x₁ ∈ ℕ` і розглянемо забарвлення `(n-1)`-підмножин у залишеній частині. За індукційним припущенням виділяємо нескінченну послідовність сумісних елементів та побудуємо нескінченну однорідну підмножину `H_∞`.

Оскільки `H_∞` є нескінченною підмножиною натуральних чисел, вона містить свій мінімальний елемент `a = min(H_∞)`.

Зафіксуємо `k = max(m, a)` і візьмемо перші `k` елементів з `H_∞`:

```
H = { x₁, x₂, ..., xₖ } ⊂ H_∞,  де x₁ = a = min(H_∞)
```

Оскільки `H ⊂ H_∞`, підмножина `H` є монохроматичною. Її розмір дорівнює `|H| = k = max(m, a)`. Звідси:
- `|H| ≥ m`;
- `|H| ≥ a = min(H)`.

Отже, для будь-якого розфарбування нескінченної множини `[ℕ]ⁿ` існує скінченна монохроматична підмножина, яка є великою та має розмір не менше `m`.

### Крок 2: Топологічна компактність (Лема Кеніга)

Припустимо від супротивного, що для деяких фіксованих `n, m, c` шуканого порогу `N` не існує. Це означає, що для кожного `N ∈ ℕ` існує «погане» розфарбування `K_N: [{1, ..., N}]ⁿ → {1, ..., c}`, яке не містить жодної великої монохроматичної підмножини розміру `≥ m`.

Розглянемо дерево «поганих» розфарбувань `T`. Коренем дерева є порожнє розфарбування. Вершинами на рівні `N` є погані розфарбування `K_N`. Вершина `K_{N+1}` є нащадком `K_N`, якщо розширення `K_{N+1}` збігається з `K_N` на всіх `n`-підмножинах з `{1, ..., N}`.

Оскільки алфавіт кольорів `{1, ..., c}` скінченний, кожен вузол дерева `T` має скінченний степінь розгалуження. Дерево `T` містить нескінченну кількість вершин (оскільки за припущенням погані розфарбування існують для кожного `N`). За лемою Кеніга (англ. *König's Tree Lemma*) нескінченне скінченно-розгалужене дерево містить нескінченну гілку.

З точки зору загальної топології, цей аргумент відповідає теоремі Тихонова про компактність добутку компактних топологічних просторів: простір усіх забарвлень `c^{[ℕ]ⁿ}` є компактним Канторовим дисконумом, тому будь-яка послідовність скінченних наближень має граничну точку.

Ця нескінченна гілка визначає граничне розфарбування `K_∞: [ℕ]ⁿ → {1, ..., c}`. Проте за Кроком 1 для `K_∞` мусить існувати скінченна велика монохроматична підмножина `H` розміру `|H| ≥ m`. Нехай `max(H) = M`. Тоді підмножина `H` міститься у `{1, ..., M}` і є монохроматичною у розфарбуванні `K_M`. Це суперечить тому, що `K_M` є «поганим» розфарбуванням!

Отже, припущення хибне, і поріг `N = PH(n, m, c)` існує для всіх `n, m, c`. Твердження PH **істинне в `ℕ`**.

## Швидкозростаюча ієрархія та оцінка швидкості зростання

Щоб зрозуміти, чому арифметика Пеано не здатна довести PH, зіставимо функцію `PH(n, m, c)` зі швидкозростаючою ієрархією функцій (англ. *Fast-Growing Hierarchy*).

Нехай `F_α: ℕ → ℕ` — сімейство функцій, індексованих ординалами `α < ε₀`:

```
F₀(x) = x + 1
F_{α+1}(x) = F_α^(x)(x)             [x-кратна ітерація функції F_α]
F_λ(x) = F_{λ[x]}(x)                 [для граничного ординалу λ]
```

Приклади рівнів:
- `F₁(x) = 2x` (лінійне зростання);
- `F₂(x) = x · 2ˣ` (експоненціальне зростання);
- `F₃(x) ≈ 2↑↑x` (суперекспонента / вежа степенів);
- `F_ω(x)` — функція типу Аккермана (поріг примітивно-рекурсивних функцій).

Теорема Кетоннена — Соловея (1981) встановлює суворі межі для функції `PH(n, m, c)`:

```
Для n = 2:  PH(2, m, c) ≈ F_ω(m)                  [рівень функції Аккермана]
Для n ≥ 3:  m ↦ PH(n, m, c) ∈ Ω( F_{ω^{n-1}}(m) ) [скок ординального рівня]
```

Якщо ми розглянемо діагональну функцію `f(n) = PH(n, n, n)`, її швидкість зростання досягає рівня ординала `ε₀`:

```
f(n) ∈ Ω( F_{ε₀}(n) )
```

## Теорія доведень, нестандартні моделі та 1-консистентність

За теоремою Ґентцена про структуру доведень у системі PA, будь-яка довідно-рекурсивна функція в арифметиці Пеано мажорується деякою функцією `F_α` для ординалу `α < ε₀`. Оскільки функція Паріса — Гаррінгтона `f(n)` зростає зі швидкістю `F_{ε₀}`, вона зростає швидше за будь-яку функцію, тотальність якої можна довести в PA!

З точки зору теорії моделей, Паріс і Гаррінгтон довели наступну фундаментальну еквівалентність у системі PA:

```
PA ⊢ ( PH ⇔ 1-Con(PA) )
```

де `1-Con(PA)` позначує 1-консистентність арифметики Пеано (твердження про те, що PA не виводить хибних `Σ₁⁰`-речень).

За ІІ теоремою Геделя про неповноту, якщо система PA є несуперечливою, вона не може довести власну несуперечливість, а отже, й `1-Con(PA)`. Завдяки вищенаведеній еквівалентності отримуємо остаточний висновок:

```
PA ⊬ PH
```

Арифметика Пеано не спроможна довести підсилений принцип Рамсея.
