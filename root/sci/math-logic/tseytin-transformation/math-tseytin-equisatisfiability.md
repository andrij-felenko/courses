# 🧮 Математична теорема про еквізатисфіабельність перетворення Цейтіна

Формальний доказ еквізатисфіабельності гарантує, що початкова булева формула має задовольняючу інтерпретацію тоді й лише тоді, коли згенерована Цейтін-КНФ є здійсненною.

## 1. Формальні означення та семантичні поняття

Нехай `V = {v₁, v₂, ..., vₙ}` — множина вхідних булевих змінних. Булева формула `F` будується індуктивно з літералів `vᵢ`, `¬vᵢ` та логічних зв'язок `∧`, `∨`, `¬`, `→`, `↔`, `⊕`.

Інтерпретацією (або оцінкою) `I` називається функція видачі істинності `I: V → {0, 1}`, яка зіставляє кожній вхідній змінній значення `0` (хибність) або `1` (істина). Семантика формули `F` при інтерпретації `I`, що позначається як `val(F, I)`, обчислюється за класичними таблицями істинності логічних операторів. Формула `F` є **здійсненною** (satisfiable), якщо існує така інтерпретація `I`, що `val(F, I) = 1`. У цьому випадку кажуть, що `I` задовольняє `F` (позначається `I ⊨ F`).

Дві формули `F` та `G` над множиною змінних `V` називаються **логічно еквівалентними** (позначається `F ≡ G`), якщо для будь-якої інтерпретації `I` виконується рівність:

```
val(F, I) = val(G, I)    [тотожність семантики на всіх можливих оцінках]
```

Нехай `F` — формула над змінними `V`, а `F'` — формула над розширеною множиною змінних `V ∪ X`, де `X = {x₁, x₂, ..., xₘ}` — множина нових допоміжних змінних, доданих алгоритмом Цейтіна.

**Означення еквізатисфіабельності:** Формули `F` та `F'` називаються **еквізатисфіабельними** (equisatisfiable, позначається `F ⊵⊲ F'`), якщо формула `F` здійсненна тоді й лише тоді, коли формула `F'` здійсненна:

```
(∃ I: V → {0, 1} такого, що I ⊨ F) ⇔ (∃ I': V ∪ X → {0, 1} такого, що I' ⊨ F')
```

Логічна еквівалентність є набагато сильнішою умовою, ніж еквізатисфіабельність. З логічної еквівалентності випливає еквізатисфіабельність, але обернене твердження невірно. Перетворення Цейтіна створює формулу `F'`, яка **не є** логічно еквівалентною `F` у базовому алфавіті `V`, але є строго еквізатисфіабельною.

## 2. Алгоритмічна побудова формули Цейтіна F'

Представимо формулу `F` у вигляді синтаксичного дерева `T(F)`. Кожному внутрішньому вузлу `u` дерева `T(F)`, який відповідає підформулі `Fᵤ` з логічним оператором `⊙ᵤ` та дочірніми вузлами `u₁` і `u₂`, зіставимо унікальну булеву змінну `xᵤ ∈ X`. Для листя дерева, яке відповідає вхідним змінним `vᵢ ∈ V`, покладемо `xᵤ = vᵢ`.

Для кожного внутрішнього вузла `u` з операндами `xᵤ₁` та `xᵤ₂` випишемо локальну тотожність еквівалентності `Cᵤ`:

```
Cᵤ = (xᵤ ↔ (xᵤ₁ ⊙ᵤ xᵤ₂))    [локальне визначення значення вузла u]
```

Перетворимо кожне `Cᵤ` у КНФ за стандартними таблицями логічного розкладу. Позначимо через `CNF(Cᵤ)` відповідний набір дизюнктів.

Загальне Цейтінівське перетворення `F'` формули `F` з кореневим вузлом `root` визначається як кон'юнкція всіх локальних КНФ-блоків та одиничного диз'юнкта для кореневої змінної:

```
F' = xᵣₒₒₜ ∧ ⋀_{u ∈ Internal(T)} CNF(Cᵤ)    [структура підсумкової КНФ-формули]
```

## 3. Формальне доведення теореми еквізатисфіабельності

**Теорема (Цейтін, 1968):** Нехай `F` — булева формула, а `F'` — її перетворення Цейтіна. Тоді `F` здійсненна тоді й лише тоді, коли `F'` здійсненна.

**Доведення:** Необхідно довести твердження в обох напрямках: імпликацію прямо вліво (`F ⊨ SAT ⇒ F' ⊨ SAT`) та обернену імпликацію вправо (`F' ⊨ SAT ⇒ F ⊨ SAT`).

### Прямий напрямок (якщо F здійсненна, то F' здійсненна)

Припустимо, що формула `F` здійсненна. Це означає, що існує інтерпретація `I: V → {0, 1}` така, що `val(F, I) = 1`.

Забудуємо розширену інтерпретацію `I': V ∪ X → {0, 1}` за наступним правилом:
1. Для всіх вхідних змінних `vᵢ ∈ V` покладемо `I'(vᵢ) = I(vᵢ)`.
2. Для кожного внутрішнього вузла `u` синтаксичного дерева з відповідною підформулою `Fᵤ` покладемо значення допоміжної змінної `I'(xᵤ)` рівним обчисленому семантичному значенню підформули на початковій інтерпретації `I`:

```
I'(xᵤ) = val(Fᵤ, I)    [індуктивне призначення значень допоміжним змінним]
```

Перевіримо виконання всіх дизюнктів формули `F'` при інтерпретації `I'`:

- **Локальні КНФ-блоки:** Для кожного внутрішнього вузла `u` з операндами `u₁` та `u₂` за побудовою маємо:

```
I'(xᵤ) = val(Fᵤ, I)
= val(Fᵤ₁ ⊙ᵤ Fᵤ₂, I)                     [розклад за логічним оператором вузла u]
= val(Fᵤ₁, I) ⊙ᵤ val(Fᵤ₂, I)             [визначення семантики логічного оператора]
= I'(xᵤ₁) ⊙ᵤ I'(xᵤ₂)                      [підстановка визначення розширеної інтерпретації I']
```

Оскільки `I'(xᵤ) = I'(xᵤ₁) ⊙ᵤ I'(xᵤ₂)`, вираз `I'(xᵤ) ↔ (I'(xᵤ₁) ⊙ᵤ I'(xᵤ₂))` набуває значення `1`. Отже, всі диз'юнкти з блоку `CNF(Cᵤ)` є істинними при інтерпретації `I'`.

- **Кореневий диз'юнкт:** Оскільки `root` відповідає всій формулі `F`, за умовою маємо:

```
I'(xᵣₒₒₜ) = val(F, I) = 1                 [істинність кореневої змінної від істинності F]
```

Оскільки одиничний диз'юнкт `xᵣₒₒₜ` і всі локальні диз'юнкти `CNF(Cᵤ)` є істинними при `I'`, кон'юнкція `F'` набуває значення `1`. Отже, `I' ⊨ F'`, і формула `F'` є здійсненною.

### Обернений напрямок (якщо F' здійсненна, то F здійсненна)

Припустимо, що формула `F'` є здійсненною. Це означає, що існує така розширена інтерпретація `I': V ∪ X → {0, 1}`, що `val(F', I') = 1`.

Розглянемо звуження інтерпретації `I'` на множину вхідних змінних `V`, яке позначимо як `I = I'|_V`.

Доведемо математичною індукцією за висотою вузла `u` у синтаксичному дереві `T(F)`, що для кожного вузла `u` виконується рівність `I'(xᵤ) = val(Fᵤ, I)`.

- **База індукції (листя дерева):** Якщо `u` — листок, то `Fᵤ = vᵢ ∈ V` і `xᵤ = vᵢ`. За визначенням звуження `I = I'|_V` маємо `I'(xᵤ) = I'(vᵢ) = I(vᵢ) = val(Fᵤ, I)`. База доведена.

- **Індуктивний крок:** Нехай `u` — внутрішній вузол з дочірніми вузлами `u₁` та `u₂`, для яких за індуктивним припущенням вже доведено:

```
I'(xᵤ₁) = val(Fᵤ₁, I)                    [індуктивне припущення для лівого операнда]
I'(xᵤ₂) = val(Fᵤ₂, I)                    [індуктивне припущення для правого операнда]
```

Оскільки `I' ⊨ F'`, то розширена інтерпретація `I'` задовольняє КНФ-блок `CNF(Cᵤ)` вузла `u`. Оскільки `CNF(Cᵤ)` є логічно еквівалентним виразу `xᵤ ↔ (xᵤ₁ ⊙ᵤ xᵤ₂)`, виконується рівність:

```
I'(xᵤ) = I'(xᵤ₁) ⊙ᵤ I'(xᵤ₂)               [істинність КНФ-блоку задовольняє локальну еквівалентність]
= val(Fᵤ₁, I) ⊙ᵤ val(Fᵤ₂, I)             [заміна за індуктивним припущенням]
= val(Fᵤ₁ ⊙ᵤ Fᵤ₂, I)                     [семантика логічного оператора]
= val(Fᵤ, I)                             [визначення підформули Fᵤ]
```

Крок індукції доведено.

Застосовуючи цю рівність до кореневого вузла `root`, отримуємо `val(F, I) = I'(xᵣₒₒₜ)`. Оскільки `I' ⊨ F'`, одиничний диз'юнкт `xᵣₒₒₜ` вимагає `I'(xᵣₒₒₜ) = 1`. Отже, `val(F, I) = 1`, що означає `I ⊨ F`. Формула `F` є здійсненною. Теорему повністю доведено.

## 4. Оптимізація Плейстеда-Ґрінбаума: врахування полярності

У класичному перетворенні Цейтіна для кожного вузла кодується двостороння еквівалентність `xᵤ ↔ (xᵤ₁ ⊙ᵤ xᵤ₂)`. Проте Девід Плейстед та Стівен Ґрінбаум у 1986 році показали, що напрямок імплікації можна оптимізувати залежно від **полярності** підформули.

Полярність підформули `Fᵤ` у формулі `F` позначається `pol(F, u) ∈ {+1, -1, 0}` і визначається кількістю заперечень на шляху від кореня до вузла `u`:
- **Позитивна полярність (+1):** підформула знаходиться під парною кількістю заперечень (або лівих операндів імплікації).
- **Негативна полярність (-1):** підформула знаходиться під непарною кількістю заперечень.
- **Обопільна полярність (0):** підформула знаходиться під оператором еквівалентності (`↔`) або виключного АБО (`⊕`).

Оптимізований КНФ-блок побудови Плейстеда-Ґрінбаума `CNF_PG(Cᵤ)` кодується за правилами:

```
pol(F, u) = +1 ⇒ кодується тільки імплікація (xᵤ → (xᵤ₁ ⊙ᵤ xᵤ₂))     [економія диз'юнктів]
pol(F, u) = -1 ⇒ кодується тільки імплікація ((xᵤ₁ ⊙ᵤ xᵤ₂) → xᵤ)     [обернена імплікація]
pol(F, u) = 0  ⇒ кодується повна еквівалентність (xᵤ ↔ (xᵤ₁ ⊙ᵤ xᵤ₂))   [двостороннє кодування]
```

Збереження еквізатисфіабельності у кодуванні Плейстеда-Ґрінбаума випливає з властивості монотонності булевих функцій: збільшення значення позитивно вхідної змінної не може зменшити значення всієї формули. Це кодування зменшує загальну кількість КНФ-диз'юнктів у монотонних формулах (які містять лише AND та OR) майже вдвічі порівняно з базовим перетворенням Цейтіна.
