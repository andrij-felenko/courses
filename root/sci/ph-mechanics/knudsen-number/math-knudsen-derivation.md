# 🧮 Математичне виведення серединного вільного пробігу та коригування Нав'є-Стокса

Цей математичний аналіз виводить формулу серединного вільного пробігу молекул із кінетичної теорії Больцмана, зводить граничні умови ковзання Максвелла та доводить співвідношення фон Кармана між числами Кнудсена, Маха й Рейнольдса.

## 1. Геометрія молекулярних зіткнень і серединний вільний пробіг

Розглянемо газ як сукупність твердих пружних сфер радіуса `r_m` (діаметром `d = 2·r_m`) та числовою концентрацією `n = N / V` частинок в одиниці об'єму.

Коли молекула рухається зі швидкістю `v` відносно інших частинок, вона "замітає" в просторі циліндр ефективного перерізу. Зіткнення відбудеться з будь-якою іншою молекулою, центр якої опиниться на відстані, меншій за `d` від траєкторії центру нашої молекули.

Ефективний переріз зіткнення `σ` дорівнює площі круга радіуса `d`:

```
σ  =  π·d²
```

За час `Δt` молекула долає шлях `Δs = v·Δt` і замитає об'єм `ΔV = σ·Δs = π·d²·v·Δt`. Кількість молекул у цьому об'ємі визначає кількість зіткнень `N_coll`:

```
N_coll  =  n·ΔV  =  n·π·d²·v·Δt
```

Проте в реальному газі всі інші молекули також перебувають у хаотичному тепловому русі. Для врахування відносного руху слід брати серединну відносну швидкість `v_rel`. Для максвеллівського розподілу молекул за швидкостями відношення серединної відносної швидкості до серединної теплової швидкості `v_avg` становить строго `√2`:

```
v_rel  =  √2 · v_avg

v_avg  =  √(8·k_B·T / (π·m))      [середня теплова швидкість]
```

Отже, частота зіткнень однієї молекули `Z` (кількість зіткнень за 1 секунду) дорівнює:

```
Z  =  N_coll / Δt  =  √2 · π · d² · n · v_avg
```

Серединний вільний пробіг `λ` — це середня відстань, яку молекула долає між двома послідовними зіткненнями. Вона дорівнює середній швидкості `v_avg`, поділеній на частоту зіткнень `Z`:

```
λ  =  v_avg / Z
   =  v_avg / (√2 · π · d² · n · v_avg)
   =  1 / (√2 · π · d² · n)          [освітня формула пробігу]
```

Підставимо рівняння стану ідеального газу `P = n·k_B·T` (де `k_B = 1.38065×10⁻²³ Дж/К` — стала Больцмана, `P` — тиск, `T` — абсолютна температура):

```
n  =  P / (k_B·T)

λ  =  (k_B·T) / (√2 · π · d² · P)     [залежність від тиску й температури]
```

Звідси чітко видно: серединний вільний пробіг `λ` прямо пропорційний абсолютній температурі `T` та обернено пропорційний тиску `P` і квадрату діаметра молекули `d²`.

### Зв'язок із динамічною в'язкістю `μ`

Зі спрощеної кінетичної теорії переносу імпульсу динамічна в'язкість газу `μ` пов'язана з пробігом `λ`, густиною `ρ = n·m` та тепловою швидкістю `v_avg` співвідношенням:

```
μ  ≈  (1/3) · ρ · v_avg · λ
```

Точне математичне виведення за методом Чепмена-Енскога (для потенціалу твердих сфер) дає точніший числовий коефіцієнт:

```
μ  =  (5·π / 32) · ρ · v_avg · λ  ≈  0.499 · ρ · v_avg · λ

λ  =  (μ / P) · √( (π·k_B·T) / (2·m) )  =  (μ / P) · √( (π·R_gas·T) / (2·M) )
```

Ця формула є фундаментальним мостом між макроскопічним вимірюванням в'язкості `μ` та мікроскопічним серединним вільним пробігом `λ`.

## 2. Ієрархія Чепмена-Енскога та розклад рівняння Больцмана

Повна функція розподілу молекул за координатами `x` та швидкостями `v` у фазовому просторі `f(x, v, t)` підпорядковується переносному рівнянню Больцмана:

```
(∂f / ∂t) + v · ∇_x f + F_ext · ∇_v f  =  C(f)
```

де `C(f)` — інтеграл зіткнень Больцмана, що описує зміну розподілу внаслідок парних молекулярних зіткнень.

Зведемо рівняння Больцмана до безрозмірного вигляду, вибравши характерну довжину `L`, характерну швидкість `v₀` та частоту зіткнень `ν_coll = v_avg / λ`:

```
x̄  =  x / L
v̄  =  v / v₀
t̄  =  t / (L / v₀)
C̄  =  C / ν_coll
```

Підстановка безрозмірних змінних дає:

```
(v₀ / L) · [ (∂f̄ / ∂t̄) + v̄ · ∇̄_x f̄ ]  =  (v_avg / λ) · C̄(f̄)

(λ / L) · (v₀ / v_avg) · [ (∂f̄ / ∂t̄) + v̄ · ∇̄_x f̄ ]  =  C̄(f̄)
```

Позначивши `Kn = λ / L` та вважаючи `v₀ ≈ v_avg`, отримуємо фундаментальне безрозмірне рівняння Больцмана:

```
Kn · [ (∂f̄ / ∂t̄) + v̄ · ∇̄_x f̄ ]  =  C̄(f̄)
```

Коефіцієнт при операторі диференціювання дорівнює числу Кнудсена `Kn`! Саме це рівняння демонструє математичний зміст числа Кнудсена як параметра малого або великого збурення:

1. **Грань `Kn → 0` (Нульове наближення):**
   Оператор конвекції зникає, залишається `C̄(f̄) = 0`. Єдиним розв'язком цього рівняння є локально-рівноважний максвеллівський розподіл `f^(0)`. Інтегрування `f^(0)` за швидкостями дає **ідеальні рівняння Ейлера** для стисливого газу без в'язкості та теплопровідності.

2. **Перше наближення Чепмена-Енскога (`Kn ≪ 1`):**
   Розкладаємо функцію розподілу в ряд за малим параметром `Kn`:
   ```
   f  =  f^(0) + Kn · f^(1) + Kn² · f^(2) + ...
   ```
   Підстановка `f^(1)` у рівняння Больцмана виводить лінійний закон тензора в'язких напружень Нав'є-Стокса `τ_ij` та закон теплопровідності Фур'є `q`:
   ```
   τ_ij  =  μ · ( (∂v_i / ∂x_j) + (∂v_j / ∂x_i) - (2/3)·δ_ij·div(v) )
   q     =  -k · ∇T
   ```
   Отже, рівняння Нав'є-Стокса є строго першим порядком малого розкладу Больцмана за числом Кнудсена `Kn`!

3. **Друге наближення (`Kn ~ 0.1`):**
   Врахування доданків `Kn² · f^(2)` дає **рівняння Бернетта** (Burnett equations). З'являються нелінійні градієнти швидкості й температури в тензорі напружень (термонапруження та нелінійне зсувне тертя).

4. **Грань `Kn → ∞` (Беззіткнувальний режим):**
   Інтеграл зіткнень зникає `C̄(f̄) → 0`. Рівняння стає лінійним переносним рівнянням Власова без правого боку:
   ```
   (∂f / ∂t) + v · ∇_x f  =  0
   ```
   Траєкторії частинок стають прямими лініями, а розв'язок визначається виключно граничними умовами на стінках.

## 3. Математична модель граничних умов Максвелла

Біля твердої стінки існує кінетичний шар (шар Кнудсена) товщиною порядку `λ`. Усередині цього шару функція розподілу молекул принципово анізотропна: молекули, що летять до стінки, несуть імпульс із об'єму газу, а молекули, що відлітають від стінки, мають імпульс, сформований взаємодією з атомами твердого тіла.

Джеймс Клерк Максвелл (1879) запропонував феноменологічну модель, за якою частка `σ_v` молекул відбивається від стінки **дифузно** (з повною аккомодацією імпульсу та температури стінки `T_w`), а решта частка `(1 - σ_v)` відбивається **дзеркально** (зі збереженням дотичної швидкості):

```
σ_v    [аккомодаційний коефіцієнт дотичного імпульсу, 0 ≤ σ_v ≤ 1]
```

Збалансувавши потік дотичного імпульсу молекул на границі шару Кнудсена, отримуємо **граничну умову ковзання першого порядку Максвелла**:

```
v_slip  =  v_gas|_wall - v_wall
        =  ( (2 - σ_v) / σ_v ) · λ · ( ∂v / ∂n )|_wall
```

аналогічно для стрибка температури `T_jump`:

```
T_jump  =  T_gas|_wall - T_wall
        =  ( (2 - σ_T) / σ_T ) · ( (2·γ) / (γ + 1) ) · (λ / Pr) · ( ∂T / ∂n )|_wall

γ       =  C_p / C_v     [показник адіабати газу]
Pr      =  μ·C_p / k     [число Прандтля, для повітря Pr ≈ 0.71]
σ_T                      [коефіцієнт термічної аккомодації]
```

Якщо стінка абсолютно шорстка або брудна (`σ_v = 1`), швидкість ковзання дорівнює `v_slip = λ · (∂v / ∂n)|_wall`. Оскільки `λ = Kn · L`, відносне ковзання прямо пропорційне числу Кнудсена:

```
v_slip / v₀  ~  Kn · ( ∂(v/v₀) / ∂(n/L) )
```

Коли `Kn < 0.01`, ковзання `v_slip` становить менше 1% від характерної швидкості й ним нехтують (`v_slip = 0` — класична умова прилипання). Коли `0.01 ≤ Kn < 0.1`, `v_slip` стає відчутним і його обов'язково підставляють як граничну умову в рівняння Нав'є-Стокса.

## 4. Математичне доведення співвідношення фон Кармана

Покажемо строго, як число Кнудсена `Kn` виражається через відношення числа Маха `Ma` до числа Рейнольдса `Re`.

За означенням:

```
Re  =  (ρ · v · L) / μ               [число Рейнольдса]
Ma  =  v / a                         [число Маха]
Kn  =  λ / L                         [число Кнудсена]
```

де `a` — швидкість звуку в ідеальному газі:

```
a  =  √(γ · R_gas · T)  =  √(γ · k_B · T / m)
```

З виведеної раніше формули кінетичної теорії виразимо динамічну в'язкість `μ` через серединний вільний пробіг `λ`:

```
μ  =  (1/2) · ρ · v_avg · λ

v_avg  =  √( (8·k_B·T) / (π·m) )  =  √( (8·R_gas·T) / π )
```

Виразимо швидкість звуку `a` через середню теплову швидкість `v_avg`:

```
a  =  √(γ·R_gas·T)  =  v_avg · √( (γ·π) / 8 )
```

Тепер обчислимо відношення `Ma / Re`:

```
Ma / Re  =  (v / a) / ( (ρ · v · L) / μ )
         =  μ / (a · ρ · L)            [швидкість v скоротилася!]
```

Підставимо у вираз вирази для `μ` та `a`:

```
Ma / Re  =  [ (1/2) · ρ · v_avg · λ ]  /  [ v_avg · √( (γ·π) / 8 ) · ρ · L ]
```

Скоротимо густину `ρ` та теплову швидкість `v_avg`:

```
Ma / Re  =  (λ / L)  ·  [ (1/2) / √( (γ·π) / 8 ) ]
         =  Kn · [ 1 / (2 · √(γ·π / 8)) ]
         =  Kn · [ 1 / √(4 · γ·π / 8) ]
         =  Kn · [ 1 / √( (γ·π) / 2 ) ]
```

Помноживши обидві частини на `√(γ·π / 2)`, отримуємо точну співвідношення фон Кармана:

```
Kn  =  (Ma / Re) · √( (γ·π) / 2 )     [співвідношення фон Кармана]
```

Для двоатомного газу (повітря, `γ = 1.4`):

```
√( (1.4 · π) / 2 )  =  √( 0.7 · π )  ≈  1.483

Kn  ≈  1.48 · (Ma / Re)
```

### Фізичні наслідки співвідношення фон Кармана

Ця формула зв'язує три головні безрозмірні параметри газової динаміки:
1. **Зростання швидкості (високий Мах `Ma`):** Якщо апарат летить із гіперзвуковою швидкістю (`Ma = 15-20`), число Кнудсена `Kn` зростає в 15-20 разів порівняно з дозвуковим потоком при тому самому `Re`.
2. **Розрідження середовища (низький Рейнольдс `Re`):** На висоті 80 км густина повітря `ρ` мала, тому `Re` дуже мале. Навіть для великого космічного корабля розміром `L = 5 м` число Кнудсена сягає `Kn > 0.1` (перехідний режим).
3. **Мікромасштаби (мале `L`):** У мікроканалах при нормальному тиску та низькій швидкості `Re ≪ 1`, але через крихітний розмір `L` відношення `Ma / Re` дає помітне число Кнудсена `Kn ~ 0.05` (режим ковзання).
