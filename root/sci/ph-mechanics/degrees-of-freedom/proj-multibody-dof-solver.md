# ⚙️ Чисельний розв'язувач зв'язків та сингулярностей просторових механізмів

Чисельний аналіз кінематики просторових механізмів вимагає точного математичного апарату для обчислення просторових конфігурацій, швидкостей, геометричних обмежень та особливих положень рухомих ланок. Якщо відкритий кінематичний ланцюг класичного серійного маніпулятора має прозору топологічну структуру, де кількість ступенів вільності дорівнює сумі рухливостей окремих шарнірів, то замкнені контури та просторові паралельні платформи накладають систему жорстких нелінійних зв'язків. У таких системах кількість фактичних ступенів вільності визначається не простою арифметичною сумою чи наївним відніманням обмежень, а рангом диференціальної матриці зв'язків — матриці Якобі обмежень. Раптова зміна рангу цієї матриці зумовлює виникнення кінематичних сингулярностей, у яких механізм або втрачає здатність рухатися за певними просторовими напрямками, або, навпаки, отримує неконтрольовану миттєву рухливість, стаючи нестійким.

Нижче розібрано повну теоретичну модель, геометричний апарат алгебр Лі, дуальних кватерніонів та теорії гвинтів, чисельні алгоритми лінійної алгебри, прикладні інженерні дослідження серійних і паралельних систем, а також програмне втілення кінематичного розв'язувача просторових багатоланкових систем мовами C99 та C++20. Розв'язувач реалізує алгоритми прямої кінематики, формує просторову матрицю Якобі маніпулятора, будує градієнтну матрицю зв'язків для замкнених контурів, проводить спектральний аналіз за допомогою сингулярного розкладу (SVD), визначає точну розмірність простору рухливості, оцінює віддаленість від особливих конфігурацій за мірою маніпулятивності Йошікави та числом обумовленості, а також здійснює регуляризоване обернене кінематичне перетворення методом демпфованих найменших квадратів (DLS) із багаторівневою проєкцією на нуль-простір зв'язків.

## 1. Геометричні основи просторового руху твердого тіла та групи Лі

Кінематична система складається з множини `N` абсолютно твердих тіл, з'єднаних кінематичними парами (шарнірами). Положення кожного вільного твердого тіла в тривимірному евклідовому просторі відносно нерухомої інерціальної системи відліку `{W}` (World frame) повністю визначається шістьма параметрами: вектором зміщення центра мас `r = (x, y, z)ᵀ ∈ ℝ³` та спеціальною ортогональною матрицею орієнтації `R ∈ SO(3)`, яка задовольняє умови ортогональності `Rᵀ R = I₃` та унімодулярності `det(R) = +1`.

Сукупність усіх можливих положень та орієнтацій твердого тіла утворює спеціальну групу Лі евклідових перетворень `SE(3) = ℝ³ ⋊ SO(3)`. Елемент цієї групи представляється однорідною матрицею перетворення розмірності `4×4`:

```
T = | R   p |
    | 0   1 |
```

де `R ∈ SO(3)` описує орієнтацію локальної системи координат тіла `{B}` відносно базової системи `{W}`, а `p ∈ ℝ³` задає координати початку системи `{B}` у базисі `{W}`.

### Конфігураційний простір та вектор узагальнених координат

Для механізму з `n` шарнірами конфігурація системи однозначно задається вектором узагальнених координат `q = (q₁, q₂, …, q_n)ᵀ ∈ 𝒬`, де `𝒬` — гладке `n`-вимірне конфігураційне многовиддя. Для обертальних шарнірів (Revolute joints) узагальненими координатами є кути повороту `θ_i ∈ (-π, π] ≃ S¹`, а для поступальних шарнірів (Prismatic joints) — лінійні зміщення `d_i ∈ ℝ`. Отже, для відкритого маніпулятора з `n` обертальними шарнірами конфігураційний простір є `n`-вимірним тором `𝒬 = 𝕋ⁿ = S¹ × S¹ × … × S¹`.

Вектор узагальнених швидкостей `q̇ = (q̇₁, q̇₂, …, q̇_n)ᵀ ∈ T_q 𝒬` належить дотичному простору до конфігураційного многовиддя в точці `q`. Дотичний простір `T_q 𝒬` ізоморфний простору `ℝⁿ`.

### Пряма кінематика та ланцюговий добуток перетворень

Пряма кінематична задача полягає у знаходженні просторового положення та орієнтації кінцевого робочого органа (схоплювача або характерної точки інструменту) за відомим вектором узагальнених координат `q`. У послідовному кінематичному ланцюзі, побудованому з ланок `0, 1, 2, …, n`, де ланка `0` — нерухома станина, однорідна матриця кінцевого органа `T₀ⁿ(q)` обчислюється як послідовний ланцюговий добуток локальних однорідних матриць перетворення між суміжними системами координат:

```
T₀ⁿ(q) = T₀¹(q₁) · T₁²(q₂) · T₂³(q₃) · … · T_{n-1}ⁿ(q_n)
```

Кожна локальна матриця перетворення `T_{i-1}ⁱ(q_i)` враховує як постійну геометрію ланки (довжину, зсув, кути нахилу), так і змінне положення шарніра `q_i`.

Для обертального шарніра `i`, вісь якого збігається з одиничним вектором `z_{i-1}`, поворот на кут `q_i = θ_i` задається формулою Родрігеса для матриці обертання:

```
Rot(z, θ_i) = | cos(θ_i)   −sin(θ_i)   0 |
              | sin(θ_i)    cos(θ_i)   0 |
              |    0           0       1 |
```

Тоді однорідне перетворення шарніра складається з відносного обертання та постійного конструктивного зміщення `T_offset`:

```
T_{i-1}ⁱ(q_i) = T_offset · | Rot(z, θ_i)   0 |
                           |      0        1 |
```

Для поступального шарніра поворот відсутній, а координата `q_i = d_i` задає лінійний зсув уздовж осі `z_{i-1}`:

```
T_{i-1}ⁱ(q_i) = T_offset · | I₃   (0, 0, d_i)ᵀ |
                           | 0          1      |
```

## 2. Теорія гвинтів та формула добутку експонент (PoE)

Класичний опис кінематики за допомогою параметрів Деневіта-Хартенберга (DH) має суттєвий математичний недолік: при наявності паралельних або майже паралельних осей суміжних шарнірів відстань між осями або положення спільного перпендикуляра стає чисельно нестійким, що створює штучні сингулярності параметризації в алгоритмах калібрування.

Сучасна теоретична кінематика базується на теорії гвинтів (Screw Theory) та формулі добутку експонент (Product of Exponentials, PoE). Відповідно до теореми Шаля-Моцці, будь-яке просторове переміщення твердого тіла в просторі еквівалентне гвинтовому руху — повороту на кут `θ` навколо деякої прямої (осі гвинта) з одночасним поступальним зсувом уздовж цієї ж осі на величину `h · θ`, де `h ∈ ℝ` — крок гвинта (pitch).

Гвинт задається одиничним просторовим вектором — твістом (гвинтовими координатами Плюккера) `𝒮 = (ωᵀ, vᵀ)ᵀ ∈ ℝ⁶`.
- Для чисто обертального шарніра навколо осі, що проходить через точку `p` у напрямку одиничного вектора `ω` (`‖ω‖ = 1`):
  ```
  𝒮 = |    ω    |
      | −ω × p  |
  ```
  де `v = −ω × p = p × ω` задає лінійну швидкість точки початку координат під час обертання навколо осі гвинта.
- Для чисто поступального шарніра вздовж напрямку `v` (`‖v‖ = 1`):
  ```
  𝒮 = | 0 |
      | v |
  ```

### Експоненційне відображення алгебри Лі на групу Лі

Кожному гвинту `𝒮 = (ωᵀ, vᵀ)ᵀ` відповідає кососиметричний матричний елемент алгебри Лі `[𝒮] ∈ 𝔰𝔢(3)` розмірності `4×4`:

```
[𝒮] = | [ω]   v |
      |  0    0 |
```

де `[ω] ∈ 𝔰𝔬(3)` — кососиметрична матриця векторного добутку:

```
[ω] = |   0   −ω_z   ω_y |
      |  ω_z    0   −ω_x |
      | −ω_y   ω_x    0  |
```

Експоненційне відображення матриці `[𝒮] θ` обчислюється аналітично через узагальнену формулу Родрігеса для `SE(3)`:

```
e^{[𝒮] θ} = | e^{[ω] θ}   G(θ) · v |
            |    0           1     |
```

де:
```
e^{[ω] θ} = I₃ + sin(θ) [ω] + (1 − cos(θ)) [ω]²
G(θ) = I₃ θ + (1 − cos(θ)) [ω] + (θ − sin(θ)) [ω]²
```

Тоді пряма кінематика будь-якого відкритого маніпулятора з `n` шарнірами виражається глобальною формулою добутку експонент:

```
T(q) = e^{[𝒮₁] q₁} · e^{[𝒮₂] q₂} · … · e^{[𝒮_n] q_n} · M
```

де `M = T(0) ∈ SE(3)` — матриця початкового положення кінцевого органа при нульових кутах шарнірів `q = 0`, а `𝒮_i` — постійні гвинти осей шарнірів, визначені у базовій системі координат у нульовій позі. Формула PoE є абсолютно гладкою, глобальною та повністю вільною від сингулярностей визначення координатних осей.

## 3. Дуальні кватерніони та безсингулярна кінематика

Альтернативним високоефективним методом представлення просторових рухів є одиничні дуальні кватерніони (Unit Dual Quaternions). Дуальний кватерніон `q̂` складається з дійсної частини `q_r` (яка кодує обертання `SO(3)`) та дуальної частини `q_d` (яка кодує поступальний зсув):

```
q̂ = q_r + ε · q_d,    ε² = 0,    ε ≠ 0
```

де `q_r = (cos(θ/2), sin(θ/2) · u) ∈ ℍ` — одиничний кватерніон обертання навколо осі `u`, а `q_d = 1/2 · p_quat · q_r`, де `p_quat = (0, p_x, p_y, p_z)` — кватерніон зміщення.

Умова унітарності одиничного дуального кватерніона вимагає:
```
q̂ · q̂* = 1  ⇔  ‖q_r‖² = 1  та  q_r · q_d* + q_d · q_r* = 0
```

Переваги дуальних кватерніонів над матрицями `4×4`:
1. **Компактність пам'яті:** 8 чисел з плаваючою комою замість 16 елементів матриці (економія 50% пам'яті та кеш-ліній процесора).
2. **Чисельна перенормалізація:** усунення похибок округлення вимагає нормалізації двох 4-векторів, що на порядок швидше за ортогоналізацію матриць Грама-Шмідта.
3. **Гладка просторова інтерполяція:** алгоритм ScLERP (Screw Linear Interpolation) здійснює природне гвинтове інтерполювання між двома позами твердого тіла вздовж геодезичної лінії на многовидді `SE(3)`.

## 4. Диференціальна кінематика та геометричний Якобіан

Просторовий рух кінцевого органа маніпулятора описується шестивимірним вектором швидкостей — просторовим твістом (twist) `𝒱_e ∈ ℝ⁶`, що об'єднує вектор миттєвої кутової швидкості `ω_e ∈ ℝ³` та вектор лінійної швидкості характерної точки `v_e ∈ ℝ³`:

```
𝒱_e = | ω_e |
      | v_e |
```

Вектор просторового твісту належить алгебрі Лі `𝔰𝔢(3)` спеціальної групи евклідових перетворень. Диференціальний зв'язок між швидкістю зміни узагальнених координат `q̇` та твістом робочого органа `𝒱_e` задається лінійним відображенням:

```
𝒱_e = J(q) · q̇
```

де `J(q) ∈ ℝ⁶ˣⁿ` — геометрична матриця Якобі маніпулятора (або просторовий Якобіан).

### Побудова стовпчиків Якобіана за векторним методом

Матриця Якобі складається з `n` стовпчиків, кожен з яких описує внесок одиничної швидкості відповідного шарніра `q̇_i = 1` у загальний просторовий рух кінцевої ланки при нерухомих решті шарнірів:

```
J(q) = [ J₁(q)   J₂(q)   …   J_n(q) ]
```

Нехай `T₀ⁱ(q)` — матриця прямої кінематики від базової системи координат до системи `i`-го шарніра. Позначимо:
- `p_e ∈ ℝ³` — радіус-вектор кінцевої робочої точки маніпулятора у базовій системі відліку;
- `p_{i-1} ∈ ℝ³` — радіус-вектор початку системи координат `i`-го шарніра у базовій системі відліку;
- `z_{i-1} ∈ ℝ³` — одиничний напрямний вектор осі дії `i`-го шарніра, виражений у базовій системі координат: `z_{i-1} = R₀^{i-1} · (0, 0, 1)ᵀ`.

Структура `i`-го стовпчика матриці Якобі `J_i(q)` залежить від фізичного типу кінематичної пари:

1. **Для обертального шарніра (Revolute joint):**
   Обертання ланки навколо осі `z_{i-1}` з одиничною кутовою швидкістю створює вектор кутової швидкості `ω_i = z_{i-1}` та спричиняє лінійну швидкість кінцевої точки `v_i = z_{i-1} × (p_e − p_{i-1})`. Відповідно:
   ```
   J_i(q) = |       z_{i-1}       |
            | z_{i-1} × (p_e − p_{i-1}) |
   ```

2. **Для поступального шарніра (Prismatic joint):**
   Поступальне переміщення вздовж осі `z_{i-1}` з одиничною швидкістю створює чисту лінійну швидкість `v_i = z_{i-1}` і не генерує кутової швидкості (`ω_i = 0`):
   ```
   J_i(q) = |    0    |
            | z_{i-1} |
   ```

Ця конструкція забезпечує точне обчислення геометричного Якобіана у світовій системі координат без необхідності чисельного диференціювання тригонометричних функцій скінченними різницями, що гарантує максимальну чисельну точність та швидкість роботи алгоритму.

### Геометричний проти аналітичного Якобіана

Слід чітко розрізняти геометричний Якобіан `J(q)` та аналітичний Якобіан `J_A(q)`. Аналітичний Якобіан визначається як пряма матриця часткових похідних вектора робочих координат `x = (pᵀ, φᵀ)ᵀ ∈ ℝ⁶`, де `φ = (roll, pitch, yaw)ᵀ` — кути Ейлера:

```
ẋ = | ṗ | = J_A(q) · q̇
    | φ̇ |
```

Зв'язок між миттєвою кутовою швидкістю `ω` та похідними кутів Ейлера `φ̇` є нелінійним і залежить від обраної послідовності поворотів. Для послідовності Z-Y-X (yaw-pitch-roll `ψ, θ, ϕ`):

```
ω = T(φ) · φ̇ = | 1    0          −sin(θ)    | | ϕ̇ |
               | 0   cos(ϕ)   sin(ϕ) cos(θ) | | θ̇ |
               | 0  −sin(ϕ)   cos(ϕ) cos(θ) | | ψ̇ |
```

Матриця перетворення `T(φ)` стає незворотною (виродженою) при `cos(θ) = 0`, тобто при `θ = ±π/2` (явище замка кардана / gimbal lock). У цій точці аналітичний Якобіан втрачає ранг через дефект математичної параметризації кутів, тоді як реальний маніпулятор залишається повністю працездатним і його геометричний Якобіан `J(q)` зберігає повний ранг. Саме тому в надійних промислових розв'язувачах кінематики використовується виключно геометричний Якобіан на основі просторового твісту `𝒱_e = (ωᵀ, vᵀ)ᵀ`.

## 5. Геометричні зв'язки, надлишковість та рухливість замкнених контурів

Розглянемо систему, що містить замкнені кінематичні ланцюги (наприклад, плоский чотириланковик, дельта-робот або паралельну платформу Стюарта). У таких системах рух ланок обмежений системою векторних рівнянь замкненості геометричних контурів:

```
Φ(q) = 0,    Φ: ℝⁿ → ℝᵐ
```

де `m` — загальна кількість незалежних скалярних рівнянь геометричних зв'язків.

Диференціюючи рівняння зв'язків за часом, отримуємо співвідношення для дозволених швидкостей системи:

```
d/dt [ Φ(q) ] = (∂Φ / ∂q) · q̇ = G(q) · q̇ = 0
```

Матриця `G(q) = ∂Φ / ∂q ∈ ℝᵐˣⁿ` називається матрицею Якобі обмежень (або градієнтною матрицею зв'язків).

### Теорема про ранг та простір вільного руху

Миттєвий простір дозволених швидкостей механізму `𝒯_q 𝒬` утворює лінійний підпростір простору `ℝⁿ`, який збігається з ядром (нуль-простором) матриці Якобі зв'язків:

```
𝒯_q 𝒬 = ker(G(q)) = { q̇ ∈ ℝⁿ | G(q) · q̇ = 0 }
```

Фактична кількість миттєвих ступенів вільності механізму (його просторова рухливість `DoF`) дорівнює розмірності цього ядра:

```
DoF(q) = dim(ker(G(q))) = n − rank(G(q))
```

Якщо всі `m` рівнянь є функціонально незалежними у точці `q`, то `rank(G(q)) = m`, і рухливість механізму становить `DoF = n - m`. Це відповідає класичному критерію Чебишова-Грюблера-Куцбаха.

Однак у реальних просторових конструкціях виникають особливі конфігурації, де ранг матриці `G(q)` зазнає стрибкоподібного зменшення:

```
rank(G(q)) = r < m  ⇒  DoF(q) = n − r > n − m
```

У такій точці механізм раптово отримує додаткові ступені вільності (парадоксальна рухливість). Навпаки, якщо при фіксованих вхідних приводах матриця зв'язків втрачає ранг за керованими координатами, механізм потрапляє у сингулярність паралельного типу, де кінцевий орган втрачає жорсткість і може неконтрольовано зміщуватися навіть при заблокованих двигунах.

### Класифікація сингулярностей паралельних механізмів за Госселіном та Енджелсом

Для паралельних маніпуляторів диференціальні рівняння кінематики пов'язують швидкості активних приводів `q̇_act ∈ ℝⁿ` та твіст рухомої платформи `𝒱_p ∈ ℝ⁶`:

```
J_dir(q) · 𝒱_p = J_inv(q) · q̇_act
```

де `J_dir ∈ ℝ⁶ˣ⁶` — прямий Якобіан платформи, а `J_inv ∈ ℝ⁶ˣⁿ` — зворотний Якобіан приводних ланцюгів. Залежно від виродження цих матриць виникають три фундаментальні класи сингулярностей:

1. **Сингулярності I типу (граничні сингулярності, `det(J_inv) = 0`):**
   Виникають на краю робочої зони, коли один або кілька приводних ланцюгів повністю випрямляються. Платформа втрачає здатність рухатися у певному просторовому напрямку.
2. **Сингулярності II типу (паралельні сингулярності, `det(J_dir) = 0`):**
   Виникають всередині робочого простору при певній орієнтації ланок. Платформа набуває паразитної рухливості при зафіксованих приводах (`q̇_act = 0`, але `𝒱_p ≠ 0`). При цьому зусилля в приводах прямують до нескінченності, що загрожує механічною руйнацією.
3. **Сингулярності III типу (комбіновані сингулярності, `det(J_dir) = det(J_inv) = 0`):**
   Архітектурні сингулярності, де водночас виникає неконтрольована рухливість платформи та блокування окремих напрямків швидкості.

## 6. Неголономні системи та диференціальні зв'язки Пфаффа

Важливим класом механічних систем, рухливість яких не описується простим інтегруванням геометричних координат, є неголономні системи (мобільні колісні роботи, кулі, що котяться, багатозвенні автопоїзди).

Зв'язки у неголономних системах задаються диференціальними формами Пфаффа на швидкості:

```
A(q) · q̇ = 0,    A(q) ∈ ℝ^{k × n}
```

які принципово не можуть бути проінтегровані до вигляду `Φ(q) = 0`.

### Теорема Фробеніуса та дужки Лі

Нехай простір дозволених швидкостей натягнутий на базисні векторні поля `g₁(q), g₂(q), …, g_m(q)` (`m = n - k`):

```
q̇ = ∑_{i=1}^m u_i · g_i(q)
```

За теоремою Фробеніуса розподіл `Δ = span{g₁, …, g_m}` є інтегровним (тобто відповідає голономним зв'язкам) тоді й лише тоді, коли він є інволютивним — замкненим відносно операції дужки Лі (комутатора векторних полів):

```
[g_i, g_j](q) = (∂g_j / ∂q) · g_i(q) − (∂g_i / ∂q) · g_j(q) ∈ Δ
```

Якщо комутатори векторних полів виходять за межі початкового розподілу `Δ`, система є неголономною. Відповідно до теореми Рашевського-Чоу, якщо послідовні дужки Лі довільного порядку разом із початковими полями породжують увесь дотичний простір `ℝⁿ`, система є повністю керованою: незважаючи на те, що миттєва кількість ступенів вільності дорівнює `m < n`, робот здатний досягти будь-якої точки `n`-вимірного конфігураційного простору шляхом виконання періодичних циклічних рухів (маневрів).

## 7. Сингулярний розклад (SVD) та діагностика кінематичних сингулярностей

Обчислення рангу прямокутної матриці за допомогою класичного методу Гауса з фіксованим порогом є чисельно нестійким через помилки округлення чисел з рухомою комою. Фундаментальним еталоном для аналізу рангу, спектрального складу та просторової геометрії лінійних операторів є сингулярний розклад (Singular Value Decomposition).

Для довільної дійсної матриці `A ∈ ℝᵐˣⁿ` (де `A` може бути матрицею Якобі маніпулятора `J` або матрицею зв'язків `G`) існують такі ортогональні матриці `U ∈ ℝᵐˣᵐ` (`Uᵀ U = I_m`) та `V ∈ ℝⁿˣⁿ` (`Vᵀ V = I_n`), що:

```
A = U · Σ · Vᵀ
```

де `Σ ∈ ℝᵐˣⁿ` — діагональна матриця, на головній діагоналі якої розташовані невід'ємні сингулярні числа, впорядковані за незростанням:

```
σ₁ ≥ σ₂ ≥ … ≥ σ_k ≥ 0,    k = min(m, n)
```

Геометричний зміст розкладу полягає в тому, що матриця `A` перетворює одиничну гіперсферу з простору входів `ℝⁿ` на гіпереліпсоїд у просторі виходів `ℝᵐ`. Довжини півосей цього еліпсоїда дорівнюють сингулярним числам `σ_i`, а просторові напрямки головних осей задаються стовпчиками матриці `U = [ u₁  u₂  …  u_m ]`. Стовпчики матриці `V = [ v₁  v₂  …  v_n ]` задають ортогональні напрямки у просторі входів, що відображаються у відповідні півосі еліпсоїда.

```
A · v_i = σ_i · u_i,    i = 1, …, k
```

### Чисельний ранг та теорема Еккарта-Янга

Через наявність чисельного шуму нульові сингулярні числа на комп'ютері набувають малих ненульових значень порядку `10⁻¹⁵`…`10⁻¹⁶`. Чисельний ранг матриці `rank_ε(A)` визначається як кількість сингулярних чисел, що перевищують строго розрахований адаптивний поріг:

```
ε_tol = max(m, n) · σ₁ · ε_mach
```

де `ε_mach` — машинне епсилон для чисел типу `double` (у стандарті IEEE 754 `ε_mach ≈ 2.2204 × 10⁻¹⁶`).

Відповідно до фундаментальної теореми Еккарта-Янга-Мірського, відстань у спектральній нормі від поточної матриці Якобі `J` до найближчої виродженої матриці меншого рангу дорівнює найменшому сингулярному числу:

```
dist_2(J, Singular) = min_{rank(B) < r} ‖ J − B ‖₂ = σ_r(J)
```

Це означає, що величина `σ_min(J)` є абсолютно точним показником евклідової відстані конфігурації робота до найближчої кінематичної сингулярності.

Якщо `r = rank_ε(A)`, то:
- Базис образу матриці (простору досяжних рухів `Im(A)`): вектори `{ u₁, u₂, …, u_r }`;
- Базис ядра матриці (простору нульового руху `ker(A)`): вектори `{ v_{r+1}, v_{r+2}, …, v_n }`.

### Двоїстість швидкостей та статичних зусиль у сингулярних конфігураціях

Кінематичний аналіз виродження рангу матриці Якобі має фундаментальну двоїстість зі статикою сил та моментів через принцип можливих робіт (Principle of Virtual Work). Якщо кінцевий робочий орган взаємодіє з навколишнім середовищем і прикладає просторовий узагальнений силомомент (wrench) `ℱ_e = (m_eᵀ, f_eᵀ)ᵀ ∈ ℝ⁶`, то статично еквівалентний вектор шарнірних моментів приводів `τ ∈ ℝⁿ` визначається транспонованою матрицею Якобі:

```
τ = J(q)ᵀ · ℱ_e
```

Геометричний розклад простору виходів `ℝᵐ` на підпростори досяжних швидкостей `Im(J)` та нездійсненних напрямків руху `Im(J)ᗮ = ker(Jᵀ)` розкриває фізичну природу сингулярності:
- Якщо маніпулятор перебуває в сингулярній конфігурації, де стовпчики `J(q)` втрачають лінійну незалежність, існує непорожній підпростір `ker(Jᵀ) = { ℱ ∈ ℝ⁶ | Jᵀ ℱ = 0 }` розмірності `m − rank(J)`.
- Будь-яка зовнішня сила або момент `ℱ_sing ∈ ker(Jᵀ)` сприймається безпосередньо жорсткою механічною структурою ланок і підшипників, не створюючи жодного навантаження на приводні двигуни (`τ = 0`). Це явище називається нескінченним механічним виграшем (infinite mechanical advantage) послідовного кінематичного ланцюга.
- Проте зворотним боком цієї статичної жорсткості є повна неможливість згенерувати швидкість кінцевого органа у напрямку вектора `u_sing ∈ ker(Jᵀ)`. Навпаки, у паралельних механізмах у сингулярностях II типу матриця `J_dir` втрачає ранг, що призводить до обнулення опору зовнішнім силам у напрямку втраченого зв'язку, через що зусилля в приводах прямують до нескінченності `‖τ‖ → ∞` при скінченному зовнішньому навантаженні.

### Кількісні критерії близькості до сингулярності

1. **Міра маніпулятивності Йошікави (Yoshikawa manipulability index):**
   Критерій характеризує загальну рухливість механізму у всіх просторових напрямках і пропорційний об'єму еліпсоїда швидкостей:
   ```
   w(q) = √( det( J(q) · J(q)ᵀ ) ) = ∏_{i=1}^{k} σ_i
   ```
   Якщо маніпулятор потрапляє у сингулярне положення, щонайменше одне сингулярне число обнуляється (`σ_min = 0`), об'єм еліпсоїда стає рівним нулю, і `w(q) = 0`.

2. **Число обумовленості (Condition number):**
   Критерій показує ступінь витягнутості еліпсоїда маніпулятивності та неоднорідність просторового руху:
   ```
   κ(J) = σ_max / σ_min = σ₁ / σ_k ∈ [1, ∞)
   ```
   Конфігурація називається ізотропною, якщо `κ(J) = 1` (усі сингулярні числа однакові, еліпсоїд перетворюється на сферу). У сингулярності `σ_min → 0`, тому `κ(J) → ∞`.

## 8. Алгоритм SVD на основі двосторонніх обертань Якобі

Для програмної реалізації без зовнішніх масивних залежностей (таких як LAPACK або Eigen) застосовується класичний двосторонній ітераційний алгоритм Якобі (Two-sided Jacobi SVD). Цей алгоритм має виняткову чисельну точність навіть для матриць із близькими або малими сингулярними числами.

Ідея методу полягає у послідовному застосуванні планарних ортогональних обертань Ґівенса до матриці `A` з метою її повної діагоналізації. На кожній ітерації для кожної пари стовпчиків `(i, j)` обчислюється підматриця Грама `2×2`:

```
a = ∑_{k=1}^m A_{ki}²,    b = ∑_{k=1}^m A_{kj}²,    c = ∑_{k=1}^m A_{ki} A_{kj}
```

Якщо недіагональний елемент `|c| > ε`, обчислюється кут обертання `v`, що обнуляє кореляцію між стовпчиками `i` та `j`:

```
ζ = (b − a) / (2 c)
t = sign(ζ) / ( |ζ| + √(1 + ζ²) )
cos(v) = 1 / √(1 + t²)
sin(v) = t · cos(v)
```

Після цього стовпчики матриці `A` та матриці накопичення переходів `V` оновлюються:

```
A'_{·, i} = cos(v) · A_{·, i} − sin(v) · A_{·, j}
A'_{·, j} = sin(v) · A_{·, i} + cos(v) · A_{·, j}

V'_{·, i} = cos(v) · V_{·, i} − sin(v) · V_{·, j}
V'_{·, j} = sin(v) · V_{·, i} + cos(v) · V_{·, j}
```

Процес ітерується по всіх парах `1 ≤ i < j ≤ n` доти, доки максимальний позадіагональний елемент не стане меншим за машинний поріг `10⁻¹⁴` (зазвичай збіжність досягається за 6–12 циклів). Після завершення ітерацій сингулярні числа дорівнюють евклідовим нормам стовпчиків матриці `A`:

```
σ_i = ‖ A_{·, i} ‖₂,    u_i = A_{·, i} / σ_i
```

## 9. Регуляризована обернена кінематика методом демпфованих найменших квадратів (DLS)

Задача оберненої кінематики на рівні швидкостей вимагає розв'язання лінійного рівняння `J(q) · q̇ = 𝒱_cmd`. Для надлишкових маніпуляторів (`n > 6`) класичний розв'язок на основі псевдоінверсії Мура-Пенроуза мінімізує норму вектора швидкостей шарнірів `‖q̇‖²`:

```
q̇ = J⁺(q) · 𝒱_cmd = Jᵀ (J Jᵀ)⁻¹ · 𝒱_cmd
```

Проте коли маніпулятор наближається до сингулярного положення, одне з сингулярних чисел прямує до нуля `σ_min → 0`. У розкладі псевдоінверсної матриці через сингулярні вектори:

```
J⁺ = ∑_{i=1}^k (1 / σ_i) · v_i u_iᵀ
```

Множник `1 / σ_i` необмежено зростає, що призводить до фізично неможливих швидкостей приводів `‖q̇‖ → ∞`.

### Регуляризація Тихонова (Damped Least Squares)

Метод демпфованих найменших квадратів формулює задачу як компроміс між точністю виконання завдання та обмеженням амплітуди швидкостей приводів:

```
min_{q̇} [ ‖ J(q) · q̇ − 𝒱_cmd ‖² + λ² ‖ q̇ ‖² ]
```

де `λ ≥ 0` — коефіцієнт демпфування. Диференціюючи цільову функцію за вектором `q̇` та прирівнюючи похідну до нуля, отримуємо регуляризований розв'язок:

```
( Jᵀ J + λ² I_n ) · q̇ = Jᵀ · 𝒱_cmd
```

Застосовуючи матричну тотожність `(Jᵀ J + λ² I_n)⁻¹ Jᵀ = Jᵀ (J Jᵀ + λ² I_m)⁻¹`, отримуємо зручний для обчислень вираз через розв'язання системи `m × m` (`6 × 6`):

```
q̇_dls = Jᵀ · ( J Jᵀ + λ² I₆ )⁻¹ · 𝒱_cmd
```

Сингулярні складові тепер модифікуються фільтруючим коефіцієнтом:

```
J_dls⁺ = ∑_{i=1}^k ( σ_i / (σ_i² + λ²) ) · v_i u_iᵀ
```

При `σ_i ≫ λ` коефіцієнт `σ_i / (σ_i² + λ²) ≈ 1 / σ_i` (зберігається точна інверсія). При `σ_i → 0` коефіцієнт прямує до нуля `σ_i / λ² → 0`, що повністю придушує сингулярний сплеск швидкості ціною незначного відхилення траєкторії в некерованому напрямку.

### Адаптивне налаштування коефіцієнта демпфування

Щоб не вносити похибки позиціювання у вільних від сингулярностей зонах робочого простору, коефіцієнт демпфування `λ` розраховується адаптивно на основі поточної маніпулятивності Йошікави `w(q)`:

```
λ² = { λ_max² · ( 1 − w(q) / w_thresh )²,  якщо w(q) < w_thresh
     { 0,                                 якщо w(q) ≥ w_thresh
```

де `w_thresh` — порогове значення маніпулятивності, нижче якого вмикається демпфування, а `λ_max` — максимальний параметр демпфування на дні сингулярності.

### Проєкція у нуль-простір для керування надлишковими ланками

Для маніпуляторів із надлишковими ступенями вільності (`n > 6`) загальний розв'язок доповнюється складовою внутрішнього саморуху, яка не впливає на рух кінцевого органа:

```
q̇ = q̇_dls + ( I_n − J⁺ J ) · q̇_null
```

де `( I_n − J⁺ J )` — ортогональний проєктор на нуль-простір Якобіана `ker(J)`, а `q̇_null = −k_null · ∇ H(q)` — вектор бажаних швидкостей, спрямований на мінімізацію вторинної функції вартості `H(q)`.

Типовими функціями вартості є:
- **Уникнення механічних упорів шарнірів:**
  `H_limits(q) = 1/4 ∑_{i=1}^n ((q_i − q_mid,i) / (q_max,i − q_min,i))⁴`
- **Максимізація маніпулятивності:**
  `H_manip(q) = −w(q)` (рух у бік найменш сингулярних конфігурацій).

### Алгоритм Левенберга-Марквардта та адаптивна довірча область (Trust-Region Levenberg-Marquardt)

Для розв'язання задачі позиційної оберненої кінематики на рівні координат `Φ(q) = x_target − f(q) = 0` класичний метод Ньютона-Рафсона `q_{k+1} = q_k + J⁺(q_k) · e(q_k)` (де `e(q_k) = x_target − f(q_k)`) зазнає невдачі поблизу сингулярностей або при поганому початковому наближенні через необмежене зростання кроку `‖Δq‖`.

Алгоритм Левенберга-Марквардта (Levenberg-Marquardt, LM) поєднує локальну квадратичну швидкість збіжності методу Гаусса-Ньютона та гарантовану глобальну збіжність градієнтного спуску в рамках концепції адаптивної довірчої області (Trust-Region). На кожній ітерації `k` обчислюється приріст координат `Δq`, який мінімізує локальну квадратичну модель нев'язки з масштабованим регуляризатором:

```
min_{Δq} [ ‖ e(q_k) − J(q_k) · Δq ‖² + λ_k² · ‖ D_k · Δq ‖² ]
```

де `D_k` — діагональна матриця масштабування координат. Класичний метод Левенберга використовує одиничну матрицю `D_k = I_n`, тоді як модифікація Марквардта застосовує масштабування за діагоналлю матриці Грама `D_k = diag( J(q_k)ᵀ J(q_k) + ε I )^{1/2}`. Таке масштабування забезпечує інваріантність кроку до вибору одиниць вимірювання (метрів чи радіанів) та автоматично зменшує крок вздовж осей шарнірів із високою чутливістю.

Крок приросту координат обчислюється розв'язанням системи лінійних рівнянь:

```
( J(q_k)ᵀ J(q_k) + λ_k² · D_kᵀ D_k ) · Δq = J(q_k)ᵀ · e(q_k)
```

Адаптація коефіцієнта демпфування `λ_k` базується на коефіцієнті якості квадратичного наближення (Gain Ratio) `ρ_k`:

```
ρ_k = ( ‖e(q_k)‖² − ‖e(q_k + Δq)‖² ) / ( ‖e(q_k)‖² − ‖e(q_k) − J(q_k) · Δq‖² )
```

Чисельник оцінює реальне зменшення квадратичної нев'язки позиціювання, а знаменник — передбачене лінійною моделлю зменшення.
- Якщо `ρ_k > 0.75`: лінійна модель чудово описує конфігураційний многовид. Крок приймається `q_{k+1} = q_k + Δq`, а коефіцієнт демпфування зменшується: `λ_{k+1} = max(λ_min, λ_k / 3)`. Алгоритм наближається до чистого методу Гаусса-Ньютона з високою швидкістю збіжності.
- Якщо `0.25 ≤ ρ_k ≤ 0.75`: модель є задовільною. Крок приймається `q_{k+1} = q_k + Δq`, параметр `λ` залишається незмінним: `λ_{k+1} = λ_k`.
- Якщо `ρ_k < 0.25` (або крок збільшує похибку `ρ_k ≤ 0`): лінійна модель неадекватна через сильну нелінійність або сингулярне виродження. Крок відхиляється `q_{k+1} = q_k`, а параметр демпфування збільшується: `λ_{k+1} = λ_k · 2` (або множиться на фактор `ν > 1`). Алгоритм плавно переходить у надійний градієнтний спуск у бік зменшення нев'язки вздовж вектора `J(q_k)ᵀ e(q_k)`.

### Фільтрація сингулярних чисел та селективне демпфування (Selective Damped Least Squares, SDLS)

Стандартний ізотропний метод DLS застосовує єдиний скалярний коефіцієнт `λ` до всієї матриці Якобі. Проте спектральний розклад показує, що збурення вносяться в усі сингулярні компоненти:

```
J_dls⁺ = ∑_{i=1}^k ( σ_i / (σ_i² + λ²) ) · v_i u_iᵀ
```

Для здорових напрямків, де `σ_i ≫ λ`, коефіцієнт передачі становить `σ_i / (σ_i² + λ²) < 1 / σ_i`. Це призводить до штучного сповільнення руху та виникнення декартової похибки навіть уздовж осей, де механізм має повну свободу переміщення і не перебуває у сингулярності.

Для усунення цього недоліку застосовується метод селективного демпфування сингулярних чисел (Selective Damped Least Squares, SDLS):
1. Псевдоінверсна матриця формується з індивідуальними фільтруючими функціями `f_i(σ_i)` для кожного сингулярного числа:
   ```
   J_sdls⁺ = ∑_{i=1}^k f_i(σ_i) · v_i u_iᵀ
   ```
2. Якщо проєкція швидкості завдання на `i`-й лівий сингулярний вектор `u_iᵀ 𝒱_cmd` створює у конфігураційному просторі швидкість `v_i · (u_iᵀ 𝒱_cmd / σ_i)`, що перевищує максимальну допустиму швидкість приводів `q̇_max`, індивідуальне демпфування `λ_i` розраховується аналітично:
   ```
   λ_i = { σ_i · √( |u_iᵀ 𝒱_cmd| / (σ_i · q̇_max) − 1 ),  якщо |u_iᵀ 𝒱_cmd| / σ_i > q̇_max
         { 0,                                             якщо |u_iᵀ 𝒱_cmd| / σ_i ≤ q̇_max
   ```
3. Тоді `f_i(σ_i) = σ_i / (σ_i² + λ_i²)`. Завдяки цьому демпфування активується строго вздовж тих просторових мод, які призводять до фізичного насичення приводів, залишаючи решту компонент руху абсолютно незбуреними.

### Метод демпфування зі збереженням декартового напрямку (Direction-Preserving DLS)

У критичних технологічних процесах (лазерне різання, зварювання, хірургічні операції) зміна напрямку вектора швидкості робочого органа є неприпустимою: робот може рухатися повільніше, але зобов'язаний суворо зберігати просторову траєкторію без бокового знесення.

Класичний метод DLS спотворює просторовий кут вектора швидкості: напрямок результуючого вектора `𝒱_actual = J · q̇_dls` не збігається з бажаним вектором `𝒱_cmd`, оскільки різні компоненти демпфуються неоднорідно.

Алгоритм демпфування зі збереженням напрямку (Direction-Preserving DLS / Error-Clamping) розв'язує цю проблему шляхом глобального просторового масштабування:
1. Спочатку обчислюється номінальний розв'язок на основі псевдоінверсії без демпфування: `q̇_nom = J⁺ · 𝒱_cmd`.
2. Визначається максимальний коефіцієнт перевищення лімітів швидкості серед усіх шарнірів маніпулятора:
   ```
   s = max_{i=1,…,n} ( |q̇_nom,i| / q̇_max,i )
   ```
3. Якщо `s > 1`, замість нелінійного спотворення окремих координат виконується масштабування вхідного декартового завдання:
   ```
   𝒱_scaled = (1 / s) · 𝒱_cmd
   q̇_safe = J⁺ · 𝒱_scaled = (1 / s) · q̇_nom
   ```
Результуючий просторовий твіст `𝒱_actual = J · q̇_safe = (1 / s) · 𝒱_cmd` є строго колінеарним до бажаного вектора швидкості `𝒱_cmd`. Робот продовжує слідувати точно за заданою просторовою траєкторією зі зниженою швидкістю, повністю уникаючи кінематичних ривків та некерованого бічного дрейфу інструменту поблизу сингулярних зон.

## 10. Прикладні дослідження типових просторових механізмів

Для глибокого розуміння роботи алгоритму розглянемо три характерні інженерні механізми, які демонструють різні типи сингулярностей та топологій зв'язків.

### Дослідження 1: Серійний промисловий маніпулятор 6-DoF (архітектура PUMA/UR)

Класичний 6-осьовий шарнірний робот складається з трьох позиціонуючих шарнірів (базовий поворот, плече, лікоть) та сферичного зап'ястя з трьома осями, що перетинаються в одній точці `p_w`.

Геометричний Якобіан такого маніпулятора у системі зап'ястя має верхньотрикутну блочну структуру `3×3`:

```
J(q) = | J_11(q_pos)     0     |
       | J_21(q_pos)   J_22(q) |
```

Визначник повної матриці Якобі розпадається на добуток визначників позиційної частини та зап'ястя:

```
det(J(q)) = det(J_11(q_pos)) · det(J_22(q_wrist))
```

Це зумовлює виникнення трьох відокремлених типів сингулярностей:
1. **Сингулярність зап'ястя (Wrist singularity):** осі 4 та 6 стають колінеарними (`θ₅ = 0`). При цьому `det(J_22) = sin(θ₅) = 0`, робот втрачає здатність здійснювати обертання навколо осі, перпендикулярної до площини шарнірів.
2. **Сингулярність ліктя (Elbow singularity):** лікоть повністю випрямлений або складений (`θ₃ = 0` або `θ₃ = π`). Робоча точка зап'ястя потрапляє на зовнішню або внутрішню межу робочої зони, маніпулятор втрачає здатність рухатися радіально.
3. **Сингулярність плеча (Shoulder singularity):** центр зап'ястя `p_w` потрапляє на вісь обертання першого шарніра `z₀`. Будь-який рух вимагає нескінченної швидкості повороту базової колони.

### Дослідження 2: Плоский паралельний маніпулятор 3-RRR

Механізм складається з рухомої трикутної платформи, з'єднаної з нерухомою основою трьома кінематичними ніжками, кожна з яких містить три обертальні шарніри `R`. Перші шарніри є активними (керованими двигунами `θ = (θ₁, θ₂, θ₃)ᵀ`), а решта — пасивними.

Рівняння замкненості векторних контурів мають вигляд:

```
‖ p_platform + R(ϕ) · r_i − A_i − L₁ · e(θ_i) ‖² − L₂² = 0,    i = 1, 2, 3
```

Диференціювання дає систему матриць прямого та зворотного Якобі:

```
J_dir(x) · ẋ = J_inv(θ) · θ̇
```

- При випрямленні другої ланки ніжки вздовж першої (`sin(θ_i - β_i) = 0`) матриця `J_inv` втрачає ранг: виникає **сингулярність I типу** (край досяжності).
- Коли поздовжні осі трьох дистальних ланок `L₂` перетинаються в одній спільній точці на площині, визначник матриці `J_dir` обнуляється: виникає **сингулярність II типу**. У цій точці рухома платформа отримує миттєвий неконтрольований поворот навколо точки перетину навіть при повністю заблокованих гальмами вхідних двигунах, а навантаження на підшипники прямує до нескінченності.

### Дослідження 3: Просторова платформа Стюарта-Гоуфа (6-UPS Hexapod)

Платформа Стюарта складається з нерухомої бази, рухомої платформи та 6 розсувних гідро- або сервоциліндрів (актуаторів). Кожна нога кріпиться до бази універсальним шарніром Кардана (`U`), має лінійний актуатор (`P`) довжиною `l_i` і закінчується сферичним шарніром (`S`) на платформі.

Вектор довжин ніг `l = (l₁, l₂, …, l₆)ᵀ` пов'язаний із просторовим твістом платформи `𝒱_p = (ωᵀ, vᵀ)ᵀ ∈ ℝ⁶` співвідношенням:

```
l̇ = J_stewart(q) · 𝒱_p
```

Рядки матриці Якобі утворюються плюккеровими координатами прямих, вздовж яких спрямовані осі актуаторів:

```
J_row,i = | (p_i × n_i)ᵀ   n_iᵀ |
```

де `n_i = (p_i − b_i) / l_i` — одиничний вектор осі `i`-ї ноги, а `p_i` — координати верхнього сферичного шарніра.

Сингулярності платформи Стюарта виникають, коли 6 просторових прямих дії актуаторів стають лінійно залежними у просторі гвинтів (наприклад, утворюють лінійчату поверхню — гіперболоїд або перетинають спільну пряму). У таких конфігураціях платформа втрачає здатність сприймати зовнішній момент сили за певним напрямком (втрата статичної жорсткості), а чисельний розв'язок прямої кінематики розпадається на до 40 дійсних коренів.

## 11. Багаторівнева пріоритетна ієрархія завдань (Task Priority IK)

У складних робототехнічних комплексах (наприклад, гуманоїдних роботах або космічних маніпуляторах) одного лише переміщення схоплювача недостатньо: одночасно необхідно утримувати баланс центру мас, уникати зіткнень ліктів із перешкодами та тримати орієнтацію камери на об'єкті. Для цього застосовується строго математично доведена багаторівнева пріоритетна схема на основі рекурсивного проєктування у нуль-простори вищих завдань.

Нехай задано ієрархію з `k` завдань із матрицями Якобі `J₁, J₂, …, J_k` та бажаними швидкостями `v₁, v₂, …, v_k`.

1. **Перше (найвищий пріоритет):**
   ```
   q̇₁ = J₁⁺ · v₁
   P₁ = I_n − J₁⁺ J₁
   ```
2. **Друге завдання (виконується строго в нуль-просторі першого):**
   ```
   J_{2|1} = J₂ · P₁
   q̇₂ = q̇₁ + J_{2|1}⁺ · ( v₂ − J₂ · q̇₁ )
   P₂ = P₁ · ( I_n − J_{2|1}⁺ J_{2|1} )
   ```
3. **Загальний рекурсивний крок для завдання `i`:**
   ```
   J_{i|prev} = J_i · P_{i-1}
   q̇_i = q̇_{i-1} + J_{i|prev}⁺ · ( v_i − J_i · q̇_{i-1} )
   P_i = P_{i-1} · ( I_n − J_{i|prev}⁺ J_{i|prev} )
   ```

Цей каскадний алгоритм математично гарантує, що виконання вторинних завдань ніколи не вносить жодних збурень у виконання первинних, оскільки кожна наступна поправка швидкості строго належить перетину ядер усіх вищих за пріоритетом матриць Якобі.

## 12. Аналіз чутливості та поширення похибок кінематичних параметрів

У реальному виробництві геометричні розміри ланок робота (довжини `L_i`, відстані між осями `d_i`, кути перекосу `α_i`) відхиляються від номінальних креслень через виробничі допуски та теплове розширення на величину `Δp ∈ ℝ^p`.

Диференціал похибки положення кінцевого органа `Δx ∈ ℝ⁶` залежить від вектора похибок параметрів `Δp` та похибок датчиків кутів `Δq` через матрицю чутливості калібрування `J_geom(q)`:

```
Δx = J(q) · Δq + J_geom(q) · Δp
```

Стовпчики матриці `J_geom(q)` утворюються похідними прямої кінематики за кожним конструктивним параметром. Показник чутливості калібрування (кінематична спостережуваність) визначається сингулярними числами матриці `J_geom`: конфігурація робота є оптимальною для калібрування, якщо всі сингулярні числа `σ_i(J_geom)` є великими та рівномірними (висока якість збудження параметрів).

### Оптимізація траєкторій у конфігураційному просторі з урахуванням сингулярних бар'єрів

Для запобігання випадковому потраплянню робота в сингулярні конфігурації під час автономного руху застосовується метод штучних потенціальних полів у просторі конфігурацій `𝒬`. Функція відштовхування від сингулярностей будується на основі міри маніпулятивності Йошікави `w(q)`:

```
U_rep(q) = { 1/2 · η · ( 1/w(q) − 1/w₀ )²,  якщо w(q) < w₀
           { 0,                             якщо w(q) ≥ w₀
```

де `η > 0` — коефіцієнт сили відштовхування, а `w₀` — межа безпечної зони маніпулятивності. Градієнт потенціалу `∇ U_rep(q)` генерує віртуальний момент у шарнірах, спрямований у бік збільшення об'єму еліпсоїда маніпулятивності, що автоматично відштовхує систему від сингулярних конфігураційного бар'єрів.

### Порівняльний аналіз чисельної складності методів лінійної алгебри

При виборі чисельного методу для оберненої кінематики на вбудованих платформах інженер враховує баланс між швидкістю виконання та стійкістю:
- **Повний розклад SVD (Two-sided Jacobi):** `O(m² n + n³)` операцій. Надає точний спектральний аналіз, точне ядро та образ, гарантує бездоганну чисельну стійкість навіть при майже нульових визначниках. Застосовується для глобального аналізу, моніторингу та планування.
- **Розклад Холецького для DLS (`A = J Jᵀ + λ² I`):** `O(m³ / 6 + m n)` операцій. Є найшвидшим методом (для `m = 6` це лише ~36 операцій ділення/множення), проте вимагає гарантованого ненульового регуляризатора `λ > 0` для збереження додатної визначеності. Ідеальний для внутрішніх контурів сервокерування на частотах 1–2 кГц.
- **QR-розклад з відбиттями Хаусхолдера:** `O(m n² − n³ / 3)` операцій. Забезпечує стабільне обчислення базису нуль-простору `ker(J)` без втрати ортогональності та добре підходить для вторинних завдань у багаторівневих ієрархіях керування.

### Векторизація SIMD для обчислень кінематики ланцюгів

Сучасні процесори підтримують векторні інструкції (AVX2, AVX-512, ARM Neon), здатні обробляти одночасно чотири числа подвійної точності або вісім чисел одинарної точності. Множення матриць перетворення `4×4` у прямій кінематиці природно вкладається у 4 векторні регістри, що прискорює пряму кінематику довголанцюгових систем у 3–4 рази порівняно зі скалярним кодом.

## 14. Практичні інженерні випадки та чисельні пастки

При інтеграції чисельного кінематичного розв'язувача в системи реального часу (наприклад, у контури керування польотними контролерами дронів або промисловими роботами на частотах 500–1000 Гц) виникає низка критичних інженерних викликів.

### Пастка 1: Вибір адаптивного порогу рангу при наявності шумів енкодерів

У математичній теорії сингулярне число або строго дорівнює нулю, або строго додатне. У реальній системі вимірювання кутів шарнірів супроводжуються шумом квантування енкодерів амплітудою `δq ~ 10⁻⁴` рад. У безпосередній близькості до сингулярності найменше сингулярне число `σ_min` коливається навколо порогу `ε_tol`, що викликає стрибкоподібні перемикання рангу матриці Якобі між сусідніми циклами керування (chattering). Це породжує різкі високочастотні стрибки керуючого моменту приводів.

**Інженерне вирішення:** Забороняється використовувати жорстке відсікання рангу (`rank = (σ > ε) ? 1 : 0`) у контурі прямого зворотного зв'язку. Натомість застосовується неперервна гладка функція демпфування `λ(w)`, яка забезпечує нескінченно диференційовний перехід між інверсією без демпфування та регуляризованим розв'язком.

### Пастка 2: Різнорідність розмірностей у матриці Якобі та вибір характерної довжини

Стовпчик геометричного Якобіана містить кутову частину безрозмірної розмірності `[рад/с] / [рад/с] = 1` та лінійну частину розмірності швидкості `[м/с] / [рад/с] = м`. Якщо змінити одиниці вимірювання координат з метрів на міліметри, числові значення нижніх трьох рядків матриці `J` зростуть у 1000 разів, що призведе до штучної зміни сингулярних чисел та спотворення числа обумовленості `κ(J)`.

**Інженерне вирішення:** Для обчислення інваріантних метрик маніпулятивності матриця Якобі нормалізується за допомогою характерного геометричного масштабу робота `L_char` (наприклад, повної довжини випрямленої руки):

```
J_norm = |   I₃               0        | · J(q)
         |   0     (1 / L_char) · I₃   |
```

Усі сингулярні числа нормалізованої матриці `J_norm` стають безрозмірними величинами, що коректно відображають справжню просторову кінематичну якість конфігурації.

### Пастка 3: Чисельний дрейф замкнених зв'язків та корекція Баумгарте

При чисельному інтегруванні кінематичних швидкостей замкненої системи за часом методом Ейлера або Рунге-Кутти (`q_{k+1} = q_k + Δt · q̇_k`) неминуче накопичуються похибки дискретизації. Через це рівняння зв'язків перестають строго виконуватися: `‖Φ(q_k)‖ > 0`. За кілька секунд вільного руху замкнений контур у чисельній моделі розривається.

**Інженерне вирішення:** Для усунення дрейфу застосовується стабілізація Баумгарте, що модифікує рівняння швидкостей додаванням пропорційної корекції нелінійної нев'язки:

```
G(q) · q̇ = −α · Φ(q)
```

де параметр стабілізації обирається як `α = 1 / (2 Δt)`. Це забезпечує стійке експоненційне затухання будь-якої похибки замикання контуру з часовою сталою `τ = 1 / α`, надійно утримуючи рух механізму на його істинному конфігураційному многовидді.

### Пастка 4: Багатозначність розв'язків та перетин кінематичних гілок

Для багатьох механізмів (як послідовних маніпуляторів типу PUMA-560 з 8 можливими конфігураціями ліктя, плеча та зап'ястя, так і паралельних платформ із кількома робочими режимами) одна й та сама декартова позиція відповідає дискретній множині різних векторів шарнірних координат `q^{(1)}, q^{(2)}, …`. При чисельному розв'язанні оберненої кінематики алгоритм методом градієнтного спуску або Ньютона може зійтися до небажаної конфігурації (наприклад, перевернутого ліктя, що спричинить зіткнення з основою).

**Інженерне вирішення:** Ініціалізація ітераційного пошуку завжди повинна починатися з поточної фактичної конфігурації робота на попередньому кроці квантування часу `q_{k-1}`. Якщо потрібна глобальна переконфігурація, розраховується траєкторія у конфігураційному просторі через спільні несингулярні перехідні точки, уникаючи перетину сепаратрис між різними гілками конфігураційного многовиддя.

### Пастка 5: Оптимізація обчислювальної складності для вбудованих контролерів

Обчислення повного SVD-розкладу матриці Якобі на кожному циклі сервокерування на мікроконтролерах із плаваючою комою (ARM Cortex-M4/M7 без підтримки апаратного векторного розширення) створює значне навантаження на процесор. Для матриці розміру `6 × 6` алгоритм Якобі вимагає від 5000 до 15000 операцій із рухомою комою.

**Інженерне вирішення:**
- Якщо потрібен лише регуляризований крок DLS без точного обчислення всіх сингулярних векторів `U` та `V`, система розв'язується через розклад Холецького симетричної додатно визначеної матриці `A = J Jᵀ + λ² I₆`. Це скорочує кількість операцій до `m³ / 6 ≈ 36` множень, зменшуючи час розрахунку на два порядки.
- Обчислення повного SVD виконується у фоновому потоці з нижчою частотою (наприклад, 50 Гц) для моніторингу маніпулятивності та діагностики небезпеки, тоді як внутрішній високочастотний контур регулятора (1 кГц) використовує прямий розв'язок методом Холецького з інтерпольованим параметром `λ`.

### Пастка 6: Втрата ортогональності базисів у класичному методі Грама-Шмідта

При використанні QR-розкладу для виділення ядра матриці Якобі часто застосовують класичний процес ортогоналізації Грама-Шмідта (CGS). У числах із рухомою комою накопичення похибок призводить до швидкої втрати ортогональності обчислених векторів базису (скалярний добуток між векторами, які мають бути ортогональними, зростає до `10⁻³`…`10⁻²`).

**Інженерне вирішення:** Забороняється застосовувати класичний CGS. Слід використовувати або модифікований процес Грама-Шмідта (MGS) з подвійною переортогоналізацією, або перетворення відбиття Хаусхолдера (Householder reflections). Відбиття Хаусхолдера є безумовно чисельно стійкими і зберігають ортогональність на рівні машинної точності незалежно від обумовленості вихідної матриці.

### Пастка 7: Глобальне планування траєкторій крізь сингулярні бар'єри

При плануванні рухів у декартовому просторі пряма лінія між початковою та кінцевою точками може перетинати сингулярну гіперповерхню конфігураційного простору. Намагання слідувати цій прямій із регуляризацією DLS призводить до тимчасової зупинки або помітного просторового відхилення робочого органа від бажаного шляху.

**Інженерне вирішення:** Для переміщень на великі відстані планування траєкторії виконується безпосередньо у конфігураційному просторі `𝒬` за допомогою алгоритмів пошуку шляхів на графах (RRT* / PRM) із функцією вартості, яка включає штраф за наближення до сингулярностей `Cost(q) = ∫ ( 1 / (w(q) + ε) ) ds`. Це змушує робота автоматично огинати сингулярні конфігурації у просторі конфігурацій, зберігаючи високу керованість та запас швидкості по всіх осях.

### Пастка 8: Динамічна маніпулятивність та врахування матриці інерції

Геометричний Якобіан `J(q)` описує лише кінематичну передачу швидкостей без урахування мас та моментів інерції ланок маніпулятора. У реальних швидкісних маніпуляторах прискорення кінцевого органа обмежується моментами двигунів `τ ∈ ℝⁿ` через рівняння динаміки `M(q) q̈ + C(q, q̇) q̇ + g(q) = τ`.

Зв'язок між прискоренням кінцевого органа `a_e = 𝒱̇_e` та моментами двигунів `τ` визначається динамічною матрицею Якобі:

```
a_e = J(q) · M(q)⁻¹ · τ
```

Динамічний еліпсоїд маніпулятивності Хатамури-Йошікави задається матрицею:

```
N(q) = J(q) · M(q)⁻¹ · M(q)⁻ᵀ · J(q)ᵀ
```

**Інженерне вирішення:** У системах динамічного силомоментного керування регуляризація DLS повинна демпфувати рух не в евклідовій метриці, а в рімановій метриці матриці інерції `M(q)`. Це гарантує, що приводи не будуть перевантажуватися спробами розвинути високе прискорення у напрямках із високою еквівалентною інерційною масою.

### Пастка 9: Змішані кінематичні петлі з обертальними та поступальними ланками

У змішаних кінематичних парах (наприклад, маніпуляторах типу SCARA з шарнірами RRP або промислових роботах-дельта з лінійними приводами) елементи узагальненого вектора координат `q` мають різні розмірності: кути вимірюються в радіанах, а лінійні зміщення — в метрах. Якщо безпосередньо обчислювати евклідову норму `‖q̇‖² = ∑ q̇_i²`, додаються непорівнювані фізичні величини `(рад/с)² + (м/с)²`, що призводить до фізично некоректної оптимізації в методі найменших квадратів.

**Інженерне вирішення:** Для змішаних ланцюгів функція оптимізації DLS завжди зважується діагональною метричною матрицею ваг `W_q = diag(w₁, w₂, …, w_n)`:

```
min_{q̇} [ ‖ J(q) q̇ − 𝒱_cmd ‖_{W_task}² + λ² ‖ q̇ ‖_{W_q}² ]
```

де для обертальних шарнірів вага обирається як `w_i = L_char²` (де `L_char` — характерна довжина ланки), а для поступальних шарнірів `w_i = 1.0`. Це зводить усі доданки цільової функції до єдиної розмірності потужності або кінетичної енергії.

### Пастка 10: Детермінізм обчислень із рухомою комою у багатопотокових фізичних рушіях

У розподілених системах симуляції та комп'ютерних іграх паралельне виконання SVD та множення матриць на різних ядрах або процесорних архітектурах (x86-64 проти ARM64) здатне викликати розходження результатів через різний порядок виконання операцій FMA (Fused Multiply-Add) та обробку денормалізованих чисел (denormalized / subnormal numbers). Поява денормалізованих чисел поблизу сингулярностей сповільнює виконання операцій на процесорі у 10–100 разів через перемикання на мікропрограмні пастки.

**Інженерне вирішення:**
1. На старті програми примусово вмикаються апаратні прапорці процесора FTZ (Flush-to-Zero) та DAZ (Denormals-are-Zero) у контрольному регістрі MXCSR: `_mm_setcsr(_mm_getcsr() | 0x8040)`.
2. Усі матричні операції записуються у строго детермінованому порядку без використання залежних від компілятора прапорців швидкої нестандартної математики (`-ffast-math`), що гарантує 100% повторюваність траєкторій на будь-яких цільових платформах.
