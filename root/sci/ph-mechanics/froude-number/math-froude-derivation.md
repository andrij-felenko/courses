## 1. Знерозмірення тривимірних рівнянь Нав'є-Стокса

Розглянемо потік в'язкої несжимаємої рідини постійної густини `ρ` та кінематичної в'язкості `ν = μ / ρ`, що рухається в однорідному полі тяжіння з вектором прискорення `g = (0, 0, -g)`.

Диференціальні рівняння збереження маси (нестисливості) та збереження імпульсу Нав'є-Стокса у векторній формі мають фундаментальний вигляд. Ліва частина рівняння Нав'є-Стокса виражає повну локальну та конвективну похідну швидкості по часу, що описує інерційне прискорення рідкої частинки: `ρ · ( ∂u/∂t + (u · ∇)u )`. Права частина виражає суму результуючих сил тиску `-∇p`, в'язких сил дифузії імпульсу `μ · ∇²u` та масової сили тяжіння `ρ · g`.

Для переходу до нерозмірної системи вибираються фундаментальні масштаби середовища. Лінійний масштаб `L` визначає характерний розмір тіла чи глибину, швидкісний масштаб `v_0` визначає набігаючий потік, а часовий масштаб `t_0 = L / v_0` визначає характерний період конвективного переносу. Динамічний тиск знерозмірюється відносно подвійного швидкісного напору `ρ · v_0²`.

Вводячи безрозмірні координати `x* = x / L`, `y* = y / L`, `z* = z / L` та безрозмірний вектор швидкості `u* = u / v_0`, отримаємо нові оператори диференціювання `∇* = L · ∇` та `∇*² = L² · ∇²`. 

Підставивши нерозмірні змінні у вихідне рівняння руху Нав'є-Стокса, ми розкладаємо кожну додачу:
- Інерційний член конвекції набуває множника `ρ · v_0² / L`.
- Градієнт динамічного тиску набуває тотожного множника `ρ · v_0² / L`.
- В'язкий член в'язкості Лапласа набуває множника `μ · v_0 / L²`.
- Масовий член гравітаційного прискорення дорівнює `-ρ · g · k̂`, де `k̂` — орт вертикальної осі.

Поділивши все рівняння на спільний інерційний масштаб `ρ · v_0² / L`, ми виділяємо безрозмірні коефіцієнти перед в'язкими та гравітаційними членами. Безрозмірний комплекс перед в'язким членом дорівнює `μ / (ρ · v_0 · L)`, що являє собою обернене число Рейнольдса `1 / Re`. Безрозмірний комплекс перед гравітаційним членом дорівнює `(g · L) / v_0²`, що являє собою обернений квадрат числа Фруда `1 / Fr²`.

У результаті знерозмірене диференціальне рівняння Нав'є-Стокса набуває універсального вигляду:

```
∂u*/∂t* + (u* · ∇*)u* = -∇*p* + (1 / Re) · ∇*²u* - (1 / Fr²) · k̂
```

Цей результат строго доводить, що при нехтуванні в'язкістю (`Re → ∞`) геометрична та кінематична подібність flows з вільною поверхнею повністю визначається єдиним безрозмірним параметром — числом Фруда `Fr`.

## 2. Швидкість гравітаційних хвиль на мілководді

Розглянемо одновимірний потік ідеальної нестислої рідини у відкритому прямокутному каналі постійної ширини. Рівняння мілководдя (рівняння Сен-Венана) виводяться з інтегрування рівнянь Ейлера по глибині за припущення гідростатичного розподілу тиску.

Рівняння неперервності (збереження маси) описує зміну глибини `h` залежно від градієнта витрати: `∂h/∂t + ∂(h · u)/∂x = 0`. Рівняння збереження імпульсу описує конвективне прискорення та градієнт гідростатичного напору: `∂u/∂t + u · ∂u/∂x + g · ∂h/∂x = 0`.

Розглянемо малоамплітудні збурення вільної поверхні над спокійним шаром рідини глибиною `h_0`. Представимо глибину та швидкість у вигляді суми незбуреного стану та малих флуктуацій: `h(x,t) = h_0 + η(x,t)` (де `|η| << h_0`) та `u(x,t) = 0 + u'(x,t)` (де `|u'| << √(g · h_0)`).

Підставивши ці вирази у диференціальні рівняння мілководдя та знехтувавши членами другого порядку малості (`η · u'`, `u' · ∂u'/∂x`), отримуємо Лінеаризовану систему лінійних диференціальних рівнянь:
- `∂η/∂t + h_0 · ∂u'/∂x = 0` (лінеаризоване рівняння маси);
- `∂u'/∂t + g · ∂η/∂x = 0` (лінеаризоване рівняння імпульсу).

Продиференціювавши перше рівняння по часу `t`, а друге по координаті `x` та виключивши змішану похідну швидкості `∂²u'/(∂x ∂t)`, ми отримуємо класичне одновимірне хвильове диференціальне рівняння Даламбера для відхилення вільної поверхні `η(x,t)`:

```
∂²η/∂t² - (g · h_0) · ∂²η/∂x² = 0
```

Канонічна форма хвильового рівняння `∂²η/∂t² - c² · ∂²η/∂x² = 0` визначає фазову швидкість поширення поверхневих гравітаційних хвиль на мілководді: `c = √(g · h_0)`. 

Звідси число Фруда `Fr = v / c = v / √(g · h_0)` є співвідношенням швидкості потоку до швидкості поширення інформаційних збурень у середовищі.

## 3. Питома енергія перерізу та критична глибина (Fr = 1)

Питома енергія потоку у відкритому каналі `E` (виражена у метрах водного стовпа відносно дна) складається з потенціальної енергії глибини `h` та кінетичної енергії швидкісного напору: `E = h + v² / (2g)`.

Виразимо швидкість течії через питому витрату рідини на одиницю ширини каналу `q = v · h` (вимірюється у м²/с): `v = q / h`. Підставивши вираз швидкості у формулу питомої енергії, отримуємо функцію однієї змінної: `E(h) = h + q² / (2g · h²)`.

Для знаходження екстремуму функції `E(h)` при сталій витраті `q` обчислимо першу похідну по глибині `h` та прирівняємо її до нуля:

```
dE/dh = 1 - (2 · q²) / (2g · h³) = 1 - q² / (g · h³) = 0
```

Зауважимо, що член `q² / (g · h³) = (v² · h²) / (g · h³) = v² / (g · h) = Fr²`. 

Таким чином, похідна питомої енергії виражається прямо через квадрат числа Фруда: `dE/dh = 1 - Fr²`.

З цієї фундаментальної формули випливають три ключові фізико-математичні висновки:
1. При `Fr < 1` (докритичний потік) `Fr² < 1`, тому `dE/dh > 0`. Це означає, що у спокійній течії зростання глибини призводить до зростання питомої енергії напору.
2. При `Fr > 1` (надкритичний потік) `Fr² > 1`, тому `dE/dh < 0`. У бурхливій течії зростання глибини призводить до зменшення питомої енергії.
3. При `Fr = 1` (критичний потік) `dE/dh = 0`. Питома енергія `E(h)` досягає свого абсолютного теоретичного мінімуму `E_min`.

Глибина, що відповідає мінімуму питомої енергії, називається критичною глибиною `h_c = ∛( q² / g )`.

Мінімальна питома енергія `E_min` виражається через критичну глибину наступним чином: `E_min = h_c + q² / (2g · h_c²) = h_c + 0.5 · h_c = 1.5 · h_c`. Отже, у критичному режимі течії (`Fr = 1`) рівно дві третини всієї питомої енергії припадає на потенціальну енергію глибини (`h_c = 2/3 · E_min`), а одна третина — на кінетичний швидкісний напір.

## 4. Виведення рівняння Беланже для гідравлічного стрибка

Розглянемо прямокутний горизонтальний канал шириною `B`. На ділянці між перерізом 1 (до стрибка, глибина `h_1`, швидкість `v_1`) та перерізом 2 (після стрибка, глибина `h_2`, швидкість `v_2`) діє закон збереження імпульсу (теорема про зміну кількості руху).

Оскільки тертям об дно на короткій ділянці стрибка можна знехтувати, сума зовнішніх сил гідростатичного тиску у перерізах 1 та 2 дорівнює зміні секундного імпульсу потоку: `F_p1 - F_p2 = ρ · Q · (v_2 - v_1)`.

Гідростатичні сили тиску на вертикальні площини прямокутного перерізу дорівнюють `F_p1 = 0.5 · ρ · g · B · h_1²` та `F_p2 = 0.5 · ρ · g · B · h_2²`. Підставимо ці сили та об'ємну витрату `Q = B · q`:

```
0.5 · ρ · g · B · (h_1² - h_2²) = ρ · B · q · (v_2 - v_1)
```

Скоротивши на `ρ · B` та підставивши `v_1 = q / h_1`, `v_2 = q / h_2`, отримуємо:

```
0.5 · g · (h_1² - h_2²) = q² · ( (h_1 - h_2) / (h_1 · h_2) )
```

Розкладемо різницю квадратів `(h_1² - h_2²) = (h_1 - h_2) · (h_1 + h_2)`. Оскільки для наявного стрибка `h_1 ≠ h_2`, скоротимо обидві частини на `(h_1 - h_2)`:

```
-0.5 · g · (h_1 + h_2) = -q² / (h_1 · h_2)
```

Помноживши обидві частини на `-2 / (g · h_1²)`, отримуємо:

```
(h_2 / h_1) · (1 + h_2 / h_1) = (2 · q²) / (g · h_1³)
```

Зауважимо, що `q² / (g · h_1³) = (v_1² · h_1²) / (g · h_1³) = v_1² / (g · h_1) = Fr_1²` — квадрат числа Фруда перед стрибком!

Ввівши безрозмірне відношення спряжених глибин `Y = h_2 / h_1`, отримуємо квадратне рівняння `Y² + Y - 2 · Fr_1² = 0`.

Його додатний фізичний корінь дає класичне рівняння Беланже (1828):

```
h_2 / h_1 = 0.5 · ( √(1 + 8 · Fr_1²) - 1 )
```

Це рівняння безпосередньо пов'язує стрибок глибини у відкритому каналі з вхідним числом Фруда `Fr_1`.

Обчислимо тепер дисипацію питомої енергії `ΔE = E_1 - E_2` у стрибку. Питома енергія в перерізах 1 та 2 становить `E_1 = h_1 + q²/(2g h_1²)` та `E_2 = h_2 + q²/(2g h_2²)`. Виразивши `q²` через рівняння Беланже, підставимо у різницю енергій:

```
ΔE = (h_1 - h_2) + (q² / (2g)) · (1/h_1² - 1/h_2²) = (h_2 - h_1)³ / (4 · h_1 · h_2)
```

Цей строгий алгебраїчний результат доводить, що оскільки `h_2 > h_1`, втрата енергії `ΔE` завжди строго додатна (`ΔE > 0`). Це узгоджується із другим законом термодинаміки: кінетична енергія бурхливого потоку незворотно дисипує у теплову та акустичну енергію турбулентного валу.

## 5. Дисперсійне виведення кута хвильового сліду Кельвіна

Розглянемо точкове джерело збурення (корпус судна), яке рухається зі сталою швидкістю `v` вздовж осі `x` на поверхні ідеальної рідини нескінченної глибини.

У рухомій системі координат, пов'язаній із джерелом, дисперсійне співвідношення для тривимірних поверхневих гравітаційних хвиль має вигляд `(k · v)² = g · |k|`, де `k = (k_x, k_y)` — хвильовий вектор, а `|k| = √(k_x² + k_y²)`.

Запишемо хвильовий вектор через кут поширення хвилі `θ` відносно напрямку руху: `k_x = |k| · cos(θ)` та `k_y = |k| · sin(θ)`. Підставивши ці вирази у дисперсійне співвідношення, знайдемо модуль хвильового вектора: `|k|(θ) = g / (v² · cos²(θ))`.

Геометричне положення гребенів стоячих хвиль визначається методом стаціонарної фази для хвильового інтерграла Фурьє. Фазова функція дорівнює `Φ(x, y; θ) = k_x · x + k_y · y = (g / v²) · ( x / cos(θ) + y · sin(θ) / cos²(θ) )`.

Умовою формування стаціонарного огинаючого фронту хвиль є рівність нулю першої похідної фази по куту `θ`: `∂Φ/∂θ = (g / v²) · ( (x · sin(θ) + y · (1 + sin²(θ))) / cos³(θ) ) = 0`.

Звідси отримуємо параметричне співвідношення між координатами хвиль `x` та `y`:
- `x(θ) = -C · (1 + sin²(θ)) · cos(θ)`
- `y(θ) = C · sin(θ) · cos²(θ)`

Для знаходження максимального кута клина огинаючої лінії розімкненого хвильового сліду обчислимо тангенс кута `α = y / (-x)`: `tan(α) = sin(θ) / (1 + sin²(θ))`.

Для знаходження максимуму функції `tan(α)` по параметру `u = sin(θ)` обчислимо похідну від `f(u) = u / (1 + u²)` по `u` та прирівняємо її до нуля: `df/du = (1 - u²) / (1 + u²)² = 0`.

Рівняння має єдиний додатний корінь `u = sin(θ) = 1 / √2` (що відповідає куту поширення хвиль `θ = 45°`).

Підставивши `u = 1 / √2` у вираз для тангенса кута клина `tan(α_max)`: `tan(α_max) = (1 / √2) / (1 + 1/2) = 1 / √8`.

Обчислимо тепер синус максимального кута огинаючого клина Кельвіна `α_max`: `sin(α_max) = tan(α_max) / √(1 + tan²(α_max)) = (1 / √8) / (3 / √8) = 1 / 3`.

Таким чином, строго доведено, що теоретичний напівкут клина хвильової картини Кельвіна на глибокій воді становить `α_max = arcsin(1/3) ≈ 19.4712°`. Повний кут кильоватого сліду дорівнює `2 · α_max ≈ 38.9424°`. Цей універсальний результат залежить виключно від дисперсійного співвідношення поверхневих гравітаційних хвиль і є незмінним для будь-яких суден незалежно від їхньої швидкості `v` та форми корпусу.

## 6. Внутрішнє число Фруда в стратифікованому середовищі

Розглянемо двошарову несжимаєму рідину в наближенні Буссінеска, де верхній шар глибиною `h_1` має густину `ρ_1`, а нижній шар глибиною `h_2` має густину `ρ_2` (`ρ_2 > ρ_1`).

Горизонтальне рівняння руху для збурення швидкості `u'` на межі поділу фаз враховує відновлювальну силу архімедової плавучості. Ефективний перепад тиску на міжфазній межі визначається різницею густин `Δρ = ρ_2 - ρ_1`.

Вводячи приведене прискорення вільного падіння `g' = g · (ρ_2 - ρ_1) / ρ_2 = g · (Δρ / ρ_2)`, фазова швидкість внутрішніх гравітаційних хвиль на межі поділу двох товстих шарів описується співвідношенням: `c_internal = √( g' · ( (h_1 · h_2) / (h_1 + h_2) ) )`.

Для випадку, коли один із шарів набагато товщий за інший (`h_2 >> h_1`), фазова швидкість спрощується до вигляду `c_internal ≈ √(g' · h_1)`.

Відповідно, внутрішнє (денсиметричне) число Фруда `Fr_i` визначається як відношення швидкості течії шару `v` до фазової швидкості внутрішніх хвиль: `Fr_i = v / √(g' · h_1) = v / √( g · (Δρ / ρ_2) · h_1 )`.

Коли `Fr_i > 1.0`, потік у стратифікованому середовищі стає внутрішньо надкритичним, що викликає обрушення внутрішніх хвиль, інтенсивне міжшарове перемішування та утворення геофізичних внутрішніх гідравлічних стрибків.

## 7. Біомеханічна модель інвертованого маятника

Розглянемо математичну модель локомоції людини та тварин як інвертований маятник масою `m`, центром мас на висоті `L` (довжина ноги) та кутовою швидкістю обертання `ω = v / L`.

У дугоподібній траєкторії руху центру мас на нього діють дві вертикальні сили: сила тяжіння `m · g` (спрямована вниз до центра Землі) та реакція опори ноги `N` (спрямована вгору уздовж оси кінцівки).

Згідно з другим законом Ньютона для радіального прискорення у найвищій точці кроку: `m · g - N = m · a_c = m · (v² / L)`.

Виразимо нормальну реакцію опори `N`: `N = m · g - m · (v² / L) = m · g · ( 1 - v² / (g · L) ) = m · g · ( 1 - Fr² )`.

де `Fr = v / √(g · L)` — біомеханічне число Фруда.

З цієї математичної залежності випливають такі фізичні умови:
- При `Fr < 1`: `N > 0`, що гарантує збереження контакта стопи з поверхнею ґрунту.
- При `Fr = 1`: `N = 0`, що відповідає повному зникненню притискаючої сили реакції опори.

Ця умова дає теоретичну верхню межу швидкості звичайної ходьби `v_max = √(g · L)`. Для людини з довжиною ноги `L = 0.9` м теоретична межа ходьби становить `v_max = √(9.81 · 0.9) ≈ 2.97 м/с` (близько 10.7 км/год).

## 8. Гранульоване число Фруда для сипучих середовищ

У механіці гранульованих середовищ потік частинок середовища з середнім діаметром `d_p` підпорядковується співвідношенню між динамічним кінетичним напруженням зсуву `τ_dyn ∝ ρ · v²` та гідростатичним гравітаційним тиском шару `p_stat ∝ ρ · g · d_p`.

Відношення цих двох напружень виражає квадрат гранульованого числа Фруда: `Fr_g² = τ_dyn / p_stat = (ρ · v²) / (ρ · g · d_p) = v² / (g · d_p)`.

Взявши квадратний корінь, отримуємо гранульоване число Фруда: `Fr_g = v / √(g · d_p)`.

При `Fr_g > 2.0` кінетична енергія зіткнень гранул перевищує роботу потенціальних сил тяжіння, середовище переходить у стан розрідженої гранульованої «газової» фази, що описується кінетичними рівняннями Больцмана для твердих сфер.

## 9. Питома сила та графічний аналіз спряжених станів

Окрім питомої енергії `E(h)`, у гідравліці відкритих каналів визначають **питому силу** (або функцію імпульсу) `M(h)`: `M(h) = q² / (g · h) + 0.5 · h²`.

Перша похідна питомої сили по глибині дорівнює: `dM/dh = -q² / (g · h²) + h = h · ( 1 - q² / (g · h³) ) = h · ( 1 - Fr² )`.

Це математичне співвідношення демонструє точний дуалізм між енергією та імпульсом:
- При `Fr = 1` питома сила `M(h)` досягає свого абсолютного мінімуму `M_min`.
- Для будь-якого значення питомої сили `M > M_min` існують два спряжені значення глибини `h_1` (надкритичне, `Fr_1 > 1`) та `h_2` (докритичне, `Fr_2 < 1`), які задовольняють рівнянню Беланже.

Графічний перетин кривої питомої енергії `E(h)` та кривої питомої сили `M(h)` на площині `(h, E)` та `(h, M)` унаочнює механізм дисипації енергії у гідравлічному стрибку: при сталому значенні імпульсу `M_1 = M_2` енергія потоку падає від `E_1` до `E_2`, перетворюючи кінетичний швидкісний напір на турбулентні вихори.

## 10. Єдність математичного формулювання числа Фруда

Усі наведені диференціальні та алгебраїчні виведення демонструють єдину математичну природу числа Фруда: воно завжди виникає як фундаментальний коефіцієнт при знерозміренні рівнянь руху суцільних середовищ у полі масових сил. 

Незалежно від конкретної фізичної системи — чи це тривимірні рівняння Нав'є-Стокса, одновимірні рівняння мілководдя Сен-Венана, дисперсійні рівняння поверхневих і внутрішніх хвиль, маятникові рівняння біомеханічної локомоції чи кінетичні рівняння гранульованих потоків — число Фруда виступає єдиним універсальним критичним параметром, що визначає зміну топології та фізичного режиму течії.
