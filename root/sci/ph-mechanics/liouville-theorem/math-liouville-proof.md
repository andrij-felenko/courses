# 🧮 Виведення теореми Ліувілля: якобіан фазового потоку та дужки Пуассона

Теорема Ліувілля є фундаментальною геодезичною точкою зв'язку між класичною механікою Гамільтона та статистичною фізикою. Вона ствердагє, що під дією консервативних гамільтонових сил фазовий потік зберігає фазовий об'єм будь-якої області простору станів. 

Математичний зміст теореми полягає у тому, що векторне поле швидкостей у фазовому просторі є строго соленоїдальним, а визначник матриці Якобі фазового відображення є тотожно рівним одиниці для будь-якого моменту часу.

Нижче наведено три незалежні й математично строгі виведення цієї теореми, кожне з яких розкриває свій власний геометричний, матричний або операторний аспект.

```
                         ТРИ ШЛЯХИ ДО ТЕОРЕМИ ЛІУВІЛЛЯ
                                       │
        ┌──────────────────────────────┼──────────────────────────────┐
        │                              │                              │
        ▼                              ▼                              ▼
  Метод 1: Дивергенція           Метод 2: Якобіан              Метод 3: Перенос густини
  фазового поля швидкостей       фазової трансформації         та дужки Пуассона
  div v = 0                      d(det J)/dt = 0               dρ/dt = ∂ρ/∂t + {ρ,H} = 0
```

## Метод 1: Нульова дивергенція фазового поля швидкостей

Розглянемо консервативну механічну систему з `N` ступенями вільності. Її стан у будь-який момент часу повністю задається `2N` координатами у багатовимірному фазовому просторі:

```
z = (q₁, q₂, ..., q_N, p₁, p₂, ..., p_N)
```

Динаміка еволюції такої системи описується канонічними рівняннями Гамільтона для кожної пари координат та імпульсів `i = 1, ..., N`:

```
q̇ᵢ =  ∂H / ∂pᵢ
ṗᵢ = −∂H / ∂qᵢ
```

де `H = H(q, p, t)` — функція Гамільтона (скалярне полеційна енергія системи).

Вектор швидкості фазового потоку `v` у `2N`-вимірному просторі станів є векторним полем, складеним із похідних усіх фазових координат за часом:

```
v = (q̇₁, ..., q̇_N, ṗ₁, ..., ṗ_N)
```

Обчислимо дивергенцію цього фазового вектора швидкості `∇ · v` за стандартизованим математичним означенням оператора дивергенції у `2N`-вимірному просторі:

```
∇ · v = ∑ᵢ₌₁ⁿ ( ∂q̇ᵢ / ∂qᵢ + ∂ṗᵢ / ∂pᵢ )
```

Підставимо у цю суму канонічні рівняння Гамільтона замість компонент `q̇ᵢ` та `ṗᵢ`:

```
∂q̇ᵢ / ∂qᵢ + ∂ṗᵢ / ∂pᵢ
= ∂/∂qᵢ ( ∂H / ∂pᵢ ) + ∂/∂pᵢ ( −∂H / ∂qᵢ )       [підстановка рівнянь Гамільтона]
= ∂²H / (∂qᵢ ∂pᵢ) − ∂²H / (∂pᵢ ∂qᵢ)              [розкриття частинних похідних]
= 0                                              [рівність мішаних похідних Лемми Шварца]
```

За теоремою Шварца про симетрію мішаних похідних, якщо функція `H` є двічі неперервно диференційовною (належить класу `C²`), то порядок взяття похідної за `qᵢ` та `pᵢ` не має значення. Тому доданок `∂²H / (∂qᵢ ∂pᵢ)` та доданок `-∂²H / (∂pᵢ ∂qᵢ)` у кожній парі координат строго нищать один одного.

Оскільки кожна з `N` пар доданків під знаком суми тотожно дорівнює нулю, ми отримуємо остаточний висновок:

```
∇ · v ≡ 0
```

**Геометричний та фізичний висновок:** Векторне поле швидкостей у фазовому просторі будь-якої консервативної гамільтонової системи є строго соленоїдальним (нестискуваним). Фазова рідина тече без виникнення джерел чи стоків, поводячись як ідеальна несжимаєма рідина.

## Метод 2: Диференціювання якобіана фазової трансформації

Другий метод є прямою геометричною демонстрацією збереження фазового об'єму через аналіз матриці Якобі фазового відображення потоку `gᵗ`.

Нехай у початковий момент часу `t = 0` якась сукупність початкових станів займає область у фазовому просторі з об'ємом `Ω(0)`. Під дією гамільтонового потоку точки цієї області за час `t` переходять у нові координати `z(t) = gᵗ(z(0))`. Зміна елементарного об'єму `dΩ(t)` порівняно з початковим `dΩ(0)` описується визначником матриці Якобі (якобіаном `J(t)`):

```
dΩ(t) = |det J(t)| · dΩ(0)
```

де матриця Якобі `J(t)` розміру `2N × 2N` складається з частинних похідних поточних фазових координат за початковими:

```
J_ij(t) = ∂z_i(t) / ∂z_j(0)
```

У початковий момент часу `t = 0` відображення є тотожнім (`z(0) = z(0)`), тому матриця `J(0)` є одиничною матрицею `I`, а її визначник дорівнює `det J(0) = 1`.

Знайдемо похідну визначника Якобі за часом `d(det J)/dt`. Використаємо класичну матричну формулу Якобі для диференціювання визначників невироджених матриць:

```
d(det J) / dt = det J · Tr( J⁻¹ · dJ/dt )
```

де `Tr` — оператор следу (суми діагональних елементів) матриці.

Обчислимо похідну елементів матриці Якобі за часом `dJ/dt`:

```
d/dt ( ∂z_i(t) / ∂z_k(0) )
= ∂/∂z_k(0) ( dz_i(t)/dt )                           [перестановка похідних за часом і початковими координатами]
= ∂/∂z_k(0) ( v_i(z(t)) )                            [означення поля швидкостей v_i = dz_i/dt]
= ∑_m ( ∂v_i / ∂z_m ) · ( ∂z_m(t) / ∂z_k(0) )       [ланцюгове правило диференціювання складеної функції]
= ∑_m ( ∂v_i / ∂z_m ) · J_mk(t)                      [підстановка елемента матриці Якобі J_mk]
```

У матричній формі цей результат означає:

```
dJ/dt = L · J
```

де `L_im = ∂v_i / ∂z_m` — матриця Якобі (градієнт) поля швидкостей `v`.

Тепер підставимо вираз `dJ/dt = L · J` у формулу Якобі для похідної визначника:

```
d(det J) / dt
= det J · Tr( J⁻¹ · (L · J) )
= det J · Tr( L )               [циклічна властивість следу: Tr(A⁻¹ B A) = Tr(B)]
= det J · ( ∇ · v )             [бо Tr(L) = ∑ ∂v_i/∂z_i = ∇ · v]
```

З Метод 1 ми вже довели, що для гамільтонових систем дивергенція `∇ · v ≡ 0`. Звідси отримуємо диференціальне рівняння для визначника `det J`:

```
d(det J) / dt = det J · 0 = 0
```

Оскільки у початковий момент часу `det J(0) = 1`, а його похідна за часом тотожно дорівнює нулю для всіх моментів `t`, ми приходимо до фундаментального висновку:

```
det J(t) ≡ 1.0
```

Інтегруючи по всій області, отримуємо суворе збереження повного фазового об'єму:

```
Ω(t) = ∫_Ω(t) dq dp = ∫_Ω(0) det J(t) dq₀ dp₀ = Ω(0)
```

## Метод 3: Рівняння переносу густини та дужки Пуассона

Третій спосіб є статистичним і спирається на аналіз функції розподілу ансамблю `ρ(q, p, t)`.

Нехай `ρ(q, p, t) dq dp` виражає ймовірність знайти механічну систему в елементарному фазовому об'ємі `dq dp` біля точки `(q, p)` у момент часу `t`. Законом збереження кількості систем (збереженням ймовірності) є диференціальне рівняння неперервності у фазовому просторі:

```
∂ρ / ∂t + ∇ · (ρ v) = 0
```

Розкриємо дивергенцію добутку скалярного поля `ρ` на векторне поле `v`:

```
∇ · (ρ v) = ρ ( ∇ · v ) + v · ∇ρ
```

Оскільки `∇ · v = 0` (згідно з Методом 1), перший доданок зникає, і рівняння неперервності спрощується до:

```
∂ρ / ∂t + v · ∇ρ = 0
```

Розпишемо скалярний добуток `v · ∇ρ` у координатах фазового простору `(q, p)`:

```
v · ∇ρ = ∑ᵢ₌₁ⁿ ( q̇ᵢ · ∂ρ/∂qᵢ + ṗᵢ · ∂ρ/∂pᵢ )
```

Звідси отримуємо:

```
∂ρ / ∂t + ∑ᵢ₌₁ⁿ ( q̇ᵢ · ∂ρ/∂qᵢ + ṗᵢ · ∂ρ/∂pᵢ ) = 0
```

Згадаємо означення повної (субстанціальної) похідної функції `ρ(q(t), p(t), t)` за часом уздовж траєкторії руху системи:

```
dρ / dt = ∂ρ / ∂t + ∑ᵢ₌₁ⁿ ( dqᵢ/dt · ∂ρ/∂qᵢ + dpᵢ/dt · ∂ρ/∂pᵢ )
```

Порівнюючи ці два вирази, бачимо, що рівняння неперервності еквівалентне вимозі:

```
dρ / dt = 0
```

Це означає: **густина фазової рідини уздовж будь-якої індивідуальної траєкторії руху залишається незмінною в часі**.

Тепер підставимо канонічні рівняння Гамільтона `q̇ᵢ = ∂H/∂pᵢ` та `ṗᵢ = -∂H/∂qᵢ` у вираз для похідної:

```
∂ρ / ∂t + ∑ᵢ₌₁ⁿ ( ∂H/∂pᵢ · ∂ρ/∂qᵢ − ∂H/∂qᵢ · ∂ρ/∂pᵢ ) = 0
```

Вираз під знаком суми є точним означенням **дужок Пуассона** `{ρ, H}` зі знаком мінус:

```
{ρ, H} = ∑ᵢ₌₁ⁿ ( ∂ρ/∂qᵢ · ∂H/∂pᵢ − ∂ρ/∂pᵢ · ∂H/∂qᵢ )
```

Таким чином, рівняння Ліувілля для фазової густини набуває своєї класичної операторної форми:

```
∂ρ / ∂t + {ρ, H} = 0
```

або у вигляді оператора Ліувілліана `L_H = i {H, ·}`:

```
∂ρ / ∂t = −{ρ, H} = −i L_H ρ
```

## Приклад: Перевірка на 1D гармонічному осциляторі

Перевіримо роботу якобіана та збереження площі на конкретному фізичному прикладі одновимірного гармонічного осцилятора з масою `m` та частотою `ω`.

Гамільтоніан системи:

```
H(q, p) = p² / (2m) + ½ m ω² q²
```

Рівняння руху:

```
q̇ = ∂H / ∂p = p / m
ṗ = −∂H / ∂q = −m ω² q
```

Точний розв'язок рівнянь руху для початкових умов `(q₀, p₀)` у момент `t = 0`:

```
q(t) =  q₀ · cos(ωt) + (p₀ / (m ω)) · sin(ωt)
p(t) = −q₀ · m ω · sin(ωt) + p₀ · cos(ωt)
```

Знайдемо елементи матриці Якобі `J(t)` переходів від `(q₀, p₀)` до `(q(t), p(t))`:

```
J = ┌                                         ┐
    │  ∂q(t)/∂q₀            ∂q(t)/∂p₀         │
    │                                         │
    │  ∂p(t)/∂q₀            ∂p(t)/∂p₀         │
    └                                         ┘

  = ┌                                         ┐
    │  cos(ωt)              sin(ωt) / (m ω)   │
    │                                         │
    │ −m ω sin(ωt)          cos(ωt)           │
    └                                         ┘
```

Обчислимо визначник цієї матриці `det J`:

```
det J = ( cos(ωt) ) · ( cos(ωt) ) − ( sin(ωt) / (m ω) ) · ( −m ω sin(ωt) )  [визначник 2x2: a·d - b·c]
      = cos²(ωt) + sin²(ωt)                                                [скорочення m·ω]
      = 1.0                                                                [тригонометрична тотожність: cos²α + sin²α = 1]
```

Визначник `det J` дорівнює **точно 1.0** для будь-якого моменту часу `t` незалежно від параметрів `m` та `ω`. Будь-який круг у початковий момент часу повертається у фазовому просторі як ціле, перетворюючись на еліпс тієї самої площі, підтверджуючи точність теореми Ліувілля.

## Формалізм похідної Лі та диференціальних форм

Для глибшого розуміння геометричної структури механіки сучасної математикою використовується формалізм диференціальних форм та похідної Лі.

У фазовому просторі `M` розмірності `2N` канонічна симплектична 2-форма `ω` записується як:

```
ω = ∑ᵢ₌₁ⁿ dqᵢ ∧ dpᵢ
```

Зовнішній диференціал цієї форми дорівнює нулю (`dω = 0`), тобто вона є замкненою.

Гамільтонова система задає векторне поле `X_H`, яке визначається умовою:

```
i_{X_H} ω = −dH
```

де `i_X` — оператор внутрішнього добутку (підстановки векторного поля у форму).

Зміна симплектичної форми `ω` вздовж фазового потоку `gᵗ` описується **похідною Лі** `L_{X_H} ω`. За формулою Картана (картанівською тотожністю) для похідної Лі маємо:

```
L_{X_H} ω = d( i_{X_H} ω ) + i_{X_H} ( dω )
```

Підставимо сюди `i_{X_H} ω = -dH` та `dω = 0`:

```
L_{X_H} ω = d( −dH ) + i_{X_H} ( 0 ) = −d²H = 0
```

Оскільки другий зовнішній диференціал будь-якої функції тотожно дорівнює нулю (`d²H ≡ 0`), отримуємо:

```
L_{X_H} ω ≡ 0
```

Похідна Лі симплектичної форми `ω` вздовж гамільтонового векторного поля тотожно дорівнює нулю. Це означає, що фазовий потік `gᵗ` є **симплектоморфізмом** — відображенням, яке зберігає симплектичну структуру.

Оскільки фазовий об'єм є `N`-м зовнішнім ступенем симплектичної форми:

```
dV = ( 1 / N! ) · ω ∧ ω ∧ ... ∧ ω    [N разів]
```

похідна Лі елемента об'єму за правилом Лейбніца дає:

```
L_{X_H} dV = ( 1 / N! ) · ∑ ( ω ∧ ... ∧ L_{X_H} ω ∧ ... ∧ ω ) = 0
```

Це надає найкоротше й найбільш елегантне сучасне доведення теореми Ліувілля у термінах диференціальної геометрії.
