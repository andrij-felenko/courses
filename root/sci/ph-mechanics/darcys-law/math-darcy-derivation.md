# 🧮 Математичне виведення закону Дарсі та модель Кармана-Козені

Закон Дарсі виник як емпірична формулювання на основі натурних вимірювань фільтрації води крізь пісок. Проте у сучасній класичній теоретичній фізиці та механіці суцільних середовищ закон Дарсі має суворе математичне обґрунтування. На макроскопічному рівні пористе середовище розглядається як суцільний тривимірний континууальний простір. Проте на мікроскопічному рівні флюїд огинає тисячі окремих твердих зерен або тече складною мережею мікроскопічних пористих каналів. Перехід від мікроскопічних рівнянь руху Нав'є-Стокса до макроскопічного закону Дарсі здійснюється за допомогою методів математичного усереднення по репрезентативному елементарному об'єму (REV).

![Мікроскопічний вигляд звивистих пор проти макроскопічного репрезентативного елементарного об'єму REV](img/pore-microscope.svg)
*Концепція репрезентативного елементарного об'єму REV: перехід від мікроскопічного поля швидкостей у порах vₚ до макроскопічного вектора швидкості фільтрації vⲇ.*

## 1. Мікроскопічний режим та усереднення за об'ємом REV

У більшості підземних та фільтраційних процесів швидкість флюїду всередині пор є надзвичайно малою — від кількох міліметрів на добу до кількох сантиметрів на секунду. Це означає, що число Рейнольдса, розраховане за діаметром окремої пори, є набагато меншим за одиницю (`Reₚ ≪ 1`). За таких умов конвективними інерційними членами `(v · ∇)v` у рівняннях Нав'є-Стокса можна повністю знехтувати, і рух рідини описується стаціонарними **рівняннями Стокса**:

```
∇p = μ ∇²v + ρ g       [баланс в'язких та гідростатичних сил]
∇ · v = 0              [умова нестисливості флюїду]
```

з умовою прилипання `v = 0` на всій складно вигнутій поверхні твердих зерен пористого каркаса.

Для переходу до макроскопічного опису введемо репрезентативний елементарний об'єм `V` з характерним лінійним розміром `L_REV`. Цей розмір вибирається так, щоб задовольняти строгій ієрархічній нерівності масштабів:

```
dₚ  ≪  L_REV  ≪  L_macro
```

де `dₚ` — середній діаметр окремих пор чи зерен, а `L_macro` — макроскопічний розмір усього фільтраційного пласта чи об'єкта.

Позначимо об'єм порового простору всередині `V` як `V_pore`, а об'єм твердих зерен як `V_grain`. Загальна пористість середовища дорівнює відношенню:

```
ϕ = V_pore / V
```

Введемо два математичні оператори просторового усереднення за об'ємом `V`:

1. **Дійсна (фазова) порова швидкість** `<v>_pore` — середня швидкість флюїду безпосередньо всередині порового простору:

```
<v>_pore = (1 / V_pore) · ∫_V_pore v dV
```

2. **Макроскопічна швидкість фільтрації (вектор Дарсі)** `v_d` — фіктивна швидкість потоку, розрахована на весь валовий геометричний переріз середовища (включаючи непроникні тверді зерна):

```
v_d = (1 / V) · ∫_V_pore v dV = ϕ · <v>_pore
```

Застосуємо теорему про просторове усереднення градієнта та лапласіана (теорема Віттакера-Слаттері) до рівнянь Стокса. Згідно з цією теоремою, об'ємний інтеграл від мікроскопічного градієнта тиску розпадається на градієнт макроскопічного середнього тиску `∇<p>` та поверхневий інтеграл сил в'язкого опору `F_drag` на межі розділу «тверде тіло — рідина»:

```
∇<p> = (1 / V_pore) · ∫_S_grain (p I − μ ∇v) · n dS
```

Оскільки мікроскопічні рівняння Стокса є абсолютно лінійними відносно швидкості `v` та тиску `p`, сила в'язкого опору на поверхні зерен складної форми мусить бути суворо прямо пропорційною середній швидкості фільтрації `v_d` та динамічній в'язкості `μ`:

```
F_drag = (μ / k) · v_d
```

де `k` — коефіцієнт пропорційності з розмірністю площі (м²), який залежить виключно від геометричної архітектури твердого каркаса. Прирівнюючи макроскопічний градієнт тиску до сил в'язкого опору породи, дістаємо класичний **векторний закон Дарсі**:

```
v_d = − (k / μ) · (∇p − ρ g)
```

Математичний принцип мінімуму дисипації енергії доводить, що для будь-якої симетричної геометрії пор тензор проникності `k_ij` є симетричним (`k_ij = k_ji`) та додатно визначеним.

## 2. Детальне виведення моделі Кармана-Козені

Хоча формальне усереднення доводить лінійність закону Дарсі, воно не дає явної формули для обчислення значення проникності `k` через геометричні параметри породи. Для вирішення цієї задачі використовують **модель Кармана-Козені** (*Kozeny-Carman model*), яка апроксимує пористий простір пучком звивистих капілярних трубок.

Розглянемо капілярну трубку неколового перерізу з гідравлічним радіусом `r_h`. За визначенням, гідравлічний радіус дорівнює відношенню об'єму пор до площі їхньої змочуваної поверхні:

```
r_h = V_pore / A_wetted = ϕ / ((1 − ϕ) · S_v)
```

де `S_v` — питома поверхня твердих зерен (площа поверхні зерен на одиницю об'єму твердої фази, м⁻¹).

Згідно з [течією Пуазейля](topic:ph-mechanics/poiseuille-flow), середня швидкість флюїду у капілярі завдовжки `L_t` під дією перепаду тиску `Δp` дорівнює:

```
v_cap = (r_h² / (C_shape · μ)) · (Δp / L_t)
```

де `C_shape` — безрозмірний коефіцієнт форми перерізу каналу (для круглого перерізу `C_shape = 2`, для еліптичного чи трикутного `C_shape ≈ 2.5...3.0`).

Урахуємо **звивистість** порових каналів (*tortuosity*) `τ`, яка показує, наскільки реальний покручений шлях флюїду `L_t` довший за пряму товщину пласта `L`:

```
τ = L_t / L  ≥  1
```

Макроскопічна швидкість Дарсі пов'язана з капілярною швидкістю співвідношенням проекції вектора швидкості:

```
v_d = (ϕ / τ) · v_cap
```

Підставимо швидкість `v_cap` та гідравлічний радіус `r_h` у вираз для `v_d`:

```
v_d = (ϕ / τ) · (r_h² / (C_shape · μ)) · (Δp / (τ · L))
    = (ϕ³ / (C_shape · τ² · (1 − ϕ)² · S_v²)) · (1 / μ) · (Δp / L)
```

Порівняємо отриманий результат із макроскопічним законом Дарсі `v_d = (k / μ) · (Δp / L)`. Звідси випливає знаменита **формула Кармана-Козені** для проникності:

```
k = ϕ³ / (C_K · S_v² · (1 − ϕ)²)
```

де `C_K = C_shape · τ²` — безрозмірна **константа Козені** (для більшості природних кулястих пісків та ґрунтів `C_K ≈ 5`).

Якщо зерна породи мають сферичну форму з середнім діаметром `dₚ`, їхня питома поверхня дорівнює `S_v = 6 / dₚ`. Підставивши це значення при `C_K = 5`, отримуємо розрахункову інженерну формулу Кармана-Козені:

```
k = (dₚ² · ϕ³) / (5 · 36 · (1 − ϕ)²) = (dₚ² · ϕ³) / (180 · (1 − ϕ)²)
```

## 3. Еквівалентна проникність шаруватих пластів

У реальній геології водоносні та нафтові пласти складаються з чергування багатьох паралельних шарів із різною товщиною `d_i` та різною проникністю `k_i`. Розглянемо два граничні випадки обчислення еквівалентної проникності пласта.

### 1. Фільтрація паралельно шаруватості (Потік вздовж пластів)
Коли градієнт тиску прикладений уздовж шарів, повна витрата дорівнює сумі витрат крізь кожен окремий шар. Еквівалентна проникність є **середнім арифметичним**:

```
k_parallel = (∑_i k_i · d_i) / (∑_i d_i)
```

Основний потік рідини прямує крізь найбільш проникні прошарки.

### 2. Фільтрація перпендикулярно до шаруватості (Потік поперек пластів)
Коли рідина мусить послідовно подолати всі шари, швидкість фільтрації `v_d` є однаковою для всіх шарів, а повна втрата напору дорівнює сумі втрат у кожному шарі. Еквівалентна проникність є **середнім гармонічним**:

```
k_perp = (∑_i d_i) / (∑_i (d_i / k_i))
```

З нерівності Коші-Буняковського випливає, що паралельна проникність завжди більша або дорівнює перпендикулярній (`k_parallel ≥ k_perp`). Навіть один дуже тонкий глиняний прошарок з невеликою проникністю `k_clay` спроможний практично повністю заблокувати фільтрацію у перпендикулярному напрямку.
