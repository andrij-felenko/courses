# 📋 Довідник інтерфейсу розрахунку розширення Прандтля — Майєра

Цей довідник містить повну технічну специфікацію, коди помилок, деталізований опис структур даних, сигнатур функцій, математичних контрактів, конфігураційних параметрів та табличних газодинамічних функцій для програмних бібліотек і алгоритмів, що виконують розрахунок течії Прандтля — Майєра.

Довідник призначений для розробників аеродинамічних програмних комплексів, обчислювальних модулів систем автоматизованого проектування (CAD/CAE), методів характеристик (MOC) та бекендів чисельного моделювання газової динаміки (CFD, таких як OpenFOAM, SU2 чи ANSYS Fluent).

## 1. Математичний контракт та вхідні обмеження

Обчислювальне ядро течії Прандтля — Майєра базується на припущенні про двовимірну, стаціонарну, невизначену (безв'язкову) течію ідеального газу зі сталою теплоємністю (`γ = c_p / c_v = const`). Для гарантування фізичної коректності та обчислювальної стійкості алгоритми розрахунку повинні строго перевіряти вхідні параметри перед початком обчислень.

Першою та найважливішою умовою є приналежність вхідного числа Маха до надзвукового діапазону (`M₁ > 1.0`). Якщо вхідний потік є дозвуковим (`M₁ < 1.0`), утворення веєра розширення Прандтля — Майєра є фізично неможливим, оскільки звукові хвилі випереджають потік і формують еліптичну структуру течії. У разі надходження дозвукового значення модуль повинен миттєво повертати відповідну помилку без запуску ітераційних процедур.

Другою критичною умовою є перевірка геометрії повороту. Кут повороту стінки `Δθ` має бути невід'ємним (`Δθ ≥ 0`). При від'ємних значеннях `Δθ` потік повертає убік увігнутого кута, що призводить не до розширення, а до стиснення із формуванням косого скачка ущільнення. Для розрахунку скачків ущільнення мають використовуватись рівняння Ранкіна — Ґюґоніо, а не функція Прандтля — Майєра.

Третьою умовою є перевірка показника адіабати газу `γ`. Фізично допустимий діапазон становить `1.0 < γ ≤ 5/3`. Для одноатомних інертних газів (аргон, гелій) `γ = 5/3 ≈ 1.667`, для двоатомних газів (повітря, азот, кисень) `γ = 1.400`, а для багатоатомних газів та пари `γ = 1.10–1.33`.

### 1.1. Області визначення вхідних параметрів

У нижченаведеній таблиці зібрано вимоги до типів даних, допустимих меж змінних та рекомендованих дефолтних параметрів для чисельних солверів:

| Параметр | Позначення | Тип | Фізичний зміст | Допустимий діапазон | Рекомендоване значення |
| :--- | :---: | :---: | :--- | :---: | :---: |
| Вхідне число Маха | `M1` | `double` | Безрозмірна швидкість набігаючого потоку | `(1.000001, +∞)` | `1.05 – 10.0` |
| Кут повороту стінки | `delta_deg` | `double` | Геометричний кут відхилення поверні (град) | `[0.0, ν_max - ν1)` | `0.0 – 60.0°` |
| Показник адіабати | `gamma` | `double` | Відношення питомих теплоємностей | `(1.0, 5/3]` | `1.40` (повітря) |

### 1.2. Граничні фізичні константи залежно від газу

Граничний кут розширення `ν_max` визначається показником адіабати `γ`. Він виражає теоретичний максимум кута повороту, при якому статичний тиск газу падає до нуля (розширення в вакуум):

```
ν_max(γ) = (π / 2) · [ √((γ + 1) / (γ - 1)) - 1 ]
```

У цій таблиці наведено константи граничних кутів для різних робочих тіл, що зустрічаються в аерокосмічній техніці:

| Газ / Середовище | `γ` | `√((γ+1)/(γ-1))` | `ν_max` (радіани) | `ν_max` (градуси) |
| :--- | :---: | :---: | :---: | :---: |
| Одноатомні гази (Ar, He, Ne) | `1.6667` | `2.0000` | `1.5708` | `90.000°` |
| Двоатомні гази (N₂, O₂, повітря при T < 600K) | `1.4000` | `2.4495` | `2.2769` | `130.454°` |
| Трьохатомні гази / пара (CO₂, H₂O) | `1.3333` | `2.6458` | `2.5852` | `148.125°` |
| Високотемпературні продукти згоряння ЖРД | `1.2000` | `3.3166` | `3.6389` | `208.497°` |

## 2. Специфікація структур даних

Для забезпечення міжмовної сумісності між модулями на мовах C, C++, Python та Fortran у бекенді газодинамічних розрахунків введено уніфіковані структури даних із чітким вирівнюванням полів у пам'яті.

### 2.1. Структура фізичних властивостей газу (`pm_gas_t` / `GasProperties`)

Ця структура описує термодинамічні константи робочого тіла. Вона передається в усі розрахункові функції як вхідний контекст середовища. Поле `R_specific` містить питому газову сталу `R = R_universal / M_molar`.

:::tabs
```c
typedef struct {
    double gamma;       /* Показник адіабати (c_p / c_v) */
    double R_specific;  /* Питома газова стала, Дж/(кг·К) */
    double M_molar;     /* Молярна маса газу, кг/моль */
} pm_gas_t;
```
```cpp
struct GasProperties {
    double gamma{1.40};         // Показник адіабати (c_p / c_v)
    double R_specific{287.058}; // Питома газова стала, Дж/(кг·К)
    double M_molar{0.028964};   // Молярна маса газу, кг/моль
};
```
:::

### 2.2. Повний стан потоку у точці (`pm_state_t` / `FlowState`)

Ця структура є основним контейнером результатів обчислення стану потоку до або після веєра розширення. Вона містить як кінематичні (числа Маха, кути), так і термодинамічні відношення. Всі поля обчислюються з підвищеною точністю подвійної плаваючої крапки.

:::tabs
```c
typedef struct {
    double M;           /* Місцеве число Маха */
    double nu_rad;      /* Значення функції Прандтля — Майєра (рад) */
    double nu_deg;      /* Значення функції Прандтля — Майєра (град) */
    double mu_rad;      /* Кут Маха μ = arcsin(1/M) (рад) */
    double mu_deg;      /* Кут Маха μ (град) */
    double p_p0;        /* Відношення статичного тиску до повного p/p0 */
    double T_T0;        /* Відношення статичної температури до повної T/T0 */
    double rho_rho0;    /* Відношення густини до повної rho/rho0 */
    double v_aSt;       /* Безрозмірна швидкість v / a* (параметр Лаваля λ) */
} pm_state_t;
```
```cpp
struct FlowState {
    double M{1.0};            // Місцеве число Маха
    double nu_rad{0.0};       // Значення функції Прандтля — Майєра (рад)
    double nu_deg{0.0};       // Значення функції Прандтля — Майєра (град)
    double mu_rad{0.0};       // Кут Маха μ = arcsin(1/M) (рад)
    double mu_deg{0.0};       // Кут Маха μ (град)
    double p_p0{1.0};         // Відношення статичного тиску до повного p/p0
    double T_T0{1.0};         // Відношення статичної температури до повної T/T0
    double rho_rho0{1.0};     // Відношення густини до повної rho/rho0
    double v_aSt{1.0};        // Безрозмірна швидкість v / a* (параметр Лаваля λ)
};
```
:::

### 2.3. Структура сіткового вузла веєра розширення (`pm_fan_ray_t` / `FanRayNode`)

При побудові характеристичних сіток у розрахунках методом характеристик (MOC) або для візуалізації веєра у CFD-системах веєр розбігання розділяють на `N` дискретних променів. Опис променя Маха виконано у двоїстому C/C++ поданні.

:::tabs
```c
typedef struct {
    int index;            /* Номер променя у веєрі (0..N) */
    double theta_deg;     /* Поточний кут повороту потоку від входу (град) */
    double ray_angle_deg; /* Фізичний кут променя Маха відносно вхідного напрямку */
    pm_state_t state;     /* Газодинамічний стан газу на даному промені */
} pm_fan_ray_t;
```
```cpp
struct FanRayNode {
    std::size_t index{0};     // Номер променя у веєрі (0..N)
    double theta_deg{0.0};    // Поточний кут повороту потоку від входу (град)
    double ray_angle_deg{0.0};// Фізичний кут променя Маха відносно вхідного напрямку
    FlowState state;          // Газодинамічний стан газу на даному промені
};
```
:::

## 3. Специфікація функціонального API

### 3.1. Перелік кодів повернення (`pm_error_t` / `ExpansionError`)

Усі функції обчислювального модуля повертають цілочисельний код статусу виконання або повертають об'єкт помилки типу `enum class` у C++.

:::tabs
```c
typedef enum {
    PM_SUCCESS               =  0,  /* Успішне виконання */
    PM_ERR_NULL_POINTER      = -1,  /* Передано нульовий вказівник */
    PM_ERR_SUBSONIC_FLOW     = -2,  /* Вхідне число Маха M1 <= 1.0 */
    PM_ERR_INVALID_GAMMA     = -3,  /* Некоректне значення gamma <= 1.0 */
    PM_ERR_VACUUM_EXCEEDED   = -4,  /* Кут повороту перевищує вакуумну межу */
    PM_ERR_CONVERGENCE_FAIL  = -5,  /* Ітераційний метод не збігся за max_iter */
    PM_ERR_OUT_OF_MEMORY     = -6   /* Помилка виділення пам'яті під сітку */
} pm_error_t;
```
```cpp
enum class ExpansionError : std::int32_t {
    Success = 0,
    NullPointer = -1,
    SubsonicFlow = -2,
    InvalidGamma = -3,
    VacuumLimitExceeded = -4,
    ConvergenceFailed = -5,
    OutOfMemory = -6
};
```
:::

### 3.2. Сигнатури основних розрахункових функцій

#### `pm_nu` / `nu` — Обчислення прямої функції Прандтля — Майєра
Обчислює кут повороту звукового потоку у радіанах при прискоренні до числа Маха `M`. Функція виражається замкненою аналітичною формулою.

:::tabs
```c
double pm_nu(double M, double gamma);
```
```cpp
[[nodiscard]] constexpr double nu(double M, double gamma = 1.40) noexcept;
```
:::

#### `pm_mu` / `mu` — Обчислення кута Маха
Обчислює кут нахилу акустичної хвилі збурення `μ = arcsin(1/M)` у радіанах відносно вектора швидкості потоку.

:::tabs
```c
double pm_mu(double M);
```
```cpp
[[nodiscard]] constexpr double mu(double M) noexcept;
```
:::

#### `pm_inverse_nu` / `inverse_nu` — Чисельне інвертування функції ν(M)
Розв'язує обернену задачу методом Ньютона — Рафсона. Шукає число Маха `M`, для якого значення функції `ν(M)` дорівнює заданому `nu_target`.

:::tabs
```c
pm_error_t pm_inverse_nu(double nu_target, double gamma, double tol, 
                          int max_iter, double *out_M);
```
```cpp
[[nodiscard]] std::expected<double, ExpansionError> inverse_nu(
    double nu_target, double gamma = 1.40, 
    double tol = 1e-12, std::size_t max_iter = 100) noexcept;
```
:::

#### `pm_solve_expansion` / `solve_expansion` — Повний розрахунок переходу через веєр
Головна функція інтерфейсу, яка за вхідними `M₁`, `Δθ` та `γ` обчислює повний стан потоку до та після розширення, заповнюючи структури стану.

:::tabs
```c
pm_error_t pm_solve_expansion(double M1, double delta_deg, double gamma,
                               pm_state_t *state1, pm_state_t *state2);
```
```cpp
[[nodiscard]] std::expected<std::pair<FlowState, FlowState>, ExpansionError> 
solve_expansion(double M1, double delta_deg, double gamma = 1.40) noexcept;
```
:::

#### `pm_generate_fan_rays` / `generate_fan_rays` — Дискретизація веєра хвиль Маха
Формує масив точок дискретизації всередині веєра розширення для побудови характеристичних сіток у газодинамічних розрахунках.

:::tabs
```c
pm_error_t pm_generate_fan_rays(double M1, double delta_deg, double gamma,
                                 int num_rays, pm_fan_ray_t *rays_array);
```
```cpp
[[nodiscard]] std::expected<std::vector<FanRayNode>, ExpansionError> 
generate_fan_rays(double M1, double delta_deg, double gamma = 1.40, 
                  std::size_t num_rays = 10) noexcept;
```
:::

## 4. Обробка крайових режимів та виняткових ситуацій

### 4.1. Обробка звукового стану (`M1 → 1.0⁺`)

Коли вхідний потік наближається до звукової межі (`M1 → 1.0`), кут Маха `μ1 → 90°`. Перша лінія Маха веєра стає суворо перпендикулярною до стінки. 
В обчислювальному ядрі застосовується апроксимація Тейлора при `M = 1.0 + ε` (`ε << 1`):

```
ν(ε) ≈ [ (2 / (γ + 1)) · (2ε)³ ] ^ (1/2) = (2 / (γ + 1))^(1/2) · (M² - 1)^(3/2) / 3
```

Це запобігає втраті точності при відніманні близьких чисел у розкладі `arctan(√(M² - 1))`.

### 4.2. Наближення до межі вакууму (`ν₂ → ν_max⁻`)

Коли кут повороту наближається до граничного `ν_max`:
- Статичний тиск прямує до нуля: `p₂ / p₁ → 0`.
- Абсолютна температура прямує до нуля: `T₂ / T₁ → 0`.
- Число Маха прямує до нескінченності: `M₂ → ∞`.

При досягненні `ν₂ >= ν_max - 1e-7` функція `pm_solve_expansion` повертає код `PM_ERR_VACUUM_EXCEEDED`. Течія більше не може залишатися притиснутою до стінки і відривається, утворюючи порожнину вакууму (сухий слід).
