# 🧮 Математичні моделі середнього напруження та нелінійної втоми

Втомні випробування зразків у лабораторіях зазвичай проводять в умовах чисто симетричного знакозмінного згину або розтягу-стиску. У такому базовому режимі середнє напруження дорівнює нулю (`σ_m = 0`), а коефіцієнт асиметрії навантаження становить `R = σ_min / σ_max = −1`. Проте елементи реальних машин і споруд рідко працюють за нульового середнього напруження. Конструктивні фактори — власна вага балок, попереднє затягування нарізних з'єднань, постійний внутрішній тиск у резервуарах та трубопроводах, відцентрові сили в роторах турбін, а також залишкові зварювальні напруження — створюють сталу напружену складову, на яку накладаються змінні експлуатаційні коливання.

Щоб застосувати стандартну криву втоми Веллера до випадкового спектра, необхідно вміти аналітично перетворювати довільний асиметричний цикл `(σ_a, σ_m)` на еквівалентну симетричну амплітуду `σ_ar` (`R = −1`), яка завдає металу точно такого самого втомного пошкодження за однакову кількість циклів.

### Повна кінематична параметризація втомного циклу

Один гармонічний або квазігармонічний цикл напруження описується часовою функцією з екстремумами `σ_max` (максимальне напруження) та `σ_min` (мінімальне напруження). В інженерній практиці використовують взаємопов'язані параметри розмаху, амплітуди, середнього рівня та коефіцієнтів асиметрії:

```
σ_max   — максимальне напруження циклу
σ_min   — мінімальне напруження циклу
Δσ      = σ_max - σ_min              [розмах напруження]
σ_a     = Δσ / 2                     [амплітуда змінного напруження]
σ_m     = (σ_max + σ_min) / 2        [середнє напруження циклу]
R       = σ_min / σ_max              [коефіцієнт асиметрії напружень]
A       = σ_a / σ_m = (1 - R)/(1 + R)[коефіцієнт амплітуди]
```

Зв'язок між амплітудою `σ_a`, середнім напруженням `σ_m` та коефіцієнтом асиметрії `R` виражається точними аналітичними формулами:

```
σ_m = σ_a · (1 + R) / (1 - R)
σ_a = σ_max · (1 - R) / 2
σ_max = σ_m + σ_a = σ_a · (1 + R) / (1 - R) + σ_a = 2 · σ_a / (1 - R)
```

Залежно від знака `σ_max` і `σ_min` розрізняють характерні режими навантаження:
- `R = −1` (`σ_m = 0`): симетричний знакозмінний цикл (базовий режим кривої Веллера);
- `R = 0` (`σ_min = 0`, `σ_m = σ_a = σ_max / 2`): віднульовий пульсуючий розтяг;
- `0 < R < 1` (`σ_min > 0`, `σ_max > 0`): асиметричний розтягувальний цикл (знакопостійний розтяг);
- `R = −∞` (`σ_max = 0`): віднульовий пульсуючий стиск;
- `−∞ < R < −1` (`|σ_min| > σ_max > 0`): асиметричний знакозмінний цикл із переважанням стиску.

### Лінійна модель Гудмана (Goodman)

Модель Гудмана базується на лінійній інтерполяції границі витривалості між чистою симетричною втомою `(σ_m = 0, σ_a = σ_e)` та статичним розривом `(σ_m = σ_u, σ_a = 0)`, де `σ_e` — межа витривалості при `R = −1`, `σ_u` — тимчасовий опір (границя міцності при розтягу).

Рівняння граничної прямої на діаграмі Хейга:

```
σ_a / σ_e + σ_m / σ_u = 1
```

Виведення еквівалентної симетричної амплітуди `σ_ar` для довільного циклу з амплітудою `σ_a` та середнім напруженням `σ_m`:

```
σ_a / σ_ar + σ_m / σ_u = 1                 [критерій еквівалентного пошкодження]
σ_a / σ_ar = 1 - σ_m / σ_u                 [відокремлення відношення амплітуд]
σ_ar = σ_a / (1 - σ_m / σ_u)               [ділення на вираз у знаменнику]
```

Якщо виразити еквівалентну амплітуду безпосередньо через максимальне напруження `σ_max` та коефіцієнт асиметрії `R`:

```
σ_ar = σ_max · (1 - R) / (2 - (1 + R) · σ_max / σ_u)
```

Модель Гудмана є фундаментальним промисловим стандартом для малопластичних сталей, високоміцних алюмінієвих сплавів (серій 2024, 7075) та деталей із концентраторами напружень за додатного середнього напруження (`0 < σ_m < σ_u`).

### Параболічна модель Гербера (Gerber)

Гербер встановив, що для пластичних вуглецевих і легованих сталей пряма Гудмана є надмірно консервативною за малих і помірних середніх напружень. Експериментальні точки на діаграмі Хейга для пластичних матеріалів утворюють опуклу криву, яку добре описує парабола.

Рівняння граничного стану за Гербером:

```
σ_a / σ_e + (σ_m / σ_u)² = 1
```

Аналітичне виведення еквівалентної амплітуди `σ_ar`:

```
σ_a / σ_ar + (σ_m / σ_u)² = 1              [параболічний закон еквівалентності]
σ_a / σ_ar = 1 - (σ_m / σ_u)²              [перенесення квадратичного доданка]
σ_ar = σ_a / (1 - (σ_m / σ_u)²)            [розв'язання відносно σ_ar]
```

За малих значень відношення `σ_m / σ_u < 0.3` поправка Гербера дає менше еквівалентне напруження, ніж пряма Гудмана, що дозволяє уникнути зайвого переобтяження конструкції. Проте для крихких деталей, зварних швів та зон із гострими концентраторами напружень використання моделі Гербера не рекомендується через ризик завищення довговічності.

### Консервативна модель Зедерберга (Soderberg)

Зедерберг запропонував найбільш обережний інженерний підхід: замінити межу міцності `σ_u` на границю плинності `σ_y`. Мета цієї поправки — одночасно захистити деталь як від втомного руйнування, так і від будь-якої залишкової макроскопічної пластичної деформації.

Рівняння кривої Зедерберга:

```
σ_a / σ_e + σ_m / σ_y = 1
```

Еквівалентна амплітуда `σ_ar`:

```
σ_ar = σ_a / (1 - σ_m / σ_y)
```

Модель Зедерберга широко використовується в енергетичному машинобудуванні, котлонагляді та нормах проектування валів за стандартами ASME.

### Деформаційно-напружена модель Морроу (Morrow)

При розрахунку втоми в зоні малоциклової та перехідної довговічності (деформаційний підхід за локальними деформаціями `ε–N`) Морроу ввів середнє напруження безпосередньо в пружну частину рівняння Коффіна — Менсона — Басквіна. Замість інженерної межі міцності `σ_u` використовується істинне напруження руйнування зразка при статичному розтягу `σ_f'` (коефіцієнт втомної міцності):

```
σ_ar = σ_a / (1 - σ_m / σ_f')
```

Для більшості конструкційних сталей середньої міцності величина `σ_f'` добре апроксимується емпіричним співвідношенням `σ_f' ≈ σ_u + 345 МПа`. Модель Морроу забезпечує високу точність прогнозування для сталей, але для алюмінієвих сплавів може давати похибку через різницю в циклічному зміцненні.

### Енергетичний критерій Сміта — Вотсона — Топпера (Smith-Watson-Topper, SWT)

Для циклів із суттєвою локальною пластичністю біля надрізу Сміт, Вотсон і Топпер запропонували комбінований критерій, заснований на добутку максимального напруження циклу `σ_max` та розмаху повної деформації `Δε`.

У зоні пружної поведінки (багатоциклова втома) критерій SWT виражається через максимальне напруження та амплітуду:

```
σ_ar = √(σ_max · σ_a)                      [еквівалентна амплітуда за критерієм SWT]
```

Якщо підставити вираз `σ_max = σ_m + σ_a`:

```
σ_ar = √((σ_m + σ_a) · σ_a) = σ_a · √(1 + σ_m / σ_a)
```

Критерій SWT має дві важливі особливості:
1. При симетричному циклі (`σ_m = 0`, `σ_max = σ_a`) вираз автоматично спрощується до `σ_ar = σ_a`.
2. Якщо максимальне напруження циклу є стискальним (`σ_max ≤ 0`), критерій дає `σ_ar = 0`. Це відповідає фізичному факту: в умовах постійного стиску береги втомної тріщини щільно замкнуті, і тріщина не розвивається.

### Границя статичної плинності (зріз Лангера)

Жоден втомний розрахунок не може дозволити максимальному напруженню перевищити границю плинності матеріалу `σ_y`, інакше деталь зазнає неприпустимих пластичних деформацій уже на першому напівциклі.

Тому на діаграмі Хейга безпечна область завжди обмежується додатковою лінією статичної плинності Лангера (*Langer static yield limit*):

```
σ_a + σ_m ≤ σ_y                            [для розтягувальних середніх напружень]
σ_a + |σ_m| ≤ σ_y                          [універсальна умова плинності]
```

Підсумкова межа працездатності деталі є нижньою обвідною між втомною кривою (Гудмана або Гербера) та лінією статичної плинності.

### Числове порівняння моделей на конкретному прикладі

Порівняємо еквівалентні амплітуди `σ_ar`, розраховані за різними моделями, для зразка з авіаційного алюмінієвого сплаву 2024-T3 (`σ_u = 470 МПа`, `σ_y = 325 МПа`, `σ_f' = 700 МПа`).

Вхідний цикл: амплітуда `σ_a = 100 МПа`, середнє напруження `σ_m = 150 МПа` (максимальне напруження `σ_max = 250 МПа`, коефіцієнт асиметрії `R = 50 / 250 = 0.20`).

Обчислення еквівалентних амплітуд:

```
Гудман:     σ_ar = 100 / (1 - 150 / 470) = 100 / (1 - 0.3191) = 146.87 МПа
Гербер:     σ_ar = 100 / (1 - (150 / 470)²) = 100 / (1 - 0.1019) = 111.34 МПа
Зедерберг:  σ_ar = 100 / (1 - 150 / 325) = 100 / (1 - 0.4615) = 185.71 МПа
Морроу:     σ_ar = 100 / (1 - 150 / 700) = 100 / (1 - 0.2143) = 127.27 МПа
SWT:        σ_ar = √(250 · 100) = √25000 = 158.11 МПа
```

Отримані значення демонструють суттєву різницю в консерватизмі:
- Найбільш консервативна оцінка — Зедерберг (185.7 МПа), яка накладає найсуворіші обмеження через межу плинності.
- Модель Гудмана (146.9 МПа) та критерій SWT (158.1 МПа) дають близькі, помірно консервативні результати, які ідеально підходять для алюмінієвих сплавів.
- Модель Гербера (111.3 МПа) дає найменшу еквівалентну амплітуду, що для крихких або чутливих до надрізів сплавів може бути небезпечним.

### Нелінійні моделі накопичення пошкоджень

Лінійне правило Пальмгрена — Майнера `D = ∑ (n_i / N_i)` припускає незалежність пошкодження від послідовності навантаження. Для точного моделювання ефектів черговості (блоків високих і низьких амплітуд) розроблено нелінійні підходи.

#### Степенева модель Марко — Старкі (Marco-Starkey)

Пошкодження на кожному рівні напруження зростає за степеневим законом від відношення відпрацьованих циклів:

```
D_i = (n_i / N_i)^(α(σ_i))
```

де показник степеня `α(σ_i)` монотонно спадає зі зростанням напруження `σ_i`. Для високих напружень `α` менше одиниці, що моделює швидке зародження мікродефектів.

#### Дволінійне правило Менсона — Хелфорда (Double Linear Damage Rule, DLDR)

У цій моделі повний ресурс `N_i` розділяється на дві окремі стадії:
1. **Фаза зародження мікротріщини `N_I`:**
   ```
   D_I = ∑ (n_i / N_{I, i})   [руйнування стадії при D_I = 1.0]
   ```
2. **Фаза макроскопічного розростання тріщини `N_II`:**
   ```
   D_II = ∑ (n_i / N_{II, i}) [остаточний злам при D_II = 1.0]
   ```

Співвідношення між фазами залежить від загального ресурсу: для високих напружень фаза зародження коротка (`N_I / N ≈ 0.1–0.2`), а для багатоциклової втоми вона займає до 90% усього життя деталі (`N_I / N ≈ 0.85–0.95`). Дволінійний закон точно пояснює, чому початкове високе перевантаження різко знижує залишковий ресурс на наступних малих циклах: воно миттєво долає фазу зародження `D_I`, переводячи деталь одразу на стадію швидкого росту тріщини.
