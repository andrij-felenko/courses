# 🧮 Повне математичне виведення рівняння імпульсу фон Кармана

Ця вставка містить строге математичне виведення інтегрального рівняння імпульсу фон Кармана з двовимірних диференціальних рівнянь Прандтля примежового шару методом контрольного об'єму та інтегрування уздовж нормальної координати.

Виведення спирається на вихідну систему диференціальних рівнянь Прандтля для двовимірної стаціонарної стисливої або нестисливої течії в'язкої рідини уздовж гладкої поверхні.

## 1. Оцінка порядків величин та диференціальні рівняння Прандтля

Перед проведенням інтегрування розглянемо вихідні стаціонарні двовимірні рівняння Нав'є — Стокса для нестисливої рідини постійної в'язкості:

```
u·(∂u/∂x) + v·(∂u/∂y) = - (1/ρ)·(∂P/∂x) + ν·(∂²u/∂x² + ∂²u/∂y²)
u·(∂v/∂x) + v·(∂v/∂y) = - (1/ρ)·(∂P/∂y) + ν·(∂²v/∂x² + ∂²v/∂y²)
∂u/∂x + ∂v/∂y = 0
```

Людвіґ Прандтль у 1904 році застосував метод аналізу порядків величин. Нехай `L` — характерний поздовжній розмір тіла (довжина пластини або хорда крила), а `U_inf` — швидкість набігаючого потоку. Тоді поздовжня координата має порядок `x ~ L`, а поздовжня швидкість `u ~ U_inf`.

Оскільки в'язке тертя зосереджене у дуже вузькому шарі товщиною `δ << L`, нормальна координата має порядок `y ~ δ`. З рівняння неперервності `∂u/∂x + ∂v/∂y = 0` випливає оцінка порядків для нормальної швидкості:

```
O(U_inf / L) + O(v / δ) = 0   ⇒   v ~ U_inf · (δ / L) << U_inf
```

Порівнюючи члени рівняння збереження імпульсу уздовж осі `y`, бачимо, що всі конвективні та в'язкі члени мають порядок малого параметра `O(δ / L)`. Це означає, що градієнт тиску уздовж нормалі `∂P/∂y = O(δ / L) ≈ 0`.

Отже, тиск усередині примежового шару є постійним по товщині й дорівнює тиску на зовнішній межі потенційного потоку: `P(x,y) = P_e(x)`.

Згідно з рівнянням Ейлера для зовнішньої нев'язкої течії, де швидкість дорівнює `U_e(x)`, поздовжній градієнт тиску пов'язаний з прискоренням зовнішнього потоку співвідношенням:

```
dP_e / dx = - ρ · U_e · (dU_e / dx)
```

Також у поздовжньому рівнянні імпульсу в'язка дифузія другої похідної уздовж осі `x` (`∂²u/∂x² ~ U_inf / L²`) є нехтовно малою порівняно з похідною за нормаллю `y` (`∂²u/∂y² ~ U_inf / δ²`).

Враховуючи ці оцінки порядків, рівняння Нав'є — Стокса спрощуються до двовимірних рівнянь Прандтля примежового шару:

```
∂u/∂x + ∂v/∂y = 0                                       [рівняння неперервності]
u·(∂u/∂x) + v·(∂u/∂y) = U_e·(dU_e/dx) + (1/ρ)·(∂τ/∂y)     [рівняння збереження імпульсу]
```

тут `τ(x,y) = μ·(∂u/∂y)` — в'язке напруження зсуву.

Граничні умови на стінці (`y = 0`) та на зовнішній межі (`y = h > δ`):
```
y = 0 :   u = 0,   v = 0,   τ = τ_w = μ·(∂u/∂y)|_w
y = h :   u = U_e(x),   v = v_h(x),   τ = 0,   ∂u/∂y = 0
```

## 2. Строге перетворення конвективних членів за допомогою інтегрування по частинах

Для проведення інтегрування рівняння імпульсу від `y = 0` до фіксованої координати `y = h` (де `h` вибрано так, щоб `h > δ(x)` для всіх розгляданих `x`), перетворимо нелінійний конвективний доданок `v·(∂u/∂y)`.

Застосуємо формулу інтегрування по частинах до інтеграла від добутку `v` на похідну `∂u/∂y`:

```
∫₀ʰ v · (∂u/∂y) dy = [ v(y) · u(y) ]₀ʰ - ∫₀ʰ u(y) · (∂v/∂y) dy
```

Підставимо граничні умови для підстановлюваного члена на нижній та верхній межах:
- На стінці (`y = 0`): `v(0) = 0`, тому `v(0) · u(0) = 0`.
- На верхній межі (`y = h`): `u(h) = U_e(x)`, тому `[ v(y) · u(y) ]₀ʰ = v(h) · U_e(x)`.

Для визначення нормальної швидкості на верхній межі `v(h)` проінтегруємо рівняння неперервності `∂v/∂y = -∂u/∂x` від `y = 0` до `y = h`:

```
∫₀ʰ (∂v/∂y) dy = v(h) - v(0) = v(h)
v(h) = - ∫₀ʰ (∂u/∂x) dy
```

Підставляючи цей вираз для `v(h)` у підстановку, отримуємо:

```
[ v(y) · u(y) ]₀ʰ = - U_e(x) · ∫₀ʰ (∂u/∂x) dy
```

Тепер підставимо `∂v/∂y = -∂u/∂x` у другий інтеграл формули інтегрування по частинах:

```
- ∫₀ʰ u(y) · (∂v/∂y) dy = + ∫₀ʰ u(y) · (∂u/∂x) dy
```

Остаточно збираємо обоє доданків для проінтегрованого члена `v·(∂u/∂y)`:

```
∫₀ʰ v · (∂u/∂y) dy = - U_e(x) · ∫₀ʰ (∂u/∂x) dy + ∫₀ʰ u · (∂u/∂x) dy
```

## 3. Інтегрування диференціального рівняння збереження імпульсу

Тепер проінтегруємо повне диференціальне рівняння імпульсу Прандтля від `y = 0` до `y = h`:

```
∫₀ʰ [ u·(∂u/∂x) + v·(∂u/∂y) - U_e·(dU_e/dx) ] dy = (1/ρ) · ∫₀ʰ (∂τ/∂y) dy
```

Обчислимо праву частину рівняння безпосереднім інтегруванням похідної напруження тертя:

```
(1/ρ) · ∫₀ʰ (∂τ/∂y) dy = (1/ρ) · [ τ(h) - τ(0) ]
```

Оскільки на верхній межі `y = h > δ` в'язке тертя відсутнє (`τ(h) = 0`), а на стінці `τ(0) = τ_w`, права частина дорівнює:

```
(1/ρ) · [ 0 - τ_w ] = - τ_w / ρ
```

Тепер підставимо розкритий вираз для `∫₀ʰ v·(∂u/∂y) dy` у ліву частину рівняння:

```
∫₀ʰ u·(∂u/∂x) dy - U_e·∫₀ʰ (∂u/∂x) dy + ∫₀ʰ u·(∂u/∂x) dy - ∫₀ʰ U_e·(dU_e/dx) dy = - τ_w / ρ
```

Об'єднаємо два однакові члени `u·(∂u/∂x)`:

```
∫₀ʰ [ 2·u·(∂u/∂x) - U_e·(∂u/∂x) - U_e·(dU_e/dx) ] dy = - τ_w / ρ
```

Тепер застосуємо математичну тотожність Лейбніца для винесення похідної `d/dx` за знак інтеграла. Оскільки верхня межа `h` є постійною величиною, похідну за `x` можна вільно переставляти з інтегралом за `y`:

```
d/dx [ ∫₀ʰ u · (U_e - u) dy ] + (dU_e/dx) · ∫₀ʰ (U_e - u) dy = τ_w / ρ
```

Доведемо тотожність цього перетворення прямим диференціюванням лівої частини за правилом Лейбніца розкриття похідної добутку:

```
d/dx [ ∫₀ʰ (u·U_e - u²) dy ]
= ∫₀ʰ [ (∂u/∂x)·U_e + u·(dU_e/dx) - 2·u·(∂u/∂x) ] dy   [похідна добутку]
```

Додаючи до цього виразу другий член `(dU_e/dx) · ∫₀ʰ (U_e - u) dy = ∫₀ʰ [ U_e·(dU_e/dx) - u·(dU_e/dx) ] dy`, бачимо, що члени `u·(dU_e/dx)` скорочуються, і залишається:

```
∫₀ʰ [ U_e·(∂u/∂x) - 2·u·(∂u/∂x) + U_e·(dU_e/dx) ] dy = τ_w / ρ
```

Зміна знака при множенні на `-1` точно повертає нас до проінтегрованого рівняння Прандтля. Тотожність доведено.

## 4. Введення інтегральних параметрів дефіциту маси та імпульсу

Отримане точне інтегральне співвідношення містить два фундаментальних вирази: `∫₀ʰ (U_e - u) dy` та `∫₀ʰ u·(U_e - u) dy`.

Оскільки поза межею примежового шару при `y > δ` швидкість `u(y) = U_e(x)`, підінтегральні вирази `(U_e - u)` тотожно дорівнюють нулю при всіх `y ≥ δ`. Це дозволяє замінити верхню межу інтегрування `h` на нескінченність `∞` без зміни значення інтегралів.

Введемо класичні визначення Прандтля:

1. **Товщина зміщення `δ*`**:
```
δ* = ∫₀^∞ (1 - u / U_e) dy   ⇒   ∫₀ʰ (U_e - u) dy = U_e · δ*
```

2. **Товщина втрати імпульсу `θ`**:
```
θ = ∫₀^∞ (u / U_e) · (1 - u / U_e) dy   ⇒   ∫₀ʰ u·(U_e - u) dy = U_e² · θ
```

Підставимо ці вирази в інтегральне рівняння:

```
d/dx [ U_e² · θ ] + (dU_e/dx) · U_e · δ* = τ_w / ρ
```

## 5. Алгебраїчне розгортання та канонічна форма Кармана

Застосуємо правило Лейбніца для диференціювання добутку `U_e²(x) · θ(x)` за змінною `x`:

```
d/dx [ U_e² · θ ] = U_e² · (dθ/dx) + θ · d(U_e²)/dx
```

Обчислимо похідну складеної функції `d(U_e²)/dx = 2 · U_e · (dU_e/dx)`:

```
d/dx [ U_e² · θ ] = U_e² · (dθ/dx) + 2 · U_e · θ · (dU_e/dx)
```

Підставимо розгорнуту похідну назад у рівняння балансу імпульсу:

```
U_e² · (dθ/dx) + 2 · U_e · θ · (dU_e/dx) + U_e · δ* · (dU_e/dx) = τ_w / ρ
```

Розділимо всі члени рівняння на величину `U_e²` (яка за визначенням є строго додатною поза точками гальмування):

```
dθ/dx + (2 · θ / U_e) · (dU_e/dx) + (δ* / U_e) · (dU_e/dx) = τ_w / (ρ · U_e²)
```

Винесемо спільний множник `(θ / U_e) · (dU_e/dx)` за дужки у другому та третьому членах лівої частини:

```
dθ/dx + (2 + δ* / θ) · (θ / U_e) · (dU_e/dx) = τ_w / (ρ · U_e²)
```

Введемо безрозмірний коефіцієнт форми `H` та місцевий коефіцієнт тертя `C_f`:

```
H = δ* / θ
C_f = τ_w / (½ · ρ · U_e²)   ⇒   τ_w / (ρ · U_e²) = C_f / 2
```

Остаточно отримуємо класичну канонічну форму **інтегрального рівняння імпульсу фон Кармана**:

```
dθ/dx + (2 + H) · (θ / U_e) · (dU_e/dx) = C_f / 2
```

## 6. Узагальнення для осесиметричних тіл обертання та рівняння енергії

Отримане рівняння Кармана можна узагальнити для трьох важливих розширених випадків гідромеханіки.

### 1. Осесиметричне обтікання тіла обертання
Для обтікання фюзеляжу, корпусу підводного човна або ракети з місцевим радіусом поперечного перерізу `r(x)` площа поверхні контрольного об'єму зростає пропорційно `2·π·r(x)`. Інтегрування у циліндричних координатах дає **осесиметричне рівняння імпульсу Кармана**:

```
dθ/dx + (2 + H) · (θ / U_e) · (dU_e/dx) + (θ / r) · (dr/dx) = C_f / 2
```

Додатковий член `(θ / r) · (dr/dx)` описує геометричне розширення або звуження примежового шару при зміні радіуса тіла.

### 2. Рівняння збереження механічної енергії (Рівняння Віґгардта)
Якщо замість балансу імпульсу проінтегрувати рівняння кінетичної енергії (помноживши рівняння імпульсу на `u`), отримуємо **інтегральне рівняння енергії Віґгардта** (Karl Wieghardt, 1945):

```
d(δ**) / dx + 3 · (δ** / U_e) · (dU_e/dx) = 2 · C_D
```

де `δ**` (або `δ_3`) — **товщина втрати кінетичної енергії**:

```
δ** = ∫₀^∞ (u / U_e) · (1 - (u / U_e)²) dy
```

а `C_D = ∫₀^∞ (τ / (ρ·U_e²)) · (∂(u/U_e)/∂y) dy` — безрозмірний коефіцієнт об'ємної дисипації в'язкої енергії.

Спільне використання рівняння імпульсу Кармана та рівняння енергії Віґгардта утворює основу дворядових інтегральних методів розрахунку (таких як метод Дрели в XFOIL), які дозволяють із високою точністю описувати відривні течії та ламінарно-турбулентний перехід.
