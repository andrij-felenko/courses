# ⚙️ Чисельна реалізація методу Твейтса для ламінарного примежового шару

У цій вставці наведено практичну чисельну реалізацію однопараметричного інтегрального методу Твейтса для розрахунку характеристик ламінарного примежового шару при довільному відомому розподілі зовнішньої швидкості `U_e(x)`.

## 1. Фізична та математична основа методу Твейтса

Метод Браяна Твейтса (Bryan Thwaites, 1949) являє собою один із найелегантніших і найефективніших інженерних методів аеродинаміки. Він розв'язує проблему замикання канонічного рівняння імпульсу Кармана для ламінарного шару шляхом зведення диференціального рівняння до прямої чисельної квадратури.

Пригадаємо канонічне інтегральне рівняння імпульсу фон Кармана:

```
dθ/dx + (2 + H) · (θ / U_e) · (dU_e/dx) = C_f / 2
```

Помножимо все рівняння на величину `(2 · U_e · θ / ν)`:

```
(U_e / ν) · d(θ²)/dx + 2 · (θ² / ν) · (dU_e/dx) · (2 + H) = 2 · (τ_w · θ / (μ · U_e))
```

Введемо параметр градієнта тиску Твейтса `λ_T = (θ² / ν) · (dU_e / dx)` та функцію безрозмірного тертя на стінці `l(λ_T) = (τ_w · θ) / (μ · U_e)`. Тоді рівняння перетворюється на:

```
(U_e / ν) · d(θ²)/dx = 2 · [ l(λ_T) - λ_T · (2 + H(λ_T)) ] ≡ F(λ_T)
```

Браян Твейтс проаналізував понад 20 відомих точних і чисельних розв'язків рівнянь Прандтля (зокрема течію Блазіуса, течії Фолкнера — Скена на клинах, та сповільнювану течію Хауарта `U_e(x) = U_0 - a·x`). Звівши значення комбінованої функції `F(λ_T)` на один графік, Твейтс виявив вражаючий факт: для всіх ламінарних профілів у діапазоні від лобової точки гальмування до точки відриву залежність `F(λ_T)` із високою точністю описується єдиною лінійною функцією:

```
F(λ_T) ≈ 0.45 - 6.0 · λ_T
```

Підставимо цю лінійну апроксимацію у диференціальне рівняння:

```
(U_e / ν) · d(θ²)/dx = 0.45 - 6.0 · (θ² / ν) · (dU_e / dx)
```

Перенесемо член з `λ_T` у ліву частину та помножимо все рівняння на `U_e⁵`:

```
U_e⁵ · d(θ²)/dx + 6.0 · U_e⁴ · (dU_e / dx) · θ² = 0.45 · ν · U_e⁵
```

Зауважимо, що ліва частина є точним виразом для похідної добутку `d/dx [ U_e⁶ · θ² ]`:

```
d/dx [ U_e⁶(x) · θ²(x) ] = 0.45 · ν · U_e⁵(x)
```

Проінтегрувавши це диференціальне рівняння від початкової точки `x = 0` до довільної координати `x`, отримуємо фундаментальну **квадратурну формулу Твейтса**:

```
θ²(x) = (0.45 · ν / U_e⁶(x)) · ∫₀ˣ U_e⁵(ξ) dξ
```

Ця формула дозволяє знайти товщину втрати імпульсу `θ(x)` у будь-якій точці ламінарного шару за допомогою одного прямого чисельного інтеграла від п'ятого степеня зовнішньої швидкості `U_e(x)`.

## 2. Аналітичні кореляції Твейтса та перевірка на відрив

Після обчислення товщини втрати імпульсу `θ(x)` розраховується місцеве значення параметра градієнта тиску `λ_T(x)`:

```
λ_T(x) = (θ²(x) / ν) · (dU_e / dx)
```

За значеним `λ_T(x)` визначаються інші важливі параметри примежового шару:
1. **Коефіцієнт форми `H(λ_T)`** (відношення товщини зміщення `δ*` до товщини втрати імпульсу `θ`).
2. **Функція безрозмірного тертя `l(λ_T)`**, з якої обчислюється місцевий коефіцієнт тертя `C_f`:

```
C_f(x) = 2 · (ν / (U_e · θ)) · l(λ_T)
```

Твейтс запропонував наступні універсальні кусочно-поліноміальні апроксимації:

- **Зона сповільненої течії (`dP/dx > 0`, `-0.09 < λ_T ≤ 0`)**:
  `l(λ_T) = 0.225 + 2.3 · λ_T - 6.0 · λ_T²`
  `H(λ_T) = 2.61 - 3.75 · λ_T + 80.0 · λ_T²`

- **Зона прискореної течії (`dP/dx < 0`, `0 < λ_T ≤ 0.10`)**:
  `l(λ_T) = 0.225 + 2.3 · λ_T - 2.0 · λ_T²`
  `H(λ_T) = 2.61 - 3.75 · λ_T + 15.0 · λ_T²`

- **Точка ламінарного відриву (`λ_T ≤ -0.09`)**:
  При `λ_T = -0.09` функція тертя дорівнює нулю `l(-0.09) = 0`, що означає нулеве напруження тертя на стінці `τ_w = 0` та `C_f = 0`. Коефіцієнт формы при цьому зростає до `H ≈ 3.55`. Якщо параметр `λ_T` досягає або перевищує значення `-0.09`, фіксується ламінарний відрив потоку, і подальший ламінарний розрахунок зупиняється.

## 3. Особливості чисельної обробки крайових випадків

При чисельній реалізації методу Твейтса на дискретній сітці координат `x[0], x[1], ..., x[n-1]` виникають два важливі крайові випадки у початковій точці `x = 0`:

### 1. Лобова точка гальмування (`Stagnation Point`)
Для затупленого тіла (наприклад, передньої кромки профілю або циліндра) у лобовій точці `x = 0` швидкість потоку дорівнює нулю (`U_e(0) = 0`), але градієнт швидкості є додатним і скінченним (`dU_e/dx = C > 0`).

Безпосередня підстановка `U_e = 0` у формулу Твейтса створює невизначеність типу `0 / 0`. Раскриваючи цю невизначеність за правилом Лопіталя, отримуємо граничне значення параметра Твейтса у точці гальмування:

```
λ_T(0) = 0.075
```

Звідси початкова товщина втрати імпульсу у точці гальмування дорівнює:

```
θ(0) = √(0.075 · ν / (dU_e/dx)|_x=0)
```

Початковий коефіцієнт форми при цьому дорівнює `H(0) ≈ 2.22`, а `l(0) ≈ 0.357`.

### 2. Плоска пластина (`Zero Pressure Gradient`)
Якщо течія починається на гострій передній кромці плоскої пластини при `U_e(x) = U_inf = const`, то `dU_e/dx = 0`. Квадратурний інтеграл `∫₀ˣ U_e⁵ dξ = U_inf⁵ · x`.

Підставляючи це у формулу Твейтса, отримуємо:

```
θ²(x) = (0.45 · ν / U_inf⁶) · (U_inf⁵ · x) = 0.45 · ν · x / U_inf
θ(x) = √0.45 · √(ν·x / U_inf) ≈ 0.6708 · √(ν·x / U_inf)
```

Порівняємо це із точним розв'язком Блазіуса `θ_Blasius = 0.6641 · √(ν·x / U_inf)`. Відносна похибка методу Твейтса для плоскої пластини становить лише **1.0 %**, що є видатним результатом для спрощеної квадратурної моделі.

## 5. Детальний аналіз алгоритму та оцінка обчислювальної складності

Розглянемо детальний крок за кроком виконання представленого алгоритму розв'язання.

### Крок 1: Перевірка коректності вхідних даних
Алгоритм приймає масив вихідних точок сітки `points` довжиною `N` та кінетичну в'язкість середовища `nu`. Перевіряються умови `N ≥ 2` та `nu > 0`. Включається захист від нульових ділень при діленні на `U_e⁶`. Якщо швидкість наближається до нуля поза точкою гальмування, ділення обмежується малим порогом `1e-12`.

### Крок 2: Накопичення квадратури методом трапецій
Обчислення інтеграла `∫₀ˣ U_e⁵(ξ) dξ` виконується в один прохід по сітці (алгоритм з часовою складністю `O(N)`). Для кожного інтервалу `[x[i-1], x[i]]` обчислюється трапецієподібний внесок `0.5 · (U_e⁵[i-1] + U_e⁵[i]) · dx`, який додається до накопичувальної змінної `integral_val`. Застосування схеми Сімпсона замість трапецій підвищує порядок апроксимації з `O(dx²)` до `O(dx⁴)`, проте на реальних неравномерних аеродинамічних сітках трапецієподібна квадратура забезпечує максимальну обчислювальну стійкість.

### Крок 3: Перевірка прапорця відриву та оновлення параметрів
Для кожної точеної координати обчислюється локальне значення `λ_T = (θ² / ν) · (dU_e / dx)`. Якщо `λ_T ≤ -0.09`, прапорець `is_separated` встановлюється в `true` (`1`), а коефіцієнт тертя `C_f` скидається в нуль. Це запобігає виникненню від'ємних значень поверхневого тертя та чисельної нестійкості.

### Обчислювальна складність та обчислювальні показники
- **Часова складність**: `O(N)` — алгоритм виконує строго один послідовний прохід уздовж сітки точок `x`.
- **Просторова складність**: `O(N)` — потрібна пам'ять тільки для збереження результуючого вектора точок.
- **Чисельна стійкість**: Усі обчислення виконуються в числах подвійної точності (`double`, 64 біти IEEE 754). Використання степеня `U_e⁵` та `U_e⁶` вимагає подвійної точності для запобігання втратам значущих розрядів (Underflow/Overflow) при малих значеннях швидкості `U_e < 1e-3` м/с.
- **Ефективність кЕшування**: Масиви точок обробляються послідовно із послідовним доступом до пам'яті (кєш-дружній векторний доступ), що забезпечує виконання розрахунку сітки з 1000 точок за мікросекунди на сучасних CPU.
