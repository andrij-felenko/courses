# ⚙️ Дискретне обчислення потенціальної вихореності Ертеля на тривимірній сітці

Обчислення потенціальної вихореності Ертеля `q = (ω_a · ∇θ) / ρ` на тривимірних дискретних сітках є базовою процедурою у сучасних чисельних моделях прогнозу погоди (WRF, IFS, ICON) та океанографічних діагностичних пакетах (MetPy, OceanParcels, Parcels3D).

Для регулярної тривимірної сітки розміром `NX × NY × NZ` з просторовими кроками `dx`, `dy`, `dz` обчислення вимагає оцінки трьох складових ротора швидкості `ω = ∇ × u`, трьох складових градієнта потенціальної температури `∇θ` та їхнього скалярного добутку із врахуванням місцевого параметра Коріоліса `f = 2·Ω·sin(φ)`.

Нижче наведено детальний аналіз математичної дискретизації, алгоритмів обробки границь, оптимізації роботи з пам'яттю та повні реалізації ядра двома мовами — C та C++.

## Особливості сіткового шаблону та різницевої схеми

У метеорологічних та океанографічних моделях розрізняють два основних класи просторової дискретизації змінних:

1. **Суміщена сітка (Arakawa A-grid)**. Усі фізичні величини — компоненти вітру `u, v, w`, потенціальна температура `θ`, тиск `p` та густина `ρ` — зберігаються у спільних географічних вузлах сітки `(i, j, k)`. Це спрощує структуру даних, але вимагає використання 2-крокових центральних різниць.
2. **Зсунута сітка (Arakawa C-grid)**. Компоненти швидкості `u, v, w` визначаються на гранях тривимірних комірок, тоді як термодинамічні змінні `θ, ρ` зберігаються в центрах комірок. Така сітка краще описує гравітаційні хвилі та геострофічну адаптацію, але обчислення ротора та градієнтів вимагає попередньої інтерполяції змінних у центри комірок.

У наведених нижче алгоритмах розглядається різницева схема для сітки типу Arakawa A з використанням 2-точкового центрально-різницевого шаблону 2-го порядку точності.

Для будь-якої тривимірної скалярної функції `f(x, y, z)` центральні різниці за відповідними просторовими напрямками у внутрішньому вузлі `(i, j, k)` обчислюються за формулами:

```
∂f/∂x ≈ (f(i+1, j, k) - f(i-1, j, k)) / (2·dx)
∂f/∂y ≈ (f(i, j+1, k) - f(i, j-1, k)) / (2·dy)
∂f/∂z ≈ (f(i, j, k+1) - f(i, j, k-1)) / (2·dz)
```

Апроксимація 2-го порядку точності має помилку дискретизації `O(dx² + dy² + dz²)`. Вона є розрахунково економічною та забезпечує збереження симетрії при обчисленні ротора.

## Дискретизація складових вихореності та стратифікації

Для внутрішніх вузлів сітки `(i, j, k)` компоненти вектора відносної вихореності `ω = ∇ × u` обчислюються через різниці компонентів швидкості:

```
ω_x = (w(i, j+1, k) - w(i, j-1, k)) / (2·dy) - (v(i, j, k+1) - v(i, j, k-1)) / (2·dz)
ω_y = (u(i, j, k+1) - u(i, j, k-1)) / (2·dz) - (w(i+1, j, k) - w(i-1, j, k)) / (2·dx)
ω_z = (v(i+1, j, k) - v(i-1, j, k)) / (2·dx) - (u(i, j+1, k) - u(i, j-1, k)) / (2·dy)
```

Звернемо увагу на горизонтальні та вертикальні масштаби. В атмосфері горизонтальний крок сітки `dx ≈ dy` зазвичай становить від 1 до 10 км, тоді як вертикальний крок `dz` становить від 10 до 100 м. Через цю анізотропію вертикальні похідні `∂u/∂z` та `∂v/∂z` є за модулем на 2–3 порядки більшими за горизонтальні похідні.

Компоненти градієнта потенціальної температури `∇θ`:

```
dθ_dx = (θ(i+1, j, k) - θ(i-1, j, k)) / (2·dx)
dθ_dy = (θ(i, j+1, k) - θ(i, j-1, k)) / (2·dy)
dθ_dz = (θ(i, j, k+1) - θ(i, j, k-1)) / (2·dz)
```

Абсолютна вихореність підсумовується з планетарною вихореністю:

```
ω_ax = ω_x
ω_ay = ω_y
ω_az = ω_z + f(j)
```

де `f(j) = 2·Ω·sin(φ_j)` — параметр Коріоліса для широти `j`-го вузла.

Потенціальна вихореність в одиницях PVU (`1 PVU = 10⁻⁶ м²·с⁻¹·К·кг⁻¹`):

```
q = [(ω_ax · dθ_dx + ω_ay · dθ_dy + ω_az · dθ_dz) / ρ] × 10⁶
```

## Перехід до ізобаричних та ізоентропійних координат

У практичних атмосферних моделях вертикальною координатою часто виступає не геометрична висота `z`, а тиск `p` (ізобарична система) або потенціальна температура `θ` (ізоентропійна система).

У ізобаричній системі координат `(x, y, p)` потенціальна вихореність Ертеля обчислюється у наближенні гідростатики `∂p/∂z = -ρ·g`:

```
q_p = -g · [ (∂v/∂x - ∂u/∂y + f)·(∂θ/∂p) + (∂u/∂p)·(∂θ/∂y) - (∂v/∂p)·(∂θ/∂x) ]
```

де `g = 9.81 м/с²` — прискорення вільного падіння.

Звернемо увагу на знак мінус перед виразом: оскільки тиск `p` зменшується з висотою (`∂p/∂z < 0`), похідна `∂θ/∂p` є від'ємною у статично стійкій атмосфері. Множник `-g` компенсує цей знак, забезпечуючи додатні значення `q_p` у Північній півкулі.

## Оптимізація роботи з пам'яттю та векторизація

Оскільки розрахунок виконується над великими 3D масивами, критично важливо забезпечити оптимальний порядок обходу вузлів у циклах.

У мові C масиви зберігаються в порядку Row-Major: останній індекс змінюється найшвидше. Тому внутрішній цикл мусить виконуватися за вертикальним індексом `k` або найправішим індексом масиву. Послідовне читання сусідніх елементів пам'яті дозволяє апаратному предвибірочникові кешу завантажувати кеш-лінійки процессора (64 байти) без простоїв та забезпечує векторизацію за допомогою SIMD-інструкцій (AVX-512 або ARM Neon).

Додатково слід забезпечити вирівнювання адрес масивів у пам'яті на межу 64 байтів (`alignas(64)` у C++ або `posix_memalign` у C). Це виключає накладні витрати на розщеплені читання між кеш-лініями (split-cache reads).

## Обробка крайових умов та рельєфу

При обчисленні на реальних сітках атмосферних моделей граничні вузли потребують окремої уваги:

1. **Періодичні граничні умови вздовж довготи (ось X)**. Для глобальних атмосферних моделей вузол `i = 0` є тотожним вузлу `i = NX-1`. Для них сусідні елементи визначаються як `im = (i == 0) ? NX - 2 : i - 1` та `ip = (i == NX - 1) ? 1 : i + 1`.
2. **Неумовні межі на полюсах та бокових стінках (ось Y)**. На північній та південній межі сітки використовують односторонні різниці 2-го порядку точності (3-точковий шаблон) або екстраполяцію з нульовим градієнтом.
3. **Верхня та нижня межа (ось Z)**. На поверхні Землі (`k = 0`) вертикальний градієнт `∂θ/∂z` розраховується через односторонню різницю вперед: `∂θ/∂z ≈ (-3·θ₀ + 4·θ₁ - θ₂) / (2·dz)`.
4. **Пересічення рельєфу (маскування подтілля)**. У вузлах, що знаходяться під поверхнею Землі (під гірським рельєфом), значення прапорця маски `mask(i,j,k) == 0`. Для цих вузлів обчислення пропускається, а значення `q` примусово встановлюється в `0.0`.

## Тестування та верифікація чисельного ядра

Для перевірки правильності обчислювального ядра використовують два стандартних тестових сценарії:

1. **Аналітична атмосфера у стані спокою**. Швидкість `u = v = w = 0`, потенціальна температура залежить лише від висоти `θ(z) = θ₀ + γ·z`, густина `ρ(z) = ρ₀·exp(-z/H_scale)`. У цьому випадку відносна вихореність дорівнює нулю, а потенціальна вихореність Ертеля стає строго одновимірною: `q(z) = (f₀ · γ) / ρ(z)`. Збіжність чисельного виходу з аналітичним профілем підтверджує відсутність дискретних зсувів шаблону.
2. **Аналітичний вихор Ранкіна або Ґаусса**. Задається циліндрично-симетричне поле кругового вітру `v_θ(r)` з відомим аналітичним ротором. Перевіряється збереження сумарної інтегральної потенціальної вихореності по всій сітці.
