# 🧮 Математичне виведення теореми Ертеля про потенціальну вихореність

Теорема Ханса Ертеля встановлює точний закон збереження скалярної величини `q = (ω_a · ∇λ) / ρ` вздовж матеріальних траєкторій рідких частинок у нев'язкому, адіабатичному та обертовому плині. Потенціальна вихореність Ертеля є одним із найпотужніших аналітичних інструментів геофізичної гідродинаміки, оскільки вона об'єднує векторну вихореність, скалярну стратифікацію та стисливість середовища.

Нижче наведено суворе математичне виведення цього інваріанта на основі векторного аналізу та фундаментальних рівнянь механіки суцільних середовищ.

Матеріальне виведення будується за чотирма послідовними кроками:
1. Отримання рівняння еволюції вектора абсолютної вихореності з рівняння руху Ейлера в обертовій системі відліку.
2. Отримання рівняння еволюції просторового градієнта консервативної скалярної характеристики плину.
3. Скалярне множення обидвох рівнянь, спрощення членів нахилу та застосування рівняння неперервності збереження маси.
4. Доведення тотожного перетворення в нуль бароклінного соленоїдального члена для термодинамічно консервативного скаляра.

## Крок 1. Еволюція вектора абсолютної вихореності

Розглянемо рівняння руху Ейлера для нев'язкої стисливої рідини або газу в системі відліку, що обертається зі сталою кутовою швидкістю `Ω`:

```
Du/Dt + 2·Ω × u = -(1/ρ)·∇p + ∇Φ
```

де `u = (u, v, w)` — вектор відносної швидкості плину, `p` — скалярний тиск, `ρ` — густина середовища, а `Φ` — потенціал зовнішніх масових сил (наприклад, сумарного гравітаційного та відцентрового потенціалу).

Матеріальну (індивідуальну) похідну вектора швидкості `Du/Dt = ∂u/∂t + (u · ∇)u` перепишемо за допомогою тотожності векторного аналізу для конвективного члена:

```
(u · ∇)u = ∇(½·|u|²) + (∇ × u) × u      [векторна тотожність для конвективного члена]
```

Підставимо цю тотожність у рівняння руху:

```
∂u/∂t + ∇(½·|u|²) + (∇ × u) × u + 2·Ω × u = -(1/ρ)·∇p + ∇Φ
```

Враховуючи визначення відносної вихореності `ω = ∇ × u`, об'єднаємо відносну вихореність та планетарне обертання `2·Ω` у єдиний вектор абсолютної вихореності `ω_a = ω + 2·Ω`. Звернемо увагу, що векторний добуток `(∇ × u) × u + 2·Ω × u` можна перегрупувати як `(∇ × u + 2·Ω) × u = ω_a × u`.

Тоді рівняння руху набуває вигляду:

```
∂u/∂t + ω_a × u + ∇(½·|u|² - Φ) = -(1/ρ)·∇p     [визначення абсолютної вихореності ω_a]
```

Застосуємо оператор ротора `∇ ×` до обох частин рівняння. Ураховуючи, що ротор градієнта будь-якого скалярного поля тотожно дорівнює нулю (`∇ × ∇f = 0`), градієнт кінетичної енергії та потенціалу `∇(½·|u|² - Φ)` зникає:

```
∂ω_a/∂t + ∇ × (ω_a × u) = ∇ × (-(1/ρ)·∇p)      [застосовано ротор до обох частин]
```

Розкриємо ротор векторного добутку `∇ × (ω_a × u)` за допомогою стандартного формульного розкладу:

```
∇ × (ω_a × u) = (u · ∇)ω_a - (ω_a · ∇)u + ω_a·(∇ · u) - u·(∇ · ω_a)      [розкриття ротора векторного добутку]
```

Оскільки ротор будь-якого векторного поля є соленоїдальним (безвихровим за дивергенцією), маємо `∇ · (∇ × u) = 0`. Оскільки кутова швидкість обертання Землі `Ω` є просторово однорідним вектором, `∇ · (2·Ω) = 0`. Отже, дивергенція абсолютної вихореності тотожно дорівнює нулю: `∇ · ω_a = 0`. Останній доданок у розкладі зникає.

Тоді розкритий ротор спрощується до:

```
∇ × (ω_a × u) = (u · ∇)ω_a - (ω_a · ∇)u + ω_a·(∇ · u)      [оскільки ∇ · ω_a = 0]
```

Розглянемо праву частину рівняння, яка містить градієнти тиску та густини. За застосуванням тотожності ротора добутку скаляра на вектор:

```
∇ × (-(1/ρ)·∇p) = -∇(1/ρ) × ∇p - (1/ρ)·(∇ × ∇p)
= (1/ρ²)·∇ρ × ∇p                                           [оскільки ∇ × ∇p = 0 та ∇(1/ρ) = -(1/ρ²)·∇ρ]
```

Вектор `(1/ρ²)·∇ρ × ∇p` називається бароклінним соленоїдальним вектором Б'єркнеса. Він характеризує швидкість генерації вихореності у місцях, де поверхні однакової густини перетинаються з поверхнями однакового тиску.

Об'єднуючи ліву та праву частини і збираючи повну індивідуальну похідну `Dω_a/Dt = ∂ω_a/∂t + (u · ∇)ω_a`, отримуємо рівняння еволюції абсолютної вихореності:

```
Dω_a/Dt = (ω_a · ∇)u - ω_a·(∇ · u) + (1/ρ²)·(∇ρ × ∇p)      [рівняння еволюції абсолютної вихореності]
```

Це рівняння виражає зміну вектора абсолютної вихореності під дією трьох фізичних ефектів:
- `(ω_a · ∇)u` — розтягнення та нахил (деформація) вихорових трубок під дією зсуву швидкостей;
- `-ω_a·(∇ · u)` — стискання чи розширення об'єму рідкої частинки;
- `(1/ρ²)·(∇ρ × ∇p)` — виникнення нової вихореності у бароклінних соленоїдах.

## Крок 2. Еволюція градієнта скалярної величини

Нехай `λ` — скалярний термодинамічний параметр рідини (наприклад, потенціальна температура `θ`), який є матеріально консервативним у даному плині:

```
Dλ/Dt = ∂λ/∂t + u · ∇λ = 0      [умова консервативності скаляра λ]
```

Застосуємо оператор градієнта `∇` до цього скалярного рівняння:

```
∇(∂λ/∂t + u · ∇λ) = 0
∂(∇λ)/∂t + ∇(u · ∇λ) = 0
```

Розкриємо градієнт скалярного добутку `∇(u · ∇λ)` за стандартною тотожністю векторного аналізу:

```
∇(u · ∇λ) = (u · ∇)∇λ + (∇λ · ∇)u + u × (∇ × ∇λ) + ∇λ × (∇ × u)
```

Ураховуючи, що ротор градієнта скаляра тотожно дорівнює нулю (`∇ × ∇λ = 0`), останні доданки зникають. Отже, отримуємо:

```
∂(∇λ)/∂t + (u · ∇)∇λ = -(∇λ · ∇)u
D(∇λ)/Dt = -(∇λ · ∇)u           [рівняння еволюції градієнта скаляра λ]
```

Це рівняння показує, як просторовий градієнт скалярного поля деформується та повертається внаслідок зсуву поля швидкостей плину `u`.

## Крок 3. Скалярне множення та застосування рівняння неперервності

Обчислимо індивідуальну похідну від скалярного добутку `(ω_a · ∇λ)` за правилом диференціювання добутку двох векторних функцій:

```
D(ω_a · ∇λ)/Dt = (Dω_a/Dt) · ∇λ + ω_a · (D(∇λ)/Dt)      [диференціювання скалярного добутку]
```

Підставимо у це співвідношення вирази для `Dω_a/Dt` та `D(∇λ)/Dt`, отримані на кроках 1 та 2:

```
D(ω_a · ∇λ)/Dt = [(ω_a · ∇)u - ω_a·(∇ · u) + (1/ρ²)·(∇ρ × ∇p)] · ∇λ + ω_a · [-(∇λ · ∇)u]
= (ω_a · ∇)u · ∇λ - ω_a·(∇ · u)·∇λ + (1/ρ²)·(∇ρ × ∇p) · ∇λ - ω_a · (∇λ · ∇)u
```

Проаналізуємо перший та останній доданки правої частини:
`((ω_a · ∇)u) · ∇λ` та `ω_a · ((∇λ · ∇)u)`.

Запишемо їх у тензорній формі за індексами Ейнштейна:
- Перший член: `(ω_a)_i (∂_i u_j) (∂_j λ)`
- Другий член: `(ω_a)_i (∂_j λ ∂_j u_i) = (ω_a)_j (∂_i λ ∂_i u_j)`

Унаслідок симетрії скалярного множення двох векторів через тензор градієнта швидкості `∂_i u_j`, ці два члени є тотожно рівними за модулем і протилежними за знаком. Вони повністю скасовують один одного:

```
((ω_a · ∇)u) · ∇λ - ω_a · ((∇λ · ∇)u) = 0     [тотожне скасування членів нахилу/деформації]
```

Фізичний зміст цього скасування є надзвичайно глибоким: зміна вихореності внаслідок нахилу вихорових трубок точно компенсується зміною нахилу самих поверхонь `λ = const`! Завдяки цьому нахил поверхонь не створює неконсервативних джерел потенціальної вихореності.

Після скасування рівняння спрощується до вигляду:

```
D(ω_a · ∇λ)/Dt = - (ω_a · ∇λ)·(∇ · u) + (1/ρ²)·(∇ρ × ∇p) · ∇λ
```

Тепер пригадаємо рівняння неперервності збереження маси рідини:

```
Dρ/Dt + ρ·(∇ · u) = 0
∇ · u = -(1/ρ)·Dρ/Dt
```

Підставимо вираз для дивергенції швидкості `∇ · u` у попереднє рівняння:

```
D(ω_a · ∇λ)/Dt = (ω_a · ∇λ) · (1/ρ) · Dρ/Dt + (1/ρ²)·(∇ρ × ∇p) · ∇λ
```

Перенесемо перший доданок правої частини вліво:

```
D(ω_a · ∇λ)/Dt - (ω_a · ∇λ) · (1/ρ) · Dρ/Dt = (1/ρ²)·(∇ρ × ∇p) · ∇λ
```

Поділимо обидві частини рівняння на густину `ρ`:

```
(1/ρ)·D(ω_a · ∇λ)/Dt - (ω_a · ∇λ) · (1/ρ²) · Dρ/Dt = (1/ρ³)·(∇ρ × ∇p) · ∇λ
```

Зауважимо, що ліва частина даного рівняння являє собою точну індивідуальну похідну від частки двох величин `(ω_a · ∇λ)` та `ρ`:

```
D [ (ω_a · ∇λ) / ρ ] / Dt = (1/ρ³) · (∇ρ × ∇p) · ∇λ     [проміжний результат для матеріальної похідної]
```

## Крок 4. Доведення тотожного перетворення в нуль бароклінного члена

Розглянемо мішаний скалярно-векторний добуток трьох векторних полів у правій частині:

```
S = (∇ρ × ∇p) · ∇λ
```

Якщо скалярний матеріальний інваріант `λ` є термодинамічною функцією стану, що залежить виключно від тиску `p` та густини `ρ`, тобто `λ = λ(p, ρ)` (наприклад, потенціальна температура ідеального газу `θ(p, ρ)`):

Тоді просторовий градієнт `∇λ` розкладається за правилом ланцюгового диференціювання складного скалярного поля:

```
∇λ = (∂λ/∂p)·∇p + (∂λ/∂ρ)·∇ρ      [розклад градієнта термодинамічної функції λ(p,ρ)]
```

Підставимо цей розклад у мішаний добуток `S`:

```
S = (∇ρ × ∇p) · [ (∂λ/∂p)·∇p + (∂λ/∂ρ)·∇ρ ]
= (∂λ/∂p) · [ (∇ρ × ∇p) · ∇p ] + (∂λ/∂ρ) · [ (∇ρ × ∇p) · ∇ρ ]
```

Згадаємо фундаментальну алгебраїчну властивість мішаного добутку трьох векторів: якщо один із векторів у скалярно-векторному добутку збігається з одним із векторів у векторному добутку (або колінеарний йому), то мішаний добуток тотожно дорівнює нулю, оскільки результат векторного добутку ортогональний до кожного зі своїх співмножників:

```
(∇ρ × ∇p) · ∇p = 0      [оскільки вектор (∇ρ × ∇p) перпендикулярний до ∇p]
(∇ρ × ∇p) · ∇ρ = 0      [оскільки вектор (∇ρ × ∇p) перпендикулярний до ∇ρ]
```

Отже, обидва доданки перетворюються на нуль:

```
S = (∇ρ × ∇p) · ∇λ = 0  [тотожне перетворення в нуль бароклінного члена]
```

Це ключовий результат виведення Ертеля: хоча бароклінні соленоїди `∇ρ × ∇p` неперервно генерують відносну вихореність у просторі, їхній внесок у напрямку градієнта `∇λ` тотожно дорівнює нулю!

## Остаточний закон збереження Ертеля

Підставляючи `S = 0` у проміжне рівняння кроку 3, отримуємо остаточне математичне співвідношення теореми Ертеля:

```
D [ (ω_a · ∇λ) / ρ ] / Dt = 0      [теорема Ертеля про потенціальну вихореність]
```

Визначаючи потенціальну вихореність Ертеля як скалярне поле `q`:

```
q = (ω_a · ∇λ) / ρ
```

отримуємо точний закон збереження:

```
Dq/Dt = 0               [консервативність q вздовж матеріальних траєкторій]
```

Математичне виведення доведено повністю.
