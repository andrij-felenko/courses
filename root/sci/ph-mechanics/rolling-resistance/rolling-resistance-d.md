# Тертя кочення

<preknowlist>
- [Тертя](root:ph-mechanics/friction) — сила, що виникає між дотичними поверхнями при їх відносному ковзанні чи намаганні зсунутися. Кочення є кардинально дешевшим способом переміщення мас, оскільки усуває макроковзання.
- [Нормальна сила](root:ph-mechanics/normal-force) — сила перпендикулярної пружної реакції опори, що утримує тіло від занурення. Величина нормальної реакції безпосередньо масштабує опір коченню.
- [Момент сили](root:ph-mechanics/torque) — міра обертальної дії сили відносно точки або осі. Опір коченню народжується саме як момент внутрішніх реакцій, зміщених відносно осі обертання.
- [Пружна деформація](root:ph-condensed/elastic-deformation) — оборотна зміна форми твердого тіла під дією напружень, що описується законом Гука.
- [В'язкопружність](root:ph-mechanics/viscoelasticity) — властивість матеріалів (полімерів, гуми) поєднувати пружну пружність і в'язку дисипацію, через що реакція на деформацію відстає за часом і розсіює механічну енергію в тепло.
- [Потужність](root:ph-mechanics/power) та [Механічна робота](root:ph-mechanics/work) — енергетичний еквівалент витрат на пересування. Кожен ньютон опору дорівнює одному джоулю витраченої енергії на метр шляху.
- [Збереження енергії](root:ph-mechanics/energy-conservation) — фундаментальний закон, за яким уся механічна робота подолання опору коченню не зникає, а перетворюється на теплову енергію в товщі матеріалу колеса й дороги.
</preknowlist>

Важкий залізничний вагон масою 60 тонн на ідеально горизонтальній колії можуть зрушити з місця й котити двоє людей, прикладаючи сумарне зусилля лише близько 300–400 ньютонів. Якщо ж зняти цей самий вагон із коліс і спробувати волочити його сталевими полозами по рейках, знадобиться потужний промисловий тягач, здатний розвинути понад 150 кілоньютонів тяги. Різниця в зусиллі сягає трьох порядків. Проте навіть на найдосконаліших рейках вільний вагон не котитиметься нескінченно довго: вибіг поступово згасає, а для підтримки постійної швидкості локомотив має безперервно споживати потужність.

З погляду ідеальної кінематики твердого тіла, чисте кочення без проковзування взагалі не повинно створювати жодного опору. У кожен момент часу геометрична точка контакту колеса з опорною площиною є миттєвим центром швидкостей, тобто має нульову швидкість відносно поверхні (`v = 0`). Оскільки відносного зміщення в точці дотику немає, [тертя](root:ph-mechanics/friction) спокою чи ковзання не виконує механічної роботи й не здатне розсіювати кінетичну енергію. Якби колесо та дорога були абсолютно твердими тілами нескінченної жорсткості, лінія нормальної реакції опори проходила б суворо через вісь обертання, створюючи нульовий гальмівний момент.

Опір коченню виникає виключно через те, що в реальному світі абсолютно твердих тіл не існує: під дією сили ваги колесо та опорна поверхня взаємно деформуються. Точковий контакт розпливається в контактну пляму скінченної площі. Під час обертання колеса матеріал у передній частині плями безперервно стискається й заглиблюється, а в задній — розвантажується й розправляється. Через реологічну природу матеріалів (внутрішнє в'язке тертя в полімерах або мікропластичність у металах) процес відновлення форми відстає від процесу стиснення. Ця фундаментальна асиметрія динамічного навантаження зміщує рівнодійну реакції опори вперед у напрямку руху, утворюючи постійний гальмівний момент, який безперервно перетворює механічну роботу тяги на теплову енергію.

## Механіка контактної плями та утворення плеча k

Розглянемо циліндричне колесо радіуса `R` і ширини `b_w`, притиснуте до опорної поверхні вертикальним навантаженням `N = m · g` (де `m` — маса, що припадає на колесо, `g = 9.81` м/с² — прискорення вільного падіння). Колесо рухається з постійною лінійною швидкістю `v` без проковзування, здійснюючи обертання з кутовою швидкістю `ω = v / R`.

Під дією нормальної сили `N` колесо й опора стискаються на глибину `δ`. Контактна зона перестає бути прямою лінією і перетворюється на плоску або злегка вигнуту смугу довжиною `2a` (від `-a` на задньому краї до `+a` на передньому краї за напрямком руху). 

Кожна елементарна площадка контактної зони зазнає дії розподіленого нормального тиску `p(x)` (у паскалях або Н/м уздовж перерізу) та дотичного зусилля зсуву `q(x)`:

```
N = ∫ p(x) dx           [інтеграл нормального тиску від −a до +a]
F = ∫ q(x) dx           [інтеграл дотичних сил у контакті]
```

Якщо припустити, що матеріал колеса й дороги володіє абсолютною пружністю (ідеальне пружне тіло без розсіяння енергії), то залежність напруження від деформації на етапі втискання й на етапі повернення форми буде ідентичною. Профіль тиску `p(x)` у такому разі буде строго симетричним відносно вертикальної осі колеса: `p(x) = p(−x)`.

Обчислимо перший момент розподілу нормального тиску відносно проекції осі колеса:

```
M_p = ∫ x · p(x) dx
```

Для парної функції `p(x)` підінтегральний вираз `x · p(x)` є непарною функцією, і визначений інтеграл у симетричних межах `[−a, +a]` перетворюється на точний нуль:

```
M_p = 0                 [для симетричного пружного контакту]
```

Це означає, що точка прикладання рівнодійної сили `N` збігається з віссю колеса. Лінія дії нормальної реакції перетинає вісь обертання, її плече відносно осі дорівнює нулю, і жодного гальмівного моменту не виникає. Кочення ідеально пружного колеса по ідеально пружній поверхні відбувалося б без утрат.

![Колесо котиться вправо; вага W діє вниз крізь вісь, реакція опори N зсунута вперед на b і створює момент N·b проти обертання, який урівноважує горизонтальна тяга P на осі.](/root/sci/ph-mechanics/rolling-resistance/img/wheel-force-shift.svg)
*Реакція опори зсунута вперед на плече k (на схемі позначено як b); пара сил N і W утворює гальмівний момент N·k, який компенсується силою тяги P через радіус колеса R.*

У реальних конструкційних матеріалах деформація завжди супроводжується внутрішнім тертям або пластичним плином. Коли ділянка колеса входить у контакт попереду осі (`x > 0`), матеріал активно стискається. У цій фазі напруження визначаються як статичною пружністю, так і динамічним опором в'язкого розтягу/стиснення. Коли та сама ділянка колеса проходить нижню точку й опиняється позаду осі (`x < 0`), вона починає розширюватися, повертаючись до вихідної форми. Через ефект запаздывания (в'язкопружну релаксацію) відновлювальне напруження виявляється суттєво меншим за напруження стиснення при тій самій величині геометричної деформації.

У результаті епюра нормального тиску `p(x)` спотворюється: тиск у передній частині плями контакту перевищує тиск у задній частині. Центр ваги епюри тиску (центроїд розподілених сил) неминуче зміщується вперед за напрямком руху на відстань `k`:

```
k = ( ∫ x · p(x) dx ) / ( ∫ p(x) dx ) = (1 / N) · ∫ x · p(x) dx
```

Величина `k` (у багатьох інженерних школах позначається також як `b` або `δ_r`) має розмірність довжини (метри або міліметри) і називається **лінійним коефіцієнтом тертя кочення** або **плечем опору коченню**.

Рівнодійна сила нормальної реакції `N`, прикладена в точці `x = +k`, більше не проходить через центр колеса. Вона створює відносно осі обертання гальмівний момент:

```
M_roll = N · k
```

Складемо рівняння статики для колеса, що рухається рівномірно під дією горизонтальної тягової сили `P`, прикладеної до осі:

```
Сума сил по вертикалі:      N − W = 0           ⟹  N = m · g
Сума сил по горизонталі:    P + F_x = 0         ⟹  F_x = −P
Сума моментів відносно осі: N · k − P · h = 0   ⟹  P · h = N · k
```

Оскільки глибина вдавлювання `δ` у більшості транспортних коліс становить одиниці відсотків від радіуса (`δ ≪ R`), плече тягової сили `h = R − δ` з високою точністю дорівнює радіусу колеса `R`. Звідси отримуємо канонічну формулу горизонтальної сили тяги, необхідної для подолання опору коченню:

```
P = (k / R) · N = C_rr · N
```

Тут безрозмірна величина `C_rr = k / R` є **безрозмірним коефіцієнтом опору коченню**. 

Якщо колесо є не веденим (до осі якого прикладають тягу `P`), а ведучим (до осі якого підводиться крутний момент `T` від двигуна), рівняння моментів набуває вигляду:

```
T − N · k − F_тракція · R = 0
F_тракція = (T − N · k) / R = T / R − C_rr · N
```

Крутний момент двигуна спершу витрачається на подолання внутрішнього гальмівного моменту опору коченню `N · k`, і лише залишковий момент трансформується в корисну силу тяги, що штовхає транспортний засіб уперед. Докладне математичне виведення балансу розподілених сил для обох випадків наведено у вставці [точне виведення рівноваги сил і кінематики плями](root:ph-mechanics/rolling-resistance/math-force-shift.md).

## В'язкопружний гістерезис і реологія втрат

Головним фізичним джерелом виникнення плеча `k` у сучасних пневматичних шинах є явище гістерезису (грец. *hystéresis* — відставання, запізнення) в полімерному матеріалі протектора, брекера та боковин.

Каучуки та еластомери, що входять до складу автомобільних шин, належать до класу в'язкопружних тіл. Їхня механічна поведінка описується комбінацією закону пружності Гука (де напруження пропорційне деформації: `σ = E · ε`) та закону в'язкого плину Ньютона (де напруження пропорційне швидкості деформації: `σ = η · (dε/dt)`).

При гармонічному циклічному навантаженні з круговою частотою `ω` деформація відстає від прикладеного напруження на фазовий кут `δ_loss` (кут механічних втрат):

```
ε(t) = ε_0 · sin(ω · t)
σ(t) = σ_0 · sin(ω · t + δ_loss) = σ_0 · cos(δ_loss) · sin(ω · t) + σ_0 · sin(δ_loss) · cos(ω · t)
```

У динамічному механічному аналізі (DMA) в'язкопружний відгук представляють через комплексний модуль пружності `E*`:

```
E* = E' + i · E''
E'  = (σ_0 / ε_0) · cos(δ_loss)     [модуль пружного накопичення, Storage Modulus]
E'' = (σ_0 / ε_0) · sin(δ_loss)     [модуль механічних втрат, Loss Modulus]
tan(δ_loss) = E'' / E'              [тангенс кута втрат, Loss Tangent]
```

![Ліворуч: тиск у плямі несиметричний — спереду більший, тож рівнодійна N зсувається вперед на b. Праворуч: петля гістерезису напруження–деформація, її площа — енергія, втрачена на тепло за цикл.](/root/sci/ph-mechanics/rolling-resistance/img/hysteresis.svg)
*Несиметричний розподіл тиску по довжині контакту (ліворуч) є прямим просторовим відображенням часової петлі гістерезису напруження–деформація (праворуч). Площа всередині замкненої петлі дорівнює об'ємній щільності енергії, безповоротно розсіяної в тепло за один оберт.*

Модуль `E'` відображає здатність матеріалу оборотно запасати пружну потенціальну енергію при стисненні, тоді як модуль `E''` характеризує частку енергії, яка безповоротно розсіюється у вигляді тепла за рахунок тертя макромолекулярних полімерних ланцюгів між собою.

Обчислимо механічну роботу, що витрачається на деформацію одиниці об'єму матеріалу шини за один повний цикл обертання:

```
w_cycle = ∮ σ dε = ∫₀^(2π/ω) σ(t) · (dε/dt) dt
        = ∫₀^(2π/ω) [σ_0 · sin(ω·t + δ_loss)] · [ω · ε_0 · cos(ω·t)] dt
        = π · σ_0 · ε_0 · sin(δ_loss)
        = π · E'' · ε_0² = π · E' · ε_0² · tan(δ_loss)
```

Графічно інтеграл `∮ σ dε` є площею петлі гістерезису на діаграмі «напруження–деформація». При коченні колеса кожен його сегмент під час наближення до плями контакту стискається вздовж верхньої гілки кривої, накопичуючи енергію, а при виході з контакту розвантажується вздовж нижньої гілки кривої, віддаючи лише частину енергії. Різниця площ під кривими навантаження й розвантаження — це чиста енергія, перетворена на внутрішню теплову енергію.

Зв'яжемо мікроскопічну енергію гістерезису з макроскопічною силою опору коченню. Нехай за один повний оберт колеса на кут `2π` (що відповідає переміщенню осі на відстань `s = 2π · R`) циклічну деформацію проходять елементи шини сумарним об'ємом `V_def`. Повна робота тяги `A_тяга = P · (2π · R)` за законом збереження енергії має строго дорівнювати сумі теплових втрат в усьому деформованому об'ємі:

```
P · 2π · R = ∫ w_cycle dV = w_cycle · V_def
P = (w_cycle · V_def) / (2π · R)
```

Підставляючи вираз `P = (k / R) · N`, отримуємо фундаментальний зв'язок між плечем `k` та об'ємною дисипацією енергії:

```
k = (w_cycle · V_def) / (2π · N)
C_rr = k / R = (w_cycle · V_def) / (2π · N · R)
```

> 🔧 **Навіщо це.** Опір коченню шини — це не поверхневе тертя о дорогу, а об'ємний тепловий процес усередині гуми. Для легкового автомобіля, що рухається зі швидкістю 100 км/год, кожне колесо безперервно розсіює в тепло від 800 до 1200 ват потужності. Саме тому температура всередині брекерного пояса покришки на автостраді прогрівається до 70–85 °C навіть за прохолодної погоди. Якщо ж шина має прихований дефект або суттєво недокачана, об'єм деформації `V_def` зростає, тепловідвід не встигає розсіювати кіловати тепла, температура перевищує критичні 120 °C, полімер зазнає термічної деструкції, і відбувається раптове руйнування (розшарування протектора).

## Безрозмірний коефіцієнт Crr та його спектр

Безрозмірний коефіцієнт `C_rr` дозволяє оцінювати енергетичну досконалість колісного рушія незалежно від його абсолютних геометричних розмірів та маси транспортного засобу. Сила опору коченню для довільного транспортного засобу повної маси `M_veh` на дорожньому покритті з кутом нахилу `θ` до горизонту розраховується за формулою:

```
F_roll = C_rr · N = C_rr · M_veh · g · cos(θ)
```

На горизонтальній ділянці дороги (`θ = 0`, `cos(θ) = 1`):

```
F_roll = C_rr · M_veh · g
```

Діапазон значень `C_rr` у сучасній техніці охоплює понад три порядки величини — від `0.0002` для прецизійних важких рейок до `0.35` для руху по глибокому пухкому піску чи болоту.

**Порівняльний чисельний розрахунок.**
Розглянемо три транспортні засоби, що переміщують корисний вантаж по горизонтальній дорозі:
1. Магістральний електропоїзд масою `M = 800` тонн (`C_rr = 0.0005`);
2. Електрична вантажівка повною масою `M = 40` тонн (`C_rr = 0.0055`);
3. Легковий електромобіль масою `M = 2000` кг (`C_rr = 0.0080`).

```
1. Поїзд (800 т):
   N      = 800000 · 9.81 = 7848000 Н = 7.848 МН
   F_roll = 0.0005 · 7848000 = 3924 Н ≈ 3.92 кН
   Питомий опір: f = F_roll / M = 3924 / 800 = 4.90 Н/т

2. Вантажівка (40 т):
   N      = 40000 · 9.81 = 392400 Н = 392.4 кН
   F_roll = 0.0055 · 392400 = 2158 Н ≈ 2.16 кН
   Питомий опір: f = F_roll / M = 2158 / 40 = 53.95 Н/т

3. Легковик (2 т):
   N      = 2000 · 9.81 = 19620 Н
   F_roll = 0.0080 · 19620 = 157.0 Н
   Питомий опір: f = F_roll / M = 157.0 / 2 = 78.50 Н/т
```

Цей розрахунок демонструє, чому залізничний транспорт утримує абсолютне лідерство за енергоефективністю масових сухопутних перевезень: на переміщення однієї тонни маси потяг витрачає у 11 разів менше зусилля, ніж вантажівка на асфальті, і в 16 разів менше, ніж легковий автомобіль.

## Фізичні фактори: тиск, швидкість, діаметр і ґрунт

Величина `C_rr` не є константою навіть для конкретної пари матеріалів колеса й дороги. Вона залежить від чотирьох ключових експлуатаційних факторів: внутрішнього тиску в шині, швидкості пересування, радіуса колеса та співвідношення жорсткості колеса й основи.

### 1. Внутрішній тиск у пневматичній шині

У пневматичній шині нормальне навантаження утримується переважно тиском стисненого газу всередині камери/безкамерного простору, і лише невелика частка (5–15%) припадає на пружність гумово-кордного каркаса.

Площа плями контакту `A_patch` у першому наближенні обернено пропорційна внутрішньому манометричному тиску `p_tire`:

```
A_patch ≈ N / p_tire
```

При падінні тиску `p_tire` площа контакту зростає. Щоб забезпечити цю площу, шина змушена сильніше прогинатися: радіальна деформація `δ` збільшується. Це призводить до зростання амплітуди знакозмінних деформацій у боковинах і протекторі. Оскільки втрати енергії за цикл пропорційні квадрату амплітуди деформації (`w_cycle ∝ ε_0²`), об'ємні теплові втрати різко зростають.

На твердому покритті (асфальт, бетон) емпірична залежність коефіцієнта опору коченню від тиску описується степеневим законом:

```
C_rr(p_tire) = C_rr0 · (p_0 / p_tire)^α_p
```

де `α_p ≈ 0.5 – 0.8` для легкових шин. Зниження тиску в легковому колесі від номінальних 2.4 бар до 1.8 бар збільшує коефіцієнт опору коченню на 20–25%.

**Парадокс деформівного ґрунту.**
На піску, багнюці чи свіжому снігу фізична картина повністю змінюється. На слабкому ґрунті головним джерелом опору є не внутрішній гістерезис шини, а необоротна пластична робота руйнування та ущільнення ґрунту (утворення колії). Жорстке, сильно накачане колесо має малу площу опори й створює високий питомий тиск на ґрунт, продавлюючи глибоку колію. Колесо постійно «їде в гору», намагаючись вибратися з власної ями.

Якщо зменшити тиск у шині в 2–3 рази (наприклад, з 2.5 бар до 0.8–1.0 бар за допомогою системи централізованого підкачування шин CTIS):
- Площа плями контакту зростає;
- Питомий тиск на ґрунт падає нижче за межу тримкості ґрунту;
- Глибина колії зменшується з 15–20 см до 2–4 см;
- Опір від деформації ґрунту падає в кілька разів, що з надлишком перекриває незначне збільшення внутрішніх втрат у самій шині.

### 2. Діаметр і радіус колеса

Залежність опору коченню від радіуса колеса `R` була предметом тривалої історичної полеміки між Шарлем Кулоном (який 1781 року встановив залежність `C_rr ∝ 1/R`) та Жулем Дюпюї (який 1837 року запропонував `C_rr ∝ 1/√R`). Детальний розбір цього протистояння наведено у вставці [історичний розвиток законів тертя кочення](root:ph-mechanics/rolling-resistance/hist-coulomb-dupuit.md).

З погляду сучасної механіки контакту:
- Для абсолютно твердого циліндра на пружно-в'язкій основі (контакт за Герцом) напівширина плями контакту `a ∝ √(N · R / E)`. Оскільки плече `k ∝ a`, маємо:
  ```
  k ∝ √(R)  ⟹  C_rr = k / R ∝ 1 / √(R)    [закон Дюпюї для лінійного контакту]
  ```
- Для твердої сферичної кулі радіуса `R` (точковий контакт Герца) `a ∝ (N · R / E)^(1/3)`, звідки:
  ```
  C_rr = k / R ∝ 1 / R^(2/3)
  ```
- Для пневматичної автомобільної шини на жорсткому асфальті розміри плями контакту диктуються переважно внутрішнім тиском повітря (`A ≈ N / p_tire`), тому зміна зовнішнього діаметра колеса в типовому діапазоні (R від 0.28 до 0.35 м) дає слабкий вплив на `C_rr` (коефіцієнт змінюється приблизно пропорційно `R^(−0.2)`).

Проте великий радіус колеса має вирішальне значення при русі по нерівностях і бруківці. При наїзді на сходинку або камінь висотою `h_obs` колесо здійснює підйом. З геометричного трикутника сила, необхідна для перекочування через перешкоду без зупинки, становить:

```
F_obs ≈ N · √(2 · h_obs / R)
```

Збільшення радіуса колеса вдвічі знижує зусилля подолання дорожніх нерівностей у `√2 ≈ 1.41` раза.

### 3. Швидкість руху та стоячі хвилі в шині

При низьких і помірних швидкостях (до 80–100 км/год) коефіцієнт `C_rr` слабо залежить від швидкості руху: нагрівання шини дещо знижує тангенс кута втрат `tan(δ_loss)` гуми, що компенсує зростання частоти деформацій.

Проте при подальшому зростанні швидкості починають домінувати динамічні інерційні сили в оболонці шини. Для точного розрахунку дорожнього опору в міжнародній автомобільній інженерії застосовують емпіричний стандарт **SAE J2452**, який апроксимує коефіцієнт опору коченню тричленною параболічною моделлю:

```
C_rr(v) = p_tire^α · N^β · (c_0 + c_1 · v + c_2 · v²)
```

де `c_0` відповідає квазістатичному гістерезису, `c_1 · v` — в'язкому демпфуванню, а `c_2 · v²` — інерційним та аеродинамічним втратам на вентиляцію протектора.

**Критична швидкість і стоячі хвилі.**
При перевищенні певної критичної швидкості `v_crit` виникає небезпечний фізичний резонанс — **стоячі хвилі в каркасі шини** (англ. *tire standing waves*). 

Ділянка протектора, виходячи з зони контакту, прагне повернутися до вихідного радіуса під дією натягу корду `T_cord`. По оболонці шини поширюється поперечна пружна хвиля зі швидкістю:

```
v_wave = √( T_cord / ρ_linear )
```

де `ρ_linear` — погонна маса протектора та брекера (кг/м).

Якщо лінійна швидкість кочення колеса `v` наближається до швидкості поширення хвилі `v_wave`, деформація після виходу з контакту не встигає згаснути до наступного оберту. Безпосередньо за плямою контакту виникає стаціонарна синусоїдальна стояча хвиля великої амплітуди. Це викликає лавиноподібне зростання амплітуди деформацій, опір коченню `C_rr` миттєво стрибає в 3–5 разів, а температура протектора за десятки секунд досягає температури плавлення гумової суміші (150–180 °C), що завершується вибуховим розривом шини.

### 4. Механіка деформівного ґрунту (модель Бекера)

Коли колесо котиться по ґрунту, торфу чи снігу, деформація опорної поверхні перевищує деформацію самого колеса. Для розрахунку нормального тиску ґрунту під колесом використовують класичне рівняння Бекера (Bekker's pressure-sinkage relation):

```
p(z) = ( k_c / b_w + k_φ ) · z^n_soil
```

де:
- `z` — глибина занурення колеса в ґрунт;
- `b_w` — ширина колісного протектора;
- `k_c` — модуль зв'язності ґрунту (Н/м^(n+1));
- `k_φ` — модуль внутрішнього тертя ґрунту (Н/м^(n+2));
- `n_soil` — показник деформації ґрунту (зазвичай 0.5–1.5).

Вертикальна рівновага колеса визначає максимальну глибину колії `z_0`:

```
N = b_w · ∫₀^(z_0) p(z) · [ (2·R·z − z²) / (2·R·z_0 − z_0²) ]^(1/2) dz
```

Сила опору колієутворенню (Sinkage Rolling Resistance) обчислюється як робота, витрачена на вертикальне ущільнення ґрунту на одиниці пройденого шляху:

```
F_sinkage = b_w · ∫₀^(z_0) p(z) dz = b_w · ( k_c / b_w + k_φ ) · ( z_0^(n_soil + 1) / (n_soil + 1) )
```

На м'яких ґрунтах `F_sinkage` складає до 80–90% від загального опору пересуванню, багаторазово перевершуючи внутрішній гістерезис матеріалу шини.

## Енергетика руху: перетин опору кочення та аеродинаміки

При рівномірному русі транспортного засобу по горизонтальній дорозі сумарна сила опору руху `F_total` складається з двох головних сил, які мають принципово різну природу залежності від швидкості:

```
F_total(v) = F_roll + F_aero(v) = C_rr · M_veh · g + ½ · ρ_air · C_d · A_front · v²
```

де:
- `F_roll` — сила опору коченню, яка в першому наближенні залишається постійною і не залежить від швидкості;
- `F_aero` — аеродинамічний опір повітря, який зростає пропорційно **квадрату швидкості** `v²`;
- `ρ_air` — густина навколишнього повітря (за нормальних умов 1.225 кг/м³ при 15 °C та тиску 101.3 кПа);
- `C_d` — аеродинамічний коефіцієнт лобового опору (Drag Coefficient);
- `A_front` — площа лобової проекції автомобіля (м²).

![Дві криві сили проти швидкості для хетчбека: горизонтальна пряма опору коченню на 141 Н і парабола опору повітря, що перетинає її на 67 км/год; ліва царина підсвічена синім, права — червоним](/root/sci/ph-mechanics/rolling-resistance/img/rolling-vs-drag.svg)
*Баланс сил дорожнього опору як функція швидкості. Нижче за швидкість перетину v* основні енергетичні втрати визначаються шинами; вище за v* домінує лобовий опір повітря.*

Оскільки опір коченню практично постійний, а аеродинамічний опір росте як парабола, існує єдина фізична **швидкість перетину** `v*`, на якій ці сили стають строго рівними між собою:

```
C_rr · M_veh · g = ½ · ρ_air · C_d · A_front · (v*)²
v* = √( (2 · C_rr · M_veh · g) / (ρ_air · C_d · A_front) )
```

Фізичний зміст швидкості перетину полягає в тому, що вона ділить увесь швидкісний діапазон транспортного засобу на дві принципово різні інженерні зони:
1. При `v < v*` (міський рух, маневрування) домінує опір коченню (`F_roll > F_aero`). У цьому режимі головним фактором оптимізації запасу ходу є зниження маси автомобіля, вибір шин із низьким гістерезисом та контроль тиску.
2. При `v > v*` (автострада, швидкісні траси) домінує аеродинаміка (`F_aero > F_roll`). На швидкості `2 · v*` аеродинамічний опір перевищує опір шин уже вчетверо (`(v/v*)² = 4`).

![Горизонтальні смуги швидкості перетину: велосипед 15 км/год, електросамокат 24, легковик-хетчбек 67, електроседан 82, фура 89 км/год](/root/sci/ph-mechanics/rolling-resistance/img/crossover-fleet.svg)
*Швидкість перетину v* для різних класів транспорту. Велосипедисти працюють в аеродинамічному режимі майже завжди, тоді як важка фура ділить опір навпіл рівно на крейсерських 90 км/год.*

Повний чисельний алгоритм пошуку швидкості перетину з урахуванням ухилу, вітру та змінної моделі SAE J2452 реалізовано у проектній вставці [розрахунок точки рівності кочення та аеродинаміки](root:ph-mechanics/rolling-resistance/proj-rolling-vs-drag.md).

Механічна потужність, необхідна для подолання обох сил опору на швидкості `v`:

```
P_mech(v) = F_total(v) · v = F_roll · v + F_aero · v = (C_rr · M_veh · g) · v + (½ · ρ_air · C_d · A_front) · v³
```

Потужність подолання опору коченню `P_roll = F_roll · v` зростає **лінійно** зі швидкістю, тоді як аеродинамічна потужність `P_aero = F_aero · v` зростає **пропорційно кубу швидкості** `v³`.

## Інженерний розрахунок електроприводу на C і C++

У тягових розрахунках електромобілів (EV) та автономних колісних роботів (AGV) точне моделювання опору коченню є критичним для визначення теплового навантаження на тяговий електродвигун, розрахунку передавального відношення редуктора та оцінки реального запасу ходу від акумуляторної батареї.

Повний тяговий баланс на колесах включає чотири складові:
```
F_wheel = F_roll + F_aero + F_grade + F_accel
F_roll  = C_rr(v, p_tire, N) · M_veh · g · cos(θ)
F_aero  = ½ · ρ_air · C_d · A_front · (v + v_wind)²
F_grade = M_veh · g · sin(θ)
F_accel = M_veh · a · (1 + δ_rot)
```
де `δ_rot` — коефіцієнт врахування обертових інерційних мас коліс, ротора електродвигуна та трансмісії (`δ_rot ≈ 0.04 – 0.08`).

Кутова швидкість обертання коліс `ω_wheel` та швидкість ротора електродвигуна `ω_motor`:
```
ω_wheel = v / R_dynamic
ω_motor = ω_wheel · i_gearbox
```
де `i_gearbox` — передавальне число редуктора, `R_dynamic ≈ 0.98 · R_static` — динамічний радіус кочення навантаженої шини.

Крутний момент на валу електродвигуна з урахуванням ККД механічного редуктора `η_gearbox`:
```
T_motor = (F_wheel · R_dynamic) / (i_gearbox · η_gearbox)     [у тяговому режимі, F_wheel > 0]
T_motor = (F_wheel · R_dynamic · η_gearbox) / i_gearbox     [у режимі рекуперативного гальмування]
```

Електрична потужність, споживана інвертором від тягової високовольтної батареї:
```
P_battery = (T_motor · ω_motor) / η_motor_inv(T_motor, ω_motor) + P_aux
```
де `η_motor_inv` — сумарний ККД інвертора та синхронного електродвигуна з постійними магнітами (PMSM), який розраховується з урахуванням мідних втрат в обмотках статора (`P_cu ∝ I² ∝ T²`), магнітних втрат на перемагнічування та вихрові струми (`P_fe ∝ ω + ω²`) та втрат на тертя в підшипниках; `P_aux` — потужність бортової електроніки та системи клімат-контролю.

Нижче наведено робочий інженерний модуль для розрахунку тягової потужності, втрат у шинах та моделювання циклу руху.

#include <stdio.h>
#include <math.h>
#include <stdbool.h>

#define GRAVITY 9.81
#define AIR_DENSITY_STD 1.225

typedef struct {
    double mass_kg;             /* Повна маса транспортного засобу (кг) */
    double cd;                  /* Коефіцієнт лобового аеродинамічного опору */
    double frontal_area_m2;     /* Лобова площа проекції (м²) */
    double tire_radius_m;       /* Динамічний радіус колеса (м) */
    double tire_pressure_bar;   /* Внутрішній тиск у шинах (бар) */
    double crr_nominal;         /* Номінальний коефіцієнт кочення за тиску 2.5 бар */
    double gear_ratio;          /* Передавальне відношення редуктора */
    double gear_efficiency;     /* Механічний ККД трансмісії */
    double rot_inertia_coeff;   /* Коефіцієнт обертових мас (1 + delta) */
    double aux_power_w;         /* Потужність допоміжних систем (Вт) */
} VehicleParams;

typedef struct {
    double speed_mps;           /* Поточна швидкість руху (м/с) */
    double accel_mps2;          /* Лінійне прискорення (м/с²) */
    double grade_rad;           /* Кут нахилу дороги (радіани) */
    double headwind_mps;        /* Зустрічна швидкість вітру (м/с) */
    double air_density;         /* Густина повітря (кг/м³) */
} DynamicState;

typedef struct {
    double f_roll_n;            /* Сила опору коченню (Н) */
    double f_aero_n;            /* Сила аеродинамічного опору (Н) */
    double f_grade_n;           /* Сила опору підйому (Н) */
    double f_accel_n;           /* Сила інерційного прискорення (Н) */
    double f_total_wheel_n;     /* Сумарна тягова сила на колесах (Н) */
    double motor_torque_nm;     /* Необхідний момент на валу двигуна (Н·м) */
    double motor_speed_radps;   /* Кутова швидкість двигуна (рад/с) */
    double motor_power_mech_w;  /* Механічна потужність двигуна (Вт) */
    double motor_efficiency;    /* Розрахунковий ККД двигуна та інвертора */
    double battery_power_w;     /* Повна споживана електрична потужність від АКБ (Вт) */
} SimulationResult;

/* Розрахунок залежності C_rr від швидкості та тиску за модифікованою моделлю SAE */
double compute_rolling_coeff(const VehicleParams* veh, double speed_mps) {
    double p_ratio = 2.5 / veh->tire_pressure_bar;
    double pressure_factor = sqrt(p_ratio);
    double speed_factor = 1.0 + 0.0035 * (speed_mps * 3.6 / 100.0) + 
                          0.0020 * pow(speed_mps * 3.6 / 100.0, 2.0);
    return veh->crr_nominal * pressure_factor * speed_factor;
}

/* Модель розрахунку ККД PMSM електродвигуна з урахуванням мідних та магнітних втрат */
double compute_motor_efficiency(double torque_nm, double speed_radps) {
    double p_mech = fabs(torque_nm * speed_radps);
    if (p_mech < 50.0) return 0.65;
    
    double loss_copper = 0.0018 * (torque_nm * torque_nm);
    double loss_iron = 0.00035 * (speed_radps * speed_radps) + 0.08 * speed_radps;
    double loss_friction = 0.015 * speed_radps + 35.0;
    double total_loss = loss_copper + loss_iron + loss_friction;
    
    double eff = p_mech / (p_mech + total_loss);
    if (eff > 0.965) eff = 0.965;
    if (eff < 0.200) eff = 0.200;
    return eff;
}

/* Обчислення миттєвого тягового балансу та енергоспоживання */
SimulationResult simulate_step(const VehicleParams* veh, const DynamicState* state) {
    SimulationResult res;
    double normal_force = veh->mass_kg * GRAVITY * cos(state->grade_rad);
    double crr = compute_rolling_coeff(veh, state->speed_mps);
    
    res.f_roll_n = crr * normal_force;
    
    double air_speed = state->speed_mps + state->headwind_mps;
    res.f_aero_n = 0.5 * state->air_density * veh->cd * veh->frontal_area_m2 * (air_speed * air_speed);
    if (air_speed < 0.0) res.f_aero_n = -res.f_aero_n;
    
    res.f_grade_n = veh->mass_kg * GRAVITY * sin(state->grade_rad);
    res.f_accel_n = veh->mass_kg * state->accel_mps2 * veh->rot_inertia_coeff;
    
    res.f_total_wheel_n = res.f_roll_n + res.f_aero_n + res.f_grade_n + res.f_accel_n;
    
    double wheel_speed_radps = state->speed_mps / veh->tire_radius_m;
    res.motor_speed_radps = wheel_speed_radps * veh->gear_ratio;
    
    if (res.f_total_wheel_n >= 0.0) {
        res.motor_torque_nm = (res.f_total_wheel_n * veh->tire_radius_m) / 
                              (veh->gear_ratio * veh->gear_efficiency);
        res.motor_power_mech_w = res.motor_torque_nm * res.motor_speed_radps;
        res.motor_efficiency = compute_motor_efficiency(res.motor_torque_nm, res.motor_speed_radps);
        res.battery_power_w = (res.motor_power_mech_w / res.motor_efficiency) + veh->aux_power_w;
    } else {
        /* Режим рекуперативного електричного гальмування */
        res.motor_torque_nm = (res.f_total_wheel_n * veh->tire_radius_m * veh->gear_efficiency) / 
                              veh->gear_ratio;
        res.motor_power_mech_w = res.motor_torque_nm * res.motor_speed_radps;
        res.motor_efficiency = compute_motor_efficiency(res.motor_torque_nm, res.motor_speed_radps);
        res.battery_power_w = (res.motor_power_mech_w * res.motor_efficiency) + veh->aux_power_w;
    }
    
    return res;
}

#include <span>

constexpr double GRAVITY = 9.81;
constexpr double AIR_DENSITY_STD = 1.225;

struct VehicleParameters {
    double mass_kg{1950.0};
    double cd{0.23};
    double frontal_area_m2{2.25};
    double tire_radius_m{0.33};
    double tire_pressure_bar{2.5};
    double crr_nominal{0.0080};
    double gear_ratio{9.05};
    double gear_efficiency{0.97};
    double rot_inertia_coeff{1.05};
    double aux_power_w{450.0};

    [[nodiscard]] constexpr double aerodynamic_drag_area() const noexcept {
        return cd * frontal_area_m2;
    }
};

struct DynamicState {
    double speed_mps{0.0};
    double accel_mps2{0.0};
    double grade_rad{0.0};
    double headwind_mps{0.0};
    double air_density{AIR_DENSITY_STD};
};

struct TractionAnalysis {
    double f_roll_n{0.0};
    double f_aero_n{0.0};
    double f_grade_n{0.0};
    double f_accel_n{0.0};
    double f_total_wheel_n{0.0};
    double motor_torque_nm{0.0};
    double motor_speed_radps{0.0};
    double motor_power_mech_w{0.0};
    double motor_efficiency{0.0};
    double battery_power_w{0.0};
};

class ElectricPowertrainSimulator {
public:
    explicit ElectricPowertrainSimulator(VehicleParameters params) 
        : params_{params} {}

    [[nodiscard]] double compute_rolling_coeff(double speed_mps) const noexcept {
        const double p_ratio = 2.5 / params_.tire_pressure_bar;
        const double pressure_factor = std::sqrt(p_ratio);
        const double v_norm = (speed_mps * 3.6) / 100.0;
        const double speed_factor = 1.0 + 0.0035 * v_norm + 0.0020 * (v_norm * v_norm);
        return params_.crr_nominal * pressure_factor * speed_factor;
    }

    [[nodiscard]] static double compute_motor_efficiency(double torque_nm, double speed_radps) noexcept {
        const double p_mech = std::abs(torque_nm * speed_radps);
        if (p_mech < 50.0) return 0.65;

        const double loss_copper = 0.0018 * (torque_nm * torque_nm);
        const double loss_iron = 0.00035 * (speed_radps * speed_radps) + 0.08 * speed_radps;
        const double loss_friction = 0.015 * speed_radps + 35.0;
        const double total_loss = loss_copper + loss_iron + loss_friction;

        const double eff = p_mech / (p_mech + total_loss);
        return std::clamp(eff, 0.200, 0.965);
    }

    [[nodiscard]] TractionAnalysis evaluate(const DynamicState& state) const noexcept {
        TractionAnalysis out;
        const double normal_force = params_.mass_kg * GRAVITY * std::cos(state.grade_rad);
        const double crr = compute_rolling_coeff(state.speed_mps);
        out.f_roll_n = crr * normal_force;

        const double air_speed = state.speed_mps + state.headwind_mps;
        const double aero_sign = (air_speed >= 0.0) ? 1.0 : -1.0;
        out.f_aero_n = aero_sign * 0.5 * state.air_density * params_.aerodynamic_drag_area() * (air_speed * air_speed);

        out.f_grade_n = params_.mass_kg * GRAVITY * std::sin(state.grade_rad);
        out.f_accel_n = params_.mass_kg * state.accel_mps2 * params_.rot_inertia_coeff;

        out.f_total_wheel_n = out.f_roll_n + out.f_aero_n + out.f_grade_n + out.f_accel_n;

        const double wheel_speed_radps = state.speed_mps / params_.tire_radius_m;
        out.motor_speed_radps = wheel_speed_radps * params_.gear_ratio;

        if (out.f_total_wheel_n >= 0.0) {
            out.motor_torque_nm = (out.f_total_wheel_n * params_.tire_radius_m) / 
                                  (params_.gear_ratio * params_.gear_efficiency);
            out.motor_power_mech_w = out.motor_torque_nm * out.motor_speed_radps;
            out.motor_efficiency = compute_motor_efficiency(out.motor_torque_nm, out.motor_speed_radps);
            out.battery_power_w = (out.motor_power_mech_w / out.motor_efficiency) + params_.aux_power_w;
        } else {
            out.motor_torque_nm = (out.f_total_wheel_n * params_.tire_radius_m * params_.gear_efficiency) / 
                                  params_.gear_ratio;
            out.motor_power_mech_w = out.motor_torque_nm * out.motor_speed_radps;
            out.motor_efficiency = compute_motor_efficiency(out.motor_torque_nm, out.motor_speed_radps);
            out.battery_power_w = (out.motor_power_mech_w * out.motor_efficiency) + params_.aux_power_w;
        }

        return out;
    }

    [[nodiscard]] const VehicleParameters& parameters() const noexcept { return params_; }

private:
    VehicleParameters params_;
};
