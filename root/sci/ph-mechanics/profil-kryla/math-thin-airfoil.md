# 🧮 Теорія тонкого профілю та інтеграл Жуковського

Аналітичний розрахунок підіймальної сили та поздовжнього моменту аеродинамічного профілю спирається на лінеаризовану теорію потенціального обтікання тонкого крила, розроблену Германом Глауертом (англ. *Hermann Glauert*, 1926). Теорія замінює реальний профіль нескінченно тонким вихровим шаром (вихровим простирадлом), розташованим уздовж лінії хорди, і зводить рівняння гідродинаміки до сингулярного інтегрального рівняння, що розв'язується через розклад у ряд Фур'є.

## Постановка крайової задачі на лінії хорди

Розглядається плоске стаціонарне обтікання профілю нестисливою нев'язкою рідиною з густиною `ρ` та швидкістю набігаючого потоку `v_∞` під малим кутом атаки `α` (у радіанах, `α ≪ 1`). Геометрія профілю задається рівнянням середньої лінії кривини `y_c(x)` на відрізку `0 ≤ x ≤ c`, де `c` — довжина хорди (грец. *chorde* — струна).

Припущення теорії тонкого профілю:
- Відносна товщина `t/c ≪ 1` та відносна кривина `y_c/c ≪ 1`.
- Збурення швидкості `u(x, y)` та `v(x, y)`, викликані присутністю тіла, набагато менші за швидкість набігаючого потоку: `|u|/v_∞ ≪ 1`, `|v|/v_∞ ≪ 1`.
- Гранична умова непротікання переноситься з реальної поверхні профілю на відрізок осі `y = 0` (`0 ≤ x ≤ c`).

Профіль моделюється неперервним розподілом вихрової інтенсивності `γ(x)` (циркуляція на одиницю довжини хорди, розмірність м/с) на відрізку `0 ≤ x ≤ c`.

Вертикальна швидкість (скіс потоку `w(x)`), індукована елементарними вихорами `γ(ξ) dξ` у точці `x` на хорді, обчислюється за законом Біо-Савара:

```
w(x) = -(1 / (2·π)) · ∫₀ᶜ [ γ(ξ) / (x - ξ) ] dξ
```

Гранична умова непротікання (дотичність сумарного вектора швидкості до середньої лінії кривини) записується у вигляді:

```
dy_c / dx = (v_∞,y + w(x)) / (v_∞,x + u(x))    [умова дотичності вектора швидкості]
≈ (v_∞·α + w(x)) / v_∞                         [малі кути атаки sin α ≈ α, u ≪ v_∞]
= α + w(x) / v_∞                               [розподіл на складові швидкості]
```

Звідси отримуємо фундаментальне інтегральне рівняння для невідомої густини циркуляції `γ(ξ)`:

```
(1 / (2·π)) · ∫₀ᶜ [ γ(ξ) / (x - ξ) ] dξ = v_∞ · [ α - dy_c/dx ]
```

Інтеграл у лівій частині є сингулярним і розуміється в сенсі головного значення за Коші (англ. *Cauchy principal value*).

## Координатне перетворення Глауерта

Для усунення сингулярностей на кінцях відрізка та переходу до тригонометричного базису Герман Глауерт запропонував заміну змінних:

```
x = (c / 2) · (1 - cos θ),     0 ≤ θ ≤ π
ξ = (c / 2) · (1 - cos θ₀),    0 ≤ θ₀ ≤ π
```

При такій заміні передній кромці `x = 0` відповідає кут `θ = 0`, а задній кромці `x = c` — кут `θ = π`. Диференціал координати набуває вигляду `dξ = (c/2)·sin θ₀ dθ₀`, а знаменник інтеграла:

```
x - ξ = (c / 2) · (cos θ₀ - cos θ)
```

Підставляючи перетворення в інтегральне рівняння, отримуємо:

```
(1 / (2·π)) · ∫₀ᵠ [ γ(θ₀) · sin θ₀ / (cos θ₀ - cos θ) ] dθ₀ = v_∞ · [ α - dy_c/dx ]
```

## Умова Кутти та розклад у ряд Фур'є

Фізично реалізований розв'язок повинен задовольняти гідродинамічну умову Кутти на гострій задній кромці (`x = c`, тобто `θ = π`): швидкість сходу потоку скінченна, що вимагає занулення вихрової інтенсивності:

```
γ(π) = 0
```

На передній кромці (`θ = 0`) для нескінченно тонкої пластини допускається коренева сингулярність `γ(θ) ~ 1/sin θ` (або `1/√x`). Найзагальніший вигляд функції `γ(θ)`, що задовольняє умову Кутти на задній кромці та допускає сингулярність на передній, розкладається в ряд Фур'є:

```
γ(θ) = 2 · v_∞ · [ A₀ · (1 + cos θ) / sin θ + ∑_{n=1}^∞ A_n · sin(n·θ) ]
```

Тут базисний член `(1 + cos θ) / sin θ = cot(θ / 2)` обертається в `0` при `θ = π` і прямує до нескінченності при `θ → 0`. Усі гармонічні члени `sin(n·θ)` рівні нулю як при `θ = 0`, так і при `θ = π`.

Для інтегрування використовується класичний інтеграл Глауерта:

```
∫₀ᵠ [ cos(n·θ₀) / (cos θ₀ - cos θ) ] dθ₀ = π · sin(n·θ) / sin θ
```

Підставивши ряд у ліву частину інтегрального рівняння, знаходимо індуковану вертикальну швидкість:

```
w(θ) / v_∞ = -A₀ + ∑_{n=1}^∞ A_n · cos(n·θ)
```

Прирівнюючи цей вираз до правої частини `α - dy_c/dx`, отримуємо тотожність:

```
A₀ - ∑_{n=1}^∞ A_n · cos(n·θ) = α - dy_c/dx
```

Використовуючи ортогональність тригонометричних функцій на інтервалі `[0, π]`, визначаємо невідомі коефіцієнти ряду `A₀` та `A_n`:

```
A₀ = α - (1 / π) · ∫₀ᵠ (dy_c/dx) dθ
A_n = (2 / π) · ∫₀ᵠ (dy_c/dx) · cos(n·θ) dθ,    n ≥ 1
```

## Сумарна циркуляція та коефіцієнт підіймальної сили

Повна циркуляція швидкості `Γ` навколо профілю дорівнює інтегралу від густини вихорів вздовж хорди:

```
Γ = ∫₀ᶜ γ(x) dx
= (c / 2) · ∫₀ᵠ γ(θ) · sin θ dθ                                        [заміна змінної x на θ]
= c · v_∞ · ∫₀ᵠ [ A₀·(1 + cos θ) + ∑_{n=1}^∞ A_n·sin(n·θ)·sin θ ] dθ   [підстановка ряду Фур'є для γ(θ)]
```

Інтеграли окремих складових:

```
∫₀ᵠ (1 + cos θ) dθ = π               [інтегрування сталого члена та косинуса]
∫₀ᵠ sin(n·θ)·sin θ dθ = π / 2         [при n = 1 за ортогональністю синусів]
∫₀ᵠ sin(n·θ)·sin θ dθ = 0             [при n ≥ 2 за ортогональністю синусів]
```

Звідси точний аналітичний вираз повної циркуляції:

```
Γ = π · c · v_∞ · (A₀ + A₁ / 2)
```

За теоремою Жуковського-Кутта підіймальна сила на одиницю розмаху дорівнює `L' = ρ · v_∞ · Γ`. Безрозмірний коефіцієнт підіймальної сили профілю `C_l` визначається через динамічний тиск `q_∞ = ½ · ρ · v_∞²`:

```
C_l = L' / (q_∞ · c)                                                  [означення безрозмірного коефіцієнта]
= (ρ · v_∞ · Γ) / (½ · ρ · v_∞² · c)                                   [підстановка теореми Жуковського-Кутта]
= 2 · Γ / (v_∞ · c)                                                   [скорочення спільних множників]
= 2·π · (A₀ + A₁ / 2)                                                 [підстановка повної циркуляції Γ]
```

Підставляючи вирази для `A₀` та `A₁`:

```
C_l = 2·π · [ α - (1 / π)·∫₀ᵠ (dy_c/dx) dθ + (1 / π)·∫₀ᵠ (dy_c/dx)·cos θ dθ ]
= 2·π · [ α - (1 / π)·∫₀ᵠ (dy_c/dx)·(1 - cos θ) dθ ]                 [об'єднання інтегралів під спільний знаменник]
```

Позначаючи кут нульової підіймальної сили як `α₀`:

```
α₀ = -(1 / π) · ∫₀ᵠ (dy_c/dx)·(1 - cos θ) dθ
```

Отримуємо класичну лінійну залежність коефіцієнта підіймальної сили:

```
C_l = 2·π · (α - α₀)
```

Теоретичний нахил кривої підіймальної сили для будь-якого тонкого профілю в нестисливому потоці є універсальною константою:

```
dC_l / dα = 2·π  рад⁻¹ ≈ 6.28318 рад⁻¹ ≈ 0.10966 град⁻¹
```

## Аеродинамічний момент та фокус профілю

Поздовжній аеродинамічний момент відносно передньої кромки `M'_LE` (додатний на кабрування) створюється розподілом елементарних сил `dL' = ρ · v_∞ · γ(x) dx` із плечем `x`:

```
M'_LE = -ρ · v_∞ · ∫₀ᶜ x · γ(x) dx
= -ρ · v_∞ · (c² / 4) · ∫₀ᵠ (1 - cos θ) · γ(θ) · sin θ dθ             [заміна змінної x = (c/2)(1 - cos θ)]
```

Обчислюючи коефіцієнт моменту відносно передньої кромки `C_{m,LE} = M'_LE / (q_∞ · c²)`:

```
C_{m,LE} = -(π / 2) · [ A₀ + A₁ - A₂ / 2 ]                            [інтегрування гармонік ряду Фур'є]
= -C_l / 4 + (π / 4) · (A₂ - A₁)                                       [виділення залежності від C_l]
```

Перераховуючи момент відносно точки на чверті хорди `x = c/4`:

```
C_{m,c/4} = C_{m,LE} + C_l / 4                                        [перенесення точки відліку моменту]
= (π / 4) · (A₂ - A₁)                                                  [скорочення члена C_l / 4]
```

Коефіцієнт моменту `C_{m,c/4}` не залежить від кута атаки `α` (оскільки коефіцієнти `A₁` та `A₂` залежать виключно від геометрії кривини `dy_c/dx`). Отже, за теорією тонкого профілю **аеродинамічний фокус завжди розташований точно на 25% хорди (`x_ac = 0.25·c`)**.

## Розрахункові приклади для типових профілів

### Приклад 1: Симетричний профіль (пластина, NACA 0012)

Для симетричного профілю середня лінія є прямою: `y_c(x) = 0 → dy_c/dx = 0`.

Усі геометричні коефіцієнти Фур'є занулюються:

```
A₀ = α
A_n = 0   для всіх n ≥ 1
```

Результати:

```
α₀ = 0
C_l = 2·π·α
C_{m,c/4} = 0
C_{m,LE} = -½·π·α = -C_l / 4
```

Центр тиску збігається з фокусом у точці `x_cp = 0.25·c` для всіх додатних кутів атаки.

### Приклад 2: Профіль із параболічною лінією кривини

Розглядається кругова (параболічна) середня лінія з максимальною кривиною `m = y_{c,max}/c` у центрі хорди (`p = 0.5`):

```
y_c(x) = 4·m·c · (x/c) · (1 - x/c)
```

Похідна по поздовжній координаті:

```
dy_c / dx = 4·m · (1 - 2·(x/c))                                       [диференціювання параболи]
= 4·m · (1 - (1 - cos θ))                                              [підстановка x/c = (1 - cos θ)/2]
= 4·m · cos θ                                                          [спрощення різниці]
```

Обчислення коефіцієнтів Фур'є:

```
A₀ = α - (1/π) · ∫₀ᵠ (4·m·cos θ) dθ
= α - (4·m / π) · [sin θ]₀ᵠ                                           [первісна від косинуса]
= α                                                                    [sin π - sin 0 = 0]

A₁ = (2/π) · ∫₀ᵠ (4·m·cos θ)·cos θ dθ
= (8·m / π) · ∫₀ᵠ cos² θ dθ                                           [винесення константи 4m]
= (8·m / π) · (π / 2)                                                 [інтеграл від квадрата косинуса]
= 4·m                                                                  [скорочення π та множників]

A₂ = (2/π) · ∫₀ᵠ (4·m·cos θ)·cos(2·θ) dθ = 0
A_n = 0   для всіх n ≥ 2
```

Аеродинамічні характеристики:

```
C_l = 2·π · (A₀ + A₁ / 2)
= 2·π · (α + 2·m)                                                     [підстановка A₀ = α та A₁ = 4m]

α₀ = -2·m  рад
C_{m,c/4} = (π / 4) · (A₂ - A₁) = -π·m
```

Для профілю з максимальною кривиною 4% (`m = 0.04`):
- Кут нульової підіймальної сили: `α₀ = -0.08` рад `≈ -4.58°`.
- Постійний поздовжній момент на чверті хорди: `C_{m,c/4} = -π · 0.04 ≈ -0.1257` (пікіруючий момент).
- При нульовому куті атаки (`α = 0°`): `C_l(0) = 2·π · 2·m = 4·π · 0.04 ≈ 0.5027`.

### Приклад 3: Аналітична модель відхилення механізації (закрилка або елерона)

Розглядається плаский профіль хордою `c`, на якому в точці `x_f` встановлено шарнір простого закрилка (елерона), відхиленого вниз на кут `δ_f` (у радіанах).

Похідна середньої лінії має кусково-постійний вигляд:

```
dy_c / dx = 0             [для 0 ≤ x < x_f, тобто 0 ≤ θ < θ_f]
dy_c / dx = -δ_f          [для x_f ≤ x ≤ c, тобто θ_f ≤ θ ≤ π]
```

де `θ_f = arccos(1 - 2·(x_f/c))`.

Обчислення коефіцієнтів ряду Фур'є через інтегрування стрибка нахилу:

```
A₀ = α - (1/π) · ∫_{θ_f}^π (-δ_f) dθ
= α + (δ_f / π) · (π - θ_f)                                            [інтегрування сталого нахилу закрилка]

A₁ = (2/π) · ∫_{θ_f}^π (-δ_f) · cos θ dθ
= -(2·δ_f / π) · [sin π - sin θ_f]
= (2·δ_f / π) · sin θ_f                                                [урахування sin π = 0]

A₂ = (2/π) · ∫_{θ_f}^π (-δ_f) · cos(2·θ) dθ
= (δ_f / π) · sin(2·θ_f)                                               [інтегрування подвійного аргументу]
```

Звідси приріст коефіцієнта підіймальної сили за рахунок відхилення закрилка:

```
ΔC_l = 2·π · (ΔA₀ + ΔA₁ / 2)
= 2·δ_f · [ (π - θ_f) + sin θ_f ]                                      [сума нульової та першої гармонік]
```

Ефективність закрилка `(∂C_l / ∂δ_f)` залежить виключно від відносної хорди закрилка `c_f / c = 1 - x_f / c`. Для типового 25-відсоткового закрилка (`x_f = 0.75·c`):
- `θ_f = arccos(1 - 2·0.75) = arccos(-0.5) = 2·π / 3` (або `120°`).
- `∂C_l / ∂δ_f = 2 · [ (π - 2·π/3) + sin(2·π/3) ] = 2 · [ π/3 + √3 / 2 ] ≈ 3.826` рад⁻¹ `≈ 0.0668` град⁻¹.

Відхилення такого закрилка на `10°` збільшує коефіцієнт підіймальної сили на `ΔC_l ≈ 0.668`.

Поздовжній момент при цьому зазнає додаткового пікіруючого приросту:

```
ΔC_{m,c/4} = (π / 4) · (A₂ - A₁)
= -(δ_f / 4) · [ 2·sin θ_f - sin(2·θ_f) ]                              [приріст пікіруючого моменту закрилка]
```

Для `25%` закрилка: `ΔC_{m,c/4} = -(δ_f / 4) · [ 2·(√3/2) - (-√3/2) ] = -(3·√3 / 8) · δ_f ≈ -0.6495 · δ_f`, що при `δ_f = 10° = 0.1745` рад дає `ΔC_{m,c/4} ≈ -0.1133`.

### Приклад 4: S-подібний (рефлексний) профіль для безхвостої авіації

У літальних апаратах схеми «літаюче крило» відсутнє горизонтальне оперення, розташоване на довгому плечі фюзеляжу, тому поздовжня рівновага вимагає, щоб сам профіль мав додатний аеродинамічний момент відносно фокусу (`C_{m,c/4} > 0`).

Для отримання додатного моменту середня лінія повинна мати S-подібний вигин: додатну кривину в носовій частині (для створення підіймальної сили) та відгин задньої кромки вгору (рефлекс, англ. *reflexed trailing edge*).

Задамо середню лінію поліномом третього степеня з точкою перегину на `x_0 = 0.6·c`:

```
dy_c / dx = k · [ (x/c) - x_0 ] · [ 1 - (x/c) ]
```

Підставляючи заміну Глауерта `x/c = ½·(1 - cos θ)` та інтегруючи коефіцієнти Фур'є `A₁` і `A₂`, бачимо, що завдяки відгину хвостової ділянки вгору коефіцієнт другої гармоніки `A₂` переважає першу `A₁`:

```
A₂ > A₁  ==>  C_{m,c/4} = (π / 4) · (A₂ - A₁) > 0
```

Такий профіль автоматично створює кабруючий момент, що компенсує зміщення центру тиску при зміні швидкості та дозволяє літальному апарату стабільно балансувати без додаткового стабілізатора.
