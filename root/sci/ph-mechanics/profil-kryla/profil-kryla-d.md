# Профіль крила

<preknowlist>
- [Циркуляція та підіймальна сила](root:ph-mechanics/circulation-lift-theorem) — несиметрія обтікання, умова Кутти на гострій задній кромці та теорема Жуковського-Кутта L' = ρ · v_∞ · Γ.
- [Кут атаки й поляра](root:ph-mechanics/kut-ataky-i-poliara) — орієнтація хорди до вектора набігаючого потоку, коефіцієнти підіймальної сили та лобового опору.
- [Динамічний тиск](root:ph-mechanics/dynamic-pressure) — кінетична енергія одиниці об'єму газу q = ½ρv² та зв'язок зі статичним тиском за законом Бернуллі.
- [Число Рейнольдса](root:ph-mechanics/reynolds-number) — міра співвідношення сил інерції та молекулярної в'язкості Re = ρ · v · c / μ.
- [Примежовий шар](root:ph-mechanics/boundary-layer) — гальмування пристінних шарів газу через тертя та розвиток товщини витіснення.
- [Відрив потоку](root:ph-mechanics/flow-separation) — руйнування безвідривного обтікання під дією несприятливого градієнта тиску dp/dx > 0.
</preknowlist>

Пласка фанерна пластина, виставлена під кутом 8° до набігаючого потоку повітря зі швидкістю 25 м/с, створює підіймальну силу, але потік неминуче зривається з її гострого переднього ребра, утворюючи велетенський застійний вихор на всій верхній поверхні. Лобовий опір такої пластини виявляється майже рівним її підіймальній силі (аеродинамічна якість `K = L/D ≤ 3`), а спроба збільшити кут атаки до 10° призводить до повного зриву потоку. Якщо ж тому самому шматку матеріалу надати вигнутого краплеподібного перерізу із заокругленим носком, плавною опуклою спинкою та гострим заднім вістрям, здатність тримати потік без зриву зростає до 16–18°, коефіцієнт підіймальної сили подвоюється, а опір падає у 15–20 разів (`K > 50`).

Аеродинамічний профіль (фр. *profil* — обрис, бічний вигляд) — це форма поперечного перерізу крила площиною, перпендикулярною до його розмаху. Саме геометрія цього двовимірного контуру керує розподілом статичного тиску, товщиною пристінного примежового шару та точкою відриву потоку, визначаючи льотні характеристики літального апарата від 50-грамового мікродрона до 500-тонного транспортного лайнера.

## Анатомія поперечного перерізу: геометричні параметри

Геометрія будь-якого аеродинамічного профілю будується навколо двох взаємно перпендикулярних ліній: базової хорди та лінії кривини.

Хорда (грец. *chorde* — струна, тятива) — це прямий відрізок, що з'єднує дві крайні точки профілю: передню кромку (англ. *Leading Edge*, LE) та задню кромку (англ. *Trailing Edge*, TE). Довжина цього відрізка позначається як `c` і є головним масштабним лінійним розміром профілю. Усі поздовжні та поперечні координати в аеродинаміці традиційно нормуються на довжину хорди, перетворюючись на безрозмірні величини `x/c` та `y/c` у діапазоні від `0.0` до `1.0`.

Середня лінія кривини (англ. *mean camber line*, від лат. *camurus* — вигнутий) `y_c(x)` — це геометричне місце точок, рівновіддалених від верхньої та нижньої поверхонь профілю. Якщо профіль дзеркально симетричний відносно хорди, лінія кривини збігається з прямою лінією хорди (`y_c(x) = 0`). У несучих асиметричних профілів лінія кривини вигнута вгору. Її форма характеризується двома величинами:
- Максимальною кривиною (кембером) `m = (y_{c,max}) / c` (виражається у відсотках хорди, зазвичай 1–6%).
- Поздовжньою позицією максимуму кривини `p = x_m / c` (зазвичай 15–50% хорди від носка).

Розподіл товщини (англ. *thickness distribution*) `y_t(x)` задає відстань від середньої лінії до контуру профілю по нормалі. Головні параметри розподілу товщини:
- Максимальна відносна товщина `t = (t_{max}) / c` (зазвичай 6–18% хорди).
- Положення максимуму товщини `x_t / c` (у класичних профілів 20–30% хорди, у ламінарних — 40–50%).
- Радіус передньої кромки `r_{LE}` — радіус кола, вписаного в носок профілю з центром на дотичній до середньої лінії. Для класичних профілів він становить `r_{LE} ≈ 1.1019 · t² · c`.
- Кут задньої кромки або форма сходження (гостра кромка, заокруглена або усічена з кінцевою товщиною `t_{TE} ≈ 0.001–0.005c` для технологічності виготовлення).

![Геометрія аеродинамічного профілю NACA 2412: хорда c, передня та задня кромки, середня лінія кривини y_c(x), розподіл товщини t_max та побудова верхньої і нижньої поверхонь.](/root/sci/ph-mechanics/profil-kryla/img/naca-geometry.svg)
*Геометричний скелет профілю крила: середня лінія кривини задає розмах несиметрії потоку, а симетричний розподіл товщини формує обтічний об'єм навколо неї.*

Побудова координат верхньої `(x_u, y_u)` (спинки, англ. *suction side*) та нижньої `(x_l, y_l)` (черева, англ. *pressure side*) поверхонь здійснюється відкладанням половини локальної товщини `y_t(x)` перпендикулярно до середньої лінії кривини під кутом `θ = arctan(dy_c / dx)`:

```
x_u = x - y_t(x) · sin θ
y_u = y_c(x) + y_t(x) · cos θ

x_l = x + y_t(x) · sin θ
y_l = y_c(x) - y_t(x) · cos θ
```

Детальний аналіз історичного шляху від емпіричних контурів до аналітичних формул наведено у вставці [Еволюція форми аеродинамічного профілю](root:ph-mechanics/profil-kryla/hist-airfoil-evolution.md).

## Параметричні сімейства: від NACA до сучасних профілів

Для стандартизації аеродинамічних форм Національний консультативний комітет з повітроплавання США (NACA) у 1930-х роках розробив математичні родини профілів.

### Чотиризначна серія NACA (NACA 4-digit)

Геометрія 4-значного профілю (наприклад, NACA 2412) однозначно кодується чотирма цифрами:
- Перша цифра (`2`): максимальна кривина `m` у відсотках хорди (`m = 2% = 0.02c`).
- Друга цифра (`4`): положення максимуму кривини `p` у десятих частках хорди (`p = 40% = 0.4c`).
- Останні дві цифри (`12`): максимальна відносна товщина `t` у відсотках хорди (`t = 12% = 0.12c`).

Розподіл товщини для всіх 4-значних профілів задається аналітичним поліномом:

```
y_t(x) = 5·t·c · [ 0.2969·√(x/c) - 0.1260·(x/c) - 0.3516·(x/c)² + 0.2843·(x/c)³ - 0.1015·(x/c)⁴ ]
```

Коефіцієнт `0.2969·√(x/c)` задає параболічне заокруглення носка з нескінченною похідною в точці `x = 0`, гарантуючи плавний вхід потоку, а від'ємний коефіцієнт `-0.1015·(x/c)⁴` забезпечує сходження товщини до малого технологічного зазору на задній кромці `x = c`.

Середня лінія кривини описується двома параболами, що гладко стикуються в точці максимуму `x = p·c`:

```
y_c(x) = (m / p²) · [ 2·p·(x/c) - (x/c)² ] · c                      [для 0 ≤ x/c ≤ p]
y_c(x) = (m / (1-p)²) · [ (1 - 2·p) + 2·p·(x/c) - (x/c)² ] · c      [для p < x/c ≤ 1]
```

Для симетричного профілю перші дві цифри дорівнюють нулю (NACA 0012: нульова кривина, 12% товщини).

### П'ятизначна серія NACA (NACA 5-digit)

У 5-значній серії (наприклад, NACA 23012) максимум кривини зміщений далеко вперед (на позицію 15% хорди). Перша цифра `2` кодує розрахунковий коефіцієнт підіймальної сили `C_{l,des} = 0.3` (множиться на `0.15`), наступні дві цифри `30` позначають положення максимуму кривини на `15%` хорди, а `12` — відносну товщину 12%. Зміщення вигину вперед створює дуже малий поздовжній момент `C_{m,c/4} ≈ -0.01` при високому максимальному `C_{l,max}`, що мінімізує балансувальний опір оперення літака.

### Шестизначна ламінарна серія NACA (NACA 6-series)

Профілі серії NACA 6 (наприклад, NACA 64-212) оптимізовані для утримання ламінарного примежового шару на спинці. Цифра `6` позначає серію, цифра `4` показує, що зона мінімального тиску (пік розрідження) розташована на 40% хорди, цифра `2` вказує на розрахунковий `C_l = 0.2`, а `12` — на товщину 12%. Плаский градієнт тиску на передніх 40% хорди затримує перехід у турбулентність, забезпечуючи «ламінарне відро» (англ. *laminar bucket*) — зону наднизького профільного опору.

### Спеціалізовані контури

- **Clark Y (1922)**: класичний профіль із абсолютно пласким нижнім контуром за 30% хорди. Забезпечує високу підіймальну силу та технологічну простоту складання крила на рівному стапелі.
- **Eppler (E387) та Wortmann FX**: профілі для високоефективних планерів, розраховані на плавне наростання тиску та мінімізацію відривних зон.
- **Selig / Donovan (SD7003, S1223)**: профілі для низьких чисел Рейнольдса з вираженою увігнутістю задньої частини черева (англ. *aft-camber / undercamber*), що забезпечують високий `C_l` без зриву потоку.
- **Drela AG (AG35, AG04)**: ультратонкі профілі професора Марка Дрели з контрольованим градієнтом тиску для легких БПЛА та планерів.
- **Суперкритичні профілі Віткомба (англ. *Whitcomb supercritical airfoils*)**: профілі з майже пласкою верхньою поверхнею та сильно вигнутою задньою частиною, розроблені для затримки виникнення хвильового кризового стрибка ущільнення на навколозвукових швидкостях польоту (`M = 0.75–0.85`).

## Механізм створення сил: інтеграл тиску та циркуляція

Аеродинамічні сили, що діють на профіль, є результатом інтегрування двох фізичних полів по замкненому контуру: нормального статичного тиску `p(s)` та дотичного напруження в'язкого тертя `τ_w(s)`.

Статичний тиск у кожній точці поверхні характеризується безрозмірним коефіцієнтом тиску `C_p`:

```
C_p = (p - p_∞) / q_∞ = (p - p_∞) / (½ · ρ · v_∞²)
```

Для нестисливого нев'язкого потоку за законом Бернуллі зв'язок між локальною швидкістю `v` на поверхні та тиском набуває вигляду:

```
C_p = 1 - (v / v_∞)²
```

Звідси випливають фундаментальні властивості розподілу тиску:
1. У точці повного гальмування потоку (англ. *stagnation point*), де потік набігає на носок профілю і швидкість падає до нуля (`v = 0`), коефіцієнт тиску досягає свого абсолютного максимуму: `C_p = +1.0`.
2. Там, де потік рухається повільніше за набігаючий (`v < v_∞`, зазвичай на нижній поверхні під додатним кутом атаки), тиск підвищений: `0 < C_p < 1.0`.
3. Там, де потік прискорюється над опуклою спинкою профілю (`v > v_∞`), статичний тиск падає нижче атмосферного: `C_p < 0`. Біля передньої кромки на кутах атаки 6–10° локальна швидкість може перевищувати швидкість польоту у 1.5–2.2 рази, утворюючи глибокий **пік розрідження** (англ. *suction peak*) зі значеннями `C_p` від `-2.0` до `-5.0`.

![Розподіл коефіцієнта тиску C_p навколо профілю: пік розрідження на верхній поверхні, зона надлишкового тиску на нижній поверхні, точка гальмування та площа інтеграла підіймальної сили C_l.](/root/sci/ph-mechanics/profil-kryla/img/cp-distribution.svg)
*Розподіл коефіцієнта тиску вздовж хорди (вісь -C_p спрямована вгору). Різниця тисків між черевом і спинкою інтегрується в підіймальну силу C_l.*

Безрозмірний коефіцієнт підіймальної сили `C_l` є прямою різницею інтегралів тиску по нижній та верхній поверхнях:

```
C_l = ∫₀¹ [ C_{p,l}(x/c) - C_{p,u}(x/c) ] d(x/c)
```

Майже 70–85% сумарної підіймальної сили створюється саме розрідженням на верхній поверхні («всмоктуванням» спинки), і лише 15–30% — надлишковим тиском знизу.

### Теорема Жуковського-Кутта та умова гладкого сходу

Виникнення несиметрії швидкостей між верхньою та нижньою поверхнями описується теоремою Жуковського-Кутта (статус — усталено). Якщо навколо профілю існує сумарна циркуляція швидкості `Γ = ∮ v · dl`, підіймальна сила на одиницю розмаху дорівнює:

```
L' = ρ · v_∞ · Γ
```

Циркуляція `Γ` виникає завдяки молекулярній в'язкості на гострій задній кромці. За нульової циркуляції потік з нижньої поверхні мусив би огинати нескінченно тонке вістря задньої кромки знизу вгору з нескінченною швидкістю та нескінченним градієнтом тиску. Реальне повітря не витримує такого розвороту й зривається з кромки, скидаючи у кільватер початковий вихор (англ. *starting vortex*). За законом збереження циркуляції Кельвіна навколо самого профілю залишається рівна за величиною і протилежна за знаком циркуляція `+Γ`.

Процес самостабілізується, коли встановлюється **умова Кутти**: потік плавно сходить з гострої задньої кромки одночасно з верхньої та нижньої поверхонь зі скінченною однаковою швидкістю.

Строге математичне виведення циркуляції та інтегралів тиску за методом розкладу в ряд Фур'є наведено у вставці [Теорія тонкого профілю та інтеграл Жуковського](root:ph-mechanics/profil-kryla/math-thin-airfoil.md).

### Аеродинамічний фокус та центр тиску

Лінія дії сумарної аеродинамічної сили перетинає хорду в точці, що зветься **центром тиску** (англ. *Center of Pressure*, `x_{cp}`). Поздовжній момент відносно передньої кромки дорівнює `M'_{LE} = -L' · x_{cp}`.

Зі зміною кута атаки `α` величина `C_l` змінюється, а разом із нею переміщується і центр тиску. Для усунення цієї незручності в динаміці польоту використовують поняття **аеродинамічного фокусу** (англ. *aerodynamic center*, `x_{ac}`).

Аеродинамічний фокус — це точка на хорді профілю, відносно якої аеродинамічний поздовжній момент залишається постійним при зміні кута атаки в робочому безвідривному діапазоні:

```
dC_m / dC_l = 0  (відносно точки x_ac)
```

Для дозвукового нестисливого потоку за теорією тонкого профілю аеродинамічний фокус розташований точно на чверті хорди:

```
x_ac = 0.25 · c
```

Поздовжній момент на фокусі `C_{m,ac} = C_{m,c/4}` залежить виключно від кривини середньої лінії `y_c(x)` і не залежить від кута атаки:
- Для симетричного профілю: `C_{m,c/4} = 0`.
- Для стандартного позитивно вигнутого несучого профілю: `C_{m,c/4} < 0` (постійний пікіруючий момент, що намагається опустити носок літака).
- Для S-подібних самобалансованих профілів (з відігнутою вгору задньою кромкою, що застосовуються на літаючих крилах без хвоста): `C_{m,c/4} ≥ 0`.

Положення центру тиску зв'язане з фокусом співвідношенням:

```
x_{cp} / c = 0.25 - C_{m,c/4} / C_l
```

Оскільки для несучого профілю `C_{m,c/4}` є від'ємною константою, при зменшенні підіймальної сили (`C_l → 0`) центр тиску стрімко зміщується назад вздовж хорди до нескінченності.

## Примежовий шар та фізика відриву потоку

Реальне повітря має молекулярну в'язкість `μ`. Через взаємодію молекул газу з поверхнею крила виконується умова прилипання (англ. *no-slip condition*): швидкість газу безпосередньо на твердій стінці дорівнює нулю (`u(0) = 0`).

Увесь градієнт швидкості від `0` до швидкості зовнішнього потоку `U_e(x)` локалізований у тонкому пристінному шарі — **примежовому шарі** (нім. *Grenzschicht*, Людвіг Прандтль, 1904).

![Розвиток примежового шару на спинці профілю: ламінарна ділянка при сприятливому градієнті тиску, ламінарний відрив, утворення відривної бульбашки (LSB) з переходом у турбулентний стан та подальше приєднання до стінки.](/root/sci/ph-mechanics/profil-kryla/img/boundary-layer-separation.svg)
*Розвиток в'язкого шару вздовж спинки профілю: від гладкого ламінарного плину через точку відриву до турбулентного перемішування та приєднання.*

Товщина примежового шару `δ(x)` зростає від носка до хвоста. Його стан визначається знаком поздовжнього градієнта статичного тиску `dp/dx`:

1. **Сприятливий (конфузорний) градієнт тиску (`dp/dx < 0`)**: ділянка від передньої кромки до піка розрідження. Тиск падає вперед за потоком, потік прискорюється. Градієнт тиску проштовхує рідину вперед, пригнічуючи гідродинамічні збурення. Тут примежовий шар залишається **ламінарним** (лат. *lamina* — пластинка, тонкий шар): шари повітря ковзають паралельно, поверхневе тертя мінімальне.
2. **Несприятливий (дифузорний) градієнт тиску (`dp/dx > 0`)**: ділянка від піка розрідження до задньої кромки. Тиск зростає у напрямку руху, зовнішній потік гальмується. Пристінні шари рідини, які вже втратили частину кінетичної енергії на в'язке тертя, змушені рухатися проти наростаючого тиску.

Швидкість біля самої стінки сповільнюється швидше, ніж у ядрі потоку. Коли кінетична енергія пристінних частинок вичерпується, профіль швидкості вигинається так, що похідна швидкості на стінці падає до нуля:

```
(∂u / ∂y)|_{y=0} = 0
```

Ця координата є **точкою відриву** (англ. *separation point*). За нею тиск проштовхує повітря у зворотному напрямку (`(∂u/∂y)|_{w} < 0`), потік відривається від поверхні, а лінії струму відтискаються вглиб потоку, утворюючи застійну зону зворотних вихорів.

### Ламінарний та турбулентний стани

Турбулентний (лат. *turbulentus* — невпорядкований, бурхливий) примежовий шар характеризується хаотичним пульсаційним перемішуванням частинок між шарами. Завдяки пульсаціям `u'v'` високошвидкісні струмені з ядра потоку постійно викидаються у пристінну зону, насичуючи її імпульсом.

Профіль швидкості турбулентного шару є значно більш «наповненим» (степеневий закон `u/U ≈ (y/δ)^{1/7}` проти параболічного ламінарного профілю Блазіуса). Тому:
- **Тертя на стінці `τ_w = μ·(∂u/∂y)|_w` у турбулентному шарі у 3–5 разів вище**, ніж у ламінарному (вищий опір тертя `C_{f}`).
- **Стійкість турбулентного шару до несприятливого градієнта тиску `dp/dx > 0` у рази вища**: турбулентний шар здатен долати значно сильніше гальмування тиском без відриву від стінки.

### Сценарії зриву потоку (Stall)

При перевищенні критичного кута атаки `α_{crit}` (зазвичай 12–18°) розвивається глобальний відрив потоку зі спинки, що зветься звалюванням (англ. *stall*). Залежно від відносної товщини та радіуса носка виділяють три типи зриву:

1. **Зрив із задньої кромки (Trailing-Edge Stall)**: характерний для товстих профілів (`t/c > 14%`, наприклад NACA 4418, Clark Y 15%). Точка відриву турбулентного шару зароджується на задній кромці й зі зростанням кута атаки плавно просувається вперед до носка. Крива `C_l(α)` має округлий плавний купол, літак втрачає підіймальну силу поступово, зберігаючи поперечну керованість.
2. **Зрив із передньої кромки (Leading-Edge Stall)**: характерний для профілів середньої товщини (`9% ≤ t/c ≤ 13%`, наприклад NACA 0012, NACA 2412). На гострому радіусі носка формується надглибокий пік розрідження. Ламінарний шар зривається відразу біля кромки, утворюючи коротку відривну бульбашку, яка на `α_{crit}` раптово «вибухає» (англ. *bubble bursting*), зриваючи потік з усієї верхньої поверхні. Крива `C_l(α)` зазнає катастрофічного стрибкоподібного падіння на 40–60%, що супроводжується різким пікіруючим кидком моменту.
3. **Тонкопрофільний зрив (Thin-Airfoil Stall)**: характерний для тонких і гострих профілів (`t/c < 8%`). Потік відривається від носка вже при малих кутах (`α ≈ 3–5°`), утворюючи довгу замкнену відривну зону, що поступово зростає вздовж хорди до задньої кромки. Зростання `C_l` припиняється плавно, але максимальний коефіцієнт `C_{l,max}` залишається низьким (`0.8–1.0`).

## Аеродинамічні поляри та вплив числа Рейнольдса

Загальні аеродинамічні властивості профілю зображуються у вигляді безрозмірних полярних кривих:
- Залежності коефіцієнта підіймальної сили від кута атаки `C_l(α)`.
- Залежності коефіцієнта профільного опору від кута атаки `C_d(α)`.
- Поляри Лілієнталя `C_l(C_d)` — кривої співвідношення підіймальної сили та опору.

![Аеродинамічні характеристики профілю: крива підіймальної сили C_l(α) та поляра Лілієнталя C_l(C_d) при високих (Re = 1 000 000) та низьких (Re = 100 000) числах Рейнольдса з демонстрацією деградації підіймальної сили та зростання опору.](/root/sci/ph-mechanics/profil-kryla/img/polar-reynolds-effect.svg)
*Вплив числа Рейнольдса на характеристики профілю: при Re = 100 000 через ламінарні відривні бульбашки спостерігається втрата максимального Cl і зростання мінімального Cd.*

Число Рейнольдса хорди є головним критерієм динамічної подібності в'язкого потоку:

```
Re = (ρ · v_∞ · c) / μ = (v_∞ · c) / ν
```

де `ν = μ / ρ` — кінематична в'язкість повітря (`ν ≈ 1.5·10⁻⁵` м²/с за нормальних умов).

### Специфіка низьких чисел Рейнольдса (БПЛА та легка авіація)

У макроавіації (пасажирські та військові літаки) хорда крила становить 1.5–6 метрів при швидкостях 70–250 м/с, що дає `Re = 5·10⁶ – 40·10⁶`. У цьому режимі інерційні сили повністю домінують над в'язкістю: ламінарно-турбулентний перехід відбувається дуже близько до носка, турбулентний шар тонкий і стабільний, аеродинамічна якість досягає `K_{max} = (C_l / C_d)_{max} ≈ 80–130`.

У безпілотній авіації (розвідувальні крила, FPV-дрони літакового типу, баражуючі боєприпаси) з хордою `c = 0.15–0.35` м і швидкостями `v = 15–35` м/с польоти проходять у зоні низьких чисел Рейнольдса:

```
Re = (20 м/с · 0.20 м) / (1.5·10⁻⁵ м²/с) ≈ 266 000
```

Для мікродронів та ручних планерів число Рейнольдса падає до `Re = 50 000 – 150 000`. У цьому діапазоні виникають специфічні фізичні явища:

1. **Ламінарна відривна бульбашка (Laminar Separation Bubble, LSB)**:
   Ламінарний примежовий шар, пройшовши пік розрідження, стикається з градієнтом `dp/dx > 0` і відривається від поверхні, оскільки слабкі сили інерції не здатні проштовхнути його вперед. У відірваному вільному зсувному шарі над стінкою різко зростають нестійкі коливання (хвилі Толміна-Шліхтінга). Відірваний шар турбулізується прямо в повітрі, і вже турбулентний вихровий потік, інтенсивно підсмоктуючи повітря згори, **приєднується назад до поверхні** (англ. *reattachment*).
   Між точкою ламінарного відриву та точкою турбулентного приєднання утворюється замкнена застійна порожнина низького тиску — ламінарна відривна бульбашка.
2. **Аеродинамічна деградація**:
   - Наявність бульбашки спотворює ефективну геометрію профілю, потовщуючи витіснення потоку. Профільний опір `C_d` зростає у 2–4 рази (від `0.008` до `0.025–0.040`).
   - На кривій `C_l(α)` виникає нелінійний перегин або «поличка» дефіциту підіймальної сили.
   - Виникає **аеродинамічний гістерезис**: характеристики при збільшенні кута атаки не збігаються з характеристиками при його зменшенні, оскільки стан бульбашки залежить від попередньої історії обтікання.
3. **Методи подолання низькорейнольдсової кризи**:
   - Використання спеціальних профілів із плавним «м'яким» градієнтом відновлення тиску (профілі Selig SD7003, Eppler E387, Drela AG35), де бульбашка має малі розміри.
   - **Турбулізація потоку (Turbulators)**: встановлення механічних збурювачів (зубчастої стрічки zig-zag tape товщиною 0.3–0.5 мм або вихрових генераторів) на спинці крила на 20–35% хорди. Турбулізатор штучно переводить ламінарний шар у турбулентний ДО точки відриву, повністю запобігаючи утворенню відривної бульбашки та зменшуючи загальний опір крила на 20–30%.

## Чисельне моделювання: метод дискретних вихорів

Для розрахунку безв'язкісного обтікання довільного профілю застосовується панельний метод (англ. *Panel Method*), який замінює суцільний контур профілю системою з `N` дискретних прямолінійних панелей.

![Дискретизація профілю на N панелей з контрольними точками колокації, одиничними векторами нормалей, невідомими інтенсивностями вихрового шару γ_i та умовою Кутти на задній кромці.](/root/sci/ph-mechanics/profil-kryla/img/panel-method-discretization.svg)
*Дискретизація контуру профілю методом панелей: у кожній контрольній точці вимагається непротікання нормалі v · n = 0, а на задній кромці накладається рівність циркуляцій.*

У центрі кожної панелі (контрольній точці колокації `(x_{c,i}, y_{c,i})`) формується гранична умова непротікання:

```
∑_{j=1}^N A_{ij} · γ_j = -(v_∞ · n_i)
```

де `A_{ij}` — матриця геометричного впливу, що обчислює нормальну швидкість, індуковану одиничною вихровою панеллю `j` у контрольній точці панелі `i`.

Для замикання системи рівнянь останнє рівняння замінюється дискретною умовою Кутти:

```
γ_1 + γ_N = 0
```

Отримана система лінійних алгебраїчних рівнянь розв'язується методом Гаусса з вибором головного елемента, після чого обчислюються поверхневі швидкості `v_{t,i}`, коефіцієнти тиску `C_{p,i}` та сумарні аеродинамічні сили `C_l`, `C_{m,c/4}`.

Нижче наведено базовий фрагмент геометричної параметризації та формування системи рівнянь на мовах C та C++:

:::tabs
```c
#include <math.h>

typedef struct {
    double x, y;
} Vec2;

typedef struct {
    Vec2 p1, p2;     /* Кінці панелі */
    Vec2 cp;         /* Точка колокації */
    Vec2 normal;     /* Вектор нормалі */
    Vec2 tangent;    /* Вектор дотичної */
    double length;   /* Довжина відрізка */
} AirfoilPanel;

/* Обчислення швидкості, індукованої панеллю одиничної циркуляції */
void compute_induced_velocity(const AirfoilPanel *panel, double x, double y, double *u, double *v) {
    double dx = x - panel->p1.x;
    double dy = y - panel->p1.y;
    double ct = panel->tangent.x;
    double st = panel->tangent.y;

    double x_loc = dx * ct + dy * st;
    double y_loc = -dx * st + dy * ct;

    if (fabs(y_loc) < 1e-9 && x_loc >= 0.0 && x_loc <= panel->length) {
        *u = 0.0;
        *v = 0.0;
        return;
    }

    double r1_sq = x_loc * x_loc + y_loc * y_loc;
    double r2_sq = (x_loc - panel->length) * (x_loc - panel->length) + y_loc * y_loc;
    double th1 = atan2(y_loc, x_loc);
    double th2 = atan2(y_loc, x_loc - panel->length);

    double u_loc = -(1.0 / (2.0 * 3.141592653589793)) * (th2 - th1);
    double v_loc = (1.0 / (4.0 * 3.141592653589793)) * log(r2_sq / (r1_sq + 1e-15));

    *u = u_loc * ct - v_loc * st;
    *v = u_loc * st + v_loc * ct;
}
```
```cpp
#include <cmath>
#include <numbers>
#include <utility>

struct Vec2 {
    double x{0.0};
    double y{0.0};
};

struct AirfoilPanel {
    Vec2 p1;
    Vec2 p2;
    Vec2 cp;
    Vec2 normal;
    Vec2 tangent;
    double length{0.0};
};

// Обчислення швидкості, індукованої панеллю одиничної циркуляції
[[nodiscard]] std::pair<double, double> compute_induced_velocity(
    const AirfoilPanel& panel, double x, double y) noexcept {
    const double dx = x - panel.p1.x;
    const double dy = y - panel.p1.y;
    const double ct = panel.tangent.x;
    const double st = panel.tangent.y;

    const double x_loc = dx * ct + dy * st;
    const double y_loc = -dx * st + dy * ct;

    if (std::abs(y_loc) < 1e-9 && x_loc >= 0.0 && x_loc <= panel.length) {
        return {0.0, 0.0};
    }

    const double r1_sq = x_loc * x_loc + y_loc * y_loc;
    const double r2_sq = (x_loc - panel.length) * (x_loc - panel.length) + y_loc * y_loc;
    const double th1 = std::atan2(y_loc, x_loc);
    const double th2 = std::atan2(y_loc, x_loc - panel.length);

    const double u_loc = -(1.0 / (2.0 * std::numbers::pi)) * (th2 - th1);
    const double v_loc = (1.0 / (4.0 * std::numbers::pi)) * std::log(r2_sq / (r1_sq + 1e-15));

    return {u_loc * ct - v_loc * st, u_loc * st + v_loc * ct};
}
```

> 🔧 **Навіщо це.** У реальному проектуванні крила розрахунок профілю є першим і головним кроком. Інженер обирає профіль не «за гарною формою», а під компроміс трьох головних обмежень:
> 1. **Несуча здатність на малих швидкостях**: максимальний `C_{l,max}` задає швидкість звалювання `v_{stall} = √( (2·m·g) / (ρ · S · C_{l,max}) )`. Для зльоту й посадки без важкої механізації обирають профілі з кривиною 3–4% (NACA 4412, Clark Y).
> 2. **Мінімальний опір на крейсерському режимі**: для швидкісного польоту обирають тонкі профілі (8–10%) з малою кривиною (NACA 0009, NACA 64-108), де коефіцієнт опору `C_{d,min} ≈ 0.005–0.007`.
> 3. **Будівельна висота для силового набору**: товщина `t_{max}` повинна вмістити силовий лонжерон крила та акумуляторні відсіки без надмірного зростання маси конструкції. У корені крила зазвичай ставлять товсті профілі (14–16%), плавно переходячи до тонких (10–12%) на законцівках.
