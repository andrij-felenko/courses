# 🧮 Математичне виведення рівнянь пружного контакту Герца

Ця математична вставка розгортає повне виведення рівнянь Герца з теорії потенціалу Буссінеска, інтегрування півкульового тиску та виведення зв'язку між силою, радіусом контакту й зближенням тіл.

## Геометрія непогоджених поверхонь та зведена кривина

Розглянемо два суцільних пружних тіла 1 і 2, які торкаються у початковій точці до прикладення зовнішнього стискального навантаження. Приймемо правовинтову декартову систему координат із початком у точці первинного непорушеного дотику. Вісь `z` спрямуємо всередину першого тіла вздовж спільної внутрішньої нормалі до поверхонь. Дотична площина `(x, y)` проходит через точку контакту перпендикулярно до осі `z`.

Поверхні обох тіл у безпосередньому сусідстві з точкою дотику можна з високою точністю розкласти у степеневі ряди Тейлора. Нехтуючи членами вищих порядків (третього та вище), отримуємо параболічну апроксимацію поверхонь второго порядку:

```
z₁ = x² / (2·R₁x) + y² / (2·R₁y)    [профіль поверхні першого тіла]
z₂ = x² / (2·R₂x) + y² / (2·R₂y)    [профіль поверхні другого тіла]
```

Тут `R₁x`, `R₁y` означають головні радіуси кривини першого тіла у взаємно перпендикулярних перетинах `x` та `y`, а `R₂x`, `R₂y` — відповідні головні радіуси кривини другого тіла.

Сумарний початковий зазор між поверхнями обох тіл у недеформованому стані вздовж нормалі `z` визначається як сума ординат `h(x, y) = z₁ + z₂`:

```
h(x, y) = z₁ + z₂
= x² / 2 · (1/R₁x + 1/R₂x) + y² / 2 · (1/R₁y + 1/R₂y)    [сумарний початковий зазор]
```

Для сферичних тіл або сфери з площиною кривина є строго однаковою за всіма азимутальними напрямками (`R₁x = R₁y = R₁`, `R₂x = R₂y = R₂`). У цьому випадку геометрія є повністю осесиметричною, а початковий зазор залежить виключно від полярного радіуса `r = √(x² + y²)`:

```
h(r) = r² / (2·R*)                  [початковий зазор для двох сфер]
1 / R* = 1 / R₁ + 1 / R₂            [означення зведеного радіуса кривини R*]
```

Зведений радіус кривини `R*` є ефективним геометричним параметром, який зводить задачу про контакт двох викривлених поверхонь до еквівалентної задачі про контакт однієї сфери радіуса `R*` з ідеально пласкою жорсткою поверхнею. Якщо одне з тіл є пласким (наприклад, сфера на плоскій плиті), його радіус кривини `R₂ = ∞`, звідки `1/R₂ = 0`, і тоді зведений радіус дорівнює радіусу сфери `R* = R₁`. Для випадку контакту кульки з увігнутою чашкою радіус увігнутої поверхні береться зі знаком мінус (`-R₂`).

## Умова деформації та геометрія пружного дотику

Під дією зовнішньої стискальної сили `F` віддалені точки обох тіл наближаються одна до одної у напрямку осі `z` на загальну величину `δ`, яку називають глибиною втискання або депресією контакту. У зоні контакту поверхні обох тіл сплющуються і зміщуються еластично у вертикальному напрямку. Позначимо нормальне пружне зміщення поверхні першого тіла через `u_z1(x, y)`, а другого тіла — через `u_z2(x, y)`.

У будь-якій точці всередині поверхні контакту `r ≤ a` деформовані поверхні обох тіл повинні щільно прилягати одна до одної без утворення зазорів чи взаємного проникнення. Це дає фундаментальне геометричне рівняння Герца:

```
u_z1(r) + u_z2(r) = δ - h(r)        [умова контактного зміщення]
u_z1(r) + u_z2(r) = δ - r² / (2·R*) [умова пружного дотику для r ≤ a]
```

Фізичний зміст цього рівняння полягає у наступному: сума вертикальних пружних зміщень поверхонь у кожній точці плями контакту має точно компенсувати початковий параболічний зазор `r² / (2·R*)` і забезпечити підсумкове зближення тіл `δ`. Поза межами контакту (`r > a`) сумарне зміщення поверхонь є меншим за `δ - r² / (2·R*)`, а нормальний тиск дорівнює нулю.

## Потенціал Буссінеска та зведений модуль пружності

Для знаходження зміщень поверхонь скористаємося класичним розв'язком Жозефа Буссінеска для пружного напівпростору під дією розподіленого нормального тиску `p(x', y')`. Згідно з теорією пружності, нормальне зміщення `u_z(x, y)` поверхні напівпростору від дії тиску на елементарний майданчик `dx' dy'` визначається як:

```
u_z1(r) = (1 - ν₁²) / (π·E₁) · ∫∫ (p(x', y') / S) dx' dy' [зміщення поверхні першого тіла]
u_z2(r) = (1 - ν₂²) / (π·E₂) · ∫∫ (p(x', y') / S) dx' dy' [зміщення поверхні другого тіла]
S = √((x - x')² + (y - y')²)                              [відстань між точками]
```

Тут `E₁`, `E₂` означають модулі Юнга відповідних матеріалів, а `ν₁`, `ν₂` — їхні коефіцієнти Пуассона. Додавши ці два вирази для сумарного зміщення `u_z1 + u_z2`, винесемо спільний подвійний інтеграл:

```
u_z1(r) + u_z2(r)
= [ (1 - ν₁²)/E₁ + (1 - ν₂²)/E₂ ] · (1/π) · ∫∫ (p(x', y') / S) dx' dy'  [сумарне зміщення]
= (1 / E*) · (1/π) · ∫∫ (p(x', y') / S) dx' dy'                         [через зведений модуль]
```

де визначено **зведений модуль пружності** `E*`:

```
1 / E* = (1 - ν₁²) / E₁ + (1 - ν₂²) / E₂    [означення зведеного модуля пружності E*]
```

Зведений модуль пружності `E*` враховує пружні деформаційні властивості обох контактуючих матеріалів. Якщо обидва тіла виготовлені з одного матеріалу (наприклад, сталь по сталі з `E₁ = E₂ = E` та `ν₁ = ν₂ = ν`), вираз спрощується до `E* = E / (2 · (1 - ν²))`.

Тепер наша математична задача зводиться до розв'язання фундаментального інтегрального рівняння Герца щодо невідомого розподілу тиску `p(x', y')` по круговій області `r ≤ a`:

```
(1 / E*) · (1/π) · ∫∫ (p(x', y') / S) dx' dy' = δ - r² / (2·R*)   [інтегральне рівняння Герца]
```

## Доказ півкульового розподілу тиску

Генріх Герц висунув гіпотезу, що розподіл нормального тиску `p(r)` по круговому диску `r ≤ a` описується півкульовою функцією з максимумом `p₀` у центрі контакту (`r = 0`):

```
p(r) = p₀ · √(1 - r² / a²)          [гіпотеза півкульового тиску]
```

Доведемо, що цей розподіл тиску строго задовольняє інтегральному рівнянню Герца. В теорії Newtonian потенціалу відомо, що потенціал поверхневої маси, розподіленої по круговому диску радіуса `a` за півкульовим законом `√(1 - r'² / a²)`, обчислюється аналітично. Подвійний інтеграл по диску дає вираз:

```
∫∫ (√(1 - r'² / a²) / S) dx' dy' = (π²·a / 4) · (1 - r² / (2·a²))   [значення потенціалу диска]
```

Підставимо це значення потенціалу у ліву частину нашого рівняння для сумарних зміщень:

```
u_z1(r) + u_z2(r)
= (1 / E*) · (1/π) · p₀ · [ (π²·a / 4) · (1 - r² / (2·a²)) ]        [підстановка потенціалу]
= (π · p₀ · a / (4 · E*)) · (1 - r² / (2·a²))                        [спрощення виразу]
= (π · p₀ · a / (4 · E*)) - (π · p₀ / (8 · a · E*)) · r²            [розкриття дужок]
```

Порівняємо отриманий квадратичний вираз із геометричною умовою Герца `δ - r² / (2·R*)`:

```
(π · p₀ · a / (4 · E*)) - (π · p₀ / (8 · a · E*)) · r²  ≡  δ - r² / (2·R*)    [тотожність]
```

Ця тотожність тотожно справджується для всіх точок плями контакту `r ≤ a` тоді й лише тоді, коли коефіцієнти при однаковому степені `r` (вільний член та коефіцієнт при `r²`) у лівій і правій частинах є строго рівними!

Прирівняємо коефіцієнти при `r²`:

```
π · p₀ / (8 · a · E*) = 1 / (2 · R*)   [рівність коефіцієнтів при r²]
p₀ = (4 · a · E*) / (π · R*)            [зв'язок пікового тиску p₀ з радіусом a]
```

Прирівняємо вільні члени:

```
δ = π · p₀ · a / (4 · E*)               [визначення зближення δ через p₀]
```

Підставимо знайдений вираз для `p₀` у формулу для зближення `δ`:

```
δ = (π · a / (4 · E*)) · [ (4 · a · E*) / (π · R*) ]   [підстановка p₀ у δ]
δ = a² / R*                             [зв'язок глибини втискання δ з радіусом a]
```

Це дивовижно простий результат: глибина втискання `δ` пов'язана з радіусом контакту `a` та зведеним радіусом кривини `R*` чисто геометричним співвідношенням `δ = a² / R*`!

## Інтегрування повної сили стискання

Повна стискальна сила `F` є інтегралом від нормального тиску `p(r)` по всій площі кругової плями контакту радіуса `a`. Перейдемо до полярної системи координат `(r, θ)`:

```
F = ∫₀²π dθ ∫₀ᵃ p(r) · r dr             [інтеграл повної сили]
F = 2·π · p₀ · ∫₀ᵃ √(1 - r²/a²) · r dr   [перехід до полярних координат]
```

Зробимо заміну змінної `u = 1 - r²/a²`, звідки `du = -2·r/a² dr`, або `r dr = - (a² / 2) du`:

```
∫₀ᵃ √(1 - r²/a²) · r dr
= (a² / 2) · ∫₀¹ √u du                   [заміна змінної в інтегралі]
= (a² / 2) · [ (2/3) · u^(3/2) ]₀¹       [первісна функція]
= a² / 3                                 [значення визначеного інтеграла]
```

Підставимо отримане значення інтеграла назад у формулу сили `F`:

```
F = 2·π · p₀ · (a² / 3)                  [інтегрування повної сили]
F = (2/3) · π · a² · p₀                  [зв'язок сили F, радіуса a та пікового тиску p₀]
```

Оскільки площа кругової плями контакту дорівнює `A = π · a²`, середній тиск по площі контакту `p_сер = F / A` дорівнює `(2/3) · p₀`. Звідси випливає, що максимальний контактний тиск у центрі `p₀` становить півтора середніх тиски:

```
p₀ = (3/2) · (F / (π · a²)) = 1.5 · p_сер  [зв'язок пікового та середнього тиску]
```

## Виведення підсумкових рівнянь Герца

Тепер ми маємо систему з трьох основних алгебраїчних співвідношень:
1. `p₀ = (4 · a · E*) / (π · R*)`
2. `F = (2/3) · π · a² · p₀`
3. `δ = a² / R*`

Підставимо перший вираз для `p₀` у формулу сили `F`:

```
F = (2/3) · π · a² · [ (4 · a · E*) / (π · R*) ]   [підстановка p₀ у вираз сили F]
F = (8 / 3) · (a³ · E* / R*)                      [вираз сили F через радіус a]
```

Виразимо куб радіуса плями контакту `a³` через силу `F`:

```
a³ = (3 · F · R*) / (4 · E*)                      [куб радіуса контакту]
a = [ (3 · F · R*) / (4 · E*) ]^(1/3)             [підсумкова формула радіуса плями Герца]
```

Підставимо вираз для `a` у формулу для глибини втискання `δ = a² / R*`:

```
δ = [ (3 · F · R*) / (4 · E*) ]^(2/3) / R*        [підстановка a у δ]
δ = [ (9 · F²) / (16 · R* · (E*)²) ]^(1/3)        [підсумкова формула глибини втискання δ]
```

Виразимо піковий тиск `p₀` безпосередньо через силу `F`, зведений радіус `R*` та модуль `E*`:

```
p₀ = (3 · F) / (2 · π · a²)                       [початкова формула p₀]
a² = [ (3 · F · R*) / (4 · E*) ]^(2/3)            [квадрат радіуса a]
p₀ = [ (6 · F · (E*)²) / (π³ · (R*)²) ]^(1/3)     [підсумкова формула пікового тиску p₀]
```

## Внутрішній стан напружень та глибина пікового зсуву

На центральній осі `z` (при `r = 0`) під дією півкульового тиску Герца тензор напружень має діагональний вигляд у циліндричних координатах. Усі три головні напруження `σ_z`, `σ_r = σ_θ` є стискальними (від'ємними). Інтегрування точкових розв'язків Буссінеска дає наступні залежності від глибини `z`:

```
σ_z(z) = - p₀ / (1 + (z/a)²)                     [осьове стискальне напруження]
σ_x(z) = σ_y(z) = - p₀ · [ (1 + ν) · (1 - (z/a)·arctan(a/z)) - 1 / (2·(1 + (z/a)²)) ] [радіальне напруження]
```

Максимальне зсувне напруження за критерієм Треска дорівнює піврізниці найбільшого та найменшого головних напружень:

```
τ_макс(z) = 0.5 · | σ_z(z) - σ_x(z) |            [максимальне зсувне напруження]
```

Дослідимо функцію `τ_макс(z)` на екстремум для коефіцієнта Пуассона `ν = 0.3` (сталь):
- На поверхні (`z = 0`): `σ_z = -p₀`, `σ_x = σ_y = -0.8·p₀`, звідси `τ_макс(0) = 0.1·p₀`.
- Зі збільшенням глибини `z` осьове стиснення `σ_z` спадає повільніше, ніж радіальне стиснення `σ_x`.
- На глибині `z = 0.481·a`: `σ_z ≈ -0.80·p₀`, `σ_x ≈ -0.18·p₀`.

Обчислимо пікове значення зсувного напруження:

```
τ_макс(0.481·a) = 0.5 · | -0.80·p₀ - (-0.18·p₀) | = 0.310 · p₀   [підповерхневий пік зсувного напруження]
```

Саме цей математичний результат доводить, що максимальні руйнівні зсувні напруження при герцівському контакті діють не на поверхні, а у товщі матеріалу на глибині близько половини радіуса плями контакту `z ≈ 0.48 a`.

## Математичні рівняння для лінійного (циліндричного) контакту

Коли притискаються два паралельні циліндри довжиною `L` з радіусами `R₁` та `R₂`, контактний майданчик перетворюється на прямокутник шириною `2b` та довжиною `L`. Розподіл тиску стає двовимірним еліптичним циліндром:

```
p(x) = p₀ · √(1 - x² / b²)          [розподіл тиску для лінійного контакту]
```

Інтегрування сили стискання `F` по прямокутнику дає:

```
F = ∫₋b⁺b p(x) · L dx = (π / 2) · b · L · p₀     [сила лінійного контакту]
```

Зв'язок півширини контакту `b` та пікового тиску `p₀` зі зведеними параметрами визначається рівняннями:

```
b = [ (4 · F · R*) / (π · L · E*) ]^(1/2)        [півширина лінійного контакту]
p₀ = [ (F · E*) / (π · L · R*) ]^(1/2)           [піковий тиск лінійного контакту]
```

У лінійному контакті піковий тиск `p₀` та півширина `b` зростають пропорційно квадратному кореню з сили `F^(1/2)`, на відміну від точкового контакту, де залежність є кубічною `F^(1/3)`.

## Детальний розкладок математичного аналізу еліптичного контакту

У загальному випадку, коли два викривлених тіла мають довільні радіуси кривини в обох головних перетинах `(R₁x, R₁y)` та `(R₂x, R₂y)`, пляма контакту є еліпсом із піввіссю `a` вздовж осі `x` та піввіссю `b` вздовж осі `y`.

Нехай `A_geom` та `B_geom` означають геометричні коефіцієнти зазору:

```
A_geom + B_geom = 0.5 · (1/R₁x + 1/R₁y + 1/R₂x + 1/R₂y) = 1 / (2·R_еф*)  [сумарна зведена кривина]
```

Герц показав, що ексцентриситет еліпса контакту `e = √(1 - b²/a²)` визначається нелінійним трансцендентним рівнянням, що містить повні еліптичні інтеграли першого `K(e)` та другого `E(e)` роду:

```
(B_geom - A_geom) / (A_geom + B_geom) = [ (1/e² - 1)·K(e) - E(e)/e² ] / [ E(e)/e² - K(e) ] [рівняння ексцентриситету]
```

Після обчислення ексцентриситету `e` через еліптичні інтеграли, півосі еліпса контакту `a` та `b` виражаються через розрахункові коефіцієнти `m_a` та `m_b`:

```
a = m_a · [ (3 · F · R_еф*) / (4 · E*) ]^(1/3)   [велика піввісь еліпса]
b = m_b · [ (3 · F · R_еф*) / (4 · E*) ]^(1/3)   [мала піввісь еліпса]
```

Піковий тиск у центрі еліптичного контакту задовольняє напівеліпсоїдному розподілу `p(x, y) = p₀ · √(1 - x²/a² - y²/b²)`:

```
p₀ = 1.5 · (F / (π · a · b))                    [піковий тиск еліптичного контакту]
```

Цей результат завершує повний математичний апарат теорії класичного пружного контакту Герца для тіл довільної геометричної конфігурації.
