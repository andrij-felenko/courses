# 🧮 Обмежена кругова задача трьох тіл та потенціал Якобі

Обмежена кругова задача трьох тіл (Circular Restricted Three-Body Problem, CRTBP) є найважливішою математичною моделлю небесної механіки. Ця вставка містить суворий математичний вивід рівнянь руху третього тіла в обертовій системі координат, виведення інтеграла Якобі, аналітичне визначення п'яти точок Лагранжа та виведення критерію стійкості Гашо–Раута для трикутних точок рівноваги.

### Безрозмірна система одиниць

Розглянемо два масивних тіла `M₁` та `M₂` (так звані первинні тіла), які обертаються по колових орбітах навколо спільного центра мас `O` під дією взаємного тяжіння. Нехай `m₁` та `m₂` — їхні маси, причому `m₁ ≥ m₂`. Третє тіло маси `m₃` рухається в гравітаційному полі `M₁` та `M₂`, проте його маса `m₃` настільки мала, що її впливом на рух `M₁` та `M₂` можна знехтувати (`m₃ → 0`).

Для спрощення рівнянь введемо канонічну безрозмірну систему одиниць:
1. Одиниця маси: `M_total = m₁ + m₂ = 1`.
2. Одиниця відстані: відстань між первинними тілами `R = 1`.
3. Гравітаційна стала: `G = 1`.

У цій системі одиниць період обертання `M₁` та `M₂` дорівнює `2π`, а кутова швидкість обертання орбіти `ω = 1`.
Позначимо безрозмірний масовий параметр через `μ`:

```
μ = m₂ / (m₁ + m₂) = m₂
```

Оскільки `m₁ + m₂ = 1`, маси тіл дорівнюють відповідно:
```
m₁ = 1 − μ
m₂ = μ
```

Завдяки цьому параметр `μ` лежить у діапазоні `0 < μ ≤ 0.5`. Для системи Земля–Місяць `μ ≈ 0.01215`, для системи Сонце–Земля `μ ≈ 3.003 × 10⁻⁶`, для системи Сонце–Юпітер `μ ≈ 0.000953`.

### Обертова (синодична) система координат

Перейдемо в декартову систему координат `(x, y, z)`, яка обертається разом із тілами `M₁` та `M₂` навколо центра мас `O` з кутовою швидкістю `ω = 1` вздовж осі `z`.
Початок координат лежить у центрі мас `O`. Вісь `x` завжди проходить через `M₁` та `M₂`, вісь `y` лежить у площині їхнього обертання, а вісь `z` перпендикулярна до площини орбіти.

Координати первинних тіл на осі `x` є постійними:
```
x₁ = −μ        (координата тіла M₁)
x₂ = 1 − μ    (координата тіла M₂)
y₁ = y₂ = z₁ = z₂ = 0
```

Відстані від третього тіла з координатами `(x, y, z)` до `M₁` та `M₂` дорівнюють відповідно:
```
r₁ = √[(x + μ)² + y² + z²]
r₂ = √[(x − 1 + μ)² + y² + z²]
```

### Рівняння руху в обертовій системі

Рівняння руху третього тіла в неінерціальній системі координат, що обертається з кутовою швидкістю `ω = (0, 0, 1)`, містять реальну гравітаційну силу, а також переносні сили інерції: відцентрову силу та силу Коріоліса.

Векторне рівняння руху має вигляд:
```
d²r/dt² + 2·(ω × dr/dt) + ω × (ω × r) = −∇V_grav
```

де `∇V_grav` — градієнт гравітаційного потенціалу первинних тіл:
```
V_grav = −(1 − μ)/r₁ − μ/r₂
```

Обчислимо переносні сили в компонентах:
```
2·(ω × dr/dt) = (−2·dy/dt, 2·dx/dt, 0)         [сила Коріоліса]
ω × (ω × r) = (−x, −y, 0)                      [відцентрове прискорення]
```

Введемо скалярну функцію **ефективного потенціалу Якобі** `Ω(x, y, z)`:

```
Ω(x, y, z) = (1/2)·(x² + y²) + (1 − μ)/r₁ + μ/r₂
```

Перший доданок `(1/2)·(x² + y²)` відповідає потенціалу відцентрової сили, а другий та третій — гравітаційним потенціалам двох тіл.

Тоді скалярні рівняння руху третього тіла набувають дивовижно симетричної та елегантної форми:

```
d²x/dt² − 2·(dy/dt) = ∂Ω/∂x      [рівняння вздовж осі x]
d²y/dt² + 2·(dx/dt) = ∂Ω/∂y      [рівняння вздовж осі y]
d²z/dt² = ∂Ω/∂z                  [рівняння вздовж осі z]
```

Зауважимо: члени `−2·(dy/dt)` та `+2·(dx/dt)` описують силу Коріоліса. Вона завжди перпендикулярна до вектора швидкості `v = (dx/dt, dy/dt, dz/dt)`, а отже **не виконує роботи** над рухом тіла.

### Виведення інтеграла Якобі

Помножимо скалярні рівняння руху відповідно на `dx/dt`, `dy/dt` та `dz/dt` і додамо їх:

```
(dx/dt)·(d²x/dt²) + (dy/dt)·(d²y/dt²) + (dz/dt)·(d²z/dt²)
− 2·(dx/dt)·(dy/dt) + 2·(dy/dt)·(dx/dt)
= (dx/dt)·(∂Ω/∂x) + (dy/dt)·(∂Ω/∂y) + (dz/dt)·(∂Ω/∂z)
```

Члени Коріоліса повністю скорочуються:
```
−2·(dx/dt)·(dy/dt) + 2·(dy/dt)·(dx/dt) = 0      [сила Коріоліса не працює]
```

Ліва частина є повною похідною від квадрата відносної швидкості `v²`:
```
(1/2)·d(v²)/dt = (1/2)·d/dt [(dx/dt)² + (dy/dt)² + (dz/dt)²]
```

Права частина є повною похідною від ефективного потенціалу `Ω(x, y, z)` по часу:
```
(dx/dt)·(∂Ω/∂x) + (dy/dt)·(∂Ω/∂y) + (dz/dt)·(∂Ω/∂z) = dΩ/dt
```

Отже, отримуємо рівняння:
```
(1/2)·d(v²)/dt = dΩ/dt
```

Інтегруючи по часу `t`, маємо:
```
v² = 2·Ω(x, y, z) − C
```

де `C` — константа інтегрування, відома як **інтеграл Якобі** (або константа Якобі):

```
C = 2·Ω(x, y, z) − v²
= (x² + y²) + 2·(1 − μ)/r₁ + 2·μ/r₂ − [(dx/dt)² + (dy/dt)² + (dz/dt)²]
```

Інтеграл Якобі є єдиним відомим точним першим інтегралом руху у обмеженій круговій задачі трьох тіл.

### Поверхні нульової швидкості (області Гілла)

Оскільки квадрат відносної швидкості `v² = (dx/dt)² + (dy/dt)² + (dz/dt)²` за визначенням є невід'ємною величиною (`v² ≥ 0`), з інтеграла Якобі випливає фундаментальна нерівність для можливих координат третього тіла:

```
2·Ω(x, y, z) ≥ C
```

Межа між дозволеними та забороненими областями руху задається умовою `v = 0`, тобто рівнянням:

```
2·Ω(x, y, z) = C
```

Ці поверхні називаються **поверхнями нульової швидкості** (або межами Гілла). Третє тіло з даною константою Якобі `C` фізично не може перетнути цю поверхню і вийти у заборонену область, де `2·Ω(x, y, z) < C`.

### Виведення координат точок Лагранжа

Точки Лагранжа — це точки стаціонарності (рівноваги) в обертовій системі координат, де відносна швидкість та прискорення третього тіла дорівнюють нулю (`v = 0`, `d²r/dt² = 0`).

З рівнянь руху випливає, що в точках рівноваги градієнт ефективного потенціалу має дорівнювати нулю:

```
∂Ω/∂x = 0
∂Ω/∂y = 0
∂Ω/∂z = 0
```

Обчислимо частинні похідні `Ω(x, y, z)`:

```
∂Ω/∂x = x − (1 − μ)·(x + μ)/r₁³ − μ·(x − 1 + μ)/r₂³ = 0
∂Ω/∂y = y · [1 − (1 − μ)/r₁³ − μ/r₂³] = 0
∂Ω/∂z = −z · [(1 − μ)/r₁³ + μ/r₂³] = 0
```

З третього рівняння одразу випливає, що `z = 0`: усі точки рівноваги лежать строго у площині обертання первинних тіл `(x, y)`.

Розглянемо два випадки для другого рівняння `∂Ω/∂y = 0`:

#### 1. Трикутні точки рівноваги L₄ та L₅ (`y ≠ 0`)

Якщо `y ≠ 0`, то з другого рівняння випливає condition:
```
1 − (1 − μ)/r₁³ − μ/r₂³ = 0
```

Підставивши це в перше рівняння `∂Ω/∂x = 0`, після спрощень отримуємо умову:
```
r₁ = 1
r₂ = 1
```

Відстані від третього тіла до обох первинних тіл дорівнюють одиниці — тобто відстані між `M₁` та `M₂`! Це означає, що тіла `M₁`, `M₂` та точка рівноваги утворюють **рівносторонній трикутник** зі стороною `1`.

Розв'язуючи систему рівнянь `r₁ = 1` та `r₂ = 1` у координатах `(x, y)`:
```
(x + μ)² + y² = 1
(x − 1 + μ)² + y² = 1
```

Віднімаючи одне рівняння від іншого, маємо:
```
2·x + 2·μ − 1 = 0   =>   x = 1/2 − μ
```

Підставляючи `x` у перше рівняння, дістаємо `y`:
```
y² = 1 − (1/2)² = 3/4   =>   y = ±√3 / 2
```

Отже, exact аналітичні координати трикутних точок Лагранжа:
```
L₄:  (x = 1/2 − μ,  y = +√3 / 2,  z = 0)
L₅:  (x = 1/2 − μ,  y = −√3 / 2,  z = 0)
```

#### 2. Колінеарні точки рівноваги L₁, L₂, L₃ (`y = 0`)

Якщо `y = 0`, всі три точки лежать на осі `x`. Рівняння `∂Ω/∂x = 0` перетворюється на алгебраїчне рівняння 5-го ступеня (квінтику Ейлера):

```
x − (1 − μ)·(x + μ)/|x + μ|³ − μ·(x − 1 + μ)/|x − 1 + μ|³ = 0
```

Це рівняння має три реальних корені:
- **Point L₁**: лежить між тілами `M₁` та `M₂` (`−μ < x < 1 − μ`).
- **Point L₂**: лежить праворуч від малого тіла `M₂` (`x > 1 − μ`).
- **Point L₃**: лежить ліворуч від великого тіла `M₁` (`x < −μ`).

Аналітичне наближення для відстані `γ` від тіла `M₂` до точки `L₂` при малуватому `μ << 1` (наприклад, для системи Сонце–Земля чи Земля–Місяць) дається формулою Гілла:

```
γ ≈ (μ / 3)^(1/3)
```

Для системи Сонце–Земля (`μ ≈ 3 × 10⁻⁶`) відстань до `L₂` становить `γ ≈ (10⁻⁶)^(1/3) ≈ 0.01` а.о., тобто приблизно 1.5 мільйона кілометрів від Землі.

### Стійкість точок Лагранжа: критерій Гашо–Раута

Аналіз стійкості визначається шляхом лінеаризації рівнянь руху в околі точок рівноваги. Нехай `(x₀, y₀)` — координати точки Лагранжа, а `(ξ, η)` — малі відхилення: `x = x₀ + ξ`, `y = y₀ + η`.

Лінеаризована система набуває вигляду:
```
d²ξ/dt² − 2·(dη/dt) = Ω_xx·ξ + Ω_xy·η
d²η/dt² + 2·(dξ/dt) = Ω_xy·ξ + Ω_yy·η
```

де `Ω_xx`, `Ω_xy`, `Ω_yy` — другі частинні похідні потенціалу `Ω`, обчислені у точці рівноваги.

Шукаючи розв'язки у вигляді `ξ = A·e^(λ·t)`, `η = B·e^(λ·t)`, дістаємо характеристичне рівняння для власних чисел `λ`:

```
λ⁴ + (4 − Ω_xx − Ω_yy)·λ² + (Ω_xx·Ω_yy − Ω_xy²) = 0
```

#### Нестійкість колінеарних точок L₁, L₂, L₃
Для колінеарних точок `Ω_xy = 0`, `Ω_xx > 0`, а `Ω_yy < 0`. Вільний член характеристичного рівняння `Ω_xx·Ω_yy < 0` від'ємний, що гарантує існування одного дійсного додатного власного числа `λ₁ > 0` та одного від'ємного `λ₂ = −λ₁`.
Наявність `λ > 0` означає **експоненціальну нестійкість** (сідлова точка). Траєкторії в околі `L₁`, `L₂`, `L₃` експоненціально віддаляються за часовою шкалою `τ_instab ~ 1/λ`.

#### Стійкість трикутних точок L₄ та L₅
Для точок `L₄` та `L₅` обчислення других похідних дає:
```
Ω_xx = 3/4
Ω_yy = 9/4
Ω_xy = ∓ (3·√3 / 4) · (1 − 2·μ)
```

Характеристичне рівняння спрощується до:
```
λ⁴ + λ² + (27/4)·μ·(1 − μ) = 0
```

Це квадратне рівняння відносно `Λ = λ²`:
```
Λ² + Λ + (27/4)·μ·(1 − μ) = 0
```

Щоб точка була орбітально стійкою, власні числа `λ` повинні бути **чисто уявними** (`λ = ±i·ω_freq`), а це вимагає, щоб обидва корені `Λ₁` та `Λ₂` були дійсними та від'ємними.

Дискримінант `D` квадратного рівняння має бути невід'ємним:
```
D = 1 − 4 · (27/4)·μ·(1 − μ) = 1 − 27·μ·(1 − μ) ≥ 0
```

Розв'язуємо квадратну нерівність `27·μ² − 27·μ + 1 ≥ 0`:

```
μ_crit = [27 − √(27² − 108)] / 54 = [1 − √(1 − 4/27)] / 2 = [1 − √(23/27)] / 2
```

Чисельне значення граничного масового параметра **критерію Гашо–Раута**:

```
μ_crit ≈ 0.03852089...   (приблизно 1 / 25.96)
```

Якщо масовий параметр менший за критичний (`μ < μ_crit ≈ 0.0385`), то сила Коріоліса виявляється достатньо сильною, щоб закручувати малі відхилення тіла в замкнені еліптичні коливання навколо точки `L₄` чи `L₅`, забезпечуючи **орбітальну стійкість**. Для систем Сонце–Юпітер (`μ ≈ 0.00095`) та Сонце–Земля (`μ ≈ 3 × 10⁻⁶`) ця умова виконується із величезним запасом, що пояснює вікову стійкість скупчень троянських астероїдів.
