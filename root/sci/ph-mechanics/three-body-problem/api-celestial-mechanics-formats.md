# 📋 Формати та параметри орбітальних елементів трьох тіл

Ця вставка є структурним довідником для інженерів балістики, розробників небесної механіки та астродинаміків. Вона містить канонічні безрозмірні параметри обмеженої кругової задачі трьох тіл (CRTBP) для ключових систем Сонячної системи, точні специфікації векторів стану, матриці перетворення систем координат, описи форматів даних SPICE SPK та TLE (Two-Line Element), а також комплексні параметри тривимірних околових гало-орбіт та вимоги до палива для їхнього утримання.

### Канонічні параметри CRTBP для систем Сонячної системи

У розрахунках обмеженої кругової задачі трьох тіл застосовують канонічну нормалізовану систему координат, у якій сума мас двох основних тіл `m₁ + m₂ = 1`, відстань між ними `R = 1`, а кутова швидкість обертання `ω = 1`. Перехід від астрономічних СІ-одиниць до канонічних здійснюється за допомогою масового параметра `μ = m₂ / (m₁ + m₂)`.

У таблиці нижче зібрано безрозмірні характеристики, координати точок Лагранжа та значення критичних констант Якобі для найбільш уживаних систем двох первинних тіл Сонячної системи.

| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **Сонце – Юпітер** | `0.000953875` | `778 570 000` | `0.93237` | `1.06763` | `−1.00040` | `3.03964` | `3.03906` |
| **Сонце – Земля** | `3.00348 × 10⁻⁶` | `149 597 870` | `0.99003` | `1.01007` | `−1.00000` | `3.00090` | `3.00089` |

| **Сонце – Марс** | `3.22715 × 10⁻⁷` | `227 939 200` | `0.99506` | `1.00494` | `−1.00000` | `3.00021` | `3.00021` |

### Матриця перетворення між інерціальною та синодичною системами

Для переведення координат космічного апарата з інерціальної системи координат (ICRF / J2000) `R_iner = [X, Y, Z]^T` у синодичну обертову систему координат `r_syn = [x, y, z]^T` застосовують ортогональну матрицю обертання `M(t)` на кут `θ(t) = ω·t`:

```
[ x ]   [  cos(ω·t)   sin(ω·t)   0 ]   [ X − X_cm ]
[ y ] = [ −sin(ω·t)   cos(ω·t)   0 ] · [ Y − Y_cm ]
[ z ]   [      0          0      1 ]   [ Z − Z_cm ]
```

де `(X_cm, Y_cm, Z_cm)` — координати барицентра системи двох первинних тіл у інерціальному просторі.

Для векторів швидкостей зв'язок враховує переносне обертання системи з кутовою швидкістю `ω = (0, 0, ω)`:
```
v_syn = M(t) · (V_iner − V_cm) − ω × r_syn
```

Зворотне перетворення здійснюється за допомогою транспонованої матриці `M(t)^T`:
```
R_iner = X_cm + M(t)^T · r_syn
V_iner = V_cm + M(t)^T · (v_syn + ω × r_syn)
```

### Специфікація вектора стану космічного апарата

У балістичних розрахунках та програмах польотного контролю стан третього тіла (космічного апарата) у кожен момент часу задається 6-компонентним вектором стану `S(t)` у декартовій інерціальній або обертовій синодичній системі координат.

```
S(t) = [ x, y, z, v_x, v_y, v_z ]^T
```

Нижче наведено повний опис та одиниці виміру компонент вектора стану:

| Поле | Позначення | Одиниці виміру (СІ) | Канонічні одиниці CRTBP | Опис |
| :--- | :--- | :--- | :--- | :--- |
| `x` | Позиція X | метри (`м`) або `км` | безрозмірна (`r / R`) | Просторова координата вздовж осі X |
| `y` | Позиція Y | метри (`м`) або `км` | безрозмірна (`r / R`) | Просторова координата вздовж осі Y |
| `z` | Позиція Z | метри (`м`) або `км` | безрозмірна (`r / R`) | Просторова координата вздовж осі Z |
| `v_x` | Швидкість X | `м/с` або `км/с` | безрозмірна (`v / v_orb`) | Компонента швидкості вздовж осі X |
| `v_y` | Швидкість Y | `м/с` або `км/с` | безрозмірна (`v / v_orb`) | Компонента швидкості вздовж осі Y |
| `v_z` | Швидкість Z | `м/с` або `км/с` | безрозмірна (`v / v_orb`) | Компонента швидкості вздовж осі Z |
| `epoch` | Епоха | TDB / UTC секунди | безрозмірний час `t·ω` | Часова мітка вимірювання (Julian Date) |

При обчисленні вектора стану у безрозмірних канонічних одиницях коефіцієнт масштабування швидкості `v_scale` визначається як середня орбітальна швидкість малого первинного тіла:
```
v_scale = √(G·(m₁ + m₂) / R)
```

Для системи Земля–Місяць `v_scale ≈ 1.0245 км/с`, для системи Сонце–Земля `v_scale ≈ 29.7848 км/с`.

### Параметри дворядкового елемента TLE (Two-Line Element Set)

Для супутників на високих навколоземних та місячних орбітах, де гравітаційні збурення від Місяця та Сонця створюють суттєвий тритіловий ефект, застосовують стандартний формат TLE з математичною моделлю SGP4/SDP4 (Deep Space Perturbations). Модель SDP4 враховує місячно-сонячні гравітаційні резонанси та прецесію орбіти через гармоніки `J₂, J₃, J₄`.

Нижче наведено приклад структури рядків TLE для космічного апарата у точці `L₂` системи Земля–Місяць:

```
1 99999U 23001A   23015.50000000  .00000000  00000-0  00000-0 0  9991
2 99999  00.1200 125.4000 0012000  45.0000 315.0000  1.00270000    12
```

Детальна розшифровка ключових полів даного елемента TLE:
1. `23015.50000000`: Епоха вимірювання (рік 2023, день 15.5 у форматі UTC).
2. `00.1200`: Кут нахилу орбіти до екватора (Inclination, у градусах).
3. `125.4000`: Довгота висхідного вузла (Right Ascension of Ascending Node, RAAN, у градусах).
4. `0012000`: Ексцентриситет орбіти (з доданою десятковою крапкою `0.0012000`).
5. `45.0000`: Аргумент перицентру (Argument of Perigee, у градусах).
6. `315.0000`: Середня аномалія орбіти (Mean Anomaly, у градусах).
7. `1.00270000`: Середній рух апарата (Mean Motion, кількість повних обертів за 24 години).

У моделі SDP4 для розрахунку трьохтілових збурень від Місяця та Сонця використовується інтегрування secular- та resonant-членів:
```
dΩ/dt = −(3/2)·J₂·(R_E / a)² · cos(i) + n_moon_secular + n_sun_secular
```
Це дозволяє моделювати еволюцію орбіти апарата на часових інтервалах до кількох місяців.

### Формат ефемерид NASA SPICE SPK (Segment Type 2, 3, 14 та 21)

Для високоточного збереження та розрахунку траєкторій космічних апаратів у тритілових системах (наприклад, James Webb Space Telescope чи Artemis Lunar Gateway) Лабораторія реактивного руху NASA (JPL) застосовує бінарні SPK-файли тулкіту SPICE. У цих файлах траєкторії апроксимуються поліномами Чебишова високих порядків.

При роботі з інтерфейсом SPICE використовуються унікальні цілочисельні ідентифікатори NAIF ID для точок рівноваги, центрів мас та космічних місій:

| NAIF ID Code | Об'єкт / Точка рівноваги | Опис фрейму координат |
| :--- | :--- | :--- |
| `0` | Сонячносистемний барицентр (SSB) | Базовий інерціальний фрейм ICRF / J2000 |
| `10` | Сонце (Sun Barycenter) | Геліоцентрична система |
| `399` | Земля (Earth Center) | Геоцентрична система координат |
| `301` | Місяць (Moon Center) | Селеноцентрична система координат |
| `399001` | Точка Лагранжа Earth-Moon L₁ | Обертовий барицентричний фрейм |
| `399002` | Точка Лагранжа Earth-Moon L₂ | Обертовий барицентричний фрейм |
| `100001` | Точка Лагранжа Sun-Earth L₁ | Обертовий фрейм Сонце–Земля |
| `100002` | Точка Лагранжа Sun-Earth L₂ | Обертовий фрейм Сонце–Земля |
| `-170` | Космічний телескоп James Webb (JWST) | Сонце–Земля L₂ гало-орбіта |
| `-28` | Сонячна обсерваторія SOHO | Сонце–Земля L₁ гало-орбіта |
| `-78` | Обсерваторія DSCOVR | Сонце–Земля L₁ гало-орбіта |
| `-123456` | Месячна станція Artemis Gateway | Земля–Місяць NRHO орбіта |

Типи сегментів SPK для тритілових орбіт:
- **Type 2**: Поліноми Чебишова лише для координат `(X, Y, Z)` при фіксованому кроці часу.
- **Type 3**: Поліноми Чебишова для координат та швидкостей `(X, Y, Z, V_x, V_y, V_z)`.
- **Type 14**: Неоднорідні сплайни Чебишова для орбіт із частими корекціями.
- **Type 21**: Модифікований метод різницевих підсумків розширеного поля для високоексцентричних гало-орбіт.

### Параметризований опис околових гало-орбіт (Halo Orbits)

Гало-орбіти являють собою замкнені або квазіперіодичні 3D-траєкторії навколо колінеарних точок рівноваги `L₁` та `L₂`. У першому аналітичному наближенні за методом Лінстедта–Пуанкаре 3D-координати гало-орбіти описуються тригонометричними рядами з амплітудами `(A_x, A_y, A_z)` та фазовими зсувами.

Сучасна аналітична форма представлення траєкторії гало-орбіти:

```
x(t) = x_L − A_x · cos(k1·t + φ)
y(t) = y_L + A_y · sin(k1·t + φ)
z(t) = z_L + A_z · cos(k2·t + ψ)
```

Детальний опис параметрів та коефіцієнтів гало-орбіти:
- `x_L, y_L, z_L`: Канонічні координати відповідної точки Лагранжа (`L₁` чи `L₂`).
- `A_x, A_y, A_z`: Просторові амплітуди коливань апарата в кілометрах. Зауважимо, що амплітуди `A_x` та `A_y` жорстко пов'язані геометрією потенціалу через коефіцієнт `k3`: `A_y = k3 · A_x`.
- `k1, k2`: Власні безрозмірні частоти плоскої (in-plane) та позаплощинної (out-of-plane) компонент коливань, визначені з лінеаризованої системи рівнянь CRTBP.
- `φ, ψ`: Початкові фазові кути. Співвідношення фаз `ψ = φ + n·π/2` розрізняє дві симетричні родини гало-орбіт: північну (Northern Halo) та південну (Southern Halo).
- `C_Jacobi`: Константа Якобі конкретної гало-орбіти, яка задає енергетичний рівень та необхідний запас імпульсної швидкості `Δv` для утримання апарата на утримувальній траєкторії (station-keeping maneuvers).

### Типові характеристики гало-орбіт у реальних космічних місіях

У балістичній практиці параметри гало-орбіт підбираються так, щоб мінімізувати річні витрати палива на утримання орбіти (Station-Keeping Delta-V).

| Космічний апарат / Місія | Точка рівноваги | Амплітуда `A_x` (км) | Амплітуда `A_y` (км) | Амплітуда `A_z` (км) | Період орбіти (дні) | Річні витрати `Δv` (м/с) |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **JWST (James Webb)** | Сонце–Земля L₂ | `250 000` | `670 000` | `400 000` | `~178` днів | `~2.5 м/с / рік` |
| **SOHO** | Сонце–Земля L₁ | `200 000` | `650 000` | `120 000` | `~177` днів | `~1.8 м/с / рік` |
| **DSCOVR** | Сонце–Земля L₁ | `240 000` | `550 000` | `150 000` | `~180` днів | `~2.0 м/с / рік` |
| **Artemis Gateway (NRHO)** | Земля–Місяць L₂ | `3 000` | `70 000` | `15 000` | `~6.5` днів | `~1.5 м/с / рік` |

Особливістю орбіт майбутньої місячної станції Artemis Gateway є використання майже прямолінійної гало-орбіти (Near-Rectilinear Halo Orbit, NRHO). Ця орбіта є стійким відгалуженням родини L₂ гало-орбіт, де перицентр проходить лише за 3 000 км від поверхні Місяця, а апоцентр віддаляється на 70 000 км. Завдяки цій геометрії зв'язок із Землею зберігається постійно без затінення Місяцем.

Вимоги до алгоритмів утримання орбіти (Station-Keeping Algorithms):
1. **Метод Floquet / Монодромії**: Визначення стійкого `W^s` та нестійкого `W^u` напрямків за допомогою матриці монодромії `M_monodromy = Φ(T, 0)`.
2. **Алгоритм маневрування**: Проведення мікроімпільсу `Δv` кожні 14–21 день для обнулення неухильно зростаючої компоненти вздовж нестійкого напрямку `W^u`.
