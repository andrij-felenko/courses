# Математичне виведення формули Гутіна для акустики обертової лопаті

Коли лопать повітряного гвинта обертається в повітрі, кожна точка її поверхні діє на навколишнє середовище зі змінною в часі силою. Для нерухомого спостерігача в дальній зоні ця сила виглядає як періодична послідовність імпульсів, що повторюються з частотою проходження лопатей. Мета цього виведення — показати крок за кроком, як із хвильового рівняння для рухомих джерел виникає класична формула радянського фізика-акустика Льва Гутіна (1936 рік), чому в ній з'являються циліндричні функції Бесселя першого роду та як число лопатей і кут спостереження керують випромінюваною акустичною енергією.

### 1. Неоднорідне хвильове рівняння та запізнілий потенціал

Поширення акустичних збурень у однорідному нерухомому середовищі з густиною `ρ₀` та швидкістю звуку `c₀` описується неоднорідним хвильовим рівнянням для флуктуацій тиску `p(x, t)`:

```
(1/c₀²) · (∂²p / ∂t²) − ∇²p = −∇ · f(x, t) + ∂q(x, t) / ∂t
```

де:
- `f(x, t)` — вектор об'ємної густини зовнішніх сил, що діють на повітря з боку лопатей (дипольне джерело, Loading Noise);
- `q(x, t)` — швидкість уведення маси в одиницю об'єму через витіснення повітря тілом лопаті (монопольне джерело, Thickness Noise).

Розгляньмо дипольний внесок сил навантаження `f(x, t)`. Розв'язок хвильового рівняння у вільному тривимірному просторі визначається через функцію Гріна із запізнілим часом:

```
p(x, t) = (1 / 4π) · ∫ [ −∇ · f(y, τ) / |x − y| ] d³y
```

де час випромінювання `τ` пов'язаний із часом прийому `t` співвідношенням запізнення акустичного сигналу:

```
τ = t − |x − y| / c₀
```

У дальній зоні (хвильовій зоні), де відстань до спостерігача `r₀ = |x|` набагато перевищує геометричний радіус гвинта `R` (`r₀ ≫ R`) та довжину акустичної хвилі `λ` (`r₀ ≫ λ`), відстань до довільного елемента лопаті `y` можна розкласти в ряд:

```
|x − y| ≈ r₀ − (x · y) / r₀ = r₀ − y · e_r
```

де `e_r = x / r₀` — одиничний вектор у напрямку спостереження.

Тоді просторову диференціальну операцію дивергенції `∇ ·` у хвильовій зоні можна замінити на похідну за часом у напрямку випромінювання:

```
p(x, t) = − (1 / (4π · c₀ · r₀)) · (∂ / ∂t) ∫ [ f(y, τ) · e_r ] d³y
```

[заміна просторового градієнта на часову похідну в дальньому полі]

### 2. Обертова зосереджена сила на диску

Нехай гвинт має `B` однакових лопатей, рівномірно розташованих по колу через кутовий інтервал `2π / B`, які обертаються з постійною кутовою швидкістю `Ω = 2π · n` навколо осі `z`.

Введемо циліндричну систему координат `(r, φ, z)`, де вісь `z` збігається з віссю обертання гвинта та спрямована вздовж вектора тяги `T`. Спостерігач розташований у точці `(r₀, θ, 0)`, де `θ` — кут між віссю обертання `z` та променем на спостереження (полярний кут спрямованості).

Одиничний вектор напрямку на спостереження має координати:

```
e_r = (sin θ · cos φ_obs,  sin θ · sin φ_obs,  cos θ)
```

Покладемо без обмеження загальності `φ_obs = 0`, тоді:

```
e_r = (sin θ, 0, cos θ)
```

Для спрощення інтегрування Гутін замінив розподілені по лопаті аеродинамічні сили зосередженими силами, прикладеними на деякому ефективному радіусі `R_eff` (для типових пропелерів `R_eff ≈ 0.75...0.80 · R`):
1. Сила тяги `T`, спрямована вздовж осі `z` (протидіє повітрю силою `−T · e_z`).
2. Колова сила опору `F_y = Q / R_eff`, де `Q` — повний крутний момент, спрямована вздовж дотичної до кола обертання.

Для `k`-ї лопаті (`k = 0, 1, ..., B−1`) кутове положення в момент часу `τ` дорівнює:

```
φ_k(τ) = Ω · τ + 2π · k / B
```

Проєкція сили лопаті на напрямок спостереження `e_r` у момент випромінювання `τ` складається з осьової та коколової компонент:

```
f_k(τ) · e_r = −(T / B) · cos θ − (Q / (B · R_eff)) · sin θ · sin(φ_k(τ))
```

де знак «мінус» перед тягою відповідає силі реакції, прикладеній до повітряного середовища у напрямку `−z`.

### 3. Ряд Фур'є та перехід до гармонік BPF

Оскільки сили періодично обертаються, створюваний акустичний тиск `p(t)` є строго періодичною функцією з основним періодом проходження лопатей:

```
T_BPF = 2π / (B · Ω)
```

Розкладемо акустичний тиск у комплексний ряд Фур'є за гармоніками лопатевої частоти `f_m = m · B · n`:

```
p(t) = ∑ [ p_m · exp(i · m · B · Ω · t) ]    (сума по m від −∞ до +∞)
```

Комплексна амплітуда `m`-ї гармоніки `p_m` обчислюється як інтеграл за періодом обертання `T_rev = 2π / Ω`:

```
p_m = (1 / T_rev) · ∫ [ p(t) · exp(−i · m · B · Ω · t) ] dt    [інтегрування від 0 до T_rev]
```

Підставимо вираз для тиску через запізнілий час. Враховуючи, що на ефективному радіусі `R_eff` скалярний добуток `y · e_r = R_eff · sin θ · cos(φ_k(τ))`, співвідношення запізнення набуває вигляду:

```
t = τ + (r₀ / c₀) − (R_eff · sin θ / c₀) · cos(Ω · τ + 2π · k / B)
```

Диференціал часу прийому через час випромінювання:

```
dt = [ 1 + (Ω · R_eff · sin θ / c₀) · sin(Ω · τ + 2π · k / B) ] dτ
```

Підставивши похідну `∂/∂t` та перейшовши від інтегрування за часом прийому `t` до інтегрування за часом випромінювання `τ`, множник перетворення `dt/dτ` у знаменнику скорочується з якобіаном переходу (ефект Доплера інтегрується за повним періодом).

Для суми за всіма `B` лопатями фазові зсуви `exp(−i · m · B · (2π · k / B)) = exp(−i · 2π · m · k) = 1` дають підсилення амплітуди рівно в `B` разів:

```
p_m = − (i · m · B · Ω · exp(−i · m · B · Ω · r₀ / c₀) / (4π · c₀ · r₀)) · I_m
```

де інтеграл `I_m` має вигляд:

```
I_m = ∫ [ (−T · cos θ − (c₀ · Q / (Ω · R_eff²)) · (Ω · R_eff / c₀) · sin θ · sin φ) · exp(−i · (m · B · φ − m · B · (Ω · R_eff / c₀) · sin θ · cos φ)) ] dφ
```

[інтегрування по куту φ від 0 до 2π]

### 4. Інтегральне представлення функцій Бесселя

Введемо безрозмірні параметри:
- Колове число Маха на ефективному радіусі: `M_eff = Ω · R_eff / c₀ = M_tip · (R_eff / R)`;
- Аргумент Бесселя: `z_m = m · B · M_eff · sin θ`.

Згадаємо класичне інтегральне представлення циліндричної функції Бесселя першого роду порядку `n`:

```
J_n(z) = (1 / 2π) · ∫ [ exp(i · (z · sin ψ − n · ψ)) ] dψ    [від −π до π]
```

Використовуючи тригонометричні перетворення та властивості парності інтегралів:

```
(1 / 2π) · ∫ [ exp(−i · (n · φ − z · cos φ)) ] dφ = (−i)ⁿ · J_n(z)
```

Для першого доданка з тягою `T · cos θ`:

```
∫ [ −T · cos θ · exp(−i · (m · B · φ − z_m · cos φ)) ] dφ = −2π · T · cos θ · (−i)^(mB) · J_{mB}(z_m)
```

Для другого доданка з крутним моментом `Q`:
Використовуючи співвідношення `sin φ · exp(i · z · cos φ) = (1 / (i · z)) · (∂ / ∂φ) exp(i · z · cos φ)` та інтегруючи частинами:

```
∫ [ sin φ · exp(−i · (m · B · φ − z_m · cos φ)) ] dφ = 2π · (m · B / z_m) · (−i)^(mB) · J_{mB}(z_m)
```

Оскільки `m · B / z_m = 1 / (M_eff · sin θ)`, множник `sin θ` у чисельнику скорочується зі знаменником:

```
(Q / R_eff) · sin θ · (m · B / z_m) = Q / (R_eff · M_eff) = c₀ · Q / (Ω · R_eff²)
```

### 5. Підсумкова формула Гутіна

Об'єднуючи інтеграли для тяги та крутного моменту, дістаємо вираз для амплітуди звукового тиску `m`-ї гармоніки:

```
p_m = (m · B · Ω / (2 · 2^(1/2) · π · c₀ · r₀)) · [ −T · cos θ + c₀ · Q / (Ω · R_eff²) ] · J_{mB}(m · B · M_eff · sin θ)
```

[квадратичний середній (RMS) акустичний тиск m-ї гармоніки в дальній зоні]

Перевіримо розмірність формули:
- `[m · B · Ω]` = 1 / с = рад/с;
- `[c₀ · r₀]` = (м/с) · м = м² / с;
- `[T · cos θ]` = Н = кг · м / с²;
- `[c₀ · Q / (Ω · R_eff²)]` = (м/с · Н · м) / ((1/с) · м²) = Н;
- `[J_{mB}(...)]` — безрозмірна величина.

Розмірність результату:

```
[p_m] = (1 / с) / (м² / с) · Н = Н / м² = Па
```

Розмірність повністю відповідає одиницям тиску в системі SI.

### 6. Асимптотичний аналіз: чому дозвукові гармоніки згасають експоненційно

Фундаментальна властивість функції Бесселя `J_ν(z)` полягає в її поведінці при значеннях аргументу, менших за порядок (`z < ν`).

Для `m`-ї гармоніки порядок функції дорівнює `ν = m · B`, а аргумент становить `z = m · B · M_eff · sin θ`.
Оскільки `sin θ ≤ 1` та для дозвукових гвинтів дронів `M_eff < 1`, аргумент **завжди строго менший за порядок**:

```
z / ν = M_eff · sin θ < 1
```

Асимптотичний розклад Дебая для функцій Бесселя високого порядку при `z < ν` має вигляд:

```
J_ν(ν · sech α) ≈ exp(−ν · (α − tanh α)) / (2π · ν · tanh α)^(1/2)
```

де `sech α = z / ν = M_eff · sin θ`, звідки `α = arcosh(1 / (M_eff · sin θ)) > 0`.

Оскільки `α − tanh α > 0`, експоненційний показник є строго від'ємним:

```
J_{mB}(m · B · M_eff · sin θ) ∝ exp[ −m · B · ( α − tanh α ) ]
```

[експоненційне загасання амплітуди за числом лопатей B та номером гармоніки m]

Цей математичний результат дає два вирішальні фізичні висновки:
1. **Зростання номера гармоніки `m`:** Амплітуда спадає експоненційно зі зростанням `m`. Тому спектр тонального шуму гвинта визначається здебільшого першими двома-трьома гармоніками (1×BPF та 2×BPF), а вищі гармоніки швидко тонуть у широкосмуговому шумі.
2. **Збільшення числа лопатей `B`:** Якщо перейти з дволопатевого гвинта (`B = 2`) на чотирилопатевий (`B = 4`) за однакової тяги й колової швидкості, показник експоненти подвоюється. Це призводить до падіння амплітуди першої гармоніки BPF на 15–25 дБ.

### 7. Монопольний шум товщини (інтеграл Демінга)

Якщо врахувати член витіснення маси `q(x, t) = ρ₀ · v_n` у хвильовому рівнянні, розв'язок для монопольного джерела товщини (за теорією Демінга — Арнольда) дає квадратурний доданок акустичного тиску:

```
p_{m, thick} = − (ρ₀ · (m · B · Ω)² / (2 · 2^(1/2) · π · r₀)) · V_blade · J_{mB}(m · B · M_eff · sin θ)
```

де `V_blade` — повний об'єм лопаті.

Зіставимо залежність тиску від колової швидкості `U_tip = Ω · R`:
- Шум навантаження Гутіна: `p_{load} ∝ Ω · T · J_{mB} ∝ U_tip² · J_{mB}`;
- Шум товщини: `p_{thick} ∝ Ω² · V_blade · J_{mB} ∝ U_tip³ · J_{mB}`.

Звідси видно, що акустична потужність шуму товщини росте швидше (`W_{thick} ∝ M_tip⁴`), ніж шуму навантаження (`W_{load} ∝ M_tip²` для фіксованої сили або `M_tip⁶` з урахуванням аеродинамічного скейлінгу тяги). На типових дозвукових режимах дронів (`M_tip = 0.25...0.45`) дипольний шум навантаження за формулою Гутіна домінує над монопольним шумом товщини у 5–15 разів за амплітудою.
