# 🧮 Виведення числа Прандтля з рівнянь Нав'є — Стокса та енергії

У цьому математичному виведенні показано, як число Прандтля природним чином виникає під час знерозмірення повних рівнянь диференціального переносу руху та теплової енергії в суцільному середовищі. Ми простежимо шлях від рівнянь Нав'є — Стокса та збереження енергії до автомобільної подібності Блазіуса — Польгаузена і доведемо вирази для відношення товщин гідродинамічного й теплового примежових шарів та місцевого числа Нуссельта.

## 1. Початкова система рівнянь переносу та їхня фізична інтерпретація

Розглянемо стаціонарну двовимірну течію нестисливої в'язкої рідини з постійними фізичними властивостями (динамічна в'язкість `μ`, густина `ρ`, теплопровідність `k` та питома теплоємність `c_p` є сталими величинами) вздовж плоскої нагрітої пластини.

Повний математичний опис цього фізичного процесу складається з трьох фундаментальних законів збереження механіки суцільних середовищ:

1. **Рівняння неперервності (закон збереження маси):**

```
∂u/∂x + ∂v/∂y = 0
```

Це рівняння стверджує, що для нестисливої рідини об'єм, який втікає в елементарний контрольний об'єм, дорівнює об'єму, що витікає з нього.

2. **Рівняння Нав'є — Стокса для проекції швидкості `u` на вісь `x` (закон збереження імпульсу):**

```
u · (∂u/∂x) + v · (∂u/∂y) = - (1/ρ) · (∂p/∂x) + ν · (∂²u/∂x² + ∂²u/∂y²)
```

Ліва частина описує конвективне прискорення рідкої частинки (перенос імпульсу макроскопічним рухом потоку). Права частина містить силу градієнта тиску та молекулярну дифузію імпульсу, задану кінематичною в'язкістю `ν = μ / ρ`.

3. **Рівняння збереження енергії (перше начало термодинаміки для рухомого флюїду):**

```
u · (∂T/∂x) + v · (∂T/∂y) = α · (∂²T/∂x² + ∂²T/∂y²) + (μ / (ρ · c_p)) · Φ
```

де `α = k / (ρ · c_p)` — коефіцієнт температуропровідності (м²/с), а `Φ` — дисипативна функція Релея, яка описує перетворення кінетичної енергії течії в теплову за рахунок в'язкого тертя. Для помірних швидкостей течії (числа Маха `Ma < 0.3`) дисипативний розігрів є нехтувно малим (`Φ ≈ 0`), тому рівняння енергії стає абсолютно аналогічним рівнянню руху.

Змінні в цій системі:
- `u`, `v` — компоненти вектора швидкості вздовж осей `x` (уздовж пластини) та `y` (перпендикулярно до пластини);
- `p` — статичний тиск у потоці;
- `T` — локальна температура середовища;
- `ν = μ / ρ` — кінематична в'язкість (м²/с);
- `α = k / (ρ · c_p)` — температуропровідність (м²/с).

## 2. Аналіз порядків величин і спрощення Прандтля

Нехай `L` — характерна довжина пластини, `U` — швидкість набігаючого незбуреного потоку, `δ_v` — товщина гідродинамічного примежового шару, а `δ_t` — товщина теплового примежового шару. Для ламінарних течій при високих числах Рейнольдса шари є мікроскопічно тонкими проти довжини пластини:

```
δ_v ≪ L,    δ_t ≪ L
```

Оцінимо порядок величин похідних за координатами в межах примежового шару:

```
x ~ L,      y ~ δ_v  (або δ_t)
u ~ U,      v ~ U · (δ_v / L) ≪ U
```

Порівняємо другі похідні у правих частинах рівнянь руху та енергії:

```
∂²u / ∂x² ~ U / L²
∂²u / ∂y² ~ U / δ_v²
```

Оскільки `(U / L²) / (U / δ_v²) = (δ_v / L)² ≪ 1`, поздовжньою дифузією імпульсу та тепла `∂²u/∂x²` і `∂²T/∂x²` можна повністю знехтувати порівняно з поперечною дифузією `∂²u/∂y²` та `∂²T/∂y²`. Поздовжнє поширення тепла кондукцією є нехтувно малим порівняно з конвективним знесенням тепла потоком.

Для безградієнтного обтікання плоскої пластини зовнішній тиск у вільному потоці є постійним (`∂p/∂x = 0`). Тоді система спрощується до класичних **рівнянь Прандтля для ламінарного примежового шару**:

```
u · (∂u/∂x) + v · (∂u/∂y) = ν · (∂²u/∂y²)
u · (∂T/∂x) + v · (∂T/∂y) = α · (∂²T/∂y²)
```

Граничні умови на стінці (`y = 0`) та на зовнішній межі (`y → ∞`):

```
y = 0:    u = 0,   v = 0,   T = T_w  (константна температура стінки)
y → ∞:   u = U,   T = T_∞  (температура вільного потоку)
```

## 3. Масштабний аналіз і первинне виникнення числа Прандтля

Оцінимо порядок величин доданків у рівнянні руху. Ліва частина описує конвективний перенос імпульсу, а права — в'язкісну дифузію:

```
u · (∂u/∂x) ~ U² / L
ν · (∂²u/∂y²) ~ ν · U / δ_v²
```

Зрівнюючи за порядком величини конвективний і дифузійний доданки, отримуємо масштаб товщини гідродинамічного шару:

```
U² / L  ~  ν · U / δ_v²
δ_v²    ~  ν · L / U
δ_v / L ~  √(ν / (U · L)) = 1 / √Re_L
```

Тепер виконаємо аналогічне оцінювання для рівняння енергії, де ліва частина описує конвективне знесення тепла, а права — температуропровідну дифузію:

```
u · (∂T/∂x) ~ U · ΔT / L
α · (∂²T/∂y²) ~ α · ΔT / δ_t²
```

Зрівнюючи доданки енергетичного балансу:

```
U · ΔT / L  ~  α · ΔT / δ_t²
δ_t²        ~  α · L / U
δ_t / L     ~  √(α / (U · L)) = 1 / √(Re_L · (α / ν))
            =  1 / √(Re_L · Pr)
```

Поділивши масштаб товщини гідродинамічного шару `δ_v` на масштаб теплового шару `δ_t`, отримуємо первинне співвідношення:

```
δ_v / δ_t ~ √(ν / α) = √Pr
```

Цей масштабний розрахунок показує, що відношення товщин шарів прямо визначається квадратним коренем із числа Прандтля. Проте точний розрахунок ураховує викривлення профілю швидкості всередині шару (адже швидкість усередині шару є меншою за `U`), що замінює степінь `1/2` на степінь `1/3`. Доведемо це через автомодельні змінні Блазіуса — Польгаузена.

## 4. Перетворення Блазіуса — Польгаузена до звичайних диференціальних рівнянь

Уведемо автомодельну змінну Блазіуса `η` та функцію течії `ψ(x, y)`:

```
η = y · √(U / (ν · x))
ψ(x, y) = √(ν · x · U) · f(η)
```

Складові швидкості визначаються через похідні функції `f(η)` за змінною `η`:

```
u = ∂ψ/∂y = U · f'(η)
v = - ∂ψ/∂x = (1/2) · √(ν · U / x) · [η · f'(η) - f(η)]
```

Підстановка `u` та `v` у рівняння руху перетворює диференціальне рівняння в частинних похідних на звичайне диференціальне рівняння 3-го порядку для функції Блазіуса `f(η)`:

```
f''' + (1/2) · f · f'' = 0      [рівняння Блазіуса]
```

з граничними умовами: `f(0) = 0`, `f'(0) = 0`, `f'(∞) = 1`.

Тепер уведемо безрозмірну температуру `θ(η)`:

```
θ(η) = (T(x, y) - T_w) / (T_∞ - T_w)
```

Граничні умови для безрозмірної температури:

```
θ(0) = 0      (T = T_w на стінці)
θ(∞) = 1      (T = T_∞ далеко від стінки)
```

Обчислимо частинні похідні температури через безрозмірну функцію `θ(η)`:

```
∂T/∂x = (T_∞ - T_w) · θ'(η) · (∂η/∂x) = (T_∞ - T_w) · θ'(η) · (-1/2) · (η / x)
∂T/∂y = (T_∞ - T_w) · θ'(η) · (∂η/∂y) = (T_∞ - T_w) · θ'(η) · √(U / (ν · x))
∂²T/∂y² = (T_∞ - T_w) · θ''(η) · (U / (ν · x))
```

Підставивши вирази для `u`, `v` та похідних температури у рівняння енергії, маємо:

```
U·f' · (T_∞ - T_w)·θ'·(-1/2)·(η/x) + (1/2)·√(ν·U/x)·[η·f' - f] · (T_∞ - T_w)·θ'·√(U/(ν·x))
= α · (T_∞ - T_w) · θ'' · (U / (ν · x))
```

Після скорочення спільних множників `(T_∞ - T_w) · (U / x)` отримуємо:

```
- (1/2) · f' · η · θ' + (1/2) · η · f' · θ' - (1/2) · f · θ' = (α / ν) · θ''
```

Перші два доданки у лівій частині тотожно знищуються! Залишається:

```
- (1/2) · f · θ' = (1 / Pr) · θ''
```

Помноживши обидві частини на `Pr`, отримуємо класичне **рівняння Польгаузена**:

```
θ'' + (1/2) · Pr · f · θ' = 0      [рівняння Польгаузена]
```

Зверніть увагу: число Прандтля `Pr` входить у це рівняння як єдиний безрозмірний параметр перед множником `f(η) · θ'(η)`.

## 5. Точне аналітичне інтегрування температурного рівняння

Рівняння Польгаузена можна точно проінтегрувати у квадратурах. Поділимо рівняння на `θ'`:

```
θ'' / θ' = - (1/2) · Pr · f(η)
```

Проінтегруємо обидві частини за `η` від `0` до `η`:

```
ln(θ'(η) / θ'(0)) = - (1/2) · Pr · ∫₀ⁿ f(ζ) dζ
θ'(η) = θ'(0) · exp[- (1/2) · Pr · ∫₀ⁿ f(ζ) dζ]
```

Для знаходження невідомого похідного на стінці `θ'(0)` проінтегруємо вираз повторно від `0` до `∞`:

```
∫₀^∞ θ'(η) dη = θ(∞) - θ(0) = 1 - 0 = 1
1 = θ'(0) · ∫₀^∞ exp[- (1/2) · Pr · ∫₀ⁿ f(ζ) dζ] dη
```

Звідси отримуємо точний аналітичний вираз для температурного градієнта на стінці:

```
θ'(0) = 1 / { ∫₀^∞ exp[- (1/2) · Pr · ∫₀ⁿ f(ζ) dζ] dη }
```

## 6. Асимптотичний аналіз і чисельні наближення

Чисельне інтегрування цього інтеграла для різних значень числа Прандтля `Pr` дає фундаментальні асимптотичні результати:

### 1. Випадок помірних і великих чисел Прандтля (`Pr ≥ 0.6`)

Для малих `η` біля стінки розклад Блазіуса дає `f(η) ≈ (1/2) · f''(0) · η² = (1/2) · 0.33206 · η²`.

Підставивши цей розклад у вираз для `θ'(0)` і зробивши заміну змінної `ξ = Pr^(1/3) · η`, інтеграл зводиться до гамма-функції:

```
θ'(0) ≈ 0.33206 · Pr^(1/3)        (похибка < 1% для Pr ≥ 0.6)
```

Обчислимо місцевий коефіцієнт тепловіддачі `h_x`:

```
q_w = - k · (∂T/∂y)_(y=0) = k · (T_w - T_∞) · θ'(0) · √(U / (ν · x))
h_x = q_w / (T_w - T_∞) = k · θ'(0) · √(U / (ν · x))
```

Знерозміривши `h_x` через місцеве число Нуссельта `Nu_x = h_x · x / k`:

```
Nu_x = h_x · x / k = θ'(0) · √(U · x / ν) = θ'(0) · √Re_x
Nu_x = 0.33206 · Re_x^(1/2) · Pr^(1/3)
```

Знайдемо співвідношення товщин примежових шарів `δ_v / δ_t`. За визначенням, товщина шару обернено пропорційна градієнту на стінці:

```
δ_v ~ 1 / f''(0) = 1 / 0.33206
δ_t ~ 1 / θ'(0) = 1 / (0.33206 · Pr^(1/3))
δ_v / δ_t = θ'(0) / f''(0) = (0.33206 · Pr^(1/3)) / 0.33206 = Pr^(1/3)
```

Ми точними математичними кроками вивели співвідношення `δ_v / δ_t = Pr^(1/3)`.

### 2. Граничний випадок малих чисел Прандтля (`Pr ≪ 1`, рідкі метали)

При `Pr → 0` тепловий шар є настільки товстим, що майже на всій його товщині поздовжня швидкість дорівнює незбуреній швидкості `u ≈ U` (`f'(η) ≈ 1`, `f(η) ≈ η`).

Підставивши `f(η) = η` в інтеграл для `θ'(0)`:

```
θ'(0) = 1 / { ∫₀^∞ exp[- (1/4) · Pr · η²] dη }
```

Цей інтеграл є класичним інтегралом Ейлера — Пуассона (помилок Гаусса). Його обчислення дає:

```
θ'(0) = √(Pr / π) ≈ 0.56419 · Pr^(1/2)
Nu_x = 0.56419 · Re_x^(1/2) · Pr^(1/2) = 0.56419 · Pe_x^(1/2)
```

Це доводить, що для рідких металів число Нуссельта залежить не від `Re` та `Pr` окремо, а виключно від їхнього добутку — числа Пекле `Pe_x = Re_x · Pr`.

## 7. Розрахунок при неізотермічній стінці (`T_w(x) - T_∞ = C · x^m`)

Якщо температура стінки змінюється вздовж поверхні за степеневим законом `T_w(x) - T_∞ = C · x^m`, автомодельний розв'язок узагальнюється. У цьому випадку рівняння для безрозмірної температури набуває вигляду:

```
θ'' + (1/2) · Pr · f · θ' - m · Pr · f' · θ = 0
```

Розв'язок цього рівняння показує, що при наростанні температури стінки уздовж течії (`m > 0`) градієнт `θ'(0)` збільшується, а тепловий шар стає тоншим. Для градієнтного обтікання (потік Фолкнера — Скан) додатково враховується градієнт тиску, де число Прандтля також входить як основний параметр розділення швидкісного та теплового масштабів.
