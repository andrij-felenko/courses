# 📋 Інтерфейс бібліотеки газодинамічних розрахунків сопел та термодинамічних функцій

Довідкова вставка містить повну специфікацію публічного програмного інтерфейсу C/C++ бібліотеки `libnozzle` для розрахунку газодинамічних функцій стисливого потоку, геометрії сопел Лаваля, режимів витікання газу, ударних хвиль та CLI-утиліти газодинамічного аналізу.

Модуль спроектовано для високонавантажених обчислень в аерокосмічних тренажерах, системах управління двигунами (FADEC) та САПР термодинамічного моделювання. Інтерфейс гарантує нульове динамічне виділення пам'яті під час виконання обчислювального циклу, повну сумісність із C11 та C++20, а також відсутність винятків у критичних за часом обчисленнях.

## 1. Архітектурні принципи та гарантії бібліотеки

Бібліотека `libnozzle` розроблена за принципом ізольованого обчислювального ядра (pure functional core). Всі розрахунки є повністю детермінованими, повторно входжуваними (reentrant) та потокобезпечними (thread-safe) за умови, що викликач не модифікує вхідні дані під час розрахунку.

Основоположні технічні вимоги до реалізації:

1. **Відсутність побічних ефектів:** жодна функція обчислювального ядра не виконує операцій введення-виведення (I/O), не звертається до системних викликів та не використовує глобальний стан або статеві статичні змінні.
2. **Нульове динамічне виділення пам'яті:** обчислення на розрахунковій сітці відбуваються виключно у буферах пам'яті, наданих викликачем (для C API) або в заздалегідь виділених контейнерах `std::span` / `std::vector` (для C++ API). Це повністю виключає затримки на роботу з купою (`malloc` / `free`) у контурах управління реального часу.
3. **Гарантія відсутності винятків:** C++ API позначено специфікатором `noexcept` для всіх функцій нижнього рівня. Обробка помилок виконується через повернення кодів станів або стандартного типу `std::expected` (C++23) чи сумісного `std::optional`.
4. **Вирівнювання пам'яті та SIMD:** усі публічні структури даних вирівняні за межею 8 або 16 байт, що дозволяє автовекторизатору компілятора застосовувати векторні інструкції AVX2, AVX-512 та ARM Neon при обробці сіток точок.

## 2. Коди помилок та переліки режимів течії

Для забезпечення найвищого рівня надійності та усунення невизначеної поведінки (undefined behavior) усі функції бібліотеки повертають явні коди помилок або обгортки результату.

### 2.1 Перелік режимів витікання (`nozzle_flow_regime_t` / `FlowRegime`)

Перелік визначає фізичний стан газового струменя та наявність хвильових структур залежно від перепаду тиску `P0 / P_amb` та геометричного відношення площ `A_exit / A_throat`.

:::tabs
```c
typedef enum {
    NOZZLE_REGIME_SUBSONIC_VENTURI  = 0, /* Дозвуковий режим (немає запирання, M < 1 усюди) */
    NOZZLE_REGIME_CHOKED_ISENTROPIC = 1, /* Розрахунковий ізоентропійний режим (P_exit = P_amb) */
    NOZZLE_REGIME_OVEREXPANDED_SHOCK= 2, /* Перерозширений режим (прямий скачок ущільнення в дифузорі) */
    NOZZLE_REGIME_OVEREXPANDED_EXIT = 3, /* Перерозширений режим (косі скачки поза соплом, ромби Маха) */
    NOZZLE_REGIME_UNDEREXPANDED     = 4  /* Недорозширений режим (віяло розширення поза соплом) */
} nozzle_flow_regime_t;
```
```cpp
enum class FlowRegime : uint8_t {
    SubsonicVenturi   = 0, // Дозвуковий режим (M < 1 усюди)
    ChokedIsentropic  = 1, // Розрахунковий ізоентропійний режим (P_exit = P_amb)
    OverexpandedShock = 2, // Прямий скачок ущільнення усередині дифузора
    OverexpandedExit  = 3, // Косі скачки ущільнення поза соплом (ромби Маха)
    Underexpanded     = 4  // Віяло розширення Прандтля-Майєра поза соплом
};
```
:::

Детальний опис фізичного змісту та умов виникнення кожного режиму:

- `NOZZLE_REGIME_SUBSONIC_VENTURI`: Виникає при малих перепадах тиску між форкамерою та довкіллям. Перепад тиску є недостатнім для досягнення звукової швидкості у горловині (`M_throat < 1`). Сопло працює як звичайна труба Вентурі з повним відновленням тиску у дифузорі. Потік залишається повністю ізоентропійним без хвильових втрат.
- `NOZZLE_REGIME_CHOKED_ISENTROPIC`: Ідеальний розрахунковий режим. Газ розганяється до `M = 1` у горловині та продовжує ізоентропійний розгін до `M > 1` у дифузорі, причому статичний тиск на зрізі точно дорівнює атмосферному тиску довкілля (`P_exit = P_amb`). Струмінь виходить паралельно осі без ударних хвиль, забезпечуючи максимальну тягу.
- `NOZZLE_REGIME_OVEREXPANDED_SHOCK`: Протитиск довкілля є завеликим. Потік не може вийти з сопла з тиском `P_exit < P_amb` без стрибка тиску, тому усередині дифузора спонтанно виникає неізоентропійний прямий скачок ущільнення. За скачком потік мгновенно сповільнюється до `M < 1`, а статичний тиск зростає.
- `NOZZLE_REGIME_OVEREXPANDED_EXIT`: Тиск на зрізі нижчий за атмосферний, але перепад недостатній для заштовхування скачка всередину дифузора. Скачки ущільнення виходять на зовнішню кромку сопла у вигляді косих хвиль та ромбів Маха (Mach diamonds).
- `NOZZLE_REGIME_UNDEREXPANDED`: Тиск на зрізі сопла вищий за атмосферний (типова робота у вакуумі чи верхніх шарах атмосфери). Газ продовжує розширюватися поза межами сопла у центрованому віялі розширення Прандтля — Майєра, розширюючи струмінь убік.

### 1.2 Коди повернення та помилок (`nozzle_error_t` / `NozzleError`)

Библіотечні статуси повернення дозволяють точно діагностувати некоректні геометричні дані або збої чисельної збіжності.

:::tabs
```c
typedef enum {
    NOZZLE_OK                       =  0, /* Успішне виконання розрахунку */
    NOZZLE_ERR_NULL_PTR             = -1, /* Нульовий вказівник у параметрах */
    NOZZLE_ERR_INVALID_GAMMA        = -2, /* Некоректне значення gamma (має бути > 1.0) */
    NOZZLE_ERR_INVALID_GEOM         = -3, /* Геометричний дефект (A_throat > A_in або A_throat > A_exit) */
    NOZZLE_ERR_NO_CHOKE             = -4, /* Перепад тиску недостатній для досягнення M = 1 */
    NOZZLE_ERR_CONVERGENCE_FAILED   = -5, /* Чисельний метод не збігся за задану кількість ітерацій */
    NOZZLE_ERR_OUT_OF_BOUNDS        = -6  /* Запит параметра за межами фізичної сітки */
} nozzle_error_t;
```
```cpp
enum class NozzleError : int32_t {
    Ok                 =  0, // Успішне виконання розрахунку
    NullPointer        = -1, // Передано некоректний вказівник або порожній span
    InvalidGamma       = -2, // Показник адіабати gamma <= 1.0
    InvalidGeometry    = -3, // Площа горловини A* перевищує вхідний або вихідний переріз
    NoChoking          = -4, // Перепад тиску замалий для розгону до M = 1
    ConvergenceFailed  = -5, // Метод Ньютона-Рафсона не дав збіжності за MAX_ITER
    OutOfBounds        = -6  // Індекс токи виходить за межі сітки
};
```
:::

Деталізація діагностичних кодів:
- `NOZZLE_ERR_NULL_PTR`: Виникає, якщо один із вхідних або вихідних вказівників масивів має значення `NULL` чи `nullptr`.
- `NOZZLE_ERR_INVALID_GAMMA`: Показник адіабати газу `γ` зафіксовано меншим або дорівнює `1.0`, що суперечить законам термодинаміки.
- `NOZZLE_ERR_INVALID_GEOM`: Задана площа горловини `A_throat` є більшою за вхідну площу `A_in` або вихідну площу `A_exit`, що порушує геометричний профіль сопла Лаваля.
- `NOZZLE_ERR_NO_CHOKE`: Відношення тиску гальмування `P0` до протитиску `P_amb` є меншим за критичне `(P0 / P_amb) < (1 / P*_ratio)`, тому швидкість у горловині залишається дозвуковою.
- `NOZZLE_ERR_CONVERGENCE_FAILED`: Чисельний ітераційний розв'язувач Ньютона — Рафсона не досяг заданої точності за максимальну кількість ітерацій.
- `NOZZLE_ERR_OUT_OF_BOUNDS`: Запитаний індекс точки сітки перевищує розмірність масиву.

## 3. Структури даних бібліотеки

Усі структури вирівняні за межею 8 байт для забезпечення максимальної швидкодії векторних інструкцій SIMD та запобігання міжплатформним розходженням упакування полів.

### 3.1 Вхідні термодинамічні властивості газу (`gas_properties_t` / `GasProperties`)

Містить фізичні константи розрахункового газу та параметри гальмування у форкамері.

:::tabs
```c
typedef struct {
    double gamma;       /* Показник адіабати (C_p / C_v), безрозмірний (> 1.0) */
    double R_spec;      /* Питома газова стала, Дж/(кг·К) */
    double P0;          /* Повний тиск гальмування на вході, Па */
    double T0;          /* Повна температура гальмування на вході, К */
    double P_amb;       /* Протитиск навколишнього середовища, Па */
} gas_properties_t;
```
```cpp
struct GasProperties {
    double gamma{1.4};       // Показник адіабати (наприклад, 1.4 для повітря)
    double R_spec{287.05};   // Питома газова стала, Дж/(кг·К)
    double P0{1.0e6};        // Повний тиск гальмування у форкамері, Па
    double T0{300.0};        // Повна температура гальмування, К
    double P_amb{101325.0};  // Протитиск довкілля, Па
};
```
:::

Поля структури описують фізичний стан робочого тіла:
- `gamma`: Співвідношення питомих теплоємностей `C_p / C_v`. Для одноатомних газів (гелій, аргон) `γ = 1.67`, для двоатомних (повітря, азот, кисень) `γ = 1.40`, для багатоатомних продуктів згоряння `γ = 1.20...1.26`.
- `R_spec`: Індивідуальна газова стала `R = R_universal / M_molar`. Для повітря `R = 287.05` Дж/(кг·К), для чистого водню `R = 4124` Дж/(кг·К).
- `P0`, `T0`: Параметри гальмування у форкамері (камері згоряння). Характеризують повну енергію газу до початку розширення.

### 3.2 Геометрична конфігурація сопла (`nozzle_geometry_t` / `NozzleGeometry`)

Описує ключові перерізи та габарити розраховуваного канала.

:::tabs
```c
typedef struct {
    double A_in;        /* Площа вхідного перерізу (конфузор), м² */
    double A_throat;    /* Площа критичного перерізу (горловини A*), м² */
    double A_exit;      /* Площа вихідного перерізу (зріз дифузора A_e), м² */
    double length;      /* Повна довжина сопла вздовж осі x, м */
    double x_throat;    /* Положення горловини вздовж осі x, м */
} nozzle_geometry_t;
```
```cpp
struct NozzleGeometry {
    double A_in{0.02};        // Площа входу, м²
    double A_throat{0.01};    // Площа горловини A*, м²
    double A_exit{0.04};      // Площа зрізу дифузора A_e, м²
    double length{1.0};       // Повна довжина сопла, м
    double x_throat{0.3};     // Координата горловини, м
};
```

### 3.3 Параметри течії у контрольованій точці (`flow_point_state_t` / `FlowPointState`)

Результуюча структура локального стану газодинамічного потоку у конкретному перерізі `x`.

:::tabs
```c
typedef struct {
    double x;           /* Осьова координата точки, м */

    double pressure;    /* Статичний тиск P, Па */
    double temp;        /* Статична температура T, К */

    double vel;         /* Швидкість газу u, м/с */
    double P0_local;    /* Повний тиск у даній точці (ураховує втрати на скачку), Па */

```
```cpp
struct FlowPointState {
    double x{0.0};           // Осьова координата точки, м

    double pressure{0.0};    // Статичний тиск P, Па
    double temp{0.0};        // Статична температура T, К
    double density{0.0};     // Густина ρ, кг/м³
    double vel{0.0};         // Швидкість газу u, м/с
    double P0_local{0.0};    // Локальний повний тиск P0, Па
};
```

### 3.4 Результат розрахунку прямого скачка ущільнення (`shock_wave_info_t` / `ShockWaveInfo`)

Містить детальну інформацію про геометричне положення та термодинамічні стрибки у випадку виникнення ударної хвилі у дифузорі.

:::tabs
```c
typedef struct {
    bool shock_present; /* Чи наявний скачок усередині сопла */
    double x_shock;     /* Координата скачка ущільнення, м */
    double A_shock;     /* Площа сопла в місці скачка, м² */
    double M1;          /* Число Маха перед скачком (M1 > 1) */
    double M2;          /* Число Маха за скачком (M2 < 1) */
    double P1;          /* Статичний тиск до скачка, Па */
    double P2;          /* Статичний тиск після скачка, Па */
    double P0_loss;     /* Втрата повного тиску (P01 - P02), Па */
} shock_wave_info_t;
```
```cpp
struct ShockWaveInfo {
    bool shock_present{false}; // Прапорець наявності скачка усередині дифузора
    double x_shock{0.0};        // Координата розрахункового скачка, м
    double A_shock{0.0};        // Площа перерізу у точці скачка, м²
    double M1{1.0};             // Число Маха перед скачком (надзвукове, M1 > 1)
    double M2{1.0};             // Число Маха за скачком (дозвукове, M2 < 1)
    double P1{0.0};             // Доскачковий статичний тиск, Па
    double P2{0.0};             // Післяскачковий статичний тиск, Па
    double P0_loss{0.0};        // Незворотна втрата повного тиску, Па
};
```

## 4. Специфікація функцій C API

Функції C API є ABI-сумісними і можуть викликатися з мов Python (через ctypes або CFFI), Rust, Go чи C#.

### 4.1 `nozzle_compute_critical_ratios`
Обчислює критичні термодинамічні співвідношення (`P*/P0`, `T*/T0`, `ρ*/ρ0`) для заданого показника адіабати `γ`.

:::tabs
```c
nozzle_error_t nozzle_compute_critical_ratios(
    double gamma,
    double *out_p_crit,
    double *out_t_crit,
    double *out_rho_crit
);
```
```cpp
struct CriticalRatios {
    double p_ratio;   // P* / P0
    double t_ratio;   // T* / T0
    double rho_ratio; // ρ* / ρ0
};

std::expected<CriticalRatios, NozzleError> computeCriticalRatios(double gamma) noexcept;
```
:::

Параметри функції:
- `gamma`: [in] Показник адіабати розраховуваного газу.
- `out_p_crit`: [out] Вказівник на змінну для запису критичного відношення тиску `P* / P0`.
- `out_t_crit`: [out] Вказівник на змінну для запису критичного відношення температур `T* / T0`.
- `out_rho_crit`: [out] Вказівник на змінну для запису критичного відношення густин `ρ* / ρ0`.

### 4.2 `nozzle_solve_mach_from_area`
Обчислює число Маха за відношенням площ `A / A*`. Параметр `is_supersonic` обирає потрібну вітку розв'язку (дозвукову чи надзвукову).

:::tabs
```c
nozzle_error_t nozzle_solve_mach_from_area(
    double area_ratio,
    double gamma,
    bool is_supersonic,
    double *out_mach
);
```
```cpp
std::expected<double, NozzleError> solveMachFromArea(
    double area_ratio, 
    double gamma, 
    bool is_supersonic
) noexcept;
```
:::

```cpp
std::expected<double, NozzleError> computeMaxMassFlow(
```

### 4.4 `nozzle_analyze_regime`
Визначає поточний режим роботи сопла за співвідношенням `P0`, `P_amb` та геометрії. Якщо виникає прямий скачок ущільнення, заповнює структуру `out_shock`.

:::tabs

```c
nozzle_error_t nozzle_analyze_regime(
```

```cpp
struct RegimeAnalysisResult {

std::expected<RegimeAnalysisResult, NozzleError> analyzeRegime(
```

### 4.5 `nozzle_solve_full_mesh`
Виконує повний розрахунок параметрів потоку уздовж заданого масиву точок сітки `x_arr` та площ `area_arr`. Результат записується у попередньо виділений масив `out_states`.

:::tabs
```c
nozzle_error_t nozzle_solve_full_mesh(
    const gas_properties_t *gas,
    const nozzle_geometry_t *geom,
    const double *x_arr,
```
