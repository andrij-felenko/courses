# 🧮 Газодинамічні рівняння ізоентропійного сопла та диференціальний зв'язок Гюгоньо

Математична вставка містить строге аналітичне виведення фундаментальних диференціальних співвідношень газової динаміки стисливого потоку, алгебраїчних ізоентропійних функцій зв'язку площ та чисел Маха, граничної витрати критичного запирання та рівнянь прямого скачка ущільнення Ренкіна — Гюгоньо.

## 1. Диференціальні рівняння квазіодновимірної течії

Розглянемо усталену (стаціонарну), ідеальну (без в'язкості та теплопровідності) течію стисливого газу уздовж узгодженого каналу зі змінною площею поперечного перерізу `A(x)`. Усі параметри потоку (густина `ρ`, статичний тиск `P`, швидкість `u`, температура `T`) вважаються усередненими за перерізом `A`.

Закон збереження маси у квазіодновимірній постановці виражається рівнянням нерозривності для масової витрати `m_dot`:

```
m_dot = ρ · u · A = const
```

Логарифмування обох частин рівняння нерозривності дає вираз:

```
ln(m_dot) = ln(ρ) + ln(u) + ln(A) = const
```

Диференціювання логарифмічного виразу дає фундаментальний зв'язок відносних змін параметрів:

```
dρ / ρ + du / u + dA / A = 0      [диференціальне рівняння нерозривності]
```

Фізичний зміст цього рівняння полягає у тому, що сума відносних змін густини, швидкості та площі у будь-якому перерізі каналу завжди дорівнює нулю. Зниження густини або площі вимагає відповідного збільшення швидкості для збереження стабільності масового потоку.

Закон збереження імпульсу для елементарного об'єму ідеального газу описується диференціальним рівнянням Ейлера (за відсутності зовнішніх масових сил і в'язкого тертя):

```
ρ · u · du + dP = 0
u · du + dP / ρ = 0               [диференціальне рівняння Ейлера]
```

Це рівняння показує, що прискорення газу (`du > 0`) можливе лише за наявності спадного градієнта тиску (`dP < 0`). Зменшення потенціальної енергії тиску безпосередньо переходить у збільшення кінетичної енергії потоку `u² / 2`.

Уздовж лінії струму для ізоентропійного процесу (безпідводне та бездисипативне розширення, `dS = 0`) термодинамічна швидкість звуку `a` визначається частковою похідною тиску за густиною:

```
a² = (dP / dρ)_s = γ · P / ρ
```

де `γ = C_p / C_v` — показник адіабати (коефіцієнт Пуассона). Для двоатомних газів (повітря, N₂, O₂) `γ = 1.4`, для триатомних продуктів згоряння (CO₂, H₂O) `γ ≈ 1.2–1.3`.

## 2. Виведення диференціального співвідношення Гюгоньо

Підставимо вираз для швидкості звуку `dP = a² · dρ` у рівняння руху Ейлера:

```
u · du + (a² · dρ) / ρ = 0
```

Поділимо обидві частини на `a²` та виразимо відносну зміну густини `dρ / ρ`:

```
dρ / ρ = - (u / a)² · (du / u)
dρ / ρ = - M² · (du / u)         [зв'язок густини та швидкості через число Маха]
```

де `M = u / a` — місцеве число Маха потоку.

Підставимо отримане вираження для `dρ / ρ` у диференціальне рівняння нерозривності:

```
- M² · (du / u) + du / u + dA / A = 0
(1 - M²) · (du / u) + dA / A = 0
```

Перенесемо член зі зміною площі у праву частину:

```
dA / A = (M² - 1) · (du / u)     [диференціальне співвідношення Гюгоньо]
```

Це співвідношення є головним фундаментальним законом геометричної газодинаміки. З нього випливають три фізичні режими течії:

1. **Дозвуковий режим (`M < 1`):** `M² - 1 < 0`. Знаки `dA` та `du` протилежні. Звуження каналу (`dA < 0`) викликає зростання швидкості (`du > 0`), а розширення (`dA > 0`) — гальмування (`du < 0`).
2. **Надзвуковий режим (`M > 1`):** `M² - 1 > 0`. Знаки `dA` та `du` збігаються. Розширення каналу (`dA > 0`) викликає дальше зростання швидкості (`du > 0`), а звуження (`dA < 0`) — гальмування (`du < 0`).
3. **Критичний переріз / Горловина (`M = 1`):** Ліва частина дорівнює нулю (`M² - 1 = 0`), отже `dA / A = 0`. Безперервний перехід з дозвукової швидкості у надзвукову можливий **виключно у мінімумі геометричного перерізу каналу**, де `dA = 0`.

Детальний аналіз градієнтів тиску та швидкості:

З рівняння Ейлера `dP = - ρ · u · du` випливає, що зміна тиску вздовж осі сопла визначається виразом:

```
dP / dA = (ρ · u² / A) / (1 - M²)
```

- У дозвуковій зоні (`M < 1`) при звуженні каналу (`dA < 0`) градієнт тиску є від'ємним (`dP / dx < 0`), що сприяє прискоренню.
- У надзвуковій зоні (`M > 1`) при розширенні каналу (`dA > 0`) градієнт тиску також залишається від'ємним (`dP / dx < 0`), завдяки чому газ продовжує прискорюватися за рахунок падіння статичного тиску.

За наявності в'язкого тертя об стінки (течія Фано) або підведення тепла (течія Релея) диференціальне співвідношення розширюється членами дисипації:

```
dA / A + (4 · f · dx / D_h) - (dQ / (C_p · T)) = (M² - 1) · (du / u)
```

де `f` — коефіцієнт поверхневого тертя Фаннінга, `D_h` — гідравлічний діаметр каналу, `dQ` — диференціальне підведення тепла. В'язкість та підведення тепла зсувають критичну точку `M = 1` трохи за течією від геометричного мінімуму `A*`.

## 3. Газодинамічні функції та співвідношення повного гальмування

З закону збереження енергії (рівняння Бернуллі для стисливого газу / рівняння збереження повної ентальпії `H₀ = h + u² / 2 = const`) випливає зв'язок між статичною температурою `T` та температурою повного гальмування `T₀`:

```
C_p · T + u² / 2 = C_p · T₀
1 + u² / (2 · C_p · T) = T₀ / T
```

Ураховуючи, що `C_p = γ · R / (γ - 1)` та `a² = γ · R · T`, отримуємо:

```
T₀ / T = 1 + ((γ - 1) / 2) · M²
```

Використовуючи ізоентропійній зв'язок між тиском, температурою та густиною (`P / P₀ = (T / T₀)^(γ / (γ - 1))` і `ρ / ρ₀ = (T / T₀)^(1 / (γ - 1))`), виводимо ізоентропійні газодинамічні функції:

```
P₀ / P = [ 1 + ((γ - 1) / 2) · M² ]^( γ / (γ - 1) )

ρ₀ / ρ = [ 1 + ((γ - 1) / 2) · M² ]^( 1 / (γ - 1) )
```

Ці рівняння показують, що при розгоні газу статична температура `T`, статичний тиск `P` та густина `ρ` монотонно падають зі зростанням числа Маха `M`.

## 4. Критичний стан та відношення площ `A / A*`

У критичному перерізі (горловині) при `M = 1` параметри потоку набувають критичних значень (`T*`, `P*`, `ρ*`):

```
T* / T₀ = 2 / (γ + 1)

P* / P₀ = [ 2 / (γ + 1) ]^( γ / (γ - 1) )

ρ* / ρ₀ = [ 2 / (γ + 1) ]^( 1 / (γ - 1) )
```

Для повітря (`γ = 1.4`):

```
T* / T₀ = 2 / 2.4 ≈ 0.8333

P* / P₀ = (2 / 2.4)^(3.5) ≈ 0.5283   [критичне відношення тиску]

ρ* / ρ₀ = (2 / 2.4)^(2.5) ≈ 0.6339
```

Записуючи масову витрату через критичний переріз `m_dot = ρ* · a* · A*` та довільний переріз `m_dot = ρ · u · A`, отримуємо алгебраїчну залежність відношення площ `A / A*` від місцевого числа Маха `M`:

```
A / A* = (1 / M) · [ (2 / (γ + 1)) · (1 + ((γ - 1) / 2) · M²) ]^( (γ + 1) / (2 · (γ - 1)) )
```

Для заданої геометрії сопла відношення `A / A*` дає **два корені**: один дозвуковий (`M < 1`) для конфузора і один надзвуковий (`M > 1`) для дифузора.

## 5. Гранична витрата критичного запирання

Коли тиск у горловині досягає критичного значення `P*`, масова витрата через сопло сягає абсолютного максимуму для заданих параметрів гальмування (`P₀`, `T₀`) і більше не залежить від зниження зовнішнього протитиску `P_amb`.

Формула критичної масової витрати (дроселювання сопла):

```
m_dot_max = A* · P₀ · √( γ / (R · T₀) ) · [ 2 / (γ + 1) ]^( (γ + 1) / (2 · (γ - 1)) )
```

Для зручності обчислень вводиться газодинамічний коефіцієнт витрати `B_q(γ)`:

```
B_q(γ) = √( γ · [ 2 / (γ + 1) ]^( (γ + 1) / (γ - 1) ) )
```

Для повітря (`γ = 1.4`, `R = 287.05 J/(kg·K)`): `B_q ≈ 0.6847`. Тоді критична витрата спрощується до:

```
m_dot_max = 0.6847 · A* · P₀ / √(R · T₀)
```

## 6. Прямий скачок ущільнення (Рівняння Ренкіна — Гюгоньо)

Якщо у надзвуковій дифузорній частині сопла протитиск перевищує розрахунковий, у потоці виникає неізоентропійний прямий скачок ущільнення. Співвідношення між параметрами перед скачком (індекс 1, `M₁ > 1`) та за скачком (індекс 2, `M₂ < 1`) визначаються рівняннями Ренкіна — Гюгоньо:

```
M₂² = [ (γ - 1) · M₁² + 2 ] / [ 2 · γ · M₁² - (γ - 1) ]

P₂ / P₁ = 1 + [ (2 · γ) / (γ + 1) ] · (M₁² - 1)

ρ₂ / ρ₁ = u₁ / u₂ = [ (γ + 1) · M₁² ] / [ (γ - 1) · M₁² + 2 ]

T₂ / T₁ = (P₂ / P₁) · (ρ₁ / ρ₂)
```

Втрата повного тиску `P₀₂ < P₀₁` на скачку ущільнення супроводжується зростанням питомої ентропії `ΔS`:

```
P₀₂ / P₀₁ = [ (γ + 1) · M₁² / ((γ - 1) · M₁² + 2) ]^(γ / (γ - 1)) · [ (γ + 1) / (2 · γ · M₁² - (γ - 1)) ]^(1 / (γ - 1))

ΔS = C_p · ln(T₂ / T₁) - R · ln(P₂ / P₁) > 0
```

Ці математичні співвідношення утворюють повний закритий базис для чисельного розрахунку будь-яких режимів течії у соплі Лаваля.
