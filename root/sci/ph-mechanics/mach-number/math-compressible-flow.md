# 🧮 Газодинамічні функції та виведення співвідношень стисливого потоку

Ця вставка містить строге математичне виведення термодинамічних та газодинамічних співвідношень для стисливого потоку ідеального газу. Наведено послідовний аналіз швидкості звуку, ізоентропійних функцій гальмування, геометрії акустичних хвиль, функцій Прандтля-Майєра, співвідношень Ренкіна-Гюгоньо для прямих і косих скачків ущільнення, а також термодинамічний аналіз незворотних втрат ентропії.

---

## 1. Виведення швидкості звуку з рівнянь неперервності та Ейлера

Розглянемо поширення плоскої акустичної хвилі малой амплітуди вздовж осі `x` у нескінченному однорідному середовищі. Нехай у незбуреному газі тиск дорівнює `p`, густина — `ρ`, а швидкість газу — `0`. У хвилі виникають малі відхилення: тиск `p + dp`, густина `ρ + dρ` та швидкість `dv`.

Перейдемо в систему відліку, що рухається разом із хвилею зі швидкістю `a`. У цій системі фронт хвилі є нерухомим, а газ набігає на нього зі швидкістю `a` і виходить зі швидкістю `a - dv`.

Зупинимося на двох фундаментальних законах збереження для вузького контрольного об'єму навколо фронту:

1. **Закон збереження маси (рівняння неперервності):**
```
ρ · a = (ρ + dρ) · (a - dv)
ρ · a = ρ · a - ρ · dv + a · dρ - dρ · dv      [розкриваємо дужки]
a · dρ - ρ · dv = 0                            [нехтуємо добутком малих dρ·dv]
dv = a · (dρ / ρ)                              [виражаємо зміну швидкості dv]
```

2. **Закон збереження імпульсу (рівняння Ейлера):**
```
dp = p - (p + dp) = -dp                       [перепад тиску на фронті]
dp = ρ · a · dv                                [зміна імпульсу в одиницю часу]
```

Підставимо вираз для `dv` із рівняння неперервності в рівняння імпульсу:
```
dp = ρ · a · (a · (dρ / ρ))
dp = a² · dρ                                  [скорочуємо густину ρ]
a² = dp / dρ
a = √(dp / dρ)
```

Оскільки акустичні коливання відбуваються надзвичайно швидко і теплообмін між сусідніми шарами газу встигає дорівнювати нулю, процес стиску та розрядження є **адіабатичним та ізоентропійним** (`s = const`).

Для ідеального газу рівняння адіабати Пуассона має вигляд:
```
p / ρ^γ = const
p = C · ρ^γ                                   [де C — стала, γ — показник адіабати]
```

Візьмемо похідну тиску за густиною при сталій ентропії:
```
dp / dρ = C · γ · ρ^(γ - 1)
dp / dρ = (p / ρ^γ) · γ · ρ^(γ - 1)           [підставляємо C = p / ρ^γ]
dp / dρ = γ · (p / ρ)                         [спрощуємо показники степеня]
```

Використовуючи рівняння стану ідеального газу Клапейрона-Менделєєва `p / ρ = R · T` (де `R` — питома газова стала, `T` — абсолютна температура), отримуємо остаточну формулу для швидкості звуку:
```
a = √(γ · (p / ρ)) = √(γ · R · T)
```

Діабатичний модуль об'ємної пружності газу `K_s` визначається як `K_s = ρ · (dp/dρ)_s = γ · p`. Звідси швидкість звуку можна записати в загальному гідродинамічному вигляді `a = √(K_s / ρ)`, що збігається з формулою для будь-якого стисливого середовища (включаючи рідини та тверді тіла).

## 2. Ізоентропійні газодинамічні функції (співвідношення гальмування)

Розглянемо адіабатичне гальмування потоку, що рухається зі швидкістю `v` та має статичну температуру `T` і статичний тиск `p`, до повної зупинки (`v = 0`). Параметри повністю загальмованого потоку позначають індексом `0` (`T₀`, `p₀`, `ρ₀`).

Закон збереження енергії для ізоентропійного потоку (рівняння Бернуллі для стисливого газу у формі повної ентальпії) має вигляд:
```
c_p · T + v² / 2 = c_p · T₀
```

Зв'язок між питомою теплоємністю при сталому тиску `c_p`, газовою сталою `R` та показником адіабати `γ`:
```
c_p = (γ · R) / (γ - 1)
```

Підставимо `c_p` у рівняння збереження енергії:
```
((γ · R) / (γ - 1)) · T + v² / 2 = ((γ · R) / (γ - 1)) · T₀
1 + ((γ - 1) / (2 · γ · R · T)) · v² = T₀ / T   [ділимо обидві частини на c_p · T]
```

Оскільки `a² = γ · R · T`, а число Маха `M = v / a`, то `v² / (γ · R · T) = v² / a² = M²`. Отримуємо співвідношення для повної температури:
```
T₀ / T = 1 + ((γ - 1) / 2) · M²
```

Використовуючи ізоентропійне співвідношення між температурою, тиском та густиною `p₀ / p = (T₀ / T)^(γ / (γ - 1))` та `ρ₀ / ρ = (T₀ / T)^(1 / (γ - 1))`, знаходимо газодинамічні функції тиску та густини:
```
p₀ / p = (1 + ((γ - 1) / 2) · M²)^(γ / (γ - 1))
ρ₀ / ρ = (1 + ((γ - 1) / 2) · M²)^(1 / (γ - 1))
```

Для двоатомного газу (повітря, `γ = 1.4`):
```
T₀ / T = 1 + 0.2 · M²
p₀ / p = (1 + 0.2 · M²)^3.5
ρ₀ / ρ = (1 + 0.2 · M²)^2.5
```

### Критичні параметри потоку (`M = 1`)

Параметри потоку в перерізі, де швидкість дорівнює місцевій швидкості звуку (`M = 1.0`), називаються **критичними** і позначаються зірочкою (`T*`, `p*`, `ρ*`, `a*`).

Підставляючи `M = 1` у формули гальмування для повітря (`γ = 1.4`), отримуємо критичні співвідношення:

```
T* / T₀ = 2 / (γ + 1) = 2 / 2.4 = 0.83333
p* / p₀ = ( 2 / (γ + 1) )^(γ / (γ - 1)) = (0.83333)^3.5 = 0.52828
ρ* / ρ₀ = ( 2 / (γ + 1) )^(1 / (γ - 1)) = (0.83333)^2.5 = 0.63394
```

Критична швидкість звуку `a*` виражається через параметри повної зупинки `T₀`:

```
a* = √( (2 · γ / (γ + 1)) · R · T₀ )
```

Для повітря при `T₀ = 288.15 K` критична швидкість звуку становить `a* ≈ 310.6 м/с`.

## 3. Геометрія кута Маха та хвилі розрядження Прандтля-Майєра

### 3.1. Геометрія кута Маха
Для надзвукового джерела збурень (`M > 1`), що рухається зі швидкістю `v`, радіус акустичної хвилі, випроміненої час `t` тому, дорівнює `r = a · t`. За цей самий час джерело долає відстань `L = v · t`.

Прямокутний трикутник, утворений траєкторією джерела, радіусом хвилі та дотичною огинальною лінією (фронтом конуса Маха), має гіпотенузу `L` та катет `r`, протилежний до кута Маха `μ`:
```
sin(μ) = r / L
sin(μ) = (a · t) / (v · t)
sin(μ) = a / v = 1 / M
```

Звідси кут Маха виражається як `μ = arcsin(1 / M)`.

### 3.2. Функція Прандтля-Майєра для поворотного надзвукового потоку
При обтіканні надзвуковим потоком опуклого кута потік повертається на кут `θ` через віяло хвиль розрядження (розширення). Процес є плавним та ізоентропійним.

Зв'язок між кутом повороту потоку `θ` та зміною числа Маха описується **функцією Прандтля-Майєра `ν(M)`**:

```
ν(M) = √( (γ + 1) / (γ - 1) ) · arctan( √[ ((γ - 1) / (γ + 1)) · (M² - 1) ] ) - arctan( √(M² - 1) )
```

При розширенні потоку від `M₁ = 1.0` до числа Маха `M₂` кут повороту дорівнює `θ = ν(M₂) - ν(M₁)`. Для повітря (`γ = 1.4`) граничний кут повороту потоку при розширенні у вакуум (`M → ∞`) становить:

```
ν_max = ( π / 2 ) · [ √( (γ + 1) / (γ - 1) ) - 1 ] ≈ 130.45°
```

## 4. Прямий скачок ущільнення (співвідношення Ренкіна-Гюгоньо)

При переході через пряму ударну хвилю (скачок ущільнення) потік стрибком гальмується від надзвукової швидкості `M₁ > 1` до дозвукової `M₂ < 1`. Цей процес є сильно незворотним і супроводжується зростанням ентропії.

Закони збереження через фронт скачка:
1. **Маса:** `ρ₁ · v₁ = ρ₂ · v₂`
2. **Імпульс:** `p₁ + ρ₁ · v₁² = p₂ + ρ₂ · v₂²`
3. **Енергія:** `h₁ + v₁² / 2 = h₂ + v₂² / 2`  (де `h = c_p · T`)

З цих рівнянь виводяться **співвідношення Ренкіна-Гюгоньо** для числа Маха після скачка `M₂`:

```
M₂² = ((γ - 1) · M₁² + 2) / (2 · γ · M₁² - (γ - 1))
```

Для повітря (`γ = 1.4`):
```
M₂² = (0.4 · M₁² + 2) / (2.8 · M₁² - 0.4)
```

Співвідношення статичних тисків до та після скачка:
```
p₂ / p₁ = 1 + ((2 · γ) / (γ + 1)) · (M₁² - 1) = (2 · γ · M₁² - (γ - 1)) / (γ + 1)
```

Співвідношення густин (та швидкостей):
```
ρ₂ / ρ₁ = v₁ / v₂ = ((γ + 1) · M₁²) / ((γ - 1) · M₁² + 2)
```

Граничне значення ущільнення газу при `M₁ → ∞` залежить виключно від показника адіабати:
```
(ρ₂ / ρ₁)_max = (γ + 1) / (γ - 1)
```
Для повітря (`γ = 1.4`) це відношення дорівнює `(1.4 + 1) / (1.4 - 1) = 6.0`. Тобто при будь-якій надзвуковій швидкості густина повітря на прямому скачку ущільнення не може зрости більш ніж у `6` разів.

Співвідношення статичних температур виражається з рівняння стану `p = ρ R T`:
```
T₂ / T₁ = (p₂ / p₁) · (ρ₁ / ρ₂)
```

Втрата повного тиску `p₀₂ / p₀₁` (коефіцієнт відновлення повного тиску) визначається як:
```
p₀₂ / p₀₁ = ( (γ+1)·M₁² / ((γ-1)·M₁²+2) )^(γ/(γ-1)) · ( (γ+1) / (2·γ·M₁² - (γ-1)) )^(1/(γ-1))
```

## 5. Термодинамічний аналіз зростання ентропії на ударній хвилі

Оскільки повна температура гальмування `T₀` при переході через ударну хвилю зберігається (`T₀₁ = T₀₂`), зміна питомої ентропії `Δs = s₂ - s₁` пов'язана виключно з втратою повного тиску `p₀`:

```
Δs = c_p · ln(T₀₂ / T₀₁) - R · ln(p₀₂ / p₀₁)
Δs = -R · ln(p₀₂ / p₀₁) = R · ln(p₀₁ / p₀₂)
```

Оскільки через незворотність процесу завжди `p₀₂ < p₀₁`, то `p₀₁ / p₀₂ > 1`, що означає `Δs > 0` відповідно до другого закону термодинаміки.

Розкладаючи вираз для `Δs` у статевий ряд за малим параметром `(M₁² - 1) << 1` для слабких ударних хвиль (`M₁ → 1.0`), отримуємо:

```
Δs / R ≈ ( (2 · γ) / (3 · (γ + 1)²) ) · (M₁² - 1)³ + O( (M₁² - 1)⁴ )
```

Цей висновок є надзвичайно важливим для аеродинаміки: при наближенні числа Маха до одиниці зростання ентропії є величиною третього порядку малості `O((M₁² - 1)³)`. Саме це пояснює, чому слабкі скачки ущільнення у трансзвуковому режимі можна з високою точністю наближати ізоентропійними моделями течії.

## 6. Косі скачки ущільнення та `θ-β-M` співвідношення

У реальних надзвукових потоках навколо клинів чи конусів виникають косі скачки ущільнення, розташовані під кутом `β` до напрямку набігаючого потоку. При цьому потік відхиляється на кут `θ`.

Нормальна складова числа Маха до скачка дорівнює `M_1n = M₁ · sin(β)`. Для косого скачка всі співвідношення Ренкіна-Гюгоньо застосовуються до `M_1n`.

Зв'язок між кутом відхилення потоку `θ`, кутом скачка `β` та числом Маха `M₁` описується **`θ-β-M` рівнянням**:

```
tan(θ) = 2 · cot(β) · [ (M₁² · sin²(β) - 1) / (M₁² · (γ + cos(2β)) + 2) ]
```

Для кожного значення `M₁ > 1` та кута відхилення `θ < θ_max` існує два фізично можливі розв'язки:
- **Слабкий косий скачок** (менший кут `β`, потік за скачком зазвичай залишається надзвуковим `M₂ > 1`).
- **Сильний косий скачок** (більший кут `β`, потік за скачком стає дозвуковим `M₂ < 1`).

У практичній аеродинаміці реалізується слабкий скачок, якщо тиск на виході не підтримується вимушено протитиском ззовні.

Ці математичні співвідношення утворюють фундаментальний апарат обчислювальної газодинаміки та аеродинамічного розрахунку надзвукових апаратів.
