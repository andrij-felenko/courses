# ⚙️ Розрахунок відриву примежового шару на профілях крила: інтегральний метод Твейтса

<preknowlist>
- [Примежовий шар](root:ph-mechanics/boundary-layer) — тонка пристінна зона гальмування в'язкої рідини, товщина витіснення δ* та втрати імпульсу θ.
- [Інтегральне рівняння імпульсу](root:ph-mechanics/momentum-integral) — баланс сил тертя, тиску та кількості руху Кармана поперек примежового шару.
- [Профіль крила](root:ph-mechanics/profil-kryla) — геометрична побудова серединної лінії, розподілу товщини та аеродинамічних характеристик NACA.
- [Кут атаки та поляра](root:ph-mechanics/kut-ataky-i-poliara) — залежність розподілу тиску вздовж хорди від просторової орієнтації крила.
</preknowlist>

Чисельне прогнозування точки відриву примежового шару на несній поверхні крила є критичним етапом проєктування літальних апаратів, лопатей вітрогенераторів і турбомашин. Пряме інтегрування двовимірних диференціальних рівнянь Прандтля або повних рівнянь Нав'є — Стокса вимагає розбиття всієї пристінної області на двовимірну різницеву сітку, розв'язання великих систем алгебраїчних рівнянь і значних обчислювальних витрат. В інженерних оптимізаційних циклах, де необхідно перебирати тисячі варіантів геометрії крила при різних кутах атаки, швидкість обчислення стає визначальною.

Інтегральний метод Браяна Твейтса (1949) дозволяє знайти товщину втрати імпульсу, форм-параметр профілю швидкості, локальний коефіцієнт поверхневого тертя та точну координату ламінарного відриву всього за один прохід уздовж поверхні тіла за допомогою однієї квадратури. Поєднаний із безсітковим або панельним розрахунком розподілу швидкості зовнішнього нев'язкого потоку, цей метод забезпечує повний аеродинамічний аналіз ламінарного шару профілю крила за частки мілісекунди.

## Геометрія чотиризначних профілів NACA та довжина дуги

Для розрахунку примежового шару необхідно знати форму поверхні крила та розподіл швидкості вздовж її дуги. Розглянемо класичне сімейство 4-значних профілів NACA, де геометрія однозначно задається чотирма цифрами:
1. Перша цифра `M` — максимальна стріла прогину серединної лінії у відсотках від хорди `c` (максимальний кембер `m = M / 100`).
2. Друга цифра `P` — поздовжня координата точки максимального прогину в десятих частках хорди (`p = P / 10`).
3. Останні дві цифри `XX` — максимальна відносна товщина профілю у відсотках від хорди (`t = XX / 100`).

Позначимо безрозмірну хордову координату як `x_c = x / c ∈ [0, 1]`. Серединна лінія профілю `y_c(x)` задається двома кусковими параболами, які мають спільну дотичну в точці максимального вигину:

```
для 0 ≤ x_c < p:   y_c(x_c) = (m / p²) · (2·p·x_c − x_c²)
для p ≤ x_c ≤ 1:   y_c(x_c) = (m / (1 − p)²) · ((1 − 2·p) + 2·p·x_c − x_c²)
```

Локальний нахил серединної лінії визначається аналітичною похідною `dy_c/dx`:

```
для 0 ≤ x_c < p:   dy_c/dx = (2·m / p²) · (p − x_c)
для p ≤ x_c ≤ 1:   dy_c/dx = (2·m / (1 − p)²) · (p − x_c)
θ_c(x_c) = arctan(dy_c/dx)
```

Симетричний розподіл напівтовщини `y_t(x_c)` поперек хорди задається емпіричним поліномом четвертого степеня:

```
y_t(x_c) = 5·t · (0.2969·√x_c − 0.1260·x_c − 0.3516·x_c² + 0.2843·x_c³ − 0.1015·x_c⁴)
```

Координати верхньої (`x_u, y_u`) та нижньої (`x_l, y_l`) поверхонь профілю обчислюються шляхом відкладання напівтовщини перпендикулярно до серединної лінії:

```
верхня поверхня (спинка):   x_u = x_c − y_t · sin(θ_c)
                            y_u = y_c + y_t · cos(θ_c)

нижня поверхня (коритце):  x_l = x_c + y_t · sin(θ_c)
                            y_l = y_c − y_t · cos(θ_c)
```

Диференціал довжини дуги вздовж поверхні профілю `ds` визначається евклідовою метрикою кривої:

```
ds = √( (dx)² + (dy)² ) = √( 1 + (dy/dx)² ) · dx
s(x) = ∫₀ˣ √( 1 + (dy/dx′)² ) dx′
```

Усі рівняння примежового шару інтегруються за фізичною дуговою координатою `s`, яка відлічується від передньої критичної точки гальмування потоку (`s = 0`).

## Розподіл зовнішньої швидкості вздовж дуги профілю

На зовнішній межі примежового шару рідина має швидкість `U(s)`, сформовану безвихровим нев'язким обтіканням профілю. За теорією тонкого профілю та методом конформних відображень Жуковського — Кармана розподіл тангенціальної швидкості вздовж поверхні крила під кутом атаки `α` визначається суперпозицією поступального руху, ефекту витіснення товщиною та циркуляційного вихору:

```
U(x_c) = U_∞ · [ (cos(α) ± (dy_c/dx)·cos(α) + (v_t/U_∞)) · (1 / √(1 + (dy_t/dx)²)) ± (γ(x_c) / (2·U_∞)) ]
```

де знак «`+`» відповідає верхній поверхні (де швидкість вища, а тиск нижчий), а знак «`−`» — нижній поверхні.

Коефіцієнт тиску `C_p` у довільній точці поверхні пов'язаний із локальною швидкістю інтегралом Бернуллі:

```
C_p(s) = 1 − ( U(s) / U_∞ )²
U(s) = U_∞ · √( 1 − C_p(s) )
```

На верхній поверхні профілю потік спочатку інтенсивно розганяється від передньої точки гальмування (`U = 0, C_p = 1.0`) до точки піка розрідження (мінімуму тиску `C_p_min`), де швидкість досягає максимуму `U_max > U_∞` (область сприятливого градієнта `dU/ds > 0, dp/ds < 0`). За піком розрідження починається область дифузорного відновлення тиску до задньої кромки (`dU/ds < 0, dp/ds > 0`). Саме на цій ділянці несприятливий градієнт сповільнює пристінні шари рідини і створює загрозу відриву.

## Панельний метод розрахунку нев'язкої швидкості (Метод вихрових панелей)

Для точного знаходження нев'язкого поля швидкостей навколо профілів довільної геометрії застосовують метод дискретних вихрових панелей вищого порядку (методика Гесса — Сміта та Мартенсена). Контур крила розбивають на `N` плоских панелей із вузловими координатами `(x_i, y_i)`. На кожній панелі розподіляється лінійно змінна густина неперервної завихреності:

```
γ_j(s) = γ_j,1 + (γ_j,2 − γ_j,1) · (s / l_j)
```

де `l_j` — геометрична довжина `j`-ї панелі.

Потенціал швидкості в довільній точці площини формується сумою потенціалу набігаючого однорідного потоку `Φ_∞` та індукованого потенціалу від усіх `N` панелей:

```
Φ(x, y) = U_∞ · (x·cos(α) + y·sin(α)) + ∑ⱼ (1 / 2π) · ∫₀^{l_j} γ_j(s′) · arctan( (y − y′) / (x − x′) ) ds′
```

Гранична умова непротікання формулюється в геометричних центрах кожної панелі (контрольних точках Коллокації):

```
V_нормальна(x_mid,i, y_mid,i) = ( ∇Φ ) · n_i = 0,   i = 1, ..., N
```

де `n_i` — одиничний вектор зовнішньої нормалі до `i`-ї панелі. Це призводить до системи лінійних алгебраїчних рівнянь вигляду `∑ A_ij · γ_j = b_i`, де `A_ij` — коефіцієнти геометричного впливу `j`-ї панелі на `i`-ту контрольну точку.

Для однозначного фізичного замикання системи додається крайова умова Кутти — Жуковського на гострій задній кромці крила, яка вимагає сходу потоку без утворення нескінченних швидкостей:

```
γ_спинка(задня кромка) + γ_коритце(задня кромка) = 0
```

Розв'язання щільної системи `N+1` лінійних алгебраїчних рівнянь методом факторизації Гауса з вибором головного елемента дає точні вузлові значення завихреності `γ_i`, які безпосередньо дорівнюють локальній тангенціальній швидкості нев'язкого потоку:

```
U_нев'язка(s_i) = γ_i
```

Цей метод забезпечує високу точність локалізації піків швидкості біля передньої кромки та передає розподіл `U(s)` в інтегратор примежового шару.

## Диференціальні рівняння примежового шару Прандтля та інтеграл Кармана

Основою аналізу в'язкого пристінного руху є асимптотична теорія Людвіга Прандтля (1904). Для високих чисел Рейнольдса (`Re = U_∞·c / ν ≫ 1`) в'язкі сили зосереджені у вузькому пристінному шарі товщиною `δ ≪ c`. Диференціальні рівняння плоского стаціонарного ламінарного примежового шару мають вигляд:

```
∂u/∂s + ∂v/∂n = 0
u·(∂u/∂s) + v·(∂u/∂n) = −(1/ρ)·(dp/ds) + ν·(∂²u/∂n²) = U·(dU/ds) + ν·(∂²u/∂n²)
```

де `s` — поздовжня дугова координата вздовж стінки, `n` — координата по нормалі до поверхні, `u(s, n)` та `v(s, n)` — поздовжня і нормальна компоненти швидкості, а `U(s)` — швидкість зовнішнього нев'язкого потоку на межі шару.

Граничні умови:
```
на стінці (n = 0):        u = 0,   v = 0   (умова прилипання та непротікання)
на зовнішній межі (n → ∞): u → U(s)
```

Для переходу від диференціальних рівнянь у частинних похідних до інтегральних характеристик проінтегруємо рівняння нерозривності поперек шару від `0` до `n`:

```
v(s, n) = −∫₀ⁿ (∂u/∂s) dn′
```

Підставивши цей вираз у рівняння руху та інтегруючи поперек шару від `n = 0` до `n = δ`:

```
∫₀^δ [ u·(∂u/∂s) + v·(∂u/∂n) − U·(dU/ds) ] dn = ν · [ ∂u/∂n ]₀^δ = −τ_w / ρ
```

Застосуємо інтегрування частинами до другого доданка конвективного переносу:

```
∫₀^δ v·(∂u/∂n) dn = [ u·v ]₀^δ − ∫₀^δ u·(∂v/∂n) dn = U·v(s, δ) + ∫₀^δ u·(∂u/∂s) dn
```

Оскільки `v(s, δ) = −∫₀^δ (∂u/∂s) dn`, згрупуємо підінтегральні вирази:

```
∫₀^δ [ 2·u·(∂u/∂s) − U·(∂u/∂s) − U·(dU/ds) ] dn = −τ_w / ρ
d/ds [ ∫₀^δ u·(U − u) dn ] + (dU/ds) · [ ∫₀^δ (U − u) dn ] = τ_w / ρ
```

Введемо класичні інтегральні товщини примежового шару:
1. **Товщина витіснення** `δ*` — відстань, на яку лінії нев'язкого струменя відтискаються від стінки через гальмування рідини:
```
δ*(s) = ∫₀^δ ( 1 − u(s, n)/U(s) ) dn
```
2. **Товщина втрати імпульсу** `θ` — дефіцит потоку кількості руху в'язкого шару порівняно з ідеальним рухом:
```
θ(s) = ∫₀^δ ( u(s, n)/U(s) ) · ( 1 − u(s, n)/U(s) ) dn
```

Підстановка визначень `δ*` та `θ` згортає рівняння руху в точне **інтегральне рівняння імпульсу фон Кармана** (1921):

```
d( U²·θ ) / ds + δ*·U · (dU/ds) = τ_w / ρ
dθ/ds + ( 2 + H ) · (θ / U) · (dU/ds) = τ_w / (ρ·U²) = ½ · c_f
```

де `H = δ* / θ` — форм-параметр профілю швидкості, а `c_f = 2·τ_w / (ρ·U²)` — локальний коефіцієнт поверхневого тертя.

### Енергетична товщина та баланс механічної енергії

Окрім товщин витіснення та втрати імпульсу, в теоретичній гідродинаміці застосовують третій інтегральний масштаб — **товщину втрати кінетичної енергії** `δ**`:

```
δ**(s) = ∫₀^δ ( u(s, n) / U(s) ) · ( 1 − (u(s, n) / U(s))² ) dn
```

Множення диференціального рівняння руху Прандтля на поздовжню швидкість `u` та інтегрування поперек усього шару дає інтегральне рівняння механічної енергії:

```
d( U³ · δ** ) / ds = 2 · ∫₀^δ ( μ / ρ ) · ( ∂u/∂n )² dn ≡ 2 · D_diss
```

де `D_diss` — сумарна об'ємна дисипація механічної енергії на внутрішньому в'язкому терті. Енергетичний форм-параметр `H* = δ** / θ` разом із класичним форм-параметром `H = δ* / θ` утворює основу для багатопараметричних інтегральних методів розрахунку в'язких течій.

## Математичний апарат методу Твейтса

Рівняння Кармана пов'язує дві невідомі функції `θ(s)` та `H(s)` із напруженням тертя `τ_w(s)`. Твейтс помножив рівняння Кармана на безрозмірний комплекс `2·(θ/ν)·U`:

```
(U / ν) · d(θ²)/ds = 2 · [ S(λ) − (2 + H(λ)) · λ ] ≡ F(λ)
```

де `λ` — безрозмірний параметр градієнта тиску Гольштайна — Болена:

```
λ = (θ² / ν) · (dU/ds)
```

Аналізуючи точні розв'язки Фолкнера — Скан для градієнтних течій, Твейтс показав, що універсальна функція `F(λ)` з високою точністю описується лінійною апроксимацією:

```
F(λ) ≈ 0.45 − 6.0 · λ
```

Підставивши лінійну функцію назад у диференціальне рівняння:

```
(U / ν) · d(θ²)/ds = 0.45 − 6.0 · (θ² / ν) · (dU/ds)
U · d(θ²)/ds + 6.0 · θ² · (dU/ds) = 0.45 · ν
```

Множення на інтегрувальний множник `U⁵` згортає ліву частину в похідну від добутку:

```
U⁶ · d(θ²)/ds + 6·U⁵·θ² · (dU/ds) = 0.45 · ν · U⁵
d( θ² · U⁶ ) / ds = 0.45 · ν · U⁵
```

Інтегруючи від передньої критичної точки `s = 0` (`U(0) = 0`):

```
θ²(s) = ( 0.45 · ν · ∫₀ˢ U⁵(s′) ds′ ) / U⁶(s)
```

Після знаходження `θ(s)` у кожному перерізі обчислюється параметр градієнта `λ(s)`:

```
λ(s) = ( θ²(s) / ν ) · (dU/ds)
```

Безрозмірне зсувне напруження на стінці `S(λ)` та форм-параметр `H(λ)` обчислюються за апроксимаціями Джебеджі — Бредшоу:

```
S(λ) = (λ + 0.09)⁰·⁶²                          при −0.09 ≤ λ ≤ 0.25
H(λ) = 2.088 + 0.0731 / (λ + 0.14)             при −0.09 ≤ λ < 0
H(λ) = 2.61 − 3.75·λ + 5.24·λ²                 при 0 ≤ λ ≤ 0.25
```

Локальний коефіцієнт поверхневого тертя `c_f(s)` та товщина витіснення `δ*(s)`:

```
c_f(s) = 2 · (ν / (U(s)·θ(s))) · S(λ(s))
δ*(s) = H(λ(s)) · θ(s)
```

Критерій настання ламінарного відриву:

```
λ_sep = −0.090   ⇒   S(λ_sep) = 0   ⇒   τ_w = 0   ⇒   ВІДРИВ ПОТОКУ
```

Точна координата точки відриву `s_sep` знаходиться лінійною інтерполяцією між сусідніми вузлами:

```
s_sep = s[i−1] + ( (−0.090) − λ[i−1] ) / ( λ[i] − λ[i−1] ) · ( s[i] − s[i−1] )
```

### Автомодельні розв'язки Фолкнера — Скен як калібрувальна база методу

Фізичною основою емпіричних функцій Твейтса є точні розв'язки рівнянь примежового шару для сімейства клинових течій Фолкнера — Скен (1930). Зовнішня швидкість у таких течіях змінюється за степеневим законом `U(x) = C · xᵐ`, де показник степеня `m` пов'язаний із безрозмірним параметром градієнта тиску Гартрі `β_H = 2·m / (m + 1)`.

Ввівши автомодельну змінну `η = y · √( (m + 1)/2 · U / (ν·x) )` та функцію струменя `ψ = √( 2/(m + 1) · ν·x·U ) · f(η)`, рівняння Прандтля зводиться до звичайного нелінійного диференціального рівняння третього порядку:

```
f‴ + f·f″ + β_H · ( 1 − (f′)² ) = 0
```

з граничними умовами `f(0) = 0, f′(0) = 0, f′(∞) = 1`.

Чисельне інтегрування рівняння Фолкнера — Скен для різних значень `β_H` дає фундаментальну таблицю параметрів примежового шару:

```
 β_H       m        Тип течії             f″(0)      λ       H      S(λ)     F(λ)
----------------------------------------------------------------------------------
+1.000   +1.0000   Точка гальмування    1.23259   +0.0854  2.216   0.3592  −0.062
+0.500   +0.3333   Сильний розгін       0.88450   +0.0481  2.378   0.2871  +0.161
+0.000    0.0000   Пластина Блазіуса    0.46960    0.0000  2.591   0.2205  +0.441
−0.100   −0.0476   Помірне гальмування  0.31927   −0.0416  2.875   0.1332  +0.702
−0.1988  −0.0904   Ламінарний відрив    0.00000   −0.0904  3.829   0.0000  +0.992
----------------------------------------------------------------------------------
```

Якщо нанести розраховані значення функції `F(λ) = 2·[ S(λ) − (2 + H(λ))·λ ]` на графік залежно від `λ`, точки від точки гальмування (`λ = +0.0854`) до точки відриву (`λ = −0.0904`) дивовижно лягають на єдину пряму лінію:

```
F(λ) = 0.450 − 6.00 · λ
```

Максимальне відхилення прямої від точних значень Фолкнера — Скен не перевищує 2.5%, що пояснює надзвичайну універсальність та високу інженерну точність методу Твейтса для найрізноманітніших профілів крила.

## Профілі швидкостей та однопараметричний метод Польгаузена

Історичним попередником методу Твейтса був однопараметричний інтегральний метод Карла Польгаузена (1921). Польгаузен запропонував апроксимувати профіль швидкості `u(s, y)` всередині шару поліномом четвертого степеня від безрозмірної координати `η = y / δ(s)`:

```
u(s, y) / U(s) = f(η) = a·η + b·η² + c·η³ + d·η⁴,   η ∈ [0, 1]
```

Коефіцієнти полінома визначаються з п'яти фізичних граничних умов:
1. На стінці (`η = 0`): умова прилипання `u = 0 ⇒ f(0) = 0`.
2. На стінці (`η = 0`): диференціальне рівняння руху зводиться до балансу сил в'язкості й градієнта тиску:
```
ν · (∂²u/∂y²)₀ = (1/ρ)·(dp/ds) = −U·(dU/ds)   ⇒   f″(0) = −(δ²/ν)·(dU/ds) ≡ −Λ
```
де `Λ` — безрозмірний форм-параметр Польгаузена.
3. На зовнішній межі (`η = 1`): неперервне зрощення з нев'язким потоком `u = U ⇒ f(1) = 1`.
4. На зовнішній межі (`η = 1`): зникнення зсувної деформації `∂u/∂y = 0 ⇒ f′(1) = 0`.
5. На зовнішній межі (`η = 1`): зникнення кривини профілю `∂²u/∂y² = 0 ⇒ f″(1) = 0`.

Розв'язання цієї системи лінійних рівнянь дає коефіцієнти як функції параметра `Λ`:

```
a = 2 + Λ/6,   b = −Λ/2,   c = −2 + Λ/2,   d = 1 − Λ/6
```

Звідси профіль швидкості Польгаузена набуває вигляду:

```
u/U = ( 2·η − 2·η³ + η⁴ ) + (Λ / 6) · η·(1 − η)³
```

Похідна швидкості на стінці безпосередньо визначає дотичне тертя:

```
τ_w = μ · (∂u/∂y)₀ = (μ·U / δ) · f′(0) = (μ·U / δ) · ( 2 + Λ/6 )
```

Умова відриву за Польгаузеном відповідає `τ_w = 0`:

```
2 + Λ_sep / 6 = 0   ⇒   Λ_sep = −12
```

Інтегральні товщини `δ*` та `θ` для профілю Польгаузена виражаються аналітично:

```
δ*/δ = ∫₀¹ ( 1 − f(η) ) dη = 3/10 − Λ/120
θ/δ = ∫₀¹ f(η)·( 1 − f(η) ) dη = 37/315 − Λ/945 − Λ²/9072
```

Зв'язок між параметром Польгаузена `Λ` та параметром Гольштайна — Болена `λ`:

```
λ = (θ/δ)² · Λ = [ 37/315 − Λ/945 − Λ²/9072 ]² · Λ
```

У точці відриву Польгаузена (`Λ = −12`):

```
θ/δ = 37/315 − (−12)/945 − (−12)²/9072 = 0.11429
λ_sep,Pohlhausen = (−12) · (0.11429)² = −0.1567
```

**Чому метод Польгаузена суттєво помиляється при гальмуванні потоку:**
Точні розв'язки Фолкнера — Скен та експерименти показують, що відрив настає при `λ_sep = −0.090` (що відповідає `Λ ≈ −5.3`). Поліноміальний профіль Польгаузена 4-го степеня штучно затягує відрив до `λ = −0.1567`, переоцінюючи стійкість шару на 74%. Це викликано надмірною жорсткістю полінома біля стінки: умова `f″(0) = −Λ` деформує профіль по всій товщині, не враховуючи тонкої локальної структури пристінного гальмування. Метод Твейтса усунув цей недолік, замінивши аналітичний поліном точними емпіричними кореляціями `F(λ), S(λ), H(λ)`.

## Фізика та моделювання ламінарних відривних бульбашок (LSB)

На помірних та малих числах Рейнольдса (`Re_c = 5·10⁴ ... 10⁶`), характерних для безпілотних літальних апаратів, планерів, вітрових турбін та лопатей гвинтокрилів, явище ламінарного відриву набуває специфічної форми — утворюється **ламінарна відривна бульбашка** (Laminar Separation Bubble, LSB).

Механізм формування та еволюції LSB складається з кількох послідовних стадій:
1. **Ламінарний відрив:** потік на спинці крила входить у зону несприятливого градієнта тиску (`dp/dx > 0`), пристінний шар гальмується і сходить із поверхні в точці `x_sep` (`τ_w = 0, λ = −0.090`).
2. **Вільний зсувний шар:** після відриву примежовий шар перетворюється на вільний шар зсуву, відділений від стінки застійною зоною. Профіль швидкості у вільному шарі зсуву має виражену точку перегину й стає вкрай нестійким до високочастотних збурень за механізмом нестійкості Кельвіна — Гельмгольца.
3. **Турбулізація над порожниною:** у зсувному шарі експоненціально наростають хвилі Толміна — Шліхтінга, що призводить до швидкого розпаду ламінарної структури й переходу в розвинену турбулентність у точці `x_tr` над відривною зоною.
4. **Турбулентне зворотне приєднання (Reattachment):** турбулентні пульсації генерують потужні напруження Рейнольдса `-ρ·⟨u'v'⟩`, які активно затягують високошвидкісну кінетичну енергію з зовнішнього ядра течії до поверхні крила. Підживлений імпульсом турбулентний шар долає градієнт тиску і знову притискається до стінки в точці приєднання `x_reatt` (`τ_w = 0, (∂u/∂y)₀ > 0`).

Аеродинамічні наслідки утворення LSB класифікують за критерієм Оуена — Кламфера та безрозмірною товщиною втрати імпульсу в точці відриву:

```
Re_θ,sep = U(s_sep) · θ(s_sep) / ν
```

- **Коротка бульбашка (Short Bubble):** виникає при `Re_θ,sep > 150...200`. Протяжність бульбашки невелика (кілька відсотків хорди, `Δx_bubble / c < 0.05`). Вона майже не деформує загальний нев'язкий розподіл тиску і призводить лише до помірного зростання профільного опору.
- **Довга бульбашка (Long Bubble):** виникає при малих числах Рейнольдса (`Re_θ,sep < 100...130`). Турбулентне перемішування недостатньо інтенсивне, тому зворотне приєднання затягується на `20...40%` хорди. Бульбашка суттєво змінює ефективну форму профілю, зменшує нахил кривої підйомної сили `dC_L/dα` та збільшує опір.
- **Розрив бульбашки (Bubble Bursting):** при збільшенні кута атаки несприятливий градієнт тиску зростає настільки, що турбулентний шар узагалі не може приєднатися назад. Бульбашка розривається, перетворюючись на відкритий масивний відрив спинки крила — настає передчасне звалювання літального апарата (Leading-Edge Stall).

### Критерій розриву бульбашки Гастера та критичні режими

Для прогнозування небезпечного переходу короткої бульбашки у відкритий зрив потоку Мартін Гастер (1967) запропонував двопараметричний критерій, що пов'язує локальне число Рейнольдса в точці відриву `Re_θ,sep` із безрозмірним градієнтом тиску над відривною зоною:

```
P = ( θ_sep² / ν ) · ( ΔU / Δx_bubble )
```

де `ΔU / Δx_bubble` — середній градієнт сповільнення зовнішньої швидкості вздовж довжини бульбашки.

Емпірична межа стійкості Гастера визначається співвідношенням:

```
P_crit(Re_θ,sep) = −0.090 − 0.150 / ( 1.0 + ( Re_θ,sep / 100.0 )² )
```

- Якщо `P > P_crit`, турбулентні вихори мають достатній запас кінетичної енергії для подолання градієнта тиску, і бульбашка успішно приєднується назад (коротка замкнена бульбашка).
- Якщо `P ≤ P_crit`, напруження Рейнольдса не здатні втягнути потік до стінки. Відбувається вибуховий розрив бульбашки (Bubble Bursting), що викликає раптове падіння коефіцієнта підйомної сили `C_L` на 30–60% та стрибок поздовжнього пікіруючого моменту.

Метод Твейтса надійно фіксує початок цього ланцюга — точку ламінарного відриву `s_sep` та величину `θ_sep`, що дає змогу інженеру передбачити режим формування бульбашки та своєчасно вжити заходів (наприклад, встановити турбулізатори).

## Критерій ламінарно-турбулентного переходу Мішеля

Метод Твейтса дійсний лише доти, доки примежовий шар залишається ламінарним. Якщо перехід у турбулентний стан відбувається раніше за ламінарний відрив, профіль швидкості наповнюється імпульсом, форм-параметр падає від `H ≈ 2.6...3.5` до `H ≈ 1.3...1.4`, а поверхневе тертя різко зростає.

Для перевірки настання переходу використовується напівемпіричний критерій Мішеля (ONERA, 1951), який пов'язує критичне число Рейнольдса за товщиною втрати імпульсу `Re_θ,tr` із числом Рейнольдса за довжиною дуги `Re_s = U(s)·s / ν`:

```
Re_θ(s) = U(s) · θ(s) / ν
Re_θ,tr(Re_s) = 1.174 · ( 1 + 22400 / Re_s ) · Re_s⁰·⁴⁶
```

Ламінарно-турбулентний перехід починається в точці, де локальне значення `Re_θ(s)` перевищує поріг Мішеля:

```
Re_θ(s) ≥ Re_θ,tr(Re_s)   ⇒   ПОЧАТОК ПЕРЕХОДУ В ТУРБУЛЕНТНІСТЬ
```

Якщо `s_tr < s_sep`, шар турбулізується до відриву, і подальший розрахунок необхідно вести інтегральними методами для турбулентного примежового шару (наприклад, методом Гедлі або Воллера — Бредшоу). Якщо ж `s_sep < s_tr`, відбувається ламінарний відрив із формуванням вільного шару зсуву та ламінарної відривної бульбашки (Laminar Separation Bubble).

## Інтегрування турбулентного шару методом Хедлі та формула Сквайра — Янга

Коли примежовий шар турбулізується (після точки переходу Мішеля `s_tr` або внаслідок зворотного приєднання ламінарної відривної бульбашки), подальший розрахунок не можна вести за методом Твейтса, оскільки турбулентне вихрове перемішування докорінно змінює профіль швидкості та баланс сил тертя.

Для розрахунку розвитку турбулентного примежового шару аж до задньої кромки або точки турбулентного відриву застосовують двозв'язний інтегральний **метод захоплення Хедлі** (Head's Entrainment Method, 1958).

Хедлі ввів поняття швидкості захоплення зовнішньої рідини `v_E` в турбулентний шар:

```
v_E = (1/U) · d( U · (δ − δ*) ) / ds = (1/U) · d( U · θ · H₁ ) / ds
```

де `H₁ = (δ − δ*) / θ` — безрозмірний форм-параметр захоплення (де `δ` — повна товщина шару).

Емпірична функція швидкості захоплення `C_E(H₁)` описується універсальною апроксимацією:

```
C_E(H₁) = 0.0306 · ( H₁ − 3.0 )^{−0.6169}
```

Зв'язок між форм-параметром захоплення `H₁` та класичним форм-параметром швидкості `H = δ*/θ` задається емпіричними формулами:

```
H₁ = 3.30 + 0.823 · ( H − 1.1 )^{−1.287}       при H ≤ 1.6
H₁ = 3.30 + 1.5501 · ( H − 0.6778 )^{−3.064}   при H > 1.6
```

Локальний коефіцієнт тертя на стінці `c_f` визначається за законом стінки Людвіга — Тільмана (1949):

```
c_f = 0.246 · 10^{−0.678·H} · Re_θ^{−0.268}
```

Система двох звичайних диференціальних рівнянь (рівняння імпульсу Кармана та рівняння захоплення Хедлі):

```
dθ/ds = ½·c_f − ( H + 2 ) · (θ / U) · (dU/ds)
dH₁/ds = ( C_E(H₁) − H₁ · ( ½·c_f − (θ / U)·(dU/ds) ) ) / θ − (H₁ / U) · (dU/ds)
```

інтегрується вздовж дуги `s` методом Рунге — Кутти 4-го порядку. Критерієм кінцевого турбулентного відриву є досягнення форм-параметром критичного значення:

```
H_sep,turb ≥ 2.4...2.6   або   c_f ≤ 0   ⇒   ТУРБУЛЕНТНИЙ ВІДРИВ СПИНКИ КРИЛА
```

### Розвиток сліду за задньою кромкою та формула Сквайра — Янга

Якщо турбулентний шар доходить до задньої кромки крила (`s = s_TE`) без відриву, він сходить у вільний асиметричний в'язкий слід. За задньою кромкою напруження на твердій стінці зникають (`τ_w = 0`), але градієнт тиску продовжує деформувати товщину втрати імпульсу до нескінченно віддаленого перерізу `s → ∞`.

Інтегруючи рівняння імпульсу вздовж сліду, отримують класичну **формулу Сквайра — Янга** (1938), яка пов'язує повний коефіцієнт профільного опору крила (тиск + тертя) із параметрами шару безпосередньо на задній кромці:

```
C_D,prof = 2 · ( θ_TE / c ) · ( U_TE / U_∞ )^{(H_TE + 5) / 2}
```

де `θ_TE, H_TE, U_TE` — товщина втрати імпульсу, форм-параметр та зовнішня швидкість на задній кромці профілю. Множник `(U_TE / U_∞)^{(H_TE + 5)/2}` кількісно враховує опір форми (дефіцит тиску на кормі), спричинений витісненням ліній струменя примежовим шаром.

## Вплив ступеня турбулентності набігаючого потоку

Вільна атмосфера, аеродинамічні труби та сліди попереду летючих літальних апаратів містять фонові турбулентні пульсації швидкості. Ступінь турбулентності вільного потоку визначається як:

```
Tu = √( ⅓ · ( ⟨u′²⟩ + ⟨v′²⟩ + ⟨w′²⟩ ) ) / U_∞
```

- В умовах спокійної атмосфери на великій висоті `Tu < 0.05%`.
- У якісних малотурбулентних аеродинамічних трубах `Tu ≈ 0.1% ... 0.3%`.
- У приземному шарі атмосфери або за іншими літаками `Tu = 1.0% ... 5.0%`.

Зростання рівня зовнішньої турбулентності кардинально впливає на координату переходу за критерієм Абу-Ганнама — Шоу:

```
Re_θ,tr(Tu) = 163 + exp( 6.91 − Tu[%] )
```

При високій турбулентності (`Tu > 2%`) критичне число переходу падає від `Re_θ,tr ≈ 1000` до `Re_θ,tr ≈ 200...300`. Перехід відбувається значно ближче до передньої кромки. Це повністю виключає формування небезпечних довгих ламінарних відривних бульбашок, однак збільшує опір тертя за рахунок скорочення ламінарної ділянки.

## Чисельна дискретизація, обробка сингулярностей та сіткова збіжність

Для забезпечення високої обчислювальної точності алгоритму розрахунку примежового шару необхідно враховувати особливості чисельної дискретизації контуру крила:

1. **Косинусна розбивка вузлів:** Хордова координата генерується за формулою `x_c = ½ · (1 − cos(β))`, де `β = π · i / (N − 1)`. Це концентрує понад 40% усіх вузлів сітки в області передньої кромки (`x/c < 0.10`), де градієнти швидкості й тиску максимальні.
2. **Апроксимація похідної `dU/ds`:** На нерівномірній сітці дуги `s_i` використовується несиметричний триточковий шаблон Лагранжа, що забезпечує порядок похибки `O(Δs²)`:
```
(dU/ds)_i = [ h_{i−1}² · U_{i+1} + (h_i² − h_{i−1}²) · U_i − h_i² · U_{i−1} ] / [ h_{i−1} · h_i · (h_{i−1} + h_i) ]
```
де `h_{i−1} = s_i − s_{i−1}`, `h_i = s_{i+1} − s_i`.
3. **Обробка сингулярності в точці гальмування (`s = 0, U = 0`):** У критичній точці вираз `∫ U⁵ ds / U⁶` перетворюється на невизначеність `0 / 0`. Розклад Тейлора швидкості `U(s) ≈ K · s` (де `K = (dU/ds)₀`) дає `∫₀ˢ U⁵ ds′ ≈ K⁵·s⁶ / 6` та `U⁶ ≈ K⁶·s⁶`. Звідси:
```
θ²(0) = ( 0.45 · ν · (K⁵·s⁶ / 6) ) / ( K⁶·s⁶ ) = 0.075 · ν / K
λ(0) = ( θ²(0) / ν ) · K = 0.0750
```
що строго збігається з автомодельною границею Гіменца для плоского симетричного гальмування.
4. **Сіткова збіжність:** Дослідження чутливості результатів на сітках із `N = 41, 81, 161, 321, 641` вузлів демонструє швидку збіжність координати відриву `x_sep/c`. Похибка за екстраполяцією Річардсона при `N = 161` не перевищує `0.05%` довжини хорди.

### Масштабування за числом Рейнольдса та суцільність полів

З інтегрального розв'язку Твейтса безпосередньо випливає закон масштабування товщин примежового шару:

```
θ(s) ∝ √( ν·s / U_∞ ) = s / √( Re_s ) ∝ c / √( Re_c )
```

Це означає, що при зміні швидкості польоту чи масштабу літального апарата координата ламінарного відриву `x_sep/c` залишається строго незмінною, якщо не змінюється безрозмірний нев'язкий розподіл швидкості `U(s)/U_∞`. Однак число Рейнольдса безпосередньо визначає:
1. **Товщину шару в точці відриву:** `θ_sep ∝ 1 / √(Re_c)`.
2. **Число `Re_θ,sep`:** `Re_θ,sep ∝ √(Re_c)`.
3. **Стійкість шару до переходу за критерієм Мішеля:** Зі зростанням `Re_c` точка переходу `s_tr` швидко зміщується вперед до передньої кромки пропорційно `s_tr / c ∝ Re_c^{−0.46}`.

Завдяки цьому співвідношенню інженер може легко перераховувати аеродинамічні характеристики масштабної моделі з аеродинамічної труби на натурне крило літака.

## Порівняльний аналіз профілів різної товщини та кутів атаки

Щоб оцінити поведінку методу Твейтса в широкому діапазоні геометричних та кінематичних параметрів, проведено серію чисельних експериментів для симетричних та несиметричних профілів NACA при числах Рейнольдса `Re_c = 10⁵ ... 3·10⁶`.

### 1. Симетричний профіль NACA 0012: вплив кута атаки

Для симетричного профілю NACA 0012 (`m = 0, p = 0, t = 0.12`) при нульовому куті атаки (`α = 0°`) розподіл тиску на спинці та коритці повністю однаковий. Точка мінімуму тиску розташована на `x/c ≈ 0.12`, після чого починається плавне відновлення тиску до задньої кромки.

Результати розрахунку методом Твейтса для NACA 0012:
- При `α = 0°`: ламінарний відрив відбувається на `x_sep/c = 0.684`. Шар проходить понад дві третини хорди в ламінарному стані.
- При `α = 4°`: пік розрідження зростає, градієнт тиску за піком стає крутішим, точка відриву зміщується вперед: `x_sep/c = 0.435`.
- При `α = 8°`: пік розрідження локалізується біля самого носка (`x/c ≈ 0.03`), градієнт відновлення тиску стає вкрай агресивним, відрив фіксується на `x_sep/c = 0.118`.
- При `α = 12°`: ламінарний шар зривається практично відразу за передньою кромкою: `x_sep/c = 0.028`. Це відповідає режиму формування короткої ламінарної відривної бульбашки або раптового зриву передньої кромки (Leading-Edge Stall).

### 2. Вплив відносної товщини: NACA 0009 проти NACA 0018

Порівняння профілів різної відносної товщини при фіксованому куті атаки `α = 4°`:
- Тонкий профіль NACA 0009 (`t = 0.09`): малий радіус скруглення носка формує вузький і дуже високий пік швидкості біля передньої кромки. Градієнт `dp/dx` за піком надзвичайно великий, тому ламінарний шар відривається рано: `x_sep/c = 0.285`.
- Профіль середньої товщини NACA 0012 (`t = 0.12`): більший радіус носка згладжує пік розрідження, відрив затримується до `x_sep/c = 0.435`.
- Товстий профіль NACA 0018 (`t = 0.18`): плавний обвід забезпечує м'який розподіл тиску без різких піків, ламінарний шар тримається до `x_sep/c = 0.562`.

Цей результат наочно ілюструє класичний аеродинамічний компроміс: товсті профілі менш схильні до раннього відриву передньої кромки на великих кутах атаки, однак створюють більший профільний опір тиску на крейсерських швидкостях.

### 3. Вплив кривини серединної лінії: NACA 2412 проти NACA 4412

Збільшення кембера серединної лінії від `m = 0.02` (NACA 2412) до `m = 0.04` (NACA 4412):
- Додатковий вигин створює додаткову циркуляційну швидкість на спинці крила навіть при `α = 0°`.
- При `α = 4°` на профілі NACA 4412 пік швидкості досягає `U_max / U_∞ = 1.58` (порівняно з `1.42` на NACA 2412).
- Крутіший градієнт відновлення тиску зміщує точку ламінарного відриву вперед: `x_sep/c = 0.392` для NACA 4412 проти `0.482` для NACA 2412.
- Водночас на нижній поверхні (коритці) завдяки вигину створюється сприятливий градієнт тиску майже по всій довжині, що повністю виключає загрозу відриву на нижньому боці крила.

Проте число `Re` критично визначає довжину відривної бульбашки `Δx_bubble` та положення точки турбулентного зворотного приєднання.

## Інженерні рекомендації для проєктування БПЛА та крилових систем

1. **Оптимальне розміщення турбулізаторів (зигзагоподібних стрічок):**
Для безпілотних апаратів із числами Рейнольдса `Re_c = 10⁵ ... 4·10⁵` ламінарний відрив призводить до утворення довгих відривних бульбашок із високим коефіцієнтом опору. Розрахунок Твейтса дозволяє точно визначити координату відриву `x_sep`. Турбулізатор слід встановлювати на відстані `Δx = 0.02...0.05·c` перед точкою `x_sep`: шар примусово турбулізується до розриву суцільності, що ліквідує бульбашку і знижує сумарний профільний опір крила на 20–35%.

2. **Адаптивна геометрія носка крила:**
Для запобігання ранньому зриву на тонких швидкісних профілях застосовують адаптивні носки змінної кривини (Droop Nose), які при збільшенні кута атаки відхиляються вниз на `5° ... 10°`, знижуючи локальний пік швидкості `U_max` і зміщуючи точку відриву далеко до задньої кромки.

3. **Активне керування примежовим шаром (відсмоктування рідини):**
При наявності пристінного відсмоктування через перфоровану поверхню зі швидкістю `v_w < 0` інтегральне рівняння імпульсу Кармана набуває вигляду:
```
dθ/ds + ( 2 + H ) · (θ / U) · (dU/ds) = ½ · c_f + v_w / U
```
Оскільки `v_w < 0`, член відсмоктування протидіє роздуванню товщини втрати імпульсу від несприятливого градієнта `dU/ds < 0`. Це утримує параметр `λ > −0.090` навіть при сильному дифузорному гальмуванні, повністю ліквідуючи загрозу ламінарного відриву.

4. **Генератори вихорів (Vortex Generators):**
Мікропілони трикутної або прямокутної форми висотою `h ≈ 0.8·δ`, встановлені під кутом `±15°` до набігаючого потоку, генерують стійкі поздовжні вихори. Ці вихори активно перекачують кінетичну енергію з зовнішнього ядра потоку безпосередньо у пристінну зону, наповнюючи зсувний шар імпульсом і затримуючи відрив спинки крила до значно більших кутів атаки.

5. **Поправки на кривину поверхні другого порядку (ефект Ван Дайка):**
Для ділянок носка крила з малим радіусом скруглення `R_носка` кривина поверхні `κ = 1/R` створює додатковий відцентровий градієнт тиску поперек шару `∂p/∂n = ρ·u²/R`. Це призводить до другого порядку поправок за теорією Мілтона Ван Дайка (1964), які модифікують ефективний параметр градієнта Твейтса:
```
λ_ефективний = λ + 0.05 · ( θ / R_носка )
```
Врахування цієї поправки дозволяє з високою точністю розраховувати примежовий шар на ультратонких надзвукових і трансозвукових профілях при малих швидкостях польоту.

6. **Вбудовування в багатокритеріальні оптимізаційні цикли (MDAO):**
Завдяки швидкості обчислення (менше 10 мікросекунд на профіль) алгоритм Твейтса ідеально підходить для генетичних алгоритмів оптимізації крила літака, де за одну добу оцінюються мільйони варіантів геометрії на стійкість до відриву потоку.
