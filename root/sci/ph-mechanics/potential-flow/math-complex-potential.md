# 🧮 Математика комплексного потенціалу та конформних перетворень

Ця математична вставка містить аналітичний вивід функцій комплексної змінної, умов Коші — Рімана, комплексного потенціалу та конформного відображення Жуковського для двовимірної безвихрової потенціальної течії несжимаємої рідини.

## Комплексна площина та умови Коші — Рімана

Розглянемо плоский потенціальний плин нестисливої рідини у декартових координатах `(x, y)`. Поле швидкостей `u = (u_x, u_y)` визначається скалярним потенціалом `ϕ(x, y)` та функцією течії `ψ(x, y)`:

```
u_x = ∂ϕ/∂x =  ∂ψ/∂y
u_y = ∂ϕ/∂y = -∂ψ/∂x
```

Об'єднаємо координати `x` та `y` у єдину комплексну змінну `z`:

```
z = x + i · y = r · e^(i · θ)
```

Де `i = √(-1)` — уявна одиниця, `r = √(x² + y²)` — модуль, а `θ = arctan(y / x)` — аргумент комплексної координати.

Введемо скалярну функцію комплексної змінної `W(z)`, яка називається комплексним потенціалом течії:

```
W(z) = ϕ(x, y) + i · ψ(x, y)
```

Функція `W(z)` є аналітичною (голоморфною) у деякій області комплексного простору тоді і тільки тоді, коли її частинні похідні по `x` та `y` задовольняють умови Коші — Рімана. Перевіримо похідну `dW/dz`:

```
dW / dz 
= ∂W / ∂x                                       [диференціювання по дійсному напрямку x]
= ∂ϕ/∂x + i · ∂ψ/∂x                             [підстановка W = ϕ + i·ψ]

З іншого боку:
dW / dz 
= (1 / i) · ∂W / ∂y                            [диференціювання по уявному напрямку i·y]
= -i · (∂ϕ/∂y + i · ∂ψ/∂y)                      [множення на -i: 1/i = -i]
= ∂ψ/∂y - i · ∂ϕ/∂y                             [розкриття дужок: -i · i = 1]
```

Прирівнюючи дійсні та уявні частини обидвох виразів, отримуємо умови Коші — Рімана:

```
∂ϕ/∂x =  ∂ψ/∂y
∂ϕ/∂y = -∂ψ/∂x
```

З аналітичності функції `W(z)` миттєво випливає, що як дійсна частина `ϕ` (потенціал швидкості), так і уявна частина `ψ` (функція течії) є гармонічними функціями та задовольняють рівняння Лапласа:

```
∇²ϕ = ∂²ϕ/∂x² + ∂²ϕ/∂y² = 0
∇²ψ = ∂²ψ/∂x² + ∂²ψ/∂y² = 0
```

## Комплексна швидкість та її властивості

Похідна від комплексного потенціалу по комплексній змінній `z` називається комплексною швидкістю `V(z)`:

```
V(z) = dW / dz = ∂ϕ/∂x + i · ∂ψ/∂x = u_x - i · u_y
```

Зверніть увагу, що уявна частина комплексної швидкості має знак «мінус». Комплексна швидкість є спряженим комплексним числом до фізичного вектора швидкості `u_x + i · u_y`.

Модуль комплексної швидкості дорівнює абсолютній величині фізичної швидкості плину:

```
|V(z)| = |dW / dz| = √(u_x² + u_y²) = v
```

А квадрат модуля комплексної швидкості виражає кінетичну енергію одиниці маси рідини:

```
|dW / dz|² = u_x² + u_y² = v²
```

У полярній системі координат `(r, θ)` комплексне число `z = r · e^(i·θ)`. Виразимо комплексну швидкість через радіальну `u_r` та тангенціальну `u_θ` компоненти:

```
dW / dz 
= (u_r - i · u_θ) · e^(-i · θ)
```

## Канонічні комплексні потенціали елементарних течій

Завдяки властивостям аналітичних функцій елементарні потенціальні течії описуються вишуканими комплексними виразами:

1. **Рівномірний потік під кутом `α` до осі `x`:**

```
W(z) = U · e^(-i · α) · z 
= U · (cos α - i · sin α) · (x + i · y)                           [формула Ейлера e^(-iα) та z = x + iy]
= U · (x · cos α + y · sin α) + i · U · (y · cos α - x · sin α)   [розкриття дужок і виділення дійсної й уявної частин]
```

Звідси миттєво: `ϕ = U · (x · cos α + y · sin α)` та `ψ = U · (y · cos α - x · sin α)`.

2. **Точкове джерело або сток у початку координат:**

```
W(z) = (Q / (2π)) · ln z 
= (Q / (2π)) · (ln r + i · θ)
```

Дійсна частина `ϕ = (Q / (2π)) · ln r`, уявна частина `ψ = (Q / (2π)) · θ`.

3. **Точковий потенціальний вихор інтенсивністю `Γ`:**

```
W(z) = -i · (Γ / (2π)) · ln z 
= -i · (Γ / (2π)) · (ln r + i · θ)                                [заміна логарифма ln z = ln r + i·θ]
= (Γ / (2π)) · θ - i · (Γ / (2π)) · ln r                          [множення на -i: -i · i = 1]
```

Дійсна частина `ϕ = (Γ / (2π)) · θ`, уявна частина `ψ = -(Γ / (2π)) · ln r`.

4. **Диполь (дуплет) з моментом `μ`, спрямований уздовж осі `x`:**

```
W(z) = μ / z 
= (μ / r) · e^(-i · θ)                                            [полярна форма z = r·e^(iθ)]
= (μ · cos θ) / r - i · (μ · sin θ) / r                           [формула Ейлера e^(-iθ) = cos θ - i sin θ]
```

5. **Обтікання циліндра радіуса `R` з циркуляцією `Γ`:**

Додавши однорідний потік `U·z`, диполь `U·R²/z` та точковий вихор `-i·(Γ/(2π))·ln z`, отримуємо підсумковий комплексний потенціал:

```
W(z) = U · (z + R² / z) - i · (Γ / (2π)) · ln z
```

Перевіримо комплексну швидкість на поверхні циліндра `z = R · e^(i·θ)`:

```
dW / dz 
= U · (1 - R² / z²) - i · Γ / (2π · z)                           [диференціювання по z]
= U · (1 - e^(-2iθ)) - i · Γ / (2π · R · e^(iθ))                 [підстановка z = R e^(iθ)]
= e^(-iθ) · [ U · (e^(iθ) - e^(-iθ)) - i · Γ / (2π · R) ]       [винесення спільного множника e^(-iθ)]
= e^(-iθ) · [ 2i · U · sin θ - i · Γ / (2π · R) ]               [формула Ейлера: e^(iθ) - e^(-iθ) = 2i sin θ]
= -i · e^(-iθ) · (2 · U · sin θ + Γ / (2π · R))                 [винесення уявної одиниці -i]
```

Модуль цієї швидкості дає тангенціальну швидкість на поверхні циліндра: `v(θ) = |2 · U · sin θ + Γ / (2π · R)|`.

## Теорема про коло Мілн-Томсона (Milne-Thomson Circle Theorem)

Фундаментальним інструментом створення нових потенціальних розв'язків є теорема про коло Мілн-Томсона. Вона дозволяє миттєво знайти збурене поле течії при внесенні круглого циліндра радіуса `a` у довільне задане потенціальне поле.

Нехай необмежений безвихровий плин нестисливої рідини у відсутності тіл описується комплексним потенціалом `f(z)`, який не має сингулярностей усередині області `|z| ≤ a`. Якщо у початок координат помістити твердий непроникний циліндр радіуса `a`, то підсумковий комплексний потенціал течії `W(z)` дорівнюватиме:

```
W(z) = f(z) + f̄(a² / z)
```

Де `f̄(z)` означає функцію, у якій усі комплексно-спряжені коефіцієнти замінено на їхні спряжені значення (`f̄(z) = conj(f(conj(z)))`).

Доведемо цієї теореми. На поверхні циліндра `|z| = a` маємо `z · z̄ = a²`, тобто `z̄ = a² / z`. Обчислимо значення комплексного потенціалу `W(z)` на колі `z = a · e^(iθ)`:

```
W(a · e^(iθ)) 
= f(a · e^(iθ)) + f̄(a / e^(iθ))                                  [підстановка z = a e^(iθ) у вираз Milne-Thomson]
= f(a · e^(iθ)) + conj(f(a · e^(iθ)))                             [властивість комплексно-спряженої функції: f̄(a e^(-iθ)) = conj(f(a e^(iθ)))]
= 2 · Re{ f(a · e^(iθ)) }                                         [сума комплексно-спряжених величин w + w̄ = 2 Re{w}]
```

Оскільки уявна частина чисто дійсної величини дорівнює нулю (`Im{2 · Re{f}} = 0`), функція течії на колі `|z| = a` є тотожно сталою величиною (`ψ = 0`). Це гарантує виконання кінематичної граничної умови непроникання на поверхні циліндра, що й доводить теорему Мілн-Томсона.

## Перетворення Шварца — Крістоффеля для багатокутників

Для обчислення потенціальних течій у просторах, обмежених ламаними стінками (канали зі ступенем, конфузори, диффузори, розширення труб), застосовується конформне перетворення Шварца — Крістоффеля.

Нехай область `D` у площині `z` обмежена багатокутником з кутами `α_1, α_2, ..., α_n` у вершинах `z_1, z_2, ..., z_n`. Інтеграл Шварца — Крістоффеля здійснює конформне відображення верхньої напівплощини `Im{ζ} > 0` на внутрішність цього багатокутника:

```
z = C · ∫ [ (ζ - k_1)^(α_1/π - 1) · (ζ - k_2)^(α_2/π - 1) · ... · (ζ - k_n)^(α_n/π - 1) ] dζ + C_0
```

Де `k_1, k_2, ..., k_n` — точки на дійсній осі площини `ζ`, які відповідають вершинам багатокутника, а `C` та `C_0` — комплексні масштабуючі константи.

Цей метод дозволяє отримувати точні аналітичні розв'язки для розподілу швидкостей у вузлах гідравлічних мереж, отворах та кавернах.

## Теорема Блазіуса для обчислення гідродинамічних сил

Німецький гідромеханік Пауль Ріхард Генріх Блазіус (нім. *Paul Richard Heinrich Blasius*, 1883–1970) у 1911 році вивів елегантні комплексні інтегральні формули для сил та моментів, що діють на тіло в потенціальному потоці.

Нехай `C` — замкнений контур, що охоплює обтікальне тіло. Сумарний вектор гідродинамічних сил `F = F_drag + i · F_lift` визначається першою формулою Блазіуса:

```
F_drag - i · F_lift 
= (i · ρ / 2) · ∮[C] (dW / dz)² dz
```

А сумарний гідродинамічний момент відносно початку координат виражається другою формулою Блазіуса:

```
M = -(ρ / 2) · Re { ∮[C] z · (dW / dz)² dz }
```

Підставивши комплексний потенціал циліндра `W(z) = U·z + U·R²/z - i·Γ/(2π)·ln z` у першу формулу Блазіуса та застосувавши лишки комплексної аналітичної функції (теорему про лишки), отримуємо:

```
(dW / dz)² 
= [ U · (1 - R²/z²) - i·Γ/(2π·z) ]² 
= U² - i · U · Γ / (π · z) + O(1/z²)
```

Єдиним доданком, який дає ненульовий лишок у точці `z = 0`, є `-(i · U · Γ) / (π · z)`. За теоремою про лишки:

```
∮[C] (dW / dz)² dz 
= 2πi · Res[z=0]                                                  [теорема про лишки Коші]
= 2πi · (-i · U · Γ / π)                                          [значення лишка в точці z = 0]
= 2 · U · Γ                                                       [множення 2πi на -i/π: i · (-i) = 1]
```

Підставивши це у формулу Блазіуса:

```
F_drag - i · F_lift 
= (i · ρ / 2) · ∮[C] (dW / dz)² dz                               [перша формула Блазіуса]
= (i · ρ / 2) · (2 · U · Γ)                                      [підстановка обчисленого інтеграла 2UΓ]
= i · ρ · U · Γ                                                   [скорочення двійки]
```

Прирівнюючи дійсні та уявні частини:

```
F_drag = 0
F_lift = ρ · U · Γ
```

Формула Блазіуса дає найбільш строгий і швидкий математичний доказ теореми Кутти — Жуковського.

## Конформні відображення та умова Кутти

Нехай задано конформне відображення `z = f(ζ)`, де `ζ = ξ + i·η` — комплексна координата у допоміжній площині, де обтікання тіла є відомим (наприклад, коло).

Якщо комплексний потенціал у площині `ζ` дорівнює `W_ζ(ζ)`, то комплексний потенціал у фізичній площині `z` визначається як:

```
W_z(z) = W_ζ(f⁻¹(z))
```

Комплексна швидкість у фізичній площині обчислюється за правилом диференціювання складної функції:

```
dW / dz = (dW / dζ) / (dz / dζ)
```

Для перетворення Жуковського `z = ζ + a² / ζ`:

```
dz / dζ = 1 - a² / ζ² = (ζ² - a²) / ζ²
```

Точки `ζ = +a` та `ζ = -a` є критичними точками відображення, у яких `dz/dζ = 0`. У фізичній площині `z` точка `ζ = +a` перетворюється на точку `z = 2a`, яка є гострою задньою кромкою аеродинамічного профілю.

Щоб швидкість `dW/dz` у точці `z = 2a` була скінченною величиною (`|dW/dz| < ∞`), чисельник `dW/dζ` у точці `ζ = a` також мусить дорівнювати нулю:

```
dW / dζ |_(ζ = a) = 0
```

Це і є математичне формулювання умови Кутти. Згадаємо комплексну швидкість для кола з циркуляцією у площині `ζ`, центр якого зміщено в точку `ζ₀`:

```
dW / dζ = U · e^(-iα) - U · R² · e^(iα) / (ζ - ζ₀)² - i · Γ / (2π · (ζ - ζ₀))
```

Підставивши `ζ = a` та вимагаючи `dW/dζ = 0`, отримуємо циркуляцію `Γ`:

```
Γ = 4π · U · R · sin(α + β)
```

Де `α` — кут атаки, а `β = arg(a - ζ₀)` — кут нахилу середньої лінії профілю.

Завдяки умові Кутти теорія конформних відображень дозволяє точно розраховувати підйомну силу для аеродинамічних профілів будь-якої геометрії.
