# 🧮 Математичні моделі екрана землі та аеродинамічного розпаду в зоні вихорового кільця

При математичному моделюванні граничних режимів несучого гвинта класична одновимірна теорія імпульсу Ренкіна — Фруда натрапляє на дві принципові гідродинамічні сингулярності: наявність непроникної твердої межі (поверхня землі) та зустрічний рух ротора у власний струмінь при вертикальному спуску. Для коректного інженерного розрахунку динаміки польоту гелікоптерів, автожирів і мультикоптерів застосовують метод дзеркальних відображень потенційних течій Чізмена — Беннетта, а також кусочно-гладкі апроксимації індукованого припливу Волковича, Джонсона та Лейшмана.

---

### 1. Теорія екрана землі (IGE): метод дзеркальних відображень

У необмеженому середовищі (режим поза екраном землі, OGE) диск ротора площею `A = π·R²` створює тягу `T`, відкидаючи масу повітря вниз. Згідно з теоремою про зміну кількості руху, тяга дорівнює масовій витраті повітря `ṁ`, помноженій на приріст швидкості у віддаленому сліді `w = 2·v_i0`:

```
T = ṁ · w = (ρ · A · v_i0) · (2 · v_i0) = 2 · ρ · A · v_i0²
```

Звідси базова індукована швидкість у площині диска у вільному просторі:

```
v_i0 = √( T / (2 · ρ · A) )
```

Коли ротор зависає на висоті `h` над пласкою твердою поверхнею `z = 0`, нормальна складова швидкості на поверхні землі мусить строго дорівнювати нулю через умову непроникності:

```
v_z(x, y, 0) = 0   для всіх x, y
```

У гідродинаміці ідеального нестисливого плину ця крайова умова задовольняється введенням фіктивного **дзеркального ротора**, розташованого симетрично на глибині `h` під поверхнею землі (тобто на відстані `2·h` від реального диска). Дзеркальний ротор має ту саму потужність, але спрямований назустріч — він виштовхує потік угору.

#### Розрахунок індукованого поля швидкостей дзеркального диска

Якщо висота `h` порівнянна з радіусом `R` або перевищує його (`h ≥ R`), диск можна замінити точковим джерелом маси (диполем) з об'ємною продуктивністю `Q = A · v_i0`.

Потенціал швидкості `Φ` точкового джерела на відстані `d` від нього визначається класичним виразом тривимірної потенціальної теорії:

```
Φ(r_dist) = −Q / (4 · π · r_dist)
```

Вертикальна складова швидкості піддуву `Δv`, яку індукує дзеркальне джерело в центрі площини реального ротора на відстані `d = 2·h`:

```
Δv = ∂Φ / ∂z = Q / (4 · π · (2·h)²)
   = (π · R² · v_i0) / (4 · π · 4 · h²) [підстановка площі диска A = π·R²]
   = (R² · v_i0) / (16 · h²)            [скорочення числа π]
   = v_i0 · ( R / (4·h) )²              [винесення базової швидкості v_i0]
```

Результуюча індукована швидкість `v_i,IGE` у площині реального ротора дорівнює векторній сумі власного низхідного потоку та висхідного піддуву від дзеркального відображення:

```
v_i,IGE
= v_i0 − Δv                            [суперпозиція полів швидкостей]
= v_i0 − v_i0 · ( R / (4·h) )²          [підстановка індукованого піддуву]
= v_i0 · ( 1 − R² / (16 · h²) )         [винесення v_i0 за дужки]
```

#### Співвідношення тяги за моделлю Чізмена — Беннетта

Згідно з теорією елемента лопаті, елементарна тяга перерізу пропорційна ефективному куту атаки `α = θ − v_i / (Ω·r)`. При фіксованому кроці лопатей `θ` та сталій частоті обертання `Ω` зменшення індукованої швидкості призводить до збільшення циркуляції та тяги.

В актуаторній теорії тяга обернено пропорційна квадрату індукованої швидкості при незмінній витраті енергії на створення припливу:

```
T_IGE / T_OGE
= (v_i0 / v_i,IGE)²                    [зв'язок тяги з індукованою швидкістю]
= 1 / ( 1 − R² / (16 · h²) )²          [квадрат відношення швидкостей]
≈ 1 / ( 1 − R² / (16 · h²) )           [лінеаризована модель Чізмена й Беннетта, 1955]
```

Для потрібної індукованої потужності `P_i = T · v_i` при фіксованій тязі `T_IGE = T_OGE = T`:

```
P_i,IGE / P_i,OGE
= v_i,IGE / v_i0                       [відношення потужностей при однаковій тязі]
= 1 − R² / (16 · h²)                   [зменшення потрібної потужності в екрані]
```

#### Емпіричні корекції Найта — Хефнера та Гейдена

Проста дипольна модель Чізмена — Беннетта має математичну сингулярність при `h / R = 0.25` (знаменник перетворюється на нуль: `16 · (0.25)² = 1`). У реальному плині при `h / R < 0.5` розвивається в'язкий пристінний шар і радіальний струмінь з хвилеподібним відривом, що обмежує максимальне зростання тяги на рівні 1.35–1.40.

Для точних розрахунків у діапазоні `h/R ∈ [0.15, 3.0]` застосовують емпіричні поліноми:

1. **Модель Найта — Хефнера (Knight & Hefner, NACA TN-835):**
```
T_IGE / T_OGE = 1 / ( 1 − 0.125 · (R / h)² )   при h / R ≥ 0.6
```

2. **Модель Гейдена (Hayden, 1976), калібрована на сучасних вертолітних роторах:**
```
T_IGE / T_OGE = 1 / ( 0.9926 + 0.0379 · (h / R)⁻² )
```

У безрозмірних координатах відносно діаметра ротора `D = 2·R` (`h/D = 0.5 · h/R`):

```
T_IGE / T_OGE = 1 / ( 0.9926 + 0.009475 · (h / D)⁻² )
```

### 2. Сингулярність теорії імпульсу Главерта при вертикальному спуску

Розглянемо ротор в умовах чисто осьового спуску зі швидкістю `V_z` (вісь `z` спрямована вгору, тому при спуску швидкість `V_z < 0`, а зустрічний потік набігає знизу зі швидкістю `|V_z| = −V_z`).

Швидкість проходження повітря крізь площину ротора дорівнює абсолютній сумі швидкості спуску та власної індукованої швидкості: `U = |V_z + v_i|`.

Рівняння балансу кількості руху Главерта (Glauert, 1926) для вертикальної тяги:

```
T = 2 · ρ · A · |V_z + v_i| · v_i
```

Введемо безрозмірні параметри, поділивши всі швидкості на індуковану швидкість висіння `v_i0`:

```
V̂_z = V_z / v_i0
v̂_i = v_i / v_i0
```

Безрозмірне рівняння імпульсу набуває універсального вигляду:

```
1 = |V̂_z + v̂_i| · v̂_i
```

#### Розв'язок для набору висоти та зависання (V̂_z ≥ 0)
Потік спрямований строго зверху вниз відносно ротора (`V̂_z + v̂_i > 0`):

```
1 = (V̂_z + v̂_i) · v̂_i
v̂_i² + V̂_z · v̂_i − 1 = 0
v̂_i = −V̂_z / 2 + √( (V̂_z / 2)² + 1 )
```

При `V̂_z = 0` маємо `v̂_i = 1.0` (висіння). При швидкому наборі висоти (`V̂_z ≫ 1`) індукована швидкість асимптотично прямує до нуля: `v̂_i ≈ 1 / V̂_z`.

#### Розв'язок для режиму швидкого спуску / вітряного гальма (V̂_z ≤ −2)
Коли швидкість зниження перевищує подвійну швидкість висіння, зустрічний потік повністю долає струмінь ротора і проходить крізь диск знизу вгору (`V̂_z + v̂_i < 0`):

```
1 = −(V̂_z + v̂_i) · v̂_i
v̂_i² + V̂_z · v̂_i + 1 = 0
v̂_i = −V̂_z / 2 − √( (V̂_z / 2)² − 1 )
```

При `V̂_z = −2.0` маємо `v̂_i = 1.0`. При дуже швидкому падінні (`V̂_z → −∞`) індукована швидкість прямує до нуля: `v̂_i ≈ −1 / V̂_z`.

#### Математичний розрив у діапазоні −2 < V̂_z < 0 (Зона VRS)
Розглянемо дискримінант квадратного рівняння для спуску `D_disc = (V̂_z / 2)² − 1`.

У проміжку швидкостей зниження `-2 < V̂_z < 0` величина дискримінанта стає строго від'ємною:

```
(V̂_z / 2)² − 1 < 0   при  |V̂_z| < 2
```

Дійсних коренів рівняння не існує. Це математичний доказ того, що в діапазоні `-2 < V̂_z < 0` не існує стаціонарного одновимірного струменя. Потік не може визначитися, куди йому рухатися — вгору чи вниз — і згортається в нестаціонарні замкнені тороїдальні вихори.

### 3. Кусочно-поліноміальні моделі індукованої швидкості у зоні VRS

Для усунення розриву в алгоритмах симуляторів та систем керування використовують феноменологічні апроксимації, побудовані на основі експериментів у гідроканалах та аеродинамічних трубах (дані Вашизу, Волковича, Джонсона).

#### Кубічна модель Волковича (Wolkovitch, 1972)
Для інтервалу `-2.0 ≤ V̂_z ≤ 0` безрозмірна індукована швидкість апроксимується кубічним поліномом, який гладко зшиває розв'язок висіння в точці `V̂_z = 0` з розв'язком вітряка в точці `V̂_z = -2.0`:

```
v̂_i(V̂_z) = 1.0 + k_1 · V̂_z + k_2 · V̂_z² + k_3 · V̂_z³
```

Коефіцієнти визначаються з умов неперервності значень та похідних на межах, а також піку рециркуляції `v̂_i ≈ 1.5` при `V̂_z = −1.0`:

```
k_1 = −0.125
k_2 = −1.125
k_3 = −0.500
```

Покроковий розрахунок характерних станів:
- `V̂_z = 0.0` (висіння): `v̂_i = 1.000`
- `V̂_z = −0.5` (початок формування тороїда): `v̂_i = 1.0 + 0.0625 − 0.2813 + 0.0625 = 0.8438`
- `V̂_z = −1.0` (максимальна інтенсивність VRS): `v̂_i = 1.0 + 0.125 − 1.125 + 0.500 = 1.5000`
- `V̂_z = −1.5` (турбулентний розпад сліду): `v̂_i = 1.0 + 0.1875 − 2.5313 + 1.6875 = 1.3438`
- `V̂_z = −2.0` (межа вітряного гальма): `v̂_i = 1.0 + 0.2500 − 4.5000 + 4.0000 = 1.0000`

#### Просторова модель Лейшмана (Leishman, 2000) при косому обдуванні
Якщо літальний апарат має одночасно вертикальну швидкість `V_z` та горизонтальну швидкість `V_x`, тороїдальний вихор здувається в бік від площини ротора.

Введемо безрозмірну горизонтальну швидкість `V̂_x = V_x / v_i0`.

Загальне рівняння індукованого припливу в косому потоці розв'язується через результуючу швидкість крізь диск:

```
v̂_i = 1 / √( V̂_x² + (V̂_z + v̂_i)² )
```

У критичній області (`-2.0 < V̂_z < 0` та `V̂_x < 1.0`) діє двовимірна інтерполяція Лейшмана:

```
v̂_i,VRS(V̂_z, V̂_x)
= v̂_i,Wolkovitch(V̂_z) · (1 − V̂_x) + ( 1 / √( V̂_x² + V̂_z² ) ) · V̂_x
```

При досягненні горизонтальної швидкості `V̂_x ≥ 1.0` (для вертольотів це швидкість понад 15–20 вузлів) перший член повністю зникає (`1 − V̂_x ≤ 0`), вихорове кільце розривається, і ротор повертається до класичного стаціонарного косого обтікання Главерта.
