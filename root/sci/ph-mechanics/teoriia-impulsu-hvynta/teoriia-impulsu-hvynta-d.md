Квадрокоптер масою 1.5 кг із чотирма невеликими 5-дюймовими пропелерами (радіус диска `R = 0.0635` м) споживає у нерухомому висінні біля землі близько 240 Вт електричної потужності від акумулятора і повністю вичерпує заряд за 6–8 хвилин. Тим часом важкий транспортний вертоліт масою 12 000 кг із діаметром несучого гвинта 21 м зависає, витрачаючи близько 1400 кВт — тобто всього 116 Вт на кожен кілограм власної маси, що втричі ощадніше за малий дрон. Обидва апарати перебувають у стані спокою: їхня вертикальна координата не змінюється (`h = \text{const}`), корисна механічна робота над гравітаційним полем дорівнює нулю (`W = F · Δh = 0`), проте двигуни безупинно перетворюють енергію палива або батарей на тепло та рух навколишнього середовища.

Причина таких енергетичних витрат криється у природі повітряного середовища: повітря не є твердою опорою, об яку можна спертися без деформацій. Щоб утримувати апарат у повітрі проти сили тяжіння, гвинт змушений щосекунди захоплювати тонни нерухомого повітря, надавати йому швидкості донизу і скидати його у формі високошвидкісного струменя. Тяга гвинта — це реакція на темп зміни імпульсу (від лат. *impulsus* — поштовх, удар) цієї повітряної маси, а потужність — це темп накачування кінетичної енергії у сформований струмінь сліду.

### Модель актуаторного диска: ідеалізація рушія

Реальний повітряний гвинт або вертолітний ротор складається з кількох пружних лопатей складного геометричного скруту, які рубають повітря з високою швидкістю, утворюють локальні зриви потоку, генерують кінцеві вихори та закручують струмінь навколо осі обертання. Безпосередній розрахунок тривимірного турбулентного поля навколо таких лопатей вимагає чисельного інтегрування рівнянь Нав'є — Стокса на суперкомп'ютерах.

Проте базову фізичну межу ефективності висіння дозволяє знайти класична аналітична модель — концепція **актуаторного диска** (від англ. *actuator disk* — диск-виконавець, рушійний диск; від лат. *actuare* — приводити в дію). Реальний гвинт у ній замінюють нескінченно тонкою проникною поверхнею площею `A = π · R²`, крізь яку середовище протікає безперешкодно, зазнаючи стрибка статичного тиску.

Цю модель формулюють на основі кількох фундаментальних припущень:
1. **Нестисливість середовища.** Густина повітря `ρ` вважається сталою (`ρ = 1.225` кг/м³ за стандартних умов на рівні моря), оскільки швидкості струменя на висінні рідко перевищують 30–50 м/с (число Маха `M < 0.15`, де стисливістю можна знехтувати).
2. **Однорідність навантаження.** Стрибок тиску `Δp` та осьова швидкість `v_i` вважаються однаковими в усіх точках площини диска від комля до кінців лопатей.
3. **Відсутність тертя й в'язкості.** Повітря розглядається як ідеальна нестислива рідина: немає втрат на в'язкісний зсув та профільний опір лопатей.
4. **Відсутність закрутки потоку.** Диск додає повітрю суто осьовий імпульс униз; обертальний рух, зумовлений крутним моментом мотора, у класичній теорії відсутній.
5. **Усталеність та ізоляція.** Розглядається стаціонарний потік крізь чітко окреслену струминну трубку, оточену нерухомим повітрям із рівномірним атмосферним тиском `p₀`.

Історично ця модель виникла з потреби розрахунку перших суднових гребних гвинтів та вітряків; детальну історію того, як формувалися ці уявлення у працях класиків гідромеханіки, розкриває нарис про [розвиток теорії ідеального рушія Ренкіна — Фруда](root:ph-mechanics/teoriia-impulsu-hvynta/hist-rankine-froude.md).

![Струмна трубка ідеального актуаторного диска](/root/sci/ph-mechanics/teoriia-impulsu-hvynta/img/actuator-disk-streamtube.svg)
*Контрольний об'єм ідеального актуаторного диска на висінні: звуження струменя від площі диска A до A_w = A / 2 у сліді зі зростанням швидкості від v_i до 2·v_i.*

### Три закони збереження на струминній трубці

Для визначення тяги та швидкості потоку виділимо контрольний об'єм рідини, обмежений бічною поверхнею струминної трубки та трьома характерними поперечними перерізами вздовж осі течії `z`:
- **Переріз 0 (далеко перед диском, `z → -∞`):** повітря перебуває в стані спокою, початкова швидкість `v₀ = 0` (режим висіння апарата), статичний тиск дорівнює атмосферному `p₀`, площа струминної трубки необмежено велика (`A₀ → ∞`).
- **Переріз диска (`z = 0`):** повітря проходить крізь диск площею `A = π · R²` зі швидкістю `v_i` (індукована швидкість, від лат. *inductio* — наведення, спонукання). Безпосередньо над диском статичний тиск падає до значення `p⁻`, а відразу під диском стрибком зростає до `p⁺`.
- **Переріз сліду (далеко за диском, `z → +∞`):** струмінь повністю сформувався (зона стисненого сліду, або *vena contracta*), статичний тиск знову вирівнюється з навколишнім атмосферним `p₀`, швидкість потоку сягає максимального значення `w`, а площа стискається до `A_w`.

Запишімо для цього контрольного об'єму фундаментальні закони збереження механіки суцільних середовищ.

#### 1. Збереження маси (рівняння неперервності)

Через будь-який поперечний переріз струминної трубки за одну секунду проходить однакова маса повітря:

```
ṁ = ρ · A · v_i = ρ · A_w · w
```

де `ṁ` — секундна масова витрата повітря (кг/с). Звідси одразу випливає відношення площ перерізів:

```
A_w / A = v_i / w
```

Якщо швидкість у сліді `w` перевищує швидкість на диску `v_i`, то площа сліду `A_w` обов'язково менша за площу диска `A`: потік під гвинтом невблаганно звужується.

#### 2. Збереження імпульсу (інтегральна теорема кількості руху)

За другим законом Ньютона результуюча сила `T` (тяга), прикладена з боку диска до повітряного стовпа, дорівнює зміні кількості руху за одиницю часу між вихідним і вхідним перерізами контрольного об'єму:

```
T = ṁ · w − ṁ · v₀
= ṁ · w − ṁ · 0       [швидкість на нескінченності перед диском v₀ = 0]
= ṁ · w               [імпульсна тяга струменя]
= ρ · A · v_i · w     [підстановка масової витрати ṁ = ρ·A·v_i]
```

За третім законом Ньютона з точно такою самою за модулем силою `T`, спрямованою вертикально вгору, повітряний потік штовхає сам актуаторний диск.

#### 3. Збереження енергії (рівняння Бернуллі для ліній течії)

Рівняння Бернуллі виражає сталість повної енергії вздовж лінії течії в ідеальному потоці. Однак застосувати його безпосередньо «наскрізь» через диск не можна: обертові лопати диска виконують механічну роботу над потоком, стрибкоподібно вливаючи в нього енергію. Тому потік розбивають на дві окремі ділянки — до диска і після диска.

Для зони перед диском (від нескінченності з тиском `p₀` та нульовою швидкістю до верхньої грані диска з тиском `p⁻` та швидкістю `v_i`):

```
p₀ + ½ · ρ · 0² = p⁻ + ½ · ρ · v_i²
p⁻ = p₀ − ½ · ρ · v_i²     [статичний тиск безпосередньо над диском]
```

Для зони за диском (від нижньої грані диска з тиском `p⁺` та швидкістю `v_i` до далекого сліду з атмосферним тиском `p₀` та швидкістю `w`):

```
p⁺ + ½ · ρ · v_i² = p₀ + ½ · ρ · w²
p⁺ = p₀ + ½ · ρ · w² − ½ · ρ · v_i²     [статичний тиск безпосередньо під диском]
```

Стрибок статичного тиску `Δp` на самому диску дорівнює різниці тисків на його нижній та верхній гранях:

```
Δp = p⁺ − p⁻
= (p₀ + ½ · ρ · w² − ½ · ρ · v_i²) − (p₀ − ½ · ρ · v_i²)     [підстановка p⁺ та p⁻]
= ½ · ρ · w²                                                 [скорочення p₀ та кінетичного члена ½·ρ·v_i²]
```

Тяга диска за визначенням тиску дорівнює інтегралу стрибка тиску по всій площі `A`:

```
T = Δp · A = ½ · ρ · A · w²
```

*Осьовий розподіл швидкості й тиску: плавний неперервний розгін повітря v(z) та стрибок статичного тиску Δp = 2·ρ·v_i² у площині диска.*

### Походження подвоєння швидкості: `w = 2 · v_i`

Тепер ми маємо два незалежних вирази для однієї й тієї самої сили тяги `T` — з імпульсного рівняння та з інтеграла тиску Бернуллі. Прирівняймо їх:

```
ρ · A · v_i · w = ½ · ρ · A · w²     [рівність імпульсної та тискової тяги]
v_i · w = ½ · w²                     [поділили обидві частини на ρ·A]
v_i = ½ · w                          [поділили обидві частини на w ≠ 0]
w = 2 · v_i                          [теорема Фруда: швидкість у сліді вдвічі більша за індуковану]
```

Цей висновок — фундаментальний закон теорії ідеального рушія: **швидкість повітря у сформованому сліді рівно вдвічі перевищує індуковану швидкість безпосередньо в площині гвинта**.

Фізичний зміст цієї двійки надзвичайно наочний. Половину загального приросту кінетичної енергії потік отримує ще **до** диска: всмоктувальна дія розрідження `p⁻ < p₀` розганяє повітря від стану спокою `v = 0` до швидкості `v_i`. На самому диску швидкість потоку залишається неперервною (`v_i`), але статичний тиск миттєво підскакує на величину `Δp`. Другу половину розгону — від `v_i` до `2 · v_i` — повітря здійснює вже **під** диском, де надлишковий тиск `p⁺ > p₀` проштовхує струмінь уперед, поки тиск на його межах не зрівняється з атмосферним.

Звідси ж випливає коефіцієнт стиснення струменя (звуження сліду):

```
A_w = A · (v_i / w) = A · (v_i / (2 · v_i)) = A / 2
```

Площа кінцевого сліду під завислим гвинтом зменшується рівно вдвічі (`A_w = 0.5 · A`), а радіус струменя звужується до `R_w = R / √2 ≈ 0.707 · R`.

> 🔧 **Навіщо це.** Коли інженер вимірює анемометром або трубкою Піто потік під квадрокоптером, покази приладу залежать від відстані до пропелера. Безпосередньо біля площини обертання швидкість дорівнює `v_i`, а на відстані одного-двох діаметрів униз струмінь звужується і розганяється до `2 · v_i`. Саме ця подвоєна швидкість струменя визначає силу обдування корисного навантаження (камер, датчиків), динамічний натиск на підстильну поверхню при посадці та інтенсивність роздування пилу з ґрунту.

### Формули ідеальної тяги та індукованої потужності

Підставивши співвідношення `w = 2 · v_i` в імпульсне рівняння тяги, отримуємо точну залежність сили тяги від індукованої швидкості:

```
T = ṁ · w
= (ρ · A · v_i) · (2 · v_i)     [підстановка ṁ та w = 2·v_i]
= 2 · ρ · A · v_i²              [ідеальна статична тяга актуаторного диска]
```

Обернувши цю формулу, знаходимо індуковану швидкість, необхідну для створення заданої тяги `T` гвинтом площею `A`:

```
v_i = √( T / (2 · ρ · A) )
```

Корисна механічна потужність, яку актуаторний диск мусить передавати повітряному потоку за секунду, дорівнює швидкості приросту кінетичної енергії струменя. Оскільки на вході швидкість нульова, а на виході `w = 2 · v_i`, потужність дорівнює:

```
P_i = ṁ · (½ · w² − ½ · v₀²)
= (ρ · A · v_i) · (½ · (2 · v_i)²)     [підстановка ṁ та w = 2·v_i]
= ρ · A · v_i · (2 · v_i²)             [піднесення до квадрата і множення на ½]
= 2 · ρ · A · v_i³                     [потужність через куб швидкості]
= (2 · ρ · A · v_i²) · v_i             [групування множників]
= T · v_i                              [ідеальна індукована потужність висіння]
```

Підставивши вираз для `v_i` через тягу, дістаємо фундаментальну формулу **ідеальної індукованої потужності висіння** (англ. *ideal induced hover power*):

```
P_i = T · √( T / (2 · ρ · A) )
= T · T^(1/2) / √(2 · ρ · A)     [розкриття кореня]
= T^(3/2) / √(2 · ρ · A)         [степінь 3/2 у чисельнику]
= √( T³ / (2 · ρ · A) )          [еквівалентний запис під одним коренем]
```

Ця формула містить два найважливіших інженерних висновки:
1. **Нелінійне зростання від тяги:** Потужність зростає пропорційно `T^(1.5)`. Якщо маса апарата зростає вдвічі, то для його утримання в повітрі на тому самому гвинті потрібно не вдвічі, а в `2^(1.5) = 2 · √2 ≈ 2.83` раза більше потужності!
2. **Зниження від площі:** Потужність обернено пропорційна кореню з площі диска `√A` (тобто радіусу `R` або діаметру `D`). Що більший пропелер створює ту саму тягу `T`, то менше енергії він вимагає щосекунди.

```
P_i ∝ 1 / R
```

### Навантаження на диск (Disk Loading) та питома тяга

Щоб порівнювати між собою літальні апарати різних вагових категорій та геометричних розмірів, вводять питому характеристику — **навантаження на диск** (англ. *Disk Loading*, `DL`):

```
DL = T / A
```

Навантаження на диск вимірюється в паскалях (Па) або ньютонах на квадратний метр (Н/м²) і показує середній стрибок тиску, який диск створює на одиницю своєї площі (`DL = Δp = 2 · ρ · v_i²`).

Виразимо індуковану швидкість через навантаження на диск:

```
v_i = √( (T / A) / (2 · ρ) ) = √( DL / (2 · ρ) )
```

Тепер введемо міру аеродинамічної досконалості рушія — **питому тягу** (англ. *Power Loading*, `PL`), тобто відношення створеної сили тяги до витраченої потужності:

```
PL_ideal = T / P_i
= T / (T · v_i)     [підстановка P_i = T · v_i]
= 1 / v_i           [питома тяга дорівнює оберненій індукованій швидкості]
= √( 2 · ρ / DL )   [питома тяга через навантаження на диск]
```

Питома тяга вимірюється в Н/Вт (в інженерній практиці частіше використовують Н/кВт або грами тяги на ват потужності, г/Вт, де `1 Н/Вт ≈ 102 г/Вт`).

З рівності `PL_ideal = 1 / v_i = √(2 · ρ / DL)` випливає головний закон енергетики вертикального польоту: **що менше навантаження на диск (що менша індукована швидкість потоку), то вища питома тяга і то менше ватів потрібно на кожен грам піднятої маси**.

![Питома тяга залежно від навантаження на диск](/root/sci/ph-mechanics/teoriia-impulsu-hvynta/img/power-loading-vs-disk-loading.svg)
*Залежність питомої тяги PL від навантаження на диск DL: виграш великого діаметра ротора у висінні для вертольотів порівняно з високошвидкісними дронами та СВВП.*

Надання повітрю такої шаленої швидкості вимагає гігантської потужності двигуна (`P ∝ v_i³`).

### Чому великий діаметр кардинально підвищує ККД

Розглянемо практичну інженерну ситуацію. Нехай нам потрібно забезпечити сумарну силу тяги `T = 40` Н (утримання в повітрі дрона масою близько 4.08 кг).

**Варіант А (дрон на 5-дюймових гвинтах, 4 штуки):**
Радіус кожного гвинта `R = 0.0635` м, площа одного диска `A₁ = π · (0.0635)² ≈ 0.01267` м², сумарна площа чотирьох дисків `A_total = 4 · 0.01267 ≈ 0.0507` м².

```
навантаження на диск:   DL_A = T / A_total = 40 / 0.0507 ≈ 789 Н/м²
індукована швидкість:   v_i_A = √( 789 / (2 · 1.225) ) ≈ 17.9 м/с
ідеальна потужність:    P_i_A = T · v_i_A = 40 · 17.9 ≈ 716 Вт
питома тяга:            PL_A = 40 / 716 ≈ 0.0558 Н/Вт  (5.7 г/Вт)
```

**Варіант Б (дрон на 15-дюймових гвинтах, 4 штуки):**
Радіус кожного гвинта `R = 0.1905` м (у 3 рази більший), площа одного диска `A₁ = π · (0.1905)² ≈ 0.1140` м², сумарна площа чотирьох дисків `A_total = 4 · 0.1140 ≈ 0.4560` м² (у 9 разів більша).

```
навантаження на диск:   DL_B = T / A_total = 40 / 0.4560 ≈ 87.7 Н/м²
індукована швидкість:   v_i_B = √( 87.7 / (2 · 1.225) ) ≈ 5.98 м/с  (втричі менша)
ідеальна потужність:    P_i_B = T · v_i_B = 40 · 5.98 ≈ 239 Вт       (втричі менша)
питома тяга:            PL_B = 40 / 239 ≈ 0.167 Н/Вт   (17.1 г/Вт)
```

Збільшення діаметра пропелерів у 3 рази зменшило необхідну потужність висіння **в 3 рази** (з 716 Вт до 239 Вт) за абсолютно однакової підйомної сили 40 Н.

Фізичне правило тут незмінне: **тяга пропорційна першому степеню швидкості відкиду (`T = ṁ · w`), а енергія — квадрату швидкості (`E_k = ½ · ṁ · w²`)**.
Щоб отримати тягу максимально дешево, потрібно захопити якомога **більшу масу** повітря `ṁ` і надати їй якомога **меншого приросту швидкості** `w`.

> 🔧 **Навіщо це.** Конструктори сільськогосподарських дронів-обприскувачів та важких коптерів завжди борються за максимальний діаметр гвинтів, який тільки дозволяє розмір рами під час транспортування. Перехід з 22-дюймових пропелерів на 30-дюймові за тієї самої корисної вантажопідйомності дозволяє збільшити час польоту на 35–45% без зміни маси акумуляторів.

### Безрозмірні коефіцієнти та аеродинамічна подоба

В аеродинаміці гвинтів і вертолітних роторів абсолютні фізичні величини приводять до безрозмірної форми за швидкістю обертання кінців лопатей `Ω · R` (де `Ω = 2π · n` — кутова швидкість обертання в рад/с, `n` — оберти за секунду):

1. **Коефіцієнт тяги (`C_T`):**
   ```
   C_T = T / (ρ · A · (Ω · R)²)
   ```
2. **Коефіцієнт потужності (`C_P`):**
   ```
   C_P = P / (ρ · A · (Ω · R)³)
   ```
3. **Безрозмірна індукована швидкість (коефіцієнт припливу, `λ_i`):**
   ```
   λ_i = v_i / (Ω · R)
   ```

Виразимо коефіцієнт тяги через коефіцієнт припливу за формулою імпульсної теорії `T = 2 · ρ · A · v_i²`:

```
C_T = (2 · ρ · A · v_i²) / (ρ · A · (Ω · R)²)
= 2 · (v_i / (Ω · R))²     [скорочення ρ·A]
= 2 · λ_i²                 [зв'язок C_T та коефіцієнта припливу]
```

Звідси індукована швидкість у безрозмірному вигляді дорівнює:

```
λ_i = √( C_T / 2 )
```

Ідеальний коефіцієнт індукованої потужності:

```
C_Pi = P_i / (ρ · A · (Ω · R)³)
= (T · v_i) / (ρ · A · (Ω · R)³)     [підстановка P_i = T · v_i]
= [T / (ρ · A · (Ω · R)²)] · [v_i / (Ω · R)]
= C_T · λ_i                          [добуток коефіцієнта тяги на коефіцієнт припливу]
= C_T · √( C_T / 2 )                 [підстановка λ_i = √(C_T/2)]
= C_T^(3/2) / √2                     [ідеальний коефіцієнт потужності за теорією імпульсу]
```

### Figure of Merit (FM): реальний гвинт проти ідеального

Теорія актуаторного диска дає теоретичну нижню межу потужності `P_i` (100% ККД перетворення енергії в осьовий імпульс). Реальний гвинт завжди споживає більше потужності на валу двигуна (`P_shaft > P_i`).

Ступінь досконалості гвинта на режимі висіння оцінюють безрозмірним коефіцієнтом, який називають **фігурою якості** або коефіцієнтом аеродинамічної досконалості висіння (англ. *Figure of Merit*, `FM`):

```
FM = P_ideal / P_actual = P_i / P_shaft = C_Pi / C_P_actual
```

де `P_i = T^(3/2) / √(2 · ρ · A)` — ідеальна індукована потужність за теорією імпульсу, а `P_shaft` — реальна механічна потужність на валу приводу.

![Структура втрат та Figure of Merit](/root/sci/ph-mechanics/teoriia-impulsu-hvynta/img/figure-of-merit-breakdown.svg)
*Розклад потужності на валу реального ротора: ідеальна індукована потужність, кінцеві втрати й профільний опір лопатей у формуванні коефіцієнта якості FM.*

Чому `FM` реальних гвинтів завжди менший за одиницю (`FM < 1`)? Реальна потужність на валу складається з трьох головних компонентів:

```
P_shaft = P_ind_real + P_0 = κ · P_i + P_0
```

1. **Індуковані втрати на нерівномірність та кінцеві вихори (`κ · P_i`):**
   Реальний гвинт має дискретну кількість лопатей (2, 3, 4 тощо). На кінцях лопатей повітря перетікає з зони підвищеного тиску знизу в зону розрідження зверху, утворюючи потужні кінцеві вихрові джгути (вихрова пелена Прандтля). Це призводить до нерівномірного розподілу індукованої швидкості по радіусу та втрати ефективної площі диска (фактор кінцевих втрат).
   Крім того, реактивний момент гвинта закручує потік (виникає тангенціальна швидкість у струмені), на що витрачається додаткова енергія.
   Усі ці ефекти враховують коефіцієнтом індукованих втрат `κ` (зазвичай `κ ≈ 1.10 … 1.20`).
2. **Профільні втрати лопатей (`P_0`):**
   Лопаті рухаються у в'язкому повітрі й зазнають профільного опору тертя та форми. Профільна потужність залежить від швидкості обертання кінців лопатей `Ω · R`, середнього коефіцієнта профільного опору `C_d0` та коефіцієнта заповнення диска `σ` (англ. *solidity*, відношення сумарної площі лопатей до площі диска `A`, `σ = (N_blades · c) / (π · R)`, де `c` — хорда лопаті):
   ```
   P_0 = ⅛ · ρ · A · (Ω · R)³ · σ · C_d0
   ```
   У безрозмірному вигляді коефіцієнт профільної потужності дорівнює:
   ```
   C_P0 = ⅛ · σ · C_d0
   ```
   Профільна потужність майже не залежить від створюваної тяги, але росте строго пропорційно кубу кутової швидкості `Ω³`.

Запишімо повний вираз для Figure of Merit через безрозмірні коефіцієнти:

```
FM = C_Pi / (κ · C_Pi + C_P0)
= (C_T^(3/2) / √2) / [ κ · (C_T^(3/2) / √2) + ⅛ · σ · C_d0 ]
= 1 / [ κ + (⅛ · σ · C_d0 · √2) / C_T^(3/2) ]
```

З цієї формули чітко видно поведінку гвинта на різних режимах:
- **Мала тяга (`C_T → 0`):** знаменник прямує до нескінченності через малий `C_T^(3/2)`, тому `FM → 0`. Лопаті обертаються на високих обертах, долаючи опір тертя `P_0`, але створюють мізерну тягу: енергія мотора марнується на перемішування повітря.
- **Оптимальна тяга (`C_T / σ ≈ 0.08 … 0.12`):** індукована потужність `P_i` значно переважає профільну `P_0`, і `FM` сягає свого максимуму `FM_max ≈ 0.75 … 0.82`.
- **Перевантаження лопатей (`C_T / σ > 0.14 … 0.18`):** кути атаки лопатей стають надто великими, починається зрив потоку (аеродинамічне звалювання), профільний опір `C_d0` різко підскакує в 5–10 разів, і `FM` знову стрімко падає.

Типові діапазони Figure of Merit у сучасній авіації та робототехніці:
- Дешеві литі пластикові пропелери малих дронів: `FM ≈ 0.48 … 0.58`
- Високоякісні карбонові пропелери мультикоптерів: `FM ≈ 0.65 … 0.74`
- Несучі гвинти сучасних вертольотів: `FM ≈ 0.75 … 0.82`
- Теоретична верхня межа для ізольованого ротора: `FM_max ≈ 0.84 … 0.86`

### Фізичні обмеження: закрутка, кінцеві вихори та швидкість звуку

Реальний гвинт відрізняється від ідеального актуаторного диска трьома критичними фізичними явищами:

#### 1. Закрутка струменя (Swirl losses)
Щоб крутити гвинт, двигун прикладає крутний момент `Q = P / Ω`. За третім законом Ньютона гвинт діє на повітря з таким самим моментом, змушуючи струмінь обертатися навколо осі з тангенціальною швидкістю `v_θ(r)`.
Кінетична енергія цього обертання не створює вертикальної тяги й безповоротно втрачається в сліді. Для високошвидкісних гвинтів втрати на закрутку становлять 3–8% загальної потужності.
Саме тому у високоефективних системах застосовують **співвісні гвинти протилежного обертання** (англ. *coaxial contra-rotating rotors*): нижній гвинт обертається у зворотний бік, розкручує потік назад до строго осьового і повертає енергію закрутки в корисну тягу, підвищуючи сумарний ККД системи на 5–10%.

#### 2. Кінцеві вихори (Prandtl tip loss)
На самому кінчику лопаті `r = R` тиск знизу й зверху миттєво вирівнюється, через що кінцева ділянка лопаті перестає створювати підйомну силу. Людвіг Прандтль показав, що ефективний радіус диска через сходження вихрової пелени зменшується до величини `R_eff = B_tip · R`, де коефіцієнт кінцевих втрат для дволопатевого гвинта зазвичай становить `B_tip ≈ 0.93 … 0.96`. Ефективна площа диска падає пропорційно `B_tip²`, що підвищує локальне навантаження на диск і додає 5–10% індукованих втрат.

#### 3. Стисливість повітря та хвильовий опір кінців лопатей
Лінійна швидкість перерізу лопаті росте лінійно з радіусом: `v_tip = Ω · R`. Якщо діаметр гвинта великий або оберти надто високі, кінці лопатей наближаються до швидкості звуку (`a ≈ 340` м/с).
Коли число Маха на кінчику лопаті сягає `M_tip = (Ω · R) / a > 0.65 … 0.75`, на верхній поверхні профілю формуються локальні надзвукові зони та ударні хвилі (хвильовий криз). Це викликає лавиноподібний ріст профільного опору `C_d0` у кілька разів і супроводжується сильним акустичним ревом.
Саме тому швидкість кінців лопатей у вертольотах та промислових дронах жорстко обмежують діапазоном `v_tip ≈ 180 … 220` м/с (число Маха `M_tip ≈ 0.55 … 0.65`).

### Робота гвинта при вертикальному підйомі та ефект землі

Теорія імпульсу легко узагальнюється на випадок осьового підйому апарата вгору з постійною вертикальною швидкістю `V_c` (англ. *climb velocity*).
У цьому режимі повітря набігає на диск зі швидкістю `V_c`, а повна швидкість протікання крізь площину диска становить `v = V_c + v_i`.

Рівняння тяги набуває вигляду:

```
T = ṁ · (w − 0) = ρ · A · (V_c + v_i) · (2 · v_i)
```

Розв'язуючи це квадратне рівняння відносно індукованої швидкості `v_i`, дістаємо формулу Глауерта для підйому:

```
v_i = −½ · V_c + √( (½ · V_c)² + T / (2 · ρ · A) )
= −½ · V_c + √( (½ · V_c)² + v_i0² )
```

де `v_i0 = √(T / (2 · ρ · A))` — індукована швидкість на чистому висінні (`V_c = 0`).
Зі зростанням швидкості набору висоти `V_c` індукована швидкість `v_i` монотонно зменшується, оскільки більша маса повітря прокачується крізь диск завдяки набіганню самого апарата.

#### Ефект близькості землі (In-Ground Effect, IGE)

Коли апарат зависає на малій висоті над твердою поверхнею (висота осі гвинта над ґрунтом `h` менша за діаметр ротора `D`, `h / D < 1.0`), струминна трубка під диском не може вільно стискатися і розширюється врізнобіч уздовж ґрунту.
Це створює під ротором повітряну подушку підвищеного статичного тиску. Згідно з класичною формулою Чізмана — Беннетта (англ. *Cheeseman & Bennett*), співвідношення між потужністю висіння в ефекті землі `P_IGE` та поза зоною впливу землі `P_OGE` (*Out of Ground Effect*) описується виразом:

```
P_IGE / P_OGE = 1 / [ 1 + (R / (4 · h))² ]
```

На висоті `h = 0.5 · R` (чверть діаметра над ґрунтом) необхідна потужність висіння знижується на 20–25%! Це дозволяє перевантаженим вертольотам та важким дронам виконувати зліт за наявності горизонтального розгону «по-літаковому» в межах екранної подушки.

### Розрахунок параметрів висіння на C та C++

Напишімо інженерну програму для розрахунку параметрів висіння: індукованої швидкості, навантаження на диск, ідеальної та реальної потужності, а також Figure of Merit для різних конфігурацій пропелерів.

```c
#include <stdio.h>
#include <math.h>
#include <stdbool.h>

#define AIR_DENSITY_SEA_LEVEL 1.225f /* кг/м³ */
#define PI_F                  3.14159265358979323846f
#define GRAVITY_M_S2          9.80665f

typedef struct {
    float thrust_newtons;    /* необхідна тяга одного гвинта, Н */
    float radius_meters;     /* радіус гвинта, м */
    float air_density;       /* густина повітря, кг/м³ */
    float figure_of_merit;   /* очікуваний FM (0.50..0.85) */
} HoverInput;

typedef struct {
    float disk_area_m2;      /* площа диска A, м² */
    float disk_loading_pa;   /* навантаження на диск DL = T/A, Па */
    float induced_vel_m_s;   /* індукована швидкість на диску v_i, м/с */
    float wake_vel_m_s;      /* швидкість у сліді w = 2*v_i, м/с */
    float ideal_power_watts; /* ідеальна індукована потужність P_i, Вт */
    float actual_shaft_watts;/* реальна механічна потужність P_shaft, Вт */
    float power_loading_n_kw;/* питома тяга, Н/кВт */
    float power_loading_g_w; /* питома тяга, г/Вт */
} HoverOutput;

bool calculate_hover_performance(const HoverInput* in, HoverOutput* out) {
    if (!in || !out) return false;
    if (in->thrust_newtons <= 0.0f || in->radius_meters <= 0.0f) return false;
    if (in->air_density <= 0.0f || in->figure_of_merit <= 0.0f || in->figure_of_merit > 1.0f) return false;

    float A = PI_F * in->radius_meters * in->radius_meters;
    float T = in->thrust_newtons;
    float rho = in->air_density;

    float DL = T / A;
    /* v_i = sqrt( T / (2 * rho * A) ) */
    float v_i = sqrtf(T / (2.0f * rho * A));
    float w = 2.0f * v_i;

    /* P_i = T * v_i */
    float P_ideal = T * v_i;
    float P_shaft = P_ideal / in->figure_of_merit;

    float PL_N_kW = (T / P_shaft) * 1000.0f;
    float PL_g_W = (T / (P_shaft * GRAVITY_M_S2)) * 1000.0f;

    out->disk_area_m2 = A;
    out->disk_loading_pa = DL;
    out->induced_vel_m_s = v_i;
    out->wake_vel_m_s = w;
    out->ideal_power_watts = P_ideal;
    out->actual_shaft_watts = P_shaft;
    out->power_loading_n_kw = PL_N_kW;
    out->power_loading_g_w = PL_g_W;

    return true;
}

int main(void) {
    /* Порівняння трьох конфігурацій для створення тяги T = 10 Н (на один мотор) */
    const char* names[] = {
        "5-дюймовий гоночний гвинт (R = 6.35 см)",
        "15-дюймовий дрон (R = 19.05 см)",
        "30-дюймовий вантажний ротор (R = 38.1 см)"
    };
    float radii[] = { 0.0635f, 0.1905f, 0.3810f };
    float fms[]   = { 0.55f,   0.68f,   0.75f };

    printf("=== Розрахунок висіння за теорією імпульсу (T = 10.0 Н на гвинт) ===\n\n");

    for (int i = 0; i < 3; ++i) {
        HoverInput input = {
            .thrust_newtons = 10.0f,
            .radius_meters = radii[i],
            .air_density = AIR_DENSITY_SEA_LEVEL,
            .figure_of_merit = fms[i]
        };
        HoverOutput res;

        if (calculate_hover_performance(&input, &res)) {
            printf("[%s]\n", names[i]);
            printf("  Площа диска A:          %.4f м²\n", res.disk_area_m2);
            printf("  Навантаження на диск DL: %6.1f Па (Н/м²)\n", res.disk_loading_pa);
            printf("  Швидкість на диску v_i:  %5.2f м/с (у сліді w: %.2f м/с)\n", res.induced_vel_m_s, res.wake_vel_m_s);
            printf("  Ідеальна потужність P_i: %6.1f Вт\n", res.ideal_power_watts);
            printf("  Потужність на валу P:   %6.1f Вт (FM = %.2f)\n", res.actual_shaft_watts, fms[i]);
            printf("  Питома тяга:             %5.1f Н/кВт (%.2f г/Вт)\n\n", res.power_loading_n_kw, res.power_loading_g_w);
        }
    }

    return 0;
}
```

```cpp
#include <iostream>
#include <iomanip>
#include <numbers>
#include <cmath>
#include <string_view>
#include <span>
#include <expected>

struct HoverSpec {
    std::string_view label;
    float thrust_newtons;    // необхідна тяга T, Н
    float radius_meters;     // радіус диска R, м
    float air_density;       // густина середовища rho, кг/м³
    float figure_of_merit;   // коефіцієнт досконалості FM (0 < FM <= 1)
};

struct HoverMetrics {
    float disk_area_m2;
    float disk_loading_pa;
    float induced_velocity_m_s;
    float wake_velocity_m_s;
    float ideal_power_watts;
    float actual_shaft_watts;
    float power_loading_n_per_kw;
    float power_loading_grams_per_watt;
};

enum class ComputeError {
    InvalidThrust,
    InvalidGeometry,
    InvalidDensity,
    InvalidFigureOfMerit
};

[[nodiscard]] constexpr std::expected<HoverMetrics, ComputeError>
evaluate_hover(const HoverSpec& spec) noexcept {
    if (spec.thrust_newtons <= 0.0f) return std::unexpected(ComputeError::InvalidThrust);
    if (spec.radius_meters <= 0.0f) return std::unexpected(ComputeError::InvalidGeometry);
    if (spec.air_density <= 0.0f) return std::unexpected(ComputeError::InvalidDensity);
    if (spec.figure_of_merit <= 0.0f || spec.figure_of_merit > 1.0f) {
        return std::unexpected(ComputeError::InvalidFigureOfMerit);
    }

    constexpr float pi = std::numbers::pi_v<float>;
    constexpr float g_accel = 9.80665f;

    const float area = pi * spec.radius_meters * spec.radius_meters;
    const float disk_loading = spec.thrust_newtons / area;
    
    // v_i = sqrt( T / (2 * rho * A) )
    const float v_induced = std::sqrt(spec.thrust_newtons / (2.0f * spec.air_density * area));
    const float v_wake = 2.0f * v_induced;

    // P_i = T * v_i
    const float p_ideal = spec.thrust_newtons * v_induced;
    const float p_actual = p_ideal / spec.figure_of_merit;

    const float pl_n_kw = (spec.thrust_newtons / p_actual) * 1000.0f;
    const float pl_g_w = (spec.thrust_newtons / (p_actual * g_accel)) * 1000.0f;

    return HoverMetrics{
        .disk_area_m2 = area,
        .disk_loading_pa = disk_loading,
        .induced_velocity_m_s = v_induced,
        .wake_velocity_m_s = v_wake,
        .ideal_power_watts = p_ideal,
        .actual_shaft_watts = p_actual,
        .power_loading_n_per_kw = pl_n_kw,
        .power_loading_grams_per_watt = pl_g_w
    };
}

void print_comparison_table(std::span<const HoverSpec> specs) {
    std::cout << std::fixed << std::setprecision(2);
    std::cout << "========================================================================================\n";
    std::cout << std::left << std::setw(32) << "Конфігурація ротора"
              << std::right << std::setw(10) << "D (дюйм)"
              << std::setw(12) << "DL (Па)"
              << std::setw(12) << "v_i (м/с)"
              << std::setw(12) << "P_sha (Вт)"
              << std::setw(14) << "PL (г/Вт)\n";
    std::cout << "========================================================================================\n";

    for (const auto& spec : specs) {
        auto result = evaluate_hover(spec);
        if (!result) {
            std::cerr << "Помилка розрахунку для " << spec.label << "\n";
            continue;
        }

        const auto& m = *result;
        const float diam_inches = (spec.radius_meters * 2.0f) / 0.0254f;

        std::cout << std::left << std::setw(32) << spec.label
                  << std::right << std::setw(10) << diam_inches
                  << std::setw(12) << m.disk_loading_pa
                  << std::setw(12) << m.induced_velocity_m_s
                  << std::setw(12) << m.actual_shaft_watts
                  << std::setw(14) << m.power_loading_grams_per_watt
                  << "\n";
    }
    std::cout << "========================================================================================\n";
}

int main() {
    constexpr float rho_std = 1.225f;
    constexpr float target_thrust = 10.0f; // 10 Н на ротор (~1.02 кг тяги)

    const HoverSpec fleet[] = {
        { "FPV Racing (5\")",          target_thrust, 0.0635f, rho_std, 0.55f },
        { "Cinelifter (8\")",          target_thrust, 0.1016f, rho_std, 0.60f },
        { "DJI Commercial (15\")",     target_thrust, 0.1905f, rho_std, 0.68f },
        { "Heavy-Lift Agras (30\")",   target_thrust, 0.3810f, rho_std, 0.75f },
        { "UAV Helicopter (60\")",     target_thrust, 0.7620f, rho_std, 0.80f }
    };

    print_comparison_table(fleet);
    return 0;
}
```
