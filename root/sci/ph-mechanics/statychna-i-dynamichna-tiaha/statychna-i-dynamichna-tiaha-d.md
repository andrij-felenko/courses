Коли безпілотний літак або FPV-дрон закріплюють на нерухомому випробувальному стенді й дають повний газ, тензодатчик упевнено фіксує максимальне зусилля — наприклад, 25 ньютонів (близько 2.55 кгс). Пропелер люто гуде, відкидаючи тугий струмінь повітря зі стану повного спокою, амперметр показує піковий струм, а силовий акумулятор швидко нагрівається. Але варто відпустити апарат у небо й розігнати його на прямій до швидкості 100 км/год, як реальна сила, що штовхає дрон уперед, несподівано падає вдвічі, а на швидкості 140 км/год зникає майже до нуля. Якщо ж розігнати літак у крутому пікіруванні ще швидше, той самий пропелер, що щойно тягнув уперед, раптом стає аеродинамічним гальмом, яке закручує мотор зустрічним потоком і сповільнює падіння.

Оця різниця між силою на нерухомому стенді та тягою у реальному швидкісному польоті — це не втрата потужності двигуна чи дефект електроніки, а фундаментальний закон перерозподілу векторів швидкості на профілі лопаті.

### Статичний режим: максимальний перепад швидкості на місці

Статичною тягою (англ. *static thrust*, від грец. *statikos* — «нерухомий») називають силу упору, яку створює повітряний гвинт за нульової швидкості поступального руху відносно навколишнього середовища (`V₀ = 0`). Це типовий стан силової установки в трьох практичних сценаріях: на випробувальному стенді, у момент старту літака перед початком розбігу смугою та під час нерухомого зависання мультиротора в штиль.

У нерухомому повітрі набігаючого зустрічного потоку немає. Щоб створити тягу `T`, гвинт мусить самостійно всмоктувати спокійне повітря з усього навколишнього простору, протягувати його крізь площину обертання диска площею `A = π · R²` і формувати звужений вихідний струмінь. Згідно з теоремою імпульсів, тяга дорівнює масовій секундній витраті захопленого повітря `ṁ`, помноженій на швидкість його відкидання в кінцевому сліді `w`:

```
T_stat = ṁ · w
```

Безпосередньо у площині диска повітря рухається зі швидкістю, яку називають **статичною індукованою швидкістю** `v_i0` (від лат. *inductio* — «наведення»). В ідеальній імпульсній теорії повний приріст швидкості у віддаленому струмені становить рівно вдвічі більше: `w = 2 · v_i0`. Масова витрата крізь диск дорівнює `ṁ = ρ · A · v_i0`, де `ρ` — густина повітря (приблизно 1.225 кг/м³ на рівні моря). Підставивши ці величини, дістаємо класичну формулу статичної тяги:

```
T_stat = ( ρ · A · v_i0 ) · ( 2 · v_i0 ) = 2 · ρ · A · v_i0²
```

Звідси індукована швидкість у площині диска на висінні виражається суто через питоме навантаження на площу `T / A`:

```
v_i0 = √( T_stat / ( 2 · ρ · A ) )
```

На нерухомому стенді ця швидкість відносно невелика — зазвичай від 8 до 20 м/с для типових безпілотників. А це означає, що приплив повітря вздовж осі обертання мінімальний. Лопать, що обертається з кутовою швидкістю `ω = 2·π·n` (де `n` — кількість обертів за секунду), зустрічає потік майже чисто перпендикулярно до осі свого руху.

```
u(r) = ω · r = 2 · π · n · r                      [колова швидкість перерізу]
```

Оскільки колова швидкість `u(r)` значно перевищує слабке підсмоктування `v_i0`, кут набігання результуючого потоку `φ` до площини обертання виявляється дуже малим:

```
tan φ_stat ≈ v_i0 / ( 2 · π · n · r )
```

Аеродинамічний переріз лопаті виставлений конструктором під кутом установки `β` (pitch angle). Ефективний кут атаки `α` (angle of attack), під яким повітря насправді обтікає криловий профіль лопаті, дорівнює геометричній різниці:

```
α_stat = β − φ_stat
```

Оскільки `φ_stat` у нерухомому повітрі є мінімальним, **ефективний кут атаки `α_stat` у статиці досягає свого абсолютного максимуму**. За таких умов профіль лопаті генерує найвищий можливий коефіцієнт підіймальної сили `C_L`. Ця підіймальна сила спрямована майже суто вперед уздовж осі валу, забезпечуючи рекордні покази тяги на вагах стенду.

> 🔧 **Навіщо це.** Статична тяга — головний орієнтир для розрахунку зависання мультикоптерів і перевірки стартового тягоозброєння літаків (TWR, *thrust-to-weight ratio*). Якщо для відриву важкого гексакоптера від землі сумарна вага апарата становить 60 Н, а чотири або шість моторів у статиці сумарно видають 120 Н, апарат має двократний запас тяги на старті й гарантовано підніметься у повітря. Проте брати цю цифру за основу для розрахунку крейсерського польоту літака — груба інженерна помилка.

### Динамічний режим: трикутник швидкостей і падіння кута атаки

Щойно літальний апарат зійшов зі стартової точки й набрав швидкість поступального польоту `V₀ > 0` (динамічний режим, від грец. *dynamikos* — «силовий, рухливий»), уся кінематика обтікання лопатей докорінно змінюється.

Розгляньмо довільний елементарний переріз лопаті на радіусі `r`. На цей переріз одночасно діють два незалежні рухи:
1. **Обертальний рух у площині диска** — колова швидкість перерізу лопаті `u = ω · r = 2 · π · n · r`. Вона спрямована у площині обертання і залежить лише від обертів мотора та відстані до осі.
2. **Осьовий рух крізь повітря** — повна осьова швидкість `V_ax = V₀ + v_i`, що складається зі швидкості польоту літака `V₀` та додаткової динамічної індукованої швидкості припливу `v_i`.

![Трикутник швидкостей: статика проти поступального польоту](/root/sci/ph-mechanics/statychna-i-dynamichna-tiaha/img/dynamic-inflow-triangle.svg)
*У статиці (ліворуч) осьова швидкість мала, тому кут набігання φ малий, а кут атаки лопаті α великий. У поступальному русі (праворуч) швидкість V₀ збільшує φ, кут атаки α = β − φ падає, і тяга стрімко знижується.*

Ці дві взаємно перпендикулярні складові утворюють **трикутник швидкостей перерізу лопаті**. Результуючий вектор набігаючого потоку `W` діє на профіль під кутом припливу `φ` (inflow angle):

```
W = √( ( 2 · π · n · r )² + ( V₀ + v_i )² )
tan φ = ( V₀ + v_i ) / ( 2 · π · n · r )
```

Ефективний кут атаки лопаті `α`, який і створює підіймальну силу крилового перерізу, визначається кутом, під яким потік `W` зустрічає хорду профілю:

```
α = β(r) − φ(r)
```

Погляньмо на дріб у формулі для `tan φ`. Коли швидкість польоту `V₀` зростає від 0 до 20, 30 чи 50 м/с:
1. Чисельник `(V₀ + v_i)` стрімко зростає.
2. Знаменник `(2 · π · n · r)` залишається майже незмінним, якщо мотор підтримує сталі оберти `n`.
3. Відношення збільшується, отже, **кут припливу набігаючого потоку `φ` неминуче росте**.
4. Оскільки кут установки лопаті `β` зафіксований формою пропелера, зростання `φ` автоматично зменшує ефективний кут атаки: `α = β − φ ↓`.

Підіймальна сила аеродинамічного профілю лопаті `L` прямо пропорційна куту атаки на лінійній ділянці поляри: `C_L = a₀ · α`, де `a₀ = d C_L / d α ≈ 2·π` на радіан. 

Коли `α` падає, підіймальна сила кожної смужки лопаті невідворотно зменшується. Ба більше, зі збільшенням кута `φ` вектор повної аеродинамічної сили нахиляється назад: його корисна осьова проєкція вперед (тяга `T`) зменшується подвійно — і через спад величини `C_L`, і через поворот вектора.

```
d T = d L · cos φ − d D · sin φ
```

де `d D` — аеродинамічний опір профілю лопаті. Що швидше летить літак, то сильніше кут `φ` «з'їдає» кут атаки `α`, і то меншу тягу здатний розвинути гвинт на тих самих обертах двигуна. 

Фізичну картину доповнює зміна індукованої швидкості: як доводить [виведення індукованої швидкості у поступальному русі](root:ph-mechanics/statychna-i-dynamichna-tiaha/math-inflow-advance-ratio.md), зі зростанням швидкості польоту `V₀` необхідне прискорення повітря `v_i` спадає за законом `v_i ∝ 1 / V₀`, оскільки масова витрата набігаючого повітря через диск стає гігантською.

### Коефіцієнт поступу J та безрозмірні характеристики

Щоб порівнювати роботу пропелерів різного розміру на різних швидкостях і обертах без прив'язки до конкретних метрів і секунд, в аеродинаміці застосовують критерії подібності. Головним безрозмірним параметром динамічного режиму гвинта є **коефіцієнт поступу** `J` (англ. *advance ratio*, від лат. *progressio*):

```
J = V₀ / ( n · D )
```

де:
- `V₀` — швидкість набігаючого потоку (швидкість польоту), м/с;
- `n` — частота обертання гвинта, обертів за секунду (об/с, тобто `об/хв ÷ 60`);
- `D` — зовнішній діаметр диска гвинта, м.

Фізичний зміст `J` винятково наочний: це **відстань `h = V₀ / n`, яку літак проходить у просторі за один повний оберт валу, виражена в частках діаметра гвинта `D`**. Якщо `J = 0.5`, це означає, що за один оберт гвинт діаметром 1 метр просунувся вперед рівно на 0.5 метра.

Усі робочі показники гвинта записують через безрозмірні коефіцієнти, залежні від `J`:

1. **Коефіцієнт тяги** `C_T(J)` (Thrust coefficient):
   ```
   C_T = T / ( ρ · n² · D⁴ )
   ```
   (Звідси тяга в ньютонах: `T = C_T(J) · ρ · n² · D⁴`).

2. **Коефіцієнт споживаної потужності** `C_P(J)` (Power coefficient):
   ```
   C_P = P_shaft / ( ρ · n³ · D⁵ )
   ```
   (Звідси механічна потужність на валу у ватах: `P_shaft = C_P(J) · ρ · n³ · D⁵`).

3. **Пропульсивний коефіцієнт корисної дії** `η(J)` (Propulsive Efficiency, від лат. *propellere* — «штовхати вперед»):
   Корисна механічна робота, яку гвинт виконує за секунду над літаком, дорівнює добутку тяги на швидкість польоту: `P_useful = T · V₀`. Пропульсивний ККД показує, яка частка механічної потужності двигуна перетворюється на рух апарата:
   ```
   η = P_useful / P_shaft                             [визначення пропульсивного ККД]
   = ( T · V₀ ) / P_shaft                             [корисна робота тяги за секунду]
   = ( C_T · ρ · n² · D⁴ · V₀ ) / ( C_P · ρ · n³ · D⁵ ) [підстановка C_T та C_P]
   = ( C_T / C_P ) · ( V₀ / ( n · D ) )               [групування співмножників]
   = J · ( C_T(J) / C_P(J) )                          [вираження через коефіцієнт поступу J]
   ```

![Аеродинамічні характеристики гвинта від коефіцієнта поступу J](/root/sci/ph-mechanics/statychna-i-dynamichna-tiaha/img/thrust-advance-ratio-curves.svg)
*Залежність коефіцієнтів тяги C_T, потужності C_P та пропульсивного ККД η від коефіцієнта поступу J. Максимум ККД припадає на крейсерський режим, при J = J_zero тяга зникає, а при J > J_zero гвинт переходить у режим гальмування (вітряка).*

Проаналізуймо поведінку цих трьох кривих на графіку:

- **Точка `J = 0` (Статика):** Швидкість руху `V₀ = 0`. Коефіцієнт тяги максимальний: `C_T = C_T0`. Проте корисна робота переміщення дорівнює нулю (`T · 0 = 0`), тому **пропульсивний ККД у статиці строго дорівнює нулю: `η = 0`**. Уся енергія мотора йде на подолання тертя лопатей об повітря та надання кінетичної енергії струменю, який без користі розсіюється в атмосфері.
- **Діапазон зростання `J` (Робочий режим):** З набором швидкості `C_T` монотонно спадає, проте поява швидкості `V₀` викликає стрімкий зліт ККД `η`. Гвинт перетворює енергію валу в рух апарата з високою віддачею.
- **Точка максимуму `η_max`:** При певному оптимальному коефіцієнті поступу `J_opt` (зазвичай `J_opt ≈ 0.6 … 0.8 · J_zero`) пропульсивний ККД сягає свого піка — від 70% до 86% для якісних композитних лопатей. Лопаті працюють на кутах атаки з максимальним аеродинамічним співвідношенням `C_L / C_D` (аеродинамічна якість профілю).
- **Точка нульової тяги `J_zero`:** При подальшому розгоні коефіцієнт тяги перетинає нуль: `C_T(J_zero) = 0`. ККД знову падає до нуля (`η = 0`), оскільки корисна тяга зникла.
- **Зона `J > J_zero` (Режим вітряка):** При перевищенні цієї швидкості коефіцієнт тяги стає від'ємним (`C_T < 0`). Гвинт створює опір польоту.

### Крок гвинта (Pitch) та швидкість виродження тяги

Геометричний крок гвинта `P` (англ. *pitch* — «крок нарізки») — це теоретична відстань, яку гвинт просунувся б уздовж осі за один повний оберт, якби вкручувався у тверде тіло без проковзування, наче болт у різьбу.

Зв'язок між кроком `P`, радіусом `r` та кутом установки профілю `β(r)` задається розгорткою гвинтової лінії на площину:

```
tan β(r) = P / ( 2 · π · r )
```

На відносному радіусі 75% довжини лопаті (`r = 0.75 · R = 0.375 · D`), який вважають аеродинамічним центром тяги лопаті:

```
tan β₀.₇₅ = P / ( 0.75 · π · D ) ≈ P / ( 2.356 · D )
```

Якщо апарат летить зі швидкістю `V₀`, то за один оберт валу тривалістю `Δt = 1 / n` секунд він проходить відстань `h = V₀ / n`. Порівняння цієї фактичної відстані з кроком `P` визначає один із трьох фундаментальних режимів роботи гвинта:

```
h = V₀ / n = J · D                                 [осьовий поступ за один оберт]
```

#### 1. Тяговий режим пропелера (`h < P`, тобто `J < J_zero`)
Фактичне просування літака вперед менше за геометричний крок гвинта. Повітря зустрічає лопать під додатним кутом атаки `α = β − φ > 0`. Лопать відкидає масу повітря назад, а реактивна віддача штовхає вал двигуна вперед (`T > 0`). Мотор витрачає крутний момент на подолання аеродинамічного опору лопатей.

#### 2. Режим нульової тяги (`h = P_aero`, тобто `J = J_zero ≈ P / D`)
Поступальний поступ за оберт точно дорівнює ефективному аеродинамічному кроку пропелера. Кут набігання потоку `φ` збігається з кутом нульової підіймальної сили профілю лопаті `β_zero`. Ефективний кут атаки дорівнює нулю (`α = 0`). Підіймальна сила на лопатях зникає, а разом із нею обнуляється й тяга:

```
V_zero = n · P_aero ≈ n · P
J_zero ≈ P / D
```

У цьому стані мотор не створює тяги вперед, але продовжує споживати невелику потужність від батареї — суто на подолання власного профільного тертя тонких лопатей об набігаючий потік повітря (`C_P(J_zero) = C_P0 > 0`).

#### 3. Режим вітряка та аеродинамічного гальмування (`h > P`, тобто `J > J_zero`)
Якщо літак розігнати зовнішньою силою (наприклад, у пікіруванні під дією сили тяжіння або за допомогою додаткового ракетного прискорювача) до швидкості, що перевищує швидкість нульової тяги `V₀ > V_zero`:
- Кут припливу потоку стає більшим за кут установки лопаті: `φ > β`.
- Ефективний кут атаки стає **від'ємним**: `α = β − φ < 0`.
- Результуючий вектор аеродинамічної сили лопатей перевертається назад. Замість тяги гвинт починає створювати спрямовану проти польоту силу — потужний **аеродинамічний опір** (`T < 0`).
- Одночасно складова аеродинамічної сили у площині обертання починає не гальмувати, а **розкручувати** гвинт за напрямком обертання. Повітряний гвинт перетворюється на класичну вітротурбіну (вітродвигун, режим авторотації). Якщо вимкнути живлення двигуна, набігаючий потік сам розкручує пропелер до високих обертів, створюючи гігантський парашутний опір.

> 🔧 **Навіщо це.** Ефект від'ємної тяги при `J > J_zero` використовують у пілотажі літаків як повітряне гальмо для стрімкого заходу на посадку без набору надлишкової швидкості. Водночас у швидкісних FPV-дронів неправильно підібраний низькокроковий пропелер стає невидимим обмежувачем: досягнувши швидкості `V_zero = n · P`, дрон упирається в «аеродинамічну стіну», де мотори ревуть на повних обертах, але не можуть прискорити апарат сильніше, оскільки гвинти починають самі себе гальмувати.

### Явище статичного зриву потоку на висококрокових гвинтах

Окремий парадокс аеродинаміки гвинтів виникає при спробі встановити пропелер із надвисоким кроковим відношенням (`P / D ≥ 0.9 … 1.2+`, наприклад, розміри 5×5, 7×7 або 12×12 дюймів) на важкий апарат для старту з місця.

При великому відношенні `P / D` геометричний кут установки лопаті `β` біля втулки та на середніх радіусах сягає `25° … 40°`. 

Коли такий гвинт стоїть на місці (`V₀ = 0`), кут припливу `φ` дуже малий (лише слабке власне підсмоктування `v_i0`). Як наслідок, ефективний кут атаки лопатей `α = β − φ` виявляється значно більшим за критичний кут звалювання аеродинамічного профілю (`α_crit ≈ 12° … 15°`).

Відбувається **статичний зрив потоку** (англ. *static blade stall*):
1. Потік повітря не може плавно огинати спинку лопаті під таким величезним кутом і повністю відривається від верхньої поверхні профілю, утворюючи хаотичні вихрові каверни.
2. Коефіцієнт підіймальної сили різко просідає, а коефіцієнт профільного опору зростає в рази.
3. Гвинт видає характерний гучний, тріскучий або рокочучий звук і викликає сильну вібрацію моторами.
4. Електродвигун споживає величезний струм (момент опору зірваних лопатей колосальний), але **фактична статична тяга виявляється меншою, ніж у помірного пропелера того ж діаметра**.

Проте варто апарату зрушити з місця й набрати швидкість `V₀ > 15 … 25 м/с`, як набігаючий потік збільшує кут `φ`. Ефективний кут атаки `α = β − φ` автоматично зменшується, повертаючись у комфортний діапазон 4°–8°. Потік на спинці лопатей миттєво «прилипає» (відновлює безвідривне ламінарно-турбулентне обтікання), тріск стихає, опір падає, а тяга несподівано зростає разом зі швидкістю, виходячи на розрахунковий швидкісний режим.

![Порівняння кроку: низький крок проти високого](/root/sci/ph-mechanics/statychna-i-dynamichna-tiaha/img/pitch-speed-characteristics.svg)
*Низький крок P/D ≈ 0.4 (ліворуч) забезпечує високу ефективність у висінні, але швидко вироджується з ростом швидкості. Високий крок P/D ≈ 1.0 (праворуч) має застійний зрив на місці, зате утримує високу тягу на швидкостях понад 150–200 км/год.*

### Вплив стисливості повітря та числа Маха на кінцях лопатей

Під час швидкісного польоту на динаміку тяги додатково накладається ефект локальної стисливості газу на кінцях лопатей. 

Результуюча швидкість кінця лопаті `W_tip` є векторною сумою поступальної швидкості літака `V₀` та максимальної колової швидкості `u_tip = π · n · D`:

```
W_tip = √( ( π · n · D )² + ( V₀ + v_i )² )
```

Місцеве число Маха на кінчику лопаті визначається відношенням цієї швидкості до швидкості звуку в повітрі `a_sound ≈ 340 м/с`:

```
M_tip = W_tip / a_sound
```

Якщо при розгоні апарата число `M_tip` наближається до критичного значення `M_crit ≈ 0.70 … 0.85`:
1. На опуклій спинці профілю лопаті виникають локальні надзвукові зони та слабкі ударні хвилі (хвильова криза).
2. Різко підскакує хвильовий аеродинамічний опір, що вимагає додаткового крутного моменту від мотора.
3. Пропульсивний ККД стрімко падає, а рівень акустичного шуму перетворюється на високочастотний різкий вереск.

Саме тому в швидкісних безпілотниках і літаках замість простого збільшення діаметра `D` чи надмірного розкручування обертів `n` переходять на багатолопатеві схеми (3–5 лопатей) меншого діаметра з більшим кроком `P`, щоб утримати кінцеве число Маха в безпечних докритичних межах `M_tip < 0.65`.

### Інженерний вибір: баланс діаметра та кроку (P/D)

Вибір комбінації діаметра `D` та кроку `P` — це класичний пошук компромісу між статичною тяговою ефективністю у висінні та швидкісною стелею польоту.

#### Задача 1: Мультиротори, розвідники, важкі знімальні коптери
- **Вимога:** Максимальний час висіння в точці, швидка стабілізація, помірні горизонтальні швидкості (до 40–60 км/год).
- **Вибір:** Великий діаметр `D` у поєднанні з низьким кроковим відношенням (`P / D ≈ 0.30 … 0.50`, наприклад 10×4.5, 15×5, 28×8 дюймів).
- **Фізичне обґрунтування:** З теорії імпульсу потужність, витрачена на створення статичної тяги, обернено пропорційна площі диска: `P_ind = T^(1.5) / √(2·ρ·A)`. Чим більший діаметр `D`, тим більша маса повітря захоплюється й тим меншу швидкість `v_i` їй потрібно надати для створення тієї самої сили упору. Малий крок гарантує відсутність зриву на місці й найвищу питому тягу на 1 ват електричної потужності (від 9 до 15 г/Вт).

#### Задача 2: Швидкісні крила-далекольоти, перехоплювачі та FPV-рейсери
- **Вимога:** Політ на швидкостях від 100 до 220+ км/год, збереження тяги на високих швидкостях, швидкий розгін у горизонталі.
- **Вибір:** Менший діаметр `D` у поєднанні з високим або «квадратним» кроковим відношенням (`P / D ≈ 0.80 … 1.25+`, наприклад 5×4.8, 7×7, 9×9, 13×12 дюймів).
- **Фізичне обґрунтування:** Літак тримається в повітрі не тягою гвинтів, а підіймальною силою крила, яка зростає пропорційно квадрату швидкості `V₀²`. Щоб літак міг летіти зі швидкістю 150 км/год (41.7 м/с), швидкість нульової тяги пропелера `V_zero = n · P` мусить бути щонайменше 180–200 км/год (50–55 м/с). Якби на такий апарат поставили мультироторний пропелер 9×4.5, то при обертах 12 000 об/хв (200 об/с) швидкість нульової тяги становила б лише `200 · 0.1143 = 22.8 м/с` (82 км/год). На швидкості 100 км/год такий пропелер став би гальмівним щитом, тоді як пропелер 9×9 (`P = 0.2286 м`) матиме `V_zero = 200 · 0.2286 = 45.7 м/с` (165 км/год) і забезпечить потужне прискорення вперед.

Нижче наведено зведену таблицю характерних крокових комбінацій для різних класів безпілотних систем:

| Тип пропелера | Відношення P/D | Статична ефективність (г/Вт) | Поведінка на швидкості | Типове застосування |
|---|---|---|---|---|
| **Наднизький крок** (напр. 30×8, 18×5) | `0.25 … 0.35` | Дуже висока (12–16 г/Вт) | Стрімке падіння тяги, `T → 0` при `V₀ > 12–15 м/с` | Агродрони, важкі промислові вантажопідйомні платформи |
| **Помірний низький крок** (напр. 10×4.5, 7×4) | `0.40 … 0.55` | Висока (8–11 г/Вт) | Робочий діапазон до 15–22 м/с (55–80 км/год) | Знімальні квадрокоптери, навчальні тренери, пошукові дрони |
| **Середній крок** (напр. 9×6, 8×6) | `0.60 … 0.75` | Середня (6–8 г/Вт) | Збереження тяги до 25–35 м/с (90–125 км/год) | Універсальні розвідувальні БПЛА типу «літаюче крило» |
| **Квадратний / Високий крок** (напр. 5×5, 7×7, 10×10) | `0.90 … 1.10` | Низька (3–5 г/Вт, шум і зрив на старті) | Потужна тяга на швидкостях 35–60 м/с (125–215 км/год) | Швидкісні FPV-перехоплювачі, кур'єрські літаки VTOL |
| **Гіперкрок** (напр. 5×6, 4.75×5.5) | `> 1.15` | Критично низька (сильний blade stall на місці) | Працює виключно на швидкостях понад 50 м/с (180+ км/год) | Рекордні гоночні пілони, військові швидкісні ударні дрони |

### Розбір телеметрії реального польоту

Щоб наочно побачити динамічне падіння тяги на практиці, проаналізуймо лог польотного контролера (blackbox) швидкісного FPV-літака під час горизонтального розгону на повному газі (100% Throttle, сталі оберти 15 000 об/хв, пропелер 7×7 дюймів):

1. **Точка `t = 0 c`, старт із руки (`V₀ = 0 м/с`, `J = 0`):**
   - Струм батареї: **48 А** (пікове навантаження на зірваних лопатях).
   - Статична тяга: **22.5 Н**.
   - Пропульсивний ККД: **0%**.
   - Звук: глухий рев через локальний зрив потоку на спинці лопатей.

2. **Точка `t = 2.5 c`, розгін (`V₀ = 25 м/с` / 90 км/год, `J = 0.56`):**
   - Струм батареї: **38 А** (опір лопатей упав завдяки відновленню безвідривного обтікання).
   - Динамічна тяга: **16.2 Н** (падіння на 28% від статики).
   - Пропульсивний ККД: **68%**.
   - Звук: чистий високий рівний тон.

3. **Точка `t = 5.0 c`, крейсерський пік (`V₀ = 40 м/с` / 144 км/год, `J = 0.90`):**
   - Струм батареї: **29 А**.
   - Динамічна тяга: **8.5 Н** (тяга врівноважила лобовий опір планера літака).
   - Пропульсивний ККД: **81%** (максимум ефективності).

4. **Точка `t = 8.0 c`, пікірування (`V₀ = 52 м/с` / 187 км/год, `J = 1.17 ≈ J_zero`):**
   - Струм батареї: **14 А** (мотор майже розвантажений набігаючим потоком).
   - Динамічна тяга: **0.0 Н**.
   - Пропульсивний ККД: **0%**.

Цей практичний розріз наочно підтверджує: струм і споживання падають разом із тягою, оскільки набігаючий потік «полегшує» роботу мотора, розвантажуючи лопаті за кутом атаки.

### Математична модель динамічної тяги на C та C++

Для інтеграції в сучасні польотні симулятори, автопілоти (наприклад, ArduPilot або PX4) чи системи аеродинамічного проєктування необхідний швидкий та точний алгоритм обчислення динамічної тяги, потужності та ККД пропелера в польоті.

Алгоритм базується на напівемпіричній моделі спадання коефіцієнтів тяги й потужності з урахуванням геометричного кроку `P`, діаметра `D`, швидкості польоту `V₀` та обертів `n`.

:::tabs
```c
#include <math.h>
#include <stdbool.h>
#include <stdio.h>

/* Параметри геометрії пропелера (усі одиниці в системі SI) */
typedef struct {
    double diameter_m;     /* Діаметр D, м */
    double pitch_m;        /* Геометричний крок P, м */
    double ct0;            /* Статичний коефіцієнт тяги при J = 0 */
    double cp0;            /* Коефіцієнт профільної потужності */
} PropellerSpec;

/* Результати аеродинамічного розрахунку в точці польоту */
typedef struct {
    double advance_ratio;  /* Коефіцієнт поступу J */
    double thrust_n;       /* Динамічна тяга T, Н */
    double power_w;        /* Механічна потужність на валу P, Вт */
    double efficiency;     /* Пропульсивний ККД eta (0.0 ... 1.0) */
    bool is_windmilling;   /* Чи перейшов гвинт у режим гальмування (T < 0) */
} PropellerState;

/* Обчислення динамічної тяги та характеристик гвинта */
bool calculate_propeller_state(
    const PropellerSpec* spec,
    double forward_speed_mps,  /* Швидкість польоту V0, м/с */
    double rpm,                /* Частота обертання, об/хв */
    double air_density,        /* Густина повітря rho, кг/м^3 */
    PropellerState* out_state
) {
    if (!spec || !out_state || spec->diameter_m <= 0.0 || rpm <= 0.0 || air_density <= 0.0) {
        return false;
    }

    const double n = rpm / 60.0;                    /* Оберти за секунду */
    const double d = spec->diameter_m;
    const double p = spec->pitch_m;
    const double v0 = (forward_speed_mps < 0.0) ? 0.0 : forward_speed_mps;

    /* Коефіцієнт поступу J = V0 / (n * D) */
    const double j = v0 / (n * d);

    /* Аеродинамічний коефіцієнт нульової тяги J_zero ≈ P / D */
    const double j_zero = p / d;

    /* Динамічний коефіцієнт тяги C_T(J) за лінійно-параболічною моделлю */
    double ct = 0.0;
    if (j_zero > 0.0) {
        ct = spec->ct0 * (1.0 - (j / j_zero));
    }

    /* Коефіцієнт потужності C_P(J) */
    double cp = spec->cp0;
    if (ct > 0.0) {
        /* Індукована складова потужності росте разом із корисною тягою */
        cp += 0.95 * j * ct;
    }

    /* Розрахунок фізичних величин сили та потужності */
    const double d4 = d * d * d * d;
    const double d5 = d4 * d;
    const double n2 = n * n;
    const double n3 = n2 * n;

    const double thrust = ct * air_density * n2 * d4;
    const double power = cp * air_density * n3 * d5;

    /* Пропульсивний ККД: eta = (T * V0) / P_shaft */
    double efficiency = 0.0;
    if (power > 1e-3 && thrust > 0.0 && v0 > 0.0) {
        efficiency = (thrust * v0) / power;
        if (efficiency > 0.90) {
            efficiency = 0.90; /* Реальне фізичне обмеження ККД лопаті */
        }
    }

    out_state->advance_ratio = j;
    out_state->thrust_n = thrust;
    out_state->power_w = power;
    out_state->efficiency = efficiency;
    out_state->is_windmilling = (thrust < 0.0);

    return true;
}

int main(void) {
    /* Приклад: карбоновий пропелер 10x4.5 дюйма (D=0.254м, P=0.1143м) */
    PropellerSpec prop = {
        .diameter_m = 0.254,
        .pitch_m = 0.1143,
        .ct0 = 0.098,
        .cp0 = 0.038
    };

    const double rpm = 8000.0;
    const double rho = 1.225;
    PropellerState state;

    printf("=== Продування гвинта 10x4.5 (P/D = %.2f) при %.0f RPM ===\n",
           prop.pitch_m / prop.diameter_m, rpm);
    printf(" V0 (м/с) |    J   | Тяга (Н) | Тяга (гс) | Потужність (Вт) |  ККД (%%)\n");
    printf("----------+--------+----------+-----------+-----------------+----------\n");

    for (double v = 0.0; v <= 20.0; v += 4.0) {
        if (calculate_propeller_state(&prop, v, rpm, rho, &state)) {
            printf("  %5.1f   |  %4.2f  |  %6.2f  |  %7.1f  |     %6.1f      |  %5.1f%%\n",
                   v,
                   state.advance_ratio,
                   state.thrust_n,
                   state.thrust_n * 101.97, /* Переведення Н у грам-сили */
                   state.power_w,
                   state.efficiency * 100.0);
        }
    }

    return 0;
}
```

```cpp
    double diameter_m;     // Зовнішній діаметр D, м
    double pitch_m;        // Геометричний крок P, м
    double ct0;            // Статичний коефіцієнт тяги (J = 0)
    double cp0;            // Базовий коефіцієнт профільної потужності

    [[nodiscard]] constexpr double pitch_to_diameter_ratio() const noexcept {
        return (diameter_m > 0.0) ? (pitch_m / diameter_m) : 0.0;
    }
};

// Розрахований робочий стан гвинта в польоті
struct PropellerState {
    double advance_ratio;  // Коефіцієнт поступу J
    double thrust_n;       // Тяга T, Н
    double power_w;        // Механічна потужність на валу P, Вт
    double efficiency;     // Пропульсивний ККД eta
    bool is_windmilling;   // Ознака режиму вітряка / гальмування (T < 0)
};

enum class CalculationError {
    InvalidGeometry,
    InvalidRpm,
    InvalidAirDensity
};

// Обчислення аеродинамічних сил пропелера
[[nodiscard]] constexpr std::expected<PropellerState, CalculationError> calculate_propeller_state(
    const PropellerSpec& spec,
    double forward_speed_mps,
    double rpm,
    double air_density = 1.225
) noexcept {
    if (spec.diameter_m <= 0.0 || spec.pitch_m <= 0.0) {
        return std::unexpected(CalculationError::InvalidGeometry);
    }
    if (rpm <= 0.0) {
        return std::unexpected(CalculationError::InvalidRpm);
    }
    if (air_density <= 0.0) {
        return std::unexpected(CalculationError::InvalidAirDensity);
    }

    const double n = rpm / 60.0; // Частота обертання, об/с
    const double d = spec.diameter_m;
    const double p = spec.pitch_m;
    const double v0 = (forward_speed_mps < 0.0) ? 0.0 : forward_speed_mps;

    // Безрозмірний коефіцієнт поступу J = V0 / (n * D)
    const double j = v0 / (n * d);

    // Точка нульової тяги J_zero ≈ P / D
    const double j_zero = p / d;

    // Розрахунок коефіцієнта тяги C_T(J)
    const double ct = spec.ct0 * (1.0 - (j / j_zero));

    // Розрахунок коефіцієнта потужності C_P(J)
    double cp = spec.cp0;
    if (ct > 0.0) {
        cp += 0.95 * j * ct;
    }

    // Масштабування в абсолютні величини за законами аеродинамічної подібності
    const double d4 = std::pow(d, 4);
    const double d5 = d4 * d;
    const double n2 = n * n;
    const double n3 = n2 * n;

    const double thrust = ct * air_density * n2 * d4;
    const double power = cp * air_density * n3 * d5;

    // Пропульсивний ККД: eta = (T * V0) / P
    double efficiency = 0.0;
    if (power > 1e-3 && thrust > 0.0 && v0 > 0.0) {
        efficiency = (thrust * v0) / power;
        if (efficiency > 0.90) {
            efficiency = 0.90; // Фізична межа максимального ККД лопатей
        }
    }

    return PropellerState{
        .advance_ratio = j,
        .thrust_n = thrust,
        .power_w = power,
        .efficiency = efficiency,
        .is_windmilling = (thrust < 0.0)
    };
}

} // namespace aero

int main() {
    // Карбоновий швидкісний FPV-пропелер 7x7 дюймів (D=0.1778м, P=0.1778м)
    constexpr aero::PropellerSpec speed_prop{
        .diameter_m = 0.1778,
        .pitch_m = 0.1778,
        .ct0 = 0.115,
        .cp0 = 0.045
    };

    constexpr double rpm = 18000.0;
    constexpr double rho = 1.225;

    std::cout << std::fixed << std::setprecision(2);
    std::cout << "=== Продування швидкісного гвинта 7x7 (P/D = "
              << speed_prop.pitch_to_diameter_ratio() << ") при "
              << static_cast<int>(rpm) << " RPM ===\n";
    std::cout << " V0 (м/с) | V0 (км/год) |   J   | Тяга (Н) | Потужність (Вт) |  ККД (%)\n";
    std::cout << "----------+-------------+-------+----------+-----------------+----------\n";

    for (double v = 0.0; v <= 60.0; v += 10.0) {
        auto result = aero::calculate_propeller_state(speed_prop, v, rpm, rho);
        if (result.has_value()) {
            const auto& state = result.value();
            std::cout << "  " << std::setw(5) << v << "   |   "
                      << std::setw(6) << (v * 3.6) << "    |  "
                      << std::setw(4) << state.advance_ratio << " |  "
                      << std::setw(6) << state.thrust_n << "  |     "
                      << std::setw(6) << state.power_w << "      |  "
                      << std::setw(5) << (state.efficiency * 100.0) << "%\n";
        }
    }

    return 0;
}
```

### Практичне резюме інженера-аеромеханіка

1. **Стендова тяга оманлива:** Статична тяга, виміряна на нерухомих вагах, є максимальною силою, на яку здатний гвинт. У поступальному польоті тяга неминуче знижується через зростання кута набігаючого потоку `φ` та падіння ефективного кута атаки лопатей `α = β − φ`.
2. **Коефіцієнт поступу задає режим:** Безрозмірне число `J = V₀ / (n·D)` повністю визначає робочий стан пропелера незалежно від його фізичного розміру. При `J = 0` гвинт розвиває максимальну тягу, але його пропульсивний ККД дорівнює нулю; в околиці `J ≈ 0.7 · (P/D)` ККД сягає піка (75–85%); при `J = P/D` тяга вироджується до нуля.
3. **Швидкість виродження тяги:** Максимальна теоретична швидкість, яку гвинт здатен надати літаку, обмежена його кроком і обертами: `V_max < n · P`. Політ швидше за цю межу перетворює пропелер на аеродинамічне гальмо (режим вітряка).
4. **Вибір під завдання:** Мультироторам та важким платформам для зависання потрібні великий діаметр `D` і низький крок `P/D ≈ 0.35 … 0.50` (максимальна тяга на ват у статиці). Швидкісним літакам і перехоплювачам потрібні помірний діаметр і високий крок `P/D ≈ 0.85 … 1.20+`, здатні створювати тягу на швидкостях 150–200+ км/год без передчасного виродження.
