# 🧮 Виведення індукованої швидкості у поступальному русі

Теорія ідеального диска актуатора дає точну формулу індукованої швидкості для нерухомого висіння у повітрі (`V₀ = 0`). Проте щойно апарат рушає вперед зі швидкістю `V₀`, крізь площину гвинта починає протікати додаткова маса набігаючого повітря. Цей потік кардинально змінює баланс імпульсу: чим швидше летить апарат, тим менший додатковий приріст швидкості `v_i` гвинт мусить надати повітрю для створення тієї самої тяги. Нижче наведено строге виведення нелінійного рівняння припливу Главерта (Glauert inflow equation), аналітичний розв'язок для індукованої швидкості `v_i(V₀)`, інтегральний зв'язок між швидкістю польоту й падінням коефіцієнта тяги `C_T(J)`, а також аналітичний розрахунок точки максимального пропульсивного ККД `η_max`.

### 1. Баланс маси та імпульсу у поступальному потоці

Розгляньмо контрольний об'єм струминної трубки, що охоплює диск гвинта площею `A = π · R²`. У системі відліку, пов'язаній із віссю обертання гвинта:
- Далеко попереду незбурене повітря набігає зі швидкістю польоту `V₀` та статичним тиском `p₀`.
- Безпосередньо у площині диска швидкість потоку становить `V_disk = V₀ + v_i`, де `v_i` — осьова індукована швидкість, створена розрідженням перед диском і стисненням за ним.
- Далеко позаду у сформованому сліді (струмені) тиск знову вирівнюється до навколишнього атмосферного `p₀`, а швидкість потоку досягає максимального значення `V_wake = V₀ + w`.

Застосуємо теорему Бернуллі окремо для двох ділянок струминної трубки — до площини диска гвинта та після неї:

```
p₀ + ½·ρ·V₀² = p_front + ½·ρ·(V₀ + v_i)²          [Бернуллі перед диском]
p_back + ½·ρ·(V₀ + v_i)² = p₀ + ½·ρ·(V₀ + w)²     [Бернуллі за диском]
```

Віднявши перше рівняння від другого, знаходимо стрибок статичного тиску `Δp = p_back - p_front` на площині обертання диска:

```
Δp = ½·ρ·(V₀ + w)² − ½·ρ·V₀²
= ½·ρ·( V₀² + 2·V₀·w + w² − V₀² )                [розкриття дужок]
= ½·ρ·( 2·V₀·w + w² )                             [скорочення V₀²]
= ρ · w · ( V₀ + ½·w )                           [винесення спільного множника]
```

Повна аеродинамічна тяга `T` дорівнює добутку стрибка статичного тиску `Δp` на геометричну площу диска `A`:

```
T = Δp · A = ρ · A · w · ( V₀ + ½·w )
```

Водночас за фундаментальною теоремою про зміну кількості руху (рівняння балансу імпульсу), тяга дорівнює секундній витраті маси `ṁ`, помноженій на повний приріст швидкості струменя `w`:

```
ṁ = ρ · A · V_disk = ρ · A · ( V₀ + v_i )         [секундна витрата крізь диск]
T = ṁ · ( V_wake − V₀ ) = ṁ · w                   [теорема імпульсів]
T = ρ · A · ( V₀ + v_i ) · w                      [підстановка секундної маси ṁ]
```

Прирівняємо обидва незалежні вирази для величини тяги `T`:

```
ρ · A · ( V₀ + v_i ) · w = ρ · A · ( V₀ + ½·w ) · w
V₀ + v_i = V₀ + ½·w                              [ділення на ρ · A · w ≠ 0]
v_i = ½ · w                                       [наслідок: w = 2 · v_i]
```

Звідси випливає фундаментальний кінематичний закон актуаторного диска: **рівно половина повного приросту швидкості струменя досягається безпосередньо в площині гвинта (`v_i`), а повний приріст у кінцевому сліді становить рівно вдвічі більше (`w = 2·v_i`)**. Цей закон є універсальним: він діє як для нерухомого висіння, так і для будь-якої поступальної швидкості `V₀`.

### 2. Квадратне рівняння для індукованої швидкості `v_i(V₀)`

Підставимо отримане співвідношення `w = 2·v_i` у формулу імпульсної тяги:

```
T = 2 · ρ · A · ( V₀ + v_i ) · v_i
```

Розділимо обидві частини рівняння на `2 · ρ · A`:

```
T / ( 2 · ρ · A ) = ( V₀ + v_i ) · v_i
v_i² + V₀ · v_i − T / ( 2 · ρ · A ) = 0          [канонічне квадратне рівняння]
```

Введемо позначення для статичної індукованої швидкості при нерухомому висінні (`V₀ = 0`):

```
v_i0 = √( T / ( 2 · ρ · A ) )
```

Тоді рівняння Главерта набуває компактного квадратного вигляду:

```
v_i² + V₀ · v_i − v_i0² = 0
```

Дискримінант цього квадратного рівняння відносно невідомої швидкості `v_i`:

```
D = V₀² + 4 · v_i0²
```

Оскільки фізична швидкість підсмоктування повітря крізь диск у прямому тяговому режимі мусить бути строго додатною (`v_i > 0`), обираємо додатний корінь:

```
v_i(V₀) = ( −V₀ + √( V₀² + 4·v_i0² ) ) / 2         [додатний корінь квадратного рівняння]
= −V₀ / 2 + √( ( V₀ / 2 )² + v_i0² )               [внесення 2 під знак кореня]
```

Це і є точна аналітична формула індукованої швидкості гвинта в осьовому польоті для довільної швидкості набігаючого потоку `V₀`.

### 3. Асимптотичний аналіз: від висіння до швидкісного польоту

Дослідимо поведінку індукованої швидкості `v_i(V₀)` на двох граничних фізичних режимах:

**Границя 1: Статичний режим (`V₀ = 0`).**

```
v_i(0) = −0 / 2 + √( 0 + v_i0² ) = v_i0
```
Індукована швидкість сягає абсолютного максимуму і визначається суто питомим навантаженням на площу диска `T / A`. Усе захоплене повітря прискорюється зі стану повного навколишнього спокою.

**Границя 2: Швидкісний поступальний політ (`V₀ ≫ v_i0`).**

Розкладемо підкореневий вираз у степеневий ряд Тейлора за малим безрозмірним параметром `ε = ( 2·v_i0 / V₀ )² ≪ 1`:

```
√( ( V₀ / 2 )² + v_i0² )
= ( V₀ / 2 ) · √( 1 + ( 2·v_i0 / V₀ )² )
≈ ( V₀ / 2 ) · ( 1 + ½ · ( 2·v_i0 / V₀ )² )       [наближення √(1+ε) ≈ 1 + ½·ε]
= V₀ / 2 + v_i0² / V₀
```

Підставимо отриманий розклад у формулу індукованої швидкості:

```
v_i(V₀) ≈ −V₀ / 2 + ( V₀ / 2 + v_i0² / V₀ )
= v_i0² / V₀                                     [скорочення V₀ / 2]
```

Звідси видно ключову фізичну закономірність динамічного потоку: **зі зростанням швидкості польоту індукована швидкість спадає обернено пропорційно швидкості `v_i ∝ 1 / V₀`**. 

Причина полягає у зміні масової витрати: щосекунди крізь диск гвинта проноситься величезна маса набігаючого повітря `ṁ ≈ ρ · A · V₀`. Щоб створити задану тягу `T = ṁ · (2·v_i)`, гвинтові більше не потрібно сильно прискорювати потік — достатньо надати мізерного додаткового імпульсу величезній масі середовища, яке й без того набігає крізь нього зі швидкістю літака.

### 4. Інтегрування тяги елемента лопаті та спад `C_T(J)`

З'єднаємо кінематику набігаючого потоку з аеродинамікою перерізу лопаті. На відносному радіусі `r` лопать обертається з коловою швидкістю `u = 2·π·n·r` і рухається вперед з осьовою швидкістю `V_ax = V₀ + v_i`.

Місцевий кут набігання потоку `φ(r)`:

```
tan φ(r) = ( V₀ + v_i ) / ( 2 · π · n · r )
```

Для тонкого слабонавантаженого гвинта у швидкісному польоті кут `φ` є малим (`tan φ ≈ φ`), тому:

```
φ(r) ≈ ( V₀ + v_i ) / ( 2 · π · n · r )
```

Ефективний кут атаки перерізу лопаті з геометричним кутом установки `β(r)`:

```
α(r) = β(r) − φ(r) = β(r) − ( V₀ + v_i ) / ( 2 · π · n · r )
```

Коефіцієнт підіймальної сили профілю на лінійній ділянці поляри виражається через теоретичний градієнт підйому по куту атаки `a₀ = d C_L / d α ≈ 2·π` (для тонкого аеродинамічного профілю):

```
C_L(r) = a₀ · α(r) = a₀ · ( β(r) − φ(r) )
```

Елементарна аеродинамічна тяга кільцевого елемента лопатей шириною `dr` (де `B` — кількість лопатей, `c(r)` — місцева хорда профілю):

```
d T ≈ ½ · ρ · W² · C_L(r) · cos φ · B · c(r) · dr
```

Оскільки при малих кутах припливу `cos φ ≈ 1`, а повна швидкість набігання `W ≈ 2·π·n·r`, підставляємо розгорнутий вираз для `C_L(r)`:

```
d T ≈ ½ · ρ · ( 2·π·n·r )² · a₀ · [ β(r) − ( V₀ + v_i ) / ( 2·π·n·r ) ] · B · c(r) · dr
= ½ · ρ · a₀ · B · c(r) · [ ( 2·π·n·r )² · β(r) − ( 2·π·n·r ) · ( V₀ + v_i ) ] · dr
```

Інтегруючи цей вираз по радіусу від втулки `r_hub` до кінця лопаті `R = D / 2` та знехтувавши малою величиною індукованої швидкості `v_i ≪ V₀` у крейсерському польоті, отримуємо:

```
T(V₀) = I₁ · n² · D⁴ − I₂ · n · D³ · V₀
```

де `I₁` та `I₂` — інтегральні геометричні константи форми лопаті, закону скрутки `β(r)` та розподілу хорди `c(r)`.

Перейдемо до безрозмірного коефіцієнта тяги `C_T = T / ( ρ · n² · D⁴ )` та безрозмірного коефіцієнта поступу `J = V₀ / ( n · D )`:

```
C_T(J) = T / ( ρ · n² · D⁴ )
= ( I₁ · n² · D⁴ − I₂ · n · D³ · V₀ ) / ( ρ · n² · D⁴ )
= C_T0 − k · ( V₀ / ( n · D ) )                  [де C_T0 = I₁ / ρ, k = I₂ / ρ]
= C_T0 − k · J
```

У точці виродження тяги до нуля `C_T(J_zero) = 0`:

```
C_T0 − k · J_zero = 0   ⇒   k = C_T0 / J_zero
```

Підставивши значення константи `k`, отримуємо класичне лінійне рівняння спадання динамічної тяги:

```
C_T(J) = C_T0 · ( 1 − J / J_zero )
```

де `J_zero ≈ P / D` — геометричний коефіцієнт нульової тяги, прямо пропорційний кроковому відношенню гвинта `P / D`.

### 5. Аналітичний розрахунок максимуму пропульсивного ККД `η_max`

Пропульсивний ККД гвинта за визначенням є відношенням корисної тягової потужності `P_thrust = T · V₀` до споживаної механічної потужності на валу `P_shaft`:

```
η(J) = ( T · V₀ ) / P_shaft                        [визначення пропульсивного ККД]
= ( C_T · ρ · n² · D⁴ · V₀ ) / ( C_P · ρ · n³ · D⁵ ) [підстановка C_T та C_P]
= J · ( C_T(J) / C_P(J) )                          [скорочення спільних множників]
```

Коефіцієнт потужності `C_P(J)` складається з індукованої частини (створення тяги) та профільного тертя лопатей `C_P0`:

```
C_P(J) ≈ J · C_T(J) + C_P0
```

Підставивши лінійну модель тяги `C_T(J) = C_T0 · (1 − J / J_zero)` у вираз для коефіцієнта корисної дії:

```
η(J) = ( J · C_T0 · ( 1 − J / J_zero ) ) / ( J · C_T0 · ( 1 − J / J_zero ) + C_P0 )
= ( 1 − J / J_zero ) / ( ( 1 − J / J_zero ) + C_P0 / ( J · C_T0 ) )
```

Щоб знайти точку екстремуму `J_opt`, продиференціюємо чисельник ідеалізованого ККД або знайдемо максимум функції `f(J) = J · (1 - J / J_zero)`. Похідна цієї параболічної залежності:

```
d/dJ [ J − J² / J_zero ] = 1 − 2 · J / J_zero = 0
```

Звідси отримуємо теоретичний оптимум:

```
J_opt ≈ ½ · J_zero ≈ 0.5 · ( P / D )
```

З урахуванням реального профільного тертя та кінцевих втрат лопаті, пік ККД зміщується трохи праворуч у бік вищих швидкостей:

```
J_opt_real ≈ ( 0.65 … 0.80 ) · J_zero
```

У цій точці пропульсивний ККД добре спрофільованого гвинта досягає свого пікового значення `η_max ≈ 75 … 85%`.

### 6. Числовий приклад розрахунку

**Умова:** Безпілотник летить зі швидкістю `V₀ = 20 м/с` (72 км/год). Встановлено гвинт діаметром `D = 0.254 м` (10 дюймів) з кроком `P = 0.1143 м` (4.5 дюйма), крокове відношення `P/D = 0.45`. Оберти двигуна `n = 150 об/с` (9000 об/хв). Статичний коефіцієнт тяги `C_T0 = 0.095`. Густина повітря `ρ = 1.225 кг/м³`.

**Крок 1. Розрахунок коефіцієнта поступу J:**

```
J = V₀ / ( n · D )                                 [визначення коефіцієнта поступу]
= 20 / ( 150 · 0.254 )                             [підстановка числових значень]
= 20 / 38.1 ≈ 0.525                                [обчислення частки]
```

**Крок 2. Розрахунок критичного коефіцієнта нульової тяги J_zero:**

```
J_zero ≈ P / D = 0.1143 / 0.254 = 0.450
```

**Крок 3. Порівняння та висновок:**
Оскільки фактичний коефіцієнт поступу `J = 0.525` перевищує критичне значення `J_zero = 0.450` (`J > J_zero`), розрахунковий коефіцієнт тяги стає від'ємним:

```
C_T(J) = 0.095 · ( 1 − 0.525 / 0.450 )             [підстановка J та J_zero]
= 0.095 · ( 1 − 1.167 )                            [обчислення відношення]
= 0.095 · ( −0.167 ) ≈ −0.0158                     [результат коефіцієнта тяги]
```

Тяга гвинта становить:

```
T = C_T · ρ · n² · D⁴                              [формула аеродинамічної тяги]
= −0.0158 · 1.225 · (150)² · (0.254)⁴              [підстановка числових величин]
= −0.0158 · 1.225 · 22500 · 0.00416 ≈ −1.81 Н      [обчислення добутку]
```

**Фізичний висновок:** На швидкості 72 км/год низькокроковий гвинт 10×4.5 не лише не створює тяги вперед, але й чинить гальмівний аеродинамічний опір силою `1.81 Н`, перейшовши в режим вітряка. Щоб на такій швидкості створювати корисну тягу вперед, літаку потрібен гвинт із суттєво вищим кроком (наприклад, 10×7 або 9×9) або значно вищі оберти двигуна `n`.
