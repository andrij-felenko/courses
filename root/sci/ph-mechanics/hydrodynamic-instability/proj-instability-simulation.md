# ⚙️ Чисельне моделювання нестійкості Кельвіна — Гельмгольца

Ця вставка містить повну практичну реалізацію 2D чисельного розв'язувача для моделювання нестійкості Кельвіна — Гельмгольца в зсувному потоці рідини. Тут детально розглянуто математичні основи методу точкових вихорів (або вихрових осередків у формулюванні «вихрості — функція струменю»), перевірку умови Куранта — Фрідріхса — Леві (CFL), обробку крайових умов, розширення на нестійкість Релея — Тейлора, бароклінну генерацію вихровості, фільтрацію аліасингу, каскад енстрофії Крайчнана, оптимізацію паралельних обчислень та практичні пастки числової дисипації й дисперсії.

## 1. Постановка фізико-математичної моделі

Розглядається двовимірна течія нестисливої в'язкої рідини на періодичному в напрямку `x` та обмеженому стінками в напрямку `y` домені розміром `L_x × L_y`. Моделювання виконується у формулюванні **вихрості та функції струменю** (vorticity-streamfunction formulation). Головна перевага цього підходу порівняно з прямою інтеграцією швидкості й тиску полягає в тому, що він тотожно задовольняє закон збереження маси (рівняння неперервності) і повністю виключає тиск з обчислювального циклу:

```
ω = ∂v/∂x - ∂u/∂y                                        [визначення вихровості]
∇²ψ = -ω                                                 [рівняння Пуассона для функції струменю]
u =  ∂ψ/∂y,   v = -∂ψ/∂x                                [зв'язок швидкостей з функцією струменю]
∂ω/∂t + u·(∂ω/∂x) + v·(∂ω/∂y) = ν·(∂²ω/∂x² + ∂²ω/∂y²)   [рівняння переносу вихровості]
```

Початковий профіль подовжньої швидкості описує неперервний зсувний шар з профілем гіперболічного тангенса (згладжена сходинка):

```
U(y) = U₀ · tanh( (y - y₀) / δ )   [початковий профіль зсуву]
```

де `U₀` — характерна амплітуда зсуву швидкості, `δ` — товщина зсувного шару, `y₀` — вертикальне положення лінії розриву. Щоб запустити розвиток нестійкості, на початковий ламінарний стан накладається мала гармонічна синусоїдальна пертурбація вертикальної швидкості `v'`:

```
v'(x, y) = ε · U₀ · sin(2·π·k·x / L_x) · exp( -((y - y₀)/δ)² )   [початкове збурення]
```

з малою амплітудою `ε ≈ 0.01 … 0.05` та хвильовим числом `k` (зазвичай `k = 1` або `k = 2` на довжині домену). Вільне варіювання параметра `ε` дозволяє досліджувати як лінійний режим росту амплітуди, так і перехід до нелінійного згортання вихорів.

## 2. Алгоритм чисельного розв'язання та дискретизація

Обчислювальна сітка є рівномірною прямокутною з кроками `Δx = L_x / N_x` та `Δy = L_y / N_y`. Чисельний алгоритм розв'язання на кожному часовому кроці `Δt` складається з чотирьох послідовних кроків:

1. **Розв'язання рівняння Пуассона для функції струменю:** За поточним полем вихровості `ω^(n)` розв'язується еліптичне рівняння Пуассона `∇²ψ = -ω`. Для періодичного домену найшвидшим методом є ітераційний метод Якобі чи релаксації, або спектральне швидке перетворення Фур'є (FFT).
2. **Відновлення поля швидкостей:** За знайденою функцією струменю `ψ(x, y)` обчислюються компоненти векторного поля швидкості за допомогою центрально-різницевих операторів 2-го порядку точності: `u_{i,j} = (ψ_{i,j+1} - ψ_{i,j-1}) / (2·Δy)` та `v_{i,j} = -(ψ_{i+1,j} - ψ_{i-1,j}) / (2·Δx)`.
3. **Обчислення конвективного й в'язкого членів:** Конвективний перенос вихровості `u·(∂ω/∂x) + v·(∂ω/∂y)` дискретизується за допомогою спрямованих проти потоку різниць (Upwind scheme) або схеми Аракави для збереження енстрофії. Дифузійний член `ν·∇²ω` обчислюється стандартним п'ятиточковим шаблоном Лапласіана.
4. **Часове інтегрування:** Оновлюється поле вихровості `ω^(n+1)` за явного схемою Ейлера або методом Рунге — Кутти 2-го порядку (RK2).

Крок за часом `Δt` суворо обмежується умовою Куранта — Фрідріхса — Леві (CFL condition) для забезпечення числової стійкості різницевої схеми:

```
Δt < CFL · min( Δx / |u_max|,  Δy / |v_max|,  Δx² / (4·ν) )   [УМОВА CFL]
```

з курантівським числом `CFL ≈ 0.25 … 0.4`.

## 3. Спектральна фільтрація та усунення аліасингу (Правило 2/3)

У псевдоспектральних розв'язувачах нелінійний доданок конвекції `u·(∂ω/∂x)` обчислюється шляхом множення полів у фізичному просторі з наступним переходом у Фур'є-простір. Це множення двох гармонік із хвильовими числами `k_1` та `k_2` генерує нову гармоніку з сумарним хвильовим числом `k = k_1 + k_2`.

Якщо значення `k` перевищує максимальне хвильове число сітки `k_max = N / 2`, ця гармоніка помилково відображається у спектрі як низькочастотна хвиля з хвильовим числом `k_alias = k - N`. Таке явище викривлення спектру називається **похибкою аліасингу** (Aliasing Error).

Для повного пригнічення аліасингу застосовується **правило двох третіх (Orszag 2/3 Rule)**. Перед виконанням нелінійного множення всі гармоніки з хвильовими числами, що перевищують `2/3 · k_max`, обнуляються у спектральному просторі:

```
ω_hat(k) = 0,   якщо |k| > (2/3) · k_max   [ПРАВИЛО 2/3 ОРСАГА ДЛЯ УСУНЕННЯ АЛІАСИНГУ]
```

Застосування маски фільтрації `2/3` гарантує математично точну відсутність спектральних викривлень і забезпечує довгострокову стійкість розв'язку нелінійної задачі.

## 4. Використання фіктивних осередків (Ghost Cells) для крайових умов

Для програмної реалізації періодичних крайових умов або стінок у скінченно-різницевих кодах застосовується методика **фіктивних осередків** (Ghost Cells або Halo Cells).

Навколо основної обчислювальної сітки розміром `N_x × N_y` створюється додаткова рамка з фіктивних шарів осередків індексу `i = -1`, `i = N_x`, `j = -1`, `j = N_y`. На початку кожного часового кроку дані з протилежних кордонів сітки копіюються у фіктивні осередки:

```
w[-1][j]  = w[Nx-2][j]   [періодична ліва межа]
w[Nx][j]  = w[1][j]      [періодична права межа]
w[i][-1]  = w[i][1]      [симетрична нижня межа]
w[i][Ny]  = w[i][Ny-2]   [симетрична верхня межа]
```

Використання фіктивних осередків дозволяє обчислювати центральні різниці другого порядку на межах домену без використання розгалужених операторів `if/else` у внутрішніх обчислювальних циклах, що істотно прискорює виконання коду на CPU.

## 5. Каскад енстрофії Крайчнана у 2D турбулентності

Важливою практичною відмінністю двовимірного моделювання нестійкості від тривимірного є характер спектрального каскаду енергії. У тривимірній турбулентності діє прямий каскад Колмогорова, де кінетична енергія передається від великих вихорів до дрібних зі спектром `E(k) ~ k^(-5/3)`.

У двовимірному потоці через додатковий закон збереження енстрофії `Ω = ∬ ω² dx dy` реалізується подвійний каскад Крайчнана — Бетчелора (Kraichnan-Batchelor cascade):
1. **Зворотний каскад енергії:** Кінетична енергія передається від дрібних вихорів до великих (`E(k) ~ k^(-5/3)` за малих `k`), зливаючи вихори у велетенські кокони (vortex merger).
2. **Прямий каскад енстрофії:** Енстрофія скидається у бік високих хвильових чисел зі крутим спектром `E(k) ~ k^(-3)`.

Розуміння каскаду Крайчнана дозволяє чисельно оцінити потрібний просторовий дозвіл сітки для збереження правильної спектральної форми розв'язку.

## 6. Моделювання бароклінної генерації вихровості та нестійкості Релея — Тейлора

У разі моделювання нестійкостей із варіацією густини `ρ(x, y, t)` (наприклад, у задачах Релея — Тейлора чи Рихтмаєра — Мешкова) у рівняння переносу вихровості додається нове джерело — **бароклінний векторний член**:

```
∂ω/∂t + u·(∂ω/∂x) + v·(∂ω/∂y) = ν·∇²ω + (1/ρ²)·( (∂ρ/∂x)·(∂p/∂y) - (∂ρ/∂y)·(∂p/∂x) )   [БАРОКЛІННА ГЕНЕРАЦІЯ ВИХРОВОСТІ]
```

Фізична суть бароклінної генерації полягає у виникненні обертального моменту сил, коли ізобари (поверхні постійного тиску `p = const`) перетинаються під кутом із ізопікнами (поверхнями постійної густини `ρ = const`).

У чисельному розв'язувачі нестійкості Релея — Тейлора поле густини `ρ` переноситься як пасивна скалярна примесь за допомогою адвективного рівняння:

```
∂ρ/∂t + u·(∂ρ/∂x) + v·(∂ρ/∂y) = D_ρ · ∇²ρ   [ПЕРЕНОС ГУСТИНИ ДИФУЗІЄЮ]
```

де `D_ρ` — коефіцієнт дифузії маси. Наявність бароклінної вихровості генерує вихори вздовж країв занурюваних шпильок важкої рідини, що обумовлює їхнє згортання у характерні "грибоподібні" капелюшки.

## 7. Обробка крайових умов на твердих стінках та формула Тома

Якщо в напрямку `y` домен обмежений твердими нерухомими стінками (`y = ±L_y/2`), на них повинні виконуватися умови прилипання: `u = 0` та `v = 0`. 

У формулюванні «вихрість — функція струменю» це вимагає специфічної обробки граничних значень вихровості на стінці `ω_wall`. Оскільки функція струменю на стінці `ψ_wall = 0`, значення вихровості на стінці розраховується за **першою формулою Тома** (Thom's boundary formula 2-го порядку точності):

```
ω_wall = -2 · ψ_interior / Δy²   [ПЕРША ФОРМУЛА ТОМА ДЛЯ ВИХРОВОСТІ НА СТІНЦІ]
```

де `ψ_interior` — значення функції струменю у першому внутрішньому вузлі сітки, віддаленому від стінки на відстань `Δy`. Застосування формули Тома забезпечує точне дотримання умови прилипання `u = ∂ψ/∂y = 0` на межі.

## 8. Детальний аналіз реалізації C та C++ коду: масиви, пам'ять та геометрія

Для досягнення максимальної обчислювальної продуктивності двовимірне поле дискретних точок `(N_x × N_y)` відображається на плоский одномірний масив подвійної точності `double*` довжиною `N_x · N_y`. 

Послідовність розташування елементів у пам'яті вибирається за схемою **Row-Major Order** (рядковий порядок, прийнятий у мовах C та C++), де елемент з просторовими індексами `(i, j)` (де `i ∈ [0, N_x-1]` відповідає вісі `x`, а `j ∈ [0, N_y-1]` відповідає вісі `y`) розміщується за лінійним зміщенням:

```
index = j · N_x + i   [лінійне зміщення елемента в одномірному масиві]
```

Така організація даних гарантує максимальне використання кєш-пам'яті першого та второго рівнів (L1/L2 Cache), оскільки внутрішній обчислювальний цикл виконується за індексом `i` вздовж безперервної ділянки пам'яті з послідовним кроком в один елемент (`stride = 1`).

У версії C пам'ять для 4 скалярних полів (`w`, `psi`, `u`, `v`) виділяється динамічно функцією `calloc()`, яка гарантує початкову зануленість усіх байтів. Всі гілки звільнення пам'яті обгортаються у функцію `kh_free()`, що запобігає витоку ресурсів.

У версії C++ замість сирих вказівників застосовуються контейнери `std::vector<double>`, які автоматично керують життєвим циклом об'єкта за принципом RAII (Resource Acquisition Is Initialization). Мобільна операція `w_ = std::move(w_next)` дозволяє миттєво обмінювати буфери вихровості за часу `O(1)` без зайвого копіювання `N_x · N_y` елементів.

## 9. Порівняння Ейлерових сіткових та Лагранжевих вихрових методів

При розв'язанні задач нестійкості зсувних течій застосовуються два фундаментально різних підходи до дискретизації:

1. **Ейлеровий сітковий підхід (Eulerian Grid Method):** Обчислювальна область ділиться на фіксовану 2D сітку вузлів. Швидкість та вихровість обчислюються у нерухомих точках простору. Головні переваги — проста реалізація, легка обробка складних граничних умов та ефективна паралелізація на CPU/GPU. Головний недолік — виникнення числової в'язкості на грубих сітках.
2. **Лагранжевий метод точкових вихорів (Vortex Particle Method):** Вихрове поле репрезентується сукупністю рухомих дискретних вихрових частинок. Кожна частинка з циркуляцією `Γ_k` переноситься зі швидкістю, яка обчислюється за законом Біо — Савара — Лапласа від усіх інших частинок:

```
u_k = Σ_j [ -Γ_j · (y_k - y_j) / ( 2·π · ((x_k - x_j)² + (y_k - y_j)² + ε²) ) ]   [ЗАКОН БІО — САВАРА]
```

де `ε` — радіус ядра згладжування частинки. Метод частинок повністю позбавлений штучної числової дисипації, проте вимагає `O(N²)` операцій або використання алгоритму швидкого многополюсника FMM (`O(N · log N)`).

## 10. Схема Аракави для збереження енстрофії та кінетичної енергії

Однією з головних проблем чисельного моделювання нестійкості у 2D формулюванні є штучна числова дисипація або накопичення помилок при дискретизації нелінійного добутку Якобіана `J(ψ, ω) = (∂ψ/∂x)·(∂ω/∂y) - (∂ψ/∂y)·(∂ω/∂x)`.

Японський метеоролог Акіо Аракава (Akio Arakawa) у 1966 році розробив спеціальний дев'ятиточковий шаблон різницевої схеми, який дискретно задовольняє такі фундаментальні тотожності збереження:

```
∬ J(ψ, ω) dx dy = 0         [збереження середньої вихровості]
∬ ψ · J(ψ, ω) dx dy = 0     [збереження кінетичної енергії]
∬ ω · J(ψ, ω) dx dy = 0     [збереження енстрофії]
```

Схема Аракави записується як середня арифметична комбінація трьох математично еквівалентних, але різницево відмінних формалізмів Якобіана:

```
J_Arakawa = 1/3 · ( J_1 + J_2 + J_3 )   [СХЕМА АРАКАВИ]
```

де `J_1` — стандартні центральні різниці, `J_2` — різниці в формалізму переносу градієнта, а `J_3` — різниці у формалізму збереження об'єму. Використання схеми Аракави запобігає нестійкому спектральному блокуванню (aliasing instability) і дозволяє моделювати згортання вихорів без штучної дисипації навіть за малих коефіцієнтів в'язкості.

## 11. Спектральний розв'язувач рівняння Пуассона у спектральному просторі Фур'є

Для зсувного шару з періодичними граничними умовами вздовж обох осей `x` та `y` найефективнішим методом є псевдоспектральний метод Фур'є. Рівняння Пуассона `∇²ψ = -ω` у спектральному просторі перетворюється на ззвичайне алгебраїчне співвідношення:

```
-(k_x² + k_y²) · ψ_hat(k_x, k_y) = -ω_hat(k_x, k_y)   [РІВНЯННЯ ПУАССОНА В СПЕКТРАЛЬНОМУ ПРОСТОРІ]
```

звідки розв'язок для гармонік функції струменю `ψ_hat` знаходить за одну операцію ділення:

```
ψ_hat(k_x, k_y) = ω_hat(k_x, k_y) / (k_x² + k_y²)   [для k_x² + k_y² ≠ 0]
```

Після цього виконується зворотне швидке перетворення Фур'є (IFFT), що дає точне поле `ψ(x, y)` за `O(N · log N)` операцій без відносних похибок ітераційних методів Якобі чи Зейделя.

import numpy as np

class KelvinHelmholtzSolverPy:
    def __init__(self, nx=128, ny=128, lx=1.0, ly=1.0, nu=1e-4, dt=1e-3):
        self.nx = nx
        self.ny = ny
        self.lx = lx
        self.ly = ly
        self.dx = lx / nx
        self.dy = ly / ny
        self.nu = nu
        self.dt = dt
        
        self.w = np.zeros((ny, nx))  # Вихровість
        self.psi = np.zeros((ny, nx)) # Функція струменю
        self.u = np.zeros((ny, nx))   # Подовжня швидкість
        self.v = np.zeros((ny, nx))   # Поперечна швидкість
        
    def init_shear_layer(self, u0=1.0, delta=0.05, eps=0.05):
        y = np.linspace(-self.ly/2, self.ly/2, self.ny)
        x = np.linspace(0, self.lx, self.nx)
        X, Y = np.meshgrid(x, y)
        
        # Основний профіль швидкості U(y) = U0 * tanh(y / delta)
        u_base = u0 * np.tanh(Y / delta)
        v_pert = eps * u0 * np.sin(2 * np.pi * X / self.lx) * np.exp(-(Y / delta)**2)
        
        self.u = u_base
        self.v = v_pert
        
        # Обчислення початкової вихровості w = dv/dx - du/dy
        du_dy = np.gradient(self.u, self.dy, axis=0)
        dv_dx = np.gradient(self.v, self.dx, axis=1)
        self.w = dv_dx - du_dy

    def solve_poisson_jacobi(self, max_iter=200, tol=1e-5):
        """Розв'язок ∇²ψ = -w методом Якобі"""
        dx2 = self.dx**2
        dy2 = self.dy**2
        factor = 0.5 * (dx2 * dy2) / (dx2 + dy2)
        
        for _ in range(max_iter):
            psi_old = self.psi.copy()
            self.psi[1:-1, 1:-1] = factor * (
                (psi_old[1:-1, 2:] + psi_old[1:-1, :-2]) / dx2 +
                (psi_old[2:, 1:-1] + psi_old[:-2, 1:-1]) / dy2 +
                self.w[1:-1, 1:-1]
            )
            # Періодичні граничні умови за X
            self.psi[:, 0] = self.psi[:, -2]
            self.psi[:, -1] = self.psi[:, 1]
            
            if np.max(np.abs(self.psi - psi_old)) < tol:
                break
                
        # Оновлення швидкостей u = dψ/dy, v = -dψ/dx
        self.u[1:-1, :] = (self.psi[2:, :] - self.psi[:-2, :]) / (2 * self.dy)
        self.v[:, 1:-1] = -(self.psi[:, 2:] - self.psi[:, :-2]) / (2 * self.dx)

    def step(self):
        self.solve_poisson_jacobi()
        
        # Обчислення конвекції та дифузії вихровості
        dw_dx = np.gradient(self.w, self.dx, axis=1)
        dw_dy = np.gradient(self.w, self.dy, axis=0)
        d2w_dx2 = np.gradient(dw_dx, self.dx, axis=1)
        d2w_dy2 = np.gradient(dw_dy, self.dy, axis=0)
        
        convection = self.u * dw_dx + self.v * dw_dy
        diffusion = self.nu * (d2w_dx2 + d2w_dy2)
        
        # Крок за часом (Ейлер)
        self.w[1:-1, 1:-1] += self.dt * (-convection[1:-1, 1:-1] + diffusion[1:-1, 1:-1])
        
        # Періодичні умови за X
        self.w[:, 0] = self.w[:, -2]
        self.w[:, -1] = self.w[:, 1]

if __name__ == "__main__":
    sim = KelvinHelmholtzSolverPy(nx=64, ny=64)
    sim.init_shear_layer()
    for t in range(100):
        sim.step()
    print("Python KH simulation success. Max vorticity:", np.max(np.abs(sim.w)))

    free(s->psi);
    free(s->u);
    free(s->v);
    free(s);

void kh_init_shear(kh_solver_c_t *s, double u0, double delta, double eps) {
    for (int j = 0; j < s->ny; j++) {
        double y = -s->ly / 2.0 + j * s->dy;
        for (int i = 0; i < s->nx; i++) {
            double x = i * s->dx;
            int idx = j * s->nx + i;
            
            s->u[idx] = u0 * tanh(y / delta);
            s->v[idx] = eps * u0 * sin(2.0 * M_PI * x / s->lx) * exp(-(y / delta) * (y / delta));
        }
    }
    
    /* Обчислення початкової вихровості w = dv/dx - du/dy */
    for (int j = 1; j < s->ny - 1; j++) {
        for (int i = 1; i < s->nx - 1; i++) {
            int idx = j * s->nx + i;
            double du_dy = (s->u[(j+1)*s->nx + i] - s->u[(j-1)*s->nx + i]) / (2.0 * s->dy);
            double dv_dx = (s->v[j*s->nx + (i+1)] - s->v[j*s->nx + (i-1)]) / (2.0 * s->dx);
            s->w[idx] = dv_dx - du_dy;
        }
    }
}

void kh_step(kh_solver_c_t *s) {
    int nx = s->nx, ny = s->ny;
    double dx2 = s->dx * s->dx, dy2 = s->dy * s->dy;
    double factor = 0.5 * (dx2 * dy2) / (dx2 + dy2);
    
    /* Ітерації Якобі для ∇²ψ = -w */
    for (int iter = 0; iter < 100; iter++) {
        for (int j = 1; j < ny - 1; j++) {
            for (int i = 1; i < nx - 1; i++) {
                int idx = j * nx + i;
                s->psi[idx] = factor * (
                    (s->psi[j*nx + (i+1)] + s->psi[j*nx + (i-1)]) / dx2 +
                    (s->psi[(j+1)*nx + i] + s->psi[(j-1)*nx + i]) / dy2 +
                    s->w[idx]
                );
            }
        }
    }
    
    /* Оновлення швидкостей u = dψ/dy, v = -dψ/dx */
    for (int j = 1; j < ny - 1; j++) {
        for (int i = 1; i < nx - 1; i++) {
            int idx = j * nx + i;
            s->u[idx] =  (s->psi[(j+1)*nx + i] - s->psi[(j-1)*nx + i]) / (2.0 * s->dy);
            s->v[idx] = -(s->psi[j*nx + (i+1)] - s->psi[j*nx + (i-1)]) / (2.0 * s->dx);
        }
    }
    
    /* Крок переносу вихровості */
    for (int j = 1; j < ny - 1; j++) {
        for (int i = 1; i < nx - 1; i++) {
            int idx = j * nx + i;
            double dw_dx = (s->w[j*nx + (i+1)] - s->w[j*nx + (i-1)]) / (2.0 * s->dx);
            double dw_dy = (s->w[(j+1)*nx + i] - s->w[(j-1)*nx + i]) / (2.0 * s->dy);
            double d2w_dx2 = (s->w[j*nx + (i+1)] - 2.0*s->w[idx] + s->w[j*nx + (i-1)]) / dx2;
            double d2w_dy2 = (s->w[(j+1)*nx + i] - 2.0*s->w[idx] + s->w[(j-1)*nx + i]) / dy2;
            
            double conv = s->u[idx] * dw_dx + s->v[idx] * dw_dy;
            double diff = s->nu * (d2w_dx2 + d2w_dy2);
            
            s->w[idx] += s->dt * (-conv + diff);
        }
    }
}

#include <iostream>
#include <vector>
#include <cmath>
#include <memory>
#include <algorithm>

class KelvinHelmholtzSolverCpp {
private:
    int nx_, ny_;
    double lx_, ly_, dx_, dy_;
    double nu_, dt_;
    
    std::vector<double> w_;   // Вихровість
    std::vector<double> psi_; // Функція струменю
    std::vector<double> u_;   // Подовжня швидкість
    std::vector<double> v_;   // Поперечна швидкість

    [[nodiscard]] inline size_t idx(int i, int j) const noexcept {
        return static_cast<size_t>(j * nx_ + i);
    }

public:
    KelvinHelmholtzSolverCpp(int nx, int ny, double lx, double ly, double nu, double dt)
        : nx_(nx), ny_(ny), lx_(lx), ly_(ly), dx_(lx / nx), dy_(ly / ny), nu_(nu), dt_(dt),
          w_(nx * ny, 0.0), psi_(nx * ny, 0.0), u_(nx * ny, 0.0), v_(nx * ny, 0.0) {}

    void initShearLayer(double u0 = 1.0, double delta = 0.05, double eps = 0.05) {
        for (int j = 0; j < ny_; ++j) {
            double y = -ly_ / 2.0 + j * dy_;
            for (int i = 0; i < nx_; ++i) {
                double x = i * dx_;
                u_[idx(i, j)] = u0 * std::tanh(y / delta);
                v_[idx(i, j)] = eps * u0 * std::sin(2.0 * M_PI * x / lx_) * std::exp(-(y / delta) * (y / delta));
            }
        }

        for (int j = 1; j < ny_ - 1; ++j) {
            for (int i = 1; i < nx_ - 1; ++i) {
                double du_dy = (u_[idx(i, j + 1)] - u_[idx(i, j - 1)]) / (2.0 * dy_);
                double dv_dx = (v_[idx(i + 1, j)] - v_[idx(i - 1, j)]) / (2.0 * dx_);
                w_[idx(i, j)] = dv_dx - du_dy;
            }
        }
    }

    void solvePoissonJacobi(int maxIter = 100) {
        double dx2 = dx_ * dx_;
        double dy2 = dy_ * dy_;
        double factor = 0.5 * (dx2 * dy2) / (dx2 + dy2);

        for (int iter = 0; iter < maxIter; ++iter) {
            for (int j = 1; j < ny_ - 1; ++j) {
                for (int i = 1; i < nx_ - 1; ++i) {
                    psi_[idx(i, j)] = factor * (
                        (psi_[idx(i + 1, j)] + psi_[idx(i - 1, j)]) / dx2 +
                        (psi_[idx(i, j + 1)] + psi_[idx(i, j - 1)]) / dy2 +
                        w_[idx(i, j)]
                    );
                }
            }
        }

        for (int j = 1; j < ny_ - 1; ++j) {
            for (int i = 1; i < nx_ - 1; ++i) {
                u_[idx(i, j)] =  (psi_[idx(i, j + 1)] - psi_[idx(i, j - 1)]) / (2.0 * dy_);
                v_[idx(i, j)] = -(psi_[idx(i + 1, j)] - psi_[idx(i - 1, j)]) / (2.0 * dx_);
            }
        }
    }

    void step() {
        solvePoissonJacobi();

        double dx2 = dx_ * dx_;
        double dy2 = dy_ * dy_;

        std::vector<double> w_next = w_;
        for (int j = 1; j < ny_ - 1; ++j) {
            for (int i = 1; i < nx_ - 1; ++i) {
                size_t id = idx(i, j);
                double dw_dx = (w_[idx(i + 1, j)] - w_[idx(i - 1, j)]) / (2.0 * dx_);
                double dw_dy = (w_[idx(i, j + 1)] - w_[idx(i, j - 1)]) / (2.0 * dy_);
                double d2w_dx2 = (w_[idx(i + 1, j)] - 2.0 * w_[id] + w_[idx(i - 1, j)]) / dx2;
                double d2w_dy2 = (w_[idx(i, j + 1)] - 2.0 * w_[id] + w_[idx(i, j - 1)]) / dy2;

                double conv = u_[id] * dw_dx + v_[id] * dw_dy;
                double diff = nu_ * (d2w_dx2 + d2w_dy2);

                w_next[id] += dt_ * (-conv + diff);
            }
        }
        w_ = std::move(w_next);
    }

    [[nodiscard]] double getMaxVorticity() const noexcept {
        double max_w = 0.0;
        for (double val : w_) {
            max_w = std::abs(val) > max_w ? std::abs(val) : max_w;
        }
        return max_w;
    }
};

int main() {
    auto solver = std::make_unique<KelvinHelmholtzSolverCpp>(64, 64, 1.0, 1.0, 1e-4, 1e-3);
    solver->initShearLayer();
    for (int t = 0; t < 50; ++t) {
        solver->step();
    }
    std::cout << "C++ KH simulation finished. Max vorticity: " << solver->getMaxVorticity() << std::endl;
    return 0;
}

## 13. Фізичний аналіз результатів розв'язку та еволюція вихорів

Під час виконання розв'язувача на сітці `128×128` або вище спостерігається три послідовні фізичні фази розвитку нестійкості:

1. **Лінійна фаза (початковий ріст):** Синусоїдальне збурення амплітуди `v'` зростає за експоненційним законом `exp(γ·t)`. На цій фазі лінійний аналіз Орра — Зоммерфельда дає точний опис інкременту зростання `γ`.
2. **Нелінійне згортання (Roll-up phase):** Амплітуда збурення досягає співрозмірності з товщиною зсувного шару `δ`. Зсувний шар згортається у вихровий скручувальний кокон (котяче око — Kelvin's cats-eyes vortices). Концентрація вихровості `ω` у ядрах вихорів локально зростає у кілька разів.
3. **Парування вихорів та вторинна нестійкість (Vortex pairing):** Сусідні вихори починають обертатися один навколо одного й зливатися в один великий вихор подвійного масштабу. На крилах зсуву між вихорами виникають дрібномасштабні вторинні нестійкості, які завершуються швидким розпадом течії на тривимірний турбулентний хаос.

## 15. Оптимізація паралельних обчислень OpenMP та GPU

У високопродуктивних обчисленнях (HPC) моделювання 2D та 3D гидродинамічних нестійкостей вимагає сіток порядку `1024³` вузлів та вище. Основні етапи розв'язувача легко паралелізуються за допомогою технології OpenMP або CUDA:

1. **OpenMP паралелізація циклів:** Вкладені цикли по просторових вузлах `i` та `j` розмічаються директивами `#pragma omp parallel for collapse(2)` у C/C++, що забезпечує рівномірне завантаження всіх ядер процесора.
2. **Векторизація SIMD:** Використання вирівняних за пам'яттю масивів `alignas(64)` дозволяє компілятору застосовувати векторизовані інструкції AVX-512 для одночасного обчислення 8 або 16 значень вихровості за один такт процесора.
3. **Обчислення на GPU (CUDA):** Ітерації розв'язувача Пуассона реалізуються у вигляді кубиків сітки ниток CUDA (Grid of Thread Blocks), що дає прискорення обчислень у 50–100 разів порівняно з послідовним CPU кодом.

## 16. Пастки та підводні камені чисельного моделювання нестійкості

Під час практичної чисельної реалізації моделювання нестійкостей виникають чотири типові проблеми:

### 1. Схема першого порядку та числова дисипація (Numerical Viscosity)
Використання простих перших протипотокових різницевих схем (upwind schemes) вносить потужну **штучну числову в'язкість** `ν_num ≈ 1/2 · |u| · Δx`. Якщо числова в'язкість перевищує фізичну в'язкість рідини `ν_num > ν`, нестійкість штучно демпфується й вихори не згортаються.
*Вирішення:* Використовувати схеми високого порядку точності (WENO-5, TVD або спектральні методи Фур'є).

### 2. Псевдо-паразитні високочастотні осциляції (Gibbs Phenomenon)
При нелінійному згортанні зсувного шару утворюються тонкі вихрові нитки з високими градієнтами. Недостатній просторовий дозвіл сітки `Δx` призводить до виникнення паразитного "шуму" й високочастотного розлітання розв'язку.
*Вирішення:* Застосовувати сіткову адаптацію (AMR) або додавати мінімальну фільтрацію спектру.

### 3. Збереження циркуляції та імпульсу
У нев'язкому граничному випадку `ν → 0` система мусить строго зберігати повну циркуляцію `Γ = ∬ ω dx dy` та енстрофію `Ω = ∬ ω² dx dy`. Прості рознесені сітки порушують ці закони збереження.
*Вирішення:* Використовувати збіжні за формою дисипативні нестисливі схеми (Arakawa scheme for Jacobian terms).

### 4. Визначення просторового дозволу Колмогорова та Бачелора
Для повномасштабного обчислення DNS (Direct Numerical Simulation) крок сітки `Δx` повинен бути меншим за **колмогорівський масштаб довжини** `η = (ν³ / ε)^(1/4)`, де `ε` — швидкість дисипації турбулентної енергії. Якщо `Δx > η`, дрібні вихори випадають із розв'язку, створюючи хибні великомасштабні вихрові скупчення.

| Параметр чисельної схеми | Наслідок неправильного вибору | Правильне значення |
| :--- | :--- | :--- |
| **Крок за часом `Δt`** | Чисельна вибухова нестійкість схеми | `CFL = |u|·Δt/Δx < 0.3` |
| **Схема конвекції** | Згладжування й вбивання вихорів | Схема 2-го/4-го порядку або WENO-5 |
| **Розв'язувач Пуассона** | Порушення умови нестисливості `∇·u ≠ 0` | Похибка Якобі/FFT `< 10⁻⁶` |
| **Просторовий крок `Δx`** | Втрата дрібномасштабних вихорів | `Δx < η` (колмогорівський масштаб) |
