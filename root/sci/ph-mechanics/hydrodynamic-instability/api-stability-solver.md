# 📋 Інтерфейс та контракт спектрального розв'язувача нестійкостей

Цей документ визначає публічний програмний інтерфейс (API Contract), схеми даних та інженерну специфікацію C/C++ бібліотеки `libhydro_stability` для чисельного розв'язання задач лінійної нестійкості зсувних потоків спектральним методом Чебишова (Chebyshev collocation method). Бібліотека призначена для розв'язання генералізованої спектральної задачі на власні значення для рівнянь Орра — Зоммерфельда й Релея в задачах аеродинаміки, гідродинаміки та теоретичної механіки.

## 1. Загальна архітектура, контракти пам'яті та потокобезпечність

Бібліотека `libhydro_stability` розроблена за стандартами C11 та C++17. Вона надає суворо C-сумісний ABI (Application Binary Interface), що дозволяє використовувати її як у чистих C-проектах, так і підключати через FFI до мов Python, Rust, Julia чи Go.

### 1.1 Контракт управління пам'яттю
Усі об'єкти, виділені всередині функцій бібліотеки (профілі `hydro_profile_t` та результати `hydro_spectrum_result_t`), залишаються під володінням бібліотеки до тих пір, поки користувач явно не звільнить їх відповідними процедурами `hydro_profile_free()` та `hydro_spectrum_result_free()`. Спроба виклику `free()` напряму на вказівниках структури призводить до невизначеної поведінки (Undefined Behavior). Кожна виділена область пам'яті вирівнюється за кордоном 64 байт (`alignas(64)`) для забезпечення максимальної продуктивності векторних інструкцій AVX-512 та SIMD операцій на багатьох ядерних обчислювальних вузлах. Всі процедури виділення даних ретельно перевіряють результат виклику системного розподілювача пам'яті і повертають статус `HYDRO_ERR_OUT_OF_MEMORY` у разі вичерпання системних ресурсів.

### 1.2 Потокобезпечність та реентерабельність
Усі обчислювальні функції є строго повторно входжуваними (reentrant) і не використовують глобальний або статичний стан. Різні екземпляри структур `hydro_grid_config_t` та розв'язувачі можуть безпечно виконуватися паралельно у різних потоках POSIX (pthread) або OpenMP без додаткового блокування м'ютексами. Бібліотека повністю безпечна для використання в багатопотокових обчислювальних вузлах сучасних суперкомп'ютерів.

### 1.3 Обробка помилок та діагностичне логування
Жодна функція C API не генерує винятків (exceptions). Будь-які помилки чисельної незбіжності або неправильних параметрів повертаються через код статусу `hydro_status_t`. У C++ обгортці помилки автоматично транслюються у винятки типу `std::runtime_error` або `std::invalid_argument`. 

Для детальної діагностики обчислювального процесу бібліотека надає зручну систему логування з трьома рівноправними рівнями деталізації (`HYDRO_LOG_NONE`, `HYDRO_LOG_INFO`, `HYDRO_LOG_DEBUG`).

## 2. Повний конвейер обчислення спектра (6 Етапів)

Обчислювальний конвейер розв'язання спектральної задачі в бібліотеці `libhydro_stability` складається з шести послідовних етапів:

1. **Етап 1 (Генерація вузлів Чебишова):** Обчислюються точки Гаусса — Лобатто `y_i = cos(i·π/N)` у діапазоні `[-1, 1]`.
2. **Етап 2 (Формування диф-матриць):** Формуються щільні матриці першої `D1`, другої `D2 = D1²` та четвертої `D4 = D2²` похідних Чебишова розміром `(N+1) × (N+1)`.
3. **Етап 3 (Збирання операторів A та B):** Будуються комплексна матриця в'язкості `B = D2 - α²·I` та оператор Орра — Зоммерфельда `A = U·B - diag(U'') + i/(α·Re)·(D4 - 2α²D2 + α⁴I)`.
4. **Етап 4 (Накладання граничних умов):** Перші два та останні два рядки матриць `A` та `B` заміщуються рівняннями прилипання `ϕ(±1) = 0` та `ϕ'(±1) = 0`.
5. **Етап 5 (Розв'язання спектральної проблеми):** Викликається процедура `zggev` з пакету LAPACK або метод Арнольді з ARPACK для знаходження комплексних власних чисел `c_k = c_r + i·c_i`.
6. **Етап 6 (Постобробка та сортування):** Власні числа сортуються за уявна частиною `c_i` у порядку спадання. Визначається максимальний інкремент зростання `γ_max = α · max(c_i)` та відповідна власна мода `ϕ_max(y)`.

## 3. Моделювання вільних поверхонь та капілярно-гравітаційних хвиль (Free Surface BC)

При аналізі нестійкостей плівкових течій чи капілярних струменів (наприклад, нестійкість Релея — Тейлора у відкритих каналах) верхня межа домену `y = 1` є вільною від нормальних та дотичних напружень.

Дискретне накладання граничних умов вільної поверхні `HYDRO_BC_FREE_SURFACE` описується кінематичною співвіднесеністю та динамічною умовою стрибка тиску з урахуванням поверхневого натягу:

```
(U - c) · ϕ' - U' · ϕ = 0                           [КІНЕМАТИЧНА УМОВА НА ВІЛЬНІЙ ПОВЕРХНІ]
(D2 + α²) ϕ = 0                                     [ВІДСУТНІСТЬ ДОТИЧНОГО НАПРУЖЕННЯ]
i/(α·Re)·(D3 - 3α²D1) ϕ + (U - c)·D1 ϕ + U' ϕ = We⁻¹ · α² · h   [ДИНАМІЧНА УМОВА З СИЛОЮ ПОВЕРХНЕВОГО НАТЯГУ]
```

де `We = ρ · U₀² · h / σ_surf` — безрозмірне число Вебера (Weber number). Використання цієї умови дозволяє моделювати гравітаційно-капілярний розпад рідинних струменів на окремі краплі (Rayleigh-Plateau breakup).

## 4. Моделювання імпульсної нестійкості Рихтмаєра — Мешкова (RMI API Extension)

Ударно-хвильова нестійкість Рихтмаєра — Мешкова виникає при проходженні ударної хвилі через збурену межу розділу двох середовищ із різною густиною.

На відміну від нестійкості Релея — Тейлора, де прискорення `g` є постійним, при нестійкості Рихтмаєра — Мешкова прискорення має характер короткого дельта-подібного імпульсу `g(t) = Δv · δ(t)`.

Бібліотека надає процедуру `hydro_profile_create_shock_interface()` для розрахунку лінійного зростання амплітуди збурення за формулою Рихтмаєра:

```
v_RM = k · A_atwood · Δv · y0   [ШВИДКІСТЬ ЗРОСТАННЯ АМПЛІТУДИ РИХТМАЄРА]
```

де `A_atwood = (ρ2 - ρ1) / (ρ2 + ρ1)` — число Атвуда, `Δv` — стрибок швидкості межі під дією ударної хвилі, `y0` — початкова амплітуда збурення.

## 5. Маппінг 3D збурень через перетворення Сквайрса (Squire's Reduction API)

Згідно з теоремою Сквайрса, тривимірне синусоїдальне збурення з подовжнім хвильовим числом `α` та поперечним хвильовим числом `β` при числі Рейнольдса `Re` еквівалентне двовимірному збуренню з еквівалентними параметрами:

```
α_2D = sqrt( α² + β² )                       [ЕКВІВАЛЕНТНЕ 2D ХВИЛЬОВЕ ЧИСЛО]
Re_2D = Re · ( α / α_2D )                     [ЕКВІВАЛЕНТНЕ 2D ЧИСЛО РЕЙНОЛЬДСА]
```

Оскільки `Re_2D < Re` при `β > 0`, двовимірні збурення є завжди більш нестійкими за тривимірні при менших числах Рейнольдса.

Бібліотека надає функцію автоматичного маппінгу `hydro_transform_squire_3d_to_2d()`, яка прозоро перераховує 3D конфігурацію в еквівалентну 2D задачу перед викликом спектрального розв'язувача.

## 6. Фільтрація паразитичних псевдоспектральних мод (Spurious Mode Filter)

При застосуванні спектрального методу Чебишова високого порядку `N > 128` через нестійкість граничних умов четвертого порядку на матричному рівні виникають **паразитичні власні значення** (Spurious Eigenvalues). Ці значення не відповідають жодному фізичному розв'язку диференціального рівняння і зазвичай мають надзвичайно велику від'ємну або позитивну уявну частину `|c_i| > 100`.

Модуль постобробки здійснює автоматичну фільтрацію паразитичних мод за двома критеріями:
1. **Критерій гладкості власного вектора:** Для кожного власного вектора `ϕ` обчислюється спектральна норма другої похідної. Власні вектори з високочастотними осциляціями біля стінок відкидаються.
2. **Критерій інваріантності сітки:** Власні значення обчислюються на двох сітках `N` та `N + 16`. Власне число вважається фізичним лише у тому разі, якщо зміна сітки зміщує його у комплексній площині менш ніж на `10⁻⁶`.

## 7. Моделювання ламінарного пограничного шару Блазіуса та Фалькнера — Скена

Для аеродинамічного аналізу стійкості пограничного шару крила літака бібліотека надає розширений інтерфейс обчислення самоподібного профілю Блазіуса (Blasius Boundary Layer Profile).

У цьому випадку безрозмірна координата `η = y / δ*(x)` перетворюється на напівнескінченний домен `η ∈ [0, η_max]` (зазвичай `η_max = 10`), який стискається на інтервал Чебишова `[-1, 1]` за допомогою алгебраїчного або експоненційного відображення Гроша — Орсага (Grosch-Orszag Mapping):

```
y_physical = L_scale · (1 + y_chebyshev) / (1 - y_chebyshev + 2 · L_scale / η_max)   [ВІДОБРАЖЕННЯ ГРОША — ОРСАГА]
```

це дозволяє згущувати точки колакації у зоні високих градієнтів швидкості поблизу стінки.

Для профілів Фалькнера — Скена (Falkner-Skan family) з градієнтом тиску задається додатковий параметр градієнта `β_FS`:
- `β_FS > 0`: Конфузорний потік з прискорювальним градієнтом тиску (підвищує стійкість).
- `β_FS = 0`: Класичний пограничний шар Блазіуса (`Re_crit = 520` за товщиною витіснення).
- `β_FS < 0`: Дифузорний потік із затримувальним градієнтом тиску (прискорює відрив та нестійкість).

## 8. Інтерфейс резольвентного та немодального аналізу (Resolvent Analysis API)

Для несамоспряжених операторів гідродинамічної стійкості (де матриця `A` не є нормальною: `A · A^H ≠ A^H · A`) власні вектори не є ортогональними. Це створює явище **перехідного підсилення енергії** (Transient Growth), коли навіть у лінійно стійкому потоці (`c_i < 0`) мала пертурбація збільшує свою кінетичну енергію у сотні разів перед остаточним затуханням.

Модуль резольвентного аналізу обчислює максимальний коефіцієнт підсилення гармонічного вимушуючого збурення `G(ω)` шляхом сингулярного розкладу (SVD) оператора резольвенти `R(ω)`:

```
R(ω) = (i · ω · B - A)⁻¹   [ОПЕРАТОР РЕЗОЛЬВЕНТИ]
G(ω) = max ||R(ω)·f||_E / ||f||_E = σ_max( R(ω) )   [ОПТИМАЛЬНИЙ КОЕФІЦІЄНТ ПІДСИЛЕННЯ]
```

де `σ_max` — максимальне сингулярне значення резольвенти в енергетичній нормі. Ліва та права сингулярні моди дають оптимальну форму вхідного збурення (Input Forcing Mode) та вихідної відповіді потоку (Output Response Mode).

## 9. Повний перелік кодів помилок `hydro_status_t`

Кожна обчислювальна процедура бібліотеки повертає дійсне значення переліку `hydro_status_t`. Від'ємні числа означають фатальні помилки обчислювального циклу або валідації вхідних даних:

```c
typedef enum {
    HYDRO_SUCCESS                    =  0,  /* Успішне виконання операції */
    HYDRO_ERR_INVALID_PARAM          = -1,  /* Некоректний вхідний параметр (NULL, N < 4, Re <= 0) */
    HYDRO_ERR_OUT_OF_MEMORY          = -2,  /* Помилка динамічного виділення пам'яті */
    HYDRO_ERR_SINGULAR_MATRIX        = -3,  /* Сингулярна або вироджена матриця в'язкості B */
    HYDRO_ERR_CONVERGENCE_FAILED     = -4,  /* Незбіжність ітерацій QZ/Арнольді алгоритму */
    HYDRO_ERR_INVALID_BC             = -5,  /* Непідтримуваний тип граничних умов */
    HYDRO_ERR_PROFILE_MISMATCH       = -6   /* Несумісність розміру сітки профілю та конфігурації */
} hydro_status_t;
```

### Детальна розшифровка кодів помилок та рекомендації щодо усунення

1. `HYDRO_ERR_INVALID_PARAM`: Повертається, якщо один із вказівників дорівнює `NULL`, чисельне значення `Re ≤ 0`, хвильове число `alpha ≤ 0`, або кількість точок сітки `N < 8`. Дії користувача: перевірити вхідні параметри перед викликом.
2. `HYDRO_ERR_OUT_OF_MEMORY`: Виникає при неможливості виділити масиви для матрицій `A` та `B` розміром `(N × N)` комплексних чисел. Дії користувача: зменшити порядок дискретизації `N` або звільнити невикористану пам'ять.
3. `HYDRO_ERR_SINGULAR_MATRIX`: Повідомляє про виродженість матриці `B` при застосуванні алгоритму `QZ`. Виникає при некоректному накладанні граничних умов четвертого порядку на межах домену. Дії користувача: перевірити тип граничних умов.
4. `HYDRO_ERR_CONVERGENCE_FAILED`: Означає, що ітераційний розв'язувач LAPACK `zggev` не зміг знайти власні значення за 300 ітерацій (зазвичай через псевдоспектральний шум за надто великих чисел Рейнольдса `Re > 10^5`). Дії користувача: перейти на метод Арнольді або застосувати фільтрацію спектру.

## 11. Алгебраїчна побудова дискретних матричних операторів

Розв'язання рівняння Орра — Зоммерфельда методом Чебишова вимагає побудови комплексних матриць `A` та `B` розміром `(N+1) × (N+1)`.

### 11.1 Алгоритм побудови матриці диференціювання Чебишова
Дискретизація просторового домену виконується у вузлах Чебишова — Гаусса — Лобатто `y_i = cos(i · π / N)` для `i = 0, 1, …, N`. Матриця першої похідної `D1` обчислюється за прямими формулами зсуву Чебишова:

```
D1_ij = (c_i / c_j) · (-1)^(i+j) / (y_i - y_j),   i ≠ j   [МАТРИЦЯ ДИФЕРЕНЦІЮВАННЯ D1]
D1_ii = -y_i / (2 · (1 - y_i²)),                 1 <= i <= N-1
D1_00 = (2 · N² + 1) / 6
D1_NN = -(2 · N² + 1) / 6
```

матриці вищих похідних обчислюються прямою матричною дуплікацією: `D2 = D1 · D1` та `D4 = D2 · D2`. Головна перевага спектрального методу Чебишова порівняно зі скінченно-різницевими схемами полягає в **експоненційній швидкості збіжності** (Spectral Convergence), коли похибка дискретизації зменшується як `O(exp(-c·N))`, що дозволяє досягати машинної точності при малих `N ≈ 64 … 128`.

### 11.2 Збирання лівої та правої матриць
Оператори рівняння Орра — Зоммерфельда `(U - c) · (D2 - α²·I) · ϕ - U'' · ϕ = -i/(α·Re) · (D4 - 2·α²·D2 + α⁴·I) · ϕ` записуються у вигляді генералізованої спектральної задачі:

```
A · ϕ = c · B · ϕ   [ГЕНЕРАЛІЗОВАНА СПЕКТРАЛЬНА ЗАДАЧА]
```

де елементи матриць мають вигляд:

```
B = D2 - α² · I   [МАПРИЦЯ КІНЕТИЧНОЇ ЕНЕРГІЇ В'ЯЗКОСТІ]
A = U · B - diag(U'') + (i / (α · Re)) · (D4 - 2·α²·D2 + α⁴·I)   [ОПЕРАТОР ОРРА — ЗОММЕРФЕЛЬДА]
```

### 11.3 Модифікація для граничних умов прилипання
На твердих стінках `y = ±1` виконуються умови `ϕ(±1) = 0` та `ϕ'(±1) = 0`. У дискретній матриці це досягається заміною перших двох та останніх двох рядків матриць `A` та `B`:
- Рядки 0 та N гарантують нульове значення власного вектора: `A[0, :] = [1, 0, …, 0]`, `B[0, :] = [0, 0, …, 0]`.
- Рядки 1 та N-1 гарантують нульову похідну на стінці за допомогою відповідних рядків матриці `D1`: `A[1, :] = D1[0, :]`, `B[1, :] = [0, 0, …, 0]`.

Така редукція рядків гарантує строго точне виконання граничних умов і виключає виникнення паразитного спектрального шуму.

## 12. Деталі розміщення даних у пам'яті (Memory Layout)

Для максимальної сумісності з Fortran-бібліотеками LAPACK та BLAS усі двовимірні комплексні матриці `A` та `B` розміщуються у пам'яті у **стовпчиковому порядку** (Column-Major Order).

Елемент матриці з індексами `(row, col)` зберігається за одномірним зміщенням:

```
offset = col · (N + 1) + row   [COLUMN-MAJOR ORDER ЗМІЩЕННЯ]
```

Комплексні числа зберігаються у стандартному C99 / C++11 форматі у вигляді двох послідовних чисел подвійної точності `double` (дісна та уявна частини, `sizeof(hydro_complex_t) == 16 bytes`). Це дозволяє передавати вказівник `(lapack_complex_double*)a_matrix` напряму у LAPACK функцію `zggev` без проміжного копіювання даних.

## 13. Специфікація розширення для теплової конвекції Релея — Бенара

Бібліотека `libhydro_stability` підтримує аналіз спектральної стійкості термоконвективних течій у наближенні Буссінеска.

У цьому випадку спектральна система складається з двох зв'язаних рівнянь 4-го порядку для вертикальної швидкості `w(y)` та 2-го порядку для температурного збурення `θ(y)`:

```
(D2 - α²)² w = α² · Ra · θ                             [РІВНЯННЯ РУХУ В БУССІНЕСКУ]
(D2 - α²) θ = -Pr · w                                   [РІВНЯННЯ ТЕПЛОПРОВІДНОСТІ]
```

Розв'язання здійснюється побудовою блочної матриці `A_boussinesq` розміром `(2N+2) × (2N+2)` та знаходженням критичного числа Релея `Ra_crit ≈ 1707.76` для плоских межових шарів.

## 15. Алгоритми QZ (LAPACK) та Арнольді (ARPACK)

Бібліотека надає два чисельні методи розв'язання спектральної задачі залежно від розміру сітки та задачі:

1. **Алгоритм QZ (LAPACK `zggev`):** Обчислює повний спектр із `N-3` власних значень за `O(N³)` операцій. Ідеально підходить для середніх сіток `N ≤ 256`, коли необхідна повна спектральна картина (включаючи дискретні та неперервні гілки спектру).
2. **Ітераційний метод Арнольді (ARPACK `znaupd`):** Використовує метод Крилова із спектральним зсувом та інверсією `(A - σ·B)⁻¹ · B`. Знаходить задану кількість `k ≪ N` найнебезпечніших мод із найменшою відстанню до зсуву `σ = c_r + i·c_i`. Часова складність складає `O(k · N²)`, що дозволяє аналізувати надвеликі сітки `N = 1024 … 4096`.

```bash
hydro_stability_cli --profile poiseuille --re 5772.2 --alpha 1.02 --grid 128 --output spectrum.csv
```

### 18.2 Доступні прапорці CLI утиліти:
- `--profile [poiseuille|tanh|couette|blasius|shock-interface|rayleigh-benard]`: Вибір основного фізичного профілю течії.
- `--re <float>`: Задання безрозмірного числа Рейнольдса.
- `--ra <float>`: Задання числа Релея для термоконвекції.
- `--alpha <float>`: Задання хвильового числа збурення.
- `--grid <int>`: Кількість точок колакації Чебишова `N`.
- `--output <path>`: Шлях до вихідного CSV-файлу зі спектром власних значень `c_r, c_i`.

| Параметр конфігурації | Опис параметра | Діапазон допустимих значень |
| :--- | :--- | :--- |
| `N` | Кількість точок колакації Чебишова | `16 … 512` (за замовчуванням `128`) |
| `Re` | Безрозмірне число Рейнольдса | `Re > 0` |
| `Ra` | Число Релея для термоконвекції | `Ra > 0` |
| `Pr` | Число Прандтля | `Pr > 0` (за замовчуванням `0.71`) |
| `We` | Число Вебера для вільної поверхні | `We > 0` |
| `alpha` | Подовжнє волнове число збурення | `0.01 … 20.0` |
| `beta` | Поперечне волнове число | `0.0` (для 2D), `> 0` (для 3D мод) |
| `bc_type` | Тип фізичних граничних умов | `HYDRO_BC_RIGID_WALL`, `FREE_SLIP`, `PERIODIC`, `FREE_SURFACE` |
| `solver` | Чисельний розв'язувач спектра | `HYDRO_SOLVER_QZ_LAPACK`, `ARNOLDI_ARPACK` |
