# Кут атаки й поляра

<preknowlist>
- [Циркуляція та підіймальна сила](root:ph-mechanics/circulation-lift-theorem) — теорема Кутти–Жуковського L' = ρ·v·Γ, як несиметрія обтікання на гострій задній кромці породжує силу.
- [Динамічний тиск](root:ph-mechanics/dynamic-pressure) — напір потоку q = ½·ρ·v², базова шкала для аеродинамічних коефіцієнтів.
- [Примежовий шар](root:ph-mechanics/boundary-layer) — тонкий в'язкий шар біля поверхні, його гальмування та перехід від ламінарного до турбулентного стану.
- [Відрив потоку](root:ph-mechanics/flow-separation) — зупинка й відрив в'язкого шару під дією несприятливого градієнта тиску dp/dx > 0.
- [Аеродинамічний опір](root:ph-mechanics/aerodynamic-drag) — сили тертя й тиску, що чинять супротив руху тіла в рідині або газі.
- [Число Рейнольдса](root:ph-mechanics/reynolds-number) — відношення сил інерції до сил в'язкості Re = ρ·v·c / μ, що визначає масштабний режим обтікання.
</preknowlist>

Коли пілот або польотний контролер безпілотника задирає ніс літака на кілька градусів вище розрахункового значення, плавний свист обтікання раптово змінюється вібрацією, підіймальна сила обвалюється на третину або половину, а лобовий опір стрибає у п'ять-десять разів. Апарат втрачає керованість і починає падати — настає звалювання (англ. *stall*). Уся ця драматична зміна поведінки визначається одним геометричним параметром — кутом між хордою крила та набігаючим потоком повітря, і ціною в опорі, яку доводиться платити за кожен ньютон підйому.

Щоб літальний апарат або лопать гвинта працювали надійно, інженер мусить знати точний баланс сил на кожному режимі: від швидкісного пікірування до повільного ширяння. Цей баланс описують дві фундаментальні концепції аеродинаміки: кут атаки `α` та поляра крила — крива, що зв'язує коефіцієнт підйомної сили з коефіцієнтом опору.

## Геометрія крила та набігаючий потік

Аеродинамічний профіль (англ. *airfoil*) — це поперечний переріз крила або лопаті площиною, паралельною напрямку руху. Його форму задають кількома базовими лініями.

Передня точка заокругленого носика зветься передньою кромкою (англ. *leading edge*, LE), а гостре вістря ззаду — задньою кромкою (англ. *trailing edge*, TE). Прямий відрізок, що з'єднує передню та задню кромки, називають **хордою профілю** (лат. *chorda* — струна) і позначають літерою `c`. Лінія, проведена рівновіддалено від верхньої та нижньої поверхонь профілю, утворює **серединну лінію кривизни** (англ. *mean camber line*). Відстань між серединною лінією та прямою хорди визначає кривизну або стрілу прогину (англ. *camber*). Симетричний профіль має нульову кривизну — його серединна лінія точно збігається з хордою.

**Кут атаки** (позначається грецькою літерою `α`) — це кут між прямою лінією хорди профілю та вектором швидкості набігаючого незбуреного потоку `v_inf`.

```
α = ∠(хорда, v_inf)        [геометричне означення кута атаки]
```

Головна пастка в розумінні кута атаки полягає в плутанні його з кутом тангажу літака відносно горизонту. Літак може летіти строго горизонтально (кут нахилу траєкторії до горизонту `γ = 0`), маючи ніс, задертий угору на 8° — тоді кут атаки дорівнює 8°. Але якщо літак падає вертикально вниз хвостом уперед або пікірує під кутом 60°, кут атаки визначається виключно тим, під яким кутом зустрічне повітря набігає на хорду крила в кожну окрему мить.

![Кут атаки α та розклад повної аеродинамічної сили R](/root/sci/ph-mechanics/kut-ataky-i-poliara/img/airfoil-angles-forces.svg)
*Кут атаки α відраховують від вектора набігаючого потоку v_inf до хорди профілю. Повна сила R розкладається на підйомну силу L і опір D у швидкісній системі або на нормальну силу N і осьову A у зв'язаній.*

Коли потік обтікає профіль під кутом `α`, розподіл статичного тиску та напружень в'язкого тертя по всій поверхні інтегрується в єдиний вектор — **повну аеродинамічну силу** `R`. Для розрахунків цю силу розкладають у двох взаємно перпендикулярних координатних системах:

1. **Швидкісна система координат (пов'язана з потоком):**
   - **Підіймальна сила** `L` (англ. *lift*) спрямована строго **перпендикулярно** до вектора набігаючого потоку `v_inf` вгору.
   - **Лобовий опір** `D` (англ. *drag*) спрямований строго **паралельно** до вектора набігаючого потоку `v_inf` назад.

2. **Зв'язана система координат (пов'язана з хордою крила):**
   - **Нормальна сила** `N` (англ. *normal force*) діє перпендикулярно до хорди профілю.
   - **Осьова (тангенціальна) сила** `A` (англ. *axial force*) діє вздовж хорди профілю від носика до хвоста.

Зв'язок між цими двома проекціями задається звичайним тригонометричним поворотом на кут атаки `α`:

```
L = N · cos α − A · sin α        [проекція на перпендикуляр до потоку]
D = N · sin α + A · cos α        [проекція вздовж вектора потоку]
```

Оскільки реальні сили залежать від площі крила `S`, густини повітря `ρ` та квадрата швидкості `v_inf²`, в аеродинаміці переходять до безрозмірних коефіцієнтів, нормуючи сили на динамічний набір `q = ½·ρ·v_inf²` та характерну площу `S` (для двовимірного профілю — на хорду `c`):

```
C_L = L / (½ · ρ · v_inf² · S)        [коефіцієнт підйомної сили]
C_D = D / (½ · ρ · v_inf² · S)        [коефіцієнт лобового опору]
C_M = M / (½ · ρ · v_inf² · S · c)    [коефіцієнт поздовжнього моменту тангажу]
```

Безрозмірні коефіцієнти `C_L` та `C_D` зручні тим, що за фіксованого числа Рейнольдса вони залежать лише від форми профілю та кута атаки `α`, дозволяючи переносити результати продувки крихітної моделі в трубі на повнорозмірний літак чи важкий дрон.

> 🔧 **Навіщо це.** Безрозмірні коефіцієнти дозволяють розділити завдання проектування: аеродинамік формує безрозмірні криві `C_L(α)` та `C_D(α)` у розрахункових програмах або трубі, а конструктор літака використовує їх для розрахунку реальних сил у кілограмах чи ньютонах для будь-якої висоти й швидкості польоту через множення на `½ρv²S`.

## Циркуляція Жуковського та лінійний приріст сили

Що фізично відбувається з потоком при збільшенні кута атаки?

У симетричного профілю за нульового кута атаки (`α = 0°`) потік набігає симетрично: струмені над спинкою та під черевцем рухаються з однаковими швидкостями, тиски з обох боків рівні, і підіймальна сила дорівнює нулю (`C_L = 0`).

Коли профіль нахиляють на додатний кут `α > 0°`, геометрична точка розгалуження набігаючого потоку (передня критична точка, де швидкість гальмується до нуля) зміщується з носика вниз, на нижню поверхню. Повітря, що прямує на верхню поверхню, змушене огинати передній заокруглений носик з високою швидкістю. Над спинкою виникає сильне прискорення потоку, а отже, за законом Бернуллі, зона глибокого розрідження (пік від'ємного тиску).

Під черевцем профілю потік, навпаки, сповільнюється, утворюючи зону підвищеного статичного тиску. Задня кромка профілю залишається гострою, і в'язкість повітря забезпечує виконання умови Кутти: потік плавно сходить з вістря хвоста, генеруючи зв'язану вихрову циркуляцію швидкості `Γ` навколо крила.

Зв'язок між циркуляцією та підйомною силою встановлює фундаментальна теорема Кутти–Жуковського:

```
L' = ρ · v_inf · Γ                   [теорема Жуковського: сила на метр розмаху]
   = ½ · ρ · v_inf² · c · C_L         [інженерний запис через коефіцієнт]
C_L = 2 · Γ / (v_inf · c)             [коефіцієнт підйому пропорційний циркуляції]
```

У класичній теорії тонкого профілю (англ. *thin airfoil theory*) М. Жуковського та Л. Прандтля циркуляція навколо слабковигнутої пластини обчислюється аналітично через конформне відображення або вихровий шар. Вона лінійно залежить від кута атаки:

```
Γ = π · v_inf · c · (α − α₀)        [циркуляція тонкого профілю]
```

де `α₀` — кут нульової підйомної сили (англ. *zero-lift angle of attack*). Підставляючи цей вираз у формулу коефіцієнта підйому, дістаємо класичний результат аеродинаміки:

```
C_L = 2 · [π · v_inf · c · (α − α₀)] / (v_inf · c)
    = 2π · (α − α₀)                 [теоретичний закон тонкого профілю]
```

Похідна коефіцієнта підйомної сили за кутом атаки, вираженим у радіанах, дорівнює константі:

```
dC_L / dα = 2π ≈ 6.28 рад⁻¹ ≈ 0.110 град⁻¹        [теоретичний нахил кривої]
```

Для реальних профілів скінченної товщини з урахуванням в'язкого примежового шару практичний нахил становить приблизно `dC_L/dα ≈ 0.095 ... 0.105 град⁻¹` (близько 0.1 на кожен градус кута атаки).

Вплив кривизни (камбера) проявляється у зміщенні величини `α₀`:
- Для **симетричного профілю** (наприклад, NACA 0012) `α₀ = 0°`. За `α = 0°` маємо `C_L = 0`.
- Для **несласиметричного, опуклого профілю** (наприклад, NACA 4412, Clark-Y) серединна лінія вигнута вгору, тому навіть за `α = 0°` потік уже має несиметричне обтікання і створює циркуляцію. Для таких профілів кут нульової сили лежить у від'ємній зоні: `α₀ ≈ −2° ... −4°`. За нульового геометричного кута такий профіль створює `C_L ≈ 0.2 ... 0.4`.

## Точка прикладання сили: центр тиску та фокус

Система розподіленого тиску на поверхні профілю не лише створює результуючу силу `R`, але й прагне закрутити крило навколо поперечної осі. Цей обертальний ефект описують двома взаємопов'язаними поняттями: центром тиску та аеродинамічним фокусом.

**Центр тиску** (англ. *center of pressure*, CP, позначається `x_cp`) — це точка на хорді профілю, відносно якої сумарний момент аеродинамічних сил дорівнює нулю. Іншими словами, це точка, в яку можна умовно прикласти результуючу силу `L`, не додаючи зовнішнього моменту.

Головна вада центру тиску — його крайня нестабільність. Коли кут атаки зменшується і `C_L` наближається до нуля, центр тиску починає стрімко зміщуватися назад уздовж хорди, а при `C_L = 0` прямує до нескінченності. Річ у тім, що несиметричний вигнутий профіль за нульової підйомної сили має ненульовий пікіруючий момент пари сил: над передньою частиною тиск менший, над задньою — більший, тому сумарна сила нульова, а закручувальний момент існує. Поділити ненульовий момент на нульову силу неможливо — точка прикладання втрачає фізичний сенс.

Щоб позбутися цієї невизначеності, в теорію стабільності та динаміки польоту ввели поняття **аеродинамічного фокуса** (англ. *aerodynamic center*, AC, позначається `x_ac`).

**Аеродинамічний фокус** — це точка на хорді, момент аеродинамічних сил відносно якої **не залежить від кута атаки** у безодривному діапазоні:

```
dC_M_ac / dα = 0        [визначення аеродинамічного фокуса]
```

Для дозвукового обтікання тонких профілів в ідеальній рідині теоретична гідродинаміка доводить: аеродинамічний фокус розташований точно на відстані однієї чверті хорди від передньої кромки:

```
x_ac = 0.25 · c = c / 4        [положення фокуса на дозвукових швидкостях]
```

Поздовжній момент відносно фокуса `C_M_ac` залишається строго сталим при зміні кута атаки аж до початку зриву потоку. Для вигнутих уперед-вгору профілів цей момент є пікіруючим (від'ємним, прагне опустити ніс, `C_M_ac ≈ −0.05 ... −0.12`), для симетричних — строго нульовим (`C_M_ac = 0`), а для профілів із загнутою вгору задньою кромкою (S-подібні рефлексні профілі для безхвостих літаків і літаючих крил) — додатним, кабруючим (`C_M_ac > 0`).

Зв'язок між рухомим центром тиску `x_cp` та нерухомим фокусом `x_ac` виражається точним співвідношенням:

```
M_ac = L · (x_ac − x_cp)             [момент відносно фокуса через плече сили]
C_M_ac = C_L · (x_ac / c − x_cp / c)  [безрозмірна форма]
x_cp / c = 0.25 − C_M_ac / C_L        [зміщення центру тиску від чверті хорди]
```

З цієї формули наочно видно: щойно кут атаки зростає і `C_L` збільшується, другий доданок зменшується, і центр тиску `x_cp` наближається до чверті хорди `0.25c`. При зменшенні `C_L` центр тиску нестійко тікає назад до задньої кромки. Саме тому всі розрахунки поздовжнього балансування літаків і розрахунки стійкості безпілотників проводять відносно аеродинамічного фокуса `x_ac`, а не відносно центру тиску.

## Залежності C_L(α) та C_D(α): критичний кут і зрив потоку

Якщо плавно збільшувати кут атаки профілю від від'ємних значень до критичних, коефіцієнти `C_L` та `C_D` демонструють характерні фази поведінки.

![Залежності коефіцієнтів C_L(α) та C_D(α)](/root/sci/ph-mechanics/kut-ataky-i-poliara/img/cl-cd-alpha-curves.svg)
*Лінійне зростання коефіцієнта підйомної сили C_L(α) обривається при досягненні критичного кута α_crit. У цей же момент коефіцієнт лобового опору C_D(α) зазнає лавиноподібного зростання через масивний відрив примежового шару.*

1. **Лінійна зона підйому (безодривне обтікання):**
   У діапазоні від `α₀` до приблизно 8°–12° коефіцієнт `C_L` зростає строго лінійно з нахилом `dC_L/dα ≈ 2π`. Потік повністю притиснутий до поверхні.
   Коефіцієнт лобового опору `C_D` у цій зоні складається переважно з опору поверхневого тертя та слабкого опору форми: він має мінімум `C_D,min` поблизу кута нульової підйомної сили і повільно зростає за параболічним законом `C_D ≈ C_D0 + k·C_L²`.

2. **Зона гальмування та зародження відриву:**
   Зі збільшенням кута атаки розрідження на спинці біля носика стає все сильнішим. Повітря розганяється до високої швидкості біля передньої кромки, а потім, рухаючись до задньої кромки, мусить гальмувати, долаючи зростаючий тиск навколишнього середовища. Виникає сильний **несприятливий градієнт тиску** (англ. *adverse pressure gradient*):

   ```
   dp / dx > 0        [тиск зростає вздовж потоку, гальмуючи пристінний шар]
   ```

   Примежовий шар біля самої стінки профілю, який уже втратив частину кінетичної енергії на тертя, не витримує протитиску. Швидкість частинок повітря біля стінки сповільнюється до нуля:

   ```
   (∂u / ∂y)|_{y=0} = 0        [умова точки гідродинамічного відриву]
   ```

   За точкою відриву потік розвертається назад, утворюючи застійні зворотні вихори. Спочатку точка відриву зароджується біля самої задньої кромки і зі зростанням `α` повільно повзе вперед до носика. Приріст підйомної сили сповільнюється — крива `C_L(α)` згинається, відхиляючись від прямої лінії.

3. **Критичний кут атаки `α_crit` та пік `C_L,max`:**
   За певного кута атаки (зазвичай `α_crit ≈ 12° ... 16°` для класичних дозвукових профілів) підйомна сила досягає свого абсолютного максимуму `C_L,max ≈ 1.2 ... 1.7`. Це максимальна здатність профілю нести вагу на заданій швидкості.

4. **Зрив потоку (звалювання, Stall):**
   Якщо збільшити кут атаки навіть на пів градуса понад `α_crit`, примежовий шар повністю відривається від спинки профілю. Замість гладкого обтікання над верхньою поверхнею розкривається величезна турбулентна вихрова каверна. Зона глибокого розрідження руйнується, циркуляція Жуковського падає — коефіцієнт `C_L` стрімко обвалюється, а лобовий опір `C_D` зростає в рази через різкий перепад тиску між лобовою частиною та розірваною каверною позаду.

![Анатомія розвитку відриву потоку на профілі](/root/sci/ph-mechanics/kut-ataky-i-poliara/img/stall-mechanisms.svg)
*Розвиток зриву потоку з ростом кута атаки: від плавного притиснутого обтікання при α = 4° через зародження відриву біля задньої кромки при α = 12° до повного зриву та формування турбулентної каверни при закритичному куті α = 18°.*

Залежно від геометричних параметрів профілю розрізняють **три механізми зриву**:

- **Задньокромочний зрив (Trailing-edge stall):** типовий для товстих профілів (відносна товщина `t/c > 14%`, наприклад NACA 4415). Відрив починається на задній кромці й плавно просувається вперед. Купол кривої `C_L(α)` виходить пологим і круглим, літак втрачає підйом поступово, даючи пілоту час на реакцію.
- **Передньокромочний зрив (Leading-edge stall):** характерний для профілів середньої товщини (`9% < t/c < 14%`, наприклад NACA 0012, NACA 2412). На гострішому носику виникає коротка ламінарна бульбашка відриву, яка при досягненні `α_crit` миттєво «лопається» (англ. *bubble burst*). Відрив накриває всю спинку раптово: `C_L` падає стрибком у формі стрімкого урвища.
- **Тонкопрофільний зрив (Thin-airfoil stall):** спостерігається на тонких профілях (`t/c < 6%`) та плоских пластинах. Потік зривається з гострого носика вже за малих кутів (`α ≈ 3° ... 5°`), утворюючи довгу вихрову бульбашку, яка повільно росте до хвоста при збільшенні кута. Крива `C_L(α)` має низький `C_L,max` без різкого піку.

## Поляра Лілієнталя: геометрія аеродинамічної досконалості

Якщо виключити параметр кута атаки `α` й побудувати графік залежності коефіцієнта підйомної сили `C_L` від коефіцієнта лобового опору `C_D`, дістанемо найважливіший графічний паспорт крила — **поляру Лілієнталя** (докладніше про те, як вона створювалася, читайте у вставці про [виміри Отто Лілієнталя](root:ph-mechanics/kut-ataky-i-poliara/hist-lilienthal.md)).

![Поляра Лілієнталя C_L(C_D) та характерні аеродинамічні точки](/root/sci/ph-mechanics/kut-ataky-i-poliara/img/lilienthal-polar.svg)
*Поляра Лілієнталя відображає зв'язок підйомної сили й опору для всіх кутів атаки. Дотична з початку координат визначає режим максимальної якості K_max (найкраще планування), а дотична до вищих C_L — економічний режим мінімальної тягової потужності.*

Кожна точка на кривій поляри відповідає певному куту атаки `α`. На полярі чітко прочитуються ключові аеродинамічні режими:

1. **Точка нульової підйомної сили `α₀`:**
   Точка перетину поляри з віссю ординат (`C_L = 0`). Опір у цій точці `C_D0` є чистим опором тертя та форми недеформованого потоку.

2. **Точка мінімального опору `C_D,min`:**
   Точка, найбільш зсунута вліво до осі `C_L`. Відповідає куту атаки швидкісного пікірування або граничної швидкості горизонтального польоту.

3. **Точка максимальної аеродинамічної якості `K_max` (найвигідніший режим):**
   Аеродинамічна якість — це відношення підйомної сили до опору:

   ```
   K = L / D = C_L / C_D        [аеродинамічна якість]
   ```

   Геометрично відношення `C_L / C_D` дорівнює тангенсу кута нахилу променя, проведеного з початку координат `(0, 0)` до точки на полярі. Щоб знайти максимум `K`, потрібно провести **дотичну з початку координат до поляри**. Точка дотику задає **найвигідніший кут атаки** `α_opt` (зазвичай 4°–6°):
   - У безмоторному польоті (планер) цей режим дає мінімальний кут зниження і максимальну дальність планування з висоти.
   - Для літака з повітряним гвинтом цей режим забезпечує максимальну дальність польоту на один кілограм пального чи ампер-годину акумулятора.

4. **Економічний режим (максимум тривалості польоту):**
   Потужність, потрібна для подолання лобового опору в горизонтальному польоті (`L = W`), пропорційна добутку сили на швидкість:

   ```
   P_req = D · v = (W / K) · √( 2W / (ρ · S · C_L) )
         = √( 2W³ / (ρ · S) ) · ( C_D / C_L^{1.5} )
   ```

   Мінімум потрібної потужності `P_req,min` (а отже мінімальна витрата енергії за секунду часу) досягається в точці, де максимальний комплекс:

   ```
   E_max = ( C_L^{1.5} / C_D )_max        [умова максимального часу висіння]
   ```

   На полярі ця точка лежить вище за `K_max` (за більших кутів атаки, близько 8°–10°). Це режим баражування розвідувального дрона або патрульного літака, коли завдання — протриматися в повітрі якомога більше годин, не дбаючи про пройдену відстань.

5. **Точка максимальної підйомної сили `C_L,max`:**
   Найвища точка кривої по вертикалі. Вона визначає **мінімальну швидкість польоту** (швидкість звалювання `v_stall`):

   ```
   v_stall = √( 2 · m · g / (ρ · S · C_L,max) )        [мінімальна швидкість тримання]
   ```

### Перший і другий режими польоту за швидкістю

Поляра розкриває небезпечний феномен динаміки польоту — розділення на два режими за швидкістю:

- **Перший режим (швидкісний, зліва від `K_max`):** кути атаки менші за найвигідніший (`α < α_opt`). Тут політ стійкий за швидкістю: якщо літак випадково сповільниться, коефіцієнт `C_L` зросте, наближаючись до `K_max`, опір зменшиться, і надлишок тяги двигуна автоматично розжене літак назад до рівноважної швидкості.
- **Другий режим (небезпечний, справа від `K_max` до `α_crit`):** кути атаки більші за найвигідніший (`α_opt < α < α_crit`). Тут політ **нестійкий за швидкістю**. Якщо літак ненавмисно сповільниться, пілот для збереження висоти змушений збільшити кут атаки, але в цій зоні це спричиняє різке зростання `C_D`. Потрібна тяга зростає швидше, ніж падає швидкість. Якщо двигун не має запасу потужності, літак почне стрімко втрачати швидкість, що неминуче завершиться звалюванням у штопор.

## Особливості малих чисел Рейнольдса (Re < 10^5) для лопатей дронів

У великій пасажирській авіації хорди крил вимірюються метрами, а швидкості — сотнями кілометрів на годину, тому число Рейнольдса становить `Re = 10^6 ... 5·10^7`. У цьому світі інерційні сили повністю домінують над в'язкістю.

Для сучасних малорозмірних безпілотників, дронів-камікадзе та FPV-квадрокоптерів ситуація радикально інша. Хорда лопаті пропелера або крила мікродрона становить лише `c = 15 ... 40 мм`, а швидкість обтікання — `v = 10 ... 35 м/с`. Розрахунок числа Рейнольдса дає діапазон:

```
Re = (ρ · v · c) / μ ≈ (1.225 · 20 · 0.03) / (1.81 · 10⁻⁵) ≈ 40 000        [Re лопаті FPV]
```

За чисел `Re < 10^5` поведінка повітря нагадує рух у в'язкому маслі. Слабкі інерційні сили не здатні примусити примежовий шар подолати навіть незначний підйом тиску на спинці крила.

![Ламінарна бульбашка відриву (LSB) на профілі лопаті дрона](/root/sci/ph-mechanics/kut-ataky-i-poliara/img/low-re-lsb-bubble.svg)
*Ламінарна бульбашка відриву (LSB) виникає при малих числах Рейнольдса: ламінарний шар відривається в точці S, зазнає турбулентного переходу в точці T і приєднується назад у точці R, утворюючи замкнений застійний вихор.*

Головним фізичним явищем малої аеродинаміки стає **ламінарна бульбашка відриву** (англ. *Laminar Separation Bubble*, LSB):

1. **Ламінарний відрив (точка S):** повітря починає рух від носика у вигляді дуже тонкого ламінарного шару. Зустрівши несприятливий градієнт тиску `dp/dx > 0`, ламінарний шар беззахисно відривається від твердої поверхні вже на перших 15–30% хорди.
2. **Вільний шар змішування (зона переходу T):** відірваний шар повітря висить над стінкою. У ньому через різницю швидкостей спалахує гідродинамічна нестійкість Кельвіна–Гельмгольца. Виникають мікрохвилі, які за кілька міліметрів руйнуються в хаотичну турбулентність.
3. **Турбулентне приєднання (точка R):** турбулентний шар має на порядки вищу здатність до поперечного імпульсного обміну — він енергійно підсмоктує швидкі маси повітря із зовнішнього потоку, потовщується і силою «прилипає» назад до поверхні профілю.
4. **Утворення каверни:** між точкою відриву `S` та точкою приєднання `R` під вихровим шаром опиняється ізольована замкнена застійна зона зі зворотним коловим рухом рідини — це і є ламінарна бульбашка.

Наявність бульбашки змінює ефективну геометрію профілю:
- На середніх кутах атаки товста бульбашка діє як аеродинамічне «здуття», різко спотворюючи розподіл тиску і знижуючи ефективну кривизну.
- Лобовий опір профілю зростає у 2–4 рази (`C_D` збільшується від звичних 0.008 до 0.025–0.050).

### Розрив бульбашки та аеродинамічний гістерезис

Найнебезпечніший сценарій на малих `Re` виникає за збільшення кута атаки або при зменшенні швидкості польоту нижче критичного порогу (`Re < 40 000 ... 50 000`).

Коли градієнт тиску стає надто крутим, турбулентний перехід у відірваному шарі просто не встигає завершитися до кінця хорди. Шар не може приєднатися назад — бульбашка «розривається» (англ. *bursting*), вироджуючись у відкритий суцільний відрив. Настає **раптовий звалювальний зрив**:
- Максимальний коефіцієнт підйомної сили падає з `C_L,max ≈ 1.3` до жалюгідних `0.6 ... 0.7`.
- Опір стрибає до `C_D ≈ 0.10 ... 0.18`.
- Виникає глибокий **аеродинамічний гістерезис**: якщо апарат уже зірвався у звалювання, повернення до безодривного обтікання вимагає зменшити кут атаки не просто до критичного значення `12°`, а опустити ніс аж до `6°–7°`! Поки кут не стане дуже малим, турбулентний шар не зможе самостійно присмоктатися назад до стінки.

### Способи приборкання низьких Re у дронобудуванні

Щоб забезпечити високу тягу пропелерів і тривалість польоту БПЛА при малих числах Рейнольдса, аеродинаміки використовують спеціальні методи:

1. **Використання спеціалізованих Low-Re профілів:**
   Класичні профілі NACA з товстим круглим носиком на малих `Re` працюють вкрай неефективно. Для дронів застосовують профілі з гострою передньою кромкою та максимальним прогином у задній третині хорди (профілі Selig S1223, SD7003, Eppler E387, Drela AG).
2. **Тонкі вигнуті пластини:**
   За екстремально малих чисел (`Re < 30 000`) найкращі результати дає тонка вигнута пластина сталого перерізу з відносною товщиною 2–4% і кривизною 5–7%. На ній відрив локалізується на самій гострій передній кромці, швидко турбулізується і негайно приєднується без утворення великих мертвих зон.
3. **Турбулізатори примежового шару:**
   Щоб запобігти ламінарному відриву, перед розрахунковою точкою `S` на поверхню наклеюють штучні мікротурбулізатори (зигзагоподібні стрічки товщиною 0.2–0.5 мм, смужки наждаку або перфорацію). Вони примусово переводять тонкий ламінарний шар у стійкий турбулентний стан ще до того, як він устигне відірватися під дією градієнта тиску.

## Практичний розрахунок польоту та програма поляри

Для автоматизації обробки поляр і пошуку оптимальних режимів польоту інженери використовують програмні калькулятори (повний сирцевий код на мовах C та C++ з детальним аналізом структур даних наведено у вставці [аеродинамічний калькулятор поляр](root:ph-mechanics/kut-ataky-i-poliara/proj-polar-calc.md)).

Розглянемо числовий приклад практичного застосування поляри для легкого розвідувального БПЛА типу «літаюче крило».

**Вхідні інженерні параметри апарата:**
- Повна польотна маса: `m = 1.6 кг` (вага `W = m · g = 1.6 · 9.81 ≈ 15.7 Н`).
- Площа крила: `S = 0.32 м²`.
- Хорда крила: `c = 0.20 м`.
- Густина повітря на рівні моря: `ρ = 1.225 кг/м³`.
- Базові точки поляри вибраного профілю:
  - Кут нульової сили: `α₀ = −2.5°` (`C_L = 0, C_D0 = 0.010`).
  - Найвигідніший режим `K_max`: `α = 5.0°`, `C_L = 0.72`, `C_D = 0.024` (якість `K_max = 0.72 / 0.024 = 30.0`).
  - Економічний режим: `α = 8.5°`, `C_L = 1.05`, `C_D = 0.042` (`E = 1.05^{1.5} / 0.042 = 25.6`).
  - Критичний режим звалювання: `α_crit = 13.5°`, `C_L,max = 1.40`, `C_D = 0.090`.

**1. Розрахунок мінімальної швидкості польоту (швидкість звалювання):**

```
v_stall = √( (2 · W) / (ρ · S · C_L,max) )
        = √( (2 · 15.7) / (1.225 · 0.32 · 1.40) )
        = √( 31.4 / 0.5488 )
        = √57.22 ≈ 7.56 м/с  (27.2 км/год)
```

Безпечна швидкість заходу на посадку вибирається з 30% запасом: `v_app = 1.3 · v_stall ≈ 9.8 м/с`.

**2. Розрахунок швидкості та дальності максимального планування (режим K_max):**

```
v_glide = √( (2 · W) / (ρ · S · C_L_at_Kmax) )
        = √( (2 · 15.7) / (1.225 · 0.32 · 0.72) )
        = √( 31.4 / 0.2822 )
        = √111.27 ≈ 10.55 м/с  (38.0 км/год)
```

Якщо на висоті `h = 600 м` у дрона відмовить двигун, плануючи на швидкості 10.55 м/с з якістю `K_max = 30.0`, він пролетить відстань:

```
d_max = K_max · h = 30.0 · 600 м = 18 000 м = 18.0 км        [дальність планування]
```

**3. Розрахунок швидкості та потрібної тягової потужності для максимальної тривалості (економічний режим):**

```
v_econ = √( (2 · W) / (ρ · S · C_L_econ) )
       = √( (2 · 15.7) / (1.225 · 0.32 · 1.05) )
       = √( 31.4 / 0.4116 )
       = √76.29 ≈ 8.73 м/с  (31.4 км/год)
```

Потрібна сила тяги двигуна на цьому режимі:

```
T_econ = D = W / (C_L / C_D)_econ = 15.7 / (1.05 / 0.042) = 15.7 / 25.0 = 0.628 Н
```

Корисна аеродинамічна потужність, яку повинен розвивати гвинт:

```
P_aero = T_econ · v_econ = 0.628 Н · 8.73 м/с ≈ 5.48 Вт
```

З урахуванням коефіцієнта корисної дії пропелера `η_prop = 0.65` та ККД безколекторного мотора `η_mot = 0.80` електрична потужність від батареї складе:

```
P_elec = P_aero / (η_prop · η_mot) = 5.48 / (0.65 · 0.80) = 5.48 / 0.52 ≈ 10.5 Вт
```

Маючи бортовий акумулятор ємністю 4S 3000 мАг (енергоємність `E_bat = 14.8 В · 3.0 А·год = 44.4 Вт·год`), теоретична тривалість баражування складе:

```
t_flight = E_bat / P_elec = 44.4 / 10.5 ≈ 4.23 год  (понад 4 години 13 хвилин)
```

Цей числовий розрахунок наочно підтверджує: точне знання полярних характеристик крила дозволяє проектувати безпілотні комплекси з винятковою енергоефективністю, балансуючи між запасом стійкості, швидкістю звалювання та максимальною дальністю місії.
