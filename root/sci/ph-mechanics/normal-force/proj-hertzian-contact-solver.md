# ⚙️ Розв'язувач контактних пружних деформацій та розподілу контактного тиску за Герцом

У машинобудуванні, трибології, транспортному машинобудуванні та прецизійній робототехніці навантаження рідко передаються через широкі плоскі поверхні: майже вся механічна потужність сучасних редукторів, шпиндельних вузлів, підшипників кочення, зубчастих зачеплень і кулачкових механізмів транслюється крізь субміліметрові зони локального дотику опуклих тіл. Коли сталева кулька вальниці діаметром 20 мм сприймає нормальне зусилля у кілька кілоньютонів, спроба розрахувати тиск за елементарною формулою `p = F / A` зазнає краху, оскільки в недеформованому геометричному стані площа дотику ідеальної сфери з площиною дорівнює строго нулю, що призвело б до нескінченного тиску.

Насправді під дією нормальної сили матеріал обох тіл зазнає пружного сплющування, формуючи мікроскопічну кругову, еліптичну або прямокутну контактну пляму, в межах якої нормальний тиск розподіляється за плавним куполоподібним законом, сягаючи в центрі значень у кілька гігапаскалів (`1000–3500 МПа`). Математичний апарат для точного розрахунку таких напружено-деформованих станів створив 1881 року Генріх Герц. Ця стаття містить повний теоретичний опис контактної задачі Герца, аналітичний розв'язок тривимірного поля напружень, критерії статичної міцності й контактної втоми, а також промислову обчислювальну бібліотеку мовами C99 та C++20 для інженерного моделювання контактних вузлів.

## Математичні засади пружного контакту тіл криволінійної форми

Аналітична теорія Герца розглядає взаємодію двох гладких пружних ізотропних тіл за припущення, що розміри області контакту є малими порівняно з характерними радіусами кривини поверхонь (`a << R`), а напруження зосереджені в локальній приповерхневій зоні, що дозволяє розглядати кожне тіло як пружний напівбезмежний простір.

### Приведені геометричні та механічні характеристики

Геометрія та пружні властивості контактної пари двох тіл з модулями Юнга `E₁, E₂`, коефіцієнтами Пуассона `ν₁, ν₂` та головними радіусами кривини `R₁, R₂` зводяться до еквівалентної взаємодії тіла з приведеним радіусом `R` і плоскої абсолютно жорсткої поверхні через ефективний модуль пружності `E*`.

1. **Еквівалентний (приведений) радіус кривини `R`**:
```
1 / R = 1 / R₁ + 1 / R₂
R = (R₁ · R₂) / (R₁ + R₂)
```
Правило знаків для радіусів кривини:
- Для опуклої поверхні (зовнішня поверхня сфери чи циліндра) радіус приймається додатним: `R_i > 0`.
- Для плоскої поверхні радіус кривини прямує до нескінченності: `R_i = ∞` (відповідно `1 / R_i = 0`).
- Для ввігнутої поверхні (внутрішня доріжка кочення чаші або кільця підшипника) радіус береться зі знаком «мінус»: `R_i < 0`.

2. **Ефективний контактний модуль пружності `E*`**:
```
1 / E* = (1 − ν₁²) / E₁ + (1 − ν₂²) / E₂
E* = 1.0 / [ (1 − ν₁²) / E₁ + (1 − ν₂²) / E₂ ]
```
Цей параметр об'єднує опір деформації обох контактуючих матеріалів з урахуванням ефекту бічного стиснення Пуассона.

### Точковий контакт (сфера зі сферою або сфера з площиною)

Притискання сферичної пари нормальною силою `N` формує кругову пляму контакту радіуса `a`. Величина плями та нормальне пружне зближення центрів тіл `δ` описуються системою нелінійних рівнянь Герца:

```
Радіус кругової контактної плями:
a = [ (3 · N · R) / (4 · E*) ]^(1/3)

Пружне зближення тіл (глибина взаємного проникнення):
δ = a² / R = [ (9 · N²) / (16 · R · E*²) ]^(1/3)

Залежність нормальної сили від величини пружного зближення:
N(δ) = (4/3) · E* · R^(1/2) · δ^(3/2)
```

Зверніть увагу на показник степеня `3/2`: на відміну від класичної лінійної пружини Гука (`F = k·x`), контактна пружність за Герцом є прогресивно жорсткою. Зі збільшенням заглиблення `δ` площа плями `A = π·a²` зростає пропорційно `δ`, тому миттєва контактна жорсткість `k_c = dN/dδ = 2·E*·a` безперервно підвищується зі зростанням нормального навантаження.

Розподіл контактного тиску `p(r)` по радіусу контактного круга `0 ≤ r ≤ a` має напівсфероїдальну форму:

```
p(r) = p₀ · √( 1 − (r / a)² )

де максимальний контактний тиск у центрі (r = 0):
p₀ = (3 · N) / (2 · π · a²) = [ (6 · N · E*²) / (π³ · R²) ]^(1/3)

Середній контактний тиск по площі плями:
p_mean = N / (π · a²) = (2/3) · p₀
```

Піковий тиск у центрі плями завжди рівно на 50% перевищує середній тиск у зоні контакту.

### Лінійний контакт (два паралельні циліндри або циліндр на площині)

Для пари паралельних циліндрів довжини `L` нормальне зусилля `N` створює прямокутну смугу контакту шириною `2b` і довжиною `L`:

```
Півширина контактної смуги:
b = √( (4 · N · R) / (π · L · E*) )

Максимальний контактний тиск вздовж центральної осі смуги (x = 0):
p₀ = (2 · N) / (π · b · L) = √( (N · E*) / (π · R · L) )

Середній контактний тиск:
p_mean = N / (2 · b · L) = (π / 4) · p₀ ≈ 0.785 · p₀

Профіль тиску впоперек осі контакту (-b ≤ x ≤ b):
p(x) = p₀ · √( 1 − (x / b)² )
```

### Загальний тривимірний еліптичний контакт

У більшості реальних машинобудівних вузлів (наприклад, контакт кульки з жолобом глибокопазового радіально-упорного підшипника або зубчасте зачеплення з конічними та гіпоїдними шестернями) радіуси кривини тіл у поздовжній та поперечній площинах є різними (`R_1x ≠ R_1y` та `R_2x ≠ R_2y`).

У цьому загальному випадку початковий недеформований зазор між поверхнями описується еліптичним параболоїдом:

```
h(x, y) = A · x² + B · y²

де геометричні константи кривини:
A = 0.5 · ( 1/R_1x + 1/R_2x )
B = 0.5 · ( 1/R_1y + 1/R_2y )
```

Контактна пляма під дією сили `N` набуває форми еліпса з великою піввіссю `a` вздовж осі `x` та малою піввіссю `b` вздовж осі `y`. Розподіл нормального тиску описується еліпсоїдом обертання:

```
p(x, y) = p₀ · √( 1 − (x/a)² − (y/b)² )

де максимальний контактний тиск у центрі еліпса:
p₀ = (3 · N) / (2 · π · a · b)
```

Аналітичний розрахунок півосей `a` та `b` вимагає обчислення повних еліптичних інтегралів Лежандра першого `K(e)` та другого `E(e)` роду від ексцентриситету еліпса `e = √(1 − (b/a)²)`. В інженерній практиці для швидких розрахунків використовують високоточні апроксимації Бреве-Хемрока (Brewe-Hamrock, 1977):

```
Коефіцієнт еліптичності:
k_elliptic = a / b ≈ 1.0339 · ( B / A )^0.6360

Велика піввісь еліптичної плями:
a = [ (6 · k_elliptic² · E_integral · N · R_eq) / (π · E*) ]^(1/3)

Мала піввісь еліптичної плями:
b = a / k_elliptic

де еквівалентний радіус R_eq = 1 / (A + B), а еліптичний інтеграл другого роду E_integral ≈ 1.0003 + 0.5968 · (A / B).
```

### Динамічний контакт і дисипація: модель Ханта–Крослі

При моделюванні зіткнення пружних тіл у фізичних рушіях та системах динаміки тіл (MBD) класична лінійна в'язкопружна модель Кельвіна–Фойгта (`N = k·δ + c·ḋ`) дає грубі фізичні артефакти:
- У момент першого геометричного дотику (`δ = 0`) при ненульовій швидкості зближення `ḋ > 0` демпфер миттєво генерує ненульову силу `N = c·ḋ ≠ 0`, ніби тіла зіткнулися з в'язкою стіною.
- У момент розмикання контакту (`δ → 0`, `ḋ < 0`) від'ємний демпферний доданок породжує штучну силу розтягу (`N < 0`), що неприродно притягує тіла одне до одного.

Фізично несуперечливу нелінійну контактну модель із дисипацією побудували К. Хант та Ф. Крослі (K. H. Hunt, F. R. E. Crossley, 1975), зв'язавши в'язкий опір із миттєвим об'ємом деформації:

```
N(δ, ḋ) = k_H · δ^(3/2) · [ 1 + (3 · (1 − e) / (2 · ḋ₀)) · ḋ ]
```

де `k_H = (4/3)·E*·√R`, `e` — коефіцієнт відновлення швидкості, а `ḋ₀` — швидкість зближення в момент першого дотику. У моделі Ханта–Крослі нормальна сила гарантовано лишається невід'ємною (`N ≥ 0`), плавно зростає від нуля, а площа петлі гістерезису на графіку `N(δ)` точно відповідає внутрішньому розсіюванню енергії в матеріалі.

### Адгезійний контакт на мікро- та наномасштабах: моделі JKR та DMT

Коли радіуси кривини деталей зменшуються до мікро- та нанометрів (мікроелектромеханічні системи МЕМС, зондова атомно-силова мікроскопія АСМ, наноіндентація), міжмолекулярні сили притягання ван дер Ваальса стають сумірними з пружними силами відсічі.

- **Модель JKR (Johnson-Kendall-Roberts, 1971)**: застосовується для податливих матеріалів (гуми, еластомери, полімери, живі клітини) з високою питомою поверхневою енергією `γ`. На межі плями контакту утворюється кільцева адгезійна шийка, а площа контакту лишається скінченною навіть при нульовому зовнішньому навантаженні:
  ```
  a₀ = [ (6 · π · γ · R²) / E* ]^(1/3)
  ```
  Сила відриву (pull-off force), необхідна для розмикання контакту: `F_pull = −(3/2) · π · γ · R`.
- **Модель DMT (Дерягін–Мюллер–Топоров, 1975)**: застосовується для високотвердих матеріалів (метали, кремній, алмаз) із малими радіусами кривини, де далекодійні сили притягання діють за межами геометричної плями контакту. Сила відриву становить `F_pull = −2 · π · γ · R`.
- **Безрозмірний параметр Тейбора `μ_T`** (David Tabor, 1977) визначає режим взаємодії:
  ```
  μ_T = [ (R · γ²) / (E*² · z₀³) ]^(1/3)
  ```
  де `z₀ ≈ 0.3–0.5 нм` — рівноважна міжатомна відстань. Якщо `μ_T > 5`, поведінка суворо описується моделлю JKR; якщо `μ_T < 0.1`, адгезія слабка й контакт підпорядковується класичній теорії Герца або моделі DMT.

### Вплив поверхневої шорсткості на контакт Герца

Класична теорія Герца розглядає ідеально гладкі тіла. Проте на реальних деталях завжди присутня мікрошорсткість із середньоквадратичним відхиленням висот `σ_rough` (RMS roughness, зазвичай `0.1–1.5 мкм` для шліфованих та полірованих підшипникових поверхонь).

Згідно з дослідженнями Джонсона, Грінвуда та Хіггінсона (K. L. Johnson, J. A. Greenwood, 1972), вплив шорсткості на пружний герцівський контакт контролюється безрозмірним контактним параметром шорсткості:

```
α_rough = (σ_rough · R^(1/3)) / ( (3 · N / (4 · E*))^(2/3) ) = σ_rough / δ_hertz
```

Якщо контактне зближення `δ_hertz >> σ_rough` (тобто `α_rough < 0.05`), вплив мікронерівностей є нехтовно малим: шорсткість згладжується під навантаженням, а розподіл макротиску з точністю до 98% повторює класичний герцівський профіль `p(r)`. Якщо ж `α_rough > 0.5` (малі навантаження або груба обробка), контактний тиск розбивається на окремі мікропіки на вершинах асперитів, які можуть у 2–3 рази перевищувати номінальний герцівський тиск `p₀`, локально прискорюючи зародження поверхневих мікротріщин.

## Тривимірний напружений стан та підповерхневі екстремуми

Розрахунок міцності деталей вимагає аналізу повного тривимірного тензора напружень `σ_ij` у матеріалі під плямою контакту.

Уздовж осі симетрії контакту `z` (де `z = 0` — поверхня контакту, а вісь `z` спрямована вглиб матеріалу) головні напруження складаються з вертикального стискального напруження `σ_z` та двох однакових горизонтальних напружень `σ_x = σ_y = σ_r` (через осесиметрію задачі). Їхні точні аналітичні вирази через безрозмірну глибину `ζ = z / a` мають вигляд:

```
Вертикальне головне напруження стиснення:
σ_z(ζ) = −p₀ / (1 + ζ²)

Радіальні горизонтальні напруження (для сталі з коефіцієнтом Пуассона ν = 0.30):
σ_r(ζ) = −p₀ · [ (1 + ν) · (1 − ζ · arctan(1/ζ)) − 1 / (2 · (1 + ζ²)) ]
```

Асимптотична поведінка напружень на поверхні (`z = 0`, тобто `ζ → 0`):
- `σ_z(0) = −p₀`
- `σ_r(0) = −p₀ · (1 + 2ν) / 2 = −0.80 · p₀` (при `ν = 0.30`)

На поверхні під центром контакту матеріал перебуває в умовах високого всебічного тривісного стиснення: стискальні напруження з усіх боків майже однакові (`-1.0·p₀` і `-0.8·p₀`). Згідно з основами теорії пластичності, всебічний гідростатичний тиск `p_hyd = -(σ_x + σ_y + σ_z) / 3 ≈ 0.87·p₀` не викликає пластичного зсуву та деформації кристалічної ґратки металів, а лише пружно стискає її об'єм.

Пластична деформація та руйнування металів контролюються **девіатором напружень** — різницею між головними напруженнями, що породжує зсувні деформації.

### Максимальні дотичні напруження за Треска (Tresca Shear Stress)

Максимальне дотичне напруження на глибині `z` визначається як половина різниці між найбільшим і найменшим головними напруженнями:

```
τ_max(z) = (1/2) · | σ_z(z) − σ_r(z) |
```

На самій поверхні тіла (`z = 0`):
```
τ_max(0) = (1/2) · | −p₀ − (−0.80 · p₀) | = 0.10 · p₀
```

У міру занурення вглиб матеріалу радіальне напруження `σ_r(z)` зменшується значно швидше, ніж вертикальне напруження `σ_z(z)`. Через це різниця `|σ_z − σ_r|` спочатку стрімко зростає, досягає абсолютного екстремуму і лише на великих глибинах прямує до нуля.

Точний числовий розрахунок точки екстремуму дає фундаментальні константи теорії Герца:

```
Для сферичного точкового контакту:
z_crit ≈ 0.481 · a
τ_max ≈ 0.3105 · p₀

Для циліндричного лінійного контакту:
z_crit ≈ 0.786 · b
τ_max ≈ 0.300 · p₀
```

### Знакозмінні ортогональні зсувні напруження при циклічному коченні

При стаціонарному притисканні максимальний зсув `τ_max` діє в площинах під кутом 45° до осі симетрії. Проте при коченні кульки або ролика по доріжці переріз матеріалу зазнає складної знакозмінної деформації: у міру наближення контактної плями дотичне напруження `τ_zx` на вертикальних і горизонтальних майданчиках зростає від нуля до додатного піка `+τ_orth`, у центрі плями спадає до нуля, а при віддаленні плями змінює напрям на протилежний, досягаючи від'ємного піка `−τ_orth`:

```
τ_orth,max ≈ 0.25 · p₀   на глибині   z ≈ 0.35 · a
```

Повний розмах циклічних зсувних напружень за один прохід кульки становить `Δτ = 2 · τ_orth,max ≈ 0.50 · p₀`. Оскільки матеріал зазнає симетричного циклу знакозмінного зсуву `+0.25·p₀ ↔ −0.25·p₀`, саме ортогональні зсувні напруження `τ_zx` відповідальні за мікропластичне знеміцнення та зародження підповерхневих втомних мікротріщин у вальницях кочення.

### Еквівалентне напруження за Губером-фон Мізесом-Генкі

Еквівалентне напруження за другою енергетичною теорією міцності (фон Мізеса) на осі симетрії дорівнює:

```
σ_vM(z) = √( (1/2) · [ (σ_x − σ_y)² + (σ_y − σ_z)² + (σ_z − σ_x)² ] ) = | σ_z(z) − σ_r(z) | = 2 · τ_max(z)
```

Пік напруження фон Мізеса досягає значення:
```
σ_vM,max ≈ 0.56 · p₀   на глибині   z ≈ 0.57 · a
```

### Радіальне напруження розтягу на зовнішній межі контакту

На поверхні деталі (`z = 0`) при віддаленні від центра плями радіальне напруження змінює знак зі стискального на розтягувальне. На зовнішньому контурі контактного круга (`r = a, z = 0`) виникає максимальне розтягувальне напруження:

```
σ_tensile = p₀ · (1 − 2·ν) / 3
```

Для загартованої сталі (`ν = 0.30`):
```
σ_tensile = +0.133 · p₀
```

Для крихких матеріалів (кераміка з карбіду кремнію, нітриду кремнію, оптичне кварцове скло, надтверді покриття), границя міцності яких на розтяг у 5–10 разів нижча, ніж на стиск, саме це крайове кільцеве напруження є головною причиною руйнування: воно ініціює кільцеві мікротріщини, які розвиваються в глибину у вигляді конічних поверхонь сколу (герцівські конуси тріщин).

## Критерії статичної міцності, текучості та контактної втоми

При проєктуванні контактних пар інженер стикається з трьома режимами навантаження:

1. **Статична міцність за критерієм текучості Треска**:
   Щоб у матеріалі під плямою контакту не виникло залишкової пластичної деформації при одиничному піковому навантаженні, максимальне підповерхневе зсувне напруження не повинно перевищувати допустиме напруження зсуву `[τ] = 0.5 · σ_yield`:
   ```
   τ_max ≤ 0.5 · σ_yield
   0.3105 · p₀ ≤ 0.5 · σ_yield   ⇒   p₀ ≤ 1.61 · σ_yield
   ```
   Коефіцієнт запасу міцності за Треска:
   ```
   SafetyFactor_Tresca = (0.5 · σ_yield) / τ_max
   ```

2. **Статична міцність за критерієм фон Мізеса**:
   ```
   σ_vM,max ≤ σ_yield
   0.56 · p₀ ≤ σ_yield   ⇒   p₀ ≤ 1.78 · σ_yield
   ```
   Обидва критерії показують, що максимальний контактний тиск Герца `p₀` може легітимно перевищувати стандартну межу текучості матеріалу `σ_yield` на 60–80%, не викликаючи макроскопічної плинності, оскільки пластична зона замкнена всередині пружної оболонки навколишнього металу.

3. **Контактна втома та довговічність (теорія Лундберга-Пальмгрена)**:
   При коченні кульки або ролика кожна ділянка доріжки циклічно зазнає підповерхневих знакозмінних зсувних напружень. Втомне руйнування (пітинг) зароджується саме на глибині `z_crit ≈ 0.48·a`.
   Згідно з класичною моделлю Лундберга-Пальмгрена (Lundberg-Palmgren, 1947), номінальна довговічність підшипника `L₁₀` (мільйони обертів до появи першої раковини втоми з імовірністю 90%) пов'язана з еквівалентним динамічним навантаженням `P` степеневою залежністю:
   ```
   L₁₀ = (C / P)^p

   де:
   C — базова динамічна вантажопідйомність вузла
   p = 3 для кулькових (точкових) контактів
   p = 10/3 ≈ 3.33 для роликових (лінійних) контактів
   ```

4. **Теорія пристосовуваності (Shakedown limit)**:
   Якщо навантаження перевищує границю текучості (`p₀ > 1.61·σ_yield`), матеріал зазнає локальної пластичної деформації. Проте при повторних циклах кочення можливі три різні сценарії:
   - **Пружна пристосовуваність (Elastic shakedown)** при `p₀ ≤ 4.0 · k_shear = 2.3 · σ_yield`: утворюються сприятливі залишкові стискальні напруження, після чого контакт деформується суто пружно.
   - **Пластична пристосовуваність (Plastic shakedown)**: циклічна замкнена пластична петля гістерезису без накопичення односпрямованої деформації (втома малого числа циклів).
   - **Прогресуюче пластичне руйнування (Ratchetting)** при `p₀ > 2.8 · σ_yield`: незворотне прогресивне розплющування доріжки та швидке руйнування.

5. **Три стадії деформації за Джонсоном (Johnson's Cavity Model)**:
   При поступовому зростанні контактного навантаження матеріал послідовно проходить три чіткі фізичні стадії:
   - **Суто пружний герцівський контакт** (`p_mean < 1.1 · σ_yield`): усі деформації повністю зворотні, мікроструктура не змінюється.
   - **Пружнопластична індентація** (`1.1 · σ_yield ≤ p_mean ≤ 2.8 · σ_yield`): на підповерхневій глибині `z_crit` зароджується пластичне ядро, оточене пружною матрицею. Зсувні дислокації накопичуються під поверхнею, але поверхня зберігає гладкість.
   - **Повністю пластична течія** (`p_mean ≈ 2.8–3.0 · σ_yield = H`): пластична зона проривається на вільну поверхню, утворюючи напливи металу навколо відбитка. Середній контактний тиск стабілізується на рівні твердості матеріалу `H` за Брінеллем або Віккерсом.

6. **Мікроструктурні зміни в підшипникових сталях (DER та WEB)**:
   При тривалій циклічній роботі (`10⁷–10⁹` циклів при `p₀ > 2.5 ГПа`) у зоні максимальних зсувних напружень відбувається локальний металургійний розпад мартенситу. Формуються темні зони травлення (Dark Etching Regions, DER), а згодом — смуги білого травлення (White Etching Bands, WEB), орієнтовані під кутами 30° та 80° до поверхні кочення, що є фінальною передвісницею катастрофічного викришування металу.

## Чисельний розв'язувач проти прямого методу скінченних елементів (МСЕ)

При розрахунку контакту в інженерній практиці постає вибір між аналітичним розв'язувачем Герца та чисельним моделюванням методом скінченних елементів (МСЕ / FEM у середовищах Ansys, Abaqus, Nastran).

Прямий чисельний розв'язок контактної задачі через МСЕ вимагає колосальних обчислювальних витрат:
- Через крутий градієнт напружень під плямою контакту розмір скінченних елементів у зоні глибини `0.01·a` повинен становити не більше `0.5–2.0 мкм`, що призводить до сіток із мільйонами елементів.
- Контактні в'язі є суворо нелінійними: алгоритми контактних пар на базі штрафних функцій (penalty method) або множників Лагранжа вимагають десятків ітерацій Ньютона-Рафсона для кожного кроку навантаження.
- Розрахунок одного контактного стану в МСЕ займає від кількох хвилин до годин процесорного часу.

Наш аналітично-чисельний алгоритм реалізує прямий розв'язок рівнянь Герца з миттєвим профілюванням напружень за постійний час `O(1)` з точністю до машинного епсилон (`10⁻¹⁶`). Це дозволяє використовувати його всередині високочастотних оптимізаційних циклів підбору підшипників, розрахунків кінематики роботів та фізичних рушіїв реального часу.

#include <stdio.h>
#include <math.h>
#include <stdbool.h>

#ifndef M_PI
#define M_PI 3.14159265358979323846
#endif

/* Тип геометрії контакту */
typedef enum {
    HERTZ_POINT_SPHERE,  /* Точковий контакт (сфери, кулі, кругова пляма) */
    HERTZ_LINE_CYLINDER  /* Лінійний контакт (циліндри, ролики, прямокутна смуга) */
} HertzContactType;

/* Вхідні геометричні та механічні параметри */
typedef struct {
    HertzContactType type;
    double R1, R2;         /* Радіуси кривини тіл, м (для площини R2 = 1.0e12) */
    double length;         /* Довжина контакту для циліндра, м (для сфери = 0) */
    double E1, E2;         /* Модулі пружності Юнга, Па */
    double nu1, nu2;       /* Коефіцієнти Пуассона матеріалів */
    double yield_strength; /* Границя текучості слабшого матеріалу, Па */
} HertzInput;

/* Вихідні результати повного аналізу контакту */
typedef struct {
    double a_or_b;         /* Радіус кругової плями a або півширина смуги b, м */
    double delta;          /* Пружне нормальне зближення центрів тіл, м */
    double p0;             /* Максимальний контактний тиск у центрі, Па */
    double p_mean;         /* Середній контактний тиск по площі, Па */
    double tau_max;        /* Максимальне підповерхневе зсувне напруження, Па */
    double z_crit;         /* Глибина залягання піка зсувних напружень, м */
    double sigma_tensile;  /* Радіальне напруження розтягу на контурі контакту, Па */
    double safety_factor;  /* Коефіцієнт запасу міцності за критерієм Треска */
    bool is_purely_elastic;/* Чи перебуває з'єднання в суто пружному стані */
} HertzOutput;

/* Точка профілю напружень під центром контакту */
typedef struct {
    double depth_z;        /* Глибина заглиблення z, м */
    double zeta;           /* Безрозмірна глибина z / a */
    double sigma_z;        /* Вертикальне напруження стиснення, Па */
    double sigma_r;        /* Радіальне горизонтальне напруження, Па */
    double tau_max;        /* Максимальне зсувне напруження на глибині z, Па */
    double von_mises;      /* Еквівалентне напруження за фон Мізесом, Па */
} HertzStressPoint;

/* Обчислення приведеного контактного модуля пружності E* */
static inline double hertz_calc_e_star(double E1, double nu1, double E2, double nu2) {
    double inv_E = (1.0 - nu1 * nu1) / E1 + (1.0 - nu2 * nu2) / E2;
    return 1.0 / inv_E;
}

/* Обчислення еквівалентного радіуса кривини R */
static inline double hertz_calc_r_eq(double R1, double R2) {
    return (R1 * R2) / (R1 + R2);
}

/* Розв'язання прямої контактної задачі Герца */
bool hertz_solve(const HertzInput *in, double normal_force, HertzOutput *out) {
    if (!in || !out || normal_force <= 0.0 || in->R1 <= 0.0 || in->R2 <= 0.0) {
        return false;
    }
    if (in->E1 <= 0.0 || in->E2 <= 0.0 || in->yield_strength <= 0.0) {
        return false;
    }

    double R = hertz_calc_r_eq(in->R1, in->R2);
    double E_star = hertz_calc_e_star(in->E1, in->nu1, in->E2, in->nu2);

    if (in->type == HERTZ_POINT_SPHERE) {
        /* Точковий контакт сфер */
        out->a_or_b = cbrt((3.0 * normal_force * R) / (4.0 * E_star));
        out->delta = (out->a_or_b * out->a_or_b) / R;
        out->p0 = (3.0 * normal_force) / (2.0 * M_PI * out->a_or_b * out->a_or_b);
        out->p_mean = (2.0 / 3.0) * out->p0;

        /* Підповерхневий зсув та крайовий розтяг */
        out->tau_max = 0.3105 * out->p0;
        out->z_crit = 0.481 * out->a_or_b;
        out->sigma_tensile = out->p0 * (1.0 - 2.0 * in->nu1) / 3.0;
    } else {
        /* Лінійний контакт циліндрів */
        if (in->length <= 0.0) return false;

        out->a_or_b = sqrt((4.0 * normal_force * R) / (M_PI * in->length * E_star));
        out->delta = (out->a_or_b * out->a_or_b) / R;
        out->p0 = (2.0 * normal_force) / (M_PI * out->a_or_b * in->length);
        out->p_mean = (M_PI / 4.0) * out->p0;

        out->tau_max = 0.300 * out->p0;
        out->z_crit = 0.786 * out->a_or_b;
        out->sigma_tensile = 0.0;
    }

    /* Запас за критерієм текучості Треска: tau_max <= 0.5 * sigma_yield */
    double allowable_tau = 0.5 * in->yield_strength;
    out->safety_factor = allowable_tau / out->tau_max;
    out->is_purely_elastic = (out->safety_factor >= 1.0);

    return true;
}

/* Обчислення напруженого стану на заданій глибині z під центром точкового контакту */
bool hertz_point_stress_at_depth(const HertzInput *in, const HertzOutput *out, 
                                 double z, HertzStressPoint *pt) {
    if (!in || !out || !pt || z < 0.0 || out->a_or_b <= 0.0) {
        return false;
    }

    double a = out->a_or_b;
    double p0 = out->p0;
    double nu = in->nu1;
    double zeta = z / a;

    pt->depth_z = z;
    pt->zeta = zeta;
    pt->sigma_z = -p0 / (1.0 + zeta * zeta);

    if (zeta < 1.0e-7) {
        pt->sigma_r = -p0 * (1.0 + 2.0 * nu) / 2.0;
    } else {
        pt->sigma_r = -p0 * ((1.0 + nu) * (1.0 - zeta * atan(1.0 / zeta)) - 
                             0.5 / (1.0 + zeta * zeta));
    }

    pt->tau_max = 0.5 * fabs(pt->sigma_z - pt->sigma_r);
    pt->von_mises = fabs(pt->sigma_z - pt->sigma_r);

    return true;
}

int main(void) {
    /* Приклад 1: сталева кулька підшипника ШХ15 (R1 = 12 мм) на сталевій плоскій доріжці */
    HertzInput input = {

        .yield_strength = 1900.0e6 /* 1900 МПа */
    };

    double normal_force = 2500.0; /* 2500 Н (~255 кг) */
    HertzOutput out;

    if (!hertz_solve(&input, normal_force, &out)) {
        fprintf(stderr, "Помилка розрахунку параметрів контакту!\n");
        return 1;
    }

    printf("================ РЕЗУЛЬТАТИ РОЗРАХУНКУ КОНТАКТУ ГЕРЦА (C99) ================\n");
    printf("Нормальне навантаження N:          %.1f Н\n", normal_force);

    /* Розрахунок та вивід епюри напружень по глибині під центром контакту */

    double mean_pressure;           // p_mean, Па
    double max_shear_stress;        // tau_max, Па
    double critical_depth;          // z_crit, м
    double edge_tensile_stress;     // sigma_tensile на r = a, Па
    double safety_factor;           // Коефіцієнт запасу за Треска
    bool   is_purely_elastic;
};

struct DepthStressEvaluation {
    double depth_z;                 // Глибина z, м
    double normalized_depth;        // z / a
    double sigma_vertical;          // sigma_z, Па
    double sigma_radial;            // sigma_r, Па
    double max_shear;               // tau_max, Па
    double von_mises;               // sigma_vM, Па
};

enum class ContactCalculationError {
    InvalidLoad,
    InvalidGeometry,
    InvalidMaterialProperties
};

[[nodiscard]] constexpr double calculate_reduced_radius(double r1, double r2) noexcept {
    return (r1 * r2) / (r1 + r2);
}

[[nodiscard]] constexpr double calculate_effective_modulus(
    double e1, double nu1, double e2, double nu2) noexcept 
{
    const double inv_e = (1.0 - nu1 * nu1) / e1 + (1.0 - nu2 * nu2) / e2;
    return 1.0 / inv_e;
}

class ContactSolver {
public:
    [[nodiscard]] static std::expected<ContactAnalysisResult, ContactCalculationError> solve(
        const GeometryParameters& geo,
        const MaterialProperties& mat1,
        const MaterialProperties& mat2,
        double normal_load) noexcept 
    {
        if (normal_load <= 0.0) return std::unexpected(ContactCalculationError::InvalidLoad);
        if (geo.radius_1 <= 0.0 || geo.radius_2 <= 0.0) {
            return std::unexpected(ContactCalculationError::InvalidGeometry);
        }
        if (mat1.young_modulus <= 0.0 || mat2.young_modulus <= 0.0 || 
            mat1.yield_strength <= 0.0 || mat2.yield_strength <= 0.0) {
            return std::unexpected(ContactCalculationError::InvalidMaterialProperties);
        }

        const double r_eq = calculate_reduced_radius(geo.radius_1, geo.radius_2);
        const double e_star = calculate_effective_modulus(
            mat1.young_modulus, mat1.poisson_ratio,
            mat2.young_modulus, mat2.poisson_ratio);

        ContactAnalysisResult res{};

        if (geo.type == ContactGeometryType::PointSpherical) {
            res.contact_radius_or_width = std::cbrt((3.0 * normal_load * r_eq) / (4.0 * e_star));
            res.indentation_depth = (res.contact_radius_or_width * res.contact_radius_or_width) / r_eq;
            res.peak_pressure = (3.0 * normal_load) / 
                (2.0 * std::numbers::pi * res.contact_radius_or_width * res.contact_radius_or_width);
            res.mean_pressure = (2.0 / 3.0) * res.peak_pressure;

            res.max_shear_stress = 0.3105 * res.peak_pressure;
            res.critical_depth = 0.481 * res.contact_radius_or_width;
            res.edge_tensile_stress = res.peak_pressure * (1.0 - 2.0 * mat1.poisson_ratio) / 3.0;
        } else {
            if (geo.contact_length <= 0.0) {
                return std::unexpected(ContactCalculationError::InvalidGeometry);
            }

            res.contact_radius_or_width = std::sqrt(
                (4.0 * normal_load * r_eq) / (std::numbers::pi * geo.contact_length * e_star));
            res.indentation_depth = (res.contact_radius_or_width * res.contact_radius_or_width) / r_eq;
            res.peak_pressure = (2.0 * normal_load) / 
                (std::numbers::pi * res.contact_radius_or_width * geo.contact_length);
            res.mean_pressure = (std::numbers::pi / 4.0) * res.peak_pressure;

            res.max_shear_stress = 0.300 * res.peak_pressure;
            res.critical_depth = 0.786 * res.contact_radius_or_width;
            res.edge_tensile_stress = 0.0;
        }

        const double min_yield = std::min(mat1.yield_strength, mat2.yield_strength);
        const double allowable_tau = 0.5 * min_yield;
        res.safety_factor = allowable_tau / res.max_shear_stress;
        res.is_purely_elastic = (res.safety_factor >= 1.0);

        return res;
    }

    [[nodiscard]] static DepthStressEvaluation evaluate_depth_stress(
        const MaterialProperties& mat,
        const ContactAnalysisResult& analysis,
        double depth_z) noexcept 
    {
        const double a = analysis.contact_radius_or_width;
        const double p0 = analysis.peak_pressure;
        const double nu = mat.poisson_ratio;
        const double zeta = depth_z / a;

        const double sz = -p0 / (1.0 + zeta * zeta);
        double sr = 0.0;

        if (zeta < 1.0e-7) {
            sr = -p0 * (1.0 + 2.0 * nu) / 2.0;
        } else {
            sr = -p0 * ((1.0 + nu) * (1.0 - zeta * std::atan(1.0 / zeta)) - 0.5 / (1.0 + zeta * zeta));
        }

        const double tau = 0.5 * std::abs(sz - sr);
        const double vm = std::abs(sz - sr);

        return DepthStressEvaluation{
            .depth_z = depth_z,
            .normalized_depth = zeta,
            .sigma_vertical = sz,
            .sigma_radial = sr,
            .max_shear = tau,
            .von_mises = vm
        };
    }
};

} // namespace mechanics::hertz

int main() {
    using namespace mechanics::hertz;

    const GeometryParameters geometry{
        .type = ContactGeometryType::PointSpherical,
        .radius_1 = 0.012,
        .radius_2 = 1.0e12,

    };

## Покроковий числовий розрахунок реального інженерного вузла

### Приклад 1. Сферична кулька радіального підшипника кочення

Розглянемо практичний інженерний приклад: кулька радіального підшипника кочення зі сталі ШХ15 (AISI 52100) радіусом `R₁ = 12 мм = 0.012 м` навантажена нормальною силою `N = 2500 Н` на плоскій сталевій доріжці кочення (`R₂ = ∞`).

Параметри сталі:
- Модуль Юнга: `E₁ = E₂ = 210 ГПа = 2.10·10¹¹ Па`
- Коефіцієнт Пуассона: `ν₁ = ν₂ = 0.30`
- Границя текучості: `σ_yield = 1900 МПа = 1.90·10⁹ Па`

Покроковий аналітичний розрахунок:

```
1. Ефективний модуль пружності:
   1/E* = (1 − 0.30²) / (2.10·10¹¹) + (1 − 0.30²) / (2.10·10¹¹)
        = 2 · 0.91 / (2.10·10¹¹) = 8.6667·10⁻¹² Па⁻¹
   E*   = 1 / (8.6667·10⁻¹²) = 1.1538·10¹¹ Па = 115.38 ГПа

2. Радіус плями контакту a:
   a = [ (3 · 2500 · 0.012) / (4 · 1.1538·10¹¹) ]^(1/3)
     = [ 90.0 / (4.6154·10¹¹) ]^(1/3)
     = [ 1.9500·10⁻¹⁰ ]^(1/3) = 5.799·10⁻⁴ м ≈ 0.580 мм

3. Пружне нормальне зближення delta:
   delta = a² / R = (5.799·10⁻⁴)² / 0.012 = 3.363·10⁻⁷ / 0.012 = 2.802·10⁻⁵ м ≈ 28.02 мкм

4. Піковий контактний тиск p0:
   p0 = (3 · 2500) / (2 · π · (5.799·10⁻⁴)²)
      = 7500 / (2 · 3.14159 · 3.363·10⁻⁷)
      = 7500 / (2.1130·10⁻⁶) = 3.549·10⁹ Па ≈ 3549 МПа (3.55 ГПа)

5. Максимальне зсувне напруження та глибина піка:
   tau_max = 0.3105 · 3549 МПа = 1102 МПа
   z_crit  = 0.481 · 0.580 мм = 0.279 мм = 279 мкм

6. Перевірка запасу міцності за Треска:
   [tau] = 0.5 · sigma_yield = 0.5 · 1900 МПа = 950 МПа
   SafetyFactor = [tau] / tau_max = 950 / 1102 = 0.86 (< 1.0)
```

**Інженерний висновок**: при навантаженні `2500 Н` коефіцієнт запасу міцності `SafetyFactor = 0.86 < 1.0`. Це означає, що на глибині `279 мкм` під поверхнею контактної плями локальне зсувне напруження перевищує границю текучості сталі. У матеріалі відбуватиметься локальна пластична мікродеформація, яка при циклічному обертанні підшипника призведе до прискореного втомного викришування (пітингу). Щоб забезпечити чисто пружну довговічну роботу з запасом `n = 1.25` (`tau_max ≤ 760 МПа`), максимальне робоче навантаження необхідно зменшити до:

```
N_allowable = N_orig · (760 / 1102)³ = 2500 · 0.328 ≈ 820 Н
```

### Приклад 2. Лінійний контакт циліндричного ролика прокатного стану

Розглянемо циліндричний сталевий ролик довжиною `L = 50 мм = 0.050 м` та радіусом `R = 25 мм = 0.025 м`, який притискається до плоскої сталевої плити під навантаженням `N = 40 000 Н` (40 кН).

Покроковий розрахунок:
```
1. Півширина контактної смуги b:
   b = √( (4 · 40000 · 0.025) / (π · 0.050 · 1.1538·10¹¹) )
     = √( 4000.0 / 1.8124·10¹⁰ ) = √( 2.2070·10⁻⁷ ) = 4.698·10⁻⁴ м ≈ 0.470 мм

2. Піковий тиск по осі контакту p0:
   p0 = (2 · 40000) / (π · 4.698·10⁻⁴ · 0.050)
      = 80000 / (7.3794·10⁻⁵) = 1.084·10⁹ Па = 1084 МПа (1.08 ГПа)

3. Максимальний підповерхневий зсув tau_max та глибина:
   tau_max = 0.300 · 1084 МПа = 325.2 МПа
   z_crit  = 0.786 · 0.470 мм = 0.369 мм = 369 мкм

4. Запас міцності за Треска:
   SafetyFactor = (0.5 · 1900 МПа) / 325.2 МПа = 950 / 325.2 = 2.92 (висока надійність)
```

Порівняння двох прикладів наочно показує, чому роликові підшипники мають значно вищу тримальну здатність порівняно з кульковими при однакових габаритах: перерозподіл нормальної сили з точкової кругової плями на видовжену лінійну смугу знижує піковий тиск з 3.55 ГПа до 1.08 ГПа навіть при зростанні загального навантаження в 16 разів.

### Приклад 3. Порівняльний інженерний аналіз пар матеріалів

Зіставимо параметри контакту сфери радіусом `R = 12 мм` із плоскою плитою під однаковою силою `N = 2500 Н` для п'яти характерних трибологічних комбінацій:

1. **Сталь по сталі (ШХ15)**: `E* = 115.4 ГПа`, `a = 0.580 мм`, `p₀ = 3549 МПа`, `τ_max = 1102 МПа`.
2. **Гібридна кераміка (Si₃N₄ по сталі ШХ15)**: `E₁ = 310 ГПа, ν₁ = 0.26`, `E* = 136.2 ГПа`, `a = 0.548 мм`, `p₀ = 3971 МПа`, `τ_max = 1233 МПа`. Керамічна кулька жорсткіша за сталеву, тому площа плями зменшується, а піковий контактний тиск зростає на 12%. Проте кераміка має вищу границю текучості (`σ_yield > 3000 МПа`), що забезпечує запас міцності навіть при вищому піковому тиску.
3. **Твердий сплав (карбід вольфраму WC-Co по сталі)**: `E₁ = 600 ГПа, ν₁ = 0.22`, `E* = 171.1 ГПа`, `a = 0.508 мм`, `p₀ = 4621 МПа`, `τ_max = 1435 МПа`.
4. **Титановий авіаційний сплав (Ti-6Al-4V по титану)**: `E₁ = E₂ = 114 ГПа, ν₁ = 0.34`, `E* = 64.5 ГПа`, `a = 0.702 мм`, `p₀ = 2420 МПа`, `τ_max = 751 МПа`. Низький модуль пружності титану спричиняє значне пружне сплющування (`a = 0.702 мм`), завдяки чому піковий контактний тиск падає до 2.42 ГПа.
5. **Інженерний полімер (поліацеталь POM / Delrin по сталі)**: `E₁ = 3.1 ГПа, ν₁ = 0.38`, `E* = 3.62 ГПа`, `a = 1.838 мм`, `p₀ = 353 МПа`, `τ_max = 110 МПа`. Податливий полімер деформується на порядок дужче (`δ = 0.281 мм`), розширюючи пляму контакту до 1.84 мм і знижуючи контактний тиск у 10 разів.

## Інженерні пастки та межі застосовності теорії Герца

При застосуванні розв'язувача на практиці необхідно враховувати критичні граничні випадки, де класичні припущення Герца перестають працювати:

1. **Крайові сингулярності прямого циліндричного контакту.** Для ідеальних циліндричних роликів із плоскими торцями на краях виникає теоретична сингулярність тиску (`p → ∞`), що спричиняє швидкий скол країв деталей. У реальному виробництві торці роликів завжди модифікують — виконують **бомбування** (скруглення радіусом R_b) або надають ролику логарифмічного профілю Лундберга, що забезпечує рівномірний розподіл тиску без крайових піків.
2. **Конформний контакт із великою площею.** Якщо радіуси деталей дуже близькі (`R₁ ≈ R₂`, наприклад, куля в глибокій сферичній чашці тазостегнового ендопротеза чи вкладиш підшипника), розмір плями `a` стає сумірним із радіусом `R` (`a / R > 0.15`). Припущення напівпростору перестає діяти, і точний розрахунок вимагає методу скінченних елементів (МСЕ, FEM) або контактної моделі Перссона.
3. **Тонкі поверхневі зміцнювальні шари (DLC, цементація, азотування).** Якщо деталь має тверде зносостійке покриття товщиною `t = 2–5 мкм`, а критична глибина зсуву `z_crit` становить `50–200 мкм`, максимальні зсувні напруження потрапляють під тонке покриття — у м'якшу серцевину матеріалу. Це викликає продавлювання покриття ("яєчна шкаралупа", egg-shell effect) і його відшарування. Товщина зміцненого шару після термообробки обов'язково має перевищувати `2 · z_crit`.
4. **Термопружні контактні сплески (Flash Temperature).** При коченні з проковзуванням на високих швидкостях (наприклад, у зачепленні високооборотних зубчастих коліс) тертя в зоні контакту Герца викликає миттєвий спалах температури (за теорією Блока, H. Blok, 1937) до `200–500 °C` тривалістю в кілька мікросекунд. Цей локальний перегрів різко знижує границю текучості сталі, провокуючи схоплювання (задирання / scuffing) поверхонь навіть за умови формального запасу статичної міцності.
