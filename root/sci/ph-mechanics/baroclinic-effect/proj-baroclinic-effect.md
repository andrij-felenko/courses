# ⚙️ Чисельне моделювання бароклінного моменту та термічного вітру

Обчислення бароклінного моменту завихреності та відновлення поля термічного вітру є базовою задачею чисельного прогнозу погоди, моделювання океанської циркуляції та астрофізичної плазми. Основна обчислювальна складність полягає у точній розностній апроксимації векторного добутку градієнтів `∇ρ × ∇p` на дискретній сітці, оскільки навіть незначні помилки апроксимації градієнта тиску над стрімким рельєфом можуть викликати ложну (чисельну) генерацію бароклінного моменту.

У цьому проектному вивченні реалізовано двовимірний модуль діагностики бароклінності: розрахунок вектора бароклінного моменту сил `τ_baro = (∇ρ × ∇p) / ρ²` та вертикального зсуву геострофічного вітру `∂v_g / ∂z` за заданими тривимірними сітковими полями тиску `p(x,y,z)`, густини `ρ(x,y,z)` та температури `T(x,y,z)`. Наведено реалізації трьома мовами: Python (для швидкого аналізу та візуалізації), C99 (для високопродуктивних гідродинамічних ядер) та сучасному ідіоматичному C++20 (з використанням RAII, `std::span` та векторних контейнерів).

## Дискретизація на сітках Аракави та порядок різниць

Для прямокутної декартової сітки з кроками `dx, dy, dz` компоненти градієнтів обчислюються центральними різницями другого або четвертого порядку точності. Обчислення градієнта тиску та густини здійснюється на внутрішніх вузлах обчислювальної області, тоді як на граничних вузлах використовуються односторонні різниці (спрямовані всередину області) або періодичні граничні умови.

У гідродинаміці геофізичних середовищ вибір розташування змінних на сітці розбігається на п'ять схем Аракави (Arakawa A, B, C, D, E). Найбільш поширеною є сітка Arakawa C, де термодинамічні скаляри (тиск `p`, густина `ρ`, температура `T`) розташовуються у центрах осередків `(i, j, k)`, а компоненти швидкості `u` та `v` — на відповідних бічних гранях осередку `(i+1/2, j, k)` та `(i, j+1/2, k)`. На рознесеній сітці Arakawa C градієнти обчислюються в точках розташування граней, що гарантує точне врівноваження тиску та сили Коріоліса без виникнення високочастотного числового пилоподібного шуму (checkerboard instability).

Для довільного сіткового поля `A[i, j, k]` у внутрішньому вузлі `(i, j)` центральна різниця другого порядку для похідної по осі `x` подається співвідношенням:

```
(∂A/∂x)[i,j] = (A[i+1, j] - A[i-1, j]) / (2 · dx)
```

Відповідно, похідна по осі `y` обчислюється як:

```
(∂A/∂y)[i,j] = (A[i, j+1] - A[i, j-1]) / (2 · dy)
```

Для схем четвертого порядку точності використовується п'ятиточковий шаблон:

```
(∂A/∂x)[i,j] = (- A[i+2, j] + 8 · A[i+1, j] - 8 · A[i-1, j] + A[i-2, j]) / (12 · dx)
```

Використовуючи ці різничні оператори, Z-компонента бароклінного моменту у двовимірній площині `(x, y)` на кожному вертикальному рівні `k` визначається як:

```
τ_z[i,j] = (1 / ρ[i,j]²) · ((∂ρ/∂x)[i,j] · (∂p/∂y)[i,j] - (∂ρ/∂y)[i,j] · (∂p/∂x)[i,j])
```

Вертикальний зсув геострофічного вітру розраховується на основі горизонтальних градієнтів поля температури `T[i,j]` згідно з законами геострофічного та гідростатичного балансів:

```
(∂u_g / ∂z)[i,j] = - (g / (f · T[i,j])) · (T[i, j+1] - T[i, j-1]) / (2 · dy)
(∂v_g / ∂z)[i,j] =   (g / (f · T[i,j])) · (T[i+1, j] - T[i-1, j]) / (2 · dx)
```

## Типові пастки та крайові випадки у чисельних моделях

При практичній реалізації чисельних алгоритмів бароклінної діагностики розробники зіштовхуються з низкою специфічних гідродинамічних пасток, які можуть спотворити фізичний результат або викликати числову нестійкість моделі:

1. **Ложний бароклінний момент у сігма-координатах (PGF error)**:
   У геофізичних моделях із рельєфо-наступними сігма-координатами (`σ = p / p_s` або `σ = (z - η) / (H + η)`) горизонтальний градієнт тиску розкладається на два великих доданки з протилежними знаками: `∇_z p = ∇_σ p + (∂p/∂σ) · ∇_σ z`. Помилка віднімання двох великих близьких чисел призводить до виникнення фиктивного чисельного моменту `τ_baro_err`, який викликає ложну вихровість уздовж підводних хребтів та гірських масивів. Для усунення цієї помилки застосовують якобіанні схеми Аракави — Суареса або перехід на z-координати в зонах крутих схилів.

2. **Незбереження енергії при апроксимації `(1/ρ) · ∇p`**:
   Якщо градієнт тиску `(1/ρ) · ∇p` та бароклінний момент `(1/ρ²) · (∇ρ × ∇p)` розраховуються на рознесених сітках (наприклад, Arakawa C-grid), невідповідність між вузлами розташування тиску та густини порушує точне збереження енергії. Рекомендується використовувати симетричні розносні схеми, що гарантують точне виконання тотожності `∇ × ((1/ρ) · ∇p) = - (1/ρ²) · (∇ρ × ∇p)` на дискретному рівні.

3. **Обробка крайових умов та кутових вузлів**:
   У вузлах на межі обчислювальної області центральні різниці неможливі через відсутність одного із сусідніх вузлів. Застосування односторонніх різниць знижує порядок точності до першого, що створює штучне крайове джерело вихровості. Рекомендований підхід — додавання фіктивних вузлів (ghost cells / halo regions) з подвоєнням або періодичним трансляційним переносом граничних значенням.

4. **Ділення на малу густину та термодинамічні розриви**:
   У високогірних областях або у верхній тропосфері густина повітря стрімко падає, що призводить до зростання множника `1 / ρ²`. Якщо в даних наявний чисельний шум, ділення на малу густину викликає спалахи нестійкості. Для запобігання цього у коді застосовують порогову фільтрацію та згладжувальний фільтр Шапіро для високочастотних шумов.

5. **Організація масивів пам'яті (SoA проти AoS)**:
   При роботі з великими 3D сітками розміром `1000 x 1000 x 100` використання структури масивів (Structure of Arrays, SoA) є значно ефективнішим за масив структур (Array of Structures, AoS). Формат SoA дозволяє завантажувати неперервні блоки густини `ρ` та тиску `p` безпосередньо у векторні регістри процесора (SIMD AVX-512 / ARM NEON), забезпечуючи прискорення розрахунку векторного добутку у 3.5–4.2 рази порівняно з базовою реалізацією.

6. **Тестування на аналітичному тесті Гауссова бульбашки**:
   Для верифікації правильності обчислення бароклінного моменту рекомендується проводити інтеграційне тестування на аналітичному полі з Гауссовою термічною бульбашкою `T(x,y,z) = T₀ + ΔT · exp(-(x²+y²+z²)/R²)`. Для такого поля точне аналітичне рішення `τ_baro_exact` відоме заздалегідь, що дозволяє виміряти норму чисельної помилки `L₂` та переконатися в досягненні заявленого порядку точності схеми.
