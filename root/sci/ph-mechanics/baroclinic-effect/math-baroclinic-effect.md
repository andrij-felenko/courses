# 🧮 Математичний вивід бароклінного моменту та закону термічного вітру

Математичний апарат бароклінності описує зародження та розвиток завихреності у середовищах, де ізобаричні поверхні не збігаються з ізопікнічними. У цьому розділі наведено строгий векторний вивід бароклінного члена в рівнянні завихреності Ейлера, інтегрування циркуляційної теореми Б'єркнеса через просторові соленоїди, математичний вивід закону термічного вітру в обертовій системі координат та аналітичний розрахунок максимального інкременту бароклінної нестійкості в моделі Іді.

## Векторний вивід бароклінного члена завихреності

Розглянемо рівняння руху нев'язкої стисливої рідини (рівняння Ейлера) у нерухомій декартовій системі координат під дією потенціального поля масових сил `g = - ∇Φ` (де `Φ` — гравітаційний потенціал):

```
du/dt = ∂u/∂t + (u · ∇)u = - (1/ρ) · ∇p - ∇Φ
```

Використаємо векторну тотожність для конвективної похідної швидкості через вектор завихреності `ω = ∇ × u`:

```
(u · ∇)u = ∇(u² / 2) - u × (∇ × u) = ∇(u² / 2) - u × ω
```

Підставляючи цю тотожність у рівняння Ейлера, отримуємо рівняння руху у формі Громнеки — Ламба:

```
∂u/∂t - u × ω = - ∇(u² / 2 + Φ) - (1/ρ) · ∇p
```

Щоб отримати рівняння для еволюції вектора завихреності `ω`, застосуємо до обох частин рівняння операцію ротора (`∇ ×`):

```
∇ × (∂u/∂t) - ∇ × (u × ω) = - ∇ × ∇(u² / 2 + Φ) - ∇ × ((1/ρ) · ∇p)
```

Розглянемо кожен доданок окремо:
1. `∇ × (∂u/∂t) = ∂(∇ × u)/∂t = ∂ω/∂t` (оператори частинної похідної по часу та ротора по простору комутують).
2. `∇ × ∇(u² / 2 + Φ) = 0` (ротор від будь-якого градієнта скалярного поля тотожно дорівнює нулю).
3. Третій доданок — ротор від добутку скаляра `(1/ρ)` на вектор `∇p`. Використаємо формулу ротора від добутку скалярного поля `f` на векторне поле `A`: `∇ × (f · A) = ∇f × A + f · (∇ × A)`.

Застосовуючи цю тотожність до градієнта тиску:

```
∇ × ((1/ρ) · ∇p)
= ∇(1/ρ) × ∇p + (1/ρ) · (∇ × ∇p)          [розклад ротора від добутку]
= - (1/ρ²) · (∇ρ × ∇p) + 0                [похідна ∇(1/ρ) = - ∇ρ / ρ² та ∇ × ∇p = 0]
= - (1/ρ²) · (∇ρ × ∇p)
```

Для другого доданка лівої частини `∇ × (u × ω)` використаємо тотожність ротора подвійного векторного добутку:

```
∇ × (u × ω) = (ω · ∇)u - (u · ∇)ω + u · (∇ · ω) - ω · (∇ · u)
```

Ураховуючи, що дивергенція ротора тотожно дорівнює нулю (`∇ · ω = ∇ · (∇ × u) = 0`), вираз спрощується до:

```
∇ × (u × ω) = (ω · ∇)u - (u · ∇)ω - ω · (∇ · u)
```

Переносячи конвективний член `(u · ∇)ω` у ліву частину для формування повної матеріальної похідної `dω/dt = ∂ω/∂t + (u · ∇)ω`, отримуємо **тривимірне рівняння завихреності бароклінного середовища**:

```
dω/dt = (ω · ∇)u - ω · (∇ · u) + (1/ρ²) · (∇ρ × ∇p)
```

У цьому рівнянні:
- `(ω · ∇)u` — член розтягування та повороту вихрових ниток (англ. *vortex stretching and tilting*), наявний у тривимірному плині;
- `- ω · (∇ · u)` — член стискання/розширення рідкого об'єму (зміна завихреності через збереження моменту імпульсу при зміні об'єму);
- `τ_baro = (1/ρ²) · (∇ρ × ∇p)` — **бароклінний момент завихреності** (англ. *baroclinic torque*).

Якщо середовище є баротропним (`ρ = ρ(p)`), то вектори `∇ρ` та `∇p` паралельні у кожній точці простору, векторний добуток `∇ρ × ∇p = 0`, і бароклінний член зникає. У бароклінному середовищі кут між градієнтом густини та градієнтом тиску відмінний від нуля, що призводить до автономної генерації вихровості.

## Інтегрування теореми Б'єркнеса та соленоїди

Обчислимо похідну по часу від циркуляції швидкості `Γ = ∮[C(t)] u · dr` вздовж матеріального контуру `C(t)`:

```
dΓ/dt = ∮[C(t)] (du/dt) · dr + ∮[C(t)] u · d(dr)/dt
```

Оскільки `d(dr)/dt = du`, другий інтеграл дорівнює `∮ u · du = ∮ d(u² / 2) = 0`. Підставляючи `du/dt = - (1/ρ) · ∇p - ∇Φ` з рівняння Ейлера:

```
dΓ/dt = - ∮[C(t)] (1/ρ) · ∇p · dr - ∮[C(t)] ∇Φ · dr
```

Оскільки `∇Φ · dr = dΦ` є повним диференціалом потенціалу, інтеграл по замкненому контуру від нього дорівнює нулю: `∮ dΦ = 0`. Отримуємо класичну форму теореми Б'єркнеса:

```
dΓ/dt = - ∮[C(t)] (dp / ρ)
```

Використовуючи теорему Стокса, перетворимо контурний інтеграл на поверхневий по замкненій площині `S(t)`, натягнутій на контур `C(t)`:

```
dΓ/dt = - ∮[C(t)] (1/ρ) · dp
      = ∬[S(t)] ∇ × (- (1/ρ) · ∇p) · dA
      = ∬[S(t)] (1/ρ²) · (∇ρ × ∇p) · dA
```

Ввівши питомий об'єм `α = 1/ρ` (лат. *volumen specificum*), вираз набуває вигляду:

```
dΓ/dt = ∬[S(t)] (∇α × ∇p) · dA = ∬[S(t)] (∂α/∂x · ∂p/∂y - ∂α/∂y · ∂p/∂x) dx dy
```

За теоремою Якобі цей інтеграл дорівнює кількості ізобарично-ізостеричних соленоїдів `N_S`, утворених перетином одиничних ізобар (`Δp = 1 hPa`) та одиничних ізостер (`Δα = 1 cm³/g`):

```
dΓ/dt = N_S (ізобара-ізостера)
```

Перехід від поверхневого інтеграла Якобіана `J(α, p) = ∂(α, p) / ∂(x, y)` до суми соленоїдів базується на зміні змінних інтегрування від просторових координат `(x, y)` до термодинамічних координат `(α, p)`:

```
∬[S(x,y)] (∂(α, p) / ∂(x, y)) dx dy = ∬[S(α,p)] dα dp = N_S
```

Ця геометрична еквівалентність показує, що площа петлі замкненого контуру у фазовому просторі `(α, p)` точно дорівнює прискоренню гідродинамічної циркуляції.

## Вивід рівняння термічного вітру

У геофізичній гідродинаміці великомасштабні атмосферні та океанічні течії перебувають у стані геострофічного балансу — рівноваги між силею градієнта тиску та силою Коріоліса:

```
f · v_g =   (1/ρ) · (∂p/∂x)
f · u_g = - (1/ρ) · (∂p/∂y)
```

де `u_g, v_g` — зональна (східна) та меридіональна (північна) компоненти геострофічного вітру, `f = 2·Ω·sin(φ)` — параметр Коріоліса.

Для визначення вертикального зсуву геострофічного вітру `∂u_g / ∂z` та `∂v_g / ∂z` продеференціюємо рівняння геострофічного балансу по вертикальній координаті `z`:

```
f · ∂(ρ · u_g)/∂z = - ∂²p / (∂z ∂y)
f · ∂(ρ · v_g)/∂z =   ∂²p / (∂z ∂x)
```

Використаємо рівняння гідростатики `∂p/∂z = - ρ · g` для заміни других похідних тиску:

```
∂²p / (∂z ∂y) = ∂/∂y (∂p/∂z) = ∂/∂y (- ρ · g) = - g · (∂ρ/∂y)
∂²p / (∂z ∂x) = ∂/∂x (∂p/∂z) = ∂/∂x (- ρ · g) = - g · (∂ρ/∂x)
```

Підставляючи ці вирази у геострофічні рівняння та нехтуючи вертикальними змінами густини в лівій частині (Буссінесківське наближення `∂ρ/∂z ≪ ρ/H`):

```
∂u_g / ∂z =   (g / (f · ρ₀)) · (∂ρ / ∂y)
∂v_g / ∂z = - (g / (f · ρ₀)) · (∂ρ / ∂x)
```

Для ідеального газу при сталому тиску густина обернено пропорційна температурі `ρ = p / (R · T)`, звідки `(1/ρ) · ∇ρ = - (1/T) · ∇T`. Підставляючи цей термодинамічний зв'язок:

```
∂u_g / ∂z = - (g / (f · T₀)) · (∂T / ∂y)
∂v_g / ∂z =   (g / (f · T₀)) · (∂T / ∂x)
```

У векторній формі це дає **класичне рівняння термічного вітру**:

```
∂v_g / ∂z = (g / (f · T₀)) · (k × ∇_H T)
```

де `v_g = (u_g, v_g)` — вектор горизонтального геострофічного вітру, `k` — вертикальний одиничний орт, `∇_H T = (∂T/∂x, ∂T/∂y)` — горизонтальний градієнт температури.

Термічний вітр `v_T = v_g(z₂) - v_g(z₁)` являє собою векторну різницю геострофічного вітру між двома висотами. З рівняння випливає: якщо на північній півкулі (`f > 0`) температура знижується у напрямку до полюса (`∂T/∂y < 0`), то `∂u_g / ∂z > 0`, що викликає потужне зростання західного вітру з висотою та утворення струминних течій на межі тропосфери.

## Аналітичний розв'язок моделі Іді та дисперсійне співвідношення

У моделі Іді (Eady, 1949) атмосфера розглядається як шар стисливого газу товщиною `H` між двома горизонтальними кришками у полі тяжіння та Коріоліса. Основний потік має сталий вертикальний зсув геобрифного вітру `U_g(z) = U_z · z`.

Рівняння для возмущення квазігеострофічної потенціальної вихровості `q'` у безрозмірних змінних виглядає як:

```
(∂/∂t + U_z · z · ∂/∂x) (∇² ψ' + (f² / N²) · ∂²ψ'/∂z²) = 0
```

де `ψ'` — функція току малого обурювання (`u' = - ∂ψ'/∂y`, `v' = ∂ψ'/∂x`).

Шукаючи розв'язок у формі біжучої хвилі `ψ'(x, y, z, t) = Re[Φ(z) · exp(i·k·(x - c·t)) · sin(l·y)]`, отримуємо звичайне диференціальне рівняння для вертикальної амплітуди `Φ(z)`:

```
d²Φ/dz² - μ² · Φ = 0
```

де `μ = (N · H / f) · √(k² + l²)` — безрозмірне абсолютне хвильове число.

Граничні умови на верхній та нижній кришках (`z = 0` та `z = H`) визначаються з умови відсутності вертикальної швидкості `w' = 0`:

```
(z - c) · dΦ/dz - Φ = 0   при z = 0
(z - c) · dΦ/dz - Φ = 0   при z = H
```

Загальний розв'язок рівняння для `Φ(z)` шукається у вигляді суми гіперболічних функцій `Φ(z) = A · cosh(μ·z/H) + B · sinh(μ·z/H)`. Підстановка цього розв'язку у граничні умови дає квадратне рівняння відносно фазової швидкості `c`:

```
c² - c · H + (H² / μ²) · (μ · coth(μ) - 1) = 0
```

Розв'язуючи це квадратне рівняння, отримуємо **дисперсійне співвідношення Іді**:

```
c = H/2 ± (H / μ) · √((μ/2 - tanh(μ/2)) · (μ/2 - coth(μ/2)))
```

Комплексні корені (`Im(c) = c_i > 0`) існують тоді і тільки тоді, коли вираз під коренем є від'ємним. Це відбувається в діапазоні безрозмірних хвильових чисел `0 < μ < 2.399`.

Максимальне значення уявного фазового кута досягається при `μ_opt ≈ 1.61`, що відповідає максимальному інкременту зростання бароклінної нестійкості:

```
σ_max = k · c_i_max ≈ 0.3098 · (f / N) · (dU_g / dz)
```

Характерний час подвоєння амплітуди бароклінної хвилі `t_2 = ln(2) / σ_max` для типових атмосферних параметрів помірних широт (`f = 10⁻⁴ s⁻¹`, `N = 10⁻² s⁻¹`, `dU_g/dz = 3 · 10⁻³ s⁻¹`) становить:

```
σ_max ≈ 0.3098 · (10⁻⁴ / 10⁻²) · (3 · 10⁻³) ≈ 9.29 · 10⁻⁶ s⁻¹
t_2 = 0.693 / (9.29 · 10⁻⁶) ≈ 74600 s ≈ 20.7 годин
```

Це математично пояснює, чому реальні атмосферні циклони помірних широт розвиваються від малого збурення до повномасштабного шторму за 1–2 доби.
