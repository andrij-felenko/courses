# 🧮 Математичні доведення теорем Гельмгольца, Кельвіна та Ертеля

Цей документ містить строге математичне виведення диференціального рівняння переносу вихореності у векторній та тензорній нотаціях, виведення лагранжевої формули Коші для вихореності, строгі доведення трьох теорем Гельмгольца, теореми Кельвіна про збереження циркуляції та теореми Ертеля про потенціальну вихореність у стратифікованих середовищах.

## 1. Тензорний аналіз та векторні тотожності диференціювання рівняння Ейлера

Розглянемо потік ідеальної (нев'язкої) нестисливої рідини постійної густини `ρ = const`, що описується векторним рівнянням руху Ейлера під дією консервативних масових сил із потенціалом `V` (`f = -∇V`):

```
∂u/∂t + (u · ∇)u = -(1/ρ)·∇p - ∇V   [РІВНЯННЯ ЕЙЛЕРА]
```

Для глибшого розуміння векторних перетворень використовуватимемо як безиндексну векторну нотацію, так і тензорну нотацію Ейнштейна з символом Леві-Чивіта `ε_ijk` та дельтою Кронекера `δ_ij`.

Запишемо `k`-ту компоненту конвективного прискорення `(u · ∇)u_k = u_j · (∂u_k / ∂x_j)`. Скориставшись алгебраїчною тотожністю для добутку символів Леві-Чивіта `ε_ijk · ε_ilm = δ_jl · δ_km - δ_jm · δ_kl`, розкладемо градієнт швидкості на симетричну та антисиметричну частини:

```
u_j · (∂u_k / ∂x_j) = ∂_k (u_j · u_j / 2) - ε_klm · u_l · (ε_mji · ∂_j u_i)
```

Оскільки вектор вихореності за визначенням є ротором швидкості `ω = ∇ × u`, його `m`-та компонента дорівнює `ω_m = ε_mji · ∂_j u_i`.

Таким чином, у векторній формі конвективне прискорення набуває вигляду:

```
(u · ∇)u = ∇(u²/2) - u × (∇ × u) = ∇(u²/2) - u × ω   [ТОТОЖНІСТЬ ГРОМЕКИ]
```

Підставляючи цю тотожність у рівняння Ейлера, отримуємо рівняння руху у формі Громеки — Лемба:

```
∂u/∂t + ∇(u²/2) - u × ω = -(1/ρ)·∇p - ∇V
∂u/∂t - u × ω = -∇( p/ρ + V + u²/2 )   [ФОРМА ГРОМЕКИ — ЛЕМБА]
```

Для виведення диференціального рівняння еволюції вихореності застосуємо оператор ротора (`∇ ×`) до обох частин рівняння Громеки — Лемба. Оскільки ротор градієнта будь-якої скалярної гладкої функції тотожно дорівнює нулю (`∇ × ∇Φ = 0`), уся права частина зі скалярним тиском, гравітаційним потенціалом та кінетичною енергією перетворюється на нуль:

```
∇ × ( ∂u/∂t ) - ∇ × ( u × ω ) = 0
∂(∇ × u)/∂t - ∇ × ( u × ω ) = 0
∂ω/∂t - ∇ × ( u × ω ) = 0            [ПРОМІЖНЕ РІВНЯННЯ РОТОРА]
```

Скористаємося фундаментальною векторною тотожністю для ротора векторного добутку двох довільних векторних полів `A` та `B`:

```
∇ × (A × B) = A·(∇ · B) - B·(∇ · A) + (B · ∇)A - (A · ∇)B
```

Покладаючи `A = u` та `B = ω`, маємо чотири доданки:

```
∇ × (u × ω) = u·(∇ · ω) - ω·(∇ · u) + (ω · ∇)u - (u · ∇)ω
```

Проаналізуємо кожен із чотирьох доданків правій частині:
1. `∇ · ω = ∇ · (∇ × u) = 0` — дивергенція ротора будь-якого векторного поля тотожно дорівнює нулю внаслідок симетрії других мішаних похідних.
2. `∇ · u = 0` — дивергенція поля швидкостей дорівнює нулю внаслідок закон збереження маси нестисливої рідини.

Отже, два перші доданки перетворюються на нуль, і тотожність спрощується до двох доданків:

```
∇ × (u × ω) = (ω · ∇)u - (u · ∇)ω
```

Підставляючи отриманий вираз у проміжне рівняння ротора, отримуємо фундаментальне **диференціальне рівняння переносу вихореності (Vorticity Transport Equation)**:

```
∂ω/∂t + (u · ∇)ω = (ω · ∇)u          [РІВНЯННЯ ПЕРЕНОСУ ВИХОРЕНОСТІ]
```

Увівши оператор повної (матеріальної/субстанційної) похідної за часом `Dω/Dt = ∂ω/∂t + (u · ∇)ω`, що описує часову зміну вихореності у частинці рідини, яка рухається зі швидкістю `u`, запишемо рівняння у компактній формі:

```
Dω/Dt = (ω · ∇)u                     [МАТЕРІАЛЬНЕ РІВНЯННЯ ВИХОРЕНОСТІ]
```

член `(ω · ∇)u` у правій частині називається **членом розтягнення та повертання вихорових трубок (Vortex Stretching and Tilting Term)**. Він описує деформацію вихорової лінії внаслідок наявності градієнта швидкості вздовж осі обертання.

### Доведення відсутності розтягнення вихорів у двовимірному потоці
У двовимірному потоці у площині `(x, y)` вектор швидкості має компоненти `u = (u_x(x,y,t), u_y(x,y,t), 0)`.
Вектор вихореності спрямований строго перпендикулярно до площини руху: `ω = (0, 0, ω_z)`, де `ω_z = ∂u_y/∂x - ∂u_x/∂y`.

Обчислимо оператор розтягнення `(ω · ∇)u`:

```
(ω · ∇)u = ω_z · (∂u / ∂z)           [ОПЕРАТОР РОЗТЯГНЕННЯ У 2D]
```

Оскільки у плоскому потоці швидкість `u` взагалі не залежить від координати `z` (`∂u/∂z = 0`), оператор розтягнення дає тотожний нуль:

```
(ω · ∇)u = 0                         [ЗНИКНЕННЯ РОЗТЯГНЕННЯ У 2D]
```

Таким чином, у 2D гідродинаміці диференціальне рівняння переносу вихореності спрощується до скалярного рівняння переносу чистої адвекції:

```
Dω_z/Dt = ∂ω_z/∂t + u_x·(∂ω_z/∂x) + u_y·(∂ω_z/∂y) = 0   [ЗБЕРЕЖЕННЯ 2D ВИХОРЕНОСТІ]
```

Це доводить, що у двовимірній нев'язкій рідині вихореність кожної окремої частинки рідини є строго постійною величиною під час усього її руху.

## 2. Формула Коші для вихореності та математичне доведення 1-ї теореми Гельмгольца

Для доведення вмороженості вихорових ліній перейдемо від ейлерового опису до лагранжевого опису руху рідини.

Нехай `x₀ = (a, b, c)` — початкове положення частинки рідини у момент часу `t = 0`, а `x = x(x₀, t)` — її положення у момент часу `t`. Швидкість частинки дорівнює `u = ∂x / ∂t`.

Розглянемо еволюцію нескінченно малого матеріального вектора зміщення `dx` між двома сусідніми частинками рідини. За правилом диференціювання складеної функції:

```
dx_i = (∂x_i / ∂x₀_j) · dx₀_j        [ТЕНЗОР ГРАДІЄНТА ДЕФОРМАЦІЇ]
```

Обчислимо матеріальну похідну за часом від елемента `dx_i`:

```
D(dx_i)/Dt = (∂ / ∂t) [ (∂x_i / ∂x₀_j) · dx₀_j ] = (∂u_i / ∂x₀_j) · dx₀_j
```

Застосувавши ланцюгове правило диференціювання `∂u_i / ∂x₀_j = (∂u_i / ∂x_k) · (∂x_k / ∂x₀_j)`, отримуємо:

```
D(dx_i)/Dt = (∂u_i / ∂x_k) · (∂x_k / ∂x₀_j) · dx₀_j = (∂u_i / ∂x_k) · dx_k
```

У безиндексній векторній формі рівняння еволюції матеріального елемента рідини записується так:

```
D(dx)/Dt = (dx · ∇)u                 [РІВНЯННЯ ЕВОЛЮЦІЇ РІДКОГО ЕЛЕМЕНТА]
```

Порівняємо це рівняння з матеріальним рівнянням переносу вихореності нестисливої рідини:

```
Dω/Dt = (ω · ∇)u                     [РІВНЯННЯ ЕВОЛЮЦІЇ ВИХОРЕНОСТІ]
```

Рівняння для матерільного векторного елемента `dx` та для вектора вихореності `ω` мають **абсолютно тотожну математичну структуру**. Це означає, що вектор вихореності `ω(t)` деформується, повертається та розтягується потоком точно так само, як і нескінченно малий рідкий елемент `dx`, утворений тими самими частинками рідини.

Звідси випливає аналітичний розв'язок — **формула Коші для вихореності (1815)**:

```
ω_i(x, t) / ρ(x, t) = (ω₀_j(x₀) / ρ₀(x₀)) · (∂x_i / ∂x₀_j)   [ФОРМУЛА КОШІ]
```

Для нестисливої рідини постійної густини (`ρ = ρ₀ = const`) формула Коші набуває векторного вигляду:

```
ω(x, t) = (ω₀(x₀) · ∇₀) x            [ВЕКТОРНА ФОРМУЛА КОШІ]
```

де `∇₀` означає оператор градієнта за початковими лагранжевими координатами `x₀`.

### Математичний висновок Першої теореми Гельмгольца:
Нехай у початковий момент часу `t = 0` дві нескінченно близькі частинки `A` та `B` лежать на одній вихоровій лінії. Це означає, що початковий матеріальний вектор `dx₀ = x₀(B) - x₀(A)` є паралельним початковому вектору вихореності `ω₀(x₀)`:

```
dx₀ = λ₀ · ω₀(x₀)                    [УМОВА ПАРАЛЕЛЬНОСТІ ПРИ t=0]
```

Помноживши обидві частини на тензор градієнта деформації `(∂x_i / ∂x₀_j)`, отримуємо для будь-якого моменту часу `t > 0`:

```
dx(t) = (∂x / ∂x₀) · dx₀ = λ₀ · (∂x / ∂x₀) · ω₀ = λ₀ · ω(t)
```

Отже, вектор `dx(t)` залишається строго паралельним вектору `ω(t)` для всіх `t > 0`. Частинки `A` та `B` протягом усього руху залишаються на одній і тій самій вихоровій лінії. Це доводить, що **вихорові лінії є вмороженими у рідину і рухаються разом із матеріальним потоком**.

## 3. Математичне доведення Другої та Третьої теорем Гельмгольца

### Доведення Третьої теореми (Соленоїдальність вихореності)
З фундаментальної тотожності векторного аналізу випливає, що дивергенція ротора будь-якого тричі диференційовного векторного поля тотожно дорівнює нулю:

```
∇ · ω = ∇ · (∇ × u) = 0             [СОЛЕНОЇДАЛЬНІСТЬ ПОЛЯ ВИХОРЕНОСТІ]
```

За теоремою Остроградського — Гаусса для довільного замкненого об'єму рідини `V`, обмеженого гладкою поверхнею `S`:

```
∭_V (∇ · ω) dV = ∬_S (ω · n) dS = 0  [ПОТОК ВИХОРЕНОСТІ ЧЕРЕЗ ЗАМКНЕНУ ПОВЕРХНЮ]
```

Розглянемо уривок вихорової трубки, обмежений бічною поверхнею `S_lat` та двома довільними поперечними перерізами `S₁` та `S₂`. За визначенням вихорової трубки, вектор вихореності `ω` у кожній точці бічної поверхні є дотичним до неї, тому скалярний добуток з зовнішньою нормаллю на `S_lat` дорівнює нулю: `ω · n_lat = 0`.

Тоді інтеграл по всій замкненій поверхні `S = S₁ ∪ S₂ ∪ S_lat` спрощується:

```
∬_S₁ (ω · n₁) dS + ∬_S₂ (ω · n₂) dS + ∬_S_lat (ω · n_lat) dS = 0
- ∬_S₁ (ω · n_in) dS + ∬_S₂ (ω · n_out) dS + 0 = 0
∬_S₁ (ω · n) dS = ∬_S₂ (ω · n) dS    [ЗБЕРЕЖЕННЯ ІНТЕНСИВНОСТІ ВЗДОВЖ ТРУБКИ]
```

Це доводить:
1. **Другу теорему Гельмгольца:** Інтенсивність вихорової трубки `Г = ∬_S (ω · n) dS` однакова у всіх її поперечних перерізах у даний момент часу.
2. **Третьому теорему Гельмгольца:** Вихорова трубка не може починатися або закінчуватися усередині об'єму рідини. Якби вихорова трубка мала торець усередині рідини, потік вихореності через замкнену поверхню навколо цього торця був би відмінним від нуля, що суперечить тотожності `∇ · ω = 0`.

## 4. Математичне доведення теореми Кельвіна про циркуляцію

Нехай `C(t)` — замкнений матеріальний контур, утворений одними й тими самими частинками рідини, що рухаються зі швидкістю `u(r, t)`.

Циркуляція швидкості вздовж контуру `C(t)` визначається як:

```
Г(t) = ∮_C(t) (u · dr)                [ВИЗНАЧЕННЯ ЦИРКУЛЯЦІЇ]
```

Обчислимо повну матеріальну похідну за часом `dГ/dt`:

```
dГ/dt = (d/dt) [ ∮_C(t) (u · dr) ] = ∮_C(t) [ (Du/Dt · dr) + (u · D(dr)/Dt) ]
```

Оскільки матеріальна похідна елемента зміщення дорівнює дифференціалу швидкості `D(dr)/Dt = d(Dr/Dt) = du`, другий доданок під інтегралом перетворюється на повний диференціал квадрата швидкості:

```
u · D(dr)/Dt = u · du = d(u²/2)
```

Інтеграл від повного диференціала гладкої функції по замкненому контуру дорівнює строго нулю:

```
∮_C(t) d(u²/2) = 0
```

Отже, похідна циркуляції спрощується до вигляду:

```
dГ/dt = ∮_C(t) (Du/Dt · dr)           [ПРОМІЖНЕ РІВНЯННЯ КЕЛЬВІНА]
```

Підставимо у це рівняння вираз для прискорення частинки `Du/Dt` з рівняння Ейлера `Du/Dt = -(1/ρ)·∇p - ∇V`:

```
dГ/dt = ∮_C(t) [ -(1/ρ)·∇p - ∇V ] · dr = - ∮_C(t) (1/ρ)·dp - ∮_C(t) dV
```

Оскільки гравітаційний потенціал `V` є однозначною скалярною функцією координат, інтеграл по замкненому контуру `∮_C dV = 0`.

Для **баротропної рідини** густина залежить виключно від тиску `ρ = ρ(p)`. У цьому випадку підінтегральний вираз `(1/ρ(p))·dp = dP(p)` є повним диференціалом функції тиску `P(p) = ∫ dp / ρ(p)`:

```
∮_C(t) (1/ρ)·dp = ∮_C(t) dP = 0
```

Таким чином, обидва інтеграли у правій частині перетворюються на нуль, і ми отримуємо математичне формулювання **теореми Кельвіна**:

```
dГ/dt = 0 ⇒ Г(t) = const              [ТЕОРЕМА КЕЛЬВІНА]
```

Це доводить, що циркуляція швидкості вздовж будь-якого матеріального замкненого контуру залишається строго постійною в часі при русі нев'язкої баротропної рідини під дією консервативних масових сил.

## 5. Узагальнення Ертеля: Потенціальна вихоровість у стратифікованих середовищах

У 1942 році німецький геофізик та метеоролог Ганс Ертель (Hans Ertel) сформулював узагальнення теорем Гельмгольца та Кельвіна для обертальних стратифікованих середовищ (наприклад, атмосфери та океану), де виконується інваріантний закон збереження скалярної величини — **потенціальної вихореності Ертеля (Ertel's Potential Vorticity)**.

Нехай `θ` — довільний скалярний інваріант рідини, що задовольняє рівняння чистої адвекції `Dθ/Dt = 0` (наприклад, потенціальна температура в атмосфері або солоність у океані).

**Потенціальна вихореність Ертеля `q`** визначається як скалярний добуток абсолютного вектора вихореності `ω_abs = ω + 2Ω` на градієнт скаляра `∇θ`, поділений на густину `ρ`:

```
q = [ (ω + 2·Ω) · ∇θ ] / ρ            [ПОТЕНЦІАЛЬНА ВИХОРЕВІСТЬ ЕРТЕЛЯ]
```

де `Ω` — вектор кутової швидкості обертання Землі.

Ертель довів, що для нев'язкого баротропного або адіабатичного потоку потенціальна вихореність кожної рідкої частинки є строго постійною в часі:

```
Dq/Dt = 0                            [ЗАКОН ЗБЕРЕЖЕННЯ ЕРТЕЛЯ]
```

Теорема Ертеля є фундаментальним інструментом сучасної геофізичної гідродинаміки, який пояснює генерацію великомасштабних хвилин Россбі, блокуючих антициклонів та океанічних вихорів Гольфстріму.
