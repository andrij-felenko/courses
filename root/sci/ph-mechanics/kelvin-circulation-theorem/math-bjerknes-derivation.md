# 🧮 Теорема Б'єркнеса та бароклінна генерація циркуляції

Теорема Кельвіна про циркуляцію виходить із припущення про баротропність рідини, коли густина середовища `ρ` є функцією виключно тиску `p` (`ρ = ρ(p)`). У багатьох реальних геофізичних та астрофізичних систем — в атмосфері Землі, океанах, зіркових плазмових оболонках та міжзоряних хмарах — це припущення порушується. Густина газу чи рідини залежить не лише від тиску, але й від температури `T`, солоності `S` або хімічного складу. Таке середовище називається бароклінним (грец. *baros* — вага, *klino* — нахил).

У 1898 році норвезький метеоролог та геофізик Вільгельм Б'єркнес (Vilhelm Bjerknes) узагальнив теорему Кельвіна на випадок довільного бароклінного плину, що стало фундаментом сучасної динамічної метеорології та фізичної океанографії.

## Фізична природа бароклійності

У баротропному середовищі поверхні постійного тиску (ізобари, `p = const`) та поверхні постійної густини (ізопікни, `ρ = const`) всюди паралельні між собою. Це означає, що градієнт густини `∇ρ` напрямлений строго уздовж градієнта тиску `∇p`. Внаслідок цього сила тиску, що діє на кожен рідкий елемент, проходить через його центр мас і не створює обертального моменту.

У бароклінному середовищі температура або хімічний склад змінюються незалежно від тиску. Наприклад, біля нагрітої підстильної поверхні повітря розширюється і його густина зменшується локально при сталому атмосферному тиску. В результаті ізобари та ізопікни перетинаються під деяким кутом `θ`. Вектори `∇ρ` та `∇p` більше не є колінеарними, і їхній векторний добуток `∇ρ × ∇p` не дорівнює нулю.

Оскільки більш щільне повітря має більшу інертність ніж розряджене, однаковий градієнт тиску `∇p` надає різного прискорення сусіднім рідким частинкам:

```
du/dt = - (1 / ρ) · ∇p
```

Ця асиметрія прискорень призводить до виникнення зсувних шарів швидкості і спричиняє обертання рідкої маси навколо осі, перпендикулярної до площини векторів `∇ρ` та `∇p`.

## Диференціальний вивід рівняння еволюції циркуляції

Розглянемо замкнений рідкий контур `C(t)`, що складається з фіксованих частинок середовища і рухається зі швидкістю течії `u`. Повна похідна циркуляції швидкості по часу виражається як:

```
dΓ/dt = d/dt ∮[C(t)] u · dr
```

Застосовуючи правило диференціювання контурного інтеграла вздовж рухомої лінії (транспортна теорема Лейбніца для лінійного елемента `d(dr)/dt = d(u)`), отримуємо:

```
dΓ/dt = ∮[C(t)] (du/dt) · dr + ∮[C(t)] u · du
```

Другий інтеграл є повним диференціалом від квадрата швидкості на замкненому контурі і тотожно дорівнює нулю:

```
∮[C(t)] u · du = ∮[C(t)] d(u² / 2) = 0
```

Підставимо у перший інтеграл рівняння руху ідеальної рідини (рівняння Ейлера) під дією консервативних масових сил із потенціалом `Φ` (наприклад, сили тяжіння, де `f = -∇Φ`):

```
du/dt = -(1 / ρ) · ∇p - ∇Φ
```

Отримуємо загальний вираз для зміни циркуляції:

```
dΓ/dt = - ∮[C(t)] (1 / ρ) · ∇p · dr - ∮[C(t)] ∇Φ · dr
```

Оскільки градієнт скалярного потенціалу `∇Φ` на замкненому контурі дає нуль (`∮ ∇Φ · dr = ∮ dΦ = 0`), вираз спрощується до:

```
dΓ/dt = - ∮[C(t)] (1 / ρ) · ∇p · dr = - ∮[C(t)] (dp / ρ)
```

У баротропній рідині `ρ = ρ(p)`, тому величина `1 / ρ` інтегрується як функція тиску `P(p) = ∫ dp / ρ`, вираз під інтегралом стає повним диференціалом `dP`, і його замкнений інтеграл дорівнює нулю (класична теорема Кельвіна).

Однак у бароклінній рідині `ρ` залежить від обох змінних `p` та `T`. Скористаємося векторною тотожністю і теоремою Стокса для перетворення контурного інтеграла по `C(t)` на інтеграл по поверхні `S(t)`, яку спирається контур:

```
dΓ/dt = - ∮[C(t)] (1 / ρ) · ∇p · dr
      = - ∬[S(t)] ∇ × ((1 / ρ) · ∇p) · dA           [теорема Стокса]
```

Розкриємо ротор добутку скаляра `1 / ρ` на вектор градієнта `∇p`:

```
∇ × ((1 / ρ) · ∇p) 
= (1 / ρ) · (∇ × ∇p) + ∇(1 / ρ) × ∇p             [векторне тотожність для ∇ × (f A)]
= 0 + (-1 / ρ²) · (∇ρ × ∇p)                        [оскільки ∇ × ∇p = 0 та ∇(1/ρ) = -∇ρ/ρ²]
= - (1 / ρ²) · (∇ρ × ∇p)
```

Підставляючи отримане підінтегральне значення назад у поверхневий інтеграл, отримуємо остаточну математичну формулювання **теореми Б'єркнеса**:

```
dΓ/dt = ∬[S(t)] (1 / ρ²) · (∇ρ × ∇p) · dA
```

Вектор `N = (1 / ρ²) · (∇ρ × ∇p)` називається бароклінним вектором або бароклінним моментом завихреності (англ. *baroclinic vector*). Він направлений перпендикулярно до площини, в якій перетинаються поверхні постійного тиску (ізобари, `p = const`) та поверхні постійної густини (ізопікни, `ρ = const`).

## Геометрична інтерпретація та соленоїди Б'єркнеса

Величина поверхневого інтеграла має наочний геометричний зміст. У двовимірному перетині атмосфери або океану лінії `p = const` та `ρ = const` утворюють сітку чотирикутників — так званих соленоїдів Б'єркнеса. 

Якщо ізобари проведені з однаковим інтервалом `Δp`, а ізопікни — з інтервалом `Δρ`, то число соленоїдів `N_s`, охоплених контуром `C(t)`, виражається сумою:

```
N_s = ∑ (Δp · Δρ / ρ²)
```

Швидкість виникнення циркуляції прямо пропорційна кількості цих соленоїдних комірок усередині контуру. Якщо поверхні ізобар та ізопікн паралельні між собою (`∇ρ ∥ ∇p`), векторний добуток дорівнює нулю (`∇ρ × ∇p = 0`), і середовище є локально баротропним. Якщо ж поверхні перетинаються під кутом, виникає горизонтальний градієнт густини при сталому тиску, який генерує замкнений вихровий рух.

Фізична причина цього явища полягає в різниці плавучості та інерції. Більш щільний об'єм рідини під дією одного й того самого градієнта тиску прискорюється повільніше, ніж сусідній менш щільний об'єм. Ця диспропорція прискорення породжує паралельні зсувні шари, які згортаються у вихрове кільце.

## Геофізичні застосування теореми Б'єркнеса

1. **Термічні бризи та гірсько-долинна циркуляція**: Нагрівання суші вдень створює горизонтальний градієнт температури. Оскільки ізобари залишаються майже горизонтальними під дією сили тяжіння, вектори `∇ρ` та `∇p` утворюють ненульовий векторний добуток, генеруючи денний морський бриз. Вночі суходіл охолоджується швидше за море, знак градієнта температури змінюється на протилежний, і теорема Б'єркнеса описує виникнення нічного берегового бризу.
2. **Океанічна термохалінна циркуляція**: В океанах густина води залежить як від температури `T`, так і від солоності `S`. Випаровування води або танення льодовиків створює горизонтальні градієнти солоності, які в поєднанні з вертикальним градієнтом гідростатичного тиску генерують глибоководні океанічні течії (наприклад, Гольфстрім та глобальний океанічний конвеєр).
3. **Зіркова конвекція та фронтогенез**: У надрах зірок та планетарних атмосфер бароклінна нестійкість розбиває однорідний обертальний рух на конвекційні комірки (комірки Бенара), генеруючи потужні магнітогідродинамічні вихори.

## Покроковий приклад: обчислення бризової циркуляції

Розглянемо прибережну зону океану в сонячний день. Суходіл нагрівається сонячним випромінюванням значно швидше за воду, створюючи сильну температурну асиметрію.

**Вихідні дані та геометрія системи:**
- Контур `C` у вертикальній площині: прямокутник висотою `H = 1000 м` та шириною `L = 20 000 м` (20 км).
- Нижній край контуру лежить на поверхні землі/океану (`y = 0`), верхній — на висоті `y = 1000 м`.
- Ліва половина контуру (`x = 0...10 км`) знаходиться над сушею (тепле повітря, `T_land = 300 K`).
- Права половина контуру (`x = 10...20 км`) знаходиться над морем (холодне повітря, `T_sea = 290 K`).
- Середній атмосферний тиск на поверхні: `p_0 = 101 325 Па`.
- Падіння тиску з висотою за барометричною формулою: `Δp = ρ_avg · g · H ≈ 1.2 · 9.81 · 1000 ≈ 11 772 Па`.
- Густина повітря над морем за рівнянням стану ідеального газу: `ρ_sea = p_0 / (R · T_sea) = 101325 / (287 · 290) = 1.218 кг/м³`.
- Густина повітря над сушею: `ρ_land = p_0 / (R · T_land) = 101325 / (287 · 300) = 1.177 кг/м³`.
- Різниця густини на поверхні: `Δρ = ρ_sea - ρ_land = 0.041 кг/м³`.
- Середня густина повітря: `ρ_avg = 1.197 кг/м³`.

Обчислимо бароклінний момент та швидкість зміни циркуляції за покроковим алгоритмом:

```
1. Оцінка горизонтального градієнта густини ∂ρ/∂x:
   ∂ρ/∂x ≈ (ρ_sea - ρ_land) / (L / 2)
         = (1.218 - 1.177) / 10000 
         = 4.1 · 10⁻⁶ кг/м⁴

2. Оцінка вертикального градієнта тиску ∂p/∂y:
   ∂p/∂y = - ρ_avg · g 
         = - 1.197 · 9.81 
         = - 11.74 Па/м

3. Модуль векторного добутку |∇ρ × ∇p| = (∂ρ/∂x) · (|∂p/∂y|):
   |∇ρ × ∇p| = (4.1 · 10⁻⁶) · (11.74) 
             = 4.81 · 10⁻⁵ Па · кг / м⁵

4. Значення бароклінного фактора N = (1 / ρ_avg²) · |∇ρ × ∇p|:
   N = (4.81 · 10⁻⁵) / (1.197²) 
     = (4.81 · 10⁻⁵) / 1.433 
     = 3.36 · 10⁻⁵ с⁻²

5. Площа контуру A = L · H:
   A = 20 000 м · 1000 м 
     = 2.0 · 10⁷ м²

6. Генерація циркуляції dΓ/dt = N · A:
   dΓ/dt = (3.36 · 10⁻⁵ с⁻²) · (2.0 · 10⁷ м²) 
         = 672 м²/с²
```

**Висновок та аналіз:**
Завдяки бароклінному ефекту в атмосфері щосекунди циркуляція швидкості контуру зростає на `672 м²/с²`. За один час (`t = 3600 с`) сумарна циркуляція досягла б `Γ ≈ 2.42 · 10⁶ м²/с`. Для прямокутного контуру це відповідає виникненню середньої швидкості морського бризу `u ≈ Γ / (2 · (L + H)) ≈ (2.42 · 10⁶) / 42 000 ≈ 57.6 м/с` у разі відсутності в'язкого тертя. У реальній атмосфері приземне тертя та турбулентна дисипація обмежують швидкість бризу до `5–10 м/с`, встановлюючи стаціонарний динамічний баланс між бароклінною генерацією за теоремою Б'єркнеса та в'язким розсіюванням завихреності.
