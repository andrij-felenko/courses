# 🧮 Виведення ємності AWGN-каналу та межі Шеннона -1.59 дБ

Математичний апарат теореми Шеннона — Гартлі встановлює строгий аналітичний зв'язок між смугою пропускання аналогового каналу, потужністю корисного сигналу, спектральною густиною потужності теплового шуму та максимальною швидкістю передачі дискретної інформації. Нижче наведено повне геометричне та теоретико-інформаційне виведення ємності для каналу з адитивним білим гаусовим шумом (AWGN), математичний аналіз явища концентрації міри у просторах високої розмірності, строге доведення прямої теореми та оберненої теореми кодування (нерівність Фано), матричний аналіз ентропії багатовимірних векторів та нерівність Адамара, аналітичне обчислення об'єму `n`-вимірних куль через інтеграли Гаусса та асимптотику Стірлінга, виведення правила розподілу потужності за методом водяного наповнення (Water-filling), аналіз експоненти випадкового кодування Галлагера, обчислення асимптотичної границі при необмеженому розширенні смуги та строге аналітичне виведення фундаментальної енергетичної межі Шеннона `-1.59 дБ`.

### 1. Простори сигналів та теорема відліків

Розгляньмо неперервний у часі сигнал `s(t)` тривалістю `T` секунд, спектр якого строго обмежений смугою частот від `0` до `B` герців (ідеальний низькочастотний канал). Згідно з класичною [теоремою відліків Найквіста](topic:com-transport/channel-band-packet), такий сигнал можна точно і без жодної втрати інформації відновити за його дискретними миттєвими значеннями, взятими з інтервалом `Δt = 1 / (2B)` секунд.

Загальна кількість незалежних дійсних відліків `n` за інтервал часу `T` становить:

```
n = T / Δt = 2 · B · T    [кількість ортогональних вимірів простору сигналів]
```

Ці `n` відліків утворюють координати вектора `x = (x₁, x₂, ..., xₙ)` у дійсній евклідовій системі координат `ℝⁿ`. Базисними функціями такого розкладу є зсунуті у часі функції відліків `sinc(2Bt - k) = sin(π(2Bt - k)) / (π(2Bt - k))`, які є взаємно ортогональними:

```
∫ sinc(2Bt - k) · sinc(2Bt - m) dt = (1 / (2B)) · δ_{km}    [ортогональність базису Найквіста]
```

Енергія переданого за час `T` сигналу виражається через інтеграл від квадрата амплітуди або через суму квадратів відліків завдяки рівності Парсеваля:

```
E_x = ∫ s²(t) dt = (1 / (2B)) · ∑ xᵢ²    [сумарна енергія сигналу за час T]
```

Середня потужність сигналу `P` дорівнює енергії, поділеній на тривалість `T`:

```
P = E_x / T = (1 / (2BT)) · ∑ xᵢ² = (1 / n) · ∑ xᵢ²    [середня потужність сигналу]
```

Таким чином, обмеження середньої потужності передавача `P` еквівалентне геометричному обмеженню на евклідову довжину вектора кодового слова `x`:

```
‖x‖² = ∑ xᵢ² ≤ n · P    [вектор кодового слова лежить усередині n-вимірної кулі]
```

### 2. Шумовий вектор та явище концентрації міри

У каналі зв'язку до переданого вектора `x` додається вектор незалежного білого гаусового шуму `z = (z₁, z₂, ..., zₙ)`. Кожна координата `zᵢ` є незалежною нормально розподіленою випадковою величиною з нульовим середнім і дисперсією `σ² = N = N₀ · B`:

```
zᵢ ~ N(0, σ²)
p(zᵢ) = (1 / √(2πσ²)) · exp( -zᵢ² / (2σ²) )    [густина ймовірності гаусового шуму]
```

Квадрат евклідової норми шумового вектора `‖z‖² = ∑ zᵢ²` являє собою суму `n` незалежних однаково розподілених випадкових величин. Згідно з теорією ймовірностей, величина `‖z‖² / σ²` має розподіл хі-квадрат (`χ²`) з `n` ступенями вільності.

Обчислимо математичне сподівання та дисперсію квадрата довжини вектора шуму:

```
E[‖z‖²] = E[ ∑ zᵢ² ] = ∑ E[zᵢ²] = n · σ² = n · N
Var(‖z‖²) = ∑ Var(zᵢ²) = n · ( E[zᵢ⁴] - (E[zᵢ²])² ) = n · ( 3σ⁴ - σ⁴ ) = 2n · σ⁴
```

Відносна флуктуація (відношення стандартного відхилення до математичного сподівання) довжини вектора шуму становить:

```
σ_{rel} = √(Var(‖z‖²)) / E[‖z‖²] = √(2n · σ⁴) / (n · σ²) = √(2 / n)
```

При збільшенні тривалості блоку `T → ∞` кількість вимірів `n = 2BT → ∞`, і відносна флуктуація прямує до нуля: `√(2 / n) → 0`. Це означає, що у просторі високої розмірності вектор гаусового шуму майже напевне має строго фіксовану довжину. Шум не розпорошується по всьому об'єму кулі, а з імовірністю, як завгодно близькою до одиниці, концентрується у надзвичайно тонкому сферичному шарі на відстані:

```
r_noise = √(n · N) = √(n · N₀ · B)    [радіус шумової сфери невизначеності]
```

### 3. Аналітичне обчислення об'єму n-вимірної кулі через інтеграли Гаусса та асимптотику Стірлінга

Для точного обчислення міри простору розгляньмо `n`-кратний інтеграл Гаусса за всім простором `ℝⁿ`:

```
I_n = ∫_{ℝⁿ} exp( -‖x‖² ) dx₁ dx₂ ... dxₙ
```

З одного боку, в декартових координатах цей інтеграл розпадається на добуток `n` незалежних одновимірних інтегралів Пуассона:

```
I_n = ( ∫_{-∞}^{∞} exp(-x²) dx )ⁿ = ( √π )ⁿ = π^(n / 2)
```

З іншого боку, переходячи до багатовимірних сферичних координат із радіусом `r = ‖x‖` та тілесним кутом `S_{n-1}`:

```
I_n = S_{n-1} · ∫₀^∞ rⁿ⁻¹ · exp(-r²) dr
```

Зробимо заміну змінної `u = r²`, тоді `du = 2r dr` або `rⁿ⁻¹ dr = (1/2) · u^(n/2 - 1) du`:

```
I_n = S_{n-1} · (1/2) · ∫₀^∞ u^(n/2 - 1) · exp(-u) du = S_{n-1} · (1/2) · Γ(n/2)
```

Прирівнюючи два вирази для `I_n`:

```
S_{n-1} · (1/2) · Γ(n/2) = π^(n/2)
S_{n-1} = ( 2 · π^(n/2) ) / Γ(n/2)    [площа поверхні одиничної n-вимірної сфери]
```

Об'єм `n`-вимірної кулі радіуса `R` отримуємо інтегруванням площ сферичних шарів від `0` до `R`:

```
Volₙ(R) = ∫₀ᴿ S_{n-1} · rⁿ⁻¹ dr = ( (2 · π^(n/2)) / Γ(n/2) ) · ( Rⁿ / n )
= ( π^(n/2) / ( (n/2) · Γ(n/2) ) ) · Rⁿ
= ( π^(n/2) / Γ(n/2 + 1) ) · Rⁿ    [об'єм n-вимірної кулі радіуса R]
```

За формулою Стірлінга для гамма-функції `Γ(k + 1) ≈ √(2πk) · (k / e)ᵏ` при `k = n / 2`:

```
Γ(n/2 + 1) ≈ √(πn) · ( n / (2e) )^(n / 2)
```

Підставляючи це наближення у формулу об'єму:

```
Volₙ(R) ≈ ( 1 / √(πn) ) · ( (2π e / n) )^(n / 2) · Rⁿ
(Volₙ(R))^(1 / n) ≈ R · √(2π e / n)    [асимптотичний радіус еквівалентного куба]
```

Цей результат безпосередньо пояснює появу множника `2π e` у формулі диференціальної ентропії гаусового процесу.

### 4. Геометричне пакування гіперсфер та виведення формули Шеннона

Прийнятий на стороні приймача вектор `y = x + z` є сумою корисного сигналу та шуму. Оскільки корисний сигнал і тепловий шум є статистично незалежними, їхні потужності додаються:

```
E[‖y‖²] = E[‖x + z‖²] = E[‖x‖²] + 2 · E[xᵀz] + E[‖z‖²]
= n · P + 0 + n · N = n · (P + N)    [сумарна енергія прийнятого вектора]
```

Усі можливі прийняті вектори `y` з імовірністю, близькою до одиниці, зосереджені всередині великої `n`-вимірної кулі радіуса:

```
R_tot = √(n · (P + N))    [радіус сфери прийнятих сигналів]
```

Навколо кожного переданого кодового слова `xₘ` формується шумова сфера радіуса `r_noise = √(n · N)`. Якщо дві шумові сфери, що відповідають різним повідомленням `x₁` та `x₂`, перетинаються, приймач не зможе однозначно визначити надіслане кодове слово при попаданні сигналу в зону перекриття. Щоб гарантувати безпомилкове декодування, кодові слова необхідно розмістити так, щоб їхні шумові сфери були взаємно неперетинними.

Максимально можлива кількість розрізнюваних кодових слів `M`, які можна розмістити всередині простору прийнятих сигналів без перекриття шумових сфер, обмежена відношенням об'ємів:

```
M ≤ Volₙ(R_tot) / Volₙ(r_noise)
M ≤ ( R_tot / r_noise )ⁿ
M ≤ ( √(n · (P + N)) / √(n · N) )ⁿ
M ≤ ( (P + N) / N )^(n / 2)
M ≤ ( 1 + P / N )^(n / 2)    [максимальне число кодових слів у блоці n відліків]
```

Кількість інформації `I` у бітах, що міститься у виборі одного з `M` рівноймовірних кодових слів, становить:

```
I = log₂(M)
= log₂( (1 + P / N)^(n / 2) )
= (n / 2) · log₂(1 + P / N)    [сумарна кількість бітів у блоці]
```

Підставивши вираз кількості ступенів вільності `n = 2 · B · T`, отримуємо:

```
I = ( (2 · B · T) / 2 ) · log₂(1 + P / N)
I = B · T · log₂(1 + P / N)    [кількість бітів за час передачі T]
```

Пропускна здатність каналу `C` — це максимальна кількість бітів, переданих за одиницю часу (`C = I / T`):

```
C = B · log₂(1 + P / N) = B · log₂(1 + SNR)    [теорема Шеннона — Гартлі, біт/с]
```

### 5. Теоретико-інформаційне виведення через диференціальну ентропію

Строге аналітичне виведення теореми спирається на апарат теорії інформації. Ємність неперервного каналу зв'язку `C` визначається як максимум взаємної інформації `I(X; Y)` між вхідним сигналом `X` та вихідним сигналом `Y` за всіма можливими розподілами ймовірностей входу `p(x)`, що задовольняють обмеження середньої потужності `E[X²] ≤ P`:

```
C = max_{p(x): E[X²]≤P} I(X; Y)    [визначення ємності за Шенноном]
```

Взаємна інформація виражається через диференціальні ентропії вихідного сигналу `h(Y)` та умовну ентропію шуму `h(Y | X)`:

```
I(X; Y) = h(Y) - h(Y | X)
```

Оскільки шум `Z` є адитивним і не залежить від корисного сигналу `X` (`Y = X + Z`), умовна ентропія дорівнює власній ентропії шуму:

```
h(Y | X) = h(X + Z | X) = h(Z | X) = h(Z)
```

Диференціальна ентропія одновимірного гаусового шуму з дисперсією `σ² = N` обчислюється через інтеграл:

```
h(Z) = - ∫ p(z) · log₂(p(z)) dz
= - ∫ p(z) · log₂( (1 / √(2πσ²)) · exp( -z² / (2σ²) ) ) dz
= - ∫ p(z) · ( - (1/2)·log₂(2πσ²) - (z² / (2σ²))·log₂(e) ) dz
= (1/2)·log₂(2πσ²) · ∫ p(z) dz + (log₂(e) / (2σ²)) · ∫ z² p(z) dz
= (1/2)·log₂(2πσ²) · 1 + (log₂(e) / (2σ²)) · σ²
= (1/2)·log₂(2πσ²) + (1/2)·log₂(e)
= (1/2)·log₂(2π e σ²) = (1/2)·log₂(2π e N)    [ентропія гаусового шуму]
```

Для максимізації взаємної інформації `I(X; Y) = h(Y) - (1/2)·log₂(2π e N)` необхідно максимізувати диференціальну ентропію вихідного сигналу `h(Y)`. За допомогою варіаційного числення доводиться, що при фіксованій дисперсії (потужності `E[Y²] = P + N`) максимальну диференціальну ентропію серед усіх можливих розподілів має саме **гаусовий розподіл**.

Максимальна ентропія виходу досягається тоді й лише тоді, коли вхідний сигнал `X` також має нормальний гаусовий розподіл `X ~ N(0, P)`:

```
h(Y)_max = (1/2)·log₂(2π e (P + N))    [максимальна ентропія виходу]
```

Підставивши значення максимальної ентропії, отримуємо пропускну здатність на один незалежний відлік:

```
C_sample = h(Y)_max - h(Z)
= (1/2)·log₂(2π e (P + N)) - (1/2)·log₂(2π e N)
= (1/2)·log₂( (2π e (P + N)) / (2π e N) )
= (1/2)·log₂( 1 + P / N )    [ємність на один відлік, біт/відлік]
```

Оскільки смуга `B` надає `2B` незалежних відліків за секунду, повна ємність каналу за одиницю часу дорівнює:

```
C = 2B · C_sample = 2B · (1/2) · log₂(1 + P / N) = B · log₂(1 + SNR) [біт/с]
```

### 6. Матрична диференціальна ентропія та нерівність Адамара

Для багатовимірного випадкового вектора `X = (X₁, ..., Xₙ)ᵀ` із коваріаційною матрицею `K_X = E[(X - μ)(X - μ)ᵀ]` диференціальна ентропія задовольняє матричну нерівність:

```
h(X) ≤ (1/2) · log₂( (2π e)ⁿ · det(K_X) )    [максимальна ентропія багатовимірного вектора]
```

Рівність досягається тоді й лише тоді, коли вектор `X` має багатовимірний спільний нормальний розподіл `X ~ N(μ, K_X)`.

Згідно з класичною нерівністю Жака Адамара для визначника симетричної додатно визначеної матриці:

```
det(K_X) ≤ ∏_{i=1}^{n} (K_X)_{ii} = ∏_{i=1}^{n} Var(Xᵢ)
```

Рівність у нерівності Адамара досягається тоді й тільки тоді, коли коваріаційна матриця `K_X` є строго діагональною. Це означає фундаментальну властивість багатовимірних каналів зв'язку: максимальна швидкість передачі досягається тоді, коли всі відліки та координати сигналу є взаємно незалежними і некорельованими. Якщо між відліками або антенами існує просторова чи часова кореляція, ефективна ємність падає, якщо не застосувати ортогоналізуюче перетворення Кархунена — Лоева чи сингулярний розклад (SVD).

### 7. Обернена теорема кодування: нерівність Фано

Важливою частиною теореми Шеннона є доведення неможливості передачі інформації зі швидкістю, що перевищує ємність каналу (`R > C`). Це доведення спирається на нерівність Роберта Фано.

Нехай повідомлення `M` рівноймовірно обирається з множини розміру `2^(nR)`. Приймач формує оцінку повідомлення `M̂` на основі прийнятої послідовності `Yⁿ`. Позначимо ймовірність помилки через `P_e = P(M̂ ≠ M)`.

Введемо бінарну випадкову величину помилки `E = 1`, якщо `M̂ ≠ M`, та `E = 0`, якщо `M̂ = M`. За правилом ланцюга для ентропії:

```
H(E, M | Yⁿ) = H(M | Yⁿ) + H(E | M, Yⁿ) = H(E | Yⁿ) + H(M | E, Yⁿ)
```

Оскільки `E` однозначно визначається парою `(M, Yⁿ)`, умовна ентропія `H(E | M, Yⁿ) = 0`. Крім того, бінарна ентропія `H(E | Yⁿ) ≤ H(E) = H_b(P_e) ≤ 1` біт.

Оцінимо доданок `H(M | E, Yⁿ)`:
- Якщо `E = 0` (помилки немає), `M = M̂(Yⁿ)` відомо однозначно, тому `H(M | E=0, Yⁿ) = 0`.
- Якщо `E = 1` (сталася помилка), правильне повідомлення `M` може бути будь-яким із решти `2^(nR) - 1` повідомлень, отже `H(M | E=1, Yⁿ) ≤ log₂(2^(nR) - 1) < n · R`.

Звідси отримуємо нерівність Фано:

```
H(M | Yⁿ) ≤ 1 + P_e · n · R    [нерівність Фано]
```

З іншого боку, за визначенням взаємної інформації:

```
n · R = H(M) = I(M; Yⁿ) + H(M | Yⁿ)
n · R ≤ I(Xⁿ; Yⁿ) + 1 + P_e · n · R    [за властивістю ланцюга обробки даних]
n · R ≤ n · C + 1 + P_e · n · R        [оскільки I(Xⁿ; Yⁿ) ≤ n · C для AWGN]
```

Поділивши обидві частини на `n · R` та згрупувавши доданки, отримуємо нижню оцінку ймовірності помилки:

```
P_e ≥ 1 - (C / R) - 1 / (n · R)    [нижня межа ймовірності помилки при R > C]
```

При збільшенні довжини кодового блоку `n → ∞` доданок `1 / (nR)` прямує до нуля:

```
P_e ≥ 1 - (C / R) > 0    (при R > C)
```

Це строго доводить, що при спробі передавати дані зі швидкістю `R > C` ймовірність помилки декодування принципово обмежена знизу додатною константою `1 - C/R` і не може бути усунена жодним збільшенням довжини кодового блоку чи ускладненням декодера.

### 8. Експонента випадкового кодування Галлагера

Для оцінки швидкості спадання ймовірності помилки при швидкостях нижче ємності (`R < C`) Роберт Галлагер вивів експоненційну верхню оцінку для середньої ймовірності помилки випадкового коду:

```
P_e ≤ exp( -n · E_r(R) )    [межа випадкового кодування Галлагера]
```

Де `E_r(R)` — експонента випадкового кодування, яка визначається як максимум за параметром `ρ ∈ [0, 1]`:

```
E_r(R) = max_{0 ≤ ρ ≤ 1} [ E₀(ρ) - ρ · R ]
```

Функція Галлагера `E₀(ρ)` для AWGN-каналу є монотонно зростаючою увігнутою функцією. При швидкості передачі `R → C` експонента помилки прямує до нуля `E_r(C) = 0`. При нульовій швидкості `R = 0` експонента досягає максимуму `E_r(0) = SNR / 4`.

Існує критична швидкість `R_{crit} = E₀'(1)`, нижче якої експонента `E_r(R)` залежить від швидкості лінійно:

```
E_r(R) = E₀(1) - R = 1 - log₂(1 + exp(-SNR / 2)) - R    (при R ≤ R_{crit})
```

Величина `R₀ = E₀(1)` називається **швидкістю зрізу** (англ. *cutoff rate*). Вона показує швидкість, до якої середня обчислювальна складність послідовного декодування залишається скінченною.

### 9. Оптимальний розподіл потужності: метод Water-Filling

Розгляньмо паралельний канал, що складається з `K` незалежних підканалів (наприклад, окремі піднесучі частоти в [OFDM](topic:com-modulation/ofdm) або підканали DSL), кожен з яких має свою смугу `B_k`, власний коефіцієнт передачі `|H_k|²` та власну потужність шуму `N_k = N_{0,k} · B_k`.

Сумарна ємність системи є сумою ємностей окремих підканалів:

```
C_total = ∑_{k=1}^{K} B_k · log₂( 1 + (P_k · |H_k|²) / N_k )
```

Завдання полягає в максимізації `C_total` за обмеження сумарної потужності передавача `∑ P_k = P` та умови невід'ємності потужностей на кожній піднесучій `P_k ≥ 0`.

Складемо функцію Лагранжа:

```
L(P₁, ..., P_K, λ) = ∑_{k=1}^{K} B_k · log₂( 1 + P_k / (N_k / |H_k|²) ) - λ · ( ∑_{k=1}^{K} P_k - P )
```

Введемо еквівалентний шумовий рівень підканалу `α_k = N_k / |H_k|²`. Візьмемо частинну похідну за потужністю `P_k`:

```
∂L / ∂P_k = (B_k / ln 2) · ( 1 / (P_k + α_k) ) - λ = 0
P_k + α_k = B_k / (λ · ln 2) = μ    [рівень водяного наповнення]
```

З урахуванням умови невід'ємності `P_k ≥ 0` розв'язок задачі Куна — Таккера набуває вигляду:

```
P_k = max( 0, μ - α_k ) = max( 0, μ - N_k / |H_k|² )    [правило водяного наповнення Water-Filling]
```

Константа `μ` («рівень води») знаходиться з рівняння сумарної потужності:

```
∑_{k=1}^{K} max( 0, μ - N_k / |H_k|² ) = P
```

Геометричний зміст методу: підканали з великим рівнем завад і згасання (`α_k ≥ μ`) взагалі не отримують потужності (`P_k = 0`) і вимикаються; у сприятливі підканали з малим згасанням заливається потужність `P_k = μ - α_k` так, щоб сумарний рівень сигналу й еквівалентного шуму `P_k + α_k` був строго однаковим для всіх активних каналів.

### 10. Асимптотична ємність при нескінченній ширині смуги (B → ∞)

Дослідимо поведінку ємності каналу при фіксованій потужності передавача `P` та необмеженому розширенні смуги пропускання `B → ∞`. Підставимо залежність потужності шуму від смуги `N = N₀ · B`:

```
C_∞ = lim_{B → ∞} B · log₂(1 + P / (N₀ · B))
```

Для розкриття невизначеності типу `∞ · 0` зробимо заміну змінної `u = P / (N₀ · B)`. При `B → ∞` параметр `u → 0`. Виразимо смугу через нову змінну: `B = P / (N₀ · u)`.

Підставимо у вираз границі:

```
C_∞
= lim_{u → 0} ( (P / (N₀ · u)) · log₂(1 + u) )
= (P / N₀) · lim_{u → 0} ( (1 / u) · log₂(1 + u) )     [винесення сталих величин]
= (P / N₀) · lim_{u → 0} log₂( (1 + u)^(1 / u) )      [властивість логарифма: a · log(x) = log(xᵃ)]
= (P / N₀) · log₂( lim_{u → 0} (1 + u)^(1 / u) )      [неперервність логарифмічної функції]
= (P / N₀) · log₂(e)                                   [друга чудова границя: lim (1+u)^(1/u) = e]
= (P / N₀) / ln(2)                                    [перехід від двійкового до натурального логарифма]
≈ 1.442695 · (P / N₀)                                 [гранична ємність каналу, біт/с]
```

Цей фундаментальний висновок показує, що навіть при нескінченній смузі частот ємність каналу залишається скінченною величиною, яка цілком визначається відношенням повної потужності сигналу до спектральної густини потужності шуму `P / N₀`.

### 11. Строге виведення абсолютної межі Шеннона (-1.59 дБ)

Нехай передавач витрачає енергію `E_b` на передачу одного корисного інформаційного біта. При швидкості передачі даних `R` біт за секунду середня потужність сигналу дорівнює:

```
P = R · E_b    [потужність передавача]
```

Для граничного випадку безпомилкового зв'язку покладемо швидкість рівною теоретичній ємності каналу: `R = C`. Тоді потужність сигналу становить `P = C · E_b`.

Підставимо цей вираз у формулу Шеннона — Гартлі:

```
C = B · log₂( 1 + (C · E_b) / (N₀ · B) )
```

Введемо безрозмірну величину спектральної ефективності `η = C / B` (вимірюється в біт/с/Гц):

```
η = log₂( 1 + η · (E_b / N₀) )
```

Розв'яжемо це трансцендентне рівняння відносно нормалізованого відношення енергії біта до густини шуму `E_b / N₀`:

```
2^η = 1 + η · (E_b / N₀)        [піднесення основи 2 до степеня обох частин]
2^η - 1 = η · (E_b / N₀)
E_b / N₀ = (2^η - 1) / η        [необхідне співвідношення Eb/N0 для досягнення ефективності η]
```

Щоб знайти абсолютний фізичний мінімум енергії, необхідний для передачі інформації, знайдемо границю функції при наближенні спектральної ефективності до нуля (`η → 0`), що відповідає переходу до нескінченної смуги (`B → ∞`):

```
(E_b / N₀)_min
= lim_{η → 0} (2^η - 1) / η
= lim_{η → 0} ( d/dη (2^η - 1) ) / ( d/dη (η) )    [правило Лопіталя для розкриття невизначеності 0/0]
= lim_{η → 0} ( 2^η · ln(2) ) / 1
= ln(2)                                             [абсолютний лінійний мінімум]
≈ 0.69314718056
```

Переведемо отримане безрозмірне відношення енергії до шуму в логарифмічний масштаб децибелів:

```
(E_b / N₀)_min [дБ]
= 10 · log₁₀( ln 2 )
= 10 · log₁₀( 0.69314718 )
= 10 · ( -0.1591749 )
≈ -1.5917 дБ ≈ -1.59 дБ
```

Отримана величина **`-1.59 дБ`** є абсолютною константою теорії інформації. Нижче цього енергетичного рівня надійна передача інформації неможлива в жодному середовищі з адитивним гаусовим шумом.

### 12. Спектральна ефективність та розрив Шеннона для QAM

У практичних системах з квадратурною амплітудною модуляцією `M-QAM` для підтримки заданої ймовірності бітової помилки `BER` необхідне відношення `SNR` перевищує теоретичну межу Шеннона. Цей розрив описується коефіцієнтом Гапа `Γ` (англ. *Shannon Gap*):

```
C_QAM = B · log₂( 1 + SNR / Γ )    [ємність дискретної модуляції з розривом Гапа]
```

Для прямокутного сузір'я `M-QAM` з ґраткою точок імовірність помилки на символ при адитивному гаусовому шумі оцінюється за допомогою `Q`-функції Гаусса:

```
P_s ≈ 4 · (1 - 1/√M) · Q( √( 3 · SNR_lin / (M - 1) ) )
```

Звідси коефіцієнт розриву Гапа `Γ` для незкодованої модуляції виражається через обернену `Q`-функцію від цільової ймовірності бітової помилки `BER`:

```
Γ = (1 / 3) · ( Q⁻¹(BER / 4) )²    [розрив Гапа для незкодованого M-QAM]
```

Для типових вимог надійності зв'язку `BER = 10⁻⁵` значення оберненої функції `Q⁻¹(2.5 · 10⁻⁶) ≈ 4.565`. Підставляючи це значення, отримуємо:

```
Γ ≈ (1 / 3) · (4.565)² ≈ (1 / 3) · 20.84 ≈ 6.95 ≈ 8.4 дБ
```

Використання завадостійких кодів (турбо-кодів, LDPC та полярних кодів) зменшує коефіцієнт розриву Гапа з початкових `8.4 дБ` до значень близько `0.5 – 1.8 дБ`, наближаючи швидкість передачі в сучасних стандартах Wi-Fi 7 та 5G практично впритул до абсолютної межі Шеннона.
