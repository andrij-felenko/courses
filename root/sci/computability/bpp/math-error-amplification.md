# 🧮 Ампліфікація помилки, межі Чернова та теорема Зіпсера — Ґачса — Лотемана

Математичний апарат класу BPP спирається на дві фундаментальні теореми: ампліфікацію ймовірності прийняття через нерівності концентрації міри (межа Чернова) та покриття простору випадкових послідовностей зсувами множин (доведення Лотемана для вкладення в Поліноміальну ієрархію). Ця вставка містить строгі алгебраїчні виведення обох принципів.

## 1. Концентрація міри: від Маркова та Чебишова до нерівності Чернова

Припустимо, що ми виконуємо `k` незалежних запусків ймовірнісного алгоритму, кожен з яких помиляється з імовірністю `p ≤ 1/3`. Нас цікавить імовірність того, що кількість помилок `S = X₁ + X₂ + ... + Xⴲ` перевищить поріг мажоритарного голосування `k / 2`.

Щоб зрозуміти, чому саме нерівність Чернова є ключовим інструментом теоретичної інформатики, порівняємо три фундаментальні нерівності теорії ймовірностей для оцінки хвоста розподілу суми випадкових величин.

Нерівність Маркова є найпростішою оцінкою, яка спирається лише на математичне сподівання випадкової величини. Для невід'ємної випадкової величини `S` із математичним сподіванням `E[S] = k · p ≤ k / 3` нерівність Маркова дає оцінку ймовірності перевищення порогу більшості:

```
P(S ≥ k / 2) ≤ E[S] / (k / 2) = (k / 3) / (k / 2) = 2/3
```

Головний недолік нерівності Маркова полягає у тому, що отримане значення `2/3` є сталою величиною і взагалі не залежить від кількості виконаних запусків `k`. Скільки б мільйонів незалежних випробувань ми не провели, нерівність Маркова залишається безпорадною для доведення ампліфікації, оскільки вона не враховує статистичну незалежність окремих монетних кидків.

Другим рівнем оцінювання є нерівність Чебишова, яка враховує дисперсію суми випадкових величин. Оскільки випробування є незалежними, дисперсія суми дорівнює сумі дисперсій окремих доданків `Var(S) = k · p · (1 - p) ≤ k / 4`. Застосувавши нерівність Чебишова для відхилення `S` від сподівання `k / 3` до порогу `k / 2` (відхилення `a = k / 6`), маємо:

```
P(|S - E[S]| ≥ k / 6) ≤ Var(S) / (k / 6)² ≤ (k / 4) / (k² / 36) = 9 / k
```

Нерівність Чебишова вже показує згасання помилки зі зростанням `k`, проте це згасання є лише **поліноміальним** `O(1 / k)`. Щоб зменшити імовірність помилки до криптографічного рівня `10⁻⁶`, за оцінкою Чебишова знадобилося б близько мільйона запусків `k ≈ 9 · 10⁶`. Це зробило б ампліфікацію надто повільною на практиці.

Справжній прорив забезпечує нерівність Чернова, яка аналізує не лише сподівання та дисперсію, а всі моменти розподілу через моментогенеруючу функцію `E[exp(t · S)]`. Це дозволяє довести експоненційне згасання помилки видавництва `exp(-c · k)`, де для досягнення помилки `10⁻⁶` достатньо лише кількох десятків повторень `k ≈ 100`.

### Повний алгебраїчний вивід нерівності Чернова

Розглянемо незалежні однаково розподілені бернулліївські випадкові величини `Xᵢ ∈ {0, 1}` із `P(Xᵢ = 1) = p`. Для суми `S = ∑ᵢ Xᵢ` маємо математичне сподівання `μ = E[S] = k · p`.

Застосуємо нерівність Маркова до моментогенеруючої функції `exp(t · S)` для довільного додатного параметра `t > 0`:

```
P(S ≥ (1 + δ) · μ)
= P(exp(t · S) ≥ exp(t · (1 + δ) · μ)) [монотонність експоненційного перетворення]
≤ E[exp(t · S)] / exp(t · (1 + δ) · μ)  [застосування нерівності Маркова]
```

Обчислимо моментогенеруючу функцію `E[exp(t · S)]` за завдяки незалежності випробувань:

```
E[exp(t · S)]
= E[exp(t · ∑ᵢ Xᵢ)]                     [розкриття суми у показникові]
= E[∏ᵢ exp(t · Xᵢ)]                     [властивість експоненти від суми]
= ∏ᵢ E[exp(t · Xᵢ)]                     [незалежність випадкових величин]
= ∏ᵢ (p · eᵗ + (1 - p))                 [обчислення сподівання для {0, 1}]
= (1 + p · (eᵗ - 1))ᵏ                   [групування доданків]
```

Скористаємося фундаментальною аналітичною нерівністю `1 + x ≤ eˣ`, яка виконується для всіх дійсних `x`. Поклавши `x = p · (eᵗ - 1)`:

```
1 + p · (eᵗ - 1) ≤ exp(p · (eᵗ - 1))
```

Підставивши це в моментогенеруючу функцію, отримаємо верхню межу:

```
E[exp(t · S)]
≤ (exp(p · (eᵗ - 1)))ᵏ
= exp(k · p · (eᵗ - 1))
= exp(μ · (eᵗ - 1))                      [підстановка μ = k · p]
```

Тепер об'єднаємо чисельник та знаменник у початковій нерівності:

```
P(S ≥ (1 + δ) · μ)
≤ exp(μ · (eᵗ - 1)) / exp(t · (1 + δ) · μ)
= exp(μ · (eᵗ - 1 - t · (1 + δ)))         [зведення показників експонент]
```

Отриманий вираз виконується для довільного `t > 0`. Щоб отримати найтіснішу оцінку, мінімізуємо цей вираз відносно `t`. Для цього знайдемо похідну від показника за `t` і прирівняємо її до нуля:

```
d/dt (eᵗ - 1 - t · (1 + δ)) = eᵗ - (1 + δ) = 0  ⇒  t = ln(1 + δ)
```

Підставимо оптимальне значення `t = ln(1 + δ)` назад у показник експоненти:

```
exp(μ · ((1 + δ) - 1 - (1 + δ) · ln(1 + δ)))
= exp(- μ · ((1 + δ) · ln(1 + δ) - δ))
```

Скориставшись наближенням Тейлора для розкладу дробової функції `g(δ) = (1 + δ) · ln(1 + δ) - δ`, доведемо, що для всіх `0 < δ ≤ 1` виконується оцінка `g(δ) ≥ δ² / 3`.

Підставивши цю нерівність, отримуємо остаточну мультиплікативну нерівність Чернова:

```
P(S ≥ (1 + δ) · μ) ≤ exp(- (μ · δ²) / 3)
```

Ця формула показує, що імовірність відхилення суми випадкових випробувань від свого математичного сподівання згасає експоненційно швидко від квадрата відхилення `δ²` та кількості випробувань `k`.

## 2. Ампліфікація поліноміально малого зазору

Розглянемо випадок, коли початковий зазор відокремлення є поліноміально малим `ε(n) = 1 / q(n)`, де `q(n)` — поліном від довжини входу. Тобто імовірність помилки алгоритму за один запуск дорівнює `p = 1/2 - 1/q(n)`.

Математичне сподівання кількості помилок у `k` незалежних запусків дорівнює:

```
μ = k · p = k · (1/2 - 1/q(n))
```

Поріг мажоритарного голосування відповідає кількості помилок `k / 2`. Визначимо відносне відхилення `δ` таке, що `(1 + δ) · μ = k / 2`:

```
(1 + δ) · k · (1/2 - 1/q(n)) = k / 2
(1 + δ) · (1 - 2/q(n)) = 1             [ділення обох частин на k/2]
1 + δ = 1 / (1 - 2/q(n))
```

Скористаємося розкладом у геометричну прогресію для малого малого параметра `1/q(n)`:

```
1 / (1 - 2/q(n)) ≈ 1 + 2/q(n)  ⇒  δ ≈ 2/q(n)
```

Підставимо отримані значення `μ ≈ k / 2` та `δ ≈ 2 / q(n)` у нерівність Чернова:

```
P(S ≥ k / 2)
≤ exp(- (μ · δ²) / 3)
≈ exp(- (k / 2) · (2/q(n))² / 3)       [підстановка значення μ]
= exp(- (k / 2) · (4 / q(n)²) / 3)
= exp(- 2 · k / (3 · q(n)²))
```

Щоб зробити імовірність підсумкової помилки меншою за експоненційно малу величину `2⁻ᵖ⁽ⁿ⁾`, підберемо необхідну кількість запусків `k`:

```
exp(- 2 · k / (3 · q(n)²)) ≤ exp(- p(n) · ln 2)
2 · k / (3 · q(n)²) ≥ p(n) · ln 2
k ≥ (3 / 2) · ln 2 · p(n) · q(n)²
```

Оскільки `p(n)` та `q(n)` є поліномами від довжини входу `n`, їхній добуток `k = O(p(n) · q(n)²)` також є **поліномом** від `n`. Це фундаментальне виведення доводить, що навіть слабкий ймовірнісний алгоритм із зазором `1/poly(n)` підсилюється до експоненційно високої надійності за поліноміальний час.

## 3. Теорема Адлемана: виведення існування фіксованого поліноміального порадника

Покажемо строго, як з експоненційного згасання помилки випливає вкладення `BPP ⊆ P/poly`.

Нехай мова `L ∈ BPP`. Візьмемо вхід `x` довжини `n`. За допомогою мажоритарного підсилення побудуємо алгоритм `M*`, який використовує `m = poly(n)` випадкових бітів і має імовірність помилки на кожному окремому вході:

```
P_r(M*(x, r) ≠ L(x)) ≤ 2⁻ⁿ⁻¹
```

Обчислимо сумарну імовірність того, що випадкова послідовність бітів `r ∈ {0, 1}ᵐ` виявиться «поганою» хоча б для одного з `2ⁿ` можливих входів довжини `n`. За застосуванням межі об'єднання (Union Bound) для ймовірностей:

```
P_r(∃ x ∈ {0, 1}ⁿ : M*(x, r) ≠ L(x))
≤ ∑_{x ∈ {0, 1}ⁿ} P_r(M*(x, r) ≠ L(x)) [межа об'єднання для 2ⁿ подій]
≤ ∑_{x ∈ {0, 1}ⁿ} 2⁻ⁿ⁻¹               [заміна імовірності кожного входу]
= 2ⁿ · 2⁻ⁿ⁻¹                          [сумування 2ⁿ доданків]
= 2⁻¹ = 1/2                            [спрощення показника степеня]
```

Оскільки імовірність того, що випадкова послідовність `r` є поганою хоча б для одного входу, становить лише `1/2 < 1`, звідси за імовірнісним методом Ердеша випливає:

```
P_r(∀ x ∈ {0, 1}ⁿ : M*(x, r) = L(x)) ≥ 1 - 1/2 = 1/2 > 0
```

Існує принаймні одна фіксована послідовність випадкових бітів `r* ∈ {0, 1}ᵐ`, для якої машина `M*(x, r*)` повертає абсолютно точну відповідь для **усіх** `2ⁿ` входів довжини `n` одночасно.

Ця послідовність `r*` використовується як поліноміальна порада (advice) для булевої схеми або нерівномірної машини Тюрінга, що доводить вкладення `BPP ⊆ P/poly`.

## 4. Доведення теореми Зіпсера — Ґачса — Лотемана: BPP у Поліноміальній ієрархії

Доведемо, що `BPP ⊆ Σ₂ᵖ`. Ідея Клеменса Лотемана полягає у визначенні множини «добрих» випадкових послідовностей і покритті усього простору випадкових бітів її побітовими зсувами (операцією XOR).

Нехай `m = poly(n)` — довжина випадкового вектора `r ∈ {0, 1}ᵐ`. Для входу `x` позначимо через `A_x ⊆ {0, 1}ᵐ}` множину тих випадкових векторів `r`, при яких машина `M` приймає вхід:

```
A_x = { r ∈ {0, 1}ᵐ | M(x, r) = 1 }
```

Завдяки ампліфікації вважатимемо, що:
- Якщо `x ∈ L`, то частка прийнятних векторів `|A_x| / 2ᵐ ≥ 1 - 2⁻ⁿ`.
- Якщо `x ∉ L`, то частка прийнятних векторів `|A_x| / 2ᵐ ≤ 2⁻ⁿ`.

Визначимо операцію зсуву множини `A_x` на вектор `u ∈ {0, 1}ᵐ}` через побітовий доданок за модулем 2 (операція XOR):

```
A_x ⊕ u = { r ⊕ u | r ∈ A_x }
```

Оскільки побітовий XOR є бієктивним відображенням простору `{0, 1}ᵐ` на себе, розмір зсунутої множини строго зберігається: `|A_x ⊕ u| = |A_x|`.

Розглянемо об'єднання `k` зсувів множини `A_x` для наборів векторів `U = (u₁, u₂, ..., uⴲ)`:

```
S_U = ⋃ᵢ₌₁ᵏ (A_x ⊕ uᵢ)
```

Встановимо кількість векторів зсуву `k = ⌈m / n⌉ + 1 = poly(n)`.

**Випадок 1: `x ∈ L`.**
Обчислимо імовірність того, що конкретний вектор `r` не потрапить до об'єднання `S_U` для випадково вибраного набору зсувів `U`:

```
P_U(r ∉ S_U)
= ∏ᵢ₌₁ᵏ P_{uᵢ}(r ∉ A_x ⊕ uᵢ)   [незалежність вибору векторів uᵢ]
= ∏ᵢ₌₁ᵏ P_{uᵢ}(r ⊕ uᵢ ∉ A_x)   [еквівалентність зсуву]
≤ ∏ᵢ₌₁ᵏ 2⁻ⁿ                    [оцінка розміру доповнення A_x]
= (2⁻ⁿ)ᵏ                       [добуток k однакових множників]
= 2⁻ⁿᵏ                         [властивість степенів]
```

Оскільки `n · k > m`, загальна кількість векторів `r`, не покритих об'єднанням, за межею об'єднання становить:

```
E_U[|{0, 1}ᵐ \ S_U|]
≤ 2ᵐ · 2⁻ⁿᵏ                   [множення на розмір простору 2ᵐ]
= 2ᵐ⁻ⁿᵏ < 1                    [оскільки n · k > m]
```

Якщо математичне сподівання кількості непокритих елементів менше 1, то за імовірнісним методом існує хоча б один набір зсувів `U`, який повністю покриває весь простір `{0, 1}ᵐ`:

```
∃ U = (u₁, ..., uⴲ) : ⋃ᵢ₌₁ᵏ (A_x ⊕ uᵢ) = {0, 1}ᵐ
```

**Випадок 2: `x ∉ L`.**
Розмір об'єднання `k` зсувів за нерівністю Буля обмежений сумою розмірів окремих зсунутих множин:

```
|S_U|
= |⋃ᵢ₌₁ᵏ (A_x ⊕ uᵢ)|
≤ ∑ᵢ₌₁ᵏ |A_x ⊕ uᵢ|            [сума розмірів множин]
= k · |A_x|                    [інваріантність розміру при зсуві]
≤ k · (2⁻ⁿ · 2ᵐ)               [оцінка малого розміру A_x]
= k · 2ᵐ⁻ⁿ                      [спрощення виразу]
```

Для достатньо великих `n` число `k · 2ᵐ⁻ⁿ < 2ᵐ`. Сумарна площа покриття строго менша за повний простір `{0, 1}ᵐ`, тому **жоден** набір зсувів `U` не здатний покрити весь простір.

**Підсумок доведення:**
Умова належності `x ∈ L` еквівалентна предикату другого рівня поліноміальної ієрархії:

```
x ∈ L  ⇔  ∃ U=(u₁,...,uⴲ)  ∀ r∈{0,1}ᵐ  ∃ i∈{1,...,k} : M(x, r ⊕ uᵢ) = 1
```

Квантори задовольняють структуру `∃ U ∀ r`, що за означенням відповідає класу `Σ₂ᵖ`. З огляду на замкненість BPP відносно доповнення, `BPP = coBPP ⊆ Π₂ᵖ`, що завершує доведення:

```
BPP ⊆ Σ₂ᵖ ∩ Π₂ᵖ
```
