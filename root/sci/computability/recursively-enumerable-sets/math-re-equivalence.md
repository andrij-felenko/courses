# 🧮 Еквівалентність означень та математичні властивості RE-множин

Ця вставка містить строгі математичні доведення еквівалентності чотирьох фундаментальних означень рекурсивно перелічних (RE) множин, детальний вивід теореми Поста про зв'язок розв'язності з напіврозв'язністю, а також аналіз алгебраїчних властивостей замкненості класу RE відносно множинних операцій та аналіз роль функцій спарювання і теореми Кліні про нормальну форму.

## 1. Чотири математичні еквівалентні означення

Нехай `ℕ = {0, 1, 2, 3, ...}` — множина натуральних чисел (або алфавіти скінченних рядків `Σ*`, які є бієктивно ізоморфними `ℕ` за допомогою кодування Ґеделя).

Підмножина `S ⊆ ℕ` називається **рекурсивно перелічною (RE)**, якщо вона задовольняє будь-яке з наступних чотирьох еквівалентних екзистенційних чи обчислювальних означень:

### Означення 1 (Область визначення частково обчислюваної функції)
Множина `S` є областю визначення деякої частково обчислюваної (частково рекурсивної) функції `φ[e]: ℕ → ℕ`:

```
S = dom(φₑ) = { x ∈ ℕ  ∣  φₑ(x) ↓ }
```

Позначення `φ[e](x) ↓` означає, що програма з номером `e` (у деякій стандартній геделівській нумерації всіх програм) зупиняється на вхідному значенні `x` і видає деякий вихідний результат. Якщо програма зациклюється, ми пишемо `φ[e](x) ↑`, і це значення не належить області визначення `dom(φ[e])`.

### Означення 2 (Область значень загально обчислюваної функції)
Множина `S` є або порожньою (`S = ∅`), або є областю значень (образом) деякої скрізь визначеної (загально рекурсивної) обчислюваної функції `g: ℕ → ℕ`:

```
S = img(g) = { g(n)  ∣  n ∈ ℕ }
```

Функція `g` ефективно «вираховує» або «друкує» елементи `S` по одному: `g(0), g(1), g(2), ...` При цьому елементи у цьому списку можуть повторюватися довільну кількість разів, але жодне число, яке не належить `S`, у список не потрапляє, і кожне число з `S` з'являється принаймні один раз для деякого індексу `n`.

### Означення 3 (Проекція розв'язного відношення / Σ₁⁰-представлення)
Множина `S` є проекцією деякого двомісного повністю розв'язного (рекурсивного) відношення `R ⊆ ℕ × ℕ`:

```
x ∈ S  ⇔  ∃ y ∈ ℕ : R(x, y) = 1
```

де предикат `R(x, y)` є обчислювальним за скінченний час для довільної пари чисел `(x, y)`. Число `y` у цій формулі називається **свідком** (англ. *witness*) або **сертифікатом** того, що число `x` належить множині `S`. Перевірка свідоцтва є механічною і швидкою, проте сам пошук свідоцтва вимагає перебору нескінченної множини натуральних чисел.

### Означення 4 (Мова, що розпізнається машиною Тюрінга)
Існує детермінована або недетермінована машина Тюрінга `M` така, що множина `S` збігається з мовою `L(M)`, яку машина приймає: `x ∈ S` тоді й лише тоді, коли `M` на вхідному слові `x` переходить у фінальний стан прийняття за скінченну кількість кроків. Для вхідних слів, що не належать `S`, машина `M` може або зупинитися у стані відмови, або працювати нескінченно довго.

## 2. Кодування та алгебраїчний апарат: Кантор і Кліні

Перед доведенням еквівалентності розберемо два фундаментальні математичні інструменти, на яких тримаються строгі конструкції теорії алгоритмів.

### 2.1 Канторівська функція спарювання
Для зведення двовимірних переборів до одного виміру використовують бієкцію Кантора `⟨x, y⟩: ℕ × ℕ → ℕ`. Вона нумерує пари натуральних чисел уздовж діагоналей 2D-сітки:

```
⟨x, y⟩ = ( (x + y) · (x + y + 1) / 2 ) + y
```

Ця функція є строго бієктивною, строго монотонною та повністю обчислюваною. Існують зворотно обчислювані проекції `π₁(z)` та `π₂(z)` такі, що для будь-якого `z ∈ ℕ` виконується:

```
⟨ π₁(z), π₂(z) ⟩ = z
π₁( ⟨x, y⟩ ) = x
π₂( ⟨x, y⟩ ) = y
```

Завдяки функціям `π₁` та `π₂` ми можемо розглядати один параметр `z` як вказівник на конкретну пару `(x, y)`, де `x` кодує вхідні дані, а `y` — обмеження на кількість кроків або обчислювальний трасувальний протокол.

### 2.2 Теорема Кліні про нормальну форму та T-предикат
Стівен Кліні довів, що існує примітивно рекурсивний тримісний предикат `T(e, x, y)` (названий `T`-предикатом Кліні) та примітивно рекурсивна функція видобутку результату `U(y)` такі, що:
1. `T(e, x, y) = 1` тоді й лише тоді, коли програма з номером `e` на вході `x` здійснює обчислення, чий повний протокол (код виконання кроків) описується числом `y`.
2. Якщо таке `y` існує, то функція `U(y)` видобуває остаточне числове значення, яке повернула програма `e`.

Таким чином, будь-яку часткову рекурсивну функцію `φ[e](x)` можна подати у нормальній формі Кліні:

```
φₑ(x) = U( μy T(e, x, y) )
```

де `μy` позначує оператор найменшого числа (оператор мінімізації): «знайти найменше `y`, для якого `T(e, x, y) = 1`». Якщо таке `y` існує, оператор повертає його; якщо ні — обчислення не зупиняється (`φ[e](x) ↑`).

## 3. Строге доведення еквівалентності (1 ⇔ 2 ⇔ 3 ⇔ 4)

Щоб довести еквівалентність усіх чотирьох означень, побудуємо замкнене коло імплікацій:

```
(1) ⇒ (3) ⇒ (2) ⇒ (1)   та   (1) ⇔ (4)
```

### Крок 1: Доведення (1) ⇒ (3)
Припустимо, що `S = dom(φ[e])`. Скориставшись `T`-предикатом Кліні, визначимо двомісне відношення `R(x, y)`:

```
R(x, y) = T(e, x, y)
```

Оскільки `T`-предикат Кліні перевіряє скінченну послідовність конфігурацій машини Тюрінга, відношення `R(x, y)` є повністю розв'язним (примітивно рекурсивним). Предикат `R(x, y) = 1` стверджує, що `y` є повним кодом зупиненого обчислення програми `e` на вході `x`.

Аналізуємо приналежність до `S`:

```
x ∈ S
⇔ φₑ(x) ↓                               [за означенням (1)]
⇔ ∃ y ∈ ℕ (y є кодом зупиненого обчислення програми e на вході x)
⇔ ∃ y ∈ ℕ : T(e, x, y) = 1              [за теоремою Кліні]
⇔ ∃ y ∈ ℕ : R(x, y) = 1                 [за побудовою R]
```

Це точно відповідає Означенню 3: множина `S` є проекцією розв'язного відношення `R`.

---

### Крок 2: Доведення (3) ⇒ (2)
Припустимо, що `x ∈ S ⇔ ∃ y R(x, y)`, де `R` — повністю розв'язний предикат. Якщо `S = ∅`, Означення 2 виконується тривіально. Розглянемо випадок, коли `S ≠ ∅`. Оскільки множина непорожня, існує принаймні один елемент `s₀ ∈ S`.

За допомогою канторівської функції декодування `z ↦ (π₁(z), π₂(z))` побудуємо функцію `g(z): ℕ → ℕ`:

```
g(z) = π₁(z),  якщо R(π₁(z), π₂(z)) = 1
g(z) = s₀,     якщо R(π₁(z), π₂(z)) = 0
```

Доведемо, що побудована функція `g(z)` задовольняє обидві вимоги Означення 2:

1. **Загальна обчислюваність (скрізь визначеність):** Для довільного вхідного числа `z ∈ ℕ` алгоритм спочатку обчислює `x = π₁(z)` та `y = π₂(z)`. Цей крок вимагає базових арифметичних операцій і завжди зупиняється. Далі алгоритм запускає вирішувач для предикату `R(x, y)`. Оскільки `R` за умовою є повністю розв'язним, ця перевірка завжди завершується за скінченний час і повертає 1 або 0. Відповідно до цього значення `g(z)` видає либо `x`, либо `s₀`. Жодного зависання чи нескінченного циклу не виникає. Отже, функція `g` є загально рекурсивною (скрізь визначеною).

2. **Точний збіг образу `img(g)` із множиною `S`:**
   - **Доведення `img(g) ⊆ S`:** Візьмемо довільний елемент `v ∈ img(g)`. За означенням образу існує таке `z`, що `g(z) = v`. Розглянемо дві гілки конструкції `g(z)`:
     - Якщо спрацювала перша гілка, то `v = π₁(z)` і при цьому `R(π₁(z), π₂(z)) = 1`. Позначивши `y = π₂(z)`, маємо `R(v, y) = 1`. Отже, існує свідок `y`, що означає `v ∈ S`.
     - Якщо спрацювала друга гілка, то `v = s₀`. Але `s₀` за вибором початкового елемента належить `S`.
     В обох випадках `v ∈ S`, тобто `img(g) ⊆ S`.

   - **Доведення `S ⊆ img(g)`:** Візьмемо довільний елемент `x ∈ S`. За Означенням 3 існує свідок `y ∈ ℕ` такий, що `R(x, y) = 1`. Закодуємо цю пару у натуральне число `z = ⟨x, y⟩`. За властивостями канторівського кодування `π₁(z) = x` та `π₂(z) = y`. Обчислюємо значення `g(z)`: оскільки `R(π₁(z), π₂(z)) = R(x, y) = 1`, алгоритм обирає першу гілку й повертає `g(z) = π₁(z) = x`. Отже, елемент `x` має свій прообраз `z` під дією функції `g`, що означає `x ∈ img(g)`.

Оскільки обидва включення доведено, `S = img(g)`. Це завершує обґрунтування Означення 2.

---

### Крок 3: Доведення (2) ⇒ (1)
Припустимо, що `S = img(g)`, де `g: ℕ → ℕ` — загально рекурсивна скрізь визначена функція. Побудуємо часткову функцію `f(x): ℕ → ℕ` за допомогою лінійного перебору:

```
f(x) = найменше n ∈ ℕ таке, що g(n) = x
```

Формальний алгоритм обчислення значення `f(x)` виглядає так:

```
Алгоритм обчислення f(x):
  n = 0
  Повторювати безкінечно:
    val = g(n)                [обчислення завжди зупиняється, бо g загальна]
    Якщо val == x:
        Повернути n           [знайдено перший прообраз, зупинка]
    n = n + 1                 [перехід до наступного кандидата]
```

Проаналізуємо область визначення `dom(f)` побудованої функції `f`:
- Якщо `x ∈ S`, то за означенням образу `S = img(g)` існує принаймні одне число `n` таке, що `g(n) = x`. За принципом найменшого числа серед таких `n` існує найменше значення `n_min`. Алгоритм перевірить послідовно `n = 0, 1, ..., n_min - 1`, де кожного разу `g(n) ≠ x`, а на кроці `n_min` знайде `g(n_min) = x`, поверне `n_min` і зупиниться за скінченну кількість кроків. Отже, `f(x) ↓ ⇒ x ∈ dom(f)`.
- Якщо `x ∉ S`, то за означенням образу не існує жодного числа `n`, для якого `g(n) = x`. Алгоритм буде обчислювати `g(0), g(1), g(2), ...` послідовно. Кожна окрема перевірка `g(n) == x` даватиме хибу, і цикл жене `n` до нескінченності, ніколи не повертаючи значення. Отже, `f(x) ↑ ⇒ x ∉ dom(f)`.

Отже, `dom(f) = S`, що доводить Означення 1.

---

### Крок 4: Еквівалентність з екзистенційними моделями автоматів (1) ⇔ (4)
Означення 1 сформульовано мовою частково рекурсивних функцій, а Означення 4 — мовою машин Тюрінга. За тезисом Черча–Тюринга будь-яка частково рекурсивна функція `φ[e](x)` може бути реалізована детермінованою машиною Тюрінга `M[e]`, яка зупиняється в стані прийняття тоді й лише тоді, коли `φ[e](x) ↓`.

Для недетермінованих машин Тюрінга (NTM) еквівалентність зберігається: недетермінована машина приймає `x`, якщо існує хоча б одна гілка обчислень у дереві конфігурацій, яка веде до стану прийняття. Оскільки дерево конфігурацій має скінченний степінь розгалуження, його можна обійти в ширину (покроково) детермінованою машиною Тюрінга. Якщо приймаюча гілка існує, пошук в ширину знайде її за скінченну кількість кроків і зупиниться.

Це завершує повне математичне коло еквівалентностей:

```
(1) ⇔ (2) ⇔ (3) ⇔ (4)
```

## 4. Доведення теореми Поста (R = RE ∩ coRE)

Формально визначимо клас розв'язних множин `R` (рекурсивних) та клас ко-рекурсивно перелічних множин `coRE`:

```
R = { S ⊆ ℕ  ∣  існує скрізь визначена функція χ_S(x) : χ_S(x) = 1 якщо x ∈ S, і 0 якщо x ∉ S }
coRE = { S ⊆ ℕ  ∣  S̄ = ℕ \ S ∈ RE }
```

> **Теорема Поста:** Множина `S` є рекурсивною (розв'язною) тоді й лише тоді, коли як сама `S`, так і її доповнення `S̄` є рекурсивно перелічними:
> 
> ```
> S ∈ R  ⇔  S ∈ RE  ∧  S ∈ coRE
> ```

### Доведення в бік (пряма імплікація: S ∈ R ⇒ S ∈ RE ∧ S ∈ coRE)
Нехай `S ∈ R`. Це означає, що існує повністю розв'язний алгоритм-вирішувач `A(x)`, який для будь-якого `x ∈ ℕ` за скінченний час повертає 1 (якщо `x ∈ S`) або 0 (якщо `x ∉ S`).

Побудуємо алгоритм для напіввирішувача `M₁(x)` множини `S`:

```
Алгоритм M₁(x):
  res = A(x)
  Якщо res == 1:
      Повернути 1  [зупинка]
  Інакше:
      Повторювати безкінечно {} [зациклення]
```

Очевидно, `M₁(x)` зупиняється тоді й лише тоді, коли `x ∈ S`. Отже, `dom(M₁) = S`, що за Означенням 1 означає `S ∈ RE`.

Побудуємо алгоритм для напіввирішувача `M₂(x)` доповнення `S̄`:

```
Алгоритм M₂(x):
  res = A(x)
  Якщо res == 0:
      Повернути 1  [зупинка]
  Інакше:
      Повторювати безкінечно {} [зациклення]
```

Очевидно, `M₂(x)` зупиняється тоді й лише тоді, коли `x ∉ S` (тобто `x ∈ S̄`). Отже, `dom(M₂) = S̄`, що за Означенням 1 означає `S̄ ∈ RE`, тобто `S ∈ coRE`.

Таким чином, `S ∈ RE ∩ coRE`.

---

### Доведення в бік (зворотна імплікація: S ∈ RE ∧ S ∈ coRE ⇒ S ∈ R)
Нехай `S ∈ RE` та `S̄ ∈ RE`.
За Означенням 3 існують два повністю розв'язні предикати `R₁(x, y)` та `R₂(x, y)` такі, що:

```
x ∈ S   ⇔  ∃ y ∈ ℕ : R₁(x, y) = 1
x ∈ S̄   ⇔  ∃ y ∈ ℕ : R₂(x, y) = 1
```

Оскільки будь-яке число `x ∈ ℕ` за фундаментальним законом тотожності належить або `S`, або `S̄`, але ніколи обом множинам одночасно (бо `S ∩ S̄ = ∅`), для кожного `x` існує принаймні один свідок `y` такий, що виконується або `R₁(x, y) = 1`, або `R₂(x, y) = 1`.

Побудуємо повний вирішувач `χ_S(x)` шляхом паралельного перебору свідків `y`:

```
Алгоритм χ_S(x):
  y = 0
  Повторювати безкінечно:
    Якщо R₁(x, y) == 1:
        Повернути 1  [підтверджено x ∈ S]
    Якщо R₂(x, y) == 1:
        Повернути 0  [підтверджено x ∈ S̄, тобто x ∉ S]
    y = y + 1
```

**Аналіз гарантії зупинки:**
Оскільки `x ∈ S ∪ S̄ = ℕ`, шуканий свідок `y` існує для будь-якого входу `x`. Алгоритм перевіряє значення `y = 0, 1, 2, ...` послідовно. За скінченну кількість кроків `y_min = min { y ∣ R₁(x, y) = 1 ∨ R₂(x, y) = 1 }` алгоритм натрапить на перший істинний предикат, виконає відповідне повернення (1 або 0) і негайно припинить роботу.

Оскільки перевірка кожного окремого `y` є розв'язною, а свідок `y_min` існує завжди, алгоритм `χ_S(x)` повертає відповідь за скінченний час для кожного `x ∈ ℕ`. Отже, характеристична функція `χ_S` є загально обчислюваною, а множина `S` є рекурсивною (`S ∈ R`).

Теорему Поста доведено.

---

## 5. Алгебраїчні властивості замкненості класу RE

Клас рекурсивно перелічних множин RE володіє чіткими властивостями замкненості відносно основних операцій математичної логіки та теорії множин.

### 5.1 Замкненість відносно Об'єднання (A ∪ B)
> **Твердження:** Якщо `A ∈ RE` і `B ∈ RE`, то `(A ∪ B) ∈ RE`.

**Доведення:**
За Означенням 3 існують розв'язні предикати `R_A(x, y)` та `R_B(x, y)` такі, що:

```
x ∈ A  ⇔  ∃ y R_A(x, y)
x ∈ B  ⇔  ∃ z R_B(x, z)
```

Застосуємо функцію декодування пар Кантора `w ↦ (π₁(w), π₂(w))`. Тоді для об'єднання отримуємо:

```
x ∈ A ∪ B
⇔ (x ∈ A) ∨ (x ∈ B)
⇔ (∃ y R_A(x, y)) ∨ (∃ z R_B(x, z))
⇔ ∃ w : ( R_A(x, π₁(w)) = 1  ∨  R_B(x, π₂(w)) = 1 )
```

Визначимо новий двомісний предикат `R_U(x, w) = R_A(x, π₁(w)) ∨ R_B(x, π₂(w))`. Оскільки диз'юнкція двох повністю розв'язних предикатів є розв'язним предикатом, множина `A ∪ B` подана у формі Означення 3, а отже `(A ∪ B) ∈ RE`.

---

### 5.2 Замкненість відносно Перетину (A ∩ B)
> **Твердження:** Якщо `A ∈ RE` і `B ∈ RE`, то `(A ∩ B) ∈ RE`.

**Доведення:**
Аналогічно, скориставшись кодуванням пар свідків `w = ⟨y, z⟩`, для перетину отримуємо:

```
x ∈ A ∩ B
⇔ (x ∈ A) ∧ (x ∈ B)
⇔ (∃ y R_A(x, y)) ∧ (∃ z R_B(x, z))
⇔ ∃ w : ( R_A(x, π₁(w)) = 1  ∧  R_B(x, π₂(w)) = 1 )
```

Кон'юнкція двох розв'язних предикатів `R_I(x, w) = R_A(x, π₁(w)) ∧ R_B(x, π₂(w))` є розв'язним предикатом, тому `(A ∩ B) ∈ RE`.

---

### 5.3 Замкненість відносно образу та прообразу обчислюваної функції
> **Твердження:** Якщо `A ∈ RE` і `f: ℕ → ℕ` — загально обчислювана функція, то прообраз `f⁻¹(A) = { x ∣ f(x) ∈ A }` належить RE, а образ `f(A) = { f(x) ∣ x ∈ A }` належить RE.

**Доведення прообразу:**
За Означенням 3 маємо `x ∈ f⁻¹(A) ⇔ f(x) ∈ A ⇔ ∃ y R_A(f(x), y) = 1`. Оскільки функція `f` загально обчислювана, а `R_A` розв'язний, новий предикат `R'(x, y) = R_A(f(x), y)` є розв'язним, отже `f⁻¹(A) ∈ RE`.

**Доведення образу:**
Для образу `y ∈ f(A)` запишемо предикат існування прообразу `x` та його свідка `z`:

```
y ∈ f(A)
⇔ ∃ x (x ∈ A ∧ f(x) = y)
⇔ ∃ x ∃ z (R_A(x, z) = 1 ∧ f(x) = y)
⇔ ∃ w (R_A(π₁(w), π₂(w)) = 1  ∧  f(π₁(w)) = y)
```

Предикат у дужках є повністю розв'язним, отже `f(A) ∈ RE`.

---

### 5.4 Незаключеність відносно Доповнення (Незамещеність RE до булевої алгебри)
> **Теорема:** Клас RE **не є замкненим** відносно операції взяття доповнення `Ā = ℕ \ A`.

**Доведення від супротивного:**
Припустимо, що для довільної `A ∈ RE` її доповнення `Ā` також обов'язково належить RE.
Розглянемо універсальну множину проблеми зупинки `K = { e ∣ φ[e](e) ↓ }`.
Відомо, що `K ∈ RE` (її напіввирішувач просто симулює виконання `φ[e](e)`).
Якби клас RE був замкнений відносно доповнення, то доповнення `K̄ = { e ∣ φ[e](e) ↑ }` також належало б до RE.
Тоді за теоремою Поста маємо:

```
K ∈ RE  ∧  K̄ ∈ RE  ⇒  K ∈ R
```

Проте нерозв'язність проблеми зупинки `K ∉ R` доведена класичним діагональним методом Тюрінга. Отримали суперечність.
Отже, припущення хибне: клас RE **не замкнений** відносно доповнення, і множина `K̄` є прикладом множини, яка **не є рекурсивно перелічною** (`K̄ ∉ RE`).

### 5.5 Зв'язок із теоремою Райса та RE-повнотою

Окремим важливим наслідком алгебраїчної структури класу RE є теорема Райса (англ. *Rice's theorem*) для семантичних властивостей частково рекурсивних функцій. Вона стверджує, що будь-яка нетривіальна семантична властивість (тобто властивість поведінки `dom(φ[e])`, яка не є тотожно істинною чи тотожно хибною для всіх програм) є повністю нерозв'язною. Якщо ж ця властивість є рекурсивно перелічною, то за теоремою Райса–Шапіро вона мусить бути монотонною та компактною: підтвердження приналежності функції `φ[e]` до властивості має спиратися на скінченну кількість обчислених точок `(x, y)`. Будь-яка властивість, яка вимагає перевірки нескінченної кількості точок (наприклад, «чи є область визначення нескінченною»), залишає клас RE і піднімається вище за арифметичною ієрархією до класів `Π₁⁰` або `Σ₂⁰`.

Підсумкова таблиця операцій замкненості:

| Операція над множинами `A, B ∈ RE` | Замкненість класу RE | Механізм побудови |
| :--- | :--- | :--- |
| **Об'єднання** (`A ∪ B`) | **Так** | Паралельне виконання / Диз'юнкція кванторів |
| **Перетин** (`A ∩ B`) | **Так** | Послідовне виконання / Кон'юнкція кванторів |
| **Декартів добуток** (`A × B`) | **Так** | Кодування пар `⟨x, y⟩` |
| **Образ функції** `f(A)` | **Так** | Існування прообразу та свідка |
| **Прообраз функції** `f⁻¹(A)` | **Так** | Підстановка значення функції |
| **Доповнення** (`Ā`) | **НІ** | Порушується теоремою Поста для `K` |
