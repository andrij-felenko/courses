# 🧮 Математичний апарат ігор Артура — Мерліна: ампліфікація помилки, еквівалентність монет та колапс раундів

Цей математичний аналіз виводить імовірнісні міри повноти та обґрунтованості ігор Артура — Мерліна, деталізує алгоритм підсилення точності через паралельне повторення, розкриває конструкцію універсального хешування у теоремі Ґольдвассер — Зіпсера та будує формальний доказ колапсу поліноміальної ієрархії при виконанні включення `coNP ⊆ AM`.

## Формальні означення класів MA та AM

Класи складності `MA` (Merlin-Arthur) та `AM` (Arthur-Merlin) визначаються через мову `L ⊆ {0, 1}*` та імовірнісний верифікатор Артура `V`, який працює за детермінований поліномний час від довжини входу `n = |x|`.

Нехай `p(n)` та `q(n)` — поліноми від довжини входу `n`.
- `p(n)` задає довжину доказового повідомлення Мерліна `m ∈ {0, 1}^p(n)`.
- `q(n)` задає кількість випадкових бітів Артура `r ∈ {0, 1}^q(n)`.

### 1. Формальне означення класу MA
Мова `L` належить до класу `MA`, якщо існує детермінований поліноміальний верифікатор `V(x, m, r)`, для якого виконуються дві умови:

```
1. Повнота (Completeness):
   x ∈ L  ⇒  ∃ m ∈ {0, 1}^p(n) : Pr_r [ V(x, m, r) = 1 ] ≥ 2/3

2. Обґрунтованість (Soundness):
   x ∉ L  ⇒  ∀ m ∈ {0, 1}^p(n) : Pr_r [ V(x, m, r) = 1 ] ≤ 1/3
```

Тут ймовірність `Pr_r` обчислюється за рівномірним розподілом випадкового вектора монет Артура `r` у просторі `{0, 1}^q(n)`.

### 2. Формальне означення класу AM
Мова `L` належить до класу `AM` (або `AM[2]`), якщо порядок кванторів змінено: спочатку Артур публічно обирає `r`, а Мерлін відповідає `m(r)` залежно від знайомого йому `r`.

```
1. Повнота (Completeness):
   x ∈ L  ⇒  Pr_r [ ∃ m ∈ {0, 1}^p(n) : V(x, r, m) = 1 ] ≥ 2/3

2. Обґрунтованість (Soundness):
   x ∉ L  ⇒  Pr_r [ ∃ m ∈ {0, 1}^p(n) : V(x, r, m) = 1 ] ≤ 1/3
```

Змінивши порядок кванторів `Pr_r` та `∃ m`, клас `AM` дає Мерліну додаткову силу: Мерлін підбирає свідок `m` після того, як побачить конкретний вектор монет Артура `r`. Звідси очевидно випливає включення:

```
MA ⊆ AM
```

```
   Порівняння структурної квантифікації класів MA та AM
┌─────────┬───────────────────────────────────────────────────────────┐
│ Клас    │ Формальний порядок вибору монет та повідомлень            │
├─────────┼───────────────────────────────────────────────────────────┤
│ NP      │ ∃ m  : V(x, m) = 1                                        │
│ BPP     │ Pr_r [ V(x, r) = 1 ] ≥ 2/3                                │
│ MA      │ ∃ m  : Pr_r [ V(x, m, r) = 1 ] ≥ 2/3                      │
│ AM      │ Pr_r [ ∃ m : V(x, r, m) = 1 ] ≥ 2/3                       │
└─────────┴───────────────────────────────────────────────────────────┘
```

## Ампліфікація імовірності помилки (Error Reduction)

Стандартні константи повноти `c = 2/3` та обґрунтованості `s = 1/3` є довільними виборами. Їх можна зменшити до експоненціально малих величин `2^(-k(n))` для будь-якого полінома `k(n)` без збільшення кількості раундів.

### Пастка паралельного повторення у класі AM
Для класичного класу `BPP` зменшення помилки досягається незалежним повторенням протоколу `k` разів з подальшим голосуванням за більшістю (за межею Чернова).

У класі `AM` звичайне мажоритарне голосування для кожної ітерації окремо не працює прямолінійно, бо шкідливий Мерлін може адаптивно обирати відповіді `m₁, m₂, ..., m_k` залежно від усього набору викликів `(r₁, r₂, ..., r_k)`.

Для проведення адекватної ампліфікації в `AM` Артур обирає `k` незалежних випадкових векторів `r = (r₁, r₂, ..., r_k)` одночасно у першому раунді. Мерлін відповідає вектором `m = (m₁, m₂, ..., m_k)`. Артур приймає вхід тоді і тільки тоді, коли більшість (або всі) перевірок `V(x, r_i, m_i) = 1` успішні.

Аналіз обґрунтованості за нерівністю Чернова:

Нехай `S(r_i)` — множина викликів `r_i`, для яких існує приймаюча відповідь `m_i`. Якщо `x ∉ L`, то за означенням:

```
Pr [ r_i ∈ S ] ≤ 1/3
```

При паралельному підкиданні `k` монет вектор викликів `r = (r₁, ..., r_k)` належить до простору `{0, 1}^(k · q(n))`. Імовірність того, що Мерлін зможе знайти приймаючі відповіді для більше ніж `k/2` ітерацій, обмежується верхньою хвостовою межею біноміального розподілу:

```
Pr [ ∑ X_i ≥ k/2 ]
≤ exp( - 2 · k · (1/2 - 1/3)² )    [Нерівність Чернова / Гьоффдинга]
= exp( - 2 · k · (1/6)² )
= exp( - k / 18 )
```

Обираючи `k = 18 · p(n)`, ми отримуємо ймовірність помилки не більше `e^(-p(n)) < 2^(-p(n))`. Це гарантує, що ампліфікація помилки в `AM` досягається за один двораундовий обмін без додавання нових раундів.

## Математичний механізм теореми Ґольдвассер — Зіпсера (IP[k] ⊆ AM[k+2])

Ключова математична задача при переході від приватних монет до публічних — перетворення прихованої перевірки верифікатора на публічну довідність розміру множини.

Розглянемо випадок, коли Артур хоче перевірити, чи є множина приймаючих монет `S_x ⊆ {0, 1}^q` «великою» (розміру `|S_x| ≥ K`) чи «малою» (розміру `|S_x| ≤ K/2`).

Мерлін знає елементи множини `S_x`, але Артур не може довіряти Мерліну на слово. Для публічної довідності розміру `S_x` застосовується **протокол оцінки нижньої межі розміру множини** (Set Lower Bound Protocol) за допомогою сімейства 2-універсальних хеш-функцій.

### 2-універсальні хеш-функції
Сімейство функцій `H = { h : {0, 1}^q → {0, 1}^m }` називається 2-універсальним, якщо для будь-яких двох різних елементів `y₁, y₂ ∈ {0, 1}^q` та будь-яких двох значень `z₁, z₂ ∈ {0, 1}^m` виконується:

```
Pr_{h ∈ H} [ h(y₁) = z₁  ∧  h(y₂) = z₂ ] = 1 / 2^(2m)
```

### Протокол публічних монет для доведення |S_x| ≥ K:
1. Артур обирає випадкову хеш-функцію `h ∈ H` та випадковий рядок `z ∈ {0, 1}^m` (де `m ≈ log₂ K`) та відкриває їх Мерліну.
2. Мерлін знаходить елемент `y ∈ S_x` та надсилає його Артуру разом з доказом того, що `y ∈ S_x`.
3. Артур детерміновано перевіряє дві умови:
   - `y ∈ S_x` (тобто `V(x, y) = 1`);
   - `h(y) == z`.

```
          Виведення імовірностей покриття простору образів
   
   Позначимо Y = h(S_x). Якщо |S_x| ≥ K та m = log₂ K - 2:
   
   E[ |Y| ]
   = ∑_{z ∈ {0,1}^m} Pr [ ∃ y ∈ S_x : h(y) = z ]
   ≥ |S_x| / 2^m  -  |S_x|² / (2 · 2^(2m))       [Межа включення-виключення]
   = K / (K/4)  -  K² / (2 · (K/4)²)
   = 4 - 1/2  = 3.5  (значно перевищує щільність покриття)
```

Якщо `|S_x|` велика (`|S_x| ≥ K`), то з імовірністю, близькою до `1`, випадковий елемент `z` має прообраз у `S_x`. Якщо ж `|S_x|` мала (`|S_x| ≤ K/2`), то за нерівністю Маркова імовірність існування такого прообразу не перевищує `|S_x| / 2^m ≤ (K/2) / (K/4) = 1/2`.

Це математичне перетворення дозволяє перекласти будь-яку приватну перевірку на публічний виклик Артура `(h, z)`.

## Формальне доведення теореми про колапс ієрархії (coNP ⊆ AM ⇒ PH = Σ₂ᵖ)

Однозначно найважливішим теоретичним результатом для класу `AM` є теорема про обмеження його складності: якщо клас `coNP` міститься в `AM`, то поліноміальна ієрархія `PH` згортається до свого другого рівня `Σ₂ᵖ = Π₂ᵖ`.

> **Теорема (Boppana — Håstad — Zachos / Schöning).** Якщо `coNP ⊆ AM`, то `Σ₂ᵖ = Π₂ᵖ = PH`.

### Покрокове математичне доведення:

За означенням другого рівня поліноміальної ієрархії, будь-яка мова `L ∈ Σ₂ᵖ` виражається через детермінований поліноміальний предикат `R(x, y, z)` з двома кванторами:

```
x ∈ L  ⇔  ∃ y ∈ {0, 1}^p(|x|) : ∀ z ∈ {0, 1}^p(|x|) : R(x, y, z) = 1
```

Позначимо внутрішній квантор через мову `L_inner`:

```
L_inner = { (x, y) | ∀ z : R(x, y, z) = 1 }
```

Оскільки внутрішній предикат містить лише загальний квантор `∀ z`, мова `L_inner` за визначенням належить до класу `coNP`.

За умовою теореми `coNP ⊆ AM`. Отже, для мови `L_inner` існує двораундовий протокол Артура — Мерліна `(V_AM)` з високою точністю (ймовірність помилки менше `2^(-p(n))`), де Артур підкидає публічні монети `r`, Мерлін відповідає `w`, і Артур перевіряє `V_AM((x, y), r, w) = 1`.

Замінимо внутрішнє твердження `∀ z` на ймовірнісну перевірку `AM`:

```
x ∈ L
⇔ ∃ y : (x, y) ∈ L_inner
⇔ ∃ y : Pr_r [ ∃ w : V_AM((x, y), r, w) = 1 ] ≥ 1 - 2^(-p(n))
```

Оскільки ймовірність успіху за монетками `r` є експоненціально близькою до 1, за принципом заміна кванторів (Probabilistic Amplification & Swapping Quantifiers) ми можемо винести квантор за `r` назовні:

```
x ∈ L
⇔ Pr_r [ ∃ y , ∃ w : V_AM((x, y), r, w) = 1 ] ≥ 2/3
```

Оскільки квантори `∃ y` та `∃ w` є сусідніми існувальними кванторами, їх можна об'єднати в один квантор `∃ (y, w)`.

Отриманий вираз:

```
Pr_r [ ∃ (y, w) : V_AM((x, y), r, w) = 1 ] ≥ 2/3
```

це за точною формою є предикатом мови з класу `BP · NP`, який міститься в `Π₂ᵖ`.

Оскільки ми виразили довільну мову `L ∈ Σ₂ᵖ` через предикат з класу `Π₂ᵖ`, це означає, що:

```
Σ₂ᵖ ⊆ Π₂ᵖ
```

За симетрією це тягне за собою повний колапс поліноміальної ієрархії:

```
Σ₂ᵖ = Π₂ᵖ = PH
```

Цей математичний результат є фундаментальним інструментом доведення того, що задачі з класу `AM` (такі як неізоморфізм графів `GNI`) малоймовірно є `NP`-повними, оскільки їх `NP`-повнота призвела б до небажаного катастрофічного колапсу усієї поліноміальної ієрархії.
