# 🧮 Доведення бієктивності, єдиності та аналітичної оборотності парної функції Кантора

Зіставлення пари дискретних величин `(x, y)` з єдиним скалярним числом `z` є коректним лише тоді, коли відображення зберігає всю інформацію без втрат і спотворень. Це означає, що кодувальне правило повинно бути **бієкцією** (взаємно однозначним відображенням): різним парам координат мають відповідати строго різні коди (ін'єктивність), а кожне натуральне число без винятку має бути кодом деякої пари (сюр'єктивність). Нижче наведено повне формальне доведення бієктивності парної функції Кантора, виведення її точних аналітичних формул декодування, дослідження монотонності, аналіз теореми Футера — Полі про єдиність квадратичного полінома спарювання, розширення на цілі числа `ℤ × ℤ`, зв'язок зі зліченністю раціональних чисел `ℚ`, теоретико-категорний контекст, зв'язок з адитивною теорією трикутних чисел, примітивну рекурсивність у формальній арифметиці та порівняння з кусково-поліноміальним спарюванням Шудзіка.

---

### 1. Формальне означення та допоміжні леми

Нехай `ℕ₀ = {0, 1, 2, 3, ...}` — множина невід'ємних цілих чисел. **Парна функція Кантора** `π: ℕ₀ × ℕ₀ → ℕ₀` задається аналітичною формулою:

```
π(x, y) = ((x + y) · (x + y + 1)) / 2 + y
```

Для спрощення позначень уведемо величину `w = x + y`, яка відповідає індексу діагоналі в цілочисельній координатній сітці, та функцію **трикутного числа** `T: ℕ₀ → ℕ₀`:

```
T(w) = (w · (w + 1)) / 2 = 0 + 1 + 2 + ... + w
```

Тоді формула функції Кантора набуває компактного вигляду:

```
π(x, y) = T(w) + y,    де w = x + y
```

#### Лема 1 (Строга монотонність трикутних чисел)
Для будь-яких цілих чисел `w₁, w₂ ∈ ℕ₀`:
```
w₁ < w₂  ⇒  T(w₁) < T(w₂)
```

**Доведення:**
Розглянемо різницю між двома сусідніми трикутними числами:
```
T(w + 1) - T(w)
= ((w + 1)(w + 2)) / 2 - (w(w + 1)) / 2    [за означенням трикутного числа T]
= (w + 1) · (w + 2 - w) / 2                [винесення спільного множника (w+1)]
= (w + 1) · 2 / 2                          [спрощення різниці в дужках]
= w + 1                                    [скорочення на 2]
```
Оскільки для будь-якого `w ∈ ℕ₀` виконується `w ≥ 0`, маємо `w + 1 ≥ 1 > 0`. Отже, `T(w + 1) - T(w) > 0`, звідки `T(w + 1) > T(w)`. За принципом математичної індукції, для довільних `w₁ < w₂` отримуємо `T(w₁) < T(w₂)`. Лему доведено.

#### Лема 2 (Межі значень функції Кантора на фіксованій діагоналі)
Для будь-якої пари `(x, y) ∈ ℕ₀ × ℕ₀` з сумою `w = x + y` значення `π(x, y)` задовольняє подвійну нерівність:
```
T(w) ≤ π(x, y) < T(w + 1)
```

**Доведення:**
1. Оскільки `x, y ∈ ℕ₀`, то `y ≥ 0`. Додавши `T(w)` до обох частин нерівності `y ≥ 0`, отримуємо:
```
T(w) + y ≥ T(w) + 0
π(x, y) ≥ T(w)
```
Це доводить ліву частину нерівності (мінімум досягається у точці `(w, 0)`).

2. Оскільки `x ≥ 0`, то `w = x + y ≥ 0 + y = y`, тобто `y ≤ w < w + 1`. З цього випливає:
```
y ≤ w
T(w) + y ≤ T(w) + w
π(x, y) ≤ T(w) + w
```
3. Застосуємо результат Леми 1 про зв'язок між сусідніми трикутними числами: `T(w + 1) = T(w) + w + 1`. Тоді:
```
π(x, y) ≤ T(w) + w < T(w) + w + 1 = T(w + 1)
π(x, y) < T(w + 1)
```
Це доводить праву частину нерівності (максимум на діагоналі досягається у точці `(0, w)` і дорівнює `T(w) + w = T(w + 1) - 1`). Лему 2 повністю доведено.

З Леми 2 випливає фундаментальний геометричний факт: **множина цілих чисел `ℕ₀` розбивається на попарно неперетинні напіввідкриті інтервали `I_w = [T(w), T(w + 1))` довжиною `w + 1`, кожен з яких містить рівно стільки елементів, скільки точок лежить на відповідній діагоналі `w`**.

#### Лема 3 (Покоординатна строга монотонність)
Функція `π(x, y)` є строго монотонно зростаючою за кожним аргументом окремо при фіксованому іншому:
```
π(x + 1, y) > π(x, y)
π(x, y + 1) > π(x, y)
```

**Доведення:**
1. Розглянемо приріст за координатою `x`:
```
π(x + 1, y) - π(x, y)
= [T(x + 1 + y) + y] - [T(x + y) + y]
= T(w + 1) - T(w)
= w + 1 = x + y + 1 ≥ 1 > 0
```
Отже, `π(x + 1, y) ≥ π(x, y) + 1 > π(x, y)`.

2. Розглянемо приріст за координатою `y`:
```
π(x, y + 1) - π(x, y)
= [T(x + y + 1) + y + 1] - [T(x + y) + y]
= [T(w + 1) - T(w)] + 1
= (w + 1) + 1 = w + 2 = x + y + 2 ≥ 2 > 0
```
Отже, `π(x, y + 1) ≥ π(x, y) + 2 > π(x, y)`. Покоординатну монотонність доведено.

#### Лема 4 (Нижні та верхні квадратичні оцінки)
Для будь-яких `x, y ∈ ℕ₀`:
```
1. π(x, y) ≥ x
2. π(x, y) ≥ y
3. π(x, y) ≥ (x + y)² / 2
```

**Доведення:**
1. Якщо `y > 0`, то `π(x, y) = T(x + y) + y ≥ y`. Якщо `y = 0`, то `π(x, 0) = T(x) = x(x + 1)/2 ≥ x` для всіх `x ≥ 1`, а для `x = 0` маємо `0 = 0`. Отже, `π(x, y) ≥ y` та `π(x, y) ≥ x`.
2. Оскільки `(x + y + 1) > (x + y)`, то `T(x + y) = (x + y)(x + y + 1)/2 > (x + y)² / 2`. Додавання `y ≥ 0` лише посилює нерівність: `π(x, y) ≥ (x + y)² / 2`.

### 2. Доведення теореми про ін'єктивність

#### Теорема 1 (Ін'єктивність функції Кантора)
Якщо для двох пар `(x₁, y₁), (x₂, y₂) ∈ ℕ₀ × ℕ₀` виконується рівність:
```
π(x₁, y₁) = π(x₂, y₂)
```
то `x₁ = x₂` та `y₁ = y₂`.

**Доведення:**
Позначимо `w₁ = x₁ + y₁`, `w₂ = x₂ + y₂` та `z = π(x₁, y₁) = π(x₂, y₂)`.
Припустимо від супротивного, що `w₁ ≠ w₂`. Без обмеження загальності нехай `w₁ < w₂`.
Оскільки `w₁` та `w₂` — цілі невід'ємні числа, то з `w₁ < w₂` випливає `w₁ + 1 ≤ w₂`.

Застосуємо Лему 2 до першої пари `(x₁, y₁)`:
```
z = π(x₁, y₁) < T(w₁ + 1)
```
Застосуємо Лему 2 та Лему 1 до другої пари `(x₂, y₂)`:
```
z = π(x₂, y₂) ≥ T(w₂) ≥ T(w₁ + 1)
```
Об'єднуючи отримані нерівності, маємо:
```
z < T(w₁ + 1) ≤ z
```
Отримали строгу суперечність `z < z`. Отже, наше припущення про нерівність сум координат було хибним, і `w₁ = w₂ = w`.

Тепер підставимо рівність `w₁ = w₂ = w` у вихідну рівність значень функції:
```
π(x₁, y₁) = π(x₂, y₂)
T(w) + y₁ = T(w) + y₂
```
Віднімемо ціле число `T(w)` від обох частин рівності:
```
y₁ = y₂
```
Оскільки `w = x₁ + y₁ = x₂ + y₂` і `y₁ = y₂`, віднімемо `y₁` від обох частин:
```
x₁ = w - y₁ = w - y₂ = x₂
x₁ = x₂
```
Таким чином, рівність значень функції `π(x₁, y₁) = π(x₂, y₂)` тягне за собою повну рівність координат `x₁ = x₂` та `y₁ = y₂`. Ін'єктивність повністю доведено.

### 3. Доведення теореми про сюр'єктивність та конструктивне декодування

#### Теорема 2 (Сюр'єктивність та точне аналітичне декодування)
Для будь-якого натурального числа `z ∈ ℕ₀` існує єдина пара `(x, y) ∈ ℕ₀ × ℕ₀`, така що `π(x, y) = z`.

**Доведення:**
Щоб довести існування та знайти явні алгебраїчні формули для `x` та `y`, розв'яжемо задачу знаходження номера діагоналі `w` за заданим числом `z`.

Згідно з Лемою 2, число `z` потрапляє у діагональ `w` тоді й лише тоді, коли воно належить інтервалу `[T(w), T(w + 1))`:
```
T(w) ≤ z < T(w + 1)
(w · (w + 1)) / 2 ≤ z < ((w + 1) · (w + 2)) / 2
```
Помножимо обидві частини нерівності на 8:
```
4w(w + 1) ≤ 8z < 4(w + 1)(w + 2)
4w² + 4w ≤ 8z < 4w² + 12w + 8
```
Додамо 1 до всіх частин:
```
4w² + 4w + 1 ≤ 8z + 1 < 4w² + 12w + 9
(2w + 1)² ≤ 8z + 1 < (2w + 3)²
(2w + 1)² ≤ 8z + 1 < (2(w + 1) + 1)²
```
Оскільки для `z ∈ ℕ₀` та `w ∈ ℕ₀` усі вирази є строго додатними, добудемо квадратний корінь:
```
2w + 1 ≤ √(8z + 1) < 2w + 3
```
Віднімемо 1 від усіх частин:
```
2w ≤ √(8z + 1) - 1 < 2w + 2
```
Поділимо на 2:
```
w ≤ (√(8z + 1) - 1) / 2 < w + 1
```
Отримана подвійна нерівність `w ≤ α < w + 1` для дійсного числа `α = (√(8z + 1) - 1) / 2` за означенням функції взяття цілої частини (підлоги `⌊ ⌋`) однозначно визначає ціле невід'ємне число `w`:
```
w = ⌊ (√(8z + 1) - 1) / 2 ⌋
```
Оскільки `z ≥ 0`, маємо `8z + 1 ≥ 1`, отже `√(8z + 1) ≥ 1`, звідки `(√(8z + 1) - 1) / 2 ≥ 0`, тому `w ∈ ℕ₀`.

Знайшовши `w`, визначимо координати `y` та `x`:
```
t = T(w) = (w · (w + 1)) / 2
y = z - t
x = w - y
```
Перевіримо виконання всіх крайових умов:
1. За побудовою `w` маємо `T(w) ≤ z`, тому `y = z - T(w) ≥ 0`, тобто `y ∈ ℕ₀`.
2. За побудовою `w` маємо `z < T(w + 1) = T(w) + w + 1`, тому `y = z - T(w) < w + 1`, що для цілих чисел рівносильно `y ≤ w`.
3. З нерівності `y ≤ w` випливає `x = w - y ≥ 0`, тобто `x ∈ ℕ₀`.
4. Обчислимо значення прямої функції Кантора для відновленої пари `(x, y)`:
```
π(x, y) = T(x + y) + y = T(w) + (z - T(w)) = z
```
Отже, для кожного `z ∈ ℕ₀` знайдено коректну пару `(x, y) ∈ ℕ₀²`, для якої `π(x, y) = z`. Єдиність випливає з уже доведеної ін'єктивності. Сюр'єктивність повністю доведено.

### 4. Неможливість лінійного спарювання

Часто виникає питання, чому не можна побудувати бієкцію `ℕ₀² → ℕ₀` за допомогою простішого лінійного многочлена вигляду `L(x, y) = a·x + b·y + c` з дійсними або раціональними коефіцієнтами.

#### Теорема 3 (Неможливість лінійної бієкції)
Не існує лінійного многочлена `L(x, y) = a·x + b·y + c`, який здійснює бієкцію `ℕ₀ × ℕ₀ → ℕ₀`.

**Доведення:**
Припустимо від супротивного, що такий многочлен існує.
1. Оскільки `L(0, 0) ∈ ℕ₀`, позначимо `c = L(0, 0) = z₀ ∈ ℕ₀`.
2. Якщо `a = 0`, то `L(x, y) = b·y + c` не залежить від `x`, що порушує ін'єктивність (`L(1, 0) = L(0, 0)`). Аналогічно при `b = 0`. Отже, `a ≠ 0` та `b ≠ 0`.
3. Оскільки `L(1, 0) = a + c ∈ ℕ₀` та `L(0, 1) = b + c ∈ ℕ₀`, то `a` і `b` є дійсними числами.
4. Розглянемо кількість точок `(x, y) ∈ ℕ₀²`, для яких `L(x, y) ≤ N` для деякого натурального `N`:
Кількість пар у першому квадранті під прямою `a·x + b·y + c ≤ N` асимптотично дорівнює площі трикутника:
```
Кількість точок = (N² / (2·a·b)) + O(N)
```
5. Проте для бієкції `L: ℕ₀² → ℕ₀` кількість значень, що не перевищують `N`, повинна точно дорівнювати кількості натуральних чисел від `0` до `N`, тобто `N + 1`.
6. Отримуємо асимптотичну рівність:
```
(N² / (2·a·b)) + O(N) = N + 1
```
При `N → ∞` ліва частина росте як `O(N²)`, тоді як права частина росте як `O(N)`. Отримали нездоланну суперечність порядків росту. Отже, лінійної бієкції між `ℕ₀²` та `ℕ₀` не існує. Мінімальний можливий степінь полінома для бієкції становить рівно `2`.

### 5. Теорема Футера — Полі про єдиність полінома спарювання

У 1923 році швейцарські математики Рудольф Футер та Георг Поля розв'язали фундаментальну проблему про класифікацію квадратичних бієкцій двох змінних:

#### Теорема (Футер — Поля, 1923)
Єдиними дійсними квадратичними многочленами `P(x, y) = a·x² + b·x·y + c·y² + d·x + e·y + f`, які здійснюють бієктивне відображення `ℕ₀ × ℕ₀ → ℕ₀`, є парна функція Кантора та її транспонована версія:
```
π₁(x, y) = ((x + y)² + 3y + x) / 2 = ((x + y)(x + y + 1)) / 2 + y
π₂(x, y) = ((x + y)² + 3x + y) / 2 = ((x + y)(x + y + 1)) / 2 + x
```

**Ключові етапи доведення Футера — Полі:**
1. **Асимптотична щільність:** Інтегральна щільність ліній рівня квадратичної форми вимагає, щоб криві рівня `P(x, y) = const` утворювали сімейство паралельних прямих `x + y = const` у першому квадранті. Це фіксує головну однорідну частину другого степеня: `a = b/2 = c = 1/2`, тобто `P₂(x, y) = (x + y)² / 2`.
2. **Аналітичне продовження:** За допомогою дзета-функцій та аналізу розподілу цілих точок доводиться, що лінійні коефіцієнти повинні забезпечувати точне чергування залишків без виникнення прогалин (дірок) на переходах між діагоналями.
3. **Фіксація коефіцієнтів:** Єдиними розв'язками системи діофантових обмежень є пари коефіцієнтів `(d = 1/2, e = 3/2)` або `(d = 3/2, e = 1/2)` при `f = 0`.

### 6. Розширення на знакозмінні цілі числа ℤ × ℤ

Для кодування пар довільних цілих чисел `(u, v) ∈ ℤ × ℤ` (включно з від'ємними значеннями) будується композиція з класичною бієкцією чергування знаків `σ: ℤ → ℕ₀`:

```
σ(n) =
  2n         при n ≥ 0
  2|n| - 1   при n < 0
```
Ця функція впорядковує цілі числа у послідовність: `0 ↦ 0, -1 ↦ 1, 1 ↦ 2, -2 ↦ 3, 2 ↦ 4, -3 ↦ 5, ...`.

Обернена функція декодування `σ⁻¹: ℕ₀ → ℤ` задається явно:
```
σ⁻¹(k) = (k % 2 == 0) ? (k / 2) : -((k + 1) / 2)
```

Тоді узагальнена бієкція `π_Z: ℤ × ℤ → ℕ₀` визначається як суперпозиція:
```
π_Z(u, v) = π(σ(u), σ(v))
```
Декодування виконується у зворотному порядку:
```
(k₁, k₂) = π⁻¹(z)
u = σ⁻¹(k₁)
v = σ⁻¹(k₂)
```
Це гарантує збереження всіх властивостей взаємної однозначності на повній дискретній площині `ℤ²`.

### 7. Зліченність раціональних чисел ℚ⁺ та щільність взаємно простих пар

Історично першим застосуванням парної функції Кантора було доведення зліченності множини додатних раціональних чисел `ℚ⁺ = {p / q | p, q ∈ ℕ, gcd(p, q) = 1}`.

Будь-який нескоротний дріб `p / q` зіставляється з парою `(p - 1, q - 1) ∈ ℕ₀²`, значення функції Кантора для якої дорівнює `z = π(p - 1, q - 1)`. Проте не кожне ціле число `z` відповідає нескоротному дробу, оскільки деякі пари `(p, q)` мають спільні дільники `gcd(p, q) > 1` (наприклад, `2/2, 2/4, 3/6`).

**Теорема про щільність нескоротних дробів на сітці Кантора:**
Асимптотична частка точок цілочисельної решітки, які відповідають взаємно простим парам `gcd(p, q) = 1`, визначається сумою функції Ейлера `φ(w)` і прямує до константи Діріхле:
```
lim_{N → ∞} (Кількість взаємно простих пар серед перших N діагоналей) / T(N)
= 6 / π² ≈ 0.607927...
```
Це означає, що приблизно 60.8% усіх натуральних кодів Кантора відповідають нескоротним раціональним числам `p / q`, що дає змогу побудувати ефективне зліченне перерахування `ℚ⁺` без повторень за допомогою простої фільтрації дільників.

### 8. Теоретико-категорний погляд та адитивна геометрія трикутних чисел

У мові теорії категорій та функційного програмування парна функція Кантора реалізує природний ізоморфізм у декартово замкненій категорії дискретних зліченних множин.

Для будь-яких трьох зліченних множин `A, B, C` існує канонічний бієктивний зв'язок між функціями від двох аргументів та одномісними функціями вищого порядку (каррінг, англ. *Currying*):
```
Hom(A × B, C) ≅ Hom(A, Hom(B, C))
```
Якщо покласти `A = B = C = ℕ₀`, то парна функція Кантора надає явний обчислюваний ізоморфізм для самого декартового добутку:
```
ℕ₀ × ℕ₀ ≅ ℕ₀
```
Це перетворює будь-яку бінарну операцію `f(x, y)` на унарну операцію над числами Кантора `f̂(z) = f(π₁(z), π₂(z))`, усуваючи необхідність підтримки багатовимірних типів даних на фундаментальному рівні обчислювальної моделі.

Більше того, трикутні числа `T(w) = w(w+1)/2`, які слугують фундаментальними базовими стовпами функції Кантора, посідають виняткове місце в аналітичній теорії чисел. У 1796 році Карл Фрідріх Гаус довів свою знамениту теорему: кожне натуральне число можна подати як суму не більше ніж трьох трикутних чисел (відомий запис у щоденнику Гауса: *«Eureka! num = Δ + Δ + Δ»*). Це підкреслює глибоку гармонію між щільністю трикутних чисел на числовій осі та можливістю безшовного розбиття простору `ℕ₀` на скінченні діагональні сегменти без жодної числової дірки чи накладання.

### 9. Примітивна рекурсивність проєкцій у формальній арифметиці

У теорії обчислюваності та арифметиці Пеано важливо, щоб функції кодування `π(x, y)` та декодування (проєкційні функції `π₁(z) = x`, `π₂(z) = y`) належали до класу **примітивно рекурсивних функцій (PR)**. Це гарантує, що операції спарювання та розпакування виконуються детерміновано за фіксований час без використання необмеженого пошуку за оператором мінімізації `μ`.

1. Пряма функція `π(x, y)` виражається через базові операції додавання та множення:
```
mult(add(x, y), add(add(x, y), 1)) / 2 + y
```
Оскільки операції додавання, множення та ділення на сталу є примітивно рекурсивними, `π(x, y) ∈ PR`.

2. Для проєкцій `π₁(z)` та `π₂(z)` використовується обмежений оператор мінімізації `μ_{w ≤ z}`:
Згідно з Лемою 4, `w = x + y ≤ π(x, y) = z`. Тому номер діагоналі `w` визначається як найменше число `w ≤ z`, для якого значення трикутного числа наступного рівня строго більше за `z`:
```
diag(z) = μ_{w ≤ z} [ T(w + 1) > z ]
```
Тоді проєкції записуються як суто примітивно рекурсивні вирази:
```
π₂(z) = z ∸ T(diag(z))
π₁(z) = diag(z) ∸ π₂(z)
```
(де `∸` — операція усіченого віднімання `a ∸ b = max(0, a - b)`). Це доводить, що парна функція Кантора повністю сумісна з синтаксисом формальних систем першого порядку.

### 10. Порівняння зі спарюванням Шудзіка (Szudzik Pairing)

Окрім діагонального розбиття простору, існує популярна альтернатива — **квадратне спарювання Метью Шудзіка (елегантне спарювання, 2006)**. Замість діагоналей воно обходить дискретний простір концентричними L-подібними шарами навколо початку координат, де кожен шар відповідає значенню `max(x, y) = k`.

Функція Шудзіка `Sz: ℕ₀ × ℕ₀ → ℕ₀` задається кусково-поліноміальним правилом:
```
Sz(x, y) =
  x < y  :  y² + x
  x ≥ y  :  x² + x + y
```

**Формули декодування Шудзіка:**
За заданим числом `z ∈ ℕ₀`:
```
s = ⌊ √z ⌋
r = z - s²
x, y = (r < s) ? (r, s) : (s, r - s)
```

**Порівняльний аналіз властивостей:**
1. **Відсутність ділення:** Формула Шудзіка не містить ділення на `2`, що прискорює пряме обчислення на процесорах без апаратного помножувача-дільника.
2. **Просторова локальність:** У задачах, де координати змінюються в межах прямокутника `[0, N] × [0, N]`, спарювання Шудзіка генерує коди в діапазоні `[0, N² - 1]`, тоді як діагональне спарювання Кантора у правому верхньому куті `(N, N)` дає значення `T(2N) + N = 2N² + 2N`, тобто майже вдвічі більший числовий діапазон.
3. **Гладкість:** Функція Кантора є єдиним гладким алгебраїчним поліномом на всьому просторі `ℕ₀²`, що робить її незамінною в аналітичних доведеннях та кванторних редукціях.

### 11. Узагальнення для k-вимірних кортежів

Для довільної розмірності `k ≥ 2` функція спарювання будується індуктивно.

#### Індуктивна побудова (Лінійне згортання)
База індукції `k = 2`:
```
π⁽²⁾(x₁, x₂) = π(x₁, x₂)
```
Індуктивний перехід від `k` до `k + 1`:
```
π⁽ᵏ⁺¹⁾(x₁, x₂, ..., xₖ, xₖ₊₁) = π(π⁽ᵏ⁾(x₁, ..., xₖ), xₖ₊₁)
```

**Теорема про бієктивність `π⁽ᵏ⁾: ℕ₀ᵏ → ℕ₀`:**
Оскільки композиція довільної кількості бієктивних функцій є бієкцією, то відображення `π⁽ᵏ⁾` є строгою бієкцією між простором `k`-вимірних векторів `ℕ₀ᵏ` та одновимірним числовим рядом `ℕ₀`.

**Алгоритм індуктивного декодування:**
Для відновлення вектора `(x₁, x₂, ..., xₖ)` з числа `z = π⁽ᵏ⁾(x₁, ..., xₖ)`:
1. Застосовуємо одновимірне декодування Кантора до `z`:
```
(z_{k-1}, xₖ) = π⁻¹(z)
```
2. Повторюємо процедуру розпакування для проміжного значення `z_{k-1}`:
```
(z_{k-2}, x_{k-1}) = π⁻¹(z_{k-1})
...
(x₁, x₂) = π⁻¹(z₂)
```
У результаті рівно за `k - 1` аналітичних кроків обчислення квадратного кореня відновлюються всі `k` координат вихідного вектора.

**Асимптотика бітової довжини:**
Нехай `M = max(x₁, ..., xₖ)`. При лінійному згортанні:
```
π⁽ᵏ⁾(x₁, ..., xₖ) = O(M^(2^(k-1)))
Бітова довжина = O(2^(k-1) · log₂(M))
```
Для оптимізації розрядності у високих розмірностях застосовують схему **збалансованого дерева спарювання**:
```
π⁽⁴⁾_tree(x₁, x₂, x₃, x₄) = π(π(x₁, x₂), π(x₃, x₄))
```
яка мінімізує асиметрію бітових довжин координат і має глибину рекурсії `⌈log₂ k⌉`.
