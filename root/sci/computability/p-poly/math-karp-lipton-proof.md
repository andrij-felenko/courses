# 🧮 Математичні доведення теорій про клас P/poly

Ця математична вставка містить формальні доведення трьох ключових теорем теорії неоднорідної складності: еквівалентності схемної моделі та моделі з підказкою, теореми Адлемана про включення BPP у P/poly, та теореми Карпа — Ліптона про схлопування поліноміальної ієрархії. Доведення наведено строгим алгебраїчним та логічним апаратом без використання штучного спрощення.

## 1. Теорема еквівалентності: Булеві схеми та Машини Тюринга з підказкою

> **Теорема 1.** Мова `L ⊆ {0, 1}*` належить до класу `P/poly` тоді й лише тоді, коли виконуються дві еквівалентні умови:
> 1. Існує сімейство булевих схем `{Cₙ | n ∈ ℕ}` таке, що `size(Cₙ) ≤ p(n)` для деякого полінома `p`, і для кожного `x ∈ {0, 1}ⁿ` виконується `x ∈ L ⇔ Cₙ(x) = 1`.
> 2. Існує детермінована машина Тюринга `M`, яка працює за поліноміальний час `q(n)`, та послідовність підказок `{aₙ | n ∈ ℕ}` довжини `|aₙ| ≤ r(n)` для деяких поліномів `q` та `r` такі, що `x ∈ L ⇔ M(x, aₙ) = 1` для всіх `n = |x|`.

### Доведення (Прямий напрямок: 1 ⇒ 2)
Припустимо, що мова `L` розпізнається сімейством схем `{Cₙ}` розміру `size(Cₙ) ≤ p(n)`. Побудуємо універсальну машину Тюринга `M` та послідовність підказок `aₙ`:

1. Кожна схема `Cₙ` є спрямованим ациклічним графом (DAG) з `N ≤ p(n)` вершинами-гейтами (AND, OR, NOT, входи).
2. Закодуємо топологію та таблицю з'єднань графа `Cₙ` у вигляді двовимірного текстового рядка або списку суміжності. Оскільки кількість гейтів `N ≤ p(n)`, довжина коду схем становить `|aₙ| = O(p(n) log p(n))`, що є поліноміальною величиною від `n`.
3. Зафіксуємо рядок кодування `Cₙ` як підказку `aₙ`.
4. Машина Тюринга `M(x, aₙ)` приймає вхід `x` та підказку `aₙ` (опис схеми `Cₙ`) і виконує обчислення схеми у топологічному порядку за час `O(|aₙ|) = O(p(n) log p(n))`.

Обчислення машини `M` є детермінованим і поліноміальним від `|x|`.

```
M(x, aₙ)
= Обчислення Cₙ(x) за допомогою універсального інтерпретатора DAG
= Cₙ(x)
= L(x)                    [за визначенням сімейства Cₙ]
```

### Доведення (Зворотний напрямок: 2 ⇒ 1)
Припустимо, що мова `L` розпізнається машиною `M(x, aₙ)` за поліноміальний час `q(n)`.

1. За теоремою Кука — Левіна, процес обчислення детермінованої машини Тюринга `M` на вхідних даних довжини `N = n + |aₙ|` за час `q(n)` можна симулювати булевою схемою `C'ₙ` розміру `O(q(n)²)`.
2. Схема `C'ₙ` має `n + |aₙ|` вхідних вентилів.
3. Побудуємо схему `Cₙ(x)` шляхом «впаювання» (фіксації) константних значень підказки `aₙ` у відповідні `|aₙ|` вхідних вентилів схеми `C'ₙ`.
4. Розмір нової схеми `size(Cₙ) ≤ size(C'ₙ) = O(q(n)²)`, що є поліномом від `n`.

Отже, обидва визначення є математично тотожними.

## 2. Доведення теореми Адлемана (BPP ⊆ P/poly)

> **Теорема 2 (Адлеман, 1978).** Будь-яка мова `L`, що належить до класу ймовірнісного поліноміального часу `BPP`, належить до класу `P/poly`.

### Доведення
Нехай `L ∈ BPP`. За визначенням BPP існує ймовірнісна машина Тюринга `M`, яка за поліноміальний час `p(n)` приймає рішення, використовуючи послідовність випадкових бітів `r ∈ {0, 1}ᵖ⁽ⁿ⁾`. 

Імовірність помилки стандартної машини BPP становить не більше `1/3`. Застосуємо техніку підсилення ймовірності (повторення обчислення `k(n)` разів із вибором більшості голосів):

```
Кількість повторень: k(n) = 12 · (n + 1)
```

За нерівністю Чернова, ймовірність того, що мажоритарне голосування по `k(n)` незалежних випадкових стрічках дасть хибну відповідь для фіксованого входу `x ∈ {0, 1}ⁿ`, знижується експоненціально:

```
Pr_r[M'(x, r) ≠ L(x)] ≤ exp(-k(n) / 12)
= exp(-(12(n + 1)) / 12)
= exp(-(n + 1))
< 2⁻⁽ⁿ⁺¹⁾                 [оскільки e¹ > 2]
```

Оцінимо ймовірність існування **бодай одного** «поганого» вхідного рядка `x` для випадково обраної послідовності бітів `r ∈ {0, 1}ᵐ` (де `m = k(n) · p(n)`):

Застосуємо суму ймовірностей (англ. *Union Bound*) по всіх `2ⁿ` можливих вхідних рядках довжини `n`:

```
Pr_r[∃ x ∈ {0, 1}ⁿ : M'(x, r) ≠ L(x)]
≤ ∑_{x ∈ {0, 1}ⁿ} Pr_r[M'(x, r) ≠ L(x)]    [Union Bound]
≤ 2ⁿ · 2⁻⁽ⁿ⁺¹⁾                              [за нерівністю Чернова]
= 2ⁿ · 2⁻ⁿ · 2⁻¹
= 1/2
```

Оскільки ймовірність того, що випадкова стрічка `r` є «поганою» хоча б для одного входу, дорівнює `1/2 < 1`, із цього чисто математично випливає, що **існує принаймні одна «золота» послідовність бітів** `r* ∈ {0, 1}ᵐ`, яка дає абсолютну правильність для **всіх `2ⁿ` вхідних рядків** довжини `n` одночасно:

```
Pr_r[∀ x ∈ {0, 1}ⁿ : M'(x, r*) = L(x)] ≥ 1 - 1/2 = 1/2 > 0
```

Зафіксуємо цю послідовність `r*` як підказку `aₙ = r*`. Довжина підказки `|aₙ| = k(n) · p(n) = O(n · p(n))`, що є поліномом.
Детермінована машина Тюринга `M_det(x, aₙ) = M'(x, r*)` розпізнає мову `L` без жодної помилки за поліноміальний час.
Отже, `L ∈ P/poly`, що й доводить теорему `BPP ⊆ P/poly`.

## 3. Доведення теореми Карпа — Ліптона (NP ⊆ P/poly ⇒ PH = Σ₂ᵖ)

> **Теорема 3 (Карп — Ліптон, 1980).** Якщо `NP ⊆ P/poly`, то поліноміальна ієрархія `PH` схлопується до свого другого рівня: `PH = Σ₂ᵖ = Π₂ᵖ`.

### Доведення
Достатньо довести, що третій рівень ієрархії схлопується до другого: `Σ₃ᵖ ⊆ Σ₂ᵖ`. Якщо це так, то за індукцією всі вищі рівні `Σₖᵖ` для `k ≥ 3` також впадуть на `Σ₂ᵖ`.

Розглянемо довільну мову `L ∈ Σ₃ᵖ`. За визначенням поліноміальної ієрархії, `x ∈ L` тоді й лише тоді, коли існує префікс кванторів із двома чергуваннями над поліноміально розпізнаваним предикатом `R`:

```
x ∈ L  ⇔  ∃ u ∈ {0, 1}ᵖ⁽ⁿ⁾  ∀ v ∈ {0, 1}ᵖ⁽ⁿ⁾  ∃ w ∈ {0, 1}ᵖ⁽ⁿ⁾  R(x, u, v, w)
```

Звернемо увагу на внутрішній предикат `Q(x, u, v) = ∃ w R(x, u, v, w)`. 
Задача перевірки істинності предиката `Q` для зафіксованих `(x, u, v)` належить до класу **NP** (бо потрібен лише один свідок `w`).

Оскільки за припущенням теореми `NP ⊆ P/poly`, для NP-повної задачі **SAT** існує сімейство схем `{Cₘ}` поліноміального розміру.
Завдяки властивості **самозведення** (англ. *self-reducibility*) SAT, схема поліноміального розміру `Cₘ` може не просто відповідати `0` або `1`, а й за поліномний час конструювати сам виконуватимий набір змінних (свідок `w`).

Отже, існує схема `Cₘ` така, що якщо існує `w` для якого `R(x, u, v, w) = 1`, то схема `Cₘ(x, u, v)` видає саме такий свідок `w`.

Підставимо роботу схеми `Cₘ` замість квантора існування `∃ w`:

```
∃ w R(x, u, v, w)  ⇔  R(x, u, v, Cₘ(x, u, v))
```

Тепер перепишемо початковий вираз для `x ∈ L`:
Замість «існує схема `Cₘ` для всіх `n`» ми можемо використати підстановку квантора існування `∃ C` (оскільки розмір опису схеми `C` обмежений поліномом `q(n)`):

```
x ∈ L  ⇔  ∃ C  ∃ u  ∀ v  [ C є коректною схемою пошуку свідків AND R(x, u, v, C(x, u, v)) ]
```

Перевірка того, що схема `C` є коректною для всіх формул довжини `m`, сама по собі має структуру `∀ (x', u', v')`.
Об'єднуючи квантори однакового типу:

```
x ∈ L  ⇔  ∃ C  ∃ u  ∀ v  ∀ (x', u', v')  R_poly(x, u, v, C, x', u', v')
```

Сусідні квантори загальності `∀ v` та `∀ (x', u', v')` можна об'єднати в один квантор `∀ y`.
Оригінальний вираз із трьома кванторами `∃ u ∀ v ∃ w` перетворився на вираз із двома кванторами:

```
x ∈ L  ⇔  ∃ (C, u)  ∀ y  R_new(x, C, u, y)
```

Цей вираз за формою точно відповідає визначенню класу **Σ₂ᵖ** (один квантор існування `∃`, за яким іде один квантор загальності `∀`).

Отже, `Σ₃ᵖ ⊆ Σ₂ᵖ`. Оскільки `Σ₂ᵖ ⊆ Σ₃ᵖ` за визначенням ієрархії, ми отримуємо `Σ₃ᵖ = Σ₂ᵖ`.
За індукцією це розповсюджується на всі вищі рівні:

```
PH = ⋃_{k≥1} Σₖᵖ = Σ₂ᵖ
```

Теорему Карпа — Ліптона повністю доведено.
