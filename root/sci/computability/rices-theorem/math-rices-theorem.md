# 🧮 Строгі доведення теореми Райса та теореми Райса–Шапіро

Математична строгість теореми Райса спирається на апарат часткових рекурсивних функцій та їхньої нумерації за Кліні. Коли ми стверджуємо, що «будь-яка нетривіальна властивість поведінки програми є нерозв'язною», це твердження потребує точного визначення того, що таке «програма», що таке «поведінка», що означає «нетривіальність» і як формально доводиться відсутність вирішального алгоритму.

Цей математичний апарат дає два принципово різні шляхи доведення теореми Райса: класичне зведення за Тюрінгом (множинне зведення за Постом) та елегантне доведення через другу теорему Кліні про нерухому точку (рекурсивну фіксовану точку). Крім того, він дозволяє вийти за межі питання повної розв'язності й отримати точний критерій напіврозв'язності через теорему Райса–Шапіро, а також класифікувати властивості програм усередині арифметичної ієрархії.

## 1. Формальний простір обчислюваних функцій

Нехай `ℕ = {0, 1, 2, ...}` — множина натуральних чисел. Позначимо через `PR` множину всіх одномісних часткових рекурсивних функцій вигляду `f: ℕ ⇀ ℕ`. Запис `f(x)↓` означає, що функція визначена на вході `x` (алгоритм зупиняється і видає значення), а `f(x)↑` означає, що функція невизначена на `x` (алгоритм зациклюється).

Дві часткові функції `f` та `g` вважаються рівними (`f = g`), якщо вони мають однакову область визначення і на всіх спільних аргументах видають однакові значення:

```
∀x ∈ ℕ: (f(x)↓ ∧ g(x)↓ ∧ f(x) = g(x)) ∨ (f(x)↑ ∧ g(x)↑)
```

За теоремою про універсальну функцію існує допустима нумерація (геделізація) всіх часткових рекурсивних функцій, яку позначають як послідовність `φ₀, φ₁, φ₂, ...`, де `φ_e` — функція, що обчислюється програмою (або машиною Тюрінга) з індексом `e ∈ ℕ`.

### Теорема про параметризацію (s-m-n теорема Кліні)

Фундаментальним інструментом синтезу програм є теорема Кліні про параметризацію: для будь-яких натуральних чисел `m, n ≥ 1` існує загальнорекурсивна (всюди визначена обчислювана) функція `s_n^m(e, x₁, ..., x_m)` така, що для всіх аргументів `y₁, ..., y_n` виконується тотожність:

```
φ_{s_n^m(e, x₁, ..., x_m)}(y₁, ..., y_n) = φ_e(x₁, ..., x_m, y₁, ..., y_n)
```

У найпростішому випадку одномісних функцій це означає існування обчислюваної функції `s(e, x)`, яка бере код програми двох змінних `e` і фіксує її перший аргумент значенням `x`, повертаючи коректний код нової програми однієї змінної.

Алгебраїчна суть s-m-n теореми полягає в тому, що спеціалізація коду під відомий вхідний параметр є чисто синтаксичною і виконується алгоритмічно без запуску самої програми. Ми просто дописуємо команду завантаження константи `x` на початок коду програми `e`.

### Екстенсіональність та індексні множини

Властивість програм є семантичною (екстенсіональною), якщо вона залежить виключно від обчислюваної функції, а не від коду. Формально це означає, що ми розглядаємо підмножину функцій `P ⊆ PR`.

Індексна множина `I_P ⊆ ℕ`, що відповідає властивості `P`, визначається як множина всіх номерів програм, що обчислюють функції з `P`:

```
I_P = { e ∈ ℕ | φ_e ∈ P }
```

Умова екстенсіональності записується як інваріантність індексної множини щодо рівності функцій:

```
∀a, b ∈ ℕ: (φ_a = φ_b) ⇒ (a ∈ I_P ⟺ b ∈ I_P)
```

Властивість `P` називається **нетривіальною**, якщо `P ≠ ∅` і `P ≠ PR`, тобто існують функції `g ∈ P` та `h ∉ P`.

## 2. Доведення через зведення за Постом (Many-One Reduction)

Формулювання теореми Райса: якщо `P ⊆ PR` — нетривіальна властивість, то відповідна індексна множина `I_P` не є рекурсивною (обчислюваною). Тобто її характеристична функція `χ_{I_P}` не є обчислюваною.

Доведемо це шляхом побудови обчислюваного зведення `m`-типу (many-one) від самозастосовної проблеми зупинки `K = { e ∈ ℕ | φ_e(e)↓ }` до множини `I_P` або її доповнення.

### Крок 1. Вибір базової функції

Позначимо через `f_∅` скрізь невизначену функцію (порожню функцію): `∀x: f_∅(x)↑`.

Оскільки `P` нетривіальна, можливі два випадки:
1. `f_∅ ∉ P`.
2. `f_∅ ∈ P`. Якщо це так, ми переходимо до розгляду доповнення `P' = PR \ P`. Оскільки `f_∅ ∉ P'`, а множина `I_P` є рекурсивною тоді й лише тоді, коли рекурсивним є її доповнення `ℕ \ I_P = I_{P'}`, достатньо довести нерекурсивність для випадку `f_∅ ∉ P`.

Отже, без обмеження загальності вважаємо, що `f_∅ ∉ P`.

### Крок 2. Фіксація представника властивості

Оскільки `P ≠ ∅`, існує деяка часткова рекурсивна функція `g ∈ P`. Нехай `e_g` — її фіксований індекс у нумерації Кліні, тобто `φ_{e_g} = g`.

### Крок 3. Побудова допоміжної функції двох змінних

Розглянемо функцію `ψ(k, x)`, задану таким алгоритмом:
«Для заданих чисел `k` та `x`:
1. Запустити обчислення `φ_k(k)` (емуляція `k`-ї машини Тюрінга на власному номері).
2. Якщо обчислення `φ_k(k)` завершилося (тобто `k ∈ K`), запустити обчислення `g(x) = φ_{e_g}(x)` і повернути його результат».

Функція `ψ(k, x)` є частковою рекурсивною функцією двох змінних, оскільки її кроки моделюються універсальною машиною Тюрінга. Її аналітичний вираз має вигляд:

```
ψ(k, x) = g(x), якщо k ∈ K
ψ(k, x) = ↑,    якщо k ∉ K
```

### Крок 4. Застосування s-m-n теореми

За теоремою про параметризацію існує загальнорекурсивна функція `r(k) = s(e_ψ, k)` така, що:

```
φ_{r(k)}(x) = ψ(k, x)
```

Дослідимо функцію, яку обчислює програма з індексом `r(k)`:

Якщо `k ∈ K`:
```
φ_{r(k)}(x)
= ψ(k, x)         [за означенням функції r(k) через s-m-n теорему]
= g(x)            [оскільки k ∈ K, перший крок обчислення завершується]
= φ_{e_g}(x)      [оскільки e_g є індексом функції g]
```
Оскільки `φ_{r(k)} = g`, а `g ∈ P`, за умовою екстенсіональності маємо `r(k) ∈ I_P`.

Якщо `k ∉ K`:
```
φ_{r(k)}(x)
= ψ(k, x)         [за означенням функції r(k) через s-m-n теорему]
= ↑               [оскільки k ∉ K, перший крок зациклюється назавжди]
= f_∅(x)          [за означенням скрізь невизначеної функції]
```
Оскільки `φ_{r(k)} = f_∅`, а `f_∅ ∉ P`, маємо `r(k) ∉ I_P`.

### Крок 5. Висновок редукції

Ми побудували тотальну обчислювану функцію `r: ℕ → ℕ`, для якої виконується еквівалентність:

```
k ∈ K ⟺ r(k) ∈ I_P
```

Це є строгим визначенням many-one зведення (зведення за перелічуваністю) `K ≤_m I_P`. Варто підкреслити, що зведення `m`-типу є значно сильнішим за загальне тюрінгове зведення зі зверненням до оракула (`≤_T`): воно показує, що питання належності `k ∈ K` напряму транслюється в єдиний запит про належність `r(k) ∈ I_P` без жодних додаткових обчислень чи логічних інверсій.

Якби множина `I_P` була рекурсивною (розв'язною), то характеристична функція проблеми зупинки обчислювалася б як `χ_K(k) = χ_{I_P}(r(k))`. Проте проблема зупинки `K` є нерозв'язною. Отже, множина `I_P` не є рекурсивною. Ба більше: якщо `f_∅ ∉ P`, то `K ≤_m I_P`, що доводить `Σ₁`-важкість множини `I_P`. Якщо ж `f_∅ ∈ P`, то аналогічно отримуємо `K ≤_m (ℕ \ I_P)`, що доводить `Π₁`-важкість `I_P`. Теорему Райса повністю доведено.

## 3. Доведення через другу теорему Кліні про нерухому точку

Альтернативне доведення базується на теоремі про нерухому точку (рекурсивну теорему Кліні), яка стверджує, що довільне обчислюване перетворення програм має синтаксичну нерухому точку з точністю до обчислюваної функції.

### Виведення теореми Кліні про нерухому точку

Щоб доведення було цілком замкненим, покажемо, звідки береться сама теорема про нерухому точку. Нехай `h: ℕ → ℕ` — довільна загальнорекурсивна функція. Розглянемо часткову обчислювану функцію двох змінних:

```
θ(u, x) = φ_{φ_u(u)}(x)
```

За s-m-n теоремою існує тотальна обчислювана функція `v(u)` така, що `φ_{v(u)}(x) = θ(u, x)`. Тепер розглянемо функцію `h(v(u))` — це також тотальна обчислювана функція. Отже, вона має деякий власний номер у нумерації Кліні, позначимо його як `m`, тобто `φ_m = h ∘ v`.

Підставимо індекс `m` у функцію `v`: розглянемо `n* = v(m)`. Обчислимо функцію `φ_{n*}`:

```
φ_{n*}(x)
= φ_{v(m)}(x)       [за означенням n* = v(m)]
= θ(m, x)           [за означенням функції v через s-m-n]
= φ_{φ_m(m)}(x)     [за означенням функції θ]
= φ_{h(v(m))}(x)    [оскільки φ_m = h ∘ v]
= φ_{h(n*)}(x)      [оскільки n* = v(m)]
```

Ми отримали рівність функцій: `φ_{n*} = φ_{h(n*)}`. Це і є теорема Кліні про нерухому точку: хоч як функція `h` переписує код програм, існує програма `n*`, чия поведінка після модифікації збігається з початковою.

### Доведення теореми Райса через нерухому точку

Припустимо від супротивного, що індексна множина `I_P` є рекурсивною. Тоді її характеристична функція є всюди визначеною і обчислюваною:

```
χ_{I_P}(e) = 1, якщо e ∈ I_P
χ_{I_P}(e) = 0, якщо e ∉ I_P
```

Оскільки властивість `P` нетривіальна, зафіксуємо два індекси `a, b ∈ ℕ` такі, що `φ_a ∈ P` (тобто `a ∈ I_P`) та `φ_b ∉ P` (тобто `b ∉ I_P`).

Побудуємо функцію `h: ℕ → ℕ` наступним чином:

```
h(e) = b, якщо χ_{I_P}(e) = 1  (тобто e ∈ I_P)
h(e) = a, якщо χ_{I_P}(e) = 0  (тобто e ∉ I_P)
```

Оскільки `χ_{I_P}` обчислювана, а вибір між сталими `a` та `b` здійснюється елементарним розгалуженням, функція `h` є загальнорекурсивною.

За теоремою Кліні про нерухому точку для функції `h` існує індекс `n*` такий, що:

```
φ_{n*} = φ_{h(n*)}
```

Оскільки `I_P` — екстенсіональна індексна множина, з рівності функцій `φ_{n*} = φ_{h(n*)}` випливає:

```
n* ∈ I_P ⟺ h(n*) ∈ I_P
```

Розглянемо належність індексу `n*` до множини `I_P`:

Якщо `n* ∈ I_P`:
```
h(n*)
= b               [за означенням функції h при n* ∈ I_P]
∉ I_P             [оскільки b обрано таким, що φ_b ∉ P]
```
Звідси `n* ∈ I_P ⟹ h(n*) ∉ I_P`, що суперечить еквівалентності `n* ∈ I_P ⟺ h(n*) ∈ I_P`.

Якщо `n* ∉ I_P`:
```
h(n*)
= a               [за означенням функції h при n* ∈ I_P]
∈ I_P             [оскільки a обрано таким, що φ_a ∈ P]
```
Звідси `n* ∉ I_P ⟹ h(n*) ∈ I_P`, що знову суперечить еквівалентності.

В обох випадках отримуємо суперечність. Отже, характеристична функція `χ_{I_P}` не може бути обчислюваною, а множина `I_P` є нерозв'язною.

## 4. Теорема Райса–Шапіро: критерій напіврозв'язності

Теорема Райса встановлює межу між розв'язним (`Δ₁`) та нерозв'язним. Теорема Райса–Шапіро піднімається на один щабель вище в арифметичній ієрархії й точно описує семантичні властивості, індексні множини яких є рекурсивно перелічуваними (напіврозв'язними, тобто належать до класу `Σ₁`).

### Скінченні підфункції

Часткова функція `θ: ℕ ⇀ ℕ` називається **скінченною (компактною)**, якщо її область визначення `dom(θ) = {x ∈ ℕ | θ(x)↓}` є скінченною множиною. Будь-яку скінченну функцію можна закодувати одним натуральним числом (наприклад, списком пар `⟨x, θ(x)⟩`).

Запис `θ ⊆ f` означає, що функція `f` є розширенням функції `θ`:

```
∀x ∈ dom(θ): (f(x)↓ ∧ f(x) = θ(x))
```

### Формулювання теореми Райса–Шапіро

Нехай `P ⊆ PR` — деяка множина часткових рекурсивних функцій, а `I_P = {e ∈ ℕ | φ_e ∈ P}` — її індексна множина. Множина `I_P` є рекурсивно перелічуваною (`I_P ∈ Σ₁`) тоді й лише тоді, коли виконуються три умови:

1. **Компактність (наближення скінченними частинами):** для будь-якої функції `f ∈ PR` умова `f ∈ P` виконується тоді й лише тоді, коли існує скінченна функція `θ ⊆ f` така, що `θ ∈ P`.
2. **Монотонність:** якщо скінченна функція `θ ∈ P` і `θ ⊆ g`, то `g ∈ P`.
3. **Ефективна перелічуваність скінченних функцій:** множина канонічних номерів усіх скінченних функцій, що належать до `P`, є рекурсивно перелічуваною.

### Доведення необхідності (якщо `I_P ∈ Σ₁`, то `P` компактна і монотонна)

Покажемо спершу монотонність: нехай `θ ∈ P` — скінченна функція, і `θ ⊆ g`. Припустимо, що `g ∉ P`. Побудуємо за допомогою s-m-n теореми функцію, яка на входах із `dom(θ)` обчислює `θ(x)`, а на інших входах обчислює `g(x)` лише за умови, що `k ∉ K`. Тоді при `k ∉ K` функція збігається з `g ∉ P`, а при `k ∈ K` вона збігається з `θ ∈ P`. Це знову зводить `K̄` до `I_P`, що неможливо для `Σ₁`-множини.

Тепер покажемо компактність: нехай `f ∈ P`. Припустимо від супротивного, що для будь-якої скінченної `θ ⊆ f` маємо `θ ∉ P`.

Нехай `e_f` — індекс функції `f`, тобто `φ_{e_f} = f`. Оскільки `I_P ∈ Σ₁`, існує обчислюване відношення `R(e, t)` таке, що `e ∈ I_P ⟺ ∃t: R(e, t)`.

Побудуємо за допомогою s-m-n теореми функцію `g(k, x)` наступним чином:
«Обчислювати `φ_{e_f}(x)` кроками. Але якщо за `x` кроків виявиться, що `k ∈ K` (знайдено свідка зупинки `φ_k(k)` за `x` тактів), то обірвати обчислення і зациклитися для всіх майбутніх кроків».

Тоді:
- Якщо `k ∉ K`, обрив ніколи не настає, тому `φ_{r(k)} = f ∈ P`. Отже, `r(k) ∈ I_P`.
- Якщо `k ∈ K`, то зупинка стається на деякому скінченному кроці `t₀`. Отже, `φ_{r(k)}` встигає обчислитися лише на скінченній кількості точок `x ≤ t₀`, утворюючи скінченну функцію `θ ⊆ f`. За нашим припущенням, жодна скінченна підфункція не належить `P`, отже `φ_{r(k)} = θ ∉ P`, звідки `r(k) ∉ I_P`.

Отримуємо еквівалентність:

```
k ∉ K ⟺ r(k) ∈ I_P
```

Це означає, що доповнення проблеми зупинки `K̄` (яке є строго `Π₁`-повним і не є рекурсивно перелічуваним) зводиться до множини `I_P ∈ Σ₁`. Це неможливо, оскільки зведення зберігає клас перелічуваності. Отримана суперечність доводить необхідність компактності.

### Доведення достатності (якщо умови виконано, то `I_P ∈ Σ₁`)

Нехай умови 1–3 виконано. Покажемо, що існує алгоритм напіврозв'язання для `I_P`.

Оскільки множина скінченних функцій у `P` є перелічуваною, існує генератор, який послідовно видає скінченні таблиці `θ₀, θ₁, θ₂, ... ∈ P`. Для довільного вхідного індексу `e` паралельно запускаємо два процеси:
1. Генеруємо чергову скінченну функцію `θ_i ∈ P`.
2. Запускаємо програму `e` на всіх точках з `dom(θ_i)` паралельними кроками (dovetailing).
3. Якщо для деякого `i` програма `e` успішно завершилася на всіх `x ∈ dom(θ_i)` і видала `φ_e(x) = θ_i(x)`, ми знайшли скінченну підфункцію `θ_i ⊆ φ_e`. Оскільки `θ_i ∈ P`, за умовою монотонності `φ_e ∈ P`. Алгоритм зупиняється і повертає «так».

Якщо `φ_e ∈ P`, то за умовою компактності існує скінченна `θ ⊆ φ_e` така, що `θ ∈ P`. Ця `θ` рано чи пізно з'явиться в переліку, і всі її значення обчисляться за скінченний час, тому процес гарантовано зупиниться. Якщо ж `φ_e ∉ P`, такий збіг ніколи не настане. Отже, `I_P` є рекурсивно перелічуваною (`Σ₁`).

## 5. Класифікація задач в арифметичній ієрархії

Теореми Райса та Райса–Шапіро дозволяють миттєво визначати статус складності семантичних множин в арифметичній ієрархії Кліні–Мостовського:

### Множина скрізь визначених функцій (`TOTAL`)

```
TOTAL = { e ∈ ℕ | ∀x: φ_e(x)↓ }
```

Чи є `TOTAL` напіврозв'язною (`Σ₁`)? Перевіримо за теоремою Райса–Шапіро: чи містить `TOTAL` якусь скінченну функцію? Жодна скінченна функція `θ` не є скрізь визначеною (бо `dom(θ)` скінченний). Отже, у `TOTAL` немає скінченних елементів. Якби `TOTAL` була `Σ₁`, то за умовою компактності вона мала б бути порожньою, що не так.

Отже, `TOTAL ∉ Σ₁`. Насправді формула `∀x ∃t: Step(e, x, t)` показує, що `TOTAL` є строго `Π₂`-повною множиною (другий рівень арифметичної ієрархії).

### Множина еквівалентності програм (`EQ`)

```
EQ = { ⟨a, b⟩ | φ_a = φ_b }
```

Чи можна за скінченний час перевірити рівність двох програм? Рівність означає: `∀x (φ_a(x)↓ ⟺ φ_b(x)↓) ∧ (φ_a(x)↓ ⟹ φ_a(x) = φ_b(x))`. Якщо зафіксувати одну програму як скрізь невизначену `f_∅`, рівність зводиться до `EMPTY` (`Π₁`). Якщо ж зафіксувати функцію як тотожну `id(x) = x`, рівність зводиться до `TOTAL` (`Π₂`). Множина `EQ` є `Π₂`-повною: перевірка еквівалентності вимагає двох кванторів по нескінченній поведінці.

### Множина функцій із непорожньою областю визначення (`NONEMPTY`)

```
NONEMPTY = { e ∈ ℕ | ∃x: φ_e(x)↓ }
```

Якщо `f ∈ NONEMPTY`, існує точка `x₀`, де `f(x₀) = y`. Розглянемо скінченну функцію `θ`, визначену лише в одній точці `x₀`: `θ(x₀) = y`. Очевидно, `θ ∈ NONEMPTY`, і будь-яке її розширення також належить до `NONEMPTY`. Умови компактності та монотонності виконані, а номери таких одноелементних функцій легко перелічити.

Отже, за теоремою Райса–Шапіро множина `NONEMPTY` є рекурсивно перелічуваною (`Σ₁`-повною).

### Множина функцій із порожньою областю визначення (`EMPTY`)

```
EMPTY = { e ∈ ℕ | ∀x: φ_e(x)↑ }
```

Єдиний елемент цієї множини — це порожня функція `f_∅`. Вона є скінченною, тому умова 1 виконана. Але умова 2 (монотонність) порушується: якщо розширити `f_∅`, додавши хоча б одне значення `g(0) = 1`, ми отримаємо функцію `g ∉ EMPTY`.

Оскільки монотонність порушена, за теоремою Райса–Шапіро `EMPTY ∉ Σ₁`. Її доповнення є `Σ₁`, отже сама множина `EMPTY` є строго `Π₁`-повною.

```
Складності семантичних множин:
Δ₁ (розв'язні)     : лише тривіальні властивості (∅ та PR)
Σ₁ (напіврозв'язні): NONEMPTY, властивості скінченної поведінки
Π₁ (ко-напіврозв.): EMPTY, властивості відсутності подій
Π₂ (складні)       : TOTAL, еквівалентність програм (EQ)
```

Математичний апарат теорем Райса та Райса–Шапіро перетворює аналіз алгоритмічних проблем зі стомливого індивідуального підбору машин Тюрінга на структурну класифікацію властивостей функцій за їхніми скінченними апроксимаціями.
