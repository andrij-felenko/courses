# 🧮 Формальне математичне доведення теореми рекурсії Кліні

Математична строгість теореми рекурсії Кліні спирається на два стовпи класичної теорії обчислюваності: існування універсальної частково-рекурсивної функції (нумерації Геделя) та теорему про параметризацію (s-m-n теорему). Це доведення демонструє, як із чистої синтаксичної композиції та діагоналізації виникає нерухома точка для довільного обчислюваного перетворення програмних індексів, а також розглядає ефективну версію Роджерса та параметричні розширення.

## 1. Базовий формалізм та нумерація Геделя

Нехай `φ[0], φ[1], φ[2], ...` — фіксована стандартна нумерація всіх одномісних частково-рекурсивних функцій (програм для машини Тюрінга). Позначення `φ[e](x)` задає результат застосування програми з геделівським номером `e` до вхідного значення `x`.

Аналогічно, `φ²[e](x, y)` позначає обчислення двомісної частково-рекурсивної функції з індексом `e` за стандартного кодування пари чисел в одне число (наприклад, через функцію парування Кантора).

Рівність двох часткових функцій `φ[a] ≡ φ[b]` (клініївська або сильна еквівалентність) означає тотожність їхніх графіків як бінарних відношень: для будь-якого входу `x` або обидва вирази `φ[a](x)` та `φ[b](x)` визначені й набувають однакового значення в множині `ℕ`, або обидва вирази одночасно невизначені (програми не зупиняються на даному вході).

Універсальна функція для одномісних програм визначається як часткова функція двох змінних:

```
U(e, x) = φ[e](x)
```

За теоремою Тюрінга про універсальну машину, функція `U(e, x)` є частково-рекурсивною і має власний номер `u_univ` у нумерації двомісних функцій.

## 2. Теорема про параметризацію (s-m-n лема)

Фундаментом конструкції Кліні є s-m-n теорема, яка формалізує операцію часткового застосування аргументів на рівні програмних індексів.

**Лема (s-m-n для m=1, n=1):**
Існує всюди визначена обчислювана (зокрема, примітивно-рекурсивна) функція двох змінних `s : ℕ × ℕ → ℕ` така, що для будь-якого індексу двомісної програми `e` та будь-яких чисел `x, y ∈ ℕ` виконується тотожність:

```
φ[s(e, x)](y)
= φ²[e](x, y)      [за означенням s-m-n спеціалізації]
```

### Конструкція функції s(e, x)

Функція `s(e, x)` будує номер нової одномісної машини Тюрінга за наступним алгоритмом:
1. Береться стандартний опис машини Тюрінга з індексом `e`.
2. Створюється префіксний блок команд, який при отриманні вхідного значення `y` на стрічці записує перед ним фіксовану константу `x` (утворюючи пару `(x, y)`), а потім передає керування початковому стану машини `e`.
3. Отриманий сукупний список інструкцій кодується в натуральне число за фіксованим геделівським алгоритмом. Оскільки алгоритм склеювання інструкцій потребує лише простих маніпуляцій з таблицею станів, функція `s(e, x)` є примітивно-рекурсивною і всюди визначеною.

Функція `s` володіє властивістю ін'єктивності за кожним аргументом: різні пари `(e, x)` переходять у різні номери машин `s(e, x)`.

## 3. Перша теорема Кліні про нерухому точку

**Теорема (Кліні, 1938):**
Для будь-якої всюди визначеної обчислюваної функції `f : ℕ → ℕ` існує таке натуральне число `e* ∈ ℕ`, що:

```
φ[e*] ≡ φ[f(e*)]
```

### Хід конструктивного доведення

**Крок 1. Побудова допоміжної двомісної функції.**
Визначимо двомісну функцію `u(v, x)` за наступним правилом:

```
u(v, x)
= φ[f(s(v, v))](x)
```

Розберемо обчислюваність функції `u`:
1. За вхідним числом `v` обчислюємо значення функції `s(v, v)`. Оскільки `s` всюди визначена й обчислювана, операція завершується за скінченну кількість тактів.
2. До отриманого числа застосовуємо функцію перетворення `f`, одержуючи індекс `f(s(v, v))`. Оскільки `f` за умовою теореми всюди визначена, результат гарантовано існує та є конкретним натуральним числом.
3. Отримане число інтерпретується як індекс програми, і універсальний інтерпретатор запускає її на вході `x`.

Отже, функція `u(v, x)` є частково-рекурсивною (обчислюваною за універсальним алгоритмом).

**Крок 2. Знаходження індексу для u.**
Оскільки `u(v, x)` обчислювана, за властивістю нумерації існує деякий фіксований індекс `v₀ ∈ ℕ` такий, що:

```
φ²[v₀](v, x)
= u(v, x)          [оскільки v₀ є геделівським номером функції u]
```

**Крок 3. Діагоналізація та визначення шуканої точки.**
Покладемо шуканий індекс `e*` рівним результату застосування s-m-n функції до пари `(v₀, v₀)`:

```
e* = s(v₀, v₀)
```

**Крок 4. Перевірка рівності для довільного аргументу x.**
Застосуємо програму з номером `e*` до довільного вхідного значення `x` і розгорнемо повний ланцюг тотожностей:

```
φ[e*](x)
= φ[s(v₀, v₀)](x)            [підстановка значення e* = s(v₀, v₀)]
= φ²[v₀](v₀, x)              [за s-m-n теоремою для програми v₀]
= u(v₀, x)                   [за означенням v₀ як індексу для функції u]
= φ[f(s(v₀, v₀))](x)         [за визначенням допоміжної функції u(v, x) при v = v₀]
= φ[f(e*)](x)                [зворотна підстановка s(v₀, v₀) = e*]
```

Оскільки тотожність `φ[e*](x) = φ[f(e*)](x)` виконується для будь-якого вхідного значення `x ∈ ℕ`, відповідні частково-рекурсивні функції збігаються:

```
φ[e*] ≡ φ[f(e*)]
```

Теорему повністю доведено.

## 4. Ефективна версія Роджерса

Гартлі Роджерс (Hartley Rogers, Jr.) посилив результат Кліні, показавши, що знаходження нерухомої точки є не просто математичним фактом існування, а алгоритмічно ефективним процесом.

**Теорема Роджерса про нерухому точку:**
Існує всюди визначена обчислювана функція `h : ℕ → ℕ` така, що якщо `i` є геделівським номером довільної всюди визначеної обчислюваної функції `f` (тобто `f = φ[i]`), то число `h(i)` є нерухомою точкою для `f`:

```
φ[h(i)] ≡ φ[φ[i](h(i))]
```

### Доведення теореми Роджерса

Розглянемо тримісну часткову функцію:

```
w(i, v, x) = φ[φ[i](s(v, v))](x)
```

Функція `w` обчислювана: спочатку обчислюється `s(v, v)`, потім запускається програма `i` на цьому числі, і нарешті отриманий індекс виконується на вході `x`.

За s-m-n теоремою для трьох змінних існує функція `s²(k, i)` така, що:

```
φ²[s²(k, i)](v, x) = w(i, v, x)
```

де `k` — фіксований індекс функції `w`. 
Позначимо `v(i) = s²(k, i)`. Тоді шукана функція побудови нерухомої точки має вигляд:

```
h(i) = s(v(i), v(i))
```

Оскільки функції `s` та `s²` примітивно-рекурсивні, функція `h(i)` є всюди визначеною та примітивно-рекурсивною. Вона автоматично обчислює індекс нерухомої точки за відомим кодом трансформатора `i`.

## 5. Друга теорема рекурсії з параметрами

У практичному аналізі програм потрібна здатність алгоритму оперувати власним індексом за наявності додаткових зовнішніх параметрів.

**Теорема (Параметрична форма другої теореми рекурсії):**
Для будь-якої обчислюваної часткової функції `g(e, x, y)` існує всюди визначена обчислювана функція `p(x)` така, що для всіх `x, y ∈ ℕ`:

```
φ[p(x)](y) ≡ g(p(x), x, y)
```

Зокрема, зафіксувавши параметр `x`, ми отримуємо одну конкретну програму `e = p(x)`, яка всередині свого тіла має повний доступ до власного індексу `e`.

### Доведення параметричної форми

За s-m-n теоремою існує функція `s(k, e, x)` така, що для фіксованого індексу `k` функції `g`:

```
φ[s(k, e, x)](y) = g(e, x, y)
```

Розглянемо функцію перетворення `F(x, e) = s(k, e, x)`. За теоремою Роджерса про нерухому точку з параметром, існує всюди визначена обчислювана функція `p(x)`, яка знаходить фіксовану точку для відображення `e ↦ F(x, e)`.

Тоді отримуємо:

```
φ[p(x)](y)
= φ[F(x, p(x))](y)           [за теоремою про нерухому точку]
= φ[s(k, p(x), x)](y)        [за означенням відображення F]
= g(p(x), x, y)              [за s-m-n теоремою]
```

Це доводить, що програма з номером `p(x)` володіє повноцінним рекурсивним самодоступом за будь-якого зовнішнього контексту `x`.

## 6. Нескінченність множини нерухомих точок

Важливим наслідком конструкції є те, що нерухома точка ніколи не є єдиною:

**Наслідок:**
Для будь-якої всюди визначеної обчислюваної функції `f : ℕ → ℕ` існує нескінченна множина попарно різних індексів `e₁ < e₂ < e₃ < ...` таких, що для кожного `k ≥ 1`:

```
φ[e_k] ≡ φ[f(e_k)]
```

Це випливає з ін'єктивності функції нумерації та можливості додавати до допоміжної функції `u(v, x)` довільну кількість еквівалентних, але синтаксично відмінних реалізацій. Будь-яка програма допускає нескінченно багато семантично еквівалентних самовідтворюваних форм.
