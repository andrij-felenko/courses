# ⚙️ Самовідтворюваний код: побудова квайнів на C та C++

Квайн (quine) — це повністю автономна комп'ютерна програма, яка під час свого виконання виводить у стандартний потік свій власний точний вихідний текст, не здійснюючи жодних операцій вводу/виводу з зовнішніх носіїв (без читання файлів із диска, звернення до мережі чи інтроспекції бінарного образу в пам'яті). Цей алгоритмічний механізм є прямим практичним втіленням другої теореми рекурсії Кліні та демонструє принцип подвійного використання інформації у скінченних автоматах.

## Архітектурний принцип побудови квайна

Спроба написати самовідтворюваний код прямим шляхом неминуче стикається з парадоксом нескінченного регресу: якщо програма складається з виклику `print("код")`, то всередині лапок має бути присутній весь текст файлу, включно з самим викликом функції `print` та самими лапками. Збільшення розміру рядка всередині лапок змінює загальний розмір файлу, що вимагає наступної модифікації, і так до нескінченності.

Розв'язання задачі спирається на поділ структури програми на два функціональні компоненти:
1. **Блок A (Пасивні дані / Шаблон):** Текстовий рядок або масив байтів, який кодує структуру алгоритмічної частини програми.
2. **Блок B (Активний алгоритм / Конструктор):** Код, який приймає рядок A і виконує дві послідовні дії:
   - розгортає рядок A як виконуваний код (друкує тіло програми);
   - бере цей самий рядок A і друкує його як літеральні дані в лапках, генеруючи рядок оголошення для блоку A.

У термінах теореми Кліні блок A відіграє роль індексу програми `v`, а блок B — роль оператора спеціалізації `s(v, v)`, який розгортає закодовані дані у повноцінний вихідний синтаксис.

## Реалізація канонічного квайна

Розглянемо дві реалізації: класичний квайн мовою C на основі форматованого рядка з кодами ASCII та сучасний ідіоматичний квайн мовою C++ з використанням об'єктів `std::string_view` та алгоритмічного екранування.

:::tabs
```c
#include <stdio.h>

int main(void) {
    /* Блок A (Дані): шаблон програми, де %s позначає місце для літерала, а %c - символи */
    const char *code = "#include <stdio.h>%c%cint main(void) {%c    const char *code = %c%s%c;%c    printf(code, 10, 10, 10, 34, code, 34, 10, 10, 10);%c    return 0;%c}%c";

    /* Блок B (Алгоритм): виклик printf з подвійним використанням рядка code:
       - перший раз code використовується як форматний рядок;
       - другий раз code передається як значення для специфікатора %s;
       - числа 10 генерують символи '\n', а числа 34 - подвійні лапки '\"'. */
    printf(code, 10, 10, 10, 34, code, 34, 10, 10, 10);
    return 0;
}
```
```cpp
#include <iostream>
#include <string_view>

int main() {
    // Блок A: початковий фрагмент коду як незмінний строковий літерал
    constexpr std::string_view head = 
        "#include <iostream>\n"
        "#include <string_view>\n\n"
        "int main() {\n"
        "    constexpr std::string_view head = \n"
        "        ";

    // Хвостовий фрагмент коду, що містить логіку конструктора (Блок B)
    constexpr std::string_view tail = 
        ";\n"
        "    constexpr char q = '\"';\n"
        "    std::cout << head << q;\n"
        "    for (char c : head) {\n"
        "        if (c == '\\n') std::cout << \"\\n        \";\n"
        "        else if (c == '\"' || c == '\\\\') std::cout << '\\\\' << c;\n"
        "        else std::cout << c;\n"
        "    }\n"
        "    std::cout << q << tail;\n"
        "    return 0;\n"
        "}\n";

    constexpr char q = '"';

    // Блок B: відтворення повного тексту через послідовний вивід частин
    std::cout << head << q;
    for (char c : head) {
        if (c == '\n') std::cout << "\n        ";
        else if (c == '"' || c == '\\') std::cout << '\\' << c;
        else std::cout << c;
    }
    std::cout << q << tail;
    return 0;
}
```

## Покроковий розбір роботи C-квайна

Розглянемо детально, як функція `printf` у програмі на C виконує точне самовідтворення:

1. **Завантаження шаблону в пам'ять:** Під час компіляції рядок `code` розміщується в сегменті константних даних `.rodata`. Цей рядок містить весь вихідний код програми, але на місці значення змінної `code` встановлено специфікатор `%c%s%c`.
2. **Підстановка керуючих кодів:**
   - Перші три аргументи зі значенням `10` відповідають десятковому ASCII-коду символу переведення рядка `\n`. Вони вставляються замість перших трьох специфікаторів `%c`, формуючи відступи між `#include <stdio.h>` та функцією `main`.
   - Наступний аргумент `34` є ASCII-кодом подвійних лапок `"`. Він формує відкривну лапку перед текстом рядка `code`.
   - Аргумент `code` передається у специфікатор `%s`. Функція `printf` читає байти рядка `code` і друкує весь текст шаблону всередині лапок.
   - Друге число `34` закриває лапки після тексту рядка.
   - Останні три числа `10` генерують перенесення рядків для виклику `printf`, оператора `return 0;` та закривної фігурної дужки `}`.
3. **Результат:** Згенерований потік символів у стандартний вивід `stdout` є абсолютно ідентичним файлу `main.c`, включно з усіма пропусками, лапками та символами нового рядка.

## Теоретичне відображення на теорему Кліні

Зв'язок між конструкцією квайна та математичною теоремою рекурсії Кліні є взаємно однозначним:

| Компонент квайна | Відповідник у теоремі Кліні | Функція в системі |
|---|---|---|
| Текстовий шаблон `code` | Індекс `v` допоміжної функції | Пасивний опис алгоритму |
| Логіка форматування `printf` | Функція спеціалізації `s(v, v)` | Побудова коду з даних |
| Текст функції `main` | Нерухома точка `e* = s(v₀, v₀)` | Повний самовідтворюваний автомат |
| Вивід у `stdout` | Значення `φ[e*]` | Результат обчислення програми |

## Квайн-реле (Ouroboros Quines)

Принцип Кліні дозволяє будувати значно складніші структури — поліглотні або циклічні квайни (Quine Relay). У такій системі програма мовою C при запуску друкує код мовою C++, компіляція та запуск якої генерує код мовою Python, а виконання Python-скрипту виводить початковий код мовою C:

```
Програма A (C) ──> Програма B (C++) ──> Програма C (Python) ──> Програма A (C)
```

Математично це відповідає знаходженню спільної нерухомої точки для композиції трьох перетворювачів компіляції: `e* = f_c(f_cpp(f_py(e*)))`. Оскільки кожна функція компіляції є обчислюваною, теорема рекурсії гарантує існування такого циклічного ланцюга будь-якої скінченної довжини.

## Зв'язок із біологічною самореплікацією фон Неймана

Джон фон Нейман показав, що механізм побудови квайнів є єдино можливим способом створення штучних або біологічних систем, здатних до повноцінного самовідтворення.

У живій клітині:
- **ДНК як Дані:** Молекула ДНК слугує матрицею, яку ферменти копіюють під час поділу клітини (аналог друку рядка `code` у лапках).
- **ДНК як Код:** Та сама молекула ДНК транслюється рибосомою для створення білків, що забезпечують життєдіяльність клітини (аналог виконання тіла `printf`).

Якщо вилучити хоча б один із цих двох аспектів, система або втрачає здатність функціонувати (стає пасивними даними), або впадає в нескінченний регрес, вимагаючи зовнішнього творця для кожного нового покоління.

## Підводні камені та типові помилки

Під час створення самовідтворюваних програм розробники найчастіше припускаються наступних помилок:

1. **Неузгодженість символів кінця рядка:** Символ переведення рядка в операційних системах сімейства Unix кодується як `\n` (байт `0x0A`), тоді як у Windows за замовчуванням використовуються два байти `\r\n` (`0x0D 0x0A`). Якщо квайн використовує явні байти, невідповідність стандарту призведе до відхилення виводу при порівнянні утилітою `diff`. Використання явного ASCII-числа `10` запобігає трансляції компілятором.
2. **Неекрановані спеціальні символи:** Спроба напряму вставити лапки або зворотні слеші у рядок вихідного тексту порушує синтаксичну структуру файлу під час повторної компіляції.
3. **Використання файлової інтроспекції:** Програми, які відкривають власний файл через `fopen(__FILE__, "r")` або читають аргумент `argv[0]`, не є квайнами за визначенням, оскільки вони не генерують власний код алгоритмічно, а лише копіюють дані з зовнішньої пам'яті.
