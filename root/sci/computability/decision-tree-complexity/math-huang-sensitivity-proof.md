# 🧮 Математичне доведення теореми Хуана та поліноміальних зв'язків

Цей математичний документ містить повний, строго виведений апарат спектральної теорії графів, який лежить в основі доведення Хао Хуана (2019) для Гіпотези про чутливість (Sensitivity Conjecture), а також математичні виведення основних поліноміальних нерівностей між заходами складності булевих функцій: `s(f)`, `bs(f)`, `C(f)`, `deg(f)` та `D(f)`.

---

## 1. Концептуальний огляд спектрального методу

Фундаментальна складність доведення Гіпотези про чутливість упродовж 25 років полягала у відсутності прямого комбінаторного містка між локальною чутливістю `s(f)` (яка описує зміни значення функції у 1-околі кожної точки) та глобальними заходами (такими як блокова чутливість `bs(f)` чи степінь многочлена `deg(f)`).

Хао Хуан знайшов цей місток за допомогою спектру розширеної матриці суміжності булевого гіперкуба `Q♁`. Перенісши задачу у векторний простір `ℝ²ⁿ`, ми можемо пов'язати кількість вершин підграфа із максимальним ступенем вершин через власні значення знаковидної матриці суміжності `A⁽ⁿ⁾`.

---

## 2. Спектральні властивості булевого гіперкуба

Булевим гіперкубом `Q♁` називається неорієнтований граф із множиною вершин `V = {0, 1}ⁿ` розміру `2ⁿ`. Дві вершини `u, v ∈ {0, 1}ⁿ` з'єднані ребром тоді й лише тоді, коли їхня відстань Геммінга `d_H(u, v) = 1` (вони відрізняються рівно в одному біті).

Визначимо послідовність знакових матриць суміжності `A⁽ⁿ⁾` розміру `2ⁿ × 2ⁿ` рекурсивно для `n ≥ 1`:

```
A⁽¹⁾ = [ 0  1 ]
       [ 1  0 ]

A⁽ⁿ⁾ = [  A⁽ⁿ⁻¹⁾     I    ]
       [    I     -A⁽ⁿ⁻¹⁾ ]
```
де `I` — це одинична матриця розміру `2ⁿ⁻¹ × 2ⁿ⁻¹`.

### Лема 1 (Квадрат знакової матриці)
Для будь-якого `n ≥ 1` виконується тотожність:
```
(A⁽ⁿ⁾)² = n · I₂ₙ
```

**Доведення (за індукцією):**

*База індукції (n = 1):*
```
(A⁽¹⁾)² = [ 0  1 ] · [ 0  1 ] = [ 1  0 ] = 1 · I₂
          [ 1  0 ]   [ 1  0 ]   [ 0  1 ]
```

*Крок індукції (від n-1 до n):*
Припустимо, що `(A⁽ⁿ⁻¹⁾)² = (n - 1) · I`. Обчислимо `(A⁽ⁿ⁾)²`:
```
(A⁽ⁿ⁾)² = [  A⁽ⁿ⁻¹⁾     I    ] · [  A⁽ⁿ⁻¹⁾     I    ]
          [    I     -A⁽ⁿ⁻¹⁾ ]   [    I     -A⁽ⁿ⁻¹⁾ ]

        = [ (A⁽ⁿ⁻¹⁾)² + I · I        A⁽ⁿ⁻¹⁾ · I - I · A⁽ⁿ⁻¹⁾   ]   [підстановка блоків]
          [ I · A⁽ⁿ⁻¹⁾ - A⁽ⁿ⁻¹⁾ · I  I · I + (-A⁽ⁿ⁻¹⁾)²        ]

        = [ (n - 1)·I + I                   0                  ]   [за припущенням індукції]
          [         0              I + (n - 1)·I               ]

        = [ n · I    0   ]
          [   0    n · I ]

        = n · I₂ₙ
```
Лема доведена.

---

### Наслідок з Леми 1 (Спектр матриці A⁽ⁿ⁾)
Оскільки `(A⁽ⁿ⁾)² = n · I₂ₙ`, усі власні значення `λ` матриці `A⁽ⁿ⁾` задовольняють рівняння `λ² = n`.
Отже, власними значеннями `A⁽ⁿ⁾` є лише два числа: `+√n` та `-√n`.

Оскільки слід матриці `A⁽ⁿ⁾` дорівнює нулю (`tr(A⁽ⁿ⁾) = 0`, бо всі діагональні елементи дорівнюють 0), кратність обох власних значень є однаковою і дорівнює `2ⁿ⁻¹`.
Таким чином, спектр матриці `A⁽ⁿ⁾` складається з:
- `2ⁿ⁻¹` власних значень, рівних `+√n`;
- `2ⁿ⁻¹` власних значень, рівних `-√n`.

## 3. Теорема Коші про переплетення та Лема Хуана

Згадаємо класичну теорему лінійної алгебри, яка пов'язує власні значення матриці з власними значеннями її головних підматриць.

### Теорема (Коші про переплетення власних значень)
Нехай `A` — симетрична дійсна матриця розміру `N × N` із власними значеннями `λ₁ ≥ λ₂ ≥ ... ≥ λ_N`.
Якщо `B` — підматриця розміру `m × m`, отримана з `A` вилученням `N - m` рядків та відповідних стовпчиків, і `μ₁ ≥ μ₂ ≥ ... ≥ μ_m` — власні значення `B`, то для кожного `i = 1, ..., m` виконується нерівність:
```
λ_i ≥ μ_i ≥ λ_{i + N - m}
```

---

### Лема 2 (Максимальний ступінь підграфа, Лема Хуана)
Нехай `H` — довільний індукований підграф гіперкуба `Q♁` на `m = 2ⁿ⁻¹ + 1` вершин. Тоді максимальний ступінь вершини в `H` (позначимо його `Δ(H)`) задовольняє нерівність:
```
Δ(H) ≥ √n
```

**Доведення:**

Нехай `V(H) ⊂ V(Q♁)` — множина вершин підграфа `H` розміру `m = 2ⁿ⁻¹ + 1`.
Нехай `B` — підматриця матриці `A⁽ⁿ⁾` розміру `m × m`, що відповідає вершинам з `V(H)`.
Застосуємо теорему Коші про переплетення для `i = 1` та `m = 2ⁿ⁻¹ + 1`:

```
μ₁(B) ≥ λ_{1 + 2ⁿ - (2ⁿ⁻¹ + 1)}(A⁽ⁿ⁾)   [за теоремою Коші]
      = λ_{2ⁿ⁻¹}(A⁽ⁿ⁾)                  [спрощення індексу: 2ⁿ - 2ⁿ⁻¹ = 2ⁿ⁻¹]
      = +√n                             [бо перші 2ⁿ⁻¹ власних значень A⁽ⁿ⁾ дорівнюють +√n]
```

Отже, найбільше власне значення підматриці `B` становить щонайменше `√n`:
```
μ_max(B) ≥ √n
```

З іншого боку, для будь-якої дійсної симетричної матриці `B` її найбільше власне значення `μ_max(B)` не перевищує максимальної модульної суми елементів у рядку:
```
μ_max(B) ≤ max_i ∑_j |B_{i, j}|
```
Оскільки елементи `B_{i, j}` дорівнюють `±1`, якщо між вершинами `i` та `j` є ребро в `H`, і `0` інакше, сума `∑_j |B_{i, j}|` дорівнює ступеню `deg_H(i)` вершини `i` в підграфі `H`.

Отже:
```
Δ(H) = max_i deg_H(i) ≥ μ_max(B) ≥ √n
```
Лему Хуана повністю доведено!

## 4. Зв'язок між чутливістю s(f) та алгебраїчним степенем deg(f)

Покажемо, як лема Хуана негайно дає фундаментальну нерівність для булевих функцій.

Нехай `f: {0, 1}ⁿ → {0, 1}` — тотальна булева функція.
Многочлен `P(x₁, ..., x♁)` є унікальним мультилінійним многочленом над `ℝ`, що збігається з `f(x)` на всіх входах `x ∈ {0, 1}ⁿ`. Його степінь називається `deg(f)`.

Нехай `k = deg(f)`. Це означає, що у многочлені `P` існує мононом степеня `k` (без обмеження загальності, нехай це мононом `x₁ · x₂ · ... · x_k`).

Зафіксуємо значення останніх `n - k` змінних так, щоб коефіцієнт при `x₁ ... x_k` залишався ненульовим. Отримаємо функцію `g: {0, 1}ᵏ → {0, 1}` зі степенем `deg(g) = k`.

З теорії булевих функцій відомо, що функція `g` з точним степенем `k` мусить мати принаймні `2ᵏ⁻¹` входів, на яких `g(x) = 1`, або принаймні `2ᵏ⁻¹` входів, на яких `g(x) = 0`.

Розглянемо підграф `H ⊂ Q_k`, утворений тими вершинами `x`, де `g(x)` дорівнює значенню з більшості. Тоді кількість вершин `|V(H)| ≥ 2ᵏ⁻¹`. Якщо `|V(H)| > 2ᵏ⁻¹` (тобто `|V(H)| ≥ 2ᵏ⁻¹ + 1`), за лемою Хуана існує вершина `x ∈ V(H)` зі ступенем `deg_H(x) ≥ √k`.

Для цієї вершини `x`, кожне ребро в `H` веде до іншої вершини з того самого підграфу `H`, а отже, сусідні вершини в `Q_k`, які НЕ належать до `H`, мають інше значення функції `g` verdict!
Кількість таких сусідів з іншим значенням `g` дорівнює `k - deg_H(x)`.

Застосувавши симетричні міркування до підграфа зі знаками `±1`, отримуємо:
```
s(g) ≥ √k = √(deg(f))
```

Оскільки чутливість початкової функції `s(f)` не менша за чутливість її звуження `s(g)` (`s(f) ≥ s(g)`), маємо фундаментальну **Теорему Хуана**:

```
s(f) ≥ √(deg(f))   ⟹   deg(f) ≤ s(f)²
```

## 5. Виведення ланцюжка нерівностей між заходами складності

Наведемо строгі математичні нерівності, що пов'язують усі заходи складності дерев рішень.

### 1. Блокова чутливість та складність сертифікатів:
Для будь-якого входу `x`, якщо `C(f, x)` — це розмір мінімального сертифіката, а `bs(f, x)` — блокова чутливість:
```
bs(f, x) ≤ C(f, x)   [кожен блок чутливості мусить перетинати будь-який 1-сертифікат]
```
З праці Нісана (1991) випливає квадратична верхня межа:
```
C(f) ≤ bs(f)²
```

### 2. Детермінована складність D(f) та блокова чутливість bs(f):
Нісан довів, що для будь-якої булевої функції:
```
D(f) ≤ C(f) · bs(f)
```
Підставивши `C(f) ≤ bs(f)²`, отримуємо знамените обмеження кубом:
```
D(f) ≤ bs(f)³
```

### 3. Блокова чутливість та степінь многочлена deg(f):
Нісан та Сегеді (1994) довели:
```
bs(f) ≤ 2 · (deg(f))²
```

### 4. Остаточний ланцюжок через чутливість s(f):
Підставивши теорему Хуана `deg(f) ≤ s(f)²` у нерівність Нісана — Сегеді:

```
bs(f) ≤ 2 · (deg(f))²
      ≤ 2 · (s(f)²)²
      = 2 · s(f)⁴
```

Тепер висловимо детерміновану складність `D(f)` прямо через просту чутливість `s(f)`:

```
D(f) ≤ bs(f)³
     ≤ (2 · s(f)⁴)³
     = 8 · s(f)¹²
```
*(Примітка: пізніші уточнення оптимізували цей показник степеня до `D(f) ≤ O(s(f)⁶)`).*

```
C(f) ≤ bs(f)²                     | Нісан (1991)           | Доведено

deg(f) ≤ s(f)²                    | Хао Хуан (2019)        | Доведено (Спектральне)
bs(f) ≤ 2 · s(f)⁴                 | Наслідок теореми Хуана | Доведено

```
