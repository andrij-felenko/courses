# 🧮 Простір конфігурацій лінійно-обмеженого автомата та межі PSPACE

Лінійно-обмежений автомат (LBA) займає особливе місце в ієрархії Хомського: на відміну від магазинних автоматів (Тип 2), він має повноцінний довільний доступ до всієї своєї пам'яті, проте, на відміну від універсальної машини Тюринга (Тип 0), його стрічка строго обмежена розміром вхідного слова. Саме це обмеження простору робить задачу розпізнавання мови алгоритмічно розв'язною, але підносить її обчислювальну складність до класу PSPACE-повних задач.

## Формальна модель автомата

Лінійно-обмежений автомат — це недетермінована машина Тюринга `M = (Q, Σ, Γ, δ, q₀, q_acc, q_rej, ⊢, ⊣)`, де:
- `Q` — скінченна множина станів керування;
- `Σ` — вхідний алфавіт;
- `Γ` — робочий стрічковий алфавіт, `Σ ⊂ Γ`;
- `⊢, ⊣ ∈ Γ \ Σ` — спеціальні лівий і правий граничні маркери;
- `q₀ ∈ Q` — початковий стан;
- `q_acc, q_rej ∈ Q` — стани прийняття та відхилення (`q_acc ≠ q_rej`);
- `δ: Q × Γ → P(Q × Γ × {L, R})` — функція переходів.

Головне структурне обмеження полягає в тому, що для вхідного слова `w = a₁a₂...aₙ` початкова конфігурація стрічки має вигляд `⊢ a₁a₂...aₙ ⊣`. Зчитувальна голівка машини `M` ніколи не виходить ліворуч за маркер `⊢` і праворуч за маркер `⊣`, а самі маркери не можуть бути перезаписані іншими символами. Таким чином, доступний робочий простір строго дорівнює `n` клітинкам (або `c · n` клітинкам для фіксованої константи `c ≥ 1`).

## Кількість конфігурацій та граф переходів

Конфігурація автомата `M` на слові довжини `n` повністю задається трійкою:
1. Поточний стан керування `q ∈ Q`.
2. Позиція зчитувальної голівки `p ∈ {1, 2, ..., n}`.
3. Вміст `n` клітинок стрічки, тобто рядок `u ∈ Γⁿ`.

Загальну кількість різних конфігурацій `N(n)` лінійно-обмеженого автомата на вході довжини `n` обчислюють за формулою добутку незалежних компонентів:

```
N(n)
= |Q| × n × |Γ|ⁿ      [добуток: стани × позиції голівки × варіанти стрічки]
```

Оскільки `|Q|` та `|Γ|` є фіксованими константами для конкретного автомата `M`, величина `N(n)` зростає експоненційно від довжини входу:

```
N(n)
= |Q| · n · |Γ|ⁿ
= 2^(log₂|Q| + log₂ n + n · log₂|Γ|)
= 2^(O(n))            [асимптотична оцінка розміру простору конфігурацій]
```

Граф конфігурацій `G_M(w) = (V, E)` будують так:
- Вершини `V` — це всі можливі конфігурації автомата розміру `n`, `|V| = N(n)`.
- Орієнтоване ребро `(C₁, C₂) ∈ E` існує тоді й лише тоді, коли автомат `M` може перейти з конфігурації `C₁` у конфігурацію `C₂` за один крок згідно з функцією `δ`.

## Розв'язність задачі належності (Membership Problem)

На відміну від універсальної машини Тюринга, лінійно-обмежений автомат не може перебирати нескінченну кількість різних станів стрічки. Якщо автомат робить понад `N(n)` кроків і не зупиняється, то за принципом Діріхле він обов'язково повторить якусь конфігурацію `C_k`. 

Оскільки переходи детермінованого або недетермінованого автомата залежать виключно від поточної конфігурації, повторення конфігурації означає зациклення. Будь-який шлях прийняття довжиною понад `N(n)` містить петлю, яку можна вирізати без втрати досяжності стану `q_acc`.

Звідси випливає фундаментальна теорема: задача перевірки, чи належить слово `w` мові `L(M)`, є алгоритмічно розв'язною.

Алгоритм розпізнавання:
1. Зафіксувати лічильник кроків `t = 0`.
2. Імітувати недетерміноване виконання `M` на вході `w`.
3. Якщо досягнуто стан `q_acc` за `t ≤ N(n)` кроків — повернути «слово прийнято».
4. Якщо минуло `N(n)` кроків, а `q_acc` не досягнуто на жодній гілці — повернути «слово відхилено».

## Теорема Севича та межі простору

Побудований граф конфігурацій має розмір `2^(O(n))`, тому прямий пошук у ширину (BFS) у пам'яті вимагав би експоненційного простору. Проте збереження однієї поточної конфігурації на стрічці вимагає лише `O(n)` біт:
- стан `q`: `O(1)` біт;
- позиція голівки `p`: `O(log n)` біт;
- вміст стрічки: `n · log₂|Γ| = O(n)` біт;
- лічильник кроків `t`: `log₂ N(n) = O(n)` біт.

Згідно з теоремою Севича (Savitch's Theorem, 1970), недетермінований алгоритм обходу графа, що використовує простір `S(n)`, можна змоделювати детермінованим алгоритмом у просторі `S²(n)`:

```
NSPACE(S(n)) ⊆ DSPACE(S²(n))
```

Для лінійно-обмеженого автомата `S(n) = n`, звідки:

```
NSPACE(n) ⊆ DSPACE(n²) ⊆ PSPACE
```

Доведення теореми Севича базується на рекурсивній функції досяжності `CAND_REACH(C₁, C₂, k)`, яка перевіряє, чи можна перейти з конфігурації `C₁` у конфігурацію `C₂` не більше ніж за `2^k` кроків. Алгоритм перебирає проміжну вершину `C_mid`:

```
CAND_REACH(C₁, C₂, k):
  якщо k = 0:
    повернути true, якщо C₁ = C₂ або (C₁ → C₂) є ребром у G_M(w)
  для кожної можливої конфігурації C_mid:
    якщо CAND_REACH(C₁, C_mid, k - 1) та CAND_REACH(C_mid, C₂, k - 1):
      повернути true
  повернути false
```

Глибина рекурсії дорівнює `log₂(N(n)) = O(n)`. На кожному рівні стека рекурсії зберігається одна конфігурація `C_mid` розміру `O(n)`. Загальний обсяг пам'яті детермінованого розпізнавача становить:

```
Space = Глибина × Пам'ять_на_рівень = O(n) × O(n) = O(n²)
```

## PSPACE-повнота задачі належності для CSL

Задача перевірки належності слова `w` контекстно-залежній мові `L(G)` є не просто розв'язною, а строго **PSPACE-повною**:
1. **Належність до PSPACE:** як показано вище, недетермінований LBA розпізнає мову в просторі `NSPACE(n) ⊆ DSPACE(n²) ⊆ PSPACE`.
2. **PSPACE-важкість:** до задачі розпізнавання LBA поліноміально зводиться будь-яка мова `A ∈ PSPACE`. Якщо мова `A` розпізнається детермінованою машиною Тюринга `M_A` у просторі `s(n) = n^k`, то для слова `x` довжини `n` робоча стрічка має довжину `m = n^k`. Побудуємо LBA `M'`, вхідним словом для якого є рядок `x` із доданими `m - n` спеціальними порожніми символами. Тоді `M'` працює у просторі, що строго дорівнює довжині вхідного розширеного слова `m`, тобто є повноцінним LBA.

Зокрема, канонічна PSPACE-повна задача істинності квантифікованих булевих формул (True Quantified Boolean Formulas, TQBF) зводиться до задачі розпізнавання LBA. LBA здатний по черзі підставляти значення `0` та `1` для кванторів `∀` та `∃`, повторно використовуючи ту саму ділянку стрічки довжини `O(n)` для обчислення істинності формули.

Це доводить, що задача аналізу контекстно-залежних мов є найскладнішою серед усіх задач, які можна розв'язати в поліноміальному обсязі пам'яті.

## Теорема Іммермана–Селепчені та замкненість CSL

Понад два десятиліття відкритим залишалося так зване перше питання Куроди (1964): чи замкнений клас контекстно-залежних мов щодо операції доповнення? Тобто чи є `NSPACE(n) = co-NSPACE(n)`?

У 1987 році Ніл Іммерман (Neil Immerman) та Роберт Селепчені (Róbert Szelepcsényi) незалежно дали ствердну відповідь, розробивши метод індуктивного підрахунку кількості досяжних вершин у графі конфігурацій.

Нехай `C₀` — початкова конфігурація LBA на слові `w`, а `V_d` — множина конфігурацій, досяжних із `C₀` за не більше ніж `d` кроків. Позначимо `c_d = |V_d|` — точну кількість таких вершин.

Алгоритм обчислює послідовність чисел `c₀, c₁, ..., c_{N(n)}` індуктивно:
1. **База:** `c₀ = 1` (множина `V₀ = {C₀}`).
2. **Індуктивний крок (обчислення `c_{d+1}` за відомим `c_d`):**
   - Ініціалізувати лічильник `c_{d+1} = 0`.
   - Для кожної конфігурації `C ∈ V`:
     - Перевірити недетерміновано, чи належить `C` до `V_{d+1}`. Для цього запустити підпрограму, яка перебирає рівно `c_d` вершин із множини `V_d`, вгадуючи для кожної шлях довжини `≤ d` від `C₀`.
     - Якщо знайдено хоча б одну вершину `C' ∈ V_d`, з якої `C` досяжна за `≤ 1` крок, збільшити лічильник `c_{d+1}` на 1.
3. **Перевірка недосяжності стану прийняття:**
   - Маючи фінальне число `c_max = c_{N(n)}` (загальну кількість досяжних конфігурацій), алгоритм перебирає всі конфігурації `C ∈ V`.
   - Для кожної з них перевіряє, чи є вона досяжною з `C₀` за час `≤ N(n)`. Алгоритм підраховує кількість знайдених досяжних вершин. Якщо ця кількість досягає `c_max`, і при цьому жодна зі знайдених конфігурацій не є конфігурацією прийняття (`q ≠ q_acc`), автомат переходить у стан прийняття доповнення.

Оскільки всі змінні алгоритму (лічильники `c_d`, поточні вершини `C, C'`) займають пам'ять `O(log |V|) = O(n)`, алгоритм працює в недетермінованому лінійному просторі.

Це довело теорему:

```
NSPACE(n) = co-NSPACE(n)
```

Звідси випливає фундаментальний наслідок для ієрархії Хомського: клас контекстно-залежних мов (Тип 1) замкнений щодо всіх булевих операцій — об'єднання, перетину та доповнення.

## Нерозв'язність проблеми порожнечі для LBA

Хоча задача належності конкретного слова для LBA розв'язна, усі глобальні структурні властивості мов Типу 1 є алгоритмічно нерозв'язними.

Доведемо нерозв'язність задачі порожнечі (`L(M) = ∅?` для довільного LBA `M`) зведенням від проблеми зупинки довільної машини Тюринга `T` на порожній стрічці.

Протокол обчислення (computation history) машини Тюринга `T` — це послідовність конфігурацій:

```
w_trace = # C₀ # C₁ # C₂ # ... # C_k #
```

де `C₀` — початкова конфігурація `T` на порожній стрічці, `C_k` — конфігурація зі станом зупинки `q_halt`, а кожен блок `C_{i+1}` утворюється з блоку `C_i` застосуванням одного кроку переходів машини `T`.

Побудуємо LBA `M_verify`, який приймає вхідне слово `w_trace` тоді й лише тоді, коли воно є коректним протоколом зупинки машини `T`:
1. Перевірити, що перший блок `C₀` відповідає стану `q₀` на порожній стрічці.
2. Перевірити для кожного `i`, що конфігурація `C_{i+1}` слідує з `C_i`. Для цього голівка LBA рухається між відповідними комірками сусідніх блоків, позначаючи перевірені символи. Оскільки довжина блоку `C_{i+1}` відрізняється від `C_i` щонайбільше на одну клітинку, вся перевірка локальних переходів виконується суто в межах самого рядка `w_trace`.
3. Перевірити, що останній блок `C_k` містить стан `q_halt`.

Оскільки `M_verify` ніколи не виходить за межі вхідного слова `w_trace`, він є лінійно-обмеженим автоматом.

Звідси:
- Якщо машина Тюринга `T` зупиняється на порожній стрічці, то існує скінченний рядок `w_trace`, який `M_verify` прийме, отже `L(M_verify) ≠ ∅`.
- Якщо машина `T` зациклюється, коректного скінченного протоколу зупинки не існує, і `L(M_verify) = ∅`.

Якби існував алгоритм перевірки порожнечі для лінійно-обмежених автоматів, ми могли б алгоритмічно розв'язати проблему зупинки машини Тюринга. Оскільки проблема зупинки нерозв'язна, проблема порожнечі для мов Типу 1 також є алгоритмічно нерозв'язною.

Аналогічно, через побудову протоколів помилкових обчислень доводиться нерозв'язність проблеми універсальності (`L(M) = Σ*`) та проблеми еквівалентності (`L(M₁) = L(M₂)`).

## Відкрита проблема: Чи є DSPACE(n) = NSPACE(n)?

Друге фундаментальне питання Куроди (1964), відоме в теорії складності як **проблема LBA**, залишається нерозв'язаним і сьогодні:
*Чи є кожен недетермінований лінійно-обмежений автомат еквівалентним певному детермінованому лінійно-обмеженому автомату?* Тобто:

```
DSPACE(n) =? NSPACE(n)
```

Це просторовий аналог великої проблеми `P =? NP`. Теорема Севича дає лише квадратичне розширення `NSPACE(n) ⊆ DSPACE(n²)`, але не відповідає на питання, чи можна усунути недетермінізм у лінійному просторі `O(n)`. Якщо `DSPACE(n) = NSPACE(n)`, це означатиме, що будь-яку контекстно-залежну мову можна детерміновано розпізнати без додаткового масштабування пам'яті.
