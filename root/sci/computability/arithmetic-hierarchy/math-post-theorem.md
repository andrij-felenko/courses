# 🧮 Теорема Поста та математичний апарат арифметичної ієрархії

Математичний апарат арифметичної ієрархії базується на глибокому зв'язку між синтаксичною префіксною формою логічних формул першого порядку та алгоритмічною теорією відносної обчислюваності з оракулами. У цій вставці наведено точні алгебраїчні формулювання класів, математичний аналіз механізму згортання кванторів через функцію парування Кантора, детальний вивід теореми Кліні про нормальну форму та повне доведення теореми Поста.

## 1. Формально-синтаксичне визначення класів ієрархії

Розглянемо мову арифметики Пеано першого порядку, що містить константи `0, 1`, операції додавання `+`, множення `·` та відношення рівності `=`. 

Нехай `R(x, y₁, y₂, ..., y♁)` — розв'язний (рекурсивний) предикат над натуральними числами `ℕ`, тобто такий предикат, що його характеристична функція є обчислюваною за Тюрингом за скінченний час для будь-якого фіксованого набору вхідних аргументів.

Предикат `P(x)` належить до одного з трьох фундаментальних класів арифметичної ієрархії:

- **Клас `Σ♁⁰` (для `n ≥ 1`):** Предикат `P(x)` належить до `Σ♁⁰`, якщо він виражається логічною формулою з `n` чергуваннями необмежених кванторів, починаючи з квантора існування `∃`:
```
P(x) ≡ ∃y₁ ∀y₂ ∃y₃ ... Q♁ y♁ R(x, y₁, y₂, ..., y♁)
```

- **Клас `Π♁⁰` (для `n ≥ 1`):** Предикат `P(x)` належить до `Π♁⁰`, якщо він виражається логічною формулою з `n` чергуваннями необмежених кванторів, починаючи з квантора загальності `∀`:
```
P(x) ≡ ∀y₁ ∃y₂ ∀y₃ ... Q♁ y♁ R(x, y₁, y₂, ..., y♁)
```

- **Клас `Δ♁⁰` (для `n ≥ 1`):** Клас предикатів, які одночасно мають подання у формі `Σ♁⁰` та у формі `Π♁⁰`:
```
Δ♁⁰ = Σ♁⁰ ∩ Π♁⁰
```

Для базісного випадку `n = 0` покладають `Δ₀⁰ = Σ₀⁰ = Π₀⁰` як клас усіх обчислюваних (рекурсивних) множин, чиї дефініційні формули містять лише обмежені квантори виду `∃z ≤ t` та `∀z ≤ t`.

## 2. Теорема про згортання однорідних кванторів та парування Кантора

У довільних логічних формулах поспіль можуть іти декілька кванторів одного типу: `∃y₁ ∃y₂ ... ∃yₖ`. Для зведення формули до канонічної префіксної форми необхідно довести, що блок з `k` однакових кванторів можна алгоритмічно стиснути у єдиний квантор того ж типу.

Згортання здійснюється за допомогою поліноміальної бієктивної обчислюваної функції парування Гіорга Кантора (англ. *Cantor pairing function*) `π: ℕ × ℕ → ℕ`:

```
π(a, b) = ⟨a, b⟩ = ((a + b) · (a + b + 1)) / 2 + b
```

### Властивості функції парування Кантора

1. **Бієктивність:** Функція `π` встановлює взаємно-однозначну відповідність між множиною пар natural чисел `ℕ × ℕ` та множиною `ℕ`.
2. **Алгоритмічність обернених проекцій:** Існують примітивно-рекурсивні функції `π₁(Y)` та `π₂(Y)` такі, що для будь-яких `a, b ∈ ℕ`:
```
π₁(⟨a, b⟩) = a ,   π₂(⟨a, b⟩) = b
```
Вивід обернених проекцій здійснюється через розв'язання квадратного рівняння:
```
w = ⌊(√(8Y + 1) - 1) / 2⌋
t = (w² + w) / 2
π₂(Y) = Y - t
π₁(Y) = w - π₂(Y)
```

Завдяки бієктивності `π`, довільне логічне твердження про існування пари натуральних чисел еквівалентне існуванню їхнього коду Кантора:

```
∃y₁ ∃y₂ R(x, y₁, y₂) 
= ∃Y R(x, π₁(Y), π₂(Y))                [парування Кантора: Y = ⟨y₁, y₂⟩]
= ∃Y R'(x, Y)                         [R' — також обчислювальний предикат]
```

Для `k` однорідних кванторів парування застосовується ітеративно: `⟨⟨y₁, y₂⟩, ..., yₖ⟩`. Аналогічно згортаються сусідні квантори загальності через заперечення Де Моргана:

```
∀z₁ ∀z₂ R(x, z₁, z₂)
= ¬(∃z₁ ∃z₂ ¬R(x, z₁, z₂))             [двоїстість Де Моргана]
= ¬(∃Z ¬R(x, π₁(Z), π₂(Z)))            [парування Кантора: Z = ⟨z₁, z₂⟩]
= ∀Z R(x, π₁(Z), π₂(Z))               [двоїстість Де Моргана]
```

Отже, будь-яка арифметична формула з довільною кількістю кванторів еквівалентна формулі зі строгим чергуванням одиничних кванторів `∃` та `∀`.

## 3. Теорема Кліні про нормальну форму

Фундаментальною основою для рівня `Σ₁⁰` є T-предикат Кліні `T(e, x, s)`, який стверджує: *«Машина Тюринга з кодом e на вхідному значенні x зупиняється за точно s кроків, і запис її обчислювальної траєкторії кодується числовим значенням s»*.

Предикат `T(e, x, s)` є повністю обчислюваним без жодного необмеженого квантора (`T ∈ Δ₀⁰`), оскільки симуляція виконання машини Тюринга протягом `s` кроків є детермінованим алгоритмом.

Теорема Кліні про нормальну форму стверджує, що для будь-якої частково обчислюваної функції `φₑ(x)` існує примітивно-рекурсивна функція видобутку результату `U(s)` така, що:

```
φₑ(x) = U(μs T(e, x, s))
```
де `μs` позначує оператор пошуку найменшого натурального числа `s`.

Звідси множина `Wₑ = dom(φₑ)` (область визначення `e`-ї машини Тюринга) подається у канонічній формі `Σ₁⁰`:

```
x ∈ Wₑ ⟺ ∃s T(e, x, s)
```

Це доводить, що клас `Σ₁⁰` точно збігається з класом усіх рекурсивно перелічуваних (r.e.) множин.

## 4. Повне математичне доведення теореми Поста

Теорема Еміля Поста встановлює фундаментальну еквівалентність між кількістю кванторів логічного префікса та ітераціями стрибка Тюринга `0⁽ⁿ⁾`.

> **Теорема (Еміль Пост, 1948).** Для будь-якого `n ≥ 0`:
> 1. Множина `A ⊆ ℕ` належить класу `Σ♁₊₁⁰` тоді й лише тоді, коли `A` є рекурсивно перелічуваною відносно оракула `0⁽ⁿ⁾` (тобто `A ∈ r.e.(0⁽ⁿ⁾)`).
> 2. Множина `A ⊆ ℕ` належить класу `Π♁₊₁⁰` тоді й лише тоді, коли її доповнення `Ā` є рекурсивно перелічуваним відносно `0⁽ⁿ⁾`.
> 3. Множина `A ⊆ ℕ` належить класу `Δ♁₊₁⁰` тоді й лише тоді, коли `A` є Тюринг-обчислюваною з оракулом `0⁽ⁿ⁾` (тобто `A ≤ₜ 0⁽ⁿ⁾`).

### Доведення за індукцією по `n`

#### Базис індукції (`n = 0`)
За означенням `0⁽⁰⁾ = ∅` (порожній оракул).
- `A ∈ Σ₁⁰ ⟺ x ∈ A ⟺ ∃s T(e, x, s)` для деякого `e`. Це за означенням означає, що `A` є рекурсивно перелічуваною множиною (r.e. відносно `∅`).
- `A ∈ Δ₁⁰ = Σ₁⁰ ∩ Π₁⁰` тоді й лише тоді, коли і `A`, і `Ā` є рекурсивно перелічуваними. За теоремою Поста для розв'язних множин це еквівалентно тому, що `A` є рекурсивною (обчислюваною за Тюрингом без оракула, `A ≤ₜ ∅`).

#### Індукційний крок (`n to n + 1`)
Припустимо, що теорема є справедливою для рівня `n`. Доведемо її для `n + 1`.

**(Пряме доведення `Σ♁₊₁⁰ ⟹ r.e.(0⁽ⁿ⁾)`)**
Нехай `A ∈ Σ♁₊₁⁰`. За означенням арифметичної ієрархії:

```
x ∈ A ⟺ ∃y R(x, y)
```
де предикат `R(x, y)` належить до класу `Π♁⁰`.

Розглянемо множину `B = {(x, y) ∣ ¬R(x, y)}`. За властивістю заперечення, `¬R(x, y)` належить до класу `Σ♁⁰`.
За індукційним припущенням, оскільки `B ∈ Σ♁⁰`, множина `B` є рекурсивно перелічуваною відносно оракула `0⁽ⁿ⁻¹⁾`.

Стрибок Тюринга `0⁽ⁿ⁾ = (0⁽ⁿ⁻¹⁾)'` за означенням розв'язує проблему зупинки для оракульних машин з оракулом `0⁽ⁿ⁻¹⁾`. Отже, оракул `0⁽ⁿ⁾` за один крок відповіді розв'язує будь-яку проблему належності до r.e.(0⁽ⁿ⁻¹⁾) множини.

Це означає, що предикат `¬R(x, y)` є повністю обчислюваним з оракулом `0⁽ⁿ⁾` (тобто `¬R(x, y) ≤ₜ 0⁽ⁿ⁾`), а отже і сам предикат `R(x, y)` є обчислюваним з оракулом `0⁽ⁿ⁾`.

Отже, формула `x ∈ A ⟺ ∃y R(x, y)` перетворюється на перелік існування `y` для предиката `R`, який є обчислюваним відносно оракула `0⁽ⁿ⁾`. За дефініцією оракульних машин Тюринга це означає, що `A` є рекурсивно перелічуваною відносно оракула `0⁽ⁿ⁾`.

**(Обернене доведення `r.e.(0⁽ⁿ⁾) ⟹ Σ♁₊₁⁰`)**
Нехай `A` є рекурсивно перелічуваною відносно оракула `0⁽ⁿ⁾`. Тоді існує оракульна машина Тюринга `Mᵉ` така, що:

```
x ∈ A ⟺ ∃s (Mᵉ⁰⁽ⁿ⁾(x) зупиняється за s кроків)
```

Запит машини до оракула `0⁽ⁿ⁾` тривалістю `s` кроків може поставити не більше ніж `s` запитань виду *«чи числа q₁, ..., qₖ належать до 0⁽ⁿ⁾?»*.
Оскільки `0⁽ⁿ⁾` є `Σ♁⁰`-повного множиною (за індукційним припущенням), належність `q ∈ 0⁽ⁿ⁾` виражається `Σ♁⁰`-формулою, а неналежність `q ∉ 0⁽ⁿ⁾` — `Π♁⁰`-формулою.

Згортаючи всі оракульні запити та відповіді за `s` кроків у єдину префіксну форму, ми отримуємо формулу з одним додатковим квантором `∃` над `Π♁⁰`-предикатом, що дає формулу класу `Σ♁₊₁⁰`.

**(Доведення для еквівалентності класу `Δ♁₊₁⁰`)**
```
A ∈ Δ♁₊₁⁰
= A ∈ Σ♁₊₁⁰  ∧  A ∈ Π♁₊₁⁰             [означення Δ♁₊₁⁰]
= A ∈ r.e.(0⁽ⁿ⁾)  ∧  Ā ∈ r.e.(0⁽ⁿ⁾)    [попередній пункт теореми Поста]
= A ≤ₜ 0⁽ⁿ⁾                           [теорема Кліні-Поста про відносну розв'язність]
```

Теорему Поста доведено повністю для всіх `n ≥ 0`. ∎

## 5. Властивості замкненості класів та логічна алгебра

Класи арифметичної ієрархії мають наступні строгі алгебраїчні властивості замкненості відносно логічних та арифметичних операцій:

1. **Замкненість відносно скінченних кон'юнкцій та диз'юнкцій:**
   Якщо `P(x) ∈ Σ♁⁰` та `Q(x) ∈ Σ♁⁰`, то їхні логічні зв'язки `(P ∧ Q)` та `(P ∨ Q)` також належать до класу `Σ♁⁰`. Аналогічне правило діє для класу `Π♁⁰`.
2. **Двоїстість заперечення:**
   Предикат `P(x)` належить до `Σ♁⁰` тоді й лише тоді, коли його заперечення `¬P(x)` належить до `Π♁⁰`.
3. **Замкненість відносно обмежених кванторів:**
   Якщо `P(x, z) ∈ Σ♁⁰`, то предикати з обмеженими кванторами `∃z ≤ t P(x, z)` та `∀z ≤ t P(x, z)` також належать до класу `Σ♁⁰`. Обмежені квантори не міняють рівень складності формули.
4. **Замкненість відносно підстановки обчислювальних функцій:**
   Якщо `P(y) ∈ Σ♁⁰`, а `f(x)` є обчислюваною функцією, то предикат `Q(x) ≡ P(f(x))` належить до того ж класу `Σ♁⁰`.
