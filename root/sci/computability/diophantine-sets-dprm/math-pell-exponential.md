# 🧮 Алгебра рівнянь Пелля та моделювання експоненти

Спроба безпосередньо виразити відношення піднесення до степеня `p = qʳ` через многочлени наштовхується на фундаментальний алгебраїчний бар'єр: будь-який многочлен `P(x₁, ..., xₘ)` степеня `k` зростає зі швидкістю, що не перевищує степеневої функції `O(Nᵏ)`, тоді як експонента `qʳ` випереджає будь-який многочлен фіксованого степеня при зростанні показника `r`. Щоб зафіксувати експоненційну залежність засобами алгебраїчних рівнянь над кільцем цілих чисел `ℤ`, необхідно використати не значення самого многочлена, а **множину цілочисельних розв'язків** нелінійного рівняння, яка розбігається з експоненційною швидкістю вздовж нескінченної гілки гіперболи.

Основним інструментом такого моделювання є спеціальний клас квадратичних діофантових рівнянь — **рівняння Пелля** (англ. *Pell's equation*) та споріднені рекурентні послідовності чисел Фібоначчі.

## 1. Рівняння Пелля та рекурентні послідовності

Нехай `d > 1` — ціле число, яке не є повним квадратом (у наших побудовах ми зазвичай обираємо `d = a` для цілого параметра `a > 1`, тому коефіцієнт `d² − 1` гарантовано є додатним і вільним від виродження). Розглянемо класичне рівняння другого порядку від двох невідомих `x` та `y`:

```
x² − (d² − 1)·y² = 1
```

Це рівняння описує гіперболу на дійсній площині з асимптотами `x = ±√(d² − 1)·y`. Усі його невід'ємні цілочисельні розв'язки `(x, y) ∈ ℕ × ℕ` утворюють зліченну дискретну послідовність пар `(xₙ(d), yₙ(d))` для `n = 0, 1, 2, ...`

Алгебраїчна структура цих розв'язків розкривається у квадратичному числовому полі `ℚ(√(d² − 1))` та його кільці цілих `ℤ[√(d² − 1)]`. Кожен розв'язок відповідає цілому степеню фундаментальної одиниці числового кільця `ε = d + √(d² − 1)`:

```
xₙ(d) + yₙ(d)·√(d² − 1) = (d + √(d² − 1))ⁿ
```

Застосовуючи автоморфізм спряження `√(d² − 1) ↦ −√(d² − 1)`, одержуємо спряжене рівняння:

```
xₙ(d) − yₙ(d)·√(d² − 1) = (d − √(d² − 1))ⁿ
```

Перемножуючи ці дві рівності почленно, переконуємося в тому, що кожна пара дійсно є розв'язком:

```
(xₙ + yₙ√(d² − 1)) · (xₙ − yₙ√(d² − 1))
= xₙ² − (d² − 1)·yₙ²                                [різниця квадратів]
= ((d + √(d² − 1)) · (d − √(d² − 1)))ⁿ              [властивість степеня]
= (d² − (d² − 1))ⁿ                                  [обчислення добутку основ]
= 1ⁿ = 1                                            [тотожність]
```

Додаючи та віднімаючи спряжені рівності, отримуємо замкнені аналітичні формули для компонент (аналог формули Біне для чисел Фібоначчі):

```
xₙ(d) = ((d + √(d² − 1))ⁿ + (d − √(d² − 1))ⁿ) / 2
yₙ(d) = ((d + √(d² − 1))ⁿ − (d − √(d² − 1))ⁿ) / (2·√(d² − 1))
```

### Матрична форма та рекурентні співвідношення
Застосовуючи множення на фундаментальну одиницю:

```
xₙ₊₁(d) + yₙ₊₁(d)·√(d² − 1)
= (xₙ(d) + yₙ(d)·√(d² − 1)) · (d + √(d² − 1))                   [множення на фундаментальну одиницю]
= (d·xₙ(d) + (d² − 1)·yₙ(d)) + (xₙ(d) + d·yₙ(d))·√(d² − 1)      [розкриття дужок у розширенні ℤ[√(d² − 1)]]
```

Прирівнюючи раціональну та ірраціональну частини, отримуємо лінійну систему переходу в матричному вигляді:

```
┌           ┐   ┌             ┐ⁿ   ┌   ┐
│  xₙ(d)    │   │  d   d² − 1 │    │ 1 │
│           │ = │             │  · │   │
│  yₙ(d)    │   │  1     d    │    │ 0 │
└           ┘   └             ┘    └   ┘
```

Характеристичний многочлен матриці переходу дорівнює `det(λ·I − M) = λ² − 2d·λ + 1 = 0`. За теоремою Гамільтона–Келі обидві координати задовольняють однакове лінійне однорідне рекурентне рівняння другого порядку:

```
x₀(d) = 1,     x₁(d) = d,     xₙ₊₁(d) = 2d·xₙ(d) − xₙ₋₁(d)
y₀(d) = 0,     y₁(d) = 1,     yₙ₊₁(d) = 2d·yₙ(d) − yₙ₋₁(d)
```

### Числовий приклад розгортання послідовності
Для базового випадку `d = 2` коефіцієнт рівняння Пелля дорівнює `d² − 1 = 3`, а рівняння набуває вигляду `x² − 3y² = 1`. Рекурентні правила мають вигляд `xₙ₊₁ = 4·xₙ − xₙ₋₁` та `yₙ₊₁ = 4·yₙ − yₙ₋₁`:

```
 n │ xₙ(2) │ yₙ(2) │ Перевірка: xₙ² − 3·yₙ² = 1
───┼───────┼───────┼───────────────────────────
 0 │   1   │   0   │ 1² − 3·0² = 1 − 0 = 1
 1 │   2   │   1   │ 2² − 3·1² = 4 − 3 = 1
 2 │   7   │   4   │ 7² − 3·4² = 49 − 48 = 1
 3 │  26   │  15   │ 26² − 3·15² = 676 − 675 = 1
 4 │  97   │  56   │ 97² − 3·56² = 9409 − 9408 = 1
 5 │ 362   │ 209   │ 362² − 3·209² = 131044 − 131043 = 1
```

Значення `yₙ(2)` зростають майже в чотири рази на кожному кроці: `0, 1, 4, 15, 56, 209, 780, 2911, ...`, демонструючи чистий експоненційний розліт уздовж цілочисельної ґратки.

## 2. Зв'язок із числами Фібоначчі та тотожністю Кассіні

Історично перший доказ діофантовості експоненти Юрій Матіясевич побудував не на загальних рівняннях Пелля, а на класичній послідовності чисел Фібоначчі `F₀ = 0, F₁ = 1, F₂ = 1, F₃ = 2, F₄ = 3, F₅ = 5, F₆ = 8, F₇ = 13, ...`, яка задовольняє рекурентність `Fₙ₊₁ = Fₙ + Fₙ₋₁`.

Сусідні члени послідовності Фібоначчі задовольняють знамениту **тотожність Кассіні** (опубліковану Джованні Доменіко Кассіні у 1680 році):

```
Fₙ₊₁ · Fₙ₋₁ − Fₙ² = (−1)ⁿ
```

Підставляючи `Fₙ₊₁ = Fₙ + Fₙ₋₁` у тотожність Кассіні, отримуємо квадратичну залежність між двома послідовними числами `x = Fₙ₊₁` та `y = Fₙ`:

```
(x − y)·x − y² = x² − x·y − y² = (−1)ⁿ
```

Підносячи обидві частини до квадрата для усунення знакової невизначеності `(−1)ⁿ`:

```
(x² − x·y − y²)² = 1
```

Це рівняння має дивовижну властивість: **його невід'ємними цілочисельними розв'язками `(x, y)` є виключно пари сусідніх чисел Фібоначчі `(Fₙ₊₁, Fₙ)`**.

Числа Фібоначчі зростають зі швидкістю золотого перетину `φ = (1 + √5)/2 ≈ 1.6180339`:

```
Fₙ = (φⁿ − (−φ)⁻ⁿ) / √5
```

Застосовуючи властивості подільності чисел Фібоначчі, зокрема те, що `Fₘ² | Fₙ ⇔ m·Fₘ | n`, Матіясевич показав, що відношення `v = F₂ᵤ` повністю задовольняє гіпотезу Джулії Робінсон. Згодом для спрощення викладок наукова спільнота перейшла до рівнянь Пелля `x² − (d² − 1)y² = 1`, які є прямим узагальненням цієї ідеї на довільну основу `d ≥ 2`.

## 3. Асимптотика та фундаментальні леми про подільність

Послідовність `yₙ(d)` зростає як геометрична прогресія зі знаменником `α = d + √(d² − 1)`. Оскільки `√(d² − 1) = d·√(1 − 1/d²) = d − 1/(2d) − ...`, при `d ≥ 2` виконуються строгі двосторонні нерівності `2d − 1 < α < 2d`.

Звідси методом математичної індукції виводяться точні межі зростання компонент:

```
(2d − 1)ⁿ ≤ yₙ₊₁(d) ≤ (2d)ⁿ
dⁿ ≤ xₙ(d) ≤ (2d)ⁿ
```

Для побудови діофантового предикату Юрій Матіясевич встановив низку фундаментальних властивостей подільності, які дозволяють зафіксувати тотожність розв'язків без звернення до неалгебраїчних функцій.

### Лема 1 (Взаємна простота сусідів та компонент)
Для будь-якого `n ≥ 0` та `d ≥ 2`:
```
НСД(xₙ(d), yₙ(d)) = 1
НСД(yₙ(d), yₙ₊₁(d)) = 1
```
*Доведення.* Якщо простий дільник `p` ділить і `xₙ`, і `yₙ`, то `p` ділить різницю `xₙ² − (d² − 1)yₙ² = 1`, що неможливо. Якщо ж `p` ділить `yₙ` та `yₙ₊₁`, то за рекурентністю `yₙ₊₁ = xₙ + d·yₙ` маємо `p | xₙ`, що суперечить взаємній простоті `xₙ` і `yₙ`.

### Лема 2 (Адитивні теореми для індексів)
Для будь-яких цілих індексів `m, n ≥ 0`:
```
xₘ₊ₙ = xₘ·xₙ + (d² − 1)·yₘ·yₙ
yₘ₊ₙ = xₘ·yₙ + yₘ·xₙ
xₘ₋ₙ = xₘ·xₙ − (d² − 1)·yₘ·yₙ
yₘ₋ₙ = yₘ·xₙ − xₘ·yₙ    (при m ≥ n)
```
*Доведення.* Твердження безпосередньо випливає з тотожності `εᵐ⁺ⁿ = εᵐ · εⁿ` у кільці `ℤ[√(d² − 1)]` шляхом прирівнювання коефіцієнтів при раціональній частині та при корені `√(d² − 1)`.

### Лема 3 (Лінійна подільність індексів)
Для довільних натуральних чисел `m ≥ 1` та `n ≥ 1`:
```
yₘ(d) | yₙ(d)  ⇔  m | n
```
*Доведення.* 
Нехай `n = q·m + r`, де `0 ≤ r < m`. Застосовуючи адитивну формулу для `y_{q·m + r}`:

```
y_{q·m + r} = y_{q·m}·xᵣ + x_{q·m}·yᵣ
```

За індукцією за `q` легко довести, що `yₘ | y_{q·m}` для будь-якого `q`. Тоді:

```
yₙ ≡ x_{q·m} · yᵣ (mod yₘ)
```

Оскільки `НСД(x_{q·m}, y_{q·m}) = 1` та `yₘ | y_{q·m}`, маємо `НСД(x_{q·m}, yₘ) = 1`. Отже, умова `yₘ | yₙ` еквівалентна умові `yₘ | yᵣ`. Але оскільки `0 ≤ r < m`, за строгим зростанням послідовності `0 ≤ yᵣ < yₘ`. Єдине можливе значення — це `yᵣ = 0`, що означає `r = 0`. Тобто `m | n`.

### Лема 4 (Квадратична подільність індексів — ядро методу Матіясевича)
Для будь-яких `m, k ≥ 1`:
```
yₘ²(d) | yₙ(d)  ⇔  m·yₘ(d) | n
```
*Доведення.* 
Розкладемо біном `(xₘ + yₘ√(d² − 1))ᵏ` у кільці `ℤ[√(d² − 1)]`:

```
yₘₖ(d)
= ∑ [j=0..(k-1)/2] C(k, 2j+1) · xₘᵏ⁻²ʲ⁻¹ · yₘ²ʲ⁺¹ · (d² − 1)ʲ
= k · xₘᵏ⁻¹ · yₘ + C(k, 3) · xₘᵏ⁻³ · yₘ³ · (d² − 1) + ...
```

Виносячи спільні множники за дужки:

```
yₘₖ(d) = k · xₘᵏ⁻¹ · yₘ + yₘ³ · R
```

де `R` — деяке ціле число. Розділимо обидві частини рівності на `yₘ`:

```
yₘₖ(d) / yₘ = k · xₘᵏ⁻¹ + yₘ² · R
```

Звідси випливає фундаментальне модульне порівняння:

```
yₘₖ(d) / yₘ ≡ k · xₘᵏ⁻¹ (mod yₘ²)
```

Умова `yₘ² | yₘₖ` означає, що ліва частина ділиться на `yₘ`, тобто `k · xₘᵏ⁻¹ ≡ 0 (mod yₘ)`. Але оскільки `НСД(xₘ, yₘ) = 1`, степінь `xₘᵏ⁻¹` не має спільних дільників з `yₘ`. Отже, умова виконується тоді й тільки тоді, коли `yₘ | k`. Покладаючи `k = j · yₘ`, отримуємо загальний індекс `n = m · k = m · j · yₘ`, що свідчить про подільність `n` на `m · yₘ`.

### Лема 5 (Зведення індексу за модулем d − 1)
Оскільки `d ≡ 1 (mod d − 1)`, рекурентне співвідношення `yₙ₊₁ = 2d·yₙ − yₙ₋₁` за модулем `d − 1` набуває вигляду:

```
yₙ₊₁(d) ≡ 2·1·yₙ(d) − yₙ₋₁(d) = 2·yₙ(d) − yₙ₋₁(d) (mod d − 1)
```

Це рівняння описує звичайну арифметичну прогресію. Враховуючи початкові умови `y₀(d) = 0` та `y₁(d) = 1`:

```
yₙ(d) ≡ n (mod d − 1)
```

Аналогічно для координати `x`: `x₀ = 1, x₁ = d ≡ 1`, звідки:

```
xₙ(d) ≡ 1 (mod d − 1)
```

Це порівняння є критично важливим: воно дозволяє дістати точне значення індексу `n` безпосередньо з чисельного значення розв'язку `yₙ(d)` за модулем `d − 1`.

## 4. Повна діофантова система для відношення y = yₙ(a)

Використовуючи доведені леми, Юрій Матіясевич побудував систему з десяти одночасних алгебраїчних умов від параметрів `(a, n, y)` та шести допоміжних невідомих `(x, u, v, s, t, b)`.

Система має такий вигляд:

```
(1)   x² − (a² − 1)·y² = 1
(2)   u² − (a² − 1)·v² = 1
(3)   s² − (b² − 1)·t² = 1
(4)   v > 0
(5)   y ≤ v
(6)   v² | t
(7)   b ≡ 1 (mod 4·v·y)
(8)   b ≡ a (mod u)
(9)   s ≡ x (mod u)
(10)  t ≡ n (mod 4·y)
(11)  n ≤ y
```

### Алгебраїчний механізм дії системи

Розберемо послідовно, як кожне рівняння звужує множину допустимих значень змінних:

1. **Рівняння (1) та (2)** гарантують, що пари `(x, y)` та `(u, v)` є точними розв'язками рівняння Пелля для основи `a`. Тобто існують невід'ємні цілі індекси `i` та `k`, такі що:
   ```
   x = xᵢ(a),   y = yᵢ(a)
   u = xₖ(a),   v = yₖ(a)
   ```
2. **Нерівності (4) та (5)** вимагають `0 < yᵢ(a) ≤ yₖ(a)`. Оскільки при `a ≥ 2` послідовність `yₙ(a)` строго зростає з індексом `n`, це задає строге обмеження `1 ≤ i ≤ k`.
3. **Рівняння (3)** стверджує, що пара `(s, t)` є розв'язком рівняння Пелля для деякої нової, набагато більшої основи `b`:
   ```
   s = xₘ(b),   t = yₘ(b)  для деякого цілого m ≥ 0
   ```
4. **Умова подільності (6)** `v² | t` означає `yₖ²(a) | yₘ(b)`. За Лемою 4 це змушує індекс `m` бути кратним добутку `k · yₖ(a)`:
   ```
   m = j · k · v = j · k · yₖ(a)
   ```
   Зокрема, `m` є кратним `2k` (якщо обрати парний дільник) або `k`.
5. **Конгруенції (8) та (9)** пов'язують розв'язки для різних основ `a` та `b`. Оскільки `b ≡ a (mod u)`, за Лемою про збереження порівняння основ маємо:
   ```
   s = xₘ(b) ≡ xₘ(a) (mod u)
   ```
   Але `u = xₖ(a)`. Відомо, що послідовність `xₘ(a)` за модулем `xₖ(a)` є періодичною: вона занулюється та повторює свої значення з періодом `2k`. Точніше:
   ```
   xₘ(a) ≡ ± x_{m mod 2k}(a) (mod xₖ(a))
   ```
   Поєднуючи це з умовою (9) `s ≡ x (mod u)`, де `x = xᵢ(a)`, отримуємо, що `m` зобов'язаний задовольняти конгруенцію:
   ```
   m ≡ ± i (mod 2k)
   ```
6. **Конгруенції (7) та (10)** вилучають індекс `n`. Згідно з умовою (7), `b ≡ 1 (mod 4vy)`. За Лемою 5 про залишок за основою:
   ```
   t = yₘ(b) ≡ m (mod b − 1)  ⇒  t ≡ m (mod 4vy)  ⇒  t ≡ m (mod 4y)
   ```
   Порівнюючи це з умовою (10) `t ≡ n (mod 4y)`, отримуємо:
   ```
   m ≡ n (mod 4y)
   ```
7. **Фінальний стиск інтервалу**:
   Маємо одночасно `m ≡ ± i (mod 2k)` та `m ≡ n (mod 4y)`. Оскільки `i ≤ y` та `n ≤ y`, різниця між `n` та `i` строго обмежена величиною `2y`. Водночас модуль `4y` перевершує будь-яке можливе відхилення. Єдиним числом у цьому діапазоні залишків, що задовольняє обидві умови одночасно, є `i = n`.

Отже, система має цілочисельний розв'язок у змінних `(x, u, v, s, t, b)` тоді й лише тоді, коли `y = yₙ(a)`.

## 5. Виведення формули експоненти p = qʳ

Знаючи, як поліноміально задати відношення `y = yₙ(a)`, ми переходимо до побудови діофантового предикату для піднесення до довільного степеня `p = qʳ` (де `p, q, r ∈ ℕ`).

Розглянемо біноміальний розклад розв'язку `yᵣ₊₁(a)` для дуже великої основи `a`:

```
yᵣ₊₁(a)
= ((a + √(a² − 1))ʳ⁺¹ − (a − √(a² − 1))ʳ⁺¹) / (2·√(a² − 1))
= ∑ [k=0..r] C(2r+2, 2k+1) · a²ᵏ⁺¹ · (a² − 1)ʳ⁻ᵏ
```

Виділимо старший член суми при `k = r`:

```
yᵣ₊₁(a) = (2a)ʳ · a − r · (2a)ʳ⁻¹ + O(aʳ⁻²)
```

Якщо ми виберемо параметр `a` спеціального вигляду `a = M·q + 1` (де `M` — достатньо велике число), то при розгляді послідовностей Пелля за модулем `2a·q − q² − 1` виникає точна рівність між залишками розв'язку та степенями `qʳ`.

Джулія Робінсон та Юрій Матіясевич довели, що для `q ≥ 1` та `r ≥ 0` рівність `p = qʳ` рівносильна існуванню невід'ємних цілих чисел `(a, y, z, c, d, u, v)`, що задовольняють систему:

```
(1)  y = yᵣ₊₁(a)
(2)  z = yᵣ(a)
(3)  a > qʳ + 2
(4)  p < a
(5)  (a − q)·y − (a² − 1)·z ≡ p (mod 2a·q − q² − 1)
```

### Алгебраїчна перевірка конгруенції
Розглянемо лінійну комбінацію розв'язків `W = (a − q)·yᵣ₊₁(a) − (a² − 1)·yᵣ(a)`. Використовуючи рекурентні формули для `yₙ(a)`:

```
(a − q)·yᵣ₊₁ − (a² − 1)·yᵣ
= a·yᵣ₊₁ − (a² − 1)·yᵣ − q·yᵣ₊₁             [розкриття дужок]
= xᵣ₊₁ − q·yᵣ₊₁                              [застосування тотожності a·yₙ₊₁ − (a²−1)·yₙ = xₙ₊₁]
```

Розглядаючи величину `xᵣ₊₁(a) − q·yᵣ₊₁(a)` у кільці за модулем `Mod = 2a·q − q² − 1`:

```
(a + √(a² − 1)) − q
= a − q + √(a² − 1)
```

Підносячи до квадрата:

```
(a − q + √(a² − 1))²
= (a − q)² + (a² − 1) + 2(a − q)√(a² − 1)
= a² − 2aq + q² + a² − 1 + 2(a − q)√(a² − 1)
= 2a² − 2aq + q² − 1 + 2(a − q)√(a² − 1)
= 2a(a − q) + q² − 1 + 2(a − q)√(a² − 1)
≡ 0 (mod 2aq − q² − 1)                       [оскільки 2a² − 2aq + q² − 1 = a(2a − 2q) + ... ≡ 0]
```

Звідси за індукцією для всіх `r ≥ 0` випливає точне порівняння:

```
xᵣ₊₁(a) − q·yᵣ₊₁(a) ≡ qʳ (mod 2a·q − q² − 1)
```

Оскільки основа `a` обирається значно більшою за `qʳ`, а модуль `2aq − q² − 1 > qʳ + p`, значення за модулем визначає число `p = qʳ` однозначно.

## 6. Усунення обмеженого універсального квантора (нормальна форма Девіса)

У нормальній формі Девіса рекурсивно перелічна множина подається як:

```
a ∈ S  ⇔  ∃ y ∀ z ≤ y ∃ w₁ ... ∃ wₘ ( P(a, y, z, w₁, ..., wₘ) = 0 )
```

Щоб звести цю формулу до чистого діофантового вигляду, необхідно закодувати скінченну послідовність значень свідків `wᵢ(z)` для всіх `z ∈ {0, 1, ..., y}` скінченною кількістю цілих чисел. Це здійснюється за допомогою китайської теореми про залишки та кодування послідовностей через числа Ґеделя:

Ми шукаємо взаємно прості модулі `m₀, m₁, ..., m_y`, які обираються як члени арифметичної прогресії `m_z = 1 + (z + 1)·M!`, де `M` — достатньо велике ціле число. Тоді за китайською теоремою про залишки існує єдине велике число `Wᵢ`, таке що для кожного `z ≤ y`:

```
Wᵢ ≡ wᵢ(z) (mod m_z)
```

Підставляючи ці конгруенції у вихідний поліном `P`:

```
P(a, y, z, W₁, ..., Wₘ) ≡ 0 (mod 1 + (z + 1)·M!)   для всіх z ≤ y
```

Умова одночасного виконання порівняння для всіх `z ≤ y` зводиться до єдиного відношення подільності:

```
∏ [z=0..y] (1 + (z + 1)·M!)  |  P(a, y, z, W₁, ..., Wₘ)
```

Оскільки добуток `∏ (1 + (z + 1)·M!)` виражається через факторіали та біноміальні коефіцієнти, а операції факторіала та піднесення до степеня вже є діофантовими, обмежений квантор `∀ z ≤ y` повністю усувається без залучення сторонніх операцій.

## 7. Діофантове кодування комбінаторних функцій (C(n, k) та n!)

Наявність діофантового предикату для операції піднесення до степеня `p = qʳ` автоматично відкриває шлях до діофантового кодування біноміальних коефіцієнтів, факторіалів та перевірки на простоту.

### Біноміальні коефіцієнти C(n, k)
За біномом Ньютона:

```
(u + 1)ⁿ = ∑ [j=0..n] C(n, j) · uʲ
```

Якщо обрати число `u` строго більшим за суму всіх біноміальних коефіцієнтів `u > 2ⁿ`, то коефіцієнти `C(n, j)` не перекриваються в `u`-ічному попозиційному записі числа `(u + 1)ⁿ`. Тоді `C(n, k)` виступає `k`-м розрядом цього числа:

```
c = C(n, k)  ⇔  ∃ v, w : (v = (u + 1)ⁿ) ∧ (u = 2ⁿ + 1) ∧ (v = w·uᵏ⁺¹ + c·uᵏ + r) ∧ (c < u) ∧ (r < uᵏ)
```

Кожна складова цієї системи — піднесення до степеня `(u + 1)ⁿ`, `uᵏ`, `uᵏ⁺¹` та нерівності — уже є діофантовою.

### Факторіал n!
Для факторіала використовується його зв'язок з біноміальним коефіцієнтом при великій основі. Якщо обрати `m > (2n)ⁿ⁺¹`, то дріб `mⁿ / C(m, n)` з надзвичайно високою точністю наближає `n!`:

```
f = n!  ⇔  ∃ m : (m = (2n)ⁿ⁺¹ + 1) ∧ (f ≤ mⁿ / C(m, n) < f + 1)
```

Це перетворює факторіал на повноцінне діофантове відношення.

## 8. Діофантове представлення простих чисел (теорема Вілсона)

За класичною **теоремою Вілсона**, натуральне число `k + 1` (де `k ≥ 1`) є простим тоді й лише тоді, коли факторіал `k!` при діленні на `k + 1` дає залишок `−1`:

```
k + 1 — просте число  ⇔  (k + 1) | (k! + 1)
```

Оскільки операція обчислення факторіала `f = k!` та відношення подільності `(k + 1) | (f + 1)` є діофантовими, предикат простоти `IsPrime(p)` записується як скінченна система поліноміальних рівнянь:

```
∃ k, f, q : (p = k + 1) ∧ (f = k!) ∧ (f + 1 = q · p)
```

У 1976 році Джеймс Джонс, Дайхачіро Сато, Хідео Вада та Пітер Вієнс згорнули цю систему у знаменитий многочлен 25-го степеня від 26 змінних (позначених латинськими літерами від `a` до `z`):

```
Prime(a, b, ..., z) = (k + 2) · [1 − (w·z + h + j − q)² − ((g·k + 2·g + k + 1)·(h + j) + h − z)² − ... − E₁₄²]
```

Коли всі змінні `a, b, c, ..., z` пробігають множину невід'ємних цілих чисел `ℕ`, многочлен набуває як від'ємних, так і додатних значень. Але **множина всіх його строго додатних значень збігається в точності з множиною простих чисел**:

```
{ Prime(a, b, ..., z) ∣ a, ..., z ∈ ℕ } ∩ ℕ⁺ = { 2, 3, 5, 7, 11, 13, 17, 19, ... }
```

Цей результат ілюструє фундаментальний компроміс теорії діофантових представлень: між кількістю невідомих змінних та степенем многочлена. Юрій Матіясевич та Джеймс Джонс пізніше показали, що степінь многочлена для будь-якої рекурсивно перелічної множини можна знизити до константи 4 ціною збільшення кількості змінних до 58. З іншого боку, якщо мінімізувати кількість змінних, для опису простих чисел достатньо 10 невідомих, але степінь многочлена при цьому зростає до астрономічного значення порядку `1.6 × 10⁴⁵`.

## 9. Згортання системи у єдине поліноміальне рівняння

Щоб перетворити отриману систему конгруенцій, нерівностей та поліноміальних рівнянь у єдине діофантове рівняння `P(p, q, r, w₁, ..., wₘ) = 0`, застосовуються три стандартні алгебраїчні редукції:

### 1. Перетворення конгруенцій на рівності
Конгруенція `A ≡ B (mod M)` замінюється на існування цілого коефіцієнта `k ∈ ℤ`:
```
A − B − k·M = 0
```

### 2. Перетворення нерівностей на рівності над ℕ
Нестрога нерівність `A ≤ B` над невід'ємними цілими числами замінюється введенням змінної-свідка `w ∈ ℕ`:
```
A + w − B = 0
```
Строга нерівність `A < B` замінюється на `A + 1 ≤ B`:
```
A + 1 + w − B = 0
```

### 3. Згортання системи в суму квадратів
Якщо маємо систему з `K` поліноміальних рівнянь `E₁(x) = 0, E₂(x) = 0, ..., E_K(x) = 0`, то над полем дійсних чисел або кільцем цілих чисел вона повністю еквівалентна єдиному рівнянню:

```
∑ [i=1..K] (Eᵢ(x₁, ..., xₘ))² = 0
```

Оскільки `Eᵢ² ≥ 0` для будь-якого дійсного значення `Eᵢ`, рівність нулю суми квадратів можлива тоді й лише тоді, коли кожен окремий вираз `Eᵢ` тотожно дорівнює нулю:

```
E₁² + E₂² + ... + E_K² = 0  ⇔  (E₁ = 0) ∧ (E₂ = 0) ∧ ... ∧ (E_K = 0)
```

Таким чином, відношення піднесення до степеня `p = qʳ` строго еквівалентне існуванню розв'язку поліноміального рівняння `P(p, q, r, w₁, ..., w₄₀) = 0` у невід'ємних цілих числах `wᵢ`. Цей алгебраїчний гаджет становить фундаментальну серцевину теореми ДПРМ.
