# 🧮 Алгебра і гаджети Валіанта: доказ #P-повноти та тотожності перманента

Перманент квадратної матриці `A` розміру `n × n` визначається як сума добутків по всіх `n!` перестановках `σ` симетричної групи `Sₙ`:

```
perm(A) = ∑_{σ ∈ Sₙ} a[1, σ(1)] · a[2, σ(2)] · ... · a[n, σ(n)]
```

На відміну від [визначника матриці](topic:math-algebra/matrix-determinant), де кожному доданку передує множник `sgn(σ) ∈ {-1, +1}`, усі доданки перманента беруться зі знаком плюс. Ця алгебраїчна особливість дає перманенту фундаментальні властивості:

1. **Полілінійність:** Перманент є лінійною функцією від кожного свого рядка (та стовпця). Якщо помножити рядок `i` на скаляр `λ`, значення перманента домножиться на `λ`. Якщо рядок `Rᵢ` є сумою двох векторів `u + v`, перманент розкладається у суму перманентів двох матриць.
2. **Симетрія відносно перестановки:** Значення перманента не змінюється при довільній перестановці рядків або стовпців: `perm(P · A · Q) = perm(A)` для транспозиційних або перестановочних матриць `P, Q`.
3. **Транспонування:** Перманент транспонованої матриці збігається з перманентом вихідної: `perm(Aᵀ) = perm(A)`.

Незважаючи на полілінійність, перманент **не є знакозмінною** функцією. Додавання одного рядка до іншого змінює значення перманента unpredictable чином, що унеможливлює використання методом Гаусса.

## 1. Виведення формули Райзера через принцип включень-виключень

Обчислимо перманент без прямого перебору `n!` перестановок. Нехай `V = {1, 2, ..., n}` — множина стовпців матриці. Для довільної підмножини стовпців `S ⊆ V` визначимо добуток рядкових сум:

```
P(S) = ∏_{i=1}ⁿ ( ∑_{j ∈ S} a[i, j] )
```

Розкриємо дужки у цій формулі. Добуток `P(S)` виражається як сума по всіх відображеннях `f: {1, ..., n} ⟶ S`:

```
P(S) = ∑_{f: {1,...,n} ⟶ S} a[1, f(1)] · a[2, f(2)] · ... · a[n, f(n)]
```

Серед усіх `nⁿ` можливих відображень `f` нас цікавлять лише бієкції (тобто перестановки `σ ∈ Sₙ`), оскільки саме вони складають перманент `perm(A)`. Відображення `f` є бієкцією тоді й лише тоді, коли його образ `Im(f)` дорівнює усій множині `V`.

Застосуємо [принцип включень-виключень](topic:math-combinatorics/inclusion-exclusion) до відображень. Сума за всіма підмножинами `S ⊆ V` зі знаковим коефіцієнтом `(-1)ⁿ⁻|S|` відсіває всі сюр'єктивні відображення, які пропустили хоча б один елемент із `V`:

```
∑_{S ⊆ V} (-1)ⁿ⁻|S| · P(S)
= ∑_{S ⊆ V} (-1)ⁿ⁻|S| · ∑_{Im(f) ⊆ S} ∏_{i=1}ⁿ a[i, f(i)]
= ∑_{f: {1,...,n} ⟶ V} ( ∏_{i=1}ⁿ a[i, f(i)] ) · ( ∑_{Im(f) ⊆ S ⊆ V} (-1)ⁿ⁻|S| )
```

Обчислимо внутрішню суму знаків для фіксованого відображення `f`. Покладемо `k = |Im(f)|`. Кількість підмножин `S`, які містять `Im(f)` і мають розмір `|S| = k + m`, дорівнює кількості способів обрати `m` елементів із решти `n - k` елементів, тобто біноміальному коефіцієнту `C(n - k, m)`:

```
∑_{Im(f) ⊆ S ⊆ V} (-1)ⁿ⁻|S|
= ∑_{m=0}ⁿ⁻ᵏ (-1)ⁿ⁻⁽ᵏ⁺ᵐ⁾ · C(n - k, m)       [заміна змінної m = |S| - k]
= (-1)ⁿ⁻ᵏ · ∑_{m=0}ⁿ⁻ᵏ (-1)ᵐ · C(n - k, m)   [винесення спільного множника]
= (-1)ⁿ⁻ᵏ · (1 - 1)ⁿ⁻ᵏ                       [біном Ньютона (1 - 1)ⁿ⁻ᵏ]
```

Ця сума дорівнює нулю для всіх `k < n` (коли відображення `f` не є сюр'єкцією) і дорівнює `(-1)⁰ = 1` лише у випадку `k = n` (коли `f` є бієкцією, тобто перестановкою).

Звідси отримуємо тотожність Райзера:

```
perm(A)
= ∑_{S ⊆ V} (-1)ⁿ⁻|S| · ∏_{i=1}ⁿ ( ∑_{j ∈ S} a[i, j] )   [виключення несюр'єктивних]
= (-1)ⁿ · ∑_{S ⊆ V} (-1)|S| · ∏_{i=1}ⁿ ( ∑_{j ∈ S} a[i, j] ) [винесення (-1)ⁿ]
```

Кількість підмножин `S` дорівнює `2ⁿ`. За умови використання коду Ґрея для послідовного обходу підмножин `S`, обчислення кожної наступної рядкової суми виконується за `O(1)` операцій додавання чи віднімання, що забезпечує точну складність `O(2ⁿ · n)`.

## 2. Виведення рандомізованого виразника Ґлінна (1990)

1990 року Девід Ґлінн (David G. Glynn) дав альтернативну формулу для перманента, яка спирається на вектор знаків `δ = (δ₁, δ₂, ..., δₙ)ᵀ`, де кожне `δᵢ ∈ {-1, +1}`.

Розглянемо вираз для довільного вектора знаків `δ`:

```
E(δ) = ( ∏_{k=1}ⁿ δ⩢ ) · ∏_{i=1}ⁿ ( ∑_{j=1}ⁿ δⱼ · a[i, j] )
```

Розкриємо внутрішній добуток по рядках `i`:

```
∏_{i=1}ⁿ ( ∑_{j=1}ⁿ δⱼ · a[i, j] ) = ∑_{f: {1,...,n} ⟶ {1,...,n}} ( ∏_{i=1}ⁿ a[i, f(i)] ) · ∏_{i=1}ⁿ δ_{f(i)}
```

Домноживши на `∏_{k=1}ⁿ δ⩢`, одержуємо:

```
E(δ) = ∑_{f} ( ∏_{i=1}ⁿ a[i, f(i)] ) · ∏_{k=1}ⁿ δ⩢ · ∏_{i=1}ⁿ δ_{f(i)}
```

Просумуємо вираз `E(δ)` по всіх `2ⁿ` можливих векторах знаків `δ ∈ {-1, +1}ⁿ`:

```
∑_{δ ∈ {-1,+1}ⁿ} E(δ) = ∑_{f} ( ∏_{i=1}ⁿ a[i, f(i)] ) · ∑_{δ} ( ∏_{k=1}ⁿ δ⩢ · ∏_{i=1}ⁿ δ_{f(i)} )
```

Розглянемо внутрішню суму знаків для фіксованого відображення `f`. Для кожного елемента `j ∈ {1, ..., n}` підрахуємо, скільки разів його індекс з'являється у добутку `∏_{k=1}ⁿ δ⩢ · ∏_{i=1}ⁿ δ_{f(i)}`:
- У першому добутку індекс `j` зустрічається рівно 1 раз.
- У другому добутку індекс `j` зустрічається `|f⁻¹(j)|` разів.

Тому загальний степінь множника `δⱼ` дорівнює `1 + |f⁻¹(j)|`. Якщо `f` є бієкцією (перестановкою `σ`), то `|f⁻¹(j)| = 1` для всіх `j`, отже степінь `1 + 1 = 2` є парним для кожного `δⱼ`. Оскільки `(±1)² = 1`, добуток знаків тотожно дорівнює `+1` для всіх `2ⁿ` векторів `δ`.

Якщо ж `f` не є бієкцією, існує принаймні один елемент `j*`, який не належить образу `Im(f)`, тобто `|f⁻¹(j*)| = 0`. Тоді степінь `δ_{j*}` дорівнює `1 + 0 = 1` (непарний). При сумуванні по всіх векторах `δ` значення `δ_{j*} = +1` та `δ_{j*} = -1` взаємно знищуються, і сума дорівнює нулю.

Отже, лише бієкції дають ненульовий внесок `2ⁿ`:

```
∑_{δ ∈ {-1,+1}ⁿ} E(δ) = 2ⁿ · perm(A)
```

Завдяки симетрії відносно зміни знаку всього вектора `δ ⟶ -δ`, можна зафіксувати `δ₁ = +1` і зменшити кількість доданків удвічі. Отримуємо точну формулу Ґлінна:

```
perm(A) = (1 / 2ⁿ⁻¹) · ∑_{δ ∈ {-1,+1}ⁿ, δ₁=1} ( ∏_{k=1}ⁿ δ⩢ ) · ∏_{i=1}ⁿ ( ∑_{j=1}ⁿ δⱼ · a[i, j] )
```

Ця формула використовується як для точного підрахунку за `O(2ⁿ⁻¹ · n)` кроків, так і для побудови незміщеного ймовірнісного оцінювача перманента для комплексних матриць.

## 3. Конструкція гаджетів у доведенні теореми Валіанта (1979)

Доведення #P-повноти 0/1-перманента за Леслі Валіантом складається з трьох ключових етапів:

### Етап 1: Графова інтерпретація перманента

Нехай `G = (V, E)` — орієнтований зважений граф із матрицею суміжності `A`, де `a[i, j] = w(uᵢ, uⱼ)` є вагою ребра від вершини `uᵢ` до `uⱼ`.

**Покриття циклами (англ. *cycle cover*):** Підмножина ребер `C ⊆ E` називається покриттям циклами, якщо кожна вершина графа `V` належить рівно одному орієнтованому циклу з `C`. Вага покриття `w(C)` визначається як добуток ваг усіх його ребер.

Оскільки кожна перестановка `σ ∈ Sₙ` однозначно розкладається у добуток незалежних циклів, перманент матриці `A` дорівнює сумі ваг усіх покриттів циклами графа `G`:

```
perm(A) = ∑_{C ∈ CycleCovers(G)} w(C)
```

Якщо `A` є 0/1-матрицею, то `perm(A)` дорівнює точній кількості покриттів циклами графа `G`.

### Етап 2: Побудова гаджетів для булевої формули 3SAT

Для заданої булевої формули `φ` у 3-КНФ із `n` змінними та `m` клозами Валіант будує граф `G(φ)` за допомогою трьох типів гаджетів:

1. **Гаджет змінної (англ. *Variable Gadget*):** Для кожної змінної `xᵢ` будується гаджет із двома основними циклами, що відповідають вибору значень `xᵢ = 1` (Істина) та `xᵢ = 0` (Хибність). Будь-яке покриття циклами має обрати один із цих двох шляхів.
2. **Гаджет клозу (англ. *Clause Gadget*):** Для кожного клозу `Cⱼ = (l₁ ∨ l₂ ∨ l₃)` будується гаджет із трьома вхідними вузлами. Гаджет влаштований так, що він дає ненульовий внесок у сумарний перманент тоді й лише тоді, коли принаймні один із літералів `lₖ` є істинним.
3. **Гаджет фільтраційного треку (англ. *Track Gadget*):** Для зв'язування змінних із клозами та скасування небажаних паразитичних циклів Валіант використовує ребра з від'ємними вагами (зокрема `-1` та `2`).

У результаті для побудованого графа зважених ребер виконано співвідношення:

```
perm(A_{weighted}) = 4ᵐ · N(φ)
```

де `N(φ)` — точна кількість виконуючих наборів булевої формули `φ`, а `m` — кількість клозів.

### Етап 3: Редукція до 0/1-матриці через модульну арифметику

Щоб позбутися від'ємних та цілочисельних ваг і перейти до 0/1-матриці:

1. Обирається досить велике ціле число `M = 2ᵐ + 1`, таке що `perm(A_{weighted}) < M`. Усі обчислення виконуються за модулем `M`.
2. Кожне ребро з від'ємною вагою `-1` замінюється ребром із додатною вагою `M - 1`.
3. Кожне ребро з цілою вагою `w > 1` або `w = M - 1` розщеплюється на подібний графовий вузол із паралельних та послідовних шляхів, що складаються виключно з ребер вагою `1`.

Утворена 0/1-матриця `A₀₁` має поліноміальний розмір `N × N` відносно вхідної формули `φ`. Значення `perm(A₀₁) mod M` дозволяє відновити точне значення `N(φ)`.

Оскільки обчислення кількості виконуючих наборів #3SAT є класичною #P-повною задачею (теорема Законка, 1979), це остаточно доводить, що обчислення 0/1-перманента є **#P-повною задачею**.

## 4. Математична теорія FPRAS та Марковських ланцюгів (JSV 2004)

Для наближеного обчислення невід'ємних перманентів алгоритм JSV будує Марковський ланцюг на множині всіх паросполучень `M = Mₙ ∪ Mₙ₋₁` двочасткового графа `G`:
- Стани `Mₙ` — це досконалі паросполучення розміру `n`.
- Стани `Mₙ₋₁` — це майже досконалі паросполучення розміру `n - 1`.

Ймовірності переходу між станами `M` задаються схемою Метрополіса-Гастінгса:
```
P(M ⟶ M') = min(1, w(M') / w(M)) / (2 |E|)
```

Основним математичним завданням був доказ **нижньої межі провідності** (англ. *conductance*) Марковського ланцюга `Ф`:

```
Ф = min_{S ⊆ M, 0 < π(S) <= 1/2} ( ∑_{x ∈ S, y ∉ S} π(x) P(x, y) ) / π(S)
```

Джеррум, Сінклер та Віґода довели, що для будь-якої невід'ємної матриці провідність обмежується поліноміальною знизу величиною `Ф >= 1 / poly(n)`. За теоремою про спектральну щілину `γ = 1 - λ₂ >= Ф² / 2`, це гарантує швидке перемішування (англ. *rapid mixing*) Марковського ланцюга за `O(n⁴ ln n)` кроків, що забезпечує поліноміальний час роботи FPRAS.
