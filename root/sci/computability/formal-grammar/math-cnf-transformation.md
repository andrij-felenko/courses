# 🧮 Алгоритм приведення контекстно-вільної граматики до нормальної форми Чомскі

Контекстно-вільні граматики в загальному вигляді можуть містити продукції довільної довжини, ланцюгові заміни одного нетермінала іншим `A → B`, стискання рядків через порожні правила `A → ε` та змішані послідовності терміналів і нетерміналів. Ця структурна довільність створює суттєві труднощі при розробці теоретичних доведень та алгоритмів синтаксичного аналізу: дерево виводу може мати довільний ступінь розгалуження, а пошук виведення може зациклюватися через ланцюгові правила.

**Нормальна форма Чомскі** (англ. *Chomsky Normal Form*, CNF) стандартизує синтаксичну структуру, усуваючи всі другорядні артефакти та зводячи всі правила до строго бінарної форми.

## Математичне означення нормальної форми Чомскі

Контекстно-вільна граматика `G = (V, Σ, R, S)` перебуває в нормальній формі Чомскі, якщо кожне правило з множини `R` належить до одного з двох канонічних типів:
1. `A → B C`, де `A, B, C ∈ V` і `B, C ≠ S` (правило породжує рівно два нетермінали);
2. `A → a`, де `A ∈ V` та `a ∈ Σ` (правило породжує рівно один термінальний символ).

Якщо мова, яку породжує граматика, містить порожнє слово (`ε ∈ L(G)`), дозволяється єдине виняткове правило:
3. `S → ε`, за обов'язкової умови, що стартовий символ `S` не зустрічається в правій частині (RHS) жодної продукції граматики.

### Теоретичні та алгоритмічні наслідки стандартизації

Приведення граматики до форми Чомскі забезпечує три фундаментальні математичні гарантії:

1. **Строго бінарна топологія дерев виводу:** Будь-яке дерево виводу для непорожнього слова `w ∈ L(G)` є повним бінарним деревом. Кожен внутрішній вузол має рівно двох нащадків-нетерміналів, а безпосередні батьки листків мають рівно одного термінального нащадка.
2. **Точна довжина деривації:** Якщо слово `w` має довжину `|w| = n ≥ 1`, то будь-яке його виведення в граматиці форми Чомскі складається з рівно `2n − 1` кроків. Справді, для отримання `n` листків за допомогою бінарних правил `A → BC` потрібно рівно `n − 1` кроків, після чого для кожного листка застосовується правило `A → a` (ще `n` кроків):
```
Кількість кроків = (n − 1) + n = 2n − 1
```
Ця властивість гарантує, що простір пошуку виведення для слова довжини `n` є скінченним і не містить нескінченних ланцюжків.
3. **Поліноміальне розпізнавання за алгоритмом CYK:** Завдяки тому, що правила мають вигляд `A → BC`, підрядок `w[i..j]` довжини `m` може бути породжений нетерміналом `A` тоді й лише тоді, коли існує така точка розбиття `k` (`i ≤ k < j`), що `B ⇒* w[i..k]` та `C ⇒* w[k+1..j]`. Це дозволяє перевіряти належність будь-якого слова мові методом динамічного програмування за поліноміальний час `O(n³ · |R|)`.

## П'ятиетапний конструктивний алгоритм

Будь-яку контекстно-вільну граматику `G` можна алгоритмічно перетворити на еквівалентну граматику `G'` у нормальній формі Чомскі за п'ять послідовних етапів.

```
Початкова граматика G
        │
        ▼
[ Етап 1: START ]  ──►  Створення нового старту S₀ → S (S₀ не зустрічається в RHS)
        │
        ▼
[ Етап 2: NULL  ]  ──►  Обчислення множини Nullable та видалення правил A → ε
        │
        ▼
[ Етап 3: UNIT  ]  ──►  Обчислення пар Unit та видалення ланцюгових правил A → B
        │
        ▼
[ Етап 4: TERM  ]  ──►  Виділення терміналів у довгих правилах через змінні T_a
        │
        ▼
[ Етап 5: BIN   ]  ──►  Каскадна бінаризація правил довжини k ≥ 3 на пари
        │
        ▼
Канонічна граматика G' у формі Чомскі
```

### Етап 1: START (новий стартовий символ)

**Мета:** Гарантувати, що стартовий символ ніколи не з'явиться в правій частині жодного правила (необхідно для коректної підтримки `ε ∈ L(G)`).

**Алгоритм:** Створюємо новий нетермінальний символ `S₀ ∉ V` і додаємо правило:
```
S₀ → S
```
Новою множиною нетерміналів стає `V' = V ∪ { S₀ }`, а новим стартом — `S₀`.

### Етап 2: NULL (вилучення ε-правил)

**Мета:** Усунути всі правила вигляду `A → ε` (крім можливого `S₀ → ε`), запобігаючи неконтрольованому зникненню символів під час виведення.

**Алгоритм:**
1. Знаходимо множину **анульовних символів** (англ. *nullable variables*) — змінних, з яких за один або декілька кроків можна вивести порожнє слово (`A ⇒* ε`):
   - **База:** Якщо `A → ε ∈ R`, то `A ∈ Nullable`.
   - **Індукція:** Якщо існує правило `B → C₁ C₂ … C_k` і всі `C_i ∈ Nullable`, то `B ∈ Nullable`.
   - Повторюємо доти, доки множина `Nullable` не перестане зростати.
2. Для кожного правила `A → X₁ X₂ … X_m` генеруємо всі можливі нові правила, де частина символів `X_i ∈ Nullable` опускається. Якщо в правилі присутні `k` входжень анульовних символів, це породжує до `2^k` варіантів правила.
3. Вилучаємо правило, в якому опущені всі символи (тобто `A → ε`), за винятком випадку, коли `S₀ ∈ Nullable` — тоді додаємо єдине правило `S₀ → ε`.

### Етап 3: UNIT (вилучення ланцюгових правил)

**Мета:** Усунути всі правила вигляду `A → B`, де `A, B ∈ V` (ланцюгові продукції, англ. *unit productions*), які не додають жодних терміналів, а лише перейменовують змінні.

**Алгоритм:**
1. Для кожного нетермінала `A ∈ V` знаходимо множину досяжних за одиничними переходами символів `Unit(A) = { B ∈ V | A ⇒* B за правилами вигляду X → Y }`.
   - Для кожного `A` множина `Unit(A)` містить як мінімум сам символ `A`.
   - Якщо `B ∈ Unit(A)` і `B → C ∈ R` (де `C ∈ V`), то додаємо `C` до `Unit(A)`.
2. Будуємо нову множину правил: для кожної пари `(A, B)`, де `B ∈ Unit(A)`, та для кожного неланцюгового правила `B → α` (де `α ∉ V`), додаємо в граматику правило:
```
A → α
```
3. Вилучаємо з граматики всі початкові ланцюгові правила вигляду `A → B`.

### Етап 4: TERM (ізоляція термінальних символів)

**Мета:** Переконатися, що термінальні символи зустрічаються виключно в правилах одиничної довжини `A → a`.

**Алгоритм:**
1. Для кожного термінала `a ∈ Σ`, який зустрічається в правилах довжиною `|α| ≥ 2`, створюємо новий нетермінальний символ `T_a` і додаємо продукцію:
```
T_a → a
```
2. У всіх правилах довжини `≥ 2` замінюємо кожне входження символу `a` на нетермінал `T_a`.

### Етап 5: BIN (бінаризація довгих правил)

**Мета:** Звести всі продукції довжини `k ≥ 3` до послідовності строго бінарних правил.

**Алгоритм:**
Кожне правило вигляду `A → B₁ B₂ B₃ … B_k` (де `k ≥ 3` і всі `B_i ∈ V`) розбивається на каскад із `k − 1` бінарних правил із введенням нових допоміжних змінних `C₁, C₂, …, C_{k-2}`:
```
A       → B₁ C₁
C₁      → B₂ C₂
C₂      → B₃ C₃
…
C_{k-2} → B_{k-1} B_k
```

Після виконання цього кроку всі правила граматики гарантовано задовольняють вимоги нормальної форми Чомскі.

## Повний покроковий приклад нормалізації

Розглянемо граматику `G` для спрощеної мови арифметичних блоків:
```
S → a S b | A | ε
A → c A | d
```

### Крок 1: START
Вводимо новий старт `S₀`:
```
S₀ → S
S  → a S b | A | ε
A  → c A | d
```

### Крок 2: NULL
Знаходимо анульовні змінні:
- `S → ε` ⇒ `S ∈ Nullable`
- `S₀ → S` ⇒ `S₀ ∈ Nullable`
- Нетермінал `A` не є анульовним (`Nullable = { S, S₀ }`).

Розмножуємо правила, опускаючи `S`, і видаляємо `ε`:
```
S₀ → S | ε       [S₀ → ε лишається, бо ε належить початковій мові]
S  → a S b | a b | A
A  → c A | d
```

### Крок 3: UNIT
Обчислюємо ланцюгові замикання:
- `Unit(S₀) = { S₀, S, A }`
- `Unit(S)  = { S, A }`
- `Unit(A)  = { A }`

Переносимо всі неланцюгові правила:
- З `S` та `A` до `S₀`: додаємо `S₀ → a S b | a b | c A | d`
- З `A` до `S`: додаємо `S → c A | d`

Отримуємо систему без ланцюгових правил:
```
S₀ → a S b | a b | c A | d | ε
S  → a S b | a b | c A | d
A  → c A | d
```

### Крок 4: TERM
Вводимо змінні `T_a → a`, `T_b → b`, `T_c → c` для терміналів у комбінованих продукціях:
```
S₀  → T_a S T_b | T_a T_b | T_c A | d | ε
S   → T_a S T_b | T_a T_b | T_c A | d
A   → T_c A | d
T_a → a
T_b → b
T_c → c
```

### Крок 5: BIN
Бінаризуємо трисимвольні продукції `T_a S T_b` через допоміжний нетермінал `X₁`:
```
S₀  → T_a X₁ | T_a T_b | T_c A | d | ε
S   → T_a X₁ | T_a T_b | T_c A | d
X₁  → S T_b
A   → T_c A | d
T_a → a
T_b → b
T_c → c
```

Граматика повністю приведена до нормальної форми Чомскі.

## Алгоритм Кока–Янгера–Касамі (CYK)

Нормальна форма Чомскі слугує основою для універсального алгоритму синтаксичного аналізу CYK, розробленого незалежно Тадао Касамі (1965), Деніелом Янгером (1967) та Джоном Коком.

Алгоритм використовує динамічне програмування для побудови трикутної таблиці `P[i, j]`, де комірка `P[i, j]` містить множину всіх нетерміналів `A`, з яких можна вивести підрядок довжини `j`, що починається з позиції `i` (`w[i .. i+j-1]`):

```
P[i, 1] = { A ∈ V | A → w[i] ∈ R }                          [база: довжина 1]

P[i, j] = ⋃_{k=1}^{j-1} { A ∈ V | A → B C ∈ R,
                                  B ∈ P[i, k],
                                  C ∈ P[i+k, j-k] }          [крок: довжина j > 1]
```

Слово `w` довжини `n` належить мові `L(G)` тоді й лише тоді, коли стартовий символ `S₀ ∈ P[1, n]`.

Завдяки строго бінарній формі правил CNF перевірка кожної пари підрядків виконується за сталий час, що забезпечує асимптотичну складність `O(n³ · |R|)` для будь-якої контекстно-вільної граматики.
