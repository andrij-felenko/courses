# 🧮 Математичні основи конфлюентності та термінації: лема Ньюмана, критичні пари та порядки редукції

Теорія систем переписування термів спирається на суворий алгебраїчний та теоретико-порядковий апарат. Щоб алгоритмічно звести доведення рівностей до перевірки синтаксичного збігу, необхідно гарантувати дві фундаментальні властивості бінарних відношень: конфлюентність (злиття розгалужених траєкторій редукції) та сильну нормалізацію (термінацію, тобто відсутність нескінченних спадних ланцюгів).

## 1. Абстрактні редукційні системи та властивості збіжності

Абстрактна редукційна система (Abstract Reduction System, ARS) є первинною алгебраїчною моделлю обчислювального процесу. Вона формалізується як пара `(A, →)`, де `A` — довільна непорожня множина об'єктів (термів), а `→ ⊆ A × A` — бінарне відношення редукції на ній.

Для відношення `→` стандартно визначаються такі похідні відношення:
- `→*` — рефлексивно-транзитивне замикання `→` (довільна скінченна кількість кроків редукції, включно з нулем).
- `→⁺` — транзитивне замикання `→` (один або більше кроків редукції).
- `←` — обернене відношення: `a ← b` тоді й лише тоді, коли `b → a`.
- `↔` — симетричне замикання `→`: `↔ = → ∪ ←`.
- `↔*` — рефлексивно-симетрично-транзитивне замикання `→` (відношення еквівалентності або конвертованості, породжене `→`).

### 1.1. Нормальні форми та відношення збіжності
Елемент `a ∈ A` називається **редуковним**, якщо існує `b ∈ A` такий, що `a → b`. Якщо такого `b` не існує, елемент `a` називається **нередуковним** або **нормальною формою**.
- Множина всіх нормальних форм позначається як `NF(A, →)`.
- Елемент `b` є нормальною формою елемента `a`, якщо `a →* b` та `b ∈ NF(A, →)`.
- Два елементи `a, b ∈ A` є **збіжними** (позначається `a ↓ b`), якщо існує спільний елемент `c ∈ A` такий, що `a →* c` та `b →* c`.
- Два елементи `a, b ∈ A` є **розбіжними** (позначається `a ↑ b`), якщо існує спільний предок `c ∈ A` такий, що `c →* a` та `c →* b`.

### 1.2. Класифікація властивостей конфлюентності
Для системи `(A, →)` розглядають чотири ключових властивості:
1. **Властивість Чорча-Россера (Church-Rosser, CR):** Для будь-яких `a, b ∈ A`, якщо `a ↔* b`, то `a ↓ b`.
2. **Конфлюентність (Confluence, CONF):** Для будь-яких `a, b, c ∈ A`, якщо `a →* b` та `a →* c`, то `b ↓ c`.
3. **Локальна (слабка) конфлюентність (Weak Church-Rosser, WCR):** Для будь-яких `a, b, c ∈ A`, якщо `a → b` та `a → c`, то `b ↓ c`.
4. **Сильна нормалізація / Термінація (Strong Normalization, SN):** Не існує нескінченної послідовності `a₀ → a₁ → a₂ → ...`.

Відомо, що властивість Чорча-Россера та глобальна конфлюентність еквівалентні для будь-якої ARS:

```
CR  ⇔  CONF
```

Проте локальна конфлюентність `WCR` у загальному випадку значно слабша за `CONF`. Класичний контрприклад: система з чотирма елементами `{a, b, c, d}` та правилами `a → b`, `b → a`, `a → c`, `b → d`. Вона є локально конфлюентною, але не є глобально конфлюентною, оскільки `c ← a →* d`, проте `c` та `d` є різними нормальними формами і не можуть злитися.

## 2. Лема Ньюмана та трансфінітна індукція за редукцією

Якщо редукційна система задовольняє умову термінації (відсутні нескінченні ланцюги), слабка локальна властивість перетворюється на глобальну.

### Теорема (Лема Ньюмана, 1942)
Нехай `(A, →)` — абстрактна редукційна система. Якщо `→` є сильно нормалізантною (`SN`) та локально конфлюентною (`WCR`), то `→` є глобально конфлюентною (`CONF`).

### Доведення леми Ньюмана
Оскільки відношення `→` є термінантним (`SN`), відношення зворотного включення строгого порядку редукції є цілком фундованим (well-founded). Отже, ми можемо застосувати принцип **індукції за фундованим відношенням** (нетерової індукції за редукцією).

Нехай індуктивна гіпотеза `P(a)` стверджує: «Елемент `a` є конфлюентним», тобто для будь-яких `b, c ∈ A` таких, що `a →* b` та `a →* c`, виконується `b ↓ c`.

За принципом фундованої індукції, достатньо довести:
```
(∀y (a →⁺ y ⇒ P(y)))  ⇒  P(a)
```

Припустимо, що для всіх елементів `y`, досяжних з `a` за один або більше кроків (`a →⁺ y`), твердження `P(y)` вже є істинним. Розглянемо довільні два шляхи з `a`:
- Якщо один із шляхів має нульову довжину (наприклад, `a = b`), то `a →* c` одразу дає спільний елемент `c` (оскільки `b = a →* c` та `c →* c`), звідки `b ↓ c`.
- Нехай обидва шляхи містять щонайменше один крок: `a → b₁ →* b` та `a → c₁ →* c`.

Застосуємо послідовні логічні кроки виведення:

```
a → b₁  ∧  a → c₁
⇒ b₁ ↓ c₁                       [за умовою локальної конфлюентності WCR]
⇒ ∃ u₁ ∈ A : (b₁ →* u₁ ∧ c₁ →* u₁)  [за визначенням збіжності ↓]
```

Оскільки `a → b₁`, елемент `b₁` строго передує `a` у фундованому порядку. Отже, за індуктивною гіпотезою для `b₁`, елемент `b₁` є глобально конфлюентним. Маємо:
```
b₁ →* b  ∧  b₁ →* u₁
⇒ b ↓ u₁                        [за індуктивною гіпотезою P(b₁)]
⇒ ∃ u₂ ∈ A : (b →* u₂ ∧ u₁ →* u₂)   [існування першого спільного терма]
```

Тепер розглянемо елемент `c₁`. Оскільки `a → c₁`, за індуктивною гіпотезою `P(c₁)` елемент `c₁` також є глобально конфлюентним. Маємо:
```
c₁ →* c  ∧  c₁ →* u₁ →* u₂
⇒ c₁ →* c  ∧  c₁ →* u₂          [транзитивність редукції →*]
⇒ c ↓ u₂                        [за індуктивною гіпотезою P(c₁)]
⇒ ∃ v ∈ A : (c →* v ∧ u₂ →* v)   [існування фінального спільного терма]
```

Об'єднуючи отримані ланцюги:
```
b →* u₂ →* v  ⇒  b →* v
c →* v
```
Таким чином, ми знайшли елемент `v`, до якого редукуються і `b`, і `c`, що доводить `b ↓ c`. За принципом нетерової індукції, `P(a)` виконується для всіх `a ∈ A`. Лему Ньюмана доведено.

## 3. Критичні пари та критерій локальної конфлюентності

У системах переписування термів вирази мають деревоподібну структуру зі змінними та функціональними символами із сигнатури `Σ`. Нехай `T(Σ, V)` — множина термів над сигнатурою `Σ` та змінними `V`.

### 3.1. Анатомія накладання редексів
Нехай задано систему переписування `R = {lᵢ → rᵢ}`. Розглянемо терм `s`, до якого можна застосувати два правила редукції в позиціях `p₁` та `p₂` за правилами `l₁ → r₁` та `l₂ → r₂`:

```
s → s₁ = s[r₁σ₁]_{p₁}    [застосування правила 1 у позиції p₁]
s → s₂ = s[r₂σ₂]_{p₂}    [застосування правила 2 у позиції p₂]
```

Можливі рівно три геометричні конфігурації розташування позицій `p₁` та `p₂` у дереві терма `s`:
1. **Паралельні (незалежні) позиції (`p₁ ∥ p₂`):** Жодна позиція не є префіксом іншої. Підтерми знаходяться у неперетинних гілках дерева. Редукції комутують тривіально:
```
s₁[r₂σ₂]_{p₂} = s₂[r₁σ₁]_{p₁}  ⇒  s₁ ↓ s₂
```
2. **Вкладення в позицію змінної:** Позиція `p₂` знаходиться всередині екземпляра змінної правила `l₁`. У цьому випадку підстановка `σ₁` змінюється на `σ₁'`, і редукція правила `l₁` може бути застосована після редукції в змінній (можливо, з дублюванням або знищенням кроків, якщо змінна входить до `r₁` кілька разів або нуль разів). Шляхи також тривіально сходяться.
3. **Нетривіальне накладання у функціональній позиції:** Позиція `p₂` має вигляд `p₁ · q`, де `q` — незмінна позиція у правилі `l₁` (`l₁|_q ∉ V`). Це означає, що ліва частина другого правила перетинається з функціональним скелетом першого правила.

### 3.2. Алгебраїчне визначення критичної пари
Нехай `l₁ → r₁` та `l₂ → r₂` — два правила з `R` (із попередньо перейменованими змінними так, що `Var(l₁) ∩ Var(l₂) = ∅`). Нехай `p` — незмінна позиція в `l₁` (`l₁|_p ∉ V`), така що підтерм `l₁|_p` та терм `l₂` є уніфіковними з найзагальнішим уніфікатором `μ = mgu(l₁|_p, l₂)`.

Тоді пара термів:
```
⟨ r₁μ,  (l₁μ)[r₂μ]_p ⟩
```
називається **критичною парою** (Critical Pair), утвореною правилом `l₂ → r₂` у правилі `l₁ → r₁` в позиції `p`.

### Теорема (Лема про критичні пари / Тест Кнута-Бендікса)
Система переписування термів `R` є локально конфлюентною (`WCR`) тоді й лише тоді, коли кожна критична пара системи `R` є збіжною (`s ↓_R t` для всіх `⟨s, t⟩ ∈ CP(R)`).

Оскільки множина правил `R` скінченна, а кількість підтермів у лівих частинах скінченна, множина `CP(R)` завжди скінченна і може бути ефективно обчислена алгоритмом уніфікації Робінсона.

## 4. Синтаксичні спрощувальні порядки: LPO та MPO

Для доведення термінації системи переписування `R` необхідно побудувати строгий частковий порядок `>` на множині термів `T(Σ, V)`, який задовольняє три умови:
1. **Фундованість (Well-foundedness):** Не існує нескінченного ланцюга `t₁ > t₂ > t₃ > ...`.
2. **Монотонність (Сумісність із контекстом):** Якщо `s > t`, то для будь-якого функціонального символу `f` та контексту `C[_]` виконується `C[s] > C[t]`.
3. **Стабільність щодо підстановок:** Якщо `s > t`, то для будь-якої підстановки `σ` виконується `sσ > tσ`.

Порядок, що задовольняє ці три умови, називається **порядком редукції**. Якщо для всіх правил `l → r ∈ R` виконується `l > r`, то система `R` є термінантною (`SN`).

### 4.1. Теорема Дершовіца та спрощувальні порядки
Порядок `>` називається **спрощувальним порядком** (simplification ordering), якщо він містить відношення власного підтерма:
```
f(... t ...) > t    [властивість підтерма для довільного аргументу]
```

За теоремою Дершовіца (Dershowitz, 1982), яка спирається на глибоку теорему про вкладення дерев Джозефа Крускала (Kruskal's Tree Theorem), будь-який спрощувальний порядок над скінченною сигнатурою `Σ` є автоматично цілком фундованим.

### 4.2. Лексикографічний деревний порядок (LPO)
Нехай на множині функціональних символів сигнатури `Σ` задано строгий порядок пріоритету (precedence) `>_Σ`. Лексикографічний деревний порядок `>_lpo` на `T(Σ, V)` індуктивно визначається трьома правилами.

Терм `s = f(s₁, ..., sₘ)` є строго більшим за `t = g(t₁, ..., tₙ)` (`s >_lpo t`), якщо виконується хоча б одна з таких умов:
1. **Умова підтерма:** Існує `i ∈ {1, ..., m}` таке, що `sᵢ ≥_lpo t` (де `≥_lpo` означає `>_lpo` або синтаксичний збіг).
2. **Умова пріоритету кореня:** `f >_Σ g` і для всіх `j ∈ {1, ..., n}` виконується `s >_lpo tⱼ`.
3. **Умова лексикографічного порівняння аргументів:** `f = g` (отже `m = n`), послідовність аргументів `(s₁, ..., sₘ)` є строго більшою за `(t₁, ..., tₘ)` у лексикографічному розширенні `>_lpo`, і для всіх `j ∈ {1, ..., n}` виконується `s >_lpo tⱼ`.

Крім того, для змінних: `s = f(s₁, ..., sₘ) >_lpo x` тоді й лише тоді, коли змінна `x ∈ Var(s)`.

### 4.3. Мультимножинний деревний порядок (MPO)
Мультимножинний порядок `>_mpo` замінює лексикографічне порівняння векторів аргументів на порівняння мультимножин (де порядок слідування аргументів не має значення).

Нехай `M, N` — скінченні мультимножини елементів. Відношення `M >_{mul} N` виконується тоді й лише тоді, коли `N` можна отримати з `M` видаленням непорожньої підмножини елементів `X ⊆ M` та заміною кожного `x ∈ X` на скінченну множину елементів `Y_x ⊆ N`, де кожен `y ∈ Y_x` задовольняє умову `x > y`.

Для термів `s = f(s₁, ..., sₘ)` та `t = g(t₁, ..., tₙ)` з однаковим головним символом `f = g`:
```
s >_mpo t  ⇔  {s₁, ..., sₘ} >_{mul} {t₁, ..., tₙ}
```
Це робить `MPO` незамінним для операцій із симетричними або комутативними аргументами.

## 5. Порядок Кнута-Бендікса (KBO)

Порядок Кнута-Бендікса (Knuth-Bendix Ordering, KBO) поєднує числову вагову функцію зі строгою ієрархією сигнатури, забезпечуючи високу швидкість обчислень.

### 5.1. Допустима вагова система
Вагова система складається з функції ваги `w: Σ ∪ V → ℝ⁺₀` та строгого порядку пріоритету `>_Σ` на `Σ`, які задовольняють умови допустимості:
1. Існує константа `w₀ > 0` така, що `w(x) = w₀` для всіх змінних `x ∈ V`.
2. Для кожного константного символу `c ∈ Σ` (арності 0): `w(c) ≥ w₀`.
3. Якщо унарний функціональний символ `f ∈ Σ` має нульову вагу `w(f) = 0`, то `f` мусить бути максимальним елементом у порядку `>_Σ` серед усіх символів сигнатури.

Загальна вага терма `t` обчислюється сумою ваг усіх його символів:
```
|t|_w = ∑_{f ∈ Sym(t)} w(f)
```

Нехай `|t|_x` позначає кількість входжень змінної `x` у терм `t`.

### 5.2. Визначення порядку KBO
Терм `s` є строго більшим за терм `t` за порядком KBO (`s >_kbo t`), якщо:
1. **Баланс змінних:** Для кожної змінної `x ∈ V` виконується `|s|_x ≥ |t|_x`, та
2. Виконується одна з умов:
   - **Умова строгої ваги:** `|s|_w > |t|_w`.
   - **Умова однакової ваги та пріоритету:** `|s|_w = |t|_w`, причому або:
     - `s = fⁿ(t)` для деякого унарного символу `f` з `w(f) = 0` та `n > 0`, або
     - `s = f(s₁, ..., sₘ)`, `t = g(t₁, ..., tₙ)` та `f >_Σ g`, або
     - `s = f(s₁, ..., sₘ)`, `t = f(t₁, ..., tₘ)` та вектор `(s₁, ..., sₘ)` лексикографічно перевершує `(t₁, ..., tₘ)` за порядком `>_kbo`.

Порядок KBO є строго монотонним, стабільним щодо підстановок та цілком фундованим порядком спрощення.

## 6. Семантичні інтерпретації: поліноми та матриці

Синтаксичні порядки спрощення (LPO, KBO) мають обмеження: вони не здатні довести термінацію систем, які не є спрощувальними (наприклад, правил вигляду `f(f(x)) → f(g(f(x)))`, де права частина містить підтерм, глибший за ліву).

Для таких систем застосовують **семантичні монотонні алгебри**.

### 6.1. Поліноміальні інтерпретації
Кожному функціональному символу `f ∈ Σ` арності `n` зіставляється монотонний многочлен `[f](x₁, ..., xₙ)` з натуральними коефіцієнтами над `ℕ` (або `ℝ⁺`):
- Для кожного аргументу `xᵢ` похідна `∂[f]/∂xᵢ ≥ 1` (строга монотонність).
- Терм `t` інтерпретується як функція `[t]`:
```
[f(t₁, ..., tₙ)] = [f]([t₁], ..., [tₙ])
[x] = x
```
- Правило `l → r` є строго спадним, якщо для всіх допустимих значень змінних `[l] > [r]`.
- Оскільки натуральні числа `(ℕ, >)` є цілком фундованими за стандартним порядком, виконання `[l] > [r]` для всіх правил гарантує сильну нормалізацію `R`.

### 6.2. Матричні інтерпретації
Для систем із лінійною рекурсією поліноміальні інтерпретації часто вимагають експоненційного зростання степенів. Матричні інтерпретації (Endrullis et al., 2006) зіставляють символу `f` афінне відображення векторів над `ℕᵈ`:
```
[f](x⃗₁, ..., x⃗ₙ) = M₁ x⃗₁ + ... + Mₙ x⃗ₙ + v⃗
```
де `Mᵢ ∈ ℕᵈˣᵈ` — матриці з натуральними коефіцієнтами, а `v⃗ ∈ ℕᵈ` — вектор зміщення. Вектори порівнюються за порядком, де перший елемент строго більший (`x₀ > y₀`), а решта не менші (`xᵢ ≥ yᵢ`). Це забезпечує виняткову виразну силу автоматичного доведення термінації в сучасних системах (AProVE, TTT2).

## 7. Фреймворк пар залежностей (Dependency Pairs)

Метод пар залежностей (Arts & Giesl, 2000) розділяє термінацію системи на дві частини: нерекурсивне спрощення аргументів та виклик рекурсивних функцій.

Нехай `D = {f | f(l₁, ..., lₙ) → r ∈ R}` — множина визначених символів (коренів лівих частин). Якщо `l → r ∈ R` і `r|_p = g(t₁, ..., tₘ)`, де `g ∈ D`, то пара:
```
⟨ l♯, (r|_p)♯ ⟩
```
називається **парою залежностей** (де `f♯` — новий символ того ж імені, що позначає виклик функції).

Побудований граф пар залежностей розбивається на сильно зв'язані компоненти (SCC). Термінація зводиться до перевірки того, що в кожному рекурсивному циклі графа хоча б одна пара залежностей строго спадає за слабким порядком редукції, що дозволяє вилучати реберні цикли по одному до повного спрощення графа.

## 8. Алгоритмічна нерозв'язність та межі обчислюваності

Системи переписування термів володіють повною виразною силою універсальних обчислювальних моделей (машин Тюринга, лямбда-числення, рекурсивних функцій). Це породжує фундаментальні бар'єри алгоритмічної розв'язності.

### 8.1. Нерозв'язність термінації
Нехай задано довільну скінченну систему переписування термів `R`. Задача визначення, чи є `R` термінантною (`SN`), є алгоритмічно **нерозв'язною** (є `Σ₁⁰`-повною в арифметичній ієрархії).

Доведення здійснюється прямим зведенням проблеми зупинки машини Тюринга `M` на порожній стрічці:
1. Конфігурація машини Тюринга `⟨q, u, a, v⟩` (де `q` — стан, `u` — стрічка ліворуч, `a` — поточний символ, `v` — стрічка праворуч) кодується у вигляді терма `cfg(q, u, a, v)` з використанням конструкторів списків `cons` та `nil`.
2. Кожен перехід машини `δ(q, a) = (q', b, R)` кодується правилом переписування:
```
cfg(q, u, a, cons(c, v)) → cfg(q', cons(b, u), c, v)
```
3. Машина `M` зупиняється тоді й лише тоді, коли відповідна система переписування термів не містить нескінченних траєкторій редукції з початкового терма.

### 8.2. Теорема Доше про одноправильні системи
У 1992 році французький математик Макс Доше (Max Dauchet) довів теорему про межі спрощення:
- Термінація систем переписування є алгоритмічно нерозв'язною навіть для систем, що складаються **лише з одного правила** переписування `l → r`.

### 8.3. Зведена таблиця розв'язності властивостей TRS

| Властивість | Довільна скінченна TRS | Термінантна TRS (SN) | Ортогональна TRS |
| :--- | :--- | :--- | :--- |
| **Термінація (SN)** | Нерозв'язна | Тривіально (Дано) | Нерозв'язна |
| **Конфлюентність (CONF)** | Нерозв'язна | **Розв'язна** (Тест CP) | **Істинна** (Завжди) |
| **Проблема слів (`s ↔* t`)** | Нерозв'язна | **Розв'язна** (`s↓ = t↓`) | Нерозв'язна |
| **Існування нормальної форми** | Нерозв'язна | **Істинна** (Завжди) | **Істинна** (Завжди) |

Математичний апарат систем переписування перетворює важкі нерозв'язні семантичні проблеми на ефективні алгоритмічні процедури скрізь, де вдається довести наявність сильної нормалізації та локальної конфлюентності.
