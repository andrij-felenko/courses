# Верифікатор леми Евкліда (C++17)

Коли ми працюємо з реальними криптографічними ключами, ми маємо справу з числами, які мають сотні або навіть тисячі розрядів. Стандартні типи даних C++, такі як `uint64_t` чи навіть розширений `__int128`, не здатні вмістити такі величезні значення. Для перевірки леми Евкліда на довільно великих числах ми можемо скористатися відомою бібліотекою Boost.Multiprecision. Вона надає спеціальний тип `cpp_int` для роботи з числами абсолютно довільної довжини.

Програма побудована за чіткою 5-компонентною структурою, що робить її модульною, зрозумілою та легкою для модифікацій.

## 1. Підключення бібліотек та налаштування

Для початку нам знадобляться стандартні потоки введення-виведення та заголовки з бібліотеки Boost. У сучасних стандартах C++ (C++17 та вище) ми можемо зручно використовувати тип `cpp_int`, який поводиться так само, як звичайні цілі числа, але автоматично виділяє пам'ять під великі значення і перевантажує всі стандартні арифметичні оператори.

```cpp
#include <iostream>
#include <string>
#include <boost/multiprecision/cpp_int.hpp>

using namespace boost::multiprecision;
using namespace std;
```

## 2. Алгоритм Евкліда та базова математика

Щоб перевірити лему Евкліда (якщо p ділить a·b, то p ділить a або p ділить b), нам знадобиться функція знаходження найбільшого спільного дільника (НСД, або англійською GCD). Вона потрібна для того, щоб у разі невиконання леми показати, які саме нетривіальні спільні дільники має наше псевдопросте число p з числами a та b.

```cpp
// Функція обчислення НСД через класичний алгоритм Евкліда
cpp_int gcd_large(cpp_int a, cpp_int b) {
    while (b != 0) {
        cpp_int temp = b;
        b = a % b;
        a = temp;
    }
    return a;
}
```

## 3. Ядро верифікатора леми Евкліда

Головна логічна функція скрипта приймає три числа: p, a та b. Вона повинна спочатку обчислити їхній добуток, потім перевірити, чи ділиться цей добуток на p без остачі, і якщо так — перевірити, чи ділиться на p хоча б одне з початкових чисел a або b. Тут ми бачимо всю міць `cpp_int`, адже множення `a * b` виконується без жодного ризику переповнення (integer overflow).

```cpp
void verify_euclid_lemma(const cpp_int& p, const cpp_int& a, const cpp_int& b) {
    cout << "------------------------------------------\n";
    cout << "Перевірка леми Евкліда:\n";
    
    // 1. Обчислюємо добуток (може бути дуже великим!)
    cpp_int product = a * b;
    
    // 2. Перевіряємо початкову умову (p | a·b)
    if (product % p != 0) {
        cout << "[ПОМИЛКА] Число p не ділить добуток a·b.\n";
        cout << "Умова леми не виконується, перевірка зупинена.\n";
        return;
    }
    
    cout << "[УСПІХ] Число p успішно ділить добуток a·b.\n";
    
    // 3. Перевіряємо наслідок (p | a або p | b)
    bool p_divides_a = (a % p == 0);
    bool p_divides_b = (b % p == 0);
    
    if (p_divides_a || p_divides_b) {
        cout << "[УСПІХ] Лема підтверджена!\n";
        if (p_divides_a) cout << "        p ділить число a.\n";
        if (p_divides_b) cout << "        p ділить число b.\n";
    } else {
        cout << "[КРИТИЧНА ПОМИЛКА] p ділить добуток, але не ділить жодного множника!\n";
        cout << "Це означає, що число p ТОЧНО НЕ Є ПРОСТИМ.\n";
        cout << "НСД(p, a) = " << gcd_large(p, a) << "\n";
        cout << "НСД(p, b) = " << gcd_large(p, b) << "\n";
    }
}
```

## 4. Обробка введення від користувача

Оскільки числа великі і можуть складатися з сотень цифр, ми не можемо використовувати стандартні типи. Ми маємо зчитувати їх як текстові рядки (`std::string`), а потім передавати в конструктор `cpp_int`. Це дозволяє користувачеві без проблем вводити числа будь-якої довжини через термінал або перенаправляти їх з текстового файлу.

```cpp
cpp_int read_big_int(const string& prompt) {
    string input;
    cout << prompt;
    cin >> input;
    // Конструктор cpp_int автоматично парсить рядок у велике число
    return cpp_int(input);
}
```

## 5. Головна функція (Точка входу)

Збираємо всі створені компоненти разом у стандартній функції `main()`. Програма привітає користувача, запитає три числа та запустить верифікатор, виводячи результати перевірки на екран.

```cpp
int main() {
    cout << "=== Верифікатор Леми Евкліда (BigInt Edition) ===\n\n";
    
    cpp_int p = read_big_int("Введіть передбачуване просте число p: ");
    cpp_int a = read_big_int("Введіть ціле число a: ");
    cpp_int b = read_big_int("Введіть ціле число b: ");
    
    verify_euclid_lemma(p, a, b);
    
    return 0;
}
```

### Як компілювати та використовувати цей інструмент

Для компіляції цього скрипта вам знадобиться встановлена бібліотека Boost. У терміналі Linux ви можете скомпілювати код такою командою:
`g++ -std=c++17 -O3 euclid_lemma.cpp -o euclid_lemma -lboost_system`

Цей скрипт ідеально підходить для розуміння того, що прості числа є своєрідними «неподільними атомами» вищої арифметики. Якщо ви введете замість `p` складене число, наприклад `p = 15`, а для `a` та `b` візьмете `3` та `5` відповідно, добуток `a·b = 15` очевидно ділитиметься на `15`. Проте число `15` не ділить ні `3`, ні `5`. Наш верифікатор миттєво виявить цю розбіжність і повідомить, що число `p` не є простим, видавши відповідну критичну помилку. Цей контрприклад яскраво демонструє, що властивість, описана в лемі Евкліда, працює виключно для справжніх простих чисел.
