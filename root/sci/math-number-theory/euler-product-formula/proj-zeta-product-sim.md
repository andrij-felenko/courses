# ⚙️ Практична реалізація чисельного порівняння ряду та добутку Ейлера

Цей модуль представляє повноцінний практичний проєкт мовою C++17 для чисельної перевірки тотожності Ейлера. Програма порівнює швидкість збіжності часткових сум Дзета-функції з частковими добутками по простих числах.

## 1. Постановка задачі та алгоритмічні цілі

Метою проєкту є чисельне підтвердження алгебраїчної тотожності ζ(s) = ∑ (1 / nˢ) = ∏ (1 / (1 - p⁻ˢ)) для значення s = 2. Відомо, що точне значення ζ(2) дорівнює π² / 6 ≈ 1.6449340668 (знаменита Задачу Базеля, розв'язана Ейлером). 

Програма обчислює:
1. Часткову суму ряду N доданків: S_N = ∑_{k=1}^N 1 / k².
2. Частковий добуток по перших M простих числах: P_M = ∏_{p ≤ P} 1 / (1 - 1 / p²).
3. Відносну похибку кожного методу відносно константи π² / 6.

## 2. Архітектурні компоненти
1. **Генератор простих чисел (Sieve of Eratosthenes):** Обчислення списку простих чисел до заданої межі P за допомогою решета Ератосфена.
2. **Обчислювач часткової суми ряду:** Сумування 1 / k^s від k = 1 до K.
3. **Обчислювач часткового добутку Ейлера:** Множення 1 / (1 - 1/p^s) по всіх простих p ≤ P.
4. **Модуль аналізу точності:** Обчислення відносної похибки між сумою ряду та добутком.
5. **Інтерфейс виводу та логування:** Вивід порівняльних таблиць у консоль з високою точністю.

## 3. Код мовою C++17

```cpp
#include <iostream>
#include <vector>
#include <cmath>
#include <iomanip>

std::vector<int> generate_primes(int max_limit) {
    std::vector<bool> is_prime(max_limit + 1, true);
    is_prime[0] = is_prime[1] = false;
    for (int p = 2; p * p <= max_limit; ++p) {
        if (is_prime[p]) {
            for (int i = p * p; i <= max_limit; i += p)
                is_prime[i] = false;
        }
    }
    std::vector<int> primes;
    for (int i = 2; i <= max_limit; ++i) {
        if (is_prime[i]) primes.push_back(i);
    }
    return primes;
}

double compute_zeta_sum(double s, int terms) {
    double sum = 0.0;
    for (int k = 1; k <= terms; ++k) {
        sum += 1.0 / std::pow(k, s);
    }
    return sum;
}

double compute_euler_product(double s, const std::vector<int>& primes) {
    double product = 1.0;
    for (int p : primes) {
        product *= 1.0 / (1.0 - 1.0 / std::pow(p, s));
    }
    return product;
}

int main() {
    double s = 2.0; // Zeta(2) = Pi^2 / 6 ≈ 1.6449340668
    int prime_limit = 100000;
    int sum_terms = 100000;

    auto primes = generate_primes(prime_limit);
    double sum_val = compute_zeta_sum(s, sum_terms);
    double prod_val = compute_euler_product(s, primes);
    double exact_zeta2 = M_PI * M_PI / 6.0;

    std::cout << std::fixed << std::setprecision(10);
    std::cout << "Точне значення Zeta(2) = Pi^2 / 6: " << exact_zeta2 << "\n";
    std::cout << "Часткова сума ряду (100,000 елементів): " << sum_val << "\n";
    std::cout << "Частковий добуток Ейлера (9,592 простих): " << prod_val << "\n";
    std::cout << "Похибка ряду: " << std::abs(exact_zeta2 - sum_val) << "\n";
    std::cout << "Похибка добутку: " << std::abs(exact_zeta2 - prod_val) << "\n";

    return 0;
}
```

## 4. Крок за кроком розбір роботи коду

1. **Ініціалізація та генерація простих:** Функція `generate_primes` використовує вектор `std::vector<bool>` для економії пам'яті (1 біт на елемент). Вона відсіює всі складені числа за O(P log log P) операцій.
2. **Обчислення суми ряду:** Функція `compute_zeta_sum` акумулює доданки 1 / k^s у типі `double` високої точності (IEEE 754 float64).
3. **Обчислення добутку Ейлера:** Функція `compute_euler_product` множить фактори (1 - p^{-s})⁻¹. Кожен фактор обчислюється через функцію `std::pow`.
4. **Порівняння похибок:** Головний модуль порівнює обидва обчислені значення з теоретичною константою π² / 6.

## 5. Аналіз алгоритмічної складності
- **Просторовий аналіз:** Решето Ератосфена потребує O(P) пам'яті для зберігання прапорців простоти.
- **Часовий аналіз:** Пошук простих чисел займає O(P log log P). Обчислення добутку займає O(π(P)) = O(P / log P) арифметичних операцій.
