# 📜 Історія леми Гензеля та відкриття p-адичних чисел

Цей історичний екскурс розкриває інтелектуальні передумови, які спонукали Курта Гензеля створити p-адичні числа, долаючи скепсис тогочасної академічної спільноти, та сформулювати фундаментальну лему про підйом коренів.

## 1. Алгебраїчний контекст XIX століття: Між аналізом та арифметикою

У другій половині XIX століття математична наука розвивалася під впливом двох потужних ідейних концепцій: строгої арифметизації аналізу Карла Вейєрштрасса та алгебраїчної теорії чисел, розробленої Ріхардом Дедекіндом, Ернстом Куммером і Леопольдом Кронекером.

У комплексному аналізі завдяки працям Огюстена-Луї Коші, Бернгарда Рімана та Карла Вейєрштрасса центральне місце посіло дослідження аналітичних функцій через їхні локальні розклади в степеневі ряди Тейлора та Лорана в околі точок:

```
f(z) = a₀ + a₁·(z - z₀) + a₂·(z - z₀)² + a₃·(z - z₀)³ + ...
```

Вейєрштрасс показав, що аналітична функція повністю визначається своїм локальним поводженням у довільно малому околі точки `z₀`. Якщо `z₀` є нулем функції (тобто `f(z₀) = 0`), порядок цього нуля визначається першим ненульовим коефіцієнтом ряду, а наближені корені можна обчислювати послідовним утриманням перших членів розкладу.

З іншого боку, Ернст Куммер у своїх спробах довести Велику теорему Ферма виявив, що в кільцях цілих чисел кругових полів порушується однозначність розкладу на прості множники. Щоб відновити єдиність факторизації, Куммер увів поняття «ідеальних чисел». Ріхард Дедекінд перетворив ідеальні числа на строгу теорію ідеалів кільця, а Леопольд Кронекер запропонував теорію дільників.

У 1882 році Ріхард Дедекінд та Генріх Вебер опублікували епохальну працю *«Теорія алгебраїчних функцій однієї змінної»* (*Theorie der algebraischen Functionen einer Veränderlichen*), у якій перенесли методи алгебраїчної теорії чисел (зокрема теорію ідеалів) на геометрію ріманових поверхонь. Вони довели, що точки на комплексній кривій відповідають простим ідеалам у кільці функцій, а порядок нуля чи полюса функції в точці збігається з показником нормування відповідного ідеалу.

Учень Кронекера та Вейєрштрасса, німецький математик Курт Гензель (Kurt Hensel, 1864–1941), поставив зворотне фундаментальне запитання:

Якщо геометрію та аналітичні функції комплексної змінної можна вивчати суто алгебраїчно через локальні розклади за степенями різницевого фактора `(z - z₀)`, чи можливо перенести аналітичні методи степеневих рядів назад у теорію чисел, розкладаючи звичайні цілі та раціональні числа за степенями «арифметичної точки» — простого числа `p`?

## 2. Відкриття p-адичних чисел (1897)

У 1897 році на засіданні Німецького математичного товариства в Брауншвейгу та у фундаментальній статті, опублікованій у часописі Крелле (*Journal für die reine und angewandte Mathematik*), Курт Гензель запропонував принципово новий спосіб подання чисел.

Гензель запропонував подавати довільне ціле або раціональне число у вигляді нескінченної позиційної суми за зростаючими степенями простого числа `p`:

```
α = c₀ + c₁·p + c₂·p² + c₃·p³ + ... + c_n·pⁿ + ...
```

де кожне значення `c_i` є «цифрою» з множини найменших невід'ємних лишків `{0, 1, ..., p - 1}`.

Для академічної спільноти кінця XIX століття такий ряд видавався математичною нісенітницею. У звичній евклідовій метриці доданки `c_n · pⁿ` зі зростанням індексу `n` стають нескінченно великими, тому числовий ряд катастрофічно розходиться. Наприклад, для простого числа `p = 5` нескінченна сума:

```
4 + 4·5 + 4·5² + 4·5³ + 4·5⁴ + ...
```

у звичайному аналізі дорівнює нескінченності. Проте Гензель помітив дивовижну алгебраїчну властивість: якщо додати до цього ряду число `1`, виникає ланцюгова реакція переносів у наступні розряди:

```
  1 + (4 + 4·5 + 4·5² + 4·5³ + ...)
= (1 + 4) + 4·5 + 4·5² + ...
= 5 + 4·5 + 4·5² + ...
= (1 + 4)·5 + 4·5² + ...
= 5·5 + 4·5² + ...
= 0 (у границі за степенями 5)
```

Отже, у новому числовому просторі сума нескінченного ряду `4 + 4·5 + 4·5² + ...` дорівнює від'ємній одиниці `-1`.

Гензель усвідомив, що для цілочисельної подільності природною є не архімедова довжина, а неархімедова міра близькості: число вважається тим «меншим» і ближчим до нуля, чим вищий степінь простого числа `p` його ділить. Якщо визначити p-адичне нормування `v_p(x)` як найбільший показник степеня `k`, для якого `pᵏ` ділить `x`, то p-адична абсолютна величина (норма) задається формулою:

```
|x|_p = p^{-v_p(x)}    (при |0|_p = 0)
```

У цій метриці доданок `c_n · pⁿ` прямує до нуля зі зростанням `n`, оскільки `|c_n · pⁿ|_p ≤ p^{-n} → 0`. Відтак нескінченний степеневий ряд стає абсолютно збіжним у новому повному метричному просторі, який отримав назву поля p-адичних чисел `Q_p`.

## 3. Практичний механізм: Обчислення p-адичного квадратного кореня

Щоб продемонструвати силу свого підходу, Гензель показав, як за допомогою p-адичного розкладу розв'язувати алгебраїчні рівняння, які не мають розв'язків у раціональних числах `Q`.

Розглянемо класичне рівняння для пошуку уявного числа `i = √(-1)` у полі 5-адичних чисел `Q_5`:

```
x² + 1 = 0
```

У звичайних раціональних або дійсних числах корінь з `-1` не існує. Проте за модулем простого числа `p = 5` ми маємо:

```
x² + 1 ≡ 0 (mod 5)
```

Один із розв'язків дорівнює `c₀ = 2`, оскільки `2² + 1 = 5 ≡ 0 (mod 5)`. Обчислимо формальну похідну многочлена `f(x) = x² + 1`:

```
f'(x) = 2·x
f'(2) = 4 ≡ -1 ≢ 0 (mod 5)
```

Похідна не ділиться на `5`, отже корінь є простим. Знайдемо послідовні 5-адичні цифри `c₁, c₂, c₃` для розкладу `x = c₀ + c₁·5 + c₂·5² + c₃·5³ + ...`:

1. **Другий розряд (модуль 5² = 25):**
   Шукаємо `x₂ = 2 + c₁·5`.
   ```
   (2 + c₁·5)² + 1 ≡ 0 (mod 25)
   4 + 20·c₁ + 1 ≡ 0 (mod 25)
   5 + 20·c₁ ≡ 0 (mod 25)
   1 + 4·c₁ ≡ 0 (mod 5)   [поділили на 5]
   4·c₁ ≡ -1 ≡ 4 (mod 5)
   c₁ = 1
   ```
   Отримуємо наближення `x₂ = 2 + 1·5 = 7`. Перевірка: `7² + 1 = 50 = 2·25 ≡ 0 (mod 25)`.

2. **Третій розряд (модуль 5³ = 125):**
   Шукаємо `x₃ = 7 + c₂·25`.
   ```
   (7 + c₂·25)² + 1 ≡ 0 (mod 125)
   49 + 14·c₂·25 + 1 ≡ 0 (mod 125)
   50 + 350·c₂ ≡ 0 (mod 125)
   50 + 100·c₂ ≡ 0 (mod 125)   [оскільки 350 ≡ 100 (mod 125)]
   2 + 4·c₂ ≡ 0 (mod 5)        [поділили на 25]
   4·c₂ ≡ -2 ≡ 3 (mod 5)
   c₂ = 2   [бо 4·2 = 8 ≡ 3 (mod 5)]
   ```
   Отримуємо наближення `x₃ = 7 + 2·25 = 57`. Перевірка: `57² + 1 = 3250 = 26·125 ≡ 0 (mod 125)`.

3. **Четвертий розряд (модуль 5⁴ = 625):**
   Шукаємо `x₄ = 57 + c₃·125`.
   ```
   (57 + c₃·125)² + 1 ≡ 0 (mod 625)
   3249 + 114·c₃·125 + 1 ≡ 0 (mod 625)
   3250 + 14250·c₃ ≡ 0 (mod 625)
   3250 ≡ 125 (mod 625),  а 14250·c₃ ≡ 500·c₃ (mod 625)
   125 + 500·c₃ ≡ 0 (mod 625)
   1 + 4·c₃ ≡ 0 (mod 5)        [поділили на 125]
   c₃ = 1
   ```
   Отримуємо наближення `x₄ = 57 + 1·125 = 182`. Перевірка: `182² + 1 = 33125 = 53·625 ≡ 0 (mod 625)`.

Цей конструктивний процес дає точне значення числа `√(-1)` у кільці 5-адичних цілих чисел `Z_5`:

```
√(-1) = 2 + 1·5 + 2·5² + 1·5³ + ... = (...1212)₅
```

Для тогочасних математиків це було справжнім відкриттям: квадратний корінь із від'ємного числа існує як суто арифметичний об'єкт без жодного залучення уявної одиниці `i` чи геометрії комплексної площини.

## 4. Сформулювання леми про підйом (1904)

Головною науковою метою Курта Гензеля було створення загального апарату для дослідження та розв'язування поліноміальних рівнянь `f(x) = 0` у цілих числах (діофантових рівнянь).

У 1904 році у своїй фундаментальній монографії *«Теорія алгебраїчних чисел»* (*Theorie der algebraischen Zahlen*) Гензель узагальнив описаний вище покроковий процес і сформулював твердження, яке сьогодні носить назву **лема Гензеля**:

Якщо многочлен `f(x)` із цілими коефіцієнтами має корінь `a₁` за простим модулем `p` (тобто `f(a₁) ≡ 0 (mod p)`), для якого формальна похідна `f'(a₁) ≢ 0 (mod p)` не кратна `p`, то для кожного показника `k ≥ 1` існує єдиний лишок `a_k (mod pᵏ)`, такий що:

```
f(a_k) ≡ 0 (mod pᵏ)   та   a_k ≡ a₁ (mod p)
```

При цьому послідовність наближень `(a₁, a₂, a₃, ...)` збігається в p-адичній топології до точного кореня `α ∈ Z_p`, який задовольняє рівність `f(α) = 0`.

Алгебраїчною мовою категорій лема Гензеля встановлює існування розв'язку в проєктивній границі кілець лишків:

```
Z_p = lim_{←} (Z / pᵏZ)
```

## 5. Скептицизм сучасників та теорема Островського (1916)

Перші п'ятнадцять років після публікацій Гензеля p-адичні числа сприймалися провідними математиками світу з великою пересторогою. Такі видатні авторитети, як Давид Гільберт та Герман Мінковський, вважали p-адичні ряди штучною нотаційною екзотикою. Вони стверджували, що це лише формальний запис систем конгруенцій, який не має самостійної математичної цінності порівняно з класичною теорією функцій та геометрією.

Перелом у сприйнятті стався у 1916 році, коли молодий український математик Олександр Островський (1893–1986), учень Гензеля та Дмитра Граве, який навчався в Геттінгені під керівництвом Фелікса Клейна та Давида Гільберта, опублікував класичну теорему класифікації абсолютних значень на полі раціональних чисел `Q`:

> **Теорема Островського (1916):** Будь-яка нетривіальна абсолютна величина (норма) `|x|` на полі раціональних чисел Q топологічно еквівалентна або стандартній архімедовій нормі дійсних чисел `|x|_∞ = |x|`, або p-адичній нормі `|x|_p` для деякого простого числа `p`.

Теорема Островського розставила всі крапки над «і»: p-адичні числа `Q_p` — це не штучна вигадка і не примха окремого автора. Вони є **єдино можливими** метричними доповненнями раціональних чисел `Q`, окрім поля дійсних чисел `R`.

Більше того, для будь-якого ненульового раціонального числа `x ∈ Q \ {0}` виконується фундаментальна **формула добутку**:

```
|x|_∞ · ∏_{p} |x|_p = 1
```

де добуток береться за всіма простими числами `p`. Ця формула пов'язує докупи всі локальні простори: значення числа у звичайному дійсному аналізі точно врівноважується сукупністю його властивостей подільності у всіх p-адичних полях.

## 6. Локально-глобальний принцип Гассе (1920-ті)

У 1920-х роках учень Гензеля, видатний німецький алгебраїст Гельмут Гассе (Helmut Hasse, 1898–1979), побудував на основі p-адичних чисел та леми Гензеля фундаментальну концепцію сучасної теорії чисел — **локально-глобальний принцип** (Принцип Гассе — Мінковського).

Досліджуючи питання про існування раціональних точок на квадратичних формах від багатьох змінних `Q(x₁, ..., x_n) = 0`, Гассе довів:

Квадратична форма має нетривіальний розв'язок у раціональних числах `Q` (глобальний розв'язок) тоді і тільки тоді, коли вона має розв'язок у полі дійсних чисел `R` (архімедовий локальний розв'язок) та у всіх p-адичних полях `Q_p` для кожного простого числа `p` (неархімедові локальні розв'язки).

У цьому алгоритмічному ланцюгу лема Гензеля відіграє роль конструктивного моста:
1. Завдяки скінченності поля `F_p` наявність розв'язку за простим модулем `p` перевіряється скінченним числом операцій;
2. Якщо знайдено простий корінь (`f'(a) ≢ 0 (mod p)`), лема Гензеля автоматично гарантує існування точного розв'язку в p-адичному полі `Q_p`;
3. Якщо розв'язки існують для всіх `p` та в `R`, принцип Гассе збирає їх у глобальний розв'язок у раціональних числах `Q`.

### Межі принципу Гассе: кубічні форми Зельмера

Важливо зазначити, що для рівнянь вищих степенів (починаючи з кубічних кривих) локально-глобальний принцип перестає діяти автоматично. У 1951 році норвезький математик Ернст Зельмер (Ernst S. Selmer) навів знаменитий контрприклад — кубічну криву:

```
3·x³ + 4·y³ + 5·z³ = 0
```

Ця крива має нетривіальні розв'язки в полі дійсних чисел `R` і в усіх без винятку p-адичних полях `Q_p` (наявність розв'язків у `Q_p` доводиться саме за допомогою леми Гензеля). Проте вона не має жодного цілочисельного чи раціонального розв'язку в `Q`, окрім тривіального `(0, 0, 0)`.

Перешкода до глобалізації локальних розв'язків для кривих роду 1 вивчається через так звану групу Шафаревича — Тейта `Ш(E/Q)`, яка вимірює розрив між локальною та глобальною розв'язністю.

## 7. Еволюція в комп'ютерній алгебрі та сучасній криптографії

У другій половині XX століття лема Гензеля перетворилася з теоретичного інструменту чистої математики на наріжний камінь практичної комп'ютерної алгебри та криптографії:

1. **Факторизація многочленів (Алгоритм Берлекампа — Гензеля — Цассенгауза):**
   У 1969 році Ганс Цассенгауз (Hans Zassenhaus) запропонував використовувати підйом Гензеля для розкладання багаточленів із цілими коефіцієнтами `f(x) ∈ Z[x]` на незвідні множники. Замість важкого перебору в `Z[x]` многочлен розкладають на множники над малим полем `F_p[x]`, а потім швидко піднімають розклад до кільця `(Z/pᵏZ)[x]`, де степінь `pᵏ` перевищує теоретичну межу коефіцієнтів можливих дільників (межу Міньотта чи Ландау). Цей підхід ліг в основу всіх сучасних систем комп'ютерної алгебри (Maple, Mathematica, Magma, PARI/GP, SymPy).

2. **Асиметрична криптографія та аналіз еліптичних кривих:**
   У криптографічних схемах на основі модульної арифметики (RSA, криптосистема Рабіна) лема Гензеля застосовується для миттєвого знаходження квадратних та кубічних коренів за модулями виду `pᵏ`. У криптографії на еліптичних кривих алгоритми Сато (Satoh) та Кедлая (Kedlaya) використовують канонічний p-адичний підйом точок та когомологій для підрахунку порядку групи точок еліптичної кривої над великими скінченними полями, що є критично важливим для перевірки криптографічної стійкості протоколів цифрового підпису ECDSA.

Від ідеї Курта Гензеля 1897 року до найсучасніших алгоритмів комп'ютерної безпеки XXI століття лема про підйом розв'язків залишається одним із найглибших і найпродуктивніших результатів на перетині алгебри, топології та обчислювальної математики.
