# 🧮 Строгий доказ леми Гензеля, багатовимірний випадок та факторизація

Ця математична вставка містить вичерпні алгебраїчні виведення леми Гензеля, доказ єдиності розв'язків, квадратичну формулу Ньютона, узагальнення на системи багатьох змінних, теорему про підйом факторизації многочленів та узагальнений випадок кратних коренів.

## 1. Цілочисельність диференціалів Тейлора для багаточленів

Центральним алгебраїчним інструментом доказу леми Гензеля є доведення того, що формальний розклад многочлена в ряд Тейлора не створює дробових коефіцієнтів при діленні похідних на факторіали.

Нехай `f(x) = c_n·xⁿ + c_{n-1}·xⁿ⁻¹ + ... + c₁·x + c₀` — довільний многочлен ступеня `n` із цілими коефіцієнтами `c_i ∈ Z`.

Розглянемо вираз `f(x + h)` та застосуємо двочлен Ньютона для кожного окремого монома `c_k · (x + h)ᵏ`:

```
c_k · (x + h)ᵏ = c_k · ∑_{m=0}ᵏ C(k, m) · xᵏ⁻ᵐ · hᵐ
```

де `C(k, m) = k! / (m! · (k - m)!)` позначує біноміальний коефіцієнт.

Зауважимо, що `m`-ша похідна монома `c_k · xᵏ` дорівнює:

```
dᵐ/dxᵐ (c_k · xᵏ) = c_k · k · (k - 1) ... (k - m + 1) · xᵏ⁻ᵐ = c_k · (k! / (k - m)!) · xᵏ⁻ᵐ
```

Якщо розділити `m`-шу похідную на `m!`, вираз набуває вигляду:

```
(1 / m!) · dᵐ/dxᵐ (c_k · xᵏ) = c_k · C(k, m) · xᵏ⁻ᵐ
```

Оскільки біноміальний коефіцієнт `C(k, m)` є цілим числом для будь-яких натуральних `k` та `m`, формальний оператор `f⁽ᵐ⁾(x) / m!` преобразує многочлен із цілими коефіцієнтами у новий многочлен `P_m(x) ∈ Z[x]` також із цілими коефіцієнтами.

Отже, розклад Тейлора багаточлена `f(x + h)` набуває точного алгебраїчного вигляду:

```
f(x + h) = f(x) + f'(x)·h + P₂(x)·h² + P₃(x)·h³ + ... + P_n(x)·hⁿ
```

де всі `P_m(x) ∈ Z[x]` є багаточленами із цілими коефіцієнтами.

Підставивши `x = a` та `h = t · pᵏ` (де `a, t ∈ Z`, `k ≥ 1`), отримуємо:

```
f(a + t·pᵏ) = f(a) + f'(a)·t·pᵏ + ∑_{m=2}ⁿ P_m(a) · tᵐ · pᵐᵏ
```

Винесємо фактор `p²ᵏ` із суми при `m ≥ 2`:

```
f(a + t·pᵏ) = f(a) + f'(a)·t·pᵏ + Q(a, t) · p²ᵏ
```

де `Q(a, t) = ∑_{m=2}ⁿ P_m(a) · tᵐ · p^{(m-2)k}` є цілим числом.

Для будь-якого показнику `k ≥ 1` маємо `2k ≥ k + 1`. Це означає, що за модулем `p^{k+1}` доданок `Q(a, t) · p²ᵏ` безпосередньо ділиться на `p^{k+1}` і перетворюється на нуль:

```
f(a + t·pᵏ) ≡ f(a) + f'(a)·t·pᵏ (mod p^{k+1})
```

Ця формула є точним модульним диференціалом Тейлора, який покладено в основу леми Гензеля.

## 2. Повний строгий доказ існування та єдиності розв'язку

> **Теорема:** Нехай `f(x) ∈ Z[x]` — многочлен із цілими коефіцієнтами. Якщо існує `a_k ∈ Z`, таке що `f(a_k) ≡ 0 (mod pᵏ)` та `f'(a_k) ≢ 0 (mod p)`, то існує **єдине** значення `a_{k+1} (mod p^{k+1})`, таке що `f(a_{k+1}) ≡ 0 (mod p^{k+1})` та `a_{k+1} ≡ a_k (mod pᵏ)`.

### Доказ існування:

Оскільки `f(a_k) ≡ 0 (mod pᵏ)`, існує ціле число `q_k ∈ Z`, таке що `f(a_k) = q_k · pᵏ`.

Покладемо `a_{k+1} = a_k + t · pᵏ` для деякого цілого `t`. Підставимо у порівняння за модулем `p^{k+1}`:

```
f(a_{k+1}) = f(a_k + t·pᵏ) ≡ f(a_k) + f'(a_k)·t·pᵏ (mod p^{k+1})
```

Замінивши `f(a_k)` на `q_k · pᵏ`, отримуємо:

```
q_k · pᵏ + f'(a_k)·t·pᵏ ≡ 0 (mod p^{k+1})
```

Розділимо обидві частини рівняння на `pᵏ` (це правомірно при переході до модуля `p`):

```
q_k + f'(a_k)·t ≡ 0 (mod p)
```

Перенесемо вільний член `q_k`:

```
f'(a_k)·t ≡ -q_k (mod p)
```

Оскільки `a_k ≡ a₁ (mod p)`, маємо `f'(a_k) ≡ f'(a₁) (mod p)`. За умовою теореми `f'(a₁) ≢ 0 (mod p)`, тому `gcd(f'(a_k), p) = 1`.

Отже, елемент `f'(a_k)` має мультиплікативний обернений `v ∈ Z/pZ`, такий що `v · f'(a_k) ≡ 1 (mod p)`.

Помноживши порівняння на `v`, отримуємо розв'язок для `t`:

```
t ≡ - q_k · v ≡ - (f(a_k) / pᵏ) · v (mod p)
```

Отже, значення `a_{k+1} = a_k + t · pᵏ` існує і задовольняє `f(a_{k+1}) ≡ 0 (mod p^{k+1})`.

### Доказ єдиності:

Припустимо, що існують два розв'язки `x` та `y` за модулем `p^{k+1}`, такі що:

1. `f(x) ≡ 0 (mod p^{k+1})` та `f(y) ≡ 0 (mod p^{k+1})`;
2. `x ≡ a_k (mod pᵏ)` та `y ≡ a_k (mod pᵏ)`.

З другої умови випливає, що `x - y` ділиться на `pᵏ`, тобто `x - y = s · pᵏ` для деякого цілого `s`.

Розкладемо `f(x) = f(y + s·pᵏ)` за модулем `p^{k+1}`:

```
f(x) ≡ f(y) + f'(y)·s·pᵏ (mod p^{k+1})
```

Оскільки `f(x) ≡ 0 (mod p^{k+1})` та `f(y) ≡ 0 (mod p^{k+1})`, отримуємо:

```
0 ≡ 0 + f'(y)·s·pᵏ (mod p^{k+1})
```

Розділивши на `pᵏ`:

```
f'(y) · s ≡ 0 (mod p)
```

Оскільки `y ≡ a₁ (mod p)`, маємо `f'(y) ≢ 0 (mod p)`. Скоротивши на `f'(y)`, отримуємо:

```
s ≡ 0 (mod p)
```

Це означає, що `s = c · p`, отже `x - y = c · p^{k+1}`, тобто `x ≡ y (mod p^{k+1})`.

Єдиність підйому повністю доведено.

## 3. Квадратичний підйом (Метод Ньютона без ітерацій ділення)

Замість лінійного підйому по одному степеню `p`, квадратичний підйом подвоює кількість значущих p-адичних розрядів на кожному кроці: `pᵏ → p²ᵏ`.

Нехай `f(a_k) ≡ 0 (mod pᵏ)` та `f'(a_k) ≢ 0 (mod p)`.

Розглянемо поправку за формулою Ньютона:

```
a_{2k} ≡ a_k - f(a_k) · (f'(a_k))⁻¹ (mod p²ᵏ)
```

де `(f'(a_k))⁻¹` позначує мультиплікативний обернений елемент до похідної за модулем `p²ᵏ`.

### Доказ квадратичної збіжності:

Позначимо `v_k ≡ (f'(a_k))⁻¹ (mod p²ᵏ)`. Тоді `a_{2k} = a_k - f(a_k) · v_k`.

Розкладемо `f(a_{2k})` у ряд Тейлора за модулем `p²ᵏ`:

```
f(a_{2k}) ≡ f(a_k - f(a_k)·v_k) (mod p²ᵏ)
≡ f(a_k) - f'(a_k) · (f(a_k)·v_k) + P₂(a_k) · (f(a_k)·v_k)² (mod p²ᵏ)
```

Оскільки `f(a_k) ≡ 0 (mod pᵏ)`, квадрат `(f(a_k))²` ділиться на `p²ᵏ`, тому доданок із `P₂` дорівнює нулю за модулем `p²ᵏ`:

```
f(a_{2k}) ≡ f(a_k) · (1 - f'(a_k) · v_k) (mod p²ᵏ)
```

Оскільки за визначенням оберненого елемента `f'(a_k) · v_k ≡ 1 (mod p²ᵏ)`, множник `(1 - f'(a_k) · v_k)` ділиться на `p²ᵏ`.

Отже, `f(a_{2k}) ≡ 0 (mod p²ᵏ)`.

### Обчислення оберненого елемента похідної без розширеного алгоритму Евкліда:

Для обчислення `v_{2k} ≡ (f'(a_{2k}))⁻¹ (mod p²ᵏ)` можна використовувати додаткову ітерацію Ньютона для функції `g(v) = 1/v - f'(a_{2k})`:

```
v_{2k} ≡ v_k · (2 - f'(a_{2k}) · v_k) (mod p²ᵏ)
```

Ця формула дозволяє здійснювати квадратичний підйом взагалі без використання алгоритму Евкліда на кожному кроці, використовуючи лише базові операції множення та віднімання.

## 4. Багатовимірний випадок: Системи n поліноміальних рівнянь

Нехай задано систему з `n` поліноміальних рівнянь від `n` змінних `X = (x₁, x₂, ..., x_n)`:

```
f₁(x₁, ..., x_n) = 0
f₂(x₁, ..., x_n) = 0
...
f_n(x₁, ..., x_n) = 0
```

Позначимо через `F(X) = (f₁(X), ..., f_n(X))ᵀ` вектор-функцію, а через `J(X)` — матрицю Якобі систем розміром `n × n`:

```
J(X) = [ ∂f_i / ∂x_j ]_{1 ≤ i, j ≤ n}
```

> **Багатовимірна лема Гензеля:** Нехай `A₁ = (a₁, ..., a_n)ᵀ ∈ Zⁿ` — цілочисельний вектор, такий що:
> 1. `F(A₁) ≡ 0 (mod p)` (вектор `A₁` є розв'язком системи за модулем `p`);
> 2. Детермінант матриці Якобі `det(J(A₁)) ≢ 0 (mod p)` (матриця Якобі неособлива за модулем `p`).
>
> Тоді для кожного `k ≥ 1` існує єдиний вектор `A_k (mod pᵏ)`, такий що `F(A_k) ≡ 0 (mod pᵏ)` та `A_k ≡ A₁ (mod p)`.

### Векторна формула підйому:

Перехід від `A_k` до `A_{k+1}` здійснюється за формулою:

```
A_{k+1} ≡ A_k - (J(A_k))⁻¹ · F(A_k) (mod p^{k+1})
```

де `(J(A_k))⁻¹` є оберненою матрицею Якобі за модулем `p`.

## 5. Теорема про підйом факторизації многочленів (Hensel Factorization)

Нехай `f(x) ∈ Z[x]` — монічний багаточлен із цілими коефіцієнтами.

Припустимо, що за простим модулем `p` багаточлен `f(x)` розкладається на два монічні взаємно прості многочлени:

```
f(x) ≡ g₁(x) · h₁(x) (mod p)
```

де `gcd(g₁(x), h₁(x)) ≡ 1 (mod p)`.

З розширеного алгоритму Евкліда для многочленів над скінченним полем `F_p[x]` випливає існування таких багаточленів `α(x), β(x) ∈ F_p[x]`, що виконується тотожність Безу:

```
α(x) · g₁(x) + β(x) · h₁(x) ≡ 1 (mod p)
```

причому `deg(α) < deg(h₁)` та `deg(β) < deg(g₁)`.

> **Теорема (Підйом Гензеля для багаточленів):** Для кожного `k ≥ 1` існують єдині монічні многочлени `g_k(x)` та `h_k(x)` у кільці `(Z/pᵏZ)[x]`, такі що:
> 1. `f(x) ≡ g_k(x) · h_k(x) (mod pᵏ)`
> 2. `g_k(x) ≡ g₁(x) (mod p)` та `h_k(x) ≡ h₁(x) (mod p)`
> 3. `deg(g_k) = deg(g₁)` та `deg(h_k) = deg(h₁)`.

### Алгоритм кроку підйому `k → k+1`:

1. Обчислюємо помилку розкладу: `m_k(x) = (f(x) - g_k(x)·h_k(x)) / pᵏ (mod p)`.
2. Знаходимо поправки `u(x)` та `v(x)` із порівняння:
   ```
   g_k(x) · v(x) + h_k(x) · u(x) ≡ m_k(x) (mod p)
   ```
3. Використовуючи тотожність Безу, маємо:
   ```
   u(x) ≡ β(x) · m_k(x) (mod g_k(x))
   v(x) ≡ α(x) · m_k(x) (mod h_k(x))
   ```
4. Формуємо підняті многочлени:
   ```
   g_{k+1}(x) = g_k(x) + u(x) · pᵏ (mod p^{k+1})
   h_{k+1}(x) = h_k(x) + v(x) · pᵏ (mod p^{k+1})
   ```

## 6. Узагальнена лема Гензеля для кратних коренів

Якщо `f'(a₁) ≡ 0 (mod p)`, звичайна лема Гензеля не працює. Проте розв'язок може існувати, якщо похідна не обнуляється тотожно в p-адичному сенсі.

Позначимо через `v_p(n)` p-адичне нормування цілого числа `n` (тобто найбільший показник `e`, такий що `pᵉ` ділить `n`).

> **Узагальнена лема Гензеля (Кратні корені):** Нехай `f(x) ∈ Z[x]`. Припустимо, що існує число `a ∈ Z`, таке що для деякого цілого `e ≥ 0` виконуються умови:
> 1. `v_p(f(a)) > 2e` (тобто `f(a) ≡ 0 (mod p^{2e+1})`);
> 2. `v_p(f'(a)) = e` (тобто `f'(a)` ділиться на `pᵉ`, але не ділиться на `p^{e+1}`).
>
> Тоді існує єдиний корінь `α ∈ Z_p`, такий що `f(α) = 0` у кільці p-адичних цілих чисел, причому `α ≡ a (mod p^{e+1})`.

Ця теорема є фундаментальною для аналізу розгалужених розширень p-адичних полів та дослідження кривих із солітарними особливими точками.
