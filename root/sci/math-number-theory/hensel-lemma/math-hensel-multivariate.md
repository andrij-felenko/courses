# 🧮 Строгий доказ леми Гензеля, багатовимірний випадок та факторизація

Ця математична вставка містить вичерпні алгебраїчні виведення леми Гензеля для однієї та багатьох змінних, доказ єдиності розв'язків, квадратичну формулу Ньютона без ділення, теорему про підйом факторизації многочленів із тотожністю Безу та узагальнену лему для кратних коренів.

## 1. Цілочисельність диференціалів Тейлора для багаточленів

Центральним алгебраїчним інструментом доказу леми Гензеля є доведення того, що формальний розклад многочлена в ряд Тейлора не створює дробових коефіцієнтів при діленні похідних на факторіали `m!`.

Нехай `f(x) = c_n·xⁿ + c_{n-1}·xⁿ⁻¹ + ... + c₁·x + c₀` — довільний многочлен степеня `n` із цілими коефіцієнтами `c_i ∈ Z`.

Розглянемо вираз `f(x + h)` та застосуємо біном Ньютона для кожного окремого монома `c_k · (x + h)ᵏ`:

```
c_k · (x + h)ᵏ = c_k · ∑_{m=0}ᵏ C(k, m) · xᵏ⁻ᵐ · hᵐ
```

де `C(k, m) = k! / (m! · (k - m)!)` позначає цілочисельний біноміальний коефіцієнт.

Обчислимо `m`-ту формальну похідну монома `c_k · xᵏ`:

```
dᵐ/dxᵐ (c_k · xᵏ) = c_k · k · (k - 1) ... (k - m + 1) · xᵏ⁻ᵐ = c_k · (k! / (k - m)!) · xᵏ⁻ᵐ
```

Якщо розділити `m`-ту похідну на факторіал `m!`, вираз набуває вигляду:

```
(1 / m!) · dᵐ/dxᵐ (c_k · xᵏ) = c_k · C(k, m) · xᵏ⁻ᵐ
```

Оскільки біноміальний коефіцієнт `C(k, m)` є цілим числом для будь-яких натуральних `k` та `m`, формальний оператор `P_m(x) = f⁽ᵐ⁾(x) / m!` перетворює многочлен із цілими коефіцієнтами на новий многочлен `P_m(x) ∈ Z[x]` також виключно із цілими коефіцієнтами.

Отже, точний алгебраїчний розклад Тейлора багаточлена `f(x + h)` набуває вигляду:

```
f(x + h) = f(x) + f'(x)·h + P₂(x)·h² + P₃(x)·h³ + ... + P_n(x)·hⁿ
```

де всі `P_m(x) ∈ Z[x]` є поліномами із цілими коефіцієнтами.

Підставивши `x = a` та `h = t · pᵏ` (де `a, t ∈ Z`, `k ≥ 1`), отримуємо:

```
f(a + t·pᵏ) = f(a) + f'(a)·t·pᵏ + ∑_{m=2}ⁿ P_m(a) · tᵐ · pᵐᵏ
```

Винесемо множник `p²ᵏ` із суми при `m ≥ 2`:

```
f(a + t·pᵏ) = f(a) + f'(a)·t·pᵏ + Q(a, t) · p²ᵏ
```

де `Q(a, t) = ∑_{m=2}ⁿ P_m(a) · tᵐ · p^{(m-2)k}` є цілим числом.

Для будь-якого натурального показника `k ≥ 1` виконується нерівність `2k ≥ k + 1`. Це означає, що при переході до порівняння за модулем `p^{k+1}` доданок `Q(a, t) · p²ᵏ` без остачі ділиться на `p^{k+1}` і перетворюється на нуль:

```
f(a + t·pᵏ) ≡ f(a) + f'(a)·t·pᵏ (mod p^{k+1})
```

Ця формула є точним модульним диференціалом Тейлора, який покладено в основу підйому розв'язків.

## 2. Повний строгий доказ існування та єдиності розв'язку

> **Теорема (Лема Гензеля для простого кореня):** Нехай `f(x) ∈ Z[x]` — багаточлен із цілими коефіцієнтами, а `p` — просте число. Якщо існує ціле число `a_k ∈ Z`, таке що:
> 1. `f(a_k) ≡ 0 (mod pᵏ)`
> 2. `f'(a_k) ≢ 0 (mod p)`
>
> то існує **єдине** значення `a_{k+1} (mod p^{k+1})`, таке що `f(a_{k+1}) ≡ 0 (mod p^{k+1})` та `a_{k+1} ≡ a_k (mod pᵏ)`.

### Покроковий доказ існування:

1. Оскільки `f(a_k) ≡ 0 (mod pᵏ)`, за визначенням подільності існує ціле число `q_k ∈ Z`, таке що:
   ```
   f(a_k) = q_k · pᵏ
   ```
2. Будь-який кандидат на піднятий корінь має вигляд `a_{k+1} = a_k + t · pᵏ` для деякого невідомого цілого числа `t ∈ {0, 1, ..., p - 1}`.
3. Підставимо `a_{k+1}` у модульний розклад Тейлора за модулем `p^{k+1}`:
   ```
   f(a_{k+1}) = f(a_k + t·pᵏ) ≡ f(a_k) + f'(a_k)·t·pᵏ (mod p^{k+1})   [за формулою Тейлора]
   ```
4. Підставимо вираз `f(a_k) = q_k · pᵏ`:
   ```
   q_k · pᵏ + f'(a_k)·t·pᵏ ≡ 0 (mod p^{k+1})   [вимога рівності нулю за mod p^{k+1}]
   ```
5. Розділимо обидві частини конгруенції та її модуль на `pᵏ` (це законна операція теорії чисел: `a·m ≡ b·m (mod c·m) ⟺ a ≡ b (mod c)`):
   ```
   q_k + f'(a_k)·t ≡ 0 (mod p)   [скорочення на p^k]
   ```
6. Перенесемо вільний член `q_k` у праву частину:
   ```
   f'(a_k)·t ≡ -q_k (mod p)   [лінійне рівняння відносно t]
   ```
7. Оскільки `a_k ≡ a₁ (mod p)`, формальні похідні збігаються за модулем `p`: `f'(a_k) ≡ f'(a₁) (mod p)`.
8. За умовою теореми `f'(a₁) ≢ 0 (mod p)`, отже `gcd(f'(a_k), p) = 1`. За теоремою Безу існує мультиплікативний обернений елемент `v ∈ Z`, такий що `v · f'(a_k) ≡ 1 (mod p)`.
9. Помноживши лінійне порівняння на `v`, знаходимо єдиний лишок `t`:
   ```
   t ≡ - q_k · v ≡ - (f(a_k) / pᵏ) · v (mod p)   [явна формула для цифри підйому]
   ```
10. Підставляючи знайдене `t` у вираз `a_{k+1} = a_k + t · pᵏ`, отримуємо шуканий розв'язок за модулем `p^{k+1}`. Існування доведено.

### Покроковий доказ єдиності:

1. Припустимо, що існують два розв'язки `x` та `y` за модулем `p^{k+1}`, такі що:
   - `f(x) ≡ 0 (mod p^{k+1})` та `f(y) ≡ 0 (mod p^{k+1})`
   - `x ≡ a_k (mod pᵏ)` та `y ≡ a_k (mod pᵏ)`
2. З умови збігу за модулем `pᵏ` випливає, що їхня різниця ділиться на `pᵏ`:
   ```
   x - y = s · pᵏ   для деякого цілого s ∈ Z
   ```
3. Застосуємо розклад Тейлора до точки `x = y + s·pᵏ` за модулем `p^{k+1}`:
   ```
   f(x) ≡ f(y) + f'(y) · s · pᵏ (mod p^{k+1})   [модульний розклад першого порядку]
   ```
4. Оскільки `f(x) ≡ 0 (mod p^{k+1})` та `f(y) ≡ 0 (mod p^{k+1})`, отримуємо:
   ```
   0 ≡ 0 + f'(y) · s · pᵏ (mod p^{k+1})   [підстановка нульових значень]
   ```
5. Розділимо рівність на `pᵏ`:
   ```
   f'(y) · s ≡ 0 (mod p)   [скорочення на спільний дільник]
   ```
6. Оскільки `y ≡ a₁ (mod p)`, маємо `f'(y) ≡ f'(a₁) ≢ 0 (mod p)`.
7. Скорочення на ненульовий елемент поля `F_p` дає:
   ```
   s ≡ 0 (mod p)   [оскільки gcd(f'(y), p) = 1]
   ```
8. Звідси `s = c · p` для деякого `c ∈ Z`.
9. Підставивши `s` у вираз для різниці:
   ```
   x - y = (c · p) · pᵏ = c · p^{k+1}
   ```
10. Отже, `x ≡ y (mod p^{k+1})`. Єдиність підйому повністю доведено.

### Числовий приклад покрокового лінійного виведення

Розглянемо многочлен `f(x) = x² - 2` та просте число `p = 7`. Знайдемо розв'язок за модулем `7³ = 343`.

1. **Крок 1 (модуль p = 7):**
   - Перевіряємо `a₁ = 3`: `f(3) = 3² - 2 = 7 ≡ 0 (mod 7)`.
   - Похідна `f'(x) = 2x`, тому `f'(3) = 6 ≡ -1 ≢ 0 (mod 7)`.
   - Обернений елемент: `v ≡ 6⁻¹ ≡ (-1)⁻¹ ≡ 6 (mod 7)`.

2. **Крок 2 (підйом до p² = 49):**
   - Неузгодженість: `q₁ = f(3) / 7 = (9 - 2) / 7 = 7 / 7 = 1`.
   - Поправка: `t₁ ≡ -q₁ · v ≡ -1 · 6 = -6 ≡ 1 (mod 7)`.
   - Новий корінь: `a₂ = a₁ + t₁·7 = 3 + 1·7 = 10 (mod 49)`.
   - Перевірка: `f(10) = 100 - 2 = 98 = 2 · 49 ≡ 0 (mod 49)`.

3. **Крок 3 (підйом до p³ = 343):**
   - Неузгодженість: `q₂ = f(10) / 49 = 98 / 49 = 2`.
   - Поправка: `t₂ ≡ -q₂ · v ≡ -2 · 6 = -12 ≡ 2 (mod 7)`.
   - Новий корінь: `a₃ = a₂ + t₂·49 = 10 + 2·49 = 10 + 98 = 108 (mod 343)`.
   - Перевірка: `f(108) = 108² - 2 = 11664 - 2 = 11662 = 34 · 343 ≡ 0 (mod 343)`.

Корінь `a₃ = 108` є точним та єдиним підйомом початкового кореня `3` до модуля `343`.

## 3. Квадратичний підйом (Метод Ньютона без операцій ділення)

Замість збільшення показника степеня на одиницю, квадратична схема підйому подвоює кількість правильних p-адичних цифр на кожній ітерації: `pᵏ → p²ᵏ`.

Нехай `f(a_k) ≡ 0 (mod pᵏ)` та `f'(a_k) ≢ 0 (mod p)`.

Формула квадратичного кроку Ньютона має вигляд:

```
a_{2k} ≡ a_k - f(a_k) · (f'(a_k))⁻¹ (mod p²ᵏ)
```

де `(f'(a_k))⁻¹` позначає мультиплікативний обернений елемент до похідної за модулем `p²ᵏ`.

### Доказ квадратичної швидкості збіжності:

1. Нехай `v_k ∈ Z` задовольняє умову `v_k · f'(a_k) ≡ 1 (mod p²ᵏ)`.
2. Покладемо `a_{2k} = a_k - f(a_k) · v_k`.
3. Застосуємо розклад Тейлора для функції `f` у точці `a_k` зі зсувом `h = -f(a_k) · v_k`:
   ```
   f(a_{2k}) = f(a_k - f(a_k)·v_k) ≡ f(a_k) - f'(a_k)·f(a_k)·v_k + P₂(a_k)·[f(a_k)·v_k]² (mod p²ᵏ)
   ```
4. Оскільки `f(a_k) ≡ 0 (mod pᵏ)`, величина `f(a_k) = M · pᵏ`. Її квадрат дорівнює:
   ```
   [f(a_k)]² = M² · p²ᵏ ≡ 0 (mod p²ᵏ)
   ```
   Тому квадратичний член Тейлора `P₂(a_k) · [f(a_k)·v_k]²` обнуляється за модулем `p²ᵏ`.
5. Згрупуємо лінійні доданки:
   ```
   f(a_{2k}) ≡ f(a_k) · (1 - f'(a_k) · v_k) (mod p²ᵏ)
   ```
6. Оскільки `v_k · f'(a_k) ≡ 1 (mod p²ᵏ)`, різниця `(1 - f'(a_k) · v_k)` ділиться на `p²ᵏ`.
7. Отже:
   ```
   f(a_{2k}) ≡ 0 (mod p²ᵏ)
   ```

### Ітераційне інвертування похідної (Ньютон — Шульц):

Щоб уникнути виклику розширеного алгоритму Евкліда на кожному квадратичному кроці для великих модулів `p²ᵏ`, обернене значення `v_{2k} ≡ (f'(a_{2k}))⁻¹ (mod p²ᵏ)` обчислюють за формулою Ньютона — Шульца:

```
v_{2k} ≡ v_k · (2 - f'(a_{2k}) · v_k) (mod p²ᵏ)
```

**Доведення коректності інвертування:**
Нехай `1 - f'(a_{2k}) · v_k = ε · pᵏ`. Тоді:
```
1 - f'(a_{2k}) · v_{2k} = 1 - f'(a_{2k}) · v_k · (2 - f'(a_{2k}) · v_k)   [підстановка формули для v_{2k}]
                        = 1 - (1 - ε·pᵏ) · (1 + ε·pᵏ)                      [підстановка f'(a_{2k})·v_k = 1 - ε·pᵏ]
                        = 1 - (1 - ε²·p²ᵏ)                                 [різниця квадратів (1-y)(1+y) = 1-y²]
                        = ε² · p²ᵏ ≡ 0 (mod p²ᵏ)                           [вираз кратний модулю p^{2k}]
```
Це означає, що точність інвертування подвоюється паралельно з точністю кореня, використовуючи лише операції множення та віднімання.

## 4. Багатовимірний випадок: Системи n поліноміальних рівнянь

Нехай задано систему з `n` поліноміальних рівнянь від `n` змінних `X = (x₁, x₂, ..., x_n)ᵀ`:

```
f₁(x₁, ..., x_n) = 0
f₂(x₁, ..., x_n) = 0
...
f_n(x₁, ..., x_n) = 0
```

Позначимо через `F(X) = (f₁(X), ..., f_n(X))ᵀ` вектор-стовпець функцій, а через `J(X)` — матрицю Якобі розміром `n × n`:

```
J(X) = [ ∂f_i / ∂x_j ]_{1 ≤ i, j ≤ n}
```

> **Теорема (Багатовимірна лема Гензеля):** Нехай `A₁ = (a₁, ..., a_n)ᵀ ∈ Zⁿ` — цілочисельний вектор, для якого виконуються умови:
> 1. `F(A₁) ≡ 0 (mod p)` (вектор є розв'язком системи за модулем `p`);
> 2. `det(J(A₁)) ≢ 0 (mod p)` (матриця Якобі є невиродженою над полем `F_p`).
>
> Тоді для кожного натурального `k ≥ 1` існує єдиний вектор `A_k (mod pᵏ)`, такий що `F(A_k) ≡ 0 (mod pᵏ)` та `A_k ≡ A₁ (mod p)`.

### Виведення векторної формули підйому:

Розкладемо вектор-функцію `F(A_k + H · pᵏ)` у багатовимірний ряд Тейлора:

```
F(A_k + H · pᵏ) = F(A_k) + J(A_k) · H · pᵏ + O(p²ᵏ)
```

За модулем `p^{k+1}` квадратичні члени зникають (`2k ≥ k + 1`):

```
F(A_k) + J(A_k) · H · pᵏ ≡ 0 (mod p^{k+1})
```

Поділивши на `pᵏ`:

```
(F(A_k) / pᵏ) + J(A₁) · H ≡ 0 (mod p)
```

Оскільки матриця Якобі `J(A₁)` невироджена за модулем `p`, існує обернена матриця `(J(A₁))⁻¹ ∈ GL_n(F_p)`. Звідси вектор поправок `H` однозначно дорівнює:

```
H ≡ - (J(A₁))⁻¹ · (F(A_k) / pᵏ) (mod p)
```

Піднятий вектор розв'язку визначається як:

```
A_{k+1} = A_k + H · pᵏ (mod p^{k+1})
```

### Розібраний приклад системи двох рівнянь від двох змінних

Розглянемо систему над простим числом `p = 7`:

```
f₁(x, y) = x² + y² - 12 ≡ 0 (mod 7)
f₂(x, y) = x · y - 2    ≡ 0 (mod 7)
```

1. **Початковий розв'язок за модулем 7:**
   Перевіримо вектор `A₁ = (1, 2)ᵀ`:
   - `f₁(1, 2) = 1² + 2² - 12 = 5 - 12 = -7 ≡ 0 (mod 7)`
   - `f₂(1, 2) = 1 · 2 - 2 = 0 ≡ 0 (mod 7)`

2. **Матриця Якобі:**
   ```
   J(x, y) = [ [2x, 2y], [y, x] ]
   J(1, 2) = [ [2, 4], [2, 1] ]
   ```
   Детермінант:
   ```
   det(J) = 2 · 1 - 4 · 2 = 2 - 8 = -6 ≡ 1 (mod 7) ≢ 0
   ```

3. **Обернена матриця Якобі за модулем 7:**
   ```
   (J(1, 2))⁻¹ ≡ (1 / det) · [ [1, -4], [-2, 2] ] ≡ [ [1, 3], [5, 2] ] (mod 7)
   ```

4. **Підйом до модуля 7² = 49:**
   - Обчислюємо нев'язку `F(A₁) = (f₁(1, 2), f₂(1, 2))ᵀ = (-7, 0)ᵀ`.
   - Вектор часток: `Q₁ = F(A₁) / 7 = (-1, 0)ᵀ`.
   - Вектор поправок `H`:
     ```
     H ≡ - (J)⁻¹ · Q₁ ≡ - [ [1, 3], [5, 2] ] · [ -1, 0 ]ᵀ ≡ - [ -1, -5 ]ᵀ ≡ [ 1, 5 ]ᵀ (mod 7)
     ```
   - Піднятий розв'язок `A₂`:
     ```
     x₂ = 1 + 1 · 7 = 8  (mod 49)
     y₂ = 2 + 5 · 7 = 37 (mod 49)
     ```

5. **Перевірка точності за модулем 49:**
   - `f₁(8, 37) = 8² + 37² - 12 = 64 + 1369 - 12 = 1421 = 29 · 49 ≡ 0 (mod 49)`
   - `f₂(8, 37) = 8 · 37 - 2 = 296 - 2 = 294 = 6 · 49 ≡ 0 (mod 49)`

Розв'язок `(8, 37)` за модулем 49 знайдено без жодного варіанту перебору серед `49² = 2401` пар чисел.

## 5. Теорема про підйом факторизації многочленів (Hensel Factorization)

Нехай `f(x) ∈ Z[x]` — унітарний (монічний) многочлен із цілими коефіцієнтами.

Припустимо, що над скінченним полем `F_p` многочлен розкладається на два унітарні взаємно прості многочлени:

```
f(x) ≡ g₁(x) · h₁(x) (mod p)
```

де `gcd(g₁(x), h₁(x)) = 1` у кільці `F_p[x]`.

За розширеним алгоритмом Евкліда для многочленів існують такі многочлени `α(x), β(x) ∈ F_p[x]`, що виконується тотожність Безу:

```
α(x) · g₁(x) + β(x) · h₁(x) ≡ 1 (mod p)
```

причому `deg(α) < deg(h₁)` та `deg(β) < deg(g₁)`.

> **Теорема (Підйом розкладу на множники):** Для кожного цілого `k ≥ 1` існують єдині унітарні многочлени `g_k(x)` та `h_k(x)` у кільці `(Z/pᵏZ)[x]`, такі що:
> 1. `f(x) ≡ g_k(x) · h_k(x) (mod pᵏ)`
> 2. `g_k(x) ≡ g₁(x) (mod p)` та `h_k(x) ≡ h₁(x) (mod p)`
> 3. `deg(g_k) = deg(g₁)` та `deg(h_k) = deg(h₁)`.

### Покроковий алгоритм кроку підйому `k → k+1`:

1. Обчислюємо поліноміальну нев'язку:
   ```
   m_k(x) = (f(x) - g_k(x) · h_k(x)) / pᵏ (mod p)
   ```
2. Знаходимо поліноми корекції `u(x)` та `v(x)` такі, що:
   ```
   g_k(x) · v(x) + h_k(x) · u(x) ≡ m_k(x) (mod p)
   ```
3. За тотожністю Безу розв'язок задається формулами:
   ```
   u(x) ≡ (β(x) · m_k(x)) rem g₁(x) (mod p)
   v(x) ≡ (α(x) · m_k(x)) rem h₁(x) (mod p)
   ```
   де `rem` позначає остачу від ділення многочленів у `F_p[x]`. Це гарантує умову `deg(u) < deg(g₁)` та `deg(v) < deg(h₁)`.
4. Оновлюємо підняті множники:
   ```
   g_{k+1}(x) = g_k(x) + u(x) · pᵏ (mod p^{k+1})
   h_{k+1}(x) = h_k(x) + v(x) · pᵏ (mod p^{k+1})
   ```

### Розібраний числовий приклад підйому факторизації

Розглянемо многочлен `f(x) = x⁴ + 1` за модулем простого числа `p = 5`. Піднімемо розклад до модуля `5² = 25`.

1. **Факторизація над полем F₅:**
   Оскільки `1 ≡ -4 (mod 5)`, маємо:
   ```
   f(x) = x⁴ + 1 ≡ x⁴ - 4 = (x² - 2) · (x² + 2) (mod 5)
   ```
   Покладемо `g₁(x) = x² - 2` та `h₁(x) = x² + 2`.
   Спільний дільник: `gcd(x² - 2, x² + 2) = gcd(x² - 2, 4) = 1` у `F₅[x]`.

2. **Тотожність Безу над F₅:**
   ```
   h₁(x) - g₁(x) = (x² + 2) - (x² - 2) = 4 ≡ -1 (mod 5)
   ```
   Помноживши на `-1 ≡ 4`:
   ```
   (-1) · (x² + 2) + 1 · (x² - 2) = -4 ≡ 1 (mod 5)
   ```
   Звідси `α(x) = 1` та `β(x) = -1 ≡ 4`.

3. **Підйом до модуля 25:**
   - Добуток базових множників: `g₁(x) · h₁(x) = (x² - 2)(x² + 2) = x⁴ - 4`.
   - Поліноміальна різниця: `f(x) - g₁(x)·h₁(x) = (x⁴ + 1) - (x⁴ - 4) = 5`.
   - Нев'язка: `m₁(x) = 5 / 5 = 1`.
   - Поправки:
     ```
     u(x) ≡ β(x) · m₁(x) = -1 · 1 = -1 ≡ 4 (mod 5)
     v(x) ≡ α(x) · m₁(x) = 1 · 1 = 1 (mod 5)
     ```
   - Оновлені множники за модулем 25:
     ```
     g₂(x) = (x² - 2) + 4 · 5 = x² + 18 ≡ x² - 7 (mod 25)
     h₂(x) = (x² + 2) + 1 · 5 = x² + 7 (mod 25)
     ```

4. **Перевірка добутку за модулем 25:**
   ```
   g₂(x) · h₂(x) = (x² - 7) · (x² + 7) = x⁴ - 49 = x⁴ + 1 - 50 ≡ x⁴ + 1 (mod 25)
   ```
   Розклад піднято абсолютно точно.

## 6. Топологічний доказ через теорему Банаха про нерухому точку

Лема Гензеля має елегантне топологічне трактування в неархімедовому аналізі як застосування теореми Банаха про стисливе відображення до повного метричного простору p-адичних цілих чисел `Z_p`.

Нехай `f(x) ∈ Z_p[x]` — многочлен із p-адичними цілими коефіцієнтами, а `a ∈ Z_p` — наближений корінь, такий що `|f(a)|_p < 1` (тобто `f(a) ≡ 0 (mod p)`) та `|f'(a)|_p = 1` (тобто `f'(a) ≢ 0 (mod p)`).

Розглянемо замкнену кулю одиничного радіуса з центром у точці `a`:
```
B(a, 1/p) = { x ∈ Z_p : |x - a|_p ≤ 1/p }
```

Оскільки `Z_p` є повним ультраметричним простором, куля `B(a, 1/p)` також є повним метричним простором.

Визначимо оператор ітерації Ньютона `T: B(a, 1/p) → Z_p`:
```
T(x) = x - f(x) / f'(a)
```

Зауважимо, що у знаменнику стоїть фіксована величина `f'(a)` (стаціонарний метод Ньютона), а не змінна `f'(x)`. Оскільки `|f'(a)|_p = 1`, ділення на `f'(a)` не змінює p-адичної норми.

### Доказ властивості стиску:

Нехай `x, y ∈ B(a, 1/p)`. Розглянемо різницю значень оператора:
```
T(x) - T(y) = (x - y) - (f(x) - f(y)) / f'(a)
```

За теоремою Тейлора для многочлена `f` у точці `y`:
```
f(x) = f(y) + f'(y)·(x - y) + P₂(y)·(x - y)²
```

Підставивши цей вираз:
```
T(x) - T(y) = (x - y) · (1 - f'(y)/f'(a)) - (P₂(y) / f'(a)) · (x - y)²
```

Оскільки `x, y ∈ B(a, 1/p)`, маємо `y ≡ a (mod p)`, тому `f'(y) ≡ f'(a) (mod p)`. Звідси різниця похідних ділиться на `p`:
```
|1 - f'(y)/f'(a)|_p = |f'(a) - f'(y)|_p / |f'(a)|_p ≤ 1/p
```

Також для другого доданка, оскільки `|x - y|_p ≤ 1/p` та `|P₂(y)|_p ≤ 1`:
```
|(P₂(y) / f'(a)) · (x - y)²|_p ≤ |x - y|_p² ≤ (1/p) · |x - y|_p
```

За сильною нерівністю трикутника для ультраметричних просторів (`|A + B|_p ≤ max(|A|_p, |B|_p)`):
```
|T(x) - T(y)|_p ≤ (1/p) · |x - y|_p
```

Оскільки коефіцієнт стиску `λ = 1/p < 1`, оператор `T` є строго стисливим відображенням на замкненій кулі `B(a, 1/p)`.

За теоремою Банаха про нерухому точку існує єдина точка `α ∈ B(a, 1/p)`, така що:
```
T(α) = α \iff α - f(α)/f'(a) = α \iff f(α) = 0
```

Цей топологічний доказ демонструє, що лема Гензеля є прямим аналогом теореми про стисливі відображення у неархімедовому аналізі.

## 7. Підйом факторизації для довільної кількості множників (Multi-Factor Lifting)

У практичній комп'ютерній алгебрі многочлен над полем `F_p` часто розкладається не на два, а на довільну кількість `r ≥ 3` незвідних унітарних множників:

```
f(x) ≡ g₁(x) · g₂(x) · ... · g_r(x) (mod p)
```

де всі многочлени `g_i(x)` є попарно взаємно простими: `gcd(g_i, g_j) = 1` для всіх `i ≠ j`.

Для одночасного підйому `r` множників застосовують узагальнену поліноміальну тотожність Безу:

```
∑_{i=1}^r w_i(x) · G_i(x) ≡ 1 (mod p)
```

де `G_i(x) = ∏_{j ≠ i} g_j(x) = f(x) / g_i(x)` — добуток усіх множників, окрім `i`-го.

### Алгоритм одночасного мульти-підйому за один крок `k → k+1`:

1. **Обчислення загальної нев'язки:**
   ```
   M_k(x) = (f(x) - ∏_{i=1}^r g_{i, k}(x)) / pᵏ (mod p)
   ```
2. **Обчислення поправок `u_i(x)` для кожного множника:**
   Для кожного `i = 1, 2, ..., r` поліном корекції знаходиться як остача від ділення:
   ```
   u_i(x) ≡ (w_i(x) · M_k(x)) rem g_i(x) (mod p)
   ```
   Це гарантує, що ступінь кожної поправки строго менший за ступінь відповідного множника: `deg(u_i) < deg(g_i)`.
3. **Оновлення всіх множників паралельно:**
   ```
   g_{i, k+1}(x) = g_{i, k}(x) + u_i(x) · pᵏ (mod p^{k+1})
   ```

Цей підхід дозволяє піднімати факторизацію довільної кількості множників паралельно за один конвеєр обчислень.

## 8. Узагальнена лема Гензеля для кратних (особливих) коренів

Коли похідна в точці ділиться на `p` (тобто `f'(a₁) ≡ 0 (mod p)`), класична лема Гензеля не застосовується безпосередньо. Проте розв'язок у кільці p-адичних цілих чисел `Z_p` все одно може існувати, якщо значення функції прямує до нуля швидше, ніж квадрат похідної.

Позначимо через `v_p(n)` показник p-адичного нормування цілого числа `n` (найбільший степінь `e`, такий що `pᵉ` ділить `n`).

> **Теорема (Узагальнена лема Гензеля / Критерій нормування):** Нехай `f(x) ∈ Z[x]`. Припустимо, що існує ціле число `a ∈ Z` та цілий показник `e ≥ 0`, такі що:
> 1. `v_p(f'(a)) = e` (похідна ділиться на `pᵉ`, але не на `p^{e+1}`);
> 2. `v_p(f(a)) ≥ 2e + 1` (значення функції ділиться на `p^{2e+1}`).
>
> Тоді в кільці p-адичних цілих чисел `Z_p` існує **єдиний** корінь `α ∈ Z_p`, такий що `f(α) = 0` та `α ≡ a (mod p^{e+1})`.

### Доказ критерію збіжності:

Розглянемо послідовність наближень Ньютона `x₀ = a`, `x_{k+1} = x_k - f(x_k) / f'(x_k)`.

Доведемо за індукцією, що:
1. `v_p(f'(x_k)) = e` для всіх `k ≥ 0`;
2. `v_p(f(x_k)) ≥ 2e + 2^k`.

База індукції `k = 0`: за умовою `v_p(f'(x₀)) = e` та `v_p(f(x₀)) ≥ 2e + 1`.

Крок індукції: нехай `v_p(f(x_k)) = 2e + m` при `m ≥ 1`.
Поправка Ньютона `δ_k = - f(x_k) / f'(x_k)` має нормування:
```
v_p(δ_k) = v_p(f(x_k)) - v_p(f'(x_k)) = (2e + m) - e = e + m ≥ e + 1
```
Оскільки `v_p(δ_k) ≥ e + 1`, похідна в новій точці за формулою Тейлора зберігає своє нормування:
```
f'(x_k + δ_k) ≡ f'(x_k) + f''(x_k)·δ_k ≡ f'(x_k) (mod p^{e+1}) \implies v_p(f'(x_{k+1})) = e
```
Значення функції в новій точці `x_{k+1}`:
```
f(x_{k+1}) = f(x_k + δ_k) = f(x_k) + f'(x_k)·δ_k + P₂(x_k)·δ_k² = P₂(x_k)·δ_k²
```
Нормування нового значення:
```
v_p(f(x_{k+1})) ≥ 2 · v_p(δ_k) = 2 · (e + m) = 2e + 2m
```
Оскільки показник `m` на кожному кроці щонайменше подвоюється, послідовність `x_k` є фундаментальною послідовністю Коші в повному метричному просторі `Z_p` і збігається до точного кореня `α`.

### Класичний приклад: Критерій квадратів у полі 2-адичних чисел Q₂

Розглянемо рівняння `x² - d = 0` для непарного цілого числа `d` над простим числом `p = 2`.

Похідна многочлена: `f'(x) = 2x`. Для будь-якого непарного `a` маємо `v₂(f'(a)) = v₂(2a) = 1`, тобто показник `e = 1`.

Умова узагальненої леми Гензеля `v₂(f(a)) ≥ 2e + 1` набуває вигляду:
```
v₂(a² - d) ≥ 2·1 + 1 = 3 \implies a² ≡ d (mod 8)
```

Оскільки квадрат будь-якого непарного числа за модулем 8 завжди дорівнює `1` (`1² ≡ 3² ≡ 5² ≡ 7² ≡ 1 (mod 8)`), отримуємо фундаментальний критерій:

> **Критерій:** Непарне ціле число `d` має квадратний корінь у полі 2-адичних чисел `Q₂` тоді і тільки тоді, коли `d ≡ 1 (mod 8)`.

- Для `d = 17`: `17 ≡ 1 (mod 8)`, тому `√17 ∈ Q₂`.
- Для `d = 5`: `5 ≡ 5 ≢ 1 (mod 8)`. Хоча `x² ≡ 5 (mod 4)` має розв'язок `x = 1`, підйом у `Q₂` неможливий, і `√5 ∉ Q₂`.

Це вичерпно демонструє тонку межу застосовності леми Гензеля для кратних та вироджених коренів.
