# Математика ланцюгових дробів

Ланцюгові (або неперервні) дроби — це один із найелегантніших способів подання дійсних чисел. На відміну від десяткових дробів, які залежать від вибору основи числення (наприклад, 10), ланцюгові дроби відображають внутрішню, об'єктивну структуру самого числа.

Математично, ланцюговий дріб записується так:
x = a₀ + 1 / (a₁ + 1 / (a₂ + 1 / (a₃ + ...)))

Де a₀ є цілим числом, а всі наступні коефіцієнти aₙ (при n > 0) є натуральними числами (додатними цілими). Для зручності цей масивний вираз часто записують у компактній формі: [a₀; a₁, a₂, a₃, ...].

## Як обчислити ланцюговий дріб?

Алгоритм розкладу числа x у ланцюговий дріб є дуже простим і базується на виділенні цілої та дробової частин.
Нехай маємо число x.
1. Знаходимо його цілу частину a₀ = ⌊x⌋.
2. Знаходимо дробову частину: f₀ = x - a₀.
3. Якщо дробова частина дорівнює нулю (або дуже близька до нього), процес зупиняється — наше число було раціональним.
4. Якщо ні, ми "перевертаємо" дробову частину, знаходячи нове число x₁ = 1 / f₀.
5. Повторюємо процес для x₁: знаходимо його цілу частину a₁ = ⌊x₁⌋, нову дробову частину f₁ і так далі.

Розглянемо це на прикладі √2. Ми знаємо, що 1 < √2 < 2, отже, його ціла частина a₀ = 1.
x₀ = √2
a₀ = 1
f₀ = √2 - 1

Перевертаємо f₀:
x₁ = 1 / (√2 - 1)
Щоб позбутися ірраціональності в знаменнику, помножимо чисельник і знаменник на спряжений вираз (√2 + 1):
x₁ = (√2 + 1) / ( (√2 - 1)(√2 + 1) ) = (√2 + 1) / (2 - 1) = √2 + 1

Знаходимо цілу частину від x₁. Оскільки √2 ≈ 1.414, то x₁ ≈ 2.414.
a₁ = ⌊√2 + 1⌋ = 2
f₁ = (√2 + 1) - 2 = √2 - 1

Знову перевертаємо f₁:
x₂ = 1 / (√2 - 1)
Ми отримали той самий вираз, що й на кроці 1! Це означає, що процес зациклився, і всі наступні коефіцієнти будуть дорівнювати 2.
Отже, ланцюговий дріб для √2 має вигляд: [1; 2, 2, 2, ...].

Ця властивість — **періодичність ланцюгового дробу** — притаманна всім квадратним ірраціональностям, тобто числам вигляду (P + √D) / Q. Це теорема, доведена Жозефом Луї Лагранжем.

## Підхідні дроби

Головна цінність ланцюгових дробів полягає в тому, що вони генерують так звані *підхідні дроби* (конвергенти). Якщо ми відкинемо нескінченний "хвіст" дробу після певного кроку n, ми отримаємо звичайний дріб pₙ/qₙ.

Для √2 = [1; 2, 2, 2, ...]:
- Крок 0: 1 = 1/1
- Крок 1: 1 + 1/2 = 3/2 (1.5)
- Крок 2: 1 + 1/(2 + 1/2) = 1 + 1/(5/2) = 1 + 2/5 = 7/5 (1.4)
- Крок 3: 1 + 1/(2 + 2/5) = 1 + 1/(12/5) = 1 + 5/12 = 17/12 (≈1.416)

Ці дроби: 1/1, 3/2, 7/5, 17/12 почергово то перевищують істинне значення, то виявляються меншими за нього, але вони невблаганно і дуже швидко наближаються до √2.

Підхідні дроби володіють дивовижною властивістю найкращого наближення. Дріб pₙ/qₙ наближає ірраціональне число x так добре, що жоден інший дріб із знаменником, меншим або рівним qₙ, не лежить ближче до x, ніж pₙ/qₙ. Більше того, різниця між числом і його конвергентом завжди менша за 1 / qₙ².

Саме завдяки цьому інструменту математики можуть розв'язувати діофантові рівняння (наприклад, рівняння Пелля), шукати оптимальні передавальні відношення для зубчастих коліс і розуміти глибинну структуру дійсних чисел.
