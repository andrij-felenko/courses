# 📜 Історія виникнення L-функцій та теореми Діріхле

У 1837 році німецький математик Петер Густав Лежен Діріхле (нім. *Peter Gustav Lejeune Dirichlet*) опублікував у Доповідях Берлінської академії наук фундаментальну працю *"Доведення теореми про те, що кожна нескінченна арифметична прогресія, перший член і різниця якої є взаємно простими числами, містить нескінченно багатьох простих чисел"* (нім. *Beweis des Satzes, dass jede unbegrenzte arithmetische Progression...*). Ця публікація вважається офіційною датою народження аналітичної теорії чисел — розділу математики, де проблеми цілочисельної подільності та дистрибуції простих чисел розв'язуються за допомогою аналітичного апарату та теорії функцій комплексної змінної.

## Стан проблеми на початку XIX століття

Питання про нескінченність кількості простих чисел цікавило математиків з античних часів. Евклід у IV столітті до н. е. навів елегантне доведення того, що множина всіх простих чисел `P = {2, 3, 5, 7, 11, ...}` є нескінченною. Однак при спробі дослідити підмножини простих чисел, які належать до певних арифметичних прогресій `a, a + q, a + 2q, a + 3q, ...`, елементарні комбінаторні методи Евкліда швидко вичерпували свій потенціал.

Елементарними шкільними міркуваннями неважко довести нескінченність простих чисел вигляду `4k + 3` або `6k + 5`. Наприклад, для прогресії `4k + 3` припускають скінченність множини простих `p₁, p₂, ..., pₖ` і розглядають число `N = 4 · p₁ · p₂ · ... · pₖ - 1`. Оскільки всі дільники числа `N` не можуть мати вигляд `4k + 1` (добуток чисел вигляду `4k + 1` завжди має вигляд `4k + 1`), принаймні один простий дільник `N` повинен мати вигляд `4k + 3`, що призводить до негайної логічної суперечності.

Проте для дзеркального випадку `4k + 1` чи загального випадку `a + k·q` цей прийом перестає працювати: добуток двох чисел вигляду `4k + 3` дорівнює `(4a + 3)(4b + 3) = 16ab + 12a + 12b + 9 = 4(4ab + 3a + 3b + 2) + 1`, тобто повертається у клас `4k + 1`. Це означає, що число `N` цілком може складатися виключно з двох простих дільників вигляду `4k + 3` (наприклад, `9 = 3 · 3` або `21 = 3 · 7`), і ми не отримуємо жодного нового простого числа.

У 1798 році французький математик Адрієн-Марі Лежандр (фр. *Adrien-Marie Legendre*) у своїй фундаментальній монографії *"Теорія чисел"* (фр. *Théorie des nombres*) висловив гіпотезу: для будь-яких взаємно простих натуральних чисел `a` та `q` (тобто `gcd(a, q) = 1`) арифметична прогресія `a + k·q` містить нескінченно багато простих чисел.

Лежандр спробував навести доведення цієї гіпотези, спираючись на властивості введеного ним символу Лежандра та квадратичного закону взаємності. Однак його міркування містили незаповнену логічну прогалину: Лежандр неявно припустив відсутність певних вироджених систем linear рівнянь для класів залишків, що у сучасній термінології еквівалентно запереченню існування так званого нуля Зігеля (виродженого нуля L-функції поблизу точки `s = 1`). Довести відсутність таких вироджених нулів на той час було неможливо.

Карл Фрідріх Гаусс (нім. *Carl Friedrich Gauss*) у своїх знаменитих *"Арифметичних дослідженнях"* (лат. *Disquisitiones Arithmeticae*, 1801) також глибоко вивчав квадратичні форми, символ Лежандра та класи залишків. Гаусс розв'язав задачу для окремих окремих випадків (зокрема, модулів `q = 3, 4, 8`), проте відкрито визнавав, що загальний випадок для довільного модуля `q` залишається нескореним алгебраїчними методами.

## Ідея Ейлера та геніальний крок Діріхле

Вирішальним поштовхом для Діріхле стала робота Леонарда Ейлера (нім. *Leonhard Euler*) 1737 року, у якій Ейлер вперше встановив глибокий зв'язок між простими числами та нескінченними аналітичними рядами через тотожність:

```
ζ(s) = ∑_{n=1}^∞ 1 / nˢ = ∏_{p ∈ P} (1 - 1 / pˢ)⁻¹
```

Розглядаючи граничний перехід `s → 1⁺`, Ейлер помітив, що гармонічний ряд розбігається:

```
lim_{s → 1⁺} ζ(s) = ∑_{n=1}^∞ 1 / n = ∞
```

Логарифмуючи нескінченний добуток, Ейлер отримав:

```
ln ζ(s) = ∑_{p ∈ P} ln(1 - 1/pˢ)⁻¹ = ∑_{p ∈ P} 1/pˢ + O(1)
```

Оскільки `ln ζ(s) → +∞` при `s → 1⁺`, сума обернених величин простих чисел `∑ 1/p` також розбігається, що надало перше аналітичне доведення нескінченності множини всіх простих чисел.

Завдання Діріхле полягало в тому, щоб модифікувати суму `∑ 1/pˢ` таким чином, щоб ізолювати лише ті прості числа `p`, які задовольняють порівняння `p ≡ a (mod q)`.

Пряме застосування характеристичної функції `1`, якщо `p ≡ a (mod q)` і `0` в іншому випадку, руйнує мультиплікативну структуру, що унеможливлює розклад у добуток Ейлера. Діріхле зробив геніальне відкриття: замість адитивних індикаторів слід застосувати **гармонічний аналіз на скінченній абелевій групі** приведених класів залишків `G = (ℤ/qℤ)*`.

Діріхле навчався у Парижі у таких видатних математиків, як Жозеф Фур'є, та глибоко засвоїв ідею розкладу функцій у ортогональні ряди Фур'є. Він зрозумів, що подібний гармонічний розклад можна побудувати на скінченних абелевих групах залишків.

Діріхле ввів нові математичні об'єкти — **числові характери** (лат. *characteres*), які є періодичними мультиплікативними функціями `χ: ℤ → ℂ`. Використовуючи співвідношення ортогональності для характерів, Діріхле записав індикатор належності до класу `a (mod q)` як лінійну комбінацію всіх характерів за модулем `q`:

```
δ(p ≡ a mod q) = (1 / φ(q)) · ∑_{χ (mod q)} χ̄(a) · χ(p)
```

де `φ(q)` — функція Ейлера, а `χ̄(a)` — комплексно-спряжене значення характера.

## Народження L-функцій та вирішальний бар'єр

Підставивши цей вираз у суму за простими числами, Діріхле ввів новий клас функцій, які сьогодні носять його ім'я:

```
L(s, χ) = ∑_{n=1}^∞ χ(n) / nˢ = ∏_{p ∈ P} (1 - χ(p) / pˢ)⁻¹
```

Для головного характера `χ₀` (який дорівнює `1` для всіх `n`, взаємно простих з `q`), L-функція `L(s, χ₀)` поводиться подібно до Дзета-функції Ейлера-Рімана `ζ(s)` і має простий полюс у точці `s = 1`. Відповідно, `ln L(s, χ₀)` прямує до `+∞` при `s → 1⁺`.

Для всіх неголовних характерів `χ ≠ χ₀` сума значень характера за повним періодом дорівнює нулю (`∑_{n=1}^q χ(n) = 0`). Завдяки цьому ряд `L(s, χ)` є збіжним у точці `s = 1` і визначає скінченне аналітичне значення.

Тоді логарифмічна сума для конкретного класу залишків приймає вигляд:

```
∑_{p ≡ a (mod q)} 1 / pˢ = (1 / φ(q)) · ln L(s, χ₀) + (1 / φ(q)) · ∑_{χ ≠ χ₀} χ̄(a) · ln L(s, χ) + O(1)
```

Щоб отримати бажану розбіжність `∑_{p ≡ a (mod q)} 1/p = ∞` при `s → 1⁺`, необхідно довести, що другий доданок (сума за неголовними характерами) залишається скінченним. А це можливо тоді і тільки тоді, коли значення **`L(1, χ) ≠ 0` для кожного неголовного характера `χ ≠ χ₀`**! Якщо б для якогось характера `L(1, χ) = 0`, то `ln L(s, χ)` прямував би до `-∞`, що могло б повністю компенсувати нескінченність від головного характера `ln L(s, χ₀) → +∞`.

Доведення незвернення в нуль `L(1, χ) ≠ 0` виявилося найважчою частиною теореми. Для комплексних характерів (`χ ≠ χ̄`) Діріхле знайшов елегантний довід із використанням добутку всіх L-функцій. Проте для дійсних (квадратичних) характерів (`χ = χ̄`, значення `±1`) цей метод не працював.

Щоб подолати цей бар'єр для дійсних характерів, Діріхле встановлює глибокий зв'язок між значенням `L(1, χ)` та кількістю класів бінарних квадратичних форм з дискримінантом `D`. Це привело його до створення **формули числа класів Діріхле** (англ. *Dirichlet class number formula*):

```
L(1, χ) = (2π / (w · √|D|)) · h(D)      [для від'ємного дискримінанта D < 0]
L(1, χ) = (2 · ln ε / √D) · h(D)        [для додатного дискримінанта D > 0]
```

Оскільки число класів квадратичних форм `h(D)` є натуральним числом (`h(D) ≥ 1`), значення `L(1, χ)` строго додатне (`L(1, χ) > 0`), що остаточно довело незвернення в нуль і завершило доведення теореми.

## Історична спадщина та подальший розвиток

Праця Діріхле 1837 року мала колосальний вплив на розвиток усієї математики:

1. **Теорія груп і представлень:** Застосування характерів на абелевих групах заклало основи гармонічного аналізу на скінченних групах та абстрактної алгебри, розвинутої пізніше Ріхардом Дедекіндом, Леопольдом Кронекером і Георгом Фроберіусом.
2. **Аналітична теорія чисел:** Робота проклала шлях для знаменитої праці Бернгарда Рімана 1859 року про дзета-функцію та розподіл нулів у комплексній площині, а також для доведення Теореми про розподіл простих чисел Жаком Адамаром та Шарлем-Жаном де ла Валле-Пуссеном у 1896 році.
3. **Алгебраїчна теорія чисел:** Формула числа класів показала, що аналітична поведінка L-функцій містить у собі фундаментальні інваріанти алгебраїчних числових полів (число класів `h`, регулятор `R`, кількість коренів з одиниці `w`).
4. **Сучасний прорив XXI століття:** У 2013 році китайсько-американський математик Ітан Чжан (англ. *Yitang Zhang*) зробив видатний прорив у доведенні існування обмежених інтервалів між простими числами (`p_{n+1} - p_n < 70 000 000`). Його доведення спиралося безпосередньо на оцінки розподілу нулів L-функцій Діріхле та відсутність виродженого нуля Зігеля (англ. *Landau-Siegel zero*).

Сьогодні L-функції Діріхле є першим та найпростішим представником величезного сімейства L-функцій у сучасній математиці — від L-функцій Гекке та Артіна у теорії полів класів до L-функцій автоморфних форм у програмі Ленглендса та L-функцій еліптичних кривих у гіпотезі Берча і Свіннертон-Даєра.

Евіденційний статус результату Діріхле — повністю доведений класичний результат, що становить основу сучасної числової науки.
