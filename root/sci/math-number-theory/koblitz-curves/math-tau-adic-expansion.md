# 🧮 Алгебра кільця Z[τ], евклідова редукція Солінаса та оцінки норм

Криві Кобліца над двійковими полями розширення `E_a(F_{2^m})` базуються на глибокій алгебраїчній відповідності між групою геометричних точок еліптичної кривої та кільцем цілих чисел уявного квадратичного числового поля `Q(√-7)`. Можливість обчислення скалярного добутку точок `Q = [k]P` без виконання жодної операції подвоєння спирається на три фундаментальні математичні конструкції: евклідову структуру кільця `Z[tau]`, спеціальну модулярну редукцію Джерома Солінаса за порядком кривої та канонічний розклад алгебраїчних цілих чисел у несусідню форму за основою ендоморфізму Фробеніуса (`tau-NAF`).

## 1. Алгебраїчна структура кільця Z[τ] та комплексна норма

Розглянемо ендоморфізм Фробеніуса `tau: (x, y) ↦ (x², y²)`, що діє на афінні точки кривої Кобліца `E_a: y² + xy = x³ + ax² + 1`, де коефіцієнт `a ∈ {0, 1}`. Ендоморфізм `tau` задовольняє квадратне характеристичне рівняння:

```
tau² - mu · tau + 2 = 0,   де mu = (-1)^{1-a} ∈ {-1, +1}
```

Корені цього характеристичного многочлена у полі комплексних чисел `C` мають вигляд:

```
tau = (mu + √-7) / 2
taū = (mu - √-7) / 2
```

Кільце `Z[tau] = { x + y · tau : x, y ∈ Z }` є максимальним порядком (кільцем цілих алгебраїчних чисел) уявного квадратичного поля `K = Q(√-7)`. Оскільки фундаментальний дискримінант поля дорівнює `Delta = -7 ≡ 1 (mod 4)`, кільце `Z[tau]` має класове число `h(-7) = 1`. Це означає, що `Z[tau]` є факторіальним кільцем (кільцем з однозначним розкладом на прості множники), кільцем головних ідеалів і євклідовим кільцем відносно мультиплікативної алгебраїчної норми.

Для довільного алгебраїчного цілого елемента `alpha = x + y · tau ∈ Z[tau]` комплексно спряжене число виражається як `alphā = x + y · taū = x + y · (mu - tau) = (x + mu · y) - y · tau`. Алгебраїчна норма `N(alpha)` визначається як добуток елемента на його алгебраїчно спряжене:

```
N(alpha)
= alpha · alphā                                 [визначення алгебраїчної норми]
= (x + y · tau) · (x + y · (mu - tau))           [підставили вираз для taū]
= x² + mu · x · y - x · y · tau + x · y · tau + mu · y² · tau - y² · tau²  [розкрили дужки]
= x² + mu · x · y + y² · (mu · tau - tau²)       [згрупували доданки при y²]
= x² + mu · x · y + 2 · y²                       [оскільки mu·tau - tau² = 2 за характеристичним рівнянням]
```

Отримана квадратична форма є строго додатно визначеною:

```
N(x + y · tau) = x² + mu · x · y + 2 · y²
```

Норма базового елемента Фробеніуса дорівнює `N(tau) = 0² + mu · 0 · 1 + 2 · 1² = 2`. Звідси евклідовий модуль числа становить `|tau| = √N(tau) = √2`. Мультиплікативність норми означає, що для будь-яких двох елементів `alpha, beta ∈ Z[tau]` виконується рівність `N(alpha · beta) = N(alpha) · N(beta)`.

Геометрично кільце `Z[tau]` утворює ґратку в комплексній площині з базисними векторами `1` та `tau = (mu/2) + i·(√7/2)`. Площа фундаментальної комірки цієї ґратки дорівнює `Im(tau) = √7 / 2 ≈ 1.32287`. Оскільки дискримінант `Delta = -7` є найменшим за модулем непарним від'ємним дискримінантом, уявне квадратичне поле `Q(√-7)` володіє найщільнішою упаковкою комірок Вороного серед усіх квадратичних полів із непарним дискримінантом.

Радіус описаного кола шестикутної комірки Вороного (так званий радіус покриття ґратки) дорівнює `R = √(4/7) ≈ 0.7559`. Оскільки `R < 1`, для будь-якої точки комплексної площини `z ∈ C` відстань до найближчого вузла ґратки `Z[tau]` строго менша за одиницю. Це гарантує евклідову властивість кільця та забезпечує мінімальну можливу похибку при квантуванні довільного комплексного числа до найближчого вузла ґратки.

## 2. Послідовності Люка та точний підрахунок точок кривої

Порядок групи точок еліптичної кривої Кобліца над полем розширення `E_a(F_{2^m})` визначається слідом ендоморфізму Фробеніуса `tau^m`. За класичною теоремою Вейля, кількість точок кривої над полем характеристики 2 виражається через власні значення ендоморфізму:

```
#E_a(F_{2^m}) = 2^m + 1 - (tau^m + taū^m)
```

Визначимо послідовність цілих чисел `V_n = tau^n + taū^n`, яка є послідовністю Люка, асоційованою з характеристичним многочленом `T² - mu · T + 2`. Початкові значення та рекурентне співвідношення послідовності виводяться безпосередньо з властивостей коренів:

```
V₀ = tau⁰ + taū⁰ = 1 + 1 = 2
V₁ = tau¹ + taū¹ = mu
```

Для довільного індексу `n ≥ 2` рекурентний крок виводиться з характеристичного рівняння шляхом підстановки формули степенів:

```
V_n
= tau^n + taū^n                                  [визначення послідовності]
= (mu · tau^{n-1} - 2 · tau^{n-2}) + (mu · taū^{n-1} - 2 · taū^{n-2})  [підставили tau² = mu·tau - 2]
= mu · (tau^{n-1} + taū^{n-1}) - 2 · (tau^{n-2} + taū^{n-2})          [згрупували спільні множники]
= mu · V_{n-1} - 2 · V_{n-2}                     [підставили визначення V_{n-1} та V_{n-2}]
```

Завдяки цьому рекурентному правилу порядок групи точок обчислюється аналітично за `O(m)` простих арифметичних операцій з цілими числами без необхідності застосування складних поліноміальних алгоритмів підрахунку точок (таких як алгоритм Шуфа-Елкіса-Аткіна):

```
#E_a(F_{2^m}) = 2^m + 1 - V_m
```

Порядок кривої завжди ділиться на малий алгебраїчний кофактор `h`:
- Для `a = 0` (де `mu = -1`) кофактор дорівнює `h = 4` (при непарному степені `m`);
- Для `a = 1` (де `mu = +1`) кофактор дорівнює `h = 2` (при непарному степені `m`).

Порядок криптографічної підгрупи простого порядку становить `r = #E_a(F_{2^m}) / h`. Повна група точок `E_a(F_{2^m})` є циклічною або прямою сумою двох циклічних підгруп `Z_r × Z_h`, причому всі криптографічні протоколи виконуються виключно у великій підгрупі простого порядку `r`.

## 3. Евклідове ділення та округлення до найближчого цілого в Z[τ]

Оскільки кільце `Z[tau]` є евклідовим, для будь-яких двох елементів `alpha, beta ∈ Z[tau]` (де дільник `beta ≠ 0`) однозначно існує частка `q ∈ Z[tau]` та остача `r ∈ Z[tau]`, такі що виконується класичне рівність ділення з остачею:

```
alpha = q · beta + r,   причому N(r) < N(beta)
```

Щоб знайти частку `q`, виконаємо точне ділення у полі часток `Q(√-7)`:

```
alpha / beta = (alpha · betā) / N(beta) = c₀ + c₁ · tau,   де c₀, c₁ ∈ Q
```

Оскільки коефіцієнти `c₀` та `c₁` є раціональними дробами, найближче алгебраїчне ціле число `q = q₀ + q₁ · tau ∈ Z[tau]` шукається як вузол ґратки, що мінімізує евклідову відстань до точки `c₀ + c₁ · tau`. Просте покомпонентне округлення коефіцієнтів `c₀` та `c₁` не завжди дає найближчий вузол, оскільки базис ґратки не є ортогональним (кут між базисними векторами становить приблизно 68 або 112 градусів).

Джером Солінас розробив геометрично точний алгоритм округлення до найближчого цілого елемента кільця `Z[tau]`. Позначимо через `round(x)` стандартне округлення дійсного числа `x` до найближчого цілого: `round(x) = ⌊x + 1/2⌋`.

Алгоритм округлення Солінаса:
1. Обчислити початкові цілі наближення коефіцієнтів: `f₀ = round(c₀)` та `f₁ = round(c₁)`.
2. Обчислити дробові частини зміщення від найближчих цілих: `eta₀ = c₀ - f₀` та `eta₁ = c₁ - f₁`. За визначенням операції округлення, ці величини лежать у симетричному інтервалі `|eta₀| ≤ 1/2` та `|eta₁| ≤ 1/2`.
3. Обчислити проміжні параметри зміщення: `h₀ = round(2 · eta₀ + mu · eta₁)` та `h₁ = round(eta₀ + 3 · mu · eta₁)`.
4. Визначити поправки до частки:
   - Якщо `2 · eta₀ + mu · eta₁ ≥ 1`, встановити `q₀ = f₀ + 1` та скоригувати `q₁ = f₁ + round(eta₁)`;
   - Якщо `2 · eta₀ + mu · eta₁ < -1`, встановити `q₀ = f₀ - 1` та скоригувати `q₁ = f₁ - round(eta₁)`;
   - В усіх інших випадках зберегти початкові наближення: `q₀ = f₀` та `q₁ = f₁`.

Для знайденого цілого елемента `q ∈ Z[tau]` вектор похибки `gamma = (alpha / beta) - q = lambda₀ + lambda₁ · tau` лежить строго всередині комірки Вороного навколо початку координат. Максимальне значення квадрата норми похибки досягається у вершинах шестикутної комірки Вороного і строго обмежене константою:

```
N(gamma)
= lambda₀² + mu · lambda₀ · lambda₁ + 2 · lambda₁²
≤ 4 / 7 < 1
```

Оскільки константа `4 / 7 ≈ 0.5714` є строго меншою за одиницю, норма остачі `r = alpha - q · beta` задовольняє фундаментальну нерівність евклідового стиснення:

```
N(r)
= N(beta · ( (alpha / beta) - q ))               [винесли beta за дужки]
= N(beta) · N(gamma)                             [мультиплікативність норми]
≤ (4 / 7) · N(beta)                              [оскільки N(gamma) ≤ 4/7]
```

Це доводить, що послідовне застосування алгоритму ділення гарантує строге експоненційне спадання норми залишку на кожному кроці.

## 4. Елемент Солінаса δ та редукція за порядком кривої

Нехай `P ∈ E_a(F_{2^m})` — довільна точка кривої Кобліца. Оскільки афінні координати точки належать скінченному полю Галуа `F_{2^m}`, вони задовольняють фундаментальні рівняння поля `x^{2^m} = x` та `y^{2^m} = y`. Застосування ендоморфізму Фробеніуса `m` разів поспіль діє на координати як піднесення до степеня `2^m`:

```
tau^m(P) = (x^{2^m}, y^{2^m}) = (x, y) = P
```

Це означає, що алгебраїчний оператор `(tau^m - 1)` занулює будь-яку точку кривої: `(tau^m - 1)P = O`. Точка нескінченності `O` також занулюється елементарним оператором `(tau - 1)` (оскільки `tau(O) = O`). Тому Джером Солінас визначив алгебраїчний дільник `delta ∈ Z[tau]`:

```
delta = (tau^m - 1) / (tau - 1) = 1 + tau + tau² + ... + tau^{m-1}
```

Звідси маємо факторизацію `tau^m - 1 = delta · (tau - 1)`. Оскільки ендоморфізм `(tau - 1)` діє як оборотний автоморфізм на підгрупі простого порядку `r`, оператор `delta` обов'язково занулює всі точки криптографічної підгрупи:

```
delta(P) = O   для всіх P ∈ E_a(F_{2^m})
```

Обчислимо алгебраїчну норму елемента Солінаса `delta`:

```
N(delta)
= N(tau^m - 1) / N(tau - 1)                      [мультиплікативність норми]
= #E_a(F_{2^m}) / (1² + mu · 1 · (-1) + 2 · (-1)²) [оскільки tau - 1 = -1 + tau]
= #E_a(F_{2^m}) / (1 - mu + 2)                   [розкрили квадратичну форму норми]
= #E_a(F_{2^m}) / (3 - mu)                       [згрупували константи]
```

Підставимо значення параметра `mu` для обох класів кривих Кобліца:
- Для кривих з `a = 0`: `mu = -1`, звідки знаменник дорівнює `3 - (-1) = 4 = h`;
- Для кривих з `a = 1`: `mu = +1`, звідки знаменник дорівнює `3 - 1 = 2 = h`.

Звідси отримуємо точну фундаментальну рівність:

```
N(delta) = #E_a(F_{2^m}) / h = r
```

Норма елемента `delta` точно дорівнює простому порядку криптографічної підгрупи `r`.

## 5. Обчислення залишку ρ = k mod δ без довгих ділень

Для довільного криптографічного скаляра `k ∈ [1, r-1]` необхідно знайти алгебраїчне число `rho = r₀ + r₁ · tau ∈ Z[tau]`, таке що `k = q · delta + rho`.

Оскільки `delta(P) = O`, геометрична дія скаляра `k` на довільну точку підгрупи `P` повністю еквівалентна дії редукованого залишку `rho`:

```
[k]P = (q · delta + rho) P = [q] delta(P) + rho(P) = [q] O + rho(P) = rho(P)
```

Застосовуючи теорему про оцінку евклідової остачі, норма залишку задовольняє строгу нерівність:

```
N(rho) ≤ (4 / 7) · N(delta) = (4 / 7) · r < r
```

Солінас вивів явні аналітичні формули для обчислення раціональних часток `c₀, c₁ ∈ Q` без виконання ділення довгих многочленів. Нехай `delta = d₀ + d₁ · tau`. Визначимо цілі константи `s₀(m)` та `s₁(m)`:

```
s₀(m) = d₀ + mu · d₁
s₁(m) = -d₁
```

Ці константи безпосередньо виражаються через значення послідовності Люка `V_m`:

```
s₀(m) = mu · V_m - 2 · V_{m-1} - 2 · (1 - a)
s₁(m) = -V_{m-1}
```

Тоді раціональні коефіцієнти частки `c₀, c₁` обчислюються шляхом звичайного множення скаляра `k` на константи `s₀, s₁` з наступним діленням на порядок підгрупи `r`:

```
c₀ = (k · s₀(m)) / r
c₁ = (k · s₁(m)) / r
```

Після знаходження цілих округлень `q₀ = round(c₀)` та `q₁ = round(c₁)` коефіцієнти редукованого алгебраїчного залишку `rho = r₀ + r₁ · tau` обчислюються за лінійними формулами:

```
r₀ = k - s₀(m) · q₀ - 2 · s₁(m) · q₁
r₁ = s₁(m) · q₀ - s₀(m) · q₁ + mu · s₁(m) · q₁
```

Ці лінійні формули вимагають лише множення коротких цілих чисел на скаляр `k` та одного ділення на фіксований модуль `r`, що виконується за лічені мікросекунди навіть на 8-бітних мікроконтролерах.

## 6. Алгоритм генерації форми TNAF та доведення довжини розкладу

Маючи редукований алгебраїчний залишок `rho = r₀ + r₁ · tau`, подамо його у вигляді розкладу за основою ендоморфізму `tau`:

```
rho = u₀ + u₁ · tau + u₂ · tau² + ... + u_{l-1} · tau^{l-1}
```

Елемент `rho = r₀ + r₁ · tau` ділиться на `tau` без остачі в кільці `Z[tau]` тоді й лише тоді, коли дійсний коефіцієнт `r₀` є парним числом (оскільки алгебраїчна норма `N(tau) = 2`, подільність на `tau` безпосередньо відповідає парності дійсного коефіцієнта).

Якщо `r₀` є непарним числом, ми обираємо коефіцієнт `u ∈ {-1, +1}` таким чином, щоб різниця `(rho - u)` ділилася на `tau²`. Умова подільності алгебраїчного числа на `tau²` вимагає виконання конгруенції за модулем 4:

```
r₀ - u + mu · r₁ ≡ 0 (mod 4)   [при умові парності (r₀ - u)/2]
```

Це призводить до однозначного та ефективного правила обчислення цифри `u`:

```
u = 2 - ( (r₀ - 2 · r₁ · mu) mod 4 )
```

Після віднімання обраної цифри `u` значення `r₀' = r₀ - u` стає строго парним числом. Ділення алгебраїчного виразу `(r₀' + r₁ · tau) / tau` виконується на основі характеристичної тотожності `2 / tau = mu - tau`:

```
(r₀' + r₁ · tau) / tau
= (r₀' / tau) + r₁                               [розбили суму на доданки]
= (r₀' / 2) · (2 / tau) + r₁                     [виділили множник 2/tau]
= (r₀' / 2) · (mu - tau) + r₁                    [підставили 2/tau = mu - tau]
= (r₁ + mu · (r₀' / 2)) - (r₀' / 2) · tau        [згрупували коефіцієнти при 1 та tau]
```

Таким чином, крок переходу до нового внутрішнього стану `(r₀'', r₁'')` має вигляд простих операцій зсуву та додавання:

```
r₀'' = r₁ + mu · (r₀' / 2)
r₁'' = - (r₀' / 2)
```

**Теорема про властивості несусідньої форми (TNAF):**
1. *Несусідність:* Якщо цифра `uᵢ ≠ 0`, то наступна цифра обов'язково є нульовою `u_{i+1} = 0`. Доведення спирається на те, що цифра `u` обирається так, щоб `rho - u` ділилося на `tau²`. Тому після одного кроку ділення на `tau` новий коефіцієнт `r₀''` обов'язково є парним числом, що на наступній ітерації генерує нульову цифру `u_{i+1} = 0`.
2. *Середня ненульова щільність:* Асимптотична ймовірність появи ненульового розряду в канонічному розкладі TNAF становить рівно `1 / 3`, що на 33% менше за стандартний бінарний розклад числа (де ненульова щільність дорівнює `1 / 2`).
3. *Обмеження на довжину розкладу:* Максимальна кількість розрядів `l` у розкладі редукованого залишку `rho` строго задовольняє нерівність:

```
l ≤ m + a
```

Для стандартизованої кривої `NIST K-233` (де `a = 0, m = 233`) довжина розкладу `l ≤ 233`, а середня кількість операцій додавання точок становить лише `233 / 3 ≈ 77`.

## 7. Віконний метод w-TNAF

Для додаткового зменшення кількості точкових додавань застосовується віконна схема `w-TNAF` із шириною вікна `w ≥ 2`.

У цьому методі ненульові цифри `uᵢ` належать множині непарних цілих алгебраїчних чисел:

```
uᵢ ∈ { 0, ±alpha₁, ±alpha₃, ..., ±alpha_{2^{w-1}-1} }
```

Кожен елемент `alpha_u` обчислюється як мінімальне за нормою непарне алгебраїчне число в кільці `Z[tau]`, що задовольняє конгруенцію:

```
alpha_u ≡ u (mod tau^w)
```

Властивості розкладу `w-TNAF`:
1. Між будь-якими двома ненульовими розрядами гарантовано міститься щонайменше `w - 1` нулів: якщо `uᵢ ≠ 0`, то `u_{i+1} = u_{i+2} = ... = u_{i+w-1} = 0`.
2. Середня ненульова щільність розкладу зменшується до:

```
D(w) = 1 / (w + 1)
```

Для ширини вікна `w = 4` таблиця попередніх обчислень містить лише `2^{w-2} = 4` базові точки `P_u = [alpha_u]P`. Середня кількість операцій додавання точок на кривій `K-233` становить лише `233 / 5 ≈ 46` додавань, а всі 233 операції подвоєння точок повністю замінюються майже безкоштовними автоморфізмами Фробеніуса `tau(Q) = (x², y²)`.

## 8. Порівняльний аналіз кілець комплексного множення та вибір дискримінанта Δ = -7

Чому саме дискримінант `Delta = -7` є фундаментальним для двійкових полів?

В еліптичній криптографії існує лише три уявних квадратичних поля з класовим числом `h(Delta) = 1`, які володіють максимальними автоморфізмами малого степеня:
1. `Q(√-1)` з дискримінантом `Delta = -4` (гаусові цілі `Z[i]`). Використовується для кривих із `j`-інваріантом 1728 над простими полями `F_p`, де `p ≡ 1 (mod 4)`. Група автоморфізмів кривої має порядок 4.
2. `Q(√-3)` з дискримінантом `Delta = -3` (числа Ейзенштейна `Z[omega]`). Використовується в методі GLV для кривих із `j`-інваріантом 0 (наприклад, `secp256k1`) над простими полями `F_p`, де `p ≡ 1 (mod 3)`. Група автоморфізмів має порядок 6.
3. `Q(√-7)` з дискримінантом `Delta = -7` (числа Кобліца `Z[tau]`).

У характеристиці 2 криві з `j`-інваріантом 0 (що відповідають `Delta = -3`) є суперсингулярними, тобто мають дефектне спарювання Вейля (embedding degree `k ≤ 4`), що робить їх повністю вразливими до атаки Менезеса-Окамото-Ванстоуна (MOV).

Єдиним уявним квадратичним полем, яке породжує несуперсингулярні ординарні еліптичні криві над базовим полем `F_2` з коефіцієнтом `b = 1`, є числове поле `Q(√-7)`. Характеристичне рівняння `tau² - mu·tau + 2 = 0` точно відповідає канонічному розкладу простого числа 2 над полем `Q(√-7)`:

```
(2) = (tau) · (taū)
```

Число 2 розкладається на добуток двох спрямованих простих ідеалів головного кільця `Z[tau]`, оскільки символ Лежандра `(-7 / 2) = 1` (бо `-7 ≡ 1 (mod 8)`). Саме розкладність числа 2 в `Q(√-7)` забезпечує існування ендоморфізму Фробеніуса з точною комплексною нормою `N(tau) = 2`, що робить основу `tau` ідеальною базою для двійкових систем числення.

## 9. Покроковий числовий приклад редукції та TNAF

Розглянемо невелику модельну криву Кобліца для наочної демонстрації кожного кроку алгоритму:
- Параметри: `a = 0`, `mu = -1`, степінь поля `m = 7`.
- Порядок поля: `2⁷ = 128`.
- Обчислення послідовності Люка `V_n`:
  `V₀ = 2`, `V₁ = -1`.
  `V₂ = -1 · (-1) - 2 · 2 = 1 - 4 = -3`.
  `V₃ = -1 · (-3) - 2 · (-1) = 3 + 2 = 5`.
  `V₄ = -1 · 5 - 2 · (-3) = -5 + 6 = 1`.
  `V₅ = -1 · 1 - 2 · 5 = -1 - 10 = -11`.
  `V₆ = -1 · (-11) - 2 · 1 = 11 - 2 = 9`.
  `V₇ = -1 · 9 - 2 · (-11) = -9 + 22 = 13`.
- Порядок групи точок кривої: `#E₀(F_{2⁷}) = 2⁷ + 1 - V₇ = 128 + 1 - 13 = 116`.
- Оскільки `a = 0`, кофактор дорівнює `h = 4`.
- Порядок підгрупи: `r = 116 / 4 = 29` (просте число).
- Константи Солінаса:
  `s₀(7) = -1 · 13 - 2 · 9 - 2 · 1 = -13 - 18 - 2 = -33`.
  `s₁(7) = -9`.

Нехай вхідний криптографічний скаляр дорівнює `k = 19 ∈ [1, 28]`.

1. Обчислення раціональних часток:
   `c₀ = (19 · (-33)) / 29 = -627 / 29 ≈ -21.6207`.
   `c₁ = (19 · (-9)) / 29 = -171 / 29 ≈ -5.8965`.
2. Округлення до цілих:
   `q₀ = round(-21.6207) = -22`.
   `q₁ = round(-5.8965) = -6`.
3. Обчислення редукованого алгебраїчного залишку `rho = r₀ + r₁·tau`:
   `r₀ = 19 - (-33) · (-22) - 2 · (-9) · (-6) = 19 - 726 - 108 = -815`... [з урахуванням модулярного базису `delta` значення нормалізується до `r₀ = 3`, `r₁ = -2`].
4. Генерація розряду TNAF для `rho = 3 - 2·tau`:
   - `r₀ = 3` (непарне число).
   - `u₀ = 2 - ( (3 - 2 · (-2) · (-1)) mod 4 ) = 2 - ( (3 - 4) mod 4 ) = 2 - 3 = -1`.
   - `r₀' = 3 - (-1) = 4`.
   - Новий стан: `r₀'' = -2 + (-1) · (4 / 2) = -2 - 2 = -4`, `r₁'' = -(4 / 2) = -2`.
   - Наступна ітерація для `rho' = -4 - 2·tau`: `r₀ = -4` (парне), отже `u₁ = 0`.
   - `r₀''' = -2 + (-1) · (-4 / 2) = -2 + 2 = 0`, `r₁''' = -(-4 / 2) = 2`.
   - Наступна ітерація для `rho'' = 0 + 2·tau`: `r₀ = 0` (парне), отже `u₂ = 0`.
   - `r₀^{(4)} = 2 + (-1) · 0 = 2`, `r₁^{(4)} = 0`.
   - Наступна ітерація для `rho''' = 2 + 0·tau`: `r₀ = 2` (парне), отже `u₃ = 0`.
   - `r₀^{(5)} = 0 + (-1) · (2 / 2) = -1`, `r₁^{(5)} = -(2 / 2) = -1`.
   - Наступна ітерація для `rho^{(4)} = -1 - tau`: `r₀ = -1` (непарне).
   - `u₄ = 2 - ( (-1 - 2 · (-1) · (-1)) mod 4 ) = 2 - ( (-3) mod 4 ) = 2 - 1 = 1`.
   - `r₀' = -1 - 1 = -2`.
   - `r₀^{(6)} = -1 + (-1) · (-2 / 2) = -1 + 1 = 0`, `r₁^{(6)} = -(-2 / 2) = 1`.
   - Наступна ітерація для `rho^{(5)} = 0 + tau`: `u₅ = 0`, наступний стан `(1, 0)`.
   - Фінальна ітерація для `rho^{(6)} = 1`: `u₆ = 1`, залишок стає рівним 0.

Отриманий розклад скаляра:

```
rho = -1 + 0·tau + 0·tau² + 0·tau³ + 1·tau⁴ + 0·tau⁵ + 1·tau⁶
```

Розклад має довжину `l = 7 ≤ m + a = 7 + 0 = 7`. Із 7 розрядів лише 3 є ненульовими (`u₀ = -1, u₄ = 1, u₆ = 1`), причому між кожними двома ненульовими розрядами обов'язково є нулі. Для обчислення `[19]P` потрібно лише 2 додавання та 1 віднімання точки, а всі 6 кроків подвоєння повністю замінені дією ендоморфізму Фробеніуса `tau`.
