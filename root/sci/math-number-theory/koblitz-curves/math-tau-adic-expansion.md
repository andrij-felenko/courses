# 🧮 Алгебра кільця Z[τ], евклідова редукція Солінаса та оцінки норм

Криві Кобліца над двійковими полями розширення `E_a(F_{2^m})` базуються на глибокій алгебраїчній відповідності між групою геометричних точок еліптичної кривої та кільцем цілих чисел уявного квадратичного числового поля `Q(√-7)`. Обчислення скалярного добутку точок `Q = [k]P` на апаратних пристроях з обмеженими ресурсами (смарт-картах, захищених мікроконтролерах) традиційно впирається у високу обчислювальну складність геометричного подвоєння точок `[2]P`. На кривих Кобліца операція подвоєння повністю замінюється природним алгебраїчним автоморфізмом Фробеніуса `tau(x, y) = (x², y²)`, піднесення координат до квадрата в двійкових полях виконується за лінійний час без множень, а скалярний добуток обчислюється через канонічний несусідній тау-адичний розклад скаляра (`tau-NAF`).

Цей математичний апарат спирається на три фундаментальні конструкції: евклідову структуру кільця алгебраїчних цілих чисел `Z[tau]`, спеціальну модулярну редукцію Джерома Солінаса за дільником порядку кривої та скінченний автомат генерації цифр розкладу за основою ендоморфізму Фробеніуса.

## 1. Ендоморфізм Фробеніуса та виведення характеристичного рівняння

Розглянемо аномальну бінарну еліптичну криву Кобліца `E_a`, задану над базовим двійковим полем `F_2 = {0, 1}` довгим рівнянням Вейєрштрасса:

```
E_a: y² + xy = x³ + a · x² + 1,   де a ∈ {0, 1}
```

Нехай `P = (x, y) ∈ E_a(F_{2^m})` — довільна афінна точка кривої, координати якої належать полю розширення `F_{2^m}`. Відображення Фробеніуса `tau: E_a(F_{2^m}) → E_a(F_{2^m})` діє на координати точки як покомпонентне піднесення до квадрата:

```
tau(x, y) = (x², y²),   tau(O) = O
```

Перевіримо коректність відображення `tau` як ендоморфізму кривої. У скінченному полі характеристики 2 операція піднесення до квадрата є лінійним автоморфізмом поля (відомим як гомоморфізм Фробеніуса), оскільки для будь-яких елементів `u, v ∈ F_{2^m}` виконується тотожність `(u + v)² = u² + 2uv + v² = u² + v²`. Піднесемо обидві частини рівняння кривої до квадрата:

```
(y²)² + (x²) · (y²)
= (y² + xy)²                                     [лінійність квадрата в характеристиці 2]
= (x³ + a · x² + 1)²                              [підставили рівняння кривої]
= (x²)³ + a² · (x²)² + 1²                        [розкрили квадрат суми]
= (x²)³ + a · (x²)² + 1                          [оскільки a ∈ {0, 1}, маємо a² = a та 1² = 1]
```

Отриманий вираз доводить, що нова точка `(x², y²)` точно задовольняє вихідне рівняння кривої `E_a`. Оскільки груповий закон додавання точок `P₃ = P₁ + P₂` задається раціональними функціями від координат із числовими коефіцієнтами виключно з базового поля `F_2`, дія автоморфізму поля на координати зберігає закон групової операції:

```
tau(P₁ + P₂) = tau(P₁) + tau(P₂)   для всіх P₁, P₂ ∈ E_a(F_{2^m})
```

Отже, відображення `tau` є ендоморфізмом алгебраїчної групи точок кривої.

Згідно з класичною теоремою Вейля та теоремою Гассе про ендоморфізми еліптичних кривих над скінченними полями, ендоморфізм Фробеніуса над полем `F_q` (де `q = 2`) задовольняє квадратне характеристичне рівняння:

```
tau² - t · tau + 2 = 0
```

де `t` — цілочисельний слід ендоморфізму Фробеніуса, який безпосередньо пов'язаний з кількістю афінних точок кривої над базовим підполем `F_2` фундаментальним співвідношенням:

```
#E_a(F_2) = 2 + 1 - t = 3 - t   =>   t = 3 - #E_a(F_2)
```

Виконаємо прямий аналітичний підрахунок кількості точок кривої над `F_2` для обох можливих значень параметра `a ∈ {0, 1}` шляхом вичерпного перебору всіх пар `(x, y) ∈ F_2 × F_2`:

1. **Клас кривих з параметром `a = 0` (`E₀: y² + xy = x³ + 1`):**
   - Для `x = 0`: рівняння набуває вигляду `y² = 1`, що в полі `F_2` дає єдиний корінь `y = 1`. Маємо точку `(0, 1)`.
   - Для `x = 1`: рівняння набуває вигляду `y² + y = 1³ + 1 = 0`, тобто `y · (y + 1) = 0`. Це рівняння має рівно два корені в `F_2`: `y = 0` та `y = 1`. Маємо дві точки `(1, 0)` та `(1, 1)`.
   - Враховуючи точку на нескінченності `O`, загальна кількість точок над `F_2` дорівнює:
     `#E₀(F_2) = 1 + 2 + 1 = 4`.
   - Звідси слід ендоморфізму Фробеніуса дорівнює:
     `t = 3 - #E₀(F_2) = 3 - 4 = -1`.

2. **Клас кривих з параметром `a = 1` (`E₁: y² + xy = x³ + x² + 1`):**
   - Для `x = 0`: рівняння набуває вигляду `y² = 1`, що дає точку `(0, 1)`.
   - Для `x = 1`: рівняння набуває вигляду `y² + y = 1³ + 1² + 1 = 1`, тобто `y² + y + 1 = 0`. Це квадратне рівняння є незвідним над полем `F_2` (його корені лежать у квадратичному розширенні `F_4`), отже для `x = 1` дійсних розв'язків у `F_2` немає.
   - Враховуючи точку на нескінченності `O`, загальна кількість точок над `F_2` дорівнює:
     `#E₁(F_2) = 1 + 0 + 1 = 2`.
   - Звідси слід ендоморфізму Фробеніуса дорівнює:
     `t = 3 - #E₁(F_2) = 3 - 2 = +1`.

Визначимо параметр `mu` через вихідний коефіцієнт рівняння кривої `a`:

```
mu = (-1)^{1-a} ∈ {-1, +1}
```

Для `a = 0` маємо `mu = (-1)¹ = -1 = t`, а для `a = 1` маємо `mu = (-1)⁰ = +1 = t`. Таким чином, слід Фробеніуса завжди точно збігається з величиною `mu`, а характеристичне рівняння ендоморфізму Фробеніуса для кривих Кобліца набуває канонічного вигляду:

```
tau² - mu · tau + 2 = 0
```

Оскільки це рівняння є операторною тотожністю в кільці ендоморфізмів `End(E_a)`, для будь-якої точки `P ∈ E_a(F_{2^m})` виконується рівність:

```
(tau² - mu · tau + 2) P = O   =>   [2]P = mu · tau(P) - tau²(P)
```

Це співвідношення є вихідною точкою тау-адичного аналізу: воно показує, що операція подвоєння точки в групі `[2]P` може бути повністю замінена двома діями ендоморфізму Фробеніуса та одним груповим відніманням/додаванням.

### 1.1. Дія групи Галуа та збереження групового закону

Дія ендоморфізму Фробеніуса `tau(x, y) = (x², y²)` безпосередньо випливає з теорії розширень Галуа. Оскільки розширення `F_{2^m} / F_2` є циклічним розширенням Галуа степеня `m`, його група Галуа `Gal(F_{2^m} / F_2) ≅ Z/mZ` породжується автоморфізмом піднесення до квадрата `sigma(alpha) = alpha²`.

Перевіримо алгебраїчне збереження формул додавання двох різних точок `P = (x₁, y₁)` та `Q = (x₂, y₂)` на кривій `E_a`:
1. Нахил січної прямої для точок `tau(P) = (x₁², y₁²)` та `tau(Q) = (x₂², y₂²)`:
   ```
   lambda(tau(P), tau(Q))
   = (y₁² + y₂²) / (x₁² + x₂²)                          [визначення нахилу січної]
   = ((y₁ + y₂) / (x₁ + x₂))²                           [лінійність квадрата в характеристиці 2]
   = (lambda(P, Q))²                                    [квадрат вихідного нахилу]
   ```
2. Результуюча координата `x₃` для суми `tau(P) + tau(Q)`:
   ```
   x₃(tau(P), tau(Q))
   = (lambda²)² + lambda² + x₁² + x₂² + a                [формула додавання Вейєрштрасса над F_{2^m}]
   = (lambda² + lambda + x₁ + x₂ + a)²                   [оскільки a² = a для a ∈ {0, 1}]
   = (x₃(P, Q))²                                        [квадрат вихідної координати x₃]
   ```
3. Результуюча координата `y₃` для суми `tau(P) + tau(Q)`:
   ```
   y₃(tau(P), tau(Q))
   = lambda² · (x₁² + x₃²) + x₃² + y₁²                   [формула для координати y]
   = (lambda · (x₁ + x₃) + x₃ + y₁)²                     [лінійність зведення до квадрата]
   = (y₃(P, Q))²                                        [квадрат вихідної координати y₃]
   ```

Оскільки всі координати суми в точності дорівнюють квадратам координат суми вихідних точок, відображення `tau` є строгим груповим гомоморфізмом:

```
tau(P + Q) = tau(P) + tau(Q)   для всіх P, Q ∈ E_a(F_{2^m})
```

## 2. Алгебраїчна структура кільця Z[τ] та комплексна норма

Розглянемо корені характеристичного многочлена `T² - mu · T + 2 = 0` над полем комплексних чисел `C`. Дискримінант многочлена дорівнює:

```
Delta = mu² - 4 · 2 = 1 - 8 = -7
```

Оскільки дискримінант є від'ємним числом, корені є комплексно-спряженими алгебраїчними числами:

```
tau = (mu + √-7) / 2
taū = (mu - √-7) / 2
```

Числове поле `K = Q(√-7)` є уявним квадратичним полем. Оскільки фундаментальний дискримінант поля задовольняє конгруенцію `-7 ≡ 1 (mod 4)`, максимальний порядок (кільце всіх алгебраїчних цілих чисел) поля `K` задається цілочисельним базисом `{ 1, (1 + √-7)/2 }`. Оскільки `tau = (mu + √-7)/2`, це кільце цілих точно збігається з кільцем:

```
Z[tau] = { x + y · tau : x, y ∈ Z }
```

Фундаментальною властивістю поля `Q(√-7)` є те, що його число класів ідеалів дорівнює одиниці: `h(-7) = 1`. Це означає, що кільце `Z[tau]` є факторіальним кільцем (кільцем з однозначним розкладом на прості множники), кільцем головних ідеалів (PID) та евклідовим кільцем відносно мультиплікативної алгебраїчної норми.

Для довільного алгебраїчного цілого елемента `alpha = x + y · tau ∈ Z[tau]` комплексно-спряжене число виражається як:

```
alphā
= x + y · taū                                    [визначення спряженого елемента]
= x + y · (mu - tau)                             [оскільки tau + taū = mu]
= (x + mu · y) - y · tau                         [згрупували доданки]
```

Алгебраїчна норма `N(alpha)` визначається як добуток елемента на його алгебраїчно спряжене число:

```
N(alpha)
= alpha · alphā                                 [визначення алгебраїчної норми]
= (x + y · tau) · ((x + mu · y) - y · tau)       [підставили вираз для alphā]
= x · (x + mu · y) - x · y · tau + y · (x + mu · y) · tau - y² · tau²  [розкрили дужки]
= x² + mu · x · y + y² · (mu · tau - tau²)       [згрупували члени з tau]
= x² + mu · x · y + 2 · y²                       [оскільки mu·tau - tau² = 2 за характеристичним рівнянням]
```

Отримана квадратична форма є строго додатно визначеною для всіх `(x, y) ≠ (0, 0)`:

```
N(x + y · tau) = x² + mu · x · y + 2 · y²
```

Норма базового ендоморфізму Фробеніуса дорівнює `N(tau) = 0² + mu · 0 · 1 + 2 · 1² = 2`. Звідси модуль комплексного числа становить `|tau| = √N(tau) = √2`. Мультиплікативність алгебраїчної норми означає, що для будь-яких двох елементів `alpha, beta ∈ Z[tau]` виконується строга рівність:

```
N(alpha · beta) = N(alpha) · N(beta)
```

Геометрично кільце `Z[tau]` утворює ґратку в комплексній площині з базисними векторами `v₁ = 1` та `v₂ = tau = (mu / 2) + i · (√7 / 2)`. Площа фундаментальної паралелограмної комірки цієї ґратки дорівнює:

```
Area = Im(tau) = √7 / 2 ≈ 1.32287
```

Комірка Вороного навколо початку координат утворена точками комплексної площини `z ∈ C`, які лежать ближче до `0`, ніж до будь-якого іншого ненульового вузла ґратки `Z[tau]`. Оскільки ґратка утворена рівнобедреними трикутниками зі сторонами `1`, `√2` та `√2`, комірка Вороного є симетричним правильним шестикутником з шістьма вершинами. Координати вершин обчислюються як точки перетину серединних перпендикулярів до шести найближчих сусідніх вузлів `{ ±1, ±tau, ±(tau - mu) }`:

```
вершини: ±(1/2 + i / (2√7)),   ±(i / √7),   ±(-1/2 + i / (2√7))
```

Квадрат відстані від початку координат до найбільш віддалених точок комірки Вороного (вершин шестикутника) дорівнює радіусу покриття ґратки:

```
R² = (1/2)² + (1 / (2√7))² = 1/4 + 1/28 = (7 + 1) / 28 = 8 / 28 = 2 / 7
```

З урахуванням масштабування базису норми, максимальне значення квадрата норми похибки для будь-якої точки комплексної площини до найближчого вузла ґратки `Z[tau]` строго задовольняє нерівність:

```
N(gamma) ≤ 4 / 7 ≈ 0.5714 < 1
```

Оскільки константа `4 / 7` строго менша за одиницю, для будь-якого комплексного числа гарантовано існує цілий елемент кільця `Z[tau]`, норма відстані до якого менша за одиницю. Це строго доводить евклідову властивість кільця `Z[tau]`.

### 2.1. Факторизація простих чисел та структура факторкілець

Розглянемо поведінку раціональних простих чисел `p ∈ Z` у кільці алгебраїчних цілих чисел `Z[tau]`. Згідно з класичною теорією кілець Дедекінда, розклад головного ідеалу `(p) = p · Z[tau]` повністю визначається символом Лежандра `(-7 / p)`:

1. **Розщеплені прості (Split Primes):** Якщо `(-7 / p) = +1`, характеристичний многочлен `T(X) = X² - mu · X + 2` розпадається на два лінійні множники над скінченним полем `F_p`. У цьому разі ідеал розпадається на добуток двох різних простих ідеалів `(p) = p₁ · p₂`, де `N(p₁) = N(p₂) = p`.
2. **Інертні прості (Inert Primes):** Якщо `(-7 / p) = -1`, многочлен `T(X)` є незвідним над `F_p`. Ідеал `(p)` залишається простим у кільці `Z[tau]`, а його алгебраїчна норма дорівнює `N((p)) = p²`.
3. **Розгалужені прості (Ramified Primes):** Якщо `p = 7` (дільник дискримінанта `Delta = -7`), ідеал розгалужується: `(7) = (sqrt(-7))² = (2·tau - mu)²`.

Особливе фундаментальне значення має просте число `p = 2`. Підставивши `p = 2` у характеристичний многочлен:

```
T(X) = X² - mu · X + 2 = (X - tau) · (X - taū)
```

Оскільки норма `N(tau) = 2`, ідеал `(2)` розпадається на добуток двох головних спряжених простих ідеалів:

```
(2) = (tau) · (taū)
```

Звідси випливає алгебраїчна будова факторкільця за модулем головного ідеалу `(tau)`:

```
Z[tau] / (tau) ≅ F₂ = {0, 1}
```

Оскільки факторкільце ізоморфне двійковому полю `F_2`, для довільного елемента `alpha = x + y · tau ∈ Z[tau]` залишок від ділення на `tau` є строго бінарним значенням:

```
alpha ≡ x (mod tau)
```

Якщо `x` є непарним числом (`x ≡ 1 (mod 2)`), елемент `alpha` не ділиться на `tau` і називається **непарним алгебраїчним числом**. Якщо `x` є парним (`x ≡ 0 (mod 2)`), елемент `alpha` ділиться на `tau` без остачі.

Розглянемо тепер факторкільце за степенем `(tau²)`. Оскільки `N(tau²) = 4`, факторкільце містить рівно 4 класи лишків:

```
Z[tau] / (tau²) ≅ Z / 4Z
```

Це ізоморфне відображення означає, що віднімання відповідної цифри `u ∈ {-1, 0, 1}` гарантує подільність різниці `alpha - u` на `tau²`, що є наріжним каменем швидкої генерації несусіднього розкладу.

## 3. Послідовності Люка та точний підрахунок точок кривої

Порядок групи точок еліптичної кривої Кобліца над полем розширення `E_a(F_{2^m})` визначається характеристичним многочленом `m`-го степеня ендоморфізму Фробеніуса `tau^m`. За теоремою Вейля, порядок групи виражається через власні значення:

```
#E_a(F_{2^m}) = 2^m + 1 - (tau^m + taū^m)
```

Визначимо послідовність цілих чисел `V_n = tau^n + taū^n`, яка є послідовністю Люка другого порядку, асоційованою з многочленом `T² - mu · T + 2`.

Початкові значення послідовності:

```
V₀ = tau⁰ + taū⁰ = 1 + 1 = 2
V₁ = tau¹ + taū¹ = mu
```

Для довільного індексу `n ≥ 2` рекурентний крок виводиться шляхом підстановки формули степенів:

```
V_n
= tau^n + taū^n                                  [визначення послідовності]
= tau^{n-2} · tau² + taū^{n-2} · taū²             [виділили квадрати]
= tau^{n-2} · (mu · tau - 2) + taū^{n-2} · (mu · taū - 2)  [підставили tau² = mu·tau - 2]
= mu · (tau^{n-1} + taū^{n-1}) - 2 · (tau^{n-2} + taū^{n-2})  [згрупували спільні множники]
= mu · V_{n-1} - 2 · V_{n-2}                     [підставили V_{n-1} та V_{n-2}]
```

Завдяки цьому рекурентному правилу порядок кривої `#E_a(F_{2^m}) = 2^m + 1 - V_m` обчислюється аналітично за `O(m)` цілочисельних операцій:

### 3.1. Матричне представлення дії Фробеніуса та біноміальний розклад

Алгебраїчну дію ендоморфізму Фробеніуса на кільці `Z[tau]` можна записати у векторно-матричній формі над цілочисельним базисом `{1, tau}`. Оскільки `tau · 1 = 0 · 1 + 1 · tau` та `tau · tau = tau² = -2 · 1 + mu · tau`, матриця лінійного оператора множення на `tau` має вигляд супутньої матриці:

```
M_tau = [ [0, -2], [1, mu] ]
```

Характеристичний многочлен матриці `M_tau` точно збігається з многочленом Фробеніуса: `det(lambda · I - M_tau) = lambda² - mu · lambda + 2 = 0`.

Піднесення супутньої матриці до степеня `m` за допомогою рекурентних співвідношень послідовностей Люка дає замкнену форму:

```
M_tau^m = [ [ -2 · U_{m-1}, -2 · U_m ], [ U_m, U_{m+1} ] ]
```

Слід матриці `M_tau^m` задовольняє рівність:

```
Tr(M_tau^m)
= -2 · U_{m-1} + U_{m+1}                                  [визначення сліду матриці]
= -2 · U_{m-1} + (mu · U_m - 2 · U_{m-1})                  [підставили U_{m+1} = mu·U_m - 2·U_{m-1}]
= mu · U_m - 4 · U_{m-1}                                  [згрупували доданки]
= V_m                                                     [за тотожністю послідовностей Люка]
```

Крім рекурентного розрахунку, елементи `V_m` можна виразити через прямий скінченний біноміальний розклад за формулою Варінга:

```
V_m = sum_{j=0}^{floor(m/2)} (-1)^j · (m / (m - j)) · C(m - j, j) · mu^{m - 2j} · 2^j
```

де `C(n, k) = n! / (k! · (n - k)!)` — біноміальні коефіцієнти.

Для стандартизованих кривих NIST обчислення порядків за формулою `#E_a(F_{2^m}) = 2^m + 1 - V_m` дає криптографічні підгрупи простого порядку `r = #E_a(F_{2^m}) / h`:
- **NIST K-163 (`m = 163, a = 1, mu = 1, h = 2`):** `r = 2¹⁶² + 1 - V₁₆₃ / 2`, де `r` є 163-бітним простим числом;
- **NIST K-233 (`m = 233, a = 0, mu = -1, h = 4`):** `r = (2²³³ + 1 - V₂₃₃) / 4`, де `r` є 232-бітним простим числом;
- **NIST K-283 (`m = 283, a = 0, mu = -1, h = 4`):** `r = (2²⁸³ + 1 - V₂₈₃) / 4`, де `r` є 281-бітним простим числом.

```
#E_a(F_{2^m}) = 2^m + 1 - V_m
```

Порядок групи точок завжди ділиться на малий алгебраїчний кофактор `h`:
- Для `a = 0` (де `mu = -1`): кофактор дорівнює `h = 4` (при непарному степені `m`);
- Для `a = 1` (де `mu = +1`): кофактор дорівнює `h = 2` (при непарному степені `m`).

Порядок криптографічної підгрупи простого порядку становить:

```
r = #E_a(F_{2^m}) / h
```

Усі криптографічні протоколи виконуються виключно у великій підгрупі простого порядку `r`.

## 4. Елемент Солінаса δ та евклідова редукція скаляра

Прямий розклад довільного великого скаляра `k ∈ [1, r-1]` за основою `tau` створює серйозну проблему: оскільки модуль основи дорівнює `|tau| = √2`, для подання скаляра `k ≈ 2^m` знадобиться розклад довжиною:

```
l ≈ log_{√2}(2^m) = 2m розрядів
```

Це призвело б до подвоєння довжини циклу скалярного множення порівняно зі звичайним бінарним розкладом.

Для скорочення розкладу до `m` розрядів Джером Солінас використав алгебраїчний дільник порядку кривої. Оскільки координати точок належать полю `F_{2^m}`, дія `tau^m` на довільну точку `P ∈ E_a(F_{2^m})` є тотожною:

```
tau^m(P) = (x^{2^m}, y^{2^m}) = (x, y) = P
```

Отже, оператор `(tau^m - 1)` занулює будь-яку точку кривої: `(tau^m - 1) P = O`.

Розкладемо різницю степенів на множники:

```
tau^m - 1 = (tau - 1) · (1 + tau + tau² + ... + tau^{m-1})
```

Визначимо елемент Солінаса `delta ∈ Z[tau]`:

```
delta = (tau^m - 1) / (tau - 1) = 1 + tau + tau² + ... + tau^{m-1}
```

Оскільки `(tau - 1) · delta(P) = (tau^m - 1)P = O`, а оператор `(tau - 1)` є автоморфізмом на підгрупі непарного простого порядку `r` (оскільки `N(tau - 1) = 3 - mu` взаємно просте з великим простим числом `r`), оператор `delta` обов'язково занулює всі точки криптографічної підгрупи:

```
delta(P) = O   для всіх P з підгрупи порядку r
```

Обчислимо алгебраїчну норму елемента Солінаса `delta`:

```
N(delta)
= N(tau^m - 1) / N(tau - 1)                      [мультиплікативність норми]
= #E_a(F_{2^m}) / ((-1)² + mu · (-1) · 1 + 2 · 1²) [оскільки tau - 1 = -1 + tau]
= #E_a(F_{2^m}) / (1 - mu + 2)                   [розкрили квадратичну форму норми]
= #E_a(F_{2^m}) / (3 - mu)                       [згрупували константи]
```

Оскільки `3 - mu = 4 = h` для `a = 0` та `3 - mu = 2 = h` для `a = 1`, знаменник завжди точно дорівнює кофактору кривої `h`. Звідси маємо фундаментальну рівність:

```
N(delta) = #E_a(F_{2^m}) / h = r
```

Норма елемента `delta` в кільці `Z[tau]` точно дорівнює простому порядку підгрупи `r`.

Таким чином, для будь-якого криптографічного скаляра `k` його геометрична дія на точку `P` повністю зберігається, якщо замінити `k` на залишок від евклідового ділення на `delta` в кільці `Z[tau]`:

```
k = q · delta + rho   =>   [k]P = [q · delta + rho]P = [q]delta(P) + [rho]P = [rho]P
```

Оскільки евклідова норма залишку задовольняє нерівність `N(rho) ≤ (4/7) · N(delta) < r`, модуль залишку обмежений величиною `|rho| < √r ≈ 2^{m/2}`. Як наслідок, довжина розкладу редукованого скаляра `rho` за основою `tau` скорочується рівно вдвічі:

```
l(rho) ≤ m + a розрядів
```

## 5. Аналітичний алгоритм швидкого ділення та округлення Солінаса

Для обчислення частки `q ∈ Z[tau]` виконаємо точне ділення у полі часток `Q(√-7)`:

```
k / delta = (k · deltā) / (delta · deltā) = (k · deltā) / r = c₀ + c₁ · tau,   де c₀, c₁ ∈ Q
```

Нехай `delta = d₀ + d₁ · tau`. Знайдемо вираз для спряженого елемента `deltā`:

```
deltā
= d₀ + d₁ · taū                                  [визначення спряженого елемента]
= d₀ + d₁ · (mu - tau)                           [підставили taū = mu - tau]
= (d₀ + mu · d₁) - d₁ · tau                      [згрупували коефіцієнти]
```

Введемо попередньо обчислені цілі константи Солінаса:

```
s₀(m) = d₀ + mu · d₁
s₁(m) = -d₁
```

Тоді `deltā = s₀(m) + s₁(m) · tau`, а раціональні коефіцієнти частки `c₀, c₁ ∈ Q` обчислюються безпосередньо через скаляр `k` та порядок підгрупи `r`:

```
c₀ = (k · s₀(m)) / r
c₁ = (k · s₁(m)) / r
```

Оскільки базис ґратки `{ 1, tau }` не є ортогональним (кут між базисними векторами становить приблизно `68°` або `112°`), просте покомпонентне округлення `round(c₀)` та `round(c₁)` не гарантує потрапляння у найближчий вузол ґратки.

Джером Солінас розробив геометрично точний алгоритм квантування раціональної точки `c₀ + c₁ · tau` до найближчого вузла ґратки `q = q₀ + q₁ · tau ∈ Z[tau]`:

1. **Цілі наближення та дробові зміщення:**
   Обчислити стандартні округлення до найближчого цілого `f₀ = round(c₀)` та `f₁ = round(c₁)`, де `round(x) = ⌊x + 1/2⌋`.
   Обчислити дробові частини похибки:
   ```
   eta₀ = c₀ - f₀,   eta₁ = c₁ - f₁   (де eta₀, eta₁ ∈ [-1/2, 1/2])
   ```

2. **Обчислення цілих індикаторів зміщення:**
   ```
   h₀ = round(2 · eta₀ + mu · eta₁)
   h₁ = round(eta₀ + 3 · mu · eta₁)
   ```

3. **Визначення поправок до частки `(q₀, q₁)`:**
   - Якщо `2 · eta₀ + mu · eta₁ ≥ 1`: встановити `q₀ = f₀ + 1` та `q₁ = f₁ + round(eta₁)`;
   - Якщо `2 · eta₀ + mu · eta₁ < -1`: встановити `q₀ = f₀ - 1` та `q₁ = f₁ - round(eta₁)`;
   - В інших випадках: зберегти початкові наближення `q₀ = f₀` та `q₁ = f₁`.

Після знаходження цілої частки `q = q₀ + q₁ · tau` коефіцієнти редукованого залишку `rho = r₀ + r₁ · tau = k - q · delta` обчислюються за точними лінійними формулами:

```
r₀ = k - (q₀ · d₀ - 2 · q₁ · d₁)
r₁ = -(q₀ · d₁ + q₁ · d₀ + mu · q₁ · d₁)
```

Оскільки `d₀ = s₀ + mu · s₁` та `d₁ = -s₁`, ці формули виконуються виключно у цілих числах через кілька множень та віднімань без використання операцій з рухомою комою.

### 5.1. Геометричний вивід індикаторів Солінаса та цілочисельне квантування

Розглянемо геометричне обґрунтування індикаторів Солінаса через проєкцію косокутної системи координат на ортогональну комплексну площину.

Будь-яке раціональне число `c = c₀ + c₁ · tau ∈ Q(sqrt(-7))` можна розкласти на дійсну та уявну частини:

```
Re(c) = c₀ + mu · c₁ / 2
Im(c) = c₁ · sqrt(7) / 2
```

Нехай `q = f₀ + f₁ · tau ∈ Z[tau]` — базове покомпонентне наближення, а `eta = eta₀ + eta₁ · tau` — вектор похибки квантування, де `eta₀, eta₁ ∈ [-1/2, 1/2]`.

Комплексна норма похибки виражається квадратичною формою:

```
N(eta) = eta₀² + mu · eta₀ · eta₁ + 2 · eta₁² = (eta₀ + mu · eta₁ / 2)² + 7 · eta₁² / 4
```

Шестикутна комірка Вороного навколо вузла ґратки `(0, 0)` обмежена шістьма лініями серединних перпендикулярів до сусідніх вузлів:
1. До вузла `±1`: пряма `|Re(eta)| = 1/2   =>   |eta₀ + mu · eta₁ / 2| = 1/2`;
2. До вузла `±tau`: пряма `|eta₀ - mu · eta₁| = 1`;
3. До вузла `±(tau - mu)`: пряма `|2 · eta₀ + mu · eta₁| = 1`.

Аналіз взаємного розташування показує, що критичною межею комірки Вороного, через яку вектор `eta` може вийти за межі області тяжіння точки `(f₀, f₁)`, є саме серединний перпендикуляр до вузла `±(tau - mu)`, що описується лінійною формою:

```
L(eta₀, eta₁) = 2 · eta₀ + mu · eta₁
```

- Якщо `L(eta₀, eta₁) ≥ 1`, точка лежить у зоні тяжіння вузла `q = (f₀ + 1, f₁ + round(eta₁))`;
- Якщо `L(eta₀, eta₁) < -1`, точка лежить у зоні тяжіння вузла `q = (f₀ - 1, f₁ - round(eta₁))`;
- Якщо `-1 ≤ L(eta₀, eta₁) < 1`, точка гарантовано залишається всередині комірки Вороного початкового вузла `(f₀, f₁)`.

Для реалізації цього алгоритму в мікроконтролерах без апаратної підтримки чисел із рухомою комою раціональні частки `c₀ = (k · s₀) / r` та `c₁ = (k · s₁) / r` обчислюються у форматі з фіксованою комою (Fixed-Point Arithmetic) з точністю `m + 16` дробових бітів:

```
C₀_fixed = (k · s₀ · 2^{m+16}) / r
C₁_fixed = (k · s₁ · 2^{m+16}) / r
```

Оскільки точність у `m + 16` бітів значно перевищує роздільну здатність комірки Вороного, алгоритм квантування з фіксованою комою забезпечує стовідсотковий збіг результату з теоретичним неперервним діленням без жодної похибки дискретизації.

## 6. Алгоритм TNAF та математичні доведення його властивостей

Маючи редукований алгебраїчний залишок `rho = r₀ + r₁ · tau ∈ Z[tau]`, подамо його у вигляді тау-адичного розкладу в несусідній формі (Tau-adic Non-Adjacent Form, `tau-NAF`):

```
rho = sum_{i=0}^{l-1} u_i · tau^i,   де u_i ∈ {-1, 0, +1}  та  u_i · u_{i+1} = 0
```

### 6.1. Критерій подільності на τ в кільці Z[τ]

**Лема про подільність на `tau`:** Елемент `alpha = r₀ + r₁ · tau ∈ Z[tau]` ділиться на `tau` без остачі в кільці `Z[tau]` тоді й лише тоді, коли дійсний коефіцієнт `r₀` є парним числом:

```
tau | (r₀ + r₁ · tau) ⟺ r₀ ≡ 0 (mod 2)
```

**Доведення:**
Виконаємо алгебраїчне ділення виразу `r₀ + r₁ · tau` на `tau`, скориставшись характеристичною тотожністю `2 / tau = mu - tau`:

```
(r₀ + r₁ · tau) / tau
= (r₀ / tau) + r₁                               [розбили суму на доданки]
= (r₀ / 2) · (2 / tau) + r₁                     [виділили множник 2/tau]
= (r₀ / 2) · (mu - tau) + r₁                    [підставили тотожність 2/tau = mu - tau]
= (r₁ + mu · (r₀ / 2)) - (r₀ / 2) · tau         [згрупували коефіцієнти при 1 та tau]
```

Отримане число належить кільцю цілих чисел `Z[tau]` тоді й лише тоді, коли коефіцієнт `(r₀ / 2)` є цілим числом, тобто коли `r₀` є парним числом. Лему доведено.

### 6.2. Вибір цифри u та подільність на τ²

Якщо дійсний коефіцієнт `r₀` є непарним числом, поточна цифра розкладу не може бути нулем. Необхідно обрати ненульову цифру `u ∈ {-1, +1}` таким чином, щоб після її віднімання різниця `rho - u` ділилася на `tau²`.

Число `rho - u = (r₀ - u) + r₁ · tau` ділиться на `tau`, оскільки `r₀ - u` є парним числом. Після першого ділення на `tau` отримуємо:

```
(rho - u) / tau = (r₁ + mu · ((r₀ - u) / 2)) - ((r₀ - u) / 2) · tau
```

Для того щоб цей вираз ділився на `tau` ще раз (тобто щоб `rho - u` ділилося на `tau²`), його дійсний коефіцієнт повинен бути парним числом за лемою про подільність:

```
r₁ + mu · ((r₀ - u) / 2) ≡ 0 (mod 2)
```

Помножимо обидві частини конгруенції на 2:

```
2 · r₁ + mu · (r₀ - u) ≡ 0 (mod 4)
```

Оскільки `mu ∈ {-1, +1}`, помножимо рівняння на `mu` (враховуючи, що `mu² = 1`):

```
r₀ - u + 2 · mu · r₁ ≡ 0 (mod 4)   =>   u ≡ r₀ + 2 · mu · r₁ (mod 4)
```

Оскільки `2 · mu ≡ -2 · mu (mod 4)`, конгруенція еквівалентна умові `u ≡ r₀ - 2 · mu · r₁ (mod 4)`. Оскільки `r₀` є непарним числом, а `2 · mu · r₁` — парним, величина `(r₀ - 2 · mu · r₁) mod 4` може набувати лише значень `1` або `3`:
- Якщо `(r₀ - 2 · mu · r₁) mod 4 = 1`: обираємо `u = +1` (оскільки `2 - 1 = +1`);
- Якщо `(r₀ - 2 · mu · r₁) mod 4 = 3`: обираємо `u = -1` (оскільки `2 - 3 = -1`).

Це дає уніфіковану аналітичну формулу для обчислення цифри `u`:

```
u = 2 - ( (r₀ - 2 · mu · r₁) mod 4 )
```

### 6.3. Доведення несусідньої властивості (Non-Adjacent Property)

**Теорема про несусідність:** У розкладі `tau-NAF` для будь-якого індексу `i ≥ 0` виконується умова `u_i · u_{i+1} = 0`.

**Доведення:**
Нехай на кроці `i` коефіцієнт `r₀` був непарним, і автомат обрав ненульову цифру `u_i ∈ {-1, +1}`.
За вибором цифри `u_i`, елемент `rho' = rho - u_i` ділиться на `tau²` в кільці `Z[tau]`.
Після першого ділення на `tau` новий стан `rho^{(i+1)} = (rho - u_i) / tau` має вигляд `r₀' + r₁' · tau`, причому за побудовою `r₀' = r₁ + mu · ((r₀ - u_i) / 2)` є парним числом.
Оскільки `r₀'` є парним числом, на наступній ітерації `i + 1` критерій непарності не виконується, і автомат обов'язково обирає нульову цифру:

```
u_{i+1} = 0
```

Це гарантує, що жодні дві ненульові цифри не можуть стояти поруч.

### 6.4. Доведення мінімальної ваги Геммінга та середньої щільності 1/3

**Теорема про мінімальну вагу Геммінга:** Канонічний розклад `tau-NAF` мінімізує кількість ненульових коефіцієнтів (вагу Геммінга) серед усіх можливих розкладів елемента `rho` за основою `tau` з цифрами із множини `{0, -1, +1}`.

**Доведення середньої щільності:**
Розглянемо процес генерації цифр як марковський ланцюг станів залишку `(r₀ mod 2, r₁ mod 2)`.
1. Якщо `r₀` є непарним (ймовірність появи непарного числа для псевдовипадкового скаляра становить `1/2`), генерується ненульова цифра `u_i = ±1`, а наступний коефіцієнт `r₀'` гарантовано стає парним за теоремою про несусідність.
2. Якщо `r₀` є парним, генерується цифра `u_i = 0`, а новий коефіцієнт `r₀'' = r₁ + mu · (r₀ / 2)` є непарним з імовірністю `1/2` (залежно від парності попереднього `r₁`).

Складемо систему рівнянь стаціонарного розподілу ймовірностей для станів автомата. Нехай `p` — ймовірність того, що поточна цифра є ненульовою (`u_i ≠ 0`). Оскільки після кожної ненульової цифри обов'язково слідує нуль, послідовність розбивається на блоки `(±1, 0)` та поодинокі нулі `(0)`.

Середня довжина нульового проміжку між ненульовими розрядами обчислюється як сума геометричної прогресії випадкових парних станів:

```
E[нулів між цифрами] = 1 (гарантований нуль) + sum_{k=1}^∞ k · (1/2)^k = 1 + 1 = 2
```

Таким чином, у стаціонарному потоці цифр на кожну ненульову цифру припадає в середньому рівно 2 нульових розряди. Середня щільність ненульових коефіцієнтів становить:

```
D(tau-NAF) = 1 / (1 + E[нулів]) = 1 / (1 + 2) = 1 / 3 ≈ 33.33%
```

Для порівняння, стандартний бінарний розклад скаляра має середню щільність ненульових бітів `1 / 2 = 50%`. Перехід до форми `tau-NAF` скорочує кількість операцій додавання точок рівно на `33.3%`.

### 6.5. Строге доведення збіжності та оцінка кількості ітерацій

Доведемо строгу збіжність алгоритму тау-адичного ділення для довільного редукованого початкового стану `rho = (r₀, r₁) ∈ Z[tau]`.

**Теорема (Монотонне спадання норми):**
Нехай `alpha = r₀ + r₁ · tau ∈ Z[tau]` — поточний стан автомата. Якщо `alpha` є непарним (`r₀ ≡ 1 (mod 2)`), а цифра `u ∈ {-1, 1}` вибрана за правилом `u = 2 - (r₀ - 2·mu·r₁ mod 4)`, то наступний стан `alpha' = (alpha - u) / tau` задовольняє оцінку комплексної норми:

```
N(alpha') ≤ (N(alpha) + 2·sqrt(N(alpha)) + 1) / 2
```

Якщо `N(alpha) ≥ 9`, то:

```
N(alpha') < N(alpha)
```

**Доведення:**
1. Оскільки `N(alpha - u) = N(alpha) - 2 · Re(alpha · ū) + N(u)`, а `N(u) = 1`, застосуємо нерівність Коші-Буняковського:
   ```
   |2 · Re(alpha · ū)| ≤ 2 · |alpha| · |u| = 2 · sqrt(N(alpha)) · 1 = 2 · sqrt(N(alpha))
   ```
2. Ділення на `tau` зменшує норму вдвічі (`N(tau) = 2`):
   ```
   N(alpha')
   [step 1] = N( (alpha - u) / tau )                     [визначення наступного стану]
   [step 2] = N(alpha - u) / N(tau)                     [мультиплікативність алгебраїчної норми]
   [step 3] = N(alpha - u) / 2                          [оскільки N(tau) = 2]
   [step 4] ≤ (N(alpha) + 2·sqrt(N(alpha)) + 1) / 2     [підставили оцінку нерівності трикутника]
   ```
3. Перевіримо умову строгого спадання `(N(alpha) + 2·sqrt(N(alpha)) + 1) / 2 < N(alpha)`:
   ```
   N(alpha) - 2·sqrt(N(alpha)) - 1 > 0
   ```
   Поклавши `t = sqrt(N(alpha))`, маємо квадратне рівняння `t² - 2t - 1 > 0`, корені якого `t > 1 + sqrt(2) ≈ 2.4142`.
   Піднесення до квадрата дає `N(alpha) > (1 + sqrt(2))² = 3 + 2·sqrt(2) ≈ 5.8284`.

Таким чином, для будь-якого елемента з нормою `N(alpha) ≥ 6` один крок віднімання цифри та ділення на `tau` строго зменшує норму. Якщо ж врахувати несусідню властивість, згідно з якою після ненульової цифри `u` наступний стан обов'язково є парним і ділиться на `tau` без віднімання цифри (`u' = 0`), норма за два кроки гарантовано ділиться на 4:

```
N(alpha'') = N(alpha') / 2 ≤ (N(alpha) + 2·sqrt(N(alpha)) + 1) / 4 < N(alpha) / 2   (для всіх N(alpha) ≥ 4)
```

Це доводить експоненційне геометричне прямування норми до нуля. Максимальна кількість розрядів розкладу редукованого скаляра `rho = k mod delta` строго обмежена зверху величиною:

```
l ≤ m + a
```

де `m` — степінь поля, а `a ∈ {0, 1}` — коефіцієнт рівняння кривої Кобліца.

## 7. Віконний метод w-TNAF

Для додаткового зменшення кількості точкових додавань застосовується віконна модифікація — метод `w-TNAF` із шириною вікна `w ≥ 2`.

У методі `w-TNAF` ненульові цифри `u_i` обираються з розширеного алфавіту непарних цілих алгебраїчних чисел:

```
u_i ∈ { 0, ±alpha₁, ±alpha₃, ±alpha₅, ..., ±alpha_{2^{w-1}-1} }
```

де кожен елемент `alpha_u` обчислюється як мінімальне за алгебраїчною нормою непарне число в кільці `Z[tau]`, що задовольняє конгруенцію за модулем `tau^w`:

```
alpha_u ≡ u (mod tau^w)
```

Властивості розкладу `w-TNAF`:
1. **Розширена несусідність:** якщо `u_i ≠ 0`, то наступні `w - 1` розрядів обов'язково є нульовими:
   ```
   u_{i+1} = u_{i+2} = ... = u_{i+w-1} = 0
   ```
2. **Середня ненульова щільність:**
   ```
   D(w-TNAF) = 1 / (w + 1)
   ```

Для ширини вікна `w = 4` середня щільність ненульових розрядів падає до `1 / (4 + 1) = 1/5 = 20%`. Таблиця попередніх обчислень містить лише `2^{w-2} = 4` точки `P_u = [alpha_u]P`, а точки з від'ємними знаками `-[alpha_u]P` обчислюються миттєво через формулу заперечення афінної точки на двійковій кривій:

```
-(x, y) = (x, x + y)
```

Це дозволяє уникнути збереження від'ємних точок у пам'яті пристрою.

### 7.1. Побудова множини цифр D_w та таблиця мінімальних норм

Алгебраїчна множина цифр `D_w` формується шляхом вибору одного представника найменшої комплексної норми з кожної пари класів лишків `±alpha ∈ (Z[tau] / (tau^w))^*`, взаємно простих з `tau`.

Кількість ненульових точок у таблиці попередніх обчислень дорівнює `2^{w-2}`. Для кожної ширини вікна `w ∈ {3, 4, 5, 6}` розрахунок дає такі точні параметри:

| Ширина вікна `w` | Кількість точок у RAM | Множина базисних залишків `alpha_u` | Середня щільність ненульових розрядів | Кількість додавань (`m = 233`) |
| :--- | :--- | :--- | :--- | :--- |
| `w = 2` (звичайний TNAF) | 0 (лише `P`) | `{ 1 }` | `1 / 3 ≈ 33.3%` | 78 додавань |
| `w = 3` | 2 точки | `{ 1, 1 + mu·tau }` | `1 / 4 = 25.0%` | 58 додавань |
| `w = 4` (стандарт NIST) | 4 точки | `{ 1, 1 + mu·tau, 1 - mu·tau, 1 + 2·mu·tau }` | `1 / 5 = 20.0%` | 46 додавань |
| `w = 5` | 8 точок | `{ 1, 1 ± mu·tau, 1 ± 2·mu·tau, 1 ± 3·mu·tau, ... }` | `1 / 6 ≈ 16.7%` | 39 додавань |
| `w = 6` | 16 точок | 16 елементів мінімальної норми в `Z[tau]` | `1 / 7 ≈ 14.3%` | 33 додавання |

Як свідчить аналіз таблиці, перехід від `w = 2` до `w = 4` скорочує кількість важких операцій додавання точок у проективних координатах із 78 до 46 (економія 32 польових множень) ціною збереження лише 4 точок у пам'яті (384 байти). Подальше збільшення вікна до `w = 5` чи `w = 6` подвоює вимоги до оперативної пам'яті за кожен крок, зменшуючи кількість додавань лише на 7 та 6 операцій відповідно, що робить конфігурацію `w = 4` оптимальним світовим інженерним стандартом для 32-бітних мікроконтролерів.

## 8. Чому саме дискримінант Δ = -7 (порівняння кілець Кобліца)

Чому саме уявне квадратичне поле `Q(√-7)` є єдино можливим базисом для побудови аномальних кривих над полем характеристики 2?

В алгебраїчній теорії чисел існує лише дев'ять уявних квадратичних полів з класовим числом `h(Delta) = 1` (теорема Хегнера-Бейкера-Старка):
`Delta ∈ { -3, -4, -7, -8, -11, -19, -43, -67, -163 }`.

Розглянемо поведінку простого числа 2 у цих числових кільцях:
1. **Поле `Q(√-1)` з дискримінантом `Delta = -4` (Гаусові цілі):** Просте число 2 є розгалуженим: `(2) = (1 + i)²`. Використовується над простими полями `F_p` для кривих із `j`-інваріантом 1728.
2. **Поле `Q(√-3)` з дискримінантом `Delta = -3` (Числа Ейзенштейна):** Просте число 2 залишається інертним. Над полями характеристики 2 криві з дискримінантом `-3` мають `j`-інваріант 0 і є суперсингулярними, що відкриває їх для атаки Менезеса-Окамото-Ванстоуна (MOV-атака через спарювання Вейля).
3. **Поле `Q(√-7)` з дискримінантом `Delta = -7` (Числа Кобліца):** Оскільки символ Лежандра `(-7 / 2) = 1` (бо `-7 ≡ 1 (mod 8)`), просте число 2 повністю розкладається на добуток двох різних простих головних ідеалів:
   ```
   (2) = (tau) · (taū)
   ```

Саме повний розклад числа 2 у числовому полі `Q(√-7)` забезпечує існування ендоморфізму Фробеніуса з точною алгебраїчною нормою `N(tau) = 2`, що робить основу `tau` природною базою для нерозширюваних систем числення над двійковими полями.

### 8.1. Класифікація кілець ендоморфізмів та захист від спарювальних атак

Алгебраїчна класифікація Де Брінґа-Тейта для еліптичних кривих над скінченними полями розрізняє три можливі типи кілець ендоморфізмів `End(E)`:

1. **Звичайні криві загального положення (Generic Ordinary Curves):** Кільце ендоморфізмів збігається з кільцем цілих чисел `End(E) ≅ Z`. Єдиними груповими ендоморфізмами є стандартні операції множення на ціле число `[k]P`. На таких кривих не існує нетривіальних раціональних автоморфізмів, тому скалярне множення неминуче вимагає повного ланцюжка геометричних подвоєнь точок.
2. **Звичайні криві з комплексним множенням (Ordinary CM-Curves):** Кільце ендоморфізмів `End(E)` є порядком в уявному квадратичному полі `Q(sqrt(Delta))`. Криві Кобліца належать саме до цього класу: їхнє кільце ендоморфізмів є максимальним порядком `Z[tau] ⊂ Q(sqrt(-7))`, причому ендоморфізм Фробеніуса `tau` безпосередньо генерує це кільце.
3. **Суперсингулярні криві (Supersingular Curves):** Кільце ендоморфізмів є порядком у невимірній кватерніонній алгебрі над `Q`, розгалуженій у `p` та `∞`.

У двійкових скінченних полях характеристики 2 будь-яка суперсингулярна крива має вигляд `y² + c·y = x³ + a·x + b` і володіє `j`-інваріантом `j(E) = 0`. Слід Фробеніуса для суперсингулярної двійкової кривої обов'язково є парним або кратним `sqrt(2·2^m)`, а степінь вкладення (Embedding Degree) `k` щодо простого порядку `r` не перевищує 4:

```
r | (2^{m · k} - 1),   де k ∈ {1, 2, 3, 4}
```

Малий степінь вкладення робить дискретний логарифм на суперсингулярних кривих вразливим до редукції Менезеса-Окамото-Венстоуна (MOV-атака): спарювання Вейля `e_r: E[r] × E[r] -> F_{2^{m·k}}^*` миттєво проєктує задачу у мультиплікативну групу двійкового поля малого степеня, де працює субекспоненційний метод обчислення індексів (Index Calculus).

На противагу цьому, криві Кобліца мають ненульовий `j`-інваріант `j(E) = 1/b = 1 ≠ 0` і є строго несуперсингулярними (звичайними). Їхній степінь вкладення `k` є астрономічно великим і близьким до порядку самої підгрупи:

```
k ≈ r ≈ 2^{m-1}   (для K-233 степінь вкладення k > 10⁶⁸)
```

Через це перенесення задачі дискретного логарифма у мультиплікативну групу поля розширення через будь-які спарювання (Вейля або Тейта-Ліхтенбаума) є математично неможливим, оскільки поле `F_{2^{m · k}}` мало б розмір понад `2^{232}` бітів, що гарантує абсолютну криптографічну стійкість проти спарювального криптоаналізу.

## 9. Повний числовий розрахунок скалярного множення k·P без подвоєнь точок

Для наочної демонстрації кожного кроку алгоритму виконаємо повний числовий розрахунок скалярного добутку `[k]P` на конкретній модельній кривій Кобліца з детальними польовими та точковими обчисленнями.

### 9.1. Параметри модельної кривої та скінченного поля

- **Скінченне двійкове поле:** `F_{2^7} = F_2[x] / (f(x))` з незвідним многочленом `f(x) = x⁷ + x + 1` (двійковий вектор `10000011₂ = 0x83`). Елементи поля подаються 7-бітними двійковими многочленами або цілими числами в діапазоні `[0, 127]`.
- **Рівняння кривої Кобліца:** `E₀: y² + xy = x³ + 1` (параметри `a = 0`, `mu = -1`, характеристичне рівняння `tau² + tau + 2 = 0`).
- **Степінь поля:** `m = 7`.
- **Послідовність Люка `V_n` для `mu = -1`:**
  ```
  V₀ = 2
  V₁ = -1
  V₂ = -1 · (-1) - 2 · 2 = 1 - 4 = -3
  V₃ = -1 · (-3) - 2 · (-1) = 3 + 2 = 5
  V₄ = -1 · 5 - 2 · (-3) = -5 + 6 = 1
  V₅ = -1 · 1 - 2 · 5 = -1 - 10 = -11
  V₆ = -1 · (-11) - 2 · 1 = 11 - 2 = 9
  V₇ = -1 · 9 - 2 · (-11) = -9 + 22 = 13
  ```
- **Порядок групи точок:** `#E₀(F_{2^7}) = 2⁷ + 1 - V₇ = 128 + 1 - 13 = 116`.
- **Кофактор:** `h = 4`.
- **Порядок криптографічної підгрупи:** `r = 116 / 4 = 29` (просте число).
- **Елемент Солінаса:** `delta = -1 - 4 · tau` (де `d₀ = -1, d₁ = -4`).
  Перевірка норми: `N(delta) = (-1)² + (-1) · (-1) · (-4) + 2 · (-4)² = 1 - 4 + 32 = 29 = r`.
- **Константи Солінаса:**
  ```
  s₀(7) = d₀ + mu · d₁ = -1 + (-1) · (-4) = 3
  s₁(7) = -d₁ = 4
  ```
- **Базова точка генератора підгрупи:** `P = (12, 17) ∈ E₀(F_{2^7})`, де:
  `x_P = 12 = x³ + x²`
  `y_P = 17 = x⁴ + 1`
  Перевірка належності точки кривій:
  `y² + xy = 17² + 12 · 17 = 7 + 82 = 85`
  `x³ + 1 = 12³ + 1 = 84 + 1 = 85` (рівність виконується).

### 9.2. Крок 1: Евклідова редукція скаляра k = 23

Нехай потрібно обчислити скалярний добуток `[23]P` для скаляра `k = 23 ∈ [1, 28]`.

1. **Обчислення раціональних часток `c₀, c₁ ∈ Q`:**
   ```
   c₀ = (k · s₀) / r = (23 · 3) / 29 = 69 / 29 ≈ 2.37931
   c₁ = (k · s₁) / r = (23 · 4) / 29 = 92 / 29 ≈ 3.17241
   ```

2. **Округлення до найближчих цілих та дробові зміщення:**
   ```
   f₀ = round(2.37931) = 2,    eta₀ = 69/29 - 2 = 11/29 ≈ 0.37931
   f₁ = round(3.17241) = 3,    eta₁ = 92/29 - 3 = 5/29 ≈ 0.17241
   ```

3. **Перевірка індикаторів Солінаса:**
   ```
   2 · eta₀ + mu · eta₁ = 2 · (11/29) - (5/29) = 17/29 ≈ 0.58621
   ```
   Оскільки величина `17/29` лежить строго в інтервалі `[-1, 1)`, поправки не потрібні:
   ```
   q₀ = f₀ = 2
   q₁ = f₁ = 3
   ```

4. **Обчислення редукованого алгебраїчного залишку `rho = k - q · delta`:**
   ```
   q · delta
   = (2 + 3 · tau) · (-1 - 4 · tau)                [підставили значення q та delta]
   = 2 · (-1) + (2 · (-4) + 3 · (-1)) · tau - 12 · tau²  [розкрили добуток многочленів]
   = -2 - 11 · tau - 12 · (-tau - 2)               [підставили характеристичне рівняння tau² = -tau - 2]
   = -2 - 11 · tau + 12 · tau + 24                 [розкрили дужки]
   = 22 + 1 · tau                                  [згрупували цілі доданки та члени при tau]
   ```
   ```
   rho = k - (q · delta) = 23 - (22 + tau) = 1 - 1 · tau = (1, -1)
   ```
   Перевірка норми залишку:
   ```
   N(rho) = 1² + (-1) · 1 · (-1) + 2 · (-1)² = 1 + 1 + 2 = 4 < 29
   ```

### 9.3. Крок 2: Генерація цифр розкладу TNAF

Починаємо роботу скінченного автомата зі стану `(r₀, r₁) = (1, -1)`:

**Ітерація 0:**
- `r₀ = 1` (непарне число).
- `val = (r₀ - 2 · mu · r₁) mod 4 = (1 - 2 · (-1) · (-1)) mod 4 = (1 - 2) mod 4 = (-1) mod 4 = 3`.
- Цифра розкладу: `u₀ = 2 - val = 2 - 3 = -1`.
- Віднімання цифри: `r₀' = r₀ - u₀ = 1 - (-1) = 2`.
- Ділення на `tau`:
  ```
  r₀'' = r₁ + mu · (r₀' / 2) = -1 + (-1) · (2 / 2) = -1 - 1 = -2
  r₁'' = -(r₀' / 2) = -(2 / 2) = -1
  ```
  Новий стан: `(r₀, r₁) = (-2, -1)`.

**Ітерація 1:**
- `r₀ = -2` (парне число).
- Цифра розкладу: `u₁ = 0`.
- Ділення на `tau`:
  ```
  r₀'' = r₁ + mu · (r₀ / 2) = -1 + (-1) · (-2 / 2) = -1 + 1 = 0
  r₁'' = -(r₀ / 2) = -(-2 / 2) = 1
  ```
  Новий стан: `(r₀, r₁) = (0, 1)`.

**Ітерація 2:**
- `r₀ = 0` (парне число).
- Цифра розкладу: `u₂ = 0`.
- Ділення на `tau`:
  ```
  r₀'' = r₁ + mu · (r₀ / 2) = 1 + (-1) · (0 / 2) = 1
  r₁'' = -(r₀ / 2) = 0
  ```
  Новий стан: `(r₀, r₁) = (1, 0)`.

**Ітерація 3:**
- `r₀ = 1` (непарне число).
- `val = (1 - 2 · (-1) · 0) mod 4 = 1 mod 4 = 1`.
- Цифра розкладу: `u₃ = 2 - 1 = +1`.
- Віднімання цифри: `r₀' = 1 - 1 = 0`.
- Ділення на `tau`:
  ```
  r₀'' = 0 + 0 = 0
  r₁'' = 0
  ```
  Стан `(0, 0)` — завершення роботи автомата!

Отриманий розклад скаляра `k = 23`:

```
TNAF(23) = [ u₀, u₁, u₂, u₃ ] = [ -1, 0, 0, 1 ]   =>   rho = tau³ - 1
```

Перевірка правильності розкладу:
`tau³ - 1 = (tau² · tau) - 1 = (-tau - 2) · tau - 1 = -tau² - 2·tau - 1 = -(-tau - 2) - 2·tau - 1 = tau + 2 - 2·tau - 1 = 1 - tau = rho`.

Розклад містить 4 розряди (`l = 4 ≤ m + a = 7`), з яких лише 2 є ненульовими (`u₀ = -1, u₃ = 1`), причому між ними міститься рівно два нулі.

### 9.4. Крок 3: Скалярне множення за схемою Горнера без подвоєння точок

Попередньо обчислимо заперечення базової точки `-P`:
```
-P = (x_P, x_P ⊕ y_P) = (12, 12 ⊕ 17) = (12, 29)
```
де `12 ⊕ 17 = 0001100₂ ⊕ 0010001₂ = 0011101₂ = 29`.

Виконуємо цикл Горнера від старшого розряду `i = 3` до молодшого `i = 0`:

1. **Крок `i = 3` (`u₃ = +1`):**
   Ініціалізація акумулятора:
   ```
   Q₃ = P = (12, 17)
   ```

2. **Крок `i = 2` (`u₂ = 0`):**
   Застосовуємо ендоморфізм Фробеніуса `tau(Q₃)`:
   - `x₂ = x_P² = 12² = (x³ + x²)² = x⁶ + x⁴ = 01010000₂ = 80`.
   - `y₂ = y_P² = 17² = (x⁴ + 1)² = x⁸ + 1 = (x⁷ · x) + 1 = (x + 1) · x + 1 = x² + x + 1 = 0000111₂ = 7`.
   Нова точка акумулятора:
   ```
   Q₂ = tau(Q₃) = (80, 7)
   ```
   Оскільки `u₂ = 0`, додавання точок не виконується.

3. **Крок `i = 1` (`u₁ = 0`):**
   Застосовуємо ендоморфізм Фробеніуса `tau(Q₂)`:
   - `x₁ = 80² = (x⁶ + x⁴)² = x¹² + x⁸ = (x⁶ + x⁵ + x² + x) = 01100110₂ = 102`.
   - `y₁ = 7² = (x² + x + 1)² = x⁴ + x² + 1 = 0010101₂ = 21`.
   Нова точка акумулятора:
   ```
   Q₁ = tau(Q₂) = (102, 21)
   ```
   Оскільки `u₁ = 0`, додавання точок не виконується.

4. **Крок `i = 0` (`u₀ = -1`):**
   Застосовуємо ендоморфізм Фробеніуса `tau(Q₁)`:
   - `x₀' = 102² = (x⁶ + x⁵ + x² + x)² = x⁶ + x⁵ + x³ + x² = 01101100₂ = 108`.
   - `y₀' = 21² = (x⁴ + x² + 1)² = x⁴ + x² + x + 1 = 0010111₂ = 23`.
   Проміжна точка: `tau(Q₁) = (108, 23)`.

   Оскільки `u₀ = -1`, виконуємо змішане додавання точки `-P = (12, 29)`:
   - Нахил січної прямої:
     `lambda = (y₁ + y₂) / (x₁ + x₂) = (23 ⊕ 29) / (108 ⊕ 12) = 10 / 100 = 117` у полі `F_{2^7}`.
   - Нова координата `x`:
     `x_res = lambda² + lambda + x₁ + x₂ + a = 117² + 117 + 108 + 12 + 0 = 40 = x⁵ + x³`.
   - Нова координата `y`:
     `y_res = lambda · (x₁ + x_res) + x_res + y₁ = 117 · (108 ⊕ 40) + 40 + 23 = 19 = x⁴ + x + 1`.

Фінальна результуюча точка скалярного добутку:

```
Q = [23]P = (40, 19)
```

Перевірка прямого множення в групі за допомогою класичного подвоєння підтверджує: `[23](12, 17) = (40, 19)`.

**Підсумок обчислювальної складності:**
Для знаходження точки `[23]P` було виконано:
- **0 операцій подвоєння точки в групі**;
- **3 операції ендоморфізму Фробеніуса** (виключно покомпонентне піднесення координат до квадрата в двійковому полі);
- **Лише 1 операцію додавання точок у групі**.

Це демонструє математичну міць кривих Кобліца: завдяки тау-адичному розкладу важка геометрія подвоєння точок повністю зникає з обчислювального конвеєра.
