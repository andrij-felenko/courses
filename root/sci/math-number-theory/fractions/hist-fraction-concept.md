# 📜 Історія виникнення концепції дробу

Цей історичний огляд відстежує еволюцію математичної думки від перших практичних спроб поділу неподільного у стародавніх цивілізаціях до побудови строгої алгебраїчної теорії полів часток у XIX столітті. Розуміння того, як людство протягом чотирьох тисячоліть переходило від наочних предметних часток до універсального абстрактного числа, розкриває глибоку внутрішню логіку розвитку арифметики, алгебри та теорії чисел.

## 1. Єгипетські аліквотні дроби, папірус Ахмеса та жадібний алгоритм

Перші письмові свідчення системного використання дробів походять зі Стародавнього Єгипту і датовані приблизно 1850 роком до н. е. (математичний папірус Ахмеса, знайдений Александром Ріндом). Єгипетська арифметика мала виняткову структурну рису: усі дроби, за єдиним спеціальним винятком дробу 2/3 (який позначався особливим ієрогліфом), записувалися виключно як сума **аліквотних дробів** — тобто одиничних дробів із чисельником 1 (виду `1/n`).

Замість того, щоб уявити величину 3/5 як три п'яті частини єдиного цілого, єгипетський писар записував її як суму двох різних аліквотних часток:
```
3/5 = 1/2 + 1/10                   [канонічний єгипетський розклад дробу 3/5]
```

Для практичного використання дробу `2/n` у папірусі Ахмеса було складено розлогу нормативну таблицю розкладів для всіх непарних знаменників `n` від 3 до 101. Наприклад:
```
2/5 = 1/3 + 1/15                   [розклад для n = 5]
2/7 = 1/4 + 1/28                   [розклад для n = 7]
2/13 = 1/8 + 1/52 + 1/104          [розклад для n = 13]
2/97 = 1/56 + 1/679 + 1/776        [розклад для великого простого n = 97]
```

Причина такого специфічного підходу полягала в організації фізичного розподілу ресурсів у державному господарстві. Якщо потрібно поділити 3 мірки зерна або 3 буханці хліба між 5 робітниками, то за способом `3/5` кожен робітник мав би отримати по 3 дрібні шматочки від кожного буханця, що вимагало 12 розрізів і створювало багато крихт. За єгипетським способом робітники отримують спершу по `1/2` буханця (3 буханці ріжуться навпіл на 6 частин, 5 роздаються, а 1 лишається), а залишок `1/2` розрізається на 5 рівних частин по `1/10`. Кожен працівник отримує дві акуратні частки — половину та десяту. Це спрощувало фізичний вимір і контроль рівності часток.

Символічно аліквотний дріб позначався ієрогліфом "ра" (зображення відкритого рота, що означало "частка" або "одна частина"), який ставився безпосередньо над числом-знаменником.

У XIII столітті Леонардо Фібоначчі математично формалізував так званий **жадібний алгоритм** розкладу довільного дробу `a/b` в суму одиничних часток (пізніше досліджений Джеймсом Джозефом Сільвестром). Алгоритм на кожному кроці знаходить найбільший можливий аліквотний дріб `1/k`, який не перевищує залишок:
```
k = ⌈b / a⌉                       [вибір найменшого знаменника k такого, що 1/k ≤ a/b]
a/b - 1/k = (a · k - b) / (b · k) [новий дріб має чисельник a · k - b < a]
```

Оскільки новий чисельник `a · k - b` є строго меншим за попередній чисельник `a`, алгоритм гарантовано зупиняється за скінченну кількість кроків. Проте розклади за жадібним методом часто дають колосальні знаменники (наприклад, для `4/5` жадібний метод дає `1/2 + 1/4 + 1/20`), тоді як єгипетські писарі підбирали значно компактніші комбінації.

Єгипетські одиничні дроби породили важливі відкриті проблеми сучасної аналітичної теорії чисел. Знаменита **гіпотеза Ердеша — Штрауса** (висунута Палом Ердешем та Ернстом Штраусом у 1948 році) стверджує, що для будь-якого натурального числа `n ≥ 2` дріб `4/n` завжди можна подати у вигляді суми не більше ніж трьох аліквотних дробів:
```
4/n = 1/x + 1/y + 1/z             [гіпотеза Ердеша — Штрауса для натуральних x, y, z]
```
Подібна гіпотеза Вацлава Серпінського розглядає подання дробів виду `5/n`. Обидві проблеми залишаються остаточно не доведеними для всіх `n`, хоча перевірені чисельно для всіх знаменників до `10^17`.

## 2. Шістдесяткові дроби Месопотамії: позиційний принцип та обчислення обернених чисел

Паралельно у Месопотамії (Вавилон, близько 2000 року до н. е.) виникла кардинально інша, позиційна система числення з основою 60. Вавилонські астрономи та писарі поширили позиційний принцип цілих чисел і на дробові величини, випередивши європейську практику на три з половиною тисячоліття.

У клинописних текстах кожна позиція праворуч від умовного розділювача означала кількість шістдесятих часток (`1/60`), наступна позиція — кількість часток розряду `1/3600`, далі — `1/216000` тощо. Число 60 має 12 натуральних дільників (1, 2, 3, 4, 5, 6, 10, 12, 15, 20, 30, 60), завдяки чому велика кількість часток повсякденної практики подавалася як короткі скінченні шістдесяткові записи:
```
1/2 = 30 / 60                      [тридцять шістдесятих]
1/3 = 20 / 60                      [двадцять шістдесятих]
1/4 = 15 / 60                      [п'ятнадцять шістдесятих]
1/5 = 12 / 60                      [дванадцять шістдесятих]
1/8 = 7 / 60 + 30 / 3600           [сім шістдесятих і тридцять тритисячшостсотних]
```

Для виконання операції ділення вавилоняни зводили його до множення на обернене число:
```
a / b = a · (1 / b)               [зведення ділення до множення на обернене]
```

Для цього укладалися спеціальні таблиці обернених величин (як на відомій табличці Plimpton 322 та навчальних табличках із Ніппура). Числа, знаменники яких містили виключно прості дільники числа 60 (тобто 2, 3 і 5), називалися **регулярними числами** (англ. *regular numbers*). Лише регулярні знаменники мали скінченний розклад у шістдесятковій системі. Для "нерегулярних" знаменників (таких як 7, 11, 13) вавилонські таблички містили попередження на зразок: "7 не ділить, обернене не обчислюється", або вказували практичні наближені значення:
```
1/7 ≈ 8 / 60 + 34 / 3600 + 17 / 216000 + 8 / 12960000   [наближення 1/7 у Вавилоні]
```

Вавилонська дробова система стала прямим попередником сучасних позиційних десяткових дробів. Спадщина шістдесяткової системи Месопотамії безперервно збереглася крізь віки: через елліністичну астрономію Клавдія Птолемея вона визначила поділ години на 60 хвилин, хвилини на 60 секунд, а також геометричний поділ повного кола на 360 градусів із подальшим поділом градуса на мінути та секунди.

## 3. Давньогрецька математика: анфірейзес, неспівмірність та теорія відношень

У давньогрецькій математиці класичної доби поняття дробу розглядалося не як окреме абстрактне число, а як геометричне або кількісне відношення (давньогрец. *λόγος*, *logos*) між двома однорідними величинами.

Піфагорійська школа (VI століття до н. е.) спиралася на філософський постулат про гармонію Всесвіту, за яким "усе є число", де під числом розумілися виключно натуральні числа. Піфагорійці вірили, що будь-які два геометричні відрізки завжди є **співмірними** (давньогрец. *σύμμετρος*, *symmetros*): тобто завжди існує спільна одиниця вимірювання (малий спільний відрізок-еталон), яка укладається в перший відрізок ціле число разів `a`, а в другий — ціле число разів `b`. Тоді відношення цих довжин точно виражалося відношенням двох натуральних чисел `a / b`.

Філософсько-математичною кризою піфагореїзму стало відкриття **неспівмірності** діагоналі одиничного квадрата з його стороною (число `√2`). Доведення спиралося на подільність чисел за парністю: якщо припустити, що відношення діагоналі до сторони дорівнює нескоротному відношенню цілих чисел `p/q`, то одночасно випливає, що і `p`, і `q` мають бути парними, що суперечить їхній взаємній простоті. Це довело неможливість виразити довжину діагоналі жодним звичайним раціональним дробом.

Для порівняння відношень давньогрецькі математики розробили метод **анфірейзесу** (давньогрец. *ἀνθυφαίρεσις* — послідовне взаємне віднімання). Якщо дано два відрізки `A` та `B`, менший багаторазово віднімається від більшого:
```
A = q₀ · B + R₁                    [віднімання B від A з остачею R₁ < B]
B = q₁ · R₁ + R₂                   [віднімання R₁ від B з остачею R₂ < R₁]
R₁ = q₂ · R₂ + R₃                  [віднімання R₂ від R₁ з остачею R₃ < R₂]
```

Послідовність цілих часток `[q₀; q₁, q₂, q₃, ...]` задавала точну характеристику геометричного відношення величин. Якщо величини були співмірними, процес взаємного віднімання за скінченну кількість кроків давав нульову остачу. Два відношення `A : B` та `C : D` вважалися строго рівними, якщо їхні процедури анфірейзесу генерували абсолютно однакову послідовність часток `q_k`. Цей процес став безпосереднім геометричним прообразом **ланцюгових (неперервних) дробів** та алгоритму Евкліда.

У V книзі "Начал" Евкліда (близько 300 року до н. е.) математик Евдокс Кнідський побудував геніальну геометричну теорію пропорцій, яка дозволяла коректно оперувати як раціональними, так і ірраціональними відношеннями без використання поняття дійсного числа:
```
A : B = C : D  ⇔  для всіх m, n ∈ N: (m · A > n · B ⇔ m · C > n · D)
```

У VII–IX книгах "Начал" Евклід виклав фундаментальну арифметичну теорію подільності чисел. Він сформулював алгоритм знаходження найбільшого спільного дільника (НСД), довів єдиність розкладу на прості множники та встановив, що дріб є нескоротним тоді й лише тоді, коли його чисельник і знаменник є взаємно простими числами (`gcd(a, b) = 1`).

Архімед у трактаті "Про вимірювання кола" використав підхідні раціональні дроби, побудовані через послідовні вписані та описані 96-кутники, щоб отримати фундаментальну двосторонню раціональну оцінку числа `π`:
```
223 / 71 < π < 22 / 7              [двостороння раціональна оцінка Архімеда]
3 + 10/71 < π < 3 + 1/7            [похибка менша за 0.002]
```

## 4. Індійсько-арабський синтез: сучасний запис, куттака та горизонтальна риска

Сучасний вигляд звичайного дробу з чисельником вгорі та знаменником внизу сформувався в класичній індійській математиці.

Аріабхата (499 рік н. е.) у трактаті "Аріабхатія" запропонував алгоритм **куттака** (санскр. *kuṭṭaka* — "подрібнювач" або "розпилювач") для знаходження цілих розв'язків лінійних діофантових рівнянь виду `a · x + b · y = c`. Цей алгоритм базувався на розкладанні дробу `a/b` у ланцюговий дріб і є точним еквівалентом розширеного алгоритму Евкліда.

Брахмагупта у праці "Брахма-спхута-сіддханта" (628 рік н. е.) запровадив запис дробів у два поверхи, де чисельник записувався безпосередньо над знаменником, але риска між ними ще не ставилася:
```
a
b
```

Брахмагупта також увів повні алгебраїчні правила для чотирьох арифметичних дій над звичайними дробами:
- Додавання і віднімання через приведення до спільного знаменника:
```
a/b + c/d = (a · d + b · c) / (b · d)
```
- Множення як добуток чисельників, поділений на добуток знаменників:
```
(a/b) · (c/d) = (a · c) / (b · d)
```

Бхаскара II у трактаті "Лілаваті" (1150 рік н. е.) дав класичне правило ділення на дріб: "Щоб поділити число на дріб, слід перевернути знаменник і чисельник дільника і помножити ділене на отриманий обернений дріб".

У XII столітті арабський математик із Магрибу (сучасний Марокко) Абу Бакр аль-Хассар у підручнику "Кітаб ал-Баян ва-т-Тадкар" уперше запровадив **горизонтальну риску дробу** для наочного відокремлення чисельника від знаменника:
```
a
─
b
```

Завдяки працям Аль-Хорезмі, перекладам Роберта Честерського та капітальному трактату Леонардо Фібоначчі ("Liber Abaci", 1202 рік) горизонтальна риска та індійські правила обчислень утвердилися в середньовічній Європі. Фібоначчі ввів у латинську термінологію слова *numerus numerator* (чисельник — той, що рахує кількість часток) та *numerus denominator* (знаменник — той, що називає міру або розмір частки).

## 5. Позиційні десяткові дроби та логарифмічна революція

Попри теоретичну довершеність звичайних дробів, практичне додавання багатьох дробів із різними знаменниками в астрономії, комерції та навігації вимагало тривалого обчислення найменшого спільного кратного.

У 1427 році перський астроном і математик Гіяс ад-Дін Джамшид аль-Каші в трактаті "Ключ до арифметики" (*Miftah al-Hisab*) детально описав систему десяткових дробів, використовуючи їх для обчислення числа `π` з точністю до 16 десяткових знаків.

У Європі перше системне викладення теорії десяткових дробів здійснив фламандський інженер і вчений Симон Стевін у брошурі "De Thiende" ("Десята", 1585 рік). Стевін доводив, що всі обчислення з дробами можна звести до звичайних операцій над цілими числами, записуючи десяткові порядки у круглих дужках: наприклад, дріб `3.1415` він записував як `3 (0) 1 (1) 4 (2) 1 (3) 5 (4)`.

У 1617 році шотландський математик Джон Непер у праці "Rabdologia" запропонував замінити громіздкі індекси Стевіна простою **десятковою крапкою або комою**, що відокремлює цілу частину від дробової. Винахід Непером логарифмів остаточно закріпив десяткові дроби як головний інструмент наукових та інженерних розрахунків.

## 6. Алгебраїчна строгість XIX століття: класи еквівалентності та поле часток

До середини XIX століття дроби сприймалися інтуїтивно як результат ділення двох фізичних або геометричних величин. Проте створення математичного аналізу вимагало усунення будь-яких геометричних чи фізичних припущень із фундаменту числової системи.

Німецький математик Ріхард Дедекінд у праці "Stetigkeit und irrationale Zahlen" (1872), Карл Вейєрштрасс та італійський логік Джузеппе Пеано побудували строгу алгебраїчну теорію поля раціональних чисел `Q`.

Вони визначили раціональне число не як вираз `a/b`, а як **клас еквівалентності впорядкованих пар цілих чисел** `(a, b) ∈ Z × (Z \ {0})` за відношенням еквівалентності:
```
(a, b) ~ (c, d)  ⇔  a · d = b · c  [алгебраїчний критерій рівності дробів]
```

Ця формалізація довела, що раціональні числа утворюють комутативне **поле часток** `Q = Q(Z)` над область цілісності цілих чисел `Z`. Кожен дріб `a/b` є представником класу еквівалентності, операції над класами повністю узгоджені, а властивості додавання та множення безпосередньо випливають з аксіом цілих чисел.

Побудова поля часток `Q` стала завершальною ланкою в обґрунтуванні класичної арифметики та відкрила шлях до сучасної топологічної і алгебраїчної побудови поля дійсних чисел `R` за допомогою перерізів Дедекінда та фундаментальних послідовностей Коші.
