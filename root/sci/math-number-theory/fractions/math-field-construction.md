# 🧮 Алгебраїчне виведення та аксіоми Поля Часток

Ця математична вставка містить строге алгебраїчне виведення побудови поля часток Q над кільцем цілих чисел Z та детальний доказ виконності всіх аксіом поля для класів еквівалентності дробів. Текст призначений для детального ознайомлення з формальним підґрунтям раціональних чисел, яке гарантує коректність арифметичних операцій без логічних суперечностей.

## 1. Концепція розширення області цілісності до поля

Кільце цілих чисел `(Z, +, ·)` є прикладом алгебраїчної структури, яка називається **областю цілісності** (англ. *integral domain*). Область цілісності — це комутативне кільце з одиницею, яке не має **дільників нуля**, тобто з рівності `a · b = 0` недвозначно випливає, що `a = 0` або `b = 0`.

Головним обмеженням будь-якої області цілісності, яка не є полем, є відсутність мультиплікативних обернених елементів для більшості ненульових елементів. У кільці `Z` єдиними оборотними елементами за множенням є `1` та `-1`.

У загальній абстрактній алгебрі існує теорема: для будь-якої комутативної області цілісності `R` існує канонічне розширення `K = Q(R)`, яке є полем і називається **полем часток** (англ. *field of fractions*) кільця `R`. Для кільця цілих чисел `R = Z` відповідним полем часток є поле раціональних чисел `Q = Q(Z)`.

## 2. Множина пар та відношення еквівалентності

Формальна побудова починається з розгляду декартового добутку множини цілих чисел та множини ненульових цілих чисел:
```
S = Z × (Z \ {0}) = {(a, b) | a ∈ Z, b ∈ Z, b ≠ 0}   [декартів добуток множин]
```

Перший елемент `a` у парі `(a, b)` виконує роль чисельника, а другий елемент `b` — роль знаменника.

На множині `S` вводиться бінарне відношення `~` (тильда), визначене через рівність хрестових добутків:
```
(a, b) ~ (c, d)  ⇔  a · d = b · c                  [відношення еквівалентності]
```

### Детальний доказ того, що відношення ~ є відношенням еквівалентності

Щоб відношення `~` утворювало коректне розбиття множини `S` на неперетинні класи, воно мусить задовольняти три фундаментальні властивості: рефлексивність, симетричність та транзитивність.

1. **Рефлексивність:** Для будь-якої пари `(a, b) ∈ S` виконується `(a, b) ~ (a, b)`.
```
a · b = b · a           [комутативність множення в Z]
⇒ (a, b) ~ (a, b)       [за визначенням відношення ~]
```

2. **Симетричність:** Якщо `(a, b) ~ (c, d)`, то `(c, d) ~ (a, b)`.
```
(a, b) ~ (c, d)
⇒ a · d = b · c         [за умовою]
⇒ c · b = d · a         [комутативність множення в Z]
⇒ (c, d) ~ (a, b)       [за визначенням відношення ~]
```

3. **Транзитивність:** Якщо `(a, b) ~ (c, d)` та `(c, d) ~ (e, f)`, то `(a, b) ~ (e, f)`.
```
a · d = b · c           [умова (a, b) ~ (c, d)]
c · f = d · e           [умова (c, d) ~ (e, f)]

(a · d) · f = (b · c) · f             [домножуємо першу рівність на f]
a · d · f = b · (c · f)               [асоціативність в Z]
a · d · f = b · (d · e)               [підставляємо c · f = d · e]
(a · f) · d = (b · e) · d             [перегруповуємо множники]
(a · f - b · e) · d = 0               [виносино d за дужки]
```
Оскільки за визначенням множини `S` ненульовий знаменник `d ≠ 0`, а кільце `Z` є областю цілісності (не має дільників нуля), з рівності `(a · f - b · e) · d = 0` недвозначно випливає:
```
a · f - b · e = 0
a · f = b · e
⇒ (a, b) ~ (e, f)                     [за визначенням відношення ~]
```

Отже, відношення `~` ділить множину `S` на неперетинні класи еквівалентності. Множина всіх класів еквівалентності позначається як `Q = S / ~`. Клас еквівалентності пари `(a, b)` позначається як `[(a, b)]` або у звичній математичній формі `a / b`.

## 3. Коректність визначення арифметичних операцій

Для класів еквівалентності `[(a, b)]` та `[(c, d)]` додавання (+) та множення (·) визначаються формулами:
```
[(a, b)] + [(c, d)] = [(a · d + b · c,  b · d)]      [визначення суми класів]
[(a, b)] · [(c, d)] = [(a · c,  b · d)]              [визначення добутку класів]
```

Оскільки знаменники `b ≠ 0` та `d ≠ 0`, їхній добуток `b · d ≠ 0`, отже результуюча пара належить множині `S`.

### Доведення незалежності операцій від вибору представника класу

Оскільки один і той самий клас еквівалентності задається безліччю еквівалентних пар, необхідно довести, що результат операцій не залежить від того, які саме пари вибрано з класів.

Нехай `[(a₁, b₁)] = [(a₂, b₂)]`, тобто `a₁ · b₂ = b₁ · a₂`, i `[(c₁, d₁)] = [(c₂, d₂)]`, тобто `c₁ · d₂ = d₁ · c₂`.

 Перевіримо додавання: потрібно довести, що `(a₁ · d₁ + b₁ · c₁, b₁ · d₁) ~ (a₂ · d₂ + b₂ · c₂, b₂ · d₂)`.
За визначенням відношення це означає рівність хрестових добутків:
```
(a₁ · d₁ + b₁ · c₁) · (b₂ · d₂) = (b₁ · d₁) · (a₂ · d₂ + b₂ · c₂)   [рівність хрестових добутків]
```

Розкриємо ліву частину:
```
L = (a₁ · d₁ + b₁ · c₁) · (b₂ · d₂)
  = a₁ · d₁ · b₂ · d₂ + b₁ · c₁ · b₂ · d₂
  = (a₁ · b₂) · d₁ · d₂ + (c₁ · d₂) · b₁ · b₂    [асоціативність та комутативність]
```
Підставимо рівності `a₁ · b₂ = b₁ · a₂` та `c₁ · d₂ = d₁ · c₂`:
```
L = (b₁ · a₂) · d₁ · d₂ + (d₁ · c₂) · b₁ · b₂
  = b₁ · d₁ · a₂ · d₂ + b₁ · d₁ · b₂ · c₂
  = (b₁ · d₁) · (a₂ · d₂ + b₂ · c₂) = R.         [винесли спільний множник (b₁ · d₁)]
```
Рівність `L = R` доведена, отже додавання визначено коректно. 

Перевіримо множення: потрібно довести, що `(a₁ · c₁, b₁ · d₁) ~ (a₂ · c₂, b₂ · d₂)`.
```
(a₁ · c₁) · (b₂ · d₂)
= (a₁ · b₂) · (c₁ · d₂)               [перегруповування множників в Z]
= (b₁ · a₂) · (d₁ · c₂)               [підстановка рівностей a₁·b₂ = b₁·a₂ та c₁·d₂ = d₁·c₂]
= (b₁ · d₁) · (a₂ · c₂)               [перегруповування множників в Z]
⇒ (a₁ · c₁, b₁ · d₁) ~ (a₂ · c₂, b₂ · d₂)
```
Отже, операція множення також визначена строго й коректно.

## 4. Строгий доказ 9 аксіом поля для алгебраїчної структури (Q, +, ·)

Алгебраїчна структура `(Q, +, ·)` є полем, якщо вона задовольняє наступні 9 аксіом.

### 1. Комутативність додавання: x + y = y + x
```
[(a, b)] + [(c, d)]
= [(a · d + b · c, b · d)]             [визначення додавання]
= [(c · b + d · a, d · b)]             [комутативність додавання та множення в Z]
= [(c, d)] + [(a, b)]                 [визначення додавання]
```

### 2. Асоціативність додавання: (x + y) + z = x + (y + z)
```
([(a, b)] + [(c, d)]) + [(e, f)]
= [(a · d + b · c, b · d)] + [(e, f)]
= [((a · d + b · c) · f + (b · d) · e, (b · d) · f)]
= [(a · d · f + b · c · f + b · d · e, b · d · f)]    [розкриття дужок в Z]

[(a, b)] + ([(c, d)] + [(e, f)])
= [(a, b)] + [(c · f + d · e, d · f)]
= [(a · (d · f) + b · (c · f + d · e), b · (d · f))]
= [(a · d · f + b · c · f + b · d · e, b · d · f)]    [розкриття дужок в Z]
```
Обидва вирази збігаються, отже асоціативність виконується.

### 3. Існування нейтрального елемента по додаванню (Нуль)
Класом нуля є `e₀ = [(0, 1)]`.
```
[(a, b)] + [(0, 1)]
= [(a · 1 + b · 0, b · 1)]
= [(a, b)]
```

### 4. Існування протилежного елемента по додаванню
Для класу `[(a, b)]` протилежним є `[(-a, b)]`.
```
[(a, b)] + [(-a, b)]
= [(a · b + b · (-a), b · b)]
= [(a · b - a · b, b²)]
= [(0, b²)]
```
Перевіримо еквівалентність `[(0, b²)] ~ [(0, 1)]`:
`0 · 1 = 0 · b²`  ⇒  `0 = 0` (істинно). Отже, `[(a, b)] + [(-a, b)] = [(0, 1)]`.

### 5. Комутативність множення: x · y = y · x
```
[(a, b)] · [(c, d)] = [(a · c, b · d)] = [(c · a, d · b)] = [(c, d)] · [(a, b)].
```

### 6. Асоціативність множення: (x · y) · z = x · (y · z)
```
([(a, b)] · [(c, d)]) · [(e, f)] = [(a · c · e, b · d · f)] = [(a, b)] · ([(c, d)] · [(e, f)]).
```

### 7. Існування нейтрального елемента по множенню (Одиниця)
Класом одиниці є `e₁ = [(1, 1)]`.
```
[(a, b)] · [(1, 1)] = [(a · 1, b · 1)] = [(a, b)].
```

### 8. Існування оберненого елемента по множенню
Для будь-якого ненульового елемента `[(a, b)] ≠ [(0, 1)]` виконується `a ≠ 0`. Оберненим є елемент `[(b, a)]`.
```
[(a, b)] · [(b, a)] = [(a · b, b · a)]
```
Перевіримо еквівалентність `[(a · b, b · a)] ~ [(1, 1)]`:
`(a · b) · 1 = (b · a) · 1`  ⇒  `a · b = a · b` (істинно).
Отже, `[(a, b)] · [(b, a)] = [(1, 1)]`.

### 9. Дистрибутивність множення відносно додавання: x · (y + z) = x · y + x · z
```
[(a, b)] · ([(c, d)] + [(e, f)])
= [(a, b)] · [(c · f + d · e, d · f)]
= [(a · (c · f + d · e), b · d · f)]
= [(a · c · f + a · d · e, b · d · f)]

[(a, b)] · [(c, d)] + [(a, b)] · [(e, f)]
= [(a · c, b · d)] + [(a · e, b · f)]
= [(a · c · b · f + b · d · a · e, b · d · b · f)]
= [b · (a · c · f + a · d · e), b · (b · d · f)]
```
Оскільки `b ≠ 0`, можемо скоротити спільний множник `b` у чисельнику та знаменнику, отримавши точну рівність із лівою частиною.

## 5. Впорядкованість та щільність поля раціональних чисел

Поле раціональних чисел `Q` є не лише алгебраїчним полем, але й **лінійно впорядкованим полем**.

### Визначення порядку на Q

Для двох раціональних чисел `x = a/b` та `y = c/d` із додатними знаменниками (`b > 0, d > 0`) відношення порядку визначається як:
```
a/b < c/d  ⇔  a · d < b · c                       [визначення порядку на Q]
```

Це відношення порядку узгоджене з алгебраїчними операціями:
1. Якщо `x < y`, то `x + z < y + z` для будь-якого `z ∈ Q`.
2. Якщо `x < y` та `z > 0`, то `x · z < y · z`.

### Властивість щільності (Density Property)

На відміну від цілих чисел `Z`, де між `n` та `n + 1` немає жодного цілого числа, поле раціональних чисел `Q` є **всюди щільним** (англ. *dense*).

**Теорема:** Між будь-якими двома різними раціональними числами `x < y` існує нескінченно багато інших раціональних чисел.

*Доказ:* Розглянемо середнє арифметичне двох чисел `z = (x + y) / 2`.
Оскільки `x < y`, додавши `x` до обох частин, отримаємо `2x < x + y  ⇒  x < (x + y) / 2 = z`.
Додавши `y` до обох частин `x < y`, отримаємо `x + y < 2y  ⇒  z = (x + y) / 2 < y`.
Отже, `x < z < y`, де `z ∈ Q`. Застосовуючи цю процедуру рекурсивно до пар `(x, z)` та `(z, y)`, отримуємо зліченну нескінченність раціональних чисел між `x` та `y`.

## 6. Канонічне вкладення Z в Q

Існує природне мономорфне вкладення `i: Z → Q`, яке кожному цілому числу `n` ставить у відповідність клас еквівалентності дробу `[(n, 1)]`:
```
i(n) = [(n, 1)]                                    [канонічне вкладення n у Q]
i(n + m) = [(n + m, 1)] = [(n, 1)] + [(m, 1)]      [збереження додавання]
i(n · m) = [(n · m, 1)] = [(n, 1)] · [(m, 1)]      [збереження множення]
```

Таким чином, кільце цілих чисел `Z` ізоморфно вкладається у поле раціональних чисел `Q` як підкільце, а `Q` є найменшим полем, що містить `Z`.
