# 🧮 Алгебраїчне виведення та аксіоми Поля Часток

Ця математична вставка містить строге алгебраїчне виведення побудови поля часток `Q` над кільцем цілих чисел `Z`, детальний доказ виконання всіх аксіом поля, універсальної властивості факторизації, теореми про канонічного нескоротного представника, властивостей лінійного порядку та архімедовості, а також демонстрацію неповноти раціональних чисел та їхніх метричних поповнень. Текст призначений для вичерпного ознайомлення з формальним алгебраїчним фундаментом раціональних чисел, який гарантує несуперечливість арифметичних операцій.

## 1. Концепція розширення області цілісності до поля

Кільце цілих чисел `(Z, +, ·)` є фундаментальним прикладом алгебраїчної структури, яка в загальній алгебрі називається **областю цілісності** (англ. *integral domain*). Область цілісності — це комутативне кільце з ненульовим одиничним елементом, яке не містить **дільників нуля**:
```
a · b = 0  ⇒  a = 0  або  b = 0   [аксіома відсутності дільників нуля]
```

Головним структурним обмеженням кільця `Z` є те, що більшість його елементів не мають мультиплікативних обернених. Єдиними оборотними елементами кільця `Z` (його групою одиниць `Z^×`) є лише числа `1` та `-1`. Рівняння `b · x = a` для довільних цілих `a` та `b ≠ 0` здебільшого не має розв'язку всередині `Z`.

В абстрактній алгебрі доведено фундаментальну теорему: для будь-якої комутативної області цілісності `R` існує єдине (з точністю до ізоморфізму) мінімальне поле `K = Q(R)`, що містить `R` як підкільце. Це поле називається **полем часток** (англ. *field of fractions*) області цілісності `R`. Для кільця цілих чисел `R = Z` відповідним полем часток є поле раціональних чисел `Q = Q(Z)`.

## 2. Множина пар та відношення еквівалентності

Формальна побудова поля часток починається з розгляду декартового добутку множини цілих чисел `Z` та множини всіх ненульових цілих чисел `Z \ {0}`:
```
S = Z × (Z \ {0}) = {(a, b) | a ∈ Z, b ∈ Z, b ≠ 0}   [декартів добуток множин]
```

Перший елемент `a` у впорядкованій парі `(a, b)` позначає чисельник майбутнього дробу, а другий елемент `b` — його знаменник.

На множині `S` вводиться бінарне відношення `~` (тильда), визначене через рівність хрестових добутків у кільці `Z`:
```
(a, b) ~ (c, d)  ⇔  a · d = b · c                  [визначення відношення еквівалентності]
```

### Детальний доказ того, що відношення ~ є відношенням еквівалентності

Щоб відношення `~` утворювало коректне розбиття множини `S` на неперетинні класи, воно мусить задовольняти три фундаментальні аксіоми еквівалентності: рефлексивність, симетричність та транзитивність.

1. **Рефлексивність:** Для будь-якої пари `(a, b) ∈ S` виконується `(a, b) ~ (a, b)`.
```
a · b = b · a           [комутативність множення в Z]
⇒ (a, b) ~ (a, b)       [за визначенням відношення ~]
```

2. **Симетричність:** Якщо `(a, b) ~ (c, d)`, то `(c, d) ~ (a, b)`.
```
(a, b) ~ (c, d)
⇒ a · d = b · c         [за умовою відношення]
⇒ c · b = d · a         [комутативність множення в Z]
⇒ (c, d) ~ (a, b)       [за визначенням відношення ~]
```

3. **Транзитивність:** Якщо `(a, b) ~ (c, d)` та `(c, d) ~ (e, f)`, то `(a, b) ~ (e, f)`.
```
a · d = b · c           [умова (a, b) ~ (c, d)]
c · f = d · e           [умова (c, d) ~ (e, f)]

(a · d) · f = (b · c) · f             [домножуємо першу рівність на f]
a · d · f = b · (c · f)               [асоціативність множення в Z]
a · d · f = b · (d · e)               [підставляємо c · f = d · e]
(a · f) · d = (b · e) · d             [перегруповуємо множники за комутативністю]
(a · f - b · e) · d = 0               [переносимо вліво й виносимо спільний множник d]
```

Оскільки за побудовою множини `S` знаменник `d ≠ 0`, а кільце `Z` є областю цілісності (не має дільників нуля), з рівності `(a · f - b · e) · d = 0` недвозначно випливає:
```
a · f - b · e = 0                     [ділення на ненульовий елемент d в області цілісності]
a · f = b · e
⇒ (a, b) ~ (e, f)                     [за визначенням відношення ~]
```

Отже, відношення `~` є строгим відношенням еквівалентності. Фактор-множина всіх класів еквівалентності позначається як `Q = S / ~`. Клас еквівалентності пари `(a, b)` позначається як `[(a, b)]` або у звичній математичній нотації `a / b`.

## 3. Теорема про єдиність канонічного нескоротного представника

Оскільки клас еквівалентності `[(a, b)]` складається з нескінченної кількості впорядкованих пар, для практики обчислень і однозначності запису чисел фундаментальне значення має виділення у кожному класі єдиного канонічного представника.

**Теорема:** У кожному класі еквівалентності `[(a, b)] ∈ Q` існує рівно одна пара цілих чисел `(p, q)` така, що:
1. Знаменник є строго додатним: `q > 0`;
2. Чисельник і знаменник є взаємно простими числами: `gcd(p, q) = 1`.

*Доведення існування:*
Нехай `(a, b)` — довільний представник класу. Якщо `b < 0`, розглянемо еквівалентну пару `(-a, -b)`, у якої другий елемент є строго додатним.
Нехай `g = gcd(|a|, |b|)`. Оскільки `b ≠ 0`, найбільший спільний дільник `g` є коректно визначеним натуральним числом `g ≥ 1`.
Покладемо `p = a / g` та `q = b / g`.
Тоді `q > 0`, а за фундаментальною властивістю НСД числа `p` та `q` є взаємно простими: `gcd(p, q) = gcd(a/g, b/g) = 1`.
Перевіримо еквівалентність пари `(p, q)` вихідній парі `(a, b)`:
```
p · b = (a / g) · b = a · (b / g) = a · q
⇒ (p, q) ~ (a, b)
```
Отже, пара `(p, q)` належить тому самому класу еквівалентності. Існування доведено.

*Доведення єдиності:*
Припустимо, що в одному класі існують дві пари `(p₁, q₁)` та `(p₂, q₂)`, які задовольняють умови теореми: `q₁ > 0, q₂ > 0` та `gcd(p₁, q₁) = gcd(p₂, q₂) = 1`.
Оскільки вони належать одному класу, за визначенням еквівалентності маємо:
```
p₁ · q₂ = q₁ · p₂
```
Звідси випливає, що число `q₁` ділить добуток `p₁ · q₂`. Оскільки за умовою чисельник і знаменник першого дробу взаємно прості `gcd(p₁, q₁) = 1`, за фундаментальною лемою Евкліда про подільність знаменник `q₁` не має спільних дільників із `p₁`, а отже зобов'язаний ділити другий множник `q₂`. Тобто `q₁ | q₂`.
Аналогічно, переписавши рівність як `p₂ · q₁ = q₂ · p₁` та врахувавши взаємну простоту `gcd(p₂, q₂) = 1`, отримуємо, що `q₂` не ділить `p₂`, а отже зобов'язаний ділити `q₁`. Тобто `q₂ | q₁`.
Оскільки обидва знаменники є строго додатними натуральними числами (`q₁ ≥ 1, q₂ ≥ 1`), з одночасної взаємної подільності `q₁ | q₂` та `q₂ | q₁` недвозначно випливає, що знаменники точно збігаються: `q₁ = q₂`.
Підставивши рівність `q₁ = q₂` у вихідне рівняння `p₁ · q₂ = q₁ · p₂` та скоротивши обидві частини на ненульовий знаменник, отримуємо `p₁ = p₂`.
Єдиність канонічного нескоротного представника повністю доведена. Це гарантує, що кожне раціональне число має рівно один нормалізований нескоротний запис.

## 4. Коректність визначення арифметичних операцій

На множині класів еквівалентності `Q` додавання (+) та множення (·) визначаються формулами:
```
[(a, b)] + [(c, d)] = [(a · d + b · c,  b · d)]      [визначення суми класів]
[(a, b)] · [(c, d)] = [(a · c,  b · d)]              [визначення добутку класів]
```

Оскільки знаменники `b ≠ 0` та `d ≠ 0`, а кільце `Z` не має дільників нуля, їхній добуток `b · d ≠ 0`, отже пара-результат завжди належить вихідній множині `S`.

### Доведення незалежності операцій від вибору представника класу

Оскільки один і той самий клас еквівалентності містить нескінченну кількість представників, необхідно довести коректність (англ. *well-definedness*): результат додавання та множення не залежить від вибору конкретної пари з класу.

Нехай `[(a₁, b₁)] = [(a₂, b₂)]`, тобто `a₁ · b₂ = b₁ · a₂`, та `[(c₁, d₁)] = [(c₂, d₂)]`, тобто `c₁ · d₂ = d₁ · c₂`.

1. **Коректність додавання:** Потрібно довести, що `(a₁ · d₁ + b₁ · c₁, b₁ · d₁) ~ (a₂ · d₂ + b₂ · c₂, b₂ · d₂)`.
Це еквівалентно рівності хрестових добутків у `Z`:
```
(a₁ · d₁ + b₁ · c₁) · (b₂ · d₂) = (b₁ · d₁) · (a₂ · d₂ + b₂ · c₂)
```

Розкриємо ліву частину:
```
L = (a₁ · d₁ + b₁ · c₁) · (b₂ · d₂)
  = a₁ · d₁ · b₂ · d₂ + b₁ · c₁ · b₂ · d₂
  = (a₁ · b₂) · d₁ · d₂ + (c₁ · d₂) · b₁ · b₂    [асоціативність та комутативність в Z]
```
Підставимо рівності `a₁ · b₂ = b₁ · a₂` та `c₁ · d₂ = d₁ · c₂`:
```
L = (b₁ · a₂) · d₁ · d₂ + (d₁ · c₂) · b₁ · b₂
  = b₁ · d₁ · a₂ · d₂ + b₁ · d₁ · b₂ · c₂
  = (b₁ · d₁) · (a₂ · d₂ + b₂ · c₂) = R          [винесення спільного множника (b₁ · d₁)]
```
Рівність `L = R` доведена. Операція додавання визначена коректно.

2. **Коректність множення:** Потрібно довести, що `(a₁ · c₁, b₁ · d₁) ~ (a₂ · c₂, b₂ · d₂)`.
```
(a₁ · c₁) · (b₂ · d₂)
= (a₁ · b₂) · (c₁ · d₂)               [комутативність та асоціативність в Z]
= (b₁ · a₂) · (d₁ · c₂)               [підстановка рівностей a₁·b₂ = b₁·a₂ та c₁·d₂ = d₁·c₂]
= (b₁ · d₁) · (a₂ · c₂)               [перегруповування множників в Z]
⇒ (a₁ · c₁, b₁ · d₁) ~ (a₂ · c₂, b₂ · d₂)
```
Операція множення визначена коректно.

## 5. Строгий доказ 9 аксіом поля для структури (Q, +, ·)

Алгебраїчна структура `(Q, +, ·)` є полем, якщо вона задовольняє наступні 9 аксіом.

### 1. Комутативність додавання: x + y = y + x
```
[(a, b)] + [(c, d)]
= [(a · d + b · c, b · d)]             [визначення додавання]
= [(c · b + d · a, d · b)]             [комутативність додавання та множення в Z]
= [(c, d)] + [(a, b)]                 [визначення додавання]
```

### 2. Асоціативність додавання: (x + y) + z = x + (y + z)
```
([(a, b)] + [(c, d)]) + [(e, f)]
= [(a · d + b · c, b · d)] + [(e, f)]
= [((a · d + b · c) · f + (b · d) · e, (b · d) · f)]
= [(a · d · f + b · c · f + b · d · e, b · d · f)]    [дистрибутивність у кільці Z]

[(a, b)] + ([(c, d)] + [(e, f)])
= [(a, b)] + [(c · f + d · e, d · f)]
= [(a · (d · f) + b · (c · f + d · e), b · (d · f))]
= [(a · d · f + b · c · f + b · d · e, b · d · f)]    [дистрибутивність у кільці Z]
```
Обидва результати збігаються. Асоціативність доведена.

### 3. Нейтральний елемент додавання (Нуль)
Нейтральним елементом є клас `e₀ = [(0, 1)]`.
```
[(a, b)] + [(0, 1)]
= [(a · 1 + b · 0, b · 1)]
= [(a, b)]                            [оскільки a·1 = a та b·0 = 0]
```

### 4. Протилежний елемент додавання
Для будь-якого класу `[(a, b)]` протилежним є елемент `[(-a, b)]`.
```
[(a, b)] + [(-a, b)]
= [(a · b + b · (-a), b · b)]
= [(a · b - a · b, b²)]
= [(0, b²)]
```
Оскільки `0 · 1 = 0 · b² = 0`, клас `[(0, b²)] = [(0, 1)] = e₀`.

### 5. Комутативність множення: x · y = y · x
```
[(a, b)] · [(c, d)]
= [(a · c, b · d)]
= [(c · a, d · b)]                    [комутативність множення в Z]
= [(c, d)] · [(a, b)]
```

### 6. Асоціативність множення: (x · y) · z = x · (y · z)
```
([(a, b)] · [(c, d)]) · [(e, f)]
= [(a · c, b · d)] · [(e, f)]
= [((a · c) · e, (b · d) · f)]
= [(a · (c · e), b · (d · f))]        [асоціативність множення в Z]
= [(a, b)] · ([(c, d)] · [(e, f)])
```

### 7. Нейтральний елемент множення (Одиниця)
Нейтральним елементом є клас `e₁ = [(1, 1)]`.
```
[(a, b)] · [(1, 1)]
= [(a · 1, b · 1)]
= [(a, b)]                            [оскільки 1 — нейтральний елемент у Z]
```

### 8. Обернений елемент множення
Для будь-якого ненульового класу `[(a, b)] ≠ [(0, 1)]` виконується умова `a ≠ 0`. Тоді пара `(b, a) ∈ S` є допустимою, а її клас `[(b, a)]` є оберненим:
```
[(a, b)] · [(b, a)]
= [(a · b, b · a)]
```
Оскільки `(a · b) · 1 = (b · a) · 1`, клас `[(a · b, b · a)] = [(1, 1)] = e₁`.

### 9. Дистрибутивність множення відносно додавання: x · (y + z) = x · y + x · z
```
L = [(a, b)] · ([(c, d)] + [(e, f)])
  = [(a, b)] · [(c · f + d · e, d · f)]
  = [(a · (c · f + d · e), b · (d · f))]
  = [(a · c · f + a · d · e, b · d · f)]

R = [(a, b)] · [(c, d)] + [(a, b)] · [(e, f)]
  = [(a · c, b · d)] + [(a · e, b · f)]
  = [(a · c · b · f + b · d · a · e, (b · d) · (b · f))]
  = [(b · (a · c · f + a · d · e), b · (b · d · f))]
```
Оскільки `b ≠ 0`, пари `(a · c · f + a · d · e, b · d · f)` та `(b · (a · c · f + a · d · e), b · (b · d · f))` еквівалентні за множником `b`. Отже, `L = R`.

## 6. Універсальна властивість поля часток

Поле часток `Q` характеризується фундаментальною теоретико-категорною властивістю:

Існує канонічний ін'єктивний гомоморфізм кілець `i: Z → Q`, визначений формулою `i(n) = [(n, 1)]`.

**Теорема (Універсальна властивість):** Нехай `K` — довільне поле, а `f: Z → K` — ін'єктивний гомоморфізм кілець. Тоді існує **єдиний** гомоморфізм полів `g: Q → K` такий, що комутує діаграма `g ∘ i = f`:
```
Z  ─── i ───>  Q
│            │
f            g
│            │
v            v
K  ─────────>  K
```

*Доведення існування:* Визначимо відображення `g([(a, b)]) = f(a) · (f(b))^(-1)`.
Оскільки `b ≠ 0` у `Z`, а `f` ін'єктивний, `f(b) ≠ 0` у полі `K`, отже елемент `(f(b))^(-1)` існує.
Якщо `[(a₁, b₁)] = [(a₂, b₂)]`, то `a₁ · b₂ = b₁ · a₂`. Застосувавши гомоморфізм `f`, маємо `f(a₁) · f(b₂) = f(b₁) · f(a₂)`. Помноживши на `(f(b₁))^(-1) · (f(b₂))^(-1)`, отримуємо:
```
f(a₁) · (f(b₁))^(-1) = f(a₂) · (f(b₂))^(-1)
```
Це доводить коректність визначення `g`. Легко перевіряється, що `g` зберігає додавання та множення.

*Доведення єдиності:* Для будь-якого дробу `[(a, b)] = [(a, 1)] · [(b, 1)]^(-1) = i(a) · (i(b))^(-1)`.
Будь-який гомоморфізм полів `g`, що задовольняє `g ∘ i = f`, зобов'язаний діяти так:
```
g([(a, b)]) = g(i(a) · (i(b))^(-1)) = g(i(a)) · (g(i(b)))^(-1) = f(a) · (f(b))^(-1)
```
Отже, гомоморфізм `g` визначений однозначно. Це доводить, що `Q` є найменшим полем, що містить `Z`.

## 7. Узагальнення: поля часток в інших алгебраїчних структурах

Конструкція поля часток через класи еквівалентності впорядкованих пар не обмежується кільцем цілих чисел, а застосовується до довільної комутативної області цілісності `R`:

1. **Поле раціональних функцій `F(x)`:**
Якщо взяти кільце многочленів `R = F[x]` над деяким полем `F`, його полем часток є поле раціональних функцій `F(x) = Q(F[x])`, елементами якого є відношення многочленів `P(x) / Q(x)`, де `Q(x) ≠ 0`. Це поле лежить в основі класичного математичного аналізу (зокрема інтегрування раціональних дробів та розкладу на найпростіші дроби) та алгебраїчної геометрії.

2. **Поле гаусових раціональних чисел `Q(i)`:**
Для кільця цілих гаусових чисел `Z[i] = {a + b·i | a, b ∈ Z}` полем часток є поле `Q(i) = {x + y·i | x, y ∈ Q}`. Кожен дріб `(a + b·i) / (c + d·i)` зводиться до стандартного вигляду множенням на спряжене число `c - d·i`.

3. **Зв'язок із локалізацією кілець:**
У сучасній комутативній алгебрі побудова поля часток є граничним випадком операції **локалізації** `S^(-1)R`, де в ролі мультиплікативної системи `S` береться множина всіх ненульових елементів кільця `S = R \ {0}`. Якщо замість усіх ненульових чисел взяти лише числа, не кратні фіксованому простому числу `p`, виникає локальне кільце `Z_(p)` (множина дробів, знаменники яких не діляться на `p`), яке відіграє вирішальну роль у p-адичному аналізі та локальній теорії чисел.

## 8. Лінійний порядок, архімедовість та щільність

Поле раціональних чисел `Q` є **лінійно впорядкованим полем**.

Кожен клас `[(a, b)]` можна канонічно записати з додатним знаменником `b > 0` (якщо `b < 0`, домножуємо пару на `-1`).

Для дробів `a/b` та `c/d` з додатними знаменниками `b > 0, d > 0` відношення порядку визначається як:
```
a/b < c/d  ⇔  a · d < b · c                       [визначення строгого порядку в Q]
```

### Властивість Архімеда (Архімедове поле)

**Теорема:** Поле `Q` є архімедовим: для будь-яких двох додатних раціональних чисел `x > 0` та `y > 0` існує натуральне число `n ∈ N` таке, що `n · x > y`.

*Доказ:* Нехай `x = a/b` та `y = c/d`, де `a, b, c, d ∈ N` (всі строго більші за нуль).
Нерівність `n · (a/b) > c/d` еквівалентна цілочисельній нерівності:
```
n · (a · d) > b · c                               [перехресне множення в N]
```
Оскільки `a · d ≥ 1` у множині натуральних чисел, візьмемо ціле число `n = b · c + 1`. Тоді:
```
n · (a · d) = (b · c + 1) · (a · d) ≥ (b · c + 1) · 1 = b · c + 1 > b · c
```
Отже, `n · x > y`. Архімедовість доведена. Це гарантує відсутність у `Q` нескінченно малих або нескінченно великих елементів.

### Всюди щільність поля Q

**Теорема:** Між будь-якими двома різними раціональними числами `x < y` існує нескінченна множина інших раціональних чисел.

*Доказ:* Середнє арифметичне `z = (x + y) / 2 = (x + y) · [(1, 2)]` належить `Q`.
З нерівності `x < y` додаванням `x` отримуємо `2x < x + y  ⇒  x < (x + y)/2 = z`.
Додаванням `y` отримуємо `x + y < 2y  ⇒  z = (x + y)/2 < y`.
Отже, `x < z < y`. Рекурсивне застосування ділення відрізка навпіл породжує зліченну щільну підмножину раціональних точок на будь-якому інтервалі.

## 9. Топологічна неповнота поля Q та його поповнення

Попри щільність, поле `Q` має фундаментальний топологічний дефект: воно **не є повним** (містить "числові дірки").

**Теорема (Дедекіндова неповнота Q):** Множина `S = {x ∈ Q | x > 0 і x² < 2}` є непорожньою та обмеженою зверху в `Q`, але не має точної верхньої межі (супремуму) всередині `Q`.

*Доказ:* Множина `S` непорожня (оскільки `1 ∈ S`) і обмежена зверху числом 2 (якщо `x > 2`, то `x² > 4 > 2`, отже `x ∉ S`).
Припустимо від супротивного, що в `Q` існує раціональне число `s = p/q = sup(S)`. За законом трихотомії можливі три випадки:

1. Якщо `s² < 2`: розглянемо раціональне число `s' = s - (s² - 2)/(s + 2) = (2s + 2)/(s + 2)`.
Обчислимо різницю:
```
s' - s = (2 - s²) / (s + 2) > 0  ⇒  s' > s        [оскільки 2 - s² > 0]
```
Обчислимо квадрат `s'`:
```
s'² - 2 = ((2s + 2)/(s + 2))² - 2 = (4s² + 8s + 4 - 2s² - 8s - 8) / (s + 2)² = 2(s² - 2) / (s + 2)² < 0
```
Оскільки `s'² < 2`, маємо `s' ∈ S`. Але `s' > s`, що суперечить тому, що `s` є верхньою межею множини `S`.

2. Якщо `s² > 2`: аналогічно те саме число `s' = (2s + 2)/(s + 2)` дає `s' < s` та `s'² > 2`. Це означає, що `s'` є меншою верхньою межею для `S`, що суперечить тому, що `s` є найменшою верхньою межею (`sup`).

3. Якщо `s² = 2`: це вимагає існування раціонального числа `s = p/q` такого, що `p² = 2q²`, що неможливо за класичною теоремою Евкліда про ірраціональність квадратного кореня з 2.

Таким чином, супремум `sup(S)` не належить `Q`. Це строго доводить топологічну неповноту раціональних чисел та обґрунтовує необхідність побудови поля дійсних чисел `R`.

За знаменитою **теоремою Островського**, будь-яке нетривіальне нормування (абсолютне значення) на полі `Q` еквівалентне або стандартному архімедовому абсолютному значенню `|x|`, або p-адичному неархімедовому нормуванню `|x|_p = p^(-v_p(x))` для деякого простого числа `p`. Відповідно, поповнення поля `Q` за фундаментальними послідовностями Коші дає або поле дійсних чисел `R` (архімедів випадок), або поля p-адичних чисел `Q_p` (неархімедів випадок).

## 10. Характеристика поля Q та статус простого поля

Характеристика поля `char(F)` — це найменше додатне число `n`, для якого сума `n` одиниць дорівнює нулю, або `0`, якщо така сума ніколи не досягає нуля.

У полі `Q` для будь-якого `n ∈ N`:
```
n · e₁ = [(n, 1)] ≠ [(0, 1)]                      [оскільки n ≠ 0 у Z]
```
Отже, характеристика поля раціональних чисел дорівнює нулю: `char(Q) = 0`.

Звідси випливає фундаментальний алгебраїчний статус `Q`: поле раціональних чисел є **простим полем** (англ. *prime field*) характеристики 0. Будь-яке поле `F` нульової характеристики містить у собі єдине підполе, ізоморфне `Q`. Таким чином, поле `Q` є неподільною основою для всієї вищої алгебри та математичного аналізу.
