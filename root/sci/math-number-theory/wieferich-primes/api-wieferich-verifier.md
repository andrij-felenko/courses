# 📋 Інтерфейс бібліотеки та CLI інструменту пошуку кандидатів Віферіха

У цій вставці наведено вичерпну специфікацію програмного інтерфейсу (C/C++ API) та інструментарію командного рядка (CLI) для верифікації й високоефективного пошуку простих чисел Віферіха `wieferich_tool`. Бібліотека надає високопродуктивне C-сумісне ABI для інтеграції в розподілені обчислювальні системи, криптографічні тестові комплекси та математичні сервери аналізу чисел.

Інтерфейс забезпечує повний контроль над обчислювальними ресурсами, параметрами двійкового піднесення до степеня за модулями великого розміру, використанням 128-бітної арифметики, підсистемою Монтгомері та форматами експорту результатів.

## Архітектурний опис та гарантії потокобезпеки

Бібліотека побудована за принципом відсутності глобального змінюваного стану (stateless execution). Усі функції перевірки та обчислення часток є чистими (pure functions) або працюють виключно з явними контекстними структурами, наданими користувачем.

1. **Потокобезпека (Thread Safety):** Базові функції верифікації `wieferich_verify_prime` та обчислення частки `wieferich_compute_quotient` є повністю потокобезпечними (reentrant and thread-safe). Вони не записують дані у статичні буфери та можуть викликатися паралельно з довільної кількості робочих потоків без синхронізаційних блокувань.
2. **Керування пам'яттю:** Бібліотека не виконує прихованих динамічних виділень пам'яті (no implicit `malloc`) під час перевірки поодиноких чисел. Динамічна пам'ять виділяється лише у функціях пакетного пошуку за діапазоном `wieferich_search_range` для створення решета простих чисел, і користувач має можливість надати власний буфер.
3. **Апаратні вимоги:** Для забезпечення максимальної швидкодії бібліотека розрахована на 64-бітну архітектуру (x86_64 або AArch64) з підтримкою апаратної 128-бітної цілочисельної арифметики (`unsigned __int128`).

Контракт бібліотеки гарантує відсутність витоків пам'яті та коректну роботу в умовах жорстких обмежень на ресурси. Завдяки ізоляції стану кожна функція може використовуватись у високонавантажених обчислювальних демонах (daemons) та мікросервісах без ризику деградації продуктивності протягом довготривалих розрахунків.

### 2. `wieferich_result_t`

Структура детального результату перевірки одного простого числа:

:::tabs
```c
typedef struct {
    uint64_t            prime;          // Перевірене просте число p
    uint64_t            base;           // Основа порівняння a (за замовчуванням 2)
    uint64_t            remainder;      // Остачка (a^(p-1) mod p²)
    uint64_t            fermat_quotient;// Частка Віферіха: W_a(p) = ((a^(p-1)-1)/p) mod p
    bool                is_wieferich;   // Прапорець: true якщо remainder == 1
    double              execution_time; // Час обчислення в мікросекундах
} wieferich_result_t;
```
:::code api-wieferich-verifier/cpp/2-wieferich-result-t.cpp
:::

Поля структури описують повний математичний та обчислювальний стан перевірки:
- `prime`: Вхідне просте число `p`, для якого виконувалася обробка.
- `base`: Основа `a`, використана при двійковому піднесенні до степеня.
- `remainder`: Одержана остачка від ділення степеня `aᵖ⁻¹` на квадрат модуля `p²`. Для простих чисел Віферіха це значення точно дорівнює `1`.
- `fermat_quotient`: Значення частки Ферма-Віферіха `Wₐ(p) mod p`. Для простих чисел Віферіха це значення точно дорівнює `0`.
- `is_wieferich`: Булів прапорець для швидкої перевірки та фільтрації кандидатів без додаткових порівнянь.
- `execution_time`: Точний замір часу обчислення у мікросекундах, одержаний за допомогою високоточних таймерів системи для аналізу швидкодії та профілювання.

### 3. `wieferich_config_t`

Структура конфігурації пошукового модуля для пакетної обробки числового інтервалу:

:::tabs
```c
typedef struct {
    uint64_t            start_range;    // Початкове значення діапазону p (inclusive)
    uint64_t            end_range;      // Кінцеве значення діапазону p (inclusive)
    uint64_t            base;           // Основа піднесення до степеня (default: 2)
    uint32_t            num_threads;    // Кількість робочих потоків (0 = автовизначення)
    bool                use_montgomery; // Прапорець увімкнення арифметики Монтгомері
    bool                verbose;        // Детальний вивід прогресу в stdout
} wieferich_config_t;
```
:::code api-wieferich-verifier/cpp/3-wieferich-config-t.cpp
:::

Детальне розшифрування полів конфігурації:
- `start_range`: Початкове просте число числового інтервалу. Мінімально допустиме значення — 3.
- `end_range`: Кінцеве число інтервалу. Завжди має виконуватися умова `end_range >= start_range`.
- `base`: Основа порівняння. За замовчуванням дорівнює 2, але може бути вказана будь-яка основа `a >= 2` для перевірки узагальнених умов Віферіха-Міріманова.
- `num_threads`: Кількість паралельних потоків виконання. При значенні `0` бібліотека автоматично визначає кількість доступних фізичних та логічних ядер процесора через виклики ОС.
- `use_montgomery`: Увімкнення прискореного алгоритму Монтгомері, який замінює важкі операції ділення 128-бітних чисел на побітові зсуви.
- `verbose`: Прапорець трасування, який вмикає форматований вивід інформаційних повідомлень про перебіг пошуку в стандартний потік виводу.

## Функціональний інтерфейс C API та C++20 API

Нижче наведено сигнатури функцій API для C та ідіоматичних C++20 обгортань.

### 1. `wieferich_verify_prime`

Основна функція верифікації одного простого числа за вибраною основою.

:::tabs
```c
wieferich_status_t wieferich_verify_prime(
    uint64_t p,
    uint64_t base,
    wieferich_result_t* out_result
);
```
```cpp
namespace wieferich {

[[nodiscard]] status verify_prime(
    std::uint64_t prime,
    std::uint64_t base = 2,
    result* out_result = nullptr
) noexcept;

} // namespace wieferich
```
:::

- **Призначення:** Здійснює перевірку умови `baseᵖ⁻¹ ≡ 1 (mod p²)` для переданого числа `p`.
- **Вхідні параметри:**
  - `p`: Просте число для перевірки (`p > 2`). Якщо передано парне число або композитне число, функція повертає відповідний код помилки.
  - `base`: Основа порівняння (`base ≥ 2`).
  - `out_result`: Вказівник на структуру `wieferich_result_t`, у яку записуються детальні результати. Якщо вказівник дорівнює `NULL`, запис результатів пропускається, але функція повертає статус.
- **Повертає значення:**
  - `WIEFERICH_IS_PRIME_WIEFERICH` — число є простим Віферіха за основою `base`.
  - `WIEFERICH_IS_NON_WIEFERICH` — число є звичайним простим числом.
  - `WIEFERICH_ERROR_NOT_PRIME` — передане число не є простим.
  - `WIEFERICH_ERROR_NULL_POINTER` — передано некоректний вказівник.

### 2. `wieferich_search_range`

Функція високоефективного паралельного пошуку простих чисел Віферіха у заданому числовому інтервалі.

:::tabs
```c
wieferich_status_t wieferich_search_range(
    const wieferich_config_t* config,
    wieferich_result_t* out_results,
    size_t max_results,
    size_t* out_found_count
);
```
```cpp
namespace wieferich {

[[nodiscard]] std::pair<status, std::vector<result>> search_range(
    const config& cfg
);

} // namespace wieferich
```
:::

- **Призначення:** Багатопотокова перевірка всіх простих чисел у діапазоні `[start_range, end_range]`.
- **Вхідні параметри:**
  - `config`: Вказівник на заповнену структуру конфігурації.
  - `out_results`: Масив структур для збереження знайдених винятків.
  - `max_results`: Ємність масиву `out_results`.
  - `out_found_count`: Вказівник на змінну, куди буде записано загальну кількість знайдених чисел Віферіха.
- **Повертає значення:** `WIEFERICH_SUCCESS` при успішному виконанні або відповідний код помилки.

## Інтерфейс командного рядка (CLI)

Консольна утиліта `wieferich_tool` надає гнучкий інтерфейс для запуску пакетного пошуку, бенчмаркінгу та автоматизації обчислень у середовищах Linux/POSIX та Windows. Утиліта парсить параметри командного рядка, створює конфігураційні структури, запускає паралельні обчислювальні ядра та експортує результати у потрібний формат.

### Синтаксис командного рядка:

```bash
wieferich_tool [ПАРАМЕТРИ] --start <ПОЧАТОК> --end <КІНЕЦЬ>
```

### Детальний перелік прапорців та опцій:

За допомогою прапорців користувач може гнучко налаштовувати діапазони обчислень, кількість обчислювальних потоків та формати збереження результатів.

- `-s`, `--start` `UINT64`: Початок інтервалу перевірки простих чисел `p`. Значення за замовчуванням: `3`.
- `-e`, `--end` `UINT64`: Кінець інтервалу перевірки простих чисел `p`. Значення за замовчуванням: `1000000`.
- `-b`, `--base` `UINT64`: Основа `a` для конгруенції `aᵖ⁻¹ ≡ 1 (mod p²)`. Значення за замовчуванням: `2`.
- `-t`, `--threads` `UINT32`: Кількість паралельних робочих потоків. При значенні `0` використовується автовизначення ядер.
- `-m`, `--montgomery`: Увімкнути швидку арифметику Монтгомері для прискорення обчислень на 300%.
- `-j`, `--json` `ШЛЯХ`: Експортувати результати обчислень та профілювання у файл стандарту JSON.
- `-c`, `--csv` `ШЛЯХ`: Експортувати результати у табличний формат CSV.
- `-v`, `--verbose`: Виводити детальний прогрес обчислень у реальному часі.
- `-h`, `--help`: Показати розширену інструкцію користувача та довідку за прапорцями.

При використанні прапорця `--json` утиліта генерує структурований звіт, що містить повний метаконтекст обчислювальної сесії, включаючи версію компілятора, архітектуру процесора та параметри швидкодії:

  "environment": {
    "compiler": "GCC 13.2.0",
    "architecture": "x86_64",

    "simd_extensions": ["AVX2", "FMA"]
  },
  "search_config": {
    "start_range": 3,
    "end_range": 10000000,
    "base": 2,
    "threads": 16,
    "algorithm": "montgomery_128bit_exponentiation"
  },
  "performance_metrics": {
    "total_primes_tested": 664579,
    "elapsed_seconds": 0.184,
    "throughput_primes_per_sec": 3611842.39
  },
  "results": [
    {
      "prime": 1093,
      "base": 2,
      "remainder": 1,
      "fermat_quotient": 0,
      "is_wieferich": true,
      "execution_time_us": 0.12
    },
    {
      "prime": 3511,
      "base": 2,
      "remainder": 1,
      "fermat_quotient": 0,
      "is_wieferich": true,

    }

Файл звіту ділиться на три основні секції:
1. `environment`: Метадані системи, на якій виконувалися обчислення (тип процесора, версія компілятора, наявність апаратних SIMD-інструкцій).
2. `search_config` та `performance_metrics`: Параметри сесії та показники продуктивності (кількість перевірених простих чисел за секунду, загальний витрачений час).
3. `results`: Масив об'єктів для всіх знайдених простих чисел Віферіха з короткими замірами часу виконання для кожного з них.
