# Ортогональність характерів Діріхле: спектральна теорія та повні доведення

<preknowlist>

- [Групові структури](root:math-algebra/group-theory) — абелеві групи, гомоморфізми та факторгрупи.
- [Функція Ейлера](root:math-number-theory/euler-totient) — порядок групи приведених лишків.
</preknowlist>

Співвідношення ортогональності для характерів Діріхле становлять фундаментальну основу дискретного гармонічного аналізу на скінченних абелевих групах. Завдяки ортогональності характери Діріхле виступають точним скінченновимірним дискретним аналогом гармонік Фур'є `exp(i k x)` на неперервному колі або хвильових коливань у математичній фізиці. Вони дозволяють проектувати довільну арифметичну функцію на ортогональні спектральні компоненти з визначеною мультиплікативною симетрією щодо множення за модулем.

У класичній теорії чисел більшість арифметичних операцій мають адитивну природу (наприклад, належність до арифметичної прогресії `a + k·q` або розподіл простих чисел), тоді як мультиплікативна структура чисел диктується їхнім розкладом на прості множники. Ортогональність характерів створює точний міст між цими двома світами: вона перетворює адитивний індикатор класу залишків на суперпозицію повністю мультиплікативних функцій.

Нижче наведено вичерпні математичні виведення двох фундаментальних теорем ортогональності, властивостей двоїстої групи `Ĝ`, проекторів на підгрупи та класи суміжності, канонічного бідуального ізоморфізму (рефлексивності Понтрягіна), спектральної тотожності Планшереля–Парсеваля, теореми про групову мультиплікативну згортку, а також детально розібрані числові приклади для циклічних груп `(ℤ/5ℤ)*`, `(ℤ/7ℤ)*` та нециклічних груп `(ℤ/8ℤ)*`, `(ℤ/12ℤ)*`.

## 1. Попередні алгебраїчні леми та трансляційна інваріантність

Нехай `q ≥ 1` — натуральне число, `G = (ℤ/qℤ)*` — мультиплікативна група приведеної системи залишків за модулем `q`. Порядок цієї групи дорівнює значенню функції Ейлера `|G| = φ(q)`. Головним характером позначається `χ₀`, який набуває значення `1` для всіх `n ∈ G` та `0` для `gcd(n, q) > 1`.

З алгебраїчної точки зору характер Діріхле — це одновимірне комплексне матричне представлення групи `G`, тобто гомоморфізм `χ: G → ℂ*`. Оскільки розмірність представлення дорівнює 1, слід представлення (характер у сенсі теорії представлень Фробеніуса) тотожно збігається із самим значенням відображення.

Для будь-якого фіксованого елемента `g ∈ G` оператор лівого зсуву (групової трансляції) `L_g: G → G`, визначений формулою `L_g(x) = (g · x mod q)`, є бієктивним автоморфізмом множини `G`. Звідси випливає, що рівномірне підсумовування за всіма елементами групи є інваріантним щодо групового зсуву. Це є скінченновимірним дискретним аналогом інваріантності міри Хаара щодо інтегрування на топологічних групах: зсув аргументу на фіксований елемент групи не змінює загальної суми значень за всією групою.

### Лема 1 (Сумування значення характеру за всіма елементами групи)

Для довільного характеру Діріхле `χ (mod q)` сума його значень за всіма елементами приведеної системи залишків задовольняє точну рівність:

```
∑_{n ∈ G} χ(n) = φ(q),   якщо χ = χ₀
∑_{n ∈ G} χ(n) = 0,      якщо χ ≠ χ₀
```

*Доведення.*

1. **Випадок `χ = χ₀` (головний характер):**
За означенням головного характеру, `χ₀(n) = 1` для кожного з `φ(q)` елементів `n ∈ G`. Сума складається з `φ(q)` однакових доданків, кожен з яких дорівнює одиниці:

```
S = ∑_{n ∈ G} χ₀(n)
  = ∑_{n ∈ G} 1                                        [підстановка означення головного характеру χ₀(n) = 1]
  = φ(q)                                              [підсумовування одиниці φ(q) разів за порядком групи]
```

2. **Випадок `χ ≠ χ₀` (неголовний характер):**
Якщо характер `χ` не є тотожно рівним `χ₀`, то за визначенням існує принаймні один елемент `g ∈ G`, для якого значення характеру відмінне від одиниці: `χ(g) ≠ 1`.
Оскільки `G` є скінченною групою, а елемент `g` є оборотним за модулем `q`, відображення множення на `g` здійснює взаємно однозначну перестановку елементів групи `G`:

```
g · G = {g · n (mod q) ∣ n ∈ G} = G
```

Розглянемо вихідну суму `S = ∑_{n ∈ G} χ(n)` і помножимо її на комплексне число `χ(g)`:

```
χ(g) · S = χ(g) · ∑_{n ∈ G} χ(n)                       [домноження суми S на комплексний скаляр χ(g)]
         = ∑_{n ∈ G} χ(g) · χ(n)                      [дистрибутивність множення комплексних чисел]
         = ∑_{n ∈ G} χ(g · n)                         [повна мультиплікативність характеру: χ(a)·χ(b) = χ(ab)]
         = ∑_{m ∈ G} χ(m)                             [заміна змінної підсумовування m = g·n mod q; множина g·G = G]
         = S                                          [за початковим означенням суми S]
```

Ми одержали однорідне лінійне алгебраїчне рівняння:

```
χ(g) · S = S                                           [рівність після трансляційного перепідсумовування]
(χ(g) - 1) · S = 0                                     [перенесення S у ліву частину та винесення за дужки]
```

Оскільки за вибором елемента `g` маємо `χ(g) ≠ 1`, комплексна різниця `(χ(g) - 1)` є строго ненульовою: `(χ(g) - 1) ≠ 0`. Поділивши обидві частини рівності на це ненульове число, отримуємо:

```
S = 0                                                 [ділення на ненульовий множник (χ(g) - 1)]
```

Лему 1 повністю доведено.

---

### Лема 2 (Сумування значень усіх характерів на фіксованому елементі групи)

Нехай `Ĝ` — двоїста група всіх `φ(q)` характерів Діріхле за модулем `q` щодо операції поточкового множення `(χ₁ · χ₂)(n) = χ₁(n) · χ₂(n)`. Для будь-якого фіксованого елемента `n ∈ G` сума значень усіх характерів на цьому елементі дорівнює:

```
∑_{χ ∈ Ĝ} χ(n) = φ(q),   якщо n ≡ 1 (mod q)
∑_{χ ∈ Ĝ} χ(n) = 0,      якщо n ≢ 1 (mod q)
```

*Доведення.*

1. **Випадок `n ≡ 1 (mod q)` (одиничний елемент групи):**
За четвертою аксіомою нормування характеру Діріхле, будь-який характер на нейтральному елементі набуває значення `χ(1) = 1`. Оскільки всього в двоїстій групі існує `|Ĝ| = φ(q)` різних характерів, сума дорівнює:

```
T = ∑_{χ ∈ Ĝ} χ(1)
  = ∑_{χ ∈ Ĝ} 1                                        [підстановка аксіоми нормування χ(1) = 1 для кожного характеру]
  = φ(q)                                              [підсумовування одиниці |Ĝ| = φ(q) разів]
```

2. **Випадок `n ≢ 1 (mod q)` (неодиничний елемент):**
Якщо елемент `n` не збігається з нейтральним елементом групи `G`, то за структурною теоремою про розділення точок характерами скінченної абелевої групи існує такий характер `χ₁ ∈ Ĝ`, для якого `χ₁(n) ≠ 1`.
Оскільки `Ĝ` є скінченною абелевою групою, оператор поточкового домноження всіх характерів на фіксований характер `χ₁` здійснює бієктивний зсув (перестановку) елементів двоїстої групи `Ĝ` на саму себе:

```
χ₁ · Ĝ = {χ₁ · χ ∣ χ ∈ Ĝ} = Ĝ
```

Розглянемо суму `T = ∑_{χ ∈ Ĝ} χ(n)` і помножимо її на комплексне значення `χ₁(n)`:

```
χ₁(n) · T = χ₁(n) · ∑_{χ ∈ Ĝ} χ(n)                   [домноження суми T на комплексне число χ₁(n)]
          = ∑_{χ ∈ Ĝ} χ₁(n) · χ(n)                   [дистрибутивність множення комплексних чисел]
          = ∑_{χ ∈ Ĝ} (χ₁ · χ)(n)                    [означення групової операції множення характерів]
          = ∑_{ψ ∈ Ĝ} ψ(n)                           [заміна змінної ψ = χ₁·χ; множина χ₁·Ĝ збігається з Ĝ]
          = T                                         [за початковим означенням суми T]
```

Отримуємо лінійне рівняння:

```
(χ₁(n) - 1) · T = 0                                    [перенесення T у ліву частину та групування доданків]
```

Оскільки за вибором характеру `χ₁(n) ≠ 1`, різниця `(χ₁(n) - 1) ≠ 0`. Діленням на цей ненульовий скаляр одержуємо:

```
T = 0                                                 [ділення на ненульовий множник (χ₁(n) - 1)]
```

Лему 2 повністю доведено.

## 2. Перша теорема ортогональності (Ортогональність за рядками таблиці характерів)

Перша теорема ортогональності стверджує, що різні характери Діріхле є взаємно ортогональними функціями на множині елементів групи приведених лишків `G`. Геометрично це означає, що вектори значень характерів у просторі `ℂ^{φ(q)}` утворюють ортогональний базис.

**Теорема 1 (Ортогональність за елементами групи).**
Для будь-яких двох характерів `χ_a` та `χ_b` за модулем `q` їхній ермітів скалярний добуток за всіма елементами приведеної системи залишків дорівнює:

```
∑_{n ∈ G} χ_a(n) · χ̄_b(n) = φ(q) · δ_{a,b}
```

де `δ_{a,b}` — символ Кронекера (`δ_{a,b} = 1`, якщо `χ_a = χ_b`, і `δ_{a,b} = 0`, якщо `χ_a ≠ χ_b`).

*Доведення.*

Оскільки для будь-якого `n ∈ G` значення характеру є комплексним коренем з одиниці, його модуль строго дорівнює 1: `|χ_b(n)| = 1`.
Тому комплексно спряжене число збігається з мультиплікативним оберненим значенням:

```
χ̄_b(n) = (χ_b(n))⁻¹ = χ_b⁻¹(n)                         [комплексне спряження унітарного числа на одиничному колі]
```

Завдяки поточковій мультиплікативності двоїстої групи, добуток значень `χ_a(n) · χ̄_b(n)` є значенням єдиного складеного характеру `ψ = χ_a · χ̄_b`:

```
χ_a(n) · χ̄_b(n) = (χ_a · χ̄_b)(n)                      [властивість групового множення характерів]
```

Підставимо складений характер `ψ` у вихідну суму скалярного добутку:

```
S_{a,b} = ∑_{n ∈ G} χ_a(n) · χ̄_b(n)
        = ∑_{n ∈ G} (χ_a · χ̄_b)(n)                     [згортання добутку значень у характер ψ = χ_a · χ̄_b]
```

Тепер застосуємо результат Леми 1 до складеного характеру `ψ`:

1. **Якщо `χ_a = χ_b` (характери збігаються):**
Тоді складений характер є добутком характеру на свій обернений: `ψ = χ_a · χ̄_a = χ₀` — тобто головним характером. За Лемою 1:

```
S_{a,b} = ∑_{n ∈ G} χ₀(n)
        = φ(q)                                         [за Лемою 1 для головного характеру χ₀]
```

2. **Якщо `χ_a ≠ χ_b` (характери різні):**
Тоді складений характер `ψ = χ_a · χ̄_b` не є нейтральним елементом двоїстої групи (`ψ ≠ χ₀`), оскільки домноженням на `χ_b` ми отримали б `χ_a = χ_b`, що суперечить умові. За Лемою 1:

```
S_{a,b} = ∑_{n ∈ G} ψ(n)
        = 0                                            [за Лемою 1 для неголовного характеру ψ ≠ χ₀]
```

Об'єднуючи обидва випадки через дельта-символ Кронекера, одержуємо:

```
∑_{n ∈ G} χ_a(n) · χ̄_b(n) = φ(q) · δ_{a,b}
```

Теорему 1 повністю доведено.

### Матрична інтерпретація та унітарність

Нехай `U` — матриця характерів розміру `φ(q) × φ(q)`, елементи якої нормовані коефіцієнтом `1 / √φ(q)`:

```
U_{a, n} = (1 / √φ(q)) · χ_a(n),   де a ∈ {1, ..., φ(q)}, n ∈ G
```

Тоді перша теорема ортогональності еквівалентна матричній рівності:

```
U · U* = I
```

де `U*` — ермітово-спряжена матриця (`U*_{n, a} = (1 / √φ(q)) · χ̄_a(n)`), а `I` — одинична матриця розміру `φ(q) × φ(q)`.
Це доводить, що нормована матриця характерів Діріхле є **унітарною матрицею**. Її рядки утворюють ортонормований базис у просторі функцій на групі.

## 3. Друга теорема ортогональності (Ортогональність за стовпчиками таблиці)

Друга теорема ортогональності встановлює дуальну ортогональність за стовпчиками матриці характерів (тобто за характерами двоїстої групи `Ĝ`). Вона гарантує, що для двох різних класів залишків сума значень усіх характерів повністю взаємно гаситься (деструктивна інтерференція фаз).

**Теорема 2 (Ортогональність за двоїстою групою).**
Для двох довільних цілих чисел `m` та `n`, взаємно простих із `q`, сума добутків значень усіх `φ(q)` характерів Діріхле дорівнює:

```
∑_{χ ∈ Ĝ} χ(m) · χ̄(n) = φ(q) · δ_{m ≡ n (mod q)}
```

де `δ_{m ≡ n (mod q)} = 1`, якщо `m ≡ n (mod q)`, і `0`, якщо `m ≢ n (mod q)`.

*Доведення.*

Оскільки `gcd(n, q) = 1`, у скінченній групі `G` існує єдиний мультиплікативно обернений залишок `n⁻¹` такий, що `n · n⁻¹ ≡ 1 (mod q)`.
Враховуючи унітарність значення на одиничному колі:

```
χ̄(n) = χ(n⁻¹)                                         [комплексне спряження дорівнює значенню на оберненому елементі]
```

Завдяки повній мультиплікативності характеру `χ(a) · χ(b) = χ(a · b)`:

```
χ(m) · χ̄(n) = χ(m) · χ(n⁻¹)
            = χ(m · n⁻¹)                              [мультиплікативність характеру на добутку елементів m · n⁻¹]
```

Підставимо цей вираз у суму за всіма характерами `T_{m,n}`:

```
T_{m,n} = ∑_{χ ∈ Ĝ} χ(m) · χ̄(n)
        = ∑_{χ ∈ Ĝ} χ(m · n⁻¹)                        [підстановка мультиплікативного згортання χ(m · n⁻¹)]
```

Позначимо залишок `k = (m · n⁻¹ mod q) ∈ G`. Застосуємо результат Леми 2 до елемента `k`:

1. **Якщо `m ≡ n (mod q)`:**
Помноживши обидві частини порівняння на `n⁻¹`, отримуємо `k = m · n⁻¹ ≡ n · n⁻¹ ≡ 1 (mod q)`.
Застосовуючи Лему 2 для одиничного елемента:

```
T_{m,n} = ∑_{χ ∈ Ĝ} χ(1)
        = φ(q)                                         [за Лемою 2: сума значень усіх характерів на 1 дорівнює |Ĝ|]
```

2. **Якщо `m ≢ n (mod q)`:**
Елемент `k = m · n⁻¹ mod q` не є одиницею групи (`k ≢ 1 (mod q)`), оскільки домноженням рівності `k ≡ 1` на `n` ми дістали б `m ≡ n (mod q)`, що суперечить вихідному припущенню.
Застосовуючи Лему 2 для неодиничного елемента:

```
T_{m,n} = ∑_{χ ∈ Ĝ} χ(k)
        = 0                                            [за Лемою 2: сума за всіма характерами на k ≢ 1 дорівнює нулю]
```

Поєднуючи обидва випадки, одержуємо:

```
∑_{χ ∈ Ĝ} χ(m) · χ̄(n) = φ(q) · δ_{m ≡ n (mod q)}
```

Теорему 2 повністю доведено.

В термінах унітарної матриці `U` Теорема 2 відповідає умові повноти:

```
U* · U = I
```

яка стверджує, що стовпчики матриці `U` утворюють ортонормований базис у просторі `ℂ^{φ(q)}`.

## 4. Спектральний розклад дельта-функції (Фур'є-проектор Діріхле)

Найважливішим наслідком другої теореми ортогональності є можливість точного аналітичного подання розривного фільтра належності до класу залишків як лінійної комбінації повністю мультиплікативних функцій.

**Наслідок (Формула дельта-проектора Діріхле).**
Для будь-якого фіксованого залишку `a ∈ G` індикаторна функція `δ(n ≡ a mod q)` на множині `G` точно подається у вигляді:

```
δ(n ≡ a mod q) = (1 / φ(q)) · ∑_{χ ∈ Ĝ} χ̄(a) · χ(n)
```

*Доведення.*

Покладемо в тотожності Теореми 2 значення `m = n` та `n = a`:

```
∑_{χ ∈ Ĝ} χ(n) · χ̄(a) = φ(q) · δ_{n ≡ a (mod q)}       [застосування Теореми 2 для пари елементів n та a]
```

Враховуючи комутативність множення комплексних чисел `χ(n) · χ̄(a) = χ̄(a) · χ(n)` та ділячи обидві частини рівності на ненульовий скаляр `φ(q)`, одержуємо:

```
δ(n ≡ a (mod q)) = (1 / φ(q)) · ∑_{χ ∈ Ĝ} χ̄(a) · χ(n)  [ділення обох частин тотожності на порядок групи φ(q)]
```

Ця формула є спектральним розкладом дельта-функції Дірака на скінченній абелевій групі залишків.

### Властивості спектрального проектора `P_a`

Визначимо лінійний оператор проектування `P_a: L²(G) → L²(G)`:

```
(P_a f)(n) = δ(n ≡ a mod q) · f(n)
```

Оператор `P_a` задовольняє всі аксіоми ортогонального проектора у гільбертовому просторі:
1. **Ідемпотентність:** `P_a² = P_a` (повторне проектування не змінює результат).
2. **Самоспряженість:** `P_a* = P_a`.
3. **Ортогональність різних проекторів:** `P_a · P_b = 0` для всіх `a ≢ b (mod q)`.
4. **Розклад одиничного оператора:** `∑_{a ∈ G} P_a = I`.

Це перетворює простір функцій `L²(G)` у пряму ортогональну суму одновимірних підпросторів, кожен з яких відповідає фіксованому класу залишків.

## 5. Структура двоїстої групи, ізоморфізм Ĝ ≅ G та бідуальність

Для завершення строгості побудови теорії необхідно довести, що двоїста група `Ĝ` має порядок `φ(q)`, є ізоморфною самій групі `G`, а друга двоїста група `Ĝ̂` канонічно ізоморфна вихідній групі `G`.

### 1. Циклічна група `C_d`

Нехай `G = ⟨g⟩` — циклічна група порядку `d`, згенерована елементом `g` (`gᵈ = 1`).
Будь-який характер `χ: G → ℂ*` є гомоморфізмом, тому значення `χ(g)` повністю однозначно визначає характер на всіх елементах:

```
χ(gᵐ) = (χ(g))ᵐ,   для всіх m ∈ ℤ
```

З умови `gᵈ = 1` та аксіоми нормування випливає:

```
(χ(g))ᵈ = χ(gᵈ)                                        [мультиплікативність гомоморфізму на степені gᵈ]
        = χ(1)                                         [підстановка рівності gᵈ = 1]
        = 1                                            [аксіома нормування характеру на нейтральному елементі]
```

Отже, значення `χ(g)` зобов'язане бути одним із `d` комплексних коренів `d`-го степеня з одиниці:

```
ω_k = exp(2 π i · k / d),   де k ∈ {0, 1, ..., d - 1}
```

Кожен вибір індексу `k` задає коректний та відмінний характер `χₖ(gᵐ) = exp(2 π i · k · m / d)`.
Групова операція поточкового множення двох характерів `χ_a` та `χ_b` відповідає додаванню їхніх індексів за модулем `d`:

```
(χ_a · χ_b)(g) = χ_a(g) · χ_b(g)
               = exp(2 π i · a / d) · exp(2 π i · b / d) [підстановка значень на твірному елементі g]
               = exp(2 π i · (a + b) / d)              [властивість експоненти: сума показників]
               = χ_{(a + b mod d)}(g)                  [редукція показника за періодом d]
```

Отже, відображення `k mod d ⟼ χₖ` є строгим ізоморфізмом абелевих груп:

```
(C_d)^̂ ≅ C_d
```

Зокрема, число характерів циклічної групи в точності дорівнює її порядку `|(C_d)^̂| = d = |C_d|`.

### 2. Загальна скінченна абелева група

За фундаментальною теоремою про структуру скінченних абелевих груп, будь-яка скінченна абелева група `G` розкладається у прямий добуток примарних циклічних підгруп:

```
G ≅ C_{d₁} × C_{d₂} × ... × C_{d_r}
```

Двоїста група прямого добутку ізоморфна прямому добутку двоїстих груп компонент:

```
Ĝ = (C_{d₁} × C_{d₂} × ... × C_{d_r})^̂
  ≅ (C_{d₁})^̂ × (C_{d₂})^̂ × ... × (C_{d_r})^̂           [дистрибутивність двоїстості щодо прямих добутків груп]
  ≅ C_{d₁} × C_{d₂} × ... × C_{d_r}                    [ізоморфізм (C_d)^̂ ≅ C_d для кожної циклічної компоненти]
  ≅ G                                                  [за вихідним канонічним розкладом групи G]
```

Звідси негайно випливає точна рівність порядків груп:

```
|Ĝ| = |C_{d₁}| · |C_{d₂}| · ... · |C_{d_r}| = |G| = φ(q)
```

### 3. Бідуальний ізоморфізм та рефлексивність Понтрягіна

Ізоморфізм `Ĝ ≅ G` залежить від вибору системи генераторів `{g₁, ..., g_r}` і тому не є канонічним. Проте ізоморфізм між групою `G` та її **другою двоїстою групою** (бідуалом) `Ĝ̂ = (Ĝ)^̂` є **канонічним (природним)**.

Визначимо відображення обчислення значення (evaluation map) `Φ: G → Ĝ̂`:

```
(Φ(g))(χ) = χ(g),   для всіх g ∈ G, χ ∈ Ĝ
```

Перевіримо, що `Φ` є гомоморфізмом груп:

```
(Φ(g₁ · g₂))(χ) = χ(g₁ · g₂)
                = χ(g₁) · χ(g₂)                        [мультиплікативність характеру χ на добутку g₁·g₂]
                = (Φ(g₁))(χ) · (Φ(g₂))(χ)              [підстановка означення відображення Φ]
                = ((Φ(g₁) · Φ(g₂)))(χ)                 [означення операції множення у бідуальній групі Ĝ̂]
```

Знайдемо ядро гомоморфізму `Ker(Φ)`:
Якщо `g ∈ Ker(Φ)`, то `(Φ(g))(χ) = χ(g) = 1` для всіх `χ ∈ Ĝ`.
За Лемою 2, якщо `g ≠ 1`, то існує характер `χ₁`, для якого `χ₁(g) ≠ 1`.
Отже, єдиним елементом ядра є нейтральний елемент `g = 1`, тобто `Ker(Φ) = {1}`.
Оскільки ядро тривіальне, гомоморфізм `Φ` є ін'єктивним. Враховуючи рівність скінченних порядків `|Ĝ̂| = |Ĝ| = |G|`, будь-яка ін'єкція між множинами однакової скінченної потужності є бієкцією.

Отже, відображення `Φ` встановлює канонічний природний ізоморфізм (рефлексивність):

```
G ≅ Ĝ̂
```

Це свідчить про те, що група `G` та двоїста група `Ĝ` відіграють абсолютно симетричну, взаємозамінну роль у гармонічному аналізі.

### 4. Ортогональність на підгрупах та анігілятори

Нехай `H ≤ G` — довільна підгрупа групи залишків `G`. Визначимо **анігілятор підгрупи** `H^⊥ ≤ Ĝ` (підгрупу всіх характерів, які набувають значення 1 на кожному елементі `H`):

```
H^⊥ = {χ ∈ Ĝ ∣ χ(h) = 1   для всіх h ∈ H}
```

Тоді узагальнена теорема ортогональності на підгрупі стверджує:

```
∑_{h ∈ H} χ(h) = |H|,   якщо χ ∈ H^⊥
∑_{h ∈ H} χ(h) = 0,     якщо χ ∉ H^⊥
```

Факторгрупа `G/H` має двоїсту групу, канонічно ізоморфну анігілятору:

```
(G/H)^̂ ≅ H^⊥
```

Зокрема, якщо обрати підгрупу квадратичних залишків `H = {x² mod p ∣ x ∈ (ℤ/pℤ)*}`, порядок підгрупи дорівнює `(p - 1) / 2`. Анігілятор `H^⊥` складається рівно з двох характерів: головного характеру `χ₀` та символу Лежандра `χ(n) = (n/p)`. Це пояснює, чому квадратичні залишки виділяються за допомогою суми двох характерів: головного та квадратичного.

## 6. Спектральний аналіз Фур'є та тотожність Парсеваля на скінченній групі

Розглянемо комплексний гільбертів простір функцій `L²(G) = {f: G → ℂ}` розмірності `dim L²(G) = |G| = φ(q)`.
Введемо у цьому просторі ермітів скалярний добуток для двох функцій `f, g ∈ L²(G)`:

```
⟨f, g⟩ = (1 / φ(q)) · ∑_{n ∈ G} f(n) · ḡ(n)
```

За першою теоремою ортогональності сімейство характерів `{χ | χ ∈ Ĝ}` утворює ортонормований базис у просторі `L²(G)`:

```
⟨χ_a, χ_b⟩ = (1 / φ(q)) · ∑_{n ∈ G} χ_a(n) · χ̄_b(n) = δ_{a,b}
```

### 1. Пряме та обернене дискретне перетворення Фур'є на групі `G`

Будь-яка функція `f ∈ L²(G)` однозначно розкладається за ортонормованим базисом характерів:

```
f(n) = ∑_{χ ∈ Ĝ} f̂(χ) · χ(n)
```

де спектральні коефіцієнти Фур'є `f̂(χ)` обчислюються як ермітові проекції на базисні вектори:

```
f̂(χ) = ⟨f, χ⟩ = (1 / φ(q)) · ∑_{n ∈ G} f(n) · χ̄(n)
```

*Доведення формули обернення Фур'є.*
Підставимо вираз коефіцієнта `f̂(χ)` у формулу розкладу:

```
∑_{χ ∈ Ĝ} f̂(χ) · χ(n) = ∑_{χ ∈ Ĝ} [ (1 / φ(q)) · ∑_{m ∈ G} f(m) · χ̄(m) ] · χ(n) [підстановка коефіцієнта f̂(χ)]
                      = ∑_{m ∈ G} f(m) · [ (1 / φ(q)) · ∑_{χ ∈ Ĝ} χ(n) · χ̄(m) ]   [зміна порядку підсумовування скінченних сум]
                      = ∑_{m ∈ G} f(m) · δ_{n ≡ m (mod q)}                     [застосування другої теореми ортогональності]
                      = f(n)                                                   [згортання за дельта-символом Кронекера при m = n]
```

### 2. Спектральна тотожність Планшереля–Парсеваля (збереження енергії сигналу)

Для будь-якої функції `f ∈ L²(G)` норма сигналу у часовому просторі точно збігається з нормою у спектральному просторі коефіцієнтів:

```
∑_{n ∈ G} |f(n)|² = φ(q) · ∑_{χ ∈ Ĝ} |f̂(χ)|²
```

*Доведення.*
Обчислимо квадрат норми `‖f‖² = ⟨f, f⟩`:

```
‖f‖² = ⟨f, f⟩
     = ⟨ ∑_{χ_a ∈ Ĝ} f̂(χ_a) · χ_a,  ∑_{χ_b ∈ Ĝ} f̂(χ_b) · χ_b ⟩             [підстановка розкладу Фур'є для f]
     = ∑_{χ_a ∈ Ĝ} ∑_{χ_b ∈ Ĝ} f̂(χ_a) · conj(f̂(χ_b)) · ⟨χ_a, χ_b⟩          [білінійність та антилінійність скалярного добутку]
     = ∑_{χ_a ∈ Ĝ} ∑_{χ_b ∈ Ĝ} f̂(χ_a) · conj(f̂(χ_b)) · δ_{a,b}              [ортонормованість базису характерів: ⟨χ_a, χ_b⟩ = δ_{a,b}]
     = ∑_{χ ∈ Ĝ} |f̂(χ)|²                                                     [згортання подвійної суми за дельта-символом δ_{a,b}]
```

З іншого боку, за явним означенням скалярного добутку:

```
‖f‖² = (1 / φ(q)) · ∑_{n ∈ G} |f(n)|²
```

Прирівнюючи обидва вирази та домножаючи на порядок групи `φ(q)`, одержуємо тотожність Парсеваля:

```
∑_{n ∈ G} |f(n)|² = φ(q) · ∑_{χ ∈ Ĝ} |f̂(χ)|²
```

### 3. Групова мультиплікативна згортка та алгоритм NTT

Для двох довільних функцій `f, g ∈ L²(G)` їхня групова мультиплікативна згортка `f ∗ g` визначається формулою:

```
(f ∗ g)(n) = ∑_{m ∈ G} f(m) · g(m⁻¹ · n mod q)
```

**Теорема про згортку.** Спектральні коефіцієнти Фур'є групової згортки є поточковим добутком коефіцієнтів співмножників, масштабованим на порядок групи:

```
(f ∗ g)^̂(χ) = φ(q) · f̂(χ) · ĝ(χ)
```

*Доведення.*
Обчислимо коефіцієнт Фур'є для згортки за означенням:

```
(f ∗ g)^̂(χ) = (1 / φ(q)) · ∑_{n ∈ G} (f ∗ g)(n) · χ̄(n)                        [означення коефіцієнта Фур'є для функції f ∗ g]
            = (1 / φ(q)) · ∑_{n ∈ G} [ ∑_{m ∈ G} f(m) · g(m⁻¹ · n) ] · χ̄(n)     [підстановка формули мультиплікативної згортки]
            = (1 / φ(q)) · ∑_{m ∈ G} f(m) · ∑_{n ∈ G} g(m⁻¹ · n) · χ̄(n)         [перестановка порядку скінченного підсумовування]
```

Зробимо заміну змінної у внутрішній сумі: нехай `k = (m⁻¹ · n mod q) ∈ G`. Тоді `n = (m · k mod q)`.
Враховуючи мультиплікативність спряженого характеру `χ̄(m · k) = χ̄(m) · χ̄(k)`:

```
(f ∗ g)^̂(χ) = (1 / φ(q)) · ∑_{m ∈ G} f(m) · χ̄(m) · ∑_{k ∈ G} g(k) · χ̄(k)     [підстановка n = m·k та факторизація χ̄(m·k) = χ̄(m)·χ̄(k)]
            = φ(q) · [ (1 / φ(q)) · ∑_{m ∈ G} f(m) · χ̄(m) ] · [ (1 / φ(q)) · ∑_{k ∈ G} g(k) · χ̄(k) ] [розподіл множників скалярів]
            = φ(q) · f̂(χ) · ĝ(χ)                                              [підстановка означень коефіцієнтів f̂(χ) та ĝ(χ)]
```

Ця теорема є математичною основою швидкого теоретико-числового перетворення Фур'є (Number Theoretic Transform, NTT). На відміну від класичного алгоритму швидкого перетворення Фур'є над полем комплексних чисел `ℂ`, де неминуче накопичуються похибки округлення чисел з рухомою комою, алгоритм NTT виконується в точній модульній арифметиці над скінченними полями або кільцями залишків `ℤ/qℤ`. Завдяки цьому обчислення згортки векторів або множення великих поліномів відбувається абсолютно точно та за оптимальний час `O(N log N)`, що робить алгоритм NTT незамінним у сучасній постквантовій криптографії на ґратках (зокрема у криптографічних протоколах Kyber та Dilithium).

## 7. Практичні розібрані числові приклади

Нижче наведено вичерпний покроковий числовий розрахунок для чотирьох показових випадків груп залишків: циклічних груп простого порядку, груп з комплексними характером та нециклічних груп складеного модуля.

### Приклад 1. Циклічна група `(ℤ/5ℤ)*` (`q = 5`, `φ(5) = 4`)

Група `G = {1, 2, 3, 4}` є циклічною порядку 4 з первісним коренем `g = 2`.
Степені генератора: `2⁰ ≡ 1`, `2¹ ≡ 2`, `2² ≡ 4`, `2³ ≡ 3 (mod 5)`.
Корені 4-го степеня з одиниці: `ω = exp(2 π i / 4) = i`.
Характери задаються формулою `χₖ(2ʲ) = i^{k · j}`:

| Характер | `n = 1` (`2⁰`) | `n = 2` (`2¹`) | `n = 4` (`2²`) | `n = 3` (`2³`) | Тип характеру |
| :--- | :---: | :---: | :---: | :---: | :--- |
| `χ₀` | `1` | `1` | `1` | `1` | Головний (тривіальний) |
| `χ₁` | `1` | `i` | `-1` | `-i` | Комплексний |
| `χ₂` | `1` | `-1` | `1` | `-1` | Дійсний (символ Лежандра `(n/5)`) |
| `χ₃` | `1` | `-i` | `-1` | `i` | Комплексний (спряжений до `χ₁`) |

Зверніть увагу: на комплексній площині значення комплексного характеру `χ₁` розташовані у вершинах правильного квадрата `1, i, -1, -i`. Їхня векторна сума дорівнює нулю в силу центральної симетрії.

**Перевірка Теореми 1 (ортогональність рядків `χ₁` та `χ₃`):**

```
⟨χ₁, χ₃⟩ = ∑_{n=1}^4 χ₁(n) · χ̄₃(n)
         = (1 · 1) + (i · i) + (-1 · -1) + (-i · -i)   [підстановка значень та комплексного спряження χ̄₃ = χ₁]
         = 1 + (-1) + 1 + (-1)                         [обчислення степенів уявної одиниці i² = -1]
         = 0                                           [ортогональність підтверджено]
```

**Перевірка норми характеру `χ₁`:**

```
⟨χ₁, χ₁⟩ = ∑_{n=1}^4 χ₁(n) · χ̄₁(n)
         = |1|² + |i|² + |-1|² + |-i|²                 [сума квадратів модулів значень]
         = 1 + 1 + 1 + 1                               [модуль кожного кореня з одиниці дорівнює 1]
         = 4 = φ(5)                                    [нормування підтверджено]
```

**Перевірка Теореми 2 (ортогональність стовпчиків `n = 2` та `n = 3`):**

```
T_{2,3} = ∑_{k=0}^3 χ_k(2) · χ̄_k(3)
        = (1 · 1) + (i · i) + (-1 · -1) + (-i · -i)     [підстановка значень характерів на n=2 та n=3]
        = 1 + (-1) + 1 + (-1)                          [обчислення квадратів i² = -1]
        = 0                                            [стовпчики ортогональні]
```

**Перевірка відновлення дельта-функції `δ(n ≡ 3 mod 5)` при `n = 3`:**

```
δ(3 ≡ 3 mod 5) = (1/4) · ∑_{k=0}^3 χ̄_k(3) · χ_k(3)
               = (1/4) · [ (1·1) + (i·-i) + (-1·-1) + (-i·i) ] [підстановка значень для k=0,1,2,3]
               = (1/4) · [ 1 + 1 + 1 + 1 ]             [обчислення добутків спряжених величин |χ(3)|² = 1]
               = 1                                     [дельта-функцію точно відновлено]
```

---

### Приклад 2. Циклічна група `(ℤ/7ℤ)*` (`q = 7`, `φ(7) = 6`)

Група `G = {1, 2, 3, 4, 5, 6}` є циклічною порядку 6 з первісним коренем `g = 3`.
Степені генератора: `3⁰ ≡ 1`, `3¹ ≡ 3`, `3² ≡ 2`, `3³ ≡ 6`, `3⁴ ≡ 4`, `3⁵ ≡ 5 (mod 7)`.
Корені 6-го степеня з одиниці: `ω = exp(2 π i / 6) = 1/2 + i √3/2`.
Характер `χ₃` (квадратичний характер) набуває значень `χ₃(3ʲ) = ω^{3j} = (-1)ʲ`:
Значення `χ₃` на елементах `{1, 2, 3, 4, 5, 6}` дорівнюють відповідно `[1, 1, -1, 1, -1, -1]` (символ Лежандра `(n/7)`).

Перевіримо умову нульової суми для цього квадратичного характеру `χ₃`:

```
∑_{n=1}^6 χ₃(n) = 1 + 1 + (-1) + 1 + (-1) + (-1)        [підстановка значень символу Лежандра (n/7)]
                = 3 - 3                                [групування трьох лишків та трьох нелишків]
                = 0                                    [сума значень неголовного характеру дорівнює нулю]
```

### Приклад 3. Нециклічна група `(ℤ/8ℤ)*` (`q = 8`, `φ(8) = 4`)

Приведена система залишків `G = {1, 3, 5, 7}`. Кожен елемент задовольняє `n² ≡ 1 (mod 8)`.
Група ізоморфна прямому добутку `(ℤ/8ℤ)* ≅ C₂ × C₂` (четвірна група Клейна `V₄`).
Усі 4 характери є дійсними, тому їхня таблиця є класичною матрицею Адамара порядку 4:

| Характер | `n = 1` | `n = 3` | `n = 5` | `n = 7` | Формульний вираз |
| :--- | :---: | :---: | :---: | :---: | :--- |
| `χ₀` | `1` | `1` | `1` | `1` | Головний |
| `χ₁` | `1` | `-1` | `1` | `-1` | `(-1)^{(n²-1)/8 mod 2}` (символ `(2/n)`) |
| `χ₂` | `1` | `1` | `-1` | `-1` | `(-1)^{(n-1)/2 mod 2}` (символ `(-1/n)`) |
| `χ₃` | `1` | `-1` | `-1` | `1` | `χ₁ · χ₂` (символ `(-2/n)`) |

Матриці Адамара такого вигляду використовуються в алгоритмах кодування з прямим розширенням спектра (CDMA), квантових логічних вентилях Адамара та швидкому перетворенні Уолша–Адамара. Вони володіють максимальною енергетичною стійкістю до шуму.

**Перевірка Теореми 1 для `χ₁` та `χ₂`:**

```
⟨χ₁, χ₂⟩ = (1 · 1) + (-1 · 1) + (1 · -1) + (-1 · -1)   [скалярний добуток дійсних рядків таблиці]
         = 1 - 1 - 1 + 1                               [розкриття добутків знаків]
         = 0                                           [ортогональність підтверджено]
```

**Перевірка Теореми 2 для стовпчиків `n = 3` та `n = 5`:**

```
∑_{k=0}^3 χ_k(3) · χ_k(5) = (1 · 1) + (-1 · 1) + (1 · -1) + (-1 · -1) [добуток значень у стовпчиках 3 та 5]
                          = 1 - 1 - 1 + 1              [розкриття знаків]
                          = 0                          [стовпчики ортогональні]
```

### Приклад 4. Складений модуль `q = 12` (`φ(12) = 4`)

Приведена система залишків: `G = {1, 5, 7, 11}`.
Група `(ℤ/12ℤ)* ≅ (ℤ/4ℤ)* × (ℤ/3ℤ)* ≅ C₂ × C₂`.
Усі 4 характери є дійсними:

| Характер | `n = 1` | `n = 5` | `n = 7` | `n = 11` | Провідник `d` | Статус |
| :--- | :---: | :---: | :---: | :---: | :---: | :--- |
| `χ₀` | `1` | `1` | `1` | `1` | 1 | Індукований (головний) |
| `χ₁` | `1` | `1` | `-1` | `-1` | 3 | Індукований з mod 3 (символ `(n/3)`) |
| `χ₂` | `1` | `-1` | `-1` | `1` | 4 | Індукований з mod 4 (символ `(-1/n)`) |
| `χ₃` | `1` | `-1` | `1` | `-1` | 12 | **Первісний характер** за модулем 12 |

Цей приклад демонструє взаємодію між провідниками (кондукторами) характерів: первісний характер `χ₃` не зводиться до жодного меншого модуля і є строго ортогональним як до головного характеру, так і до індукованих характерів `χ₁` та `χ₂`.

**Перевірка ортогональності первісного характеру `χ₃` до індукованого `χ₁`:**

```
⟨χ₃, χ₁⟩ = (1 · 1) + (-1 · 1) + (1 · -1) + (-1 · -1)   [підстановка значень характерів]
         = 1 - 1 - 1 + 1                               [розкриття добутків]
         = 0                                           [ортогональність підтверджено]
```

Всі чотири наведені числові приклади повністю ілюструють універсальність абстрактної спектральної теорії та точність співвідношень ортогональності на довільних скінченних абелевих групах залишків.

## 8. Застосування до спектрального розкладу зважених сум простих чисел Чебишова

Вершиною застосування ортогональності характерів Діріхле в аналітичній теорії чисел є точний спектральний розклад функції Чебишова `ψ(x; q, a)`, яка підраховує логарифми простих чисел та їхніх степенів у заданій прогресії:

```
ψ(x; q, a) = ∑_{n ≤ x, n ≡ a (mod q)} Λ(n)
```

де `Λ(n)` — арифметична функція фон Мангольдта (`Λ(pᵐ) = ln p` для простих чисел `p` і цілих `m ≥ 1`, та `Λ(n) = 0` в інших випадках).

Підставимо у визначення формулу спектрального дельта-проектора Діріхле (розділ 4):

```
ψ(x; q, a) = ∑_{n ≤ x} Λ(n) · δ(n ≡ a (mod q))
           = ∑_{n ≤ x} Λ(n) · ( (1 / φ(q)) · ∑_{χ ∈ Ĝ} χ̄(a) · χ(n) )          [підстановка спектральної дельта-функції]
           = (1 / φ(q)) · ∑_{χ ∈ Ĝ} χ̄(a) · ( ∑_{n ≤ x} χ(n) · Λ(n) )          [перестановка порядку сумування скінченної кількості доданків]
           = (1 / φ(q)) · ∑_{χ ∈ Ĝ} χ̄(a) · ψ(x, χ)                            [введення зваженої функції Чебишова ψ(x, χ)]
```

де `ψ(x, χ) = ∑_{n ≤ x} χ(n) · Λ(n)` є зваженою сумою функції фон Мангольдта за характером `χ`.

Тепер виділимо внесок головного характеру `χ₀` та неголовних характерів:

1. **Внесок головного характеру `χ₀`:**
   Оскільки `χ₀(n) = 1` для всіх `n`, взаємно простих із `q`, і `0` для `gcd(n, q) > 1`, сума `ψ(x, χ₀)` відрізняється від повної безумовної функції Чебишова `ψ(x)` лише на логарифми скінченного числа простих дільників модуля `q`:
   ```
   ψ(x, χ₀) = ∑_{n ≤ x, gcd(n, q) = 1} Λ(n)
            = ψ(x) - ∑_{p | q} ∑_{k ≥ 1, pᵏ ≤ x} ln p [виключення дільників модуля q]
            = x + O(x · exp(-c √ln x))                 [теорема про розподіл простих чисел]
   ```
   Множачи на коефіцієнт `χ̄₀(a) / φ(q) = 1 / φ(q)`, одержуємо домінуючий головний член асимптотики:
   ```
   (1 / φ(q)) · x
   ```

2. **Внесок усіх неголовних характерів `χ ≠ χ₀`:**
   Оскільки відповідна L-функція Діріхле `L(s, χ)` є цілою функцією на всій комплексній площині (не має простого полюса в точці `s = 1`) та за фундаментальною теоремою Діріхле не має нулів на вертикальній прямій `Re(s) = 1` (`L(1, χ) ≠ 0`), з комплексної формули Перрона для оберненого перетворення Мелліна випливає, що зважена сума `ψ(x, χ)` є залишковим флуктуаційним членом:
   ```
   ψ(x, χ) = O(x · exp(-c √ln x))                      [оцінка за відсутності нулів на Re(s) = 1]
   ```
   Якщо ж виконується Узагальнена гіпотеза Рімана (GRH), тобто всі нетривіальні нулі кожної функції `L(s, χ)` лежать на критичній прямій `Re(s) = 1/2`, то залишковий член флуктуацій зменшується до величини порядку `O(√x · ln² x)`.

Об'єднуючи спектральні компоненти в єдиний вираз, отримуємо закон розподілу простих чисел в арифметичних прогресіях:

```
ψ(x; q, a) = (1 / φ(q)) · x + O(x · exp(-c √ln x))
```

Цей фундаментальний результат строго доводить, що прості числа розподіляються асимптотично рівномірно між усіма `φ(q)` допустимими класами залишків за модулем `q`.
