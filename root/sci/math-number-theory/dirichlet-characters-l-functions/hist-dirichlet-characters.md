# Як Діріхле подружив гармонічний аналіз із простими числами

Історія характерів Діріхле та L-функцій — це історія одного з найдивовижніших концептуальних проривів у математиці XIX століття. Вона показує, як нерозв'язна арифметична задача про розподіл простих чисел у числових рядах знайшла своє несподіване розв'язання завдяки ідеям фізичного гармонічного аналізу, теорії коливань та комплексної геометрії. Створений Петером Густавом Леженом Діріхле апарат не просто закрив багатовікову гіпотезу, а заклав підвалини двох абсолютно нових математичних дисциплін: аналітичної теорії чисел та абстрактної теорії представлень груп.

## 1. Загадка арифметичних прогресій та глухий кут евклідової алгебри

У IX книзі своїх «Начал» Евклід Александрійський навів елегантний доказ нескінченності множини всіх простих чисел. Його ідея полягала в утворенні числа N = (p₁ · p₂ · ... · pₖ) + 1 з добутку всіх відомих простих чисел: число N не може ділитися на жодне з pᵢ, а отже, або саме є простим, або містить новий простий дільник.

Проте щойно математики спробували звузити питання і запитали: *«Чи нескінченно багато простих чисел міститься в окремій арифметичній прогресії  + k·q при взаємно простих  та q?»*, метод Евкліда швидко зіткнувся з непереборними перешкодами.

Для деяких простих випадків евклідів прийом ще вдавалося модифікувати:
- Для прогресії 4k + 3 (де q = 4,  = 3) розглядають число N = 4(p₁ · p₂ · ... · pₖ) - 1. Будь-який простий дільник числа N має вигляд 4m + 1 або 4m + 3. Оскільки добуток довільної кількості чисел вигляду 4m + 1 завжди дає число того самого вигляду 4m + 1 ((4x + 1)(4y + 1) = 4(4xy + x + y) + 1 ≡ 1 (mod 4)), число N ≡ 3 (mod 4) обов'язково повинно мати принаймні один новий простий множник вигляду 4k + 3.
- Подібним чином вдається розібрати випадки прогресій 3k + 2 та 6k + 5.

Але спроба застосувати цей самий підхід до прогресії 4k + 1 зазнає повної невдачі. Якщо утворити число N = 4(p₁ · ... · pₖ) + 1 ≡ 1 (mod 4), то воно цілком може бути добутком двох простих чисел вигляду 4k + 3 (наприклад, 9 = 3 · 3 або 21 = 3 · 7). Добуток двох чисел з остачею 3 дає остачу 1 ((4a + 3)(4b + 3) = 4(4ab + 3a + 3b + 2) + 1 ≡ 1 (mod 4)). Алгебраїчна схема більше не здатна змусити хоча б один дільник належати до потрібного класу.

Для загального модуля q та довільної остачі  комбінаторика остач стає настільки заплутаною, що чисто алгебраїчні методи на основі поліноміальних підстановок виявляються безсилі.

### Спроби Лежандра та критика Ґаусса

Адрієн-Марі Лежандр у 1788 році у своїй праці з теорії чисел сформулював загальну гіпотезу: будь-яка арифметична прогресія , a + q, a + 2q, a + 3q, ..., де gcd(a, q) = 1, містить нескінченну кількість простих чисел. У 1808 році у другому виданні «Théorie des nombres» Лежандр навіть запропонував спробу доведення.

Однак Карл Фрідріх Ґаусс у своїх епохальних «Арифметичних дослідженнях» (*Disquisitiones Arithmeticae*, 1801, стаття 297) піддав доведення Лежандра нищівній критиці. Ґаусс показав, що Лежандр у своїх викладках неявно припускав існування простих чисел у спеціальних бінарних квадратичних формах — твердження, яке за своєю складністю було еквівалентним самій доводжуваній теоремі. Це було класичне логічне коло (*petitio principii*). Ґаусс зауважив, що хоча твердження Лежандра безсумнівно є істинним, його строге доведення вимагає принципово нових математичних методів, яких на той час ще не існувало.

## 2. Ейлерів аналітичний міст та мультиплікативна криза

Перший промінь світла з'явився ще у 1737 році, коли Леонард Ейлер опублікував свою знамениту тотожність, що пов'язала підсумовування за всіма натуральними числами з нескінченним добутком за всіма простими числами:

`
ζ(s) = ∑_{n=1}^∞ 1 / nˢ = ∏_{p ∈ P} (1 - 1 / pˢ)⁻¹
`

Ейлер показав, що при прямуванні дійсного параметра s → 1⁺ дзета-функція поводиться як розбіжний гармонічний ряд ζ(1) = 1 + 1/2 + 1/3 + ... = ∞. Логарифмуючи нескінченний добуток:

`
ln ζ(s) = ∑_{p ∈ P} ln(1 - 1/pˢ)⁻¹ = ∑_{p ∈ P} 1 / pˢ + O(1)
`

Ейлер дійшов фундаментального висновку: сума обернених величин усіх простих чисел є розбіжною:

`
∑_{p ∈ P} 1 / p = ∞
`

Це був перший в історії випадок, коли властивості неперервного аналізу (граничні переходи та логарифми) використали для доведення дискретного арифметичного факту.

Однак перед дослідниками постала фундаментальна мультиплікативна криза. Як виділити з ейлерової суми ∑ 1/p лише ті доданки, які задовольняють умову p ≡ a (mod q)?

Природною ідеєю здавалося ввести індикаторну дельта-функцію δ(n ≡ a mod q) прямо під знак ряду:

`
F(s) = ∑_{n=1}^∞ δ(n ≡ a mod q) / nˢ
`

Але індикатор класу залишків **не володіє мультиплікативністю**:

`
δ(m · n ≡ a mod q) ≠ δ(m ≡ a mod q) · δ(n ≡ a mod q)
`

Наприклад, якщо q = 4 та  = 1, то для чисел m = 3 та 
 = 3 маємо δ(3 ≡ 1 mod 4) = 0, тоді як для їхнього добутку 3 · 3 = 9 ≡ 1 (mod 4) маємо δ(9 ≡ 1 mod 4) = 1. Оскільки коефіцієнти ряду не мультиплікативні, ряд F(s) неможливо розкласти у добуток Ейлера за простими множниками. Втрата Ейлерового добутку означала повний розрив зв'язку між аналітичним рядом та простими числами.

## 3. Діріхле: математик на перетині двох великих культур

Розв'язання цієї кризи вимагало мислителя унікальної долі, здатного синтезувати дві провідні математичні школи того часу — французьку школу неперервного аналізу та німецьку школу дискретної арифметики. Таким мислителем став Петер Густав Лежен Діріхле (1805–1859).

Народившись у місті Дюрен (поблизу Аахена), молодий Діріхле у віці сімнадцяти років вирушив навчатися до Парижа. У 1820-х роках Париж був світовою столицею математичного аналізу та математичної фізики. У Колеж де Франс та Сорбонні Діріхле відвідував лекції Жана-Батіста Жозефа Фур'є, Адрієна-Марі Лежандра, П'єра-Симона Лапласа, Симеона Дені Пуассона та Оґюстена-Луї Коші.

Найбільший вплив на формування наукового світогляду Діріхле справили двоє людей:
1. **Жан-Батіст Жозеф Фур'є**, чия фундаментальна праця «Аналітична теорія тепла» (*Théorie analytique de la chaleur*, 1822) висунула революційну ідею: будь-яку періодичну функцію, навіть зі зламами та розривами, можна розкласти в гармонічний ряд за синусами та косинусами. Діріхле став першим, хто дав строге математичне доведення збіжності рядів Фур'є (ознака Діріхле).
2. **Карл Фрідріх Ґаусс**, чию книгу «Арифметичні дослідження» Діріхле вивчав щоденно. За спогадами сучасників, Діріхле ніколи не вирушав у дорогу без цього фоліанта під пахвою і був одним із небагатьох європейських математиків, які повністю опанували складні гауссові конструкції вищих степенів та бінарних форм.

Перебуваючи на стику ідей Фур'є (спектральний гармонічний розклад) та ідей Ґаусса (модульна арифметика та первісні корені), Діріхле зробив геніальний здогад: якщо розривну дельта-функцію на відрізку можна подати через неперервні гармоніки exp(i k x), то розривну дельта-функцію на скінченній групі залишків (ℤ/qℤ)* можна розкласти за періодичними мультиплікативними гармоніками!

## 4. Меморандум 1837 року: народження характерів та L-функцій

27 квітня 1837 року в Берліні на засіданні Прусської королівської академії наук Діріхле зачитав епохальну доповідь: *«Доведення теореми про те, що будь-яка нескінченна арифметична прогресія, перший член і різниця якої не мають спільних дільників, містить нескінченно багато простих чисел»* (*Beweis des Satzes, dass jede unbegrenzte arithmetische Progression, deren erstes Glied und Differenz keine gemeinschaftlichen Factoren haben, unendlich viele Primzahlen enthält*).

У цій роботі Діріхле ввів функції, які він спочатку назвав «спеціальними множниками» (*besondere Factoren*). Він визначив їх як функції χ: ℤ → ℂ, які задовольняють три умови:
1. Періодичність за модулем: χ(n + q) = χ(n).
2. Повна мультиплікативність: χ(m · n) = χ(m) · χ(n).
3. Рівність нулю на числах, не взаємно простих з модулем: χ(n) = 0, якщо gcd(n, q) > 1, та χ(1) = 1.

Спираючись на розроблену Ґауссом теорію первісних коренів, Діріхле явно побудував ці функції. Для модуля q, який має первісний корінь g, кожне взаємно просте число 
 однозначно записується через індекс (дискретний логарифм) 
 ≡ g^{ind(n)} (mod q). Тоді φ(q) різних характерів визначаються через комплексні корені з одиниці:

`
χₖ(n) = exp(2 π i · k · ind_g(n) / φ(q)),   де k ∈ {0, 1, ..., φ(q) - 1}
`

Використовуючи сумування геометричної прогресії коренів з одиниці, Діріхле вивів фундаментальні співвідношення ортогональності. Завдяки їм індикаторна дельта-функція класу залишків розклалася у дискретний спектральний ряд Фур'є:

`
δ(n ≡ a mod q) = (1 / φ(q)) · ∑_{χ ∈ Ĝ} χ̄(a) · χ(n)
`

Підставивши цей розклад у суму за простими числами, Діріхле отримав:

`
∑_{p ≡ a (mod q)} 1 / pˢ = (1 / φ(q)) · ∑_{χ ∈ Ĝ} χ̄(a) · ( ∑_{p ∈ P} χ(p) / pˢ )
`

Для кожної окремої гармоніки χ внутрішня сума зберігала мультиплікативність, що дало змогу згорнути її у новий нескінченний ряд, названий Діріхле L-рядом:

`
L(s, χ) = ∑_{n=1}^∞ χ(n) / nˢ = ∏_{p ∈ P} (1 - χ(p) / pˢ)⁻¹
`

Позначення L було обрано Діріхле на честь терміна *Linearform* (лінійні форми) або як наступну літеру в алфавіті після фундаментальних математичних функцій.

Логарифмуючи кожну L-функцію:

`
ln L(s, χ) = ∑_{p ∈ P} χ(p) / pˢ + O(1)
`

Діріхле перетворив суму простих чисел на лінійну комбінацію аналітичних логарифмів:

`
∑_{p ≡ a (mod q)} 1 / pˢ = (1 / φ(q)) · ln L(s, χ₀) + (1 / φ(q)) · ∑_{χ ≠ χ₀} χ̄(a) · ln L(s, χ) + O(1)
`

Для головного характеру χ₀ L-функція відрізняється від дзета-функції Ейлера лише скінченним добутком простих дільників модуля q. Тому при s → 1⁺ маємо ln L(s, χ₀) → +∞.

## 5. Драматична битва за ненульове значення L(1, χ) ≠ 0

У цей момент доведення натрапило на колосальну перешкоду, яка ледь не зруйнувала всю будівлю нової теорії.

Якщо для деякого неголовного характеру χ₁ ≠ χ₀ значення ряду в одиниці перетвориться на нуль, тобто L(1, χ₁) = 0, то ln L(s, χ₁) → -∞ при s → 1⁺. Ця від'ємна нескінченність могла б повністю компенсувати додатну нескінченність від головного характеру ln L(s, χ₀), і вся сума ∑_{p ≡ a} 1/pˢ залишилася б скінченною константою!

Таким чином, уся теорема про нескінченність простих чисел звелася до єдиного вирішального твердження: **довести, що L(1, χ) ≠ 0 для всіх неголовних характерів χ ≠ χ₀**.

Діріхле розділив характери на два класи:

1. **Комплексні характери (χ ≠ χ̄):**
   Для них Діріхле розглянув добуток усіх φ(q) L-функцій:
   `
   Φ(s) = ∏_{χ ∈ Ĝ} L(s, χ)
   `
   Логарифм цього добутку розкладається у суму з виключно невід'ємними коефіцієнтами:
   `
   ln Φ(s) = φ(q) · ∑_{pᵐ ≡ 1 (mod q)} 1 / (m · p^{m·s}) ≥ 0
   `
   Звідси випливає, що Φ(s) ≥ 1 для всіх дійсних s > 1.
   Якби комплексний характер χ₁ мав нуль L(1, χ₁) = 0, то його комплексно спряжений характер χ̄₁ ≠ χ₁ також мав би нуль L(1, χ̄₁) = 0. Два нулі дали б множник (s - 1)², який переміг би простий полюс першого порядку від L(s, χ₀) = c / (s - 1). У результаті границя lim_{s → 1⁺} Φ(s) = 0, що прямо суперечить нерівності Φ(s) ≥ 1. Отже, для комплексних характерів L(1, χ) ≠ 0.

2. **Дійсні (квадратичні) характери (χ = χ̄):**
   Для дійсного характеру спряжений характер збігається із самим характером. Нуль був би лише першого порядку і дав би скінченну границю lim Φ(s) = C > 0, що не створює аналітичної суперечності.

Діріхле витратив місяці на пошук доведення для дійсних характерів. Прорив стався у 1839 році, коли він знайшов несподіваний міст між L-функціями та своєю попередньою роботою з бінарних квадратичних форм A x² + 2 B x y + C y².

Діріхле обчислив границю середнього значення кількості представлень чисел квадратичними формами дискримінанта D двома різними способами:
- Геометрично: обчислюючи об'єм фундаментальної області решітки (площу еліпса для D < 0 або площу гіперболічного сектора з фундаментальною одиницею ε_D для D > 0), помножену на число класів еквівалентності форм h(D).
- Аналітично: через суму значень дійсного характеру χ_D(n) = (D/n).

Прирівнявши ці два результати, Діріхле вивів знамениту **аналітичну формулу числа класів** (*Dirichlet class number formula*):
`
L(1, χ_D) = (2 π · h(D)) / (w · √|D|),     для D < 0
L(1, χ_D) = (h(D) · ln ε_D) / √D,          для D > 0
`
Оскільки число класів еквівалентності ідеалів або квадратичних форм h(D) є натуральним числом (h(D) ≥ 1), а фундаментальна одиниця ε_D > 1 дає ln ε_D > 0, усі співмножники у формулі є строго додатними дійсними числами.
Отже, L(1, χ_D) > 0 строго і ні за яких умов не може дорівнювати нулю!

Це тріумфальне відкриття остаточно замкнуло логічний ланцюг доведення. Сума ∑_{p ≡ a mod q} 1/p є розбіжною, а теорема про нескінченність простих чисел в арифметичних прогресіях була строго доведена.

## 6. Еволюція концепції: від спеціальних множників до абстрактної алгебри

Праця Діріхле 1837 року справила ефект розірваної бомби. Вона продемонструвала силу методів математичного аналізу у розв'язанні задач, які раніше вважалися виключно дискретними. Протягом наступного століття відкриття Діріхле пережило масштабне узагальнення.

### Ріхард Дедекінд та формалізація терміна «характер»

У 1863 році учень Діріхле Ріхард Дедекінд видав посмертні лекції свого вчителя («Vorlesungen über Zahlentheorie»). У наступних перевиданнях (1871, 1879, 1894) Дедекінд суттєво переробив виклад і додав знамениті додатки (*Supplemente*).

Саме Дедекінд замінив громіздкий вираз «спеціальні множники» на елегантний термін **характер** (від грецького *charaktēr* — ознака, відбиток). Більше того, Дедекінд абстрагував це поняття: він визначив характер як довільний гомоморфізм зі скінченної абелевої групи G у мультиплікативну групу ненульових комплексних чисел ℂ*. Дедекінд також увів дзета-функцію числового поля (дзета-функцію Дедекінда), яка узагальнила L-функції Діріхле на алгебраїчні числові поля.

### Генріх Вебер та двоїстість скінченних груп

У 1880-х роках Генріх Вебер створив загальну теорію характерів скінченних абелевих груп. Він довів, що множина всіх характерів утворює групу Ĝ, ізоморфну вихідній групі G, а подвійна двоїста група Ĝ̂ канонічно ізоморфна самій групі G (G ≅ Ĝ̂).

### Фердинанд Георг Фробеніус і неабелеві групи

У 1896 році Фердинанд Георг Фробеніус у серії фундаментальних статей поширив поняття характеру на скінченні **неабелеві** групи. Для неабелевої групи характер уже не є мультиплікативною функцією чисел: він є слідом матричного представлення групи χ(g) = Tr(ρ(g)). Теорія характерів Фробеніуса стала основним апаратом квантової механіки, фізики твердого тіла та сучасної алгебри.

### Двоїстість Понтрягіна та гармонічний аналіз на групах

У 1934 році видатний математик Лев Понтрягін завершив грандіозне узагальнення, побудувавши теорію двоїстості для довільних локально компактних топологічних абелевих груп (двоїстість Понтрягіна).

З'ясувалося, що класичні математичні інструменти, які раніше вважалися різними, є лише частковими випадками єдиної концепції характеру Понтрягіна:
- Для одиничного кола S¹ = ℝ/ℤ характерами є функції exp(2 π i n x) — це класичні ряди Фур'є;
- Для дійсної прямої ℝ характерами є неперервні експоненти exp(i ω x) — це неперервне перетворення Фур'є;
- Для скінченної дискретної групи залишків (ℤ/qℤ)* характерами є саме характери Діріхле;
- Для кільця p-адичних чисел ℚ_p характери описують локальні коливання в p-адичному аналізі.

### Дисертація Тейта та програма Ленґлендса

У 1950 році Джон Тейт у своїй знаменитій докторській дисертації в Принстоні показав, що всі L-функції Діріхле та дзета-функції Дедекінда можна отримати як єдиний гармонічний інтеграл Фур'є на кільці аделей числового поля (адельні дзета-інтеграли Тейта). Це дало змогу автоматично отримати аналітичне продовження та функціональне рівняння для всіх L-функцій без складних комбінаторних обчислень.

Наприкінці 1960-х років Роберт Ленґлендс сформулював глобальну Програму Ленґлендса — грандіозну систему гіпотез, що пов'язують автоморфні L-функції груп Лі з представленнями груп Галуа. L-функції Діріхле в цій програмі є фундаментальним базовим рівнем (автоморфні форми для одновимірної групи GL(1)).

## 7. Спадщина та сучасні застосування

Відкриття Діріхле 1837 року продовжує жити у найсучасніших прикладних та теоретичних напрямах:

1. **Аналітичний розподіл простих чисел:**
   Теорема Зігеля–Вальфіша та узагальнена гіпотеза Рімана (GRH) для L-функцій Діріхле дають найточніші оцінки кількості простих чисел π(x; q, a) в арифметичних прогресіях, що є критично важливим для аналізу складності алгоритмів факторизації чисел.
2. **Алгоритми перевірки простоти:**
   Тест Соловея–Штрассена (1977) використовує квадратичний характер Діріхле (символ Якобі) для швидкої ймовірнісної перевірки чисел на простоту, що використовується в протоколах генерації ключів RSA.
3. **Криптографія на основі дискретного логарифма:**
   Стійкість протоколу обміну ключами Діффі–Геллмана та цифрового підпису DSA безпосередньо спирається на структуру циклічних компонент групи (ℤ/qℤ)*, вперше детально описану в роботах Діріхле та Ґаусса.
4. **Обробка сигналів та швидкі перетворення:**
   Теорія ортогональності характерів Діріхле є основою теоретико-числового перетворення Фур'є (NTT), яке забезпечує надшвидке множення великих поліномів у сучасній постквантовій криптографії (криптосистеми Kyber та Dilithium).

Геніальний синтез дискретної арифметики та гармонічного аналізу, здійснений Петером Густавом Леженом Діріхле у 1837 році, назавжди змінив обличчя математики, довівши, що найглибші таємниці цілих чисел розкриваються через гармонію неперервного світу.
