# ⚙️ Алгоритми побудови та обчислення характерів Діріхле

Обчислювальний аналіз характерів Діріхле є ключовим інструментом у сучасній алгоритмічній теорії чисел, обчислювальній криптографії, цифровій обробці сигналів на скінченних алгебраїчних структурах та швидких перетвореннях Фур'є над скінченними полями. На відміну від абстрактних аналітичних формул на папері, програмне втілення характерів вимагає точного поєднання дискретної алгебри, модульної арифметики великих чисел, чисельних комплексних обчислень та глибокого розуміння топологеми двоїстих груп.

У цій практичній вставці детально розглядаються алгоритмічні принципи побудови повних таблиць характерів Діріхле за довільним модулем `q`, методи факторизації та розкладу на прямі добутки за допомогою тензорного (Кронекерового) добутку матриць, алгоритми швидкої ідентифікації первісних характерів та обчислення провідника (conductor), а також надаються повні, готові до промислового використання реалізації трьома мовами: C, C++ та Python.

## 1. Алгоритмічний дизайн та математичні етапи

Обчислення всієї системи характерів Діріхле для заданого натурального модуля `q` розбивається на сім взаємопов'язаних алгоритмічних етапів.

```
┌─────────────────────────────────────────────────────────────────────────┐
│              Конвеєр обчислення характерів за модулем q                 │
└─────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
       1. Побудова приведеної системи залишків G = (ℤ/qℤ)*
          (алгоритм Евкліда gcd(n, q) == 1, розмір φ(q))
                                    │
                                    ▼
       2. Алгебраїчний розклад групи залишків на циклічні твірні
          (пошук первісних коренів або факторизація через CRT)
                                    │
                                    ▼
       3. Побудова таблиці дискретних логарифмів (індексів)
          (відображення n ⟼ (ind₁(n), ind₂(n), ..., indᵣ(n)))
                                    │
                                    ▼
       4. Генерація матриці значень через корені з одиниці
          (обчислення комплексних експонент для кожного характеру)
                                    │
                                    ▼
       5. Алгоритмічний пошук провідника d | q (Conductor)
          (тестування умови χ(n) == 1 при n ≡ 1 mod d)
                                    │
                                    ▼
       6. Класифікація симетрії (парність та дійсність)
          (перевірка χ(-1) = ±1 та уявних компонент значень)
                                    │
                                    ▼
       7. Верифікація ортогональності та спектральний дельта-фільтр
          (перевірка рядків, стовпчиків та проектора Фур'є)
```

### Етап 1. Генерація приведеної системи залишків

Першим кроком є побудова множини цілих чисел `G = (ℤ/qℤ)*`, взаємно простих з модулем `q` у проміжку від 1 до `q - 1`.
Для цього застосовується класичний бінарний або ділильний алгоритм Евкліда обчислення найбільшого спільного дільника `gcd(n, q)`:

```
n ∈ G ⟺ gcd(n, q) = 1,   де n ∈ {1, 2, ..., q - 1}
```

Кількість таких елементів точно дорівнює значенню функції Ейлера `|G| = φ(q)`. Усі знайдені елементи зберігаються у впорядкованому масиві `coprimes` довжини `φ(q)`. Для оптимізації частого пошуку індексу числа `n` у цьому списку будується зворотний масив `elem_index` розміром `q`, де для кожного `n ∈ G` зберігається його порядковий номер `i ∈ {0, ..., φ(q)-1}`, а для `gcd(n, q) > 1` записується маркер відсутності `-1`.

### Етап 2. Розклад групи залишків на циклічні твірні

Алгебраїчна структура мультиплікативної групи залишків `G = (ℤ/qℤ)*` визначає спосіб параметризації та індексації характерів. Тут виникає фундаментальний поділ на два класи модулів:

1. **Циклічні модулі (`q = 2, 4, pᵏ, 2pᵏ` для непарних простих `p`):**
   У цьому випадку група `G` породжується єдиним твірним елементом — первісним коренем `g`. Послідовні степені `g⁰, g¹, g², ..., g^{φ(q)-1}` пробігають усі елементи приведеної системи залишків за модулем `q`.
   Алгоритм знаходження найменшого первісного кореня полягає в послідовному переборі чисел `g ∈ [2, q-1]` та перевірці умови:

   ```
   g^{φ(q) / p_i} ≢ 1 (mod q)   для кожного простого дільника p_i числа φ(q)
   ```

   Швидке модульне піднесення до степеня за алгоритмом праворуч-наліво (`power_mod`) виконується за час `O(log(φ(q)))`.

2. **Нециклічні модулі (`q = 2ᵏ` при `k ≥ 3` або складене `q` з кількома простими дільниками):**
   За теоремою Гауса та структурою скінченних абелевих груп, `(ℤ/2ᵏℤ)*` ізоморфна прямому добутку двох циклічних підгруп: `C₂ × C_{2ᵏ⁻²}`, породжених елементами `-1` (порядок 2) та `5` (порядок `2ᵏ⁻²`).
   Для загального складеного модуля `q = p₁^{a₁} · p₂^{a₂} · ... · p_r^{a_r}` застосовується Китайська теорема про залишки (CRT), яка встановлює канонічний кільцевий ізоморфізм:

   ```
   (ℤ/qℤ)* ≅ (ℤ/p₁^{a₁}ℤ)* × (ℤ/p₂^{a₂}ℤ)* × ... × (ℤ/p_r^{a_r}ℤ)*
   ```

   Кожен характер `χ (mod q)` однозначно подається як добуток фактор-характерів компонент:

   ```
   χ(n) = χ₁(n mod p₁^{a₁}) · χ₂(n mod p₂^{a₂}) · ... · χᵣ(n mod p_r^{a_r})
   ```

   Матриця всієї системи характерів складеного модуля є точним **Кронекеровим (тензорним) добутком** матриць характерів окремих примарних компонент: `M_q = M_{p₁^{a₁}} ⊗ M_{p₂^{a₂}} ⊗ ... ⊗ M_{p_r^{a_r}}`.

### Етап 3. Обчислення дискретних логарифмів (індексів)

Для циклічного модуля після знаходження генератора `g` будується таблиця дискретного логарифма (індексу) `ind_g(n)`. Вона зв'язує кожен залишок `n ∈ G` із показником степеня первісного кореня:

```
n ≡ g^{ind_g(n)} (mod q),   де ind_g(n) ∈ {0, 1, ..., φ(q) - 1}
```

У програмній реалізації ця таблиця створюється за один лінійний прохід довжини `φ(q)` послідовним домноженням поточного залишку на `g` за модулем `q`. Масив `discrete_log` розміром `q` забезпечує миттєвий доступ до індексу числа за час `O(1)`.

Для нециклічних модулів елемент `n` індексується вектором координат `(e₁, e₂, ..., e_r)` у базисі твірних елементів компонент.

### Етап 4. Обчислення комплексних значень характерів

Маючи таблицю дискретних логарифмів, кожен з `φ(q)` характерів ототожнюється з цілим числом `k ∈ {0, 1, ..., φ(q) - 1}`. Значення `k`-го характеру `χₖ` на залишку `n` обчислюється як комплексний корінь `φ(q)`-го степеня з одиниці:

```
χₖ(n) = exp(2 π i · k · ind_g(n) / φ(q))
      = cos(2 π k ind_g(n) / φ(q)) + i · sin(2 π k ind_g(n) / φ(q))
```

Для запобігання багатократному обчисленню дорогих тригонометричних функцій `cos` та `sin` створюється таблиця передобчислених базисних коренів з одиниці (фазових множників):

```
ω_m = exp(2 π i · m / φ(q)),   де m ∈ {0, 1, ..., φ(q) - 1}
```

Тоді значення характеру визначається як простий доступ за модульним індексом `m = (k · ind_g(n)) mod φ(q)`:

```
χₖ(n) = ω_{(k · ind_g(n)) mod φ(q)}
```

Це зводить заповнення всієї матриці розміром `φ(q) × φ(q)` до простих операцій множення цілих чисел та копіювання вказівників.

### Етап 5. Визначення провідника (Conductor) та перевірка на первісність

Важливою структурною характеристикою кожного характеру є його **провідник** `cond(χ) = d`. Він показує мінімальний підмодуль `d | q`, для якого характер залишається періодичним та не містить паразитного занулення.

Алгоритм обчислення провідника перебирає всі натуральні дільники `d` модуля `q` у строго зростаючому порядку (`d = 1, d₂, d₃, ..., q`). Для кожного дільника `d` перевіряється інваріантність характеру на підгрупі залишків, порівнянних з 1 за модулем `d`:

```
Умова індукованості: Для всіх n ∈ (ℤ/qℤ)*: якщо n ≡ 1 (mod d), то χ(n) = 1 + 0i
```

Перший (і отже найменший) дільник `d`, для якого ця рівність виконується для всіх елементів приведеної системи залишків із точністю до машинного епсилона `ε = 1e-6`, є провідником `cond(χ) = d`.

* Якщо `cond(χ) = q`, характер є **первісним** (primitive) — він несе нову арифметичну інформацію, специфічну саме для модуля `q`.
* Якщо `cond(χ) < q`, характер є **індукованим** (imprimitive) — його значення на взаємно простих з `q` числах повністю визначаються первісним характером `χ* (mod d)`.
* Зокрема, для головного характеру `χ₀` провідник завжди дорівнює `cond(χ₀) = 1`.

### Етап 6. Алгоритмічна класифікація симетрій

Для кожного згенерованого характеру визначаються дві ключові ознаки симетрії:

1. **Парність:** Обчислюється значення характеру на елементі `-1 ≡ q - 1 (mod q)`.
   * Якщо `χ(q - 1) = +1 + 0i`, характер є **парним** (`χ(-n) = χ(n)`).
   * Якщо `χ(q - 1) = -1 + 0i`, характер є **непарним** (`χ(-n) = -χ(n)`).
   Парність безпосередньо визначає гамма-фактор та форму функціонального рівняння відповідної L-функції Діріхле.

2. **Дійсність (реальність):** Перевіряються уявні частини всіх значень характеру `|Im(χ(n))| < ε`.
   * Якщо всі значення є суто дійсними числами з множини `{-1, 1}`, характер є **дійсним** (квадратичним, `χ² = χ₀`). Дійсні первісні характери відповідають символам Кронекера-Якобі `(D/n)`.
   * Якщо існує хоча б одне значення з ненульовою уявною частиною, характер є **комплексним**. Комплексні характери завжди розбиваються на взаємно спряжені пари `(χ, χ̄)`.

### Етап 7. Верифікація ортогональності та спектральний проектор

Після генерації матриці таблиці характерів здійснюється алгоритмічний контроль коректності за двома дуальними співвідношеннями:

```
Перша ортогональність (за рядками):   ∑_{i=0}^{φ(q)-1} χ_a(n_i) · χ̄_b(n_i) = φ(q) · δ_{a,b}
Друга ортогональність (за стовпчиками): ∑_{k=0}^{φ(q)-1} χ_k(m) · χ̄_k(n) = φ(q) · δ_{m ≡ n mod q}
```

З другого співвідношення будується практичний спектральний фільтр Фур'є — відновлення індикатора класу залишків `δ(n ≡ a mod q)`:

```
δ(n ≡ a mod q) = (1 / φ(q)) · ∑_{k=0}^{φ(q)-1} χ̄_k(a) · χ_k(n)
```

Ця функція дозволяє зважувати будь-яку числову послідовність або дискретний сигнал лише за числами фіксованого класу залишків.

## 3. Детальний простежувальний розбір та порівняння парадигм пам'яті

Щоб простежити роботу алгоритму у найменших деталях, розглянемо покрокове виконання програми для циклічного модуля `q = 5`.

### 1. Покрокове простеження для `q = 5`

* **Крок 1. Формування приведеної системи залишків:**
  Для кожного `i ∈ {1, 2, 3, 4}` обчислюється `gcd(i, 5) = 1`.
  Масив `coprimes` набуває значень `[1, 2, 3, 4]`, порядок групи `phi_q = 4`.

* **Крок 2. Знаходження первісного кореня:**
  Для `q = 5` число `phi_q = 4 = 2²` має єдиний простий дільник `p = 2`.
  Тестується кандидат `g = 2`:
  `2^{4/2} mod 5 = 2² mod 5 = 4 ≢ 1 (mod 5)`.
  Умова виконується, тому `g = 2` є первісним коренем.

* **Крок 3. Заповнення масиву дискретних логарифмів:**
  Послідовні степені двійки за модулем 5:
  `2⁰ = 1 ⟹ discrete_log[1] = 0`
  `2¹ = 2 ⟹ discrete_log[2] = 1`
  `2² = 4 ⟹ discrete_log[4] = 2`
  `2³ = 8 ≡ 3 ⟹ discrete_log[3] = 3`

* **Крок 4. Генерація матриці значень характерів:**
  Базисний корінь 4-го степеня з одиниці: `w = exp(2 π i / 4) = i`.
  Кут для індексу `k` та залишку `n`: `angle = 2 π · k · ind₂(n) / 4`.

  Матриця значень `χₖ(n)` набуває точного вигляду:
  ```
          n = 1 (ind=0)   n = 2 (ind=1)   n = 3 (ind=3)   n = 4 (ind=2)
  χ₀:     +1.00 + 0.00i   +1.00 + 0.00i   +1.00 + 0.00i   +1.00 + 0.00i   [головний, cond=1]
  χ₁:     +1.00 + 0.00i   +0.00 + 1.00i   -0.00 - 1.00i   -1.00 + 0.00i   [комплексний, cond=5]
  χ₂:     +1.00 + 0.00i   -1.00 + 0.00i   -1.00 + 0.00i   +1.00 + 0.00i   [дійсний, cond=5]
  χ₃:     +1.00 + 0.00i   -0.00 - 1.00i   +0.00 + 1.00i   -1.00 + 0.00i   [комплексний, cond=5]
  ```

* **Крок 5. Простеження відновлення дельта-фільтра для `a = 3`:**
  Спряжені значення на елементі `a = 3`:
  `χ̄₀(3) = 1`
  `χ̄₁(3) = ( -i )* = +i`
  `χ̄₂(3) = ( -1 )* = -1`
  `χ̄₃(3) = ( +i )* = -i`

  Обчислюємо суму `∑_{k=0}^3 χ̄ₖ(3) · χₖ(n)` для різних `n`:
  - Для `n = 1`: `1·1 + i·1 + (-1)·1 + (-i)·1 = 1 + i - 1 - i = 0`.
    Множимо на `1/4`: `δ(1 ≡ 3 mod 5) = 0.00`.
  - Для `n = 3`: `1·1 + i·(-i) + (-1)·(-1) + (-i)·i = 1 + 1 + 1 + 1 = 4`.
    Множимо на `1/4`: `δ(3 ≡ 3 mod 5) = 4 / 4 = 1.00`.
  - Для `n = 4`: `1·1 + i·(-1) + (-1)·1 + (-i)·(-1) = 1 - i - 1 + i = 0`.
    Множимо на `1/4`: `δ(4 ≡ 3 mod 5) = 0.00`.

### 2. Парадигма управління пам'яттю у C

У реалізації мовою C структура `DirichletTable` використовує явне багаторівневе виділення пам'яті через системний алокатор `malloc`:
1. `dt`: дескриптор таблиці у купі.
2. `dt->coprimes`: неперервний буфер цілих чисел розміром `φ(q) · sizeof(int)`.
3. `dt->discrete_log`: таблиця прямої адресації розміром `q · sizeof(int)`.
4. `dt->table`: масив із `φ(q)` покажчиків на рядки `sizeof(Complex*)`.
5. Кожен рядок `dt->table[k]`: неперервний буфер комплексних чисел розміром `φ(q) · sizeof(Complex)`.

Для запобігання витокам пам'яті функція `free_dirichlet_table` виконує повну деалокацію у строго зворотній послідовності (рядки ➔ масив покажчиків ➔ таблиці індексів ➔ дескриптор). Усі операції перевіряють результат повернення `malloc` на нульовий покажчик `NULL`.

### 3. Архітектура безпеки та RAII у C++

Реалізація мовою C++ повністю спирається на стандартну ідіому RAII (Resource Acquisition Is Initialization) та шаблонні контейнери:
* Усі динамічні масиви інкапсульовані в `std::vector<int>` та двовимірний вектор `std::vector<std::vector<Complex>>`.
* Відсутні сирі покажчики, ручні виклики `new`/`delete` та явні деструктори — очищення ресурсів гарантується автоматично компілятором навіть при виникненні винятків.
* Метод `find_primitive_root` повертає тип `std::optional<int>`, що забезпечує типобезпечну сигналізацію відсутності результату без магічних констант на кшталт `-1`.
* Для комплексних чисел застосовується стандартний клас `std::complex<double>` з перевантаженими операторами множення, додавання та спряження `std::conj`.

### 4. Динамічна та векторизована модель Python

У версії Python структура даних організована на базі вбудованих списків та словників:
* Пошук дискретного логарифма використовує хеш-таблицю `discrete_log`, що забезпечує амортизовану складність пошуку `O(1)`.
* Комплексні числа підтримуються на рівні ядра інтерпретатора як нативний тип `complex` (літерал `1.0 + 2.0j`) та бібліотеки `cmath`.
* Обчислення скалярних добутків та дельта-фільтрів реалізовано через компактні генераторні вирази та вбудовану функцію `sum()`, що мінімізує накладні витрати циклів мови.

## 4. Складність, чисельна стійкість та інженерні крайові випадки

При проектуванні високонавантажених бібліотек для роботи з характерами Діріхле слід враховувати такі інженерні фактори:

### 1. Асимптотична складність алгоритмів

| Етап обчислення | Складність за часом | Складність за пам'яттю |
| :--- | :--- | :--- |
| Генерація залишків `(ℤ/qℤ)*` | `O(q · log q)` | `O(φ(q))` |
| Факторизація `φ(q)` та пошук `g` | `O(q^{0.5} + \log(q) \cdot \log(φ(q)))` | `O(\log(φ(q)))` |
| Таблиця дискретного логарифма | `O(φ(q))` | `O(q)` |
| Заповнення матриці характерів | `O(φ(q)²)` | `O(φ(q)²)` |
| Перевірка провідників усіх `χ` | `O(d(q) · φ(q)²)` | `O(1)` додатково |
| Скалярний добуток двох характерів | `O(φ(q))` | `O(1)` |

де `d(q)` — кількість натуральних дільників числа `q`. Для великих модулів зберігання всієї матриці стає неефективним, тому замість матриці обчислюють значення `χₖ(n)` на льоту за час `O(log q)` через модульне піднесення до степеня індексу.

### 2. Чисельна стійкість та накопичення похибок IEEE 754

Обчислення комплексних експонент через `cos` та `sin` неминуче вносить похибку округлення порядку `1e-16` на одну операцію. При багаторазовому множенні або сумуванні по великому періоду `φ(q) > 10⁶` похибка накопичується за законом випадкового блукання `O(√φ(q) · ε_mach)`.

Для запобігання хибним спрацьовуванням:
1. Порівняння з 1 при пошуку провідника повинно використовувати адаптивний поріг `|χ(n) - 1| < 100 · φ(q) · ε_mach`.
2. В алгебраїчній криптографії замість чисел з плаваючою комою використовують **чисельно точні корені з одиниці** у скінченних розширеннях полів `𝔽_p[x] / (x^M - 1)` або кільцях цілих кругових полів `ℤ[ζ_q]`.

### 3. Швидке перетворення на характерах (Walsh-Hadamard та FFT)

Оскільки таблиця характерів циклічної групи `(ℤ/qℤ)*` є матрицею дискретного перетворення Фур'є (DFT) після перестановки стовпчиків за індексами `ind_g(n)`, спектральний аналіз довільного сигналу `x(n)` на групі залишків можна виконати за час `O(φ(q) · log(φ(q)))` за допомогою швидкого алгоритму Кулі-Тьюкі (FFT).

Для нециклічних 2-груп `(ℤ/2ᵏℤ)*` матриця характерів розпадається на тензорний добуток матриць Адамара другого порядку `H₂ = [[1, 1], [1, -1]]`, що дозволяє виконувати спектральне перетворення за алгоритмом **швидкого перетворення Волша-Адамара (FWHT)** без жодної операції множення — виключно операціями додавання та віднімання.

### 4. Крайові випадки модульної арифметики

* **Модуль `q = 2`:** `φ(2) = 1`, група містить єдиний елемент `{1}`, існує єдиний головний характер `χ₀(1) = 1`, провідник `d = 1`.
* **Модуль `q = 4`:** `φ(4) = 2`, `coprimes = [1, 3]`, два характери: головний `χ₀` (`cond=1`) та нетривіальний квадратичний характер `χ₁(1) = 1, χ₁(3) = -1` (`cond=4`, первісний).
* **Модуль `q = 8`:** Не має первісного кореня. Використання циклічного алгоритму безпосередньо призведе до помилки. Вимагає факторизації через базис `{-1 mod 8, 5 mod 8}`.
* **Непервісні індуковані характери:** Якщо для характеру `χ (mod q)` знайдено провідник `d < q`, його L-функція відрізняється від L-функції відповідного первісного характеру `χ* (mod d)` лише скінченним добутком Ейлерових множників за простими дільниками `p | q, p ∤ d`:
  ```
  L(s, χ) = L(s, χ*) · ∏_{p | q, p ∤ d} (1 - χ*(p) / pˢ)
  ```
  Це співвідношення є основою редукції аналітичних властивостей довільних L-функцій до первісних.

## 5. Факторизація за Китайською теоремою про залишки та тензорний добуток

Для загального складеного модуля `q`, який не є простим числом або степенем непарного простого, група `(ℤ/qℤ)*` не є циклічною, і знайти єдиний первісний корінь принципово неможливо. Розглянемо детальний алгоритм побудови характерів методом прямого розкладу на прикладі `q = 15 = 3 · 5`.

### 1. Канонічний розклад групи залишків

За Китайською теоремою про залишки (CRT), оскільки `gcd(3, 5) = 1`, маємо кільцевий ізоморфізм `ℤ/15ℤ ≅ ℤ/3ℤ × ℤ/5ℤ`. Обмежуючи це відображення на оборотні елементи, дістаємо ізоморфізм мультиплікативних груп:

```
(ℤ/15ℤ)* ≅ (ℤ/3ℤ)* × (ℤ/5ℤ)* ≅ C₂ × C₄
```

Порядок групи дорівнює `φ(15) = φ(3) · φ(5) = 2 · 4 = 8`. Приведена система залишків складається з 8 чисел:

```
G = {1, 2, 4, 7, 8, 11, 13, 14}
```

Кожному залишку `n ∈ G` однозначно відповідає пара залишків `(n₁ = n mod 3, n₂ = n mod 5)`:

| `n (mod 15)` | `n₁ = n mod 3` | `n₂ = n mod 5` |
| :---: | :---: | :---: |
| 1 | 1 | 1 |
| 2 | 2 | 2 |
| 4 | 1 | 4 |
| 7 | 1 | 2 |
| 8 | 2 | 3 |
| 11 | 2 | 1 |
| 13 | 1 | 3 |
| 14 | 2 | 4 |

### 2. Побудова фактор-характерів компонент

1. **Компонента за модулем 3 (`φ(3) = 2`):**
   Група `(ℤ/3ℤ)* = {1, 2}` породжується первісним коренем `g₁ = 2`.
   Вона має 2 характери:
   * `ψ₀ (mod 3)`: `ψ₀(1) = 1, ψ₀(2) = 1` (головний).
   * `ψ₁ (mod 3)`: `ψ₁(1) = 1, ψ₁(2) = -1` (первісний дійсний характер).

2. **Компонента за модулем 5 (`φ(5) = 4`):**
   Група `(ℤ/5ℤ)* = {1, 2, 3, 4}` породжується коренем `g₂ = 2`.
   Вона має 4 характери `λ₀, λ₁, λ₂, λ₃`, значення яких на елементах `{1, 2, 4, 3}` задаються степенями уявного числа `i`:
   * `λ₀`: `[1, 1, 1, 1]` (головний).
   * `λ₁`: `[1, i, -1, -i]` (первісний комплексний).
   * `λ₂`: `[1, -1, 1, -1]` (первісний дійсний).
   * `λ₃`: `[1, -i, -1, i]` (первісний комплексний, спряжений до `λ₁`).

### 3. Формування повної матриці характерів через Кронекерів добуток

Кожен характер `χ_{a, b} (mod 15)` для `a ∈ {0, 1}` та `b ∈ {0, 1, 2, 3}` обчислюється як добуток відповідних фактор-характерів:

```
χ_{a, b}(n) = ψ_a(n mod 3) · λ_b(n mod 5)
```

Матриця системи характерів за модулем 15 утворюється як тензорний добуток матриць:

```
M₁₅ = M₃ ⊗ M₅
```

Розглянемо класифікацію всіх 8 побудованих характерів за модулем 15:

| Характер | Формула | Провідник `d` | Тип характеру | Парність `χ(14)` | Дійсність |
| :--- | :--- | :---: | :--- | :---: | :--- |
| `χ_{0,0}` | `ψ₀ · λ₀` | 1 | Індукований (головний) | +1 (парний) | Дійсний |
| `χ_{1,0}` | `ψ₁ · λ₀` | 3 | Індукований з mod 3 | -1 (непарний) | Дійсний |
| `χ_{0,1}` | `ψ₀ · λ₁` | 5 | Індукований з mod 5 | -1 (непарний) | Комплексний |
| `χ_{0,2}` | `ψ₀ · λ₂` | 5 | Індукований з mod 5 | +1 (парний) | Дійсний |
| `χ_{0,3}` | `ψ₀ · λ₃` | 5 | Індукований з mod 5 | -1 (непарний) | Комплексний |
| `χ_{1,1}` | `ψ₁ · λ₁` | 15 | **Первісний** | +1 (парний) | Комплексний |
| `χ_{1,2}` | `ψ₁ · λ₂` | 15 | **Первісний** | -1 (непарний) | Дійсний |
| `χ_{1,3}` | `ψ₁ · λ₃` | 15 | **Первісний** | +1 (парний) | Комплексний |

Цей приклад наочно демонструє, як провідник добутку характерів дорівнює добутку їхніх провідників для взаємно простих модулів: `cond(ψ_a · λ_b) = cond(ψ_a) · cond(λ_b)`.

## 6. Алгоритми швидкого обчислення без збереження таблиць

У практичних задачах криптографії (криптосистеми на еліптичних кривих, перевірка простоти за алгоритмом Моріса-Пріста-Лежандра, протоколи з нульовим розголошенням) модулі `q` сягають 1024–4096 бітів. Створення та зберігання таблиці розміром `φ(q) × φ(q)` є фізично неможливим, оскільки вона вимагала б експоненційного обсягу пам'яті.

У таких сценаріях значення характерів обчислюються **динамічно (на льоту)** спеціалізованими алгоритмами.

### 1. Швидке обчислення квадратичних характерів через символ Якобі

Будь-який дійсний первісний характер `χ (mod q)` задається символом Кронекера-Якобі:

```
χ(n) = (D / n)
```

де `D` — фундаментальний дискримінант квадратичного поля (`D = q` або `-q`, `D ≡ 0, 1 (mod 4)`).

Алгоритм обчислення символу Якобі `(a / b)` не вимагає факторизації чисел `a` та `b`. Він спирається на три закони взаємності та за структурою є точним аналогом алгоритму Евкліда:

```
1. Винесення степенів двійки: Якщо a = 2ᵏ · a', то (a / b) = (2 / b)ᵏ · (a' / b),
   де (2 / b) = (-1)^{(b² - 1) / 8}.
2. Квадратичний закон взаємності: Якщо a' та b непарні додатні числа, то
   (a' / b) = (-1)^{(a' - 1)(b - 1) / 4} · (b / a' mod a').
3. Редукція: Обчислюємо нове a = b mod a' і повторюємо кроки 1–2, доки a > 0.
```

Бітова складність алгоритму обчислення символу Якобі становить `O(log(a) · log(b))` бітових операцій, що дозволяє миттєво обчислювати дійсні характери для тисячорозрядних чисел.

### 2. SIMD-оптимізація та апаратна векторизація

При обробці масивів великих сигналів у задачах цифрової фільтрації та спектрального перетворення на характерах застосовуються інструкції векторного розширення процесора (Intel AVX-512 або ARM NEON):

* **Структура даних Structure of Arrays (SoA):** Замість масиву комплексних структур `Complex` (де дійсна та уявна частини чергуються в пам'яті як `real, imag, real, imag`), дані розміщуються у двох окремих вирівняних масивах: `double real_part[]` та `double imag_part[]`.
* **Векторний скалярний добуток:** Інструкція FMA (Fused Multiply-Add, наприклад `_mm512_fmadd_pd`) виконує множення 8 пар дійсних чисел подвійної точності за один машинний такт:
  ```
  sum_real = _mm512_fmadd_pd(a_real, b_real, _mm512_fmadd_pd(a_imag, b_imag, sum_real));
  sum_imag = _mm512_fmadd_pd(a_imag, b_real, _mm512_fmsub_pd(a_real, b_imag, sum_imag));
  ```
* **Швидкість обробки:** Застосування SoA-структури разом із AVX-512 забезпечує прискорення обчислення рядків матриці характерів у 6.8–7.4 раза порівняно з базовою скалярною версією, практично досягаючи пропускної здатності шини оперативної пам'яті DDR5.

## 7. Підсумкові висновки для розробника

1. **Для малих модулів (`q < 1000`):** Оптимальною є повна попередня генерація таблиці через дискретний логарифм у пам'яті (парадигма C++ `std::vector<std::complex<double>>`), що гарантує доступ `O(1)` під час спектрального аналізу.
2. **Для складених модулів:** Необхідно застосовувати факторизацію CRT та Кронекерів добуток матриць замість наївного перебору генераторів.
3. **Для квадратичних характерів великих чисел:** Слід використовувати алгоритм символу Якобі `O(log² q)` без факторизації модуля та без комплексних чисел з плаваючою комою.
4. **Для аналітичних перевірок:** Алгоритм обов'язково повинен підтверджувати як ортогональність за рядками, так і ортогональність за стовпчиками, а також точне значення провідника для коректного зведення L-функції до первісного ядра.

## 8. Мультиплікативна згортка та спектральна обробка сигналів на групах залишків

Одне з найважливіших інженерних застосувань таблиць характерів Діріхле — розв'язання рівнянь мультиплікативної дискретної згортки на скінченній групі `G = (ℤ/qℤ)*`.

### 1. Означення групової згортки

Для двох дискретних числових сигналів (або арифметичних розподілів ймовірностей) `f, g: G → ℂ` операція мультиплікативної групової згортки `f * g` визначається як зважена сума за всіма парними добутками в групі:

```
(f * g)(n) = ∑_{m ∈ G} f(m) · g(n · m⁻¹ mod q)
```

Пряме обчислення такої згортки для всіх `n ∈ G` наївним перебором вимагає `O(|G|²) = O(φ(q)²)` операцій комплексного множення.

### 2. Теорема про згортку у базисі характерів

Визначимо дискретне перетворення Фур'є функції `f` у базисі характерів Діріхле (спектральний образ) як:

```
f̂(χ) = ∑_{n ∈ G} f(n) · χ̄(n)
```

Завдяки співвідношенням ортогональності та мультиплікативності `χ̄(n · m⁻¹) = χ̄(n) · χ(m)`, спектральний образ згортки двох функцій точно дорівнює точковому добутку їхніх спектральних образів:

```
(f * g)^̂(χ) = f̂(χ) · ĝ(χ)
```

Відновлення вихідного сигналу здійснюється за формулою оберненого перетворення Фур'є:

```
(f * g)(n) = (1 / φ(q)) · ∑_{χ ∈ Ĝ} (f * g)^̂(χ) · χ(n)
```

### 3. Алгоритмічний конвеєр швидкої фільтрації

Завдяки спектральній теоремі розрахунок складної взаємної кореляції або фільтрації розподілу ймовірностей зводиться до трикрокового конвеєра:

```
f(n), g(n)  ──[ Швидке перетворення Фур'є на харакетрах ]──>  f̂(χ), ĝ(χ)
                                                                 │
                                                   (поточкове множення f̂ · ĝ)
                                                                 │
                                                                 ▼
(f * g)(n)  <──[ Обернене перетворення Фур'є ]─────────────────  ĥ(χ) = f̂(χ) · ĝ(χ)
```

Застосування швидкого алгоритму розкладу на циклічні компоненти знижує часову складність фільтрації з `O(φ(q)²)` до `O(φ(q) · log(φ(q)))`. Цей підхід є базовим при аналізі криптографічної стійкості генераторів псевдовипадкових чисел (зокрема алгоритму Блюма-Блюма-Шуба) та оцінці мультиплікативного бітового зміщення в сучасних шифрах.

## 9. Методологія автоматизованого тестування та валідації

Для гарантії надійності обчислювального ядра бібліотеки характерів Діріхле розробляється набір обов'язкових модульних тестів (unit tests):

1. **Тест на унітарність матриці та детермінант:**
   Оскільки матриця характерів `M` розміром `φ(q) × φ(q)` задовольняє співвідношення ортогональності `M · M* = φ(q) · I`, її визначник за абсолютною величиною строго дорівнює:
   ```
   |det(M)| = φ(q)^{φ(q) / 2}
   ```
   Обчислення визначника методом LU-розкладу з чисельним похибковим допуском слугує глобальним інваріантом правильності всіх фаз і знаків.

2. **Тест на слід матриці (Trace):**
   Сума діагональних елементів матриці `Tr(M) = ∑_{k=0}^{φ(q)-1} χ_k(coprimes[k])` для канонічно впорядкованої групи перевіряє правильність індексації дискретних логарифмів.

3. **Стрес-тестування на крайових модулях:**
   Автоматичний прогін на модулях `q ∈ {2, 3, 4, 5, 8, 9, 12, 15, 16, 24, 60}` охоплює всі класи симетрій: прості числа, квадрати простих, парні степені двійки з нециклічною структурою та багаторазові прямі добутки. Повна перевірка умов ортогональності на кожному з цих модулів гарантує відсутність прихованих дефектів у продакшен-коді.
