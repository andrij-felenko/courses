# Математика економічності систем числення

Коли ми розробляємо обчислювальні системи, одним із фундаментальних питань є вибір основи системи числення (radix). Чому ми використовуємо двійкову систему? Чи є вона найкращою з математичної точки зору? Щоб відповісти на це запитання, ми повинні ввести поняття «економічності» або «апаратурних витрат» (radix economy) системи числення.

Уявіть, що ми хочемо представити число N у системі числення з основою b. Скільки розрядів (або цифр) нам для цього знадобиться? Ширина числа W, тобто кількість розрядів, визначається як логарифм N за основою b:

W ≈ log_b(N)

З математики відомо, що логарифм за будь-якою основою можна виразити через натуральний логарифм (ln):
log_b(N) = ln(N) / ln(b)

Тепер подумаємо про апаратні витрати. Щоб фізично реалізувати один розряд у системі з основою b, нам потрібен апаратний елемент, який може перебувати у b різних станах (наприклад, тригер із 2 станами для двійкової, або елемент із 3 станами для трійкової). Тож витрати на один розряд прямо пропорційні основі b.
Загальна апаратурна складність (або економічність) E для представлення числа N обчислюється як добуток кількості розрядів на кількість станів в одному розряді:

E(b) = W × b ≈ b × (ln(N) / ln(b))

Оскільки число N є константою (якусь конкретну кількість інформації ми хочемо зберегти), економічність системи залежить лише від функції:

f(b) = b / ln(b)

Наша мета — знайти таке значення b, при якому функція f(b) досягає свого мінімуму (чим менші витрати, тим краща система). Для цього застосуємо методи математичного аналізу: знайдемо похідну функції f(b) і прирівняємо її до нуля.

Похідна дробу (u/v)' = (u'v - uv') / v².
Тут u = b, v = ln(b).
u' = 1
v' = 1/b

f'(b) = (1 × ln(b) - b × (1/b)) / (ln(b))²
f'(b) = (ln(b) - 1) / (ln(b))²

Щоб похідна дорівнювала нулю, чисельник має дорівнювати нулю (за умови, що знаменник не нуль, а отже b ≠ 1):

ln(b) - 1 = 0
ln(b) = 1

Єдине число, натуральний логарифм якого дорівнює 1 — це основа натурального логарифма, число Непера e (e ≈ 2.71828...).
Отже, теоретично найоптимальнішою основою для системи числення є ірраціональне число e. Звісно, на практиці ми не можемо створити апаратний елемент із дробовою кількістю станів. Ми повинні обрати ціле число, найближче до e.

Спробуймо порівняти двійкову (b = 2) та трійкову (b = 3) системи:
Для b = 2:
f(2) = 2 / ln(2) ≈ 2 / 0.693 ≈ 2.885

Для b = 3:
f(3) = 3 / ln(3) ≈ 3 / 1.098 ≈ 2.732

Для b = 4:
f(4) = 4 / ln(4) ≈ 4 / 1.386 ≈ 2.885

Як бачимо, f(3) = 2.732 є найменшим значенням серед цілих чисел. Трійкова система числення (b = 3) найближча до ідеального числа e. Вона приблизно на 5.3% економічніша за двійкову систему (2.885 проти 2.732). Це означає, що для зберігання тієї ж кількості інформації трійкова система потребує менше апаратних ресурсів. Ця математична елегантність і стала головним аргументом на користь розробки комп'ютера «Сетунь».
