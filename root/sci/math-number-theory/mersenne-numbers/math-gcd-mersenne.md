# 🧮 Алгебраїчні властивості дільників та теореми про НСД чисел Мерсенна

Числа Мерсенна `M♞ = 2ⁿ − 1` демонструють унікальний математичний феномен: алгебраїчні зв'язки між показниками степеня `n` точно віддзеркалюються на самих числах. Найглибшим проявом цього паралелізму є теорема про найбільший спільний дільник (НСД), яка стверджує, що операція `n ↦ 2ⁿ − 1` переносить адитивну структуру дільників показників у мультиплікативну структуру дільників самих чисел.

Алгебра дільників чисел Мерсенна спирається на чотири взаємопов'язані фундаментальні принципи:
1. Теорему про збереження НСД `НСД(2ᵃ − 1, 2ᵇ − 1) = 2^(НСД(a, b)) − 1` та її індуктивний доказ через крок алгоритму Евкліда.
2. Поліноміальне узагальнення для довільної цілочисельної основи `q ≥ 2`, кільця многочленів `Z[x]`, лінійного співвідношення Безу та теорії сильних роздільних послідовностей.
3. Канонічний розклад за круговими многочленами `Φ_d(x)` та взаємну простоту їхніх числових значень.
4. Структуру первинних дільників Зігмонді та систему конгруенцій `q = 2kp + 1`, `q ≡ ±1 (mod 8)`.

## 1. Теорема про НСД чисел Мерсенна та індуктивний механізм алгоритму Евкліда

### Формулювання теореми

Для будь-яких двох натуральних чисел `a` та `b` найбільший спільний дільник відповідних чисел Мерсенна дорівнює числу Мерсенна, показник якого є найбільшим спільним дільником самих показників `a` та `b`:

```
НСД(2ᵃ − 1, 2ᵇ − 1) = 2^(НСД(a, b)) − 1
```

Або в скороченому записі через позначення чисел Мерсенна: `НСД(M␁, M_b) = M_(НСД(a, b))`.

### Лема про алгебраїчну остачу ділення

Доведення теореми базується на точній відповідності між діленням показників з остачею та діленням самих чисел Мерсенна.

Нехай `a` та `b` — довільні натуральні числа (`a ≥ b`). За класичною теоремою про ділення цілих чисел з остачею, існують єдині цілі невід'ємні числа — частка `k` та остача `r` (`0 ≤ r < b`), такі що:

```
a = k · b + r
```

Розкладемо вираз `2ᵃ − 1`, підставивши це розбиття показника:

```
2ᵃ − 1
= 2^(k·b + r) − 1                         [підстановка ділення показників a = k·b + r]
= 2ʳ · 2^(k·b) − 1                        [властивість степеня: 2^(X+Y) = 2ˣ · 2ʸ]
= 2ʳ · 2^(k·b) − 2ʳ + 2ʳ − 1              [штучне додавання та віднімання 2ʳ]
= 2ʳ · (2^(k·b) − 1) + (2ʳ − 1)           [винесення спільного множника 2ʳ за дужки]
```

Розглянемо доданок `2^(k·b) − 1`. За алгебраїчною тотожністю розкладу різниці степенів `xᵏ − 1 = (x − 1) · (xᵏ⁻¹ + xᵏ⁻² + … + x + 1)` для змінної `x = 2ᵇ`, маємо:

```
2^(k·b) − 1
= (2ᵇ)ᵏ − 1                               [властивість степеня: 2^(k·b) = (2ᵇ)ᵏ]
= (2ᵇ − 1) · ((2ᵇ)ᵏ⁻¹ + (2ᵇ)ᵏ⁻² + … + 2ᵇ + 1) [розклад різниці k-их степеней]
```

Позначимо суму цілих степеней `((2ᵇ)ᵏ⁻¹ + (2ᵇ)ᵏ⁻² + … + 2ᵇ + 1)` як ціле число `S`. Тоді:

```
2^(k·b) − 1 = (2ᵇ − 1) · S
```

Підставимо цей вираз назад у розклад `2ᵃ − 1`:

```
2ᵃ − 1
= 2ʳ · (2ᵇ − 1) · S + (2ʳ − 1)            [підстановка виразу для 2^(k·b) − 1]
= (2ʳ · S) · (2ᵇ − 1) + (2ʳ − 1)          [перегрупування цілих множників]
```

Позначивши цілий коефіцієнт `2ʳ · S` як частку `Q`, отримуємо точне рівняння:

```
2ᵃ − 1 = Q · (2ᵇ − 1) + (2ʳ − 1)
```

Оскільки за умовою ділення показників `0 ≤ r < b`, оцінимо величину доданка `2ʳ − 1`:

```
0 ≤ 2ʳ − 1 < 2ᵇ − 1                       [монотонне зростання функції 2ˣ − 1 для 0 ≤ r < b]
```

Оскільки вираз `2ʳ − 1` є цілим невід'ємним числом і строго меншим за дільник `2ᵇ − 1`, за єдиністю ділення цілих чисел з остачею число `2ʳ − 1` є **точною математичною остачею** від ділення `2ᵃ − 1` на `2ᵇ − 1`:

```
(2ᵃ − 1) mod (2ᵇ − 1) = 2^(a mod b) − 1
```

### Редукція найбільшого спільного дільника

Для будь-яких двох цілих чисел `X` та `Y` (де `Y > 0`) ділення з остачею `X = Q · Y + R` зберігає множину всіх спільних дільників пари:

```
НСД(X, Y) = НСД(Y, R) = НСД(Y, X mod Y)
```

Застосуємо цю фундаментальну властивість до чисел `X = 2ᵃ − 1` та `Y = 2ᵇ − 1`. Оскільки остача `R = 2ʳ − 1`, де `r = a mod b`, маємо:

```
НСД(2ᵃ − 1, 2ᵇ − 1) = НСД(2ᵇ − 1, 2ʳ − 1)
```

Ця рівність демонструє повний структурний паралелізм: один крок алгоритму Евкліда над числами Мерсенна `(2ᵃ − 1, 2ᵇ − 1)` точно відповідає одному кроку алгоритму Евкліда над їхніми показниками `(a, b)`.

### Строге доведення за математичною індукцією

Проведемо строге індуктивне доведення тотожності `НСД(2ᵃ − 1, 2ᵇ − 1) = 2^(НСД(a, b)) − 1` за принципом повної математичної індукції за величиною меншого показника `b ≥ 1`.

**База індукції.**

Нехай `b` ділить `a` без остачі (`b | a`). Тоді остача від ділення показників дорівнює нулю: `r = a mod b = 0`.

Обчислимо остачу чисел Мерсенна:

```
2ʳ − 1 = 2⁰ − 1 = 1 − 1 = 0
```

Підставляючи `r = 0` в рівняння ділення, маємо:

```
2ᵃ − 1 = Q · (2ᵇ − 1) + 0                 [рівняння ділення при r = 0]
```

Звідси число `2ᵇ − 1` ділить `2ᵃ − 1` без остачі (`(2ᵇ − 1) | (2ᵃ − 1)`). Отже, найбільший спільний дільник пари дорівнює меншому числу:

```
НСД(2ᵃ − 1, 2ᵇ − 1) = 2ᵇ − 1
```

З іншого боку, оскільки `b | a`, найбільший спільний дільник показників дорівнює `НСД(a, b) = b`. Підставляючи це у формулу теореми, отримуємо:

```
2^(НСД(a, b)) − 1 = 2ᵇ − 1
```

Значення обох частин тотожно збігаються. Базу індукції доведено.

**Індукційний перехід.**

Припустимо, що твердження теореми вже доведено для всіх пар показників `(x, y)`, у яких другий аргумент строго менший за `b` (тобто для всіх `y < b`).

Розглянемо довільну пару `(a, b)`. Якщо `b | a`, випадок вичерпується базою індукції. Якщо ж `b` не ділить `a`, то остача `r = a mod b` задовольняє сувору нерівність:

```
0 < r < b
```

За доведеною вище формулою редукції НСД маємо:

```
НСД(2ᵃ − 1, 2ᵇ − 1) = НСД(2ᵇ − 1, 2ʳ − 1)
```

Оскільки `r < b`, для пари показників `(b, r)` виконується індукційне припущення. Застосовуючи його до правої частини рівності, отримуємо:

```
НСД(2ᵇ − 1, 2ʳ − 1) = 2^(НСД(b, r)) − 1    [за індукційним припущенням, бо r < b]
```

За класичною властивістю одного кроку алгоритму Евкліда для показників маємо тотожність `НСД(a, b) = НСД(b, r)`. Підставивши її в показник степеня, отримуємо остаточний висновок:

```
2^(НСД(b, r)) − 1 = 2^(НСД(a, b)) − 1
```

Отже, рівність `НСД(2ᵃ − 1, 2ᵇ − 1) = 2^(НСД(a, b)) − 1` виконується і для пари `(a, b)`. Індукційний перехід повністю завершено.

За принципом математичної індукції теорема справедлива для всіх натуральних чисел `a, b ∈ N`.

### Покроковий ланцюг ділень: числовий розбір

Проілюструємо повний ланцюг евклідових ділень на конкретних числових прикладах.

#### Приклад 1: a = 35 та b = 10

**Алгоритм Евкліда на показниках (a = 35, b = 10):**

```
35 = 3 · 10 + 5                           [частка k₁ = 3, остача r₁ = 5]
10 = 2 · 5 + 0                            [частка k₂ = 2, остача r₂ = 0]
```

Остання ненульова остача дорівнює `r₁ = 5`. Отже, `НСД(35, 10) = 5`.

**Паралельний алгоритм Евкліда на числах Мерсенна:**

Обчислимо значення чисел Мерсенна:
- `M₃₅ = 2³⁵ − 1 = 34359738367`
- `M₁₀ = 2¹⁰ − 1 = 1023`
- `M₅ = 2⁵ − 1 = 31`

Виконуємо перший крок ділення з остачею:

```
2³⁵ − 1 = Q₁ · (2¹⁰ − 1) + (2⁵ − 1)
34359738367 = 33587232 · 1023 + 31        [частка Q₁ = 2⁵ · (2²⁰ + 2¹⁰ + 1) = 33587232, остача 31]
```

Оскільки остача `31 < 1023`, за редукцією НСД:

```
НСД(2³⁵ − 1, 2¹⁰ − 1) = НСД(1023, 31)
```

Виконуємо другий крок ділення з остачею:

```
2¹⁰ − 1 = Q₂ · (2⁵ − 1) + 0
1023 = 33 · 31 + 0                        [частка Q₂ = 2⁵ + 1 = 33, остача 0]
```

Остання ненульова остача в ланцюгу дорівнює `31 = 2⁵ − 1`.

Отже, `НСД(2³⁵ − 1, 2¹⁰ − 1) = 31 = 2^(НСД(35, 10)) − 1`.

#### Приклад 2: a = 24 та b = 18

**Алгоритм Евкліда на показниках (a = 24, b = 18):**

```
24 = 1 · 18 + 6                           [частка k₁ = 1, остача r₁ = 6]
18 = 3 · 6 + 0                            [частка k₂ = 3, остача r₂ = 0]
```

Остання ненульова остача: `r₁ = 6 ⇒ НСД(24, 18) = 6`.

**Паралельний ланцюг на числах Мерсенна:**
- `M₂₄ = 2²⁴ − 1 = 16777215`
- `M₁₈ = 2¹⁸ − 1 = 262143`
- `M₆ = 2⁶ − 1 = 63`

Крок 1: `16777215 = 64 · 262143 + 63` (остача `63 = 2⁶ − 1`).
Крок 2: `262143 = 4161 · 63 + 0` (остача `0`).

Результат: `НСД(M₂₄, M₁₈) = 63 = M₆ = 2^(НСД(24, 18)) − 1`.

## 2. Узагальнення для довільної основи q > 1, кільця Z[x], тотожності Безу та сильних роздільних послідовностей

### Теорема для репунітів за основою q

Алгебраїчний механізм теореми про НСД не залежить від двійкової природи основи і природно узагальнюється на довільне ціле число `q ≥ 2`.

Для будь-якого цілого числа `q ≥ 2` та будь-яких натуральних чисел `a, b ∈ N` виконується тотожність:

```
НСД(qᵃ − 1, qᵇ − 1) = q^(НСД(a, b)) − 1
```

**Строге виведення.**

Нехай `a = k · b + r`, де `k ≥ 0` та `0 ≤ r < b`. Розкладемо різницю `qᵃ − 1`:

```
qᵃ − 1
= q^(k·b + r) − 1                         [підстановка ділення a = k·b + r]
= qʳ · q^(k·b) − 1                        [властивість степеня q^(X+Y) = qˣ · qʸ]
= qʳ · q^(k·b) − qʳ + qʳ − 1              [додавання та віднімання qʳ]
= qʳ · (q^(k·b) − 1) + (qʳ − 1)           [винесення qʳ за дужки]
```

Розкладаючи `q^(k·b) − 1 = (qᵇ)ᵏ − 1` як різницю `k`-их степеней, отримуємо:

```
q^(k·b) − 1 = (qᵇ − 1) · ((qᵇ)ᵏ⁻¹ + (qᵇ)ᵏ⁻² + … + qᵇ + 1)
```

Позначивши ціле число `qʳ · ((qᵇ)ᵏ⁻¹ + … + 1)` як `Q_q`, маємо:

```
qᵃ − 1 = Q_q · (qᵇ − 1) + (qʳ − 1)
```

Оскільки `q ≥ 2` та `0 ≤ r < b`, степінь задовольняє нерівність:

```
0 ≤ qʳ − 1 < qᵇ − 1
```

Отже, `(qᵃ − 1) mod (qᵇ − 1) = qʳ − 1`. За повною аналогією з індуктивним доведенням для двійки, алгоритм Евкліда на показниках `(a, b)` повністю переноситься на числа `(qᵃ − 1, qᵇ − 1)`.

### Поліноміальний НСД у кільці Z[x]

Розглянемо кільце многочленів з цілими коефіцієнтами `Z[x]`. Для довільних натуральних чисел `a, b ∈ N` вираз `xⁿ − 1` є унітарним (нормованим) многочленом степеня `n`.

У кільці `Z[x]` виконується поліноміальна теорема про НСД:

```
НСД(xᵃ − 1, xᵇ − 1) = x^(НСД(a, b)) − 1
```

**Доведення через евклідове ділення многочленів.**

Нехай `a = k · b + r` (`0 ≤ r < b`). Запишемо тотожність у кільці `Z[x]`:

```
xᵃ − 1
= x^(k·b + r) − 1                         [підстановка показника a = k·b + r]
= xʳ · (x^(k·b) − 1) + (xʳ − 1)           [алгебраїчне перегрупування]
= xʳ · (xᵇ − 1) · ((xᵇ)ᵏ⁻¹ + … + 1) + (xʳ − 1) [розклад різниці степеней]
```

Позначимо многочлен `Q(x) = xʳ · ((xᵇ)ᵏ⁻¹ + (xᵇ)ᵏ⁻² + … + 1) ∈ Z[x]`. Тоді:

```
xᵃ − 1 = Q(x) · (xᵇ − 1) + (xʳ − 1)
```

Оскільки степінь остачі `deg(xʳ − 1) = r`, а степінь дільника `deg(xᵇ − 1) = b`, і за умовою `r < b`, многочлен `xʳ − 1` є **остачею від ділення многочлена `xᵃ − 1` на `xᵇ − 1`** у кільці `Z[x]`:

```
deg(xʳ − 1) < deg(xᵇ − 1)
```

Отже, евклідове ділення многочленів `xᵃ − 1` та `xᵇ − 1` крок за кроком повторює алгоритм Евкліда для цілих показників `a` та `b`. Останнім ненульовим многочленом у ланцюгу буде `x^(НСД(a, b)) − 1`.

### Співвідношення Безу для многочленів та чисел Мерсенна

За розширеним алгоритмом Евкліда для показників `a` та `b` існують такі цілі коефіцієнти Безу `u` та `v`, що:

```
a · u + b · v = g = НСД(a, b)
```

У кільці многочленів `Q[x]` це породжує відповідне поліноміальне лінійне представлення Безу: існують такі многочлени `A(x), B(x) ∈ Q[x]`, що:

```
A(x) · (xᵃ − 1) + B(x) · (xᵇ − 1) = x^(НСД(a, b)) − 1
```

Підставляючи в цю рівність `x = 2`, отримуємо безпосереднє лінійне співвідношення для чисел Мерсенна, що підтверджує: будь-який спільний дільник чисел `2ᵃ − 1` та `2ᵇ − 1` обов'язково ділить число `2^(НСД(a, b)) − 1`.

### Ізоморфізм ґраток дільників та теорема про НСК

Множина натуральних чисел `N` утворює дистрибутивну ґратку відносно операцій найбільшого спільного дільника та найменшого спільного кратного `⟨N, НСД, НСК⟩`.

Оскільки відображення `n ↦ 2ⁿ − 1` зберігає операцію НСД, воно є монотонним гомоморфізмом напівґраток. Для операції найменшого спільного кратного (НСК) виконується теорема:

```
НСК(2ᵃ − 1, 2ᵇ − 1) = (2ᵃ − 1) · (2ᵇ − 1) / (2^(НСД(a, b)) − 1)
```

**Приклад обчислення НСК для a = 4 та b = 6:**
- `M₄ = 2⁴ − 1 = 15`
- `M₆ = 2⁶ − 1 = 63`
- `НСД(4, 6) = 2 ⇒ НСД(M₄, M₆) = 2² − 1 = 3`
- `НСК(15, 63) = (15 · 63) / 3 = 945 / 3 = 315`

### Поняття сильної роздільної послідовності

У загальній теорії чисел числова послідовність `(uₙ)ₙ≥₁` називається:
1. **Роздільною послідовністю (Divisibility Sequence):** якщо з умови `a | b` випливає подільність `uₐ | u_b`.
2. **Сильною роздільною послідовністю (Strong Divisibility Sequence):** якщо для будь-яких `a, b ∈ N` виконується тотожність `НСД(uₐ, u_b) = u_(НСД(a, b))`.

Числа Мерсенна `uₙ = 2ⁿ − 1` є найважливішим прикладом сильної роздільної послідовності. Іншим класичним прикладом є послідовність чисел Фібоначчі `Fₙ`, для якої також виконується тотожність `НСД(Fₐ, F_b) = F_(НСД(a, b))`. На відміну від них, послідовність чисел Ферма `Fₙ = 2^(2ⁿ) + 1` не є сильною роздільною послідовністю, але володіє іншою унікальною властивістю — попарною взаємною простотою `НСД(Fₙ, F_m) = 1` для будь-яких `n ≠ m`.

### Наслідок для десяткових репунітів

У десятковій системі числення числа, що складаються з `n` одиниць, називаються репунітами `R♞`:

```
R♞ = 11…1₁₀ = (10ⁿ − 1) / 9
```

Застосовуючи теорему для основи `q = 10`, маємо:

```
НСД(10ᵃ − 1, 10ᵇ − 1) = 10^(НСД(a, b)) − 1
```

Поділивши обидві частини на 9, отримуємо теорему про НСД десяткових репунітів:

```
НСД(R␁, R_b) = R_(НСД(a, b))
```

**Приклад:** Для `a = 6` (`R₆ = 111111`) та `b = 4` (`R₄ = 1111`):

```
НСД(6, 4) = 2
НСД(111111, 1111) = R₂ = 11
```

Перевірка діленням: `111111 = 101 · 1111 + 0` (не ділиться без остачі), `111111 = 10101 · 11`, `1111 = 101 · 11`. Справді, `НСД(111111, 1111) = 11`.

## 3. Зв'язок із круговими многочленами Φ_d(x) та взаємна простота дільників

### Кругові многочлени та розклад xⁿ − 1

Глибша алгебраїчна природа чисел Мерсенна розкривається через теорію кругових многочленів (циклотомічних поліномів) `Φ_d(x)`.

**Означення:** `d`-й круговий многочлен `Φ_d(x)` — це унітарний многочлен із цілими коефіцієнтами, коренями якого є всі первісні комплексні корені `d`-го степеня з одиниці:

```
Φ_d(x) = ∏_{k=1, НСД(k, d)=1}^d (x − e^(2πi · k / d))
```

Степінь кругового многочлена дорівнює значенню функції Ейлера: `deg(Φ_d(x)) = φ(d)`.

Оскільки кожен із `n` комплексних коренів рівняння `xⁿ − 1 = 0` є первісним коренем степеня `d` для деякого єдиного дільника `d | n`, многочлен `xⁿ − 1` розкладається на незвідні множники над полем раціональних чисел `Q` (і кільцем `Z`):

```
xⁿ − 1 = ∏_{d | n} Φ_d(x)
```

Застосовуючи формулу обернення Мебіуса (Mobius Inversion Formula) до цієї мультиплікативної рівності, отримуємо явний вираз для `Φ_n(x)`:

```
Φ_n(x) = ∏_{d | n} (x^(n / d) − 1)^μ(d)
```

де `μ(d)` — функція Мебіуса (`μ(1) = 1`, `μ(d) = (−1)ᵏ` для вільних від квадратів чисел із `k` простими дільниками, і `μ(d) = 0`, якщо `d` ділиться на квадрат простого числа).

### Мультиплікативна структура Φ_d(2)

Підставивши `x = 2` у поліноміальний розклад, отримуємо точний числовий розклад числа Мерсенна на кругові компоненти:

```
2ⁿ − 1 = ∏_{d | n} Φ_d(2)
```

Обчислимо перші кілька кругових многочленів та їхні числові значення при `x = 2`:

```
Φ₁(x) = x − 1                    ⇒  Φ₁(2) = 2 − 1 = 1
Φ₂(x) = x + 1                    ⇒  Φ₂(2) = 2 + 1 = 3
Φ₃(x) = x² + x + 1               ⇒  Φ₃(2) = 4 + 2 + 1 = 7
Φ₄(x) = x² + 1                   ⇒  Φ₄(2) = 4 + 1 = 5
Φ₆(x) = x² − x + 1               ⇒  Φ₆(2) = 4 − 2 + 1 = 3
Φ₈(x) = x⁴ + 1                   ⇒  Φ₈(2) = 16 + 1 = 17
Φ₁₂(x) = x⁴ − x² + 1             ⇒  Φ₁₂(2) = 16 − 4 + 1 = 13
```

Розглянемо повний круговий розклад для `n = 12` (дільники `d ∈ {1, 2, 3, 4, 6, 12}`):

```
M₁₂ = 2¹² − 1 = 4095
4095 = Φ₁(2) · Φ₂(2) · Φ₃(2) · Φ₄(2) · Φ₆(2) · Φ₁₂(2)
4095 = 1 · 3 · 7 · 5 · 3 · 13 = 3² · 5 · 7 · 13
```

### Взаємна простота кругових множників

Дослідимо питання: за яких умов числові значення `Φ_a(2)` та `Φ_b(2)` для різних індексів `a ≠ b` мають спільний простий дільник?

**Теорема про спільні дільники значень кругових многочленів.**

Нехай `a` та `b` — різні натуральні числа (`a ≠ b`), а `p` — спільний простий дільник чисел `Φ_a(2)` та `Φ_b(2)`:

```
p | Φ_a(2)   і   p | Φ_b(2)
```

Тоді:
1. Мультиплікативний порядок двійки за модулем `p` (`ord_p(2) = d`) ділить найбільший спільний дільник `g = НСД(a, b)`.
2. Число `p` є єдиним можливим простим дільником відношення `a / g` (або `b / g`), і при цьому `p` ділить індекс `a` (або `b`).
3. Якщо частки `a / g` та `b / g` не є степенями простого числа `p`, то `НСД(Φ_a(2), Φ_b(2)) = 1`.

**Строге доведення.**

Оскільки `Φ_a(2) | (2ᵃ − 1)` та `Φ_b(2) | (2ᵇ − 1)`, спільний простий дільник `p` ділить обидва числа Мерсенна:

```
p | (2ᵃ − 1)   ⇒   2ᵃ ≡ 1 (mod p)
p | (2ᵇ − 1)   ⇒   2ᵇ ≡ 1 (mod p)
```

За теоремою про НСД чисел Мерсенна маємо:

```
p | НСД(2ᵃ − 1, 2ᵇ − 1) = 2^(НСД(a, b)) − 1
```

Нехай `g = НСД(a, b)`, а `d = ord_p(2)` — мультиплікативний порядок двійки в мультиплікативній групі поля `F_p`. Тоді `d` обов'язково ділить `g`:

```
d | g   ⇒   d | a   і   d | b
```

З теорії кругових полів відомо: умова `p | Φ_m(2)` означає, що або `ord_p(2) = m` (первинний дільник), або `m / ord_p(2)` є степенем простого числа `p`, і тоді `p | m`.

Застосуємо цю властивість до індексів `a` та `b`:
- Якщо `d = a`, то оскільки `d | b` і `d ≤ b`, при `a ≠ b` маємо `d < b`. Отже, для індексу `b` порядок `d < b`, звідки `b / d` мусить бути степенем числа `p`, тобто `p | b`.
- Якщо `d < a` та `d < b`, то `a / d` та `b / d` є степенями числа `p`, отже `p | a` та `p | b`.

Звідси випливає фундаментальний висновок: **значення кругових многочленів `Φ_a(2)` та `Φ_b(2)` можуть мати спільний простий дільник `p` лише тоді, коли `p` ділить самі індекси `a` або `b`**.

У всіх інших випадках (зокрема, коли `НСД(a, b) = 1` або коли прості дільники не входять до складу індексів):

```
НСД(Φ_a(2), Φ_b(2)) = 1
```

Це пояснює, чому розклад числа Мерсенна `2ⁿ − 1 = ∏_{d | n} Φ_d(2)` розбиває його на практично попарно взаємно прості алгебраїчні блоки.

## 4. Наслідки для простоти чисел Мерсенна: необхідність та недостатність

### Необхідна умова: обов'язкова простота показника

Фундаментальним наслідком теореми про подільність та НСД чисел Мерсенна є базовий критерій простоти:

**Теорема (Необхідна умова простоти).**

Якщо число Мерсенна `M♞ = 2ⁿ − 1` є **простим**, то його показник степеня `n` обов'язково є **простим числом**.

**Строге алгебраїчне доведення методом контрапозиції.**

Доведемо твердження методом від супротивного. Припустимо протилежне: нехай число `M♞ = 2ⁿ − 1` є простим, але його показник `n` є складеним числом.

Оскільки `n` складене, воно розкладається у добуток двох натуральних чисел, строго більших за одиницю:

```
n = a · b,   де   1 < a < n   і   1 < b < n
```

Оскільки `a` є дільником `n` (`a | n`), за теоремою про НСД чисел Мерсенна:

```
НСД(2ᵃ − 1, 2ⁿ − 1) = 2^(НСД(a, n)) − 1 = 2ᵃ − 1
```

Це означає, що число `2ᵃ − 1` ділить число `2ⁿ − 1` без остачі:

```
(2ᵃ − 1) | (2ⁿ − 1)
```

Оцінимо строго величину цього дільника `2ᵃ − 1`:
1. Оскільки `a > 1`, за монотонністю показникової функції: `2ᵃ − 1 > 2¹ − 1 = 1`.
2. Оскільки `a < n`, за монотонністю показникової функції: `2ᵃ − 1 < 2ⁿ − 1`.

Отже, число `2ᵃ − 1` є **власним (нетривіальним) дільником** числа `2ⁿ − 1`, тобто дільником, який строго більший за `1` і строго менший за саме число `2ⁿ − 1`.

За класичним означенням простого числа, просте число не може мати жодних власних дільників, крім `1` та самого себе. Отримана суперечність доводить хибність припущення.

Отже, якщо `2ⁿ − 1` просте, показник `n` обов'язково є простим числом.

### Недостатність: відсутність алгебраїчних дільників проти арифметичних

Умова простоти показника `n = p` є **необхідною, але не достатньою**: якщо `p` — просте число, число `Mₚ = 2ᵖ − 1` не обов'язково є простим.

Пояснимо причину цього явища через різницю між двома типами дільників:

1. **Алгебраїчні дільники (поліноміальні):**
   Якщо показник `n` складений (`n = a · b`), число `2ⁿ − 1` має алгебраїчний розклад над кільцем многочленів `xⁿ − 1 = (xᵃ − 1) · (xᵃ⁽ᵇ⁻¹⁾ + … + 1)`. Цей розклад спрацьовує при будь-якому значенні `x`, утворюючи множники `2ᵃ − 1`.
2. **Арифметичні дільники (теоретико-числові):**
   Якщо показник `p` є простим, розклад за круговими многочленами має лише два множники:
   ```
   2ᵖ − 1 = Φ₁(2) · Φ_p(2) = 1 · Φ_p(2) = Φ_p(2)
   ```
   Число `2ᵖ − 1` є алгебраїчно незвідним (воно не розкладається на менші многочлени від двійки). Проте саме значення цілого числа `Φ_p(2)` у кільці `Z` може виявитися складеним числом, якщо воно ділиться на деяке просте число `q`.

Такі дільники `q` виникають не з поліноміальної структури, а з властивостей скінченних полів `F_q` (коли порядок двійки `ord_q(2) = p`).

Перші складені числа Мерсенна з простими показниками демонструють цей феномен:

```
M₁₁ = 2¹¹ − 1 = 2047 = 23 · 89
M₂₃ = 2²³ − 1 = 8388607 = 47 · 178481
M₂₉ = 2²⁹ − 1 = 536870911 = 233 · 2304167
M₆₇ = 2⁶⁷ − 1 = 147573952589676412927 = 193707721 · 761838257287
```

## 5. Теорема Зігмонді про первинні прості дільники (1892)

### Поняття первинного простого дільника

Простий множник `q` числа Мерсенна `M♞ = 2ⁿ − 1` називається **первинним простим дільником** (primitive prime factor), якщо `q` ділить `2ⁿ − 1`, але **не ділить** жодне число Мерсенна `2ᵏ − 1` для всіх менших показників `1 ≤ k < n`.

Мовою теорії груп це означає, що мультиплікативний порядок числа 2 за модулем `q` дорівнює точно `n`:

```
ord_q(2) = n
```

Якщо `q` ділив би якесь `2ᵏ − 1` для `k < n`, то двійка мала б менший порядок `ord_q(2) ≤ k < n`, що суперечило б означенню.

### Формулювання теореми Карла Зігмонді (Zsigmondy's Theorem)

Для будь-якого натурального показника `n > 6` число Мерсенна `M♞ = 2ⁿ − 1` **обов'язково має принаймні один первинний простий дільник**.

Еквівалентно: для будь-якого `n > 6` існує принаймні одне таке просте число `q`, що `ord_q(2) = n`.

### Аналіз винятків n = 1 та n = 6

Теорема Зігмонді має лише два виняткові значення показника для послідовності `2ⁿ − 1`:

1. **Виняток n = 1:** `M₁ = 2¹ − 1 = 1`. Число 1 взагалі не має простих дільників.
2. **Виняток n = 6:** `M₆ = 2⁶ − 1 = 63 = 3² · 7`.
   - Простий дільник `3` ділить `M₂ = 2² − 1 = 3`, тому його порядок `ord₃(2) = 2 < 6`.
   - Простий дільник `7` ділить `M₃ = 2³ − 1 = 7`, тому його порядок `ord₇(2) = 3 < 6`.

Для `n = 6` обоє простих дільників (`3` та `7`) уже зустрічалися раніше в послідовності (на кроках `k = 2` та `k = 3`), тому `M₆` не містить жодного *нового* (первинного) простого дільника.

Для всіх інших `n` (наприклад `n = 2, 3, 4, 5, 7, 8, 9…`) первинний дільник завжди існує:
- `n = 2`: `M₂ = 3` (первинний дільник 3).
- `n = 3`: `M₃ = 7` (первинний дільник 7).
- `n = 4`: `M₄ = 15 = 3 · 5` (3 уже було на `n=2`, але 5 нове — первинний дільник 5).
- `n = 5`: `M₅ = 31` (первинний дільник 31).
- `n = 7`: `M₇ = 127` (первинний дільник 127).
- `n = 8`: `M₈ = 255 = 3 · 5 · 17` (17 — новий первинний дільник).
- `n = 9`: `M₉ = 511 = 7 · 73` (73 — новий первинний дільник).
- `n = 10`: `M₁₀ = 1023 = 3 · 11 · 31` (11 — новий первинний дільник).

## 6. Квадратичний закон та система конгруенцій q = 2kp + 1 і q ≡ ±1 (mod 8)

### Теорема про будову дільників Mₚ

Нехай `p` — непарне просте число, а `q` — довільний простий дільник числа Мерсенна `Mₚ = 2ᵖ − 1`. Тоді `q` обов'язково задовольняє систему двох точних умов:

```
1) q ≡ 1 (mod 2p)   ⇒   q = 2k·p + 1
2) q ≡ ±1 (mod 8)   ⇒   q ≡ 1 або q ≡ 7 (mod 8)
```

### Строге покрокове виведення

**Крок 1: Доведення умови q ≡ 1 (mod p).**

Оскільки `q | (2ᵖ − 1)`, у кільці лишків за модулем `q` виконується порівняння:

```
2ᵖ ≡ 1 (mod q)
```

Звідси мультиплікативний порядок числа 2 за модулем `q` (`ord_q(2)`) мусить ділити просте число `p`. Оскільки `2¹ = 2 ≢ 1 (mod q)` (бо `q > 2`), порядок не може дорівнювати 1. Оскільки `p` — просте число, єдиним дільником `p`, більшим за 1, є саме `p`:

```
ord_q(2) = p
```

За Малою теоремою Ферма, для будь-якого простого `q`, яке не ділить 2:

```
2^(q−1) ≡ 1 (mod q)
```

За фундаментальною властивістю порядку елемента в групі, якщо `2ˣ ≡ 1 (mod q)`, то порядок `ord_q(2)` ділить показник `x`. Застосувавши це до `x = q − 1`, отримуємо:

```
p | (q − 1)   ⇒   q ≡ 1 (mod p)
```

**Крок 2: Перехід до модуля 2p.**

Число `Mₚ = 2ᵖ − 1` є непарним для будь-якого `p ≥ 1`. Отже, будь-який його простий дільник `q` також є непарним простим числом (`q > 2`).

З умови `q ≡ 1 (mod p)` випливає, що `q − 1` є кратним `p`. Оскільки `q` непарне, `q − 1` є парним числом. Якщо ціле число `q − 1` ділиться на непарне просте `p` і на 2, воно ділиться на їхній добуток `2p`:

```
2p | (q − 1)   ⇒   q ≡ 1 (mod 2p)   ⇒   q = 2k·p + 1
```

**Крок 3: Доведення умови q ≡ ±1 (mod 8) через символ Лежандра.**

З рівняння `q = 2kp + 1` виразимо значення `(q − 1) / 2`:

```
(q − 1) / 2 = k · p
```

Піднесемо число 2 до степеня `(q − 1) / 2` за модулем `q`:

```
2^((q−1)/2)
= 2^(k·p)                                 [підстановка (q−1)/2 = k·p]
= (2ᵖ)ᵏ                                   [властивість степеня]
≡ 1ᵏ ≡ 1 (mod q)                          [оскільки 2ᵖ ≡ 1 (mod q)]
```

За критерієм Ейлера для символа Лежандра `(2 / q)`:

```
(2 / q) ≡ 2^((q−1)/2) (mod q)
```

Оскільки `2^((q−1)/2) ≡ 1 (mod q)`, значення символа Лежандра дорівнює:

```
(2 / q) = +1
```

Це означає, що **число 2 є квадратичним лишком за модулем q**.

За другою доповняльною тотожністю квадратичного закону взаємності Гаусса, символ Лежандра `(2 / q)` обчислюється за формулою:

```
(2 / q) = (−1)^((q² − 1) / 8)
```

Значення `(−1)^((q² − 1) / 8) = +1` досягається тоді й лише тоді, коли `(q² − 1) / 8` є парним числом.

Проаналізуємо всі непарні остачі за модулем 8:
- Якщо `q ≡ 1 (mod 8)`: `q² ≡ 1 (mod 16) ⇒ (q² − 1) / 8` парне ⇒ `(2 / q) = +1`.
- Якщо `q ≡ 3 (mod 8)`: `q² ≡ 9 ≡ 1 (mod 8)`, але `(q² − 1) / 8` непарне ⇒ `(2 / q) = −1`.
- Якщо `q ≡ 5 (mod 8)`: `q² ≡ 25 ≡ 1 (mod 8)`, але `(q² − 1) / 8` непарне ⇒ `(2 / q) = −1`.
- Якщо `q ≡ 7 (mod 8)`: `q² ≡ 49 ≡ 1 (mod 16) ⇒ (q² − 1) / 8` парне ⇒ `(2 / q) = +1`.

Отже, рівність `(2 / q) = +1` виконується **тоді й лише тоді**, коли:

```
q ≡ 1 (mod 8)   або   q ≡ 7 (mod 8)   (тобто q ≡ ±1 mod 8)
```

### Застосування теореми: розрахунок дільників для p = 37 та p = 41

Проілюструємо застосування системи двох фільтрів до більших показників:

1. **Аналіз M₃₇ = 2³⁷ − 1 (p = 37):**
   Крок прогресії дорівнює `2p = 74`. Кандидати мають форму `q = 74k + 1`:
   - `k = 1`: `q = 75` (складене).
   - `k = 2`: `q = 149`. `149 mod 8 = 5` — відкинуто квадратичним фільтром!
   - `k = 3`: `q = 223`. `223 mod 8 = 7` — фільтр пройдено! Обчислюємо `2³⁷ mod 223 = 1`.
   - Знайдено дільник `q = 223`. Повний розклад: `M₃₇ = 223 · 616318177`.

2. **Аналіз M₄₁ = 2⁴¹ − 1 (p = 41):**
   Крок прогресії дорівнює `2p = 82`. Кандидати мають форму `q = 82k + 1`:
   - Серед кандидатів найменший дільник досягається при `k = 163`: `q = 13367`.
   - Перевірка: `13367 mod 8 = 7` (відповідає критерію) та `2⁴¹ mod 13367 = 1`.
   - Повний розклад: `M₄₁ = 13367 · 164511353`.

Виведення та аналіз повністю завершено.
