# ⚙️ Швидкі алгоритми арифметики за модулем Мерсенна та пробного ділення

Числа вигляду `M♞ = 2ⁿ − 1` посідають унікальне місце у системному програмуванні, криптографії, мікропроцесорній архітектурі та комп'ютерній алгебрі. Завдяки фундаментальній модульній тотожності `2ⁿ ≡ 1 (mod M♞)` складні й обчислювально дорогі операції цілочисельного ділення з остачею в кільці лишків замінюються на побітові зсуви, маскування та додавання. Крім того, завдяки суворим теоретико-числовим обмеженням на форму простих дільників `q = 2kp + 1` із додатковою конгруентною умовою `q ≡ ±1 (mod 8)`, процедура пробного ділення для чисел Мерсенна `Mₚ = 2ᵖ − 1` прискорюється в сотні разів порівняно зі звичайним перебором.

У цій вставці наведено детальний обчислювальний аналіз, математичне обґрунтування та повні вихідні коди двох алгоритмів мовами C та C++:
1. Безділильне згортання 64-бітного цілого числа за модулем Мерсенна `M♞ = 2ⁿ − 1`.
2. Оптимізоване пробне ділення для пошуку малого простого дільника числа Мерсенна `Mₚ`.

---

## 1. Апаратний механізм безділильного модульного зведення

### Проблема апаратного ділення в мікропроцесорах

У стандартних арифметико-логічних пристроях (АЛП / ALU) процесорів архітектур x86-64, ARM64 та RISC-V цілочисельне ділення виконується за допомогою інструкцій `div`, `idiv` або `sdiv`. На відміну від інструкцій додавання (`add`), віднімання (`sub`) чи побітового зсуву (`shl`/`shr`), які виконуються за 1 процесорний такт, інструкція цілочисельного ділення є багатокроковим ітеративним процесом, що потребує від 12 до 40 тактів генератора частоти.

Більше того, інструкція ділення конвеєризується надзвичайно важко. Вона створює тривалу затримку (latency) в обчислювальному конвеєрі та змушує виконавчі блоки процесора простоювати в очікуванні результату.

### Алгебраїчна ідея згортання за модулем Мерсенна

Особливість модуля вигляду `M♞ = 2ⁿ − 1` полягає в тому, що основа позиційної системи числення `2ⁿ` є порівнянною з одиницею:

```
2ⁿ = M♞ + 1   ⇒   2ⁿ ≡ 1 (mod M♞)
```

Нехай у нас є довільне 64-бітне беззнакове ціле число `x`, яке потрібно звести за модулем `2ⁿ − 1`. Запишемо двійкове подання числа `x` і розділимо його бітове поле на два фрагменти:
- **Молодша частина `B`:** `n` молодших бітів (значення в діапазоні від `0` до `2ⁿ − 1`).
- **Старша частина `A`:** всі біти, що розміщені вище `n`-го розряду (значення `x >> n`).

Тоді число `x` точно подається алгебраїчною сумою:

```
x = A · 2ⁿ + B
```

Застосуємо порівняння `2ⁿ ≡ 1 (mod 2ⁿ − 1)` до цієї рівності:

```
x = A · 2ⁿ + B ≡ A · 1 + B = A + B (mod 2ⁿ − 1)
```

Математичний результат є вражаючим: **знаходження остачі від ділення на `2ⁿ − 1` дорівнює звичайній сумі старшої та молодшої частин двійкового запису числа**.

### Покроковий алгоритм згортання

Виділення частин `A` та `B` у програмі виконується за допомогою двох найпростіших побітових інструкцій:
1. **Виділення старшої частини `A`:** виконується правим логічним зсувом `x >> n`.
2. **Виділення молодшої частини `B`:** виконується побітовим «І» з бітовою маскою `(1 << n) - 1`.

Якщо отримана сума `A + B` все ще перевищує або дорівнює `2ⁿ − 1`, операцію згортання повторюють (для 64-бітних чисел достатньо одного додаткового кроку) або виконують одноразове віднімання `2ⁿ − 1`.

### Крайові випадки та обробка нуля

В арифметиці за модулем `2ⁿ − 1` значення `2ⁿ − 1` є тотожно рівним `0`.
Якщо в результаті додавання `A + B` виходить значення, яке строго дорівнює `2ⁿ − 1` (двійкова маска з `n` одиниць), математично це відповідає точній остачі `0`. У коді цей випадок обробляється явним поверненням нуля.

## 2. Оптимізований алгоритм пробного ділення для Mₚ

### Теорія фільтрації кандидатів у дільники

Для факторизації або перевірки простоти числа Мерсенна `Mₚ = 2ᵖ − 1` (де `p` — просте число) класичний метод пробного ділення вимагав би перевірки всіх простих чисел `q = 3, 5, 7, 11, 13, 17…` у діапазоні до `√Mₚ`.

Проте строгі математичні теореми теорії чисел дозволяють застосувати два потужні апаратні фільтри, які відсіюють понад 99% усіх потенційних дільників без виконання ділення:

1. **Перший фільтр (Адитивна прогресія):** Будь-який простий дільник `q` числа `Mₚ` мусить мати форму `q = 2kp + 1` для деякого цілого `k ≥ 1`. Це означає, що перевіряти потрібно лише числа з арифметичної прогресії з кроком `2p`. Для `p = 31` крок прогресії дорівнює `62`, для `p = 61` крок дорівнює `122`. Це зменшує кількість кандидатів у `2p` разів.
2. **Другий фільтр (Квадратичний залишок):** Будь-який простий дільник `q` числа `Mₚ` мусить задовольняти порівняння `q ≡ ±1 (mod 8)` (тобто `q ≡ 1` або `q ≡ 7 mod 8`). Оскільки з чотирьох непарних остач за модулем 8 (`1, 3, 5, 7`) підходять лише дві (`1` та `7`), цей фільтр відсіює рівно 50% кандидатів, що залишилися після першого фільтра.

### Швидка перевірка подільності через бінарне піднесення до степеня

Коли кандидат `q` пройшов обидва фільтри, нам потрібно перевірити, чи ділить `q` число `Mₚ = 2ᵖ − 1`.

Пряме обчислення `(2ᵖ − 1) % q` є неможливим для великих `p`, оскільки число `2ᵖ − 1` не вміщується в 64-бітний регістр. Проте конгруенція `2ᵖ − 1 ≡ 0 (mod q)` рівносильна порівнянню:

```
2ᵖ ≡ 1 (mod q)
```

Обчислення остачі `2ᵖ mod q` виконується за допомогою алгоритму бінарного піднесення до степеня (Square-and-Multiply) за `O(log p)` кроків. На кожному кроці проміжні результати зводяться за модулем `q`. Для запобігання переповненню при множенні двох 64-бітних чисел використовується 128-бітне розширення (`unsigned __int128`).

## 4. Оцінка продуктивності та обчислювальної складності

Сукупний ефект застосування обох алгебраїчних оптимізацій показує колосальну перевагу над традиційними підходами:

1. **Ефективність безділильного зведення:** Заміна інструкції цілочисельного ділення `%` на побітові зсуви та додавання скорочує час зведення числа за модулем `2ⁿ − 1` з 30 тактів до 2–4 тактів процесора. Це надає прискорення обчислень у 4–8 разів у таких прикладних задачах, як генерація псевдовипадкових чисел (генератор Mersenne Twister MT19937) та обчислення теоретико-числових перетворень Фур'є (NTT).
2. **Ефективність теоретико-числової фільтрації:** Поєднання адитивного фільтра `q = 2kp + 1` та квадратичного фільтра `q ≡ ±1 (mod 8)` зменшує кількість кандидатів у дільники у `4p` разів. Для показника `p = 61` перебір кандидатів скорочується у 244 рази. Це дозволяє миттєво відсіювати складені числа Мерсенна на звичайних персональних комп'ютерах без залучення суперкомп'ютерних потужностей.
