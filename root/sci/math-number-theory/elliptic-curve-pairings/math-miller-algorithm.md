# 𝔮 Математичне виведення алгоритму Міллера та теорія дивізорів

Обчислення білінійних спарювань на еліптичних кривих вимагає знаходження значень раціональних функцій, дивізори яких задаються кратними точок кручення. Для криптографічних порядків підгруп `r ≈ 2²⁵⁶` пряма побудова таких раціональних функцій як многочленів неможлива, оскільки їхній степінь вимагав би астрономічної кількості коефіцієнтів, що перевищує число атомів у видимому Всесвіті. Алгоритм Віктора Міллера (англ. *Miller's algorithm*) розв'язує цю задачу, зводячи побудову функції з дивізором `r · (P) - r · (O)` до `O(log2 r)` кроків рекурентного накопичення за аналогією зі швидким бінарним піднесенням до степеня (англ. *double-and-add*).

Нижче наведено повне математичне обґрунтування теорії дивізорів, виведення рекурентних співвідношень Міллера, алгебраїчні формули обчислення прямих у проєктивних та Якобієвих координатах, декомпозицію фінального експонування та покроковий числовий розрахунок спарювання для навчальної кривої.

---

## 1. Алгебраїчна група дивізорів та теорема Абеля — Якобі

Нехай `E` — еліптична крива над скінченним полем `F_q`, задана рівнянням Вейєрштрасса `y² = x³ + a·x + b` з дискримінантом `Δ = -16·(4·a³ + 27·b²) ≠ 0`. Позначимо через `F̄_q` алгебраїчне замикання поля `F_q`, а через `O` — нескінченно віддалену точку (нейтральний елемент групового закону).

Групою дивізорів `Div(E)` називається вільна абелева група, породжена точками кривої `P ∈ E(F̄_q)`. Кожен дивізор `D ∈ Div(E)` — це формальна скінченна `Z`-лінійна комбінація точок:

```
D = ∑_{P ∈ E} n_P · (P),  де n_P ∈ Z, і лише скінченна кількість n_P ≠ 0
```

Для аналізу дивізорів вводяться два фундаментальні гомоморфізми груп:

1. **Ступінь дивізора (англ. *degree*):**
   ```
   deg: Div(E) → Z
   deg(D) = ∑_{P ∈ E} n_P
   ```
   Множина дивізорів ступеня 0 утворює підгрупу `Div⁰(E) = Ker(deg) ⊂ Div(E)`.

2. **Сума точок на кривій (англ. *sum map*):**
   ```
   sum: Div(E) → E(F̄_q)
   sum(D) = ∑_{P ∈ E} [n_P] P
   ```
   де `[n_P] P` — результат `n_P`-кратного додавання точки `P` за алгебраїчним груповим законом на еліптичній кривій.

### Головні дивізори та критерій Абеля — Якобі

Нехай `F_q(E)` — поле раціональних функцій на кривій `E`. Для будь-якої ненульової функції `f ∈ F_q(E)*` її дивізор `div(f)` визначається нулями та полюсами з урахуванням їхніх кратностей (порядків `ord_P(f)`):

```
div(f) = ∑_{P ∈ E} ord_P(f) · (P)
```

де `ord_P(f) > 0`, якщо точка `P` є нулем функції `f` кратності `ord_P(f)`, та `ord_P(f) < 0`, якщо точка `P` є полюсом функції `f` порядку `|ord_P(f)|`.

Дивізор `D` називається **головним дивізором** (англ. *principal divisor*), якщо існує раціональна функція `f ∈ F_q(E)*` така, що `D = div(f)`. Множина всіх головних дивізорів утворює підгрупу `Prin(E) ⊂ Div⁰(E)`.

**Теорема Абеля — Якобі:** Дивізор `D = ∑ n_P · (P) ∈ Div(E)` є головним дивізором (`D ∈ Prin(E)`) тоді і тільки тоді, коли одночасно виконуються дві умови:
1. `deg(D) = ∑ n_P = 0` (сума коефіцієнтів дорівнює нулю).
2. `sum(D) = ∑ [n_P] P = O` (сума точок за груповим законом кривої дорівнює нейтральному елементу `O`).

Факторгрупа `Pic⁰(E) = Div⁰(E) / Prin(E)` називається **групою Пікара ступеня 0** (або Якобіаном еліптичної кривої `Jac(E)`). Відображення `sum: Pic⁰(E) → E(F̄_q)` є ізоморфізмом груп:

```
Pic⁰(E) ≅ E(F̄_q)
```

З ізоморфізму Абеля — Якобі випливає: якщо два дивізори `D_1, D_2 ∈ Div⁰(E)` мають однакову суму `sum(D_1) = sum(D_2)`, то їхня різниця `D_1 - D_2` є головним дивізором деякої раціональної функції `g`, тобто `D_1 = D_2 + div(g)`.

## 2. Математичне виведення рекурентних співвідношень Міллера

Нехай `P ∈ E(F_q)[r]` — точка порядку `r` (`[r]P = O`). Для кожного цілого `m ∈ Z` побудуємо частинний дивізор Міллера:

```
D_m = m · (P) - ( [m]P ) - (m - 1) · (O)
```

Перевіримо виконання умов теореми Абеля — Якобі для дивізора `D_m`:

```
deg(D_m)
= m - 1 - (m - 1)  [підсумовування коефіцієнтів: m·1 - 1 - (m-1)]
= 0                [умова deg(D) = 0 виконана]

sum(D_m)
= [m]P - [m]P - [m - 1]O  [групове додавання точок на кривій E]
= O                       [умова sum(D) = O виконана]
```

Оскільки обидві умови виконані, для кожного цілого `m ≥ 1` існує єдина з точністю до ненульового скалярного множника з `F_q*` раціональна функція `f_{m,P} ∈ F_q(E)*` така, що:

```
div(f_{m,P}) = D_m = m · (P) - ( [m]P ) - (m - 1) · (O)
```

Нормуємо функцію умовою `f_{1,P} = 1` (оскільки `D_1 = 1·(P) - (P) - 0·(O) = 0`). Коли `m = r`, враховуючи `[r]P = O`, отримуємо цільову функцію спарювання:

```
div(f_{r,P}) = r · (P) - (O) - (r - 1) · (O) = r · (P) - r · (O)
```

### Геометрія прямих на кривій Вейєрштрасса

Нехай `T = (x_T, y_T)` та `R = (x_R, y_R)` — дві афінні точки на кривій `E: y² = x³ + a·x + b`.

1. **Січна пряма `l_{T, R}` при `T ≠ R`:**
   Кутовий коефіцієнт січної дорівнює:
   ```
   λ = (y_R - y_T) / (x_R - x_T)
   ```
   Рівняння січної прямої через `T` та `R`:
   ```
   l_{T, R}(x, y) = (y - y_T) - λ · (x - x_T)
   ```

2. **Дотична пряма `l_{T, T}` при `T = R` (подвоєння точки):**
   Беручи неявну похідну від рівняння кривої `y² - x³ - a·x - b = 0`:
   ```
   2 · y · dy - (3 · x² + a) · dx = 0
   λ = dy / dx = (3 · x_T² + a) / (2 · y_T)
   ```
   Рівняння дотичної прямої:
   ```
   l_{T, T}(x, y) = (y - y_T) - λ · (x - x_T)
   ```

3. **Вертикальна пряма `v_{T+R}`:**
   Проходить через точку `T + R = (x_{T+R}, y_{T+R})` та симетричну точку `-(T + R) = (x_{T+R}, -y_{T+R})`:
   ```
   v_{T+R}(x, y) = x - x_{T+R}
   ```
   де координата `x_{T+R}` обчислюється як:
   ```
   x_{T+R} = λ² - x_T - x_R  (при T ≠ R)
   x_{2T}  = λ² - 2 · x_T    (при T = R)
   ```

### Дивізори функцій прямих

Пряма `l_{T, R}` перетинає кубічну криву `E` рівно у трьох точках: `T`, `R` та `-(T + R)`. На нескінченності `O` вона має полюс 3-го порядку:

```
div(l_{T, R}) = (T) + (R) + (-(T + R)) - 3 · (O)
```

Вертикальна пряма `v_{T+R}` перетинає криву у точках `T + R` та `-(T + R)`, маючи на нескінченності полюс 2-го порядку:

```
div(v_{T+R}) = (T + R) + (-(T + R)) - 2 · (O)
```

Обчислимо дивізор раціонального відношення `l_{T, R} / v_{T+R}`:

```
div( l_{T, R} / v_{T+R} )
= div(l_{T, R}) - div(v_{T+R})                                 [властивість дивізора частки]
= [ (T) + (R) + (-(T+R)) - 3·(O) ] - [ (T+R) + (-(T+R)) - 2·(O) ]  [підстановка дивізорів прямих]
= (T) + (R) - (T + R) - (O)                                    [скорочення точки -(T+R) та полюсів]
```

### Виведення основного рекурентного співвідношення

Розглянемо суму двох індексів `m, n ∈ Z` та дивізори функцій `f_{m,P}`, `f_{n,P}` і `f_{m+n,P}`:

```
div(f_{m,P})   = m · (P) - ( [m]P ) - (m - 1) · (O)
div(f_{n,P})   = n · (P) - ( [n]P ) - (n - 1) · (O)
div(f_{m+n,P}) = (m + n) · (P) - ( [m+n]P ) - (m + n - 1) · (O)
```

Знайдемо суму дивізорів `div(f_{m,P}) + div(f_{n,P})`:

```
div(f_{m,P}) + div(f_{n,P})
= (m + n) · (P) - ( [m]P ) - ( [n]P ) - (m + n - 2) · (O)
```

Обчислимо різницю між `div(f_{m+n,P})` та цією сумою:

```
div(f_{m+n,P}) - ( div(f_{m,P}) + div(f_{n,P}) )
= [ (m+n)·(P) - ([m+n]P) - (m+n-1)·(O) ] - [ (m+n)·(P) - ([m]P) - ([n]P) - (m+n-2)·(O) ]
= ( [m]P ) + ( [n]P ) - ( [m+n]P ) - (O)
```

Поклавши `T = [m]P` та `R = [n]P`, бачимо, що отримана різниця точно збігається з дивізором відношення `l_{[m]P, [n]P} / v_{[m+n]P}`:

```
div(f_{m+n,P}) - div(f_{m,P}) - div(f_{n,P}) = div( l_{[m]P, [n]P} / v_{[m+n]P} )
```

Об'єднуючи доданки під знаком дивізора:

```
div(f_{m+n, P}) = div( f_{m, P} · f_{n, P} · ( l_{[m]P, [n]P} / v_{[m+n]P} ) )
```

Оскільки функції з тотожними дивізорами відрізняються лише ненульовою константою, за умови нормування отримуємо **фундаментальне рекурентне рівняння Міллера**:

```
f_{m+n, P} = f_{m, P} · f_{n, P} · ( l_{[m]P, [n]P} / v_{[m+n]P} )
```

У частинному випадку подвоєння індексу (`m = n`):

```
f_{2m, P} = (f_{m, P})² · ( l_{[m]P, [m]P} / v_{[2m]P} )
```

Ці формули дозволяють обчислити функцію `f_{r,P}` за бінарним розкладом скаляра `r = ∑_{j=0}^{L-1} b_j · 2^j` за `L = ⌊log2 r⌋` ітерацій подвоєння та не більше ніж `L` ітерацій додавання.

## 3. Кроки подвоєння та додавання у проєктивних і Якобієвих координатах

В афінних координатах кожен крок обчислення кутового коефіцієнта `λ` вимагає виконання дорогої операції знаходження оберненого елемента у скінченному полі (інверсії). Для усунення інверсій із гарячого циклу алгоритму Міллера точки кривої подають у проєктивних або Якобієвих координатах.

### Якобієві координати (Jacobian Coordinates)

У Якобієвих координатах точка `(X : Y : Z)` відповідає афінній точці `(x, y) = (X / Z², Y / Z³)`. Рівняння кривої Вейєрштрасса набуває вигляду:

```
Y² = X³ + a · X · Z⁴ + b · Z⁶
```

Нейтральний елемент `O` подається як `(1 : 1 : 0)`.

#### 1. Крок подвоєння та оцінка дотичної прямої (Double Step)

Нехай поточна точка `T = (X_1 : Y_1 : Z_1)` задана в Якобієвих координатах, а точка оцінки спарювання `Q = (x_Q, y_Q)` — в афінних координатах. Подвоєння `[2]T = (X_3 : Y_3 : Z_3)` та оцінка функції дотичної прямої `l_{T,T}(Q)` обчислюються за таким безінверсним алгоритмом:

```
A = X_1²                                  [квадрат координати X]
B = Y_1²                                  [квадрат координати Y]
C = B² = Y_1⁴                             [четвертий степінь Y]
D = 2 · ((X_1 + B)² - A - C) = 4·X_1·Y_1² [проміжний добуток подвоєння]
E = 3 · A + a · Z_1⁴                      [чисельник нахилу дотичної: 3·X_1² + a·Z_1⁴]
F = E²                                    [квадрат чисельника нахилу]
X_3 = F - 2 · D                           [нова координата X точки [2]T]
Z_3 = (Y_1 + Z_1)² - B - Z_1² = 2·Y_1·Z_1 [нова координата Z точки [2]T]
Y_3 = E · (D - X_3) - 8 · C               [нова координата Y точки [2]T]
```

Оцінимо функцію дотичної прямої `l_{T,T}` у точці `Q = (x_Q, y_Q)`:

```
l_{T,T}(x_Q, y_Q) = (y_Q - y_T) - λ · (x_Q - x_T)
= y_Q - (Y_1 / Z_1³) - (E / (2·Y_1·Z_1)) · (x_Q - (X_1 / Z_1²))
```

Помноживши вираз на проєктивний знаменник `2 · Y_1 · Z_1³ = Z_3 · Z_1²` (який є скаляром з базового поля і зникає під час фінального експонування):

```
l_{T,T}(Q) = (E · X_1 - 2 · B) - (E · Z_1²) · x_Q + (Z_3 · Z_1²) · y_Q
```

Це рівняння обчислюється як скалярна лінійна комбінація:

```
l_{T,T}(Q) = λ₀ + λ₁ · x_Q + λ₂ · y_Q
```

де коефіцієнти прямої дорівнюють:
- `λ₀ = E · X_1 - 2 · B`
- `λ₁ = -E · Z_1²`
- `λ₂ = Z_3 · Z_1²`

Усі коефіцієнти `λ₀, λ₁, λ₂` обчислюються без жодної операції ділення в полі.

#### 2. Крок змішаного додавання та оцінка січної прямої (Add Step)

При змішаному додаванні поточна точка `T = (X_1 : Y_1 : Z_1)` задана в Якобієвих координатах, а точка `P = (x_P, y_P)` — в афінних координатах (`Z_P = 1`). Додавання `T + P = (X_3 : Y_3 : Z_3)` та оцінка січної прямої `l_{T,P}(Q)` виконуються за формулами:

```
u_1 = X_1                                [масштабована координата X точки T]
u_2 = x_P · Z_1²                         [масштабована координата X точки P]
s_1 = Y_1                                [масштабована координата Y точки T]
s_2 = y_P · Z_1³                         [масштабована координата Y точки P]
H   = u_2 - u_1                          [різниця по осі X]
r_2 = s_2 - s_1                          [різниця по осі Y]
I   = (2 · H)² = 4 · H²                  [квадрат подвоєної різниці X]
J   = H · I = 4 · H³                     [кубічний член]
V   = u_1 · I = 4 · X_1 · H²             [проміжне масштабування]
X_3 = r_2² - J - 2 · V                   [нова координата X точки T + P]
Y_3 = r_2 · (V - X_3) - 2 · s_1 · J      [нова координата Y точки T + P]
Z_3 = 2 · Z_1 · H                        [нова координата Z точки T + P]
```

Оцінка січної прямої `l_{T,P}` у точці `Q = (x_Q, y_Q)` з масштабуванням на `H · Z_1`:

```
l_{T,P}(Q) = (r_2 · x_P - H · y_P · Z_1) - r_2 · x_Q + (H · Z_1) · y_Q
```

### Скорочення вертикальних прямих (Vertical Line Elimination)

У спарюваннях на дружніх кривих зі ступенем занурення `k = 2·d` (парне `k`) застосовується скручування кривої (англ. *twist*). Точка `Q = (x_Q, y_Q)` має координату `x_Q ∈ F_{p^{k/2}}` або `x_Q ∈ F_{p^{k/d}}`.

Вертикальна пряма `v(Q) = x_Q - x_{T+R}` повністю лежить у власному підполі `F_{p^{k/2}}`. Під час фінального піднесення до степеня `(p^k - 1) / r`:

```
( v(Q) )^( (p^k - 1) / r )
= ( (v(Q))^(p^{k/2} - 1) )^( (p^k - 1) / (r · (p^{k/2} - 1)) )  [розклад показника]
= ( 1 )^( (p^k - 1) / (r · (p^{k/2} - 1)) )                      [бо a^(q-1) = 1 для a ∈ F_q*]
= 1
```

Оскільки значення будь-якої вертикальної прямої при фінальному експонуванні тотожно перетворюється на `1`, ділення на `v_{[2m]P}` та `v_{[m+n]P}` у циклі Міллера **повністю відкидається**:

```
f_{2m, P}(Q) = (f_{m, P}(Q))² · l_{[m]P, [m]P}(Q)
f_{m+n, P}(Q) = f_{m, P}(Q) · f_{n, P}(Q) · l_{[m]P, [n]P}(Q)
```

Це вдвічі скорочує кількість множень у розширенні поля на кожній ітерації алгоритму Міллера.

## 4. Крайові випадки та виродження прямих у циклі Міллера

Під час виконання циклу Міллера виникають геометричні конфігурації, які вимагають окремої математичної обробки:

1. **Додавання взаємно протилежних точок `T = -R` (`T + R = O`):**
   Якщо `x_T = x_R`, але `y_T = -y_R ≠ 0`, пряма, що проходить через `T` та `R`, є строго вертикальною прямою `x = x_T`. Її дивізор дорівнює `div(l) = (T) + (-T) - 2·(O)`. Відношення `l_{T,-T} / v_O` перетворюється на функцію `x - x_T`. Точка `T` оновлюється значенням нейтрального елемента `O`.

2. **Додавання точки на нескінченності `T = O` або `R = O`:**
   Якщо `T = O`, функція прямої приймається рівною `1`, а накопичувальна точка `T` встановлюється в значення `R`. Множення акумулятора `f` на функцію прямої пропускається (`f` залишається незмінним).

3. **Крок подвоєння у точці кручення 2-го порядку (`y_T = 0`):**
   Якщо `y_T = 0`, дотична до кривої є вертикальною прямою `x = x_T`. Точка `[2]T = O`. Значення прямої дорівнює `x - x_T`, а подальші кроки циклу перемикаються на опрацювання нейтрального елемента.

## 5. Фінальне піднесення до степеня (Final Exponentiation)

Результат виконання циклу Міллера `f_{r,P}(Q)` є елементом мультиплікативної групи поля розширення `F_{p^k}*`. Однак функція `f_{r,P}` визначена лише з точністю до множення на константу, а її значення утворює клас еквівалентності у факторгрупі `F_{p^k}* / (F_{p^k}*)^r`.

Для отримання єдиного канонічного значення та забезпечення білінійності результат підноситься до степеня:

```
e = (p^k - 1) / r
```

Ця операція виконує три математичні задачі:
1. **Знищення класів суміжності:** Для будь-якого елемента `c ∈ F_{p^k}*` його `r`-й степінь анігілюється: `(c^r)^e = c^{p^k - 1} = 1`.
2. **Проєкція в підгрупу коренів з одиниці:** Результат `f^e` гарантовано належить підгрупі `μ_r = { ζ ∈ F_{p^k}* : ζ^r = 1 }`.
3. **Усунення коефіцієнтів підполів:** Усі скалярні знаменники з проміжних підполів `F_{p^d}` (зокрема вертикальні прямі та проєктивні масштабні множники) автоматично перетворюються на `1`.

### Декомпозиція показника степеня на легку та важку частини

Пряме піднесення до степеня `e` довжиною `k · log2 p` є обчислювально важким. Показник `e` розкладають на два множники:

```
e = e_{easy} · e_{hard}
```

#### 1. Легка частина (Easy Part)

Для кривих зі ступенем занурення `k = 12` (наприклад, BLS12 та BN254) круговий многочлен дорівнює `Φ₁₂(p) = p⁴ - p² + 1`. Тотожність розкладу має вигляд:

```
p¹² - 1 = (p⁶ - 1) · (p⁶ + 1) = (p⁶ - 1) · (p² + 1) · (p⁴ - p² + 1)
```

Поділивши на `r`, отримуємо розклад:

```
e = (p⁶ - 1) · (p² + 1) · ( (p⁴ - p² + 1) / r )
```

Легка частина показника визначається як:

```
e_{easy} = (p⁶ - 1) · (p² + 1)
```

Обчислення `f^{e_{easy}}` виконується за два швидкі кроки:

1. **Піднесення до степеня `p⁶ - 1`:**
   Оскільки розширення `F_{p¹²}` будується як квадратичне розширення над `F_{p⁶}` (`F_{p¹²} = F_{p⁶}[w] / (w² - v)`), дія автоморфізму Фробеніуса `π_{p⁶}(a + b·w) = a - b·w` є комплексним спряженням `f̄`. Тому:
   ```
   f^{p⁶ - 1} = f^{p⁶} / f = f̄ · f⁻¹
   ```
   Це вимагає лише однієї інверсії в полі `F_{p¹²}` та одного множення.

2. **Піднесення до степеня `p² + 1`:**
   ```
   g = (f^{p⁶ - 1})^{p² + 1} = π_{p²}(f^{p⁶ - 1}) · f^{p⁶ - 1}
   ```
   Автоморфізм `π_{p²}` у вежі полів виконується через множення компонентів на попередньо обчислені константи без загальних множень многочленів.

**Кругова підгрупа (Cyclotomic Subgroup):**
Після застосування легкої частини елемент `g = f^{e_{easy}}` потрапляє в кругову підгрупу `G_{Φ₁₂(p)} = { u ∈ F_{p¹²}* : u^{p⁴ - p² + 1} = 1 }`. У цій підгрупі будь-який елемент є унітарним:

```
u⁻¹ = u^{p⁶} = ū
```

Інверсія стає безкоштовною операцією (зміна знака уявних компонентів), а піднесення до квадрата прискорюється за алгоритмом Грейнджера — Скотта (англ. *Granger-Scott cyclotomic squaring*).

#### 2. Важка частина (Hard Part)

Важка частина показника дорівнює:

```
e_{hard} = Φ₁₂(p) / r = (p⁴ - p² + 1) / r
```

Для кривих сімейств BLS12 параметри кривої `p` та `r` задаються многочленами від цілого скаляра `x` (параметра конструкції):
- `p(x) = (x - 1)² · (x⁴ - x² + 1) / 3 + x`
- `r(x) = x⁴ - x² + 1`

Тоді частка `e_{hard}(x) = (p(x)⁴ - p(x)² + 1) / r(x)` записується у вигляді полінома за степенями `p` з малими коефіцієнтами, що залежать від `x`:

```
e_{hard} = d₀ + d₁ · p + d₂ · p² + d₃ · p³
```

де коефіцієнти `d_i(x)` подаються через короткі ланцюжки множення на `x` (наприклад, для BLS12-381 значення `x` має довжину всього 64 біти). Застосовуючи схему Горнера разом із швидким автоморфізмом Фробеніуса `π_p(u) = u^p`, піднесення до важкого степеня `u^{e_{hard}}` обчислюється через кілька експонувань на короткий скаляр `x` замість повнорозмірного 256-бітового піднесення.

## 6. Математичне доведення властивостей спарювання Тейта

Зведене спарювання Тейта визначається як:

```
t_r(P, Q) = f_{r,P}(Q)^( (q - 1) / r )
```

де `q = p^k`, `P ∈ E(F_p)[r]`, `Q ∈ E(F_{p^k})`.

### Доведення білінійності за першим аргументом

Доведемо, що `t_r(P_1 + P_2, Q) = t_r(P_1, Q) · t_r(P_2, Q)`.

За рекурентним співвідношенням Міллера для суми точок `P_1, P_2 ∈ E[r]` та індексу `m = r`:

```
f_{r, P_1 + P_2} = f_{r, P_1} · f_{r, P_2} · ( l_{P_1, P_2} / v_{P_1 + P_2} )^r · ( h / v )
```

де `h` та `v` — допоміжні раціональні функції прямих, що з'єднують точки в процесі додавання.

Оцінимо функцію в точці `Q` та піднесемо до степеня `e = (q - 1) / r`:

```
t_r(P_1 + P_2, Q)
= ( f_{r, P_1}(Q) · f_{r, P_2}(Q) · (h(Q) / v(Q)) )^( (q - 1) / r )  [за рекурентною формулою Міллера для f_{r, P_1+P_2}]
= f_{r, P_1}(Q)^e · f_{r, P_2}(Q)^e · (h(Q) / v(Q))^e                 [за дистрибутивністю піднесення до степеня]
= f_{r, P_1}(Q)^e · f_{r, P_2}(Q)^e · 1                              [бо (h(Q)/v(Q))^(q-1) = 1 у полі F_{p^k}*]
= t_r(P_1, Q) · t_r(P_2, Q)                                           [за означенням спарювання Тейта]
```

Оскільки `h(Q), v(Q) ∈ F_{p^k}*`, за малою теоремою Ферма для скінченних полів будь-який елемент `w ∈ F_{p^k}*` задовольняє `w^{q - 1} = 1`. Тому:

```
( h(Q) / v(Q) )^( (q - 1) / r ) = ( (h(Q) / v(Q))^(q - 1) )^(1 / r) = 1^(1 / r) = 1
```

Отже:

```
t_r(P_1 + P_2, Q) = t_r(P_1, Q) · t_r(P_2, Q)
```

### Доведення білінійності за другим аргументом

Доведемо, що `t_r(P, Q_1 + Q_2) = t_r(P, Q_1) · t_r(P, Q_2)`.

За теоремою Вейля про взаємність дивізорів (англ. *Weil reciprocity theorem*), для будь-яких двох раціональних функцій `f, g ∈ F_q(E)*` із взаємно неперетинними носіями дивізорів виконується рівність:

```
f(div(g)) = g(div(f))
```

Нехай `g` — раціональна функція з дивізором `div(g) = (Q_1 + Q_2) - (Q_1) - (Q_2) + (O) = div(l_{Q_1, Q_2} / v_{Q_1 + Q_2})`.

Застосуємо теорему взаємності Вейля до цільової функції `f_{r,P}` (де `div(f_{r,P}) = r · (P) - r · (O)`) та функції `g`:

```
f_{r,P}(div(g)) = g(div(f_{r,P}))
```

Розкриваючи значення за означенням оцінки функції на дивізорі `f(∑ n_i (A_i)) = ∏ f(A_i)^{n_i}`:

```
f_{r,P}(Q_1 + Q_2) / ( f_{r,P}(Q_1) · f_{r,P}(Q_2) )
= ( g(P) / g(O) )^r  [за теоремою взаємності Вейля для div(f_{r,P}) = r·(P) - r·(O)]
= g(P)^r            [при нормуванні g(O) = 1]
```

Піднесемо обидві частини рівності до степеня `(q - 1) / r`:

```
( f_{r,P}(Q_1 + Q_2) / ( f_{r,P}(Q_1) · f_{r,P}(Q_2) ) )^( (q - 1) / r )
= ( g(P)^r )^( (q - 1) / r )  [піднесення до степеня e = (q - 1) / r]
= g(P)^(q - 1)                [скорочення r · (1/r)]
= 1                           [за малою теоремою Ферма в полі F_{p^k}*]
```

Звідси випливає:

```
t_r(P, Q_1 + Q_2) = t_r(P, Q_1) · t_r(P, Q_2)
```

Що повністю доводить білінійність спарювання Тейта за обома аргументами.

## 7. Повний числовий приклад розрахунку спарювання Тейта

Для закріплення теоретичного виведення виконаємо повний покроковий числовий розрахунок спарювання Тейта на малій навчальній кривій від ініціалізації до кінцевого елемента підгрупи коренів з одиниці.

### Параметри кривої та полів

- **Базове поле:** `F_{19}` (`p = 19`).
- **Рівняння кривої:** `E: y² = x³ + 1 (mod 19)` (параметри `a = 0, b = 1`).
- **Порядок підгрупи кручення:** `r = 3`.
- **Ступінь занурення:** `k = 2` (оскільки `r = 3 | (19² - 1) = 360`, але `3 ∤ (19 - 1) = 18`... зауважимо, що `19 ≡ 1 (mod 3)`, тому корінь з одиниці існує вже в `F_{19}`, а розширення `F_{19²}` містить повну групу `E[3] ≅ Z₃ × Z₃`).
- **Квадратичне розширення:** `F_{19²} = F_{19}[i] / (i² + 1)`. Елементи записуються як `u₀ + u₁ · i`, де `u₀, u₁ ∈ F_{19}`.
- **Показник фінального експонування:**
  ```
  e = (p² - 1) / r = (361 - 1) / 3 = 360 / 3 = 120
  ```

### Вхідні точки

1. **Точка `P ∈ E(F_{19})[3]`:**
   Виберемо `P = (0, 1)`.
   Перевірка належності кривій: `y² = 1² = 1`, `x³ + 1 = 0³ + 1 = 1 (mod 19)`.
   Обчислимо `[2]P`:
   Кутовий коефіцієнт дотичної:
   ```
   λ = (3 · x_P² + a) / (2 · y_P) = (3 · 0² + 0) / (2 · 1) = 0 / 2 = 0
   x_{2P} = λ² - 2 · x_P = 0 - 0 = 0
   y_{2P} = λ · (x_P - x_{2P}) - y_P = 0 - 1 = -1 ≡ 18 (mod 19)
   ```
   Отже, `[2]P = (0, 18) = -P`.
   Тоді `[3]P = [2]P + P = (0, 18) + (0, 1) = O`. Точка `P` справді має порядок `r = 3`.

2. **Точка `Q ∈ E(F_{19²})`:**
   Виберемо точку `Q = (5 + 4·i, 2 + 2·i)`.
   Перевіримо належність точці кривій:
   ```
   y_Q² = (2 + 2·i)² = 4 + 8·i + 4·i² = 4 + 8·i - 4 = 8·i (mod 19)
   x_Q² = (5 + 4·i)² = 25 + 40·i + 16·i² = 9 + 40·i ≡ 9 + 2·i (mod 19)
   x_Q³ = (9 + 2·i) · (5 + 4·i) = 45 + 36·i + 10·i - 8 = 37 + 46·i ≡ 18 + 8·i (mod 19)
   x_Q³ + 1 = 18 + 8·i + 1 = 19 + 8·i ≡ 8·i (mod 19)
   ```
   Рівність `y_Q² = x_Q³ + 1` виконується (`8·i = 8·i`), отже `Q ∈ E(F_{19²})`.

### Трасування циклу Міллера

Порядок `r = 3` у двійковому записі має вигляд `(11)₂`.
Довжина бітового розкладу — 2 біти (`b₁ = 1`, `b₀ = 1`).

#### Ініціалізація

- Поточна точка: `T = P = (0, 1)`.
- Акумулятор функції: `f = 1 + 0·i`.

#### Ітерація для біта b₀ = 1

Цикл проходить від старшого біта `b₁` до молодшого `b₀`.

**1. Крок подвоєння (Double Step: T → [2]T):**
- Обчислимо кутовий коефіцієнт дотичної до `T = (0, 1)`:
  ```
  λ = (3 · 0² + 0) / (2 · 1) = 0
  ```
- Оцінимо функцію дотичної прямої `l_{T,T}` у точці `Q = (5 + 4·i, 2 + 2·i)`:
  ```
  l_{T,T}(Q)
  = (y_Q - y_T) - λ · (x_Q - x_T)        [формула оцінки дотичної прямої]
  = (2 + 2·i - 1) - 0 · (5 + 4·i - 0)    [підстановка точок Q=(5+4·i, 2+2·i) та T=(0,1)]
  = 1 + 2·i                              [результат у полі F_{19²}]
  ```
- Оновлюємо точку `T`:
  ```
  x_{2T} = λ² - 2 · x_T = 0 - 0 = 0
  y_{2T} = λ · (x_T - x_{2T}) - y_T = 0 - 1 = -1 ≡ 18 (mod 19)
  [2]T = (0, 18)
  ```
- Оцінимо вертикальну пряму `v_{[2]T}` у точці `Q`:
  ```
  v_{[2]T}(Q) = x_Q - x_{2T} = 5 + 4·i - 0 = 5 + 4·i
  ```
- Обчислимо інверсію `1 / v_{[2]T}(Q)` у полі `F_{19²}`:
  Норма знаменника: `N = 5² + 4² = 25 + 16 = 41 ≡ 3 (mod 19)`.
  Інверсія норми: `3⁻¹ ≡ 13 (mod 19)` (бо `3 · 13 = 39 ≡ 1 (mod 19)`).
  ```
  (5 + 4·i)⁻¹ = 13 · (5 - 4·i) = 65 - 52·i ≡ 8 - 14·i ≡ 8 + 5·i (mod 19)
  ```
- Відношення прямих:
  ```
  l_{T,T}(Q) / v_{[2]T}(Q)
  = (1 + 2·i) · (8 + 5·i)                [множення чисельника на обернений знаменник]
  = 8 + 5·i + 16·i + 10·i²               [розкриття дужок у полі розширення]
  = 8 + 21·i - 10                        [підстановка i² = -1]
  = -2 + 21·i ≡ 17 + 2·i (mod 19)        [зведення за модулем p=19]
  ```
- Оновлення акумулятора `f`:
  ```
  f ← f² · ( l_{T,T}(Q) / v_{[2]T}(Q) ) = 1² · (17 + 2·i) = 17 + 2·i
  T ← [2]T = (0, 18)
  ```

**2. Крок додавання (Add Step: T + P, оскільки b₀ = 1):**
- Додаємо `T = (0, 18)` та `P = (0, 1)`.
- Оскільки `x_T = x_P = 0`, а `y_T = 18 = -y_P (mod 19)`, точки є взаємно протилежними: `T + P = O`.
- Січна пряма, що проходить через `(0, 18)` та `(0, 1)`, є вертикальною прямою `x = 0`:
  ```
  l_{T,P}(x, y) = x - 0 = x
  ```
- Її значення у точці `Q` дорівнює `l_{T,P}(Q) = x_Q = 5 + 4·i`.
- Вертикальна пряма на нескінченності `v_O` тотожно дорівнює `1`.
- Оновлення акумулятора `f`:
  ```
  f
  = (17 + 2·i) · (5 + 4·i)               [множення акумулятора на значення січної прямої]
  = 85 + 68·i + 10·i + 8·i²              [розкриття дужок у полі F_{19²}]
  = 85 + 78·i - 8                        [підстановка i² = -1]
  = 77 + 78·i                            [зведення подібних доданків]
  ≡ 1 + 2·i (mod 19)                     [зведення коефіцієнтів за модулем 19: 77≡1, 78≡2]
  ```

Результат виконання циклу Міллера: `f_{3,P}(Q) = 1 + 2·i ∈ F_{19²}`.

### Фінальне піднесення до степеня

Піднесемо `f = 1 + 2·i` до степеня `e = 120`.

Розкладемо показник `120` за допомогою легкого та важкого розкладів:
```
e = 120 = (p + 1) · ( (p - 1) / 3 ) = (19 + 1) · (18 / 3) = 20 · 6
```

1. **Легка частина (піднесення до степеня p + 1 = 20):**
   Застосовуючи автоморфізм Фробеніуса `π₁₉(1 + 2·i) = (1 + 2·i)¹⁹ = 1 - 2·i`:
   ```
   f^{p + 1}
   = f · f^p = f · f̄                      [властивість автоморфізму Фробеніуса у F_{p²}]
   = (1 + 2·i) · (1 - 2·i)                [підстановка f = 1 + 2·i та спряженого f̄]
   = 1 - 4·i² = 1 + 4 = 5 ∈ F_{19}        [підстановка i² = -1, дійсний результат у F_{19}]
   ```
   Отриманий проміжний результат `5` є дійсним елементом базового поля `F_{19}`.

2. **Важка частина (піднесення до степеня (p - 1)/3 = 6):**
   Обчислимо `5⁶ (mod 19)`:
   ```
   5² = 25 ≡ 6 (mod 19)                   [перший крок піднесення до квадрата]
   5⁴ = 6² = 36 ≡ 17 ≡ -2 (mod 19)        [другий крок піднесення до квадрата]
   5⁶ = 5⁴ · 5² ≡ (-2) · 6 = -12 ≡ 7 (mod 19) [підсумковий добуток за модулем 19]
   ```

### Підсумковий результат спарювання

```
t_3(P, Q) = 7 ∈ F_{19}*
```

**Перевірка властивостей результату:**
1. Елемент `7` є кубічним коренем з одиниці в полі `F_{19}`:
   ```
   7³ = 343 = 18 · 19 + 1 ≡ 1 (mod 19)
   ```
2. Елемент `7 ≠ 1`, що підтверджує **невиродженість** спарювання.
3. Перевірка білінійності: обчислимо спарювання для `[2]P = (0, 18)`:
   ```
   t_3([2]P, Q) = (t_3(P, Q))² = 7² = 49 = 2 · 19 + 11 ≡ 11 (mod 19)
   ```
   Перевіримо, чи є `11` другим коренем з одиниці:
   ```
   11³ = 1331 = 70 · 19 + 1 ≡ 1 (mod 19)
   ```
   Обидва корені `7` та `11` утворюють повну мультиплікативну групу `μ₃ = {1, 7, 11} ⊂ F_{19}*`.

## 8. Розклад дивізорів раціональних функцій на кривій

Для наочного розуміння зв'язку між геометрією та раціональними функціями обчислимо дивізор функції `f(x, y) = (y - 1) / x` на кривій `E: y² = x³ + 1` над `F_{19}`.

1. **Нулі та полюси функції чисельника `y - 1`:**
   Рівняння `y = 1` перетинає криву `y² = x³ + 1` при `1 = x³ + 1 ⇒ x³ = 0 ⇒ x = 0` (потрійний корінь).
   Точка `P = (0, 1)` є нулем функції `y - 1` кратності 3. На нескінченності `O` функція має полюс 3-го порядку:
   ```
   div(y - 1) = 3 · ( (0, 1) ) - 3 · (O)
   ```

2. **Нулі та полюси функції знаменника `x`:**
   Рівняння `x = 0` перетинає криву при `y² = 1 ⇒ y = 1` та `y = -1 ≡ 18 (mod 19)`.
   Точки `(0, 1)` та `(0, 18)` є нулями 1-го порядку. На нескінченності `O` функція `x` має полюс 2-го порядку:
   ```
   div(x) = ( (0, 1) ) + ( (0, 18) ) - 2 · (O)
   ```

3. **Дивізор частки `f(x, y) = (y - 1) / x`:**
   ```
   div( (y - 1) / x )
   = div(y - 1) - div(x)                                         [дивізор частки раціональних функцій]
   = [ 3·((0, 1)) - 3·(O) ] - [ ((0, 1)) + ((0, 18)) - 2·(O) ]    [підстановка обчислених дивізорів чисельника та знаменника]
   = 2 · ( (0, 1) ) - ( (0, 18) ) - (O)                          [зведення подібних формальних символів]
   ```

Перевіримо умови Абеля — Якобі для отриманого дивізора:
- `deg = 2 - 1 - 1 = 0`.
- `sum = 2 · (0, 1) - (0, 18) - O = (0, 18) - (0, 18) = O`.

Отриманий дивізор `2·(P) - ([2]P) - (O)` у точності відповідає функціональному дивізору Міллера `D_2` для точки `P = (0, 1)` при `m = 2`.

## 9. Математичне обґрунтування спарювання Optimal Ate та решіткова оптимізація

У спарюванні Ате аргументи міняються місцями: точка `Q ∈ G₂ = E'(F_{p^{k/d}})[r]` стає базою циклу Міллера, а точка `P ∈ G₁ = E(F_p)[r]` — точкою оцінки функції прямої.

Характеристичне рівняння ендоморфізму Фробеніуса `π_p(x, y) = (x^p, y^p)` на групі `G₂` має вигляд:

```
π_p(Q) = [p] Q
```

Оскільки `r | (p^k - 1)`, порядок `p` за модулем `r` пов'язаний зі слідом Фробеніуса `t = p + 1 - #E(F_p)` співвідношенням:

```
p ≡ t - 1 (mod r)
```

Позначивши `T = t - 1`, отримуємо дію `[T] Q = [p] Q` у підгрупі `G₂`.

У спарюванні Optimal Ate задача мінімізації довжини циклу Міллера формулюється як пошук найкоротшого вектора у решітці цілочисельних тотожностей:

```
L = { (c₀, c₁) ∈ Z² : c₀ + c₁ · p ≡ 0 (mod r) }
```

Застосовуючи алгоритм редукції базису решітки LLL (Ленстра — Ленстра — Ловас) або алгоритм Гауса для двовимірних решіток, знаходять короткий вектор `(c₀, c₁)` із нормами координат:

```
|c₀|, |c₁| ≤ r^{1 / φ(k)}
```

де `φ(k)` — функція Ейлера від ступеня занурення.

Тоді повна раціональна функція спарювання подається через добуток двох укорочених функцій Міллера:

```
a_{opt}(Q, P) = ( f_{c₀, Q}(P) · ( f_{c₁, Q}(P) )^p · l_{[c₀]Q, [c₁·p]Q}(P) )^( (p^k - 1) / r )
```

Оскільки піднесення до степеня `p` у полях `F_{p^k}` зводиться до миттєвого автоморфізму Фробеніуса `π_p`, кількість ітерацій циклу Міллера скорочується до:

```
L_{opt} ≈ log2(|c₀|) ≈ log2(r) / φ(k)
```

Для кривих типу BLS12 (`k = 12`, `φ(12) = 4`) порядок `r` має довжину 255 бітів, тоді як параметр скручування `x` має довжину всього 64 біти. Математична оптимізація спарювання Optimal Ate скорочує довжину циклу Міллера з 255 ітерацій (у спарюванні Тейта) до 64 ітерацій, що забезпечує чотирикратне теоретичне та практичне прискорення обчислення білінійного спарювання.
