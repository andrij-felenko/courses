# Динамічне програмування: Пошук числа Фробеніуса

Хоча для двох змінних ми маємо формулу Сильвестра g(a,b) = a·b - a - b, для n = 3 (наприклад, монети номіналом 6, 9 і 20) простої закритої формули не існує. Щоб перевірити, чи можна представити число, або знайти найбільше непредставиме число загалом, ми можемо використати підхід динамічного програмування (ДП).

Ось практичний C++17 скрипт, який вирішує цю задачу за допомогою одновимірного масиву (таблиці) ДП.

## Архітектура розв'язку

1. **Стан ДП:** `dp[i]` буде дорівнювати `true`, якщо суму `i` можна набрати наявними монетами, і `false` в іншому випадку.
2. **Базовий випадок:** `dp[0] = true` (суму 0 можна набрати, не використовуючи жодної монети).
3. **Переходи:** Для кожної суми `i` та для кожної монети `c`, якщо ми можемо набрати `i`, то ми можемо набрати й `i + c`. Тобто `dp[i + c] = dp[i] | dp[i + c]`.
4. **Межа пошуку:** Щоб знайти число Фробеніуса, нам треба ітеруватися до якоїсь розумної верхньої межі. Для n = 2 ця межа відома, а для n > 2 можна використати оцінки або просто достатньо велике число (наприклад, сума найменших двох помножених на найбільшу).
5. **Результат:** Останнє число, для якого `dp[i] == false`.

## C++17 Код

```cpp
#include <iostream>
#include <vector>
#include <numeric>
#include <algorithm>

// Функція для знаходження НСД вектора чисел
int find_gcd(const std::vector<int>& coins) {
    int res = coins[0];
    for (size_t i = 1; i < coins.size(); ++i) {
        res = std::gcd(res, coins[i]);
    }
    return res;
}

int frobenius_number(const std::vector<int>& coins) {
    if (find_gcd(coins) != 1) {
        return -1; // Числа Фробеніуса не існує, НСД > 1
    }

    // Для n=2 та n=3 верхня межа рідко перевищує 100000 для невеликих номіналів
    const int MAX_LIMIT = 100000;
    std::vector<bool> dp(MAX_LIMIT + 1, false);
    dp[0] = true;

    int last_unreachable = -1;

    for (int i = 0; i <= MAX_LIMIT; ++i) {
        if (!dp[i]) {
            last_unreachable = i;
        } else {
            for (int c : coins) {
                if (i + c <= MAX_LIMIT) {
                    dp[i + c] = true;
                }
            }
        }
    }

    return last_unreachable;
}

int main() {
    std::vector<int> coins_2 = {3, 5};
    std::vector<int> coins_3 = {6, 9, 20}; // g(6,9,20) = 43

    std::cout << "Frobenius number for (3, 5): " << frobenius_number(coins_2) << "\n";
    std::cout << "Expected: " << 3*5 - 3 - 5 << "\n";
    
    std::cout << "Frobenius number for (6, 9, 20): " << frobenius_number(coins_3) << "\n";
    
    return 0;
}
```

## Як це працює

Цей код створює вектор `dp` з `MAX_LIMIT` елементів. Ми йдемо від 0 до максимуму. Кожного разу, коли ми бачимо `dp[i] == false`, ми оновлюємо `last_unreachable`. Якщо `dp[i] == true`, ми розповсюджуємо цю істинність на всі можливі наступні кроки `i + c`, додаючи кожен номінал монети.

Цей підхід O(M·n), де M — максимальний ліміт, а n — кількість номіналів монет. Для практичних задач із невеликими монетами це надзвичайно швидкий і надійний метод.
