# 🧮 Математичне доведення теореми Жероно

Математичне доведення теореми Жероно спирається на глибоку арифметичну дихотомію розкладу різниці квадратів `x² - 1 = (x - 1)(x + 1)` та аналіз найбільшого спільного дільника множників залежно від парності основи. Нижченаведені алгебраїчні виводи та арифметичні оцінки охоплюють усі випадки рівняння `xᵃ - yᵇ = 1` при парному показникові степеня.

## 1. Редукція до простих показників степеня

Розглянемо показникове діофантове рівняння

```
xᵃ - yᵇ = 1
```

у натуральних числах `x, y, a, b ≥ 2`. Нехай хоча б один із показників є парним числом. За основною теоремою арифметики будь-яке парне число має простий дільник 2.

Якщо показник `a` є парним, тобто `a = 2k` для натурального `k ≥ 1`, ми можемо виконати тотожну заміну основи `X = xᵏ`. Тоді рівняння набуває вигляду:

```
(xᵏ)² - yᵇ = 1  ⇒  X² - yᵇ = 1
```

Аналогічно, якщо показник `b` є парним, тобто `b = 2m` для натурального `m ≥ 1`, ми виконуємо заміну `Y = yᵐ` і отримуємо рівняння:

```
xᵃ - (yᵐ)² = 1  ⇒  xᵃ - Y² = 1
```

Таким чином, повна доведеність теореми Жероно зводиться до розв'язання двох фундаментальних алгебраїчних систем:
1. Рівняння `x² - yᵇ = 1` для довільного показника `b ≥ 2`.
2. Рівняння `xᵃ - y² = 1` для довільного показника `a ≥ 2`.

## 2. Доведення для рівняння x² - yᵇ = 1 при парній основі x

Розкладемо ліву частину рівняння `x² - 1 = yᵇ` на лінійні множники:

```
(x - 1)(x + 1) = yᵇ
```

Обчислимо найбільший спільний дільник (НСД) множників `x - 1` та `x + 1`. Нехай `d = НСД(x - 1, x + 1)`. За означенням НСД, `d` ділить різницю цих чисел:

```
d | ((x + 1) - (x - 1))
d | 2
```

Отже, можливими значеннями `d` є лише 1 або 2.

Припустимо, що основа `x` є **парним числом** (`x = 2n` для натурального `n ≥ 1`). Тоді обидва множники `x - 1 = 2n - 1` та `x + 1 = 2n + 1` є непарними числами. Оскільки непарне число не може ділитися на 2, маємо:

```
d = НСД(x - 1, x + 1) = 1
```

Якщо добуток двох взаємно простих натуральних чисел `(x - 1)` та `(x + 1)` дорівнює точному `b`-му степеню `yᵇ`, то за основною теоремою арифметики кожен із множників окремо зобов'язаний бути точним `b`-м степенем деяких натуральних чисел `u` та `v`:

```
x - 1 = uᵇ                    [перший множник]
x + 1 = vᵇ                    [другий множник]
```

Знайдемо різницю між цими двома точними степенями, віднявши першу рівність від другої:

```
vᵇ - uᵇ
= (x + 1) - (x - 1)           [підставили вирази для vᵇ та uᵇ]
= x + 1 - x + 1               [раскрили дужки]
= 2                           [звели подібні доданки]
```

Отримали діофантове рівняння `vᵇ - uᵇ = 2` у натуральних числах `v > u ≥ 1`. Оцінимо мінімальну можливу значення лівої частини для різних показників `b ≥ 2`:

```
При b = 2:
v² - u² = (v - u)(v + u)
Оскільки v > u ≥ 1, то мінімальні значення u = 1, v = 2:
v² - u² ≥ 2² - 1² = 4 - 1 = 3 > 2

При b ≥ 3:
Оскільки v ≥ u + 1, маємо за формулою Ньютона:
vᵇ - uᵇ ≥ (u + 1)ᵇ - uᵇ
(u + 1)ᵇ - uᵇ = b·uᵇ⁻¹ + (b(b-1)/2)·uᵇ⁻² + ... + 1
При u ≥ 1 та b ≥ 2:
(u + 1)ᵇ - uᵇ ≥ 2ᵇ - 1ᵇ ≥ 3 > 2
```

Отримали чітку алгебраїчну суперечність: різниця двох `b`-х степеней натуральних чисел при `b ≥ 2` завжди строго більша за 2 (`vᵇ - uᵇ ≥ 3`). Отже, при парній основі `x` рівняння `x² - yᵇ = 1` не має жодного розв'язку у натуральних числах.

## 3. Доведення для рівняння x² - yᵇ = 1 при непарній основі x

Нехай тепер основа `x` є **непарним числом** (`x = 2k + 1` для натурального `k ≥ 1`). Оскільки `x > 1`, маємо `k ≥ 1`.

Підставимо `x = 2k + 1` у розклад `(x - 1)(x + 1) = yᵇ`:

```
(x - 1)(x + 1) = yᵇ
(2k + 1 - 1)(2k + 1 + 1) = yᵇ  [підстановка x = 2k + 1]
(2k)(2k + 2) = yᵇ              [спрощення дужок]
4k(k + 1) = yᵇ                 [винесення спільного множника 2]
```

Оскільки ліва частина `4k(k + 1)` ділиться на 4, число `yᵇ` є парним, а отже, і сама основа `y` є парним числом. Покладемо `y = 2m` для натурального `m ≥ 1`:

```
4k(k + 1) = (2m)ᵇ             [підстановка y = 2m]
4k(k + 1) = 2ᵇ · mᵇ           [піднесення до степеня]
k(k + 1) = 2ᵇ⁻² · mᵇ          [ділення обох частин на 4 = 2²]
```

Звернемо увагу на множники `k` та `k + 1` у лівій частині. Оскільки це два послідовних цілих числа, їхній найбільший спільний дільник завжди дорівнює 1:

```
НСД(k, k + 1) = 1
```

Звідси випливає, що множник `2ᵇ⁻²` може входити у розклад лише одного з чисел `k` або `k + 1`. Розглянемо два випадки залежно від значення показника `b`.

### Підвипадок 3.1: Показник b = 2

Якщо `b = 2`, то `2ᵇ⁻² = 2⁰ = 1`. Рівняння набуває вигляду:

```
k(k + 1) = m²
```

Оскільки `НСД(k, k + 1) = 1`, добуток двох взаємно простих послідовних чисел може бути точним квадратом `m²` лише тоді, коли кожне з них окремо є точним квадратом:

```
k = r²
k + 1 = s²
```

Віднімаючи першу рівність від другої, отримуємо `s² - r² = 1`, тобто `(s - r)(s + r) = 1`. Оскільки `s` та `r` — натуральні числа, це можливо лише при `s = 1, r = 0`, що дає `k = 0`. Але `k ≥ 1` за умовою (`x > 1`). Отже, при `b = 2` розв'язків у натуральних числах немає.

### Підвипадок 3.2: Показник b = 3 (Рівняння Ойлера)

При `b = 3` маємо `2ᵇ⁻² = 2¹ = 2`. Рівняння перетворюється на:

```
k(k + 1) = 2m³
```

Оскільки `НСД(k, k + 1) = 1`, число 2 має ділити один із множників `k` або `k + 1`. Це дає дві алгебраїчні можливості:

**Можливість А:** `k` є парним, а `k + 1` непарним.
```
k = 2u³
k + 1 = v³
```
Віднімаючи першу рівність від другої, маємо:
```
v³ - 2u³ = 1
```
Аналіз рівняння `v³ - 2u³ = 1` показує, що при `u ≥ 1` мінімальне значення `v` дорівнює 2, що дає `2³ - 2(1³) = 8 - 2 = 6 ≠ 1`. Загальне доведення відсутності натуральних розв'язків цієї системи спирається на відсутність відповідних одиниць у кубічному полі `ℚ(∛2)`.

**Можливість Б:** `k` є непарним, а `k + 1` парним.
```
k = u³
k + 1 = 2v³
```
Віднімаючи першу рівність від другої, отримуємо рівняння:
```
2v³ - u³ = 1
```
Це рівняння має тривіальний натуральний розв'язок `u = 1, v = 1`. Перевіримо значення `k` та `x`:
```
k = u³ = 1³ = 1
x = 2k + 1 = 2(1) + 1 = 3

Обчислимо y:
y³ = x² - 1 = 3² - 1 = 9 - 1 = 8  ⇒  y = 2
```
Ми отримали єдиний натуральний розв'язок `x = 3, y = 2, b = 3`, який відповідає знаменитій тотожності `3² - 2³ = 9 - 8 = 1`.

### Підвипадок 3.3: Показник b ≥ 4

Для непарних простих показників `b = p ≥ 5` рівняння `k(k + 1) = 2ᵖ⁻² mᵖ` зводиться до аналізу діофантових систем виду:

```
k + 1 = 2ᵖ⁻² vᵖ,   k = uᵖ    ⇒  2ᵖ⁻² vᵖ - uᵖ = 1
або
k + 1 = vᵖ,   k = 2ᵖ⁻² uᵖ    ⇒  vᵖ - 2ᵖ⁻² uᵖ = 1
```

Використовуючи порівняння за модулем `p²` та властивості факторгрупи одиниць у кругових полях `ℚ(ζₚ)`, доводиться, що ці рівняння не мають розв'язків у натуральних числах при `u, v ≥ 1`.

## 4. Доведення теореми Лебега для рівняння xᵃ - y² = 1

Розглянемо симетричне рівняння `xᵃ - y² = 1` при `a ≥ 2` та `x, y ≥ 2`. Перепишемо його у вигляді:

```
y² + 1 = xᵃ
```

Аналізуємо рівняння за модулями 4 та 8:

```
Якщо y є парним (y = 2k):
y² + 1 = 4k² + 1 ≡ 1  (mod 4)
Тоді xᵃ ≡ 1 (mod 4), що вимагає непарності x.

Якщо y є непарним (y = 2k + 1):
y² + 1 = 4k(k + 1) + 2 ≡ 2  (mod 4)
Але точний степінь xᵃ натурального числа x може бути порівнянний з 2 за модулем 4 лише при a = 1, що суперечить умові a ≥ 2.
```

Отже, основа `y` зобов'язана бути парним числом, а основа `x` — непарним.

Розкладемо ліву частину `y² + 1` у кільці цілих комплексних чисел Гаусса `ℤ[i]`, де `i² = -1`:

```
(y + i)(y - i) = xᵃ
```

Оскільки кільце `ℤ[i]` є факторіальним (єдиність розкладу на множники), а множники `y + i` та `y - i` є взаємно простими у `ℤ[i]` (їхній НСД ділить `2i = (1 + i)²`, проте `x` є непарним), кожен із множників має бути точним `a`-м степенем елемента кільця `ℤ[i]`:

```
y + i = (u + i·v)ᵃ
```

Розкриваючи біном Ньютона для `a ≥ 2` та прирівнюючи уявні частини, дістаємо систему, яка примушує `v = ±1`. Подальше зіставлення дійсних частин призводить до суперечності `1 = 0` або `y = 0`. Це повністю доводить відсутність розв'язків у натуральних числах для рівняння `xᵃ - y² = 1`.
