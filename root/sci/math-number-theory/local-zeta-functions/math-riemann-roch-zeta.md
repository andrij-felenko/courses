# 𝧮 Теорема Рімана–Роха та раціональність локальної дзета-функції

Ця вставка містить алгебраїчне виведення раціональності локальної дзета-функції `Z(C/𝔽_q, t)` та її функціонального рівняння для гладкої проективної алгебраїчної кривої `C` роду `g` над скінченним полем `𝔽_q`. Доведення спирається на геометрію дивізорів, простір Рімана–Роха, диференціальні форми, дуальність Серра та скінченність числа класів дивізорів Якобіана `J(C)(𝔽_q)`.

## 1. Алгебраїчний підгрунтовий апарат: Функціональні поля та дивізори

Нехай `C` — гладка проективна абсолютно незвідна крива роду `g` над скінченним полем `𝔽_q`.

Поле раціональних функцій кривої позначається через `K = 𝔽_q(C)`. Кожна замкнена точка `x ∈ |C|` (орбіта спряжених точок над алгебраїчним замиканням `𝔽_bar_q`) відповідає дискретному нормуванню `v_x: K* → ℤ`. Для будь-якої ненульової раціональної функції `f ∈ K*` це нормування визначає порядок нуля (`v_x(f) > 0`) або порядок полюса (`v_x(f) < 0`) у точці `x`.

Кільце локальних функцій у точці `x` позначається через `O_x = { f ∈ K* | v_x(f) ≥ 0 } ∪ { 0 }`. Його єдиний максимальний ідеал є `m_x = { f ∈ K* | v_x(f) > 0 } ∪ { 0 }`. Поле залишків `κ(x) = O_x / m_x` є скінченним розширенням базового поля `𝔽_q`.

Ступінь замкненої точки `deg(x)` є степенем розширення її поля залишків над базовим полем `𝔽_q`:

```
deg(x) = [ κ(x) : 𝔽_q ] = [ O_x / m_x : 𝔽_q ]
```

Абелева група дивізорів `Div(C)` — це вільна абелева група, заснована на множині замкнених точок кривої `C`. Елемент `D ∈ Div(C)` виражається у вигляді скінченної формальної суми:

```
D = ∑_{x ∈ |C|} n_x · [x]    (де n_x ∈ ℤ, і лише скінченна кількість n_x ≠ 0)
```

Ступінь дивізора `deg(D)` обчислюється як сума степенів точок із коефіцієнтами:

```
deg(D) = ∑_{x ∈ |C|} n_x · deg(x)
```

Відображення `deg: Div(C) → ℤ` є гомоморфізмом абелевих груп. Його ядро позначається через `Div⁰(C)` — це група дивізорів ступеня 0.

Дивізор `D` називається **ефективним** (позначається `D ≥ 0`), якщо всі його коефіцієнти є невід'ємними: `n_x ≥ 0` для всіх точок `x ∈ |C|`.

Кожній ненульовій раціональній функції `f ∈ K*` відповідає головний дивізор `div(f)`, визначений як сума її нулів та полюсів з урахуванням порядків мультиплікативності:

```
div(f) = ∑_{x ∈ |C|} v_x(f) · [x]
```

Оскільки крива `C` є проективною та гладкою, сумарна кількість нулів будь-якої раціональної функції дорівнює сумарній кількості її полюсів (з урахуванням степенів точок). Отже, ступінь будь-якого головного дивізора дорівнює нулю:

```
deg(div(f)) = 0
```

Множина головних дивізорів утворює підгрупу `Principal(C) ⊂ Div⁰(C)`. Вона задає точну послідовність абелевих груп:

```
1 → 𝔽_q* → K* → Div⁰(C) → Pic⁰(C) → 1
```

де перше відображення вкладає ненульові скаляри, а друге відображає функцію `f` у її головний дивізор `div(f)`.

## 2. Лінійні системи та вкладення кривих у проективні простори

Кожному дивізору `D` відповідає лінійна система `|D|`, яка складається з усіх ефективних дивізорів, лінійно еквівалентних `D`:

```
|D| = { D' ∈ Div(C) | D' ≥ 0, D' ∼ D }
```

Лінійна система `|D|` має природну структуру проективного простору `ℙ(L(D))` розмірності `r = l(D) - 1`. Базис векторного простору `L(D)`, що складається з функцій `(f₀, f₁, ..., f_r)`, визначає раціональне відображення кривої у проективний простір розмірності `r`:

```
φ_|D|: C → ℙʳ,    x ↦ (f₀(x) : f₁(x) : ... : f_r(x))
```

Згідно з класичною теоремою алгебраїчної геометрії:
1. Лінійна система `|D|` не має базисних точок (тобто відображення `φ_|D|` визначене скрізь на `C`) тоді і лише тоді, коли для кожної точки `x ∈ |C|` виконується `l(D - [x]) = l(D) - 1`. Це завжди виконується, якщо `deg(D) ≥ 2g`.
2. Відображення `φ_|D|` є **вкладенням** (ізоморфізмом кривої `C` на її образ у `ℙʳ`) тоді і лише тоді, коли для будь-яких двох точок `x, y ∈ |C|` виконується `l(D - [x] - [y]) = l(D) - 2`. Це завжди виконується для будь-якого дивізора ступеня `deg(D) ≥ 2g + 1`.

Для канонічного дивізора `K` ступеня `2g - 2` відповідне канонічне відображення `φ_|K|: C → ℙᵍ⁻¹` вкладає будь-яку неканонічну криву роду `g ≥ 2` як гладку проективну криву в `ℙᵍ⁻¹`. Для гіпереліптичних кривих відображення `φ_|K|` є дволистним накриттям проективної прямої `ℙ¹`.

Ця геометрична структура лінійних систем пояснює, чому розмірності `l(D)` стають строго регулярними `l(D) = deg(D) + 1 - g` для всіх дивізорів великого ступеня `deg(D) ≥ 2g - 1`.

## 3. Твірна функція дивізорів та Ейлерів добуток

Розглянемо кількість ефективних дивізорів ступеня `m ≥ 0`. Позначимо цю кількість через `A_m`:

```
A_m = # { D ∈ Div(C) | D ≥ 0, deg(D) = m }
```

Твірна функція для послідовності `A_m` задається як степеневий ряд від формальної змінної `t`:

```
Z(C, t) = ∑_{m=0}^∞ A_m · tᵐ
```

Кожен ефективний дивізор `D ≥ 0` унікально розкладається на суму простих замкнених точок `x`: `D = ∑ k_x [x]` з `k_x ≥ 0`. Завдяки цій унікальності твірна функція `Z(C, t)` може бути переписана у вигляді нескінченного добутку по всіх замкнених точках `x ∈ |C|`:

```
Z(C, t) = ∏_{x ∈ |C|} ( 1 + t^{deg(x)} + t^{2·deg(x)} + t^{3·deg(x)} + ... )
```

Кожен множник у цьому добутку є сумою нескінченної спадної геометричної прогресії зі знаменником `t^{deg(x)}`. Застосувавши формулу суми геометричної прогресії `1 / (1 - u)`, отримуємо канонічний Ейлерів добуток:

```
Z(C, t) = ∏_{x ∈ |C|} 1 / (1 - t^{deg(x)})
```

Цей добуток демонструє, що Дзета-функція кривої є арифметичним інваріантом, який повністю упаковує геометрію розподілу простих точок будь-яких степенів над полем `𝔽_q`.

## 3. Простори Рімана–Роха та скінченність Якобіана

Для будь-якого дивізора `D ∈ Div(C)` визначається векторний простір Рімана–Роха `L(D)`. Він складається з тих раціональних функцій `f ∈ K*`, чиї полюси обмежені ефективною частиною `D`:

```
L(D) = { f ∈ K* | div(f) + D ≥ 0 } ∪ { 0 }
```

Простір `L(D)` є скінченновимірним векторним простором над базовим полем `𝔽_q`. Його розмірність позначається через `l(D) = dim_{𝔽_q} L(D)`.

Два дивізори `D₁` та `D₂` називаються **лінійно еквівалентними** (позначається `D₁ ∼ D₂`), якщо їхня різниця є головним дивізором: `D₁ - D₂ = div(f)` для деякої функції `f ∈ K*`.

Фактор-група `Pic(C) = Div(C) / Principal(C)` називається групою класів дивізорів. Відображення степеня індукує гомоморфізм `Pic(C) → ℤ`. Його ядро позначається через `Pic⁰(C) = Div⁰(C) / Principal(C)`.

Група `Pic⁰(C)` ізоморфна множині `𝔽_q`-раціональних точок Якобіана кривої `J(C)(𝔽_q)`. Оскільки поле `𝔽_q` є скінченним, а Якобіан є абелевим многовидом (компактним алгебраїчним многовидом), група `Pic⁰(C)` є **скінченною абелевою групою**. Позначимо порядок цієї групи через `h`:

```
h = # Pic⁰(C) = # J(C)(𝔽_q)
```

Число `h` називається числом класів дивізорів (або класовим числом кривої `C`).

Для будь-якого фіксованого ступеня `m ∈ ℤ` кількість класів лінійної еквівалентності дивізорів ступеня `m` також дорівнює `h` (при умові існування хоча б одного дивізора ступеня `m`).

З'ясуємо, скільки ефективних дивізорів міститься в одному конкретному класі лінійної еквівалентності `[D]`.

Два ефективних дивізори `D'` та `D''` належать одному класу `[D]` тоді і лише тоді, коли `D' - D = div(f)` та `D'' - D = div(g)` для функцій `f, g ∈ L(D)`. При цьому дві ненульові функції `f` та `g` визначають один і той самий ефективний дивізор `div(f) + D = div(g) + D` тоді і лише тоді, коли вони відрізняються на константний ненульовий множник `c ∈ 𝔽_q*` (тобто `f = c · g`).

Отже, множина ефективних дивізорів у класі `[D]` перебуває у взаємно однозначній відповідності з точками проективного простору `ℙ(L(D))` над полем `𝔽_q`. Оскільки простір `L(D)` має розмірність `l(D)`, кількість точок у його проективізації дорівнює:

```
# { D' ≥ 0 | D' ∼ D } = # ℙ(L(D)) = (q^{l(D)} - 1) / (q - 1)
```

Тепер обчислимо загальну кількість ефективних дивізорів `A_m` ступеня `m`. Для цього підсумуємо кількості ефективних дивізорів по всіх `h` класах дивізорів `C_1, C_2, ..., C_h` ступеня `m`:

```
A_m = ∑_{j=1}^h (q^{l(D_j)} - 1) / (q - 1)
```

де `D_j` — довільно обраний представник `j`-го класу дивізорів ступеня `m`.

## 4. Точний аналіз за Теоремою Рімана–Роха

Теорема Рімана–Роха є центральним інструментом обчислення розмірностей `l(D)`. Вона стверджує, що для будь-якого дивізора `D ∈ Div(C)` виконується точна алгебраїчна тотожність:

```
l(D) - l(K - D) = deg(D) + 1 - g
```

де `K` — канонічний дивізор кривої `C` (дивізор ненульової канонічної диференціальної 1-форми `ω ∈ Ω¹(C)`), який має ступінь `deg(K) = 2g - 2`. Простір голоморфних диференціальних форм `Ω¹(C)` має розмірність `dim_{𝔽_q} H⁰(C, Ω¹) = g`.

Проаналізуємо значення розмірностей `l(D)` залежно від ступеня `m = deg(D)`:

### Зона 1: Від'ємний ступінь (`m < 0`)
Якщо `deg(D) < 0`, то на кривій `C` не існує жодного ефективного дивізора. Справді, якби існував `D' ≥ 0` та `D' ∼ D`, то `deg(D') = deg(D) < 0`, що суперечить визначенню ефективності (`deg(D') = ∑ n_x deg(x) ≥ 0`).

Отже, для всіх `D` зі ступенем `m < 0` маємо `l(D) = 0`, і кількість ефективних дивізорів дорівнює `A_m = 0`.

### Зона 2: Великий ступінь (`m > 2g - 2`)
Якщо `deg(D) > 2g - 2`, то ступінь дивізора `K - D` становить:

```
deg(K - D) = (2g - 2) - m < 0
```

Зважаючи на результат Зони 1, для дивізора `K - D` від'ємного ступеня простір Рімана–Роха є нульовим: `l(K - D) = 0`.

Підставивши `l(K - D) = 0` у тотожність Рімана–Роха, отримуємо точний вираз для розмірності:

```
l(D) = deg(D) + 1 - g = m + 1 - g
```

Це фундаментальний результат: для всіх дивізорів ступеня `m > 2g - 2` розмірність `l(D)` **не залежить від конкретного класу дивізора `D`**, а визначається виключно його ступенем `m` та родом кривої `g`!

Завдяки цьому всі `h` доданків у сумі для `A_m` стають однаковими:

```
A_m = ∑_{j=1}^h (q^{m + 1 - g} - 1) / (q - 1) = h · (q^{m + 1 - g} - 1) / (q - 1)   (для всіх m ≥ 2g - 1)
```

### Зона 3: Проміжна критична зона (`0 ≤ m ≤ 2g - 2`)
У цій зоні розмірності `l(D_j)` можуть різнитися для різних класів дивізорів одного й того самого ступеня `m`. Проте для кожного `m` значення `A_m` є скінченним цілим числом. Загальна кількість таких проміжних членів становить рівно `2g - 1` (для `m = 0, 1, ..., 2g - 2`).

Зокрема, проаналізуємо крайові значення Зони 3:
- Для `m = 0`: єдиним ефективним дивізором ступеня 0 є нульовий дивізор `D = 0`. Єдиними функціями без полюсів на проективній кривій є константи `f ∈ 𝔽_q`. Отже, `l(0) = 1` і `A_0 = 1`.
- Для `m = 2g - 2`: канонічний дивізор `K` має `deg(K) = 2g - 2`. За теоремою Рімана–Роха `l(K) - l(0) = (2g - 2) + 1 - g = g - 1`. Оскільки `l(0) = 1`, маємо `l(K) = g`.

Для еліптичної кривої (`g = 1`) Зона 3 звужується до єдиної точки `m = 0` (оскільки `2g - 2 = 0`). Для `g = 1` розмірності просторів повністю визначені для всіх `m ≥ 0`:
- `m = 0`: `l(D) = 1`, `A_0 = 1`.
- `m ≥ 1`: `l(D) = m`, `A_m = h · (qᵐ - 1) / (q - 1)`.

Для кривої роду `g = 2` Зона 3 охоплює степені `m = 0, 1, 2`.

## 5. Явні приклади підрахунку дивізорів та сумування для g = 0 та g = 1

Розглянемо явне сумування дивізорів для кривих роду 0 та роду 1, яке наочно ілюструє роботу механізму Рімана–Роха.

### Приклад 1. Проективна пряма `ℙ¹` (`g = 0`)
Для проективної прямої `ℙ¹` рід дорівнює `g = 0`. Число класів дивізорів `h = 1` (кожен дивізор ступеня 0 є головним).

Ступінь канонічного дивізора дорівнює `deg(K) = 2g - 2 = -2 < 0`. Отже, Зона 3 взагалі відсутня (оскільки `2g - 1 = -1`). Для всіх `m ≥ 0` розмірність за формулою Рімана–Роха становить `l(D) = m + 1 - 0 = m + 1`.

Кількість ефективних дивізорів ступеня `m` дорівнює:

```
A_m = (q^{m + 1} - 1) / (q - 1) = 1 + q + q² + ... + qᵐ
```

Обчислимо твірну функцію `Z(ℙ¹, t)` через сумування за `A_m`:

```
Z(ℙ¹, t) = ∑_{m=0}^∞ [ (q^{m + 1} - 1) / (q - 1) ] · tᵐ
         = (1 / (q - 1)) · [ q · ∑_{m=0}^∞ (q·t)ᵐ  -  ∑_{m=0}^∞ tᵐ ]
         = (1 / (q - 1)) · [ q / (1 - q·t)  -  1 / (1 - t) ]
         = (1 / (q - 1)) · [ (q · (1 - t) - (1 - q·t)) / ((1 - t)(1 - q·t)) ]
         = (1 / (q - 1)) · [ (q - 1) / ((1 - t)(1 - q·t)) ]
         = 1 / ( (1 - t) · (1 - q·t) )
```

Отриманий дріб повністю збігається з логарифмічним рядам експоненти для `N_n = qⁿ + 1`!

### Приклад 2. Еліптична крива `E` (`g = 1`)
Для еліптичної кривої `E` рід дорівнює `g = 1`. Канонічний дивізор має ступінь `deg(K) = 0`. Число класів дивізорів ступеня 0 дорівнює кількості точок кривої `h = #E(𝔽_q) = N₁`.

Значення `A_m` розподіляються наступним чином:
- `m = 0`: `A_0 = 1` (лише нульовий дивізор).
- `m ≥ 1`: `l(D) = m`, отже `A_m = h · (qᵐ - 1) / (q - 1)`.

Підставимо ці значення у суму `Z(E, t)`:

```
Z(E, t) = 1  +  ∑_{m=1}^∞ [ h · (qᵐ - 1) / (q - 1) ] · tᵐ
        = 1  +  (h / (q - 1)) · [ ∑_{m=1}^∞ (q·t)ᵐ  -  ∑_{m=1}^∞ tᵐ ]
        = 1  +  (h / (q - 1)) · [ (q·t / (1 - q·t))  -  (t / (1 - t)) ]
        = 1  +  (h / (q - 1)) · [ (q·t(1 - t) - t(1 - q·t)) / ((1 - t)(1 - q·t)) ]
        = 1  +  (h / (q - 1)) · [ (q·t - t) / ((1 - t)(1 - q·t)) ]
        = 1  +  (h · t) / ( (1 - t) · (1 - q·t) )
        = [ (1 - t)(1 - q·t) + h·t ] / [ (1 - t)(1 - q·t) ]
        = [ 1 - (q + 1)t + q·t² + h·t ] / [ (1 - t)(1 - q·t) ]
        = [ 1 - (q + 1 - h)t + q·t² ] / [ (1 - t)(1 - q·t) ]
```

Поклавши `a = q + 1 - h = q + 1 - N₁`, отримуємо точний чисельник `P(t) = 1 - a·t + q·t²`. Це демонструє повну узгодженість теорії Рімана–Роха з аналізом сліду Фробеніуса!

### Приклад 3. Гіпереліптична крива `C₂` роду `g = 2`
Для кривої роду `g = 2` канонічний дивізор має ступінь `deg(K) = 2g - 2 = 2`. Зона 3 охоплює степені `m = 0, 1, 2`.

Поліном чисельника `P(t)` має ступінь `2g = 4` і містить два незалежні коефіцієнти `a₁` та `a₂`:

```
P(t) = 1 - a₁·t + a₂·t² - a₁·q·t³ + q²·t⁴
```

Значення `A_m` для роду 2 задовольняють співвідношення:
- `m = 0`: `A_0 = 1`.
- `m = 1`: `A_1 = #C(𝔽_q) = N₁`. (Оскільки кожен ефективний дивізор ступеня 1 на кривій є просто раціональною точкою).
- `m = 2`: за теоремою Рімана–Роха `l(D) - l(K - D) = 2 + 1 - 2 = 1`. Для канонічного класу `[K]` маємо `l(K) = 2`, що дає канонічний пучок точок. Для інших невироджених класів `l(D) = 1`.

Кількість точок Якобіана `h = #J(C₂)(𝔽_q)` виражається через значення чисельника `P(1)`:

```
h = P(1) = 1 - a₁ + a₂ - a₁·q + q² = q² + 1 - a₁(q + 1) + a₂
```

Виразимо коефіцієнти `a₁` та `a₂` через кількості точок над базовим полем `N₁ = #C(𝔽_q)` та його розширенням `N₂ = #C(𝔽_{q²})`. З формули підйому точок через 4 власні значення Фробеніуса `α₁, α₂, α₃, α₄` маємо:

```
N₁ = q + 1 - (α₁ + α₂ + α₃ + α₄) = q + 1 - a₁  ⇒  a₁ = q + 1 - N₁
```

```
N₂ = q² + 1 - (α₁² + α₂² + α₃² + α₄²)
```

За тотожностями Ньютона сума квадратів виражається як `α₁² + α₂² + α₃² + α₄² = a₁² - 2a₂`. Підставивши це в формулу для `N₂`:

```
N₂ = q² + 1 - (a₁² - 2a₂)  ⇒  a₂ = (N₂ - q² - 1 + a₁²) / 2
```

Це дозволяє обчислити повний чисельник Дзета-функції `P(t)` кривої роду 2, знаючи лише підрахунок точок `N₁` над `𝔽_q` та `N₂` над `𝔽_{q²}`!

## 6. Доведення Раціональності Дзета-функції у загальному випадку

Розділимо нескінченну суму твірної функції `Z(C, t) = ∑_{m=0}^∞ A_m tᵐ` на дві частини: скінченний поліном для `0 ≤ m ≤ 2g - 2` та нескінченний хвіст `S_{tail}(t)` для `m ≥ 2g - 1`:

```
Z(C, t) = ∑_{m=0}^{2g-2} A_m · tᵐ  +  S_{tail}(t)
```

Обчислимо нескінченну суму хвоста `S_{tail}(t)` за допомогою формули для `A_m` при `m ≥ 2g - 1`:

```
S_{tail}(t)
= ∑_{m=2g-1}^∞ [ h · (q^{m + 1 - g} - 1) / (q - 1) ] · tᵐ             [підстановка значення A_m для m ≥ 2g-1]
= (h / (q - 1)) · [ q^{1-g} · ∑_{m=2g-1}^∞ (q·t)ᵐ  -  ∑_{m=2g-1}^∞ tᵐ ]    [винесення константних множників]
```

Застосуємо формулу суми нескінченної геометричної прогресії `∑_{m=k}^∞ uᵐ = uᵏ / (1 - u)`:

```
∑_{m=2g-1}^∞ (q·t)ᵐ = (q·t)^{2g-1} / (1 - q·t)
```

```
∑_{m=2g-1}^∞ tᵐ = t^{2g-1} / (1 - t)
```

Підставивши ці суми, отримуємо для `S_{tail}(t)` дріб зі спільним знаменником `(1 - t) · (1 - q·t)`:

```
S_{tail}(t)
= (h / (q - 1)) · [ (qᵍ · t^{2g-1}) / (1 - q·t)  -  (t^{2g-1}) / (1 - t) ]                        [підстановка сум прогресій]
= [ h · qᵍ · t^{2g-1} · (1 - t) - h · t^{2g-1} · (1 - q·t) ] / [ (q - 1) · (1 - t) · (1 - q·t) ]   [зведення до спільного знаменника]
= [ h · t^{2g-1} · (qᵍ - 1 + t·(q - qᵍ)) ] / [ (q - 1) · (1 - t) · (1 - q·t) ]                    [групування коефіцієнтів при t]
```

Тепер зведемо всю суму `Z(C, t) = ∑_{m=0}^{2g-2} A_m tᵐ + S_{tail}(t)` до спільного знаменника `(1 - t) · (1 - q·t)`:

```
Z(C, t) = P(t) / ( (1 - t) · (1 - q·t) )
```

де чисельник `P(t)` задається явним поліномом:

```
P(t) = (1 - t) · (1 - q·t) · ∑_{m=0}^{2g-2} A_m · tᵐ  +  (h / (q - 1)) · [ qᵍ · t^{2g-1} · (1 - t) - t^{2g-1} · (1 - q·t) ]
```

Оскільки перша частина є добутком поліномів степенів `2` та `2g - 2` (тобто має ступінь `2g`), а друга частина також є поліномом степеня `2g`, чисельник `P(t)` є цілочисельним поліномом степеня `2g`:

```
P(t) ∈ ℤ[t],    deg(P) = 2g
```

Це повністю доводить **Раціональність** локальної Дзета-функції!

## 7. Дуальність Серра та Доведення Функціонального Рівняння

Дуальність Серра для алгебраїчних кривих стверджує наявність канонічного невиродженого парного спарювання між просторами когомологій векторних розшарувань:

```
H⁰(C, O(D)) × H¹(C, O(D)) → 𝔽_q
```

Оскільки `H¹(C, O(D)) ≅ H⁰(C, Ω¹(-D)) = L(K - D)`, дуальність Серра встановлює точний ізоморфізм дуальних просторів.

Це додає дзеркальну симетрію для кількості ефективних дивізорів протилежних класів: відображення `D ↦ K - D` встановлює бієкцію між класами дивізорів степеня `m` та класами дивізорів степеня `2g - 2 - m`.

Використовуючи тотожність `l(K - D) = l(D) - m - 1 + g`, знаходимо зв'язок між `A_m` та `A_{2g - 2 - m}`:

```
A_{2g - 2 - m} = q^{g - 1 - m} · A_m
```

Підставивши цю дзеркальну симетрію у формулу для полінома `P(t)`, ми отримуємо фундаментальну тотожність:

```
P(t) = qᵍ · t²ᵍ · P(1 / (q·t))
```

З цієї симетрії чисельника негайно випливає **Функціональне рівняння** для всієї локальної Дзета-функції:

```
Z(C/𝔽_q, 1 / (q·t)) = Z(C/𝔽_q, t) · (q · t²)¹⁻ᵍ
```

Обчислимо значення чисельника у точці `t = 1`:

```
P(1) = (1 - 1) · (1 - q) · ∑ A_m + (h / (q - 1)) · [ qᵍ · (0) - 1 · (1 - q) ]
     = (h / (q - 1)) · (q - 1) = h
```

Отримане значення `P(1) = h` має глибокий геометро-топологічний зміст: воно показує, що кількість раціональних точок на многовиді Якобі `J(C)(𝔽_q)` повністю визначається чисельником Дзета-функції кривої `C`. Своєю чергою, за гіпотезою Вейля всі власні значення Фробеніуса `α_i` на Якобіані маю рівно модуль `√q`.

Узагальнення цієї теорії на абелеві многовиди та многовиди вищих розмірностей `V` вимагало побудови етальних ℓ-адичних когомологій Гротендіка. Проте саме для кривих геометричний апарат Рімана–Роха та класи дивізорів дозволяють отримати повне алгебраїчне доведення раціональності та функціонального рівняння без використання важкої когомологічної машинії.

Крім того, оскільки група класів дивізорів `Pic⁰(C)` задає абелеву групу раціональних точок Якобіана, теорема Рімана–Роха гарантує, що порядок цієї групи `h = P(1)` безпосередньо зв'язує коефіцієнти чисельника з класичним класовим числом функціонального поля `𝔽_q(C)`. Це встановлює фундаментальну арифметичну тотожність між Дзета-функцією та абелевими розширеннями у теорії полів класів за аналогією з числовою дзета-функцією Дедекінда.

Таким чином, теорія дивізорів та теорема Рімана–Роха зводять аналіз нескінченного Ейлерового добутку до обчислення характеристичного полінома скінченновимірного лінійного оператора Фробеніуса, встановлюючи повний зв'язок між алгеброю, топологією та теорією чисел.
