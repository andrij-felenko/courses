# Обчислення оберненого елемента за модулем

Уміння знаходити обернений елемент за модулем є критично важливим для криптографії та комбінаторики, де операція ділення замінюється множенням на відповідний обернений елемент. Наприклад, щоб обчислити вираз вигляду (A / B) mod M, ми повинні спочатку знайти таке число C, для якого виконується умова (B * C) mod M = 1, і тоді результат ділення обчислюється як (A * C) mod M. У цьому проєкті ми реалізуємо два найпоширеніші алгоритми мовою програмування C++17: розширений алгоритм Евкліда та малу теорему Ферма.

Алгоритм Евкліда є універсальним інструментом і працює для будь-якого модуля M, за єдиної умови, що числа B та M є взаємно простими (їхній найбільший спільний дільник дорівнює одиниці). Мала теорема Ферма працює швидше і вимагає менше коду, але має жорстке обмеження: модуль M обов'язково має бути простим числом. У практичних задачах криптографії, таких як алгоритм RSA, або під час обчислення біноміальних коефіцієнтів у спортивному програмуванні, найчастіше використовують саме великі прості модулі, наприклад 1000000007 або 998244353. Тому обидва методи мають широке практичне застосування.

## Структура програми

Наша програма містить обидва методи. Для обчислення за теоремою Ферма ми використаємо алгоритм швидкого піднесення до степеня. Якщо ж числа не є взаємно простими, оберненого елемента не існує, про що алгоритм Евкліда нас попередить, згенерувавши виключення.

### 1. Мета скрипту

Цей скрипт демонструє, як швидко знайти таке ціле число X, що (A * X) mod M = 1, використовуючи два різні підходи, та виводить результати для їхнього порівняння.

### 2. Залежності та налаштування

Для реалізації нам знадобляться базові бібліотеки введення-виведення, обробки виключень та роботи з кортежами, які з'явилися у сучасних стандартах мови.

```cpp
#include <iostream>
```

### 3. Основна логіка: алгоритми

Спочатку реалізуємо розширений алгоритм Евкліда, який повертає не лише найбільший спільний дільник (НСД), а й коефіцієнти x та y рівняння A*x + M*y = НСД(A, M).

```cpp
// Розширений алгоритм Евкліда
// Повертає кортеж (gcd(a, b), x, y) такі, що a*x + b*y = gcd(a, b)
std::tuple<long long, long long, long long> extendedGcd(long long a, long long b) {
    if (b == 0) {
        return {a, 1, 0};
    }
    auto [gcd, x1, y1] = extendedGcd(b, a % b);
    long long x = y1;
    long long y = x1 - y1 * (a / b);
    return {gcd, x, y};
}

// Знаходження оберненого елемента за модулем m через алгоритм Евкліда
long long modInverseGcd(long long a, long long m) {
    auto [gcd, x, y] = extendedGcd(a, m);
    if (gcd != 1) {
        throw std::invalid_argument("Оберненого елемента не існує (числа не взаємно прості)");
    }
    return (x % m + m) % m; // Забезпечення додатного результату
}
```

Для малої теореми Ферма відомо, що A^(M-1) = 1 mod M, отже обернений елемент дорівнює A^(M-2) mod M. Реалізуємо швидке піднесення до степеня за модулем, яке працює за логарифмічний час.

```cpp
// Швидке піднесення a до степеня b за модулем m
long long powerMod(long long a, long long b, long long m) {
    long long result = 1;
    a = a % m;
    while (b > 0) {
        if (b % 2 == 1) {
            result = (result * a) % m;
        }
        b /= 2;
        a = (a * a) % m;
    }
    return result;
}

// Знаходження оберненого елемента за модулем m (m обов'язково має бути простим)
long long modInverseFermat(long long a, long long m) {
    return powerMod(a, m - 2, m);
}
```

### 4. Точка входу

У головній функції ми перевіримо обидва методи на конкретному прикладі. Виберемо відоме просте число як модуль, щоб обидва алгоритми спрацювали успішно та показали однаковий результат.

```cpp
int main() {
    long long a = 42;
    long long m = 1000000007; // Відомий простий модуль

    std::cout << "Шукаємо обернений елемент для a = " << a << " за модулем m = " << m << "\n";

    try {
        long long invGcd = modInverseGcd(a, m);
        std::cout << "Результат (Евклід): " << invGcd << "\n";
        std::cout << "Перевірка: (" << a << " * " << invGcd << ") mod " << m << " = " 
                  << (a * invGcd) % m << "\n";
                  
        long long invFermat = modInverseFermat(a, m);
        std::cout << "Результат (Ферма) : " << invFermat << "\n";
        std::cout << "Перевірка: (" << a << " * " << invFermat << ") mod " << m << " = " 
                  << (a * invFermat) % m << "\n";
                  
    } catch (const std::exception& e) {
        std::cerr << "Помилка: " << e.what() << "\n";
    }

    return 0;
}
```

### 5. Компіляція та запуск

Збережіть код у файл `inverse.cpp` та скомпілюйте його. Використання стандарту C++17 є необхідним для коректної роботи структурованого зв'язування (structured binding) під час розпакування кортежів у розширеному алгоритмі Евкліда.

```bash
g++ -std=c++17 -O2 inverse.cpp -o inverse
./inverse
```

Ми успішно реалізували та протестували два класичні методи пошуку оберненого елемента. Хоча розширений алгоритм Евкліда виглядає дещо складнішим у реалізації через використання рекурсії та розпакування значень із кортежів, він є значно більш універсальним інструментом, оскільки не накладає жорстких обмежень на простоту модуля. Метод, заснований на малій теоремі Ферма, з іншого боку, дуже легко імплементується. Якщо у вашому базовому наборі інструментів вже є функція швидкого піднесення до степеня за модулем (яка є стандартною для розробників криптографічних систем та учасників змагань зі спортивного програмування), додавання функції пошуку оберненого елемента займає лише один рядок коду. Завжди зважайте на те, з яким саме модулем працює ваша програма, щоб обрати найефективніший підхід.
