# 🧮 Алгебраїчна структура кільця арифметичних функцій та строге обернення Мебіуса

Для глибокого розуміння природи цілих чисел та співвідношень між арифметичними функціями необхідно розглянути їх не просто як окремі обчислювальні правила, а як елементи впорядкованої алгебраїчної структури. Множина всіх комплекснозначних функцій, визначених на додатних цілих числах, утворює комутативне кільце з одиницею відносно точкового додавання та згортки Діріхле. Нижче наведено строгі математичні виведення алгебраїчних властивостей цієї структури, побудову обернених елементів, топологічну повноту, метод формальних степенних рядів Белла, теорію арифметичного диференціювання та загальне обернення Мебіуса на частково впорядкованих множинах.

## 1. Аксіоми кільця арифметичних функцій та відсутність дільників нуля

Нехай `A = {f: ℤ⁺ → ℂ}` — множина всіх арифметичних функцій, що зіставляють кожному натуральному числу `n ∈ {1, 2, 3, ...}` деяке комплексне число `f(n)`. Ця множина природно є нескінченновимірним векторним простором над полем комплексних чисел `ℂ` відносно звичайного точкового додавання функцій та множення на скаляри.

Визначимо на множині `A` дві бінарні внутрішні алгебраїчні операції:

1. **Точкове додавання:** Сумою двох арифметичних функцій `f` та `g` називається функція `(f + g)`, значення якої в кожній точці `n` дорівнює алгебраїчній сумі значень: `(f + g)(n) = f(n) + g(n)`.
2. **Згортка Діріхле:** Добутком (згорткою) двох арифметичних функцій `f` та `g` називається нова функція `(f * g)`, значення якої в точці `n` обчислюється як сума добутків `f(a) g(b)` за всіма парами дільників `a` та `b`, добуток яких дорівнює `n`:
   ```
   (f * g)(n) = ∑_{d|n} f(d) g(n/d) = ∑_{a · b = n} f(a) g(b)
   ```

Множина `A` із цими операціями утворює комутативне асоціативне кільце з одиницею, яке є цілісним доменом (областю цілісності). Доведемо покроково виконання всіх кільцевих аксіом.

### Комутативність операції згортки

Властивість комутативності стверджує, що для будь-яких двох функцій `f, g ∈ A` результат їхньої згортки не залежить від порядку множників: `f * g = g * f`.

Для довільного натурального числа `n` розпишемо ліву частину рівності за означенням згортки:

```
(f * g)(n)
= ∑_{a·b = n} f(a) g(b)          [означення згортки через впорядковані пари дільників]
= ∑_{b·a = n} g(b) f(a)          [комутативність множення комплексних чисел у полі C]
= (g * f)(n)                     [висновок: f * g = g * f]
```

Оскільки рівність справджується для будь-якого `n ≥ 1`, операція згортки є строго комутативною на всьому просторі `A`.

### Асоціативність операції згортки

Властивість асоціативності стверджує, що при послідовному перемноженні трьох довільних арифметичних функцій `f, g, h ∈ A` результат групування множників є тотожним: `(f * g) * h = f * (g * h)`.

Для доведення розгорнемо ліву частину в подвійну скінченну суму за дільниками числа `n`:

```
((f * g) * h)(n)
= ∑_{d·c = n} (f * g)(d) h(c)                      [означення згортки (f * g) з h]
= ∑_{d·c = n} ( ∑_{a·b = d} f(a) g(b) ) h(c)        [розгортка внутрішньої згортки за дільниками d]
= ∑_{a·b·c = n} f(a) g(b) h(c)                      [об'єднання у суму за всіма трійками a·b·c = n]
= ∑_{a·e = n} f(a) ( ∑_{b·c = e} g(b) h(c) )        [перегрупування доданків при e = b·c]
= (f * (g * h))(n)                                  [висновок: згортка f з (g * h)]
```

Симетричне подання через упорядковані трійки `(a, b, c)` таких натуральних чисел, що `a · b · c = n`, повністю усуває залежність від порядку дій та доводить асоціативність.

### Дистрибутивність згортки відносно додавання

Дистрибутивність пов'язує операції згортки та додавання: `f * (g + h) = f * g + f * h`. Перевіримо це в довільній точці `n`:

```
(f * (g + h))(n)
= ∑_{d|n} f(d) (g + h)(n/d)
= ∑_{d|n} f(d) ( g(n/d) + h(n/d) )
= ∑_{d|n} f(d) g(n/d) + ∑_{d|n} f(d) h(n/d)
= (f * g)(n) + (f * h)(n)
```

### Нейтральний (одиничний) елемент

Визначимо арифметичну функцію `ε(n)` (символ Кронекера в одиниці):
- `ε(1) = 1`;
- `ε(n) = 0` для всіх цілих чисел `n > 1`.

Функція `ε` є двостороннім нейтральним елементом кільця. Для довільної функції `f ∈ A` та будь-якого `n`:

```
(f * ε)(n)
= ∑_{d|n} f(d) ε(n/d)            [за означенням згортки]
= f(n) · ε(1)                    [єдиний ненульовий доданок при n/d = 1, тобто d = n]
= f(n) · 1 = f(n)                [підстановка значення ε(1) = 1]
```

Отже, рівність `f * ε = ε * f = f` виконується тотожно.

### Відсутність дільників нуля та порядок функції

Для будь-якої ненульової функції `f ∈ A` (тобто існує хоча б одне `n`, де `f(n) ≠ 0`) визначимо важливу числову характеристику — **порядок функції** `ord(f)`:

```
ord(f) = min { n ∈ ℤ⁺ | f(n) ≠ 0 }
```

Порядок показує перший натуральний індекс, на якому функція відхиляється від нуля.

**Теорема про відсутність дільників нуля.** Кільце `(A, +, *)` є цілісним доменом: якщо згортка двох функцій `f * g = 0` дорівнює тотожному нулю, то принаймні одна з функцій `f` або `g` є тотожним нулем.

**Доведення:**
Припустимо від супротивного, що `f ≠ 0` та `g ≠ 0`. Це означає, що існують скінченні цілі числа `n₁ = ord(f)` та `n₂ = ord(g)`. За означенням порядку:
- `f(a) = 0` для всіх `a < n₁`, а `f(n₁) ≠ 0`;
- `g(b) = 0` для всіх `b < n₂`, а `g(n₂) ≠ 0`.

Розглянемо значення згортки `(f * g)` у точці `n = n₁ · n₂`:

```
(f * g)(n₁ n₂) = ∑_{a · b = n₁ n₂} f(a) g(b)
```

Проаналізуємо всі пари дільників `(a, b)`, добуток яких дорівнює `n₁ n₂`:
1. Якщо `a < n₁`, то за означенням порядку `f(a) = 0`, тому відповідний доданок `f(a) g(b) = 0`.
2. Якщо `a > n₁`, то ділячи обидві частини рівності `a · b = n₁ n₂` на `a`, отримуємо частку `b = (n₁ n₂) / a < n₂`. Оскільки `b < n₂`, за означенням порядку `g(b) = 0`, тому доданок `f(a) g(b) = 0`.
3. Єдиною парою дільників, для якої обидва множники можуть бути ненульовими, є пара `a = n₁` та `b = n₂`.

Підставивши цю єдину пару в суму, маємо:

```
(f * g)(n₁ n₂) = f(n₁) · g(n₂)
```

Оскільки `f(n₁) ≠ 0` та `g(n₂) ≠ 0` у полі комплексних чисел `ℂ`, їхній числовий добуток `f(n₁) g(n₂) ≠ 0`. Отже, функція `(f * g)` набуває ненульового значення в точці `n₁ n₂`, що спростовує припущення `f * g = 0`. Кільце арифметичних функцій є областю цілісності без дільників нуля. Крім того, ми отримали важливе співвідношення:

```
ord(f * g) = ord(f) · ord(g)
```

## 2. Топологічна структура кільця та ультраметричний простір

Поняття порядку функції `ord(f)` дозволяє ввести на кільці `A` природну ультраметричну топологію, яка робить його повним метричним простором.

Для будь-яких двох функцій `f, g ∈ A` визначимо відстань `d(f, g)`:
- `d(f, g) = 0`, якщо `f = g`;
- `d(f, g) = 2^{-ord(f - g)}`, якщо `f ≠ g`.

Функція `d` задовольняє сильну нерівність трикутника (аксіому ультраметрики):

```
d(f, h) ≤ max( d(f, g), d(g, h) )
```

**Теорема про повноту (Кешвелл-Еверетт).** Метричний простір `(A, d)` є повним: будь-яка фундаментальна послідовність арифметичних функцій має границю в `A`. Послідовність функцій `f_k` збігається до `f` тоді й лише тоді, коли для кожного фіксованого натурального числа `n` числова послідовність `f_k(n)` стабілізується при `k → ∞`.

Більше того, кільце арифметичних функцій `(A, +, *)` топологічно ізоморфне кільцю формальних степенних рядів від зліченної кількості змінних `ℂ[[x₁, x₂, x₃, ...]]`. Цей ізоморфізм зіставляє кожному простому числу `p_i` формальну змінну `x_i`, а числу `n = p₁^{k₁} ... p_r^{k_r}` — моном `x₁^{k₁} ... x_r^{k_r}`.

## 3. Група оборотних елементів та алгоритм побудови оберненого

Елемент `f ∈ A` називається оборотним відносно згортки Діріхле, якщо існує така функція `f⁻¹ ∈ A`, що `f * f⁻¹ = ε`.

**Теорема.** Функція `f ∈ A` має обернену відносно згортки тоді й лише тоді, коли **`f(1) ≠ 0`**. При цьому обернена функція `f⁻¹` є єдиною.

### Доведення (конструктивне за сильною індукцією)

Необхідно знайти такі значення `f⁻¹(n)`, щоб виконувалася рівність `(f * f⁻¹)(n) = ε(n)` для всіх `n ≥ 1`.

**База індукції (`n = 1`):**
Для початкового елемента маємо:
```
(f * f⁻¹)(1) = ε(1)
f(1) · f⁻¹(1) = 1                [бо єдиний дільник числа 1 — це 1]
f⁻¹(1) = 1 / f(1)               [можливо тоді й лише тоді, коли f(1) ≠ 0]
```

Якщо `f(1) = 0`, то `(f * g)(1) = f(1) g(1) = 0 ≠ 1` для будь-якої функції `g`, що робить обернення неможливим.

**Крок індукції (`n > 1`):**
Для будь-якого `n > 1` за означенням маємо `ε(n) = 0`. Запишемо розгортку суми дільників:

```
(f * f⁻¹)(n) = 0                 [умова нейтральності для n > 1]
∑_{d|n} f(d) f⁻¹(n/d) = 0        [розгортка формули згортки]
f(1) f⁻¹(n) + ∑_{d|n, d > 1} f(d) f⁻¹(n/d) = 0 [виділення доданку d = 1]
```

Оскільки при всіх `d > 1` частка `n/d < n`, за припущенням індукції всі попередні значення `f⁻¹(n/d)` вже однозначно обчислені. Переносячи суму в праву частину й ділячи на `f(1) ≠ 0`, отримуємо рекурентну формулу:

```
f⁻¹(n) = − (1 / f(1)) · ∑_{d|n, d > 1} f(d) f⁻¹(n/d)      [для всіх n > 1]
```

Ця формула однозначно визначає кожне наступне значення `f⁻¹(n)` через попередні, що одночасно гарантує існування та єдиність оберненого елемента.

### Обернена функція для абсолютно мультиплікативних функцій

**Теорема.** Якщо арифметична функція `f` є абсолютно (повністю) мультиплікативною та задовольняє умову `f(1) = 1`, то її обернена відносно згортки функція дорівнює точковому добутку з функцією Мебіуса:

```
f⁻¹(n) = μ(n) · f(n)
```

**Доведення:**
Перевіримо значення згортки `f * (μ · f)` для довільного числа `n`:

```
(f * (μ · f))(n)
= ∑_{d|n} f(d) · μ(n/d) f(n/d)   [підстановка за означенням згортки]
= ∑_{d|n} μ(n/d) · (f(d) f(n/d)) [комутативність множення в C]
= ∑_{d|n} μ(n/d) · f(n)          [абсолютна мультиплікативність: f(d) f(n/d) = f(d · n/d) = f(n)]
= f(n) · ∑_{d|n} μ(n/d)          [винесення спільного множника f(n) за знак суми]
= f(n) · ε(n)                    [основна сумаційна властивість функції Мебіуса]
= ε(n)                          [бо при n = 1: f(1)·1 = 1; при n > 1: f(n)·0 = 0]
```

Цей результат надзвичайно спрощує обчислення обернених функцій у практичній роботі.

### Обчислення обернених для класичних функцій

1. **Обернена до постійної функції `1(n) = 1`:**
   Оскільки функція `1(n)` є абсолютно мультиплікативною, її обернена дорівнює функції Мебіуса:
   ```
   1⁻¹(n) = μ(n) · 1(n) = μ(n)
   ```

2. **Обернена до тотожної функції `id(n) = n`:**
   Оскільки функція `id(n)` є абсолютно мультиплікативною, її обернена дорівнює:
   ```
   id⁻¹(n) = μ(n) · n
   ```

3. **Обернена до кількості дільників `d = 1 * 1`:**
   За асоціативністю та комутативністю згортки:
   ```
   d⁻¹ = (1 * 1)⁻¹ = 1⁻¹ * 1⁻¹ = μ * μ
   ```
   Обчислимо значення `(μ * μ)(n)` на простих степенях `p^k`:
   - `d⁻¹(p) = μ(1) μ(p) + μ(p) μ(1) = 1·(-1) + (-1)·1 = -2`.
   - `d⁻¹(p²) = μ(1) μ(p²) + μ(p) μ(p) + μ(p²) μ(1) = 1·0 + (-1)·(-1) + 0·1 = 1`.
   - `d⁻¹(p^k) = 0` для всіх `k ≥ 3`.

4. **Обернена до суми дільників `σ = id * 1`:**
   ```
   σ⁻¹ = (id * 1)⁻¹ = id⁻¹ * 1⁻¹ = (μ · id) * μ
   ```
   На простому степені `p`:
   - `σ⁻¹(p) = (μ · id)(1) μ(p) + (μ · id)(p) μ(1) = 1·(-1) + (-p)·1 = -(p + 1)`.
   - `σ⁻¹(p²) = (μ · id)(p) μ(p) = (-p) · (-1) = p`.
   - `σ⁻¹(p^k) = 0` для всіх `k ≥ 3`.

## 4. Степенні ряди Белла та локальний аналіз над простими числами

Для алгебраїчного аналізу мультиплікативних функцій Ерік Темпл Белл запропонував розглядати їхні формальні проекції на степені фіксованого простого числа `p`.

Для будь-якої арифметичної функції `f` та простого числа `p` **рядом Белла** `f_p(x)` називається формальний степенний ряд від однієї змінної `x`:

```
f_p(x) = ∑_{k=0}^∞ f(p^k) x^k = f(1) + f(p) x + f(p²) x² + f(p³) x³ + …
```

**Теорема про ізоморфізм Белла.** Операція згортки Діріхле двох мультиплікативних функцій `h = f * g` у просторі рядів Белла відповідає звичайному добутку формальних степенних рядів Коші для кожного простого числа `p`:

```
h_p(x) = (f * g)_p(x) = f_p(x) · g_p(x)
```

**Доведення:**
Розпишемо коефіцієнт при `x^k` у добутку двох формальних рядів `f_p(x) · g_p(x)`:

```
(f_p(x) · g_p(x))_k
= ∑_{j=0}^k f(p^j) g(p^{k-j})       [правило множення формальних рядів Коші]
= ∑_{d | p^k} f(d) g(p^k / d)       [бо всі дільники числа p^k мають вигляд d = p^j, 0 ≤ j ≤ k]
= (f * g)(p^k)                      [означення згортки Діріхле в точці n = p^k]
= h(p^k)                            [коефіцієнт ряду h_p(x) при x^k]
```

Це доводить, що перетворення Белла перетворює згортку арифметичних функцій на просте алгебраїчне множення формальних степенних рядів.

### Зведена таблиця рядів Белла для класичних функцій

| Функція `f(n)` | Формула на простому степені `f(p^k)` | Ряд Белла `f_p(x)` | Алгебраїчний вигляд |
| :--- | :--- | :--- | :--- |
| **Нейтральний елемент `ε`** | `[k = 0]` | `1` | `1` |
| **Постійна одиниця `1`** | `1` | `1 + x + x² + x³ + …` | `1 / (1 - x)` |
| **Функція Мебіуса `μ`** | `μ(p) = -1, μ(p^k) = 0 (k ≥ 2)` | `1 - x` | `1 - x` |
| **Тотожна функція `id_m`** | `p^{k m}` | `1 + p^m x + p^{2m} x² + …` | `1 / (1 - p^m x)` |
| **Кількість дільників `d = 1 * 1`** | `k + 1` | `1 + 2x + 3x² + 4x³ + …` | `1 / (1 - x)²` |
| **Сума дільників `σ = id * 1`** | `(p^{k+1} - 1)/(p - 1)` | `1 + (p+1)x + (p²+p+1)x² + …` | `1 / ((1 - x)(1 - p x))` |
| **Функція Ейлера `φ = id * μ`** | `p^{k-1}(p - 1)` при `k ≥ 1` | `1 + (p-1)x + p(p-1)x² + …` | `(1 - x) / (1 - p x)` |
| **Функція Ліувілля `λ`** | `(-1)^k` | `1 - x + x² - x³ + …` | `1 / (1 + x)` |
| **Індикатор безквадратності `μ²`** | `[k ≤ 1]` | `1 + x` | `1 + x` |
| **Псі-функція Дедекінда `ψ_D`** | `p^{k-1}(p + 1)` при `k ≥ 1` | `1 + (p+1)x + p(p+1)x² + …` | `(1 + x) / (1 - p x)` |
| **Тотієнт Жордана `J_m`** | `p^{m(k-1)}(p^m - 1)` | `1 + (p^m-1)x + …` | `(1 - x) / (1 - p^m x)` |

### Доведення алгебраїчних тотожностей через ряди Белла

1. **Тотожність `ψ_D = id * μ²`:**
   Множимо ряди Белла для `id` та `μ²`:
   ```
   id_p(x) · (μ²)_p(x) = ( 1 / (1 - p x) ) · (1 + x) = (1 + x) / (1 - p x) = (ψ_D)_p(x)
   ```
   Оскільки ряди Белла збігаються для всіх простих `p`, рівність `ψ_D = id * μ²` доведена для всіх натуральних чисел.

2. **Тотожність `σ = φ * d`:**
   Множимо ряди Белла для `φ` та `d`:
   ```
   φ_p(x) · d_p(x)
   = ( (1 - x) / (1 - p x) ) · ( 1 / (1 - x)² )
   = 1 / ((1 - x)(1 - p x))
   = σ_p(x)
   ```
   Звідси безпосередньо випливає класична числова рівність `σ(n) = ∑_{d|n} φ(d) d(n/d)`.

3. **Тотожність `d(n²) = ∑_{d|n} 2^{ω(d)}`:**
   Для степеня простого числа `p^k` функція `d((p^k)²) = d(p^{2k}) = 2k + 1`. Ряд Белла лівої частини дорівнює:
   ```
   ∑_{k=0}^∞ (2k + 1) x^k = (1 + x) / (1 - x)²
   ```
   Для правої частини функція `2^{ω(n)}` на степенях простого має значення `2^{ω(1)} = 1` та `2^{ω(p^k)} = 2` при `k ≥ 1`. Її ряд Белла дорівнює `1 + 2x + 2x² + … = (1 + x) / (1 - x)`. Згортка з функцією `1` (ряд `1/(1-x)`) дає:
   ```
   ( (1 + x) / (1 - x) ) · ( 1 / (1 - x) ) = (1 + x) / (1 - x)²
   ```
   Оскільки ряди Белла збігаються, тотожність доведено для всіх натуральних чисел.

## 5. Алгебраїчна деривація та логарифмічна похідна

Визначимо оператор арифметичного диференціювання `D: A → A` формулою:

```
(D f)(n) = f(n) · ln n
```

Для будь-яких комплексних скалярів `a, b ∈ ℂ` та функцій `f, g ∈ A` оператор `D` є лінійним: `D(a f + b g) = a D(f) + b D(g)`.

### Правило Лейбніца для згортки

**Теорема.** Оператор `D` є деривацією кільця `(A, +, *)`, тобто задовольняє диференціальне правило Лейбніца:

```
D(f * g) = D(f) * g + f * D(g)
```

**Доведення:**
Запишемо значення `D(f * g)` у довільній точці `n`:

```
(D(f * g))(n)
= ( ∑_{d|n} f(d) g(n/d) ) · ln n                     [означення оператора D]
= ∑_{d|n} f(d) g(n/d) · ( ln d + ln(n/d) )           [властивість логарифма ln n = ln d + ln(n/d)]
= ∑_{d|n} (f(d) ln d) g(n/d) + ∑_{d|n} f(d) (g(n/d) ln(n/d)) [розподільний закон]
= ∑_{d|n} (D f)(d) g(n/d) + ∑_{d|n} f(d) (D g)(n/d)  [підстановка оператора D]
= (D(f) * g)(n) + (f * D(g))(n)                      [означення операції згортки]
```

### Логарифмічна похідна

Для будь-якої оборотної арифметичної функції `f` (де `f(1) ≠ 0`) визначимо її **логарифмічну похідну** `L(f)` формулою:

```
L(f) = D(f) * f⁻¹
```

**Властивості логарифмічної похідної:**
1. Для добутку двох оборотних функцій `f` та `g`:
   ```
   L(f * g)
   = D(f * g) * (f * g)⁻¹
   = ( D(f) * g + f * D(g) ) * (f⁻¹ * g⁻¹)
   = D(f) * f⁻¹ * (g * g⁻¹) + D(g) * g⁻¹ * (f * f⁻¹)
   = D(f) * f⁻¹ * ε + D(g) * g⁻¹ * ε
   = L(f) + L(g)
   ```
   Отже, відображення `L` є гомоморфізмом із мультиплікативної групи оборотних функцій `(A*, *)` в адитивну групу кільця `(A, +)`.

2. **Зв'язок із функцією ман Гольдта `Λ`:**
   Розглянемо логарифмічну похідну постійної одиничної функції `1(n) = 1`:
   ```
   (D 1)(n) = 1(n) · ln n = ln n
   L(1) = D(1) * 1⁻¹ = ln * μ
   ```
   Оскільки `(ln * μ)(n) = Λ(n)` є функцією ман Гольдта, ми отримуємо фундаментальний висновок: **функція ман Гольдта є логарифмічною похідною постійної одиниці в кільці арифметичних функцій**:

   ```
   L(1) = Λ
   ```

3. **Логарифмічна похідна тотожної функції `id`:**
   ```
   L(id) = D(id) * id⁻¹ = (ln · id) * (μ · id) = id · (ln * μ) = id · Λ
   ```

## 6. Доведення теореми про обернення Мебіуса

**Теорема.** Нехай `f` та `g` — дві арифметичні функції. Тоді рівність
`g(n) = ∑_{d|n} f(d)`
виконується для всіх `n ≥ 1` тоді й лише тоді, коли
`f(n) = ∑_{d|n} μ(d) g(n/d)`.

### Строге алгебраїчне доведення

Перепишемо умову `g(n) = ∑_{d|n} f(d)` у компактній формі згортки: `g = f * 1`.

**Пряме твердження:**
Нехай `g = f * 1`. Згорнемо обидві частини рівності з функцією Мебіуса `μ`:

```
g * μ
= (f * 1) * μ                    [підстановка g = f * 1]
= f * (1 * μ)                    [за асоціативністю згортки]
= f * ε                          [бо 1 * μ = ε за означенням μ]
= f                              [бо f * ε = f для нейтрального елемента]
```

**Обернене твердження:**
Нехай `f = g * μ`. Згорнемо обидві частини рівності з функцією `1`:

```
f * 1
= (g * μ) * 1                    [підстановка f = g * μ]
= g * (μ * 1)                    [за асоціативністю згортки]
= g * ε                          [бо μ * 1 = ε за комутативністю]
= g                              [бо g * ε = g]
```

## 7. Збереження мультиплікативності при згортці

**Теорема.** Якщо `f` та `g` — мультиплікативні функції, то їхня згортка `h = f * g` також є мультиплікативною.

### Доведення

Нехай `m, n ∈ ℤ⁺` такі, що `gcd(m, n) = 1`. Необхідно довести, що `h(m n) = h(m) h(n)`.

Кожен дільник `d | (m n)` за умови `gcd(m, n) = 1` однозначно факторизується у вигляд `d = d₁ · d₂`, де `d₁ | m`, `d₂ | n`, причому `gcd(d₁, d₂) = 1` та `gcd(m/d₁, n/d₂) = 1`. Тоді:

```
h(m n)
= ∑_{d | m n} f(d) g((m n) / d)                     [за означенням згортки]
= ∑_{d₁ | m} ∑_{d₂ | n} f(d₁ d₂) g((m/d₁) · (n/d₂)) [факторизація d = d₁ d₂]
= ∑_{d₁ | m} ∑_{d₂ | n} f(d₁) f(d₂) g(m/d₁) g(n/d₂) [мультиплікативність f та g]
= ( ∑_{d₁ | m} f(d₁) g(m/d₁) ) · ( ∑_{d₂ | n} f(d₂) g(n/d₂) ) [розділення незалежних сум]
= h(m) · h(n)                                       [добуток згорток h(m) та h(n)]
```

Крім того, якщо `f` є мультиплікативною, її обернена функція `f⁻¹` також є мультиплікативною. Це доводиться індукцією за кількістю простих множників або через розклад Белла: оскільки ряд Белла `(f⁻¹)_p(x) = 1 / f_p(x)` залежить лише від локальної поведінки `f_p(x)`, функція `f⁻¹` однозначно факторизується по незалежних простих числах.

Отже, **множина всіх мультиплікативних функцій утворює абелеву підгрупу** групи оборотних елементів `(A*, *)`.

## 8. Обернення Мебіуса на частково впорядкованих множинах (посетах)

Нехай `(P, ≤)` — локально скінченна частково впорядкована множина (посет), у якій кожен затиснутий інтервал `[x, y] = {z ∈ P | x ≤ z ≤ y}` є скінченною множиною.

**Алгеброю інцидентності** `I(P)` називається множина всіх комплекснозначних функцій двох змінних `f(x, y)`, визначених для всіх пар `x ≤ y` в `P`. Операція множення (згортки) в `I(P)` задається формулою:

```
(f * g)(x, y) = ∑_{x ≤ z ≤ y} f(x, z) g(z, y)
```

Нейтральним елементом виступає дельта-функція Кронекера `δ(x, y) = [x = y]`.

Визначимо **дзета-функцію посету** `ζ ∈ I(P)` рівністю `ζ(x, y) = 1` для всіх `x ≤ y`. Оскільки `ζ(x, x) = 1 ≠ 0` для кожного `x ∈ P`, функція `ζ` є оборотною в алгебрі інцидентності `I(P)`. Її обернений елемент `μ = ζ⁻¹` називається **функцією Мебіуса посету `P`**.

Значення `μ(x, y)` визначаються рекурентно:
- `μ(x, x) = 1` для всіх `x ∈ P`;
- `μ(x, y) = - ∑_{x ≤ z < y} μ(x, z)` для всіх `x < y`.

**Загальна теорема обернення Мебіуса:**
Для будь-яких функцій `f, g: P → ℂ`:
```
g(x) = ∑_{y ≤ x} f(y)   ⇔   f(x) = ∑_{y ≤ x} g(y) μ(y, x)
```

### Факторизація на прямих добутках посетів

**Теорема.** Якщо посет `P = P₁ × P₂` є прямим декартовим добутком двох локально скінченних посетів із покомпонентним порядком `(x₁, x₂) ≤ (y₁, y₂) ⇔ x₁ ≤ y₁ \text{ та } x₂ ≤ y₂`, то функція Мебіуса прямого добутку дорівнює добутку функцій Мебіуса компонент:

```
μ_{P₁ × P₂}( (x₁, x₂), (y₁, y₂) ) = μ_{P₁}(x₁, y₁) · μ_{P₂}(x₂, y₂)
```

Завдяки фундаментальній теоремі арифметики решітка дільників числа `n = p₁^{k₁} · … · p_r^{k_r}` ізоморфна прямому добутку лінійних числових ланцюгів `[0, k₁] × … × [0, k_r]`.

Для лінійного ланцюга `[0, k]` функція Мебіуса дорівнює `μ(0, 0) = 1`, `μ(0, 1) = -1` та `μ(0, j) = 0` при `j ≥ 2`.

Перемножуючи функції Мебіуса по всіх `r` простих компонентах:
- Якщо всі `k_i = 1` (число вільне від квадратів), то `μ(1, n) = (-1) · … · (-1) = (-1)^r`.
- Якщо хоча б один `k_i ≥ 2` (ділиться на квадрат простого), то у добутку з'являється множник `0`, тому `μ(1, n) = 0`.

### Приклад: q-аналог Мебіуса на решітці підпросторів векторного простору

Розглянемо посет `L(V)` усіх лінійних підпросторів `n`-вимірного векторного простору `V = 𝔽_q^n` над скінченним полем з `q` елементів, упорядкованих за включенням `U ≤ W ⇔ U ⊆ W`.

Інтервал `[U, W]` ізоморфний решітці підпросторів простору розмірності `k = dim(W) - dim(U)`. Функція Мебіуса на цій решітці залежить лише від різниці розмірностей `k` і задається формулою:

```
μ(U, W) = (-1)^k · q^{k(k-1)/2}
```

Ця формула лежить в основі квантового числення (q-аналогів комбінаторики) та використовується для точного підрахунку кількості лінійно незалежних конфігурацій підпросторів у криптографічних схемах із кодами з виправленням помилок.

## 9. Формальні експоненти та логарифми в кільці арифметичних функцій

У кільці арифметичних функцій `(A, +, *)` можна визначити операції формальної експоненти та формального логарифма за допомогою збіжних рядів у топології ультраметричного простору.

Нехай `A₀ = { f ∈ A | f(1) = 0 }` — максимальний ідеал функцій, що зануляються в одиниці (`ord(f) ≥ 2`). Для будь-якої функції `f ∈ A₀` та будь-якого `n ≥ 1` степінь за згорткою `f^{*k}(n) = 0` для всіх `k > log₂ n`. Тому формальний експоненціальний ряд містить лише скінченну кількість ненульових доданків у кожній фіксованій точці `n`:

```
exp_*(f) = ε + f + (f * f) / 2! + (f * f * f) / 3! + … = ∑_{k=0}^∞ f^{*k} / k!
```

Функція `exp_*(f)` завжди задовольняє умову `exp_*(f)(1) = 1`, тобто належить до групи `A₁ = { g ∈ A | g(1) = 1 }`.

Навпаки, для будь-якої функції `g ∈ A₁` визначимо формальний логарифм:

```
ln_*(g) = (g - ε) − (g - ε)^{*2} / 2 + (g - ε)^{*3} / 3 − … = ∑_{k=1}^∞ (-1)^{k-1} (g - ε)^{*k} / k
```

**Теорема про ізоморфізм експоненти.** Відображення `exp_*: (A₀, +) → (A₁, *)` є ізоморфізмом адитивної групи ідеалу `A₀` на мультиплікативну групу `A₁`. Зокрема, для будь-яких `f, h ∈ A₀`:

```
exp_*(f + h) = exp_*(f) * exp_*(h)
```

А для довільної функції `g ∈ A₁` виконуються співвідношення взаємного обернення:

```
ln_*( exp_*(f) ) = f
exp_*( ln_*(g) ) = g
```

Більше того, логарифмічна похідна `L` пов'язана з формальним логарифмом співвідношенням:

```
L(g) = D( ln_*(g) )
```

Це встановлює повну паралель між численням арифметичних функцій та класичним аналізом функцій дійсної змінної.

## 10. Алгебра характерів Діріхле та співвідношення ортогональності

Нехай `q` — натуральне число. Мультиплікативна група оборотних елементів кільця лишків `(ℤ / q ℤ)*` є скінченною абелевою групою порядку `φ(q)`.

**Характером Діріхле за модулем `q`** називається гомоморфізм `χ: (ℤ / q ℤ)* → ℂ*`, продовжений на всю множину цілих чисел `ℤ` за правилом:
- `χ(n) = χ(n \bmod q)`, якщо `gcd(n, q) = 1`;
- `χ(n) = 0`, якщо `gcd(n, q) > 1`.

Характери Діріхле є абсолютно мультиплікативними функціями: `χ(a b) = χ(a) χ(b)` для всіх натуральних чисел `a` та `b`.

Множина всіх характерів за фіксованим модулем `q` утворює групу характерів `X(q)`, яка ізоморфна самій групі `(ℤ / q ℤ)*` і містить рівно `φ(q)` різних елементів. Нейтральним елементом групи є головний характер `χ₀(n) = [gcd(n, q) = 1]`.

### Перше співвідношення ортогональності (по елементах групи)

Для будь-яких двох характерів `χ₁, χ₂ ∈ X(q)`:

```
∑_{a=1}^q χ₁(a) · \bar{χ₂}(a) = φ(q), якщо χ₁ = χ₂, та 0 інакше
```

**Доведення:**
Якщо `χ₁ = χ₂`, то для кожного `a`, взаємно простого з `q`, добуток `χ₁(a) \bar{χ₁}(a) = |χ₁(a)|² = 1`. Сумуючи по всіх таких `a`, кількість яких дорівнює `φ(q)`, отримуємо значення `φ(q)`.

Якщо ж `χ₁ ≠ χ₂`, то функція `ψ = χ₁ \bar{χ₂}` є нетривіальним характером (`ψ ≠ χ₀`). Знайдеться такий елемент `b` з `gcd(b, q) = 1`, що `ψ(b) ≠ 1`. Оскільки при множенні на `b` множина всіх лишків переставляється:

```
∑_{a=1}^q ψ(a) = ∑_{a=1}^q ψ(b a) = ψ(b) · ∑_{a=1}^q ψ(a)
(1 - ψ(b)) · ∑_{a=1}^q ψ(a) = 0
```

Оскільки `ψ(b) ≠ 1`, сума `∑_{a=1}^q ψ(a) = 0`.

### Друге співвідношення ортогональності (по характерах)

Для будь-яких двох цілих чисел `n` та `m`, взаємно простих із модулем `q`:

```
∑_{χ ∈ X(q)} χ(n) · \bar{χ}(m) = φ(q), якщо n ≡ m (mod q), та 0 інакше
```

Ці два співвідношення ортогональності дозволяють розкладати будь-яку періодичну функцію на класах лишків у дискретний ряд Фур'є за характерами Діріхле, що є основним аналітичним інструментом при дослідженні розподілу простих чисел.

## 11. Точне алгебраїчне виведення формули сум Рамануджана

Сума Рамануджана визначається тригонометричним виразом:

```
c_q(n) = ∑_{1 ≤ a ≤ q, gcd(a, q) = 1} exp(2πi · a · n / q)
```

Виведемо її явне подання через функцію Мебіуса суто алгебраїчними методами.

Для довільного натурального числа `q` розглянемо повну експоненціальну суму по всіх лишках `a` від `1` до `q`:

```
S_q(n) = ∑_{a=1}^q exp(2πi · a · n / q) = q, якщо q | n, та 0 інакше
```

З іншого боку, згрупуємо елементи `a` за їхнім найбільшим спільним дільником з `q`, позначивши `d = gcd(a, q)`. Тоді `a = d · a'`, `q = d · q'`, де `gcd(a', q') = 1` та `1 ≤ a' ≤ q'`:

```
S_q(n)
= ∑_{d|q} ∑_{1 ≤ a' ≤ q/d, gcd(a', q/d) = 1} exp(2πi · a' · n / (q/d))
= ∑_{d|q} c_{q/d}(n)
```

Покладемо `m = q/d`. Отримуємо співвідношення згортки:

```
S_q(n) = ∑_{m|q} c_m(n)
```

Вважаючи `n` фіксованим параметром, а `q` — аргументом арифметичної функції, ми бачимо, що функція `S(q) = (c * 1)(q)` є згорткою функції Рамануджана з постійною одиницею `1`.

Застосуємо фундаментальну теорему про обернення Мебіуса до цієї рівності:

```
c_q(n)
= (S * μ)(q)                                       [обернення Мебіуса c = S * μ]
= ∑_{d|q} S_d(n) · μ(q / d)                        [розгортка згортки]
= ∑_{d|q, d|n} d · μ(q / d)                         [бо S_d(n) = d при d|n, та 0 інакше]
= ∑_{d | gcd(q, n)} d · μ(q / d)                   [об'єднання умов d|q та d|n у d|gcd(q,n)]
```

Ми щойно суто алгебраїчно, в чотири рядки, вивели знамениту формулу Рамануджана без використання складного неперервного інтегрування!

## 12. Ідеали та структура локального кільця

Глибший погляд на кільце `A = {f: ℤ⁺ → ℂ}` крізь призму комутативної алгебри розкриває його внутрішню модульну будову.

Для кожного натурального числа `k ≥ 1` визначимо підмножину функцій, порядок яких не менший за `k`:

```
I_k = { f ∈ A | ord(f) ≥ k } = { f ∈ A | f(1) = f(2) = … = f(k - 1) = 0 }
```

**Теорема.** Кожна підмножина `I_k` є ідеалом кільця `(A, +, *)`.

**Доведення:**
1. Якщо `f, g ∈ I_k`, то для будь-якого `n < k` маємо `(f + g)(n) = f(n) + g(n) = 0 + 0 = 0`, отже `ord(f + g) ≥ k`, тобто `f + g ∈ I_k`.
2. Якщо `f ∈ I_k` та `h ∈ A` — довільна арифметична функція, то за формулою множення порядків:
   ```
   ord(h * f) = ord(h) · ord(f) ≥ 1 · k = k
   ```
   Отже `h * f ∈ I_k`, що підтверджує властивість ідеалу.

Послідовність ідеалів утворює нескінченну спадну фільтрацію кільця:

```
A = I₁ ⊃ I₂ ⊃ I₃ ⊃ I₄ ⊃ …
```

Причому перетин усіх цих ідеалів містить лише нульову функцію: `⋂_{k=1}^∞ I_k = {0}`.

**Теорема про локальність кільця.** Кільце арифметичних функцій `A` є **локальним кільцем**. Його єдиним максимальним ідеалом є ідеал `I₂ = { f ∈ A | f(1) = 0 }`.

**Доведення:**
Множина всіх необоротних елементів кільця `A` точно збігається з множиною функцій, для яких `f(1) = 0` (критерій оборотності Дедекінда). Оскільки ця множина утворює ідеал `I₂`, усі елементи поза `I₂` є оборотними. За критерієм теорії кілець це означає, що `A` є локальним кільцем із єдиним максимальним ідеалом `I₂`.

Поле лишків цього локального кільця ізоморфне полю комплексних чисел:

```
A / I₂ ≅ ℂ
```

де ізоморфізм задається гомоморфізмом оцінки в одиниці `ev₁(f) = f(1)`. А фактор-кільця `A / I_k` описують зрізані скінченні арифметичні структури, що відповідають чисельним розрахункам на обмежених масивах даних.

Радикал Джекобсона кільця `A` (перетин усіх максимальних ідеалів) збігається з єдиним максимальним ідеалом `J(A) = I₂`. Оскільки `A` є цілісним доменом без дільників нуля, нільрадикал кільця є тривіальним: `Nil(A) = {0}` (єдиним нільпотентним елементом є нульова функція). Будь-яка нетривіальна функція не може дати нуль при піднесенні до будь-якого скінченного степеня згортки `f^{*k} ≠ 0`. Це забезпечує абсолютну стійкість та однозначність алгебраїчних операцій над числовими послідовностями.

Функція порядку `v(f) = ln(ord(f))` задовольняє всі аксіоми неархімедового нормування: `v(f * g) = v(f) + v(g)` та `v(f + g) ≥ min(v(f), v(g))`. Це перетворює кільце арифметичних функцій на неархімедову банахову алгебру, де кожна збіжна послідовність однозначно визначає мультиплікативну граничну функцію. Завдяки цьому математики отримують строгий апарат для побудови формальних степеневих рядів та дослідження аналітичних властивостей розподілу простих чисел. Отже, алгебра згортки Діріхле володіє бездоганною гармонією як дискретних алгебраїчних, так і неперервних топологічних властивостей.
