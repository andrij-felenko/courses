# 🧮 Алгебра згортки Діріхле та дуальність рядів

Алгебра згортки Діріхле та мультиплікативна дуальність рядів утворюють центральний аналітичний міст теорії чисел: дискретні відношення подільності цілих чисел вони перетворюють на алгебраїчне множення аналітичних функцій та формальних степеневих рядів. Коли ми розглядаємо взаємодію дільників, обернення формул або асимптотику арифметичних сум, апарат згортки дозволяє замінити складний комбінаторний перебір простим множенням рядів у комплексній площині.

## 1. Кільцева структура та алгебраїчні властивості

Арифметичною функцією називається будь-яке відображення `f: ℕ → ℂ`, яке кожному натуральному числу `n ∈ {1, 2, 3, ...}` ставить у відповідність комплексне число `f(n)`. Множина всіх арифметичних функцій, яку позначають через `𝒜`, утворює комутативне кільце відносно двох операцій: звичайного точкового додавання `(f + g)(n) = f(n) + g(n)` та **згортки Діріхле** `(f * g)(n)`.

**Визначення згортки Діріхле:** Згорткою Діріхле (англ. *Dirichlet convolution*) двох арифметичних функцій `f` та `g` називається нова арифметична функція `h = f * g`, значення якої для кожного `n ∈ ℕ` обчислюється як сума за всіма додатними дільниками `d` числа `n`:

```
(f * g)(n) = ∑_{d|n} f(d) · g(n/d) = ∑_{a · b = n} f(a) · g(b)
```

Згортка Діріхле задовольняє фундаментальні алгебраїчні закони:

1. **Комутативність:** `f * g = g * f`.
   Рівність `a · b = n` є симетричною відносно множників, тому сума `∑_{a · b = n} f(a) · g(b)` не змінюється при перестановці функцій `f` та `g`.

2. **Асоціативність:** `(f * g) * h = f * (g * h)`.
   Розпишемо ліву частину за визначенням зовнішньої та внутрішньої згортки:

```
((f * g) * h)(n)
= ∑_{d|n} (f * g)(d) · h(n/d)                                    [зовнішня згортка за d|n]
= ∑_{d|n} [ ∑_{a|d} f(a) · g(d/a) ] · h(n/d)                     [розгортання внутрішньої згортки]
= ∑_{a · b · c = n} f(a) · g(b) · h(c)                           [заміна a = a, b = d/a, c = n/d]
= ∑_{c|n} h(c) · [ ∑_{a|(n/c)} f(a) · g((n/c)/a) ]               [перегрупування доданків за дільником c]
= ∑_{c|n} h(c) · (f * g)(n/c)                                    [згортання виразу в дужках]
= (f * (g * h))(n)                                               [комутативність та визначення]
```

Обидві частини тотожно дорівнюють симетричній сумі за всіма впорядкованими трійками натуральних чисел `(a, b, c)` такими, що `a · b · c = n`.

3. **Нейтральний елемент:** Існує функція `ε(n)` (одинична функція), визначена як:

```
ε(n) = 1,  якщо n = 1
ε(n) = 0,  якщо n > 1
```

Для будь-якої функції `f` виконується `(f * ε)(n) = f(1) · ε(n) + f(n) · ε(1) = f(n)`.

4. **Дистрибутивність відносно додавання:** `f * (g + h) = (f * g) + (f * h)`.
   Випливає безпосередньо з дистрибутивності множення комплексних чисел: `∑_{d|n} f(d) · (g(n/d) + h(n/d)) = ∑_{d|n} f(d) · g(n/d) + ∑_{d|n} f(d) · h(n/d)`.

5. **Існування оберненого елемента:** Арифметична функція `f` має обернену відносно згортки функцію `f⁻¹` (таку, що `f * f⁻¹ = ε`) тоді й лише тоді, коли `f(1) ≠ 0`.

Значення оберненої функції `f⁻¹(n)` обчислюються за рекурентною формулою:

```
f⁻¹(1) = 1 / f(1)                                             [база рекуренсії при n = 1]

f⁻¹(n) = - (1 / f(1)) · ∑_{d|n, d > 1} f(d) · f⁻¹(n/d)        [для кожного n > 1]
```

Ця формула виводиться з розкриття умови `(f * f⁻¹)(n) = ε(n) = 0` для `n > 1`:

```
∑_{d|n} f(d) · f⁻¹(n/d) = f(1) · f⁻¹(n) + ∑_{d|n, d > 1} f(d) · f⁻¹(n/d) = 0
```

Виразивши `f⁻¹(n)`, отримуємо наведену рекурентність. Множина всіх арифметичних функцій з `f(1) ≠ 0` утворює абелеву групу `(𝒜*, *)` оборотних елементів кільця `𝒜`.

6. **Область цілісності (відсутність дільників нуля):**
   Кільце арифметичних функцій `(𝒜, +, *)` не містить дільників нуля: якщо `f * g = 0` (тотожно нульова функція), то `f = 0` або `g = 0`.

   *Доведення:* Припустимо супротивне: нехай існують дві ненульові функції `f ≠ 0` та `g ≠ 0`, для яких `f * g = 0`.
   Оскільки функції ненульові, існують найменші натуральні індекси `n₁` та `n₂`, на яких вони приймають ненульові значення:

```
n₁ = min { n ∈ ℕ : f(n) ≠ 0 }
n₂ = min { m ∈ ℕ : g(m) ≠ 0 }
```

Обчислимо значення згортки `(f * g)` у точці `n = n₁ · n₂`:

```
(f * g)(n₁ · n₂) = ∑_{d | (n₁ · n₂)} f(d) · g((n₁ · n₂) / d)
```

Розглянемо довільний дільник `d` числа `n₁ · n₂`:
- якщо `d < n₁`, то за мінімальністю `n₁` маємо `f(d) = 0`;
- якщо `d > n₁`, то другий співмножник задовольняє нерівність `(n₁ · n₂) / d < n₂`. Тоді за мінімальністю `n₂` маємо `g((n₁ · n₂) / d) = 0`;
- отже, єдиний можливий ненульовий доданок у всій сумі досягається виключно при `d = n₁`, коли другий співмножник дорівнює `(n₁ · n₂) / n₁ = n₂`.

Звідси отримуємо:

```
(f * g)(n₁ · n₂) = f(n₁) · g(n₂)
```

Оскільки `f(n₁) ≠ 0` та `g(n₂) ≠ 0` є ненульовими комплексними числами, їхній добуток `f(n₁) · g(n₂) ≠ 0`. Це суперечить умові `(f * g)(n) = 0` для всіх `n`.
Таким чином, припущення хибне, і кільце `(𝒜, +, *)` є цілісним (областю цілісності).

7. **Ізоморфізм до формальних степеневих рядів нескінченної кількості змінних:**
   За Основною теоремою арифметики кожне натуральне число `n ≥ 1` однозначно розкладається у добуток простих чисел:

```
n = p₁ᵃ¹ · p₂ᵃ² ··· pₖᵃᵏ ··· = ∏_{i=1}^∞ pᵢ^{v_pᵢ(n)}
```

де `p₁ = 2, p₂ = 3, p₃ = 5, ...` — впорядкована послідовність усіх простих чисел, а показники `v_pᵢ(n) ≥ 0` дорівнюють нулю для всіх простих, окрім скінченної кількості.

Зіставимо кожному числу `n` моном від зліченної множини формальних змінних `X = (X₁, X₂, X₃, ...)`:

```
n ⟼ X^n = X₁^{v_2(n)} · X₂^{v_3(n)} · X₃^{v_5(n)} ···
```

Це зіставлення породжує канонічне відображення `Φ` з кільця арифметичних функцій `(𝒜, +, *)` у кільце формальних степеневих рядів від зліченної кількості змінних `ℂ[[X₁, X₂, X₃, ...]]`:

```
Φ(f) = ∑_{n=1}^∞ f(n) · X₁^{v_2(n)} · X₂^{v_3(n)} ···
```

Перевіримо збереження операцій:
- Додавання функцій `f + g` відповідає коефіцієнтному додаванню степеневих рядів: `Φ(f + g) = Φ(f) + Φ(g)`.
- Добуток двох чисел `a · b = n` відповідає додаванню показників степенів: `X^a · X^b = X^{a · b} = X^n`. Тому коефіцієнт при мономі `X^n` у добутку двох рядів `Φ(f) · Φ(g)` дорівнює:

```
∑_{X^a · X^b = X^n} f(a) · g(b) = ∑_{a · b = n} f(a) · g(b) = (f * g)(n)
```

Отже, `Φ(f * g) = Φ(f) · Φ(g)`. Оскільки кожен моном однозначно кодує натуральне число `n`, відображення `Φ` є бієктивним.

Це доводить фундаментальну **теорему Кешвелла–Еверетта** (англ. *Cashwell–Everett theorem*, 1959): кільце арифметичних функцій `(𝒜, +, *)` ізоморфне кільцю формальних степеневих рядів від зліченної кількості змінних `ℂ[[X₁, X₂, ...]]`. Звідси безпосередньо випливає, що `𝒜` є факторіальним кільцем (кільцем з однозначним розкладом на незвідні множники).

## 2. Теорема про збереження мультиплікативності

Арифметична функція `f` називається **мультиплікативною**, якщо `f(1) = 1` і для будь-якої пари взаємно простих чисел `n` та `m` (тобто `НСД(n, m) = 1`) виконується тотожність:

```
f(n · m) = f(n) · f(m)
```

Якщо ця рівність виконується для абсолютно всіх пар чисел `n, m ∈ ℕ` (навіть не взаємно простих), функція називається **цілком мультиплікативною**.

**Теорема (про збереження мультиплікативності):** Якщо арифметичні функції `f` та `g` є мультиплікативними, то їхня згортка Діріхле `h = f * g` також є мультиплікативною функцією.

### Строге алгебраїчне доведення:

Нехай `n` та `m` — дві взаємно прості натуральні числа (`НСД(n, m) = 1`). Дослідимо значення згортки `h(n · m)`:

```
h(n · m) = ∑_{d | (n · m)} f(d) · g((n · m) / d)
```

Оскільки `НСД(n, m) = 1`, кожен дільник `d` числа `n · m` однозначно розкладається у добуток `d = d₁ · d₂`, де `d₁ | n` та `d₂ | m`, причому `НСД(d₁, d₂) = 1` та `НСД(n/d₁, m/d₂) = 1`.

Розпишемо суму через паралельні дільники `d₁` та `d₂`:

```
h(n · m)
= ∑_{d₁|n} ∑_{d₂|m} f(d₁ · d₂) · g( (n/d₁) · (m/d₂) )      [однозначний розклад дільників d = d₁ · d₂]
= ∑_{d₁|n} ∑_{d₂|m} f(d₁) · f(d₂) · g(n/d₁) · g(m/d₂)      [мультиплікативність f та g]
= [ ∑_{d₁|n} f(d₁) · g(n/d₁) ] · [ ∑_{d₂|m} f(d₂) · g(m/d₂) ] [факторизація подвійної суми]
= h(n) · h(m)                                               [за визначенням h = f * g]
```

Оскільки `h(1) = f(1) · g(1) = 1 · 1 = 1`, функція `h = f * g` задовольняє всі умови мультиплікативності.

**Оберненість мультиплікативних функцій:** Якщо функція `f` є мультиплікативною, то її обернена відносно згортки функція `f⁻¹` також є мультиплікативною.
Множина всіх мультиплікативних функцій утворює підгрупу `ℳ` в абелевій групі оборотних арифметичних функцій `(𝒜*, *)`.

Варто зауважити, що цілковита мультиплікативність при згортці загалом не зберігається: наприклад, константна функція `1(n) = 1` є цілком мультиплікативною, однак її згортка з собою `(1 * 1)(n) = d(n)` (кількість дільників) є лише мультиплікативною (`d(4) = 3 ≠ d(2)² = 4`).

## 3. Ряди Белла та локальний аналіз згортки

Для аналізу мультиплікативних функцій застосовують **ряди Белла** (англ. *Bell series*), названі на честь математика Еріка Темпла Белла.

Нехай `f` — мультиплікативна арифметична функція, а `p` — фіксоване просте число. Рядом Белла функції `f` за простою основою `p` називається формальний степеневий ряд однієї змінної:

```
f_p(x) = ∑_{k=0}^∞ f(pᵏ) xᵏ = f(1) + f(p) x + f(p²) x² + f(p³) x³ + ...
```

**Теорема про локальну факторизацію згортки:** Згортка двох мультиплікативних функцій `h = f * g` локально для кожного простого числа `p` відповідає звичайному множенню (добутку Коші) їхніх рядів Белла:

```
h_p(x) = f_p(x) · g_p(x)
```

*Доведення:* Розпишемо коефіцієнт при `xᵏ` у добутку степеневих рядів:

```
(f_p · g_p)(x)
= ( ∑_{i=0}^∞ f(pⁱ) xⁱ ) · ( ∑_{j=0}^∞ g(pʲ) xʲ )
= ∑_{k=0}^∞ [ ∑_{i+j=k} f(pⁱ) · g(pʲ) ] xᵏ
= ∑_{k=0}^∞ [ ∑_{i=0}^k f(pⁱ) · g(p^{k-i}) ] xᵏ
```

Оскільки додатними дільниками числа `pᵏ` є виключно степені `d = pⁱ` для `i ∈ {0, 1, ..., k}`, внутрішня сума в точності дорівнює `∑_{d|pᵏ} f(d) · g(pᵏ/d) = (f * g)(pᵏ) = h(pᵏ)`. Отже, коефіцієнти при `xᵏ` збігаються для всіх `k ≥ 0`.

### Каталог рядів Белла для базових функцій:

1. **Константна одиниця `1(n) = 1`:**
   Коефіцієнти `1(pᵏ) = 1` для всіх `k ≥ 0`, тому ряд Белла є сумою нескінченної геометричної прогресії:

```
1_p(x) = 1 + x + x² + x³ + ... = 1 / (1 - x)
```

2. **Число дільників `d = 1 * 1`:**
   Ряд Белла дорівнює квадрату ряду для одиниці:

```
d_p(x) = 1_p(x) · 1_p(x) = 1 / (1 - x)² = 1 + 2x + 3x² + 4x³ + ... + (k + 1)xᵏ + ...
```

Коефіцієнт при `xᵏ` дорівнює `k + 1 = d(pᵏ)`.

3. **Функція Мебіуса `μ`:**
   Оскільки `μ(1) = 1`, `μ(p) = -1`, а `μ(pᵏ) = 0` для всіх `k ≥ 2`, ряд Белла є лінійним двочленом:

```
μ_p(x) = 1 - x
```

Добуток `1_p(x) · μ_p(x) = (1 / (1 - x)) · (1 - x) = 1 = ε_p(x)` підтверджує тотожність `1 * μ = ε`.

4. **Степенева функція `Nᵃ(n) = nᵃ`:**
   Для степеня `Nᵃ(pᵏ) = (pᵃ)ᵏ` ряд Белла має вигляд:

```
(Nᵃ)_p(x) = 1 + pᵃ x + p²ᵃ x² + ... = 1 / (1 - pᵃ x)
```

5. **Сума степенів дільників `σ_a = Nᵃ * 1`:**
   За теоремою про множення рядів Белла:

```
(σ_a)_p(x) = (Nᵃ)_p(x) · 1_p(x) = 1 / ((1 - pᵃ x) · (1 - x)) = ∑_{k=0}^∞ [ (pᵃ⁽ᵏ⁺¹⁾ - 1) / (pᵃ - 1) ] xᵏ
```

6. **Функція Ейлера `φ = N * μ`:**
   Перемноживши ряди для `N(n) = n` (де `a = 1`) та `μ`, маємо:

```
φ_p(x) = (1 - x) / (1 - p x) = 1 + (p - 1) x + p(p - 1) x² + p²(p - 1) x³ + ...
```

Коефіцієнт при `xᵏ` для `k ≥ 1` дорівнює `pᵏ - pᵏ⁻¹ = pᵏ(1 - 1/p) = φ(pᵏ)`.

7. **Функція Ліувілля `λ(n) = (-1)^{Ω(n)}`:**
   Для степеня простого числа `Ω(pᵏ) = k`, тому `λ(pᵏ) = (-1)ᵏ`:

```
λ_p(x) = 1 - x + x² - x³ + ... = 1 / (1 + x)
```

## 4. Дуальність із множенням рядів Діріхле та аналітичні теореми

Фундаментальне значення рядів Діріхле в аналітичній теорії чисел полягає в точній відповідності між звичайним множенням аналітичних функцій та згорткою їхніх коефіцієнтів.

### Строге перетворення добутку абсолютно збіжних рядів (Теорема Коші):

Нехай задано два ряди Діріхле:

```
F(s) = ∑_{n=1}^∞ a[n] / nˢ    та    G(s) = ∑_{m=1}^∞ b[m] / mˢ
```

з абсцисами абсолютної збіжності `σ_a(F)` та `σ_a(G)` відповідно.

**Теорема (про добуток рядів Діріхле):** У спільній півплощині абсолютної збіжності `Re(s) > max(σ_a(F), σ_a(G))` добуток функцій `H(s) = F(s) · G(s)` задається рядом Діріхле:

```
H(s) = ∑_{k=1}^∞ c[k] / kˢ
```

коефіцієнти якого `c[k]` дорівнюють згортці Діріхле `c = a * b`:

```
c[k] = ∑_{d|k} a[d] · b[k/d] = ∑_{n · m = k} a[n] · b[m]
```

*Строге аналітичне виведення:*
Нехай `s = σ + i·t` з `σ > max(σ_a(F), σ_a(G))`. За умовою ряди `∑ |a[n]| / n^σ` та `∑ |b[m]| / m^σ` збігаються.
Розглянемо подвійний ряд із модулів членів:

```
∑_{n=1}^∞ ∑_{m=1}^∞ | (a[n] · b[m]) / (n · m)ˢ |
= ∑_{n=1}^∞ ∑_{m=1}^∞ ( |a[n]| / n^σ ) · ( |b[m]| / m^σ )
= ( ∑_{n=1}^∞ |a[n]| / n^σ ) · ( ∑_{m=1}^∞ |b[m]| / m^σ ) < ∞
```

Оскільки подвійний ряд збігається абсолютно, за теоремою Коші про подвійні ряди його члени можна групувати та переставляти у довільному порядку без зміни суми ряду.

Розіб'ємо множину всіх пар індексів `ℕ × ℕ` на неперетинні підмножини за фіксованим значенням добутку `n · m = k`:

```
ℕ × ℕ = ⨆_{k=1}^∞ { (n, m) ∈ ℕ × ℕ : n · m = k }
```

Для кожного фіксованого `k` множина пар `(n, m)` є скінченною і параметризується додатними дільниками `d` числа `k` (де `n = d`, а `m = k/d`).

Виконуючи перегрупування, маємо ланцюжок тотожних рівностей:

```
F(s) · G(s)
= ( ∑_{n=1}^∞ a[n] / nˢ ) · ( ∑_{m=1}^∞ b[m] / mˢ )              [вихідний добуток рядів]
= ∑_{n=1}^∞ ∑_{m=1}^∞ (a[n] · b[m]) / (n · m)ˢ                   [почленне множення абсолютно збіжних рядів]
= ∑_{k=1}^∞ [ ∑_{n · m = k} a[n] · b[m] ] / kˢ                    [групування за фіксованим добутком k = n · m]
= ∑_{k=1}^∞ [ ∑_{d|k} a[d] · b[k/d] ] / kˢ                       [параметризація через дільники d|k]
= ∑_{k=1}^∞ (a * b)(k) / kˢ                                      [за визначенням згортки Діріхле]
```

### Збереження абсолютної збіжності:

Позначимо `c[k] = (a * b)(k)`. Оцінимо суму модулів утвореного ряду `H(s) = ∑ c[k] / kˢ`:

```
∑_{k=1}^∞ |c[k]| / k^σ
= ∑_{k=1}^∞ | ∑_{d|k} a[d] · b[k/d] | / k^σ                      [підстановка визначення c[k]]
≤ ∑_{k=1}^∞ [ ∑_{d|k} |a[d]| · |b[k/d]| ] / k^σ                 [нерівність трикутника для скінченної суми]
= ∑_{n=1}^∞ ∑_{m=1}^∞ (|a[n]| · |b[m]|) / (n · m)^σ             [зворотне розкриття групування k = n · m]
= ( ∑_{n=1}^∞ |a[n]| / n^σ ) · ( ∑_{m=1}^∞ |b[m]| / m^σ ) < ∞   [добуток двох збіжних числових рядів]
```

Це доводить, що ряд для згортки `∑ c[k] / kˢ` абсолютно збігається в усій півплощині `Re(s) > max(σ_a(F), σ_a(G))`. Отже, абсциса абсолютної збіжності задовольняє нерівність:

```
σ_a(F · G) ≤ max(σ_a(F), σ_a(G))
```

### Теорема про єдиність розкладу рядів Діріхле:

Фундаментальне питання алгебри рядів Діріхле полягає у тому, чи можуть два різних набори коефіцієнтів породжувати одну й ту саму аналітичну функцію.

**Теорема (про єдиність):** Якщо два ряди Діріхле `∑ a[n] / nˢ` та `∑ b[n] / nˢ` збігаються абсолютно в деякій півплощині `Re(s) > σ₀` і їхні суми тотожно рівні для всіх `s` з цієї півплощини:

```
∑_{n=1}^∞ a[n] / nˢ = ∑_{n=1}^∞ b[n] / nˢ
```

то їхні коефіцієнти повністю збігаються: `a[n] = b[n]` для всіх `n ∈ ℕ`.

*Доведення:*
Позначимо різницю коефіцієнтів `c[n] = a[n] - b[n]`. Тоді для всіх `s` з `Re(s) > σ₀` виконується рівність:

```
∑_{n=1}^∞ c[n] / nˢ = 0
```

Припустимо від супротивного, що не всі коефіцієнти `c[n]` дорівнюють нулю. Нехай `N` — найменший натуральний індекс, для якого `c[N] ≠ 0`:

```
N = min { n ∈ ℕ : c[n] ≠ 0 }
```

Тоді ряд для нульової функції набуває вигляду:

```
c[N] / Nˢ + ∑_{n=N+1}^∞ c[n] / nˢ = 0
```

Помножимо обидві частини рівності на `Nˢ`:

```
c[N] + ∑_{n=N+1}^∞ c[n] · (N / n)ˢ = 0
```

Виразимо `c[N]` та перейдемо до дійсних значень змінної `s = σ > σ₀ + 1`:

```
|c[N]| ≤ ∑_{n=N+1}^∞ |c[n]| · (N / n)^σ
```

Оскільки для всіх `n ≥ N + 1` виконується `N / n ≤ N / (N + 1) < 1`, винесемо спільний спадний множник:

```
|c[N]|
≤ ( N / (N + 1) )^{σ - (σ₀ + 1)} · ∑_{n=N+1}^∞ |c[n]| · ( N / n )^{σ₀ + 1}
≤ ( N / (N + 1) )^{σ - (σ₀ + 1)} · M
```

де `M = ∑_{n=1}^∞ |c[n]| / n^{σ₀+1} < ∞` є скінченною константою (за абсолютною збіжністю ряду при `σ = σ₀ + 1`).

Оскільки `N / (N + 1) < 1`, при спрямуванні дійсної частини `σ → +∞` геометричний множник прямує до нуля:

```
lim_{σ → +∞} ( N / (N + 1) )^{σ - (σ₀ + 1)} = 0
```

Звідси отримуємо `|c[N]| ≤ 0`, що означає `c[N] = 0`. Це прямо суперечить вибору індексу `N`.
Отже, `c[n] = 0` для всіх `n ≥ 1`, звідки випливає `a[n] = b[n]` для кожного натурального `n`.

Теорема про єдиність гарантує, що відображення кільця арифметичних функцій `(𝒜, +, *)` у простір рядів Діріхле є **строгим алгебраїчним ізоморфізмом**.

## 5. Покрокові виведення фундаментальних тотожностей

Застосуємо теорему про добуток рядів Діріхле для виведення п'яти ключових тотожностей аналітичної теорії чисел.

### 1. Квадрат Дзета-функції та узагальнена сума степенів дільників `σ_α(n)`

Дзета-функція Рімана `ζ(s)` задається рядом з коефіцієнтами `1(n) = 1`:

```
ζ(s) = ∑_{n=1}^∞ 1 / nˢ    [Re(s) > 1]
```

Перемножимо `ζ(s)` на саму себе:

```
ζ(s)²
= ( ∑_{n=1}^∞ 1 / nˢ ) · ( ∑_{m=1}^∞ 1 / mˢ )                    [добуток двох Дзета-рядів]
= ∑_{k=1}^∞ [ ∑_{d|k} 1 · 1 ] / kˢ                                [згортка коефіцієнтів 1 * 1]
= ∑_{k=1}^∞ d(k) / kˢ                                            [d(k) — кількість дільників числа k]
```

Для довільного комплексного параметра `α ∈ ℂ` розглянемо ряд для зсунутої функції `ζ(s - α) = ∑_{m=1}^∞ mᵃ / mˢ`. Його коефіцієнтами є степенева функція `Nᵃ(m) = mᵃ`. Перемножимо `ζ(s)` та `ζ(s - α)`:

```
ζ(s) · ζ(s - α)
= ( ∑_{n=1}^∞ 1 / nˢ ) · ( ∑_{m=1}^∞ mᵃ / mˢ )                   [добуток Дзета-рядів зі зсувом аргументу]
= ∑_{k=1}^∞ [ ∑_{d|k} 1 · (k/d)ᵃ ] / kˢ                          [згортка 1 * Nᵃ за дільниками d|k]
= ∑_{k=1}^∞ [ ∑_{d|k} dᵃ ] / kˢ                                  [заміна порядку підсумовування d ↦ k/d]
= ∑_{k=1}^∞ σ_α(k) / kˢ                                          [σ_α(k) — сума α-х степенів дільників k]
```

При `α = 1` функція `σ₁(n) = σ(n)` обчислює суму всіх дільників числа `n`, що дає формулу `ζ(s) · ζ(s - 1) = ∑ σ(n) / nˢ`.

### 2. Обернена Дзета-функція `1 / ζ(s)` та функція Мебіуса `μ(n)`

Знайдемо аналітичний вираз для функції, алгебраїчно оберненої до `ζ(s)`, тобто такої, що `ζ(s) · M(s) = 1`.
Нехай `M(s) = ∑_{m=1}^∞ a[m] / mˢ`. Тоді:

```
ζ(s) · M(s) = ∑_{k=1}^∞ (1 * a)(k) / kˢ = 1 / 1ˢ + 0 / 2ˢ + 0 / 3ˢ + ... = ∑_{k=1}^∞ ε(k) / kˢ
```

За теоремою про єдиність коефіцієнтів маємо `(1 * a)(k) = ε(k)`. Як доведено в розділі про ряди Белла, єдиним розв'язком цього рівняння є **функція Мебіуса** `a(k) = μ(k)`.

Розгорнемо перевірку через пряме множення рядів:

```
ζ(s) · ( ∑_{m=1}^∞ μ(m) / mˢ )
= ∑_{k=1}^∞ [ ∑_{d|k} μ(d) · 1 ] / kˢ                            [згортка коефіцієнтів μ * 1]
= ∑_{k=1}^∞ ε(k) / kˢ                                            [тотожність ∑_{d|k} μ(d) = ε(k)]
= 1                                                              [оскільки ε(1) = 1, а ε(k) = 0 для k > 1]
```

Поділивши на `ζ(s)`, отримуємо аналітичний розклад:

```
1 / ζ(s) = ∑_{n=1}^∞ μ(n) / nˢ    [Re(s) > 1]
```

Ця формула також прямо випливає з Ейлерового добутку:

```
1 / ζ(s) = ∏_{p ∈ ℙ} (1 - p⁻ˢ) = ∏_{p ∈ ℙ} ( 1 + μ(p)/pˢ + μ(p²)/p²ˢ + ... ) = ∑_{n=1}^∞ μ(n) / nˢ
```

### 3. Функція Ейлера `φ(n)` та відношення `ζ(s - 1) / ζ(s)`

За класичною теоремою Гаусса сума значень тотієнта Ейлера за всіма дільниками числа `n` дорівнює самому числу:

```
∑_{d|n} φ(d) = n
```

У термінах згортки Діріхле це записується як `φ * 1 = N`, де `N(n) = n`.

Побудуємо ряд Діріхле для обох частин рівності:

```
( ∑_{n=1}^∞ φ(n) / nˢ ) · ζ(s)
= ( ∑_{n=1}^∞ φ(n) / nˢ ) · ( ∑_{m=1}^∞ 1 / mˢ )                 [добуток рядів для φ та 1]
= ∑_{k=1}^∞ [ ∑_{d|k} φ(d) · 1 ] / kˢ                            [згортка коефіцієнтів φ * 1]
= ∑_{k=1}^∞ k / kˢ                                               [застосування тотожності Гаусса φ * 1 = N]
= ∑_{k=1}^∞ 1 / kˢ⁻¹                                             [спрощення показника степеня k / kˢ = k⁻⁽ˢ⁻¹⁾]
= ζ(s - 1)                                                       [визначення Дзета-функції зі зсувом аргументу]
```

Помноживши обидві частини на `1 / ζ(s)`, маємо:

```
∑_{n=1}^∞ φ(n) / nˢ = ζ(s - 1) / ζ(s)    [Re(s) > 2]
```

Застосувавши формулу обернення згортки `φ = N * μ`, отримуємо прямий вираз для тотієнта:

```
φ(n) = ∑_{d|n} d · μ(n/d) = n · ∑_{d|n} μ(d) / d
```

### 4. Логарифмічна похідна Дзета-функції та функція Мангольдта `Λ(n)`

Функція Мангольдта `Λ(n)` визначається як:

```
Λ(n) = ln p,  якщо n = pᵏ (k ≥ 1 для простого p)
Λ(n) = 0,     в інших випадках
```

Доведемо тотожність `1 * Λ = ln`. Для довільного натурального `n = ∏ pᵢᵃⁱ` візьмемо натуральний логарифм:

```
ln n = ln ( ∏_{i} pᵢᵃⁱ ) = ∑_{i} aᵢ · ln pᵢ
```

З іншого боку, розпишемо суму `∑_{d|n} Λ(d)`. Ненульові доданки з'являються лише тоді, коли дільник `d` є степенем простого числа `d = pᵢʲ` (де `1 ≤ j ≤ aᵢ`). Кожен такий доданок дає `ln pᵢ`. Оскільки для кожного простого дільника `pᵢ` існує рівно `aᵢ` таких степенів (`pᵢ¹, pᵢ², ..., pᵢᵃⁱ`), сума дорівнює:

```
∑_{d|n} Λ(d) = ∑_{i} aᵢ · ln pᵢ = ln n
```

Отже, `(1 * Λ)(n) = ln n`.

Тепер обчислимо похідну від Дзета-функції Рімана за змінною `s`:

```
ζ'(s) = d/ds [ ∑_{n=1}^∞ n⁻ˢ ] = - ∑_{n=1}^∞ (ln n) / nˢ
```

Перемножимо `ζ(s)` на ряд для функції Мангольдта:

```
ζ(s) · ( ∑_{m=1}^∞ Λ(m) / mˢ )
= ∑_{k=1}^∞ [ ∑_{d|k} 1 · Λ(d) ] / kˢ                            [згортка коефіцієнтів 1 * Λ]
= ∑_{k=1}^∞ (ln k) / kˢ                                          [за тотожністю 1 * Λ = ln]
= - ζ'(s)                                                        [похідна Дзета-функції зі знаком мінус]
```

Поділивши обидві частини на `ζ(s)`, отримуємо фундаментальну формулу для логарифмічної похідної:

```
- ζ'(s) / ζ(s) = ∑_{n=1}^∞ Λ(n) / nˢ    [Re(s) > 1]
```

Застосування згортки з функцією Мебіуса дає тотожність обернення: `Λ = ln * μ`, тобто:

```
Λ(n) = ∑_{d|n} μ(d) · ln(n/d) = - ∑_{d|n} μ(d) · ln d
```

### 5. Функція Ліувілля `λ(n)` та відношення `ζ(2s) / ζ(s)`

Функція Ліувілля `λ(n) = (-1)^{Ω(n)}` (де `Ω(n)` — загальна кількість простих множників числа `n` з урахуванням кратності) є цілком мультиплікативною: `λ(n · m) = λ(n) · λ(m)`.

Розглянемо Ейлерів добуток для ряду функції Ліувілля:

```
∑_{n=1}^∞ λ(n) / nˢ
= ∏_{p ∈ ℙ} ( 1 + λ(p)/pˢ + λ(p²)/p²ˢ + ... )                   [добуток Ейлера для мультиплікативної функції]
= ∏_{p ∈ ℙ} ( 1 - 1/pˢ + 1/p²ˢ - 1/p³ˢ + ... )                  [підстановка λ(pᵏ) = (-1)ᵏ]
= ∏_{p ∈ ℙ} 1 / ( 1 + p⁻ˢ )                                     [сума нескінченної спадної геометричної прогресії]
= ∏_{p ∈ ℙ} ( 1 - p⁻ˢ ) / ( 1 - p⁻²ˢ )                          [домноження чисельника і знаменника на 1 - p⁻ˢ]
= [ ∏_{p ∈ ℙ} (1 - p⁻²ˢ)⁻¹ ] / [ ∏_{p ∈ ℙ} (1 - p⁻ˢ)⁻¹ ]        [розподіл добутків]
= ζ(2s) / ζ(s)                                                  [за канонічним розкладом Дзета-функції]
```

У термінах згортки це еквівалентно тотожності `(λ * 1)(n) = q(n)`, де `q(n) = 1`, якщо `n` є точним квадратом (`n = m²`), і `q(n) = 0` в інших випадках.

Аналогічно, для функції кількості безквадратних дільників `2^{ω(n)} = (1 * |μ|)(n)`:

```
∑_{n=1}^∞ 2^{ω(n)} / nˢ = ζ(s)² / ζ(2s)    [Re(s) > 1]
```

## 6. Формула обернення Мебіуса та числовий розрахунок

З фундаментальної алгебраїчної тотожності `1 * μ = ε` безпосередньо випливає **класична формула обернення Мебіуса**:

```
g(n) = ∑_{d|n} f(d)   ⟺   f(n) = ∑_{d|n} g(d) · μ(n/d)
```

В аналітичній мові рядів Діріхле це твердження є еквівалентним простому діленню на Дзета-функцію:

```
G(s) = F(s) · ζ(s)   ⟺   F(s) = G(s) / ζ(s) = G(s) · ( ∑_{n=1}^∞ μ(n) / nˢ )
```

### Приклад 1: Обчислення функції Ейлера `φ(12)` за формулою обернення

Дільниками числа `12` є множина `{1, 2, 3, 4, 6, 12}`.
Перевіримо рівність Гаусса `g(12) = ∑_{d|12} φ(d)`:

```
g(12) = φ(1) + φ(2) + φ(3) + φ(4) + φ(6) + φ(12)
      = 1 + 1 + 2 + 2 + 2 + 4 = 12
```

Тепер застосуємо обернену формулу Мебіуса для відновлення значення `φ(12)` за відомою функцією `g(d) = d`:

```
φ(12) = ∑_{d|12} d · μ(12/d)
      = 1·μ(12) + 2·μ(6) + 3·μ(4) + 4·μ(3) + 6·μ(2) + 12·μ(1)
```

Обчислимо значення функції Мебіуса для співмножників `12/d`:
- `μ(12) = μ(2² · 3) = 0` (містить квадрат `2²`);
- `μ(6) = μ(2 · 3) = (-1)² = 1` (добуток двох різних простих чисел);
- `μ(4) = μ(2²) = 0` (містить квадрат `2²`);
- `μ(3) = (-1)¹ = -1` (одне просте число);
- `μ(2) = (-1)¹ = -1` (одне просте число);
- `μ(1) = 1` (базове значення).

Підставимо отримані значення у суму:

```
φ(12) = 1·(0) + 2·(1) + 3·(0) + 4·(-1) + 6·(-1) + 12·(1)
      = 0 + 2 + 0 - 4 - 6 + 12 = 4
```

Значення `φ(12) = 4` повністю збігається з кількістю чисел від 1 до 12, які є взаємно простими з 12 (це числа 1, 5, 7, 11).

### Приклад 2: Обчислення функції Мангольдта `Λ(12)` та `Λ(8)` через `μ * ln`

Застосуємо формулу `Λ(n) = ∑_{d|n} μ(d) · ln(n/d)` для складеного числа `n = 12 = 2² · 3`:

```
Λ(12)
= μ(1)·ln(12) + μ(2)·ln(6) + μ(3)·ln(4) + μ(4)·ln(3) + μ(6)·ln(2) + μ(12)·ln(1)   [підстановка дільників d ∈ {1, 2, 3, 4, 6, 12}]
= 1·ln(12) - 1·ln(6) - 1·ln(4) + 0·ln(3) + 1·ln(2) + 0·ln(1)                      [обчислення значень функції Мебіуса μ(d)]
= (2·ln 2 + ln 3) - (ln 2 + ln 3) - 2·ln 2 + ln 2                                 [розклад логарифмів ln(a·b) = ln a + ln b]
= (2 - 1 - 2 + 1)·ln 2 + (1 - 1)·ln 3                                             [зведення подібних доданків]
= 0·ln 2 + 0·ln 3                                                                 [спрощення коефіцієнтів]
= 0                                                                               [підсумковий результат]
```

Отримали `Λ(12) = 0`, що повністю відповідає визначенню: число 12 не є степенем простого числа.

Тепер обчислимо значення для степеня простого числа `n = 8 = 2³` (дільники `{1, 2, 4, 8}`):

```
Λ(8)
= μ(1)·ln(8) + μ(2)·ln(4) + μ(4)·ln(2) + μ(8)·ln(1)                              [підстановка дільників d ∈ {1, 2, 4, 8}]
= 1·(3·ln 2) - 1·(2·ln 2) + 0·(ln 2) + 0·(0)                                      [обчислення значень μ(d) та ln(2ᵏ) = k ln 2]
= 3·ln 2 - 2·ln 2                                                                 [спрощення нульових доданків]
= ln 2                                                                            [віднімання коефіцієнтів: (3 - 2) ln 2]
```

Отримали `Λ(8) = ln 2`, що точно відповідає `ln p` для `8 = 2³`.

Алгебра згортки Діріхле забезпечує строгий та елегантний підхід до перетворення арифметичних функцій і є фундаментальним інструментом аналітичної теорії чисел.
