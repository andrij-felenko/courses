# ⚙️ Обчислення та згортка рядів Діріхле

Обчислювальні алгоритми для роботи з рядами Діріхле спираються на скінченні структури даних зберігання зрізаних рядів, ситоподібні процедури обчислення згортки арифметичних функцій у пам'яті, рекурентні схеми знаходження оберненого ряду, покрокове трасування обчислень та чисельну оцінку значень рядів у комплексній площині. Пряме втілення цих механізмів у мовах C та C++ поєднує точність аналітичних перетворень із лінійним чи майже лінійним використанням пам'яті та процесорного часу.

## 1. Практична постановка задачі та аналіз обчислювальної складності

При розробці програмних систем для комп'ютерної алгебри, аналізу криптографічних алгоритмів (зокрема аналізу факторизаційного сита GNFS/NFS) чи дискретного моделювання виникає потреба опрацьовувати ряди Діріхле `F(s) = ∑_{n=1}^∞ a[n] / nˢ`.

Оскільки реальні обчислення на комп'ютері оперують скінченними ресурсами пам'яті та процесорного часу, нескінченний ряд замінюється **зрізаним рядом Діріхле** (англ. *truncated Dirichlet series*) до певної фіксованої межі `N`:

```
F_N(s) = ∑_{n=1}^N a[n] / nˢ
```

При проведенні чисельних розрахунків виникають три основні обчислювальні задачі:

1. **Точкова оцінка значення `F_N(s)`:** Для заданого комплексного числа `s = σ + i·t` обчислити дісну та уявну частини суми. Для кожного доданка обчислюється модуль `n⁻σ` та фазовий кут `θ = -t · ln n` за формулою Ейлера `n⁻ˢ = n⁻σ · (cos(t ln n) - i sin(t ln n))`.
2. **Арифметична згортка коефіцієнтів:** Маючи два ряди з коефіцієнтами `a[1..N]` та `b[1..N]`, знайти коефіцієнти їхнього добутку `c[k] = (a * b)(k) = ∑_{d|k} a[d] b[k/d]` для всіх `k ≤ N`.
3. **Рекурентне інвертування рядів:** За відомими коефіцієнтами `a[1..N]` знайти коефіцієнти оберненого ряду `b[1..N]` такого, що `(a * b)(n) = ε(n)`.

### Аналіз часової та просторової складності

Прямий розрахунок згортки для кожного `k ≤ N` через окреме знаходження всіх його дільників вимагає `O(N √N)` операцій. Однак, використовуючи ситоподібний підхід (вкладений подвійний цикл за індексами `i` та `j`, де підсумковий знаменник дорівнює `k = i · j`), складність зменшується до `O(N log N)`.

Це випливає з точної суми асимптотики гармонічного ряду:

```
∑_{i=1}^N (N / i) = N · ( 1/1 + 1/2 + 1/3 + ... + 1/N ) = N · ln N + O(N)
```

Проілюструємо цю складність кількісно:
- Для `N = 10`: сума операцій дорівнює `10 · (1 + 1/2 + ... + 1/10) ≈ 29` кроків циклу.
- Для `N = 1000`: приблизно `1000 · ln(1000) ≈ 6907` кроків.
- Для `N = 10⁶`: приблизно `10⁶ · 13.8 ≈ 1.38 · 10⁷` кроків, що виконується менше ніж за 20 мілісекунд на сучасному процесорі.

Таким чином, ситоподібне накопичення коефіцієнтів забезпечує високу обчислювальну ефективність.

Інвертування ряду реалізується через покрокове виключення: `b[1] = 1 / a[1]`, а для `n > 1`:

```
b[n] = - (1 / a[1]) · ∑_{d|n, d > 1} a[d] · b[n/d]
```

Якщо `a[1] = 0`, ряд є необоротним відносно згортки Діріхле (оскільки коефіцієнт при `1/1ˢ` дорівнює нулю і ділення на `a[1]` є неможливим).

## 2. Реалізація алгоритмів у мовах C та C++

Нижче наведено робочі реалізації алгоритмів для обчислення, згортки та інвертування рядів Діріхле.

```c
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

/* Структура для представлення зрізаного ряду Діріхле */
typedef struct {
    double* coeff; /* Масив коефіцієнтів a[1..N] (1-indexed) */
    size_t size;   /* Верхня межа N */
} DirichletSeries;

/* Створення та ініціалізація ряду */
DirichletSeries* dirichlet_create(size_t size) {
    DirichletSeries* ds = (DirichletSeries*)malloc(sizeof(DirichletSeries));
    if (!ds) return NULL;
    ds->size = size;
    ds->coeff = (double*)calloc(size + 1, sizeof(double));
    if (!ds->coeff) {
        free(ds);
        return NULL;
    }
    return ds;
}

/* Звільнення пам'яті */
void dirichlet_free(DirichletSeries* ds) {
    if (ds) {
        free(ds->coeff);
        free(ds);
    }
}

/* Чисельне обчислення значення F(s) для s = sigma + i*t */
void dirichlet_eval(const DirichletSeries* ds, double sigma, double t, double* real_out, double* imag_out) {
    double res_re = 0.0;
    double res_im = 0.0;
    
    for (size_t n = 1; n <= ds->size; ++n) {
        if (ds->coeff[n] == 0.0) continue;
        
        double norm = pow((double)n, -sigma);
        double angle = -t * log((double)n);
        
        res_re += ds->coeff[n] * norm * cos(angle);
        res_im += ds->coeff[n] * norm * sin(angle);
    }
    
    *real_out = res_re;
    *imag_out = res_im;
}

/* Алгоритм швидкої згортки за O(N log N) */
DirichletSeries* dirichlet_convolve(const DirichletSeries* a, const DirichletSeries* b) {
    size_t min_n = (a->size < b->size) ? a->size : b->size;
    DirichletSeries* res = dirichlet_create(min_n);
    if (!res) return NULL;

    for (size_t i = 1; i <= min_n; ++i) {
        if (a->coeff[i] == 0.0) continue;
        for (size_t j = 1; i * j <= min_n; ++j) {
            res->coeff[i * j] += a->coeff[i] * b->coeff[j];
        }
    }
    return res;
}

/* Обчислення оберненого ряду b = a⁻¹ відносно згортки */
DirichletSeries* dirichlet_invert(const DirichletSeries* a) {
    if (a->size == 0 || a->coeff[1] == 0.0) return NULL;

    DirichletSeries* inv = dirichlet_create(a->size);
    if (!inv) return NULL;

    inv->coeff[1] = 1.0 / a->coeff[1];

    for (size_t n = 2; n <= a->size; ++n) {
        double sum = 0.0;
        for (size_t d = 2; d <= n; ++d) {
            if (n % d == 0) {
                sum += a->coeff[d] * inv->coeff[n / d];
            }
        }
        inv->coeff[n] = -sum / a->coeff[1];
    }
    return inv;
}

int main(void) {
    size_t N = 10;
    DirichletSeries* zeta = dirichlet_create(N);
    for (size_t i = 1; i <= N; ++i) {
        zeta->coeff[i] = 1.0; /* ζ(s) має коефіцієнти a[n] = 1 */
    }

    DirichletSeries* d_func = dirichlet_convolve(zeta, zeta);
    printf("Коефіцієнти ζ(s)² (число дільників d(n)):\n");
    for (size_t i = 1; i <= N; ++i) {
        printf("d(%zu) = %.0f\n", i, d_func->coeff[i]);
    }

    double re, im;
    dirichlet_eval(zeta, 2.0, 3.5, &re, &im);
    printf("\nζ(2.0 + 3.5i) (зрізана до N=10): %.5f + %.5fi\n", re, im);

    dirichlet_free(zeta);
    dirichlet_free(d_func);
    return 0;
}
```
```cpp
#include <iostream>
#include <vector>
#include <complex>
#include <cmath>
#include <span>
#include <stdexcept>

class DirichletSeries {
private:
    std::vector<double> coeff_;

public:
    explicit DirichletSeries(size_t size) : coeff_(size + 1, 0.0) {}

    size_t size() const { return coeff_.size() - 1; }

    double& operator[](size_t idx) { return coeff_[idx]; }
    double operator[](size_t idx) const { return coeff_[idx]; }

    /* Оцінка значення у комплексній точці s */
    std::complex<double> evaluate(std::complex<double> s) const {
        std::complex<double> sum(0.0, 0.0);
        for (size_t n = 1; n <= size(); ++n) {
            if (coeff_[n] == 0.0) continue;
            double n_val = static_cast<double>(n);
            /* n⁻ˢ = exp(-s * ln(n)) */
            std::complex<double> term = std::exp(-s * std::log(n_val));
            sum += coeff_[n] * term;
        }
        return sum;
    }

    /* Згортка за O(N log N) */
    DirichletSeries convolve(const DirichletSeries& other) const {
        size_t min_n = std::min(size(), other.size());
        DirichletSeries result(min_n);

        for (size_t i = 1; i <= min_n; ++i) {
            if (coeff_[i] == 0.0) continue;
            for (size_t j = 1; i * j <= min_n; ++j) {
                result[i * j] += coeff_[i] * other[j];
            }
        }
        return result;
    }

    /* Обчислення оберненого ряду */
    DirichletSeries invert() const {
        if (size() == 0 || coeff_[1] == 0.0) {
            throw std::invalid_argument("Перший коефіцієнт не може бути нулем.");
        }

        DirichletSeries inv(size());
        inv[1] = 1.0 / coeff_[1];

        for (size_t n = 2; n <= size(); ++n) {
            double sum = 0.0;
            for (size_t d = 2; d <= n; ++d) {
                if (n % d == 0) {
                    sum += coeff_[d] * inv[n / d];
                }
            }
            inv[n] = -sum / coeff_[1];
        }
        return inv;
    }
};

int main() {
    constexpr size_t N = 10;
    DirichletSeries zeta(N);
    for (size_t i = 1; i <= N; ++i) {
        zeta[i] = 1.0;
    }

    DirichletSeries d_func = zeta.convolve(zeta);
    std::cout << "Коефіцієнти ζ(s)² (число дільників d(n)):\n";
    for (size_t i = 1; i <= N; ++i) {
        std::cout << "d(" << i << ") = " << d_func[i] << "\n";
    }

    std::complex<double> s(2.0, 3.5);
    std::complex<double> val = zeta.evaluate(s);
    std::cout << "\nζ(2.0 + 3.5i) (зрізана до N=10): "
              << val.real() << " + " << val.imag() << "i\n";

    DirichletSeries mobius = zeta.invert();
    std::cout << "\nОбчислена функція Мебіуса μ(n) = (1/ζ)(n):\n";
    for (size_t i = 1; i <= N; ++i) {
        std::cout << "μ(" << i << ") = " << mobius[i] << "\n";
    }

    return 0;
}
```

## 3. Детальний аналіз та покрокове розкриття алгоритму

Розглянемо практичні нюанси програмної реалізації, підводні камені та методи оптимізації обчислень.

### 1. Індексація та структура пам'яті
У математичному визначенні рядів Діріхле підсумовування розпочинається з `n = 1`. Для збігу математичної позначки та програмного коду у вищенаведених реалізаціях масив `coeff` має розмірність `N + 1`, де нульовий елемент `coeff[0]` ігнорується, а індекси від `1` до `N` прямо відповідають значенням знаменників `nˢ`. У версії C++ клас `DirichletSeries` інкапсулює вектор `std::vector<double>` і надає безпечний перевантажений оператор `[]`.

### 2. Оптимізація обчислення логарифмів
У функції оцінки `dirichlet_eval` для кожного додатка виконується виклик `log((double)n)` та тригонометричних функцій `cos` і `sin`. При повторних розрахунках значення ряду в багатьох точках `s` (наприклад, під час побудови графіків чи пошуку нулів уздовж критичної прямої `Re(s) = 1/2`) багаторазовий розрахунок `log(n)` стає головною пляшковою шийкою продуктивності.

Для підвищення швидкодії до 4–5 разів застосовують векторну попередньо обчислену таблицю натуральних логарифмів:

```cpp
std::vector<double> log_table(N + 1);
for (size_t n = 1; n <= N; ++n) {
    log_table[n] = std::log(static_cast<double>(n));
}
```

Після цього фазовий кут обчислюється безпосередньо як `angle = -t * log_table[n]`.

### 3. Чисельна стійкість та обмеження точності
При розрахунку зрізаних рядів великого порядку (наприклад, `N > 10⁶`) накопичення помилок округлення чисел з плаваючою крапкою подвійної точності (`double`, 64 біти) може викривляти значення уявних осциляцій. Особливо це стосується поблизу точок розбіжності чи полюсів (таких як `s = 1` для Дзета-функції).

Для усунення втрати точності рекомендується:
- Використовувати тип підвищеної точності `long double` або мультиточкові математичні бібліотеки (наприклад, MPFR / GMP);
- Застосовувати алгоритм підсумовування Кахана (англ. *Kahan summation algorithm*) для компенсації помилок округлення при додаванні великої кількості малих чисел з плаваючою крапкою;
- Застосовувати формула Ейлера–Маклорена (англ. *Euler–Maclaurin formula*) для прискорення збіжності залишку ряду при значних `N`.

### 4. Крайові випадки та обробка помилок
У функції `dirichlet_invert` перевіряється умова `a[1] != 0.0`. Якщо перший коефіцієнт дорівнює нулю, операція інвертування є математично неможливою. Версія C++ генерує стандартний виняток `std::invalid_argument`, що гарантує захист від ділення на нуль і запобігає появі значень `NaN` у пам'яті.

## 4. Покрокова трасування чисельних результатів для N = 10

Простежимо результат виконання програми для зрізаної межі `N = 10`:

1. **Обчислення згортки `ζ * ζ` (число дільників `d(n)`):**
   - `d(1) = 1` (дільник: 1)
   - `d(2) = 2` (дільники: 1, 2)
   - `d(3) = 2` (дільники: 1, 3)
   - `d(4) = 3` (дільники: 1, 2, 4)
   - `d(5) = 2` (дільники: 1, 5)
   - `d(6) = 4` (дільники: 1, 2, 3, 6)
   - `d(7) = 2` (дільники: 1, 7)
   - `d(8) = 4` (дільники: 1, 2, 4, 8)
   - `d(9) = 3` (дільники: 1, 3, 9)
   - `d(10) = 4` (дільники: 1, 2, 5, 10)

Згортка за `O(N log N)` безпосередньо обчислила правильну кількість дільників для кожного числа.

2. **Інвертування Дзета-функції `ζ⁻¹` (функція Мебіуса `μ(n)`):**
   - `μ(1) = 1`
   - `μ(2) = -1`
   - `μ(3) = -1`
   - `μ(4) = 0` (ділиться на `2²`)
   - `μ(5) = -1`
   - `μ(6) = 1` (добуток двох простих `2 · 3`)
   - `μ(7) = -1`
   - `μ(8) = 0` (ділиться на `2²`)
   - `μ(9) = 0` (ділиться на `3²`)
   - `μ(10) = 1` (добуток двох простих `2 · 5`)

Рекурентний алгоритм інвертування без жодних знань про факторизацію чисел відновив класичні значення функції Мебіуса.

## 5. Порівняння підходів C та C++, RAII та безпека ресурсів

Порівняльний аналіз двох реалізацій демонструє переваги та відмінності мовних парадигм:

- **Керування пам'яттю:** Версія C вимагає явного створення об'єкта через `malloc`/`calloc` та обов'язкового виклику `dirichlet_free`. Будь-яке дострокове повернення з функції без `free` призводить до витоку пам'яті. У версії C++ вектор `std::vector<double>` керує пам'яттю за допомогою концепції RAII (англ. *Resource Acquisition Is Initialization*), автоматично звільняючи пам'ять при виході з області видимості.
- **Робота з комплексними числами:** У C обчислення виконувалися роздільно через параметри `double* real_out, double* imag_out` та функції `cos`/`sin`. У C++ стандартний тип `std::complex<double>` підтримує прямі математичні операції та комплексне експоненціювання `std::exp(-s * std::log(n))`, що робить код більш виразним та менш схильним до помилок у знаках.

Ці реалізації формують надійне підґрунтя для побудови обчислювальних модулів комп'ютерної алгебри та аналітичного дослідження функцій теорії чисел.
