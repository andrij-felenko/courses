# 🧮 Аналітичне доведення існування та меж асимптотичної щільності надлишкових чисел

Ця математична вставка містить суворе аналітичне виведення теореми Марцинкевича–Давенпорта про існування неперервної функції розподілу індексу надлишковості `I(n) = σ(n) / n` та обчислення асимптотичної щільності надлишкових чисел за допомогою методу моментів, характеристичних функцій у сенсі Фур'є, теорії ймовірнісних мір на натуральних числах і рядів Діріхле.

## 1. Асиметрія дільників та формалізація асимптотичної міри

Вивчення розподілу значень арифметичних функцій вимагає побудови формальної ймовірнісної міри на множині натуральних чисел. На відміну від скінченних множин, на нескінченній множині `N` не існує рівномірного ймовірнісного розподілу. Тому роль ймовірності у мові аналітичної теорії чисел відіграє **асимптотична (натуральна) щільність**.

Для будь-якої підмножини натуральних чисел `S ⊆ N` її асимптотична щільність `D(S)` визначається як границя відносної частоти появи елементів множини `S` серед перших `N` натуральних чисел при прямуванні `N` до нескінченності:

```
D(S) = lim_{N → ∞} (1 / N) · |{n ∈ S : n ≤ N}|      [асимптотична щільність множини S]
```

Розглянемо арифметичну функцію індексу надлишковості `I(n) = σ(n) / n`. Позначимо через `S(t)` множину всіх натуральних чисел, індекс надлишковості яких не перевищує дійсний параметр `t ≥ 1`:

```
S(t) = {n ∈ N : I(n) ≤ t}      [підмножина чисел з обмеженим індексом]
```

Асимптотична функція розподілу `F(t)` задається як щільність множини `S(t)`:

```
F(t) = D(S(t)) = lim_{N → ∞} (1 / N) · |{n ≤ N : I(n) ≤ t}|      [функція розподілу індексу]
```

Оскільки натуральне число `n` є надлишковим за класифікацією Нікомаха тоді й лише тоді, коли сума його власних дільників перевищує саме число (`s(n) > n`), що еквівалентно умові `I(n) > 2`, шукана асимптотична щільність надлишкових чисел `D_A` дорівнює точній доповняльній ймовірності події `I(n) > 2`:

```
D_A = D({n ∈ N : I(n) > 2}) = 1 - F(2)      [вираження щільності надлишкових чисел через F(2)]
```

Для доведення існування границі `F(t)` та її суворої неперервності необхідно дослідити асимптотичну поведінку моментів функції `I(n)` або її характеристичної функції Фур'є.

## 2. Метод моментів: Перший момент та арифметичні суми Діріхле

Метод моментів полягає у доведенні того, що усереднені значення степенів арифметичної функції `I(n)кількість` збігаються до скінченних границь при `N → ∞`, і що ці границі однозначно визначають розподіл `F(t)`.

Обчислимо перший момент `M₁`, який за визначенням є середнім значенням індексу надлишковості `I(n)` на множині натуральних чисел.

Запишемо індекс `I(n)` у вигляді суми обернених дільників числа `n`. Справді, якщо дільники `n` позначити через `d₁ < d₂ < ... < d_k`, то при діленні кожного дільника `d_i` на `n` ми отримуємо парний дільник `n / d_i`. Отже:

```
I(n) = σ(n) / n = (1 / n) · ∑_{d | n} d = ∑_{d | n} (n / d) / n = ∑_{d | n} 1 / d      [тотожність суми обернених дільників]
```

Розглянемо суму індексів `I(n)` для всіх `n` від `1` до `N`:

```
∑_{n=1}^N I(n) = ∑_{n=1}^N ∑_{d | n} 1 / d      [сума індексів на діапазоні 1..N]
```

Змінимо порядок підсумовування у подвійній сумі. Переберемо кожне можливе значення дільника `d` у межах від `1` до `N`. Число `d` є дільником натурального числа `n` тоді й лише тоді, коли `n` є кратним `d`. Кількість натуральних чисел `n ≤ N`, які діляться на `d` без остачі, дорівнює цілій частині від ділення `⌊N / d⌋`.

Завдяки цьому подвійна сума спрощується до однократної суми за всіма можливими дільниками `d`:

```
∑_{n=1}^N I(n) = ∑_{d=1}^N (1 / d) · ⌊N / d⌋      [зміна порядку підсумовування за дільниками]
```

Розкладемо цілу частину `⌊N / d⌋` на різницю дійсного значення `N / d` та дробової частини `{N / d}`:

```
⌊N / d⌋ = N / d - {N / d}      [вираження цілої частини через дробову]
```

Підставляючи цей розклад у суму, отримуємо вирази для головного та залишкового членів:

```
∑_{n=1}^N I(n)
= ∑_{d=1}^N (1 / d) · (N / d - {N / d})
= N · ∑_{d=1}^N 1 / d² - ∑_{d=1}^N {N / d} / d      [виділення головного члена та суми дробових частин]
```

Оцінимо суму залишкових членів `R(N) = ∑_{d=1}^N {N / d} / d`. Оскільки дробова частина будь-якого дійсного числа задовольняє подвійну нерівність `0 ≤ {x} < 1`, кожен доданок `{N / d} / d` обмежений зверху величиною `1 / d`.
Звідси сума `R(N)` обмежується частковою сумою гармонійного ряду:

```
R(N) < ∑_{d=1}^N 1 / d = log(N) + γ + O(1 / N)      [верхня оцінка залишкового члена через логарифм]
```

де `γ ≈ 0.577215` — стала Ейлера–Маскероні.

Поділимо обидві частини рівності для суми `∑_{n=1}^N I(n)` на `N`:

```
(1 / N) · ∑_{n=1}^N I(n) = ∑_{d=1}^N 1 / d² - R(N) / N      [середнє значення індексу на проміжку 1..N]
```

У граничному переході при `N → ∞` величина `R(N) / N < (log(N) + γ) / N` прямує до нуля за правилом Лопіталя. Перша ж сума перетворюється на нескінченний ряд для квадратично обернених чисел, який дорівнює значенню риманової дзета-функції `ζ(s)` у точці `s = 2`:

```
lim_{N → ∞} (1 / N) · ∑_{n=1}^N I(n)
= ∑_{d=1}^∞ 1 / d²                               [граничний перехід до нескінченного ряду]
= ζ(2) = π² / 6 ≈ 1.644934066                    [значення дзета-функції Ейлера у точці 2]
```

Отже, строго доведено, що **середній індекс надлишковості всіх натуральних чисел дорівнює точно `ζ(2) = π² / 6 ≈ 1.64493`**.

Оскільки значення `1.64493` строго менше за `2`, це дає аналітичне пояснення того, чому недостатні числа (для яких `I(n) < 2`) переважають у натуральному ряді.

## 3. Другий момент та структура ейлерового добутку

Для повного аналізу асиметрії розподілу обчислимо другий момент `M₂ = lim_{N→∞} (1/N) · ∑_{n=1}^N I(n)²`.

Піднесемо вираз для `I(n)` до квадрата:

```
I(n)² = (∑_{d₁ | n} 1 / d₁) · (∑_{d₂ | n} 1 / d₂) = ∑_{d₁ | n} ∑_{d₂ | n} 1 / (d₁ · d₂)      [квадрат суми дільників]
```

При підсумовуванні по всіх `n ≤ N` пара дільників `(d₁, d₂)` входить у суму для тих і лише тих чисел `n`, які діляться одночасно і на `d₁`, і на `d₂`. Це означає, що `n` повинно ділитися на найменше спільне кратне `lcm(d₁, d₂)`.
Кількість таких чисел `n ≤ N` дорівнює `⌊N / lcm(d₁, d₂)⌋`.

Переходячи до границі при `N → ∞`, отримуємо вираз для второго моменту через подвійний нескінченний ряд:

```
M₂ = lim_{N → ∞} (1 / N) · ∑_{n=1}^N I(n)²
   = ∑_{d₁=1}^∞ ∑_{d₂=1}^∞ 1 / (d₁ · d₂ · lcm(d₁, d₂))      [граничний вираз другого моменту]
```

Використаємо фундаментальну арифметичну тотожність, яка пов'язує найбільший спільний дільник `g = gcd(d₁, d₂)` та найменше спільне кратне:

```
d₁ · d₂ = gcd(d₁, d₂) · lcm(d₁, d₂)      [зв'язок НСД та НСК]
```

Підставляючи `lcm(d₁, d₂) = (d₁ · d₂) / gcd(d₁, d₂)` у знаменник, переписуємо загальний член ряду:

```
1 / (d₁ · d₂ · lcm(d₁, d₂)) = gcd(d₁, d₂) / (d₁ · d₂)²      [спрощення знаменника через НСД]
```

Оскільки арифметична функція `f(d₁, d₂) = gcd(d₁, d₂) / (d₁ · d₂)²` є мультиплікативною відносно двох змінних, подвійний ряд розкладається у нескінченний добуток Ейлера по всіх простих числах `p`:

```
M₂ = ∏_{p} L_p      [розклад другого моменту в добуток Ейлера]
```

де локальний фактор `L_p` відповідає підсумовуванню по степенях простого числа `pᵃ` та `pᵇ`:

```
L_p = (1 - 1 / p) · ∑_{a=0}^∞ ∑_{b=0}^∞ I(pᵃ) · I(pᵇ) / p^{max(a,b)}      [локальний фактор Ейлера]
```

Обчисливши суму геометричних прогресій для кожного простого `p`, отримуємо аналітичний зв'язок із значеннями дзета-функції у точках `2`, `3` та `6`:

```
M₂ = ζ(2)² · ζ(3) / ζ(6)                      [точний аналітичний вираз другого моменту]
   = (π² / 6)² · ζ(3) / (π⁶ / 945)
   = (105 / 4) · (ζ(3) / π²) ≈ 2.9238388          [чисельне значення другого моменту]
```

Значення другого моменту `M₂ ≈ 2.9238` дозволяє обчислити дисперсію індексу надлишковості:

```
Var(I) = M₂ - (M₁)² = 2.923838 - (1.644934)² = 2.923838 - 2.705808 = 0.218030      [дисперсія індексу надлишковості]
```

Мала величина дисперсії `0.2180` доводить, що більшість натуральних чисел мають індекс `I(n)`, сконцентрований навколо середнього значення `1.645`, а відхилення `I(n) > 2` є винятковими подіями, що охоплюють близько чверті натурального ряду.

Аналогічно обчислюються моменти вищих порядків `M_k = lim_{N→∞} (1/N) · ∑_{n=1}^N I(n)ᵏ`.
Узагальнена формула для `k`-го моменту виражається через скінченні комбінації значень дзета-функцій `ζ(2), ζ(3), ..., ζ(k + 1)`.
Зростання моментів задовольняє асимптотичну оцінку `M_k = exp(O(k · log(k)))`. За теоремою Хаусдорфа–Рісса про моменти, оскільки моменти задовольняють умову Карлемана:

```
∑_{k=1}^∞ M_{2k}^{-1/(2k)} = ∞      [умова Карлемана для відновлення розподілу]
```

функція розподілу `F(t)` **однозначно відновлюється за своїми моментами**.

## 4. Характеристична функція та аддитивна теорема Ердеша–Вінта

Альтернативний аналітичний підхід до доведення існування `F(t)` спирається на характеристичні функції Фур'є та логарифмування індексу.

Перейдемо від мультиплікативної функції `I(n)` до додатної аддитивної арифметичної функції `Y(n) = log(I(n))`.
Використовуючи канонічний розклад `n = ∏ pᵃ`, запишемо `Y(n)` у вигляді суми по простих дільниках:

```
Y(n) = log(σ(n) / n) = ∑_{pᵃ || n} log( (pᵃ⁺¹ - 1) / (pᵃ · (p - 1)) )      [розклад логарифма індексу в суму]
```

Оскільки для простих чисел `p` доданок задовольняє наближення `log(1 + 1/p) = 1/p + O(1/p²)`, функція `Y(n)` поводиться як сума слабозалежних випадкових величин.

Характеристична функція Фур'є `Ψ(τ)` функції `Y(n)` визначається як середнє значення комплексної експоненти:

```
Ψ(τ) = lim_{N → ∞} (1 / N) · ∑_{n=1}^N exp(i · τ · Y(n))      [характеристична функція Фур'є]
```

Оскільки `exp(i · τ · Y(n)) = ∏_{pᵃ || n} (I(pᵃ))^{i · τ}` є мультиплікативною арифметичною функцією, за теоремою Ейлера її середнє значення дорівнює нескінченному добутку:

```
Ψ(τ) = ∏_{p} ( (1 - 1/p) · ∑_{a=0}^∞ (I(pᵃ))^{i · τ} / pᵃ )      [добуток Ейлера характеристичної функції]
```

Цей добуток збігається абсолютно і рівномірно для всіх `τ ∈ R`, оскільки для кожного простого `p` доданок дорівнює `1 + ( (1 + 1/p)^{i·τ} - 1 ) / p + O(1/p²) = 1 + i·τ / p² + O(1/p²)`.
Збіжність ряду `∑ 1 / p²` гарантує, що `Ψ(τ)` є неперервною функцією Фур'є-перетворення.

За теоремою Леві про неперервність Фур'є-перетворень, існування неперервної характеристичної функції `Ψ(τ)` доводить існування неперервної граничної функції розподілу `F_Y(y) = D({n : log(I(n)) ≤ y})`.
Здійснюючи зворотну заміну `t = exp(y)`, отримуємо існування функції розподілу `F(t) = F_Y(log(t))`.

## 5. Теорема Марцинкевича та сувора неперервність і монотонність F(t)

Доведення існування граничної функції розподілу `F(t)` спирається на теорему Марцинкевича про розподіл значень додатних мультиплікативних арифметичних функцій.

**Теорема Марцинкевича (1933).** Нехай `g(n) ≥ 0` є мультиплікативною арифметичною функцією. Якщо ряд, складений з відхилень на простих числах:

```
∑_{p} (g(p) - 1) / p < ∞      [умова збіжності ряду відхилень на простих]
```

збігається, то функція `g(n)` має асимптотичну функцію розподілу `F_g(t) = lim_{N→∞} (1/N) · |{n ≤ N : g(n) ≤ t}|`.

Застосуємо теорему Марцинкевича до індексу надлишковості `I(n)`. Для простого числа `p` маємо `I(p) = (p + 1) / p = 1 + 1/p`.
Отже, відхилення дорівнює `I(p) - 1 = 1/p`.
Перевіримо умову збіжності ряду:

```
∑_{p} (I(p) - 1) / p = ∑_{p} (1 / p) / p = ∑_{p} 1 / p² < ∑_{n=1}^∞ 1 / n² = ζ(2) < ∞      [збіжність ряду для індексу]
```

Оскільки ряд `∑_{p} 1 / p²` збігається, **умови теореми Марцинкевича виконуються повністю**. Звідси випливає існування асимптотичної функції розподілу `F(t)`.

Давенпорт довів, що `F(t)` є не лише неперервною функцією, але й **строго монотонною** на всій напівпрямій `[1, ∞)`.

Доведемо строгу монотонність `F(t)`. Для будь-яких двох дійсних чисел `1 ≤ t₁ < t₂` необхідно довести, що `F(t₂) > F(t₁)`, тобто що щільність натуральних чисел, для яких `t₁ < I(n) < t₂`, є строго додатною:

```
D({n ∈ N : t₁ < I(n) < t₂}) = F(t₂) - F(t₁) > 0      [умова строгої монотонності]
```

Для доведення цього виберемо скінченний добуток простих чисел `Q_k = p₁ · p₂ · ... · p_k` такий, щоб урізаний індекс `I_k(Q_k)` потрапляв у відкритий інтервал `(t₁, t₂)`.
Оскільки кратні числа `n = m · Q_k` (де `gcd(m, Q_k) = 1`) мають індекс `I(n) = I(m) · I_k(Q_k)`, варюючи дільники `m`, ми можемо утворити множину арифметичних прогресій позитивної щільності, для яких `t₁ < I(n) < t₂`.
Це гарантує, що між будь-якими двома значеннями `t₁ < t₂` існує додатна щільність чисел, що й доводить строгу монотонність `F(t)`.

Для доведення відсутності розривів (атомів міри) розглянемо ймовірність того, що `I(n)` дорівнює точечному значенню `t₀`.
Якщо `t₀` було б точкою розриву `F(t)`, то існувала б додатна щільність чисел, для яких `σ(n) / n = t₀`. Але рівняння `σ(n) = t₀ · n` має не більше ніж скінченну кількість розв'язків для кожного конкретного раціонального `t₀`, якщо врахувати структуру простих дільників, або ці розв'язки мають щільність `0`.

Звідси випливає строга неперервність `F(t)` на всьому проміжку `[1, ∞)`:

```
P(I(n) = t₀) = 0      [відсутність точкових мас у розподілі]
```

Зокрема, для `t₀ = 2` щільність досконалих чисел дорівнює точно нулю: `D({n : I(n) = 2}) = 0`.

## 6. Конструктивний чисельний розрахунок урізаної функції F₃(t)

Щоб проілюструвати механіку формування нижньої межі щільності, проаналізуємо дискретний розподіл урізаного індексу `I₃(n)`, який враховує лише перші три прості числа `{2, 3, 5}`.

Будь-яке натуральне число `n` можна представити у вигляді `n = 2ᵃ · 3ᵇ · 5ᶜ · m`, де `gcd(m, 30) = 1`.
Значення урізаного індексу `I₃(n)` залежить виключно від показників `a, b, c`:

```
I₃(n) = I(2ᵃ) · I(3ᵇ) · I(5ᶜ)      [урізаний індекс для простих 2, 3, 5]
```

Розглянемо класи чисел за ділимістю на прості `2, 3, 5`:

1. **Числа, кратні 6 (`a ≥ 1, b ≥ 1`):**
   Найменше значення індексу досягається при `a = 1, b = 1, c = 0`:
   `I₃(n) ≥ I(2) · I(3) = (3/2) · (4/3) = 12 / 6 = 2.0`.
   Оскільки `2.0 ≥ 2.0`, **абсолютно всі числа, кратні 6, є надлишковими** у системі `I₃`.
   Асимптотична щільність чисел, кратних 6, дорівнює точно `1 / 6 ≈ 0.16667` (16.67%).

2. **Числа, кратні 20 (`a ≥ 2, c ≥ 1`):**
   Мінімальне значення індексу: `I₃(n) ≥ I(4) · I(5) = (7/4) · (6/5) = 42 / 20 = 2.1 > 2.0`.
   Усі числа, кратні 20, є надлишковими.
   Щільність кратності 20 дорівнює `1 / 20 = 0.05000` (5.00%).

3. **Числа, кратні 42 (`a ≥ 1, b ≥ 1, p = 7`):**
   При додаванні четвертого простого `7` числа, кратні 42, дають `I₄(n) ≥ (3/2) · (8/7) = ... > 2.0`.

Обчислимо об'єднання щільностей для чисел, кратних 6 та 20, за формулою включення-виключення:

```
D(6 ∪ 20) = 1/6 + 1/20 - 1/lcm(6, 20) = 1/6 + 1/20 - 1/60 = 10/60 + 3/60 - 1/60 = 12/60 = 1/5 = 0.2000      [щільність кратностей 6 та 20]
```

Додаючи числа, кратні `30` (`1/30`) та `42` (`1/42`), отримуємо суму:

```
D_A(урізана) = 1/6 + 1/18 + 1/20 + 1/30 + 1/42 - correction ≈ 0.2333      [нижня межа урізаної системи]
```

Цей чисельний розрахунок показує, як геометрично нашаровуються сімейства кратностей, створюючи платформу щільності `0.2474`.

## 8. Розподіл на множині непарних чисел та умовні моменти

Цікавим аналітичним аспектом є вивчення розподілу індексу надлишковості умовного підкласу **непарних натуральних чисел** `N_odd = 2N + 1`.

Обчислимо умовне математичне сподівання `M_{1, odd} = E[I(n) | n ∈ N_odd]`.
Оскільки для непарних чисел просте число `2` виключено з розкладу `n`, у відповідному добутку Ейлера випадає фактор, що відповідає `p = 2`:

```
M_{1, odd} = lim_{N → ∞} (2 / N) · ∑_{n ≤ N, n ∈ N_odd} I(n)
           = ∏_{p > 2} (1 + 1 / p²) = ζ(2) · (1 - 1/4) = (3/4) · ζ(2) ≈ 1.233700      [середнє значення для непарних чисел]
```

Оскільки умовний перший момент для непарних чисел становить лише `1.2337` (що набагато менше за загальночисловий поріг `1.645` та поріг надлишковості `2.0`), непарні надлишкові числа утворюють екстремально тонкий хвіст розподілу.

Асимптотична щільність непарних надлишкових чисел відносно всієї множини натуральних чисел за оцінками Делегліза становить:

```
D_{A, odd} < 0.00001        [екстремально мала щільність непарних надлишкових чисел]
```

Це пояснює, чому непарні надлишкові числа є унікальними та рідкісними об'єктами теорії чисел.

## 9. Натуральна проти логарифмічної щільності та остаточні межі

У теорії чисел важно розрізняти натуральну (асимптотичну) щільність `D_A` та **логарифмічну щільність** `δ_A`.
Логарифмічна щільність підмножини `S` визначається із зваженим ваговим коефіцієнтом `1/n`:

```
δ_A = lim_{x → ∞} (1 / log(x)) · ∑_{n ≤ x, n ∈ S} 1 / n      [логарифмічна щільність]
```

Для багатьох виняткових підмножин натуральних чисел натуральна щільність не існує (наприклад, для чисел з непарною першою цифрою), але логарифмічна щільність існує завжди, якщо існує натуральна.
За теоремою Давенпорта–Ердеша, для будь-якої множини кратностей `S` з неперервною функцією розподілу `F(t)` натуральна щільність дорівнює точно логарифмічній щільності:

```
D_A = δ_A      [еквівалентність натуральної та логарифмічної щільностей для надлишкових чисел]
```

Це означає, що імовірнісна структура дільників є надзвичайно стійкою відносно логарифмічного зважування.

Для обчислення точних чисельних меж асимптотичної щільності `D_A = 1 - F(2)` використовується комбінація принципу включення-виключення та урізаних ейлерових добутків.

### Схема включення-виключення для примітивних надлишкових чисел

Кожне надлишкове число є кратним принаймні одного первинного (примітивного) надлишкового числа.
Позначимо множину примітивних надлишкових чисел через `P = {q₁, q₂, q₃, ...}`.

Якщо ми обмежуємося першими `m` примітивними надлишковими числами, то за формулою включення-виключення щільність кратностей оцінюється знизу:

```
D_A ≥ ∑_{i=1}^m D(q_i · N) - ∑_{1 ≤ i < j ≤ m} D(lcm(q_i, q_j) · N)      [формула включень-виключень]
```

Оскільки щільність чисел, кратних `K`, дорівнює точно `1 / K`, оцінка набуває вигляду:

```
D_A ≥ ∑_{i=1}^m 1 / q_i - ∑_{1 ≤ i < j ≤ m} 1 / lcm(q_i, q_j)      [чисельна оцінка через НСК]
```

Враховуючи перші 100 примітивних надлишкових чисел та застосовуючи подвійні оцінки Бонферроні, отримуємо сувору нижню межу:

```
D_A > 0.2474      [остаточна нижня межа Делегліза]
```

### Верхня межа та урізані добутки

Для отримання верхньої межі Делегліз (1998) розбив натуральні числа за їхніми найменшими простими дільниками та обчислив розклад індексу `I(n)` для чисел, що не діляться на малі прості.

Застосовуючи теорему Мертенса для суми обернених простих чисел:

```
∑_{p ≤ x} 1 / p = log(log(x)) + M + O(1 / log(x))      [теорема Мертенса для простих чисел]
```

де `M ≈ 0.261497` — стала Мейсселя–Мертенса, Делегліз оцінив залишковий фактор неперервної міри для простих дільників `p > 10⁶`.

Комбінуванням високоточних інтегральних оцінок для урізаного добутку Ейлера доведено остаточну двосторонню нерівність для асимптотичної щільності надлишкових чисел:

```
0.247404 < D_A < 0.247677      [сувора аналітична смуга Давенпорта-Делегліза]
```

Це остаточно доводить, що асимптотична щільність надлишкових чисел становить приблизно **`24.76%`**. Q.E.D.
