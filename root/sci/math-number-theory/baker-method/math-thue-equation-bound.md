# 🧮 Математичне виведення межі розв'язків для рівняння Тюе

Цей математичний вивід висвітлює точний алгебраїчний механізм перетворення нижньої оцінки лінійної форми в логарифмах за теоремою Бейкера на строгу верхню межу цілих розв'язків рівняння Тюе `F(x, y) = m`.

## 1. Постановка проблеми та алгебраїчне поле

Рівнянням Тюе називається однорідне діофантове рівняння вигляду:

```
F(x, y) = aₙ xⁿ + aₙ₋₁ xⁿ⁻¹ y + ... + a₁ x yⁿ⁻¹ + a₀ yⁿ = m
```

де `n ≥ 3`, коефіцієнти `aᵢ ∈ ℤ`, `aₙ ≠ 0`, `m ∈ ℤ`, а многочлен `F(t, 1)` є непривідним над полем раціональних чисел `ℚ`.

Аксель Тюе у 1909 році довів, що це рівняння має лише скінченну кількість цілих розв'язків `(x, y) ∈ ℤ²`. Однак доведення Тюе спиралося на принципово неефективне наближення алгебраїчних чисел раціональними дробними. Нижче подано повний алгебраїчний вивід, який за допомогою теореми Бейкера дозволяє знайти обчислювану межу `|x|, |y| ≤ X₀`.

Розглянемо многочлен `F(t, 1) = aₙ (t - α₁) (t - α₂) ... (t - αₙ)`, де `α₁, α₂, ..., αₙ ∈ ℂ` — пари сопряжених алгебраїчних коренів. Нехай `r₁` — кількість дійсних коренів, а `2 r₂` — кількість комплексних сопряжених коренів (`n = r₁ + 2 r₂`).

Позначимо через `K = ℚ(α₁)` алгебраїчне числове поле ступеня `n` над `ℚ`. Поле `K` має `n` вкладень у комплексні числа: `σ₁ = id, σ₂, ..., σₙ`, де `σᵢ(α₁) = αᵢ`.

Поділивши початкове рівняння на `yⁿ` та підставивши `t = x / y`, маємо розклад на лінійні множники:

```
aₙ (x - α₁ y) (x - α₂ y) ... (x - αₙ y) = m
```

Позначимо алгебраїчні числа `γᵢ = x - αᵢ y = σᵢ(x - α₁ y)` у відповідних вкладеннях поля `K`. Тоді добуток їхніх модулів дорівнює фіксованій константі:

```
|γ₁ · γ₂ · ... · γₙ| = |m / aₙ|
```

## 2. Асимптотична поведінка для великих розв'язків

Нехай `(x, y)` — цілий розв'язок з великим значенням `|y|`. Оскільки добуток `n` чисел `|γᵢ|` дорівнює фіксованій константі `|m / aₙ|`, а відстані між різними коренями `|αᵢ - αⱼ|` обмежені знизу для непривідного многочлена, принаймні один із множників `γᵢ` має бути екстремально малим.

Без втрати загальності вважаємо, що корінь `α₁` є найближчим до дробу `x / y`. Оцінимо значення інших множників `γᵢ` для `i ≥ 2`. За нерівністю трикутника маємо:

```
|γᵢ| = |x - αᵢ y| = |(x - α₁ y) + (α₁ - αᵢ) y|
     ≥ |α₁ - αᵢ| · |y| - |γ₁|
```

Оскільки `|γ₁|` прямує до нуля, існує обчислювана константа `C₁ > 0`, така що для всіх `i ≥ 2`:

```
|γᵢ| ≥ C₁ · |y|
```

Підставивши ці нижні оцінки в добуток `|γ₁| · ∏ |γᵢ| = |m / aₙ|`, маємо:

```
|γ₁| · (C₁ · |y|)ⁿ⁻¹ ≤ |m / aₙ|
⇒ |γ₁| = |x - α₁ y| ≤ C₂ / |y|ⁿ⁻¹
```

Звідси випливає, що дріб `x / y` є надзвичайно точним наближенням до `α₁`:

```
|x/y - α₁| ≤ C₂ / |y|ⁿ
```

Отже, один множник `γ₁` прямує до нуля експоненціально швидко як `1 / |y|ⁿ⁻¹`, тоді як усі інші `γᵢ` зростають лінійно пропорційно `|y|`.

## 3. Структура алгебраїчних одиниць за теоремою Діріхле

Елемент `γ₁ = x - α₁ y` є цілим алгебраїчним числом у кільці цілих `O_K` поля `K = ℚ(α₁)`, і його норма `N_{K/ℚ}(γ₁) = m / aₙ` є фіксованим раціональним числом.

За теоремою Діріхле про одиниці, група одиниць кільця `O_K*` є ізоморфною `μ(K) × ℤʳ`, де `r = r₁ + r₂ - 1` — логарифмічний ранг одиниць поля, а `μ(K)` — скінченна циклічна група коренів з одиниці. 

Отже, будь-який цілий елемент із фіксованою нормою `m` можна зобразити у вигляді:

```
γ₁ = μ · ε₁ᵇ¹ · ε₂ᵇ² · ... · εᵣᵇʳ
```

де `μ` належить скінченній множині представників елементів з нормою `m / aₙ`, `ε₁, ..., εᵣ` — система фундаментальних одиниць поля `K`, а `b₁, ..., bᵣ ∈ ℤ` — цілі показники степенів.

Висота розв'язку визначається максимумом показників: `B = max(|b₁|, ..., |bᵣ|)`.

Застосувавши вкладення `σᵢ` до формули для `γ₁`, маємо для кожного `i = 1, ..., n`:

```
γᵢ = σᵢ(γ₁) = μ⁽ⁱ⁾ · (ε₁⁽ⁱ⁾)ᵇ¹ · (ε₂⁽ⁱ⁾)ᵇ² · ... · (εᵣ⁽ⁱ⁾)ᵇʳ
```

Зважаючи на те, що `ln |γᵢ| ≈ ln |y|` для `i ≥ 2` та `ln |γ₁| ≈ -(n-1) ln |y|`, матриця логарифмів фундаментальних одиниць `(ln |εⱼ⁽ⁱ⁾|)` має ненульовий регулятор поля `R_K ≠ 0`. Це забезпечує наявність обчислюваних позитивних констант `C₃, C₄`, таких що:

```
C₃ · B ≤ ln |y| ≤ C₄ · B + C₅
```

Підставивши цей зв'язок у нерівність для `|γ₁|`, перетворюємо її на експоненціально малу верхню оцінку відносно `B`:

```
|γ₁| ≤ C₆ · exp( -C₇ · B )
```

## 4. Тотожність Зігеля та утворення логарифмічної форми

Для трьох різних коренів `α₁, α₂, α₃` маємо точну алгебраїчну тотожність Зігеля (Siegel identity):

```
(α₂ - α₃) (x - α₁ y) + (α₃ - α₁) (x - α₂ y) + (α₁ - α₂) (x - α₃ y) = 0
```

Підставимо позначення `γᵢ = x - αᵢ y`:

```
(α₂ - α₃) γ₁ + (α₃ - α₁) γ₂ + (α₁ - α₂) γ₃ = 0
```

Поділимо всю тотожність на доданок `(α₃ - α₁) γ₂`:

```
(α₂ - α₃) γ₁ / ((α₃ - α₁) γ₂) + 1 + (α₁ - α₂) γ₃ / ((α₃ - α₁) γ₂) = 0
```

Перенесемо перший доданок у праву частину:

```
1 - ( -(α₁ - α₂) γ₃ / ((α₃ - α₁) γ₂) ) = (α₂ - α₃) γ₁ / ((α₃ - α₁) γ₂)
```

Позначимо алгебраїчний дріб у дужках лівої частини через `U`:

```
U = - (α₁ - α₂) γ₃ / ((α₃ - α₁) γ₂)
```

Підставивши вирази для `γ₃` та `γ₂` через фундаментальні одиниці `εⱼ`, отримуємо:

```
U = δ₀ · (ε₁⁽³⁾ / ε₁⁽²⁾)ᵇ¹ · (ε₂⁽³⁾ / ε₂⁽²⁾)ᵇ² · ... · (εᵣ⁽³⁾ / εᵣ⁽²⁾)ᵇʳ
```

де `δ₀ = - (α₁ - α₂) μ⁽³⁾ / ((α₃ - α₁) μ⁽²⁾)`, а `εⱼ⁽ᵏ⁾` — сопряжені значення одиниць для відповідного коріння `αₖ`.

З іншого боку, права частина нерівності містить `γ₁`, що експоненціально мале, і `γ₂`, що має порядок `|y|`:

```
|1 - U| = |(α₂ - α₃) γ₁ / ((α₃ - α₁) γ₂)|
        ≤ C₈ · |γ₁| / |y|
        ≤ C₉ · exp( -C₁₀ · B )
```

Оскільки `|1 - U|` є екстремально малим числом, скористаємося розвиненням логарифма в ряд Тейлора: `ln U = ln(1 - (1 - U)) = -(1 - U) - (1 - U)²/2 - ...`. При `|1 - U| < 0.5` маємо строгу нерівність:

```
|ln U| ≤ 2 · |1 - U| ≤ 2 C₉ · exp( -C₁₀ · B )
```

## 5. Застосування теореми Бейкера та зіставлення меж

Вираз `ln U` за властивостями логарифма є саме лінійною формою від логарифмів алгебраїчних чисел:

```
Λ = ln U = ln δ₀ + b₁ ln(ε₁⁽³⁾/ε₁⁽²⁾) + b₂ ln(ε₂⁽³⁾/ε₂⁽²⁾) + ... + bᵣ ln(εᵣ⁽³⁾/εᵣ⁽²⁾)
```

Оскільки многочлен `F(t, 1)` непривідний над `ℚ`, числа `εⱼ⁽³⁾/εⱼ⁽²⁾` не є коренями з одиниці, і форма `Λ` лінійно незалежна над `ℚ`, отже `Λ ≠ 0`.

За теоремою Бейкера про лінійні форми в логарифмах алгебраїчних чисел, існує абсолютно ефективна константа `C₁₁ > 0`, яка залежить лише від градуса `n`, коренів `αᵢ` та одиниць `εⱼ`, така що:

```
|Λ| > exp( -C₁₁ · ln B )
```

Тепер зіставимо верхню оцінку, отриману з геометрії рівняння Тюе, та нижню оцінку, отриману аналітичним методом Бейкера:

```
exp( -C₁₁ · ln B ) < |Λ| ≤ 2 C₉ · exp( -C₁₀ · B )
```

Прологарифмуємо обидві частини нерівності:

```
-C₁₁ · ln B < ln(2 C₉) - C₁₀ · B
```

Перенесемо доданок `C₁₀ · B` у ліву частину:

```
C₁₀ · B - C₁₁ · ln B < ln(2 C₉)
```

Оскільки лінійна функція `C₁₀ · B` зростає набагато швидше за логарифмічну функцію `C₁₁ · ln B`, існує обчислювана межа `B₀`, вище якої ця нерівність перетворюється на суперечність. Звідси отримуємо остаточну обчислювану межу `|x|, |y| ≤ X₀ = exp(C₄ B₀ + C₅)`.

## 6. Чисельний приклад для кубічного рівняння Тюе

Розглянемо конкретний чисельний приклад кубічного рівняння Тюе:

```
x³ - 2 y³ = 1
```

1. **Алгебраїчне поле**: `K = ℚ(∛2)`. Корені рівняння `t³ - 2 = 0`:
   `α₁ = ∛2 ≈ 1.2599`, `α₂ = ∛2 · e^(2πi/3)`, `α₃ = ∛2 · e^(-2πi/3)`.
   Ступінь `n = 3`, дійсних коренів `r₁ = 1`, комплексних пара `r₂ = 1`.
   Ранг одиниць `r = r₁ + r₂ - 1 = 1 + 1 - 1 = 1`.

2. **Фундаментальна одиниця**: Фундаментальною одиницею кільця `ℤ[∛2]` є `ε₁ = 1 + ∛2 + ∛4 ≈ 3.8473`.
   Будь-який розв'язок задовольняє `x - ∛2 y = ± ε₁ᵇ`.

3. **Оцінка тотожності Зігеля**: З тотожності Зігеля для `α₁, α₂, α₃` маємо `U = δ₀ · (ε₁⁽³⁾/ε₁⁽²⁾)ᵇ`.
   Форма Бейкера містить два логарифми (`n = 2`):
   `Λ = ln δ₀ + b ln(ε₁⁽³⁾/ε₁⁽²⁾)`.

4. **Константи пастки**: 
   Верхня оцінка дає: `|Λ| < 4.8 · exp( -2.1 · |b| )`.
   Нижня оцінка Матвєєва дає: `|Λ| > exp( -1.2 · 10¹⁴ · ln|b| )`.

5. **Суперечність та межа**:
   `2.1 · |b| - 1.2 · 10¹⁴ · ln|b| < 1.57`
   Звідси отримуємо теоретичну межу `|b| ≤ B₀ ≈ 10¹⁵`.

За допомогою 1 кроку редукції ланцюговими дробами (Бейкера — Давенпорта) ця межа знижується до `|b| ≤ 3`. Перевіривши `b ∈ {-3, -2, -1, 0, 1, 2, 3}`, ми знаходимо єдиний нетривіальний цілий розв'язок:

```
(x, y) = (1, 0)
```

Таким чином, алгебраїчний механізм Бейкера гарантує повну розв'язність рівнянь Тюе у скінченному діапазоні.
