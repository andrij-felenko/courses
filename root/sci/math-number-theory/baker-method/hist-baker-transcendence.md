# 📜 Історія логарифмічних форм та відкриття Бейкера

Концепція лінійних форм у логарифмах виникла з потреби розв'язати сьому проблему Гільберта про трансцендентність степенів алгебраїчних чисел та подолати принципову неефективність класичних теорем діофантового аналізу.

## Від Ліувілля до Сьомої проблеми Гільберта

Історія трансцендентних чисел розпочалася у 1844 році, коли французький математик Жозеф Ліувіль довів існування чисел, які не є коренями жодного многочлена з цілими коефіцієнтами. Ліувіль побудував перші штучні трансцендентні числа (такі як константа Ліувілля `∑ 10^(-k!)`), використавши властивість, що алгебраїчні числа не можуть надто добре наближатися раціональними дробними. Однак питання про трансцендентність природних математичних констант залишалося відкритим.

У 1873 році Шарль Ерміт довів трансцендентність основи натурального логарифма `e`. У 1882 році Фердинанд фон Ліндеман, узагальнивши метод Ерміта, довів трансцендентність числа `π` та вів фундаментальну теорему Ліндемана — Вейєрштрасса: якщо `α₁, ..., αₙ` — алгебраїчні числа, лінійно незалежні над `ℚ`, то їхні експоненти `e^(α₁), ..., e^(αₙ)` є алгебраїчно незалежними над `ℚ`. Звідси одразу випливало остаточне доведення неможливості квадратури круга за допомогою циркуля та лінійки.

На II Міжнародному конгресі математиків у Парижі у 1900 році Давид Гільберт включив до свого знаменитого списку з 23 невирішених проблем питання про трансцендентність степенів алгебраїчних чисел. Сьома проблема Гільберта формулювалася так: чи є число `α^β` трансцендентним, якщо `α` — алгебраїчне число, відмінне від 0 та 1, а `β` — алгебраїчне ірраціональне число? 

Гільберт висловив думку, що доведення трансцендентності таких чисел, як `2^√2` (константа Гільберта) або `e^π = (-1)^(-i)` (константа Ґельфонда), є надзвичайно глибоким і важким. Він прогнозував, що гіпотеза Рімана буде розв'язана найближчим часом, тоді як сьома проблема вимагатиме зусиль багатьох майбутніх поколінь математиків.

## Триумф Ґельфонда та Шнайдера (1934)

Прогноз Гільберта виявився надто песимістичним. У 1934 році Олександр Ґельфонд у Радянському Союзі та Теодор Шнайдер у Німеччині незалежно один від одного і абсолютно різними методами повністю та ствердно розв'язали сьому проблему Гільберта.

```
α, β — алгебраїчні числа
α ∉ {0, 1}, β ∉ ℚ
⇒ α^β — трансцендентне число
```

Ґельфонд застосував метод інтерполяційних цілих аналітичних функцій, побудувавши допоміжний многочлен `P(z, α^z)`, який мав надто багато нулів у цілих точках, що суперечило теоремі про зростання функцій. Шнайдер, з іншого боку, використав теорію еліптичних та автоморфних функцій і побудував допоміжні функції на цілих ґратках у комплексній площині.

Для застосування у діофантовому аналізі виявилося зручнішим переформулювати теорему Ґельфонда — Шнайдера у логарифмічному вигляді. Якщо прологарифмувати рівняння `α₁^b₁ · α₂^b₂ = 1`, ми отримуємо лінійну комбінацію логарифмів:

```
b₁ ln α₁ + b₂ ln α₂ = 0
```

Теорема Ґельфонда — Шнайдера стверджує: якщо `ln α₁` та `ln α₂` лінійно незалежні над раціональними числами `ℚ`, то така лінійна комбінація не може дорівнювати нулю для будь-яких цілих коефіцієнтів `b₁, b₂ ∈ ℤ`, не рівних нулю одночасно.

## Кількісна оцінка Ґельфонда (1935) та межа двох логарифмів

У 1935 році Олександр Ґельфонд зробив фундаментальний крок від якісного твердження (трансцендентності) до кількісного (оцінки модуля). Він поставив питання: якщо вираз `b₁ ln α₁ + b₂ ln α₂` не дорівнює нулю точно, наскільки близько до нуля він може наближатися?

Ґельфонд довів першу в історії нижню межу для форми з двох логарифмів:

```
|b₁ ln α₁ + b₂ ln α₂| > exp( -C · ln B )
```

де `B = max(|b₁|, |b₂|)`, а `C` — явна, ефективно обчислювана константа, що залежить лише від висот та ступенів алгебраїчних чисел `α₁` та `α₂`.

Ця оцінка дозволила вперше надати ефективні межі розв'язків для деяких окремих класів діофантових рівнянь з двома змінними (наприклад, рівняння вида `axⁿ - byⁿ = c`). Однак класичний діофантів аналіз вимагав значно більшого. Загальне рівняння Тюе `F(x, y) = m` для ступенів `n ≥ 3`, рівняння Еліпса `y² = x³ + k`, рівняння Каталана `xᵖ - yʳ = 1` при розкладі на алгебраїчні одиниці поля за теоремою Діріхле приводять до лінійних комбінацій з **трьох або більше логарифмів** (`n ≥ 3`).

Протягом понад 30 років спроби узагальнити оцінку Ґельфонда на `n ≥ 3` логарифмів наражалися на нездоланні аналітичні перешкоди. Проблема полягала у тому, що при `n ≥ 3` допоміжні аналітичні функції багатьох комплексних змінних не мали необхідної кількості нулів для застосування традиційних детермінантних методів інтерполяції (Zero Interpolation Determinants). Спроба розширити систему рівнянь призводила до того, що кількість невідомих коефіцієнтів зростала швидше, ніж кількість незалежних оцінок.

## Прорив Алана Бейкера (1966–1968) та Філдсівська премія

У 1966–1968 роках молодий англійський математик Алан Бейкер (Alan Baker) з Кембриджського університету у серії з чотирьох фундаментальних праць під назвою *Linear forms in logarithms* (частини I–IV), опублікованих у журналі *Mathematica*, здійснив грандіозний науковий прорив.

У першій статті (1966) Бейкер довів трансцендентність лінійних комбінацій будь-якої кількості логарифмів. У наступних трьох статтях (1967–1968) він розробив новий метод побудови допоміжних аналітичних функцій багатьох комплексних змінних з похідними високих порядків за декількома напрямками одночасно. Це дозволило йому отримати строгу кількісну нижню межу для довільної кількості `n` логарифмів алгебраїчних чисел:

```
Λ = b₁ ln α₁ + b₂ ln α₂ + ... + bₙ ln αₙ

Якщо ln α₁, ..., ln αₙ лінійно незалежні над ℚ і Λ ≠ 0, то:
|Λ| > exp( -(16 n d)^(200 n) · ln A₁ ... ln Aₙ · ln B )
```

де `d = [ℚ(α₁, ..., αₙ) : ℚ]` — ступінь розширення поля, `Aᵢ` — висоти алгебраїчних чисел `αᵢ`, а `B = max |bᵢ|`.

Відкриття Бейкера справило вибуховий ефект у теорії чисел. Воно миттєво вирішило цілу низку давніх проблем:
1. **Проблема числа класів Гаусса (Class Number Problem)**: Гаусс у 1801 році висловив гіпотезу про перелік усіх уявних квадратних полів `ℚ(√-d)` з числом класів ідеалів `h(-d) = 1`. У 1966 році Бейкер та Гарольд Старк (Harold Stark) незалежно довели, що існує точно 9 таких полів: `d = 1, 2, 3, 7, 11, 19, 43, 67, 163`.
2. **Ефективність теореми Тюе**: Бейкер надав першу явну верхню межу розв'язків рівнянь Тюе `F(x, y) = m`.
3. **Ефективність теореми Зігеля**: Метод Бейкера надав явні межі для цілих точок на еліптичних та гіпереліптичних кривих.

У 1970 році на Міжнародному конгресі математиків у Ніцці 31-річному Алану Бейкеру було вручено найвищу математичну нагороду — **Філдсівську премію** за створення методу логарифмічних форм та його застосування до діофантового аналізу.

## Еволюція констант та сучасні оцінки

Після фундаментальних робіт Бейкера розпочалася ера вдосконалення логарифмічних меж. Початкова константа Бейкера `(16 n d)^(200 n)` була надзвичайно великою, що призводило до теоретичних меж розв'язків `B₀` порядку `10³⁰⁰`. 

Протягом 1970–2000-х років математики активно зменшували ці константи, застосовуючи нові результати з алгебраїчної геометрії, теорії висот Фальтінгса та багатовимірного аналізу:

- **Алан Бейкер (1977)**: Узагальнив та зменшив константу за допомогою методів теорії функцій багатьох змінних до `C = (c · n · d)ⁿ`.
- **Мішель Вальдшмідт (Michel Waldschmidt, 1980–1993)**: Розробив систематичний підхід до логарифмічних форм у комплексній та p-адичній областях, значно спростивши структури доведення та оновивши висоти Малера.
- **Ґізельберт Вюстгольц (Gisbert Wüstholz, 1989)**: Довів загальну теорему про алгебраїчні групи та лему про нулі (Zero Lemma) на комутативних алгебраїчних групах, що надало фундаментальну алгебро-геометричну основу методу Бейкера.
- **Микола Матвєєв (Nikolai Matveev, 2000)**: Отримав найточнішу на сьогодні оцінку для дійсних логарифмів алгебраїчних чисел, яка використовується в сучасних алгоритмах:

```
|Λ| > exp( -1.4 · 30ⁿ⁺¹ · n³·⁵ · d² · (1 + ln d) · ln A₁ ... ln Aₙ · ln B )
```

У 1990–2000-х роках Юй Куньжуй (Yu Kunrui) поширив метод Бейкера на **p-адичні логарифми** (`p-adic linear forms in logarithms`), що дозволило ефективно розв'язувати S-одиничні діофантові рівняння та досліджувати найбільші прості дільники послідовностей `P(f(n))`.

Крім того, застосування методу Бейкера до **еліптичних логарифмів** (комплексних та p-адичних логарифмів на еліптичних кривих), розроблене у працях Джозефа Сильвермана (Joseph Silverman), Сергія Дворака (Sergei Vostokov) та Ніколя Смарта (Nigel Smart), дозволило розв'язувати діофантові рівняння вищих родів безпосередньо над кривими.

Сьогодні метод Бейкера залишається одним із найпотужніших та найживіших розділів аналітичної теорії чисел. Він слугує містком між абстрактною алгебраїчною геометрією, теорією трансцендентності та практичними комп'ютерними алгоритмами розв'язання діофантових рівнянь.
