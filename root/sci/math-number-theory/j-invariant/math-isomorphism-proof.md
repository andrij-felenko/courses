# 🧮 Алгебраїчні доведення класифікаційної теореми та геометрія відображення Лежандра

Ця математична праця містить повні алгебраїчні доведення фундаментальної теореми про класифікацію еліптичних кривих над алгебраїчно замкненими полями, аналіз характеристик 2 та 3, точний розрахунок автоморфізмів і твістів через когомології Галуа, виведення геометрії параметризації Лежандра через подвійні відношення точок розгалуження, інваріантний зв'язок із кривими Монтгомері та Едвардса, поліноми класів Гільберта, алгебраїчну теорію модулярних многочленів ізогеній та диференціальні критерії надсингулярності.

## 1. Допустимі перетворення координат та інваріанти Вейєрштрасса

Нехай еліптична крива `E` над довільним полем `K` задана загальним рівнянням Вейєрштрасса (нім. *Weierstrass*):

```
E: y² + a₁xy + a₃y = x³ + a₂x² + a₄x + a₆
```

У проективних координатах `[X : Y : Z]`, де `x = X/Z` та `y = Y/Z`, крива має вигляд кубічної форми в `ℙ²(K)` з єдиною нескінченно віддаленою точкою `O = [0 : 1 : 0]`. Будь-який морфізм між двома еліптичними кривими, що зберігає нейтральний елемент `O`, є лінійним проективним перетворенням площини `ℙ²`, яке фіксує точку `[0 : 1 : 0]` та дотичну пряму до неї `Z = 0`.

З вимоги збереження точки `O` та форми кубічного рівняння випливає, що найзагальніша допустима заміна координат в афінній карті `(x, y)` задається чотирма параметрами: ненульовим масштабним множником `u ∈ K*` та трьома параметрами зсуву `r, s, t ∈ K`:

```
x = u²x' + r
y = u³y' + su²x' + t
```

Ці параметри мають чіткий геометричний зміст:
* `u` здійснює градуйоване зважене розтягнення координат, де координата `x` має вагу 2, а координата `y` — вагу 3.
* `s` відповідає за поворот або скошування осі `y` для усунення перехресного добутку `xy`.
* `r` здійснює паралельне перенесення осі `x` для усунення квадратичного члена `x²`.
* `t` здійснює вертикальний зсув для усунення лінійного за `y` члена `a₃y`.

### Трансформація базових коефіцієнтів та інваріантів

Для опису геометрії кривої вводяться стандартні поліноміальні комбінації коефіцієнтів, запропоновані Тейтом та Делінгом:

```
b₂ = a₁² + 4a₂
b₄ = 2a₄ + a₁a₃
b₆ = a₃² + 4a₆
b₈ = a₁²a₆ + 4a₂a₆ - a₁a₃a₄ + a₂a₃² - a₄²
```

З величин `bᵢ` будуються фундаментальні коваріанти `c₄` (ваги 4), `c₆` (ваги 6) та модулярний дискримінант `Δ` (ваги 12):

```
c₄ = b₂² - 24b₄
c₆ = -b₂³ + 36b₂b₄ - 216b₆
Δ = -b₂²b₈ - 8b₄³ - 27b₆² + 9b₂b₄b₆
```

Між цими трьома величинами виконується універсальна тотожність у характеристиках, відмінних від 2 і 3:

```
1728 · Δ = c₄³ - c₆²
```

При застосуванні допустимого перетворення координат `(x, y) ↦ (u²x' + r, u³y' + su²x' + t)` коефіцієнти рівняння трансформуються згідно з формулами:

```
u · a₁' = a₁ + 2s
u² · a₂' = a₂ - sa₁ + 3r - s²
u³ · a₃' = a₃ + ra₁ + 2t
u⁴ · a₄' = a₄ - sa₃ + 2ra₂ - (t + rs)a₁ + 3r² - 2st
u⁶ · a₆' = a₆ + ra₄ + r²a₂ + r³ - ta₃ - t² - rta₁
```

Простежимо перетворення величини `b₂'`. Підставивши перетворені коефіцієнти, отримуємо:

```
b₂'
= (a₁')² + 4a₂'
= u⁻² · ((a₁ + 2s)² + 4(a₂ - sa₁ + 3r - s²))    [підстановка перетворених коефіцієнтів]
= u⁻² · (a₁² + 4a₁s + 4s² + 4a₂ - 4sa₁ + 12r - 4s²)    [розкриття дужок та спрощення]
= u⁻² · (b₂ + 12r)    [скорочення доданків з s та виділення b₂]
```

Для величини `c₄'` маємо повне алгебраїчне скорочення параметрів зсуву `r, s, t`:

```
c₄'
= (b₂')² - 24b₄'
= u⁻⁴ · ((b₂ + 12r)² - 24(b₄ + rb₂ + 6r²))    [підстановка b₂' та b₄']
= u⁻⁴ · (b₂² + 24rb₂ + 144r² - 24b₄ - 24rb₂ - 144r²)    [розкриття дужок]
= u⁻⁴ · (b₂² - 24b₄)    [взаємне знищення доданків з r]
= u⁻⁴ · c₄    [застосування визначення c₄]
```

Для величини `c₆'` аналогічно отримуємо строге масштабування шостого степеня:

```
c₆'
= u⁻⁶ · c₆    [однорідне масштабування ваги 6]
```

Для модулярного дискримінанта `Δ'` розрахунок через різницю степенів дає:

```
Δ'
= (1 / 1728) · ((c₄')³ - (c₆')²)    [визначення через c₄' та c₆']
= (1 / 1728) · ((u⁻⁴c₄)³ - (u⁻⁶c₆)²)    [підстановка правил масштабування]
= (1 / 1728) · (u⁻¹²c₄³ - u⁻¹²c₆²)    [винесення спільного множника u⁻¹²]
= u⁻¹² · ((c₄³ - c₆²) / 1728)    [факторизація]
= u⁻¹² · Δ    [однорідне масштабування дискримінанта ваги 12]
```

### Доведення інваріантності j(E)

Визначимо j-інваріант еліптичної кривої `E` як відношення:

```
j(E) = c₄³ / Δ
```

Обчислимо значення j-інваріанта для нової ізоморфної кривої `E'`:

```
j(E')
= (c₄')³ / Δ'    [визначення j-інваріанта для нової кривої]
= (u⁻⁴c₄)³ / (u⁻¹²Δ)    [підстановка законів перетворення c₄' та Δ']
= (u⁻¹² · c₄³) / (u⁻¹² · Δ)    [піднесення до куба чисельника]
= c₄³ / Δ    [скорочення ненульового множника u⁻¹²]
= j(E)    [інваріантність доведена]
```

Оскільки знаменник `Δ ≠ 0` для гладких кривих, а степінь чисельника `(u⁻⁴)³ = u⁻¹²` точно компенсує степінь знаменника `u⁻¹²`, число `j(E)` повністю не залежить від вибору системи координат.

## 2. Теорема класифікації над алгебраїчно замкненим полем

**Теорема.** *Нехай `K` — довільне поле, а `K̄` — його алгебраїчне замикання. Дві еліптичні криві `E₁` та `E₂`, визначені над `K`, є ізоморфними над полем `K̄` тоді й лише тоді, коли їхні j-інваріанти збігаються:*

```
E₁ ≅ E₂ над K̄   ⟺   j(E₁) = j(E₂)
```

### Доведення достатності для характеристики char(K) ≠ 2, 3

Якщо характеристика поля не дорівнює 2 або 3, заміна змінних `x ↦ x - b₂/12` та `y ↦ y - (a₁x + a₃)/2` приводить довільну криву до короткої форми Вейєрштрасса:

```
E₁: y² = x³ + A₁x + B₁
E₂: y² = x³ + A₂x + B₂
```

Для короткої форми величини набувають компактного вигляду:
`c₄ = -48A`, `c₆ = -864B`, `Δ = -16(4A³ + 27B²)`.
Формула j-інваріанта перетворюється на:

```
j(E) = 1728 · 4A³ / (4A³ + 27B²)
```

Нехай `j(E₁) = j(E₂)`. Доведемо існування елемента `u ∈ K̄*`, такого що `A₁ = u⁴A₂` та `B₁ = u⁶B₂`. Розглянемо три можливі структури інваріанта:

#### 1. Загальний випадок: j(E₁) = j(E₂) ∉ {0, 1728}

Нерівність `j ≠ 0` означає, що `A₁ ≠ 0` та `A₂ ≠ 0`.
Нерівність `j ≠ 1728` означає, що `B₁ ≠ 0` та `B₂ ≠ 0`, оскільки `j - 1728 = 1728 · (-27B²) / (4A³ + 27B²)`.

Прирівняємо вирази для j-інваріантів:

```
4A₁³ / (4A₁³ + 27B₁²) = 4A₂³ / (4A₂³ + 27B₂²)
```

Перемножуючи чисельники та знаменники:

```
4A₁³ · (4A₂³ + 27B₂²) = 4A₂³ · (4A₁³ + 27B₁²)
16A₁³A₂³ + 108A₁³B₂² = 16A₁³A₂³ + 108A₂³B₁²
108A₁³B₂² = 108A₂³B₁²
A₁³ / B₁² = A₂³ / B₂²
```

Оберемо `u = (A₁ / A₂)^(1/4) ∈ K̄*`. Тоді `u⁴ = A₁ / A₂`, звідки `A₁ = u⁴A₂`.
Підставивши це співвідношення у рівність часток:

```
(u⁴A₂)³ / B₁² = A₂³ / B₂²
u¹²A₂³ / B₁² = A₂³ / B₂²
B₁² = u¹²B₂² = (u⁶B₂)²
```

Звідси випливає, що `B₁ = ± u⁶B₂`. Якщо `B₁ = u⁶B₂`, заміна координат `(x, y) ↦ (u²x, u³y)` є шуканим ізоморфізмом. Якщо `B₁ = -u⁶B₂`, замінимо `u` на `iu` (де `i ∈ K̄` — корінь рівняння `i² = -1`). Тоді:
`(iu)⁴ = i⁴u⁴ = u⁴`, отже `(iu)⁴A₂ = u⁴A₂ = A₁`.
`(iu)⁶ = i⁶u⁶ = -u⁶`, отже `(iu)⁶B₂ = -u⁶B₂ = B₁`.
Шуканий ізоморфізм побудовано над `K̄`.

#### 2. Спеціальний випадок j = 0 (A = 0, B ≠ 0)

Рівняння кривих мають вигляд `E₁: y² = x³ + B₁` та `E₂: y² = x³ + B₂`.
Оскільки дискримінанти ненульові, `B₁ ≠ 0` та `B₂ ≠ 0`.
Обираємо `u = (B₁ / B₂)^(1/6) ∈ K̄*`. Перевірка перетворень:
`u⁴ · A₂ = u⁴ · 0 = 0 = A₁`.
`u⁶ · B₂ = (B₁ / B₂) · B₂ = B₁`.
Заміна `(x, y) ↦ (u²x, u³y)` задає ізоморфізм.

#### 3. Спеціальний випадок j = 1728 (A ≠ 0, B = 0)

Рівняння кривих мають вигляд `E₁: y² = x³ + A₁x` та `E₂: y² = x³ + A₂x`.
Оскільки дискримінанти ненульові, `A₁ ≠ 0` та `A₂ ≠ 0`.
Обираємо `u = (A₁ / A₂)^(1/4) ∈ K̄*`. Перевірка:
`u⁴ · A₂ = (A₁ / A₂) · A₂ = A₁`.
`u⁶ · B₂ = u⁶ · 0 = 0 = B₁`.
Ізоморфізм встановлено.

## 3. Особливості характеристик 2 та 3

У полях малої характеристики стандартна редукція до короткої форми Вейєрштрасса неможлива через неможливість ділення на 2 або 3. Проте теорема про класифікацію через j-інваріант залишається повністю справедливою.

### Характеристика char(K) = 2

У характеристиці 2 будь-яка несингулярна еліптична крива належить до одного з двох взаємовиключних класів:

1. **Звичайні (ординарні) криві (`j ≠ 0`):**
   Крива зводиться до форми:

   ```
   y² + xy = x³ + a₂x² + a₆
   ```

   Для цієї форми `b₂ = 1`, `b₄ = 0`, `b₆ = a₆`, `c₄ = 1`, `Δ = a₆`.
   Значення j-інваріанта дорівнює:

   ```
   j(E) = c₄³ / Δ = 1 / a₆
   ```

   Дві ординарні криві ізоморфні над `K̄` тоді й лише тоді, коли їхні параметри `a₆` збігаються (тобто коли `j(E₁) = j(E₂)`).

2. **Надсингулярні криві (`j = 0`):**
   Крива зводиться до форми:

   ```
   y² + a₃y = x³ + a₄x + a₆,  де a₃ ≠ 0
   ```

   Для цієї форми `c₄ = 0`, `Δ = a₃⁴ ≠ 0`.
   Значення j-інваріанта дорівнює:

   ```
   j(E) = 0 / a₃⁴ = 0
   ```

   Усі надсингулярні еліптичні криві в характеристиці 2 мають j-інваріант, рівний 0, і є ізоморфними над алгебраїчним замиканням `K̄`.

### Характеристика char(K) = 3

У характеристиці 3 крива зводиться до форми `y² = x³ + a₂x² + a₄x + a₆`.

1. **Ординарні криві (`j ≠ 0`):**
   Зводяться до форми `y² = x³ + a₂x² + a₆`, де `a₂ ≠ 0`. Дискримінант `Δ = -a₂³a₆ ≠ 0`, величина `c₄ = a₂²`, тому:

   ```
   j(E) = c₄³ / Δ = -a₂³ / a₆
   ```

2. **Надсингулярні криві (`j = 0`):**
   Зводяться до форми `y² = x³ + a₄x + a₆`, де `a₄ ≠ 0`. Величина `c₄ = 0`, дискримінант `Δ = -a₄³ ≠ 0`, звідки `j(E) = 0`.

## 4. Групи автоморфізмів та когомологічна класифікація твістів

Автоморфізми еліптичної кривої над алгебраїчним замиканням `K̄` визначаються як стабілізатори коефіцієнтів кривої під дією групи перетворень координат.

Для короткої форми Вейєрштрасса умова `(u²x, u³y)` бути автоморфізмом зводиться до системи:

```
u⁴ · A = A
u⁶ · B = B
```

Розв'язки цієї системи в полі `K̄` визначають структуру групи `Aut(E)`:

```
Aut(E) ≅ ℤ / 2ℤ,  якщо j ∉ {0, 1728}
Aut(E) ≅ ℤ / 4ℤ,  якщо j = 1728  (char ≠ 2)
Aut(E) ≅ ℤ / 6ℤ,  якщо j = 0     (char ≠ 2, 3)
```

### Когомології Галуа та класифікація твістів над незамкненим полем

Над полем `K`, яке не є алгебраїчно замкненим (наприклад, скінченне поле `𝔽_q` або поле раціональних чисел `ℚ`), дві криві з однаковим j-інваріантом можуть не бути ізоморфними над `K`. Такі криві називаються **твістами** (англ. *twists*).

Множина класів `K`-ізоморфізму еліптичних кривих, ізоморфних `E` над `K̄`, перебуває у бієктивній відповідності з першою множиною когомологій Галуа:

```
Twist(E/K) ≅ H¹(Gal(K̄/K), Aut(E))
```

Оскільки група `Aut(E)` є скінченною циклічною групою порядку `n ∈ {2, 4, 6}`, елементи когомологій описуються теорією Куммера через фактор-групи поля:

1. **Квадратичні твісти (`n = 2`, `j ∉ {0, 1728}`):**
   `H¹(Gal(K̄/K), ±1) ≅ K* / (K*)²`.
   Для кожного неквадрата `d ∈ K* \ (K*)²` крива `E^{(d)}: y² = x³ + d²Ax + d³B` (або `dy² = x³ + Ax + B`) є квадратичним твістом `E`. Над полем `K(√d)` ці криві стають ізоморфними через перетворення `(x, y) ↦ (dx, d^(3/2)y)`.

2. **Четвертинні (квартичні) твісти (`n = 4`, `j = 1728`):**
   `H¹(Gal(K̄/K), μ₄) ≅ K* / (K*)⁴`.
   Криві мають вигляд `E^{(d)}: y² = x³ + dAx`, де `d ∈ K* / (K*)⁴`. Над скінченним полем `𝔽_q` (де `q ≡ 1 mod 4`) існує рівно 4 класи ізоморфізму кривих з `j = 1728`.

3. **Шестикратні (секстичні) твісти (`n = 6`, `j = 0`):**
   `H¹(Gal(K̄/K), μ₆) ≅ K* / (K*)⁶`.
   Криві мають вигляд `E^{(d)}: y² = x³ + dB`, де `d ∈ K* / (K*)⁶`. Над полем `𝔽_q` (де `q ≡ 1 mod 6`) існує рівно 6 класів ізоморфізму кривих з `j = 0`.

## 5. Параметризація Лежандра та група перестановок S₃

Форма Лежандра параметризує еліптичну криву через положення четвертої точки розгалуження `λ` проективної прямої `ℙ¹`:

```
E_λ: y² = x · (x - 1) · (x - λ),  де λ ∈ K̄ \ {0, 1}
```

Подвійне відношення чотирьох точок `{0, 1, ∞, λ}` перетворюється під дією групи перестановок `S₄` на шість можливих значень:
`λ`, `1/λ`, `1 - λ`, `1/(1 - λ)`, `(λ - 1)/λ`, `λ/(λ - 1)`.

### Формула j(λ) та інваріантність

Прирівнюючи коефіцієнти форми Лежандра до форми Вейєрштрасса заміною `x ↦ x + (λ + 1)/3`, отримуємо формулу j-інваріанта:

```
j(λ) = 256 · (λ² - λ + 1)³ / (λ² · (λ - 1)²)
```

Перевіримо дію генератора інверсії `λ ↦ 1/λ`:

```
j(1/λ)
= 256 · ((1/λ)² - (1/λ) + 1)³ / ((1/λ)² · ((1/λ) - 1)²)    [підстановка 1/λ]
= 256 · ((1 - λ + λ²) / λ²)³ / ((1/λ²) · ((1 - λ)/λ)²)    [зведення до спільного знаменника]
= 256 · ((λ² - λ + 1)³ / λ⁶) / ((λ - 1)² / λ⁴)    [піднесення до степенів]
= 256 · (λ² - λ + 1)³ / (λ² · (λ - 1)²)    [скорочення на λ⁴]
= j(λ)    [інваріантність доведена]
```

Перевіримо дію генератора зсуву `λ ↦ 1 - λ`:

```
j(1 - λ)
= 256 · ((1 - λ)² - (1 - λ) + 1)³ / ((1 - λ)² · ((1 - λ) - 1)²)    [підстановка 1 - λ]
= 256 · (1 - 2λ + λ² - 1 + λ + 1)³ / ((1 - λ)² · (-λ)²)    [розкриття дужок]
= 256 · (λ² - λ + 1)³ / (λ² · (λ - 1)²)    [спрощення чисельника та знаменника]
= j(λ)    [інваріантність доведена]
```

Оскільки `1/λ` та `1 - λ` породжують усю групу `S₃`, функція `j(λ)` однакова для всіх шести значень параметра `λ`. Відображення `λ ↦ j(λ)` є 6-листковим розгалуженим накриттям сфери Рімана `ℙ¹` над `j`-сферою.

Параметр `λ` також безпосередньо пов'язаний з періодами еліптичних інтегралів через гіпергеометричну функцію Гаусса `F(1/2, 1/2; 1; λ)`. Це дозволяє аналітично обчислювати періоди ґратки безпосередньо з геометрії конфігурації точок розгалуження.

## 6. Зв'язок із кривими Монтгомері та скрученими кривими Едвардса

У сучасній криптографії широкого застосування набули альтернативні моделі еліптичних кривих, що оптимізують швидкість скалярного множення та забезпечують захист від атак за часом виконання. Обчислення j-інваріанта дозволяє миттєво співвідносити ці моделі з канонічною формою Вейєрштрасса.

### Криві Монтгомері (Montgomery Curves)

Крива Монтгомері задається рівнянням:

```
M_{A, B}: B · y² = x³ + A · x² + x,  де B · (A² - 4) ≠ 0
```

Раціональна біраціональна заміна `(x, y) ↦ (x/B + A/(3B), y/B)` переводить форму Монтгомері у форму Вейєрштрасса з коефіцієнтами:

```
a₄ = (3 - A²) / (3B²)
a₆ = (2A³ - 9A) / (27B³)
```

Обчислення дискримінанта та коваріантів дає точну формулу j-інваріанта кривої Монтгомері:

```
j(M_{A, B}) = 256 · (A² - 3)³ / (A² - 4)
```

З цієї формули видно ключові алгебраїчні властивості:
1. Значення `j(M_{A, B})` залежить виключно від коефіцієнта `A` і не залежить від масштабувального параметра `B`. Зміна параметра `B` породжує квадратичний твіст кривої над базовим полем.
2. Крива `Curve25519` має параметр `A = 486662`, що дає конкретне 256-бітне значення j-інваріанта.

### Скручені криві Едвардса (Twisted Edwards Curves)

Скручена крива Едвардса задається рівнянням:

```
E_{a, d}: a · x² + y² = 1 + d · x² · y²,  де a · d · (a - d) ≠ 0
```

Кожна скручена крива Едвардса є біраціонально еквівалентною кривій Монтгомері з параметрами `A = 2(a + d)/(a - d)` та `B = 4/(a - d)`. Підставляючи ці значення у формулу Монтгомері, отримуємо явний вираз j-інваріанта через коефіцієнти Едвардса:

```
j(E_{a, d}) = 16 · (a² + 14ad + d²)³ / (a · d · (a - d)⁴)
```

Для класичних кривих Едвардса (де `a = 1`, наприклад `Ed25519` з `d = -121665/121666`) формула спрощується:

```
j(E_{1, d}) = 16 · (1 + 14d + d²)³ / (d · (1 - d)⁴)
```

## 7. Поліноми класів Гільберта та комплексне множення

Еліптична крива `E` над полем `ℂ` має комплексне множення (англ. *Complex Multiplication*, CM), якщо її кільце ендоморфізмів `End(E)` є строго ширшим за кільце цілих чисел `ℤ`, тобто є порядком `𝒪_D` в уявному квадратичному полі `K = ℚ(√-D)` з дискримінантом `-D < 0`.

У цьому випадку значення `j(E) = j(𝒪_D)` є цілим алгебраїчним числом. Мінімальний многочлен числа `j(𝒪_D)` над полем `ℚ` називається **поліномом класів Гільберта** (нім. *Hilbert-Klassenpolynom*) `H_D(X)`:

```
H_D(X) = ∏ (X - j(𝔮))
```

де добуток береться за всіма `h(D)` класами еквівалентності ідеалів `𝔮` порядку `𝒪_D`, а `h(D)` — класове число (англ. *class number*) квадратичного поля.

Поліном `H_D(X)` має виключно цілі коефіцієнти `H_D(X) ∈ ℤ[X]`. Спільні приклади для малих дискримінантів із класовим числом `h(D) = 1`:
* `D = 3` (`ℚ(√-3)`): `H₃(X) = X` (корінь `j = 0`).
* `D = 4` (`ℚ(√-1)`): `H₄(X) = X - 1728` (корінь `j = 1728`).
* `D = 11` (`ℚ(√-11)`): `H₁₁(X) = X + 32768 = X + 32³`.
* `D = 19` (`ℚ(√-19)`): `H₁₉(X) = X + 884736 = X + 96³`.
* `D = 163` (`ℚ(√-163)`): `H₁₆₃(X) = X + 262537412640768000 = X + 640320³`.

Якщо просте число `p` розкладається в полі `ℚ(√-D)` як `4p = t² + D · v²` (де `t` — слід Фробеніуса), то многочлен `H_D(X)` повністю розкладається на лінійні множники над скінченним полем `𝔽_p`. Кожен його корінь `j₀ ∈ 𝔽_p` є j-інваріантом еліптичної кривої над `𝔽_p`, яка має рівно `p + 1 - t` точок. Це дозволяє миттєво генерувати криві із наперед заданим порядком групи для криптографічних застосувань.

## 8. Диференціальні форми та алгебраїчний критерій надсингулярності

Голоморфний диференціал на еліптичній кривій задається формулою інваріантного диференціала:

```
ω = dx / (2y + a₁x + a₃)
```

При допустимому перетворенні координат `(x, y) ↦ (u²x' + r, u³y' + su²x' + t)` диференціал масштабується лінійно:

```
ω' = u · ω
```

Це перетворення підтверджує, що диференціал `ω` є 1-формою ваги 1, а добуток `ω¹²` має вагу 12, що в точності відповідає вазі дискримінанта `Δ`.

У формальній групі біля нескінченно віддаленої точки `O` локальний параметр `z = -x/y` розкладає диференціал у формальний степеневий ряд `ω(z) = (1 + a₁z + (a₁² + a₂)z² + ...) dz`. Інтегрування цього ряду дає формальний логарифм кривої, чиї коефіцієнти пов'язують формальну групу кривої з коваріантами Вейєрштрасса.

Над скінченним полем `𝔽_p` непарної характеристики крива `E: y² = f(x) = x³ + Ax + B` є надсингулярною (англ. *supersingular*) тоді й лише тоді, коли слід ендоморфізму Фробеніуса ділиться на характеристику поля: `a_p ≡ 0 mod p`.

За критерієм Деінга — Хассе, слід Фробеніуса за модулем `p` в точності дорівнює коефіцієнту при члені `x^(p - 1)` у многочлені `f(x)^((p - 1)/2)`. Позначимо цей коефіцієнт через `H_p(A, B)`.

Критерій надсингулярності набуває елегантного вигляду через коефіцієнти рівняння:

```
E є надсингулярною   ⟺   H_p(A, B) ≡ 0 mod p
```

Оскільки вираз `H_p(A, B)` є однорідним поліномом від `A³` та `B²`, відношення коренів цього полінома визначає скінченну множину надсингулярних j-інваріантів у полі `𝔽_p²`. Загальна кількість надсингулярних j-інваріантів у характеристиці `p` дорівнює в точності роду модулярної кривої `X₀(p)` плюс поправки на точки галуження:

```
N_ss = ⌊p / 12⌋ + ε,  де ε ∈ {0, 1, 2}
```

Усі надсингулярні j-інваріанти лежать у розширенні другого степеня `𝔽_p²` і утворюють замкнений граф ізогеній Рамануджана.

## 9. Алгебраїчна теорія модулярних многочленів ізогеній

Ізогенією (грец. *isos* — рівний, *genos* — рід) степеня `ℓ` називається ненульовий раціональний груповий гомоморфізм `φ: E₁ → E₂` зі скінченним ядром порядку `|ker(φ)| = ℓ`.

Якщо ядро ізогенії `C = ker(φ) ⊂ E₁[ℓ]` є циклічною підгрупою порядку `ℓ`, факторобчислення за Велю (фр. *Vélu*) дозволяє побудувати ізогенну криву `E₂ = E₁ / C`.

### Модулярний многочлен Φ_ℓ(X, Y)

Класичний модулярний многочлен `Φ_ℓ(X, Y)` визначається як незвідний поліном із цілими коефіцієнтами `Φ_ℓ(X, Y) ∈ ℤ[X, Y]`, корені якого задають пари j-інваріантів кривих, пов'язаних циклічною `ℓ`-ізогенією:

```
Φ_ℓ(j(E₁), j(E₂)) = 0   ⟺   існує циклічна ℓ-ізогенія φ: E₁ → E₂
```

Фундаментальні властивості модулярного многочлена:
1. **Симетрія:** `Φ_ℓ(X, Y) = Φ_ℓ(Y, X)` для будь-якого простого `ℓ`, оскільки кожна ізогенія має двоїсту ізогенію `φ̂: E₂ → E₁` того самого степеня `ℓ`.
2. **Степінь:** степінь многочлена за кожною змінною дорівнює кількості циклічних підгруп порядку `ℓ` у групі точок кручення `E[ℓ] ≅ ℤ/ℓℤ × ℤ/ℓℤ`, тобто:

   ```
   deg_X(Φ_ℓ) = deg_Y(Φ_ℓ) = ℓ + 1
   ```

3. **Співвідношення конгруентності Кронекера:** за модулем простого числа `ℓ` модулярний многочлен розпадається:

   ```
   Φ_ℓ(X, Y) ≡ (X^ℓ - Y) · (X - Y^ℓ) mod ℓ
   ```

   Це співвідношення відображає дію ендоморфізму Фробеніуса `π: (x, y) ↦ (x^ℓ, y^ℓ)` над скінченними полями.

### Явний вигляд многочлена Φ₂(X, Y)

Для випадку `ℓ = 2` класичний модулярний многочлен має вигляд:

```
Φ₂(X, Y)
= X³ + Y³ - X²Y² + 1488·(X²Y + XY²) - 162000·(X² + Y²) + 40773375·XY + 8748000000·(X + Y) - 157464000000000
```

Для знаходження 2-ізогенних кривих до кривої з відомим інваріантом `j₀` підставляють `X = j₀` у многочлен `Φ₂(j₀, Y) = 0` та знаходять його три корені `Y ∈ {j₁, j₂, j₃}` у полі `𝔽_q` (або його квадратичному розширенні).

## 10. Алгоритм відновлення кривої за інваріантом j₀

Нехай задано довільне значення `j₀ ∈ K`. Побудуємо явне рівняння кривої `E: y² = x³ + Ax + B`, для якої `j(E) = j₀`:

1. **Якщо `j₀ ∉ {0, 1728}`:**
   Покладемо коефіцієнти:

   ```
   A = 3 · j₀ · (1728 - j₀)
   B = 2 · j₀ · (1728 - j₀)²
   ```

   Розрахуємо компоненти дискримінанта:

   ```
   4A³
   = 4 · [3 · j₀ · (1728 - j₀)]³
   = 108 · j₀³ · (1728 - j₀)³    [обчислення 4A³]
   ```

   ```
   27B²
   = 27 · [2 · j₀ · (1728 - j₀)²]²
   = 108 · j₀² · (1728 - j₀)⁴    [обчислення 27B²]
   ```

   ```
   4A³ + 27B²
   = 108 · j₀² · (1728 - j₀)³ · [j₀ + (1728 - j₀)]    [винесення спільного множника]
   = 108 · j₀² · (1728 - j₀)³ · 1728    [скорочення у дужках]
   = 186624 · j₀² · (1728 - j₀)³    [знаменник обчислено]
   ```

   Обчислимо j-інваріант побудованої кривої:

   ```
   j(E)
   = 1728 · (4A³) / (4A³ + 27B²)
   = 1728 · (108 · j₀³ · (1728 - j₀)³) / (1728 · 108 · j₀² · (1728 - j₀)³)    [підстановка формул]
   = j₀³ / j₀²    [повне скорочення дужок та констант]
   = j₀    [відновлення успішне]
   ```

2. **Якщо `j₀ = 0`:** крива `y² = x³ + 1` має `A = 0, B = 1, Δ = -432, j(E) = 0`.
3. **Якщо `j₀ = 1728`:** крива `y² = x³ + x` має `A = 1, B = 0, Δ = -64, j(E) = 1728`.

Цей детермінований алгоритм виконується за `O(1)` операцій у базовому полі `K` і гарантує побудову коректної кривої для будь-якого елемента поля.
