# 🧮 Алгебраїчні доведення класифікаційної теореми та геометрія відображення Лежандра

Класифікація еліптичних кривих над довільними полями спирається на точний опис їхніх допустимих замін координат, будову груп автоморфізмів, теорію твістів у когомологіях Галуа та інваріанти модулярних відображень. Алгебраїчний `j`-інваріант виникає як єдина раціональна комбінація коефіцієнтів форми Вейєрштрасса (нім. *Weierstrass*), яка залишається абсолютно незмінною під дією градуйованих афінних трансформацій площини й однозначно розділяє класи ізоморфізму кривих над алгебраїчно замкненим полем.

## 1. Допустимі перетворення координат та інваріанти Вейєрштрасса

Нехай еліптична крива `E` над довільним полем `K` задана загальним кубічним рівнянням Вейєрштрасса Тейта — Делінга:

```
E: y² + a₁xy + a₃y = x³ + a₂x² + a₄x + a₆
```

У проєктивних координатах `[X : Y : Z]`, де `x = X/Z` та `y = Y/Z`, крива є гладкою кубікою в `ℙ²(K)` з єдиною нескінченно віддаленою точкою `𝒪 = [0 : 1 : 0]`. Будь-який ізоморфізм між двома еліптичними кривими як абелевими многовидами є лінійним проективним перетворенням площини `ℙ²`, яке фіксує точку `𝒪` та дотичну пряму до неї `Z = 0`.

З вимоги збереження точки `𝒪` та структури кубічного рівняння випливає, що найзагальніша допустима заміна координат в афінній карті `(x, y)` задається четвіркою параметрів: ненульовим масштабним множником `u ∈ K*` та трьома параметрами зсуву `r, s, t ∈ K`:

```
x = u²x' + r
y = u³y' + su²x' + t
```

Ці параметри мають чіткий геометричний та алгебраїчний зміст:
* `u` здійснює градуйоване зважене розтягнення координат у зваженому проєктивному просторі `ℙ(2, 3, 1)`, де координата `x` має вагу 2, а координата `y` — вагу 3.
* `s` відповідає за поворот (скошування) осі `y` для усунення перехресного добутку `xy`.
* `r` здійснює паралельне перенесення осі `x` для усунення квадратичного члена `x²`.
* `t` здійснює вертикальний зсув для усунення лінійного за `y` члена `a₃y`.

### 1.1. Трансформація базових коефіцієнтів та інваріантів Тейта

Для опису геометрії кривої вводяться стандартні поліноміальні комбінації коефіцієнтів, запропоновані Джоном Тейтом (англ. *John Tate*):

```
b₂ = a₁² + 4a₂
b₄ = 2a₄ + a₁a₃
b₆ = a₃² + 4a₆
b₈ = a₁²a₆ + 4a₂a₆ - a₁a₃a₄ + a₂a₃² - a₄²
```

Між величинами `bᵢ` виконується фундаментальне алгебраїчне співвідношення:

```
4b₈ = b₂b₆ - b₄²
```

З величин `bᵢ` будуються коваріанти `c₄` (ваги 4), `c₆` (ваги 6) та модулярний дискримінант `Δ` (ваги 12):

```
c₄ = b₂² - 24b₄
c₆ = -b₂³ + 36b₂b₄ - 216b₆
Δ  = -b₂²b₈ - 8b₄³ - 27b₆² + 9b₂b₄b₆
```

Між цими трьома величинами виконується універсальна тотожність:

```
1728 · Δ = c₄³ - c₆²
```

При застосуванні допустимого перетворення координат `(x, y) ↦ (u²x' + r, u³y' + su²x' + t)` коефіцієнти рівняння трансформуються за формулами:

```
u · a₁'  = a₁ + 2s
u² · a₂' = a₂ - sa₁ + 3r - s²
u³ · a₃' = a₃ + ra₁ + 2t
u⁴ · a₄' = a₄ - sa₃ + 2ra₂ - (t + rs)a₁ + 3r² - 2st
u⁶ · a₆' = a₆ + ra₄ + r²a₂ + r³ - ta₃ - t² - rta₁
```

Простежимо точне перетворення величини `b₂'`:

```
b₂'
= (a₁')² + 4a₂'
= u⁻² · ((a₁ + 2s)² + 4(a₂ - sa₁ + 3r - s²))    [підстановка перетворених коефіцієнтів]
= u⁻² · (a₁² + 4a₁s + 4s² + 4a₂ - 4sa₁ + 12r - 4s²)    [розкриття дужок]
= u⁻² · (b₂ + 12r)    [скорочення доданків з s та виділення b₂]
```

Для коваріанта `c₄'` маємо повне алгебраїчне взаємознищення параметрів зсуву `r, s, t`:

```
c₄'
= (b₂')² - 24b₄'
= u⁻⁴ · ((b₂ + 12r)² - 24(b₄ + rb₂ + 6r²))    [підстановка b₂' та b₄']
= u⁻⁴ · (b₂² + 24rb₂ + 144r² - 24b₄ - 24rb₂ - 144r²)    [розкриття дужок]
= u⁻⁴ · (b₂² - 24b₄)    [взаємне знищення доданків з r]
= u⁻⁴ · c₄    [однорідне масштабування ваги 4]
```

Для величини `c₆'` аналогічний розрахунок дає точне масштабування шостого степеня:

```
c₆'
= u⁻⁶ · c₆    [однорідне масштабування ваги 6]
```

Для модулярного дискримінанта `Δ'` розрахунок через різницю степенів коваріантів підтверджує однорідність ваги 12:

```
Δ'
= (1 / 1728) · ((c₄')³ - (c₆')²)    [визначення через коваріанти]
= (1 / 1728) · ((u⁻⁴c₄)³ - (u⁻⁶c₆)²)    [підстановка правил масштабування]
= (1 / 1728) · (u⁻¹²c₄³ - u⁻¹²c₆²)    [винесення спільного множника u⁻¹²]
= u⁻¹² · ((c₄³ - c₆²) / 1728)    [факторизація]
= u⁻¹² · Δ    [однорідне масштабування дискримінанта ваги 12]
```

### 1.2. Виведення формули j-інваріанта через коефіцієнти короткої форми

Якщо характеристика поля `char(K) ∉ {2, 3}`, загальне рівняння зводиться до короткої форми Вейєрштрасса двома послідовними кроками:

1. **Виділення повного квадрата за `y`:**
   Множимо повне рівняння Вейєрштрасса на 4 та переносимо члени:

   ```
   4y² + 4a₁xy + 4a₃y = 4x³ + 4a₂x² + 4a₄x + 4a₆
   (2y + a₁x + a₃)² - (a₁x + a₃)² = 4x³ + 4a₂x² + 4a₄x + 4a₆
   (2y + a₁x + a₃)² = 4x³ + (a₁² + 4a₂)x² + (2a₁a₃ + 4a₄)x + (a₃² + 4a₆)
   (2y + a₁x + a₃)² = 4x³ + b₂x² + 2b₄x + b₆
   ```

   Позначивши `y₁ = 2y + a₁x + a₃`, маємо рівняння `y₁² = 4x³ + b₂x² + 2b₄x + b₆`.

2. **Виділення повного куба за `x`:**
   Поділивши на 4 (у полях характеристики, відмінної від 2), отримуємо `(y₁/2)² = x³ + (b₂/4)x² + (b₄/2)x + (b₆/4)`.
   Зсув абсциси `x = x' - b₂/12` усуває квадратичний доданок `x²`. Обчислимо коефіцієнти при степенях `x'`:

   ```
   (x' - b₂/12)³
   = (x')³ - 3(b₂/12)(x')² + 3(b₂/12)²x' - (b₂/12)³    [біном Ньютона третього степеня]
   = (x')³ - (b₂/4)(x')² + (b₂²/48)x' - b₂³/1728       [скорочення коефіцієнтів]
   ```

   Підставивши цей розклад у кубічний многочлен, отримуємо коротку форму Вейєрштрасса:

   ```
   y'² = x'³ + Ax' + B
   ```

   де коефіцієнти `A` та `B` мають точний вигляд:

   ```
   A = (b₄/2) - (b₂²/48) = -(b₂² - 24b₄) / 48 = -c₄ / 48
   B = (b₆/4) - (b₂b₄/24) + (b₂³/864) = -(-b₂³ + 36b₂b₄ - 216b₆) / 864 = -c₆ / 864
   ```

Для короткої форми Вейєрштрасса `y² = x³ + Ax + B` коваріанти Тейта набувають компактного вигляду:

```
c₄ = -48A
c₆ = -864B
```

Обчислимо модулярний дискримінант `Δ` через різницю `c₄³ - c₆²`:

```
c₄³
= (-48A)³
= -110592 · A³    [обчислення куба коваріанта c₄]
```

```
c₆²
= (-864B)²
= 746496 · B²    [обчислення квадрата коваріанта c₆]
```

```
c₄³ - c₆²
= -110592 · A³ - 746496 · B²
= -1728 · (64A³ + 432B²)    [винесення множника 1728]
= -1728 · 16 · (4A³ + 27B²)    [винесення множника 16]
```

Оскільки `Δ = (c₄³ - c₆²) / 1728`, отримуємо класичний дискримінант короткої форми:

```
Δ = -16 · (4A³ + 27B²)
```

Визначимо `j`-інваріант еліптичної кривої `E` як відношення коваріанта дванадцятого степеня `c₄³` до дискримінанта `Δ`:

```
j(E) = c₄³ / Δ
```

Підставивши вирази `c₄ = -48A` та `Δ = -16(4A³ + 27B²)`, виконуємо покрокове скорочення числових коефіцієнтів:

```
j(E)
= (-48A)³ / (-16 · (4A³ + 27B²))    [підстановка c₄ та Δ]
= (-110592 · A³) / (-16 · (4A³ + 27B²))    [піднесення до куба чисельника]
= (110592 · A³) / (16 · (4A³ + 27B²))    [скорочення знаків мінус]
= (6912 · A³) / (4A³ + 27B²)    [ділення чисельника на 16]
= (1728 · 4A³) / (4A³ + 27B²)    [виділення множника 1728 = 12³]
```

Формула `j = 1728 · 4A³ / (4A³ + 27B²)` виведена в явному вигляді. Константа `1728 = 12³ = 2⁶ · 3³` нормалізує провідний коефіцієнт розкладу Фур'є в рядах Ейзенштейна при переході до комплексної параметризації.

### 1.3. Зв'язок із коренями кубічного многочлена

Нехай `e₁, e₂, e₃ ∈ K̄` — три корені кубічного многочлена `x³ + Ax + B = 0`. За теоремою Вієта:

```
e₁ + e₂ + e₃ = 0
e₁e₂ + e₂e₃ + e₃e₁ = A
e₁e₂e₃ = -B
```

Дискримінант многочлена через різниці коренів дорівнює:

```
Δ_roots = (e₁ - e₂)² · (e₂ - e₃)² · (e₃ - e₁)² = -(4A³ + 27B²) = Δ / 16
```

Сума квадратів коренів виражається через `A`:

```
e₁² + e₂² + e₃²
= (e₁ + e₂ + e₃)² - 2(e₁e₂ + e₂e₃ + e₃e₁)    [виділення повного квадрата суми]
= 0² - 2A                                    [підстановка нульової суми коренів та виразу A]
= -2A                                        [обчислення значення]
```

Обчислимо суму квадратів різниць коренів:

```
(e₁ - e₂)² + (e₂ - e₃)² + (e₃ - e₁)²
= 2(e₁² + e₂² + e₃²) - 2(e₁e₂ + e₂e₃ + e₃e₁)    [розкриття квадратів різниць та групування]
= 2(-2A) - 2(A)                                 [підстановка суми квадратів -2A та попарних добутків A]
= -4A - 2A                                      [множення констант]
= -6A                                           [зведення подібних доданків]
```

Тоді коваріант `c₄` записується безпосередньо через взаємні відстані між коренями:

```
c₄ = -48A = 8 · (-6A) = 8 · [(e₁ - e₂)² + (e₂ - e₃)² + (e₃ - e₁)²]
```

Підставивши цей вираз у формулу `j(E) = c₄³ / Δ`:

```
j(E)
= (8 · [(e₁ - e₂)² + (e₂ - e₃)² + (e₃ - e₁)²])³ / (16 · (e₁ - e₂)²(e₂ - e₃)²(e₃ - e₁)²)
= (512 · [(e₁ - e₂)² + (e₂ - e₃)² + (e₃ - e₁)²]³) / (16 · (e₁ - e₂)²(e₂ - e₃)²(e₃ - e₁)²)
= 32 · [(e₁ - e₂)² + (e₂ - e₃)² + (e₃ - e₁)²]³ / ((e₁ - e₂)² · (e₂ - e₃)² · (e₃ - e₁)²)
```

Використовуючи тотожність `e₁² + e₂² + e₃² - e₁e₂ - e₂e₃ - e₃e₁ = -3A = c₄ / 16`, отримуємо альтернативний вираз Клейна:

```
j(E) = 256 · (e₁² + e₂² + e₃² - e₁e₂ - e₂e₃ - e₃e₁)³ / ((e₁ - e₂)² · (e₂ - e₃)² · (e₃ - e₁)²)
```

Ці формули показують, що `j`-інваріант геометрично описує конфігурацію трьох точок розгалуження на площині з точністю до спільних рухів.

## 2. Теорема класифікації над алгебраїчно замкненим полем

**Теорема.** *Нехай `K` — довільне поле, а `K̄` — його алгебраїчне замикання. Дві еліптичні криві `E₁` та `E₂`, визначені над `K`, є ізоморфними над полем `K̄` тоді й лише тоді, коли їхні j-інваріанти збігаються:*

```
E₁ ≅ E₂ над K̄   ⟺   j(E₁) = j(E₂)
```

### 2.1. Доведення необхідності (⇒)

Нехай існує ізоморфізм `φ: E₁ → E₂` над полем `K̄`. Оскільки `φ` є ізоморфізмом абелевих многовидів, він переводить нейтральний елемент `𝒪` у `𝒪`. Отже, `φ` задається допустимим перетворенням координат Вейєрштрасса:

```
x = u²x' + r
y = u³y' + su²x' + t
```

де `u ∈ K̄*` та `r, s, t ∈ K̄`.

Як доведено в розділі 1.1, коваріант `c₄` та дискримінант `Δ` трансформуються за законами:

```
c₄(E₁) = u⁻⁴ · c₄(E₂)
Δ(E₁)  = u⁻¹² · Δ(E₂)
```

Обчислимо `j`-інваріант кривої `E₁`:

```
j(E₁)
= c₄(E₁)³ / Δ(E₁)
= (u⁻⁴ · c₄(E₂))³ / (u⁻¹² · Δ(E₂))    [підстановка законів масштабування]
= (u⁻¹² · c₄(E₂)³) / (u⁻¹² · Δ(E₂))    [піднесення чисельника до куба]
= c₄(E₂)³ / Δ(E₂)    [скорочення ненульового множника u⁻¹²]
= j(E₂)    [необхідність доведена]
```

### 2.2. Доведення достатності (⇐) для char(K) ≠ 2, 3

Нехай `j(E₁) = j(E₂)`. Зведемо обидві криві до короткої форми Вейєрштрасса над полем `K`:

```
E₁: y² = x³ + A₁x + B₁
E₂: y² = x³ + A₂x + B₂
```

Для короткої форми допустимі заміни координат, що зберігають відсутність членів `xy`, `x²` та `y`, вимагають `r = s = t = 0`. Отже, будь-який ізоморфізм між короткими формами має вигляд:

```
(x, y) ↦ (u²x, u³y),  де u ∈ K̄*
```

Під дією такого перетворення коефіцієнти трансформуються як:

```
A₁ = u⁴ · A₂
B₁ = u⁶ · B₂
```

Доведемо існування такого елемента `u ∈ K̄*` у кожному з трьох можливих випадків значення `j`-інваріанта.

#### 1. Загальний випадок: j(E₁) = j(E₂) ∉ {0, 1728}

Нерівність `j ≠ 0` означає, що чисельник `1728 · 4A³ ≠ 0`, отже `A₁ ≠ 0` та `A₂ ≠ 0`.
Нерівність `j ≠ 1728` означає, що `B₁ ≠ 0` та `B₂ ≠ 0`, оскільки:

```
j - 1728
= 1728 · 4A³ / (4A³ + 27B²) - 1728 · (4A³ + 27B²) / (4A³ + 27B²)    [зведення до спільного знаменника]
= 1728 · (4A³ - 4A³ - 27B²) / (4A³ + 27B²)                          [об'єднання чисельників]
= 1728 · (-27B²) / (4A³ + 27B²)                                     [скорочення 4A³]
```

Прирівняємо вирази для `j`-інваріантів кривих `E₁` та `E₂`:

```
4A₁³ / (4A₁³ + 27B₁²) = 4A₂³ / (4A₂³ + 27B₂²)
```

Перемножуючи навхрест:

```
4A₁³ · (4A₂³ + 27B₂²)
= 4A₂³ · (4A₁³ + 27B₁²)    [перехресне множення]
16A₁³A₂³ + 108A₁³B₂²
= 16A₁³A₂³ + 108A₂³B₁²    [розкриття дужок]
108A₁³B₂²
= 108A₂³B₁²    [віднімання спільного доданка 16A₁³A₂³]
A₁³B₂²
= A₂³B₁²    [ділення на 108]
A₁³ / B₁²
= A₂³ / B₂²    [ділення на B₁²A₂³]
```

Оскільки поле `K̄` є алгебраїчно замкненим, оберемо елемент `u₀ ∈ K̄*` як довільний корінь 4-го степеня:

```
u₀ = (A₁ / A₂)^(1/4)
```

Тоді `u₀⁴ = A₁ / A₂`, звідки `A₁ = u₀⁴ · A₂`.
Підставимо це співвідношення у рівність часток:

```
(u₀⁴ · A₂)³ / B₁² = A₂³ / B₂²
u₀¹² · A₂³ / B₁² = A₂³ / B₂²
B₁² = u₀¹² · B₂² = (u₀⁶ · B₂)²
```

З рівності квадратів у полі випливає:

```
B₁ = ± u₀⁶ · B₂
```

* **Якщо `B₁ = u₀⁶ · B₂`:** обираємо `u = u₀`. Тоді `u⁴A₂ = A₁` та `u⁶B₂ = B₁`. Заміна `(x, y) ↦ (u²x, u³y)` є шуканим ізоморфізмом.
* **Якщо `B₁ = -u₀⁶ · B₂`:** оберемо `u = i · u₀`, де `i ∈ K̄` — елемент, для якого `i² = -1` (оскільки `char(K) ≠ 2`). Перевіримо коефіцієнти:

```
u⁴ = (i · u₀)⁴ = i⁴ · u₀⁴ = 1 · u₀⁴ = A₁ / A₂   ⟹   u⁴ · A₂ = A₁
u⁶ = (i · u₀)⁶ = i⁶ · u₀⁶ = (i²)³ · u₀⁶ = (-1)³ · u₀⁶ = -u₀⁶
u⁶ · B₂ = -u₀⁶ · B₂ = B₁
```

Шуканий елемент `u ∈ K̄*` побудовано в обох випадках.

#### 2. Спеціальний випадок j = 0 (A = 0, B ≠ 0)

Рівняння кривих мають вигляд `E₁: y² = x³ + B₁` та `E₂: y² = x³ + B₂`.
Оскільки дискримінанти `Δ = -432B² ≠ 0`, маємо `B₁ ≠ 0` та `B₂ ≠ 0`.

Оберемо елемент `u ∈ K̄*` як довільний корінь 6-го степеня:

```
u = (B₁ / B₂)^(1/6)
```

Перевіримо умови узгодженості коефіцієнтів:

```
u⁴ · A₂ = u⁴ · 0 = 0 = A₁
u⁶ · B₂ = (B₁ / B₂) · B₂ = B₁
```

Заміна `(x, y) ↦ (u²x, u³y)` задає коректний ізоморфізм. Існує рівно 6 різних виборів `u` (коренів із одиниці `μ₆`).

#### 3. Спеціальний випадок j = 1728 (A ≠ 0, B = 0)

Рівняння кривих мають вигляд `E₁: y² = x³ + A₁x` та `E₂: y² = x³ + A₂x`.
Оскільки дискримінанти `Δ = -64A³ ≠ 0`, маємо `A₁ ≠ 0` та `A₂ ≠ 0`.

Оберемо елемент `u ∈ K̄*` як довільний корінь 4-го степеня:

```
u = (A₁ / A₂)^(1/4)
```

Перевіримо коефіцієнти:

```
u⁴ · A₂ = (A₁ / A₂) · A₂ = A₁
u⁶ · B₂ = u⁶ · 0 = 0 = B₁
```

Заміна координат задає ізоморфізм. Існує рівно 4 різних вибори `u` (коренів із одиниці `μ₄`).

Теорему класифікації для характеристики `char(K) ∉ {2, 3}` повністю доведено.

## 3. Особливості характеристик 2 та 3

У полях малих характеристик поділ на 2 або 3 неможливий, тому класична редукція до короткої форми Вейєрштрасса не діє. Проте класифікація через `j`-інваріант залишається справедливою.

### 3.1. Характеристика char(K) = 2

У полі характеристики 2 несингулярна еліптична крива належить до одного з двох типів залежно від коефіцієнта `a₁`:

1. **Ординарні (звичайні) криві (`a₁ ≠ 0`, тобто `j ≠ 0`):**
   Заміна змінних `x ↦ a₁²x + a₃/a₁` та `y ↦ a₁³y + a₁²a₂x/a₁ + (a₄ + a₃a₂/a₁)/a₁` приводить рівняння до канонічної форми:

   ```
   y² + xy = x³ + a₂'x² + a₆'
   ```

   Для цієї форми інваріанти Тейта обчислюються як:
   `b₂ = 1`, `b₄ = 0`, `b₆ = a₆'`, `b₈ = a₆'`, `c₄ = 1`, `Δ = a₆'`.
   Значення `j`-інваріанта дорівнює:

   ```
   j(E) = c₄³ / Δ = 1 / a₆'
   ```

   Дві такі криві є ізоморфними над `K̄` тоді й лише тоді, коли їхні інваріанти `j = 1/a₆'` збігаються. Допустимі заміни між канонічними формами мають вигляд `(x, y) ↦ (x, y + sx)` де `s² + s + (a₂' - a₂'') = 0`.

2. **Надсингулярні криві (`a₁ = 0`, тобто `j = 0`):**
   Заміна `x ↦ x + a₂` приводить криву до форми:

   ```
   y² + a₃y = x³ + a₄x + a₆,  де a₃ ≠ 0
   ```

   Для цієї форми `b₂ = 0`, `b₄ = 0`, `b₆ = a₃²`, `c₄ = 0`, `Δ = a₃⁴ ≠ 0`.
   Значення `j`-інваріанта:

   ```
   j(E) = 0 / a₃⁴ = 0
   ```

   Усі надсингулярні криві в характеристиці 2 мають `j = 0` і є ізоморфними над `K̄`. Заміна `(x, y) ↦ (u²x + r, u³y + su²x + t)` з `u = a₃^(1/3)` переводить будь-яку таку криву в стандартну модель `y² + y = x³`.

### 3.2. Характеристика char(K) = 3

У характеристиці 3 підстановка `y ↦ y - (a₁x + a₃)/2 = y + a₁x + a₃` усуває член `y` з лівої частини, зводячи рівняння до `y² = x³ + a₂'x² + a₄'x + a₆'`.

1. **Ординарні криві (`a₂' ≠ 0`, тобто `j ≠ 0`):**
   Зсув `x ↦ x - a₄'/a₂'` усуває лінійний за `x` член, даючи форму:

   ```
   y² = x³ + a₂'x² + a₆'',  де a₂' ≠ 0
   ```

   Для цієї форми `b₂ = a₂'`, `b₄ = 0`, `b₆ = a₆''`, `c₄ = (a₂')²`, `Δ = -(a₂')³a₆'' ≠ 0`.
   Тоді `j`-інваріант дорівнює:

   ```
   j(E) = c₄³ / Δ = (a₂')⁶ / (-(a₂')³a₆'') = -(a₂')³ / a₆''
   ```

2. **Надсингулярні криві (`a₂' = 0`, тобто `j = 0`):**
   Зводяться до форми `y² = x³ + a₄'x + a₆'`, де `a₄' ≠ 0`. Тут `b₂ = 0`, `c₄ = 0`, `Δ = -(a₄')³ ≠ 0`, звідки:

   ```
   j(E) = 0 / -(a₄')³ = 0
   ```

   Усі надсингулярні криві в характеристиці 3 мають `j = 0` та ізоморфні над `K̄` кривій `y² = x³ + x`.

## 4. Групи автоморфізмів та когомологічна класифікація твістів

Автоморфізмами еліптичної кривої `E` над алгебраїчним замиканням `K̄` називаються ізоморфізми `φ: E → E`, які зберігають нейтральний елемент `𝒪`. Вони утворюють групу `Aut(E) = Aut_{K̄}(E)`.

Для короткої форми Вейєрштрасса `y² = x³ + Ax + B` (при `char(K) ∉ {2, 3}`) будь-який автоморфізм задається масштабуванням `(x, y) ↦ (u²x, u³y)`, де `u ∈ K̄*` задовольняє систему рівнянь:

```
u⁴ · A = A
u⁶ · B = B
```

Розв'язання цієї системи визначає структуру групи `Aut(E)`:

* **Загальний випадок (`j ∉ {0, 1728}`):**
  Оскільки `A ≠ 0` та `B ≠ 0`, маємо `u⁴ = 1` та `u⁶ = 1`. Найбільший спільний дільник степенів `НСД(4, 6) = 2`, звідки `u² = 1`, тобто `u ∈ {1, -1}`.
  Група автоморфізмів є циклічною порядку 2:

  ```
  Aut(E) = { [1], [-1] } ≅ ℤ / 2ℤ
  ```

  де `[-1](x, y) = (x, -y)` — стандартне взяття протилежного елемента на кривій.

* **Спеціальний випадок `j = 1728` (`A ≠ 0, B = 0`):**
  Рівняння `u⁶ · 0 = 0` виконується автоматично, а `u⁴ · A = A` дає `u⁴ = 1`.
  Група автоморфізмів є циклічною порядку 4:

  ```
  Aut(E) = μ₄ = { 1, i, -1, -i } ≅ ℤ / 4ℤ
  ```

  де `[i](x, y) = (-x, iy)` з `i² = -1`.

* **Спеціальний випадок `j = 0` (`A = 0, B ≠ 0`):**
  Рівняння `u⁴ · 0 = 0` виконується автоматично, а `u⁶ · B = B` дає `u⁶ = 1`.
  Група автоморфізмів є циклічною порядку 6:

  ```
  Aut(E) = μ₆ = { ζ₆^k ∣ k = 0, 1, ..., 5 } ≅ ℤ / 6ℤ
  ```

  де `ζ₆ = (1 + √-3)/2`, а генератор діє як `[ζ₆](x, y) = (ζ₆²x, ζ₆³y) = (ζ₃x, -y)`.

### 4.1. Теорія твістів та 1-когомології Галуа

Нехай `K` — незамкнене поле (наприклад, скінченне поле `𝔽_q` або поле раціональних чисел `ℚ`), а `G_K = Gal(K̄/K)` — його абсолютна група Галуа.

**Означення.** Крива `E'/K` називається **твістом** (скруткою) кривої `E/K`, якщо існує ізоморфізм `φ: E' → E` над алгебраїчним замиканням `K̄`.

Два твісти `E₁'` та `E₂'` вважаються еквівалентними, якщо вони ізоморфні над базовим полем `K`. Множина класів `K`-ізоморфізму твістів кривої `E` позначається `Twist(E/K)`.

Для будь-якого елемента групи Галуа `σ ∈ G_K` та ізоморфізму `φ: E' → E` відображення `σ(φ): E' → E` також є `K̄`-ізоморфізмом. Розглянемо композицію:

```
ξ_σ = φ ∘ σ(φ)⁻¹ ∈ Aut_{K̄}(E)
```

Відображення `ξ: G_K → Aut_{K̄}(E)`, `σ ↦ ξ_σ` задовольняє умову 1-коциклу:

```
ξ_{στ} = φ ∘ (στ)(φ)⁻¹ = φ ∘ σ(φ)⁻¹ ∘ σ(φ ∘ τ(φ)⁻¹) = ξ_σ ∘ σ(ξ_τ)
```

Заміна ізоморфізму `φ` на інший `φ' = α ∘ φ` (де `α ∈ Aut(E)`) змінює коцикл на когомологічно еквівалентний `ξ'_σ = α ∘ ξ_σ ∘ σ(α)⁻¹`. Це встановлює канонічну бієкцію:

```
Twist(E/K) ≅ H¹(Gal(K̄/K), Aut_{K̄}(E))
```

### 4.2. Явна класифікація твістів над полями характеристики ≠ 2, 3

Оскільки група `Aut(E)` є комутативною для `char(K) ∉ {2, 3}`, когомології Галуа явно обчислюються за допомогою теорії Куммера.

#### 1. Квадратичні твісти (j ∉ {0, 1728})

Група автоморфізмів `Aut(E) = {±1}` тривіально комутує з дією групи Галуа. За ізоморфізмом Куммера:

```
H¹(G_K, {±1}) ≅ K* / (K*)²
```

Для кожного елемента `d ∈ K* / (K*)²` квадратичний твіст задається рівнянням:

```
E^{(d)}: y² = x³ + d²Ax + d³B   (або dy² = x³ + Ax + B)
```

Ізоморфізм `φ_d: E^{(d)} → E` визначений над квадратичним розширенням `K(√d)` правилом:

```
φ_d(x, y) = (x / d, y / d^(3/2))   або   (x, y) ↦ (dx, d^(3/2)y)
```

Обчислимо інваріанти кривої `E^{(d)}`:

```
A(E^{(d)}) = d²A
B(E^{(d)}) = d³B
Δ(E^{(d)}) = -16 · (4(d²A)³ + 27(d³B)²) = -16 · d⁶(4A³ + 27B²) = d⁶ · Δ(E)
j(E^{(d)}) = 1728 · 4(d²A)³ / (d⁶(4A³ + 27B²)) = 1728 · 4d⁶A³ / (d⁶(4A³ + 27B²)) = j(E)
```

Над скінченним полем `𝔽_q` існує рівно два класи квадратичних твістів: сама крива `E` (для `d = 1`) та її єдиний нетривіальний квадратичний твіст (для будь-якого неквадрата `d ∈ 𝔽_q* \ (𝔽_q*)²`).
Слід ендоморфізму Фробеніуса змінює знак:

```
a_q(E^{(d)}) = (d / q) · a_q(E) = -a_q(E)
```

Тому кількість точок на квадратичному твісті дорівнює `#E^{(d)}(𝔽_q) = q + 1 + a_q(E) = 2(q + 1) - #E(𝔽_q)`.

#### 2. Квартичні (четвертинні) твісти (j = 1728)

Крива має форму `E: y² = x³ + Ax`. Якщо поле `K` містить корені з одиниці 4-го степеня (тобто `i = √-1 ∈ K`, що для `𝔽_q` еквівалентно `q ≡ 1 mod 4`), то дія Галуа на `μ₄` тривіальна, і:

```
H¹(G_K, μ₄) ≅ K* / (K*)⁴
```

Для кожного `d ∈ K* / (K*)⁴` квартичний твіст має вигляд:

```
E^{(d)}: y² = x³ + dAx
```

Ізоморфізм `φ_d: E^{(d)} → E` діє над розширенням Куммера `K(d^(1/4))` як `(x, y) ↦ (x / d^(1/2), y / d^(3/4))`.
* Якщо `d ∈ (K*)² \ (K*)⁴`, то `E^{(d)}` є квадратичним твістом.
* Якщо `d ∉ (K*)²`, то `E^{(d)}` є власним квартичним твістом порядку 4.

Над полем `𝔽_q` при `q ≡ 1 mod 4` існує рівно 4 класи ізоморфізму кривих з `j = 1728`. Якщо `q ≡ 3 mod 4` (де `i ∉ 𝔽_q`), група `H¹(G_K, μ₄) ≅ K* / (K*)²` містить лише 2 класи (квадратичні твісти).

#### 3. Секстичні (шестикратні) твісти (j = 0)

Крива має форму `E: y² = x³ + B`. Якщо `K` містить примітивний корінь `ζ₆ ∈ K` (для `𝔽_q` це `q ≡ 1 mod 6`), то:

```
H¹(G_K, μ₆) ≅ K* / (K*)⁶
```

Для кожного `d ∈ K* / (K*)⁶` секстичний твіст задається рівнянням:

```
E^{(d)}: y² = x³ + dB
```

Ізоморфізм над полем `K(d^(1/6))` задається як `(x, y) ↦ (x / d^(1/3), y / d^(1/2))`.
Множина секстичних твістів містить підродини:
* **Кубічні твісти:** `d = c² ∈ (K*)² / (K*)⁶ ≅ K* / (K*)³`, рівняння `y² = x³ + c²B` (ізоморфізм над розширенням степеня 3).
* **Квадратичні твісти:** `d = c³ ∈ (K*)³ / (K*)⁶ ≅ K* / (K*)²`, рівняння `y² = x³ + c³B`.
* **Примітивні секстичні твісти:** елементи порядку 6 у фактор-групі `K* / (K*)⁶`.

Над полем `𝔽_q` при `q ≡ 1 mod 6` існує рівно 6 класів ізоморфізму кривих з `j = 0`. При `q ≡ 5 mod 6` існує лише 2 класи.

## 5. Параметризація Лежандра, модулярна група SL₂(ℤ) та лямбда-функція

Форма Лежандра параметризує еліптичну криву над полем характеристики `char(K) ≠ 2` через положення чотирьох точок розгалуження проективної прямої `ℙ¹`, зведених проективним автоморфізмом до множини `{0, 1, ∞, λ}`:

```
E_λ: y² = x · (x - 1) · (x - λ),  де λ ∈ K̄ \ {0, 1}
```

### 5.1. Виведення формули j(λ)

Корені кубічного многочлена у формі Лежандра дорівнюють `e₁' = 0`, `e₂' = 1`, `e₃' = λ`.
Середнє арифметичне коренів дорівнює `(0 + 1 + λ) / 3 = (λ + 1) / 3`.
Зсув `x = x' + (λ + 1) / 3` центрує корені, переводячи рівняння у форму Вейєрштрасса з коренями:

```
e₁ = -(λ + 1) / 3
e₂ = 1 - (λ + 1) / 3 = (2 - λ) / 3
e₃ = λ - (λ + 1) / 3 = (2λ - 1) / 3
```

Сума коренів тотожно рівна нулю: `e₁ + e₂ + e₃ = 0`.
Обчислимо різниці між центрованими коренями:

```
e₁ - e₂ = -(λ + 1)/3 - (2 - λ)/3 = -3/3 = -1
e₂ - e₃ = (2 - λ)/3 - (2λ - 1)/3 = (3 - 3λ)/3 = 1 - λ
e₃ - e₁ = (2λ - 1)/3 - (-(λ + 1)/3) = 3λ/3 = λ
```

Обчислимо суму квадратів різниць коренів:

```
(e₁ - e₂)² + (e₂ - e₃)² + (e₃ - e₁)²
= (-1)² + (1 - λ)² + λ²    [підстановка різниць центрованих коренів]
= 1 + (1 - 2λ + λ²) + λ²   [піднесення до квадрата]
= 2 - 2λ + 2λ²             [зведення констант та доданків]
= 2 · (λ² - λ + 1)         [винесення двійки за дужки]
```

Обчислимо добуток квадратів різниць (дискримінант коренів):

```
(e₁ - e₂)² · (e₂ - e₃)² · (e₃ - e₁)²
= (-1)² · (1 - λ)² · λ²    [підстановка різниць e₁ - e₂ = -1, e₂ - e₃ = 1 - λ, e₃ - e₁ = λ]
= 1 · (λ - 1)² · λ²        [використання тотожності (1 - λ)² = (λ - 1)²]
= λ² · (λ - 1)²            [спрощення добутку]
```

Підставивши ці вирази у формулу розділу 1.3:

```
j(λ)
= 32 · [(e₁ - e₂)² + (e₂ - e₃)² + (e₃ - e₁)²]³ / ((e₁ - e₂)² · (e₂ - e₃)² · (e₃ - e₁)²)
= 32 · [2 · (λ² - λ + 1)]³ / (λ² · (λ - 1)²)    [підстановка значень]
= 32 · 8 · (λ² - λ + 1)³ / (λ² · (λ - 1)²)    [піднесення двійки до куба]
= 256 · (λ² - λ + 1)³ / (λ² · (λ - 1)²)    [перемноження 32 · 8 = 256]
```

Формулу `j(λ) = 256 · (λ² - λ + 1)³ / (λ² · (λ - 1)²)` виведено безпосередньо з геометрії коренів.

### 5.2. Дія групи перестановок S₃ та інваріантність

Подвійне відношення чотирьох точок `{0, 1, ∞, λ}` при довільних перестановках точок набуває 6 можливих значень:

```
λ,  1/λ,  1 - λ,  1/(1 - λ),  (λ - 1)/λ,  λ/(λ - 1)
```

Ці 6 значень утворюють орбіту під дією групи дробово-лінійних перетворень, ізоморфної групі перестановок `S₃ = ⟨σ, τ⟩`, де `σ(λ) = 1 - λ` та `τ(λ) = 1/λ`.

Перевіримо інваріантність функції `j(λ)` під дією генератора `τ: λ ↦ 1/λ`:

```
j(1/λ)
= 256 · ((1/λ)² - (1/λ) + 1)³ / ((1/λ)² · ((1/λ) - 1)²)    [підстановка 1/λ]
= 256 · ((1 - λ + λ²) / λ²)³ / ((1/λ²) · ((1 - λ)/λ)²)    [зведення до спільного знаменника]
= 256 · ((λ² - λ + 1)³ / λ⁶) / ((1 - λ)² / λ⁴)    [розкриття степенів знаменника]
= 256 · (λ² - λ + 1)³ / (λ² · (λ - 1)²)    [скорочення чисельника і знаменника на λ⁴]
= j(λ)    [інваріантність доведена]
```

Перевіримо дію генератора `σ: λ ↦ 1 - λ`:

```
j(1 - λ)
= 256 · ((1 - λ)² - (1 - λ) + 1)³ / ((1 - λ)² · ((1 - λ) - 1)²)    [підстановка 1 - λ]
= 256 · (1 - 2λ + λ² - 1 + λ + 1)³ / ((1 - λ)² · (-λ)²)    [розкриття дужок]
= 256 · (λ² - λ + 1)³ / (λ² · (λ - 1)²)    [спрощення чисельника та знаменника]
= j(λ)    [інваріантність доведена]
```

Оскільки `σ` та `τ` породжують усю групу `S₃`, функція `j(λ)` набуває однакового значення для всіх 6 параметрів орбіти. Відображення `λ ↦ j(λ)` є 6-листковим накриттям сфери Рімана `ℙ¹` над `j`-сферою, розгалуженим над трьома критичними значеннями:
* `j = 0` (при `λ² - λ + 1 = 0`, тобто `λ = e^{±iπ/3}`, порядок розгалуження 3).
* `j = 1728` (при `λ ∈ {-1, 1/2, 2}`, порядок розгалуження 2).
* `j = ∞` (при `λ ∈ {0, 1, ∞}`, полюси 2-го порядку).

### 5.3. Зв'язок із модулярною групою SL₂(ℤ) та комплексною лямбда-функцією

Над полем комплексних чисел `ℂ` еліптична крива ізоморфна тору `ℂ / (ℤ + ℤτ)`, де `τ ∈ ℍ = {z ∈ ℂ ∣ Im(z) > 0}`.
Модулярна група `SL₂(ℤ)` діє на верхній півплощині дробово-лінійними перетвореннями:

```
τ ↦ (aτ + b) / (cτ + d),  де a, b, c, d ∈ ℤ,  ad - bc = 1
```

Головна конгруенц-підгрупа рівня 2 визначається як:

```
Γ(2) = { M ∈ SL₂(ℤ) ∣ M ≡ [[1, 0], [0, 1]] mod 2 }
```

Фактор-група `PSL₂(ℤ) / Γ(2) ≅ S₃` ізоморфна групі перестановок трьох ненульових напівперіодів ґратки.
Модулярна лямбда-функція `λ(τ)` визначається як подвійне відношення значень еліптичної функції Вейєрштрасса на напівперіодах:

```
λ(τ) = (℘( (τ + 1)/2 ) - ℘( 1/2 )) / (℘( τ/2 ) - ℘( 1/2 ))
```

Через тета-константи Якобі `θ₂(τ), θ₃(τ), θ₄(τ)` лямбда-функція набуває вигляду:

```
λ(τ) = θ₂(τ)⁴ / θ₃(τ)⁴ = 16q^(1/2) ∏_{n=1}^∞ ((1 + qⁿ) / (1 + q^(n - 1/2)))⁸
```

де `q = exp(2πiτ)`.
Генератори повної модулярної групи `T: τ ↦ τ + 1` та `S: τ ↦ -1/τ` діють на `λ(τ)` як:

```
λ(τ + 1) = λ(τ) / (λ(τ) - 1)
λ(-1/τ)  = 1 - λ(τ)
```

Оскільки `j(λ)` інваріантна щодо цих перетворень, суперпозиція `j(τ) = j(λ(τ))` є модулярною функцією для повної групи `SL₂(ℤ)`:

```
j((aτ + b) / (cτ + d)) = j(τ)  для всіх [[a, b], [c, d]] ∈ SL₂(ℤ)
```

Обчислимо значення `j(τ)` у фундаментальних точках верхньої півплощини:
1. **Точка `τ = i` (квадратна ґратка):**
   Оскільки `S(i) = -1/i = i`, маємо `λ(i) = 1 - λ(i)`, звідки `λ(i) = 1/2`.

   ```
   j(i)
   = 256 · ((1/2)² - (1/2) + 1)³ / ((1/2)² · (1/2 - 1)²)    [підстановка значення λ(i) = 1/2]
   = 256 · (1/4 - 1/2 + 1)³ / ((1/4) · (-1/2)²)            [піднесення до степенів у дужках]
   = 256 · (3/4)³ / ((1/4) · (1/4))                        [обчислення чисельника та знаменника]
   = 256 · (27/64) / (1/16)                                [піднесення 3/4 до куба]
   = 256 · (27/64) · 16                                    [множення на обернений дріб]
   = 1728                                                  [скорочення 256 · 16 / 64 = 64, 64 · 27 = 1728]
   ```

2. **Точка `τ = ρ = exp(2πi/3) = (-1 + i√3)/2` (гексагональна ґратка):**
   Точка `ρ` задовольняє `S(T(ρ)) = ρ`, отже `λ(ρ) = exp(iπ/3) = (1 + i√3)/2`.
   Тоді `λ(ρ)² - λ(ρ) + 1 = 0`, звідки:

   ```
   j(ρ) = 256 · 0³ / (λ²(λ - 1)²) = 0
   ```

3. **Вістря (касп) `τ → i∞` (`q → 0`):**
   Оскільки `λ(τ) ≈ 16q^(1/2)`, маємо `λ² ≈ 256q`.
   Тоді провідний член ряду:

   ```
   j(τ) ≈ 256 · 1³ / (256q) = 1/q + 744 + 196884q + ...
   ```

## 6. Зв'язок із кривими Монтгомері та скрученими кривими Едвардса

У прикладній криптографії поряд із канонічною моделлю Вейєрштрасса використовуються моделі Монтгомері та Едвардса.

### 6.1. Криві Монтгомері (Montgomery Curves)

Крива Монтгомері задається рівнянням:

```
M_{A, B}: B · y² = x³ + A · x² + x,  де B · (A² - 4) ≠ 0
```

Раціональна біраціональна заміна `(x, y) ↦ (x/B + A/(3B), y/B)` переводить форму Монтгомері у форму Вейєрштрасса `y² = x³ + a₄x + a₆` з коефіцієнтами:

```
a₄ = (3 - A²) / (3B²)
a₆ = (2A³ - 9A) / (27B³)
```

Обчислимо компоненти дискримінанта:

```
4a₄³ + 27a₆²
= 4 · (3 - A²)³ / (27B⁶) + 27 · (2A³ - 9A)² / (729B⁶)    [підстановка формул a₄ та a₆]
= (108 - 108A² + 36A⁴ - 4A⁶ + 4A⁶ - 36A⁴ + 81A²) / (27B⁶)    [зведення до спільного знаменника 27B⁶]
= (108 - 27A²) / (27B⁶)    [скорочення взаємно протилежних членів]
= 27(4 - A²) / (27B⁶)    [винесення множника 27]
= (4 - A²) / B⁶    [скорочення на 27]
```

Обчислимо `j`-інваріант:

```
j(M_{A, B})
= 1728 · 4a₄³ / (4a₄³ + 27a₆²)    [визначення j-інваріанта через коефіцієнти]
= 1728 · [4(3 - A²)³ / (27B⁶)] / [(4 - A²) / B⁶]    [підстановка чисельника та знаменника]
= (1728 · 4 / 27) · (3 - A²)³ / (4 - A²)    [скорочення степеня B⁶]
= 256 · (A² - 3)³ / (A² - 4)    [обчислення коефіцієнта 1728 · 4 / 27 = 256 та зміна знака знаменника]
```

Властивості:
* Значення `j(M_{A, B})` залежить виключно від коефіцієнта `A` і не залежить від параметра `B`.
* Зміна параметра `B` породжує квадратичний твіст кривої над базовим полем.
* Для кривої `Curve25519` (`A = 486662`) значення `j` однозначно визначає її клас ізоморфізму над `𝔽_{2²⁵⁵ - 19}`.

### 6.2. Скручені криві Едвардса (Twisted Edwards Curves)

Скручена крива Едвардса задається рівнянням:

```
E_{a, d}: a · x² + y² = 1 + d · x² · y²,  де a · d · (a - d) ≠ 0
```

Кожна скручена крива Едвардса є біраціонально еквівалентною кривій Монтгомері з параметрами:

```
A = 2(a + d) / (a - d)
B = 4 / (a - d)
```

Підставивши вираз для `A` у формулу Монтгомері:

```
A² - 3
= [2(a + d) / (a - d)]² - 3    [підстановка формули параметра A]
= 4(a + d)² / (a - d)² - 3(a - d)² / (a - d)²    [зведення до спільного знаменника]
= (4a² + 8ad + 4d² - 3a² + 6ad - 3d²) / (a - d)²    [розкриття повних квадратів]
= (a² + 14ad + d²) / (a - d)²    [зведення подібних доданків]
```

```
A² - 4
= [2(a + d) / (a - d)]² - 4    [підстановка виразу A]
= 4(a + d)² / (a - d)² - 4(a - d)² / (a - d)²    [зведення до спільного знаменника]
= 4[(a + d)² - (a - d)²] / (a - d)²    [винесення четвірки за дужки]
= 4[4ad] / (a - d)²    [різниця квадратів (a+d)² - (a-d)² = 4ad]
= 16ad / (a - d)²    [перемноження 4 · 4 = 16]
```

Обчислюємо частку:

```
j(E_{a, d})
= 256 · (A² - 3)³ / (A² - 4)    [формула j-інваріанта Монтгомері]
= 256 · [(a² + 14ad + d²) / (a - d)²]³ / [16ad / (a - d)²]    [підстановка A² - 3 та A² - 4]
= 256 · (a² + 14ad + d²)³ / ((a - d)⁶ · 16ad / (a - d)²)    [піднесення до куба чисельника]
= 16 · (a² + 14ad + d²)³ / (a · d · (a - d)⁴)    [скорочення 256/16 = 16 та степеня (a - d)²]
```

Для класичних кривих Едвардса (`a = 1`, зокрема `Ed25519` з `d = -121665/121666`) формула набуває вигляду:

```
j(E_{1, d}) = 16 · (1 + 14d + d²)³ / (d · (1 - d)⁴)
```

## 7. Поліноми класів Гільберта та комплексне множення

Еліптична крива `E` над полем `ℂ` має комплексне множення (англ. *Complex Multiplication*, CM), якщо її кільце ендоморфізмів `End(E)` є строго ширшим за `ℤ`, тобто є порядком `𝒪_D` в уявному квадратичному полі `K = ℚ(√-D)` з дискримінантом `-D < 0`.

У цьому разі значення `j(E) = j(𝒪_D)` є цілим алгебраїчним числом. Мінімальний многочлен числа `j(𝒪_D)` над полем `ℚ` називається **поліномом класів Гільберта** (нім. *Hilbert-Klassenpolynom*) `H_D(X)`:

```
H_D(X) = ∏_{k=1}^{h(D)} (X - j(𝔮_k))
```

де добуток береться за всіма `h(D)` класами еквівалентності ідеалів `𝔮_k` порядку `𝒪_D`, а `h(D)` — класове число поля.

Поліном `H_D(X)` належить до кільця `ℤ[X]`. Для однокласових дискримінантів (`h(D) = 1`):
* `D = 3` (`ℚ(√-3)`): `H₃(X) = X` (корінь `j = 0`).
* `D = 4` (`ℚ(√-1)`): `H₄(X) = X - 1728` (корінь `j = 1728`).
* `D = 11` (`ℚ(√-11)`): `H₁₁(X) = X + 32768 = X + 32³`.
* `D = 19` (`ℚ(√-19)`): `H₁₉(X) = X + 884736 = X + 96³`.
* `D = 163` (`ℚ(√-163)`): `H₁₆₃(X) = X + 262537412640768000 = X + 640320³`.

Якщо просте число `p` розкладається в полі `ℚ(√-D)` як `4p = t² + D · v²` (де `t` — слід Фробеніуса), то многочлен `H_D(X)` повністю розкладається на лінійні множники над `𝔽_p`. Кожен його корінь `j₀ ∈ 𝔽_p` визначає еліптичну криву над `𝔽_p` із рівно `p + 1 - t` точками.

## 8. Диференціальні форми та алгебраїчний критерій надсингулярності

Канонічний інваріантний голоморфний диференціал на еліптичній кривій задається формулою:

```
ω = dx / (2y + a₁x + a₃)
```

При допустимому перетворенні координат `(x, y) ↦ (u²x' + r, u³y' + su²x' + t)` диференціал трансформується лінійно:

```
ω' = u · ω
```

Це перетворення підтверджує, що диференціал `ω` є 1-формою ваги 1, а тензорний добуток `ω¹²` має вагу 12, що в точності відповідає вазі дискримінанта `Δ`.

Над скінченним полем `𝔽_p` непарної характеристики крива `E: y² = f(x) = x³ + Ax + B` є надсингулярною (англ. *supersingular*) тоді й лише тоді, коли слід ендоморфізму Фробеніуса ділиться на `p`: `a_p ≡ 0 mod p`.

За критерієм Делінга — Хассе, слід Фробеніуса за модулем `p` в точності дорівнює коефіцієнту при члені `x^(p - 1)` у многочлені `f(x)^((p - 1)/2)`. Позначимо цей коефіцієнт (інваріант Гассе) через `H_p(A, B)`:

```
E є надсингулярною   ⟺   H_p(A, B) ≡ 0 mod p
```

Оскільки `H_p(A, B)` є однорідним поліномом від `A³` та `B²`, відношення його коренів визначає скінченну множину надсингулярних `j`-інваріантів у розширенні `𝔽_{p²}`. Загальна кількість надсингулярних `j`-інваріантів у характеристиці `p` дорівнює:

```
N_ss = ⌊p / 12⌋ + ε,  де ε ∈ {0, 1, 2} залежить від p mod 12
```

Усі надсингулярні `j`-інваріанти лежать у полі `𝔽_{p²}` та утворюють замкнений зв'язний `ℓ`-ізогенний граф Рамануджана.

## 9. Алгебраїчна теорія модулярних многочленів ізогеній

Ізогенією степеня `ℓ` називається ненульовий раціональний груповий гомоморфізм `φ: E₁ → E₂` зі скінченним ядром порядку `|ker(φ)| = ℓ`.

### 9.1. Модулярний многочлен Φ_ℓ(X, Y)

Класичний модулярний многочлен `Φ_ℓ(X, Y)` є незвідним поліномом із цілими коефіцієнтами `Φ_ℓ(X, Y) ∈ ℤ[X, Y]`, корені якого задають пари `j`-інваріантів кривих, пов'язаних циклічною `ℓ`-ізогенією:

```
Φ_ℓ(j(E₁), j(E₂)) = 0   ⟺   існує циклічна ℓ-ізогенія φ: E₁ → E₂
```

Фундаментальні властивості модулярного многочлена:
1. **Симетрія:** `Φ_ℓ(X, Y) = Φ_ℓ(Y, X)` для будь-якого простого `ℓ`, оскільки кожна ізогенія має двоїсту ізогенію `φ̂: E₂ → E₁` того самого степеня `ℓ`.
2. **Степінь:** степінь многочлена за кожною змінною дорівнює кількості циклічних підгруп порядку `ℓ` у групі точок кручення `E[ℓ] ≅ ℤ/ℓℤ × ℤ/ℓℤ`, тобто:

   ```
   deg_X(Φ_ℓ) = deg_Y(Φ_ℓ) = ℓ + 1
   ```

3. **Співвідношення конгруентності Кронекера:** за модулем простого числа `ℓ` модулярний многочлен розпадається:

   ```
   Φ_ℓ(X, Y) ≡ (X^ℓ - Y) · (X - Y^ℓ) mod ℓ
   ```

   Це співвідношення відображає дію ендоморфізму Фробеніуса `π: (x, y) ↦ (x^ℓ, y^ℓ)` над скінченними полями.

### 9.2. Явний вигляд многочлена Φ₂(X, Y)

Для випадку `ℓ = 2` класичний модулярний многочлен має вигляд:

```
Φ₂(X, Y)
= X³ + Y³ - X²Y² + 1488·(X²Y + XY²) - 162000·(X² + Y²) + 40773375·XY + 8748000000·(X + Y) - 157464000000000
```

Для знаходження 2-ізогенних кривих до кривої з відомим інваріантом `j₀` підставляють `X = j₀` у многочлен `Φ₂(j₀, Y) = 0` та знаходять три корені `Y ∈ {j₁, j₂, j₃}` у полі `𝔽_q` (або `𝔽_{q²}`).

## 10. Алгоритм відновлення кривої за інваріантом j₀

Нехай задано довільне значення `j₀ ∈ K`. Канонічне рівняння кривої `E: y² = x³ + Ax + B`, для якої `j(E) = j₀`, будується за явним алгоритмом:

1. **Якщо `j₀ ∉ {0, 1728}`:**
   Покладемо коефіцієнти:

   ```
   A = 3 · j₀ · (1728 - j₀)
   B = 2 · j₀ · (1728 - j₀)²
   ```

   Розрахуємо компоненти дискримінанта:

   ```
   4A³
   = 4 · [3 · j₀ · (1728 - j₀)]³
   = 108 · j₀³ · (1728 - j₀)³    [обчислення 4A³]
   ```

   ```
   27B²
   = 27 · [2 · j₀ · (1728 - j₀)²]²
   = 108 · j₀² · (1728 - j₀)⁴    [обчислення 27B²]
   ```

   ```
   4A³ + 27B²
   = 108 · j₀² · (1728 - j₀)³ · [j₀ + (1728 - j₀)]    [винесення спільного множника]
   = 108 · j₀² · (1728 - j₀)³ · 1728    [скорочення доданків у дужках]
   = 186624 · j₀² · (1728 - j₀)³    [знаменник обчислено]
   ```

   Обчислимо `j`-інваріант побудованої кривої:

   ```
   j(E)
   = 1728 · (4A³) / (4A³ + 27B²)
   = 1728 · (108 · j₀³ · (1728 - j₀)³) / (1728 · 108 · j₀² · (1728 - j₀)³)    [підстановка формул]
   = j₀³ / j₀²    [повне скорочення дужок та констант]
   = j₀    [відновлення успішне]
   ```

2. **Якщо `j₀ = 0`:** крива `y² = x³ + 1` має `A = 0, B = 1, Δ = -432, j(E) = 0`.
3. **Якщо `j₀ = 1728`:** крива `y² = x³ + x` має `A = 1, B = 0, Δ = -64, j(E) = 1728`.

Цей детермінований алгоритм виконується за `O(1)` операцій у базовому полі `K` і гарантує побудову гладкої еліптичної кривої з наперед заданим значенням `j`-інваріанта.
