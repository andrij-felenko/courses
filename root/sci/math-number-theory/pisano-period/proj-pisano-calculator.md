# ⚙️ Алгоритм обчислення періоду Пізано та Fₙ mod m

У цій вставці наведено практичну алгоритмічну реалізацію високоефективного обчислення періоду Пізано `π(m)` та знаходження `n`-го числа Фібоначчі за модулем `m` для астрономічно великих індексів `n` (аж до `10¹⁸` та більше). Подано розгортання двох принципово різних обчислювальних стратегій: прямої лінійної ітерації для малих модулів та факторизаційно-теоретичного алгоритму для великих чисел із розбором крайових випадків і захисту від переповнення цілих типів.

## Обчислювальна архітектура та постановка задачі

Задача знаходження числа Фібоначчі за модулем `F[n] mod m` виникає в багатьох галузях обчислювальної математики: від криптографічних протоколів на основі рекурентних послідовностей до аналізу довжини циклів у генераторах псевдовипадкових чисел (Linear Congruential та Lagged Fibonacci Generators).

Коли індекс `n` вимірюється значеннями порядку `10¹⁸` (що є стандартним для 64-бітних обчислень), обчислення послідовними додаваннями за час `O(n)` є неприйнятним. Алгоритмічне розв'язання складається з двох послідовних кроків:

1. **Редукція індексу за періодом Пізано:** Обчислюється період `π(m)`, після чого величезний індекс `n` замінюється його остачею `n' = n mod π(m)`. Це гарантує, що новий індекс `n'` не перевищує `6m`.
2. **Матричне бінарне піднесення до степеня:** Для зменшеного індексу `n'` обчислюється `F[n'] mod m` за допомогою піднесення фундаментальної матриці `Q` до степеня `n' - 1` за час `O(log n')`.

---

## Алгоритм 1. Швидке матричне піднесення Fₙ mod m за O(log n)

Замість ітеративного додавання `F[k] = (F[k-1] + F[k-2]) mod m`, розглянемо матричне співвідношення:

```
┌          ┐       n-1   ┌   ┐
│ F[n]     │ =  Q     ·  │ 1 │   (mod m)
│ F[n-1]   │             │ 0 │
└          ┘             └   ┘
```

де `Q = [[1, 1], [1, 0]]`.

Піднесення матриці `Q` до степеня `k = n - 1` виконується методом двоічного (бінарного) піднесення до степеня (Binary Exponentiation).

### Механізм бінарного зведення у степінь:

Представимо індекс `k` у двійковій системі числення: `k = b_r … b₁ b₀`.

Матриця `Q^k` розкладається у добуток степеней, що відповідають одиничним бітам числа `k`:

```
Q^k = ∏ (Q^(2^i))    для всіх i, де біт b_i = 1
```

На кожному кроці алгоритму поточна матриця підноситься до квадрата (`Q^(2^(i+1)) = (Q^(2^i))²`), а якщо поточний біт `b_i` дорівнює `1`, ця матриця множиться на накопичуваний результат.

Кількість множень 2x2 матриць не перевищує `2 · log₂(k)`. Для `n = 10¹⁸` це вимагає лише близько 60 матричних множень, що виконується за кілька мікросекунд.

## Алгоритм 2. Пошук періоду Пізано π(m)

Для знаходження самого періоду `π(m)` використовуються два підходи залежно від величини модуля `m`.

### Стратегія А: Пряма лінійна ітерація (для малих модулів m ≤ 10⁶)

Для малих модулів здійснюється пряме моделювання послідовності остач від стартового стану `(0, 1)` до першого повторного випадання пари `(0, 1)`.

1. Ініціалізуємо змінну попереднього члена `prev = 0` та поточного `curr = 1`.
2. На кожній ітерації `i` від `0` до `6m`:
   - Обчислюємо наступний член: `next = (prev + curr) mod m`.
   - Зсуваємо стан: `prev = curr`, `curr = next`.
   - Перевіряємо умову зациклення: якщо `prev == 0` та `curr == 1`, то довжина періоду дорівнює `i + 1`.

За доведеною нерівністю `π(m) ≤ 6m`, цикл гарантовано завершиться не пізніше ніж за `6m` кроків.

---

### Стратегія Б: Алгебраїчний розклад через факторизацію (для великих модулів m)

Для великих чисел `m` пряма ітерація стає занадто повільною. Використовується теоретико-числовий алгоритм:

1. **Факторизація модуля:** Знаходимо розклад числа `m` на прості множники:
   ```
   m = p₁^(e₁) · p₂^(e₂) · … · p_r^(e_r)
   ```
2. **Знаходження періоду для кожного простого p:**
   - Обчислюємо кандидаційну верхню межу `L`:
     - Якщо `p = 2`, `L = 3`.
     - Якщо `p = 5`, `L = 20`.
     - Якщо `p ≡ 1, 4 (mod 5)`, `L = p - 1`.
     - Якщо `p ≡ 2, 3 (mod 5)`, `L = 2(p + 1)`.
   - Шукаємо справжній мінімальний період `π(p)` серед всіх подільників числа `L`. Для кожного подільника `d | L` у порядку зростання перевіряємо умову `F[d] ≡ 0 (mod p)` та `F[d+1] ≡ 1 (mod p)` за допомогою матричного піднесення до степеня за `O(log d)`. Перший подільник, який задовольняє умову, і є `π(p)`.
3. **Піднесення до степеня простого числа:**
   ```
   π(p^e) = p^(e-1) · π(p)
   ```
4. **Об'єднання за Китайською теоремою про остачі:**
   ```
   π(m) = НСК( π(p₁^(e₁)), π(p₂^(e₂)), …, π(p_r^(e_r)) )
   ```

Складність цього підходу визначається швидкістю факторизації `m`. Для 64-бітних чисел використання алгоритму Полларда (Pollard's rho) дозволяє знайти `π(m)` за частки мілісекунди.

## Захист від переповнення цілих типів (Overflow Safety)

При виконанні матричного множення за модулем `m` обчислюються добутки вигляду `A.m[i][k] * B.m[k][j]`.

Якщо модуль `m` наближається до межі 64-бітного цілого числа (`m ≈ 2⁶³ - 1`), добуток двох чисел порядку `10¹⁸` перевищує `2⁶⁴ - 1` (досягає `10³⁶`), що викликає арифметичне переповнення стандартних типів `uint64_t`.

Для запобігання переповненню використовуються два прийоми:
1. **Використання 128-бітного розширення (`__int128_t`):** У сучасних компіляторах (GCC, Clang) тип `unsigned __int128` дозволяє виконувати множення 64-бітних чисел без втрати точності.
2. **Бітове модулярне множення (MulMod):** На платформах без підтримки 128-бітних типів добуток `(a · b) mod m` реалізується аналогом бінарного піднесення до степеня за допомогою додавання за `O(log b)` кроків.

## Аналіз складності та підсумкові рекомендації

| Операція | Часова складність | Просторова складність | Примітки |
| :--- | :--- | :--- | :--- |
| **Лінійний пошук періоду π(m)** | `O(π(m)) = O(m)` | `O(1)` | Застосовується при `m ≤ 10⁶` |
| **Матричний `F[n] mod m`** | `O(log n)` | `O(1)` | 64-бітне бінарне зведення у степінь |
| **Факторизаційний `π(m)`** | `O(√m)` або `O(m^(1/4))` | `O(1)` | Застосовується при великих `m` |

### Практичні висновки для розробника:

1. **Захист від вироджених виразок:** Завжди перевіряйте крайовий випадок `m = 1`. За модулем 1 будь-яка остача дорівнює 0, тож `π(1) = 1` за визначенням.
2. **Переповнення типів:** У C/C++ при обчисленні `A.m[i][k] * B.m[k][j]` завжди переконуйтеся, що ви простір використовуєте 128-бітний тип `unsigned __int128` або додаткову бітову функцію модулярного множення.
3. **Прискорення алгоритмів:** Якщо необхідно обчислити серію з тисяч значень `F[n_i] mod m` для одного й того самого модуля `m`, обчислити період `π(m)` потрібно лише один раз на старті, після чого кожен новий індекс зменшується за `O(1)` операцією `% π(m)`.
