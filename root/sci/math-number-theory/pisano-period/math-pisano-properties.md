# 🧮 Строгі доведення властивостей періоду Пізано

Ця вставка містить вичерпні й строгі алгебраїчні доведення фундаментальних властивостей періоду Пізано `π(m)`. Викладений матеріал охоплює структурну теоретико-групову мультиплікативність періоду за Китайською теоремою про остачі, класифікацію періодів для простих модулів за допомогою теорії розширень скінченних піль Galois та закону взаємності квадратних лишків, поведінку періоду при піднесенні простого числа до степеня, аналіз гіпотези Волла-Сунь-Суня, а також повне доведення точної верхньої межі `π(m) ≤ 6m` і детальні числові приклади з матричними орбітами та повними таблицями лишків.

---

## 1. Матричний апарат та алгебраїчна природа періоду Пізано

### Перехід до простору станів

Послідовність чисел Фібоначчі визначається лінійним рекурентним співвідношенням другого порядку:

```
F[0] = 0,    F[1] = 1,    F[n+1] = F[n] + F[n-1]   при n ≥ 1
```

Щоб дослідити поведінку цієї послідовності за довільним модулем `m`, зручно об'єднати два послідовні члени у вектор стану `v[n] = (F[n+1], F[n])ᵀ` розмірності 2×1.

Зв'язок між сусідніми векторами стану `v[n-1]` та `v[n]` описується лінійним оператором переходу, який задається фундаментальною матрицею кроку `M` розміру 2×2:

```
┌          ┐   ┌      ┐ ┌        ┐
│ F[n+1]   │ = │ 1  1 │ │ F[n]   │
│ F[n]     │   │ 1  0 │ │ F[n-1] │
└          ┘   └      ┘ └        ┘
```

де матриця переходу дорівнює `M = [[1, 1], [1, 0]]`.

---

### Математична індукція для степеня матриці Mⁿ

Доведемо за індукцією, що `n`-й степінь матриці `M` виражається безпосередньо через члени послідовності Фібоначчі:

```
       ┌               ┐
 Mⁿ =  │ F[n+1]   F[n]  │
       │ F[n]    F[n-1] │
       └               ┘
```

**База індукції (`n = 1`):**

Підставимо `n = 1` у формулу:

```
┌               ┐   ┌             ┐   ┌      ┐
│ F[2]   F[1]   │ = │ 1         1 │ = │ 1  1 │ = M¹
│ F[1]   F[0]   │   │ 1         0 │   │ 1  0 │
└               ┘   └             ┘   └      ┘
```

База індукції виконується.

**Крок індукції (`n → n + 1`):**

Припустимо, що формула правильна для деякого цілого `n ≥ 1`. Обчислимо степінь `M^(n+1) = Mⁿ · M`:

```
M^(n+1)
= ┌               ┐   ┌      ┐
  │ F[n+1]   F[n]  │ · │ 1  1 │
  │ F[n]    F[n-1] │   │ 1  0 │
  └               ┘   └      ┘
= ┌                                    ┐
  │ F[n+1]·1 + F[n]·1   F[n+1]·1 + F[n]·0 │   [множення матриць: рядок на стовпчик]
  │ F[n]·1 + F[n-1]·1   F[n]·1 + F[n-1]·0 │
  └                                    ┘
= ┌                       ┐
  │ F[n+1] + F[n]   F[n+1] │                 [спрощення арифметичних добутків]
  │ F[n] + F[n-1]   F[n]   │
  └                       ┘
= ┌                 ┐
  │ F[n+2]   F[n+1] │                        [рекурентне правило: F[k+1] = F[k] + F[k-1]]
  │ F[n+1]   F[n]   │
  └                 ┘
```

Рівність доведена для всіх натуральних чисел `n ≥ 1`. ◼

---

### Тотожність Кассіні та оборотність матриці M

Обчислимо визначник фундаментальної матриці `M`:

```
det(M) = 1 · 0 − 1 · 1 = -1
```

Оскільки визначник добутку матриць дорівнює добутку їхніх визначників, для `n`-го степеня маємо `det(Mⁿ) = (det(M))ⁿ = (-1)ⁿ`.

Обчислюючи визначник за елементами матриці `Mⁿ`, отримуємо тотожність Кассіні (J.-D. Cassini, 1680):

```
det(Mⁿ) = F[n+1] · F[n-1] − F[n]² = (-1)ⁿ
```

Перейдемо тепер до модульної арифметики за довільним цілим модулем `m ≥ 2`.

Оскільки `det(M) = -1`, а число `-1` є взаємно простим із будь-яким модулем `m` (бо `(-1) · (-1) ≡ 1 (mod m)`), визначник матриці `M` є оборотним елементом кільця остач `ℤ/mℤ`.

Це означає, що матриця `M (mod m)` є оборотним лінійним оператором і належить **загальній лінійній групі матриць другого порядку** над кільцем остач:

```
M mod m ∈ GL₂(ℤ/mℤ)
```

---

### Період Пізано як порядок матриці в групі GL₂(ℤ/mℤ)

Послідовність векторів стану `v[n] (mod m)` зациклюється на кроці `k`, коли пара остач `(F[k+1], F[k])` знову стає рівною початковій парі `(F[1], F[0]) = (1, 0)`.

У матричному вираженні це еквівалентно умові:

```
        ┌               ┐   ┌      ┐
M^k ≡   │ F[k+1]   F[k]  │ ≡ │ 1  0 │ = I   (mod m)
        │ F[k]    F[k-1] │   │ 0  1 │
        └               ┘   └      ┘
```

де `I = [[1, 0], [0, 1]]` — одинична матриця.

> **Означення:** **Період Пізано `π(m)`** — це мультиплікативний порядок матриці `M` у скінченній групі `GL₂(ℤ/mℤ)`:
> ```
> π(m) = ord_{GL₂(ℤ/mℤ)}(M)
> ```

Оскільки кільце остач `ℤ/mℤ` скінченне і містить `m` елементів, множина всіх матриць розміру 2×2 налічує `m⁴` елементів. Група `GL₂(ℤ/mℤ)` є скінченною підмножиною цієї множини.

За теоремою Лагранжа, порядок будь-якого елемента скінченної групи є скінченним і ділить порядок самої групи. Тому найменше натуральне число `k > 0`, для якого `M^k ≡ I (mod m)`, існує завжди для будь-якого `m ≥ 1`.

---

### Парність періоду Пізано для m > 2

Дослідимо парність числа `π(m)`.

Нехай `k = π(m)`. Оскільки `M^k ≡ I (mod m)`, визначники обох частин порівняння мусять бути рівними за модулем `m`:

```
det(M^k) ≡ det(I) (mod m)
(-1)^k ≡ 1 (mod m)
```

Розглянемо два випадки:
1. Якщо `m = 2`, то `-1 ≡ 1 (mod 2)`. Порівняння `(-1)^k ≡ 1 (mod 2)` виконується як для парних, так і для непарних `k`. Справді, `π(2) = 3` — це єдиний непарний період Пізано.
2. Якщо `m > 2`, то `-1 ≢ 1 (mod m)` (оскільки `1 - (-1) = 2`, а `m > 2` не ділить 2). Тому рівність `(-1)^k ≡ 1 (mod m)` можлива тоді й лише тоді, коли показник `k` є **парним числом**.

**Висновок:** Для кожного натурального модуля `m > 2` період Пізано `π(m)` обов'язково є **парним числом**. ◼

## 2. Теореми про мультиплікативність періоду Пізано

### Теорема 1A. Мультиплікативність для взаємно простих модулів

Нехай `a` та `b` — натуральні числа, для яких `НСД(a, b) = 1`. Тоді період Пізано за модулем їхнього добутку дорівнює найменшому спільному кратному періодів за кожним із модулів окремо:

```
π(a · b) = НСК( π(a), π(b) )
```

#### Доведення:

За [Китайською теоремою про остачі](root:math-number-theory/chinese-remainder-theorem), якщо `НСД(a, b) = 1`, існує канонічний кільцевий ізоморфізм:

```
ℤ/(a·b)ℤ ≅ (ℤ/aℤ) × (ℤ/bℤ)
```

Цей ізоморфізм природно поширюється на матричні кільця та індукує ізоморфізм відповідних груп матриць:

```
GL₂(ℤ/(a·b)ℤ) ≅ GL₂(ℤ/aℤ) × GL₂(ℤ/bℤ)
```

Звідси матричне порівняння за складеним модулем `a · b` рівносильне одночасному виконанню двох незалежних порівнянь у проєкціях прямого добутку:

```
M^k ≡ I (mod a · b)
⇔ (M^k ≡ I (mod a))  ∧  (M^k ≡ I (mod b))   [ізоморфізм Китайської теореми про остачі]
⇔ (π(a) | k)         ∧  (π(b) | k)          [визначення мультиплікативного порядку матриці M]
⇔ НСК( π(a), π(b) ) | k                      [властивість найменшого спільного кратного]
```

Найменшим додатним цілим числом `k`, яке задовольняє умову `НСК(π(a), π(b)) | k`, за визначенням є `k = НСК(π(a), π(b))`.

Отже, мінімальний період дорівнює `π(a · b) = НСК(π(a), π(b))`. ◼

За математичною індукцією, для довільного числа з канонічним розкладом на прості множники `m = p₁^(k₁) · p₂^(k₂) · … · p_r^(k_r)` отримуємо загальну формулу:

```
π(m) = НСК( π(p₁^(k₁)), π(p₂^(k₂)), …, π(p_r^(k_r)) )
```

---

### Теорема 1B. Узагальнена мультиплікативність для довільних чисел: π(НСК(a, b)) = НСК(π(a), π(b))

Формула мультиплікативності може бути узагальнена на довільну пару натуральних чисел `a` та `b`, навіть якщо вони **не є взаємно простими**.

**Твердження:** Для будь-яких натуральних чисел `a, b ≥ 1` виконується тотожність:

```
π( НСК(a, b) ) = НСК( π(a), π(b) )
```

#### Доведення:

Розкладемо числа `a` та `b` на спільний набір простих множників:

```
a = ∏ p_i^(e_i),     b = ∏ p_i^(f_i)
```

де `e_i, f_i ≥ 0`. Найменше спільне кратне чисел `a` та `b` розкладається як:

```
НСК(a, b) = ∏ p_i^(max(e_i, f_i))
```

Оскільки степені різних простих чисел є взаємно простими, застосуємо теорему 1A:

```
π( НСК(a, b) )
= НСК_i ( π( p_i^(max(e_i, f_i)) ) )
```

Як буде строгово доведено в розділі 4 (теорема Волла), функція `π(p^k)` є монотонно неспадною за показником `k`: для будь-якого простого `p` і `k ≥ 1` маємо `π(p^k) = p^(k-1) · π(p)` (або в загальному випадку `π(p^k) = p^(k-e) · π(p^e)`).

Тому для кожного простого множника `p_i` значення періоду за максимальним степенем збігається з максимумом періодів:

```
π( p_i^(max(e_i, f_i)) ) = max( π(p_i^(e_i)), π(p_i^(f_i)) ) = НСК( π(p_i^(e_i)), π(p_i^(f_i)) )
```

(Оскільки одне зі значень ділить інше, їхнє найменше спільне кратне дорівнює більшому з них).

Підставимо цей вираз назад у формулу:

```
π( НСК(a, b) )
= НСК_i ( НСК( π(p_i^(e_i)), π(p_i^(f_i)) ) )              [підстановка максимуму степенів]
= НСК( НСК_i( π(p_i^(e_i)) ),  НСК_i( π(p_i^(f_i)) ) )   [асоціативність і комутативність операції НСК]
= НСК( π(a), π(b) )                                       [теорема про канонічний розклад]
```

Це доводить узагальнену мультиплікативність для довільних модулів. ◼

## 3. Квадратична класифікація періоду π(p) для простих чисел

### Характеристичний многочлен і формула Біне

Для обчислення періоду за простим модулем `p` дослідимо характеристичне рівняння матриці `M`:

```
P(x) = det(x · I − M) = det([[x - 1, -1], [-1, x]]) = x · (x - 1) − (-1) · (-1) = x² − x − 1
```

Дискримінант многочлена `x² − x − 1 = 0` дорівнює:

```
D = (-1)² − 4 · 1 · (-1) = 1 + 4 = 5
```

Корені характеристичного рівняння задаються формулами:

```
φ = (1 + √5) / 2,     ψ = (1 − √5) / 2
```

За формулою Біне (J. P. M. Binet, 1843), `n`-й член послідовності Фібоначчі та `n`-й член супутньої послідовності Люка `L[n]` виражаються як:

```
F[n] = (φⁿ − ψⁿ) / √5,     L[n] = φⁿ + ψⁿ
```

де послідовність Люка починається як `L[0] = 2, L[1] = 1, L[2] = 3, L[3] = 4, L[4] = 7…` і задовольняє те саме рекурентне правило `L[n+1] = L[n] + L[n-1]`.

Поведінка коренів `φ` та `ψ` за модулем простого числа `p` фундаментально залежить від того, чи є число 5 квадратичним лишком у скінченному полі остач `𝔽[p] = ℤ/pℤ`.

---

### Закон взаємності та символ Лежандра (5 / p)

За [законом взаємності квадратних лишків](root:math-number-theory/quadratic-reciprocity) Гауса, для двох непарних простих чисел `p` та `q` зв'язок між символами Лежандра визначається формулою:

```
(q / p) · (p / q) = (-1)^((p-1)/2 · (q-1)/2)
```

Покладемо `q = 5`. Оскільки `(5 - 1) / 2 = 2` є парним числом, знак `(-1)^(2 · (p-1)/2) = 1`.

Звідси отримуємо тотожність:

```
(5 / p) = (p / 5)
```

Остачі від ділення простих чисел `p ≠ 5` на 5 можуть дорівнювати `1, 2, 3, 4`. Обчислимо квадрати ненульових остач за модулем 5:

```
1² ≡ 1 (mod 5),    2² ≡ 4 (mod 5),    3² ≡ 9 ≡ 4 (mod 5),    4² ≡ 16 ≡ 1 (mod 5)
```

Квадратичними лишками за модулем 5 є лише числа 1 та 4. Квадратичними нелишками є числа 2 та 3.

Отже:

```
(5 / p) = +1   якщо p ≡ 1 або 4 (mod 5)    (тобто p ≡ ±1 (mod 5))
(5 / p) = -1   якщо p ≡ 2 або 3 (mod 5)    (тобто p ≡ ±2 (mod 5))
```

Розглянемо кожен із цих випадків окремо.

---

### Теорема 2A. Випадок p ≡ ±1 (mod 5): π(p) ділить p − 1

**Твердження:** Якщо `p ≡ 1` або `p ≡ 4 (mod 5)`, то період Пізано `π(p)` є дільником числа `p - 1`:

```
π(p) | (p - 1)
```

#### Доведення:

1. **Існування кореня у базовому полі:** Оскільки `(5 / p) = +1`, за критерієм Ейлера число 5 має квадратний корінь у полі `𝔽[p]`. Тобто існує такий елемент `d ∈ 𝔽[p]`, що `d² ≡ 5 (mod p)`.
2. **Власні числа:** Оскільки `p > 2`, число 2 є оборотним за модулем `p` (існує `2⁻¹ ≡ (p+1)/2 (mod p)`). Тому корені `φ = (1 + d) · 2⁻¹` та `ψ = (1 − d) · 2⁻¹` є коректно визначеними ненульовими елементами поля `𝔽[p]`. Оскільки `d ≢ 0 (mod p)`, корені `φ` та `ψ` є різними: `φ ≢ ψ (mod p)`.
3. **Діагоналізація матриці:** Матриця `M` має два різні власні значення `φ` та `ψ` у полі `𝔽[p]`. Отже, матриця `M` є діагоналізовною над `𝔽[p]`:
   ```
   M = P · ┌      ┐ · P⁻¹
           │ φ  0 │
           │ 0  ψ │
           └      ┘
   ```
   де `P` — матриця, складена з відповідних власних векторів.
4. **Застосування малої теореми Ферма:** Мультиплікативна група поля `𝔽[p]*` має порядок `p - 1`. За [малою теоремою Ферма](root:math-number-theory/fermat-little-theorem), для будь-якого ненульового елемента `x ∈ 𝔽[p]*` виконується `x^(p-1) ≡ 1 (mod p)`.
   Тому:
   ```
   φ^(p-1) ≡ 1 (mod p),     ψ^(p-1) ≡ 1 (mod p)
   ```
5. **Степінь матриці:** Піднесемо матрицю `M` до степеня `p - 1`:
   ```
   M^(p-1)
   = P · ┌                  ┐ · P⁻¹   [діагональна форма матриці]
         │ φ^(p-1)    0     │
         │   0      ψ^(p-1) │
         └                  ┘
   = P · ┌      ┐ · P⁻¹               [мала теорема Ферма: φ^(p-1) ≡ ψ^(p-1) ≡ 1 (mod p)]
         │ 1  0 │
         │ 0  1 │
         └      ┘
   = P · I · P⁻¹                      [одинична матриця I]
   = I   (mod p)                      [скорочення матриць: P · I · P⁻¹ = I]
   ```
6. **Аналіз членів послідовності за формулою Біне:**
   ```
   F[p-1] = (φ^(p-1) − ψ^(p-1)) / √5 ≡ (1 − 1) / d ≡ 0 (mod p)
   ```
   Для індексу `p` скористаємося тим, що `φ^p = φ^(p-1) · φ ≡ 1 · φ = φ (mod p)` та `ψ^p ≡ ψ (mod p)`:
   ```
   F[p] = (φ^p − ψ^p) / √5 ≡ (φ − ψ) / d = d / d ≡ 1 (mod p)
   ```
   Оскільки пара остач `(F[p-1], F[p]) ≡ (0, 1) (mod p)` збігається зі стартовою парою `(F[0], F[1]) = (0, 1)`, послідовність зациклюється на кроці `p - 1`.

З властивостей порядків елементів у групі випливає, що мультиплікативний порядок `π(p) = ord(M)` обов'язково ділить показник `p - 1`:

```
π(p) | (p - 1)
```

Це доводить теорему 2A. ◼

### Теорема 2B. Випадок p ≡ ±2 (mod 5): π(p) ділить 2(p + 1)

**Твердження:** Якщо `p ≡ 2` або `p ≡ 3 (mod 5)`, то період Пізано `π(p)` є дільником числа `2(p + 1)`:

```
π(p) | 2(p + 1)
```

#### Доведення:

1. **Квадратне розширення поля:** Оскільки `(5 / p) = -1`, число 5 не є квадратом у полі `𝔽[p]`. Тому характеристичний многочлен `x² − x − 1` є незвідним над `𝔽[p]`.
   Побудуємо квадратне розширення поля:
   ```
   𝔽[p²] = 𝔽[p][√5] = { u + v√5  |  u, v ∈ 𝔽[p] }
   ```
   Поле `𝔽[p²]` містить `p²` елементів, а його мультиплікативна група `𝔽[p²]*` має порядок `p² - 1`.
2. **Автоморфізм Фробеніуса:** Розглянемо відображення Фробеніуса `σ: 𝔽[p²] → 𝔽[p²]`, визначене як `σ(x) = x^p`.
   У полі характеристики `p` біноміальні коефіцієнти `C(p, i) ≡ 0 (mod p)` для всіх `0 < i < p`, тому `(a + b)^p = a^p + b^p`.
   За малою теоремою Ферма для елементів базового поля `u, v ∈ 𝔽[p]` маємо `u^p ≡ u` та `v^p ≡ v`.
   Для елемента `√5`, застосовуючи критерій Ейлера `5^((p-1)/2) ≡ (5 / p) = -1 (mod p)`, отримуємо:
   ```
   (√5)^p = (5^((p-1)/2)) · √5 ≡ -√5 (mod p)
   ```
3. **Дія Фробеніуса на корені φ та ψ:**
   ```
   φ^p = ((1 + √5) / 2)^p ≡ (1^p + (√5)^p) / 2^p ≡ (1 − √5) / 2 = ψ (mod p)
   ψ^p = ((1 − √5) / 2)^p ≡ (1^p − (√5)^p) / 2^p ≡ (1 + √5) / 2 = φ (mod p)
   ```
   Таким чином, автоморфізм Фробеніуса міняє корені `φ` та `ψ` місцями.
4. **Піднесення до степеня p + 1:**
   Обчислимо степінь `φ^(p+1)`:
   ```
   φ^(p+1) = φ^p · φ ≡ ψ · φ (mod p)
   ```
   Добуток коренів характеристичного рівняння за теоремою Вієта дорівнює вільному члену:
   ```
   φ · ψ = ((1 + √5)/2) · ((1 − √5)/2) = (1 − 5) / 4 = -4 / 4 = -1
   ```
   Звідси отримуємо фундаментальне співвідношення:
   ```
   φ^(p+1) ≡ -1 (mod p),     ψ^(p+1) ≡ -1 (mod p)
   ```
5. **Піднесення до степеня 2(p + 1):**
   Піднесемо обидва вирази до квадрата:
   ```
   φ^(2(p+1)) = (φ^(p+1))² ≡ (-1)² = 1 (mod p)
   ψ^(2(p+1)) = (ψ^(p+1))² ≡ (-1)² = 1 (mod p)
   ```
6. **Діагоналізація в розширенні та степінь матриці:**
   У полі `𝔽[p²]` матриця `M` діагоналізується:
   ```
   M^(2(p+1))
   = P · ┌                      ┐ · P⁻¹   [діагоналізація у розширенні 𝔽[p²]]
         │ φ^(2(p+1))     0     │
         │     0      ψ^(2(p+1))│
         └                      ┘
   = P · ┌      ┐ · P⁻¹                   [піднесення до квадрата: (-1)² = 1 (mod p)]
         │ 1  0 │
         │ 0  1 │
         └      ┘
   = I   (mod p)                          [добуток P · I · P⁻¹ = I]
   ```
7. **Поведінка залишків Фібоначчі на проміжних індексах:**
   З'ясуємо, що відбувається на кроці `n = p + 1`:
   ```
   F[p+1] = (φ^(p+1) − ψ^(p+1)) / √5 ≡ (-1 − (-1)) / √5 = 0 / √5 ≡ 0 (mod p)
   ```
   На кроці `n = p`:
   ```
   F[p] = (φ^p − ψ^p) / √5 ≡ (ψ − φ) / √5 = - (φ − ψ) / √5 ≡ -1 (mod p)
   ```
   На кроці `n = p + 2`:
   ```
   F[p+2] = F[p+1] + F[p] ≡ 0 + (-1) = -1 (mod p)
   ```
   Отже, на індексі `n = p + 1` вектор стану дорівнює:
   ```
   (F[p+2], F[p+1]) ≡ (-1, 0) = - (1, 0) (mod p)
   ```
   Матриця `M^(p+1) ≡ -I (mod p)`. Це означає, що відрізок довжиною `p + 1` є **антиперіодом**: наступні `p + 1` остач є точним дзеркальним відображенням перших `p + 1` остач, але з протилежним знаком `-1`.
   Повторення двох таких антиперіодів дає `(-1) · (-1) = 1`, тобто повне зациклення:
   ```
   M^(2(p+1)) ≡ (-I)² = I (mod p)
   ```

Звідси випливає, що мінімальний період Пізано `π(p)` ділить число `2(p + 1)`:

```
π(p) | 2(p + 1)
```

Це повністю доводить теорему 2B. ◼

### Теорема 2C. Вироджений випадок p = 5: Жорданова форма та π(5) = 20

Розглянемо випадок `p = 5`, коли дискримінант `D = 5 ≡ 0 (mod 5)`.

#### Доведення:

Характеристичний многочлен набуває вигляду:

```
x² − x − 1 ≡ x² − 6x + 9 = (x − 3)² (mod 5)
```

Многочлен має кратний корінь `λ = 3` кратності 2 у полі `𝔽[5]`.

Перевіримо, чи є матриця `M` діагоналізовною. Якби вона була діагоналізовною, вона була б подібною до скалярної матриці `3I`, тобто сама була б рівною `3I`, але:

```
M − 3I = ┌      ┐ − ┌      ┐ = ┌        ┐ ≡ ┌      ┐ ≢ 0 (mod 5)
         │ 1  1 │   │ 3  0 │   │ -2   1 │   │ 3  1 │
         │ 1  0 │   │ 0  3 │   │  1  -3 │   │ 1  2 │
         └      ┘   └      ┘   └        ┘   └      ┘
```

Оскільки матриця не діагоналізується, вона приводиться до **жорданової клітини** розміру 2×2:

```
J = ┌      ┐ = 3 · I + N
    │ 3  1 │
    │ 0  3 │
    └      ┘
```

де `N = [[0, 1], [0, 0]]` — нільпотентна матриця індексу 2 (тобто `N² = 0`).

Піднесемо жорданову форму `J` до степеня `k` за біномом Ньютона:

```
J^k = (3I + N)^k = 3^k · I + k · 3^(k-1) · N   [оскільки N² = N³ = … = 0]
```

Для того щоб `J^k ≡ I (mod 5)`, необхідно й достатньо виконання двох умов одночасно:
1. Діагональна частина: `3^k ≡ 1 (mod 5)`.
   Мультиплікативний порядок числа 3 у групі `𝔽[5]* = {1, 2, 3, 4}`:
   `3¹ ≡ 3`, `3² ≡ 4`, `3³ ≡ 2`, `3⁴ ≡ 1 (mod 5)`.
   Отже, `ord₅(3) = 4`, тому `4 | k`.
2. Позадіагональна (нільпотентна) частина: `k · 3^(k-1) ≡ 0 (mod 5)`.
   Оскільки `3^(k-1) ≢ 0 (mod 5)`, ця умова рівносильна `5 | k`.

Найменшим додатним числом `k`, яке ділиться одночасно на 4 та на 5, є їхнє найменше спільне кратне:

```
π(5) = НСК(4, 5) = 20
```

Таким чином, період за модулем 5 дорівнює точно `π(5) = 20`. ◼

## 4. Періоди за степенями простих чисел та гіпотеза Волла-Сунь-Суня

### Теорема Волла (1960)

Як поводиться період Пізано при піднесенні простого числа `p` до степеня `k`? Фундаментальний результат отримав Дональд Волл (D. D. Wall, 1960).

**Теорема 3:** Якщо `p` — просте число, і `e` — найменший натуральний показник степеня, для якого `π(p^e) > π(p)`, то для всіх цілих `k ≥ e` виконується рівність:

```
π(p^k) = p^(k-e) · π(p^e)
```

Зокрема, якщо `π(p²) ≠ π(p)` (тобто `e = 2`), то для всіх `k ≥ 1` виконується точна формула:

```
π(p^k) = p^(k-1) · π(p)
```

---

### Алгебраїчне виведення через лему Гензеля та біноміальний розклад

Нехай `T = π(p)` — період матриці `M` за простим модулем `p`. За визначенням періоду:

```
M^T ≡ I (mod p)
```

Це означає, що матриця `M^T` може бути подана у вигляді:

```
M^T = I + p · K
```

де `K` — деяка цілочисельна матриця розміру 2×2.

Піднесемо обидві частини до `p`-го степеня:

```
M^(p · T) = (M^T)^p = (I + p · K)^p
```

Застосуємо біном Ньютона для комутуючих матриць `I` та `p·K`:

```
(I + p · K)^p
= I + C(p, 1) · p · K + C(p, 2) · p² · K² + … + p^p · K^p   [біном Ньютона для комутуючих матриць]
= I + p² · K + (p · (p - 1) / 2) · p² · K² + O(p³)          [підстановка біноміальних коефіцієнтів]
```

Оскільки для будь-якого простого `p ≥ 3` дріб `p · (p - 1) / 2` є цілим числом, що ділиться на `p` (якщо розглядається доданок `p³`), за модулем `p²` отримуємо:

```
M^(p · T) ≡ I + p² · K ≡ I (mod p²)
```

Розглянемо тепер довільний проміжний показник `1 ≤ j < p`. Піднесення до степеня `j` дає:

```
M^(j · T) = (I + p · K)^j ≡ I + j · p · K (mod p²)
```

Якщо матриця `K ≢ 0 (mod p)`, то для будь-якого `1 ≤ j < p` маємо `j · p · K ≢ 0 (mod p²)`, оскільки `НСД(j, p) = 1`.

Це означає, що:
1. Матриця `M^(j · T) ≢ I (mod p²)` для всіх `1 ≤ j < p`.
2. Матриця `M^(p · T) ≡ I (mod p²)`.

Отже, мультиплікативний порядок матриці `M` у групі `GL₂(ℤ/p²ℤ)` дорівнює в точності `p · T = p · π(p)`.

За індукцією для довільного степеня `k ≥ 1`:

```
M^(p^(k-1) · T) = I + p^k · K + O(p^(k+1))
```

Звідси отримуємо канонічну формулу:

```
π(p^k) = p^(k-1) · π(p)
```

за умови, що `K ≢ 0 (mod p)`. ◼

---

### Гіпотеза Волла-Сунь-Суня та зв'язок із Великою теоремою Ферма

Умова `K ≡ 0 (mod p)` означає, що `M^(π(p)) ≡ I (mod p²)`, тобто період за модулем `p²` збігається з періодом за модулем `p`:

```
π(p²) = π(p)
```

> **Означення:** Просте число `p`, для якого виконується рівність `π(p²) = π(p)`, називається **простим числом Волла-Сунь-Суня** (Wall-Sun-Sun prime, або простим числом Волла).

У 1960 році Дональд Волл висловив гіпотезу, що таких простих чисел **не існує взагалі**.

У 1992 році китайські математики-близнюки Чжі-Хун Сунь та Чжі-Вей Сунь (Zhi-Hong Sun, Zhi-Wei Sun) встановили глибокий зв'язок між цими числами та класичною проблемою теорії чисел — **Великою теоремою Ферма**.

**Теорема Суня-Суня (1992):** Якщо перший випадок Великої теореми Ферма (рівність `x^p + y^p = z^p` при `p ∤ x·y·z`) не виконується для простого показника `p`, то `p` зобов'язане бути числом Волла-Сунь-Суня і задовольняти порівняння:

```
F[p − (5 / p)] ≡ 0 (mod p²)
```

де `(5 / p)` — символ Лежандра.

Хоча Велика теорема Ферма була повністю доведена Ендрю Вайлсом у 1995 році за допомогою модулярних еліптичних кривих, питання про існування чисел Волла-Сунь-Суня залишається однією з найвідоміших відкритих проблем обчислювальної теорії чисел.

#### Сучасний стан пошуку:
- Р. Макінтош та Г. Реттгер (McIntosh & Roettger, 2007) перевірили всі прості числа до `2 · 10¹⁴`.
- Проєкт розподілених обчислень PrimeGrid та дослідження Доре й Клайва (Dorais & Klyve, 2010) розширили межу пошуку до `p > 3 · 10¹⁷`.
- Станом на сьогодні **не знайдено жодного простого числа Волла-Сунь-Суня**.

#### Евристична ймовірність:
Для випадкового простого числа `p` остача `(F[π(p)] / p) mod p` поводиться як рівномірно розподілена випадкова величина на множині `{0, 1, …, p - 1}`.
Ймовірність того, що ця величина дорівнює нулю (тобто `p² | F[π(p)]`), становить `1 / p`.
Сума ймовірностей для всіх простих чисел до межі `X` оцінюється за теоремою Мертенса:

```
∑_{p ≤ X} (1 / p) ≈ ln(ln(X)) + M
```

де `M ≈ 0.261497` — константа Майсселя-Мертенса.

Для перевіреної межі `X = 10¹⁸` маємо `ln(ln(10¹⁸)) ≈ ln(41.45) ≈ 3.72`. Очікувана кількість чисел Волла-Сунь-Суня в усьому діапазоні до `10¹⁸` становить лише близько 4 чисел, що пояснює, чому вони досі не зустрілися в експериментах.

## 5. Доведення точної верхньої межі π(m) ≤ 6m

### Формулювання теореми

Для будь-якого натурального числа `m ≥ 1` період Пізано задовольняє точну нерівність:

```
π(m) ≤ 6m
```

Рівність `π(m) = 6m` досягається тоді й лише тоді, коли `m` має вигляд `m = 2 · 5^k` при `k ≥ 1` (тобто для модулів `10, 50, 250, 1250, 6250…`).

---

### Повне математичне виведення

Дослідимо відношення `R(m) = π(m) / m` для всіх класів натуральних чисел.

#### 1. Прості числа p:
- Для `p = 2`: `π(2) = 3`, тому `R(2) = 3 / 2 = 1.5 < 6`.
- Для `p = 5`: `π(5) = 20`, тому `R(5) = 20 / 5 = 4 < 6`.
- Для `p ≡ ±1 (mod 5)`: за теоремою 2A, `π(p) ≤ p - 1 < p`, отже `R(p) = π(p) / p < 1 < 6`.
- Для `p ≡ ±2 (mod 5)`: за теоремою 2B, `π(p) ≤ 2(p + 1)`.
  - Для найменшого такого простого `p = 3`: `π(3) = 8`, `R(3) = 8 / 3 = 2.666… < 6`.
  - Для `p = 7`: `π(7) = 16`, `R(7) = 16 / 7 ≈ 2.285 < 6`.
  - Для довільного `p ≥ 7`: `R(p) ≤ 2(p + 1) / p = 2 + 2/p ≤ 2 + 2/7 = 16/7 < 2.3 < 6`.

#### 2. Степені простих чисел p^k:
За теоремою Волла (розділ 4), для всіх відомих простих чисел `π(p^k) = p^(k-1) · π(p)`. Обчислимо відношення:

```
R(p^k) = π(p^k) / p^k = (p^(k-1) · π(p)) / p^k = π(p) / p = R(p)
```

Отже, піднесення до степеня не збільшує відношення `R(p^k)`.

#### 3. Складені числа m:
Нехай `m = a · b` при `НСД(a, b) = 1`. За теоремою про мультиплікативність:

```
R(a · b) = π(a · b) / (a · b) = НСК( π(a), π(b) ) / (a · b)
```

Оскільки `НСК(x, y) = (x · y) / НСД(x, y) ≤ x · y`, маємо:

```
R(a · b) = (π(a) · π(b)) / (НСД(π(a), π(b)) · a · b) = (R(a) · R(b)) / НСД( π(a), π(b) )
```

Відношення `R(m)` максимізується, коли:
1. Множники `a` та `b` мають максимально можливі індивідуальні коефіцієнти `R(a)` та `R(b)`.
2. Їхні періоди є взаємно простими: `НСД(π(a), π(b)) = 1`, завдяки чому найменше спільне кратне досягає точного добутку.

Найбільші індивідуальні коефіцієнти серед простих чисел мають `p = 5` (`R(5) = 4`) та `p = 2` (`R(2) = 1.5`).

Обчислимо період для їхнього добутку `m = 10 = 2 · 5`:

```
π(10) = НСК( π(2), π(5) ) = НСК(3, 20)
```

Оскільки `НСД(3, 20) = 1`, отримуємо:

```
π(10) = 3 · 20 = 60
R(10) = 60 / 10 = 6
```

Для будь-якого модуля вигляду `m = 2 · 5^k`:

```
π(2 · 5^k)
= НСК( π(2), π(5^k) )
= НСК( 3, 20 · 5^(k-1) )
= 3 · 20 · 5^(k-1)            [оскільки НСД(3, 20 · 5^(k-1)) = 1]
= 60 · 5^(k-1)
= 6 · (2 · 5^k)
= 6m
```

Чи може інший простий множник збільшити це відношення?
Для будь-якого простого `p > 2` період `π(p)` є **парним числом** (розділ 1).
Якщо складене число `m` містить бодай ще один непарний простий множник `p ≥ 3`, то `π(p)` ділиться на 2. Оскільки `π(5^k) = 20 · 5^(k-1)` ділиться на 4, спільний дільник періодів задовольняє `НСД(π(p), π(5^k)) ≥ 2`.

Через це у формулі `R(m)` з'являється додатковий дільник у знаменнику:

```
R(2 · 5^k · p) = (R(2 · 5^k) · R(p)) / НСД( π(2 · 5^k), π(p) ) ≤ (6 · 2.666…) / 2 = 8 / 2 = 4 < 6   (при p = 3)
```

а для більших простих `p ≥ 7` відношення стає ще меншим: `(6 · 2.285) / 2 ≈ 6.85 / 2 = 3.42 < 6`.

Отже, максимальне значення відношення `π(m) / m` дорівнює в точності 6 і досягається виключно на числах виду `m = 2 · 5^k`. Нерівність `π(m) ≤ 6m` доведена повністю. ◼

## 6. Числові приклади розрахунку, матричні орбіти та таблиці лишків

### Приклад 1. Модуль p = 3 (Квадратичний нелишок, p ≡ 3 mod 5)

Для `p = 3` маємо `(5 / 3) = (3 / 5) = -1`.
За теоремою 2B, період ділить `2(p + 1) = 2(3 + 1) = 8`.

#### Повна таблиця остач чисел Фібоначчі за модулем 3:

| `n` | `F[n]` | `F[n] mod 3` | Пояснення кроку |
|---|---|---|---|
| 0 | 0 | **0** | Початковий стан `F[0]` |
| 1 | 1 | **1** | Початковий стан `F[1]` (стартова пара `(0, 1)`) |
| 2 | 1 | 1 | `(0 + 1) mod 3 = 1` |
| 3 | 2 | 2 | `(1 + 1) mod 3 = 2` |
| 4 | 3 | **0** | `(1 + 2) mod 3 = 0` (точка входження `α(3) = 4`) |
| 5 | 5 | 2 | `(2 + 0) mod 3 = 2` (антиперіод: пара `(0, 2) ≡ -(0, 1)`) |
| 6 | 8 | 2 | `(0 + 2) mod 3 = 2` |
| 7 | 13 | 1 | `(2 + 2) mod 3 = 1` |
| 8 | 21 | **0** | `(2 + 1) mod 3 = 0` (повернення: пара `(0, 1)`) |
| 9 | 34 | **1** | Початок нового періоду |

#### Орбіта степенів матриці M mod 3:

```
M¹ = ┌      ┐
     │ 1  1 │ (mod 3)
     │ 1  0 │
     └      ┘

M² = M¹ · M = ┌      ┐ ┌      ┐ = ┌      ┐
              │ 1  1 │ │ 1  1 │   │ 2  1 │ (mod 3)
              │ 1  0 │ │ 1  0 │   │ 1  1 │
              └      ┘ └      ┘   └      ┘

M³ = M² · M = ┌      ┐ ┌      ┐ = ┌      ┐
              │ 2  1 │ │ 1  1 │   │ 0  2 │ (mod 3)
              │ 1  1 │ │ 1  0 │   │ 2  1 │
              └      ┘ └      ┘   └      ┘

M⁴ = M³ · M = ┌      ┐ ┌      ┐ = ┌      ┐
              │ 0  2 │ │ 1  1 │   │ 2  0 │ ≡ -I (mod 3)   [антиперіод на кроці n = p+1 = 4]
              │ 2  1 │ │ 1  0 │   │ 0  2 │
              └      ┘ └      ┘   └      ┘

M⁸ = (M⁴)²  = (-I)² ≡ I = ┌      ┐ (mod 3)                [повний період π(3) = 8]
                          │ 1  0 │
                          │ 0  1 │
                          └      ┘
```

Період дорівнює `π(3) = 8`.

### Приклад 2. Модуль p = 11 (Квадратичний лишок, p ≡ 1 mod 5)

Для `p = 11` маємо `(5 / 11) = (11 / 5) = (1 / 5) = +1`.
За теоремою 2A, період ділить `p - 1 = 11 - 1 = 10`.

Знайдемо власні числа в полі `𝔽[11]`:

```
x² − x − 1 ≡ 0 (mod 11)
(2x − 1)² ≡ 5 ≡ 16 (mod 11)
2x − 1 ≡ ±4 (mod 11)
```

Звідси:
- `2x ≡ 5 (mod 11) ⇒ x ≡ 8 (mod 11)` (оскільки `2 · 8 = 16 ≡ 5`). Позначимо `φ ≡ 8 (mod 11)`.
- `2x ≡ -3 ≡ 8 (mod 11) ⇒ x ≡ 4 (mod 11)`. Позначимо `ψ ≡ 4 (mod 11)`.

Перевіримо порядки елементів у групі `𝔽[11]*`:
- Для `φ = 8`:
  ```
  8¹ ≡ 8,    8² ≡ 9,    8³ ≡ 6,    8⁴ ≡ 4,    8⁵ ≡ 10 ≡ -1,    8¹⁰ ≡ 1 (mod 11)
  ```
  Порядок `ord₁₁(8) = 10`.
- Для `ψ = 4`:
  ```
  4¹ ≡ 4,    4² ≡ 5,    4³ ≡ 9,    4⁴ ≡ 3,    4⁵ ≡ 1 (mod 11)
  ```
  Порядок `ord₁₁(4) = 5`.

Період матриці `M` дорівнює найменшому спільному кратному порядків її власних чисел:

```
π(11) = НСК( ord₁₁(8), ord₁₁(4) ) = НСК(10, 5) = 10
```

| 3 | 2 | 2 | `(6 − 9) · 3 ≡ -3 · 3 = -9 ≡ 2` |
| 4 | 3 | 3 | `(4 − 3) · 3 ≡ 1 · 3 ≡ 3` |
| 5 | 5 | 5 | `(10 − 1) · 3 ≡ 9 · 3 = 27 ≡ 5` |
| 6 | 8 | 8 | `(3 − 4) · 3 ≡ -1 · 3 = -3 ≡ 8` |
| 7 | 13 | 2 | `(2 − 5) · 3 ≡ -3 · 3 ≡ 2` |

Період дорівнює `π(11) = 10 = p - 1`.

### Приклад 3. Складений модуль m = 12 = 2² · 3

Розкладемо модуль на взаємно прості множники: `12 = 4 · 3`, де `НСД(4, 3) = 1`.

1. **Для модуля 4:**
   Послідовність остач: `0, 1, 1, 2, 3, 1 | 0, 1…` має період `π(4) = 6`.
   Матриця: `M⁶ ≡ I (mod 4)`.
2. **Для модуля 3:**
   Період дорівнює `π(3) = 8`.
   Матриця: `M⁸ ≡ I (mod 3)`.
3. **Об'єднання за теоремою мультиплікативності:**
   ```
   π(12) = НСК( π(4), π(3) ) = НСК(6, 8)
   ```
   Обчислимо через НСД:
   ```
   НСК(6, 8) = (6 · 8) / НСД(6, 8) = 48 / 2 = 24
   ```

#### Матрична перевірка:
Піднесемо матрицю до степеня 24:
- За модулем 4: `M²⁴ = (M⁶)⁴ ≡ I⁴ = I (mod 4)`.
- За модулем 3: `M²⁴ = (M⁸)³ ≡ I³ = I (mod 3)`.

За Китайською теоремою про остачі, `M²⁴ ≡ I (mod 12)`.
Перевіримо півперіод `k = 12`:
- `M¹² = (M⁶)² ≡ I (mod 4)`.
- `M¹² = M⁸ · M⁴ ≡ I · (-I) = -I ≡ 2 · I ≢ I (mod 3)`.

Оскільки `M¹² ≢ I (mod 3)`, меншого періоду не існує. Період дорівнює `π(12) = 24`.

### Приклад 4. Складений модуль m = 10 = 2 · 5 (Останні десяткові цифри)

Модуль `10 = 2 · 5` складається з взаємно простих множників `НСД(2, 5) = 1`.

1. Для `p = 2`: остачі `0, 1, 1 | 0, 1…` дають `π(2) = 3`.
2. Для `p = 5`: за теоремою 2C, `π(5) = 20`.
3. За теоремою про мультиплікативність:
   ```
   π(10) = НСК( π(2), π(5) ) = НСК(3, 20) = (3 · 20) / НСД(3, 20) = 60 / 1 = 60
   ```

Період повторення останніх десяткових цифр чисел Фібоначчі дорівнює в точності 60. На цьому модулі досягається точна верхня межа відношення `π(10) / 10 = 60 / 10 = 6`. ◼
