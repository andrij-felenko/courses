# [Розподіл простих чисел](topic:math-number-theory/prime-distribution) та дзета-функція Рімана

[Розподіл простих чисел](topic:math-number-theory/prime-distribution) на числовій осі завжди був однією з найбільших таємниць математики. На перший погляд здається, що прості числа з'являються абсолютно випадково і не підкоряються жодному закону. Проте, якщо подивитися на картину глобально, вимальовується вражаюча закономірність.

Ключовим інструментом для дослідження цієї закономірності є функція π(x), яка рахує кількість простих чисел, що не перевищують задане число x. Наприклад, якщо x = 10, то π(10) = 4, оскільки існують чотири прості числа (2, 3, 5, 7), які менші або дорівнюють 10. Із зростанням x прості числа стають все більш рідкісними.

Ще в кінці 18 століття Карл Фрідріх Гаус та Адрієн-Марі Лежандр незалежно один від одного помітили, що щільність простих чисел поблизу числа x обернено пропорційна натуральному логарифму x, тобто ln(x). Це означає, що функція π(x) з високою точністю наближається до значення x / ln(x). Це твердження отримало назву Теореми про [Розподіл простих чисел](topic:math-number-theory/prime-distribution) (Prime Number Theorem). Вона записується так:
π(x) ~ x / ln(x)

Цей закон показує, що хоча ми не можемо точно передбачити, яким буде наступне просте число, ми можемо дуже точно оцінити їх кількість у великих діапазонах. Однак математикам цього було мало, вони прагнули ще точнішої формули. Інтегральний логарифм Li(x) дає значно краще наближення для π(x), ніж просте відношення x / ln(x).

Справжній прорив у розумінні розподілу простих чисел зробив німецький математик Бернгард Ріман у 1859 році. Він розширив ідеї Леонарда Ейлера, який знайшов зв'язок між простими числами та спеціальною математичною функцією, що сумує обернені ступені натуральних чисел. Ріман розглянув цю функцію для комплексних чисел, і сьогодні вона відома як дзета-функція Рімана, ζ(s).

Дзета-функція Рімана визначається як сума нескінченного ряду:
ζ(s) = 1/1^s + 1/2^s + 1/3^s + 1/4^s + ...

Ейлер показав, що цю ж саму суму можна записати як нескінченний добуток, що включає лише прості числа:
ζ(s) = 1 / ( (1 - 1/2^s) * (1 - 1/3^s) * (1 - 1/5^s) * ... )

Цей запис є математичним мостом між неперервним світом аналізу та дискретним світом простих чисел. Ріман показав, що [Розподіл простих чисел](topic:math-number-theory/prime-distribution) тісно пов'язаний з "нулями" цієї функції — такими значеннями s, для яких ζ(s) = 0. Він висунув гіпотезу про розташування цих нулів на комплексній площині, яка стала відомою як Гіпотеза Рімана. Вона стверджує, що всі нетривіальні нулі дзета-функції лежать на одній "критичній прямій".

Якщо Гіпотеза Рімана виявиться правильною, це означатиме, що [Розподіл простих чисел](topic:math-number-theory/prime-distribution) є настільки рівномірним, наскільки це взагалі можливо, і відхилення π(x) від Li(x) є мінімальним. Доведення цієї гіпотези є однією з семи "Проблем тисячоліття", за вирішення якої призначено нагороду в 1 мільйон доларів, і вона залишається найбільшою невирішеною проблемою сучасної математики.
