# Сегментоване решето Ератосфена (C++17)

Стандартне решето Ератосфена чудово підходить для знаходження всіх простих чисел до значення N, якщо N порівняно невелике. Проте, коли N досягає значень порядку 10⁹ або більше, класичний підхід стикається з серйозною проблемою: він вимагає масиву розміром O(N) для зберігання станів чисел, що може призвести до вичерпання доступної оперативної пам'яті. Щоб вирішити цю проблему, застосовується техніка під назвою "Сегментоване решето". Вона дозволяє зменшити споживання пам'яті до O(√N), поділяючи весь діапазон на менші сегменти.

## 1. Ідея алгоритму

Ключова ідея сегментованого решета полягає в тому, що для того, щоб перевірити, чи є число X простим (де X ≤ N), достатньо перевірити його подільність лише на прості числа, що не перевищують √N. Тому спочатку ми знаходимо всі базові прості числа до √N за допомогою звичайного решета Ератосфена. Після цього ми розбиваємо діапазон [1, N] на невеликі відрізки (сегменти) і просіюємо кожен сегмент окремо, використовуючи вже знайдені базові прості числа.

## 4. Оптимізація пам'яті

Як бачимо, розмір масиву `mark` у циклі `while` ніколи не перевищує розміру одного сегмента (приблизно √N). Замість того, щоб виділяти пам'ять розміром N, що дорівнювало б гігабайтам для великих значень, ми використовуємо лише кілька кілобайт пам'яті за раз. Це дозволяє обробляти дуже великі діапазони, не виходячи за межі кешу L1, що також значно прискорює час виконання.

## 5. Запуск програми

Щоб запустити цей код, достатньо викликати функцію `segmentedSieve` із потрібним значенням N у функції `main`.

```cpp
int main() {
    int N = 100000;
    cout << "Прості числа до " << N << " :\n";
    segmentedSieve(N);
    return 0;
}
```

Цей алгоритм є стандартом де-факто для генерації великих послідовностей простих чисел у спортивному програмуванні та криптографічних застосуваннях, де потрібна висока продуктивність та економне використання пам'яті.
