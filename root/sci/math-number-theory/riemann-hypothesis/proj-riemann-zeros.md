# ⚙️ Обчислення нулів Дзета-функції на критичній лінії

Чисельний пошук нетривіальних нулів Дзета-функції на критичній лінії `s = 1/2 + i·t` є важливою задачею обчислювальної теорії чисел. Практичне обчислення дозволяє перевіряти Гіпотезу Рімана для конкретних діапазонів `t`, досліджувати статистичні інтервали між нулями, перевіряти кореляційні закони Монтгомері–Одлижка та моделювати хвильові поправки у явній формулі.

## Задача та обчислювальні виклики

Функція `ζ(s)` на критичній лінії `s = 1/2 + i·t` є комплекснозначною функцією:

```
ζ(1/2 + i·t) = U(t) + i·V(t)
```

де `U(t) = Re(ζ(1/2 + i·t))` та `V(t) = Im(ζ(1/2 + i·t))` — дійсна та уявна частини відповідно.

Шукати нулі комплексної функції двох змінних `(σ, t)` за допомогою двовимірних градієнтних методів чи комплексного пошуку Ньютона неефективно. Комплексний оптимізаційний пошук не дає гарантій, що знайдений нуль лежить строго на лінії `σ = 1/2`, і може легко застрягати у локальних мінімумах модуля `|ζ(s)|`.

## Ідея: Функція Харді Z(t) та фаза Зігеля θ(t)

Британський математик Ґодфрі Гарольд Гарді розв'язав цю проблему, ввівши спеціальну дійснозначну функцію `Z(t)` (функцію Харді). Вона отримується шляхом повороту значення `ζ(1/2 + i·t)` на фазовий кут `θ(t)` (фазу Рімана–Зігеля):

```
Z(t) = eⁱᵐθ⁽ᵗ⁾ · ζ(1/2 + i·t)
```

Фазовий кут `θ(t)` обирається так, щоб усунути уявну частину виразу, роблячи `Z(t)` строго ДІЙСНИМ числом для будь-якого дійсного `t ∈ ℝ`:

```
θ(t) = arg(Γ(1/4 + i·t/2)) - (t/2) · ln(π)
```

Для практичних розрахунків фазовий кут `θ(t)` з високою точністю наближається асимптотичною формулою Рімана–Зігеля через розклад Стирлінга:

```
θ(t) ≈ (t/2) · ln(t / (2·π)) - (t/2) - (π / 8) + 1 / (48·t) + 7 / (5760·t³)
```

Властивості функції Харді `Z(t)`:
1. `Z(t)` є строго дійсною і неперервною функцією для всіх дійсних значень `t`.
2. Модуль функції дорівнює модулю Дзета-функції: `|Z(t)| = |ζ(1/2 + i·t)|`.
3. **Нулі Дзета-функції на критичній лінії відповідають зміні знаку функції `Z(t)`!**

Отже, складне комплексне завдання розшуку коренів зводиться до простого одновимірного пошуку точок перетину нуля: якщо для двох сусідніх точок `Z(t₁) · Z(t₂) < 0`, то за теоремою Больцано–Коші про проміжне значення на інтервалі `[t₁, t₂]` гарантовано існує принаймні один нетривіальний нуль!

## Формула Рімана–Зігеля для обчислення Z(t)

Для швидкого обчислення `Z(t)` скористаємося фундаментальною формулою Рімана–Зігеля:

```
Z(t) = 2 · ∑ (1 / √n) · cos(θ(t) - t · ln n) + R(t)      [сума по n від 1 до N = ⌊√(t / (2·π))⌋]
```

Тут:
- `N = ⌊√(t / (2·π))⌋` — межа сумування головної частини формули.
- `R(t)` — залишковий член Рімана–Зігеля, який враховує дробову частину `p = √(t / (2·π)) - N`.

Залишковий член першого порядку дається формулою:

```
R(t) ≈ (-1)ᴺ⁻¹ · (2·π / t)¹/⁴ · C₀(p)
```

де `C₀(p) = cos(2·π·(p² - p - 1/16)) / cos(2·π·p)`.

Для значень `t > 10` головна сума дає достатню точність для локалізації нулів.

## Покроковий алгоритм пошуку нулів

1. **Крок 1**: Задати інтервал пошуку по уявній осі `[t_start, t_end]` (наприклад, `t ∈ [10, 30]`) та крок сканування `step` (наприклад, `step = 0.1`).
2. **Крок 2**: Обчислити початкове значення `Z(t_curr)` у стартовій точці.
3. **Крок 3**: Просуватися вздовж осі `t` з кроком `step`, обчислюючи значення `Z(t_next)`.
4. **Крок 4**: Перевіряти умову зміни знаку `Z(t_curr) · Z(t_next) < 0`.
5. **Крок 5**: При виявленні зміни знаку застосувати метод бісекції (або метод Брента) на інтервалі `[t_curr, t_next]` для уточнення координати нуля `t_zero` з високою точністю (наприклад, `tol = 10⁻⁷`).

Розглянемо чисельне простеження для першого нуля:
- При `t = 14.0`: `θ(14.0) ≈ -1.824`, головна сума `N = 1`, `Z(14.0) ≈ +0.814` (знак плюс).
- При `t = 14.2`: `θ(14.2) ≈ -1.745`, `Z(14.2) ≈ -0.198` (знак мінус).
- Оскільки `Z(14.0) · Z(14.2) < 0`, між `14.0` та `14.2` лежить нуль. Бісекція звужує інтервал і знаходить точне значення `t₁ ≈ 14.134725`.

## Точки Ґрама та метод Тюрінга для контролю нулів

Окрім простого сканування, теорія чисел пропонує потужні аналітичні інструменти для контролю повноти знайдених нулів:

1. **Точки Ґрама `g_n`**: це значення `t`, у яких фазовий кут Рімана–Зігеля дорівнює цілому кратному `π`:
   ```
   θ(g_n) = n · π
   ```
   Згідно з **Законом Ґрама**, нетривіальні нулі у більшості випадків чергуються з точками Ґрама, тобто на кожному інтервалі `[g_n, g_{n+1}]` лежить рівно один нуль `t_n`. Перше порушення Закону Ґрама виникає лише при `n = 126` (так звана аномалія Ґрама).

2. **Метод Тюрінга**: розроблений Аланом Тюрінгом у 1953 році для гарантії того, що жоден нуль не було пропущено. Метод базується на інтегруванні функції `ln |ζ(s)|` вздовж контуру та обчисленні кількості нулів `N(T)` у прямокутній області за формулою підрахунку нулів:
   ```
   N(T) = (T / (2·π)) · ln(T / (2·π·e)) + 7/8 + S(T) + O(1/T)
   ```
   де `S(T) = (1/π) · arg ζ(1/2 + i·T)` — залишкова фазова функція. Метод Тюрінга дозволяє строго довести, що всі нулі у дослідженому інтервалі лежать саме на критичній лінії, а не вискочили у критичну смугу.

import math

def riemann_siegel_theta(t: float) -> float:
    """Обчислення фазового кута θ(t) за асимптотичною формулою Рімана-Зігеля."""
    if t < 0.1:
        return 0.0
    t_2pi = t / (2.0 * math.pi)
    return (t / 2.0) * math.log(t_2pi) - (t / 2.0) - (math.pi / 8.0) + (1.0 / (48.0 * t))

def hardy_z(t: float) -> float:
    """Обчислення дійснозначної функції Харді Z(t)."""
    theta = riemann_siegel_theta(t)
    bound = int(math.sqrt(t / (2.0 * math.pi)))
    if bound < 1:
        bound = 1
    
    z_sum = 0.0
    for n in range(1, bound + 1):
        z_sum += (1.0 / math.sqrt(n)) * math.cos(theta - t * math.log(n))
    
    return 2.0 * z_sum

def find_zeros(t_min: float, t_max: float, step: float = 0.1, tol: float = 1e-7):
    """Пошук нулів Z(t) методом бісекції."""
    zeros = []
    t_curr = t_min
    z_curr = hardy_z(t_curr)
    
    while t_curr < t_max:
        t_next = t_curr + step
        z_next = hardy_z(t_next)
        
        # Перевірка зміни знаку (зміна знаку розкриває наявність нуля)
        if z_curr * z_next < 0:
            # Метод бісекції
            low, high = t_curr, t_next
            for _ in range(50):
                mid = (low + high) / 2.0
                z_mid = hardy_z(mid)
                if abs(z_mid) < tol or (high - low) / 2.0 < tol:
                    zeros.append(mid)
                    break
                if z_curr * z_mid < 0:
                    high = mid
                else:
                    low = mid
                    z_curr = z_mid
        
        t_curr = t_next
        z_curr = z_next
    
    return zeros

if __name__ == "__main__":
    print("Пошук перших нетривіальних нулів Дзета-функції Рімана на Re(s) = 1/2:")
    found_zeros = find_zeros(10.0, 30.0, step=0.1)
    for i, z in enumerate(found_zeros, 1):
        print(f"Нуль #{i}: t = {z:.6f}  => s = 1/2 + i·{z:.6f}")

#include <stdio.h>
#include <math.h>

#ifndef M_PI
#define M_PI 3.14159265358979323846
#endif

/* Асимптотична фаза Рімана-Зігеля θ(t) */
double riemann_siegel_theta(double t) {
    if (t < 0.1) return 0.0;
    double t_2pi = t / (2.0 * M_PI);
    return (t / 2.0) * log(t_2pi) - (t / 2.0) - (M_PI / 8.0) + (1.0 / (48.0 * t));
}

/* Дійснозначна функція Харді Z(t) */
double hardy_z(double t) {
    double theta = riemann_siegel_theta(t);
    int bound = (int)sqrt(t / (2.0 * M_PI));
    if (bound < 1) bound = 1;

    double z_sum = 0.0;
    for (int n = 1; n <= bound; ++n) {
        z_sum += (1.0 / sqrt((double)n)) * cos(theta - t * log((double)n));
    }
    return 2.0 * z_sum;
}

/* Пошук нулів методом бісекції */
void find_riemann_zeros(double t_min, double t_max, double step, double tol) {
    double t_curr = t_min;
    double z_curr = hardy_z(t_curr);
    int count = 1;

    printf("Пошук нулів на інтервалі t ∈ [%.1f, %.1f]:\n", t_min, t_max);

    while (t_curr < t_max) {
        double t_next = t_curr + step;
        double z_next = hardy_z(t_next);

        if (z_curr * z_next < 0.0) {
            double low = t_curr;
            double high = t_next;
            double mid = low;

            for (int iter = 0; iter < 50; ++iter) {
                mid = (low + high) / 2.0;
                double z_mid = hardy_z(mid);
                if (fabs(z_mid) < tol || (high - low) / 2.0 < tol) {
                    break;
                }
                if (z_curr * z_mid < 0.0) {
                    high = mid;
                } else {
                    low = mid;
                    z_curr = z_mid;
                }
            }
            printf("Нуль #%d: t = %.6f  =>  s = 1/2 + i·%.6f\n", count++, mid, mid);
        }
        t_curr = t_next;
        z_curr = z_next;
    }
}

int main(void) {
    find_riemann_zeros(10.0, 30.0, 0.1, 1e-7);
    return 0;
}

#include <iostream>
#include <vector>
#include <cmath>
#include <iomanip>

class RiemannZeroFinder {
public:
    static double riemannSiegelTheta(double t) noexcept {
        if (t < 0.1) return 0.0;
        const double t2pi = t / (2.0 * M_PI);
        return (t / 2.0) * std::log(t2pi) - (t / 2.0) - (M_PI / 8.0) + (1.0 / (48.0 * t));
    }

    static double hardyZ(double t) noexcept {
        const double theta = riemannSiegelTheta(t);
        int bound = static_cast<int>(std::sqrt(t / (2.0 * M_PI)));
        if (bound < 1) bound = 1;

        double sum = 0.0;
        for (int n = 1; n <= bound; ++n) {
            sum += (1.0 / std::sqrt(static_cast<double>(n))) * std::cos(theta - t * std::log(static_cast<double>(n)));
        }
        return 2.0 * sum;
    }

    static std::vector<double> findZeros(double tMin, double tMax, double step = 0.1, double tol = 1e-7) {
        std::vector<double> zeros;
        double tCurr = tMin;
        double zCurr = hardyZ(tCurr);

        while (tCurr < tMax) {
            const double tNext = tCurr + step;
            const double zNext = hardyZ(tNext);

            if (zCurr * zNext < 0.0) {
                double low = tCurr;
                double high = tNext;
                double mid = low;

                for (int iter = 0; iter < 50; ++iter) {
                    mid = (low + high) / 2.0;
                    const double zMid = hardyZ(mid);
                    if (std::abs(zMid) < tol || (high - low) / 2.0 < tol) {
                        break;
                    }
                    if (zCurr * zMid < 0.0) {
                        high = mid;
                    } else {
                        low = mid;
                        zCurr = zMid;
                    }
                }
                zeros.push_back(mid);
            }
            tCurr = tNext;
            zCurr = zNext;
        }
        return zeros;
    }
};

int main() {
    std::cout << std::fixed << std::setprecision(6);
    std::cout << "Пошук нулів Дзета-функції Рімана (C++ RAII/STL):\n";
    
    const auto zeros = RiemannZeroFinder::findZeros(10.0, 30.0, 0.1);
    for (size_t i = 0; i < zeros.size(); ++i) {
        std::cout << "Нуль #" << (i + 1) << ": t = " << zeros[i] 
                  << "  =>  s = 1/2 + i·" << zeros[i] << "\n";
    }
    return 0;
}

## Порівняльний аналіз реалізацій та оптимізація продуктивності

1. **Версія на Python**: чудово підходить для швидкого дослідження та інтерактивного аналізу в середовищах даних. Використовує вбудований модуль `math`. Недоліком є інтерпретованість та обмежена швидкість циклів сумування при великих `t`.
2. **Версія мовою C**: демонструє максимальну обчислювальну швидкість за рахунок прямих викликів синусоїд та логарифмів з `math.h` і відсутності накладних витрат об'єктної моделі. При компіляції прапорцями `-O3 -ffast-math` векторні інструкції SIMD автоматично розпаралелюють обчислення доданків `cos(θ - t·ln n)`.
3. **Версія мовою C++**: виражена через ідіоми сучасної розробки C++ (RAII, статичні методи класів `noexcept`, безелементні контейнери `std::vector`, потоки `std::cout`). Воно надає повну безпеку роботи з пам'яттю при нульовій вартості накладних витрат продуктивності порівняно з C.

## Практичні пастки, краеві випадки та обмеження

1. **Пропущені нулі при занадто великому кроці `step`**: якщо два сусідні нулі лежать дуже близько один до одного (проблема близьких нулів), функція `Z(t)` може змінити знак двічі всередині одного кроку `step`, через що обидва нулі будуть пропущені. Математики розробили точки Ґрама `g_n` та правило Россера, щоб точно визначати очікувану кількість нулів в інтервалі.
2. **Точність асимптотики для малих `t`**: при `t < 10` урізана формула Рімана–Зігеля втрачає точність. Для прецизійних розрахунків при дуже малих чи дуже великих `t` використовують повний розклад Рімана–Зігеля з залишковими членами `R(t)` або метод підсумовування Ейлера–Маклорена.
3. **Обчислювальна складність для великих `t`**: кількість доданків `N = ⌊√(t / 2π)⌋` зростає як `O(√t)`. Для обчислення нулів при `t ≈ 10¹²` direct-сумування вимагає мільйонів операцій на одну точку. У таких масштабах застосовують алгоритм Одлижка–Схюнгаге на основі Швидкого Перетворення Фур'є (ШПФ), що знижує складність до `O(t¹/⁶⁺ᵉ)`.
