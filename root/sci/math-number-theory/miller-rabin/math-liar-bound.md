# 🧮 Межа Моньє–Рабіна: доведення, що брехунів не більш ніж чверть

Головний числовий факт, на якому стоїть надійність тесту простоти, звучить так: для будь-якого непарного складеного n (окрім єдиного винятку — дев'ятки) сильними брехунами є щонайбільше чверть основ, точніше — не більш ніж φ(n)/4. Тут ми доведемо це від першої цеглини до останньої: розкладемо групу лишків за китайською теоремою про остачі, полічимо брехунів через порядки елементів у циклічних групах і побачимо на власні очі, звідки береться саме чвертка, чому найгірші числа — безквадратні добутки різних простих і чому з-під межі вислизає рівно 9. А наприкінці з тієї чвертки випаде оцінка похибки 4⁻ᵏ для k раундів.

## Що саме доводимо

Зафіксуймо об'єкт лічби. Дано непарне складене n; записуємо

```
n − 1 = 2ˢ · d,   d непарне.
```

Основу a (де 1 ≤ a ≤ n − 1) звемо **сильним брехуном** для n, якщо вона не викриває складеності — тобто виконується хоча б одне з двох:

```
a^d ≡ 1        (mod n),   або
a^(2ʲ·d) ≡ −1  (mod n)    для якогось j,  0 ≤ j ≤ s − 1.
```

Множину таких основ позначимо S(n), а її розмір — |S(n)|.

Перше ж спостереження вполовину скорочує задачу: **кожен сильний брехун взаємно простий з n**. Справді, з будь-якої з двох умов випливає a^(n−1) ≡ 1 (mod n) — з першої піднесенням до степеня 2ˢ, з другої піднесенням до 2^(s−j); а рівність a^(n−1) ≡ 1 означає, що a має обернений за модулем n, отже gcd(a, n) = 1. Тому вся множина S(n) сидить усередині групи оборотних лишків (Z/nZ)*, а в ній рівно φ(n) елементів: [φ(n) — функція Ейлера](topic:math-number-theory/euler-totient) лічить лишки від 1 до n, взаємно прості з n; вона мультиплікативна, і φ(p^e) = p^(e−1)·(p − 1).

Отже, доводимо

```
|S(n)| ≤ φ(n)/4     для непарного складеного n ≠ 9.
```

А що φ(n) ≤ n − 1, звідси задарма випливає й грубіша, зате зручніша на практиці межа |S(n)| ≤ (n − 1)/4.

## Єдиний лічильний важіль

Усе доведення тримається на одній елементарній лемі про циклічні групи.

**Лема.** Нехай G — циклічна група порядку g. Тоді рівняння xᵐ = 1 має в G рівно gcd(m, g) розв'язків. Рівняння xᵐ = c для фіксованого c ∈ G має або жодного розв'язку, або так само gcd(m, g).

Візьмімо твірну γ групи G — елемент, [степені якого пробігають усю групу](topic:math-number-theory/multiplicative-order), тож кожен x = γᵗ для однозначного t за модулем g. Тоді xᵐ = γ^(m·t), і це дорівнює 1 = γ⁰ рівно тоді, коли

```
m · t ≡ 0   (mod g).
```

Лінійне конгруентне рівняння m·t ≡ 0 (mod g) має точно gcd(m, g) розв'язків t на проміжку довжини g — стільки, отже, і різних x. Для xᵐ = c = γᵘ маємо m·t ≡ u (mod g): воно розв'язне, лише коли gcd(m, g) ділить u, і тоді знову ж дає gcd(m, g) розв'язків. □

Це весь потрібний алгебраїчний інструмент. Аби ним скористатися, групу (Z/nZ)* спершу треба розкласти на циклічні шматки.

## Розклад за китайською теоремою

Нехай канонічний розклад n на прості —

```
n = p₁^e₁ · p₂^e₂ · … · p_r^e_r      (r різних непарних простих).
```

[Китайська теорема про остачі](topic:math-number-theory/chinese-remainder-theorem) каже, що знати лишок за складеним модулем — те саме, що знати набір лишків за кожним взаємно простим множником, а дії узгоджені покомпонентно. Мовою груп це ізоморфізм

```
(Z/nZ)*  ≅  (Z/p₁^e₁Z)* × … × (Z/p_r^e_rZ)*.
```

Наслідок, яким користуватимемось раз по раз: будь-яка степенева рівність виду a^k ≡ c (mod n) рівносильна тому, що така сама рівність виконується **одночасно в кожному** множнику.

Кожен множник — **циклічна** група: для непарного простого p група (Z/p^eZ)* циклічна, тобто [має первісний корінь](topic:math-number-theory/primitive-root) — елемент, чиї степені дають усі оборотні лишки. Її порядок —

```
nᵢ := φ(pᵢ^eᵢ) = pᵢ^(eᵢ−1) · (pᵢ − 1).
```

Оскільки pᵢ непарне, pᵢ − 1 парне; виділимо двійки:

```
nᵢ = 2^sᵢ · mᵢ,   mᵢ непарне,   sᵢ = v₂(pᵢ − 1).
```

Степінь двійки в nᵢ сидить лише в множнику pᵢ − 1, бо pᵢ^(eᵢ−1) непарне. Тепер маємо все, щоб лічити.

## Формула Моньє: точна кількість брехунів

Розкладемо S(n) на **неперетинні** частини за тим, ЯК основа проходить перевірку.

**Частина A — «одиниця з самого старту»:** a^d ≡ 1 (mod n). Покомпонентно це a^d ≡ 1 у кожному множнику; за лемою в i-му множнику розв'язків gcd(d, nᵢ), а що d непарне — gcd(d, nᵢ) = gcd(d, mᵢ). Разом

```
A = ∏ᵢ gcd(d, nᵢ).
```

**Частина Bⱼ — «−1 уперше на рівні j»:** a^(2ʲ·d) ≡ −1 (mod n) для фіксованого j. У циклічній групі парного порядку nᵢ елемент −1 — єдиний елемент порядку 2, тобто −1 = γ^(nᵢ/2). Рівняння в показниках стає

```
2ʲ·d · t ≡ nᵢ/2 = 2^(sᵢ−1)·mᵢ   (mod 2^sᵢ · mᵢ).
```

Тут gcd(2ʲ·d, nᵢ) = 2^min(j, sᵢ)·gcd(d, mᵢ). За критерієм леми рівняння розв'язне, лише коли це gcd ділить праву частину 2^(sᵢ−1)·mᵢ, а для двійкової частини це означає min(j, sᵢ) ≤ sᵢ − 1, тобто **j < sᵢ**. І коли j < sᵢ, розв'язків рівно 2ʲ·gcd(d, mᵢ).

Щоб −1 вийшло **одночасно в усіх** множниках, потрібно j < sᵢ для кожного i, тобто

```
j < ν,   ν := minᵢ sᵢ.
```

Тоді число таких основ — добуток покомпонентних лічб:

```
Bⱼ = ∏ᵢ (2ʲ · gcd(d, nᵢ)) = 2^(j·r) · ∏ᵢ gcd(d, nᵢ).
```

Частини не перетинаються: якщо драбина a^d, a^(2d), … стартує з одиниці — це A; інакше −1, коли й трапляється, трапляється на єдиному рівні j (наступний квадрат дає 1 і далі 1 назавжди). Сумуємо геометричну прогресію ∑_{j=0}^{ν−1} 2^(j·r) = (2^(rν) − 1)/(2^r − 1):

```
|S(n)| = A + ∑_{j=0}^{ν−1} Bⱼ
       = ( 1 + (2^(rν) − 1)/(2^r − 1) ) · ∏ᵢ gcd(d, nᵢ).
```

Це **формула Моньє** — точна кількість сильних брехунів, виражена через розклад n (Луї Моньє, 1980; ту саму чвертку незалежно й того ж року встановив Майкл Рабін). Пряма перевірка перебором для всіх непарних складених до кількох мільйонів збігається з нею до одиниці. Тепер із неї видавимо чвертку.

![Дві компоненти-драбини за КТЗ: у першій (s₁ = 2) значення −1 можливе лише на рівнях 0 і 1, у другій (s₂ = 3) — на рівнях 0, 1, 2. Спільний −1 можливий тільки там, де його дозволяють обидві компоненти одразу — рівні 0 … ν−1, ν = min(s₁, s₂) = 2. Найкоротша компонента обриває драбину першою.](img/liar-crt-levels.svg)

*Чому в лічбі виринає саме min sᵢ: спільний −1 можливий лише на рівнях, де −1 доступне в кожній компоненті одразу, тож найкоротша компонента обриває драбину першою — і межа рівнів ν = min sᵢ дає в |S(n)| множник 2^(rν).*

## Від точної формули до чверті

Оцінюємо відношення |S(n)|/φ(n), де φ(n) = ∏ᵢ nᵢ. Ключ, що дає всю силу оцінці: **жодне pᵢ не ділить d**. Бо n ≡ 0, отже n − 1 ≡ −1 (mod pᵢ) — pᵢ не входить у n − 1, а значить і в d. Тому в gcd(d, nᵢ) увесь множник pᵢ^(eᵢ−1) випадає:

```
gcd(d, nᵢ) = gcd(d, mᵢ′) ≤ mᵢ′,   де  mᵢ′ := (pᵢ − 1)/2^sᵢ   (непарне).
```

Звідси покомпонентно

```
gcd(d, nᵢ) / nᵢ  ≤  mᵢ′ / (pᵢ^(eᵢ−1) · 2^sᵢ · mᵢ′)  =  1 / (pᵢ^(eᵢ−1) · 2^sᵢ).
```

Перемноживши й позначивши σ := ∑ᵢ sᵢ та P := ∏ᵢ pᵢ^(eᵢ−1), дістаємо робочу нерівність

```
|S(n)|/φ(n)  ≤  ( 1 + (2^(rν) − 1)/(2^r − 1) ) / ( P · 2^σ ).       (★)
```

Далі — три випадки за числом простих r.

**r ≥ 3.** Відкиньмо P ≥ 1 і скористаймося σ ≥ r·ν (кожне sᵢ ≥ ν). Права частина (★) не більша за

```
( 1 + (2^(rν) − 1)/(2^r − 1) ) · 2^(−rν).
```

Ця величина спадає зі зростанням ν (більший показник у 2^(−rν) переважує ріст дужки), тож максимальна при ν = 1, де дужка = 2, а все відношення = 2·2^(−r) = 2^(1−r). Отже

```
|S(n)|/φ(n) ≤ 2^(1−r) ≤ 2^(−2) = 1/4    (r ≥ 3).
```

Трьох простих множників уже досить; а що більше простих — то менша межа.

**r = 1 — степінь простого n = p^e, e ≥ 2.** Тут ν = s₁, дужка = 2^(s₁), і 2^σ = 2^(s₁) з нею скорочується. Оцінка стає прозорою:

```
|S(n)|/φ(n) = gcd(d, m₁′) / (p^(e−1) · m₁′) ≤ 1/p^(e−1).
```

Це ≤ 1/4, щойно p^(e−1) ≥ 4. Для e ≥ 3 маємо p^(e−1) ≥ 3² = 9 — із запасом. Для e = 2 треба p ≥ 5, і тоді 1/p ≤ 1/5. Єдиний непарний степінь простого, де p^(e−1) < 4, — це p = 3, e = 2, тобто **n = 9**, де межа сягає 1/p^(e−1) = 1/3 > 1/4. Ось де народжується виняток; за мить розберемо його окремо.

**r = 2 — n = p₁^e₁·p₂^e₂.** Хай s₁ ≤ s₂, тож ν = s₁; дужка = (4^ν + 2)/3. Винесемо з (★) множник-префактор:

```
|S(n)|/φ(n) = (4^s₁ + 2)/(3·4^s₁) · c₁c₂ / (P · 2^(s₂−s₁)),   cᵢ := gcd(d, mᵢ′)/mᵢ′ ≤ 1.
```

Префактор (4^s₁ + 2)/(3·4^s₁) = 1/3 + 2/(3·4^s₁) ≤ 1/2 (максимум при s₁ = 1). Тому

```
|S(n)|/φ(n) ≤ (1/2) · c₁c₂ / (P · 2^(s₂−s₁)).
```

- **s₂ > s₁:** дільник 2^(s₂−s₁) ≥ 2 сам дотягує до чверті: ≤ (1/2)·(1/2) = 1/4. Рівність можлива (s₁ = 1, s₂ = 2, обидва cᵢ = 1, P = 1) — саме такі числа й будуть найгіршими.
- **s₂ = s₁ і є справжній степінь (P ≥ 3):** ≤ (1/2)·(1/3) = 1/6.
- **s₂ = s₁ і n = p·q безквадратне (P = 1):** тут спрацьовує дільниковий аргумент. Якби обидва cᵢ = 1, тобто m₁′ | d і m₂′ | d, то з тотожності

```
p·q − 1 = 2^s₁ · ( 2^s₁ · m₁′ · m₂′ + m₁′ + m₂′ )
```

за модулем m₁′ лишається 2^s₁·m₂′, отже m₁′ | (pq − 1) тягне m₁′ | m₂′; симетрично m₂′ | m₁′; разом m₁′ = m₂′, а тоді p = q — суперечність. Тому принаймні один mᵢ′ не ділить d; його gcd — власний дільник непарного числа, не більший за третину, тож cᵢ ≤ 1/3 і |S(n)|/φ(n) ≤ (1/2)·(1/3) = 1/6.

Усі гілки дають ≤ ¼. Разом із r = 1 (окрім 9) і r ≥ 3 це доводить теорему.

## Чому найгірші — безквадратні, і чому 9

Тепер видно всю картину. Степінь простого несе в знаменнику множник P = ∏ pᵢ^(eᵢ−1): кожен повторений простий (eᵢ ≥ 2) додає щонайменше pᵢ ≥ 3 у дільник і заганяє частку глибоко під ¼ — для 25 це 1/5, для 49 — 1/7, для 27 — 1/9. Тому **стелю ¼ можуть дістати лише безквадратні числа** — добутки різних простих у першому степені, де P = 1. І дістають: рівність |S(n)| = φ(n)/4 справджується, наприклад, для

```
n = 15 = 3·5,   91 = 7·13,   703 = 19·37,   1891 = 31·61,   …
```

(усі виду p·(2p − 1), де p і 2p − 1 водночас прості), а також для декотрих добутків трьох простих на кшталт 8911 = 7·19·67. Отже, константу ¼ поліпшити не можна — вона реально досягається для цілої низки чисел, тож жодну меншу сталу в теорему поставити не вийде.

![Стовпчики частки брехунів |S(n)|/φ(n). Ліворуч — степені простого: 25 дає 0.20, 49 дає 0.143, 27 дає 0.111, усі під межею ¼; єдиний виняток 9 стирчить на 0.333. Праворуч — безквадратні добутки різних простих: 15, 91 і 8911 упираються рівно в ¼, а 561 лежить низько на 0.031.](img/liar-bound-structure.svg)

*Степінь простого несе множник 1/p^(e−1) і лежить строго під ¼; стелю ¼ саме дістають безквадратні числа. Єдина паличка над межею — 9, бо φ(9) = 6 замала навіть для двох вимушених брехунів ±1.*

Виняток 9 тепер теж прозорий. Дві основи ±1 — сильні брехуни для будь-якого непарного n (1 дає a^d ≡ 1, а −1 дає a^d ≡ −1 уже на рівні 0, бо d непарне), тож |S(n)| ≥ 2 завжди. Для 9 цих двох брехунів рівно два й ніяких більше, але φ(9) = 6, і чвертка від неї — лише 1.5. Двом вимушеним брехунам просто нікуди подітися: 2 > 6/4. Жодне інше непарне складене такої халепи не має, бо в кожного іншого або φ(n) досить велика, або структура (безквадратність із двома-трьома простими) утримує частку рівно під стелею. Показово, що навіть 9 не порушує грубішої межі (n − 1)/4: там (9 − 1)/4 = 2, і |S(9)| = 2 лягає точно в неї.

## Наслідок: похибка 4⁻ᵏ

З доведеної межі практична надійність випадає негайно. Візьмімо k незалежних основ, кожну рівномірно з {1, …, n − 1}. Для складеного n частка брехунів у цьому діапазоні — |S(n)|/(n − 1) ≤ 1/4 (нерівність |S(n)| ≤ (n − 1)/4 тримається для КОЖНОГО непарного складеного, включно з 9). Тож імовірність, що навмання взята основа виявиться брехуном, не більша за ¼, а для k незалежних основ імовірність, що **всі** промовчать, не перевищує

```
(1/4)^k = 4⁻ᵏ.
```

Ось скільки коштує складеному числу прослизнути крізь k раундів:

```
k = 10   →   4⁻¹⁰ ≈ 9.5·10⁻⁷
k = 20   →   4⁻²⁰ ≈ 9.1·10⁻¹³
k = 40   →   4⁻⁴⁰ ≈ 8.3·10⁻²⁵
```

І це песимістична оцінка найгіршого випадку: рівність 4⁻ᵏ вимагала б, щоб кожен із k раундів улучив у брехуна числа, чия частка брехунів справді близька до ¼, — а таких чисел мало й вони особливі. На випадковому кандидаті справжня похибка на багато порядків менша. Саме тому чвертка Моньє–Рабіна перетворює один імовірнісний крок на тест, чия межа помилки керована й спадає геометрично з кожним новим раундом.
