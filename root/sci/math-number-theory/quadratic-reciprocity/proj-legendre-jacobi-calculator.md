# Проєкт: Калькулятор символів Лежандра та Якобі

Коли ми вивчаємо теорію чисел, розуміння концепцій є ключовим, але справжнє відчуття сили цих математичних інструментів приходить тоді, коли ми застосовуємо їх на практиці. Символ Лежандра, який повідомляє нам, чи є число квадратичним лишком, є потужним, але його обчислення вручну для великих чисел може бути виснажливим. Більше того, символ Лежандра працює лише тоді, коли нижнє число (знаменник у позначенні) є простим.

Тут на сцену виходить символ Якобі. Це узагальнення символу Лежандра, яке дозволяє нижньому числу бути будь-яким непарним додатним цілим числом. Цікаво, що правила обчислення символу Якобі майже ідентичні до правил для символу Лежандра, включаючи сам квадратичний закон взаємності! Це робить символ Якобі неймовірно корисним інструментом для швидкого обчислення символу Лежандра без необхідності розкладати числа на прості множники, що для великих чисел є дуже складною задачею.

Ваше завдання у цьому проєкті — написати програму (наприклад, мовою JavaScript або Python), яка автоматично обчислює символ Якобі (a / n). Оскільки символ Лежандра є окремим випадком символу Якобі (коли n є простим), ваш калькулятор автоматично зможе обчислювати і символи Лежандра.

## Алгоритм обчислення

Щоб написати ефективний калькулятор, вам не потрібно перевіряти всі можливі квадрати. Використовуйте властивості символу Якобі, які базуються на квадратичному законі взаємності. Ось основні кроки алгоритму, який вам потрібно реалізувати:

1.  **Базові випадки:**
    *   Якщо a і n мають спільний дільник більший за 1, то (a / n) = 0.
    *   Якщо a = 1, то (1 / n) = 1.
    *   Якщо a = 0, то (0 / n) = 0.
    *   Якщо a = 2, використовуйте правило двійки: (2 / n) = 1, якщо n ≡ 1 або 7 (mod 8), і (2 / n) = -1, якщо n ≡ 3 або 5 (mod 8).

2.  **Зведення по модулю:**
    *   Оскільки нас цікавлять лише залишки, ви завжди можете замінити 'a' на 'a mod n'. Тобто (a / n) = (a mod n / n). Це зменшує верхнє число, спрощуючи обчислення.

3.  **Винесення двійок:**
    *   Якщо 'a' — парне число, ви можете виділити з нього всі двійки. Тобто a = 2^k * b, де b — непарне число. Завдяки мультиплікативності символу Якобі: (a / n) = (2^k / n) * (b / n). Перший множник обчислюється за правилом двійки (крок 1), а для другого множника ми маємо непарне 'b'.

4.  **Застосування закону взаємності:**
    *   Тепер у вас залишився символ (b / n), де і 'b', і 'n' — непарні числа (і 'b' < 'n' завдяки кроку 2). Це ідеальний момент для застосування квадратичного закону взаємності!
    *   Закон говорить: (b / n) = (n / b) * (-1)^(((b-1)/2) * ((n-1)/2)).
    *   Простіше кажучи, ви можете перевернути символ: обчислювати (n / b) замість (b / n). При цьому знак результату змінюється на протилежний, ТІЛЬКИ якщо і 'b', і 'n' дають остачу 3 при діленні на 4. В іншому випадку знак не змінюється.

5.  **Рекурсія:**
    *   Після перевертання ви отримуєте новий символ (n / b). Тепер 'n' більше за 'b'. Поверніться до кроку 2 (зведення по модулю) і повторюйте процес. З кожним кроком числа ставатимуть все меншими, поки ви не досягнете одного з базових випадків.

## Реалізація

Ваша програма повинна приймати два цілих числа 'a' та 'n' (де 'n' > 0 та непарне) і повертати 1, -1 або 0. Спробуйте реалізувати цей алгоритм рекурсивно або за допомогою циклу. Ви побачите, що він працює надзвичайно швидко, подібно до алгоритму Евкліда для знаходження найбільшого спільного дільника.

Цей проєкт не лише покращить ваші навички програмування, але й дасть вам глибоке, практичне розуміння того, як алгоритмічно застосовується квадратичний закон взаємності.

```javascript
function jacobiSymbol(a, n) {
    if (n <= 0 || n % 2 === 0) return 0;
    a = a % n;
    let t = 1;
    while (a !== 0) {
        while (a % 2 === 0) {
            a = Math.floor(a / 2);
            let r = n % 8;
            if (r === 3 || r === 5) {
                t = -t;
            }
        }
        let temp = a;
        a = n;
        n = temp;
        if (a % 4 === 3 && n % 4 === 3) {
            t = -t;
        }
        a = a % n;
    }
    if (n === 1) return t;
    return 0;
}
console.log("Символ Якобі (29 / 53):", jacobiSymbol(29, 53));
```
