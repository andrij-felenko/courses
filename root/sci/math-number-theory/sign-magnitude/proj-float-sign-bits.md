# ⚙️ Бітовий аналіз знаку у числах з рухомою комою: C++17

Оскільки сучасні процесори використовують доповняльний код для цілих чисел, ми рідко стикаємося з форматом знак-величина на рівні бітів. Проте цей формат є серцем стандарту IEEE 754 для дійсних чисел (`float` та `double`). Коли нам потрібно написати надшвидкий код, наприклад, у графічних рушіях або системах цифрової обробки сигналів, іноді вигідніше маніпулювати бітами числа напряму, замість того, щоб використовувати звичайні арифметичні операції.

У цьому проєкті ми напишемо C++17 код для безпосереднього доступу та модифікації знакового біта у 32-бітному числі з рухомою комою (`float`). Ми не будемо розбирати мантису та експоненту, наша мета — побачити, як працює знайомий формат знак-величина в реальному залізі.

### 1. Мета та проблема

Операція зміни знаку (`x = -x`) для цілих чисел вимагає інверсії всіх бітів та додавання одиниці. Але для `float` це просто зміна одного найстаршого біта (MSB) з 0 на 1 (або навпаки). Процесор має спеціальну інструкцію для цього, але ми можемо зробити це вручну, щоб зрозуміти механіку.

Однак, C++ забороняє напряму застосовувати побітові операції (такі як `&`, `|`, `^`) до типів з рухомою комою. Ми не можемо просто написати `f ^ 0x80000000`. Нам потрібно безпечно переглянути пам'ять `float` як масив бітів. До стандарту C++20 для цього використовували вказівники або `union`, але це порушувало правила строгого накладання типів (strict aliasing). У C++17 правильним інструментом є `std::memcpy`.

### 2. Структура маски

У 32-бітному числі (тип `float`), біт знаку знаходиться на 31-й позиції (якщо рахувати від нуля). Тобто це найлівіший біт. 
Маска для доступу до цього біта матиме вигляд, де 31-й біт дорівнює 1, а всі інші — 0.
У шістнадцятковому записі це: `0x80000000`.

### 3. Алгоритм та реалізація

Наш код складатиметься з трьох функцій:
1. `print_sign` — перевірка знакового біта.
2. `flip_sign` — інверсія знакового біта.
3. `force_positive` — очищення знакового біта (математичний модуль числа).

```cpp
#include <iostream>
#include <cstring>
#include <cstdint>
#include <iomanip>

// Маска для знакового біта (31-й біт)
constexpr uint32_t SIGN_BIT_MASK = 0x80000000;

// Функція для перевірки знакового біта
bool is_negative(float value) {
    uint32_t bits;
    // Безпечне копіювання бітів з float у uint32_t
    std::memcpy(&bits, &value, sizeof(bits));
    
    // Побітове І з маскою залишає тільки знаковий біт
    return (bits & SIGN_BIT_MASK) != 0;
}

// Функція для швидкої зміни знаку (заміна value = -value)
float flip_sign(float value) {
    uint32_t bits;
    std::memcpy(&bits, &value, sizeof(bits));
    
    // Побітове АБО-НЕ (XOR) інвертує лише знаковий біт
    bits ^= SIGN_BIT_MASK;
    
    float result;
    std::memcpy(&result, &bits, sizeof(result));
    return result;
}

// Функція для знаходження модуля (абсолютної величини)
float force_positive(float value) {
    uint32_t bits;
    std::memcpy(&bits, &value, sizeof(bits));
    
    // Побітове І з інвертованою маскою (0x7FFFFFFF) очищає знаковий біт
    bits &= ~SIGN_BIT_MASK;
    
    float result;
    std::memcpy(&result, &bits, sizeof(result));
    return result;
}

int main() {
    float a = 42.5f;
    float b = -13.25f;
    
    // Перевірка знаку
    std::cout << "Is " << a << " negative? " << (is_negative(a) ? "Yes" : "No") << "\n";
    std::cout << "Is " << b << " negative? " << (is_negative(b) ? "Yes" : "No") << "\n";
    
    // Зміна знаку
    std::cout << "\nFlipping sign of " << a << " -> " << flip_sign(a) << "\n";
    std::cout << "Flipping sign of " << b << " -> " << flip_sign(b) << "\n";
    
    // Абсолютне значення (force positive)
    std::cout << "\nAbsolute value of " << a << " -> " << force_positive(a) << "\n";
    std::cout << "Absolute value of " << b << " -> " << force_positive(b) << "\n";
    
    // Демонстрація двох нулів
    float zero_pos = 0.0f;
    float zero_neg = flip_sign(zero_pos); // Створюємо -0.0f
    
    std::cout << "\nPos zero == Neg zero? " << (zero_pos == zero_neg ? "True" : "False") << "\n";
    std::cout << "Is zero_pos negative? " << (is_negative(zero_pos) ? "Yes" : "No") << "\n";
    std::cout << "Is zero_neg negative? " << (is_negative(zero_neg) ? "Yes" : "No") << "\n";
    
    return 0;
}
```

### 4. Розбір ключових моментів

У функції `flip_sign` ми використовуємо оператор `^` (XOR). XOR з 1 інвертує біт, а XOR з 0 залишає його без змін. Оскільки маска має лише одну одиницю на початку, ця операція миттєво змінює знак числа на протилежний, не впливаючи на саму величину.

У функції `force_positive` ми використовуємо `&` (AND) з інвертованою маскою `~SIGN_BIT_MASK` (що дорівнює `0x7FFFFFFF`). Ця операція примусово скидає 31-й біт у 0, перетворюючи будь-яке число на додатне. Це найшвидший спосіб реалізувати функцію `abs()` для дійсних чисел, якщо процесор не має вбудованої апаратної підтримки.

### 5. Підсумки та складність

Цей код демонструє головну перевагу формату знак-величина. Зміна знаку та обчислення абсолютного значення не вимагають жодних арифметичних суматорів, переносів розрядів чи порівнянь. Усе зводиться до єдиної побітової операції над найстаршим бітом. 
На рівні асемблера сучасні компілятори C++ (такі як GCC або Clang) оптимізують `std::memcpy` і перетворюють ці функції на кілька інструкцій. Більше того, у C++20 для цієї мети з'явилася стандартна функція `std::bit_cast`, яка робить цей процес ще елегантнішим. Проте розуміння бітової природи залишається незмінним.
