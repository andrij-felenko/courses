# Метод Шенкса Baby-step Giant-step: Практична реалізація

Цей проєкт демонструє реалізацію алгоритму Baby-step Giant-step (крок немовляти, крок велетня) для обчислення дискретного логарифма `x = log_g(y) (mod p)`.

> 🔧 **Навіщо це.** Щоб побачити на практиці, як теоретична складність `O(√p)` перетворюється на працюючий код, здатний зламати невеликі криптографічні ключі за частки секунди. Ми використаємо C++ для максимальної швидкодії.

## 1. Постановка задачі

Нам дано три числа:
*   Основа `g`.
*   Модуль `p` (просте число).
*   Результат `y`.

Потрібно знайти таке найменше невід'ємне ціле число `x`, що `gˣ ≡ y (mod p)`.
Оскільки `p` — просте, за малою теоремою Ферма можливі значення `x` лежать у діапазоні від `0` до `p-2`.
Алгоритм Baby-step Giant-step, запропонований Деніелом Шенксом, дозволяє знайти `x` за час `O(√p)` з використанням `O(√p)` пам'яті, що значно швидше за простий перебір, який вимагав би `O(p)` кроків.

## 2. Математична основа алгоритму

Нехай `m = ⌈√p⌉`. Будь-яке число `x` з діапазону `[0, p-1]` можна подати у вигляді:
`x = i · m + j`
де `0 ≤ i < m` та `0 ≤ j < m`.

Підставимо це рівняння у вихідну умову:
```text
[Підстановка]       g^(i · m + j) ≡ y (mod p)
[Розкриття]         g^(i · m) · gʲ ≡ y (mod p)
[Обернений елемент] gʲ ≡ y · (g⁻ᵐ)ⁱ (mod p)
```

Тут ми маємо два набори значень:
1.  **Baby steps (кроки немовляти):** обчислюємо `gʲ (mod p)` для всіх `0 ≤ j < m` і зберігаємо їх у хеш-таблицю (або відсортований масив) у вигляді пар `(значення, j)`.
2.  **Giant steps (кроки велетня):** обчислюємо значення правої частини `y · (g⁻ᵐ)ⁱ (mod p)` для `i = 0, 1, 2, ..., m-1`. Якщо отримане значення знайдено в хеш-таблиці на кроці 1, ми знайшли потрібні `i` та `j`. Відповідь: `x = i · m + j`.

## 4. Тестування та збірка

Щоб скомпілювати цей код, збережіть його у файл `bsgs.cpp` та виконайте команду в терміналі:

```bash
g++ -std=c++17 -O2 bsgs.cpp -o bsgs
```


## 5. Застосування та обмеження

**Де це використовується:**
Цей алгоритм застосовується для зламу невеликих ключів у протоколах, заснованих на проблемі дискретного логарифмування, таких як Diffie-Hellman або ElGamal. Він також корисний для атаки на еліптичні криві, де замість множення за модулем використовується додавання точок на кривій.

**Обмеження:**
Для великих значень `p` (наприклад, 2048 біт у сучасній криптографії), пам'ять та час `O(√p)` стають астрономічними. Квадратний корінь з `2²⁰⁴⁸` — це `2¹⁰²⁴`, що неможливо обчислити на сучасних комп'ютерах. Для більших чисел існують інші методи (наприклад, ρ-алгоритм Полларда, який також працює за `O(√p)`, але вимагає значно менше пам'яті, або метод решета числового поля для специфічних груп). Проте, для розуміння криптографічної стійкості, Baby-step Giant-step є фундаментальним інструментом.
