# 📋 Довідник метрик, математичних критеріїв та низькодискрепантних послідовностей

Цей довідник містить систематичний перелік математичних метрик рівномірного розподілу, критеріїв збіжності, теоретичних меж дискрепантності та параметрів класичних низькодискрепантних послідовностей.

---

## 1. Систематизація еквівалентних критеріїв рівномірного розподілу

Послідовність `(xₙ)_{n=1}^∞ ⊂ [0, 1)` називається **рівномірно розподіленою за модулем 1**, якщо вона задовольняє будь-яку з наведених еквівалентних математичних умов. Кожен критерій відкриває власний аналітичний підхід до дослідження точкових послідовностей.

| Назва критерію | Математичне формулювання | Застосування та особливості |
| :--- | :--- | :--- |
| **Індикаторний критерій (Означення)** | `lim_{N→∞} (1/N) ∑_{n=1}^N I_[a,b)(xₙ) = b − a` для всіх `[a,b) ⊆ [0,1)` | Базове мірно-теоретичне означення. Вимагає прямих геометричних підрахунків точок. |
| **Критерій неперервних функцій** | `lim_{N→∞} (1/N) ∑_{n=1}^N f(xₙ) = ∫₀¹ f(t) dt` для всіх `f ∈ C([0,1])` | Основа для аналітичних доведень, теорем про граничні переходи та чисельного інтегрування. |
| **Критерій Вейля (Гармонічний)** | `lim_{N→∞} (1/N) ∑_{n=1}^N e²ᵖⁱ ⁱ ʰ ˣⁿ = 0` для всіх цілих `h ≠ 0` | Фундаментальний аналітичний інструмент. Переводить геометрію у тригонометричні суми Вейля. |
| **Критерій моментів** | `lim_{N→∞} (1/N) ∑_{n=1}^N (xₙ)ᵏ = 1 / (k + 1)` для всіх `k ∈ ℕ` | Застосовується в теорії ймовірностей, коли легше обчислити степеневі моменти вибірки. |
| **Критерій дискрепантності** | `lim_{N→∞} D_N = 0` (або `lim_{N→∞} D_N* = 0`) | Кількісний обчислювальний критерій. Дає швидкість збіжності для скінченних `N`. |
| **Критерій Унікальної Ергодичності** | Для будь-якої неперервної функції на зсуві `T(x) = x + α mod 1` | Пов'язує теорію чисел із динамічними системами та теорією орбіт на торі `ℝ / ℤ`. |

### Докладний аналітичний розбір критеріїв збіжності

Мірно-теоретичний зміст рівномірного розподілу спирається на концепцію слабкої збіжності ймовірнісних мір. Дисперсна міра, зосереджена в точках вибірки `μ_N = (1/N) ∑_{n=1}^N δ_{xₙ}`, слабко збігається до тотожної міри Лебеґа `λ` на одиничному інтервалі `[0, 1)`. Це означає, що для будь-якої обмеженої неперервної функції інтеграл за мірою `μ_N` прямує до інтеграла за мірою `λ`.

Головна аналітична перевага критерію Вейля полягає у використанні ортогонального базису тригонометричної системи `e²ᵖⁱ ⁱ ʰ ˣ` на `[0, 1]`. Завдяки ортогональності гармонік, аналіз рівномірності будь-якої складної арифметичної послідовності (такої як `n² α`, `p α` по простих числах чи `2ⁿ α`) зводиться до звичайної алгебраїчної оцінки модуля експоненціальних сум `S_N(h) = ∑ e²ᵖⁱ ⁱ ʰ ˣⁿ`.

Моментний критерій використовує той факт, що многочлени за теоремою Вейєрштрасса утворюють щільну підмножину в просторі неперервних функцій `C([0, 1])`. Оскільки степеневі функції `xᵏ` задовольняють `∫₀¹ tᵏ dt = 1 / (k + 1)`, збіжність усіх скінченних моментів вибірки до теоретичних моментів рівномірного розподілу гарантує виконаність критерію для будь-якої неперервної функції.

Ергодичний підхід розглядає послідовність точок як орбіту динамічної системи під дією ірраціонального зсуву кола `T(x) = {x + α}`. Завдяки унікальній ергодичності (наявності єдиної інваріантної ймовірнісної міри), індивідуальна ергодична теорема Біркгофа виконується не просто для майже всіх, а для абсолютно всіх початкових точок `x₀`.

## 2. Повний довідник метрик відхилення та дискрепантності

Дискрепантність вимірює нерівномірність розміщення скінченного набору точок `P_N = {x₁, ..., x_N}` на відрізку `[0, 1]` або в `d`-вимірному кубі `[0, 1]ᵈ`.

### 2.1. Загальна крайня дискрепантність (Extreme Discrepancy)

```
D_N(P_N) = sup_{0 ≤ a < b ≤ 1} | (1 / N) · # { 1 ≤ n ≤ N : xₙ ∈ [a, b) } − (b − a) |
```

- **Математичний зміст:** Найбільша абсолютна помилка підрахунку точок у довільному замкненому чи відкритому підінтервалі `[a, b)`.
- **Діапазон значень:** `1/N ≤ D_N ≤ 1`.
- **Властивості:** Загальна дискрепантність є інваріантною відносно паралельного зсуву точок на колі `ℝ / ℤ`.

### 2.2. Зіркова дискрепантність (Star Discrepancy)

```
D_N*(P_N) = sup_{0 ≤ x ≤ 1} | (1 / N) · # { 1 ≤ n ≤ N : xₙ ∈ [0, x) } − x |
```

- **Математичний зміст:** Максимальне відхилення емпіричної функції розподілу від діагональної прямої `y = x`. Інтервали завжди прив'язані до початку координат `0`.
- **Зв'язок із загальною дискрепантністю:** 

```
D_N* ≤ D_N ≤ 2 · D_N*
```

- **Точна обчислювальна формула для впорядкованого масиву `0 ≤ x₁ ≤ x₂ ≤ ... ≤ x_N < 1`:**

```
D_N* = max_{1 ≤ i ≤ N} max( | (i / N) − x_i |, | ((i − 1) / N) − x_i | )
```

### 2.3. L₂-дискрепантність (L₂ Discrepancy)

Метрика середньоквадратичного відхилення, яка замінює супремум на інтеграл квадрата помилки:

```
(D_N^{(2)})² = ∫₀¹ ( (1 / N) · # { 1 ≤ n ≤ N : xₙ ≤ x } − x )² dx
```

- **Точна формула Варнока (Warnock Formula):**

```
(D_N^{(2)})² = (1 / (3 N²)) + (1 / N) ∑_{n=1}^N xₙ² − (1 / N²) ∑_{m=1}^N ∑_{n=1}^N max(x☵, xₙ)
```

- **Перевага:** Обчислюється точним алгебраїчним виразом за час `O(N²)` у будь-якій вимірності `d` без необхідності пошуку глобальних максимумів.

### 2.4. Двовимірна та багатовимірна зіркова дискрепантність

Для `d`-вимірного куба `[0, 1]ᵈ` зіркова дискрепантність вимірюється по прямокутних паралелепіпедах `[0, x₁] × [0, x₂] × ... × [0, x_d]`:

```
D_N*(P_N) = sup_{x ∈ [0,1]ᵈ} | (1 / N) · # { n : xₙ ∈ [0, x] } − ∏_{j=1}^d xⱼ |
```

### 2.5. Діафонія та дисперсія (Diaphony and Dispersion)

Поряд із класичною дискрепантністю в аналізі використовують дві допоміжні геометричні метрики:

1. **Діафонія Зінтера (Diaphony):** Запроваджена Пітером Зінтером у 1976 році як норма суми гармонік Вейля зі спадними вагами:
   ```
   F_N = ( (2 / (e²ᵖⁱ − 1)) ∑_{h=1}^∞ h⁻² |(1/N) ∑_{n=1}^N e²ᵖⁱ ⁱ ʰ ˣⁿ|² )¹/²
   ```
   Діафонія є гладкою характеристикою нерівномірності і обчислюється точними інтегральними формулами.

2. **Дисперсія вибірки (Dispersion):** Вимірює радіус найбільшої порожньої кулі або інтервалу у просторі, який не містить жодної точки вибірки:
   ```
   d_N = sup_{x ∈ [0,1]} min_{1 ≤ n ≤ N} |x − xₙ|
   ```
   Для рівномірно розподіленої послідовності дисперсія обов'язково прямує до нуля `lim_{N→∞} d_N = 0`.

## 3. Таблиця теоретичних меж та швидкостей збіжності

| Послідовність / Клас | Нижнє / Верхнє значення `D_N*` | Складність / Коментар |
| :--- | :--- | :--- |
| **Теоретична нижня межа Шмідта (1D)** | `D_N* ≥ C · (log N / N)` | Абсолютний теоретичний ліміт для будь-якої 1D послідовності (Шмідт, 1972). |
| **Теоретична нижня межа Ротта (d-D)** | `D_N* ≥ C_d · (log N)⁽ᵈ⁻¹⁾/² / N` | Доведено Клаусом Роттом (Roth, 1954) для `L₂`-дискрепантності. |
| **Послідовність `{n α}` (Золотий перетин)** | `D_N* = O(log N / N)` | Досягає теоретичної межі Шмідта завдяки гіршому наближенню. |
| **Послідовність `{n α}` (Загальне ірраціональне)** | `D_N* = O(N⁻¹ · ∑_{k=1}^K aₖ)` | Залежить від часткових часток `aₖ` розкладу у ланцюговий дріб. |
| **Послідовність Ван дер Корпута (Base 2)** | `D_N* ≤ (log N / (3 log 2)) + O(1/N)` | Оптимальна детермінована послідовність на двоічній основі. |
| **Багатовимірна послідовність Галтона (d-D)** | `D_N* = O( (log N)ᵈ / N )` | Працює для будь-якого `d`, спирається на прості числа `b₁, ..., b_d`. |
| **Послідовності Соболя / Нідерейтера (d-D)** | `D_N* = O( (log N)ᵈ / N )` | Оптимальні `(t, m, s)`-мережі над скінченними полями `GF(2)`. |
| **Випадкова вибірка (Псевдовипадкові числа)** | `D_N* = O( (log log N / N)¹/² )` | За законом повторного логарифма (класичний Монте-Карло). |

## 4. Паспорт та параметри низькодискрепантних послідовностей (LDS)

Низькодискрепантні послідовності (англ. *Low-Discrepancy Sequences*) — це детерміновані послідовності точок, розроблені для заміни псевдовипадкових чисел у квазі-Монте-Карло алгоритмах.

### 4.1. Послідовність Ван дер Корпута (Van der Corput)

- **Рік створення:** 1935.
- **Базовий механізм:** Дзеркальне відображення цифр `b`-арного розкладу цілого числа відносно коми.
- **Алгоритм побудови:** Для `n = ∑_{k=0}^K aₖ bᵏ` число дорівнює `ϕ_b(n) = ∑_{k=0}^K aₖ b⁻ᵏ⁻¹`.
- **Точна межа дискрепантності:** `limsup_{N→∞} (N · D_N* / log N) = 1 / (3 log 2)` (для `b = 2`).
- **Переваги:** Простота реалізації, відсутність обчислювальних витрат.

### 4.2. Послідовність Галтона (Halton Sequence)

- **Рік створення:** 1960.
- **Базовий механізм:** Узагальнення послідовності Ван дер Корпута на `d` вимірів шляхом вибору взаємно простих основ `b₁, b₂, ..., b_d` (найчастіше перших `d` простих чисел `2, 3, 5, 7, 11...`).
- **Вектор точки:** `Xₙ = (ϕ_{b₁}(n), ϕ_{b₂}(n), ..., ϕ_{b_d}(n))`.
- **Обмеження:** При високих вимірностях `d > 10` великі прості числа (наприклад `b₂₀ = 71`) викликають небажані геометричні кореляційні смуги (проблема виправляється скамблюванням / Scrambled Halton).

### 4.3. Послідовність Соболя (Sobol Sequence)

- **Рік створення:** 1967 (Ілля Соболь).
- **Базовий механізм:** Генерація точок у двоічному полі `GF(2)` з використанням примітивних многочленів та напрямних чисел `vᵢ`.
- **Властивість `(t, m, s)`-мереж:** Забезпечує математично рівномірну кількість точок у кожному двоічному підкубі об'єму `2⁻ᵐ`.
- **Галузь застосування:** Промисловий стандарт у комп'ютерній графіці (трасування променів у рендерингу) та фінансовому інжинірингу.

### 4.4. Послідовності Нідерейтера та Фора (Niederreiter and Faure Sequences)

- **Послідовність Фора (Faure, 1982):** Працює за простою основою `p ≥ d`, де `p` — найменше просте число, яке перевищує або дорівнює вимірності простору `d`. Генераційні матриці будуються за допомогою коефіцієнтів Паскаля над полем `Galois Field GF(p)`.
- **Послідовність Нідерейтера (Niederreiter, 1988):** Узагальнює цифрові мережі на довільні скінченні поля `GF(q)` та раціональні функції. Забезпечує найменші відомі теоретичні константи в оцінці `D_N* = O((log N)ᵈ / N)`.

## 5. Оцінка похибки Квазі-Монте-Карло інтегрування

### 5.1. Теорема Коксми — Главки (Koksma — Hlawka Inequality)

Для будь-якої інтегровної функції `f`, яка має обмежену варіацію у сенсі Харді — Краузе `V(f)` на одиничному кубі `[0, 1]ᵈ`:

```
| (1 / N) · ∑_{n=1}^N f(xₙ) − ∫_{[0,1]ᵈ} f(t) dt | ≤ V(f) · D_N*(x₁, ..., x_N)
```

### 5.2. Поняття варіації Харді — Краузе (Hardy — Krause Variation)

Для одновимірної функції `f` варіація `V(f)` збігається з класичною повного варіацією Жордана `⋁₀¹ f`.

Для багатовимірної функції `f(t₁, ..., t_d)` варіація Харді — Краузе є сумою варіацій функції на всіх граничних гранях куба плюс інтеграл від мішаної часткової похідної:

```
V(f) = ∫₀¹ ... ∫₀¹ | (∂ᵈ f) / (∂t₁ ∂t₂ ... ∂t_d) | dt₁ dt₂ ... dt_d + ∑_{грані} V(f|_{грань})
```

Якщо функція `f` має неперервні мішані похідні до степеня `d`, її варіація `V(f)` є скінченною константою, і теорема Коксми — Главки дає строгу гарантію збіжності.

### 5.3. Порівняльна таблиця методів чисельного інтегрування

| Характеристика | Квадратурна решітка (Grid) | Стандартний Монте-Карло (MC) | Квазі-Монте-Карло (QMC) |
| :--- | :--- | :--- | :--- |
| **Тип точок** | Декартова ґратка | Псевдовипадкові числа | Низькодискрепантні послідовності |
| **Похибка (1D)** | `O(N⁻¹)` | `O(N⁻¹/²)` | `O(N⁻¹ log N)` |
| **Похибка (d-D)** | `O(N⁻¹/ᵈ)` | `O(N⁻¹/²)` | `O(N⁻¹ (log N)ᵈ)` |
| **Прокляття вимірності** | Катастрофічне | Відсутнє | Слабке (ефективно при `d ≤ 30`) |

## 6. Зв'язок рівномірного розподілу з іншими розділами математики

### 6.1. Закон Бенфорда (Benford's Law)

Послідовність чисел `yₙ = aⁿ` задовольняє закон першої цифри Бенфорда тоді й лише тоді, коли послідовність `xₙ = log₁₀(aⁿ) = n log₁₀(a) mod 1` є рівномірно розподіленою на `[0, 1)`.
- **Умова:** `log₁₀(a)` є ірраціональним числом.
- **Формула ймовірності першої цифри `d ∈ {1, 2, ..., 9}`:**

```
P(перша цифра = d) = log₁₀(1 + 1 / d)
```

### 6.2. Нормальні числа за Борелем (Normal Numbers)

Дійсне число `x` називається **нормальним за основою `b`**, якщо послідовність дробових частин `{bⁿ x}` для `n = 0, 1, 2, ...` є рівномірно розподіленою за модулем 1 на `[0, 1)`.
- **Значення:** Усі цифри та скінченні комбінації цифр у `b`-арному розкладі нормального числа з'являються з однаковою асимптотичною частотою.
- **Приклад:** Число Чамперноунов `0.12345678910111213...` є нормальним за основою 10.

### 6.3. Теорема про три відстані (Three-Gap Theorem / Steinhaus Conjecture)

Для будь-якого ірраціонального `α` та будь-якого `N`, точки `{α}, {2α}, ..., {Nα}` ділять коло `[0, 1)` на `N + 1` інтервалів, довжини яких приймають **не більше ніж три різних значення**. Цей результат показує глибоку арифметичну впорядкованість ірраціональних ротацій.
