# ⚙️ Алгоритми обчислення дискрепантності та Квазі-Монте-Карло інтегрування

Практичне вимірювання рівномірності розподілу спирається на точний обчислювальний алгоритм зіркової дискрепантності D*N, обчислення тригонометричних сум Вейля та чисельне порівняння квазі-Монте-Карло інтегрування з класичним методом Монте-Карло мовами C, C++ та Python.

---

## 1. Геометрична та алгоритмічна концепція одновимірної дискрепантності

Для скінченної одновимірної послідовності точок `x₁, x₂, ..., x_N ∈ [0, 1)` зіркова дискрепантність `D_N*` визначається як найбільше абсолютне відхилення емпіричної функції розподілу `F_N(x)` від ідеальної прямолінійної залежності `y = x`:

```
D_N* = sup_{x ∈ [0, 1]} | F_N(x) − x |
```

де емпірична функція розподілу виражає відносну частку точок послідовності, які лежать строго лівіше від порогового значення `x`:

```
F_N(x) = (1 / N) · # { 1 ≤ n ≤ N : xₙ < x }
```

Геометричний зміст цієї величини полягає у вимірюванні найбільшого локального дисбалансу густини. Якщо точки розташовані абсолютно рівномірно, то для будь-якої координати `x` частка точок `F_N(x)` має бути якомога ближчою до `x`. Якщо ж у деяких регіонах утворюються "натовпи" або "порожнечі", значення `F_N(x)` починає суттєво відхилятися від лінії `y = x`.

Пряма чисельна оцінка супремуму вимагала б нескінченного перебору всіх дійсних точок `x` на інтервалі `[0, 1]`, що математично неможливо. Проте графік емпіричної функції розподілу `F_N(x)` має дуже специфічну структуру. Він є східчастою функцією, яка складається з горизонтальних відрізків і має розриви першого роду (скачки у висоту `1/N`) точно у тих точках `xₙ`, які входять до складу вибірки.

Між сусідніми точками вибірки значення `F_N(x)` залишається абсолютно сталим (горизонтальна лінія), тоді як функція ідеального розподілу `y = x` є суворо зростаючою з постійним кутовим коефіцієнтом. Оскільки відхилення `|F_N(x) − x|` є різницею між константою та лінійно зростаючою функцією, локальні максимуми цієї різниці можуть досягатися виключно у крайніх точках кожного горизонтального відрізка.

Це означає, що точками кандидатів на глобальний максимум відхилення є виключно граничні значення біля розривів:
1. Значення безпосередньо у точці стрибка `x_i`, де висота сходинки `F_N(x)` вискакує до значення `i / N`.
2. Значення у лівій границі `x_i⁻` безпосередньо перед стрибком, де висота сходинки ще дорівнює `(i − 1) / N`.

Якщо попередньо впорядкувати всі точки вибірки за зростанням `0 ≤ x₁ ≤ x₂ ≤ ... ≤ x_N < 1`, складну непреривну оптимізаційну задачу можна звести до точного скінченного алгоритму, який виконується за час `O(N log N)`:

```
D_N* = max_{1 ≤ i ≤ N} max( | (i / N) − x_i |, | ((i − 1) / N) − x_i | )
```

Головним обчислювальним етапом цього алгоритму є сортування масиву дійсних чисел. Після сортування за час `O(N log N)` алгоритм виконує один лінійний прохід `O(N)`, порівнюючи два значення відхилення для кожного елемента й знаходячи абсолютний максимум.

## 2. Генерання низькодискрепантних послідовностей Ван дер Корпута

Для проведення порівняльного чисельного аналізу збіжності у програмах застосовують генератор послідовностей Ван дер Корпута (*Van der Corput*).

Послідовність Ван дер Корпута за цілою основою `b ≥ 2` є класичним прикладом детермінованої послідовності із низькою дискрепантністю `D_N* = O(log N / N)`. Вона будується за допомогою операції радикальної інверсії (дзеркального відображення цифр) у `b`-арній позиційній системі числення.

Будь-яке ціле невід'ємне число `n ≥ 0` у позиційній системі числення за основою `b` розкладається у скінченну суму за степенями `b`:

```
n = a₀ + a₁ · b + a₂ · b² + ... + aₖ · bᵏ
```

де кожна цифра `aⱼ` належить скінченній множині `{0, 1, ..., b − 1}`.

Функція радикальної інверсії `ϕ_b(n)` переносить ці цифри за десяткову кому у зворотному порядку:

```
ϕ_b(n) = a₀ · b⁻¹ + a₁ · b⁻² + a₂ · b⁻³ + ... + aₖ · b⁻ᵏ⁻¹
```

Результат `ϕ_b(n)` строго належить напівінтервалу `[0, 1)`. При послідовному збільшенні `n = 1, 2, 3...` генерується детермінована послідовність точок, яка рівномірно заповнює одиничний інтервал. Точки послідовності Ван дер Корпута мають властивість "відштовхуватися" одна від одної: кожне нове значення випадає у найбільшу з наявних прогалин між попередніми точками.

## 3. Порівняння методу Квазі-Монте-Карло з класичним Монте-Карло

При обчисленні визначених інтегралів `I = ∫₀¹ f(t) dt` традиційний метод Монте-Карло генерує `N` псевдовипадкових чисел `uₙ ∈ [0, 1)` і оцінює інтеграл як середнє арифметичне `I_MC = (1/N) ∑ f(uₙ)`. 

За центральною граничною теоремою теорії ймовірностей, статистична похибка класичного Монте-Карло спадає зі швидкістю `O(σ / √N)`, де `σ²` — дисперсія функції `f`. Щоб зменшити похибку обчислення у `10` разів, метод Монте-Карло вимагає збільшення кількості точок у `100` разів.

Метод Квазі-Монте-Карло (QMC) замінює псевдовипадкові числа детермінованими низькодискрепантними послідовностями (наприклад, послідовністю Ван дер Корпута або Соболя). 

За теоремою Коксми — Главки, верхня межа похибки Квазі-Монте-Карло прямо пропорційна зірковій дискрепантності `D_N*`:

```
| I_QMC − I | ≤ V(f) · D_N*
```

Оскільки для низькодискрепантних послідовностей `D_N* = O(log N / N)`, похибка чисельного інтегрування спадає майже як `O(1 / N)`. Це означає, що для зменшення похибки у `10` разів методу QMC потрібно лише у `10` разів більше точок.

```c
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

#ifndef M_PI
#define M_PI 3.14159265358979323846
#endif

/* Компаратор для порівняння чисел плаваючої крапки у qsort */
static int compare_doubles(const void *a, const void *b) {
    double da = *(const double *)a;
    double db = *(const double *)b;
    if (da < db) return -1;
    if (da > db) return 1;
    return 0;
}

/* Точне обчислення зіркової дискрепантності D*N за O(N log N) */
double compute_star_discrepancy(const double *pts, size_t n) {
    if (n == 0) return 0.0;
    
    /* Виділення пам'яті під копію для сортування */
    double *sorted = (double *)malloc(n * sizeof(double));
    if (!sorted) return -1.0;
    
    /* Заганяємо значення у напівінтервал [0, 1) */
    for (size_t i = 0; i < n; i++) {
        double val = fmod(pts[i], 1.0);
        if (val < 0.0) val += 1.0;
        sorted[i] = val;
    }
    
    /* Сортування точок за зростанням O(N log N) */
    qsort(sorted, n, sizeof(double), compare_doubles);
    
    double max_diff = 0.0;
    double inv_n = 1.0 / (double)n;
    
    /* Обчислення максимальної вертикальної відстані */
    for (size_t i = 0; i < n; i++) {
        double current_i = (double)(i + 1) * inv_n;
        double previous_i = (double)i * inv_n;
        
        double diff1 = fabs(current_i - sorted[i]);
        double diff2 = fabs(previous_i - sorted[i]);
        
        if (diff1 > max_diff) max_diff = diff1;
        if (diff2 > max_diff) max_diff = diff2;
    }
    
    free(sorted);
    return max_diff;
}

/* Модуль нормованої тригонометричної суми Вейля (1/N) * |sum e^(2pi i h x_n)| */
double compute_weyl_sum(const double *pts, size_t n, int h) {
    if (n == 0) return 0.0;
    
    double re_sum = 0.0;
    double im_sum = 0.0;
    
    for (size_t i = 0; i < n; i++) {
        double angle = 2.0 * M_PI * (double)h * pts[i];
        re_sum += cos(angle);
        im_sum += sin(angle);
    }
    
    double mod = sqrt(re_sum * re_sum + im_sum * im_sum);
    return mod / (double)n;
}

/* Функція радикальної інверсії для послідовності Ван дер Корпута */
double van_der_corput(size_t n, size_t base) {
    double q = 0.0;
    double bk = 1.0 / (double)base;
    while (n > 0) {
        q += (double)(n % base) * bk;
        n /= base;
        bk /= (double)base;
    }
    return q;
}

int main(void) {
    size_t N = 1000;
    double phi = (sqrt(5.0) - 1.0) / 2.0; /* Золотий перетин */
    
    double *golden_seq = (double *)malloc(N * sizeof(double));
    double *vdc_seq = (double *)malloc(N * sizeof(double));
    
    for (size_t i = 0; i < N; i++) {
        golden_seq[i] = fmod((i + 1) * phi, 1.0);
        vdc_seq[i] = van_der_corput(i + 1, 2);
    }
    
    double d_golden = compute_star_discrepancy(golden_seq, N);
    double d_vdc = compute_star_discrepancy(vdc_seq, N);
    double w_golden = compute_weyl_sum(golden_seq, N, 1);
    
    printf("Дискрепантність {n*phi} (N=%zu): %.6f\n", N, d_golden);
    printf("Дискрепантність Ван дер Корпута (N=%zu): %.6f\n", N, d_vdc);
    printf("Сума Вейля |S_N(1)|/N для {n*phi}: %.6f\n", w_golden);
    
    free(golden_seq);
    free(vdc_seq);
    return 0;
}
```

```cpp
// Точне обчислення зіркової дискрепантності D*N для std::vector<double>
double compute_star_discrepancy(const std::vector<double>& pts) {
    if (pts.empty()) return 0.0;
    
    std::vector<double> sorted(pts.size());
    for (size_t i = 0; i < pts.size(); ++i) {
        double val = std::fmod(pts[i], 1.0);
        if (val < 0.0) val += 1.0;
        sorted[i] = val;
    }
    
    // Ідіоматичне сортування C++
    std::sort(sorted.begin(), sorted.end());
    
    const size_t n = sorted.size();
    const double inv_n = 1.0 / static_cast<double>(n);
    double max_diff = 0.0;
    
    for (size_t i = 0; i < n; ++i) {
        double current_i = static_cast<double>(i + 1) * inv_n;
        double previous_i = static_cast<double>(i) * inv_n;
        
        double diff1 = std::abs(current_i - sorted[i]);
        double diff2 = std::abs(previous_i - sorted[i]);
        
        max_diff = std::max({max_diff, diff1, diff2});
    }
    
    return max_diff;
}

// Обчислення тригонометричної суми Вейля з використанням std::complex
double compute_weyl_sum(const std::vector<double>& pts, int h) {
    if (pts.empty()) return 0.0;
    
    std::complex<double> sum(0.0, 0.0);
    const double two_pi = 2.0 * std::numbers::pi;
    
    for (double x : pts) {
        double angle = two_pi * h * x;
        sum += std::complex<double>(std::cos(angle), std::sin(angle));
    }
    
    return std::abs(sum) / static_cast<double>(pts.size());
}

        q += static_cast<double>(n % base) * bk;
        n /= base;
        bk /= static_cast<double>(base);
    }
    return q;
}
```

```py
import math

def compute_star_discrepancy(pts: list[float]) -> float:
    """Обчислення зіркової дискрепантності D*N за O(N log N)."""
    if not pts:
        return 0.0
    
    # Нормалізація та сортування
    sorted_pts = sorted([x % 1.0 for x in pts])
    n = len(sorted_pts)
    inv_n = 1.0 / n
    
    max_diff = 0.0
    for i, x in enumerate(sorted_pts):
        diff1 = abs((i + 1) * inv_n - x)
        diff2 = abs(i * inv_n - x)
        if diff1 > max_diff:
            max_diff = diff1
        if diff2 > max_diff:
            max_diff = diff2
            
    return max_diff

def compute_weyl_sum(pts: list[float], h: int) -> float:
    """Обчислення тригонометричної суми Вейля (1/N) * |sum e^(2pi i h x_n)|."""
    if not pts:
        return 0.0
    
    two_pi = 2.0 * math.pi
    re_sum = sum(math.cos(two_pi * h * x) for x in pts)
    im_sum = sum(math.sin(two_pi * h * x) for x in pts)
    
    return math.hypot(re_sum, im_sum) / len(pts)

def van_der_corput(n: int, base: int = 2) -> float:
    """Генератор послідовності Ван дер Корпута."""
    q, bk = 0.0, 1.0 / base
    while n > 0:
        q += (n % base) * bk
        n //= base
        bk /= base
    return q
```

## 5. Оцінка чисельної стабільності та пастки реалізації

1. **Крайові значення у математичних операціях.** Під час застосування оператора `fmod(x, 1.0)` через чисельні похибки форматів `double` або `float` значення іноді може дорівнювати точно `1.0` або ставати від'ємним (`-0.0000000000000001`). Необхідно явно притискати значення до діапазону `[0, 1)`.
2. **Пастка відсутності сортування.** Алгоритм обчислення зіркової дискрепантності критично залежить від впорядкованості елементів. Спроба обчислити формулу на несортованому масиві дасть некоректний результат порядку `O(1)` для будь-якої послідовності.
3. **Обчислювальний бар'єр у багатьох вимірах.** У 1D просторі дискрепантність обчислюється точним алгоритмом `O(N log N)`. Проте у `d`-вимірному просторі (`d ≥ 2`) обчислення зіркової дискрепантності перетворюється на NP-важку задачу (доведено Матушеком і Недеррайтером). На практиці у багатовимірних застосуваннях для `d > 3` замість точного `D_N*` використовують `L₂`-дискрепантність за формулою Варнока або нижні межі Ердеша — Турана — Коксми.
4. **Вибір основи для послідовностей Ван дер Корпута.** При розширенні генератора на декілька вимірів основи `b₁, b₂, ..., b_d` повинні бути строго взаємно простими числами (зазвичай обирають послідовні прості числа `2, 3, 5, 7, 11...`). Якщо обрати складені чи кратні основи (наприклад `b₁ = 2` та `b₂ = 4`), двовимірні точки вироджуються у діагональні лінії, втрачаючи рівномірність.
