# ⚙️ Генератор послідовностей Фарея та раціональне наближення

Алгоритми генерації послідовностей Фарея застосовуються у комп'ютерній графіці, цифровому обробленні сигналів, криптографії, системному програмуванні та механічному інжинірингу для швидкого перебору нескоротних дробів без використання обчислень із рухомою комою. У цій вставці розібрано два ключові прикладні алгоритми: послідовний генератор `Fₙ` із постійною пам'яттю `O(1)` та бінарний пошук найкращого раціонального наближення дійсного числа за допомогою дерев медіант Стерна — Броко.

### Послідовний генератор з пам'яттю O(1): математичний вивід та алгоритмічна побудова

Найпростіший спосіб сформувати послідовність Фарея порядку `n` — це згенерувати всі можливі пари цілих чисел `(a, b)` для `1 ≤ b ≤ n` та `0 ≤ a ≤ b`, відфільтрувати скоротні дроби за допомогою алгоритму Евкліда (перевіряючи умову `НСД(a, b) = 1`), а потім відсортувати отриманий масив за зростанням величини `a/b`. Проте такий лобовий метод потребує збереження `O(n²)` елементів у пам'яті та виконує `O(n² log n)` порівнянь при сортуванні. Для великих значень `n` (наприклад, `n = 100000`, де послідовність містить понад 3 мільярди дробів) цей підхід вимагатиме гігабайти оперативної пам'яті та тривалий час обчислень на центральному процесорі.

На щастя, глибока алгебраїчна структура послідовностей Фарея дозволяє повністю уникнути сортування та виділення динамічної пам'яті під масиви. Виведемо математичну формулу, яка дозволяє обчислити наступний дріб послідовності за двома попередніми.

Розглянемо три послідовні дроби `a/b < c/d < e/f` у послідовності `Fₙ`. Оскільки вони є сусідніми, для кожної пари справджуються фундаментальні детермінантні тотожності Фарея:

```
b·c − a·d = 1
d·e − c·f = 1
```

Домножимо першу тотожність на `e`, а другу на `a`, і додамо отримані рівняння:

```
e·(b·c − a·d) + a·(d·e − c·f) = e·1 + a·1
e·b·c − e·a·d + a·d·e − a·c·f = e + a
c·(e·b − a·f) = e + a
```

Аналогічно, домноживши першу тотожність на `f`, а другу на `b`, отримуємо для знаменників:

```
c·(f·b − b·f) + d·(e·b − a·f) = f + b
d·(e·b − a·f) = f + b
```

Оскільки чисельник `c` та знаменник `d` є взаємно простими (`НСД(c, d) = 1`), число `(e·b − a·f)` має бути цілим ділителем, яке позначимо як цілий коефіцієнт `k`:

```
k = (e + a) / c = (f + b) / d
```

Звідси виражаємо чисельник `e` та знаменник `f` наступного дробу через коефіцієнт `k`:

```
e = k·c − a
f = k·d − b
```

Оскільки дріб `e/f` є елементом послідовності `Fₙ`, його знаменник `f` за визначенням не може перевищувати граничний порядок `n`:

```
k·d − b ≤ n
k·d ≤ n + b
k ≤ (n + b) / d
```

Оскільки `e/f` має бути найближчим наступним дробом у послідовності, коефіцієнт `k` повинен братися максимально можливим цілим числом, тобто дробова частина відкидається (застосовується операція цілочислового ділення):

```
k = ⌊ (n + b) / d ⌋
```

Ця формула є ключем до ідеального генератора. Вона показує, що для знаходження **наступного** дробу `e/f` нам не потрібно знати всю послідовність і не потрібно зберігати масиви — достатньо пам'ятати лише **два попередні дроби** `a/b` та `c/d`.

Стартуючи з двох перших дробів `0/1` та `1/n`, ми робимо крок за кроком, обчислюючи `k`, знаходячи новий дріб `e/f` і зсуваючи ковзне вікно з трьох елементів. Процес завершується природним чином, коли черговий дріб досягає значення `1/1`.

Простежимо роботу цього алгоритму на конкретному обчислювальному прикладі для `n = 5`. На кожному кроці ми обчислюємо коефіцієнт `k = ⌊(5+b)/d⌋`, знаходимо `e = k·c − a` та `f = k·d − b`, після чого зсуваємо параметри `(a,b) ← (c,d)` та `(c,d) ← (e,f)`:

На першому кроці маємо `a/b = 0/1` та `c/d = 1/5`. Знаходимо `k = ⌊(5+1)/5⌋ = 1`. Обчислюємо `e = 1·1 − 0 = 1`, `f = 1·5 − 1 = 4`. Новий дріб: `1/4`.

На другому кроці маємо `a/b = 1/5` та `c/d = 1/4`. Знаходимо `k = ⌊(5+5)/4⌋ = 2`. Обчислюємо `e = 2·1 − 1 = 1`, `f = 2·4 − 5 = 3`. Новий дріб: `1/3`.

На третьому кроці маємо `a/b = 1/4` та `c/d = 1/3`. Знаходимо `k = ⌊(5+4)/3⌋ = 3`... чекайте, `(5+4)/3 = 3`, `e = 3·1 − 1 = 2`, `f = 3·3 − 4 = 5`. Новий дріб: `2/5`.

На четвертому кроці маємо `a/b = 1/3` та `c/d = 2/5`. Знаходимо `k = ⌊(5+3)/5⌋ = 1`. Обчислюємо `e = 1·2 − 1 = 1`, `f = 1·5 − 3 = 2`. Новий дріб: `1/2`.

На п'ятому кроці маємо `a/b = 2/5` та `c/d = 1/2`. Знаходимо `k = ⌊(5+5)/2⌋ = 5`... ні, `(5+5)/2 = 5`, `e = 5·1 − 2 = 3`, `f = 5·2 − 5 = 5`. Новий дріб: `3/5`.

На шостому кроці маємо `a/b = 1/2` та `c/d = 3/5`. Знаходимо `k = ⌊(5+2)/5⌋ = 1`. Обчислюємо `e = 1·3 − 1 = 2`, `f = 1·5 − 2 = 3`. Новий дріб: `2/3`.

На сьомому кроці маємо `a/b = 3/5` та `c/d = 2/3`. Знаходимо `k = ⌊(5+5)/3⌋ = 3`. Обчислюємо `e = 3·2 − 3 = 3`, `f = 3·3 − 5 = 4`. Новий дріб: `3/4`.

На восьмому кроці маємо `a/b = 2/3` та `c/d = 3/4`. Знаходимо `k = ⌊(5+3)/4⌋ = 2`. Обчислюємо `e = 2·3 − 2 = 4`, `f = 2·4 − 3 = 5`. Новий дріб: `4/5`.

На дев'ятому кроці маємо `a/b = 3/4` та `c/d = 4/5`. Знаходимо `k = ⌊(5+4)/5⌋ = 1`. Обчислюємо `e = 1·4 − 3 = 1`, `f = 1·5 − 4 = 1`. Новий дріб: `1/1`. Генерацію завершено.

### Пошук найкращого раціонального наближення за допомогою дерев медіант

У багатьох прикладно-інженерних задачах виникає зворотна задача: дано довільне дійсне число `x ∈ (0, 1)` (наприклад, константу `π − 3 = 0.14159265...` або коефіцієнт теплового розширення матеріалу) і поріг знаменника `max_den`. Необхідно знайти нескоротний дріб `p/q` зі знаменником `q ≤ max_den`, який лежить найближче до `x`.

Найефективніший спосіб розв'язання цієї задачі спирається на бінарний пошук по дереву медіант Стерна — Броко (або двосторонній пошук Фарея). Ми підтримуємо інтервал `[left, right]`, який спочатку дорівнює `[0/1, 1/1]`. На кожному кроці ми будуємо медіанту `med = (left.num + right.num) / (left.den + right.den)`:

1. Якщо знаменник медіанти `med.den` перевищує заданий поріг `max_den`, ми більше не можемо поглиблювати пошук у дану гілку. Ми зупиняємося і обираємо серед двох меж `left` та `right` той дріб, який має меншу абсолютну похибку до `x`.
2. Якщо знаменник медіанти задовольняє обмеження (`med.den ≤ max_den`), ми порівнюємо значення медіанти з цільовим числом `x`:
   - Якщо `x > med`, шукане число лежить у правому підінтервалі, тож ми оновлюємо ліву межу: `left = med`.
   - Якщо `x < med`, шукане число лежить у лівому підінтервалі, тож оновлюємо праву межу: `right = med`.
   - Якщо `x == med`, ми знайшли точний збіг і негайно повертаємо `med`.

Складність цього алгоритму є логарифмічною `O(log max_den)` від обмеження знаменника, що робить його незрівнянно швидшим за повний перебір усіх можливих знаменників.

Порівняємо пошук по дереву Фарея з розкладом у [ланцюгові дроби](root:math-number-theory/continued-fractions). Ланцюгові дроби видають послідовність найкращих підхідних дробів першого роду (які швидко зростають у знаменниках). Проте якщо нам потрібне найкраще раціональне наближення з жорстким обмеженням знаменника `q ≤ N`, підхідний дріб ланцюгового дробу може «перестрибнути» поріг `N`, тоді як бінарний пошук по дереву Фарея послідовно перебирає всі проміжні дроби другого роду і дає гарантовано точну відповідь під заданий поріг `N`.

### Практичні пастки, переповнення та чисельна стійкість

При практичній реалізації алгоритмів Фарея на реальному апаратному забезпеченні слід враховувати кілька важливих обчислювальних нюансів:

1. **Цілочислове переповнення:** При обчисленні коефіцієнта `k = (n + b) / d` вираз `k·c` або `k·d` може виходити за межі стандартного знакового 32-бітного типу `int32_t` для `n > 46000`. У промисловому коді чисельники й знаменники слід оголошувати типом `int64_t`.
2. **Уникнення плаваючої коми при порівнянні:** У бінарному пошуку порівняння `target_val > med_val` за допомогою чисел із комою (`double`) може призводити до помилкових розгалужень через округлення в двійковому форматі IEEE 754. Якщо вхідне число `x` сама задане раціональним дробом `target_num / target_den`, порівняння краще виконувати строго у цілих числах через перехресний добуток:
   ```
   target_num · med_den  >  target_den · med_num
   ```
   Це гарантує абсолютну математичну точність алгоритму без жодних похибок дискретизації.
3. **Застосування у цифрових синтезаторах частоти (DDS):** У генераторах прямого цифрового синтезу (Direct Digital Synthesis) фазовий накопичувач підсумовує цілочисловий крок `M` у регістрах шириною `B` бітів. Коефіцієнт поділу частоти становить `M / 2⩝`. Для синтезу точної аналогової частоти без паразитного фазового джитера використовують дроби Фарея, щоб розрахувати оптимальний крок `M` та модуль накопичувача `N`, які мінімізують фазову похибку при обмеженому розмірі регістрів ПЛІС (FPGA).
