# 🧮 Доведення властивостей послідовностей Фарея та кіл Форда

Послідовність Фарея порядку `n` — це не просто список впорядкованих дробів, а суворо впорядкована алгебраїчна система, де кожен елемент жорстко зв'язаний із сусідніми цілочисловими тотожностями. Тут наведено детальні математичні доведення п'яти головних теорем: властивості детермінанта сусідніх дробів, єдиності відсутності проміжних дробів, правила вставки медіанти, геометричної умови дотику кіл Форда та асимптотики довжини послідовності через функцію Ейлера та дзета-функцію Рімана.

### 1. Теорема про сусідні дроби (детермінант Фарея)

**Теорема 1.** Якщо `a/b` та `c/d` — два послідовні дроби у послідовності Фарея `Fₙ` такі, що `a/b < c/d`, то виконується сувора тотожність:

```
b·c − a·d = 1
```

**Доведення.**
Розглянемо різницю між сусідніми дробами у послідовності:

```
c/d − a/b
= (b·c − a·d) / (b·d)      [звели до спільного знаменника b·d]
```

Оскільки за умовою `a/b < c/d`, чисельник `k = b·c − a·d` є суворо додатним цілим числом, тобто `k ≥ 1`. Наша мета — довести, що `k` не може бути більшим за 1.

Припустимо від супротивного, що `k > 1`.
Оскільки дроби `a/b` та `c/d` належать `Fₙ`, їхні знаменники `b` та `d` не перевищують `n`. За [співвідношенням Безу](topic:math-number-theory/bezout-identity) для взаємно простих чисел `b` та `d` (які не мають спільних дільників) існують такі цілі числа `x` та `y`, що:

```
b·y − a·x = 1
```

Звідси можна підібрати дріб `x/y` зі знаменником `y ≤ n`, який задовольняє подвійну нерівність:

```
a     x     c
─  <  ─  <  ─
b     y     d
```

Проведемо детальну перевірку лівої та правої нерівностей через обчислення відповідних різниць:

```
x/y − a/b
= (b·x − a·y) / (b·y)      [звели до спільного знаменника b·y]
= 1 / (b·y)                [підставили b·y − a·x = 1]
> 0                        [бо b > 0 та y > 0]

c/d − x/y
= (c·y − d·x) / (d·y)      [звели до спільного знаменника d·y]
= (k − 1) / (d·y)          [підставили c·y − d·x = k − 1]
≥ 0                        [бо k > 1 ⇒ k − 1 ≥ 1]
```

Оскільки за нашим припущенням `k > 1`, чисельник `k − 1 ≥ 1`, отже, дріб `x/y` лежить суворо між `a/b` та `c/d`. Але знаменник `y` не перевищує `n`, тому дріб `x/y` мав би входити до послідовності Фарея `Fₙ` між `a/b` та `c/d`. Це суперечить тому, що `a/b` та `c/d` є сусідніми у `Fₙ`.

Таким чином, припущення `k > 1` приводить до алгебраїчної суперечності. Отже, `k = b·c − a·d = 1`. Теорему доведено. ∎

### 1b. Теорема про неможливість проміжного дробу

**Теорема 1b.** Якщо для двох дробів `a/b` та `c/d` виконується рівність `b·c − a·d = 1`, то жоден інший нескоротний дріб `x/y` зі знаменником `y ≤ b + d − 1` не може лежати суворо між `a/b` та `c/d`.

**Доведення.**
Нехай `x/y` — дріб такий, що `a/b < x/y < c/d`.
Розглянемо різниці:

```
x/y − a/b = (b·x − a·y) / (b·y) ≥ 1 / (b·y)    [бо b·x − a·y ≥ 1]
c/d − x/y = (c·y − d·x) / (d·y) ≥ 1 / (d·y)    [бо c·y − d·x ≥ 1]
```

Додамо ці дві нерівності:

```
c/d − a/b
= (x/y − a/b) + (c/d − x/y)
≥ 1 / (b·y) + 1 / (d·y)                       [підставили нижні оцінки]
= (b + d) / (b·d·y)                           [звели до спільного знаменника]
```

З іншого боку, за умовою теореми `c/d − a/b = (b·c − a·d) / (b·d) = 1 / (b·d)`.

Отримуємо подвійну нерівність:

```
1 / (b·d) ≥ (b + d) / (b·d·y)
```

Помноживши обидві частини на `b·d · y > 0`, дістаємо:

```
y ≥ b + d
```

Це означає, що знаменник будь-якого проміжного дробу `x/y` обов'язково є не меншим за суму знаменників `b + d`. Отже, жоден дріб зі знаменником `y < b + d` не може потрапити у цей проміжок. Це пояснює, чому у послідовності `Fₙ` між сусідніми дробами `a/b` та `c/d` не може виникнути жодного нового дробу, поки граничний порядок не досягне значення `n = b + d`. Теорему доведено. ∎

### 2. Властивість медіанти та взаємна простота

**Теорема 2.** Для двох сусідніх дробів `a/b` та `c/d` з `Fₙ` їхня медіанта `m = (a+c)/(b+d)` задовольняє три суворі умови:
1. Медіанта лежить суворо між батьківськими дробами: `a/b < (a+c)/(b+d) < c/d`.
2. Чисельник `(a+c)` та знаменник `(b+d)` є взаємно простими числами.
3. Медіанта утворює з кожним із батьків таку ж детермінантну тотожність одиниці.

**Доведення.**

Перевіримо першу умову обчисленням різниць між медіантою та лівим дробом:

```
(a+c)/(b+d) − a/b
= (b·(a+c) − a·(b+d)) / (b·(b+d))   [звели до спільного знаменника]
= (b·a + b·c − a·b − a·d) / (b·(b+d)) [розкрили дужки]
= (b·c − a·d) / (b·(b+d))             [скоротили b·a та −a·b]
= 1 / (b·(b+d))                       [підставили тотожність b·c − a·d = 1]
```

Оскільки `b > 0` та `b+d > 0`, різниця суворо додатна, отже `a/b < (a+c)/(b+d)`.

Аналогічно перевіримо різницю між правим дробом та медіантою:

```
c/d − (a+c)/(b+d)
= (c·(b+d) − d·(a+c)) / (d·(b+d))   [звели до спільного знаменника]
= (c·b + c·d − d·a − d·c) / (d·(b+d)) [розкрили дужки]
= (b·c − a·d) / (d·(b+d))             [скоротили c·d та −d·c]
= 1 / (d·(b+d))                       [підставили тотожність b·c − a·d = 1]
```

Різниця також суворо додатна, що доводить нерівність `(a+c)/(b+d) < c/d`.

Для доведення взаємної простоти чисельника `(a+c)` та знаменника `(b+d)` застосуємо лінійну комбінацію із коефіцієнтами `d` та `-c`:

```
d·(a+c) − c·(b+d)
= d·a + d·c − c·b − c·d     [розкрили дужки]
= d·a − c·b                 [скоротили d·c та −c·d]
= −(b·c − a·d)              [винесли мінус за дужки]
= −1                        [підставили b·c − a·d = 1]
```

Якщо чисельник `(a+c)` та знаменник `(b+d)` мали б спільний дільник `g > 1`, то `g` обов'язково ділив би їхню лінійну комбінацію, тобто число `-1`, що неможливо для натуральних чисел. Отже, `НСД(a+c, b+d) = 1`.

Нарешті, детермінантні тотожності медіанти з батьківськими дробами складають:
- З лівим дробом: `b·(a+c) − a·(b+d) = b·c − a·d = 1`.
- З правим дробом: `(b+d)·c − (a+c)·d = b·c − a·d = 1`.

Це означає, що вставка медіанти зберігає фундаментальну тотожність Фарея на усіх наступних рівнях розщеплення. Теорему доведено. ∎

### 2b. Теорема про довжину дуги Фарея

**Теорема 2b.** Нехай дріб `c/d` має лівого та правого сусідів `a/b` та `e/f` у послідовності `Fₙ`. Інтервал `[(a+c)/(b+d), (c+e)/(d+f)]` між медіантами називається дугою Фарея дробу `c/d`. Довжина цієї дуги дорівнює:

```
L(c/d) = (b + 2·d + f) / (d·(b + d)·(d + f))
```

**Доведення.**
Обчислимо довжину дуги як різницю правої та лівої медіант:

```
L(c/d)
= (c+e)/(d+f) − (a+c)/(b+d)
= [ (c+e)·(b+d) − (a+c)·(d+f) ] / [ (d+f)·(b+d) ]   [звели до спільного знаменника]
```

Розкриємо чисельник виразу:

```
(c+e)·(b+d) − (a+c)·(d+f)
= c·b + c·d + e·b + e·d − (a·d + a·f + c·d + c·f)   [розкрили дужки]
= (c·b − a·d) + (e·d − c·f) + e·b − a·f             [перегрупували доданки]
= 1 + 1 + e·b − a·f                                 [бо b·c − a·d = 1 та d·e − c·f = 1]
= 2 + e·b − a·f                                     [звели числа]
```

Використовуючи рекурентні співвідношення `e = k·c − a` та `f = k·d − b`, де `k = (b+f)/d`:

```
e·b − a·f
= (k·c − a)·b − a·(k·d − b)                         [підставили e та f]
= k·c·b − a·b − a·k·d + a·b                         [розкрили дужки]
= k·(b·c − a·d)                                     [скоротили a·b та винесли k]
= k·1 = k                                           [підставили b·c − a·d = 1]
= (b + f) / d                                       [підставили значення k]
```

Підставимо це значення у чисельник довжини дуги:

```
Чисельник = 2 + (b + f) / d = (2·d + b + f) / d     [звели до спільного знаменника d]
```

Ділимо чисельник на знаменник `(d+f)·(b+d)`:

```
L(c/d) = (b + 2·d + f) / (d·(b + d)·(d + f))
```

Ця формула визначає точний мікроскопічний розмір осередку впливу кожного дробу Фарея при раціональному наближенні. Теорему доведено. ∎

### 3. Геометрична теорема про дотик кіл Форда

**Теорема 3.** Колом Форда `C(p/q)` для нескоротного дробу `p/q` називається коло з центром у точці `(p/q, 1/(2q²))` та радіусом `r = 1/(2q²)`.

Два кола Форда `C(a/b)` та `C(c/d)` дотикаються одне одного тоді й лише тоді, коли дроби `a/b` та `c/d` є сусідніми у деякій послідовності Фарея (тобто `|b·c − a·d| = 1`). Якщо дроби не є сусідніми, їхні кола Форда не мають жодної спільної внутрішньої точки (не перетинаються з накладанням).

**Доведення.**

Обчислимо квадрат евклідової відстані `D²` між центрами кіл `C₁(a/b)` та `C₂(c/d)` у декартових координатах:

```
Центр C₁ = (a/b,  1/(2b²)),   радіус r₁ = 1/(2b²)
Центр C₂ = (c/d,  1/(2d²)),   радіус r₂ = 1/(2d²)

D² = (a/b − c/d)² + (1/(2b²) − 1/(2d²))²
```

Розкриємо квадрат різниці радіусів `(r₁ − r₂)²`:

```
(r₁ − r₂)² = (1/(2b²) − 1/(2d²))²
```

Сума радіусів у квадраті дорівнює:

```
(r₁ + r₂)²
= (1/(2b²) + 1/(2d²))²                         [формула квадрата суми]
= (1/(2b²) − 1/(2d²))² + 4·r₁·r₂               [тотожність (u+v)² = (u-v)² + 4uv]
= (1/(2b²) − 1/(2d²))² + 4·(1/(2b²))·(1/(2d²)) [підставили r₁ та r₂]
= (1/(2b²) − 1/(2d²))² + 1/(b²·d²)             [перемножили коефіцієнти]
```

Тепер знайдемо різницю між квадратом відстані між центрами `D²` та квадратом суми радіусів `(r₁ + r₂)²`:

```
D² − (r₁ + r₂)²
= (a/b − c/d)² + (r₁ − r₂)² − [ (r₁ − r₂)² + 1/(b²·d²) ] [підставили значення (r₁+r₂)²]
= (a/b − c/d)² − 1/(b²·d²)                               [скоротили (r₁−r₂)²]
= ( (b·c − a·d) / (b·d) )² − 1/(b²·d²)                   [звели a/b − c/d до спільного знаменника]
= ( (b·c − a·d)² − 1 ) / (b²·d²)                         [винесли спільний знаменник b²·d²]
```

Проаналізуємо вираз `((b·c − a·d)² − 1) / (b²·d²)`:

1. Якщо `|b·c − a·d| = 1` (дроби є сусідніми у послідовності Фарея), то `(b·c − a·d)² = 1`, звідки:
   `D² − (r₁ + r₂)² = 0  ⇒  D = r₁ + r₂`.
   Відстань між центрами точно дорівнює сумі радіусів, що означає **зовнішній геометричний дотик** кіл у єдиній точці.

2. Якщо `|b·c − a·d| > 1` (дроби не є сусідніми), то цілочислове значення `(b·c − a·d)² ≥ 4`, звідки:
   `D² − (r₁ + r₂)² > 0  ⇒  D > r₁ + r₂`.
   Відстань між центрами суворо більша за суму радіусів, отже, кола **повністю рознесені у просторі і не мають спільних точок**.

Таким чином, жодна пара кіл Форда ніколи не перетинається із заходженням одне в одне. Вони або торкаються зовні у єдиній точці, або рознесені у просторі. Теорему доведено. ∎

### 4. Асимптотика кількості членів у послідовності Фарея

**Теорема 4.** Кількість елементів `|Fₙ|` у послідовності Фарея порядку `n` задовольняє точну формулу:

```
|Fₙ| = 1 + ∑ₖ₌₁ⁿ φ(k)
```

де `φ(k)` — [функція Ейлера](topic:math-number-theory/euler-totient). Асимптотично при `n → ∞`:

```
|Fₙ| = (3 / π²) · n² + O(n · log n)
```

**Доведення.**

Для кожного знаменника `k` від 1 до `n` кількість нескоротних дробів `h/k` на проміжку `(0, 1]` за визначенням дорівнює кількості цілих чисел `h ∈ [1, k]`, взаємно простих із `k`. Це за визначенням є значення функції Ейлера `φ(k)`. Додаючи дріб `0/1` на початку, отримуємо точну суму `|Fₙ| = 1 + ∑ₖ₌₁ⁿ φ(k)`.

Для знаходження асимптотики застосуємо обернення Мебіуса для функції Ейлера `φ(k) = ∑ₛ╎ₖ μ(s)·(k/s)`:

```
∑ₖ₌₁ⁿ φ(k)
= ∑ₖ₌₁ⁿ ∑ₛ╎ₖ μ(s)·(k/s)                                [підставили формулу для φ(k)]
= ∑ₛ╎ₙ μ(s) · ∑ₘ₌₁────────ⁿᐟˢ m·s / s                  [поміняли порядок підсумовування, m = k/s]
= ∑ₛ╎ₙ μ(s) · (1/2) · ⌊n/s⌋ · (⌊n/s⌋ + 1)              [застосували формулу суми арифметичної прогресії]
= (1/2) · n² · ∑ₛ╎ₙ (μ(s) / s²) + O(n · log n)        [виділили головний член n²]
```

Відомо, що нескінченний ряд `∑ₛ₌₁∞ (μ(s) / s²) = 1 / ζ(2)`. Оскільки `ζ(2) = π² / 6` (класичний розв'язок Базельської задачі, знайдений Ойлером), маємо:

```
1 / ζ(2) = 6 / π²
```

Підставляючи це значення в асимптотичний вираз, отримуємо:

```
|Fₙ| ≈ (1/2) · n² · (6 / π²) = (3 / π²) · n² ≈ 0.30396 · n²
```

Таким чином, кількість дробів зростає квадратично від граничного знаменника `n`, а коефіціент `3/π²` безпосередньо пов'язаний із ймовірністю того, що два випадково обрані цілі числа виявляться взаємно простими. Теорему доведено. ∎
