# 𝔮 Алгебраїчне виведення формул групового закону, дискримінанта та інваріанта j

Строге алгебраїчне виведення координат суми точок `P + Q` та подвоєння `2·P` на еліптичній кривій, аналітичне виведення через `℘`-функцію Вейєрштрасса, обчислення дискримінанта через результант Сильвестра, поділкові многочлени, інваріантні диференціали, доведення асоціативності через теорему Келі–Бахараха та дивізори групи Пікара, теорія кривих Тейта, формальні групи, біраціональні ізоморфізми з моделями Монтгомері та Едвардса, канонічна висота Нерона–Тате, теорема Морделла–Вейля, теорема Луц–Нагеля, рівномірна обмеженість Мереля, L-функція Хассе–Вейля, гіпотеза BSD, алгоритм Шоофа–Елкіса–Аткіна (SEA), комплексне множення (CM), група Шафаревича–Тейта, модуль Тейта та представлення Галуа, модулярні форми та теорема Вайлса, алгоритм Міллера для спарювань, криптографія на спарюваннях, формули Велю для ізогеній та класифікація через `j`-інваріант.

Для аналітичної та програмної роботи з еліптичною кривою абстрактне геометричне правило «провести січну пряму та віддзеркалити точку перетину» необхідно перекласти точними алгебраїчними формулами у координатах `(x, y)`.

## 1. Геометрія плоских алгебраїчних кривих та формула степеня-роду

Алгебраїчною кривою називається геометричне місце точок проективної площини `ℙ²(K)`, однорідні координати `(X : Y : Z)` яких задовольняють поліноміальне рівняння `F(X, Y, Z) = 0`. Ступінь однорідного многочлена `d = deg(F)` визначає алгебраїчний порядок кривої:
- `d = 1`: проективні прямі;
- `d = 2`: конічні перерізи (кола, еліпси, параболи, гіперболи);
- `d = 3`: плоскі кубічні криві.

Топологічна та алгебраїчна природа гладкої кривої характеризується її **геометричним родом `g`**. Для будь-якої неподільної гладкої кривої степеня `d` у проективній площині рід визначається класичною **формулою степеня-роду (Degree-Genus Formula)**:
```
g = (d - 1) · (d - 2) / 2
```

Застосовуючи цю формулу для кривих різного порядку:
- Для прямої `d = 1`: рід `g = (0) · (-1) / 2 = 0`.
- Для коніки `d = 2`: рід `g = (1) · (0) / 2 = 0`. Будь-яка гладка коніка з раціональною точкою є раціональною кривою і допускає глобальну раціональну параметризацію через стереографічну проекцію, тому вона біраціонально ізоморфна проективній прямій `ℙ¹`.
- Для кубіки `d = 3`: рід `g = (2) · (1) / 2 = 1`. 

Значення роду `g = 1` є винятковим в усій алгебраїчній геометрії: за теоремою Абеля–Якобі, компактна ріманова поверхня роду `g = 1` володіє природною структурою неперервної комутативної абелевої групи, оскільки вона природно ізоморфна своєму многовиду Якобі `Jac(C) ≅ C`. Криві вищих степенів (`d ≥ 4`, де `g ≥ 3`) не можуть бути наділені груповою структурою безпосередньо на своїх геометричних точках.

Таким чином, **еліптична крива** за фундаментальним визначенням алгебраїчної геометрії — це **гладка проективна алгебраїчна крива роду `g = 1` з фіксованою базовою раціональною точкою `O`**, яка обирається як нейтральний елемент (нуль) групи.

## 2. Точки перегину кубіки, визначник Гессе та вибір нейтрального елемента

Нехай `F(X, Y, Z) = 0` — однорідний многочлен 3-го степеня, що задає гладку плоску кубічну криву `C`. Точка `P ∈ C` називається **точкою перегину (Inflection Point / Flex)**, якщо дотична пряма до кривої у цій точці має порядок дотику (кратність перетину) щонайменше 3.

Згідно з класичною диференціальною та алгебраїчною геометрією, точки перегину кривої визначаються спільним перетином кривої `C` з її **кривою Гессе (Hessian Curve)** `H(C) = 0`. Крива Гессе задається визначником матриці других часткових похідних (матриці Гессе):

```
H(F) = det [ ∂²F / (∂X_i ∂X_j) ]_{i,j ∈ {X, Y, Z}}
```

Оскільки `F` має степінь 3, кожна друга похідна `∂²F / (∂X_i ∂X_j)` є лінійною формою (степеня 1). Визначник матриці `3 × 3` має степінь `1 + 1 + 1 = 3`. Таким чином, крива Гессе `H(C)` також є кубічною кривою.

За **теоремою Безу**, дві кубічні криві `C` та `H(C)` без спільних компонент перетинаються у проективній площині рівно у `3 × 3 = 9` точках (з урахуванням кратності). Над алгебраїчно замкненим полем характеристики, відмінної від 2 і 3, усі 9 точок є простими. Отже, **будь-яка гладка плоска кубічна крива має рівно 9 точок перегину**.

Якщо обрати одну з цих точок перегину за базову точку `O`, а дотичну пряму в ній призначити нескінченно віддаленою прямою `Z = 0`, то в афінній карті `x = X/Z, y = Y/Z` точка перегину відходить у нескінченність `O = (0 : 1 : 0)`. Це геометрично усуває всі кубічні та перехресні члени, перетворюючи загальне рівняння на канонічну форму Вейєрштрасса.

## 3. Повне алгебраїчне зведення загальної кубіки до форми Вейєрштрасса

Загальне плоске кубічне рівняння від двох афінних змінних `x` та `y` над довільним числовим полем `K` містить 10 коефіцієнтів:

```
c₁·x³ + c₂·x²·y + c₃·x·y² + c₄·y³ + c₅·x² + c₆·x·y + c₇·y² + c₈·x + c₉·y + c₁₀ = 0
```

Якщо проективна кубічна крива у площині `ℙ²(K)` є гладкою (не має особливих точок) і володіє хоча б однією раціональною точкою `O`, її можна перевести проективним лінійним перетворенням до **довгої форми Вейєрштрасса**:

```
y² + a₁·x·y + a₃·y = x³ + a₂·x² + a₄·x + a₆
```
де `a₁, a₂, a₃, a₄, a₆ ∈ K` — сталі коефіцієнти поля `K`.

### 1. Зведення для полів характеристики `char(K) ≠ 2, 3`:
Якщо характеристика поля `K` не дорівнює 2 і 3 (зокрема для полів `ℚ`, `ℝ`, `ℂ` та для криптографічних простих полів `𝔽ₚ` при `p > 3`), довгоформатне рівняння зводиться до **короткої форми Вейєрштрасса**:

```
y² = x³ + a·x + b
```

Покрокове виведення з обґрунтуванням кожного кроку:

```
y² + (a₁·x + a₃)·y = x³ + a₂·x² + a₄·x + a₆                          [вихідне довге рівняння Вейєрштрасса]
(y + (a₁·x + a₃)/2)² - (a₁·x + a₃)²/4 = x³ + a₂·x² + a₄·x + a₆        [виділення повного квадрата за змінною y, char(K) ≠ 2]
(y + (a₁·x + a₃)/2)² = x³ + a₂·x² + a₄·x + a₆ + (a₁²·x² + 2·a₁·a₃·x + a₃²)/4  [перенесення квадрата доповнення праворуч]
y₁² = x³ + (a₂ + a₁²/4)·x² + (a₄ + a₁·a₃/2)·x + (a₆ + a₃²/4)        [заміна змінної y₁ = y + (a₁·x + a₃)/2]
4·y₁² = 4·x³ + (4·a₂ + a₁²)·x² + (4·a₄ + 2·a₁·a₃)·x + (4·a₆ + a₃²)   [домноження обох частин на 4 для цілочисельності]
y₂² = 4·x³ + b₂·x² + 2·b₄·x + b₆                                     [введення коефіцієнтів b₂ = a₁² + 4a₂, b₄ = 2a₄ + a₁a₃, b₆ = a₃² + 4a₆]
```

Тепер усунемо квадратичний член `b₂·x²` за допомогою лінійного зсуву змінної `x`:

```
y₂² = 4·(x + b₂/12)³ + ...                                           [виділення куба за змінною x, char(K) ≠ 3]
заміна x₂ = x + b₂/12,  y₃ = y₂ / 2                                   [масштабування координат]
y₃² = x₂³ + a·x₂ + b                                                 [скорочення квадратичного члена]
```
де підсумкові канонічні коефіцієнти виражаються як:
```
a = (4·b₄ - b₂²/3) / 16 = (24·a₁·a₃ + 48·a₄ - 8·a₁²·a₂ - 16·a₂² - a₁⁴) / 48
b = (b₆ - b₂·b₄/3 + 2·b₂³/27) / 16
```

### 2. Специфіка полів характеристики 2 (`char(K) = 2`):
У полі характеристики 2 ділення на 2 заборонено, тому короткої форми Вейєрштрасса не існує. Еліптичні криві поділяються на два неізоморфні класи:
- **Звичайні криві (Ordinary curves, `a₁ ≠ 0`):** заміна координат зводить рівняння до канонічної форми `y² + x·y = x³ + a₂·x² + a₆`. У цих кривих група 2-кручення ізоморфна `E[2] ≅ ℤ/2ℤ`.
- **Суперсингулярні криві (Supersingular curves, `a₁ = 0`):** заміна координат зводить рівняння до канонічної форми `y² + a₃·y = x³ + a₄·x + a₆`. Група 2-кручення є тривіальною: `E[2] = {O}`.

### 3. Специфіка полів характеристики 3 (`char(K) = 3`):
У полі характеристики 3 виділення квадрата по `y` дозволено, але усунення `x²` через ділення на 3 заборонено. Канонічна форма має вигляд:
```
y² = x³ + a₂·x² + a₆
```

## 4. Аналітичне виведення через двоперіодичну ℘-функцію Вейєрштрасса

Нехай `Λ = { m·ω₁ + n·ω₂ : m, n ∈ ℤ }` — решітка (гратка) у комплексній площині `ℂ`, породжена двома лінійно незалежними комплексними періодами `ω₁, ω₂ ∈ ℂ` (`Im(ω₂/ω₁) > 0`).

Функція `℘`-Вейєрштрасса визначається абсолютно збіжним рядом:
```
℘(z) = 1/z² + ∑_{w ∈ Λ\{0}} [ 1/(z - w)² - 1/w² ]
```

Розкладемо функцію `℘(z)` у ряд Лорана в околі точки `z = 0`:

```
1/(z - w)² = (1/w²) · (1 - z/w)⁻²                                    [винесення множника 1/w²]
(1 - z/w)⁻² = 1 + 2·(z/w) + 3·(z/w)² + 4·(z/w)³ + 5·(z/w)⁴ + ...     [біноміальний розклад]
1/(z - w)² - 1/w² = 2·z/w³ + 3·z²/w⁴ + 4·z³/w⁵ + 5·z⁴/w⁶ + ...       [віднімання сталого члена 1/w²]
```

Оскільки гратка `Λ` є центрально-симетричною (`w ∈ Λ ⇔ -w ∈ Λ`), усі суми з непарними степенями `∑_{w ≠ 0} 1/w^{2k+1} = 0` тотожно зникають. Вводячи ряди Ейзенштейна парної ваги `G₄ = ∑_{w ≠ 0} 1/w⁴` та `G₆ = ∑_{w ≠ 0} 1/w⁶`, отримуємо розклад:

```
℘(z) = 1/z² + 3·G₄·z² + 5·G₆·z⁴ + O(z⁶)                               [підсумовування парних членів]
℘'(z) = -2/z³ + 6·G₄·z + 20·G₆·z³ + O(z⁵)                             [почленне диференціювання за змінною z]
```

Обчислимо степені розкладів:

```
(℘'(z))² = 4/z⁶ - 24·G₄/z² - 80·G₆ + O(z²)                            [піднесення до квадрата похідної ℘'(z)]
(℘(z))³ = 1/z⁶ + 9·G₄/z² + 15·G₆ + O(z²)                              [піднесення до куба функції ℘(z)]
4·(℘(z))³ = 4/z⁶ + 36·G₄/z² + 60·G₆ + O(z²)                           [домноження куба на константу 4]
(℘'(z))² - 4·(℘(z))³ = -60·G₄/z² - 140·G₆ + O(z²)                     [віднімання двох розкладів Лорана]
```

Введемо модулярні інваріанти Вейєрштрасса `g₂ = 60·G₄` та `g₃ = 140·G₆`:

```
(℘'(z))² - 4·(℘(z))³ + g₂·℘(z) = -140·G₆ + O(z²) + g₂/z²             [додавання члена g₂·℘(z)]
(℘'(z))² - 4·(℘(z))³ + g₂·℘(z) + g₃ = O(z²)                          [додавання константи g₃]
```

Різниця `F(z) = (℘'(z))² - 4·(℘(z))³ + g₂·℘(z) + g₃` є:
1. Двоперіодичною функцією на торі `ℂ/Λ`: `F(z + ω) = F(z)`.
2. Голоморфною на всій комплексній площині `ℂ`, оскільки сингулярні члени `1/z⁶` та `1/z²` взаємно знищилися.
3. Обмеженою на компактному паралелограмі періодів.

За **теоремою Ліувілля**, будь-яка обмежена ціла функція є строгою константою. Оскільки `F(0) = 0`, ця константа дорівнює нулю тотожно:
```
(℘'(z))² = 4·(℘(z))³ - g₂·℘(z) - g₃
```

Поклавши `x = ℘(z)` та `y = ℘'(z)/2`, отримуємо канонічне алгебраїчне рівняння `y² = x³ + a·x + b` з параметрами `a = -g₂/4` та `b = -g₃/4`.

Аналітична теорема додавання для `℘`-функцій Вейєрштрасса стверджує:
```
℘(u + v) = -℘(u) - ℘(v) + (1/4) · [ (℘'(u) - ℘'(v)) / (℘(u) - ℘(v)) ]²
```
Це співвідношення строго доводить, що адитивне додавання комплексних чисел на торі `ℂ/Λ` є ізоморфним геометричному закону хорд і дотичних на плоскій кубічній кривій.

## 5. Покрокове алгебраїчне виведення додавання нерівних точок (P ≠ Q)

Нехай дано дві різні точки `P = (x₁, y₁)` та `Q = (x₂, y₂)` на неособливій кривій `y² = x³ + a·x + b` з умовою `x₁ ≠ x₂`.

Пряма лінія `L`, що проходить через точки `P` та `Q`, задається рівнянням `y = λ·(x - x₁) + y₁,` де нахил `λ` обчислюється як відношення різниці ординат до різниці абсцис:
```
λ = (y₂ - y₁) / (x₂ - x₁)
```

Щоб визначити всі спільні точки перетину прямої `L` та еліптичної кривої, підставимо вираз для `y` у рівняння кривої:

```
(λ·(x - x₁) + y₁)² = x³ + a·x + b                                     [підстановка рівняння прямої у кубіку]
λ²·(x - x₁)² + 2·λ·y₁·(x - x₁) + y₁² = x³ + a·x + b                   [розкриття квадрата лівої частини]
λ²·(x² - 2·x₁·x + x₁²) + 2·λ·y₁·x - 2·λ·y₁·x₁ + y₁² = x³ + a·x + b   [розкриття внутрішніх дужок]
x³ - λ²·x² + (a + 2·λ²·x₁ - 2·λ·y₁)·x + (b - y₁² + 2·λ·y₁·x₁ - λ²·x₁²) = 0 [зведення до кубічного многочлена]
```

Отримано приведений кубічний многочлен `P(x) = x³ + c₂·x² + c₁·x + c₀ = 0` зі старшим коефіцієнтом `1` та коефіцієнтом при `x²`, рівним `c₂ = -λ²`.

За основною теоремою алгебри та теоремою Безу пряма перетинає кубіку рівно у 3 точках `x₁, x₂, x₃` (з урахуванням кратності):

```
(x - x₁) · (x - x₂) · (x - x₃) = x³ - (x₁ + x₂ + x₃)·x² + ... = 0     [розклад многочлена за його коренями]
-(x₁ + x₂ + x₃) = c₂ = -λ²                                            [теорема Вієта для коефіцієнта при x²]
x₁ + x₂ + x₃ = λ²                                                     [множення рівності на -1]
x₃ = λ² - x₁ - x₂                                                     [вираження абсциси третьої точки перетину]
```

Знайдемо ординату третьої точки перетину `R = (x₃, y₃)` на прямій `L`:
```
y₃ = λ·(x₃ - x₁) + y₁                                                 [підстановка x₃ у рівняння прямої L]
```

За геометричним груповим законом сума точок `P + Q` визначається як відображення точки `R` відносно осі `Ox`:
```
P + Q = (x₄, y₄) = (x₃, -y₃)                                          [віддзеркалення третьої точки перетину]
x₄ = λ² - x₁ - x₂                                                     [фінальна формула абсциси суми]
y₄ = - (λ·(x₄ - x₁) + y₁) = λ·(x₁ - x₄) - y₁                          [фінальна формула ординати суми]
```

## 6. Покрокове алгебраїчне виведення подвоєння точки (P = Q)

Нехай задано точку `P = (x₁, y₁)` на кривій `y² = x³ + a·x + b`. При збігу точок `P = Q` січна пряма граничним переходом перетворюється на **дотичну пряму** до кривої у точці `P`.

Знайдемо нахил дотичної `λ = dy/dx` методом неявного диференціювання:

```
d/dx [ y² ] = d/dx [ x³ + a·x + b ]                                   [диференціювання обох частин рівняння]
2·y · (dy/dx) = 3·x² + a                                              [правило диференціювання складеної функції]
dy/dx = (3·x² + a) / (2·y)                                            [ділення на 2y, за умови y ≠ 0]
λ = (3·x₁² + a) / (2·y₁)                                              [обчислення нахилу у точці P=(x₁,y₁)]
```

Якщо `y₁ = 0`, дотична є строго вертикальною прямою `x = x₁`, яка перетинає криву у нескінченно віддаленій точці `O`, тому `2·P = O`.

При `y₁ ≠ 0` дотична має кратність дотику 2 у точці `x₁`. Застосовуючи теорему Вієта до кубічного многочлена:

```
x₁ + x₁ + x₃ = λ²                                                     [теорема Вієта з урахуванням кратності 2 точки x₁]
2·x₁ + x₃ = λ²                                                        [додавання однакових доданків]
x₃ = λ² - 2·x₁                                                        [вираження третьої точки перетину]
```

Віддзеркалюючи точку перетину відносно осі `Ox`:
```
x₄ = λ² - 2·x₁                                                        [абсциса подвоєної точки]
y₄ = λ·(x₁ - x₄) - y₁                                                 [ордината подвоєної точки]
```

## 7. Особливі кубічні криві та група регулярних точок

Якщо дискримінант кубічного многочлена дорівнює нулю, крива перестає бути гладкою і втрачає структуру компактної поверхні роду 1. Проте множина її неособливих точок `E_{ns}(K) = E(K) \setminus \{P_{sing}\}` все одно зберігає природну групову структуру хорд і дотичних!

Існують два топологічні типи особливих точок:

### 1. Вузлова кубіка (Node, `Δ = 0`, `a ≠ 0`):
У точці самоперетину дотичні прямі мають два різні дійсні або комплексні нахили. Рівняння зводиться до вигляду `y² = x² · (x + c)`.
- Якщо нахили дотичних належать базовому полю `K` (розщеплений вузол), група неособливих точок є ізоморфною мультиплікативній групі поля:
  ```
  E_{ns}(K) ≅ K* = K \setminus {0}
  ```
  Геометричний груповий закон хорд і дотичних на вузловій кубіці точно моделює звичайне множення ненульових чисел поля `u ↦ u₁ · u₂`.
- Якщо нахили лежать у квадратичному розширенні `K(√d)` (нерозщеплений вузол), група ізоморфна одиничному колу норми: `E_{ns}(K) ≅ { u ∈ K(√d)* : N(u) = 1 }`.

### 2. Каспідальна кубіка (Cusp, `Δ = 0`, `a = b = 0`):
Точка загострення має єдину дотичну подвійної кратності. Рівняння має канонічний вигляд `y² = x³`.
- Група неособливих точок каспідальної кривої є ізоморфною адитивній групі поля:
  ```
  E_{ns}(K) ≅ K⁺
  ```
  Груповий закон хорд і дотичних на каспі точно моделює звичайне додавання чисел поля `t ↦ t₁ + t₂` через раціональну параметризацію `x = t⁻², y = t⁻³`.

## 8. Обчислення дискримінанта через результант Сильвестра

Еліптична крива `y² = f(x) = x³ + a·x + b` є гладкою (неособливою) тоді й лише тоді, коли кубічний многочлен `f(x)` не має кратних коренів. Многочлен має кратний корінь тоді й тільки тоді, коли його результант із похідною `f'(x) = 3·x² + a` дорівнює нулю: `Res(f, f') = 0`.

Побудуємо матрицю Сильвестра розміру `5 × 5` для многочленів `f(x) = 1·x³ + 0·x² + a·x + b` та `f'(x) = 3·x² + 0·x + a`:

```
        | 1   0   a   b   0 |
        | 0   1   0   a   b |
S =     | 3   0   a   0   0 |
        | 0   3   0   a   0 |
        | 0   0   3   0   a |
```

Обчислимо визначник матриці Сильвестра `det(S)` методом розкладу за рядками:

```
det(S) = 1 · det(S₁₁) + 3 · det(S₃₁)                                  [розклад за першим стовпчиком]
... розкриття мінорів 4 × 4 ...
det(S) = 4·a³ + 27·b²                                                 [результат обчислення визначника]
```

Дискримінант кубічного многочлена `D` пов'язаний із результантом співвідношенням `D = -Res(f, f') = -(4·a³ + 27·b²)`. 

У теорії еліптичних кривих канонічний **дискримінант кривої `Δ`** нормують множником `16` (що відповідає дискримінанту відносно змінної `y`):
```
Δ = -16 · (4·a³ + 27·b²)
```

- Якщо `Δ ≠ 0`: крива неособлива (еліптична).
- Якщо `Δ = 0` та `a ≠ 0`: крива має **вузол (node)** з двома різними дотичними.
- Якщо `Δ = 0` та `a = b = 0`: крива має **касп (cusp)** — точку загострення `y² = x³`.

## 9. Класифікація через j-інваріант та викрути

**`j`-інваріант** еліптичної кривої визначається як:
```
j = 1728 · (4·a³) / (4·a³ + 27·b²) = -1728 · (4·a³) / Δ
```

### Властивості `j`-інваріанта:
1. Дві еліптичні криві `E₁` та `E₂` є ізоморфними над алгебраїчно замкненим полем `K̄` тоді і тільки тоді, коли `j(E₁) = j(E₂)`.
2. Для будь-якого значення `j₀ ∈ K` існує еліптична крива над `K`, чий `j`-інваріант дорівнює `j₀`.
3. **Квадратичні, четвертинні та шості викрути (Twists):**
   - Для загального `j ∉ {0, 1728}`: група автоморфізмів `Aut(E) ≅ ℤ/2ℤ` (`(x, y) ↦ (x, -y)`). Існують лише квадратичні викрути `d·y² = x³ + a·x + b`.
   - Для `j = 1728` (`a ≠ 0, b = 0`, крива `y² = x³ + a·x`): `Aut(E) ≅ ℤ/4ℤ` (`(x, y) ↦ (-x, i·y)`). Існують 4-кратні викрути (quartic twists).
   - Для `j = 0` (`a = 0, b ≠ 0`, крива `y² = x³ + b`): `Aut(E) ≅ ℤ/6ℤ` (`(x, y) ↦ (ζ₆²·x, -y)`). Існують 6-кратні викрути (sextic twists).

## 10. Строге доведення асоціативності групового закону

Асоціативність `(P + Q) + R = P + (Q + R)` є найскладнішою аксіомою групового закону. Нижче наведено два незалежні строгі доведення.

### Метод 1: Геометричне доведення через теорему Келі–Бахараха

> **Теорема Келі–Бахараха (Cayley–Bacharach):** Нехай `C₁` та `C₂` — дві кубічні криві у проективній площині `ℙ²`, що перетинаються у 9 різних точках `P₁, P₂, ..., P₉`. Якщо будь-яка кубічна крива `C₃` проходить через 8 з цих точок `P₁, ..., P₈`, то вона обов'язково проходить і через дев'яту точку `P₉`.

Нехай дано 3 точки `P, Q, R ∈ E`. Розглянемо 9 точок:
- `P₁ = P`, `P₂ = Q`, `P₃ = R`
- `P₄ = -(P + Q)`, `P₅ = -(Q + R)`
- `P₆ = P + Q`, `P₇ = Q + R`
- `P₈ = O` (точка на нескінченності)
- `P₉ = -((P + Q) + R)`

Побудуємо дві розкладні кубіки `C₁` та `C₂` як об'єднання прямих:
- `C₁ = Line(P, Q, -(P+Q)) ∪ Line(R, P+Q, -((P+Q)+R)) ∪ Line(Q+R, -(Q+R), O)`
- `C₂ = Line(Q, R, -(Q+R)) ∪ Line(P, Q+R, -(P+(Q+R))) ∪ Line(P+Q, -(P+Q), O)`

Обидві кубіки `C₁` та `C₂` проходять через точки `P₁, P₂, P₃, P₄, P₅, P₆, P₇, P₈`. Вихідна еліптична крива `E` є кубікою, яка за побудовою містить перші 8 точок. За теоремою Келі–Бахараха, крива `E` зобов'язана містити і точку `P₉`. Отже, дев'ята точка кривої `C₂` збігається з `P₉`, звідки:
```
-(P + (Q + R)) = -((P + Q) + R)  ⇒  (P + Q) + R = P + (Q + R)
```

### Метод 2: Алгебраїчне доведення через групу дивізорів та теорему Рімана–Роха

Нехай `Div(E)` — вільна абелева група дивізорів `D = ∑ n_P · (P)`. **Степенем дивізора** є `deg(D) = ∑ n_P`. Дивізор називається **головним**, якщо він є дивізором нулів та полюсів раціональної функції `f ∈ K(E)*`: `D = div(f)`. За теоремою про раціональні функції на кривих, для будь-якої `f` виконується `deg(div(f)) = 0`.

Фактор-група дивізорів степеня нуль `Div⁰(E)` за підгрупою головних дивізорів `Prin(E)` називається **групою Пікара**:
```
Pic⁰(E) = Div⁰(E) / Prin(E)
```

За **теоремою Рімана–Роха** для кривої роду `g = 1`, для будь-якого дивізора `D ∈ Div⁰(E)` існує єдина точка `P ∈ E` така, що:
```
D ∼ (P) - (O)   (тобто D - (P) + (O) є головним дивізором)
```

Це встановлює бієктивне відображення Абеля–Якобі `Φ: E → Pic⁰(E)`, задане правилом `P ↦ [(P) - (O)]`.

Оскільки пряма `L`, що проходить через `P, Q, R` (де `P + Q + R = O`), задовольняє `div(L) = (P) + (Q) + (R) - 3·(O)`, маємо в `Pic⁰(E)`:
```
[(P) - (O)] + [(Q) - (O)] + [(R) - (O)] = 0
```
Звідси геометричне додавання точок `P ⊕ Q` на кривій `E` повністю відповідає додаванню класів дивізорів у групі Пікара `Pic⁰(E)`. Оскільки додавання у `Pic⁰(E)` є асоціативним за визначенням абелевої групи, груповий закон на еліптичній кривій є **строго асоціативним**.

## 11. Поділкові многочлени (Division Polynomials) та n-кручення

Для довільного цілого `n ≥ 1` координати кратної точки `n·P = (x_n, y_n)` виражаються через координати `P = (x, y)` за допомогою поділкових многочленів `Ψ_n(x, y)`:
```
x_n = x - (Ψ_{n-1} · Ψ_{n+1}) / (Ψ_n²)
y_n = (Ψ_{2n}) / (2 · Ψ_n⁴)
```

### Початкові члени послідовності:
- `Ψ₁ = 1`
- `Ψ₂ = 2·y`
- `Ψ₃ = 3·x⁴ + 6·a·x² + 12·b·x - a²`
- `Ψ₄ = 4·y · (x⁶ + 5·a·x⁴ + 20·b·x³ - 5·a²·x² - 4·a·b·x - 8·b² - a³)`

### Рекурентні співвідношення для `m > n`:
```
Ψ_{2m+1} = Ψ_{m+2} · Ψ_m³ - Ψ_{m-1} · Ψ_{m+1}³
Ψ_{2m} = (Ψ_m / 2y) · (Ψ_{m+2} · Ψ_{m-1}² - Ψ_{m-2} · Ψ_{m+1}²)
```

### Структура підгрупи n-кручення:
Многочлен `Ψ_n²(x)` має степінь `n² - 1` за змінною `x`. Над алгебраїчно замкненим полем характеристики 0 або `p ∤ n` підгрупа `n`-кручення `E[n] = { P ∈ E(K̄) : n·P = O }` складається з `n²` точок і ізоморфна прямій сумі двох циклічних груп:
```
E[n] ≅ ℤ/nℤ ⊕ ℤ/nℤ
```

## 12. Інваріантний диференціал та формальні групи

На еліптичній кривій `E: y² = x³ + a·x + b` існує єдина з точністю до константи регулярна ненульова диференціальна 1-форма:
```
ω = dx / (2·y) = dx / (2 · √(x³ + a·x + b))
```

### Трансляційна інваріантність:
Для будь-якої точки `Q ∈ E` розглянемо автоморфізм зсуву `τ_Q : P ↦ P + Q`. Відкат (pullback) диференціала є інваріантним:
```
τ_Q*(ω) = ω
```

В околі точки на нескінченності `O` введемо локальний параметр `z = -x/y`. Розклад `ω` у степеневий ряд набуває вигляду:
```
ω = (1 + a₁·z + (a₂ + a₁²)·z² + ...) dz
```
Інтегрування `ω` породжує **формальний логарифм `log_F(z) = ∫ ω = z + ...`**, а операція додавання точок задає **одновимірну формальну групу (Formal Group Law)**:
```
F(z₁, z₂) = z₁ + z₂ - a₁·z₁·z₂ - a₂·(z₁²·z₂ + z₁·z₂²) + ...
```

## 13. Теорія кривих Тейта над неархімедовими полями

Для локальних `p`-адичних числових полів `K` (таких як поле `p`-адичних чисел `ℚ_p`), якщо еліптична крива має розщеплену мультиплікативну редукцію (її `j`-інваріант задовольняє `|j|_p > 1`), Джон Тейт (1959) побудував витончений `p`-адичний аналог комплексної теорії Вейєрштрасса — **криву Тейта `E_q`**.

Крива Тейта задається аналітичним ізоморфізмом між мультиплікативною групою поля `K*` та еліптичною кривою:
```
E_q(K) ≅ K* / q^ℤ
```
де `q ∈ K*` — параметр Тейта з нормою `|q|_p < 1`, пов'язаний з `j`-інваріантом розкладом:
```
j = 1/q + 744 + 196884·q + 21493760·q² + ...
```

Координати точок кривої Тейта виражаються абсолютно збіжними рядами Лорана Тейта від змінної `u ∈ K*`:
```
x(u, q) = ∑_{n ∈ ℤ} [ qⁿ·u / (1 - qⁿ·u)² ] - 2 · ∑_{n ≥ 1} [ qⁿ / (1 - qⁿ)² ]
y(u, q) = ∑_{n ∈ ℤ} [ (qⁿ·u)² / (1 - qⁿ·u)³ ] + ∑_{n ≥ 1} [ qⁿ / (1 - qⁿ)² ]
```
Ця параметризація дозволяє досліджувати канонічну висоту Нерона–Тате та періоди кривих у `p`-адичній теорії чисел.

## 14. Біраціональні ізоморфізми: моделі Монтгомері та скручені криві Едвардса

Крім форми Вейєрштрасса, у сучасній криптографії застосовують дві альтернативні алгебраїчні моделі:

### 1. Криві Монтгомері (Montgomery Form):
Рівняння кривої: `B·y² = x³ + A·x² + x`, де `B · (A² - 4) ≠ 0`.
Будь-яка крива Монтгомері біраціонально еквівалентна короткій формі Вейєрштрасса `y'² = x'³ + a·x' + b` за формулами:
```
x' = x/B + A/(3·B),   y' = y/B,   a = (3 - A²) / (3·B²),   b = (2·A³ - 9·A) / (27·B³)
```

### 2. Скручені криві Едвардса (Twisted Edwards Form):
Рівняння кривої: `a·u² + v² = 1 + d·u²·v²`.
Крива Едвардса біраціонально ізоморфна кривій Монтгомері `B·y² = x³ + A·x² + x` за формулами переходу:
```
A = 2·(a + d) / (a - d),   B = 4 / (a - d)
x = (1 + v) / (1 - v),     y = (1 + v) / ((1 - v)·u)
```
Якщо `a` є квадратом у `𝔽ₚ`, а `d` — неквадратом, знаменник формули додавання Едвардса `1 + d·u₁·u₂·v₁·v₂` ніколи не дорівнює нулю над `𝔽ₚ`, забезпечуючи **повні формули додавання без жодних виняткових станів**.

## 15. Теорія висот та канонічна висота Нерона–Тате

Для вивчення арифметики точок на еліптичній кривій над полем раціональних чисел `ℚ` фундаментальне значення має поняття арифметичної складності точки — її **висота**.

### 1. Наївна висота (Weil Height):
Для раціонального числа `x = p/q ∈ ℚ` (де `gcd(p, q) = 1`) логарифмічна висота визначається як `h(x) = \log \max(|p|, |q|)`. Для точки `P = (x, y) ∈ E(ℚ)` наївна висота дорівнює `h(P) = h(x(P))` (та `h(O) = 0`).

Наївна висота задовольняє наближене рівняння подвоєння: `h(2·P) = 4·h(P) + O(1)`.

### 2. Канонічна висота Нерона–Тате (Canonical Height):
Щоб позбутися обмеженого залишку `O(1)`, Андре Нерон та Джон Тейт ввели границю:
```
ĥ(P) = lim_{k → ∞} [ 4⁻ᵏ · h(2ᵏ · P) ]
```

Канонічна висота `ĥ: E(ℚ) → ℝ` задовольняє точні властивості:
1. **Квадратичність:** `ĥ(2·P) = 4·ĥ(P)` для всіх `P ∈ E(ℚ)`.
2. **Тотожність паралелограма:** `ĥ(P + Q) + ĥ(P - Q) = 2·ĥ(P) + 2·ĥ(Q)`.
3. **Невід'ємність та кручення:** `ĥ(P) ≥ 0`, причому `ĥ(P) = 0` тоді і тільки тоді, коли `P` є точкою скінченного порядку (кручення) `P ∈ E(ℚ)_{tors}`.
4. **Білінійна форма Нерона–Тате:** 
   ```
   ⟨P, Q⟩ = (1/2) · ( ĥ(P + Q) - ĥ(P) - ĥ(Q) )
   ```
   Матриця Грама цієї форми для базису вільної підгрупи `E(ℚ) / E(ℚ)_{tors}` визначає **еліптичний регулятор `Reg(E/ℚ) = det(⟨P_i, P_j⟩) > 0`**, що входить у формулу гіпотези BSD.

## 16. Метод нескінченного спуску та доведення теореми Морделла–Вейля

> **Теорема Морделла–Вейля:** Для будь-якої еліптичної кривої `E`, визначеної над числовим полем `K`, група `K`-раціональних точок `E(K)` є скінченно породженою абелевою групою:
> ```
> E(K) ≅ E(K)_{tors} ⊕ ℤʳ
> ```
> де `r ≥ 0` — ранг кривої, а `E(K)_{tors}` — скінченна група кручення.

### Схема доведення методом спуску:

1. **Слабка теорема Морделла–Вейля (Weak Mordell-Weil):**
   Використовуючи точну послідовність Куммера та когомології Галуа `H¹(G_K, E[2])`, доводиться, що фактор-група `E(K) / 2·E(K)` є **скінченною групою**:
   ```
   # ( E(K) / 2·E(K) ) = 2^{r + dim E(K)[2]} < ∞
   ```

2. **Лема про спуск з квадратичною висотою:**
   Нехай `{Q₁, Q₂, ..., Q_m}` — повний набір представників суміжних класів фактор-групи `E(K) / 2·E(K)`. 
   Нехай константа `C = max_i ĥ(Q_i)`. Розглянемо скінченну множину точок `S = { P ∈ E(K) : ĥ(P) ≤ C }`.
   
   Для будь-якої точки `P ∈ E(K)` знайдеться `Q_{i_1}` такий, що `P - Q_{i_1} = 2·P₁`. Тоді:
   ```
   ĥ(P₁) = (1/4) · ĥ(P - Q_{i_1}) ≤ (1/4) · ( 2·ĥ(P) + 2·ĥ(Q_{i_1}) ) ≤ (1/2)·ĥ(P) + C/2
   ```
   Якщо `ĥ(P) > C`, то `ĥ(P₁) < ĥ(P)`. Повторюючи цей процес, висота точки строго спадає на кожному кроці. Оскільки множина точок з обмеженою висотою є скінченною, процес спуску завершується за скінченну кількість кроків у множині `S`. 
   
   Отже, множина `S` породжує всю групу `E(K)`, що строго доводить її скінченну породженість!

## 17. Теорема Луц–Нагеля про точки кручення над ℚ

Для практичного знаходження всіх точок скінченного порядку над полем `ℚ` застосовується класична теорема Елізабет Луц (1937) та Трюґве Нагеля (1935):

> **Теорема Луц–Нагеля:** Нехай `E: y² = x³ + a·x + b` — еліптична крива з цілими коефіцієнтами `a, b ∈ ℤ`.
> Якщо точка `P = (x, y) ∈ E(ℚ)` має скінченний порядок `n ≥ 2`, то:
> 1. Координати `x` та `y` є **строго цілими числами**: `x, y ∈ ℤ`.
> 2. Або `y = 0` (точка порядку 2), або `y²` є дільником дискримінанта кубічного многочлена:
>    ```
>    y² | (4·a³ + 27·b²)
>    ```

### Алгебраїчне обґрунтування:
Доведення спирається на `p`-адичну фільтрацію точок `E_n(ℚ_p)` у формальній групі. Якщо точка кручення мала б дробові координати з простим знаменником `p`, вона належала б ядру редукції `E₁(ℚ_p)`. Але формальна група над кільцем `p`-адичних цілих чисел `ℤ_p` не містить нетривіального кручення для простих чисел `p ∤ n`, що виключає дробові координати.

Ця теорема зводить пошук усіх раціональних точок скінченного порядку до скінченної перевірки дільників дискримінанта.

## 18. Класифікація кручення: теореми Мазура та Мереля

Питання про те, які саме структури груп кручення можуть виникати на еліптичних кривих, отримало вичерпну відповідь у фундаментальних працях Баррі Мазура та Луїка Мереля:

### 1. Теорема Мазура (1977):
Над полем раціональних чисел `ℚ` група кручення `E(ℚ)_{tors}` може бути ізоморфною лише одній із **15 можливих груп**:
- `ℤ/nℤ` для `1 ≤ n ≤ 10` та `n = 12`;
- `ℤ/2ℤ ⊕ ℤ/2nℤ` для `1 ≤ n ≤ 4`.

### 2. Теорема Мереля про рівномірну обмеженість (Uniform Boundedness Theorem, 1996):
Для будь-якого фіксованого степеня числового поля `d = [K : ℚ]` існує універсальна стала `B(d) > 0`, що залежить виключно від степеня розширення `d`, така, що для будь-якої еліптичної кривої `E` над полем `K` порядок групи кручення обмежений:
```
#E(K)_{tors} ≤ B(d)
```
Це відкриття довело, що розмір групи кручення не може зростати нескінченно при фіксованому степені поля.

## 19. L-функція Хассе–Вейля та Гіпотеза Берча і Свіннертона-Даєра (BSD)

Для кожної еліптичної кривої `E` над `ℚ` глобальні арифметичні властивості кодуються у її комплексному аналітичному інваріанті — **`L`-функції Хассе–Вейля `L(E, s)`**.

### 1. Означення L-функції:
Для простого числа `p` позначимо кількість точок над полем залишків `N_p = #E(𝔽ₚ)` та слід Фробеніуса `a_p = p + 1 - N_p`. Локальні фактори Ейлера задаються правилом:
- Для простого числа доброї редукції (`p ∤ Δ`): `L_p(E, s) = (1 - a_p · p⁻ˢ + p¹⁻²ˢ)⁻¹`
- Для простого мультиплікативної редукції: `L_p(E, s) = (1 - a_p · p⁻ˢ)⁻¹`, де `a_p = ±1`
- Для простого адитивної редукції: `L_p(E, s) = 1`

Глобальна `L`-функція визначається ейлеровим добутком, збіжним при `Re(s) > 3/2`:
```
L(E, s) = ∏_p L_p(E, s)
```

Завдяки теоремі про модулярність (Вайлс, Брей, Конрад, Даймонд, Тейлор), `L(E, s)` допускає аналітичне продовження на всю комплексну площину `ℂ` і задовольняє функціональне рівняння:
```
Λ(E, s) = N^{s/2} · (2·π)⁻ˢ · Γ(s) · L(E, s) = w_E · Λ(E, 2 - s)
```
де `N` — провідник кривої, а `w_E = ±1` — кореневий знак (Root Number).

### 2. Гіпотеза BSD (Birch and Swinnerton-Dyer Conjecture):
Гіпотеза BSD стверджує, що порядок нуля `L(E, s)` у центральній точці `s = 1` дорівнює алгебраїчному рангу `r` кривої Морделла–Вейля:
```
ord_{s=1} L(E, s) = rank(E(ℚ)) = r
```
Крім того, провідний коефіцієнт розкладу Тейлора у точці `s = 1` виражається точними арифметичними інваріантами:
```
lim_{s → 1} [ L(E, s) / (s - 1)ʳ ] = ( Ω_E · Reg(E/ℚ) · #Ш(E/ℚ) · ∏ c_p ) / ( #E(ℚ)_{tors} )²
```
де `Ω_E` — дійсний період, `Reg(E/ℚ)` — регулятор Нерона–Тате, `c_p` — локальні фактори Тамагави, а `Ш(E/ℚ)` — група Шафаревича–Тейта.

## 20. Комплексне множення (CM-теорія) та многочлени Гільберта

Для більшості еліптичних кривих кільце ендоморфізмів ізоморфне кільцю цілих чисел: `End(E) ≅ ℤ`. Проте якщо кільце ендоморфізмів є строго більшим за `ℤ`, кажуть, що крива має **Комплексне множення (Complex Multiplication, CM)**.

У цьому випадку `End(E)` є порядком `O_K` в уявному квадратичному полі `K = ℚ(√-D)` з дискримінантом `-D < 0`.

### Многочлени класу Гільберта (Hilbert Class Polynomials):
Многочлен класу Гільберта `H_D(X)` визначається як добуток за всіма класами ідеалів поля `K`:
```
H_D(X) = ∏_{i=1}^{h(-D)} (X - j(E_i))
```
де `h(-D)` — число класів ідеалів порядку `O_K`. Дивовижно, що всі коефіцієнти многочлена `H_D(X)` є строго цілими числами (`H_D(X) ∈ ℤ[X]`). 

Корені `H_D(X) mod p` дають `j`-інваріанти еліптичних кривих над скінченним полем `𝔽ₚ` з наперед відомою кількістю точок `#E(𝔽ₚ) = p + 1 - t`, де `4·p = t² + D·y²`. Цей метод (CM-метод Аткена–Моріна) є основним інструментом генерації криптографічних кривих з простим порядком групи.

## 21. Модуль Тейта та ℓ-адичні представлення Галуа

Для вивчення симетрій кривої під дією абсолютної групи Галуа `G_K = Gal(K̄/K)` будується проективна границя груп кручення — **модуль Тейта `T_ℓ(E)`** для простого числа `ℓ`:
```
T_ℓ(E) = lim_{← n} E[ℓⁿ] ≅ ℤ_ℓ ⊕ ℤ_ℓ
```

Дія автоморфізмів Галуа комутує з груповим законом на точках кривої, тому породжує неперервне матричне представлення:
```
ρ_{E, ℓ} : Gal(K̄/K) → GL₂(ℤ_ℓ)
```

### Теорема Серра про відкрите зображення (Serre's Open Image Theorem, 1972):
Якщо еліптична крива `E` над `ℚ` не має комплексного множення, то для майже всіх простих `ℓ` представлення Галуа `ρ_{E, ℓ}` є **сюр'єктивним**:
```
Im(ρ_{E, ℓ}) = GL₂(ℤ_ℓ)
```
а образ для всіх простих є відкритою підгрупою скінченного індексу у `GL₂(ℤ_ℓ)`.

## 22. Група Шафаревича–Тейта та перешкоди принципу Гассе

Локально-глобальний принцип Мінковського–Гассе стверджує, що квадратичне діофантове рівняння має розв'язок у полі `ℚ` тоді й лише тоді, коли воно має розв'язки у полі дійсних чисел `ℝ` та в усіх `p`-адичних полях `ℚ_p`.

Для кубічних кривих принцип Гассе **порушується**. Класичний контрприклад Ернста Сельмера (1951) — кубічна крива:
```
3·x³ + 4·y³ + 5·z³ = 0
```
Ця крива має гладкі розв'язки у `ℝ` та в усіх `ℚ_p` для будь-якого простого `p`, але **не має жодного ненульового раціонального розв'язку у `ℚ`**!

Мірою порушення принципу Гассе для головних однорідних просторів еліптичної кривої є **група Шафаревича–Тейта `Ш(E/ℚ)`**:
```
Ш(E/ℚ) = ker [ H¹(G_ℚ, E) → ∏_v H¹(G_{ℚ_v}, E) ]
```
За гіпотезою Шафаревича, група `Ш(E/ℚ)` завжди є скінченною, а її порядок входить у формулу гіпотези BSD.

## 23. Модулярні форми та теорема Модулярності Вайлса

Зв'язок між еліптичними кривими та модулярними формами є однією з найглибших вершин математики XX століття:

Параболічною модулярною формою (Cusp Form) ваги 2 рівня `N` називається голоморфна функція `f: ℍ → ℂ` на верхній півплощині `ℍ`, яка задовольняє закон трансформації для модулярної групи `Γ₀(N)`:
```
f( (a·z + b) / (c·z + d) ) = (c·z + d)² · f(z)
```
та зникає у всіх параболічних точках (каспах). Простір таких форм позначається `S₂(Γ₀(N))`. 

Функція `f(z)` допускає розклад у ряд Фур'є (q-розклад):
```
f(z) = ∑_{n=1}^∞ a_n · qⁿ,   де q = e^{2·π·i·z}
```

> **Теорема про модулярність (Вайлс, Тейлор, Брей, Конрад, Даймонд):** Для будь-якої еліптичної кривої `E` над `ℚ` з провідником `N` існує нормована власна форма Гекке `f ∈ S₂(Γ₀(N))` така, що коефіцієнти ряду Фур'є `a_p` форми `f` точно збігаються зі слідами Фробеніуса еліптичної кривої для всіх простих чисел `p`:
> ```
> a_p(f) = a_p(E) = p + 1 - #E(𝔽ₚ)
> ```
> Відповідно, `L`-функція кривої тотожно дорівнює `L`-функції модулярної форми: `L(E, s) = L(f, s)`.

Саме цей монументальний результат дозволив Ендрю Вайлсу остаточно довести Велику теорему Ферма через криву Фрея–Геллегуарша.

## 24. Алгоритм Шоофа та підрахунок точок над скінченними полями

Для криптографічного використання над полями `𝔽ₚ` необхідно точно знати кількість точок `#E(𝔽ₚ) = p + 1 - t`. 

1985 року Рене Шооф розробив перший детермінований алгоритм поліноміального часу `O(\log^8 p)` для підрахунку точок:
1. За теоремою Гассе `|t| ≤ 2·√p`. Обирається набір малих простих чисел `{ℓ₁, ℓ₂, ..., ℓ_k}`, добуток яких перевищує `4·√p`.
2. Для кожного `ℓ` використовується характеристичне рівняння Фробеніуса:
   ```
   π² - t · π + p = 0  ⇒  (x^{p²}, y^{p²}) + p · (x, y) = t · (xᵖ, yᵖ)  (mod Ψ_ℓ(x))
   ```
3. Обчислюючи значення `t mod ℓ` у фактор-кільці `𝔽ₚ[x, y] / (y² - x³ - ax - b, Ψ_ℓ(x))`, знаходять залишки `t mod ℓ_i`.
4. Значення `t` однозначно відновлюється за Китайською теоремою про залишки (CRT).

Розширення Елкіса та Аткіна (алгоритм SEA) використовує факторизацію модулярних многочленів `Φ_ℓ(X, Y)`, що зменшує степінь поділкових многочленів з `(ℓ² - 1)/2` до `(ℓ - 1)/2` та скорочує асимптотичну складність до `O(\log^4 p)`.

## 25. Спарювання Вейля, спарювання Тейта та алгоритм Міллера

### 1. Спарювання Вейля (Weil Pairing):
Для двох точок `P, Q ∈ E[n]` існують дивізори `D_P ∼ n·(P) - n·(O) = div(f_P)` та `D_Q ∼ n·(Q) - n·(O) = div(f_Q)`. **Спарювання Вейля `e_n(P, Q)`** визначається як:
```
e_n(P, Q) = f_P(D_Q) / f_Q(D_P)
```
Воно є білінійним (`e_n(P₁ + P₂, Q) = e_n(P₁, Q)·e_n(P₂, Q)`), кососиметричним (`e_n(P, Q) = e_n(Q, P)⁻¹`), невиродженим та приймає значення у групі коренів `n`-го степеня з одиниці `μ_n`.

### 2. Алгоритм Міллера (Miller's Algorithm):
Віктор Міллер (1986) розробив швидкий алгоритм обчислення значень функції `f_P(Q)` складності `O(\log n)`. 
Він використовує рекурентні співвідношення для функцій з дивізорами:
```
f_{j+k} = f_j · f_k · ( L_{j,k} / V_{j+k} )
```
де `L_{j,k}` — пряма через точки `j·P` та `k·P`, а `V_{j+k}` — вертикальна пряма через `(j+k)·P`. Це дає змогу швидко подвоювати та додавати аргументи функцій за схемою подвоюй-і-додавай (Double-and-Add).

### 3. Застосування спарювань у сучасній криптографії (Pairing-Based Cryptography):
Спарювання Вейля та Тейта–Ліхтенбаума лежать в основі проривних криптографічних примітивів XXI століття:
- **Короткі цифрові підписи BLS (Boneh–Lynn–Shacham):** дають змогу створювати підписи довжиною всього 48 байтів та агрегувати тисячі підписів у єдиний константного розміру (використовується в блокчейнах Ethereum та Chia).
- **Шифрування на основі ідентифікатора (Identity-Based Encryption, IBE Боне–Франкліна):** дозволяє використовувати відкриту адресу електронної пошти як публічний ключ без сертифікатів PKI.
- **Криптографічні доведення з нульовим розголошенням (zk-SNARKs, Groth16, PLONK):** забезпечують математично верифіковану конфіденційність транзакцій.
Для практичних протоколів застосовують криві з малим ступенем занурення `k` (Embedding Degree), зокрема криві Баррето–Наеріга (BN-254) та родини BLS12-381.

### 4. Формули Велю для обчислення фактор-кривих E/G (Vélu's Formulas):
Нехай `G ⊂ E(K)` — скінченна підгрупа. Жак Велю (1971) отримав явні раціональні формули для ізогенії `ϕ: E → E' = E/G`:
```
x' = x + ∑_{Q ∈ G\{O}} [ (x - x_Q)⁻¹ · g_Q ]
y' = y - ∑_{Q ∈ G\{O}} [ (x - x_Q)⁻² · y · ... ]
```
Формули Велю дозволяють за поліноміальний час обчислювати ізогенні криві, що є основою постквантових алгоритмів CSIDH та SQISign.

## 26. Порівняння проективних систем координат та обчислювальна вартість

Для практичної інженерної реалізації точкової арифметики в криптографії афінні координати замінюють проективними, що дозволяє усунути операції знаходження оберненого елемента:

```
+---------------------------------------------------------------------------------------------------------+
| Система координат          | Формули представлення точок | Подвоєння (2·P)   | Додавання (P + Q)        |
+----------------------------+-----------------------------+-------------------+--------------------------+
| Афінна                     | (x, y)                      | 1 I + 2 M + 2 S   | 1 I + 2 M + 1 S          |
| Однорідна проективна       | (X : Y : Z), x=X/Z, y=Y/Z   | 7 M + 5 S         | 12 M + 2 S               |
| Координати Якобі           | (X : Y : Z), x=X/Z², y=Y/Z³ | 4 M + 6 S (3M+5S) | 12 M + 4 S               |
| Модифіковані Якобі         | (X : Y : Z : a·Z⁴)          | 4 M + 4 S         | 13 M + 5 S               |
| Координати Чудновського    | (X : Y : Z : Z² : Z³)       | 5 M + 4 S         | 11 M + 3 S (змішане)     |
+---------------------------------------------------------------------------------------------------------+
```

Ці детальні виведення та алгебраїчні конструкції формують цілісну основу сучасної арифметичної геометрії та забезпечують математичний фундамент алгоритмів криптографічного захисту інформації на еліптичних кривих.
