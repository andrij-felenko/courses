# 𝔮 Алгебраїчне виведення формул групового закону, дискримінанта та інваріанта j

Строге алгебраїчне виведення координат суми точок `P + Q` та подвоєння `2·P` на еліптичній кривій, перевірка асоціативності через геометрію кубік, поділкові многочлени, інваріантні диференціали, квадратичні викрути, спарювання Вейля, ізогенії та канонічні інваріанти рівняння Вейєрштрасса.

Для аналітичної та програмної роботи з еліптичною кривою абстрактне геометричне правило «провести січну пряму та віддзеркалити точку перетину» необхідно перекласти точними алгебраїчними формулами у координатах `(x, y)`.

---

## 1. Повний алгебраїчний вивід короткої форми Вейєрштрасса

Загальне плоске кубічне рівняння від двох змінних `x` та `y` у будь-якому числовому полі містить 10 членів:

```
A·x³ + B·x²·y + C·x·y² + D·y³ + E·x² + F·x·y + G·y² + H·x + I·y + J = 0
```

Якщо кубічна крива є гладкою і має принаймні одну раціональну точку `O`, її можна звести до **довгої форми Вейєрштрасса** шляхом проективної зміни координат у проективному просторі `ℙ²(K)`:

```
y² + a₁·x·y + a₃·y = x³ + a₂·x² + a₄·x + a₆
```

Ця довша форма використовується над полями характеристики 2 та 3 (`char(K) = 2` або `char(K) = 3`). Якщо ж характеристика поля `char(K) ≠ 2, 3` (зокрема над полями `ℝ`, `ℂ`, `ℚ` та для більшості криптографічних простих полів `𝔽ₚ`), довгоформатне рівняння можна спростити до **короткої форми Вейєрштрасса**:

```
y² = x³ + a·x + b
```

### Кроки алгебраїчного зведення:

1. **Виділення повного квадрата по `y` (`char(K) ≠ 2`):**
   Перенесемо члени з `y` у ліву частину: `y² + (a₁·x + a₃)·y = x³ + a₂·x² + a₄·x + a₆`. 
   Зробимо заміну зміної `y ↦ (y' - a₁·x - a₃) / 2`. Підстановка повністю знищує члени `x·y` та `y` у лівій частині, даючи рівняння вигляду:
   ```
   (y')² = 4·x³ + b₂·x² + 2·b₄·x + b₆
   ```
   де коефіцієнти виражаються через початкові як `b₂ = a₁² + 4·a₂`, `b₄ = 2·a₄ + a₁·a₃`, `b₆ = a₃² + 4·a₆`.

2. **Виділення повного куба по `x` (`char(K) ≠ 3`):**
   Поділимо рівняння на 4 і зробимо заміну `x ↦ (x' - b₂/12)`. Ця заміна вираховує член `(x')²` і повністю знищує його.

3. **Нормування коефіцієнтів:**
   Позначивши підсумкові коефіцієнти при `x'` та вільний член як `a` та `b`, отримуємо остаточну коротку форму Вейєрштрасса `y² = x³ + a·x + b`.

У проективних координатах `(X : Y : Z)`, де `x = X/Z` та `y = Y/Z`, рівняння набуває однорідного вигляду: `Y²·Z = X³ + a·X·Z² + b·Z³`. Єдина точка кривої з `Z = 0` — це нескінченно віддалена точка `O = (0 : 1 : 0)`, яка слугує **нейтральним елементом (нулем)** абелевої групи `E(K)`.

## 2. Аналітичне виведення рівняння Вейєрштрасса через комплексну `℘`-функцію

У комплексній аналітичній геометрії кубічна крива описується двоперіодичною `℘`-функцією Вейєрштрасса від комплексної змінної `z ∈ ℂ` відносно гратки періодів `Λ = {m·ω₁ + n·ω₂ : m, n ∈ ℤ}`:

```
℘(z) = 1/z² + ∑_{w ∈ Λ\{0}} [ 1/(z - w)² - 1/w² ]
```

Розкладемо функцію `℘(z)` у ряд Лорана біля точки `z = 0`:

```
℘(z) = 1/z² + 3·G₄·z² + 5·G₆·z⁴ + O(z⁶)
```

де ряди Ейзенштейна `G₄` та `G₆` виражаються як `G₄ = ∑_{w ≠ 0} 1/w⁴` та `G₆ = ∑_{w ≠ 0} 1/w⁶`.

Обчислимо похідну `℘'(z)` розкладу Лорана:

```
℘'(z) = -2/z³ + 6·G₄·z + 20·G₆·z³ + O(z⁵)
```

Піднесемо `℘'(z)` до квадрата:

```
(℘'(z))² = 4/z⁶ - 24·G₄/z² - 80·G₆ + O(z²)
```

Тепер обчислимо куб `(℘(z))³`:

```
(℘(z))³ = 1/z⁶ + 9·G₄/z² + 15·G₆ + O(z²)
```

Помножимо `(℘(z))³` на 4 і віднімемо від квадрата похідної `(℘'(z))²`:

```
(℘'(z))² - 4·(℘(z))³ = -60·G₄/z² - 140·G₆ + O(z²)
```

Додамо член `60·G₄·℘(z) = 60·G₄/z² + 180·G₄²·z² + ...`:

```
(℘'(z))² - 4·(℘(z))³ + 60·G₄·℘(z) = -140·G₆ + O(z²)
```

Позначивши інваріанти Вейєрштрасса як `g₂ = 60·G₄` та `g₃ = 140·G₆`, бачимо, що різниця `(℘'(z))² - 4·(℘(z))³ + g₂·℘(z) + g₃` є обмеженою голоморфною двоперіодичною функцією на торі `ℂ / Λ`, яка обнуляється у точці `z = 0`. За теоремою Ліувілля, кожна обмежена ціла двоперіодична функція є строго константою, тому вона дорівнює нулю тотожно:

```
(℘'(z))² = 4·(℘(z))³ - g₂·℘(z) - g₃
```

Зробивши заміну координат `x = ℘(z)` та `y = ℘'(z)/2`, отримуємо канонічну коротку форму Вейєрштрасса `y² = x³ + a·x + b`, де `a = -g₂ / 4` та `b = -g₃ / 4`.

Аналітична теорема додавання для `℘`-функцій Вейєрштрасса стверджує:

```
℘(u + v) = -℘(u) - ℘(v) + (1/4) · [ (℘'(u) - ℘'(v)) / (℘(u) - ℘(v)) ]²
```

Це рівняння є точним аналітичним еквівалентом координатних формул додавання точок `x₄ = λ² - x₁ - x₂`!

## 3. Алгебраїчне виведення формул додавання нерівних точок (P ≠ Q)

Нехай задано дві різні точки `P = (x₁, y₁)` та `Q = (x₂, y₂)` на неособливій кривій `y² = x³ + a·x + b`, причому `x₁ ≠ x₂` (пряма через `P` та `Q` не є строго вертикальною).

Пряма `L`, що проходит через `P` та `Q`, описується рівнянням `y = λ·(x - x₁) + y₁`, де нахил `λ` дорівнює:

```
λ = (y₂ - y₁) / (x₂ - x₁)
```

Щоб знайти координати точок перетину прямої `L` з еліптичною кривою, підставимо вираз для `y` у рівняння кривої:

```
(λ·(x - x₁) + y₁)² = x³ + a·x + b
```

Розкриємо квадрат у лівій частині:

```
λ²·(x - x₁)² + 2·λ·y₁·(x - x₁) + y₁² = x³ + a·x + b
λ²·(x² - 2·x₁·x + x₁²) + 2·λ·y₁·x - 2·λ·y₁·x₁ + y₁² = x³ + a·x + b
```

Перенесемо всі члени у праву частину і згрупуємо за степенями `x`:

```
x³ - λ²·x² + (a + 2·λ²·x₁ - 2·λ·y₁)·x + (b + 2·λ·y₁·x₁ - y₁² - λ²·x₁²) = 0
```

Отримано приведений кубічний многочлен від `x` вигляду `x³ + c₂·x² + c₁·x + c₀ = 0`, де `c₂ = -λ²`.

За теоремою Безу та основною теоремою алгебри, цей многочлен має точно 3 корені `x₁, x₂, x₃` (з урахуванням кратності). Оскільки точки `P = (x₁, y₁)` та `Q = (x₂, y₂)` належать кривій і лежать на прямій `L`, `x₁` та `x₂` є двома коренями цього многочлена.

За теоремою Вієта, сума трьох коренів приведеного кубічного рівняння дорівнює коефіцієнту при `x²` з протилежним знаком (`-c₂`):

```
x₁ + x₂ + x₃ = -(-λ²) = λ²
```

Звідси негайно отримуємо формулу для абсциси третьої точки перетину `R = (x₃, y₃)`:

```
x₃ = λ² - x₁ - x₂
```

Оскільки точка `R` лежить на прямій `L`, її ордината `y₃` обчислюється підстановкою `x₃` у рівняння прямої:

```
y₃ = λ·(x₃ - x₁) + y₁
```

Згідно з визначенням групового закону, сума `P + Q` дорівнює віддзеркаленню точки `R` відносно осі абсцис: `-R = (x₃, -y₃)`. Позначивши координати підсумкової точки `P + Q = (x₄, y₄)`, отримуємо канонічні формули:

```
x₄ = λ² - x₁ - x₂
y₄ = λ·(x₁ - x₄) - y₁
```

## 4. Алгебраїчне виведення формул подвоєння точки (P = Q)

Якщо точки збігаються `P = Q = (x₁, y₁)`, то січна пряма перетворюється на **дотичну пряму** до кривої у точці `P`.

Нахил дотичної `λ` знайдемо за допомогою неявного диференціювання вихідного рівняння Вейєрштрасса `y² = x³ + a·x + b`:

```
d/dx (y²) = d/dx (x³ + a·x + b)
2·y · (dy/dx) = 3·x² + a
```

Звідси нахил дотичної прямої `λ = dy/dx` у точці `(x₁, y₁)` дорівнює:

```
λ = (3·x₁² + a) / (2·y₁)
```

*(Якщо ордината `y₁ = 0`, дотична пряма є вертикальною `x = x₁`. Дотична перетинає криву в точці `O` на нескінченності, що дає `2·P = O`).*

Застосовуючи теорему Вієта до кубічного рівняння для дотичної прямої (де корінь `x₁` має кратність 2 через дотик):

```
x₁ + x₁ + x₃ = λ²  ⇒  x₃ = λ² - 2·x₁
```

Остаточні координати подвоєної точки `2·P = (x₄, y₄)`:

```
λ = (3·x₁² + a) / (2·y₁)
x₄ = λ² - 2·x₁
y₄ = λ·(x₁ - x₄) - y₁
```

## 5. Точки кручення 2-го та 3-го порядків та Поділкові многочлени (Division Polynomials)

### Точки 2-кручення (`E[2]`)

Точки кручення 2-го порядку задовольняють співвідношення `2·P = O`, що еквівалентно `P = -P`. Для точки `P = (x, y)` це означає `(x, y) = (x, -y)`, звідки випливає `y = -y ⇔ 2·y = 0`. У будь-якому полі характеристики `char(K) ≠ 2` це вимагає **`y = 0`**.

Підставляючи `y = 0` у коротку форму Вейєрштрасса `y² = x³ + a·x + b`, отримуємо кубічне рівняння `x³ + a·x + b = 0`. Нехай `e₁, e₂, e₃ ∈ K̄` — три корені цього рівняння. Тоді підгрупа 2-кручення `E[2]` складається з 4 точок і є ізоморфною четверній групі Клейна `E[2] = { O, (e₁, 0), (e₂, 0), (e₃, 0) } ≅ ℤ / 2·ℤ ⊕ ℤ / 2·ℤ`.

### Точки 3-кручення (`E[3]`) та 3-й поділковий многочлен `Ψ₃(x)`

Точки 3-кручення задовольняють `3·P = O ⇔ 2·P = -P`. Геометрично це означає, що абсциси точок `P` та `2·P` є однаковими: `x(2·P) = x(P)`.

Використовуючи формулу подвоєння абсциси `x(2·P) = λ² - 2·x = (3·x² + a)² / (4·y²) - 2·x`, прирівняємо її до `x`:

```
(3·x² + a)² / (4·(x³ + a·x + b)) - 2·x = x
(3·x² + a)² / (4·(x³ + a·x + b)) = 3·x
```

Помножимо обидві частини на `4·(x³ + a·x + b)`:

```
(3·x² + a)² = 12·x · (x³ + a·x + b)
9·x⁴ + 6·a·x² + a² = 12·x⁴ + 12·a·x² + 12·b·x
```

Перенесемо всі члени в один бік і помножимо на -1. Отримуємо **3-й поділковий многочлен `Ψ₃(x)`**:

```
Ψ₃(x) = 3·x⁴ + 6·a·x² + 12·b·x - a² = 0
```

Корені цього многочлена 4-го степеня дають абсциси `x` 8 нетривіальних точок 3-кручення. Разом із точкою `O` вони утворюють підгрупу `E[3] ≅ ℤ / 3·ℤ ⊕ ℤ / 3·ℤ` з 9 точок.

### Загальні поділкові многочлени `Ψ_n(x, y)`

У загальному випадку для будь-якого цілого `n ≥ 1` координати кратної точки `n·P = (x_n, y_n)` виражаються через раціональні функції від `x` та `y` за допомогою **поділкових многочленів `Ψ_n(x, y)`**:

```
x_n = x - (Ψ_{n-1} · Ψ_{n+1}) / (Ψ_n²)
```

Рекурентні співвідношення для `Ψ_n` задаються формулами Тейта-Вейєрштрасса:
- `Ψ₁ = 1`
- `Ψ₂ = 2·y`
- `Ψ₃ = 3·x⁴ + 6·a·x² + 12·b·x - a²`
- `Ψ₄ = 4·y · (x⁶ + 5·a·x⁴ + 20·b·x³ - 5·a²·x² - 4·a·b·x - 8·b² - a³)`

Поділкові многочлени відіграють фундаментальну роль у алгоритмі Шоофа для обчислення кількості точок `N = #E(𝔽ₚ)` над скінченними полями за поліноміальний час.

## 6. Квадратичні викрути еліптичних кривих (Quadratic Twists)

Нехай `E` — еліптична крива `y² = x³ + a·x + b`, визначена над полем `K`. Розглянемо неквадратний елемент `d ∈ K` (число, яке не є квадратом у `K`). **Квадратичним викрутом `E^(d)`** кривої `E` називається нова еліптична крива, задана рівнянням: `d·y² = x³ + a·x + b`.

Шляхом заміни `y' = y·√d` це рівняння зводиться до короткої форми Вейєрштрасса з новими коефіцієнтами `y'² = x³ + (a·d²)·x + (b·d³)`.

Над розширенням поля `K(√d)` викручена крива `E^(d)` є повністю ізоморфною вихідній кривій `E`. Проте над самим полем `K` криві `E` та `E^(d)` не є ізоморфними. Сума кількостей точок кривої `E(𝔽ₚ)` та її квадратичного викруту `E^(d)(𝔽ₚ)` над скінченним полем `𝔽ₚ` задовольняє точне співвідношення:

```
#E(𝔽ₚ) + #E^(d)(𝔽ₚ) = 2·p + 2
```

Якщо `E` має `N = p + 1 - t` точок (де `t` — слід Фробеніуса), то її квадратичний викрут `E^(d)` має `N' = p + 1 + t` точок. Це співвідношення активно використовується у криптографії для створення безпечних кривих з опірністю до атак на викрутах (Twist Security).

## 7. Спарювання Вейля та Тейта (Weil & Tate Pairings)

У сучасному зашифруванні широкого вжитку набули **спарювання на еліптичних кривих (Pairing-Based Cryptography)**. Спарювання — це білінійна невироджена функція `e_n`, яка відображає дві точки підгрупи `n`-кручення у корінь з одиниці мультиплікативної групи розширення скінченного поля `𝔽_{p^k}*`:

```
e_n : E[n] × E[n] → μ_n ⊂ 𝔽_{p^k}*
```

Спарювання Вейля задовольняє 3 алгебраїчні властивості:
1. **Білінійність:** `e_n(P₁ + P₂, Q) = e_n(P₁, Q) · e_n(P₂, Q)` та `e_n(P, Q₁ + Q₂) = e_n(P, Q₁) · e_n(P, Q₂)`.
2. **Кососиметричність:** `e_n(P, Q) = e_n(Q, P)⁻¹` (зокрема `e_n(P, P) = 1`).
3. **Невиродженість:** Якщо `e_n(P, Q) = 1` для всіх `Q`, то `P = O`.

Алгоритм Віктора Міллера (Miller's Algorithm) дозволяє обчислювати спарювання Вейля та Тейта за час `O(log n)` за допомогою побудови раціональних функцій `f_P` з дивізорами `div(f_P) = n·(P) - n·(O)`. Спарювання застосовуються у криптосистемі на основі ідентифікаторів (IBE), коротких підписах BLS та системах доказів із нульовим розголошенням zk-SNARKs.

## 8. Ізогенії між еліптичними кривими (Isogenies)

Алгебраїчне відображення `ϕ : E₁ → E₂` між двома еліптичними кривими називається **ізогенією**, якщо воно є голоморфним геометричним морфізмом алгебраїчних кривих, який зберігає нейтральний елемент `ϕ(O) = O`.

Будь-яка ненульова ізогенія `ϕ` автоматично є сур'єктивним груповим гомоморфізмом зі скінченним ядром `ker(ϕ)`. **Степенем ізогенії `deg(ϕ)`** називається розмір її ядра (для сепарабельних ізогеній). Дві еліптичні криві `E₁` та `E₂` називаються ізогенними, якщо між ними існує ненульова ізогенія.

Над скінченними полями `𝔽ₚ` дві еліптичні криві `E₁` та `E₂` є ізогенними (`E₁ ~ E₂`) тоді і тільки тоді, коли вони мають **однакову кількість точок** `#E₁(𝔽ₚ) = #E₂(𝔽ₚ)` (що за теоремою Тейта еквівалентно збігу їхніх слідів Фробеніуса `t₁ = t₂`).

Конструювання графів ізогеній (Isogeny Graphs) та пошук шляхів у них лежить в основі поствизначеної криптографії (Post-Quantum Cryptography, алгоритм CSIDH), яка забезпечує опірність проти атак на потужних квантових комп'ютерах.

## 9. Інваріантний голоморфний диференціал `ω`

На неособливій еліптичній кривій `E` існує єдиний з точністю до константного множника голоморфний **диференціал першого роду `ω`**:

```
ω = dx / (2·y) = dx / (2 · √(x³ + a·x + b))
```

Головна властивість диференціала `ω` — його **трансляційна інваріантність**. Якщо для будь-якої фіксованої точки `Q ∈ E` розглянути зсув (автоморфізм) `τ_Q : P ↦ P + Q`, то відкат диференціала (pullback) є інваріантним: `τ_Q*(ω) = ω`.

Трансляційна інваріантність диференціала `dx / (2·y)` є геометричною причиною того, чому обернені функції до еліптичних інтегралів (еліптичні функції `℘(z)`) задовольняють теореми додавання й формують групову структуру.

## 10. Дискримінант `Δ` та j-інваріант

Умова гладкості означає відсутність точок, у яких одночасно обнуляються значення кривої `F(x, y) = y² - x³ - a·x - b` та її часткові похідні `F_x = -3·x² - a = 0` та `F_y = 2·y = 0`. Це еквівалентно вимозі, щоб кубічний многочлен `P(x) = x³ + a·x + b` не мав кратних коренів.

Нехай `e₁, e₂, e₃ ∈ K̄` — корені многочлена `x³ + a·x + b`. Дискримінант кубічного многочлена визначається як квадрат добутку різниць його коренів `D = (e₁ - e₂)² · (e₂ - e₃)² · (e₃ - e₁)² = -(4·a³ + 27·b²)`.

У теорії еліптичних кривих канонічний **дискримінант кривої `Δ`** нормують множником `16`:

```
Δ = -16 · (4·a³ + 27·b²)
```

- **`Δ ≠ 0`**: Крива є неособливою (еліптичною).
- **`Δ = 0`**: Крива є особливою (виродженою): касп при `a = b = 0`, або вузол при `4·a³ + 27·b² = 0`.

### Інваріант `j` (j-інваріант) та Кільце ендоморфізмів `End(E)`

Для класифікації еліптичних кривих із точністю до ізоморфізму над алгебраїчно замкненим полем використовують **`j`-інваріант**: `j = 1728 · (4·a³) / (4·a³ + 27·b²) = -1728 · (4·a³) / Δ`.

Дві криві `y² = x³ + a·x + b` та `y² = x³ + a'·x + b'` ізоморфні над `K̄` тоді і тільки тоді, коли їхні `j`-інваріанти збігаються (`j(E₁) = j(E₂)`).

Кільце ендоморфізмів `End(E)` складається з усіх голоморфних гомоморфізмів `α: E → E`. Для більшості еліптичних кривих ендоморфізми обмежуються звичайним скалярним множенням `[m] : P ↦ m·P`, тому `End(E) ≅ ℤ`.

Проте для окремих особливих значень `j`-інваріанта крива володіє додатковими автоморфізмами — це явище називається **Комплексним множенням (Complex Multiplication, CM)**:
- **`j = 0` (`a = 0, b ≠ 0`, крива `y² = x³ + b`):** Кільце ендоморфізмів розширюється до `End(E) ≅ ℤ[e^{2·π·i / 3}]`. Крива має автоморфізм 6-го порядку `(x, y) ↦ (ζ₃·x, y)`.
- **`j = 1728` (`a ≠ 0, b = 0`, крива `y² = x³ + a·x`):** Кільце ендоморфізмів розширюється до `End(E) ≅ ℤ[i]`. Крива має автоморфізм 4-го порядку `(x, y) ↦ (-x, i·y)`.

## 11. Доведення асоціативності: Теорема Келі–Бахараха

Доведення того, що геометрія хорд задає абелеву групу, вимагає перевірки 4 аксіом: замикання, наявність нейтрального елемента `O`, існування оберненого елемента `-P` та асоціативність `(P + Q) + R = P + (Q + R)`.

Доведення асоціативності спирається на класичну теорему алгебраїчної геометрії — **Теорему Келі–Бахараха**:

> **Теорема Келі–Бахараха:** Якщо дві кубічні криві `C₁` та `C₂` у проективній площині перетинаються у 9 різних точках, то будь-яка третя кубічна крива `C₃`, що проходить через 8 з цих точок, обов'язково проходить і через 9-ту точку.

### Конструкція доведення:

Розглянемо 3 довільні точки `P, Q, R` на еліптичній кривій `E`. Побудуємо дві складені кубічні криві `C₁` та `C₂`, кожна з яких утворена трійкою прямих ліній:
- **Кубіка `C₁`:** об'єднання прямих `L(P, Q) ∪ L(P+Q, R) ∪ L(Q+R, -(Q+R))`
- **Кубіка `C₂`:** об'єднання прямих `L(Q, R) ∪ L(Q+R, P) ∪ L(P+Q, -(P+Q))`

Ці дві кубіки `C₁` та `C₂` перетинаються точно у 9 точках: `P, Q, R, P+Q, -(P+Q), Q+R, -(Q+R), O` та дев'ятій точці `S = (P + Q) + R` і `S' = P + (Q + R)`. Оскільки вихідна неособлива еліптична крива `E` за побудовою проходить через перші 8 точок перетину, за теоремою Келі–Бахараха крива `E` зобов'язана пройти і через 9-ту точку, що доводить асоціативність.

## 12. Арифметика у проективних координатах Якобі (Jacobian Coordinates)

Для підвищення обчислювальної ефективності у програмах афінні координати `(x, y)` переводять у проективні координати Якобі `(X : Y : Z)`, зв'язані співвідношеннями `x = X / Z²` та `y = Y / Z³`. Рівняння Вейєрштрасса набуває вигляду `Y² = X³ + a·X·Z⁴ + b·Z⁶`. Точка на нескінченності `O` відповідає проективній потрійній `(1 : 1 : 0)`.

### Явні формули додавання точок `(X₃ : Y₃ : Z₃) = (X₁ : Y₁ : Z₁) + (X₂ : Y₂ : Z₂)`:

1. `U₁ = X₁ · Z₂² mod p`
2. `U₂ = X₂ · Z₁² mod p`
3. `S₁ = Y₁ · Z₂³ mod p`
4. `S₂ = Y₂ · Z₁³ mod p`
5. `H = U₂ - U₁ mod p`
6. `r = S₂ - S₁ mod p`
7. `X₃ = r² - H³ - 2·U₁·H² mod p`
8. `Y₃ = r·(U₁·H² - X₃) - S₁·H³ mod p`
9. `Z₃ = H · Z₁ · Z₂ mod p`

Обчислення за цими формулами вимагають **12 множень у полі (`12M`) та 4 квадрати (`4S`)**, без жодної операції знаходження оберненого елемента! Знаходження оберненого елемента `Z⁻¹ mod p` виконується лише одного разу в самом кінці обчислень для отримання афінних координат `x = X₃ / Z₃²` та `y = Y₃ / Z₃³`.

Цей комплексний алгебраїчний та аналітичний апарат забезпечує повну точність, швидкість, стійкість та теоретичну обґрунтованість точкової арифметики на еліптичних кривих у всіх застосуваннях сучасної чистої математики, комп'ютерних наук та криптографічного захисту інформації.
