# 📜 Від довжини дуги еліпса до алгебраїчних груп: історія еліптичних кривих

Як спроба обчислити периметр звичайного еліпса у XVIII столітті відкрила новий математичний всесвіт неалгебраїчних інтегралів, комплексних торів та геометричних груп, що лягли в основу сучасної теорії чисел і криптографії.

Термін «еліптична крива» часто спантеличує початківців: на графіку еліптичної кривої немає жодного еліпса. Еліпс описується квадратним рівнянням `(x/a)² + (y/b)² = 1`, тоді як еліптична крива є кубічною кривою вигляду `y² = x³ + a·x + b`. Цей термінологічний зв'язок — не випадковість і не помилка найменування, а наслідок ґрунтовної двохсотлітньої еволюції аналізу, геометрії, топології, математичної фізики та теорії чисел.

## 1. Загадка периметра еліпса, маятник Гюйгенса та диференціальні дослідження Фаньяно

Усе розпочалося наприкінці XVII століття з двох чисто практичних фізико-геометричних задач: астрономічного розрахунку руху планет орбітами Кеплера (обчислення довжини дуги еліпса) та точного моделювання коливань фізичного маятника з великою амплітудою коливань.

Для одиничного кола радіуса `R = 1` довжина дуги виражається через елементарні тригонометричні або обернені тригонометричні функції:
```
L_circle = ∫₀ˣ dt / √(1 - t²) = arcsin(x)
```

Проте коли Ісаак Ньютон та Ґотфрід Вільгельм Лейбніц заклали основи математичного аналізу, виявилося, що аналогічний інтеграл для дуги еліпса з канонічними півосями `a` та `b` (з ексцентриситетом `e = √(1 - b²/a²)`) принципово не зводиться до жодної скінченної комбінації елементарних функцій (раціональних, степеневих, тригонометричних, показникових чи логарифмічних):
```
L_ellipse = a · ∫₀ᵗ √((1 - e²·u²) / (1 - u²)) du
```

Аналогічна ситуація виникла у класичній механіці при аналізі коливань математичного маятника довжини `L`. Точне нелінійне диференціальне рівняння коливань `d²θ/dt² + (g/L)·sin(θ) = 0` після інтегрування закону збереження енергії визначає період коливань `T` через повний інтеграл:
```
T = 4 · √(L/g) · ∫₀^{π/2} dφ / √(1 - k² · sin²(φ)),   де k = sin(θ₀ / 2)
```

Інтеграли такого типу — де під знаком квадратного кореня стоїть многочлен третього або четвертого степеня від змінної інтегрування без кратних коренів — отримали загальну назву **еліптичних інтегралів**.

Паралельно Якоб Бернуллі 1694 року при дослідженні форми пружної балки (задача про еластику) ввів нову криву — **лемніскату Бернуллі**, задану полярним рівнянням `r² = a²·cos(2θ)` або у декартових координатах `(x² + y²)² = a²·(x² - y²)`. Довжина дуги лемніскати описується еліптичним інтегралом першого роду:
```
S(s) = ∫₀ˢ dt / √(1 - t⁴)
```

У першій половині XVIII століття італійський граф та математик Джуліо Карло дельї Тоскі ді Фаньяно (1718) вивчав геометричні властивості лемніскати. Фаньяно зробив несподіване і глибоке відкриття: хоча сам інтеграл не обчислюється у замкненому вигляді через елементарні функції, існує точний **алгебраїчний закон**, який дозволяє подвоювати або ділити навпіл дугу лемніскати за допомогою циркуля та лінійки! 

Фаньяно довів, що для заданої межі `u` нові межі `v(u)` обчислюються за точними раціональними алгебраїчними формулами:
```
v = (2·u · √(1 - u⁴)) / (1 + u⁴)
```
причому значення інтеграла до межі `v` дорівнює подвоєному інтегралу до межі `u`: `S(v) = 2·S(u)`. Це була перша у історії математики проява операції «подвоєння точки» на прихованій алгебраїчній кривій.

## 2. Відкриття Ейлера та монументальна систематизація Лежандра

23 грудня 1751 року стало знаменним днем в історії математики. 44-річний Леонард Ейлер, отримавши від Берлінської Академії наук зібрання творів графа Фаньяно «Produzioni Matematiche» для підготовки офіційного академічного відгуку, розгледів за конкретними геометричними формулами лемніскати загальний фундаментальний закон математичного аналізу.

Ейлер узагальнив результат Фаньяно і довів **загальну теорему додавання для еліптичних інтегралів**. Він розглянув нелінійне диференціальне рівняння:
```
dx / √(R(x)) + dy / √(R(y)) = 0
```
де `R(t) = a₀ + a₁·t + a₂·t² + a₃·t³ + a₄·t⁴` — довільний кубічний або квартичний многочлен без кратних коренів.

Ейлер показав, що перший інтеграл цього диференціального рівняння є строго алгебраїчним співвідношенням між `x` та `y`. Зокрема, сума двох таких еліптичних інтегралів дорівнює третьому інтегралу від раціональної алгебраїчної симетричної комбінації меж:
```
∫₀ˣ dt / √(R(t)) + ∫₀ʸ dt / √(R(t)) = ∫₀ᶻ dt / √(R(t))
```
де нова верхня межа `z = f(x, y)` задається явним алгебраїчним рівнянням від `x` та `y`:
```
z = (x·√(R(y)) + y·√(R(x))) / (1 - a₄·x²·y²)
```

Теорема Ейлера про додавання еліптичних інтегралів стала першим в історії аналітичним вираженням операції групового додавання точок на еліптичній кривій.

Наприкінці XVIII — на початку XIX століття французький математик Адрієн-Марі Лежандр присвятив понад 40 років систематизації та табличному обчисленню еліптичних інтегралів. У своєму монументальному тритомнику «Traité des fonctions elliptiques» (1825–1828) Лежандр довів, що будь-який еліптичний інтеграл шляхом раціональних замін змінних зводиться до лінійної комбінації трьох канонічних форм:
1. **Перший рід `F(k, φ)`:** `∫₀ᵠ dθ / √(1 - k²·sin²θ)` (інтеграл без особливих точок на дійсній осі).
2. **Другий рід `E(k, φ)`:** `∫₀ᵠ √(1 - k²·sin²θ) dθ` (обчислення довжини дуги еліпса).
3. **Третій рід `П(n, k, φ)`:** `∫₀ᵠ dθ / ((1 - n·sin²θ) · √(1 - k²·sin²θ))` (логарифмічні особливості).

Лежандр також відкрив чудове аналітичне співвідношення між повними еліптичними інтегралами першого та другого роду та їхніми доповняльними модулями `k' = √(1 - k²)` (**Співвідношення Лежандра для періодів**):
```
E(k) · K(k') + E(k') · K(k) - K(k) · K(k') = π / 2
```

Проте Лежандр розглядав інтеграли виключно як прямі функції від верхньої межі `x`, що заважало побачити їхню повну внутрішню періодичну симетрію. Сам Лежандр на схилі літ визнавав, що його сорокарічна титанічна праця була лише класифікацією зовнішньої форми явища.

## 3. Революційна ідея Ґаусса, Абеля і Якобі: обернення та подвійна періодичність

Справжній науковий прорив відбувся у 1827–1829 роках завдяки роботам трьох геніїв — Карла Фрідріха Ґаусса (чиї щоденникові записи 1797–1799 років залишалися неопублікованими за його життя), молодого норвежця Нільса Генріка Абеля та німецького математика Карла Ґустава Якоба Якобі.

### 1. Ранні відкриття Ґаусса та арифметико-геометричне середнє (AGM)
Ще 1799 року 22-річний Ґаусс виявив дивовижний зв'язок між повним еліптичним інтегралом лемніскати `ϖ = 2 · ∫₀¹ dt / √(1 - t⁴) \approx 2.6220575...` та **арифметико-геометричним середнім `AGM(1, √2)`**:
```
ϖ = π / AGM(1, √2)
```
Ґаусс першим зрозумів необхідність розгляду оберненої функції — **синуса лемніскати** `x = sl(u)`, та занотував у своєму щоденнику, що ця функція має два комплексні періоди: дійсний `2·ϖ` та уявний `2·i·ϖ`. Проте через свою строгу вимогу публікувати лише довершені результати («Pauca sed matura») Ґаусс не оприлюднив ці дослідження.

### 2. Тріумф та трагедія Нільса Генріка Абеля
1827 року у журналі Крелля («Crelle's Journal») 25-річний норвезький математик Нільс Генрік Абель опублікував епохальну працю «Recherches sur les fonctions elliptiques». Абель зробив революційний крок: замість дослідження інтеграла `u = I(x)` він запропонував **обернути** цю залежність і досліджувати залежність межі `x` від значення інтеграла `u`:
```
x = φ(u),  де  u = ∫₀ˣ dt / √( (1 - t²) · (1 - k² · t²) )
```

Розглянувши ці функції у комплексній площині `u ∈ ℂ`, Абель відкрив їхню унікальну природу: еліптичні функції є **двоперіодичними мероморфними функціями**.

На відміну від експоненти `eᶻ` (один комплексний період `2·π·i`) чи тригонометричного синуса `sin(z)` (один дійсний період `2·π`), еліптична функція має **два лінійно незалежні комплексні періоди** `ω₁` та `ω₂` (відношення яких має ненульову уявну частину `Im(ω₂ / ω₁) > 0`):
```
f(u + m·ω₁ + n·ω₂) = f(u)  для всіх m, n ∈ ℤ
```

Фундаментальною областю значень еліптичних функцій є паралелограм періодів, протилежні сторони якого склеюються, утворюючи **комплексний тор** — замкнену двовимірну поверхню `ℂ / Λ`, де `Λ = {m·ω₁ + n·ω₂ : m, n ∈ ℤ}` — гратка періодів.

Абель також сформулював і довів монументальну **Теорему Абеля про дивізори на алгебраїчних кривих** (1826, представлена Паризькій Академії, де рукопис загубив Коші й знайшов лише після смерті Абеля). Теорема Абеля встановила загальні алгебраїчні умови, за яких сума інтегралів від алгебраїчних функцій дорівнює нулю.

### 3. «Fundamenta Nova» Карла Якобі та тета-функції
Майже одночасно з Абелем 24-річний Карл Ґустав Якоб Якобі розвинув теорію **еліптичних функцій Якобі** `sn(u, k)`, `cn(u, k)` та `dn(u, k)`. У своєму шедеврі «Fundamenta Nova Theoriae Functionum Ellipticarum» (1829) Якобі ввів потужний аналітичний апарат **тета-функцій** `θ₁(z, q), θ₂(z, q), θ₃(z, q), θ₄(z, q)` (де `q = exp(i·π·τ)` — модулярний параметр):
```
θ₃(z, q) = 1 + 2 · ∑_{n=1}^{∞} q^{n²} · cos(2·n·z)
```
Тета-функції дозволили представити будь-яку еліптичну функцію як відношення двох цілих рядів, що збігаються з надзвичайною експоненційною швидкістю. 

### 3. Арифметико-геометричне середнє (AGM) Ґаусса
Карл Фрідріх Ґаусс розробив надзвичайно швидкий чисельний алгоритм обчислення повних еліптичних інтегралів через ітераційний процес **арифметико-геометричного середнього (AGM)**:
```
a₀ = a,   b₀ = b
a_{n+1} = (a_n + b_n) / 2
b_{n+1} = √(a_n · b_n)
```
Ґаусс довів, що обидві послідовності прямують до спільної границі `M(a, b) = AGM(a, b)` із квадратичною швидкістю збіжності (кількість вірних десяткових знаків подвоюється на кожній ітерації). Повний еліптичний інтеграл першого роду `K(k)` обчислюється за елегантною формулою:
```
K(k) = π / ( 2 · AGM(1, √(1 - k²)) )
```
Це відкриття заклало фундамент для сучасних надшвидких алгоритмів обчислення числа `π` (алгоритм Саламіна–Брента) та елементарних функцій із довільною точністю в комп'ютерній алгебрі.

### 4. Розв'язання рівняння 5-го степеня Шарлем Ермітом (1858)
1858 року французький математик Шарль Ерміт подолав обмеження теореми Абеля–Руффіні про неможливість розв'язання загальних алгебраїчних рівнянь 5-го степеня у звичайних арифметичних радикалах. Ерміт довів, що нормальну форму Брінга–Жеррара `x⁵ - x + a = 0` можна точно розв'язати у радикалах від модулярних еліптичних функцій Якобі. 

Використовуючи групу автоморфізмів двадцятигранника (ікосаедра), що ізоморфна простій знаковизначеній групі `A₅`, та модулярне рівняння 5-го степеня для функцій ділення періодів, Ерміт виразив усі 5 коренів рівняння через значення тета-констант `θ₂(0, q), θ₃(0, q), θ₄(0, q)`. Це стало тріумфом аналітичної теорії еліптичних функцій над класичною алгеброю!

## 4. Канонічна теорія Вейєрштрасса та геометрія Рімана

У другій половині XIX століття теорія еліптичних функцій набула сучасного вигляду завдяки двом різним, але взаємодоповнюючим підходам — аналітичному Карла Вейєрштрасса та геометричному Бернгарда Рімана.

### 1. Канонічна `℘`-функція Вейєрштрасса
У 1860-х роках видатний німецький математик Карл Вейєрштрасс у Берлінському університеті відмовився від заплутаної системи трьох функцій Якобі та висунув на перший план єдину канонічну парну двоперіодичну функцію з подвійним полюсом у нулі — **`℘`-функцію Вейєрштрасса**:
```
℘(z; Λ) = 1/z² + ∑_{w ∈ Λ\{0}} [ 1/(z - w)² - 1/w² ]
```

Вейєрштрасс довів, що функція `℘(z)` та її похідна `℘'(z)` задовольняють диференціальне рівняння кубіки:
```
(℘'(z))² = 4·(℘(z))³ - g₂·℘(z) - g₃
```
де інваріанти `g₂` та `g₃` прямо виражаються через ряди Ейзенштейна гратки періодів `Λ`:
```
g₂ = 60 · ∑_{w ∈ Λ\{0}} 1/w⁴,   g₃ = 140 · ∑_{w ∈ Λ\{0}} 1/w⁶
```

Зробивши алгебраїчну заміну змінних `x = ℘(z)` та `y = ℘'(z) / 2`, диференціальне рівняння Вейєрштрасса перетворюється на канонічну алгебраїчну кубічну криву у проективній площині `ℙ²(ℂ)`:
```
y² = x³ + a·x + b
```
де `a = -g₂ / 4` та `b = -g₃ / 4`.

Голоморфне відображення `z ↦ (℘(z) : ℘'(z)/2 : 1)` задає **точний аналітичний та геометричний ізоморфізм** між комплексним тором `ℂ / Λ` (з природною груповою операцією додавання комплексних чисел `z₁ + z₂ mod Λ`) та кубічною кривою у проективній площині `ℙ²(ℂ)`.

### 2. Квазіперіодичні дзета- та сигма-функції та співвідношення Лежандра
Поряд із `℘(z)`, Вейєрштрасс увів допоміжні функції `ζ(z)` та `σ(z)`. Дзета-функція задовольняє `ζ'(z) = -℘(z)` і є квазіперіодичною:
```
ζ(z + ω₁) = ζ(z) + η₁,   ζ(z + ω₂) = ζ(z) + η₂
```
де `η₁ = 2·ζ(ω₁ / 2)` та `η₂ = 2·ζ(ω₂ / 2)` — квазіперіодичні константи. Вейєрштрасс довів, що періоди `ω₁, ω₂` та константи `η₁, η₂` пов'язані фундаментальним **співвідношенням Лежандра**:
```
η₁ · ω₂ - η₂ · ω₁ = 2 · π · i
```
Це співвідношення є комплексним аналітичним виразом теореми Коші про інтегрування диференціалів вздовж границі фундаментального паралелограма гратки.

### 3. Ріманові поверхні та топологічний рід g = 1
Бернгард Ріман у своїй фундаментальній праці з теорії абелевих функцій (1857) запровадив поняття **Ріманової поверхні**. Ріман показав, що еліптична крива над `ℂ` є компактною одновимірною комплексною рімановою поверхнею топологічного роду `g = 1` (поверхнею з однією ручкою — тором). 

Простір голоморфних диференціальних 1-форм на ній є одновимірним і породжується інваріантним диференціалом `ω = dx / (2y) = dz`. Інтегрування цього диференціала вздовж двох незалежних замкнених циклів (A-циклу та B-циклу на торі) відновлює фундаментальні періоди гратки `ω₁` та `ω₂`.

## 5. Методологічна суперечка XIX століття: Берлін проти Геттінгена

У другій половині XIX століття дослідження еліптичних функцій опинилося в центрі фундаментальної методологічної дискусії між двома провідними математичними центрами Німеччини:

- **Берлінська школа (Карл Вейєрштрасс, Леопольд Кронекер):**
  Наполягала на строгій арифметизації аналізу. Будь-який математичний об'єкт мав бути побудований з цілих чисел за допомогою скінченної кількості арифметичних дій або строго збіжних степеневих рядів з ε-δ оцінками. Вейєрштрасс скептично ставився до геометричної інтуїції, наголошуючи, що необачне спирання на наочні образи може призвести до хибних висновків (що він блискуче проілюстрував відкриттям неперервної функції, яка ніде не має похідної).

- **Геттінгенська школа (Бернгард Ріман, Фелікс Клейн):**
  Розвивала концептуальний, топологічний та геометричний підхід. Ріман виходив із глобальної структури комплексних многовидів, конформних відображень та інтегральних інваріантів, розглядаючи еліптичні криві як єдине ціле через призму їхньої топології та періодів.

Наприкінці століття Фелікс Клейн та Давид Гільберт синтезували обидва підходи. Клейн показав, що геометрія комплексних торів та модулярних функцій тісно пов'язана з групами симетрій платонових тіл (ікосаедром) та неевклідовою геометрією Лобачевського на верхній комплексній півплощині `ℍ`.

## 6. Геометрія модулярних кривих: від верхньої півплощини до простору модулів

Кожна еліптична крива над `ℂ` повністю визначається граткою `Λ = ℤ·ω₁ + ℤ·ω₂`. Оскільки масштабування гратки `Λ ↦ c·Λ` дає ізоморфну еліптичну криву, будь-яку гратку можна нормалізувати вибором базису `(1, τ)`, де параметр `τ = ω₂ / ω₁` лежить у верхній комплексній півплощині `ℍ = { τ ∈ ℂ : Im(τ) > 0 }`.

Дві гратки `Λ_τ` та `Λ_{τ'}` задають ізоморфні еліптичні криві тоді й лише тоді, коли їхні модулярні параметри пов'язані дробово-лінійним перетворенням із **повної модулярної групи `SL₂(ℤ)`**:
```
τ' = (a·τ + b) / (c·τ + d),   де a, b, c, d ∈ ℤ,  a·d - b·c = 1
```

Фактор-простір `Y(1) = SL₂(ℤ) \ ℍ` є **простором модулів еліптичних кривих**. Функція Клейна `j(τ)` (модулярний `j`-інваріант) здійснює конформний ізоморфізм між простором модулів `Y(1)` та комплексною площиною `ℂ`. 

Додавання точки на нескінченності (каспа `τ = i·∞`) перетворює простір модулів на компактну модулярну криву `X(1) ≅ ℙ¹(ℂ)`.

Конгруенц-підгрупи `Γ₀(N)` та `Γ₁(N)` породжують модулярні криві `X₀(N)` та `X₁(N)`, які параметризують класи еліптичних кривих із фіксованими циклічними підгрупами порядку `N`. Саме геометрія цих кривих стала ключем до розв'язання найважливіших арифметичних проблем XX століття.

## 7. Арифметична революція XX століття: Морделл, Вейль, Гассе та Мазур

На початку XX століття фокус досліджень еліптичних кривих перемістився з комплексного аналізу в арифметичну алгебраїчну геометрію та теорію чисел: скільки розв'язків у цілих або раціональних числах `(x, y) ∈ ℚ²` має кубічне рівняння `y² = x³ + a·x + b`?

### 1. Анрі Пуанкаре та ідея рангу (1901)
У своїй класичній статті «Sur les propriétés arithmétiques des courbes algébriques» Анрі Пуанкаре першим дав строге алгебраїчне формулювання геометричного методу хорд і дотичних як групової операції на раціональних точках `E(ℚ)`. Пуанкаре висловив гіпотезу про те, що група `E(ℚ)` є скінченно породженою, і ввів поняття **арифметичного рангу `r`** еліптичної кривої.

### 2. Теорема Морделла–Вейля (1922, 1928)
- 1922 року британський математик Луї Морделл блискуче довів гіпотезу Пуанкаре для поля раціональних чисел `ℚ`, застосувавши метод нескінченного спуску Ферма:
```
E(ℚ) ≅ E(ℚ)_tors ⊕ ℤʳ
```
де `E(ℚ)_tors` — скінченна група точок скінченного порядку (кручення), а `r ≥ 0` — ранг вільної абелевої групи.
- 1928 року французький математик Андре Вейль узагальнив теорему Морделла на будь-які алгебраїчні числові поля `K` та абелеві многовиди довільної вимірності (**Теорема Морделла–Вейля**), запровадивши концепцію висоти точки.

### 3. Теорема Мазура про кручення (1977)
Американський математик Баррі Мазур здійснив монументальний прорив, застосувавши геометрію модулярних кривих `X₁(N)` та їхніх якобіанів (метод розрізу Ейзенштейна). Мазур повністю класифікував усі можливі структури груп кручення над `ℚ`: група `E(ℚ)_{tors}` може приймати **лише один із 15 можливих ізоморфних типів**:
- `ℤ / n·ℤ` для `1 ≤ n ≤ 10` або `n = 12`;
- `ℤ / 2·ℤ ⊕ ℤ / 2n·ℤ` для `1 ≤ n ≤ 4`.

### 4. Комплексне множення та Теорема Гассе над скінченними полями (1934–1936)
Німецький математик Гельмут Гассе дослідив властивості еліптичних кривих над скінченними полями залишків `𝔽ₚ`. Гассе розглянув дію ендоморфізму Фробеніуса `π : (x, y) ↦ (xᵖ, yᵖ)` та довів аналог Гіпотези Рімана для функціональних полів роду 1 — фундаментальну **Теорему Гассе**:
```
| #E(𝔽ₚ) - (p + 1) | ≤ 2 · √p
```

### 5. Комп'ютерні експерименти на EDSAC 2 та Гіпотеза BSD (1960-ті)
На початку 1960-х років у Кембриджському університеті Браян Берч та Пітер Свіннертон-Даєр використали один із перших лампових комп'ютерів EDSAC 2 для чисельного підрахунку кількості точок `#E(𝔽ₚ)` для тисяч простих чисел `p`. На основі цих обчислень вони сформулювали знамениту **Гіпотезу Берча і Свіннертона-Даєра (BSD)** — одну з семи Проблем Тисячоліття Інституту Клея, яка стверджує, що ранг `r` дорівнює порядку нуля аналітичної `L`-функції `L(E, s)` у точці `s = 1`.

### 6. Факторизація цілих чисел методом ECM Гендріка Ленстри (1987)
Нідерландський математик Гендрік Ленстра розробив метод факторизації великих складених чисел `N` за допомогою еліптичних кривих (ECM). Метод моделює групову операцію над кільцем `ℤ / Nℤ`. Якщо для невідомого дільника `p | N` порядок групи `#E(𝔽ₚ)` ділить скаляр `k`, спроба виконати інверсію знаменника за алгоритмом Евкліда знаходить дільник `gcd(den, N) = p`. ECM має субекспоненційну складність і залишається найшвидшим у світі алгоритмом для пошуку дільників розміром 20–80 десяткових знаків.

## 8. Модулярні форми, програма Ленглендса та доведення теореми Ферма

У другій половині XX століття еліптичні криві стали центральним вузлом так званої **Програми Ленглендса** — грандіозної системи гіпотез, що пов'язують теорію чисел, представлення груп Галуа та автоморфні форми.

### 1. Модулярні форми та гіпотеза Таніями–Шимури–Вейля
Японські математики Ютака Таніяма та Ґоро Шимура (1955–1957), спираючись на ідеї Андре Вейля, висунули сміливу гіпотезу:
> **Гіпотеза про модулярність:** Кожна еліптична крива `E`, визначена над полем раціональних чисел `ℚ`, є **модулярною**.

Це означає, що послідовність чисел `a_p = p + 1 - #E(𝔽ₚ)` (слідів Фробеніуса) збігається з коефіцієнтами Фур'є `c_p` деякої параболічної модулярної нової форми `f(z) = ∑ c_n · qⁿ` ваги 2 для конгруенц-підгрупи `Γ₀(N)` (де `N` — провідник кривої).

### 2. Епопея доведення Ендрю Вайлса (1994)
1984 року Ґерхард Фрай зрозумів, що потенційний розв'язок рівняння Ферма `aⁿ + bⁿ = cⁿ` породив би криву Фрая `y² = x · (x - aⁿ) · (x + bⁿ)` з дискримінантом `Δ = (a·b·c)²ⁿ / 256`, яка була б занадто «гладкою» (мала занадто малий рівень розгалуження) і тому не могла б бути модулярною. 1986 року Кен Рібет строгим доведенням теореми про рівень (Epsilon Conjecture) підтвердив немодулярність кривої Фрая.

1994 року Ендрю Вайлс (за участі Річарда Тейлора) побудував теорію деформацій представлень Галуа і довів теорему про модулярність для напівстабільних еліптичних кривих. Це остаточно спростувало існування кривої Фрая і довело **Велику теорему Ферма**. Згодом Крістоф Брей, Браян Конрад, Фред Даймонд та Річард Тейлор (2001) довели теорему про модулярність у повному обсязі для абсолютно всіх еліптичних кривих над `ℚ`.

## 9. Цифрова революція: Криптографія Міллера–Кобліца, спарювання та zk-SNARKs

Наприкінці XX та на початку XXI століття еліптичні криві перетворилися на найважливіший математичний інструмент сучасних цифрових технологій.

```
1718: Фаньяно (подвоєння дуги лемніскати)
  │
1751: Ейлер (алгебраїчна теорема додавання еліптичних інтегралів)
  │
1825: Лежандр (систематизація еліптичних інтегралів 1, 2, 3 роду)
  │
1827: Абель, Ґаусс, Якобі (обернення інтегралів, подвійна періодичність, комплексні тори)
  │
1860: Вейєрштрасс, Ріман (℘-функція, диференціальне рівняння кубіки y² = x³ + ax + b)
  │
1922: Морделл, Вейль (скінченна породженість групи раціональних точок E(ℚ))
  │
1934: Гассе (структура точок над F_p, гіпотеза Рімана для роду 1)
  │
1965: Берч, Свіннертон-Даєр (обчислення на EDSAC 2, формулювання гіпотези BSD)
  │
1977: Мазур (повна класифікація 15 типів кручення над ℚ)
  │
1985: Міллер, Кобліц (створення еліптичної криптографії ECC)
  │
1994: Вайлс, Тейлор (доведення теореми про модулярність та Останньої теореми Ферма)
  │
2005: Бернштейн (криві Curve25519 та Ed25519)
  │
2020+: Спарювання Вейля/Тейта, криві BN254 / BLS12-381 у zk-SNARKs та блокчейнах
```

### 1. Винайдення еліптичної криптографії (ECC, 1985)
1985 року Віктор Міллер (IBM) та Ніл Кобліц (Університет Вашингтона) незалежно запропонували використовувати дискретну групу точок еліптичної кривої над скінченним полем `𝔽ₚ` для побудови асиметричних криптосистем. 

Оскільки в групі `E(𝔽ₚ)` немає природного поняття гладкості чисел (Smoothness), там не працюють субекспоненційні алгоритми числового решета (NFS), які зламують класичний RSA та ElGamal. Задача дискретного логарифма на еліптичній кривій (ECDLP) вимагає експоненційного часу `O(√n)`. Це дозволило зменшити розмір ключа з 3072 бітів (RSA) до 256 бітів (ECC) при збереженні того самого 128-бітного рівня безпеки.

### 2. Криптографія на основі спарювань та докази з нульовим розголошенням (zk-SNARKs)
На початку XXI століття спарювання Вейля та Тейта `e_n : E[n] × E[n] → μ_n` отримали революційне конструктивне застосування. Ден Боне та Метт Франклін розробили криптосистему на основі ідентифікаторів (Identity-Based Encryption, IBE), а Боне, Лінн та Шачам — короткі цифрові підписи BLS з агрегацією.

Сьогодні спеціальні класи кривих із високою ефективністю спарювань (криві Баррето–Нерига BN254 та криві Баррето–Лінна–Скотта BLS12-381) лежать в основі найсучасніших протоколів децентралізованих систем, блокчейнів (Ethereum 2.0) та криптографічних протоколів доведення з нульовим розголошенням (**zk-SNARKs** / Groth16 / PLONK).

### 3. Інженерні стандарти Curve25519 та Ed25519
2005 року Деніел Бернштейн представив криву **Curve25519** для обміну ключами (X25519) та криву **Ed25519** для цифрових підписів. Завдяки повним формулам додавання, швидкій редукції за модулем `2²⁵⁵ - 19` та драбині Монтгомері у сталий час, ці криві стали світовим золотим стандартом інтернет-протоколів безпеки (TLS 1.3, SSH, Signal, WireGuard, Apple iMessage).

## 10. Інтегровні системи у фізиці та дзеркальна симетрія в теорії струн

Еліптичні криві відіграють виняткову роль у сучасній теоретичній та математичній фізиці:

- **Нелінійні хвилі та солітони (Рівняння Кортевега–де Фріза):**
  Точні періодичні розв'язки нелінійного хвильового рівняння Кортевега–де Фріза (KdV), що описує поширення солітонів на мілководді (хвилі Кноідаля), виражаються через еліптичні функції Якобі `cn(u, k)`.
- **Багаточастинкові інтегровні системи Калоджеро–Мозера:**
  Класична та квантова системи взаємодіючих частинок на колі з парним потенціалом Вейєрштрасса `V(x_i - x_j) = ℘(x_i - x_j)` мають повний набір збережуваних інтегралів руху, які визначаються спектральною кривою роду 1.
- **Статистична фізика та рівняння Янга–Бакстера:**
  У точних розв'язках двовимірних ґраткових моделей статистичної механіки (таких як восьмивершинна модель Бакстера та модель Ізінга в магнітному полі) фундаментальне квантове рівняння Янга–Бакстера розв'язується через еліптичні `R`-матриці, параметризовані мероморфними функціями на еліптичній кривій. Еліптична параметризація забезпечує точну комутативність трансфер-матриць за будь-яких температур, відкриваючи глибинний зв'язок між алгебраїчною геометрією та термодинамікою фазових переходів другого роду.
- **Ланцюжок Тоди та квантові групи:**
  Нелінійна динаміка ланцюжка Тоди (системи частинок на прямій з експоненційними силами взаємодії між сусідами) інтегрується в термінах тета-функцій Рімана для гіпереліптичних та еліптичних кривих. Роботи школи Людвига Фаддєєва у Санкт-Петербурзі на початку 1980-х років показали, що квантування таких еліптичних систем породжує квантові алгебри та еліптичні квантові групи (алгебри Скляніна), які поєднують некомутативну геометрію з вищими симетріями математичної фізики.
- **Теорія струн та дзеркальна симетрія:**
  У теорії суперструн одновимірний комплексний тор `ℂ / Λ` є найпростішим компактним простором Калабі–Яу (вимірності 1). Дзеркальна симетрія пов'язує комплексну структуру тора (модулярний параметр `τ`) з його симплектичною структурою (комплексифікованим келеровим об'ємом `ρ = B + i·A`), реалізуючи фундаментальну фізичну Т-дуальність струнних замкнених петель.

## 11. Постквантові перспективи: Ізогенії суперсингулярних кривих

Із розвитком квантових обчислювачів класична асиметрична криптографія опинилася перед загрозою алгоритму Пітера Шора (1994), який розв'язує задачу дискретного логарифма (ECDLP) та факторизації за поліноміальний час `O(log³ n)` на квантовому комп'ютері.

Проте еліптичні криві знайшли друге дихання у **постквантовій криптографії на основі ізогеній (Isogeny-Based Cryptography)**:
- Замість групи точок однієї кривої розглядається велетенський граф, вершинами якого є класи ізоморфізмів суперсингулярних еліптичних кривих над `𝔽_{p²}`, а ребрами — ізогенії фіксованого малого степеня `ℓ` (наприклад, `ℓ = 2` чи `ℓ = 3`).
- Такі графи (графи Пільцера–Кані–Прензеля / Рамануджана) є ідеальними експандерами з високим коефіцієнтом перемішування та спектральною щілиною.
- Знаходження шляху між двома кривими у такому графі вимагає розв'язання задачі пошуку ізогенії, яка залишається експоненційно важкою навіть для потужних квантових комп'ютерів (алгоритми CSIDH, SQISign). Навіть після відхилення протоколу SIDH через атаку Кастріка–Декса на додаткову інформацію про точки кручення, нові протоколи на основі ізогеній довели свою стійкість та компактність підписів.

Історія еліптичних кривих — це один із найвражаючих прикладів єдності та неперервності математичного пізнання в історії цивілізації. Проста і суто практична геометрична задача обчислення периметра еліпса та періоду коливань фізичного маятника у працях Фаньяно, Ейлера та Лежандра породила теорію еліптичних інтегралів. 

Обернення цих інтегралів Абелем, Ґауссом та Якобі відкрило світ двоперіодичних функцій та комплексних торів, який Вейєрштрасс та Ріман перетворили на фундамент комплексної алгебраїчної геометрії та теорії поверхонь. 

У XX столітті Морделл, Вейль, Гассе, Мазур і Ленстра перенесли цю геометрію на мову раціональних чисел та скінченних полів, що підготувало ґрунт для доведення Останньої теореми Ферма Ендрю Вайлсом та створення систем еліптичної криптографії Міллером і Кобліцом. 

Сьогодні еліптичні криві забезпечують математичний захист глобальної банківської системи, конфіденційність інтернет-трафіку, надійність систем доказів із нульовим розголошенням та квантову стійкість майбутніх протоколів зв'язку, залишаючись вічним символом глибини, гармонії та невичерпної продуктивності людського інтелекту.
