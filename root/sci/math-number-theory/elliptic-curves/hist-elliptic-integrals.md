# 📜 Від довжини дуги еліпса до алгебраїчних груп: історія еліптичних кривих

Як спроба обчислити периметр звичайного еліпса у XVIII столітті відкрила новий математичний всесвіт неалгебраїчних інтегралів, комплексних торів та геометричних груп, що лягли в основу сучасної теорії чисел і криптографії.

Термін «еліптична крива» часто спантеличує початківців: на графіку еліптичної кривої немає жодного еліпса. Еліпс описується квадратним рівнянням `(x/a)² + (y/b)² = 1`, тоді як еліптична крива є кубічною кривою вигляду `y² = x³ + a·x + b`. Цей термінологічний зв'язок — не випадковість і не помилка найменування, а наслідок ґрунтовної двохсотлітньої еволюції аналізу та геометрії.

---

## 1. Загадка периметра еліпса та диференціальні дослідження Фаньяно

Усе розпочалося наприкінці XVII століття з чисто практичної геодезичної та астрономічної задачі обчислення довжини дуги еліпса. Для одиничного кола радіуса `R = 1` довжина дуги обчислюється через елементарні тригонометричні або обернені тригонометричні функції:

```
L_circle = ∫₀ˣ dt / √(1 - t²) = arcsin(x)
```

Проте коли Ісаак Ньютон та Ґотфрід Вільгельм Лейбніц заклали основи математичного аналізу, виявилося, що аналогічний інтеграл для дуги еліпса з канонічними напіввісями `a` та `b` (з ексцентриситетом `e = √(1 - b²/a²)`) не зводиться до жодної скінченної комбінації елементарних функцій (раціональних, степенявих, тригонометричних, показниковій чи логарифмічних):

```
L_ellipse = a · ∫₀ᵗ √((1 - e²·u²) / (1 - u²)) du
```

Інтеграли такого типу — де під знаком квадратного кореня стоїть многочлен третього або четвертого степеня від змінної `u` без кратних коренів — отримали назву **еліптичних інтегралів**.

У першій половині XVIII століття італійський граф та математик-самоучка Джуліо Карло дельй Нео graph та Фаньяно (1718) вивчав криву дуги лемніскати Бернуллі `(x² + y²)² = a²·(x² - y²)`. Довжина дуги лемніскати виражається еліптичним інтегралом першого роду:

```
S(s) = ∫₀ˢ dt / √(1 - t⁴)
```

Фаньяно зробив несподіване і глибоке відкриття: хоча сам інтеграл не обчислюється у замкненому вигляді через елементарні функції, існує точний **алгебраїчний закон**, який дозволяє подвоювати або ділити навпіл дугу лемніскати. Фаньяно довів, що для заданої межі `u` нові межі `v(u)` обчислюються за точними раціональними формулами:

```
v = (2·u · √(1 - u⁴)) / (1 + u⁴)
```

причому значення інтеграла до межі `v` дорівнює подвоєному інтегралу до межі `u`: `S(v) = 2·S(u)`. Це була перша у історії математики проява операції «подвоєння точки» на прихованій алгебраїчній кривій.

## 2. Відкриття Ейлера та систематизація Лежандра

1751 року 23-річний Леонард Ейлер, рецензуючи зібрання праць Фаньяно для вступу італійського вченого до Берлінської Академії наук, розгледів за конкретними формулами лемніскати загальний фундаментальний закон. 

Ейлер узагальнив результат Фаньяно і довів **загальну теорему додавання для еліптичних інтегралів**. Він показав, що для будь-якого еліптичного інтеграла `I(x) = ∫ dx / √(R(x))`, де `R(x) = a₀ + a₁·x + a₂·x² + a₃·x³ + a₄·x⁴` — многочлен без кратних коренів, сума двох інтегралів дорівнює третьому інтегралу від раціональної алгебраїчної симетричної комбінації меж:

```
∫₀ˣ dx / √(R(x)) + ∫₀ʸ dy / √(R(y)) = ∫₀ᶻ dz / √(R(z))
```

де нова межа `z = f(x, y)` задається алгебраїчним рівнянням від `x` та `y`:

```
z = (x·√(R(y)) + y·√(R(x))) / (1 - a₄·x²·y²)
```

Теорема Ейлера про додавання еліптичних інтегралів стала першим аналітичним вираженням додавання точок на еліптичній кривій.

Наприкінці XVIII — на початку XIX століття французький математик Адрієн-Марі Лежандр присвятив понад 40 років систематизації еліптичних інтегралів. У своєму монументальному тритомнику «Traité des fonctions elliptiques» Лежандр довів, що кожен еліптичний інтеграл шляхом раціональних замін змінних зводиться до лінійної комбінації трьох канонічних форм:
1. **Перший рід `F(k, φ)`:** `∫₀ᵀ dt / √((1 - t²)·(1 - k²·t²))` (без особливих точок).
2. **Другий рід `E(k, φ)`:** `∫₀ᵀ √((1 - k²·t²) / (1 - t²)) dt` (обчислення довжини дуги еліпса).
3. **Третій рід `П(n, k, φ)`:** `∫₀ᵀ dt / ((1 - n·t²)·√((1 - t²)·(1 - k²·t²)))`.

Проте Лежандр розглядав інтеграли лише як функції від верхньої межі `x`, що заважало побачити їхню повну внутрішню симетрію.

## 3. Революційна ідея Ґаусса, Абеля і Якобі: обернення та подвійна періодичність

Справжній науковий вибух відбувся у 1827–1829 роках завдяки незалежним роботам трьох математиків — Карла Фрідріха Ґаусса (чиї ранні щоденники 1797 року залишалися неопублікованими за його життя), норвежця Нільса Генріка Абеля та німця Карла Ґустава Якоба Якобі.

Ґаусс, Абель і Якобі зробили революційний крок: замість того, щоб досліджувати інтеграл `u = I(x)` як функцію від верхньої межі `x`, вони запропонували **обернути** цю залежність і розглядати межу `x` як функцію від значення інтеграла `u`:

```
x = φ(u),  де  u = ∫₀ˣ dt / √(1 - t⁴)
```

Ґаусс назвав таку обернену функцію **синусом лемніскати** `sl(u)`. Абель і Якобі узагальнили цей підхід на довільні еліптичні інтеграли, створивши теорію **еліптичних функцій Якобі** `sn(u, k)`, `cn(u, k)` та `dn(u, k)`.

Розглянувши ці функції у комплексній площині `u ∈ ℂ`, Абель і Якобі відкрили їхню вражаючу та унікальну властивість: еліптичні функції є **двоперіодичними голоморфними мероморфними функціями**.

На відміну від звичайної показниковій функції `eᶻ` чи синуса `sin(z)`, які мають один період у комплексній площині (`2·π·i` для експоненти), еліптична функція має **два лінійно незалежні комплексні періоди** `ω₁` та `ω₂` (відношення яких не є дійсним числовим значенням, `Im(ω₂ / ω₁) > 0`):

```
f(u + m·ω₁ + n·ω₂) = f(u)  для всіх m, n ∈ ℤ
```

Це означало, що область значень еліптичних функцій визначається не лінійною смугою, а **комплексним тором** — двовимірною поверхнею `ℂ / Λ`, утвореною факторизацією комплексної площини за граткою періодів `Λ = {m·ω₁ + n·ω₂ : m, n ∈ ℤ}`.

Абель також довів фундаментальну теорему (Теорема Абеля про резидууми), яка дала повне алгебраїчне характеристичне визначення умов, за яких сума точок на комплексній алгебраїчній кривій дорівнює нулю. 

Якобі розробив потужний апарат **тета-функцій** `θ₁(z, q), θ₂(z, q), θ₃(z, q), θ₄(z, q)`, які виражають еліптичні функції як відношення нескінченних збіжних рядів. За допомогою модулярних функцій Якобі французький математик Шарль Ерміт 1858 року розв'язав загальне алгебраїчне рівняння п'ятого степеня у радикалах еліптичних функцій (чого неможливо зробити у звичайних арифметичних радикалах за теоремою Абеля–Руффіні).

## 4. Канонічна теорія Вейєрштрасса та комплексна геометрія

У 1860-х роках видатний німецький математик Карл Вейєрштрасс привів теорію еліптичних функцій до її найдосконалішої сучасної форми. Він висунув на перший план єдину канонічну двоперіодичну функцію — **`℘`-функцію Вейєрштрасса**:

```
℘(z; Λ) = 1/z² + ∑_{w ∈ Λ\{0}} [ 1/(z - w)² - 1/w² ]
```

Вейєрштрасс довів, що функція `℘(z)` та її перша похідна `℘'(z)` задовольняють точне алгебраїчне диференціальне рівняння:

```
(℘'(z))² = 4·(℘(z))³ - g₂·℘(z) - g₃
```

де інваріанти `g₂` та `g₃` прямо виражаються через ряди Ейзенштейна гратки періодів `Λ`:

```
g₂ = 60 · ∑_{w ∈ Λ\{0}} 1/w⁴,   g₃ = 140 · ∑_{w ∈ Λ\{0}} 1/w⁶
```

Якщо виконати заміни координат `x = ℘(z)` та `y = ℘'(z) / 2`, диференціальне рівняння Вейєрштрасса перетворюється на канонічну алгебраїчну кубічну криву:

```
y² = x³ + a·x + b
```

де `a = -g₂ / 4` та `b = -g₃ / 4`.

Так аналітичне дослідження XVIII століття об'єдналося з алгебраїчною геометрією: голоморфне відображення `z ↦ (℘(z), ℘'(z)/2)` задає **точний аналітичний ізоморфізм** між комплексним тором `ℂ / Λ` (з природною операцією додавання комплексних чисел `z₁ + z₂ mod Λ`) та кубічною кривою у проективній площині `ℙ²(ℂ)`.

Саме цей ізоморфізм переносить звичайне адитивне додавання комплексних чисел на торі у геометричний закон хорд і дотичних на кубічній кривій.

## 5. Арифметична революція XX століття: Морделл, Вейль, Гассе та Ленстра

На початку XX століття фокус досліджень перемістився з комплексного аналізу в арифметичну геометрію та теорію чисел. Науковців цікавило питання: скільки розв'язків у цілих або раціональних числах `(x, y) ∈ ℚ²` має рівняння `y² = x³ + a·x + b`?

- **1901 рік:** Анрі Пуанкаре запровадив геометрію січних і дотичних як алгебраїчну групову операцію на кубічних кривих і висловив припущення про скінченну породженість цієї групи.
- **1922 рік:** Британський математик Луї Морделл довів фундаментальну теорему: для будь-якої еліптичної кривої `E` над полем раціональних чисел `ℚ`, група раціональних точок `E(ℚ)` є **скінченно породженою абелевою групою** (`E(ℚ) ≅ E(ℚ)_tors ⊕ ℤʳ`).
- **1934 рік:** Андре Вейль узагальнив результат Морделла на довільні алгебраїчні числові поля `K` та абелеві многовиди вищих розмірностей (Теорема Морделла–Вейля).
- **1936 рік:** Гельмут Гассе дослідив еліптичні криві над скінченними полями `𝔽ₚ` і довів фундаментальну оцінку на кількість дискретних точок `|N - (p + 1)| ≤ 2·√p`.
- **1987 рік:** Гендрік Ленстра розробив **метод факторизації цілих чисел на еліптичних кривих (ECM)**, який використовує виродження групового закону при обчисленні `k·P (mod n)` для швидкого знаходження дільників великих чисел.

## 6. Цифрова революція: Криптографія Міллера–Кобліца та Велика теорема Ферма

У 1980–1990-х роках відбулися дві масштабні події, які перетворили еліптичні криві на один із головних інструментів сучасної цивілізації:

1. **Заснування еліптичної криптографії (ECC, 1985):** Віктор Міллер (IBM) та Ніл Кобліц (Університет Вашингтона) незалежно запропонували використовувати групу точок еліптичної кривої над скінченними полями для побудови асиметричних криптосистем. Задача дискретного логарифма на еліптичних кривих (ECDLP) виявилася набагато складнішою за класичну задачу розкладання на множники, що дозволило зменшити розмір ключів безпеки з 3072 біт до 256 біт при однаковій стійкості.

2. **Доведення Великої теореми Ферма (1994):** Ендрю Уайлс за участі Річарда Тейлора довів теорему про модулярність (гіпотезу Таніями–Шимури–Вейля), яка стверджує, що кожна еліптична крива над `ℚ` є модулярною. Оскільки Ґерхард Фрай та Жан-П'єр Серр раніше довели, що потенційний розв'язок рівняння Ферма `aⁿ + bⁿ = cⁿ` породив би гіпотетичну криву Фрая, доведення модулярності еліптичних кривих автоматично поставило крапку у 350-річній загадці П'єра Ферма.

Сьогодні еліптичні криві стоять у центрі безпеки інтернет-протоколів (HTTPS/TLS 1.3), блокчейн-технологій (secp256k1 у Bitcoin/Ethereum), електронного підпису Ed25519 та доказах із нульовим розголошенням (Zero-Knowledge Proofs, zk-SNARKs nad BN254). Цей двохсотлітній шлях від простих задач про периметр еліпса до криптографічного захисту інтернет-трафіку є одним із найвражаючих прикладів того, як чиста математична теорія перетворюється на незамінний фундамент технічного прогресу людства.
