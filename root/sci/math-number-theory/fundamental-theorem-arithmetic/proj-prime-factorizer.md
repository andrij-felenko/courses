# Практика: Програмний факторизатор чисел

## 1. Постановка задачі

Основна теорема арифметики стверджує, що кожне натуральне число, більше за 1, можна єдиним чином подати у вигляді добутку простих множників. Знаходження цих множників для надвеликих чисел є складною обчислювальною задачею, яка лежить в основі сучасної криптографії, зокрема популярного алгоритму RSA. Надійність таких систем безпосередньо залежить від неможливості швидко факторизувати великі напівпрості числа.

Наша практична задача — розробити ефективну програму мовою C++17, яка приймає на вхід ціле число (аж до максимального 64-бітного значення) і виводить його розклад на прості множники. Оскільки класичні методи працюють надто повільно для таких масштабів, ми застосуємо комбінацію методу пробного ділення та алгоритму ро-методу Полларда, що значно прискорить пошук дільників.

## 2. Теоретичний мінімум

Метод пробного ділення є найпростішим підходом. Він полягає в тому, щоб перевіряти подільність заданого числа n на всі можливі дільники від 2 до √n. Це ефективно працює для невеликих чисел або для вилучення дуже малих простих дільників (наприклад, 2, 3, 5), але стає неприйнятним для 64-бітних чисел через експоненційне зростання часу обчислень.

Алгоритм ро-методу Полларда (Pollard's rho algorithm) — це імовірнісний алгоритм, який набагато швидше знаходить нетривіальні дільники великих чисел. Його ідея базується на парадоксі днів народження та побудові псевдовипадкової числової послідовності за правилом x = (x² + c) mod n. Завдяки скінченності остач послідовність неминуче зациклюється, утворюючи форму літери "ро" (ρ). Якщо обчислювати найбільший спільний дільник d = НСД(|x - y|, n) для різних значень кроку (де y обчислюється вдвічі швидше за x), існує висока ймовірність знайти нетривіальний дільник d.
Щоб уникнути нескінченних спроб факторизації вже простого числа, перед застосуванням ро-методу число перевіряється на простоту за допомогою [Тест Міллера — Рабіна](root:math-number-theory/miller-rabin-test).

## 4. Збірка та запуск

Збережіть наведений код у файл `factorizer.cpp`. Для збірки програми в терміналі скористайтеся компілятором `g++` або `clang++`, вказавши підтримку стандарту C++17. Обов'язково ввімкніть максимальну оптимізацію:

```bash
g++ -O3 -std=c++17 factorizer.cpp -o factorizer
./factorizer
```

Прапорець `-O3` є критично важливим для обчислювально інтенсивних алгоритмів. Без нього розрахунки модульної арифметики для 128-бітних чисел будуть працювати в кілька разів повільніше.

## 5. Аналіз результатів

Після запуску програма виведе: `Факторизація числа 13835058055282163712: 2 * 2 * 2 * 2 * 2 * 2 * 2 * 2 * 2 * 2 * 2 * 2 * 2 * 2 * 2 * 2 * 2 * 2 * 2 * 2 * 2 * 2 * 2 * 2 * 2 * 2 * 3331 * 62057` (числа наведено для прикладу). Для великих напівпростих чисел програма знаходить множники за частки секунди. 

Ро-метод Полларда демонструє асимптотичну часову складність близько O(n^0.25), що перетворює його на потужний інструмент для факторизації 64-бітних цілих чисел, недосяжних для простого перебору за прийнятний час. Застосування [Тест Міллера — Рабіна](root:math-number-theory/miller-rabin-test) убезпечує рекурсію від безкінечного розв'язання вже простих чисел. Наступним кроком у вивченні алгоритмів факторизації може стати метод квадратичного решета, який розширює можливість обчислень до 100 і більше десяткових знаків.
