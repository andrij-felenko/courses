# 🧮 Рушій спуску: чому x⁴ + y⁴ = z² не має цілих розв'язків

Ця вставка доводить строго й до кінця одне рівняння — **x⁴ + y⁴ = z² не має розв'язку в додатних цілих числах** — і показує, як саме звідси падає показник чотири. Доводимо методом [нескінченного спуску](root:math-logic/infinite-descent): припускаємо, що розв'язок усе-таки є, і з нього самого, чистою алгеброю, будуємо інший розв'язок того самого вигляду, але з **меншим** z. Повторюючи, дістали б нескінченний спадний ланцюг додатних цілих — а такого не буває, бо нижче одиниці натуральним числам спадати нікуди. Отже, першого розв'язку не було. Уся машина крутиться довкола двох важелів: параметризації [трійок Піфагора](root:math-number-theory/pythagorean-triples) і [єдиності розкладу на прості множники](root:math-number-theory/fundamental-theorem-arithmetic).

> 🔧 **Навіщо доводити саме «слабше» рівняння.** Показник чотири — це x⁴ + y⁴ = w⁴, тобто права частина мусить бути точним **четвертим** степенем. Ми ж беремо x⁴ + y⁴ = z², де праворуч лише точний **квадрат**. Це вимога слабша (квадратів набагато більше, ніж четвертих степенів), а тому саме твердження — сильніше: кожен розв'язок рівняння з w⁴ автоматично є розв'язком рівняння з z² (просто z = w²), тож «немає розв'язку з квадратом» одразу тягне «немає розв'язку з четвертим степенем». Але головна причина глибша. Рівняння з z² **замкнене** відносно спуску: машина бере розв'язок (x, y, z) і повертає (a, b, c) знову з квадратом праворуч. Якби ми чіплялися за форму w⁴, то менший об'єкт мусив би мати c саме точним квадратом — а цього ніщо не гарантує, форма зламалася б після першого ж кроку і драбина не повторювалася б. Слабше рівняння — це рівно те, що робить спуск самоподібним.

## Два важелі

**Перший — параметризація трійок Піфагора.** Примітивна трійка — це a² + b² = c² зі взаємно простими a, b. У кожній такій трійці рівно один катет парний; якщо парний саме b, то знайдуться взаємно прості p > q > 0 різної парності (одне парне, друге непарне), для яких

```
a = p² − q²    (непарний катет)
b = 2pq        (парний катет)
c = p² + q²
```

Це не здогад, а повний опис усіх примітивних трійок — саме він розчепить наше рівняння на керовані шматки.

**Другий — добуток, що є квадратом.** Якщо кілька **попарно взаємно простих** цілих перемножуються в точний квадрат, то кожен множник окремо — теж точний квадрат. Причина проста і лежить в [єдиності розкладу на прості](root:math-number-theory/fundamental-theorem-arithmetic): будь-який простий, що ділить один із множників, у решту не входить (вони з ним взаємно прості), тож увесь його показник у добутку зібраний в одному місці; а раз добуток — квадрат, цей показник парний — отже, той єдиний множник, у якому простий сидить, сам квадрат. Наочно:

```
4 · 9 · 25 = 900 = 30²      → 4 = 2², 9 = 3², 25 = 5²   (кожен квадрат)
```

Умова про попарну простоту не декоративна. Без неї правило хибне: 2 · 8 = 16 = 4² — добуток квадрат, а жоден зі співмножників квадратом не є (бо 2 і 8 мають спільний дільник, і двійки «перетікають» між ними).

## Крок за кроком: розв'язок → менший розв'язок

Хай (x, y, z) — розв'язок x⁴ + y⁴ = z² у додатних цілих. Серед усіх розв'язків візьмімо той, у якого z **найменше** можливе (таке існує: натуральні числа не спадають без дна). Уся мета — побудувати розв'язок із ще меншим z і тим отримати суперечність.

**Крок 1. x і y взаємно прості.** Нехай d = gcd(x, y) і d > 1. Тоді

```
x = d·x₁,   y = d·y₁
d⁴·x₁⁴ + d⁴·y₁⁴ = z²   ⇒   d⁴ | z²   ⇒   d² | z
z = d²·z₁:   d⁴x₁⁴ + d⁴y₁⁴ = d⁴z₁²   ⇒   x₁⁴ + y₁⁴ = z₁²
z₁ = z / d² < z
```

Вийшов менший розв'язок — суперечність із мінімальністю z. Отже, d = 1: числа x, y взаємно прості.

**Крок 2. Рівно одне з x, y парне.** Обидва парними бути не можуть — вони взаємно прості. Обидва непарними — теж ні, і це видно за модулем 8. Квадрат непарного завжди дає остачу 1: (2k+1)² = 4k(k+1) + 1, а k(k+1) парне, тож ділиться на 8 без остачі. Звідси й четвертий степінь непарного ≡ 1 (mod 8). Якби x, y були непарні разом:

```
x⁴ + y⁴ ≡ 1 + 1 ≡ 2 (mod 8)
```

Але квадрат z² за модулем 8 буває лише 0, 1 або 4 — двійки серед них немає. Суперечність. Отже, одне з чисел парне; хай це y (парне), а x непарне.

**Крок 3. (x², y², z) — примітивна трійка Піфагора.** Перепишімо рівняння як (x²)² + (y²)² = z². Катети x² і y² взаємно прості (спільний простий дільник ділив би й x, і y), тож трійка примітивна. Парний катет тут — y² (бо y парне, x непарне). Застосуймо параметризацію з взаємно простими p > q > 0 різної парності:

```
x² = p² − q²
y² = 2pq
z  = p² + q²
```

**Крок 4. Непарний катет дає ще одну примітивну трійку.** З першого рядка x² = p² − q² миттєво

```
x² + q² = p²
```

Знову трійка Піфагора — і знову примітивна: спільний простий дільник x і q ділив би p² = x² + q², а отже й p, що суперечить gcd(p, q) = 1. Оскільки x непарне, парним у цій трійці мусить бути q (а p — непарне). Параметризуймо її взаємно простими m > n > 0 різної парності:

```
x = m² − n²
q = 2mn
p = m² + n²
```

**Крок 5. Парний катет розсипається на квадрати.** Підставмо q = 2mn у другий рядок кроку 3:

```
y² = 2pq = 2·p·(2mn) = 4·m·n·p       ⇒   (y/2)² = m·n·p
```

Тепер ключ — m, n, p попарно взаємно прості:

```
gcd(m, n) = 1              (з параметризації)
gcd(m, p) = 1:  r|m, r|p  ⇒  r | (p − m²) = n²  ⇒  r|n  — неможливо
gcd(n, p) = 1:  r|n, r|p  ⇒  r | (p − n²) = m²  ⇒  r|m  — неможливо
```

Отже, попарно взаємно простий добуток m·n·p дорівнює квадрату (y/2)². За другим важелем кожен множник сам квадрат:

```
m = a²,   n = b²,   p = c²
```

**Крок 6. Складання меншого розв'язку.** Останній рядок кроку 4 каже p = m² + n². Підставмо m = a², n = b², p = c²:

```
c² = (a²)² + (b²)² = a⁴ + b⁴       ⇒   a⁴ + b⁴ = c²
```

Це той самий вигляд, що й початкове рівняння, лише з новими додатними цілими a, b, c (усі ≥ 1, бо m, n, p ≥ 1). Лишилося переконатись, що новий розв'язок **менший**:

```
c ≤ c² = p < p² + q² = z       ⇒   c < z
```

(тут c ≤ c² бо c ≥ 1, а p < p² + q² бо q² ≥ 1). Ми стартували з найменшого z — і побудували розв'язок із c < z. Суперечність. Значить, припущення хибне: жодного розв'язку в додатних цілих немає. ∎

## Дві вимоги, яких не буває разом

Придивімося, де саме реальність відмовляє. Розв'язок x⁴ + y⁴ = z² — це, по суті, насіння (p, q) примітивної трійки, у якому **водночас** і p² − q², і 2pq виявилися точними квадратами (тоді x = √(p²−q²), y = √(2pq), z = p² + q²). Кожну з цих двох вимог окремо задовольнити легко:

```
p = 5, q = 4:   p² − q² = 9 = 3²  (квадрат!),   2pq = 40   (не квадрат)
p = 2, q = 1:   p² − q² = 3  (не квадрат),      2pq = 4 = 2²  (квадрат!)
```

Перше насіння дає непарний катет квадратом, друге — парний; трійки при цьому цілком справжні (9² + 40² = 41², 3² + 4² = 5²). Але жодне з них не виконує **обидві** умови разом — а саме це потрібно для розв'язку. Спуск і доводить те, чого перебором не побачити: насіння, у якого обидва вирази — квадрати одночасно, не існує зовсім.

## Звідси падає показник чотири

Тепер безкоштовний висновок. Хай хтось знайшов x⁴ + y⁴ = w⁴. Тоді

```
x⁴ + y⁴ = (w²)²
```

тобто (x, y, w²) — розв'язок рівняння x⁴ + y⁴ = z² із z = w². Але щойно доведено, що таких розв'язків немає. Отже, немає й розв'язку x⁴ + y⁴ = w⁴: показник чотири закрито. Оскільки будь-який показник, кратний чотирьом, зводиться до четвертого (з aⁿ = (aⁿ/⁴)⁴), разом упали й усі степені двійки, більші за два.

Саме цей спуск — єдине доведення в усій історії Великої теореми, яке впевнено приписують особисто Ферма: коротка й повна алгебра, що тримається на єдиності розкладу на прості. На непарних простих показниках той самий трюк загрузне — бо там єдиність розкладу вже не гарантована, і другий важіль ламається.
