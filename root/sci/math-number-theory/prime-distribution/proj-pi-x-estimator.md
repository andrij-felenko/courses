# ⚙️ Обчислення π(x) та порівняння з Li(x) на практиці

Хоча Теорема про розподіл простих чисел доводить, що кількість простих чисел асимптотично наближається до інтегрального логарифма Li(x), інколи корисно перевірити це твердження на практиці, власноруч порахувавши прості числа. Наведений нижче скрипт на C++ реалізує ефективний алгоритм для точного обчислення значення функції π(x) та порівнює його зі значенням Li(x) для чисел аж до 100 мільйонів (10⁸).

Наш підхід ґрунтується на Решеті Ератосфена, яке є одним з найшвидших алгоритмів для знаходження всіх простих чисел у заданому діапазоні. Оскільки ми хочемо працювати з числами до 10⁸, ми можемо дозволити собі тримати весь масив прапорців у пам'яті (використовуючи std::vector<bool>, який упаковує біти і займає лише близько 12 Мегабайт оперативної пам'яті). Інтегральний логарифм Li(x) обчислюється через апроксимацію рядами, оскільки стандартна бібліотека не має вбудованої функції для нього.

Цей алгоритм складається з п'яти ключових компонентів:
1. Оцінка наближення Li(x), що досягається за допомогою обчислення суми ряду Ейлера.
2. Підрахунок π(x) через масив прапорців, де не прості числа викреслюються кроками.
3. Точний підрахунок кількості залишених прапорців.
4. Порівняння результатів π(x), x / ln(x) та Li(x) шляхом знаходження абсолютної похибки.
5. Запуск для масиву значень, що експоненціально зростають, щоб наочно продемонструвати поведінку функцій.

Зверніть увагу на те, як зі збільшенням змінної x похибка наближення x/ln(x) зростає доволі суттєво, тоді як похибка інтегрального логарифма Li(x) залишається неймовірно малою у відсотковому відношенні. Саме ця емпірична перевірка доводить ефективність аналітичних функцій для розуміння дискретної природи чисел.
