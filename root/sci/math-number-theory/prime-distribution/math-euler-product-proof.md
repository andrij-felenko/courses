# 🧮 Тотожність Ейлера: доведення зв'язку між неперервним та дискретним

Тотожність Ейлера є фундаментальним мостом між двома різними світами: неперервним підсумовуванням усіх натуральних чисел і дискретним множенням винятково простих чисел. Розуміння того, як саме працює це доведення, дозволяє побачити магію розкладу на прості множники в дії.

Ейлер хотів показати, що сума обернених степенів усіх цілих чисел (Дзета-функція) дорівнює добутку певних виразів, кожен з яких відповідає одному простому числу:

```
∑ (1 / nˢ) = ∏ [1 / (1 - p⁻ˢ)]
```
(тут s — певне фіксоване дійсне число, більше за 1, щоб ряди сходилися; p пробігає всі прості числа: 2, 3, 5, 7 і так далі, а n пробігає всі натуральні числа: 1, 2, 3, 4...).

Доведення цього факту спирається на два відомих математичних інструменти: формулу суми нескінченної геометричної прогресії та Основну теорему арифметики (кожне ціле число можна унікальним чином розкласти на прості множники).

Давайте розглянемо праву частину рівняння, яка містить добуток по простих числах. Візьмемо один множник з цього добутку, наприклад, для простого числа p:

```
1 / (1 - p⁻ˢ)
```

Цей вираз виглядає точнісінько як сума нескінченної геометричної прогресії. Якщо ми маємо прогресію зі знаменником q, її сума дорівнює 1 / (1 - q). У нашому випадку знаменником q є вираз p⁻ˢ (тобто 1 / pˢ). Розгорнемо цей дріб назад у нескінченну суму:

```
1 / (1 - p⁻ˢ) = 1 + (1 / pˢ) + (1 / p²ˢ) + (1 / p³ˢ) + ...
```

Тепер застосуємо цю операцію до всіх множників у нашому нескінченному добутку. Ми отримаємо добуток нескінченної кількості нескінченних сум. Кожна сума відповідає одному простому числу:

```
(1 + 1/2ˢ + 1/2²ˢ + 1/2³ˢ + ...) ×
(1 + 1/3ˢ + 1/3²ˢ + 1/3³ˢ + ...) ×
(1 + 1/5ˢ + 1/5²ˢ + 1/5³ˢ + ...) ×
(1 + 1/7ˢ + 1/7²ˢ + 1/7³ˢ + ...) ×
...
```

Щоб зрозуміти, що станеться, коли ми розкриємо всі дужки і перемножимо все це, уявімо, як ми обираємо по одному доданку з кожної довгої дужки. Коли ми перемножуємо вирази, ми формуємо нові доданки, вибираючи рівно один елемент з кожного рядка-суми. 

Більшість часу ми будемо вибирати "1". Але давайте оберемо, наприклад, елемент `1/2²ˢ` з першої дужки, `1/3ˢ` з другої дужки, і "1" з усіх інших дужок. Перемножимо їх:

```
(1/2²ˢ) · (1/3ˢ) · 1 · 1 · ... = 1 / (2² · 3)ˢ = 1 / (12)ˢ
```

Ми отримали доданок `1 / 12ˢ`.

Згідно з Основною теоремою арифметики, будь-яке натуральне число n має єдиний розклад на прості множники. Наприклад, число 12 розкладається виключно як 2² · 3. Це означає, що при повному розкритті дужок існує лише один спосіб отримати знаменник 12ˢ — саме той, який ми щойно показали. І це правило працює для кожного натурального числа n.

Отже, коли ми розкриємо всі дужки в добутку, ми згенеруємо доданки вигляду `1 / nˢ` для кожного можливого натурального числа n (оскільки кожне n складається з певної унікальної комбінації простих чисел). Кожне число n з'явиться в цій велетенській сумі рівно один раз.

Таким чином, добуток усіх цих дужок після розкриття перетворюється на:

```
1 + 1/2ˢ + 1/3ˢ + 1/4ˢ + 1/5ˢ + 1/6ˢ + 1/7ˢ + 1/8ˢ + ... = ∑ (1 / nˢ)
```

А це і є ліва частина Тотожності Ейлера. Ми щойно перетворили дискретний добуток, у якому фігурували лише прості числа, на неперервну суму, в якій присутні всі цілі натуральні числа. Алгебра нескінченних рядів ідеально віддзеркалила властивості подільності чисел. Ця тотожність довела, що глибокий аналіз неперервних функцій може дати нам вичерпні відповіді про природу простих чисел.
