# Практичний скрипт на мові C++17 для перевірки критерію Корсельта

У цьому практичному проєкті ми крок за кроком реалізуємо ефективну консольну програму сучасною мовою програмування C++17, яка надійно перевіряє, чи повністю задовольняє будь-яке задане додатне ціле число строгому критерію Корсельта, і відповідно, чи можна вважати його справжнім числом Кармайкла. Внутрішня архітектура та структура нашої програми для забезпечення найкращої якості коду складатиметься з п'яти ключових та незалежних компонентів: обробки аргументів командного рядка, алгоритму факторизації числа на прості множники, модуля перевірки на повну відсутність квадратних дільників, модуля перевірки специфічної умови подільності Корсельта та основного керуючого модуля для форматування і виведення результатів. Цей сучасний підхід гарантовано забезпечує високу модульність, максимальну ефективність обчислень та ідеальну чистоту вихідного коду.

## 1. Включення системних бібліотек та обробка користувацького вводу

Найперший базовий компонент нашої консольної програми повністю відповідає за правильне підключення всіх необхідних заголовних файлів і безпечну обробку стандартного користувацького вводу. Ми активно використовуємо перевірені стандартні бібліотеки C++17 для вводу-виводу тексту, безпечної роботи з динамічними векторами та виконання математичних операцій. Наша програма гнучко очікує, що ціле число для перевірки буде передано користувачем або як прямий аргумент командного рядка під час запуску, або буде введено з клавіатури інтерактивно, якщо такий аргумент був відсутній. Ми свідомо застосовуємо саме 64-бітний беззнаковий цілочисельний тип `uint64_t` для гарантованої підтримки достатньо великих чисел під час тестів.

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <cstdint>

// Базова функція для безпечного отримання вхідного цілого числа від користувача
uint64_t getInput(int argc, char* argv[]) {
    if (argc > 1) {
        return std::stoull(argv[1]);
    }
    uint64_t n;
    std::cout << "Введіть ціле додатне число для перевірки: ";
    std::cin >> n;
    return n;
}
```

## 2. Оптимізований алгоритм факторизації числа

Другий важливий компонент — це оптимізована функція факторизації, яка ефективно розкладає задане велике число виключно на його прості множники. Це абсолютно критично важливий обчислювальний крок для застосування критерію Корсельта, оскільки він безпосередньо вимагає повного знання всіх простих дільників заданого числа n. Ми використовуємо тут перевірений і достатньо оптимізований класичний алгоритм пробного ділення, який швидко перевіряє можливі дільники лише до квадратного кореня з заданого числа, економлячи час процесора. Кожен успішно знайдений простий множник одразу ж додається до динамічного вектора, який потім безпечно повертається у викликаючу функцію.

```cpp
std::vector<uint64_t> getPrimeFactors(uint64_t n) {
    std::vector<uint64_t> factors;
    
    if (n % 2 == 0) {
        factors.push_back(2);
        while (n % 2 == 0) n /= 2;
    }
    
    for (uint64_t i = 3; i * i <= n; i += 2) {
        if (n % i == 0) {
            factors.push_back(i);
            while (n % i == 0) n /= i;
        }
    }
    
    if (n > 2) {
        factors.push_back(n);
    }
    return factors;
}
```

## 3. Надійна перевірка на вільність від квадратів

Третій логічний компонент математично перевіряє, чи ділиться наше число на повний квадрат будь-якого з його знайдених простих дільників. Якщо хоч один такий квадрат знайдено, то досліджуване число апріорі не може бути числом Кармайкла згідно з першою умовою критерію. Задля кращої алгоритмічної оптимізації ми могли б не виконувати цю перевірку окремим проходом, а просто рахувати кількість поділів, однак, щоб зробити вихідний код значно більш читабельним для студентів та суворо відповідати тексту критерію, ми створимо саме окрему, спеціалізовану функцію, яка прозоро перевіряє умову, чи виконується n % (p * p) == 0 для кожного виявленого простого фактора p.

```cpp
bool isSquareFree(uint64_t n, const std::vector<uint64_t>& factors) {
    for (uint64_t p : factors) {
        if (n % (p * p) == 0) {
            return false; // Знайдено квадратний дільник
        }
    }
    return true; // Число повністю вільне від квадратів
}
```

## 4. Перевірка ключової умови подільності (p - 1) | (n - 1)

Четвертий обчислювальний компонент нашої програми безпосередньо та строго імплементує другу, ключову умову критерію Корсельта. Для абсолютно кожного знайденого простого дільника p нашого складеного числа n, ми арифметично перевіряємо, чи ділиться різниця n - 1 на різницю p - 1 повністю без остачі. Якщо раптом хоча б для одного єдиного простого множника ця сувора математична умова порушується і не виконується, то наше число гарантовано відхиляється і не є числом Кармайкла.

```cpp
bool satisfiesKorseltDivisibility(uint64_t n, const std::vector<uint64_t>& factors) {
    for (uint64_t p : factors) {
        if ((n - 1) % (p - 1) != 0) {
            return false; // Умова подільності Корсельта не виконана
        }
    }
    return true; // Усі фактори успішно пройшли перевірку
}
```

## 5. Основний керуючий модуль (main) та форматоване виведення

П'ятий і заключний архітектурний компонент — це класична головна точка входу в програму, функція `main`, де всі наші попередні незалежні компоненти гармонійно об'єднуються в єдиний робочий конвеєр. Саме тут також проводиться базова попередня перевірка на те, чи є вказане число дійсно складеним, оскільки звичайні прості числа цілком тривіально задовольняють більшості подібних умов подільності, але за строгим визначенням не можуть бути числами Кармайкла.

```cpp
int main(int argc, char* argv[]) {
    uint64_t n = getInput(argc, argv);
    
    // Перевірка на достатню величину числа
    if (n < 4) {
        std::cout << n << " не є складеним числом, отже апріорі не є числом Кармайкла.\n";
        return 0;
    }
    
    std::vector<uint64_t> factors = getPrimeFactors(n);
    
    // Елементарна перевірка, чи є задане число простим
    if (factors.size() == 1 && factors[0] == n) {
        std::cout << n << " є звичайним простим числом, а зовсім не числом Кармайкла.\n";
        return 0;
    }
    
    // Запуск першої частини критерію Корсельта
    if (!isSquareFree(n, factors)) {
        std::cout << n << " має повні квадратні дільники, тому не задовольняє критерію Корсельта.\n";
        return 0;
    }
    
    // Запуск другої частини критерію Корсельта
    if (!satisfiesKorseltDivisibility(n, factors)) {
        std::cout << n << " не задовольняє обов'язковій умові подільності Корсельта: (p - 1) | (n - 1).\n";
        return 0;
    }
    
    // Фінальний успішний висновок
    std::cout << n << " успішно проходить весь критерій Корсельта! Це справжнє число Кармайкла.\n";
    std::cout << "Його повна факторизація: ";
    for (size_t i = 0; i < factors.size(); ++i) {
        std::cout << factors[i] << (i < factors.size() - 1 ? " * " : "");
    }
    std::cout << "\n";
    
    return 0;
}
```

Цей невеликий, але потужний скрипт наочно демонструє практичне застосування базових та абстрактних концепцій вищої теорії чисел у реальному програмуванні на сучасній C++17. Правильне логічне розбиття єдиної задачі на п'ять невеликих, незалежних та функціональних блоків робить увесь код надзвичайно легким для автоматичного тестування, підтримки та можливих подальших модифікацій іншими розробниками. Наприклад, після компіляції ви можете одразу спробувати перевірити знамените та перше знайдене число Кармайкла 561, щоб на власні очі побачити, як ця програма блискавично підтвердить його унікальні математичні властивості, безпомилково розклавши його на прості множники 3 * 11 * 17.
