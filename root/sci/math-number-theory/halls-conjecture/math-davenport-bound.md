# 🧮 Математичне доведення теореми Девенпорта для поліномів

<preknowlist>
- [Основна теорема арифметики](topic:math-number-theory/fundamental-theorem-arithmetic) — унікальність розкладу на прості множники.
- [Гіпотеза ABC](topic:math-number-theory/abc-conjecture) — зв'язок між адитивною сумою та мультиплікативним радикалом цілих чисел.
</preknowlist>

Ця математична вставка містить строге виведення теореми Гарольда Девенпорта (1965) про нижню межу степеня різниці `f(t)³ - g(t)²` для поліномів у комплексному полі `C[t]`. Доведення спирається на поліноміальну теорему Месона-Стозерса (поліноміальний аналог гіпотези ABC) і демонструє, чому у поліноміальному середовищі показник `1/2` досягається строго і без асимптотичних поправок.

У той час як для цілих чисел аналіз відхилень між степенями зіштовхується з арифметика-комбінаторним "хаосом" переносів при додаванні, у поліноміальному кільці `C[t]` діє строгий апарат диференціального числення. Наявність операції диференціювання дозволяє пов'язати степені поліномів із кількістю їхніх геометричних коренів через вронскіан, що робить поліноміальну теорію повністю прозорою.

## Формулювання теореми Девенпорта

Нехай `f(t)` та `g(t)` — ненульові поліноми з комплексними коефіцієнтами з кільця `C[t]` такі, що `f(t)³ ≠ g(t)²`. Тоді степінь їхньої різниці задовольняє нерівність:

```
deg(f³ - g²) ≥ (1/2) · deg(f) + 1
```

де `deg(P)` позначає степінь полінома `P(t)`.

Це твердження є функціональним аналогом гіпотези Холла. Воно показує, що для двох поліномів степені різниці `f(t)³ - g(t)²` неможливо зробити довільно малою: вона обов'язково зростає пропорційно половині степеня полінома `f(t)`.

## Теорема Месона-Стозерса як диференціальна основа

Фундаментальною основою для доведення теореми Девенпорта є **теорема Месона-Стозерса** (опублікована незалежно Рондо Стозерсом у 1981 році та РК Месоном у 1983 році). Вона слугує строго доведеним поліноміальним аналогом [гіпотези ABC](topic:math-number-theory/abc-conjecture).

**Теорема (Месон-Стозерс):** Нехай `A(t), B(t), C(t) ∈ C[t]` — ненульові взаємно прості поліноми над полем комплексних чисел, які задовольняють адитивне співвідношення:

```
A(t) + B(t) = C(t)
```

причому принаймні один із поліномів не є константою. Тоді степінь кожного з цих поліномів строго обмежується кількістю унікальних коренів їхнього добутку:

```
max(deg(A), deg(B), deg(C)) ≤ n₀(A · B · C) - 1
```

де `n₀(P)` позначає кількість **різних (унікальних)** комплексних коренів полінома `P(t)` без урахування їхньої кратних степенів.

### Ідея доведення теореми Месона-Стозерса через вронскіан

Щоб осягнути незаперечну строгість теореми Месона-Стозерса, розглянемо її короткий диференціальний механізм. 

Диференціюючи рівність `A + B = C` по змінній `t`, отримуємо співвідношення для похідних:

```
A' + B' = C'
```

Складемо вронскіан двох функцій `W(A, B) = A · B' - A' · B`. Завдяки лінійності похідної та рівності `A + B = C`, маємо тотожності:

```
W(A, B) = A · B' - A' · B
        = A · (C' - A') - A' · (C - A)     [підстановка B = C - A та B' = C' - A']
        = A · C' - A' · C                   [скорочення A · A']
        = W(A, C)
```

Отже, вронскіан `W = A · B' - A' · B` одночасно ділиться на спільні дільники `A` та `A'`, `B` та `B'`, а також `C` та `C'`. 

Якщо просте число (або лінійний множник `t - α`) входить до полінома `A(t)` з кратністю `k`, то до похідної `A'(t)` воно входить з кратністю `k - 1`. Отже, воно входить до найбільшого спільного дільника `НСД(A, A')` з кратністю `k - 1`. 

Позначивши через `D(P)` поліном найбільшого спільного дільника `НСД(P, P')`, бачимо, що степінь `D(P)` дорівнює `deg(P) - n₀(P)`. Оскільки вронскіан `W` ділиться на добуток `D(A) · D(B) · D(C)`, його степінь задовольняє нерівність:

```
deg(W) ≥ deg(D(A)) + deg(D(B)) + deg(D(C))
       = (deg(A) - n₀(A)) + (deg(B) - n₀(B)) + (deg(C) - n₀(C))  [сума степенів найбільших дільників]
```

З іншого боку, з прямої формули `W = A · B' - A' · B` випливає верхня оцінка степеня вронскіана:

```
deg(W) ≤ deg(A) + deg(B) - 1
```

Об'єднуючи дві нерівності для `deg(W)` і враховуючи, що `A + B = C`, після простих алгебраїчних скорочень отримуємо теорему Месона-Стозерса: `max(deg(A), deg(B), deg(C)) ≤ n₀(A · B · C) - 1`.

## Покрокове доведення теореми Девенпорта

Тепер використаємо теорему Месона-Стозерса для виведення оцінки Девенпорта.

### Крок 1: Формулювання поліноміального тотожності

Розглянемо вихідне рівняння:

```
f(t)³ - g(t)² = H(t)
```

де `H(t)` позначає різницю `f(t)³ - g(t)²`. Перепишемо це співвідношення у вигляді адитивної суми трьох поліномів:

```
A(t) + B(t) = C(t)
```

визначивши компоненти трійки наступним чином:

```
A(t) = f(t)³
B(t) = -H(t) = g(t)² - f(t)³
C(t) = g(t)²
```

Без втрати загальності вважаємо, що поліноми `f(t)` та `g(t)` є взаємно простими (`НСД(f, g) = 1`). Якщо б вони мали спільний корінь `(t - α)`, його можна було б винести за дужки, що лише зменшило б степені всіх поліномів і підсилило б нерівність.

### Крок 2: Аналіз співвідношення степенів

Розглянемо два можливі випадки для степенів `f(t)³` та `g(t)²`:

**Випадок 1: `deg(f³) ≠ deg(g²)`**

Якщо степені `f(t)³` та `g(t)²` є різними (`3 · deg(f) ≠ 2 · deg(g)`), то при відніманні `f(t)³ - g(t)²` старші члени не скорочуються. У цьому разі степінь різниці `H(t)` дорівнює максимуму степенів двох доданків:

```
deg(H) = max(3 · deg(f), 2 · deg(g)) ≥ 3 · deg(f)
```

Оскільки `3 · deg(f) ≥ (1/2) · deg(f) + 1` для будь-якого `deg(f) ≥ 1`, у цьому випадку нерівність Девенпорта виконується з величезним запасом.

**Випадок 2: `deg(f³) = deg(g²)` (критичний випадок скорочення старших членів)**

Найбільш цікавим і складним є випадок, коли старші члени `f(t)³` та `g(t)²` повністю взаємно знищуються. Це вимагає рівності їхніх степенів:

```
deg(f³) = deg(g²)
3 · deg(f) = 2 · deg(g)
```

Звідси виражаємо степінь полінома `g(t)` через степінь полінома `f(t)`:

```
deg(g) = (3/2) · deg(f)
```

Максимум степенів трьох поліномів `A(t) = f(t)³`, `B(t) = -H(t)` та `C(t) = g(t)²` дорівнює степеню куба `f(t)³`:

```
max(deg(A), deg(B), deg(C)) = deg(f³) = 3 · deg(f)
```

### Крок 3: Оцінка кількості унікальних коренів добутку

Обчислимо кількість унікальних комплексних коренів добутку `A(t) · B(t) · C(t)`:

```
A(t) · B(t) · C(t) = f(t)³ · (-H(t)) · g(t)²
```

Піднесення полінома до степеня (квадрата чи куба) змінює кратність його коренів, але не створює жодного нового кореня. Отже, множина унікальних коренів добутку `f³ · H · g²` тотожно збігається з множиною унікальних коренів простішого добутку `f · g · H`:

```
n₀(A · B · C) = n₀(f · g · H)
```

За властивістю кількості коренів, кількість унікальних коренів добутку декількох поліномів не перевищує суми степенів цих поліномів:

```
n₀(f · g · H) ≤ deg(f) + deg(g) + deg(H)
```

Підставимо у цю нерівність раніше знайдене співвідношення `deg(g) = (3/2) · deg(f)`:

```
n₀(A · B · C) ≤ deg(f) + (3/2) · deg(f) + deg(H)
              = (5/2) · deg(f) + deg(H)             [зведення подібних доданків 1 + 3/2 = 5/2]
```

### Крок 4: Алгебраїчне виведення підсумкової нерівності

Підставимо отримане значення `max(deg(A), deg(B), deg(C)) = 3 · deg(f)` та верхню оцінку `n₀(A · B · C)` у нерівність Месона-Стозерса:

```
3 · deg(f)
≤ n₀(A · B · C) - 1                                     [за теоремою Месона-Стозерса]
≤ (5/2) · deg(f) + deg(H) - 1                           [підстановка верхньої оцінки n₀]
```

Отримали ключове алгебраїчне співвідношення:

```
3 · deg(f) ≤ (5/2) · deg(f) + deg(H) - 1
```

Віднімемо доданок `(5/2) · deg(f)` від обох частин нерівності:

```
3 · deg(f) - (5/2) · deg(f) + 1 ≤ deg(H)                [перенесення членів з deg(f)]
(1/2) · deg(f) + 1 ≤ deg(H)                             [обчислення 3 - 5/2 = 1/2]
```

Згадавши, що `H(t) = f(t)³ - g(t)²`, отримуємо остаточну формулу Девенпорта:

```
deg(f³ - g²) ≥ (1/2) · deg(f) + 1
```

Теорему Девенпорта повністю доведено!

## Детальний числовий аналіз прикладів досягнення межі

Розглянемо два конкретні приклади поліномів, щоб побачити, як теорема Девенпорта працює на практиці і де межа досягається як точна рівність.

### Приклад 1: Точна рівність при `deg(f) = 2`

Розглянемо поліноми:

```
f(t) = t² + 2
g(t) = t³ + 3·t
```

Обчислимо степені початкових поліномів: `deg(f) = 2`, `deg(g) = 3`. Перевіримо умову пропорційності степенів: `3 · deg(f) = 6` та `2 · deg(g) = 6`.

Обчислимо куб полінома `f(t)` за формулою куба бінома:

```
f(t)³ = (t² + 2)³
      = (t²)³ + 3·(t²)²·2 + 3·(t²)·2² + 2³   [розклад за формулою куба суми]
      = t⁶ + 6·t⁴ + 12·t² + 8                [спрощення коефіцієнтів та степенів]
```

Обчислимо квадрат полінома `g(t)` за формулою квадрата бінома:

```
g(t)² = (t³ + 3·t)²
      = (t³)² + 2·(t³)·(3·t) + (3·t)²        [розклад за формулою квадрата суми]
      = t⁶ + 6·t⁴ + 9·t²                     [перемноження членів]
```

Знайдемо різницю `H(t) = f(t)³ - g(t)²`:

```
H(t) = (t⁶ + 6·t⁴ + 12·t² + 8) - (t⁶ + 6·t⁴ + 9·t²)
     = (t⁶ - t⁶) + (6·t⁴ - 6·t⁴) + (12·t² - 9·t²) + 8  [перегрупування за однаковими степенями]
     = 3·t² + 8                                        [віднімання коефіцієнтів]
```

Старші члени `t⁶` та `6·t⁴` повністю скоротилися! Степінь отриманого полінома `H(t)` дорівнює:

```
deg(f³ - g²) = deg(3·t² + 8) = 2
```

Обчислимо теоретичну нижню межу Девенпорта для `deg(f) = 2`:

```
(1/2) · deg(f) + 1 = (1/2) · 2 + 1 = 1 + 1 = 2
```

Отримали точний збіг: `2 = 2`. Цей приклад доводить, що оцінка Девенпорта є **непокращуваною** (найкращою з можливих): зменшити коефіцієнт `1/2` чи викреслити `+ 1` неможливо.

### Приклад 2: Точна рівність при `deg(f) = 4` (родина Стозерса)

Розглянемо складніший приклад поліномів степеня 4:

```
f(t) = t⁴ + 4·t
g(t) = t⁶ + 6·t³ + 6
```

Обчислимо степені: `deg(f) = 4`, `deg(g) = 6`.

Обчислимо куб `f(t)` та квадрат `g(t)`:

```
f(t)³ = (t⁴ + 4·t)³
      = t¹² + 12·t⁹ + 48·t⁶ + 64·t³         [розклад за формулою куба двочлена]
g(t)² = (t⁶ + 6·t³ + 6)²
      = t¹² + 12·t⁹ + 48·t⁶ + 72·t³ + 36    [розклад за формулою квадрата тричлена]
```

Знайдемо їхню різницю `H(t) = f(t)³ - g(t)²`:

```
H(t) = (t¹² + 12·t⁹ + 48·t⁶ + 64·t³) - (t¹² + 12·t⁹ + 48·t⁶ + 72·t³ + 36)
     = (64·t³ - 72·t³) - 36                 [скорочення однакових членів t¹², t⁹, t⁶]
     = -8·t³ - 36                           [обчислення 64 - 72 = -8]
```

Степінь різниці дорівнює `deg(H) = 3`. 

Обчислимо теоретичну межу Девенпорта для `deg(f) = 4`:

```
(1/2) · deg(f) + 1 = (1/2) · 4 + 1 = 2 + 1 = 3
```

Знову отримали точну рівність: `3 = 3`.

## Чому цілі числа відрізняються від поліномів

Виникає фундаментальне питання: чому для поліномів у `C[t]` виконується строга нерівність `deg(f³ - g²) ≥ (1/2)deg(f) + 1` без жодних поправок, а для цілих чисел у `Z` сильна гіпотеза `|y² - x³| > C · √x` виявилася хибною і потребує поправки `x⁻ᵉ`?

Відповідь полягає у **відсутності переносу розрядів** при додаванні поліномів.

Коли ми додаємо чи віднімаємо два поліноми `A(t)` та `B(t)`, коефіцієнт біля степеня `tᵏ` залежить **виключно** від коефіцієнтів біля `tᵏ` в `A` та `B`. Додавання поліномів відбувається "покомпонентно" і не створює взаємодії між різними степенями `t`.

Натомість, у кільці цілих чисел `Z` додавання супроводжується **переносом розрядів** (carry propagation). Додавання двох чисел може викликати ланцюгову реакцію переносу одиниці через десятки позицій (наприклад, `999 999 + 1 = 1 000 000`). Цей перенос розрядів повністю змінює структуру простих множників суми `a + b` і створює арифметичні аномалії (такі як нескінченні родини розв'язків [рівняння Пелля](topic:math-number-theory/pell-equation)), які зрізають різницю `|y² - x³|` на логарифмічні множники `ln(x)`.

Саме тому поліноміальний світ дає ідеальну точну формулу Девенпорта зі степенем `1/2`, а цілочисельний світ вимагає слабкої гіпотези Холла з показником `1/2 - ε`.
