# 📜 Історія гіпотези Холла: від сильної формулювання до спростування Данилова

Півстолітній шлях дослідження асимптотичної відстані між точними квадратами та кубами пролягає від початкового припущення Маршалла Холла у 1971 році через несподіване алгебраїчне спростування Л. В. Данилова до сучасних алгоритмічних рекордів Ноама Елкіса. Еволюція діофантових оцінок пояснює, чому сучасна теорія чисел відмовилася від "чистого" степеня `1/2` на користь асимптотичного порогу `1/2 - ε`.

## Висунення гіпотези Маршаллом Холлом (1971)

У другій половині XX століття американський математик Маршалл Холл молодший (Marshall Hall Jr., 1910–1990), відомий своїми фундаментальними працями з комбінаторики та теорії груп, звернувся до аналізу діофантового рівняння Морделла (від імені англійського математика Луїса Морделла, *Louis Mordell*):

```
y² - x³ = k
```

Систематично аналізуючи відомі числові таблиці розв'язків для малих значень параметра `k`, Холл звернув увагу на дивовижну регулярність: для всіх знайдених цілих розв'язків `(x, y)` ненульова різниця `k = y² - x³` ніколи не ставала надто малою порівняно з величиною `x`. 

З точки зору елементарної евристики (від грецького *εὑρίσκω* — знаходжу), якщо числа `y²` та `x³` зростають до нескінченності, ордината `y` має порядок `x³/²`. Припустимо, що значення `y` дещо відхиляється від ідеального дійсного значення `x³/²` на невелику величину `δ`. Тоді піднесення до квадрата дає:

```
y² = (x³/² + δ)²
   = x³ + 2 · δ · x³/² + δ²         [розклад за квадратом суми]
```

Звідси випливає, що відхилення `y² - x³` має порядок `2 · δ · x³/²`. Якщо припустити, що цілі числа розподілені випадковим чином відносно дробової частини `x³/²`, то найближче ціле значення відповідає `δ ≈ 1/4`, що дає мінімальну різницю порядку `x¹/²`.

На основі цих обчислень і числового матеріалу Маршалл Холл у 1971 році висунув гіпотезу, яка згодом отримала назву **сильної гіпотези Холла**: існує абсолютна додатна константа `C > 0` така, що для всіх цілих чисел `x, y ≥ 1`, які задовольняють умову `y² ≠ x³`, виконується нерівність:

```
|y² - x³| > C · √x
```

Холл припустив, що `C = 1/5 = 0.2`, оскільки жодна з відомих на той час числових пар не порушувала цієї межі.

## Алгебраїчний прорив Девенпорта для поліномів (1965)

Оптимізм щодо сильної форми гіпотези Холла значно посилився завдяки праці англійського математика Гарольда Девенпорта (Harold Davenport, 1907–1969). У 1965 році Девенпорт дослідив аналог цієї проблеми для поліномів у комплексному полі `C[t]`.

Девенпорт довів, що якщо `f(t)` та `g(t)` є ненульовими поліномами над полем комплексних чисел такими, що `f(t)³ ≠ g(t)²`, то степінь їхньої різниці задовольняє точне оціночне співвідношення:

```
deg(f³ - g²) ≥ (1/2) · deg(f) + 1
```

Ця теорема показала, що у світлі функціональних полів показник `1/2` є абсолютно точним і природним. У поліноміальному світі не виникає жодних додаткових логарифмічних чи асимптотичних поправок. Це створило ілюзію, що аналогічна строга нерівність з `√x` має виконуватися і для звичайних цілих чисел.

## Спростування сильної форми: послідовність Данилова (1982)

Сподівання на справедливість нерівності `|y² - x³| > C · √x` розвіялися у 1982 році, коли радянський математик Л. В. Данилов опублікував коротку, але фундаментальну працю. 

Данилов показав, що цілочисельний світ володіє глибокою арифметичною специфікою, якої немає в поліноміальному випадку. Використовуючи тотожності, пов'язані з поліномами Чебишова та нескінченними родинами розв'язків [рівняння Пелля](root:math-number-theory/pell-equation), Данилов побудував явну нескінченну послідовність пар цілих чисел `(xₙ, yₙ)`, для яких відношення різниці до квадратного кореня прямує до нуля:

```
lim (n → ∞) |yₙ² - xₙ³| / √xₙ = 0
```

Для побудови цієї послідовності Данилов розглянув розв'язки рівняння Пелля `u² - 2 · v² = 1`. Завдяки мультиплікативній структурі кільця `Z[√2]`, це рівняння має нескінченну серію розв'язків `(uₙ, vₙ)`. Ввівши поліноміальні параметричні вирази від `uₙ` та `vₙ`, Данилов дістав пару натуральних чисел `xₙ` та `yₙ`, для яких різниця `yₙ² - xₙ³` зростала повільніше, ніж `√xₙ`.

Зокрема, Данилов довів, що існує нескінченна кількість розв'язків, для яких виконується верхня оцінка:

```
|y² - x³| < c · √x / ln(x)
```

де `c > 0` — стала величина. Наявність логарифмічного дільника `ln(x)` означає, що співвідношення `|y² - x³| / √x` не має додатної нижньої межі `C > 0`. Таким чином, **сильна гіпотеза Холла виявилася хибною**.

## Сучасна (слабка) формулювання гіпотези

Після спростування Данилова математична спільнота переглянула формулювання гіпотези. Стало зрозуміло, що через наявність арифметичних аномалій порог `√x` зазнає збурень на довільно малі степені.

Сучасна формулювання, відома як **слабка гіпотеза Холла**, стверджує: для будь-якого сколь завгодно малого `ε > 0` існує додатна константа `C(ε) > 0` (яка залежить лише від `ε`), така що для всіх цілих чисел `x, y ≥ 1` з умовою `y² ≠ x³` виконується нерівність:

```
|y² - x³| > C(ε) · x^(1/2 - ε)
```

Додавання малої величини `ε` в показник степеня повністю поглинає будь-які логарифмічні дільники виду `ln(x)`, які виявив Данилов, і відновлює стійкість асимптотичного закону.

## Алгоритмічний пошук та рекорди Ноама Елкіса (1998–2000)

Із розвитком обчислювальної техніки дослідники розпочали масштабні пошуки числових пар `(x, y)`, що мають мінімальне відношення `|y² - x³| / √x`.

У 1998 році гарвардський математик Ноам Елкіс (Noam Elkies), застосувавши геометрію чисел, алгоритм скорочення базисів ґраток LLL (від імен винахідників Ар'єна Ленстри, Гендріка Ленстри та Ласло Ловаса, *Lenstra–Lenstra–Lovász*) та раціональні точки на модулярних кривих, виявив дивовижну пару чисел:

```
x = 5853886516781223
y = 447884928428402042307918
```

Для цієї пари обчислимо різницю та відповідний показник:

```
y² - x³ = -1641843
√x = √5853886516781223 ≈ 76 510 695.44
```

Відношення модуля різниці до квадратного кореня дорівнює:

```
1641843 / 76 510 695.44 ≈ 0.021459
```

Це значення є майже в 10 разів меншим за межу `C = 0.2`, яку початково передбачав Маршалл Холл!

У 2000 році Елкіс покращив цей результат, виявивши ще масштабніші числові аномалії з величезною кількістю знаків, що підтвердило складноасимптотичну природу гіпотези Холла. Пошук таких пар залишається одним із найважчих завдань експериментальної теорії чисел.
