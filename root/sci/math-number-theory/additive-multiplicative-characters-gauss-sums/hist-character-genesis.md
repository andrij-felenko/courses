# 📜 Історія виникнення характерів: від Ґаусса до Дедекінда й Фробеніуса

Спроба зрозуміти розподіл простих чисел і структуру цілочисельних рівнянь зіштовхнулася з фундаментальною перешкодою: операція додавання цілих чисел та операція множення поводяться як два абсолютно незалежні алгебраїчні світи. Мультиплікативна структура оборотних лишків за модулем чинить запеклий опір прямому аналітичному аналізу, оскільки звичайне додавання числових функцій не зберігає мультиплікативних властивостей множення. Виникнення та розвиток концепції характерів стали результатом столітнього пошуку алгебраїчного містка, який дозволив перетворити складне множення елементів у просте додавання комплексних фаз на одиничному колі.

## 1. Ейлер, Лагранж та резольвенти коренів з одиниці (1737–1770)

Перші кроки до гармонічного аналізу на дискретних структурах здійснив Леонгард Ейлер у 1737 році. Досліджуючи гармонічний ряд та нескінченні добутки, Ейлер вивів свою епохальну тотожність:

```
∑_{n=1}^∞ 1 / n^s = ∏_{p} (1 - 1 / p^s)⁻¹
```

Ця формула вперше показала, що аналітичні функції від комплексної чи дійсної змінної здатні кодувати дискретну мультиплікативну будову цілих чисел: додавання аргументів у логарифмі ряду перетворювалося на множення простих чисел у нескінченному добутку. Проте Ейлер міг працювати лише з усією множиною натуральних чисел одночасно. Спроба виділити окремі класи чисел (наприклад, лишки певного виду) засобами звичайного сумування призводила до втрати ейлерового добутку, оскільки характеристична функція арифметичної підмножини не зберігала операції множення.

Паралельно в алгебрі виникла ідея використання комплексних коренів з одиниці як ваг для розщеплення симетрій. У 1770 році Жозеф-Луї Лагранж у своїй фундаментальній праці *Réflexions sur la résolution algébrique des équations* представив так звані **резольвенти Лагранжа**. Для розв'язання рівнянь степеня `n` Лагранж будував лінійні комбінації коренів рівняння `x₀, x₁, ..., x_{n-1}`, зважені степенями первісного кореня з одиниці `ω = exp(2·π·i / n)`:

```
(x, ω^k) = ∑_{j=0}^{n-1} ω^{j·k} · x_j
```

Резольвента Лагранжа діяла як дискретне перетворення Фур'є на циклічній групі перестановок індексів. Вона перетворювала циклічний зсув коренів у множення на фазовий множник `ω^k`. Цей прийом показав математикам кінця XVIII століття, що ортогональні комплексні експоненти є природним інструментом для лінеаризації нелінійних циклічних дій.

## 2. Неявні характери Ґаусса, теорія родів та суми Ґаусса (1801–1811)

Витоки концепції характеру як числової функції сягають монументальної праці Карла Фрідріха Ґаусса *Disquisitiones Arithmeticae*, опублікованої у 1801 році. Досліджуючи бінарні квадратичні форми виду:

```
f(x, y) = a·x² + 2·b·x·y + c·y²
```

з цілими коефіцієнтами та дискримінантом `D = b² - a·c`, Ґаусс поставив за мету повністю класифікувати всі форми та з'ясувати, які саме числа вони можуть представляти при цілих значеннях `x` та `y`.

Ґаусс виявив дивовижне поняття **композиції форм**, яке перетворювало множину класів еквівалентних форм з однаковим дискримінантом на скінченну абелеву групу (хоча термін «група» ще не був уведений). Досліджуючи структуру цієї групи класів `Cl(D)`, Ґаусс помітив, що класи природно розпадаються на ширші сукупності — так звані **роди** (родові класи, genres).

Щоб розрізнити роди, Ґаусс зіставив кожній формі набір знаків `+1` або `-1`, обчислених через символи Лежандра `(n / p)` для кожного простого дільника дискримінанта `p | D`. Для кожного простого дільника знак визначався тим, чи є числа `n`, представлені формою, квадратичними залишками або незалишками за модулем `p`.

Хоча Ґаусс не мав сучасного апарату теорії груп і називав ці величини «характеристичними знаками родів» (*characteres generum*), вони являли собою перші в історії квадратичні характери (характери порядку 2) на групі класів. Ґаусс довів фундаментальні закони ортогональності для знаків родів:
- Добуток усіх знаків родів для дійсного роду підпорядковується закону взаємності.
- Рівно половина з усіх можливих комбінацій знаків відповідає дійсно існуючим родам квадратичних форм.

Це дозволило Ґауссу вперше суворо довести квадратичний закон взаємності та встановити структуру фактор-групи `Cl(D) / Cl(D)²`.

### Боротьба Ґаусса за знак квадратичної суми (1801–1811)

У 356-й статті *Disquisitiones Arithmeticae* Ґаусс увів скінченну тригонометричну суму, яка зараз носить його ім'я:

```
S(p) = ∑_{k=0}^{p-1} exp( 2·π·i · k² / p )
```

Ґаусс швидко встановив, що квадрат цієї суми точно дорівнює:

```
S(p)² = (-1)^{(p-1)/2} · p
```

Це означало, що сама сума `S(p)` повинна дорівнювати `+√p`, `-√p` (якщо `p ≡ 1 mod 4`) або `+i·√p`, `-i·√p` (якщо `p ≡ 3 mod 4`). Проте визначення точного алгебраїчного знака виявилося однією з найважчих задач усього життя Ґаусса. Він понад чотири роки марно намагався знайти строге аналітичне доведення того, що знак перед коренем завжди є додатним (`+1`).

Лише 30 травня 1805 року Ґаусс знайшов довгоочікуване рішення через розклад спеціальних добутків у ряди (відомі як q-біноміальні коефіцієнти та тета-функції). Своє повне доведення Ґаусс опублікував у 1811 році в мемуарах *Summatio quarumdam serierum singularium*. Суми Ґаусса стали першим явним мостом, що з'єднав адитивну структуру поля `F_p` з його мультиплікативними квадратичними залишками.

## 3. Лежен-Діріхле та народження аналітичної теорії чисел (1837)

Справжній прорив, який перетворив алгебраїчний інваріант Ґаусса на потужний аналітичний інструмент математичного аналізу, здійснив Петер Ґустав Лежен-Діріхле у 1837 році. Діріхле прагнув довести гіпотезу Адрієна-Марі Лежандра: будь-яка нескінченна арифметична прогресія:

```
a,  a + q,  a + 2·q,  a + 3·q,  a + 4·q,  ...
```

з взаємно простими початковим членом `a` та кроком `q` (`gcd(a, q) = 1`) містить нескінченно багато простих чисел.

Лежандр у праці *Essai sur la théorie des nombres* (1798) намагався довести квадратичний закон взаємності, неявно припускаючи існування простих чисел у довільних арифметичних прогресіях, проте довести саму наявність таких простих чисел він не зміг.

Ейлерів підхід доведення нескінченності простих чисел спирався на розбіжність суми `∑ 1/p`. Щоб повторити цей успіх для чисел виду `p = a + k·q`, потрібно було ізолювати лише ті члени ейлерового добутку, для яких `p ≡ a (mod q)`. Проте дискретна індикаторна функція:

```
I_a(n) = 1  [якщо n ≡ a (mod q)],   I_a(n) = 0  [якщо n ≢ a (mod q)]
```

не була мультиплікативною (`I_a(m·n) ≠ I_a(m) · I_a(n)`), що робило неможливим її прямий розклад у добуток Ейлера за простими числами.

Діріхле усвідомив, що індикаторну функцію `I_a(n)` слід подати у вигляді лінійної комбінації повністю мультиплікативних функцій. Він визначив **мультиплікативний характер за модулем q** як числову функцію `χ: Z → C`, що задовольняє три аксіоми:
1. **Періодичність:** `χ(n + q) = χ(n)` для всіх `n ∈ Z`.
2. **Повна мультиплікативність:** `χ(m · n) = χ(m) · χ(n)` для всіх `m, n ∈ Z`.
3. **Арифметична підтримка:** `χ(n) ≠ 0` тоді і тільки тоді, коли `gcd(n, q) = 1`.

Для побудови характерів Діріхле використав дискретне логарифмування за первісним коренем `g mod p`. Будь-яке число `n ≢ 0 (mod p)` записується як `n ≡ g^k (mod p)`, а `p - 1` різних характерів задаються формулою:

```
χ_m(n) = exp( 2·π·i · m · ind_g(n) / (p - 1) ),   де m ∈ {0, 1, ..., p - 2}
```

Головним відкриттям Діріхле стали співвідношення подвійної ортогональності характерів:

```
(1 / φ(q)) · ∑_{χ} χ̄(a) · χ(n)
= 1  [якщо n ≡ a (mod q)]
= 0  [якщо n ≢ a (mod q)]
```

За допомогою цього проєкційного оператора Діріхле ввів L-функції `L(s, χ) = ∑_{n=1}^∞ χ(n) / n^s`. Завдяки повній мультиплікативності характеру кожна L-функція розкладалася у нескінченний добуток Ейлера:

```
L(s, χ) = ∏_{p} (1 - χ(p) / p^s)⁻¹
```

Найглибшою перешкодою на шляху доведення теореми було доведення того, що значення `L(1, χ) ≠ 0` для всіх нетривіальних характерів. Для комплексних характерів нерівність нулю випливала з того, що припустивши `L(1, χ) = 0`, функція `∏_χ L(s, χ)` залишалася б обмеженою при `s → 1+`, що суперечило б наявності простого полюса дзета-функції. Проте для дійсних (квадратичних) характерів цей метод не спрацьовував.

Діріхле подолав цю перешкоду геніальним відкриттям: він виразив значення `L(1, χ)` для дійсного характеру через число класів бінарних квадратичних форм `h(D)` (формула числа класів Діріхле):

```
L(1, χ_D) = ( 2·π · h(D) ) / ( w · √|D| )   [для D < 0]
L(1, χ_D) = ( h(D) · ln(ε) ) / ( √D )       [для D > 0]
```

Оскільки число класів ідеалів `h(D) ≥ 1` є строго додатним цілим числом, а регулятор `ln(ε) > 0`, значення `L(1, χ_D)` не може перетворитися на нуль. Це відкриття об'єднало алгебру квадратичних форм, комплексну геометрію та гармонічний аналіз в єдину наукову дисципліну — аналітичну теорію чисел.

## 4. Якобі, Куммер та Ейзенштейн: суми Якобі й вищі закони взаємності (1828–1850)

У 1830-х роках Карл Ґустав Якоб Якобі продовжив дослідження Ґаусса і ввів мультиплікативні згортки двох характерів, які отримали назву **сум Якобі**:

```
J(χ, ψ) = ∑_{x ∈ F_p} χ(x) · ψ(1 - x)
```

Якобі встановив, що суми Якобі пов'язані з сумами Ґаусса елегантним співвідношенням:

```
J(χ, ψ) = ( g(χ) · g(ψ) ) / g(χ · ψ)
```

На відміну від самих сум Ґаусса, які лежать у полях кругового поділу з коренями степеня `p`, суми Якобі для характерів порядку `m` лежать у значно меншому круговому полі `Q(exp(2·π·i / m))`.

Ернст Едуард Куммер та Ґотгольд Ейзенштейн у 1840–1850 роках використали суми Якобі та Ґаусса для встановлення законів взаємності вищих степенів (кубічного та біквадратичного законів взаємності). Вони показали, що прості числа `p ≡ 1 (mod 3)` розкладаються на добуток простих елементів у кільці цілих чисел Ейзенштейна `Z[ω]` саме за допомогою суми Якобі для кубічного характеру `χ₃`:

```
p = a² + 3·b² = J(χ₃, χ₃) · J̄(χ₃, χ₃)
```

Аналогічно, для простих чисел `p ≡ 1 (mod 4)` біквадратична сума Якобі `J(χ₄, χ₄)` здійснює явний розклад числа `p` у кільці цілих гауссових чисел `Z[i]`: `p = a² + b²`. Характери Діріхле та їхні спектральні суми стали головним інструментом арифметики полів кругового поділу.

## 5. Дедекінд та абстракція дуальних груп (1879)

До праць Ріхарда Дедекінда характери розглядалися виключно як обчислювальні числові таблиці за числовим модулем. У 1879 році, готуючи четверте видання лекцій Діріхле з теорії чисел (*Vorlesungen über Zahlentheorie*), Дедекінд здійснив вирішальний стрибок від конкретної модульної арифметики до абстрактної алгебри.

Дедекінд увів сучасне загальноалгебраїчне означення: **характер скінченної абелевої групи G** — це гомоморфізм групи `G` у мультиплікативну групу ненульових комплексних чисел `C*`:

```
χ: G → C*,   де   χ(g₁ · g₂) = χ(g₁) · χ(g₂)
```

Дедекінд довів три ключові положення абстрактної теорії:
1. **Дуальна група:** Множина всіх гомоморфізмів `Ĝ = Hom(G, C*)` сама утворює абелеву групу відносно поточкового множення `(χ₁ · χ₂)(g) = χ₁(g) · χ₂(g)`. Для будь-якої скінченної абелевої групи існує неізоморфний ізоморфізм `G ≅ Ĝ`.
2. **Канонічний подвійний дуалізм:** Відображення `g ↦ (χ ↦ χ(g))` задає природний ізоморфізм `G ≅ (Ĝ)̂`, вільний від вибору системи твірних. Елементи початкової групи діють як характери на своїй групі характерів.
3. **Теорема Дедекінда про лінійну незалежність:** Будь-яка скінченна множина різних характерів на довільній групі `G` є лінійно незалежною над полем комплексних чисел `C`. Якщо `∑ c_i · χ_i(g) = 0` для всіх `g ∈ G`, то всі коефіцієнти `c_i = 0`.

Ця теорема про лінійну незалежність характерів стала одним з найважливіших інструментів сучасної теорії полів та теорії Галуа.

## 6. Фробеніус і народження теорії уявлень (1896)

Наприкінці XIX століття перед математиками постало завдання поширити теорію характерів на **некомутативні (неабелеві) групи**. Приводом до цього стало листування між Ріхардом Дедекіндом та Ґеорґом Фробеніусом у 1895–1896 роках щодо задачі факторизації **групового детермінанта**.

Дедекінд звернув увагу на те, що якщо побудувати матрицю `M` розміру `|G| × |G|` зі змінними `x_{g·h⁻¹}`, то для абелевих груп детермінант `det(M)` повністю розпадається на добуток лінійних множників, які відповідають одновимірним характерам:

```
det(M) = ∏_{χ ∈ Ĝ} ( ∑_{g ∈ G} χ(g) · x_g )
```

Проте для некомутативних груп (наприклад, несиметричної групи `S₃`) детермінант містив незвідні множники вищих степенів (квадратичні та кубічні). Дедекінд не знав, як пояснити появу цих множників.

Ґеорґ Фробеніус у 1896 році дав повну відповідь на цю загадку. Він показав, що для некомутативних груп характери є не гомоморфізмами у числове поле, а **слідами лінійних матричних уявлень** групи:

```
χ(g) = Tr( ρ(g) )
```

де `ρ: G → GL(V)` — гомоморфізм групи `G` у групу оборотних лінійних операторів у векторному просторі `V`. Розмірність простору `dim V` визначає ступінь незвідного множника у груповому детермінанті.

Фробеніус довів, що:
- Одновимірні характери абелевих груп є частковим випадком уявлень розмірності `1`.
- Кількість незвідних характерів дорівнює кількості класів спряжених елементів групи.
- Характери є функціями класів (`χ(h·g·h⁻¹) = χ(g)`).
- Характери уявлень задовольняють співвідношення ортогональності Фробеніуса-Шура.

У ХХ столітті завдяки роботам Ісая Шура, Еміля Артіна (який увів L-функції Артіна для неабелевих характерів у 1923–1930 роках) та Роберта Ленґлендса характери стали універсальним математичним фундаментом для сучасної теорії автоморфних форм, квантової механіки та алгебраїчної геометрії.
