# 🧮 Суми Ґаусса та Якобі: алгебраїчні властивості й точні модулі

Цей математичний документ містить суворі алгебраїчні виведення фундаментальних властивостей сум Ґаусса та Якобі, повне аналітичне доведення теореми про рівномірність спектрального модуля привідної суми Ґаусса, детальне виведення формули зв'язку між сумами Ґаусса й Якобі (разом із вичерпним аналізом усіх граничних і вироджених випадків), а також застосування цих гармонічних інструментів до підрахунку розв'язків алгебраїчних рівнянь над скінченними полями.

## 1. Конструктивне означення та трансформаційні властивості

Скінченне просте поле характеристика якого дорівнює непарному простому числу поєднує в собі дві фундаментальні алгебраїчні структури, що діють на одній і тій самій множині лишків:
- адитивну циклічну групу порядку з операцією додавання за модулем;
- мультиплікативну циклічну групу порядку з операцією множення за модулем.

Ці дві операції взаємодіють між собою через дистрибутивний закон, проте їхній спектральний аналіз вимагає побудови двох взаємно дуальних систем комплексних функцій.

Адитивні характери скінченного поля є незвідними одновимірними уявленнями адитивної групи у мультиплікативну групу комплексних чисел. Оскільки адитивна група є циклічною, будь-який такий гомоморфізм повністю визначається тим, куди відображається одиничний елемент поля. Канонічний базисний адитивний характер зіставляє кожному елементу поля відповідну комплексну фазу на одиничному колі:

```
ψ_a(x) = exp( 2·π·i · a·x / p ) = e_p(a·x)
```

де параметр вибору частоти є фіксованим елементом поля. При зміні цього параметра ми отримуємо рівно різних адитивних функцій, які утворюють повний ортонормований базис у просторі всіх комплексних функцій на адитивній групі.

Мультиплікативні характери поля є гомоморфізмами з мультиплікативної групи ненульових лишків у групу комплексних коренів з одиниці степеня. Щоб проводити гармонічний аналіз по всій множині поля одночасно, область визначення мультиплікативного характеру розширюють на нульовий елемент за наступним аналітичним правилом: для будь-якого нетривіального характеру значення в нулі вважається строго рівним нулю, тоді як для головного тривіального характеру значення в нулі покладається рівним одиниці або нулю залежно від контексту адитивної згортки.

Сума Ґаусса є фундаментальним інтегральним мостом між цими двома світами. Вона визначається як дискретна комплексна згортка мультиплікативного характеру з адитивним характером по всій множині елементів поля:

```
g(χ, a) = ∑_{x ∈ F_p} χ(x) · exp( 2·π·i · a·x / p )
```

Коли частотний параметр адитивного характеру дорівнює одиниці, відповідну суму називають стандартною базисною сумою Ґаусса. Вона діє як дискретний оператор Фур'є, що перетворює мультиплікативні симетрії у спектральні амплітуди на адитивній ґратці.

### Фазова трансформація при адитивному масштабуванні

З'ясуємо, як змінюється значення суми Ґаусса, коли ми змінюємо аргумент адитивної хвилі. Для будь-якого ненульового елемента поля множення аргументу на константу є автоморфізмом поля, що дозволяє здійснити точну заміну змінної у сумі.

Теорема про масштабування стверджує, що для будь-якого ненульового параметра частоти зважена сума Ґаусса відрізняється від базисної суми Ґаусса лише домноженням на комплексно спряжене значення мультиплікативного характеру:

```
g(χ, a)
= ∑_{x=1}^{p-1} χ(x) · exp( 2·π·i · a·x / p )        [за означенням суми Ґаусса, оскільки значення в нулі дорівнює нулю]
= ∑_{y=1}^{p-1} χ(a⁻¹ · y) · exp( 2·π·i · y / p )     [заміна змінної y = a·x mod p, звідки x = a⁻¹·y mod p]
= χ(a⁻¹) · ∑_{y=1}^{p-1} χ(y) · exp( 2·π·i · y / p )   [винесення множника за мультиплікативністю характеру]
= χ̄(a) · g(χ)                                        [оскільки модуль значення характеру дорівнює одиниці, обернений елемент збігається зі спряженим]
```

Ця властивість демонструє, що вся родина зважених сум Ґаусса для фіксованого характеру повністю породжується одним комплексним числом — стандартною сумою Ґаусса.

Якщо ж параметр частоти стає рівним нулю, фазовий адитивний множник перетворюється на тотожну одиницю. Для нетривіального характеру відповідна сума стає звичайною сумою значень характеру по всій мультиплікативній групі, яка строго дорівнює нулю внаслідок базової ортогональності. Для головного характеру сума значень по всіх ненульових елементах дає точну кількість цих елементів, тобто число на одиницю менше за модуль.

## 2. Теорема про точний модуль привідної суми Ґаусса

Однією з найглибших властивостей сум Ґаусса є їхня ідеальна ізотропність: незважаючи на надзвичайно складну внутрішню фазову структуру, геометрична довжина комплексного вектора нетривіальної суми Ґаусса завжди строго фіксована і дорівнює квадратному кореню з характеристики поля.

Теорема стверджує, що для будь-якого нетривіального характеру квадрат абсолютного значення суми Ґаусса точно дорівнює числу елементів простого поля:

```
|g(χ)|² = p   ⇒   |g(χ)| = √p
```

### Детальне аналітичне доведення теореми

Для доведення обчислимо квадрат модуля комплексного числа через добуток самого числа на його комплексне спряження. Оскільки комплексне спряження суми дорівнює сумі спряжених доданків, спряжена сума Ґаусса містить спряжені значення мультиплікативного характеру та протилежний знак в експоненті адитивної фази.

Перемножуючи дві незалежні суми за змінними підсумовування, ми отримуємо подвійну суму по всіх парах ненульових елементів поля:

```
|g(χ)|²
= g(χ) · ḡ(χ)                                              [визначення квадрата модуля комплексного числа]
= ( ∑_{x=1}^{p-1} χ(x) · e_p(x) ) · ( ∑_{y=1}^{p-1} χ̄(y) · e_p(-y) )  [комплексне спряження фаз підсумовування]
= ∑_{x=1}^{p-1} ∑_{y=1}^{p-1} χ(x) · χ̄(y) · e_p(x - y)      [об'єднання двох скінченних сум у подвійну суму]
```

Оскільки ненульові елементи поля утворюють мультиплікативну групу, для кожного фіксованого другого індексу ми можемо зробити заміну першого індексу через добуток нового параметра на другий індекс за модулем поля. Ця операція є взаємно однозначним перетворенням групи:

```
|g(χ)|²
= ∑_{t=1}^{p-1} ∑_{y=1}^{p-1} χ(t·y) · χ̄(y) · e_p(t·y - y)  [заміна змінної першого індексу на добуток t на y]
= ∑_{t=1}^{p-1} ∑_{y=1}^{p-1} χ(t) · χ(y) · χ̄(y) · e_p(y · (t - 1)) [розклад мультиплікативного характеру від добутку]
= ∑_{t=1}^{p-1} χ(t) · ( ∑_{y=1}^{p-1} e_p(y · (t - 1)) )   [скорочення взаємно спряжених значень характеру в одиницю]
```

Тепер проаналізуємо поведінку внутрішньої суми адитивних експонент залежно від значення мультиплікативного зсуву:

1. Якщо параметр зсуву дорівнює одиниці, різниця в аргументі експоненти обнуляється. Експонента від нуля перетворюється на одиницю для кожного значення другого індексу, тому внутрішня сума перетворюється на суму одиниць, кількість яких дорівнює числу ненульових лишків:

```
∑_{y=1}^{p-1} e_p(y · 0) = ∑_{y=1}^{p-1} 1 = p - 1          [підсумовування константних одиниць]
```

2. Якщо параметр зсуву не дорівнює одиниці, різниця є ненульовим елементом поля. При зміні індексу підсумовування аргумент адитивної експоненти пробігає всі ненульові елементи поля. Доповнюючи цю суму нульовим доданком, ми отримуємо повну суму адитивного характеру по всій групі, яка тотожно дорівнює нулю. Віднімаючи значення в нулі, знаходимо точну величину внутрішньої суми:

```
∑_{y=1}^{p-1} e_p(y · (t - 1))
= ( ∑_{y=0}^{p-1} e_p(y · (t - 1)) ) - e_p(0)               [доповнення суми до повної групи]
= 0 - 1 = -1                                                [застосування ортогональності адитивного характеру]
```

Підставляючи ці два випадки у зовнішню суму за параметром зсуву, отримуємо точне співвідношення:

```
|g(χ)|²
= χ(1) · (p - 1) + ∑_{t=2}^{p-1} χ(t) · (-1)                 [розділення на одиничний і неодиничні випадки]
= 1 · (p - 1) - ∑_{t=2}^{p-1} χ(t)                           [врахування того, що характер від одиниці дорівнює одиниці]
= (p - 1) - ( ∑_{t=1}^{p-1} χ(t) - χ(1) )                     [додавання та віднімання першого доданка суми]
= (p - 1) - ( 0 - 1 )                                        [використання ортогональності для нетривіального характеру]
= (p - 1) + 1                                                [розкриття подвійного мінуса]
= p                                                          [строге завершення доведення теореми]
```

Отриманий результат є аналогом теореми Планшереля або збереження енергії у гармонічному аналізі: будь-який мультиплікативний характер має абсолютно рівномірний спектральний профіль на адитивній групі.

## 3. Суми Якобі та класифікація їхніх властивостей

Якщо суми Ґаусса описують взаємодію між мультиплікативним та адитивним характерами, то **суми Якобі** є нелінійною згорткою двох незалежних мультиплікативних характерів на адитивно зв'язаних аргументах.

Означення суми Якобі задається згорткою значень першого характеру та другого характеру на лінійно доповняльних елементах поля:

```
J(χ, ψ) = ∑_{x ∈ F_p} χ(x) · ψ(1 - x)
```

де при обчисленні враховується домовленість про нульове значення характеру на нульовому елементі поля.

### Повний структурний аналіз можливих випадків

Залежно від вибору двох характерів виникають чотири фундаментальні конфігурації:

1. **Невироджений регулярний випадок:** обидва характери є нетривіальними, і їхній добуток також є нетривіальним характером. У цьому випадку сума Якобі виражається через відношення відповідних сум Ґаусса, а її геометричний модуль строго дорівнює кореню з простого числа.

2. **Випадок взаємно спряжених характерів:** обидва характери є нетривіальними, проте їхній добуток перетворюється на тривіальний характер, що еквівалентно умові спряженості другого характеру до першого. У цьому випадку значення суми Якобі можна обчислити прямо через заміну змінної відношення:

```
J(χ, χ̄)
= ∑_{x=2}^{p-1} χ(x) · χ̄(1 - x)                              [вилучення нульових граничних доданків]
= ∑_{x=2}^{p-1} χ( x / (1 - x) )                             [використання спряженості мультиплікативного характеру]
= ( ∑_{u=1}^{p-1} χ(u) ) - χ(-1)                             [перехід до нової змінної відношення та вилучення особливої точки]
= 0 - χ(-1)                                                  [використання ортогональності для нетривіального характеру]
= -χ(-1)                                                     [остаточний точний вираз для спряженої пари]
```

3. **Випадок двох тривіальних характерів:** якщо обидва характери є головними, їхній добуток у кожній внутрішній точці поля дорівнює одиниці. Оскільки в нулі та в одиниці відповідні множники обнуляються, сума Якобі складається з одиниць по всіх інших точках поля:

```
J(χ₀, χ₀) = ∑_{x=2}^{p-1} 1 = p - 2
```

4. **Випадок одного тривіального характеру:** якщо перший характер є нетривіальним, а другий тривіальним, значення другого характеру дорівнює одиниці скрізь, окрім точки одиниці. Сума Якобі зводиться до повної суми нетривіального характеру без одиничного доданка:

```
J(χ, χ₀)
= ∑_{x=1}^{p-1} χ(x) · χ₀(1 - x)                             [вилучення нульової точки]
= ( ∑_{x=1}^{p-1} χ(x) ) - χ(1)                              [вилучення точки одиниці, де головний характер обнуляється]
= 0 - 1 = -1                                                 [застосування ортогональності для нетривіального характеру]
```

## 4. Строге виведення зв'язку сум Ґаусса та Якобі

Доведемо теорему, яка встановлює універсальну формулу факторизації добутку двох сум Ґаусса через суму Якобі у регулярному невиродженому випадку.

Теорема стверджує, що добуток двох незалежних сум Ґаусса тотожно розкладається на добуток суми Ґаусса їхнього характеру-добутку та суми Якобі цих двох характерів:

```
g(χ) · g(ψ) = g(χ · ψ) · J(χ, ψ)
```

### Покрокове аналітичне виведення формули розкладу

Розпишемо добуток двох сум Ґаусса як подвійну суму за двома незалежними індексами:

```
g(χ) · g(ψ)
= ( ∑_{u=1}^{p-1} χ(u) · e_p(u) ) · ( ∑_{v=1}^{p-1} ψ(v) · e_p(v) )  [запис добутку двох незалежних сум Ґаусса]
= ∑_{u=1}^{p-1} ∑_{v=1}^{p-1} χ(u) · ψ(v) · e_p(u + v)                [об'єднання фаз та множників під єдину подвійну суму]
```

Згрупуємо всі доданки цієї подвійної суми за значенням їхньої адитивної суми за модулем поля. Нехай новий параметр задає повну адитивну суму двох змінних:

```
g(χ) · g(ψ) = ∑_{s=0}^{p-1} ( ∑_{u=1}^{p-1} χ(u) · ψ(s - u) ) · e_p(s)  [перегрупування за фіксованою сумою аргументів]
```

Тепер дослідимо внутрішню суму для нульового та ненульового значень повної адитивної суми:

- Якщо сума аргументів дорівнює нулю, другий індекс стає протилежним до першого за модулем. Виносячи знак мінус за межі характеру завдяки мультиплікативності, ми отримуємо суму добутку характерів по всій групі. Оскільки за припущенням теореми добуток характерів є нетривіальним, ця сума строго дорівнює нулю:

```
∑_{u=1}^{p-1} χ(u) · ψ(-u)
= ψ(-1) · ∑_{u=1}^{p-1} χ(u) · ψ(u)                          [винесення константного фазового множника]
= ψ(-1) · ∑_{u=1}^{p-1} (χ · ψ)(u)                           [об'єднання двох характерів в єдиний характер-добуток]
= ψ(-1) · 0 = 0                                              [ортогональність нетривіального характеру-добутку]
```

- Якщо сума аргументів є ненульовою, цей елемент має мультиплікативно обернений у полі. Зробимо заміну змінної першого індексу через добуток повної суми на новий відносний параметр. Завдяки повній мультиплікативності спільний множник виноситься за дужки:

```
∑_{u=1}^{p-1} χ(u) · ψ(s - u)
= ∑_{x ∈ F_p} χ(s · x) · ψ(s · (1 - x))                      [заміна змінної першого індексу на добуток]
= ∑_{x ∈ F_p} χ(s) · χ(x) · ψ(s) · ψ(1 - x)                  [розкриття мультиплікативних характерів від добутків]
= χ(s) · ψ(s) · ( ∑_{x ∈ F_p} χ(x) · ψ(1 - x) )             [винесення спільних фазових множників за дужки]
= (χ · ψ)(s) · J(χ, ψ)                                       [ідентифікація отриманих виразів як суми Якобі]
```

Підставляючи знайдені значення внутрішніх сум назад у загальний вираз для добутку, отримуємо:

```
g(χ) · g(ψ)
= 0 · e_p(0) + ∑_{s=1}^{p-1} (χ · ψ)(s) · J(χ, ψ) · e_p(s)  [підстановка нульового та регулярного випадків]
= J(χ, ψ) · ( ∑_{s=1}^{p-1} (χ · ψ)(s) · e_p(s) )           [винесення константної суми Якобі за дужки]
= J(χ, ψ) · g(χ · ψ)                                         [запис суми у вигляді стандартної суми Ґаусса]
```

Оскільки модуль суми Ґаусса для нетривіального добутку характерів дорівнює кореню з простого числа і не перетворюється на нуль, ми можемо розділити обидві частини рівності на цю величину. Це дає остаточну формулу для суми Якобі через відношення сум Ґаусса:

```
J(χ, ψ) = ( g(χ) · g(ψ) ) / g(χ · ψ)
```

Звідси безпосередньо випливає точний модуль суми Якобі для регулярної пари:

```
|J(χ, ψ)| = ( |g(χ)| · |g(ψ)| ) / |g(χ · ψ)| = ( √p · √p ) / √p = √p
```

## 5. Узагальнені суми Якобі та гіперповерхні Ферма

Означення суми Якобі природно узагальнюється на випадок довільної кількості мультиплікативних характерів. Для набору з кількох характерів узагальнена сума Якобі визначається як кратна згортка по всіх точках векторного простору, координати яких у сумі дають одиничний елемент поля:

```
J(χ₁, χ₂, ..., χ_k) = ∑_{x₁ + x₂ + ... + x_k = 1} χ₁(x₁) · χ₂(x₂) · ... · χ_k(x_k)
```

Якщо жоден з характерів у наборі не є тривіальним і добуток усіх характерів також не перетворюється на головний характер, узагальнена сума Якобі розкладається у добуток окремих сум Ґаусса, поділений на суму Ґаусса їхнього спільного добутку:

```
J(χ₁, χ₂, ..., χ_k) = ( g(χ₁) · g(χ₂) · ... · g(χ_k) ) / g(χ₁ · χ₂ · ... · χ_k)
```

Модуль такої кратної суми Якобі обчислюється як відповідний степінь кореня з простого числа:

```
|J(χ₁, ..., χ_k)| = ( (√p)^k ) / √p = p^{(k-1)/2}
```

Ця теорема є центральним інструментом для обчислення кількості розв'язків діагональних рівнянь та гіперповерхонь Ферма у довільних скінченних полях.

## 6. Застосування: підрахунок кількості точок на алгебраїчних кривих

Розглянемо класичну діофантову задачу підрахунку кількості розв'язків рівняння одиничного кола у скінченному полі:

```
x² + y² ≡ 1 (mod p)
```

Кількість розв'язків одновимірного квадратного рівняння для будь-якого фіксованого значення аргументу виражається через квадратичний характер Лежандра: якщо елемент є квадратичним залишком, рівняння має два розв'язки; якщо елемент дорівнює нулю, існує рівно один розв'язок; якщо елемент є незалишком, розв'язків немає. Цей факт записується компактною формулою:

```
N(u² = t) = 1 + χ_leg(t)
```

Підсумовуючи кількість розв'язків по всіх можливих парах елементів поля, сума яких дорівнює одиниці, ми зводимо підрахунок точок на колі до суми Якобі:

```
N
= ∑_{a + b = 1} N(x² = a) · N(y² = b)                        [розклад на незалежні компоненти квадратів змінних]
= ∑_{a + b = 1} ( 1 + χ_leg(a) ) · ( 1 + χ_leg(b) )          [підстановка формульних індикаторів через характер Лежандра]
= ∑_{a+b=1} 1 + ∑_{a+b=1} χ_leg(a) + ∑_{a+b=1} χ_leg(b) + ∑_{a+b=1} χ_leg(a) · χ_leg(b) [розкриття дужок у подвійній сумі]
= p + 0 + 0 + J(χ_leg, χ_leg)                                [застосування ортогональності та означення суми Якобі]
```

Оскільки характер Лежандра є дійсним і задовольняє умову самоспряженості, сума Якобі для двох однакових символів Лежандра дорівнює взятому з протилежним знаком значенню характеру в мінус одиниці:

```
J(χ_leg, χ_leg) = -χ_leg(-1) = -(-1)^{(p-1)/2}
```

Підставляючи це співвідношення, отримуємо остаточну точну кількість точок на колі:

```
N = p - (-1)^{(p-1)/2}
```

- Для простих чисел, які при діленні на чотири дають остачу один, кількість точок строго дорівнює числу на одиницю меншому за модуль поля.
- Для простих чисел, які при діленні на чотири дають остачу три, кількість точок строго дорівнює числу на одиницю більшому за модуль поля.

### Аналіз кубічної кривої Ферма

Для кубічного рівняння у полі, характеристика якого при діленні на три дає остачу один, мультиплікативна група містить кубічні характери порядку три. Кількість точок на такій кривій виражається через дійсну частину суми Якобі кубічного характеру:

```
N_3 = p + 2 · Re( J(χ₃, χ₃) )
```

Оскільки геометричний модуль кубічної суми Якобі дорівнює кореню з простого числа, відхилення кількості точок від середнього значення не перевищує подвоєного кореня з характеристики поля, що є строгим підтвердженням гіпотези Рімана для алгебраїчних кривих над скінченними полями (теорема Гассе-Вейля).

## 7. Чисельний приклад і перевірка для модуля p = 7

Проведемо повну чисельну перевірку всіх виведених теоретичних результатів для конкретного простого модуля сім.

У полі лишків за модулем сім елементи діляться на квадратичні залишки та квадратичні незалишки. Квадратами ненульових лишків є числа один, два та чотири (на них символ Лежандра дорівнює плюс один), тоді як числа три, п'ять та шість є незалишками (на них символ Лежандра дорівнює мінус один).

Обчислимо суму Якобі для квадратичного характеру безпосереднім додаванням:

```
J(χ_leg, χ_leg) = ∑_{x=0}^{6} χ_leg(x) · χ_leg(1 - x)
```

Таблиця всіх семи доданків має вигляд:
- при нульовому значенні аргументу перший множник дорівнює нулю, доданок дорівнює нулю;
- при одиничному значенні аргументу другий множник дорівнює нулю, доданок дорівнює нулю;
- при аргументі два маємо добуток значень у точках два та шість, що дає мінус один;
- при аргументі три маємо добуток значень у точках три та п'ять, що дає плюс один;
- при аргументі чотири маємо добуток значень у точках чотири та чотири, що дає плюс один;
- при аргументі п'ять маємо добуток значень у точках п'ять та три, що дає плюс один;
- при аргументі шість маємо добуток значень у точках шість та два, що дає мінус один.

Додаючи всі знайдені величини, отримуємо точне значення суми: мінус один плюс один плюс один плюс один мінус один дорівнює плюс одиниці.

Теоретична формула для модуля сім передбачає значення мінус символ Лежандра від шести, тобто мінус від мінус одиниці, що точно дорівнює плюс одиниці.

Кількість точок на колі за модулем сім згідно з формулою становить сім мінус мінус одиниця, тобто рівно вісім точок.

Прямий перебір пар дає чотири точки на координатних осях (нуль один, нуль шість, один нуль, шість нуль) та чотири внутрішні точки (два два, два п'ять, п'ять два, п'ять п'ять), сума квадратів координат яких при діленні на сім дає остачу один. Теоретичні виведення повністю узгоджуються з точним чисельним результатом.
