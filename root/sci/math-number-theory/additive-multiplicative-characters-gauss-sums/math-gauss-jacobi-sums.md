# 🧮 Суми Ґаусса та Якобі: алгебраїчні властивості й точні модулі

Цей математичний документ містить суворі алгебраїчні виведення властивостей сум Ґаусса та Якобі, повне доведення теореми про модуль привідної суми Ґаусса `|g(χ)| = √p`, виведення точної формули зв'язку між сумами Ґаусса й Якобі та їхнє застосування до точного підрахунку кількості розв'язків діофантових рівнянь у скінченних полях.

## 1. Конструктивне означення та трансформаційні властивості

Розглянемо скінченне просте поле `F_p = Z/pZ` характеристика `p` (де `p` — непарне просте число). Поле `F_p` об'єднує в собі дві фундаментальні алгебраїчні структури: адитивну групу `(F_p, +)` порядку `p` та мультиплікативну групу `(F_p*, ·)` порядку `p - 1`.

Адитивні характери поля `F_p` являють собою комплексні експоненціальні функції адитивної групи, які виражаються через комплексні корені з одиниці степеня `p`:

```
ψ_a(x) = exp(2·π·i · a·x / p) = e_p(a·x)
```

де `a ∈ F_p`. Якщо параметр `a = 1`, ми отримуємо канонічний (базовий) адитивний характер `e_p(x) = exp(2·π·i · x / p)`.

Мультиплікативні характери `χ: F_p* → C*` являють собою гомоморфізми з мультиплікативної групи поля у мультиплікативну групу комплексних чисел. Для зручності підсумовування по всьому полю `F_p` область визначення характеру розширюють на нульовий елемент, покладаючи `χ(0) = 0` для всіх нетривіальних характерів та `χ₀(0) = 0` (або `χ₀(0) = 1` за домовленістю у теорії L-функцій).

**Означення:** Для будь-якого мультиплікативного характеру `χ` та будь-якого адитивного характеру `e_p(a·x)` **сумою Ґаусса** `g(χ, a)` називається скінченна комплексна згортка:

```
g(χ, a) = ∑_{x ∈ F_p} χ(x) · exp(2·π·i · a·x / p)
```

Якщо параметр `a = 1`, суму називають стандартною сумою Ґаусса і позначають просто `g(χ)`.

Сума Ґаусса відіграє роль дискретного перетворення Фур'є мультиплікативного характеру `χ` на адитивній групі `(F_p, +)`. Вона зв'язує мультиплікативні фази `χ(x)` з адитивними осциляціями `e_p(a·x)`.

### Трансформаційна властивість суми Ґаусса

Дослідимо, як поводиться сума Ґаусса `g(χ, a)` при зміні адитивного параметра `a`. Для будь-якого ненульового елемента `a ∈ F_p*` (тобто `gcd(a, p) = 1`) аргумент адитивної фази піддається зсуву, який компенсується сопряженим значенням мультиплікативного характеру:

```
g(χ, a)
= ∑_{x=1}^{p-1} χ(x) · exp(2·π·i · a·x / p)       [за визначенням суми Ґаусса]
= ∑_{y=1}^{p-1} χ(a⁻¹ · y) · exp(2·π·i · y / p)    [зміна змінної: y ≡ a·x mod p  ⇒  x ≡ a⁻¹·y mod p]
= χ(a⁻¹) · ∑_{y=1}^{p-1} χ(y) · exp(2·π·i · y / p)  [мультиплікативність: χ(a⁻¹·y) = χ(a⁻¹)·χ(y)]
= χ̄(a) · g(χ)                                   [властивість унітарності: χ(a⁻¹) = χ̄(a)]
```

Ця трансформаційна властивість показує, що зважена адитивна сума `g(χ, a)` повністю визначається значенням базисної суми `g(χ)` та комплексно-спряженим значенням характеру `χ̄(a)`. Якщо `a = 0`, то `g(χ, 0) = ∑_{x=1}^{p-1} χ(x) = 0` для будь-якого нетривіального характеру за ортогональністю.

## 2. Теорема про модуль привідної суми Ґаусса

Фундаментальне значення сум Ґаусса в аналітичній теорії чисел та криптографії полягає у їхньому тоці геометричному модулі. Для будь-якого привідного характеру сума Ґаусса розподіляє свою енергію абсолютно рівномірно по всьому спектру.

**Теорема:** Якщо характер `χ` є нетривіальним (`χ ≠ χ₀`), то квадрат абсолютного значення суми Ґаусса точно дорівнює характеристиці поля `p`:

```
|g(χ)|² = p   ⇒   |g(χ)| = √p
```

### Строге покрокове доведення:

Скористаємося фундаментальним визначенням модуля комплексного числа `|z|² = z · z̄`, де спряження суми дорівнює сумі спряжених доданків:

```
|g(χ)|²
= g(χ) · ḡ(χ)                                              [визначення модуля комплексного числа]
= ( ∑_{x=1}^{p-1} χ(x) · e_p(x) ) · ( ∑_{y=1}^{p-1} χ̄(y) · e_p(-y) )  [комплексне спряження адитивної фази]
= ∑_{x=1}^{p-1} ∑_{y=1}^{p-1} χ(x) · χ̄(y) · e_p(x - y)      [об'єднання сум у подвійну суму за всіма парами x, y]
```

Здійснюємо заміну змінної в мультиплікативній групі `(F_p*, ·)`: покладаємо `x ≡ t · y (mod p)`, де `t` пробігає всі ненульові лишки `{1, 2, ..., p - 1}` при фіксованому значення `y`. Оскільки множення на `y` є автоморфізмом групи `F_p*`, ця заміна є взаємно однозначною:

```
|g(χ)|²
= ∑_{t=1}^{p-1} ∑_{y=1}^{p-1} χ(t·y) · χ̄(y) · e_p(t·y - y)  [заміна x = t·y mod p]
= ∑_{t=1}^{p-1} ∑_{y=1}^{p-1} χ(t) · χ(y) · χ̄(y) · e_p(y · (t - 1)) [використання мультиплікативності]
= ∑_{t=1}^{p-1} χ(t) · ( ∑_{y=1}^{p-1} e_p(y · (t - 1)) )   [оскільки χ(y)·χ̄(y) = |χ(y)|² = 1]
```

Проаналізуємо внутрішню суму за змінною `y`. Вона являє собою суму адитивних фаз і має абсолютно різну поведінку залежно від того, чи дорівнює значення `t` одиниці:

1. **Перший випадок: `t = 1`.**
   Аргумент експоненти `t - 1 = 0`. Тоді `e_p(y · 0) = e_p(0) = 1` для всіх `y`.
   Внутрішня сума дорівнює кількості елементів групи:

```
∑_{y=1}^{p-1} 1 = p - 1   [підсумовування p-1 одиниць]
```

2. **Другий випадок: `t ≠ 1` (тобто `t - 1 ≢ 0 mod p`).**
   Оскільки `y` пробігає значення `1, 2, ..., p - 1`, доповнення суми елементом `y = 0` дає повну суму адитивного характеру по всій групі `F_p`, яка дорівнює нулю за співвідношенням ортогональності:

```
∑_{y=0}^{p-1} e_p(y · (t - 1)) = 0  ⇒  ∑_{y=1}^{p-1} e_p(y · (t - 1)) = 0 - e_p(0) = -1  [ортогональність адитивної фази]
```

Підставляємо ці значення у зовнішню суму за `t`:

```
|g(χ)|²
= χ(1) · (p - 1) + ∑_{t=2}^{p-1} χ(t) · (-1)                  [розділення суми на доданок t = 1 та суму за t ≠ 1]
= 1 · (p - 1) - ∑_{t=2}^{p-1} χ(t)                            [оскільки значення характеру в одиниці χ(1) = 1]
= (p - 1) - ( ∑_{t=1}^{p-1} χ(t) - χ(1) )                      [додавання та віднімання терму t = 1 у сумі]
= (p - 1) - ( 0 - 1 )                                         [за ортогональністю нетривіального характеру]
= (p - 1) + 1                                                 [спрощення різниці мінус на мінус]
= p                                                           [завершення строгого доведення]
```

Отже, абсолютна величина будь-якої нетривіальної суми Ґаусса за простим модулем строго дорівнює `√p`. Цей результат є аналогом теореми Парсеваля для дискретного перетворення Фур'є.

## 3. Суми Якобі та їхній зв'язок із сумами Ґаусса

Якщо суми Ґаусса описують взаємодію між мультиплікативним та адитивним характером, то **суми Якобі** описують нелінійну згортку двох різних мультиплікативних характерів на адитивно зсунутих аргументах.

**Означення:** Для двох мультиплікативних характерів `χ` та `ψ` за модулем `p` **сумою Якобі** `J(χ, ψ)` називається сума:

```
J(χ, ψ) = ∑_{x ∈ F_p} χ(x) · ψ(1 - x)
```

Сума Якобі вимірює алгебраїчну кореляцію між значеннями характерів `χ` та `ψ` на елементах `x` та `1 - x`. Вона є фундаментальним інструментом у підрахунку точок на алгебраїчних кривих над скінченними полями.

### Теорема про зв'язок сум Ґаусса та Якобі

Якщо характери `χ`, `ψ` та їхній добуток `χ · ψ` є нетривіальними за модулем `p`, то сума Якобі тотожно виражається через добуток відповідних сум Ґаусса:

```
J(χ, ψ) = ( g(χ) · g(ψ) ) / g(χ · ψ)
```

### Строге доведення:

Розглянемо добуток двох незалежних сум Ґаусса `g(χ)` та `g(ψ)`:

```
g(χ) · g(ψ)
= ( ∑_{u=1}^{p-1} χ(u) · e_p(u) ) · ( ∑_{v=1}^{p-1} ψ(v) · e_p(v) )  [за визначенням сум Ґаусса для χ та ψ]
= ∑_{u=1}^{p-1} ∑_{v=1}^{p-1} χ(u) · ψ(v) · e_p(u + v)                [об'єднання незалежних сум за u та v]
```

Здійснюємо заміну змінних у цій подвійній сумі. Покладемо `s ≡ u + v (mod p)`.
Якщо `s ≡ 0 (mod p)`, то `v ≡ -u (mod p)`. Внесок таких пар `(u, -u)` у суму дорівнює:

```
∑_{u=1}^{p-1} χ(u) · ψ(-u) = ψ(-1) · ∑_{u=1}^{p-1} (χ · ψ)(u) = 0   [ортогональність нетривіального характеру χ·ψ]
```

оскільки за умовою теореми добуток характерів `χ · ψ` є нетривіальним.

Якщо `s ≢ 0 (mod p)`, ми можемо параметризувати пари `(u, v)` за допомогою нової змінної `x ∈ F_p`: покладаємо `u ≡ s · x (mod p)` та `v ≡ s · (1 - x) (mod p)`. Коли `x` пробігає всі значення поля `F_p`, пара `(u, v)` пробігає всі можливі елементи з фіксованою сумою `u + v ≡ s (mod p)`:

```
g(χ) · g(ψ)
= ∑_{s=1}^{p-1} ∑_{x ∈ F_p} χ(s · x) · ψ(s · (1 - x)) · e_p(s)      [заміна змінних u = s·x та v = s·(1-x)]
= ∑_{s=1}^{p-1} ∑_{x ∈ F_p} χ(s) · ψ(s) · χ(x) · ψ(1 - x) · e_p(s)   [за мультиплікативністю характерів]
= ( ∑_{s=1}^{p-1} (χ · ψ)(s) · e_p(s) ) · ( ∑_{x ∈ F_p} χ(x) · ψ(1 - x) ) [відокремлення незалежних сум за s та x]
= g(χ · ψ) · J(χ, ψ)                                               [за визначенням сум Ґаусса та Якобі]
```

Поділивши обидві частини рівності на `g(χ · ψ)` (що правомірно, оскільки `|g(χ · ψ)| = √p ≠ 0`), отримуємо шукану формулу зв'язку.

З цієї теореми негайно випливає точний модуль суми Якобі для нетривіальних характерів:

```
|J(χ, ψ)| = ( |g(χ)| · |g(ψ)| ) / |g(χ · ψ)| = ( √p · √p ) / √p = √p   [обчислення модуля за модулями сум Ґаусса]
```

## 4. Точний підрахунок точок на кривих над F_p

Застосуємо розвинутий математичний апарат сум Ґаусса та Якобі до класичної діофантової задачі: обчислення точної кількості розв'язків рівняння кола у скінченному простому полі `F_p`:

```
x² + y² ≡ 1 (mod p)
```

Для аналізу квадратних лишків скористаємося квадратичним характером Лежандра `χ_leg(t) = (t / p)`. Кількість розв'язків квадратного рівняння `u² ≡ t (mod p)` для будь-якого `t ∈ F_p` виражається точним формульним індикатором:

```
N(u² = t) = 1 + χ_leg(t)   [формульний індикатор кількості квадратних коренів]
```

Записуємо загальну кількість точок `N(x² + y² = 1 mod p)` як суму за всіма можливими парами `(a, b)` таким, що `a + b ≡ 1 (mod p)`:

```
N(x² + y² = 1 mod p)
= ∑_{a + b = 1} N(x² = a) · N(y² = b)                              [підрахунок за незалежними компонентами a = x² та b = y²]
= ∑_{a + b = 1} (1 + χ_leg(a)) · (1 + χ_leg(b))                    [підстановка індикаторів через символ Лежандра]
= ∑_{a+b=1} 1 + ∑_{a+b=1} χ_leg(a) + ∑_{a+b=1} χ_leg(b) + ∑_{a+b=1} χ_leg(a) · χ_leg(b) [розкриття дужок у подвійній сумі]
= p + 0 + 0 + J(χ_leg, χ_leg)                                      [ортогональність характерів та визначення суми Якобі]
```

Проаналізуємо кожну з чотирьох отриманих сум окремо:

1. Перша сума `∑_{a+b=1} 1 = p`, оскільки існує рівно `p` пар `(a, b)` у полі `F_p` з сумою `1`.
2. Друга сума `∑_{a+b=1} χ_leg(a) = ∑_{a ∈ F_p} χ_leg(a) = 0` за ортогональністю квадратичного характеру.
3. Третя сума `∑_{a+b=1} χ_leg(b) = ∑_{b ∈ F_p} χ_leg(b) = 0` аналогічно.
4. Четверта сума за визначенням являє собою суму Якобі `J(χ_leg, χ_leg)` для двох символів Лежандра:

```
N(x² + y² = 1 mod p) = p + J(χ_leg, χ_leg)   [вираження точок через суму Якобі]
```

Обчислимо суму Якобі `J(χ_leg, χ_leg)` через зв'язок із сумами Ґаусса:

```
J(χ_leg, χ_leg) = ( g(χ_leg)² ) / g(χ_leg²) = ( g(χ_leg)² ) / g(χ₀)   [застосування теореми про зв'язок сум]
```

Оскільки `χ_leg² = χ₀` (головний характер), сума Ґаусса для головного характеру дорівнює `g(χ₀) = ∑_{x=1}^{p-1} e_p(x) = -1`. Квадрат квадратичної суми Ґаусса визначається точним співвідношенням з теорії квадратичного закону взаємності:

```
g(χ_leg)² = (-1)^{(p-1)/2} · p   [квадрат квадратичної суми Ґаусса]
```

Звідси отримуємо точне значення суми Якобі:

```
J(χ_leg, χ_leg) = ( (-1)^{(p-1)/2} · p ) / (-1) = - (-1)^{(p-1)/2}   [ділення квадрата суми Ґаусса на g(χ₀) = -1]
```

Підставляючи це значення у формулу для кількості точок, отримуємо остаточну точну формулу:

```
N(x² + y² = 1 mod p) = p - (-1)^{(p-1)/2}   [остаточна точна формула кількості точок]
```

Аналіз отриманого результату:
- Якщо `p ≡ 1 (mod 4)`, то `(-1)^{(p-1)/2} = 1`, отже кількість точок дорівнює `N = p - 1`.
- Якщо `p ≡ 3 (mod 4)`, то `(-1)^{(p-1)/2} = -1`, отже кількість точок дорівнює `N = p + 1`.

Цей результат є яскравим прикладом того, як абстрактний гармонічний аналіз характерів дозволяє миттєво обчислювати кількість розв'язків нелінійних діофантових рівнянь без перебору варіантів.

## 5. Обчислювальний приклад для модуля p = 7

Проведемо повний чисельний розрахунок усіх введених величин для конкретного простого модуля `p = 7`.

1. **Структура поля:** `F_7 = {0, 1, 2, 3, 4, 5, 6}`, мультиплікативна група `F_7* = {1, 2, 3, 4, 5, 6}` порядку `6`.
2. **Первісний корінь:** `g = 3`. Перевірка степенів: `3⁰=1`, `3¹=3`, `3²=2`, `3³=6`, `3⁴=4`, `3⁵=5`.
3. **Квадратичний характер (символ Лежандра mod 7):**
   Квадратичні залишки `mod 7`: `1² ≡ 1`, `2² ≡ 4`, `3² ≡ 2`.
   - `χ_leg(1) = +1`, `χ_leg(2) = +1`, `χ_leg(4) = +1`.
   - `χ_leg(3) = -1`, `χ_leg(5) = -1`, `χ_leg(6) = -1`.

4. **Обчислення суми Якобі `J(χ_leg, χ_leg)` mod 7:**

```
J(χ_leg, χ_leg) = ∑_{x=0}^{6} χ_leg(x) · χ_leg(1 - x)
```

Таблиця доданків для кожного `x ∈ F_7`:
- `x = 0`: `χ_leg(0) · χ_leg(1) = 0 · 1 = 0`
- `x = 1`: `χ_leg(1) · χ_leg(0) = 1 · 0 = 0`
- `x = 2`: `χ_leg(2) · χ_leg(-1) = χ_leg(2) · χ_leg(6) = (+1) · (-1) = -1`
- `x = 3`: `χ_leg(3) · χ_leg(-2) = χ_leg(3) · χ_leg(5) = (-1) · (-1) = +1`
- `x = 4`: `χ_leg(4) · χ_leg(-3) = χ_leg(4) · χ_leg(4) = (+1) · (+1) = +1`
- `x = 5`: `χ_leg(5) · χ_leg(-4) = χ_leg(5) · χ_leg(3) = (-1) · (-1) = +1`
- `x = 6`: `χ_leg(6) · χ_leg(-5) = χ_leg(6) · χ_leg(2) = (-1) · (+1) = -1`

Сумуємо всі ненульові доданки:

```
J(χ_leg, χ_leg) = -1 + 1 + 1 + 1 - 1 = +1
```

5. **Перевірка точок на колі `x² + y² ≡ 1 (mod 7)`:**
   Оскільки `7 ≡ 3 (mod 4)`, наша теорема передбачає кількість точок:

```
N = 7 - (-1)^{(7-1)/2} = 7 - (-1)³ = 7 + 1 = 8 точок   [обчислення за остаточною формулою]
```

Перелічимо всі 8 дійсних розв'язків `(x, y) mod 7`:
- Осі координат: `(0, 1)`, `(0, 6)`, `(1, 0)`, `(6, 0)` [4 точки]
- Внутрішні точки поля:
  - `(2, 2)`: `2² + 2² = 4 + 4 = 8 ≡ 1 (mod 7)`
  - `(2, 5)`: `2² + 5² = 4 + 25 = 29 ≡ 1 (mod 7)`
  - `(5, 2)`: `5² + 2² = 25 + 4 = 29 ≡ 1 (mod 7)`
  - `(5, 5)`: `5² + 5² = 25 + 25 = 50 ≡ 1 (mod 7)` [4 точки]

Разом отримати точно 8 розв'язків, що повністю упевнює в абсолютній строгості теоретичних математичних виведень.
