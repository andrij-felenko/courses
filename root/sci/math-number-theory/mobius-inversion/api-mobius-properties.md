## 1. Фундаментальні визначення та таблиця значень

Функція Мьобіуса `μ: ℤ⁺ → {-1, 0, 1}` є мультиплікативною арифметичною функцією, що визначається за даними розкладу числа `n` на прості множники.

Для кожного натурального числа `n > 1` розглянемо його канонічний розклад на прості множники згідно з фундаментальною теоремою арифметики:

```
n = p₁^{k₁} · p₂^{k₂} · … · p_r^{k_r}
```

Значення функції Мьобіуса `μ(n)` визначається за трьома правилами:

```
          {  1,   якщо n = 1
μ(n) =    {  (-1)^r, якщо k₁ = k₂ = ... = k_r = 1  (n — бесквадратне число)
          {  0,   якщо існує k_i ≥ 2  (n ділиться на квадрат p²)
```

Функціональні характеристики числових величин, пов'язаних із факторизацією:
- `ω(n)` — кількість різних простих множників числа `n`.
- `Ω(n)` — загальна кількість простих множників числа `n` з урахуванням їхніх кратностей.
- `M(n) = ∑_{i=1}^n μ(i)` — значення функції Мертенса, що є префіксною сумою значень функції Мьобіуса.

## 2. Розширений звід алгебраїчних тотожностей згортки

Операція згортки Діріхле `(f * g)(n) = ∑_{d|n} f(d)g(n/d)` створює багату систему зв'язків між функцією Мьобіуса та іншими важливими чисельними функціями. Розглянемо детальний механізм кожного з цих співвідношень.

### 1. Тотожність обернення одиниці
Згортка функції Мьобіуса з постійною одиничною функцією `u(n) = 1` дає нейтральний елемент згортки `e(n) = [n == 1]`:
```
(μ * 1)(n) = ∑_{d|n} μ(d) = [n == 1] = e(n)
```
Ця тотожність є серцем усього теорії обернення. Вона стверджує, що сума коефіцієнтів Мьобіуса по всіх дільниках будь-якого числа `n > 1` дорівнює нулю.

### 2. Тотожність для функції Ейлера φ(n)
Згортка функції Мьобіуса з тотожною функцією `id(n) = n` виражає функцію Ейлера:
```
(μ * id)(n) = ∑_{d|n} μ(d) · (n/d) = φ(n)
```
Обернена форма за формулою обернення Мьобіуса має вигляд `(φ * 1)(n) = ∑_{d|n} φ(d) = n`. Ця формула показує, що кількість взаємно простих чисел від 1 до `n` можна отримати з кількості всіх чисел `n` шляхом віднімання чисел, які діляться на прості множники, з подальшим додаванням чисел, які діляться на добутки двох простих множників.

### 3. Тотожність для кількості дільників d(n)
Згортка функції Мьобіуса з функцією кількості дільників `d(n)` дає постійну одиницю `u(n) = 1`:
```
(μ * d)(n) = 1(n)  ⇒  ∑_{d|n} μ(d) · d(n/d) = 1
```
Обернена форма виражає кількість дільників як згортку двох одиниць: `d = 1 * 1`. Тобто `d(n) = ∑_{d|n} 1`.

### 4. Тотожність для суми дільників σ(n)
Згортка функції Мьобіуса з функцією суми дільників `σ(n)` дає тотожну функцію `id(n) = n`:
```
(μ * σ)(n) = id(n)  ⇒  ∑_{d|n} μ(d) · σ(n/d) = n
```
Обернена форма: `σ = id * 1`, що відповідає класичному означенню `σ(n) = ∑_{d|n} d`.

### 5. Тотожність для функції фон Мангольдта Λ(n)
Згортка функції Мьобіуса з логарифмом аргументу `ln(n)` виражає функцію фон Мангольдта `Λ(n)`:
```
(μ * ln)(n) = ∑_{d|n} μ(d) · ln(n/d) = Λ(n)
```
де `Λ(n) = ln p`, якщо `n = p^k` є степенем простого числа, та `0` у протилежному випадку. Обернена форма: `∑_{d|n} Λ(d) = ln n`. Ця тотожність відіграє фундаментальну роль у аналітичному доведенні теореми про розподіл простих чисел.

### 6. Взаємозв'язок із функцією Ліувілля λ(n)
Функція Ліувілля визначається як `λ(n) = (-1)^{Ω(n)}`, де `Ω(n)` є загальною кількістю простих множників з урахуванням їхніх кратностей. Вона пов'язана з функцією Мьобіуса співвідношенням:
```
(μ * λ)(n) = ∑_{d|n} μ(d) · λ(n/d) = |μ(n)| = μ²(n)
```
де `μ²(n)` є індикаторною функцією бесквадратних чисел. На відміну від `μ(n)`, функція Ліувілля є повністю мультиплікативною.

## 3. Суми Рамануджана та їхній зв'язок із функцією Мьобіуса

Спеціальні тригонометричні суми, введені індійським математиком Срінівасою Рамануджаном у 1918 році, визначаються як сума `k`-х степеней комплексних коренів з одиниці:

```
c_q(n) = ∑_{1 ≤ a ≤ q, gcd(a, q) = 1} exp( 2π · i · a · n / q )
```

Видатною властивістю сум Рамануджана є те, що вони завжди є цілими числами та виражаються безпосередньо через функцію Мьобіуса:

```

```

Для будь-якого вхідного натурального числа `n ∈ ℕ⁺` функція `mobius_value(n)` задовольняє наступні фундаментальні властивості:

## 5. Асимптотичні оцінки та гіпотеза Рімана

Асимптотична поведінка сум за участю функції Мьобіуса є тісно пов'язаною з найглибшими відкритими проблемами сучасної математики.

### 1. Функція Мертенса `M(x)`:
**Функцією Мертенса** називається підсумкова сума значень функції Мьобіуса для всіх натуральних чисел від `1` до `x`:

```
M(x) = ∑_{n ≤ x} μ(n)
```

- **Теорема про прості числа (PNT):** Співвідношення `lim_{x → ∞} M(x) / x = 0` є еквівалентним теоремі про розподіл простих чисел `π(x) ~ x / ln x`.
- **Гіпотеза Рімана (RH):** Спектральна гіпотеза про нулі дзета-функції Рімана є абсолютно еквівалентною твердженню, що для будь-якого `ε > 0` справджується асимптотична оцінка:
  ```
  M(x) = O( x^{1/2 + ε} )
  ```

### 2. Щільність бесквадратних чисел:
Кількість бесквадратних чисел (для яких `μ²(n) = 1`), що не перевищують `x`, задовольняє асимптотичну формулу:

```
Q(x) = ∑_{n ≤ x} μ²(n) = (6 / π²) · x + O( √x )
```

Звідси асимптотична щільність бесквадратних чисел серед усіх цілих дорівнює `6 / π² ≈ 0.6079` (або `60.79%`). Це означає, що понад 60% усіх натуральних чисел не мають жодного повторюваного простого множника.
