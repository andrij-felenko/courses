# 🧮 Алгебраїчне обґрунтування та доведення коректності алгоритму REDC

Ця вставка містить вичерпні математичні доведення коректності алгоритму редукції Монтгомері (REDC), строго обґрунтовує властивості кільцевого ізоморфізму простору Монтгомері, доводить єдиність коефіцієнта обнулення розрядів, встановлює точну границю проміжних значень, описує метод Гензеля для миттєвого обчислення констант, обґрунтовує алгебру диференційного додавання на кривих Монтгомері, доводить біраціональну еквівалентність із кривими Едвардса, обґрунтовує коректність безрозгалуженого зведення, виводить метод одночасного пакетного обернення, доводить асимптотичну складність гібриду Карацуби та аналізує інваріанти драбини Монтгомері для безпечних модульних обчислень.

### 1. Алгебраїчна структура простору Монтгомері та кільцевий ізоморфізм

Нехай `N` — фіксоване непарне натуральне число (`N > 1`), яке відіграє роль модуля обчислень, а `ℤ/Nℤ` — класичне кільце лишків за модулем `N`.

Оберемо допоміжну основу Монтгомері `R = 2ᵏ`, де натуральне число `k` обирається так, що основа строго перевищує модуль:

```
R > N
```

Оскільки число `N` непарне за умовою, а основа `R = 2ᵏ` є степенем двійки, вони не мають спільних дільників, крім одиниці. Отже, їхній найбільший спільний дільник дорівнює одиниці:

```
gcd(R, N) = 1      [N непарне, R є степенем двійки]
```

**Лема 1 (Необхідність непарності модуля).** Якщо модуль `N` парний (`gcd(R, N) = d > 1`), то мультиплікативний обернений `N⁻¹ mod R` не існує, оскільки для будь-якого цілого `x` добуток `N · x` є парним і не може давати непарний залишок `-1` за основою `2ᵏ`. Таким чином, непарність модуля є строгою алгебраїчною вимогою існування константи Монтгомері. Якщо криптографічна задача вимагає обчислень за парним модулем, парну частину попередньо відокремлюють за допомогою китайської теореми про залишки.

Визначимо відображення `φ: ℤ/Nℤ → ℤ/Nℤ`, яке ставить у відповідність кожному класичному залишку `a ∈ ℤ/Nℤ` його образ Монтгомері `ā`:

```
ā = φ(a) = (a · R) mod N
```

**Теорема 1 (Бієктивність відображення).** Відображення `φ` є взаємно однозначною відповідністю (бієкцією) на множині `ℤ/Nℤ`.

*Доведення.* Оскільки множина `ℤ/Nℤ` є скінченною (містить рівно `N` елементів), для доведення бієктивності достатньо довести ін'єктивність: якщо `φ(a) = φ(b)`, то `a = b`.

Припустимо, що `φ(a) = φ(b)`. За означенням відображення це означає:

```
(a · R) ≡ (b · R) (mod N)
```

Віднімемо праву частину від лівої та винесемо спільний множник:

```
(a - b) · R ≡ 0 (mod N)
```

Це означає, що добуток `(a - b) · R` ділиться націло на `N`. Оскільки за умовою `gcd(R, N) = 1`, за класичною лемою Евкліда модуль `N` зобов'язаний ділити перший множник `(a - b)`:

```
a - b ≡ 0 (mod N)      [оскільки gcd(R, N) = 1]
a ≡ b (mod N)          [додавання b до обох частин]
```

Оскільки обидва елементи `a` та `b` належать канонічній множині лишків `{0, 1, ..., N - 1}`, рівність за модулем `N` означає їхню точну числову рівність `a = b`. Отже, відображення `φ` ін'єктивне, а через скінченність множини — бієктивне. Кожен залишок має єдиний образ Монтгомері, і кожен образ однозначно визначає початковий залишок.

### 2. Співвідношення Безу та константи Монтгомері

Оскільки основа `R` та модуль `N` взаємно прості (`gcd(R, N) = 1`), за розширеною теоремою Безу існують такі цілі числа `R⁻¹` та `N'`, що виконується тотожність:

```
R · R⁻¹ - N · N' = 1
```

Перепишемо це алгебраїчне рівняння окремо за модулем `R` та за модулем `N`.

**Розгляд за модулем R:**

```
R · R⁻¹ - N · N' ≡ 1 (mod R)
0 - N · N' ≡ 1 (mod R)         [оскільки R · R⁻¹ ділиться на R націло]
-N · N' ≡ 1 (mod R)            [спрощення лівої частини]
N · N' ≡ -1 (mod R)            [множення обох частин на -1]
N' ≡ -N⁻¹ (mod R)              [визначення константи Монтгомері]
```

Таким чином, константа `N'` є від'ємним оберненим елементом до модуля `N` у кільці лишків за основою `R`. Її завжди можна привести до канонічного діапазону `N' ∈ [0, R - 1]`.

**Розгляд за модулем N:**

```
R · R⁻¹ - N · N' ≡ 1 (mod N)
R · R⁻¹ - 0 ≡ 1 (mod N)         [оскільки N · N' ділиться на N націло]
R · R⁻¹ ≡ 1 (mod N)             [визначення модульного оберненого до R]
```

Отже, ціле число `R⁻¹` є канонічним мультиплікативним оберненим до основи `R` за модулем `N`.

### 3. Теорема про коректність алгоритму редукції REDC

Нехай задано довільне ціле число `T` у діапазоні `0 ≤ T < R · N` (типово `T` є добутком двох образів Монтгомері `ā · b̄`, де кожен множник менший за `N`, тому `T < N² < R · N`).

Алгоритм `REDC(T)` виконує такі математичні кроки:

1. Обчислюється коефіцієнт обнулення:
   `m = ((T mod R) · N') mod R`
2. Обчислюється сума та ділення на основу:
   `t = (T + m · N) / R`
3. Якщо `t ≥ N`, повертається `t - N`, інакше повертається `t`.

**Теорема 2 (Коректність ділення націло та конгруентність).**
Значення `(T + m · N)` ділиться на `R` без остачі (є точним цілим числом), а результат `t = (T + m · N) / R` задовольняє модульне рівняння:

```
t ≡ T · R⁻¹ (mod N)
```

*Доведення.* Доведення складається з двох послідовних кроків: обґрунтування подільності націло на `R` та перевірки конгруентності за модулем `N`.

**Крок 1: Доведення подільності націло на R.**
Розглянемо вираз `(T + m · N)` за модулем `R`:

```
T + m · N
= T + (((T mod R) · N') mod R) · N    [підстановка визначення m]
≡ T + (T · N') · N (mod R)            [властивість взяття модуля в добутку]
= T + T · (N' · N)                    [асоціативність множення цілих чисел]
≡ T + T · (-1) (mod R)                [за тотожністю Безу N' · N ≡ -1 (mod R)]
= T - T                               [множення на -1]
≡ 0 (mod R)                           [віднімання однакових величин]
```

Оскільки остача від ділення `(T + m · N)` на `R` дорівнює нулю, число `(T + m · N)` ділиться на `R` націло. Отже, величина:

```
t = (T + m · N) / R
```

є строго цілим числом. Ділення на `R = 2ᵏ` в комп'ютерній пам'яті є абсолютно точним правим бітовим зсувом `>> k` і не втрачає жодного біта інформації.

**Крок 2: Доведення конгруентності за модулем N.**
Розглянемо вираз `t · R` за модулем `N`:

```
t · R
= ((T + m · N) / R) · R               [підстановка визначення t]
= T + m · N                           [скорочення множника R]
≡ T + m · 0 (mod N)                   [оскільки доданок m · N ділиться на N]
≡ T (mod N)                           [спрощення додавання нуля]
```

Маємо рівняння `t · R ≡ T (mod N)`. Помножимо обидві частини рівняння на модульний обернений елемент `R⁻¹`:

```
(t · R) · R⁻¹ ≡ T · R⁻¹ (mod N)
t · (R · R⁻¹) ≡ T · R⁻¹ (mod N)       [асоціативність множення]
t · 1 ≡ T · R⁻¹ (mod N)               [оскільки R · R⁻¹ ≡ 1 (mod N)]
t ≡ T · R⁻¹ (mod N)                   [нейтральний елемент множення]
```

Рівність доведено. Алгоритм `REDC(T)` дійсно множить число `T` на `R⁻¹` за модулем `N`.

### 4. Теорема про межі проміжного значення: обґрунтування t < 2N

Критично важливим для швидкодії та простоти алгоритму є доведення того, що число `t` після ділення на `R` не перевищує `2N - 1`. Це гарантує, що для отримання канонічного залишку `< N` знадобиться **не більше одного віднімання** модуля `N`.

**Теорема 3 (Строга межа редукції).**
Якщо вхідне число задовольняє нерівність `0 ≤ T < R · N`, то проміжне значення `t` строго задовольняє подвійну нерівність:

```
0 ≤ t < 2N
```

*Доведення.*
За визначенням операції взяття залишку за модулем `R`, коефіцієнт `m = ((T mod R) · N') mod R` строго обмежений діапазоном:

```
0 ≤ m ≤ R - 1
```

Оцінимо чисельник виразу `t = (T + m · N) / R`.
Оскільки за умовою теореми `T < R · N`, а для коефіцієнта `m` маємо `m < R`:

```
T + m · N
< R · N + R · N                       [заміна T на R·N та m на R за строгими нерівностями]
= 2 · R · N                           [зведення подібних доданків]
```

Поділимо обидві частини отриманої строгої нерівності на додатне число `R`:

```
t = (T + m · N) / R < (2 · R · N) / R = 2N
```

Оскільки `T ≥ 0`, `m ≥ 0` та `N > 0`, чисельник невід'ємний, звідки `t ≥ 0`. Отже, строго доведено:

```
0 ≤ t < 2N
```

Оскільки `t` — ціле число, можливі лише два взаємовиключні випадки:

1. Якщо `0 ≤ t < N`, то `t` вже є шуканим залишком `(T · R⁻¹) mod N`. Віднімання не потрібне.
2. Якщо `N ≤ t < 2N`, то віднімання `t - N` дає величину `0 ≤ t - N < N`, яка є канонічним залишком за модулем `N`.

Таким чином, алгоритм `REDC` ніколи не потребує повторного або циклічного віднімання `N`. Рівно одне порівняння та одне віднімання гарантовано зводять результат до діапазону `[0, N - 1]`.

### 5. Піднесення Гензеля для надшвидкого знаходження константи

При практичній реалізації постає питання: як швидко знайти однослівну константу `n₀' = -N₀⁻¹ mod 2ʷ` (де `w = 64` або `w = 32`) без використання повільного розширеного алгоритму Евкліда?

Для цього застосовують метод Ньютона–Рафсона у 2-адичних числах, відомий як **піднесення Гензеля** (*Hensel's Lifting*). Задача полягає у знаходженні кореня рівняння `f(x) = 1/x - N₀ = 0` за модулем степеня двійки `2ʷ`.

Ітераційна формула Ньютона має вигляд:

```
xₖ₊₁
= xₖ - f(xₖ) / f'(xₖ)                  [класична формула методу Ньютона]
= xₖ - (1/xₖ - N₀) / (-1/xₖ²)          [підстановка f(x) = 1/x - N₀ та f'(x) = -1/x²]
= xₖ + xₖ² · (1/xₖ - N₀)               [спрощення ділення на дріб зі знаком мінус]
= xₖ + xₖ - N₀ · xₖ²                   [розкриття дужок у добутку]
= xₖ · (2 - N₀ · xₖ)                   [винесення спільного множника xₖ]
```

**Теорема 4 (Квадратична збіжність піднесення Гензеля).**
Якщо `xₖ · N₀ ≡ 1 (mod 2ᵐ)`, то для наступного наближення `xₖ₊₁ = xₖ · (2 - N₀ · xₖ)` виконується конгруенція:

```
xₖ₊₁ · N₀ ≡ 1 (mod 2²ᵐ)
```

*Доведення.*
За умовою `xₖ · N₀ ≡ 1 (mod 2ᵐ)`, отже існує таке ціле `q`, що `1 - N₀ · xₖ = q · 2ᵐ`.
Розглянемо вираз `1 - N₀ · xₖ₊₁`:

```
1 - N₀ · xₖ₊₁
= 1 - N₀ · (xₖ · (2 - N₀ · xₖ))       [підстановка формули ітерації]
= 1 - 2 · N₀ · xₖ + (N₀ · xₖ)²        [розкриття дужок]
= (1 - N₀ · xₖ)²                      [виділення повного квадрата]
= (q · 2ᵐ)²                           [підстановка q · 2ᵐ]
= q² · 2²ᵐ                            [піднесення до квадрата]
≡ 0 (mod 2²ᵐ)                         [ділення націло на 2²ᵐ]
```

Оскільки `1 - N₀ · xₖ₊₁ ≡ 0 (mod 2²ᵐ)`, маємо:

```
xₖ₊₁ · N₀ ≡ 1 (mod 2²ᵐ)
```

Це доводить, що кожна ітерація **подвоює** кількість точних бітів оберненого елемента.
Оскільки число `N₀` непарне, його молодший біт дорівнює 1, тому початкове наближення `x₀ = 1` дає точність у 1 біт (`1 · N₀ ≡ 1 mod 2`).

Для 64-бітового слова (`w = 64`) потрібно лише 6 простих ітерацій:
- `x₀ = 1` (1 біт)
- `x₁ = x₀ · (2 - N₀ · x₀)` (2 біти)
- `x₂ = x₁ · (2 - N₀ · x₁)` (4 біти)
- `x₃ = x₂ · (2 - N₀ · x₂)` (8 бітів)
- `x₄ = x₃ · (2 - N₀ · x₃)` (16 бітів)
- `x₅ = x₄ · (2 - N₀ · x₄)` (32 біти)
- `x₆ = x₅ · (2 - N₀ · x₅)` (64 біти)

Фінальна константа Монтгомері обчислюється простим унарним мінусом: `n₀' = -x₆`. Весь розрахунок виконується за кілька наносекунд без жодного ділення.

### 6. Багаторозрядна редукція CIOS та її інваріанти

У криптосистемах великої розрядності модуль `N` представляють масивом із `s` слів довжиною `w` бітів кожне:

```
N = ∑_{j=0}^{s-1} Nⱼ · 2ʲʷ
```

Найефективнішим алгоритмом є метод сумісного сканування операндів (CIOS — Coarsely Integrated Operand Scanning). В алгоритмі підтримується багаторозрядний акумулятор `A` довжиною `s + 2` слів.

На кожному зовнішньому кроці `i` (від `0` до `s - 1`):

1. Обчислюється частковий добуток множення чергового слова `āᵢ` на вектор `b̄` та додається до акумулятора `A`:
   `A = A + āᵢ · b̄`
2. Обчислюється однослівний множник зведення:
   `m = (A₀ · n₀') mod 2ʷ`
3. До акумулятора додається кратне модуля:
   `A = (A + m · N) / 2ʷ`

**Інваріант циклу CIOS:**
Перед початком ітерації `i` акумулятор задовольняє співвідношення:

```
A ≡ (∑_{j=0}^{i-1} āⱼ · 2ʲʷ) · b̄ · (2ʷ)⁻ⁱ (mod N)
```

Після виконання всіх `s` ітерацій сума `∑_{j=0}^{s-1} āⱼ · 2ʲʷ` збігається з повним числом `ā`, а дільник `(2ʷ)⁻ˢ` дорівнює `R⁻¹`. Отже, кінцевий стан акумулятора становить:

```
A ≡ ā · b̄ · R⁻¹ (mod N)
```

### 7. Алгебра кривих Монтгомері та диференційне додавання точок

Петер Монтгомері показав, що принципи швидкої модульної арифметики можна поширити на алгебраїчну геометрію еліптичних кривих. Еліптична крива Монтгомері над скінченним полем задається рівнянням:

```
B · y² = x³ + A · x² + x
```

де `B · (A² - 4) ≠ 0`.

У проєктивних координатах точка представляється парою `(X : Z)`, де афінна координата відновлюється як `x = X / Z` (координата `y` взагалі не обчислюється і не зберігається, що заощаджує пам'ять і такти процесора).

**Теорема 5 (Формули диференційного додавання та подвоєння).**
Нехай відомі проєктивні координати точок `P = (X₁ : Z₁)`, `Q = (X₂ : Z₂)` та їхньої різниці `P - Q = (X_d : Z_d)`. Тоді координати суми `P + Q = (X_add : Z_add)` та подвоєння `2P = (X_dbl : Z_dbl)` обчислюються без ділення за формулами:

```
X_add = Z_d · ((X₁ - Z₁) · (X₂ + Z₂) + (X₁ + Z₁) · (X₂ - Z₂))²
Z_add = X_d · ((X₁ - Z₁) · (X₂ + Z₂) - (X₁ + Z₁) · (X₂ - Z₂))²
```

Для подвоєння точки `P = (X₁ : Z₁)` маємо формули:

```
4 · X₁ · Z₁ = (X₁ + Z₁)² - (X₁ - Z₁)²
X_dbl = (X₁ + Z₁)² · (X₁ - Z₁)²
Z_dbl = (4 · X₁ · Z₁) · ((X₁ - Z₁)² + ((A + 2) / 4) · (4 · X₁ · Z₁))
```

Усі проміжні множення та піднесення до квадрата в цих формулах виконуються через редукцію `REDC`, що забезпечує максимальну швидкість скалярного множення на сучасних кривих X25519.

### 8. Біраціональний ізоморфізм із кривими Едвардса

Крива Монтгомері `B · v² = u³ + A · u² + u` є біраціонально еквівалентною скрученій кривій Едвардса (*Twisted Edwards Curve*):

```
a · x² + y² = 1 + d · x² · y²
```

при виборі коефіцієнтів `A = 2(a + d) / (a - d)` та `B = 4 / (a - d)`.

Відображення точок здійснюється за алгебраїчними формулами:

```
u = (1 + y) / (1 - y)
v = (1 + y) / ((1 - y) · x)
```

Зворотне перетворення точок із кривої Монтгомері на криву Едвардса:

```
x = u / v
y = (u - 1) / (u + 1)
```

Цей ізоморфізм об'єднує протоколи X25519 (обмін ключами на кривій Монтгомері) та Ed25519 (цифровий підпис на кривій Едвардса): обидва алгоритми спираються на спільний арифметичний рушій `REDC` над полем `GF(2²⁵⁵ - 19)`.

### 9. Пакетне одночасне модульне обернення Монтгомері

Під час роботи з великими масивами криптографічних ключів або точок еліптичних кривих часто виникає потреба обчислити модульні обернені для `k` різних ненульових чисел `x₁, x₂, ..., xₖ mod N`.

Класичне обчислення оберненого через розширений алгоритм Евкліда є важкою операцією, яка забирає близько 200–300 тактів на одне число. Петер Монтгомері запропонував елегантний алгебраїчний прийом — **пакетне обернення** (*Montgomery's Simultaneous Inversion*), яке зводить обчислення `k` обернених величин до **одного-єдиного повного обернення** та `3(k - 1)` швидких модульних множень:

1. Обчислюються префіксні добутки:
   `p₁ = x₁`
   `p₂ = p₁ · x₂ = x₁ · x₂`
   `pᵢ = pᵢ₋₁ · xᵢ = x₁ · x₂ · ... · xᵢ`
2. Обчислюється одне спільне модульне обернене до повного добутку:
   `I = pₖ⁻¹ = (x₁ · x₂ · ... · xₖ)⁻¹ mod N`
3. Зворотним проходом обчислюються індивідуальні обернені величини для кожного числа:
   `xₖ⁻¹ = I · pₖ₋₁`
   `I = I · xₖ = (x₁ · x₂ · ... · xₖ₋₁)⁻¹`
   `xᵢ⁻¹ = I · pᵢ₋₁`

Для `k = 100` замість 100 повільних евклідових ділень виконується 1 ділення та 297 надшвидких множень Монтгомері `REDC`, що прискорює пакетну обробку криптографічних підписів у 20–30 разів.

### 10. Асимптотична складність гібриду Карацуби–Монтгомері

Для чисел екстремальної довжини (RSA-4096) множення Карацуби розбиває кожне `2n`-розрядне число на два блоки по `n` розрядів:

```
M(2n) = 3 · M(n) + O(n)
```

За основною теоремою про рекурентні співвідношення (*Master Theorem*), розв'язок цього рівняння має вигляд:

```
M(s) = O(s^{\log₂ 3}) ≈ O(s^{1.585})
```

Оскільки редукція Монтгомері після розрахунку повного 4096-бітового добутку вимагає `O(s²)` доданків зі зсувом, сукупне поєднання рекурсивного множення Карацуби та блочної редукції Монтгомері дає найвищу продуктивність серед усіх практичних алгоритмів для ключів RSA довжиною від 2048 до 8192 бітів.

### 11. Теорема Ейлера та порядок елементів у просторі Монтгомері

Розглянемо, як класичні теореми теорії чисел (мала теорема Ферма та теорема Ейлера) трансформуються у просторі Монтгомері.

У класичному кільці `ℤ/Nℤ` для будь-якого числа `a`, взаємно простого з `N`, за теоремою Ейлера маємо:

```
a^{φ(N)} ≡ 1 (mod N)
```

де `φ(N)` — функція Ейлера (кількість чисел, менших за `N` та взаємно простих із ним).

Знайдемо, чому дорівнює піднесення образу Монтгомері `ā = (a · R) mod N` до степеня `φ(N)` у просторі Монтгомері (тобто послідовне виконання `φ(N) - 1` множень `REDC`):

```
ā^{(φ(N))}
= φ(a^{φ(N)})                         [за гомоморфізмом простору Монтгомері]
= (a^{φ(N)} · R) mod N                [за визначенням образу φ]
≡ (1 · R) mod N (mod N)               [за класичною теоремою Ейлера a^{φ(N)} ≡ 1]
= R mod N                             [множення на одиницю]
```

Отримано важливий алгебраїчний результат: нейтральним елементом відносно множення Монтгомері (образом одиниці `1̄`) є залишок:

```
1̄ = φ(1) = R mod N
```

Піднесення будь-якого оборотного елемента до степеня `φ(N)` у просторі Монтгомері завжди повертає образ нейтрального елемента `R mod N`.

### 12. Безрозгалужене приведення в константному часі

Щоб усунути витік часу при фінальному умовному відніманні `t - N`, обчислюють різницю `d = t - N` та маску запозичення `mask`:

```
mask = -(t < N)
```

У двійковій системі з доповняльним кодом:
- Якщо `t < N`, умова `t < N` дорівнює `1`, і `-(1)` дає маску зі всіма одиничними бітами `0xFF...FF`.
- Якщо `t ≥ N`, умова `t < N` дорівнює `0`, і `-(0)` дає маску з нулями `0x00...00`.

Фінальний результат формується побітовим мультиплексуванням:

```
result = (t & mask) | (d & ~mask)
```

Це доводить, що модульне зведення можна реалізувати за строго константну кількість тактів без жодного умовного переходу в машинному коді.

### 13. Алгебраїчні інваріанти Драбини Монтгомері

Для піднесення елемента `A` до степеня `e` (де `e` має двійковий запис `e = (eₘ₋₁ ... e₁ e₀)₂`) драбина Монтгомері підтримує пару регістрів `(R₀, R₁)`.

Початковий стан:

```
R₀ = 1
R₁ = A
```

**Теорема 6 (Інваріант різниці драбини).**
На кожному кроці алгоритму для поточного префікса показника степеня `k` виконуються алгебраїчні співвідношення:

```
R₁ · R₀⁻¹ ≡ A (mod N)
R₀ = Aᵏ mod N
R₁ = Aᵏ⁺¹ mod N
```

*Доведення індукцією.*
База індукції: при `k = 0` маємо `R₀ = A⁰ = 1`, `R₁ = A¹ = A`. Різниця: `R₁ · R₀⁻¹ = A · 1⁻¹ = A`. База виконується.

Крок індукції: нехай на кроці `k` маємо пару `(R₀, R₁) = (Aᵏ, Aᵏ⁺¹)`.
Розглянемо черговий біт показника `b ∈ {0, 1}`:

**Випадок 1: біт b = 0.** Нове значення степеня `k' = 2k`.
За правилом драбини:
`R₁' = R₀ · R₁ = Aᵏ · Aᵏ⁺¹ = A²ᵏ⁺¹`
`R₀' = R₀ · R₀ = Aᵏ · Aᵏ = A²ᵏ`
Маємо: `R₀' = A²ᵏ = Aᵏ'`, `R₁' = A²ᵏ⁺¹ = Aᵏ'⁺¹`.

**Випадок 2: біт b = 1.** Нове значення степеня `k' = 2k + 1`.
За правилом драбини:
`R₀' = R₀ · R₁ = Aᵏ · Aᵏ⁺¹ = A²ᵏ⁺¹`
`R₁' = R₁ · R₁ = Aᵏ⁺¹ · Aᵏ⁺¹ = A²ᵏ⁺²`
Маємо: `R₀' = A²ᵏ⁺¹ = Aᵏ'`, `R₁' = A²ᵏ⁺² = Aᵏ'⁺¹`.

В обох випадках інваріант `R₁' · (R₀')⁻¹ = A` повністю зберігається. Після обробки всіх `m` бітів показника степеня `R₀` містить точне значення `Aᵉ mod N`.
