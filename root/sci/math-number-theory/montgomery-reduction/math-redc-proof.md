# 🧮 Алгебраїчне обґрунтування та доведення коректності алгоритму REDC

Модульне множення у великих полях і кільцях лишків `ℤ/Nℤ` (криптографія RSA, протоколи обміну ключами X25519 та X448, цифрові підписи Ed25519 та ECDSA) спирається на заміну важкого довгого ділення на довільний непарний модуль `N` швидкими двійковими зсувами за допоміжною основою `R = 2ᵏ > N`. Нижче наведено строгий алгебраїчний апарат редукції Монтгомері: від аксіоматики кільцевого ізоморфізму та єдиності коефіцієнта Безу до доведення стабільності границь у константному часі, захисту від timing-атак та покрокових розрахунків для 64-бітних слів.

---

### 1. Алгебраїчна структура простору Монтгомері та кільцевий ізоморфізм

Нехай `N` — фіксоване непарне натуральне число (`N > 1`), яке відіграє роль модуля обчислень, а `ℤ/Nℤ` — класичне кільце лишків за модулем `N`.

Оберемо допоміжну основу Монтгомері `R = 2ᵏ`, де натуральне число `k` обирається так, що основа строго перевищує модуль:

```
R > N
```

Оскільки число `N` непарне за умовою, а основа `R = 2ᵏ` є степенем двійки, їхній найбільший спільний дільник строго дорівнює одиниці:

```
gcd(R, N) = 1      [N непарне, R є степенем двійки]
```

**Лема 1 (Необхідність непарності модуля).** Якщо модуль `N` парний (`gcd(R, N) = d > 1`), то мультиплікативний обернений `N⁻¹ mod R` не існує, оскільки для будь-якого цілого `x` добуток `N · x` є парним і не може давати непарний залишок `-1` за основою `2ᵏ`. Таким чином, непарність модуля є строгою алгебраїчною вимогою існування константи Монтгомері. Якщо криптографічна задача вимагає обчислень за парним модулем, парну частину попередньо відокремлюють за допомогою китайської теореми про залишки.

Визначимо відображення `φ: ℤ/Nℤ → ℤ/Nℤ`, яке ставить у відповідність кожному класичному залишку `a ∈ ℤ/Nℤ` його образ Монтгомері `ā`:

```
ā = φ(a) = (a · R) mod N
```

Зворотне відображення `φ⁻¹: ℤ/Nℤ → ℤ/Nℤ` відновлює класичний залишок домноженням на модульний обернений елемент `R⁻¹ mod N`:

```
a = φ⁻¹(ā) = (ā · R⁻¹) mod N = REDC(ā)
```

**Теорема 1 (Бієктивність відображення).** Відображення `φ` є взаємно однозначною відповідністю (бієкцією) на множині `ℤ/Nℤ`.

*Доведення.* Оскільки множина `ℤ/Nℤ` є скінченною (містить рівно `N` елементів), для доведення бієктивності достатньо довести ін'єктивність: якщо `φ(a) = φ(b)`, то `a = b`.

Припустимо, що `φ(a) = φ(b)`. За означенням відображення це означає:

```
(a · R) ≡ (b · R) (mod N)
```

Віднімемо праву частину від лівої та винесемо спільний множник:

```
(a - b) · R ≡ 0 (mod N)
```

Це означає, що добуток `(a - b) · R` ділиться націло на `N`. Оскільки за умовою `gcd(R, N) = 1`, за класичною лемою Евкліда модуль `N` зобов'язаний ділити перший множник `(a - b)`:

```
a - b ≡ 0 (mod N)      [оскільки gcd(R, N) = 1]
a ≡ b (mod N)          [додавання b до обох частин]
```

Оскільки обидва елементи `a` та `b` належать канонічній множині лишків `{0, 1, ..., N - 1}`, рівність за модулем `N` означає їхню точну числову рівність `a = b`. Отже, відображення `φ` ін'єктивне, а через скінченність множини — бієктивне. Кожен залишок має єдиний образ Монтгомері, і кожен образ однозначно визначає початковий залишок.

#### Гомоморфізм операцій та аксіоми простору Монтгомері

Введемо на множині образів Монтгомері три операції:
- **Модульне додавання образів `⊕`:** `ā ⊕ b̄ = (ā + b̄) mod N`
- **Модульне віднімання образів `⊖`:** `ā ⊖ b̄ = (ā - b̄) mod N`
- **Множення Монтгомері `⋆_M`:** `ā ⋆_M b̄ = (ā · b̄ · R⁻¹) mod N = REDC(ā · b̄)`

**Теорема 2 (Кільцевий ізоморфізм).** Алгебраїчна структура `(ℤ/Nℤ, ⊕, ⋆_M)` утворює комутативне кільце з одиницею, ізоморфне класичному кільцю лишків `(ℤ/Nℤ, +, ·)`.

*Доведення.* Перевіримо виконання гомоморфізму для всіх операцій кільця:

1. **Гомоморфізм додавання:**
```
φ(a) ⊕ φ(b)
= ((a · R) mod N + (b · R) mod N) mod N    [підстановка визначення φ]
= ((a · R) + (b · R)) mod N                [властивість додавання лишків]
= ((a + b) · R) mod N                      [винесення спільного множника R]
= φ(a + b)                                 [за визначенням образу суми]
```

2. **Гомоморфізм віднімання:**
```
φ(a) ⊖ φ(b)
= ((a · R) - (b · R)) mod N                [визначення операції ⊖]
= ((a - b) · R) mod N                      [винесення спільного множника R]
= φ(a - b)                                 [за визначенням образу різниці]
```

3. **Гомоморфізм множення:**
```
φ(a) ⋆_M φ(b)
= (φ(a) · φ(b) · R⁻¹) mod N                [визначення множення Монтгомері ⋆_M]
= ((a · R) · (b · R) · R⁻¹) mod N          [підстановка образів φ(a) та φ(b)]
= (a · b · R · (R · R⁻¹)) mod N            [асоціативність та перегрупування множників]
= (a · b · R · 1) mod N                    [за визначенням оберненого R · R⁻¹ ≡ 1 mod N]
= ((a · b) · R) mod N                      [нейтральний елемент множення]
= φ(a · b)                                 [за визначенням образу добутку]
```

4. **Нейтральний елемент щодо множення:**
Образом класичної одиниці `1 ∈ ℤ/Nℤ` є величина:
```
1̄ = φ(1) = (1 · R) mod N = R mod N
```
Перевіримо нейтральність `1̄` відносно множення Монтгомері для довільного образу `ā`:
```
ā ⋆_M 1̄
= (ā · 1̄ · R⁻¹) mod N                      [визначення множення ⋆_M]
= (ā · (R mod N) · R⁻¹) mod N              [підстановка 1̄ = R mod N]
= (ā · (R · R⁻¹)) mod N                    [асоціативність множення]
= (ā · 1) mod N                            [оскільки R · R⁻¹ ≡ 1 mod N]
= ā mod N = ā                              [нейтральність одиниці]
```

5. **Асоціативність множення Монтгомері:**
Для будь-яких трьох образів `ā, b̄, c̄`:
```
(ā ⋆_M b̄) ⋆_M c̄
= (((ā · b̄ · R⁻¹) mod N) · c̄ · R⁻¹) mod N  [послідовне застосування ⋆_M]
= (ā · b̄ · c̄ · (R⁻¹)²) mod N               [асоціативність множення цілих чисел]
= ā ⋆_M (b̄ ⋆_M c̄)                          [симетричне розкриття правої частини]
```

6. **Дистрибутивність множення відносно додавання:**
```
ā ⋆_M (b̄ ⊕ c̄)
= (ā · ((b̄ + c̄) mod N) · R⁻¹) mod N        [визначення операцій ⊕ та ⋆_M]
= (ā · (b̄ + c̄) · R⁻¹) mod N                [дистрибутивність у кільці цілих чисел]
= ((ā · b̄ · R⁻¹) + (ā · c̄ · R⁻¹)) mod N    [розкриття дужок]
= (ā ⋆_M b̄) ⊕ (ā ⋆_M c̄)                    [за визначенням операцій]
```

7. **Мультиплікативний обернений елемент:**
Якщо `gcd(a, N) = 1`, то в класичному кільці існує `a⁻¹ mod N`. Його образом у просторі Монтгомері є `(a⁻¹)̄ = (a⁻¹ · R) mod N`. Тоді:
```
ā ⋆_M (a⁻¹)̄
= ((a · R) · (a⁻¹ · R) · R⁻¹) mod N        [підстановка визначень]
= (a · a⁻¹ · R · (R · R⁻¹)) mod N          [перегрупування множників]
= (1 · R · 1) mod N                        [підстановка a · a⁻¹ ≡ 1 та R · R⁻¹ ≡ 1]
= R mod N = 1̄                              [отримано нейтральний елемент простору]
```

Оскільки відображення `φ` бієктивне та узгоджене з усіма кільцевими операціями, структура `(ℤ/Nℤ, ⊕, ⋆_M)` утворює повноцінне ізоморфне кільце.

### 2. Співвідношення Безу та константи Монтгомері

Оскільки основа `R` та модуль `N` взаємно прості (`gcd(R, N) = 1`), за розширеною теоремою Безу існують такі цілі числа `R⁻¹` та `N'`, що виконується тотожність:

```
R · R⁻¹ - N · N' = 1
```

Перепишемо це алгебраїчне рівняння окремо за модулем `R` та за модулем `N`.

**Розгляд за модулем R:**

```
R · R⁻¹ - N · N' ≡ 1 (mod R)
0 - N · N' ≡ 1 (mod R)         [оскільки R · R⁻¹ ділиться на R націло]
-N · N' ≡ 1 (mod R)            [спрощення лівої частини]
N · N' ≡ -1 (mod R)            [множення обох частин на -1]
N' ≡ -N⁻¹ (mod R)              [визначення константи Монтгомері]
```

Таким чином, константа `N'` є від'ємним оберненим елементом до модуля `N` у кільці лишків за основою `R`. Її завжди можна привести до канонічного діапазону `N' ∈ [0, R - 1]`.

**Розгляд за модулем N:**

```
R · R⁻¹ - N · N' ≡ 1 (mod N)
R · R⁻¹ - 0 ≡ 1 (mod N)         [оскільки N · N' ділиться на N націло]
R · R⁻¹ ≡ 1 (mod N)             [визначення модульного оберненого до R]
```

Отже, ціле число `R⁻¹` є канонічним мультиплікативним оберненим до основи `R` за модулем `N` у діапазоні `R⁻¹ ∈ [0, N - 1]`.

### 3. Теорема про коректність алгоритму редукції REDC

Нехай задано довільне ціле число `T` у діапазоні `0 ≤ T < R · N` (типово `T` є добутком двох образів Монтгомері `ā · b̄`, де кожен множник менший за `N`, тому `T < N² < R · N`).

Алгоритм `REDC(T)` виконує такі математичні кроки:

1. Обчислюється коефіцієнт обнулення молодших розрядів:
   `m = ((T mod R) · N') mod R`
2. Обчислюється сума та ділення на основу:
   `t = (T + m · N) / R`
3. Якщо `t ≥ N`, повертається `t - N`, інакше повертається `t`.

**Лема 2 (Єдиність та коректність коефіцієнта обнулення).**
Для будь-якого цілого `T` існує єдине ціле число `m ∈ [0, R - 1]`, для якого сума `T + m · N` ділиться на `R` націло:

```
T + m · N ≡ 0 (mod R)
```

*Доведення.*
Перевіримо існування розв'язку підстановкою `m = ((T mod R) · N') mod R`:
```
T + m · N
≡ T + (T · N') · N (mod R)            [заміна m на T · N' mod R]
= T + T · (N · N')                    [асоціативність множення]
≡ T + T · (-1) (mod R)                [за тотожністю Безу N · N' ≡ -1 mod R]
= T - T                               [множення на -1]
≡ 0 (mod R)                           [віднімання рівних величин]
```

Доведемо єдиність `m`. Нехай існують два коефіцієнти `m₁, m₂ ∈ [0, R - 1]`, для яких виконується подільність:
```
T + m₁ · N ≡ 0 (mod R)
T + m₂ · N ≡ 0 (mod R)
```
Віднімемо друге рівняння від першого:
```
(m₁ - m₂) · N ≡ 0 (mod R)
```
Це означає, що основа `R` ділить добуток `(m₁ - m₂) · N`. Оскільки `gcd(R, N) = 1`, за лемою Евкліда основа `R` зобов'язана ділити різницю `(m₁ - m₂)`.
Оскільки `0 ≤ m₁ ≤ R - 1` та `0 ≤ m₂ ≤ R - 1`, їхня різниця обмежена діапазоном:
```
-(R - 1) ≤ m₁ - m₂ ≤ R - 1
```
Єдиним цілим числом у цьому інтервалі, яке ділиться на `R`, є `0`. Отже, `m₁ - m₂ = 0`, звідки `m₁ = m₂`. Коефіцієнт обнулення `m` визначений абсолютно однозначно.

**Теорема 3 (Коректність ділення націло та конгруентність).**
Значення `(T + m · N)` ділиться на `R` без остачі (є точним цілим числом), а результат `t = (T + m · N) / R` задовольняє модульне рівняння:

```
t ≡ T · R⁻¹ (mod N)
```

*Доведення.*
Доведення складається з двох послідовних кроків: обґрунтування подільності націло на `R` та перевірки конгруентності за модулем `N`.

**Крок 1: Доведення подільності націло на R.**
За Лемою 2 залишок від ділення `(T + m · N)` на `R` дорівнює нулю:
```
(T + m · N) mod R = 0
```
Отже, величина `t = (T + m · N) / R` є строго цілим числом. У двійковій системі числення з основою `R = 2ᵏ` додавання `m · N` обнуляє рівно молодші `k` бітів числа `T`, після чого ділення на `2ᵏ` є звичайним апаратним зсувом праворуч на `k` розрядів (`>> k`), який не втрачає жодного біта інформації.

**Крок 2: Доведення конгруентності за модулем N.**
Розглянемо вираз `t · R` за модулем `N`:

```
t · R
= ((T + m · N) / R) · R               [підстановка визначення t]
= T + m · N                           [скорочення множника R]
≡ T + m · 0 (mod N)                   [оскільки доданок m · N ділиться на N]
≡ T (mod N)                           [додавання нуля]
```

Маємо рівняння `t · R ≡ T (mod N)`. Помножимо обидві частини рівняння на модульний обернений елемент `R⁻¹`:

```
(t · R) · R⁻¹ ≡ T · R⁻¹ (mod N)
t · (R · R⁻¹) ≡ T · R⁻¹ (mod N)       [асоціативність множення]
t · 1 ≡ T · R⁻¹ (mod N)               [оскільки R · R⁻¹ ≡ 1 (mod N)]
t ≡ T · R⁻¹ (mod N)                   [нейтральний елемент множення]
```

Рівність доведено. Алгоритм `REDC(T)` дійсно множить вхідне число `T` на `R⁻¹` за модулем `N`.

#### Алгебраїчна композиція перетворень
З теореми випливає універсальність рушія `REDC`:
1. **Модульне множення образів:** якщо `T = ā · b̄ = (a · R) · (b · R) = a · b · R²`, то:
   `REDC(ā · b̄) ≡ (a · b · R² · R⁻¹) ≡ (a · b · R) ≡ (a · b)̄ (mod N)`.
2. **Переведення в простір Монтгомері:** якщо заздалегідь обчислити константу `R² mod N`, то для класичного числа `a` маємо `T = a · (R² mod N)`. Тоді:
   `REDC(a · (R² mod N)) ≡ (a · R² · R⁻¹) ≡ (a · R) ≡ ā (mod N)`.
3. **Зворотне переведення у звичайний вигляд:** для образу `ā` виклик `REDC(ā)` дає:
   `REDC(ā) ≡ (ā · R⁻¹) ≡ (a · R · R⁻¹) ≡ a (mod N)`.

### 4. Теорема про межі проміжного значення: обґрунтування t < 2N

Критично важливим для алгоритму є доведення того, що число `t` після ділення на `R` не перевищує `2N - 1`. Це гарантує, що для отримання канонічного залишку `< N` знадобиться **не більше одного віднімання** модуля `N`.

**Теорема 4 (Строга межа редукції).**
Якщо вхідне число задовольняє нерівність `0 ≤ T < R · N`, то проміжне значення `t = (T + m · N) / R` строго задовольняє подвійну нерівність:

```
0 ≤ t < 2N
```

*Доведення.*
Оцінимо максимальні можливі значення доданків у чисельнику виразу `t = (T + m · N) / R`:
- За умовою теореми `T` є цілим числом і `0 ≤ T ≤ R · N - 1`.
- За визначенням операції взяття залишку за модулем `R`, коефіцієнт `m = ((T mod R) · N') mod R` задовольняє строгу нерівність `0 ≤ m ≤ R - 1`.

Знайдемо верхню оцінку суми `T + m · N`:

```
T + m · N
≤ (R · N - 1) + (R - 1) · N           [підстановка максимальних значень T та m]
= R · N - 1 + R · N - N               [розкриття дужок у добутку (R - 1) · N]
= 2 · R · N - N - 1                   [зведення подібних доданків]
= 2 · R · N - (N + 1)                 [винесення мінуса за дужки]
```

Оскільки модуль `N ≥ 1`, величина `(N + 1) ≥ 2 > 0`. Отже:

```
T + m · N ≤ 2 · R · N - (N + 1) < 2 · R · N
```

Поділимо отриману нерівність на додатне число `R`:

```
t = (T + m · N) / R ≤ (2 · R · N - (N + 1)) / R = 2N - (N + 1) / R
```

Оскільки `R > N ≥ 1`, дріб `(N + 1) / R > 0`. Оскільки `t` є цілим числом, а величина `(N + 1) / R` додатна, значення `t` строго менше за `2N`:

```
t ≤ 2N - 1 < 2N
```

Оцінимо нижню межу: оскільки `T ≥ 0`, `m ≥ 0`, `N > 0` та `R > 0`, маємо `T + m · N ≥ 0`, звідки `t ≥ 0`.

Отже, строго доведено:

```
0 ≤ t < 2N
```

Оскільки `t` є цілим числом, проміжок `[0, 2N - 1]` розпадається на два взаємовиключні випадки:
1. Якщо `0 ≤ t < N`, то `t` вже є канонічним залишком `(T · R⁻¹) mod N`. Фінальне віднімання не потрібне (виконується `0` віднімань).
2. Якщо `N ≤ t < 2N`, то віднімання `t - N` дає величину `0 ≤ t - N < N`, яка є шуканим залишком за модулем `N` (виконується рівно `1` віднімання).

Таким чином, алгоритм `REDC` ніколи не потребує циклічного віднімання `N` (жодних циклів `while (t >= N)`). Одне умовне віднімання гарантовано зводить результат до канонічного діапазону.

### 5. Редукція в константному часі та надлишкове представлення без умовного віднімання

У класичній реалізації алгоритму `REDC` наявна перевірка:

```
if (t >= N) t = t - N;
```

Ця інструкція створює **умовне розгалуження, що залежить від секретних даних**. 

#### Анатомія атак за часом виконання (Timing Attacks)
У 2000 році Колін Шіндлер показав, що частота виконання фінального умовного віднімання в алгоритмі Монтгомері безпосередньо залежить від проміжних числових значень. Якщо під час піднесення до степеня `Aᵉ mod N` черговий біт таємного ключа `e` дорівнює одиниці, процесор виконує додаткове множення, що змінює розподіл імовірності виникнення події `t ≥ N`. 

У 2003 році Девід Брамлі та Ден Боне здійснили практичну атаку на сервер OpenSSL через мережу, вимірюючи затримки обробки запитів RSA-CRT. Різниця в кілька десятків процесорних тактів між випадками `t < N` та `t ≥ N` дозволила повністю відновити закритий ключ факторизації `p` та `q` за кілька годин віддалених вимірювань.

У сучасній криптографії застосовують два підходи до повного усунення цього витоку.

#### Підхід 1: Безрозгалужене умовне віднімання (Branchless Conditional Subtraction)
Різниця `d = t - N` та бітова маска запозичення обчислюються завжди, а вибір виконується побітовими операціями за фіксовану кількість тактів (детально виведено в Розділі 14).

#### Підхід 2: Надлишкове представлення без умовного віднімання (Relaxed Montgomery Reduction)
Найбільш прогресивний метод, закріплений у сучасних криптографічних стандартах RFC 7748 (Curve25519 / X25519), Ed448 та високошвидкісних реалізаціях RSA-CRT (Gueron, Bosselaers), полягає у **повній відмові від умовного віднімання всередині ітераційних циклів**.

Ідея полягає в тому, щоб дозволити проміжним результатам перебувати в розширеному «надлишковому» діапазоні `[0, 2N - 1]` (або `[0, R - 1]`) протягом усіх сотень ітерацій піднесення до степеня чи скалярного множення на еліптичній кривій, виконуючи єдине фінальне зведення за модулем `N` лише перед поверненням результату назовні.

**Теорема 5 (Стабільність надлишкового діапазону Монтгомері).**
Нехай основа Монтгомері задовольняє умову `R > 4N`. Якщо вхідні операнди `ā, b̄` належать надлишковому інтервалу:

```
0 ≤ ā < 2N
0 ≤ b̄ < 2N
```

то результат редукції добутку без фінального віднімання `t = (ā · b̄ + m · N) / R` гарантовано повертається в той самий надлишковий інтервал:

```
0 ≤ t < 2N
```

*Доведення.*
Оскільки `ā < 2N` та `b̄ < 2N`, добуток операндів задовольняє нерівність:
```
T = ā · b̄ < (2N) · (2N) = 4N²
```
Коефіцієнт `m = ((T mod R) · N') mod R` за визначенням задовольняє нерівність `m ≤ R - 1 < R`.
Оцінимо значення чисельника виразу редукції `t`:
```
T + m · N
< 4N² + R · N                         [підстановка T < 4N² та m < R]
```
Поділимо обидві частини строгої нерівності на основу `R`:
```
t = (T + m · N) / R < (4N² + R · N) / R = (4N² / R) + N
```
Оскільки за умовою теореми `R > 4N`, поділимо обидві частини нерівності `4N < R` на `R` та помножимо на додатне число `N`:
```
4N / R < 1
(4N / R) · N < 1 · N
4N² / R < N
```
Підставимо оцінку `4N² / R < N` у вираз для `t`:
```
t < (4N² / R) + N < N + N = 2N
```
Оскільки `T ≥ 0` та `m · N ≥ 0`, маємо `t ≥ 0`. Отже:
```
0 ≤ t < 2N
```

**Наслідок.** При виборі основи `R > 4N` надлишковий діапазон `[0, 2N - 1]` є замкненим інваріантом редукції Монтгомері. 

Усі 255 ітерацій скалярного множення на кривій Curve25519 (де `p = 2²⁵⁵ - 19`, а основа `R = 2²⁵⁶ > 4p`) виконуються без жодного порівняння та без жодного віднімання модуля. Це забезпечує абсолютну стійкість до часових атак на рівні самої алгебраїчної моделі.

### 6. Покрокові числові приклади та перевірка алгоритму

Щоб у деталях побачити роботу формул та механізму обнулення розрядів, розглянемо два повні розрахунки: числовий приклад за малим модулем та машинний блок для 64-бітних регістрів.

#### 6.1. Малий розібраний приклад: N = 79, R = 128

Нехай модуль обчислень `N = 79` (непарне просте число).
Оберемо основу Монтгомері `R = 2⁷ = 128`. Перевіримо базові умови:
- `R > N` (`128 > 79`) — виконується;
- `gcd(128, 79) = 1` — числа взаємно прості.

**Крок 1: Знаходження констант Безу.**
Застосуємо розширений алгоритм Евкліда для пари `(R, N) = (128, 79)`:

```
128 = 1 · 79 + 49
 79 = 1 · 49 + 30
 49 = 1 · 30 + 19
 30 = 1 · 19 + 11
 19 = 1 · 11 + 8
 11 = 1 · 8 + 3
  8 = 2 · 3 + 2
  3 = 1 · 2 + 1
```

Виконуючи зворотну підстановку, отримуємо лінійне представлення одиниці:

```
128 · 50 - 79 · 81 = 6400 - 6399 = 1
```

Звідси маємо точні константи:
- `R⁻¹ = 50 mod 79` (перевірка: `(128 · 50) mod 79 = 6400 mod 79 = 1`);
- `N' = 81 mod 128` (перевірка: `(79 · 81) mod 128 = 6399 mod 128 = 127 ≡ -1 mod 128`).

**Крок 2: Множення двох чисел у просторі Монтгомері.**
Нехай потрібно перемножити числа `a = 43` та `b = 57` за модулем `79`.
У класичній арифметиці: `(43 · 57) mod 79 = 2451 mod 79 = 2` (оскільки `2451 = 31 · 79 + 2`).

Переведемо операнди у простір Монтгомері:
- `ā = (a · R) mod N = (43 · 128) mod 79 = 5504 mod 79 = 53`
- `b̄ = (b · R) mod N = (57 · 128) mod 79 = 7296 mod 79 = 28`

Обчислимо прямий добуток образів:
```
T = ā · b̄ = 53 · 28 = 1484
```
Перевіримо умову теореми: `T = 1484 < R · N = 128 · 79 = 10112` (виконується).

Виконаємо редукцію `REDC(T)`:
1. Знаходимо коефіцієнт обнулення `m`:
```
T mod R = 1484 mod 128 = 76
m = ((T mod R) · N') mod R = (76 · 81) mod 128 = 6156 mod 128 = 12
```
2. Обчислюємо суму `T + m · N`:
```
T + m · N = 1484 + 12 · 79 = 1484 + 948 = 2432
```
Поглянемо на двійковий запис чисел:
- `T = 1484 = 10111001100₂`
- `m · N = 948 = 01110110100₂`
- `Сума = 2432 = 100110000000₂`
Молодші 7 бітів суми дорівнюють строго `0000000₂`.

3. Виконуємо точне ділення на `R = 128`:
```
t = 2432 / 128 = 19
```
Оскільки `t = 19 < N = 79`, результат дорівнює `c̄ = 19`.

Перевіримо результат: образ класичної відповіді `c = 2` у просторі Монтгомері дорівнює:
```
c̄ = (2 · 128) mod 79 = 256 mod 79 = 19
```
Отримано точний збіг.

**Крок 3: Зворотне переведення у класичний простір.**
Застосуємо `REDC` до отриманого образу `c̄ = 19`:
1. `T_back = 19`
2. `m_back = ((19 mod 128) · 81) mod 128 = (19 · 81) mod 128 = 1539 mod 128 = 3` (оскільки `1539 = 12 · 128 + 3`)
3. `T_back + m_back · N = 19 + 3 · 79 = 19 + 237 = 256`
4. `t_back = 256 / 128 = 2`

Оскільки `2 < 79`, маємо канонічний результат `2`, що ідеально відповідає вихідному добутку `(43 · 57) mod 79`.

#### 6.2. Багатопрецизійний блок 64-бітних машинних слів

У 64-бітних криптосистемах розмір машинного слова становить `w = 64` біти, а основа одного розряду `r = 2⁶⁴`.
Розглянемо молодше слово модуля кривої Curve25519: `N₀ = 2⁶⁴ - 19 = 0xFFFFFFFFFFFFFFED`.

Знайдемо однослівну константу `n₀' = -N₀⁻¹ mod 2⁶⁴` за допомогою методу піднесення Гензеля (ітерації Ньютона–Рафсона у 2-адичних числах):

```
Початкове наближення (1 біт):
x₀ = 1

Ітерація 1 (2 біти):
x₁ = x₀ · (2 - N₀ · x₀) mod 2⁶⁴ = 0x0000000000000015

Ітерація 2 (4 біти):
x₂ = x₁ · (2 - N₀ · x₁) mod 2⁶⁴ = 0x00000000000020E5

Ітерація 3 (8 бітів):
x₃ = x₂ · (2 - N₀ · x₂) mod 2⁶⁴ = 0x00000000504F35E5

Ітерація 4 (16 бітів):
x₄ = x₃ · (2 - N₀ · x₃) mod 2⁶⁴ = 0xDEAE71ABD79435E5

Ітерація 5 (32 біти):
x₅ = x₄ · (2 - N₀ · x₄) mod 2⁶⁴ = 0x79435E50D79435E5

Ітерація 6 (64 біти):
x₆ = x₅ · (2 - N₀ · x₅) mod 2⁶⁴ = 0x79435E50D79435E5

Константа Монтгомері n₀' = -x₆ mod 2⁶⁴:
n₀' = 0x86BCA1AF286BCA1B
```

Перевіримо коректність знайденої константи:
```
(N₀ · n₀') mod 2⁶⁴
= (0xFFFFFFFFFFFFFFED · 0x86BCA1AF286BCA1B) mod 2⁶⁴    [підстановка числових значень]
= 0xFFFFFFFFFFFFFFFF ≡ -1 (mod 2⁶⁴)                   [обчислення добутку за модулем 2⁶⁴]
```

Коли на черговому кроці алгоритму багаторозрядної редукції CIOS поточне молодше 64-бітне слово акумулятора дорівнює `A₀`, обчислюється множник зведення:
```
m = (A₀ · n₀') mod 2⁶⁴
```
Додавання добутку `m · N₀` до слова `A₀` дає:
```
(A₀ + m · N₀) mod 2⁶⁴
≡ A₀ + (A₀ · n₀') · N₀ (mod 2⁶⁴)    [підстановка m = (A₀ · n₀') mod 2⁶⁴]
= A₀ + A₀ · (n₀' · N₀)              [асоціативність множення слів]
≡ A₀ + A₀ · (-1) (mod 2⁶⁴)          [оскільки n₀' · N₀ ≡ -1 mod 2⁶⁴]
= 0 (mod 2⁶⁴)                       [віднімання рівних величин A₀ - A₀ = 0]
```
Молодше 64-бітне слово акумулятора гарантовано обнуляється, а зсув `A >> 64` у машинному коді є простим зсувом покажчиків слів у масиві без виконання жодної інструкції ділення.

### 7. Піднесення Гензеля для надшвидкого знаходження константи

При практичній реалізації постає питання: як швидко знайти однослівну константу `n₀' = -N₀⁻¹ mod 2ʷ` (де `w = 64` або `w = 32`) без використання повільного розширеного алгоритму Евкліда?

Для цього застосовують метод Ньютона–Рафсона у 2-адичних числах, відомий як **піднесення Гензеля** (*Hensel's Lifting*). Задача полягає у знаходженні кореня рівняння `f(x) = 1/x - N₀ = 0` за модулем степеня двійки `2ʷ`.

Ітераційна формула Ньютона має вигляд:

```
xₖ₊₁
= xₖ - f(xₖ) / f'(xₖ)                  [класична формула методу Ньютона]
= xₖ - (1/xₖ - N₀) / (-1/xₖ²)          [підстановка f(x) = 1/x - N₀ та f'(x) = -1/x²]
= xₖ + xₖ² · (1/xₖ - N₀)               [спрощення ділення на дріб зі знаком мінус]
= xₖ + xₖ - N₀ · xₖ²                   [розкриття дужок у добутку]
= xₖ · (2 - N₀ · xₖ)                   [винесення спільного множника xₖ]
```

**Теорема 6 (Квадратична збіжність піднесення Гензеля).**
Якщо `xₖ · N₀ ≡ 1 (mod 2ᵐ)`, то для наступного наближення `xₖ₊₁ = xₖ · (2 - N₀ · xₖ)` виконується конгруенція:

```
xₖ₊₁ · N₀ ≡ 1 (mod 2²ᵐ)
```

*Доведення.*
За умовою `xₖ · N₀ ≡ 1 (mod 2ᵐ)`, отже існує таке ціле `q`, що `1 - N₀ · xₖ = q · 2ᵐ`.
Розглянемо вираз `1 - N₀ · xₖ₊₁`:

```
1 - N₀ · xₖ₊₁
= 1 - N₀ · (xₖ · (2 - N₀ · xₖ))       [підстановка формули ітерації]
= 1 - 2 · N₀ · xₖ + (N₀ · xₖ)²        [розкриття дужок]
= (1 - N₀ · xₖ)²                      [виділення повного квадрата]
= (q · 2ᵐ)²                           [підстановка q · 2ᵐ]
= q² · 2²ᵐ                            [піднесення до квадрата]
≡ 0 (mod 2²ᵐ)                         [ділення націло на 2²ᵐ]
```

Оскільки `1 - N₀ · xₖ₊₁ ≡ 0 (mod 2²ᵐ)`, маємо:

```
xₖ₊₁ · N₀ ≡ 1 (mod 2²ᵐ)
```

Це доводить, що кожна ітерація **подвоює** кількість точних бітів оберненого елемента.
Оскільки число `N₀` непарне, його молодший біт дорівнює 1, тому початкове наближення `x₀ = 1` дає точність у 1 біт (`1 · N₀ ≡ 1 mod 2`).

Для 64-бітового слова (`w = 64`) потрібно лише 6 простих ітерацій:
- `x₀ = 1` (1 біт)
- `x₁ = x₀ · (2 - N₀ · x₀)` (2 біти)
- `x₂ = x₁ · (2 - N₀ · x₁) mod 2⁶⁴` (4 біти)
- `x₃ = x₂ · (2 - N₀ · x₂)` (8 бітів)
- `x₄ = x₃ · (2 - N₀ · x₃)` (16 бітів)
- `x₅ = x₄ · (2 - N₀ · x₄)` (32 біти)
- `x₆ = x₅ · (2 - N₀ · x₅)` (64 біти)

Фінальна константа Монтгомері обчислюється простим унарним мінусом: `n₀' = -x₆`. Весь розрахунок виконується за кілька наносекунд без жодного ділення.

### 8. Багаторозрядна редукція CIOS та її інваріанти

У криптосистемах великої розрядності модуль `N` представляють масивом із `s` слів довжиною `w` бітів кожне:

```
N = ∑_{j=0}^{s-1} Nⱼ · 2ʲʷ
```

Найефективнішим алгоритмом є метод сумісного сканування операндів (CIOS — *Coarsely Integrated Operand Scanning*). В алгоритмі підтримується багаторозрядний акумулятор `A` довжиною `s + 2` слів.

На кожному зовнішньому кроці `i` (від `0` до `s - 1`):

1. Обчислюється частковий добуток множення чергового слова `āᵢ` на вектор `b̄` та додається до акумулятора `A`:
   `A = A + āᵢ · b̄`
2. Обчислюється однослівний множник зведення:
   `m = (A₀ · n₀') mod 2ʷ`
3. До акумулятора додається кратне модуля:
   `A = (A + m · N) / 2ʷ`

**Інваріант циклу CIOS:**
Перед початком ітерації `i` акумулятор задовольняє співвідношення:

```
A ≡ (∑_{j=0}^{i-1} āⱼ · 2ʲʷ) · b̄ · (2ʷ)⁻ⁱ (mod N)
```

*Доведення інваріанта за математичною індукцією.*

**База індукції (i = 0):** Перед першою ітерацією акумулятор ініціалізовано нулями: `A = 0`. Сума `∑_{j=0}^{-1}` є порожньою і дорівнює 0. Рівність `0 ≡ 0 (mod N)` виконується тривіально.

**Індукційний перехід:** Припустимо, що інваріант виконується перед початком ітерації `i`:
```
A_cur ≡ (∑_{j=0}^{i-1} āⱼ · 2ʲʷ) · b̄ · (2ʷ)⁻ⁱ (mod N)
```

На ітерації `i` виконуються такі послідовні дії:
1. Додається добуток слова `āᵢ` на вектор `b̄`:
```
A₁ = A_cur + āᵢ · b̄
```
2. Обчислюється `m = (A₁[0] · n₀') mod 2ʷ` та додається кратне `m · N`:
```
A₂ = A₁ + m · N
```
Оскільки `m · N ≡ 0 (mod N)`, маємо:
```
A₂ ≡ A₁ ≡ A_cur + āᵢ · b̄ (mod N)
```
3. Виконується зсув акумулятора праворуч на одне машинне слово (ділення на `2ʷ`):
```
A_next = A₂ / 2ʷ
```
Оскільки молодше слово `A₂[0]` обнулено додаванням `m · N`, це ділення є точним у кільці цілих чисел. Помноживши обидві частини на `2ʷ`, отримуємо:
```
A_next · 2ʷ = A₂ ≡ A_cur + āᵢ · b̄ (mod N)
```
Помножимо обидві частини модульного рівняння на обернений елемент `(2ʷ)⁻¹ mod N`:
```
A_next ≡ (A_cur + āᵢ · b̄) · (2ʷ)⁻¹ (mod N)
```
Підставимо індукційне припущення для `A_cur`:
```
A_next
≡ ((∑_{j=0}^{i-1} āⱼ · 2ʲʷ) · b̄ · (2ʷ)⁻ⁱ + āᵢ · b̄) · (2ʷ)⁻¹ (mod N)
= ((∑_{j=0}^{i-1} āⱼ · 2ʲʷ) · (2ʷ)⁻ⁱ + āᵢ) · b̄ · (2ʷ)⁻¹
= ((∑_{j=0}^{i-1} āⱼ · 2ʲʷ + āᵢ · 2ⁱʷ) · (2ʷ)⁻ⁱ) · b̄ · (2ʷ)⁻¹
= (∑_{j=0}^{i} āⱼ · 2ʲʷ) · b̄ · (2ʷ)⁻⁽ⁱ⁺¹⁾ (mod N)
```
Отримано точний вираз інваріанта для наступного кроку `i + 1`. Індукційний перехід доведено.

Після виконання всіх `s` ітерацій сума `∑_{j=0}^{s-1} āⱼ · 2ʲʷ` збігається з повним числом `ā`, а дільник `(2ʷ)⁻ˢ` дорівнює `R⁻¹`. Отже, кінцевий стан акумулятора становить:

```
A ≡ ā · b̄ · R⁻¹ (mod N)
```

**Теорема про межу переносу в CIOS (Carry bound ≤ 2).**
На кожному внутрішньому кроці додавання стовпчика акумулятора до суми додаються поточне слово акумулятора `A[j] < 2ʷ`, добуток слів `āᵢ · b[j] ≤ (2ʷ - 1)²` та добуток зведення `m · N[j] ≤ (2ʷ - 1)²`, а також вхідний біт переносу `c_in`. Тоді максимальна сума стовпчика:
```
S_col = A[j] + āᵢ · b[j] + m · N[j] + c_in
≤ (2ʷ - 1) + 2 · (2ʷ - 1)² + c_in
= (2ʷ - 1) + 2 · (2²ʷ - 2 · 2ʷ + 1) + c_in
= 2 · 2²ʷ - 3 · 2ʷ + 1 + c_in
```
Якщо припустити за індукцією, що `c_in ≤ 2`, то `S_col < 2 · 2²ʷ`. Отже, нове перенесення `c_out = ⌊S_col / 2ʷ⌋ ≤ 2 · 2ʷ - 3 < 2 · 2ʷ`, а старше слово переносу у наступний розряд не перевищує константи `2`. Це гарантує, що розрядність додаткового переповнення акумулятора ніколи не перевищує двох слів (`s + 2` слів достатньо для довільної кількості кінцевих слів `s`).

### 9. Алгебра кривих Монтгомері та диференційне додавання точок

Петер Монтгомері показав, що принципи швидкої модульної арифметики можна поширити на алгебраїчну геометрію еліптичних кривих. Еліптична крива Монтгомері над скінченним полем задається рівнянням:

```
B · y² = x³ + A · x² + x
```

де `B · (A² - 4) ≠ 0`.

У проєктивних координатах точка представляється парою `(X : Z)`, де афінна координата відновлюється як `x = X / Z` (координата `y` взагалі не обчислюється і не зберігається, що заощаджує пам'ять і такти процесора).

**Теорема 7 (Формули диференційного додавання та подвоєння).**
Нехай відомі проєктивні координати точок `P = (X₁ : Z₁)`, `Q = (X₂ : Z₂)` та їхньої різниці `P - Q = (X_d : Z_d)`. Тоді координати суми `P + Q = (X_add : Z_add)` та подвоєння `2P = (X_dbl : Z_dbl)` обчислюються без ділення за формулами:

```
X_add = Z_d · ((X₁ - Z₁) · (X₂ + Z₂) + (X₁ + Z₁) · (X₂ - Z₂))²
Z_add = X_d · ((X₁ - Z₁) · (X₂ + Z₂) - (X₁ + Z₁) · (X₂ - Z₂))²
```

Для подвоєння точки `P = (X₁ : Z₁)` маємо формули:

```
4 · X₁ · Z₁ = (X₁ + Z₁)² - (X₁ - Z₁)²
X_dbl = (X₁ + Z₁)² · (X₁ - Z₁)²
Z_dbl = (4 · X₁ · Z₁) · ((X₁ - Z₁)² + ((A + 2) / 4) · (4 · X₁ · Z₁))
```

Усі проміжні множення та піднесення до квадрата в цих формулах виконуються через редукцію `REDC`, що забезпечує максимальну швидкість скалярного множення на сучасних кривих X25519.

### 10. Біраціональний ізоморфізм із кривими Едвардса

Крива Монтгомері `B · v² = u³ + A · u² + u` є біраціонально еквівалентною скрученій кривій Едвардса (*Twisted Edwards Curve*):

```
a · x² + y² = 1 + d · x² · y²
```

при виборі коефіцієнтів `A = 2(a + d) / (a - d)` та `B = 4 / (a - d)`.

Відображення точок здійснюється за алгебраїчними формулами:

```
u = (1 + y) / (1 - y)
v = (1 + y) / ((1 - y) · x)
```

Зворотне перетворення точок із кривої Монтгомері на криву Едвардса:

```
x = u / v
y = (u - 1) / (u + 1)
```

Цей ізоморфізм об'єднує протоколи X25519 (обмін ключами на кривій Монтгомері) та Ed25519 (цифровий підпис на кривій Едвардса): обидва алгоритми спираються на спільний арифметичний рушій `REDC` над полем `GF(2²⁵⁵ - 19)`.

### 11. Пакетне одночасне модульне обернення Монтгомері

Під час роботи з великими масивами криптографічних ключів або точок еліптичних кривих часто виникає потреба обчислити модульні обернені для `k` різних ненульових чисел `x₁, x₂, ..., xₖ mod N`.

Класичне обчислення оберненого через розширений алгоритм Евкліда є важкою операцією, яка забирає близько 200–300 тактів на одне число. Петер Монтгомері запропонував елегантний алгебраїчний прийом — **пакетне обернення** (*Montgomery's Simultaneous Inversion*), яке зводить обчислення `k` обернених величин до **одного-єдиного повного обернення** та `3(k - 1)` швидких модульних множень:

1. Обчислюються префіксні добутки:
   `p₁ = x₁`
   `p₂ = p₁ · x₂ = x₁ · x₂`
   `pᵢ = pᵢ₋₁ · xᵢ = x₁ · x₂ · ... · xᵢ`
2. Обчислюється одне спільне модульне обернене до повного добутку:
   `I = pₖ⁻¹ = (x₁ · x₂ · ... · xₖ)⁻¹ mod N`
3. Зворотним проходом обчислюються індивідуальні обернені величини для кожного числа:
   `xₖ⁻¹ = I · pₖ₋₁`
   `I = I · xₖ = (x₁ · x₂ · ... · xₖ₋₁)⁻¹`
   `xᵢ⁻¹ = I · pᵢ₋₁`

Для `k = 100` замість 100 повільних евклідових ділень виконується 1 ділення та 297 надшвидких множень Монтгомері `REDC`, що прискорює пакетну обробку криптографічних підписів у 20–30 разів.

### 12. Асимптотична складність гібриду Карацуби–Монтгомері

Для чисел екстремальної довжини (RSA-4096) множення Карацуби розбиває кожне `2n`-розрядне число на два блоки по `n` розрядів:

```
M(2n) = 3 · M(n) + O(n)
```

За основною теоремою про рекурентні співвідношення (*Master Theorem*), розв'язок цього рівняння має вигляд:

```
M(s) = O(s^(log₂ 3)) ≈ O(s^1.585)
```

Оскільки редукція Монтгомері після розрахунку повного 4096-бітового добутку вимагає `O(s²)` доданків зі зсувом, сукупне поєднання рекурсивного множення Карацуби та блочної редукції Монтгомері дає найвищу продуктивність серед усіх практичних алгоритмів для ключів RSA довжиною від 2048 до 8192 бітів.

### 13. Теорема Ейлера та порядок елементів у просторі Монтгомері

Розглянемо, як класичні теореми теорії чисел (мала теорема Ферма та теорема Ейлера) трансформуються у просторі Монтгомері.

У класичному кільці `ℤ/Nℤ` для будь-якого числа `a`, взаємно простого з `N`, за теоремою Ейлера маємо:

```
a^(φ(N)) ≡ 1 (mod N)
```

де `φ(N)` — функція Ейлера (кількість чисел, менших за `N` та взаємно простих із ним).

Знайдемо, чому дорівнює піднесення образу Монтгомері `ā = (a · R) mod N` до степеня `φ(N)` у просторі Монтгомері (тобто послідовне виконання `φ(N) - 1` множень `REDC`):

```
ā^(φ(N))
= φ(a^(φ(N)))                         [за гомоморфізмом простору Монтгомері]
= (a^(φ(N)) · R) mod N                [за визначенням образу φ]
≡ (1 · R) mod N (mod N)               [за класичною теоремою Ейлера a^(φ(N)) ≡ 1]
= R mod N                             [множення на одиницю]
```

Отримано важливий алгебраїчний результат: нейтральним елементом відносно множення Монтгомері (образом одиниці `1̄`) є залишок:

```
1̄ = φ(1) = R mod N
```

Піднесення будь-якого оборотного елемента до степеня `φ(N)` у просторі Монтгомері завжди повертає образ нейтрального елемента `R mod N`.

### 14. Безрозгалужене приведення в константному часі через бітові маски

Щоб усунути витік часу при фінальному умовному відніманні `t - N`, обчислюють різницю `d = t - N` та маску запозичення `mask`:

```
mask = -(t < N)
```

У двійковій системі з доповняльним кодом:
- Якщо `t < N`, умова `t < N` дорівнює `1`, і `-(1)` дає маску зі всіма одиничними бітами `0xFF...FF`.
- Якщо `t ≥ N`, умова `t < N` дорівнює `0`, і `-(0)` дає маску з нулями `0x00...00`.

Фінальний результат формується побітовим мультиплексуванням:

```
result = (t & mask) | (d & ~mask)
```

Це доводить, що модульне зведення можна реалізувати за строго константну кількість тактів без жодного умовного переходу в машинному коді.

### 15. Арифметика Монтгомері в бінарних поліноміальних полях GF(2ᵐ)

Принцип Монтгомері бездоганно узагальнюється на поліноміальні кільця та поля `GF(2ᵐ) = GF(2)[x] / f(x)`, де `f(x)` — незвідний бінарний многочлен степеня `m`.

У полі `GF(2ᵐ)` елементи є многочленами степеня менше `m` з бінарними коефіцієнтами `{0, 1}`:
- Додавання та віднімання збігаються й виконуються побітовою операцією додавання за модулем 2 (`XOR`), що повністю усуває поширення переносів між розрядами.
- Множення є звичайним безпереносним множенням многочленів (*carry-less multiplication*).

Оберемо монополіноміальну основу Монтгомері:

```
R(x) = xᵐ
```

Оскільки многочлен `f(x)` незвідний і його молодший ненульовий член дорівнює 1 (оскільки `f(0) ≠ 0`), степені `xᵐ` та `f(x)` взаємно прості в кільці `GF(2)[x]`:

```
gcd(xᵐ, f(x)) = 1
```

За розширеним алгоритмом Евкліда для поліномів існують многочлени `R⁻¹(x)` та `f'(x)` степеня менше `m`, для яких виконується тотожність Безу:

```
xᵐ · R⁻¹(x) ⊕ f(x) · f'(x) = 1
```

Звідси константа Монтгомері для поліноміального поля задовольняє рівняння:

```
f'(x) ≡ f(x)⁻¹ mod xᵐ
```

Образ Монтгомері бінарного полінома `a(x)` задається формулою:

```
ā(x) = (a(x) · xᵐ) mod f(x)
```

Алгоритм поліноміальної редукції `PolyREDC(T(x))` для многочлена `T(x)` степеня не більше `2m - 2` виконує такі прості дії:
1. Знаходиться коефіцієнт обнулення молодших степенів:
```
m(x) = (T(x) · f'(x)) mod xᵐ
```
2. Обчислюється сума поліномів у характеристиці 2:
```
S(x) = T(x) ⊕ (m(x) · f(x))
```
3. Молодші `m` коефіцієнтів многочлена `S(x)` обнуляються:
```
S(x) mod xᵐ ≡ T(x) ⊕ (T(x) · f'(x)) · f(x) ≡ T(x) ⊕ T(x) · 1 ≡ 0 (mod xᵐ)
```
4. Ділення на `xᵐ` є простим зсувом бітів коефіцієнтів праворуч на `m` позицій:
```
t(x) = S(x) >> m
```

Оскільки степінь `S(x)` не перевищує `2m - 2`, степінь редукованого полінома `t(x)` строго менша за `m`. Фінальне віднімання модуля не потрібне взагалі, оскільки в полях характеристики 2 довжина результату автоматично потрапляє в канонічний діапазон. Це робить поліноміальну редукцію Монтгомері найшвидшим способом модульного зведення в сучасних криптосистемах AES-GCM та GHASH на процесорах із підтримкою інструкцій `CLMUL` / `PMULL`.

### 16. Мультиплікативна група та збереження порядку елементів

Розглянемо мультиплікативну групу оборотних залишків класичного кільця:

```
(ℤ/Nℤ)* = { x ∈ ℤ/Nℤ : gcd(x, N) = 1 }
```

та відповідну множину образів Монтгомері:

```
(ℤ_M)* = { ā = φ(a) : a ∈ (ℤ/Nℤ)* }
```

**Теорема 8 (Ізоморфізм мультиплікативних груп).**
Група `((ℤ_M)*, ⋆_M)` ізоморфна класичній групі `((ℤ/Nℤ)*, ·)`.

*Доведення.*
Оскільки за Теоремою 1 відображення `φ` бієктивне, а за Теоремою 2 виконується гомоморфізм `φ(a · b) = φ(a) ⋆_M φ(b)`, звуження `φ` на множину оборотних елементів утворює груповий ізоморфізм.

Зокрема:
1. **Збереження порядку елемента:** Порядок елемента `ord(a)` — це найменше натуральне число `d`, для якого `aᵈ ≡ 1 (mod N)`. За гомоморфізмом степеня:
```
ā^(d) = φ(aᵈ) = φ(1) = 1̄
```
Отже, порядок образу `ā` у групі простору Монтгомері строго дорівнює порядку початкового елемента `a`:
```
ord_{⋆_M}(ā) = ord_{·}(a)
```
2. **Збереження первісних коренів:** Якщо `g` — первісний корінь за модулем `N` (генератор мультиплікативної групи порядку `φ(N)`), то його образ `ḡ = (g · R) mod N` є генератором групи простору Монтгомері `((ℤ_M)*, ⋆_M)`.
3. **Еквівалентність дискретного логарифмування:** Задача дискретного логарифма `gˣ ≡ y (mod N)` має абсолютно ту саму складність у просторі Монтгомері: `ḡˣ ≡ ȳ (mod N)`. Жоден криптографічний захист протоколів Діффі–Геллмана не послаблюється при переході до простору Монтгомері.

### 17. Редукція Монтгомері в постквантових решітках: схема CRYSTALS-Kyber (ML-KEM)

У постквантових алгоритмах на решітках обчислення проводяться над поліноміальним кільцем `R_q = ℤ_q[x] / (x²⁵⁶ + 1)`, де модуль `q = 3329` — мале просте число, для якого `3329 < 2¹²`.

Для швидкого множення многочленів застосовують теоретико-числове перетворення (NTT — *Number Theoretic Transform*). Всередині метелика NTT (алгоритм Кулі–Тьюкі) виконується мільйони множень коефіцієнтів на степені первісного кореня з одиниці `ζ`.

Оскільки `q = 3329`, обирають 16-бітну основу Монтгомері:

```
R = 2¹⁶ = 65536
```

Константа Монтгомері для 16-бітних регістрів:

```
q' = -q⁻¹ mod 2¹⁶ = 3327      [оскільки (3329 · 3327) mod 65536 = 11075583 mod 65536 = 65535 ≡ -1 mod 65536]
```

Функція 16-бітної редукції Монтгомері для добутку `a · b` (де `a, b ∈ [-q, q]`):

```
m = (int16_t)(T) * q'         [множення молодших 16 бітів зі знаком]
t = (T - (int32_t)m * q) >> 16
```

Завдяки тому, що всі коефіцієнти вміщуються у 16-бітні регістри процесора, SIMD-інструкції AVX2 (`_mm256_mullo_epi16`, `_mm256_mulhi_epi16`) виконують 16 паралельних множень Монтгомері за один такт. Це забезпечує рекордну продуктивність алгоритму ML-KEM на сучасних серверах.

### 18. Матричне представлення кроків Евкліда та теорема Ламе

Для обчислення коефіцієнтів Безу `R⁻¹` та `N'` послідовність кроків розширеного алгоритму Евкліда можна записати у компактній матричній формі. Нехай на кроці `k` неповна частка дорівнює `q_k = ⌊r_{k-1} / r_k⌋`. Перехід між послідовними залишками описується матрицею переходу розміру 2×2:

```
[r_k, r_{k+1}]^T = [[0, 1], [1, -q_k]] · [r_{k-1}, r_k]^T
```

Повна матриця перетворення `M` є добутком елементарних матриць:

```
M = M_n · M_{n-1} · ... · M₁
```

**Теорема 9 (Інваріант визначника).** Визначник матриці `M_k` дорівнює `det(M_k) = -1`, тому для повної матриці маємо `det(M) = (-1)ⁿ = ±1`. Це гарантує існування цілочисельного розв'язку тотожності Безу `u · R + v · N = gcd(R, N) = 1`.

**Теорема Ламе про швидкість збіжності.** Кількість ітерацій ділення в алгоритмі Евкліда для пари `(R, N)` не перевищує величини `5 · log₁₀(min(R, N))`. Для 2048-бітових чисел знаходження константи Монтгомері вимагає не більше 3000 елементарних кроків, які виконуються одноразово при генерації ключів криптосистеми.

### 19. Піднесення до степеня за методом вікна у просторі Монтгомері

В алгоритмах піднесення до степеня з фіксованим розміром вікна `w` (англ. *k-ary Sliding Window Exponentiation*) показник степеня `e` розбивається на блоки по `w` бітів.

Алгебраїчна оптимізація полягає у попередньому розрахунку таблиці непарних степенів основи у просторі Монтгомері:
- `ḡ₁ = ḡ`
- `ḡ₂ = ḡ ⋆_M ḡ = (g²)̄`
- `ḡ₃ = ḡ₂ ⋆_M ḡ = (g³)̄`
- `ḡ_{2ʷ - 1} = ḡ_{2ʷ - 3} ⋆_M ḡ₂ = (g^(2ʷ - 1))̄`

Усі значення таблиці зберігаються безпосередньо у формі Монтгомері. Під час сканування бітів показника степеня виконується `w` послідовних операцій піднесення до квадрата `x̄ = x̄ ⋆_M x̄` та одне множення на значення з попередньо обчисленої таблиці `x̄ = x̄ ⋆_M ḡ_v`.

Це скорочує кількість множень з `1.5 · k` (у класичному двійковому алгоритмі) до `k + (2^(w-1) - 1) + k / (w + 1)`, що для 2048-бітових чисел (при `w = 5`) дає скорочення загальної кількості редукцій `REDC` на 20–25%.

### 20. Кільця лишків парного ступеня та декомпозиція CRT

Якщо практична задача вимагає обчислень за складеним модулем `M = 2ᵉ · N`, де `N` — непарне число, безпосереднє застосування редукції Монтгомері неможливе через парність `M` (`gcd(2ᵏ, M) = 2^min(k, e) > 1`).

У цьому випадку кільце `ℤ/Mℤ` розкладають за китайською теоремою про залишки (CRT):

```
ℤ/Mℤ ≅ (ℤ/2ᵉℤ) × (ℤ/Nℤ)
```

Для парної компоненти `ℤ/2ᵉℤ` модульна арифметика виконується через пряме побітове маскування `x mod 2ᵉ = x & ((1 << e) - 1)` без жодного множника Монтгомері. Для непарної компоненти `ℤ/Nℤ` застосовується класичний простір Монтгомері з основою `R = 2ᵏ > N`.

Після завершення ланцюжка обчислень кінцевий результат реконструюється за формулою Безу для взаємно простих чисел `2ᵉ` та `N`:

```
x = (x_odd · (2ᵉ · (2ᵉ)⁻¹ mod N) + x_even · (N · N⁻¹ mod 2ᵉ)) mod M
```

Така декомпозиція поєднує безкоштовну апаратну бітову маску двійкової частини з максимальною продуктивністю редукції Монтгомері для непарного дільника.

### 21. Спектральний аналіз розподілу образів Монтгомері

Відображення `φ(a) = (a · R) mod N` є лінійною конгруентною перестановкою множини лишків `{0, 1, ..., N - 1}`. 

Оскільки `gcd(R, N) = 1`, послідовність образів для послідовних натуральних чисел `a = 1, 2, 3, ...` рівномірно розподілена по всьому інтервалу `[0, N - 1]`. Різниця між сусідніми образами становить:

```
φ(a + 1) - φ(a) ≡ R (mod N)
```

Це псевдовипадкове розсіювання гарантує, що навіть якщо вхідні операнди `a` та `b` є малими числами з малою кількістю одиничних бітів (мала вага Хеммінга), їхні образи `ā` та `b̄` є повнорозрядними псевдовипадковими залишками. Завдяки цьому апаратні атаки, що експлуатують розрідженість бітів (Low-Weight Attacks), повністю нівелюються при роботі у просторі Монтгомері.
