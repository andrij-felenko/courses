# ⚙️ Обчислення коефіцієнтів Фур'є та дії операторів Гекке

Обчислення коефіцієнтів Фур'є рядів Ейзенштейна `E₄(τ)`, `E₆(τ)`, `E₈(τ)`, `E₁₀(τ)`, `E₁₄(τ)` та параболічного дискримінанта `Δ(τ)` (функції Рамануджана `τ(n)`) спирається на дискретне подання формальних степеневих рядів та згортку скінченних числових векторів. Алгоритмічна реалізація дії операторів Гекке `T_p` перетворює абстрактні алгебраїчні співвідношення над нескінченновимірними просторами функцій на точні лінійні перетворення масивів. Це дає змогу програмно перевіряти ейлерові розклади L-функцій, мультиплікативні тотожності між власними значеннями та доведену П'єром Делінем межу Рамануджана на зростання коефіцієнтів параболічних форм.

## 1. Постановка обчислювальної задачі та потреба в алгоритмічному апараті

Теорія модулярних форм формулює глибокі алгебраїчні та аналітичні закони, проте безпосереднє застосування цих законів до розв'язання діофантових рівнянь, аналізу еліптичних кривих та дослідження розподілу простих чисел вимагає точних числових розрахунків коефіцієнтів Фур'є. Кожен коефіцієнт Фур'є модулярної форми кодує дискретну арифметичну інформацію:
- Для рядів Ейзенштейна `E_k(τ)` коефіцієнти задають суми степенів дільників `σ_{k-1}(n)`.
- Для параболічного дискримінанта `Δ(τ)` коефіцієнти утворюють функцію Рамануджана `τ(n)`, яка визначає власні значення операторів Гекке у вазі 12 та пов'язана з представленнями групи Галуа.
- Для модулярних форм ваги 2 рівня `N`, асоційованих з еліптичними кривими `E/ℚ`, коефіцієнти `a_p` кодують число точок кривої над скінченними полями `𝔽_p`: `a_p = p + 1 - #E(𝔽_p)`.

Спроба обчислювати ці коефіцієнти за допомогою класичного числового інтегрування вздовж контурів у верхній півплощині `ℍ` є обчислювально неефективною через експоненціальне накопичення похибок заокруглення та необхідність інтегрування швидкоосцилюючих функцій. Натомість алгебраїчна природа модулярних форм дозволяє побудувати точний символьний та дискретний апарат у кільці formal power series (формальних степеневих рядів).

Основна обчислювальна проблема полягає в ефективній реалізації операцій у градуйованому кільці модулярних форм `M_*(SL(2, ℤ))`:
1. Швидка генерація базових рядів Ейзенштейна через решето дільників.
2. Символьне множення урізаних степеневих рядів у фактор-кільці `ℂ[q]/(q^{N+1})`.
3. Побудова нормалізованих параболічних власних форм через лінійні комбінації добутків рядів Ейзенштейна.
4. Обчислення лінійних операторів Гекке `T_n` як матричних перетворень на просторах коефіцієнтів.
5. Автоматизована числова перевірка алгебраїчних співвідношень між просторами різної ваги та верифікація гіпотези Рамануджана про швидкість росту коефіцієнтів.
6. Контроль точності за допомогою теореми про межу Штурма, яка перетворює скінченну перевірку коефіцієнтів на строге математичне доведення тотожності на всій нескінченній півплощині.

## 2. Математична модель дискретизації просторів модулярних форм

Усяка голоморфна модулярна форма `f(τ)` ваги `k` відносно повної модулярної групи `SL(2, ℤ)` є інваріантною відносно паралельного зсуву `T: τ ↦ τ + 1`, тобто задовольняє періодичність `f(τ + 1) = f(τ)`. Завдяки цьому вона допускає однозначний розклад у ряд Фур'є за локальним параметром `q = e^{2πiτ}` у проколотому околі каспу `i∞`:

```
f(q) = ∑_{n=0}^∞ a_n · qⁿ = a₀ + a₁·q + a₂·q² + a₃·q³ + ...
```

Для комп'ютерного моделювання нескінченний ряд урізається до фіксованого максимального степеня `N`, перетворюючись на елемент скінченновимірного фактор-кільця `ℂ[q] / (q^{N+1})`. Усі подальші обчислення виконуються за модулем `q^{N+1}`.

### Нормовані ряди Ейзенштейна

Ряди Ейзенштейна утворюють непараболічну частину простору модулярних форм. Для будь-якого парного цілого числа `k ≥ 4` нормований ряд Ейзенштейна ваги `k` має вигляд:

```
E_k(q) = 1 - (2k / B_k) · ∑_{n=1}^∞ σ_{k-1}(n) · qⁿ
```

де `B_k` — відповідне парне число Бернуллі, а `σ_{k-1}(n) = ∑_{d | n} d^{k-1}` — арифметична сума степенів дільників числа `n`.

Числові значення констант `-2k / B_k` для найважливіших ваг обчислюються точно:
- Для ваги `k = 4`: число Бернуллі `B₄ = -1/30`, отже константа `- (2 · 4) / (-1/30) = 8 · 30 = 240`.
- Для ваги `k = 6`: число Бернуллі `B₆ = 1/42`, отже константа `- (2 · 6) / (1/42) = -12 · 42 = -504`.
- Для ваги `k = 8`: число Бернуллі `B₈ = -1/30`, отже константа `- (2 · 8) / (-1/30) = 16 · 30 = 480`.
- Для ваги `k = 10`: число Бернуллі `B₁₀ = 5/66`, отже константа `- (2 · 10) / (5/66) = -20 · 66 / 5 = -264`.
- Для ваги `k = 12`: число Бернуллі `B₁₂ = -691/2730`, константа `- (2 · 12) / (-691/2730) = 65520 / 691`.
- Для ваги `k = 14`: число Бернуллі `B₁₄ = 7/6`, константа `- (2 · 14) / (7/6) = -28 · 6 / 7 = -24`.

Відповідно, ряди Ейзенштейна набувають конкретного явного вигляду:

```
E₄(q)  = 1 + 240 · ∑_{n=1}^∞ σ₃(n) · qⁿ
E₆(q)  = 1 - 504 · ∑_{n=1}^∞ σ₅(n) · qⁿ
E₈(q)  = 1 + 480 · ∑_{n=1}^∞ σ₇(n) · qⁿ
E₁₀(q) = 1 - 264 · ∑_{n=1}^∞ σ₉(n) · qⁿ
E₁₄(q) = 1 - 24 · ∑_{n=1}^∞ σ₁₃(n) · qⁿ
```

### Параболічний дискримінант `Δ(q)`

Згідно з теоремою про формулу валентності, простір параболічних форм `S_k(SL(2, ℤ))` має нульову розмірність для всіх `k < 12`, а для `k = 12` простір `S₁₂` є одновимірним і породжується нормованою модулярною формою — дискримінантом `Δ(q)`. Дискримінант будується як алгебраїчна комбінація генераторів `E₄` та `E₆`:

```
Δ(q) = ( E₄(q)³ - E₆(q)² ) / 1728 = ∑_{n=1}^∞ τ(n) · qⁿ
```

Перевіримо перші коефіцієнти символьно:
- Вільний член: `(1³ - 1²) / 1728 = 0 / 1728 = 0`. Форма зникає у каспі `i∞`, що є означенням параболічності.
- Коефіцієнт при `q¹`:
  `E₄³(q) = (1 + 240q + ...)³ = 1 + 3 · 240q + ... = 1 + 720q + ...`
  `E₆²(q) = (1 - 504q + ...)² = 1 + 2 · (-504q) + ... = 1 - 1008q + ...`
  Різниця: `(1 + 720q) - (1 - 1008q) = 1728q`.
  Ділення на 1728: `1728q / 1728 = 1 · q`. Отже, `τ(1) = 1`.

Коефіцієнти `τ(n)` утворюють знамениту арифметичну функцію Рамануджана.

## 3. Теорія операторів Гекке як лінійних ендоморфізмів

Оператори Гекке є фундаментальними симетріями у просторах модулярних форм. Для заданого натурального числа `m` оператор Гекке `T_m` переводить простір модулярних форм `M_k` у себе і зберігає підпростір параболічних форм `S_k`.

Геометрично дія оператора `T_m` відповідає підсумовуванню значень функції `f` по всіх підґратках індексу `m` у комплексній решітці `Λ`. За допомогою розкладу подвійного суміжного класу `SL(2, ℤ) · (1, 0; 0, m) · SL(2, ℤ)` на ліві суміжні класи отримують явне аналітичне представлення дії `T_m` на функції `f(τ)`:

```
(T_m f)(τ) = m^{k-1} · ∑_{a, d > 0, ad = m} ∑_{b=0}^{d-1} d⁻ᵏ · f( (a·τ + b) / d )
```

Для простого числа `m = p` дільниками є пари `(a=1, d=p)` та `(a=p, d=1)`. Це спрощує формулу до суми:

```
(T_p f)(τ) = p^{k-1} · f(p·τ) + (1 / p) · ∑_{b=0}^{p-1} f( (τ + b) / p )
```

Підставивши розклад Фур'є `f(τ) = ∑_{n=0}^∞ a_n e^{2πi n τ}` в обидва доданки, простежимо перетворення коефіцієнтів:
1. Перший доданок:
   `p^{k-1} f(pτ) = p^{k-1} ∑_{n=0}^∞ a_n e^{2πi n (pτ)} = ∑_{n=0}^∞ p^{k-1} a_n q^{p n}`.
   Він робить внесок `p^{k-1} a_{n/p}` у коефіцієнт при `qⁿ` тоді й тільки тоді, коли `n` кратне `p`.
2. Другий доданок:
   `(1 / p) ∑_{b=0}^{p-1} ∑_{m=0}^∞ a_m e^{2πi m (τ + b) / p} = ∑_{m=0}^∞ a_m e^{2πi m τ / p} · ( (1 / p) ∑_{b=0}^{p-1} e^{2πi m b / p} )`.
   Внутрішня сума експонент дорівнює `p`, якщо `m` ділиться на `p` націло (`m = p · n`), і дорівнює `0`, якщо `m` не ділиться на `p`. Отже, другий доданок дає:
   `∑_{n=0}^∞ a_{p n} e^{2πi n τ} = ∑_{n=0}^∞ a_{p n} qⁿ`.

Збираючи обидва внески, отримуємо фундаментальну дискретну формулу для коефіцієнтів розкладу образу `(T_p f)`:

```
(T_p f)[n] = a_{p · n} + p^{k-1} · a_{n / p}
```

де `a_{n/p} = 0`, якщо `n` не ділиться на `p`.

Якщо модулярна форма `f` є **власною формою Гекке** (англ. *Hecke eigenform*), тобто задовольняє рівняння `T_p f = λ_p · f`, і є нормованою (`a₁ = 1`), то коефіцієнт при `q¹` дає:
```
(T_p f)[1] = a_{p · 1} + p^{k-1} · a_{1/p} = a_p + 0 = a_p
```
З іншого боку, `(T_p f)[1] = (λ_p · f)[1] = λ_p · a₁ = λ_p · 1 = λ_p`.

Отже, **власне значення оператора Гекке `T_p` точно дорівнює `p`-му коефіцієнту Фур'є нормованої власної форми**:

```
λ_p = a_p
```

Це фундаментальний міст теорії Гекке: спектральні власні значення диференціальних операторів симетрії безпосередньо збігаються з коефіцієнтами розкладу Фур'є.

## 4. Зв'язок із L-функціями та ейлеровими добутками

Головне арифметичне значення власних форм Гекке полягає в тому, що їхні ряди Діріхле розкладаються у нескінченні ейлерові добутки над усіма простими числами. 

Для нормованої власної форми `f(τ) = ∑_{n=1}^∞ a_n qⁿ ∈ S_k(SL(2, ℤ))` асоційована L-функція визначається як ряд Діріхле:

```
L(s, f) = ∑_{n=1}^∞ a_n · n⁻ˢ
```

Завдяки мультиплікативним властивостям операторів Гекке:
```
a_m · a_n = a_{mn}                             при gcd(m, n) = 1
a_p · a_{p^k} = a_{p^{k+1}} + p^{k-1} · a_{p^{k-1}}  для простого p
```
ряд Діріхле розкладається у добуток Ейлера ступеня 2:

```
L(s, f) = ∏_p ( 1 - a_p · p⁻ˢ + p^{k - 1 - 2s} )⁻¹
```

Розглянемо знаменник кожного ейлерового множника для фіксованого простого числа `p`. Позначивши `X = p⁻ˢ`, маємо квадратичний тричлен:
```
1 - a_p · X + p^{k-1} · X² = (1 - α_p · X) · (1 - β_p · X)
```
де комплексні корені задовольняють співвідношення Вієта:
```
α_p + β_p = a_p
α_p · β_p = p^{k-1}
```

Звідси стає зрозумілою глибина гіпотези Рамануджана. Якщо корені `α_p` та `β_p` є комплексно спряженими, то їхні абсолютні модулі дорівнюють `|α_p| = |β_p| = p^{(k-1)/2}`. Тоді коефіцієнт Фур'є оцінюється як:
```
|a_p| = |α_p + β_p| ≤ |α_p| + |β_p| = 2 · p^{(k-1)/2}
```
Це і є точна межа Деліня, доведена через когомології алгебраїчних многовидів над скінченними полями.

## 5. Теорема про межу Штурма та алгоритмічна повнота

При комп'ютерному дослідженні модулярних форм виникає принципове методологічне питання: скільки початкових коефіцієнтів `a_n` необхідно обчислити та порівняти, щоб гарантувати строгу тотожність двох форм `f(τ)` та `g(τ)` для всіх нескінченних степенів `qⁿ`?

Відповідь дає **теорема Штурма** (Джейкоб Штурм, 1987 р.):

**Теорема (Межа Штурма).** Нехай `Γ` — підгрупа конгруентності групи `SL(2, ℤ)` індексу `μ = [SL(2, ℤ) : Γ]`, а `f, g ∈ M_k(Γ)` — дві модулярні форми ваги `k` із коефіцієнтами Фур'є з кільця цілих чисел (або поля характеристика якого не ділить знаменники). Якщо різниця `h = f - g` має розклад:
```
h(q) = ∑_{n=M+1}^∞ c_n · qⁿ,     тобто c_n = 0 для всіх 0 ≤ n ≤ M
```
де ціле число `M` (межа Штурма) дорівнює:
```
M = ⌊ (k · μ) / 12 ⌋
```
тоді форми є тотожно рівними на всій півплощині `ℍ`: `f ≡ g` (і `h ≡ 0`).

Для повної модулярної групи `SL(2, ℤ)` маємо індекс `μ = 1`. Значення межі Штурма `M` для різних ваг:
- Для ваги `k = 4`: `M = ⌊4 / 12⌋ = 0`. Достатньо порівняти вільний член `a₀`!
- Для ваги `k = 6`: `M = ⌊6 / 12⌋ = 0`.
- Для ваги `k = 8`: `M = ⌊8 / 12⌋ = 0`. Оскільки `E₈[0] = 1` та `E₄²[0] = 1`, рівність `E₈ = E₄²` доведена математично вже при `n = 0`!
- Для ваги `k = 10`: `M = ⌊10 / 12⌋ = 0`.
- Для ваги `k = 12`: `M = ⌊12 / 12⌋ = 1`. Для перевірки будь-якої тотожності у вазі 12 достатньо обчислити коефіцієнти при `q⁰` та `q¹`.
- Для ваги `k = 14`: `M = ⌊14 / 12⌋ = 1`.
- Для ваги `k = 24`: `M = ⌊24 / 12⌋ = 2`.

Завдяки теоремі Штурма наш програмний розрахунок для `n ≤ 10` не є просто числовим наближенням: він є 100% строгим математичним доведенням усіх перевірених алгебраїчних тотожностей.

## 6. Алгоритмічна структура програми та оптимізація обчислень

Для ефективного обчислення коефіцієнтів та перевірки тотожностей алгоритм розбивається на оптимізовані математичні підпрограми:

### 1. Обчислення арифметичної функції `σ_k(n)`

Найпростіший алгоритм знаходження дільників перебирає всі цілі числа від `1` до `n`, виконуючи `O(n)` операцій на кожне число. Для масиву розміру `N` це дає квадратичну складність `O(N²)`.

Оптимізація методу базується на симетрії дільників: якщо `d | n`, то парний дільник `d' = n / d` також ділить `n`. При цьому один із них обов'язково не перевищує `√n`. Алгоритм перебирає лише `1 ≤ d ≤ √n`:
- Якщо `n % d == 0`, обчислюється `dᵏ` та додається до суми.
- Якщо `d ≠ n / d`, обчислюється `(n / d)ᵏ` та також додається до суми.
Це зменшує складність генерації `N` коефіцієнтів до `O(N · √N)`.

Для високопродуктивних розрахунків на великих масивах (`N > 10⁶`) застосовують решето Ейлера (лінійне решето), що знаходить факторизацію всіх чисел за час `O(N)`. Оскільки `σ_k(n)` є мультиплікативною функцією:
```
σ_k(p₁^{a₁} · ... · p_r^{a_r}) = ∏_{j=1}^r ( (p_j^{k(a_j + 1)} - 1) / (p_j^k - 1) )
```
значення обчислюються за лінійний час.

### 2. Множення formal power series

Множення двох урізаних рядів степеня `N` здійснюється через дискретну згортку:
```
c_n = ∑_{k=0}^n a_k · b_{n - k}
```
Для фіксованого степеня `N` прямий алгоритм вимагає `(N + 1)(N + 2) / 2 = O(N²)` множень цілих чисел. Оскільки в теоретико-числових дослідженнях зазвичай достатньо `N ≤ 100` для однозначного встановлення тотожностей (за межею Штурма), пряма згортка є оптимальною за простотою реалізації та відсутністю накладних витрат.

### 3. Операції в градуйованому кільці `M_*`

При множенні форми ваги `k₁` на форму ваги `k₂` результуюча форма автоматично набуває ваги `k₁ + k₂`:
- `E₄ ∈ M₄`, тому `E₄² ∈ M₈`, `E₄³ ∈ M₁₂`.
- `E₆ ∈ M₆`, тому `E₆² ∈ M₁₂`, `E₄ · E₆ ∈ M₁₀`.
- Параболічний дискримінант `Δ = (E₄³ - E₆²) / 1728 ∈ S₁₂`.

## 8. Детальне покрокове трасування операторів Гекке

Розглянемо докладне виконання обчислень для перших десяти значень коефіцієнтів функції Рамануджана `τ(n)` та перевіримо дію операторів `T₂` і `T₃`.

Значення коефіцієнтів Фур'є `Δ(q)` до `n = 10`:
- `n = 1`: `τ(1) = 1`
- `n = 2`: `τ(2) = -24`
- `n = 3`: `τ(3) = 252`
- `n = 4`: `τ(4) = -1472`
- `n = 5`: `τ(5) = 4830`
- `n = 6`: `τ(6) = -6048`
- `n = 7`: `τ(7) = -16744`
- `n = 8`: `τ(8) = 84480`
- `n = 9`: `τ(9) = -113643`
- `n = 10`: `τ(10) = -115920`

### Покроковий розрахунок дії `T₂` на `Δ` (вага `k = 12`, `p = 2`, `p^{k-1} = 2¹¹ = 2048`)

Формула оператора: `(T₂ Δ)[n] = τ(2n) + 2048 · τ(n/2)`.

1. **Крок для `n = 1`:**
   Оскільки `1 % 2 ≠ 0`, доданок `τ(1/2)` відсутній:
   ```
   (T₂ Δ)[1] = τ(2 · 1) + 2048 · 0 = τ(2) = -24
   ```
   Перевірка власного значення: `τ(2) · τ(1) = (-24) · 1 = -24`. Збіг `(-24 == -24)`.

2. **Крок для `n = 2`:**
   Число `2` ділиться на `2` (`2 / 2 = 1`):
   ```
   (T₂ Δ)[2] = τ(2 · 2) + 2048 · τ(1) = τ(4) + 2048 · 1
             = -1472 + 2048 = 576
   ```
   Перевірка власного значення: `τ(2) · τ(2) = (-24) · (-24) = 576`. Збіг `(576 == 576)`.

3. **Крок для `n = 3`:**
   Число `3` непарне:
   ```
   (T₂ Δ)[3] = τ(2 · 3) + 2048 · 0 = τ(6) = -6048
   ```
   Перевірка власного значення: `τ(2) · τ(3) = (-24) · 252 = -6048`. Збіг `(-6048 == -6048)`.

4. **Крок для `n = 4`:**
   Число `4` парне (`4 / 2 = 2`):
   ```
   (T₂ Δ)[4] = τ(2 · 4) + 2048 · τ(2) = τ(8) + 2048 · (-24)
             = 84480 - 49152 = 35328
   ```
   Перевірка власного значення: `τ(2) · τ(4) = (-24) · (-1472) = 35328`. Збіг `(35328 == 35328)`.

5. **Крок для `n = 5`:**
   Число `5` непарне:
   ```
   (T₂ Δ)[5] = τ(2 · 5) + 2048 · 0 = τ(10) = -115920
   ```
   Перевірка власного значення: `τ(2) · τ(5) = (-24) · 4830 = -115920`. Збіг `(-115920 == -115920)`.

### Покроковий розрахунок дії `T₃` на `Δ` (вага `k = 12`, `p = 3`, `p^{k-1} = 3¹¹ = 177147`)

Формула оператора: `(T₃ Δ)[n] = τ(3n) + 177147 · τ(n/3)`.

1. **Крок для `n = 1`:**
   `1` не ділиться на `3`:
   ```
   (T₃ Δ)[1] = τ(3 · 1) + 177147 · 0 = τ(3) = 252
   ```
   Перевірка: `τ(3) · τ(1) = 252 · 1 = 252`. Збіг.

2. **Крок для `n = 2`:**
   `2` не ділиться на `3`:
   ```
   (T₃ Δ)[2] = τ(3 · 2) + 177147 · 0 = τ(6) = -6048
   ```
   Перевірка: `τ(3) · τ(2) = 252 · (-24) = -6048`. Збіг.

3. **Крок для `n = 3`:**
   `3` ділиться на `3` (`3 / 3 = 1`):
   ```
   (T₃ Δ)[3] = τ(3 · 3) + 177147 · τ(1) = τ(9) + 177147 · 1
             = -113643 + 177147 = 63504
   ```
   Перевірка: `τ(3) · τ(3) = 252 · 252 = 63504`. Збіг `(63504 == 63504)`.

## 9. Числова верифікація тотожностей у кільці `M_*(SL(2, ℤ))`

Алгебраїчна структура кільця модулярних форм породжує замкнені тотожності між коефіцієнтами Фур'є рядів Ейзенштейна різної ваги.

### Тотожність `E₈ = E₄²` у просторі `M₈`

Оскільки `dim M₈ = 1`, ряди `E₈` та `E₄²` повинні повністю збігатися:
- Коефіцієнти `E₄(q) = 1 + 240q + 2160q² + 6720q³ + ...`
- Квадрат `E₄²(q)`:
  - `n = 0`: `1 · 1 = 1`
  - `n = 1`: `2 · 1 · 240 = 480`
  - `n = 2`: `2 · 1 · 2160 + 240² = 4320 + 57600 = 61920`
  - `n = 3`: `2 · 1 · 6720 + 2 · 240 · 2160 = 13440 + 1036800 = 1050240`
- Порівняння з `E₈(q) = 1 + 480 ∑ σ₇(n) qⁿ`:
  - `n = 1`: `480 · σ₇(1) = 480 · 1 = 480`
  - `n = 2`: `480 · σ₇(2) = 480 · (1 + 2⁷) = 480 · 129 = 61920`
  - `n = 3`: `480 · σ₇(3) = 480 · (1 + 3⁷) = 480 · (1 + 2187) = 480 · 2188 = 1050240`
Результати ідентичні для всіх `n`. Це породжує арифметичну тотожність для дільників:
```
σ₇(n) = σ₃(n) + 120 · ∑_{k=1}^{n-1} σ₃(k) · σ₃(n - k)
```

### Тотожність `E₁₀ = E₄ · E₆` у просторі `M₁₀`

Оскільки `dim M₁₀ = 1`, ряди `E₁₀` та `E₄ · E₆` збігаються:
- `E₆(q) = 1 - 504q - 16632q² - 122976q³ - ...`
- Добуток `(E₄ · E₆)(q)`:
  - `n = 0`: `1 · 1 = 1`
  - `n = 1`: `1 · (-504) + 240 · 1 = -264`
  - `n = 2`: `1 · (-16632) + 240 · (-504) + 2160 · 1 = -16632 - 120960 + 2160 = -135432`
- Порівняння з `E₁₀(q) = 1 - 264 ∑ σ₉(n) qⁿ`:
  - `n = 1`: `-264 · σ₉(1) = -264 · 1 = -264`
  - `n = 2`: `-264 · σ₉(2) = -264 · (1 + 2⁹) = -264 · 513 = -135432`
Збіг точний.

### Тотожність `E₁₄ = E₄² · E₆` у просторі `M₁₄`

Оскільки `dim M₁₄ = 1` (бо `14 ≡ 2 (mod 12)`):
- Добуток `(E₄² · E₆)[1] = E₄²[1] · 1 + 1 · E₆[1] = 480 - 504 = -24`.
- Коефіцієнт `E₁₄[1] = -24 · σ₁₃(1) = -24 · 1 = -24`.
Збіг підтверджує структуру кільця многочленів `M_* = ℂ[E₄, E₆]`.

## 10. Числова верифікація гіпотез Рамануджана та межі Деліня

Срініваса Рамануджан у 1916 році сформулював три гіпотези щодо коефіцієнтів `τ(n)`:

### 1. Мультиплікативність для взаємно простих чисел

Для будь-яких взаємно простих чисел `m` та `n` (`gcd(m, n) = 1`):
```
τ(m · n) = τ(m) · τ(n)
```
Перевіримо на конкретних числах:
- Для пари `(2, 3)`: `τ(6) = -6048`. Добуток `τ(2) · τ(3) = (-24) · 252 = -6048`.
- Для пари `(2, 5)`: `τ(10) = -115920`. Добуток `τ(2) · τ(5) = (-24) · 4830 = -115920`.
- Для пари `(3, 3)`: числа не взаємно прості (`gcd(3, 3) = 3 ≠ 1`), тому проста мультиплікативність не діє (`τ(9) = -113643 ≠ τ(3)² = 63504`).

### 2. Рекурентне співвідношення для степенів простого числа

Для будь-якого простого `p` та показника `k ≥ 1`:
```
τ(p^{k+1}) = τ(p) · τ(p^k) - p^{11} · τ(p^{k-1})
```
Перевіримо:
- Для `p = 2`, `k = 1`:
  `τ(4) = τ(2) · τ(2) - 2¹¹ · τ(1) = (-24)² - 2048 · 1 = 576 - 2048 = -1472`.
- Для `p = 2`, `k = 2`:
  `τ(8) = τ(2) · τ(4) - 2¹¹ · τ(2) = (-24) · (-1472) - 2048 · (-24) = 35328 + 49152 = 84480`.
- Для `p = 3`, `k = 1`:
  `τ(9) = τ(3) · τ(3) - 3¹¹ · τ(1) = 252² - 177147 · 1 = 63504 - 177147 = -113643`.

### 3. Межа Деліня (доведення гіпотези Рамануджана)

П'єр Делінь у 1974 році довів, що для власної нормованої параболічної форми ваги `k` будь-який коефіцієнт `a_p` задовольняє нерівність:
```
|a_p| ≤ 2 · p^{(k - 1) / 2}
```
Для ваги `k = 12` показник степеня дорівнює `(12 - 1) / 2 = 11/2 = 5.5`:
```
|τ(p)| ≤ 2 · p^{5.5}
```

Зведемо результати перевірки у таблицю:

| Просте `p` | `τ(p)` | `|τ(p)|` | Теоретична межа `2 · p^{5.5}` | Статус виконання нерівності |
|---|---|---|---|---|
| 2 | -24 | 24 | `2 · 2^{5.5} ≈ 90.51` | Виконується (`24 ≤ 90.51`) |
| 3 | 252 | 252 | `2 · 3^{5.5} ≈ 841.78` | Виконується (`252 ≤ 841.78`) |
| 5 | 4830 | 4830 | `2 · 5^{5.5} ≈ 13975.42` | Виконується (`4830 ≤ 13975.42`) |
| 7 | -16744 | 16744 | `2 · 7^{5.5} ≈ 91562.16` | Виконується (`16744 ≤ 91562.16`) |

Ці числові результати наочно ілюструють фундаментальну відмінність параболічних форм від рядів Ейзенштейна: коефіцієнти `E_k` ростуть як `O(p^{k-1})` (для ваги 12 це `O(p¹¹)`), тоді як коефіцієнти параболічних форм мають порядок росту `O(p^{5.5})`.

## 11. Алгоритм модулярних символів Маніна та обчислення параболічних форм рівня `Γ₀(N)`

Для рівнів `N > 1` (підгруп конгруентності `Γ₀(N)`) розмірність простору параболічних форм `S₂(Γ₀(N))` може бути більшою за одиницю, а ряди Ейзенштейна вже не породжують усі параболічні форми простими поліноміальними комбінаціями. Для обчислення коефіцієнтів у таких просторах Юрій Манін запропонував алгоритм **модулярних символів** (англ. *Manin modular symbols*).

Модулярний символ `{α, β}` для двох точок `α, β ∈ ℚ ∪ {i∞}` відповідає контурному інтегралу від параболічної форми `f ∈ S₂(Γ₀(N))` вздовж геодезичної, що з'єднує ці точки у верхній півплощині:
```
{α, β}_f = 2πi · ∫_α^β f(τ) dτ
```

Будь-який такий шлях розкладається за допомогою неперервних дробів у суму шляхів вигляду `{γ(0), γ(i∞)}`, де `γ ∈ SL(2, ℤ)`. Простір модулярних символів є скінченновимірним векторним простором над полем раціональних чисел `ℚ`. Дія операторів Гекке `T_p` на цьому просторі задається явними раціональними матрицями перестановки суміжних класів:
```
T_p · {α, β} = {pα, pβ} + ∑_{b=0}^{p-1} { (α + b)/p, (β + b)/p }
```

### Числовий приклад: Рівень `N = 11` та еліптична крива `X₀(11)`

Розглянемо найменший рівень, для якого простір параболічних форм є ненульовим: `N = 11`. Рід кривої `X₀(11)` дорівнює `g = 1`, отже `dim S₂(Γ₀(11)) = 1`.

Єдина нормована власна форма `f₁₁(q) ∈ S₂(Γ₀(11))` має розклад:
```
f₁₁(q) = q - 2·q² - q³ + 2·q⁴ + q⁵ + 2·q⁶ - 2·q⁷ - 2·q⁹ - 2·q¹⁰ + q¹¹ + O(q¹²)
```

Ця форма точно відповідає еліптичній кривій `E: y² + y = x³ - x² - 10x - 20` (крива 11a1 за таблицею Кремони). Згідно з теоремою про модулярність, її коефіцієнти `a_p` збігаються з числом точок над скінченними полями `𝔽_p` за формулою `a_p = p + 1 - #E(𝔽_p)`:

1. **Над полем `𝔽₂` (`p = 2`):**
   Перевіряємо можливі пари `(x, y) ∈ {0, 1}²`:
   - `x = 0`: `y² + y = 0 ⇒ y(y + 1) = 0` має 2 розв'язки: `(0, 0)` та `(0, 1)`.
   - `x = 1`: `y² + y = 1 - 1 - 0 - 0 = 0` має 2 розв'язки: `(1, 0)` та `(1, 1)`.
   Враховуючи точку на нескінченності `O`, крива має `#E(𝔽₂) = 2 + 2 + 1 = 5` точок.
   Коефіцієнт: `a₂ = 2 + 1 - 5 = -2`. Збіг із коефіцієнтом `f₁₁[2] = -2`!

2. **Над полем `𝔽₃` (`p = 3`):**
   Рівняння `y² + y = x³ - x² - x + 1 (mod 3)`:
   - `x = 0`: `y² + y = 1 ⇒ y² + y + 2 = 0`. При `y=0: 2 ≠ 0`, `y=1: 4=1≠0`, `y=2: 8=2≠0` (0 розв'язків).
   - `x = 1`: `y² + y = 0` дає розв'язки `y=0, 2` (2 розв'язки: `(1, 0), (1, 2)`).
   - `x = 2`: `y² + y = 8 - 4 - 2 + 1 = 3 ≡ 0` дає розв'язки `y=0, 2` (2 розв'язки: `(2, 0), (2, 2)`).
   Разом із точкою `O` отримуємо `#E(𝔽₃) = 0 + 2 + 2 + 1 = 5` точок.
   Коефіцієнт: `a₃ = 3 + 1 - 5 = -1`. Збіг із коефіцієнтом `f₁₁[3] = -1`!

3. **Над полем `𝔽₅` (`p = 5`):**
   Підрахунок точок дає `#E(𝔽₅) = 5` точок.
   Коефіцієнт: `a₅ = 5 + 1 - 5 = +1`. Збіг із коефіцієнтом `f₁₁[5] = 1`!

## 12. Скалярний добуток Петерсона та спектральне розкладання

У просторі параболічних форм `S_k(SL(2, ℤ))` вводиться ермітів **скалярний добуток Петерсона**:
```
⟨f, g⟩ = ∬_{ℱ} f(τ) · ḡ(τ) · y^{k - 2} dx dy
```
де `τ = x + i·y`, а інтегрування ведеться по фундаментальній області `ℱ`.

Фундаментальна властивість теорії Гекке полягає в тому, що оператори `T_n` є **самоспряженими** (ермітовими) відносно скалярного добутку Петерсона:
```
⟨T_n f, g⟩ = ⟨f, T_n g⟩
```
Оскільки оператори `T_n` комутують між собою (`T_m T_n = T_n T_m`) та є самоспряженими, за спектральною теоремою лінійної алгебри у просторі `S_k` існує ортогональний базис, що складається зі спільних власних векторів для всіх операторів `T_n`. Більше того, усі власні значення `λ_n` (а отже, і коефіцієнти Фур'є `a_n` нормованих власних форм) є **дійсними числами**.

Для обчислення норми Петерсона `⟨f, f⟩` параболічної власної форми використовують **метод Ранкіна-Сельберга**. Він пов'язує інтеграл від квадрата модуля форми `|f(τ)|²` зі спеціальним значенням згорнутого ряду Діріхле `D(s, f ⊗ f) = ∑ |a_n|² / nˢ`:
```
⟨f, f⟩ = ( (k - 1)! / ( (4π)^k ) ) · Res_{s = k} D(s, f ⊗ f)
```
Це перетворює складне двохвимірне контурне інтегрування на півплощині на задачу знаходження лишка одновимірної комплексної L-функції, що обчислюється за скінченною кількістю коефіцієнтів Фур'є.

## 13. Порівняльний аналіз архітектури C та C++

Обидві реалізації мають чітко визначені інженерні цілі та демонструють різні парадигми програмування:

1. **Реалізація на C:**
   - Пряме керування оперативною пам'яттю за допомогою `calloc` і `free`.
   - Мінімальний оверхед у виконанні (zero runtime overhead) та відсутність динамічних таблиць віртуальних функцій.
   - Необхідність явного передавання розмірів масивів `max_deg` та ваги `weight` у кожну функцію окремими параметрами.
   - Ризик витоків пам'яті у разі помилки виділення на проміжних етапах без спеціальних очищувальних блоків.

2. **Реалізація на C++:**
   - Повна інкапсуляція стану в класі `ModularFormSeries` (вага, степінь та буфер коефіцієнтів зберігаються разом).
   - Автоматичне керування життєвим циклом об'єктів за стандартом RAII через контейнер `std::vector<std::int64_t>`, що гарантує відсутність memory leaks.
   - Використання сучасного типу `std::span` для передачі незмінних числових зрізів без копіювання.
   - Природний математичний синтаксис завдяки перевантаженню операторів `*`, `+`, `-`, `==`, що робить запис `auto e4_3 = e4 * e4 * e4;` ідентичним формулі в математичній статті.

## 12. Крайові випадки та обробка граничних станів

При алгоритмічній обробці модулярних форм слід враховувати такі крайові сценарії:
- **Переповнення 64-бітних цілих чисел (Integer Overflow):** Коефіцієнти рядів Ейзенштейна великої ваги ростуть експоненціально. Для `E₁₄` коефіцієнт `E₁₄[10] = -24 · σ₁₃(10) ≈ -2.4 · 10¹⁴`, що вже наближається до межі `int64_t` (`9.22 · 10¹⁸`). При роботі з вагами `k ≥ 20` або степенями `N ≥ 1000` обов'язково слід інтегрувати бібліотеки довгої арифметики (GMP / BigInt).
- **Вихід за межі масиву при дії операторів Гекке:** Член `a_{p · n}` вимагає доступу до елемента з індексом `p · n`. Якщо `p · n > max_deg`, масив не містить цього коефіцієнта. У програмі цей випадок обробляється тернарною умовою `(n * p <= max_deg) ? coeffs_[n * p] : 0`, що захищає від порушення пам'яті.
- **Ділення на константу 1728:** При формуванні дискримінанта `Δ = (E₄³ - E₆²) / 1728` важливо, щоб ділення було цілочисельним без залишку. Алгебра модулярних форм гарантує точну подільність кожного коефіцієнта різниці на 1728, що виключає накопичення похибок округлення чисел з плаваючою крапкою.
- **Модулярні форми за модулем простого числа `p` (редукція за Серром):** При дослідженні коефіцієнтів у скінченних полях `𝔽_p` коефіцієнти модулярних форм редукуються за модулем `p`. Жан-П'єр Серр побудував теорію `p`-адичних модулярних форм, де ряд Ейзенштейна `E_{p-1}(q) ≡ 1 (mod p)` діє як одиничний елемент, що дає змогу будувати неперервні `p`-адичні сім'ї модулярних форм (сім'ї Хіди та криві Ейгенварієтетів).
