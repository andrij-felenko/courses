# 📜 Історія виникнення та розвитку теорії модулярних форм

Формування теорії модулярних форм охоплює понад два століття інтелектуального пошуку — від класичного обчислення еліптичних інтегралів у працях Леонарда Ейлера та Карла Фрідріха Ґаусса у XVIII столітті до доведення Великої теореми Ферма, побудови програми Ленглендса та відкриття зв'язку з квантовою теорією струн наприкінці XX століття. Комплексно-аналітичні функції, наділені нескінченною симетрією відносно дробово-лінійних перетворень модулярної групи `SL(2, ℤ)`, виявилися фундаментальним універсальним мостом між геометрією, дискретною теорією чисел, теорією груп та сучасною теоретичною фізикою.

## 1. Еліптичні інтеграли, арифметика Ґаусса та подвійна періодичність (Ейлер, Ґаусс, Абель, Якобі)

Витоки теорії модулярних форм сягають класичної механіки та диференціальної геометрії середини XVIII століття, зокрема задачі про точне обчислення довжини дуги еліпса, лемніскати Бернуллі та періоду нелінійних коливань математичного маятника з довільною амплітудою. Обчислення таких геометричних величин приводило до невизначених інтегралів вигляду:

```
I(x) = ∫₀ˣ dt / √( (1 - t²) (1 - k² t²) )
```

де `k ∈ (0, 1)` — модуль еліптичного інтеграла. Ці інтеграли принципово не виражалися через елементарні тригонометричні, степеневі чи логарифмічні функції.

Леонард Ейлер у 1750-х роках встановив дивовижну теорему додавання для еліптичних інтегралів, показавши, що сума двох таких інтегралів алгебраїчно виражається через інтеграл від раціональної комбінації меж. Крім того, у 1748 році у своїй праці *Introductio in analysin infinitorum* Ейлер відкрив пентагональну теорему про нескінченний добуток:

```
∏_{n=1}^∞ (1 - qⁿ) = ∑_{k=-∞}^∞ (-1)ᵏ · q^{k(3k - 1) / 2} = 1 - q - q² + q⁵ + q⁷ - q¹² - ...
```

Цей нескінченний розклад через півтора століття виявився 24-м степенем ета-функції Дедекінда та основою розкладу модулярного дискримінанта `Δ(τ)`.

Справжній прорив у розумінні природи цих функцій здійснив Карл Фрідріх Ґаусс. 30 травня 1799 року Ґаусс записав у своєму математичному щоденнику фундаментальне відкриття: арифметико-геометричне середнє `AGM(1, √2)` двох чисел `1` та `√2` з дивовижною точністю дорівнює величині `π / ϖ`, де `ϖ = 2 · ∫₀¹ dt / √(1 - t⁴) = 2.62205755...` — константа довжини дуги лемніскати. Досліджуючи обернену функцію до лемніскатного інтеграла `x = \text{sl}(u)` (синус лемніскати), Ґаусс уперше зрозумів, що вона володіє **подвійною періодичністю** у комплексній площині з дійсним періодом `ϖ` та суто уявним періодом `i·ϖ`. Ґаусс побудував перші тета-ряди та досліджував модулярні перетворення параметра `τ = i`, проте переважна більшість його записів залишилася неопублікованою за життя.

У 1827–1829 роках норвезький математик Нільс Генрік Абель та німецький аналітик Карл Ґустав Якобі незалежно один від одного здійснили переворот в аналізі, опублікувавши концепцію обернення еліптичних інтегралів. Замість інтеграла `u = I(x)` вони стали досліджувати обернену функцію `x = f(u)`. 

Ці нові функції (еліптичні функції Якобі `\text{sn}(u, k)`, `\text{cn}(u, k)`, `\text{dn}(u, k)`) виявилися мероморфними функціями на комплексній площині `ℂ`, які мають два лінійно незалежні періоди над `ℝ` — комплексні числа `ω₁` та `ω₂` із недійсним відношенням `τ = ω₂ / ω₁` (`Im(τ) > 0`):

```
f(z + ω₁) = f(z),    f(z + ω₂) = f(z)
```

Множина `Λ = ℤ·ω₁ + ℤ·ω₂` утворює періодичну решітку (ґратку) на площині `ℂ`. Карл Якобі у фундаментальній монографії *Fundamenta Nova Theoriae Functionum Ellipticarum* (1829 р.) запровадив чотири класичні тета-функції `θ_j(z, q)`, де `q = e^{iπτ}`, і показав, що при заміні базису решітки параметр `τ` у Верхній півплощині `ℍ` зазнає дробово-лінійних модулярних перетворень.

## 2. Від геометрії решіток до групи модулярних перетворень (Ейзенштейн, Дедекінд, Кляйн, Пуанкаре)

У середині XIX століття фокус досліджень змістився від самих подвійно періодичних функцій до простору параметрів решіток (простору модулів).

Ґотгольд Ейзенштейн у 1847 році поставив питання: які аналітичні функції можна побудувати безпосередньо з геометрії самої решітки `Λ = ℤ·ω₁ + ℤ·ω₂`? Він розглянув симетричні суми за всіма ненульовими вузлами решітки:

```
G_k(ω₁, ω₂) = ∑_{(m, n) ∈ ℤ² \ {(0, 0)}} 1 / (m·ω₁ + n·ω₂)ᵏ
```

Якщо масштабувати решітку, поділивши на `ω₁`, параметр `τ = ω₂ / ω₁ ∈ ℍ` повністю визначає конфігурацію решітки з точністю до подібності. Ряди Ейзенштейна набули вигляду:

```
G_k(τ) = ∑_{(m, n) ≠ (0, 0)} 1 / (m·τ + n)ᵏ
```

Ейзенштейн довів, що для парних `k ≥ 4` ці ряди абсолютно збігаються, є голоморфними функціями у верхній півплощині `ℍ` і при заміні базису решітки матрицею `γ = (a, b; c, d) ∈ SL(2, ℤ)` перетворюються за законом:

```
G_k( (a·τ + b) / (c·τ + d) ) = (c·τ + d)ᵏ · G_k(τ)
```

Це було перше строге відкриття модулярних форм цілої ваги `k`.

Карл Веєрштрасс у 1860-х роках побудував канонічну теорію еліптичних функцій на основі своєї `℘`-функції:
```
℘(z; Λ) = 1/z² + ∑_{w ∈ Λ \ {0}} ( 1/(z - w)² - 1/w² )
```
Він довів, що функція `℘(z)` задовольняє диференціальне рівняння першого порядку `(℘'(z))² = 4℘(z)³ - g₂℘(z) - g₃`, де коефіцієнти `g₂ = 60·G₄(τ)` та `g₃ = 140·G₆(τ)` є рядами Ейзенштейна ваг 4 та 6. Модулярний дискримінант кубічного тричлена `Δ = g₂³ - 27g₃²` виявився параболічною модулярною формою ваги 12.

У 1877 році Ріхард Дедекінд опублікував працю про ета-функцію Дедекінда:

```
η(τ) = q^{1/24} · ∏_{n=1}^∞ (1 - qⁿ),    q = e^{2πiτ}
```

Дедекінд довів, що під дією генераторів модулярної групи `T: τ ↦ τ + 1` та `S: τ ↦ -1/τ` функція `η(τ)` перетворюється з 24-ми коренями з одиниці (характер мультиплікативності), що започаткувало теорію модулярних форм півцілої ваги та модулярних форм із характером.

Фелікс Кляйн у 1870–1880-х роках здійснив великий геометричний синтез теорії груп, неевклідової геометрії та комплексного аналізу. У своїй знаменитій монографії *Vorlesungen über das Ikosaeder und die Auflösung der Gleichungen vom fünften Grade* (1884 р.) Кляйн використав модулярні форми для точного аналітичного розв'язання загального алгебраїчного рівняння 5-го степеня через групу симетрій ікосаедра. Кляйн побудував фундаментальну область `ℱ = {τ ∈ ℍ : |Re(τ)| ≤ 1/2, |τ| ≥ 1}` дії групи `PSL(2, ℤ)` на гіперболічній площині Пуанкаре та запровадив **абсолютний інваріант Кляйна**:

```
j(τ) = 1728 · ( g₂³ / (g₂³ - 27g₃²) ) = E₄(τ)³ / Δ(τ)
```

Кляйн довів, що функція `j(τ)` задає конформний ізоморфізм фактор-простору `SL(2, ℤ)\ℍ` на комплексну площину `ℂ`, класифікуючи комплексні еліптичні криві з точністю до ізоморфізму.

Приблизно в цей же час Анрі Пуанкаре у серії мемуарів 1881–1884 років узагальнив модулярні форми до класу автоморфних функцій відносно довільних дискретних підгруп групи дробово-лінійних перетворень (фуксових груп), запровадивши апарат рядів Пуанкаре для уніформізації довільних компактних ріманових поверхонь.

## 3. Таємниця функції Рамануджана та аналітична теорія чисел (Рамануджан, Морделл, Гекке, Делінь)

На початку XX століття модулярні форми несподівано стали ключовим інструментом аналітичної теорії чисел.

У 1916 році геніальний індійський математик Срініваса Рамануджан у праці *On certain arithmetical functions* досліджував розклад Фур'є модулярного дискримінанта `Δ(τ)`:

```
Δ(τ) = q · ∏_{n=1}^∞ (1 - qⁿ)²⁴ = ∑_{n=1}^∞ τ(n) · qⁿ = q - 24·q² + 252·q³ - 1472·q⁴ + ...
```

Обчислюючи вручну таблиці значень коефіцієнтів `τ(n)` (функція Рамануджана), він емпірично відкрив дивовижні арифметичні закономірності та сформулював три гіпотези:
1. **Мультиплікативність:** `τ(m · n) = τ(m) · τ(n)` для всіх взаємно простих чисел `gcd(m, n) = 1`.
2. **Рекурентність степенів:** `τ(p^{k+1}) = τ(p) · τ(p^k) - p¹¹ · τ(p^{k-1})` для будь-якого простого числа `p`.
3. **Гіпотеза Рамануджана про межу росту:** Для кожного простого числа `p` виконується точна оцінка:
   ```
   |τ(p)| ≤ 2 · p¹¹/² = 2 · p^{5.5}
   ```

У 1917 році англійський математик Луїс Морделл довів перші дві властивості, застосувавши оператори зсуву на просторах тета-рядів. Проте повний алгебраїчний механізм цього явища залишався невідомим.

У 1935–1937 роках німецький математик Еріх Гекке побудував загальну теорію лінійних операторів на просторах модулярних форм — **операторів Гекке** `T_n`. Гекке показав, що мультиплікативність коефіцієнтів Фур'є є прямим наслідком того, що форма є спільним власним вектором для всього комутативного сімейства операторів `T_n`.

Гекке встановив, що якщо нормована форма `f(τ) = ∑ a_n qⁿ` є власною формою Гекке (`T_p f = a_p f`), то її асоційований ряд Діріхле розкладається в ейлерів добуток ступеня 2:

```
L(s, f) = ∑_{n=1}^∞ a_n · n⁻ˢ = ∏_p ( 1 - a_p · p⁻ˢ + p^{k - 1 - 2s} )⁻¹
```

Це відкриття назавжди зв'язало теорію модулярних форм із L-функціями Діріхле та гіпотезою Рімана.

У 1939 році Ганс Петерсон запровадив інваріантний скалярний добуток (скалярний добуток Петерсона) у просторі параболічних форм, довівши, що оператори Гекке є самоспряженими, а отже, простір параболічних форм має ортогональний базис із власних форм із дійсними коефіцієнтами Фур'є.

Третя гіпотеза Рамануджана `|τ(p)| ≤ 2·p^{11/2}` залишалася однією з найглибших проблем теорії чисел протягом 58 років. У 1974 році французький математик П'єр Делінь довів її у повній загальності для довільних параболічних форм будь-якої ваги `k`:
```
|a_p| ≤ 2 · p^{(k - 1) / 2}
```
Делінь здійснив це через доведення знаменитих гіпотез Вейля про власні значення ендоморфізму Фробеніуса на етальних когомологіях алгебраїчних многовидів над скінченними полями, за що був нагороджений Філдсівською премією 1978 року.

## 4. Гіпотеза Таніями-Шимури-Вейля та тріумф Великої теореми Ферма (Таніяма, Шимура, Вейль, Фрей, Серр, Рібет, Вілс, Тейлор)

У вересні 1955 року на міжнародному симпозіумі з алгебраїчної теорії чисел у Токіо та Нікко молодий японський математик Ютака Таніяма сформулював низку сміливих запитань щодо зв'язку між еліптичними кривими та модулярними формами. Його колега Ґоро Шимура розвинув ці ідеї у точну математичну концепцію.

У 1967 році Андре Вейль опублікував фундаментальну працю *Über die Bestimmung Dirichletscher Reihen durch Funktionalgleichungen*, де встановив теорему про обернення: якщо L-функція та її скрутки з характерами Діріхле задовольняють певні функціональні рівняння, то вона походить від модулярної форми. Це перетворило інтуїтивне припущення на строгу **гіпотезу Таніями-Шимури-Вейля (теорему про модулярність)**:

> **Кожна еліптична крива `E`, визначена над полем раціональних чисел `ℚ`, є модулярною.**

Це означало, що для еліптичної кривої `E: y² = x³ + ax + b` з кондуктором `N` існує параболічна модулярна форма `f ∈ S₂(Γ₀(N))` ваги 2, коефіцієнти Фур'є `a_p` якої точно дорівнюють локальним слідам Фробеніуса:
```
a_p = p + 1 - #E(𝔽_p)
```

Десятиліттями ця гіпотеза розглядалася як красива, але абсолютно недосяжна мрія. Ситуація кардинально змінилася восени 1984 року, коли німецький математик Ґергард Фрей на конференції в Обервольфаху висунув ідею: якщо Велика теорема Ферма хибна (тобто існують попарно взаємно прості цілі числа `a, b, c` та просте `p ≥ 5` такі, що `aᵖ + bᵖ = cᵖ`), то гіпотетична еліптична крива Фрей:

```
E_Frey: y² = x · (x - aᵖ) · (x + bᵖ)
```

має настільки вироджені арифметичні властивості (її дискримінант `Δ = (a·b·c)^{2p} / 256` є точним `p`-м степенем), що відповідна модулярна форма не може існувати.

Жан-П'єр Серр у 1986 році формалізував цю ідею у вигляді гіпотези зниження рівня (англ. *epsilon conjecture*). У 1990 році американський математик Кен Рібет блискуче довів теорему Серра про зниження рівня: з модулярності кривої Фрей випливало б існування ненульової модулярної форми ваги 2 рівня 2 (`S₂(Γ₀(2))`). Але за формулою валентності рід кривої `X₀(2)` дорівнює 0, тому `dim S₂(Γ₀(2)) = 0`! 

Це створило логічний ланцюг:
```
Модулярність напівстабільних еліптичних кривих over ℚ  ==>  Велика теорема Ферма істинна
```

Дізнавшись про результат Рібета у 1986 році, англійський математик Ендрю Вілс усамітнився у своєму мансардному кабінеті в Прінстоні на 7 років для доведення модулярності напівстабільних еліптичних кривих. Вілс побудував революційний апарат деформацій представлень Галуа та теорему про ізоморфізм кілець деформацій та алгебр Гекке `R = T`.

23 червня 1993 року наприкінці серії лекцій в Інституті Ісаака Ньютона в Кембриджі Вілс оголосив про доведення Великої теореми Ферма. Під час ретельного рецензування рукопису восени 1993 року Ніколас Кац виявив серйозну прогалину у використанні системи Ейлера-Флаха. Вілс разом зі своїм учнем Річардом Тейлором майже рік намагався закрити цю діру. 19 вересня 1994 року Вілса осяяло прозріння: комбінація теорії деформацій з теорією Івасави дозволила повністю завершити конструкцію. У травні 1995 року в *Annals of Mathematics* вийшли дві вирішальні статті Вілса та Тейлора-Вілса, які остаточно розв'язали 358-річну проблему Ферма.

У 2001 році Крістоф Брейль, Браян Конрад, Фред Даймонд та Річард Тейлор довели теорему про модулярність у повній загальності для всіх еліптичних кривих над `ℚ`.

## 5. Багатовимірні узагальнення: Модулярні форми Гільберта та Зігеля

У першій половині XX століття виникло природне питання про узагальнення модулярних форм на алгебраїчні числові поля вищих степенів та простори модулів абелевих многовидів вищої розмірності.

### Модулярні форми Гільберта-Блументаля

Давид Гільберт на початку 1900-х років та його учень Отто Блументаль (1903–1904 рр.) узагальнили теорію модулярних форм на випадок довільного повністю дійсного числового поля `K` степеня `g = [K : ℚ]`. Замість однієї верхньої півплощини розглядається прямий добуток `g` копій:
```
ℍᵍ = ℍ × ℍ × ... × ℍ
```
на якому діє гільбертова модулярна група `SL(2, 𝒪_K)` (де `𝒪_K` — кільце цілих чисел поля `K`). Кожна матриця `γ ∈ SL(2, 𝒪_K)` діє на вектор `(τ₁, ..., τ_g) ∈ ℍᵍ` через `g` різних дійсних вкладень поля `K ↪ ℝ`.

Блументаль довів, що для `g > 1` умова голоморфності в каспах виконується **автоматично** (теорема Кехера про відсутність особливостей у корозмірності `≥ 2`).

### Простори Зігеля та симплектична геометрія

У 1935–1939 роках Карл Людвіг Зігель побудував фундаментальне узагальнення теорії модулярних форм на випадок багатовимірних комплексних торусів (абелевих многовидів розмірності `g`).

Зігель замінив півплощину `ℍ` на **верхню півплощину Зігеля** `ℍ_g` — простір симетричних комплексних матриць розміру `g × g` із додатно визначеною уявною частиною:
```
ℍ_g = { Z = X + i·Y ∈ M_{g×g}(ℂ) : Zᵀ = Z,  Y > 0 }
```
На цьому просторі діє симплектична модулярна група `Sp(2g, ℤ)`. Зігелеві модулярні форми стали незамінним апаратом для класифікації алгебраїчних кривих роду `g` через матриці періодів (відображення Якобі) та розв'язання проблеми Шотткі.

## 6. Алгебраїзація та геометричні модулярні форми (Гротендік, Серр, Кац, Хіда)

У 1960–1970-х роках французька математична школа кардинально переосмислила модулярні форми мовою сучасної алгебраїчної геометрії схем та стеків.

Александр Гротендік та П'єр Делінь визначили модулярні криві `X₀(N)` як алгебраїчні схеми модулів над кільцем цілих чисел `ℤ`, що класифікують еліптичні схеми з додатковою структурою кручення.

Ніколас Кац у 1973 році ввів поняття **геометричної модулярної форми** над довільним комутативним кільцем `R`. Модулярна форма ваги `k` була перевизначена як функторне правило, що зіставляє кожній парі `(E/R, ω)` (де `E` — еліптична крива над `R`, а `ω ∈ Ω¹(E/R)` — регулярний диференціал) елемент кільця `R`, однорідний степеня `k` відносно масштабування диференціала:
```
f(E, c · ω) = c⁻ᵏ · f(E, ω)
```
Це дозволило визначати модулярні форми над скінченними полями `𝔽_p` та кільцями `p`-адичних цілих чисел `ℤ_p`.

У 1986 році Харузо Хіда побудував теорію `p`-адичних сімей Хіди, показавши, що власні форми Гекке різної ваги об'єднуються у неперервні аналітичні `p`-адичні родини над простором ваг Івасави. Це стало фундаментом сучасного `p`-адичного аналізу та програми Ленглендса.

## 8. Сучасний стан: програма Ленглендса, «Monster Moonshine» та теорія струн

У сучасному математичному ландшафті класичні модулярні форми розглядаються як одновимірний вхід до грандіозної **програми Ленглендса** — масштабної системи гіпотез, висунутої Робертом Ленглендсом у 1967 році в його історичному листі до Андре Вейля. Програма стверджує фундаментальну еквівалентність між:
1. Автоморфними представленнями редуктивних алгебраїчних груп Лі над кільцем аделів `GL(n, 𝔸_ℚ)`.
2. `n`-вимірними представленнями абсолютної групи Галуа `Gal(ℚ̄/ℚ)`.
Для `n = 1` програма збігається з класичною теорією полів класів Абеля та законами взаємності Артіна; для `n = 2` вона відповідає теоремі про модулярність еліптичних кривих та формам Гекке.

Паралельно наприкінці XX століття виник інший вражаючий зв'язок — гіпотеза «Monstrous Moonshine», сформульована Джоном Конвеєм та Саймоном Нортоном у 1979 році. Вони помітили, що перші коефіцієнти розкладу `j`-інваріанта Кляйна:
```
j(τ) - 744 = q⁻¹ + 196884·q + 21493760·q² + 864299970·q³ + ...
```
точно дорівнюють сумам розмірностей найменших незвідних представлень групи-Монстра `𝕄` (найбільшої спорадичної скінченної простої групи порядку приблизно `8 · 10⁵³`):
```
196884 = 196883 + 1
21493760 = 21296876 + 196883 + 1
```

У 1992 році Річард Борчердс повністю довів цю гіпотезу, сконструювавши вершинні операторні алгебри та узагальнені алгебри Каца-Муді (алгебру Лі Монстра), за що отримав Філдсівську премію 1998 року.

У теоретичній фізиці модулярні форми стали незамінним апаратом теорії суперструн. При обчисленні 1-петльових амплітуд розсіювання замкнених струн інтегрування ведеться по простору модулів конформних торусів `SL(2, ℤ)\ℍ`. Вимога модулярної інваріантності стає фізичною умовою узгодженості квантової теорії поля та скорочення гравітаційних аномалій у 10- та 26-вимірному просторах-часах.

Крім того, у 2000-х роках математики розгадали останню таємницю Рамануджана — його «несправжні тета-функції» (англ. *mock theta functions*), описані у його передсмертному листі до Годфрі Гарді у 1920 році. У 2002–2006 роках Сандер Звеґерс, Кен Оно та Кетрін Брінгманн довели, що ці функції є голоморфними компонентами гармонічних слабких форм Маасса. Дон Цагір у 2010 році ввів поняття **квантових модулярних форм**, визначених на множині раціональних чисел `ℚ`, що пов'язує топологічні інваріанти 3-вимірних вузлів Віттена-Решетіхіна-Тураєва з квантовими чорними дірами.
