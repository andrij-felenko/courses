# 🧮 Виведення формули валентності для простору модулярних форм

Цей математичний екскурс містить повне виведення теореми про валентність (формули `k/12`) для голоморфних та мероморфних модулярних форм відносно модулярної групи `SL(2, ℤ)` та підгруп конгруентності `Γ₀(N)`. Без цієї теореми неможливо довести скінченновимірність просторів модулярних форм, встановити точну алгебраїчну структуру градуйованого кільця `M_* = ℂ[E₄, E₆]`, обчислити замкнені тотожності між коефіцієнтами Фур'є та оцінити кількість нулів і полюсів модулярних форм у фундаментальній області.

## 1. Геометрична топологія та формулювання теореми про валентність

Розглянемо дію модулярної групи `SL(2, ℤ)` дробово-лінійними перетвореннями `γ · τ = (a·τ + b) / (c·τ + d)` на Верхню півплощину комплексної площини `ℍ = { τ = x + i·y ∈ ℂ : y = Im(τ) > 0 }`. Оскільки матриці `+I` та `-I` діють на півплощину однаково, геометричною групою автоморфізмів є проективна модулярна група `PSL(2, ℤ) = SL(2, ℤ) / {±I}`.

Канонічна фундаментальна область `ℱ` для дії групи `PSL(2, ℤ)` задається нерівностями:
```
ℱ = { τ ∈ ℍ : |Re(τ)| ≤ 1/2,  |τ| ≥ 1 }
```

Ця область містить особливі геометричні точки:
1. **Касп у нескінченності `i∞`:** Вершина фундаментальної області, що відповідає границі при `Im(τ) → ∞`. Для аналізу поведінки функції в каспі використовують локальний параметр `q = e^{2πiτ}`. Порядок нуля (або полюса) функції `f` у нескінченності позначається `v_∞(f)` і визначається як найменший степінь `n` у ряді Лорана за змінною `q`:
   ```
   f(τ) = ∑_{n = v_∞(f)}^∞ a_n · qⁿ,     a_{v_∞(f)} ≠ 0
   ```
2. **Еліптична точка порядку 2 (`τ = i`):** Залишається нерухомою під дією інверсії `S: τ ↦ -1/τ` (`S(i) = -1/i = i`). Її стабілізатор у групі `PSL(2, ℤ)` породжується перетворенням `S` і має порядок 2. Внутрішній кут фундаментальної області у точці `i` дорівнює розгорнутому куту `π`.
3. **Еліптична точка порядку 3 (`τ = ρ = e^{2πi/3} = -1/2 + i·√(3)/2`):** Залишається нерухомою під дією композиції `(S·T)(ρ) = ρ` (де `T: τ ↦ τ + 1`). Її стабілізатор у `PSL(2, ℤ)` має порядок 3.
4. **Кон'югована еліптична вершина (`τ = ρ + 1 = e^{πi/3} = 1/2 + i·√(3)/2`):** Еквівалентна точці `ρ` під дією паралельного зсуву `T`. Разом точки `ρ` та `ρ + 1` утворюють один клас модулярної еквівалентності з сумарним внутрішнім кутом `π/3 + π/3 = 2π/3`.

Нехай `f` — ненульова мероморфна модулярна форма цілої ваги `k` відносно групи `SL(2, ℤ)`. Для будь-якої точки `p ∈ ℍ` позначимо через `v_p(f)` порядок нуля функції `f` у точці `p` (якщо `f` має у точці `p` полюс порядку `m`, то `v_p(f) = -m`; якщо `f(p) ≠ 0` та функція голоморфна, то `v_p(f) = 0`).

**Теорема про валентність (Теорема про `k/12`).** Для будь-якої ненульової мероморфної модулярної форми `f` ваги `k` виконується точна алгебраїчна тотожність:

```
v_∞(f) + (1/2) · v_i(f) + (1/3) · v_ρ(f) + ∑_{p ∈ ℱ \ {i, ρ, ∞}} v_p(f) = k / 12
```

де сума береться за всіма точками фундаментальної області `ℱ`, які не еквівалентні еліптичним точкам `i`, `ρ` та каспу `i∞`, причому якщо точка лежить на межі `ℱ`, вона враховується у сумі рівно один раз.

## 2. Контурне інтегрування та покрокове виведення формули

Доведення теореми базується на класичній теоремі Коші про лишки (англ. *Cauchy Residue Theorem*) у комплексному аналізі. Якщо функція `f(τ)` є мероморфною на області, то її логарифмічна похідна `f'(τ) / f(τ)` є мероморфною функцією, яка має прості полюси виключно у нулях та полюсах функції `f(τ)`.

Лишок логарифмічної похідної у точці `p` дорівнює порядку `v_p(f)`:

```
Res_{τ = p} ( f'(τ) / f(τ) ) = v_p(f)
```

За теоремою Коші інтеграл від логарифмічної похідної вздовж додатньо орієнтованого (проти годинникової стрілки) замкненого контуру `C`, що охоплює фундаментальну область, дорівнює:

```
(1 / (2πi)) ∮_C ( f'(τ) / f(τ) ) dτ = ∑_{p ∈ Int(C)} v_p(f)
```

### Побудова деформованого контуру інтегрування

Оскільки функція `f(τ)` може мати нулі або полюси безпосередньо у вершинах або на межах фундаментальної області `ℱ`, побудуємо модифікований контур `C`, який обходить усі особливі точки малими коловими дугами радіуса `ε > 0` та зрізає нескінченність на великій висоті `Im(τ) = R`:

1. **Верхня горизонтальна ділянка `L_top`:** Відрізок від точки `1/2 + i·R` до точки `-1/2 + i·R` (напрямок справа наліво).
2. **Ліва вертикальна ділянка `L_left`:** Прямолінійний відрізок уздовж прямої `Re(τ) = -1/2` від `Im(τ) = R` вниз до точки `ρ + i·ε`.
3. **Обхід вершини `ρ` (`C_ρ`):** Дуга кола радіуса `ε` з центром у точці `ρ`, що проходить всередині `ℱ` від прямої `Re(τ) = -1/2` до дуги одиничного кола `|τ| = 1`.
4. **Ліва нижня дугова ділянка `A_left`:** Дуга одиничного кола `|τ| = 1` від `C_ρ` до точки `i - ε`.
5. **Обхід точки `i` (`C_i`):** Дуга кола радіуса `ε` з центром у точці `i`, спрямована за годинниковою стрілкою всередину `ℱ`.
6. **Права нижня дугова ділянка `A_right`:** Дуга одиничного кола `|τ| = 1` від `i + ε` до точки `ρ + 1 - ε`.
7. **Обхід вершини `ρ + 1` (`C_{ρ+1}`):** Дуга кола радіуса `ε` з центром у точці `ρ + 1`.
8. **Права вертикальна ділянка `L_right`:** Прямолінійний відрізок уздовж прямої `Re(τ) = 1/2` від `C_{ρ+1}` вгору до точки `1/2 + i·R`.

Обчислимо граничні значення інтегралів уздовж кожної ділянки контуру при `ε → 0` та `R → ∞`.

```
                  L_top: від 1/2 + iR до -1/2 + iR
       -1/2 + iR <=========================== 1/2 + iR
           |                                     ^
   L_left  |                                     |  L_right
   (вниз)  |                                     |  (вгору)
           v                                     |
         C_ρ (кут π/3)                      C_{ρ+1} (кут π/3)
             \                                 /
       A_left \            C_i (кут π)        / A_right
               =====>-----[  дуга  ]----->====
                          точкою i
```

### Крок 1. Інтегрування вздовж верхньої ділянки `L_top` (Внесок каспу `i∞`)

На горизонтальному відрізку `L_top` зробимо заміну комплексної змінної `q = e^{2πiτ}`:
- Диференціал: `dq = 2πi · e^{2πiτ} dτ = 2πi · q · dτ`, отже `dτ = dq / (2πi · q)`.
- Похідна за змінною `τ`: `f'(τ) = d/dτ [ f(q) ] = df/dq · dq/dτ = (df/dq) · 2πi · q`.
- Логарифмічний диференціал набуває вигляду:
  ```
  ( f'(τ) / f(τ) ) dτ = ( (df/dq · 2πi q) / f(q) ) · ( dq / (2πi q) ) = ( (df/dq) / f(q) ) dq
  ```

Коли координата `τ` змінюється від `1/2 + i·R` до `-1/2 + i·R`, аргумент точки `q` зменшується на `2π`, що відповідає обходу кола радіуса `|q| = e^{-2πR}` навколо початку координат `q = 0` у напрямку **за годинниковою стрілкою** (від'ємна орієнтація).

За теоремою Коші про лишки для функції змінної `q` у точці `q = 0`:

```
(1 / (2πi)) ∫_{L_top} ( f'(τ) / f(τ) ) dτ 
= (1 / (2πi)) ∮_{|q| = e⁻²ᵖⁱᴿ (за стрілкою)} ( (df/dq) / f(q) ) dq          [перехід до інтеграла по змінній q]
= - (1 / (2πi)) ∮_{|q| = e⁻²ᵖⁱᴿ (проти стрілки)} ( (df/dq) / f(q) ) dq      [зміна орієнтації контуру на додатну]
= - Res_{q = 0} ( (df/dq) / f(q) )                                          [теорема про лишки у нулі]
= - v_∞(f)                                                                 [означення порядку нуля v_∞(f)]
```

Отже, внесок верхньої ділянки дає строго `- v_∞(f)`.

### Крок 2. Скорочення інтегралів уздовж вертикальних меж `L_left` та `L_right`

Розглянемо ліву вертикальну пряму `L_left` (`Re(τ) = -1/2`) та праву вертикальну пряму `L_right` (`Re(τ) = 1/2`).

За означенням модулярної форми, для матриці паралельного зсуву `T = (1, 1; 0, 1) ∈ SL(2, ℤ)` виконується тотожність:
```
f(τ + 1) = f(T · τ) = (0·τ + 1)ᵏ · f(τ) = f(τ)
```
Диференціюючи цю тотожність по `τ`, отримуємо `f'(τ + 1) = f'(τ)`. Звідси логарифмічна похідна є строго періодичною функцією з періодом 1:
```
f'(τ + 1) / f(τ + 1) = f'(τ) / f(τ)
```

Для будь-якої точки `τ` на лівій межі `L_left` відповідна точка `τ + 1` лежить на правій межі `L_right`. Оскільки на контурі `C` інтегрування вздовж `L_left` спрямоване вниз (від `Im(τ) = R` до вершини `ρ`), а вздовж `L_right` — вгору (від `ρ + 1` до `Im(τ) = R`), напрямки руху протилежні:

```
∫_{L_left} ( f'(τ) / f(τ) ) dτ + ∫_{L_right} ( f'(τ) / f(τ) ) dτ 
= ∫_{R}^{y_0} ( f'(-1/2 + iy) / f(-1/2 + iy) ) i dy + ∫_{y_0}^{R} ( f'(1/2 + iy) / f(1/2 + iy) ) i dy   [параметризація вертикальних відрізків]
= - ∫_{y_0}^{R} ( f'(-1/2 + iy) / f(-1/2 + iy) ) i dy + ∫_{y_0}^{R} ( f'(-1/2 + iy) / f(-1/2 + iy) ) i dy [періодичність f'(τ+1)/f(τ+1) = f'(τ)/f(τ)]
= 0                                                                                                        [повне взаємне скорочення інтегралів]
```

Сума інтегралів уздовж вертикальних меж тотожно дорівнює нулю.

### Крок 3. Інтегрування вздовж дуги одиничного кола (Внесок інверсії `S`)

Розглянемо дугу одиничного кола `|τ| = 1` від точки `ρ` до точки `ρ + 1`. Розділимо її на дві частини:
- Ліва дуга `A_left`: від `ρ` до `i`.
- Права дуга `A_right`: від `i` до `ρ + 1`.

Матриця модулярної інверсії `S = (0, -1; 1, 0) ∈ SL(2, ℤ)` задає відображення `S(τ) = -1/τ`. При цьому:
- Точка `ρ = e^{2πi/3}` переходить у `S(ρ) = -1 / e^{2πi/3} = - e^{-2πi/3} = e^{πi/3} = ρ + 1`.
- Точка `i` залишається нерухомою: `S(i) = -1/i = i`.
- Ліва дуга `A_left` відображається матрицею `S` на праву дугу `A_right` зі зміною напрямку обходу.

Закон модулярного перетворення форми `f` ваги `k` при дії інверсії `S`:
```
f(-1/τ) = τᵏ · f(τ)
```

Візьмемо натуральний логарифм від обох частин рівності:
```
ln f(-1/τ) = k · ln(τ) + ln f(τ)
```

Диференціюємо обидві частини за змінною `τ` за правилом диференціювання складеної функції:

```
d/dτ [ ln f(-1/τ) ] = f'(-1/τ) · (d/dτ [ -1/τ ]) / f(-1/τ) = f'(-1/τ) · (1/τ²) / f(-1/τ)     [похідна лівої частини]
d/dτ [ k · ln(τ) + ln f(τ) ] = k / τ + f'(τ) / f(τ)                                          [похідна правої частини]
```

Прирівнюючи вирази та множачи на `dτ`, одержуємо:
```
( f'(-1/τ) / f(-1/τ) ) · (dτ / τ²) = ( f'(τ) / f(τ) ) dτ + k · (dτ / τ)
```

Оскільки `d(-1/τ) = dτ / τ²`, ліва частина є точним диференціалом `( f'(S(τ)) / f(S(τ)) ) d(S(τ))`.

Тепер підсумуємо інтеграли вздовж лівої дуги `A_left` (від `ρ` до `i`) та правої дуги `A_right` (від `i` до `ρ + 1`):

```
∫_{A_left} ( f'(τ) / f(τ) ) dτ + ∫_{A_right} ( f'(τ) / f(τ) ) dτ
= ∫_{ρ}^{i} ( f'(τ) / f(τ) ) dτ + ∫_{i}^{ρ+1} ( f'(τ') / f(τ') ) dτ'                      [розбиття на дві ділянки]
= ∫_{ρ}^{i} ( f'(τ) / f(τ) ) dτ + ∫_{i}^{ρ} ( f'(-1/τ) / f(-1/τ) ) d(-1/τ)                [заміна змінної τ' = -1/τ на правій дузі]
= ∫_{ρ}^{i} ( f'(τ) / f(τ) ) dτ - ∫_{ρ}^{i} [ ( f'(τ) / f(τ) ) dτ + k · (dτ / τ) ]        [підстановка знайденого диференціала та зміна меж]
= - k · ∫_{ρ}^{i} (dτ / τ)                                                                [скорочення доданків f'(τ)/f(τ)]
```

Параметризуємо дугу одиничного кола `|τ| = 1` через кут `θ`: `τ = e^{iθ}`, де `dτ = i · e^{iθ} dθ = i · τ dθ`, отже `dτ / τ = i dθ`.
- У точці `ρ = e^{2πi/3}` кут `θ = 2π/3`.
- У точці `i = e^{πi/2}` кут `θ = π/2`.

Обчислюємо визначений інтеграл:

```
(1 / (2πi)) [ - k · ∫_{ρ}^{i} (dτ / τ) ]
= (1 / (2πi)) [ - k · ∫_{2π/3}^{π/2} i dθ ]                                               [підстановка параметризації dτ/τ = i dθ]
= (- k / (2π)) · [ θ ]_{2π/3}^{π/2}                                                       [інтегрування константи]
= (- k / (2π)) · ( π/2 - 2π/3 )                                                           [підстановка границь інтегрування]
= (- k / (2π)) · ( -π/6 )                                                                 [обчислення різниці кутів 3π/6 - 4π/6 = -π/6]
= k / 12                                                                                  [остаточне скорочення π та знаків мінус]
```

Внесок інтегрування вздовж дуги одиничного кола дає строго **`k / 12`**!

### Крок 4. Обхід еліптичних точок `i`, `ρ` та `ρ + 1`

Коли контур `C` обходить нулі або полюси на межі за малими дугами радіуса `ε → 0`, внесок кожної дуги за лемою про обхід простого полюса дорівнює добутку відповідного лишка `v_p(f)` на частку повного кута `2π`, яку займає внутрішній сектор обходу:

1. **Обхід точки `i` (`C_i`):**
   Точка `τ = i` лежить на дузі кола `|τ| = 1`. Внутрішній кут фундаментальної області у цій точці утворює розгорнутий кут `π` (половина повного кола `2π`). Оскільки контур обходить точку за годинниковою стрілкою (від'ємний напрямок), внесок становить:
   ```
   lim_{ε → 0} (1 / (2πi)) ∫_{C_i} ( f'(τ) / f(τ) ) dτ = - (π / 2π) · v_i(f) = - (1/2) · v_i(f)
   ```

2. **Обхід вершин `ρ` та `ρ + 1` (`C_ρ` та `C_{ρ+1}`):**
   Внутрішній кут фундаментальної області при вершині `ρ` дорівнює `π/3` (між вертикальною прямою `Re(τ) = -1/2` та дугою кола). Аналогічно, внутрішній кут при вершині `ρ + 1` дорівнює `π/3`. Оскільки точки `ρ` та `ρ + 1` задають одну й ту саму точку на фактор-поверхні `PSL(2, ℤ)\ℍ`, сумарний внутрішній кут дорівнює `π/3 + π/3 = 2π/3` (одна третина повного кола `2π`). Внесок обходу обох вершин становить:
   ```
   lim_{ε → 0} (1 / (2πi)) [ ∫_{C_ρ} + ∫_{C_{ρ+1}} ] ( f'(τ) / f(τ) ) dτ = - ( (2π/3) / 2π ) · v_ρ(f) = - (1/3) · v_ρ(f)
   ```

### Крок 5. Зведення компонентів та завершення доведення

Підсумовуючи всі вісім ділянок контуру `C`, за теоремою Коші отримуємо суму порядків нулів у внутрішніх точках `ℱ`:

```
∑_{p ∈ ℱ \ {i, ρ, ∞}} v_p(f) = (1 / (2πi)) ∮_C ( f'(τ) / f(τ) ) dτ
```

Розкриваємо інтеграл за знайденими внесками ділянок:
```
∑_{p ∈ ℱ \ {i, ρ, ∞}} v_p(f) = - v_∞(f) + 0 + k/12 - (1/2)·v_i(f) - (1/3)·v_ρ(f)
```

Переносимо всі від'ємні члени, що містять порядки нулів, у ліву частину рівності:

```
v_∞(f) + (1/2) · v_i(f) + (1/3) · v_ρ(f) + ∑_{p ∈ ℱ \ {i, ρ, ∞}} v_p(f) = k / 12
```

Теорему про валентність повністю доведено для довільної ненульової мероморфної модулярної форми ваги `k`. ∎

## 3. Крайовий випадок: нулі та полюси на вертикальних межах

Якщо функція `f(τ)` має нуль або полюс у точці `p₀` на лівій вертикальній межі `Re(τ) = -1/2` (де `p₀ ≠ ρ`), то в силу модулярності `f(τ + 1) = f(τ)` вона має нуль такого самого порядку `v_{p₀}(f)` у точці `p₀ + 1` на правій вертикальній межі `Re(τ) = 1/2`.

При деформації контуру навколо точки `p₀` будується півколо радіуса `ε` всередині `ℱ`, що охоплює кут `π` за годинниковою стрілкою. Відповідний інтеграл дає внесок:
```
- (π / 2π) · v_{p₀}(f) = - (1/2) · v_{p₀}(f)
```
Аналогічно, обхід точки `p₀ + 1` на правій межі дає другий внесок:
```
- (π / 2π) · v_{p₀}(f) = - (1/2) · v_{p₀}(f)
```

Сума двох внесків дорівнює:
```
- (1/2) · v_{p₀}(f) - (1/2) · v_{p₀}(f) = - v_{p₀}(f)
```

Це точно відповідає внеску одиничного нуля внутрішньої точки, що підтверджує коректність врахування граничних точок рівно один раз у сумі `∑ v_p(f)`.

## 4. Алгебраїчні наслідки для просторів `M_k` та `S_k`

Формула валентності накладає жорсткі обмеження на структуру просторів голоморфних модулярних форм. Для будь-якої голоморфної форми `f ∈ M_k` усі порядки нулів є невід'ємними цілими числами: `v_p(f) ≥ 0`, `v_∞(f) ≥ 0`, `v_i(f) ≥ 0`, `v_ρ(f) ≥ 0`.

Звідси ліва частина формули валентності є строго невід'ємною:

```
k / 12 = v_∞(f) + (1/2) · v_i(f) + (1/3) · v_ρ(f) + ∑ v_p(f) ≥ 0
```

### Наслідок 1. Відсутність форм від'ємної ваги та непарної ваги

1. **Якщо вага `k < 0`:** Права частина `k/12 < 0`, тоді як ліва частина `≥ 0`. Таке рівняння не має розв'язків у невід'ємних числах, отже:
   ```
   M_k(SL(2, ℤ)) = {0}     при k < 0
   ```
2. **Якщо вага `k` непарна (`k ≡ 1 (mod 2)`):** Оскільки матриця `-I = (-1, 0; 0, -1) ∈ SL(2, ℤ)` діє на `f` як `f(τ) = (-1)ᵏ · f(τ) = - f(τ)`, єдиною голоморфною формою є `f ≡ 0`.

### Наслідок 2. Відсутність модулярних форм ваги `k = 2`

Для `k = 2` права частина формули валентності дорівнює `2 / 12 = 1/6`.
Рівняння у цілих невід'ємних числах `a, b, c, d ≥ 0`:
```
a + b/2 + c/3 + d = 1/6
```
не має жодного цілочисельного розв'язку, оскільки мінімальне ненульове значення лівої частини становить `1/3` (при `c = 1`) або `1/2` (при `b = 1`), що строго більше за `1/6`. Звідси:
```
M₂(SL(2, ℤ)) = {0}
```

### Наслідок 3. Одновимірність просторів `M₄`, `M₆`, `M₈`, `M₁₀` та розташування нулів

Розглянемо малі парні ваги:

1. **Вага `k = 0`:** `0/12 = 0 ⇒ v_p(f) = 0` для всіх `p ∈ ℱ ∪ {∞}`. Форма не має нулів і полюсів, отже є константою: `M₀ = ℂ`.
2. **Вага `k = 4`:** `4/12 = 1/3`. Єдиний розв'язок у невід'ємних числах: `v_ρ(f) = 1`, решта `v_p = 0`. Форма `E₄` має **єдиний простий нуль у точці `ρ`** і не має інших нулів у всій півплощині `ℍ`. Оскільки відношення двох таких форм є константою без нулів, `dim M₄ = 1` (базис `E₄`).
3. **Вага `k = 6`:** `6/12 = 1/2`. Єдиний розв'язок: `v_i(f) = 1`, решта `v_p = 0`. Форма `E₆` має **єдиний простий нуль у точці `i`**. `dim M₆ = 1` (базис `E₆`).
4. **Вага `k = 8`:** `8/12 = 2/3`. Єдиний розв'язок: `v_ρ(f) = 2` (подвійний нуль у `ρ`). Базисом є `E₄²`, `dim M₈ = 1`.
5. **Вага `k = 10`:** `10/12 = 5/6 = 1/2 + 1/3`. Єдиний розв'язок: `v_i(f) = 1` та `v_ρ(f) = 1`. Базисом є `E₄ · E₆`, `dim M₁₀ = 1`.
6. **Вага `k = 12`:** `12/12 = 1`. Тут можливі два невід'ємні розв'язки:
   - Розв'язок 1: `v_∞(f) = 1`, решта `v_p = 0` — параболічна форма, що має простий нуль у каспі `i∞` (дискримінант `Δ`).
   - Розв'язок 2: `v_ρ(f) = 3` (нуль порядку 3 у `ρ`), `v_∞ = 0` — форма `E₄³`.
   Звідси `dim M₁₂ = 2`, а простір параболічних форм `dim S₁₂ = 1` з базисом `Δ`.

## 6. Застосування до мероморфного інваріанта Кляйна `j(τ)`

Абсолютний інваріант Кляйна визначається як мероморфна функція ваги `k = 0`:

```
j(τ) = 1728 · ( E₄(τ)³ / (E₄(τ)³ - E₆(τ)²) ) = E₄(τ)³ / Δ(τ)
```

Застосуємо формулу валентності до функції `j(τ) - c`, де `c ∈ ℂ` — довільне комплексне число.
Оскільки `j(τ) - c` є модулярною функцією ваги `k = 0`, формула валентності дає:

```
v_∞(j - c) + (1/2) · v_i(j - c) + (1/3) · v_ρ(j - c) + ∑_{p ∉ {i, ρ, ∞}} v_p(j - c) = 0
```

Оскільки `Δ(τ)` має простий нуль у нескінченності `v_∞(Δ) = 1`, функція `j(τ)` має **простий полюс у каспі `i∞`**:
```
v_∞(j - c) = -1
```

Підставляючи `v_∞ = -1` у формулу валентності, отримуємо фундаментальний висновок:

```
(1/2) · v_i(j - c) + (1/3) · v_ρ(j - c) + ∑_{p ∉ {i, ρ, ∞}} v_p(j - c) = 1
```

Це доводить три фундаментальні геометричні властивості `j`-інваріанта:
1. **Сюр'єктивність та бієктивність:** Для будь-якого комплексного числа `c ∈ ℂ` функція `j(τ) = c` набуває значення `c` **рівно один раз** у фундаментальній області `ℱ` (з урахуванням кратності еліптичних точок). Тобто `j` здійснює конформний ізоморфізм фактор-простору `PSL(2, ℤ)\ℍ` на комплексну сферу Рімана `ℂ ∪ {∞}`.
2. **Значення у точці `ρ` (`c = 0`):** Оскільки `E₄(ρ) = 0`, маємо `j(ρ) = 0`. Формула дає `(1/3) · v_ρ(j) = 1 ⇒ v_ρ(j) = 3`. Отже, функція `j(τ)` має **нуль третього порядку** у вершині `ρ`.
3. **Значення у точці `i` (`c = 1728`):** Оскільки `E₆(i) = 0`, маємо `j(i) = 1728 · (E₄³ / E₄³) = 1728`. Формула дає `(1/2) · v_i(j - 1728) = 1 ⇒ v_i(j - 1728) = 2`. Отже, функція `j(τ) - 1728` має **нуль другого порядку** у точці `i`.

## 7. Узагальнення для підгруп конгруентності `Γ₀(N)` та теорема Рімана-Роха

Для довільної підгрупи конгруентності `Γ ⊂ SL(2, ℤ)` скінченного індексу `μ = [SL(2, ℤ) : Γ]` фундаментальна область `ℱ_Γ` складається з `μ` копій стандартної фундаментальної області `ℱ`.

Інтегруючи логарифмічну похідну вздовж межі області `ℱ_Γ`, отримуємо **узагальнену формулу валентності**:

```
∑_{c ∈ Cusps(Γ)} v_c(f) + ∑_{e ∈ Ell₂(Γ)} (1/2) · v_e(f) + ∑_{e ∈ Ell₃(Γ)} (1/3) · v_e(f) + ∑_{p ∈ Y_Γ} v_p(f) = (k · μ) / 12
```

де:
- `Cusps(Γ) = Γ \ (ℚ ∪ {i∞})` — множина нееквівалентних вершин (каспів).
- `Ell₂(Γ)` — множина нееквівалентних еліптичних точок порядку 2.
- `Ell₃(Γ)` — множина нееквівалентних еліптичних точок порядку 3.
- `Y_Γ = Γ \ ℍ` — модулярна крива (некомпактна ріманова поверхня).

### Зв'язок із родом модулярної кривої `X₀(N)`

Компактна модулярна крива `X₀(N) = Γ₀(N) \ (ℍ ∪ ℚ ∪ {i∞})` є компактною рімановою поверхнею роду `g`. За теоремою Рімана-Гурвіца для модулярного накриття `X₀(N) → X₀(1)` рід обчислюється за формулою:

```
g(X₀(N)) = 1 + μ / 12 - ν₂ / 4 - ν₃ / 3 - ν_∞ / 2
```

де `ν₂ = |Ell₂(Γ₀(N))|`, `ν₃ = |Ell₃(Γ₀(N))|`, `ν_∞ = |Cusps(Γ₀(N))|`.

За класичною теоремою Рімана-Роха на поверхні `X₀(N)` простір голоморфних диференціалів `Ω¹(X₀(N))` має розмірність `g`. Оскільки диференціал `ω = f(τ) dτ` є голоморфним на `X₀(N)` тоді й лише тоді, коли `f ∈ S₂(Γ₀(N))` є параболічною формою ваги `k = 2`, ми отримуємо фундаментальний зв'язок алгебраїчної геометрії та модулярних форм:

```
dim S₂(Γ₀(N)) = g(X₀(N))
```

Для рівня `N = 2` маємо індекс `μ = 3`, кількість каспів `ν_∞ = 2` (`i∞` та `0`), еліптичні точки `ν₂ = 1`, `ν₃ = 0`. Обчислюємо рід:
```
g(X₀(2)) = 1 + 3/12 - 1/4 - 0/3 - 2/2 = 1 + 1/4 - 1/4 - 1 = 0
```
Звідси `dim S₂(Γ₀(2)) = g(X₀(2)) = 0`. Відсутність ненульових параболічних форм ваги 2 рівня 2 була ключовим кроком Кена Рібета у доведенні того, що модулярна форма для кривої Фрей не може існувати, що й закрило Велику теорему Ферма!

Для простого рівня `N = 11` індекс підгрупи становить `μ = 11 · (1 + 1/11) = 12`. Кількість каспів `ν_∞ = 2` (каспи `i∞` та `0`), а еліптичні точки відсутні (`ν₂ = 0`, `ν₃ = 0`). Обчислюємо рід кривої `X₀(11)`:
```
g(X₀(11)) = 1 + 12/12 - 0/4 - 0/3 - 2/2 = 1 + 1 - 1 = 1
```
Оскільки рід дорівнює `1`, простір параболічних форм `S₂(Γ₀(11))` є одновимірним (`dim S₂(Γ₀(11)) = 1`), що породжує першу нетривіальну модулярну еліптичну криву з кондуктором 11!

## 8. Алгебраїчна незалежність `E₄` та `E₆` і структура кільця `M_*`

Формула валентності дозволяє повністю розкрити структуру градуйованого кільця всіх модулярних форм `M_*(SL(2, ℤ)) = ⨁_{k=0}^∞ M_k(SL(2, ℤ))`.

**Теорема про структуру кільця.** Градуйоване кільце модулярних форм `M_*(SL(2, ℤ))` є вільним кільцем многочленів від двох алгебраїчно незалежних генераторів `E₄` та `E₆`:
```
M_*(SL(2, ℤ)) = ℂ[E₄, E₆]
```

### Доведення алгебраїчної незалежності

Припустимо від супротивного, що між `E₄` та `E₆` існує нетривіальне поліноміальне співвідношення над полем комплексних чисел:
```
P(E₄, E₆) = ∑_{4a + 6b = k} c_{a, b} · E₄ᵃ · E₆ᵇ = 0
```
Оскільки форми різної ваги лінійно незалежні, ми можемо без обмеження загальності вважати многочлен `P` ізобаричним ваги `k` (тобто кожен одночлен `E₄ᵃ · E₆ᵇ` має однакову сумарну вагу `4a + 6b = k`).

1. Оскільки `E₄(ρ) = 0`, підставимо точку `τ = ρ` у рівняння:
   ```
   P(E₄(ρ), E₆(ρ)) = ∑ c_{a, b} · 0ᵃ · E₆(ρ)ᵇ = 0
   ```
   Для `a = 0` показник ваги вимагає `6b = k`. Якщо `k` кратне 6, то доданок з `a = 0` має вигляд `c_{0, k/6} · E₆(ρ)^{k/6}`.
   Оскільки `E₆(ρ) ≠ 0` (бо `E₆` має нуль виключно в точці `i`, а в `ρ` набуває ненульового значення `E₆(ρ) = - 3 · √(3) · i / (2π³)`), звідси негайно випливає, що коефіцієнт `c_{0, k/6} = 0`.
2. Отже, кожен одночлен з ненульовим коефіцієнтом містить `E₄` у степені `a ≥ 1`. Винесемо `E₄` за дужки:
   ```
   E₄ · Q(E₄, E₆) = 0
   ```
3. Оскільки кільце голоморфних функцій на `ℍ` не має дільників нуля, а `E₄ ≢ 0`, отримуємо `Q(E₄, E₆) = 0` для форми меншої ваги `k - 4`.
4. За принципом математичної індукції за вагою `k`, усі коефіцієнти `c_{a, b}` тотожно дорівнюють нулю.

Це повністю доводить, що `E₄` та `E₆` є алгебраїчно незалежними над `ℂ`, а кільце `M_*` ізоморфне кільцю многочленів від двох змінних `ℂ[X, Y]`.

## 9. Застосування до арифметичних конгруенцій: Конгруенція Рамануджана за модулем 691

Для ваги `k = 12` простір `M₁₂` є двовимірним із базисом `{E₄³, E₆²}` або `{E₁₂, Δ}`. Виразимо ряд Ейзенштейна `E₁₂` через куб `E₄` та параболічний дискримінант `Δ`.

Коефіцієнти розкладів Фур'є мають вигляд:
- `E₁₂(q) = 1 + (65520 / 691) · ∑_{n=1}^∞ σ₁₁(n) · qⁿ`   (оскільки `B₁₂ = -691/2730`)
- `E₄³(q) = 1 + 720·q + 179280·q² + ...`
- `Δ(q) = q - 24·q² + 252·q³ + ...`

Оскільки `E₁₂` та `E₄³` мають однаковий вільний член `a₀ = 1`, їхня різниця є параболічною формою з простору `S₁₂ = ℂ · Δ`:
```
E₁₂(q) - E₄³(q) = c · Δ(q)
```
Порівнюючи коефіцієнти при `q¹`:
- У лівій частині: `(65520 / 691) · σ₁₁(1) - 720 = 65520 / 691 - 497520 / 691 = - 432000 / 691`.
- У правій частині: `c · τ(1) = c · 1 = c`.
Отже, константа `c = - 432000 / 691 = - (1728 · 250) / 691`.

Підставляючи `c` у тотожність, отримуємо точну аналітичну формулу:
```
691 · E₁₂(q) = 441 · E₄(q)³ + 250 · E₆(q)² - 65520 · 691 · Δ(q)
```

Редукуючи коефіцієнти цієї тотожності за модулем простого чисельника Бернуллі `691`:
```
65520 · σ₁₁(n) ≡ 65520 · τ(n) (mod 691)
```
Оскільки `gcd(65520, 691) = 1`, ми можемо скоротити на 65520 і отримати знамениту **конгруенцію Рамануджана**:

```
τ(n) ≡ σ₁₁(n) (mod 691)
```

Цей числовий приклад демонструє, як геометрична теорема про контурне інтегрування на фундаментальній області безпосередньо відкриває глибокі арифметичні конгруенції між параболічними коефіцієнтами та сумами дільників.

## 10. Розподіл нулів рядів Ейзенштейна (Теорема Ранкіна-Свіннертона-Даєра)

Формула валентності визначає точну зважену суму порядків нулів, проте не вказує їхніх точних координат на площині для великих ваг `k`. 

Для рядів Ейзенштейна `E_k(τ)` відповідь дає видатна теорема Ф. Ранкіна та Пітера Свіннертона-Даєра (1970 р.):

**Теорема (Ранкін, Свіннертон-Даєр).** Для будь-якої парної ваги `k ≥ 4` усі нулі ряду Ейзенштейна `E_k(τ)` у фундаментальній області `ℱ` лежать **строго на нижній дузі одиничного кола** `|τ| = 1` (між вершиною `ρ` та точкою `i`).

### Механізм доведення

Розглянемо функцію `F_k(θ) = e^{i k θ / 2} · E_k(e^{iθ})` для кута `θ ∈ [π/2, 2π/3]` на одиничному колі `τ = e^{iθ}`.
1. Завдяки закону модулярності `E_k(-1/τ) = τᵏ E_k(τ)` функція `F_k(θ)` є **суто дійснозначною** для всіх дійсних `θ`.
2. Обчислюючи значення `F_k(θ)` на границях інтервалу:
   - У точці `θ = π/2` (`τ = i`): якщо `k ≡ 2 (mod 4)`, то `E_k(i) = 0`.
   - У точці `θ = 2π/3` (`τ = ρ`): якщо `k ≢ 0 (mod 3)`, то `E_k(ρ) = 0`.
3. Виділяючи головні доданки ряду Фур'є `E_k(e^{iθ}) = 1 + O(e^{-2π Im(τ)})`, показують, що функція `F_k(θ)` коливається, змінюючи знак рівно `⌊k/12⌋` (або `⌊k/12⌋ - 1`) разів на інтервалі `(π/2, 2π/3)`.
4. За теоремою Больцано-Коші про проміжні значення неперервної функції, кожна зміна знака дає дійсний корінь `θ_j`, що відповідає нулю `τ_j = e^{iθ_j}` на дузі кола.
5. Оскільки загальна кількість знайдених нулів з урахуванням еліптичних точок точно вичерпує величину `k/12` у формулі валентності, інших нулів у фундаментальній області `ℱ` просто не існує!

## 11. Геометрична інтерпретація через векторні розшарування

З сучасної точки зору алгебраїчної геометрії модулярна форма ваги `k` є не просто функцією, а глобальним перетином (англ. *global section*) лінійного розшарування `ω^{⊗k}` над модулярною кривою `X(1) = PSL(2, ℤ) \ ℍ*`.

Диференціал `dτ` на Верхній півплощині при дії матриці `γ = (a, b; c, d)` перетворюється за правилом:
```
d(γ · τ) = (c·τ + d)⁻² · dτ
```
Звідси `(c·τ + d) = ( d(γ·τ) / dτ )^{-1/2}`. Тоді закон перетворення модулярної форми `f(γ·τ) = (c·τ + d)ᵏ f(τ)` еквівалентний твердженню, що диференціальна форма:
```
ω_f = f(τ) · (dτ)^{k / 2}
```
є строго інваріантною відносно дії модулярної групи `PSL(2, ℤ)`.

Ступінь канонічного лінійного розшарування на орбіфолді `X(1)` дорівнює ейлеровій характеристиці фактор-простору:
```
deg(ω) = 1 / 12
```
Теорема про валентність у цій геометричній мові є безпосереднім вираженням того, що кількість нулів будь-якого мероморфного перетину лінійного розшарування дорівнює його ступеню:
```
deg(ω^{⊗k}) = k · deg(ω) = k / 12
```
Це об'єднує комплексний аналіз, теорію чисел та топологію низьковимірних многовидів у єдину цілісну математичну картину.
