# 🧮 Виведення формули валентності для простору модулярних форм

Цей математичний екскурс містить повне виведення теореми про валентність (формули `k/12`) для голоморфних та мероморфних модулярних форм відносно модулярної групи `SL(2, ℤ)`. Без цієї теореми неможливо довести скінченновимірність просторів модулярних форм, встановити точну алгебраїчну структуру кільця `M_* = ℂ[E₄, E₆]`, обчислити строгі тотожності між коефіцієнтами Фур'є та оцінити кількість нулів форм у фундаментальній області.

## 1. Геометрична топологія та формулювання теореми про валентність

Розглянемо дію модулярної групи `PSL(2, ℤ) = SL(2, ℤ) / {±I}` на Верхню півплощину `ℍ = { τ ∈ ℂ : Im(τ) > 0 }`. Фактор-простір `ℱ = PSL(2, ℤ)\ℍ` утворює орієнтований двовимірний поверхневий орбіфолд з особливими еліптичними точками та каспом у нескінченності.

Нехай `f ≠ 0` — мероморфна модулярна форма ваги `k` відносно групи `SL(2, ℤ)`. Позначимо через `v_p(f)` порядок нуля (або полюса зі знаком мінус) функції `f` у точці `p ∈ ℍ`.

Порядок `f` у нескінченності `v_∞(f)` визначається як порядок нуля її розкладу Фур'є за зміщеною комплексною змінною `q = e^{2πiτ}`:

```
f(τ) = ∑_{n = v_∞(f)}^\infty a_n · qⁿ,     a_{v_∞(f)} ≠ 0
```

Для особливих еліптичних точок фундаментальної області `ℱ`:
- `i = (0, 1)` — точка порядку 2 (стабілізатор підгрупи має порядок 4 у `SL(2, ℤ)` та порядок 2 у `PSL(2, ℤ)`).
- `ρ = e^{2πi/3} = -1/2 + i·√(3)/2` — точка порядку 3 (стабілізатор має порядок 6 у `SL(2, ℤ)` та порядок 3 у `PSL(2, ℤ)`).
- `ρ + 1 = e^{πi/3} = 1/2 + i·√(3)/2` — кон'югована вершина порядку 3, еквівалентна `ρ` під дією матриці `T`.

**Теорема (Формула валентності / Теорема про `k/12`).** Для будь-якої ненульової мероморфної модулярної форми `f` ваги `k` виконується співвідношення:

```
v_∞(f) + (1/2) · v_i(f) + (1/3) · v_ρ(f) + ∑_{p ∈ ℱ \ {i, ρ, ∞}} v_p(f) = k / 12
```

де сума береться за всіма внутрішніми точками фундаментальної області `ℱ`, які не пов'язані між собою модулярними перетвореннями групи `SL(2, ℤ)`.

## 2. Повне контурне інтегрування на фундаментальній області

Доведення базується на класичній теоремі Коші про лишки (англ. *Cauchy Residue Theorem*). Для мероморфної функції `f(τ)` логарифмічна похідна `f'(τ) / f(τ)` має прості полюси у точках нулів та полюсів `f`, причому лишок у точці `p` дорівнює порядку `v_p(f)`:

```
Res_{τ = p} ( f'(τ) / f(τ) ) = v_p(f)
```

За теоремою про лишки, якщо замкнений контур `C` охоплює внутрішні точки `p ∈ ℱ`, то:

```
(1 / (2πi)) ∮_C ( f'(τ) / f(τ) ) dτ = ∑_{p ∈ ℱ \ {i, ρ, ∞}} v_p(f)
```

Розглянемо видозмінений контур `C`, який обходить межі фундаментальної області `ℱ`:
1. Верхня горизонтальна лінія `L_R` від `1/2 + i·R` до `-1/2 + i·R` при великому `R → ∞`.
2. Ліва вертикальна межа `Re(τ) = -1/2` від `Im(τ) = R` до вершини `ρ`.
3. Мала колові дуги радіуса `ε` для обходу еліптичних точок `ρ`, `i`, `ρ + 1`.
4. Нижня дуга одиничного кола `|τ| = 1` від `ρ` до `ρ + 1`.
5. Права вертикальна межа `Re(τ) = 1/2` від `ρ + 1` до `Im(τ) = R`.

Обчислимо внесок кожного сегмента контуру `C` у границі при радіусах обходу `ε → 0` та `R → ∞`.

### Крок 1. Інтеграл уздовж верхньої лінії `L_R` (Внесок у нескінченності)

На лінії `L_R` зробимо заміну змінної `q = e^{2πiτ}`. При цьому `dq = 2πi · e^{2πiτ} dτ = 2πi · q dτ`, отже `dτ = dq / (2πi · q)`.

Коли `τ` змінюється від `1/2 + i·R` до `-1/2 + i·R`, змінна `q` робить один повний обхід проти годинникової стрілки навколо `q = 0` по колу радіуса `e^{-2πR}`. Враховуючи орієнтацію контуру (зліва направо), напрямок обходу по `q` є за годинниковою стрілкою (від'ємним):

```
(1 / (2πi)) ∫_{L_R} ( f'(τ) / f(τ) ) dτ 
= (1 / (2πi)) ∮_{|q| = e⁻²ᵖⁱᴿ} ( (d/dq f(q) · 2πi q) / f(q) ) (dq / (2πi q))   [заміна змінної q = e^{2πiτ}]
= - Res_{q = 0} ( (d/dq f(q)) / f(q) )                                           [теорема про лишки у q = 0]
= - v_∞(f)                                                                      [визначення порядку нуля v_∞(f)]
```

Отже, внесок верхівки дорівнює `-v_∞(f)`.

### Крок 2. Вертикальні межі (Перетворення паралельного зсуву T)

Розглянемо ліву вертикальну межу `L₁` (`Re(τ) = -1/2`) та праву вертикальну межу `L₂` (`Re(τ) = 1/2`).

За умовою модулярності відносно генератора `T: τ ↦ τ + 1`, маємо `f(τ + 1) = f(τ)`. Похідна також задовольняє `f'(τ + 1) = f'(τ)`.

Оскільки права межа `L₂` є результатом паралельного зсуву лівої межі `L₁` на `+1`, але контур рухається у протилежних напрямках (на `L₁` внизу до `ρ`, на `L₂` вгору від `ρ + 1`), їхні інтеграли повністю скорочуються:

```
∫_{L₁} ( f'(τ) / f(τ) ) dτ + ∫_{L₂} ( f'(τ) / f(τ) ) dτ = 0
```

### Крок 3. Дуга одиничного кола (Перетворення інверсії S)

Розглянемо ліву частину дуги кола `A₁` від `ρ` до `i` та праву частину `A₂` від `i` до `ρ + 1`.

Генератор `S: τ ↦ -1/τ` відображає ліву дугу `A₁` на праву дугу `A₂` зі зміною орієнтації. Скористаємося законами перетворення модулярної форми `f` та її похідної при дії `S`:

```
f(-1/τ) = τᵏ · f(τ)                    [закон модулярності ваги k]
```

Візьмемо логарифмічну похідну від обох частин за змінною `τ`:

```
d/dτ [ ln f(-1/τ) ] = d/dτ [ k · ln(τ) + ln f(τ) ]
f'(-1/τ) · (1/τ²) / f(-1/τ) = k / τ + f'(τ) / f(τ)
```

Звідси маємо співвідношення для диференціалів логарифмічних похідних:

```
( f'(-1/τ) / f(-1/τ) ) d(-1/τ) = ( f'(τ) / f(τ) ) dτ + k · (dτ / τ)
```

Інтегруючи від `ρ` до `i` (де `-1/τ` змінюється від `i` до `ρ + 1`), отримуємо:

```
(1 / (2πi)) ∫_{дуга} ( f'(τ) / f(τ) ) dτ 
= (1 / (2πi)) ∫_{ρ}^{i} ( -k / τ ) dτ
= (1 / (2πi)) ∫_{2π/3}^{π/2} (-k · i dθ) 
= (-k / (2π)) · (π/2 - 2π/3)       [первісна сталі під знаком інтеграла]
= (-k / (2π)) · (-π/6)             [різниця границь інтегрування]
= k / 12                            [скорочення π та множників]
```

Внесок дуги одиничного кола точно дорівнює `k / 12`!

### Крок 4. Малі обходи еліптичних точок `i` та `ρ`

Малі дуги радіуса `ε` навколо особливих точок зрізають кути фундаментальної області `ℱ`:
- Точка `τ = i` має внутрішній кут `π` (півколо). Внесок обходу дорівнює `- (1/2) · v_i(f)`.
- Точки `ρ` та `ρ + 1` разом складають внутрішній кут `2π/3` (третина кола). Внесок дорівнює `- (1/3) · v_ρ(f)`.

## 3. Завершення доведення та підсумок

Збираючи внески всіх частин контуру в єдине рівняння теореми про лишки, отримуємо:

```
- v_∞(f) + k/12 - (1/2)·v_i(f) - (1/3)·v_ρ(f) = ∑_{p ∈ ℱ \ {i, ρ, ∞}} v_p(f)
```

Переносячи від'ємні члени у праву частину, одержуємо остаточну тотожність:

```
v_∞(f) + (1/2) · v_i(f) + (1/3) · v_ρ(f) + ∑_{p ∈ ℱ \ {i, ρ, ∞}} v_p(f) = k / 12
```

Теорему повністю доведено. ∎

## 4. Узагальнення для підгруп конгруентності `Γ₀(N)`

Для підгрупи конгруентності `Γ ⊂ SL(2, ℤ)` скінченного індексу `μ = [SL(2, ℤ) : Γ]` формула валентності узагальнюється через підсумовування за всіма вершинами (каспами) та еліптичними точками модулярної кривої `X_Γ = Γ\ℍ*`.

**Теорема (Узагальнена формула валентності).** Якщо `f` — мероморфна модулярна форма ваги `k` відносно підгрупи `Γ`, то:

```
∑_{c ∈ Cusps(Γ)} v_c(f) + ∑_{e ∈ Ell(Γ)} (1 / e_order) · v_e(f) + ∑_{p ∈ Y_Γ} v_p(f) = (k · μ) / 12
```

де:
- `Cusps(Γ)` — множина класів еквівалентності вершин (каспів).
- `e_order` — порядок стабілізатора еліптичної точки `e` у підгрупі `Γ / {±I}` (`e_order ∈ {2, 3}`).
- `μ` — індекс підгрупи `Γ` у польній модулярній групі `SL(2, ℤ)`.

Наприклад, для підгрупи `Γ₀(2)` індекс `μ = 3`. Формула валентності має вигляд:

```
v_∞(f) + v₀(f) + (1/2) · v_i(f) + ∑ v_p(f) = 3k / 12 = k / 4
```

Для ваги `k = 2` отримуємо `k/4 = 1/2`. Оскільки ліва частина не може прийняти значення `1/2` без еліптичних точок, це прямо доводить, що простір параболічних форм `S₂(Γ₀(2)) = {0}`, що стало ключовою ланкою у доведенні Рібета для Великої теореми Ферма!

## 5. Наслідки для розмірностей просторів `M_k` та `S_k`

Формула валентності накладає жорсткі арифметичні обмеження на можливі значення ваги `k` та нулі модулярних форм.

### Наслідок 1. Відсутність ненульових форм від'ємної ваги та ваги 2

Оскільки для голоморфної форми `f ∈ M_k` усі порядки нулів `v_p(f) ≥ 0`, ліва частина формули є неелементарно невід'ємною.

1. Якщо `k < 0`, то `k/12 < 0`, отже `M_k = {0}`.
2. Якщо `k = 2`, то `k/12 = 1/6`. Оскільки комбінація `n₀ + n_i/2 + n_ρ/3` для цілих `n ≥ 0` не може дорівнювати `1/6`, маємо `M₂ = {0}`.

### Наслідок 2. Одновимірність просторів малої ваги

Для `k ∈ {0, 4, 6, 8, 10}` розв'язок рівняння в цілих невід'ємних числах є **єдиним**:
- `k = 0`: `M₀ = ℂ` (лише константи).
- `k = 4`: `4/12 = 1/3 ⇒ v_ρ(E₄) = 1`, решта `v_p = 0`. Форма `E₄` має єдиний простий нуль у точці `ρ`. `dim M₄ = 1`.
- `k = 6`: `6/12 = 1/2 ⇒ v_i(E₆) = 1`, решта `v_p = 0`. Форма `E₆` має єдиний простий нуль у точці `i`. `dim M₆ = 1`.
- `k = 8`: `dim M₈ = 1`, базис `E₄²`.
- `k = 10`: `dim M₁₀ = 1`, базис `E₄ · E₆`.
- `k = 12`: `12/12 = 1`. Тут можливі два варіанти: або `v_∞ = 1` (дискримінант `Δ`), або `v_p = 0` (форма `E₄³`). Звідси `dim M₁₂ = 2`, а `dim S₁₂ = 1` (базис `Δ`).

### Загальна формула розмірності `dim M_k(SL(2, ℤ))`

Для будь-якого парного `k ≥ 0`:

```
dim M_k = ⌊k / 12⌋ + 1      якщо k ≢ 2 (mod 12)
dim M_k = ⌊k / 12⌋          якщо k ≡ 2 (mod 12)
```

Формула розмірності простору параболічних форм `S_k(SL(2, ℤ))`:

```
dim S_k = dim M_k - 1       при k ≥ 4
dim S_k = 0                 при k < 12
```

Це доводить, що кільце модулярних форм `M_*` є вільним алгебраїчним кільцем многочленів від двох утворюючих `E₄` та `E₆`:

```
M_*(SL(2, ℤ)) = ℂ[E₄, E₆]
```

## 6. Практичне значення та числова перевірка тотожностей

Формула валентності дозволяє миттєво перевіряти тотожності між модулярними формами без обчислення нескінченних рядів. 

Якщо дві модулярні форми `f, g ∈ M_k` мають однакові перші `dim M_k` коефіцієнтів Фур'є, то їхня різниця `h = f - g` має порядок нуля `v_∞(h) ≥ dim M_k > k/12`. За формулою валентності це можливо лише тоді, коли `h ≡ 0`, тобто `f ≡ g`.

**Приклад 1 (Тотожність ваги 12):**
Розглянемо форму `E₄³ - E₆² ∈ M₁₂`. Оскільки її вільний член `a₀ = 1 - 1 = 0`, вона має нуль у нескінченності `v_∞ ≥ 1`. Простір `S₁₂` є одновимірним і породжується дискриміннатом `Δ`. Порівняння першого коефіцієнта при `q¹`:
```
E₄³ - E₆² = (1 + 720q + ...) - (1 - 1008q + ...) = 1728·q + ...
```
одразу доводить тотожність `E₄³ - E₆² = 1728 · Δ` без обчислення решти коефіцієнтів!

**Приклад 2 (Тотожність ваги 14):**
Для ваги 14 маємо `14 ≡ 2 (mod 12)`, отже `dim M₁₄ = ⌊14/12⌋ = 1`. Оскільки `E₄² · E₆ ∈ M₁₄` та `E₁₄ ∈ M₁₄`, їхні коефіцієнти повинні збігатися, що дає тотожність `E₁₄ = E₄² · E₆` та зв'язує арифметичні функції `σ₁₃(n)` із комбінаціями `σ₃` та `σ₅`:
```
σ₁₃(n) = (1274 / 691) · σ₃(n) + (504 / 691) · σ₅(n) + ...
```

Це демонструє, як геометрична теорема про контурне інтегрування породжує нетривіальні тотожності між арифметичними функціями теорії чисел.
