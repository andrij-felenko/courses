# 🧮 Форма дільника числа Мерсенна

Просте `q`, що ділить `Mₚ = 2ᵖ − 1` (усюди далі `p` — непарне просте), не буває яким завгодно: воно змушене лежати одразу у двох тісних класах лишків, і саме ця вимушеність робить величезні числа Мерсенна перевірними вручну.

<preknowlist>
- [Модульна арифметика](root:math-number-theory/modular-arithmetic) — запис `a ≡ b (mod m)`, ділення з остачею `n = d·k + r` при `0 ≤ r < d`, вільне додавання й множення лишків.
- [Прості числа](root:math-number-theory/prime-numbers) — просте число, розклад на прості й те, що будь-яке складене число має простий дільник.
- [Мультиплікативний порядок](root:math-number-theory/multiplicative-order) — найменший `d > 0` з `aᵈ ≡ 1 (mod m)`; існує, коли `a` оборотне за модулем.
- [Мала теорема Ферма](root:math-number-theory/fermat-little-theorem) — `a^(q−1) ≡ 1 (mod q)` для простого `q`, що не ділить `a`.
- [Квадратичні лишки](root:math-number-theory/quadratic-residues) — коли `a` є квадратом за модулем `q`; символ Лежандра `(a|q)`, критерій Ейлера, лема Гаусса.
</preknowlist>

Твердження таке: якщо просте `q` ділить `Mₚ = 2ᵖ − 1`, то одразу

```
q ≡ 1  (mod 2p)        і        q ≡ ±1  (mod 8)
```

Це не спостереження, а теорема, і кожна її половина зрізає більшість чисел як кандидатів у дільники. Разом вони перетворюють перевірку `Mₚ` на простоту з безнадійного перебору на короткий рахунок пером — саме так Ейлер `1772` року довів руками, що `M₃₁ = 2 147 483 647` просте. Обидві умови випливають з елементарних причин — перша з порядку двійки, друга з її квадратичного характеру; розберімо їх по черзі, а тоді пустимо в діло.

Одразу зауважмо очевидне, що знадобиться повсюди: `Mₚ` непарне (степінь двійки, зменшений на один), тож жоден його дільник не дорівнює `2`. Отже `q` — непарне просте, `q ≥ 3`, і двійка за модулем `q` оборотна.

## Перша умова: q ≡ 1 (mod 2p)

`q` ділить `2ᵖ − 1`, тобто

```
2ᵖ ≡ 1  (mod q)
```

Погляньмо на найменший додатний показник, при якому двійка дає одиницю за модулем `q`, — на її [мультиплікативний порядок](root:math-number-theory/multiplicative-order) `d`. У порядку є одна властивість, з якої тут випливає все: **якщо `2ⁿ ≡ 1 (mod q)`, то `d` ділить `n`.** Причина — звичайне ділення з остачею. Запишімо `n = d·k + r` з `0 ≤ r < d`; тоді

```
1 ≡ 2ⁿ = (2ᵈ)ᵏ · 2ʳ ≡ 1ᵏ · 2ʳ = 2ʳ   (mod q)
```

Отже `2ʳ ≡ 1` при `0 ≤ r < d`. Але `d` — найменший **додатний** показник із такою рівністю; єдиний вихід — `r = 0`, тобто `d | n`.

Тепер застосуймо цю властивість двічі. По-перше, з `2ᵖ ≡ 1` маємо `d | p`. Число `p` просте, тож `d` дорівнює або `1`, або `p`. Випадок `d = 1` означав би `2¹ ≡ 1 (mod q)`, тобто `q` ділить `1` — для простого `q` неможливо. Лишається

```
d = p
```

По-друге, за [малою теоремою Ферма](root:math-number-theory/fermat-little-theorem) `2^(q−1) ≡ 1 (mod q)` (двійка не ділиться на просте `q`). За тією ж властивістю порядку `d | (q − 1)`, а `d = p`, тому

```
p | (q − 1)
```

Лишився один крок — від `p` до `2p`. Число `q − 1` ділиться на `p`; воно ділиться й на `2`, бо `q` непарне. А `p` — непарне просте, тож `p` і `2` взаємно прості, і число, кратне обом одночасно, кратне їхньому добутку:

```
p | (q − 1)   і   2 | (q − 1),   gcd(2, p) = 1   ⟹   2p | (q − 1)
```

тобто `q ≡ 1 (mod 2p)`. Першу умову доведено. Побічний наслідок вартий уваги: `q ≡ 1 (mod 2p)` тягне `q ≥ 2p + 1`, тож навіть найменший можливий дільник уже досить великий — це перша економія в переборі.

## Друга умова: q ≡ ±1 (mod 8)

Ця половина тонша: вона випливає не з того, який у двійки порядок, а з того, чи є двійка **квадратом** за модулем `q`.

Тут непарність `p` спрацьовує напряму. Оскільки `p` непарне, `p + 1` парне, і показник `(p+1)/2` цілий. Помножмо `2ᵖ ≡ 1` на `2`:

```
2 ≡ 2 · 2ᵖ = 2^(p+1) = (2^((p+1)/2))²   (mod q)
```

Права частина — точний квадрат. Отже двійка має квадратний корінь за модулем `q`, і то навіть явний, `2^((p+1)/2)`. Мовою [символа Лежандра](root:math-number-theory/quadratic-residues) — він дорівнює `+1`, коли число є ненульовим квадратом за модулем `q`, і `−1`, коли ні, — це записують `(2|q) = +1`.

Лишилося перекласти «`(2|q) = +1`» на клас `q` за модулем `8`. Цей переклад робить **друге доповнення до квадратичного закону взаємності**:

```
(2|q) = +1   ⟺   q ≡ ±1 (mod 8)
```

Доведімо його рахунком — [лема Гаусса](root:math-number-theory/quadratic-residues) дає найкоротший шлях. Лема каже: `(a|q) = (−1)^μ`, де `μ` — це скільки серед чисел `a·1, a·2, …, a·(q−1)/2` мають найменший додатний лишок понад `q/2`. Візьмімо `a = 2`. Числа `2·1, 2·2, …, 2·(q−1)/2` — це `2, 4, …, q−1`: усі парні й усі менші за `q`, тож кожне вже дорівнює своєму лишку. Понад `q/2` серед них ті, де `2k > q/2`, тобто `k > q/4`. Значить,

```
μ = (q−1)/2 − ⌊q/4⌋
```

Порахуймо парність `μ`, розписавши `q = 8m + r` по чотирьох можливих непарних лишках `r`:

```
q = 8m+1:  μ = 4m   − 2m       = 2m      парне    →  (2|q) = +1
q = 8m+3:  μ = 4m+1 − 2m       = 2m+1    непарне  →  (2|q) = −1
q = 8m+5:  μ = 4m+2 − (2m+1)   = 2m+1    непарне  →  (2|q) = −1
q = 8m+7:  μ = 4m+3 − (2m+1)   = 2m+2    парне    →  (2|q) = +1
```

Двійка виявляється лишком рівно при `q ≡ 1` і `q ≡ 7 ≡ −1 (mod 8)` — тобто при `q ≡ ±1 (mod 8)`. (Те саме коротко пакується у формулу `(2|q) = (−1)^((q²−1)/8)`, парність якої і дає цей самий поділ.)

Ми вже довели, що для нашого `q` виконано `(2|q) = +1`; за щойно встановленою рівносильністю звідси `q ≡ ±1 (mod 8)`. Другу умову доведено.

> 🔧 **Навіщо це.** Кожна умова — окреме сито. Перша, `q ≡ 1 (mod 2p)`, лишає одну частку `1/φ(2p)` усіх простих; друга, `q ≡ ±1 (mod 8)`, вирізає ще половину з того, що вціліло. Дільник, приречений на такий вузький клас, знайти (або впевнено виключити) незрівнянно легше, ніж дільник довільного числа тієї ж величини. Уся практична сила чисел Мерсенна в пробному діленні тримається на цих двох конгруенціях.

## Приклад: 2047 = 23 · 89

Найменше складене число Мерсенна з простим показником (`p = 11`) — зручний полігон: обидва його прості множники мусять сидіти у формі, і сидять.

```
p = 11,   2p = 22
23 = 1·22 + 1  →  23 ≡ 1 (mod 22)      23 = 2·8 + 7   →  23 ≡ −1 (mod 8)
89 = 4·22 + 1  →  89 ≡ 1 (mod 22)      89 = 11·8 + 1  →  89 ≡  1 (mod 8)
```

Перевірмо і явний корінь двійки з доведення. Тут `(p+1)/2 = 6`, тож коренем має бути `2⁶ = 64`:

```
64 ≡ 18 (mod 23),   18² = 324 = 14·23 + 2    →   18² ≡ 2 (mod 23)
64² = 4096 = 46·89 + 2                        →   64² ≡ 2 (mod 89)
```

Двійка справді квадрат за обома модулями. Нарешті — порядок двійки, серце першої умови. Оскільки `2¹¹ = 2048 = 23·89 + 1`:

```
2¹¹ = 2047 + 1 ≡ 1  (mod 23)  і  (mod 89)
```

а менших показників, крім `1`, у дільниках `11` немає — тому порядок двійки за кожним із `23` і `89` дорівнює рівно `11 = p`, як і має бути.

## Обидві умови разом: два класи за модулем 8p

Порізно кожна умова корисна, але справжня сила в їхньому поєднанні. Умова `q ≡ 1 (mod 2p)` фіксує `q` за модулем `2p`, умова `q ≡ ±1 (mod 8)` додає інформацію за модулем `8`. Оскільки `p` непарне, найменше спільне кратне `lcm(2p, 8) = 8p`, тож пара умов приколює `q` до класів за модулем `8p`.

Скільки цих класів? Лишків `r` за модулем `8p`, що дають `r ≡ 1 (mod 2p)`, рівно чотири (бо `8p / 2p = 4`):

```
r = 1,   2p + 1,   4p + 1,   6p + 1   (mod 8p)
```

Тепер накладімо друге сито — лишити ті `r`, що `≡ ±1 (mod 8)`. Оскільки `p` непарне, `4p ≡ 4 (mod 8)`, а `{2p, 6p}` за модулем `8` дають `{2, 6}` у якомусь порядку; тому четвірка лишків за модулем `8` — це завжди `{1, 3, 5, 7}`. З них `±1` — рівно два, `1` і `7`. Отже **з чотирьох класів завжди виживають рівно два**: клас `≡ 1` і той із `2p+1`, `6p+1`, який дає `≡ 7 (mod 8)`.

Для `M₃₁` (тут `p = 31`, `8p = 248`) це виглядає так:

```
чотири класи ≡ 1 (mod 62):    1,   63,   125,   187   (mod 248)
кожен за модулем 8:           1,    7,     5,     3
лишаються (≡ ±1 mod 8):       1,   63
```

Отже простий дільник `M₃₁` зобов'язаний бути `≡ 1` або `≡ 63 (mod 248)` — і більше ніяким.

![Форма дільника як сито: три бруски, що звужуються — усі 4792 прості до кореня з M₃₁, потім 157 із них у класі ≡1 (mod 62), потім 84 у класах ≡1 або 63 (mod 248)](/root/sci/math-number-theory/mersenne-primes/img/sieve.svg)

*Дві конгруенції на дільник послідовно зрізають перебір: перша лишає прості одного класу за модулем `2p`, друга — половину з них; для `M₃₁` від 4792 кандидатів лишається 84.*

## Як Ейлер довів M₃₁ вручну

Тепер віддача. `M₃₁ = 2³¹ − 1 = 2 147 483 647`. Якби воно було складене, то мало б простий дільник не більший за корінь: `√M₃₁ ≈ 46 340.95`, тобто `q ≤ 46 340`. А кожен простий дільник, як щойно доведено, `≡ 1` або `≡ 63 (mod 248)`.

Порахуймо, скільки лишається кандидатів. Простих чисел до `46 340` усього `4792` — стільки ділень вимагав би сліпий перебір. Умова `≡ 1 (mod 62)` (це перша, `2p = 62`) лишає з них `157`. Додаток `≡ ±1 (mod 8)` зрізає майже вдвічі — до `84` простих у класах `1` і `63` за модулем `248`:

```
311,  1303,  1489,  2543,  2729,  2791,  4217,  5023,  …   (усього 84)
```

Досить перебрати саме ці прості: якби `M₃₁` ділило складене число потрібної форми, його простий дільник теж ділив би `M₃₁` і теж мав би цю форму — тобто вже стояв би у списку. Ейлер розділив `M₃₁` на кожного з `84` кандидатів; жоден не розділив націло — отже, `M₃₁` просте.

Історія тут точна й задокументована. Форму дільника `≡ 1 (mod 2p)` помітив ще Ферма (близько `1640` року, у ту саму пору, що й свою малу теорему). Додаткову умову `≡ ±1 (mod 8)` — квадратичний характер двійки — додав саме Ейлер, і, озброївшись обома, він `1772` року довів простоту `M₃₁`, повідомивши це в листі до Даніеля Бернуллі; його оптимізоване пробне ділення обходилося щонайбільше `372` діленнями на числа потрібної форми, а справді необхідних — на прості цієї форми — лишалося тільки `84`. Це `M₃₁` протрималося найбільшим відомим простим числом `95` років, аж до `1867`-го — рекорд, здобутий пером на самій лише формі дільника.

## Миттєвий успіх сита: як знайти дільник M₂₃ за один крок

Якщо для доведення простоти `M₃₁` Ейлеру довелося перевірити всі 84 кандидати, то у випадку складеного числа форма дільника нерідко викриває дільник з першої ж спроби.

Розгляньмо число `M₂₃ = 2²³ − 1 = 8 388 607`. Показник `p = 23` є простим числом. Перевіримо, які дільники дозволяє теорема:

```
p = 23,   2p = 46,   8p = 184
чотири класи ≡ 1 (mod 46):    1,   47,   93,   139   (mod 184)
кожен за модулем 8:           1,    7,    5,     3
лишаються (≡ ±1 mod 8):       1,   47   (mod 184)
```

Найменшим можливим кандидатом на дільник серед чисел більше за одиницю є число `q = 47` (оскільки `47 = 2 · 23 + 1`, воно належить до класу `47 mod 184` і є простим).

Перевіримо, чи ділить воно `M₂₃`. Для цього досить обчислити `2²³ (mod 47)` методом послідовного піднесення до квадрата:

```
2⁵  = 32 ≡ −15           (mod 47)  [бо 32 = 47 − 15]
2¹⁰ = (−15)² = 225       (mod 47)  [квадрат попереднього]
    = 4 · 47 + 37 ≡ −10  (mod 47)  [бо 37 = 47 − 10]
2²⁰ = (−10)² = 100       (mod 47)  [квадрат попереднього]
    = 2 · 47 + 6 ≡ 6     (mod 47)  [ділення з остачею]
2²³ = 2²⁰ · 2³ = 6 · 8   (mod 47)  [множення на 2³ = 8]
    = 48 = 47 + 1 ≡ 1    (mod 47)  [остача дорівнює 1]
```

Оскільки `2²³ ≡ 1 (mod 47)`, різниця `2²³ − 1` ділиться на 47 без остачі:

```
8 388 607 = 47 · 178 481
```

Перший же перевірений кандидат виявився дільником! Число `178 481` також є простим і задовольняє ту саму форму:

```
178 481 = 3880 · 46 + 1 ≡ 1   (mod 46)
178 481 = 22310 · 8 + 1 ≡ 1   (mod 8)
178 481 = 970 · 184 + 1 ≡ 1   (mod 184)
```

Обидва множники лежать у дозволених класах лишків, а форма дільника скоротила пошук до єдиного пробного кроку.

## Крайовий випадок: чому теорема вимагає непарності p

У формулюванні теореми скрізь зазначено: `p` — непарне просте число. Погляньмо, що станеться з єдиним парним простим числом `p = 2`.

Для `p = 2` маємо число `M₂ = 2² − 1 = 3`. Його єдиним простим дільником є саме число `q = 3`. Перевіримо обидві умови:

1. `q ≡ 1 (mod 2p)` означало б `3 ≡ 1 (mod 4)`, що хибно, адже `3 ≡ 3 (mod 4)`.
2. `q ≡ ±1 (mod 8)` означало б `3 ≡ 1` або `3 ≡ 7 (mod 8)`, що також хибно, адже `3 ≡ 3 (mod 8)`. Символ Лежандра `(2|3) = −1`, тобто двійка не є квадратичним лишком за модулем 3.

Причина збою очевидна з кроків доведення:

- У першій умові ми спиралися на те, що `p` і `2` взаємно прості (`gcd(2, p) = 1`). Якщо `p = 2`, то `gcd(2, 2) = 2 ≠ 1`. З того, що `q − 1` ділиться на 2 і на 2, випливає лише подільність на 2, а не на `2 · 2 = 4`.
- У другій умові показник `(p + 1)/2` для `p = 2` дає `(2 + 1)/2 = 3/2` — неціле число. Тотожність `2 = (2^((p+1)/2))²` перестає існувати в цілих числах, і двійка не зобов'язана бути квадратом за модулем `q`.

Отже, вимога непарності `p ≥ 3` є не технічною деталлю, а фундаментом усієї конструкції.

## Кратні дільники та прості числа Віферіха

Чи може число Мерсенна містити квадрат простого числа, тобто чи можливе `q² | Mₚ`?

Припустімо, що `2ᵖ ≡ 1 (mod q²)` для деякого простого дільника `q`. Знайдемо наслідки для мультиплікативного порядку двійки за модулем `q²`:

```
d — порядок двійки за модулем q²
d | p                              [бо 2ᵖ ≡ 1 (mod q²)]
p просте, d > 1  ⟹  d = p          [виключаємо d = 1, бо 2¹ ≠ 1]
d | φ(q²)                          [за теоремою Ейлера]
φ(q²) = q(q − 1)                   [значення функції Ейлера]
p | q(q − 1)                       [підстановка d = p]
```

Оскільки `q | (2ᵖ − 1)`, дільник `q` є непарним простим, більшим за 2. Якщо `p | q`, то оскільки `p` і `q` прості, маємо `p = q`, звідки `p | (2ᵖ − 1)`, що неможливо (жодне `p` не ділить `2ᵖ − 1` за малою теоремою Ферма, бо `2ᵖ ≡ 2 ≠ 1 mod p`). Отже `gcd(p, q) = 1`.

З `p | q(q − 1)` та `gcd(p, q) = 1` неминуче випливає:

```
p | (q − 1)
```

Показник `q − 1` є кратним порядку `p`. А це означає, що конгруенція виконується і для `q − 1`:

```
2^(q−1) ≡ 1  (mod q²)
```

Просте число `q`, яке задовольняє конгруенцію `2^(q−1) ≡ 1 (mod q²)`, називається **простим числом Віферіха** (Wieferich prime).

Такі числа трапляються надзвичайно рідко. Серед усіх простих чисел, перевірених комп'ютерними розрахунками аж до `2 · 10¹⁷`, знайдено лише два простих числа Віферіха:

```
q₁ = 1093,      q₂ = 3511
```

Жодне з них не ділить жодного відомого числа Мерсенна. Це привело математиків до гіпотези: **кожне число Мерсенна є вільним від квадратів** (square-free), тобто в його канонічному розкладі всі прості множники входять лише в першому степені.

## Від ручного рахунку до алгоритму Trial Factoring у GIMPS

В епоху суперкомп'ютерів форма дільника не втратила актуальності — вона перетворилася на перший і найшвидший етап фільтрації в розподіленому проєкті GIMPS.

Тест Люка–Лемера має складність порядку `O(p² log p)` і вимагає днів або тижнів обчислень для показників із десятками мільйонів цифр. Проте якщо число `Mₚ` є складеним і має малий дільник, його можна виявити за частки секунди, не запускаючи повний тест.

Алгоритм сита (Trial Factoring) працює так:

1. Для заданого непарного простого `p` генеруються числа вигляду `q = 2kp + 1` для послідовних `k = 1, 2, 3, …`
2. Відкидаються ті `q`, для яких `q ≢ ±1 (mod 8)`.
3. Перевіряється, чи є кандидат `q` простим числом.
4. Якщо `q` просте, обчислюється лишок `2ᵖ mod q` за допомогою швидкого бінарного піднесення до степеня. Обчислення ведеться за малим модулем `q` (що вміщується у звичайне 64-бітне машинне слово або регістр GPU), тому воно вимагає лише `O(log p)` операцій множення машинних слів.
5. Якщо `2ᵖ mod q == 1`, знайдено точний дільник: `q | Mₚ`. Число оголошується складеним, і його перевірка миттєво завершується.

Завдяки тому, що кандидати обмежені лише двома класами лишків за модулем `8p`, сучасні графічні процесори (GPU) здатні перевіряти мільярди таких кандидатів за кілька секунд. Цей етап фільтрує від 60% до 70% усіх кандидатів ще до того, як вони потраплять на основний конвеєр тесту Люка–Лемера.
