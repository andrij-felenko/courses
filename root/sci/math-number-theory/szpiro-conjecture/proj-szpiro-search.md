# ⚙️ Обчислювальний аналіз та пошук екстремальних кривих

Алгоритми обчислювальної числової арифметики розраховують інваріанти еліптичних кривих — дискримінант `Δ_E`, провідник `N_E` та індекс Шпіро `σ(E)` — через сканування сімейств кривих Фрея для автоматизованого пошуку аномальних екземплярів із високим значенням індексу Шпіро.

Для аналізу співвідношення між дискримінантом та провідником еліптичної кривої `E` над `Q` використовується коефіцієнт (індекс) Шпіро:

```
σ(E) = log |Δ_E| / log N_E
```

Обчислювальне завдання полягає в автоматизованому генеруванні коефіцієнтів еліптичних кривих, знаходженні мінімальної моделі Вейєрштрасса, факторизації дискримінатора та розрахунку локальних показників провідника у точках поганої редукції.

### 1. Загальний обчислювальний алгоритм та інваріанти Вейєрштрасса

Процес обчислення інваріантів Шпіро для довільної еліптичної кривої складається з чотирьох основних етапів.

#### Етап 1: Зведення до мінімальної моделі Вейєрштрасса
Вихідне рівняння Вейєрштрасса має загальний вигляд:

```
y² + a₁ · x · y + a₃ · y = x³ + a₂ · x² + a₄ · x + a₆
```

де коефіцієнти `a₁, a₂, a₃, a₄, a₆` є цілими числами. Обчислюються допоміжні інваріанти Вейєрштрасса `b₂, b₄, b₆, b∸`:

```
b₂ = a₁² + 4 a₂
b₄ = 2 a₄ + a₁ a₃
b₆ = a₃² + 4 a₆
b∸ = a₁² a₆ + 4 a₂ a₆ - a₁ a₃ a₄ + a₂ a₃² - a₄²
```

З них будуються канонічні інваріанти `c₄` та `c₆`:

```
c₄ = b₂² - 24 b₄
c₆ = -b₂³ + 36 b₂ b₄ - 216 b₆
```

Дискримінант обчислюється за фундаментальною формулою:

```
1728 · Δ = c₄³ - c₆²
```

Якщо модель не є мінімальною над `Z` у простому числі `p`, виконується заміна змінних `x = u² x' + r` та `y = u³ y' + s u² x' + t`, де `u` є дільником `c₄` та `c₆`. Якщо не привести модель до мінімального вигляду, логарифм дискримінанта буде штучно завищеним, що призведе до хибного розрахунку індексу Шпіро.

#### Етап 2: Локальний аналіз редукції за алгоритмом Тейта
Для кожного простого числа `p`, що ділить дискримінант `Δ_E`, виконується алгоритм Тейта (Tate's algorithm). Він послідовно визначає тип редукції за шкалою Кодаіри:
- `I₀`: добра редукція (`v_p(N_E) = 0`).
- `I_n` (`n ≥ 1`): мультиплікативна редукція (`v_p(N_E) = 1`). Якщо `c₄` не ділиться на `p`, редукція є напівстабільною.
- `II`, `III`, `IV`, `I_n*`, `IV*`, `III*`, `II*`: адитивна редукція. Для непарних простих чисел `p ≥ 5` показник провідника дорівнює `v_p(N_E) = 2`. Для `p = 2` та `p = 3` показники обчислюються через дерево розділення Тейта і можуть досягати `v₂(N_E) ≤ 8` та `v₃(N_E) ≤ 5`.

#### Етап 3: Обчислення провідника `N_E` та індексу `σ(E)`
Провідник виражається як `N_E = ∏ p^(v_p(N_E))`. Після цього обчислюється логарифмічне відношення `σ(E) = log |Δ_E| / log N_E`.

### 2. Спеціалізований алгоритм для кривих Фрея

Для еліптичних кривих Фрея `y² = x · (x - a) · (x + b)`, побудованих за взаємно простими натуральними числами `a` та `b` (`a + b = c`), обчислення інваріантів значно спрощується:

1. Перевірити умову взаємної простоти `нсд(a, b) = 1` та обчислити `c = a + b`.
2. Дискримінант обчислюється прямо за формулою: `Δ = 16 · (a · b · c)²`.
3. Радикал обчислюється як добуток унікальних простих дільників: `rad(a · b · c) = ∏ p`.
4. Провідник напівстабільної кривої дорівнює `N_E = rad(a · b · c)` (або `2 · rad(a · b · c)` за наявності парного додатка).
5. Обчислити індекс Шпіро `σ(E) = log |Δ| / log N_E`.

Нижче наведено практичну реалізацію цього алгоритму сканування мовою Python та мовою C++.

```py
import math
from functools import reduce

def prime_factors(n):
    """Повертає множину унікальних простих дільників числа n."""
    factors = set()
    d = 2
    temp = abs(n)
    while d * d <= temp:
        if temp % d == 0:
            factors.add(d)
            while temp % d == 0:
                temp //= d
        d += 1
    if temp > 1:
        factors.add(temp)
    return factors

def radical(n):
    """Обчислює радикал натурального числа (добуток унікальних простих дільників)."""
    factors = prime_factors(n)
    return reduce(lambda x, y: x * y, factors, 1)

def analyze_frey_curve(a, b):
    """Обчислює дискримінант, провідник та індекс Шпіро для кривої Фрея y² = x(x-a)(x+b)."""
    if math.gcd(a, b) != 1:
        return None
    c = a + b
    abc = a * b * c
    
    # Дискримінант кривої Фрея
    disc = 16 * (abc ** 2)
    
    # Радикал добутку abc
    rad_abc = radical(abc)
    
    # Оцінка провідника (з урахуванням оцінки для p=2)
    conductor = rad_abc
    if abc % 2 != 0:
        conductor *= 2
        
    sigma = math.log(abs(disc)) / math.log(conductor)
    
    return {
        'a': a, 'b': b, 'c': c,
        'disc': disc,
        'rad': rad_abc,
        'conductor': conductor,
        'sigma': sigma
    }

def scan_frey_range(max_a, max_b, min_sigma=1.1):
    """Сканує діапазон a та b у пошуках кривих із високим індексом Шпіро."""
    results = []
    for a in range(1, max_a):
        for b in range(a + 1, max_b):
            res = analyze_frey_curve(a, b)
            if res and res['sigma'] >= min_sigma:
                results.append(res)
    results.sort(key=lambda x: x['sigma'], reverse=True)
    return results

if __name__ == '__main__':
    # Приклад обчислення для відомої трійки Решата (1 + 4374 = 4375)
    rec = analyze_frey_curve(1, 4374)
    print(f"Трійка 1 + 4374 = 4375:")
    print(f"  Дискримінант log|Δ| = {math.log(rec['disc']):.4f}")
    print(f"  Провідник log N_E = {math.log(rec['conductor']):.4f}")
    print(f"  Індекс Шпіро σ(E) = {rec['sigma']:.4f}")
```
```cpp
#include <iostream>
#include <vector>
#include <cmath>
#include <numeric>
#include <set>
#include <algorithm>

// Обчислення унікальних простих дільників
std::set<long long> get_prime_factors(long long n) {
    std::set<long long> factors;
    long long temp = std::abs(n);
    for (long long d = 2; d * d <= temp; ++d) {
        if (temp % d == 0) {
            factors.insert(d);
            while (temp % d == 0) {
                temp /= d;
            }
        }
    }
    if (temp > 1) {
        factors.insert(temp);
    }
    return factors;
}

// Обчислення радикала
long long compute_radical(long long n) {
    auto factors = get_prime_factors(n);
    long long rad = 1;
    for (auto p : factors) {
        rad *= p;
    }
    return rad;
}

struct CurveResult {
    long long a, b, c;
    long long rad;
    double sigma;
};

// Аналіз кривої Фрея для пари (a, b)
bool analyze_curve(long long a, long long b, CurveResult& out) {
    if (std::gcd(a, b) != 1) return false;
    long long c = a + b;
    long long abc = a * b * c;
    
    long long rad_abc = compute_radical(abc);
    long long conductor = rad_abc;
    if (abc % 2 != 0) conductor *= 2;
    
    // Дискримінант |Δ| = 16 * (abc)^2
    double log_disc = std::log(16.0) + 2.0 * std::log(std::abs((double)abc));
    double log_cond = std::log((double)conductor);
    
    out.a = a;
    out.b = b;
    out.c = c;
    out.rad = rad_abc;
    out.sigma = log_disc / log_cond;
    return true;
}

int main() {
    CurveResult res;
    if (analyze_curve(1, 4374, res)) {
        std::cout << "Frey Curve for 1 + 4374 = 4375:" << std::endl;
        std::cout << "  Radical rad(abc): " << res.rad << std::endl;
        std::cout << "  Szpiro Index sigma(E): " << res.sigma << std::endl;
    }
    return 0;
}
```

### 3. Аналіз кривих із бази даних Кремона

База даних Ендрю Кремони (Cremona Database) містить повну класифікацію еліптичних кривих над `Q` для всіх провідників `N_E ≤ 500000`.

Простежимо інваріанти для найпростішої кривої з найменшим можливим провідником `N_E = 11` (крива Кремони `11a1`):

```
11a1: y² + y = x³ - x² - 10 x - 20
```

Для цієї кривої інваріанти Вейєрштрасса дорівнюють `c₄ = 496` та `c₆ = 20008`, а її дискримінант становить `Δ_E = -11⁵ = -161051`.

Обчислимо індекс Шпіро для кривої `11a1`:

```
log |Δ_E| = log(161051) ≈ 11.989
log N_E = log(11) ≈ 2.398
σ(E) = 11.989 / 2.398 = 5.000
```

Бачимо, що навіть для найпростішої кривої `11a1` індекс Шпіро дорівнює точно 5.0, що демонструє, як швидко накопичується степінь дискримінанта на невеликих провідниках.

### 4. Оптимізація факторизації та довгої арифметики

При автоматизованому пошуку екстремальних еліптичних кривих у великих діапазонах `a, b > 10¹²` виникають два ключові технічні бар'єри:

1. **Алгоритмічна складність факторизації.**
   Простий перебір дільників `O(√n)` стає неприйнятно повільним при `n > 10¹²`. Для швидкого розкладу великих чисел `a · b · c` використовується поєднання алгоритму розкладу Полларда (Pollard's rho algorithm) та методу факторизації на еліптичних кривих Ленстри (ECM). Оскільки для обчислення радикала `rad(abc)` потрібні лише прості множники без урахування їхніх степенів, алгоритм зупиняє розщеплення, як тільки перевірено простоту за допомогою ймовірнісного тесту Міллера-Рабіна.

2. **Переповнення типів при обчисленні факторіальних добутків.**
   При обчисленні `abc = a · b · c` для чисел порядку `10⁹` добуток `(abc)²` досягає значень `10⁵⁴`, що виходить за межі стандартних 64-бітних цілих типів (`long long` у C++ вміщує значення до `9 · 10¹⁸`). Для запобігання переповненню обчислення логарифмів слід виконувати у логарифмічній формі:
   ```
   log |Δ| = log(16) + 2 · (log a + log b + log c)
   ```
   Це дозволяє сканувати велетенські трійки без використання громіздких бібліотек довгої арифметики.

### 5. Інтеграція із пакетами комп'ютерної алгебри (SageMath)

У дослідницькій практиці обчислення інваріантів Шпіро для загальних кривих зручно виконувати у системі комп'ютерної алгебри SageMath. Нижче наведено приклад скрипту для авто-аналізу довільної моделі:

```python
# SageMath скрипт для обчислення індексу Шпіро
E = EllipticCurve([0, -1, 1, -10, -20])  # Крива 11a1
disc = E.discriminant()
cond = E.conductor()
sigma = log(abs(disc)) / log(cond)
print(f"Δ_E = {disc}, N_E = {cond}, σ(E) = {float(sigma):.4f}")
```

Система SageMath автоматично реалізує алгоритм Тейта для локальної мінімізації та аналізу особливих шарів над `Z_p`, що виключає ризик помилок при ручному розрахунку адитивних редукцій.

### 6. Помилки інтерпретації та обчислювальні пастки

При вивченні результатів обчислювального пошуку слід уникати типових методологічних помилок:

1. **Сплески індексу на малих провідниках.**
   Для еліптичних кривих із малим провідником (наприклад, `N_E < 500`) значення `log N_E` у знаменнику є малим. У цьому діапазоні спостерігаються значні локальні відхилення, де індекс Шпіро сягає `σ(E) ≈ 7..8`. Це не спростовує гіпотезу Шпіро, оскільки вона є **асимптотичним твердженням**:
   ```
   limsup_{N_E → ∞} σ(E) ≤ 6
   ```
   Гіпотеза допускає існування скінченної кількості кривих із вищими значеннями індексу для малого провідника, але стверджує непорушність верхньої межі 6 при зростанні провідника до нескінченності.

2. **Аналіз частотного розподілу у базах даних.**
   Масштабне обчислювальне дослідження бази даних Кремони свідчить, що середня величина індексу Шпіро становить `σ_avg ≈ 1.5..2.5`, а частка кривих із `σ(E) > 4` становить менше 0.001%. Це підтверджує надзвичайну рідкість аномальних арифметичних конфігурацій і служить вагомим емпіричним доказом справедливості межі 6.
