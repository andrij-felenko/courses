# 🧮 Математичне доведення повноти параметризації

Геометричний метод хорди демонструє, як отримати раціональні координати точок одиничного кола, використовуючи пряму з раціональним нахилом. Проте, для повної математичної строгості необхідно довести, що цей метод генерує абсолютно ВСІ можливі раціональні точки на колі, і що жодна раціональна точка не може бути пропущена цією побудовою.

Нехай Q = (x, y) — довільна раціональна точка на одиничному колі x² + y² = 1. Наше завдання полягає у тому, щоб довести, що існує раціональне число t таке, що точка Q отримується через перетин прямої з нахилом t, проведеної через точку P = (-1, 0), та кола.

Спершу розглянемо виняток: нехай Q збігається з P, тобто Q = (-1, 0). Для цієї єдиної точки ми не можемо визначити нахил січної в класичному сенсі (це буде дотична з нескінченним нахилом, тобто вертикальна пряма x = -1). Тому ми заздалегідь виключаємо точку P з нашого генератора. Метод параметризації охоплює всі точки кола, КРІМ (-1, 0).

Тепер припустимо, що Q = (x, y) — раціональна точка і Q не дорівнює P. Тоді x не дорівнює -1. Проведемо пряму лінію через точки P(-1, 0) та Q(x, y). Ми можемо знайти кутовий коефіцієнт (нахил) цієї прямої, який ми позначимо як t. 

Формула нахилу прямої, що проходить через дві точки (x₁, y₁) та (x₂, y₂), є такою:
t = (y₂ - y₁) / (x₂ - x₁)

Підставляючи координати P та Q, маємо:
t = (y - 0) / (x - (-1)) = y / (x + 1)

Оскільки точка Q є раціональною, то x та y є раціональними числами. Оскільки раціональні числа утворюють поле (тобто замкнені щодо додавання, віднімання, множення та ділення на ненульові числа), результат ділення раціонального числа y на раціональне число (x + 1) також гарантовано є раціональним числом. 

Отже, ми довели, що для БУДЬ-ЯКОЇ раціональної точки Q на колі нахил січної t обов'язково є раціональним числом. 

Тепер розглянемо зворотний бік: ми вже знаємо, що якщо t — раціональне число, алгебраїчне розв'язання системи рівнянь:
1) x² + y² = 1
2) y = t · (x + 1)
дає координати:
x = (1 - t²) / (1 + t²)
y = 2t / (1 + t²)

Очевидно, що якщо t є раціональним числом, то (1 - t²), (1 + t²) та 2t також є раціональними. Оскільки (1 + t²) ніколи не дорівнює нулю для дійсних t, результати ділення x та y також будуть раціональними числами. 

Таким чином, ми встановили бієкцію (взаємно однозначну відповідність) між множиною всіх раціональних чисел t та множиною всіх раціональних точок Q = (x, y) на одиничному колі (за винятком точки P). Кожне раціональне t генерує унікальну раціональну точку, і кожна раціональна точка Q відповідає унікальному раціональному t. 

Ця строга логіка доводить повноту методу: метод хорди не пропустить жодної раціональної точки. Це фундаментальне твердження гарантує, що отримані нами формули для a = m² - n², b = 2mn, c = m² + n² описують ВСІ можливі Піфагорові трійки. Математична повнота тут не є просто технічною деталлю, це суть методу, яка робить геометричний аналіз еквівалентним вичерпному перебору розв'язків.
