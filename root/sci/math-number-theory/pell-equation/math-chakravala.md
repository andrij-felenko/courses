# 🧮 Циклічний метод Чукравала та тотожність Брахмагупти

Математичний метод Чукравала (санскр. *Chakravala* — циклічний або коловий метод, від *Chakra* — колесо, цикл) є фундаментальним алгебраїчним алгоритмом для знаходження найменшого додатного цілочисельного розв'язку (фундаментального розв'язку) квадратичного діофантового рівняння Пелля:

```
x² - d·y² = 1
```

де параметр `d` є додатним цілим числом, яке не є точним квадратом.

Алгоритм створено індійськими математиками Джаядевою (XI століття) та Бхаскарою II (1150 р.) на основі тотожності композиції Брахмагупти (628 р.). Метод поєднує алгебраїчну структуру композиції квадратичних форм з цілочисельною оптимізацією норми на кожному кроці циклу, забезпечуючи швидку збіжність до цілочисельного розв'язку.

---

## 1. Алгебраїчна тотожність Брахмагупти (Samasa / Bhavana)

У 628 році індійський математик Брахмагупта у праці «Брахма-спхута-сіддханта» відкрив фундаментальну тотожність композиції квадратичних форм. Введемо поняття **трійки Брахмагупти**: впорядкована трійка цілих чисел `(a, b, k)` називається трійкою Брахмагупти для параметра `d`, якщо вона задовольняє квадратичне співвідношення:

```
a² - d·b² = k
```

де ціле число `k` називається нормою або залишком трійки. Якщо маємо дві трійки `(a₁, b₁, k₁)` та `(a₂, b₂, k₂)`, тотожність Брахмагупти дозволяє алгебраїчно сконструювати нову трійку `(a₃, b₃, k₃)`, норма якої дорівнює добутку вихідних норм: `k₃ = k₁·k₂`.

### Алгебраїчна природа в кільці Z[√d] та строгий вивід

Розглянемо квадратичне розширення кільця цілих чисел `Z[√d] = {a + b·√d | a, b ∈ Z}`. Для кожного елемента `α = a + b·√d` визначимо операцію алгебраїчного спряження `ᾱ = a - b·√d`. Алгебраїчна норма `N(α)` визначається як добуток елемента на його спряження:

```text
N(α) = α · ᾱ = (a + b·√d)·(a - b·√d) = a² - d·b²
```

Норма володіє фундаментальною властивістю мультиплікативності: для будь-яких двох елементів `α, β ∈ Z[√d]` виконується рівність `N(α · β) = N(α) · N(β)`.

Обчислимо добуток двох довільних елементів `α₁ = a₁ + b₁·√d` та `α₂ = a₂ + b₂·√d`:

```text
α₁ · α₂ = (a₁ + b₁·√d)·(a₂ + b₂·√d) = (a₁·a₂ + d·b₁·b₂) + (a₁·b₂ + a₂·b₁)·√d
```

Позначимо коефіцієнти добутку як:

```text
a₃ = a₁·a₂ + d·b₁·b₂
b₃ = a₁·b₂ + a₂·b₁
```

Виведемо строгу алгебраїчну тотожність, підставивши вирази для `a₃` та `b₃` у квадратичну форму норми:

```text
a₃² - d·b₃²
= (a₁·a₂ + d·b₁·b₂)² - d·(a₁·b₂ + a₂·b₁)²                                    [підстановка значень a₃ та b₃]
= a₁²·a₂² + 2·d·a₁·a₂·b₁·b₂ + d²·b₁²·b₂² - d·(a₁²·b₂² + 2·a₁·a₂·b₁·b₂ + a₂²·b₁²) [розкриття квадратів суми]
= a₁²·a₂² + 2·d·a₁·a₂·b₁·b₂ + d²·b₁²·b₂² - d·a₁²·b₂² - 2·d·a₁·a₂·b₁·b₂ - d·a₂²·b₁² [розкриття дужок при множенні на d]
= a₁²·a₂² + d²·b₁²·b₂² - d·a₁²·b₂² - d·a₂²·b₁²                                [взаємне скорочення подвоєних добутків]
= a₁²·(a₂² - d·b₂²) - d·b₁²·(a₂² - d·b₂²)                                     [групування та винесення спільних множників]
= (a₁² - d·b₁²)·(a₂² - d·b₂²)                                                [винесення спільної дужки (a₂² - d·b₂²)]
= k₁·k₂                                                                      [заміна вихідними нормами k₁ та k₂]
```

Отже, пряма тотожність Брахмагупти (композиція Самаса) повністю доведена:

```
(a₁·a₂ + d·b₁·b₂)² - d·(a₁·b₂ + a₂·b₁)² = (a₁² - d·b₁²)·(a₂² - d·b₂²)
```

Якщо при перемноженні взяти спряжений другий елемент `α₂̄ = a₂ - b₂·√d`, ми отримуємо зворотну (парну) тотожність Брахмагупти:

```text
a₄² - d·b₄²
= (a₁·a₂ - d·b₁·b₂)² - d·(a₁·b₂ - a₂·b₁)²                                    [підстановка з від'ємним знаком]
= a₁²·a₂² - 2·d·a₁·a₂·b₁·b₂ + d²·b₁²·b₂² - d·(a₁²·b₂² - 2·a₁·a₂·b₁·b₂ + a₂²·b₁²) [розкриття квадратів різниці]
= a₁²·a₂² + d²·b₁²·b₂² - d·a₁²·b₂² - d·a₂²·b₁²                                [взаємне скорочення доданків]
= (a₁² - d·b₁²)·(a₂² - d·b₂²)                                                [факторизація]
= k₁·k₂                                                                      [підстановка значень k₁ та k₂]
```

Це доводить, що множина трійок `(a, b, k)` утворює замкнену напівгрупу відносно операції бінарної композиції.

## 2. Ітераційний крок та трансформування трійок Чукравала

Нехай на поточному кроці алгоритму ми маємо трійку цілих чисел `(a, b, k)`, для якої виконується рівність `a² - d·b² = k` при `k ≠ 0`.

Розглянемо допоміжну тривіальну трійку `(m, 1, m² - d)`, побудовану для довільного цілого параметра `m`. Ця трійка очевидно задовольняє рівняння:

```
m² - d·1² = m² - d
```

Застосуємо тотожність Брахмагупти до вихідної трійки `(a, b, k)` та допоміжної трійки `(m, 1, m² - d)`:

```text
(a·m + d·b)² - d·(a + b·m)²
= (a² - d·b²)·(m² - d)      [застосування тотожності Самаса]
= k · (m² - d)              [підстановка початкової норми k]
```

Поділимо обидві частини отриманого рівняння на `k²`:

```text
((a·m + d·b) / |k|)² - d·((a + b·m) / |k|)²
= (k · (m² - d)) / k²       [ділення обох частин рівності на k²]
= (m² - d) / k              [скорочення спільного множника k]
```

Введемо нові змінні для наступної трійки `(a', b', k')`:

```
a' = (a·m + d·b) / |k|
b' = (a + b·m) / |k|
k' = (m² - d) / k
```

Ці формули визначають елементарний ітераційний крок методу Чукравала.

### Доказ цілочисельності нових коефіцієнтів (Лема Брахмагупти)

Щоб нові коефіцієнти `a'`, `b'` та новий залишок `k'` були цілими числами, необхідно і достатньо забезпечити подільність на `|k|`. Сформулюємо та доведемо фундаментальну лему.

:::lemma Лема Брахмагупти про цілочисельність
Якщо для трійки `(a, b, k)` з взаємно простими `a` та `b` підібрано ціле число `m` таке, що:

```
(a + b·m) ≡ 0 (mod |k|)
```

то величини `(a·m + d·b)` та `(m² - d)` також обов'язково націло діляться на `|k|`.
:::

**Доведення**:

1. **Цілочисельність `a'`**:
   Розглянемо добуток чисельника `(a·m + d·b)` на число `b`:

```text
(a·m + d·b)·b
= a·b·m + d·b²              [розкриття дужок]
= a·b·m + (a² - k)          [підстановка d·b² = a² - k з початкової рівності]
= a·(a + b·m) - k           [групування відносно виразу (a + b·m)]
```

   Оскільки за умовою `(a + b·m)` ділиться на `|k|`, то й `a·(a + b·m)` ділиться на `|k|`. Звідси різниця `a·(a + b·m) - k` ділиться на `|k|`.
   З рівності `a² - d·b² = k` випливає, що будь-який спільний дільник `b` та `k` мусить ділити `a²`. Оскільки `НСД(a, b) = 1`, маємо `НСД(b, k) = 1`.
   Оскільки добуток `(a·m + d·b)·b` ділиться на `|k|`, а `НСД(b, |k|) = 1`, за лемою Евкліда величина `(a·m + d·b)` націло ділиться на `|k|`. Отже, `a' ∈ Z`.

2. **Цілочисельність `k'`**:
   Розглянемо добуток чисельника `(m² - d)` на число `b²`:

```text
(m² - d)·b²
= b²·m² - d·b²              [розкриття дужок]
= b²·m² - (a² - k)          [підстановка d·b² = a² - k]
= (b·m)² - a² + k           [перегрупування доданків]
= (b·m - a)·(b·m + a) + k   [розклад різниці квадратів]
```

   Оскільки `(b·m + a)` ділиться на `|k|`, добуток `(b·m - a)·(b·m + a)` ділиться на `|k|`. Отже, вся сума `(b·m - a)·(b·m + a) + k` націло ділиться на `|k|`.
   Оскільки `НСД(b, k) = 1`, то й `НСД(b², |k|) = 1`. За лемою Евкліда величина `(m² - d)` націло ділиться на `|k|`. Отже, `k' ∈ Z`.

Лему Брахмагупти повністю доведено: єдина лінійна умова порівняння `a + b·m ≡ 0 (mod |k|)` гарантує, що вся нова трійка `(a', b', k')` складається виключно з цілих чисел.

## 3. Критерій мінімізації та теорема про скінченність алгоритму

Для виконання умови подільності `a + b·m ≡ 0 (mod |k|)` необхідно розв'язати лінійне порівняння:

```
b·m ≡ -a (mod |k|)
```

Оскільки `НСД(b, |k|) = 1`, за розширеним алгоритмом Евкліда існує мультиплікативно обернений елемент `b⁻¹ (mod |k|)`. Розв'язок порівняння утворює нескінченну арифметичну прогресію значень `m`:

```
m = m₀ + t · |k|,   t ∈ Z
```

де `m₀ = (-a · b⁻¹) mod |k|`.

### Критерій вибору оптимального m

Метод Чукравала вибирає серед усіх допустимих значень `m` таке число, яке **мінімізує абсолютну величину нової норми**:

```
|m² - d| → min
```

Геометрично це означає, що значення `m` вибирається якомога ближче до дійсного квадратного кореня `√d`. Оскільки функція `f(m) = |m² - d|` є опуклою та монотонно зростає при віддаленні `m` від `√d`, мінімум досягається для одного з двох найближчих цілих значень прогресії, розташованих ліворуч та праворуч від `√d`.

### Збіжність та скінченність методу Чукравала

Мінімізація `|m² - d|` забезпечує стрімке зменшення величини `|k'| = |m² - d| / |k|`.

:::theorem Теорема про скінченність методу Чукравала
Послідовність трійок `(aₙ, bₙ, kₙ)`, що генерується алгоритмом Чукравала, завжди за скінченну кількість кроків приводить до трійки із залишком `k ∈ {±1, ±2, ±4}`.
:::

**Ідея математичного доведення**:
Кожен крок методу Чукравала відповідає переходу між суміжними повними елементами у ланцюгу напіврегулярних неперервних дробів (найближчих цілих дробів Гурвіца). Оскільки множина цілих чисел `k`, для яких `|k| < 2√d`, є строго скінченною, а трійки `(a, b)` задають редуковані ідеали у порядку квадратичного поля `Z[√d]`, процес не може зациклитися без проходження через фундаментальну одиницю. Завдяки вибору найближчого цілого залишок швидко падає нижче `2√d` і досягає одиничних норм.

## 4. Спеціальні правила зупинки Бхаскари II

Коли на певному кроці досягається малий залишок `k ∈ {±1, ±2, ±4}`, подальше ітерування можна миттєво зупинити і отримати шуканий розв'язок з `k = 1` за допомогою прямих алгебраїчних формул композиції Самаса:

### 1. Досягнуто k = 1
Розв'язок знайдено безпосередньо: `x = a, y = b`.

### 2. Досягнуто k = -1
Підносимо трійку `(a, b, -1)` до квадрата за формулами тотожності Брахмагупти:

```text
x = a² + d·b²
y = 2·a·b
k_new = (-1)² = 1
```

### 3. Досягнуто k = ±2
Композиція трійки `(a, b, ±2)` із собою дає трійку `(a² + d·b², 2·a·b, 4)`. Поділивши обидві координати на `2`:

```text
x = (a² + d·b²) / 2
y = a·b
k_new = 4 / 4 = 1
```

Оскільки `a² - d·b² = ±2`, числа `a` та `d·b` мають однакову парність, тому сума `a² + d·b²` є парним числом, і значення `x` завжди є цілим!

### 4. Досягнуто k = ±4
- Якщо `a` є парним числом, то й `b` є парним (бо `a² - d·b² = ±4`). Поділивши обидва числа на `2`, отримуємо тривіальний перехід до `k = ±1`.
- Якщо `a` є непарним числом і `k = -4`: підносимо трійку `(a, b, -4)` до куба за формулами Самаса і ділимо координати на `8`, отримуючи цілий розв'язок для `k = -1`, квадрат якого дає розв'язок для `k = 1`. Прямі формули Бхаскари:

```text
x = a · (a² + 3·d·b²) / 8 = a · (a² + 3) / 2
y = b · (3·a² + d·b²) / 8 = b · (a² + 1) / 2
```

## 5. Детальний покроковий приклад виконання алгоритму для d = 67

Простежимо всі обчислювальні операції методу Чукравала для параметра `d = 67`.

### Крок 1. Початкова ініціалізація
Шукаємо найближчий точний квадрат до `d = 67`. Найближчим квадратом є `8² = 64`.
Покладаємо `a₀ = 8`, `b₀ = 1`.
Обчислюємо початковий залишок `k₀`:

```text
k₀ = a₀² - d·b₀² = 8² - 67·1² = 64 - 67 = -3
```

Отримуємо початкову трійку `(a₀, b₀, k₀) = (8, 1, -3)`.

### Крок 2. Перша ітерація
Шукаємо ціле число `m₁`, що задовольняє умови:
1. `8 + 1·m₁ ≡ 0 (mod 3)`  ⇒  `m₁ ≡ -8 ≡ 1 (mod 3)`. Допустимі значення: `..., 1, 4, 7, 10, 13, ...`
2. Мінімізація `|m₁² - 67|`.

Порівняємо два найближчих кандидати до `√67 ≈ 8.185`:
- При `m₁ = 7`: `|7² - 67| = |49 - 67| = 18`.
- При `m₁ = 10`: `|10² - 67| = |100 - 67| = 33`.

Вибираємо `m₁ = 7`, оскільки `18 < 33`.

Обчислюємо нову трійку `(a₁, b₁, k₁)`:

```text
a₁ = (8·7 + 67·1) / |-3| = (56 + 67) / 3 = 123 / 3 = 41
b₁ = (8 + 1·7) / |-3| = 15 / 3 = 5
k₁ = (7² - 67) / (-3) = -18 / (-3) = 6
```

Отримуємо трійку `(a₁, b₁, k₁) = (41, 5, 6)`.
Перевірка квадратичної форми:

```text
41² - 67·5²
= 1681 - 67·25   [піднесення до квадрата: 41² = 1681, 5² = 25]
= 1681 - 1675    [множення: 67 · 25 = 1675]
= 6              [віднімання: рівність відповідає k₁ = 6]
```

### Крок 3. Друга ітерація
Шукаємо ціле число `m₂`:
1. `41 + 5·m₂ ≡ 0 (mod 6)`  ⇒  `5·m₂ ≡ -41 ≡ 1 (mod 6)`. Помноживши на 5: `25·m₂ ≡ 5 (mod 6)`  ⇒  `m₂ ≡ 5 (mod 6)`.
   Допустимі значення: `..., -1, 5, 11, 17, ...`
2. Мінімізація `|m₂² - 67|`:
   - При `m₂ = 5`: `|5² - 67| = |25 - 67| = 42`.
   - При `m₂ = 11`: `|11² - 67| = |121 - 67| = 54`.

Вибираємо `m₂ = 5`.

Обчислюємо трійку `(a₂, b₂, k₂)`:

```text
a₂ = (41·5 + 67·5) / 6 = (205 + 335) / 6 = 540 / 6 = 90
b₂ = (41 + 5·5) / 6 = (41 + 25) / 6 = 66 / 6 = 11
k₂ = (5² - 67) / 6 = -42 / 6 = -7
```

Отримуємо трійку `(a₂, b₂, k₂) = (90, 11, -7)`.
Перевірка:

```text
90² - 67·11²
= 8100 - 67·121  [піднесення до квадрата: 90² = 8100, 11² = 121]
= 8100 - 8107    [множення: 67 · 121 = 8107]
= -7             [віднімання: рівність відповідає k₂ = -7]
```

### Крок 4. Третя ітерація
Шукаємо ціле число `m₃`:
1. `90 + 11·m₃ ≡ 0 (mod 7)`  ⇒  `6 + 4·m₃ ≡ 0 (mod 7)`  ⇒  `4·m₃ ≡ 1 (mod 7)`. Помноживши на 2: `8·m₃ ≡ 2 (mod 7)`  ⇒  `m₃ ≡ 2 (mod 7)`.
   Допустимі значення: `..., -5, 2, 9, 16, ...`
2. Мінімізація `|m₃² - 67|`:
   - При `m₃ = 9`: `|9² - 67| = |81 - 67| = 14`.
   - При `m₃ = 2`: `|2² - 67| = |4 - 67| = 63`.

Вибираємо `m₃ = 9`.

Обчислюємо трійку `(a₃, b₃, k₃)`:

```text
a₃ = (90·9 + 67·11) / |-7| = (810 + 737) / 7 = 1547 / 7 = 221
b₃ = (90 + 11·9) / |-7| = (90 + 99) / 7 = 189 / 7 = 27
k₃ = (9² - 67) / (-7) = 14 / (-7) = -2
```

Отримуємо трійку `(a₃, b₃, k₃) = (221, 27, -2)`.
Перевірка:

```text
221² - 67·27²
= 48841 - 67·729 [піднесення до квадрата: 221² = 48841, 27² = 729]
= 48841 - 48843  [множення: 67 · 729 = 48843]
= -2             [віднімання: рівність відповідає k₃ = -2]
```

### Крок 5. Застосування правила зупинки Бхаскари для k = -2
Оскільки досягнуто залишок `k₃ = -2`, ми зупиняємо ітерації і застосовуємо формулу композиції з подвоєнням:

```text
x = (a₃² + d·b₃²) / 2 = (221² + 67·27²) / 2 = (48841 + 48843) / 2 = 97684 / 2 = 48842
y = a₃ · b₃ = 221 · 27 = 5967
```

Фундаментальним розв'язком рівняння Пелля для `d = 67` є пара чисел:

```
x = 48842,   y = 5967
```

Фінальна перевірка розв'язку:

```text
48842² - 67·5967²
= 2385540964 - 67·35605089 [піднесення до квадратів]
= 2385540964 - 2385540963   [множення на 67]
= 1                         [точний розв'язок рівняння Пелля]
```

## 6. Тест Ферма: Розв'язання випадку d = 61 Бхаскарою II

Випадок `d = 61`, який Ферма у 1657 році запропонував як складний математичний виклик, Бхаскара II розв'язав повністю:

1. **Ініціалізація**: Найближчий квадрат до 61 — це `8² = 64` (або `7² = 49`, для якого `k = -12`). Беремо `a₀ = 8, b₀ = 1`:
   `k₀ = 8² - 61·1² = 64 - 61 = 3`. Отримуємо трійку `(8, 1, 3)`.

2. **Перша ітерація**:
   Умова подільності: `8 + 1·m₁ ≡ 0 (mod 3)` ⇒ `m₁ ≡ 1 (mod 3)`.
   Найближче число до `√61 ≈ 7.81` з цим залишком — `m₁ = 7` (`|49 - 61| = 12`).
   Обчислення коефіцієнтів:
   `a₁ = (8·7 + 61·1) / 3 = 117 / 3 = 39`
   `b₁ = (8 + 1·7) / 3 = 15 / 3 = 5`
   `k₁ = (7² - 61) / 3 = -12 / 3 = -4`
   Отримуємо трійку `(39, 5, -4)`.
   Перевірка: `39² - 61·5² = 1521 - 1525 = -4`.

3. **Прямий перехід Бхаскари через правило k = -4**:
   Оскільки `a₁ = 39` є непарним числом, піднесення до куба дає розв'язок для `k = -1`:
   `u = 39 · (39² + 3) / 2 = 39 · (1521 + 3) / 2 = 39 · 762 = 29718`
   `v = 5 · (39² + 1) / 2 = 5 · (1521 + 1) / 2 = 5 · 761 = 3805`
   Перевірка проміжного розв'язку:
   `29718² - 61·3805² = 883159524 - 61·14478025 = 883159524 - 883159525 = -1`.

4. **Піднесення розв'язку для k = -1 до квадрата**:
   За тотожністю Брахмагупти підносимо пару `(29718, 3805)` до квадрата:
   `x = 29718² + 61·3805² = 883159524 + 883159525 = 1766319049`
   `y = 2 · 29718 · 3805 = 226153980`

Отримуємо колосальний фундаментальний розв'язок для `d = 61`:

```
x = 1766319049,   y = 226153980
```

Перевіримо тотожність:

```text
1766319049² - 61·226153980²
= 3119882982845646401 - 61 · 51145622669580400 [піднесення до квадратів]
= 3119882982845646401 - 3119882982845646400     [множення на 61]
= 1                                             [точний розв'язок рівняння Пелля]
```

Це доводить неперевершену потужність, елегантність та алгоритмічну красу індійського методу Чукравала.

## 7. Порівняльний аналіз швидкості: Чукравала проти ланцюгових дробів для d = 13

Щоб усвідомити фундаментальну обчислювальну перевагу методу Чукравала над європейським методом регулярних неперервних дробів, розглянемо випадок `d = 13`.

### Метод звичайних неперервних дробів (Лагранж)
У класичному розкладі неперервного дробу неповні частки обираються за допомогою однобічного взяття цілої частини знизу: `aₙ = ⌊αₙ⌋`. Для `√13 ≈ 3.60555` розклад має вигляд:

```text
√13 = [3; (1, 1, 1, 1, 6)]
```

Довжина періоду розкладу становить `k = 5` (непарне число). Оскільки довжина періоду є непарною, підхідні дроби першого періоду дають розв'язок лише негативного рівняння:

```text
p₄ / q₄ = 18 / 5  ⇒  18² - 13·5² = 324 - 325 = -1
```

Щоб отримати розв'язок рівняння Пелля з `+1`, алгоритм неперервних дробів змушений виконати подвоєний період довжиною `2k = 10` кроків, послідовно обчисливши десять підхідних дробів:
- `p₀/q₀ = 3/1` (`3² - 13·1² = -4`)
- `p₁/q₁ = 4/1` (`4² - 13·1² = 3`)
- `p₂/q₂ = 7/2` (`7² - 13·2² = -3`)
- `p₃/q₃ = 11/3` (`11² - 13·3² = 4`)
- `p₄/q₄ = 18/5` (`18² - 13·5² = -1`)
- `p₅/q₅ = 119/33` (`119² - 13·33² = 4`)
- `p₆/q₆ = 137/38` (`137² - 13·38² = -3`)
- `p₇/q₇ = 256/71` (`256² - 13·71² = 3`)
- `p₈/q₈ = 393/109` (`393² - 13·109² = -4`)
- `p₉/q₉ = 649/180` (`649² - 13·180² = 1`)

Лише на десятому кроці досягається шуканий результат `(649, 180)`.

### Розв'язання за методом Чукравала
Індійський метод Чукравала використовує двосторонній вибір найближчого цілого та прямі алгебраїчні правила скорочення:
1. Початкова ініціалізація `a₀ = 3, b₀ = 1`:

```text
k₀ = 3² - 13·1² = 9 - 13 = -4
```

2. Оскільки одразу отримано залишок `k₀ = -4`, а число `a₀ = 3` є непарним, застосовуємо кубічне правило Бхаскари:

```text
u = a₀ · (a₀² + 3) / 2 = 3 · (9 + 3) / 2 = 3 · 6 = 18
v = b₀ · (a₀² + 1) / 2 = 1 · (9 + 1) / 2 = 1 · 5 = 5
```

Отримуємо розв'язок з нормою `-1`: `18² - 13·5² = -1`.

3. Піднесення пари `(18, 5)` до квадрата за тотожністю Брахмагупти миттєво дає шуканий фундаментальний розв'язок:

```text
x = 18² + 13·5² = 324 + 325 = 649
y = 2 · 18 · 5 = 180
```

Перевірка:

```text
649² - 13·180²
= 421201 - 13·32400  [піднесення до квадратів]
= 421201 - 421200    [множення на 13]
= 1                  [точний розв'язок]
```

Там, де європейський алгоритм ланцюгових дробів вимагав 10 послідовних рекурентних кроків, метод Чукравала знайшов розв'язок за **один-єдиний алгебраїчний крок**.

## 8. Геометрична модель у просторі Мінковського та редукція решіток

Математична природа методу Чукравала стає особливо прозорою при розгляді у псевдоевклідовому просторі `R^{1,1}` з метричним тензором `g = diag(1, -d)`. Скалярний добуток двох векторів `u = (x₁, y₁)` та `v = (x₂, y₂)` задається квадратичною формою:

```text
⟨u, v⟩ = x₁·x₂ - d·y₁·y₂
```

Квадрат псевдоевклідової норми вектора `u = (x, y)` точно відповідає значенню квадратичної форми Пелля:

```text
‖u‖² = x² - d·y²
```

Цілочисельні розв'язки рівняння Пелля є вузлами дискретної решітки `Z²`, що лежать на гіперболі одиничного псевдорадіуса `‖u‖² = 1`.

Тотожність Брахмагупти визначає групову операцію повороту на площині Лобачевського (або бусту в просторі Мінковського). Перехід `(a, b, k) → (a', b', k')` у методі Чукравала геометрично відповідає проектуванню вздовж світлоподібної асимптоти `x = y·√d`.

Вимога мінімізації `|m² - d|` є вибором найближчого вузла фундаментальної області Вороного для гіперболічної решітки. Завдяки цьому алгоритм Чукравала здійснює найкоротший геодезичний спуск по гіперболічному многовиду прямо до генератора групи одиниць кільця `Z[√d]`.

## 9. Алгебраїчна еквівалентність формул Бхаскари та фундаментальної одиниці кільця

Індійська алгебраїчна техніка композиції Самаса безпосередньо еквівалентна сучасній теорії кілець та числових полів. Розглянемо поле часток `Q(√d)`. Будь-яка трійка Брахмагупти `(a, b, k)` природно зіставляється з елементом поля:

```text
ω = (a + b·√d) / √|k|
```

псевдоевклідова норма якого у полі `Q(√d)` дорівнює знаку залишку:

```text
N(ω) = (a² - d·b²) / |k| = k / |k| = sgn(k) = ±1
```

Коли залишок дорівнює `k = ±1`, елемент `ε = a + b·√d` належить порядку `Z[√d]` і є одиницею кільця. Якщо ж залишок дорівнює `k = -1`, елемент `ε` має норму `-1`. Піднесення до другого степеня:

```text
ε² = (a + b·√d)² = (a² + d·b²) + 2·a·b·√d
```

має норму `N(ε²) = (N(ε))² = (-1)² = +1`, що в точності відтворює правило Бхаскари для випадку `k = -1`.

Аналогічно, коли залишок дорівнює `k = ±2`, елемент `γ = (a + b·√d) / √2` при піднесенні до квадрата переходить у:

```text
γ² = (a + b·√d)² / 2 = ((a² + d·b²) / 2) + (a·b)·√d
```

де коефіцієнти `x = (a² + d·b²) / 2` та `y = a·b` є цілими числами порядку `Z[√d]`, а норма дорівнює `N(γ²) = (±2 / 2)² = 1`.

У випадку `k = -4` елемент `δ = (a + b·√d) / 2` належить кільцю цілих чисел `O_K` квадратичного поля `Q(√d)` (якщо `d ≡ 1 mod 4`) і має норму `N(δ) = (a² - d·b²) / 4 = -4 / 4 = -1`. Піднесення `δ` до куба дає елемент кільця `Z[√d]`:

```text
δ³ = ((a + b·√d) / 2)³ = (a·(a² + 3·d·b²) / 8) + (b·(3·a² + d·b²) / 8)·√d
```

який має цілі коефіцієнти та норму `N(δ³) = (-1)³ = -1`. Наступне піднесення до квадрата породжує фундаментальну одиницю з нормою `+1`.

Це демонструє дивовижну алгебраїчну глибину відкриття Брахмагупти, Джаядеви та Бхаскари: створений ними алгоритмічний апарат повністю передбачив концепції алгебраїчної теорії чисел на вісім століть.
