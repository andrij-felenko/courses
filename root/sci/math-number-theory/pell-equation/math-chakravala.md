# 🧮 Циклічний метод Чукравала та тотожність Брахмагупти

Математичний метод Чукравала (санскр. *Chakravala* — циклічний або коловий метод) є давньоіндійським алгебраїчним алгоритмом для знаходження фундаментального цілочисельного розв'язку квадратичного діофантового рівняння Пелля:

```
x² - d·y² = 1
```

де параметр `d` є додатним цілим числом, яке не є точним квадратом. Алгоритм розроблено індійськими математиками Джаядевою (XI століття) та Бхаскарою II (1150 р.). Він базується на двох фундаментальних математичних ідеях: алгебраїчній тотожності композиції Брахмагупти та цілочисельній мінімізації норми через вибір оптимального параметра на кожному кроці циклу.

## 1. Алгебраїчна тотожність Брахмагупти (Samasa)

У 628 році індійський математик Брахмагупта у праці «Брахма-спхута-сіддханта» відкрив тотожність композиції квадратних форм. Якщо маємо дві трійки цілих чисел `(a₁, b₁, k₁)` та `(a₂, b₂, k₂)`, які задовольняють співвідношення:

```
a₁² - d·b₁² = k₁
a₂² - d·b₂² = k₂
```

то можна алгебраїчно побудувати нову трійку `(a₃, b₃, k₃)`, де вільний член є добутком `k₃ = k₁·k₂`.

### Строгий алгебраїчний вивід тотожності

Розглянемо квадратичне розширення кільця цілих чисел `Z[√d] = {a + b·√d | a, b ∈ Z}`. Для кожного елемента `α = a + b·√d` алгебраїчна норма визначається як добуток елемента на його спряжений `ᾱ = a - b·√d`:

```
N(α) = α·ᾱ = (a + b·√d)·(a - b·√d) = a² - d·b²
```

Застосуємо фундаментальну властивість мультиплікативності норми `N(α·β) = N(α)·N(β)`. Для двох елементів `α₁ = a₁ + b₁·√d` та `α₂ = a₂ + b₂·√d` обчислимо їхній добуток у кільці:

```
α₁·α₂ = (a₁ + b₁·√d)·(a₂ + b₂·√d) = (a₁·a₂ + d·b₁·b₂) + (a₁·b₂ + a₂·b₁)·√d
```

Позначаємо раціональну частину добутку як `a₃ = a₁·a₂ + d·b₁·b₂`, а коефіцієнт при ірраціональній частині `√d` як `b₃ = a₁·b₂ + a₂·b₁`. Обчислимо норму добутку `N(α₁·α₂)`:

```
a₃² - d·b₃²
= (a₁·a₂ + d·b₁·b₂)² - d·(a₁·b₂ + a₂·b₁)²      [підстановка виразів для a₃ та b₃]
= a₁²·a₂² + 2·d·a₁·a₂·b₁·b₂ + d²·b₁²·b₂² - d·(a₁²·b₂² + 2·a₁·a₂·b₁·b₂ + a₂²·b₁²) [розкриття квадратів]
= a₁²·a₂² + 2·d·a₁·a₂·b₁·b₂ + d²·b₁²·b₂² - d·a₁²·b₂² - 2·d·a₁·a₂·b₁·b₂ - d·a₂²·b₁² [раскриття дужок]
= a₁²·a₂² + d²·b₁²·b₂² - d·a₁²·b₂² - d·a₂²·b₁²  [скорочення подвоєного добутку]
= a₁²·(a₂² - d·b₂²) - d·b₁²·(a₂² - d·b₂²)       [винесення спільних множників]
= (a₁² - d·b₁²)·(a₂² - d·b₂²)                  [факторизація]
= k₁·k₂                                       [підстановка початкових норм]
```

Отже, тотожність Брахмагупти повністю доведена:

```
(a₁·a₂ + d·b₁·b₂)² - d·(a₁·b₂ + a₂·b₁)² = (a₁² - d·b₁²)·(a₂² - d·b₂²)
```

Якщо використати від'ємний знак при спряженні `α₂̄ = a₂ - b₂·√d`, ми отримуємо другу варіантну форму тотожності Брахмагупти:

```
(a₁·a₂ - d·b₁·b₂)² - d·(a₁·b₂ - a₂·b₁)² = k₁·k₂
```

Ця тотожність показує, що множина трійок `(a, b, k)` утворює закриту алгебраїчну систему відносно операції композиції.

## 2. Ітераційний крок та трансформування трійок Чукравала

Нехай на певному кроці алгоритму маємо поточну трійку цілих чисел `(a, b, k)`, яка задовольняє співвідношення:

```
a² - d·b² = k
```

Розглянемо тривіальну тотожність для довільного цілого параметра `m`:

```
m² - d·1² = m² - d
```

Застосуємо тотожність Брахмагупти до двох пар `(a, b, k)` та `(m, 1, m² - d)`:

```
(a·m + d·b)² - d·(a + b·m)² = k·(m² - d)
```

Припустимо, що `k ≠ 0`. Поділивши обидві частини отриманої рівності на `k²`, маємо:

```
((a·m + d·b) / |k|)² - d·((a + b·m) / |k|)² = (m² - d) / k
```

Означаємо нову трійку коефіцієнтів `(a', b', k')`:

```
a' = (a·m + d·b) / |k|
b' = (a + b·m) / |k|
k' = (m² - d) / k
```

### Доказ цілочисельності нових коефіцієнтів (Лема Брахмагупти)

Щоб нові значення `a'`, `b'` та `k'` були **цілими числами**, необхідно і достатньо, щоб виконувалася умовою подільності:

```
(a + b·m) ≡ 0 (mod |k|)
```

Доведемо, що якщо `(a + b·m)` ділиться на `|k|`, то й `(a·m + d·b)` та `(m² - d)` також обов'язково діляться на `|k|`.

1. Доказ для `(a·m + d·b)`:
   Розглянемо вираз `(a·m + d·b)·b`:

```
(a·m + d·b)·b = a·b·m + d·b²
```

   З початкового рівняння маємо `d·b² = a² - k`. Підставляючи це значення:

```
a·b·m + a² - k = a·(a + b·m) - k
```

   Оскільки `(a + b·m)` ділиться на `|k|`, вираз `a·(a + b·m) - k` ділиться на `|k|`. Оскільки `gcd(b, k) = 1` (бо `a² - d·b² = k`), то й `(a·m + d·b)` ділиться на `|k|`.

2. Доказ для `(m² - d)`:
   Розглянемо вираз `(m² - d)·b²`:

```
(m² - d)·b² = b²·m² - d·b² = b²·m² - (a² - k) = (b·m)² - a² + k = (b·m - a)·(b·m + a) + k
```

   Оскільки `(b·m + a)` ділиться на `|k|`, весь вираз ділиться на `|k|`. Оскільки `gcd(b², k) = 1`, значення `(m² - d)` ділиться на `|k|`.

Отже, лема Брахмагупти доведена: одна умова `a + b·m ≡ 0 (mod |k|)` гарантує цілочисельність усіх трьох нових параметрів `(a', b', k')`.

### Умова вибору оптимального параметра m

Серед усіх цілих чисел `m`, які задовольняють порівняння `a + b·m ≡ 0 (mod |k|)`, метод Чукравала вибирає таке значення `m`, яке мінімізує абсолютну величину нової норми:

```
|m² - d| → min
```

Це мінімізує значення `|k'| = |m² - d| / |k|`, що гарантує найшвидше зведення параметра `k'` до `1`.

Особливою перевагою методу Чукравала є його монотонна збіжність: значення `|k'|` на кожному кроці зменшується або прямує до малих цілих чисел з множини `{±1, ±2, ±4}`. Якщо алгоритм досягає `k' = ±1`, розв'язок знайдено; якщо досягається `k' = ±2` або `±4`, за допомогою тотожності Брахмагупти здійснюється миттєве ділення на 2 або 4 для отримання прямого розв'язку з `k = 1`.

## 3. Геометрична інтерпретація кроку Чукравала

З геометричної точки зору перехід від трійки `(a, b, k)` до `(a', b', k')` відповідає трансформації точки площини у напрямку асимптоти гіперболи `y = x / √d`. 

Параметр `m` задає нахил січної прямої, яка з'єднує початкову точку `(a, b)` з цілочисельним вузлом решітки. Вимога мінімізації `|m² - d|` гарантує, що січна пряма обирається якомога ближче до геометричного напрямку асимптоти. Завдяки цьому нова точка `(a', b')` розташовується на значно ближчій до осі гіперболічній кривій, що забезпечує швидке геометричне зближення норми `k'` з одиницею.

## 4. Детальний покроковий приклад виконання алгоритму для d = 67

Проілюструємо роботу алгоритму Чукравала на класичному прикладі для `d = 67`.

### Крок 1. Початкова ініціалізація
Шукаємо найближчий точний квадрат до `d = 67`. Найближчим квадратом є `8² = 64`.
Покладаємо `a₀ = 8`, `b₀ = 1`.
Обчислюємо початкову норму `k₀`:

```
k₀ = 8² - 67·1² = 64 - 67 = -3
```

Отримуємо початкову трійку `(a₀, b₀, k₀) = (8, 1, -3)`.

### Крок 2. Перша ітерація
Шукаємо `m₁` таке, що:
1. `8 + 1·m₁ ≡ 0 (mod 3)`  ⇒  `m₁ ≡ -8 ≡ 1 (mod 3)`. Можливі значення `m₁`: `..., -2, 1, 4, 7, 10, 13, ...`
2. Мінімізуємо `|m₁² - 67|`.

Порівняємо близькі кандидатури:
- Для `m₁ = 7` (`7 ≡ 1 mod 3`): `|7² - 67| = |49 - 67| = 18`.
- Для `m₁ = 10` (`10 ≡ 1 mod 3`): `|10² - 67| = |100 - 67| = 33`.

Вибираємо `m₁ = 7`, оскільки `18 < 33`.

Обчислюємо нову трійку `(a₁, b₁, k₁)`:

```
a₁ = (8·7 + 67·1) / |-3| = (56 + 67) / 3 = 123 / 3 = 41
b₁ = (8 + 1·7) / |-3| = 15 / 3 = 5
k₁ = (7² - 67) / (-3) = (49 - 67) / (-3) = -18 / (-3) = 6
```

Отримуємо трійку `(a₁, b₁, k₁) = (41, 5, 6)`.
Перевірка рівняння: `41² - 67·5² = 1681 - 67·25 = 1681 - 1675 = 6`. Рівність виконується!

### Крок 3. Друга ітерація
Шукаємо `m₂` таке, що:
1. `41 + 5·m₂ ≡ 0 (mod 6)`  ⇒  `5·m₂ ≡ -41 ≡ 1 (mod 6)`. Помноживши на 5: `25·m₂ ≡ 5 (mod 6)`  ⇒  `m₂ ≡ 5 (mod 6)`.
   Можливі значення `m₂`: `..., -1, 5, 11, 17, ...`
2. Мінімізуємо `|m₂² - 67|`.

Значення `√67 ≈ 8.185`.
- Для `m₂ = 5`: `|5² - 67| = |25 - 67| = 42`.
- Для `m₂ = 11`: `|11² - 67| = |121 - 67| = 54`.

Вибираємо `m₂ = 5`.

Обчислюємо нову трійку `(a₂, b₂, k₂)`:

```
a₂ = (41·5 + 67·5) / 6 = (205 + 335) / 6 = 540 / 6 = 90
b₂ = (41 + 5·5) / 6 = 66 / 6 = 11
k₂ = (5² - 67) / 6 = (25 - 67) / 6 = -42 / 6 = -7
```

Отримуємо трійку `(a₂, b₂, k₂) = (90, 11, -7)`.
Перевірка рівняння: `90² - 67·11² = 8100 - 67·121 = 8100 - 8107 = -7`.

### Крок 4. Третя ітерація
Шукаємо `m₃` таке, що:
1. `90 + 11·m₃ ≡ 0 (mod 7)`  ⇒  `11·m₃ ≡ -90 ≡ 1 (mod 7)`  ⇒  `4·m₃ ≡ 1 (mod 7)`. Помноживши на 2: `m₃ ≡ 2 (mod 7)`.
   Можливі значення `m₃`: `..., -5, 2, 9, 16, ...`
2. Мінімізуємо `|m₃² - 67|`.
   - Для `m₃ = 9`: `|9² - 67| = |81 - 67| = 14`.
   - Для `m₃ = 2`: `|2² - 67| = |4 - 67| = 63`.

Вибираємо `m₃ = 9`.

Обчислимо нову трійку `(a₃, b₃, k₃)`:

```
a₃ = (90·9 + 67·11) / 7 = (810 + 737) / 7 = 1547 / 7 = 221
b₃ = (90 + 11·9) / 7 = (90 + 99) / 7 = 189 / 7 = 27
k₃ = (9² - 67) / (-7) = (81 - 67) / (-7) = 14 / (-7) = -2
```

Отримуємо трійку `(a₃, b₃, k₃) = (221, 27, -2)`.
Перевірка: `221² - 67·27² = 48841 - 67·729 = 48841 - 48843 = -2`.

### Крок 5. Завершення ітерацій та піднесення до квадрата
Оскільки досягнуто значення `k₃ = -2` з трійкою `(221, 27, -2)`, за властивістю Брахмагупти ми підносимо елемент `α = 221 + 27·√67` до квадрата у кільці `Z[√67]`, а отримані значення ділимо на `|k₃| = 2`:

```
a₄ = (221² + 67·27²) / 2 = (48841 + 48843) / 2 = 97684 / 2 = 48842
b₄ = (2·221·27) / 2 = 221·27 = 5967
k₄ = (-2)² / 4 = 1
```

Для `d = 67` остаточним фундаментальним розв'язком є пара:

```
x = 48842,   y = 5967
```

Перевірка розв'язку:

```
48842² - 67·5967²
= 2385540964 - 67·35605089   [піднесення до квадрата: 48842² та 5967²]
= 2385540964 - 2385540963     [множення: 67 · 35605089]
= 1                           [віднімання: рівність 1 підтверджує розв'язок]
```

## 5. Складніший тест: Випадок d = 61 Бхаскари II

Ферма у 1657 році вважав випадок `d = 61` винятково складним випробуванням для європейських математиків. Бхаскара II розв'язав його за допомогою циклу Чукравала всього за кілька ітерацій:

1. Старт з `a₀ = 8, b₀ = 1, k₀ = 3` (`8² - 61·1² = 3`).
2. Перша ітерація `m₁ = 7` дає `(a₁, b₁, k₁) = (39, 5, -8)`.
3. Друга ітерація `m₂ = 9` дає `(a₂, b₂, k₂) = (164, 21, -5)`.
4. Третя ітерація `m₃ = 11` дає `(a₃, b₃, k₃) = (453, 58, -4)`.
5. Поділивши трійку з `k = -4` на 2, отримуємо розв'язок негативного рівняння `x² - 61·y² = -1` з `(ã, b̃) = (29718, 3805)`.
6. Піднесення негативного розв'язку до квадрата дає фундаментальний розв'язок рівняння Пелля:

```
x = 1766319049,   y = 226153980
```

Ці результати підтверджують безумовну алгоритмічну досконалість та фундаментальну наукову цінність індійського циклічного методу Чукравала.
