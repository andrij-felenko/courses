# 📜 Історія відкриття та еволюція рядів Ейзенштейна

Ряди Ейзенштейна є одним із найвеличніших відкриттів математичного аналізу та теорії чисел XIX століття. Вони виникли на перетині теорії еліптичних функцій та аналітичної теорії чисел у працях видатного німецького математика Ґотгольда Ейзенштейна (нім. *Gotthold Eisenstein*, 1823–1852). Упродовж свого драматично короткого життя — Ейзенштейн помер від туберкульозу у віці лише 29 років — він устиг закласти підвалини сучасної теорії модулярних форм, арифметики комплексних решіток та вищих законів взаємності.

## 1. Від еліптичних інтегралів Ґаусса та Якобі до решіток Ейзенштейна

На початку XIX століття Карл Фрідріх Ґаусс (нім. *Carl Friedrich Gauss*, 1777–1855) та Карл Ґустав Якоб Якобі (нім. *Carl Gustav Jacob Jacobi*, 1804–1851) досліджували обернення еліптичних інтегралів, які виникали під час обчислення довжини дуги еліпси чи лемніскати Бернуллі. Ґаусс ще у 1790-х роках у своїх ненадрукованих щоденниках відкрив, що еліптичні функції є двоперіодичними функціями на комплексній площині `ℂ`, тобто задовольняють співвідношення `f(z + ω₁) = f(z)` та `f(z + ω₂) = f(z)` для двох лінійно незалежних комплексних періодів `ω₁` та `ω₂`.

Якобі розробив потужний аналітичний апарат тета-функцій `ϑ(z, τ)`, який дозволяв подавати еліптичні функції у вигляді часток нескінченних добутків та рядів. Однак теорія Якобі спиралася на вибір конкретної параметризації періодів і приховувала глибинну геометричну симетрію — інваріантність відносно вибору базису комплексної решітки `Λ = ℤ·ω₁ + ℤ·ω₂`.

У 1840-х роках Ґотгольд Ейзенштейн задався фундаментальним питанням: як побудувати аналітичні двоперіодичні функції безпосередньо з геометрії двовимірної решітки `Λ`, не прив'язуючись до конкретного вибору її генеруючих векторів? Ейзенштейн був учнем і улюбленцем Ґаусса, який казав про нього: «У математиці було лише три епохальні постаті: Архімед, Ньютон та Ейзенштейн».

Натхненний працями Ґаусса з квадратичних форм, Ейзенштейн запропонував розглядати нескінченні суми обернених степенів за всіма вузлами решітки:

```
G₂ₖ(Λ) = ∑' 1 / ω²ₖ = ∑' 1 / (m·ω₁ + n·ω₂)²ₖ
```

де штрих біля знака суми означає виключення нульового вузла `(m, n) = (0, 0)`.

Ейзенштейн усвідомив, що такі суми є інваріантними відносно будь-якої цілочисельної заміни базису `(ω₁, ω₂)` з детермінантом `+1`. Це означало, що `G₂ₖ` залежить не від конкретної пари векторів, а від ізоморфного класу самої решітки. При масштабуванні решітки чинником `ω₁` параметр `τ = ω₂ / ω₁` належить Верхній півплощині `ℍ = { τ ∈ ℂ : Im(τ) > 0 }`, а ряд перетворюється на функцію від `τ`:

```
G₂ₖ(τ) = ∑' 1 / (m·τ + n)²ₖ
```

Ці суми отримали назву **рядів Ейзенштейна** (нім. *Eisenstein-Reihen*).

## 2. Дилема умовної збіжності та відкриття квазімодулярності

Найбільшим аналітичним бар'єром, із яким зіштовхнувся Ейзенштейн, було питання збіжності побудованих рядів. Для парних показників `2k ≥ 4` ряд `G₂ₖ(τ)` збігається абсолютно та рівномірно на будь-якій компактній підмножині Верхньої півплощини `ℍ`. Проте для випадку `2k = 2` (показник степеня в знаменнику дорівнює `2`) ряд:

```
G₂(τ) = ∑' 1 / (m·τ + n)²
```

виявився лише **умовно збіжним**. Це означало, що числове значення суми фундаментально залежить від порядку, в якому підсумовуються вузли решітки `(m, n)`.

Ейзенштейн запропонував фіксований порядок сумування — спочатку за внутрішньою змінною `n` від `-∞` до `+∞`, а потім за зовнішньою змінною `m` від `-N` до `+N` при `N → ∞`. За такого визначення ряд `G₂(τ)` аналітично обчислюється, але втрачає повну симетрію відносно дробово-лінійного перетворення `S: τ ↦ -1/τ`. Замість чистого модулярного закону `G₂(-1/τ) = τ² · G₂(τ)` виникає додатковий адитивний член:

```
G₂(-1/τ) = τ² · G₂(τ) - 2·π·i·τ
```

Це явище згодом у XX столітті отримало назву **квазімодулярності**. Спостереження Ейзенштейна щодо ряду `G₂` випередило свій час майже на століття: саме квазімодулярні форми в 1990-х роках виявилися ключовим математичним інструментом у математичній фізиці, дзеркальній симетрії та теорії струн для підрахунку алгебраїчних кривих на тривимірних многовидах Калабі — Яу (нім. *Erich Calabi*, яп. *Shing-Tung Yau*).

## 3. Вейєрштрасс, Клейн та алгебраїчна теорія модулярних форм

У другій половині XIX століття Карл Вейєрштрасс (нім. *Karl Weierstrass*, 1815–1897) переосмислив теорію еліптичних функцій на основі рядів Ейзенштейна. Вейєрштрасс увів `℘`-функцію (еліптичну функцію Вейєрштрасса):

```
℘(z; Λ) = 1/z² + ∑' [ 1/(z - ω)² - 1/ω² ]
```

і довів, що вона задовольняє кубічне диференціальне рівняння:

```
(℘'(z))² = 4·(℘(z))³ - g₂·℘(z) - g₃
```

Коефіцієнти цього рівняння `g₂` та `g₃` виявилися прямо пропорційними рядам Ейзенштейна ваги 4 та ваги 6:

```
g₂ = 60 · G₄(τ),     g₃ = 140 · G₆(τ)
```

Таким чином, ряди Ейзенштейна стали містком між аналітичними функціями комплексного змінного та алгебраїчною геометрією еліптичних кривих вида `y² = 4x³ - g₂x - g₃`.

Фелікс Клейн (нім. *Felix Klein*, 1849–1925) зробив наступний вирішальний крок: він дослідив модулярну групу `SL(2, ℤ)` як арифметичну групу симетрій Верхньої півплощини. Клейн побудував **абсолютний модулярний інваріант** `j(τ)` (абсолютний інваріант Клейна):

```
j(τ) = 1728 · g₂³ / (g₂³ - 27·g₃³) = 1728 · (60·G₄)³ / [ (60·G₄)³ - 27·(140·G₆)² ]
```

Інваріант `j(τ)` володіє дивовижною властивістю: дві еліптичні криві є ізоморфними над комплексома поля `ℂ` тоді й лише тоді, коли їхні значення `j`-інваріанта збігаються. Отже, ряди Ейзенштейна повністю параметризують простір модулів (класів ізоморфізму) еліптичних кривих.

## 4. Спадщина Рамануджана та сучасна теорія автоморфних форм

У 1916 році індійський математичний геній Срініваса Рамануджан (англ. *Srinivasa Ramanujan*, 1887–1920) опублікував епохальну працю *«On certain arithmetical functions»*. Рамануджан систематично дослідив розклади рядів Ейзенштейна в степеневі ряди за параметром `q = exp(2·π·i·τ)` (так званий `q`-розклад або розклад Фур'є).

Рамануджан відкрив дивовижний системний зв'язок між нормованими рядами Ейзенштейна:

```
P(q) = E₂(q) = 1 - 24 · ∑_{n=1}^∞ σ₁(n)·qⁿ
Q(q) = E₄(q) = 1 + 240 · ∑_{n=1}^∞ σ₃(n)·qⁿ
R(q) = E₆(q) = 1 - 504 · ∑_{n=1}^∞ σ₅(n)·qⁿ
```

Він вивів замкнену систему диференціальних рівнянь відносно оператора `q · d/dq` (диференціальні рівняння Рамануджана):

```
q · dP/dq = (P² - Q) / 12
q · dQ/dq = (Q·P - R) / 3
q · dR/dq = (R·P - Q²) / 2
```

Крім того, Рамануджан дослідив дискримінантну форму `Δ(q) = (Q³ - R²) / 1728` і відкрив мультиплікативні властивості її коефіцієнтів Фур'є `τ(n)` (функція тау Рамануджана), що започаткувало теорію операторів Геке (Еріх Геке, нім. *Erich Hecke*, 1936).

У другій половині XX століття Жан-П'єр Серр (фр. *Jean-Pierre Serre*) та Ґоро Шімура (яп. *Goro Shimura*) узагальнили ряди Ейзенштейна на конгруенц-підгрупи групи `SL(2, ℤ)`, а Роберт Ленглендс (англ. *Robert Langlands*) побудував узагальнені ряди Ейзенштейна на редуктивних групах Лі вищих рангів. Сьогодні ряди Ейзенштейна є наріжним каменем Програми Ленглендса — грандіозного павутиння гіпотез, що пов'язує теорію чисел, представлення груп та автоморфні форми.
