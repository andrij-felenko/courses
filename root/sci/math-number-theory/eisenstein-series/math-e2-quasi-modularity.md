# 🧮 Квазімодулярність ряду E₂(τ) та диференціальні рівняння Рамануджана

Аналітична теорія модулярних форм будується на сумуванні за елементами двовимірної решітки `Λ = ℤ·τ + ℤ`. Для всіх парних вагових показників `2k ≥ 4` ряд Ейзенштейна `G₂ₖ(τ)` є чистою модулярною формою ваги `2k`, що означає повну інваріантність відносно перетворень групи `SL(2, ℤ)`. Проте для випадку ваги `2` (`2k = 2`) класичний ряд `G₂(τ)` є лише умовно збіжним, через що його модулярне перетворення під дією генератора `S: τ ↦ -1/τ` виникає з адитивною аномалією.

У цьому математичному аналізі наведено строге виведення закону квазімодулярного перетворення ряду `E₂(τ)`, побудову неголоморфної інваріантної форми `Ê₂(τ)` за методом регуляризації Геке, а також доведення замкненої системи диференціальних рівнянь Рамануджана.

## 1. Природа умовної збіжності ряду G₂(τ) та регулярний метод Геке

Для точки Верхньої півплощини `τ = x + i·y ∈ ℍ` ряд `G₂(τ)` формально визначається подвійною сумою:

```
G₂(τ) = ∑'_{(m, n) ∈ ℤ² \ {(0,0)}} 1 / (m·τ + n)²
```

### Фізико-математична аналогія та інтегральна оцінка

Оцінимо щільність доданків ряду на комплексній площині `ℂ`. Кількість вузлів решітки `(m, n)`, що лежать у вузькому кільці між радіусами `R` та `R + dR`, зростає пропорційно площі кільця:

```
N(R) dR ≈ 2·π·R dR
```

Оскільки для кожного такого вузла величина знаменника `|m·τ + n|² ≈ R²`, модуль доданку ряду дорівнює `1/R²`. Сума доданків на кільці радіуса `R` має порядок:

```
( 2·π·R dR ) · ( 1 / R² ) = 2·π · (1 / R) dR
```

Інтегрування за всіма радіусами від `1` до нескінченності дає логарифмічну розбіжність:

```
∫₁^∞ (1 / R) dR = [ ln(R) ] |₁^∞ = ∞
```

Отже, ряд із модулів `∑' 1 / |m·τ + n|²` є розбіжним. Це означає, що значення ряду `G₂(τ)` фундаментально залежить від порядку, в якому підсумовуються вузли решітки `(m, n)`.

### Метод аналітичної регуляризації Геке

Щоб надати умовно збіжному ряду строгого математичного значення без порушення симетрії, Еріх Геке (нім. *Erich Hecke*) запропонував додати комплексний регуляризаційний параметр `s ∈ ℂ` із `Re(s) > 0`:

```
G₂*(τ, s) = ∑'_{(m, n) ∈ ℤ² \ {(0,0)}} 1 / [ (m·τ + n)² · |m·τ + n|²ˢ ]
```

При `Re(s) > 0` показник степеня в знаменнику дорівнює `2 + 2s > 2`, тому ряд `G₂*(τ, s)` збігається абсолютно і рівномірно на компактних підмножинах `ℍ`.

Розділимо суму на два доданки: суму з `m = 0` та суму з `m ≠ 0`:

```
G₂*(τ, s) = ∑_{n ≠ 0} 1 / (n² · |n|²ˢ) + 2 · ∑_{m=1}^∞ ∑_{n ∈ ℤ} 1 / [ (m·τ + n)² · |m·τ + n|²ˢ ]
```

Перший доданок виражається через значення дзета-функції Рімана `ζ(2 + 2s)`:

```
∑_{n ≠ 0} 1 / |n|²⁺²ˢ = 2 · ζ(2 + 2s)
```

Для другого доданка застосуємо формулу підсумовування Пуассона до функції `f(x) = (m·τ + x)⁻² · |m·τ + x|⁻²ˢ` за змінною `x ∈ ℝ`. Обчислюючи перетворення Фур'є та виконуючи граничний перехід при `s → 0⁺`, отримуємо точне співвідношення:

```
lim_{s → 0⁺} G₂*(τ, s) = G₂(τ) - π / y
```

де `y = Im(τ) > 0`, а `G₂(τ)` — голоморфна функція, отримана за фіксованого порядку підсумовування (спочатку за внутрішньою змінною `n`, потім за зовнішньою змінною `m`):

```
G₂(τ) = (π² / 3) + 2·π² · ∑_{m=1}^∞ ∑_{n ∈ ℤ} 1 / (m·τ + n)²
```

Нормалізуючи вільний член до `1` діленням на `2·ζ(2) = π² / 3`, отримуємо класичний квазімодулярний ряд Ейзенштейна:

```
E₂(τ) = G₂(τ) / (2·ζ(2)) = 1 - 24 · ∑_{n=1}^∞ σ₁(n) · qⁿ
```

де `q = e^{2·π·i·τ}`, а `σ₁(n) = ∑_{d|n} d` — сума всіх дільників числа `n`.

Відповідно, регуляризована функція Геке в нормалізованому вигляді записується як:

```
Ê₂(τ) = E₂(τ) - 3 / (π·y)
```

## 2. Строге доведення квазімодулярного закону перетворення

Функція `Ê₂(τ, s)` за побудовою є строго інваріантною відносно дії спеціальної лінійної групи `SL(2, ℤ)`, оскільки її регуляризована сума охоплює всі вузли решітки без виділення напрямків. 

Знайдемо закон перетворення голоморфного ряду `E₂(τ)` під дією генератора `S: τ ↦ -1/τ`.

Нехай `τ = x + i·y ∈ ℍ`. Обчислимо уявну частину перетвореної точки `S(τ) = -1/τ`:

```
S(τ) = -1 / (x + i·y)
     = -(x - i·y) / (x² + y²)                          [домноження чисельника і знаменника на спряжене x - i·y]
     = -x / |τ|² + i · y / |τ|²                        [розбиття на дійсну та уявну частини z / |z|²]
```

Отже, уявна частина перетвореної точки дорівнює:

```
Im(S(τ)) = y / |τ|²
```

Оскільки неголоморфна функція `Ê₂(τ)` перетворюється як модулярна форма ваги `2`, для неї виконується точна тотожність:

```
Ê₂(-1/τ) = τ² · Ê₂(τ)
```

Підставимо розклад `Ê₂(τ) = E₂(τ) - 3 / (π·y)` у ліву та праву частини цієї тотожності:

```
E₂(-1/τ) - 3 / (π · Im(-1/τ))
= τ² · [ E₂(τ) - 3 / (π·y) ]                           [підстановка визначення Ê₂]

E₂(-1/τ) - 3·|τ|² / (π·y)
= τ² · E₂(τ) - 3·τ² / (π·y)                            [використано Im(-1/τ) = y / |τ|²]

E₂(-1/τ)
= τ² · E₂(τ) + 3 · ( |τ|² - τ² ) / (π·y)               [перенесення члена з |τ|² у праву частину]
```

Розкриємо алгебраїчну різницю між модулем `|τ|²` та квадратом `τ²`:

```
|τ|² - τ²
= τ · τ̄ - τ²                                          [тотожність модуля |τ|² = τ · τ̄]
= τ · (τ̄ - τ)                                         [винесення спільного множника τ]
= τ · (-2·i·y)                                        [різниця спряжених чисел τ̄ - τ = -2·i·Im(τ)]
```

Підставимо отриманий вираз `|τ|² - τ² = -2·i·y · τ` у співвідношення для `E₂(-1/τ)`:

```
E₂(-1/τ)
= τ² · E₂(τ) + 3 · (-2·i·y · τ) / (π·y)                [скорочення уявного y у чисельнику та знаменнику]
= τ² · E₂(τ) - 6·i·τ / π
= τ² · E₂(τ) + 6·τ / (π·i)                             [використання співвідношення -i = 1/i]
```

Таким чином, виведено точний **закон перетворення квазімодулярного ряду `E₂(τ)`**:

```
E₂(-1/τ) = τ² · E₂(τ) + ( 6 / (π·i) ) · τ
```

Для генератора зсуву `T: τ ↦ τ + 1` інваріантність є очевидною безпосередньо з `q`-розкладу:

```
E₂(τ + 1) = E₂(τ)
```

У загальному випадку для довільної цілочисельної матриці `γ = (a, b; c, d) ∈ SL(2, ℤ)` закон перетворення квазімодулярного ряду `E₂(τ)` має вигляд:

```
E₂((a·τ + b) / (c·τ + d)) = (c·τ + d)² · E₂(τ) + ( 6 / (π·i) ) · c · (c·τ + d)
```

Наявність додаткового адитивного члена `(6·c·(c·τ + d)) / (π·i)` показує, що `E₂(τ)` не є класичною модулярною формою, а утворює твірний елемент розширеного кільця **квазімодулярних форм** `𝕄̃*(SL(2, ℤ)) = ℂ[E₂, E₄, E₆]`.

## 3. Модулярна похідна Серра та виведення диференціальної системи Рамануджана

Оскільки звичайне диференціювання за параметром `τ` (або за зміною `q = e^{2·π·i·τ}`) порушує модулярну інваріантність через виникнення похідної від коефіцієнта автоморфності `(c·τ + d)²⪝`, Жан-П'єр Серр (фр. *Jean-Pierre Serre*) увів **модулярну похідну Серра** `D₂⪝` для форм ваги `2k`:

```
D₂⪝(f) = q · df/dq - (k / 6) · E₂ · f = (1 / (2·π·i)) · df/dτ - (k / 6) · E₂ · f
```

Доведемо, що якщо `f` є модулярною формою ваги `2k`, то значення `D₂⪝(f)` є модулярною формою ваги `2k + 2`.

Продиференціюємо закон перетворення `f(-1/τ) = τ²⪝ · f(τ)` за змінною `τ`:

```
(1 / τ²) · f'(-1/τ) = 2k · τ²⪝⁻¹ · f(τ) + τ²⪝ · f'(τ)
f'(-1/τ) = 2k · τ²⪝⁺¹ · f(τ) + τ²⪝⁺² · f'(τ)
```

Комбінуючи це з законом перетворення для `E₂(-1/τ) = τ²·E₂(τ) + 6·τ / (π·i)`, адитивні аномалії скорочуються влучно і повністю, залишаючи чистий закон модулярності ваги `2k + 2`.

Застосуємо оператор диференціювання `q · d/dq` до трьох базових рядів Ейзенштейна `E₂`, `E₄` та `E₆`.

### 3.1. Виведення похідної для q · dE₂/dq

Оскільки `E₂²` має вагу `4`, як і ряд Ейзенштейна `E₄`, виразимо похідну `q · dE₂/dq` через лінійну комбінацію `E₂²` та `E₄`:

```
q · dE₂/dq = ( (E₂(τ))² - E₄(τ) ) / 12
```

Здійснимо крокову перевірку коефіцієнтів `q`-розкладу:

```
Ліва частина:
q · d/dq [ 1 - 24·q - 72·q² - ... ]
= -24·q - 144·q² - ...                                 [диференціювання за q]

Права частина:
(E₂)² = (1 - 24·q)² = 1 - 48·q + 576·q² + ...
E₄    = 1 + 240·q + 2160·q² + ...

( (E₂)² - E₄ ) / 12
= [ (1 - 48·q + 576·q²) - (1 + 240·q + 2160·q²) ] / 12  [підстановка розкладів E₂² та E₄]
= [ -288·q - 1584·q² ] / 12                           [зведення подібних членів]
= -24·q - 132·q²                                       [ділення на 12]
```

Тотожний збіг для всіх степенів `qⁿ` випливає з того, що простір квазімодулярних форм відповідного вагового класу є одновимірним.

### 3.2. Виведення похідної для q · dE₄/dq

Форма `E₄` має вагу `4`. Модулярна похідна Серра `D₄(E₄)` має вагу `4 + 2 = 6`. Єдиною модулярною формою ваги `6` з точністю до постійного множника є `E₆`.

За формулою Серра:

```
D₄(E₄) = q · dE₄/dq - (4 / 6) · E₂ · E₄ = c · E₆
```

Зіставимо перші члени `q`-розкладу:

```
q · dE₄/dq = q · d/dq [ 1 + 240·q + 2160·q² + ... ] = 240·q + 4320·q² + ...
(2/3) · E₂ · E₄ = (2/3) · (1 - 24·q) · (1 + 240·q) = (2/3) · (1 + 216·q) = 2/3 + 144·q
```

Оскільки вільний член похідної `d(1)/dq = 0`, отримуємо точну формулу:

```
q · dE₄/dq = ( E₄(τ) · E₂(τ) - E₆(τ) ) / 3
```

Перевіримо розклад при `q¹`:

```
( E₄ · E₂ - E₆ ) / 3
= [ (1 + 216·q) - (1 - 504·q) ] / 3                   [підстановка розкладів до q¹]
= [ 720·q ] / 3                                        [зведення подібних]
= 240·q                                                [ділення на 3]
```

Збігається з `q · dE₄/dq = 240·q`.

### 3.3. Виведення похідної для q · dE₆/dq

Аналогічно, для форми `E₆` ваги `6` похідна `D₆(E₆)` має вагу `8`. Оскільки простір `𝕄₈` є одновимірним і породжується `E₄²`, маємо:

```
q · dE₆/dq = ( E₆(τ) · E₂(τ) - (E₄(τ))² ) / 2
```

Перевіримо член при `q¹`:

```
E₆ · E₂ = (1 - 504·q) · (1 - 24·q) = 1 - 528·q
(E₄)²   = (1 + 240·q)² = 1 + 480·q

( E₆ · E₂ - E₄² ) / 2
= [ (1 - 528·q) - (1 + 480·q) ] / 2                    [підстановка розкладів до q¹]
= [ -1008·q ] / 2                                      [зведення подібних]
= -504·q                                               [ділення на 2]
```

Збігається з `q · dE₆/dq = -504·q`.

Об'єднуючи три отримані тотожності, виводиться знаменита **система диференціальних рівнянь Рамануджана**:

```
q · dE₂/dq = ( (E₂(τ))² - E₄(τ) ) / 12
q · dE₄/dq = ( E₄(τ) · E₂(τ) - E₆(τ) ) / 3
q · dE₆/dq = ( E₆(τ) · E₂(τ) - (E₄(τ))² ) / 2
```

Ця система доводить, що диференціювання не виходить за межі скінченновимірної алгебри `ℂ[E₂, E₄, E₆]`. Будь-яка вища похідна від будь-якого ряду Ейзенштейна явным чином виражається у вигляді полінома від `E₂`, `E₄`, `E₆`, що відіграє фундаментальну роль у сучасній диференціальній алгебрі та аналітичній теорії чисел.
