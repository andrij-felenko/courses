# ⚙️ Реалізація розширеного алгоритму Евкліда на C++

Для програмної реалізації тотожності Безу та розширеного алгоритму Евкліда на C++ ми можемо написати коротку та ефективну функцію. Її архітектура базується на ітеративному оновленні двох пар коефіцієнтів, що значно швидше за рекурсивний підхід і не несе ризику переповнення стека при великих числах. 

Нижче наведено C++17 реалізацію з використанням структури для повернення трьох значень одразу (НСД та двох коефіцієнтів), що робить код більш читабельним і зручним у використанні.

### Розбір компонентів

Алгоритм має п'ять основних компонентів, що визначають його роботу:
1. **Змінні стану**: Підтримуються дві змінні для кожного параметра — поточне значення (`r`, `x`, `y`) та значення з попереднього кроку (`old_r`, `old_x`, `old_y`).
2. **Обчислення частки**: На кожній ітерації ми обчислюємо цілочисельну частку `quotient = old_r / r`, яка визначає, скільки разів поточне значення вкладається в попереднє.
3. **Оновлення остач**: Класичний алгоритм Евкліда, де нова остача `r` стає залишком від ділення, а попереднє значення `old_r` стає дільником для наступного кроку.
4. **Паралельне оновлення коефіцієнтів**: Точно за тією ж математичною формулою, що й остачі, ми оновлюємо коефіцієнти `x` та `y`, підтримуючи інваріант рівняння Безу.
5. **Нормалізація результату (для модульної арифметики)**: Оскільки `x` може виявитися від'ємним, ми використовуємо конструкцію `(x % m + m) % m`, щоб безпечно привести результат до додатного діапазону від 0 до `m-1`. Це критично важливо для правильної роботи криптографічних алгоритмів.
