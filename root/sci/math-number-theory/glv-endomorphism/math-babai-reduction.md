# 🧮 Математичний апарат розкладу Бабая для GLV та GLS

Обчислення скалярного добутку точки еліптичної кривої `Q = [k]P` для 256-бітного скаляра `k` класичним методом подвоєння та додавання точок (англ. *Double-and-Add*) або методом ковзного вікна `wNAF` потребує виконання близько 256 операцій подвоєння точок у проективних координатах. За наявності алгебраїчного ендоморфізму кривої `phi: E -> E`, що діє на підгрупі точок простого порядку `r` як множення на відоме число `lambda ∈ Z_r` (тобто `phi(P) = [lambda]P`), задачу скалярного множення зводять до сумісного обчислення двох скалярів удвічі меншої довжини:

```
[k]P = [k₁]P + [k₂]phi(P)
```

Для реалізації цього прискорення скаляр `k` розкладають на пару цілих чисел `(k₁, k₂) ∈ Z²`, що задовольняють модулярну конгруенцію `k ≡ k₁ + k₂ · lambda (mod r)` за умови суворого обмеження їхніх абсолютних величин:

```
max(|k₁|, |k₂|) ≤ C · √r ≈ 2¹²⁸
```

Знаходження такої пари `(k₁, k₂)` зводиться до пошуку близького вектора (англ. *Closest Vector Problem*, CVP) у спеціально побудованій двовимірній цілочисельній ґратці `L ⊂ Z²`. Алгоритм редукції Бабая (англ. *Babai's Nearest Plane / Rounding technique*) у поєднанні з редукованим базисом Гаусса-Лагранжа або розширеним алгоритмом Евкліда дає детермінований конструктивний розв'язок цієї задачі з гарантованими оцінками залишків.

## 1. Конструкція 2-вимірної ґратки L та теорема Мінковського

Розглянемо множину цілочисельних пар `(u, v) ∈ Z²`, що утворюють лінійні комбінації скалярів, еквівалентні нулю за модулем порядку групи `r`:

```
L = { (u, v) ∈ Z²  :  u + v · lambda ≡ 0 (mod r) }
```

Ґратка `L` є замкненою відносно операцій векторного додавання та множення на цілі числа, утворюючи підгрупу адитивної групи `Z²` та вільний `Z`-модуль рангу 2. 

Алгебраїчний зміст ґратки `L` полягає в тому, що кожен її елемент `(u, v) ∈ L` кодує тотожно нульову операцію в підгрупі точок еліптичної кривої `E(F_p)[r]`:

```
[u]P + [v]phi(P)
= [u]P + [v][lambda]P         [за властивістю ендоморфізму phi(P) = [lambda]P]
= [u + v · lambda]P           [дистрибутивність скалярного множення]
= [q · r]P                    [бо u + v · lambda = q · r для деякого q ∈ Z]
= [q]([r]P)                   [властивість асоціативності]
= [q]O                        [бо порядок точки P дорівнює r, отже [r]P = O]
= O                           [нейтральний елемент групи точок]
```

Для визначення фундаментальних геометричних характеристик ґратки `L` розглянемо гомоморфізм груп `psi: Z² -> Z_r`, визначений формулою `psi(u, v) = (u + v · lambda) mod r`. Ядром цього гомоморфізму є сама ґратка `ker(psi) = L`. За першою теоремою про гомоморфізми фактор-група `Z² / L` є ізоморфною полю залишків `Z_r`:

```
Z² / L ≅ Z_r
```

Оскільки порядок групи `Z_r` дорівнює `r`, індекс підґратки становить `[Z² : L] = r`. Отже, визначник ґратки (площа її фундаментального паралелограма або кооб'єм `Vol(R² / L)`) є строго фіксованим алгебраїчним інваріантом:

```
det(L) = r
```

Канонічний нередукований базис ґратки задають вектори `w₁ = (r, 0)` та `w₂ = (-lambda, 1)`. Матриця генераторів `M` у цьому базисі має вигляд:

```
M = [ r        0 ]
    [ -lambda  1 ]
```

Визначник матриці `M` підтверджує обчислену площу фундаментальної комірки:

```
det(M)
= r · 1 - 0 · (-lambda)       [визначник квадратної матриці розміру 2x2]
= r                           [інваріант кооб'єму ґратки]
```

Перша теорема Мінковського про опуклі тіла стверджує, що будь-яка центрально-симетрична опукла область `S ⊂ R²` з площею `Area(S) > 4 · det(L) = 4r` містить щонайменше одну ненульову точку ґратки `v ∈ L \ {(0,0)}`. Якщо як область `S` обрати евклідовий круг радіуса `R` з площею `pi · R² = 4r`, то норма найкоротшого вектора ґратки `lambda₁(L)` гарантовано задовольняє нерівність:

```
lambda₁(L) ≤ √( (4 / pi) · r ) ≈ 1.128 · √r
```

Застосовуючи геометричну оцінку Гаусса для редукованих базисів, норма найкоротшого вектора обмежується ще точніше: `lambda₁(L) ≤ √( 2 / √3 ) · √r ≈ 1.075 · √r`. Це доводить існування коротких базисних векторів із довжиною порядку `√r`.

## 2. Алгоритми знаходження короткого базису ґратки

Нередукований базис `(w₁, w₂)` містить вектор `w₁ = (r, 0)` повної довжини 256 бітів і не підходить для безпосередньої декомпозиції скаляра. Необхідно знайти редукований базис `B = {v₁, v₂}`, вектори якого мають норму порядку `√r` та кут між собою, близький до прямого.

### Метод 1: Модифікований розширений алгоритм Евкліда (EEA)

Двовимірна структура ґратки `L` дозволяє знайти короткий базис за допомогою модифікованого розширеного алгоритму Евкліда, застосованого до пари чисел `(r, lambda)`. Ініціалізуємо дві послідовності:

```
r₀ = r,        t₀ = 0
r₁ = lambda,   t₁ = 1
```

На кожному кроці `i ≥ 1` обчислюємо неповну частку `qᵢ = ⌊rᵢ₋₁ / rᵢ⌋` та формуємо нові залишки:

```
rᵢ₊₁ = rᵢ₋₁ - qᵢ · rᵢ
tᵢ₊₁ = tᵢ₋₁ - qᵢ · tᵢ
```

Для кожного кроку `i` зберігаються два інваріанти:

```
rᵢ ≡ -tᵢ · lambda (mod r)
rᵢ · |tᵢ₊₁| + rᵢ₊₁ · |tᵢ| = r
```

Перший інваріант доводить, що кожен вектор вигляду `(rᵢ, -tᵢ)` належить ґратці `L`, оскільки `rᵢ + tᵢ · lambda ≡ 0 (mod r)`.

Другий інваріант випливає з визначника перетворень і гарантує, що визначник матриці, складеної з двох послідовних векторів `vᵢ = (rᵢ, -tᵢ)` та `vᵢ₊₁ = (rᵢ₊₁, -tᵢ₊₁)`, за модулем дорівнює `r`.

У міру виконання алгоритму послідовність залишків `rᵢ` монотонно спадає `r₀ > r₁ > r₂ > ... > 0`, а абсолютні значення коефіцієнтів Безу `|tᵢ|` монотонно зростають `0 = |t₀| < |t₁| < |t₂| < ...`. Алгоритм зупиняють на кроці `m`, де залишок уперше стає меншим за `√r`:

```
rₘ₊₁ < √r ≤ rₘ
```

Базисні вектори обирають як два послідовні кроки евклідової послідовності:

```
v₁ = (b₁₁, b₁₂) = (rₘ₊₁, -tₘ₊₁)
v₂ = (b₂₁, b₂₂) = (rₘ,   -tₘ)
```

Оцінимо довжину компонент вектора `v₁`. За умовою зупинки `rₘ₊₁ < √r`. З інваріанта визначника `rₘ · |tₘ₊₁| < rₘ · |tₘ₊₁| + rₘ₊₁ · |tₘ| = r`, звідки маємо:

```
|tₘ₊₁| < r / rₘ ≤ r / √r = √r
```

Отже, обидві координати вектора `v₁` строго менші за `√r`. Для вектора `v₂` виконується `|tₘ| ≤ √r`, а координата `rₘ` лежить у безпосередній близькості до `√r`.

### Метод 2: Редукція за Гауссом-Лагранжем

Альтернативним класичним методом побудови редукованого базису є алгоритм Гаусса-Лагранжа (двовимірний аналог ортогоналізації Грама-Шмідта та LLL-редукції).

Алгоритм приймає на вхід довільний базис `(v₁, v₂)` ґратки `L` і виконує ітеративне проектування:

```
1. Якщо ||v₁||₂ > ||v₂||₂, поміняти v₁ та v₂ місцями.
2. Обчислити коефіцієнт проекції: mu = ⌊ <v₁, v₂> / ||v₁||₂² ⌉, де ⌊·⌉ — округлення до найближчого цілого.
3. Якщо mu = 0, завершити роботу (базис редуковано).
4. Оновити вектор: v₂ = v₂ - mu · v₁.
5. Перейти до кроку 1.
```

Після завершення алгоритму вектори задовольняють умови редукції Гаусса:

```
||v₁||₂ ≤ ||v₂||₂
2 · |<v₁, v₂>| ≤ ||v₁||₂²
```

Кут `theta` між базисними векторами редукованого за Гауссом базису обмежений діапазоном `pi / 3 ≤ theta ≤ 2 · pi / 3`, тобто `|cos(theta)| ≤ 1/2`. Площа фундаментальної комірки виражається через векторний добуток:

```
det(L) = ||v₁||₂ · ||v₂||₂ · sin(theta) = r
```

Оскільки `sin(theta) ≥ sin(pi / 3) = √3 / 2`, отримуємо строгу оцінку на добуток норм базисних векторів:

```
||v₁||₂ · ||v₂||₂ = r / sin(theta) ≤ (2 / √3) · r ≈ 1.155 · r
```

Враховуючи `||v₁||₂ ≤ ||v₂||₂`, маємо `||v₁||₂² ≤ (2 / √3) · r`, звідки:

```
||v₁||₂ ≤ √( 2 / √3 ) · √r ≈ 1.075 · √r
||v₂||₂ ≤ √( 2 / √3 ) · √r ≈ 1.075 · √r
```

## 3. Алгоритм округлення Бабая (Babai's Rounding Technique)

Нехай задано довільний секретний 256-бітний скаляр `k ∈ [1, r - 1]`. Сформуємо цільовий вектор у евклідовому просторі `R²`:

```
u = (k, 0)
```

Задача декомпозиції полягає у знаходженні вектора ґратки `v = (v_x, v_y) ∈ L`, розташованого максимально близько до точки `u`, так щоб вектор різниці `(k₁, k₂) = u - v` мав малі компоненти.

Розкладемо вектор `u = (k, 0)` за базисом `B = {v₁, v₂}`, де `v₁ = (b₁₁, b₁₂)`, `v₂ = (b₂₁, b₂₂)`:

```
u = beta₁ · v₁ + beta₂ · v₂
(k, 0) = beta₁ · (b₁₁, b₁₂) + beta₂ · (b₂₁, b₂₂)
```

Запишемо векторне рівняння у матричній формі для рядкових векторів:

```
[ k  0 ] = [ beta₁  beta₂ ] · [ b₁₁  b₁₂ ]
                              [ b₂₁  b₂₂ ]
```

Позначимо матрицю базису через `B`. Оскільки `det(B) = b₁₁ · b₂₂ - b₁₂ · b₂₁ = r ≠ 0`, обернена матриця `B⁻¹` має вигляд:

```
B⁻¹ = (1 / r) · [  b₂₂  -b₁₂ ]
                [ -b₂₁   b₁₁ ]
```

Помножимо цільовий вектор `[k  0]` на `B⁻¹`:

```
[ beta₁  beta₂ ]
= [ k  0 ] · B⁻¹                                     [множення рядкового вектора на обернену матрицю]
= [ k  0 ] · (1 / r) · [  b₂₂  -b₁₂ ]                [підставили формулу оберненої матриці B⁻¹]
                       [ -b₂₁   b₁₁ ]
= (1 / r) · [ k · b₂₂ + 0 · (-b₂₁),  k · (-b₁₂) + 0 · b₁₁ ]  [виконали матричний добуток]
= [ (k · b₂₂) / r,  (-k · b₁₂) / r ]                 [отримали точні дійсні коефіцієнти розкладу]
```

Таким чином, дійсні коефіцієнти проекції точки `(k, 0)` на базис ґратки обчислюються за формулами:

```
beta₁ = (k · b₂₂) / r
beta₂ = (-k · b₁₂) / r
```

Алгоритм округлення Бабая замінює нецілі коефіцієнти `beta₁, beta₂ ∈ R` найближчими цілими числами:

```
c₁ = ⌊beta₁⌉ = ⌊ (k · b₂₂) / r ⌉
c₂ = ⌊beta₂⌉ = ⌊ (-k · b₁₂) / r ⌉
```

Обчислюємо відповідний вузол ґратки `v ∈ L`:

```
v = c₁ · v₁ + c₂ · v₂ = (c₁ · b₁₁ + c₂ · b₂₁,  c₁ · b₁₂ + c₂ · b₂₂)
```

Вектор декомпозиції `(k₁, k₂)` визначається як вектор залишку:

```
(k₁, k₂) = u - v = (k, 0) - (c₁ · v₁ + c₂ · v₂)
```

Розкриваючи покомпонентно:

```
k₁ = k - (c₁ · b₁₁ + c₂ · b₂₁)
k₂ = 0 - (c₁ · b₁₂ + c₂ · b₂₂) = - (c₁ · b₁₂ + c₂ · b₂₂)
```

### Доведення коректності модулярної еквівалентності

Доведемо, що знайдена пара `(k₁, k₂)` точно задовольняє вихідну конгруенцію `k₁ + k₂ · lambda ≡ k (mod r)`:

```
k₁ + k₂ · lambda
= (k - c₁ · b₁₁ - c₂ · b₂₁) + (-c₁ · b₁₂ - c₂ · b₂₂) · lambda    [підставили вирази для k₁ та k₂]
= k - c₁ · (b₁₁ + b₁₂ · lambda) - c₂ · (b₂₁ + b₂₂ · lambda)       [згрупували доданки за коефіцієнтами c₁ та c₂]
≡ k - c₁ · 0 - c₂ · 0 (mod r)                                      [бо v₁, v₂ ∈ L, отже bᵢ₁ + bᵢ₂ · lambda ≡ 0 (mod r)]
≡ k (mod r)                                                        [отримали початковий скаляр k]
```

Конгруенція виконується строго й абсолютно для будь-яких цілих значень `c₁` та `c₂`.

## 4. Строге доведення меж довжини компонент декомпозиції

Оцінимо абсолютні значення компонент `k₁` та `k₂`. Позначимо похибки округлення дійсних чисел `beta₁, beta₂` до цілих як:

```
epsilon₁ = beta₁ - c₁
epsilon₂ = beta₂ - c₂
```

Оскільки округлення `⌊·⌉` виконується до найближчого цілого, похибки за модулем не перевищують половини одиниці:

```
|epsilon₁| ≤ 1/2
|epsilon₂| ≤ 1/2
```

Виразимо вектор залишку `(k₁, k₂)` через похибки округлення:

```
(k₁, k₂)
= u - v                                              [визначення вектора різниці]
= (beta₁ · v₁ + beta₂ · v₂) - (c₁ · v₁ + c₂ · v₂)    [підставили точний та округлений розклад]
= (beta₁ - c₁) · v₁ + (beta₂ - c₂) · v₂              [згрупували коефіцієнти при базисних векторах]
= epsilon₁ · v₁ + epsilon₂ · v₂                      [підставили похибки округлення epsilon₁, epsilon₂]
```

Запишемо покомпонентно:

```
k₁ = epsilon₁ · b₁₁ + epsilon₂ · b₂₁
k₂ = epsilon₁ · b₁₂ + epsilon₂ · b₂₂
```

Застосовуючи нерівність трикутника, отримуємо покомпонентну оцінку для `k₁`:

```
|k₁|
= |epsilon₁ · b₁₁ + epsilon₂ · b₂₁|                  [модуль суми компонент]
≤ |epsilon₁| · |b₁₁| + |epsilon₂| · |b₂₁|            [нерівність трикутника для дійсних чисел]
≤ (1/2) · |b₁₁| + (1/2) · |b₂₁|                      [бо |epsilon₁| ≤ 1/2 та |epsilon₂| ≤ 1/2]
= ( |b₁₁| + |b₂₁| ) / 2                              [спільний знаменник]
```

Аналогічно для `k₂`:

```
|k₂| ≤ ( |b₁₂| + |b₂₂| ) / 2
```

Оскільки базисні вектори отримані за допомогою евклідової редукції або редукції Гаусса, абсолютні значення всіх компонент матриці базису обмежені величиною `|bᵢⱼ| ≤ √r`. Підставляючи цю межу:

```
|k₁| ≤ ( √r + √r ) / 2 = √r
|k₂| ≤ ( √r + √r ) / 2 = √r
```

### Оцінка евклідової норми вектора залишку

Обчислимо квадрат евклідової норми вектора залишку `||(k₁, k₂)||₂²`:

```
||(k₁, k₂)||₂²
= ||epsilon₁ · v₁ + epsilon₂ · v₂||₂²                                            [підставили вираз для вектора залишку]
= epsilon₁² · ||v₁||₂² + 2 · epsilon₁ · epsilon₂ · <v₁, v₂> + epsilon₂² · ||v₂||₂²  [розкрили квадрат норми суми векторів]
```

Оцінимо вираз за модулем зверху, враховуючи `epsilonᵢ² ≤ 1/4` та `|epsilon₁ · epsilon₂| ≤ 1/4`:

```
||(k₁, k₂)||₂²
≤ (1/4) · ||v₁||₂² + (1/2) · |<v₁, v₂>| + (1/4) · ||v₂||₂²     [врахували межі epsilonᵢ² ≤ 1/4 та |epsilon₁ · epsilon₂| ≤ 1/4]
≤ (1/4) · ||v₁||₂² + (1/4) · ||v₁||₂² + (1/4) · ||v₂||₂²     [за властивістю редукції Гаусса 2 · |<v₁, v₂>| ≤ ||v₁||₂²]
≤ (3/4) · ||v₂||₂²                                            [бо ||v₁||₂ ≤ ||v₂||₂ для редукованого базису]
≤ (3/4) · (2 / √3) · r                                        [підставили оцінку Гаусса ||v₂||₂² ≤ (2 / √3) · r]
= (√3 / 2) · r                                                [скоротили числові множники]
≈ 0.866 · r                                                   [десяткове наближення коефіцієнта]
```

Беручи квадратний корінь:

```
||(k₁, k₂)||₂ ≤ √(0.866 · r) ≈ 0.931 · √r
```

Оскільки максимальна координата вектора не перевищує його евклідової норми `max(|k₁|, |k₂|) ≤ ||(k₁, k₂)||₂`, маємо строгу універсальну оцінку:

```
max(|k₁|, |k₂|) ≤ √(2 · r)
```

Для порядку підгрупи `r ≈ 2²⁵⁶` бітова довжина обох скалярів `k₁` та `k₂` становить:

```
log₂(|kᵢ|) ≤ log₂(√r) = (1/2) · log₂(r) ≈ 128 бітів
```

Це математично гарантує рівно двократне скорочення кількості кроків подвоєння точок при обчисленні скалярного множення.

## 5. Безрозгалужена реалізація з фіксованою точністю (Constant-Time Babai)

У криптографічних реалізаціях обчислення коефіцієнтів округлення `c₁ = ⌊(k · b₂₂) / r⌉` та `c₂ = ⌊(-k · b₁₂) / r⌉` за допомогою стандартної процесорної інструкції цілочисельного ділення неприпустиме. Час виконання апаратного ділення залежить від числових значень та кількості провідних нулів у операндах, що створює витік інформації через часові побічні канали (англ. *Timing Side-Channel Attacks*).

Для усунення ділення застосовують масштабування констант із фіксованою комою на `l = 384` біти. Попередньо розраховують дві цілочисельні константи:

```
g₁ = ⌊ (2³⁸⁴ · b₂₂) / r ⌉
g₂ = ⌊ (2³⁸⁴ · (-b₁₂)) / r ⌉
```

Для довільного скаляра `k` значення коефіцієнтів `c₁` та `c₂` обчислюють за допомогою операцій множення та побітового зсуву:

```
c₁ = ⌊ (k · g₁ + 2³⁸³) / 2³⁸⁴ ⌋ = (k · g₁ + 2³⁸³) >> 384
c₂ = ⌊ (k · g₂ + 2³⁸³) / 2³⁸⁴ ⌋ = (k · g₂ + 2³⁸³) >> 384
```

### Доведення достатності 384-бітної точності

Доведемо, що заміна точного ділення наближеним множенням із 384-бітним зсувом не вносить помилки в округлення для будь-якого `k ∈ [0, r - 1]`.

Позначимо похибку наближення константи `g₁` як `delta = (2³⁸⁴ · b₂₂) / r - g₁`, де `|delta| ≤ 1/2`. Розглянемо різницю між масштабованим виразом та точним значенням:

```
(k · g₁) / 2³⁸⁴
= (k / 2³⁸⁴) · [ (2³⁸⁴ · b₂₂) / r - delta ]          [підставили визначення константи g₁]
= (k · b₂₂) / r - (k · delta) / 2³⁸⁴                 [розкрили дужки]
```

Оцінимо модуль залишкового дробового зміщення `epsilon_scale = (k · delta) / 2³⁸⁴`:

```
|epsilon_scale|
= (k · |delta|) / 2³⁸⁴                               [визначення залишкового дробового зміщення]
≤ (r · (1/2)) / 2³⁸⁴                                 [бо k < r та |delta| ≤ 1/2]
< (2²⁵⁶ · 1/2) / 2³⁸⁴                                [оскільки r < 2²⁵⁶]
= 2²⁵⁵ / 2³⁸⁴                                        [виконали множення у чисельнику]
= 2⁻¹²⁹                                              [відняли показники степенів]
```

Оскільки величина зміщення `|epsilon_scale| < 2⁻¹²⁹` є нескінченно малою порівняно з відстанню до порогу округлення `1/2`, округлення `(k · g₁ + 2³⁸³) >> 384` дає результат, абсолютно ідентичний математичному значенню `⌊(k · b₂₂) / r⌉`.

## 6. Геометрія Вороного, унікальність розкладу та від'ємні знаки

### Комірка Вороного та єдиність розкладу

Комірка Вороного `V(0)` ґратки `L` — це множина всіх точок евклідового простору `R²`, розташованих ближче до початку координат `(0,0)`, ніж до будь-якого іншого вузла ґратки:

```
V(0) = { x ∈ R²  :  ||x||₂ < ||x - v||₂  для всіх v ∈ L \ {(0,0)} }
```

Якщо вектор залишку `(k₁, k₂)` лежить усередині комірки Вороного, розклад скаляра є строго єдиним. Припустимо, що існують два різних розклади `k ≡ k₁ + k₂ · lambda ≡ k₁' + k₂' · lambda (mod r)`, такі що `max(|k₁|, |k₂|) < (√r) / 2` та `max(|k₁'|, |k₂'|) < (√r) / 2`. 

Віднімемо одну рівність від іншої:

```
(k₁ - k₁') + (k₂ - k₂') · lambda ≡ 0 (mod r)
```

Це означає, що вектор різниці `w = (k₁ - k₁',  k₂ - k₂')` належить ґратці `L`. Оцінимо його норму за нерівністю трикутника:

```
||w||∞
= max(|k₁ - k₁'|, |k₂ - k₂'|)                        [визначення чебишовської норми вектора різниці]
≤ max(|k₁|, |k₂|) + max(|k₁'|, |k₂'|)                [нерівність трикутника для максимуму модулів]
< (√r) / 2 + (√r) / 2                                [за умовою обмеженості обох розкладів]
= √r                                                 [підсумували граничні значення]
```

Але мінімальна відстань між будь-якими двома вузлами ґратки `L` становить `lambda₁(L) ≥ √r`. Єдиним вектором ґратки з нормою, строго меншою за `√r`, є нульовий вектор `(0, 0)`. Отже, `k₁ = k₁'` та `k₂ = k₂'`, що доводить єдиність декомпозиції.

### Обробка знаків у груповому законі кривої

Оскільки коефіцієнти `k₁` та `k₂` можуть набувати як додатних, так і від'ємних значень, у скалярному множенні використовують тотожність протилежної точки:

```
[-|kᵢ|]P = [|kᵢ|](-P)
```

В афінних та проективних координатах заміна точки `P = (x, y)` на протилежну `-P = (x, -y mod p) = (x, p - y)` потребує лише одного модулярного віднімання у полі `F_p` і не вимагає додаткових обчислень.

## 7. Повний чисельний розрахунок для кривої secp256k1

Продемонструємо повний цикл розрахунку для стандартизованої кривої `secp256k1` (`y² = x³ + 7` над полем `F_p`).

### Параметри кривої та ендоморфізму

Порядок підгрупи точок кривої `r` та власне значення ендоморфізму `lambda`:

```
r      = 0xFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFEBAAEDCE6AF48A03BBFD25E8CD0364141
lambda = 0x5363AD4CC05C30E0A5261C028812645A122E22EA20816678DF02967C1B23BD72

Масштабуючий коефіцієнт координат `beta ∈ F_p` (`beta³ ≡ 1 mod p`):

```
beta   = 0x7AE96A2B657C07106E64479EAC3434E99CF0497512F58995C1396C28719501EE
```

### Генерація редукованого базису (EEA)

Виконуючи розширений алгоритм Евкліда для пари `(r, lambda)`, на кроках 70 та 71 отримуємо вектори:

```
Крок 70: r₇₀ = 0x114CA50F7A8E2F3F657C1108D9D44CFD8,  t₇₀ = -0x3086D221A7D46BCDE86C90E49284EB15

Формуємо матрицю редукованого базису `B = [v₁; v₂]`:

Перевірка визначника: `det(B) = b₁₁ · b₂₂ - b₁₂ · b₂₁ = r`.

Попередньо обчислені 384-бітні константи `g₁` та `g₂`:

Нехай задано 256-бітний скаляр `k`:

```
k = 0xA1B2C3D4E5F60718293A4B5C6D7E8F90123456789ABCDEF0123456789ABCDEF0
```

**Крок 1: Обчислення коефіцієнтів округлення `c₁` та `c₂`**

```
c₁
= ⌊ (k · b₂₂) / r ⌉                                  [математичне округлення коефіцієнта проекції]
= (k · g₁ + 2³⁸³) >> 384                             [обчислення через константу фіксованої точки g₁]
= 0x1EA6AD0453402D138A0A8EF503429473                 [шістнадцятковий результат для скаляра k]

c₂
= ⌊ (-k · b₁₂) / r ⌉                                 [математичне округлення коефіцієнта проекції]

**Крок 2: Обчислення вектора ґратки `v = c₁ · v₁ + c₂ · v₂`**

```
v_x
= c₁ · b₁₁ + c₂ · b₂₁                                [перша координата лінійної комбінації c₁ · v₁ + c₂ · v₂]
= 0xA1B2C3D4E5F60718293A4B5C6D7E8F9043A858E41631EA3E8845FF00365C3447 [результат обчислення координати X]

v_y
= c₁ · b₁₂ + c₂ · b₂₂                                [друга координата лінійної комбінації c₁ · v₁ + c₂ · v₂]
= 0x3250CC28C0CEA0B809A22CBA32FBDABC                 [результат обчислення координати Y]
```

**Крок 3: Знаходження компонентів декомпозиції `(k₁, k₂)`**

```
k₁
= k - v_x                                            [різниця між цільовим значенням k та координатою v_x]
= -0x3174026B7B750B4E7611A8879B9F5557                [126-бітний редукований скаляр зі знаком мінус]

k₂
= 0 - v_y                                            [різниця між нульовою цільовою Y-координатою та v_y]
= -0x3250CC28C0CEA0B809A22CBA32FBDABC                [126-бітний редукований скаляр зі знаком мінус]

1. Бітова довжина:
   - `|k₁|` займає 126 бітів (`< 128` бітів).
   - `|k₂|` займає 126 бітів (`< 128` бітів).
2. Модулярна перевірка:
   - `k₁ + k₂ · lambda mod r = 0xA1B2C3D4E5F60718293A4B5C6D7E8F90123456789ABCDEF0123456789ABCDEF0 = k`.

Оскільки обидва скаляри від'ємні, скалярне множення зводиться до:

```
[k]P = [|k₁|](-P) + [|k₂|](-phi(P))
```

де `-P = (x, p - y)` та `-phi(P) = (beta · x mod p, p - y)`.

## 8. Узагальнення на 4-вимірні ґратки для GLS та 4D-GLV

Метод декомпозиції Бабая природно узагальнюється на вищі розмірності при використанні кривих із кількома незалежними ендоморфізмами (наприклад, поєднання ендоморфізму Фробеніуса на квадратичних розширеннях `F_{p²}` у методі GLS з ендоморфізмом CM-кривих).

У 4-вимірному випадку скаляр `k` розкладають на 4 компоненти:

```
k ≡ k₁ + k₂ · lambda₁ + k₃ · lambda₂ + k₄ · lambda₃ (mod r)
```

Розглядають 4-вимірну ґратку `L₄ ⊂ Z⁴`:

```
L₄ = { (v₁, v₂, v₃, v₄) ∈ Z⁴  :  v₁ + v₂ · lambda₁ + v₃ · lambda₂ + v₄ · lambda₃ ≡ 0 (mod r) }
```

Нередукована матриця генераторів має розмірність 4 × 4:

```
M₄ = [ r        0   0   0 ]
     [ -lambda₁ 1   0   0 ]
     [ -lambda₂ 0   1   0 ]
     [ -lambda₃ 0   0   1 ]
```

Визначник ґратки дорівнює `det(L₄) = r`. Редукція базису у просторі `Z⁴` виконується за допомогою алгоритму LLL (Lenstra-Lenstra-Lovász) із параметром Ловаса `delta = 3/4`. 

Багатовимірний алгоритм округлення Бабая знаходить коефіцієнти `c = [c₁, c₂, c₃, c₄] ∈ Z⁴`:

```
[ c₁  c₂  c₃  c₄ ] = ⌊ [ k  0  0  0 ] · B₄⁻¹ ⌉
```

Вектор залишку `k_res = (k₁, k₂, k₃, k₄) = (k, 0, 0, 0) - c · B₄` задовольняє оцінку Мінковського для 4D-простору:

```
max(|k₁|, |k₂|, |k₃|, |k₄|) ≤ C₄ · r¹/⁴ ≈ 2⁶⁴
```

У результаті 256-бітне скалярне множення `[k]P` обчислюється через 4-векторний інтерлівінговий цикл Штрауса лише за 64 операції подвоєння точок, що забезпечує 4-кратне прискорення відносно класичного алгоритму.
