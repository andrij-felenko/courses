# Доведення ефективності схеми Горнера

Схема Горнера є класичним прикладом оптимізації в обчислювальній математиці. Коли ми розглядаємо переведення чисел у десяткову систему (або загалом обчислення значення многочлена), постає питання: яка мінімальна кількість математичних операцій потрібна для отримання результату?

Розглянемо многочлен n-го ступеня, який представляє число N у базі b:
P(x) = dₙ·xⁿ + dₙ₋₁·xⁿ⁻¹ + ... + d₁·x¹ + d₀, де x = b.

## «Наївний» підхід

Якщо обчислювати цей вираз прямо "в лоб", для кожного i-го члена (від 1 до n) потрібно обчислити xⁱ. 
Щоб обчислити xⁱ звичайним множенням (x · x · ... · x), нам потрібно i-1 операцій множення. А потім ще одне множення на коефіцієнт dᵢ.
Рахуємо загальну кількість множень:
Для d₁·x — 1 множення.
Для d₂·x² — 2 множення.
...
Для dₙ·xⁿ — n множень.

Загальна кількість множень = 1 + 2 + ... + n = n·(n + 1) / 2.
Кількість додавань = n.

Складність цього алгоритму є квадратичною — O(n²). Для числа з 10 цифр це 55 множень. Якщо ми використовуємо алгоритми швидкого піднесення до степеня, можна зменшити цю кількість, але це вимагає додаткової пам'яті.

## Підхід за схемою Горнера

Перепишемо многочлен, послідовно виносячи x за дужки:
P(x) = d₀ + x·(d₁ + x·(d₂ + ... + x·(dₙ₋₁ + x·dₙ)...)).

Рахуємо операції:
На кожній вкладеній дужці (починаючи з найглибшої dₙ₋₁ + x·dₙ) ми виконуємо рівно 1 множення і 1 додавання.
Кількість вкладених дужок дорівнює ступеню многочлена n (тобто на 1 менше, ніж кількість цифр).

Отже, схема Горнера вимагає:
Кількість множень = n.
Кількість додавань = n.

Складність стає лінійною — O(n). Для того ж 10-значного числа нам потрібно лише 9 множень і 9 додавань.

## Доведення мінімальності (Теорема Островського-Пана)

У 1954 році математик Олександр Островський висунув гіпотезу, що для обчислення довільного многочлена n-го ступеня неможливо використати менше ніж n множень (і n додавань). Це було строго доведено у 1966 році математиком Віктором Паном.

Суть доведення Пана (в спрощеному вигляді для множень) спирається на незалежність коефіцієнтів dᵢ. Кожен коефіцієнт d₁, d₂, ..., dₙ повинен бути "зв'язаний" зі змінною x хоча б одним множенням, щоб вплинути на фінальний результат у правильній пропорції. 
Оскільки маємо n незалежних коефіцієнтів (крім вільного члена d₀, який лише додається), ми фізично не можемо уникнути n множень. Будь-який алгоритм, який використовує менше ніж n множень, не зможе правильно обчислити многочлен для всіх можливих комбінацій коефіцієнтів (він "загубить" інформацію про якийсь dᵢ).

Отже, схема Горнера є **математично оптимальною**. Вона досягає теоретичної нижньої межі кількості операцій. Саме тому вона беззаперечно використовується у всіх мікропроцесорах і стандартних бібліотеках мов програмування при перетворенні рядків-чисел (наприклад, "12345") у внутрішнє двійкове представлення (функції на кшталт `atoi` або `parseInt`).
