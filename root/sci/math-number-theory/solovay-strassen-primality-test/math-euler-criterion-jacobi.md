# 🧮 Математичне обґрунтування критерію Ейлера та символу Якобі

Ця вставка містить строге математичне виведення двох фундаментальних підвалин тесту Соловея–Штрассена: критерію Ейлера для квадратичних лишків та алгебраїчної доведеності того, що множина брехунів Ейлера утворює власну підгрупу мультиплікативної групи остач для будь-якого непарного складеного числа `n`.

## 1. Критерій простоти Ейлера та символ Лежандра

Нехай `p` — непарне просте число. Для будь-якого цілого числа `a`, не кратного `p`, символ Лежандра `(a / p)` визначається як:

```
(a / p) = +1     [якщо a є квадратичним лишком за модулем p]
(a / p) = -1     [якщо a є квадратичним нелишком за модулем p]
```

Формально, `a` називається квадратичним лишком за модулем `p`, якщо існує таке ціле число `x`, що виконується порівняння `x² ≡ a (mod p)`. Якщо такого `x` не існує, число `a` називається квадратичним нелишком.

Теорема Ейлера (критерій Ейлера, 1748) стверджує, що для будь-якого непарного простого `p` та `gcd(a, p) = 1` виконується порівняння:

```
a^((p-1)/2) ≡ (a / p) (mod p)
```

### 1.1. Строге виведення критерію Ейлера

За Малою теоремою Ферма, для будь-якого `a`, не кратного `p`, ми маємо:

```
aᵖ⁻¹ ≡ 1 (mod p)
```

Застосуємо алгебраїчний розклад різниці квадратів для виразу `aᵖ⁻¹ - 1`:

```
aᵖ⁻¹ - 1
= (a^((p-1)/2) - 1) · (a^((p-1)/2) + 1)      [розклад різниці квадратів]
≡ 0 (mod p)                                  [за Малою теоремою Ферма]
```

Оскільки `p` — просте число, кільце остач `ℤ/pℤ` є полем (не містить дільників нуля). Це означає, що добуток двох елементів дорівнює нулю тоді й лише тоді, коли хоча б один із множників дорівнює нулю. Отже, один із двох множників обов'язково ділиться на `p`:

```
a^((p-1)/2) ≡ 1 (mod p)   або   a^((p-1)/2) ≡ -1 (mod p)        [власність поля остач за простим модулем]
```

Розглянемо тепер два вичерпних випадки щодо значення символу Лежандра:

1. **Випадок 1: `a` є квадратичним лишком (`(a / p) = +1`).**
   За визначенням, існує таке ціле `x`, що `x² ≡ a (mod p)`. Піднесемо обидві частини цієї конгруенції до степеня `(p - 1) / 2`:

```
a^((p-1)/2)
≡ (x²)^((p-1)/2)                  [заміна a на x²]
≡ xᵖ⁻¹                            [власність степенів: (x²)ᵏ = x²ᵏ]
≡ 1 (mod p)                       [за Малою теоремою Ферма для елемента x]
```

Отже, якщо `(a / p) = 1`, то `a^((p-1)/2) ≡ 1 ≡ (a / p) (mod p)`.

2. **Випадок 2: `a` є квадратичним нелишком (`(a / p) = -1`).**
   За теоремою про примітивний корінь, мультиплікативна група остач `(ℤ/pℤ)*` є циклічною групою порядку `p - 1`. Нехай `g` — примітивний корінь за модулем `p`. Тоді будь-який ненульовий елемент групи подається у вигляді `gᵏ mod p`.
   
   Зауважимо, що `a` є квадратичним нелишком тоді й лише тоді, коли показник `k` є непарним числом. Якби `k` було парним (`k = 2m`), то `a ≡ (gᵐ)² (mod p)` було б квадратичним лишком. Отже, `a ≡ gᵏ (mod p)` для деякого непарного `k`.
   
   Піднесемо `a` до степеня `(p - 1) / 2`:

```
a^((p-1)/2)
≡ (gᵏ)^((p-1)/2)                  [заміна a на gᵏ]
≡ (g^((p-1)/2))ᵏ (mod p)          [перестановка степенів]
```

Оскільки `g` — примітивний корінь, порядок елемента `g` у групі `(ℤ/pℤ)*` дорівнює точно `p - 1`. Тобто `g^((p-1)/2)` є елементом порядку 2. У полів `ℤ/pℤ` єдиним елементом порядку 2 є `-1 mod p` (або `p - 1`).
Отже, `g^((p-1)/2) ≡ -1 (mod p)`.
Оскільки показник `k` є непарним числом, маємо:

```
(-1)ᵏ ≡ -1 (mod p)                [піднесення -1 до непарного степеня k]
```

Отже, якщо `(a / p) = -1`, то `a^((p-1)/2) ≡ -1 ≡ (a / p) (mod p)`. Критерій Ейлера повністю доведено для всіх непарних простих чисел `p`.

### 1.2. Числовий приклад критерію Ейлера

Розглянемо просте число `p = 13`. Порядок групи `(ℤ/13ℤ)*` дорівнює `12`, а половинний степінь `(p - 1) / 2 = 6`.

Знайдемо всі квадратичні лишки за модулем 13, піднісши елементи 1..6 до квадрата:
```
1² = 1  ≡ 1 (mod 13)
2² = 4  ≡ 4 (mod 13)
3² = 9  ≡ 9 (mod 13)
4² = 16 ≡ 3 (mod 13)
5² = 25 ≡ 12 (mod 13)
6² = 36 ≡ 10 (mod 13)
```
Множина квадратичних лишків за модулем 13: `{1, 3, 4, 9, 10, 12}`.
Множина квадратичних нелишків за модулем 13: `{2, 5, 6, 7, 8, 11}`.

Перевіримо критерій Ейлера:
- Для лишку `a = 3`: `3⁶ = 729`. `729 / 13 = 56` (остача 1). Отже `3⁶ ≡ +1 = (3 / 13) (mod 13)`.
- Для нелишку `a = 2`: `2⁶ = 64`. `64 / 13 = 4` (остача 12 ≡ -1). Отже `2⁶ ≡ -1 = (2 / 13) (mod 13)`.

## 2. Символ Якобі та його квадратична взаємність

Нехай `n` — непарне складене число з розкладом на прості множники `n = p₁ᵃ¹ · p₂ᵃ² · ... · pₖᵃₖ`. Символ Якобі `(a / n)` визначається як добуток відповідних символів Лежандра:

```
(a / n) = ∏ᵢ₌₁ᵏ (a / pᵢ)ᵃⁱ
```

### 2.1. Властивості символу Якобі

Символ Якобі унаслідував мультиплікативні властивості символу Лежандра:
1. **Мультиплікативність за чисельником:** `(a · b / n) = (a / n) · (b / n)`
2. **Мультиплікативність за знаменником:** `(a / m · n) = (a / m) · (a / n)`
3. **Периодичність:** Якщо `a ≡ b (mod n)`, то `(a / n) = (b / n)`

Найважливішою властивістю є **Закон квадратичної взаємності для символу Якобі**: для двох непарних додатних взаємно простих чисел `a` та `n`:

```
(a / n) = (-1)^(((a-1)/2) · ((n-1)/2)) · (n / a)
```

а також додаткові закони для `-1` та `2`:

```
(-1 / n) = (-1)^((n-1)/2)
(2 / n)  = (-1)^((n²-1)/8)
```

Завдяки цим властивостям символ Якобі `(a / n)` обчислюється за `O(log² n)` кроків без обчислення розкладу `n` на прості множники, застосовуючи алгоритм, повністю аналогічний алгоритму Євкліда для знаходження найбільшого спільного дільника.

> ⚠️ **Важливе застереження:** Якщо `(a / n) = 1` для складеного `n`, це **не означає**, що `a` є квадратичним лишком за модулем `n`. Наприклад, для `n = 15 = 3 · 5` та `a = 2`:
> `(2 / 15) = (2 / 3) · (2 / 5) = (-1) · (-1) = +1`.
> Проте порівняння `x² ≡ 2 (mod 15)` не має розв'язків, адже 2 не є квадратичним лишком ні за модулем 3, ні за модулем 5.

### 2.2. Приклад обчислення символу Якобі за алгоритмом взаємності

Обчислимо символ Якобі `(7 / 143)` без факторизації числа `143`:

```
(7 / 143)
= (-1)^(((7-1)/2) · ((143-1)/2)) · (143 / 7)     [за коном квадратичної взаємності: (3) · (71) = 213 — непарне, знак -1]
= - (143 mod 7 / 7)                              [редукція чисельника за модулем 7]
= - (3 / 7)                                      [оскільки 143 = 7 · 20 + 3]
= - [ (-1)^(((3-1)/2) · ((7-1)/2)) · (7 / 3) ]  [повторне застосування взаємності: (1) · (3) = 3 — непарне, знак -1]
= - [ - (7 mod 3 / 3) ]                         [редукція чисельника]
= + (1 / 3)                                      [подвійний мінус дає плюс]
= +1                                             [оскільки (1 / 3) = 1]
```

Результат `(7 / 143) = 1` отримано за 4 кроки без факторизації `143 = 11 · 13`.

## 3. Доведення підгрупової структури брехунів Ейлера

Нехай `n` — непарне складене число. Основа `a ∈ (ℤ/nℤ)*` називається **брехуном Ейлера** для числа `n`, якщо виконується порівняння:

```
a^((n-1)/2) ≡ (a / n) (mod n)
```

Позначимо множину всіх брехунів Ейлера через `Eₙ`:

```
Eₙ = { a ∈ (ℤ/nℤ)* : a^((n-1)/2) ≡ (a / n) (mod n) }
```

### Теорема про підгрупу
Для будь-якого непарного складеного числа `n` множина `Eₙ` є **власною підгрупою** мультиплікативної групи остач `(ℤ/nℤ)*`.

### 3.1. Доведення замкненості та властивостей підгрупи

Нехай `a, b ∈ Eₙ`. Перевіримо, чи належить їхній добуток `a · b` до `Eₙ`:

```
(a · b)^((n-1)/2)
= a^((n-1)/2) · b^((n-1)/2)      [мультиплікативність степеня]
≡ (a / n) · (b / n) (mod n)      [оскільки a, b ∈ Eₙ за визначенням]
≡ (a · b / n) (mod n)            [мультиплікативність символу Якобі]
```

Отже, `a · b ∈ Eₙ`. Оскільки нейтральний елемент `1` завжди належить до `Eₙ` (`1^((n-1)/2) = 1 = (1 / n)`), а група `(ℤ/nℤ)*` є скінченною, замкненість відносно множення гарантує, що `Eₙ` є підгрупою в `(ℤ/nℤ)*`.

### 3.2. Доведення існування свідка Ейлера (власність підгрупи `Eₙ ≠ (ℤ/nℤ)*`)

Доведемо існування принаймні одного елемента `a ∈ (ℤ/nℤ)*`, для якого `a^((n-1)/2) ≢ (a / n) (mod n)`.

Розглянемо два випадки арифметичної структури складеного числа `n`:

#### Випадок А: `n` не є бесквадратним (містить квадрат простого числа)
Нехай `n = p² · m`, де `p` — непарне просте число. Розглянемо основу `a = 1 + p · m`.
Перевіримо, що `gcd(a, n) = 1`: оскільки `a = 1 + p · m`, будь-який спільний дільник `a` та `p · m` мав би ділити 1, тому `НСД(a, n) = 1`.

Піднесемо `a` до степеня `(n - 1) / 2` за біномом Ньютона:

```
a^((n-1)/2)
= (1 + p · m)^((n-1)/2)
= 1 + ((n - 1) / 2) · p · m + C₂ · (p · m)² + ...     [розклад за біномом Ньютона]
≡ 1 + ((n - 1) / 2) · p · m (mod p² · m)             [оскільки доданочки з (p·m)² діляться на n = p²·m]
```

Обчислимо символ Якобі для цієї основи: оскільки `a = 1 + p · m ≡ 1 (mod p)`, то за періодичністю та властивістю символу Якобі `(a / n) = 1`.

Якби `a ∈ Eₙ`, то мало б виконуватися порівняння:
```
1 + ((n - 1) / 2) · p · m ≡ 1 (mod p² · m)
```
Це означає, що доданок `((n - 1) / 2) · p · m` має ділитися на `p² · m`. Скорочуючи на `p · m`, отримуємо вимогу, щоб `(n - 1) / 2` ділилося на `p`.
Проте `n = p² · m` ділиться на `p`, звідки `n ≡ 0 (mod p)`, а отже `n - 1 ≡ -1 ≢ 0 (mod p)`.
Оскільки `-1` не ділиться на `p`, чисельник `(n - 1) / 2` не може ділитися на `p`.

Отримали суперечність. Отже, для не-бесквадратного числа `n` основа `a = 1 + p · m` є свідком Ейлера, тому `Eₙ ≠ (ℤ/nℤ)*`.

#### Випадок Б: `n` є бесквадратним складеним числом
Нехай `n = p₁ · p₂ · ... · pₖ`, де `k ≥ 2` і всі `pᵢ` — різні непарні прості числа.

Оберемо ціле число `b`, яке є квадратичним нелишком за модулем `p₁` (`(b / p₁) = -1`).
За Китайською теоремою про остачі, побудуємо таке число `a ∈ (ℤ/nℤ)*`, яке задовольняє систему конгруенцій:

```
a ≡ b (mod p₁)      [вибір нелишку за модулем p₁]
a ≡ 1 (mod p₂)      [вибір лишків за іншими простого модулями]
...
a ≡ 1 (mod pₖ)      [вибір лишків за іншими простого модулями]
```

Обчислимо символ Якобі для цього побудованого числа `a`:

```
(a / n)
= (a / p₁) · (a / p₂) ... (a / pₖ)     [за визначенням символу Якобі]
= (-1) · (+1) ... (+1)                [підстановка відповідних символів Лежандра]
= -1                                  [добуток знаків]
```

Припустимо від супротивного, що `Eₙ = (ℤ/nℤ)*`. Тоді для всіх `x ∈ (ℤ/nℤ)*` виконується `x^((n-1)/2) ≡ (x / n) (mod n)`.
Зокрема, це мало б виконуватися і для нашого побудованого `a`:

```
a^((n-1)/2) ≡ (a / n) ≡ -1 (mod n)
```

Оскільки `p₂` ділить `n`, це порівняння має виконуватися і за модулем `p₂`:

```
a^((n-1)/2) ≡ -1 (mod p₂)
```

Проте за побудовою `a ≡ 1 (mod p₂)`, звідки піднесенням 1 до довільного степеня отримуємо:

```
a^((n-1)/2) ≡ 1^((n-1)/2) ≡ +1 (mod p₂)
```

Отримали суперечність: `+1 ≡ -1 (mod p₂)`. Оскільки `p₂ ≥ 3` є непарним простим числом, `+1` та `-1` є різними елементами за модулем `p₂`.

Отже, припущення про те, що `Eₙ = (ℤ/nℤ)*`, було хибним. Множина брехунів Ейлера `Eₙ` обов'язково є **власною підгрупою** в `(ℤ/nℤ)*`.

## 4. Оцінка порядку підгрупи брехунів за теоремою Лагранжа

Оскільки `Eₙ` є власною підгрупою скінченної групи `(ℤ/nℤ)*`, за Теоремою Лагранжа порядок підгрупи `|Eₙ|` є дільником порядку всієї групи `|(ℤ/nℤ)*| = φ(n)` (де `φ(n)` — функція Ейлера).

Оскільки `Eₙ ≠ (ℤ/nℤ)*`, найменший можливий індекс підгрупи дорівнює 2:

```
[ (ℤ/nℤ)* : Eₙ ] = |(ℤ/nℤ)*| / |Eₙ| ≥ 2
```

Звідси отримуємо строгу верхню оцінку на кількість брехунів Ейлера:

```
|Eₙ|
≤ (1 / 2) · |(ℤ/nℤ)*|      [за теоремою Лагранжа для власної підгрупи]
= φ(n) / 2                 [порядок мультиплікативної групи дорівнює φ(n)]
≤ (n - 1) / 2              [оскільки φ(n) < n - 1 для складеного n]
```

Це доводить, що при виборі випадкової основи `a ∈ [2, n - 1]` ймовірність того, що `a` виявиться брехуном Ейлера, **не перевищує 1/2**. Множина свідків Ейлера `Wₙ = (ℤ/nℤ)* \ Eₙ` становить принаймні 50% усіх елементів групи остач.
