# 🧮 Доведення межі 1/4 для тесту Міллера-Рабіна

Для будь-якого непарного складеного числа `n` кількість "баз-брехунів" (баз `a`, які обманюють тест) ніколи не перевищує `(n - 1) / 4`. Завдяки цьому гарантовано, що одна випадкова перевірка виявить складеність із ймовірністю щонайменше 75%. Звідки береться ця жорстка межа 1/4? Вона виникає як добуток двох математичних сил, кожна з яких відсікає принаймні половину кандидатів.

### Передумови: група оборотних елементів

Бази `a` вибираються з множини від `1` до `n - 1`. Якщо база має спільний дільник із числом `n` (тобто `gcd(a, n) > 1`), базовий алгоритм Евкліда чи порушення теореми Ферма одразу викриє складеність. Тому найнебезпечніші кандидати — це числа, взаємно прості з `n`.

Вони утворюють математичну групу, загальна кількість елементів якої позначається функцією Ейлера `φ(n)`. Для складених чисел `φ(n)` завжди строго менша за `n - 1`. Отже, якщо ми доведемо, що кількість брехунів не перевищує `φ(n) / 4`, це автоматично означатиме, що їх ще менше відносно загальної кількості `(n - 1) / 4`.

### Сила перша: теорема Лагранжа

Перший бар'єр тесту — це перевірка за Малою теоремою Ферма:
```text
a^(n - 1) ≡ 1 (mod n)
```
Усі бази, які задовольняють це рівняння, утворюють підгрупу групи взаємно простих чисел. Тут діє **теорема Лагранжа**: розмір будь-якої підгрупи завжди націло ділить загальний розмір групи.

Якщо існує хоча б одне взаємно просте число, яке не задовольняє умову, підгрупа не покриває всю групу. А оскільки її розмір є цілим дільником, то найбільший можливий розмір такої підгрупи — рівно половина. Щойно знаходиться одна «чесна» база, яка не проходить тест Ферма, ми автоматично знаємо, що щонайменше 50% усіх можливих баз його також не пройдуть. Маємо перший множник: 1/2.

### Сила друга: нетривіальні корені та розсинхронізація

Тепер поглянемо на ті бази, які пробили перший бар'єр. Серцевина тесту Міллера-Рабіна — це послідовне добування квадратного кореня з одиниці. Ми розкладаємо `n - 1 = d * 2^s` і підносимо `a^d` у квадрат крок за кроком. Аби обманути тест, цей ряд має закінчитися одиницею, а безпосередньо перед нею обов'язково мусить стояти `-1` (еквівалент `n - 1`).

Оскільки `n` є складеним, воно розкладається на прості множники, наприклад `n = p * q`. За Китайською теоремою про остачі, будь-яке обчислення за модулем `n` відбувається паралельно й абсолютно незалежно всередині кожного з модулів `p` та `q`.

Це означає, що коли ми бачимо підсумковий результат `-1 (mod n)`, насправді під капотом відбулося:
```text
x ≡ -1 (mod p)
x ≡ -1 (mod q)
```
Щоб база `a` стала сильним брехуном, `-1` мусить з'явитися **одночасно** для кожного простого дільника. Якщо база дійде до своєї `-1` за модулем `p` на одному кроці, а за модулем `q` — на іншому, то на проміжному етапі виникне розсинхронізація:
```text
x ≡  1 (mod p)
x ≡ -1 (mod q)
```
Для всього числа `n` таке `x` не дорівнює ні `1`, ні `-1`. Це нетривіальний корінь з одиниці, і тест на цьому кроці безпомилково оголосить число складеним.

Рівняння `x^2 = 1` для складеного числа з `k` різними простими множниками має `2^k` варіантів комбінацій коренів. З них лише два є тривіальними (суцільні одиниці або суцільні мінус одиниці). Отже, шанс ідеально синхронізувати корені на одному кроці становить `2 / (2^k)`. Оскільки множників щонайменше два (`k ≥ 2`), ця ймовірність не перевищує `2/4 = 1/2`. Це наш другий незалежний множник.

### Виняток: квадрат простого числа

Ситуація змінюється, якщо `n` має лише один простий множник, але в ступені — наприклад, `n = p^2`. Тут Китайська теорема про остачі не ділить число на незалежні модулі, і `k` не дорівнює 2. Але натомість працює обмеження порядків.

Розмір групи взаємно простих чисел для `p^2` становить `p * (p - 1)`. Аби база пройшла тест Ферма, її порядок мусить бути спільним дільником для `p * (p - 1)` та `p^2 - 1`. Спільний дільник цих двох значень дорівнює `p - 1`.

Отже, з `p * (p - 1)` можливих баз рівняння задовольняють не більше ніж `p - 1`. Обчислюємо частку:
```text
(p - 1) / (p * (p - 1)) = 1 / p
```
Оскільки ми перевіряємо лише непарні числа, найменше просте число `p = 3` (для `n = 9`). Перевіримо це на практиці: для `n = 9` є рівно 8 баз (від 1 до 8). Кількість баз-брехунів не перевищує `3 - 1 = 2`. Дві бази з восьми дають рівно `2/8 = 1/4`. Для будь-якого більшого простого числа (наприклад, `p = 5`) частка брехунів буде `1/5 < 1/4`. Тобто межа непорушна і тут.

### Підсумок

Обидва потужні фільтри — структурне обмеження Лагранжа для підгруп (множник `1/2`) та неминуча розсинхронізація коренів для різних множників (КТО, множник `1/2`) — діють незалежно і перемножуються.
```text
(1/2) * (1/2) = 1/4
```
У результаті кількість сильних баз-брехунів ніколи не може перетнути рубіж в одну чверть від усієї групи. Саме цей математичний доказ забезпечує тесту Міллера-Рабіна його абсолютну надійність на практиці.
