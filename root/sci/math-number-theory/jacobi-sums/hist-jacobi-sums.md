# 📜 Історія виникнення та розвитку сум Якобі

Історичний розвиток і еволюція сум Якобі в класичній та сучасній теорії чисел охоплює шлях від перших спроб Карла Фрідріха Гаусса порахувати кількість розв'язків кубічних і квартичних діофантових рівнянь до створення вищої теорії степенних законів взаємності, p-адичної аналітики André Weil та сучасного квазіполіноміального алгоритму перевірки простоти APR-CL.

## 1. Діофантові витоки: Гаусс і квадратичні суми (1801)

Витоки теорії арифметичних сум на скінченних полях сягають фундаментального шедевра Карла Фрідріха Гаусса (Carl Friedrich Gauss) *Disquisitiones Arithmeticae* (1801). Досліджуючи розподіл квадратичних лишків за модулем простого числа `p`, Гаусс зіштовхнувся з необхідністю підрахунку кількості розв'язків діофантових рівнянь виду:

```
x² + y² ≡ 1 (mod p)
```

Застосувавши квадратичний символ Лежандра `(a/p)` (латинське *symbolum*, що позначає належність елемента до класу квадратичних лишків), Гаусс виразив кількість розв'язків через скінченну суму добутків двох символів Лежандра:

```
N(x² + y² = 1) = ∑_{u + v ≡ 1 (mod p)} (1 + (u/p)) · (1 + (v/p))
```

Розкриваючи дужки під знаком сумування, Гаусс виділив три базові частини: головний член `p`, два перехресних члени, що обнуляються через ортогональність характерів, і нетривіальне ядро:

```
∑_{u + v ≡ 1 (mod p)} (u/p) · (v/p)
```

Це арифметичне ядро стало найпростішим історичним прикладом суми Якобі для двох квадратичних характерів. Гаусс довів, що значення цієї суми дорівнює `-(-1/p)` — тобто `-1` для простих чисел виду `p ≡ 1 (mod 4)` і `1` для `p ≡ 3 (mod 4)`.

Проте справжній геометричний і арифметичний прорив стався у розділі 358 *Disquisitiones Arithmeticae*, коли Гаусс звернувся до кубічного рівняння `x³ + y³ ≡ 1 (mod p)` для простих чисел вида `p ≡ 1 (mod 3)` та квартичного рівняння `x⁴ + y⁴ ≡ 1 (mod p)` для `p ≡ 1 (mod 4)`. Тут квадратичного символу Лежандра виявилося недостатньо, і виникла потреба в кубічних та квартичних характерах над скінченними полями `𝔽_p`. Гаусс виявив, що кількість розв'язків кубічного рівняння прямо виражається через представлення простого числа у вигляді квадратичної форми `4p = L² + 27M²`, але повного загального апарату характерних сум він на той час ще не опублікував.

## 2. Формалізація та систематична теорія Карла Якобі (1837–1839)

Видатний німецький математик Карл Густав Якоб Якобі (Carl Gustav Jacob Jacobi) у 1830-х роках систематично узагальнив ідеї Гаусса. На засіданні Берлінської академії наук у 1837 році та у фундаментальній праці 1839 року Якобі ввів у математичний ужиток загальне означення сум для двох довільних мультиплікативних характерів `χ₁` та `χ₂` над скінченним полем `𝔽_q`:

```
J(χ₁, χ₂) = ∑_{t ∈ 𝔽_q} χ₁(t) · χ₂(1 - t)
```

Якобі усвідомив, що ці суми не є просто зручним комбінаторним трюком для підрахунку точок. Вони є фундаментальними арифметичними об'єктами, які мають три ключові властивості:

1. **Комплексна нормалізація:** Модуль кожної нетривіальної суми Якобі дорівнює точно `√q` в комплексній площині `ℂ`.
2. **Алгебраїчна природа:** Значення `J(χ₁, χ₂)` лежать у кільці цілих кругового поля `ℤ[ζ_m]`, де `m` — порядок характерів.
3. **Факторизація сум Гаусса:** Сума Якобі розкладається у частку двох сум Гаусса:

```
J(χ₁, χ₂) = (g(χ₁, ψ) · g(χ₂, ψ)) / g(χ₁ · χ₂, ψ)
```

Ця формула факторизації стала мостом між мультиплікативною теорією характерів та адитивною аналітикою експоненційних сум. Завдяки цьому Якобі зміг сформулювати та довести закони кубічної та квартичної взаємності (грецьке *reciprocatio* — взаємний обмін лишками в кругових розширеннях). Якобі довів, що суми Якобі порядку `4` для простих `p ≡ 1 (mod 4)` безпосередньо розкладають число `p` на суму двох квадратів `p = a² + b²` у кільці цілих гауссових чисел `ℤ[i]`, де `J(χ, χ) = -a + i b`.

## 3. Кубічні розширення та внесок Айзенштайна (1844–1850)

Молодший сучасник Якобі, Готхольд Айзенштайн (Gotthold Eisenstein), поглибив теорію сум Якобі для кілець цілих комплексних чисел. Досліджуючи кільце чисел Айзенштайна `ℤ[ω]`, де `ω = e^{2π i / 3} = -1/2 + i √3 / 2`, Айзенштайн застосував суми Якобі від кубічних характерів для представлення простих чисел `p ≡ 1 (mod 3)` у вигляді квадратичної форми:

```
4p = L² + 27M²
```

Айзенштайн показав, що значення суми Якобі `J(χ, χ)` для кубічного характеру `χ` точно визначає цілі коефіцієнти `L` та `M` із умовою `L ≡ 1 (mod 3)` та `3 | M`. Це довело, що суми Якобі слугують мостом між дискретним аналізом на скінченних полях та глибинною структурою арифметики квадратичних і кубічних числових полів. 

Крім того, Айзенштайн розробив аналітичний метод доведення законів взаємності, використовуючи тригонометричні тотожності та добутки сум Якобі, що стало передвісником сучасної теорії модулярних форм.

## 4. Спектральний розклад Штікельберга (1890)

Наприкінці XIX століття швейцарський математик Людвіг Штікельбергер (Ludwig Stickelberger) опублікував фундаментальну працю *Ueber eine Verallgemeinerung der Kreistheilung* у часописі *Mathematische Annalen* (1890). Штікельбергер поставив питання: як саме головний ідеал, породжений сумою Якобі `(J(χᵃ, χᵇ))`, розкладається на просторні ідеали у круговому полі `ℚ(ζ_m)`?

Штікельбергер знайшов дивовижну формулу, яка пов'язала `p`-адичний порядок суми Якобі із сумами `p`-адичних цифр показників характерів:

```
v_𝔭(J(χᵃ, χᵇ)) = (s_p(a) + s_p(b) - s_p(a + b)) / (p - 1)
```

де `s_p(k)` позначила суму цифр числа `k` у `p`-адичній системі числення. Це відкриття довело, що показник степеня простого ідеалу в розкладі суми Якобі точно дорівнює кількості перенесень розрядів (англійське *digit carry*) при додаванні показників характерів `a` та `b` за модулем `p - 1`. Теорема Штікельбергера побудувала так званий ідеал Штікельбергера в груповому кільці `ℤ[G]` групи Galois `G = Galois(ℚ(ζ_m)/ℚ)`, що став основою для сучасної Івасавівської теорії кругових полів (Iwasawa theory) та теореми Мазура–Уілеса.

## 5. Гіпотези Вейля та геометрична революція XX століття (1949)

У 1949 році французький математик Андре Вейль (André Weil) опублікував епохальну статтю *Numbers of solutions of equations in finite fields* у часописі *Bulletin of the American Mathematical Society*. Вейль дослідив точний підрахунок кількості розв'язків для діагональних гіперповерхонь типу Ферма над скінченними полями `𝔽_q`:

```
c₁ x₁^{n₁} + c₂ x₂^{n₂} + ... + c_k x_k^{n_k} = 0
```

Вейль довів, що локальна дзета-функція `Z(T)` такої гіперповерхні є раціональною функцією, а її нулі та полюси виражаються безпосередньо через суми Якобі `J(χ₁,...,χ_k)`. Оскільки модуль кожної нетривіальної суми Якобі дорівнює `q^{(k-2)/2}`, це дало пряме доведення аналога Гіпотези Рімана для діагональних різноманітностей за чверть століття до загального доведення П'єра Деліня (Pierre Deligne) у 1974 році за допомогою алгебраїчної геометрії Ґротендіка.

## 6. Сучасне застосування: Алгоритм перевірки простоти APR-CL (1980–1984)

У 1980 році Леонард Адлеман (Leonard Adleman), Карл Померанс (Carl Pomerance) та Роберт Румелі (Robert Rumely), згодом удосконалені Анрі Коеном (Henri Cohen) та Хендріком Ленстрою (Hendrik Lenstra) у 1984 році, створили алгоритм APR-CL — один із найпотужніших детермінованих алгоритмів перевірки чисел на простоту.

Алгоритм APR-CL використовує тестові співвідношення для сум Якобі у кругових розширеннях `ℤ[ζ_m]`. Замість важкого ідеального розкладу алгоритм перевіряє порівняння для сум Якобі за модулем досліджуваного числа `N`. Якщо `N` є простим, суми Якобі задовольняють точні степеневі порівняння, які випливають із теореми Штікельбергера:

```
J(p, q)^{N - σ_N} ≡ ζ (mod N)
```

де `σ_N` — елемент Galois, а `ζ` — корінь з одиниці. Це дозволило досягти квазіполіноміального часу роботи `O((\log N)^{c \log \log \log N})`, що зробило суми Якобі практичним інструментом сучасної обчислювальної теорії чисел, математичної криптографії та комп'ютерної алгебри.
