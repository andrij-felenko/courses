# 📋 Інтерфейс та контракт обчислення сум Якобі

Модуль обчислення сум Якобі над скінченними полями `𝔽_q` реалізує формальний публічний контракт, структури даних, специфікацію функціональних інтерфейсів та зведені математичні таблиці.

Модуль надає уніфікований програмний інтерфейс для побудови мультиплікативних характерів, виконання експоненційного згортання за адитивними змінними, обчислення двовимірних та багатовимірних сум Якобі, а також точного визначення кількості розв'язків діофантових рівнянь Ферма. Він призначений для використання у числово-теоретичних бібліотеках, обчислювальних алгебраїчних системах та модулях перевірки простоти великих чисел.

Усі обчислення виконуються з дотриманням суворих вимог математичної точності та відсутності витоків пам'яті. Модуль оптимізований для високоефективного застосування у криптографічних протоколах на еліптичних кривих та числово-теоретичних алгоритмах факторизації.

## 1. Специфікація типів даних та контрактних структур

Для роботи з мультиплікативними характерами та сумами Якобі модуль визначає фундаментальні структури даних, які забезпечують безпечне управління пам'яттю, збереження обчислених логарифмічних таблиць та точну комплексну арифметику.

### 1.1. Контекст скінченного поля

Структура `PrimeField` виступає контейнером контексту для всього поля `𝔽_p`. Вона ініціалізує та зберігає масив дискретних логарифмів, що дозволяє іншим функціям виконувати оцінку характеру за сталий час `O(1)` замість обчислення тригонометричних функцій від нуля. Завдяки цьому обчислення великої кількості сум Якобі для одного й того ж поля не вимагає повторної ініціалізації логарифмічних масивів. Усі об'єкти поля гарантують повну потокобезпечність при паралельному читанні контексту з багатьох потоків виконання, оскільки об'єкт є незмінним після завершення створення.

### 1.2. Характери та результати обчислення

Структура `MultiplicativeCharacter` представляє конкретний характер `χ_k` порядку `d` над мультиплікативною групою `𝔽_p*`. Вона містить індекс характеру `k`, його алгебраїчний порядок `d` та вказівник на таблицю логарифмів відповідного поля.

Структура `JacobiSumResult` зберігає обчислене комплексне значення суми Якобі `J`, квадрат його комплексного модуля `|J|²`, прапорець нетривіальності характеру та логічний статус відповідності теоретичному модулю `√q`. Якщо модуль обчисленого значення відрізняється від `√q` більше ніж на `ε = 1e-9`, результат позначається прапорцем помилки обчислення.

### Таблиця 1: Структури даних модуля сум Якобі

| Назва структури / типу | Мовний еквівалент | Призначення та семантика |
| :--- | :--- | :--- |
| `PrimeField` | `struct PrimeField` (C) / `class Field` (C++) | Описує алгебраїчну структуру скінченного поля `𝔽_p` (модуль `p`, первісний корінь `g`, порядок групи `p-1`). |
| `MultiplicativeCharacter` | `struct MultiplicativeChar` (C) / `class Character` (C++) | Характер `χ_k` порядку `d` над `𝔽_p*` (значення `k`, порядок `d`, вектор дискретних логарифмів). |
| `JacobiSumResult` | `struct JacobiResult` (C) / `struct JacobiResult` (C++) | Результат обчислення суми Якобі: комплексне значення `J`, квадрат модуля `|J|²`, статус відповідності `√q`. |
| `FermatCurveConfig` | `struct CurveConfig` (C) / `struct CurveConfig` (C++) | Параметри діагональної кривої `xⁿ + yⁿ ≡ 1 (mod p)` (степінь `n`, модуль `p`, очікуваний рід `g = (n-1)(n-2)/2`). |

## 2. Публічний функціональний інтерфейс

Нижче наведено формальні сигнатури функцій та методів для виконання арифметичних операцій над сумами Якобі, побудови характерів та обчислення точок на кривих.

### 2.1. Конструювання полів та таблиць характерів

Функції ініціалізації перевіряють, чи є переданий модуль `p` простим числом, і шукають найменший первісний корінь `g`. Після цього будується таблиця дискретних логарифмів `ind_g(x)`. При виклику процедури в мові C виділяється динамічний масив розміром `p` елементів `int`, який повинен бути звільнений викликом `field_free`.

:::tabs
```c
/* Створення та ініціалізація скінченного поля F_p */
int field_init(PrimeField* field, uint64_t p);

/* Звільнення ресурсів поля */
void field_free(PrimeField* field);

/* Обчислення характеру χ_k(x) */
double complex character_eval(const PrimeField* field, uint64_t k, uint64_t x);
```
```cpp
namespace math::number_theory {

// Створення об'єкта поля F_p із перевіркою простоти
std::expected<PrimeField, FieldError> make_prime_field(uint64_t p);

// Отримання значення характеру χ_k(x)
[[nodiscard]] std::complex<double> eval_character(const PrimeField& field, uint64_t k, uint64_t x) noexcept;

} // namespace math::number_theory
```
:::

Перед викликом `eval_character` гарантується, що `x < p`. Для `x = 0` повертається точне комплексне значення `0.0 + 0.0i` для всіх нетривіальних характерів та `1.0 + 0.0i` для тривіального характеру.

### 2.2. Обчислення сум Якобі та підрахунок точок

Обчислення суми Якобі виконується шляхом ітерації по всіх елементах `t ∈ 𝔽_p` і додавання добутку `χ_a(t) · χ_b(1 - t)`. Для підрахунку точок на кривій Ферма `xⁿ + yⁿ ≡ 1 (mod p)` функція сумує `(n-1)²` нетривіальних сум Якобі і додає їх до головного члена `p`.

Часова складність виклику `compute_jacobi` становить `O(p)` операцій додавання та множення комплексних чисел. Просторова складність становить `O(1)` додаткової пам'яті поза збереженою таблицею поля.

:::tabs
```c
/* Обчислення суми Якобі J(χ_a, χ_b) над полем field */
JacobiResult compute_jacobi(const PrimeField* field, uint64_t a, uint64_t b);

/* Обчислення багатовимірної суми Якобі J(χ_1, χ_2, ..., χ_m) */
JacobiResult compute_jacobi_multidim(const PrimeField* field, const uint64_t* indices, size_t m);

/* Підрахунок точок на кривій Ферма x^n + y^n = 1 mod p */
int64_t count_fermat_points(const PrimeField* field, uint64_t n);
```
```cpp
namespace math::number_theory {

// Обчислення двовимірної суми Якобі
[[nodiscard]] JacobiResult compute_jacobi(const PrimeField& field, uint64_t a, uint64_t b) noexcept;

// Обчислення багатовимірної суми Якобі J(χ_1, ..., χ_m)
[[nodiscard]] JacobiResult compute_jacobi(const PrimeField& field, std::span<const uint64_t> indices) noexcept;

// Точний підрахунок кількості розв'язків діофантового рівняння x^n + y^n = 1 mod p
[[nodiscard]] std::expected<int64_t, CurveError> count_fermat_points(const PrimeField& field, uint64_t n) noexcept;

} // namespace math::number_theory
```
:::

Функція `count_fermat_points` приймає параметр `n`, який мусить ділити порядок мультиплікативної групи `p - 1`. Якщо `(p - 1) % n != 0`, повертається помилка `CurveError::DegreeDoesNotDivideOrder`.

## 3. Зведена таблиця тотожностей та граничних властивостей

Властивості сум Якобі залежать від тривіальності характерів-аргументів. При використанні модуля діють наступні алгебраїчні правила:

### Таблиця 2: Фундаментальні граничні властивості сум Якобі J(χ₁, χ₂)

| Умова на характери `χ₁` та `χ₂` | Значення суми Якобі `J(χ₁, χ₂)` | Комплексний модуль `\|J\|` | Математичний зміст |
| :--- | :--- | :--- | :--- |
| `χ₁ = χ₀` та `χ₂ = χ₀` (обидва тривіальні) | `q` | `q` | Повна сума одиниць по всьому полю `𝔽_q`. |
| `χ₁ ≠ χ₀`, а `χ₂ = χ₀` (один тривіальний) | `0` | `0` | Ортогональність характерів: `∑_{t ≠ 1} χ₁(t) = -χ₁(1) = 0`. |
| `χ₁ ≠ χ₀`, а `χ₂ = χ̄₁` (`χ₁ · χ₂ = χ₀`) | `-χ₁(-1)` | `1` | Інверсна згортка характеру зі своїм сопряженим. |
| `χ₁ ≠ χ₀`, `χ₂ ≠ χ₀` та `χ₁ · χ₂ ≠ χ₀` | `(g(χ₁) g(χ₂)) / g(χ₁ χ₂)` | `√q` | Нетривіальна сума Якобі, що лежить на колі радіуса `√q`. |

Усі нетривіальні значення сум Якобі задовольняють фундаментальну геометричну властивість: їхній модуль дорівнює точно `√q` в комплексній площині, що дає точну оцінку відхилення кількості точок на алгебраїчних кривих від головного члену `q`. При виконанні обчислень модуль автоматично перевіряє тотожність `|J|² = q` із точністю до машинного `ε = 1e-9`.

Дані тотожності дозволяють проводити автоматизовану верифікацію математичних результатів у юніт-тестах для довільних простих полів. Також модуль підтримує обчислення для довільних розширень Галуа `𝔽_{q^s}` через нормовий підйом Девенпорта–Хассе.

## 4. Специфікація кодів помилок та виняткових станів

При виконанні обчислень модуль повертає коди помилок або генерує виняткові стани, які виникають при порушенні математичних умов або невідповідності параметрів:

### 4.1. Обробка крайових випадків та відновлення

Помилка `ERR_NOT_PRIME` виникає при спробі ініціалізації поля складеним числом `p`. Модуль вимагає попередньої перевірки числа `p` тестом Міллера–Рабіна.

Помилка `ERR_DEGREE_MISMATCH` сигналізує про те, що обраний степінь кривої `n` не ділить `p - 1`. У цьому випадку обчислення точок через характери порядку `n` неможливе, і необхідно замінити `n` на `gcd(n, p - 1)`.

Помилка `ERR_MEMORY_ALLOC` виникає, якщо системі не вдалося виділити масив розміром `p * sizeof(int)` для таблиці логарифмів. Для систем із обмеженою пам'яттю рекомендується використовувати розряджені таблиці або обчислення логарифмів налету. При виникненні будь-якої помилки функція повертає від'ємний код, а виділені ресурси гарантовано звільняються.

Гарантія безпеки виконання викликів забезпечується суворими контрактами передумов (preconditions) та постумов (postconditions). При некоректних аргументах пам'ять не протікає.

Також модуль підтримує обчислення з високою точністю для полів великого розміру, запобігаючи втраті значущих розрядів при підсумовуванні багатьох комплексних фаз.

### Таблиця 3: Коди помилок модуля обчислення сум Якобі

| Код помилки | Константа / Виняток | Причина виникнення | Спосіб обробки та відновлення |
| :--- | :--- | :--- | :--- |
| `0x00` | `SUCCESS` / `Ok` | Успішне обчислення. | Повертається обчислене комплексне значення `J`. |
| `0x01` | `ERR_NOT_PRIME` | Аргумент `p` не є простим числом. | Перевірити `p` тестом Міллера–Рабіна перед ініціалізацією. |
| `0x02` | `ERR_DEGREE_MISMATCH` | Степінь `n` не ділить порядок `p - 1`. | Зменшити степінь `n` до `gcd(n, p - 1)`. |
| `0x03` | `ERR_MEMORY_ALLOC` | Помилка виділення пам'яті під таблицю. | Перевірити обсяг доступної RAM для полів великого розміру. |

Правильна обробка помилок дозволяє гарантувати стабільність криптографічних алгоритмів та уникнути невизначеної поведінки при виконанні тесту простоти APR-CL та обчисленні алгебраїчних кривих.
