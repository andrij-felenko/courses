# 🧮 Виведення рівняння рекомбінації SRH з кінетичних рівнянь

Математична вставка дає суворе виведення рівняння швидкості рекомбінації Шокли — Рида — Холла (`R_{SRH}`) з кінетичних рівнянь балансу носіїв заряду та принципу детальної рівноваги у стаціонарному стані.

### 1. Фізична модель і кінетика чотирьох елементарних процесів

Розглядаємо однорідний напівпровідник із нерівноважними концентраціями вільних електронів `n` у зоні провідності, вільних дірок `p` у валентній зоні та глибоких пасток із загальною об'ємною концентрацією `N_t` (см⁻³) й дискретним енергетичним рівнем `E_t` у забороненій зоні.

У будь-який момент часу квантовий стан пастки описується ступенем її заповнення: позначимо через `f` імовірність того, що пастка **зайнята електроном** (перебуває у відновленому/нейтральному або негативно зарядженому стані). Відповідно, імовірність того, що пастка **порожня** (готова прийняти електрон з зони провідності або захопити дірку з валентної зони), дорівнює `(1 - f)`.

Об'ємна концентрація пасток, зайнятих електронами, дорівнює `N_t · f`, а концентрація порожніх пасток дорівнює `N_t · (1 - f)`.

Запишемо швидкості чотирьох елементарних квантових процесів в одиниці об'єму напівпровідника (вимірюються в см⁻³·с⁻¹):

```
1. Захоплення електрона із зони провідності порожньою пасткою:
r_a = C_n · n · N_t · (1 - f)

2. Зворотна теплова емісія електрона з пастки у зону провідності:
r_b = e_n · N_t · f

3. Захоплення дірки з валентної зони зайнятою пасткою (рекомбінація):
r_c = C_p · p · N_t · f

4. Зворотна емісія дірки з пастки у валентну зону (генерація):
r_d = e_p · N_t · (1 - f)
```

У цих рівняннях використано такі коефіцієнти взаємодії:
- `C_n = σ_n · v_{th,n}` — коефіцієнт захоплення електронів (см³/с), де `σ_n` — переріз захоплення електрона пасткою (см²), `v_{th,n}` — теплова швидкість електрона;
- `C_p = σ_p · v_{th,p}` — коефіцієнт захоплення дірок (см³/с), де `σ_p` — переріз захоплення дірки;
- `e_n` — коефіцієнт зворотної емісії електронів з пастки в зону провідності (с⁻¹);
- `e_p` — коефіцієнт зворотної емісії дірок з пастки у валентну зону (с⁻¹).

### 2. Застосування принципу детальної рівноваги в термодинамічній рівновазі

Коефіцієнти емісії `e_n` та `e_p` залежать від внутрішньої структури потенціальної ями пастки та температури ґратки. Оскільки напряму виміряти їх надзвичайно важко, застосуємо **принцип детальної рівноваги** (*principle of detailed balance*).

У стані повної термодинамічної рівноваги (при засуві напруги `V = 0`, без зовнішнього освітлення чи випромінювання) концентрації носіїв дорівнюють своїм рівноважним значенням `n_0` та `p_0`. При цьому кожен елементарний процес рекомбінації строго врівноважується зворотним процесом генерації:

```
r_a0 = r_b0  [рівновага потоку електронів: C_n · n_0 · N_t · (1 - f_0) = e_n · N_t · f_0]
r_c0 = r_d0  [рівновага потоку дірок: C_p · p_0 · N_t · f_0 = e_p · N_t · (1 - f_0)]
```

Звідси виражаємо невідомі коефіцієнти емісії `e_n` та `e_p` через рівноважні параметри:

```
e_n = C_n · n_0 · (1 - f_0) / f_0  [виражено e_n з умови r_a0 = r_b0]
e_p = C_p · p_0 · f_0 / (1 - f_0)  [виражено e_p з умови r_c0 = r_d0]
```

У стані термодинамічної рівноваги імовірність заповнення пастки `f_0` підпорядковується статистиці Фермі — Дірака з єдиним рівнянням Фермі `E_F`:

```
f_0 = 1 / (1 + exp((E_t - E_F) / (k_B · T)))  [розподіл Фермі — Дірака]
```

Знайдемо відношення імовірностей перебування пастки у порожньому та зайнятому станах:

```
(1 - f_0) / f_0
= (1 + exp((E_t - E_F) / (k_B · T)) - 1)    [підставлено розподіл f_0]
= exp((E_t - E_F) / (k_B · T))              [зведено подібні доданки 1 - 1 = 0]
```

Згадаємо фундаментальні рівняння для рівноважних концентрацій вільних електронів `n_0` та вільних дірок `p_0` через власну концентрацію напівпровідника `n_i` та рівень Фермі власного напівпровідника `E_i`:

```
n_0 = n_i · exp((E_F - E_i) / (k_B · T))  [концентрація електронів через n_i]
p_0 = n_i · exp((E_i - E_F) / (k_B · T))  [концентрація дірок через n_i]
```

Підставимо ці вирази у формули для коефіцієнтів емісії:

```
e_n
= C_n · n_0 · exp((E_t - E_F) / (k_B · T))                                [підставлено відношення (1 - f_0)/f_0]
= C_n · n_i · exp((E_F - E_i) / (k_B · T)) · exp((E_t - E_F) / (k_B · T)) [підставлено вираз для n_0]
= C_n · n_i · exp((E_t - E_i) / (k_B · T))                                [скорочено рівень Фермі E_F у показнику]
= C_n · n_1                                                                [введено параметр n_1]

e_p
= C_p · p_0 · exp((E_F - E_t) / (k_B · T))                                [підставлено відношення f_0/(1 - f_0)]
= C_p · n_i · exp((E_i - E_F) / (k_B · T)) · exp((E_F - E_t) / (k_B · T)) [підставлено вираз для p_0]
= C_p · n_i · exp((E_i - E_t) / (k_B · T))                                [скорочено рівень Фермі E_F у показнику]
= C_p · p_1                                                                [введено параметр p_1]
```

Параметри `n_1` та `p_1` мають чіткий фізичний зміст: це концентрації електронів у зоні провідності та дірок у валентній зоні відповідно у тому гіпотетичному випадку, коли рівень Фермі `E_F` точно збігається з енергетичним рівнем пастки `E_t`.

### 3. Рівняння стаціонарного стану та знаходження ступеня заповнення f

У нерівноважному стаціонарному стані (наприклад, під впливом постійної інжекції струму або стаціонарного освітлення) концентрації носіїв приймають значення `n` та `p`. Швидкість зміни концентрації електронів на пастках дорівнює нулю:

```
d(N_t · f) / dt = (r_a - r_b) - (r_c - r_d) = 0  [умова стаціонарності]
```

Це означає, що чистий результуючий потік електронів із зони провідності на пастки дорівнює чистому результуючому потоку дірок із валентної зони на пастки:

```
U_n = r_a - r_b = C_n · n · N_t · (1 - f) - e_n · N_t · f  [результуючий потік електронів]
U_p = r_c - r_d = C_p · p · N_t · f - e_p · N_t · (1 - f)  [результуючий потік дірок]

У стаціонарному стані: U_n = U_p = R_{SRH}                [баланс швидкостей]
```

Підставимо у цю рівність знайдені значення `e_n = C_n · n_1` та `e_p = C_p · p_1`:

```
C_n · n · N_t · (1 - f) - C_n · n_1 · N_t · f
= C_p · p · N_t · f - C_p · p_1 · N_t · (1 - f)   [підставлено коефіцієнти емісії]
```

Скоротимо обидві частини рівняння на загальну концентрацію пасток `N_t` і розкриємо дужки для вираження ступеня заповнення `f`:

```
C_n · n - C_n · n · f - C_n · n_1 · f
= C_p · p · f - C_p · p_1 + C_p · p_1 · f         [розкрито дужки при f]
= C_n · n + C_p · p_1
= f · (C_n · n + C_n · n_1 + C_p · p + C_p · p_1)  [групування доданків із f]
```

Звідси отримуємо вираз для стаціонарного ступеня заповнення пасток електронами `f`:

```
f = (C_n · n + C_p · p_1) / (C_n · (n + n_1) + C_p · (p + p_1))  [знайдено f з балансу]
```

### 4. Підстановка f та отримання результуючого рівняння R_{SRH}

Підставимо отримане значення `f` у вираз для рекомбінаційного потоку електронів `R_{SRH} = C_n · N_t · [n · (1 - f) - n_1 · f]`:

```
R_{SRH}
= C_n · N_t · [ n - f · (n + n_1) ]                                                      [винесено спільний множник]
= C_n · N_t · [ n - ((C_n · n + C_p · p_1) · (n + n_1)) / (C_n · (n + n_1) + C_p · (p + p_1)) ] [підставлено вираз для f]
```

Зведемо вираз у квадратних дужках до спільного знаменника та перетворимо чисельник:

```
Чисельник
= n · [C_n · (n + n_1) + C_p · (p + p_1)] - (C_n · n + C_p · p_1) · (n + n_1) [зведено до спільного знаменника]
= C_n · n · (n + n_1) + C_p · n · (p + p_1) - C_n · n · (n + n_1) - C_p · p_1 · (n + n_1) [розкрито дужки]
= C_p · n · p + C_p · n · p_1 - C_p · p_1 · n - C_p · p_1 · n_1               [скорочено C_n · n · (n + n_1)]
= C_p · (n · p - n_1 · p_1)                                                   [винесено C_p і скорочено взаємні доданки]
```

Звернемо увагу на добуток `n_1 · p_1`:

```
n_1 · p_1
= n_i · exp((E_t - E_i) / (k_B · T)) · n_i · exp((E_i - E_t) / (k_B · T)) [перемножено показники]
= n_i²                                                                    [скорочено показниковий доданок]
```

Множимо чисельник на `C_n · N_t` і отримуємо канонічну формулу Шокли — Рида — Холла для швидкості рекомбінації:

```
R_{SRH} = (C_n · C_p · N_t · (n · p - n_i²)) / (C_n · (n + n_1) + C_p · (p + p_1))  [канонічне рівняння SRH]
```

### 5. Перехід до характеристичних часів життя τ_{n0} та τ_{p0} та виведення граничних випадків

У практичній фізиці напівпровідників замість мікроскопічних коефіцієнтів `C_n` та `C_p` зручніше використовувати макроскопічні часи життя неосновних носіїв при низькому рівні інжекції:

```
τ_{n0} = 1 / (C_n · N_t) = 1 / (σ_n · v_{th,n} · N_t)  [час життя електрона у p-матеріалі]
τ_{p0} = 1 / (C_p · N_t) = 1 / (σ_p · v_{th,p} · N_t)  [час життя дірки у n-матеріалі]
```

Поділимо чисельник і знаменник канонічної формули `R_{SRH}` на `(C_n · C_p · N_t)`:

```
R_{SRH} = (n · p - n_i²) / ( (1 / (C_p · N_t)) · (n + n_1) + (1 / (C_n · N_t)) · (p + p_1) )  [поділено на C_n · C_p · N_t]
```

Підставляючи `τ_{n0}` та `τ_{p0}`, отримуємо стандартний вигляд рівняння SRH:

```
R_{SRH} = (n · p - n_i²) / (τ_{p0} · (n + n_1) + τ_{n0} · (p + p_1))  [стандартний вигляд через часи життя]
```

#### Виведення режиму низького рівня інжекції (Low Injection Level)
У напівпровіднику p-типу з рівноважною концентрацією дірок `p_0 >> n_0` додамо надлишкові носії `Δn = Δp << p_0`. Тоді `p = p_0 + Δn ≈ p_0` та `n = n_0 + Δn`.

Підставимо ці концентрації у рівняння SRH для глибокої пастки, де `n_1, p_1 << p_0`:

```
R_{SRH}
= ((n_0 + Δn) · p_0 - n_i²) / (τ_{p0} · (Δn + n_1) + τ_{n0} · (p_0 + p_1))  [підставлено нерівноважні концентрації]
= (n_0 · p_0 + Δn · p_0 - n_i²) / (τ_{n0} · p_0)                            [нехтуємо дрібними доданками]
= (Δn · p_0) / (τ_{n0} · p_0)                                               [враховано рівноважну умову n_0 · p_0 = n_i²]
= Δn / τ_{n0}                                                               [скорочено p_0 у чисельнику та знаменнику]
```

Звідси отримуємо фундаментальний закон для низької інжекції: час життя неосновних носіїв є константою `τ_n = τ_{n0}` і не залежить від концентрації інжектованих носіїв.

#### Виведення режиму високого рівня інжекції (High Injection Level)
Під високим рівнем інжекції `Δn = Δp >> p_0, n_0`. Отже, `n ≈ Δn` та `p ≈ Δn`.

Підставляємо ці значення у канонічну формулу SRH:

```
R_{SRH}
= (Δn² - n_i²) / (τ_{p0} · (Δn + n_1) + τ_{n0} · (Δn + p_1))   [підставлено n = p = Δn]
= Δn² / (τ_{p0} · Δn + τ_{n0} · Δn)                           [нехтуємо n_i², n_1, p_1 порівняно з Δn]
= Δn² / (Δn · (τ_{p0} + τ_{n0}))                              [винесено Δn за дужки у знаменнику]
= Δn / (τ_{n0} + τ_{p0})                                       [скорочено Δn у чисельнику та знаменнику]
```

Таким чином, ефективний час життя під високою інжекцією дорівнює сумі двох характеристичних часів: `τ_{HIL} = τ_{n0} + τ_{p0}`.

#### Виведення швидкості генерації у збідненій області
У збідненій області zворотно зсунутого p-n переходу електронне поле вимиває всі вільні носії, тож `n ≈ 0` та `p ≈ 0`.

Підставляючи ці значення у канонічну формулу SRH, отримуємо швидкість генерації носіїв `G_{SRH} = -R_{SRH}`:

```
G_{SRH}
= - (- n_i²) / (τ_{p0} · n_1 + τ_{n0} · p_1)                                [підставлено n = 0, p = 0]
= n_i² / (τ_{p0} · n_i · exp((E_t - E_i)/k_B T) + τ_{n0} · n_i · exp((E_i - E_t)/k_B T)) [підставлено вирази для n_1 та p_1]
= n_i / (τ_{p0} · exp((E_t - E_i)/k_B T) + τ_{n0} · exp((E_i - E_t)/k_B T))  [скорочено n_i у чисельнику та знаменнику]
```

Якщо пастка розташована строго посередині забороненої зони (`E_t = E_i`) і часи життя однакові (`τ_{n0} = τ_{p0} = τ_0`), швидкість генерації приймає свій відомий вигляд:

```
G_{SRH} = n_i / (2 · τ_0)  [швидкість генерації у збідненому шарі]
```

Ця формула використовується в фізиці напівпровідникових приладів для розрахунку темного струму витоку p-n переходів та пікселів КМОН-сенсорів зображення.
