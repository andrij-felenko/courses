# 🧮 Виведення рівняння рекомбінації SRH з кінетичних рівнянь

Статистична теорія рекомбінації Шокли — Рида — Холла (Shockley-Read-Hall, SRH) описує кінетику винищення та теплової генерації нерівноважних носіїв заряду в напівпровідниках через локалізовані квантові стани (пастки) у забороненій зоні. Повний математичний апарат базується на системі диференціальних рівнянь балансу між чотирма елементарними процесами захоплення й емісії, принципі мікроскопічної оборотності та статистиці Фермі — Дірака.

### 1. Фізична модель, квантові стани та мікроскопічна кінетика чотирьох переходів

Розглядаємо однорідний напівпровідник із шириною забороненої зони `E_g = E_c - E_v`, де `E_c` — енергетичне дно зони провідності, `E_v` — стеля валентної зони, `E_i` — рівень Фермі власного напівпровідника. У кристалі присутні глибокі домішкові центри або структурні дефекти ґратки з об'ємною концентрацією `N_t` (см⁻³) та дискретним енергетичним рівнем `E_t` у забороненій зоні.

Квантовий стан локалізованого центру описується ступенем його заповнення електронами: позначимо через `f_t` імовірність того, що стан `E_t` зайнятий електроном. Відповідно, імовірність того, що пастка порожня (здатна прийняти вільний електрон із зони провідності або віддати електрон у валентну зону, що еквівалентно захопленню дірки), становить `1 - f_t`.

Об'ємна концентрація зайнятих пасток дорівнює `n_t = N_t · f_t`, а об'ємна концентрація порожніх пасток дорівнює `p_t = N_t · (1 - f_t)`. Повна концентрація центрів зберігається: `n_t + p_t = N_t`.

Локалізований центр володіє квантовомеханічним фактором виродження. Нехай `g_0` — статистична вага (кратність виродження) порожнього стану дефекту, а `g_1` — кратність виродження стану, зайнятого електроном. Для простого донорного рівня з урахуванням двох можливих орієнтацій спіну захопленого електрона кратність зайнятого стану становить `g_1 = 2`, а порожнього — `g_0 = 1`. Для акцепторного рівня зазвичай `g_0 = 1`, `g_1 = 4` або `g_0 = 2`, `g_1 = 1` через складну валентну зону з виродженням легких і важких дірок. Введемо безрозмірний фактор виродження `g = g_1 / g_0`.

Динаміка обміну носіями заряду між енергетичними зонами кристала та глибоким рівнем `E_t` визначається чотирма елементарними процесами, швидкості яких в одиниці об'єму (см⁻³·с⁻¹) мають такий вигляд:

```
1. Захоплення вільного електрона із зони провідності порожньою пасткою:
r_a = c_n · n · N_t · (1 - f_t)

2. Зворотна теплова емісія електрона з пастки у зону провідності:
r_b = e_n · N_t · f_t

3. Захоплення вільної дірки з валентної зони зайнятою пасткою (рекомбінація):
r_c = c_p · p · N_t · f_t

4. Зворотна теплова емісія дірки з пастки у валентну зону (генерація):
r_d = e_p · N_t · (1 - f_t)
```

Мікроскопічний механізм захоплення носіїв базується на квантовому переході електрона чи дірки з вільного делокалізованого стану блохівської хвилі у сильно локалізований стан дефекту. Коефіцієнт захоплення електронів `c_n` (см³/с) є результатом квантово-статистичного усереднення добутку перерізу захоплення `σ_n(v)` на швидкість вільного електрона `v` за больцманівським розподілом швидкостей:

```
c_n = ⟨σ_n(v) · v⟩ = ∫ σ_n(v) · v · f_0(v) d³v
```

У незродженому напівпровіднику з параболічною зоною провідності та ефективною масою густини станів `m_n*` інтегрування дає макроскопічний вираз через середньоквадратичну теплову швидкість електронів:

```
c_n = σ_n · v_{th,n}
```

де теплова швидкість електрона визначається з рівнорозподілу кінетичної енергії за ступенями вільності:

```
(1 / 2) · m_n* · v_{th,n}² = (3 / 2) · k_B · T
v_{th,n} = √(3 · k_B · T / m_n*)
```

Аналогічно, коефіцієнт захоплення дірок `c_p` (см³/с) виражається через переріз захоплення дірки `σ_p` та середню теплову швидкість дірок у валентній зоні `v_{th,p}`:

```
c_p = σ_p · v_{th,p} = σ_p · √(3 · k_B · T / m_p*)
```

Параметри `e_n` та `e_p` є коефіцієнтами теплової емісії (с⁻¹), які задають імовірність того, що захоплений на пастку носій заряду отримає від теплових коливань ґратки (фононів) достатню порцію енергії для повернення у відповідну дозволену зону.

### 2. Термодинамічна рівновага та принцип детальної рівноваги

Коефіцієнти теплової емісії `e_n` та `e_p` залежать від внутрішньої структури дефекту, багатофононного зв'язку та спектра коливань ґратки. Отримати їхнє аналітичне співвідношення з коефіцієнтами захоплення `c_n` та `c_p` дозволяє фундаментальний принцип детальної рівноваги (*principle of detailed balance*), який випливає з мікроскопічної оборотності рівнянь квантової механіки відносно обернення часу.

У стані повної термодинамічної рівноваги за відсутності зовнішніх збурень (напруга `V = 0`, освітлення відсутнє, температура стала) в системі встановлюються рівноважні концентрації електронів `n_0` і дірок `p_0`. При цьому кожен елементарний прямий квантовий процес повинен строго врівноважуватися відповідним зворотним процесом:

```
r_a0 = r_b0  [потокова рівновага зони провідності та пасток]
r_c0 = r_d0  [потокова рівновага валентної зони та пасток]
```

Підставимо у ці рівності вирази для швидкостей процесів при рівноважній функції заповнення `f_0`:

```
c_n · n_0 · N_t · (1 - f_0) = e_n · N_t · f_0   [умова r_a0 = r_b0]
c_p · p_0 · N_t · f_0 = e_p · N_t · (1 - f_0)   [умова r_c0 = r_d0]
```

Скорочуючи загальну концентрацію пасток `N_t`, виражаємо невідомі коефіцієнти емісії через рівноважні статистичні величини:

```
e_n = c_n · n_0 · ((1 - f_0) / f_0)  [коефіцієнт емісії електронів]
e_p = c_p · p_0 · (f_0 / (1 - f_0))  [коефіцієнт емісії дірок]
```

У стані термодинамічної рівноваги розподіл електронів за локалізованими станами підпорядковується статистиці Гіббса з урахуванням фактора квантового виродження `g = g_1 / g_0` та єдиного рівня Фермі `E_F`:

```
f_0 = 1 / (1 + (g_0 / g_1) · exp((E_t - E_F) / (k_B · T)))
f_0 = 1 / (1 + (1 / g) · exp((E_t - E_F) / (k_B · T)))  [розподіл Фермі — Дірака для пасток]
```

Знайдемо алгебраїчне відношення імовірностей перебування пастки у порожньому та зайнятому станах:

```
(1 - f_0) / f_0
= (1 / f_0) - 1                                                    [алгебраїчне перетворення]
= 1 + (1 / g) · exp((E_t - E_F) / (k_B · T)) - 1                  [підставлено розподіл f_0]
= (1 / g) · exp((E_t - E_F) / (k_B · T))                           [зведено подібні доданки 1 - 1 = 0]
```

Обернене відношення для діркової емісії набуває вигляду:

```
f_0 / (1 - f_0)
= 1 / ((1 - f_0) / f_0)                                            [обернена величина]
= g · exp(-(E_t - E_F) / (k_B · T))                                [піднесено експоненту до степеня -1]
= g · exp((E_F - E_t) / (k_B · T))                                 [внесено знак мінус у показник]
```

Рівноважні концентрації вільних електронів `n_0` та вільних дірок `p_0` у незродженому напівпровіднику задаються больцманівськими інтегралами за густиною станів у зонах:

```
n_0 = N_c · exp(-(E_c - E_F) / (k_B · T)) = n_i · exp((E_F - E_i) / (k_B · T))
p_0 = N_v · exp(-(E_F - E_v) / (k_B · T)) = n_i · exp((E_i - E_F) / (k_B · T))
```

де `N_c` та `N_v` — ефективні густини квантових станів у зоні провідності та валентній зоні відповідно, `n_i` — власна концентрація носіїв у нелегованому напівпровіднику.

Підставимо ці вирази у формулу для коефіцієнта емісії електронів `e_n`:

```
e_n
= c_n · n_0 · (1 / g) · exp((E_t - E_F) / (k_B · T))                                            [вихідне співвідношення]
= c_n · N_c · exp(-(E_c - E_F) / (k_B · T)) · (1 / g) · exp((E_t - E_F) / (k_B · T))           [підставлено n_0 через N_c]
= c_n · (N_c / g) · exp( (-(E_c - E_F) + (E_t - E_F)) / (k_B · T) )                            [об'єднано показники експонент]
= c_n · (N_c / g) · exp(-(E_c - E_t) / (k_B · T))                                              [рівень Фермі E_F повністю скоротився]
= c_n · n_1                                                                                    [введено статистичний параметр n_1]
```

Виразимо `e_n` також через власну концентрацію `n_i` та власний рівень `E_i`:

```
e_n
= c_n · n_i · exp((E_F - E_i) / (k_B · T)) · (1 / g) · exp((E_t - E_F) / (k_B · T))           [підставлено n_0 через n_i]
= c_n · (n_i / g) · exp( ((E_F - E_i) + (E_t - E_F)) / (k_B · T) )                            [об'єднано показники експонент]
= c_n · (n_i / g) · exp((E_t - E_i) / (k_B · T))                                              [рівень Фермі E_F скоротився]
= c_n · n_1                                                                                    [еквівалентний вираз для n_1]
```

Виконаємо аналогічний покроковий вивід для коефіцієнта емісії дірок `e_p`:

```
e_p
= c_p · p_0 · g · exp((E_F - E_t) / (k_B · T))                                                 [вихідне співвідношення]
= c_p · N_v · exp(-(E_F - E_v) / (k_B · T)) · g · exp((E_F - E_t) / (k_B · T))                [підставлено p_0 через N_v]
= c_p · (g · N_v) · exp( (-(E_F - E_v) + (E_F - E_t)) / (k_B · T) )                            [об'єднано показники експонент]
= c_p · (g · N_v) · exp(-(E_t - E_v) / (k_B · T))                                              [рівень Фермі E_F повністю скоротився]
= c_p · p_1                                                                                    [введено статистичний параметр p_1]
```

Виразимо `e_p` через власну концентрацію `n_i`:

```
e_p
= c_p · n_i · exp((E_i - E_F) / (k_B · T)) · g · exp((E_F - E_t) / (k_B · T))                [підставлено p_0 через n_i]
= c_p · (g · n_i) · exp( ((E_i - E_F) + (E_F - E_t)) / (k_B · T) )                            [об'єднано показники експонент]
= c_p · (g · n_i) · exp((E_i - E_t) / (k_B · T))                                              [рівень Фермі E_F скоротився]
= c_p · p_1                                                                                    [еквівалентний вираз для p_1]
```

Статистичні параметри `n_1` та `p_1` мають строгий фізичний зміст:
- `n_1` — це концентрація вільних електронів у зоні провідності, яка встановилася б у кристалі, якби рівень Фермі `E_F` точно збігся з енергетичним рівнем пастки `E_t` (з поправкою на виродження);
- `p_1` — це концентрація вільних дірок у валентній зоні, яка встановилася б у кристалі, якби рівень Фермі точно збігся з енергетичним рівнем пастки `E_t`.

Знайдемо фундаментальний добуток параметрів `n_1 · p_1`:

```
n_1 · p_1
= [ (n_i / g) · exp((E_t - E_i) / (k_B · T)) ] · [ (g · n_i) · exp((E_i - E_t) / (k_B · T)) ]  [підставлено вирази через n_i]
= (n_i² / g) · g · exp( ((E_t - E_i) + (E_i - E_t)) / (k_B · T) )                              [перемножено множники та згруповано показники]
= n_i² · exp(0)                                                                                [скорочено фактор g і показник дорівнює нулю]
= n_i²                                                                                         [термодинамічний інваріант]
```

Добуток `n_1 · p_1 = n_i²` є універсальним термодинамічним інваріантом: він строго дорівнює квадрату власної концентрації носіїв за будь-якого положення енергетичного рівня пастки `E_t` та будь-яких факторів виродження `g`.

Оскільки коефіцієнти емісії `e_n` та `e_p` визначаються лише локальною структурою центру та фононним спектром ґратки, вони не залежать від того, чи перебуває напівпровідник у рівновазі, чи під сильним зовнішнім збудженням. Тому співвідношення `e_n = c_n · n_1` та `e_p = c_p · p_1` залишаються абсолютно точними і в нерівноважних умовах.

### 3. Нестаціонарне диференціальне рівняння балансу та динаміка релаксації пасток

Розглянемо кінетику системи в нерівноважному стані, коли концентрації вільних електронів `n(t)` та вільних дірок `p(t)` змінюються в часі. Швидкість накопичення електронів на пастках визначається алгебраїчною сумою швидкостей усіх чотирьох елементарних процесів:

```
d(N_t · f_t) / dt = (r_a - r_b) - (r_c - r_d)
```

Перша дужка `r_a - r_b` задає результуючий потік електронів із зони провідності на пастки (захоплення мінус емісія). Друга дужка `r_c - r_d` задає результуючий потік захоплення дірок (що еквівалентно результуючому переходу електронів із пасток у валентну зону).

Підставимо мікроскопічні швидкості та вирази для коефіцієнтів емісії:

```
N_t · (d f_t / dt)
= c_n · n · N_t · (1 - f_t) - e_n · N_t · f_t - [ c_p · p · N_t · f_t - e_p · N_t · (1 - f_t) ]
= c_n · n · N_t · (1 - f_t) - c_n · n_1 · N_t · f_t - c_p · p · N_t · f_t + c_p · p_1 · N_t · (1 - f_t)
```

Скоротимо обидві частини рівняння на повну об'ємну концентрацію центрів `N_t`:

```
d f_t / dt
= c_n · n · (1 - f_t) - c_n · n_1 · f_t - c_p · p · f_t + c_p · p_1 · (1 - f_t)
= c_n · n - c_n · n · f_t - c_n · n_1 · f_t - c_p · p · f_t + c_p · p_1 - c_p · p_1 · f_t
= (c_n · n + c_p · p_1) - f_t · [ c_n · (n + n_1) + c_p · (p + p_1) ]
```

Це лінійне неоднорідне диференціальне рівняння першого порядку відносно функції заселеності пасток `f_t(t)`:

```
d f_t / dt + (1 / τ_t) · f_t = S(t)
```

де введено характерну частоту релаксації пастки `1 / τ_t` та функцію джерела `S(t)`:

```
1 / τ_t = c_n · (n + n_1) + c_p · (p + p_1)  [обернений час релаксації заповнення пастки]
S(t) = c_n · n(t) + c_p · p_1                [швидкість генераційно-захоплювального джерела]
```

Якщо концентрації вільних носіїв `n` та `p` є сталими (або змінюються набагато повільніше за `τ_t`), коефіцієнти рівняння стають константами. Загальний розв'язок із початковою умовою `f_t(0)` знаходиться інтегруванням:

```
f_t(t) = f_t(∞) + [ f_t(0) - f_t(∞) ] · exp(-t / τ_t)
```

де асимптотичне стаціонарне значення заселеності пастки при `t → ∞` дорівнює:

```
f_t(∞) = S · τ_t = (c_n · n + c_p · p_1) / [ c_n · (n + n_1) + c_p · (p + p_1) ]
```

Фізичний зміст параметра `τ_t` полягає в тому, що він визначає внутрішній інерційний час квантового відгуку дефекту на будь-які зовнішні флуктуації.

Розглянемо випадок малих гармонічних збурень концентрацій носіїв:

```
n(t) = n_0 + δn · exp(i · ω · t)
p(t) = p_0 + δp · exp(i · ω · t)
f_t(t) = f_0 + δf_t · exp(i · ω · t)
```

Підставляючи ці варіації у диференціальне рівняння балансу та лінеаризуючи за малими амплітудами `δn`, `δp`, `δf_t`, отримуємо комплексну амплітуду коливань заряду пасток:

```
i · ω · δf_t = c_n · (1 - f_0) · δn - c_p · f_0 · δp - (1 / τ_t) · δf_t
δf_t · (1 / τ_t + i · ω) = c_n · (1 - f_0) · δn - c_p · f_0 · δp
δf_t(ω) = [ c_n · (1 - f_0) · δn - c_p · f_0 · δp ] / [ 1 / τ_t + i · ω ]
```

Цей результат є математичним фундаментом спектроскопії адмітансу та ємнісної спектроскопії глибоких рівнів (DLTS — *Deep-Level Transient Spectroscopy*).

На низьких частотах (`ω · τ_t << 1`) пастки встигають перезаряджатися вслід за змінним електричним полем, забезпечуючи максимальний внесок у низькочастотну ємність p-n переходу або структури метал-діелектрик-напівпровідник: `C_{trap} = q · N_t · (d f_t / dV)`. На високих частотах (`ω · τ_t >> 1`) перезарядка «вимерзає» через запізнення квантових переходів, динамічна ємність дефектів спадає пропорційно `1 / (1 + ω² · τ_t²)`, а активна провідність проходить через характерний релаксаційний максимум Дебая при `ω · τ_t = 1`.

У методі DLTS збіднену область p-n переходу збуджують коротким імпульсом заповнення, після чого вимірюють спад ємності у часі при зворотному зсуві (`n ≈ 0, p ≈ 0`). У цих умовах `1 / τ_t = c_n · n_1 + c_p · p_1 = e_n + e_p`. Для електронної пастки у верхній половині зони `e_n >> e_p`, і час спаду визначається виключно швидкістю емісії `e_n(T)`:

```
e_n(T) = c_n · n_1 = (σ_n · v_{th,n} · N_c / g) · exp(-(E_c - E_t) / (k_B · T))
```

Враховуючи, що `v_{th,n} ∝ T^{1/2}` та `N_c ∝ T^{3/2}`, перед експонентою виникає температурна залежність `T²`. Логарифмуючи відношення `e_n / T²`, отримуємо лінійне рівняння Арреніуса:

```
ln(e_n / T²) = ln(γ_n · σ_n) - (E_c - E_t) / (k_B · T)
```

де `γ_n` — константа, скомпонована з фундаментальних фізичних сталих та ефективної маси електрона. Нахил експериментальної прямої на графіку в координатах `ln(e_n / T²)` проти `1 / T` дає глибину залягання рівня `E_c - E_t`, а точка перетину з віссю ординат — переріз захоплення `σ_n`.

### 4. Стаціонарний розв'язок для заселеності пасток та повне алгебраїчне виведення швидкості U

У стаціонарному нерівноважному режимі похідна за часом обнуляється: `d f_t / dt = 0`. Це означає, що концентрація електронів на пастках залишається незмінною, і результуючий потік електронів із зони провідності на дефекти строго дорівнює результуючому потоку дірок із валентної зони на дефекти:

```
U_n = r_a - r_b = c_n · n · N_t · (1 - f_t) - e_n · N_t · f_t
U_p = r_c - r_d = c_p · p · N_t · f_t - e_p · N_t · (1 - f_t)

Умова стаціонарності: U_n = U_p = U
```

Підставимо у рівняння потоків вирази `e_n = c_n · n_1` та `e_p = c_p · p_1`:

```
U_n = c_n · N_t · [ n · (1 - f_t) - n_1 · f_t ]  [чистий потік електронів]
U_p = c_p · N_t · [ p · f_t - p_1 · (1 - f_t) ]  [чистий потік дірок]
```

Прирівнюємо `U_n = U_p` для знаходження стаціонарного ступеня заповнення пасток `f_t`:

```
c_n · N_t · [ n · (1 - f_t) - n_1 · f_t ] = c_p · N_t · [ p · f_t - p_1 · (1 - f_t) ]
```

Скорочуємо обидві частини на `N_t` та послідовно групуємо доданки:

```
c_n · n · (1 - f_t) - c_n · n_1 · f_t
= c_p · p · f_t - c_p · p_1 · (1 - f_t)          [розподіл лівої та правої частин]

c_n · n - c_n · n · f_t - c_n · n_1 · f_t
= c_p · p · f_t - c_p · p_1 + c_p · p_1 · f_t    [розкрито множення на (1 - f_t)]

c_n · n + c_p · p_1
= c_n · n · f_t + c_n · n_1 · f_t + c_p · p · f_t + c_p · p_1 · f_t  [перенесено доданки з f_t праворуч]

c_n · n + c_p · p_1
= f_t · [ c_n · (n + n_1) + c_p · (p + p_1) ]   [винесено f_t за дужки]
```

Отримуємо канонічний вираз для стаціонарної функції заповнення пасток електронами:

```
f_t = (c_n · n + c_p · p_1) / [ c_n · (n + n_1) + c_p · (p + p_1) ]
```

Знайдемо відповідну ймовірність того, що пастка є порожньою:

```
1 - f_t
= 1 - (c_n · n + c_p · p_1) / [ c_n · (n + n_1) + c_p · (p + p_1) ]                          [підставлено f_t]
= [ c_n · (n + n_1) + c_p · (p + p_1) - (c_n · n + c_p · p_1) ] / [ c_n · (n + n_1) + c_p · (p + p_1) ]  [зведено до спільного знаменника]
= [ c_n · n + c_n · n_1 + c_p · p + c_p · p_1 - c_n · n - c_p · p_1 ] / [ c_n · (n + n_1) + c_p · (p + p_1) ] [розкрито дужки]
= (c_n · n_1 + c_p · p) / [ c_n · (n + n_1) + c_p · (p + p_1) ]                             [скорочено однакові доданки]
```

Тепер виконаємо покрокове підставлення отриманих виразів `f_t` та `1 - f_t` у формулу рекомбінаційного потоку електронів `U_n`:

```
U_n
= c_n · N_t · [ n · (1 - f_t) - n_1 · f_t ]                                                  [вихідна формула потоку]
= c_n · N_t · [ n · (c_n · n_1 + c_p · p) - n_1 · (c_n · n + c_p · p_1) ] / [ c_n · (n + n_1) + c_p · (p + p_1) ] [підставлено f_t та (1 - f_t)]
```

Перетворимо чисельник у квадратних дужках:

```
Чисельник
= n · (c_n · n_1 + c_p · p) - n_1 · (c_n · n + c_p · p_1)                                    [вираз чисельника]
= c_n · n · n_1 + c_p · n · p - c_n · n_1 · n - c_p · n_1 · p_1                              [розкрито множення]
= (c_n · n · n_1 - c_n · n · n_1) + c_p · n · p - c_p · n_1 · p_1                            [згруповано взаємні доданки]
= c_p · n · p - c_p · n_1 · p_1                                                              [скорочено c_n · n · n_1 - c_n · n · n_1 = 0]
= c_p · (n · p - n_1 · p_1)                                                                  [винесено c_p за дужки]
= c_p · (n · p - n_i²)                                                                       [використано інваріант n_1 · p_1 = n_i²]
```

Для перевірки виконаємо аналогічне незалежне підставлення у формулу рекомбінаційного потоку дірок `U_p`:

```
U_p
= c_p · N_t · [ p · f_t - p_1 · (1 - f_t) ]                                                  [вихідна формула потоку дірок]
= c_p · N_t · [ p · (c_n · n + c_p · p_1) - p_1 · (c_n · n_1 + c_p · p) ] / [ c_n · (n + n_1) + c_p · (p + p_1) ] [підставлено f_t та (1 - f_t)]
```

Перетворимо чисельник діркового потоку:

```
Чисельник
= p · (c_n · n + c_p · p_1) - p_1 · (c_n · n_1 + c_p · p)                                    [чисельник потоку дірок]
= c_n · n · p + c_p · p · p_1 - c_n · n_1 · p_1 - c_p · p_1 · p                              [розкрито множення]
= c_n · n · p - c_n · n_1 · p_1 + (c_p · p · p_1 - c_p · p · p_1)                            [згруповано взаємні доданки]
= c_n · (n · p - n_1 · p_1)                                                                  [скорочено c_p · p · p_1 - c_p · p · p_1 = 0]
= c_n · (n · p - n_i²)                                                                       [використано n_1 · p_1 = n_i²]
```

Множачи чисельник на зовнішній коефіцієнт `c_n · N_t` (для електронів) або `c_p · N_t` (для дірок), отримуємо абсолютно ідентичний вираз:

```
U = (c_n · c_p · N_t · (n · p - n_i²)) / [ c_n · (n + n_1) + c_p · (p + p_1) ]
```

Це доводить точну внутрішню узгодженість кінетичної моделі Шокли — Рида — Холла.

Введемо характеристичні часи життя неосновних носіїв заряду, які є фундаментальними макроскопічними константами матеріалу:
- `τ_n0 = 1 / (N_t · c_n) = 1 / (N_t · σ_n · v_{th,n})` — мінімальний час життя електронів у сильно легованому p-напівпровіднику при низькому рівні інжекції;
- `τ_p0 = 1 / (N_t · c_p) = 1 / (N_t · σ_p · v_{th,p})` — мінімальний час життя дірок у сильно легованому n-напівпровіднику при низькому рівні інжекції.

Поділимо чисельник і знаменник швидкості `U` на добуток `c_n · c_p · N_t`:

```
U
= (n · p - n_i²) / [ (c_n · (n + n_1) + c_p · (p + p_1)) / (c_n · c_p · N_t) ]
= (n · p - n_i²) / [ (c_n · (n + n_1)) / (c_n · c_p · N_t) + (c_p · (p + p_1)) / (c_n · c_p · N_t) ]
= (n · p - n_i²) / [ (1 / (c_p · N_t)) · (n + n_1) + (1 / (c_n · N_t)) · (p + p_1) ]
```

Підставляючи визначення `τ_n0` та `τ_p0`, приходимо до стандартного канонічного вигляду рівняння SRH:

```
U = (n · p - n_i²) / [ τ_p0 · (n + n_1) + τ_n0 · (p + p_1) ]
```

Чисельник `n · p - n_i²` виражає термодинамічну рушійну силу рекомбінації. Виразимо нерівноважні концентрації вільних носіїв через квазірівні Фермі для електронів `E_{Fn}` та дірок `E_{Fp}`:

```
n = n_i · exp((E_{Fn} - E_i) / (k_B · T))
p = n_i · exp((E_i - E_{Fp}) / (k_B · T))
```

Знайдемо добуток нерівноважних концентрацій:

```
n · p
= n_i · exp((E_{Fn} - E_i) / (k_B · T)) · n_i · exp((E_i - E_{Fp}) / (k_B · T)) [підставлено нерівноважні концентрації через квазірівні]
= n_i² · exp( ((E_{Fn} - E_i) + (E_i - E_{Fp})) / (k_B · T) )                    [об'єднано показники експонент]
= n_i² · exp((E_{Fn} - E_{Fp}) / (k_B · T))                                     [скорочено рівень Фермі E_i у показнику]
```

Тоді чисельник швидкості рекомбінації набуває компактного вигляду:

```
n · p - n_i² = n_i² · [ exp((E_{Fn} - E_{Fp}) / (k_B · T)) - 1 ]
```

Звідси очевидні три фундаментальні режими роботи дефекту:
1. **Інжекція носіїв або оптичне збудження (`E_{Fn} > E_{Fp}`):** `n · p > n_i²`, чисельник додатний, швидкість `U > 0`. Відбувається чиста рекомбінація — знищення надлишкових електрон-діркових пар з виділенням енергії у ґратку кристала.
2. **Повна термодинамічна рівновага (`E_{Fn} = E_{Fp} = E_F`):** `n · p = n_i²`, чисельник дорівнює нулю, швидкість `U = 0`. Кількість актів рекомбінації в точності дорівнює кількості актів теплової генерації.
3. **Екстракція носіїв або збіднена область під зворотною напругою (`E_{Fn} < E_{Fp}`):** `n · p < n_i²`, чисельник від'ємний, результуюча швидкість `U < 0`. Відбувається чиста теплова генерація пар (`G = -U > 0`).

### 5. Строгий аналітичний аналіз асимптотичних режимів інжекції та легування

Ефективний інтегральний час життя надлишкових носіїв `τ` визначається як відношення концентрації надлишкових пар `Δn` (за умови квазінейтральності `Δn = Δp`) до чистої швидкості рекомбінації:

```
τ = Δn / U
```

Дослідимо аналітичну поведінку `τ` у різних фізичних та технологічних граничних випадках.

#### 1. Низький рівень інжекції у напівпровіднику n-типу

Нехай маємо напівпровідник n-типу з рівноважною концентрацією електронів `n_0 ≈ N_D` та дірок `p_0 = n_i² / n_0 << n_0`. Режим низької інжекції означає, що концентрація доданих надлишкових носіїв набагато менша за концентрацію основних носіїв: `Δn = Δp << n_0`.

Тоді повні концентрації дорівнюють:

```
n = n_0 + Δn ≈ n_0
p = p_0 + Δp ≈ Δp
```

Перетворимо чисельник формули SRH:

```
n · p - n_i²
= (n_0 + Δn) · (p_0 + Δp) - n_0 · p_0
= n_0 · p_0 + n_0 · Δp + p_0 · Δn + Δn · Δp - n_0 · p_0
= n_0 · Δp + p_0 · Δn + Δn · Δp
≈ n_0 · Δp                                    [знехтувано p_0 · Δn та Δn · Δp << n_0 · Δp]
```

Знаменник швидкості рекомбінації при `n ≈ n_0` та `p = p_0 + Δp` набуває вигляду:

```
Знаменник
= τ_p0 · (n_0 + Δn + n_1) + τ_n0 · (p_0 + Δp + p_1)
≈ τ_p0 · (n_0 + n_1) + τ_n0 · p_1             [нехтуємо Δn та Δp порівняно з n_0]
```

Підставимо ці вирази у формулу для швидкості рекомбінації `U`:

```
U = (n_0 · Δp) / [ τ_p0 · (n_0 + n_1) + τ_n0 · p_1 ]
```

Звідси знаходимо ефективний час життя неосновних носіїв (дірок у матеріалі n-типу):

```
τ_p
= Δp / U
= [ τ_p0 · (n_0 + n_1) + τ_n0 · p_1 ] / n_0
= τ_p0 · (n_0 / n_0 + n_1 / n_0) + τ_n0 · (p_1 / n_0)
= τ_p0 · [ 1 + (n_1 / n_0) ] + τ_n0 · (p_1 / n_0)
```

Для глибоких рекомбінаційних центрів у добре легованому напівпровіднику параметри `n_1` та `p_1` набагато менші за `n_0` (`n_1 / n_0 << 1`, `p_1 / n_0 << 1`). Тоді формули спрощуються до константи:

```
τ_p ≈ τ_p0 = 1 / (N_t · σ_p · v_{th,p})
```

Час життя неосновних дірок у матеріалі n-типу не залежить від концентрації інжектованих носіїв і визначається виключно перерізом захоплення дірки `σ_p`. Оскільки вільних електронів у матеріалі n-типу величезна кількість, усі пастки практично завжди заповнені електронами (`f_t ≈ 1`). Вузьким місцем («пляшковою шийкою») процесу є лише прихід рідкісної дірки та її захоплення на зайняту пастку.

#### 2. Низький рівень інжекції у напівпровіднику p-типу

Розглянемо симетричний випадок для матеріалу p-типу: `p_0 ≈ N_A >> n_0`, `Δn = Δp << p_0`.

Повні концентрації носіїв:

```
p = p_0 + Δp ≈ p_0
n = n_0 + Δn ≈ Δn
```

Чисельник:

```
n · p - n_i² ≈ p_0 · Δn
```

Знаменник:

```
Знаменник ≈ τ_p0 · n_1 + τ_n0 · (p_0 + p_1)
```

Швидкість рекомбінації:

```
U = (p_0 · Δn) / [ τ_p0 · n_1 + τ_n0 · (p_0 + p_1) ]
```

Звідси час життя неосновних носіїв (електронів у матеріалі p-типу) дорівнює:

```
τ_n
= Δn / U
= [ τ_p0 · n_1 + τ_n0 · (p_0 + p_1) ] / p_0
= τ_n0 · [ 1 + (p_1 / p_0) ] + τ_p0 · (n_1 / p_0)
```

Для глибоких центрів (`p_1, n_1 << p_0`):

```
τ_n ≈ τ_n0 = 1 / (N_t · σ_n · v_{th,n})
```

У матеріалі p-типу більшість пасток порожні (`f_t ≈ 0`), і лімітуючою стадією є захоплення електрона з зони провідності.

#### 3. Високий рівень інжекції (High-Level Injection)

При високому рівні збудження концентрація доданих електрон-діркових пар набагато перевищує рівноважні концентрації обох типів носіїв: `Δn = Δp >> n_0, p_0`. Цей режим реалізується в сонячних елементах під концентрованим сонячним світлом, у базах силових діодів, тиристорів та IGBT під час прямого струму.

У цьому випадку:

```
n = n_0 + Δn ≈ Δn
p = p_0 + Δp ≈ Δn
```

Чисельник формули SRH набуває вигляду:

```
n · p - n_i² ≈ Δn² - n_i² ≈ Δn²  [оскільки Δn >> n_i]
```

Знаменник:

```
Знаменник
= τ_p0 · (Δn + n_1) + τ_n0 · (Δn + p_1)
≈ τ_p0 · Δn + τ_n0 · Δn                  [знехтувано n_1, p_1 порівняно з Δn]
= (τ_p0 + τ_n0) · Δn                     [винесено Δn за дужки]
```

Швидкість рекомбінації при високій інжекції набуває лінійного вигляду:

```
U_{HL}
= Δn² / [ (τ_p0 + τ_n0) · Δn ]
= Δn / (τ_n0 + τ_p0)
```

Звідси асимптотичний час життя носіїв заряду при високому рівні інжекції строго дорівнює сумі двох базових часів:

```
τ_{HL} = Δn / U_{HL} = τ_n0 + τ_p0
```

Фізична причина сумування часів полягає в тому, що при надлишку як електронів, так і дірок, центр рекомбінації повинен почергово здіснити два послідовні акти: спершу захопити електрон (середній час очікування `τ_n0`), а потім захопити дірку (середній час очікування `τ_p0`). Оскільки ці процеси відбуваються послідовно, повний період рекомбінаційного циклу одного центру дорівнює сумі середніх часів очікування кожного з двох кроків.

#### 4. Неперервна інжекційна залежність часу життя

Об'єднаємо отримані результати в єдину аналітичну залежність часу життя від довільної густини надлишкових носіїв `Δn` у напівпровіднику довільного ступеня легування (формула Шокли — Ріда):

```
τ(Δn) = [ τ_p0 · (n_0 + Δn + n_1) + τ_n0 · (p_0 + Δn + p_1) ] / [ n_0 + p_0 + Δn ]
```

Розкладемо чисельник на доданки, залежні та незалежні від `Δn`:

```
τ(Δn)
= [ (τ_p0 · (n_0 + n_1) + τ_n0 · (p_0 + p_1)) + (τ_n0 + τ_p0) · Δn ] / [ (n_0 + p_0) + Δn ]
= [ τ_{LL} · (n_0 + p_0) + τ_{HL} · Δn ] / [ (n_0 + p_0) + Δn ]
= τ_{LL} · [ 1 + (τ_{HL} / τ_{LL}) · (Δn / (n_0 + p_0)) ] / [ 1 + (Δn / (n_0 + p_0)) ]
```

Ця формула показує плавний монотонний перехід часу життя від низькоінжекційного значення `τ_{LL}` до високоінжекційного значення `τ_{HL}` при зростанні параметра інжекції `Δn / (n_0 + p_0)`.

Якщо `τ_{HL} > τ_{LL}` (наприклад, у p-кремнії, де `τ_p0 > τ_n0`), час життя зростає зі збільшенням рівня інжекції. Якщо ж `τ_{HL} < τ_{LL}`, час життя монотонно спадає.

#### 5. Теплова генерація носіїв у збідненій області

У збідненій області (області просторового заряду) зворотно зміщеного p-n переходу або під затвором збідненого польового транзистора сильне внутрішнє електричне поле виносить усі вільні електрони та дірки. Концентрації стають набагато меншими за власну концентрацію: `n << n_1`, `p << p_1` та `n · p << n_i²`.

Підставимо `n ≈ 0` та `p ≈ 0` у вихідне рівняння SRH:

```
U_{SCR} = (0 - n_i²) / [ τ_p0 · (0 + n_1) + τ_n0 · (0 + p_1) ] = - n_i² / [ τ_p0 · n_1 + τ_n0 · p_1 ]
```

Швидкість рекомбінації є від'ємною, що відповідає чистому процесу теплової генерації носіїв `G = -U_{SCR}`:

```
G = n_i² / [ τ_p0 · n_1 + τ_n0 · p_1 ]
```

Підставимо у цей вираз квантово-статистичні формули для `n_1` та `p_1` через власний рівень `E_i`:

```
G
= n_i² / [ τ_p0 · n_i · exp((E_t - E_i) / (k_B · T)) + τ_n0 · n_i · exp((E_i - E_t) / (k_B · T)) ]
= n_i / [ τ_p0 · exp((E_t - E_i) / (k_B · T)) + τ_n0 · exp((E_i - E_t) / (k_B · T)) ]
```

Зведемо знаменник до симетричного гіперболічного косинуса. Для цього введемо геометричне середнє базових часів `τ_0 = √(τ_n0 · τ_p0)` та логарифмічне зміщення `ΔE_0 = (1 / 2) · k_B · T · ln(τ_p0 / τ_n0)`:

```
τ_p0 · exp((E_t - E_i) / (k_B · T)) + τ_n0 · exp((E_i - E_t) / (k_B · T))
= 2 · √(τ_n0 · τ_p0) · cosh[ ((E_t - E_i) / (k_B · T)) + (1 / 2) · ln(τ_p0 / τ_n0) ]
```

Швидкість теплової генерації набуває вигляду:

```
G = n_i / [ 2 · √(τ_n0 · τ_p0) · cosh( ((E_t - E_i) / (k_B · T)) + (1 / 2) · ln(τ_p0 / τ_n0) ) ]
```

Якщо енергетичний рівень пастки розташований строго посередині забороненої зони (`E_t = E_i`) і часи життя симетричні (`τ_n0 = τ_p0 = τ_0`), аргумент гіперболічного косинуса дорівнює нулю (`cosh(0) = 1`), і швидкість генерації досягає абсолютного максимуму:

```
G_{max} = n_i / (2 · τ_0)
```

Ця формула використовується в напівпровідниковій мікроелектроніці для аналітичного розрахунку струму витоку p-n переходів та темного струму пікселів КМОН-матриць зображення:

```
J_{gen} = q · G · W_{SCR} = (q · n_i · W_{SCR}) / (2 · τ_0)
```

де `W_{SCR}` — ширина збідненого шару, `q` — елементарний електричний заряд.

### 6. Математична оптимізація положення рекомбінаційного рівня

Дослідимо задачу знаходження енергетичного положення пастки `E_t`, при якому швидкість рекомбінації `U(E_t)` набуває максимального значення за фіксованих нерівноважних концентрацій `n` та `p`.

Оскільки чисельник швидкості SRH `n · p - n_i²` не залежить від енергії пастки `E_t`, максимізація швидкості `U(E_t)` строго еквівалентна знаходженню точки мінімуму знаменника:

```
D(E_t) = τ_p0 · (n + n_1(E_t)) + τ_n0 · (p + p_1(E_t))
```

Виділимо частину знаменника, яка явно залежить від `E_t`:

```
D_t(E_t)
= τ_p0 · n_1(E_t) + τ_n0 · p_1(E_t)                                             [виділено залежні від E_t доданки знаменника]
= τ_p0 · n_i · exp((E_t - E_i) / (k_B · T)) + τ_n0 · n_i · exp((E_i - E_t) / (k_B · T)) [підставлено вирази для n_1 та p_1]
```

Для знаходження екстремуму обчислимо першу похідну функції `D_t(E_t)` за енергією `E_t`:

```
dD_t / dE_t
= d/dE_t [ τ_p0 · n_i · exp((E_t - E_i) / (k_B · T)) + τ_n0 · n_i · exp((E_i - E_t) / (k_B · T)) ]
= (n_i / (k_B · T)) · [ τ_p0 · exp((E_t - E_i) / (k_B · T)) - τ_n0 · exp((E_i - E_t) / (k_B · T)) ]
```

Прирівняємо першу похідну до нуля:

```
(n_i / (k_B · T)) · [ τ_p0 · exp((E_t - E_i) / (k_B · T)) - τ_n0 · exp((E_i - E_t) / (k_B · T)) ] = 0
```

Оскільки `n_i / (k_B · T) ≠ 0`, прирівнюємо до нуля вираз у квадратних дужках:

```
τ_p0 · exp((E_t - E_i) / (k_B · T)) = τ_n0 · exp((E_i - E_t) / (k_B · T))  [умова екстремуму]
```

Помножимо обидві частини на `exp((E_t - E_i) / (k_B · T))` і поділимо на `τ_p0`:

```
exp( 2 · (E_t - E_i) / (k_B · T) ) = τ_n0 / τ_p0
```

Логарифмуємо обидві частини рівності за основою `e`:

```
2 · (E_t - E_i) / (k_B · T) = ln(τ_n0 / τ_p0)
```

Звідси отримуємо точний аналітичний вираз для оптимального енергетичного рівня найефективнішої рекомбінаційної пастки:

```
E_t^{opt} = E_i + (1 / 2) · k_B · T · ln(τ_n0 / τ_p0)
```

Виразимо відношення часів через мікроскопічні перерізи захоплення та теплові швидкості:

```
τ_n0 / τ_p0
= (1 / (N_t · c_n)) / (1 / (N_t · c_p))     [підставлено означення базових часів життя]
= c_p / c_n                                 [скорочено спільний множник N_t]
= (σ_p · v_{th,p}) / (σ_n · v_{th,n})       [підставлено мікроскопічні коефіцієнти захоплення]
```

Підставляючи це співвідношення, отримуємо формулу Шокли — Ріда для енергетичного максимуму рекомбінації:

```
E_t^{opt} = E_i + (1 / 2) · k_B · T · ln(c_p / c_n) = E_i + (1 / 2) · k_B · T · ln( (σ_p · v_{th,p}) / (σ_n · v_{th,n}) )
```

Перевіримо знак другої похідної для підтвердження того, що знайдена точка є саме мінімумом знаменника:

```
d²D_t / dE_t²
= d/dE_t [ (n_i / (k_B · T)) · [ τ_p0 · exp((E_t - E_i) / (k_B · T)) - τ_n0 · exp((E_i - E_t) / (k_B · T)) ] ]
= (n_i / (k_B · T)²) · [ τ_p0 · exp((E_t - E_i) / (k_B · T)) + τ_n0 · exp((E_i - E_t) / (k_B · T)) ]
```

Оскільки експоненти та константи `n_i, T, τ_p0, τ_n0` є строго додатними величинами, друга похідна є додатною для всіх значень енергії:

```
d²D_t / dE_t² > 0  ∀ E_t ∈ (-∞, +∞)
```

Це строго доводить, що функція `D_t(E_t)` є строго опуклою вниз, а точка `E_t^{opt}` є її єдиним абсолютним глобальним мінімумом. Відповідно, швидкість рекомбінації `U(E_t)` у цій точці досягає свого абсолютного максимуму.

Проаналізуємо фізичні наслідки цього результату:
1. **Симетричні перерізи (`σ_n ≈ σ_p`):** Якщо коефіцієнти захоплення електронів і дірок однакові, то `c_p / c_n = 1`, логарифм перетворюється на нуль `ln(1) = 0`, і найнебезпечніший рекомбінаційний центр лежить **строго посередині забороненої зони** (`E_t^{opt} = E_i`).
2. **Асиметрія перерізів (`σ_p >> σ_n`):** Якщо пастка значно сильніше притягує дірки, ніж електрони (наприклад, негативно заряджений акцепторний центр), то `ln(c_p / c_n) > 0`, і оптимальний рівень рекомбінації зміщується у верхню половину забороненої зони (`E_t > E_i`). Це необхідно для того, щоб компенсувати малий переріз захоплення електрона збільшенням концентрації `n_1`.
3. **Дрібні рівні біля меж зон (`|E_t - E_i| >> k_B · T`):** Якщо дефект розташований близько до краю зони провідності `E_c` (або валентної зони `E_v`), параметр `n_1` (або `p_1`) зростає експоненційно (`n_1 ∝ exp((E_t - E_i)/k_B T)`). Знаменник швидкості збільшується на багато порядків, і швидкість рекомбінації стрімко падає до нуля.

Дрібний рівень біля зони провідності захоплює електрон, але за час близько `10⁻¹⁰` с термічно викидає його назад у зону, не дочекавшись приходу дірки. Такий центр перестає бути рекомбінатором і перетворюється на звичайну пастку прилипання (*trapping center*).

### 7. Багаторівнева статистика Са — Шоклі для амфотерних центрів

Класична теорія SRH розглядає дефект із двома зарядовими станами (один одноелектронний рівень). Проте реальні домішки перехідних та благородних металів у кремнії (золото Au, платина Pt), а також структурні радіаційні дефекти (бівакансії `V_2`) є амфотерними центрами (*amphoteric centers*) і можуть перебувати у кількох різних зарядових станах.

Розглянемо статистику Са — Шоклі (*Sah-Shockley statistics*) для дефекту із загальною концентрацією `N_t`, який може зв'язувати до `M` електронів, володіючи `M+1` дискретними зарядовими станами: `k ∈ {0, 1, ..., M}`. Позначимо через `f_k` імовірність того, що центр перебуває в стані з `k` захопленими електронами.

Імовірності підпорядковуються умові квантового нормування:

```
∑_{k=0}^M f_k = f_0 + f_1 + ... + f_M = 1
```

Перехід між сусідніми зарядовими станами `k` та `k+1` відбувається через чотири процеси:
1. Захоплення електрона станом `k` з коефіцієнтом `c_{n,k}` (перехід `k → k+1`): `r_{a,k} = c_{n,k} · n · N_t · f_k`;
2. Теплова емісія електрона зі стану `k+1` зі швидкістю `e_{n,k+1}` (перехід `k+1 → k`): `r_{b,k+1} = e_{n,k+1} · N_t · f_{k+1}`;
3. Захоплення дірки станом `k+1` з коефіцієнтом `c_{p,k+1}` (перехід `k+1 → k`): `r_{c,k+1} = c_{p,k+1} · p · N_t · f_{k+1}`;
4. Теплова емісія дірки зі стану `k` зі швидкістю `e_{p,k}` (перехід `k → k+1`): `r_{d,k} = e_{p,k} · N_t · f_k`.

За принципом детальної рівноваги в стані термодинамічної рівноваги:

```
e_{n,k+1} = c_{n,k} · n_{1,k}
e_{p,k} = c_{p,k+1} · p_{1,k}
```

де характеристики `n_{1,k}` та `p_{1,k}` для переходу між станами `k` та `k+1` задаються енергетичним рівнем `E_{t,k}`:

```
n_{1,k} = (g_k / g_{k+1}) · N_c · exp(-(E_c - E_{t,k}) / (k_B · T))
p_{1,k} = (g_{k+1} / g_k) · N_v · exp(-(E_{t,k} - E_v) / (k_B · T))
n_{1,k} · p_{1,k} = n_i²
```

Чистий результуючий потік рекомбінації через квантовий перехід `k ⇄ k+1` дорівнює:

```
U_k = N_t · [ c_{n,k} · n · f_k - c_{n,k} · n_{1,k} · f_{k+1} ] = N_t · [ c_{p,k+1} · p · f_{k+1} - c_{p,k+1} · p_{1,k} · f_k ]
```

Розглянемо найважливіший практичний випадок тристадійного амфотерного центру (золото Au у кремнії), який має три зарядові стани: позитивний `Au⁺` (`k = 0`), нейтральний `Au⁰` (`k = 1`) та негативний `Au⁻` (`k = 2`).

Центр має два взаємопов'язані енергетичні рівні:
- Донорний рівень `E_{t1} = E_v + 0.35` еВ (перехід `Au⁺ ⇄ Au⁰`);
- Акцепторний рівень `E_{t2} = E_c - 0.54` еВ (перехід `Au⁰ ⇄ Au⁻`).

У стаціонарному стані записуємо систему балансу для потоків:

```
c_{n,0} · n · f_0 - c_{n,0} · n_{1,0} · f_1 = c_{p,1} · p · f_1 - c_{p,1} · p_{1,0} · f_0  [баланс переходу 0 ⇄ 1]
c_{n,1} · n · f_1 - c_{n,1} · n_{1,1} · f_2 = c_{p,2} · p · f_2 - c_{p,2} · p_{1,1} · f_1  [баланс переходу 1 ⇄ 2]
f_0 + f_1 + f_2 = 1                                                                         [умова нормування]
```

З першого рівняння виражаємо ймовірність `f_0` через `f_1`:

```
f_0 · (c_{n,0} · n + c_{p,1} · p_{1,0}) = f_1 · (c_{n,0} · n_{1,0} + c_{p,1} · p)
f_0 = f_1 · [ (c_{n,0} · n_{1,0} + c_{p,1} · p) / (c_{n,0} · n + c_{p,1} · p_{1,0}) ]
```

З другого рівняння виражаємо ймовірність `f_2` через `f_1`:

```
f_2 · (c_{n,1} · n_{1,1} + c_{p,2} · p) = f_1 · (c_{n,1} · n + c_{p,2} · p_{1,1})
f_2 = f_1 · [ (c_{n,1} · n + c_{p,2} · p_{1,1}) / (c_{n,1} · n_{1,1} + c_{p,2} · p) ]
```

Підставляючи вирази для `f_0` та `f_2` в умову нормування `f_0 + f_1 + f_2 = 1`, однозначно знаходимо ймовірність нейтрального стану `f_1`:

```
f_1 = 1 / [ 1 + (c_{n,0} · n_{1,0} + c_{p,1} · p) / (c_{n,0} · n + c_{p,1} · p_{1,0}) + (c_{n,1} · n + c_{p,2} · p_{1,1}) / (c_{n,1} · n_{1,1} + c_{p,2} · p) ]
```

Повна результуюча швидкість рекомбінації Са — Шоклі є сумою швидкостей рекомбінації через обидва рівні: `U_{total} = U_0 + U_1`.

Підставляючи знайдені функції розподілу, отримуємо замкнену аналітичну формулу:

```
U_{total} = N_t · (n · p - n_i²) · [ α_0 + α_1 ] / [ 1 + β_0 + β_1 ]
```

де коефіцієнти визначаються співвідношеннями мікроскопічних параметрів захоплення для кожного зарядового стану:

```
α_0 = (c_{n,0} · c_{p,1}) / (c_{n,0} · n + c_{p,1} · p_{1,0})
α_1 = (c_{n,1} · c_{p,2}) / (c_{n,1} · n_{1,1} + c_{p,2} · p)
β_0 = (c_{n,0} · n_{1,0} + c_{p,1} · p) / (c_{n,0} · n + c_{p,1} · p_{1,0})
β_1 = (c_{n,1} · n + c_{p,2} · p_{1,1}) / (c_{n,1} · n_{1,1} + c_{p,2} · p)
```

Якщо енергетичні рівні центру розташовані далеко один від одного або рівень Фермі зафіксований біля одного з них, відповідний доданок починає домінувати, і формула Са — Шоклі автоматично редукується до класичного однорівневого рівняння SRH.

### 8. Ефекти сильного електричного поля: польове підсилення за моделями Пула — Френкеля та Шенка (TAT)

У збіднених областях сильно легованих зворотних p-n переходів, силових приладів та субмікронних польових транзисторів напруженість локального електричного поля `F` досягає значень `10⁴...10⁶` В/см. У таких умовах класична модель SRH суттєво занижує реальну швидкість генерації та витоку, оскільки зовнішнє поле експоненційно підсилює ймовірність емісії носіїв із пасток.

Існують два ключові фізичні механізми польового підсилення:
1. Класичне зниження кулонівського бар'єра дефекту (тривимірний ефект Пула — Френкеля);
2. Квантовомеханічне тунелювання за участю пасток (Trap-Assisted Tunneling, TAT) за моделлю Шенка.

#### 1. Модель Пула — Френкеля (Poole-Frenkel Effect)

Якщо центр рекомбінації є кулонівським (наприклад, позитивно заряджений донор притягує електрон), потенціал дефекту у зовнішньому електричному полі `F` вздовж координати `r` під кутом `θ` до вектора поля набуває вигляду:

```
V(r, θ) = - q² / (4 · π · ε · r) - q · F · r · cos(θ)
```

Знайдемо максимум потенціального бар'єра вздовж напрямку дії поля (`θ = 0`):

```
dV / dr = q² / (4 · π · ε · r²) - q · F = 0
r_{max} = √( q / (4 · π · ε · F) )
```

Підставляючи `r_{max}` у вираз для потенціалу, знаходимо величину класичного зниження бар'єра `ΔE_{PF}`:

```
ΔE_{PF} = V(∞) - V(r_{max}, 0) = 2 · √( q³ · F / (4 · π · ε) ) = √( (q³ · F) / (π · ε) )
```

Зниження бар'єра полегшує теплову емісію електрона у зону провідності:

```
e_n(F) = e_n(0) · exp(ΔE_{PF} / (k_B · T))
```

Для коректного врахування просторової тривимірності дефекту виконують інтегрування за всіма просторовими напрямками `θ`. Тривимірний коефіцієнт підсилення Пула — Френкеля набуває вигляду:

```
g_{PF}(F) = (1 / α²) · [ 1 + (α - 1) · exp(α) ] + 1 / 2
```

де `α = ΔE_{PF} / (k_B · T) = √(q³ · F / (π · ε)) / (k_B · T)`.

#### 2. Квантовомеханічне тунелювання за участю пасток (Модель Шенка)

При полях `F > 10⁵` В/см домінує квантовомеханічне тунелювання електрона крізь трикутний потенціальний бар'єр, сформований електричним полем, з одночасною участю фононів кристалічної ґратки.

Згідно з польовою моделлю Андреаса Шенка (*Schenk trap-assisted tunneling model*), коефіцієнти емісії електронів та дірок модифікуються безрозмірними польовими факторами `Γ_n(F)` та `Γ_p(F)`:

```
e_n(F) = e_n(0) · [ 1 + Γ_n(F) ]
e_p(F) = e_p(0) · [ 1 + Γ_p(F) ]
```

Польовий фактор Шенка розраховується через інтегрування за енергією переходу `ξ` з урахуванням багатофононного фактора Хуанга — Ріса `S` та енергії фонона `ħω`:

```
Γ_n(F) = ∫_0^{(E_c - E_t)/(k_B · T)} dξ · exp[ ξ - (4 / 3) · ( (2 · m_n*)^{1/2} · (k_B · T)^{3/2} / (q · ħ · F) ) · ((E_c - E_t) / (k_B · T) - ξ)^{3/2} ] · ...
```

Врахування польових факторів еквівалентне зменшенню ефективних характеристичних часів життя в сильному полі:

```
τ_{n0}(F) = τ_{n0} / [ 1 + Γ_n(F) ]
τ_{p0}(F) = τ_{p0} / [ 1 + Γ_p(F) ]
```

Підставляючи ці польові константи у рівняння Шокли — Рида — Холла, отримуємо узагальнене польове рівняння швидкості рекомбінації-генерації носіїв:

```
U(F) = (n · p - n_i²) / [ (τ_p0 / (1 + Γ_p(F))) · (n + n_1) + (τ_n0 / (1 + Γ_n(F))) · (p + p_1) ]
```

У слабких полях (`F → 0`) фактори підсилення прямують до нуля (`Γ_n, Γ_p → 0`), і рівняння строго переходить у класичний вираз SRH. У сильних полях (`F > 3·10⁵` В/см) фактори `Γ(F)` досягають значень `10³...10⁶`, викликаючи лавиноподібне зростання струму термопольової генерації в збіднених переходах напівпровідникових приладів.

### 9. Квантовомеханічна теорія перерізів захоплення: багатофононна модель та фактор Франка — Кондона

Константи захоплення `c_n = σ_n · v_{th,n}` та `c_p = σ_p · v_{th,p}` базуються на квантовомеханічних перерізах `σ_n` та `σ_p`. Коли електрон падає з зони провідності на глибокий рівень `E_t`, система повинна позбутися надлишкової енергії `ΔE = E_c - E_t ≈ 0.5...0.6` еВ. Оскільки типова енергія оптичного фонона становить `ħω ≈ 0.05...0.06` еВ, квантовий перехід вимагає одночасного збудження пакета з `p = ΔE / (ħω) ≈ 8...12` фононів.

Згідно з адіабатичним наближенням Борна — Оппенгеймера, повна хвильова функція системи «електрон + коливання ґратки» записується як добуток електронної хвильової функції `ψ(r, Q)` та ядерної хвильової функції коливальних мод ґратки `Φ_m(Q)`:

```
Ψ(r, Q) = ψ(r, Q) · Φ_m(Q)
```

де `Q` — узагальнена конфігураційна координата зміщення атомів навколо дефекту від положення рівноваги.

Потенціальна енергія системи в початковому стані `i` (вільний електрон на дні зони провідності `E_c`) та кінцевому стані `f` (електрон, локалізований на пастці `E_t`) в гармонічному наближенні описується двома зміщеними параболами:

```
U_i(Q) = (1 / 2) · M · ω² · Q² + E_c
U_f(Q) = (1 / 2) · M · ω² · (Q - ΔQ)² + E_t
```

де `M` — ефективна маса коливальної моди дефекту, `ΔQ` — зміщення рівноважного положення ядер внаслідок електронно-деформаційної релаксації ґратки після захоплення носія.

Енергія релаксації ґратки (енергія Франка — Кондона) пов'язана з безрозмірним фактором електрон-фононного зв'язку Хуанга — Ріса `S`:

```
E_{rel} = (1 / 2) · M · ω² · (ΔQ)² = S · ħω
```

Квантова ймовірність переходу за одиницю часу розраховується за золотим правилом Фермі:

```
W_{i→f} = (2 · π / ħ) · |⟨Ψ_f | H_{e-ph} | Ψ_i⟩|² · δ(E_f - E_i)
```

У наближенні Кондона матричний елемент оператора електрон-фононної взаємодії факторизується на електронний матричний елемент `M_{el}` та інтеграл перекриття коливальних хвильових функцій (фактор Франка — Кондона):

```
|⟨Ψ_f | H_{e-ph} | Ψ_i⟩|² = |M_{el}|² · |⟨Φ_{m'}(Q - ΔQ) | Φ_m(Q)⟩|²
```

Знайдемо класичну точку перетину двох парабол `Q_c`, де потенційні енергії збігаються `U_i(Q_c) = U_f(Q_c)`:

```
(1 / 2) · M · ω² · Q_c² + E_c = (1 / 2) · M · ω² · (Q_c - ΔQ)² + E_t
(1 / 2) · M · ω² · Q_c² + (E_c - E_t) = (1 / 2) · M · ω² · Q_c² - M · ω² · Q_c · ΔQ + (1 / 2) · M · ω² · (ΔQ)²
E_c - E_t = - M · ω² · Q_c · ΔQ + S · ħω
M · ω² · Q_c · ΔQ = S · ħω - (E_c - E_t)
Q_c = [ S · ħω - (E_c - E_t) ] / (M · ω² · ΔQ)
```

Висота класичного термоактиваційного потенціального бар'єра захоплення `E_B = U_i(Q_c) - E_c` набуває вигляду:

```
E_B
= (1 / 2) · M · ω² · Q_c²
= (1 / 2) · M · ω² · [ (S · ħω - (E_c - E_t)) / (M · ω² · ΔQ) ]²
= [ (E_c - E_t - S · ħω)² ] / [ 2 · M · ω² · (ΔQ)² ]
= [ (E_c - E_t - S · ħω)² ] / [ 4 · S · ħω ]
```

Усереднення квантових факторів Франка — Кондона за больцманівським розподілом заселеності коливальних рівнів при високих температурах (`k_B · T > ħω`) дає термоактиваційну експоненційну залежність перерізу захоплення:

```
σ(T) = σ_∞ · exp(- E_B / (k_B · T))
```

де `σ_∞` — асимптотичний високотемпературний геометричний переріз захоплення, який визначається електронним матричним елементом `|M_{el}|²`.

При низьких температурах (`k_B · T << ħω`), коли теплової енергії недостатньо для подолання бар'єра `E_B`, захоплення відбувається шляхом підбар'єрного квантового ядерного тунелювання (*nuclear tunneling*) атомів ґратки з нульового коливального рівня початкового стану безпосередньо в еквівалентний за енергією стан кінцевої параболи. У цій квантовій області переріз виходить на температурне плато:

```
σ(T → 0) = σ_0 = σ_∞ · exp(- 2 · S) · (S^p / p!)
```

де `p = (E_c - E_t) / (ħω)` — кількість згенерованих фононів.

### 10. Просторова неперервність рекомбінації SRH та поверхневі стани

У реальних напівпровідникових структурах (діодах, фотодіодах, сонячних елементах, планарних транзисторах) концентрації носіїв просторово неоднорідні через градієнти інжекції, просторовий заряд та поверхневі межі поділу фаз.

#### 1. Стаціонарне рівняння амбіполярної неперервності

Розподіл надлишкових носіїв `Δn(x)` вздовж координати `x` у нейтральній області напівпровідника описується одновимірним диференціальним рівнянням дифузії-дрейфу та неперервності:

```
D_a · (d² Δn / dx²) - μ_a · F · (d Δn / dx) - U(Δn) + G_{ext}(x) = 0
```

де `D_a` — амбіполярний коефіцієнт дифузії, `μ_a` — амбіполярна рухливість, `G_{ext}(x)` — швидкість зовнішньої оптичної генерації пар, а `U(Δn)` — швидкість рекомбінації SRH.

У квазінейтральній базі за відсутності сильного електричного поля (`F ≈ 0`) та однорідного збудження рівняння спрощується:

```
D · (d² Δn / dx²) - Δn / τ = 0
```

де `τ` — час життя SRH (за низької інжекції `τ = τ_{LL}`). Введемо фундаментальний просторовий масштаб — дифузійну довжину неосновних носіїв:

```
L = √( D · τ )
```

Диференціальне рівняння набуває канонічного вигляду:

```
d² Δn / dx² - Δn / L² = 0
```

Загальний розв'язок для напівнескінченного напівпровідника `x ∈ [0, ∞)` зі спадною граничною умовою `Δn(x → ∞) = 0` має експоненційний вигляд:

```
Δn(x) = Δn(0) · exp(-x / L)
```

Дифузійна довжина `L` задає середню відстань, яку вільний нерівноважний носій заряду проходить шляхом випадкових теплових блукань (дифузії) від точки свого народження до моменту безвипромінювального знищення на пастці SRH.

#### 2. Поверхнева рекомбінація SRH на інтерфейсі Si/SiO₂

На поверхні кристала та на межі розділу напівпровідник-діелектрик (наприклад, `Si/SiO₂` у КМОН-транзисторах) періодичність кристалічної ґратки обривається, створюючи високу густину ненасичених («обірваних») хімічних зв'язків (*dangling bonds*, так звані `P_b`-центри). Вони утворюють неперервний спектр поверхневих пасток із поверхневою густиною станів `D_{it}(E)` (см⁻²·еВ⁻¹).

Швидкість поверхневої рекомбінації SRH в одиниці площі (см⁻²·с⁻¹) для одного дискретного поверхневого рівня з поверхневою концентрацією `N_{it}` (см⁻²) виражається формулою:

```
U_s = (n_s · p_s - n_i²) / [ (n_s + n_1) / S_{p0} + (p_s + p_1) / S_{n0} ]
```

де `n_s` та `p_s` — приповерхневі концентрації електронів і дірок, а `S_{n0}` та `S_{p0}` — фундаментальні швидкості поверхневої рекомбінації (см/с):

```
S_{n0} = N_{it} · σ_{n,s} · v_{th,n}
S_{p0} = N_{it} · σ_{p,s} · v_{th,p}
```

Гранична умова на поверхні `x = 0` пов'язує дифузійний потік носіїв із глибини кристала зі швидкістю їх винищення на поверхневих пастках:

```
D · (d Δn / dx)|_{x=0} = S_{eff} · Δn(0)
```

де `S_{eff} = U_s / Δn(0)` — ефективна швидкість поверхневої рекомбінації.

Для реальної межі розділу `Si/SiO₂` поверхневі стани розподілені неперервно по всій забороненій зоні за U-подібним законом з мінімумом біля середини зони:

```
D_{it}(E) = D_{it,0} + D_{it,c} · exp((E - E_c) / E_0) + D_{it,v} · exp((E_v - E) / E_0)
```

Повна інтегральна швидкість поверхневої рекомбінації знаходиться інтегруванням внесків усіх елементарних енергетичних інтервалів `dE`:

```
U_{s,total} = (n_s · p_s - n_i²) · ∫_{E_v}^{E_c} [ v_{th} · D_{it}(E) ] / [ (n_s + n_1(E)) / σ_p(E) + (p_s + p_1(E)) / σ_n(E) ] dE
```

де `n_1(E) = n_i · exp((E - E_i)/(k_B · T))` та `p_1(E) = n_i · exp((E_i - E)/(k_B · T))`.

Аналітичний аналіз цього інтеграла показує, що через експоненційну залежність `n_1(E)` та `p_1(E)` у знаменнику підінтегральний вираз має гострий дзвоноподібний максимум біля середини забороненої зони шириною близько `4...6 · k_B · T`. Стани, розташовані глибше ніж на `0.15` еВ від середини зони, практично не дають внеску в рекомбінацію через швидку зворотну теплову емісію носіїв у найближчу дозволену зону.

Саме тому хімічна пасивація воднем при температурах 400–450 °C (відпал у формуючому газі `H_2/N_2`), що зв'язує обірвані зв'язки кремнію в стійкі групи `Si-H`, зменшує густину `D_{it}` з `10¹²` до менш ніж `10¹⁰` см⁻²·еВ⁻¹, знижуючи поверхневу швидкість рекомбінації `S_{eff}` з 1000 см/с до менш ніж 1 см/с.
