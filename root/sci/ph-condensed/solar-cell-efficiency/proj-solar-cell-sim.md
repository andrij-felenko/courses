# ⚙️ Симуляція IV-характеристики та розрахунок ККД сонячного елемента

Моделювання вольт-амперної характеристики (IV), знаходження точки максимальної потужності (MPP), фактора заповнення (FF) та підсумкового коефіцієнта корисної дії (ККД) сонячного елемента реалізується через обчислювальний алгоритм на основі фізичної однодіодної еквівалентної схеми.

### Математична модель однодіодного еквівалентного кола

У напівпровідниковій фізиці сонячний елемент моделюється як паралельне з'єднання ідеального джерела фотоструму `I_ph`, напівпровідникового p-n діода, що описує випромінювальну та безипромінювальну рекомбінацію носіїв, послідовного опору `R_s` та паралельного опору витоку `R_sh`.

Повний вихідний струм елемента `I` при заданій зовнішній напрузі `V` підпорядковується неявному трансцендентному рівнянню:

```
f(I) = I_ph - I_0 · [ exp( (e · (V + I · R_s)) / (n · k_B · T) ) - 1 ] - (V + I · R_s) / R_sh - I = 0
```

де:
- `I_ph` — світловий фотострум генерації носіїв (А),
- `I_0` — зворотний струм насичення p-n переходу (А),
- `e = 1.60217663·10⁻¹⁹ Кл` — елементарний заряд,
- `k_B = 1.380649·10⁻²³ Дж/К` — стала Больцмана,
- `T` — температура p-n переходу в кельвінах (K),
- `n` — фактор ідеальності диода (1.0 для ідеальної дифузійної рекомбінації, 2.0 для рекомбінації у виснаженій зоні),
- `R_s` — послідовний опір металевих шин та емітера (Ом),
- `R_sh` — паралельний опір витоку на краях кристала (Ом).

Оскільки змінна `I` входить як у лінійну частину, так і в показник експоненти, рівняння не має аналітичного розв'язку в елементарних функціях. Для знаходження струму `I` при кожній напрузі `V` застосовують чисельний **метод Ньютона-Рафсона** (*Newton-Raphson method*).

Аналітично розв'язок неявного рівняння можна записати через спецфункцію — W-функцію Ламберта (*Lambert W function*):

```
I(V) = ( R_sh · (I_ph + I_0) - V ) / ( R_s + R_sh ) - ( v_t / R_s ) · W( θ )
```

де `θ = ( (I_0 · R_s · R_sh) / (v_t · (R_s + R_sh)) ) · exp( (R_sh · (R_s · (I_ph + I_0) + V)) / (v_t · (R_s + R_sh)) )`, а `v_t = (n · k_B · T) / e`. Проте чисельне обчислення W-функції Ламберта є обчислювально складнішим, ніж прямий алгоритм Ньютона-Рафсона.

### Розширення моделі: дводіодна еквівалентна схема

Для більш точного моделювання напівпровідникових елементів при малій інсоляції або високих температурних градієнтах використовують дводіодну модель (*Two-Diode Model*), у якій рекомбінація розділяється на дві складові:

```
I(V) = I_ph - I_01 · [ exp(e·V_d / (k_B·T)) - 1 ] - I_02 · [ exp(e·V_d / (2·k_B·T)) - 1 ] - V_d / R_sh
```

де `V_d = V + I·R_s`. Діод з струмом `I_01` описує дифузійний струм у квазінейтральних областях (`n = 1`), а діод з `I_02` — рекомбінаційно-генераційний струм у виснаженій зоні p-n переходу (`n = 2`).

### Чисельний метод Ньютона-Рафсона та швидкості збіжності

Метод Ньютона-Рафсона шукає корінь рівняння `f(I) = 0` шляхом послідовних наближень:

```
I_{k+1} = I_k - f(I_k) / f'(I_k)
```

Аналітична похідна функції `f(I)` за змінною струму `I` становить:

```
f'(I) = - I_0 · (e · R_s / (n · k_B · T)) · exp( (e · (V + I · R_s)) / (n · k_B · T) ) - R_s / R_sh - 1
```

Оскільки похідна `f'(I)` є строго від'ємною для всіх фізичних значень струму (`f'(I) < -1`), функція `f(I)` є строго спадною та монотонною. Це забезпечує швидку квадратичну збіжність алгоритму Ньютона-Рафсона за 3–6 ітерацій для будь-яких напруг у діапазоні від `0` до `V_oc`.

Для запобігання чисельному переповненню типу `double` при обчисленні експоненти при високих напругах аргумент `arg = e·(V + I·R_s) / (n·k_B·T)` затискається підголівником `arg ≤ 80.0`.

### Критерії збіжності струму та контроль похибки симуляційного поля

Для забезпечення високої обчислювальної точності у фотовольтаїчному моделюванні недостатньо відстежувати лише абсолютний зсув струму `|I_{k+1} - I_k| < ε_abs`. Додатково запроваджують двокритерільну перевірку збіжності:

1. **Відносна неузгодженість струму:** `|I_{k+1} - I_k| / (|I_{k+1}| + ε_zero) < ε_rel`, де `ε_rel = 10⁻⁸` гарантує точність у мікроамперній зоні при близьких до `V_oc` напругах.
2. **Нев'язка фізичного рівняння:** перевірка відновлення нуля `|f(I_{k+1})| < ε_f`, яка підтверджує виконуваність першого закону Кірхгофа для вузла p-n переходу.

У складних полях симуляції з градієнтом температури чи локальним затіненням значення `R_s` та `R_sh` стають динамічними функціями напруги. У таких умовах стабільність ітерацій Ньютона-Рафсона забезпечується адаптивним зменшенням кроку `ΔI = -α · f(I_k) / f'(I_k)` із коефіцієнтом демпфування `α ∈ (0, 1]`.

### Пошук параметрів V_oc, I_sc та точки максимальної потужності (MPP)

Алгоритм розрахунку складається з чотирьох послідовних етапів:

1. **Струм короткого замикання `I_sc`:** розраховується як значення струму при нульовій напрузі `V = 0`.
2. **Напруга холостого ходу `V_oc`:** шукається методом бісекції (ділення навпіл) у діапазоні `V ∈ [0, 1.2 В]` до досягнення струму `I(V_oc) = 0`.
3. **Сканування IV-профілю та пошук MPP:** інтервал напруги `[0, V_oc]` розбивається на N сіткових кроків (`N = 1000`). У кожному вузлі обчислюється струм `I(V_k)` та електрична потужність `P(V_k) = V_k · I(V_k)`. Точка з найвищим значенням `P` визначає напругу `V_mp` та струм `I_mp`.
4. **Розрахунок FF та ККД:** оцінюється фактор заповнення `FF = P_max / (V_oc · I_sc)` та підсумковий ККД `η = P_max / P_in`.

### Алгоритми відстеження точки максимальної потужності (MPPT)

У реальних мережевих інверторах сонячних електростанцій для утримання сонячного модуля в точці MPP застосовують спеціальні цифрові алгоритми MPPT:

- **Метод збурення та спостереження (Perturb and Observe, P&O):** мікроконтролер інвертора робить малий крок зміни напруги `ΔV` та порівнює вихідну потужність `P_k` із попереднім значенням `P_{k-1}`. Якщо `ΔP > 0`, напруга продовжує змінюватись у тому ж напрямку; якщо `ΔP < 0`, напрямок змінюється на протилежний.
- **Метод зростаючої провідності (Incremental Conductance):** базується на аналізі похідної потужності за напругою `dP / dV = 0`. У точці MPP виконується співвідношення:

```
dI / dV = - I / V
```

Якщо `dI / dV > -I / V`, робоча точка перебуває зліва від MPP (напругу слід збільшувати); якщо `dI / dV < -I / V`, робоча точка праворуч (напругу слід зменшувати).

### Оцінка параметрів моделі з експериментальних вимірювань

При практичній розробці система повинна витягувати 5 параметрів моделі (`I_ph, I_0, n, R_s, R_sh`) з виміряної вольт-амперної кривої лабораторії. Для цього застосовують алгоритм Левенберга-Маркварда (*Levenberg-Marquardt algorithm*) мінімізації нелінійної квадратичної неузгодженості:

```
S = ∑_{j=1}^{M} [ I_exp(V_j) - I_calc(V_j; I_ph, I_0, n, R_s, R_sh) ]²
```

Мінімізація нелінійної суми квадратів відхилень дозволяє відновити омічний опір контакту `R_s` та опір витоку `R_sh` із точністю понад 99%.

### Типові інженерні пастки та чисельна стійкість

1. **Експоненційне переповнення (`Floating-point overflow`):** при початковому ітеруванні чи неправильно вибраній напрузі `V + I·R_s > 0.8 В` значення `exp()` виходить за межі допустимого діапазону чисел подвійної точності IEEE-754 (`exp(709) ≈ 1.79·10³⁰⁸`). Обмеження аргументу `arg ≤ 80.0` гарантує стабільну роботу диференціального кроку без ризику отримання значення `NaN` чи `Inf`.
2. **Деградація фактора заповнення через послідовний опір `R_s`:** зростання `R_s` всього лише на 10 мОм (наприклад, через окиснення паяних струмознімальних шин) зменшує фактор заповнення `FF` з 82% до 68%, перетворюючи високоефективний фотоелемент на низькоякісний.
3. **Паразитний шунтуючий витік `R_sh`:** малий опір шунта (`R_sh < 100 Ом`) суттєво зменшує вихідну напругу `V_oc` та робить фотоелемент надзвичайно чутливим до затінення та низького рівня освітленості.
