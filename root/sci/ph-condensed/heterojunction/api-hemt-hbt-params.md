# 📋 Специфікації та інженерні параметри гетероструктурних приладів HEMT та HBT

Цей інженерний довідник містить систематизований опис фізичних параметрів напівпровідникових гетеропар, розрахункові формули, специфікації та конструктивні характеристики приладів надвисокочастотної (НВЧ), оптоелектронної та силової електроніки — транзисторів із високою рухливістю електронів (HEMT), гетероструктурних біполярних транзисторів (HBT), подвійних гетеролазерів та лазерів із поверхневим випромінюванням (VCSEL).

### 1. Таблиця та фізичний аналіз електрофізичних параметрів фундаментальних гетеропар

Промислове виготовлення гетероструктур спирається на обмежений перелік матеріальних систем, у яких збігання періодів кристалічної ґратки або можливість пружної деформації дозволяють ростити бездефектні епітаксійні шари методом молекулярно-променевої епітаксії (MBE) або металоорганічного газофазного осадження (MOCVD).

#### Фізичні особливості кожної матеріальної системи
1. **Система `GaAs / AlGaAs`:** Ідеальна ізоґраткова система, у якій заміщення атомів галію на алюміній практично не змінює період кристалічної ґратки. Оскільки `88%` розриву припадає на зону провідності (`ΔE_c = 0.33 еВ`), ця система є стандартом для HEMT транзисторів та напівпровідникових лазерів близького інфрачервоного діапазону (`850 нм`).
2. **Система `InGaAs / InP`:** Точно підібраний склад твердого розчину `In_{0.53}Ga_{0.47}As` забезпечує повний збіг кристалічної ґратки з підкладкою `InP`. Великий розрив валентної зони (`ΔE_v = 0.38 еВ`) блокує зворотну інжекцію дірок, що робить її найкращою для високошвидкісних HBT транзисторів із частотою понад 500 ГГц та телекомунікаційних лазерів на довжини хвиль `1.31 мкм` та `1.55 мкм` (зони мінімального загасання й дисперсії у кварцовому волокні).
3. **Система `AlGaN / GaN`:** Широкозонна гетеропара з гігантським зонним розривом (`ΔE_c = 0.70 еВ`) та пробійною напругою понад `3 МВ/см`. Завдяки вюрцитній симетрії та сильним п'єзоелектричним полям утворює двовимірний електронний газ із густиною понад `10^13 см^-2` без штучного легування донорами, що є основою сучасної силової електроніки та підсилювачів 5G.
4. **Система `Si / SiGe`:** Єдина гетеропара, сумісна з класичною кремнієвою технологією КМОН (CMOS). Тонкий шар напруженого кремній-германію виступає в ролі бази біполярного транзистора, що піднімає швидкодію кремнієвих мікросхем до `200...300 ГГц` при низькій собівартості виробництва.

### 2. Специфікація та розрахункові формули HEMT (High Electron Mobility Transistor)

Транзистор із високою рухливістю електронів спирається на просторове розділення вільних електронів та позитивних іонів донорів завдяки створенню двовимірного електронного газу (2DEG) у трикутній квантовій ямі.

#### Поверхнева густина носіїв у 2DEG (`n_s`)
Для гетероструктури `AlGaAs / GaAs` з нелегованим спейсерним шаром товщиною `d_s` (який віддаляє донори від ями) та легованим широкозонним шаром товщиною `d_d` поверхнева концентрація електронів `n_s` (в см⁻²) на межі розділу розраховується за формулою:

```
n_s = (ε / (q · (d + Δd))) · (V_gs - V_p)
```

де:
- `ε` — діелектрична проникність широкозонного бар'єрного шару `AlGaAs` (`ε = ε_r · ε_0`);
- `d = d_s + d_d` — повна товщина широкозонного шару `AlGaAs` під затвором (типово `20...40 нм`);
- `Δd` — ефективна глибина залягання квантового рівня 2DEG у ямі (типово `5...8 нм`);
- `V_gs` — управляюча напруга затвор-витік;
- `V_p` — напруга відсічки (порогова напруга відкривання транзистора).

#### Напруга відсічки каналу (`V_p`)
Напруга відсічки визначає мінімальне від'ємне зміщення на затворі, за якого двовимірний електронний газ повністю збіднюється і канал закривається:

```
V_p = ϕ_b - (ΔE_c / q) - (q · N_d · d_d²) / (2 · ε)
```

де `ϕ_b` — висота бар'єра Шотткі для контакту метал-затвор (типово `0.8...0.9 В` для контакту `Ti/Au` або `Ni/Au` на `AlGaAs`).

#### Поляризаційний 2DEG у нітридних гетероструктурах (`AlGaN / GaN`)
У гетероструктурах на основі нітридів елементів III групи (`GaN / AlGaN`) двовимірний електронний газ утворюється **навіть без штучного легування донорами** завдяки надпотужним поляризаційним ефектам:
1. **Спонтанній поляризації (`P_SP`):** внаслідок несимметричності гексагональної вюрцитної кристалічної ґратки;
2. **П'єзоелектричній поляризації (`P_PE`):** внаслідок сильного пружного деформування тонкого шару `AlGaN` на підкладці `GaN`.

Сумарна поверхнева густина поляризаційного заряду `σ_pol` на межі `AlGaN / GaN` досягає значення:

```
σ_pol = | P_SP(AlGaN) - P_SP(GaN) + P_PE(AlGaN) | / q ≈ 1.0·10^13 ... 1.5·10^13 см^-2
```

Це дозволяє отримувати рекордні струми у силових GaN транзисторах без введення домішок, що погіршують пробійну напругу середовища.

#### Питома крутість характеристики (`g_m`)
Максимальна питома крутість транзистора у режимі насичення описує ефективність управління струмом стоку за допомогою напруги затвору:

```
g_m = dI_ds / dV_gs = (w_gate · ε · v_sat) / (d + Δd)
```

де:
- `w_gate` — ширина затвору транзистора;
- `v_sat` — дрейфова швидкість насичення електронів (у `GaAs` `v_sat ≈ 1.2 · 10^7 см/с`, у `GaN` `v_sat ≈ 2.5 · 10^7 см/с`).

#### Мінімальний коефіцієнт шуму (`F_min`)
Для малошумних підсилювачів НВЧ діапазону коефіцієнт шуму HEMT описується феноменологічною формулою Фукуї:

```
F_min = 1 + K_f · (f / f_T) · √( g_m · (R_s + R_g) )
```

де `K_f` — підганяльний фактор якості матеріалу (`0.5...1.1`), `f` — робоча частота сигналу, `R_s` — паразитний опір витоку, `R_g` — опір металізації затвору. Завдяки низьким паразитним опорам `R_s` HEMT є найменш шумливим підсилювачем у діапазоні `1...100 ГГц`.

### 3. Специфікація та розрахункові формули HBT (Heterojunction Bipolar Transistor)

У гетероструктурному біполярному транзисторі N-p-n емітер виготовлено з широкозонного матеріалу (`InP` або `AlGaAs`), а базу — з вузькозонного (`InGaAs` або `GaAs`).

#### Коефіцієнт інжекції емітера (`γ`)
Завдяки розриву валентної зони `ΔE_v` зворотний потік дірок із бази в емітер пригнічується в `exp(ΔE_v / (k_B · T))` разів:

```
γ = I_n / (I_n + I_p) = 1 / [ 1 + (N_a / N_d) · (v_p / v_n) · exp(-ΔE_v / (k_B · T)) ]
```

Оскільки `ΔE_v >> k_B · T` (наприклад, `0.38 еВ >> 0.026 еВ` при 300 К), експоненційний фактор становить `exp(-14.6) ≈ 4 · 10^-7`. Це робить `γ ≈ 0.99999` незалежно від рівня легування бази.

#### Коефіцієнт підсилення струму в схемі зі спільним емітером (`β`)

```
β = I_c / I_b ≈ (N_d · v_n) / (N_a · v_p) · exp(ΔE_v / (k_B · T))
```

Це дозволяє легувати базу HBT до екстремальних рівнів `N_a > 10^20 см^-3` (зменшуючи опір бази `R_b` в десятки разів) при збереженні високого коефіцієнта підсилення `β = 100...500`.

#### Гранична частота підсилення за струмом (`f_T`)
Гранична частота визначається сумарним часом затримки носіїв `τ_ec` при прольоті від емітера до колектора:

```
f_T = 1 / (2 · π · τ_ec)
```

Загальний час затримки складається із чотирьох послідовних компонентів:

```
τ_ec = τ_e + τ_b + τ_dep + τ_c
```

де:
- `τ_e = r_e · C_je` — час заряджання бар'єрної ємності емітерного переходу через диференціальний опір `r_e = k_B·T / (q·I_e)`;
- `τ_b = W_b² / (2 · D_n)` — час дифузійного прольоту електронів через базу товщиною `W_b` (при використанні градного поля Крьомера в базі `τ_b` зменшується в 3...5 разів);
- `τ_dep = W_c / (2 · v_sat)` — час дрейфового прольоту через збіднену область колектора товщиною `W_c`;
- `τ_c = (R_e + R_c) · C_jc` — час заряджання ємності колекторного переходу.

#### Гранична частота максимальної потужності (`f_max`)
Частота, на якій коефіцієнт підсилення потужності падає до одиниці:

```
f_max = √( f_T / (8 · π · R_b · C_jc) )
```

Завдяки наднизькому опору бази `R_b` гетеротранзистори InP/InGaAs досягають `f_max > 1000 ГГц` (1 ТГц).

### 4. Специфікація подвійних гетеролазерів (DH Laser & VCSEL)

Подвійна гетероструктура забезпечує подвійне обмеження: електричне (потенціальна яма) та оптичне (діелектричний хвилевід).

#### Порогова густина струму лазера (`J_th`)
Порогова густина струму описує умову, за якої оптичне підсилення в активній області точно компенсує внутрішні втрати випромінювання та вихід світла через дзеркала резонатора:

```
J_th = (q · d_act · B_rec · n_th²) / η_int
```

де:
- `d_act` — товщина активного шару (для квантової ями `d_act = 5...10 нм`);
- `B_rec` — коефіцієнт випромінювальної рекомбінації;
- `η_int` — внутрішній квантовий вихід (типово `0.90...0.98`);
- `n_th` — порогова концентрація носіїв для досягнення інверсії населеності.

#### Фактор оптичного обмеження (`Γ`)
Частка потужності світлової хвилі, локалізована в межах активного шару:

```
Γ ≈ (2 · π² · (n_1² - n_2²) · d_act²) / λ₀²
```

де `n_1` — показник заломлення активного шару, `n_2` — показник заломлення обкладок, `λ₀` — довжина хвилі випромінювання у вакуумі.

#### Характеристична температура лазера (`T_0`)
Температурна нестабільність порогового струму описується феноменологічною формулою Панківа:

```
J_th(T) = J_0 · exp(T / T_0)
```

Для лазерів на квантових ямах `GaAs / AlGaAs` характеристична температура становить `T_0 = 150...220 К`, що забезпечує стабільну роботу без термоелектричного охолодження Пельтьє.
