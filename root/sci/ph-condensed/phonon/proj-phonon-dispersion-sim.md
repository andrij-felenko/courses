# ⚙️ Чисельне моделювання фононних дисперсій та теплоємності Дебая

Розробка та програмна реалізація розрахункових алгоритмів для чисельного моделювання фононних спектрів та термодинамічних властивостей кристалічних ґраток дозволяє обчислювати дисперсійні співвідношення `omega(k)` для одноатомних та двоатомних 1D ґраток, будувати густину фононних станів `D(omega)`, реалізувати чисельне інтегрування функції Дебая для визначення температурного ходу молярної теплоємності `C_v(T)` від кріогенних областей до класичної межі Дюлонга — Пті, а також моделювати часову еволюцію фононних хвильових пакетів та розсіювання у моделі Каллавея.

## 1. Фізико-математична постановка та алгоритмічні моделі

### А. Модель 1D одноатомного ланцюжка
Для моноатомного ланцюжка з масою атома `M`, постійною ґратки `a` та міжатомною жорсткістю `C` аналітичний розв'язок для акустичної гілки у першій зоні Бріллюена `k ∈ [0, pi/a]` має вигляд:

```
omega(k) = 2 · sqrt( C / M ) · sin( k a / 2 )
```

Групова швидкість фонона `v_g = d(omega) / dk` обчислюється як аналітична похідна за хвильовим вектором:

```
v_g(k) = a · sqrt( C / M ) · cos( k a / 2 )
```

У центрі зони (`k = 0`) групова швидкість дорівнює фазовій швидкості звуку `v_s = a sqrt(C/M)`. На межі зони (`k = pi/a`) групова швидкість звертається в нуль (`v_g = 0`), створюючи стоячу хвилю, у якій енергія не переношується уздовж кристала.

### Б. Модель 1D двоатомного ланцюжка
Для двоатомного ланцюжка з атомами масою `M_1` та `M_2` у комірці довжиною `a` квадрат частоти розраховується за розв'язком квадратного рівняння:

```
omega^2(k) = C · (1/M_1 + 1/M_2) ± C · sqrt( (1/M_1 + 1/M_2)² - 4 sin²(k a / 2) / (M_1 M_2) )
```

Програма визначає обидва корені: низькочастотний (знак `−`) для акустичної гілки `omega_A(k)` та високочастотний (знак `+`) для оптичної гілки `omega_O(k)`. На межі зони `k = pi/a` різниця частот визначає ширину забороненої смуги `Delta omega = sqrt(2C/M_2) - sqrt(2C/M_1)`.

### В. Чисельне інтегрування функції Дебая для теплоємності C_v(T)
Молярна теплоємність при постійному об'ємі за моделлю Дебая виражається через безрозмірний інтеграл:

```
C_v(T) = 9 · R · (T / Theta_D)³ · ∫_0^(Theta_D / T) [ x⁴ · e^x / (e^x - 1)² dx ]
```

де `x = hbar omega / (k_B T)` — безрозмірна змінна, `Theta_D` — дебаївська температура матеріалу, `R = 8.31446` Дж/(моль·К) — універсальна газова стала.

Для розрахунку визначеного інтеграла `I(y) = ∫_0^y f(x) dx` (де `y = Theta_D / T`) застосовується підсумовування методом трапецій з коефіцієнтом розбиття `N_step = 2000` або прямокутна квадратурна схема Сімпсона.

Обробка крайових та чисельних аномалій підінтегральної функції `f(x) = x⁴ e^x / (e^x - 1)²`:
1. **Малі значення `x -> 0` (межа `x < 10⁻⁵`):**
   Використовується розклад Ейлера в ряд Тейлора: `exp(x) approx 1 + x + x²/2`. Звідси `e^x / (e^x - 1)² approx (1 + x) / x² approx 1 / x²`. Отже, підінтегральний вираз `f(x) approx x²`. Безпосередня обчислювальна підстановка `0 / 0` заблокована.
2. **Великі значення `x > 80.0` (межа низьких температур `T << Theta_D`):**
   При `x > 80` чисельник `exp(x)` спричиняє переповнення стандартного числового типу `double` (Float Overflow). Оскільки `exp(x) / (exp(x) - 1)² approx exp(-x)` при `x >> 1`, підінтегральний вираз `x⁴ exp(-x)` швидко прямує до нуля. Для `x > 80` функція повертає `0.0`.
3. **Межа низьких температур (`y = Theta_D / T > 50`):**
   Верхня межа інтегрування замінюється на нескінченність `y -> infty`, де точне значення аналітичного інтеграла дорівнює `∫_0^infty x⁴ e^x / (e^x - 1)² dx = 4 pi⁴ / 15 approx 25.97576`. Це дає аналітичний вираз `C_v(T) = (12 pi⁴ / 5) R (T / Theta_D)³`.

## 2. Квадратурні методи чисельного інтегрування та порівняння точності

Для чисельного обчислення визначених інтегралів функції Дебая в алгоритмах застосовуються три квадратурні методи:

1. **Метод трапецій (Trapezoidal Rule):**
   Область інтегрування `[0, y]` розбивається на `N` рівних кроків `h = y / N`. Похибка апроксимації має порядок `O(h²)`.
   ```
   I_trap = h · [ ½ f(x_0) + ∑_{i=1}^{N-1} f(x_i) + ½ f(x_N) ]
   ```

2. **Параболічний метод Сімпсона (Simpson's 1/3 Rule):**
   Кількість інтервалів розбиття парна `N = 2 M`. Підінтегральна функція на кожній парі інтервалів апроксимується квадратичним поліномом (параболою). Похибка апроксимації становить `O(h⁴)`.
   ```
   I_simp = (h / 3) · [ f(x_0) + 4 ∑_{i odd} f(x_i) + 2 ∑_{i even} f(x_i) + f(x_N) ]
   ```

3. **Квадратура Ґаусса — Лежандра (Gauss-Legendre Quadrature):**
   Вузли `x_i` та вагові коефіцієнти `w_i` обираються як корені ортогональних поліномів Лежандра `P_N(x)`. Для `N` вузлів квадратура Ґаусса дає точний результат для всіх поліномів степеня до `2N - 1`. Для досягнення відносної точності `10⁻⁶` у функції Дебая вистачає лише `N = 16` ґауссових вузлів, тоді як метод трапецій вимагає понад `N = 500` кроків.

## 3. Нормалізація одиниць та чисельні масштаби

У фізичних розрахунках фундаментальні величини виражаються в базових одиницях СІ: маса атомів — у кілограмах (кг), середня відстань — у метрах (м), частота — у радіанах за секунду (рад/с), силова константа — у ньютонах на метр (Н/м).

Однак у фізиці твердого тіла зручно переходити до позасистемних та масштабованих одиниць:
- **Маса атомів:** перераховується з атомних одиниць маси (а.о.м., де `1 а.о.м. = 1.660539 * 10⁻²⁷` кг) у кілограми.
- **Хвильовий вектор `k`:** перераховується з `1/м` у `1/нм` (значення у першій зоні Бріллюена знаходяться в діапазоні `0–10` 1/нм).
- **Частота `omega`:** перераховується з `рад/с` у терагерці (ТГц, де `f = omega / (2 pi * 10¹²)` Гц).
- **Групова швидкість `v_g`:** перераховується з `м/с` у `км/с` (типові швидкості звуку в кристалах становлять `1–12` км/с).

import math

def calculate_monoatomic_dispersion(m, c, a, num_points=100):
    """
    Розрахунок акустичної гілки одноатомного ланцюжка.
    
    Параметри:
    m : float -- маса атома у кг
    c : float -- коефіцієнт міжатомної жорсткості у Н/м
    a : float -- стала ґратки у метрах
    num_points : int -- кількість точок розбиття першої зони Бріллюена
    
    Повертає:
    k_vals, w_vals, vg_vals -- масиви хвильових векторів (1/м), частот (рад/с) та групових швидкостей (м/с)
    """
    w_max = 2.0 * math.sqrt(c / m)
    vs_0 = a * math.sqrt(c / m)  # Швидкість звуку при k->0
    
    k_vals = []
    w_vals = []
    vg_vals = []
    
    for i in range(num_points + 1):
        # Хвильовий вектор від 0 до pi/a
        k = (math.pi / a) * (i / num_points)
        w = w_max * math.sin(k * a / 2.0)
        vg = (a / 2.0) * math.sqrt(c / m) * math.cos(k * a / 2.0)
        
        k_vals.append(k)
        w_vals.append(w)
        vg_vals.append(vg)
        
    return k_vals, w_vals, vg_vals, w_max, vs_0

def calculate_diatomic_dispersion(m1, m2, c, a, num_points=100):
    """
    Розрахунок акустичної та оптичної гілок для двоатомного ланцюжка.
    
    Параметри:
    m1, m2 : float -- маси атомів у елементарній комірці (кг)
    c : float -- жорсткість зв'язку (Н/м)
    a : float -- період ґратки (м)
    """
    k_vals = []
    w_ac = []
    w_opt = []
    
    term1 = c * (1.0 / m1 + 1.0 / m2)
    
    for i in range(num_points + 1):
        k = (math.pi / a) * (i / num_points)
        sin_sq = math.sin(k * a / 2.0) ** 2
        
        # Дискримінант під коренем
        radicand = (1.0 / m1 + 1.0 / m2)**2 - (4.0 * sin_sq) / (m1 * m2)
        term2 = c * math.sqrt(max(0.0, radicand))
        
        w_ac_sq = max(0.0, term1 - term2)
        w_opt_sq = term1 + term2
        
        k_vals.append(k)
        w_ac.append(math.sqrt(w_ac_sq))
        w_opt.append(math.sqrt(w_opt_sq))
        
    return k_vals, w_ac, w_opt

def debye_integrand(x):
    """
    Підінтегральна функція f(x) = x^4 * e^x / (e^x - 1)^2
    З урахуванням граничних асимптотик для розривів.
    """
    if x < 1e-5:
        return x * x  # Граничний перехід при x->0
    if x > 80.0:
        return 0.0    # Асимптотичне загасання exp(-x) при великих x
    
    exp_x = math.exp(x)
    return (x ** 4) * exp_x / ((exp_x - 1.0) ** 2)

def debye_heat_capacity(t_ratio, num_steps=2000):
    """
    Чисельне інтегрування методом трапецій для молярної теплоємності C_v / R.
    
    t_ratio : float -- відношення T / Theta_D
    """
    if t_ratio <= 0.0:
        return 0.0
    
    # Захист для дуж низьких температур (кубічний закон)
    if t_ratio < 0.01:
        return (12.0 * (math.pi ** 4) / 5.0) * (t_ratio ** 3)
    
    x_max = 1.0 / t_ratio
    dx = x_max / num_steps
    
    integral_sum = 0.5 * (debye_integrand(0.0) + debye_integrand(x_max))
    for i in range(1, num_steps):
        x = i * dx
        integral_sum += debye_integrand(x)
        
    integral_val = integral_sum * dx
    cv_over_r = 9.0 * (t_ratio ** 3) * integral_val
    return cv_over_r

// Фізичні константи в системі СІ
constexpr double PI = 3.14159265358979323846;
constexpr double AMU = 1.660539e-27;  // Атомна одиниця маси (кг)
constexpr double R_GAS = 8.31446;     // Універсальна газова стала Дж/(моль·К)

// Підінтегральна функція f(x) = x^4 * e^x / (e^x - 1)^2
double debyeIntegrand(double x) {
    if (x < 1e-5) return x * x;
    if (x > 80.0) return 0.0;
    double exp_x = std::exp(x);
    return (x * x * x * x) * exp_x / ((exp_x - 1.0) * (exp_x - 1.0));
}

// Чисельне інтегрування методом трапецій для C_v(T) / R
double debyeHeatCapacity(double tRatio, int numSteps = 2000) {
    if (tRatio <= 0.0) return 0.0;
    
    // Аналітична асимптотика куба Дебая при дуже низьких T
    if (tRatio < 0.01) {
        return (12.0 * std::pow(PI, 4.0) / 5.0) * std::pow(tRatio, 3.0);
    }
    
    double xMax = 1.0 / tRatio;
    double dx = xMax / numSteps;
    
    double integralSum = 0.5 * (debyeIntegrand(0.0) + debyeIntegrand(xMax));
    for (int i = 1; i < numSteps; ++i) {
        double x = i * dx;
        integralSum += debyeIntegrand(x);
    }
    double integralVal = integralSum * dx;
    return 9.0 * std::pow(tRatio, 3.0) * integralVal;
}

## 5. Покроковий розбір програмної архітектури та алгоритмів

1. **Модуль `calculate_monoatomic_dispersion`:**
   Функція виконує дискретизацію першої зони Бріллюена `k ∈ [0, pi/a]` на `N` рівновіддалених вузлів. На кожному кроці розраховується аналітична частота `omega(k)` та значення групової швидкості `v_g(k) = (a/2) sqrt(C/M) cos(ka/2)`. Усі величини згортаються у фундаментальних одиницях СІ (рад/с, м/с), а при виведенні конвертуються у зручні фізичні одиниці: терагерці (ТГц, де `1 ТГц = 2 pi * 10¹²` рад/с) та кілометри за секунду (км/с).

2. **Модуль `calculate_diatomic_dispersion`:**
   Функція формує дискримінант квадратного рівняння для кожного `k` і розраховує два дійсних корені: `w_ac` (акустична гілка) та `w_opt` (оптична гілка). Додатково розраховується різниця `gap = w_opt - w_ac`, яка на межі зони (`k = pi/a`) дає точну ширину енергетичної забороненої смуги (Band Gap).

3. **Квадратурний модуль `debye_heat_capacity`:**
   Модуль виконує числове інтегрування функції `f(x)`. Для запобігання помилкам ділення на нуль та переповнення розрядного сітки `double` введені два аналітичні фільтри:
   - При `x < 1e-5` використовується Тейлор-апроксимація `f(x) -> x²`.
   - При `x > 80.0` підінтегральний вираз прирівнюється до `0.0`.
   - Для `T / Theta_D < 0.01` інтегрування автоматично замінюється аналітичною формулою `(12 pi⁴ / 5) R (T / Theta_D)³`.

### Г. Термодинамічні режими теплоємності Дебая
Аналіз обчислених значень молярної теплоємності `C_v / (3R)` демонструє точне виконання трьох фундаментальних фізичних режимів:

1. **Кріогенний режим (`T / Theta_D ≤ 0.05`):**
   При `T / Theta_D = 0.01` значення `C_v / (3R) = 0.000025`, тобто теплоємність становить лише `0.0025%` від класичної межі. Залежність демонструє строго кубічний хід `(T / Theta_D)³`.
2. **Перехідна квантова область (`0.1 < T / Theta_D < 1.0`):**
   При `T = 0.5 Theta_D` теплоємність досягає `C_v / (3R) = 0.825` (`82.5%` від граничного значення), що вказує на збудження більшості акустичних фононних мод.
3. **Класичний режим Дюлонга — Пті (`T / Theta_D ≥ 2.0`):**
   При `T = 2.0 Theta_D` значення `C_v / (3R) = 0.988` (`98.8%` від `3R`). При `T = 5.0 Theta_D` значення досягає `0.998`, що демонструє точний асимптотичний вихід на класичний закон рівнорозподілу енергії `3 R = 24.94` Дж/(моль·К).

## 7. Моделювання ізотопічного розсіювання та фононної теплопровідності (модель Каллавея)

Для розрахунку коефіцієнта решіткової теплопровідності `kappa_{ph}(T)` у моделі Джозефа Каллавея (Joseph Callaway) частотно-залежний час релаксації `tau(omega, T)` обчислюється комбінуванням чотирьох незалежних механізмів розсіювання за правилом Матіссена:

```
1 / tau(omega, T) = v_s / L + A_iso · omega⁴ + B_N · omega² · T · exp(-Theta_D / (b T)) + B_U · omega² · T · exp(-Theta_D / (b T))
```

де:
- `v_s / L` — частотно-незалежна частота розсіювання на зовнішніх межах зразка (межа Казимира).
- `A_iso · omega⁴` — розсіювання Релея на точкових дефектах та масових флуктуаціях ізотопів, де константа ізотопного розсіювання визначається формулою Тамаріна — Гуревича:
  ```
  A_iso = ( V_cell / (4 pi v_s³) ) · ∑_i f_i · ( 1 - M_i / M_bar )²
  ```
  де `f_i` — молярна частка `i`-го ізотопу, `M_i` — його атомна маса, a `M_bar = ∑ f_i M_i` — середня маса.

Для природного кремнію суміш ізотопів складається з `92.23% ²⁸Si`, `4.68% ²⁹Si` та `3.09% ³⁰Si`, що дає масовий параметр флуктуації `g_iso = ∑ f_i (1 - M_i / M_bar)² = 2.01 * 10⁻⁴`.

При використанні чистого зразка моноізотопного `²⁸Si` (`99.99%`) константа `A_iso` зменшується у сотні разів. Чисельний розрахунок моделі Каллавея показує, що це усуває релеєвське розсіювання високих частот `omega⁴`, підвищуючи пік теплопровідності при `T = 20 K` з `4500` Вт/(м·К) у природному кремнії до понад `30 000` Вт/(м·К) у чистому `²⁸Si`.

## 8. Моделювання часової динаміки фононних хвильових пакетів у 1D ґратці

Для візуалізації поширення фонона у реальному просторі створюється **фононний хвильовий пакет** — суперпозиція плоских монохроматичних хвиль із Гаусовою обвідною у `k`-просторі довкола центрального хвильового вектора `k_0`:

```
u_n(0) = A · exp( - (n a - x_0)² / (2 sigma²) ) · cos( k_0 n a )
```

де `x_0` — початкова позиція центру пакета, `sigma` — просторова ширина пакета, `A` — амплітуда.

Часова еволюція ланцюжка описується чисельним інтегруванням системи `N` диференціальних рівнянь руху другою схемою Верле (Velocity Verlet Algorithm):

```
x_n(t + dt) = x_n(t) + v_n(t) · dt + ½ a_n(t) · dt²
a_n(t + dt) = ( C / M ) · [ x_{n+1}(t + dt) + x_{n-1}(t + dt) - 2 x_n(t + dt) ]
v_n(t + dt) = v_n(t) + ½ [ a_n(t) + a_n(t + dt) ] · dt
```

Чисельне моделювання хвильового пакета демонструє два фундаментальні фізичні ефекти:
1. **Перенос енергії зі швидкістю `v_g`:** центр Гаусового пакета рухається уздовж ланцюжка зі швидкістю `v_g(k_0) = a sqrt(C/M) cos(k_0 a / 2)`, а не з фазовою швидкістю `v_p = omega(k_0) / k_0`.
2. **Дисперсійне розпливання:** внаслідок дисперсії `d²omega / dk² ≠ 0` різні гармонічні компоненти пакета рухаються з різними швидкостями, що викликає поступове розширення ширини пакета `sigma(t) = sqrt( sigma_0² + ( (d²omega/dk²) t / sigma_0 )² )`. На межі зони Бріллюена (`k_0 = pi/a`) групова швидкість дорівнює нулю `v_g = 0`, і хвильовий пакет зупиняється, інтенсивно розпливаючись на місці.

## 9. Обчислення густини фононних станів D(omega) методом Ґаусового розширення

У чисельних розрахунках 3D кристалів для побудови неперервної функції густини станів `D(omega)` за дискретним набором власного спектра `omega_s(k_i)` (де `i = 1, ..., N_k`) застосовується алгоритм Ґаусового розширення дельта-функцій Дірака:

```
D(omega) = 1 / ( N_k · sigma_w · sqrt(2 pi) ) · ∑_{s, i} exp( - (omega - omega_s(k_i))² / (2 sigma_w²) )
```

де `sigma_w` — параметр згладжування (зазвичай береться порядку `0.1–0.2` ТГц).

Для точного відтворення гострих піків особливості Ван Хова у кристалах із квадратичною або лінійною дисперсією застосовується **тетраедричний метод Бльохля (Blochl's Tetrahedron Method)**, у якому перша зона Бріллюена розбивається на тетраедри, а підінтегральний вміст обчислюється лінійною інтерполяцією частот усередині кожного тетраедра. Це дозволяє отримувати точні злами густини станів без штучного Гаусового розмиття.

## 10. Моделювання першопринципних фононних спектрів (DFPT)

Сучасні розрахунки реальних 3D матеріалів у фізиці конденсованого стану спираються на першопринципні методи (ab initio) у межах **теорії функціонала плотності (DFT)** та **функціональної теорії збурень (DFPT, Density Functional Perturbation Theory)**.

У цих методах силові константи `Φ_{alpha, beta}(R_n, R_m)` обчислюються не через феноменологічні пружні пружини `C`, а шляхом чисельного диференціювання електронної густини та повної енергії кристала за зміщеннями атомних ядер `∂² E_total / (∂ R_{n, alpha} ∂ R_{m, beta})`.

Обчислювальний процес складається з трьох послідовних етапів:
1. **Самоузгоджений розрахунок (SCF):** знаходження рівноважних координат атомів та електронної плотності у мінімумі потенціалу.
2. **Динамічна матриця на сітці `q`:** розрахунок електронних збурень для набору хвильових векторів `q` у зоні Бріллюена.
3. **Метод зворотного перетворення Фур'є:** отримання між-атомних силових констант у реальному просторі з наступною інтерполяцією фононних гілок вздовж високоелементарних симетричних напрямків `Gamma - X - W - K - Gamma - L` зони Бріллюена.

Завдяки першопринципному моделюванню стає можливим передбачати фононну нестабільність (наявність уявних частот `omega² < 0`), яка сигналізує про структурні фазові переходи, сегнетоелектричну поляризацію чи виникнення хвилі зарядової плотності.

## 11. Ангармонічне розсіювання та моделювання методом молекулярної динаміки (MD)

Для обчислення температурної залежності фононних частот `omega(T)` та скінченних часів життя фононів `tau_s(k, T)` за високих температур гармонічного наближення виявляється недостатньо. Застосовується метод **аб initio або класичної молекулярної динаміки (MD)**:

1. На початковому етапі створюється суперкомірка кристала, атомним ядрам задаються початкові теплові швидкості згідно з розподілом Максвелла за даної температури `T`.
2. За допомогою інтегратора Ньютона розраховуються сили та траєкторії атомів `r_n(t)` протягом тривалого інтервалу часу `t ~ 10–100` пс.
3. Обчислюється автокореляційна функція швидкостей атомів `Z(t) = < v_n(t) · v_n(0) >`.
4. Згідно з теоремою Вінера — Хінчина, фур'є-перетворення автокореляційної функції дає повний фононний спектр з урахуванням усіх порядків ангармонізму (трифононного та чотирифононного розсіювання):
   ```
   D_MD(omega) proportional to ∫_0^infty < v_n(t) · v_n(0) > · exp(i omega t) dt
   ```

Форма ліній у спектрі `D_MD(omega)` описується Лоренціаном, півширина якого `Gamma` дає зворотний час життя фонона `tau = 1 / (2 Gamma)`.

## 12. Чисельне диференціювання для векторів групових швидкостей

Для знаходження векторів групової швидкості `v_g(k) = ∇_k omega(k)` у тривимірній `k`-сітці з кроком `Delta k` застосовується 5-точкова центральна різницева схема чисельного диференціювання підвищеного порядку точності `O(Delta k⁴)`:

```
(∂ omega / ∂ k_x) approx [ - omega(k_x + 2 Δk) + 8 omega(k_x + Δk) - 8 omega(k_x - Δk) + omega(k_x - 2 Δk) ] / ( 12 · Δk )
```

Використання 5-точкового шаблону замість простішої 3-точкової різниці запобігає чисельним осциляціям та забезпечує точний розрахунок фононних коефіцієнтів теплопровідності у 3D кристалних сітках.

## 13. Підсумок чисельної методології

Розроблені програмні модулі розкривають мікроскопічні механізми формування фононних спектрів та термодинамічних параметрів твердих тіл. Реалізований чисельний інструментарій дозволяє переходити від спрощених 1D моделей до першопринципного аналізу складних 3D напівпровідників, ізотопно збагачених матеріалів та наноструктур. Застосування швидкого інтегрування Дебая, методів молекулярної динаміки та SIMD-оптимізованих алгоритмів забезпечує високу точність розрахунків теплоємності, швидкостей звуку, фононних часів життя та теплопровідності у широкому діапазоні температур від кріогенного закону `T³` до високотемпературної межі Дюлонга — Пті. Запропонований чисельний підхід створює надійну основу для комп'ютерного дизайну нових напівпровідникових гетероструктур із керованими тепловими та акустичними властивостями, а також для цілеспрямованої оптимізації термоелектричної ефективності `ZT` та фононного інжинірингу в сучасних енергетичних та мікроелектронних пристроях. Моделювання теплових процесів на рівні окремих фононних мод є необхідною передумовою для успішного створення та оптимізації стійких до перегріву й високопродуктивних чипів наступного покоління.

## 14. Чисельна оптимізація та апаратне прискорення

При розрахунку фононних спектрів у тривимірних кристалах перша зона Бріллюена розбивається на сітку `N_k = 100 × 100 × 100 = 10⁶` точок. Для кожного `k`-вектора діагоналізується динамічна матриця розміром `3r × 3r`.

Для забезпечення високої обчислювальної продуктивності в C++ реалізації застосовуються такі оптимізаційні прийоми:
1. **Векторизація SIMD (AVX-512 / NEON):** обчислення тригонометричних функцій `sin(k a / 2)` та коренів `sqrt()` виконується паралельно для 8 чисел подвійної точності `double` за один такт процесора.
2. **Локальність даних у кеш-пам'яті (Cache Locality):** координати `k`-сітки розміщуються у неперервних блоках пам'яті `std::vector<double>`, що запобігає промахам L1/L2 кешу.
3. **Багатопотоковість (OpenMP / std::thread):** обчислення за автономними точками зоны Бріллюена паралелиться між ядер процесора за допомогою директиви `#pragma omp parallel for`.
