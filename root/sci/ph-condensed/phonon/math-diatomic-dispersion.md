# 🧮 Виведення дисперсійного співвідношення для двоатомної ґратки

У цій вставці наведено вичерпний математичний та фізичний аналіз динаміки одновимірної, двовимірної та тривимірної кристалічної ґратки. Опис розгортається від мікроскопічного потенціалу міжатомних сил до точного виведення спектральних рівнянь для одноатомного й двоатомного ланцюжків. Детально розібрано виведення акустичних та оптичних гілок, фізичний зміст зведеної маси, фазові співвідношення коливань підґраток, утворення забороненої смуги частот (Band Gap), поведінку фазових і групових швидкостей, тензор пружних констант у 3D та співвідношення Крістоффеля, згинальні моди у 2D кристалах, аналітичне виведення густини фононних станів та особливості Ван Хова, граничні асимптотики дебаївського інтеграла, а також мікроскопічну теорію полярних оптичних мод та співвідношення Ліддейна — Сакса — Теллера (LST) у полярних кристалах.

## 1. Мікроскопічна основа: від міжатомного потенціалу до сил відновлення

Розглянемо парний потенціал міжатомної взаємодії `U(r)` між двома сусідніми атомами у кристалічній ґратці. У стані термодинамічної рівноваги атоми розміщені на відстані `r = a_0`, яка відповідає глобальному мінімуму потенціальної енергії `U(r)`. У цій точці рівнодійна міжатомних сил дорівнює нулю:

```
F(a_0) = - U'(a_0) = 0
```

При проведеному розкладі потенціальної енергії `U(r)` у ряд Тейлора за малими відносними зміщеннями `x = r - a_0` довкола положення рівноваги отримуємо:

```
U(a_0 + x) = U(a_0) + U'(a_0) · x + ½ U''(a_0) · x² + (1/6) U'''(a_0) · x³ + (1/24) U''''(a_0) · x⁴ + ...
```

Оскільки перша похідна `U'(a_0) = 0`, перший лінійний член зникає. Першим живим доданком у розкладі є квадратичний член. Ввівши позначення силової константи (коефіцієнта жорсткості зв'язку) `C = U''(a_0)`, у **гармонічному наближенні** потенціальна енергія набуває квадратичної форми:

```
U_harm(x) = U(a_0) + ½ C · x²
```

Відповідна квазіпружня відновлювальна сила описується точним аналогом закону Гука:

```
F(x) = - dU_harm / dx = - C · x
```

Для реальних кристалів сила жорсткості `C` визначається природою хімічного зв'язку. У ковалентних кристалах (алмаз, кремній) силова константа становить `150–200` Н/м, у металах (мідь, алюміній) — `30–80` Н/м, а в іонних кристалах (NaCl, KCl) — `15–40` Н/м.

Члени вищих порядків — кубічний `(1/6) U'''(a_0) x³` та квартальний `(1/24) U''''(a_0) x⁴` — задають **ангармонізм** міжатомних сил, який описує теплове розширення тіл та взаємодію між фононами.

## 2. Одноатомний ланцюжок: математичне виведення закону дисперсії

Розглянемо одновимірний кристал, що складається з `N` тотожних атомів масою `M`, розміщених уздовж прямої з періодом ґратки `a`. Нехай `u_n(t)` — зміщення `n`-го атома від його рівноважної координати `x_n = n a`.

Враховуючи гармонічну взаємодію лише між найближчими сусідами, запишемо пружні сили, що діють на `n`-й атом з боку лівого `(n-1)` та правого `(n+1)` атомів:

```
F_n = C · (u_{n+1} - u_n) - C · (u_n - u_{n-1}) = C · (u_{n+1} + u_{n-1} - 2 u_n)
```

За другим законом Ньютона рівняння руху `n`-го атома має вигляд:

```
M · d²u_n / dt² = C · (u_{n+1} + u_{n-1} - 2 u_n)
```

Оскільки кристал має дискретну трансляційну симетрію, розв'язок шукаємо у вигляді плоскої монохроматичної хвилі:

```
u_n(t) = u_0 · exp(i · (k · n · a - omega · t))
```

де `u_0` — амплітуда зміщення, `k` — хвильовий вектор, `omega` — колова частота.

Підставимо розв'язок у рівняння руху:

```
- M · omega² · u_0 · exp(i(k n a - omega t)) 
= C · u_0 · [ exp(i k (n+1) a) + exp(i k (n-1) a) - 2 exp(i k n a) ] · exp(-i omega t)
```

Скоротимо обидві частини на вираз `u_0 exp(i (k n a - omega t))`:

```
- M · omega² = C · [ exp(i k a) + exp(-i k a) - 2 ]    [ділення на u_n(t)]
```

Скориставшись формулою Ейлера `exp(i x) + exp(-i x) = 2 cos(x)` та тригонометричною тотожністю `1 - cos(x) = 2 sin²(x / 2)`:

```
- M · omega² = C · [ 2 cos(k a) - 2 ]                 [формула Ейлера]
= - 2 C · [ 1 - cos(k a) ]                            [винесення -2C]
= - 4 C · sin²(k a / 2)                               [тотожність 1 - cos(x) = 2 sin²(x/2)]
```

Звідси отримуємо точний закон дисперсії для одноатомного ланцюжка:

```
omega(k) = 2 · sqrt( C / M ) · |sin( k a / 2 )|
```

Проаналізуємо дві межі отриманого закону дисперсії:

1. **Довгохвильова границя (`k -> 0`):**
   При `k -> 0` довжина хвилі `lambda = 2 pi / k >> a`. Розкладаючи синус у ряд Тейлора `sin(k a / 2) approx k a / 2`, отримуємо лінійний закон дисперсії:
   ```
   omega(k) approx a · sqrt( C / M ) · k = v_s · k
   ```
   Фазова швидкість `v_p = omega / k` та групова швидкість `v_g = d(omega) / dk` збігаються і дорівнюють класичній швидкості звуку:
   ```
   v_s = a · sqrt( C / M )
   ```

2. **Межа зони Бріллюена (`k = ± pi / a`):**
   На кордоні першої зони Бріллюена `|sin(pi / 2)| = 1`. Частота досягає максимального значення `omega_max = 2 sqrt(C / M)`.
   Групова швидкість звертається в нуль:
   ```
   v_g = d(omega) / dk = a · sqrt(C / M) · cos(k a / 2) = 0    при k = pi/a
   ```
   Нульова групова швидкість означає, що енергія хвилі не переношується уздовж кристала: хвиля зазнає бржеггівського відбивання від ґратки і перетворюється на стоячу хвилю, у якій сусідні атоми коливаються у протифазі (`u_{n+1} = - u_n`).

## 3. Двоатомний ланцюжок: алгебраїчна система та секулярний детермінант

Розглянемо одновимірний ланцюжок, елементарна комірка якого містить два атоми з масами `M_1` та `M_2`. Період ґратки дорівнює `a`. Вважаємо, що атоми чергуються у порядку `... A_n - B_n - A_{n+1} - B_{n+1} ...`.

Позначимо зміщення атома `A` у `n`-й комірці як `u_n(t)`, а зміщення атома `B` у `n`-й комірці як `v_n(t)`.

Атом `A_n` розміщений між атомом `B_{n-1}` та атомом `B_n`. Сила, що діє на нього, дорівнює `C (v_n - u_n) - C (u_n - v_{n-1})`.
Атом `B_n` розміщений між атомом `A_n` та атомом `A_{n+1}`. Сила, що діє на нього, дорівнює `C (u_{n+1} - v_n) - C (v_n - u_n)`.

Запишемо диференціальні рівняння руху за другим законом Ньютона:

```
M_1 · d²u_n / dt² = C · (v_n + v_{n-1} - 2 u_n)
M_2 · d²v_n / dt² = C · (u_{n+1} + u_n - 2 v_n)
```

Шукаємо розв'язки для двох підґраток у формі плоских хвиль з однаковим хвильовим вектором `k` та частотою `omega`, але власними комплексними амплітудами `u_0` та `v_0`:

```
u_n(t) = u_0 · exp(i · (k · n · a - omega · t))
v_n(t) = v_0 · exp(i · (k · n · a - omega · t))
```

Підставимо ці розв'язки у диференціальні рівняння руху. Для першого рівняння підґратки `A`:

```
- M_1 · omega² · u_0 · exp(i (k n a - omega t)) 
= C · [ v_0 exp(i k n a) + v_0 exp(i k (n-1) a) - 2 u_0 exp(i k n a) ] · exp(-i omega t)
```

Скоротимо обидві частини на вираз `exp(i (k n a - omega t))`:

```
- M_1 · omega² · u_0 = C · v_0 · (1 + exp(-i k a)) - 2 C · u_0
```

Аналогічно для другого рівняння підґратки `B`:

```
- M_2 · omega² · v_0 = C · u_0 · (1 + exp(i k a)) - 2 C · v_0
```

Перегрупуємо члени відносно невідомих амплітуд `u_0` та `v_0`:

```
(2 C - M_1 · omega²) · u_0  -  C · (1 + exp(-i k a)) · v_0  = 0
- C · (1 + exp(i k a)) · u_0  +  (2 C - M_2 · omega²) · v_0  = 0
```

Отримана система двох однорідних лінійних алгебраїчних рівнянь має ненульові розв'язки `(u_0, v_0) ≠ (0,0)` тоді й лише тоді, коли детермінант її матриці дорівнює нулю:

```
det |  (2 C - M_1 · omega²)       - C · (1 + exp(-i k a))  |
    | - C · (1 + exp(i k a))        (2 C - M_2 · omega²)   | = 0
```

## 4. Аналітичний розв'язок секулярного рівняння та дві фононні гілки

Розкриємо детермінант 2х2 за правилом діагоналей:

```
(2 C - M_1 · omega²) · (2 C - M_2 · omega²) - C² · (1 + exp(-i k a)) · (1 + exp(i k a)) = 0
```

Обчислимо добуток експоненціальних дужок:

```
(1 + exp(-i k a)) · (1 + exp(i k a)) 
= 1 + exp(i k a) + exp(-i k a) + 1    [перемножили дужки]
= 2 + 2 cos(k a)                      [формула Ейлера: exp(ix) + exp(-ix) = 2 cos(x)]
= 2 (1 + cos(k a))                    [винесли 2 за дужки]
= 4 cos²(k a / 2)                     [формула половинного кута: 1 + cos(x) = 2 cos²(x/2)]
```

Підставимо отриманий вираз у рівняння детермінанта:

```
(2 C - M_1 · omega²) · (2 C - M_2 · omega²) - 4 C² cos²(k a / 2) = 0
= M_1 M_2 · omega⁴ - 2 C (M_1 + M_2) · omega² + 4 C² - 4 C² cos²(k a / 2)    [розкрили дужки]
= M_1 M_2 · omega⁴ - 2 C (M_1 + M_2) · omega² + 4 C² (1 - cos²(k a / 2))      [групування 4 C²]
```

Оскільки `1 - cos²(x) = sin²(x)`, отримуємо квадратне рівняння відносно змінної `z = omega²`:

```
M_1 M_2 · z² - 2 C (M_1 + M_2) · z + 4 C² sin²(k a / 2) = 0     [позначення z = omega²]
```

Знайдемо дискримінант квадратного рівняння:

```
D = 4 C² (M_1 + M_2)² - 16 M_1 M_2 C² sin²(k a / 2)             [формула D = b² - 4ac]
= 4 C² · [ (M_1 + M_2)² - 4 M_1 M_2 sin²(k a / 2) ]              [винесення 4 C²]
```

Розв'язки для `z = omega²`:

```
omega²(k) = [ 2 C (M_1 + M_2) ± sqrt(D) ] / (2 M_1 M_2)
= C · (1/M_1 + 1/M_2) ± C · sqrt( (1/M_1 + 1/M_2)² - 4 sin²(k a / 2) / (M_1 M_2) )
```

Наявність знака `±` означає існування двох фізично відмінних гілок коливань:
- Знак `−` визначає низькочастотну **акустичну гілку `omega_A(k)`**.
- Знак `+` визначає високочастотну **оптичну гілку `omega_O(k)`**.

## 5. Фізичні властивості мод та фазові співвідношення підґраток

Дослідиємо поведінку розв'язків та співвідношення амплітуд `u_0 / v_0` у ключових точках зони Бріллюена.

### А. Довгохвильова акустична мода (`k -> 0`, знак `−`)
При `k -> 0` синус малий `sin(k a / 2) approx k a / 2`. Розкладемо корінь у ряд за формулою `sqrt(1 - x) approx 1 - x / 2`:

```
sqrt( (1/M_1 + 1/M_2)² - 4 sin²(k a / 2) / (M_1 M_2) )
approx (1/M_1 + 1/M_2) · [ 1 - 2 sin²(k a / 2) / ( M_1 M_2 (1/M_1 + 1/M_2)² ) ]
```

Підставивши цей розклад у вираз для `omega_A²`:

```
omega_A²(k)
approx C · (1/M_1 + 1/M_2) - C · (1/M_1 + 1/M_2) + 2 C sin²(k a / 2) / (M_1 + M_2)    [підставили розклад кореня]
= (2 C / (M_1 + M_2)) · (k a / 2)²                                                       [скоротили однакові доданки та sin(x) ≈ x]
= C a² k² / (2 (M_1 + M_2))                                                              [піднесли до квадрата ka/2]
```

Звідси отримуємо лінійну дисперсію акустичних фононів:

```
omega_A(k) = v_s · |k|
```

де фазова та групова швидкість звуку в двоатомному кристалі дорівнює:

```
v_s = a · sqrt( C / (2 (M_1 + M_2)) )
```

Знайдемо співвідношення амплітуд підґраток `u_0` та `v_0` з першого рівняння алгебраїчної системи `(2 C - M_1 omega_A²) u_0 - 2 C v_0 = 0`. Оскільки `omega_A(0) = 0`:

```
2 C · u_0 - 2 C · v_0 = 0   =>   u_0 = v_0
```

*Фізичний висновок:* у разі акустичних фононів при `k -> 0` обидва атоми в елементарній комірці коливаються з однаковою амплітудою і в однаковій фазі (`u_0 = v_0`). Елементарна комірка зміщується як нероздільне ціле, створюючи звичайну пружну звукову хвилю.

### Б. Довгохвильова оптична мода (`k -> 0`, знак `+`)
При `k = 0` значення синуса дорівнює нулю `sin(0) = 0`, і квадратний корінь дає `(1/M_1 + 1/M_2)`:

```
omega_O²(0) = C · (1/M_1 + 1/M_2) + C · (1/M_1 + 1/M_2) = 2 C · (1/M_1 + 1/M_2)
```

Частота оптичної гілки в центрі зони є ненульовою і виражається через зведену масу `mu = (M_1 M_2) / (M_1 + M_2)`:

```
omega_O(0) = sqrt( 2 C · (M_1 + M_2) / (M_1 M_2) ) = sqrt( 2 C / mu )
```

Підставимо значення `omega_O²(0) = 2 C / mu` у перше рівняння системи:

```
[ 2 C - M_1 · (2 C (M_1 + M_2) / (M_1 M_2)) ] · u_0 = 2 C · v_0     [підставили omega_O²]
= [ 2 C - 2 C (M_1 + M_2) / M_2 ] · u_0 = 2 C · v_0                 [скоротили M_1]
= - (2 C M_1 / M_2) · u_0 = 2 C · v_0                               [звели до спільного знаменника]
```

Звідси отримуємо співвідношення амплітуд коливань підґраток:

```
M_1 · u_0 + M_2 · v_0 = 0   =>   v_0 / u_0 = - M_1 / M_2
```

*Фізичний висновок:* у разі оптичних фононів при `k -> 0` атоми `A` та `B` коливаються strictly у **протифазі** (`v_0` та `u_0` мають протилежні знаки), причому спільний центр мас комірки `M_1 u_0 + M_2 v_0` лишається строго нерухомим. Якщо атоми мають різнойменні заряди (наприклад, `Na⁺` та `Cl⁻`), таке протифазне коливання створює змінний макроскопічний дипольний момент, що взаємодіє з світловими електромагнітними хвилями.

## 6. Межа зони Бріллюена та заборонена смуга частот (Band Gap)

На кордоні першої зони Бріллюена `k = ± pi / a` маємо `sin(k a / 2) = sin(pi / 2) = 1`.

Тоді підкореневий вираз перетворюється на точний квадрат різниці:

```
(1/M_1 + 1/M_2)² - 4 / (M_1 M_2) = (1/M_1 - 1/M_2)²
```

Звідси для значень квадрата частоти на межі зони маємо:

```
omega²(pi/a) = C · (1/M_1 + 1/M_2) ± C · (1/M_1 - 1/M_2)
```

Припускаючи для конкретності `M_1 > M_2`:
- **Вершина акустичної гілки:** `omega_A(pi/a) = sqrt( 2 C / M_1 )`
- **Підошва оптичної гілки:** `omega_O(pi/a) = sqrt( 2 C / M_2 )`

Між цими двома граничними частотами утворюється **заборонена смуга частот (Band Gap)** шириною:

```
Delta omega = sqrt( 2 C / M_2 ) - sqrt( 2 C / M_1 )
```

У частотному діапазоні `[sqrt(2C/M_1), sqrt(2C/M_2)]` хвильовий вектор `k` є комплексним `k = k' + i k''`, і пружні коливання не можуть поширюватися крізь кристал, експоненціально загасаючи по глибині.

Якщо маси атомів однакові `M_1 = M_2 = M`, шириною забороненої смуги стає нуль `Delta omega = 0`, період комірки зменшується до `a / 2`, а межа зони Бріллюена зміщується до `2 pi / a`, перетворюючи оптичну гілку на згорнуту акустичну.

## 7. Аналітичне виведення густини фононних станів D(omega) у 1D

Для одновимірного одноатомного ланцюжка довжиною `L = N a` кількість дозволених станів у першій зоні Бріллюена дорівнює `N`. Оскільки `k = (2 pi / L) n`, інтервал між сусідніми модами дорівнює `Delta k = 2 pi / L`.

Густина станів у `k`-просторі є постійною: `dN / dk = L / (2 pi)`.
Враховуючи обидва напрямки хвильового вектора (`+k` та `-k`), повне число мод `D(omega) d omega = 2 · (dN / dk) · dk`.

Отже, густина фононних станів за частотою дорівнює:

```
D(omega) = ( L / pi ) · ( 1 / |d(omega) / dk| ) = ( L / pi ) · ( 1 / v_g(omega) )
```

Знайдемо групову швидкість `v_g` з закону дисперсії `omega(k) = omega_max sin(k a / 2)`:

```
v_g = d(omega) / dk = (a / 2) · omega_max · cos(k a / 2) = (a / 2) · sqrt( omega_max² - omega² )
```

Підставимо вираз для `v_g` у густину станів `D(omega)`:

```
D(omega) = ( 2 N / pi ) · ( 1 / sqrt( omega_max² - omega² ) )     при omega < omega_max
```

При `omega -> omega_max` знаменник прямує до нуля, і густина станів має корінову особливість `1 / sqrt(omega_max² - omega²)`. Це класична **особливість Ван Хова** в одновимірному просторі.

Для двоатомного ланцюжка аналітичний вираз густини станів `D(omega)` демонструє дві корінові особливості Ван Хова: одну на вершині акустичної гілки `omega = sqrt(2C/M_1)`, а другу на підошві оптичної гілки `omega = sqrt(2C/M_2)`. Між ними густина станів дорівнює нулю `D(omega) = 0`, що строго відповідає фононній забороненій смузі.

## 8. Тривимірна динаміка: тензор пружних констант та тензорне рівняння Крістоффеля

У тривимірному суцільному пружному середовищі з густиною `rho` довгохвильова пружна динаміка описується тензором пружних констант (модулів) `c_{i j k l}` у вираженні закону Гука:

```
sigma_{i j} = ∑_{k, l} c_{i j k l} · exp_{k l}
```

де `sigma_{i j}` — тензор напружень, `exp_{k l} = ½ (∂ u_k / ∂ x_l + ∂ u_l / ∂ x_k)` — тензор деформацій.

Диференціальне рівняння руху хвилі в 3D суцільному середовищі:

```
rho · d²u_i / dt² = ∑_{j, k, l} c_{i j k l} · ( ∂² u_k / (∂ x_j ∂ x_l) )
```

Підставляючи розв'язок плоского зсуву `u_i(r, t) = u_{0, i} exp(i (k · r - omega t))`, отримуємо тензорне рівняння Крістоффеля:

```
det | Γ_{i k}(n) - rho · v² · δ_{i k} | = 0
```

де `v = omega / k` — фазова швидкість звуку, `n = k / |k|` — орт напрямку поширення хвилі, а `Γ_{i k}(n) = ∑_{j, l} c_{i j k l} n_j n_l` — акустичний тензор Крістоффеля.

Для кубічного кристала (наприклад, Si, Ge, Cu) існує лише три незалежні пружні константи: `c₁₁` (поздовжній стиск), `c₁₂` (поперечне розширення) та `c₄₄` (чистий зсув).

Швидкості звуку вздовж головних кристалографічних напрямків:
- **Напрямок `[100]` (вздовж ребра куба):**
  - Поздовжня акустична мода (LA): `v_{LA} = sqrt( c₁₁ / rho )`
  - Дві вироджені поперечні моди (TA): `v_{TA} = sqrt( c₄₄ / rho )`
- **Напрямок `[110]` (вздовж діагоналі грані):**
  - Поздовжня мода (LA): `v_{LA} = sqrt( (c₁₁ + c₁₂ + 2 c₄₄) / (2 rho) )`
  - Поперечна мода з поляризацією `[001]`: `v_{TA,1} = sqrt( c₄₄ / rho )`
  - Поперечна мода з поляризацією `[1-10]`: `v_{TA,2} = sqrt( (c₁₁ - c₁₂) / (2 rho) )`

## 9. Акустичні моди двовимірних матеріалів (графен)

У двовимірних матеріалах (графен, монокристалічні шари TMD `MoS₂`) існує `3` акустичні фононні гілки, однак їхній функціональний хід суттєво відрізняється від 3D кристалів:
1. **Поздовжня акустична мода (LA):** зміщення в площині шару (`u_x, u_y || k`), закон дисперсії лінійний `omega_{LA} proportional to k`.
2. **Поперечна акустична мода (TA):** зміщення в площині шару перпендикулярно до імпульсу (`u_x, u_y ⊥ k`), закон дисперсії лінійний `omega_{TA} proportional to k`.
3. **Згинальна позаплощинна акустична мода (ZA / Flexural mode):** зміщення атомів перпендикулярно до двовимірної площини шару (`u_z ⊥ 2D plane`).

Внаслідок симетрії 2D мембрани при відсутності натягу опір згинанню пропорційний квадрату кривини шару. Це приводить до **квадратичного закону дисперсії згинальної ZA-моди**:

```
omega_{ZA}(k) = gamma · k²
```

де `gamma = sqrt( kappa_{flex} / rho_{2D} )` виражається через згинальну жорсткість мембрани `kappa_{flex}`.

Квадратична ZA-мода має аномально високу густину станів `D_{ZA}(omega) = const` при низьких частотах, що відіграє вирішальну роль у високій теплопровідності графену (до `5000` Вт/(м·К) при кімнатній температурі).

## 10. Асимптотичний аналіз інтеграла Дебая при `T -> 0` та `T -> infty`

Для отримання точного аналітичного закону куба Дебая `C_v proportional to T³` при низьких температурах (`T << Theta_D`) розглядається верхня межа безрозмірного інтеграла `y = Theta_D / T -> infty`:

```
I(infty) = ∫_0^infty x³ / (exp(x) - 1) dx
```

Розкладаючи підінтегральний вираз у геометричну прогресію `1 / (exp(x) - 1) = ∑_{n=1}^infty exp(-n x)`:

```
I(infty) = ∑_{n=1}^infty ∫_0^infty x³ · exp(-n x) dx
```

Застосовуючи заміну змінної `u = n x`, отримуємо `∫_0^infty (u/n)³ exp(-u) (du/n) = (1/n⁴) ∫_0^infty u³ exp(-u) du = 6 / n⁴`.

Звідси сума дорівнює:

```
I(infty) = 6 · ∑_{n=1}^infty (1 / n⁴) = 6 · zeta(4) = 6 · (pi⁴ / 90) = pi⁴ / 15
```

Підставляючи `I(infty) = pi⁴ / 15` у вираз для внутрішньої енергії Дебая `E(T) = 9 N k_B T (T/Theta_D)³ I(infty)`:

```
E(T) = ( 3 pi⁴ / 5 ) · N k_B T · ( T / Theta_D )³
```

Диференціюючи за температурою `C_v = dE / dT`:

```
C_v(T) = ( 12 pi⁴ / 5 ) · N k_B · ( T / Theta_D )³
```

Це дає точний чисельний коефіцієнт `12 pi⁴ / 5 approx 233.78` для квантового кубічного закону Дебая.

При високих температурах (`T >> Theta_D`) безрозмірна верхня межа інтегрування є малою `y = Theta_D / T << 1`.
Розкладаючи підінтегральний вираз в ряд Тейлора `1 / (exp(x) - 1) approx 1 / x - 1 / 2 + x / 12`:

```
I(y) = ∫_0^y x³ / (exp(x) - 1) dx approx ∫_0^y x² dx = y³ / 3 = (Theta_D / T)³ / 3
```

Підставляючи `I(y) = (Theta_D / T)³ / 3` у внутрішню енергію `E(T) = 9 N k_B T (T / Theta_D)³ · ( (Theta_D / T)³ / 3 ) = 3 N k_B T`.
Диференціювання за температурою `C_v = dE / dT = 3 N k_B = 3 R` строго відтворює класичний закон рівнорозподілу Дюлонга — Пті. Фізично це пояснюється тим, що при високих температурах квантова дискретність енергетичних рівнів `hbar omega` стає незначною порівняно з енергією теплового руху `k_B T`, і фононний газ поводиться як ансамбль класичних гармонічних осциляторів. Внесок енергії нульових коливань `(9/8) N hbar omega_D` залишається постійною добавкою до внутрішньої енергії і не змінює молярної теплоємності при зміні температури.

## 11. Полярні оптичні фонони та розщеплення LO-TO у 3D іонних кристалах

У 3D полярних кристалах (NaCl, GaAs, TiO₂) протифазне зміщення різнойменних іонів `w = u_1 - u_2` створює макроскопічний вектор поляризації `P`.

Макроскопічні рівняння електродинаміки суцільних середовищ пов'язують поляризацію `P` та електричне поле `E`:

```
P = N_v · Z* · w + epsilon_0 · (epsilon_inf - 1) · E
```

де `Z*` — ефективний заряд Борна, `N_v` — концентрація комірок, `epsilon_inf` — високочастотна діелектрична проникність.

Для поперечної оптичної моди (TO) вектор зміщення `w` перпендикулярний до хвильового вектора `k` (`w ⊥ k`). Оскільки `div P = 0`, макроскопічне електричне поле дорівнює нулю `E_TO = 0`. Частота TO-моди визначається лише пружними силами ґратки:

```
omega_TO² = 2 C / mu
```

Для поздовжньої оптичної моди (LO) вектор зміщення паралельний до хвильового вектора (`w || k`). Внаслідок цього `div P ≠ 0`, що згідно з рівнянням Максвелла `div D = 0` (де `D = epsilon_0 E + P`) генерує деполяризуюче електричне поле:

```
E_LO = - P / ( epsilon_0 · epsilon_inf )
```

Це поле створює додаткову електричну відновлювальну силу, що збільшує частоту LO-моди порівняно з TO-модою:

```
omega_LO² = omega_TO² + ( N_v · (Z*)² ) / ( mu · epsilon_0 · epsilon_inf )
```

Зіставляючи цей результат із формулою діелектричної проникності Лоренца `epsilon(omega) = epsilon_inf + (epsilon(0) - epsilon_inf) / (1 - omega² / omega_TO²)`, отримуємо фундаментальне **співвідношення Ліддейна — Сакса — Теллера (Lyddane-Sachs-Teller, LST)**:

```
omega_LO² / omega_TO² = epsilon(0) / epsilon(infty)
```

Оскільки статична проникність завжди перевищує високочастотну (`epsilon(0) > epsilon(infty)`), частота поздовжніх оптичних фононів `omega_LO` у полярних діелектриках завжди строго більша за частоту поперечних фононів `omega_TO`.
