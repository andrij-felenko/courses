# 🧮 Квантові стани, густість станів та фермієвська статична механіка 2DEG

Математичний апарат опису двовимірного електронного газу (2DEG) базується на розділенні змінних у тривимірному рівнянні Шредінгера при наявності анізотропного обмежувального потенціалу `V(z)`. Оскільки рух електронів уздовж площини гетероінтерфейсу є повністю вільним, а рух уздовж нормалі квантований, хвильові функції та енергетичний спектр розділяються на поздовжню та поперечну компоненти. Нижче подано строгі виведення енергетичного спектра квантованих підзон, східчастої двовимірної густості станів, рівня Фермі, ефективного скринінгу Кулонівської взаємодії та ємності рівнів Ландау в сильному перпендикулярному магнітному полі.

## 1. Квантування руху в потенціальній ямі та наближення Ейрі

Розглядаємо електростатичний потенціал інверсійного шару або гетероінтерфейсу `z = 0`. Рух носіїв уздовж площини `(x, y)` описується плоскими хвилями з планарними хвильовими векторами `(k_x, k_y)`, а рух уздовж осі `z` обмежений потужним електричним полем `F_s = -dV/dz`, створеним іонізованими донорами та накопиченим електронним зарядом.

У першому фізичному наближенні електричне поле `F_s` у межах вузької квантової ями вважається просторово однорідним. Це дає потенціальну яму трикутної форми:

```
V(z) = +∞,          при z < 0  (високий потенціальний бар'єр широкозонного напівпровідника)
V(z) = e · F_s · z,  при z ≥ 0  (однорідне електричне поле в приповерхневій області)
```

Стаціонарне одномірне рівняння Шредінгера для потенціалу `V(z)` із ефективною масою електрона `m*` вздовж осі `z` має вигляд:

```
[- (ħ² / (2·m*)) · (d²/dz²) + e · F_s · z] · ψ(z) = E_z · ψ(z)
```

Для розв'язання цього рівняння зручно ввести безрозмірну просторову змінну `ξ`, яка об'єднує координату `z` та енергію поперечного руху `E_z`:

```
ξ = (2 · m* · e · F_s / ħ²)¹/³ · [z - E_z / (e · F_s)]
```

Після підстановки цієї змінної одномірне рівняння Шредінгера зводиться до стандартного канонічного рівняння Ейрі:

```
(d²ψ / dξ²) - ξ · ψ = 0
```

Фізично прийнятним розв'язком, що задовольняє умову прагнення хвильової функції до нуля при `z → +∞` (у глибині напівпровідника), є функція Ейрі першого роду `Ai(ξ)`:

```
ψ_n(z) = C_n · Ai(ξ)
```

де `C_n` — нормувальний коефіцієнт. Гранична умова непроникності електрона на потенціальній стінці `ψ(0) = 0` вимагає, щоб при `z = 0` аргумент `ξ` збігався з `n`-ним нулем функції Ейрі `a_n` (найнижчі нулі: `a₁ ≈ -2.3381`, `a₂ ≈ -4.0879`, `a₃ ≈ -5.5206`):

```
ξ(0) = - (2 · m* · e · F_s / ħ²)¹/³ · (E_z / (e · F_s)) = a_n
```

Звідси виражаємо квантований спектр енергії поперечного руху `E_n`:

```
E_n = (ħ² / (2 · m*))¹/³ · [(3 · π · e · F_s / 2) · (n - 1/4)]²/³  [квазікласичне наближення ВКБ для нулів функції Ейрі]
```

Для квантової ями прямокутної форми з шириною `w` та нескінченно високими потенціальними стінками квантовані рівні підзон приймають квадратичну залежність від номера підзони `n`:

```
E_n = (ħ² · π² · n²) / (2 · m* · w²)
```

Повний енергетичний спектр двовимірного електрона складається з дискретної енергії квантування поперечного руху `E_n` та неперервної параболічної кінетичної енергії планарного руху у площині `(x, y)`:

```
E(k_x, k_y, n) = E_n + (ħ² / (2 · m*)) · (k_x² + k_y²)
```

## 2. Строге виведення двовимірної густості станів g₂D(E)

Нехай двовимірний електронний газ локалізований у площині зразка площею `S = L_x · L_y`. Застосування стандартних періодичних межових умов Борна — фон Кармана приводить до квантування дискретних значень планарних хвильових векторів `(k_x, k_y)`:

```
k_x = (2 · π / L_x) · n_x,   n_x ∈ ℤ
k_y = (2 · π / L_y) · n_y,   n_y ∈ ℤ
```

Площа, яку займає один дозволений квантовий стан у двовимірному `k`-просторі:

```
ΔA_k = (2 · π / L_x) · (2 · π / L_y) = 4 · π² / S
```

Загальна кількість квантових станів `N₂D(k)` всередині кола радіусом `k = √(k_x² + k_y²)` з урахуванням двократного спінового виродження `g_s = 2` та можливого долинового виродження `g_v` визначається як площа кола, поділена на площу одного стану:

```
N₂D(k) = g_s · g_v · (π · k² / ΔA_k)
       = 2 · g_v · (π · k² · S / (4 · π²))    [підстановка ΔA_k = 4·π²/S та g_s = 2]
       = (g_v · S · k²) / (2 · π)             [скорочення π та коефіцієнтів]
```

Переходимо від хвильового вектора `k` до енергії планарного руху `E - E_n = ħ² · k² / (2 · m*)`:

```
k² = (2 · m* / ħ²) · (E - E_n)
```

Підставляємо значення `k²` у вираз для кількості квантових станів `N₂D(E)` у межах однієї підзони `n`:

```
N₂D(E) = (g_v · S · m* / (π · ħ²)) · (E - E_n)
```

Диференціальна густість станів на одиницю площі зразка `g₂D(E) = (1 / S) · (dN₂D / dE)` обчислюється як похідна кількості станів за енергією:

```
g₂D(E) = d/dE [ (g_v · m* / (π · ħ²)) · (E - E_n) ]
       = (g_v · m*) / (π · ħ²)                            [диференціювання за E для E ≥ E_n]
```

Підсумовуючи внески від усіх квантованих поперечних підзон `n`, отримуємо загальну двовимірну густість станів як східчасту функцію Хевісайда `θ(x)`:

```
g₂D(E) = ((g_v · m*) / (π · ħ²)) · ∑_{n=0}^{∞} θ(E - E_n)
```

Для прямозонного напівпровідника `GaAs` із єдиним мінімумом зони провідності у центрі зони Бріллюена (`g_v = 1`) висота одного ступеня густості станів є фундаментальною матеріальною константою:

```
g₀ = m* / (π · ħ²)
```

## 3. Фермієвська статистика та рівень Фермі 2DEG

Повна концентрація двовимірного електронного газу `n_s` (кількість електронів на одиницю площі гетероінтерфейсу в `см⁻²` або `м⁻²`) визначається інтегруванням добутку двовимірної густості станів `g₂D(E)` на функцію розподілу Фермі — Дірака `f(E)`:

```
n_s = ∫_{E₀}^{∞} g₂D(E) · f(E) dE
```

При абсолютному нулі температур `T = 0 K` функція розподілу Фермі — Дірака є строгою східчастою функцією: `f(E) = 1` для `E ≤ E_F` та `f(E) = 0` для `E > E_F`. Якщо заповненою є лише найнижча квантова підзона (`E₀ < E_F < E₁`), інтеграл спрощується до обчислення площі прямокутника:

```
n_s = ∫_{E₀}^{E_F} (m* / (π · ħ²)) dE
    = (m* / (π · ħ²)) · (E_F - E₀)                [інтегрування константи g0 від E0 до E_F]
```

Це рівняння встановлює виключно пряму лінійну залежність між енергією Фермі `E_F` та площинною концентрацією носіїв `n_s`:

```
E_F - E₀ = (π · ħ² · n_s) / m*
```

Хвильовий вектор Фермі `k_F`, який визначає радіус кругової поверхні Фермі у двовимірному `k`-просторі, виражається безпосередньо через концентрацію електронів:

```
k_F = √(2 · π · n_s)
```

При скінченних температурах `T > 0 K` функція розподілу Фермі — Дірака розмиває графік заповнення. Інтеграл концентрації обчислюється аналітично:

```
n_s = (m* · k_B · T / (π · ħ²)) · ln[1 + exp((E_F - E₀) / (k_B · T))]
```

Виражаючи звідси енергію Фермі `E_F(T)` як функцію температури `T` та концентрації `n_s`, отримуємо:

```
E_F(T) = E₀ + k_B · T · ln[ exp((π · ħ² · n_s) / (m* · k_B · T)) - 1 ]
```

## 4. Двовимірне Томас-Фермі скринінг Кулонівського потенціалу

Коли у площину двовимірного електронного газу вноситься сторонній точковий електричний заряд `Q`, електрони провідності перерозподіляються, створюючи індуковану планарну густість заряду `δn_s(r)`. У наближенні Томас-Фермі цей перерозподіл викликає місцеву зміну електростатичного потенціалу `ϕ(r)`.

Фур'є-компонента екранованого Кулонівського потенціалу `ϕ(q)` у двовимірній системі має вигляд:

```
ϕ(q) = (2 · π · e) / [ ε · (q + q_TF) ]
```

де `q_TF` — двовимірний хвильовий вектор скринінгу Томас-Фермі, який описує ефективний радіус екранування Кулонівської взаємодії:

```
q_TF = (2 · π · e² / ε) · (dn_s / dE_F)
     = (2 · π · e² / ε) · (m* / (π · ħ²))     [підстановка похідної dn_s/dE_F = m*/(π·ħ²)]
     = (2 · m* · e²) / (ε · ħ²)               [скорочення π у чисельнику й знаменнику]
```

Цей результат є фундаментальним: на відміну від тривимірного напівпровідника, де хвильовий вектор скринінгу залежить від концентрації як `q_TF,3D ∝ (n_3D)¹/⁶`, у двовимірному електронному газі двовимірний параметр скринінгу `q_TF` **є повністю постійною величиною**, що залежить лише від ефективної маси `m*` та диелектричної проникності `ε`.

## 5. Квантування Ландау та виродження рівнів у магнітному полі

При прикладанні зовнішнього магнітного поля `B`, орієнтованого строго перпендикулярно до площини 2DEG, сила Лоренца закручує траєкторії планарного руху електронів у кола. Неперервний двовимірний спектр підзони квантується на дискретні рівні Ландау:

```
E_{N, s} = E₀ + ħ · ω_c · (N + 1/2) ± (1/2) · g* · μ_B · B
```

де `ω_c = e · B / m*` — циклотронна частота обертання, `g*` — ефективний g-фактор носіїв, `μ_B = e · ħ / (2 · m_0)` — магнетон Бора.

Усі квантові стани 2DEG із неперервного енергетичного інтервалу `ΔE = ħ · ω_c` стискаються у єдиний рівень Ландау. Кількість станів, що припадає на один рівень Ландау на одиницю площі зразка (просторова ємність або виродження рівня Ландау `n₀`), обчислюється як добуток двовимірної густості станів `g₂D` на енергетичну відстань між рівнями `ħ · ω_c`:

```
n₀ = g₂D(E) · ħ · ω_c
   = (m* / (π · ħ²)) · ħ · (e · B / m*)         [підстановка g2D = m*/(π·ħ²) та ω_c = e·B/m*]
   = (e · B) / (π · ħ)                          [скорочення m* та ħ]
   = (2 · e · B) / h                            [перехід від ħ = h/(2·π) до сталої Планка h]
   = 2 · (B / Φ₀)                               [вираження через квант магнітного потоку Φ0 = h/e]
```

З урахуванням того, що кожен спіновий подрівень містить `n₀,s = e · B / h` квантових станів, безрозмірний фактор заповнення рівнів Ландау `ν` визначається як відношення повної концентрації електронів 2DEG `n_s` до ємності одного спінового подрівня:

```
ν = n_s / (e · B / h) = (h · n_s) / (e · B)
```

Коли фактор заповнення набуває точного цілого значення `ν = 1, 2, 3, ...`, рівень Фермі `E_F` опиняється у спектральній щілині між сусідніми рівнями Ландау. У цьому стані поздовжній опір зразка дорівнює нулю `ρ_xx = 0`, а поперечний холлівський опір квантується з точністю `10⁻⁹`: `ρ_xy = h / (e² · ν)`.
