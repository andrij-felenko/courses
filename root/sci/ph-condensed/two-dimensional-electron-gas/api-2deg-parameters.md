# 📋 Довідник фізичних параметрів та матеріальних систем з 2DEG

Цей довідник містить систематизовані фізичні параметри, порівняльні таблиці матеріальних систем, фундаментальні математичні співвідношення та технологічні критерії вибору для двовимірного електронного газу (2DEG — *Two-Dimensional Electron Gas*) у напівпровідникових гетероструктурах, кріогенних MOSFET-транзисторах, оксидних інтерфейсах та атомарно-тонких 2D-матеріалах.

## 2. Детальний фізичний профіль та специфіка матеріальних систем

### А. Арсенід галію / Арсенід алюмінію-галію (`AlGaAs / GaAs`)
Система `AlGaAs / GaAs` являє собою еталонну класичну гетероструктуру з 2DEG. Завдяки майже ідеальному узгодженню постійних кристалічної ґратки між `GaAs` та `AlAs` (відносне неузгодження `Δa / a < 0.1%`), межа розділу практично позбавлена дислокацій та механічних напружень.

Головною перевагою системи є дуже мала ефективна маса електронів `m* = 0.067 m₀` у ізотропній `Γ`-долині зони провідності. Це забезпечує високу швидкість Фермі `v_F = ħ · k_F / m*` та велику циклотронну частоту `ω_c = e · B / m*`. Використання технології модуляційного допування з товстими спейсерними шарами (`d_spacer = 20 – 80 нм`) пригнічує кулонівське розсіювання на донорах, дозволяючи досягати рекордних у фізиці конденсованого стану значень рухливості `μ > 3.5 × 10⁷ см²/(В·с)` за температур нижче `1 K`. Довжина вільного пробігу електронів у таких структураз сягає сотень мікрометрів, що робить їх ідеальною платформою для метрології (квантовий ефект Холла) та фундаментальних досліджень дробового квантового ефекту Холла (FQHE).

### Б. Нітрид галію / Нітрид алюмінію-галію (`AlGaN / GaN`)
Система `AlGaN / GaN` суттєво відрізняється від класичних арсенідних гетероструктур тим, що формування двовимірного електронного газу відбувається **абсолютно без використання зовнішнього допування донорними домішками**.

У гексагональній кристалічній ґратці вюрциту уздовж напрямку `[0001]` існує потужна спонтанна поляризація `P_SP`. Крім того, через неузгодження параметрів ґратки між плівкою `AlGaN` та підкладкою `GaN` виникають механічні напруження, які створюють п'єзоелектричну поляризацію `P_PE`. Сумарний стрибок поляризаційного вектора `ΔP = P_SP + P_PE` на гетероінтерфейсі створює гігантську зв'язану поверхневу густість заряду `σ_pol ~ 10¹³ см⁻²`. Це викликає настільки стрімке вигинання зон, що утворюється двовимірний електронний газ із рекордне високою листовою концентрацією `n_s ≈ (0.8 – 1.5) × 10¹³ см⁻²`.

Попри відносно високу ефективну масу `m* ≈ 0.20 m₀` та помірну кріогенну рухливість `μ ≈ 25 000 см²/(В·с)`, GaN-гетероструктури володіють величезним пробійним електричним полем `E_br > 3 МВ/см` та високою критичною температурою роботи. Це робить `AlGaN/GaN` домінуючою матеріальною платформою для створення силових НВЧ-транзисторів (HEMT) у радіолокації, 5G базових станціях та електроприводах електромобілів.

### В. Кремнієві інверсійні шари (`Si / SiO₂` MOSFET)
У кремнієвих польових транзисторах 2DEG формується у тонкому інверсійному шарі під дією позитивної напруги затвора, прикладеної до межі `Si / SiO₂`. 

Кристал кремнію має багатодолинну зонну структуру з шістьма еквівалентними мінімумами зони провідності вздовж напрямків `<100>`. На поверхні `Si(100)` електростатичне обмежувальне поле знімає долинове виродження: дві долини з важкою поздовжньою масою `m_l* = 0.98 m₀`, орієнтованою перпендикулярно до межі, опускаються нижче за енергією, утворюючи основну квантову підзону. Рух у площині інверсійного шару описується легкою поперечною масою `m_t* = 0.19 m₀`.

Хоча рухливість електронів у Si-MOSFET обмежена величиною `μ ~ 40 000 см²/(В·с)` через атомарну шорсткість межі з аморфним `SiO₂`, кремнієві інверсійні шари є технологічною основою всієї сучасної обчислювальної мікроелектроніки (CMOS). Крім того, ізотопно очищений кремній `²⁸Si` із нульовим ядерним спіном забезпечує рекордні часи спінової декогеренції `T₂ > 1 с`, що робить 2DEG у Si-MOSFET та гетероструктурах `Si/SiGe` провідною платформою для напівпровідникових спінових кубітів.

### Г. Оксидні гетероінтерфейси (`LaAlO₃ / SrTiO₃`)
Формування двовимірного електронного газу на межі контакту двох прозорих диелектриків — титанату строцію `SrTiO₃` та алюмінату лантану `LaAlO₃` — стало одним із найбільш вражаючих відкриттів фізики конденсованого стану у 2004 році.

Фізичною причиною виникнення провідності є так звана "полярна катастрофа". Перовскітна структура `LaAlO₃` складається з чергованих полярних атомних площин `(LaO)⁺` та `(AlO₂)⁻` із зарядними імпульсами, тоді як `SrTiO₃` побудований з нейтральних площин `(SrO)⁰` та `(TiO₂)⁰`. Нарощування полярних шарів `LaAlO₃` понад критичну товщину в 4 моноклітини викликає нескінченне зростання електростатичного потенціалу. Для запобігання потенціальній катастрофі відбувається електронна реконструкція: пів-електрона перетікає з поверхні `LaAlO₃` на гетеромежу, утворюючи 2DEG у d-орбіталях титану `Ti³⁺` з концентрацією `n_s ~ 10¹³ см⁻²`.

Головною унікальною рисою оксидного 2DEG є співіснування двовимірної металевої провідності, сильної спін-орбітальної взаємодії Рашби та **двовимірної надпровідності** при температурах нижче `T_c ≈ 300 мК`, критичною температурою якої можна прецизійно управляти за допомогою зовнішньої напруги затвора.

## 3. Ключові співвідношення та формули параметрів 2DEG

### А. Геометричні та спектральні величини в площині `(x, y)`

- **Хвильовий вектор Фермі `k_F`:**
  ```
  k_F = √(2 · π · n_s) ≈ 2.5066 × 10³ · √(n_s [см⁻²])   (см⁻¹)
  ```

- **Довжина хвилі Фермі `λ_F`:**
  ```
  λ_F = 2 · π / k_F = √(2 · π / n_s)
  ```

- **Енергія Фермі `E_F` відносно дна підзони `E₀`:**
  ```
  E_F - E₀ = (π · ħ² · n_s) / m* = (ħ² · k_F²) / (2 · m*)
  ```
  *Чисельне правило для `GaAs` (`m* = 0.067 m₀`):*
  `E_F - E₀ [меВ] ≈ 3.58 × (n_s / 10¹¹ см⁻²)`.

- **Повноцінна двовимірна густість станів `g₀` (на підзону):**
  ```
  g₀ = m* / (π · ħ²) ≈ 4.18 × 10¹⁰ · (m* / m₀)   (еВ⁻¹ · см⁻²)
  ```
  *Для `GaAs` (`m* = 0.067 m₀`):* `g₀ ≈ 2.80 × 10⁹ еВ⁻¹ · см⁻²`.

### Б. Транспортні параметри та час релаксації імпульсу

- **Двовимірна питома провідність Друде `σ_xx`:**
  ```
  σ_xx = e · n_s · μ = (e² · n_s · τ_p) / m*
  ```

- **Час релаксації імпульсу `τ_p` (транспортний час):**
  ```
  τ_p = (m* · μ) / e
  ```
  *Приклад для `GaAs` з `μ = 10⁷ см²/(В·с)`:* `τ_p ≈ 3.81 × 10⁻¹₀ с = 381 пс`.

- **Одночастинковий квантовий час життя `τ_q` (ширина рівня Ландау `Γ = ħ / (2·τ_q)`):**
  Визначається з аналізу амплітуди осциляцій Шубникова — де Гааза (графік Дінґла). Відношення `τ_p / τ_q`:
  - `τ_p / τ_q ≈ 1` — переважає малокутове розсіювання на короткодіючих точкових дефектах.
  - `τ_p / τ_q ≫ 10 – 100` — переважає великокутове малоінтенсивне розсіювання на віддалених іонізованих донорах (за домінування спейсера).

- **Довжина вільного пробігу електрона `l_m`:**
  ```
  l_m = v_F · τ_p = (ħ · k_F / m*) · ((m* · μ) / e) = (ħ · k_F · μ) / e
  ```

- **Циклотронна частота `ω_c`:**
  ```
  ω_c = (e · B) / m* ≈ 1.7588 × 10¹¹ · (m₀ / m*) · B [Тл]   (рад/с)
  ```
  *Для `GaAs` (`m* = 0.067 m₀`) при `B = 1 Тл`:* `ħ · ω_c ≈ 1.73 меВ`.

## 4. Температурні діапазони та картування механізмів розсіювання

Обмеження рухливості `μ(T)` у двовимірному електронному газі описується правилом Матіссена:

```
1 / μ_total = 1 / μ_IMP + 1 / μ_PE + 1 / μ_DP + 1 / μ_LO
```

1. **Кріогенна область (`T < 4.2 K`):** Рухливість повністю лімітується розсіюванням на іонізованих донорах `μ_IMP` та атомарній шорсткості межі розділу. При використанні спейсерів завтовшки `d > 20 нм` рухливість виходить на насичений платоподібний рівень і не залежить від температури.
2. **Проміжна область (`4.2 K < T < 80 K`):** Головну роль відіграють акустичні фонони через деформаційний потенціал `μ_DP ∝ T⁻¹` та п'єзоелектричну взаємодію `μ_PE ∝ T⁻¹/²`.
3. **Високотемпературна область (`T > 100 K`):** Рухливість стрімко падає за експоненційним законом через поглинання та випромінювання полярних оптичних фононів `μ_LO ∝ exp(ħ·ω_LO / (k_B · T)) - 1`. Для `GaAs` енергія оптичного фонона становить `ħ·ω_LO = 36.1 меВ` (`T_LO ≈ 418 K`), що обмежує рухливість при кімнатній температурі величиною `μ_300K ≈ 8500 см²/(В·с)`.

## 5. Практичні рекомендації з вибору системи з 2DEG

- **Якщо потрібна максимальна квантова чистота та балістичний транспорт:** Обирайте **`AlGaAs / GaAs`** з товстим спейсером (`d = 30 нм`). Це єдиний вибір для дослідження дробового ефекту Холла, квантових дротів та інтерферометрів Фабрі — Перо.
- **Якщо потрібна висока вихідна потужність та силова електроніка:** Обирайте **`AlGaN / GaN`**. Величезна густість електронів `10¹³ см⁻²` без допування та пробійне поле `3 МВ/см` роблять цю систему домінуючою у НВЧ-транзисторах.
- **Якщо потрібна надпровідність, що регулюється затвором:** Обирайте **`LaAlO₃ / SrTiO₃`**.
