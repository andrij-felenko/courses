# 📋 Довідник методів дифрактометрії: Лауе, обертовий кристал та дебаєграми

Цей довідник містить систематизовані технічні параметри, експериментальні геометрії, спектральні характеристики джерел рентгенівського випромінювання, алгоритми обробки профілів дифракційних піків та формули розрахунку міжплощинних відстаней для основних методів кристалографічної дифрактометрії (Лауе, обертового кристала, Дебая — Шеррера та Бреґґа — Брентано). Читач відкрив цю вставку з практичною метою: щоб швидко підібрати довжину хвилі джерела та геометрію експерименту під конкретний фізичний стан зразка (монокристал, полікристалічний порошок чи тонка плівка), а також розрахувати міжплощинні відстані `d(h,k,l)` та індекси Міллера для будь-якої з семи сингоній без виведення рівнянь з нуля.

## 1. Фізичні основи та спектральні характеристики лабораторних анодів

У лабораторних дифрактометрах джерелом рентгенівських променів слугує рентгенівська трубка (РТ) із металевим анодом. При прискоренні електронів високою напругою (від 30 до 60 кВ) вони бомбардують поверхню анода. При цьому відбуваються два незалежні фізичні процеси:
1. **Гальмівне випромінювання (біле світло)**: Виникає внаслідок резкого гальмування електронів у кулонівському полі ядер анода. Воно має неперервний спектр із чіткою короткохвильовою межею `λ_min = h · c / (e · V)`.
2. **Характеристичне випромінювання**: Виникає при вибиванні електронів прискореними снарядами з внутрішніх електронних оболонок атомів анода (передесім `K`-оболонки) з подальшим заповненням вакансій електронами з вищих рівнів (`L`- та `M`-оболонок).

Перехід електрона з `L`-оболонки на `K`-оболонку дає характеристичний дуплет `Kα₁` та `Kα₂`, а перехід із `M`-оболонки — лінію `Kβ`. Оскільки `Kα₁` відповідає переходу з підрівня `L₃` (із більшим статистичним ваговим коефіцієнтом), інтенсивність лінії `Kα₁` у два рази перевищує інтенсивність лінії `Kα₂` (`I(Kα₁) : I(Kα₂) = 2 : 1`).

| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |

| **Fe** (Залізо) | 26 | 0.19360 | 0.19399 | 0.19373 | 0.17566 | 35–45 | Mn (Марганець) |
| **Co** (Кобальт) | 27 | 0.17889 | 0.17928 | 0.17902 | 0.16208 | 35–45 | Fe (Залізо) |
| **Cu** (Мідь) | 29 | 0.15406 | 0.15444 | 0.15418 | 0.13922 | 40–50 | Ni (Нікель) |

### Метод виділення монохроматичного випромінювання:
- **Селективні Kβ-фільтри**: Використовують тонку металеву фольгу з елемента із атомним номером `Z - 1` або `Z - 2` відносно матеріалу анода. Край `K`-поглинання фільтра розташовується точно між лініями `Kα` та `Kβ` анода, що дозволяє послабити `Kβ`-лінію у десятки разів при збереженні прозорості для `Kα`.
- **Кристал-монохроматори**: Використовують вигнуті або плоскі монокристали германію `Ge(111)`, кремнію `Si(111)` чи високоорієнтованого піролітичного графіту (HOPG). Налаштування монохроматора на бреґґівський кут відображення `Ge(111)` дозволяє повністю відфільтрувати лінію `Kα₂` і працювати виключно з чистою монохроматичною лінією `Kα₁`.

## 2. Порівняльний аналіз експериментальних методів дифрактометрії

Залежно від фізичного стану об'єкта (монокристал, полікристалічний порошок, тонка плівка) та поставленої наукової задачі застосовують різні геометрії експерименту.

### 1. Метод Лауе (поліхроматичне випромінювання на монокристалі)
Нерухомий монокристал опромінюється неперервним (білим) рентгенівським пучком.
- **Геометрія на проходження (напружений Лауе)**: Плівка або плоскопаралельний детектор розташовується позаду кристала. Метод застосовують для тонких зразків із слабким поглинанням.
- **Геометрія на відбивання (зворотний Лауе)**: Плівка розміщується між рентгенівською трубкою та кристалом (пучок проходить крізь отвір у плівці). Використовується для товстих непрозорих монокристалів.
- **Індексація**: Плями на лауеграмі розташовуються уздовж еліпсів або гіпербол (зонових осей). Метод не дозволяє безпосередньо розрахувати абсолютні періоди ґратки, але за симетрією розташування плям миттєво визначають кристалографічний клас, точкову групу та орієнтацію осей монокристала з точністю до кількох мінут.

### 2. Метод обертового кристала
Монокристал закріплюють у гоніометричній головці та обертають із постійною кутовою швидкістю навколо певної кристалографічної осі у монохроматичному пучку `λ₀`.
- **Формування шарових ліній**: Розсіяні промені утворюють сімейство співвісних конусів. При перетині циліндричної фотоплівки вони утворюють паралельні горизонтальні шарові лінії.
- **Розрахунок періоду ґратки**: Відстань `y_n` між `n`-ю шаровою лінією та екваторіальною лінією на розгорнутій плівці радіуса `R` дає період ґратки `I` уздовж осі обертання:
  `I = (n · λ) / sin(arctan(y_n / R))`

### 3. Порошковий метод Дебая — Шеррера
Дрібноподрібнений полікристалічний порошок розміщується у капілярі або на плоскій підкладці. Мільйони хаотично орієнтованих мікрокристалітів утворюють неперервний ансамбль орієнтацій.
- **Дифракційні конуси**: Для кожного дозволеного сімейства площин `(h, k, l)` з міжплощинною відстанню `d` випромінювання розсіюється під кутом `2θ`. Оскільки кристал орієнтований хаотично за азимутальним кутом, розсіяні промені формують конус із кутом при вершині `4θ`.
- **Дебаєграма**: На фотоплівці чи 2D-детекторі конуси залишають концентричні кільця. Положення кілець задає бреґґівські кути `θ`, а їхня відносна почорнілість — інтенсивність `I(h,k,l)`.

### 4. Дифрактометрія Бреґґа — Брентано (порошкова фокусуюча геометрія `θ - 2θ`)
Найпоширеніша лабораторна геометрія для плоских порошкових зразків та тонких плівок.
- **Принцип фокусування**: Джерело рентгенівських променів, поверхня плоского зразка та вхідна щілина детектора розташовуються на одному колі фокусування радіуса `R_f`.
- **Синхронний рух**: Зразок обертається з кутовою швидкістю `ω`, а детектор — з подвійною кутовою швидкістю `2ω`. Це забезпечує постійне виконання умови симетрії, при якій кут падіння дорівнює куту відбивання.

| Параметр порівняння | Метод Лауе | Метод обертового кристала | Метод Дебая — Шеррера | Дифрактометрія Бреґґа — Брентано |
| :--- | :--- | :--- | :--- | :--- |
| **Об'єкт дослідження** | Монокристал | Монокристал | Порошок / полікристал | Порошок / тонка плівка |
| **Спектр випромінювання** | Поліхроматичний (білий) | Монохроматичний | Монохроматичний | Монохроматичний |
| **Рух зразка** | Нерухомий | Обертання навколо осі | Обертання капіляра | Синхронне обертання `θ - 2θ` |
| **Тип детектора** | 2D плоскопаралельний | 2D циліндричний | 2D кільцевий / плівка | 1D лінійний / 0D точковий |
| **Основна інформація** | Симетрія та орієнтація | Осі ґратки, точкова група | Фазовий склад, періоди | Повний якісний і кількісний аналіз |

## 3. Математичний апарат індексації та міжплощинні відстані d(h,k,l)

Аналітична індексація дифракційного спектра полягає у співвіднесенні виміряних бреґґівських кутів `θ` із трійками цілих індексів Міллера `(h, k, l)`. Для кожної з семи кристалографічних сингоній міжплощинна відстань `d` пов'язана з параметрами елементарної комірки `a, b, c` та кутами `α, β, γ` відповідними квадратичними формами.

### 1. Кубічна сингонія (`a = b = c`, `α = β = γ = 90°`):
```
1 / d² = (h² + k² + l²) / a²
```
Для кубічних кристалів квадрати бреґґівських синусів знаходяться у відношенні цілих чисел:
`sin² θ_{(hkl)} = (λ² / (4 a²)) · (h² + k² + l²)`

### 2. Тетрагональна сингонія (`a = b ≠ c`, `α = β = γ = 90°`):
```
1 / d² = (h² + k²) / a² + l² / c²
```

### 3. Гексагональна сингонія (`a = b ≠ c`, `α = β = 90°`, `γ = 120°`):
```
1 / d² = (4/3) · (h² + h·k + k²) / a² + l² / c²
```

### 4. Ромбоедрична (тригональна) сингонія (`a = b = c`, `α = β = γ ≠ 90°`):
```
1 / d² = ((h² + k² + l²)·sin² α + 2(hk + kl + hl)·(cos² α - cos α)) / (a² · (1 - 3 cos² α + 2 cos³ α))
```

### 5. Орторомбічна сингонія (`a ≠ b ≠ c`, `α = β = γ = 90°`):
```
1 / d² = h² / a² + k² / b² + l² / c²
```

### 6. Моноклінна сингонія (`a ≠ b ≠ c`, `α = γ = 90°`, `β ≠ 90°`):
```
1 / d² = (1 / sin² β) · (h² / a² + (k² · sin² β) / b² + l² / c² - (2 h l cos β) / (a c))
```

### 7. Триклінна сингонія (`a ≠ b ≠ c`, `α ≠ β ≠ γ ≠ 90°`):
Загальна формула використовує детермінант метричного тензора кристала `V²` (де `V` — об'єм елементарної комірки):
```
1 / d² = (1 / V²) · (S₁₁ h² + S₂₂ k² + S₃₃ l² + 2 S₁₂ h k + 2 S₂₃ k l + 2 S₁₃ h l)
```

## 4. Фізичний профіль піка та аналіз розширення (Метод Вільямсона — Голла)

У реальних матеріалах дифракційний пік не є нескінченно вузькою лінією. Його профіль описується математичними функціями розподлу Гаусса, Лоренца або комбінованим профілем Псевдо-Войгта (англ. *Pseudo-Voigt function*):

```
I(2θ) = η · L(2θ) + (1 - η) · G(2θ)
```

де `η` — коефіцієнт змішування Лоренціана та Гауссіана (`0 ≤ η ≤ 1`).

Ширина дифракційного максимуму на піввисоті `β_total` (FWHM, радіани) обумовлена трьома незалежними фізичними факторами:
1. **Приладове розширення (`β_inst`)**: Неідеальність коліматорів, скінченна ширина щілин та розмір плями рентгенівської трубки.
2. **Розмірний ефект кристалітів (`β_size`)**: Обмежений розмір областей когерентного розсіювання `L` (формула Шеррера):
   `β_size = (K · λ) / (L · cos θ)`
3. **Мікронапруження ґратки (`β_strain`)**: Наявність локальних деформацій `ε = Δd / d`, спричинених дислокаціями, вакансіями або точковими дефектами:
   `β_strain = 4 · ε · tan θ`

### Метод розділення внесків Вільямсона — Голла (Williamson-Hall Plot):
Сумарне фізичне уширення піка `β_struct` (очищене від приладового внеску `β_inst`) обчислюється як:
`β_struct = √(β_obs² - β_inst²)`

Загальне рівняння Вільямсона — Голла записується у вигляді:

```
β_struct · cos θ = (K · λ) / L + 4 · ε · sin θ
```

Побудова графіка у координатах `Y = β_struct · cos θ` від `X = 4 · sin θ`:
- **Точка перетину графіком осі Y** (`X = 0`) дорівнює `(K · λ) / L`, що дозволяє точно визначити середній розмір кристалітів `L`.
- **Тангенс кута нахилу прямої** дорівнює величині мікронапружень `ε`.

Це робить дифрактометрію Бреґґа потужним інструментом для контролю нанодисперсност та внутрішніх деформацій у наноматеріалах та термооброблених сплавах.
