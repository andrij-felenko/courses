# ⚙️ Симуляція дифракційної картини та геометричного структурного фактора

Ця практична вставка містить розбір обчислювального проєкту із симуляції рентгенівської дифракції та повнофункціональну програмну реалізацію мовами C і C++ для автоматизованого розрахунку бреґґівських кутів `2θ`, геометричних структурних факторів `S(h,k,l)` та інтенсивностей дифракційних піків. Читач відкрив цей розділ із практичною метою: щоб самостійно реалізувати програму моделювання дифракційного спектра за априорною атомною моделлю кристала, навчитися чисельно перевіряти перетин сфери Евальда, розраховувати згасання рефлексів та враховувати атомні формфактори розсіювання без проведення коштовних лабораторних вимірювань.

Обчислювальне моделювання рентгенівської дифракції є ключовим інструментом сучасної комп'ютерної кристалографії, матеріалознавства та фазового аналізу. Воно дозволяє за априорною атомною моделлю кристала розрахувати теоретичний спектр дифракційних піків, визначити бреґґівські кути `2θ`, їхні відносні інтенсивності, а також ідентифікувати систематичні згасання рефлексів для простої кубічної (SC), об'ємноцентрованої (BCC), гранецентрованої (FCC) ґраток та структури алмазу.

---

## 1. Фізична та обчислювальна модель симулятора

Симуляційний модуль виконує чисельний розрахунок дифракційного спектра для трьох фундаментальних кубічних ґраток Браве (простої кубічної SC, об'ємноцентрованої BCC, гранецентрованої FCC), а також для складної двоатомної ґратки алмазу (Diamond structure).

### Послідовний алгоритм обчислювального конвеєра:

1. **Генерація векторів індексів Міллера `(h, k, l)`**:
   Програма будує дискретну тривимірну сітку індексів `h, k, l` у заданій області оберненого простору `0 ≤ h, k, l ≤ N_max`. Нульовий вектор `(0, 0, 0)` відкидається на першому кроці, оскільки він відповідає нерозсіяному прямому пучку, який проходить крізь зразок без зміни напрямку.

2. **Обчислення міжплощинної відстані `d_{hkl}`**:
   Для кубічної сингонії із параметром елементарної комірки `a` міжплощинна відстань обчислюється як довжина вектора, перпендикулярного до даного сімейства площин:
   `d_{hkl} = a / √(h² + k² + l²)`

3. **Перевірка бреґґівського критерію перетину сфери Евальда**:
   За законом Бреґґа `2d sin θ = λ` синус кута дифракції обчислюється як:
   `sin θ = λ / (2 · d_{hkl})`
   Якщо для даної трійки індексів отримане значення `sin θ > 1.0`, відповідний вузол оберненої ґратки лежить за межами сфери Евальда радіуса `R = 2π / λ`. Такий рефлекс є фізично неможливим при даній довжині хвилі падаючого випромінювання і виключається з розрахунку.

4. **Обчислення комплексного геометричного структурного фактора `S(h,k,l)`**:
   Структурний фактор враховує фазове додавання вторинних хвиль, розсіяних усіма атомами в межах однієї елементарної комірки в позиціях `(x_j, y_j, z_j)`:
   `S(h,k,l) = ∑_{j=1}^{M} exp(-2π i · (h·x_j + k·y_j + l·z_j))`
   - Для **SC**: Базис містить 1 атом `(0,0,0)`. `S = 1` (усі рефлекси дозволені).
   - Для **BCC**: Базис містить 2 атоми `(0,0,0)` та `(1/2, 1/2, 1/2)`. `S = 1 + (-1)^(h+k+l)`. Рефлекс існує лише при парній сумі індексів `(h + k + l)`.
   - Для **FCC**: Базис містить 4 атоми `(0,0,0)`, `(1/2, 1/2, 0)`, `(1/2, 0, 1/2)`, `(0, 1/2, 1/2)`. `S = 1 + (-1)^(h+k) + (-1)^(h+l) + (-1)^(k+l)`. Рефлекс існує лише тоді, коли індекси `h, k, l` мають незмішану парність.
   - Для **Diamond**: Структура складається з двох вкладених FCC ґраток зі зсувом `(1/4, 1/4, 1/4)`. `S = S_fcc · (1 + exp(-i (π/2) · (h + k + l)))`.

5. **Обчислення відносної інтенсивності `I_{hkl}`**:
   Інтенсивність розсіяного променя пропорційна квадрату модуля структурного фактора:
   `I_{hkl} ∝ |S(h,k,l)|²`

6. **Сортування за кутом `2θ` та формування спектра**:
   Усі знайдені дифракційні піки сортуються за зростанням бреґґівського кута `2θ`, що дозволяє згенерувати ідеальну теоретичну дебаєграму або лінійчасту дифрактограму.

## 2. Аналітична апроксимація атомного фактора розсіювання f(q)

У спрощеній моделі геометрії структурного фактора вважається, що всі атоми є точковими джерелами. Проте в реальності рентгенівські промені розсіюються розмитою електронною хмарою атома. Атомний фактор розсіювання `f(q)` зменшується зі зростанням кута розсіювання `θ`, оскільки хвилі, розсіяні протилежними краями електронної хмари одного й того самого атома, зазнають часткової деструктивної інтерференції.

У міжнародних кристалографічних таблицях (International Tables for Crystallography) атомний формфактор длякожного хімічного елемента апроксимується сумою чотирьох гауссових експонент та константи (апроксимація Вайтенштейна — Крамбса):

```
f(s) = ∑_{i=1}^{4} a_i · exp(-b_i · s²) + c
```

де `s = sin θ / λ = 1 / (2 d)` (вимірюється в нм⁻¹ або Å⁻¹), а `a_i, b_i, c` — табульовані коефіцієнти для кожного атомного номера `Z`.

При `s = 0` (падіння уздовж прямого променя `θ = 0`):
`f(0) = a₁ + a₂ + a₃ + a₄ + c = Z`

Врахування аналітичної функції `f(s)` дозволяє обчислювати не лише відносні геометричні погасання, а й точні співвідношення інтенсивностей між низькокутовими та висококутовими дифракційними піками.

## 3. Вплив просторових груп симетрії та елементів ковзання

У складніших кристалічних структурах (тетрагональних, орторомбічних, моноклінних) крім трансляцій Браве наявні несиморфні елементи симетрії:
- **Гвинтові осі симетрії (`2_1, 3_1, 4_1, 6_3`)**: Поєднують поворот навколо осі з трансляцією на дробову частку вектора ґратки. Вони спричиняють систематичні згасання осевих рефлексів `(h00), (0k0), (00l)`.
- **Площини ковзного відображення (`a, b, c, d, n`)**: Поєднують дзеркальне відображення у площині з трансляцією уздовж цієї площини. Вони викликають погасання двовимірних зонових рефлексів `(0kl), (h0l), (hk0)`.

Для автоматизованої обробки складних кристалографічних структур симуляційний модуль перебирає координати усіх атомів асиметричної одиниці `(x_j, y_j, z_j)` та діє на них матрицями операторів симетрії просторової групи `R_k · r + t_k`, де `R_k` — матриця повороту, а `t_k` — вектор трансляції.

```c
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

#ifndef M_PI
#define M_PI 3.14159265358979323846
#endif

typedef enum {
    LATTICE_SC,
    LATTICE_BCC,
    LATTICE_FCC,
    LATTICE_DIAMOND
} LatticeType;

typedef struct {
    int h, k, l;
    double d_spacing;
    double theta_deg;
    double two_theta_deg;
    double intensity;
} PeakInfo;

// Аналітичний розрахунок квадрата структурного фактора |S(h,k,l)|^2
double get_structure_factor_square(LatticeType type, int h, int k, int l) {
    int sum = h + k + l;
    int h_even = (h % 2 == 0);
    int k_even = (k % 2 == 0);
    int l_even = (l % 2 == 0);

    switch (type) {
        case LATTICE_SC:
            return 1.0;

        case LATTICE_BCC:
            return (sum % 2 == 0) ? 4.0 : 0.0;

        case LATTICE_FCC:
            if ((h_even == k_even) && (k_even == l_even)) {
                return 16.0;
            }
            return 0.0;

        case LATTICE_DIAMOND:
            if ((h_even == k_even) && (k_even == l_even)) {
                if (h_even) {
                    return (sum % 4 == 0) ? 64.0 : 0.0;
                } else {
                    return 32.0;
                }
            }
            return 0.0;

        default:
            return 0.0;
    }
}

// Компаратор для сортування піків за кутом 2*theta
int compare_peaks(const void *a, const void *b) {
    const PeakInfo *p1 = (const PeakInfo *)a;
    const PeakInfo *p2 = (const PeakInfo *)b;
    if (p1->two_theta_deg < p2->two_theta_deg) return -1;
    if (p1->two_theta_deg > p2->two_theta_deg) return 1;
    return 0;
}

void run_diffraction_simulation(LatticeType lattice, double a_nm, double lambda_nm, int max_hkl) {
    PeakInfo peaks[256];
    int count = 0;

    for (int h = 0; h <= max_hkl; ++h) {
        for (int k = 0; k <= max_hkl; ++k) {
            for (int l = 0; l <= max_hkl; ++l) {
                if (h == 0 && k == 0 && l == 0) continue;

                double s_sq = get_structure_factor_square(lattice, h, k, l);
                if (s_sq <= 0.001) continue; // Систематичне згасання

                double hkl_sq = (double)(h * h + k * k + l * l);
                double d = a_nm / sqrt(hkl_sq);
                double sin_t = lambda_nm / (2.0 * d);

                if (sin_t <= 1.0) {
                    double t_rad = asin(sin_t);
                    double t_deg = t_rad * (180.0 / M_PI);

                    peaks[count].h = h;
                    peaks[count].k = k;
                    peaks[count].l = l;
                    peaks[count].d_spacing = d;
                    peaks[count].theta_deg = t_deg;
                    peaks[count].two_theta_deg = 2.0 * t_deg;
                    peaks[count].intensity = s_sq;
                    count++;
                }
            }
        }
    }

    qsort(peaks, count, sizeof(PeakInfo), compare_peaks);

    printf("=========================================================================\n");
    printf("СИМУЛЯЦІЯ ДИФРАКЦІЇ (параметр a = %.4f нм, lambda = %.4f нм)\n", a_nm, lambda_nm);
    printf("=========================================================================\n");
    printf("  (h k l)  |  d (нм)   |  theta (deg) | 2*theta (deg) | Інтенсивність\n");
    printf("-------------------------------------------------------------------------\n");
    for (int i = 0; i < count; ++i) {
        printf("  (%d %d %d)  |  %8.4f  |  %11.2f | %13.2f | %12.1f\n",
               peaks[i].h, peaks[i].k, peaks[i].l,
               peaks[i].d_spacing, peaks[i].theta_deg,
               peaks[i].two_theta_deg, peaks[i].intensity);
    }
    printf("-------------------------------------------------------------------------\n");
    printf(" Дозволених піків у спектрі: %d\n\n", count);
}

int main(void) {
    double a_si = 0.5431;    // Параметр ґратки кремнію Si (нм)
    double lambda_cu = 0.15406; // Cu K-alpha1 (нм)

    printf("--- РЕЗУЛЬТАТ ДЛЯ КРЕМНІЮ (Si, Структура Алмазу) ---\n");
    run_diffraction_simulation(LATTICE_DIAMOND, a_si, lambda_cu, 4);

    printf("--- РЕЗУЛЬТАТ ДЛЯ МІДІ (Cu, FCC ґратка) ---\n");
    run_diffraction_simulation(LATTICE_FCC, 0.3615, lambda_cu, 3);

    return 0;
}
```

```cpp
#include <iostream>
#include <vector>
#include <cmath>
#include <numbers>
#include <iomanip>
#include <algorithm>
#include <string_view>

enum class CrystalLattice {
    SimpleCubic,
    BodyCenteredCubic,
    FaceCenteredCubic,
    Diamond
};

struct DiffractionReflection {
    int h{0};
    int k{0};
    int l{0};
    double interplanar_d_nm{0.0};
    double bragg_theta_deg{0.0};
    double two_theta_deg{0.0};
    double relative_intensity{0.0};
};

class DiffractionEngine {
public:
    [[nodiscard]] static constexpr double calculate_structure_factor_sq(
        CrystalLattice lattice, int h, int k, int l) noexcept {
        const int sum = h + k + l;
        const bool even_h = (h % 2 == 0);
        const bool even_k = (k % 2 == 0);
        const bool even_l = (l % 2 == 0);
        const bool same_parity = (even_h == even_k) && (even_k == even_l);

        switch (lattice) {
            case CrystalLattice::SimpleCubic:
                return 1.0;

            case CrystalLattice::BodyCenteredCubic:
                return (sum % 2 == 0) ? 4.0 : 0.0;

            case CrystalLattice::FaceCenteredCubic:
                return same_parity ? 16.0 : 0.0;

            case CrystalLattice::Diamond:
                if (!same_parity) return 0.0;
                if (!even_h) return 32.0; // Усі індекси непарні
                return (sum % 4 == 0) ? 64.0 : 0.0; // Парні індекси, сума 4n
        }
        return 0.0;
    }

    [[nodiscard]] static std::vector<DiffractionReflection> compute_spectrum(
        CrystalLattice lattice,
        double lattice_parameter_a_nm,
        double wavelength_lambda_nm,
        int max_hkl_index = 4) {

        std::vector<DiffractionReflection> reflections;

        for (int h = 0; h <= max_hkl_index; ++h) {
            for (int k = 0; k <= max_hkl_index; ++k) {
                for (int l = 0; l <= max_hkl_index; ++l) {
                    if (h == 0 && k == 0 && l == 0) continue;

                    const double intensity = calculate_structure_factor_sq(lattice, h, k, l);
                    if (intensity <= 0.001) continue;

                    const double hkl_sum_sq = static_cast<double>(h * h + k * k + l * l);
                    const double d = lattice_parameter_a_nm / std::sqrt(hkl_sum_sq);
                    const double sin_theta = wavelength_lambda_nm / (2.0 * d);

                    if (sin_theta <= 1.0) {
                        const double theta_rad = std::asin(sin_theta);
                        const double theta_deg = theta_rad * (180.0 / std::numbers::pi);

                        reflections.push_back(DiffractionReflection{
                            .h = h,
                            .k = k,
                            .l = l,
                            .interplanar_d_nm = d,
                            .bragg_theta_deg = theta_deg,
                            .two_theta_deg = 2.0 * theta_deg,
                            .relative_intensity = intensity
                        });
                    }
                }
            }
        }

        std::ranges::sort(reflections, [](const auto& lhs, const auto& rhs) noexcept {
            return lhs.two_theta_deg < rhs.two_theta_deg;
        });

        return reflections;
    }
};

void display_diffraction_table(std::string_view title,
                               const std::vector<DiffractionReflection>& reflections) {
    std::cout << "=========================================================================\n";
    std::cout << "  СИМУЛЯЦІЙНИЙ СПЕКТР: " << title << "\n";
    std::cout << "=========================================================================\n";
    std::cout << std::right
              << std::setw(10) << "(h k l)" << " | "
              << std::setw(10) << "d (нм)" << " | "
              << std::setw(12) << "theta (deg)" << " | "
              << std::setw(14) << "2*theta (deg)" << " | "
              << std::setw(14) << "Інтенсивність" << "\n";
    std::cout << "-------------------------------------------------------------------------\n";

    for (const auto& ref : reflections) {
        std::cout << "  (" << ref.h << " " << ref.k << " " << ref.l << ")   | "
                  << std::fixed << std::setprecision(4)
                  << std::setw(9) << ref.interplanar_d_nm << " | "
                  << std::setprecision(2)
                  << std::setw(11) << ref.bragg_theta_deg << " | "
                  << std::setw(13) << ref.two_theta_deg << " | "
                  << std::setprecision(1)
                  << std::setw(13) << ref.relative_intensity << "\n";
    }
    std::cout << "-------------------------------------------------------------------------\n";
    std::cout << " Кількість дозволених дифракційних максимуми: " << reflections.size() << "\n\n";
}

int main() {
    constexpr double lambda_cu_ka1 = 0.15406; // Мідне випромінювання Cu K-alpha1 (нм)

    const auto silicon_spectrum = DiffractionEngine::compute_spectrum(
        CrystalLattice::Diamond, 0.5431, lambda_cu_ka1, 4);
    display_diffraction_table("Кремній Si (Алмазна ґратка, a = 0.5431 нм)", silicon_spectrum);

    const auto copper_spectrum = DiffractionEngine::compute_spectrum(
        CrystalLattice::FaceCenteredCubic, 0.3615, lambda_cu_ka1, 3);
    display_diffraction_table("Мідь Cu (Гранецентрована FCC, a = 0.3615 нм)", copper_spectrum);

    return 0;
}
```

## 5. Аналіз розрахованих дифракційних даних та крайових випадків

Обчислювальні результати дають важливе розуміння фізики кристалографічного аналізу та дозволяють розібрати декілька фундаментальних крайових випадків.

### 1. Ефект систематичних згасань у монокристалічному кремнії (`Si`)
Для кремнію (`Si`, параметр `a = 0.5431 нм`) під час опромінення характеристичним випромінюванням `Cu Kα₁` (`λ = 0.15406 нм`) симуляція демонструє чітку послідовність виходу дифракційних піків:
1. **(111)**: `d = 0.3135 нм`, `2θ = 28.44°`, `I = 32` — найінтенсивніший низькокутовий рефлекс.
2. **(220)**: `d = 0.1920 нм`, `2θ = 47.30°`, `I = 64` — дозволений рефлекс для `4n`.
3. **(311)**: `d = 0.1637 нм`, `2θ = 56.12°`, `I = 32` — непарний рефлекс.
4. **(400)**: `d = 0.1358 нм`, `2θ = 69.13°`, `I = 64` — дозволений рефлекс.

У спектрі кремнію повністю відсутній рефлекс **(200)** (який у звичайній гранецентрованій ґратці міді виникає при `2θ ≈ 32.9°`). Причина полягає у тому, що для алмазоподібної кристалічної ґратки парні індекси `(h, k, l)` мусять давати суму `h + k + l = 4n`. Для `(200)` сума `2 + 0 + 0 = 2`, що не ділиться на 4. Промені, розсіяні другим підгратком FCC, знаходяться у протифазі з першим підгратком і повністю скасовують амплітуду відбитого сигналу.

### 2. Залежність від довжини хвилі випромінювання
Якщо замінити джерело мідного анода `Cu Kα` (`λ = 0.15406 нм`) на молібденовий анод `Mo Kα` (`λ = 0.07093 нм`), довжина хвилі зменшується більш ніж удвічі. Відповідно до умови `sin θ = λ / (2d)`, усі бреґґівські кути `θ` зменшуються, і дифракційні піки стискаються у область малих кутів `2θ`. Це дозволяє спостерігати значно більшу кількість рефлексів у межах сфери Евальда, що є критично важливим для розшифровки складних макромолекулярних структур білків.

### 3. Температурний фактор Дебая — Валлера (Тепловий рух)
У реальному кристалі при температурі `T > 0 K` атоми здійснюють теплові коливання навколо положень рівноваги з середьоквадратичним відхиленням `<u²>`. Це призводить до зменшення інтенсивності піків із зростанням кута `θ`, що описується температурним множником Дебая — Валлера:

```
I_temp(θ) = I_0 · exp(-2 B · (sin θ / λ)²)
```

де `B = 8 π² · <u²>` — температурний фактор. Врахування цього множника у обчислювальній моделі дозволяє моделювати реальні дифрактограми при довільних температурах аж до точки плавлення кристала.
