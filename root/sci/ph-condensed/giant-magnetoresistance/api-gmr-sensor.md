# 📋 Електричний інтерфейс та мостова топологія GMR-сенсора

Інтегральний магнітометричний датчик на основі гігантського магнітоопору випускається у вигляді чотириплечого вимірювального моста Вітстона, сформованого на єдиному силіцієвому кристалі. Чотири спінові клапани поєднані у містову схему з метою компенсації температурного дрейфу опору, усунення синфазного сигналу живильної напруги та забезпечення лінійної вихідної характеристики при вимірюванні слабких магнітних полів від десятих часток мікротесли до десятків мілітесл.

Використання мостової структури дозволяє перетворити відносно малу зміну опору окремого елемента на високоточний диференціальний напруговий сигнал. Оскільки всі чотири плечі моста виготовляються в єдиному технологічному циклі напилення і розташовані на відстані кількох десятків мікрометрів один від одного, вони володіють ідентичними температурними параметрами. Це дозволяє пригнічувати температурний дрейф опору першого порядку та забезпечувати високу стабільність нульового рівня в широкому діапазоні температур.

### Детальний фізичний зміст базових параметрів

1. **Номінальний опір моста (`R_0`):** Задає базовий рівень енергоспоживання датчика. Значення `2.5–5.0 кОм` забезпечує компроміс між низьким струмом споживання (менше `1 мА` при живленні `3.3 В`) та помірним рівнем теплового шуму Джонсона — Найквіста. Використання вищих опорів (понад `50 кОм`) призвело б до неприпустимого зростання спектральної густини шуму напруги, тоді як низькоомні мости (`< 500 Ом`) споживають надто великий струм і викликають локальний самонагрів кристала.
2. **Магніточутливість (`S_v`):** Нормована величина диференційного сигналу на один вольт напруги живлення при прикладанні зовнішнього поля в один мілітесла. Значення `3.5 мВ/(В·мТл)` (що еквівалентно `0.35 мВ/(В·Е)` у системі СГС, де `1 Е ≈ 0.1 мТл`) означає, що при живленні `5 В` та полі `1 мТл` диференціальна напруга моста становить `17.5 мВ`, що у 15–30 разів перевищує вихідний сигнал класичних тонкоплівкових елементів Холла.
3. **Лінійний діапазон (`B_lin`) та поле насичення (`B_sat`):** Діапазон `B_lin` визначає амплітуду полів, у межах яких нелінійність передатної функції не перевищує `1%`. При перевищенні `B_sat` кут між векторами намагніченості вільного та закріпленого шарів досягає `0°` або `180°`, опір стає константним, і сенсор втрачає чутливість до подальшого зростання магнітного поля.
4. **Температурні коефіцієнти (`TCR` та `TCS`):**
   - Додатний коефіцієнт `TCR` (`+0.11 … +0.14 %/°C`) зумовлений збільшенням частоти фононного розсіювання електронів провідності при підвищенні температури кристалічної ґратки.
   - Від'ємний коефіцієнт `TCS` (`-0.10 … -0.14 %/°C`) викликаний температурним розмиванням фермієвського розподілу та інтенсифікацією розсіювання на теплових магнонах, що знижує ступінь спінової поляризації `P(T)` на рівні Фермі та зменшує амплітуду відносного магнітоопору `ΔR/R`.

## Шумові характеристики та гранична роздільна здатність

Поріг чутливості GMR-сенсора визначається сумарною спектральною густиною шумів, яка складається з фундаментального теплового шуму, низькочастотного флікер-шуму (`1/f`) та магнітного доменного шуму:

```
S_v,total(f) = S_v,th + S_v,1/f(f) + S_v,mag(f)
```

```
                        Спектр напругового шуму GMR-сенсора
  S_v(f)
  [нВ/√Гц] ▲
           │
      100 ─┼───\
           │    \  1/f флікер-шум (кут f_c ≈ 500 Гц)
       30 ─┼─────\
           │      \
       10 ─┼───────\──────────────────────────── Білий тепловий шум e_th ≈ 9.1 нВ/√Гц
           │
           └───────┬────────────────────────────► f [Гц]
                  f_c
```

### 1. Тепловий шум Джонсона — Найквіста

Тепловий рух носіїв заряду в металевих шарах створює білий шум із частотно-незалежною спектральною густиною напруги `e_th`:

```
e_th = √(4 · k_B · T · R_0)     [спектральна густина теплового шуму напруги]
```

де `k_B = 1.380649 × 10⁻²³` Дж/К — стала Больцмана, `T` — абсолютна температура в кельвінах, `R_0` — активний опір моста Вітстона.

Розрахунок для кімнатної температури (`T = 300 K`) та номінального опору `R_0 = 5 кОм`:

```
4 · k_B · T = 4 · (1.38 × 10⁻²³) · 300 = 1.656 × 10⁻²⁰ В·А·с
e_th = √(1.656 × 10⁻²⁰ · 5000)
     = √(8.28 × 10⁻¹⁷)
     ≈ 9.10 × 10⁻⁹ В/√Гц = 9.10 нВ/√Гц
```

### 2. Низькочастотний флікер-шум (1/f)

Флікер-шум у GMR-структурах виникає внаслідок повільних флуктуацій потенційного рельєфу на міжфазних межах металевих шарів та описується емпіричним співвідношенням Хооге:

```
S_v,1/f(f) = (α_H · V_cc²) / (N_c · f^γ)     [спектральна густина 1/f шуму]
```

тут `α_H` — безрозмірний параметр Хооге (для плівок Cu/CoFe `α_H ≈ 10⁻³ – 10⁻²`), `N_c` — повна кількість вільних електронів провідності у зразку, `γ ≈ 0.9–1.1` — показник спектрального нахилу, `V_cc` — напруга живлення.

Частота кута флікер-шуму `f_c`, на якій амплітуда шуму `1/f` зрівнюється з рівнем теплового шуму, для оптимізованих спінових клапанів становить `f_c ≈ 100 Гц – 1 кГц`.

### 3. Гранична магнітна роздільна здатність (LOD)

Гранична магнітна роздільна здатність (Limit of Detection, LOD), або еквівалентний магнітний шум `S_B(f)`, виражається як відношення повної спектральної густини напругового шуму до абсолютної магніточутливості датчика:

```
S_B(f) = S_v,total(f) / (S_v · V_cc)     [еквівалентний магнітний шум у нТл/√Гц]
```

Для сенсора з чутливістю `S_v = 4.0 мВ/(В·мТл)` при живленні `V_cc = 5.0 В`:
- Абсолютна крутизна перетворення: `K_v = S_v · V_cc = 20 мВ/мТл = 20 мкВ/мкТл = 20 нВ/нТл`.
- У високочастотній ділянці білого шуму (`f > 1 кГц`, `S_v ≈ 9.1 нВ/√Гц`):
  ```
  S_B(f > 1 кГц) = (9.1 нВ/√Гц) / (20 нВ/нТл) = 0.455 нТл/√Гц
  ```
- У низькочастотній ділянці (`f = 1 Гц`, де `S_v(1 Гц) ≈ 250 нВ/√Гц` через флікер-шум):
  ```
  S_B(1 Гц) = (250 нВ/√Гц) / (20 нВ/нТл) = 12.5 нТл/√Гц
  ```

Інтегральна магнітна роздільна здатність у смузі `1 Гц – 10 кГц` становить близько `10–50 нТл` (0.1–0.5 мікроерстед), що дозволяє GMR-сенсорам детектувати зміщення магнітних наночастинок та мікрострумові поля без застосування кріогенного охолодження.

## Топологія кристала, конфігурації моста та градієнтометрія

Для перетворення зміни опору `ΔR(H)` на лінійний диференціальний сигнал використовують три основні топологічні компонування елементів на кристалі:

### 1. Повний міст з магнітним екрануванням (Shielded Bridge)

Класична схема NVE (серії AA, AAH): два протилежні діагональні плечі `R1` та `R4` залишаються відкритими і реагують на зовнішнє магнітне поле, тоді як плечі `R2` та `R3` закриваються товстим шаром магнітом'якого екрана (му-метал або пермалой `Ni₈₀Fe₂₀` товщиною `5–10 мкм`).

```
                       ┌──────────────┐
                       │   V_cc (1)   │
                       └──────┬───────┘
                              │
               ┌──────────────┴──────────────┐
               │                             │
        ┌──────┴──────┐               ┌──────┴──────┐
        │  R1 (GMR)   │               │  R2 (GMR*)  │
        │ Активне R+  │               │ Екрановане  │
        └──────┬──────┘               └──────┬──────┘
               │                             │
               ├──────────────┐              ├──────────────┐
               │              │              │              │
        ┌──────┴──────┐ ┌─────┴──────┐ ┌─────┴──────┐ ┌─────┴──────┐
        │  Out- (4)   │ │  R3 (GMR*) │ │  Out+ (2)  │ │  R4 (GMR)  │
        └─────────────┘ │ Екрановане │ └────────────┘ │ Активне R+ │
                        └─────┬──────┘                └─────┬──────┘
                              │                             │
                              └──────────────┬──────────────┘
                                             │
                                      ┌──────┴──────┐
                                      │   GND (3)   │
                                      └─────────────┘
```

Екран перенаправляє магнітний потік в обхід захищених смужок: `R2 = R3 = R_0`, тоді як активні смужки змінюють опір: `R1 = R4 = R_0 + ΔR(H)`.

### 2. Повний диференціальний міст з протилежним закріпленням (Push-Pull Bridge)

У високочутливих кутових датчиках (Infineon TLE, TDK TAS) усі чотири резистори є відкритими магніточутливими елементами. За допомогою локального лазерного відпалу або подвійної термомагнітної фіксації вектори обмінного зсуву закріплених шарів орієнтують антипаралельно: у плечах `R1, R4` вздовж `+X`, а в плечах `R2, R3` — вздовж `-X`.
При появі поля `+H`:
```
R1 = R4 = R_0 + ΔR(H)
R2 = R3 = R_0 - ΔR(H)
```
Це подвоює крутизну вихідного сигналу (`V_out = 2 · V_cc · ΔR/R_0`) та повністю усуває необхідність нанесення товстих екранувальних шарів.

### 3. Градієнтометричний міст (Gradiometer dB/dx)

Для безконтактного вимірювання струму в умовах потужних сторонніх магнітних завад застосовують просторово рознесену градієнтометричну конфігурацію (NVE серії AB, Allegro ACS70331). Два активні резистори `R1` та `R3` розташовані над висхідною ділянкою первинного провідника (`x = 0`), а резистори `R2` та `R4` — над низхідною ділянкою (`x = d_base`):

```
                        Градієнтометр GMR (dB/dx):
                        
      Провідник струму (+I)                Провідник струму (-I)
             │ │                                  │ │
             │ │ ──► Поле +B_I                    │ │ ──► Поле -B_I
             ▼ ▼                                  ▼ ▼
        ┌───────────┐                        ┌───────────┐
        │ R1, R4    │                        │ R2, R3    │
        │ на кристалі│                        │ на кристалі│
        └───────────┘                        └───────────┘
        ◄──────────────── d_base ≈ 0.5 мм ───────────────►
```

- Однорідне зовнішнє поле завади `B_ext` однаково діє на всі плечі: `ΔR(B_ext)` є синфазною для всіх резисторів і повністю віднімається мостовою схемою (`CMRR > 40–60 дБ`).
- Градієнтне поле від вимірюваного струму `B_I` має протилежний знак під резисторами: `R1, R4` зменшують опір, а `R2, R3` збільшують опір, формуючи подвоєний корисний сигнал.

## Методи лінеаризації робочої характеристики

Природний відгук спінового клапана пропорційний косинусу кута між намагніченостями: `ΔR ∝ -cos(θ)`. Оскільки поблизу точки рівноваги `θ = 0°` або `180°` похідна `d(cos θ)/dθ = -sin(θ) ≈ 0`, незміщений спіновий клапан має квадратичну нелінійну характеристику з нульовою чутливістю до малих полів. Для отримання максимальної лінійної крутизни вимагається зміщення початкового робочого кута до `θ_0 = 90°` (`cos(90° + Δθ) = -sin(Δθ) ≈ -Δθ`).

Для лінеаризації передатної характеристики в промислових давачах використовують три основні методи:

```
                            Методи лінеаризації GMR
                            
  1. Bias Magnet                    2. Crossed Anisotropy           3. Barber Poles
  
      H_bias (↑)                       M_pinned (→)                 Струм під кутом 45°
  ┌─────────────────┐               ┌─────────────────┐             ┌─\───\───\───\─┐
  │ M_free (↑)      │               │ M_pinned (→)    │             │  \   \   \   \│ ◄── Смужки Au
  ├─────────────────┤               ├─────────────────┤             ├───────────────┤
  │ M_pinned (→)    │               │ M_free (↑)      │             │ M_free (→)    │
  └─────────────────┘               └─────────────────┘             └───────────────┘
  Зовнішній постійний               Термомагнітний відпал:          Еквіпотенціальні
  магніт поперек осі                H_k_free ⊥ H_ex_pinned          золоті доріжки
```

### 1. Зовнішній магніт поперечного зміщення (Bias Magnet)

Біля кристала сенсора монтується постійний феритовий або самарій-кобальтовий мікромагніт, який створює фіксоване поле `H_bias` (типово `1.0–3.0 мТл`), орієнтоване строго перпендикулярно до осі закріплення опорного шару. Поле зміщення повертає вектор намагніченості вільного шару на `90°`. Зовнішнє вимірюване поле `H_ext`, прикладене вздовж осі закріплення, відхиляє вільний шар на малий кут `Δθ`, забезпечуючи лінійну залежність:

```
sin(Δθ) ≈ H_ext / (H_bias + H_k)     [кут відхилення вільного шару]
```

### 2. Схрещена магнітна анізотропія (Crossed Anisotropy)

Сучасний безмагнітний метод формування внутрішньої лінеаризації безпосередньо в структурі плівки під час виробництва:
- Під час першого високотемпературного відпалу (`T = 280 °C`) у сильному полі `H_1` закріплюється намагніченість опорного шару вздовж осі `X`.
- Під час другого низькотемпературного відпалу (`T = 180 °C`, нижче температури блокування `T_B` антиферомагнетика) у полі `H_2 ⊥ H_1` формується вісь легкого намагнічування вільного шару вздовж осі `Y`.
- За відсутності зовнішнього поля вільний шар самостійно орієнтується під кутом `90°` до закріпленого, створюючи ідеально лінійний відгук без додаткових зовнішніх деталей.

### 3. Смужки Барбера (Barber Poles)

На поверхню GMR-смужки напилюють тонкі похилі провідні доріжки з золота або алюмінію під кутом `45°` до поздовжньої осі смужки. Оскільки питомий опір золота в сотні разів нижчий за опір феромагнітних шарів, лінії електричного струму протікають найкоротшим шляхом — перпендикулярно до золотих смужок, тобто під кутом `45°` до намагніченості. Це зміщує робочу точку кривої магнітоопору в лінійну зону.

## Математична модель вихідного сигналу та компенсація дрейфу

Диференціальна напруга між виводами `OUT+` та `OUT-` обчислюється за формульним виразом для збалансованого моста:

```
V_out = V_(OUT+) - V_(OUT-)

V_(OUT+) = V_cc · [ R4 / (R2 + R4) ]
V_(OUT-) = V_cc · [ R3 / (R1 + R3) ]

V_out = V_cc · [ (R_0 + ΔR)/(2·R_0) - (R_0 - ΔR)/(2·R_0) ]
      = V_cc · [ (2·ΔR) / (2·R_0) ]
      = V_cc · [ ΔR(H) / R_0 ]
```

З урахуванням коефіцієнта чутливості `S_v`, залишкового зміщення `V_off` та температурної залежності вихідна напруга описується рівнянням:

```
V_out(B, T) = V_cc · [ S_v · (1 + TCS · (T - 25)) · B + V_off/V_cc + TCR_off · (T - 25) ]
```

тут `B` — проєкція зовнішнього магнітного поля на вісь чутливості датчика (у мТл), `T` — температура навколишнього середовища (у °C).

### Схемотехнічна компенсація температурного спаду чутливості

Для автоматичної компенсації від'ємного температурного коефіцієнта чутливості `TCS` (`-0.12 %/°C`) замість живлення моста фіксованою напругою `V_cc` застосовують живлення стабільним струмом `I_cc` або схему живлення з пропорційним зростанням напруги від терморезистора:

```
V_bridge(T) = I_cc · R_0(T) = I_cc · R_0(25) · [ 1 + TCR · (T - 25) ]
```

Вихідна напруга моста при струмовому живленні набуває вигляду:

```
V_out(B, T) = I_cc · R_0(25) · [ 1 + TCR · (T - 25) ] · S_v · [ 1 + TCS · (T - 25) ] · B
            ≈ I_cc · R_0(25) · S_v · [ 1 + (TCR + TCS) · (T - 25) ] · B
```

Оскільки додатний температурний коефіцієнт опору `TCR ≈ +0.13 %/°C` практично повністю компенсує від'ємний коефіцієнт чутливості `TCS ≈ -0.12 %/°C`:

```
TCR + TCS ≈ +0.13% - 0.12% = +0.01 %/°C
```

Результуючий температурний дрейф вихідного сигналу зменшується у 10–15 разів без застосування складних цифрових обчислювачів.

## Динамічні характеристики та частотний діапазон

Внутрішня динаміка магнітного відгуку GMR-сенсора визначається швидкістю прецесії та релаксації вектора намагніченості вільного шару і описується квантовомеханічним рівнянням Ландау — Ліфшиця — Гільберта (LLG):

```
dM/dt = - γ_LLG · (M × H_eff) + (α_LLG / M_s) · (M × dM/dt)     [динамічне рівняння LLG]
```

де `γ_LLG = 2.211 × 10⁵` м/(А·с) — гіромагнітне відношення, `α_LLG ≈ 0.008–0.015` — безрозмірний коефіцієнт демпфування Гільберта для пермалою `NiFe`, а `H_eff` — сумарне ефективне магнітне поле (включаючи зовнішнє поле, магнітокристалічну анізотропію та розмагнічуючі фактори форми).

### Власна частота та час перемикання наноматеріалу

Частота феромагнітного резонансу (FMR) вільного шару, виведена з формули Кіттеля:

```
f_FMR = (γ_LLG / (2 · π)) · √(H_k · (H_k + 4 · π · M_s))     [частота Кіттеля]
```

Для плівки пермалою товщиною `3 нм` із полем анізотропії `H_k ≈ 0.5 мТл` та намагніченістю насичення `4·π·M_s ≈ 1.0 Тл`:

```
f_FMR ≈ (28 ГГц/Тл) · √(0.0005 · 1.0) ≈ 28 · 0.0224 ≈ 0.63 ГГц = 630 МГц
```

Власний час магніторезистивного відгуку спінової підсистеми становить менше однієї наносекунди:

```
t_resp ≈ 1 / (2 · π · f_FMR) < 0.5–1.0 нс
```

### Обмеження смуги пропускання готового виробу

Хоча фізичний GMR-ефект у тонкій плівці зберігає працездатність до гігагерцових частот, смуга пропускання інтегрального сенсора обмежується паразитними електричними параметрами конструкції:
1. **Паразитна ємність та індуктивність виводів:** Ємність кремнієвої підкладки `C_sub ≈ 2–5 пФ` та індуктивність корпусних розварок `L_bond ≈ 2–5 нГн` формують паразитний RC/LC-фільтр низьких частот з частотою зрізу `f_cut ≈ 50–100 МГц` для безкорпусних кристалів.
2. **Вбудований тракт обробки (ASIC / операційний підсилювач):** У готових сенсорних мікросхемах із вбудованими підсилювачами та АЦП (Infineon, Allegro) смуга пропускання свідомо обмежується внутрішнім фільтром Бесселя або Баттерворта на рівні `100 кГц – 1 МГц` з метою пригнічення високочастотних електромагнітних завад (EMI) та шумів квантування.

## Схема первинного підсилення та аналогового узгодження

Оскільки диференціальний вихідний сигнал моста при малих полях вимірюється у мілівольтах, для його оцифрування аналогово-цифровим перетворювачем (АЦП) вимагається використання високоточного інструментального підсилювача з високим коефіцієнтом пригнічення синфазного сигналу (CMRR > 100 дБ, наприклад AD8221, INA333 або MCP6N11).

```

                  │                 GMR SENSOR                   │
                  │                                              │
                  │   V_CC ───┐                                  │
                  │           │                                  │
                  │        ┌──┴──┐                               │
                  │        │  R  │                               │

                  │        ┌──┴──┐                           │   │

                  │        └──┬──┘                           │   │
                  │           │                              │   │
                  │          GND                             │   │
                  └──────────────────────────────────────────┼───┘
                                                             │
                                                             ▼
┌────────────────────────────────────────────────────────────────────────┐
│                        ІНСТРУМЕНТАЛЬНИЙ ПІДСИЛЮВАЧ                     │
│                                                                        │
│   OUT+ ────────► ┌──────────┐                                          │
│                  │ IN+      │                                          │
```

1. **Коефіцієнт підсилення (Gain):** Задається зовнішнім прецизійним резистором `R_G`: `G = 1 + (49.4 кОм / R_G)`. При `R_G = 499 Ом` коефіцієнт підсилення становить `G = 100`. Це масштабує діапазон сигналів `± 15 мВ` у комфортний для АЦП діапазон `± 1.5 В`.
2. **Зсув опорного рівня (Reference Voltage):** Вивід `REF` підсилювача підключається до прецизійного джерела опорної напруги `V_ref = V_cc / 2 = 1.65 В`. Це дозволяє вимірювати як позитивні, так і негативні магнітні поля при використанні однополярного живлення АЦП (`0 – 3.3 В`).
3. **Диференціальна та синфазна фільтрація:** На входах підсилювача встановлюється симетричний RC-фільтр низьких частот (конденсатори між входами та на землю) з частотою зрізу близько `10–50 кГц` для пригнічення високочастотних радіозавад, імпульсних наведень та шуму перемикання імпульсних джерел живлення.

## Процедура скидання гістерезису та усунення зміщення (Set/Reset Pulse)

Незважаючи на низьку коерцитивну силу вільного шару (`H_c < 0.05` мТл), сильні випадкові магнітні завади (`H > 50` мТл) можуть порушити монодоменну структуру вільного шару, утворивши локальні магнітні домени з розсіяною орієнтацією. Це викликає залишковий гістерезисний зсув точки нуля (зміщення нульової напруги на кілька мілівольт), що призводить до похибки вимірювання.

Для відновлення заводського калібрування та усунення гістерезису мікросхема оснащена вбудованою плоскою спіральною котушкою або струмовою шиною `SET+/SET-`, розміщеною безпосередньо над резисторами моста.

```
Схема генерації імпульсу відновлення (Set/Reset circuit):

 +5V ───┬───────────────┐
        │               │
       ┌┴┐             ┌┴┐
       │ │ R_charge    │ │ R_charge
       └┬┘             └┬┘
        │               │
        ├───────┐       ├───────┐
       ─── C1   │      ─── C2   │
       ─── 4.7u │      ─── 4.7u │
        │       ▼       │       ▼
       GND    ┌───┐    GND    ┌───┐
              │FET│           │FET│
              └─┬─┘           └─┬─┘
                │               │
                ▼               ▼
              SET+ ───▒▒▒▒▒─── SET-
                    Котушка
```

### Алгоритм виконання процедури відновлення

1. **Генерація позитивного імпульсу (SET):**
   Використовуючи H-міст або конденсаторний розрядник, через шину `SET` пропускають короткий струмовий імпульс тривалістю `1.0–2.0` мікросекунди та амплітудою `1.0–1.5` А. Імпульс створює потужне локальне магнітне поле (`H_set > 20` мТл), яке перемагнічує вільний шар до повного насичення уздовж осі легкого намагнічування, відновлюючи монодоменну структуру.

2. **Вимірювання вихідної напруги `V_SET`:**
   Мікроконтролер оцифровує вихідну напругу підсилювача після позитивного імпульсу: `V_SET = V_off + V_signal`.

3. **Генерація негативного імпульсу (RESET):**
   Через шину `SET` пропускають імпульс протилежної полярності, який розвертає намагніченість вільного шару на 180°.

4. **Вимірювання вихідної напруги `V_RESET`:**
   Мікроконтролер оцифровує вихідну напругу після негативного імпульсу: `V_RESET = V_off - V_signal`.

5. **Обчислення точного сигналу без похибки зміщення:**
   Корисний магнітний сигнал обчислюється як піврізниця двох вимірювань, що повністю виключає постійну складову напруги зміщення `V_off` та її температурний дрейф:

```
V_signal = (V_SET - V_RESET) / 2
V_offset = (V_SET + V_RESET) / 2
```

Такий підхід дозволяє досягти стабільності точки нуля на рівні `0.005 мТл` у широкому діапазоні робочих температур від `-40 °C` до `+125 °C`.

## Промислові застосування та типові інженерні архітектури

### 1. Прецизійні безконтактні давачі струму з гальванічною розв'язкою

GMR-давачі струму (Allegro ACS70331, Infineon TLI4971) інтегрують товстий мідний провідник (leadframe) безпосередньо всередину корпусу мікросхеми на відстані `0.2–0.5 мм` від GMR-кристала.

```
                    Інтегрований GMR-давач струму:
                    
                     Вхідний струм I_in ──►
               ┌─────────────────────────────────┐
               │    Мідна шина первинного струму │  R_in < 1 мОм
               └───────────────┬─────────────────┘
                               │ Шар ізоляції SiO₂ (гальванічна міцність > 3 кВ)
                        ┌──────┴──────┐
                        │ GMR-градієнт│ ◄── Вимірює B = μ₀·I / (2·π·r)
                        │  ASIC мікро │
                        └─────────────┘
```

Переваги над датчиками Холла та шунтами:
- **Нульові втрати потужності:** Опір інтегрованої первинної шини становить менше `1 мОм` (типово `0.2–0.5 мОм`), що мінімізує тепловиділення `P = I² · R` при струмах до `50 А`.
- **Висока гальванічна ізоляція:** Надійний діелектричний шар діоксиду кремнію або полііміду витримує пробивну напругу понад `3.0–5.0 кВ RMS`.
- **Широка смуга пропускання:** Відсутність феритових магнітопроводів усуває магнітне насичення та втрати на перемагнічування на високих частотах, забезпечуючи лінійний відгук від постійного струму до `1 МГц`.

### 2. Автомобільні енкодери кута й швидкості обертання

У системах керування двигуном (датчики розподільвалу та колінвалу), трансмісією та системах стабілізації руху (ABS / ESP) використовуються прецизійні GMR-енкодери кута (Infineon TLE5009 / TLE5012B, TDK TAS2141).

Датчик розміщується навпроти торця постійного магніту, закріпленого на валу, що обертається:
- На кристалі інтегровано два повні мости Вітстона, розвернуті просторово на `45°` або `90°` один відносно одного.
- Сенсори генерують квадратурні вихідні напруги: `V_sin = V_0 · sin(2·φ)` та `V_cos = V_0 · cos(2·φ)`.
- Вбудований цифровий сигнальний процесор (DSP) обчислює миттєвий кут обертання вала за функцією арктангенса:

```
φ = (1/2) · atan2(V_sin, V_cos)     [обчислення абсолютного кута]
```

Оскільки амплітуди `V_sin` та `V_cos` однаково змінюються при зміні відстані до магніту (air gap) або коливаннях температури, їхнє відношення `V_sin / V_cos = tan(2·φ)` залишається інваріантним до температурного дрейфу та ексцентриситету вала. Це забезпечує точність вимірювання кута кращу за `0.1°` у діапазоні `0–360°` при швидкостях обертання до `30 000 об/хв`.

### 3. Біомедичні Lab-on-a-Chip магнітометри

GMR-сенсори застосовують у портативних діагностичних біочипах для детектування біомолекул (ДНК, вірусних білків, антитіл), помічених функціоналізованими суперпарамагнітними наночастинками оксиду заліза (SPIONs, маггеміт `γ-Fe₂O₃` або магнетит `Fe₃O₄` діаметром `20–50 нм`).

- Поверхню відкритого GMR-резистора вкривають біорецепторами (наприклад, антитілами).
- При зв'язуванні цільової молекули з міченою наночастинкою частинка фіксується безпосередньо над поверхнею GMR-сенсора.
- Під дією зовнішнього змінного поля збудження наночастинка намагнічується і генерує локальне дипольне поле розсіювання, яке реєструється GMR-мостом за допомогою синхронного детектування (lock-in amplification).
- Метод дозволяє виявляти одиничні магнітні мікрогранули з концентрацією аналіту аж до пікомолярного (`10⁻¹² М`) та фемтомолярного (`10⁻¹⁵ М`) рівнів без необхідності оптичної флуоресцентної мітки.

## Монтажні вимоги та компенсація паразитичних полів

При конструюванні друкованих плат із GMR-сенсорами необхідно дотримуватися суворих конструктивних правил для запобігання викривленню магнітного поля:

- **Заборона феромагнітних матеріалів:** У радіусі `15–20 мм` довкола сенсора заборонено розміщувати компоненти із вмістом заліза, нікелю або кобальту (наприклад, сталеві гвинти, феритні індуктивності, нікельовані роз'єми або стійки). Намагнічення цих елементів спотворює локальні силові лінії.
- **Орієнтація щодо високострумових провідників:** Сильнострумові шини живлення та провідники імпульсних перетворювачів генерують магнітні поля Біо — Савара (`B = μ₀·I / (2·π·r)`). Провідники мають розводитися перпендикулярно до осі чутливості датчика або на достатній відстані (`> 30 мм`).
- **Екранування від зовнішніх завад:** Для захисту від промислових магнітних полів частоти 50 Гц застосовують зовнішні екрани з пермалою або му-металу з прорізом уздовж вимірювальної осі.
- **Захист від статичної електрики (ESD):** Оскільки товщина немагнітної проміжки Cu становить лише `2 нм`, високовольтні імпульси статичної електрики можуть викликати локальний електричний пробій та зварювання металевих шарів. Сенсори вимагають стандартного захисту ESD (TVS-діоди на лініях живлення та виходах).
