# 🔌 Спіновий клапан: архітектури, шарова структура та порівняльний аналіз

Спіновий клапан є нанорозмірною металевою гетероструктурою, у якій орієнтація магнітного моменту одного з феромагнітних шарів жорстко зафіксована антиферомагнетиком за допомогою явища екранного обмінного зсуву, тоді як намагніченість другого шару вільно повертається під дією слабких зовнішніх магнітних полів. На відміну від перших багатошарових суперґраток Fe/Cr, де для зміни опору вимагалося подолання надпотужного антиферомагнітного RKKY-зв'язку по всій площі структури полем у кілька тесл, спіновий клапан функціонально розділяє магнітні шари: один шар слугує нерухомим магнітним репером (опорним шаром), а другий — надчутливим магнітом'яким детектором.

## Архітектура нанорозмірної багатошарової структури

Типовий промисловий спіновий клапан складається з 6–10 послідовно напилених нанорозмірних металевих шарів, кожен із яких виконує суворо визначену фізико-технологічну роль у забезпеченні спін-залежного транспорту заряду та термомагнітної стабільності:

```
┌─────────────────────────────────────────────────────────┐
│ Захисний шар (Cap Layer): Ta / Ru (2–4 нм)              │  ← Запобігає окисленню та дифузії
├─────────────────────────────────────────────────────────┤
│ Вільний шар (Free Layer): Ni₈₀Fe₂₀ (3 нм) / CoFe (0.5 нм)│  ← Повертається зовнішнім полем H
├─────────────────────────────────────────────────────────┤
│ Проміжка (Spacer): Cu (2.0–2.4 нм)                      │  ← Спін-зберігаючий місток (d > d_RKKY)
├─────────────────────────────────────────────────────────┤
│ Закріплений шар (Pinned Layer): Co₉₀Fe₁₀ (2–3 нм)       │  ← Зафіксована опорна намагніченість
├─────────────────────────────────────────────────────────┤
│ Антиферомагнетик (AFM Pinning): Ir₂₀Mn₈₀ / PtMn (6–10 нм)│  ← Створює поле обмінного зсуву H_ex
├─────────────────────────────────────────────────────────┤
│ Буферний шар (Seed Layer): Ta / NiFeCr (3–5 нм)         │  ← Формує кристалографічну текстуру (111)
├─────────────────────────────────────────────────────────┤
│ Підкладка: Кремній із термічним оксидом (Si / SiO₂)     │
└─────────────────────────────────────────────────────────┘
```

1. **Буферний шар (Seed Layer):** Тонка плівка танталу (`Ta`) або нікель-хрому (`NiFeCr`) товщиною `3–5` нм. Аморфний або дрібнодисперсний підшар вирівнює топографію поверхні окисленої кремнієвої підкладки та нав'язує чітку кристалографічну текстуру `(111)` у гранецентрованій кубічній (ГЦК) ґратці наступних металевих шарів. Текстура `(111)` є обов'язковою кристалографічною умовою для формування щільноупакованих площин антиферомагнетика та виникнення максимального міжфазного обмінного зсуву.
2. **Антиферомагнітний шар (AFM Pinning Layer):** Сплави іридію та марганцю (`Ir₂₀Mn₈₀`) або платини та марганцю (`Pt₅₀Mn₅₀`) товщиною `6–10` нм. Шар має скомпенсовану антиферомагнітну структуру в об'ємі, проте на межі поділу з феромагнетиком містить шар некомпенсованих атомних спінів, які слугують джерелом односпрямованої магнітної анізотропії.
3. **Закріплений шар (Pinned Layer):** Плівка кобальт-заліза (`Co₉₀Fe₁₀`) товщиною `2–3` нм. Намагніченість шару жорстко зафіксована в одному напрямку завдяки прямому обмінному зв'язку зі спінами поверхні антиферомагнетика. Сплав `CoFe` забезпечує високу спінову поляризацію електронів на рівні Фермі (`P ≈ 50–55%`) та високий коефіцієнт інтерфейсної спінової асиметрії `γ`.
4. **Немагнітна проміжка (Non-magnetic Spacer):** Шар надчистої міді (`Cu`) товщиною точно `2.0–2.4` нм. Нижній поріг товщини обмежений радіусом дії прямого обмінного та RKKY-зв'язку: при `d_Cu < 1.8` нм виникає паразитна феромагнітна взаємодія із закріпленим шаром, яка блокує обертання вільного шару. Верхній поріг обмежений шунтуванням струму та довжиною спінової дифузії в міді (`l_sf > 100` нм).
5. **Вільний шар (Free Layer):** Двошарова комбінація `Co₉₀Fe₁₀ (0.5–1.0 нм) / Ni₈₀Fe₂₀ (2–4 нм)`. Надвисока спінова асиметрія тонкої вставки `CoFe` на межі з міддю максимізує інтерфейсне розсіювання, а товстий шар пермалою `Ni₈₀Fe₂₀` забезпечує майже нульову магнітострикцію (`λ_s ≈ 0`), надзвичайно низьку коерцитивну силу (`H_c < 0.3` мТл) та високу магнітну проникність.
6. **Захисний шар (Cap Layer):** Плівка танталу (`Ta`) або рутенію (`Ru`) товщиною `2–4` нм, яка захищає вільний шар від атмосферного окислення, корозії та блокує міжфазну дифузію атомів під час фінального технологічного відпалу.

## Фізика екранного обмінного зсуву (Exchange Bias)

Явище екранного обмінного зсуву (Exchange Bias, відкрите В. Мейклджоном та К. Біном у 1956 році) виникає на межі поділу антиферомагнетик/феромагнетик (`AFM / FM`) у результаті квантовомеханічної обмінної взаємодії між локалізованими `d`-спінами сусідніх атомних площин.

```
               Термомагнітне охолодження (T > T_B → T < T_B) у полі H_set
               
Антиферомагнетик (AFM: IrMn)               Феромагнетик (FM: CoFe)
┌─────────────────────────────┐         ┌─────────────────────────────┐
│  ↑  ↓  ↑  ↓  ↑  ↓  ↑  ↓  ↑  │         │  →  →  →  →  →  →  →  →  →  │
│  ↓  ↑  ↓  ↑  ↓  ↑  ↓  ↑  ↓  │         │  →  →  →  →  →  →  →  →  →  │
│  →  →  →  →  →  →  →  →  →  │ ◄──────►│  →  →  →  →  →  →  →  →  →  │
└─────────────────────────────┘         └─────────────────────────────┘
  Некомпенсовані поверхневі               Вектор намагніченості M_pinned
  спіни закріплені вздовж H_set           орієнтований уздовж H_set
```

Для створення односпрямованої анізотропії структуру піддають термомагнітній обробці:
1. Систему нагрівають у вакуумі вище температури блокування антиферомагнетика `T_B` (для `Ir₂₀Mn₈₀` `T_B ≈ 250–280 °C`, для `Pt₅₀Mn₅₀` `T_B ≈ 350 °C`), але нижче температури Кюрі феромагнетика `T_C` (`T_C(CoFe) > 800 °C`) та температури Неєля `T_N`. При `T > T_B` теплова енергія долає локальну магнітокристалічну анізотропію антиферомагнітних зерен, усуваючи міжфазне закріплення.
2. До зразка прикладають сильне однорідне магнітне поле `H_set ≈ 0.5–1.0` Тл, яке повністю насичує намагніченість феромагнітного шару в заданому напрямку.
3. Систему повільно охолоджують у полі крізь точку `T_B`. При переході через `T_B` антиферомагнітний порядок у зернах «заморожується», а некомпенсовані спіни граничного атомного шару антиферомагнетика шикуються паралельно вектору намагніченості феромагнетика під дією міжфазного обмінного інтеграла `J_ex`.

Після охолодження до робочої температури жорстка магнітна підґратка антиферомагнетика утримує граничні спіни. Спроба розвернути намагніченість феромагнітного шару протилежним зовнішнім полем наражається на протидію міжфазного обмінного моменту. Це еквівалентно прикладанню до феромагнетика додаткового внутрішнього ефективного поля — поля екранного обмінного зсуву `H_ex`:

```
H_ex = J_K / (M_FM · d_FM)                                             [поле екранного обмінного зсуву]
```

де `J_K` — питома енергія міжфазного обмінного зв'язку (для інтерфейсу `IrMn / CoFe` `J_K ≈ 0.15–0.22` мДж/м²), `M_FM` — спонтанна намагніченість закріпленого шару, а `d_FM` — його товщина. У результаті петля гістерезису закріпленого шару асиметрично зсувається вздовж осі напруженості магнітного поля на величину `H_ex` (типово `30–60` мТл або `300–600` Ерстед), що на два порядки перевищує поле коерцитивності вільного шару (`H_c < 0.5` мТл).

## Еволюція закріплення: простий спіновий клапан проти SAF

### Простий спіновий клапан та його фундаментальні обмеження

У найпростішій конфігурації спінового клапана (*Simple Spin Valve*) закріплений шар є монолітною феромагнітною плівкою `CoFe`, нанесеною безпосередньо на антиферомагнетик: `AFM / CoFe / Cu / NiFe / Cap`. 

Така базова архітектура володіє двома критичними недоліками, які унеможливлюють її застосування у прецизійній сенсориці та мікроелектроніці:

1. **Дипольні поля розсіювання (Demagnetizing Stray Fields):** Оскільки закріплений шар має значний нескомпенсований магнітний момент `m = M_FM · d_FM · A`, на краях наноструктури виникають локальні магнітні заряди (`∇ · M ≠ 0`). Вони створюють просторове дипольне магнітне поле розсіювання, яке замикається крізь вільний шар. Це поле спрямоване антипаралельно до намагніченості закріпленого шару і зміщує точку нульового перемагнічування вільного шару, спричиняючи асиметрію чутливості сенсора та дрейф нуля.
2. **Топологічний зв'язок Неєля («Orange-peel coupling»):** Реальні міжфазні межі розділу металевих шарів мають залишкову конформну хвилястість після магнетронного напилення. Періодична шорсткість межі розділу `CoFe / Cu / NiFe` із середньою висотою нерівностей `h` та характерною довжиною хвилі `λ_r` створює на скосах інтерфейсу локальні магнітні полюси. Магнітостатична взаємодія між цими полюсами генерує ефективний феромагнітний зв'язок Неєля, що зміщує петлю вільного шару на поле `H_orange`:

```
H_orange = (π² · h² / (√2 · λ_r · d_free)) · M_pinned · exp(- 2·π·√2 · d_spacer / λ_r)
```

Сумарний зсув петлі гістерезису вільного шару `H_off = H_stray + H_orange` досягає `1.5–4.0` мТл, що спотворює лінійний відгук давача слабких полів.

### Спіновий клапан із синтетичним антиферомагнетиком (SAF)

Радикальним вирішенням проблеми полів розсіювання стало впровадження штучного синтетичного антиферомагнетика (Synthetic Antiferromagnet, SAF) як опорного шару. Замість одиночної плівки `CoFe` формується тришарова система: `CoFe(1) / Ru (0.8 нм) / CoFe(2)`:

```
            Синтетичний антиферомагнетик (SAF Spin Valve)
┌─────────────────────────────────────────────────────────┐
│  Захисний шар (Cap): Ta / Ru (2–3 нм)                   │
├─────────────────────────────────────────────────────────┤
│  Вільний шар (Free Layer): NiFe / CoFe (2–4 нм)         │
├─────────────────────────────────────────────────────────┤
│  Проміжка (Spacer): Cu (2.0–2.4 нм)                      │
├─────────────────────────────────────────────────────────┤
│  FM2 (Опорний шар): CoFe (t₂ ≈ 2.2 нм)  ◄── M₂ (←)      │
├─────────────────────────────────────────────────────────┤
│  Рутеній (Ru Spacer): 0.8 нм             ◄── 1-й АФМ-пік│
├─────────────────────────────────────────────────────────┤
│  FM1 (Закріплений шар): CoFe (t₁ ≈ 2.0 нм) ◄── M₁ (→)   │
├─────────────────────────────────────────────────────────┤
│  Антиферомагнетик (AFM): Ir₂₀Mn₈₀ (6–8 нм)              │
├─────────────────────────────────────────────────────────┤
│  Буферний шар (Seed): Ta (3 нм) / NiFeCr (2 нм)         │
└─────────────────────────────────────────────────────────┘
```

Товщина проміжки рутенію вибирається з субмоношаровою точністю `d_Ru = 0.80 ± 0.05` нм, що відповідає найглибшому першому антиферомагнітному максимуму міжшарової RKKY-взаємодії. Антиферомагнітний обмінний інтеграл крізь шар рутенію сягає гігантської величини `J_RKKY ≈ - 1.0 ... - 1.5` мДж/м², що надійно зв'язує магнітні моменти шарів `FM1` та `FM2` строго антипаралельно один до одного.

Переваги конструкції SAF-клапана:
- **Повне замикання магнітного потоку (Flux Closure):** Якщо добутки намагніченості на товщину шарів збалансовані (`M₁·t₁ ≈ M₂·t₂`), сумарний магнітний момент SAF-структури практично дорівнює нулю (`M_net = |M₁·t₁ - M₂·t₂| / (t₁ + t₂) ≈ 0`). Поля розсіювання на краях елемента ліквідуються, усуваючи зсув робочої точки вільного шару.
- **Багаторазове зростання поля закріплення:** Ефективне поле розкріплення `H_ex,eff` SAF-структури визначається різницею магнітних моментів у знаменнику:

```
H_ex,eff = J_K / |M₁·t₁ - M₂·t₂|                                       [ефективне поле закріплення SAF]
```

Оскільки різниця `|M₁·t₁ - M₂·t₂|` прямує до нуля, експериментальне поле утримання зростає від `30–50` мТл до `200–400` мТл (`2000–4000` Ерстед).
- **Пригнічення спін-флоп переходів (Spin-Flop Suppression):** Жорсткий обмінний зв'язок через рутеній блокує неколінеарний розворот підґраток (спін-флоп) у сильних паразитних зовнішніх полях, забезпечуючи стабільність сенсора при температурах до `200–250 °C`.

## Подвійний спіновий клапан (Dual Spin Valve)

Для збільшення вихідного сигналу та підвищення відношення сигнал/шум (SNR) застосовують симетричну структуру — подвійний спіновий клапан (*Dual Spin Valve*), у якому центральний вільний шар контактує з двома незалежними немагнітними проміжками та двома закріпленими SAF-системами:

```
                  Подвійний спіновий клапан (Dual Spin Valve)
┌─────────────────────────────────────────────────────────────────┐
│ 11. Верхній захисний шар (Cap Layer): Ta (3 нм)                 │
├─────────────────────────────────────────────────────────────────┤
│ 10. Верхній антиферомагнетик (AFM2): IrMn (7 нм)                │
├─────────────────────────────────────────────────────────────────┤
│  9. Верхній SAF2 (FM1): CoFe (2.0 нм)           ◄── M(→)        │
├─────────────────────────────────────────────────────────────────┤
│  8. Верхня проміжка Ru: 0.8 нм                  ◄── RKKY (AP)   │
├─────────────────────────────────────────────────────────────────┤
│  7. Верхній SAF2 (FM2): CoFe (2.2 нм)           ◄── M(←)        │
├─────────────────────────────────────────────────────────────────┤
│  6. Верхня проміжка (Cu Spacer 2): Cu (2.2 нм)                  │ ◄── Інтерфейс 2 (GMR)
├─────────────────────────────────────────────────────────────────┤
│  5. Центральний вільний шар: CoFe (0.5) / NiFe (2) / CoFe (0.5) │ ◄── Вільне обертання
├─────────────────────────────────────────────────────────────────┤
│  4. Нижня проміжка (Cu Spacer 1): Cu (2.2 нм)                   │ ◄── Інтерфейс 1 (GMR)
├─────────────────────────────────────────────────────────────────┤
│  3. Нижній SAF1 (FM2): CoFe (2.2 нм)            ◄── M(←)        │
├─────────────────────────────────────────────────────────────────┤
│  2. Нижня проміжка Ru: 0.8 нм                   ◄── RKKY (AP)   │
├─────────────────────────────────────────────────────────────────┤
│  1. Нижній SAF1 (FM1): CoFe (2.0 нм)            ◄── M(→)        │
├─────────────────────────────────────────────────────────────────┤
│  0. Нижній антиферомагнетик (AFM1): IrMn (7 нм) / Seed: Ta      │
└─────────────────────────────────────────────────────────────────┘
```

У подвійному спіновому клапані обидва інтерфейси вільного шару (`Cu1 / Free` та `Free / Cu2`) є активними зонами спін-залежного розсіювання. Обидві опорні системи `SAF1` та `SAF2` орієнтують свої прилеглі шари `FM2` в одному магнітному напрямку (вліво `←`).

Фізичні переваги та інженерні компроміси Dual Spin Valve:
1. **Зростання амплітуди GMR на 60–80%:** Оскільки електрони провідності зазнають спін-залежного розсіювання як на верхній, так і на нижній межах вільного шару, коефіцієнт магнітоопору в CIP-геометрії підвищується з `8–10%` (для одинарного клапана) до `15–18%`.
2. **Симетрія топологічного зв'язку:** Дія полів Неєля від верхнього та нижнього інтерфейсів взаємно компенсується, що забезпечує ідеально симетричну характеристику перемагнічування вільного шару довкола нульового поля.
3. **Технологічна ціна:** Повна товщина металевого сендвіча зростає з `25` до `45–50` нм. У CIP-геометрії це викликає додаткове паразитичне шунтування струму крізь пасивні антиферомагнітні шари. Крім того, структура вимагає точного узгодження температур блокування обох антиферомагнетиків `AFM1` та `AFM2` під час термомагнітного відпалу.

## Спінові клапани з нанооксидними дзеркальними шарами (NOL)

При зменшенні товщини шарів у CIP-геометрії (з метою зниження паразитичного шунтування струму) виникає фундаментальне обмеження: електрони провідності починають інтенсивно зазнавати дифузного розсіювання на зовнішніх шорстких поверхнях плівки (межі з підкладкою та захисним шаром). Відповідно до теорії Фукса — Зондгеймера, параметр дзеркальності звичайної металевої поверхні становить `p ≈ 0`, що руйнує спінову пам'ять електронів і знижує відношення `ΔR/R`.

Для подолання цього обмеження було розроблено дзеркальні спінові клапани (*Specular Spin Valves*) із застосуванням нанооксидних шарів (Nano-Oxide Layers, NOL):

```
               Дзеркальний спіновий клапан із шарами NOL
┌─────────────────────────────────────────────────────────────────┐
│ Захисний шар (Cap Layer): Ta (2 нм)                             │
├─────────────────────────────────────────────────────────────────┤
│ Верхній NOL: TaO_x або CoFeO_x (0.8 нм)    ▲▲▲ Дзеркало (p ≈ 0.8)│
├─────────────────────────────────────────────────────────────────┤
│ Вільний шар (Free Layer): CoFe (1 нм) / NiFe (2 нм) / CoFe (1)  │
├─────────────────────────────────────────────────────────────────┤
│ Проміжка (Spacer): Cu (2.0 нм)                                  │
├─────────────────────────────────────────────────────────────────┤
│ Закріплений шар (Pinned Layer 2): CoFe (1.5 нм)                 │
├─────────────────────────────────────────────────────────────────┤
│ Внутрішній NOL: CoFeO_x (0.6–0.8 нм)       ▼▼▼ Дзеркало (p ≈ 0.8)│
├─────────────────────────────────────────────────────────────────┤
│ Закріплений шар (Pinned Layer 1): CoFe (1.0 нм)                 │
├─────────────────────────────────────────────────────────────────┤
│ Рутеній (Ru): 0.8 нм / CoFe / AFM (PtMn)                        │
└─────────────────────────────────────────────────────────────────┘
```

Шар NOL формують шляхом короткочасного контрольованого природного або плазмового окислення (*in-situ radical oxidation*) ультратонкого шару металу (`CoFe` або `Ta`) товщиною `0.5–0.8` нм.

Механізм дії NOL:
- **Квантове дзеркальне відбивання:** Оксидний шар утворює високий діелектричний енергетичний бар'єр у зоні провідності. Електрони з хвильовими векторами, спрямованими до межі плівки, зазнають дзеркального квантового відбивання (коефіцієнт дзеркальності зростає до `p ≈ 0.75–0.85`) без зміни проекції спіна (`Δs = 0`).
- **Штучне подовження траєкторії:** Завдяки багаторазовому відбиванню всередині активного каналу `FM / Cu / FM` ефективна середня довжина вільного пробігу електронів зростає без збільшення фізичної товщини металу.
- **Приріст GMR:** Введення двох дзеркальних шарів (внутрішнього у закріплений шар та зовнішнього під захисний шар) підвищує кімнатний коефіцієнт CIP-GMR із `10–12%` до `18–22%` при збереженні низького питомого поверхневого опору.

## Порівняльний аналіз антиферомагнітних матеріалів закріплення

Вибір антиферомагнітного матеріалу для шару закріплення визначає робочий температурний діапазон, термічну стабільність, величину поля обмінного зсуву та корозійну стійкість сенсора.

### 1. Залізо-марганець (FeMn: Fe₅₀Mn₅₀)
Історично перший матеріал, використаний у лабораторних спінових клапанах. Має антиферомагнітну гранецентровану кубічну фазу `γ-FeMn`.
- **Переваги:** Високе поле зсуву при кімнатній температурі без потреби у високотемпературному відпалі; мала критична товщина `d_cr ≈ 5` нм.
- **Недоліки:** Низька температура блокування (`T_B ≈ 140–160 °C`), що виключає застосування в промислових та автомобільних пристроях. Катастрофічно низька корозійна стійкість: марганець активно окислюється при взаємодії з атмосферною вологою навіть крізь тонкі захисні покриття.

### 2. Іридій-марганець (IrMn: Ir₂₀Mn₈₀)
Найпопулярніший матеріал для масових комерційних GMR-сенсорів загального призначення та зчитувальних голівок накопичувачів перших поколінь.
- **Переваги:** Формує стабільний обмінний зсув безпосередньо в процесі магнетронного напилення (не вимагає обов'язкового тривалого фазового відпалу). Володіє високою корозійною стійкістю та малою критичною товщиною (`d_cr ≈ 5–6` нм), що мінімізує шунтування струму.
- **Характеристики:** Температура блокування `T_B ≈ 250–280 °C`, константа міжфазного обмінного зв'язку `J_K ≈ 0.15–0.22` мДж/м².

### 3. Платина-марганець (PtMn: Pt₅₀Mn₅₀)
Золотий стандарт для високотемпературних промислових, автомобільних сенсорів (стандарт AEC-Q100 Grade 0) та жорстких дисків високої щільності.
- **Особливість структури:** У стані після осадження плівка `PtMn` перебуває в немагнітній хімічно невпорядкованій ГЦК-фазі. Для формування антиферомагнітного порядку необхідний тривалий вакуумний термомагнітний відпал при `260–300 °C` протягом `2–4` годин у полі понад `0.5` Тл. Під час відпалу відбувається фазовий перехід у впорядковану тетрагональну структуру `L1_0` (просторова група `P4/mmm`).
- **Переваги:** Рекордно висока температура блокування `T_B ≈ 350–380 °C` (температура Неєля `T_N ≈ 500 °C`), максимальна енергія обміну `J_K ≈ 0.25–0.35` мДж/м², виняткова стійкість до розмагнічування та міжфазної дифузії при циклічних нагрівах до `+175 °C`.
- **Недоліки:** Збільшена критична товщина (`d_cr ≈ 10–12` нм) та висока вартість платини.

### 4. Оксид нікелю (NiO)
Діелектричний антиферомагнетик зі структурою кам'яної солі (NaCl).
- **Переваги:** Повна відсутність електричної провідності (питомий опір `ρ > 10⁶` Ом·см). Повністю усуває паразитичне шунтування струму в CIP-геометрії, що дозволяє підняти коефіцієнт GMR.
- **Недоліки:** Низька енергія обмінного зв'язку (`J_K < 0.05` мДж/м²), слабке поле `H_ex` (`10–20` мТл), низька температура блокування (`T_B ≈ 180–200 °C`). Вимагає товстого шару (`d > 30–50` нм), що призводить до катастрофічного зростання поверхневої шорсткості (`RMS > 0.6` нм) та посилення зв'язку Неєля.

| Матеріал AFM | Хімічний склад | Кристалічна структура | Потрібен відпал | `T_B` (°C) | `T_N` (°C) | `J_K` (мДж/м²) | `d_cr` (нм) | Корозійна стійкість | Галузь застосування |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |

| **IrMn** | `Ir₂₀Mn₈₀` | Невпорядкована ГЦК | Бажаний | 250–280 | 420 | 0.15–0.22 | 5–6 | Висока | Сенсори струму, HDD |
| **PtMn** | `Pt₅₀Mn₅₀` | Впорядкована `L1_0` (FCT) | **Так (280°C, 3 год)** | 350–380 | 500 | 0.25–0.35 | 10–12 | Виняткова | Автомобільні датчики, MRAM |

## Геометрії CIP та CPP: струм у площині проти струму по нормалі

Взаємна орієнтація напрямку протікання вимірювального струму `I` та площини наношарів кардинально змінює фізику спінового переносу та електротехнічні характеристики пристрою:

```
CIP (Current-in-Plane)                CPP (Current-Perpendicular-to-Plane)
Струм тече в площині шарів            Струм тече по нормалі крізь усі шари

       I ───►                                  │ I
┌──────────────────┐                   ┌───────┴──────────┐
│  Захисний шар    │                   │  Верхній контакт │
├──────────────────┤                   ├──────────────────┤
│  Вільний FM      │                   │  Вільний FM      │
├──────────────────┤                   ├──────────────────┤
│  Spacer Cu       │                   │  Spacer Cu       │
├──────────────────┤                   ├──────────────────┤
│  Закріплений FM  │                   │  Закріплений FM  │
├──────────────────┤                   ├──────────────────┤
│  Антиферомагнетик│                   │  Нижній контакт  │
└──────────────────┘                   └───────┬──────────┘
       I ───►                                  │ ▼
```

### Фізичні відмінності та електродинаміка CIP проти CPP

1. **Шунтування струму проти послідовного переносу:**
   - У геометрії **CIP** шари структури з'єднані паралельно. Питомий опір міді (`ρ_Cu ≈ 2` мкОм·см) у 8–10 разів нижчий за опір феромагнітних шарів (`ρ_CoFe ≈ 15–20` мкОм·см) та у 50 разів нижчий за опір антиферомагнетика (`ρ_IrMn ≈ 100` мкОм·см). До 50–70% повного струму без користі протікає крізь мідну проміжку, не беручи участі в спін-залежному розсіюванні, що обмежує CIP-GMR величиною `8–15%`.
   - У геометрії **CPP** струм протікає послідовно крізь кожен шар. 100% електронів провідності вимушено перетинають усі міжфазні межі `FM / Cu`, завдяки чому амплітуда GMR зростає до `30–60%`.
2. **Спінове накопичення (Spin Accumulation):**
   - У CIP-геометрії розсіювання описується напівкласичним кінетичним рівнянням Больцмана (модель Кемлі — Барнася), де головну роль відіграє співвідношення між товщиною шару `d` та середньою довжиною вільного пробігу електрона за імпульсом `λ_p` (`1–10` нм).
   - У CPP-геометрії через розрив спінової густини струму на межах феромагнетик/немагнітний метал виникає квантове розщеплення електрохімічних потенціалів `Δμ = μ_↑ - μ_↓`. Транспорт описується макроскопічною дифузійною теорією Валета — Ферта, а критичним просторовим масштабом виступає довжина спінової дифузії `l_sf` (`20–200` нм), яка значно перевищує товщину окремих шарів.
3. **Опір та масштабованість до наномасштабів:**
   - Опір CIP-елемента визначається квадратом плівки: `R = R_□ · (L / W)`, де `R_□ = ρ / d_total ≈ 15–30` Ом/□. Це забезпечує зручний електричний опір сенсора (`100 Ом – 5 кОм`) при стандартній літографії мікронного масштабу. Проте при зменшенні розміру зчитувального датчика жорстких дисків нижче `100` нм опір CIP-смужки катастрофічно зростає, а вихідна напруга падає через шунтування контактів.
   - Опір CPP-елемента нормується на площу: `R = (RA) / A`. Оскільки для металевих CPP-шарів питомий добуток `RA ≈ 0.02–0.08` Ом·мкм², макроскопічний елемент розміром `10×10` мкм мав би мізерний опір `0.0005` Ом (непридатний для вимірювання). Застосування CPP стає вигідним лише при нанорозмірній факторизації: при площі наностовпчика `A = 50×50` нм (`0.0025` мкм²) опір елемента становить оптимальні `20–40` Ом.
4. **Тепловиділення та спін-трансферний момент:**
   - У CPP-наноструктурах густина струму досягає екстремальних значень `j = 10⁷–10⁸` А/см². При таких густинах виникає сильний джоулів нагрів та проявляється ефект спін-трансферного обертального моменту (STT, Spin-Transfer Torque): спіново поляризований струм починає самостійно перевертати вільний шар, створюючи магнітний шум та обмежуючи робочий струм сенсора.

| Параметр порівняння | CIP (Current-in-Plane) | CPP (Current-Perpendicular-to-Plane) |
| :--- | :--- | :--- |
| **Напрямок струму** | Вздовж площини шарів | Перпендикулярно до шарів |
| **Амплітуда GMR (300 K)** | 8 – 15% (до 20% з NOL) | 30 – 60% |
| **Питома характеристика опору** | Поверхневий опір `R_□ ≈ 15–30` Ом/□ | Добуток `RA ≈ 0.02–0.08` Ом·мкм² |
| **Типовий опір компонента** | `500 Ом – 10 кОм` | `10 – 50 Ом` (для наностовпчика) |
| **Шунтування проміжкою Cu** | Сильне (до 60% струму) | Повністю відсутнє (0%) |
| **Характерний масштаб переносу** | Довжина пробігу `λ_p` (1–10 нм) | Спін-дифузійна довжина `l_sf` (50–200 нм) |
| **Межа літографічного масштабування** | > 100 нм (неефективний на наномасштабах) | < 30 нм (ідеальний для субмікрона) |
| **Паразитні ефекти струму** | Відсутні | STT-шум, джоулів перегрів, електродифузія |
| **Технологічна складність** | Стандартна планарна фотолітографія | Субмікронне травлення наностовпчиків (IBE) |
| **Основна сфера застосування** | Промислові та автомобільні сенсори | Зчитувальні голівки HDD > 200 Гбіт/дюйм² |

## Порівняльний аналіз магніторезистивних технологій: AMR, GMR та TMR

Спінові клапани GMR займають проміжне, але критично важливе інженерне положення між класичними анізотропними магніторезисторами (AMR) та магнітними тунельними контактами (TMR).

```
AMR (Анізотропний магнітоопір)    GMR (Гігантський магнітоопір)       TMR (Тунельний магнітоопір)
Одношаровий пермалой NiFe          Металевий спіновий клапан          Магнітний тунельний перехід
Ефект: спін-орбітальна взаємодія   Ефект: спін-залежне розсіювання    Ефект: спін-поляризоване тунелювання
ΔR/R: 1 – 3%                       ΔR/R: 10 – 20% (CIP), 50% (CPP)    ΔR/R: 100 – 300%
```

### 1. Анізотропний магнітоопір (AMR: Anisotropic Magnetoresistance)
- **Фізичний механізм:** Внутрішньоатомна релятивістська спін-орбітальна взаємодія у масивній плівці пермалою `Ni₈₀Fe₂₀` товщиною `20–40` нм. Опір залежить від кута `θ` між вектором густини струму `J` та вектором намагніченості `M`: `ρ(θ) = ρ_⊥ + Δρ · cos²(θ)`.
- **Характеристики:** Низька амплітуда відгуку `ΔR/R ≈ 2–3%`. Для лінеаризації вимагає формування смужок Барбера (золоті смужки під кутом 45° на поверхні).
- **Переваги та недоліки:** Надзвичайно простий і дешевий у виробництві (одношарове напилення, 1 маска літографії), мінімальний рівень низькочастотного флікер-шуму `1/f`. Проте низька чутливість (`0.5–1.0` мВ/В/мТл) обмежує застосування грубими геомагнітними компасами та датчиками кута повороту.

### 2. Спінові клапани GMR (Giant Magnetoresistance Spin Valves)
- **Фізичний механізм:** Спін-залежне інтерфейсне та об'ємне розсіювання `4s`-електронів провідності при переході між шарами `FM / Cu / FM`. Опір залежить від кута `θ` між векторами намагніченостей двох шарів: `R(θ) = R_0 - (ΔR_GMR / 2) · cos θ`.
- **Характеристики:** Відносна зміна опору `ΔR/R ≈ 10–20%` (CIP) та до `40–60%` (CPP). Чутливість мостових схем досягає `3.0–5.0` мВ/В/мТл.
- **Переваги:** Суцільнометалева структура забезпечує виняткову стійкість до електричного пробою (ESD, Electrostatic Discharge) та напругових перевантажень. Низький питомий опір і відсутність діелектричних бар'єрів гарантують надшироку смугу пропускання частот (понад `1–2` ГГц), що робить GMR ідеальним для високошвидкісних безконтактних вимірювачів струму, енкодерів та промислової автоматики.

### 3. Тунельний магнітоопір (TMR: Tunneling Magnetoresistance)
- **Фізичний механізм:** Спін-поляризоване квантовомеханічне тунелювання електронів крізь надтонкий діелектричний бар'єр оксиду магнію: `CoFeB (110) / MgO (001) / CoFeB (110)` товщиною `0.8–1.5` нм. Завдяки ефекту когерентної фільтрації хвильових функцій електронів із симетрією `Δ₁` у кристалічному бар'єрі `MgO(001)` тунельна прозорість для мажоритарних спінів на порядок перевищує прозорість для міноритарних.
- **Характеристики:** Рекордна амплітуда `ΔR/R ≈ 100–300%` при кімнатній температурі (і понад `600%` при `4.2 K`). Чутливість датчиків перевищує `20–80` мВ/В/мТл.
- **Недоліки:** Високий рівень низькочастотного шуму `1/f` через пастки заряду в бар'єрі `MgO`; підвищений дробовий шум (shot noise); критична чутливість до електростатичного пробою бар'єра при напругах `V > 0.8–1.2` В; складна й дорога технологія напилення бар'єра з точністю до `0.02` нм.

## Технологія магнетронного напилення та відпалу

Виготовлення промислових спінових клапанів вимагає атомарного контролю товщини та субнанометрової гладкості кожного шару. У промисловості застосовують надвисоковакуумні кластерні комплекси магнетронного напилення постійного (`DC`) та високочастотного (`RF`) струму з автоматизованою шлюзовою системою.

Основні фізико-хімічні вимоги до технологічного циклу:
1. **Базовий вакуум:** Залишковий тиск у ростовій камері перед початком напилення підтримується на рівні не вище `10⁻⁸–10⁻⁹` Торр (`10⁻⁶–10⁻⁷` Па). Парціальний тиск кисню та водяної пари не повинен перевищувати `10⁻¹⁰` Торр, інакше ультратонкі шари кобальту та міді зазнають неконтрольованого окислення, що блокує формування квантових станів на межі поділу.
2. **Контроль міжфазної шорсткості:** Середньоквадратична шорсткість підкладки та інтерфейсних меж `RMS` підтримується на рівні `RMS < 0.15–0.20` нм. Перевищення цього рівня експоненціально підсилює топологічний зв'язок Неєля і руйнує антиферомагнітний RKKY-зв'язок у SAF-тришаровиках.
3. **Термомагнітний вакуумний відпал:** Після завершення осадження кремнієві пластини переносять у спеціалізовану вакуумну піч із безградієнтним магнітним полем `0.5–1.0` Тл. Відпал проводять при температурі `260–300 °C` протягом `2–4` годин із подальшим повільним охолодженням (`~1 °C/хв`). Цей крок є критичним для:
   - Фазового переходу антиферомагнетика `PtMn` у високостабільну магнітну фазу `L1_0`;
   - Фіксації єдиного вектора поля обмінного зсуву `H_ex` для шарів `FM1` по всій площі 200/300-мм пластини;
   - Зняття внутрішніх механічних напружень у плівках та релаксації дислокацій кристалічної ґратки.
