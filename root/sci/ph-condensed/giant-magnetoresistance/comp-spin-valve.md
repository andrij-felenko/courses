# 🔌 Спиновий клапан: шарова структура та екранний обмінний зсув

Спиновий клапан є тонкоплівковою металевою гетероструктурою, у якій орієнтація намагніченості одного з феромагнітних шарів жорстко зафіксована антиферомагнетиком, тоді як намагніченість другого шару вільно повертається під дією слабких зовнішніх магнітних полів. На відміну від перших суперґраток Fe/Cr, де для зміни опору вимагалося подолання міцного антиферомагнітного RKKY-зв'язку по всій площі структури, спиновий клапан розділяє функції шарів: один відповідає за створення опорного магнітного стану, а другий слугує чутливим елементом для вимірювання поля.

## Архітектура нанорозмірної багатошарової структури

Типовий промисловий спиновий клапан складається з 6–8 послідовно напилених нанорозмірних металевих шарів, кожен із яких виконує суворо визначену фізико-технологічну роль. 

```
┌─────────────────────────────────────────────────────────┐
│ Захисний шар (Cap Layer): Ta / Ru (2–4 нм)              │  ← Запобігає окисленню
├─────────────────────────────────────────────────────────┤
│ Вільний шар (Free Layer): Ni₈₀Fe₂₀ / CoFe (2–4 нм)     │  ← Повертається від поля H
├─────────────────────────────────────────────────────────┤
│ Проміжка (Spacer): Cu (2.0–2.4 нм)                      │  ← Спін-зберігаючий місток
├─────────────────────────────────────────────────────────┤
│ Закріплений шар (Pinned Layer): Co₉₀Fe₁₀ (2–3 нм)       │  ← Зафіксована намагніченість
├─────────────────────────────────────────────────────────┤
│ Антиферомагнетик (AFM Pinning): Ir₂₀Mn∸₀ (6–10 нм)      │  ← Створює exchange bias
├─────────────────────────────────────────────────────────┤
│ Буферний шар (Seed Layer): Ta / NiFeCr (3–5 нм)         │  ← Формує кристалічну текстуру
├─────────────────────────────────────────────────────────┤
│ Підкладка: Кремній із оксидом (Si / SiO₂ / Al₂O₃)      │
└─────────────────────────────────────────────────────────┘
```

1. **Буферний шар (Seed Layer):** Тонка плівка танталу (`Ta`) або нікель-хрому (`NiFeCr`). Вона вирівнює аморфну поверхню підкладки та формує бажану кристалографічну текстуру `(111)` у гранецентрованій кубічній (ГЦК) ґратці наступних шарів. Така текстура є кристалографічною вимогою для виникнення максимального обмінного зсуву у марганцевмісних антиферомагнетиках.
2. **Антиферомагнітний шар (AFM Pinning Layer):** Сплави іридію та марганцю (`Ir₂₀Mn₈₀`) або платини та марганцю (`Pt₅₀Mn₅₀`). Цей шар володіє антиферомагнітним порядком із некомпенсованими спінами на поверхні і слугує джерелом екранного обмінного зсуву. Сплав `IrMn` володіє високою константою міжфазного зсуву, а `PtMn` забезпечує відмінну термічну стабільність при нагріванні понад `200 °C`.
3. **Закріплений шар (Pinned Layer):** Сплав кобальту та заліза (`Co₉₀Fe₁₀`). Його вектор намагніченості утримується у фіксованому напрямку завдяки прямій обмінній взаємодії з атомними спінами поверхні антиферомагнетика. Сплав `CoFe` вибирається через високу спінову поляризацію електронів провідності та значний коефіцієнт спінової асиметрії `β`.
4. **Немагнітна проміжка (Non-magnetic Spacer):** Плівка надчистої міді (`Cu`) товщиною точно `2.0–2.4` нм. Товщина вибирається на основі двох протилежних вимог: вона має бути достатньо великою, щоб ослабити прямий феромагнітний зв'язок між шарами, але меншою за довжину збереження спінової пам'яті в міді (`λ_spin > 100` нм), щоб електрони переносили спінову інформацію без розсіювання.
5. **Вільний шар (Free Layer):** Магнітном'який двошаровий сплав `CoFe (0.5 нм) / Ni₈₀Fe₂₀ (3 нм)` (пермалой). Вставка з кобальт-заліза на межі з міддю забезпечує високе поверхневе розсіювання спінів, а товстий шар пермалою гарантує низьку коерцитивну силу (`H_c < 0.5` мТл) та нульову магнітострикцію.
6. **Захисний шар (Cap Layer):** Шари танталу (`Ta`) або рутенію (`Ru`), які захищають спиновий клапан від атмосферного окислення та деградації при наступних технологічних відпалах.

## Фізика екранного обмінного зсуву (Exchange Bias)

Екранний обнійний зсув виникає на межі поділу між антиферомагнетиком та феромагнетиком у результаті квантовомеханічної обмінної взаємодії між локалізованими спінами. 

```
               Охолодження у полі H (T > T_B → T < T_B)
               
Антиферомагнетик (AFM)                   Феромагнетик (FM)
┌─────────────────────────────┐         ┌─────────────────────────────┐
│  ↑  ↓  ↑  ↓  ↑  ↓  ↑  ↓  ↑  │         │  →  →  →  →  →  →  →  →  →  │
│  ↓  ↑  ↓  ↑  ↓  ↑  ↓  ↑  ↓  │         │  →  →  →  →  →  →  →  →  →  │
│  ↑  ↓  ↑  ↓  ↑  ↓  ↑  ↓  ↑  │ ◄──────►│  →  →  →  →  →  →  →  →  →  │
└─────────────────────────────┘         └─────────────────────────────┘
  Атомні спіни зафіксовані                Вектор намагніченості M
  у підґратках (Net M = 0)                орієнтований уздовж поля H
```

Процес формування обмінного зсуву вимагає термомагнітної обробки. Структуру нагрівають вище температури Блокування антиферомагнетика (`T_B`, яка залежить від товщини шару і для `IrMn` становить близько `250–280 °C`, що нижче за температуру Неєля `T_N`), але нижче температури Кюрі феромагнетика. У цьому стані антиферомагнетик втрачає міжфазне закріплення.

При прикладанні сильного зовнішнього магнітного поля (близько `0.5–1.0` Тл) вектор намагніченості феромагнетика `M` повністю орієнтується уздовж поля. Під час повільного охолодження гетероструктури крізь точку `T_B` нескомпенсовані спіни поверхневого атомного шару антиферомагнетика замикаються у напрямку намагніченості феромагнетика через прямий обмінний інтеграл `J_ex`.

Після повернення до кімнатної температури жорстка антиферомагнітна матриця утримує свої поверхневі спіни. При спробі розвернути намагніченість феромагнетика зовнішнім протилежним полем, поверхневі спіни антиферомагнетика створюють утримувальний обмінний момент. Це еквівалентно дії додаткового внутрішнього магнітного поля — поля обмінного зсуву `H_ex`:

```
H_ex = J_ex / (M_FM · d_FM)                                             [величина поля обмінного зсуву]
```

де `M_FM` та `d_FM` — намагніченість насичення та товщина феромагнітного шару. В результаті петля гістерезису закріпленого шару асиметрично зміщується по осі полів на величину `H_ex` (зазвичай від `30` до `100` мТл).

## Синтетичний антиферомагнетик (SAF)

У сучасних високоточних спинових клапанах замість молітарного закріпленого шару використовують тришарову систему — синтетичний антиферомагнетик (Synthetic Antiferromagnet, SAF): `CoFe(1) / Ru (0.8 нм) / CoFe(2)`.

```
           Синтетичний антиферомагнетик (SAF)
┌─────────────────────────────────────────────────────────┐
│  CoFe (2) шар: намагніченість M₂ (←)                    │
├─────────────────────────────────────────────────────────┤
│  Ru проміжка (0.8 нм): Перший антиферомагнітний максимум│
├─────────────────────────────────────────────────────────┤
│  CoFe (1) шар: намагніченість M₁ (→)                    │
├─────────────────────────────────────────────────────────┤
│  IrMn шар: антиферомагнітне закріплення                 │
└─────────────────────────────────────────────────────────┘
```

Товщина рутенію (`0.8` нм) вибирається з високою точністю (±0.05 нм), що відповідає першому антиферомагнітному максимуму осциляцій RKKY-взаємодії. Завдяки цьому між шарами `CoFe(1)` та `CoFe(2)` виникає потужний міжшаровий обмінний зв'язок, який примушує їхні магнітні моменти орієнтуватися строго антипаралельно один до одного.

Використання SAF надає три вирішальні переваги:
- **Замикання магнітного потоку (Flux Closure):** Якщо товщини шарів підібрані так, що їхні магнітні моменти рівні (`M₁·d₁ = M₂·d₂`), результуючий магнітний момент SAF-структури дорівнює нулю. Це повністю усуває паразитичні поля розсіювання від країв закріпленого шару, які в одношарових конструкціях викликали небажане підмагнічування вільного шару.
- **Гігантське поле закріплення:** Ефективне поле розкріплення `H_ex` зростає у 3–5 разів і може перевищувати `200–300` мТл, оскільки зовнішнє поле не може ефективно зачепитися за компенсовану магнітну структуру.
- **Термічна стабільність:** Конструкція є стійкою до розмагнічування при підвищених робочих температурах (до `150–200 °C`) та дії сильних магнітних завад.

## Геометрії CIP та CPP

За залежністю напрямку електричного струму відносно площини шарів спинові клапани поділяють на дві геометричні конфігурації:

```
CIP (Current-in-Plane)                CPP (Current-Perpendicular-to-Plane)
Струм вздовж шарів                    Струм перпендикулярно до шарів

       I ───►                                  │ I
┌──────────────────┐                   ┌──────────────────┐
│    Вільний FM    │                   │    Вільний FM    │
├──────────────────┤                   ├──────────────────┤
│    Spacer Cu     │                   │    Spacer Cu     │
├──────────────────┤                   ├──────────────────┤
│  Закріплений FM  │                   │  Закріплений FM  │
└──────────────────┘                   └──────────────────┘
       I ───►                                  │ ▼
```

- **CIP (Current-In-Plane):** Електричний струм подається через бічні контакти і тече вздовж площини шарів. Електрони багатократно перетинають межі поділу завдяки рикошетному розсіюванню. Величина GMR становить `8–15%`. Проста у виготовленні геометрія, яка вимагає порівняно низького опору пристрою (`10–100 Ом`), що застосовувалася у зчитувальних голівках HDD першого покоління.
- **CPP (Current-Perpendicular-to-Plane):** Струм підводиться до верхнього та нижнього контактів і тече перпендикулярно до площини шарів. Усі електрони обов'язково проходять через кожен шар гетероструктури. Величина GMR досягає `20–40%`. Необхідна для ультрамалих датчиків із площею менше `100×100` нм, проте вимагає складних наностовпчикових фотолітографічних процесів та урахування опору лід-фрейму.

## Технологія магнетронного напилення та відпалу

Виготовлення спинових клапанів вимагає атомарного контролю товщини та шорсткості кожного шару. У промисловості використовується метод надвисоковакуумного магнетронного напилення (*DC/RF Magnetron Sputtering*) на постійному струмі. 

Основні вимоги до технологічного процесу:
- **Базовий вакуум:** Тиск залишкових газів у ростовій камері не повинен перевищувати `10⁻⁸–10⁻⁹` Торр для запобігання окисленню надтонких шарів міді та кобальту.
- **Контроль шорсткості:** Середньоквадратична шорсткість підкладки та міжфазних меж `RMS` повинна бути меншою за `0.2` нм. Перевищення шорсткості викликає локальне неєлівське зчеплення («Orange-peel coupling») між вільним та закріпленим шарами, що погіршує чутливість.
- **Магнітний відпал:** Після напилення пластини піддають вакуумному відпалу при температурі `250–300 °C` протягом 2–4 годин у однорідному магнітному полі `0.5–1.0` Тл для формування кристалічної структури `PtMn/IrMn` та фіксації напрямку `H_ex`.
