# 🧮 Двоканальна модель Мотта та розрахунок коефіцієнта GMR

Аналітичний опис ефекту гігантського магнітоопору спирається на теоретичну концепцію двох незалежних каналів провідності, висунуту Невіллом Моттом у 1936 році для розрахунку електропереносу у феромагнітних 3d-металах. За температур, значно нижчих за температуру Кюрі (`T ≪ T_C`), частота процесів розсіювання із переворотом спіна (взаємодія електронів із тепловими магнонами та спін-орбітальне розсіювання) є на кілька порядків меншою за частоту пружного розсіювання на домішках, дефектах ґратки та фононах. У цьому наближенні струм провідності розпадається на два незалежні паралельні потоки: носії зі спіном «вгору» (`↑`, мажоритарні носії) та зі спіном «вниз» (`↓`, міноритарні носії).

Розглянемо послідовний мікроскопічний квантовомеханічний та кінетичний вивід двоканальної провідності, починаючи від розсіювання електронів у розщепленій обмінною взаємодією зонній структурі перехідних металів, еквівалентних резистивних схем багатошарових систем, напівкласичної кінетичної моделі Кемлі — Барнася для геометрії струму у площині шарів (CIP) та одновимірної дифузійної теорії Валета — Ферта для перпендикулярного струму (CPP).

## Фізичні передумови та розділення каналів провідності

У немагнітному металі за відсутності магнітного поля підзони електронів із протилежними проєкціями спіна є енергетично виродженими, а їхні густини станів — тотожними: `D_↑(E) = D_↓(E)`. У феромагнетиках (Fe, Co, Ni та їхніх сплавах) квантова обмінна взаємодія знімає це виродження, зсуваючи підзони одна відносно одної на енергію обмінного розщеплення `ΔE_ex`.

Головне кінетичне припущення моделі Мотта полягає у співвідношенні між двома фундаментальними часовими масштабами розсіювання носіїв заряду:

```
τ_p   ≈ 10⁻¹⁴ с        [час релаксації за імпульсом / транспортний час]
τ_sf  ≈ 10⁻¹¹–10⁻¹² с   [час релаксації за спіном / spin-flip time]
```

Оскільки час збереження спінової поляризації перевищує час релаксації за імпульсом на два-три порядки:

```
τ_sf ≫ τ_p             [критерій незалежності спінових каналів Мотта]
```

електрон зазнає сотень або тисяч пружних зіткнень зі збереженням проєкції свого магнітного моменту (`Δs = 0`), перш ніж відбудеться одиничний акт перевороту спіна (`↑ ↔ ↓`). Відповідно, просторовий масштаб збереження спінової пам'яті — довжина спінової дифузії `l_sf` — визначається через коефіцієнт дифузії `D = v_F · λ_p / 3`:

```
l_sf = √(D · τ_sf) = √((1/3) · v_F · λ_p · τ_sf)     [довжина спінової дифузії]
```

Для міді (`Cu`) довжина спінової дифузії при кімнатній температурі перевищує `100–300` нм, а для феромагнітних шарів кобальту (`Co`) чи пермалою (`Ni₈₀Fe₂₀`) становить `20–50` нм. Якщо товщина кожного окремого шару `d` у гетероструктурі та повна товщина всієї структури є значно меншими за `l_sf` (`d ≪ l_sf`), електрон перетинає всі шари та міжфазні межі без втрати спінової пам'яті.

Мікроскопічним джерелом спін-фліп переходів у металах із центросиметричною кристалічною ґраткою є механізм Елліотта — Яфета (Elliott — Yafet mechanism). Внаслідок спін-орбітальної взаємодії блохівські хвильові функції містять малу домішку протилежної спінової проєкції:

```
ψ_k,↑(r) = [ u_k,↑(r) · |↑⟩ + (λ_SO / ΔE_g) · u_k,↓(r) · |↓⟩ ] · exp(i·k·r)
```

де `λ_SO` — константа спін-орбітального зв'язку, а `ΔE_g` — енергетична щілина до сусідніх зон. Під час кожного акту пружного розсіювання на домішці або фононі існує скінченна ймовірність `(λ_SO / ΔE_g)²` перевороту спіна. Частота спін-фліп релаксації пропорційна звичайній частоті розсіювання імпульсу:

```
1 / τ_sf = α_EY · (Δg)² · (1 / τ_p)                   [співвідношення Елліотта — Яфета]
```

де `Δg = g - 2.0023` — зсув g-фактора електрона відносно вільного електрона, а `α_EY` — безрозмірний коефіцієнт порядку одиниці. Оскільки у легких перехідних і благородних металах `(Δg)² ≈ 10⁻³–10⁻⁴`, час `τ_sf` виявляється у сотні й тисячі разів більшим за `τ_p`.

За цієї умови повна густина електричного струму `j` строго дорівнює сумі двох парціальних густин струму, а питома електропровідність `σ` є сумою парціальних провідностей:

```
j = j_↑ + j_↓ = (σ_↑ + σ_↓) · E
σ = σ_↑ + σ_↓                                       [адитивність спінових провідностей]
```

де `E` — напруженість прикладеного електричного поля, а `σ_↑` та `σ_↓` — провідності підсистем мажоритарних та міноритарних носіїв.

## Мікроскопічний механізм: s-d розсіювання за золотим правилом Фермі

Провідність 3d-перехідних феромагнітних металів формується двома групами електронів із кардинально різними характеристиками:

1. **Рухливі `4s`-електрони:** Мають малу ефективну масу (`m_s^* ≈ m_0`), високу швидкість Фермі (`v_Fs ≈ 10⁶` м/с) та широку майже вільну зону дисперсії `E(k) = ℏ²·k² / (2·m_s^*)`. Густина станів `D_4s(E_F)` на рівні Фермі є низькою. Понад 90% повного електричного струму переносять саме `4s`-носії.
2. **Локалізовані `3d`-електрони:** Утворюють вузькі сильно розщеплені зони з великою ефективною масою (`m_d^* ≈ 5–10·m_0`) та майже нульовою груповою швидкістю `v_gd = (1/ℏ) · (∂E/∂k) ≈ 0`. Вони майже не переносять електричного заряду, але мають гігантську густину станів `D_3d(E_F)` на рівні Фермі.

Згідно з квантовомеханічним золотим правилом Фермі, частота пружного розсіювання електрона `1/τ` з початкового стану `|i⟩ = |4s, k, s⟩` у множину кінцевих станів `|f⟩ = |k', s'⟩` на ізоенергетичній поверхні Фермі визначається матричним елементом оператора збурення потенціалу розсіювання `V_pert` та густиною доступних кінцевих станів `D(E_F)`:

```
1/τ = (2·π / ℏ) · |⟨f| V_pert |i⟩|² · D(E_F)         [золоте правило Фермі]
```

Оскільки пружне розсіювання на немагнітних домішках і дефектах зберігає спін (`s' = s`), переходи можливі лише між станами з однаковою спіновою проєкцією. Повна частота розсіювання `4s`-електрона складається з внутрішньозонного `s-s` розсіювання та міжзонного `s-d` розсіювання за правилом Матіссена:

```
1/τ_↑ = 1/τ_ss↑ + 1/τ_sd↑ = (2·π / ℏ) · [ |M_ss|² · D_4s↑(E_F) + |M_sd|² · D_3d↑(E_F) ]
1/τ_↓ = 1/τ_ss↓ + 1/τ_sd↓ = (2·π / ℏ) · [ |M_ss|² · D_4s↓(E_F) + |M_sd|² · D_3d↓(E_F) ]
```

Оскільки густина станів у d-зоні на два порядки перевищує густину станів у s-зоні (`D_3d(E_F) ≫ D_4s(E_F)`), домінуючим каналом релаксації імпульсу є саме переходи `s → d`. Внутрішньозонним внеском `s-s` можна з високою точністю знехтувати:

```
1/τ_↑ ≈ (2·π / ℏ) · |M_sd|² · D_3d↑(E_F)
1/τ_↓ ≈ (2·π / ℏ) · |M_sd|² · D_3d↓(E_F)
```

Внаслідок внутрішньоатомної квантової обмінної взаємодії Стонера підзона електронів зі спіном «вгору» (`↑`) опускається нижче рівня Фермі на величину `ΔE_ex ≈ 1.0–2.0` еВ і виявляється майже або повністю заповненою:

```
D_3d↑(E_F) ≈ 0 ──► 1/τ_↑ мінімальна ──► τ_↑ великий ──► λ_↑ = v_Fs · τ_↑ велика (10–20 нм)
```

Натомість підзона міноритарних електронів зі спіном «вниз» (`↓`) зміщується вгору, і рівень Фермі перетинає найщільнішу ділянку d-піка:

```
D_3d↓(E_F) ≫ D_3d↑(E_F) ──► 1/τ_↓ максимальна ──► τ_↓ малий ──► λ_↓ = v_Fs · τ_↓ мала (1–2 нм)
```

За класичною формулою Друде питомий опір кожного спінового каналу обернено пропорційний часу релаксації:

```
ρ_↑ = m_s^* / (n_↑ · e² · τ_↑) ∝ D_3d↑(E_F)
ρ_↓ = m_s^* / (n_↓ · e² · τ_↓) ∝ D_3d↓(E_F)
```

де `n_↑` та `n_↓` — густини `s`-електронів відповідної спінової орієнтації (`n_↑ ≈ n_↓ ≈ n/2`). Звідси безпосередньо випливає фундаментальна нерівність питомих опорів: `ρ_↓ ≫ ρ_↑`.

## Спінова асиметрія питомого опору феромагнетика

Для кількісного опису різниці провідностей двох каналів використовують два еквівалентні безрозмірні параметри:

1. **Коефіцієнт відношення парціальних питомих опорів `α`:**
   ```
   α = ρ_↓ / ρ_↑ = σ_↑ / σ_↓ = τ_↑ / τ_↓ = λ_↑ / λ_↓     [α ≥ 1]
   ```

2. **Коефіцієнт спінової асиметрії питомого опору `β`:**
   ```
   β = (ρ_↓ - ρ_↑) / (ρ_↓ + ρ_↑) = (α - 1) / (α + 1)     [0 ≤ β < 1]
   ```

Зв'язок між параметрами `α` та `β` встановлюється прямим алгебраїчним перетворенням:

```
β = (α - 1) / (α + 1)
β · (α + 1) = α - 1
β·α + β = α - 1
1 + β = α · (1 - β)
α = (1 + β) / (1 - β)                                  [вираз α через параметр β]
```

Виразимо парціальні питомі опори каналів через середній питомий опір `ρ_0` неполяризованого металу у парамагнітному стані (`ρ_0 = (ρ_↑ + ρ_↓) / 4` за паралельного з'єднання):

```
ρ_↑ = 2·ρ_0·(1 - β)     [питомий опір мажоритарного каналу]
ρ_↓ = 2·ρ_0·(1 + β)     [питомий опір міноритарного каналу]
```

Розрахуємо сумарний питомий опір монолітного феромагнетика `ρ_tot`:

```
1/ρ_tot
= 1/ρ_↑ + 1/ρ_↓                                       [додавання паралельних провідностей]
= 1 / [2·ρ_0·(1 - β)] + 1 / [2·ρ_0·(1 + β)]           [підстановка виразів через β]
= [ (1 + β) + (1 - β) ] / [ 2·ρ_0·(1 - β)·(1 + β) ]   [зведення до спільного знаменника]
= 2 / [ 2·ρ_0·(1 - β²) ]                              [спрощення чисельника та знаменника]
= 1 / [ ρ_0·(1 - β²) ]

ρ_tot = ρ_0·(1 - β²)                                  [повний питомий опір феромагнетика]
```

У чистому кобальті (`Co`) параметр `α ≈ 3–5` (`β ≈ 0.5–0.66`), у нікелі (`Ni`) `α ≈ 5–8` (`β ≈ 0.66–0.78`), а у сплавах `Co₉₀Fe₁₀` параметр `α` сягає `8–15` (`β ≈ 0.78–0.875`).

## Розрахунок опору двошарової структури FM1 / NM / FM2

Розглянемо тришарову гетероструктуру `FM1 / NM / FM2`, що складається з двох однакових феромагнітних шарів завтовшки `d_FM` та площею поперечного перерізу `S`, розділених надтонким немагнітним проміжком `NM` завтовшки `d_NM < l_sf`.

Позначимо базовий геометричний опір одного феромагнітного шару без урахування магнітної асиметрії як `r_0 = ρ_0 · d_FM / S`. Тоді парціальні опори одного шару для електронів зі спіном «вгору» та «вниз» дорівнюють:

```
r_↑ = r_0 · (1 - β)     [опір шару для мажоритарних носіїв]
r_↓ = r_0 · (1 + β)     [опір шару для міноритарних носіїв]
```

де `r_↓ > r_↑` внаслідок підвищеного `s-d` розсіювання міноритарних носіїв.

### Паралельний стан намагніченості (P)

У паралельному стані намагніченості обох шарів спрямовані колінеарно в один бік (`FM1 ↑ / FM2 ↑`).
- **Канал спін-вгору (`↑`):** Електрони є мажоритарними в обох шарах. Вони зазнають слабкого розсіювання в першому (`r_↑`) і другому (`r_↑`) шарах. Повний послідовний опір гілки:
  ```
  R_up = r_↑ + r_↑ = 2·r_↑ = 2·r_0·(1 - β)
  ```
- **Канал спін-вниз (`↓`):** Електрони є міноритарними в обох шарах і зазнають сильного розсіювання в обох шарах (`r_↓`). Повний послідовний опір гілки:
  ```
  R_down = r_↓ + r_↓ = 2·r_↓ = 2·r_0·(1 + β)
  ```

Оскільки обидва канали з'єднані паралельно, еквівалентний електричний опір `R_P` розраховується за правилом паралельних віток:

```
R_P
= (R_up · R_down) / (R_up + R_down)                   [формула паралельного з'єднання]
= [ 2·r_↑ · 2·r_↓ ] / [ 2·r_↑ + 2·r_↓ ]               [підстановка послідовних опорів]
= 4·r_↑·r_↓ / [ 2·(r_↑ + r_↓) ]                       [винесення двійки у знаменнику]
= 2·r_↑·r_↓ / (r_↑ + r_↓)                             [скорочення на 2]
= [ 2 · r_0·(1 - β) · r_0·(1 + β) ] / [ r_0·(1 - β) + r_0·(1 + β) ]
= [ 2·r_0²·(1 - β²) ] / [ 2·r_0 ]                     [розкриття дужок]
= r_0 · (1 - β²)                                      [опір стану P через r_0 та β]
```

Якщо позначити загальний опір структури у неполяризованому парамагнітному стані як `2·R_0` (де `R_0 = r_0 / 2` — опір двох паралельних шарів при `β = 0`), вираз набуває стандартного вигляду:

```
R_P = 2·R_0·(1 - β²)
```

У стані P низькоомний мажоритарний канал `2·r_↑` діє як шунт короткого замикання: майже весь електричний струм тече крізь нього практично без розсіювання, забезпечуючи мінімальний загальний опір структури.

### Антипаралельний стан намагніченості (AP)

В антипаралельному стані намагніченість першого шару спрямована вгору, а другого — вниз (`FM1 ↑ / FM2 ↓`).
- **Канал спін-вгору (`↑`):** У першому шарі електрони є мажоритарними (опір `r_↑`), але при переході у другий шар вони стають міноритарними і зазнають інтенсивного розсіювання (опір `r_↓`). Повний послідовний опір гілки:
  ```
  R_up = r_↑ + r_↓ = r_0·(1 - β) + r_0·(1 + β) = 2·r_0
  ```
- **Канал спін-вниз (`↓`):** У першому шарі електрони є міноритарними (опір `r_↓`), а у другому шарі — мажоритарними (опір `r_↑`). Повний послідовний опір гілки:
  ```
  R_down = r_↓ + r_↑ = r_0·(1 + β) + r_0·(1 - β) = 2·r_0
  ```

Обидві гілки набувають однакового високого опору `2·r_0`. Шунтуючий ефект повністю зникає, оскільки кожен носій обов'язково зазнає сильного розсіювання в одному з двох феромагнітних шарів. Еквівалентний опір `R_AP` становить:

```
R_AP
= (R_up · R_down) / (R_up + R_down)                   [паралельне з'єднання гілок]
= (2·r_0 · 2·r_0) / (2·r_0 + 2·r_0)                   [підстановка однакових опорів 2·r_0]
= 4·r_0² / (4·r_0)                                    [спрощення дробу]
= r_0                                                 [опір стану AP через r_0]
= (r_↑ + r_↓) / 2                                     [опір через парціальні опори r_↑ та r_↓]
= 2·R_0                                               [опір стану AP через базовий опір R_0]
```

## Покрокове виведення коефіцієнта GMR

Розрахуємо абсолютну зміну електричного опору `ΔR = R_AP - R_P` при переході системи від антипаралельного до паралельного магнітного стану:

```
ΔR
= R_AP - R_P
= (r_↑ + r_↓)/2 - 2·r_↑·r_↓/(r_↑ + r_↓)               [підстановка виразів для R_AP та R_P]
= [ (r_↑ + r_↓)² - 4·r_↑·r_↓ ] / [ 2·(r_↑ + r_↓) ]     [зведення дробів до спільного знаменника]
= [ r_↑² + 2·r_↑·r_↓ + r_↓² - 4·r_↑·r_↓ ] / [ 2·(r_↑ + r_↓) ] [розкриття повного квадрата суми]
= [ r_↑² - 2·r_↑·r_↓ + r_↓² ] / [ 2·(r_↑ + r_↓) ]     [зведення подібних доданків]
= (r_↓ - r_↑)² / [ 2·(r_↑ + r_↓) ]                    [згортання у квадрат різниці]
```

Підставивши вирази `R_AP = r_0` та `R_P = r_0·(1 - β²)`, отримуємо компактну формулу абсолютної зміни опору:

```
ΔR = r_0 - r_0·(1 - β²) = r_0·β² = 2·R_0·β²
```

Оскільки різниця `(r_↓ - r_↑)²` стоїть у квадраті, абсолютна зміна `ΔR` є строго додатною за будь-якої асиметрії розсіювання (`β ≠ 0`). Опір антипаралельного стану завжди строго перевищує опір паралельного стану (`R_AP > R_P`).

### Виведення формули через параметр анізотропії β

У фізиці магнітних явищ та спінтроніці коефіцієнт гігантського магнітоопору найчастіше визначають відносно опору низькоомного паралельного стану `GMR_P = (R_AP - R_P) / R_P` (так звана «оптимістична» шкала):

```
GMR_P
= (R_AP - R_P) / R_P
= [ (r_↓ - r_↑)² / (2·(r_↑ + r_↓)) ] / [ (2·r_↑·r_↓) / (r_↑ + r_↓) ]
= [ (r_↓ - r_↑)² / (2·(r_↑ + r_↓)) ] · [ (r_↑ + r_↓) / (2·r_↑·r_↓) ]
= (r_↓ - r_↑)² / (4·r_↑·r_↓)                          [скорочення спільного множника (r_↑ + r_↓)]
```

Підставимо у знайдений вираз `r_↑ = r_0·(1 - β)` та `r_↓ = r_0·(1 + β)`:

```
r_↓ - r_↑ = r_0·(1 + β) - r_0·(1 - β) = 2·β·r_0
r_↑ · r_↓ = r_0² · (1 - β²)

GMR_P
= (2·β·r_0)² / [ 4 · r_0²·(1 - β²) ]
= (4·β²·r_0²) / [ 4·r_0²·(1 - β²) ]                  [піднесення до квадрата]
= β² / (1 - β²)                                       [фундаментальна формула GMR через β]
```

### Виведення через відношення парціальних опорів α

Виразимо коефіцієнт `GMR_P` безпосередньо через коефіцієнт асиметрії опорів `α = ρ_↓ / ρ_↑`:

```
β² = [ (α - 1) / (α + 1) ]² = (α - 1)² / (α + 1)²

1 - β²
= 1 - (α - 1)² / (α + 1)²
= [ (α + 1)² - (α - 1)² ] / (α + 1)²                  [зведення до спільного знаменника]
= [ (α² + 2·α + 1) - (α² - 2·α + 1) ] / (α + 1)²      [розкриття квадратів]
= [ α² + 2·α + 1 - α² + 2·α - 1 ] / (α + 1)²
= 4·α / (α + 1)²                                      [результат для знаменника]
```

Ділимо `β²` на `(1 - β²)`:

```
GMR_P
= [ (α - 1)² / (α + 1)² ] / [ 4·α / (α + 1)² ]
= [ (α - 1)² / (α + 1)² ] · [ (α + 1)² / (4·α) ]
= (α - 1)² / (4·α)                                    [формула GMR через відношення α]
```

Аналіз отриманого виразу для різних діапазонів `α`:
- При `α = 1` (`β = 0`, розсіювання симетричне): `GMR_P = (1 - 1)² / 4 = 0` (ефект повністю відсутній).
- При `α = 3` (`β = 0.5`): `GMR_P = (3 - 1)² / (4 · 3) = 4 / 12 = 1/3 ≈ 33.3%`.
- При `α = 5` (`β = 2/3 ≈ 0.667`): `GMR_P = (5 - 1)² / (4 · 5) = 16 / 20 = 0.80 = 80.0%`.
- При `α = 10` (`β = 9/11 ≈ 0.818`): `GMR_P = (10 - 1)² / (4 · 10) = 81 / 40 = 2.025 = 202.5%`.
- При `α → ∞` (`β → 1`, ідеальний половинний метал Гейслера): `GMR_P → ∞` (опір стану P прямує до нуля при скінченному опорі стану AP).

### Порівняння визначень GMR_P та GMR_AP

У літературі також зустрічається альтернативне нормування відносно максимального опору антипаралельного стану `GMR_AP = (R_AP - R_P) / R_AP` (так звана «песимістична» шкала):

```
GMR_AP
= (R_AP - R_P) / R_AP
= (r_0·β²) / r_0
= β²                                                  [формула GMR_AP через β]
= (α - 1)² / (α + 1)²                                 [формула GMR_AP через α]
```

Зв'язок між двома шкалами визначається аналітичним співвідношенням:

```
GMR_AP = GMR_P / (1 + GMR_P)
GMR_P  = GMR_AP / (1 - GMR_AP)
```

Для прикладу, якщо `β = 0.5`, то `GMR_P = 0.25 / 0.75 = 33.3%`, тоді як `GMR_AP = 0.25 = 25.0%`. Величина `GMR_AP` ніколи не може перевищити `100%` (`β² < 1`), тоді як `GMR_P` необмежено зростає при наближенні `β` до 1.

## Шунтування струму немагнітним шаром у геометрії CIP

У геометрії струму в площині шарів (CIP, *Current-In-Plane*) електричний струм тече паралельно вздовж шарів `FM1`, `NM` та `FM2`. Провідний немагнітний шар (як правило, мідь `Cu` з низьким питомим опором `ρ_NM ≈ 15–20` нОм·м) підключений паралельно до обох спін-залежних феромагнітних каналів і відводить на себе значну частину струму.

Позначимо електричний опір немагнітного шару як `R_NM = ρ_NM · L / (w · d_NM)`, де `L` — довжина, `w` — ширина, а `d_NM` — товщина шару міді.

Повний опір тришарової системи у паралельному та антипаралельному станах з урахуванням шунта `R_NM` визначається формулами паралельного з'єднання:

```
1 / R_P^tot  = 1 / R_P + 1 / R_NM   ──► R_P^tot  = (R_P · R_NM) / (R_P + R_NM)
1 / R_AP^tot = 1 / R_AP + 1 / R_NM  ──► R_AP^tot = (R_AP · R_NM) / (R_AP + R_NM)
```

Обчислимо абсолютну зміну повного опору `ΔR^tot = R_AP^tot - R_P^tot`:

```
ΔR^tot
= [ (R_AP · R_NM) / (R_AP + R_NM) ] - [ (R_P · R_NM) / (R_P + R_NM) ]
= [ R_AP·R_NM·(R_P + R_NM) - R_P·R_NM·(R_AP + R_NM) ] / [ (R_AP + R_NM)·(R_P + R_NM) ]
= [ R_AP·R_P·R_NM + R_AP·R_NM² - R_P·R_AP·R_NM - R_P·R_NM² ] / [ (R_AP + R_NM)·(R_P + R_NM) ]
= [ R_NM² · (R_AP - R_P) ] / [ (R_AP + R_NM) · (R_P + R_NM) ]
```

Розрахуємо результуючий коефіцієнт GMR у геометрії CIP:

```
GMR_CIP
= ΔR^tot / R_P^tot
= [ (R_NM² · (R_AP - R_P)) / ((R_AP + R_NM)·(R_P + R_NM)) ] / [ (R_P · R_NM) / (R_P + R_NM) ]
= [ R_NM² · (R_AP - R_P) ] / [ R_P · R_NM · (R_AP + R_NM) ]
= [ (R_AP - R_P) / R_P ] · [ R_NM / (R_AP + R_NM) ]
= GMR_0 · [ 1 / (1 + R_AP / R_NM) ]                    [деградація GMR через шунтування]
```

тут `GMR_0 = β² / (1 - β²)` — ідеальний коефіцієнт GMR без урахування шунтування.

Оскільки опір мідної проміжки обернено пропорційний її товщині (`R_NM ∝ 1 / d_NM`), відношення `R_AP / R_NM` лінійно зростає зі збільшенням товщини немагнітного металу:

```
R_AP / R_NM = (ρ_0 · d_NM) / (ρ_NM · 2·d_FM) = ξ · d_NM
```

Звідси випливає закон спаду магніторезистивного ефекту при збільшенні товщини проміжки:

```
GMR_CIP(d_NM) = GMR_0 / (1 + ξ · d_NM)
```

Збільшення товщини мідного шару понад `3–4` нм призводить до катастрофічного спаду вимірюваного сигналу GMR внаслідок того, що струм вибирає високопровідний мідний місток, минаючи спін-залежні феромагнітні інтерфейси.

## Багатошарові суперґратки з N періодів

У разі багатошарової періодичної структури `(FM / NM)_N`, що складається з `N` однакових повторюваних бішарів (суперґраток типу `[Fe / Cr]_N` або `[Co / Cu]_N`), загальний опір розраховується з урахуванням геометрії протікання струму.

Якщо товщина одного періоду `Λ = d_FM + d_NM` є значно меншою за середню довжину вільного пробігу електрона (`Λ ≪ λ_↑`), електрон пролітає крізь декілька періодів без розсіювання, усереднюючи локальний потенціал. Загальні опори структури у паралельному та антипаралельному станах виражаються як:

```
R_P(N)   = N · [ 2·r_↑·r_↓ / (r_↑ + r_↓) + r_NM ]
R_AP(N)  = N · [ (r_↑ + r_↓) / 2 + r_NM ]
```

де `r_NM` — опір одиничного немагнітного шару в межах одного періоду.

Обчислюємо коефіцієнт GMR для `N`-періодної суперґратки:

```
GMR(N)
= (R_AP(N) - R_P(N)) / R_P(N)
= [ N · (r_↓ - r_↑)² / (2·(r_↑ + r_↓)) ] / [ N · (2·r_↑·r_↓ / (r_↑ + r_↓) + r_NM) ]
= (r_↓ - r_↑)² / [ 4·r_↑·r_↓ + 2·r_NM·(r_↑ + r_↓) ]
= β² / [ (1 - β²) + (r_NM / r_0) ]                     [GMR для періодичної суперґратки]
```

Оскільки число періодів `N` скорочується у чисельнику та знаменнику, амплітуда GMR ідеальної суперґратки не залежить від кількості шарів `N` (за умови `N ≥ 10–20`, коли можна знехтувати крайовими ефектами крайніх шарів на підкладці та захисному шарі).

## Напівкласична кінетична модель Кемлі — Барнася (CIP)

Просторовий розподіл носіїв та профіль густини струму вздовж перерізу наноструктури у геометрії CIP описується лінеаризованим кінетичним рівнянням Больцмана для функцій розподілу `f_↑(z, v)` та `f_↓(z, v)`:

```
v_z · (∂f_↑,↓ / ∂z) + (e·E_x / m*) · (∂f_0 / ∂v_x) = - (f_↑,↓ - f_0) / τ_↑,↓
```

тут `z` — просторова координата вздовж нормалі до шарів, `x` — напрямок прикладеного електричного поля `E_x`, `v_z` — складова швидкості електрона вздовж нормалі, `f_0(v)` — рівноважна функція розподілу Фермі — Дірака, а `τ_↑,↓(z)` — локальний спін-залежний час релаксації.

Представимо функцію розподілу як суму рівноважної частини та малої добавки від поля: `f_↑,↓(z, v) = f_0(v) + g_↑,↓(z, v)`. Рівняння набуває вигляду:

```
v_z · (∂g_↑,↓ / ∂z) + g_↑,↓ / τ_↑,↓ = - (e·E_x / m*) · (∂f_0 / ∂v_x)
```

Загальний розв'язок для електронів, що рухаються до верхньої межі (`v_z > 0`, позначаємо `g⁺`) та до нижньої межі (`v_z < 0`, позначаємо `g⁻`), має вигляд:

```
g⁺_↑,↓(z, v) = - (e·E_x·τ_↑,↓ / m*) · (∂f_0 / ∂v_x) · [ 1 + C⁺_↑,↓ · exp(- z / (τ_↑,↓·|v_z|)) ]
g⁻_↑,↓(z, v) = - (e·E_x·τ_↑,↓ / m*) · (∂f_0 / ∂v_x) · [ 1 + C⁻_↑,↓ · exp(+ z / (τ_↑,↓·|v_z|)) ]
```

Невідомі константи інтегрування `C⁺_↑,↓` та `C⁻_↑,↓` знаходяться з граничних умов Фукса — Зондгеймера на інтерфейсах `z = z_i`:

```
g⁺_↑,↓(z_i⁺, v_z > 0) = p_↑,↓ · g⁻_↑,↓(z_i⁺, v_z < 0) + T_↑,↓ · g⁺_↑,↓(z_i⁻, v_z > 0)
```

де `p_↑,↓` — коефіцієнт дзеркального відбивання на межі поділу для відповідного спіну, а `T_↑,↓` — коефіцієнт квантового проходження крізь межу.

Фізична причина спінової залежності коефіцієнтів відбивання полягає у зонному узгодженні хвильових векторів електронів:
- Для мажоритарних електронів (`↑`) у системі `Co / Cu` потенціали кристалічної ґратки та фермієвські імпульси `k_F` для s-подібних станів збігаються з точністю до кількох відсотків. Інтерфейс є оптично прозорим: `T_↑ ≈ 1`, `p_↑ ≈ 0` (електрони вільно перетинають границю поділу без розсіювання).
- Для міноритарних електронів (`↓`) через обмінний зсув d-зони виникає потужний стрибок зонного потенціалу, що діє як квантовий бар'єр: `T_↓ ≪ 1`, `p_↓ → 1` (сильне дифузне або дзеркальне відбивання).

Локальна провідність `σ_xx(z)` визначається інтегруванням за кутами сфери Фермі:

```
σ_xx(z) = (3/4) · σ_0 · ∫₀¹ (1 - u²) · [ 2 - (C⁺ + C⁻) · exp(- z / (λ · u)) ] du     [u = cos θ]
```

де `σ_0 = n·e²·τ / m*` — об'ємна провідність, а інтегрування локальної густини електричного струму `j_x(z) = σ_xx(z) · E_x` по повній товщині структури `d_tot` дає сумарну провідність:

```
G_CIP = (1 / d_tot) · ∫ j_x(z) dz
```

Аналіз розв'язків моделі Кемлі — Барнася виявляє два важливі граничні випадки:
1. **Тонкі шари (`d_FM, d_NM ≪ λ_↑`):** Електрони багатократно перетинають інтерфейси. Величина GMR визначається виключно коефіцієнтами спінової прозорості `T_↑ / T_↓` та дзеркальності `p_↑ / p_↓` на межах поділу.
2. **Товсті шари (`d_FM, d_NM ≫ λ_↑`):** Електрони розсіюються в об'ємі металу не долітаючи до меж. Інтерфейси перестають взаємодіяти між собою, і амплітуда GMR експоненційно затухає за законом `GMR ∝ exp(- d_NM / λ_NM) · (λ_FM / d_FM)`.

## Теорія спінової дифузії Валета — Ферта (CPP)

У геометрії струму, перпендикулярного до площини шарів (CPP, *Current-Perpendicular-to-Plane*), електричний струм примусово протікає крізь усі феромагнітні шари та межі поділу. На кожному інтерфейсі виникає перерозподіл спінових струмів, що призводить до явища накопичення спіна (*spin accumulation*) та розщеплення електрохімічних потенціалів `μ_↑(z)` та `μ_↓(z)`.

### Одновимірне рівняння дифузії спінового накопичення

Електрохімічний потенціал електронів для кожного спінового каналу складається з електростатичного потенціалу `φ(z)` та хімічного зсуву через нерівноважну концентрацію носіїв `δn_↑,↓(z)`:

```
μ_↑(z) = - e · φ(z) + δn_↑(z) / D_↑(E_F)
μ_↓(z) = - e · φ(z) + δn_↓(z) / D_↓(E_F)
```

За умовою локальної квазінейтральності провідника сумарна зміна концентрації заряду дорівнює нулю: `δn_↑(z) + δn_↓(z) = 0`. Звідси випливає, що зсуви хімічних потенціалів протилежні за знаком і пов'язані з густинами станів `D_↑(E_F)` та `D_↓(E_F)`.

Густини струму для двох спінових каналів визначаються градієнтами електрохімічних потенціалів:

```
j_↑(z) = (σ_↑ / e) · (∂μ_↑ / ∂z)
j_↓(z) = (σ_↓ / e) · (∂μ_↓ / ∂z)
```

Повний електричний струм зберігається в кожному перерізі: `j = j_↑(z) + j_↓(z) = const`.

Рівняння неперервності струму з урахуванням спін-фліп релаксації мають вигляд:

```
(1/e) · (∂j_↑ / ∂z) = + (δn_↑ / τ_sf↑↓ - δn_↓ / τ_sf↓↑) = (μ_↑ - μ_↓) / (e² · ρ_0 · l_sf²)
(1/e) · (∂j_↓ / ∂z) = - (δn_↑ / τ_sf↑↓ - δn_↓ / τ_sf↓↑) = - (μ_↑ - μ_↓) / (e² · ρ_0 · l_sf²)
```

Визначимо спінове накопичення як різницю електрохімічних потенціалів: `Δμ(z) = μ_↑(z) - μ_↓(z)`. Диференціюючи вирази для густини струму та віднімаючи їх, отримуємо одновимірне дифузійне рівняння Валета — Ферта:

```
∂²(Δμ) / ∂z² = Δμ / l_sf²                              [дифузійне рівняння Валета — Ферта]
```

де `l_sf = √(D · τ_sf)` — довжина спінової дифузії відповідного шару.

Загальний розв'язок цього рівняння у довільному шарі являє собою лінійну комбінацію експонент:

```
Δμ(z) = A · exp(- z / l_sf) + B · exp(+ z / l_sf)
```

### Граничні умови з інтерфейсними опорами та поляризацією

На кожній міжфазній межі `FM / NM` (`z = z_i`) виникають стрибки електрохімічних потенціалів, пропорційні питомим інтерфейсним опорам `r_b↑` та `r_b↓`:

```
μ_↑(z_i⁺) - μ_↑(z_i⁻) = e · r_b↑ · j_↑(z_i)
μ_↓(z_i⁺) - μ_↓(z_i⁻) = e · r_b↓ · j_↓(z_i)
```

Інтерфейсні опори виражають через середній питомий опір межі `r_b` та коефіцієнт інтерфейсної спінової асиметрії `γ`:

```
r_b↑ = 2·r_b·(1 - γ)
r_b↓ = 2·r_b·(1 + γ)
γ = (r_b↓ - r_b↑) / (r_b↓ + r_b↑)                     [інтерфейсна спінова асиметрія, 0 ≤ γ < 1]
```

### Аналітичний вивід добутку опору на площу Δ(R·A)_CPP

У наближенні тонких плівок (дифузійна границя, коли товщини шарів значно менші за довжину спінової дифузії: `d_FM ≪ l_sf^FM`, `d_NM ≪ l_sf^NM`), розв'язок системи рівнянь Валета — Ферта дає точний аналітичний вираз для повного добутку опору на одиницю площі `(R · A)_CPP` у станах AP та P:

```
(R · A)_AP = 2·ρ_FM·d_FM + ρ_NM·d_NM + 2·r_b           [добуток опір-площа у стані AP]
(R · A)_P  = (R · A)_AP - Δ(R · A)_CPP                 [добуток опір-площа у стані P]
```

Абсолютна зміна добутку опору на площу `Δ(R · A)_CPP` становить:

```
Δ(R · A)_CPP = 2 · [ β·ρ_FM·d_FM + γ·r_b ]² / [ 2·(1 - β²)·ρ_FM·d_FM + (1 - γ²)·r_b + ρ_NM·d_NM ]
```

Коефіцієнт GMR у геометрії CPP розраховується як:

```
GMR_CPP = Δ(R · A)_CPP / (R · A)_P = Δ(R · A)_CPP / [ (R · A)_AP - Δ(R · A)_CPP ]
```

З аналітичного розв'язку Валета — Ферта випливають три фундаментальні переваги CPP-геометрії:
1. **Конструктивне додавання об'ємного та інтерфейсного внесків:** У чисельнику `Δ(R · A)_CPP` стоїть повний квадрат суми `[ β·ρ_FM·d_FM + γ·r_b ]²`. Якщо об'ємна `β` та інтерфейсна `γ` асиметрії мають однаковий знак (як у структурах `Co/Cu`), обидва механізми підсилюють один одного.
2. **Відсутність паразитного шунтування:** У CPP струм не може оминути феромагнітні шари крізь мідь, тому шунтуючий опір `ρ_NM·d_NM` входить лише адитивно у знаменник, не обнуляючи ефект.
3. **Систематично вища амплітуда:** Амплітуда `GMR_CPP` для однакових матеріалів завжди перевищує `GMR_CIP` у 2–4 рази (сягаючи `50–100%` при кімнатній температурі).

## Розрахунковий приклад: порівняння параметрів гетероструктур Co/Cu та Py/Cu

Для ілюстрації практичного застосування наведених аналітичних формул розрахуємо опір та коефіцієнт GMR для двох класичних спінтронічних систем: `Co (3 нм) / Cu (2 нм) / Co (3 нм)` та `Py (3 нм) / Cu (2 нм) / Py (3 нм)` (де `Py` — пермалой `Ni₈₀Fe₂₀`) при кімнатній температурі.

### Базові фізичні параметри матеріалів

| Параметр | Позначення | Кобальт (`Co`) | Пермалой (`Ni₈₀Fe₂₀`) | Мідь (`Cu`) | Одиниці |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Питомий опір** | `ρ` | `60.0` | `200.0` | `15.0` | нОм·м |
| **Об'ємна асиметрія** | `β` | `0.50` | `0.70` | `0.00` | — |
| **Інтерфейсна асиметрія з Cu** | `γ` | `0.75` | `0.70` | — | — |
| **Інтерфейсний опір з Cu** | `r_b` | `0.50` | `0.40` | — | фОм·м² (`10⁻¹⁵` Ом·м²) |
| **Довжина вільного пробігу** | `λ_p` | `10.0` | `4.0` | `30.0` | нм |
| **Довжина спінової дифузії** | `l_sf` | `40.0` | `5.0` | `250.0` | нм |

### Покроковий розрахунок для структури Co / Cu / Co у геометрії CPP

Задано товщини: `d_FM = 3` нм (`3 · 10⁻⁹` м), `d_NM = 2` нм (`2 · 10⁻⁹` м).

1. **Розрахунок об'ємних та інтерфейсних внесків:**
   ```
   ρ_FM · d_FM = 60.0 нОм·м · 3.0 нм = 180.0 фОм·м²
   ρ_NM · d_NM = 15.0 нОм·м · 2.0 нм = 30.0 фОм·м²
   r_b         = 0.50 фОм·м²
   ```

2. **Розрахунок повного опору антипаралельного стану `(R · A)_AP`:**
   ```
   (R · A)_AP
   = 2 · (ρ_FM · d_FM) + (ρ_NM · d_NM) + 2 · r_b       [підстановка виразів внесків]
   = 2 · 180.0 + 30.0 + 2 · 0.50                      [підстановка числових значень]
   = 360.0 + 30.0 + 1.0                               [проміжне додавання]
   = 391.0 фОм·м²                                     [добуток опір-площа стану AP]
   ```

3. **Розрахунок чисельника `Δ(R · A)_CPP`:**
   ```
   Внесок_чисельника
   = β · (ρ_FM · d_FM) + γ · r_b                      [формула спін-поляризованого внеску]
   = 0.50 · 180.0 + 0.75 · 0.50                       [підстановка параметрів для Co]
   = 90.0 + 0.375                                     [проміжне множення]
   = 90.375 фОм·м²                                    [сумарний амплітудний внесок]

   Чисельник = 2 · (90.375)² = 2 · 8167.64 = 16335.28 (фОм·м²)²
   ```

4. **Розрахунок знаменника `Δ(R · A)_CPP`:**
   ```
   1 - β² = 1 - (0.50)² = 1 - 0.25 = 0.75
   1 - γ² = 1 - (0.75)² = 1 - 0.5625 = 0.4375

   Знаменник
   = 2 · (1 - β²) · (ρ_FM · d_FM) + (1 - γ²) · r_b + (ρ_NM · d_NM)   [формула знаменника Валета — Ферта]
   = 2 · 0.75 · 180.0 + 0.4375 · 0.50 + 30.0                         [підстановка обчислених параметрів]
   = 270.0 + 0.21875 + 30.0                                          [проміжне додавання]
   = 300.22 фОм·м²                                                   [підсумкове значення знаменника]
   ```

5. **Обчислення абсолютної зміни `Δ(R · A)_CPP` та коефіцієнта GMR:**
   ```
   Δ(R · A)_CPP = 16335.28 / 300.22 = 54.41 фОм·м²

   (R · A)_P = (R · A)_AP - Δ(R · A)_CPP = 391.0 - 54.41 = 336.59 фОм·м²

   GMR_CPP = Δ(R · A)_CPP / (R · A)_P = 54.41 / 336.59 = 0.1616 = 16.16%
   ```

### Покроковий розрахунок для структури Py / Cu / Py у геометрії CPP

Для пермалоєвої гетероструктури `Py (3 нм) / Cu (2 нм) / Py (3 нм)` розрахунок демонструє домінування об'ємного розсіювання:

1. **Розрахунок об'ємних та інтерфейсних внесків:**
   ```
   ρ_Py · d_FM = 200.0 нОм·м · 3.0 нм = 600.0 фОм·м²
   ρ_Cu · d_NM = 15.0 нОм·м · 2.0 нм = 30.0 фОм·м²
   r_b         = 0.40 фОм·м²
   ```

2. **Розрахунок повного опору антипаралельного стану `(R · A)_AP`:**
   ```
   (R · A)_AP
   = 2 · (ρ_Py · d_FM) + (ρ_Cu · d_NM) + 2 · r_b      [формула опору для системи Py/Cu]
   = 2 · 600.0 + 30.0 + 2 · 0.40                      [підстановка числових значень]
   = 1200.0 + 30.0 + 0.80                             [проміжне додавання]
   = 1230.80 фОм·м²                                   [добуток опір-площа стану AP для Py]
   ```

3. **Розрахунок чисельника `Δ(R · A)_CPP`:**
   ```
   Внесок_чисельника
   = β · (ρ_Py · d_FM) + γ · r_b                      [формула спін-поляризованого внеску]
   = 0.70 · 600.0 + 0.70 · 0.40                       [підстановка параметрів для Py]
   = 420.0 + 0.28                                     [проміжне множення]
   = 420.28 фОм·м²                                    [сумарний амплітудний внесок для Py]

   Чисельник = 2 · (420.28)² = 2 · 176635.28 = 353270.56 (фОм·м²)²
   ```

4. **Розрахунок знаменника `Δ(R · A)_CPP`:**
   ```
   1 - β² = 1 - (0.70)² = 1 - 0.49 = 0.51
   1 - γ² = 1 - (0.70)² = 1 - 0.49 = 0.51

   Знаменник
   = 2 · (1 - β²) · (ρ_Py · d_FM) + (1 - γ²) · r_b + (ρ_Cu · d_NM)   [формула знаменника Валета — Ферта]
   = 2 · 0.51 · 600.0 + 0.51 · 0.40 + 30.0                           [підстановка параметрів Py]
   = 612.0 + 0.204 + 30.0                                            [проміжне додавання]
   = 642.204 фОм·м²                                                  [підсумкове значення знаменника]
   ```

5. **Обчислення абсолютної зміни `Δ(R · A)_CPP` та коефіцієнта GMR для Py:**
   ```
   Δ(R · A)_CPP = 353270.56 / 642.204 = 550.09 фОм·м²

   (R · A)_P = 1230.80 - 550.09 = 680.71 фОм·м²

   GMR_CPP = 550.09 / 680.71 = 0.8081 = 80.81%
   ```

У пермалої внаслідок великого питомого опору (`200` нОм·м) та високої об'ємної спінової асиметрії (`β = 0.70`) внесок об'єму (`420.0` фОм·м²) переважає інтерфейсний внесок (`0.28` фОм·м²) більш ніж у 1000 разів. Натомість у кобальті внесок інтерфейсу дає значну частку повного сигналу завдяки малому опору кобальтової матриці.

### Порівняння з розрахунком у геометрії CIP

1. **Ідеальний коефіцієнт без шунтування для Co/Cu/Co:**
   ```
   GMR_0 = β² / (1 - β²) = 0.25 / 0.75 = 33.33%
   ```

2. **Врахування коефіцієнта шунтування для Co/Cu/Co:**
   ```
   R_AP / R_NM = (ρ_FM · d_NM) / (ρ_NM · 2·d_FM) = (60.0 · 2.0) / (15.0 · 2 · 3.0) = 120.0 / 90.0 = 1.333

   GMR_CIP = GMR_0 / (1 + R_AP / R_NM) = 33.33% / (1 + 1.333) = 33.33% / 2.333 = 14.28%
   ```

3. **Розрахунок CIP для Py/Cu/Py:**
   ```
   GMR_0(Py) = (0.70)² / (1 - 0.49) = 0.49 / 0.51 = 96.08%

   R_AP / R_NM(Py) = (200.0 · 2.0) / (15.0 · 2 · 3.0) = 400.0 / 90.0 = 4.444

   GMR_CIP(Py) = 96.08% / (1 + 4.444) = 96.08% / 5.444 = 17.65%
   ```

### Температурна залежність коефіцієнта GMR

При підвищенні температури від кріогенної (`4.2 K`) до кімнатної (`300 K`) коефіцієнт GMR спадає внаслідок двох фізичних механізмів:
1. **Збудження теплових магнонів:** Спінові хвилі спричиняють непружні розсіювання носіїв із переворотом спіна, що описується законом Блоха для поляризації `P(T) = P_0 · (1 - A_sp · T^(3/2))`. Параметр спінової асиметрії `β(T)` зменшується на `30–50%`.
2. **Скорочення довжини спінової дифузії:** Інтенсифікація спін-фліп процесів призводить до зменшення `l_sf(T) ∝ 1/T`, через що ефективне спінове накопичення на інтерфейсах частково релаксує всередині шарів.

В результаті амплітуда GMR, яка при `4.2 K` досягає `50–80%` у суперґратках Fe/Cr та Co/Cu, при кімнатній температурі знижується до робочих значень `10–20%` у промислових спінових клапанах.
