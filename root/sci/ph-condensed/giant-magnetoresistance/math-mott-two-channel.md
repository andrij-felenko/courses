# 🧮 Двоканальна модель Мотта та розрахунок коефіцієнта GMR

Аналітичний опис ефекту гігантського магнітоопору спирається на теоретичну концепцію двох незалежних каналів провідності, висунуту Невіллом Моттом у 1936 році для розрахунку електропереносу у феромагнітних металах. За температур, значно нижчих за температуру Кюрі (`T ≪ T_C`), частота процесів розсіювання із переворотом спіна (взаємодія електронів із магнонами) є нехтовно малою порівняно з частотою пружного розсіювання на домішках, фононах та межах поділу. У цьому наближенні струм провідності розпадається на два незалежні паралельні потоки: носії зі спіном «вгору» (`↑`, мажоритарні носії) та зі спіном «вниз» (`↓`, міноритарні носії).

Розглянемо послідовний мікроскопічний та макроскопічний вивід формул опору, починаючи від квантовомеханічного розсіювання у 3d-зоні до напівкласичної моделі Кемлі-Барнася та теорії Валє-Фера для багатошарових гетероструктур.

## Спінова асиметрія та питомий опір феромагнетика

У феромагнітному металі (Fe, Co, Ni) обмінна взаємодія розщеплює `3d`-електронну зону, зміщуючи підзону зі спіном «вгору» вниз по енергії відносно підзони зі спіном «вниз». Оскільки електрони провідності `4s`-зони ефективно розсіюються у незаповнені стани `3d`-зони, ймовірність розсіювання згідно із золотим правилом Фермі пропорційна густині станів `N_3d(E_F)` на рівні Фермі. Через обмінне розщеплення густина станів `N_3d↑(E_F)` є малою, а `N_3d↓(E_F)` — високою, що створює сильну асиметрію середньої довжини вільного пробігу (`λ_↑ ≫ λ_↓`).

Питомий опір матеріалу для двох спінових каналів виражають через коефіцієнт спінової асиметрії `β`:

```
ρ_↑ = 2·ρ_0·(1 - β)     [питомий опір мажоритарного каналу спін-вгору]
ρ_↓ = 2·ρ_0·(1 + β)     [питомий опір міноритарного каналу спін-вниз]
```

тут `ρ_0` — середній питомий опір неполяризованого металу у парамагнітному стані, а коефіцієнт спінової асиметрії `β` визначається відношенням питомих опорів:

```
β = (ρ_↓ - ρ_↑) / (ρ_↓ + ρ_↑)      [0 ≤ β < 1]
```

Для чистого кобальту (Co) параметр `β` досягає `0.3–0.5`, тоді як для сплавів CoFe або NiFe (пермалой) може перевищувати `0.6–0.7`. Якщо `β = 0`, розсіювання є симетричним і магнітоопір відсутній.

## Розрахунок опору двошарової феромагнітної структури

Розглянемо макроскопічний опір шаруватої системи з двох однакових феромагнітних шарів `FM1` та `FM2` товщиною `d`, розділених немагнітною проміжкою `NM` товщиною `d_NM < λ`. Позначаємо опір одного феромагнітного шару для спіна «вгору» як `r_↑`, а для спіна «вниз» — як `r_↓` (`r_↓ > r_↑`).

### 1. Паралельний стан намагніченості (P)

У паралельному стані намагніченості обидвох шарів спрямовані вгору (`FM1 ↑ / FM2 ↑`).
- Канал спін-вгору проходить перший шар із опором `r_↑` і другий шар із опором `r_↑`. Загальний опір верхньої гілки дорівнює `r_↑ + r_↑ = 2·r_↑`.
- Канал спін-вниз проходить перший шар із опором `r_↓` і другий шар із опором `r_↓`. Загальний опір нижньої гілки дорівнює `r_↓ + r_↓ = 2·r_↓`.

Оскільки два канали підключені паралельно, еквівалентний опір `R_P` обчислюється як:

```
R_P = (2·r_↑)·(2·r_↓) / (2·r_↑ + 2·r_↓)
    = 4·r_↑·r_↓ / (2·(r_↑ + r_↓))
    = 2·r_↑·r_↓ / (r_↑ + r_↓)             [паралельне з'єднання гілок у стані P]
```

### 2. Антипаралельний стан намагніченості (AP)

У антипаралельному стані перша намагніченість спрямована вгору, а друга — вниз (`FM1 ↑ / FM2 ↓`).
- Канал спін-вгору проходить перший шар як мажоритарний (`r_↑`), а другий шар як міноритарний (`r_↓`). Загальний опір верхньої гілки дорівнює `r_↑ + r_↓`.
- Канал спін-вниз проходить перший шар як міноритарний (`r_↓`), а другий шар як мажоритарний (`r_↑`). Загальний опір нижньої гілки дорівнює `r_↓ + r_↑`.

Обидві гілки мають однаковий опір `r_↑ + r_↓`. Еквівалентний опір `R_AP` становить:

```
R_AP = (r_↑ + r_↓)·(r_↑ + r_↓) / ((r_↑ + r_↓) + (r_↑ + r_↓))
     = (r_↑ + r_↓)² / (2·(r_↑ + r_↓))
     = (r_↑ + r_↓) / 2                    [паралельне з'єднання гілок у стані AP]
```

## Покрокове виведення формули ефекту GMR

Визначимо відносний магнітоопір як відносну різницю між антипаралельним та паралельним опорами `GMR = (R_AP - R_P) / R_P`.

Виконаємо поетапне віднімання опорів `R_AP - R_P`:

```
R_AP - R_P
= (r_↑ + r_↓)/2 - (2·r_↑·r_↓)/(r_↑ + r_↓)                 [підстановка виразів для R_AP та R_P]
= ((r_↑ + r_↓)² - 4·r_↑·r_↓) / (2·(r_↑ + r_↓))             [зведення до спільного знаменника]
= (r_↑² + 2·r_↑·r_↓ + r_↓² - 4·r_↑·r_↓) / (2·(r_↑ + r_↓))   [розкриття квадрата суми]
= (r_↓ - r_↑)² / (2·(r_↑ + r_↓))                            [згортання у квадрат різниці]
```

Тепер розділимо різницю `R_AP - R_P` на `R_P`:

```
GMR = (R_AP - R_P) / R_P
    = [ (r_↓ - r_↑)² / (2·(r_↑ + r_↓)) ] / [ (2·r_↑·r_↓) / (r_↑ + r_↓) ]
    = (r_↓ - r_↑)² / (4·r_↑·r_↓)                            [скорочення (r_↑ + r_↓)]
```

Виражаємо `r_↑` та `r_↓` через коефіцієнт спінової асиметрії `β`: `r_↑ = r_0·(1 - β)`, `r_↓ = r_0·(1 + β)`:

```
r_↓ - r_↑ = r_0·(1 + β) - r_0·(1 - β) = 2·β·r_0
r_↓·r_↑   = r_0²·(1 - β²)

GMR = (2·β·r_0)² / (4·r_0²·(1 - β²))
    = (4·β²·r_0²) / (4·r_0²·(1 - β²))
    = β² / (1 - β²)                                       [підсумкова формула GMR через β]
```

Ця фундаментальна формула показує, що магнітоопір визначається виключно внутрішньою спіновою асиметрією розсіювання `β`. При `β = 0.5` величина `GMR = 0.25 / (1 - 0.25) = 1/3 ≈ 33%`.

## Багатошарові суперґратки з N періодів

У разі багатошарової суперґратки, яка складається з `N` періодично повторюваних фольг `(FM / NM)ₙ`, загальний опір системи можна розрахувати шляхом послідовного додавання опорів періодів.

Якщо кожен період володіє товщиною феромагнетика `d_FM` та немагнітного металу `d_NM`, за умови `d_FM + d_NM ≪ λ` електрону провідності байдуже, скільки періодів він перетинає протягом одного часу релаксації `τ`. Тоді ефективний опір суперґратки у паралельному та антипаралельному станах виражається як:

```
R_P(N)   = N · [ 2·r_↑·r_↓ / (r_↑ + r_↓) + r_NM ]
R_AP(N)  = N · [ (r_↑ + r_↓) / 2 + r_NM ]
```

тут `r_NM` — опір немагнітного шару проміжки, який додається однаково до обох спінових каналів і виступає в ролі паразитного опору.

Обчислюємо коефіцієнт GMR для `N`-періодної суперґратки з урахуванням паразитного опору `r_NM`:

```
GMR(N) = (R_AP - R_P) / R_P
       = [ N · (r_↓ - r_↑)² / (2·(r_↑ + r_↓)) ] / [ N · (2·r_↑·r_↓ / (r_↑ + r_↓) + r_NM) ]
       = (r_↓ - r_↑)² / [ 4·r_↑·r_↓ + 2·r_NM·(r_↑ + r_↓) ]
```

Звідси видно, що збільшення товщини немагнітного проміжка `d_NM` (зростання `r_NM`) монотонно зменшує вимірюваний коефіцієнт GMR, оскільки паразитний струм крізь мідь шунтує спін-залежні феромагнітні шари.

## Напівкласична модель Кемлі-Барнася (Camley-Barniś Model)

Для геометрії течії струму вздовж площини шарів (CIP, Current-In-Plane) просторовий розподіл електронів описується кінетичним рівнянням Больцмана для функції розподілу `f_k(r, v)` спінових каналів:

```
v_z · (∂f_↑,↓ / ∂z) + (e·E / m) · (∂f_↑,↓ / ∂v_x) = - (f_↑,↓ - f_0) / τ_↑,↓
```

тут `z` — координата, перпендикулярна до площини шарів, `x` — напрямок електричного поля `E`, `τ_↑,↓` — спін-залежний час релаксації.

Граничні умови на межах поділу `z = z_i` визначаються через коефіцієнти дзеркального відбивання `p_↑,↓` та коефіцієнти дифракційного (дифузного) розсіювання `(1 - p_↑,↓)`:

```
f_↑,↓⁺(z_i, v_z > 0) = p_↑,↓ · f_↑,↓⁻(z_i, v_z < 0) + (1 - p_↑,↓) · f_0
```

Розв'язок рівняння Больцмана дає просторовий профіль густини струму `j_x(z)` вздовж товщини наноструктури. Інтегрування `j_x(z)` по товщині дає повний опір структури, який залежить від відношення товщини шарів `d` до середньої довжини вільного пробігу `λ_↑,↓`. 

Якщо товщина шару `d ≫ λ_↑`, електрони розсіюються в об'ємі металу не доходивши до межі, і ефект GMR спадає як `λ / d`. Якщо `d ≪ λ_↑`, електрони легко перетинають проміжку, і опір визначається переважно поверхневими коефіцієнтами `p_↑,↓`.

## Модель Валє-Фера (Valet-Fert Model) для геометрії CPP

Для геометрії струму, перпендикулярного до площини шарів (CPP, Current-Perpendicular-to-Plane), розселення спінів на межах поділу викликає перерозподіл хімічних потенціалів `μ_↑` та `μ_↓`, що описується явищем накопичення спіна (*spin accumulation*).

Рівняння дифузії для спінового накопичення `Δμ(z) = μ_↑(z) - μ_↓(z)` має вигляд:

```
∂²(Δμ) / ∂z² = Δμ / l_sf²                 [рівняння спінової дифузії Валє-Фера]
```

тут `l_sf = √(v_F · τ · t_sf / 3)` — довжина спінової релаксації (spin diffusion length), яка визначає відстань, на якій згасає спінова поляризація.

Враховуючи як об'ємний коефіцієнт асиметрії `β`, так і поверхневий коефіцієнт асиметрії на межах поділу `γ = (r_S↓ - r_S↑) / (r_S↓ + r_S↑)`, повний поверхневий опір на одиницю площі `A·R_CPP` для антипаралельного та паралельного станів дорівнює:

```
A·R_AP = N · [ ρ_0·d_FM + ρ_NM·d_NM + 2·R_S ]
A·R_P  = A·R_AP - [ (N·β·ρ_0·d_FM + 2·N·γ·R_S)² / (A·R_AP) ]
```

тут `R_S` — середній поверхневий опір однієї межі поділу `FM/NM`.

З формули Валє-Фера випливає фундаментальний висновок: у геометрії CPP коефіцієнт GMR є завжди вищим, ніж у геометрії CIP, оскільки в CPP струм примусово перетинає абсолютно всі межі поділу, а спінове накопичення додається конструктивно на кожному періоді структури.
