# ⚙️ Чисельне моделювання дебаївського екранування потенціалу

Ця вставка детально описує математичне формулювання, розностну апроксимацію, архітектуру та реалізацію чисельного солвера для одновимірного нелінійного рівняння Пуассона — Больцмана. Наведено порівняльний аналіз скінченно-різницевих схем релаксації, критеріїв збіжності, оцінку обчислювальної складності та повний працюючий код мовами C та C++.

### 1. Постановка чисельної задачі та дискретизація

При моделюванні розподілу потенціалу біля поверхні напівпровідника або електрода в електроліті виникає потреба розв'язати одновимірне нелінійне диференціальне рівняння второго порядку для потенціалу `Φ(x)`:

```
d²Φ / dx² = (1 / λ_D²) · (k_B · T / e) · sinh( e · Φ(x) / (k_B · T) )
```

Область визначення задачі — відрізок `x ∈ [0, X_max]`, де `X_max` вибирається достатньо великим (зазвичай `X_max ≥ (5–10) · λ_D`), щоб потенціал на зовнішній межі гарантовано встигав згаснути до нуля.

Граничні умови задачі:
1. **На лівій межі (`x = 0`):** гранична умова Діріхле, що задає фіксований поверхневий потенціал `Φ(0) = Φ₀`.
2. **На правій межі (`x = X_max`):** гранична умова Діріхле `Φ(X_max) = 0` або умова Неймана відсутності нормального поля `(dΦ/dx)|_{x=X_max} = 0`.

Введемо рівномірну просторову сітку з `N` вузлів. Крок сітки дорівнює `h = X_max / (N - 1)`. Координата `i`-го вузла задається як `x[i] = i · h`, а невідоме значення потенціалу в ньому — `Φ[i]`.

Друга похідна у внутрішніх вузлах сітки (`i = 1, 2, ..., N-2`) апроксимується симетричною триточковою скінченно-різницевою схемою второго порядку точності `O(h²)`:

```
d²Φ / dx²|_{x=x[i]} ≈ ( Φ[i+1] - 2 · Φ[i] + Φ[i-1] ) / h²
```

Підставляючи розностну апроксимацію у вихідне рівняння Пуассона — Больцмана, отримуємо систему нелінійних алгебраїчних рівнянь для внутрішніх вузлів:

```
( Φ[i+1] - 2 · Φ[i] + Φ[i-1] ) / h² = (1 / λ_D²) · V_T · sinh( Φ[i] / V_T )
```

де `V_T = k_B · T / e` — тепловий потенціал.

### 2. Метод підрелаксації та збіжність ітерацій

Пряме застосування класичного методу ітерацій Якобі або Гаусса — Зайделя до нелінійного рівняння з гіперболічним синусом виявляється нестійким при великих початкових потенціалах (`Φ₀ > V_T`). Оскільки функція `sinh(z)` зростає експоненціально для великих аргументів, найменша похибка на проміжній ітерації викликає гігантську нелінійну нев'язку, що призводить до чисельного розгону (дрібіння та нескінченності).

Для пригнічення чисельної нестійкості застосовується **метод підрелаксації** (*under-relaxation method*). Вираз для обчислення нового значення потенціалу `Φ_new[i]` на поточному кроці має вигляд:

```
Φ_raw = 0.5 · ( Φ[i+1] + Φ[i-1] - h² · (1 / λ_D²) · V_T · sinh( Φ[i] / V_T ) )
Φ_new[i] = (1 - ω) · Φ[i] + ω · Φ_raw
```

де `ω ∈ (0, 1]` — параметр релаксації. Для малих потенціалів (`Φ₀ ≤ V_T`) можна вибирати `ω = 0.8–1.0`. Для сильних поверхневих потенціалів (`Φ₀ > 5 · V_T`) параметр `ω` необхідно зменшувати до `0.1–0.4`, щоб гарантувати стійку збіжність ітерацій.

Ітераційний процес триває до виконання критерію зупинки за максимальною чебишовською нормою різниці двох послідовних ітерацій:

```
max_{i} | Φ_new[i] - Φ_old[i] | < ε_tol
```

де `ε_tol` — задана точність обчислень (зазвичай `10⁻⁶–10⁻⁸ В`).

### 3. Оцінка складності та вибір параметрів сітки

Обчислювальна складність однієї ітерації Гаусса — Зайделя лінійно залежить від кількості вузлів сітки `O(N)`. Загальна кількість ітерацій `K`, необхідна для досягнення точності `ε_tol`, залежить від кроку сітки `h` та параметра релаксації `ω`. Для еліптичних рівнянь кількість ітерацій масштабується як `K ∝ 1/h² = O(N²)`.

Крок сітки `h` повинен бути суттєво меншим за дебаївську довжину `λ_D` (`h ≤ 0.2 · λ_D`), щоб скінченно-різницева схема точна передавала експоненціальний профіль згасання потенціалу та не викликала числової дисипації. Якщо вибрати `h > λ_D`, розностна схема розмиває градієнт поля біля межі, занижуючи обчислений поверхневий заряд.

При виборі фізичних параметрів для напівпровідникового кремнію (`ε_r = 11.7`, `T = 300 K`) з легуванням `N_D = 10¹⁶ см⁻³` дебаївська довжина становить `λ_D ≈ 40 нм`. Вибір розрахункової області `X_max = 300 нм` та кількості вузлів `N = 500` дає крок сітки `h = 0.6 нм`, що забезпечує високу точність дискретизації `h / λ_D ≈ 0.015`.

### 4. Аналіз похибок та граничних умов

При чисельному розв'язанні виникає два типи похибок: похибка апроксимації скінченно-різницевої схеми `O(h²)` та похибка усічення розрахункової області `X_max`.

Якщо вибрати розмір області `X_max` занадто малим (наприклад, `X_max < 3 · λ_D`), штучна гранична умова `Φ(X_max) = 0` викличе викривлення профілю потенціалу, оскільки реальне поле у нескінченному середовищі ще не встигає повністю згаснути. Це призводить до завищення індукованого об'ємного заряду поблизу межі. Збільшення розміру області до `X_max ≥ 6 · λ_D` гарантує, що штучна межа впливає на розв'язок у межах менше ніж `0.1%`.

Для апроксимації граничної умови Неймана відсутності струму або поля `(dΦ/dx)|_{x=X_max} = 0` можна використовувати односторонню різницю другого порядку з трьох точок: `(3·Φ[N-1] - 4·Φ[N-2] + Φ[N-3]) / (2·h) = 0`, що зберігає порядок точності всієї схеми `O(h²)`.

### 5. Архітектура та особливості реалізації

Представлений нижче код розроблено з урахуванням сучасних стандартів програмування та оптимізації продуктивності.

У реалізації мовою **C**:
* Структура `DebyeParams` описує фізичні параметри середовища (температуру, діелектричну проникність, концентрацію носіїв).
* Функція `compute_debye_length()` обчислює дебаївську довжину за вхідними матеріальними параметрами.
* Обчислювальне ядро `run_debye_simulation()` самостійно виділяє динамічну пам'ять під масиви координат і потенціалів та здійснює цикл Гаусса — Зайделя з підрелаксацією.
* Звільнення ресурсів виконується через спеціальну функцію `free_simulation_result()`, яка запобігає витокам пам'яті.

У реалізації мовою **C++**:
* Використано сучасний стандарт C++23 / C++20 із концептами та типом `std::expected` для безпечної обробки помилок без винятків.
* Клас `DebyeSolver` реалізовано у вигляді статичного обчислювального модуля без збереження прихованого стану.
* Результат повертається у вигляді контейнера `std::vector<SimulationPoint>`, який містить координату, потенціал та локальну об'ємну густину заряду `ρ(x)`.
* Пам'ять резервується заздалегідь через `reserve()`, що виключає повторні реалокації у процесі обчислень та гарантує максимальну швидкість виконання.

```c
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

#define KB_EV 8.617333262e-5  /* Стала Больцмана в еВ/К */
#define ELEC_CHARGE 1.602176634e-19
#define EPS0 8.854187812e-12

typedef struct {
    double temp_k;        /* Температура в Кельвінах */
    double rel_perm;      /* Відносна діелектрична проникність */
    double n0_m3;         /* Концентрація носіїв у м⁻³ */
    double debye_m;       /* Обчислена дебаївська довжина */
} DebyeParams;

typedef struct {
    int num_points;
    double grid_step;
    double *x_coords;
    double *potential_v;
} SimulationResult;

/* Обчислення радіуса Дебая */
double compute_debye_length(double temp_k, double rel_perm, double n0_m3) {
    double eps = rel_perm * EPS0;
    double vt = (KB_EV * temp_k); /* у вольтах */
    return sqrt((eps * vt) / (2.0 * n0_m3 * ELEC_CHARGE));
}

/* Ініціалізація симуляції */
int run_debye_simulation(DebyeParams params, double phi0_v, double x_max_m, 
                         int N, double tol, SimulationResult *out_res) {
    if (N < 3 || params.debye_m <= 0.0 || out_res == NULL) {
        return -1;
    }

    double *x = (double *)malloc(sizeof(double) * N);
    double *phi = (double *)malloc(sizeof(double) * N);
    if (!x || !phi) {
        free(x);
        free(phi);
        return -2;
    }

    double h = x_max_m / (N - 1);
    double vt = KB_EV * params.temp_k;
    double inv_ld2 = 1.0 / (params.debye_m * params.debye_m);

    /* Початкові умови: лінійний спад */
    for (int i = 0; i < N; ++i) {
        x[i] = i * h;
        phi[i] = phi0_v * exp(-x[i] / params.debye_m);
    }
    phi[0] = phi0_v;
    phi[N - 1] = 0.0;

    /* Ітераційний процес релаксації Гаусса — Зайделя */
    int max_iter = 10000;
    double omega = 0.5; /* Коефіцієнт релаксації */

    for (int iter = 0; iter < max_iter; ++iter) {
        double max_diff = 0.0;
        for (int i = 1; i < N - 1; ++i) {
            double rhs = inv_ld2 * vt * sinh(phi[i] / vt);
            double phi_new = 0.5 * (phi[i + 1] + phi[i - 1] - h * h * rhs);
            double phi_relaxed = (1.0 - omega) * phi[i] + omega * phi_new;

            double diff = fabs(phi_relaxed - phi[i]);
            if (diff > max_diff) {
                max_diff = diff;
            }
            phi[i] = phi_relaxed;
        }

        if (max_diff < tol) {
            break;
        }
    }

    out_res->num_points = N;
    out_res->grid_step = h;
    out_res->x_coords = x;
    out_res->potential_v = phi;
    return 0;
}

void free_simulation_result(SimulationResult *res) {
    if (res) {
        free(res->x_coords);
        free(res->potential_v);
        res->x_coords = NULL;
        res->potential_v = NULL;
    }
}
```

```cpp
#include <iostream>
#include <vector>
#include <cmath>
#include <expected>
#include <numbers>

namespace physics {

struct DebyeParams {
    double temp_k{300.0};       // Температура в Кельвінах
    double rel_perm{11.7};      // Відносна проникність (кремній = 11.7)
    double n0_m3{1.0e22};       // Концентрація носіїв м⁻³

    [[nodiscard]] constexpr double debye_length() const noexcept {
        constexpr double kb_ev = 8.617333262e-5;
        constexpr double eps0 = 8.854187812e-12;
        constexpr double q = 1.602176634e-19;
        
        const double eps = rel_perm * eps0;
        const double vt = kb_ev * temp_k;
        return std::sqrt((eps * vt) / (2.0 * n0_m3 * q));
    }
};

struct SimulationPoint {
    double x_m;
    double potential_v;
    double charge_density_c_m3;
};

enum class SimulationError {
    InvalidParameters,
    ConvergenceFailed
};

class DebyeSolver {
public:
    [[nodiscard]] static std::expected<std::vector<SimulationPoint>, SimulationError>
    solve_planar(const DebyeParams& params, double phi0_v, double x_max_m, 
                 std::size_t num_nodes = 500, double tol = 1.0e-7) {
        
        if (num_nodes < 3 || x_max_m <= 0.0) {
            return std::unexpected(SimulationError::InvalidParameters);
        }

        const double ld = params.debye_length();
        const double h = x_max_m / static_cast<double>(num_nodes - 1);
        constexpr double kb_ev = 8.617333262e-5;
        const double vt = kb_ev * params.temp_k;
        const double inv_ld2 = 1.0 / (ld * ld);

        std::vector<double> phi(num_nodes);
        for (std::size_t i = 0; i < num_nodes; ++i) {
            const double x = static_cast<double>(i) * h;
            phi[i] = phi0_v * std::exp(-x / ld);
        }
        phi.front() = phi0_v;
        phi.back() = 0.0;

        constexpr std::size_t max_iter = 20000;
        constexpr double omega = 0.4;
        bool converged = false;

        for (std::size_t iter = 0; iter < max_iter; ++iter) {
            double max_diff = 0.0;
            for (std::size_t i = 1; i < num_nodes - 1; ++i) {
                const double rhs = inv_ld2 * vt * std::sinh(phi[i] / vt);
                const double phi_new = 0.5 * (phi[i + 1] + phi[i - 1] - h * h * rhs);
                const double phi_relaxed = (1.0 - omega) * phi[i] + omega * phi_new;

                max_diff = std::max(max_diff, std::abs(phi_relaxed - phi[i]));
                phi[i] = phi_relaxed;
            }

            if (max_diff < tol) {
                converged = true;
                break;
            }
        }

        if (!converged) {
            return std::unexpected(SimulationError::ConvergenceFailed);
        }

        std::vector<SimulationPoint> result;
        result.reserve(num_nodes);

        constexpr double q = 1.602176634e-19;
        for (std::size_t i = 0; i < num_nodes; ++i) {
            const double x = static_cast<double>(i) * h;
            const double rho = -2.0 * q * params.n0_m3 * std::sinh(phi[i] / vt);
            result.push_back({.x_m = x, .potential_v = phi[i], .charge_density_c_m3 = rho});
        }

        return result;
    }
};

} // namespace physics
```

### 6. Приклад використання та аналіз результатів

При виконанні програми з параметрами поверхневого потенціалу `Φ₀ = 0.1 В` (що перевищує тепловий потенціал `V_T ≈ 0.026 В` майже у 4 рази) обчислений розв'язок демонструє виразну різницю між лінеаризованою дебаївською експонентою та точним нелінійним профілем:
* Поблизу межі `x < λ_D` нелінійний потенціал спадає стрімкіше за лінійне наближення, оскільки висока об'ємна густина індукованого заряду `ρ(x) ∝ sinh(eΦ/k_B T)` екранує поле значно ефективніше.
* На відстанях `x > 2 · λ_D` потенціал падає нижче `0.01 В`, і нелінійний розв'язок плавно асимптотично зливається з класичною експонентою Дебая — Гюккеля.
