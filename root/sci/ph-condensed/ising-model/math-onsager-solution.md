# 🧮 Точний розв'язок 2D моделі Ізінга та трансфер-матриця

Точний аналітичний розв'язок двовимірної моделі Ізінга на квадратній ґратці — один із найвидатніших результатів математичної фізики. Метою цього математичного розбору є простеження того, як класична статистична сума двовимірної сітки дискретних спінів перетворюється на задачу вирахування власних значень квантовомеханічного оператора трансфер-матриці, діагоналізації системи вільних ферміонів та отримання логарифмічної сингулярності питомої теплоємності.

Гамільтоніан 2D моделі Ізінга для `N = L × L` спінів `σ_{i,j} ∈ {-1, +1}` у нульовому зовнішньому полі має вигляд:

```
H = -J · sum_i sum_j (σ_{i,j} · σ_{i+1,j} + σ_{i,j} · σ_{i,j+1})   [гамільтоніан 2D ґратки]
```

де `J > 0` — інтеграл феромагнітної взаємодії найближчих сусідів. Приймемо періодичні граничні умови: `σ_{L+1,j} = σ_{1,j}` та `σ_{i,L+1} = σ_{i,1}`. Статистична сума описується виразом:

```
Z = sum_{σ} exp(-β · H)                                            [статистична сума Ґіббса]
Z = sum_{σ} exp[ K · sum_{i,j} (σ_{i,j} σ_{i+1,j} + σ_{i,j} σ_{i,j+1}) ]  [через параметр K]
```

де `β = 1 / (k_B · T)`, а безрозмірний параметр зв'язку позначено як `K = β · J = J / (k_B · T)`.

### 1. Метод трансфер-матриці: одновимірний випадок (1D)

Щоб зрозуміти ідею трансфер-матриці, розглянемо замкнений 1D ланцюжок із `N` спінів з гамільтоніаном `H = -J · sum_i σ_i · σ_{i+1}` (де `σ_{N+1} = σ_1`).

Статистичну суму можна подати як добуток локальних множників для кожної пари сусідів:

```
Z = sum_{σ_1} sum_{σ_2} ... sum_{σ_N} P(σ_1, σ_2) · P(σ_2, σ_3) · ... · P(σ_N, σ_1)
```

де `P(σ, σ') = exp(K · σ · σ')` — елемент матриці розміром 2 × 2:

```
P = | P(+1,+1)  P(+1,-1) | = | exp(K)   exp(-K) |
    | P(-1,+1)  P(-1,-1) |   | exp(-K)  exp(K)  |              [трансфер-матриця 1D]
```

Сумування за всіма проміжними конфігураціями спінів відповідає послідовному множенню матриць `P`. Завдяки періодичним граничним умовам статистична сума стає следом `N`-ного степеня цієї матриці:

```
Z = Sp( P^N ) = λ_1^N + λ_2^N                                     [след матриці 1D]
```

де `λ_1, λ_2` — власні значення матриці `P`. Характеристичне рівняння `det(P - λ·I) = 0` дає:

```
(exp(K) - λ)² - exp(-2K) = 0                                       [характеристичне рівняння]
λ_1,2 = exp(K) ± exp(-K)                                           [корені характеристичного рівняння]
```

Отже, власні значення дорівнюють:

```
λ_1 = 2 · cosh(K)                                                  [старше власне значення]
λ_2 = 2 · sinh(K)                                                  [молодше власне значення]
```

Оскільки `K > 0`, найбільше власне значення дорівнює `λ_1 = 2 · cosh(K) > λ_2`. У термодинамічній границі нескінченного ланцюжка (`N → ∞`) внесок молодшого власного значення `λ_2^N` зникає експоненціально:

```
Z ≈ λ_1^N = ( 2 · cosh(J / (k_B · T)) )^N                          [статсума у границі N → ∞]
```

Вільна енергія на один спін `f` становить:

```
f(T) = -lim_{N → ∞} (k_B · T / N) · ln Z                          [визначення вільної енергії]
f(T) = -k_B · T · ln( 2 · cosh(J / (k_B · T)) )                   [вільна енергія 1D моделі]
```

#### Парна кореляційна функція та довжина кореляції в 1D
Використовуючи трансфер-матрицю, можна точно обчислити парну спін-спінову кореляційну функцію `G(r) = <σ_i · σ_{i+r}>` для двох спінів, віддалених на відстань `r`:

```
G(r) = ( λ_1^(N-r) · λ_2^r + λ_1^r · λ_2^(N-r) ) / ( λ_1^N + λ_2^N )  [кореляційна функція через λ]
```

У границі `N → ∞` це співвідношення спрощується до точного виразу:

```
G(r) = ( λ_2 / λ_1 )^r = ( tanh K )^r = exp( -r / ξ )              [експоненціальне затухання]
```

де **радіус (довжина) кореляції `ξ`** визначається як:

```
ξ(T) = -1 / ln( tanh(J / (k_B · T)) )                              [радіус кореляції 1D моделі]
```

При низьких температурах (`T → 0 K`, `K → ∞`) розклад дає `tanh K ≈ 1 - 2·exp(-2K)`, звідки:

```
ξ(T) ≈ (1 / 2) · exp( 2J / (k_B · T) )                             [асимптотика радіуса кореляції]
```

Радіус кореляції прямує до нескінченності **лише при строгому нулі температур (`T = 0 K`)**. Для будь-якої скінченної температури `T > 0` радіус кореляції є скінченним, що підтверджує відсутність далекого магнітного порядку в 1D.

### 2. Дуальність Крамерса — Ванньє: високо- та низькотемпературні розклади

Гендрік Крамерс та Грегорі Ванньє у 1941 році довели існування точного тотожного зв'язку між властивостями 2D моделі Ізінга при високих та низьких температурах без повного розв'язання задачі.

#### Низькотемпературний розклад (Low-temperature expansion)
При низьких температурах (`K → ∞`) основним станом є повністю впорядкована ґратка, де всі спіни орієнтовані паралельно (`Z_0 = 2 · exp(2 N K)`). Збурення виникають шляхом утворення замкнених контурів перевернутих спінів периметром `L`. Статистична сума розкладається за параметром `v = exp(-2K)`:

```
Z(K) = 2 · exp(2 N K) · [ 1 + N · v⁴ + 2N · v⁶ + ... ]              [низькотемпературний розклад статсуми]
```

#### Високотемпературний розклад (High-temperature expansion)
При високих температурах (`K → 0`) множник Больцмана розкладається через ґратчасті тотожності: `exp(K · σ_i σ_j) = cosh K · (1 + σ_i σ_j · tanh K)`. Оскільки сума за будь-яким одиночним спіном `sum_{σ=±1} σ = 0`, ненульовий внесок у статсуму дають лише ті конфігурації ребер, де у кожному вузлі сходиться парна кількість ребер (тобто замкнені контури на дуальній ґратці). Статистична сума розкладається за параметром `w = tanh K`:

```
Z(K) = (2 cosh K)^(2N) · [ 1 + N · w⁴ + 2N · w⁶ + ... ]             [високотемпературний розклад статсуми]
```

#### Точка самодуальності
Порівняння двох серій розкладів показує, що 2D модель Ізінга на квадратній ґратці дуальна сама собі (самодуальна). Співвідношення між оригінальним параметром `K` та дуальним параметром `K*` задається виразом:

```
tanh K* = exp(-2K)                                                 [дутальність Крамерса — Ванньє]
sinh(2K) · sinh(2K*) = 1                                           [симетрична форма дуальності]
```

Точка критичного фазового переходу збігається з точкою самодуальності (`K = K* = K_c`), що негайно дає критичне рівняння `sinh(2K_c) = 1`.

### 3. Сформулювання трансфер-матриці для двовимірної ґратки (2D)

У двовимірному випадку ґратка розміром `L × L` розглядається як стос із `L` горизонтальних рядків. Стан одного рядка `i` задається вектором із `L` спінів:

```
σ_i = (σ_{i,1}, σ_{i,2}, ..., σ_{i,L})                             [стан рядка ґратки]
```

Кожен рядок може перебувати в одному з `2^L` мікростанів. Енергія 2D ґратки складається з двох частин: взаємодії спінів усередині рядків (`E_intra`) та взаємодії між сусідніми рядками (`E_inter`):

```
H = sum_{i=1}^L [ E_intra(σ_i) + E_inter(σ_i, σ_{i+1}) ]           [розділення енергії за рядками]
```

де:

```
E_intra(σ_i) = -J · sum_j σ_{i,j} · σ_{i,j+1}                       [внутрішньорядкова енергія]
E_inter(σ_i, σ_{i+1}) = -J · sum_j σ_{i,j} · σ_{i+1,j}              [міжрядкова енергія]
```

Трансфер-матриця `V` тепер має величезний розмір `2^L × 2^L`. Її матричний елемент між станом рядка `σ` та станом сусіднього рядка `σ'` виражається як:

```
V_{σ, σ'} = exp[ K · sum_j σ_j σ'_j + (K / 2) · sum_j (σ_j σ_{j+1} + σ'_j σ'_{j+1}) ]  [елемент 2D трансфер-матриці]
```

За аналогією з 1D випадком, статистична сума 2D ґратки дорівнює следу `L`-ного степеня оператора `V`:

```
Z = Sp( V^L ) = sum_{m=1}^{2^L} Λ_m^L ≈ Λ_max^L                     [статсума через 2D трансфер-матрицю]
```

де `Λ_max` — найбільше власне значення трансфер-матриці `V` розміром `2^L × 2^L`. Вільна енергія на один спін у границі `L → ∞` визначається логарифмом `Λ_max`:

```
f(T) = -lim_{L → ∞} (k_B · T / L) · ln Λ_max                       [вільна енергія 2D ґратки]
```

### 4. Алгебра операторів Паулі та факторизація Онсагера

Ларс Онсагер розклав оператор трансфер-матриці `V` у добуток двох симетричних операторів: `V = V_1^(1/2) · V_2 · V_1^(1/2)`, де:

```
V_1 = exp( K · sum_j σ_j^z · σ_{j+1}^z )                            [оператор міжспінового зв'язку]
V_2 = (2 · sinh 2K)^(L/2) · exp( K* · sum_j σ_j^x )                 [оператор поперечного поля]
```

тут `σ_j^x, σ_j^z` — класичні квантові спинові матриці Паулі, які діють у гільбертовому просторі рядка.

Визначаючи оператори `P_j = σ_j^z · σ_{j+1}^z` та `Q_j = σ_j^x`, Онсагер виявив, що вони генерують скінченновимірну замкнену алгебру Лі з комутаційними співвідношеннями:

```
[ P_j, Q_k ] = 2i · ( δ_{j,k} · σ_j^y σ_{j+1}^z - δ_{j+1,k} · σ_j^z σ_{j+1}^y )  [комутатор генераторів]
```

Ця квадратична замкненість дозволяє провести точну діагоналізацію без прямого використання обчислювально недосяжних матриць розміром `2^L × 2^L`.

### 5. Квантове перетворення Йордана — Вігнера до вільних ферміонів

Щоб діагоналізувати матричний оператор `V`, Онсагер та згодом Бранмет і Шульц скористалися перетворенням Йордана — Вігнера, яке тотожно відображає спінові оператори Паулі на безспінові ферміонні оператори народження `c_j†` та знищення `c_j`:

```
σ_j^x = 1 - 2 · c_j† · c_j                                         [перетворення для x-компоненти]
σ_j^z = [ prod_{m < j} (1 - 2 · c_m† · c_m) ] · (c_j + c_j†)       [перетворення для z-компоненти]
```

Ферміонні оператори задовольняють канонічні антикомутаційні співвідношення:

```
{ c_i, c_j† } = c_i · c_j† + c_j† · c_i = δ_{ij}                     [антикомутатор ферміонів]
{ c_i, c_j } = 0,   { c_i†, c_j† } = 0                              [антикомутатори однойменних]
```

Це перетворення перетворює складну нелінійну задачу взаємодіючих спінів на квантову гамільтонову систему **невзаємодіючих квазічастинок (вільних ферміонів)**.

Переходячи до фур'є-простору за хвильовими векторами `k = 2π·m / L` (де `m` — напівцілі або цілі числа):

```
c_j = (1 / sqrt(L)) · sum_k d_k · exp(i · k · j)                  [перехід у фур'є-простір]
```

За допомогою перетворення Боголюбова `η_k = u_k · d_k + v_k · d_{-k}†` оператор трансфер-матриці розпадається на добуток незалежних операторів для кожної пари квазіімпульсів `(k, -k)`:

```
H_eff = sum_k ε(k) · ( η_k† · η_k - 1/2 )                          [діагоналізований гамільтоніан]
```

де одночастинний спектр збуджень `ε(k)` виражається через аналітичну функцію:

```
cosh ε(k) = cosh(2K) · cosh(2K*) - sinh(2K) · sinh(2K*) · cos k    [дисперсійне співвідношення збуджень]
```

### 6. Точна формула вільної енергії та логарифмічна сингулярність

Сумуючи за всіма імпульсними модами у термодинамічній границі нескінченної ґратки (`L → ∞`), Онсагер отримав точний двовимірний інтеграл для вільної енергії на один спін `f(T)`:

```
f(T) = -k_B · T · ln 2 - (k_B · T / 2π²) · int_0^π int_0^π ln[ cosh²(2K) - sinh(2K) · (cos θ_1 + cos θ_2) ] dθ_1 dθ_2  [інтеграл Онсагера]
```

Аналіз цього інтеграла показує джерело фізичної сингулярності. Підінтегральний вираз звертається в нуль у єдиній точці простору кутів `θ_1 = 0, θ_2 = 0` тоді і тільки тоді, коли виконується умова:

```
cosh²(2K) - 2 · sinh(2K) = 0                                       [нуль підінтегрального виразу]
(sinh(2K) - 1)² = 0                                                [спрощення умови]
sinh(2K) = 1                                                       [критичний випадок]
```

Це точно відповідає критичній температурі `K = K_c`.

#### Еліптичні інтеграли та логарифмічна розбіжність
Інтегрування за одним із кутів зводить вільну енергію до повного еліптичного інтеграла першого роду `K(k_mod)`:

```
f(T) = -k_B · T · ln(2 cosh 2K) - (k_B · T / 2π) · int_0^π K( k_mod ) dθ  [форма через еліптичний інтеграл]
```

де модуль еліптичного інтеграла дорівнює `k_mod = 2 sinh(2K) / cosh²(2K)`. У критичній точці `T → T_c` модуль прямує до одиниці (`k_mod → 1`), де еліптичний інтеграл демонструє логарифмічну сингулярність `K(k_mod) ~ -ln|1 - k_mod|`.

Дворазове диференціювання функціонала `f(T)` за температурою дає питому теплоємність `C_v(T) = -T · ∂²f / ∂T²`:

```
C_v(T) ≈ -(2 k_B / π) · (2J / (k_B · T_c))² · ln|1 - T / T_c| + B_reg  [асимптотика теплоємності]
```

Логарифмічна розбіжність показує, що критичний індекс теплоємності для 2D моделі Ізінга дорівнює `α = 0` (із логарифмічною поправкою), що кардинально відрізняє 2D модель Ізінга від теорії середнього поля, де `C_v` виявляє лише скінченний стрибок.
