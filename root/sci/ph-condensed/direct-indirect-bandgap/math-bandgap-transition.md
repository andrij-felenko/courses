# 🧮 Квантово-механічний розрахунок оптичних переходів у прямозонних та непрямозонних напівпровідниках

Ця вставка містить строге квантово-механічне виведення швидкостей міжзонних оптичних переходів, матричних елементів взаємодії з електромагнітним полем, обчислення зведеної густини станів, а також покроковий вивід спектральних та температурних залежностей коефіцієнта поглинання світла для прямозонних і непрямозонних напівпровідників.

### 1. Гамільтоніан взаємодії та Золоте правило Фермі

Взаємодія електронів напівпровідникового кристала з оптичним електромагнітним полем розглядається у рамках квантово-механічної теорії збурень. У класичному або вторинно квантованому описі електромагнітне поле задається векторним потенціалом `A(r, t)` та скалярним потенціалом `Φ(r, t)`. У кулонівському калібруванні (калібруванні випромінювання):

```
div A = 0
Φ = 0
```

Гамільтоніан електрона масою `m_0` у кристалічному потенціалі `V(r)` за наявності електромагнітного поля одержується за допомогою принципу мінімальної взаємодії через заміну канонічного імпульсу `p → p - q A = p + e A`, де `-e` — заряд електрона (`e > 0`):

```
H = (1 / (2 m_0)) · (p + e A)² + V(r)
  = (p² / (2 m_0)) + V(r) + (e / (2 m_0)) · (p · A + A · p) + (e² / (2 m_0)) · A²   [розкриття квадрата оператора]
```

Оскільки квантовий оператор імпульсу `p = -iℏ ∇`, комутатор оператора імпульсу з векторним потенціалом визначається дивергенцією векторного поля:

```
[p, A] f = -iℏ ∇ · (A f) - A · (-iℏ ∇ f) = -iℏ (∇ · A) f = 0   [у калібруванні Кулона div A = 0]
```

Звідси випливає рівність `p · A = A · p`, і лінійний за полем доданок набуває форми `(e / m_0) A · p`.

Квадратичний за векторним потенціалом член `(e² / (2 m_0)) A²` відповідає одночасному поглинанню або випромінюванню двох фотонів, розсіянню світла (томсонівському розсіянню) та діамагнітному зсуву рівнів. Для оптичних інтенсивностей нелазерного діапазону (густина потужності значно менша за гігавати на квадратний сантиметр) амплітуда векторного потенціалу мала, а відношення квадратичного члена до лінійного становить величину порядку `e |A| / |p| ≈ 10⁻⁴...10⁻⁵`. Тому в лінійній оптичній спектроскопії квадратичним членом нехтують, а гамільтоніан збурення записують у вигляді:

```
H_int(t) = (e / m_0) · A(r, t) · p
```

Векторний потенціал плоскої монохроматичної світлової хвилі з частотою `ω`, хвильовим вектором `k_ph` та одиничним вектором поляризації `e_pol` має вигляд:

```
A(r, t) = A_0 · e_pol · [exp(i k_ph · r - i ω t) + exp(-i k_ph · r + i ω t)]
```

Перший доданок `exp(-i ω t)` описує процес поглинання світлового кванта, а другий доданок `exp(+i ω t)` — вимушене випромінювання фотона.

Нехай до увімкнення оптичного збурення електрон кристала перебував у початковому стаціонарному стані валентної зони `|i⟩ = |v, k_i⟩` з енергією `E_i = E_v(k_i)`. Під дією нестаціонарного гармонічного збурення хвильова функція системи розвивається в часі згідно з часовим рівнянням Шредінгера `iℏ (∂Ψ / ∂t) = (H_0 + H_int(t)) Ψ`.

Розкладаючи хвильову функцію за власними станами незбуреного кристала `Ψ(r, t) = ∑_n c_n(t) ψ_n(r) exp(-i E_n t / ℏ)`, у першому порядку теорії збурень для амплітуди переходу в кінцевий стан зони провідності `|f⟩ = |c, k_f⟩` з енергією `E_f = E_c(k_f)` одержуємо:

```
iℏ · (dc_f / dt) = ⟨f| H_int(t) |i⟩ · exp(i ω_fi t)   [де ω_fi = (E_f - E_i) / ℏ]
```

Інтегруючи за часом від початкового моменту `t = 0` до моменту `t` за початкової умови `c_i(0) = 1`, `c_f(0) = 0` для процесу поглинання фотона:

```
c_f(t) = -(1 / ℏ) · ∫_0^t ⟨f| H_int^(0) |i⟩ · exp(i (ω_fi - ω) t') dt'
       = -(⟨f| H_int^(0) |i⟩ / ℏ) · [exp(i (ω_fi - ω) t) - 1] / [i (ω_fi - ω)]   [інтегрування експоненти]
```

де амплітудний матричний елемент поглинання дорівнює:

```
M_fi = ⟨f| H_int^(0) |i⟩ = (e A_0 / m_0) · ⟨f| exp(i k_ph · r) · (e_pol · p) |i⟩
```

Ймовірність виявлення електрона в кінцевому стані `|f⟩` до моменту часу `t` визначається квадратом модуля амплітуди:

```
|c_f(t)|² = (|M_fi|² / ℏ²) · sin²((ω_fi - ω) t / 2) / ((ω_fi - ω) / 2)²
```

При великих інтервалах часу `t → ∞` функція під знаком ймовірності перетворюється на дельта-функцію Дірака:

```
lim_(t→∞) [sin²(x t / 2) / (π t (x / 2)²)] = δ(x)
```

Швидкість квантового переходу (ймовірність переходу в одиницю часу) `W_(i→f) = d|c_f(t)|² / dt = lim_(t→∞) (|c_f(t)|² / t)` набуває форми Золотого правила Фермі для міжзонного поглинання світла:

```
W_(i→f) = (2π / ℏ) · |M_fi|² · δ(E_f - E_i - ℏω)
```

де дельта-функція виражає строгий закон збереження енергії при переході: `E_f - E_i = ℏω`.

### 2. Прямі переходи: хвильові функції Блоха та правила добору

У кристалічному періодичному потенціалі решітки `V(r + R) = V(r)` одночастинкові стани описуються блохівськими хвильовими функціями:

```
ψ_(n, k)(r) = (1 / √V) · u_(n, k)(r) · exp(i k · r)
```

де `V = N · Ω_cell` — об'єм основного об'єму кристала, `N` — число елементарних комірок, `Ω_cell` — об'єм однієї комірки, а `u_(n, k)(r)` — блохівська амплітуда, яка має період кристалічної решітки `u_(n, k)(r + R) = u_(n, k)(r)` та нормована в межах однієї елементарної комірки:

```
(1 / Ω_cell) · ∫_cell |u_(n, k)(r)|² d³r = 1
```

Матричний елемент переходу між початковим станом валентної зони `|v, k_i⟩` та кінцевим станом зони провідності `|c, k_f⟩` з урахуванням оператора взаємодії записується як просторовий інтеграл по всьому об'єму кристала:

```
M_fi = (e A_0 / (m_0 · V)) · ∫_V u*_(c, k_f)(r) · exp(-i k_f · r) · [e_pol · p] · [u_(v, k_i)(r) · exp(i k_i · r)] · exp(i k_ph · r) d³r
```

Застосовуючи диференціальний оператор імпульсу `p = -iℏ ∇` до добутку блохівської амплітуди на експоненту за правилом Лейбніца:

```
p [u_(v, k_i)(r) · exp(i k_i · r)] = exp(i k_i · r) · [p u_(v, k_i)(r)] + ℏ k_i · u_(v, k_i)(r) · exp(i k_i · r)   [диференціювання добутку]
```

Підставляючи цей вираз у матричний елемент, отримуємо суму двох внесків:

```
M_fi = M_fi^(міжзонний) + M_fi^(внутрішньозонний)
```

Внутрішньозонний внесок пропорційний інтегралу перекриття блохівських амплітуд двох різних зон при фіксованому хвильовому векторі:

```
(1 / Ω_cell) · ∫_cell u*_(c, k)(r) · u_(v, k)(r) d³r = δ_cv = 0   [ортогональність функцій різних зон c ≠ v]
```

Завдяки взаємній ортогональності хвильових функцій різних зон при однаковому квазіімпульсі, внутрішньозонний член тотожно обнуляється.

Міжзонний внесок розбивається на суму по всіх `N` елементарних комірках із радіус-векторами `R_j` та інтеграл по об'єму однієї комірки `Ω_cell` (де `r = R_j + r'`):

```
M_fi = (e A_0 / (m_0 · V)) · ∑_(j=1)^N exp[i (k_i - k_f + k_ph) · R_j] · ∫_cell u*_(c, k_f)(r') · [e_pol · p] · u_(v, k_i)(r') · exp[i (k_i - k_f + k_ph) · r'] d³r'
```

Сума за вузлами кристалічної решітки перетворюється на дельта-символ Кронекера:

```
(1 / N) · ∑_(j=1)^N exp[i (k_i - k_f + k_ph) · R_j] = δ_(k_f, k_i + k_ph + G)
```

де `G` — довільний вектор оберненої решітки кристала.

Оцінимо величину хвильового вектора оптичного кванта. Для довжини хвилі видимого або ближнього інфрачервоного світла `λ ≈ 500...1000 нм` хвильовий вектор фотона становить `k_ph = 2π / λ ≈ 10⁷ м⁻¹`. Водночас розмір першої зони Бріллюена дорівнює `k_ZB = π / a ≈ 6·10⁹ м⁻¹` (де `a ≈ 0.5 нм` — стала решітки).

Оскільки `|k_ph| / k_ZB ≈ 10⁻³ ≪ 1`, довжина хвилі світла на три порядки перевищує міжатомну відстань, і фазовий множник `exp[i k_ph · r'] ≈ 1` у межах елементарної комірки. Це наближення називається електричним дипольним наближенням.

Звідси випливає закон збереження кристалічного квазіімпульсу при прямому оптичному переході (з урахуванням `G = 0` для оптичних переходів біля центра зони):

```
k_f = k_i + k_ph ≈ k_i   [правило добору за квазіімпульсом: вертикальний перехід]
```

Остаточний матричний елемент прямого переходу набуває вигляду:

```
M_fi = (e A_0 / m_0) · (e_pol · p_cv) · δ_(k_f, k_i)
```

де `p_cv` — міжзонний матричний елемент оператора імпульсу:

```
p_cv = (1 / Ω_cell) · ∫_cell u*_(c, k)(r) · p · u_(v, k)(r) d³r
```

Міжзонний матричний елемент імпульсу пов'язаний із матричним елементом оператора координати (електричного дипольного моменту) через квантове комутаційне співвідношення Гейзенберга:

```
[r, H_0] = (iℏ / m_0) · p
```

Обчислюючи матричний елемент комутатора між блохівськими станами:

```
⟨c| [r, H_0] |v⟩ = (E_v - E_c) · ⟨c| r |v⟩ = -ℏ ω_cv · r_cv
```

Звідси одержуємо точний зв'язок між матричними елементами імпульсу та координати:

```
p_cv = i m_0 ω_cv · r_cv = i m_0 · ((E_c - E_v) / ℏ) · r_cv
```

За симетрією блохівських амплітуд у центрі зони Бріллюена прямі міжзонні оптичні переходи поділяються на два класи:

1. **Прямі дозволені переходи (direct allowed transitions):**
   У прямозонних напівпровідниках зі структурою цинкової обманки (`GaAs`, `InP`, `InAs`) дно зони провідності у точці `Γ` (`k = 0`) утворене сферично-симетричними `s`-орбіталями атомів (парна просторова парність), а вершина валентної зони утворена `p`-орбіталями (непарна просторова парність). Оскільки оператор градієнта `p = -iℏ ∇` є непарним, підінтегральний вираз `u*_c p u_v` є парною функцією, і інтеграл по елементарній комірці відмінний від нуля при `k = 0`:

   ```
   p_cv(0) ≠ 0   [дозволений перехід: матричний елемент не залежить від k біля краю зони]
   ```

2. **Прямі заборонені переходи (direct forbidden transitions):**
   Якщо зони в центрі зони Бріллюена мають однакову просторову парність (як, наприклад, у закису міді `Cu_2O` або діоксиді титану `TiO_2`), матричний елемент у точці `k = 0` тотожно обнуляється: `p_cv(0) = 0`. Тоді матричний елемент розкладають у ряд Тейлора за малими відхиленнями хвильового вектора від центра:

   ```
   p_cv(k) = (k · ∇_k) p_cv|_(k=0) ∝ |k|
   ```

   Квадрат модуля матричного елемента такого переходу виявляється прямо пропорційним квадрату хвильового вектора: `|M_fi|² ∝ k²`.

### 3. Виведення спектрального коефіцієнта поглинання прямозонного напівпровідника

Коефіцієнт оптичного поглинання `α(ℏω)` визначається як відношення енергії світла, поглинутої в одиниці об'єму напівпровідника за одиницю часу, до густини потоку падаючої енергії випромінювання (модуля вектора Пойнтінга `S`):

```
α(ℏω) = (dI_abs / dt) / S
```

Густина потоку енергії монохроматичної електромагнітної хвилі в середовищі з показником заломлення `n_r` виражається через амплітуду векторного потенціалу `A_0` або амплітуду електричного поля `E_0 = ω A_0`:

```
S = (1 / 2) · ε_0 · n_r · c · |E_0|² = (1 / 2) · ε_0 · n_r · c · ω² · A_0²
```

де `ε_0` — електрична стала, `c` — швидкість світла у вакуумі.

Повна швидкість поглинання енергії в одиниці об'єму дорівнює сумі швидкостей переходів за Золотим правилом Фермі по всіх станах зони Бріллюена, помноженій на енергію одного кванта `ℏω`:

```
dI_abs / dt = (ℏω / V) · ∑_(i, f) W_(i→f)
```

Переходимо від сумування за дискретними значеннями хвильового вектора `k` до інтегрування по неперервному фазовому простору з урахуванням двократного спінового виродження електрона:

```
∑_k → 2 · (V / (2π)³) · ∫ d³k
```

Розглянемо випадок двох параболічних ізотропних зон поблизу точки `k = 0`:

```
E_c(k) = E_g + (ℏ² k²) / (2 m*_e)   [зона провідності]
E_v(k) = -(ℏ² k²) / (2 m*_h)        [валентна зона]
```

де `m*_e` та `m*_h` — ефективні маси електрона та дірки.

Енергія прямого міжзонного оптичного переходу між станами з однаковим квазіімпульсом `k`:

```
E_cv(k) = E_c(k) - E_v(k) = E_g + (ℏ² k² / (2 m*_e)) + (ℏ² k² / (2 m*_h))
        = E_g + (ℏ² k²) / (2 m_r)   [через зведену ефективну масу]
```

де `m_r` — зведена ефективна маса пари електрон-дірка (reduced effective mass):

```
1 / m_r = (1 / m*_e) + (1 / m*_h)   ⇒   m_r = (m*_e · m*_h) / (m*_e + m*_h)
```

Виведемо аналітичний вираз для зведеної оптичної густини станів `g_red(E)` (joint density of states), яка визначає кількість електрон-діркових пар на одиницю об'єму в одиничному інтервалі енергії переходу:

```
g_red(E) = (2 / (2π)³) · ∫ d³k · δ(E_cv(k) - E)
         = (2 / (2π)³) · ∫_0^∞ 4π k² · δ(E_g + (ℏ² k² / (2 m_r)) - E) dk   [перехід до сферичних координат]
         = (1 / π²) · ∫_0^∞ k² · δ(E_g + (ℏ² k² / (2 m_r)) - E) dk         [скорочення на 4π]
```

Виконаємо заміну змінної інтегрування: нехай `ε = E_g + (ℏ² k² / (2 m_r))`. Диференціал енергії дорівнює:

```
dε = (ℏ² k / m_r) dk   ⇒   k dk = (m_r / ℏ²) dε
```

Хвильовий вектор виражається через енергію:

```
k = √[2 m_r (ε - E_g) / ℏ²]
```

Підставляючи `k` та `k dk` в інтеграл:

```
g_red(E) = (1 / π²) · ∫_(E_g)^∞ √[2 m_r (ε - E_g) / ℏ²] · (m_r / ℏ²) · δ(ε - E) dε
         = (1 / (2π²)) · (2 m_r / ℏ²)^(3/2) · √(E - E_g)   [інтегрування з дельта-функцією при E ≥ E_g]
```

Підставимо отриману зведену густину станів та матричний елемент переходу у вираз для коефіцієнта поглинання:

```
α_dir(ℏω) = [(ℏω / V) · (2π / ℏ) · (e² A_0² / m_0²) · |e_pol · p_cv|² · V · g_red(ℏω)] / [(1 / 2) · ε_0 · n_r · c · ω² · A_0²]
          = [4π² e² · |e_pol · p_cv|²] / [n_r · c · ε_0 · m_0² · ω] · g_red(ℏω)   [скорочення A_0² та енергій]
```

Для кубічного або ізотропного кристала виконується просторове усереднення квадрата скалярного добутку вектора поляризації світла та матричного елемента імпульсу по всіх можливих напрямках:

```
⟨|e_pol · p_cv|²⟩ = (1 / 3) · |p_cv|²
```

Підставляючи явний вираз для `g_red(ℏω)` та усереднений матричний елемент, отримуємо точну аналітичну формулу коефіцієнта поглинання прямозонного напівпровідника для дозволених переходів:

```
α_dir(ℏω) = [e² · (2 m_r)^(3/2) · |p_cv|²] / [3 π · n_r · c · ε_0 · m_0² · ℏ²] · √(ℏω - E_g) / (ℏω)
```

Оскільки у вузькому спектральному діапазоні поблизу фундаментального краю поглинання енергія фотона `ℏω ≈ E_g` змінюється слабо порівняно з кореневим виразом `√(ℏω - E_g)`, множник `1 / (ℏω)` часто об'єднують із константами у спектральний коефіцієнт `A_dir`:

```
α_dir(ℏω) = A_dir · √(ℏω - E_g)   [для ℏω ≥ E_g]
```

Для прямого забороненого переходу матричний елемент пропорційний `k`, тому `|M_fi|² ∝ k² = 2 m_r (ℏω - E_g) / ℏ²`. Множення цього додаткового лінійного множника на кореневу густину станів дає степінь `3/2`:

```
α_forb(ℏω) = A_forb · (ℏω - E_g)^(3/2) / (ℏω) ≈ A_forb · (ℏω - E_g)^(3/2)   [для ℏω ≥ E_g]
```

### 4. Непрямі переходи: другий порядок теорії збурень та фононний оператор

У непрямозонному напівпровіднику абсолютний максимум валентної зони розташований у центрі зони Бріллюена в точці `Γ` (`k_v = 0`), а абсолютний мінімум зони провідності зміщений у точку `k_c = k_0 ≠ 0` (наприклад, уздовж осей `⟨100⟩` у кремнії або в точках `L` уздовж осей `⟨111⟩` у германії).

Оскільки хвильовий вектор оптичного фотона `k_ph ≈ 0`, матричний елемент прямого оптичного переходу між цими станами за першим порядком теорії збурень дорівнює нулю:

```
⟨c, k_0| H_int |v, 0⟩ = 0   [через невідповідність хвильових векторів k_0 ≠ 0]
```

Перехід стає квантово дозволеним лише як тричастинковий процес, у якому одночасно беруть участь три квазічастинки: електрон, фотон та квант теплових коливань кристалічної решітки — фонон із хвильовим вектором `q ≈ ±k_0` та енергією `ℏΩ_q`.

Оператор електрон-фононної взаємодії `H_ep` у представленні вторинного квантування записується через оператори знищення `a_(q, j)` та народження `a⁺_(q, j)` фононів `j`-ї поляризаційної гілки:

```
H_ep = ∑_(q, j) [ V_(q, j) · a_(q, j) · exp(i q · r) + V*_(q, j) · a⁺_(q, j) · exp(-i q · r) ]
```

де `V_(q, j)` — матричний елемент взаємодії електрона з коливаннями решітки (через механізм акустичного деформаційного потенціалу або полярної оптичної взаємодії Фреліха).

Оскільки оптичний перехід у непрямозонному матеріалі відбувається з одночасною зміною енергії фотонного та фононного полів, імовірність переходу розраховується за другим порядком квантово-механічної теорії збурень. Амплітуда переходу з початкового стану `|i⟩ = |v, k_i; N_q⟩` у кінцевий стан `|f⟩ = |c, k_f; N_q ± 1⟩` визначається сумою за всіма проміжними віртуальними станами `|m⟩`:

```
M_fi^(ind) = ∑_m [ (⟨f| H_ep |m⟩ · ⟨m| H_int |i⟩) / (E_i - E_m + ℏω) + (⟨f| H_int |m⟩ · ⟨m| H_ep |i⟩) / (E_i - E_m ∓ ℏΩ_q) ]
```

Ця сума описує інтерференцію двох фундаментальних квантових шляхів через віртуальні стани:

1. **Квантовий шлях I (спочатку поглинання фотона, потім розсіяння на фононі):**
   - На першому кроці електрон поглинає фотон `ℏω` і здійснює вертикальний оптичний перехід без зміни хвильового вектора з валентного стану `|v, k_i⟩` у віртуальний проміжний стан зони провідності `|m⟩ = |c, k_i⟩` біля точки `k ≈ 0`. Енергетичний дефіцит цього віртуального стану становить `ΔE_1 = E_c(k_i) - (E_v(k_i) + ℏω) = E_g^dir - ℏω`.
   - На другому кроці електрон розсіюється на коливаннях решітки, поглинаючи або випромінюючи фонон із хвильовим вектором `q = k_f - k_i`, і переходить із віртуального стану `|c, k_i⟩` у реальний стан мінімуму зони провідності `|c, k_f⟩`.

2. **Квантовий шлях II (спочатку розсіяння на фононі, потім поглинання фотона):**
   - На першому кроці електрон взаємодіє з фононом і розсіюється з початкового стану валентної зони `|v, k_i⟩` у проміжний віртуальний стан валентної зони `|m'⟩ = |v, k_f⟩` біля хвильового вектора `k_f ≈ k_0`. Енергетичний знаменник дорівнює `ΔE_2 = E_v(k_i) - E_v(k_f) ∓ ℏΩ_q`.
   - На другому кроці електрон поглинає фотон `ℏω` і здійснює вертикальний оптичний перехід із віртуального стану `|v, k_f⟩` у кінцевий стан зони провідності `|c, k_f⟩`.

Віртуальний стан `|m⟩` не є стаціонарним станом частинки і не має власного реального заселення. Згідно зі співвідношенням невизначеностей Гейзенберга для енергії та часу, час життя віртуального стану обмежений величиною:

```
Δt_virt ≈ ℏ / |E_i - E_m ± ℏω| ≈ 10⁻¹⁵ с   [порядку однієї фемтосекунди]
```

Проте для повного квантового переходу між початковим `|i⟩` та кінцевим `|f⟩` станами закони збереження енергії та повного кристалічного квазіімпульсу виконуються абсолютно строго:

```
E_c(k_f) - E_v(k_i) = ℏω ∓ ℏΩ_q   [збереження енергії: «-» випромінювання фонона, «+» поглинання фонона]
k_f - k_i = ±q                   [збереження квазіімпульсу]
```

### 5. Виведення квадратичного закону непрямого поглинання та температурної залежності

Головна відмінність непрямого переходу від прямого полягає у структурі фазового об'єму. При прямому переході збереження квазіімпульсу фіксує кінцевий стан `k_f = k_i`, тому інтегрування ведеться за однією змінною хвильового вектора. При непрямому переході фонон може передати будь-який вектор `q = k_f - k_i`, тому хвильові вектори початкового стану у валентній зоні `k_i` та кінцевого стану в зоні провідності `k_f` є повністю взаємно незалежними.

Сумарна ймовірність оптичного переходу в одиницю часу одержується подвійним інтегруванням за всіма початковими станами валентної зони та всіма кінцевими станами зони провідності:

```
W_ind(ℏω) ∝ ∫ ∫ ρ_v(E_v) · ρ_c(E_c) · δ(E_c - E_v - (ℏω ∓ ℏΩ_q)) dE_v dE_c
```

Відраховуватимемо енергію дірки `ε_v` вглиб валентної зони від її вершини (`ε_v = -E_v ≥ 0`), а енергію електрона `ε_c` — вгору від дна зони провідності (`ε_c = E_c - E_g ≥ 0`). Густини станів тривимірних параболічних зон мають вигляд:

```
ρ_v(ε_v) = C_v · √ε_v
ρ_c(ε_c) = C_c · √ε_c
```

Закон збереження енергії набирає форми:

```
ε_c + ε_v = ℏω - E_g ∓ ℏΩ_q ≡ Δ_±
```

де величина `Δ_± = ℏω - E_g ∓ ℏΩ_q` позначає повну надлишкову енергію оптично-фононного переходу. Якщо `Δ_± < 0`, перехід енергетично неможливий, і поглинання дорівнює нулю.

Якщо `Δ_± ≥ 0`, інтегрування за енергією `ε_c` за допомогою дельта-функції фіксує `ε_c = Δ_± - ε_v`, а межі інтегрування за `ε_v` змінюються від `0` до `Δ_±`:

```
I(Δ_±) = ∫_0^(Δ_±) √ε_v · √(Δ_± - ε_v) dε_v
```

Виконаємо аналітичне обчислення цього інтеграла за допомогою заміни змінної `ε_v = Δ_± · x`, де `x ∈ [0, 1]`, `dε_v = Δ_± dx`:

```
I(Δ_±) = ∫_0^1 √(Δ_± · x) · √(Δ_± · (1 - x)) · Δ_± dx
       = (Δ_±)² · ∫_0^1 x^(1/2) · (1 - x)^(1/2) dx   [винесення енергетичного множника у квадраті]
```

Інтеграл, що залишився, є бета-функцією Ейлера `B(p, q) = ∫_0^1 x^(p-1) (1 - x)^(q-1) dx` для значень `p = 3/2` та `q = 3/2`:

```
∫_0^1 x^(1/2) · (1 - x)^(1/2) dx = B(3/2, 3/2) = [Γ(3/2)]² / Γ(3)   [зв'язок бета- та гамма-функцій]
```

Обчислюємо значення гамма-функцій:

```
Γ(3/2) = (1 / 2) · Γ(1/2) = (1 / 2) · √π
Γ(3) = 2! = 2
B(3/2, 3/2) = [(1 / 2) · √π]² / 2 = (π / 4) / 2 = π / 8   [точне значення інтеграла]
```

Таким чином, згортка густин станів дає строгу квадратичну залежність від надлишкової енергії:

```
I(Δ_±) = (π / 8) · (Δ_±)² = (π / 8) · (ℏω - E_g ∓ ℏΩ_q)²
```

Матричні елементи операторів народження та знищення фононів визначаються статистичним числом заповнення фононних мод `N_q` з енергією `ℏΩ_q` за розподілом Бозе-Айнштайна при температурі кристала `T`:

```
N_q = 1 / [exp(ℏΩ_q / (k_B T)) - 1]
```

1. **Гілка поглинання фонона (Absorption):**
   Квадрат матричного елемента оператора знищення фонона дорівнює `|⟨N_q - 1| a_q |N_q⟩|² = N_q`.
   Енергетичний поріг початку поглинання становить `ℏω ≥ E_g - ℏΩ_q`.
   Коефіцієнт поглинання для цієї гілки дорівнює:

   ```
   α_abs(ℏω) = B_ind · (ℏω - E_g + ℏΩ_q)² / [exp(ℏΩ_q / (k_B T)) - 1]   [поріг: ℏω ≥ E_g - ℏΩ_q]
   ```

   При наближенні до абсолютного нуля температур (`T → 0 K`) число термічних фононів прямує до нуля (`N_q → 0`), і процес поглинання з участю фононів решітки повністю згасає.

2. **Гілка випромінювання фонона (Emission):**
   Квадрат матричного елемента оператора народження фонона дорівнює `|⟨N_q + 1| a⁺_q |N_q⟩|² = N_q + 1`.
   Множник заселеності перетворюється до вигляду:

   ```
   N_q + 1 = 1 + 1 / [exp(ℏΩ_q / (k_B T)) - 1] = 1 / [1 - exp(-ℏΩ_q / (k_B T))]
   ```

   Енергетичний поріг початку випромінювання фонона зміщений у бік вищих енергій: `ℏω ≥ E_g + ℏΩ_q`.
   Коефіцієнт поглинання для гілки випромінювання фонона дорівнює:

   ```
   α_em(ℏω) = B_ind · (ℏω - E_g - ℏΩ_q)² / [1 - exp(-ℏΩ_q / (k_B T))]   [поріг: ℏω ≥ E_g + ℏΩ_q]
   ```

   Оскільки `N_q + 1 → 1` при `T → 0 K`, процес поглинання світла зі спонтанним випромінюванням фонона залишається можливим навіть за нульової температури.

У реальних непрямозонних напівпровідниках оптичний перехід може супроводжуватися випромінюванням або поглинанням фононів різних гілок коливань решітки: поздовжніх акустичних (`LA`), поперечних акустичних (`TA`), поздовжніх оптичних (`LO`) та поперечних оптичних (`TO`). Повний коефіцієнт непрямого поглинання являє собою суму за всіма активними фононними модами:

```
α_indirect(ℏω) = ∑_j B_j · [ (ℏω - E_g + ℏΩ_j)² / [exp(ℏΩ_j / (k_B T)) - 1] · Θ(ℏω - E_g + ℏΩ_j) + (ℏω - E_g - ℏΩ_j)² / [1 - exp(-ℏΩ_j / (k_B T))] · Θ(ℏω - E_g - ℏΩ_j) ]
```

де `Θ(x)` — одинична функція Хевісайда (`Θ(x) = 1` при `x ≥ 0`, `Θ(x) = 0` при `x < 0`).

Для непрямих заборонених переходів (коли матричний елемент прямого переходу в віртуальний стан обнуляється в центрі зони) інтегральна згортка містить додаткові степені хвильового вектора, що приводить до кубічної спектральної залежності:

```
α_ind,forb(ℏω) ∝ (ℏω - E_g ∓ ℏΩ_q)³
```

### 6. Кулонівська взаємодія та екситонні ефекти (підсилення Зоммерфельда)

В одночастинковій зонній моделі вважається, що згенеровані світлом електрон і дірка рухаються абсолютно незалежно. Проте в реальному кристалі між негативно зарядженим електроном (заряд `-e`) та позитивно зарядженою діркою (заряд `+e`) діє привабливий кулонівський потенціал, екранований статичною діелектричною проникністю напівпровідника `ε_r`:

```
V_Coulomb(r) = -e² / (4π · ε_0 · ε_r · r)
```

де `r = |r_e - r_h|` — відносна відстань між електроном та діркою.

Ця кулонівська взаємодія кардинально змінює спектр поглинання як нижче, так і вище фундаментального краю забороненої зони:

1. **Дискретні зв'язані стани (екситони Ванньє — Мотта):**
   Нижче краю `E_g` виникають зв'язані квазіводнеподібні стани електрона та дірки — екситони Ванньє — Мотта. Енергетичні рівні зв'язаного екситона утворюють дискретну серію:

   ```
   E_n = E_g - R_ex / n²   [де n = 1, 2, 3, ...]
   ```

   де `R_ex` — енергія зв'язку екситона (екситонний Рідберг):

   ```
   R_ex = (m_r · e⁴) / (2 · (4π ε_0 ε_r)² · ℏ²) = (m_r / m_0) · (1 / ε_r²) · 13.606 еВ
   ```

   Борівський радіус екситона становить `a_ex = a_0 · ε_r · (m_0 / m_r)`. Для арсеніду галію (`GaAs`: `ε_r ≈ 12.8`, `m_r ≈ 0.058 m_0`) `R_ex ≈ 4.8 меВ`, а радіус `a_ex ≈ 11.5 нм` охоплює десятки елементарних комірок кристала.

   Оптичне поглинання на дискретних рівнях екситона проявляється у вигляді серії вузьких ліній нижче `E_g`, інтенсивність яких спадає як `1 / n³`.

2. **Неперервний спектр та фактор Зоммерфельда (теорія Елліотта):**
   При енергіях фотонів `ℏω > E_g` електрон і дірка утворюють незв'язаний стан неперервного спектра. Проте кулонівське притягання збільшує ймовірність знаходження електрона і дірки в одній точці простору `|ψ(r = 0)|²` порівняно з плоскими хвилями вільного електронного газу.

   Згідно з квантово-механічною теорією Елліотта (R. J. Elliott, 1957), коефіцієнт міжзонного поглинання прямозонного напівпровідника з урахуванням кулонівської взаємодії модифікується множником кулонівського підсилення Зоммерфельда `S(ℏω)`:

   ```
   α_exciton(ℏω) = α_dir(ℏω) · S(ℏω)
   ```

   Фактор підсилення Зоммерфельда має точний аналітичний вигляд:

   ```
   S(ℏω) = |ψ_Coulomb(0)|² / |ψ_free(0)|² = (2π · η) / [1 - exp(-2π · η)]
   ```

   де безрозмірний параметр Зоммерфельда `η` визначається відношенням екситонного Рідберга до надлишкової енергії фотона:

   ```
   η = √[R_ex / (ℏω - E_g)]
   ```

   Дослідимо поведінку коефіцієнта поглинання біля самого краю забороненої зони при `ℏω → E_g⁺`:

   ```
   η → ∞   ⇒   exp(-2π η) → 0   ⇒   S(ℏω) ≈ 2π · η = 2π · √[R_ex / (ℏω - E_g)]
   ```

   Підставляючи цей асимптотичний вираз у формулу для коефіцієнта поглинання:

   ```
   α_exciton(ℏω) ∝ √(ℏω - E_g) · [2π · √[R_ex / (ℏω - E_g)]] = 2π · √R_ex = const
   ```

   Кулонівська взаємодія кардинально змінює форму краю поглинання прямозонного напівпровідника: замість плавного зростання від нуля за законом квадратного кореня `√(ℏω - E_g)`, коефіцієнт поглинання виходить на сходинку кінцевої висоти безпосередньо біля краю `E_g`.

3. **Екситонні ефекти при непрямих переходах:**
   У непрямозонних напівпровідниках утворення зв'язаного непрямого екситона з повним квазіімпульсом `K = k_0` супроводжується поглинанням або випромінюванням фонона. Оскільки екситон як ціла квазічастинка має параболічну дисперсію `E_ex(K) = E_g - R_ex + (ℏ² (K - k_0)²) / (2 M_ex)` (де `M_ex = m*_e + m*_h` — повна маса екситона), інтегрування за густиною станів екситонної зони дає кореневу залежність від енергії:

   ```
   α_ind,ex(ℏω) ∝ √(ℏω - (E_g - R_ex) ∓ ℏΩ_q)
   ```

   Тому на низькотемпературних спектрах поглинання кремнію та германію біля кожного фононного порогу спостерігаються характерні східчасто-кореневі виступи, які переходять у квадратичну залежність `(ℏω - E_g ∓ ℏΩ_q)²` лише при вищих енергіях фотонів, коли починається поглинання в неперервний спектр незв'язаних електрон-діркових пар.

### 7. Порівняльна аналітика та метод Тауца (Tauc Plot)

Спектральні залежності коефіцієнта поглинання для різних типів оптичних переходів у напівпровідниках узагальнюються фундаментальним співвідношенням Тауца — Девіса — Мотта:

```
(α · ℏω)^(1/r) = C · (ℏω - E_g)
```

де показник степеня `r` однозначно визначається квантовою природою міжзонного переходу:

| Тип оптичного переходу | Спектральний закон `α(ℏω)` | Показник `r` | Лінеаризація для графіка Тауца |
|---|---|---|---|
| **Прямий дозволений** | `α ∝ (ℏω - E_g)^(1/2) / (ℏω)` | `r = 1/2` | `(α · ℏω)²` від `ℏω` |
| **Прямий заборонений** | `α ∝ (ℏω - E_g)^(3/2) / (ℏω)` | `r = 3/2` | `(α · ℏω)^(2/3)` від `ℏω` |
| **Непрямий дозволений** | `α ∝ (ℏω - E_g ∓ ℏΩ_q)² / (ℏω)` | `r = 2` | `(α · ℏω)^(1/2)` від `ℏω` |
| **Непрямий заборонений** | `α ∝ (ℏω - E_g ∓ ℏΩ_q)³ / (ℏω)` | `r = 3` | `(α · ℏω)^(1/3)` від `ℏω` |

Методика експериментального визначення параметрів зонної структури за методом Тауца полягає у побудові спектра поглинання у відповідних координатах та екстраполяції лінійних ділянок до перетину з віссю енергії `ℏω`:

1. Для **прямозонного кристала** будують графік величини `(α · ℏω)²` як функції енергії фотона `ℏω`. Точка перетину екстрапольованої прямої з віссю абцис безпосередньо дає ширину прямої забороненої зони `E_g`.
2. Для **непрямозонного кристала** будують графік величини `√(α · ℏω)` від `ℏω`. При кімнатній або підвищеній температурі на графіку чітко розрізняються дві лінійні ділянки з різними нахилами та двома характерними точками перетину:
   - Низькоенергетичний поріг `E_1 = E_g - ℏΩ_q` (гілка поглинання фонона);
   - Високоенергетичний поріг `E_2 = E_g + ℏΩ_q` (гілка випромінювання фонона).

Розв'язуючи систему двох лінійних рівнянь, знаходять фундаментальні параметри напівпровідника:

```
E_g = (E_1 + E_2) / 2      [ширина непрямої забороненої зони]
ℏΩ_q = (E_2 - E_1) / 2     [енергія характеристичного фонона решітки]
```

Порівняємо кількісні значення оптичного коефіцієнта поглинання для прямозонного арсеніду галію (`GaAs`) та непрямозонного кремнію (`Si`):

- В арсеніді галію (`GaAs`, `E_g = 1.42 еВ` при `300 K`) коефіцієнт пропорційності `A_dir ≈ 4.5·10⁴ см⁻¹ еВ⁻¹/²`. При невеликому перевищенні енергії фотона над краєм зони `ℏω = E_g + 0.1 еВ = 1.52 еВ` коефіцієнт поглинання досягає гігантського значення:

  ```
  α_GaAs(1.52 еВ) ≈ 1.4 · 10⁴ см⁻¹
  ```

  Характеристична глибина проникнення світла становить `δ = 1 / α ≈ 0.7 мкм`. Для практично повного (понад 95%) поглинання світлового потоку достатньо тонкої напівпровідникової плівки товщиною лише `d ≈ 2...3 мкм`.

- У кремнії (`Si`, `E_g = 1.12 еВ` при `300 K`, `ℏΩ_TO ≈ 0.058 еВ`) при тій самій надлишковій енергії `ℏω = E_g + 0.1 еВ = 1.22 еВ` коефіцієнт поглинання становить лише:

  ```
  α_Si(1.22 еВ) ≈ 50 см⁻¹
  ```

  Характеристична глибина проникнення світла сягає `δ = 1 / α ≈ 200 мкм`. Для ефективного поглинання сонячного випромінювання кремнієвий фотоелемент мусить мати товщину монокристалічної пластини не менше `150...200 мкм`, а також вимагає спеціального текстурування поверхні (мікропірамід) для багатократного внутрішнього відбивання світлових променів.

Квантово-механічний розрахунок доводить: різниця у швидкостях оптичних процесів між прямими та непрямими переходами становить 2–3 порядки величини. Прямі переходи є процесами першого порядку теорії збурень із часом життя випромінювальної рекомбінації порядку наносекунд (`1...10 нс`), що забезпечує майже стовідсотковий внутрішній квантовий вихід у світлодіодах та інжекційних напівпровідникових лазерах. Непрямі переходи є процесами другого порядку теорії збурень за участю фононів із часом випромінювальної рекомбінації порядку мікросекунд або мілісекунд (`10⁻⁶...10⁻³ с`), через що випромінювальний канал у непрямозонних напівпровідниках повністю програє безвипромінювальним процесам рекомбінації Оже та рекомбінації Шоклі — Ріда — Холла.
