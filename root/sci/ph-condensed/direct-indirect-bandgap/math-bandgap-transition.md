# 🧮 Квантово-механічний розрахунок оптичних переходів у прямозонних та непрямозонних напівпровідниках

Ця вставка містить квантово-механічне виведення ймовірностей міжзонних оптичних переходів, матричних елементів взаємодії та функціональної залежності коефіцієнта поглинання світла від енергії фотона для прямої та непрямої забороненої зони.

### 1. Гамільтоніан взаємодії та Золоте правило Фермі

Взаємодія електрона кристала з електромагнітною хвилею світла описується гамільтоніаном, одержаним із підстановки векторного потенціалу `A(r, t)` у квантове рівняння Шредінгера. У калібруванні Кулона (`div A = 0`) квадратичним за полем членом `A²` можна знехтувати для нелазерних інтенсивностей, тож гамільтоніан збурення має вигляд:

```
H_int = -(e / m_0) · A · p
```

де `e` — елементарний заряд, `m_0` — маса вільного електрона, `p = -iℏ ∇` — оператор квантово-механічного імпульсу.

Плоска монохроматична світлова хвиля з частотою `ω`, вектором поляризації `e_pol` та хвильовим вектором `k_ph` описується векторним потенціалом:

```
A(r, t) = A_0 · e_pol · [exp(i k_ph · r - i ω t) + exp(-i k_ph · r + i ω t)]
```

За Золотим правилом Фермі, ймовірність переходу електрона з початкового стану валентної зони `|i⟩ = |v, k_i⟩` у кінцевий стан зони провідності `|f⟩ = |c, k_f⟩` в одиницю часу дорівнює:

```
W_(i→f) = (2π / ℏ) · |M_(fi)|² · δ(E_c(k_f) - E_v(k_i) - ℏω)
```

де `M_(fi) = ⟨c, k_f| H_int |v, k_i⟩` — матричний елемент переходу.

### 2. Прямі переходи: хвильові функції Блоха та правило добору за імпульсом

У періодичному потенціалі решітки хвильові функції електрона є блохівськими станами `ψ_(n, k)(r) = u_(n, k)(r) · exp(i k · r)`, де `u_(n, k)(r)` — періодична функція з періодом кристалічної решітки, а `n` — номер енергетичної зони (`v` або `c`).

Обчислюємо матричний елемент між двома блохівськими станами:

```
M_(fi) = -(e A_0 / m_0) · ∫ u*_(c, k_f)(r) · exp(-i k_f · r) · [e_pol · p] · [u_(v, k_i)(r) · exp(i k_i · r)] · exp(i k_ph · r) d³r
```

Дія оператора імпульсу `p = -iℏ ∇` на добуток двох функцій дає два доданки:
1. Похідна від експоненти `exp(i k_i · r)` дає `ℏ k_i`, що описує міжзонне розсіяння всередині однієї зони (внутрішньозонне поглинання вільними носіями).
2. Похідна від блохівської амплітуди `u_(v, k_i)(r)` описує справжній міжзонний перехід під дією світла.

Оскільки довжина хвилі оптичного випромінювання (`λ ≈ 500...1000 нм`) значно перевищує сталу решітки (`a ≈ 0.5 нм`), хвильовий вектор фотона `k_ph = 2π / λ ≈ 10⁷ м⁻¹` на кілька порядків менший за розмір першої зони Бріллюена `k_ZB = π / a ≈ 6·10⁹ м⁻¹`.

Це дозволяє використати дипольне наближення `exp(i k_ph · r) ≈ 1`. Інтегрування по об'єму кристала розпадається на суму по елементарних комірках, що дає delta-функцію Кронекера для хвильових векторів:

```
k_f = k_i + k_ph ≈ k_i     [правило добору: вертикальний перехід]
```

Остаточний матричний елемент прямого дозволеного переходу дорівнює:

```
M_(fi) ≈ -(e A_0 / m_0) · (e_pol · p_(cv)) · δ_(k_f, k_i)
```

де `p_(cv) = (1 / Ω_cell) · ∫_cell u*_(c, 0)(r) p u_(v, 0)(r) d³r` — міжзонний матричний елемент імпульсу, який обчислюється по об'єму однієї елементарної комірки `Ω_cell`.

### 3. Виведення спектрального коефіцієнта поглинання прямозонного напівпровідника

Коефіцієнт оптичного поглинання `α(ℏω)` визначається як відношення енергії, поглинутої в одиниці об'єму за одиницю часу, до густини потоку падаючої енергії Пойнтінга `S`:

```
α(ℏω) = (ℏω · ∑_(i, f) W_(i→f)) / (V · S)
```

Густина потоку енергії електромагнітної хвилі в середовищі з показником заломлення `n_r`:

```
S = (1/2) · ε_0 · n_r · c · ω² · A_0²
```

Переходимо від сумування по дискретних станах `k` до інтегрування по фазовому об'єму з урахуванням спінового виродження (`2`):

```
∑_k → (2 · V / (2π)³) · ∫ d³k
```

Енергія міжзонного переходу для двох параболічних зон (зони провідності з ефективною масою `m*_e` та валентної зони з ефективною масою `m*_h`):

```
E(k) = E_c(k) - E_v(k) = E_g + (ℏ² k²) / (2 m*_e) + (ℏ² k²) / (2 m*_h) = E_g + (ℏ² k²) / (2 m_r)
```

де `m_r` — зведена ефективна маса пар електрон-дірка:

```
1 / m_r = 1 / m*_e + 1 / m*_h   ⇒   m_r = (m*_e · m*_h) / (m*_e + m*_h)
```

Враховуючи трьохвимірну симетрію, інтеграл по сферичних ізоенергетичних поверхнях `d³k = 4π k² dk` перетвориться на інтеграл по енергії через зведену густину станів `ρ_red(E)`:

```
ρ_red(E) = (1 / 2π²) · (2 m_r / ℏ²)^(3/2) · (E - E_g)^(1/2)
```

Підставляючи густину станів та матричний елемент у формулу для `α(ℏω)`, одержуємо фундаментальний закон спектральної залежності поглинання прямозонного напівпровідника:

```
α_direct(ℏω) = [e² · (2 m_r)^(3/2) · |e_pol · p_(cv)|²] / [3 π · n_r · c · ε_0 · m_0² · ℏ²] · (ℏω - E_g)^(1/2) / (ℏω)
```

Для енергій фотонів біля краю поглинання (`ℏω ≈ E_g`) множник `1 / (ℏω)` можна вважати константою, що дає канонічну пропорційність:

```
α_direct(ℏω) = A_dir · (ℏω - E_g)^(1/2)    [при ℏω ≥ E_g]
```

Значення константи `A_dir` для типових прямозонних кристалів (`GaAs`, `InP`) лежить у діапазоні `(3...6) · 10⁴ см⁻¹ еВ⁻¹/²`.

Якщо матричний елемент імпульсу для центра зони `p_(cv)(0) = 0` через симетрію хвильових функцій (прямий заборонений перехід), розклад `p_(cv)(k) = |k| · (∇_k p_(cv))` дає підкореневий вираз третього степеня:

```
α_forbidden(ℏω) = A_forb · (ℏω - E_g)^(3/2)
```

### 4. Непрямі переходи: другий порядок теорії збурень та фононний оператор

У непрямозонному напівпровіднику мінімум зони провідності розташований у точці `k_c`, тоді як максимум валентної зони — у точці `k_v` (`k_c ≠ k_v`). Оскільки `k_ph ≈ 0`, прямому переходу заважає відсутність дозволених кінцевих станів із тим самим квазіімпульсом.

Перехід стає можливим завдяки одночасній взаємодії з коливаннями решітки. Гамільтоніан електрон-фононної взаємодії описує випромінювання або поглинання фонона з квазіімпульсом `q` та частотою `Ω_q`:

```
H_el-phon = ∑_q [V_q · a_q · exp(i q · r) + V*_q · a⁺_q · exp(-i q · r)]
```

де `a_q` та `a⁺_q` — оператори знищення та народження фонона.

Оскільки перехід є двостадійним, амплітуда переходу розраховується за другим порядком квантово-механічної теорії збурень як сума по всіх можливих проміжних віртуальних станах `|m⟩`:

```
M_(fi)^(ind) = ∑_m [ (⟨f| H_el-phon |m⟩ · ⟨m| H_int |i⟩) / (E_i - E_m ± ℏΩ) + (⟨f| H_int |m⟩ · ⟨m| H_el-phon |i⟩) / (E_i - E_m') ]
```

Проміжні стани `|m⟩` — це віртуальні стани електрона в зоні провідності або дірки у валентній зоні.

При непрямому переході закони збереження набирають вигляду:

```
1) Збереження енергії:   E_c(k_f) - E_v(k_i) = ℏω ± ℏΩ
2) Збереження імпульсу:  k_f - k_i = ±q
```

знак `+` відповідає поглинанню фонона середовища, а знак `-` — випромінюванню фонона в решітку.

### 5. Виведення квадратичного закону непрямого поглинання

Для обчислення повного коефіцієнта поглинання необхідно проінтегрувати ймовірності переходів по всіх початкових станах валентної зони `k_i` та кінцевих станах зони провідності `k_f`, які задовольняють закон збереження енергії.

На відміну від прямого переходу, де хвильовий вектор кінцевого стану суворо фіксований `k_f = k_i`, при непрямому переході фонон може забрати будь-який імпульс `q = k_f - k_i`. Це знімає обмеження суворого зв'язку між `k_f` та `k_i`.

Повний інтеграл розпадається на добуток двох незалежних густин станів валентної зони `ρ_v(E_v)` та зони провідності `ρ_c(E_c)`:

```
α_indirect(ℏω) ∝ ∫ ∫ ρ_v(E_v) · ρ_c(E_c) · δ(E_c - E_v - ℏω ± ℏΩ) dE_v dE_c
```

Підставляючи параболічні густини станів `ρ_v ∝ (E_v,max - E_v)^(1/2)` та `ρ_c ∝ (E_c - E_c,min)^(1/2)` і беручи подвійний інтеграл, одержуємо квадратичну залежність від перевищення енергії:

```
∫_0^(ℏω - E_g ± ℏΩ) E'^(1/2) · (ℏω - E_g ± ℏΩ - E')^(1/2) dE' = (π / 8) · (ℏω - E_g ± ℏΩ)²
```

Враховуючи статистику фононів Бозе-Айнштайна для чисел заповнення фононних мод з енергією `ℏΩ` при температурі `T`:

```
N_q = 1 / [exp(ℏΩ / k_B T) - 1]
```

одержуємо дві температурно-залежні компоненти коефіцієнта непрямого поглинання:

#### Гілка А: Поглинання фонона кристала
Вимагає наявності теплових фононів у решітці, тому її інтенсивність спадає до нуля при наближенні до абсолютного нуля температур (`T → 0 K`):

```
α_abs(ℏω) = B_ind · (ℏω - E_g + ℏΩ)² / [exp(ℏΩ / k_B T) - 1]    [поріг: ℏω ≥ E_g - ℏΩ]
```

#### Гілка Б: Випромінювання фонона в решітку
Можливе навіть при `T = 0 K`, оскільки електрон сам створює фонон у решітці:

```
α_em(ℏω) = B_ind · (ℏω - E_g - ℏΩ)² / [1 - exp(-ℏΩ / k_B T)]    [поріг: ℏω ≥ E_g + ℏΩ]
```

Повний коефіцієнт непрямого поглинання є сумою обох компонент:

```
α_indirect(ℏω) = α_abs(ℏω) + α_em(ℏω)
```

### 6. Порівняльна аналітика залежностей `α(ℏω)`

Графічне вимірювання залежності `α(ℏω)` дозволяє експериментально визначити тип забороненої зони та її ширину `E_g`:

1. Для **прямозонного напівпровідника** будують графік у координатах `[α · ℏω]²` від `ℏω`. Екстраполяція прямолінійної ділянки до перетину з віссю енергій дає точне значення прямої забороненої зони `E_g`.
2. Для **непрямозонного напівпровідника** будують графік у координатах `α^(1/2)` від `ℏω` (метод Тауца, англ. *Tauc plot*). На графіку виникають дві зламані лінійні ділянки з порогами `E_1 = E_g - ℏΩ` та `E_2 = E_g + ℏΩ`. Півсума цих двох порогів дає ширину непрямої забороненої зони `E_g = (E_1 + E_2) / 2`, а їх піврізниця — енергію фонона `ℏΩ = (E_2 - E_1) / 2`.

```
Прямий дозволений перехід:    α ∝ (ℏω - E_g)^(1/2)   ⇒  α² ∝ (ℏω - E_g)
Прямий заборонений перехід:   α ∝ (ℏω - E_g)^(3/2)   ⇒  α^(2/3) ∝ (ℏω - E_g)
Непрямий дозволений перехід:  α ∝ (ℏω - E_g ∓ ℏΩ)²  ⇒  √α ∝ (ℏω - E_g ∓ ℏΩ)
Непрямий заборонений перехід: α ∝ (ℏω - E_g ∓ ℏΩ)³  ⇒  α^(1/3) ∝ (ℏω - E_g ∓ ℏΩ)
```

Математичний аналіз переконує: непрямі переходи є процесами другого порядку теорії збурень, їх коефіцієнти поглинання на кілька порядків нижчі, ніж у прямих переходів, а інтенсивність суттєво залежить від температури через теплову статистику фононів.
