# ⚙️ Розрахунок спектра поглинання та товщини напівпровідника для фотоприймача

Ця вставка містить аналіз чисельного алгоритму та програмну реалізацію мовами C та C++ для розрахунку коефіцієнтів міжзонного оптичного поглинання `α(hν)` та обчислення мінімальної товщини напівпровідникового шару `d`, необхідної для поглинання заданої частки падаючого фотонного випромінювання (95%) згідно з законом Бугера — Ламберта — Бера.

### Фізико-математична модель та інженерний розрахунок

Під час проектування фотоприймачів, фотодіодів, фототранзисторів, сонячних елементів та матриць зображення (CMOS/CCD) основным конструктивним параметром є товщина фотоактивної області. Якщо шар напівпровідника надто тонкий, значна частина світла пройде наскрізь без поглинання, що знизить квантову ефективність приладу. Якщо ж шар зроблено надто товстим, це збільшить час прольоту фотозгенерованих носіїв заряду (електронів і дірок), погіршить часовий відгук (швидкодію) та збільшить ймовірність об'ємної рекомбінації носіїв до їх виходу в зовнішнє коло.

Зменшення інтенсивності монохроматичного світлового потоку з частотою `ν` під час поширення вглиб кристала уздовж осі `z` описується диференціальним законом поглинання:

```
dI / dz = -α(hν) · I(z)
```

де `α(hν)` — спектральний коефіцієнт міжзонного поглинання в `см⁻¹`.

За умови падаючої інтенсивності `I(0) = I_0` на поверхні напівпровідникового кристала, розв'язком є експоненційний закон Бугера — Ламберта — Бера:

```
I(z) = I_0 · exp(-α(hν) · z)
```

Частка поглинутої в об'ємі світлової енергії на глибині `d` визначається співвідношенням:

```
η(d) = (I_0 - I(d)) / I_0 = 1 - exp(-α(hν) · d)
```

Виражаючи товщину `d` через задану частку поглинання `η` (наприклад, `η = 0.95`, що відповідає поглинанню 95% падаючих фотонів), одержуємо розрахункову формулу:

```
1 - η = exp(-α · d)   ⇒   ln(1 - η) = -α · d   ⇒   d_η = -ln(1 - η) / α
```

Для 95% поглинання (`η = 0.95`):

```
d_95 = -ln(0.05) / α = ln(20) / α ≈ 2.99573 / α
```

### Алгоритм розрахунку коефіцієнта поглинання `α(hν)`

Функціональна залежність `α(hν)` кардинально різниться для матеріалів із прямою та непрямою забороненою зоною:

#### 1. Прямозонні напівпровідники (`GaAs`, `InP`, `GaN`, `CdTe`)
Для фотонів з енергією, меншою за ширину забороненої зони (`hν < E_g`), міжзонне поглинання відсутнє (`α = 0`). Коли енергія фотона перевищує поріг (`hν ≥ E_g`), міжзонні прямі вертикальні переходи описуються підкореневою залежністю:

```
α_direct(hν) = A_dir · (hν - E_g)^(1/2)
```

де `A_dir` — характерна константа матеріалу (зазвичай `(3...6) · 10⁴ см⁻¹ еВ⁻¹/²`), яка залежить від зведеної ефективної маси електрона та дірки `m_r` і матричного елемента імпульсу.

#### 2. Непрямозонні напівпровідники (`Si`, `Ge`, `SiC`, `GaP`)
Оскільки оптичний перехід вимагає компенсації великого квазіімпульсу `Δk ≈ k_0`, у процесі беруть участь акустичні або оптичні фонони кристалічної решітки з енергією `ℏΩ` та вектором `q`. Коефіцієнт поглинання є сумою двох температурно-залежних компонент:

- **Гілка з поглинанням фонона решітки** (можлива при енергіях `hν ≥ E_g - ℏΩ`):
  ```
  α_abs(hν) = B_ind · (hν - E_g + ℏΩ)² / [exp(ℏΩ / k_B T) - 1]
  ```
- **Гілка з випромінюванням фонона в решітку** (можлива при енергіях `hν ≥ E_g + ℏΩ`):
  ```
  α_em(hν) = B_ind · (hν - E_g - ℏΩ)² / [1 - exp(-ℏΩ / k_B T)]
  ```

Повний коефіцієнт непрямого поглинання дорівнює `α_indirect(hν) = α_abs(hν) + α_em(hν)`.

### Аналіз крайових випадків та фізичних обмежень

При практичній чисельній реалізації в програмі необхідно враховувати кілька важливих фізичних обставин і крайових режимів:

1. **Крайовий режим низьких температур (`T → 0 K`):**
   При наближенні температури до абсолютного нуля теплові коливання решітки замерзають, і число фононів `N_q = 1 / [exp(ℏΩ / k_B T) - 1] → 0`. Гілка поглинання фонона `α_abs` повністю зникає. Поглинання стає можливим лише для фотонів з енергією `hν ≥ E_g + ℏΩ` за рахунок випромінювання фонона.
2. **Високі енергії у непрямих напівпровідниках (`hν ≫ E_g`):**
   У непрямозонному кремнії при підвищенні енергії фотона до `hν ≥ 3.4 еВ` вмикаються прямі міжзонні переходи (оскільки зона провідності має прямий мінімум над валентною зоною у центрі зони Бріллюена). У цьому діапазоні коефіцієнт поглинання кремнію стрибкоподібно зростає від `10³ см⁻¹` до `10⁵ см⁻¹`, і чисельний розрахунок мусить перемикатися на прямозонну модель.
3. **Оптичні втрати на відбивання:**
   Реальний коефіцієнт поглинання падаючого світла зменшується за рахунок відбивання від поверхні напівпровідника з показником заломлення `n_r`. Згідно з формулою Френеля для нормального падіння:
   ```
   R = (n_r - 1)² / (n_r + 1)²
   ```
   Для кремнію (`n_r ≈ 3.5`) відбивання становить `R ≈ 30%`. Отже, повна поглинута частка світла без просвітлювального покриття дорівнює `η_real = (1 - R) · [1 - exp(-α · d)]`. Для досягнення 95% поглинання від початкового потоку необхідне нанесення антивідбивальних плівок (`Si_3N_4` або `TiO_2`).

### Перевірка чисельної стійкості та обробка помилок

Під час чисельного обчислення показникові функції `exp(ℏΩ / k_B T)` при дуже низьких температурах або великих енергіях фононів можуть спричиняти переповнення діапазону плаваючої крапки (`overflow`). Програма містить захист від арифметичного переповнення:
- Якщо аргумент експоненти перебільшує 80.0, вираз `exp(x)` замінюється на граничне наближення, запобігаючи генерації `NaN` або `Inf`.
- При коефіцієнтах поглинання `α < 10⁻⁶ см⁻¹` (область високої прозорості нижче порогової енергії) функція розрахунку товщини повертає умовний прапорець нескінченності `10⁹ мкм` ("N/A"), що вказує на неможливість створення фотоприймача на цій довжині хвилі.
- У C++ реалізації застосовано строгий клас `AbsorptionCalculator` із постійними методами `[[nodiscard]]` та інкапсульованою температурною залежністю, а в C реалізації — безпечну передачу структур за вказівником на константу.

### Порівняльний аналіз прямозонних та непрямозонних матеріалів

Розрахунки за алгоритмом показують вражаючу відмінність між `GaAs` та `Si`:

- **Арсенід галію (`GaAs`):** При енергії фотонів видимого діапазону `hν = 1.8 еВ` коефіцієнт поглинання дорівнює `α ≈ 2.7·10⁴ см⁻¹`. Для поглинання 95% світла достатньо шару товщиною лише `d_95 ≈ 1.1 мкм`. Це дозволяє створювати надтонкі плівкові сонячні елементи для космічних супутників та надшвидкодійні PIN-фотодіоди з часом відгуку `τ < 100 пс`.
- **Кремній (`Si`):** Для червоного світла з енергією `hν = 1.8 еВ` непрямий коефіцієнт поглинання становить лише `α ≈ 2.2·10³ см⁻¹`. Необхідна товщина фотоактивного шару зростає до `d_95 ≈ 13.6 мкм`. Для фотонів близько краю забороненої зони (`hν = 1.2 еВ`, ближнє інфрачервоне випромінювання) коефіцієнт падає до `α ≈ 150 см⁻¹`, що вимагає товщини пластини `d_95 ≈ 200 мкм`.
