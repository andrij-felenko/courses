Ця вставка містить суворий математичний вивід розкладів густини енергії магнітокристалічної, поверхневої, магнітостатичної, магнітопружної, обмінної та хіральної анізотропії Дзялошинського — Морія, вивід обертальних моментів для торсійного магнітометра, вивід кривих розмагнічувальних факторів еліпсоїдів, квантовомеханічне виведення констант анізотропії через спін-орбітальну взаємодію, вивід товщини й енергії доменних стінок, а також вивід рівняння астроїди Стонера — Вольфарта та розрахунок теплового бар'єра релаксації Нееля — Арреніуса.

### 1. Феноменологічні розклади густини магнітокристалічної енергії

Вектор макроскопічної намагніченості `M` має постійну за модулем величину `|M| = M_s` (намагніченість насичення) при фіксованій температурі. Орієнтація вектора задається одиничним вектором `m = M / M_s = (α_1, α_2, α_3)`, де `α_1, α_2, α_3` — напрямні косинуси відносно кристалографічних осей `x, y, z`:

```
α_1 = cos(φ) · sin(θ)
α_2 = sin(φ) · sin(θ)
α_3 = cos(θ)
```

Густина потенціальної енергії магнітокристалічної анізотропії `E_A` виражається у вигляді інваріантного феноменологічного ряду за степенями `α_i`, який задовольняє симетрію точкової групи кристала та часову інваріантність `E(m) = E(-m)`.

#### Одноосна кристалічна анізотропія (гексагональні та тетрагональні ґратки)

Для гексагональних кристалів (наприклад, кобальту `Co`) головна вісь симетрії спрямована вздовж осі `z [0001]`. Енергія залежить лише від кута `θ` між вектором намагніченості `m` та віссю `z`:

```
E_A = K_1 · sin²(θ) + K_2 · sin⁴(θ) + K_3 · sin⁶(θ)
```

де `K_1, K_2, K_3` — константи одноосної анізотропії (вимірюються в `Дж/м³`).

Залежно від знаків та співвідношення `K_1` і `K_2` виникають три можливі фундаментальні конфігурації легких напрямків:
1. **Легка вісь (Easy Axis):** При `K_1 > 0` та `K_1 + K_2 > 0` мінімум енергії досягається при `θ = 0` та `θ = π` (уздовж осі `z`).
2. **Легка площина (Easy Plane):** При `K_1 < 0` та `K_2 < |K_1| / 2` мінімум енергії досягається при `θ = π / 2` (у базисній площині `xy`).
3. **Легкий конус (Easy Cone):** При `K_1 < 0` та `K_2 > |K_1| / 2` мінімум енергії виникає під кутом `θ_0`, який задовольняє умову:

```
sin²(θ_0) = - K_1 / (2 · K_2)
```

Ефективне поле анізотропії `H_A`, яке утримує намагніченість уздовж легкої осі, визначається другою похідною енергії за кутом при `θ = 0`:

```
H_A = (2 · K_1) / (μ_0 · M_s)
```

#### Кубічна кристалічна анізотропія (ОЦК та ГЦК ґратки)

Для кубічних кристалів (залізо `Fe`, нікель `Ni`) енергія розкладається за парними комбінаціями напрямних косинусів, інваріантними відносно перестановки осей `x, y, z`:

```
E_A = K_1 · (α_1²·α_2² + α_2²·α_3² + α_3²·α_1²) + K_2 · (α_1²·α_2²·α_3²)
```

У сферичній системі координат `(θ, φ)` при `K_2 = 0` формула набуває вигляду:

```
E_A = K_1 · (sin⁴(θ) · sin²(2φ) / 4 + sin²(2θ) / 4)
```

Аналіз екстремумів цієї функції виявляє дві фундаментальні геометрії:
- **`K_1 > 0` (Залізо Fe):** Мінімуми енергії `E_A = 0` виникають уздовж осей ребер куба `<100>`. Напрямки діагоналей куба `<111>` відповідають максимуму енергії `E_A = K_1 / 3` (важкі осі). Напрямки граневих діагоналей `<110>` дають проміжну енергію `E_A = K_1 / 4`.
- **`K_1 < 0` (Нікель Ni):** Мінімуми енергії `E_A = K_1 / 3` (з урахуванням від'ємного знаку) досягаються вздовж просторових діагоналей куба `<111>` (легкі осі). Напрямки ребер куба `<100>` виступають важкими осями.

#### Розрахунок анізотропії при обертанні намагніченості у площині (110)

У площині `(110)` вектор намагніченості утворює кут `θ` з віссю `[001]`. Напрямні косинуси дорівнюють:

```
α_1 = (1 / √2) · sin(θ)
α_2 = (1 / √2) · sin(θ)
α_3 = cos(θ)
```

Підставляючи ці косинуси в розклад кубічної енергії при `K_2 = 0`:

```
E_A(θ) = K_1 · [ (1/4)·sin⁴(θ) + (1/2)·sin²(θ)·cos²(θ) + (1/2)·sin²(θ)·cos²(θ) ]
       = K_1 · [ (1/4)·sin⁴(θ) + sin²(θ)·cos²(θ) ]
       = (K_1 / 32) · [ 7 - 4·cos(2θ) - 3·cos(4θ) ]
```

Аналіз цієї функції показує локальні екстремуми при:
- `θ = 0` (напрямок `[001]`): `E_A = 0`
- `θ = 54.74°` (напрямок `[111]`): `E_A = K_1 / 3`
- `θ = 90°` (напрямок `[110]`): `E_A = K_1 / 4`

#### Математика вимірювання констант: механічний обертальний момент (Torque Magnetometry)

При обертанні сильного зовнішнього поля `H` у площині кристала на зразок діє механічний обертальний момент `L_z = - ∂E_A / ∂θ`.

Для одноосного кристала при обертанні поля у площині, що містить легку вісь:

```
L_z(θ) = - d/dθ [K_1 · sin²(θ) + K_2 · sin⁴(θ)]
       = - K_1 · sin(2θ) - K_2 · (sin(2θ) - (1/2) · sin(4θ))
```

Для кубічного кристала при обертанні поля у площині `(001)` (`θ = π / 2`, кут `φ` вимірюється від осі `[100]`):

```
E_A(φ) = K_1 · sin²(φ) · cos²(φ) = (K_1 / 4) · sin²(2φ)
```

Механічний обертальний момент як функція кута `φ`:

```
L_z(φ) = - dE_A / dφ
       = - (K_1 / 2) · sin(4φ)
```

Вимірюючи амплітуду синусоїдальної залежності `L_z(4φ)` на обертальному магнітометрі, експериментатор з високою точністю визначає константу `K_1`.

### 2. Квантовомеханічне виведення: спін-орбітальна взаємодія у другого порядку теорії збурень

З мікроскопічної точки зору спіновий гамільтоніан 3d-електронів не містить прямої залежності від кристалічних осей. Анізотропія виникає як поправка другого порядку теорії збурень від спін-орбітальної взаємодії `H_so = λ L · S`, де `λ` — константа спін-орбітального зв'язку (порядку `0.01 ... 0.05 еВ` для 3d-металів).

Початковий основний стан електронів `|g⟩` має заморожений орбітальний момент (`⟨g| L |g⟩ = 0`) через сильне кулонівське кристалічне поле. Проте спін-орбітальний оператор змішує основний стан з збудженими орбітальними станами `|e⟩`:

```
ΔE_so = - λ² · ∑_e [ |⟨g| L · S |e⟩|² / (E_e - E_g) ]
```

Розкриваємо скалярний добуток `L · S = L_z · S_z + L_x · S_x + L_y · S_y`. Оскільки спін має спрямованість вздовж вектора `m = (α_1, α_2, α_3)`, очікуване значення спінових компонент `S_i = S · α_i`.

Для одновимірної анізотропії на поверхні або в гексагональній ґратці різниця енергій між орієнтацією спінів уздовж `z` та у площині `xy` дає квантовий вираз для константи Нееля — Ван Флека:

```
K_1 = λ² · S² · ∑_e [ ( |⟨g| L_z |e⟩|² - |⟨g| L_x |e⟩|² ) / (E_e - E_g) ]
```

Ця формула висвітлює фундаментальний фізичний факт: **анізотропія пропорційна анізотропії орбітального моменту електрона**. Якщо кристалічне поле повністю симетричне (наприклад, у товщі кубічного кристала), внески `L_x, L_y, L_z` майже повністю компенсують один одного, що пояснює малість кубічної анізотропії (`K_1 ~ λ⁴ / ΔE³`). На поверхні або інтерфейсі симетрія розірвана, що викликає потужний внесок другого порядку `~ λ² / ΔE` і дає велику перпендикулярну анізотропію.

### 3. Розрахунок параметрів 180-градусної доменної стінки Блоха

Анізотропія безпосередньо задає товщину `δ` та поверхневу густину енергії `γ_dw` доменних стінок, які розділяють області з різним напрямком намагніченості.

Розглянемо 180-градусну доменну стінку Блоха вздовж осі `x`, у якій вектор намагніченості розвертається на кут `θ(x)` від `0` до `π`. Повна енергія стінки на одиницю площі складається з обмінної енергії деформації спінів та енергії анізотропії:

```
γ_dw = ∫ [ A · (dθ/dx)² + K_eff · sin²(θ) ] dx
```

де `A` — константа обмінного зв'язку (у `Дж/м`).

Для мінімізації функціонала застосовуємо рівняння Ейлера — Лагранжа:

```
2 A · (d²θ/dx²) - K_eff · sin(2θ) = 0
```

Інтегруючи це диференціальне рівняння з граничними умовами `θ(-∞) = 0` та `θ(+∞) = π`:

```
dθ/dx = √(K_eff / A) · sin(θ)
```

Інтегрування дає точний профіль розвороту спінів у доменній стінці:

```
x(θ) = √(A / K_eff) · ln(tan(θ / 2))
```

Точна поверхнева енергія 180-градусної доменної стінки:

```
γ_dw = 4 · √(A · K_eff)
```

Ефективна товщина доменної стінки `δ`, яка визначається за максимальним нахилом `(dθ/dx)_max = √(K_eff / A)`:

```
δ = π · √(A / K_eff)
```

Ці формули чітко показують фізичний компроміс: обмінна енергія `A` намагається зробити стінку якомога ширшою (щоб кут між сусідніми спінами був мінімальним), тоді як енергія анізотропії `K_eff` намагається стиснути стінку (щоб якомога менше спінів відхилялося від легкої осі). У високоанізотропних матеріалах (NdFeB, FePt) товщина доменної стінки становить всього `2 ... 4 нм`, тоді як у м'якому пермаллої сягає сотень нанометрів.

### 4. Магнітостатична енергія розмагнічування та тензор розмагнічувальних факторів

Коли зразок скінченного об'єму `V` намагнічений до величини `M`, на його поверхнях виникають ефективні магнітні заряди з густиною `σ_m = M · n`, де `n` — зовнішня нормаль. Ці заряди створюють всередині зразка поле розмагнічування `H_d`.

Для зразків у формі еліпсоїдів обертання поле розмагнічування однорідне й пов'язане з намагніченістю через діагональний тензор размагнічувальних факторів `N_ik`:

```
H_d = - N · M
```

Головні значення тензора задовольняють фундаментальну сумарну теорему:

```
N_x + N_y + N_z = 1
```

Густина магнітостатичної енергії розмагнічування `E_d` дорівнює:

```
E_d = - (1/2) · μ_0 · (H_d · M)
    = (1/2) · μ_0 · (N_x · M_x² + N_y · M_y² + N_z · M_z²)
```

Застосуємо напрямні косинуси `M_i = M_s · α_i`:

```
E_d = (1/2) · μ_0 · M_s² · (N_x · α_1² + N_y · α_2² + N_z · α_3²)
```

#### Математичний вивід факторів розмагнічування еліпсоїдів обертання

Розглянемо витягнутий еліпсоїд з півосями `a = b` (поперечні) та `c` (вздовж осі `z`), де співвідношення осей `m = c / a > 1`.

Аналітично розрахований фактор розмагнічування `N_z` дається інтегральним виразом:

```
N_z = (1 / (m² - 1)) · [ (m / (2 · √(m² - 1))) · ln((m + √(m² - 1)) / (m - √(m² - 1))) - 1 ]
```

Для сплюснутого еліпсоїда обертання (сфероїд типу диску, `a = b > c`, `m = c / a < 1`):

```
N_z = (1 / (1 - m²)) · [ 1 - (m / √(1 - m²)) · arcsin(√(1 - m²)) ]
```

Поперечні фактори для обох геометрій через ротаційну симетрію дорівнюють:

```
N_x = N_y = (1 - N_z) / 2
```

Асимптотичний аналіз трьох граничних геометрій:
1. **Ідеальна сфера (`a = b = c`, `m = 1`):**
   ```
   N_x = N_y = N_z = 1 / 3
   ```
   Густина енергії `E_d = (1/6) μ_0 M_s²` не залежить від напрямку `m`. Анізотропія форми строго дорівнює нулю (`K_shape = 0`).

2. **Нескінченно довгий циліндр / дріт (`c >> a`, `m → ∞`):**
   ```
   N_z = 0
   N_x = N_y = 1 / 2
   ```
   Константа анізотропії форми вздовж осі дроту дорівнює:
   ```
   K_shape = (1/4) · μ_0 · M_s²
   ```

3. **Тонка плівка (`c << a`, `m → 0`):**
   ```
   N_z = 1
   N_x = N_y = 0
   ```
   Константа анізотропії форми для виходу намагніченості з площини плівки:
   ```
   K_shape = - (1/2) · μ_0 · M_s²
   ```

Від'ємний знак означає, що анізотропія форми примусово утримує вектор намагніченості у площині плівки (`θ = π / 2`).

### 5. Поверхнева анізотропія Нееля та ефективна константа тонкої плівки

На межі поділу феромагнетика з ізолятором або іншим металом (наприклад, `Co/Pt` або `Fe/MgO`) порушення симетрії створює поверхневу густину енергії `E_s` (вимірюється в `Дж/м²`):

```
E_s = K_s · sin²(θ)
```

Для плівки товщиною `t` з двома поверхнями (верхньою та нижньою) загальна густина енергії на одиницю об'єму виражається як сума об'ємної магнітокристалічної анізотропії `K_v`, анізотропії форми та поверхневого внеску:

```
K_eff = K_v - (1/2) · μ_0 · M_s² + (2 · K_s) / t
```

Умова виникнення **перпендикулярної магнітної анізотропії** (PMA, коли легка вісь строго перпендикулярна плівці, тобто `K_eff > 0`):

```
(2 · K_s) / t > (1/2) · μ_0 · M_s² - K_v
```

Критична товщина `t_c`, нижче якої намагнічування спонтанно виходить з площини плівки у вертикальний напрямок:

```
t_c = (4 · K_s) / (μ_0 · M_s² - 2 · K_v)
```

### 6. Вивід астроїди Стонера — Вольфарта

Розглянемо однодоменну частинку з ефективною одноосною константою `K_eff` та легкою віссю уздовж `z`. Зовнішнє магнітне поле `H` прикладене у площині `xz` під кутом `θ_H` до легкої осі. Вектор намагніченості утворює кут `θ` з легкою віссю.

Повна густина енергії з урахуванням зееманівського взаємодії:

```
E(θ) = K_eff · sin²(θ) - μ_0 · M_s · H · cos(θ - θ_H)
```

Введемо безрозмірні змінні для полів:

```
H_A = (2 · K_eff) / (μ_0 · M_s)
h = H / H_A
h_x = h · sin(θ_H)
h_z = h · cos(θ_H)
```

Перепишемо безрозмірну енергію `e(θ) = E(θ) / (2 K_eff)`:

```
e(θ) = (1/2) · sin²(θ) - h_z · cos(θ) - h_x · sin(θ)
```

Умова рівноваги (перша похідна по `θ` дорівнює нулю):

```
de/dθ = sin(θ)·cos(θ) + h_z·sin(θ) - h_x·cos(θ) = 0
```

Розділимо на `cos(θ) · sin(θ)`:

```
1 + h_z / cos(θ) - h_x / sin(θ) = 0
```

Умова межі стійкості станів (точка перегину потенціального бар'єра, друга похідна дорівнює нулю):

```
d²e/dθ² = cos²(θ) - sin²(θ) + h_z·cos(θ) + h_x·sin(θ) = 0
```

Шляхом алгебраїчних перетворень системи рівнянь `de/dθ = 0` та `d²e/dθ² = 0` отримуємо параметричний зв'язок компонент критичного поля через кут намагніченості `θ`:

```
h_x = sin³(θ)
h_z = - cos³(θ)
```

Підносячи обидва рівняння до степеня `2/3` та додаючи їх, отримуємо канонічне рівняння **астроїди Стонера — Вольфарта**:

```
h_x^(2/3) + h_z^(2/3) = 1
```

або у фізичних полях:

```
(H_x)^(2/3) + (H_z)^(2/3) = (H_A)^(2/3)
```

#### Аналіз перемагнічування за допомогою астроїди

1. **Якщо вектор зовнішнього поля `(h_x, h_z)` лежить всередині астроїди:** Функція енергії має два локальні мінімуми. Система перебуває у двостабільному стані (гістерезис).
2. **При виході вектора поля за межі астроїди:** Один із мінімумів енергії зникає, і вектор намагніченості стрибком розвертається у єдиний залишковий мінімум (незворотний стрибок Баукгаузена).
3. **Критичне поле перемагнічування `H_c(θ_H)`:**
   - При `θ_H = 0` (поле уздовж легкої осі): `H_c = H_A`. Петля гістерезису строго прямокутна з коерцитивною силою `H_c = H_A`.
   - При `θ_H = 45°`: `H_c = 0.5 · H_A` (мінімальне поле перемикання).
   - При `θ_H = 90°` (поле перпендикулярне легкості): `H_c = 0`. Петля перетворюється на лінійну безгістерезисну залежність.

### 7. Обмінна анізотропія (Exchange Bias) та несиметричні анізотропні взаємодії

Коли феромагнітний шар (FM) товщиною `t_FM` межує з антиферомагнетиком (AFM), при охолодженні системи нижче температури Нееля `T_N` у зовнішньому магнітному полі виникає обмінне зсунення (англ. *Exchange Bias*).

Густина поверхневої обмінної енергії `E_eb`:

```
E_eb = - J_eb · cos(θ - θ_AFM)
```

де `J_eb` — константа інтерфейсного обмінного зв'язку (в `Дж/м²`), `θ_AFM` — напрямок закріплення спінів антиферомагнетика.

Ефективне поле обмінного зсуву `H_eb`, яке зміщує петлю гістерезису вздовж осі полів:

```
H_eb = J_eb / (μ_0 · M_s · t_FM)
```

Це поле створює однонаправлену анізотропію (з постійним мінімумом при `θ = 0`), на відміну від класичної одноосної анізотропії, яка має два симетричні мінімуми при `θ = 0` та `θ = π`.

При одночасному наявності спін-орбітальної взаємодії та порушення інверсійної симетрії на межі поділу двох металів виникає несиметрична **взаємодія Дзялошинського — Морія** (DMI). Густина енергії DMI виражається вектором Дзялошинського `D_ij`:

```
E_DMI = - D_ij · (S_i × S_j)
```

Ця взаємодія створює хіральну анізотропію, яка віддає перевагу ліво- або правозакрученим спіновим конфігураціям (доменним стінкам Ніеля та магнітним скірміонам).

### 8. Теплова релаксація Нееля — Арреніуса та суперпарамагнітний бар'єр

Для наночастинки об'ємом `V` з ефективною анізотропією `K_eff` енергетичний бар'єр між двома протилежними напрямками намагніченості дорівнює:

```
ΔE = K_eff · V
```

За наявності теплових флуктуацій при температурі `T` ймовірність спонтанного подолання цього бар'єра описується законом Нееля — Арреніуса для часу релаксації `τ`:

```
τ = τ_0 · exp( (K_eff · V) / (k_B · T) )
```

де `τ_0 ≈ 10⁻⁹ ... 10⁻¹¹ с` — час спроби спінової прецесії, `k_B` — константа Больцмана.

#### Критичний критерій теплової стабільності (Критерій 10 років)

Для збереження даних у магнітній пам'яті (HDD або STT-MRAM) протягом 10 років (`τ ≈ 3 · 10⁸ с`) вимагається:

```
ln(τ / τ_0) = ln(3 · 10⁸ / 10⁻⁹) ≈ 40
```

Звідси випливає фундаментальний **критерій теплової стабільності**:

```
Δ = (K_eff · V) / (k_B · T) ≥ 40 ... 60
```

Якщо розмір частинки `V` зменшується настільки, що `Δ < 25`, час релаксації `τ` падає до часток секунди. Частинка спонтанно хаотично змінює напрямок намагніченості під дією теплового руху, втрачаючи феромагнітний гістерезис. Цей стан називається **суперпарамагнетизмом**, а відповідний граничний діаметр частинки `D_sp` визначає суперпарамагнітний ліміт щільності запису:

```
D_sp = [ (6 / π) · (25 · k_B · T / K_eff) ]^(1/3)
```

Застосування матеріалів з високою константою `K_eff` (наприклад, FePt або SmCo зі значеннями `K_eff ≈ 5 · 10⁶ Дж/м³`) дозволяє зменшити граничний діаметр `D_sp` до 3–5 нм, забезпечуючи колосальну щільність збереження інформації.

### 9. Магнітопружна енергія та магнітострикція

При пружній деформації кристала з тензором напружень `σ_ij` міжатомні відстані змінюються, що модулює спін-орбітальну взаємодію та створює додаткову **магнітопружну анізотропію**.

Для ізотропного за магнітострикційними властивостями матеріалу густина магнітопружної енергії `E_me` описується феноменологічним співвідношенням:

```
E_me = - (3/2) · λ_s · σ · cos²(θ)
```

де `λ_s` — насичена константа магнітострикції (безрозмірна величина деформації `ΔL / L`), `σ` — одноосне механічне напруження (в `Па`), `θ` — кут між вектором намагніченості та віссю натягу/стиску.

Розглянемо два випадки (ефект Вілларі):
- **Позитивна магнітострикція (`λ_s > 0`, наприклад залізо):** Механічний розтяг (`σ > 0`) створює легку вісь намагнічування уздовж напрямку прикладеного напруження. Механічний стиск (`σ < 0`), навпаки, розвертає спіни перпендикулярно до осі стиску.
- **Негативна магнітострикція (`λ_s < 0`, наприклад нікель):** Механічний розтяг формує легку площину, перпендикулярну напрямку розтягу, а механічний стиск створює легку вісь уздовж вектора напруження.

Ефективне магнітопружне поле `H_me`:

```
H_me = (3 · λ_s · σ) / (μ_0 · M_s)
```

Це рівняння дозволяє керувати магнітними станами у мультифероїках та гнучких спінтронічних пристроях шляхом прикладання зовнішніх механічних напруг. Пружні деформації дозволяють динамічно змінювати легкі осі без використання зовнішніх магнітних полів.
