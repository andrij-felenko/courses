# 🧮 Виведення високочастотної провідності, плазмової частоти та ефекту Голла в моделі Друде

Математичний апарат моделі Друде спирається на класичне диференціальне рівняння руху електрона у зовнішніх електричному `E` та магнітному `B` полях із додатковим феноменологічним членом дисипації (згасання), який описує розсіювання на іонах ґратки з часом релаксації `τ`.

Загальне векторне рівняння руху для середнього імпульсу електрона `p(t) = m · v(t)` має вигляд:

```
dp/dt = -e · (E + v × B) - p / τ
```

де перший член праворуч — сила Лоренца, що прискорює частинку, а другий член `-p / τ` — усереднена сила гальмування за рахунок зіткнень, яка прагне повернути систему до стану спокою при вимкненні полів.

---

### 1. Стаціонарний режим на постійному струмі (DC-провідність)

Розглянемо найпростіший випадок: постійне однорідне електричне поле `E = (E_x, 0, 0)` за відсутності магнітного поля (`B = 0`). У стаціонарному стані середня швидкість зміни імпульсу дорівнює нулю (`dp/dt = 0`), тому рівняння руху набуває вигляду:

```
0 = -e · E - m · v_d / τ
```

Звідси негайно виражаємо стаціонарну дрейфову швидкість електрона `v_d`:

```
v_d = - (e · τ / m) · E
```

Враховуючи, що густина електричного струму визначається добутком концентрації електронів `n`, їхнього заряду `-e` та дрейфової швидкості `v_d`, отримуємо макроскопічний диференціальний закон Ома:

```
J = -n · e · v_d = (n · e² · τ / m) · E = σ_0 · E
```

де `σ_0 = n·e²·τ / m` — питома електропровідність на постійному струмі.

---

### 2. Високочастотна провідність на змінному струмі (AC-дисперсія)

Розглянемо гармонічне електричне поле з коловою частотою `ω`, яке поширюється вздовж провідника:

```
E(t) = E_0 · exp(-i·ω·t)
```

Шукаємо стаціонарний розв'язок для швидкості електрона у такій самій комплексній формі: `v(t) = v_0 · exp(-i·ω·t)`.

Підставляємо `v(t)` та `E(t)` у рівняння руху за відсутності магнітного поля (`B = 0`):

```
m · d(v_0 · exp(-i·ω·t)) / dt + (m · v_0 · exp(-i·ω·t)) / τ = -e · E_0 · exp(-i·ω·t)

-i·ω·m · v_0 + (m / τ) · v_0 = -e · E_0            [скоротили exp(-i·ω·t)]

m · v_0 · (1/τ - i·ω) = -e · E_0

v_0 = (-e · τ / m) · E_0 / (1 - i·ω·τ)             [помножили чисельник і знаменник на τ]
```

Густина електричного струму визначається виразом `J(t) = -n · e · v(t) = σ(ω) · E(t)`. Звідси отримуємо комплексну провідність Друде `σ(ω)`:

```
σ(ω) = σ_0 / (1 - i · ω · τ)
```

Виділивши дійсну `σ₁` та уявну `σ₂` частини `σ(ω) = σ₁ + i·σ₂`, маємо:

```
σ₁(ω) = σ_0 / (1 + ω²·τ²)             [активна провідність, дисипація енергії]
σ₂(ω) = σ_0 · ω·τ / (1 + ω²·τ²)       [реактивна провідність, інерційність електронів]
```

Дійсна частина `σ₁(ω)` відповідає за поглинання енергії електромагнітного поля (Джоулеве нагрівання провідника), тоді як уявна частина `σ₂(ω)` описує фазовий зсув струму відносно поля через кінетичну інерцію електронів. У низькочастотному граничному випадку (`ω·τ << 1`) активна провідність наближається до статичного значення `σ₁(ω) ≈ σ_0`, а реактивна частина прямує до нуля. У високочастотному граничному випадку (`ω·τ >> 1`) активна провідність спадає як `1 / ω²`, а реактивна частина переважає та згасає як `1 / ω`.

### 3. Комплексна діелектрична проникність та плазмова частота

Зв'язок між густиною струму провідності `J` та зміщенням електромагнітного поля у рівняннях Максвелла дозволяє записати комплексну діелектричну проникність середовища `ε(ω)`:

```
rot H = J + ε_0 · dE/dt = σ(ω) · E - i · ω · ε_0 · E = -i · ω · ε_0 · ε(ω) · E
```

Звідси виражаємо комплексну діелектричну проникність `ε(ω)`:

```
ε(ω) = 1 + i · σ(ω) / (ε_0 · ω)
```

Підставляємо значення `σ(ω)` у діелектричну функцію:

```
ε(ω) = 1 + i · [σ_0 / (ε_0 · ω · (1 - i·ω·τ))]

ε(ω) = 1 - (n · e² / (ε_0 · m)) / (ω² + i · ω / τ)
```

Означимо величину **плазмової частоти** `ω_p`:

```
ω_p = √(n · e² / (ε_0 · m))
```

Тоді комплексна діелектрична проникність набуває компактного вигляду:

```
ε(ω) = 1 - ω_p² / (ω² + i · ω / τ)
```

Розділивши діелектричну проникність на дійсну `ε₁` та уявну `ε₂` частини (`ε(ω) = ε₁ + i·ε₂`), отримуємо класичні формули дисперсії Друде:

```
ε₁(ω) = 1 - (ω_p² · τ²) / (1 + ω²·τ²)
ε₂(ω) = (ω_p² · τ) / (ω · (1 + ω²·τ²))
```

У високочастотній області (`ω·τ >> 1`), коли зіткненнями за період коливань можна знехтувати (`τ → ∞`), згасання відсутнє (`ε₂ → 0`) і діелектрична функція стає суто дійсною:

```
ε(ω) ≈ 1 - ω_p² / ω²
```

Аналіз цього виразу пояснює оптичні властивості металів:
- При `ω < ω_p`: `ε(ω) < 0`. Показник заломлення `n = √ε` є суто уявним, електромагнітна хвиля експоненціально загасає у глибині металу на скін-шарі. Коефіцієнт відбивання від поверхні дорівнює `R = 100%` (металеве дзеркало).
- При `ω = ω_p`: `ε(ω) = 0`. У системі виникають поздовжні колективні коливання електронного газу — плазмони.
- При `ω > ω_p`: `ε(ω) > 0`. Метал стає прозорим для електромагнітного випромінювання (наприклад, лужні метали стають прозорими в ультрафіолетовому діапазоні).

---

### 4. Глибина скін-шару та поглинання низькочастотних хвиль

У низькочастотній області (`ω·τ << 1`) активна провідність `σ₁ ≈ σ_0` значно перевищує струм зміщення. Хвильове рівняння для електричного поля всередині провідника має вигляд:

```
d²E / dz² = -i · ω · μ_0 · σ_0 · E = k² · E
```

де хвильове число `k` є комплексним:

```
k = (1 + i) / δ  ⟹  δ = √(2 / (μ_0 · σ_0 · ω))
```

Величина `δ` називається **глибиною скін-шару** (*skin depth*).Вона визначає відстань від поверхні провідника, на якій амплітуда електромагнітної хвилі зменшується в `e ≈ 2.718` разів. На низьких частотах струм тече по всьому перерізу провідника, але зі зростанням частоти `ω` глибина `δ` зменшується, витісняючи струм до тонкої поверхневої плівки, що суттєво збільшує ефективний високоефективний опір деталей.

### 5. Ефект Голла та тензор провідності у магнітному полі

Розглянемо стаціонарний рух електронів (`dv/dt = 0`) у постійному електричному полі `E = (E_x, E_y, 0)` та магнітному полі, напрямленому уздовж осі Z: `B = (0, 0, B_z)`.

Векторний добуток `v × B` має компоненти: `(v_y·B_z, -v_x·B_z, 0)`. Рівняння руху Друде у проекціях на осі X та Y набувають вигляду:

```
m · v_x / τ = -e · E_x - e · v_y · B_z
m · v_y / τ = -e · E_y + e · v_x · B_z
```

Ввівши **циклотронну частоту** `ω_c = e · B_z / m`, перепишемо систему для компонент швидкостей:

```
v_x + ω_c · τ · v_y = -e · τ / m · E_x
v_y - ω_c · τ · v_x = -e · τ / m · E_y
```

У типовому вимірювальному експерименті Голла зразок витягнутий уздовж осі X, струм тече у поздовжньому напрямку (`J_x ≠ 0`), а в поперечному напрямку Y коло розімкнене, тому поперечна густина струму відсутня: `J_y = -n·e·v_y = 0 ⟹ v_y = 0`.

Підставляючи `v_y = 0` у друге рівняння системи, знаходимо поперечне електричне поле Голла `E_y`:

```
0 - ω_c · τ · v_x = -e · τ / m · E_y

E_y = (m / e) · ω_c · v_x = (m / e) · (e · B_z / m) · v_x = v_x · B_z
```

Оскільки `J_x = -n · e · v_x ⟹ v_x = -J_x / (n · e)`, отримуємо:

```
E_y = -J_x · B_z / (n · e)
```

За визначенням **коефіцієнт Голла** `R_H` дорівнює:

```
R_H = E_y / (J_x · B_z) = -1 / (n · e)
```

Матричний зв'язок між вектором поля `E` та вектором струму `J` у магнітному полі описується тензором питомого опору `E_i = ρ_ij · J_j`:

```
[ E_x ]   [  ρ_xx   ρ_xy  ]   [ J_x ]
[ E_y ] = [ -ρ_xy   ρ_yy  ] · [ J_y ]
```

компоненти якого у моделі Друде дорівнюють:

```
ρ_xx = ρ_yy = m / (n · e² · τ) = ρ_0        [поздовжній опір не залежить від B]
ρ_xy = -ρ_yx = -B_z / (n · e) = R_H · B_z   [поперечний опір Голла]
```

Обертаючи тензор питомого опору `ρ`, знаходимо компоненти **тензора питомої провідності** `σ = ρ⁻¹`:

```
σ_xx = σ_yy = σ_0 / (1 + ω_c²·τ²)
σ_xy = -σ_yx = -σ_0 · (ω_c·τ) / (1 + ω_c²·τ²)
```

Ці формули показують, що в міру зростання магнітного поля (`ω_c·τ >> 1`) діагональна провідність `σ_xx` падає як `1 / B²`, що описує закручування електронів по циклотронних орбітах між розсіюваннями.

### 6. Магнітооптичний ефект та циклотронний резонанс

Якщо на електронний газ у постійному магнітному полі `B_z` падає колово-поляризована електромагнітна хвиля `E_±(t) = E_0 · (x̂ ± i·ŷ) · exp(-i·ω·t)`, то рівняння руху Друде для двох право- та лівополяризованих компонент розщеплюються:

```
σ_±(ω) = σ_0 / (1 - i · (ω ∓ ω_c) · τ)
```

Звідси випливає існування явища **циклотронного резонансу**: коли частота падаючого випромінювання збігається з циклотронною частотою електронів (`ω = ω_c`), поглинання енергії для правополяризованої хвилі різко зростає. 

Вимірювання частоти циклотронного резонансу `ω_c = e·B / m*` дає експериментаторам прямий метод визначення ефективної маси носіїв `m*` у напівпровідниках та металах.
