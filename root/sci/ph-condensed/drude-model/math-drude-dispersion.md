# 🧮 Виведення високочастотної провідності, плазмової частоти та ефекту Голла в моделі Друде

Математичний апарат моделі Друде спирається на класичне диференціальне рівняння руху електрона у зовнішніх електричному `E` та магнітному `B` полях із додатковим феноменологічним членом дисипації (згасання), який описує розсіювання на іонах ґратки з характеристичним часом релаксації `τ`.

Загальне векторне рівняння руху для середнього імпульсу електрона `p(t) = m · v(t)` має вигляд:

```
dp/dt = -e · (E + v × B) - p / τ
```

де перший член праворуч — сила Лоренца, що прискорює частинку під дією зовнішніх полів, а другий член `-p / τ` — усереднена сила стохастичного гальмування за рахунок зіткнень із тепловими коливаннями та дефектами ґратки, яка повертає ансамбль електронів до рівноважного стану спокою за відсутності збурення.

---

### 1. Стаціонарний режим на постійному струмі (DC-провідність)

Розглянемо базовий випадок: постійне однорідне електричне поле `E = (E_x, 0, 0)` за відсутності магнітного поля (`B = 0`). 

У стаціонарному режимі під дією постійної зовнішньої сили швидкість напрямленого дрейфу стабілізується, і середня похідна імпульсу за часом обнуляється (`dp/dt = 0`). Рівняння балансу сил набуває вигляду:

```
0 = -e · E - m · v_d / τ
```

Звідси однозначно визначаємо стаціонарну дрейфову швидкість електрона `v_d`:

```
v_d = - (e · τ / m) · E
```

Враховуючи, що густина електричного струму `J` визначається добутком об'ємної концентрації електронів `n`, елементарного заряду `-e` та середньої дрейфової швидкості `v_d`, отримуємо макроскопічний диференціальний закон Ома:

```
J = -n · e · v_d
  = -n · e · [ - (e · τ / m) · E ]      [підставили стаціонарну швидкість v_d]
  = (n · e² · τ / m) · E                [перемножили заряди й винесли скаляр]
  = σ_0 · E                             [ввели статичну питому провідність σ_0]
```

де `σ_0` — статична питома електропровідність металу на постійному струмі (DC-провідність):

```
σ_0 = (n · e² · τ) / m
```

Коефіцієнт пропорційності між дрейфовою швидкістю та електричним полем називають **рухливістю носіїв заряду** `μ`:

```
v_d = - μ · E  ⟹  μ = (e · τ) / m
```

Через рухливість питома провідність записується у канонічній формі `σ_0 = n · e · μ`. Питомий електричний опір `ρ_0 = 1 / σ_0 = m / (n · e² · τ)` прямо пропорційний масі електрона та частоті розсіювань `1 / τ`.

#### Кінетичне виведення провідності з рівняння Больцмана
Для строгішого статистичного опису ансамблю частинок розглянемо кінетичне рівняння Больцмана для функції розподілу електронів `f(k, r, t)` у наближенні часу релаксації (RTA — *Relaxation Time Approximation*):

```
∂f/∂t + v(k) · ∇_r f - (e / ħ) · E · ∇_k f = - (f - f_0) / τ
```

де `f_0(E)` — рівноважна функція розподілу (у класичному випадку Максвелла — Больцмана або квантовому Фермі — Дірака), а `v(k) = (1/ħ) · ∇_k E(k)` — групова швидкість блохівського електрона з хвильовим вектором `k`.

У просторово однорідному провіднику (`∇_r f = 0`) у стаціонарному стані (`∂f/∂t = 0`) під дією слабкого електричного поля функція розподілу відхиляється від рівноважної на малу поправку: `f(k) = f_0(k) + f_1(k)`, де `|f_1| << f_0`. Лінеаризуючи рівняння, отримуємо:

```
- (e / ħ) · E · ∇_k f_0 = - f_1(k) / τ

f_1(k) = (e · τ / ħ) · (E · ∇_k f_0)                    [знайшли нерівноважну поправку]
```

Оскільки градієнт енергії у квазіімпульсному просторі пов'язаний зі швидкістю `∇_k E = ħ · v(k)`, за правилом диференціювання складної функції маємо `∇_k f_0 = (∂f_0 / ∂E) · ∇_k E = ħ · v(k) · (∂f_0 / ∂E)`. Тоді поправка набуває вигляду:

```
f_1(k) = e · τ · (∂f_0 / ∂E) · (v(k) · E)
```

Густина електричного струму визначається інтегруванням за всіма станами зони Бріллюена з урахуванням спінового виродження:

```
J = - (2 · e / (2π)³) · ∫ v(k) · f(k) d³k
  = - (2 · e / (2π)³) · ∫ v(k) · [ f_0(k) + f_1(k) ] d³k
```

Оскільки рівноважна функція `f_0(k)` парна за швидкістю `v(-k) = -v(k)`, інтеграл від `f_0` тотожно дорівнює нулю (за відсутності поля струм відсутній). Підставляємо нерівноважну частину `f_1(k)`:

```
J = - (2 · e² · τ / (2π)³) · ∫ v(k) · (v(k) · E) · (∂f_0 / ∂E) d³k
```

Для сферично симетричного параболічного закону дисперсії `E(k) = ħ² · k² / (2m)` тензорний добуток швидкостей усреднюється по кутах: `∫ v_i · v_j · dΩ = (1/3) · v² · δ_ij · ∫ dΩ`. За низьких температур похідна ферміївського розподілу поводиться як дельта-функція на поверхні Фермі: `∂f_0 / ∂E ≈ - δ(E - E_F)`. Інтегруючи за енергією та кутами, приходимо до виразу:

```
J = [ (n · e² · τ) / m ] · E = σ_0 · E
```

що строго доводить: виведена Друде формульна залежність `σ_0 = n·e²·τ / m` залишається справедливою і в точній квантовій кінетичній теорії виродженого фермі-газу за умови, що маса `m` інтерпретується як зонна ефективна маса `m*` на рівні Фермі, а `τ` — як час релаксації квазічастинок біля сфери Фермі.

### 2. Динамічна AC-провідність та фазовий зсув у змінному полі

Нехай на провідник діє гармонічне монохроматичне електричне поле з коловою частотою `ω`:

```
E(t) = E_0 · exp(-i · ω · t)
```

де `E_0` — комплексна амплітуда поля, а часова залежність обрана у стандартній фізичній формі `exp(-i · ω · t)`.

Шукаємо вимушений стаціонарний розв'язок для швидкості електрона з тією самою часовою частотою: `v(t) = v_0 · exp(-i · ω · t)`. Підставляємо цей анзац у диференціальне рівняння руху за відсутності магнітного поля:

```
m · (dv/dt + v/τ) = -e · E(t)
```

Диференціюємо швидкість за часом `dv/dt = -i · ω · v_0 · exp(-i · ω · t)` і підставляємо у вихідне рівняння:

```
m · [ -i · ω · v_0 · exp(-i·ω·t) + (1/τ) · v_0 · exp(-i·ω·t) ] = -e · E_0 · exp(-i·ω·t)

m · v_0 · (1/τ - i · ω) = -e · E_0                     [скоротили спільний множник exp(-i·ω·t)]

v_0 = - (e / m) · E_0 / (1/τ - i · ω)                  [виразили комплексну амплітуду швидкості]

v_0 = - (e · τ / m) · E_0 / (1 - i · ω · τ)            [домножили чисельник і знаменник на τ]
```

Густина струму на змінному полі дорівнює `J(t) = -n · e · v(t) = σ(ω) · E(t)`. Звідси знаходимо **комплексну динамічну провідність Друде** `σ(ω)`:

```
σ(ω) = (-n · e) · [ - (e · τ / m) / (1 - i · ω · τ) ]
     = (n · e² · τ / m) / (1 - i · ω · τ)              [звели мінуси й виділили σ_0]
     = σ_0 / (1 - i · ω · τ)                           [канонічний вираз провідності Друде]
```

Для аналізу фізичних наслідків домножимо чисельник і знаменник на комплексно-спряжену величину `(1 + i · ω · τ)` та виділимо дійсну `σ₁` та уявну `σ₂` частини: `σ(ω) = σ₁(ω) + i · σ₂(ω)`.

```
σ(ω) = σ_0 · (1 + i · ω · τ) / [ (1 - i · ω · τ) · (1 + i · ω · τ) ]
     = σ_0 · (1 + i · ω · τ) / (1 + ω² · τ²)           [розкрили різницю квадратів у знаменнику]
     = [ σ_0 / (1 + ω² · τ²) ] + i · [ σ_0 · ω · τ / (1 + ω² · τ²) ]
```

Отримуємо дві базові компоненти динамічного відгуку:

```
σ₁(ω) = σ_0 / (1 + ω² · τ²)                            [дійсна частина: активна провідність]
σ₂(ω) = (σ_0 · ω · τ) / (1 + ω² · τ²)                  [уявна частина: реактивна провідність]
```

#### Фізичний зміст активної та реактивної складових
1. **Активна провідність `σ₁(ω)` (дисипативна складова)**: Описує струм, що коливається синфазно з електричним полем. Вона відповідає за незворотне перетворення енергії електромагнітного поля у тепло (Джоулеві втрати). Усереднена за періодом коливань питома потужність дисипації тепла дорівнює:
   ```
   ⟨P⟩ = (1/2) · Re(J · E*)
       = (1/2) · Re(σ(ω) · |E_0|²)                     [підставили закон Ома J = σ·E]
       = (1/2) · σ₁(ω) · |E_0|²
       = (1/2) · [ σ_0 / (1 + ω² · τ²) ] · |E_0|²      [явний вираз через частоту поля]
   ```
   На низьких частотах (`ω · τ << 1`) активна провідність практично збігається зі статичною `σ₁(ω) ≈ σ_0`. На високих частотах (`ω · τ >> 1`) електрони не встигають розігнатися за півперіод зміни напрямку поля, тому дисипація стрімко спадає як `1 / ω²`.

2. **Реактивна провідність `σ₂(ω)` (індуктивна складова)**: Описує струм, зсунутий за фазою на `π/2` відносно прикладеного поля. Цей зсув зумовлений власною механічною інертністю електронів: масивна частинка через наявність інертної маси `m` реагує на прикладену силу з запізненням. Тангенс кута фазового зсуву `φ` між вектором струму та вектором поля дорівнює:
   ```
   tan(φ) = σ₂(ω) / σ₁(ω) = [ (σ_0 · ω · τ) / (1 + ω² · τ²) ] / [ σ_0 / (1 + ω² · τ²) ] = ω · τ
   ```
   При `ω · τ << 1` зсув фаз мізерний (`φ ≈ 0`), оскільки зіткнення миттєво гасять накопичений імпульс. При `ω · τ >> 1` зсув наближається до чистого індуктивного значення `φ → π/2`, і струм відстає від поля на чверть періоду.

### 3. Комплексна діелектрична проникність та плазмова частота

У макроскопічній електродинаміці поведінка середовища визначається системою рівнянь Максвелла. Розглянемо рівняння для ротора магнітного поля у середовищі з провідністю `σ(ω)` та фоновою діелектричною проникністю вакууму `ε_0`:

```
rot H = J + ∂D/∂t
```

Для гармонічного поля з часовою залежністю `exp(-i · ω · t)` оператор диференціювання за часом еквівалентний множенню на `-i · ω`. Враховуючи зв'язок `D = ε_0 · E` та `J = σ(ω) · E`, перепишемо рівняння:

```
rot H = σ(ω) · E - i · ω · ε_0 · E
      = -i · ω · ε_0 · [ 1 + i · σ(ω) / (ε_0 · ω) ] · E     [винесли спільний множник -i·ω·ε_0]
      = -i · ω · ε_0 · ε(ω) · E                             [ввели узагальнену діелектричну проникність]
```

Звідси випливає фундаментальний зв'язок між комплексною провідністю `σ(ω)` та узагальненою **комплексною діелектричною проникністю** `ε(ω)`:

```
ε(ω) = 1 + i · σ(ω) / (ε_0 · ω)
```

Підставимо у цей вираз формулу динамічної провідності Друде `σ(ω) = σ_0 / (1 - i · ω · τ)`:

```
ε(ω) = 1 + i · [ σ_0 / (ε_0 · ω · (1 - i · ω · τ)) ]
     = 1 + [ i · σ_0 / (ε_0 · ω) ] / (1 - i · ω · τ)
     = 1 - [ σ_0 / (ε_0 · τ) ] / [ ω · (ω + i / τ) ]       [винесли множник -i з чисельника і знаменника]
```

Звернемо увагу на комбінацію фундаментальних параметрів у чисельнику:

```
σ_0 / (ε_0 · τ) = [ (n · e² · τ) / m ] / (ε_0 · τ) = (n · e²) / (ε_0 · m)
```

Ця величина має розмірність квадрата колової частоти і визначає власну резонансну частоту колективних коливань електронного газу — **плазмову частоту** `ω_p`:

```
ω_p = √( (n · e²) / (ε_0 · m) )
```

Виразивши чисельник через плазмову частоту `ω_p² = σ_0 / (ε_0 · τ)`, отримуємо класичну формулу комплексної діелектричної проникності Друде:

```
ε(ω) = 1 - ω_p² / [ ω · (ω + i / τ) ] = 1 - ω_p² / (ω² + i · ω / τ)
```

#### Розділення діелектричної функції на дійсну та уявну частини
Представимо діелектричну проникність у вигляді `ε(ω) = ε₁(ω) + i · ε₂(ω)`. Домножимо дріб на комплексно-спряжений знаменник `(ω² - i · ω / τ)`:

```
ε(ω) = 1 - [ ω_p² · (ω² - i · ω / τ) ] / [ (ω² + i · ω / τ) · (ω² - i · ω / τ) ]
     = 1 - [ ω_p² · (ω² - i · ω / τ) ] / [ ω⁴ + ω² / τ² ]
     = 1 - [ ω_p² · (1 - i / (ω · τ)) ] / [ ω² + 1 / τ² ]   [скоротили ω у чисельнику та знаменнику]
     = 1 - [ (ω_p² · τ²) / (1 + ω² · τ²) ] + i · [ (ω_p² · τ) / (ω · (1 + ω² · τ²)) ]
```

Отримуємо аналітичні вирази для дійсної та уявної частин:

```
ε₁(ω) = 1 - (ω_p² · τ²) / (1 + ω² · τ²)                [дійсна діелектрична проникність]
ε₂(ω) = (ω_p² · τ) / [ ω · (1 + ω² · τ²) ]             [уявна частина: діелектричні втрати]
```

Порівнюючи вираз для `ε₂(ω)` з активною провідністю `σ₁(ω)`, легко переконатися у тотожності:

```
ε₂(ω) = σ₁(ω) / (ε_0 · ω)
```

що підтверджує прямий зв'язок між уявною частиною діелектричної проникності та дисипацією електромагнітної енергії в речовині.

#### Вплив зв'язаних електронів: узагальнена модель Друде — Лоренца
У реальних благородних та перехідних металах (золото, срібло, мідь) поряд із газом вільних електронів значний поляризаційний внесок у діелектричну проникність роблять зв'язані d-електрони заповнених іонних остовів та міжзонні квантові оптичні переходи. 

У високочастотній області поляризація іонного остову описується залишковою фоновою діелектричною проникністю `ε_∞ > 1` (для золота `ε_∞ ≈ 9–10`, для срібла `ε_∞ ≈ 4–5`, для міді `ε_∞ ≈ 7–8`). Повна діелектрична функція узагальненої моделі Друде — Лоренца записується у вигляді:

```
ε(ω) = ε_∞ - ω_p² / [ ω · (ω + i / τ) ] + ∑_j [ f_j · ω_pj² / (ω_0j² - ω² - i · ω · γ_j) ]
```

де другий член описує внесок вільних друде-носіїв, а третій доданок — суму лоренцівських осциляторів міжзонного поглинання з резонансними частотами `ω_0j`, силами осциляторів `f_j` та ширинами `γ_j`.

Знехтувавши згасанням (`τ → ∞`) в області нижче міжзонних резонансів, умова обнулення діелектричної проникності `ε(ω) = 0` набуває вигляду:

```
ε_∞ - ω_p² / ω² = 0  ⟹  ω = ω_p / √ε_∞
```

Величина **`ω'_p = ω_p / √ε_∞`** називається **екранованою (зсунутою) плазмовою частотою**. Поляризація внутрішніх електронних оболонок істотно знижує поріг плазмового відбиття з вакуумного ультрафіолету в оптичний діапазон, що безпосередньо зумовлює характерний жовтий колір золота та червонуватий відтінок міді (через початок міжзонного поглинання d-зон у синій частині спектра).

### 4. Оптичні константи: показник заломлення та коефіцієнт екстинкції

Поширення плоских електромагнітних хвиль у провідному середовищі підпорядковується хвильовому рівнянню Гельмгольца:

```
∇²E - (ε(ω) / c²) · ∂²E/∂t² = 0
```

де `c = 1 / √(ε_0 · μ_0)` — швидкість світла у вакуумі. Шукаємо розв'язок у вигляді плоскої хвилі `E(z, t) = E_0 · exp(i · (k · z - ω · t))`. Підстановка дає дисперсійне рівняння:

```
k² = (ω² / c²) · ε(ω)  ⟹  k = (ω / c) · √ε(ω)
```

Введемо **комплексний показник заломлення** `ñ(ω) = n(ω) + i · κ(ω)` як корінь із комплексної діелектричної проникності:

```
ñ(ω) = √ε(ω) = n(ω) + i · κ(ω)
```

де `n(ω)` — дійсний коефіцієнт заломлення (визначає фазову швидкість хвилі `v_ph = c / n`), а `κ(ω)` — коефіцієнт екстинкції (безрозмірний показник поглинання та просторового згасання хвилі).

Піднесемо обидві частини рівності до квадрата:

```
ñ² = (n + i · κ)² = (n² - κ²) + i · (2 · n · κ)
```

Прирівнюючи дійсну та уявну частини до `ε(ω) = ε₁ + i · ε₂`, маємо систему зв'язаних рівнянь:

```
n² - κ² = ε₁(ω)
2 · n · κ = ε₂(ω)
```

Виразимо `κ = ε₂ / (2 · n)` з другого рівняння і підставимо у перше:

```
n² - ε₂² / (4 · n²) = ε₁

4 · (n²)² - 4 · ε₁ · (n²) - ε₂² = 0                   [звели до квадратного рівняння відносно n²]
```

Знаходимо дискримінант квадратного рівняння `D = 16 · ε₁² + 16 · ε₂² = 16 · (ε₁² + ε₂²)`. Оскільки фізичний показник заломлення є строго дійсною додатною величиною (`n² > 0`), обираємо додатний корінь:

```
n² = [ 4 · ε₁ + 4 · √(ε₁² + ε₂²) ] / 8
   = [ √(ε₁² + ε₂²) + ε₁ ] / 2                        [знайшли точний вираз для квадрата n]
```

Значення `κ²` отримуємо з різниці `κ² = n² - ε₁`:

```
κ² = [ √(ε₁² + ε₂²) + ε₁ ] / 2 - ε₁
   = [ √(ε₁² + ε₂²) - ε₁ ] / 2                        [знайшли точний вираз для квадрата κ]
```

Добуваючи квадратний корінь, маємо строгі аналітичні формули для оптичних констант Друде:

```
n(ω) = √[ (√(ε₁²(ω) + ε₂²(ω)) + ε₁(ω)) / 2 ]
κ(ω) = √[ (√(ε₁²(ω) + ε₂²(ω)) - ε₁(ω)) / 2 ]
```

### 5. Відбивання світла: формули Френеля та граничні частотні режими

Розглянемо падіння електромагнітної хвилі з вакууму на плоску поверхню напівнескінченного металу під нормальним кутом (`θ = 0`). 

Згідно з граничними умовами електродинаміки для тангенціальних компонент полів `E` та `H`, амплітудний коефіцієнт відбиття Френеля дорівнює `r = (1 - ñ) / (1 + ñ)`. Енергетичний **коефіцієнт відбиття за інтенсивністю** `R(ω) = |r|²` визначається модулем комплексної амплітуди:

```
R(ω) = | (1 - ñ) / (1 + ñ) |²
     = | (1 - n - i·κ) / (1 + n + i·κ) |²
     = [ (n - 1)² + κ² ] / [ (n + 1)² + κ² ]           [підставили ñ = n + i·κ і взяли квадрат модуля]
```

Розглянемо три фундаментальні частотні діапазони, які повністю описують оптичний спектр металу.

```
Частотні інтервали моделі Друде:
0 -------------- 1/τ ---------------------- ω_p -----------------> ω
  Хагенса —           Проміжний режим:          Ультрафіолетова
  Рубенса:           ε₁ < 0, дзеркало          прозорість:
  R ≈ 1 - √(8ε₀ω/σ₀) R ≈ 100%                   ε₁ > 0, хвиля проходить
```

---

#### 5.1. Низькочастотна область Хагенса — Рубенса (`ω · τ << 1`)
У квазістатичному діапазоні (радіохвилі, мікрохвилі та далекий інфрачервоний спектр) частота поля набагато менша за частоту релаксації носіїв `1 / τ ~ 10¹⁴` рад/с.

Розкладаємо діелектричні функції при `ω · τ << 1`:

```
ε₁(ω) ≈ 1 - ω_p² · τ² = 1 - σ_0 · τ / ε_0              [константа порядку -10² ... -10⁴]
ε₂(ω) ≈ (ω_p² · τ) / ω = σ_0 / (ε_0 · ω)               [домінує, оскільки прямує до нескінченності при ω → 0]
```

Оскільки `ε₂(ω) >> |ε₁(ω)|`, величина під коренем спрощується: `√(ε₁² + ε₂²) ≈ ε₂(ω)`. Підставляємо це наближення у формули для оптичних констант:

```
n(ω) ≈ √[ ε₂(ω) / 2 ] = √( σ_0 / (2 · ε_0 · ω) )
κ(ω) ≈ √[ ε₂(ω) / 2 ] = √( σ_0 / (2 · ε_0 · ω) )
```

У цій області `n(ω) ≈ κ(ω) >> 1`. Підставимо ці значення у формулу відбиття Френеля:

```
R(ω) = [ (n - 1)² + n² ] / [ (n + 1)² + n² ]          [врахували κ ≈ n]
     = [ 2·n² - 2·n + 1 ] / [ 2·n² + 2·n + 1 ]
     = [ 1 - 1/n + 1/(2·n²) ] / [ 1 + 1/n + 1/(2·n²) ] [поділили чисельник і знаменник на 2·n²]
     ≈ (1 - 1/n) · (1 - 1/n)                           [розклали в ряд за малим параметром 1/n << 1]
     ≈ 1 - 2/n
```

Підставляючи значення `n(ω) = √(σ_0 / (2 · ε_0 · ω))`, отримуємо знамените **співвідношення Хагенса — Рубенса**:

```
R(ω) ≈ 1 - 2 · √( (2 · ε_0 · ω) / σ_0 ) = 1 - √( (8 · ε_0 · ω) / σ_0 )
```

Коефіцієнт поглинання `A(ω) = 1 - R(ω)` прямо пропорційний кореню з частоти `√ω` і обернено пропорційний кореню зі статичної провідності `√σ_0`. Ця формула чудово описує високе дзеркальне відбиття металів (понад 99%) в інфрачервоному діапазоні.

---

#### 5.2. Проміжний діапазон релаксації (`1/τ << ω < ω_p`)
У діапазоні від ближнього інфрачервоного до видимого світла частота поля перевищує частоту розсіювань (`ω · τ >> 1`), але залишається меншою за плазмову частоту `ω_p`.

У цьому режимі діелектричні функції набувають вигляду:

```
ε₁(ω) ≈ 1 - ω_p² / ω² < 0                              [строго від'ємна дійсне значення]
ε₂(ω) ≈ ω_p² / (ω³ · τ) << |ε₁(ω)|                     [мале згасання]
```

Оскільки `ε₂(ω) << |ε₁(ω)|`, маємо `√(ε₁² + ε₂²) ≈ |ε₁(ω)| = -ε₁(ω)`. Тоді оптичні константи дорівнюють:

```
n(ω) ≈ √[ (|ε₁| + ε₁) / 2 ] = 0                        [фазова швидкість прагне до нескінченності]
κ(ω) ≈ √[ (|ε₁| - ε₁) / 2 ] = √|ε₁| ≈ √( ω_p² / ω² - 1 ) ≈ ω_p / ω
```

Враховуючи малу поправку на скінченний час релаксації, `n(ω) ≈ ε₂ / (2 · κ) ≈ 1 / (2 · ω_p · τ) << 1`. Підставляючи ці значення у формулу відбиття:

```
R(ω) = [ (0 - 1)² + κ² ] / [ (0 + 1)² + κ² ] = (1 + κ²) / (1 + κ²) = 100%
```

Метал у цьому діапазоні поводиться як ідеальне дзеркало: електромагнітна хвиля не може поширюватися всередині середовища (`n ≈ 0`) і повністю відбивається від межі поділу, формуючи стоячу хвилю зовні.

---

#### 5.3. Високочастотна область прозорості (`ω > ω_p`)
Коли частота падаючого випромінювання перевищує плазмову частоту металу (типово в ультрафіолетовому діапазоні `ħ·ω_p ~ 3–15` еВ), електрони просто не встигають екранувати високочастотне електричне поле.

Діелектрична проникність стає додатною:

```
ε₁(ω) ≈ 1 - ω_p² / ω² > 0
ε₂(ω) ≈ 0
```

Оптичні константи переходять у режим прозорого діелектрика:

```
n(ω) ≈ √( 1 - ω_p² / ω² )
κ(ω) ≈ 0
```

Коефіцієнт екстинкції обнуляється, хвиля безперешкодно проникає в об'єм речовини без експоненціального згасання, і метал стає прозорим. Коефіцієнт відбиття падає до низьких діелектричних значень:

```
R(ω) = [ (n(ω) - 1)² ] / [ (n(ω) + 1)² ] < 10%
```

На точній граничній частоті `ω = ω_p` дісна діелектрична проникність обнуляється (`ε₁(ω_p) = 0`). За відсутності зовнішнього поля це відповідає умові існування власних незгасаючих поздовжніх коливань електронної густини — **об'ємних плазмонів**.

---

### 6. Глибина проникнення електромагнітного поля та скін-ефект

Розглянемо просторовий профіль електромагнітного поля всередині провідника при нормальному падінні вздовж осі `z`:

```
E(z, t) = E_0 · exp(i · (k · z - ω · t))
```

Оскільки хвильовий вектор є комплексним `k = (ω / c) · (n + i · κ) = k₁ + i · k₂`, запишемо поле у факторизованій формі:

```
E(z, t) = E_0 · exp(-k₂ · z) · exp(i · (k₁ · z - ω · t))
```

де дійсна частина хвильового числа визначає просторову просторову довжину хвилі `λ = 2π / k₁`, а уявна частина `k₂ = (ω / c) · κ` задає просторове згасання амплітуди.

**Глибиною скін-шару** `δ(ω)` (*skin depth*) називають відстань, на якій амплітуда поля зменшується в `e ≈ 2.718` разів:

```
δ(ω) = 1 / k₂ = c / (ω · κ(ω))
```

#### 1. Класичний скін-ефект на низьких частотах (`ω · τ << 1`)
Підставимо у вираз для `δ` низькочастотне значення коефіцієнта екстинкції `κ(ω) = √(σ_0 / (2 · ε_0 · ω))`:

```
δ(ω) = c / [ ω · √( σ_0 / (2 · ε_0 · ω) ) ]
     = (1 / √(ε_0 · μ_0)) · √( (2 · ε_0 · ω) / (σ_0 · ω²) )  [підставили c = 1/√(ε_0·μ_0)]
     = √( 2 / (μ_0 · σ_0 · ω) )                              [скоротили ε_0 та один степінь ω]
```

Отримуємо класичну інженерну формулу глибини скін-шару:

```
δ = √( 2 / (μ_0 · σ_0 · ω) )
```

На низьких частотах струм протікає по всьому перерізу масивного провідника. Зі зростанням частоти `ω` глибина проникнення зменшується обернено пропорційно `√ω`, витісняючи електричний струм у тонку приповерхневу плівку, що викликає стрімке зростання активного опору провідників на радіочастотах.

#### 2. Беззіткнювальна плазмова глибина екранування (`1/τ << ω < ω_p`)
У високочастотному дзеркальному режимі підставимо `κ(ω) ≈ ω_p / ω`:

```
δ_L = c / [ ω · (ω_p / ω) ] = c / ω_p
```

Величина `δ_L = c / ω_p` називається **лондонівською (плазмовою) глибиною проникнення**. Вона не залежить від частоти випромінювання та часу вільного пробігу `τ`, а визначається суто фундаментальною густиною електронів `n`:

```
δ_L = c / √( (n · e²) / (ε_0 · m) ) = √( m / (μ_0 · n · e²) )
```

Для типових металів з `n ~ 10²⁸` м⁻³ плазмова глибина проникнення становить лише `δ_L ~ 15–50` нм, що визначає мінімальну товщину металевого напилення, необхідну для формування оптичного дзеркала.

#### 3. Границі застосовності: аномальний скін-ефект Ройтера — Зондгеймера
Класична теорія Друде передбачає **локальний зв'язок** між полем і струмом `J(r) = σ · E(r)`. Це припущення справедливе лише доти, доки середня довжина вільного пробігу електрона `l = v_F · τ` набагато менша за глибину скін-шару `δ`:

```
l << δ
```

У надчистих металах за кріогенних температур (рідкий гелій) час релаксації зростає у тисячі разів, і довжина вільного пробігу сягає мікрометрів або навіть міліметрів (`l ~ 10–100` мкм), значно перевищуючи класичну глибину проникнення поля (`l >> δ`).

У цьому **режимі аномального скін-ефекту** електрон встигає багаторазово перетнути скін-шар без зіткнень, відчуваючи неоднорідне поле на своїй траєкторії. Локальний закон Ома втрачає силу, і струм у точці `r` визначається інтегралом Чемберса за всіма полями в околі радіуса `l`:

```
J(r) = ∫ K(r - r') · E(r') d³r'
```

Ефективну взаємодію з полем зберігають лише електрони, що рухаються майже паралельно до поверхні металу під малими кутами `θ ~ δ / l` (неефективні електрони, що летять углиб зразка, миттєво виходять із зони дії поля). Тоді ефективна концентрація взаємодіючих електронів зменшується як `n_eff ≈ n · (δ / l)`. Підставляючи `σ_eff = (n_eff · e² · τ) / m = σ_0 · (δ / l)` у вираз для глибини скін-шару `δ ~ √(2 / (μ_0 · σ_eff · ω))`:

```
δ³ ~ (2 · l) / (μ_0 · σ_0 · ω) = (2 · v_F · m) / (μ_0 · n · e² · ω)

δ_anom ∝ ( (m · v_F) / (μ_0 · n · e² · ω) )^(1/3) ∝ ω^(-1/3)
```

В аномальному режимі глибина проникнення та поверхневий опір спадають із частотою значно повільніше (`ω^(-1/3)` замість класичного `ω^(-1/2)`) і повністю перестають залежати від часу розсіювання `τ`, що використовується в радіофізиці для спектроскопічного вимірювання форми фермі-поверхні металів.

### 7. Дисперсійні співвідношення Крамерса — Кроніга та правила сум

Зв'язок між вектором електричного зміщення `D(t)` та напруженістю електричного поля `E(t)` у часовому просторі задається інтегралом згортки через функцію лінійного відгуку середовища `χ(t)`:

```
D(t) = ε_0 · E(t) + ε_0 · ∫₀^∞ χ(t') · E(t - t') dt'
```

Нижня межа інтегрування строго дорівнює нулю (`t' ≥ 0`), що є прямим математичним вираженням **принципу причинності**: відгук середовища в момент часу `t` може залежати лише від значень поля у минулі моменти часу `t - t' ≤ t`, і не може передбачати майбутнє поле.

Завдяки принципу причинності фур'є-образ відгуку — комплексна діелектрична проникність `ε(ω)` — є аналітичною функцією у верхній півплощині комплексної частоти `Im(ω) > 0`. Застосовуючи теорему Коші про інтегрування вздовж замкненого контуру, що охоплює дійсну вісь та замикається нескінченним півколом у верхній півплощині, отримуємо **дисперсійні інтеграли Крамерса — Кроніга**:

```
ε₁(ω) - 1 = (2 / π) · P.V. ∫₀^∞ [ s · ε₂(s) / (s² - ω²) ] ds
ε₂(ω)     = - (2 · ω / π) · P.V. ∫₀^∞ [ (ε₁(s) - 1) / (s² - ω²) ] ds
```

де символ `P.V.` (*Principal Value*) позначає інтеграл у сенсі головного значення за Коші. 

Ці співвідношення доводять, що дійсна `ε₁(ω)` (реактивна поляризація) та уявна `ε₂(ω)` (дисипативне поглинання) частини діелектричної проникності не є незалежними: повний спектр поглинання матеріалу на всіх частотах однозначно задає його спектр заломлення.

---

#### 7.1. Пряма перевірка моделі Друде через інтеграл Крамерса — Кроніга
Перевіримо виконання першого співвідношення Крамерса — Кроніга безпосередньо для діелектричної функції Друде. Підставимо вираз `ε₂(s) = (ω_p² · τ) / [ s · (1 + s² · τ²) ]` у правий інтеграл:

```
I(ω) = (2 / π) · P.V. ∫₀^∞ [ s / (s² - ω²) ] · [ (ω_p² · τ) / (s · (1 + s² · τ²)) ] ds
     = (2 · ω_p² · τ / π) · P.V. ∫₀^∞ ds / [ (s² - ω²) · (1 + s² · τ²) ]
```

Розкладемо підінтегральний дріб на простіші дроби за методом невизначених коефіцієнтів:

```
1 / [ (s² - ω²) · (1 + s² · τ²) ] = [ 1 / (1 + ω² · τ²) ] · [ 1 / (s² - ω²) - τ² / (1 + s² · τ²) ]
```

Обчислимо два табличні інтеграли окремо:

```
P.V. ∫₀^∞ ds / (s² - ω²) = 0                            [головне значення симетричного полюса]
∫₀^∞ τ² · ds / (1 + s² · τ²) = τ · [ arctan(s · τ) ]₀^∞ = τ · (π / 2)
```

Підставляючи результати інтегрування у вираз для `I(ω)`:

```
I(ω) = (2 · ω_p² · τ / π) · [ 1 / (1 + ω² · τ²) ] · [ 0 - τ · (π / 2) ]
     = (2 · ω_p² · τ / π) · [ - π · τ / (2 · (1 + ω² · τ²)) ]
     = - (ω_p² · τ²) / (1 + ω² · τ²)
```

Порівнюючи з лівою частиною співвідношення Крамерса — Кроніга:

```
ε₁(ω) - 1 = 1 - (ω_p² · τ²) / (1 + ω² · τ²) - 1 = - (ω_p² · τ²) / (1 + ω² · τ²)
```

Отримуємо точний збіг `ε₁(ω) - 1 ≡ I(ω)`, що строго підтверджує математичну та фізичну самоузгодженість моделі Друде з фундаментальним принципом причинності.

---

#### 7.2. Оптичні правила сум та закон збереження спектральної ваги
Інтеграл від дійсної провідності `σ₁(ω)` за всіма додатними частотами називають **спектральною вагою провідності**:

```
W_σ = ∫₀^∞ σ₁(ω) dω
```

Підставимо у цей інтеграл дійсну частину динамічної провідності Друде `σ₁(ω) = σ_0 / (1 + ω² · τ²)`:

```
W_σ = ∫₀^∞ [ σ_0 / (1 + ω² · τ²) ] dω
```

Зробимо заміну змінної `x = ω · τ`, звідки `dω = dx / τ`:

```
W_σ = (σ_0 / τ) · ∫₀^∞ dx / (1 + x²)
    = (σ_0 / τ) · [ arctan(x) ]₀^∞                     [взяли первісну арктангенса]
    = (σ_0 / τ) · (π / 2)
```

Підставимо у цей вираз формулу статичної провідності `σ_0 = (n · e² · τ) / m`:

```
W_σ = [ (n · e² · τ / m) / τ ] · (π / 2)
    = (π · n · e²) / (2 · m)                           [скоротили час релаксації τ]
```

Отримуємо **f-правило сум Томаса — Райхе — Куна (f-sum rule)**:

```
∫₀^∞ σ₁(ω) dω = (π · n · e²) / (2 · m) = (π · ε_0 · ω_p²) / 2
```

#### Фізичне значення правила сум
Зверніть увагу: час релаксації `τ` повністю випав з остаточного результату. Інтегральна спектральна вага під кривою оптичного поглинання є константою і залежить виключно від повної густини електронів `n` та їхньої маси `m`. 

Якщо якість зразка змінюється (наприклад, метал охолоджують або очищують від домішок, збільшуючи `τ`), статичний пік провідності Друде на нульовій частоті стає вищим (`σ_0 ∝ τ`), але одночасно звужується його півширина `Δω = 1 / τ`. Повна площа під графіком `σ₁(ω)` лишається абсолютно незмінною.

Аналогічне оптичне правило сум діє і для уявної частини діелектричної проникності:

```
∫₀^∞ ω · ε₂(ω) dω = (1 / ε_0) · ∫₀^∞ σ₁(ω) dω = (π / 2) · ω_p²
```

### 8. Ефект Голла та тензор динамічної провідності у магнітному полі

Розглянемо стаціонарний та високочастотний рух електронів під дією одночасного змінного електричного поля `E(t) = E_0 · exp(-i · ω · t)` та постійного магнітного поля, спрямованого вздовж осі Z: `B = (0, 0, B_z)`.

Векторний добуток `v × B` у системі координат XYZ має вигляд:

```
v × B = ( v_y · B_z,  - v_x · B_z,  0 )
```

Диференціальне рівняння Друде у проекціях на осі X та Y набуває вигляду:

```
m · (dv_x/dt + v_x/τ) = -e · E_x - e · v_y · B_z
m · (dv_y/dt + v_y/τ) = -e · E_y + e · v_x · B_z
```

Введемо фундаментальну характеристику руху заряду в магнітному полі — **циклотронну частоту** `ω_c`:

```
ω_c = (e · B_z) / m
```

Ділимо рівняння на `m` та підставляємо гармонічну залежність `d/dt → -i · ω`:

```
(1/τ - i · ω) · v_x + ω_c · v_y = - (e / m) · E_x
(1/τ - i · ω) · v_y - ω_c · v_x = - (e / m) · E_y
```

---

#### 8.1. Метод комплексних кругових координат
Для розщеплення зв'язаної системи рівнянь помножимо друге рівняння на `± i` та додамо до першого. Введемо кругові компоненти швидкості `v_± = v_x ± i · v_y` та електричного поля `E_± = E_x ± i · E_y`:

```
(1/τ - i · ω) · (v_x ± i · v_y) ∓ i · ω_c · (v_x ± i · v_y) = - (e / m) · (E_x ± i · E_y)

[ 1/τ - i · (ω ∓ ω_c) ] · v_± = - (e / m) · E_±
```

Звідси негайно знаходимо амплітуди швидкості для право- та лівоциркулярних рухів:

```
v_±(ω) = - (e / m) · E_± / [ 1/τ - i · (ω ∓ ω_c) ]
```

Кругова густина струму `J_± = -n · e · v_± = σ_±(ω) · E_±` визначається круговою провідністю:

```
σ_±(ω) = σ_0 / [ 1 - i · (ω ∓ ω_c) · τ ]
```

Повертаючись до декартових компонент струму `J_x = (J_+ + J_-) / 2` та `J_y = (J_+ - J_-) / (2 · i)`, знаходимо матричний зв'язок `J = σ̂(ω) · E`:

```
[ J_x ]   [  σ_xx(ω)   σ_xy(ω)  ]   [ E_x ]
[ J_y ] = [ -σ_xy(ω)   σ_xx(ω)  ] · [ E_y ]
```

де компоненти **динамічного тензора питомої провідності** дорівнюють:

```
σ_xx(ω) = (σ_+ + σ_-) / 2
        = (σ_0 / 2) · [ 1 / (1 - i·(ω - ω_c)·τ) + 1 / (1 - i·(ω + ω_c)·τ) ]

σ_xy(ω) = i · (σ_+ - σ_-) / 2
        = (i · σ_0 / 2) · [ 1 / (1 - i·(ω - ω_c)·τ) - 1 / (1 - i·(ω + ω_c)·τ) ]
```

---

#### 8.2. Стаціонарний режим (DC-ефект Голла)
Покладемо частоту поля рівною нулю (`ω = 0`). Кругові компоненти статичної провідності набувають вигляду `σ_±(0) = σ_0 / (1 ± i · ω_c · τ)`. Підставляючи їх у декартові формули:

```
σ_xx(0) = (σ_0 / 2) · [ 1 / (1 + i·ω_c·τ) + 1 / (1 - i·ω_c·τ) ]
        = σ_0 / (1 + ω_c² · τ²)                        [поздовжня магнітопровідність]

σ_xy(0) = (i · σ_0 / 2) · [ 1 / (1 + i·ω_c·τ) - 1 / (1 - i·ω_c·τ) ]
        = - (σ_0 · ω_c · τ) / (1 + ω_c² · τ²)          [поперечна холлівська провідність]
```

Обернемо тензор провідності для знаходження **тензора питомого опору** `ρ̂ = σ̂⁻¹`:

```
[ E_x ]   [  ρ_xx   ρ_xy  ]   [ J_x ]
[ E_y ] = [ -ρ_xy   ρ_xx  ] · [ J_y ]
```

Компоненти тензора опору обчислюються за правилами обертання матриць:

```
ρ_xx = σ_xx / (σ_xx² + σ_xy²)
     = [ σ_0 / (1 + ω_c²·τ²) ] / [ σ_0² / (1 + ω_c²·τ²) ]
     = 1 / σ_0 = m / (n · e² · τ) = ρ_0                [поздовжній опір не залежить від B]

ρ_xy = - σ_xy / (σ_xx² + σ_xy²)
     = [ (σ_0 · ω_c · τ) / (1 + ω_c²·τ²) ] / [ σ_0² / (1 + ω_c²·τ²) ]
     = (ω_c · τ) / σ_0
     = [ (e · B_z / m) · τ ] / [ (n · e² · τ) / m ]
     = B_z / (n · e)                                   [поперечний опір Голла]
```

У класичному експерименті Голла поперечний струм відсутній (`J_y = 0`), тому `E_y = - ρ_xy · J_x = - (B_z / (n · e)) · J_x`. 

За визначенням **коефіцієнт Голла** `R_H` дорівнює:

```
R_H = E_y / (J_x · B_z) = - 1 / (n · e)
```

Цей фундаментальний вираз показує, що коефіцієнт Голла в моделі Друде залежить виключно від знака заряду носіїв та їхньої об'ємної концентрації `n`, що робить вимірювання ефекту Голла головним експериментальним методом визначення типу та густини носіїв у металах і напівпровідниках.

### 9. Магнітооптика, циклотронний резонанс та геліконні хвилі

Розглянемо поширення кругово поляризованої електромагнітної хвилі вздовж зовнішнього магнітного поля `B = (0, 0, B_z)`. Комплексні діелектричні проникності для правої `(+)` та лівої `(-)` поляризацій мають вигляд:

```
ε_±(ω) = 1 + i · σ_±(ω) / (ε_0 · ω)
       = 1 - ω_p² / [ ω · (ω ∓ ω_c + i / τ) ]
```

---

#### 9.1. Циклотронний резонанс
Для правополяризованої хвилі `(+)`, вектор напруженості якої обертається у той самий бік, що й електрони на своїх циклотронних орбітах, знаменник діелектричної проникності містить різницю `(ω - ω_c)`.

Коли частота падаючого випромінювання точно збігається з циклотронною частотою (`ω = ω_c`), виникає явище **циклотронного резонансу**:

```
σ_+(ω_c) = σ_0 / [ 1 - i · (ω_c - ω_c) · τ ] = σ_0
```

Уявна частина знаменника обнуляється, і поглинання енергії досягає гігантського піка. Для спостереження чіткого циклотронного піка необхідно виконати критерій сильного поля:

```
ω_c · τ >> 1
```

тобто електрон повинен встигнути зробити декілька повних обертів по орбіті без зіткнень. Оскільки частота `ω_c = e · B / m*` точно вимірюється в експерименті (типово в мікрохвильовому діапазоні при гелієвих температурах), циклотронний резонанс є прямим спектроскопічним методом точного вимірювання ефективної маси електронів `m*` у кристалах.

---

#### 9.2. Низькочастотні геліконні хвилі (Helicons)
Розглянемо поширення хвилі правої поляризації `(+)` у сильному магнітному полі (`ω_c · τ >> 1`) на низьких частотах, що задовольняють умову:

```
ω << ω_c << ω_p
```

Оцінимо дійсну діелектричну проникність `ε_+(ω)` при знехтуванні зіткненнями (`τ → ∞`):

```
ε_+(ω) ≈ 1 - ω_p² / [ ω · (ω - ω_c) ]
       ≈ 1 + ω_p² / (ω · ω_c)                          [оскільки ω << ω_c, знак мінус змінився на плюс]
       ≈ ω_p² / (ω · ω_c) >> 1
```

Зверніть увагу: на відміну від випадку без магнітного поля (де `ε(ω) < 0` і хвиля не може проникнути в метал), у магнітному полі для правої кругової поляризації `ε_+(ω) > 0` є великою та додатною!

Хвильове число `k` стає суто дійсним:

```
k² = (ω² / c²) · ε_+(ω) = (ω² / c²) · [ ω_p² / (ω · ω_c) ] = (ω · ω_p²) / (c² · ω_c)
```

Звідси знаходимо дисперсійне співвідношення для слабозгасаючих низькочастотних електромагнітних хвиль у металах — **геліконів** (*helicons*):

```
ω(k) = (k² · c² · ω_c) / ω_p²
```

Підставимо у дисперсію явні вирази для плазмової `ω_p² = (n · e²) / (ε_0 · m)` та циклотронної `ω_c = (e · B) / m` частот:

```
ω(k) = [ k² · c² · (e · B / m) ] / [ (n · e²) / (ε_0 · m) ]
     = [ k² · (1 / (ε_0 · μ_0)) · (e · B) ] / [ (n · e²) / ε_0 ]
     = (k² · B) / (n · e · μ_0)
```

Геліконні хвилі мають квадратичний закон дисперсії `ω ∝ k²` (подібно до феромагнітних спінових хвиль) і можуть поширюватися крізь масивний метал на значні відстані з дуже малими фазовими швидкостями (від метрів до кілометрів за секунду). Інтерферометрія геліконів слугує потужним безконтактним методом вимірювання концентрації вільних носіїв заряду `n` у надчистих металах при низьких температурах.
