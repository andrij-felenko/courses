# ⚙️ Моделювання електронного газу Друде: дрейф, розсіювання та статистичний розподіл

Чисельне моделювання електронного газу за моделлю Друде є одним із найпопулярніших навчальних та дослідницьких методів у фізиці твердого тіла. Воно дає змогу на власні очі побачити, як із хаотичних випадкових зіткнень окремих мікроскопічних частинок виникає стабільний макроскопічний дрейфовий струм, який підпорядковується диференціальному закону Ома.

У класичній фізиці розрізняють два основні підходи до чисельного опису руху електронів: детерміноване інтегрування рівняння руху з випадковими зіткненнями (метод Монте-Карло) та стохастичне диференціальне рівняння Ланжевена. Нижче реалізовано метод Монте-Карло для ансамблю незалежних частинок, що рухаються у двовимірній площині провідника.

### 1. Фізична постановка задачи та чисельний алгоритм

Розглядається система з `N` незалежних електронів у 2D-кристалі. На електрони діє зовнішнє однорідне електричне поле `E_x`, напрямлене уздовж осі X.

У міжзіткнувальний інтервал часу `dt` на кожен електрон діє постійна сила Кулона `F_x = -e · E_x`, яка створює постійне прискорення `a_x = -e · E_x / m`. Згідно зі стохастичним постулатом Друде, ймовірність того, що електрон зазнає зіткнення з іоном ґратки за малий проміжок часу `dt`, визначається виразом:

```
P_scatter = 1 - exp(-dt / τ) ≈ dt / τ
```

Алгоритм обчислювального кроку розбивається на чотири послідовні фази:

1. **Прискорення полем (Ньютонівський етап)**: Оновлення швидкості кожної частинки під дією електричного поля: `v_x(t + dt) = v_x(t) + a_x · dt`. Компонента швидкості `v_y` у перпендикулярному напрямку залишається незмінною.
2. **Перевірка умов зіткнення (Етап Монте-Карло)**: Для кожної частинки генерується випадкове число `r`, рівномірно розподілене на інтервалі `[0, 1)`. Якщо `r < P_scatter`, частинка вважається такою, що зазнала розсіювання на іоні ґратки.
3. **Ізотропна релаксація та термостатування**: Частинки, що розсіялися, повністю втрачають напрямок попереднього руху. Його компоненти швидкостей перевизначаються як випадкові величини з нормальним (гауссівським) розподілом з дисперсією `σ² = k_B · T / m`, що відповідає рівноважному двовимірному розподілу Максвелла — Больцмана за температури `T`.
4. **Переміщення у просторі (Кінематичний етап)**: Оновлення координат електронів: `x(t + dt) = x(t) + v_x · dt` та `y(t + dt) = y(t) + v_y · dt`.

Після завершення кожного кроку проводиться усереднення швидкостей усіх частинок по ансамблю `⟨v_x⟩ = (1/N) · ∑ v_x`, що дає поточне значення макроскопічної дрейфової швидкості.

### 2. Дифузія та співвідношення Ейнштейна

Крім дрейфу у зовнішньому полі, симулятор дозволяє дослідити вільно-дифузійне розпливання електронної хмари за відсутності поля (`E_x = 0`).

Якщо у початковий момент часу `t = 0` всі `N` електронів помістити у точку `(0, 0)`, то з часом дисперсія їхніх координат (середній квадрат переміщення) зростає лінійно з часом:

```
⟨r²(t)⟩ = ⟨x²(t) + y²(t)⟩ = 4 · D · t
```

де `D` — **коефіцієнт дифузії** електронного газу. У моделі Друде коефіцієнт дифузії пов'язаний із тепловою швидкістю `v_th` та часом релаксації `τ`:

```
D = (1/2) · v_th² · τ = (k_B · T / m) · τ
```

Розділивши коефіцієнт дифузії `D` на рухливість електронів `μ = e·τ / m`, отримуємо фундаментальне **співвідношення Ейнштейна**:

```
D / μ = k_B · T / e
```

Це важливе співвідношення показує глибинний зв'язок між флуктуаціями (дифузією за відсутності полів) та дисипацією (дрейфовим відгуком на зовнішнє поле) для будь-якої класичної статистичної системи.

### 3. Реалізація симулятора мовами C++ та Python

Нижче наведено паралельні реалізації алгоритму Друде мовами C++17 та Python з використанням бібліотеки NumPy. Обидва приклади будують траєкторію встановлення дрейфової швидкості від початкового стану спокою до стаціонарного значення `v_d = -e·E·τ / m`.

```cpp
#include <iostream>
#include <vector>
#include <random>
#include <cmath>
#include <numeric>
#include <iomanip>

// Структура для опису стану електрона у двовимірній площині
struct Electron {
    double x{0.0};
    double y{0.0};
    double vx{0.0};
    double vy{0.0};
};

class DrudeSimulator {
private:
    std::size_t num_particles;
    double tau;          // Час релаксації (секунди)
    double E_x;          // Напруженість електричного поля (В/м)
    double dt;           // Крок інтегрування за часом (секунди)
    double mass;         // Маса електрона (кг)
    double charge;       // Заряд електрона (Кл)
    double v_thermal;    // Середня теплова швидкість (м/с)

    std::vector<Electron> particles;
    std::mt19937_64 rng;
    std::uniform_real_distribution<double> uniform_dist{0.0, 1.0};
    std::normal_distribution<double> gaussian_dist{0.0, 1.0};

public:
    DrudeSimulator(std::size_t n, double tau_s, double field_v_m, double dt_s, double v_th)
        : num_particles(n), tau(tau_s), E_x(field_v_m), dt(dt_s),
          mass(9.109e-31), charge(1.602e-19), v_thermal(v_th), particles(n)
    {
        std::random_device rd;
        rng.seed(rd());
        reset_velocities();
    }

    void reset_velocities() {
        double sigma = v_thermal / std::sqrt(2.0);
        for (auto& p : particles) {
            p.vx = gaussian_dist(rng) * sigma;
            p.vy = gaussian_dist(rng) * sigma;
        }
    }

    void step() {
        double p_scatter = 1.0 - std::exp(-dt / tau);
        double a_x = -charge * E_x / mass;
        double sigma = v_thermal / std::sqrt(2.0);

        for (auto& p : particles) {
            // 1. Прискорення полем
            p.vx += a_x * dt;

            // 2. Випадкове розсіювання на ґратці
            if (uniform_dist(rng) < p_scatter) {
                p.vx = gaussian_dist(rng) * sigma;
                p.vy = gaussian_dist(rng) * sigma;
            }

            // 3. Зсув координат
            p.x += p.vx * dt;
            p.y += p.vy * dt;
        }
    }

    double get_mean_drift_velocity_x() const {
        double sum_vx = 0.0;
        for (const auto& p : particles) {
            sum_vx += p.vx;
        }
        return sum_vx / static_cast<double>(num_particles);
    }

    double get_mean_squared_displacement() const {
        double sum_r2 = 0.0;
        for (const auto& p : particles) {
            sum_r2 += (p.x * p.x + p.y * p.y);
        }
        return sum_r2 / static_cast<double>(num_particles);
    }
};

int main() {
    const std::size_t N = 100'000;
    const double tau = 2.5e-14;      // 25 фс
    const double E_x = 1.0e4;        // 10 кВ/м
    const double dt = 1.0e-15;       // 1 фс
    const double v_th = 1.0e5;       // Теплова швидкість ~10^5 м/с

    DrudeSimulator sim(N, tau, E_x, dt, v_th);
    double theoretical_v_d = -(1.602e-19 * E_x * tau) / 9.109e-31;

    std::cout << std::scientific << std::setprecision(4);
    std::cout << "Теоретична дрейфова швидкість v_d: " << theoretical_v_d << " м/с\n";
    std::cout << "--------------------------------------------------------\n";
    std::cout << "Крок\tЧас (фс)\tСимульована v_d (м/с)\n";

    for (int step = 0; step <= 200; ++step) {
        if (step % 20 == 0) {
            double current_t = step * dt * 1.0e15;
            double sim_v_d = sim.get_mean_drift_velocity_x();
            std::cout << step << "\t" << current_t << " фс\t\t" << sim_v_d << " м/с\n";
        }
        sim.step();
    }

    return 0;
}
```

```py
import numpy as np

def simulate_drude(num_particles=100000, tau=2.5e-14, E_x=1.0e4, dt=1.0e-15, steps=200):
    """
    Чисельне моделювання ансамблю Друде методом Монте-Карло у NumPy.
    """
    mass = 9.109e-31     # Маса електрона (кг)
    charge = 1.602e-19   # Заряд електрона (Кл)
    v_th = 1.0e5         # Теплова швидкість (м/с)

    sigma = v_th / np.sqrt(2.0)
    vx = np.random.normal(0, sigma, num_particles)
    vy = np.random.normal(0, sigma, num_particles)

    a_x = -charge * E_x / mass
    p_scatter = 1.0 - np.exp(-dt / tau)

    theoretical_vd = -charge * E_x * tau / mass
    print(f"Теоретична дрейфова швидкість v_d: {theoretical_vd:.4e} м/с")
    print("-" * 55)
    print("Крок\tЧас (фс)\tСимульована v_d (м/с)")

    for step in range(steps + 1):
        if step % 20 == 0:
            mean_vd = np.mean(vx)
            print(f"{step}\t{step * dt * 1e15:.1f} фс\t\t{mean_vd:.4e} м/с")

        # 1. Прискорення полем
        vx += a_x * dt

        # 2. Визначення частинок, що розсіюються
        scattered = np.random.random(num_particles) < p_scatter

        # 3. Перевизначення швидкостей після зіткнення
        num_scattered = np.sum(scattered)
        if num_scattered > 0:
            vx[scattered] = np.random.normal(0, sigma, num_scattered)
            vy[scattered] = np.random.normal(0, sigma, num_scattered)

if __name__ == "__main__":
    simulate_drude()
```

### 4. Автокореляція швидкостей та теорема Гріна — Кубо

Ще однією важливою властивістю моделі Друде є **автокореляційна функція швидкостей** (*velocity autocorrelation function*), яка визначається як середня кореляція швидкості частинки у момент часу `t` із її початковою швидкістю у момент `t = 0`:

```
C_vv(t) = ⟨v(t) · v(0)⟩ = v_th² · exp(-t / τ)
```

Через ізотропність розсіювання кожне зіткнення повністю стирає кореляцію напрямку руху, тому автокореляційна функція експоненціально згасає з характерним часом `τ`.

Згідно з теоремою Гріна — Кубо, статична провідність `σ_0` та коефіцієнт дифузії `D` прямо пропорційні часовому інтегралу від автокореляційної функції швидкостей:

```
D = (1/d) · ∫₀^∞ ⟨v(t) · v(0)⟩ dt = (1/2) · v_th² · ∫₀^∞ exp(-t / τ) dt = (1/2) · v_th² · τ
```

Це доводить логічну узгодженість кінетичного підходу Друде та формулює фундаментальний мікроскопічний фундамент для статистичного опису переносу заряду і тепла у твердих тілах.

### 5. Аналіз результатів та чисельні застереження

Під час запуску програми спостерігається чіткий вихід середьої швидкості ансамблю на насичення. На початкових кроках (`t < τ`) електрони вільно прискорюються полем, і середня швидкість лінійно зростає з часом: `⟨v_x(t)⟩ ≈ a_x · t`.

Однак у міру того, як час наближається до декількох часів релаксації (`t > 3·τ`), кількість зіткнень зрівноважує прискорення, і середня швидкість виходить на стаціонарне плато: `⟨v_x⟩ → v_d = -e·E·τ / m`.

Під час розробки подібних моделей слід ураховувати кілька важливих чисельних застережень:

1. **Критерій стійкості за часом (`dt << τ`)**: Крок інтегрування за часом `dt` обов'язково має бути на один-два порядки меншим за час релаксації `τ`. Якщо обрати `dt ≥ τ`, формула ймовірності `P = dt / τ` дасть значення, близькі до 1, що призведе до штучного «заморожування» прискорення полем.
2. **Флуктуації за часом та число частинок `N`**: Середня теплова швидкість електронів (`~10⁵` м/с) на дев'ять порядків перевищує дрейфову швидкість (`~10⁻⁴` м/с). Щоб виділити такий слабкий корисний сигнал дрейфу на тлі колосального теплового шуму, потрібен ансамбль як мінімум із `N = 100 000` частинок. Відносна флуктуація середнього зменшується за законом `1 / √N`, тому на малих вибірках (`N = 1000`) стаціонарне плато буде повністю зашумлене тепловими спотвореннями.
3. **Граничні умови на поверхнях**: У тонких металевих плівках та нанодротах товщиною `d ~ l` розсіювання на поверхнях матеріалу стає визначальним (модель Фукса — Зондхаймера). Дзеркальне відбивання зберігає поздовжній імпульс електрона, тоді як дифузне розсіювання на шорсткостях стінок різко зменшує ефективний час релаксації `τ_eff` та збільшує питомий опір провідника.
