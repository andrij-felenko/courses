# 🧮 Математика спінової прецесії Рашби та інтерференції магнонів

Ця вставка містить повний математичний вивід фундаментальних рівнянь, які описують квантову прецесію спіна електрона у двовимірному каналі під дією спін-орбітальної взаємодії Рашби та Дрессельхауза, спін-залежне транспортне рівняння Ландауера — Бюттікера, матричний формалізм щільності станів, дисперсію дипольно-обмінних спінових хвиль у феромагнітних плівках та вихідні інтерференційні рівняння магнонного логічного елемента Маха — Цендера.

## 1. Релятивістське походження та гамільтоніан 2DEG

У двовимірному електронному газі (2DEG), сформованому в асиметричній квантовій ямі (наприклад, у гетероструктурах InAs/InGaAs або GaAs/AlGaAs), квантування руху уздовж осі `z` створює внутрішнє електричне поле `E_z = - ∂V/∂z`.

Спін-орбітальна взаємодія виникає як релятивістська поправка до рівняння Дірака при переході до нерелятивістського рівняння Шредінгера через перетворення Фольді — Ваутгайзена (Foldy-Wouthuysen transformation). Релятивістська поправка до потенціалу `V(r)` має вигляд:

```
H_SO = (ℏ / (4 · m₀² · c²)) · (σ × ∇V) · p
```

У двовимірному електронному газі з асиметричним потенціалом квантової ями вздовж осі `z` градієнт потенціалу становить `∇V = (0, 0, e·E_z)`. Підстановка цього градієнта у релятивістський оператор дає гамільтоніан Рашби.

Загальний гамільтоніан одноелектронних станів у площині `(x, y)` враховує два основні внески спін-орбітальної взаємодії:

```
H = H₀ + H_R + H_D
  = p² / (2·m*) + (α_R / ℏ) · (σ_x · p_y - σ_y · p_x) + (β_D / ℏ) · (σ_x · p_x - σ_y · p_y)
```

де:
- `m*` — ефективна маса електрона у напівпровідниковій квантовій ямі (для InAs `m* ≈ 0.023 · m₀`);
- `σ = (σ_x, σ_y, σ_z)` — вектор матриць Паулі;
- `α_R` — константа спін-орбітального зв'язку Рашби, обумовлена структурною асиметрією потенціалу квантової ями (Structural Inversion Asymmetry, SIA);
- `β_D` — константа Дрессельхауза, обумовлена об'ємною асиметрією кристалічної ґратки ковалентного сполуки без центра інверсії (Bulk Inversion Asymmetry, BIA).

### Умова Стійкої спінової спіралі (Persistent Spin Helix, PSH)
Коли константа Рашби точно дорівнює константі Дрессельхауза (`α_R = β_D`), спін-орбітальний гамільтоніан набуває симетрії `SU(2)`. За цієї умови ефективне магнітне поле стає однорідним у напрямку, паралельному кристалографічній осі `[110]`. Це усуває спінову релаксацію за механізмом Дьяконова — Переля, а довжина спінової когерентності збільшується на два порядки, формуючи так звану стійку спінову спіраль (Persistent Spin Helix).

У подальшому аналізі транзистора Датта — Даса розглядається випадок домінування ефекту Рашби (`α_R ≫ β_D`), який піддається плавному керуванню напругою затвора `V_g`.

Для електрона, що рухається балістично уздовж вузького одновимірного каналу у напрямку `x` (при цьому `p_y = 0` та `p_x = ℏ·k_x`), гамільтоніан спрощується до вигляду:

```
H_1D = (ℏ²·k_x²) / (2·m*) - α_R · k_x · σ_y
```

Ефективне поле Рашби спрямоване уздовж осі `y`:

```
B_R = (2 · α_R · k_x) / (g · μ_B) · ŷ
```

тут `g` — g-фактор електрона в напівпровіднику, `μ_B = e·ℏ / (2·m₀)` — магнетон Бора, а `ŷ` — одиничний вектор уздовж осі `y`.

## 2. Квантовомеханічний вивід спінової прецесії та провідності каналу

Розглянемо рух електрона з фермієвською енергією `E_F`. Власні значення енергії 1D-гамільтоніана для двох спінових підзон станують:

```
E_±(k_x) = (ℏ²·k_x²) / (2·m*) ∓ α_R · k_x
```

Розв'язуючи це квадратне рівняння відносно хвильового вектора `k_x` для заданого значення енергії `E_F`, отримуємо два значення хвильових векторів `k_+` та `k_-` для спінових станів, орієнтованих уздовж та проти осі `y`:

```
k_± = √[(2·m*·E_F) / ℏ² + (m*·α_R / ℏ²)²] ∓ (m* · α_R) / ℏ²

k_± ≈ k_F ∓ (m* · α_R) / ℏ²      [при m* · α_R ≪ ℏ · k_F]
```

тут `k_F = √(2·m*·E_F) / ℏ` — фермієвський хвильовий вектор за відсутності спін-орбітальної взаємодії.

Різниця хвильових векторів між двома спіновими гілками дорівнює:

```
Δk = k_- - k_+ = (2 · m* · α_R) / ℏ²
```

### Еволюція хвильової функції спіна уздовж каналу

Нехай у точці інжекції `x = 0` електрон виходить із феромагнітного витоку зі спіновим станом, поляризованим уздовж осі `z` (поляризація вгору `|↑_z⟩`):

```
|Ψ(0)⟩ = |↑_z⟩ = (1 / √2) · |↑_y⟩ + (i / √2) · |↓_y⟩
```

Для аналізу еволюції спінового стану скористаємося унітарним оператором еволюції спіна `U(x)`:

```
U(x) = exp( -i · (m* · α_R · x / ℏ²) · σ_y )
     = cos( (m* · α_R · x) / ℏ² ) · I - i · sin( (m* · α_R · x) / ℏ² ) · σ_y
```

Після проходження каналу довжиною `L` хвильова функція набуває вигляду:

```
|Ψ(L)⟩ = U(L) · |Ψ(0)⟩
       = exp(i · k_F · L) · [ (1 / √2) · exp(-i · Δk·L / 2) · |↑_y⟩ + (i / √2) · exp(i · Δk·L / 2) · |↓_y⟩ ]
```

Обчислюючи середнє значення операторів Паулі у стані `|Ψ(L)⟩`, знаходимо компоненти вектора спінової поляризації електрона у точці `x = L`:

```
⟨σ_x⟩ = 0
⟨σ_y⟩ = 0
⟨σ_z⟩ = cos(Δk · L) = cos( (2 · m* · α_R · L) / ℏ² )
```

Отже, вектор спіна прецесує у площині `(z, x)` навколо поля Рашби `B_R ∥ y`. Повний кут прецесії спіна `Δθ` на довжині каналу `L` становить:

```
Δθ = Δk · L = (2 · m* · α_R · L) / ℏ²    [Формула прецесії Датта — Даса]
```

### Розрахунок струму за формулою Ландауера — Бюттікера

Згідно з формалізмом Ландауера — Бюттікера для балістичного квантового транспорту, провідність каналу `G` між феромагнітним витоком з поляризацією `P_S` та стоком з поляризацією `P_D` описується виразом:

```
G = (e² / h) · Tr(T · T†)
  = (e² / h) · [ 1 + P_S · P_D · cos(Δθ) ]
```

При ідеальній поляризації контактів (`P_S = P_D = 1`) струм каналу залежить від напруги затвора за косинусоїдальним законом:

```
I(V_g) = I_max · cos²( Δθ / 2 )
       = I_max · cos²( (m* · α_R(V_g) · L) / ℏ² )
```

Умови формування логічних станів у транзисторі Датта — Даса:

```
Δθ_ON  = 2·π · n  ⇒  α_R_ON  = (n · π · ℏ²) / (m* · L)     [Стан 1: I = I_max, опір R_min]
Δθ_OFF = π · (2n+1) ⇒  α_R_OFF = ((2n+1) · π · ℏ²) / (2·m* · L) [Стан 0: I = 0, опір R_max]
```

## 3. Математична теорія магнонних хвильових логічних вентилів

У магнонних логічних вентилях носієм інформації є колективні прецесійні коливання намагніченості `m(r, t) = M(r, t) - M_s · ẑ` у тонких плівках залізо-ітрієвого гранату (YIG).

Динаміка вектора намагніченості описується рівнянням Ландау — Ліфшиця — Гільберта (LLG):

```
∂M / ∂t = -γ · μ₀ · (M × H_eff) + (α_G / M_s) · (M × ∂M / ∂t)
```

де `γ = 1.76 × 10¹¹` рад/(с·Тл) — гіромагнітне відношення, `μ₀` — магнітна стала, `α_G` — безрозмірний параметр згасання Гільберта, а `H_eff` — ефективне магнітне поле:

```
H_eff = H_ext · ẑ + H_ex + H_dip + H_an
```

тут `H_ex = (D / (γ · μ₀ · M_s)) · ∇²M` — обмінне поле, `H_dip` — магнитостатичне дипольне поле, `H_an` — поле магнітної анізотропії.

### Дисперсійне співвідношення та моди спінових хвиль у плівках YIG

Залежно від орієнтації зовнішнього магнітного поля `H_ext` відносно хвильового вектора `k`, у плівці товщиною `d` розрізняють три основні моди магнитостатичних хвиль:

1. **Поверхневі хвилі Демона — Ешбаха (Damon-Eshbach waves, MSSW):** Поле `H_ext` лежить у площині плівки перпендикулярно до хвильового вектора `k`. Дисперсійне співвідношення має вигляд:
   ```
   ω²(k) = ω_H · (ω_H + ω_M) + (ω_M² / 4) · (1 - exp(-2·k·d))
   ```
   де `ω_H = γ · μ₀ · H_ext`, `ω_M = γ · μ₀ · M_s`.
2. **Об'ємні зворотні хвилі (MSBVW):** Поле `H_ext` паралельне хвильовому вектору `k`. Дисперсія має від'ємний нахил (`∂ω/∂k < 0`), а групова швидкість спрямована проти фазової.
3. **Об'ємні прямі хвилі (MSFVW):** Поле `H_ext` спрямоване перпендикулярно до площини плівки.

Для короткохвильових обмінних магнонів (при `k · d ≫ 1`) дисперсія описується квадратичною залежністю:

```
ω(k) ≈ γ · μ₀ · (H_ext + D · k²)
```

Групова швидкість поширення магнонного пакета становить `v_g = ∂ω / ∂k = 2 · γ · μ₀ · D · k`.

### Модель магнонного інтерферометра Маха — Цендера

Розглянемо інтерферометр із двома однаковими плечима довжиною `L_arm`. Вхідна спінова хвиля `m_in(t) = A₀ · exp(i·(k·x - ω·t))` розщеплюється на дві рівні компоненти.

У першому плечі під дією керуючого поля затвора `H_gate` або напругової зміни анізотропії (VCMA) хвильовий вектор отримує приріст `k₁ = k₀ + Δk`. У другому плечі хвильовий вектор залишається незмінним `k₂ = k₀`.

Фазовий зсув `Δφ`, що накопичується між двома плечима на виході:

```
Δφ = ∫₀^{L_arm} (k₁(x) - k₂(x)) dx = Δk · L_gate
```

де `L_gate` — довжина ділянки фазового затвора.

При зміні коефіцієнта поверхневої анізотропії `K_s` під дією напруги затвора `V_g` (ефект VCMA):

```
ΔK_s = ξ_VCMA · (V_g / d_ox)

Δk = (∂k / ∂K_s) · ΔK_s
```

тут `ξ_VCMA` — коефіцієнт напругової модуляції анізотропії (типово `30–100` фДж/(В·м)), а `d_ox` — товщина підзатворного діелектрика.

### Сумування хвиль та логічний вихід

На виході Y-розгалужувача комплексні амплітуди хвиль додаються за законом суперпозиції:

```
m_out(t) = A₁ · exp(i·(k₀·L_arm - ω·t + Δφ)) + A₂ · exp(i·(k₀·L_arm - ω·t))
```

Результуюча інтенсивність магнонного сигналу `I_out`, яка реєструється вихідним індуктивним або SOT-детектором, пропорційна квадрату модуля амплітуди:

```
I_out = |m_out|² = A₁² + A₂² + 2 · A₁ · A₂ · cos(Δφ)
```

При рівних амплітудах у плечах (`A₁ = A₂ = A`):

```
I_out(Δφ) = 2 · A² · (1 + cos(Δφ)) = 4 · A² · cos²(Δφ / 2)
```

1. **При `Δφ = 0` або `2·π` (Конструктивна інтерференція):** `I_out = 4·A²` — максимальний вихідний сигнал, що відповідає логічному стануть `1`.
2. **При `Δφ = π` (Деструктивна інтерференція):** `I_out = 0` — повне взаємне погашення хвиль у протифазі, що відповідає логічному стануть `0`.

Ця витончена хвильова суперпозиція дозволяє реалізувати логічний елемент XOR або мажоритарний вентиль без застосування напівпровідникових p-n переходів та без перевитрати енергії на нагрівання провідників.
