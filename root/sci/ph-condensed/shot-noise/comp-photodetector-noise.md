# 🔌 Шум фотодетекторів та p-n переходів

Дробовий шум є фундаментальним фізичним чинником, який визначає межу чутливості більшості оптичних та електронних пристроїв — від напівпровідникових p-n фотодіодів і лавинних фотодетекторів до вакуумних фотопомножувачів та волоконно-оптичних приймачів. На відміну від омічних резисторів, де в стані термодинамічної рівноваги виникає тепловий шум хаотично рухомих електронів, у пристроях із потенціальними бар'єрами носії заряду долають збіднену область у випадкові моменти часу. Це викликає потужні нерівноважні флуктуації струму, спектральна потужність яких прямо пропорційна величині протікаючого постійного струму.

### 1. Шумова модель p-n фотодіода

Розглянемо еквівалентну шумову схему напівпровідникового p-n або PIN фотодіода, що працює під зворотним зсувом. При освітленні деплеційної області фотонами з енергією `h·ν > E_g` відбувається фотогенерація електронно-діркових пар. Під дією сильного внутрішнього електричного поля фотозгенеровані носії розділяються: електрони дрейфують до n-області, а дірки — до p-області, створюючи макроскопічний фотострум `I_ph`.

Одночасно через фотодіод навіть у повній темряві протікає темновий струм `I_dark`. Він складається з трьох фізичних компонентів:
- **Дифузійного струму неосновних носіїв**, що потрапляють до деплеційної області з нейтральних n- та p-областей;
- **Струму термогенерації в деплеційній області** через глибокі рівні домішок та дефекти ґратки (механізм Шокли — Рида — Холла);
- **Поверхневого струму витоку**, що протікає по краях кристала фотодіода.

Оскільки як процес генерації фотоелектронів, так і термогенерація темнового струму є сукупністю статистично незалежних квантових подій, обидва струми генерують дробовий шум. Загальна одностороння спектральна густина потужності шумового струму фотодіода описується формулою:

```
S_I,shot = 2 · q · (I_ph + I_dark)
```

Середньоквадратичне значення шумового струму в ефективній смузі частот підсилювального тракту `Δf` становить:

```
i_n,shot = √(2 · q · (I_ph + I_dark) · Δf)
```

У реальному фотоприймальному вузлі фотодіод підключається до навантажувального опору `R_L` або до кола зворотного зв'язку трансімпедансного підсилювача (TIA). Резистор навантаження створює власний тепловий шум Найквіста:

```
i_n,thermal = √((4 · k_B · T / R_L) · Δf)
```

Повний шумовий струм фотоприймача обчислюється як квадратична сума всіх статистично незалежних шумових компонентів:

```
i_n,total = √(i_n,shot² + i_n,thermal²)
          = √((2 · q · (I_ph + I_dark) + 4 · k_B · T / R_L) · Δf)
```

### 2. Режими роботи фотоприймача та квантова границя

Співвідношення між дробовим та тепловим шумом визначає два принципово різних режими роботи фотоприймального пристрою:

1. **Теплово-шумовий предел (Thermal-Noise Limited).** При слабких оптичних сигналах (`I_ph ≪ I_dark` або коли фотострум є надто малим) тепловий шум резистора навантаження `4 k_B T / R_L` значно перевищує дробовий шум фотоструму. У цьому режимі відношення сигнал/шум `SNR` за напругою або струмом квадратично залежить від падної оптичної потужності `P_opt`:

```
SNR = I_ph² / i_n,thermal²
    = (R_p · P_opt)² / ((4 · k_B · T / R_L) · Δf)
```

де `R_p = (η · q) / (h · ν)` — спектральна чутливість фотодіода (А/Вт), `η` — квантова ефективність, `h·ν` — енергія фотона. Для підвищення чутливості у цьому режимі необхідно збільшувати опір навантаження `R_L` та охолоджувати схему.

2. **Дробово-шумовий предел (Shot-Noise Limited / Quantum Limit).** При високому рівні освітленості фотострум створює дробовий шум, який повністю пригнічує тепловий шум навантаження та темновий струм: `2 q I_ph ≫ (4 k_B T / R_L + 2 q I_dark)`. У цьому випадку вираз для `SNR` набуває гранично простого вигляду:

```
SNR = I_ph² / (2 · q · I_ph · Δf)
    = I_ph / (2 · q · Δf)
```

Виразивши фотострум через кількість падних фотонів `N_ph` за час спостереження `t_int = 1 / (2 Δf)`, маємо:

```
SNR = η · N_ph
```

Це означає, що у дробово-шумовому режимі відношення сигнал/шум обмежується виключно квантовою корпускулярною природою самого світла. Навіть ідеальний детектор із `η = 1` не може подолати цей фундаментальний поріг.

### 3. Шум у фотодетекторах із внутрішнім підсиленням (APD та PMT)

Для реєстрації надзвичайно слабких оптичних сигналів використовують фотодетектори з внутрішнім помноженням носіїв: лавинні фотодіоди (APD) та вакуумні фотоелектронні помножувачі (ФЕУ/PMT). У цих пристроях первинний фотоелектрон прискорюється електричним полем і викликає лавину вторинних іонізацій, помножуючи заряд у `M` разів.

Однак лавинний процес є ймовірнісним: кожен первинний електрон генерує лавину з випадковим коефіцієнтом підсилення `M_k` навколо середнього значення `⟨M⟩`. Через флуктуації коефіцієнта підсилення спектральна густина шуму на виході зростає швидше, ніж `⟨M⟩²`:

```
S_I,out = 2 · q · I_primary · ⟨M⟩² · F(M)
```

де `F(M) > 1` — коефіцієнт надлишкового шуму (Excess Noise Factor).

Для лавинних напівпровідникових фотодіодів (APD) Макайнтайр (R.J. McIntyre) вивів формулу для `F(M)` через відношення коефіцієнтів ударної іонізації дірок та електронів `k = α_h / α_e`:

```
F(M) = k · M + (1 - k) · (2 - 1 / M)
```

У кремнієвих (Si) APD відношення `k ≈ 0.02...0.05` є дуже малим, тому надлишковий шум є низьким (`F(M) ≈ 2...3`). У германієвих (Ge) та індо-галієвих (InGaAs) APD значення `k ≈ 0.4...0.5`, що призводить до стрімкого зростання шуму при підсиленні. 

Для вакуумних фотопомножувачів із дінодною системою надлишковий фактор описується коефіцієнтом вторинної емісії першого дінода `δ_1`:

```
F(M) ≈ 1 + 1 / δ_1
```

Оскільки для ефективних дінодів `δ_1 ≈ 5...8`, надлишковий шум вакуумних ФЕУ є дуже малим (`F(M) ≈ 1.15...1.25`), що робить їх ідеальними приладами для рахування поодиноких фотонів (Single-Photon Counting).

### 4. Інженерні показники та параметри оптимізації

Для порівняння різних фотодетекторів за рівнем власного дробового шуму використовують дві основні величини:

1. **Еквівалентна потужність шуму NEP (Noise Equivalent Power):** потужність оптичного сигналу, яка створює фотострум, рівний шумовому струму детектора у смузі 1 Гц:

```
NEP = √(2 · q · I_dark) / R_p     [Вт / √Гц]
```

2. **Питома виявна здатність D* (Detectivity):** нормована на площу фоточутливого майданчика `A` та смугу частот величина, протилежна NEP:

```
D* = √A / NEP     [см · √Гц / Вт]
```

Для досягнення граничної чутливості у сучасних оптоелектронних системах дотримуються наступних рекомендацій:
- **Глибоке термоелектричне охолодження.** Спадання температури матриці на кожні 8–10 °C зменшує темновий струм `I_dark` удвічі, що знижує підшорсток дробового шуму.
- **Оптимізація площі фотодіода.** Зменшення фізичної площі `A` кристала фотодіода лінійно зменшує темновий струм і бар'єрну ємність `C_j`.
- **Застосування трансімпедансних підсилювачів із низьким імпедансом.** Підключення фотодіода до віртуальної землі операційного підсилювача усуває вплив зсуву напруги і мінімізує струми витоку.
