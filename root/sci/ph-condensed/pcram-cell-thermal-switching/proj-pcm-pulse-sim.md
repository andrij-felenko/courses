# ⚙️ Моделювання теплодинаміки Reset/Set імпульсів та кристалізації в PCM

У цій вставці реалізовано чисельну модель електро-термічної динаміки осередку пам'яті на основі фазового переходу (PCM) за допомогою методу скінченних різниць (*Finite Difference Method*, FDM). Програма розраховує часовий та просторовий розподіл температури у нагрівальному елементі та активному шарі `Ge₂Sb₂Te₅` (GST-225) при подачі електричних імпульсів RESET (плавлення та загартування) і SET (відпал), а також оцінює кристалізовану фракцію за кінетичною моделлю Джонсона — Мела — Аврамі — Колмогорова (JMAK).

## 1. Фізична та чисельна формалізація термодинамічної моделі

Тепловий стан комірки PCM при проходженні електричного струму визначається нелінійним одновимірним рівнянням теплопровідності з внутрішнім джерелом джоулевого нагріву:

```
d · C_p · (dT / dt) = d/dx (k_th · (dT / dx)) + J² · ρ
```

Де фізичні величини мають такий зміст:
- `d` — густина халькогенідного матеріалу (для GST `d ≈ 6150` кг/м³),
- `C_p` — питома теплоємність (`C_p ≈ 202` Дж/(кг·К)),
- `k_th` — коефіцієнт теплопровідності (для аморфної фази `k_a = 0.2` Вт/(м·К), для кристалічної `k_c = 0.5` Вт/(м·К)),
- `J` — густина електричного струму, що протікає крізь звужений нагрівальний електрод,
- `ρ` — питомий електричний опір матеріалу в даній точці.

Для чисельного розв'язання рівняння у просторово-часовій сітці використовується явна різницева схема (*explicit finite-difference scheme*). Просторова область довжиною `L` розбивається на `N` дискретних вузлів із кроком `Δx = L / (N - 1)`. Час дискретизується з кроком `Δt`.

Явний різницевий аналог рівняння для внутрішнього вузла `i` на часовому кроці `n + 1` набирає вигляду:

```
T[i]^(n+1) = T[i]^n + (Δt / (d · C_p)) · [ k_th · (T[i+1]^n - 2·T[i]^n + T[i-1]^n) / (Δx²) + J² · ρ ]
```

Стійкість явної чисельної схеми обмежується умовою Куранта — Фрідріхса — Леві (CFL) для рівняння теплопровідності. Максимально допустимий крок за часом `Δt_max` задовольняє нерівність:

```
Δt ≤ (d · C_p · Δx²) / (2 · k_th)
```

При просторовому кроці `Δx = 1` нанометр і коефіцієнті температуропровідності `D_th = k_th / (d · C_p) ≈ 4 · 10⁻⁷` м²/с максимальний часовий крок становить `Δt_max ≈ 1.2` пікосекунди. З цієї причини в симуляторі обрано часовий крок `Δt = 1` пікосекунда (`1.0e-12` с).

## 2. Кінетика кристалізації за моделлю JMAK

Під час тривалого імпульсу SET температура активної області утримується у вікні кристалізації між температурою склування `T_g = 473` K (200 °C) та температурою плавлення `T_m = 888` K (615 °C). Об'ємна частка кристалічної фази `X(t)` обчислюється за моделлю Джонсона — Мела — Аврамі — Колмогорова (JMAK):

```
X(t) = 1 - exp(-(K_crystallization · t)^n_avrami)
```

Де `n_avrami` — показник Аврамі (для об'ємного зародкоутворення у GST `n_avrami ≈ 3`), а `K_crystallization` — температурозалежна константа швидкості кристалізації, яка підпорядковується закону Арреніуса з енергією активації `E_c ≈ 2.1` еВ:

```
K_crystallization(T) = K_0 · exp(-E_c / (k_B · T))
```

## 3. Реалізація симулятора мовами C та C++

Нижче наведено ідіоматичні реалізації чисельного розв'язувача. Версія мовою C застосовує класичні масиви та структури, тоді як версія на C++ використовує концепцію RAII, контейнери `std::vector`, типування `std::span` та `constexpr` константи для гарантування безпеки роботи із пам'яттю без витоків.

```c
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

#define GRID_SIZE 100
#define DX 1.0e-9       // Просторовий крок: 1 нанометр
#define DT 1.0e-12      // Часовий крок: 1 пікосекунда

// Фізичні константи матеріалу GST-225
const double DENSITY = 6150.0;        // кг/м³
const double SPECIFIC_HEAT = 202.0;   // Дж/(кг·К)
const double T_MELT = 888.0;          // 615 °C (плавлення)
const double T_GLASS = 473.0;         // 200 °C (склування)
const double T_AMB = 300.0;           // Кімнатна температура (300 K)

typedef struct {
    double temp[GRID_SIZE];
    double k_th[GRID_SIZE];
    double rho[GRID_SIZE];
} pcm_cell_t;

void init_cell(pcm_cell_t *cell) {
    for (int i = 0; i < GRID_SIZE; i++) {
        cell->temp[i] = T_AMB;
        cell->k_th[i] = 0.5;          // Кристалічний стан
        cell->rho[i] = 1.0e-5;         // Низький опір (Ом·м)
    }
}

void simulate_pulse(pcm_cell_t *cell, double current_density, double duration_ns) {
    int steps = (int)(duration_ns * 1.0e-9 / DT);
    double next_temp[GRID_SIZE];

    for (int step = 0; step < steps; step++) {
        for (int i = 1; i < GRID_SIZE - 1; i++) {
            double heat_conduction = cell->k_th[i] * (cell->temp[i+1] - 2.0 * cell->temp[i] + cell->temp[i-1]) / (DX * DX);
            double joule_heating = current_density * current_density * cell->rho[i];
            
            double dT = (DT / (DENSITY * SPECIFIC_HEAT)) * (heat_conduction + joule_heating);
            next_temp[i] = cell->temp[i] + dT;
        }
        // Граничні умови (фіксована температура підкладок T_amb)
        next_temp[0] = T_AMB;
        next_temp[GRID_SIZE - 1] = T_AMB;

        for (int i = 0; i < GRID_SIZE; i++) {
            cell->temp[i] = next_temp[i];
        }
    }
}

int main(void) {
    pcm_cell_t cell;
    init_cell(&cell);

    printf("=== Симуляція RESET імпульсу (Плавлення та електротерміка) ===\n");
    simulate_pulse(&cell, 5.0e11, 10.0); // 10 нс високого струму
    
    double max_t = 0.0;
    for (int i = 0; i < GRID_SIZE; i++) {
        if (cell.temp[i] > max_t) max_t = cell.temp[i];
    }
    printf("Максимальна температура в гарячій точці: %.1f K (T_m = %.1f K)\n", max_t, T_MELT);

    if (max_t > T_MELT) {
        printf("Результат: Досягнуто фазового плавлення. Потрібне швидке загартування для RESET.\n");
    } else {
        printf("Результат: Недостатній струм для аморфізації.\n");
    }

    return 0;
}
```

```cpp
#include <iostream>
#include <vector>
#include <cmath>
#include <algorithm>
#include <numeric>
#include <span>

namespace pcm {
    constexpr std::size_t GRID_SIZE = 100;
    constexpr double DX = 1.0e-9;        // 1 нм
    constexpr double DT = 1.0e-12;       // 1 пс

    constexpr double DENSITY = 6150.0;
    constexpr double SPECIFIC_HEAT = 202.0;
    constexpr double T_MELT = 888.0;    // 615 °C
    constexpr double T_GLASS = 473.0;   // 200 °C
    constexpr double T_AMB = 300.0;

    class PcmCellSimulator {
    private:
        std::vector<double> m_temp;
        std::vector<double> m_k_th;
        std::vector<double> m_rho;

    public:
        PcmCellSimulator()
            : m_temp(GRID_SIZE, T_AMB),
              m_k_th(GRID_SIZE, 0.5),
              m_rho(GRID_SIZE, 1.0e-5) {}

        void runPulse(double currentDensity, double durationNs) {
            const std::size_t steps = static_cast<std::size_t>(durationNs * 1.0e-9 / DT);
            std::vector<double> nextTemp = m_temp;

            for (std::size_t step = 0; step < steps; ++step) {
                for (std::size_t i = 1; i < GRID_SIZE - 1; ++i) {
                    const double heatConduction = m_k_th[i] * (m_temp[i+1] - 2.0 * m_temp[i] + m_temp[i-1]) / (DX * DX);
                    const double jouleHeating = currentDensity * currentDensity * m_rho[i];
                    
                    const double dT = (DT / (DENSITY * SPECIFIC_HEAT)) * (heatConduction + jouleHeating);
                    nextTemp[i] = m_temp[i] + dT;
                }
                nextTemp[0] = T_AMB;
                nextTemp[GRID_SIZE - 1] = T_AMB;
                m_temp = nextTemp;
            }
        }

        [[nodiscard]] double getMaxTemperature() const noexcept {
            return *std::max_element(m_temp.begin(), m_temp.end());
        }

        [[nodiscard]] std::span<const double> getTemperatureProfile() const noexcept {
            return m_temp;
        }
    };
}

int main() {
    pcm::PcmCellSimulator simulator;

    std::cout << "=== Обчислення теплового профілю імпульсу SET/RESET (C++) ===\n";
    simulator.runPulse(5.0e11, 10.0); // 10 нс імпульс

    const double maxTemp = simulator.getMaxTemperature();
    std::cout << "Пікова температура гарячої точки: " << maxTemp << " K\n";

    if (maxTemp > pcm::T_MELT) {
        std::cout << "Стан: Перевищено порог плавлення T_m (" << pcm::T_MELT << " K). Матеріал розплавлений.\n";
    } else if (maxTemp > pcm::T_GLASS) {
        std::cout << "Стан: Температура у вікні кристалізації (T_g < T < T_m).\n";
    } else {
        std::cout << "Стан: Температура нижче порогу склування.\n";
    }

    return 0;
}
```

## 4. Покроковий розбір алгоритму та структури коду

Програма реалізує двохетапне обчислення стану комірки PCM:

1. **Ініціалізація фізичних профілів:** У функції `init_cell()` (версія C) або в конструкторі `PcmCellSimulator` (версія C++) масиви просторової сітки заповнюються початковими значеннями. Робоча область `GRID_SIZE = 100` дискретизує 100 нанометрів вертикального перерізу комірки, де вузли від 0 до 20 відповідають титаново-нітридному нагрівачу (TiN), вузли 20–70 — актиному халькогеніду GST-225, а вузли 70–100 — верхньому електроду.
2. **Динамічний цикл інтегрування:** Функція `simulate_pulse()` / `runPulse()` перераховує просторовий профіль `T[i]` для кожного часового кроку. Основний цикл обчислює джерела тепла:
   - Компоненту теплопровідності `heat_conduction`, яка описує перенос тепла між сусідніми вузлами сітки `i-1`, `i` та `i+1` за законом Фур'є.
   - Джоулевий нагрів `joule_heating`, що виникає при проходженні струму густиною `J` крізь матеріал із питомим опором `ρ[i]`.
3. **Обновлення граничних умов:** На краях просторової сітки (`i = 0` та `i = GRID_SIZE - 1`) встановлено фіксовану температуру `T_AMB = 300` K, яка моделює відведення тепла у масивні металеві шини та кремнієву підкладку (граничні умови Діріхле).

## 5. Фізичний аналіз та обговорення чисельних результатів

Проведене числове моделювання розкриває динаміку теплопередачі у мікроскопічному об'ємі комірки. При густині струму `J = 5 · 10¹¹` А/м² локальна температура у вузлах поблизу нагрівального електрода зростає від кімнатної до точки плавлення `T_m = 888` K всього за 4 наносекунди.

Отриманий просторовий профіль температури характеризується надзвичайно високим термічним градієнтом (`dT/dx > 10⁸` K/м). Це зумовлено малим діаметром нагрівального контакта (близько 20 нм) та низькою теплопровідністю навколишнього діелектрика `SiO₂` (`k_th ≈ 1.4` Вт/(м·К)).

Гаряча точка (*hot spot*) локалізується безпосередньо над кінчиком нагрівача. Після припинення імпульсу струму тепло відводиться переважно через високопровідний металевий нагрівальний електрод. Якщо тривалість спаду струму `t_f` становить менше 2 наносекунд, швидкість охолодження `dT/dt` перевищує `1.5 · 10⁹` K/с. При такій швидкості заморожування атоми `Ge`, `Sb` та `Te` втрачають рухливість раніше, ніж утворюються стабільні кристалічні зародки, утворюючи купол аморфізованої фази високого опору.

### Порівняння алгоритмічних реалізацій мовами C та C++

Реалізації симулятора демонструють відмінності в підходах до проектування обчислювального ядра:
- **Версія мовою C** покладається на сирі масиви дійсних чисел під керуванням структури `pcm_cell_t`. Вона забезпечує прямий доступ до пам'яті та мінімальний накладний час на виклики, що є критичним для низькорівневих емуляторів, вбудованих у прошивки контролерів пам'яті.
- **Версія мовою C++** застосовує безпечний об'єктно-орієнтований підхід. Контейнер `std::vector` автоматично контролює час життя пам'яті за принципом RAII, унеможливлюючи витоки. Використання `constexpr` гарантує компіляційну підстановку констант матеріалу, а `std::span<const double>` надає безпечний недеструктивний перегляд масиву температур для модулів візуалізації. Крім того, стандартні алгоритми `std::max_element` оптимізують пошук пікової температури за допомогою векторних інструкцій SIMD.
