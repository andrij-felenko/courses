# 🧮 Квантування провідності через хіральні крайкові канали та формалізм Ландауера-Бюттікера

Математична строгість цілочисельного квантового ефекту Холла спирається на два взаємодоповнюючі теоретичні фундаменти: мезоскопічний формалізм квантового транспорту Ландауера — Бюттікера (*Landauer-Büttiker formalism*) для балістичних одновимірних каналів та топологічну теорію зонної структури (числа Черна, інваріант TKNN та відповідність об'єму і межі). Нижче наведено послідовний математичний апарат: від одновимірного квантування провідності та багатополюсної матриці розсіювання до точного розв'язання системи рівнянь для 6-контактного містка Холла, аналізу зворотного розсіювання у звуженнях (QPC) та топологічного виведення Лафліна і Таулесса.

---

### 1. Одновимірний квантовий транспорт та формула Ландауера

Розглянемо одновимірний квантовий провідник (або окремий крайковий канал на межі зразка), підключений між двома макроскопічними електронними резервуарами: лівим (`L`, source) та правим (`R`, drain). Резервуари перебувають у стані локальної термодинамічної рівноваги з хімічними потенціалами `μ_L` та `μ_R`, відповідно.

При прикладанні малої різниці потенціалів `ΔV` зсув хімічних потенціалів становить:

```
μ_L - μ_R = e · ΔV
```

Електрони в лівому резервуарі заповнюють енергетичні стани відповідно до розподілу Фермі — Дірака `f_L(E) = f(E - μ_L)`, а у правому — `f_R(E) = f(E - μ_R)`.

#### Густина станів та швидкість носіїв у 1D каналі

У кожному одновимірному квантовому каналі енергія носія задається дисперсійною кривою `E(k)`. Густина квантових станів для одного напрямку руху у просторі одновимірних хвильових векторів `k` (з урахуванням граничних умов Борна — Кармана на довжині `L_x`) дорівнює:

```
d N / d k = 1 / (2π)
```

Переходячи від простору хвильових векторів до енергетичного спектра за допомогою похідної `d E / d k = ℏ · v(E)` (де `v(E)` — групова швидкість електрона), одержуємо одновимірну густину квантових станів за енергією для одного напрямку руху:

```
d N / d E
= (d N / d k) · (d k / d E)                 [диференціювання за складною функцією E(k)]
= (1 / (2π)) · (1 / (ℏ · v(E)))             [підстановка значення d N / d k = 1 / 2π]
= 1 / (h · v(E))                            [використання зв'язку h = 2π · ℏ]
```

Звернемо увагу на фундаментальну математичну властивість одновимірного руху: густина квантових станів `d N / d E` є строго обернено пропорційною до групової швидкості носіїв `v(E)`. Що швидше рухається електрон уздовж каналу, то меншим є час його перебування в елементі довжини, і то менша кількість квантових станів припадає на одиничний інтервал енергії.

#### Розрахунок результуючого струму та квант провідності

Повний електричний струм `I`, що протікає крізь одновимірний канал, визначається різницею потоків електронів, що інжектуються лівим резервуаром і рухаються праворуч, та електронів, що інжектуються правим резервуаром і рухаються ліворуч:

```
I = e · ∫ [f_L(E) - f_R(E)] · v(E) · (d N / d E) · T(E) dE
```

де `T(E)` — ймовірність квантово-механічного проходження (коефіцієнт трансмісії) електрона крізь бар'єр або канал провідності на енергії `E`.

Підставляючи отриману одновимірну густину станів `d N / d E = 1 / (h · v(E))`, спостерігаємо точне скорочення групової швидкості носіїв `v(E)` у чисельнику та знаменнику підінтегрального виразу:

```
I
= e · ∫ [f_L(E) - f_R(E)] · v(E) · [ 1 / (h · v(E)) ] · T(E) dE   [підстановка d N / d E]
= (e / h) · ∫ [f_L(E) - f_R(E)] · T(E) dE                         [точне скорочення швидкості v(E)]
```

У граничному випадку низьких температур (`T → 0` К) різниця функцій розподілу Фермі — Дірака `[f_L(E) - f_R(E)]` перетворюється на прямокутне вікно одиничної висоти в інтервалі енергій `μ_R ≤ E ≤ μ_L` шириною `ΔE = μ_L - μ_R = e · ΔV`. Якщо коефіцієнт трансмісії `T(E)` слабко змінюється у цьому малому енергетичному вікні, інтегрування виконується аналітично:

```
I
= (e / h) · T · ∫_(μ_R)^(μ_L) dE              [винесення постійного коефіцієнта трансмісії T]
= (e / h) · T · (μ_L - μ_R)                   [інтегрування енергетичного вікна]
= (e / h) · T · (e · ΔV)                      [підстановка різниці потенціалів μ_L - μ_R = e · ΔV]
= (e² / h) · T · ΔV                           [алгебраїчне зведення множників]
```

Відношення результуючого струму до прикладеної напруги дає знамениту формулу Ландауера для провідності одного квантового каналу:

```
G = I / ΔV = (e² / h) · T
```

Якщо канал є повністю балістичним (відсутнє зворотне розсіювання), коефіцієнт проходження строго дорівнює одиниці `T = 1`. У цьому випадку провідність каналу набуває універсального значення — фундаментального кванта електричної провідності:

```
G_0 = e² / h ≈ 38.740691 мкСм
R_0 = 1 / G_0 = h / e² ≈ 25812.807459 Ом
```

#### Багатоканальний транспорт та матриця розсіювання

Якщо провідник має кінцеву ширину `W`, поперечне розмірне квантування породжує дискретний набір поперечних просторових мод (підзон квантування) із власними енергетичними відсічками `E_n`. Кількість відкритих поперечних мод `N_modes` на рівні Фермі `E_F` дорівнює числу підзон, для яких `E_n < E_F`.

Для опису багатоканального розсіювання використовують квантову матрицю розсіювання (`S`-матрицю), яка пов'язує комплексні амплітуди вхідних хвильових функцій `a = (a_1, ..., a_M)^T` та вихідних хвиль `b = (b_1, ..., b_M)^T`:

```
b = S · a
```

Матриця розсіювання складається з блоків відбиття `r, r'` та проходження `t, t'`:

```
S = [ [ r,   t' ],
      [ t,   r' ] ]
```

Фундаментальний закон збереження густини ймовірності (збереження потоку частинок) вимагає строгої унітарності `S`-матриці:

```
S† · S = S · S† = I
```

Розкриваючи матричний добуток унітарності для діагональних та позадіагональних блоків, отримуємо матричні співвідношення:

```
r† · r + t† · t = I
t · t† + r' · r'† = I
```

Повний коефіцієнт трансмісії багатоканального провідника визначається слідом матричного добутку блоків трансмісії:

```
T = Tr( t† · t ) = ∑_(n=1)^(N_R) ∑_(m=1)^(N_L) |t_nm|²
```

де `t_nm` — квантова амплітуда переходу з моди `m` лівого контакту в моду `n` правого контакту. Відповідно, повна багатоканальна формула Ландауера записується як:

```
G = (e² / h) · Tr( t† · t ) = (e² / h) · ∑_(n=1)^(N_modes) T_n
```

### 2. Багатополюсний формалізм Бюттікера, закони збереження та симетрії Онсагера

Маркус Бюттікер розширив підхід Ландауера на довільні складні планарні структури із довільною кількістю макроскопічних резервуарів (контактів), позначених індексами `p, q = 1, 2, ..., M`.

Кожен контакт `p` виступає ідеальним термодинамічним резервуаром електронів з власним хімічним потенціалом `μ_p` та електростатичним потенціалом `V_p = μ_p / e`.

#### Виведення багатополюсної формули струму

Розглянемо контакт `p`. Струм, що входить із резервуара `p` у мезоскопічний провідник, складається з двох компонентів:
1. Потік електронів, інжектованих резервуаром `p` за всіма його відкритими поперечними модами `N_p`. Повний інжектований струм дорівнює `(e / h) · N_p · μ_p`.
2. Частина цих електронів зазнає внутрішнього відбиття назад у контакт `p` із сумарною ймовірністю відбиття `R_p = T_pp`. Відбитий струм дорівнює `(e / h) · T_pp · μ_p`.
3. Потік електронів, що прибувають у контакт `p` з усіх інших контактів `q ≠ p`, де кожен контакт `q` інжектує носії з потенціалом `μ_q` із сумарною ймовірністю проходження `T_pq` у контакт `p`. Цей вхідний струм дорівнює `(e / h) · ∑_(q ≠ p) T_pq · μ_q`.

Результуючий струм `I_p`, що витікає з контакту `p` у систему (прийнято вважати додатним струм, спрямований від контакту в провідник), дорівнює різниці випроміненого та поглиненого потоків:

```
I_p = (e / h) · [ (N_p - T_pp) · μ_p - ∑_(q ≠ p) T_pq · μ_q ]
```

Завдяки унітарності повної `S`-матриці розсіювання сума ймовірностей переходу електрона, що вилетів із контакту `p`, в усі можливі кінцеві контакти (включаючи повернення в `p`) строго дорівнює повному числу мод `N_p`:

```
∑_q T_qp = T_pp + ∑_(q ≠ p) T_qp = N_p
```

Звідси виражаємо ефективну трансмісію виходу: `N_p - T_pp = ∑_(q ≠ p) T_qp`. Підставляючи цей вираз у рівняння для струму, одержуємо канонічну багатополюсну формулу Ландауера — Бюттікера:

```
I_p
= (e / h) · [ (∑_(q ≠ p) T_qp) · μ_p - ∑_(q ≠ p) T_pq · μ_q ]   [підстановка суми трансмісій N_p - T_pp]
= (e / h) · ∑_q [ T_qp · μ_p - T_pq · μ_q ]                   [об'єднання суми за всіма контактами q]
```

Переходячи від хімічних потенціалів `μ_p` до вимірюваних напруг `V_p = μ_p / e`, формулу записують через провідності:

```
I_p = (e² / h) · ∑_q [ T_qp · V_p - T_pq · V_q ]
```

де `T_pq` — сумарний коефіцієнт квантової трансмісії з контакту `q` у контакт `p`.

#### Закон збереження заряду та перший закон Кірхгофа

У стаціонарному стані електричний заряд усередині мезоскопічного зразка не накопичується. Отже, алгебраїчна сума всіх струмів, що протікають крізь контакти системи, повинна тотожно дорівнювати нулю.

Доведемо строге виконання першого закону Кірхгофа `∑_p I_p = 0` виходячи з унітарності матриці розсіювання:

```
∑_p I_p
= (e / h) · ∑_p ∑_q [ T_qp · μ_p - T_pq · μ_q ]               [підстановка формули Бюттікера]
= (e / h) · [ ∑_p μ_p · (∑_q T_qp) - ∑_q μ_q · (∑_p T_pq) ]   [перегрупування подвійних сум]
= (e / h) · [ ∑_p μ_p · N_p - ∑_q μ_q · N_q ]                 [використання унітарності ∑_q T_qp = N_p та ∑_p T_pq = N_q]
= (e / h) · [ ∑_p N_p · μ_p - ∑_p N_p · μ_p ]                 [перейменування німого індексу підсумовування q → p]
= 0                                                           [тотожне скорочення]
```

Це доведення показує, що збереження заряду в теорії Бюттікера є прямим математичним наслідком унітарності квантової `S`-матриці.

#### Калібрувальна інваріантність відносно зсуву потенціалу

Якщо потенціали абсолютно всіх контактів одночасно змістити на довільну постійну величину `Δμ = e · ΔV` (тобто здійснити калібрувальне перетворення `μ_p → μ_p + Δμ`), результуючі струми в системі не повинні змінитися, оскільки транспорт зумовлений виключно різницями потенціалів.

Перевіримо це аналітично:

```
I_p(μ + Δμ)
= (e / h) · ∑_q [ T_qp · (μ_p + Δμ) - T_pq · (μ_q + Δμ) ]     [підстановка зміщених потенціалів]
= (e / h) · ∑_q [ T_qp · μ_p - T_pq · μ_q ] + (e / h) · Δμ · ∑_q [ T_qp - T_pq ]  [розподільна властивість]
= I_p(μ) + (e / h) · Δμ · [ ∑_q T_qp - ∑_q T_pq ]             [винесення множника Δμ]
= I_p(μ) + (e / h) · Δμ · [ N_p - N_p ]                       [використання унітарності ∑_q T_qp = N_p та ∑_q T_pq = N_p]
= I_p(μ) + 0                                                  [скорочення N_p - N_p = 0]
= I_p(μ)                                                      [калібрувальна інваріантність доведена]
```

#### Співвідношення взаємності Онсагера — Казимира у магнітному полі

У наявності зовнішнього магнітного поля `B` мікроскопічна оборотність часу порушується. Проте одночасна зміна знака магнітного поля відновлює інваріантність рівняння Шредінгера. Для матриці розсіювання це приводить до співвідношення Онсагера — Казимира:

```
S_pq(B) = S_qp^T(-B)
```

Беручи слід від добутку амплітуд переходів, одержуємо фундаментальну симетрію коефіцієнтів трансмісії:

```
T_pq(B) = T_qp(-B)
```

Ймовірність переходу з контакту `q` у контакт `p` у магнітному полі `B` строго дорівнює ймовірності зворотного переходу з `p` у `q` при реверсі магнітного поля на `-B`.

Для чотириконтактних вимірювань опору `R_mn,kl(B)` (де струм `I` подається між контактами `m` та `n`, а напруга `V_k - V_l` вимірюється між контактами `k` та `l`) співвідношення Онсагера набуває вигляду:

```
R_mn,kl(B) = R_kl,mn(-B)
```

Звідси випливає парність поздовжнього опору `R_xx(B) = R_xx(-B)` та непарність поперечного опору Холла `R_xy(B) = -R_xy(-B)`.

### 3. Гамільтоніан 2DEG у магнітному полі та просторове розділення крайкових каналів

Розглянемо квантово-механічний гамільтоніан електрона в двовимірному електронному газі (площина `xy`) під дією перпендикулярного магнітного поля `B = (0, 0, B)` та обмежувального електростатичного потенціалу зразка `V(x)`:

```
H = (1 / 2m*) · [ p_x² + (p_y + e · B · x)² ] + V(x)
```

де застосовано калібрування Ландау для векторного потенціалу `A = (0, B · x, 0)`.

Оскільки гамільтоніан не містить явної залежності від координати `y`, оператор імпульсу `p_y` комутує з повним гамільтоніаном: `[H, p_y] = 0`. Отже, хвильова функція факторизується у добуток плоскої хвилі вздовж осі `y` та поперечної функції `χ(x)`:

```
Ψ(x, y) = exp(i · k_y · y) · χ(x)
```

Підставляючи власний розв'язок у рівняння Шредінгера `H · Ψ = E · Ψ`, отримуємо одновимірне рівняння квантового осцилятора для `χ(x)`:

```
[ -(ℏ² / 2m*) · (d² / dx²) + (1/2) · m* · ω_c² · (x - x_0)² + V(x) ] χ(x) = E · χ(x)
```

де `ω_c = e · B / m*` — циклотронна частота, а `x_0` — центр осциляторної хвильової функції (центр циклотронної орбіти), що однозначно фіксується квантовим числом `k_y`:

```
x_0 = - (ℏ · k_y) / (e · B) = - l_B² · k_y
```

де `l_B = √(ℏ / (e · B))` — магнітна довжина (квантовий радіус циклотронної орбіти на нульовому рівні Ландау).

#### Дисперсія та групова швидкість крайкових станів

У товщі (bulk) зразка, де обмежувальний потенціал є константним `V(x) = 0`, енергетичні рівні є виродженими за `k_y` рівнями Ландау:

```
E_n(k_y) = ℏ · ω_c · (n + 1/2) = const
```

Групова швидкість електронів у товщі зразка тотожно дорівнює нулю:

```
v_y = (1 / ℏ) · (d E_n / d k_y) = 0
```

Проте біля фізичних меж зразка (при `x → -W/2` на верхній/лівій межі та `x → +W/2` на нижній/правій межі) обмежувальний потенціал `V(x)` стрімко зростає. Ефективна потенційна енергія осцилятора зсувається вгору:

```
E_n(k_y) ≈ ℏ · ω_c · (n + 1/2) + V(x_0)
```

Обчислимо групову швидкість носія на межі зразка за допомогою ланцюгового правила диференціювання:

```
v_y
= (1 / ℏ) · (d E_n(k_y) / d k_y)              [визначення групової швидкості хвильового пакета]
= (1 / ℏ) · (d E_n / d x_0) · (d x_0 / d k_y)  [диференціювання складної функції x_0(k_y)]
= (1 / ℏ) · (d V / d x_0) · ( - l_B² )         [підстановка похідної d x_0 / d k_y = -l_B²]
= - (l_B² / ℏ) · (d V / d x_0)                 [зведення множників]
```

Знак групової швидкості строго визначається похідною обмежувального потенціалу:
- На лівій/верхній межі (`x_0 ≈ -W/2`) потенціал зростає назовні зразка (при зменшенні `x_0`), отже `d V / d x_0 < 0`. Відповідно, швидкість `v_y > 0` — усі електрони рухаються строго вперед (вправо).
- На правій/нижній межі (`x_0 ≈ +W/2`) потенціал зростає при збільшенні `x_0`, отже `d V / d x_0 > 0`. Відповідно, швидкість `v_y < 0` — усі електрони рухаються строго назад (вліво).

#### Експоненційне пригнічення зворотного розсіювання

У класичному одновимірному провіднику розсіювання на будь-якій домішці з потенціалом `U_imp(r)` перекидає електрон із стану `+k` у стан `-k`, створюючи кінцевий опір.

У квантовому ефекті Холла стани, що рухаються праворуч (`+k_y`), локалізовані на верхній межі зразка (`x ≈ -W/2`), тоді як стани, що рухаються ліворуч (`-k_y`), просторово локалізовані на протилежній нижній межі зразка (`x ≈ +W/2`). Матричний елемент квантового розсіювання між зустрічними крайковими каналами пропорційний перекриттю їхніх осциляторних хвильових функцій:

```
|⟨Ψ_left | U_imp | Ψ_right⟩| ∝ exp( - (x_0,left - x_0,right)² / (4 · l_B²) ) ≈ exp( - W² / (4 · l_B²) )
```

Оскільки ширина зразка `W ≈ 100` мкм на багато порядків перевищує магнітну довжину `l_B ≈ 10` нм, фактор перекриття становить:

```
exp( - (10⁻⁴ м)² / (4 · (10⁻⁸ м)²) ) = exp( - 10⁸ / 4 ) = exp( - 2.5 · 10⁷ ) ≈ 0
```

Імовірність зворотного розсіювання стає астрономічно малим нулем. Електрон не здатний змінити напрямок руху, навіть зазнаючи пружних зіткнень із дефектами: хвильовий пакет просто плавно огинає будь-які локальні домішки вздовж ізопотенціальної лінії межі.

### 4. Точний матричний розрахунок для 6-контактного містка Холла

Розглянемо стандартну шестиконтактну геометрію містка Холла (Hall bar), у якому заповнено `N` рівнів Ландау (тобто вздовж меж зразка циркулює `N` хіральних крайових каналів).

```
                      Контакт 2            Контакт 3
                         │                    │
                         ▼                    ▼
                ┌────────┴────────────────────┴────────┐
 Контакт 1 ───► │  ═══════ Крайові канали ══════►      │ ───► Контакт 4
 (+I_in)        │                                      │      (-I_out)
                │  ◄══════ Крайові канали ══════       │
                └────────┬────────────────────┬────────┘
                         ▲                    ▲
                         │                    │
                      Контакт 6            Контакт 5
```

Контакти розподілені у просторі наступним чином:
- Контакт 1: струмовий інжектор (джерело), струм `I_1 = +I`;
- Контакт 4: струмовий стік (земля), струм `I_4 = -I`;
- Контакти 2 та 3: потенціальні зонди на верхній межі зразка;
- Контакти 5 та 6: потенціальні зонди на нижній межі зразка.

Потенціальні зонди підключені до ідеальних електрометрів з нескінченним вхідним опором, тому струми через них не протікають:

```
I_2 = I_3 = I_5 = I_6 = 0
```

#### Матриця трансмісії 6-полюсника

У сильному магнітному полі при повній відсутності зворотного розсіювання всі `N` каналів рухаються строго за годинниковою стрілкою (або проти, залежно від орієнтації поля `B`). Для орієнтації, показаної на схемі:
- З контакту 1 усі електрони потрапляють у контакт 2: `T_21 = N`;
- З контакту 2 усі електрони потрапляють у контакт 3: `T_32 = N`;
- З контакту 3 усі електрони потрапляють у контакт 4: `T_43 = N`;
- З контакту 4 усі електрони потрапляють у контакт 5: `T_54 = N`;
- З контакту 5 усі електрони потрапляють у контакт 6: `T_65 = N`;
- З контакту 6 усі електрони потрапляють у контакт 1: `T_16 = N`.

Усі інші несусідні та зворотні коефіцієнти трансмісії тотожно дорівнюють нулю: `T_pq = 0` для всіх інших пар. Кількість вихідних мод у кожному контакті дорівнює `N_p = N`.

Матриця коефіцієнтів трансмісії `T` розмірністю `6 × 6` має строгий циклічний вигляд:

```
T = [ [ 0,  0,  0,  0,  0,  N ],
      [ N,  0,  0,  0,  0,  0 ],
      [ 0,  N,  0,  0,  0,  0 ],
      [ 0,  0,  N,  0,  0,  0 ],
      [ 0,  0,  0,  N,  0,  0 ],
      [ 0,  0,  0,  0,  N,  0 ] ]
```

#### Система лінійних рівнянь Бюттікера

Запишемо загальну систему рівнянь Бюттікера `I_p = (e / h) · [ N_p · μ_p - ∑_q T_pq · μ_q ]` для всіх шести контактів:

```
I_1 = (e / h) · [ N · μ_1 - N · μ_6 ]
I_2 = (e / h) · [ N · μ_2 - N · μ_1 ]
I_3 = (e / h) · [ N · μ_3 - N · μ_2 ]
I_4 = (e / h) · [ N · μ_4 - N · μ_3 ]
I_5 = (e / h) · [ N · μ_5 - N · μ_4 ]
I_6 = (e / h) · [ N · μ_6 - N · μ_5 ]
```

#### Покрокове аналітичне розв'язання для потенціалів

Розв'яжемо систему, використовуючи граничні умови для потенціальних зондів `I_2 = I_3 = I_5 = I_6 = 0`:

1. **Рівняння для контакту 2**:
```
I_2 = (e / h) · N · (μ_2 - μ_1) = 0
⇒  μ_2 = μ_1
```

2. **Рівняння для контакту 3**:
```
I_3 = (e / h) · N · (μ_3 - μ_2) = 0
⇒  μ_3 = μ_2 = μ_1
```

3. **Рівняння для контакту 5**:
```
I_5 = (e / h) · N · (μ_5 - μ_4) = 0
⇒  μ_5 = μ_4
```

4. **Рівняння для контакту 6**:
```
I_6 = (e / h) · N · (μ_6 - μ_5) = 0
⇒  μ_6 = μ_5 = μ_4
```

Ми отримали фундаментальний розподіл хімічних потенціалів: усі контакти на верхній грані зразка набувають хімічного потенціалу інжектора 1 (`μ_2 = μ_3 = μ_1`), а всі контакти на нижній грані набувають хімічного потенціалу стоку 4 (`μ_5 = μ_6 = μ_4`).

Тепер підставимо значення `μ_6 = μ_4` у рівняння для повного струму інжектора `I_1 = I`:

```
I = I_1
= (e / h) · N · (μ_1 - μ_6)                   [рівняння Бюттікера для контакту 1]
= (e / h) · N · (μ_1 - μ_4)                   [підстановка знайденого потенціалу μ_6 = μ_4]
```

Звідси зв'язок між повним струмом `I` та різницею хімічних потенціалів інжектора і стоку становить:

```
μ_1 - μ_4 = [ h / (N · e) ] · I
V_1 - V_4 = (μ_1 - μ_4) / e = [ h / (N · e²) ] · I
```

#### Аналітичне виведення нульового поздовжнього опору R_xx

Поздовжня напруга `V_xx` вимірюється між двома сусідніми потенціальними зондами на **одному й тому самому** боці зразка:

На верхній межі (між контактами 2 та 3):
```
V_xx,top = V_2 - V_3 = (μ_2 - μ_3) / e
```

Підставляючи отримані значення `μ_2 = μ_1` та `μ_3 = μ_1`:

```
V_xx,top
= (μ_1 - μ_1) / e                             [підстановка рівних потенціалів μ_2 = μ_3 = μ_1]
= 0
```

Відповідно, поздовжній опір зразка:

```
R_xx,top = V_xx,top / I = 0 / I = 0
```

Аналогічно, на нижній межі (між контактами 6 та 5):

```
V_xx,bottom = V_6 - V_5 = (μ_4 - μ_4) / e = 0
R_xx,bottom = V_xx,bottom / I = 0
```

Поздовжній опір зразка тотожно дорівнює нулю. Електрони вздовж краю рухаються балістично без падіння напруги між контактами на одній межі.

#### Аналітичне виведення квантованого опору Холла R_xy

Поперечна напруга Холла `V_xy` вимірюється між потенціальними зондами на **протилежних** краях зразка (наприклад, між контактами 2 та 6, або контактами 3 та 5):

```
V_xy = V_2 - V_6 = (μ_2 - μ_6) / e
```

Підставляючи `μ_2 = μ_1` та `μ_6 = μ_4`:

```
V_xy
= (μ_1 - μ_4) / e                             [підстановка потенціалів країв]
= (1 / e) · [ (h / (N · e)) · I ]             [підстановка виразу для μ_1 - μ_4 через струм I]
= [ h / (N · e²) ] · I                        [алгебраїчне спрощення]
```

Знаходимо опір Холла `R_xy` як відношення поперечної напруги до струму:

```
R_xy
= V_xy / I                                    [визначення опору Холла]
= ( [ h / (N · e²) ] · I ) / I                [підстановка виразу для V_xy]
= h / (N · e²)                                [скорочення повного струму I]
```

Це доводить, що квантування опору Холла на строгому плато `R_xy = h / (N · e²)` та зникання дисипативного опору `R_xx = 0` є строгим математичним наслідком унітарності та хіральності крайового транспорту у формалізмі Бюттікера.

#### Двоточковий та чотириточковий опір: роль контактного опору

Зауважимо важливу фізико-математичну різницю між двоточковим та чотириточковим опором:

Якщо вимірювати напругу безпосередньо між струмовими контактами 1 та 4 (двоточковий опір):
```
R_2wire = (V_1 - V_4) / I = h / (N · e²)
```

Двоточковий опір ніколи не дорівнює нулю, навіть за відсутності розсіювання у зразку! Він містить квантовий контактний опір інжекції носіїв із тривимірного резервуара в одновимірні крайкові канали.

У чотириточковому вимірюванні струмові контакти відокремлені від потенціальних. Оскільки через потенціальні контакти 2 і 3 струм не тече, на їхніх границях немає падіння напруги, що й дозволяє виміряти справжній нульовий внутрішній опір каналу `R_xx = 0`.

### 5. Розрахунок впливу неідеальних контактів, зворотного розсіювання та звужень (QPC)

У реальних експериментальних структурах можуть виникати відхилення від ідеальної моделі: скінченний опір омічних контактів, тунелювання між краями у звуженнях або термічна активація. Формалізм Бюттікера дозволяє розрахувати ці ефекти з абсолютною точністю.

#### Неідеальні потенціальні контакти без міжкрайкового перекриття

Припустимо, що потенціальний контакт 2 є неідеальним: він частково відбиває вхідні електрони назад у канал або має внутрішній коефіцієнт відбиття `R_2 > 0`. Нехай ефективна трансмісія з каналу в зонд дорівнює `T_c < N`.

Оскільки зонд 2 розташований виключно на верхній межі зразка і не має контакту з нижньою гранню, усі електрони, які не поглинулися зондом, продовжують рух у бік контакту 3.

Запишемо рівняння струму для зонда 2:

```
I_2 = (e / h) · [ (N - R_2) · μ_2 - T_21 · μ_1 ] = 0
```

За законом збереження частинок `N - R_2 = T_21`. Отже:

```
T_21 · μ_2 = T_21 · μ_1
⇒  μ_2 = μ_1
```

Потенціал зонда `μ_2` залишається строго рівним `μ_1`, незалежно від величини контакту `T_c`! Це доводить надзвичайну стійкість квантування плато Холла: доки зонди контактують лише з однією межею зразка, неідеальність контактів не здатна змінити вимірювані значення `R_xy` та `R_xx`.

#### Зворотне розсіювання у звуженні (Quantum Point Contact, QPC)

Розглянемо випадок, коли між верхньою та нижньою межами зразка штучно створено звуження за допомогою електростатичних затворів — квантовий точковий контакт (QPC).

```
                      Контакт 2            Контакт 3
                         │                    │
                         ▼                    ▼
                ┌────────┴───────┐    ┌───────┴────────┐
 Контакт 1 ───► │  ════════════► │\  /│ ════════════►  │ ───► Контакт 4
 (+I_in)        │                │ )( │ QPC            │      (-I_out)
                │  ◄════════════ │/  \│ ◄════════════  │
                └────────┬───────┘    └───────┬────────┘
                         ▲                    ▲
                         │                    │
                      Контакт 6            Контакт 5
```

У звуженні верхня і нижня межі зближуються до відстаней порядку кількох десятків нанометрів, що дозволяє електронам квантово тунелювати з верхнього краю на нижній.

Нехай повна кількість мод у широкій частині зразка дорівнює `N`, а через QPC вільно проходить лише `T_qpc` мод (`T_qpc < N`). Частина каналів `R_qpc = N - T_qpc` зазнає зворотного відбиття (тунелює на протилежну межу).

Матриця трансмісії модифікується:
- З контакту 1 на контакт 2: `T_21 = N`;
- З контакту 2 на контакт 3 (крізь QPC): `T_32 = T_qpc`;
- З контакту 2 на контакт 6 (тунелювання через QPC на нижній край): `T_62 = R_qpc = N - T_qpc`;
- З контакту 4 на контакт 5: `T_54 = N`;
- З контакту 5 на контакт 6 (крізь QPC): `T_65 = T_qpc`;
- З контакту 5 на контакт 3 (тунелювання через QPC на верхній край): `T_35 = R_qpc = N - T_qpc`;
- З контакту 6 на контакт 1: `T_16 = N`;
- З контакту 3 на контакт 4: `T_43 = N`.

Складемо систему рівнянь Бюттікера для зондів 2, 3, 5, 6 при нульових струмах `I_2 = I_3 = I_5 = I_6 = 0` та заземленому стоці `μ_4 = 0`:

1. Для контакту 2:
```
I_2 = (e / h) · [ N · μ_2 - N · μ_1 ] = 0
⇒  μ_2 = μ_1
```

2. Для контакту 5:
```
I_5 = (e / h) · [ N · μ_5 - N · μ_4 ] = 0
⇒  μ_5 = μ_4 = 0
```

3. Для контакту 3 (розташованого після QPC на верхньому краї):
```
I_3 = (e / h) · [ N · μ_3 - T_32 · μ_2 - T_35 · μ_5 ] = 0
N · μ_3 = T_qpc · μ_1 + R_qpc · μ_4
```

Оскільки `μ_4 = 0`:
```
μ_3 = (T_qpc / N) · μ_1
```

4. Для контакту 6 (розташованого після QPC на нижньому краї):
```
I_6 = (e / h) · [ N · μ_6 - T_65 · μ_5 - T_62 · μ_2 ] = 0
N · μ_6 = T_qpc · μ_4 + R_qpc · μ_1
```

Оскільки `μ_4 = 0`:
```
μ_6 = (R_qpc / N) · μ_1 = [ (N - T_qpc) / N ] · μ_1
```

5. Знайдемо повний струм інжектора `I_1 = I`:
```
I = I_1
= (e / h) · [ N · μ_1 - N · μ_6 ]             [рівняння струму на контакті 1]
= (e / h) · [ N · μ_1 - (N - T_qpc) · μ_1 ]   [підстановка знайденого значення μ_6]
= (e / h) · T_qpc · μ_1                       [спрощення різниці]
```

Звідси виражаємо потенціал джерела `μ_1`:
```
μ_1 = [ h / (e · T_qpc) ] · I
```

#### Розрахунок залишкового поздовжнього опору R_xx при наявності QPC

Обчислимо поздовжнє падіння напруги `V_2 - V_3` поперек звуження на верхньому краї:

```
V_xx = V_2 - V_3 = (μ_2 - μ_3) / e
```

Підставляючи вирази для `μ_2 = μ_1` та `μ_3 = (T_qpc / N) · μ_1`:

```
V_xx
= (1 / e) · [ μ_1 - (T_qpc / N) · μ_1 ]        [підстановка потенціалів зондів]
= (1 / e) · [ (N - T_qpc) / N ] · μ_1         [винесення множника μ_1]
= (1 / e) · [ (N - T_qpc) / N ] · [ (h / (e · T_qpc)) · I ]  [підстановка виразу для μ_1 через струм I]
= (h / e²) · [ (N - T_qpc) / (N · T_qpc) ] · I  [зведення алгебраїчних множників]
```

Звідси отримуємо аналітичний вираз для поздовжнього опору `R_xx`:

```
R_xx = V_xx / I = (h / e²) · [ (N - T_qpc) / (N · T_qpc) ] = (h / e²) · [ R_qpc / (N · T_qpc) ]
```

Аналіз отриманого результату:
- Якщо звуження відсутнє (`T_qpc = N`, `R_qpc = 0`), поздовжній опір строго зникає `R_xx = 0`.
- Якщо хоча б один канал зазнає часткового відбиття (`R_qpc > 0`), поздовжній опір стає строго додатним `R_xx > 0`.
- Якщо QPC повністю закриває один канал (`T_qpc = N - 1`), поздовжній опір виходить на локальний максимум.

#### Розрахунок поперечного опору Холла R_xy біля QPC

Обчислимо поперечну напругу Холла до звуження (між контактами 2 та 6):

```
V_xy,upstream = V_2 - V_6 = (μ_2 - μ_6) / e
```

Підставляючи `μ_2 = μ_1` та `μ_6 = [ (N - T_qpc) / N ] · μ_1`:

```
V_xy,upstream
= (1 / e) · [ μ_1 - (1 - T_qpc / N) · μ_1 ]   [підстановка значень]
= (1 / e) · (T_qpc / N) · μ_1                 [спрощення різниці]
= (1 / e) · (T_qpc / N) · [ (h / (e · T_qpc)) · I ]  [підстановка виразу для μ_1]
= [ h / (N · e²) ] · I                        [скорочення T_qpc]
```

Опір Холла перед звуженням залишається ідеально квантованим:

```
R_xy,upstream = V_xy,upstream / I = h / (N · e²)
```

Проте діагональний опір між контактом 2 та контактом 5 (через саме звуження) безпосередньо міряє пропускну здатність звуження:

```
R_diagonal = (V_2 - V_5) / I = (μ_1 - 0) / (e · I) = h / (T_qpc · e²)
```

Цей розрахунок лежить в основі роботи інтерферометрів Фабрі — Перо та Маха — Цендера на крайових каналах у напівпровідникових гетероструктурах.

### 6. Топологічне обґрунтування: аргумент Лафліна, інваріант TKNN та числа Черна

Щоб зрозуміти, чому число крайових каналів `N` є абсолютно стійким цілим числом, звернемося до двох фундаментальних топологічних доведень: калібрувального уявного експерименту Лафліна та квантової теорії лінійного відгуку Кубо — TKNN.

#### Калібрувальний експеримент Лафліна на циліндрі Корбіно

Роберт Лафлін запропонував розглянути квантову систему у формі замкненого кільця або порожнистого циліндра Корбіно радіусом `R` та шириною `W`.

```
                    ┌────────────────────────┐
   Внутрішній край  │ ════════════════════►  │  Крайовий струм
   (Потенціал V_in) │   Двовимірний газ     │
                    │   у магнітному полі B  │
   Зовнішній край   │ ◄════════════════════  │  Крайовий струм
   (Потенціал V_out)└────────────────────────┘
                              │ │
                              │ │ Адіабатичний магнітний
                              ▼ ▼ потік Φ(t) крізь отвір
```

Крізь вісь циліндра пропускається адіабатично наростаючий магнітний потік `Φ(t)`. При зміні потоку вздовж кола циліндра генерується вихрове електричне поле індукції Фарадея `E_θ = - (1 / (2π R)) · (d Φ / d t)`.

Згідно з квантовою механікою, при зміні потоку на один фундаментальний квант магнітного потоку:

```
ΔΦ = Φ_0 = h / e
```

векторний потенціал змінюється на величину `ΔA_θ = Φ_0 / (2π R) = ℏ / (e · R)`. Хвильові функції електронів набувають додаткової фази `exp(i · e · ∮ A d r / ℏ) = exp(i · 2π) = 1`.

Отже, гамільтоніан системи після додавання одного кванта потоку є унітарно еквівалентним початковому гамільтоніану. Проте центри циклотронних орбіт зміщуються у радіальному напрямку на одну міжорбітальну відстань `Δx_0 = - l_B² · Δk_y = - l_B² · (2π / L_y)`.

У результаті цього процесу (спектрального потоку, *spectral flow*) рівно `N` електронів переносяться з внутрішнього краю циліндра на його зовнішній край.

Робота `ΔW`, виконана вихровим електричним полем над перенесеними зарядами, дорівнює зміні електростатичної енергії:

```
ΔW = N · e · (V_out - V_in) = N · e · V_H
```

З іншого боку, робота джерела ЕРС виражається через струм Холла `I_H`:

```
ΔW = ∫ I_H · (d Φ / d t) dt = I_H · ΔΦ = I_H · (h / e)
```

Прирівнюючи два вирази для виконаної роботи:

```
I_H · (h / e) = N · e · V_H
⇒  I_H = N · (e² / h) · V_H
```

Звідси провідність Холла циліндра дорівнює:

```
G_xy = I_H / V_H = N · (e² / h)
```

Цей калібрувальний аргумент показує, що квантування провідності Холла є прямим наслідком збереження калібрувальної інваріантності хвильової функції при додаванні кванта потоку `h / e`.

#### Топологічне виведення інваріанта TKNN та чисел Черна

Для доведення незалежності квантування від форми потенціалу кристалічної ґратки розпишемо топологічне виведення Таулесса, Комото, Найтінгела та ден Найса (інваріант TKNN).

За формулою Кубо, компонента тензора провідності `σ_xy` для системи електронів у періодичному потенціалі описується квантовим лінійним відгуком:

```
σ_xy = (i · ℏ · e² / A) · ∑_(E_n < E_F) ∑_(E_m > E_F) [ (v_x)_nm · (v_y)_mn - (v_y)_nm · (v_x)_mn ] / (E_m - E_n)²
```

де `|n⟩` та `|m⟩` — зайняті та вільні блохівські стани з енергіями `E_n` та `E_m`, а `A` — площа системи.

Переходячи від операторів швидкості `v = (1 / ℏ) · ∇_k H(k)` до періодичних частин блохівських функцій `|u_n(k)⟩`, цей вираз згортається в інтеграл по двовимірній зоні Бріллюена:

```
σ_xy = (e² / h) · (1 / 2π) · ∑_n ∬_BZ [ ∇_k × A_n(k) ]_z d²k
```

де `A_n(k)` — **векторний потенціал Беррі** (Berry connection) у просторі хвильових векторів:

```
A_n(k) = i · ⟨u_n(k) | ∇_k u_n(k)⟩
```

Ротор векторного потенціалу Беррі називається **кривиною Беррі** (*Berry curvature*):

```
Ω_n(k) = ∇_k × A_n(k)
```

Згідно з топологічною теоремою Черна, інтеграл від кривини Беррі по замкненому двовимірному тору (зоні Бріллюена `T²`) є строго квантованим цілим числом — першим топологічним **числом Черна**:

```
C_n = (1 / 2π) · ∬_BZ Ω_n(k) d²k  ∈  ℤ
```

Сумуючи внески від усіх `N` повністю заповнених підзон Ландау, отримуємо точне квантування макроскопічної провідності Холла:

```
σ_xy = (e² / h) · ∑_(n=1)^N C_n = N · (e² / h)
```

#### Відповідність об'єму та межі (Bulk-Boundary Correspondence)

Топологічний інваріант Черна `C = ∑ C_n = N`, розрахований для нескінченного періодичного об'єму (bulk), строго фіксує кількість незникаючих хіральних крайових каналів `N`, що перетинають рівень Фермі на фізичній межі зразка.

Будь-які локальні збурення, деформації кристалічної ґратки або домішки можуть змінювати вигляд хвильових функцій, але вони не здатні змінити топологічний інваріант `C_n`, доки енергетична щілина між рівнями Ландау залишається відкритою. Це завершує математичний доказ абсолютної стійкості квантового ефекту Холла: топологічний інваріант у товщі зразка гарантує існування цілої кількості `N` балістичних хіральних мод, а формалізм Ландауера — Бюттікера забезпечує бездисипативний транспорт `R_xx = 0` та квантований опір Холла `R_xy = h / (N · e²)`.
