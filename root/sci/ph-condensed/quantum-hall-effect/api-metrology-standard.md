# 📋 Метрологічний специфікат та квантовий еталон електричного опору

Цей довідковий специфікат описує метрологічні вимоги, вимірювальні процедури, алгоритми калібрування та апаратні параметри первинного квантового еталона електричного опору, що базується на цілочисельному квантовому ефекті Холла (QHE). Специфікацію розроблено відповідно до офіційних рекомендацій Міжнародного бюро мір та ваг (BIPM / Recommendation INC-1) та міжнародних метрологічних стандартів IEEE 2888 та ISO/IEC Guide 98-3 (GUM).

### 1. Фундаментальні константи та еталонні квантові значення

Згідно з реформою Міжнародної системи одиниць SI, що набула чинності 20 травня 2019 року, значення сталої Планка `h` та елементарного електричного заряду `e` є точно зафіксованими фундаментальними фізичними константами. Унаслідок цього константа фон Клітцинга `R_K = h / e²` більше не містить експериментальної похибки перевизначення і є фундаментальною константою з точним математичним значенням.

| Фізична величина / Параметр | Позначення | Точне значення у системі SI | Одиниця вимірювання |
| :--- | :--- | :--- | :--- |
| **Константа фон Клітцинга** | `R_K` | `25812.8074593045...` | Ом (Ом = В / А) |
| **Квант опору Холла (i = 1)** | `R_H(1)` | `25812.8074593045...` | Ом |
| **Основний робочий квант (i = 2)** | `R_H(2)` | `12906.4037296522...` | Ом |
| **Квант опору Холла (i = 4)** | `R_H(4)` | `6453.2018648261...` | Ом |
| **Елементарний заряд** | `e` | `1.602176634 × 10⁻¹⁹` | Кулон (Кл) |
| **Стала Планка** | `h` | `6.62607015 × 10⁻³⁴` | Джоуль-секунда (Дж·с) |
| **Зведена стала Планка** | `ℏ = h / (2π)` | `1.054571817... × 10⁻³⁴` | Дж·с |

Використання плато `i = 2` із точним значенням опору `12906.4037296522...` Ом є міжнародним метрологічним стандартом за замовчуванням, оскільки це плато має найбільшу енергетичну щілину між першим та другим рівнями Ландау у типових гетероструктурах, забезпечуючи максимальну стійкість до температурного розігріву електронів.

### 2. Специфікація та матеріалознавчі вимоги до квантово-холлівських зразків

Первинний еталон опору вимагає спеціально вирощених напівпровідникових або двовимірних кристалічних гетероструктур, у яких двовимірний електронний газ (2DEG) має екстремально високу рухливість носіїв `μ` та низьку концентрацію дефектів.

#### Матеріальні системи: GaAs/AlGaAs проти епітаксійного Графену

Історично основними матеріалами для метрологічних еталонів є гетероструктури арсеніду галію та арсеніду галію-алюмінію (`GaAs / AlGaAs`), вирощені методом молекулярно-променевої епітаксії (MBE). Проте розвиток технологій синтезу епітаксійного графену на карбіді кремнію (`SiC`) створив нову генерацію квантових еталонів, здатних працювати при помітно вищих температурах та в слабших магнітних полях.

| Характеристика зразка | Гетероструктура GaAs / AlGaAs | Епітаксійний Графен (на 4H-SiC) |
| :--- | :--- | :--- |
| **Типовий робочий стан** | Плато `i = 2` (`12906.40` Ом) | Плато `i = 2` (`12906.40` Ом) |
| **Поверхнева густина носіїв `n_s`** | `(3.0 ... 5.0) × 10¹⁵` м⁻² | `(1.0 ... 2.0) × 10¹6` м⁻² |
| **Рухливість носіїв `μ` при 4.2 K** | `50 ... 100` м² / (В·с) | `3 ... 8` м² / (В·с) |
| **Робоча температура `T_work`** | `< 1.2` К (оптимально `0.3` К) | `< 4.2` К (можливо при `1.5...4.2` К) |
| **Робоче магнітне поле `B_work`** | `9.0 ... 14.0` Тесла | `3.0 ... 8.0` Тесла |
| **Критичний струм зразка `I_crit`** | `20 ... 60` мкА | `100 ... 500` мкА |
| **Геометричні розміри каналу** | Довжина `2.0` мм, ширина `0.4` мм | Довжина `1.0` мм, ширина `0.2` мм |

#### Технологічні вимоги до виготовлення зразка

1. **Епітаксійний ріст та легування**: У гетероструктурах `GaAs/AlGaAs` область допування сіркою або кремнієм відсувається від двовимірного каналу на відстань `20...80` нанометрів за допомогою незарядженого спейсерного шару `AlGaAs`. Це суттєво зменшує кулонівське розсіювання носіїв на іонізованих домішках і піднімає рухливість `μ` до рекордних значень.
2. **Омічні контакти**: Створення надійних омічних контактів із низьким перехідним опором є найкритичнішим етапом. Контакти формуються шляхом послідовного термічного або електронно-променевого напилення шарів нікелю, германію та золота (`Ni / Ge / Au`) з наступним високотемпературним впалюванням при `450 °C` у відновному середовищі. Перехідний опір кожного окремого контакту при температурі `1.2` К не повинен перевищувати `1.0` Ом. Контакти з опором понад `10` Ом викликають локальне випромінювання гарячих електронів під дією струму, що призводить до розігріву каналу та руйнування квантового плато.
3. **Пасивація поверхні**: Поверхня зразка покривається тонким діелектричним шаром нітриду кремнію (`Si₃N₄`) або оксиду алюмінію (`Al₂O₃`) методом атомарно-шарового осадження (ALD) для захисту від випаровування вологи, адсорбції газів та деградації контактів.

### 3. Специфікація геометричної топології та електричного розведення

Вимірювальний зразок виготовляється у формі класичного фотолітографічного містка Холла (Hall bar) або у вигляді кільця Корбіно. Для метрологічних цілей найвищої точності застосовується 8-контактна геометрія з подвійними потенціальними виводами на кожному краї.

#### Топологічна схема 8-контактного метрологічного містка Холла

```
                      V_xx1 (Верхня поздовжня напруга)
                   ┌──────────────────────────────┐
                   │                              │
               [2] ┴                          [3] ┴
┌──────────────────┴──────────────────────────────┴──────────────────┐
│ (1) +I_in                                              (4) -I_out  │  2DEG Channel
└──────────────────┬──────────────────────────────┬──────────────────┘
               [6] ┬                          [5] ┬
                   │                              │
                   └──────────────────────────────┘
                      V_xx2 (Нижня поздовжня напруга)
```

Поперечна напруга Холла `V_xy` знімається між діагонально або протилежно розташованими контактами (наприклад, між контактом 2 та контактом 6, або контактом 3 та контактом 5).

#### Схема трикратно-послідовного підключення (Triple-Series Connection)

Для виключення впливу паразитного опору контактних підводів та провідників потенціальних щупів у сучасних квантових еталонах застосовують схему підключення за методом Бюттікера-Клітцинга (Triple-Series Connection). При цій схемі кожен потенціальний контакт розділяється на кілька паралельних струмових та потенціальних ліній, з'єднаних зовнішніми надпровідними містками. Це дозволяє експоненціально пригнічувати похибку від скінченного опору контактів, зменшуючи її відносну величину з `10⁻⁵` до рівнів нижче `10⁻¹⁰`.

### 4. Кріогенне та магнітне інженерне забезпечення

Дотримання умов квантування вимагає підтримки наднизьких температур та надсильних однорідних магнітних полів протягом багатьох годин вимірювальних сесій.

#### Комплекс кріогенного охолодження

1. **Безрідинні або відкачувані кріостати**: Для гетероструктур `GaAs` використовуються кріостати розчинення `³He / ⁴He` або відкачувані кріостати на основі ізотопу гелію-3 (`³He sorption cryostats`), які забезпечують стабільну базову температуру від `0.3` К до `1.2` К.
2. **Температурна стабільність**: Автоматизована система термостабілізації повинна утримувати температуру блоку зразка із точністю не гірше `± 0.005` К протягом усієї серії вимірювань.
3. **Вібраційна ізоляція**: Кріостат оснащується пневматичною системою гасіння вібрацій від форвакуумних та турбомолекулярних насосів, оскільки механічні мікровібрації зразка у магнітному полі викликають індуковані змінні ЕРС, що викривляють постійний напруговий відлік.

#### Надпровідна магнітна система

1. **Надпровідний соленоїд**: Магнітне поле створюється соленоїдом із нитки `NbTi` або `Nb₃Sn`, зануреним у рідкий гелій-4 при `4.2` К. Соленоїд створює поле від `8` до `14` Тесла.
2. **Просторова однорідність**: Просторове відхилення індукції магнітного поля у зоні розташування напівпровідникового чипа розміром `3 × 3` мм не повинно перевищувати `0.01%` (`100 ppm`).
3. **Замкнений надпровідний режим (Persistent Current Mode)**: Після виходу на необхідне значення індукції соленоїд закорочується надпровідним ключем. Це забезпечує часову стабільність магнітного поля з дрейфом менше `10⁻⁷` на годину.

### 5. Метрологічний вимірювальний місток: Кріогенний компаратор струму (CCC)

Для передачі значення квантованого опору `R_H(2) ≈ 12906.40` Ом до стандартних десятичних еталонів опору (`100` Ом, `1000` Ом, `10000` Ом) звичайні дільники напруги чи класичні містки Уітстона є непридатними через власний шум та термічний дрейф.

Основним інструментом вищої точності в усіх провідних національних метрологічних інститутах (PTB, NIST, BIPM, NPL) є **Кріогенний компаратор струму** (*Cryogenic Current Comparator*, CCC), підключений до надпровідного квантового магнітометра (СКВІД, SQUID).

#### Фізичний принцип дії компаратора CCC

Компаратор складається з тороїдального надпровідного екрана з чистого ніобію, усередині якого прокладено кілька незалежних обмоток із точним числом витків `N_1, N_2, N_3...`.

```
        Кріогенний компаратор струму (CCC)
        ┌───────────────────────────────────┐
        │   Надпровідний ніобієвий екран    │
        │   ┌───────────────────────────┐   │
  I_1 ──┼──►│  Обмотка 1: N_1 витків    │───┼──► До зразка QHE (R_H)
        │   └───────────────────────────┘   │
        │   ┌───────────────────────────┐   │
  I_2 ──┼──►│  Обмотка 2: N_2 витків    │───┼──► До еталона R_std (100 Ом)
        │   └───────────────────────────┘   │
        └─────────────────┬─────────────────┘
                          │ Сверхпровідна петля звязку
                          ▼
                  [ SQUID Магнітометр ] ──► Нуль-індикатор
```

Якщо крізь обмотку 1 пропустити струм `I_1`, а крізь обмотку 2 — струм `I_2` у протилежному напрямку, за законом Повної обмотки поверхневий надпровідний струм на зовнішній стороні екрана буде строго пропорційним різниці ампер-витків:

```
I_net = N_1 · I_1 - N_2 · I_2
```

Цей надпровідний струм створює магнітний потік у котушці зв'язку, який вимірюється високочутливим SQUID-магнітометром. Сигнал із SQUID подається у зворотний зв'язок джерела струму, підтримуючи умову балансу ампер-витків із екстремальною точністю:

```
N_1 · I_1 = N_2 · I_2  ⇒  I_1 / I_2 = N_2 / N_1
```

Оскільки відношення струмів підтримується автокомпенсатором точно дорівнює відношенню чисел витків `N_2 / N_1` (які є строго цілими числами, визначеними при намотуванні), відношення вимірюваних опорів обчислюється як:

```
R_x / R_std = (V_x / I_1) / (V_std / I_2) = (I_2 / I_1) = (N_1 / N_2)
```

Похибка коефіцієнта трансформації струму у кріогенному компараторі CCC завдяки мейсснеровському екрануванню ніобію становить менше `10⁻¹¹`.

### 6. Бюджет невизначеності вимірювання (Uncertainty Budget)

Відповідно до керівництва ISO/IEC Guide 98-3 (GUM), під час зіставлення робочого еталона опору `100` Ом із плато `i = 2` квантового ефекту Холла складається повний бюджет невизначеності.

Приклад реального бюджету невизначеності первинного еталона PTB (Німеччина):

| Джерело невизначеності | Фізичний механізм виникнення | Тип оцінки | Відносна стандартна невизначеність (`u_r`) |
| :--- | :--- | :--- | :--- |
| **Недосконалість плато (`R_xx ≠ 0`)** | Залишкове термопольове розсіювання носіїв | Тип B | `1.5 × 10⁻¹⁰` |
| **Паразитний опір контактів** | Скінченна провідність омічних підводів зразка | Тип B | `1.0 × 10⁻¹⁰` |
| **Витікання струму в ізоляції** | Скінченний опір витоку дротів кріостата (`> 10¹⁴` Ом) | Тип B | `2.0 × 10⁻¹⁰` |
| **Похибка витків компаратора CCC** | Неоднорідність надпровідного екранування | Тип B | `0.5 × 10⁻¹⁰` |
| **Шум SQUID-магнітометра** | Білий тепловий та флікер-шум датчика потоку | Тип A | `3.5 × 10⁻¹⁰` |
| **Термо-ЕРС вимірювальних кіл** | Паразитні температурні градієнти на стиках металів | Тип A | `1.2 × 10⁻¹⁰` |
| **Температурний нестабільний дрейф** | Невеликі коливання температури блоку `±0.005` К | Тип B | `0.8 × 10⁻¹⁰` |
| **Суммарна комбінована невизначеність (k=1)** | **Квадратна сума всіх компонентів** | **Total** | **`4.5 × 10⁻¹⁰` (0.00045 ppm)** |

Розширена невизначеність при коефіцієнті покриття `k = 2` (довірчий інтервал `95.45%`) становить:

```
U_95 = 2 · u_r = 9.0 × 10⁻¹⁰  (0.0009 ppm)
```

Це означає, що значення опору каліброваного десятичного резистора відновлюється із точністю до 9-го знака після коми.

### 7. Протокол верифікації та валидації плато QHE (Validation Protocol)

Перед проведенням точних метрологічних зіставлень оператор зобов'язаний виконати п'ятикрокову процедуру перевірки належності системи до квантованого плато:

#### Крок 1. Перевірка зникання поздовжнього опору `R_xx`
За вимірювального струму `I = 10` мкА вимірюється поздовжня напруга `V_xx` на обох краях зразка. Система вважається валідною, якщо поздовжній опір задовольняє умову:

```
R_xx = V_xx / I < 10⁻⁴ Ом
```

Якщо `R_xx > 10⁻³` Ом, зразок працює поза плато (температура занадто висока або магнітне поле зміщене від центра плато).

#### Крок 2. Перевірка симетрії щодо інверсії магнітного поля
Вимірювання `R_xy` проводиться при прямому `+B` та інвертованому `-B` напрямках магнітного поля. Відносна різниця виміряних значень повинна задовольняти критерію:

```
| R_xy(+B) - R_xy(-B) | / R_xy < 10⁻⁸
```

Це виключає географічну асиметрію розміщення потенціальних контактів (паразитну підмішку поздовжньої компоненти `R_xx` у поперечний сигнал `R_xy`).

#### Крок 3. Тест на критерій струмового розігріву (Current Independence Test)
Серія вимірювань `R_xy` виконується при послідовних значеннях струму: `5` мкА, `10` мкА, `20` мкА, `40` мкА. Упродовж усього інтервалу значення `R_xy` повинно залишатися константним у межах шуму. Якщо при струмі `40` мкА спостерігається зміна `R_xy` на рівні `10⁻⁸`, це свідчить про перегрів двовимірних електронів вище температури решітки (пробій квантового ефекту Холла). Робочий струм зменшують до безпечного рівня `15...20` мкА.

#### Крок 4. Тест ізоляції вимірювальних каналів
При відключеному джерелі струму опір витікання між будь-яким вимірювальним провідником та заземленим корпусом кріостата повинен перевищувати `10¹3` Ом.

#### Крок 5. Фінальна реєстрація відліку
Після успішного проходження перших чотирьох кроків запускається автоматизований цикл реверсивного вимірювання струму (`+I` та `-I`) з часом інтегрування кожного відліку не менше `100` секунд для повного усереднення низькочастотних флікер-шумів та термоелектрорушійних сил.
