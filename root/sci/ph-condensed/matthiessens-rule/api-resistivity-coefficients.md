# 📋 Довідкові параметри розсіяння та залишкового опору домішок у металах

Цей довідник містить комплексні виміряні та розраховані фізичні параметри переносу зарядів у металах, двокомпонентних сплавах, напівпровідникових структурах та тонкоплівкових мікроелектронних з'єднаннях. Зібрані дані описують коефіцієнти розсіяння точкових домішок, характеристики електропровідності чистих металів при різних температурах, інженерну класифікацію матеріалів за відношенням залишкового опору (RRR), емпіричні параметри відхилень від правила Матіссена (DMR) та фізичні коефіцієнти розмірного розсіяння в нановимірних дротах.

## 1. Залишковий питомий опір домішок `Δρ / c` та фізичні закони розсіяння

При розчиненні стороннього елемента в металевій матриці кожен домішковий атом створює локальне збурення періодичного потенціалу ґратки. Оскільки кінетична енергія електронів провідності поблизу поверхні Фермі є дуже великою (`ε_F ~ 2 – 10 еВ`), статичне розсіяння на домішках не залежить від температури, а питомий опір розведеного твердого розчину зростає лінійно з атомною концентрацією домішки `c`.

Величина `Δρ / c` визначає приріст питомого опору в мікроом-сантиметрах на один атомний відсоток домішки (`мкОм·см / ат.%` або `µΩ·cm / at.%`). Цей коефіцієнт є чутливим індикатором електронної структури елементів і підпорядковується кільком фундаментальним мікроскопічним закономірностям.

### 1.1. Ключові мікроскопічні правила та виведення Фріделя

1. **Емпіричне правило Лінде (Linde's Rule):** Для домішок, які належать до одного періоду з металом-матрицею, приріст залишкового опору є квадратичною функцією різниці валентностей `ΔZ = Z_impurity - Z_matrix`:

```
Δρ / c = a + b · (ΔZ)²
```

де `a` описує розмірне деформаційне розсіяння через відмінність іонних радіусів, а `b` описує розсіяння на надлишковому кулонівському потенціалі закрипованого ядра.

2. **Теорема про суми Фріделя (Friedel Sum Rule):** Екранування надлишкового заряду домішки `ΔZ` електронами провідності викликає фазові зсуви `η_l(ε_F)` часткових електронних хвиль із кутовим моментом `l`. Правило сум Фріделя пов'язує надлишковий заряд із фазовими зсувами на рівні Фермі:

```
ΔZ = (2 / π) · ∑_l (2l + 1) · η_l(ε_F)
```

Переріз розсіяння електронів `σ_sc` та внесок домішки у питомий опір виражаються через ці фазові зсуви:

```
Δρ / c = (4π · ℏ) / (n · e² · k_F) · ∑_l (l + 1) · sin²(η_l(ε_F) - η_(l+1)(ε_F))
```

3. **Ефект розмірної невідповідності (Size Mismatch):** Якщо іонний радіус домішки суттєво відрізняється від радіуса атома матриці, навколо домішки виникає локальне поле пружних деформацій ґратки, що додатково збільшує ефективний переріз розсіяння електронів.

4. **d-Резонансне розсіяння Мотта–Фріделя:** Домішки перехідних 3d-металів (таких як залізо, хроми, марганець, нікель) у благородних металах (міді, сріблі, золоті) створюють віртуальні зв'язані d-рівні у зоні провідності. Коли фазовий зсув `η_2(ε_F) → π / 2`, виникає резонансне розсіяння, яке піднімає `Δρ / c` до гігантських значень 8–10 мкОм·см / ат.%.

## 2. Фізичні та кінетичні параметри чистих металів

Для обчислення фононного опору `ρ_ph(T)` та оцінки довжини вільного пробігу електронів `l_e` використовуються фундаментальні кінетичні характеристики чистих монодеканих металів при кімнатній температурі (`T = 293.15 K`).

### 2.2. Метод обчислення кріогенної довжини пробігу

При кріогенних температурах (`T = 4.2 K`) фононне розсіяння вимикається, і довжина вільного пробігу електрона обмежується виключно відстані між дефектами. Вона обчислюється через коефіцієнт RRR:

```
l_e(4.2 K) ≈ l_e(293.15 K) · RRR
```

Для ультрачистої міді з `RRR = 10 000` середня довжина вільного пробігу електрона при гелієвих температурах досягає `l_e ≈ 0.4 мм`. Це означає, що електрон долає мільйони кристалічних комірок без жодного зіткнення.

## 3. Інженерна класифікація чистоти металів за відношенням RRR

Параметр `RRR = ρ(293.15 K) / ρ(4.2 K)` є головним стандартом контролю чистоти металів, відсутності точкових дефектів та досконалості кристалічної ґратки.

У надпровідній техніці мідна або алюмінієва матриця навколо надпровідних жил (`NbTi` або `Nb₃Sn`) повинна мати `RRR > 200`. Це необхідно для того, щоб у разі аварійного переходу надпровідника в нормальний стан (квенч) струм у тисячі ампер перетік у мідь з мінімальним виділенням тепла Джоуля–Ленца, запобігаючи вибуховому руйнуванню магніту.

## 4. Кількісні параметри відхилень від правила Матіссена (DMR)

Відхилення від правила Матіссена описуються нелінійним температурно-дефектним додаткам `Δρ_DMR(T, c)` у виразі:

```
ρ_total(T, c) = ρ₀(c) + ρ_ph(T) + Δρ_DMR(T, c)
```

Причини цих відхилень включають анізотропію поверхні Фермі, двозонну провідність Зондгаймера та квантову електрон-фонон-домішкову інтерференцію (ефект Кагана–Жернова).

### 4.1. Емпіричні параметри відхилень DMR для ключових alloy-систем

| Система сплаву | Діапазон T (K) | Математична форма `Δρ_DMR` | Максимальне відхилення `Δρ / ρ₀` (%) | Фізична причина DMR |
| :--- | :--- | :--- | :--- | :--- |
| Cu–Ni | 20 – 100 K | `B · c · T⁵` | 8 – 12% | Електрон-фонон-домішкова інтерференція (Каган–Жернов) |
| Cu–Ge | 10 – 80 K | `A · c · log(T)` | 15 – 25% | Анізотропія поверхні Фермі (шийки д-зони) |
| Al–Mg | 30 – 120 K | `C · c · T²` | 5 – 10% | Зміна фононного спектра (квазілокальні моди) |
| Pt–Ir | 100 – 300 K | Двозонна модель Зондгаймера | 14 – 22% | Перерозподіл носіїв між s- та d-зонами |

## 5. Параметри розмірних ефектів у тонких плівках та нанопровідниках

У сучасних інтегральних мікросхемах ширина мідних мікроскопічних з'єднань (interconnects) становить `d < 12 нм`, що є набагато меншим за об'ємну довжину вільного пробігу електронів у міді (`l_e ≈ 39.9 нм`). У цьому нановимірному режимі питомий опір зростає в кілька разів через поверхневе та міжзернове розсіяння електронів.

Повний питомий опір нанопровідника обчислюється через узагальнене правило Матіссена:

```
ρ_nano = ρ_bulk + ρ_surface(d) + ρ_grain(D)
```

де `ρ_surface(d)` описується моделлю Фукса–Зондгаймера (параметр дзеркальності `p`), а `ρ_grain(D)` описується моделлю Майдадаса–Шацкеса (коефіцієнт відбивання меж зерен `R`).

### 5.1. Модельні параметри поверхонь і меж зерен для тонких плівок Cu та Al

| Фізичний параметр | Позначення | Типове значення для Cu | Типове значення для Al | Фізичний зміст |
| :--- | :--- | :--- | :--- | :--- |
| Коефіцієнт дзеркальності поверхні | `p` | 0.10 – 0.20 | 0.20 – 0.30 | Частка електронів, що розсіюються поверхнею дзеркально (Модель Фукса–Зондгаймера) |
| Коефіцієнт відбивання меж зерен | `R` | 0.35 – 0.50 | 0.25 – 0.35 | Ймовірність відбивання електрона від межі між монокристалічними зернами (Модель Майдадаса–Шацкеса) |
| Середній розмір зерна | `D` | 10 – 50 нм | 20 – 100 нм | Середній діаметр кристалітів у тонкій плівці |
| Розрахунковий опір при `d = 10 нм` | `ρ_nano` | 6.5 – 8.5 мкОм·см | 8.0 – 11.0 мкОм·см | Зростання опору в 4-5 разів порівняно з об'ємним металом |

### 5.2. Аналітичне виведення моделі Фукса–Зондгаймера та Майдадаса–Шацкеса

У моделі Фукса–Зондгаймера розмірний внесок поверхні для тонких дротів прямокутного перерізу `d × d` описується асимптотичним виразом при `d ≪ l_e`:

```
ρ_surface(d) ≈ ρ_bulk · (3 / 4) · (1 - p) · (l_e / d)
```

де `p = 0` відповідає повністю диффузному розсіянню (електрон втрачає весь спрямований імпульс при зіткненні з поверхнею), а `p = 1` відповідає ідеально дзеркальному відбиванню.

У моделі Майдадаса–Шацкеса додатковий опір кристалічних меж зерен визначається коефіцієнтом відбивання `R`:

```
ρ_grain(D) = ρ_bulk · [ 3 · α_g · ( 1/2 - α_g + α_g² · ln(1 + 1/α_g) ) ]⁻¹
α_g = (l_e / D) · (R / (1 - R))
```

Для тонких провідників мікропроцесорів з шириною `d = 10 нм` та розміром зерна `D = 10 нм` внесок меж зерен становить до 60% від сумарного опору, поверхневе розсіяння — близько 25%, а власний фононний опір чистої міді — лише 15%. Це робить вирощування великих зерен (`D > d`) вирішальним технологічним завданням для сучасної наноелектроніки.
