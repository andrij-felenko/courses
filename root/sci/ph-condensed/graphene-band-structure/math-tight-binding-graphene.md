# 🧮 Математичний вивід зонного спектра графену в наближенні сильного зв'язку

Ця вставка містить детальний математичний вивід електронного енергетичного спектра графену в наближенні сильного зв'язку (tight-binding approximation). Вивід охоплює розрахунок недіагональних матричних елементів перекриття атомарних орбіталей у плоскій гексагональній ґратці з двома підґратками, точне розв'язання векового детермінантного рівняння для двох зон, Тейлорівське розкладання енергії поблизу особливих точок Бріллюенівської зони з отриманням релятивістського гамільтоніана Дірака, розрахунок кривини Беррі та топологічної фази Беррі, вплив перескоків другого порядку, точний алгебраїчний вивід рівнянь Ландау у магнітному полі, вивід спектра масивних діраківських ферміонів, макроскопічні деформації та псевдомагнітні поля, вивід міжзонних оптичних матричних елементів, математику долинотроніки та 4-спінорні оператори, електрон-фононний деформаційний потенціал, термодинамічне потенційне розширення, а також модель міжшарової взаємодії у двошаровому графені.

## 1. Геометрія кристалічної ґратки та базисні вектори

Кристалічна ґратка графену не є простою ґраткою Браве, оскільки окремий елементарний осередок містить два фізично нееквівалентні атоми вуглецю, позначувані як підґратка `A` та підґратка `B`. Кожен атом підґратки `A` оточений трьома найближчими сусідами, що належать підґратці `B`, і навпаки.

Загальна симетрія двовимірного кристала описується двовимірною трикутною ґраткою Браве з двоатомним базисом. Базисні вектори примітивної трансляції `a₁` та `a₂` у декартових координатах `(x, y)` задаються виразами:

```
a₁ = (a_cc · √3 / 2,  a_cc · 3 / 2)
a₂ = (a_cc · √3 / 2, -a_cc · 3 / 2)
```

де `a_cc = 1.42 Å` є постійною довжиною ковалентного `sp²`-зв'язку між сусідніми атомами вуглецю. Повна постійна ґратки (довжина вектора трансляції) дорівнює `a = |a₁| = |a₂| = a_cc · √3 ≈ 2.46 Å`.

Вектори, що з'єднують обраний центральний атом підґратки `A` з трьома його найближчими сусідами на підґратці `B`, мають геометричні координати:

```
δ₁ = (a_cc · √3 / 2,  a_cc / 2)
δ₂ = (-a_cc · √3 / 2, a_cc / 2)
δ₃ = (0, -a_cc)
```

Вектори оберненої ґратки `b₁` та `b₂` визначаються зі стандартної умови ортонормованості `a[i] · b[j] = 2π δ[ij]`, де `δ[ij]` — символ Кронекера:

```
b₁ = (2π / (a_cc · √3),  2π / (3 a_cc))
b₂ = (2π / (a_cc · √3), -2π / (3 a_cc))
```

Зона Бріллюена має форму правильного шестикутника в двовимірному квазіімпульсному просторі `(k_x, k_y)`. Її кутові вершини розпадаються на два нееквівалентні набори точок, позначувані як долині `K` та `K'`. Будь-які інші вершини шестикутника зв'язані з `K` або `K'` векторами оберненої ґратки і є фізично тотожними. Точки Дірака `K` та `K'` мають координати:

```
K  = (4π / (3 · √3 · a_cc), 0)
K' = (-4π / (3 · √3 · a_cc), 0)
```

## 2. Формулювання гамільтоніана у наближенні сильного зв'язку

У графені чотири валентні електрони кожного атома вуглецю розподіляються між трьома плоскими `sp²`-гібридизованими орбіталями та однією негібридизованою `2p_z`-орбіталлю, орієнтованою перпендикулярно до атомарної площини. Три `sp²`-орбіталі утворюють міцні насичені σ-зв'язки з енергією зв'язку близько `4.7 еВ`, які лежать глибоко у валентній зоні й не беруть участі у процесах електронного переносу при низьких енергіях. Електронні властивості графену в околі рівня Фермі повністю визначаються `2p_z`-електронами, які перекриваються з сусідніми атомами та утворюють π-валентну зону та π*-зону провідності.

Згідно з методом ЛКАО (лінійна комбінація атомарних орбіталей), одноелектронна хвильова функція станового квазіімпульсу `k = (k_x, k_y)` записується як суперпозиція блохівських хвиль двох підґраток `A` та `B`:

```
|Ψ(k)⟩ = c_A(k) |Ψ_A(k)⟩ + c_B(k) |Ψ_B(k)⟩
```

Блохівські хвильові функції підґраток формуються як суми атомарних `2p_z`-орбіталей `ϕ(r)`, розташованих у вузлах відповідних підґраток:

```
|Ψ_A(k)⟩ = (1 / √N) ∑[R_A] e^(i k · R_A) |ϕ(r - R_A)⟩
|Ψ_B(k)⟩ = (1 / √N) ∑[R_B] e^(i k · R_B) |ϕ(r - R_B)⟩
```

де `N` — число елементарних осередків у кристалі, а сумування проводиться за всіма координатами вузлів `R_A` та `R_B`.

Рівняння Шредінгера `H |Ψ(k)⟩ = E(k) |Ψ(k)⟩` у двоелементному базисі `{|Ψ_A⟩, |Ψ_B⟩}` приводить до секулярної матричної системи `det(H(k) - E(k) S(k)) = 0`, де `S(k)` — матриця перекриття. Нехтуючи недіагональним перекриттям атомарних хвильових функцій на різних вузлах (`S_AB ≈ 0`) та вибираючи власну енергію атомарної `2p_z`-орбіталі за точку відліку (`ε_0 = 0`), діагональні елементи гамільтоніана перетворюються на нуль:

```
H_AA(k) = ⟨Ψ_A(k)| H |Ψ_A(k)⟩ = 0
H_BB(k) = ⟨Ψ_B(k)| H |Ψ_BB(k)⟩ = 0
```

Недіагональний елемент `H_AB(k)` описує квантово-механічні перескоки електронів між найближчими сусідами з інтегралом перескоку `t = -⟨ϕ(r - R_A)| H |ϕ(r - R_A - δ_j)⟩ ≈ 2.8 еВ`:

```
H_AB(k) = -t · f(k)
```

Тут комплексна функція `f(k)` є геометричним структурним фактором ґратки, який дорівнює сумі фазових множників по трьох векторах найближчих сусідів:

```
f(k) = e^(i k · δ₁) + e^(i k · δ₂) + e^(i k · δ₃)
```

Матриця одноелектронного гамільтоніана графену в базисі підґраток `(Ψ_A, Ψ_B)^T` набуває компактного вигляду:

```
H(k) = [[ 0,         -t · f(k) ],
        [ -t · f*(k), 0        ]]
```

## 3. Точний аналітичний розрахунок дисперсійного співвідношення

Власні значення енергії `E(k)` знаходяться зі стандартної детермінантної умови існування нетривіальних розв'язків алгебраїчної системи:

```
det [[ -E(k),     -t · f(k) ],
     [ -t · f*(k), -E(k)    ]] = 0
```

Розкриваємо матричний визначник покроково:

```
(-E) · (-E) - (-t · f(k)) · (-t · f*(k))
= E² - t² · |f(k)|²      [алгебраїчне розкриття детермінанта]
= 0                      [умова характеристичного рівняння]
```

Отримуємо аналітичний вираз для енергетичних зон графену:

```
E(k) = ± t · |f(k)|
```

Знак «+» описує верхню симетричну зону провідності (π*), а знак «−» — нижню валентну зону (π). 

Обчислимо квадрат модуля структурного фактора `|f(k)|² = f(k) · f*(k)` шляхом прямого множення трьох фазових експонент:

```
|f(k)|²
= |e^(i k · δ₁) + e^(i k · δ₂) + e^(i k · δ₃)|²
= (e^(i k · δ₁) + e^(i k · δ₂) + e^(i k · δ₃)) · (e^(-i k · δ₁) + e^(-i k · δ₂) + e^(-i k · δ₃))   [множення суми на комплексно спряжену]
= 3 + (e^(i k · (δ₁ - δ₂)) + e^(-i k · (δ₁ - δ₂))) + (e^(i k · (δ₁ - δ₃)) + e^(-i k · (δ₁ - δ₃))) + (e^(i k · (δ₂ - δ₃)) + e^(-i k · (δ₂ - δ₃))) [групування діагональних і недіагональних членів]
= 3 + 2 · cos(k · (δ₁ - δ₂)) + 2 · cos(k · (δ₁ - δ₃)) + 2 · cos(k · (δ₂ - δ₃))                   [застосування тотожності e^(ix) + e^(-ix) = 2 cos(x)]
```

Розкриємо скалярні добутки квазіімпульсу `k = (k_x, k_y)` на різниці векторів найближчих сусідів:

```
δ₁ - δ₂ = (a_cc · √3, 0)
δ₁ - δ₃ = (a_cc · √3 / 2, a_cc · 3 / 2)
δ₂ - δ₃ = (-a_cc · √3 / 2, a_cc · 3 / 2)
```

Обчислюємо три тригонометричні доданки:

```
k · (δ₁ - δ₂) = k_x · a_cc · √3
k · (δ₁ - δ₃) = k_x · a_cc · √3 / 2 + k_y · a_cc · 3 / 2
k · (δ₂ - δ₃) = -k_x · a_cc · √3 / 2 + k_y · a_cc · 3 / 2
```

Застосовуючи формулу суми косинусів `cos(α + β) + cos(-α + β) = 2 cos(α) cos(β)` та тригонометричну тотожність для `cos(2α) = 2 cos²(α) - 1`, перетворюємо суму трьох косинусів до підсумкового вигляду:

```
|f(k)|² = 1 + 4 · cos(k_x · a_cc · √3 / 2) · cos(k_y · a_cc · 3 / 2) + 4 · cos²(k_x · a_cc · √3 / 2)
```

Таким чином, підставляючи вираз для `|f(k)|` в енергетичний спектр, отримуємо точну аналітичну формулу зонної структури графену у всьому просторі першої зони Бріллюена:

```
E(k_x, k_y) = ± t · √(1 + 4 · cos(k_x · a_cc · √3 / 2) · cos(k_y · a_cc · 3 / 2) + 4 · cos²(k_x · a_cc · √3 / 2))
```

Перевіримо значення спектра у точці високої симетрії `K = (4π / (3 · √3 · a_cc), 0)`:

```
k_x · a_cc · √3 / 2 = (4π / (3 · √3 · a_cc)) · a_cc · √3 / 2 = 2π / 3
cos(2π / 3) = -1 / 2
cos²(2π / 3) = 1 / 4
```

Підставляємо отримані числові значення тригонометричних функцій у вираз модуля структурного фактора:

```
|f(K)|²
= 1 + 4 · (-1 / 2) · 1 + 4 · (1 / 4)    [підстановка cos(2π/3) = -1/2 та cos(0) = 1]
= 1 - 2 + 1                             [арифметика]
= 0                                     [точне обнулення у вершині K]
```

Рівність `|f(K)| = 0` показує, що у високосиметричній точці `K` (і аналогічно у точці `K'`) енергетичні зони π та π* повністю торкаються одна одної без жодного енергетичного зазору (`E(K) = 0`). Оскільки нейтральний графен має рівно один `2p_z`-електрон на кожен атом вуглецю, нижня валентна зона π виявляється повністю заповненою, а верхня зона провідності π* — порожньою. Рівень Фермі `E_F` проходить точно через точки торкання зон `E = 0`, утворюючи безщілинний напівметал.

## 4. Лінійне розкладання поблизу точок Дірака та ефективний гамільтоніан

Для вивчення електронних властивостей при низьких енергіях розглянемо малі відхилення квазіімпульсу `q = (q_x, q_y)` від вершини `K`: `k = K + q`, де виконується умова `|q| · a_cc << 1`.

Розкладемо три експоненціальні доданки структурного фактора `f(K + q)` в ряд Тейлора першого порядку за малими приростами `q · δ_j`:

```
f(K + q)
= e^(i (K + q) · δ₁) + e^(i (K + q) · δ₂) + e^(i (K + q) · δ₃)
= e^(i K · δ₁) · (1 + i q · δ₁) + e^(i K · δ₂) · (1 + i q · δ₂) + e^(i K · δ₃) · (1 + i q · δ₃) [лінійний розклад експоненти e^(i q · δ) ≈ 1 + i q · δ]
```

Значення скалярних добутків фазових аргументів у точці `K`:

```
K · δ₁ = (4π / (3 · √3 · a_cc)) · (a_cc · √3 / 2) = 2π / 3
K · δ₂ = (4π / (3 · √3 · a_cc)) · (-a_cc · √3 / 2) = -2π / 3
K · δ₃ = 0
```

Застосовуємо комплексні значення фазових множників `e^(i 2π/3) = -1/2 + i √3/2` та `e^(-i 2π/3) = -1/2 - i √3/2`:

```
f(K + q)
= (-1/2 + i √3/2) · (1 + i q_x · a_cc · √3/2 + i q_y · a_cc/2) + (-1/2 - i √3/2) · (1 - i q_x · a_cc · √3/2 + i q_y · a_cc/2) + 1 · (1 - i q_y · a_cc)  [підстановка скалярних добутків q · δ_i]
= -3/2 · a_cc · (q_x - i q_y)                  [скасування нульових членів і групування по q_x та q_y]
```

Отриманий простий результат показує, що поблизу точки `K` структурний фактор є суворо лінійним по малій імпульсній змінній `q_x - i q_y`.

Введемо фундаментальну константу — швидкість Фермі `v_F`, яка відіграє роль ефективної швидкості світла для квазічастинок у графені:

```
v_F = (3 · a_cc · t) / (2 · ħ) ≈ 10⁶ м/с
```

Підставляючи розклад `f(K + q)` у матрицю гамільтоніана `H(K + q)`, отримуємо ефективний низькоенергетичний гамільтоніан `H_eff(q)` у базисі підґраточних компонент хвильової функції `(Ψ_A, Ψ_B)^T`:

```
H_eff(q) = ħ · v_F · [[ 0,           q_x - i q_y ],
                      [ q_x + i q_y, 0           ]]
```

Використовуючи 2D-матриці Паулі `σ_x` та `σ_y`, що діють у квантовому просторі підґраткового псевдоспіну:

```
σ_x = [[ 0, 1 ], [ 1, 0 ]]
σ_y = [[ 0, -i ], [ i, 0 ]]
```

Записуємо підсумковий ефективний гамільтоніан у векторній формі:

```
H_eff(q) = ħ · v_F · (σ_x · q_x + σ_y · q_y) = ħ · v_F · (σ · q)
```

Цей вираз збігається з двовимірним релятивістським рівнянням Дірака для безмасових частинок зі спіном 1/2, де роль реального фізичного спіну відіграє псевдоспін (індекс належності електрона до підґратки `A` або `B`), а роль швидкості світла `c` відіграє швидкість Фермі `v_F ≈ 10⁶ м/с`, що приблизно в 300 разів менше за швидкість світла у вакуумі.

Власні значення ефективного гамільтоніана Дірака утворюють симетричні лінійні конуси:

```
E(q) = ± ħ · v_F · |q| = ± ħ · v_F · √(q_x² + q_y²)
```

Для другої нееквівалентної долини `K'` аналогічний розклад дає гамільтоніан `H_eff'(q) = ħ · v_F · (σ_x · q_x - σ_y · q_y)`, що відрізняється комплексно спряженою хіральністю.

## 5. Повний 4-компонентний гамільтоніан та математика долинотроніки

Для одночасного опису обох долин `K` та `K'` вводиться 4-компонентний спінор Намбу — Дірака:

```
Ψ_full(q) = (Ψ_A,K, Ψ_B,K, Ψ_B,K', -Ψ_A,K')^T
```

Повний 4x4 гамільтоніан Дірака конструюється за допомогою тензорного добутку матриць Паулі підґратки `σ` та матриць Паулі долинного псевдоспіну `τ`:

```
H_4x4 = ħ · v_F · (τ_z ⊗ σ_x · q_x + I_2 ⊗ σ_y · q_y)
```

де `τ_z = [[1, 0], [0, -1]]` розрізняє долині `K` (`τ_z = +1`) та `K'` (`τ_z = -1`). Оператор міждолинного розсіяння записується через `τ_x ⊗ σ_z`, що дозволяє математично моделювати вплив короткосяжних атомарних дефектів на змішування станів `K` та `K'`.

## 6. Електрон-фононний деформаційний потенціал

При взаємодії діраківських електронів із поздовжніми акустичними фононами (LA) потенційна енергія деформації кристала модифікує діагональні елементи гамільтоніана:

```
H_e-ph = D_D · (u_xx + u_yy) · I_2
```

де `D_D ≈ 18 еВ` є деформаційним потенціалом акустичних мод. Внесок вигинних фононів (ZA) описується квадратичним оператором деформації `(1/2) D_D (∇ h)²`, де `h(r)` — вертикальне зміщення атомарного шару.

Імовірність електрон-фононного розсіяння за золотим правилом Фермі задає довжину вільного пробігу електронів `λ_mfp = (ρ_2D v_s² ħ³ v_F²) / (D_D² k_B T E_F)`.

## 7. Псевдомагнітні поля при нерівномірних механічних деформаціях

При застосуванні тензора деформацій `u_ij` до кристала графену вектори найближчих сусідів змінюються на `δ_j' = (I + u) δ_j`. Інтеграли перескоку зазнають лінійного зсуву `t_j = t - (β t / a_cc²) (δ_j · u · δ_j)`.

Це приводить до появи калібрувального псевдомагнітного векторного потенціалу `A_pseudo = (A_x, A_y)` в гамільтоніані Дірака `H = ħ v_F σ · (q - (e/c) A_pseudo)`:

```
A_x = (ħ / (2 e v_F a_cc)) · (β / 2) · (u_xx - u_yy)
A_y = -(ħ / (2 e v_F a_cc)) · β · u_xy
```

де `β = - d ln(t) / d ln(a_cc) ≈ 2.2`.

Калібрувальне псевдомагнітне поле `B_pseudo = ∂ A_y / ∂ x - ∂ A_x / ∂ y` квантує енергетичні зони у рівні Ландау без наявності зовнішнього магнітного поля, що підтверджує глибоку зв'язаність геометрії ґратки та калібрувальних полів у графені.

## 8. Масивні діраківські ферміони та кривина Беррі

Коли інверсійна симетрія кристала порушена (наприклад, підкладкою `h-BN`), потенціали двох підґраток стають різними: `ε_A = +Δ / 2` та `ε_B = -Δ / 2`. 

Гамільтоніан набуває вигляду масивних діраківських ферміонів:

```
H_mass(q) = ħ v_F (σ_x q_x + σ_y q_y) + (Δ / 2) σ_z
```

Зонний спектр стає масивним із забороненою зоною шириною `Δ`:

```
E_±(q) = ± √((ħ v_F q)² + (Δ / 2)²)
```

Обчислимо кривину Беррі `Ω_z(q)` для валентної зони масивних діраківських ферміонів:

```
Ω_z(q) = (ħ² · v_F² · Δ) / (2 · ((ħ v_F q)² + (Δ / 2)²)^(3/2))
```

Інтегрування кривини Беррі по всій 2D-площині дає половину числа Черна на одну долину `C_valley = (1 / 2π) ∫ Ω_z(q) d²q = (1/2) sgn(Δ)`. Сумування внесків обох долин `K` та `K'` описує точні топологічні фазові переходи між звичайним диелектриком та топологічним ізолятором.

## 9. Розрахунок оптичного поглинання за золотим правилом Фермі

Обчислимо міжзонне оптичне поглинання електромагнітної хвилі за золотим правилом Фермі. Оператор взаємодії світла з псевдоспіном записується як `H_int = (e / c) v_F (σ · A_light)`.

Матричний елемент дипольного оптичного переходу між валентною зоною `|χ_-(q)⟩` та зоною провідності `|χ_+(q)⟩` дорівнює:

```
|M_opt|² = |⟨χ_+(q)| H_int |χ_-(q)⟩|² = (e² / c²) v_F² A_light² · sin²(θ_q - θ_pol)
```

Усереднення по кутах `θ_q` дає фактор `1/2`. Пряме інтегрування ймовірності поглинання фотона з енергією `ħ ω` приводить до універсального коефіцієнта поглинання моношару:

```
A = (4 π² / c) · (e² / h) = π · α ≈ 2.293%
```

де `α = e² / (4π ε₀ ħ c) ≈ 1/137` — стала тонкої структури.

## 10. Модель двошарового AB-графену (Bernal Stacking)

Для двошарового графену із Берналівським накладенням осередків чотирикомпонентна матриця гамільтоніана у базисі `(A₁, B₁, A₂, B₂)^T` будується з урахуванням міжшарового перескоку `γ₁ ≈ 0.39 еВ` між суміжними атомами `B₁` та `A₂`:

```
H_2layer(q) = [[ 0,           ħ v_F q_dagger, 0,           0    ],
               [ ħ v_F q,     0,              γ₁,          0    ],
               [ 0,           γ₁,             0,           ħ v_F q_dagger ],
               [ 0,           0,              ħ v_F q,     0    ]]
```

де `q = q_x + i q_y` та `q_dagger = q_x - i q_y`.

Редукуючи цей 4x4 гамільтоніан у базис низькоенергетичних станів `(A₁, B₂)^T` за допомогою квантово-механічної теорії збурень (метод Левдіна), отримуємо ефективний 2x2 гамільтоніан двошарового графену:

```
H_2layer_eff(q) = - (1 / (2 m*)) · [[ 0,           (q_x - i q_y)² ],
                                    [ (q_x + i q_y)², 0           ]]
```

де ефективна маса дорівнює `m* = γ₁ / (2 v_F²) ≈ 0.033 m_e`. Це математично доводить, що носії у двошаровому графені мають параболічну дисперсію `E(q) = ± ħ² q² / (2 m*)` з фазою Беррі `2π`.

## 11. Вплив перескоків другого порядку (next-nearest-neighbor hopping)

У більш точних розрахунках враховують також перескоки електронів між атомами однієї і тієї ж підґратки (`A → A` та `B → B`) на відстань `a = a_cc √3` з інтегралом перескоку другого порядку `t' ≈ 0.02 - 0.2 t ≈ 0.1 - 0.5 еВ`.

Оскільки перескоки другого порядку відбуваються в межах однієї підґратки, вони додають однакові діагональні елементи до гамільтоніана:

```
H_AA'(k) = H_BB'(k) = -t' · C(k)
```

де функція `C(k)` визначається підсумовуванням по шести векторах другого порядку `a₁`, `a₂`, `a₁ - a₂`:

```
C(k) = 2 · cos(k · a₁) + 2 · cos(k · a₂) + 2 · cos(k · (a₁ - a₂))
= 2 · cos(k_x · a_cc · √3) + 4 · cos(k_x · a_cc · √3 / 2) · cos(k_y · a_cc · 3 / 2)
```

Модифікований енергетичний спектр набуває вигляду:

```
E_±(k) = -t' · C(k) ± t · |f(k)|
```

У точках Дірака `K` значення додатка дорівнює `C(K) = -3`, тому точки Дірака зсуваються за енергією на величину `+3 t'`, проте електрон-діркова симетрія порушується: валентна зона та зона провідності стають асиметричними відносно точки торкання, хоча самі точки торкання (точки Дірака) залишаються безщілинними.

## 12. Власні спінори псевдоспіну та геометрична фаза Беррі

Власні хвильові функції (спінори) низькоенергетичного гамільтоніана Дірака `H_eff(q)` задаються у двокомпонентному псевдоспіновому базисі підґраток:

```
χ_±(q) = (1 / √2) · [[ 1 ],
                    [ ± e^(i θ_q) ]]
```

де полярний кут імпульсу в 2D-просторі дорівнює `θ_q = arctan(q_y / q_x)`. Напрямок псевдоспіну для електронів зони провідності (`+`) суворо паралельний напрямку імпульсу `q`, а для дірок валентної зони (`−`) — антипаралельний. Ця властивість називається хіральністю або спіральністю квантового стану.

Обчислимо геометричну фазу Беррі `γ`, яку набуває хвильова функція електрона при обході замкненого контуру навколо точки Дірака `K` у квазіімпульському просторі. За означенням, фаза Беррі визначається як циркуляція векторного потенціалу Беррі по контуру:

```
γ = i ∮ ⟨χ_+(q)| ∇[q] |χ_+(q)⟩ · dq
= i ∫₀²ⁿ (1/2) · [[1, e^(-i θ_q)]] · (d/dθ_q [[1], [e^(i θ_q)]]) · dθ_q  [параметризація контуру кутом θ_q від 0 до 2π]
= i ∫₀²ⁿ (1/2) · e^(-i θ_q) · (i e^(i θ_q)) dθ_q                          [диференціювання другого компонента спінора]
= -1/2 ∫₀²ⁿ dθ_q                                                         [інтегрування константи -1/2 від 0 до 2π]
= -π                                                                     [значення фази Беррі]
```

Значення фази Беррі `γ = ±π` є точним топологічним інваріантом двовимірних діраківських ферміонів. При повороті вектора імпульсу на кут `2π` хвильова функція псевдоспіну зміщує свою фазу на `π`, тобто змінює знак на протилежний (`e^(i π) = -1`). Саме ця топологічна фаза Беррі забороняє розсіяння електронів на кут `180°` при взаємодії з гладкими потенціалами і є причиною аномального напівцілочисельного квантового ефекту Холла у графені.

## 13. Рівняння руху в зовнішньому магнітному полі та рівні Ландау

У перпендикулярному магнітному полі `B = (0, 0, B)` квазіімпульс `q` замінюється кинематичним імпульсом за допомогою підстановки Паєрлса `q → q + (e / c) A`, де `A` — векторний потенціал магнітного поля.

Вибираючи калібрування Ландау `A = (-B y, 0, 0)`, ефективний гамільтоніан Дірака перетворюється на операторну систему:

```
H_B = v_F · [[ 0,             p_x - i e B y - i p_y ],
             [ p_x - i e B y + i p_y, 0            ]]
```

Запроваджуючи оператори знищення та народження для гармонічного осцилятора в магнітному полі з магнітною довжиною `l_B = √(ħ / (e B))`:

```
a = (l_B / (√2 ħ)) · (q_x - i q_y)
a† = (l_B / (√2 ħ)) · (q_x + i q_y)
```

Гамільтоніан Дірака набуває операторного вигляду алгебри розщеплення:

```
H_B = (√2 · ħ · v_F / l_B) · [[ 0, a ],
                              [ a†, 0 ]]
```

Власні значення енергії Ландау знаходяться точним шляхом:

```
E[N] = sgn(N) · v_F · √(2 · e · ħ · B · |N|)
```

де `N = 0, ±1, ±2, ...` є квантовим числом рівня Ландау.

Унікальною рисою релятивістських дискретних рівнів Ландау є залежність енергії від кореня квадратного з індексу рівня та магнітного поля `E_N ∝ √(B |N|)`, на відміну від класичних рівнів Ландау з еквідистантним інтервалом `E_n = ħ ω_c (n + 1/2) ∝ B`. Існування нульового рівня Ландау при `N = 0` независимо від величини магнітного поля `B` фундаментально пояснює збереження квантового ефекту Холла при кімнатній температурі.
