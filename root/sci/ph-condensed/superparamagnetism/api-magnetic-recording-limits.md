# 📋 Довідник параметрів матеріалів, однодоменних частинок та технологічних меж магнітного запису

Цей довідник містить систематизовані фізичні параметри магнітно-твердих матеріалів, кількісні критерії однодоменності та термічної стабільності, а також порівняльний аналіз технологічних поколінь жорстких магнітних дисків (PMR, HAMR, BPM). Таблиці, формули та специфікації призначені для розрахунку граничної щільності запису, аналізу суперпарамагнітного ліміту та підбору суперпарамагнітних наночастинок для біомедичних застосувань.

### Фізичний зміст та інтерпретація табличних параметрів

1. **Константа анізотропії K_u (Дж/м³)**: Визначає густину енергії, необхідну для відхилення макроспіна від легкої осі. Матеріали з `K_u > 10⁶` Дж/м³ (такі як хімічно впорядкована фаза `L1₀-FePt` та інтерметалід `SmCo₅`) називаються високоанізотропними і дозволяють зменшувати розмір зерна до `3` нм без втрати термічної стабільності.
2. **Намагніченість насичення M_s (А/м)**: Сумарний магнітний момент у одиниці об'єму при повному впорядкуванні спінів. Визначає амплітуду зчитуваного сигналу, величину полів розмагнічування та початкову сприйнятливість.
3. **Температура Кюрі T_C (°C)**: Температура фазового переходу другого роду з феромагнітного стану в парамагнітний. У технології HAMR визначає необхідну температуру локального лазерного нагріву.
4. **Критичний діаметр однодоменності D_crit (нм)**: Фізична межа розміру частини, нижче якої утворення доменної стінки є енергетично невигідним, і частинка стає однодоменною.

## 2. Розрахункові формули та критерії однодоменності і суперпарамагнетизму

Нижче наведено математичні співвідношення для обчислення критичних параметрів наночастинок та визначення термічної стабільності.

### Критичний діаметр однодоменності D_crit
Діаметр сферичної частинки, нижче якого утворення доменної стінки є енергетично невигідним:

```
D_crit ≈ 9 · √(A_ex · K_u) / (μ0 · M_s²)
```

де `A_ex` — константа обмінної взаємодії (типово `10⁻¹¹` Дж/м), `μ0 = 4π · 10⁻⁷` Гн/м.

### Межевий суперпарамагнітний діаметр D_sp
Діаметр сферичної частинки `(V = π · D³ / 6)`, нижче якого час релаксації `τ` стає меншим за час вимірювання `τ_meas`:

```
D_sp = [(6 · k_B · T · ln(τ_meas / τ_0)) / (π · K_u)]^(1/3)
```

Для стандартного експериментального часу вимірювання магнітометром `τ_meas = 100` с `(ln(τ_meas / τ_0) ≈ 25)` при `T = 300` К:

```
D_sp ≈ [150 · k_B · T / (π · K_u)]^(1/3)
```

### Температурна залежність коерцитивного поля H_c(T) (Рівняння Шаррока)
У заблокованому стані `(T < T_B)` коерцитивна сила однодоменної частинки з довільною орієнтацією легкої осі підпорядковується часово-температурному закону Шаррока:

```
H_c(T, t) = H_c0 · [1 - ((k_B · T / (K_u · V)) · ln(t / τ_0))^(1/2)]
```

де `H_c0 = 0.48 · H_k = 0.96 · K_u / M_s` — коерцитивна сила при абсолютному нулю `0 K`, а `t` — тривалість прикладення розмагнічувального поля.

Для квазістатичного вимірювання тривалістю `t = τ_meas` вираз спрощується до вигляду:

```
H_c(T) = H_c0 · [1 - (T / T_B)^(1/2)]
```

При досягненні температури блокування `T ≥ T_B` коерцитивна сила стає рівною нулю:

```
H_c(T) = 0   [суперпарамагнітний стан]
```

### Кількісні зони фактора термічної стабільності K_u·V / k_B·T
Значення фактора стабільності `K_v_ratio = K_u · V / (k_B · T)` визначає часовий діапазон збереження намагніченості:

- **`K_v_ratio < 25` (Суперпарамагнітна зона)**: Спонтанна релаксація відбувається за частки секунди. Намагніченість описується функцією Ланжевена `(H_c = 0, M_r = 0)`.
- **`25 ≤ K_v_ratio < 40` (Квазістабільна зона)**: Час релаксації становить від хвилин до кількох днів. Непридатна для тривалого зберігання даних.
- **`40 ≤ K_v_ratio < 60` (Зона межі поздовжнього запису)**: Час зберігання даних становить від місяців до кількох років.
- **`K_v_ratio ≥ 60` (Промисловий стандарт HDD)**: Гарантує термічну стабільність recorded біта протягом понад `10` років при робочій температурі `T = 330` К (`60 °C`).

### Технічні особливості архітектур

1. **LMR (Longitudinal Magnetic Recording)**: Вектори намагніченості зерен лежать у площині диска. Обмежений відштовхуванням суміжних бітів та малим об'ємом зерен.
2. **PMR (Perpendicular Magnetic Recording)**: Вектори намагніченості орієнтовані перпендикулярно до диска. Застосування м'якого магнітного підшару (SUL) подвоює ефективне поле запису.
3. **HAMR (Heat-Assisted Magnetic Recording)**: Використовує лазерний нагрів за допомогою плазмонного ближньопольового оптичного транзистора (NFT) для тимчасового зниження коерцитивного поля `L1₀-FePt` під час запису.
4. **BPM (Bit-Patterned Media)**: Кожен біт формується у вигляді одного впорядкованого однодоменного наноострівця, сформованого методом електронно-променевої літографії, що повністю усуває міжзерновий шум.

## 4. Біомедичні специфікації суперпарамагнітних наночастинок (SPIONs)

Діагностичне та терапевтичне застосування суперпарамагнітних наночастинок оксиду заліза (SPIONs — `Fe₃O₄`, `γ-Fe₂O₃`) вимагає дотримання суворих біофізичних інваріантів.

### 1. Гідродинамічний діаметр D_h та фармакокінетика
Повний діаметр наночастинки з урахуванням захисного полімерного покриття (декстран, ПЕГ, цитрат) розраховується як:

```
D_h = D_core + 2 · d_shell
```

- **`D_h < 10` нм**: Швидко фільтруються нирками та виводяться з організму (час напіввиведення `< 30` хв).
- **`10 нм < D_h < 100` нм**: Оптимальний діапазон для тривалої циркуляції у кровоносній системі. Не захоплюються нирками й оминають швидку фільтрацію селезінкою.
- **`D_h > 200` нм**: Швидко поглинаються клітинами ретикулоендотеліальної системи (макрофагами печінки та селезінки).

### 2. МРТ релаксуюча здатність r₁ та r₂
Контрастна ефективність SPIONs оцінюється за коефіцієнтами релаксуючої здатності `r₁` (поздовжня) та `r₂` (поперечна), які визначають зміну швидкості релаксації протонів води на мілімоль концентрації заліза:

```
1 / T_1,2 = (1 / T_1,2)_0 + r_1,2 · C_Fe
```

Для суперпарамагнітних частинок `r₂` перевищує `r₁` у десятки разів (`r₂ / r₁ > 10`), що робить їх класичними негативними `T₂`-контрастними агентами. Типові значення `r₂` для `Fe₃O₄` частинок діаметром 12 нм становлять від `100` до `250` (мМ·с)⁻¹.

### 3. Розрахунок питомої потужності поглинання для гіпертермії (SAR / SLP)
При опроміненні частинок змінним магнітним полем `H(t) = H_0 · sin(2π · f · t)` питома потужність виділення тепла `SAR` (Specific Absorption Rate) у розрахунку на масу заліза описується формулою Розенцвейга:

```
SAR = (π · μ0 · χ" · H_0² · f) / ρ_Fe
```

де `ρ_Fe` — густина заліза, а `χ"` — уявна частина динамічної магнітної сприйнятливості:

```
χ"(f) = χ_0 · (2π · f · τ_eff) / (1 + (2π · f · τ_eff)²)
```

Ефективний час релаксації `τ_eff` враховує паралельну дію двох механізмів (Нееля та Брауна):

```
1 / τ_eff = 1 / τ_Neel + 1 / τ_Brown
```

де `τ_Brown = (3 · η · V_h) / (k_B · T)` (`η` — в'язкість рідини, `V_h` — гідродинамічний об'єм).

Максимум тепловиділення досягається при виконанні умови резонансу:

```
2π · f · τ_eff = 1
```

Для безпеки пацієнта під час процедур магнітної гіпертермії добуток амплітуди поля на частоту повинен відповідати клінічному критерію Брезовіча:

```
H_0 · f ≤ 5 · 10⁹ А / (м · с)
```

Перевищення цього порогу призводить до небажаного вихрового нагріву здорових тканин організму за рахунок закону індукції Фарадея.
