# 🧮 Феноменологічна енергія анізотропії та ефективне поле анізотропії

Математичний опис магнітокристалічної анізотропії ґрунтується на феноменологічному розкладі густини вільної енергії кристала у серію степеневих рядів за напрямними косинусами вектора намагніченості. Цей підхід дозволяє строго обчислити орієнтації осей легкого та важкого намагнічування, умови стійкості магнітних фаз, роботу намагнічування, критичні поля переключення та тензор ефективного поля анізотропії без безпосереднього розв'язання багатоелектронного рівняння Шредінгера.

## Напрямні косинуси та сферична система координат

Вектор макроскопічної намагніченості монокристала `M` у стані магнітного насичення має постійний модуль `|M| = M_s` (намагніченість насичення). Його просторова орієнтація відносно декартових кристалографічних осей `(x, y, z)` задається одиничним вектором `m`:

```
m = M / M_s = (α₁, α₂, α₃)      [нормування вектора намагніченості]
```

де `α₁, α₂, α₃` — напрямні косинуси, які задовольняють фундаментальну геометричну тотожність:

```
α₁² + α₂² + α₃² = 1            [умова норми одиничного вектора]
```

У сферичній системи координат, де `θ` — полярний кут відносно головної кристалографічної осі `z` (або `[0001]`), а `φ` — азимутальний кут у базисній площині `(x, y)`, напрямні косинуси набувають вигляду:

```
α₁ = sin θ · cos φ              [проекція на вісь x]
α₂ = sin θ · sin φ              [проекція на вісь y]
α₃ = cos θ                      [проекція на вісь z]
```

Густина вільної енергії анізотропії `E_A` є скалярною функцією напрямку `m`. Форма цієї функції повністю визначається точковою групою кристалографічної симетрії матеріалу.

## Одноосьова анізотропія: стаціонарні стани та умови стійкості

Для гексагональних (наприклад, `Co`), тетрагональних (наприклад, `Nd₂Fe₁₄B`) та тригональних кристалів енергія анізотропії має осьову симетрію відносно головної кристалографічної осі `c` (`z`). Це означає, що енергія залежить лише від полярного кута `θ` і не залежить від азимутального кута `φ`.

Через симетрію відносно інверсії `m → -m`, розклад енергії містить лише парні степені `sin θ`:

```
E_A(θ) = K₁·sin²θ + K₂·sin⁴θ + K₃·sin⁶θ + ...     [ряд за парними степенями синуса]
```

де `K₁, K₂, K₃` — феноменологічні константи анізотропії (вимірюються у `Дж/м³` в SI або `ерг/см³` у CGS, причому `1 Дж/м³ = 10 ерг/см³`). 

Обчислимо екстремуми енергії `E_A(θ)`, обмежившись першими двома членами розкладу (`K₁` та `K₂`). Похідна густини енергії за кутом `θ` дорівнює:

```
dE_A / dθ 
= d/dθ (K₁·sin²θ + K₂·sin⁴θ)                          [взято похідну за θ]
= 2·K₁·sin θ·cos θ + 4·K₂·sin³θ·cos θ                [диференціювання складеної функції]
= 2·sin θ·cos θ · (K₁ + 2·K₂·sin²θ)                   [винесено спільний множник]
= sin(2θ) · (K₁ + 2·K₂·sin²θ) = 0                     [формула подвійного кута sin(2θ)]
```

Це рівняння має три можливі групи коренів, які відповідають різним магнітним конфігураціям та фазовим станам кристала.

### 1. Вісь легкого намагнічування (Easy Axis)

Перша умова рівноваги відповідає розв'язку:

```
sin θ = 0  ⇒  θ = 0  або  θ = π (180°)                [орієнтація уздовж осі c]
```

Вектор намагніченості орієнтований строго уздовж кристалографічної осі `z` (`[0001]`). Перевіримо умову мінімуму енергії через другу похідну:

```
d²E_A / dθ² |_(θ=0) 
= 2·K₁·(cos²θ - sin²θ) + 4·K₂·(3·sin²θ·cos²θ - sin⁴θ) |_(θ=0)   [взято другу похідну за θ]
= 2·K₁                                                       [підстановка sin(0)=0, cos(0)=1]
```

Стан є стійким мінімумом енергії за умови, коли друга похідна строго додатна:

```
d²E_A / dθ² > 0  ⇒  K₁ > 0                            [критерій мінімуму енергії]
```

Якщо `K₁ > 0` (і `K₂ > -K₁`), кристал має **легку вісь намагнічування** уздовж `[0001]`. Це спостерігається у гексагональному кобальті при кімнатній температурі (`K₁ = 4.1×10⁵ Дж/м³`).

### 2. Площина легкого намагнічування (Easy Plane)

Друга умова рівноваги відповідає розв'язку:

```
cos θ = 0  ⇒  θ = π/2 (90°)                           [орієнтація у базисній площині]
```

Вектор намагніченості лежить у базисній площині, перпендикулярній до головної осі `c`. Друга похідна в цій точці дорівнює:

```
d²E_A / dθ² |_(θ=π/2) 
= 2·K₁·(-1) + 4·K₂·(-1)                                [підстановка sin(π/2)=1, cos(π/2)=0]
= -2·(K₁ + 2·K₂)                                       [спрощення виразу]
```

Стан є стійким мінімумом енергії, якщо:

```
d²E_A / dθ² > 0  ⇒  K₁ + 2·K₂ < 0                      [умова від'ємності суми]
```

Якщо `K₁ < 0` і `K₂ < |K₁|/2`, кристал має **площину легкого намагнічування**. Усі напрямки у базисній площині `(0001)` є енергетично еквівалентними у даному наближенні.

### 3. Конус легкого намагнічування (Easy Cone)

Третя умова рівноваги виникає, коли вираз у дужках дорівнює нулю:

```
K₁ + 2·K₂·sin²θ₀ = 0  ⇒  sin²θ₀ = - K₁ / (2·K₂)         [визначення кута конуса]
```

Оскільки значення квадрата синуса лежить у межах `0 ≤ sin²θ₀ ≤ 1`, цей стан існує лише тоді, коли `K₁` та `K₂` мають протилежні знаки, причому виконується умова:

```
0 < - K₁ < 2·K₂                                        [умова існування розв'язку]
```

У цьому разі мінімум енергії досягається на конусі з кутом напіврозхилу `θ₀ = arcsin(√(-K₁ / (2·K₂)))`. Така ситуація спостерігається, наприклад, у кобальті при підвищених температурах (понад 245 °C) або у деяких феритах та сполуках рідкісноземельних металів.

## Обчислення роботи намагнічування

Робота `W`, яку необхідно виконати зовнішньому магнітному полю для повороту вектора намагніченості від легкої осі (`θ = 0`) до важкої площини (`θ = π/2`), дорівнює інтегралу або різниці густини енергії анізотропії у цих двох станах:

```
W = ∫₀^(M_s) H_зовн dM 
  = E_A(π/2) - E_A(0)                                  [визначення роботи через різницю потенціалів]
  = (K₁·sin²(π/2) + K₂·sin⁴(π/2)) - (0)                [підстановка граничних кутів]
  = K₁ + K₂                                            [значення sin(π/2)=1]
```

Ця площа на графіку `M(H)` між кривими намагнічування вздовж легкої та важкої осей є прямим способом експериментального визначення констант `K₁` та `K₂`.

## Кубічна анізотропія: полиноми симетрії та особливі осі

У кубічних кристалах (ОЦК залізо, ГЦК нікель, шпінелі, гранати) густина енергії анізотропії повинна бути інваріантною відносно точкової групи симетрії куба `O_h`. Це вимагає інваріантності відносно:
1. Зміни знаків напрямних косинусів: `α_i → -α_i` (інверсія відносно центру);
2. Будь-якої перестановки індексів: `α₁ ↔ α₂ ↔ α₃`.

Загальний вираз розкладу енергії за полиномами симетрії має вигляд:

```
E_A = K₁·(α₁²·α₂² + α₂²·α₃² + α₃²·α₁²) + K₂·α₁²·α₂²·α₃² + ...   [кубічний розклад симетрії]
```

Обчислимо значення `E_A` для трьох головних кристалографічних напрямків у кубічному кристалі:

### 1. Напрямок ребра куба `[100]`
Напрямні косинуси: `α₁ = 1, α₂ = 0, α₃ = 0`.
```
E_A([100]) = K₁·(1·0 + 0·0 + 0·1) + K₂·(1·0·0) = 0     [підстановка напрямних косинусів [100]]
```

### 2. Напрямок діагоналі грані `[110]`
Напрямні косинуси: `α₁ = 1/√2, α₂ = 1/√2, α₃ = 0`.
```
E_A([110]) = K₁·((1/2)·(1/2) + (1/2)·0 + 0·(1/2)) + K₂·0 = K₁ / 4   [підстановка косинусів [110]]
```

### 3. Напрямок просторової діагоналі куба `[111]`
Напрямні косинуси: `α₁ = 1/√3, α₂ = 1/√3, α₃ = 1/√3`.
```
E_A([111]) = K₁·((1/3)·(1/3) + (1/3)·(1/3) + (1/3)·(1/3)) + K₂·(1/3)·(1/3)·(1/3)
           = K₁ / 3 + K₂ / 27                          [підстановка косинусів [111]]
```

Різниця енергій між напрямками дозволяє встановити орієнтацію легких і важких осей у залежності від знаків `K₁` та `K₂`:

```
Для K₁ > 0 (наприклад, ОЦК Залізо Fe):
E_A([100]) = 0                    [найменша енергія → Легка вісь [100]]
E_A([110]) = K₁ / 4               [проміжна енергія бар'єра]
E_A([111]) = K₁ / 3 + K₂ / 27     [найбільша енергія → Важка вісь [111]]

Для K₁ < 0 (наприклад, ГЦК Нікель Ni):
E_A([111]) = K₁ / 3 + K₂ / 27     [найменша від'ємна енергія → Легка вісь [111]]
E_A([110]) = K₁ / 4               [проміжна енергія]
E_A([100]) = 0                    [найбільша енергія → Важка вісь [100]]
```

Математично різниця енергій між важкою та легкою віссю для заліза дорівнює:

```
ΔE_A = E_A([111]) - E_A([100]) = K₁ / 3 + K₂ / 27    [різниця енергій між діагоналлю та ребром]
```

При `K₁ = 4.8×10⁴ Дж/м³` та `K₂ = 0.5×10⁴ Дж/м³` маємо `ΔE_A ≈ 1.62×10⁴ Дж/м³`.

## Ефективне поле анізотропії та момент сил

У варіаційному формулюванні мікромагнетизму енергія анізотропії входить до загального функціоналу вільної енергії. Зміна енергії анізотропії при малій деформації вектора намагніченості `δM` еквівалентна дії на намагніченість внутрішнього ефективного поля анізотропії `H_A`:

```
δE_A = - μ₀ · ∫ (H_A · δM) dV                         [варіація енергії анізотропії]
```

Звідси тензорний вираз для вектора ефективного поля анізотропії записується як варіаційна похідна:

```
H_A = - (1 / μ₀) · (∂E_A / ∂M) = - (1 / (μ₀ · M_s)) · ∇_m E_A   [градієнт енергії в просторі напрямків]
```

де `∇_m = (∂/∂α₁, ∂/∂α₂, ∂/∂α₃)` — градієнт у просторі напрямних косинусів.

Обчислимо компоненти ефективного поля анізотропії для одноосьового кристала з `E_A = K₁·(1 - α₃²)`:

```
H_(A, x) = - (1 / (μ₀ · M_s)) · ∂/∂α₁ [K₁·(1 - α₃²)] = 0         [x-компонента поля]
H_(A, y) = - (1 / (μ₀ · M_s)) · ∂/∂α₂ [K₁·(1 - α₃²)] = 0         [y-компонента поля]
H_(A, z) = - (1 / (μ₀ · M_s)) · ∂/∂α₃ [K₁·(1 - α₃²)] = (2·K₁ / (μ₀ · M_s)) · α₃   [z-компонента поля]
```

Отже, ефективне поле анізотропії спрямоване уздовж легкої осі `z` і має максимальну модульну величину:

```
H_A = 2·K₁ / (μ₀ · M_s)                               [модуль поля анізотропії]
```

Це поле `H_A` утримує вектор намагніченості паралельно до легкої осі. Щоб повернути намагніченість у перпендикулярний напрямок, зовнішнє магнітне поле повинно перевищити значення `H_A`.

Векторний механічний момент сил `T_A`, що діє на вектор намагніченості з боку кристалічної ґратки, дорівнює:

```
T_A = μ₀ · (M × H_A) = - m × ∇_m E_A                   [векторний добуток для моменту сил]
```

У стані рівноваги сумарний момент сил від зовнішнього поля `H_зовн` та поля анізотропії `H_A` дорівнює нулю:

```
T_сумарний = μ₀ · M × (H_зовн + H_A) = 0               [умова магнітостатичної рівноваги]
```

## Модель Стонера — Вольфарта та критичне поле переключення

Розглянемо однодоменну частинку з одноосьовою анізотропією `K₁ > 0` під дією зовнішнього поля `H`, прикладеного під кутом `ψ` до легкої осі. Повна густина енергії дорівнює:

```
E(θ) = K₁·sin²θ - μ₀·M_s·H·cos(ψ - θ)                  [сума анізотропії та Зеємана]
```

Умова екстремуму `dE/dθ = 0` визначає кут `θ` рівноважної орієнтації намагніченості:

```
K₁·sin(2θ) - μ₀·M_s·H·sin(ψ - θ) = 0                    [похідна полярного кута]
```

Увівши безрозмірне поле `h = H / H_A = μ₀·M_s·H / (2·K₁)`, отримуємо фундаментальне рівняння Стонера — Вольфарта:

```
sin(2θ) - 2·h·sin(ψ - θ) = 0                           [безрозмірне рівняння рівноваги]
```

Межа стійкості (точка втрати локального мінімуму і стрибкоподібного перекричування намагніченості) визначається одночасним виконанням двох умов:

```
dE / dθ = 0   та   d²E / dθ² = 0                        [умова біфуркації катастрофи]
```

Ці дві умови дають параметричне рівняння астроїди Стонера — Вольфарта у координатах паралельної `h_|| = h·cos ψ` та перпендикулярної `h_⊥ = h·sin ψ` компонент зовнішнього поля:

```
h_|| = cos³θ                                           [паралельна компонента астроїди]
h_⊥ = - sin³θ                                          [перпендикулярна компонента астроїди]
```

Звідси випливає алгебраїчний критерій необоротного стрибка намагніченості (коерцитивного переключення):

```
(h_||)^(2/3) + (h_⊥)^(2/3) = 1                          [рівняння астроїди у безрозмірних полях]
```

Коли вектор зовнішнього безрозмірного поля `(h_||, h_⊥)` перетинає межу астроїди, енергетичний бар'єр між двома лунками анізотропії зникає, і вектор намагніченості робить лавиноподібний необоротний стрибок. При `ψ = 180°` (протилежно легкій осі) критичне поле переключення сягає свого максимуму `H_sw = H_A = 2·K₁ / (μ₀·M_s)`. При `ψ = 45°` критичне поле переключення мінімальне і дорівнює `H_sw = H_A / 2`.

## Степовий закон температурного згасання Акулова — Зенера

З ростом температури `T` інтенсивність теплових флуктуацій викликає спінові хвилі (магнони), що зменшують спонтанну намагніченість насичення `M_s(T)`. Проте константи анізотропії згасають із температурою значно швидше, ніж сама намагніченість.

Микола Акулов та Кларенс Зенер (*Clarence Zener*) довели, що для кристала симетрії порядку `n` температурна залежність константи анізотропії описується степенем від відносної намагніченості:

```
K_n(T) / K_n(0) = [ M_s(T) / M_s(0) ]^l                [закон масштабування Акулова — Зенера]
```

де показник степеня `l` визначається за формулою:

```
l = n · (n + 1) / 2                                    [формула показника степеня за порядком n]
```

Для одноосьового кристала перша константа `K₁` пов'язана з гармонікою другого порядку `n = 2`:

```
l_одноосьова = 2 · (2 + 1) / 2 = 3                     [обчислення степеня для одноосьового кристала]
K₁(T) / K₁(0) ≈ [ M_s(T) / M_s(0) ]³                   [кубічна залежність від намагніченості]
```

Для кубічного кристала перша константа `K₁` визначається поліномом четвертого порядку `n = 4`:

```
l_кубічна = 4 · (4 + 1) / 2 = 10                       [обчислення степеня для кубічного кристала]
K₁(T) / K₁(0) ≈ [ M_s(T) / M_s(0) ]¹⁰                  [десятий степінь температурного згасання]
```

Цей десятий степінь пояснює, чому у кубічному залізі при нагріванні від `0 K` до кімнатної температури намагніченість насичення `M_s` падає лише на `~5%`, тоді як константа анізотропії `K₁` падає майже удвічі!
