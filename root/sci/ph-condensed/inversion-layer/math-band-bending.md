# 🧮 Математична теорія згину зон та розподілу заряду в інверсійній МДН-структурі

Ця математична вставка містить точний аналітичний вивід одновимірного рівняння Пуассона-Больцмана для напівпровідникової МДН-структури, визначення поверхневого потенціалу, інтегрування електростатичного поля через функцію Кінгстона-Нейштадтера, виділення заряду рухомих електронів інверсійного шару та математичне обґрунтування порогу сильної інверсії.

## 1. Одновимірне рівняння Пуассона-Больцмана у приповерхневій області

Розглянемо напівпровідник p-типу з рівномірною концентрацією акцепторів `N_A`, який контактує з шарчиком діелектрика товщиною `d_{ox}`. Нехай вісь `x` спрямована перпендикулярно до межі розділу `діелектрик-напівпровідник` вглиб кристала (`x = 0` відповідає гетероінтерфейсу).

При накладанні зовнішньої напруги на затвор `V_G` у приповерхневому шарі виникає електростатичний потенціал `ψ(x)`. За нульовий орієнтир потенціалу приймається об'єм напівпровідника на нескінченності: `ψ(x → ∞) = 0`.

Концентрації вільних дірок `p(x)` та електронів `n(x)` у локальній точці `x` описуються розподілом Больцмана через енергетичне зміщення відносно рівня Фермі:

```
p(x) = p₀ · exp(-q · ψ(x) / (k_B · T))
n(x) = n₀ · exp(+q · ψ(x) / (k_B · T))
```

де `p₀ ≈ N_A` та `n₀ = n_i² / N_A` — рівноважні концентрації носіїв у глибокому об'ємі напівпровідника, `q` — елементарний заряд, `k_B` — стала Больцмана, `T` — абсолютна температура, а `n_i` — власна концентрація носіїв напівпровідника.

Визначимо безрозмірний потенціал `u(x)` та об'ємний потенціал Фермі `u_b`:

```
u(x) = q · ψ(x) / (k_B · T)
u_b  = q · ψ_B / (k_B · T) = ln(N_A / n_i)
```

Об'ємна густість заряду `ρ(x)` складається із рухомих носіїв та нерухомих іонізованих акцепторів `N_A⁻ ≈ N_A`. Виходячи з умови нейтальності об'єму на нескінченності, де `p₀ - n₀ - N_A = 0`, маємо `N_A = p₀ - n₀`. Підставляючи це в вираз для заряду, отримуємо:

```
ρ(x) = q · [p(x) - n(x) - N_A]
     = q · [p₀ · exp(-u) - n₀ · exp(u) - (p₀ - n₀)]
     = q · p₀ · [(exp(-u) - 1) - (n₀ / p₀) · (exp(u) - 1)]
```

Враховуючи, що для напівпровідника p-типу `p₀ ≈ N_A`, а `n₀ / p₀ = (n_i / N_A)²`, отримуємо остаточний точний розпис об'ємної густини заряду як функції потенціалу `ρ(u)`:

```
ρ(u) = q · N_A · [(exp(-u) - 1) - (n_i / N_A)² · (exp(u) - 1)]
```

Розподіл потенціалу `ψ(x)` підпорядковується одновимірному рівнянню Пуассона:

```
d²ψ / dx² = -ρ(x) / ε_s
```

де `ε_s = ε_r · ε₀` — абсолютна діелектрична проникність напівпровідника.

## 2. Інтегрування поля та функція Кінгстона-Нейштадтера

Для інтегрування рівняння Пуассона скористаємося класичною тотожністю математичного аналізу для других похідних:

```
d²ψ / dx² = (1 / 2) · d/dψ (dψ / dx)² = -ρ(ψ) / ε_s
```

Множачи обидві частини на `2 · dψ` та інтегруючи від об'єму на нескінченності (`ψ = 0`, `dψ/dx = 0`) до поверхні (`ψ = ψ_s`), отримуємо квадрат напруженості електричного поля `F(x) = -dψ / dx`:

```
F²(ψ) = (2 / ε_s) · ∫₀^{ψ} (-ρ(ψ')) dψ'
```

Підставляючи вираз для `ρ(u')` та переходжучи до безрозмірної змінної `u' = q · ψ' / (k_B · T)`, виконуємо визначений інтеграл:

```
∫₀^{u} [(1 - exp(-u')) + (n_i / N_A)² · (exp(u') - 1)] du'
= [u + exp(-u) - 1] + (n_i / N_A)² · [exp(u) - u - 1]
```

Звідси напруженість електричного поля `F(u)` у будь-якій точці приповерхневої області виражається через **функцію Кінгстона-Нейштадтера** `F(u, u_b)`:

```
F(u) = ± (√2 · k_B · T / (q · L_D)) · F(u, u_b)
```

де `L_D = √(ε_s · k_B · T / (2 · q² · N_A))` — дебаївський радіус екранування для домішкового напівпровідника, а функція `F(u, u_b)` має вигляд:

```
F(u, u_b) = √[ (exp(-u) + u - 1) + (n_i / N_A)² · (exp(u) - u - 1) ]
```

Знак поля вибирається від'ємним при `u > 0` (полі збіднення та інверсії спрямоване вглиб напівпровідника) та позитивним при `u < 0` (режим накопичення).

Математичний аналіз чотирьох доданків під коренем функції Кінгстона-Нейштадтера дозволяє точно виділити фізичні режими роботи МДН-структури:

- При `u < 0` (накопичення): домінує доданок `exp(-u)`, електричне поле зростає експоненційно з ростом від'ємної напруги `F_s ∝ exp(|u_s| / 2)`.
- При `0 < u < u_b` (збіднення): домінує лінійний доданок `u`, поле зростає як корінь квадратний `F_s ∝ √u_s`.
- При `u > 2 · u_b` (сильна інверсія): починає домінувати експоненційний доданок `(n_i / N_A)² · exp(u)`, що викликає стрімке підняття поля біля поверхні.

## 3. Обчислення повного поверхневого заряду Q_sc

Згідно з теоремою Гаусса, повний заряд напівпровідника на одиницю площі `Q_sc` дорівнює електричному потоку через межу розділу `x = 0`:

```
Q_sc = -ε_s · F_s = -ε_s · F(u_s)
```

де `u_s = q · ψ_s / (k_B · T)` — безрозмірний поверхневий потенціал.

Остаточний точний вираз для повного заряду напівпровідникової об'ємної області має вигляд:

```
Q_sc = ∓ (√(2 · ε_s · q · N_A · k_B · T / q)) · √[ (exp(-u_s) + u_s - 1) + (n_i / N_A)² · (exp(u_s) - u_s - 1) ]
```

Аналіз внеску кожного доданка показує:
1. `exp(-u_s)` — заряд накопичених дірок на поверхні;
2. `u_s - 1` — заряд нерухомих іонізованих акцепторних іонів у збідненій області;
3. `(n_i / N_A)² · exp(u_s)` — заряд рухомих вільних електронів інверсійного каналу.

## 4. Розділення заряду збіднення Q_d та інверсійного заряду Q_n

Повний заряд `Q_sc` складається з двох фізично різних компонент: непорушного заряду іонізованих домішок збідненої області `Q_d` та заряду вільних електронів інверсійного шару `Q_n`:

```
Q_sc = Q_d + Q_n
```

У наближенні збідненого шару (*depletion approximation*), коли `u_s < 2 · u_b`, інверсійний заряд `Q_n` є нехтовно малим, і заряд визначається виключно іонізованими акцепторами на глибині `W_d`:

```
Q_d = -q · N_A · W_d = -√(2 · ε_s · q · N_A · ψ_s)
```

Максимальна товщина збідненого шару `W_{d,max}` досягається на порозі сильної інверсії (`ψ_s = 2 · ψ_B`):

```
W_{d,max} = √(2 · ε_s · (2 · ψ_B) / (q · N_A))
```

При подальшому зростанні напруги затвора `V_G > V_{th}` поверхневий потенціал `ψ_s` практично насичується на рівні `2 · ψ_B`, а товщина збідненого шару зафіксовується на `W_{d,max}`. Весь додатковий заряд, що індукується затвором, іде на формування рухомого інверсійного заряду `Q_n`.

Точний алгебраїчний розрахунок інверсійного заряду `Q_n` отримують відніманням `Q_d` від повного заряду `Q_sc`:

```
Q_n = Q_sc - Q_d
    = -√(2 · ε_s · q · N_A) · [ √[ ψ_s + (k_B·T / q) · (n_i / N_A)² · exp(q·ψ_s / (k_B·T)) ] - √ψ_s ]
```

У режимі сильної інверсії (`u_s ≥ 2 · u_b`) експоненційний доданок розкладається в ряд, що дає спрощену формулу:

```
Q_n ≈ - (ε_s / (2 · L_D)) · (k_B · T / q) · (n_i / N_A)² · (1 / √u_s) · exp(u_s)
```

Ця формула яскраво демонструє надзвичайно різку (експоненційну) залежність концентрації носіїв інверсійного каналу від найменших змін поверхневого потенціалу `ψ_s`.

## 5. Вивід порогової напруги V_th та рівняння балансу напруг

Рівняння балансу напруг у МДН-структурі пов'язує зовнішню напругу затвора `V_G` із падінням напруги на діелектрику `V_{ox}` та поверхневим потенціалом напівпровідника `ψ_s`:

```
V_G = V_{FB} + V_{ox} + ψ_s
```

де `V_{FB}` — напруга плоских зон (*flatband voltage*), яка враховує різницю робіт виходу металу та напівпровідника `ΔΦ_{MS}`, а також фіксований заряд в оксиді `Q_{ox}`:

```
V_{FB} = ΔΦ_{MS} - (Q_{ox} / C_{ox})
```

тут `C_{ox} = ε_{ox} / d_{ox}` — питома ємність оксиду затвора на одиницю площі.

Згідно з умовою неперервності вектора електричної індукції, заряд на металевому затворі `Q_G` дорівнює за модулем і протилежний за знаком заряду напівпровідника `Q_sc`:

```
V_{ox} = Q_G / C_{ox} = -Q_sc / C_{ox} = -(Q_d + Q_n) / C_{ox}
```

Підставляючи вирази для `V_{ox}` та критерію сильної інверсії `ψ_s = 2 · ψ_B`, коли `Q_n → 0` безпосередньо у точці виникнення каналу, отримуємо точну математичну формулу для **порогової напруги** `V_{th}`:

```
V_{th} = V_{FB} + 2 · ψ_B + (√(2 · ε_s · q · N_A · (2 · ψ_B)) / C_{ox})
```

Для напруг затвора, що перевищують порогову (`V_G > V_{th}`), інверсійний заряд `Q_n` з високою точністю описується формулою планарного конденсатора (наближення зарядового шару, *charge-sheet approximation*):

```
Q_n = -C_{ox} · (V_G - V_{th})
```

Математичний вивід ефекту підкладки (*body effect*) отримують розкладом заряду збіднення `Q_d` при наявності зворотної напруги на підкладці `V_{SB}`:

```
Q_d(V_{SB}) = - √(2 · ε_s · q · N_A · (2·ψ_B + V_{SB}))
```

Підставляючи це значення у рівняння балансу напруг, отримуємо порогову напругу як функцію потенціалу підкладки:

```
V_{th}(V_{SB}) = V_{th0} + γ · [ √(2·ψ_B + V_{SB}) - √(2·ψ_B) ]
```

де параметр `γ = √(2 · ε_s · q · N_A) / C_{ox}` називається коефіцієнтом впливу підкладки (*body effect parameter*). Ця формула слугує фундаментальним вихідним співвідношенням для розрахунку вольт-амперних характеристик усіх сучасних польових транзисторів.
