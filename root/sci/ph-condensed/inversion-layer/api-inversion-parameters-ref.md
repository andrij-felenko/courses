# 📋 Довідник фізичних параметрів та характеристик інверсійного шару в напівпровідниках

Цей довідник містить систематизовані таблиці фундаментальних фізичних параметрів, електростатичних співвідношень та транспортних характеристик інверсійних шарів для ключових напівпровідникових матеріалів (кремнію `Si`, карбіду кремнію `4H-SiC`, нітриду галію `GaN` та арсеніду галію `GaAs`) та їхніх МДН-структур.

Довідник розроблено як фізико-технічне керівництво для розробників напівпровідникових приладів, розрахунку порогових напруг, підзатворних ємностей, електронного розподілу в квантових підзонах та аналізу ефектів деградації поверхневої рухливості носіїв.

## 1. Порівняльна характеристика МДН-структур на основі різних напівпровідників

Вибір матеріалу підкладки та підзатворного діелектрика визначає граничні робочі характеристики польових транзисторів: максимальну напругу пробою, граничну частоту перемикання, струми витоку затвора та температурну стабільність. У наведеній нижче таблиці зібрано експериментальні та теоретичні фізичні параметри інверсійних шарів при кімнатній температурі (`T = 300 K`) для чотирьох провідних напівпровідникових систем.

| Параметр / Матеріал | Si / SiO₂ (100) | 4H-SiC / SiO₂ (0001) | GaN / Al₂O₃ (0001) | GaAs / Al₀.₃Ga₀.₇As |
| :--- | :--- | :--- | :--- | :--- |
| **Ширина забороненої зони E_g (еВ)** | 1.12 | 3.26 | 3.44 | 1.42 |
| **Відносна проникність ε_r** | 11.7 | 9.7 | 8.9 | 12.9 |
| **Власна концентрація n_i (см⁻³)** | 1.5 × 10¹⁰ | 5.0 × 10⁻⁹ | 1.9 × 10⁻¹⁰ | 2.1 × 10⁶ |
| **Потенціал інверсії 2ψ_B при N_A=10¹⁶ см⁻³ (В)** | 0.71 | 2.52 | 2.68 | 0.98 |
| **Бар'єр зони провідності ΔE_c (еВ)** | 3.15 | 2.70 | 2.10 | 0.30 |
| **Густість поверхневих станів D_it (см⁻² еВ⁻¹)** | 10¹⁰ – 10¹¹ | 10¹² – 10¹³ | 10¹¹ – 10¹² | 10¹² – 10¹³ |
| **Об'ємна рухливість електронів μ_n (см²/(В·с))** | 1450 | 900 | 1200 | 8500 |
| **Поверхнева рухливість в інверсії μ_inv (см²/(В·с))** | 450 – 650 | 20 – 40 | 100 – 170 | 1500 – 3000 |
| **Ефективна маса поздовжнього руху m_l* / m₀** | 0.98 | 0.48 | 0.20 | 0.067 |
| **Ефективна маса поперечного руху m_t* / m₀** | 0.19 | 0.36 | 0.20 | 0.067 |
| **Фактор долинового виродження g_v (поверхня 100)** | 2 (нижня) / 4 | 1 | 1 | 1 |
| **Критичне поле пробою оксиду E_bd (МВ/см)** | 10 – 12 | 8 – 10 | 6 – 8 | 3 – 5 |

Фізичний аналіз показує фундаментальну перевагу класичної кремнієвої системи `Si/SiO₂`. Завдяки унікальній хімічній сумісності термічного діоксиду кремнію з підкладкою кремнію, густість ненасичених обірваних зв'язків зменшується до рекордно низького рівня `D_{it} ~ 10¹⁰ см⁻² еВ⁻¹`. Потенціальний бар'єр у зоні провідності `ΔE_c = 3.15 еВ` є настільки високим, що квантове тунелювання електронів через оксид товщиною понад `2 нм` є практично відсутнім.

Натомість широкозонні напівпровідники — карбід кремнію `4H-SiC` та нітрид галію `GaN` — володіють гігантською шириною забороненої зони (`E_g > 3.2 еВ`) та високими пробійними полями (`E_{bd} > 3 МВ/см`). Вони є ідеальними матеріалами для силової електроніки високої напруги. Однак формування оксидного діелектрика на карбіді кремнію супроводжується накопиченням вуглецевих кластерів та виникненням високої густості пасток `D_{it} ~ 10¹² – 10¹³ см⁻² еВ⁻¹`. Ці пастки інтенсивно захоплюють електрони інверсійного каналу, знижуючи поверхневу рухливість до низьких значень `μ_{inv} ≈ 20 – 40 см²/(В·с)`. Для пасивації таких пасток у промисловості застосовують спеціальний високотемпературний відпал у атмосфері закису азоту `N₂O` або аміаку `NH₃`.

Прямозонний напівпровідник арсенід галію `GaAs` демонструє астрономічну об'ємну рухливість електронів `8500 см²/(В·с)` завдяки малій ефективній масі `m* = 0.067 · m₀`. Проте оксиди галію та арсену є хімічно нестабільними, через що на межі з діелектриком виникає сильна зафіксованість рівня Фермі (*Fermi level pinning*). Замість МДН-структур із проводимим інверсійним шаром для `GaAs` використовують гетероструктурні транзистори з високою рухливістю електронів (HEMT), де канал створюється шляхом модуляційного допування на межі `GaAs/AlGaAs`.

## 2. Електростатичний розрахунок МДН-структури у наближенні зарядового шару

Наближення зарядового шару (*charge-sheet approximation*) виходить із припущення, що товщина інверсійного шару є значно меншою за товщину збідненої області `z_{inv} ≪ W_d`, що дозволяє розглядати інверсійні електрони як двовимірний плоский заряд `Q_n`, локалізований безпосередньо на інтерфейсі `x = 0`.У наведеній нижче таблиці систематизовано фундаментальні розрахункові формули електростатики МДН-структури.

| Фізична величина | Математична формула | Детальний опис та фізичний зміст |
| :--- | :--- | :--- |
| **Питома ємність оксиду C_ox** | `C_{ox} = ε_{ox} / d_{ox}` | Питома ємність плоского підзатворного конденсатора (`ε_{ox} = 3.9 · ε₀`) |
| **Потенціал об'єму ψ_B** | `ψ_B = (k_B·T / q) · ln(N_A / n_i)` | Потенціальне зміщення від рівня Фермі `E_F` до власного рівня `E_i` у глибині кристала |
| **Поріг сильної інверсії ψ_s,th** | `ψ_{s,th} = 2 · ψ_B` | Поверхневий потенціал, при якому концентрація електронів на поверхні `n_s(0) = N_A` |
| **Максимальна ширина збіднення W_d,max** | `W_{d,max} = √(2·ε_s·(2ψ_B) / (q·N_A))` | Гранична просторова ширина розширення заряду іонізованих акцепторів |
| **Максимальний заряд збіднення Q_d,max** | `Q_{d,max} = -√(2·ε_s·q·N_A·(2ψ_B))` | Інтегральний заряд непорушних іонів акцептора на одиницю площі |
| **Напруга плоских зон V_FB** | `V_{FB} = ΔΦ_{MS} - (Q_{ox} / C_{ox})` | Напруга затвора, при якій поле в напівпровіднику відсутнє (`ψ(x) = 0`) |
| **Порогова напруга V_th** | `V_{th} = V_{FB} + 2ψ_B + (|Q_{d,max}| / C_{ox})` | Мінімальна зовнішня напруга затвора для виникнення проводимого інверсійного каналу |
| **Заряд інверсійного шару Q_n** | `Q_n = -C_{ox} · (V_G - V_{th})` | Поверхнева густість індукованого заряду електронів у режимі `V_G > V_{th}` |
| **Поверхнева концентрація n_s** | `n_s = |Q_n| / q = (C_{ox} / q) · (V_G - V_{th})` | Кількість рухомих електронів інверсійного каналу на один квадратний сантиметр |
| **Ефективна товщина каналу z_inv** | `z_{inv} ≈ 3 · (ε_s·k_B·T / (2·q·|Q_{sc}|))` | Просторова товщина шарчика, в якому локалізовано 90% інверсійного заряду |

Розрахунок порогової напруги `V_{th}` є критично важливим етапом проектування цифрових та аналогових мікросхем. У реальних МДН-транзисторах напруга плоских зон `V_{FB}` відхиляється від ідеального значення через наявність позитивного фіксованого заряду в оксиді `Q_f ~ 10¹⁰ – 10¹¹ см⁻²`, який утворюється нестачі кисню біля інтерфейсу `Si/SiO₂`. Цей позитивний заряд зміщує порогову напругу n-канального MOSFET у бік від'ємних значень, що може перетворити транзистор із збагачувального на збіднювальний. Для точного налаштування порогової напруги у сучасних технологічних процесах застосовують іонну імплантацію борu або фосфору безпосередньо у канальну область підкладки.

## 3. Математичні моделі деградації поверхневої рухливості в інверсійному каналі

Поверхнева рухливість електронів `μ_{inv}` у проводимому інверсійному каналі є значно нижчою за об'ємну рухливість `μ_n` у монокристалічному напівпровіднику. Головною причиною деградації є наявність поперечного електричного поля затвора `F_{eff}`, яке притискає рухомі електрони до шорсткої межі розділу `Si/SiO₂`.

Відповідно до феноменологічного правила Маттіссена, результуюча ефективна рухливість виражається як обернена сума трьох незалежних механізмів розсіювання:

```
1 / μ_{inv} = 1 / μ_{ph} + 1 / μ_{sr} + 1 / μ_{C}
```

де кожна з трьох компонент описується окремими фізико-математичними залежностями:

### 3.1. Поверхневе фононне розсіювання (μ_ph)
Поверхневе фононне розсіювання викликане взаємодією носіїв заряду з акустичними та оптичними фононами кристалічної ґратки в умовах двовимірного просторового обмеження. На відміну від об'ємного напівпровідника, де фононне розсіювання залежить лише від температури `T`, у проводимому каналі воно зростає зі збільшенням поперечного поля `F_{eff}` через ущільнення електронної хвильової функції біля поверхні:

```
μ_{ph} = B_0 · T⁻¹ · F_{eff}^{-1/3}
```

де `B_0` — константа матеріалу (`B_0 ≈ 3.2 × 10⁵ см^{4/3}/(В^{2/3}·с·К)` для кремнію). Підвищення температури підсилює теплове коливання атомів ґратки, що приводить до падіння фононної рухливості пропорційно `T⁻¹.⁵`.

### 3.2. Розсіювання на шорсткостях межі розділу (μ_sr)
Межа розділу між аморфним діоксидом кремнію та монокристалічним кремнієм не є ідеально планарною атомарною площиною. Вона містить флуктуації висоти (ступеньки та атомні горбики), які описуються середньоквадратичним відхиленням `Δ ≈ 0.2 – 0.4 нм` та довжиною кореляції `L ≈ 1.5 – 3.0 нм`. Коли електрони рухаються у вузькому каналі під дією сильного поперечного поля, флуктуації товщини ями створюють хаотичні потенціальні збурення. Цей механізм домінує у сильних електричних полях (`F_{eff} > 0.5 МВ/см`):

```
μ_{sr} = C_0 · (Δ · L)⁻² · F_{eff}⁻²
```

Стрімка залежність від квадрата поля `F_{eff}⁻²` викликає різке зниження крутизни вольт-амперної характеристики транзистора при великих напругах на затворі.

### 3.3. Кулонівське розсіювання на заряджених центрах (μ_C)
Викликане розсіюванням рухомих носіїв на іонізованих поверхневих пастках `D_{it}`, іонах домішок підкладки `N_A` та фіксованому заряді оксиду `Q_{ox}`. Цей механізм домінує при низьких концентраціях електронів у каналі (поблизу порогової напруги `V_th`), коли кулонівські центри є слабко екранованими:

```
μ_{C} = A_0 · (n_s / N_{tc})^{α} · (T / 300)^{β}
```

де `N_{tc} = Q_{ox}/q + D_{it}·k_B T` — сумарна щільність заряджених центрів на інтерфейсі, `α ≈ 0.5 – 1.0`.Зі зростанням напруги затвора концентрація вільних електронів `n_s` стрімко зростає, що приводить до колективного екранування кулонівських центрів і ослаблення розсіювання `μ_C`.

### 3.4. Визначення ефективного поперечного поля F_eff
Ефективне електричне поле `F_{eff}`, що діє на електрони в інверсійній ямі, розраховується як висереджене поле за правилом Саха (*Sabnis-Clemens rule*):

```
F_{eff} = (1 / ε_s) · ( |Q_d| + η · |Q_n| )
```

де параметр висередження `η = 1/2` для електронів у кремнії орієнтації (100) та `η = 1/3` для дірок.

## 4. Квантові підзони та анізотропія ефективних мас у Si(100), Si(110) та Si(111)

Зона провідності кремнію має 6 еквівалентних мінімумів (долин), розташованих уздовж осей `<100>` зворотного простору. При формуванні потенціальної ями інверсійного шару симетрія кристала порушується, що викликає зняття долинового виродження та розщеплення енергетичного спектра на систему підзон.

У наведеній таблиці зібрано параметри квантованих підзон для трьох головних орієнтацій кремнієвих пластин.

| Орієнтація поверхні | Система підзон | Маса квантування m_x* | Планарна маса транспорту m_d* | Долинове виродження g_v | Енергія дна підзони E₀ |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Si (100)** | Unprimed (E₀) | `m_l* = 0.91·m₀` (важка) | `m_t* = 0.19·m₀` (легка) | 2 | Найнижча (заселена на 85%) |
| **Si (100)** | Primed (E₀') | `m_t* = 0.19·m₀` (легка) | `√(m_l*·m_t*) = 0.42·m₀` | 4 | Вища на `40–80 мЕв` |
| **Si (110)** | Unprimed (E₀) | `m_t* = 0.19·m₀` (легка) | `m_l* = 0.91·m₀` (важка) | 4 | Вища ніж у Si(100) |
| **Si (111)** | Single system | `0.32·m₀` | `0.36·m₀` | 6 | Однакова для всіх долин |

Аналіз підзон пояснює, чому орієнтація Si(100) є золотим стандартом для створення n-канальних MOSFET. Для поверхні (100) дві долини орієнтовані важкою масою `m_x* = 0.91 · m₀` перпендикулярно до поверхні. Завдяки високій масі квантування енергія нульових коливань `E₀ ∝ (m_x*)⁻¹/³` виявляється найнижчою серед усіх підзон. При кімнатній температурі понад 85% електронів заселяють саме цю нижню підзону `E₀`. Важливо, що в площині каналу ці електрони мають легку маса транспорту `m_d* = 0.19 · m₀`, що забезпечує максимальну дрейфову рухливість та максимальний струм стоку.

Натомість для p-канальних транзисторів (p-MOSFET) орієнтація Si(110) забезпечує на 50–70% вищу рухливість дірок порівняно з Si(100) за рахунок деформації валентної зони та розщеплення зон легких і важких дірок. Це використовується у технології 3D FinFET, де бічні стінки вертикальних ребер мають орієнтацію (110).

## 5. Класифікація фізичних режимів приповерхневої області

Для систематизації стану МДН-структури при різних напругах затвора виділяють 6 базових режимів, які відрізняються значенням поверхневого потенціалу `ψ_s`, напругою затвора `V_G` та співвідношенням між концентраціями носіїв.

| Режим роботи | Умова за потенціалом ψ_s | Умова за напругою V_G | Концентрації носіїв на поверхні | Характерний опис |
| :--- | :--- | :--- | :--- | :--- |
| **Накопичення (Accumulation)** | `ψ_s < 0` | `V_G < V_{FB}` | `p_s > N_A`, `n_s ≪ n_i` | Основні носії (дірки) притягуються до поверхні |
| **Плоскі зони (Flatband)** | `ψ_s = 0` | `V_G = V_{FB}` | `p_s = N_A`, `n_s = n_i² / N_A` | Поле в напівпровіднику відсутнє |
| **Збіднення (Depletion)** | `0 < ψ_s < ψ_B` | `V_{FB} < V_G < V_{mid}` | `p_s < N_A`, `n_s < n_i` | Основні носії відштовхнуті, утворено заряд `Q_d` |
| **Слабка інверсія (Weak Inversion)** | `ψ_B ≤ ψ_s < 2ψ_B` | `V_{mid} ≤ V_G < V_{th}` | `n_i ≤ n_s < N_A` | `n_s > p_s`, виникає підпороговий струм |
| **Поріг інверсії (Threshold)** | `ψ_s = 2ψ_B` | `V_G = V_{th}` | `n_s = N_A` | Поверхнева концентрація електронів дорівнює `N_A` |
| **Сильна інверсія (Strong Inversion)** | `ψ_s ≥ 2ψ_B` | `V_G > V_{th}` | `n_s ≫ N_A` | Утворено високопровідний n-канал електронів |

Кожен із наведених режимів має власне практичне застосування в мікроелектроніці. Режим накопичення використовують у варікапах (ємностях, керованих напругою). Режим збіднення відповідає роботі запертих каналів у сипових транзисторах. Слабка інверсія є робочим режимом для наднизькоспоживаючих аналогових та нейроморфних мікросхем, де транзистори працюють при напругах, менших за порогову. Режим сильної інверсії слугує основним робочим станом відкритих ключів у всіх цифрових обчислювальних процесорах, контролерах та пам'яті.
