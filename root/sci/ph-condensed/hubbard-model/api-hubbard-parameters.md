# 📋 Довідник параметрів t, U та матеріалознавчих характеристик корельованих систем

Без точних числових значень міжатомних та електронних параметрів абстрактний Гамільтоніан Габбарда залишається теоретичною конструкцією, що позбавляє фізика можливості передбачити реальний фазовий стан матеріалу. Цей довідник розв'язує задачу кількісної параметризації сильнокорельованих систем, надаючи систематизовані числові значення фізичних параметрів Гамільтоніана Габбарда (стрибковий інтеграл `t`, вузлове кулонівське відштовхування `U`, міжвузловий обмін `J`, ширина зони `W`), величини мотт-габбардівської щілини та критичні температури для оксидів 3d-металів, купратних надпровідників, органічних провідників та світлових ґраток.

---

### 1. Методологія визначення та спектроскопічного вимірювання параметрів

Параметри Гамільтоніана Габбарда не є абстрактними математичними коефіцієнтами: вони прямо відповідають вимірюваним міжатомним та електронним характеристикам твердих тіл. Для витягнення числових значень `t` та `U` у реальних матеріалах застосовують комплекс експериментальних спектроскопічних методик та чисельних розрахунків з перших принципів:

1. **Фотоелектронна спектроскопія з кутовим розділенням (ARPES) та фотоемісія (XPS/BIS):**
   Ультрафіолетова та рентгенівська фотоемісійна спектроскопія (XPS) вимірює спектральну густину заповнених електронних станів нижньої зони Габбарда (LHB), вибиваючи електрони з кристала. Інверсна фотоемісія (BIS) додає електрон у незаповнені стани верхньої зони Габбарда (UHB). Відстань між енергетичними максимумами у спектрах XPS та BIS дає пряме значення кулонівського відштовхування `U`. Кутова фотоемісія (ARPES) дозволяє виміряти дисперсію `ε(k)` та ширину зони `W = 2 z t`, звідки розраховується стрибковий інтеграл `t`.

2. **Оптична спектроскопія та еліпсометрія:**
   Вимірювання коефіцієнта оптичного поглинання та коефіцієнта заломлення в інфрачервоному та видимому діапазонах дає змогу точно зафіксувати поріг міжзонних оптичних переходів — фундаментальну діелектричну щілину `E_g`. Знаючи ширину зон `W`, з оптичних даних отримують `U ≈ E_g + W`.

3. **Магнітна сприйнятливість та неупруге розсіяння нейтронів (INS):**
   Температурна залежність статичної магнітної сприйнятливості `χ(T)` вище температури Нееля дає змогу оцінити ефективний обмінний інтеграл `J` за допомогою високотемпературних розкладів. Неупруге розсіяння нейтронів на спінових хвилях (магнонах) у впорядкованій антиферомагнітній фазі дозволяє виміряти повну магнонну дисперсію, з якої за формулою спинової хвилі `E_mag(q) = 2 J z S sin(q a)` прямо обчислюється `J = 4 t² / U`.

4. **Теорія функціонала густини з урахуванням кулонівського корективу (DFT+U, GW+DMFT):**
   У теоретичних розрахунках квантової хімії та фізики твердого тіла для опису корельованих орбіталей застосовують метод локальної густини з додаванням одновузлового Кулона (LDA+U або DFT+U). Значення `U` розраховується самоузгоджено за допомогою методу затиснутої випадкової фази (cRPA), який враховує екранування кулонівського поля іншими незв'язаними s- та p-електронами кристала.

### 2. Оксиди перехідних металів (Класичні мотт-габбардівські та чарж-трансферні ізолятори)

У монооксидах перехідних металів 3d-групи кулонівське відштовхування між d-електронами на тому самому катіоні металу становить `U ~ 5–8 еВ`, тоді як перекриття 3d-орбіталей є малим, що дає вузьку ширину зони `W ~ 2–3 еВ`.

Згідно з класифікацією Заанена — Саватоцького — Аллена (Zaanen-Sawatzky-Allen, ZSA), ізоляційні властивості оксидів поділяють на два фундаментальні класи залежно від співвідношення між кулонівським штрафом `U` та енергією перенесення заряду `Δ_CT` з 2p-орбіталей аніона кисню на 3d-орбіталь металу:

- **Строгі Мотт-Габбардівські ізолятори (`U < Δ_CT`):** Найнижчим за енергією збудженням є перенесення електрона між d-орбіталями сусідніх катіонів металу (`d_i^n d_j^n → d_i^{n-1} d_j^{n+1}`). Величина забороненої щілини визначається кулонівським відштовхуванням `E_g ≈ U - W`. До цього класу належать оксиди ванадію та титану (`V₂O₃`, `LaVO₃`, `Ti₂O₃`).
- **Ізолятори з перенесенням заряду (Charge-Transfer insulators, `Δ_CT < U`):** Кулонівське відштовхування d-електронів є настільки величезним (`U > 6–8 еВ`), що найнижчим за енергією збудженням є перескок електрона з заповненої 2p-оболонки кисню `O²⁻` на d-оболонку металу (`d^n p^6 → d^{n+1} p^5`). Заборонена щілина визначається енергією перенесення заряду `E_g ≈ Δ_CT - W/2`. До цього класу належать оксиди нікелю, кобальту та міді (`NiO`, `CoO`, `CuO`).

### 3. Високотемпературні купратні надпровідники (2D плоскості CuO₂)

Електронні властивості купратних надпровідників визначаються двовимірними квадратними сітками `CuO₂`. Мікроскопічний опис цих площин здійснюється **трьохзонною моделлю Емері** (*Emery 3-band model*), яка враховує d-орбіталі міді `Cu 3d_{x²-y²}` та p-орбіталі кисню `O 2p_x, 2p_y`.

При розгляді низькоенергетичних збуджень поблизу рівня Фермі трьохзонна модель строго зводиться до **ефективної однозонної моделі Габбарда**. Дірка, що додається на орбіталь кисню, зв'язується зі спіном катіона міді `Cu²⁺` у синглетний стан Жанга — Райса (*Zhang-Rice singlet*), який пересувається по ґратці як єдиний квазічастинковий носій заряду з ефективним стрибковим інтегралом `t`.

Відношення `|t'/t|` контролює форма поверхні Фермі та визначає ступінь спінової фрустрації. Збільшення `|t'/t|` руйнує ідеальний нестінг поверхні Фермі та пригнічує антиферомагнітний порядок, сприяючи розширенню надпровідного купола.

### 4. Органічні моттівські ізолятори (Квазі-2D молекулярні кристали)

Органічні провідники на основі катіон-радикальних солей тетратіафульвалену `κ-(BEDT-TTF)₂X` (де `X` — неорганічний аніон `Cu[N(CN)₂]Cl`, `Cu[N(CN)₂]Br` або `Cu₂(CN)₃`) являють собою унікальні модельні системи для вивчення фазового переходу Мотта.

У цих кристалах роль окремого «атома» відіграє димер із двох паралельних молекул `(BEDT-TTF)₂`. Димери утворюють шарувату двовимірну ґратку зі складано-трикутною або майже ідеальною трикутною топологією. Головна перевага органічних мотт-систем полягає у тому, що відстані між димерами та ширина зони `W` легко змінюються за допомогою зовнішнього гідростатичного тиску `p` або ізоморфної хімічної заміни аніона `X`.

| Органічний кристал | Геометрія ґратки | t (меВ) | t' / t (фрустрація) | U (меВ) | U / W | Стан при тиску p = 1 атм | Критичний тиск переходу p_c |
|---|---|---|---|---|---|---|---|
| **κ-(BEDT-TTF)₂Cu[N(CN)₂]Cl** | Складано-трикутна | 45 | 0.75 | 480 | 1.10 | AFM Ізолятор Мотта | 300 бар → Надпровідник (T_c = 12.8 K) |
| **κ-(BEDT-TTF)₂Cu[N(CN)₂]Br** | Складано-трикутна | 47 | 0.68 | 450 | 0.95 | Корельований надпровідник | 1 атм (Уже в надпровідній фазі T_c = 11.6 K) |
| **κ-(BEDT-TTF)₂Cu₂(CN)₃** | Почти ідеальна трикутна| 50 | 0.96 | 420 | 1.05 | Квантова спінова рідина (QSL) | 4 кбар → Надпровідник (T_c = 6 K) |

> 📌 **Парадокс квантової спінової рідини:** У сполуці `κ-(BEDT-TTF)₂Cu₂(CN)₃` відношення `t'/t ≈ 0.96` означає майже ідеальну геометричну фрустрацію спінів на трикутній ґратці. Незважаючи на мотт-ізоляторний стан (`U/W > 1`) та значний антиферомагнітний обмін `J ≈ 250 K`, геометрична фрустрація повністю заважає формуванню антиферомагнітного порядку впритул до найнижчих температур `T < 20 мК`. Система перебуває в особливому стані квантової спінової рідини (Quantum Spin Liquid).

### 5. Квантові симулятори: Ультрахолодні фермі-гази в оптичних ґратках

Квантові симулятори на основі ультрахолодних нейтральних атомів у світлових ґратках дозволяють реалізувати Гамільтоніан Габбарда у «чистому вигляді» — без дефектів кристалографічної ґратки, фононних коливань та примесей.

#### 1. Фундаментальні фізико-математичні формули зв'язку

- **Енергія віддачі фотона (Recoil Energy `E_R`):**
  При поглинанні або випромінюванні фотона з хвильовим вектором `k = 2π / λ` атом маси `m` отримує енергію віддачі:
```
E_R = (ℏ² k²) / (2 m) = (2 π² ℏ²) / (m λ²)
```
де `λ` — довжина хвилі лазерних променів, що формують оптичну ґратку.

- **Стрибковий інтеграл `t` (тунелювання між світловими ямами):**
  У глибокому світловому потенціалі `V(r) = V_0 ∑_i sin²(k x_i)` глибина ями виражається у безрозмірних одиницях віддачі `s = V_0 / E_R`. Апроксимаційне виведення для квазікласичного тунелювання дає:
```
t / E_R ≈ (4 / √π) · s^(3/4) · exp( - 2 · √s )
```

- **Одновузлове контактне кулонівське відштовхування `U`:**
  Оскільки взаємодія між нейтральними атомами при низьких енергіях є короткосяжною (s-хвильове розсіяння з довжиною `a_s`), кулонівський штраф виражається через просторове інтегрування основної моди гармонічного осцилятора у ямі:
```
U / E_R = √(8 / π) · k · a_s · s^(3/4)
```

- **Керування взаємодією через резонанс Фано — Фешбаха:**
  Зовнішнє постійне магнітне поле `B` змінює енергію зв'язаного молекулярного стану відносно стану двох вільних атомів. Довжина розсіювання `a_s` регулюється за формулою:
```
a_s(B) = a_bg · [ 1 - ΔB / (B - B_0) ]
```
де `a_bg` — фонова довжина розсіювання, `B_0` — магнітне поле резонансу, `ΔB` — ширина резонансу.

### 6. Критичні межі фазових переходів у моделі Габбарда

Нижче наведено зведені значення критичних точок та фазових меж для моделі Габбарда залежно від геометрії ґратки та розмірності простору:

1. **Одновимірна ґратка (1D chain, n = 1):**
   Точний розв'язок Ліба — Ву за допомогою анзацу Бете свідчить, що мотт-габбардівська щілина `E_g > 0` виникає при будь-якому від'ємному чи позитивному `U > 0`. Одновимірний стан є мотт-ізолятором при довільно слабкій взаємодії. Щілина демонструє асимптотику:
```
E_g(U → 0) ≈ (8 / π) · √(t U) · exp( - 2π t / U )
```

2. **Двовимірна квадратна ґратка (2D square lattice, n = 1):**
   Завдяки нестінгу поверхні Фермі (`ε(k + Q) = -ε(k)` для `Q = (π/a, π/a)`) спінова антиферомагнітна сприйнятливість логарифмічно розбігається при `T → 0`. Перехід до антиферомагнітного мотт-ізолятора відбувається при `U > 0`, проте кросовер від слабких спінових флуктуацій до локалізованих моттівських моментів здійснюється при `U_c ≈ W = 8t`.

3. **Тривимірна кубічна ґратка (3D simple cubic, n = 1):**
   Перехід Мотта — Габбарда є справжнім термодинамічним фазовим переходом 1-го роду. Розрахунки методом теорії динамічного середнього поля (DMFT) та квантового Монте-Карло дають критичне значення для парамагнітного мотт-переходу при абсолютному нулю:
```
(U / t)_c ≈ 14.3   (або U_c / W ≈ 1.19)
```
Нижче цієї межі система перебуває у стані металу Фермі-рідини, вище — у стані мотт-габбардівського ізолятора.
