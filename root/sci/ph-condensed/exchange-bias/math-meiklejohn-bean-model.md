# 🧮 Феноменологічна модель Мейклджона — Біна та математичний вивід поля зміщення

Ця вставка розв'язує задачу кількісного математичного опису ефекту обмінного зміщення шляхом виводу феноменологічної моделі Мейклджона — Біна (*Meiklejohn-Bean model*) для двошарової плівкової системи феромагнетик / антиферомагнетик (FM/AFM). Необхідність цього виводу виникла тому, що без формалізації енергетичного рельєфу та умов кутової рівноваги спінів неможливо аналітично розрахувати поле зміщення `H_EB`, коерцитивні поля `H_c1` і `H_c2` та критичну товщину антиферомагнетика `t_AFM^c`, за якої закріплення руйнується. У матеріалі детально виведено рівняння повної магнітної енергії одиниці площі, знайдено умови кутової рівноваги спінових підґраток, обчислено межі жорсткого закріплення та розглянуто поправку Малоземова для невпорядкованих інтерфейсів з атомарною шорсткістю.

---

### 1. Повний енергетичний потенціал двошарової структури FM/AFM

Розглянемо двошарову гетероструктуру, що складається з феромагнітного шару (FM) товщиною `t_FM` із насиченою намагніченістю `M_FM` та антиферомагнітного шару (AFM) товщиною `t_AFM`.

Припустимо, що перемагнічування феромагнетика відбувається шляхом однорідного обертання вектора намагніченості у площині плівки (модель Стонера — Вольфарта). Введемо кутові змінні у площині плівки відносно осі термомагнітного оброблення (вісі `H_FC`):
- `θ` — кут між вектором намагніченості FM `M_FM` та віссю `H_FC`.
- `ϕ` — кут між вектором підґратки нескомпенсованих спінів AFM на інтерфейсі та віссю `H_FC`.
- `ψ` — кут між напрямком зовнішнього вимірювального магнітного поля `H` та віссю `H_FC`.

```
                          Вісь охолодження H_FC
                                 ^
                                 |  / Вектор M_FM (кут θ)
                                 | /
                                 |/___ Вектор спінів AFM (кут ϕ)
                                 +------------------------>
```

Повна магнітна енергія одиниці площі гетероструктури `E` (вимірювана у Дж/м² у системі SI або erg/cm² у системі СГС) включає чотири основні енергетичні внески:

1. **Зеєманівська енергія** взаємодії намагніченості феромагнетика із зовнішнім полем `H`:
   `E_Z = - H · M_FM · t_FM · cos(θ - ψ)`

2. **Енергія одноосьової магнітно-кристалічної анізотропії** феромагнетика з константою об'ємної анізотропії `K_FM`:
   `E_K_FM = K_FM · t_FM · sin²(θ)`

3. **Енергія одноосьової магнітно-кристалічної анізотропії** антиферомагнетика з константою об'ємної анізотропії `K_AFM`:
   `E_K_AFM = K_AFM · t_AFM · sin²(ϕ)`

4. **Енергія міжфазної обмінної взаємодії** на одиницю площі інтерфейсу між спінами FM та незакомплексованими спінами AFM з константою поверхневого обміну `J_EB`:
   `E_int = - J_EB · cos(θ - ϕ)`

Об'єднуючи усі чотири доданки, отримуємо повну енергетичну функцію одиниці площі:

```
E(θ, ϕ) = - H · M_FM · t_FM · cos(θ - ψ) + K_FM · t_FM · sin²(θ) 
          + K_AFM · t_AFM · sin²(ϕ) - J_EB · cos(θ - ϕ)
```

Для спрощення математичного аналізу розглянемо випадок поздовжнього поля, коли вимірювальне поле `H` прикладене вздовж осі охолодження (`ψ = 0`):

```
E(θ, ϕ) = - H · M_FM · t_FM · cos(θ) + K_FM · t_FM · sin²(θ) 
          + K_AFM · t_AFM · sin²(ϕ) - J_EB · cos(θ - ϕ)
```

### 2. Рівноважний стан спінів антиферомагнетика та кутове рівняння

Спінова підґратка антиферомагнетика на інтерфейсі займає кутову орієнтацію `ϕ`, яка відповідає мінімуму повної енергії за змінною `ϕ` при заданому стані феромагнетика `θ`:

```
∂E / ∂ϕ = 0
```

Виконуємо диференціювання функції `E(θ, ϕ)` за кутом `ϕ`:

```
∂E / ∂ϕ = K_AFM · t_AFM · 2 · sin(ϕ) · cos(ϕ) - J_EB · sin(θ - ϕ)
```

Використовуючи тригонометричну тотожність `2 · sin(ϕ) · cos(ϕ) = sin(2·ϕ)`, отримуємо фундаментальне рівняння кутової рівноваги спінів AFM:

```
K_AFM · t_AFM · sin(2·ϕ) = J_EB · sin(θ - ϕ)      [рівняння рівноваги AFM]
```

Фізичний зміст цього рівняння полягає у балансі двох моментів сил:
- Права частина `J_EB · sin(θ - ϕ)` являє собою обмінний обертальний момент, який прагне розвернути спіни AFM за вектором намагніченості феромагнетика `M_FM`.
- Ліва частина `K_AFM · t_AFM · sin(2·ϕ)` являє собою утримуючий обертальний момент анізотропії антиферомагнетика, який прагне втримати спіни AFM уздовж легкої осі (`ϕ = 0` або `ϕ = π`).

### 3. Режим жорсткого антиферомагнетика та вивід формули Мейклджона — Біна

Розглянемо випадок, коли анізотропія антиферомагнетика або його товщина є достатньо великими, тобто виконується умова **жорсткого закріплення**:

```
K_AFM · t_AFM >> J_EB
```

У цьому випадку максимальний утримуючий момент анізотропії `K_AFM · t_AFM` суттєво перевищує будь-який обмінний момент `J_EB`. Це означає, що при будь-яких розворотах вектор намагніченості FM кут відхилення спінів AFM залишається малим (`ϕ ≈ 0`).

Підставляємо значення `ϕ = 0` у вихідну формулу повної енергії `E(θ, ϕ)`:

```
E(θ) = - H · M_FM · t_FM · cos(θ) + K_FM · t_FM · sin²(θ) - J_EB · cos(θ)
```

Об'єднуємо доданки при `cos(θ)`:

```
E(θ) = - (H · M_FM · t_FM + J_EB) · cos(θ) + K_FM · t_FM · sin²(θ)
```

Винесемо множник `M_FM · t_FM` за дужки у зеєманівському доданку:

```
E(θ) = - M_FM · t_FM · (H + J_EB / (M_FM · t_FM)) · cos(θ) + K_FM · t_FM · sin²(θ)
```

Введемо поняття **ефективного магнітного поля** `H_eff`:

```
H_eff = H + H_EB
```

де **поле обмінного зміщення** `H_EB` визначається класичною формулою Мейклджона — Біна:

```
H_EB = J_EB / (M_FM · t_FM)      [формула Мейклджона — Біна]
```

Знак поля зміщення залежить від орієнтації закріплених спінів. Оскільки для мінімізації інтерфейсної енергії закріплені спіни орієнтовані вздовж поля охолодження `H_FC` (`ϕ = 0`), при від'ємному зовнішньому полі `H < 0` обмінна енергія прагне розвернути FM назад у стан `θ = 0`. В результаті ефективне поле зміщення входить у рівняння зі знаком мінус, зсуваючи петлю гістерезису в область від'ємних полів.

#### Розрахунок коерцитивних полів перемагнічування
Знайдемо критичні поля, при яких вектор намагніченості феромагнетика втрачає стійкість. Для цього обчислимо другу похідну енергії за кутом `θ`:

```
∂E / ∂θ = (H · M_FM · t_FM + J_EB) · sin(θ) + 2 · K_FM · t_FM · sin(θ) · cos(θ)
```

Прирівнюючи першу похідну до нуля (`∂E / ∂θ = 0`), отримуємо два тривіальні стани рівноваги:
- `θ = 0` (намагніченість уздовж поля охолодження).
- `θ = π` (намагніченість проти поля охолодження).

Стан `θ = 0` втрачає стійкість, коли друга похідна `∂²E / ∂θ²` змінює знак із плюса на мінус:

```
∂²E / ∂θ² = (H · M_FM · t_FM + J_EB) · cos(θ) + 2 · K_FM · t_FM · cos(2·θ)
```

1. **Ліве коерцитивне поле `H_c1` (перехід `θ: 0 → π`):**
   Підставляємо `θ = 0` у умову втрати стійкості `∂²E / ∂θ² = 0`:

   ```
   (H_c1 · M_FM · t_FM + J_EB) · (1) + 2 · K_FM · t_FM · (1) = 0
   ```

   Розв'язуємо відносно `H_c1`:

   ```
   H_c1 = - (2 · K_FM / M_FM) - (J_EB / (M_FM · t_FM))
   ```

2. **Праве коерцитивне поле `H_c2` (перехід `θ: π → 0`):**
   Підставляємо `θ = π` у умову втрати стійкості `∂²E / ∂θ² = 0`:

   ```
   (H_c2 · M_FM · t_FM + J_EB) · (-1) + 2 · K_FM · t_FM · (1) = 0
   ```

   Розв'язуємо відносно `H_c2`:

   ```
   H_c2 = + (2 · K_FM / M_FM) - (J_EB / (M_FM · t_FM))
   ```

#### Параметри петлі гістерезису
Використовуючи знайдені поля `H_c1` та `H_c2`, обчислимо характеристичні параметри петлі:

- **Горизонтальний зсув петлі (Поле обмінного зміщення):**

  ```
  H_EB = (H_c1 + H_c2) / 2 = - J_EB / (M_FM · t_FM)
  ```

- **Коерцитивна сила (Півширина петлі):**

  ```
  H_c = (H_c2 - H_c1) / 2 = 2 · K_FM / M_FM
  ```

З цих виводів чітко видно дві ключові особливості моделі Мейклджона — Біна:
1. Поле зміщення `H_EB` строго обернено пропорційне товщині феромагнетика `t_FM`.
2. В ідеальному режимі жорсткого AFM коерцитивна сила `H_c` залежить виключно від власної анізотропії феромагнетика `K_FM` і не змінюється при виникненні обмінного зміщення.

### 4. Критична товщина антиферомагнетика t_AFM^c та розширення коерцитивності

Якщо товщина антиферомагнетика зменшується, умова жорсткого закріплення порушується, оскільки анізотропія AFM `K_AFM · t_AFM` стає сумірною з обмінною енергією `J_EB`.

Повернемося до рівняння кутової рівноваги спінів AFM:

```
K_AFM · t_AFM · sin(2·ϕ) = J_EB · sin(θ - ϕ)
```

Максимальне значення лівої частини (утримуючий момент анізотропії AFM) досягається при `ϕ = π/4` і дорівнює:

```
T_AFM_max = K_AFM · t_AFM
```

Якщо обмінний момент `J_EB` перевищує це значення (`J_EB > K_AFM · t_AFM`), анізотропія антиферомагнетика більше не може утримати спіни AFM від розвороту. Спіни AFM починають повертатися разом із вектором намагніченості феромагнетика при перемагнічуванні.

Це визначає **критичну товщину антиферомагнітного шару** `t_AFM^c`:

```
t_AFM^c = J_EB / K_AFM      [критична товщина AFM]
```

Проаналізуємо поведінку гетероструктури у двох товщинних режимах:

#### Режим 1: `t_AFM > t_AFM^c` (Товстий антиферомагнетик)
- Спіни AFM залишаються жорстко закріпленими (`ϕ ≈ 0`).
- Сстерігається максимальне поле обмінного зміщення: `H_EB = J_EB / (M_FM · t_FM)`.
- Коерцитивна сила дорівнює власному значення феромагнетика `H_c = 2 K_FM / M_FM`.

#### Режим 2: `t_AFM < t_AFM^c` (Тонкий антиферомагнетик)
- Анізотропія AFM недостатня для закріплення. Спіни AFM незворотно повертаються услід за `M_FM`.
- Оскільки односпрямоване закріплення зникає, поле зміщення обнуляється: `H_EB = 0`.
- Проте незворотне обертання спінів AFM вимагає додаткових енергетичних витрат на подолання бар'єрів `K_AFM`, що створює **гігантське розширення коерцитивної сили** `ΔH_c`:

```
ΔH_c = (2 · K_AFM · t_AFM) / (M_FM · t_FM)      [для t_AFM < t_AFM^c]
```

Залежність полів `H_EB` та `H_c` від товщини антиферомагнетика `t_AFM` підсумовується графічною залежністю:

```
 Поле |
      |          /-- H_c (Пік коерцитивності при t_AFM^c)
  H_c |         / \
      |  ______/   \____________________
      | /
 H_EB |/___________/-------------------- (Плато H_EB)
      +------------------------------------> t_AFM
      0           t_AFM^c
```

### 5. Поправка Малоземова: Модель випадкових полів для реальних шорстких інтерфейсів

Класична модель Мейклджона — Біна припускає ідеально плоский нескомпенсований інтерфейс, де кожен атом AFM створює паралельний обмінний зв'язок з атомом FM. Для типових міжфазних обмінних інтегралів `J_inter ≈ 10–20 мДж/м²` ця модель передбачає значення полів зміщення `H_EB` порядку `10³–10⁴ Ое`.

Prote у реальних тонких плівках експериментально виміряні поля зміщення виявляються у **10–100 разів меншими** (зазвичай `10–200 Ое`).

Причину цього розходження пояснив Алан Малоземов (*A. P. Malozemoff*, 1987) у **моделі випадкових полів** (*Random-Field Model*):

1. **Атомарна шорсткість:** Реальний інтерфейс тонкої плівки має атомарні сходинки, дефекти та шорсткість. В результаті сусідні ділянки інтерфейсу містять нескомпенсовані спіни протилежних підґраток AFM.
2. **Випадкові поля:** Локальний обмінний інтеграл флуктує за знаком, створюючи випадкове поле `+J` та `-J` з середнім значенням нуль.
3. **Утворення доменних стінок у AFM:** Щоб мінімізувати сумарну енергію випадкового поля, антиферомагнетик розбивається на домени товщиною `L_x`, перпендикулярні до інтерфейсу. Ширина доменів визначається балансом між анізотропією `K_AFM` та внутрішнім обміном `A_AFM`:

   ```
   L_x ≈ π · √(A_AFM / K_AFM)
   ```

4. **Компенсація та статистичний залишок:** Більшість випадкових полів у межах кожного домену взаємно компенсуються. Лічильний залишок нескомпенсованих спінів масштабується як `1 / √N`, де `N` — кількість атомів у домені.

В результаті Малоземов вивів вираз для ефективної енергії обмінного зміщення реального шорсткого інтерфейсу:

```
J_eff = (2 / π) · √(A_AFM · K_AFM)      [формула Малоземова]
```

де `A_AFM` — константа обмінної взаємодії в об'ємі антиферомагнетика (`Дж/м`).

Формула Малоземова математично пояснює, чому реальна ефективна обмінна енергія становить `J_eff ≈ 0.1–0.3 мДж/м²` замість теоретичних `10–20 мДж/м²`, що повністю узгоджується з експериментальними даними для промислових плівок `IrMn` та `PtMn`.
