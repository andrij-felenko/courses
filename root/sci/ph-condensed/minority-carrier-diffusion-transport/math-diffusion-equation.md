# 🧮 Виведення рівняння дифузії та крайові задачі переносу носіїв

Математичний опис дифузії та дрейфу неосновних носіїв заряду є фундаментальним розділом кінетичної теорії напівпровідників. Він спирається на закони збереження кількості частинок (рівняння безперервності) з урахуванням трьох взаємопов'язаних процесів: просторового переносу заряду під дією градієнтів концентрації та електричних полів, його незворотного зникнення внаслідок рекомбінації на дефектах або зона-зона, а також генерації носіїв зовнішніми джерелами енергії.

Розглянемо послідовне математичне виведення рівнянь переносу для неосновних носіїв — дірок у напівпровіднику n-типу провідності. Позначимо повну концентрацію дірок як `p(x, t)`, рівноважну концентрацію як `p₀`, а надлишкову концентрацію як `Δp(x, t) = p(x, t) - p₀` (вживається також позначення `δp(x, t)`). У напівпровіднику n-типу рівноважна концентрація основних носіїв (електронів) дорівнює `n₀ ≈ N_d`, де `N_d` — концентрація донорної домішки, а `p₀ = n_i² / N_d ≪ n₀`. Умова низького рівня ін'єкції (`Δp ≪ n₀`) гарантує постійність часу життя носіїв `τ_p` та збереження локальної квазінейтральності напівпровідника.

---

### 1. Виведення одновимірного рівняння безперервності

Розглянемо нескінченно малий шар напівпровідника товщиною `dx` та площею поперечного перерізу `S`, розташований між просторовими координатами `x` та `x + dx`.

За елементарний проміжок часу `dt` повна кількість дірок усередині цього об'єму `N = p(x, t) · S · dx` змінюється внаслідок чотирьох незалежних фізичних процесів:

1. **Вхідний потік дірок** через ліву площину `x`:

```
Φ_in = (1 / q) · J_p(x) · S · dt
```

2. **Вихідний потік дірок** через праву площину `x + dx`:

```
Φ_out = (1 / q) · J_p(x + dx) · S · dt
```

3. **Об'ємна рекомбінація** надлишкових дірок усередині шару (зменшення кількості вільних частинок):

```
R_loss = (Δp / τ_p) · S · dx · dt
```

де `τ_p` — час життя неосновних носіїв заряду за статистикою Шокли — Рида — Холла (SRH).

4. **Зовнішня генерація** електрон-діркових пар (наприклад, поглинанням фотонів світла):

```
G_gain = G_L(x, t) · S · dx · dt
```

де `G_L(x, t)` — швидкість оптичної або радіаційної генерації в одиниці об'єму (`см⁻³·с⁻¹`).

Загальний баланс зміни кількості частинок усередині виділеного об'єму записується через суму потокових, рекомбінаційних та генераційних членів:

```
dN = S · dx · [p(x, t + dt) - p(x, t)] = Φ_in - Φ_out - R_loss + G_gain
```

Підставимо у баланс вирази для кожного компонента:

```
S · dx · (∂(Δp) / ∂t) · dt
= (1 / q) · [J_p(x) - J_p(x + dx)] · S · dt - (Δp / τ_p) · S · dx · dt + G_L(x, t) · S · dx · dt
```

Розкладемо густину струму на правій межі `J_p(x + dx)` у ряд Тейлора за малою просторовою координатою `dx`, обмежившись членом першого порядку:

```
J_p(x + dx) = J_p(x) + (∂J_p / ∂x) · dx
```

Підставивши цей розклад у рівняння балансу й скоротивши спільний об'ємно-часовий множник `S · dx · dt`, отримуємо фундаментальне **одновимірне рівняння безперервності для дірок**:

```
∂(Δp) / ∂t = - (1 / q) · (∂J_p / ∂x) - (Δp / τ_p) + G_L(x, t)
```

Для неосновних електронів у напівпровіднику p-типу провідності густина надлишкового заряду від'ємна, тому рівняння безперервності має вигляд:

```
∂(Δn) / ∂t = (1 / q) · (∂J_n / ∂x) - (Δn / τ_n) + G_L(x, t)
```

Знак плюс перед просторовою похідною струму електронів обумовлений від'ємним зарядом електрона (`-q`), оскільки напрямок електричного струму протилежний фізичному напрямку руху електронів.

### 2. Дрейфово-дифузійне наближення та перший закон Фіка

Повна густина струму дірок `J_p` у напівпровіднику складається з двох компонент — дрейфової під дією локального електричного поля `E` та дифузійної за градієнтом просторової концентрації:

```
J_p = J_drift,p + J_diff,p = q · μ_p · p · E - q · D_p · (∂p / ∂x)
```

де `μ_p` — дрейфова рухливість дірок, `D_p` — коефіцієнт дифузії дірок.

У квазінейтральній області напівпровідника за відсутності поздовжнього електричного поля (`E = 0`) або коли дифузійний градієнт переважає полеву складову, струм задається виключно **першим законом Фіка**:

```
J_p = J_diff,p = - q · D_p · (∂(Δp) / ∂x)
```

Підставимо вираз для дифузійного струму в одновимірне рівняння безперервності:

```
∂(Δp) / ∂t
= - (1 / q) · ∂/∂x [ - q · D_p · (∂(Δp) / ∂x) ] - (Δp / τ_p) + G_L(x, t)    [підстановка струму Фіка]
= D_p · (∂²(Δp) / ∂x²) - (Δp / τ_p) + G_L(x, t)                             [диференціювання за сталого D_p]
```

Якщо в зразку додатково діє однорідне протягувальне електричне поле `E = const`, повний вираз для густини струму набуває вигляду `J_p = q · μ_p · p · E - q · D_p · (∂(Δp)/∂x)`. Враховуючи, що `∂p/∂x = ∂(Δp)/∂x`, диференціювання струму дає:

```
∂J_p / ∂x = q · μ_p · E · (∂(Δp) / ∂x) - q · D_p · (∂²(Δp) / ∂x²)
```

Підстановка цього виразу в рівняння безперервності формує повне **дрейфово-дифузійне рівняння переносу неосновних носіїв**:

```
∂(Δp) / ∂t = D_p · (∂²(Δp) / ∂x²) - μ_p · E · (∂(Δp) / ∂x) - (Δp / τ_p) + G_L(x, t)
```

Це лінійне параболічне диференціальне рівняння в частинних похідних описує часову та просторову еволюцію будь-якого нестаціонарного розподілу надлишкового заряду.

### 3. Термодинамічний зв'язок: співвідношення Ейнштейна

Незважаючи на різну фізичну природу дрейфу (макроскопічна дія кулонівської сили) та дифузії (статистичне розсіювання теплового хаосу), обидва процеси лімітуються одними й тими самими мікроскопічними актами розсіювання носіїв на фононах кристалічної ґратки та іонізованих домішках.

Розглянемо ізольований напівпровідник у стані повної термодинамічної рівноваги за абсолютної температури `T`. Нехай у зразку існує просторовий градієнт легування, що створює внутрішнє вбудоване електричне поле `E(x)`. Оскільки коло розімкнене, сумарний струм дірок у будь-якому перерізі кристала дорівнює нулю (`J_p = 0`). Це вимагає точної рівноваги дрейфового та дифузійного потоків:

```
J_drift,p + J_diff,p = 0
q · μ_p · p(x) · E(x) - q · D_p · (dp / dx) = 0
```

Скоротимо вираз на заряд `q` і виразимо напруженість електричного поля `E(x)`:

```
E(x) = (D_p / μ_p) · (1 / p(x)) · (dp / dx)
```

З іншого боку, у невиродженому напівпровіднику розподіл дірок за енергетичними рівнями підпорядковується статистиці Максвелла — Больцмана:

```
p(x) = n_i · exp[ (E_i(x) - E_F) / (k_B · T) ]
```

де `E_i(x)` — власний рівень Фермі (середина забороненої зони), `E_F` — рівноважний рівень Фермі, що є константою по всьому кристалу (`dE_F / dx = 0`), `k_B` — стала Больцмана.

Зв'язок нахилу енергетичних зон із напруженістю електричного поля визначається потенціалом електростатичного поля: `dE_i / dx = q · E(x)`. Обчислимо просторову похідну концентрації дірок:

```
dp / dx
= n_i · exp[ (E_i(x) - E_F) / (k_B · T) ] · (1 / (k_B · T)) · (dE_i / dx)   [диференціювання експоненти]
= p(x) · [ q · E(x) / (k_B · T) ]                                           [підстановка p(x) та dE_i/dx]
```

Підставивши знайдену похідну `dp/dx` у рівняння рівноваги струмів:

```
q · μ_p · p(x) · E(x) = q · D_p · [ p(x) · q · E(x) / (k_B · T) ]
```

Скоротивши спільні множники `q · p(x) · E(x)` в обох частинах, одержуємо фундаментальне **співвідношення Ейнштейна**:

```
D_p / μ_p = (k_B · T) / q = V_T
```

де `V_T = (k_B · T) / q` — тепловий потенціал, що за кімнатної температури `T = 300 K` становить `V_T ≈ 25.85 мВ`.

### 4. Одновимірне стаціонарне рівняння дифузії та канонічна дифузійна довжина

У стаціонарному режимі концентрація носіїв у кожній точці простору залишається незмінною в часі (`∂(Δp) / ∂t = 0`). За відсутності електричного поля (`E = 0`) рівняння переносу зводиться до лінійного звичайного диференціального рівняння другого порядку з неоднорідною правою частиною (зовнішньою генерацією `G_L(x)`):

```
D_p · (d²(Δp) / dx²) - Δp / τ_p = - G_L(x)
```

Поділимо обидві частини рівняння на коефіцієнт дифузії `D_p`:

```
d²(Δp) / dx² - Δp / (D_p · τ_p) = - G_L(x) / D_p
```

Введемо фундаментальний просторовий масштаб кінетики напівпровідників — **дифузійну довжину неосновних носіїв** `L_p`:

```
L_p = √(D_p · τ_p)
```

Фізичний зміст `L_p` — це середня відстань, яку надлишковий носій заряду проходить уздовж заданого напрямку внаслідок броунівського дифузійного блукання від точки генерації до моменту своєї рекомбінації.

З урахуванням визначення `L_p` одновимірне стаціонарне рівняння дифузії записується у канонічному вигляді:

```
d²(Δp) / dx² - (1 / L_p²) · Δp = - G_L(x) / D_p
```

#### Загальний розв'язок однорідного рівняння

В областях напівпровідника, де зовнішня об'ємна генерація відсутня (`G_L(x) = 0`), рівняння стає однорідним:

```
d²(Δp) / dx² - (1 / L_p²) · Δp = 0
```

Складемо характеристичне алгебраїчне рівняння для пошуку розв'язку у вигляді `Δp(x) = exp(λ · x)`:

```
λ² - 1 / L_p² = 0  ⇒  λ₁,₂ = ± 1 / L_p
```

Оскільки корені характеристичного рівняння дійсні й протилежні за знаком, загальний розв'язок можна записати у двох взаємно еквівалентних математичних базисах:

1. **Експоненціальний базис** (зручний для напівбезмежних зразків `x → ∞`):

```
Δp(x) = C₁ · exp(- x / L_p) + C₂ · exp(x / L_p)
```

2. **Гіперболічний базис** (зручний для пластин скінченної товщини `W`):

```
Δp(x) = A · cosh(x / L_p) + B · sinh(x / L_p)
```

або зі зміщеним просторовим початком відносно протилежної поверхні `x = W`:

```
Δp(x) = A₁ · cosh((W - x) / L_p) + B₁ · sinh((W - x) / L_p)
```

Зв'язок між константами інтегрування встановлюється за формулами Ейлера для гіперболічних функцій `cosh(z) = (exp(z) + exp(-z))/2` та `sinh(z) = (exp(z) - exp(-z))/2`.

### 5. Аналітичні розв'язки стаціонарних крайових задач

Конкретний просторовий розподіл надлишкових носіїв та величина струмів повністю визначаються геометричними розмірами зразка та фізичними умовами на його границях.

#### Задача 1: Напівбезмежний напівпровідник (`x ≥ 0`)

Розглянемо напівпровідниковий кристал товщиною, що набагато перевищує дифузійну довжину (`W ≫ L_p`). На лівій грані `x = 0` підтримується постійна надлишкова концентрація носіїв `Δp(0) = Δp₀` (наприклад, шляхом інжекції через прямо-зміщений p-n перехід).

Сформулюємо граничні умови:

```
1. Δp(0) = Δp₀
2. lim_{x → ∞} Δp(x) = 0
```

Умова на нескінченності випливає з фізичної вимоги обмеженості концентрації: оскільки `exp(x / L_p) → ∞` при `x → ∞`, коефіцієнт при зростаючій експоненті зобов'язаний дорівнювати нулю:

```
C₂ = 0
```

Підставивши умову на передній поверхні `x = 0` у залишковий вираз `Δp(x) = C₁ · exp(- x / L_p)`:

```
Δp(0) = C₁ · exp(0) = C₁ = Δp₀
```

Отримуємо класичний експоненціальний профіль спадання концентрації вглиб кристала:

```
Δp(x) = Δp₀ · exp(- x / L_p)
```

Густина дифузійного струму дірок як функція координати `x` обчислюється взяттям просторової похідної:

```
J_diff,p(x)
= - q · D_p · (d(Δp) / dx)
= - q · D_p · [ - (Δp₀ / L_p) · exp(- x / L_p) ]     [диференціювання експоненти]
= q · (D_p / L_p) · Δp₀ · exp(- x / L_p)             [спрощення знаків]
```

На вході в напівпровідник (`x = 0`) густина струму ін'єкції становить:

```
J_diff,p(0) = q · (D_p / L_p) · Δp₀
```

Обчислимо повний інтегральний надлишковий заряд дірок `Q_p`, накопичений в об'ємі на одиницю площі:

```
Q_p
= q · ∫₀^∞ Δp(x) dx                        [інтеграл по всій глибині кристала]
= q · Δp₀ · ∫₀^∞ exp(- x / L_p) dx         [підстановка експоненційного профілю]
= q · Δp₀ · [ - L_p · exp(- x / L_p) ]₀^∞  [первісна від експоненти]
= q · Δp₀ · L_p                            [підстановка границь 0 та нескінченності]
```

Порівняння формул струму ін'єкції та накопиченого заряду демонструє точний інтегральний баланс частинок:

```
J_diff,p(0) = q · Δp₀ · L_p / τ_p = Q_p / τ_p
```

Весь струм, що входить через поверхню `x = 0`, повністю витрачається на стаціонарну рекомбінацію надлишкового об'ємного заряду `Q_p` за час життя `τ_p`.

---

#### Задача 2: Пластина скінченної товщини W з ідеальним стоком носіїв (тонка база транзистора)

Розглянемо пластину товщиною `W`, на лівій межі якої задано фіксовану концентрацію `Δp(0) = Δp₀`, а на правій межі `x = W` розташований ідеальний колектор (зворотно зміщений p-n перехід або омічний контакт із нескінченною швидкістю рекомбінації), який миттєво відводить усі носії, що дісталися межі: `Δp(W) = 0`.

Крайові умови першого роду (Діріхле):

```
1. Δp(0) = Δp₀
2. Δp(W) = 0
```

Скористаємося гіперболічним базисом, зсунутим до точки `x = W`:

```
Δp(x) = A · cosh((W - x) / L_p) + B · sinh((W - x) / L_p)
```

Підставимо граничну умову при `x = W`:

```
Δp(W) = A · cosh(0) + B · sinh(0) = A · 1 + B · 0 = A = 0
```

Отже, член із гіперболічним косинусом зникає (`A = 0`). Залишається:

```
Δp(x) = B · sinh((W - x) / L_p)
```

Підставимо граничну умову на вході при `x = 0`:

```
Δp(0) = B · sinh(W / L_p) = Δp₀  ⇒  B = Δp₀ / sinh(W / L_p)
```

Отримуємо строгий аналітичний розподіл надлишкових носіїв у базі скінченної товщини:

```
Δp(x) = Δp₀ · [ sinh((W - x) / L_p) / sinh(W / L_p) ]
```

Обчислимо просторовий розподіл густини дифузійного струму `J_diff,p(x)`:

```
J_diff,p(x)
= - q · D_p · (d(Δp) / dx)
= - q · D_p · (Δp₀ / sinh(W / L_p)) · [ - (1 / L_p) · cosh((W - x) / L_p) ]  [диференціювання sinh((W-x)/L_p)]
= q · (D_p / L_p) · Δp₀ · [ cosh((W - x) / L_p) / sinh(W / L_p) ]            [спрощення подвійного мінуса]
```

Знайдемо струм на вході в базу (`x = 0`) та вихідний струм на колекторі (`x = W`):

```
J_in = J_diff,p(0) = q · (D_p / L_p) · Δp₀ · coth(W / L_p)
J_out = J_diff,p(W) = q · (D_p / L_p) · Δp₀ / sinh(W / L_p)
```

Коефіцієнт переносу неосновних носіїв через базу (транспортний фактор бази біполярного транзистора `α_T`) визначається відношенням вихідного струму до вхідного:

```
α_T = J_out / J_in = (1 / sinh(W / L_p)) / coth(W / L_p) = 1 / cosh(W / L_p)
```

Розглянемо дві ключові граничні асимптотики:

1. **Товста база (`W ≫ L_p`)**:
   Оскільки `sinh(W / L_p) ≈ cosh(W / L_p) ≈ (1/2) · exp(W / L_p)`, маємо:
   ```
   Δp(x) ≈ Δp₀ · exp(- x / L_p)
   α_T ≈ 2 · exp(- W / L_p) → 0
   ```
   Профіль перетворюється на звичайну експоненту напівбезмежного зразка, а колектора досягає експоненційно зникаюча частка носіїв через сильну об'ємну рекомбінацію.

2. **Тонка база (`W ≪ L_p`)**:
   Розкладемо гіперболічні функції в ряд Тейлора за малим аргументом `z = (W - x) / L_p ≪ 1` та `z₀ = W / L_p ≪ 1` (`sinh(z) ≈ z + z³/6`, `cosh(z) ≈ 1 + z²/2`):

```
Δp(x)
= Δp₀ · [ (W - x) / L_p ] / [ W / L_p ]     [апроксимація першим членом Тейлора]
= Δp₀ · (1 - x / W)                          [строго лінійний профіль]
```

Дифузійний струм через тонку базу стає майже сталим по всій координаті `x`:

```
J_diff,p(x) ≈ q · D_p · (Δp₀ / W)
```

А транспортний фактор бази наближається до одиниці:

```
α_T
= 1 / cosh(W / L_p)
≈ 1 / [ 1 + (1/2) · (W / L_p)² ]            [розклад косинуса в ряд]
≈ 1 - (1/2) · (W / L_p)²                    [формула Тейлора для (1 + ε)⁻¹]
```

Відносні втрати носіїв на рекомбінацію в об'ємі бази становлять мізерну величину `1 - α_T ≈ W² / (2 L_p²) ≪ 1`, що забезпечує високий коефіцієнт підсилення біполярного транзистора.

#### Задача 3: Пластина з ідеально відбивною або пасивованою поверхнею (`d(Δp)/dx = 0`)

Нехай на тильній поверхні пластини `x = W` створено ідеальний ізолюючий бар'єр або нанесено діелектричний шар пасивації (наприклад, оксид або нітрид кремнію з нульовою швидкістю поверхневої рекомбінації `S = 0`). Оскільки потік частинок через межу відсутній, градієнт концентрації на поверхні дорівнює нулю.

Крайові умови (суміш умов Діріхле та Неймана):

```
1. Δp(0) = Δp₀
2. (d(Δp) / dx)|_{x=W} = 0
```

Шукаємо розв'язок у зсунутому гіперболічному базисі:

```
Δp(x) = A · cosh((W - x) / L_p) + B · sinh((W - x) / L_p)
```

Візьмемо похідну за координатою `x`:

```
d(Δp) / dx = - (A / L_p) · sinh((W - x) / L_p) - (B / L_p) · cosh((W - x) / L_p)
```

Підставимо умову відсутності градієнта при `x = W`:

```
(d(Δp) / dx)|_{x=W} = - (A / L_p) · sinh(0) - (B / L_p) · cosh(0) = - B / L_p = 0  ⇒  B = 0
```

Член із гіперболічним синусом зникає (`B = 0`). Значення коефіцієнта `A` визначаємо з умови на лівій грані `x = 0`:

```
Δp(0) = A · cosh(W / L_p) = Δp₀  ⇒  A = Δp₀ / cosh(W / L_p)
```

Остаточний аналітичний розподіл концентрації дірок у пластині з відбивною межею:

```
Δp(x) = Δp₀ · [ cosh((W - x) / L_p) / cosh(W / L_p) ]
```

Розподіл густини дифузійного струму:

```
J_diff,p(x)
= - q · D_p · (d(Δp) / dx)
= - q · D_p · (Δp₀ / cosh(W / L_p)) · [ - (1 / L_p) · sinh((W - x) / L_p) ]  [диференціювання cosh((W-x)/L_p)]
= q · (D_p / L_p) · Δp₀ · [ sinh((W - x) / L_p) / cosh(W / L_p) ]            [спрощення подвійного мінуса]
```

Струм на вході пластини (`x = 0`):

```
J_in = J_diff,p(0) = q · (D_p / L_p) · Δp₀ · tanh(W / L_p)
```

Для тонкої пластини (`W ≪ L_p`) використаємо наближення `tanh(z) ≈ z`:

```
J_in ≈ q · (D_p / L_p) · Δp₀ · (W / L_p) = q · Δp₀ · W / τ_p
```

Оскільки виходу носіїв назовні через праву грань немає (`J_diff,p(W) = 0`), весь інжектований струм іде виключно на компенсацію об'ємної рекомбінації у шарі товщиною `W`.

#### Задача 4: Скінченна швидкість поверхневої рекомбінації S (гранична умова Робена)

На реальних поверхнях кристалів дефекти ґратки, обірвані валентні зв'язки та сторонні домішки створюють високу густину поверхневих квантових станів. Вони діють як ефективні пастки, що рекомбінують носії з певною **швидкістю поверхневої рекомбінації** `S` (`см/с`).

Потік частинок, що зникає на поверхні `x = W`, дорівнює `F_surf = S · Δp(W)`. За законом збереження речовини цей поверхневий потік має точно підживлюватися дифузійним притоком з об'єму кристала:

```
- D_p · (d(Δp) / dx)|_{x=W} = S · Δp(W)
```

Це змішана гранична умова третього роду (умова Робена). Сформулюємо повну систему крайових умов для пластини товщиною `W`:

```
1. Δp(0) = Δp₀
2. - D_p · (d(Δp) / dx)|_{x=W} = S · Δp(W)
```

Запишемо загальний розв'язок у зсунутому базисі:

```
Δp(x) = A · cosh((W - x) / L_p) + B · sinh((W - x) / L_p)
```

Обчислимо концентрацію та її просторову похідну в точці `x = W`:

```
Δp(W) = A
(d(Δp) / dx)|_{x=W} = - B / L_p
```

Підставимо ці вирази в граничну умову Робена:

```
- D_p · [ - B / L_p ] = S · A
(D_p / L_p) · B = S · A
B = [ S · L_p / D_p ] · A
```

Введемо зручний безрозмірний параметр поверхневої рекомбінації:

```
h = S · L_p / D_p = S / v_diff
```

де `v_diff = D_p / L_p = √(D_p / τ_p)` — характеристична дифузійна швидкість носіїв.

Тоді коефіцієнти пов'язані простим співвідношенням `B = h · A`, а розв'язок набуває вигляду:

```
Δp(x) = A · [ cosh((W - x) / L_p) + h · sinh((W - x) / L_p) ]
```

Використаємо граничну умову на вході при `x = 0`:

```
Δp(0) = A · [ cosh(W / L_p) + h · sinh(W / L_p) ] = Δp₀
```

Звідси знаходимо амплітудний множник `A`:

```
A = Δp₀ / [ cosh(W / L_p) + h · sinh(W / L_p) ]
```

Остаточний точний аналітичний розв'язок крайової задачі Робена має вигляд:

```
Δp(x) = Δp₀ · [ cosh((W - x) / L_p) + h · sinh((W - x) / L_p) ] / [ cosh(W / L_p) + h · sinh(W / L_p) ]
```

Перевіримо граничні переходи за швидкістю поверхневої рекомбінації:

1. **Ідеально пасивована поверхня (`S → 0`, `h → 0`)**:
   Члени з `h` перетворюються на нуль, і вираз точно переходить у формулу задачі 3 з `cosh`:
   ```
   Δp(x) = Δp₀ · cosh((W - x) / L_p) / cosh(W / L_p)
   ```

2. **Нескінченна швидкість поверхневої рекомбінації (`S → ∞`, `h → ∞`)**:
   Домінують члени при `h`, множники `cosh` стають нехтовно малими порівняно з `h · sinh`, і формула спрощується до задачі 2 з `sinh`:
   ```
   Δp(x) = Δp₀ · sinh((W - x) / L_p) / sinh(W / L_p)
   ```

#### Ефективний час життя носіїв у тонкій пластині

Поверхнева рекомбінація на обох гранях пластини товщиною `W` прискорює загасання концентрації носіїв. Сумарний **ефективний час життя** `τ_eff` виводиться з розв'язку нестаціонарного рівняння дифузії методом розділення змінних:

1. **Режим низької швидкості поверхневої рекомбінації (`S · W / (2 D_p) ≪ 1`)**:
   Швидкість рекомбінації лімітується безпосередньо поверхневими пастками:
   ```
   1 / τ_eff = 1 / τ_bulk + 2 · S / W
   ```

2. **Режим дифузійного обмеження (`S → ∞`)**:
   Швидкість рекомбінації лімітується часом дифузійного перельоту носіїв від середини пластини до її поверхні:
   ```
   1 / τ_eff ≈ 1 / τ_bulk + π² · D_p / W²
   ```

### 6. Неоднорідне стаціонарне рівняння: фотогенерація світлом

Розглянемо напівбезмежний напівпровідник (`x ≥ 0`), освітлений монохроматичним світловим потоком із довжиною хвилі `λ`.

Згідно з законом Бугера — Ламберта — Бера, інтенсивність світла з глибиною спадає експоненційно `I(x) = I₀ · exp(- α · x)`, де `α` — коефіцієнт оптичного поглинання матеріалу (`см⁻¹`). Відповідно, функція оптичної генерації носіїв записується як:

```
G_L(x) = α · Φ₀ · (1 - R_opt) · exp(- α · x) = G₀ · exp(- α · x)
```

де `Φ₀` — густина падаючого фотонного потоку (`фотонів / (см² · с)`), `R_opt` — коефіцієнт оптичного відбиття від поверхні, `G₀ = α · Φ₀ · (1 - R_opt)`.

Підставимо функцію генерації в стаціонарне рівняння дифузії:

```
d²(Δp) / dx² - (1 / L_p²) · Δp = - (G₀ / D_p) · exp(- α · x)
```

Повний розв'язок неоднорідного лінійного диференціального рівняння складається із загального розв'язку однорідного рівняння `Δp_hom(x)` та частинного розв'язку неоднорідного рівняння `Δp_part(x)`:

```
Δp(x) = Δp_hom(x) + Δp_part(x)
```

Шукаємо частинний розв'язок у формі правої частини: `Δp_part(x) = K · exp(- α · x)`. Обчислимо другу похідну: `d²(Δp_part) / dx² = K · α² · exp(- α · x)`.

Підставимо у диференціальне рівняння:

```
K · α² · exp(- α · x) - (K / L_p²) · exp(- α · x) = - (G₀ / D_p) · exp(- α · x)
K · [ α² - 1 / L_p² ] = - G₀ / D_p
K = - (G₀ / D_p) / [ α² - 1 / L_p² ] = - (G₀ · L_p² / D_p) / [ α² · L_p² - 1 ]
```

Враховуючи, що `L_p² / D_p = τ_p`:

```
Δp_part(x) = - [ G₀ · τ_p / (α² · L_p² - 1) ] · exp(- α · x)
```

Загальний розв'язок для напівбезмежного зразка набуває вигляду:

```
Δp(x) = C₁ · exp(- x / L_p) - [ G₀ · τ_p / (α² · L_p² - 1) ] · exp(- α · x)
```

Константа `C₁` знаходиться з крайової умови на поверхні `x = 0` за наявності поверхневої рекомбінації зі швидкістю `S₀`:

```
D_p · (d(Δp) / dx)|_{x=0} = S₀ · Δp(0)
```

Диференціювання та підстановка дають замкнений вираз для концентраційного профілю, що визначає квантову ефективність сонячних елементів та фотодіодів.

### 7. Нестаціонарне рівняння та метод функції Гріна (експеримент Хейнса — Шоклі)

У класичному експерименті Хейнса — Шоклі на брусок напівпровідника n-типу довжиною кілька сантиметрів подається поздовжнє постійне електричне поле `E`. У початковий момент часу `t = 0` у фіксованій точці `x = 0` короткий імпульс напруги інжектує точковий заряд дірок площею `Q₀` (`кулон/см²`).

Математично початкове джерело описується добутком двох дельта-функцій Дірака:

```
G_ext(x, t) = (Q₀ / q) · δ(x) · δ(t)
```

Повне нестаціонарне одновимірне рівняння переносу має вигляд:

```
∂(Δp) / ∂t = D_p · (∂²(Δp) / ∂x²) - μ_p · E · (∂(Δp) / ∂x) - Δp / τ_p + (Q₀ / q) · δ(x) · δ(t)
```

з початковою умовою спокою `Δp(x, t < 0) = 0` та граничними умовами згасання на нескінченності `Δp(±∞, t) = 0`.

#### Аналітичне розв'язання методом послідовних замін змінних

Розв'яжемо це рівняння в три послідовні математичні кроки:

**Крок 1: Усунення лінійного рекомбінаційного члена.**
Введемо допоміжну функцію `u(x, t)`:

```
Δp(x, t) = u(x, t) · exp(- t / τ_p)
```

Обчислимо часову похідну:

```
∂(Δp) / ∂t = [ ∂u / ∂t - u / τ_p ] · exp(- t / τ_p)
```

Підставивши цей вираз у вихідне рівняння переносу, бачимо, що члени `- u / τ_p` та `- Δp / τ_p` взаємно скорочуються:

```
∂u / ∂t = D_p · (∂²u / ∂x²) - μ_p · E · (∂u / ∂x) + (Q₀ / q) · δ(x) · δ(t)
```

**Крок 2: Перехід у рухому систему відліку (усунення дрейфового члена).**
Здійснимо перехід до просторової координати `ξ`, що рухається разом із центром дрейфуючої хмари носіїв зі швидкістю `v_dr = μ_p · E`:

```
ξ = x - μ_p · E · t
t' = t
```

За правилом диференціювання складної функції:

```
∂/∂x = ∂/∂ξ
∂/∂t = ∂/∂t' + (∂ξ / ∂t) · (∂/∂ξ) = ∂/∂t' - μ_p · E · (∂/∂ξ)
```

Підставимо ці оператори в диференціальне рівняння для `u`:

```
∂u / ∂t' - μ_p · E · (∂u / ∂ξ)
= D_p · (∂²u / ∂ξ²) - μ_p · E · (∂u / ∂ξ) + (Q₀ / q) · δ(ξ) · δ(t')
```

Полеві члени `- μ_p · E · (∂u / ∂ξ)` в обох частинах тотожно скорочуються! Рівняння перетворюється на канонічне одновимірне рівняння чистої дифузії (рівняння теплопровідності):

```
∂u / ∂t' = D_p · (∂²u / ∂ξ²) + (Q₀ / q) · δ(ξ) · δ(t')
```

**Крок 3: Інтегрування методом перетворення Фур'є.**
Фундаментальний розв'язок (функція Гріна) одновимірного рівняння дифузії для точкового миттєвого джерела добре відомий і являє собою гаусовий розподіл:

```
u(ξ, t') = [ (Q₀ / q) / √(4 π · D_p · t') ] · exp( - ξ² / (4 · D_p · t') )
```

**Крок 4: Повернення до фізичних змінних `(x, t)`.**
Підставимо назад вирази для `ξ = x - μ_p · E · t` та `Δp = u · exp(- t / τ_p)`:

```
Δp(x, t) = [ (Q₀ / q) / √(4 π · D_p · t) ] · exp[ - (x - μ_p · E · t)² / (4 · D_p · t) ] · exp( - t / τ_p )
```

Це точний аналітичний розв'язок задачі Хейнса — Шоклі, який описує одночасну дію трьох процесів: дрейфу, дифузійного розпливання та рекомбінації.

---

#### Аналіз параметрів імпульсу в експерименті Хейнса — Шоклі

Отриманий аналітичний розв'язок дозволяє детально проаналізувати кінетику хвильового пакета носіїв:

1. **Координата центру (максимуму) імпульсу `x_max(t)`**:
   Експоненціальний аргумент гаусового розподілу набуває максимуму, коли вираз у дужках дорівнює нулю:
   ```
   x_max(t) = μ_p · E · t = v_dr · t
   ```
   Центр хмари надлишкових носіїв рухається вздовж кристала рівномірно і прямолінійно зі швидкістю дрейфу `v_dr`.

2. **Дисперсія та просторова ширина пакета**:
   Густина ймовірності розподілу частинок відповідає нормальному закону Гауса з дисперсією:
   ```
   σ²(t) = 2 · D_p · t  ⇒  σ(t) = √(2 · D_p · t)
   ```
   Повна просторова ширина імпульсу на половині його максимальної висоти (FWHM — Full Width at Half Maximum) визначається рівнянням:
   ```
   exp[ - (Δx / 2)² / (2 · σ²) ] = 1/2
   - Δx² / (8 · σ²) = - ln 2
   Δx = √(8 · ln 2) · σ(t) = √(16 · ln 2 · D_p · t) ≈ 3.3302 · √(D_p · t)
   ```
   Ширина імпульсу зростає пропорційно квадратному кореню з часу прольоту `√t`.

3. **Амплітудне згасання вершини імпульсу**:
   Підставивши координату максимуму `x = x_max(t)` у загальний розв'язок, знаходимо максимальну концентрацію у піку:
   ```
   Δp_max(t) = Δp(x_max, t) = [ (Q₀ / q) / √(4 π · D_p · t) ] · exp( - t / τ_p )
   ```
   Амплітуда піка зменшується внаслідок двох незалежних факторів:
   - **Дифузійного розширення** геометрії пакета (`~ 1 / √t`);
   - **Експоненційного об'ємного згасання** через рекомбінацію (`~ exp(- t / τ_p)`).

4. **Часова форма сигналу на колекторі в точці `x = d`**:
   Колекторний зонд реєструє струм як функцію часу `t` у фіксованій точці `x = d`. Підставивши `x = d` у формулу, отримуємо залежність `Δp(d, t)`:
   ```
   Δp(d, t) = [ (Q₀ / q) / √(4 π · D_p · t) ] · exp[ - (d - μ_p · E · t)² / (4 · D_p · t) ] · exp( - t / τ_p )
   ```
   Через наявність множника `1 / √t` у знаменнику та залежність знаменника експоненти від `t`, часовий відгук на осцилографі є злегка асиметричним: його передній фронт дещо крутіший за задній.

### 8. Математичний апарат амбіполярного транспорту

Коли інжектовані дірки `Δp` дифундують у кристал n-типу, під дією кулонівських сил рухливі електрони `Δn` миттєво перерозподіляються для нейтралізації просторового заряду (`Δn ≈ Δp`). Проте електрони та дірки мають різні коефіцієнти дифузії (`D_n ≠ D_p`) та рухливості (`μ_n ≠ μ_p`). Їхній спільний рух описується теорією **амбіполярного транспорту**.

Запишемо повну систему одновимірних рівнянь безперервності з урахуванням самоузгодженого електричного поля `E`:

```
∂p / ∂t = D_p · (∂²p / ∂x²) - μ_p · ∂/∂x (p · E) - Δp / τ
∂n / ∂t = D_n · (∂²n / ∂x²) + μ_n · ∂/∂x (n · E) - Δn / τ
```

Помножимо перше рівняння на питому електронну провідність `σ_n = q · μ_n · n`, а друге — на питому діркову провідність `σ_p = q · μ_p · p`:

```
σ_n · (∂p / ∂t) = σ_n · D_p · (∂²p / ∂x²) - σ_n · μ_p · ∂/∂x (p · E) - σ_n · (Δp / τ)
σ_p · (∂n / ∂t) = σ_p · D_n · (∂²n / ∂x²) + σ_p · μ_n · ∂/∂x (n · E) - σ_p · (Δn / τ)
```

Додамо обидва рівняння, враховуючи умову квазінейтральності `Δn = Δp`, `∂n/∂t = ∂p/∂t` та `∂n/∂x = ∂p/∂x`:

```
(σ_n + σ_p) · (∂(Δp) / ∂t)
= (σ_n · D_p + σ_p · D_n) · (∂²(Δp) / ∂x²)
  - q · μ_n · μ_p · [ n · ∂/∂x (p · E) - p · ∂/∂x (n · E) ]
  - (σ_n + σ_p) · (Δp / τ)
```

Розкриємо похідні добутку в дужках:

```
n · ∂/∂x (p · E) - p · ∂/∂x (n · E)
= n · [ p · (∂E / ∂x) + E · (∂p / ∂x) ] - p · [ n · (∂E / ∂x) + E · (∂n / ∂x) ]   [диференціювання добутку]
= n · p · (∂E / ∂x) + n · E · (∂p / ∂x) - p · n · (∂E / ∂x) - p · E · (∂p / ∂x)   [розкриття дужок]
= (n - p) · E · (∂(Δp) / ∂x)                                                      [скорочення членів із dE/dx]
```

Поділимо все рівняння на повну провідність `σ_total = σ_n + σ_p = q · (n · μ_n + p · μ_p)`:

Отримуємо канонічне **рівняння амбіполярного транспорту Ван Роосбрука**:

```
∂(Δp) / ∂t = D_a · (∂²(Δp) / ∂x²) - μ_a · E · (∂(Δp) / ∂x) - Δp / τ
```

де `D_a` — **коефіцієнт амбіполярної дифузії**:

```
D_a
= (σ_n · D_p + σ_p · D_n) / (σ_n + σ_p)         [коефіцієнт при другій похідній]
= (D_n · D_p · (n + p)) / (n · D_n + p · D_p)   [підстановка питомих провідностей]
```

а `μ_a` — **амбіполярна рухливість**:

```
μ_a
= (μ_n · μ_p · (n - p)) / (n · μ_n + p · μ_p)   [підстановка провідностей у полевий член]
```

#### Аналіз асимптотичних режимів амбіполярного переносу

1. **Низький рівень ін'єкції у напівпровіднику n-типу (`n ≫ p`)**:

```
D_a ≈ D_p
μ_a ≈ μ_p
```

Коефіцієнт дифузії та рухливість плазми повністю визначаються параметрами **неосновних носіїв** (дірок). Основні електрони миттєво підлаштовуються під рух повільніших дірок, щоб уникнути порушення нейтральності.

2. **Низький рівень ін'єкції у напівпровіднику p-типу (`p ≫ n`)**:

```
D_a ≈ D_n
μ_a ≈ - μ_n
```

Хмара плазми рухається зі швидкістю та дифузією неосновних електронів. Знак мінус перед рухливістю означає, що пакет дрейфує у напрямку, протилежному до вектора поля `E`.

3. **Високий рівень ін'єкції (`n ≈ p ≫ N_d, N_a`)**:

```
D_a ≈ (2 · D_n · D_p) / (D_n + D_p)
μ_a ≈ 0
```

Коефіцієнт дифузії стає середнім гармонійним між електронним та дірковим значеннями, а амбіполярна рухливість падає до нуля (`μ_a → 0`). Це означає, що при високому рівні ін'єкції електричне поле не здатне переміщувати нейтральний згусток плазми як ціле: пакет лише симетрично розширюється дифузією.
