# 🧮 Виведення рівняння дифузії та дифузійної довжини

Математичний опис дифузії неосновних носіїв є фундаментальним розділом кінетики напівпровідників. Він ґрунтується на законах збереження числа частинок (рівнянні безперервності) з урахуванням трьох ключових феноменів: просторового переносу заряду (дрейфу й дифузії), його зникнення внаслідок рекомбінації та генерації носіїв зовнішніми чинниками.

Розглянемо виведення рівнянь переносу для неосновних носіїв — дірок у напівпровіднику n-типу провідності. Позначимо повну концентрацію дірок як `p(x, t)`, рівноважну концентрацію як `p₀`, а надлишкову концентрацію як `Δp(x, t) = p(x, t) - p₀`.

---

### 1. Виведення одновимірного рівняння безперервності

Розглянемо нескінченно малий шар напівпровідника товщиною `dx` та площею поперечного перерізу `S`, розташований між координатою `x` та `x + dx`.

За час `dt` кількість дірок усередині цього об'єму `N = p(x, t) · S · dx` змінюється внаслідок чотирьох незалежних процесів:

1. **Вхідний потік дірок** через ліву межу `x`:

```
Φ_in = (1 / q) · J_p(x) · S · dt
```

2. **Вихідний потік дірок** через праву межу `x + dx`:

```
Φ_out = (1 / q) · J_p(x + dx) · S · dt
```

3. **Об'ємна рекомбінація** дірок усередині шару (зменшення кількості частинок):

```
R_loss = (Δp / τ_p) · S · dx · dt
```

де `τ_p` — час життя неосновних носіїв.

4. **Зовнішня генерація** (наприклад, поглинанням світлових квантів):

```
G_gain = G_ext · S · dx · dt
```

де `G_ext` — швидкість генерації електрон-діркових пар в одиниці об'єму (`см⁻³·с⁻¹`).

Загальний баланс зміні кількості частинок усередині об'єму виражається рівністю:

```
dN = S · dx · [p(x, t + dt) - p(x, t)] = Φ_in - Φ_out - R_loss + G_gain
```

Підставимо відповідні вирази:

```
S · dx · (∂(Δp) / ∂t) · dt
= (1 / q) · [J_p(x) - J_p(x + dx)] · S · dt - (Δp / τ_p) · S · dx · dt + G_ext · S · dx · dt
```

Розкладемо густину струму `J_p(x + dx)` у ряд Тейлора по малій товщині `dx`, обмежившись першим членом:

```
J_p(x + dx) = J_p(x) + (∂J_p / ∂x) · dx
```

Підставивши цей розклад і скоротивши обидві частини на множник `S · dx · dt`, отримуємо фундаментальне **одновимірне рівняння безперервності для дірок**:

```
∂(Δp) / ∂t = - (1 / q) · (∂J_p / ∂x) - (Δp / τ_p) + G_ext
```

Аналогічно, для неосновних електронів у напівпровіднику p-типу рівняння безперервності має вигляд:

```
∂(Δn) / ∂t = (1 / q) · (∂J_n / ∂x) - (Δn / τ_n) + G_ext
```

Знак плюс перед похідною струму електронів пов'язаний із негативним знаком заряду електрона (`-q`).

### 2. Дифузійне наближення та перший закон Фіка

Повна густина струму дірок `J_p` складається з дрейфової та дифузійної компонент:

```
J_p = J_drift,p + J_diff,p = q · μ_p · p · E - q · D_p · (∂p / ∂x)
```

У квазінейтральній області без зовнішнього електричного поля (`E = 0`) або за умов, коли градієнт концентрації значно перевищує полеву складову, густина струму визначається виключно дифузією за **першим законом Фіка**:

```
J_p = J_diff,p = - q · D_p · (∂(Δp) / ∂x)
```

де `D_p` — коефіцієнт дифузії дірок.

Підставимо густину дифузійного струму в рівняння безперервності:

```
∂(Δp) / ∂t
= - (1 / q) · ∂/∂x [ - q · D_p · (∂(Δp) / ∂x) ] - (Δp / τ_p) + G_ext
= D_p · (∂²(Δp) / ∂x²) - (Δp / τ_p) + G_ext
```

Це і є **параболічне диференціальне рівняння дифузії неосновних носіїв у частинних похідних**.

### 3. Математичне виведення співвідношення Ейнштейна

Зв'язок між коефіцієнтом дифузії `D` та рухливістю `μ` виводиться з умови термодинамічної рівноваги.

У стані рівноваги за відсутності зовнішнього кола повний струм дірок у напівпровіднику дорівнює нулю (`J_p = 0`). Це означає, що дрейфовий струм під дією внутрішнього поля точно врівноважується дифузійним струмом:

```
J_drift,p + J_diff,p = 0
q · μ_p · p(x) · E(x) - q · D_p · (dp / dx) = 0
```

Скоротивши на `q`, виразимо електричне поле `E(x)`:

```
E(x) = (D_p / μ_p) · (1 / p(x)) · (dp / dx)
```

З іншого боку, з квантової статистики та зонної теорії відомо, що потенціальна енергія електрона `V(x)` пов'язана з електричним полем виразом `E(x) = (1 / q) · (dV / dx)`. Концентрація дірок у невиродженому напівпровіднику описується розподілом Максвелла — Больцмана:

```
p(x) = n_i · exp[ (E_i(x) - E_F) / (k_B · T) ]
```

Враховуючи, що нахил зон визначений полем `dE_i / dx = q · E(x)`, візьмемо похідну від концентрації `p(x)` за координатою:

```
dp / dx = p(x) · (1 / (k_B · T)) · (dE_i / dx) = p(x) · (q · E(x) / (k_B · T))
```

Підставивши цей вираз у рівняння рівноваги струмів:

```
q · μ_p · p(x) · E(x) = q · D_p · [ p(x) · q · E(x) / (k_B · T) ]
```

Скоротивши на спільні множники `q · p(x) · E(x)`, отримуємо видатне **співвідношення Ейнштейна**:

```
D_p / μ_p = (k_B · T) / q = V_T
```

### 4. Стаціонарний режим і канонічна дифузійна довжина

Розглянемо стаціонарний режим (`∂(Δp) / ∂t = 0`) поза зоною зовнішньої генерації (`G_ext = 0` при `x > 0`).

Рівняння дифузії спрощується до звичайного диференціального рівняння другого порядку:

```
D_p · (d²(Δp) / dx²) - (Δp / τ_p) = 0
```

Поділимо обидві частини на `D_p`:

```
d²(Δp) / dx² - Δp / (D_p · τ_p) = 0
```

Введемо характеристичний просторовий параметр — **дифузійну довжину неосновних носіїв** `L_p`:

```
L_p = √(D_p · τ_p)
```

Тоді рівняння набуває лінійного канонічного вигляду:

```
d²(Δp) / dx² - (1 / L_p²) · Δp = 0
```

Загальний розв'язок описується лінійною комбінацією двох експонент:

```
Δp(x) = C₁ · exp(- x / L_p) + C₂ · exp(x / L_p)
```

де `C₁` та `C₂` — константи інтегрування, які визначаються граничними умовами.

---

### 5. Аналіз розв'язків для різних граничних умов

Фізичний профіль неосновних носіїв повністю задається геометрією зразка та станом його поверхонь.

#### Випадок А: Напівбезкінечний напівпровідник (`x → ∞`)

Якщо кристал має велику товщину (`W ≫ L_p`), а на поверхні `x = 0` підтримується постійна ін'єкція `Δp(0)`:

1. Гранична умова при `x = 0`: `Δp(0) = C₁ + C₂`
2. Гранична умова при `x → ∞`: `Δp(∞) = 0` (концентрація не може безмежно зростати).

З другої умови негайно маємо `C₂ = 0`. Тоді з першої умови `C₁ = Δp(0)`.

Остаточний розподіл надлишкових дірок:

```
Δp(x) = Δp(0) · exp(- x / L_p)
```

Густина інжектованого дифузійного струму на поверхні `x = 0`:

```
J_diff,p(0)
= - q · D_p · (d(Δp) / dx)|_{x=0}
= - q · D_p · [ - (Δp(0) / L_p) ]
= q · (D_p / L_p) · Δp(0)
```

#### Випадок Б: Тонка база з ідеальним поглиначем (біполярний транзистор)

У тонкому шарі товщиною `W ≪ L_p`, де на лівій межі `x = 0` сидить інжектор (`Δp(0) = Δp_0`), а на правій межі `x = W` розташований зворотний p-n перехід, який миттєво відсмоктує всі носії (`Δp(W) = 0`):

1. `Δp(0) = Δp_0 = C₁ + C₂`
2. `Δp(W) = 0 = C₁ · exp(- W / L_p) + C₂ · exp(W / L_p)`

Виразивши `C₁` та `C₂`, отримуємо точний розв'язок через гіперболічний синус:

```
Δp(x) = Δp_0 · sinh((W - x) / L_p) / sinh(W / L_p)
```

Для тонкої бази (`W ≪ L_p`) використаємо розклад гіперболічного синуса в ряд `sinh(z) ≈ z`:

```
Δp(x)
= Δp_0 · [ (W - x) / L_p ] / [ W / L_p ]     [наближення малого аргументу sinh]
= Δp_0 · (1 - x / W)                          [лінійний профіль в базі]
```

У тонкій базі розподіл носіїв стає **майже строго лінійним**, а рекомбінаційні втрати в об'ємі бази прямують до нуля. Дифузійний струм через базу стає сталим по всій товщині:

```
J_diff,p ≈ q · D_p · (Δp_0 / W)
```

#### Випадок В: Поверхнева рекомбінація з довільною швидкістю S

На реальній поверхні напівпровідника з координатою `x = W` наявні поверхневі стани, які викликають поверхневу рекомбінацію зі швидкістю `S` (`см/с`).

Гранична умова за рахунок поверхневого стоку носіїв має вигляд:

```
- D_p · (d(Δp) / dx)|_{x=W} = S · Δp(W)
```

У результаті сумарний ефективний час життя неосновних носіїв у тонкій пластині товщиною `W` визначається комбінацією об'ємного та поверхневого процесів:

```
1 / τ_eff = 1 / τ_bulk + 2 · S / W
```

При високій швидкості поверхневої рекомбінації (`S → ∞`) ефективний час життя обмежений суто дифузійним виходом носіїв на поверхню:

```
1 / τ_eff ≈ 1 / τ_bulk + π² · D_p / W²
```

### 6. Рівняння амбіполярного транспорту

Коли інжектовані дірки `Δp` дифундують у напівпровідник, рухливі електрони `Δn` миттєво підлаштовуються під їхній профіль для збереження квазінейтральності (`Δn ≈ Δp`).

Запишемо повні рівняння безперервності для електронів та дірок з урахуванням поля `E`:

```
∂(Δp) / ∂t = D_p · (∂²(Δp) / ∂x²) - μ_p · ∂/∂x (p · E) - Δp / τ
∂(Δn) / ∂t = D_n · (∂²(Δn) / ∂x²) + μ_n · ∂/∂x (n · E) - Δn / τ
```

Помножимо перше рівняння на `σ_n = q · μ_n · n`, друге — на `σ_p = q · μ_p · p`, додамо їх і використаємо умову квазінейтральності `∂(Δn)/∂x = ∂(Δp)/∂x`:

Отримуємо **рівняння амбіполярного транспорту**:

```
∂(Δp) / ∂t = D_a · (∂²(Δp) / ∂x²) - μ_a · E · (∂(Δp) / ∂x) - Δp / τ
```

де `D_a` — коефіцієнт амбіполярної дифузії:

```
D_a = (n + p) / (n / D_p + p / D_n) = (D_n · D_p · (n + p)) / (n · D_n + p · D_p)
```

Граничні випадки рівняння амбіполярної дифузії:

1. **Низький рівень ін'єкції в n-типі** (`n ≫ p`):

```
D_a ≈ D_p
```

Швидкість спільного розтікання плазми строго дорівнює коефіцієнту дифузії неосновних носіїв.

2. **Високий рівень ін'єкції** (`n ≈ p`):

```
D_a ≈ (2 · D_n · D_p) / (D_n + D_p)
```

Коефіцієнт дифузії стає усередненим гармонійним значенням для обох типів носіїв.
