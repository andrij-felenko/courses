# 🧮 Математична теорія нуклеації та кінетики кристалізації JMAK

Ця математична вставка містить строгий аналітичний апарат термодинаміки та кінетики фазових перетворень першого роду в матеріалах зі зміною фазового стану: класичну теорію нуклеації (CNT) для обчислення критичного бар'єру зародкоутворення, диференціальну модель Джонсона — Мела — Аврамі — Колмогорова (JMAK) для опису часової еволюції закристалізованого об'єму, гетерогенну нуклеацію на інтерфейсах, неізотермічний аналіз Кіссінджера, теорію релаксації Адама — Ґіббса, модель механічних напружень Аврамі та фазову діаграму Гіббса.

## 1. Класична теорія нуклеації (Classical Nucleation Theory)

Кристалізація аморфного халкогеніду (наприклад, Ge2Sb2Te5) починається з утворення гетерофазних флуктуацій — зародень (нуклеїв) кристалічної фази всередині переохолодженого аморфного середовища. Термодинаміка цього процесу визначається конкуренцією двох протилежних енергетичних факторів: зменшенням вільної енергії системи за рахунок вигіднішого впорядкованого стану кристалічної ґратки та збільшенням енергії через виникнення нової міжфазної межі між аморфною матрицею й зароденем.

Зміна вільної енергії Гіббса `ΔG(r)` при утворенні сферичного кристалічного зародка радіусом `r` складається з двох внесків: від'ємного об'ємного та додатнього поверхневого:

```
ΔG(r) = - (4/3)·π·r³·ΔG_v + 4·π·r²·γ
```

тут:
- `ΔG_v` — різниця вільної енергії Гіббса між аморфною та кристалічною фазами на одиницю об'єму (`Дж/м³`);
- `γ` — питома поверхнева енергія межі аморфна фаза / кристал (`Дж/м²`).

При малих радіусах `r` переважає додатній поверхневий член, пропорційний `r²`. Це означає, що дрібні зародки є термодинамічно нестабільними й прагнуть розчинитися в аморфній матриці. При великих радіусах переважає від'ємний об'ємний член, пропорційний `r³`. Залежність `ΔG(r)` має максимум, який відповідає критичному радіусу зародка `r*`. Зародки з радіусом `r > r*` стають стабільними та здатними до самовільного подальшого росту.

Для знаходження критичного радіуса `r*` береться перша похідна від функції `ΔG` по змінній `r` та прирівнюється до нуля:

```
d(ΔG)/dr = 0
- 4·π·(r*)²·ΔG_v + 8·π·r*·γ = 0                [диференціювання по радіусу r]
4·π·r* · (2·γ - r*·ΔG_v) = 0                   [винесення спільного множника]
r* = 2·γ / ΔG_v                                [критичний радіус зародка]
```

Підстановка знайденого виразу `r*` назад у формулу вільної енергії визначає термодинамічний потенціальний бар'єр нуклеації `ΔG*`, який флуктуація повинна подолати для утворення стійкого кристаліта:

```
ΔG* = ΔG(r*)
= - (4/3)·π·(2·γ / ΔG_v)³·ΔG_v + 4·π·(2·γ / ΔG_v)²·γ
= - (32/3)·π·γ³ / (ΔG_v)² + 16·π·γ³ / (ΔG_v)²    [піднесення до куба та квадрата]
= (16·π·γ³) / (3·(ΔG_v)²)                      [висота бар'єру нуклеації]
```

Об'ємна термодинамічна рушійна сила кристалізації `ΔG_v` залежить від ступеня переохолодження матеріалу `ΔT = T_m - T` (де `T_m` — температура плавлення халкогеніду). У лінійному наближенні Тернбалла ця залежність має вигляд:

```
ΔG_v ≈ ΔH_m · (T_m - T) / (T_m · V_m)
```

де `ΔH_m` — прихована молярна теплота плавлення, а `V_m` — молярний об'єм речовини. Отже, при наближенні до температури плавлення `T → T_m` рушійна сила прямує до нуля `ΔG_v → 0`, а критичний бар'єр нуклеації прямує до нескінченності `ΔG* → ∞`. Це пояснює, чому безпосередньо поблизу точки плавлення кристали не можуть самовільно зароджуватися.

## 2. Швидкість нуклеації та швидкість росту кристалів

Інтенсивність кристалізаційного процесу визначається двома незалежними кінетичними параметрами: швидкістю утворення нових зародків `I(T)` та швидкістю просування міжфазної межі `u(T)`.

Стаціонарна швидкість зародкоутворення `I(T)` (кількість критичних зародків, що виникають в одиниці об'єму за одиницю часу, `1/(м³·с)`) описується формулою Арреніуса з урахуванням термодинамічного та дифузійного множників:

```
I(T) = I_0 · exp(- ΔG* / (k_B · T)) · exp(- E_a / (k_B · T))
```

де:
- `I_0` — предекспоненційний фактор (кінетична частота спроб, порядок `10³³ – 10³⁶ 1/(м³·с)`);
- `E_a` — енергія активації атомарного переміщення та перебудови зв'язків в аморфній фазі;
- `k_B` — константа Больцмана (`1.38 × 10⁻²³ Дж/К`).

Перша експонента визначає ймовірність термодинамічної флуктуації потрібного розміру, а друга — швидкість дифузійного приєднання атомів до зародка.

Лінійна швидкість росту кристалічної фази `u(T)` (`м/с`) описується моделлю Вілсона — Френкеля, яка враховує як енергію активації атомарного переходу `E_d`, так і ймовірність зворотного розчинення атомів з поверхні кристала:

```
u(T) = u_0 · exp(- E_d / (k_B · T)) · (1 - exp(- ΔG_v / (k_B · T)))
```

Обидві величини — `I(T)` та `u(T)` — є асиметричними куполоподібними функціями температури. При низьких температурах, близьких до температури склування `T_g`, кристалізація блокується в'язкістю матеріалу та високим дифузійним бар'єром (`exp(-E_a / k_B·T) → 0`). При високих температурах поблизу точки плавлення `T_m` кристалізація припиняється через термодинамічне зникнення рушійної сили (`ΔG_v → 0`). Максимум швидкості фазового переходу знаходиться в температурному інтервалі між `T_g` та `T_m` (для халкогеніду GST-225 це діапазон `350–450 °C`).

## 3. Кінетичне рівняння Джонсона — Мела — Аврамі — Колмогорова (JMAK)

Під час масової кристалізації аморфної плівки окремі кристаліти ростуть у всіх напрямках, стикаються межами та перекривають один одного. Строгий облік геометричного стеричного перекриття зерен є головною задачею теорії JMAK.

Нехай `X(t)` — реальна об'ємна частка закристалізованої речовини в момент часу `t` (`0 ≤ X ≤ 1`). Для уникнення складного обліку геометрії зіткнень вводиться фіктивна математична величина — узагальнений (розширений) закристалізований об'єм `X_ext(t)` (extended volume). Це об'єм, який сформували б усі зародки, якби вони проростали скрізь безперешкодно, ігноруючи існування інших зерен та стінок зразка.

Диференціальний зв'язок між приростом реального об'єму `dX` та приростом узагальненого об'єму `dX_ext` визначається ймовірністю того, що новий елементарний об'єм припадає на незакристалізовану аморфну матрицю `(1 - X)`:

```
dX = (1 - X) · dX_ext                          [диференціальний баланс об'ємів]
dX / (1 - X) = dX_ext                          [відокремлення змінних]
```

Інтегрування обох частин цього диференціального рівняння від початкового стану `X = 0, X_ext = 0` до поточного стану `t`:

```
∫₀ˣ dX / (1 - X) = ∫₀ᵀᵉˣᵗ dX_ext
- ln(1 - X) = X_ext                            [обчислення первісних]
1 - X = exp(- X_ext)                           [потенціювання рівняння]
X(t) = 1 - exp(- X_ext(t))                     [інтегральна формула JMAK]
```

Для стаціонарного тривимірного ізотермічного процесу з постійною швидкістю зародкоутворення `I` та постійною ізотропною швидкістю росту `u` сферичних кристалітів узагальнений об'єм `X_ext(t)` обчислюється шляхом інтегрування об'ємів усіх зерен, що зародилися у проміжках часу `τ`:

```
X_ext(t) = ∫₀ᵗ I · (4/3)·π·[u · (t - τ)]³ dτ
= (4/3)·π·I·u³ · ∫₀ᵗ (t - τ)³ dτ              [винесення констант]
= (4/3)·π·I·u³ · [-(t - τ)⁴ / 4]₀ᵗ            [інтегрування полінома]
= (1/3)·π·I·u³ · t⁴                            [узагальнений об'єм сферичних зерен]
```

Підставляючи одержаний результат у загальну формулу JMAK, отримуємо класичне кінетичне рівняння:

```
X(t) = 1 - exp(- K · tⁿ)
```

де:
- `K = (1/3)·π·I·u³` — ефективна константа швидкості фазового переходу (`1/сⁿ`);
- `n` — показник Аврамі (Avrami exponent).

Показник Аврамі `n` відображає геометрію та фізичний механізм фазового перетворення:
- `n = 4` — об'ємна кристалізація (3D) за постійної швидкості нуклеації (`I = const`);
- `n = 3` — об'ємна кристалізація (3D) на заздалегідь наявних готових центрах нуклеації (`I = 0`, ріст існуючих зерен);
- `n = 2` — двовимірний ріст (2D) в ультратонких плівках при гетерогенній нуклеації на поверхнях;
- `n = 1` — одновимірний ріст (1D) уздовж провідних каналів або ниток.

## 4. TTT-діаграми та розрахунок швидкостей загартування

З інтегрального рівняння JMAK можна аналітично виразити час `t_X`, необхідний для досягнення заданого ступеня кристалізації `X` (наприклад, `X = 0.99` для повного завершення переходу) при сталій температурі `T`:

```
- ln(1 - X) = K(T) · tⁿ
t_X(T) = [ - ln(1 - X) / K(T) ]^(1/n)
```

Побудова залежності `t_X(T)` у координатах `(T, log t)` дає характеристичну C-подібну криву на **TTT-діаграмі (Temperature-Time-Transformation)**.

Найважливішою точкою TTT-діаграми є «ніс» C-кривої — мінімум часу кристалізації `t_min` при оптимальній температурі `T_nose`. У цій точці добуток швидкості нуклеації та швидкості росту `I(T) · u³(T)` досягає свого абсолютного максимуму. Для халкогенідного сплаву Ge2Sb2Te5 значення `t_min` становить менше `10–20 наносекунд` при температурі `T_nose ≈ 400 °C`.

Щоб під час електричного чи оптичного імпульсу **RESET** заморозити розплавлений рідкий халкогенід у безладовому аморфному стані, швидкість охолодження `dT/dt` повинна перевищувати критичну швидкість загартування `R_crit`:

```
R_crit ≈ (T_m - T_nose) / t_min
```

Для матеріалу GST-225 критична швидкість гасіння становить:

```
R_crit ≈ (600 - 400) K / (10 × 10⁻⁹ с) = 2 × 10¹⁰ K/с
```

Якщо спад напруги або лазерного імпульсу забезпечує охолодження зі швидкістю понад `10¹⁰ K/с`, траєкторія температури проходить ліворуч від «носа» TTT-кривої, не перетинаючи лінію початку кристалізації. У результаті атоми не встигають перебудуватися у кристалічну ґратку й заморожуються у метастібільному аморфному стані з високим опором.

## 5. Неізотермічний аналіз Кіссінджера для експериментального визначення E_a

Для експериментального вимірювання ефективної енергії активації кристалізації `E_a` халкогенідних плівок використовують неізотермічні калориметричні вимірювання методом диференціальної скануючої калориметрії (DSC) при різних швидкостях нагріву `β = dT/dt` (`К/мін`).

Метод Кіссінджера (Kissinger method) базується на диференціюванні рівняння JMAK за умов постійної швидкості нагріву `T(t) = T_0 + β · t`. Температура піку екзотермічного кристалізаційного виділення тепла `T_p` зміщується у бік вищих температур при збільшенні швидкості нагріву `β`.

Рівняння Кіссінджера має вигляд:

```
ln( β / T_p² ) = - E_a / ( R · T_p ) + C
```

де:
- `β` — швидкість нагріву зразка (`К/с`);
- `T_p` — температура піку кристалізації на калориметричній кривій (`К`);
- `E_a` — ефективна енергія активації кристалізації (`Дж/моль`);
- `R` — універсальна газова стала (`8.314 Дж/(моль·К)`);
- `C` — константа, що залежить від предекспоненційного фактора.

Побудова експериментального графіка залежності `ln(β / T_p²)` від оберненої температури `1 / T_p` дає пряму лінію, тангенс кута нахилу якої дорівнює `- E_a / R`. Для матеріалу `Ge2Sb2Te5` знайдена енергія активації кристалізації становить `E_a ≈ 2.2 – 2.4 еВ` (`212–230 кДж/моль`), що підтверджує високу термічну стабільність аморфного стану при кімнатній температурі.

## 6. Гетерогенна нуклеація на міжфазних межах

У тонких плівках халкогенідів та комірках PCRAM зародкоутворення майже завжди відбувається не у чистому об'ємі (гомогенно), а гетерогенно — на межах розділу халкогенід / діелектрик (`SiO2/Si3N4`) або халкогенід / металевий нагрівач (`TiN/W`).

Поверхня підкладки зменшує енергетичний бар'єр нуклеації за рахунок геометричного фактора змочування `f(θ)`:

```
ΔG*_het = ΔG*_hom · f(θ)
```

Формула геометричного фактора сферичного капелюха зародка з кутом змочування `θ`:

```
f(θ) = ( (2 + cos θ) · (1 - cos θ)² ) / 4
```

Оскільки `0 ≤ f(θ) ≤ 1`, при хорошому змочуванні (`θ < 90°`) енергетичний бар'єр зародження на межі контакту падає на `50–80%`. Це пояснює, чому у реальних Mushroom Cell осередках кристалізація під час імпульсу SET завжди стартує від точкового контакту з нижнім нагрівачем `TiN`, поширюючись далі вглиб аморфного купола.

## 7. Теоретична модель нестаціонарної затримки нуклеації Кашчиєва

При надкоротких електричних імпульсах наносекундної тривалості (`τ_pulse < 10 нс`) швидкість зародкоутворення `I(t)` не встигає миттєво вийти на стаціонарний рівень `I_st`. Необхідний певний часовий інтервал релаксації для побудови рівноважного розподілу зародків за розмірами.

Нестаціонарна часова еволюція швидкості нуклеації описується рівнянням Кашчиєва:

```
I(t) = I_st · [ 1 + 2 · ∑ₘ₌₁∞ (-1)ᵐ · exp( - m² · t / τ_lag ) ]
```

де `τ_lag` — час затримки нуклеації (nucleation time-lag), що виражається через коефіцієнт дифузії атомів `D*` у критичному зародку:

```
τ_lag = (4 · k_B · T) / (π² · D* · ΔG_v)
```

При тривалостях імпульсу `t < τ_lag` значення `I(t) → 0`, що робить кристалізацію фізично неможливою. Цей ефект задає абсолютну фундаментальну нижню межу швидкості запису SET для даного сплаву. Для GST-225 час затримки Кашчиєва становить `τ_lag ≈ 1 – 3 нс` при температурі `400 °C`, що визначає максимально досяжну часову дискретизацію запису даних.

## 8. Модель в'язкоеластичної релаксації Адама — Ґіббса

В'язкість переохолодженого розплаву `η(T)` халкогеніду суттєво регулює коефіцієнт дифузії атомів `D = k_B · T / (6 · π · η · r_atom)` за співвідношенням Стокса — Ейнштейна. Згідно з теорією Адама — Ґіббса (Adam-Gibbs model), в'язкість пов'язана з конфігураційною ентропією рідини `S_c(T)`:

```
η(T) = A · exp( C / (T · S_c(T)) )
```

де `A` та `C` — матеріалознавчі сталі, а `S_c(T) = ∫_Tg^T (ΔC_p / T) dT`.

При охолодженні рідини нижче температури склування `T_g` конфігураційна ентропія різко заморожується, що спричиняє експоненційне зростання в'язкості до значень `η > 10¹² Па·с`. Це повністю припиняє переміщення атомів і забезпечує термодинамічную довговічність збереженого аморфного стану.

## 9. Пружно-механічний внесок у потенціальний бар'єр кристалізації

При фазовому переході з аморфної у кристалічну фазу матеріал `Ge2Sb2Te5` зазнає значного об'ємного стиснення (густина збільшується від `5880 кг/м³` до `6270 кг/м³`, що відповідає об'ємній усадці `ΔV/V ≈ 6.5%`). В жорсткій матриці діелектрика `SiO2` це викликає виникнення значних пружних напружень `σ_stress ≈ 100 – 300 МПа`.

Додаткова пружна енергія деформації `ΔG_stress` збільшує критичний бар'єр нуклеації:

```
ΔG_total(r) = - (4/3)·π·r³·(ΔG_v - E_elastic) + 4·π·r²·γ
```

де `E_elastic = (1/2) · E_Young · (ε_misfit)² / (1 - ν_Poisson)` — питома пружна енергія.

Наявність пружних напружень гальмує кристалізацію у затиснутих комірках, що вимагає підвищення напруги програмування SET на `10–15%` для компенсації механічного бар'єру.

## 10. Термодинаміка потрійної діаграми Гіббса для сплавів Ge-Sb-Te

Матеріалознавчий квазібінарний розріз `GeTe - Sb2Te3` у потрійній системі `Ge-Sb-Te` описується за допомогою термодинамічних потенціалів Гіббса для багатокомпонентних фаз. Стехіометричний сплав `Ge2Sb2Te5` відповідає точці молярного співвідношення 2:1 між `GeTe` та `Sb2Te3`.

Термодинамічний потенціал змішування аморфної рідини `ΔG_mix` обчислюється в наближенні регулярного розчину:

```
ΔG_mix = ΔH_mix - T · ΔS_mix
```

де `ΔH_mix = Ω · x_GeTe · x_Sb2Te3` (де `Ω` — параметр взаємодії), а `ΔS_mix = - R · [ x · ln(x) + (1-x) · ln(1-x) ]`.

При тривалому високотемпературному відпалі (`T > 500 °C`) або тривалому циклуванні метастібільний сплав `Ge2Sb2Te5` може розпадатися за спинодальним механізмом на дві стабільні фази `GeTe` та `Sb2Te3`. Це розшарування супроводжується локальним зміщенням температури плавлення та утворенням зеренних меж із підвищеним опором, що є однією з причин деградації комірок пам'яті.

## 11. Квантовий радіус поларона та стрибковий транспорт Мотта

В аморфному халкогеніді електрони переносяться за рахунок стрибків по локалізованих станах поблизу рівня Фермі. Довжина стрибка `R_hop` та енергія активації `W_hop` описуються моделлю Мотта для провідності зі змінною довжиною стрибка (Variable-Range Hopping, VRH):

```
σ(T) = σ_0 · exp[ - (T_0 / T)^(1/4) ]
```

де `T_0 = 18 · α³ / (k_B · N(E_F))`, `α` — параметр згасання хвильової функції локалізованого електрона (`1/α ≈ 0.5 – 1 нм`), а `N(E_F)` — густина станів на рівні Фермі.

Утворення дрібного поларона (малого поляризаційного збудження ґратки навколо зарядженого дефекту `C_3⁺` чи `C_1⁻`) додатково локалізує носії. Квантовий радіус поларона `r_polaron ≈ 0.3 нм` порівнянний із міжатомною відстанню, що пояснює наднизьку рухливість електронів в аморфному стані (`μ_amo < 0.1 см²/(В·с)` проти `μ_cry ≈ 10–20 см²/(В·с)` у кристалі).

## 12. Співвідношення Крамерса — Кроніґа та оптичний контраст

Оптичний контраст коефіцієнта відбиття `ΔR/R` між аморфною та кристалічною фазами математично зв'язаний із дійсною `ε_1(ω)` та уявною `ε_2(ω)` частинами діелектричної проникності через співвідношення Крамерса — Кроніґа:

```
ε_1(ω) = 1 + (2/π) · P ∫₀∞ [ x · ε_2(x) / (x² - ω²) ] dx
```

У кристалічному стані поява делокалізованих p-орбітальних резонансних зв'язків додає потужний пік у спектр диперсійного поглинання `ε_2(ω)` на низьких частотах. За інтегралом Крамерса — Кроніґа це викликає стрибкоподібне зростання низькочастотної діелектричної проникності `ε_1(0)` від `15` в аморфній фазі до `30` у кристалі, що й визначає гігантську зміну коефіцієнта відбиття світла `R = |(√ε - 1) / (√ε + 1)|²` на `25–30%`. Цей квантово-оптичний ефект уможливив роботу всіх поколінь оптичних носіїв інформації від CD-RW до тришарових дисків Blu-ray BD-RE, де потужність зчитувального лазера підбирається так, щоб не викликати нагріву активного шару та забезпечувати високу стійкість до зчитування без руйнування записаних даних.
