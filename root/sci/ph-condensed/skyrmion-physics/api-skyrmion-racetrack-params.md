# 📋 Специфікація та параметри магнітних матеріалів для скироміонної трекової пам'яті

Цей довідник містить технічні параметри, мікромагнітні константи матеріалів, критерії стійкості, розрахункові інваріанти та специфікації спін-орбітальних інтерфейсів для проектування пристроїв скирміонної трекової пам'яті (Skyrmion Racetrack Memory).

## 1. Специфікація мікромагнітних параметрів матеріалів

Для термодинамічної стійкості скирміонів кімнатної температури матеріал має володіти оптимізованим співвідношенням між обмінною жорсткістю `A`, інтерфейсною взаємодією Дзялошинського — Моріа `D`, перпендикулярною магнітною анізотропією `K_u` та намагніченістю насичення `M_s`.

| Матеріальна гетероструктура | Тип скирміона | Температура існування `T` (K) | Обмінна жорсткість `A` (pJ/m) | Константа DMI `D` (mJ/m²) | Перпендикулярна анізотропія `K_u` (kJ/m³) | Намагніченість насичення `M_s` (kA/m) | Характерний діаметр `d_sk` (nm) |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| `Pt / Co (0.8 nm) / MgO` | Неєлівський | 300 | 15.0 | 1.8–2.2 | 800 | 1100 | 50–100 |
| `Ta / CoFeB (1.0 nm) / MgO` | Неєлівський | 300 | 10.0 | 0.8–1.2 | 450 | 800 | 80–150 |
| `Ir / Fe (0.5 nm) / Co (0.5 nm) / Pt` | Неєлівський | 300 | 12.0 | 1.5–2.0 | 600 | 950 | 30–60 |
| `[Pt / Co / Pt]_N` (багатошаровий) | Неєлівський | 300 | 16.0 | 1.2–1.6 | 700 | 1000 | 60–120 |
| `MnSi` (монокристал `B20`) | Блохівський | 28–29 | 0.28 | 0.09 | 0 (кубічний) | 160 | 18 |
| `FeGe` (об'ємний кристал) | Блохівський | 270–278 | 0.87 | 0.25 | 0 (кубічний) | 380 | 70 |
| `Mn₂PtSn` (геуслерів сплав `D₂d`) | Антискирміон | 300–400 | 8.5 | 0.45 (анізотропний) | 320 | 450 | 100–250 |
| `[Pt/Co/Ru/Co/Pt]` (SAF трек) | Неєлівський (SAF) | 300 | 14.0 | 1.5 | 650 | 0 (компенсована) | 10–30 |

### Фізична інтерпретація фундаментальних параметрів

- **Обмінна жорсткість (`A`):** визначає квантовомеханічний опір матеріалу неоднорідному розвороту спінів. Чим вище значення `A`, тим «жорсткішою» є магнітна система, і тим більшим стає діаметр скирміона.
- **Константа DMI (`D`):** характеризує інтенсивність асиметричного надобміну, викликаного спін-орбітальним зв'язком у розриві симетрії інверсії. Високі значення `D > 1.5 mJ/m²` необхідні для формування нанометрових скирміонів за відсутності зовнішніх магнітних полів.
- **Перпендикулярна магнітна анізотропія (`K_u`):** виникає за рахунок інтерфейсного гібридизування орбіталей на межі `Co/MgO` або `Fe/Pt`. Вона утримує фонову намагніченість строго перпендикулярно до площини треку, запобігаючи розпаду скирміонів у площинні домени.
- **Намагніченість насичення (`M_s`):** визначає повний магнітний момент одиниці об'єму матеріалу. Висока `M_s` підвищує розмагнічувальні поля (диполь-дипольну взаємодію), що вимагає додаткового підсилення `K_u` для збереження перпендикулярної орієнтації.

## 2. Безрозмірний параметр Дзялошинського `κ` та вікно стійкості

Для формування стабільних ізольованих скирміонів без переходу у спіральну смугасту фазу (stripe domain phase) безрозмірний параметр Дзялошинського `κ` повинен задовольняти суворе вікно значень:

```
κ = (π · D) / (4 · √(A · K_eff))
```

де `K_eff = K_u - (1/2) μ₀ M_s²` — ефективна магнітна анізотропія з урахуванням розмагнічувального поля тонкої плівки.

Фізична класифікація термодинамічних режимів залежно від величини `κ`:

1. **Режим колапсу (`κ < 0.6`):**
   Взаємодія DMI є недостатньо сильною, щоб компенсувати енергетичні витрати на утворення доменної стінки скирміона. Якщо скирміон зародити штучно, він є метастабільним і під дією перпендикулярної анізотропії `K_eff` швидко стискається до повного колапсу (`R_sk → 0`).

2. **Режим метастабільних та стабільних ізольованих скирміонів (`0.6 ≤ κ < 1.0`):**
   Оптимальне технологічне вікно для пристроїв трекової пам'яті. Повна енергія ізольованого скирміона має локальний мінімум при скінченному радіусі `R_sk > 0`. Скирміони є термодинамічно стійкими квазічастинками, які не колапсують і не зливаються між собою за наявності помірного зовнішнього поля або утримувального внутрішнього потенціалу.

3. **Спіральний та лабіринтний режим (`κ ≥ 1.0`):**
   Взаємодія DMI домінує над анізотропією. Енергія доменної стінки стає від'ємною (`E_dw < 0`), через що однорідний феромагнітний стан стає нестійким. У плівці спонтанно утворюється спіральна (лабіринтна) доменна фаза або щільна ґратка скирміонів, у якій усунено можливість керувати поодинокими ізольованими бітами.

## 3. Динаміка та характеристики струмового керування (Spin-Orbit Torque, SOT)

Переміщення скирміонів вздовж магнітного нанотрека здійснюють імпульсами електричного струму заряду `I_e` через підкладку важкого металу (`Pt`, `Ta`, `W`), що генерує спіновий струм `J_s` завдяки спіновому ефекту Холла (Spin Hall Effect).

### 3.1. Параметри спін-орбітального транспорту

- **Кут спінового Холла (Spin Hall Angle, `θ_SH`):** виражає ефективність перетворення поздовжнього електричного струму заряду у поперечний спіновий струм: `J_s = θ_SH · J_e`.
  - Платина (`Pt`): `θ_SH = +0.08 ... +0.12` (позитивний знак, спіни з полярністю `+y` відхиляються догори);
  - Тантал (`Ta`): `θ_SH = -0.12 ... -0.15` (негативний знак);
  - Вольфрам (`β-W`): `θ_SH = -0.30 ... -0.40` (рекордно висока ефективність за рахунок аморфної фази `β-W`).
- **Критична густина струму для початку руху (`j_c`):** `10⁵ – 10⁶ A/m²` (порівняно з `10¹¹ A/m²` для звичайних доменних стінок).
- **Максимальна швидкість руху скирміона (`v_sk`):** `100 – 750 m/s` при густині струму `j_e = 10¹¹ A/m²`.
- **Ефективне поле спін-орбітального моменту (SOT Field):**
  - Польоподібне поле (Field-like torque): `H_FL = (ħ θ_FL j_e) / (2 e M_s t_FM)`
  - Демпфінгоподібне поле (Damping-like torque): `H_DL = (ħ θ_SH j_e) / (2 e M_s t_FM)`

### 3.2. Рівняння Тіле та Холівський ефект скирміона (Skyrmion Hall Effect)

Динаміку скирміона як цілісної квазічастинки описують узагальненим рівнянням Тіле, яке отримують шляхом інтегрування рівняння Ландау — Ліфшиця — Гільберта по просторовій площині скирміона:

```
G × v - D_d · v + F_SOT + F_pin = 0
```

Компоненти рівняння Тіле мають наступний фізичний зміст:
- `G = (0, 0, 4π Q M_s t_FM / γ_0)` — гіровектор (Magnus gyrovector), пропорційний топологічному заряду `Q`. Він створює гіроскопічну силу Магнуса `F_M = G × v`, спрямовану перпендикулярно до вектору швидкості.
- `D_d` — тензор дисипації (магнітна релаксація Гільберта `α`), який описує в'язке тертя скирміона об кристал: `D_xx = D_yy = π α M_s t_FM / γ_0 · ∫ ( (∂m/∂x)² ) r dr`.
- `v = (v_x, v_y)` — вектор швидкості центра мас скирміона.
- `F_SOT` — рушійна сила спін-орбітального моменту, пропорційна густині струму `j_e` та куту спінового Холла `θ_SH`.
- `F_pin` — сила зачеплення на дефектах кристалічної ґратки (pinning force).

Через наявність гіровектора `G` скирміон відхиляється від напрямку руху струму під кутом Скирміонівського ефекту Холла (Skyrmion Hall Angle, `θ_Sk`):

```
tan θ_Sk = v_y / v_x = G_z / (α · D_xx)
```

Для типових феромагнітних плівок `θ_Sk = 10° ... 30°`. Це створює загрозу зміщення скирміона до бокового краю треку та його анігіляції на межі нанодроту.

## 4. Синтетичні антиферомагнітні треки (SAF Racetrack Design)

Для повного приглушення скирміонівського ефекту Холла (`θ_Sk = 0`) та забезпечення прямолінійного руху застосовують синтетичні антиферомагнітні (Synthetic Antiferromagnetic, SAF) треки складу `[Pt / Co / Ru / Co / Pt]`.

### 4.1. Геометрична та фізична специфікація SAF трека

- **Товщина феромагнітних шарів `Co`:** `t_FM1 = 0.8 nm`, `t_FM2 = 0.8 nm` (суворо симетричні шари).
- **Немагнітний прошарок рутенію `Ru`:** `t_Ru = 0.8–0.9 nm` (відповідає першому антиферомагнітному піку Рудермана — Киттеля — Касуї — Йосіди, RKKY).
- **Енергія антиферомагнітного міжшарового обміну `J_RKKY`:** `-0.5 ... -1.5 mJ/m²`.
- **Результуючий магнітний момент:** `M_tot = M₁ - M₂ = 0` (повністю скомпенсована макроскопічна намагніченість, що усуває магнітостатичні поля розсіювання).

### 4.2. Сумарний гіровектор SAF скирміона

У SAF треку скирміон складається з двох куплованих Неєлівських скирміонів у верхньому та нижньому шарах із протилежними напрямками намагніченості в ядрах (`Q₁ = +1` у верхньому шарі та `Q₂ = -1` у нижньому відносно єдиної осі z):

```
G_tot = G₁ + G₂ = 0
```

Оскільки сумарний гіровектор дорівнює нулю, Магнусівська сила зникає (`F_M = 0`), скирміон рухається суворо прямолінійно вздовж осі треку зі підвищеною швидкістю (до `1000 m/s`), а критичний струм руху зменшується до `j_c < 10⁵ A/m²`.

### 5.1. Критерії термодинамічної стабільності бітів

Для надійного збереження записаних даних протягом 10 років без збоїв параметр теплової стабільності `Δ` повинен задовольняти критерію:

```
Δ = E_barrier / (k_B · T) ≥ 50 ... 60
```

де `E_barrier` — енергетичний бар'єр анігіляції скирміона, `k_B` — константа Больцмана, а `T = 300 K` — робоча температура. Завдяки топологічному захисту скирміони з діаметром `d_sk = 20 nm` забезпечують `Δ > 60` при значно меншому об'ємі порівняно з класичними прямокутними магнітними доменами.

### 5.2. Системні показники енергоефективності

- **Енергія на операцію запису біта:** `< 100 fJ` (фемтоджоулів).
- **Енергія на операцію зсуву біта на один осередок:** `< 1 fJ`.
- **Робоча тактова частота зсуву бітів:** `1 – 3 GHz`.
- **Зносостійкість (Write Endurance):** `> 10¹⁵` циклів перезапису (перевищує показники флеш-пам'яті NAND на 10 порядків).
