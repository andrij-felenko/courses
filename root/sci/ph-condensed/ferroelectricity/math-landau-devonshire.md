# 🧮 Потенціал Ландау — Девоншира та термодинаміка сегнетоелектричних переходів

Феноменологічна теорія фазових переходів Ландау — Гінзбурга — Девоншира описує сегнетоелектричний стан без необхідності розв'язання багаточастинкових квантовомеханічних рівнянь для тисяч взаємодіючих іонів у кристалічній ґратці. Вона базується на фундаментальних принципах термодинаміки та симетрії кристалів, розглядаючи макроскопічну спонтанну поляризацію `P` як термодинамічний параметр порядку (order parameter), а густину вільної енергії системи розкладає у степеневий ряд за парними степенями цього параметра поблизу критичної точки переходу.

Ця математична вставка містить строгий аналітичний апарат теорії: від симетрійного обґрунтування розкладу вільної енергії Гіббса та аналізу фазових переходів другого й першого роду до виведення закону двійки для сприйнятливості, розрахунку внутрішнього коерцитивного поля Ландау, динаміки релаксації Ландау — Халатникова, структури доменної стінки та термодинаміки електрокалоричного ефекту.

---

### 1. Повний розклад термодинамічного потенціалу Гіббса та симетрійні основи

У термодинаміці твердого тіла за незалежні змінні стану обирають температуру `T`, напруженість зовнішнього електричного поля `E` та тензор механічних напружень `σ`. Відповідним характеристичним термодинамічним потенціалом є густина вільної енергії Гіббса `G(P, T, E, σ)`. Для ізотропного або одновісного сегнетоелектрика, в якому вектор спонтанної поляризації спрямований уздовж виділеної кристалографічної полярної осі `z` (`P = P_z`), потенціал розглядають як скалярну функцію величини поляризації `P`.

#### Симетрійне обґрунтування парних степенів

Високотемпературна пароелектрична фаза сегнетоелектричного кристала (наприклад, кубічна фаза перовськіту `BaTiO3` зі структурою типу `Pm3̄m`) володіє центром просторової інверсії. Це означає, що кристалічна ґратка є абсолютно інваріантною відносно просторового перетворення `r → -r`. 

Оскільки поляризація `P` є полярним вектором, при операції інверсії вона змінює знак на протилежний (`P → -P`). Густина вільної енергії кристала є скалярною величиною і за відсутності зовнішнього поля (`E = 0`) не може залежати від вибору напрямку полярної осі: стани з `+P` та `-P` володіють строго однаковою термодинамічною енергією:

```
G(P, T) = G(-P, T)     [вимога просторової інверсійної симетрії пароелектричної фази]
```

Звідси випливає фундаментальна теорема симетрії Ландау: вільна енергія кристала в околі точки фазового переходу розкладається виключно за парними степенями параметра порядку (`P²`, `P⁴`, `P⁶`...). Непарні члени (`P`, `P³`, `P⁵`) у розкладі за відсутності поля строго тотожно дорівнюють нулю. Взаємодія поляризації із зовнішнім електричним полем `E` додає лінійний внесок енергії диполя в електричному полі `- E · P`.

Повний одновимірний розклад термодинамічного потенціалу Ландау — Девоншира має вигляд:

```
G(P, T, E) = G₀ + (1/2)·α·P² + (1/4)·β·P⁴ + (1/6)·γ·P⁶ - E·P
```

Тут `G₀(T)` — вільна енергія неполяризованого пароелектричного кристала (`P = 0`), а коефіцієнти `α`, `β`, `γ` є феноменологічними параметрами матеріалу. Дробові множники `1/2`, `1/4`, `1/6` уведено для зручності диференціювання.

#### Температурна залежність коефіцієнта α та закон Кюрі — Вейсса

За постулатом теорії Ландау, коефіцієнти вищих степенів `β` та `γ` поблизу точки переходу вважаються слабкими додатними або сталими функціями температури, тоді як головна термічна нестабільність системи повністю зосереджена в найнижчому квадратичному коефіцієнті `α(T)`.

Коефіцієнт `α(T)` лінійно залежить від температури і змінює свій знак у критичній точці `T₀` (температурі Кюрі — Вейсса):

```
α(T) = α₀ · (T - T₀) = (T - T₀) / (ε₀ · C)
```

де `α₀ = 1 / (ε₀ · C) > 0` — стала матеріалу, `ε₀ ≈ 8.854 × 10⁻¹² Ф/м` — електрична стала вакууму, а `C` — стала Кюрі.

Зміна знака коефіцієнта `α(T)` має глибоку мікроскопічну природу. Згідно з концепцією м'якої моди Кохрана (Cochran soft mode), квадрат частоти поперечного оптичного фонона `ω_TO` у центрі зони Бріллюена лінійно зменшується при охолодженні:

```
ω_TO²(T) = A · (T - T₀)     [закон пом'якшення критичної фононної моди]
```

Зі співвідношення Лідейна — Сакса — Теллера (Lyddane — Sachs — Teller relation) випливає, що спадання пружної відновлювальної сили ґратки (`ω_TO → 0`) призводить до розбіжності статичної діелектричної проникності, що в макроскопічній термодинаміці відповідає зміні знака `α(T)` від додатного до від'ємного.

#### Тривимірний анізотропний потенціал Девоншира для перовськітів

У реальних тривимірних сегнетоелектриках зі структурою перовськіту (зокрема `BaTiO3` та `PbTiO3`) вектор спонтанної поляризації має три просторові компоненти `P = (P_x, P_y, P_z)`. Вільна енергія має бути інваріантною відносно всіх 48 операцій симетрії кубічної точкової групи `m3̄m`.

А. Девоншир (A. Devonshire) узагальнив потенціал Ландау для кубічної фази, побудувавши повний набір незалежних інваріантів до шостого порядку:

```
G(P) = G₀ + (1/2)·α·(P_x² + P_y² + P_z²)
     + (1/4)·β₁·(P_x⁴ + P_y⁴ + P_z⁴) + (1/2)·β₂·(P_x²·P_y² + P_y²·P_z² + P_z²·P_x²)
     + (1/6)·γ₁·(P_x⁶ + P_y⁶ + P_z⁶)
     + (1/2)·γ₂·[ P_x⁴·(P_y² + P_z²) + P_y⁴·(P_z² + P_x²) + P_z⁴·(P_x² + P_y²) ]
     + (1/2)·γ₃·(P_x²·P_y²·P_z²) - E · P
```

Співвідношення між коефіцієнтами `β₁` та `β₂` визначає просторову орієнтацію вектора поляризації при зниженні температури:
- Якщо `β₁ > 0` та `β₂ > -β₁`, мінімум енергії реалізується вздовж осей типу `[001]`: виникає тетрагональна сегнетофаза (`P_x = P_y = 0`, `P_z = P_s`), що спостерігається у `BaTiO3` в діапазоні від 5 °C до 120 °C.
- Якщо переважають перехресні члени, вектор `P_s` повертається вздовж діагоналей граней `[110]` (орторомбічна фаза) або головних просторових діагоналей куба `[111]` (ромбоедрична фаза при `T < -90 °C`).

#### Електрострикційний зв'язок та ренормування коефіцієнтів

У реальному твердому тілі поляризація ґратки нерозривно пов'язана з її механічною деформацією через явище електрострикції (квадратичний зв'язок деформації з поляризацією). Густина енергії вільного кристала записується через пружну енергію та електрострикційний тензор `q_ijkl`:

```
G_elast = (1/2)·s_ijkl·σ_ij·σ_kl - Q_ijkl·σ_ij·P_k·P_l
```

де `s_ijkl` — тензор пружної піддатливості, `Q_ijkl` — коефіцієнти електрострикції, а `σ_ij` — тензор механічних напружень.

Якщо кристал механічно вільний (`σ = 0`), деформації вільно релаксують до значень `u_ij = Q_ijkl · P_k · P_l`. Підстановка цих деформацій назад у вільну енергію перенормовує коефіцієнт `β`:

```
β_free = β_clamped - 2 · Q² / s     [ренормування коефіцієнта четвірки за рахунок пружної релаксації]
```

де `β_clamped` — коефіцієнт для затиснутого кристала (деформація `u = 0`). Оскільки `2 · Q² / s > 0`, пружна релаксація завжди зменшує коефіцієнт четвертого степеня. Внаслідок цього матеріал, який у затиснутому стані мав би перехід другого роду (`β_clamped > 0`), у вільному стані може зазнавати переходу першого роду (`β_free < 0`). Це явище називають перенормуванням Ларкіна — Пікінського.

### 2. Фазовий перехід другого роду (`β > 0`)

Розглянемо випадок `β > 0`, коли член шостого степеня `γ·P⁶` є малою поправкою і ним можна знехтувати. За відсутності зовнішнього поля (`E = 0`) густина термодинамічного потенціалу зводиться до форми:

```
G(P, T) = G₀ + (1/2)·α₀·(T - T₀)·P² + (1/4)·β·P⁴
```

```
          Потенціал Ландау для фазового переходу 2-го роду
G(P) ↑
     |     T > T₀ (пароелектричний стан, один мінімум у P=0)
     |          \________/
     |
     |     T = T₀ (критична точка, надпласке дно d²G/dP² = 0)
     |          \________/
     |
     |     T < T₀ (сегнетоелектричний стан, подвійна потенціальна яма)
     |          __  /\  __
     |         /  \/  \/  \
     +--------+----+---+---+----------------------> Поляризація P
            -P_s   0  +P_s
```

#### Рівняння рівноваги та спонтанна поляризація

Термодинамічно рівноважні стани системи визначаються умовою стаціонарності вільної енергії за параметром порядку (`∂G/∂P = 0`):

```
∂G / ∂P = 0
= α₀·(T - T₀)·P + β·P³           [взяття першої похідної від G(P)]
= P · [ α₀·(T - T₀) + β·P² ] = 0 [винесення поляризації P за дужки]
```

Це алгебраїчне рівняння має три можливі корені:
1. `P = 0` — неполяризований стан.
2. `P_s² = - α₀ · (T - T₀) / β = α₀ · (T₀ - T) / β` — ненульові симетричні стани спонтанної поляризації.

#### Дослідження термодинамічної стійкості станів

Стійкість знайдених екстремумів визначається знаком другої похідної термодинамічного потенціалу (ізотермічного модуля пружності поляризації):

```
∂²G / ∂P² = α(T) + 3·β·P² = α₀·(T - T₀) + 3·β·P²
```

Проаналізуємо обидва температурні діапазони:

1. **Високотемпературна область (`T > T₀`)**:
   - Для розв'язку `P = 0`:
     `∂²G/∂P² = α₀ · (T - T₀) > 0`.
     Друга похідна строго додатна, отже `P = 0` є єдиним стійким глобальним мінімумом вільної енергії.
   - Ненульові корені `P_s² = - α₀(T - T₀)/β < 0` дають чисто уявні значення, тобто полярні стани фізично не існують.

2. **Низькотемпературна область (`T < T₀`)**:
   - Для розв'язку `P = 0`:
     `∂²G/∂P² = α₀ · (T - T₀) = - α₀ · (T₀ - T) < 0`.
     Друга похідна від'ємна, отже стан `P = 0` перетворюється на нестійкий локальний максимум (вершину потенціального бар'єра).
   - Для ненульових розв'язків `P_s = ± √[ α₀·(T₀ - T) / β ]`:
     Підставимо значення `P_s²` у вираз другої похідної:

```
∂²G / ∂P² |_{P=P_s}
= α₀·(T - T₀) + 3·β · [ α₀·(T₀ - T) / β ]   [підстановка P_s² у вираз другої похідної]
= - α₀·(T₀ - T) + 3·α₀·(T₀ - T)             [розкриття дужок та спрощення коефіцієнта β]
= 2 · α₀ · (T₀ - T) > 0                     [значення строго додатне при T < T₀]
```

Оскільки `∂²G/∂P² > 0`, точки `±P_s` є двома строго еквівалентними абсолютними мінімумами вільної енергії. Система самочинно обирає один із них, що відповідає **спонтанному порушенню симетрії**.

Температурна залежність спонтанної поляризації описується кореневим законом:

```
P_s(T) = ± √[ (α₀ / β) · (T₀ - T) ] = ± P₀ · (1 - T/T₀)^(1/2)    [при T ≤ T₀]
```

де критичний показник параметра порядку `β_crit = 1/2` відповідає класичній середньопольовій теорії Ландау (mean-field theory). У точці переходу `T = T₀` поляризація змінюється неперервно, прямуючи до нуля без стрибка.

#### Рівноважна вільна енергія

Підставимо отримане значення спонтанної поляризації `P_s(T)` назад у термодинамічний потенціал, щоб знайти рівноважну енергію сегнетоелектричної фази:

```
G_eq(T) - G₀
= (1/2)·α₀·(T - T₀)·P_s² + (1/4)·β·P_s⁴                         [розклад потенціалу при E = 0]
= (1/2)·[ - α₀·(T₀ - T) ] · [ α₀·(T₀ - T)/β ] + (1/4)·β · [ α₀·(T₀ - T)/β ]²
= - (1/2) · (α₀² / β) · (T₀ - T)² + (1/4) · (α₀² / β) · (T₀ - T)²
= - (α₀² · (T₀ - T)²) / ( 4 · β )                               [мінімізована вільна енергія сегнетофази]
```

Рівноважна вільна енергія є гладкою функцією температури і монотонно знижується нижче точки `T₀`, роблячи сегнетоелектричний стан енергетично вигіднішим за пароелектричний.

### 3. Діелектрична сприйнятливість та строге виведення «закону двійки»

Знайдемо макроскопічний відгук поляризації кристала на зовнішнє електричне поле `E`. Рівноважне значення поляризації під дією поля визначається мінімізацією повного потенціалу `G(P, T, E)`:

```
∂G / ∂P = 0
⇒ α(T)·P + β·P³ - E = 0
⇒ E = α₀·(T - T₀)·P + β·P³    [термодинамічне рівняння стану сегнетоелектрика]
```

Статична ізотермічна діелектрична сприйнятливість `χ` визначається як похідна поляризації за полем у границі слабкого поля (`E → 0`):

```
χ = ( ∂P / ∂E )_{E→0}
```

Продиференціюємо рівняння стану `E = α·P + β·P³` за змінною `E`:

```
dE / dE = 1
= α · (∂P/∂E) + 3·β·P² · (∂P/∂E)     [диференціювання лівої і правої частин за E]
= ( α + 3·β·P² ) · (∂P/∂E)           [винесення сприйнятливості ∂P/∂E за дужки]
```

Звідси отримуємо фундаментальне співвідношення між сприйнятливістю та другою похідною термодинамічного потенціалу:

```
χ(T) = 1 / ( ∂²G / ∂P² ) = 1 / ( α(T) + 3·β·P² )
```

#### Сприйнятливість у пароелектричній та сегнетоелектричній фазах

Обчислимо точні значення сприйнятливості `χ(T)` для обох температурних областей:

1. **Пароелектрична фаза (`T > T₀`)**:
   Оскільки `P = 0`, підстановка дає:

```
χ_para(T) = 1 / α(T)
          = 1 / [ α₀ · (T - T₀) ]
          = C / ( T - T₀ )             [класичний закон Кюрі — Вейсса, де C = 1/α₀]
```

2. **Сегнетоелектрична фаза (`T < T₀`)**:
   У сегнетофазі `P = P_s`, де `P_s² = α₀·(T₀ - T) / β`. Підставимо це значення:

```
χ_ferro(T) = 1 / [ α₀·(T - T₀) + 3·β · ( α₀·(T₀ - T) / β ) ]
           = 1 / [ - α₀·(T₀ - T) + 3·α₀·(T₀ - T) ]
           = 1 / [ 2 · α₀ · (T₀ - T) ]
           = C / [ 2 · (T₀ - T) ]
```

#### Строгий аналіз нахилів оберненої сприйнятності: «закон двійки»

Розглянемо обернену діелектричну сприйнятливість `1/χ(T)` як функцію температури:

```
1 / χ_para(T)  =  α₀ · (T - T₀)        [при T > T₀]
1 / χ_ferro(T) = 2·α₀ · (T₀ - T)       [при T < T₀]
```

Обчислимо похідні (температурні нахили) оберненої сприйнятливості по обидва боки від критичної точки:

```
[ d(1/χ)/dT ]_{T > T₀} = + α₀ = + 1 / C     [температурний нахил у пароелектричній фазі]
[ d(1/χ)/dT ]_{T < T₀} = - 2·α₀ = - 2 / C   [температурний нахил у сегнетоелектричній фазі]
```

Беручи відношення абсолютних величин нахилів, отримуємо знаменитий **«закон двійки» Ландау**:

```
| [ d(1/χ)/dT ]_{T < T₀} | / | [ d(1/χ)/dT ]_{T > T₀} | = ( 2 · α₀ ) / α₀ = 2
```

```
Обернена сприйнятливість 1/χ ↑
                             |         нахил -2·α₀             нахил +α₀
                             |           (сегнетофаза)       (парофаза)
                             |            \                 /
                             |             \               /
                             |              \             /
                             |               \           /
                             |                \         /
                             +-----------------\-------/-----------------> Температура T
                                               T_C = T₀
```

**Фізичний зміст закону двійки:** подвійний нахил у сегнетофазі зумовлений тим, що нижче точки Кюрі термодинамічний потенціал має додатковий стабілізуючий внесок від нелінійного члена четвертого степеня (`3·β·P_s² = 3·|α|`). Дно кожної з двох потенціальних ям при `±P_s` має кривину вдвічі більшу, ніж кривина дна пароелектричної ями при `P = 0` на тій самій температурній відстані `|T - T₀|`. Тому зсунути іони зовнішнім полем у сегнетофазі вдвічі важче, а діелектрична сприйнятливість є рівно вдвічі меншою.

### 4. Теплоємність та термодинамічні аномалії при переході 2-го роду

Зміна параметра порядку при фазовому переході другого роду призводить до характерного стрибка теплоємності без виділення прихованої теплоти.

#### Ентропія системи

Густина ентропії `S` визначається з першого начала термодинаміки як від'ємна температурна похідна вільної енергії Гіббса:

```
S = - ( ∂G / ∂T )_P,E
  = - ∂/∂T [ G₀(T) + (1/2)·α₀·(T - T₀)·P² + (1/4)·β·P⁴ ]
  = S₀ - (1/2) · α₀ · P²
```

де `S₀(T) = - dG₀/dT` — ентропія високотемпературної ґратки кристала.

Проаналізуємо поведінку ентропії:
- При `T ≥ T₀`: `P = 0`, тому `S(T) = S₀(T)`.
- При `T < T₀`: `P_s² = α₀·(T₀ - T) / β`, звідки:

```
S(T) = S₀(T) - (1/2) · α₀ · [ α₀·(T₀ - T) / β ]
     = S₀(T) - ( α₀² / (2·β) ) · (T₀ - T)
```

У самій точці фазового переходу `T = T₀` ентропія є строго неперервною:

```
S(T₀⁻) = S(T₀⁺) = S₀(T₀)
```

Оскільки ентропія не зазнає розриву (`ΔS = 0`), **прихована теплота переходу дорівнює нулю (`q = T₀ · ΔS = 0`)**, що є визначальною ознакою фазового переходу другого роду за класифікацією Еренфеста.

#### Стрибок питомої теплоємності (аномалія Дрезеля — Ландау)

Питома ізобарична теплоємність за постійного поля визначається через температурну похідну ентропії:

```
C_p = T · ( ∂S / ∂T )_E
```

Обчислимо значення теплоємності для обох фаз:

1. **Пароелектрична фаза (`T > T₀`)**:
   `C_p(T) = T · (dS₀/dT) = C_p0(T)` (звичайна дебаївська теплоємність ґратки).

2. **Сегнетоелектрична фаза (`T < T₀`)**:

```
C_p(T) = T · [ dS₀/dT + d/dT ( - (α₀² / (2·β)) · (T₀ - T) ) ]
       = C_p0(T) + T · [ ( α₀² ) / ( 2 · β ) ]
       = C_p0(T) + ( α₀² · T ) / ( 2 · β )
```

У точці фазового переходу `T = T₀` виникає стрибкоподібне зростання питомої теплоємності:

```
ΔC_p = C_p(T₀⁻) - C_p(T₀⁺) = ( α₀² · T₀ ) / ( 2 · β )
```

```
Теплоємність C_p ↑
                |               Стрибок ΔC_p = (α₀²·T₀)/(2·β)
                |                  |
                |               |  |
                |              /|  |
                |             / |  |
                |            /  +------------------------- C_p0 (парофаза)
                |           /
                |          / (сегнетофаза)
                +---------+-----+------------------------> Температура T
                               T₀
```

Стрибок `ΔC_p` пропорційний квадрату температурного коефіцієнта `α₀²` і обернено пропорційний коефіцієнту ангармонізму `β`. Фізично цей стрибок виникає через те, що при охолодженні нижче `T₀` енергія кристала додатково витрачається на зміщення підґраток і формування макроскопічного дипольного моменту.

### 5. Фазовий перехід першого роду (`β < 0`, `γ > 0`)

У багатьох практично важливих сегнетоелектриках (зокрема у монокристалах титанату барію `BaTiO3` та титанату свинцю `PbTiO3`) коефіцієнт `β` є від'ємним (`β < 0`). 

Якщо `β < 0`, четвертий член `(1/4)·β·P⁴ = - (1/4)·|β|·P⁴` нахиляє потенціал униз при зростанні `P`. Для забезпечення термодинамічної стійкості кристала при великих поляризаціях розклад обов'язково повинен містити член шостого степеня `(1/6)·γ·P⁶` із додатним коефіцієнтом `γ > 0`:

```
G(P, T) = G₀ + (1/2)·α₀·(T - T₀)·P² - (1/4)·|β|·P⁴ + (1/6)·γ·P⁶
```

```
               Еволюція потенціалу при переході 1-го роду (β < 0, γ > 0)
G(P) ↑
     |     T > T₁ (один глобальний мінімум у P=0)
     |          \________/
     |
     |     T = T₁ (поява перегинів / зародження метастабільної сегнетофази)
     |        __/\______/\__
     |
     |     T = T_C (три РІВНІ мінімуми: термодинамічна рівновага фаз G(0)=G(P_s))
     |        __/\  __  /\__
     |       /  \ \/  \/  / \
     |
     |     T₀ < T < T_C (полярні мінімуми глибші за нульовий, P=0 метастабільний)
     |        \     __     /
     |         \__ /  \ __/
     |
     |     T ≤ T₀ (нуль стає локальним максимумом, парофаза абсолютно нестійка)
     |          \   /\   /
     |           \_/  \_/
     +----------+---+---+---+----------------------> Поляризація P
              -P_s  0  +P_s
```

#### Рівняння екстремумів та полярні корені

Знайдемо стаціонарні точки термодинамічного потенціалу за відсутності поля (`∂G/∂P = 0`):

```
∂G / ∂P = 0
⇒ P · [ α₀·(T - T₀) - |β|·P² + γ·P⁴ ] = 0
```

Це рівняння має нульовий розв'язок `P = 0` та біквадратне рівняння для ненульових коренів:

```
γ · (P²)² - |β| · (P²) + α(T) = 0
```

Розв'язуючи це квадратне рівняння відносно `P²`, знаходимо положення бічних екстремумів:

```
P²(T) = [ |β| ± √( β² - 4 · α₀ · γ · (T - T₀) ) ] / ( 2 · γ )
```

Знак «плюс» перед квадратним коренем відповідає бічним мінімумам вільної енергії (сегнетоелектричний стан `P_s`), а знак «мінус» — проміжним максимумам (потенційним бар'єрам, що розділяють стани `P = 0` та `P = P_s`).

#### Три критичні температури фазового переходу 1-го роду

Поведінка системи з `β < 0` повністю визначається трьома характерними температурами:

1. **Верхня спінодаль `T₁` (межа перегріву сегнетофази)**:
   Температура, вище якої підкореневий вираз стає від'ємним і бічні мінімуми зникають. Вона визначається умовою обнулення дискримінанта `β² - 4·α·γ = 0`:

```
α(T₁) = β² / ( 4 · γ )
⇒ α₀ · (T₁ - T₀) = β² / ( 4 · γ )
⇒ T₁ = T₀ + β² / ( 4 · α₀ · γ )
```

При `T > T₁` сегнетоелектрична фаза не може існувати навіть як метастабільний стан.

2. **Температура термодинамічного переходу `T_C` (точка Кюрі)**:
   Температура, за якої глибина полярних мінімумів точно зрівнюється з вільна енергією пароелектричної фази: `G(P_s, T_C) = G(0, T_C) = G₀`.

Виведемо точні вирази для `T_C` та стрибка поляризації `P_s(T_C)`. Запишемо систему двох фундаментальних рівнянь при `T = T_C`:

```
1. Умова екстремуму:          α(T_C) - |β|·P_s² + γ·P_s⁴ = 0
2. Умова рівності енергій:    (1/2)·α(T_C) - (1/4)·|β|·P_s² + (1/6)·γ·P_s⁴ = 0
```

Помножимо друге рівняння на `2` і віднімемо його від першого:

```
[ α(T_C) - |β|·P_s² + γ·P_s⁴ ] - [ α(T_C) - (1/2)·|β|·P_s² + (1/3)·γ·P_s⁴ ] = 0
⇒ - (1/2)·|β|·P_s² + (2/3)·γ·P_s⁴ = 0
⇒ P_s² · [ (2/3)·γ·P_s² - (1/2)·|β| ] = 0
```

Оскільки `P_s ≠ 0`, знаходимо точний **стрибок спонтанної поляризації в точці переходу**:

```
P_s²(T_C) = ( 3 · |β| ) / ( 4 · γ )
⇒ P_s(T_C) = √[ ( 3 · |β| ) / ( 4 · γ ) ]
```

Тепер підставимо отримане значення `P_s²(T_C)` назад у перше рівняння екстремуму:

```
α(T_C) = |β| · P_s²(T_C) - γ · [ P_s²(T_C) ]²
       = |β| · [ (3·|β|) / (4·γ) ] - γ · [ (9·β²) / (16·γ²) ]
       = ( 3 · β² ) / ( 4 · γ ) - ( 9 · β² ) / ( 16 · γ )
       = ( 12 · β² - 9 · β² ) / ( 16 · γ )
       = ( 3 · β² ) / ( 16 · γ )
```

Прирівнюючи `α(T_C) = α₀ · (T_C - T₀)`, знаходимо термодинамічну **температуру фазового переходу першого роду**:

```
T_C = T₀ + ( 3 · β² ) / ( 16 · α₀ · γ )
```

3. **Нижня спінодаль `T₀` (температура Кюрі — Вейсса / межа переохолодження парофази)**:
   Температура, за якої коефіцієнт `α(T₀) = 0`. При `T < T₀` стан `P = 0` перестає бути навіть локальним мінімумом (`∂²G/∂P² < 0`), і пароелектрична фаза абсолютно втрачає стійкість.

#### Ієрархія критичних температур та температурний гістерезис

Порівнюючи отримані формули, вибудовуємо строгу нерівність критичних температур:

```
T₀  <  T_C  <  T₁
```

Співвідношення інтервалів становить:

```
T_C - T₀ = (3/4) · (T₁ - T₀) = ( 3 · β² ) / ( 16 · α₀ · γ )
T₁ - T_C = (1/4) · (T₁ - T₀) = β² / ( 16 · α₀ · γ )
```

Ширина області метастабільності `ΔT_hyst = T₁ - T₀ = β² / (4·α₀·γ)` зумовлює явище **температурного гістерезису**: при нагріванні сегнетоелектричний стан зберігається аж до температури перегріву `T₁`, а при охолодженні пароелектричний стан може переохолоджуватися до температури Кюрі — Вейсса `T₀`.

#### Прихована теплота фазового переходу

Оскільки поляризація при `T = T_C` зазнає стрибка від `0` до `P_s(T_C)`, ентропія кристала також змінюється стрибкоподібно:

```
ΔS = S_para(T_C) - S_ferro(T_C)     [означення стрибка ентропії між паро- та сегнетофазою]
   = (1/2) · α₀ · P_s²(T_C)         [підстановка температурної похідної вільної енергії]
   = ( 3 · |β| · α₀ ) / ( 8 · γ )   [підстановка стрибка поляризації P_s²(T_C) = 3|β|/(4γ)]
```

Відповідно, фазовий перехід першого роду супроводжується виділенням (при охолодженні) або поглинанням (при нагріванні) **прихованої теплоти фазового переходу `q`**:

```
q = T_C · ΔS                        [зв'язок теплоти переходу зі стрибком ентропії q = T·ΔS]
  = (1/2) · α₀ · T_C · P_s²(T_C)    [підстановка виразу для стрибка ентропії ΔS]
  = ( 3 · |β| · α₀ · T_C ) / ( 8 · γ ) [остаточний вираз для прихованої теплоти переходу]
```

#### Стрибок діелектричної сприйнятливості при переході 1-го роду

Обчислимо діелектричну сприйнятливість у точці `T = T_C`:

1. З боку пароелектричної фази (`T → T_C⁺`, `P = 0`):
   `χ(T_C⁺) = 1 / α(T_C) = 1 / [ (3·β²) / (16·γ) ] = ( 16 · γ ) / ( 3 · β² )`.

2. З боку сегнетоелектричної фази (`T → T_C⁻`, `P = P_s(T_C)`):
   `∂²G/∂P² = α(T_C) - 3·|β|·P_s² + 5·γ·P_s⁴`.
   Підставляючи `P_s² = (3·|β|)/(4·γ)` та `α(T_C) = (3·β²)/(16·γ)`:

```
∂²G / ∂P² |_{T_C⁻}
= (3·β²)/(16·γ) - 3·|β| · [ (3·|β|)/(4·γ) ] + 5·γ · [ (9·β²)/(16·γ²) ]
= ( 3/16 - 9/4 + 45/16 ) · (β² / γ)
= ( (3 - 36 + 45) / 16 ) · (β² / γ)
= ( 12 / 16 ) · (β² / γ)
= ( 3 · β² ) / ( 4 · γ )
```

Звідси знаходимо сприйнятливість у сегнетофазі:

```
χ(T_C⁻) = 1 / ( ∂²G/∂P² ) = ( 4 · γ ) / ( 3 · β² ) = (1/4) · χ(T_C⁺)
```

Таким чином, при переході першого роду діелектрична сприйнятливість у точці Кюрі не прямує до нескінченності, а зазнає кінцевого стрибка рівно в **4 рази**: `χ(T_C⁺) / χ(T_C⁻) = 4`.

### 6. Термодинамічна петля гістерезису та внутрішнє коерцитивне поле Ландау

Розглянемо сегнетоелектрик у зовнішньому електричному полі `E` нижче точки Кюрі (`T < T₀`). Рівняння стану має вигляд:

```
E(P) = α·P + β·P³     [де α = -|α| < 0, β > 0]
```

```
          Термодинамічна петля гістерезису Ландау P(E)
Поляризація P ↑
              |                   +P_s
              |                  /
        +P_spin ---------------+·
              |               / |
              |              /  |
    ──────────┼─────────────/───┼──────────────> Зовнішнє поле E
       -E_c   |            /    │ +E_c (внутрішнє поле Ландау)
              |           ·-----+ -P_spin
              |          /
         -P_s |         /
```

#### Розрахунок спінодального поля Ландау E_c

При збільшенні протилежно спрямованого електричного поля стан поляризації рухається вздовж метастабільної гілки доти, доки бар'єр, що розділяє мінімуми, повністю не зникне. Межа термодинамічної стійкості (спінодальна точка) визначається умовою обнулення диференціальної пружності:

```
dE / dP = ∂²G / ∂P² = 0
⇒ α + 3·β·P_spin² = 0
⇒ P_spin² = - α / ( 3 · β ) = |α| / ( 3 · β ) = P_s² / 3
⇒ P_spin = ± P_s / √3
```

Підставимо значення критичної поляризації `P_spin = - P_s / √3` у рівняння стану `E(P)`:

```
E_c = | E(P_spin) |
    = | α · ( - √[ |α| / (3·β) ] ) + β · ( - √[ |α| / (3·β) ] )³ |
    = | - |α| · √[ |α| / (3·β) ] + ( |α| / 3 ) · √[ |α| / (3·β) ] |
    = | - ( 2/3 ) · |α| · √[ |α| / (3·β) ] |
    = ( 2 / (3 · √3) ) · ( |α|^(3/2) / √β )
```

Виражаючи `|α| = α₀ · (T₀ - T)`, отримуємо точну аналітичну формулу **внутрішнього термодинамічного коерцитивного поля Ландау**:

```
E_c(T) = ( 2 / (3 · √3) ) · [ ( α₀ · (T₀ - T) )^(3/2) ] / √β
```

Коерцитивне поле Ландау спадає до нуля при наближенні до точки Кюрі за законом `E_c ∝ (T₀ - T)^(3/2)`.

#### Парадокс Ландауера та механізм перемикання у реальних кристалах

Розрахунок за формулою Ландау для типових сегнетоелектриків (наприклад, `BaTiO3` при кімнатній температурі) дає колосальні значення внутрішнього коерцитивного поля: `E_c^{Landau} ≈ 100–500 кВ/см` (10–50 МВ/м). Проте реальні експериментальні вимірювання на монокристалах дають коерцитивні поля `E_c^{exp} ≈ 1–10 кВ/см`, що на 2–3 порядки величини менше за термодинамічну межу.

Ця розбіжність відома як **парадокс Ландауера** (Landauer paradox). Її причина полягає в тому, що формула Ландау припускає абсолютно однорідне, когерентне обертання поляризації одночасно по всьому об'єму кристала. 

У реальних сегнетоелектриках перемикання відбувається неоднорідно через термоактивоване зародкоутворення нанокристалічних зародків протилежної фази на дефектах, поверхнях електродів та границях зерен з подальшим швидким поперечним рухом 180° доменних стінок за механізмом Мерца (Merz's switching law) та Колмогорова — Аврамі — Ішібаші (KAI model).

### 7. Динаміка поляризації та рівняння релаксації Ландау — Халатникова

Для опису часової еволюції поляризації `P(t)` у змінних зовнішніх електричних полях використовується дисипативне динамічне рівняння Ландау — Халатникова (часозалежне рівняння Гінзбурга — Ландау):

```
γ_d · ( dP / dt ) = - δG / δP
```

де `γ_d > 0` — феноменологічний коефіцієнт кінетичного тертя (в'язкості поляризації), що має розмірність `В·с/Кл` або `Ом·м`.

Підставляючи варіаційну похідну термодинамічного потенціалу з градієнтним членом `(1/2)·κ·(∇P)²`, отримуємо повне рівняння динаміки:

```
γ_d · ( dP / dt ) = E(t) - α·P - β·P³ + κ · ∇²P
```

#### Час релаксації та ефект критичного сповільнення

Розглянемо релаксацію малого відхилення поляризації від рівноважного стану: `P(t) = P_eq + δP(t)`, де `δP ≪ P_eq`.

Лінеаризуємо рівняння Ландау — Халатникова за малим збуренням `δP` за відсутності просторових градієнтів:

```
γ_d · ( d(δP) / dt ) = - ( ∂²G / ∂P² )_{P_eq} · δP = - ( 1 / χ ) · δP
```

Розв'язок цього лінійного диференціального рівняння є експоненціальним:

```
δP(t) = δP(0) · exp( - t / τ )
```

де час релаксації поляризації `τ` дорівнює:

```
τ(T) = γ_d · χ(T) = γ_d / ( ∂²G / ∂P² )
```

Оскільки поблизу точки Кюрі діелектрична сприйнятливість розбігається (`χ ∝ |T - T₀|⁻¹`), час релаксації необмежено зростає:

```
τ(T) = ( γ_d · C ) / ( T - T₀ )       [при T > T₀]
τ(T) = ( γ_d · C ) / [ 2·(T₀ - T) ]   [при T < T₀]
```

Це явище називають **критичним сповільненням** (critical slowing down): при наближенні до точки фазового переходу відновлювальна термодинамічна сила прямує до нуля, і системі потрібно дедалі більше часу для повернення до стану рівноваги після зовнішнього збурення.

#### Комплексна динамічна сприйнятливість у змінному полі

Якщо до кристала прикласти гармонічне поле `E(t) = E₀ · exp(i·ω·t)`, відгук поляризації також є гармонічним: `δP(t) = P₀ · exp(i·ω·t)`. Підстановка у лінеаризоване рівняння дає:

```
i · ω · γ_d · δP(ω) + ( 1 / χ(0) ) · δP(ω) = E(ω)
⇒ δP(ω) · [ 1 + i · ω · γ_d · χ(0) ] = χ(0) · E(ω)
```

Звідси отримуємо класичний дебаївський вираз для комплексної динамічної діелектричної сприйнятності `χ*(ω) = χ'(ω) - i · χ''(ω)`:

```
χ*(ω) = χ(0) / ( 1 + i · ω · τ )
```

Розділяючи дійсну та уявну частини:

```
χ'(ω)  = χ(0) / ( 1 + ω² · τ² )         [дійсна частина: діелектрична проникність]
χ''(ω) = ( χ(0) · ω · τ ) / ( 1 + ω² · τ² ) [уявна частина: діелектричні втрати]
```

Максимум діелектричних втрат `χ''(ω)` спостерігається на критичній частоті релаксації `ω_max = 1 / τ`.

### 8. Просторова структура 180° доменної стінки Гінзбурга — Ландау

У просторово-неоднорідному сегнетоелектрику поляризація змінюється за координатами: `P = P(x)`. Щоб врахувати енергетичну вартість просторових градієнтів, В. Гінзбург модифікував функціонал Ландау градієнтним внеском:

```
G[P] = ∫ [ G₀ + (1/2)·α·P² + (1/4)·β·P⁴ + (1/2)·κ·( dP/dx )² ] dx
```

де `κ > 0` — коефіцієнт градієнтної енергії (градієнтна жорсткість), що має розмірність `В·м³/Кл` або `Дж·м³ / Кл²`.

```
         Профіль 180-градусної доменної стінки Гінзбурга — Ландау
Поляризація P(x) ↑
           +P_s  |                              .-----------
                 |                            /
                 |                          /
                 |                         /  ← P(x) = P_s · tanh( x / (√2·ξ) )
                 |                        /
               0 +-----------------------+------------------------> Координата x
                 |                      /
                 |                     /
                 |                    /
           -P_s  |          _________/
                 |                   |<- 2·ξ ->|
                 |                 Товщина стінки
```

#### Виведення рівняння Ейлера — Лагранжа

Мінімізуємо функціонал вільної енергії за допомогою варіаційного числення. Варіація функціонала дорівнює:

```
δG = ∫ [ ( ∂g/∂P ) · δP + ( ∂g/∂(P') ) · δ(P') ] dx = 0
```

де `g(P, P') = G₀ + (1/2)·α·P² + (1/4)·β·P⁴ + (1/2)·κ·(P')²`, а `P' = dP/dx`.

Інтегруючи другий доданок частинами:

```
∫ ( ∂g/∂(P') ) · d(δP)/dx dx = [ (∂g/∂P') · δP ]_{-∞}^{+∞} - ∫ d/dx ( ∂g/∂P' ) · δP dx
```

Оскільки на нескінченності поляризація виходить на постійні значення в глибині доменів (`dP/dx → 0`), позаінтегральний член зникає. Отримуємо одновимірне рівняння Ейлера — Лагранжа:

```
κ · ( d²P / dx² ) - α·P - β·P³ = 0
```

Нижче точки Кюрі `α = -|α| < 0` та `P_s² = |α|/β`. Перепишемо рівняння:

```
κ · ( d²P / dx² ) + |α|·P · [ 1 - ( P / P_s )² ] = 0
```

#### Точне інтегрування та кінк-солітонний профіль

Помножимо обидві частини рівняння на `dP/dx` та зінтегруємо по `x` (знаходимо перший інтеграл руху, аналог закону збереження енергії у фазовому просторі):

```
κ · ( dP/dx ) · ( d²P/dx² ) = [ - |α|·P + β·P³ ] · ( dP/dx )
⇒ (1/2)·κ · d/dx [ ( dP/dx )² ] = d/dx [ - (1/2)·|α|·P² + (1/4)·β·P⁴ ]
```

Інтегруючи від `-∞` (де `P = -P_s` та `dP/dx = 0`) до поточної точки `x`:

```
(1/2)·κ · ( dP/dx )² = G(P) - G(P_s)
                     = - (1/2)·|α|·P² + (1/4)·β·P⁴ - [ - (1/2)·|α|·P_s² + (1/4)·β·P_s⁴ ]
                     = (1/4)·β · ( P² - P_s² )²
```

Добуваючи квадратний корінь:

```
dP / dx = √[ β / ( 2 · κ ) ] · ( P_s² - P² )
```

Розділимо змінні та виконаємо аналітичне інтегрування:

```
∫ dP / ( P_s² - P² ) = √[ β / ( 2 · κ ) ] · ∫ dx
```

Табличний інтеграл у лівій частині виражається через гіперболічний ареатангенс:

```
( 1 / P_s ) · artanh( P / P_s ) = √[ β / ( 2 · κ ) ] · x
⇒ artanh( P / P_s ) = P_s · √[ β / ( 2 · κ ) ] · x
```

Враховуючи, що `P_s · √β = √|α|`, аргумент набуває вигляду:

```
P_s · √[ β / ( 2 · κ ) ] = √[ |α| / ( 2 · κ ) ] = 1 / ( √2 · ξ )
```

де `ξ` — **кореляційна довжина Гінзбурга (характерна напівтовщина стінки)**:

```
ξ(T) = √[ κ / |α| ] = √[ κ / ( α₀ · (T₀ - T) ) ]
```

Обертаючи функцію `artanh`, знаходимо точний **солітонний профіль 180° доменної стінки**:

```
P(x) = P_s · tanh( x / ( √2 · ξ ) )
```

#### Розрахунок поверхневої густини енергії доменної стінки

Надлишкова питома поверхнева енергія `σ_w` 180-градусної межі дорівнює інтегралу від надлишкової густини вільної енергії по всій товщині перехідного шару:

```
σ_w = ∫_{-∞}^{+∞} [ G(P) - G(P_s) + (1/2)·κ·(dP/dx)² ] dx
```

Оскільки за першим інтегралом `G(P) - G(P_s) = (1/2)·κ·(dP/dx)²`, обидва внески строго рівні між собою (теорема віріалу для солітонів):

```
σ_w = 2 · ∫_{-∞}^{+∞} (1/2)·κ·( dP/dx )² dx
    = κ · ∫_{-P_s}^{+P_s} ( dP/dx ) dP
```

Підставляючи вираз `dP/dx = √[β/(2·κ)] · (P_s² - P²)`:

```
σ_w = κ · √[ β / ( 2 · κ ) ] · ∫_{-P_s}^{+P_s} ( P_s² - P² ) dP
    = √[ ( κ · β ) / 2 ] · [ P_s² · P - P³ / 3 ]_{-P_s}^{+P_s}
    = √[ ( κ · β ) / 2 ] · [ ( 2 · P_s³ ) - ( 2/3 · P_s³ ) ]
    = √[ ( κ · β ) / 2 ] · ( 4/3 · P_s³ )
    = ( 2 · √2 / 3 ) · √κ · √β · P_s³
```

Підставляючи `P_s³ = ( |α| / β )^(3/2) = |α|^(3/2) / β^(3/2)`:

```
σ_w = ( 2 · √2 / 3 ) · [ ( κ · |α|³ )^(1/2) / β ]
    = ( 2 · √2 / 3 ) · κ^(1/2) · α₀^(3/2) · β⁻¹ · ( T₀ - T )^(3/2)
```

**Особливість сегнетоелектричних меж:** на відміну від феромагнітних стінок Блоха, товщина яких становить десятки нанометрів (`20–100 нм`), сегнетоелектричні 180° доменні стінки є екстремально тонкими: `ξ ≈ 0.5–1.5 нм` (1–3 періоди елементарної комірки). Це пояснюється дуже великим значенням коефіцієнта об'ємної анізотропії `|α|` порівняно з відносно слабкою градієнтною дисперсією `κ`.

### 9. Термодинаміка електрокалоричного ефекту (ECE)

Електрокалоричний ефект (electrocaloric effect) полягає у зміні температури або виділенні/поглинанні тепла сегнетоелектричним діелектриком при адіабатичній зміні прикладеного зовнішнього електричного поля `E`.

#### Термодинамічне співвідношення Максвелла

Запишемо повний диференціал питомого термодинамічного потенціалу Гіббса `dG`:

```
dG = - S · dT - P · dE
```

Оскільки `dG` є повним диференціалом, мішані другі частинні похідні рівні між собою:

```
∂²G / ( ∂E ∂T ) = ∂²G / ( ∂T ∂E )
⇒ ( ∂S / ∂E )_T = ( ∂P / ∂T )_E     [термодинамічне співвідношення взаємності Максвелла]
```

#### Адіабатична зміна температури

Розглянемо диференціал ентропії `S(T, E)`:

```
dS = ( ∂S / ∂T )_E · dT + ( ∂S / ∂E )_T · dE = 0     [умова адіабатичного процесу dS = 0]
```

Враховуючи, що `(∂S/∂T)_E = (ρ · C_E) / T` (де `ρ` — густина матеріалу, а `C_E` — питома теплоємність за постійного поля) та застосовуючи співвідношення Максвелла:

```
( ( ρ · C_E ) / T ) · dT + ( ∂P / ∂T )_E · dE = 0
⇒ dT = - ( T / ( ρ · C_E ) ) · ( ∂P / ∂T )_E · dE
```

Інтегруючи від початкового поля `E₁` до кінцевого `E₂`, отримуємо загальну формулу електрокалоричної зміни температури:

```
ΔT_ad = - ∫_{E₁}^{E₂} ( T / ( ρ · C_E ) ) · ( ∂P / ∂T )_E dE
```

#### Розрахунок у теорії Ландау для переходу 2-го роду

Знайдемо аналітичний вираз для `ΔT_ad` за допомогою рівняння стану Ландау `E = α₀·(T - T₀)·P + β·P³`.

Продиференціюємо рівняння стану за температурою за постійного поля `E`:

```
0 = α₀ · P + [ α₀·(T - T₀) + 3·β·P² ] · ( ∂P / ∂T )_E
⇒ ( ∂P / ∂T )_E = - ( α₀ · P ) / ( α + 3·β·P² )
```

З іншого боку, диференціал поля за постійної температури дорівнює `dE = ( α + 3·β·P² ) dP`. Підставимо цей вираз під інтеграл:

```
ΔT_ad = - ∫_{P(E₁)}^{P(E₂)} ( T / ( ρ · C_E ) ) · [ - ( α₀ · P ) / ( α + 3·β·P² ) ] · ( α + 3·β·P² ) dP
      = + ( α₀ · T / ( ρ · C_E ) ) · ∫_{P₁}^{P₂} P dP
      = ( α₀ · T / ( 2 · ρ · C_E ) ) · [ P²(E₂) - P²(E₁) ]
```

Таким чином, електрокалорична зміна температури прямо пропорційна зміні квадрата поляризації кристала:

```
ΔT_ad = ( α₀ · T / ( 2 · ρ · C_E ) ) · Δ(P²)
```

Максимальний електрокалоричний відгук досягається поблизу температури фазового переходу, де поляризація найчутливіша до зовнішнього електричного поля (`∂P/∂T` має гігантський пік). У тонких сегнетоелектричних плівках (наприклад, `PbZr_{0.95}Ti_{0.05}O3`), здатних витримувати надвисокі поля `E > 1 МВ/см` без електричного пробою, спостерігається **гігантський електрокалоричний ефект** зі зміною температури `ΔT_ad > 12–20 K`, що використовується для розробки високоефективних твердотільних мікрохолодильників без рідкого холодоагенту.

### 10. Розрахунковий приклад: числовий аналіз модельного кристала BaTiO3

Для закріплення математичного апарату виконаємо повний покроковий термодинамічний розрахунок параметрів фазового переходу першого роду для типового сегнетоелектрика — титанату барію (`BaTiO3`).

**Вхідні феноменологічні параметри потенціалу Ландау — Девоншира (у системі SI):**
- Температура Кюрі — Вейсса: `T₀ = 381 K` (108 °C)
- Температурний коефіцієнт: `α₀ = 3.8 × 10⁵ В·м / (Кл·К)`
- Коефіцієнт четвертого степеня: `β = - 2.8 × 10⁸ В·м⁵ / Кл³` (знак мінус вказує на 1-й рід)
- Коефіцієнт шостого степеня: `γ = 3.2 × 10⁹ В·м⁹ / Кл⁵`
- Густина кристала: `ρ = 6020 кг/м³`
- Питома теплоємність: `C_p ≈ 430 Дж / (кг·К)` (об'ємна теплоємність `C_v = ρ · C_p ≈ 2.59 × 10⁶ Дж / (м³·К)`)

---

#### 1. Розрахунок температури фазового переходу T_C

```
T_C = T₀ + ( 3 · β² ) / ( 16 · α₀ · γ )
    = 381 + ( 3 · (-2.8 × 10⁸)² ) / ( 16 · (3.8 × 10⁵) · (3.2 × 10⁹) )   [підстановка числових значень]
    = 381 + ( 3 · 7.84 × 10¹⁶ ) / ( 1.9456 × 10¹⁶ )                     [обчислення степенів]
    = 381 + ( 2.352 × 10¹⁷ ) / ( 1.9456 × 10¹⁶ )
    = 381 + 12.09
    = 393.09 K  ( ≈ 120.1 °C )
```

**Висновок:** температура фазового переходу `T_C = 393.1 K` вища за температуру Кюрі — Вейсса `T₀ = 381 K` рівно на 12.1 K.

---

#### 2. Розрахунок стрибка спонтанної поляризації в точці переходу P_s(T_C)

```
P_s²(T_C) = ( 3 · |β| ) / ( 4 · γ )
          = ( 3 · 2.8 × 10⁸ ) / ( 4 · 3.2 × 10⁹ )                       [підстановка коефіцієнтів β і γ]
          = ( 8.4 × 10⁸ ) / ( 1.28 × 10¹⁰ )
          = 0.065625 Кл² / м⁴

P_s(T_C)  = √( 0.065625 )
          = 0.2562 Кл / м²  ( = 25.62 мкКл / см² )
```

**Висновок:** у точці Кюрі поляризація стрибком зростає від нуля до гігантського значення `25.6 мкКл/см²`, що ідеально узгоджується з експериментально виміряним значенням для `BaTiO3` (`26 мкКл/см²`).

---

#### 3. Розрахунок прихованої теплоти фазового переходу q

```
q = (1/2) · α₀ · T_C · P_s²(T_C)
  = 0.5 · (3.8 × 10⁵) · 393.1 · 0.065625                                [підстановка значень у СІ]
  = 4.901 × 10⁶ Дж / м³
```

Переведемо об'ємну теплоту у молярну (молярна маса `BaTiO3` становить `M = 0.2332 кг/моль`, об'єм одного моля `V_m = M / ρ = 0.2332 / 6020 ≈ 3.874 × 10⁻⁵ м³/моль`):

```
q_mol = q · V_m
      = (4.901 × 10⁶ Дж/м³) · (3.874 × 10⁻⁵ м³/моль)             [множення об'ємної теплоти на молярний об'єм]
      = 189.8 Дж / моль  ( ≈ 0.19 кДж / моль )                   [прихована теплота на один моль речовини]
```

**Висновок:** при охолодженні через точку 120 °C один моль титанату барію виділяє близько 190 Дж прихованої теплоти.

---

#### 4. Розрахунок верхньої межі перегріву сегнетофази T₁

```
T₁ = T₀ + β² / ( 4 · α₀ · γ )
   = 381 + ( (-2.8 × 10⁸)² ) / ( 4 · (3.8 × 10⁵) · (3.2 × 10⁹) )   [підстановка числових параметрів BaTiO3]
   = 381 + ( 7.84 × 10¹⁶ ) / ( 4.864 × 10¹⁵ )                     [обчислення значень у знаменнику]
   = 381 + 16.12
   = 397.12 K  ( ≈ 124.1 °C )                                     [температура перегріву сегнетофази]
```

**Висновок:** ширина області температурного гістерезису становить `ΔT_hyst = T₁ - T₀ = 16.1 K`.

---

#### 5. Розрахунок внутрішнього коерцитивного поля Ландау при кімнатній температурі (T = 293 K)

Обчислимо коефіцієнт `|α|` при `T = 293 K` (20 °C):

```
|α(293 K)| = α₀ · (T₀ - T)
           = (3.8 × 10⁵) · (381 - 293)                            [підстановка температурної різниці]
           = (3.8 × 10⁵) · 88
           = 3.344 × 10⁷ В·м / Кл                                 [значення квадратичного коефіцієнта]
```

Обчислимо термодинамічне коерцитивне поле Ландау:

```
E_c = ( 2 / (3 · √3) ) · [ |α|^(3/2) ] / √|β|
    = ( 2 / 5.19615 ) · [ (3.344 × 10⁷)^(1.5) ] / √( 2.8 × 10⁸ )       [підстановка значень]
    = 0.3849 · [ 1.9337 × 10¹¹ ] / [ 1.6733 × 10⁴ ]
    = 0.3849 · 1.1556 × 10⁷
    = 4.448 × 10⁶ В / м  ( = 44.5 кВ / см )
```

**Висновок:** теоретичне внутрішнє коерцитивне поле Ландау становить `44.5 кВ/см`. Оскільки реальне експериментальне поле перемикання тонких полідоменних пластин `BaTiO3` становить близько `1–2 кВ/см`, це підтверджує доменний механізм перемикання через зародкоутворення та бічний рух стінок.

### Підсумкова таблиця відповідностей термодинамічних режимів

| Фізична характеристика | Фазовий перехід 2-го роду (`β > 0`) | Фазовий перехід 1-го роду (`β < 0`, `γ > 0`) |
| :--- | :--- | :--- |
| **Спонтанна поляризація при `T_C`** | Неперервна: `P_s(T_C) = 0` | Стрибок: `P_s(T_C) = √[ 3·\|β\| / (4·γ) ]` |
| **Критична температура `T_C`** | Збігається з `T₀`: `T_C = T₀` | Зсунута вгору: `T_C = T₀ + 3·β² / (16·α₀·γ)` |
| **Прихована теплота `q`** | Відсутня: `q = 0` (`ΔS = 0`) | Ненульова: `q = (1/2)·α₀·T_C·P_s²(T_C)` |
| **Теплоємність `C_p` при `T_C`** | Скінченний стрибок: `ΔC_p = (α₀²·T₀)/(2·β)` | `δ`-подібна розбіжність (прихована теплота) |
| **Сприйнятливість `χ` при `T_C`** | Розбігається до `∞` за законом Кюрі | Скінченний стрибок у 4 рази: `χ(T_C⁺) = 4·χ(T_C⁻)` |
| **Температурний гістерезис** | Відсутній: `T₁ = T_C = T₀` | Присутній: вікно `ΔT = β² / (4·α₀·γ)` |
| **Нахили `1/χ(T)` біля `T_C`** | Закон двійки: нахил сегнетофази `2·α₀` | Нахил парофази `α₀`, стрибок у точці `T_C` |
