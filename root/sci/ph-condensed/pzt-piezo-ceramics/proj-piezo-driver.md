# ⚙️ Проєкт драйвера PZT-стека та ультразвукового генератора

Цей практичний проєкт описує розробку, схемотехнічне розрахування та програмну реалізацію резонансного силового інвертора для керування п'єзокерамічним актуатором PZT або ультразвуковим випромінювачем Ланжевена з автоматичним відстеженням резонансної частоти (ZVS) на базі мікроконтролера.

---

### Схемотехнічні проблеми ємнісного навантаження та топологія драйвера

З точки зору силової електроніки, п'єзокерамічний елемент є **високодобротним ємнісним навантаженням**. Його еквівалентна схема поблизу механічного резонансу описується чотириполюсником Баттерворта — Ван-Дайка (BVD), що складається з паралельного з'єднання статичної ємності `C₀` (від `2 nF` у дисках до `5 μF` у стеках) та послідовної динамічної гілки `R_m - L_m - C_m`.

Якщо подати на такий елемент прямокутну напругу безпосередньо від звичайного ключового містка чи напівмістка, статична ємність `C₀` при кожному перемиканні транзисторів заряджатиметься струмовим піком колосальної амплітуди:

```
I_peak = C₀ · (dU / dt)
```

При частоті перемикання `100 kHz` і напрузі `100 V` реактивна потужність перезарядки `Q_c = 2π · f · C₀ · U_rms²` досягає сотень ват. Ця енергія марно циркулює між силовими транзисторами та керамікою, спричиняючи:
1. Перегрів та вихід з ладу силових MOSFET або IGBT-ключів через пікові струми;
2. Колосальний рівень електромагнітних завад (EMI);
3. Ризик деполяризації кераміки від коротких зворотних піків напруги;
4. Низький коефіцієнт корисної дії (ККД < 40%).

```
                  ┌─────────[ L_comp ]─────────┐
                  │                            │
   [ Мостовий ]───┴───┬────────────────────┬───┴───[ PZT Елемент ]
   [ Інвертор ]       │                    │
                     [C₀]     ┌──[R_m]──[L_m]──[C_m]──┐
                      │       │                       │
                     ─┴─     ─┴─                     ─┴─
```

Для усунення реактивного струму послідовно або паралельно з PZT-елементом вмикають **компенсаційний дросель `L_comp`**.

Значення індуктивності дроселя розраховують з умови забезпечення електричного резонансу на робочій частоті `f_work`:

```
L_comp = 1 / (4 · π² · f_work² · C₀)
```

При цьому статична ємність `C₀` утворює паралельний або послідовний LC-контур із дроселем `L_comp`. Реактивний струм ємності повністю замикається всередині контуру, а від силового інвертора споживається лише активний струм, необхідний для покриття механічної потужності `R_m`.

Струм через силові ключі стає синусоїдальним і збігається за фазою з напругою, що дозволяє реалізувати режим перемикання при нульовій напрузі (**ZVS — Zero Voltage Switching**). Це забезпечує зниження динамічних втрат на транзисторах і підвищує ККД схеми до `90–95%`.

### Розрахунок силового трансформатора узгодження та давачів фази

Оскільки силові ультразвукові випромінювачі високої потужності вимагають високої амплітуди синусоїдальної напруги (`300–800 V_rms`), а первинне джерело живлення драйвера зазвичай має напругу `24 V` або `48 V`, між напівмостом та PZT-елементом вмикають **високочастотний узгоджувальний трансформатор** на феритовому осерді (наприклад, N87 або N97).

Коефіцієнт трансформації `n = N_sec / N_pri` розраховують виходячи з необхідної акустичної потужності `P_ac` та опіру резонансної гілки `R_m`:

```
n = U_pzt_rms / U_bridge_rms = √(P_ac · R_m) / (0.45 · U_DC)
```

Для забезпечення роботи алгоритму автоматичного підлаштування частоти (ФАПЧ / PLL) схемотехніка драйвера містить два вимірювальних канали:

1. **Давач напруги**: Знімає сигнал з електродів PZT через резистивний дільник або високочастотний трансформатор напруги.
2. **Давач струму**: Використовує високочастотний трансформатор струму (Current Transformer, CT), первинна обмотка якого включена послідовно з PZT-елементом.

Сигнали з давачів подаються на швидкі компаратори із регульованим гістерезисом (наприклад, MAX9031 або TLV3501), які перетворюють синусоїдальні сигнали струму `I(t)` та напруги `U(t)` на прямокутні імпульси логічного рівня 3.3V (сигнали `V_SENSE` та `I_SENSE`).

Ці прямокутні сигнали подаються на входи захоплення таймера мікроконтролера (Input Capture) або на фазовий детектор ФАПЧ.

### Алгоритм автопідлаштування частоти (PLL / ФАПЧ)

Під час тривалої роботи PZT-елемент нагрівається, а механічне навантаження (наприклад, зміна рівня рідини у мийці чи зміна зусилля притиску інструменту) зміщує послідовну резонансну частоту `f_r`.

Аби драйвер не втрачав резонанс, мікроконтролер реалізує цифровий ПІД-регулятор фазового зсуву `Δφ`:
- На послідовному резонансі `f_r` фазовий зсув між струмом і напругою `Δφ = 0` (активне навантаження);
- Якщо частота занизька (`f < f_r`), струм випереджає напругу (`Δφ > 0`, ємнісний режим);
- Якщо частота зависока (`f > f_r`), струм відстає від напруги (`Δφ < 0`, індуктивний режим).

Цифровий алгоритм обчислює різницю часів переходу через нуль сигналів `V_SENSE` та `I_SENSE`, розраховує поточний фазовий зсув `Δφ` і корегує період таймера ШШІМ (PWM) для підтримання `Δφ = 0`.

### Програмна реалізація драйвера ZVS

Нижче наведено повний робочий модуль керування ШІМ-генератором та цифровою петлею ФАПЧ для мікроконтролера. Код реалізовано у двох варіантах — мовою **C** та ідіоматичною **C++**.

:::tabs
@tab C
```c
#include <stdint.h>
#include <stdbool.h>
#include <math.h>

#define PI_F 3.1415926535f

// Структура конфігурації та стану цифрового ФАПЧ-контролера PZT
typedef struct {
    float target_phase_rad;  // Цільовий фазовий зсув (0.0 рад для резонансу f_r)
    float kp;                // Пропорційний коефіцієнт ПІД-регулятора
    float ki;                // Інтегральний коефіцієнт ПІД-регулятора
    float kd;                // Диференціальний коефіцієнт ПІД-регулятора
    float current_freq_hz;   // Поточна генерується частота
    float min_freq_hz;       // Межа мінімальної робочої частоти
    float max_freq_hz;       // Межа максимальної робочої частоти
    float integral_sum;      // Накопичена інтегральна сума
    float prev_error;        // Попереднє значення помилки для диф-ланки
} PztPllController;

// Ініціалізація ФАПЧ-контролера
void pzt_pll_init(PztPllController *pll, float init_freq, float min_f, float max_f) {
    pll->target_phase_rad = 0.0f;
    pll->kp = 25.0f;
    pll->ki = 4.5f;
    pll->kd = 0.5f;
    pll->current_freq_hz = init_freq;
    pll->min_freq_hz = min_f;
    pll->max_freq_hz = max_f;
    pll->integral_sum = 0.0f;
    pll->prev_error = 0.0f;
}

// Оновлення частоти драйвера за виміряним фазовим зсувом (в радіанах)
float pzt_pll_update(PztPllController *pll, float measured_phase_rad, float dt_sec) {
    if (dt_sec <= 0.0f) return pll->current_freq_hz;

    // Помилка фази (відхилення від нульового фазового зсуву ZVS)
    float error = pll->target_phase_rad - measured_phase_rad;
    
    // Накопичення інтегральної суми з антинасиченням (anti-windup)
    pll->integral_sum += error * dt_sec;
    if (pll->integral_sum > 200.0f) pll->integral_sum = 200.0f;
    if (pll->integral_sum < -200.0f) pll->integral_sum = -200.0f;

    // Диференціальна складова
    float derivative = (error - pll->prev_error) / dt_sec;
    pll->prev_error = error;

    // Обчислення поправки частоти
    float freq_delta = (pll->kp * error) + (pll->ki * pll->integral_sum) + (pll->kd * derivative);
    pll->current_freq_hz += freq_delta;

    // Захисне обмеження діапазону частот
    if (pll->current_freq_hz < pll->min_freq_hz) {
        pll->current_freq_hz = pll->min_freq_hz;
    } else if (pll->current_freq_hz > pll->max_freq_hz) {
        pll->current_freq_hz = pll->max_freq_hz;
    }

    return pll->current_freq_hz;
}

// Розрахунок компенсаційної індуктивності L_comp
float pzt_calculate_l_comp_henry(float static_cap_farad, float resonant_freq_hz) {
    if (static_cap_farad <= 0.0f || resonant_freq_hz <= 0.0f) return 0.0f;
    float omega = 2.0f * PI_F * resonant_freq_hz;
    return 1.0f / (omega * omega * static_cap_farad);
}
```

@tab C++
```cpp
#include <cstdint>
#include <cmath>
#include <algorithm>
#include <numbers>

class PztPllController {
public:
    PztPllController(float init_freq_hz, float min_f_hz, float max_f_hz) noexcept
        : current_freq_hz_(init_freq_hz),
          min_freq_hz_(min_f_hz),
          max_freq_hz_(max_f_hz) {}

    // Оновлення частоти за виміряним фазовим зсувом (в радіанах)
    [[nodiscard]] float update(float measured_phase_rad, float dt_sec) noexcept {
        if (dt_sec <= 0.0f) return current_freq_hz_;

        const float error = target_phase_rad_ - measured_phase_rad;
        
        integral_sum_ += error * dt_sec;
        integral_sum_ = std::clamp(integral_sum_, -200.0f, 200.0f);

        const float derivative = (error - prev_error_) / dt_sec;
        prev_error_ = error;

        const float freq_delta = (kp_ * error) + (ki_ * integral_sum_) + (kd_ * derivative);
        current_freq_hz_ = std::clamp(current_freq_hz_ + freq_delta, min_freq_hz_, max_freq_hz_);

        return current_freq_hz_;

    }

    [[nodiscard]] float current_frequency() const noexcept { return current_freq_hz_; }

    // Розрахунок компенсаційної індуктивності L_comp
    [[nodiscard]] static constexpr float calculate_l_comp(float static_cap_farad, float resonant_freq_hz) noexcept {
        if (static_cap_farad <= 0.0f || resonant_freq_hz <= 0.0f) return 0.0f;
        const float omega = 2.0f * std::numbers::pi_v<float> * resonant_freq_hz;
        return 1.0f / (omega * omega * static_cap_farad);
    }

private:
    float target_phase_rad_{0.0f};
    float kp_{25.0f};
    float ki_{4.5f};
    float kd_{0.5f};
    float current_freq_hz_;
    float min_freq_hz_;
    float max_freq_hz_;
    float integral_sum_{0.0f};
    float prev_error_{0.0f};
};
```

### Інженерні правила безпеки та запуск системи

1. **Мертвий час (Dead Time)**: Між перемиканням верхнього та нижнього ключа півмоста обов'язково задають мертвий час `t_dead ≈ 100–250 ns` для запобігання наскрізному короткому замиканню (shoot-through).
2. **Захист від сухого ходу**: Ненавантажений випромінювач Ланжевена має механічну добротність `Q_m > 1000`. На резонансі амплітуда деформації може легко перевищити межу міцності кераміки на розрив (`20–30 MPa`) і розколоти зразок. Перший запуск виконують від заниженої напруги живлення (`12 V`) з поступовим підйомом потужності.
3. **Термоконтроль**: На корпус PZT-елемента встановлюють давач температури NTC. При перевищенні `100 °C` контролер повинен автоматично знижувати потужність ШШІМ або вимикати генерацію для захисту від термічної деполяризації.
4. **Захист від перенапруги**: При випадковому обриві акустичного навантаження резонансна напруга на `LC`-контурі може підскочити у `Q_m` разів, що призведе до електричного пробою кераміки. У схему вбудовують швидкий компаратор пикового значення напруги.
