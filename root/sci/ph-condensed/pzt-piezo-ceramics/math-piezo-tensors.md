# 🧮 Математика п'єзомодулів і тензорних рівнянь PZT

Ця вставка містить строгий математичний апарат феноменологічної теорії п'єзоелектрики, матриці симетрії групи `C[6v]` для поляризованої кераміки PZT, лінійні конститутивні рівняння стандарту IEEE, перетворення граничних умов та математичні формули розрахунку електромеханічного зв'язку, пружних констант і хвильових рівнянь акустичних коливань.

---

### Тетради конститутивних рівнянь IEEE та перетворення змінних

П'єзоелектричний ефект описується лінійним зв'язком між двома механічними змінними — тензором напружень `T[ij]` (Па) та тензором деформацій `S[ij]` (безрозмірна величина), а також двома електричними змінними — вектором напруженості поля `E[k]` (В/м) та вектором електричної індукції `D[i]` (Кл/м²).

У загальному тривимірному випадку механічні тензори `T` та `S` є симетричними тензорами 2-го рангу (майже 6 незалежних компонент кожен), вектор `E` та `D` мають по 3 компоненти, а зв'язувальні п'єзоелектричні коефіцієнти утворюють тензор 3-го рангу з 27 компонентами.

Залежно від того, які саме змінні обираються незалежними вхідними величинами (причинами), а які — вихідними відгуками (наслідками), стандарт IEEE Std 176-1987 формулює 4 фундаментальні системи лінійних п'єзоелектричних рівнянь:

#### 1. Форма d (деформація-заряд / strain-charge form)
Використовується, коли незалежними змінними є механічне напруження `T` та електричне поле `E`. Це найзручніша форма для розрахунку розширення та стиску п'єзоактюаторів:
```
S[i] = s[ij]^E · T[j] + d[ki] · E[k]
D[i] = d[ij]   · T[j] + ε[ik]^T · E[k]
```
Тут `s[ij]^E` — модуль механічної гнучкості при постійному електричному полі, `d[ki]` — п'єзоелектричний модуль заряда (м/В або Кл/Н), `ε[ik]^T` — діелектрична проникність вільного кристалу.

#### 2. Форма e (напруження-заряд / stress-charge form)
Використовується, коли незалежними змінними є деформація `S` та електричне поле `E`. Ця форма є базовою для скінченноелементного чисельного моделювання (FEM/ANSYS/COMSOL):
```
T[i] = c[ij]^E · S[j] - e[ki] · E[k]
D[i] = e[ij]   · S[j] + ε[ik]^S · E[k]
```
Тут `c[ij]^E` — тензор модулів пружності (Жорсткості), `e[ki]` — п'єзоелектричний модуль напруження (Кл/м² або Н/(В·м)).

#### 3. Форма g (деформація-напруга / strain-voltage form)
Використовується, коли незалежними є напруження `T` та електрична індукція `D`. Зручна для розрахунку чутливості давачів тиску та акселерометрів у режимі холостого ходу:
```
S[i] = s[ij]^D · T[j] + g[ki] · D[k]
E[i] = -g[ij]  · T[j] + β[ik]^T · D[k]
```
Тут `g[ki]` — п'єзоелектричний модуль напруги (В·м/Н або м²/Кл), `β[ik]^T = 1 / ε[ik]^T` — діелектрична непроникність.

#### 4. Форма h (напруження-напруга / stress-voltage form)
Використовується, коли незалежними є деформація `S` та індукція `D`:
```
T[i] = c[ij]^D · S[j] - h[ki] · D[k]
E[i] = -h[ij]  · S[j] + β[ik]^S · D[k]
```

Верхні індекси позначають граничні умови вимірювання:
- `^E` — виміряно при короткозамкнених електродах (`E = 0`);
- `^D` — виміряно при розімкнених електродах / постійному заряді (`D = 0`);
- `^T` — виміряно у вільному некоригованому стані (`T = 0`);
- `^S` — виміряно при механічно затиснутій деформації (`S = 0`).

Співвідношення між коефіцієнтами різних форм виражаються матричними перетвореннями:
```
e[ij] = d[ik] · c[kj]^E
g[ij] = d[ik] · β[kj]^T
h[ij] = e[ik] · β[kj]^S
```

### Нотація Фогта та матриці симетрії групи C_6v для PZT

Для спрощення математичного запису симетричні тензори 2-го рангу `S[ij]` та `T[ij]` згортають у 6-вимірні вектори-стовпчики за нотацією Фогта (Voigt Notation):

```
1 ↔ xx,   2 ↔ yy,   3 ↔ zz
4 ↔ yz,   5 ↔ xz,   6 ↔ xy
```

При цьому тензор деформацій згортається з інженерним множником 2 для зсувних компонент: `S₁ = S_xx`, `S₂ = S_yy`, `S₃ = S_zz`, `S₄ = 2 S_yz`, `S₅ = 2 S_xz`, `S₆ = 2 S_xy`.

Спечена полікристалічна кераміка PZT після високовольтної поляризації вздовж осі 3 стає трансверсально-ізотропним середовищем із точковою групою симетрії **`C[6v]`** (або `6mm`).

Завдяки осьовій симетрії навколо осі поляризації 3 та площинам дзеркального відображення, більшість компонент тензорів перетворюються на нуль. Увесь математичний опис PZT зводиться до трьох матриць:

#### 1. Матриця п'єзоелектричних модулів `d[ki]` (розмір 3 × 6):
```
          ┌                                       ┐
          │   0      0      0      0    d₁₅    0   │
d[ki]  =  │   0      0      0     d₁₅    0     0   │
          │  d₃₁    d₃₁    d₃₃     0     0     0   │
          └                                       ┘
```

Ненульові компоненти мають наступну фізичну інтерпретацію:
- `d₃₃`: Поздовжній п'єзомодуль. Визначає зміну товщини пластини при подачі поля вздовж осі поляризації (`S₃ = d₃₃ · E₃`). Для PZT-5H `d₃₃ ≈ +590 pC/N`.
- `d₃₁ = d₃₂`: Поперечний п'єзомодуль. Визначає зміну довжини/ширини у площині перпендикулярно до поляризації (`S₁ = d₃₁ · E₃`). Має від'ємний знак (`d₃₁ ≈ -270 pC/N`).
- `d₁₅ = d₂₄`: Зсувний п'єзомодуль. Визначає кутову зсувну деформацію під дією поперечного поля (`S₅ = d₁₅ · E₁`). Значення досягає `740 pC/N`.

#### 2. Матриця пружної гнучкості `s[ij]^E` (розмір 6 × 6):
```
          ┌                                                 ┐
          │  s₁₁   s₁₂   s₁₃    0      0          0         │
          │  s₁₂   s₁₁   s₁₃    0      0          0         │
s[ij]^E = │  s₁₃   s₁₃   s₃₃    0      0          0         │
          │   0     0     0    s₄₄     0          0         │
          │   0     0     0     0     s₄₄         0         │
          │   0     0     0     0      0   2(s₁₁ - s₁₂)     │
          └                                                 ┘
```
Вона містить лише 5 незалежних пружних констант: `s₁₁`, `s₁₂`, `s₁₃`, `s₃₃` та `s₄₄`. Компонента `s₆₆ = 2(s₁₁ - s₁₂)` виражає ссувний модуль у площині 1-2.

#### 3. Матриця діелектричної проникності `ε[ik]^T` (розмір 3 × 3):
```
          ┌                   ┐
          │  ε₁₁   0     0    │
ε[ik]^T = │   0   ε₁₁    0    │
          │   0    0    ε₃₃   │
          └                   ┘
```
Тут `ε₁₁ = ε₂₂` — поперечна діелектрична проникність, `ε₃₃` — поздовжня проникність вздовж осі поляризації.

### Фізичний зміст та розрахунок коефіцієнтів електромеханічного зв'язку k

Коефіцієнт електромеханічного зв'язку `k` є безрозмірною мірою ефективності перетворення енергії п'єзоелементом. Безпосереднє термодинамічне визначення має вигляд:

```
k² = W_mech_stored / W_elec_input  (в режимі мотора / актуатора)
k² = W_elec_stored / W_mech_input  (в режимі генератора / давача)
```

Через фундаментальні константи матеріалу коефіцієнти зв'язку для різних геометрій деформації виражаються наступними формулами:

1. **Поздовжня мода `k₃₃`** (стрижень або стек, поляризований і деформований вздовж осі 3):
   ```
   k₃₃ = d₃₃ / √(s₃₃^E · ε₃₃^T)
   ```
   Для PZT-5H значення `k₃₃ ≈ 0.75`, що означає перетворення `k₃₃² ≈ 56.2%` підведеної енергії за один цикл.

2. **Поперечна мода `k₃₁`** (тонка пластина, поляризована за товщиною, коливання вздовж довжини):
   ```
   k₃₁ = d₃₁ / √(s₁₁^E · ε₃₃^T)
   ```
   Для PZT-5A `k₃₁ ≈ 0.34`.

3. **Планарна мода `k_p`** (тонкий диск, поляризований за товщиною, радіальні коливання):
   ```
   k_p = k₃₁ · √(2 / (1 - ν))
   ```
   Де `ν = -s₁₂^E / s₁₁^E` — коефіцієнт Пуассона п'єзокераміки (`ν ≈ 0.31`).

4. **Зсувна мода `k₁₅`**:
   ```
   k₁₅ = d₁₅ / √(s₄₄^E · ε₁₁^T)
   ```

### Хвильове рівняння та резонансні частоти п'єзопластини

Для тонкої п'єзокерамічної пластини товщиною `t`, поляризованої за товщиною, рівняння руху суцільного середовища Нав'є — Коші має вигляд:

```
ρ · (∂² u₃ / ∂ t²) = ∂ T₃ / ∂ z
```

Підставляючи конститутивне рівняння форми `e`: `T₃ = c₃₃^E · (∂ u₃ / ∂ z) - e₃₃ · E₃`, та враховуючи відсутність вільних об'ємних зарядів (`∂ D₃ / ∂ z = 0`), отримуємо хвильове рівняння поздовжніх акустичних коливань:

```
∂² u₃ / ∂ t² = (c₃₃^D / ρ) · (∂² u₃ / ∂ z²)
```

Де `c₃₃^D = c₃₃^E + (e₃₃² / ε₃₃^S)` — модуль жорсткості при розімкнених електродах («жорсткий» кристал за рахунок поляризаційного заряду).

Розв'язок цього хвильового рівняння з граничними умовами вільних поверхонь (`T₃(±t/2) = 0`) дає трансцендентне рівняння для електричного імпедансу пластини `Z(ω)`:

```
Z(ω) = 1 / (j · ω · C₀) · [1 - k_t² · (tan(X) / X)]
```

Де `X = (ω · t) / (2 v_3^D)`, а `v_3^D = √(c₃₃^D / ρ)` — швидкість поздовжньої акустичної хвилі.

Звідси отримуємо характерні частоти:

1. **Серійний (послідовний) резонанс `f_r`** (імпеданс `Z → 0`): Умова `X_r = π / 2`:
   ```
   f_r = v_3^E / (2 t) = (1 / (2 t)) · √(1 / (ρ · s₃₃^E))
   ```
2. **Паралельний антирезонанс `f_a`** (імпеданс `Z → ∞`): Умова `1 - k_t² · (tan(X_a) / X_a) = 0`:
   ```
   f_a = v_3^D / (2 t) = N_t / t
   ```

Точний зв'язок між виміряними частотами `f_r` та `f_a` дозволяє визначити ефективний коефіцієнт електлектромеханічного зв'язку за товщиною `k_t`:

```
k_t² = (π / 2) · (f_r / f_a) · tan((π / 2) · ((f_a - f_r) / f_a))
```

Ці математичні співвідношення складають основу стандартизованого методу резонансної спектроскопії (Resonance Ultrasound Spectroscopy) для повного визначення тензора матеріальних констант PZT.
