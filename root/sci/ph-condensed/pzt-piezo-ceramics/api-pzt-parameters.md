# 📋 Параметри та специфікація п'єзокерамічних матеріалів PZT

Цей довідник містить зведені фізико-механічні, електричні та п'єзоелектричні характеристики стандартних промислових марок п'єзокераміки PZT (PZT-4, PZT-5A, PZT-5H, PZT-8), розширений опис фізичних параметрів, правила вибору матеріалу під конкретні інженерні задачі, рівняння температурного старіння та алгоритм визначення компонент еквівалентної схеми Баттерворта — Ван-Дайка (BVD).

---

### Стандартизація та військово-промислова класифікація (Navy Types)

У світовій інженерній практиці характеристики п'єзокераміки регулюються міжнародними стандартами **IEEE Std 176-1987**, **EN 50324** та військовим стандартом США **MIL-STD-1376B (NAVY)**.

Згідно з MIL-STD-1376B, усі комерційні марки PZT поділяють на шість основних типів Navy Types:

- **Navy Type I (наприклад, PZT-4 / ЦТС-19)**: Сегнетожорсткий матеріал високої потужності. Призначений для силових випромінювачів, ультразвукового зварювання, промислових мийок та гідролокаторів середньої потужності.
- **Navy Type II (наприклад, PZT-5A / ЦТС-23)**: Сегнетом'який матеріал загального призначення з високою чутливістю, високою діелектричною проникністю та часовою стабільністю. Призначений для давачів деформації, тиску, акселерометрів, вимірювачів витрати та гідрофонів.
- **Navy Type III (наприклад, PZT-8)**: Наджорсткий силовий матеріал із найнижчими діелектричними та механічними втратами для роботи при екстремальних напруженостях електричних полів та механічних навантаженнях.
- **Navy Type IV (наприклад, BaTiO₃)**: Історичний тип на основі титанату барію.
- **Navy Type V (наприклад, PZT-5H)**: Високочутливий сегнетом'який матеріал із рекордним п'єзомодулем `d₃₃` та гігантською діелектричною проникністю. Призначений для прецизійних наноактюаторів, АФМ-мікроскопів та акустичних випромінювачів низької напруги.
- **Navy Type VI (наприклад, PZT-7A)**: Спеціальний матеріал для високочастотних давачів із високою температурною стабільністю та стабільним коефіцієнтом зв'язку.

### Фізичний зміст та глибокий аналіз параметрів

#### 1. П'єзоелектричні модулі заряда `d[ij]` (pC/N або m/V)
П'єзоелектричний модуль заряда виражає прямо пропорційний зв'язок між електричним полем та механічною деформацією у режимі актуатора (`S = d · E`), або між прикладеною силою та згенерованим зарядом у режимі давача (`Q = d · F`).
- `d₃₃`: Поздовжній п'єзомодуль. Визначає зміну товщини керамічного диска або стека при подачі напруги паралельно до осі поляризації. Значення варіюється від `225 pC/N` у жорсткого PZT-8 до рекордних `593 pC/N` у м'якого PZT-5H.
- `d₃₁`: Поперечний п'єзомодуль. Визначає деформацію стиску або розширення у площині, перпендикулярній до осі поляризації. Оскільки кераміка зберігає об'єм майже незмінним, знак `d₃₁` є протилежним до `d₃₃` (від `-97` до `-274 pC/N`).
- `d₁₅`: Зсувний п'єзомодуль. Визначає кут зсуву граней під дією електричного поля, прикладеного перпендикулярно до осі поляризації. Це найвищий коефіцієнт у PZT, який досягає `741 pC/N` у PZT-5H.

#### 2. П'єзоелектричні модулі напруги `g[ij]` (V·m/N або m²/C)
Модуль напруги виражає напруженість електричного поля, що виникає у кераміці при прикладенні одиничного механічного напруження в режимі розімкнених електродів (холостого ходу):
```
g[ij] = d[ij] / (ε[ij]^T)
```
Чим вище значення `g₃₃`, тим більшу різницю потенціалів створює кераміка при стисканні. Марка PZT-4 має високий `g₃₃ = 26.1 · 10⁻³ V·m/N`, що робить її ідеальною для п'єзоелектричних генераторів та сенсорів удару. Натомість PZT-5H, попри гігантський `d₃₃`, має нижчий `g₃₃ = 19.7 · 10⁻³ V·m/N` через колосальну діелектричну проникність `ε₃₃^T`.

#### 3. Механічна добротність `Q_m`
Механічна добротність виражає відношення накопиченої механічної енергії коливань до енергії, що розсіюється за один період коливань через внутрішнє в'язке тертя кристалографічних доменних стінок:
```
Q_m = 1 / (2 · π · f_r · R_m · C_m)
```
- **Висока добротність (`Q_m = 500–1000`)**: Характерна для сегнетожорстких матеріалів (PZT-4, PZT-8). Кераміка майже не нагрівається при інтенсивних коливаннях на резонансі, що дозволяє передавати кВт акустичної потужності.
- **Низька добротність (`Q_m = 50–75`)**: Характерна для сегнетом'яких матеріалів (PZT-5A, PZT-5H). М'яка кераміка швидко гасить власні резонансні коливання, забезпечуючи широкий частотний діапазон для УЗД-сканерів та дефектоскопів.

#### 4. Діелектричні втрати `tan δ`
Тангенс кута втрат описує активні електричні втрати у диелектрику:
```
tan δ = P_loss / (2 · π · f · W_stored)
```
У сегнетожорстких матеріалів `tan δ` становить всього `0.2–0.4%`, тоді як у сегнетом'яких сягає `2.0%`. При роботі в сильних електричних полях високі втрати спричиняють тепловий розгін кераміки та деполяризацію.

#### 5. Механізми температурного старіння PZT
З часом залишкова поляризація `P_r` та п'єзомодулі `d[ij]` зазнають повільної термодинамічної релаксації (старіння) за логарифмічним законом:
```
d(t) = d_0 · [1 - k_age · log₁₀(t / t_0)]
```
Де `k_age` — коефіцієнт старіння (% на декаду часу). Для жорсткого PZT-8 `k_age < 0.5%`, а для м'якого PZT-5H `k_age ≈ 1.5–2.0%`.

### Матриця вибору матеріалу PZT під прикладні задачі

Для вибору оптимальної марки PZT керуйтеся наступними інженерними критеріями:

```
                            Яка мета розробки?
                                    │
           ┌────────────────────────┴────────────────────────┐
           ▼                                                 ▼
   [ Силовий ультразвук ]                            [ Давачі та Актюатори ]
 (Висока потужність, нагрів)                        (Чутливість, точність)
           │                                                 │
     ┌─────┴─────┐                                     ┌─────┴─────┐
     ▼           ▼                                     ▼           ▼
  [PZT-4]     [PZT-8]                               [PZT-5A]    [PZT-5H]
(Ванни,     (Зварювання,                          (Давачі,    (Мікроприводи,
 сонари)    екстремальне                          гідрофони,   нанопозиціонування,
            навантаження)                         автопром)   низковольтні стеки)
```

1. **Ультразвукові мийки, зварювання пластмас, хірургічний інструмент**:
   - **Рекомендація**: **PZT-8** або **PZT-4**.
   - **Причина**: Низькі втрати (`tan δ < 0.4%`), висока добротність (`Q_m > 500`), висока коерцитивна сила проти деполяризації.
2. **Прецизійні мікроактюатори, АФМ-мікроскопи, адаптивна оптика**:
   - **Рекомендація**: **PZT-5H**.
   - **Причина**: Гігантський п'єзомодуль `d₃₃ ≈ 590 pC/N` дозволяє отримувати максимальне переміщення при низьких напругах.
3. **Давачі тиску, акселерометри, гідрофони, акустичні мікрофони**:
   - **Рекомендація**: **PZT-5A**.
   - **Причина**: Високий коефіцієнт `g₃₃`, стійкість до температури до `200 °C`, стабільність параметрів у часі.

### Алгоритм розрахунку компонент еквівалентної схеми BVD

За результатами вимірювання імпедансу п'єзоелемента на послідовному резонансі `f_r` та антирезонансі `f_a` розраховують компоненти еквівалентної схеми Баттерворта — Ван-Дайка (BVD):

1. **Статична ємність `C₀`**: Вимірюється на частоті `1 kHz` (далеко від резонансу):
   ```
   C₀ = (ε₃₃^T · ε₀ · A) / t
   ```
2. **Динамічна ємність `C_m`**:
   ```
   C_m = C₀ · ((f_a² - f_r²) / f_r²)
   ```
3. **Динамічна індуктивність `L_m`**:
   ```
   L_m = 1 / (4 · π² · f_r² · C_m)
   ```
4. **Динамічний опір `R_m`**: Вимірюється мінімальний імпеданс `Z_min` на частоті `f_r`:
   ```
   R_m = Z_min
   ```

Цей довідковий набір параметрів та алгоритмів дозволяє інженеру швидко провести розрахунок акустичного випромінювача та розробити відповідне джерело живлення.
