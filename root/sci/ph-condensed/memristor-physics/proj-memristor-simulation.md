# ⚙️ Чисельне моделювання нелінійного дрейфу вакансій у мемристорі HP

Ця вставка містить практичну числову реалізацію нелінійного дрейфу кисневих вакансій у двошаровому наномемристорі діоксиду титану (HP Labs). Програма розв'язує систему звичайних диференціальних рівнянь дрейфу з підтримкою віконних функцій Джоглекара та Біолека, що запобігають нефізичному виходу нормованої координати `x = w/D` за межі `[0, 1]` і розв'язують проблему термінального блокування.

## Фізична модель дрейфу та математичний формалізм

У двошаровій моделі Струкова — Вільямса мемристор розглядається як нанорозмірна плівка діоксиду титану товщиною `D ≈ 10 нм`, розділена на два послідовно з'єднаних шари. Перший шар товщиною `w(t)` є збагаченим позитивно зарядженими кисневими вакансіями `V_O⁺⁺` і має низький опір `R_ON`. Другий шар товщиною `D - w(t)` є чистим стехіометричним `TiO₂` із високим опором `R_OFF`.

Рівняння стану нормованої товщини збагаченого шару `x(t) = w(t) / D` з урахуванням віконної функції `f(x, i)` описує дрейф носіїв під дією напрямного електричного поля:

```
dx / dt = (μ_v · R_ON / D²) · i(t) · f(x, i)
```

де:
- `μ_v` — іонна рухливість кисневих вакансій у кристалічній ґратці (типово `10⁻¹⁴–10⁻¹³ м² / (В·с)`);
- `D` — тотальна товщина діелектричної плівки (`10 нм`);
- `R_ON` та `R_OFF` — опір повністю відкритого (`x = 1`) та повністю закритого (`x = 0`) мемристора відповідно;
- `f(x, i)` — безрозмірна віконна функція, що модулює швидкість дрейфу біля меж.

Миттєвий еквівалентний опір елемента становить:

```
R(x) = R_ON · x + R_OFF · (1 - x)
```

### Порівняння віконних функцій: проблема термінального блокування

При лінійному дрейфі без віконної функції (`f(x) = 1`) чисельне інтегрування призводить до того, що під дією постійної або тривалої напруги нормований стан `x(t)` виходить за межі фізичного інтервалу `[0, 1]`, що спричиняє від'ємні значення опору.

Просте вікно Джоглекара `f(x) = 1 - (2x - 1)^(2p)` обнуляє швидкість дрейфу на межах `f(0) = f(1) = 0`. Проте воно має суттєвий недолік — **термінальне блокування (boundary lock)**. Якщо стан пристрою досягає межі `x = 1`, похідна `dx/dt` стає нульовою, і навіть при зміні полярності прикладеної напруги на протилежну (`i < 0`) пристрій не може «зрушити» з місця.

**Віконна функція Біолека (Biolek Window)** усуває цей парадокс шляхом запровадження залежності від напрямку струму через ступенчасту функцію Хевісайда `stp(-i)`:

```
f(x, i) = 1 - (x - stp(-i))^(2p)
```

Коли стан прямує до верхньої межі `x → 1` при додатній напрузі (`i > 0`), ступенчаста функція дорівнює `stp(-i) = 0`, і вікно `f(1, i>0) = 1 - (1 - 0)^(2p) = 0` придушує подальше зростання `x`. 

Проте як тільки полярність змінюється на від'ємну (`i < 0`), значення ступенчастої функції змінюється на `stp(-i) = 1`. У результаті віконний множник стає дорівнювати `f(1, i<0) = 1 - (1 - 1)^(2p) = 1`, що дозволяє вакансіям миттєво почати зворотний дрейф углиб плівки.

## Чисельний алгоритм та вибір методом інтегрування

Оскільки диференціальні рівняння мемристорів із віконними функціями є жорсткими (stiff ODEs) внаслідок експоненційного зростання похідних біля меж, чисельний алгоритм вимагає правильного вибору кроку інтегрування `dt`.

У представленій реалізації використовуються два методи:
1. **Метод Ейлера (у C++ реалізації)**: простий та швидкий алгоритм для демонстрації базової кінетики, який вимагає достатньо малого кроку `dt ≤ 0.1 мс` для уникнення числової нестійкості.
2. **Метод Рунге-Кутти 4-го порядку RK4 (у Python реалізації)**: забезпечує четвертий порядок точності `O(dt⁴)`, обчислюючи чотири проміжні оцінки похідної `k₁, k₂, k₃, k₄` на кожному кроці, що гарантує високу точність фазової траєкторії `I(V)` навіть біля самих меж плівки.

### Параметри симуляції

Для моделювання обрано типові параметри експериментального наномемристора HP Labs:
- `R_ON = 100 Ом` (низькоомний стан із провідним каналом);
- `R_OFF = 16 кОм` (високоомний діелектричний стан);
- `D = 10 нм` (товщина активного діелектричного шару);
- `μ_v = 10⁻¹⁴ м² / (В·с)` (рухливість вакансій у кристалітичному оксиді);
- `V_peak = 1.2 В` (амплітуда синусоїдної напруги);
- `f = 2.0 Гц` (частота гармонічного збудження).

## Аналіз фізичних результатів та чисельна стійкість

Під час виконання програми спостерігається чітка динамічна трансформація стану мемристора:

1. **Додатна півхвиля (`v(t) > 0`)**: електричне поле змушує позитивно заряджені кисневі вакансії `V_O⁺⁺` дрейфувати у напрямку чистого діелектричного шару `TiO₂`. Товщина збагаченого шару `w(t)` зростає, нормований стан `x` збільшується від початкового `0.1` убік `1.0`, а загальний опір `R(x)` монотонно зменшується від `14.4 кОм` до низькоомного стану (ON state).
2. **Від'ємна півхвиля (`v(t) < 0`)**: вектор електричного поля змінює напрямок. Вакансії втягуються назад у збагачений шар, товщина `w(t)` зменшується (`x → 0`), і елемент повертається у високоомний стан (OFF state).

Побудова графіка `i(t)` від `v(t)` за результатами обчислень утворює неперервну **стиснути петлю гістерезису у формі вісімки**, яка проходить строго через точку `(0, 0)`. 

### Аналіз чутливості до параметрів та крайові випадки

1. **Вплив амплітуди напруги `V_peak`**: якщо прикласти занадто малу напругу `V_peak < 0.3 В`, дрейф іонів за один період є мізерним (`Δx < 0.01`), і опір елемента залишається практично постійним. При збільшенні амплітуди до `1.5 В` опір перемикається повністю за один напівперіод, демонструючи ефект порогового резистивного перемикання.
2. **Аналіз стійкості при `x → 0` та `x → 1`**: завдяки функції Біолека похідна `dx/dt` гладко знижується біля меж, запобігаючи числовим осциляціям та виходу `x` за межі відрізка `[0, 1]`. Застосування примусового насичення `max(0.0, min(1.0, x))` слугує додатковим захисним бар'єром числової схеми від похибок накопичення у довготривалих симуляціях.
3. **Оцінка обчислювальних витрат**: алгоритм RK4 вимагає чотирьох обчислень функції похідної на крок, проте забезпечує високу точність фазової траєкторії при кроці `dt = 100 мкс`. Для масового моделювання матричних кросбарів розномірністю `1024 × 1024` елементів у реальному часі зазвичай застосовують оптимізований виявний метод Ейлера з адаптивним вибором кроку за похибкою.

Якщо змінити частоту напруги у симуляторі від `2 Гц` до `200 Гц` (параметр `frequency_hz = 200.0`), то за короткий період `T = 5 мс` іони вакансій фізично не встигатимуть зміститися на помітну відстань (`Δx ≈ 0.001`). Завдяки цьому стан `x(t)` фіксується біля квазіпостійного значення `x_eq`, а вольт-амперна характеристика стискається у прямолінійний омічний опір `i = v / R(x_eq)`, що наочно демонструє другу фундаментальну теорему Леона Чуа про частотне виродження.
