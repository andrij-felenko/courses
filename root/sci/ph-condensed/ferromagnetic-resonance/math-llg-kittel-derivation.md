# 🧮 Виведення рівняння Ландау-Ліфшиця-Гільберта та формули Кіттеля

Математичне виведення рівняння динаміки намагніченості Ландау — Ліфшиця — Гільберта та формули Кіттеля розкриває, як розмагнічувальні фактори форми зразка перетворюють ізотропну Ларморівську прецесію на еліптичну.

---

### 1. Векторна динаміка та рівняння Ландау — Ліфшиця — Гільберта (LLG)

Рух макроскопічного вектора намагніченості `M` під дією ефективного магнітного поля `H_eff` підпорядковується фундаментальному рівнянню прецесії моменту імпульсу. Оскільки зв'язаний з намагніченістю механічний момент імпульсу одиниці об'єму дорівнює `J = M / γ`, рівняння руху без урахування згасання має вигляд:

```
dM / dt = -γ · (M × H_eff)
```

де `γ = g · |e| / (2 m_e)` — ґіромагнітне співвідношення. Оскільки векторний добуток `(M × H_eff)` перпендикулярний до `M`, модуль вектора намагніченості зберігається строго постійним: `|M| = M_s = const`.

Для врахування енергетичної дисипації (згасання прецесії) Томас Гільберт (1955) модифікував феноменологічний член Ландау — Ліфшиця, додавши в'язкий релаксаційний момент сил, пропорційний швидкості зміни вектора намагніченості `dM/dt`:

```
dM / dt = -γ · (M × H_eff)  +  (α / M_s) · [ M × (dM / dt) ]
```

де `α` — безрозмірний параметр згасання Гільберта (`α ≪ 1` для якісних феромагнетиків). 

Векторно помноживши ліву та праву частини рівняння Гільберта на `M`, можна виразити похідну `dM/dt` у явній формі Ландау — Ліфшиця з ефективним ґіромагнітним співвідношенням `γ_G`:

```
dM / dt = -γ_G · (M × H_eff)  -  (α · γ_G / M_s) · [ M × (M × H_eff) ]
```

де `γ_G = γ / (1 + α²)`. У слабкозгасаючих середовищах (`α² ≪ 1`) прийнято покладати `γ_G ≈ γ`.

### 2. Лінеаризація рівнянь для малих відхилень

Розглянемо феромагнітний зразок у формі еліпсоїда з головними осями `x, y, z`. Постійне зовнішнє магнітне поле `H₀` прикладене вздовж осі `z`. У стані рівноваги вектор спонтанної намагніченості орієнтований вздовж поля: `M_0 = (0, 0, M_s)`.

Нехай слабке високочастотне НВЧ-магнітне поле `h(t) = (h_x e^{i ω t}, h_y e^{i ω t}, 0)` викликає малі динамічні відхилення намагніченості `m(t) = (m_x, m_y, 0)`, де `|m_x|, |m_y| ≪ M_s`. 

Тоді повний вектор намагніченості дорівнює:

```
M(t) = ( m_x(t),  m_y(t),  M_s - (m_x² + m_y²) / (2 M_s) )  ≈  ( m_x(t),  m_y(t),  M_s )
```

Ефективне магнітне поле `H_eff` всередині зразка складається з чотирьох компонентів:
1. Зовнішнє статичне поле `H₀ ẑ`.
2. Зовнішнє змінне НВЧ-поле `h(t) = (h_x, h_y, 0)`.
3. Внутрішнє розмагнічувальне поле форми `H_d = -N · M = (-N_x m_x,  -N_y m_y,  -N_z M_s)`, де `N_x, N_y, N_z` — розмагнічувальні фактори, що задовольняють умову нормування `N_x + N_y + N_z = 1` (у системі СІ).
4. Ефективне поле кристалографічної анізотропії `H_k = (2 K_u / M_s) ẑ`.

Збираючи усі компоненти вектора `H_eff`:

```
H_eff,x = h_x - N_x · m_x
H_eff,y = h_y - N_y · m_y
H_eff,z = H₀ + H_k - N_z · M_s
```

Для спрощення позначень введемо ефективне поздовжнє поле `H_z = H₀ + H_k - N_z M_s`.

### 3. Алгебраїчний вивід власної частоти (формула Кіттеля)

Підставимо розклади для `M` та `H_eff` у лінеаризоване рівняння руху без згасання (`dM/dt = -γ (M × H_eff)`) та відкинемо добутки малих величин другого порядку (`m_x h_x ≈ 0`):

```
d m_x / dt = -γ · [ m_y · H_eff,z  -  M_s · H_eff,y ]
d m_y / dt = -γ · [ M_s · H_eff,x  -  m_x · H_eff,z ]
```

Підставивши компоненти `H_eff`:

```
d m_x / dt = -γ · [ m_y · H_z - M_s · (h_y - N_y m_y) ]
           = -γ · [ H_z + N_y M_s ] · m_y  +  γ M_s · h_y

d m_y / dt = -γ · [ M_s · (h_x - N_x m_x) - m_x · H_z ]
           =  γ · [ H_z + N_x M_s ] · m_x  -  γ M_s · h_x
```

Шукаємо власні коливання системи за відсутності зовнішнього змінного поля (`h_x = h_y = 0`). Припустивши гармонічну часову залежність `m_x, m_y ∝ exp(i ω t)`:

```
i ω · m_x  +  γ · [ H₀ + H_k + (N_y - N_z) M_s ] · m_y  =  0
-γ · [ H₀ + H_k + (N_x - N_z) M_s ] · m_x  +  i ω · m_y  =  0
```

Для існування ненульового розв'язку детермінант цієї системи двох лінійних рівнянь має дорівнювати нулю:

```
det |   i ω                           γ [ H₀ + H_k + (N_y - N_z) M_s ]   |  =  0
    | -γ [ H₀ + H_k + (N_x - N_z) M_s ]                i ω               |
```

Обчислюємо детермінант:

```
(i ω) · (i ω)  -  [ -γ (H₀ + H_k + (N_x - N_z) M_s) ] · [ γ (H₀ + H_k + (N_y - N_z) M_s) ] = 0
-ω²  +  γ² · [ H₀ + H_k + (N_x - N_z) M_s ] · [ H₀ + H_k + (N_y - N_z) M_s ] = 0
```

Переносячи `ω²` в праву частину та добуваючи квадратний корінь, отримуємо **загальну формулу Кіттеля** для частоти феромагнітного резонансу з урахуванням анізотропії:

```
ω₀ = γ · √[ ( H₀ + H_k + (N_x - N_z) · M_s ) · ( H₀ + H_k + (N_y - N_z) · M_s ) ]
```

### 4. Докладний розбір граничних випадків для різних геометрій

Формула Кіттеля показує фундаментальну залежність резонансної частоти від геометрії зразка та напрямку прикладеного поля:

#### 1. Сферичний зразок (`N_x = N_y = N_z = 1 / 3`)
Різниця розмагнічувальних факторів дорівнює нулю: `N_x - N_z = 0` та `N_y - N_z = 0`.
```
ω₀ = γ · ( H₀ + H_k )
```
Частота резонансу сфери за відсутності анізотропії (`H_k = 0`) строго збігається з Ларморівською частотою ізотропного спіна `ω₀ = γ H₀` і не залежить від намагніченості `M_s`.

#### 2. Тонка плівка з полем у площині (`N_x = 1`, `N_y = 0`, `N_z = 0`)
Нехай вісь `x` нормальна до площини плівки, а статичне поле `H₀` прикладене вздовж осі `z` у площині плівки:
```
N_x - N_z = 1 - 0 = 1
N_y - N_z = 0 - 0 = 0
ω₀ = γ · √[ ( H₀ + H_k + M_s ) · ( H₀ + H_k ) ]
```
Поле розмагнічування нормальної компоненти створює додаткову «жорсткість», суттєво підвищуючи частоту резонансу.

#### 3. Тонка плівка з перпендикулярним полем (`N_x = 0`, `N_y = 0`, `N_z = 1`)
Нехай статичне поле `H₀` прикладене вздовж нормалі до плівки (вісь `z`):
```
N_x - N_z = 0 - 1 = -1
N_y - N_z = 0 - 1 = -1
ω₀ = γ · ( H₀ + H_k - M_s )    (при H₀ + H_k > M_s)
```
Поле розмагнічування віднімається від зовнішнього поля `H₀`. Резонанс виникає лише тоді, коли ефективне поле перевищує поле насичення плівки.

#### 4. Нескінченний циліндр вздовж осі поля (`N_x = 1/2`, `N_y = 1/2`, `N_z = 0`)
Нехай вісь циліндра орієнтована вздовж полю `z`:
```
N_x - N_z = 1/2
N_y - N_z = 1/2
ω₀ = γ · ( H₀ + H_k + M_s / 2 )
```

#### 5. Нескінченний циліндр перпендикулярно до осі поля (`N_x = 0`, `N_y = 1/2`, `N_z = 1/2`)
Нехай вісь циліндра орієнтована вздовж осі `x`, перпендикулярно до поля `z`:
```
N_x - N_z = -1/2
N_y - N_z = 0
ω₀ = γ · √[ ( H₀ + H_k - M_s / 2 ) · ( H₀ + H_k ) ]
```

### 5. Тензор динамічної магнітної сприйнятливості та поглинання НВЧ-енергії

При розв'язанні неоднорідної системи з НВЧ-полем `h(t)` зв'язок між змінною намагніченістю та полем дається тензором сприйнятливості `m = χ(ω) · h`:

```
m_x = χ_xx · h_x  +  i · χ_xy · h_y
m_y = -i · χ_xy · h_x  +  χ_yy · h_y
```

З урахуванням згасання Гільберта `α` (через зміну `i ω → i ω + α ω` у рівняннях руху) діагональна компонента тензора для сферичного зразка набуває вигляду:

```
χ_xx(ω) = χ'(ω) - i · χ''(ω) = (γ · M_s · ω₀) / ( ω₀² - ω² + i · 2 · α · ω · ω₀ )
```

Виділяючи дійсну та уявную частини:

```
χ'(ω)  = ( γ · M_s · ω₀ · (ω₀² - ω²) ) / ( (ω₀² - ω²)² + (2 α ω ω₀)² )
χ''(ω) = ( 2 · α · γ · M_s · ω² · ω₀ ) / ( (ω₀² - ω²)² + (2 α ω ω₀)² )
```

Уявна частина тензора `χ''(ω)`, яка відповідає за поглинання НВЧ-потужності `P = (1/2) ω χ'' h²`, має класичну лоренцівську форму. Ширина лінії поглинання на напіввисоті у термінах частоти становить:

```
Δω = 2 · α · ω₀
```

Перераховуючи ширину лінії у шкалу магнітного поля `ΔH = Δω / (dω₀/dH₀)`, отримуємо фундаментальне співвідношення Гільберта:

```
ΔH = ( 2 · α / γ ) · ω
```

### 6. Нелінійні нестійкості Зуля при високих рівнях НВЧ-потужності

При проведенні FMR-вимірювань виникає важливе фізичне обмеження на амплітуду змінного НВЧ-поля `h_RF`. Коли амплітуда НВЧ-поля перевищує певний поріг `h_c`, лінеаризовані рівняння LLG перестають працювати через розвиток **нелінійних нестійкостей Зуля (Suhl Instabilities)**.

Гаррі Зуль у 1957 році розробив нелінійну теорію, показавши існування двох типів параметричних нестійкостей:

1. **Нестійкість Зуля I роду (Параметричний резонанс спінових хвиль):**
   Виникає при збігу половини частоти FMR `ω₀ / 2` з частотою спінових хвиль `ω_k`. Однорідна прецесія `k = 0` вироджується і параметрично накачує пару спінових хвиль із протилежно спрямованими хвильовими векторами `k` та `-k` на половинній частоті `ω_k = ω₀ / 2`.
2. **Нестійкість Зуля II роду (Насичення головного резонансу):**
   Виникає безпосередньо на частоті FMR `ω₀ = ω_k`. При досягненні критичного кута прецесії `θ_c ≈ 1°–3°` енергія від однорідної прецесії починає інтенсивно передаватися у короткохвильові магнони тієї ж частоти.

Експериментально це проявляється як розширення лінії `ΔH`, передчасне насичення амплітуди поглинання та виникнення додаткових супутніх піків поглинання у слабших магнітних полях.
