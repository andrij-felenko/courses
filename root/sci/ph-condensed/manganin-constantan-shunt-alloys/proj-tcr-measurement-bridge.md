# ⚙️ Алгоритм та код компенсації термо-ЕРС і вимірювання ТКО

Автоматизоване вимірювання температурного коефіцієнта опору (ТКО) прецизійних сплавів типу манганіну та константану вимагає усунення двох основних систематичних похибок: паразитної термоелектрорушійної сили (термо-ЕРС) у контактах вимірювального кола та власного джоулевого самонагріву досліджуваного зразка під час проходження вимірювального струму.

## 1. Метод імпульсного реверсу струму (Chopped DC / Current Reversal)

Для повного компенсаційного усунення постійної складної термо-ЕРС `V_emf` у чотирипровідній схемі Кельвіна вимірювальний струм `I` пропускають через зразок послідовно у прямому та зворотному напрямках.

Схема побудована на використанні керованого джерела струму та мостового комутатора (H-моста) на низькоомних твердотільних реле. Метод базується на двох послідовних тактах вимірювання:

1. **Пряма фаза (+I)**: вимірювальне джерело задає струм `+I`. Напруга на потенційних клемах дорівнює алгебраїчній сумі корисного падіння напруги та паразитної термо-ЕРС:
   ```
   V_pos = I · R + V_emf
   ```
2. **Зворотна фаза (-I)**: джерело інвертує напрямок струму на `-I`. Оскільки термо-ЕРС виникає внаслідок градієнта температур `ΔT` і не залежить від напрямку струму у колі, її знак залишається незмінним:
   ```
   V_neg = -I · R + V_emf
   ```

Різниця двох послідовних вимірювань повністю виключає термо-ЕРС:

```
V_true = (V_pos - V_neg) / 2
       = (I · R + V_emf - (-I · R + V_emf)) / 2
       = (2 · I · R) / 2 = I · R     [термо-ЕРС V_emf взаємно гаситься]
```

Істинний опір `R` обчислюється як `R = V_true / I`.

Паразитна напруга термо-ЕРС `V_emf`, яка була присутня під час тактів вимірювання, може бути виділена та збережена для діагностики термічного дисбалансу колових контактів:

```
V_emf = (V_pos + V_neg) / 2
```

## 2. Апаратна топологія вимірювального комплексу

Автоматизована вимірювальна установка містить наступні апаратні вузли:

- **Термокамера**: Термостатована олійна або повітряна камера з елементами Пельтьє та PID-регулятором, що підтримує температуру від `15 °C` до `60 °C` із точністю `±0.01 °C`.
- **Джерело струму**: Прецизійне джерело постійного струму на операційному підсилювачі з від'ємним зворотним зв'язком та опорним напруговим елементом (наприклад, ADR4525), що задає тестовий струм від `10 мА` до `1 А`.
- **Комутатор полярності**: Ключова схема на чотирьох MOSFET-транзисторах із низьким опором каналу (`R_ds_on < 5 мОм`) або бістабільних реле з золотомеченими контактами.
- **Аналого-цифровий перетворювач**: 24-бітний дельта-сігма АЦП (ADS1256, LTC2400) із вхідним підсилювачем низького шуму (PGA).

Для запобігання похибкам від власного самонагріву досліджуваного зразка джоулевим тепла вимірювальний струм подають короткочасними імпульсами тривалістю `100–200 мс`. Між перемиканнями полярності струму обов'язково витримують технічну паузу `50 мс` для загасання перехідних індуктивних та ємнісних процесів у комутаційних реле та кабельних лініях.

Програма керування автоматично знімає відгуки напруги при зміні температури термокамери від `15 °C` до `60 °C` з кроком `5 °C`, після чого виконує квадратичну поліноміальну регресію методом найменших квадратів.

## 3. Програмна реалізація компенсації та обчислення α, β

Нижче наведено робочий код компенсації термо-ЕРС та МНК-обчислення ТКО двома мовами: C та ідіоматичною C++.

```c
/* tcr_analyzer.c - Автоматизована компенсація термо-ЕРС та МНК-апроксимація ТКО */
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

typedef struct {
    double temp_c;   /* Температура у градусах Цельсія */
    double v_pos;    /* Напруга при прямому струмі (+I), Вольт */
    double v_neg;    /* Напруга при зворотному струмі (-I), Вольт */
} tcr_measurement_t;

typedef struct {
    double r0;       /* Опір при 20 °C, Ом */
    double alpha;    /* Лінійний ТКО, 1/K або ppm/K */
    double beta;     /* Квадратичний ТКО, 1/K^2 або ppm/K^2 */
    double t_max;    /* Температура вершини параболи, °C */
} tcr_fit_result_t;

/* Обчислення істинного опору без паразитної термо-ЕРС */
double compute_true_resistance(double v_pos, double v_neg, double i_test) {
    double v_true = (v_pos - v_neg) / 2.0;
    return v_true / i_test;
}

/* Обчислення паразитної термо-ЕРС, яка була присутня під час вимірювання */
double compute_thermal_emf(double v_pos, double v_neg) {
    return (v_pos + v_neg) / 2.0;
}

/* Квадратична регресія методом найменших квадратів (МНК) для R(T) = R0 * (1 + a*dT + b*dT^2) */
int fit_tcr_parabola(const tcr_measurement_t* data, size_t count, double i_test, tcr_fit_result_t* result) {
    if (!data || count < 3 || !result || i_test <= 0.0) {
        return -1;
    }

    double s0 = 0.0, s1 = 0.0, s2 = 0.0, s3 = 0.0, s4 = 0.0;
    double sy = 0.0, s1y = 0.0, s2y = 0.0;

    for (size_t i = 0; i < count; ++i) {
        double dt = data[i].temp_c - 20.0;
        double r = compute_true_resistance(data[i].v_pos, data[i].v_neg, i_test);

        double dt2 = dt * dt;
        s0 += 1.0;
        s1 += dt;
        s2 += dt2;
        s3 += dt * dt2;
        s4 += dt2 * dt2;

        sy += r;
        s1y += dt * r;
        s2y += dt2 * r;
    }

    /* Розв'язання системи лінійних рівнянь 3x3 за методом Крамера */
    double det = s0 * (s2 * s4 - s3 * s3) - s1 * (s1 * s4 - s2 * s3) + s2 * (s1 * s3 - s2 * s2);
    if (fabs(det) < 1e-12) {
        return -2; /* Вироджена матриця */
    }

    double det_a = sy * (s2 * s4 - s3 * s3) - s1 * (s1y * s4 - s2y * s3) + s2 * (s1y * s3 - s2y * s2);
    double det_b = s0 * (s1y * s4 - s2y * s3) - sy * (s1 * s4 - s2 * s3) + s2 * (s1 * s3 - s2y * s2);
    double det_c = s0 * (s2 * s2y - s1y * s3) - s1 * (s1 * s2y - s1y * s2) + sy * (s1 * s3 - s2 * s2);

    double c0 = det_a / det;  /* R0 */
    double c1 = det_b / det;  /* R0 * alpha */
    double c2 = det_c / det;  /* R0 * beta */

    result->r0 = c0;
    result->alpha = (c1 / c0) * 1e6; /* Переведення у ppm/K */
    result->beta = (c2 / c0) * 1e6;  /* Переведення у ppm/K^2 */
    
    if (fabs(result->beta) > 1e-9) {
        result->t_max = 20.0 - (result->alpha / (2.0 * result->beta));
    } else {
        result->t_max = 20.0;
    }

    return 0;
}
```

```cpp
// tcr_analyzer.cpp - Ідіоматична C++ реалізація з RAII, std::span та std::expected
#include <iostream>
#include <vector>
#include <span>
#include <expected>
#include <cmath>
#include <numeric>

struct TcrMeasurement {
    double temp_c{};
    double v_pos{};  // Напруга при +I, Вольт
    double v_neg{};  // Напруга при -I, Вольт
};

struct TcrFitResult {
    double r0{};       // Опір при 20 °C, Ом
    double alpha_ppm{};// Лінійний ТКО, ppm/K
    double beta_ppm{}; // Квадратичний ТКО, ppm/K^2
    double t_max_c{};  // Температура вершини параболи, °C
};

enum class TcrFitError {
    InsufficientData,
    InvalidCurrent,
    DegenerateMatrix
};

class TcrAnalyzer {
public:
    explicit TcrAnalyzer(double test_current_a) : test_current_(test_current_a) {}

    [[nodiscard]] double compute_true_resistance(const TcrMeasurement& m) const noexcept {
        return ((m.v_pos - m.v_neg) / 2.0) / test_current_;
    }

    [[nodiscard]] double compute_thermal_emf(const TcrMeasurement& m) const noexcept {
        return (m.v_pos + m.v_neg) / 2.0;
    }

    [[nodiscard]] std::expected<TcrFitResult, TcrFitError> 
    fit_parabola(std::span<const TcrMeasurement> data) const noexcept {
        if (data.size() < 3) {
            return std::unexpected(TcrFitError::InsufficientData);
        }
        if (test_current_ <= 0.0) {
            return std::unexpected(TcrFitError::InvalidCurrent);
        }

        double s0 = 0.0, s1 = 0.0, s2 = 0.0, s3 = 0.0, s4 = 0.0;
        double sy = 0.0, s1y = 0.0, s2y = 0.0;

        for (const auto& m : data) {
            double dt = m.temp_c - 20.0;
            double r = compute_true_resistance(m);

            double dt2 = dt * dt;
            s0 += 1.0;
            s1 += dt;
            s2 += dt2;
            s3 += dt * dt2;
            s4 += dt2 * dt2;

            sy += r;
            s1y += dt * r;
            s2y += dt2 * r;
        }

        double det = s0 * (s2 * s4 - s3 * s3) - s1 * (s1 * s4 - s2 * s3) + s2 * (s1 * s3 - s2 * s2);
        if (std::abs(det) < 1e-12) {
            return std::unexpected(TcrFitError::DegenerateMatrix);
        }

        double det_a = sy * (s2 * s4 - s3 * s3) - s1 * (s1y * s4 - s2y * s3) + s2 * (s1y * s3 - s2y * s2);
        double det_b = s0 * (s1y * s4 - s2y * s3) - sy * (s1 * s4 - s2 * s3) + s2 * (s1 * s3 - s2y * s2);
        double det_c = s0 * (s2 * s2y - s1y * s3) - s1 * (s1 * s2y - s1y * s2) + sy * (s1 * s3 - s2 * s2);

        double c0 = det_a / det;
        double c1 = det_b / det;
        double c2 = det_c / det;

        TcrFitResult res{};
        res.r0 = c0;
        res.alpha_ppm = (c1 / c0) * 1e6;
        res.beta_ppm = (c2 / c0) * 1e6;
        res.t_max_c = (std::abs(res.beta_ppm) > 1e-9) 
            ? (20.0 - (res.alpha_ppm / (2.0 * res.beta_ppm))) 
            : 20.0;

        return res;
    }

private:
    double test_current_{1.0};
};
```

## 4. Опис алгоритму та обробка помилок у коді

Алгоритм регресійного аналізу виконує обчислення у три послідовні етапи:

1. **Етап очищення даних**: Функція `compute_true_resistance()` обчислює різницю двох напруг `(V_pos - V_neg) / 2.0` та ділить її на тестовий струм, одержуючи опір зразка без паразитної термо-ЕРС.
2. **Формування матриці нормальних рівнянь**: Обчислюються суми степенів температурного відхилення `∑ΔT`, `∑ΔT²`, `∑ΔT³`, `∑ΔT⁴` та суми добутків `∑R`, `∑ΔT·R`, `∑ΔT²·R`.
3. **Обчислення методом Крамера**: Обчислюється головний визначник матриці `det`. Якщо визначник виявляється близьким до нуля (`|det| < 1e-12`), це свідчить про виродженість даних (наприклад, всі вимірювання виконані при одній температурі). Код повертає відповідну помилку `DegenerateMatrix`.
4. **Розрахунок фізичних параметрів**: Коефіцієнти полінома `c0`, `c1`, `c2` нормуються відносно `R0`, виражаючи ТКО `α` та `β` у зручних метрологічних одиницях `ppm/K` та `ppm/K²`.

## 5. Аналіз розширеної невизначеності вимірювань

При атестації прецизійних сплавів у відповідності до вимог міжнародних метрологічних стандартів ISO/IEC 17025 підсумкова розширена невизначеність `U(TCR)` визначається об'єднанням трьох незалежних компонент:

- **Компонента АЦП**: Невизначеність вимірювання напруги АЦП (з урахуванням квантування, лінійності та шуму підсилювача).
- **Компонента термометрії**: Невизначеність платинового датчика температури Pt100 та каканалу термостатування.
- **Компонента регресії**: Невизначеність відхилень виміряних точок від квадратичної параболи (залишкова дисперсія).

Використання методу двофазного реверсу струму повністю ліквідує термоелектричну компоненту невизначеності, знижуючи підсумкову розширену невизначеність ТКО до рівня менше ніж `0.05 ppm/K`.

## 6. Часові затримки та релаксація термодинамічного стану

При зміні напрямку струму у мостовому інверторі виникають спалахи завад, пов'язані з самоіндукцією підвідних кабелів та реактивністю вимірювального шунта. Якщо вимірювання напруги виконувати негайно після спрацьовування реле, АЦП зареєструє перехідний процес, що спотворить обчислене значення опору.

З цієї причини в алгоритмі керування передбачено затримку релаксації `t_rel = 50 мс`, яка перевищує постійну часу вимірювального кола `τ = L / R` принаймні у п'ять разів (`t_rel > 5 · τ`).

Крім того, при тривалому проходженні струму прямої фази на контактах з'єднання починає накопичуватися температура за ефектом Пельтьє. Завдяки синхронному вимірюванню зворотної фази тривалість кожного імпульсу `100 мс` є занадто малою для розвитку локальних термічних градієнтів у мідно-манганінових блоках.

## 7. Практичні вказівки до проведення вимірювань

1. **Мінімізація комутаційних завад**: Для перемикання полярності струму слід використовувати реле з контактними групами з золоченого срібла або герконові реле із наднизьким власнім термо-ЕРС потенціалом (`< 100 нВ`).
2. **Контроль термостатування**: Реєстрацію значень `V_pos` та `V_neg` виконують лише після того, як датчик температури вимірювальної камери підтвердить стабільність температури в межах `±0.01 °C` протягом не менше ніж `5 хвилин`.
3. **Статистична фільтрація вибірки**: Кожне значення напруги обчислюють як медіану вибірки з `100` послідовних вимірювань АЦП для ефективного видалення випадкових імпульсних завад промислової мережі `50 Гц`.
