# 🔌 Архітектура та фізика 2D польових транзисторів (2D FET)

Польові транзистори на основі атомарно тонких двовимірних напівпровідників є фундаментальним класом електронних пристроїв, здатних подолати короткоканальні ефекти (short-channel effects) при масштабуванні транзисторного каналу нижче `5 нм`. Фізика роботи 2D FET визначається електростатичним розподілом потенціалу у квантово-обмеженому каналі, механізмами формування бар'єра Шотткі на контактах, діелектричним екрануванням у моношарах та фундаментальними межами підпорогового нахилу.

## 1. Конструкція каналу та електростатичний контроль у нанометровому маштабі

При зменшенні фізичної довжини затвора `L_g < 10 нм` у класичних об'ємних напівпровідникових транзисторах (Planar MOSFET або FinFET) виникає деградація електростатичного контролю. Електричне поле стоку починає проникати в глибину напівпровідникового каналу, що викликає зниження потенціального бар'єра, індуковане стоком (DIBL — Drain-Induced Barrier Lowering), підвищення підпорогового струму витоку та пробій затвора.

Електростатична довжина екранування `λ`, яка визначає глибину проникнення паразитного поля стоку в канал та визначає мінімально можливу довжину затвора без виникнення короткоканальних ефектів `L_{g, min} ≈ 3 · λ`, описується формулою:

```
λ = √ [ (ε_ch / (N · ε_ox)) · d_ch · t_ox ]
```

де `d_ch` — товщина напівпровідникового каналу, `t_ox` — товщина затворної ізоляції, `ε_ch` та `ε_ox` — відносні діелектричні проникності каналу та оксиду відповідно, а `N` — геометричний фактор транзистора (`N = 1` для однозатворного транзистора, `N = 2` для двозатворного та `N = 4` для архітектури з повністю охоплюючим затвором Gate-All-Around).

Для об'ємного кремнію мінімальна товщина каналу `d_ch` обмежена величиною близько `3–5 нм`, оскільки подальше потоншення викликає колосальну деградацію рухливості носіїв через розсіяння на шорсткостях поверхонь. Це дає довжину екранування `λ ≈ 3–4 нм`, що встановлює межу довжини затвора `L_g ≈ 10–12 нм`.

У двовимірних напівпровідниках (дихалькогенідах перехідних металів TMD, таких як `MoS₂`, `WSe₂`, `MoSe₂`) товщина моношару фіксована на атомарному рівні і становить всього `d_ch ≈ 0.65–0.70 нм`. Оскільки поверхня моношару є атомарно гладкою і не містить ненасичених хімічних зв'язків (dangling bonds), носії заряду не зазнають поверхневого розсіяння.

```
[Об'ємний Si-канал: d_ch ≈ 5–10 нм]  →  λ ≈ 3.5 нм   (Сильні короткоканальні ефекти при L_g < 10 нм)
[2D моношар MoS₂:  d_ch ≈ 0.65 нм]   →  λ ≈ 0.8 нм   (Ідеальний контроль затвора при L_g ≈ 1–3 нм)
```

Завдяки малій товщині `d_ch ≈ 0.65 нм` довжина екранування `λ` у 2D FET зменшується до `λ ≈ 0.8–1.0 нм`. Це дає змогу затвору здійснювати повний електростатичний контроль над розподілом потенціалу у каналі навіть при екстремальному масштабуванні довжини затвора до `L_g ≈ 1–3 нм`.

```
         [Верхній затвор (Top Gate: Metal / Graphene)]
--------------------------------------------------------------
         [Верхній диелектрик h-BN / HfO₂ (t_ox ≈ 2-5 нм)]
==============================================================
 [Стік (Drain)] ═══ [Канал моношару MoS₂ / WSe₂] ═══ [Витік (Source)]
==============================================================
         [Нижній диелектрик h-BN (Bottom Gate Dielectric)]
--------------------------------------------------------------
         [Нижній затвор / Підкладка Si (Back Gate)]
```

## 2. Потенціальний бар'єр Шотткі та вандерваальсові контакти

Головним технологічним викликом при створенні високоефективних 2D FET є контактний опір `R_c` на межі розділу між тривимірним металевим електродом (витіком/стоком) та двовимірним напівпровідниковим каналом.

При традиційному осадженні металу (Au, Ti, Ni, Pt) методом термічного або електронно-променевого напилення високоенергетичні атоми металу бомбардують атомарну решітку 2D матеріалу, розриваючи ковалентні зв'язки та утворюючи дефекти. Це призводить до утворення дежурних станів у забороненій зоні та ефекту закріплення рівня Фермі (Fermi Level Pinning):

```
Φ_SB = Φ_M - χ_sem      [у разі відсутності закріплення рівня Фермі]
```

де `Φ_SB` — висота потенціального бар'єра Шотткі (від імені німецького фізика Вальтера Шотткі), `Φ_M` — робота виходу металу, а `χ_sem` — сродство до електрона двовимірного напівпровідника.

При сильному закріпленні рівня Фермі рівень `E_F` металу фіксується поблизу середини забороненої зони напівпровідника незалежно від обраного металу. Це створює високий бар'єр Шотткі `Φ_SB ≈ 0.3–0.6 еВ`.

Струм через бар'єр Шотткі у підпороговому режимі описується формулою термоелектронної емісії:

```
I_DS = A* · T² · exp( - e · Φ_SB / (k_B · T) ) · [ exp( e · V_DS / (k_B · T) ) - 1 ]
```

де `A*` — ефективна стала Річардсона (від імені британського фізика Оуена Річардсона). Високий бар'єр `Φ_SB` експоненційно обмежує інжекцію носіїв заряду з витоку в канал, обмежуючи струм у відкритому стані `I_ON` та збільшуючи контактний опір до `R_c > 10–100 кОм·мкм`.

Для подолання бар'єра Шотткі застосовують три альтернативні архітектури контактів:
1. **Безпошкоджені вандерваальсові контакти (van der Waals Contacts):** Механічний перенос попередньо сформованих атомарно гладких металевих плівок або застосування ультранизької роботи виходу (наприклад, сплавів вісмуту `Bi` або індію `In`). Відсутність хімічного пошкодження каналу усуває закріплення рівня Фермі, зменшуючи бар'єр до `Φ_SB → 0` та контактний опір до рекордних `R_c < 100 Ом·мкм`.
2. **Фазові контакти (Phase-Engineered Contacts):** Локальне хімічне перетворення напівпровідникової 2H-фази моношару `MoS₂` у металеву 1T-фазу (з октаедричною координацією атомів). Металева 1T-фаза формує з напівпровідниковою 2H-фазою атомарно безшовний ковалентний контакт із білянульовим бар'єром.
3. **Графенові контакти:** Використання моношару графена як проміжного контакту. Напруга на додатковому затворі дає змогу ефективно змінювати роботу виходу графена `Φ_g`, налаштовуючи її точно під дно зони провідності або вершину валентної зони TMD.

## 3. Підпороговий нахил та термодинамічні межі перемикання

Ключовим параметром енергоефективності транзистора є підпороговий нахил (Subthreshold Swing, SS), який визначає зміну напруги на затворі `ΔV_GS`, необхідну для зміни струму стоку `I_DS` на один порядок (у 10 разів):

```
SS = d V_GS / d(log₁₀ I_DS) = ln(10) · (k_B · T / e) · (1 + C_d / C_ox)
```

де `C_d` — ємність збідненого шару каналу, `C_ox` — ємність заторного диелектрика, а `n = 1 + C_d / C_ox` — коефіцієнт ідеалності транзистора.

Оскільки товщина каналу 2D FET становить всього `0.65 нм`, збіднена зона охоплює увесь шар повністю, а ємність збіднення прямує до нуля `C_d → 0`. Це забезпечує граничний коефіцієнт ідеалності `n → 1.0`.

При кімнатній температурі (`T = 300 К`) фундаментальна термодинамічна межа підпорогового нахилу для будь-якого класичного транзистора з термоелектронним механізмом інжекції носіїв становить:

```
SS_limit = ln(10) · (k_B · 300 / e) ≈ 59.5 мВ/декаду
```

Завдяки атомарній гладкості інтерфейсу між моношаром TMD та диелектриком h-BN 2D FET досягають граничних експериментальних значень `SS ≈ 60–62 мВ/декаду`. Це дає змогу знизити напругу живлення транзистора до `V_DD < 0.5 В`, зменшуючи статичну потужність розсіювання мікросхем.

```
[Підпороговий струм витоку I_DS]
    ↑
10⁻³│              /  2D FET з h-BN диелектриком (SS ≈ 60 мВ/дек)
    │             /
10⁻⁶│            /   / Кремнієвий FinFET (SS ≈ 80-90 мВ/дек)
    │           /   /
10⁻⁹│          /   /
    └─────────┴───┴──────────────→  Напруга затвора V_GS
```

## 4. Механізми розсіяння та деградація рухливості

Попри відсутність шорсткості поверхні, рухливість носіїв заряду `μ` у реальних 2D FET обмежена трьома основними механізмами розсіяння:

1. **Розсіяння на оптичних фононах підкладки (RIP — Remote Interfacial Phonon Scattering):** Полярні фонони високовисокої частоти у диелектрику підкладки (наприклад, у `SiO₂` або `HfO₂`) створюють дистанційне змінне електричне поле, яке проникає в атомарно тонкий 2D канал та розсіює електрони. Заміна `SiO₂` на атомарно плоский h-BN пригнічує RIP-розсіяння в десятки разів.
2. **Примісне кулонівське розсіяння (Charged Impurity Scattering):** Локалізовані заряди на інтерфейсі підкладка/канал створюють кулонівські центри розсіяння. Слабке 2D екранування потенціалу Кельдиша робить 2D електрони чутливими до цих зарядів при низьких концентраціях носіїв.
3. **Власне фононне розсіяння (Intrinsic Acoustic & Optical Phonons):** При підвищенні температури `T > 200 К` основним обмеженням стає розсіяння на акустичних та внутрішньозонних оптичних фононах самого моношару. Для моношару `MoS₂` решіткова рухливість обмежена величиною `μ_limit ≈ 410 см²/(В·с)` при кімнатній температурі.
