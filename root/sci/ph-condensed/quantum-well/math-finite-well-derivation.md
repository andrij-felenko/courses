# 🧮 Математичне виведення енергетичних рівнів прямокутної ями та 2D густини станів

Для фундаментального математичного опису квантованих електронних станів у гетероструктурній квантовій ямі використовується **наближення огинаючої функції** (*envelope function approximation*, EFA), розроблене у межах `k·p`-методів теорії зон. У цьому підході швидкі атомарні осциляції кристалічного потенціалу з періодом ґратки `a_0` усереднюються, а повна тривимірна хвильова функція носія `Ψ(r, z)` розкладається на добуток швидкоосцилюючої блохівської амплітуди дна зони `u_0(r)` та повільної огинаючої хвильової функції `χ(z)`:

```
Ψ(x, y, z) = u_0(x, y, z) · χ(z) · exp(i · k_x · x + i · k_y · y)
```

де `k_∥ = (k_x, k_y)` — двовимірний хвильовий вектор вільного руху носія у площині ями (паралельно гетеромежам, площина `xy`), `u_0(r)` — періодичний блохівський множник дна зони у центрі зони Бріллюена (точка `Γ`, `k = 0`), а `χ(z)` — квантована огинаюча хвильова функція поздовжнього руху вздовж осі конфайнменту `z`.

---

### Одновимірне рівняння Шредінгера у формі Штурма — Ліувілля

Розглянемо симетричну одновимірну потенціальну яму шириною `L_z` з постійною глибиною `V_0`. Початок системних координат `z = 0` розмістимо строго у геометричному центрі ями:

```
V(z) = 0,    при |z| ≤ L_z / 2   (шар активної ями, наприклад, GaAs)
V(z) = V_0,  при |z| > L_z / 2   (шар потенціального бар'єра, наприклад, Al_x Ga_1-x As)
```

Стаціонарне одновимірне рівняння Шредінгера для огинаючої функції `χ(z)` у формі Штурма — Ліувілля із урахуванням можливої відмінності ефективних мас носія в ямі `m_w*` та у бар'єрі `m_b*` має вигляд:

```
- (ℏ² / 2) · (d / dz) [ (1 / m*(z)) · (dχ / dz) ] + V(z) · χ(z) = E_z · χ(z)
```

де `E_z` — енергія квантованого руху вздовж осі `z`. Вибір самоспряженої операторної форми `(d/dz)[(1/m*)(dχ/dz)]` є критично важливим, оскільки звичайний оператор `(1/m*)(d²χ/dz²)` при ступенчастій зміні маси `m*(z)` на межі матеріалів не є ермітовим і порушує закон збереження квантового потоку ймовірності.

### Зв'язані стани (0 < E_z < V_0): повне виведення трансцендентних рівнянь

Для зв'язаних станів (`0 < E_z < V_0`) розв'язок рівняння Шредінгера шукається окремо у трьох просторових областях:

1. **Центральна область (шар ями, |z| ≤ L_z / 2):**
   Потенціал `V(z) = 0`, і рівняння вироджується у гармонічний осцилятор з дійсним хвильовим вектором `k_w`:
   ```
   k_w = √(2 · m_w* · E_z) / ℏ
   ```
   Завдяки парній дзеркальній симетрії потенціалу `V(-z) = V(z)` відносно точки `z = 0`, усі власні функції `χ(z)` поділяються на строго парні `χ_even(z)` та непарні `χ_odd(z)`:
   ```
   χ_even(z) = A · cos(k_w · z)
   χ_odd(z)  = B · sin(k_w · z)
   ```

2. **Зовнішня область (правий бар'єр, z > L_z / 2):**
   Потенціал `V(z) = V_0 > E_z`. Розв'язок має експоненціально згасаючий характер із коефіцієнтом згасання `κ_b`:
   ```
   κ_b = √(2 · m_b* · (V_0 - E_z)) / ℏ
   χ(z) = C · exp(-κ_b · (z - L_z / 2))
   ```

3. **Зовнішня область (лівий бар'єр, z < -L_z / 2):**
   ```
   χ(z) = C · exp(κ_b · (z + L_z / 2))    (для парних станів)
   χ(z) = -C · exp(κ_b · (z + L_z / 2))   (для непарних станів)
   ```

#### Граничні умови Бен-Даніеля — Дюка

Для стикування розв'язків на гетеромежі `z = L_z / 2` вимагається виконання двох фізичних умов (граничні умови Бен-Даніеля — Дюка):
1. Неперервність самої хвильової функції `χ(z)` (відсутність розривів ймовірності):
   ```
   χ(L_z / 2 - 0) = χ(L_z / 2 + 0)
   ```
2. Неперервність нормованого густиною маси квантового потоку ймовірності `(1 / m*) · (dχ / dz)`:
   ```
   (1 / m_w*) · (dχ/dz)|_(z = L_z/2 - 0) = (1 / m_b*) · (dχ/dz)|_(z = L_z/2 + 0)
   ```

Застосуємо ці умови послідовно для парних та непарних станів.

#### А. Виведення для парних станів (χ = A cos(k_w z))

З підстави значення `z = L_z / 2` у граничні умови маємо систему двох алгебраїчних рівнянь відносно коефіцієнтів `A` та `C`:

```
[Умова 1]: A · cos(k_w · L_z / 2) = C
[Умова 2]: - (A · k_w / m_w*) · sin(k_w · L_z / 2) = - (C · κ_b / m_b*)
```

Поділивши рівняння [Умова 2] на рівняння [Умова 1] почленно, отримуємо точне трансцендентне рівняння для парних рівнів енергії:

```
(k_w / m_w*) · tan(k_w · L_z / 2) = (κ_b / m_b*)
```

або у формі згрупованого тангенса:

```
k_w · tan(k_w · L_z / 2) = (m_w* / m_b*) · κ_b
```

#### Б. Виведення для непарних станів (χ = B sin(k_w z))

Аналогічно підставляємо `χ = B sin(k_w z)` у граничні умови на межі `z = L_z / 2`:

```
[Умова 1]: B · sin(k_w · L_z / 2) = C
[Умова 2]: (B · k_w / m_w*) · cos(k_w · L_z / 2) = - (C · κ_b / m_b*)
```

Поділ рівняння [Умова 2] на [Умова 1] дає трансцендентне рівняння для непарних рівнів енергії:

```
(k_w / m_w*) · cot(k_w · L_z / 2) = - (κ_b / m_b*)
```

або у формі котангенса:

```
k_w · cot(k_w · L_z / 2) = - (m_w* / m_b*) · κ_b
```

### Виведення нормалізаційних коефіцієнтів та ефективної ширини ями

Нормувальна умова для огинаючої хвильової функції зв'язаного стану вимагає, щоб інтеграл від квадрата модуля хвильової функції по всьому простору дорівнював одиниці:

```
∫_{-∞}^{+∞} |χ(z)|² dz = 1
```

Обчислимо інтеграл для парного основного стану `χ_even(z)` (припускаючи для спрощення `m_w* = m_b* = m*`):

```
∫_{-L_z/2}^{+L_z/2} A² · cos²(k_w z) dz + 2 · ∫_{L_z/2}^{+∞} C² · exp(-2 κ_b (z - L_z/2)) dz = 1
```

Обчислюємо окремо два доданки:
1. Інтеграл усередині ями:
   ```
   A² · [ (L_z / 2) + (sin(k_w L_z) / (2 k_w)) ]
   ```
2. Інтеграл у бар'єрах:
   ```
   2 · C² · [ 1 / (2 κ_b) ] = C² / κ_b
   ```

Використовуючи граничне співвідношення `C = A cos(k_w L_z / 2)` та тригонометричну тотожність `cos²(x) = (1 + cos(2x))/2`, об'єднуємо обидва доданки:

```
A² · [ (L_z / 2) + (sin(k_w L_z) / (2 k_w)) + (cos²(k_w L_z / 2) / κ_b) ] = 1
```

Використовуючи трансцендентну умову `tan(k_w L_z / 2) = κ_b / k_w`, маємо:

```
A = √( 2 / (L_z + 2 / κ_b) ) = √( 2 / L_eff )
```

де `L_eff = L_z + 2 / κ_b` являє собою **ефективну ширину квантової ями**, яка враховує тунельне затікання хвильової функції під бар'єри на тунельну глибину `d_tun = 1 / κ_b` з кожного боку.

#### Просторова ймовірність локалізації частинки

Частка ймовірності знаходження електрона безпосередньо всередині квантової ями `P_well` обчислюється як:

```
P_well = ∫_{-L_z/2}^{+L_z/2} |χ(z)|² dz = (L_z + sin(k_w L_z)/k_w) / (L_z + 2 / κ_b)
```

А частка ймовірності проникнення у бар'єри становить `P_barrier = 1 - P_well = (2 / κ_b) / L_eff`. Чим меншою є глибина ями `V_0` або її ширина `L_z`, тим більша частка хвильової функції електрона виштовхується під бар'єри.

### Безрозмірний аналіз та графічне розв'язання

Для зручності чисельного та графічного розв'язання введемо безрозмірні змінні `ξ` та `η`:

```
ξ = (k_w · L_z) / 2 = (L_z / 2) · √(2 · m_w* · E_z) / ℏ
η = (κ_b · L_z) / 2 = (L_z / 2) · √(2 · m_b* · (V_0 - E_z)) / ℏ
```

Підносячи обидва вирази до квадрата та додаючи їх (припускаючи рівність мас `m_w* = m_b* = m*`), отримуємо рівняння кола в першому квадранті безрозмірної площини `(ξ, η)` з фіксованим радіусом `R`:

```
ξ² + η² = R² = (m* · V_0 · L_z²) / (2 · ℏ²)
```

Безрозмірний параметр `R` характеризує «потужність» ями: він прямо пропорційний ширині ями `L_z` та кореню з її глибини `√V_0`.

А трансцендентні рівняння набувають витонченого геометричного вигляду:

```
η = ξ · tan(ξ)    (для парних станів)
η = -ξ · cot(ξ)   (для непарних станів)
```

Точки перетину кола радіуса `R` з графіками функцій `ξ tan(ξ)` (перша, третя гілки) та `-ξ cot(ξ)` (друга, четверта гілки) дають точні значення безрозмірних енергій `ξ_n`, з яких обчислюються дискретні рівні `E_z,n = (2 ℏ² ξ_n²) / (m* L_z²)`.

Кількість дискретних зв'язаних станів у прямокутній ямі `N_bound` прямо визначається параметром радіуса `R`:

```
N_bound = 1 + floor( (2 · R) / π ) = 1 + floor( (L_z / π) · √(2 · m* · V_0) / ℏ )
```

#### Доведення існування принаймні одного зв'язаного стану

Унікальна математична властивість одновимірної симетричної ями полягає в тому, що **найнижчий парний стан `E_1` існує завжди**, незалежно від того, наскільки малою є глибина ями `V_0` чи її ширина `L_z`. 

Дійсно, при `ξ → 0` функція `η = ξ tan(ξ) ≈ ξ² → 0`. Коло радіуса `R` при будь-якому `R > 0` неодмінно перетинає криву `ξ tan(ξ)` у першому квадранті. 

Для гранично мілкої або вузької ями (`R << 1`) асимптотичне розв'язання шляхом розкладу `tan(ξ) ≈ ξ` дає:

```
ξ_1 ≈ R - R³ / 2   ⇒   E_1 ≈ V_0 - (m* · V_0² · L_z²) / (2 · ℏ²)
```

Тобто навіть при мізерній глибині ями в ній зберігається один зв'язаний рівень `E_1`, що лежить трохи нижче верхнього краю бар'єра `V_0`.

### Безконечно глибока яма (граничний випадок V_0 → ∞)

Коли глибина бар'єра `V_0` прямує до безкінечності (абсолютно жорсткі потенціальні стінки), хвильова функція не проникає під бар'єр (`κ_b → ∞`, `η → ∞`). Хвильова функція дорівнює нулю на стінках ями: `χ(±L_z/2) = 0`.

Трансцендентні умови спрощуються до вимоги `cos(k_w L_z / 2) = 0` (для парних станів) та `sin(k_w L_z / 2) = 0` (для непарних станів), що еквівалентно умові цілої кількості півхвиль на ширині ями:

```
k_w · L_z = n · π,    n = 1, 2, 3, ...
```

Звідси виводиться аналітична формула для дискретного енергетичного спектра нескінченно глибокої квантової ями:

```
E_z,n = (ℏ² · π² · n²) / (2 · m_w* · L_z²)
```

Аналіз формули розкриває фундаментальні квантово-розмірні закономірності:
- Енергія основного стану (енергія нульових коливань) `E_1 ∝ 1 / L_z²`.
- Відстань між сусідніми квантованими рівнями:
  ```
  ΔE = E_(n+1) - E_n = (ℏ² · π² / (2 · m_w* · L_z²)) · (2n + 1)
  ```
  зростає квадратично при зменшенні ширини ями `L_z`.
- Чим менша ефективна маса частинки `m_w*`, тим більшим є розщеплення енергетичних рівнів.

### Математична модель тунельно-зв'язаних подвійних ями (CDQW)

Коли дві однакові квантові ями шириною `L_z` розділені тонким бар'єром товщиною `d_b` (порядку 1–3 нм), хвильові функції ізольованих ями `χ_L(z)` та `χ_R(z)` починають тунельно перекриватися. 

У світлі теорії збурень (метод сильного зв'язку, LCAO) власні стани подвійної ями утворюють симетричну `χ_+` та антисиметричну `χ_-` комбінації:

```
χ_+(z) = (1 / √2) · [ χ_L(z) + χ_R(z) ]    (парний стан)
χ_-(z) = (1 / √2) · [ χ_L(z) - χ_R(z) ]    (непарний стан)
```

Енергетичний рівень одиночної ями `E_0` розщеплюється на тунельний дублет із виразом:

```
E_± = E_0 ∓ t_tun
```

де `t_tun` — тунельний матричний елемент зв'язку між ямами:

```
t_tun = ⟨χ_L | H | χ_R⟩ ≈ (2 ℏ² k_w² κ_b / (m* (k_w² + κ_b²))) · exp(-κ_b · d_b)
```

Величина тунельного розщеплення `ΔE_tun = E_- - E_+ = 2 t_tun` експоненціально спадає зі збільшенням товщини внутрішнього бар'єра `d_b`. Електрон, поміщений у початковий момент часу `t = 0` у ліву яму, здійснює тунельні осциляції квантового перетікання між ямами з частотою Рабі:

```
ω_tun = ΔE_tun / ℏ = (2 t_tun) / ℏ
```

Цей ефект слугує основою двокубітних квантових логічних гейтів на напівпровідникових квантових точках та каскадних модулів QCL-лазерів.

### Повне виведення двовимірної густини станів g_2D(E) та рівня Фермі

У квантовій ямі рух носіїв квантований уздовж осі `z` (дискретні рівні `E_n`), але залишається неперервним і вільним у площині `xy` з двовимірним хвильовим вектором `k_∥ = (k_x, k_y)`. 

Повна енергія електрона у підзоні `n` є сумою квантованої енергії обмеження та кінетичної енергії планарного руху:

```
E(n, k_∥) = E_n + (ℏ² · k_∥²) / (2 · m_w*)
```

де `k_∥² = k_x² + k_y²`.

#### Підрахунок кількості станів у k-просторі

Розглянемо квантову яму прямокутної форми з макроскопічною площею `S = L_x · L_y`. За періодичних граничних умов Борна — Кармана дозволені значення хвильових векторів у площині утворюють двовимірну ґратку з кроком `Δk_x = 2π / L_x` та `Δk_y = 2π / L_y`. Площа однієї квантової комірки в `k`-просторі дорівнює:

```
ΔS_k = (2π / L_x) · (2π / L_y) = (4π²) / S
```

Кількість орбітальних квантових станів у тонкому кільці `k`-простору від радіуса `k_∥` до `k_∥ + dk_∥` становить:

```
dN_k = (Площа кільця) / (Площа однієї комірки) = (2π · k_∥ · dk_∥) / ((4π²) / S) = (S / 2π) · k_∥ · dk_∥
```

З урахуванням двох можливих проекцій спіну електрона (`g_s = 2`), загальна кількість станів на одиницю площі `S` у підзоні `n` дорівнює:

```
dN_2D = 2 · (1 / S) · dN_k = 2 · (1 / 2π) · k_∥ · dk_∥ = (k_∥ · dk_∥) / π
```

#### Перехід від хвильового вектора до енергії

Диференціюючи вираз для параболічної спектральної дисперсії `E - E_n = (ℏ² k_∥²) / (2 m_w*)`, маємо:

```
dE = (ℏ² · k_∥ / m_w*) · dk_∥   ⇒   k_∥ · dk_∥ = (m_w* / ℏ²) · dE
```

Підставляючи вираз `k_∥ dk_∥` у формулу кількості станів `dN_2D`, отримуємо:

```
dN_2D = (m_w* / (π · ℏ²)) · dE
```

Густина станів на одиницю площі за визначенням є похідною `g_2D(E) = dN_2D / dE`:

```
g_2D^(n)(E) = m_w* / (π · ℏ²)
```

Отриманий вираз є фундаментальним: **двовимірна густина станів однієї підзони взагалі не залежить від енергії `E`** і являє собою сувору фізичну константу `m_w* / (π ℏ²)`.

Враховуючи, що кожна підзона `n` вступає в дію тільки при досягненні порогової енергії `E ≥ E_n`, підсумовуємо внески всіх підзон за допомогою функції ступеня Гевісайда `Θ(x)`:

```
g_2D(E) = (m_w* / (π · ℏ²)) · ∑_{n=1}^{∞} Θ(E - E_n)
```

де `Θ(E - E_n) = 1` при `E ≥ E_n`, та `Θ(E - E_n) = 0` при `E < E_n`.

#### Двовимірна концентрація електронів та рівень Фермі E_F

Інтегруючи густину станів `g_2D(E)` із функцією розподілу Фермі — Дірака `f(E) = 1 / (exp((E - E_F)/k_B T) + 1)`, отримуємо аналітичний зв'язок між двовимірною концентрацією електронів `n_2D` (на одиницю площі) та енергією Фермі `E_F`:

```
n_2D = ∫_{E_1}^{∞} g_2D(E) · f(E) dE = (m* · k_B T / (π · ℏ²)) · ln[ 1 + exp( (E_F - E_1) / (k_B T) ) ]
```

При абсолютному нуля температур (`T = 0 К`) рівень Фермі пов'язаний із двовимірною концентрацією строго лінійно:

```
E_F = E_1 + (π · ℏ² · n_2D) / m*
```

Порівняння розмірностей та форм густини станів для систем різної розмірності:

```
3D (Об'ємний кристал):  g_3D(E) = (1 / 2π²) · (2m* / ℏ³)^(3/2) · √(E - E_c)    [еВ⁻¹ · м⁻³]
2D (Квантова яма):      g_2D(E) = (m* / π ℏ²) · ∑ Θ(E - E_n)                  [еВ⁻¹ · м⁻²]
1D (Квантова нитка):    g_1D(E) = (√(2m*) / π ℏ) · ∑ (E - E_n,m)⁻¹/²          [еВ⁻¹ · м⁻¹]
0D (Квантова точка):    g_0D(E) = 2 · ∑ δ(E - E_i)                             [еВ⁻¹]
```

### Математичні правила відбору міжзонних оптичних переходів

Матричний елемент міжзонного дипольного оптичного переходу `M_cv` з поглинанням фотона поляризації `e` пропорційний добутку атомарного міжзонного матричного елемента імпульсу та інтеграла перекриття огинаючих хвильових функцій зони провідності `χ_c,n(z)` та валентної зони `χ_v,m(z)`:

```
M_cv = ⟨Ψ_c,n | e · p | Ψ_v,m⟩ ≈ ⟨u_c0 | e · p | u_v0⟩ · ∫_{-∞}^{+∞} χ_c,n*(z) · χ_v,m(z) dz
```

Для симетричної прямокутної ями огинаючі функції мають визначену парність (парні при непарному `n` або `m`, непарні при парному `n` або `m`). Оскільки інтеграл добутку двох функцій різної парності дорівнює нулю, отримуємо суворе **правило відбору за парністю**:

```
Δn = n - m = 0, ±2, ±4, ...    (переважають переходи з Δn = 0)
```

Для міжзонних переходів при `Δn = 0` інтеграл перекриття `I_nm = ∫ χ_c,n* χ_v,n dz ≈ 1`, що забезпечує гігантську ймовірність випромінювальної рекомбінації у квантових ямах.

### Виведення Штарківського зсуву (QCSE) у теорії збурень

При прикладанні зовнішнього однорідного електричного поля `F` вздовж осі `z` оператор збурення Гамільтоніана має вигляд `H' = e · F · z`.

Оцінимо зсув основного енергетичного рівня `E_1` нескінченно глибокої ями в другому порядку стаціонарної теорії збурень:

1. **Зсув першого порядку `ΔE_1^(1)`:**
   ```
   ΔE_1^(1) = ⟨χ_1 | e · F · z | χ_1⟩ = ∫_{-L_z/2}^{+L_z/2} e · F · z · (2/L_z) · cos²(π z / L_z) dz = 0
   ```
   Зсув першого порядку дорівнює нулю через підінтегральну непарність (добуток парного квадрата хвильової функції на непарне `z`).

2. **Зсув другого порядку `ΔE_1^(2)`:**
   ```
   ΔE_1^(2) = ∑_{m=2}^{∞} |⟨χ_m | e · F · z | χ_1⟩|² / (E_1 - E_m)
   ```

Обчислюючи матричні елементи `⟨χ_m | z | χ_1⟩` для непарних `m` (парні `m` дають нуль за симетрією):

```
⟨χ_m | z | χ_1⟩ = (8 · L_z / π²) · ( (-1)^((m+1)/2) · m ) / (m² - 1)²
```

Підставляючи значення `E_1 - E_m = (ℏ² π² / (2 m* L_z²)) (1 - m²)`, отримуємо точну аналітичну формулу для квантово-розмірного Штарківського зсуву:

```
ΔE_QCSE = - C_stark · (m* · e² · F² · L_z⁴) / ℏ²
```

де числова константа `C_stark = (1 / (24 π²)) · (15 / π² - 1) ≈ 0.0022`. 

Виводжуваний зсув є строго від'ємним (зсув рівня вниз) і демонструє сильну залежність від ширини ями `L_z⁴`, що пояснює, чому QCSE-модуляція є надзвичайно ефективною саме у квантових ямах помірної товщини (8–12 нм).

### Математична теорія 2D екситона та почотириократна енергія зв'язку

У квантовій ямі кулонівська взаємодія між електроном та діркою описується двовимірним рівнянням Шредінгера для відносного руху з приведеною масою `μ_ex = (m_e* · m_h*) / (m_e* + m_h*)`:

```
- (ℏ² / (2 μ_ex)) · [ (1/r) (∂/∂r) (r ∂ψ/∂r) ] - (e² / (4π ε ε_0 r)) · ψ(r) = E_ex · ψ(r)
```

У тривимірному об'ємному кристалі енергія зв'язку екситона Вапьє — Мотта становить:

```
E_B^3D = (R_Rydberg · μ_ex) / (m_0 · ε²) ≈ 4.2 меВ  (для GaAs)
```

У гранично тонкій двовимірній квантовій ямі розв'язок 2D рівняння Шредінгера дає серію спектральних рівнів:

```
E_ex,n^2D = - E_B^3D / (n - 1/2)²,    n = 1, 2, 3, ...
```

Для основного стану (`n = 1`) енергія зв'язку двовимірного екситона становить:

```
E_B^2D = E_B^3D / (1/2)² = 4 · E_B^3D ≈ 16.8 меВ
```

Математичне зростання енергії зв'язку екситона у 4 рази пояснюється тим, що стиснення огинаючої хвильової функції вздовж осі `z` зменшує ефективну кулонівську відстань між частинками, роблячи 2D екситони стійкими до фононного розпаду при `T = 300 К`.

### Розщеплення важких та легких дірок у валентній зоні

У 3D-кристалі арсеніду галію вершина валентної зони в точці `Γ` (`k = 0`) є чотирикратно виродженою по спіну та орбітальному моменту (`J = 3/2`). Вона складається з двох суміщених зон: зони важких дірок (*heavy holes*, `m_hh* ≈ 0.45 m_0`, `m_J = ±3/2`) та зони легких дірок (*light holes*, `m_lh* ≈ 0.082 m_0`, `m_J = ±1/2`).

Математичний опис валентної зони під дією конфайнменту вимагає застосування гамільтоніана Латтінджера — Кона `4×4`:

```
H_LK = | P + Q     L       M       0   |
       |  L*    P - Q      0       M   |
       |  M*      0     P - Q     -L   |
       |  0      M*      -L*    P + Q  |
```

де елементи гамільтоніана залежать від параметрів Латтінджера `γ_1, γ_2, γ_3`:

```
P = (ℏ² γ_1 / 2m_0) · (k_x² + k_y² + k_z²)
Q = (ℏ² γ_2 / 2m_0) · (k_x² + k_y² - 2 k_z²)
```

У квантовій ямі оператор `k_z` замінюється похідною `-i d/dz`. В результаті ефективна маса дірок для поздовжнього руху вздовж осі квантування `z` стає анізотропною:

```
m_hh,z* = m_0 / (γ_1 - 2 · γ_2) ≈ 0.45 · m_0
m_lh,z* = m_0 / (γ_1 + 2 · γ_2) ≈ 0.082 · m_0
```

Просторове обмеження вздовж осі `z` знімає виродження у точці `k = 0` завдяки відмінності ефективних мас. Енергія квантування дірок пропорційна `1 / m_z*`:

```
E_hh1 = (ℏ² · π²) / (2 · m_hh,z* · L_z²)
E_lh1 = (ℏ² · π²) / (2 · m_lh,z* · L_z²)
```

Оскільки `m_hh,z* > m_lh,z*`, перший рівень важких дірок `E_hh1` лежить ближче до дна потенціальної ями (тобто вище за енергією для дірок), ніж рівень легких дірок `E_lh1`.

У результаті валентна зона квантової ями розщеплюється у точці `k_∥ = 0` на дві незалежні системи підзон: підзону `HH1` та підзону `LH1`. Величина розщеплення `ΔE_hh-lh = E_lh1 - E_hh1` у вузьких ямах (`L_z ~ 8 нм`) досягає кількох десятків міліелектронвольт.

При цьому виникає цікавий інверсійний ефект для руху у площині ями `xy`: за рахунок змішування станів Латтінджера підзона `HH1` отримує легку планарну ефективну масу `m_hh,∥* = m_0 / (γ_1 + γ_2) ≈ 0.11 m_0`, тоді як підзона `LH1` отримує важку планарну масу `m_lh,∥* = m_0 / (γ_1 - γ_2) ≈ 0.20 m_0`. Це кардинально змінює оптичні правила відбору та коефіцієнт підсилення в лазерних гетероструктурах.
