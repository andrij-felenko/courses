# 🧮 Тензор деформацій, нотація Фойгта та матриця жорсткості суцільного середовища

У тривимірному деформівному суцільному середовищі зв'язок між механічними силами та внутрішніми зміщеннями точок описується тензорним математичним апаратом. Одновимірний закон Гука `σ = E · ε` є окремим проекційним випадком загального узагальненого співвідношення між 3x3 симетричним тензором напружень Коші `σ_ij` та 3x3 симетричним тензором деформацій `ε_ij`.

### 1. Кинематика суцільного середовища: тензор малих деформацій Коші

Розглянемо деформівне тіло. Нехай радіус-вектор матеріальної точки до деформації дорівнює `r = (x, y, z)`, а після деформації точка зміщується у нове положення `r' = (x + u_x, y + u_y, z + u_z)`. Вектор `u(x, y, z) = (u_x, u_y, u_z)` описує поле переміщень.

Якщо зміщення двох сусідніх точок різняться, у тілі виникає деформація. Відстань між двома нескінченно близькими точками до деформації дорівнює `ds² = dx² + dy² + dz²`, а після деформації `ds'² = dx'² + dy'² + dz'²`.

Різниця квадратів відстаней виражається через градієнти переміщення:

```
ds'² - ds² = 2 · ∑_i ∑_j ε_ij · dx_i · dx_j
```

При малих деформаціях і градієнтах (`|∂u_i / ∂x_j| << 1`) нехтують квадратичними доданками й отримують **тензор малих деформацій Коші** `ε_ij`:

```
ε_ij = 1/2 · (∂u_i / ∂x_j + ∂u_j / ∂x_i)     [симетризований градієнт переміщень]
```

У декартовій системі координат тензор деформацій подається у вигляді симетричної матриці 3x3:

```
[ ε_xx   ε_xy   ε_xz ]
[ ε_yx   ε_yy   ε_yz ]
[ ε_zx   ε_zy   ε_zz ]
```

Фізичний зміст компонент:
- Діагональні елементи `ε_xx = ∂u_x / ∂x`, `ε_yy = ∂u_y / ∂y`, `ε_zz = ∂u_z / ∂z` описують відносні лінійні подовження уздовж відповідних осей координат;
- Позадіагональні елементи `ε_xy = ε_yx = 1/2 · (∂u_x / ∂y + ∂u_y / ∂x)` описують чисто зсувні деформації (зміну прямого кута між гранями елементарного кубика).

#### Інваріанти тензора деформацій

При повороті системи координат компоненти тензора `ε_ij` змінюються за тензорними законами перетворення, але три головні комбінації залишаються незмінними. Вони називаються **інваріантами деформації**:

1. **Перший інваріант (след тензора):**
   ```
   I_1 = tr(ε) = ε_xx + ε_yy + ε_zz = div u = θ
   ```
   Перший інваріант дорівнює відносній зміні об'єму (дилатації) `θ = ΔV / V₀`.
2. **Другий інваріант:**
   ```
   I_2 = ε_xx·ε_yy + ε_yy·ε_zz + ε_zz·ε_xx - ε_xy² - ε_yz² - ε_zx²
   ```
3. **Третій інваріант (детермінант матриці):**
   ```
   I_3 = det(ε)
   ```

### 2. Динаміка середовища: тензор напружень Коші

Механічний стан усередині деформівного тіла характеризується поверхневими силами, що діють між суміжними мікрооб'ємами. Якщо уявити мисленнєвий переріз із вектором нормалі `n`, то сила `dF`, яка діє на елементарну площадку `dA`, пов'язана з нормаллю через тензор напружень Коші `σ_ij`:

```
dF_i = ∑_j σ_ij · n_j · dA
```

Матриця тензора напружень розміром 3x3 має вигляд:

```
[ σ_xx   σ_xy   σ_xz ]
[ σ_yx   σ_yy   σ_yz ]
[ σ_zx   σ_zy   σ_zz ]
```

Компоненти `σ_xx`, `σ_yy`, `σ_zz` являють собою нормальні напруження (розтяг чи стиск), а `σ_xy`, `σ_xz`, `σ_yz` — дотичні напруження (зсув). З моментної умови рівноваги елементарного об'єму (за відсутності розподілених внутрішніх підводимих моментів) випливає закон парності дотичних напружень:

```
σ_ij = σ_ji      [симетрія тензора напружень Коші]
```

### 3. Узагальнений закон Гука та термодинамічна симетрія тензора жорсткості

У найзагальнішому лінійному пружному середовищі кожна компонента тензора напружень є лінійною комбінацією усіх компонент тензора деформацій:

```
σ_ij = ∑_k ∑_l C_ijkl · ε_kl
```

Величина `C_ijkl` є тензором жорсткості 4-го рангу і початково містить 3⁴ = 81 компоненту.

Наявність симетрії у тензорах `σ_ij` та `ε_ij` суттєво зменшує кількість незалежних компонент:
1. Симетрія тензора напружень `σ_ij = σ_ji` дає:
   ```
   C_ijkl = C_jikl      [скорочує кількість незалежних компонент з 81 до 54]
   ```
2. Симетрія тензора деформацій `ε_kl = ε_lk` дає:
   ```
   C_ijkl = C_ijlk      [скорочує кількість незалежних компонент з 54 до 36]
   ```
3. **Майоранівська симетрія (існування пружного потенціалу).** Для ізотермічних або адіабатичних процесів деформування існує функція густини пружної потенціальної енергії `W(ε_ij)`. Напруження визначаються як перші частинні похідні від потенціалу:
   ```
   σ_ij = ∂W / ∂ε_ij
   ```
   Оскільки друга частинна похідна не залежить від порядку диференціювання:
   ```
   C_ijkl = ∂²W / (∂ε_ij ∂ε_kl) = ∂²W / (∂ε_kl ∂ε_ij) = C_klij
   ```
   Ця парна симетрія скорочує кількість незалежних пружних констант для найнижчої симетрії (триклінна кристалічна система) з 36 до **21**.

### 4. Нотація Фойгта: матричне згортання 6x6

Щоб уникнути роботи з 4-індексними тензорами, застосовують інженерну нотацію Фойгта *(англ. Voigt notation)*. Симетричні пари індексів `(i, j)` замінюють одним індексом `A ∈ {1, 2, 3, 4, 5, 6}`:

```
(xx) → 1,   (yy) → 2,   (zz) → 3
(yz, zy) → 4,   (xz, zx) → 5,   (xy, yx) → 6
```

Вектори напружень `σ` та деформацій `ε` у нотації Фойгта мають вигляд:

```
σ = [ σ_1, σ_2, σ_3, σ_4, σ_5, σ_6 ]ᵀ = [ σ_xx, σ_yy, σ_zz, σ_yz, σ_xz, σ_xy ]ᵀ

ε = [ ε_1, ε_2, ε_3, ε_4, ε_5, ε_6 ]ᵀ = [ ε_xx, ε_yy, ε_zz, 2·ε_yz, 2·ε_xz, 2·ε_xy ]ᵀ
```

Зверніть увагу: зсувні компоненти вектора Фойгта `ε_4 = γ_yz`, `ε_5 = γ_xz`, `ε_6 = γ_xy` дорівнюють подвійним тензорним деформаціям (так звані **інженерні деформації зсуву**).

У нотації Фойгта узагальнений закон Гука набирає вигляду системи 6 лінійних рівнянь:

```
σ_A = ∑_B C_AB · ε_B      [де A, B = 1..6]
```

Матриця жорсткості `C_AB` є симетричною матрицею 6x6 (`C_AB = C_BA`), яка містить 21 незалежний елемент. Обернене матричне рівняння виражається через матрицю податливості `S_AB = (C_AB)⁻¹`:

```
ε_A = ∑_B S_AB · σ_B
```

### 5. Матриця жорсткості для різних кристалічних симетрій

Залежно від симетрії кристалічної ґратки кількість незалежних елементів матриці `C_AB` суттєво зменшується:

1. **Триклінна система:** 21 незалежна константа (немає осей симетрії).
2. **Моноклінна система:** 13 незалежних констант (одна площина або вісь симетрії другого порядку).
3. **Орторомбічна система:** 9 незалежних констант (три взаємно перпендикулярні осі другого порядку).
4. **Гексагональна та тетрагональна системи:** 5–6 незалежних констант.
5. **Кубічна система (кремній Si, германій Ge, арсенід галію GaAs, мідь Cu, алюміній Al, залізо Fe):** **3 незалежні константи** (`C_11`, `C_12`, `C_44`).
   ```
   [ C_11  C_12  C_12    0     0     0   ]
   [ C_12  C_11  C_12    0     0     0   ]
   [ C_12  C_12  C_11    0     0     0   ]
   [  0     0     0     C_44   0     0   ]
   [  0     0     0      0    C_44   0   ]
   [  0     0     0      0     0    C_44 ]
   ```
6. **Ізотропне середовище:** **2 незалежні константи** (параметри Ляме `λ` та `μ`). Для ізотропного тіла додатково виконується умова ротаційної інваріантності: `C_44 = 1/2 · (C_11 - C_12)`.

### 6. Повна система перерахунку пружних констант ізотропного тіла

Для макроскопічно ізотропного середовища будь-яку пружну константу можна обчислити через довільну пару інших. Ниче наведено зведену таблицю фундаментальних співвідношень між інженерними константами (`E`, `ν`), параметрами Ляме (`λ`, `μ`) та об'ємним модулем `K`:

```
G = μ = C_44 = E / (2 · (1 + ν))                  [модуль зсуву]

K = (C_11 + 2·C_12) / 3 = E / (3 · (1 - 2·ν))      [модуль об'ємного стиску]

λ = C_12 = (E · ν) / ((1 + ν) · (1 - 2·ν))          [перший параметр Ляме]

C_11 = λ + 2·μ = (E · (1 - ν)) / ((1 + ν) · (1 - 2·ν)) [поздовжній модуль пружності]
```

Фізичний зміст параметрів Ляме:
- **Другий параметр Ляме `μ`** дорівнює модулю зсуву `G` і вимірює опір тіла зсувним деформаціям формозміни.
- **Перший параметр Ляме `λ`** описує пружну взаємодію між нормальними напруженнями у взаємно перпендикулярних напрямках через бічний ефект Пуассона.

Обернені вирази для модуля Юнга `E` та коефіцієнта Пуассона `ν`:

```
E = μ · (3·λ + 2·μ) / (λ + μ) = (9 · K · G) / (3·K + G)

ν = λ / (2 · (λ + μ)) = (3·K - 2·G) / (2 · (3·K + G))
```

### 7. Енергетичний баланс та питома пружна потенціальна енергія

Густина потенціальної енергії пружної деформації `w` (Дж/м³) записується як квадратична форма від компонент деформації:

```
w = 1/2 · ∑_A σ_A · ε_A 
  = 1/2 · ∑_A ∑_B C_AB · ε_A · ε_B
```

Для ізотропного тіла в термінах інваріантів тензора деформацій (тензорної дилатації `θ = ε_xx + ε_yy + ε_zz` та девіатора деформацій `e_ij = ε_ij - 1/3 · θ · δ_ij`) густина енергії розпадається на суму енергії зміни об'єму та енергії зміни форми:

```
w = w_об'єм + w_форма
  = 1/2 · K · θ² + μ · ∑_i ∑_j e_ij · e_ij
```

Цей поділ має вирішальне значення в критеріях пластичності (наприклад, у критерії Губера-Мізеса-Генкі), де пластична плинність металу визначається виключно енергією формозміни `w_форма`, а всебічний об'ємний тиск `w_об'єм` не викликає пластичних зсувів у кристалічній ґратці.
