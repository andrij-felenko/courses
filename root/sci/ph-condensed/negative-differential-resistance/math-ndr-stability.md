# 🧮 Математичний аналіз стійкості та динаміки від'ємного опору

Математичний опис кінетики та стійкості кіл із від'ємним диференційним опором (NDR) ґрунтується на аналізі диференціальних рівнянь другого порядку, матричного Якобіана у точках рівноваги та методах асимптотичного розкладу нелінійних коливань. Оскільки стаціонарний опір `R = V/I` завжди залишається додатним, від'ємним є лише локальний похідний коефіцієнт (диференційна провідність або диференційний опір).

Ця вставка містить строгий математичний аналіз малого сигналу, умови виникнення біфуркації Андронова-Гопфа, розрахунок граничних циклів методом Крилова-Боголюбова та аналіз бістабільності у фазовому просторі.

## 1. Малосигнальна еквівалентна схема та характеристичне рівняння

Розглянемо двополюсник із нелінійною вольт-амперною характеристикою `I = f(V)`. У точці статичного зсуву `(V₀, I₀)` малий сигнал описується диференційною провідністю:

```
g_d = dI / dV |_(V=V₀)
r_d = 1 / g_d = dV / dI |_(V=V₀)
```

Для елемента з від'ємним диференційним опором `g_d < 0` або `r_d < 0`. Позначимо модуль від'ємного опору як `R_n = |r_d| = 1 / |g_d|`.

Реальний фізичний прилад із від'ємним опором завжди володіє паразитною ємністю `C` (ємність p-n переходу або міжелектродна ємність) та паразитною індуктивністю виводів `L`.

### Критерій стійкості N-типу (VCNDR)

Для приладу N-типу (вольт-амперна характеристика є однозначною функцією напруги `I = f(V)`) еквівалентна малосигнальна схема складається з паралельного з'єднання від'ємної провідності `-|g_d|` та ємності `C`, які підключені до зовнішнього кола з опором навантаження `R_L` та індуктивністю `L`.

Диференціальне рівняння для відхилення напруги `v(t) = V(t) - V₀` від точки рівноваги має вигляд:

```
C · (dv / dt) + (1 / R_L - |g_d|) · v + (1 / L) · ∫ v dt = 0
```

Диференціюючи по часу `t`, отримуємо однорідне диференціальне рівняння другого порядку:

```
d²v / dt² + (1 / (R_L·C) - |g_d| / C) · (dv / dt) + (1 / (L·C)) · v = 0
```

Характеристичне рівняння системи має вигляд:

```
s² + 2·α·s + ω₀² = 0
```

де коефіцієнт згасання `α` та власна частота `ω₀` визначаються виразами:

```
α = 1 / 2 · (1 / (R_L·C) - |g_d| / C) = 1 / (2·C) · (1 / R_L - 1 / R_n)
ω₀² = 1 / (L·C)
```

Корені характеристичного рівняння (полюси системи):

```
s₁,₂ = -α ± √(α² - ω₀²)
```

Аналіз стійкості на комплексній площині `s = σ + j·ω` дає три методично важливих режими:

1. **Абсолютна стійкість (стаціонарний режим підсилення або очікування):**
   Система є асимптотично стійкою, якщо дісна частина обох коренів від'ємна (`Re(s₁,₂) < 0`), тобто `α > 0`.
   Це виконується за умови:

```
1 / R_L > 1 / R_n  ⇒  R_L < R_n
```

   **Висновок:** Прилад N-типу є стійким у точці спокою лише тоді, коли внутрішній опір джерела живлення/навантаження `R_L` строго менший за модуль від'ємного опору `R_n = |r_d|` (малоомне джерело напруги).

2. **Границя генерації (незатухаючі гармонічні коливання):**
   При `α = 0` дісна частина коренів дорівнює нулю (`Re(s) = 0`), а полюси лежать суто на уявній осі `s = ±j·ω₀`:

```
R_L = R_n = |r_d|
```

   У цьому стані від'ємний опір приладу повністю компенсує позитивний опір навантаження, і в контурі виникають незатухані синусоїдальні коливання з частотою `ω₀ = 1 / √(L·C)`.

3. **Нестійкість та автоколивання (зростання амплітуди):**
   Якщо `α < 0` (`R_L > R_n`), дісна частина коренів стає додатною (`Re(s) > 0`). Будь-яке мікроскопічне флуктуаційне відхилення напруги зростає за експоненційним законом:

```
v(t) = V_amp · e^(|α|·t) · cos(ω·t)
```

### Критерій стійкості S-типу (CCNDR)

Для приладу S-типу (характеристика є однозначною функцією струму `V = f(I)`) еквівалентна схема являє собою послідовне з'єднання від'ємного опору `-R_n = -|r_d|`, індуктивності `L` та зовнішнього навантаження `R_L` з паралельною ємністю `C`.

Характеристичне рівняння для відхилення струму `i(t)` має вигляд:

```
s² + ( (R_L - R_n) / L ) · s + 1 / (L·C) = 0
```

Коефіцієнт згасання дорівнює:

```
α_S = (R_L - R_n) / (2·L)
```

Система є стійкою у точці рівноваги (`α_S > 0`), якщо:

```
R_L > R_n = |r_d|
```

**Висновок:** Прилад S-типу є стійким лише під час живлення від високоомного джерела струму (`R_L > |r_d|`). Спроба заживити S-прилад від низькоомного джерела напруги (`R_L < |r_d|`) негайно призводить до стрибкоподібного перемикання або релаксаційного пробою.

## 2. Матричний аналіз Якобіана та біфуркація Андронова-Гопфа

Для повного нелінійного кола другого порядку з динамічними змінними стану `X = [v, i_L]ᵀ` система рівнянь має вигляд:

```
dv / dt = (i_L - f(v)) / C
di_L / dt = (V_CC - v - R_L · i_L) / L
```

Матриця Якобі `J` у точці рівноваги `(V₀, I₀)` обчислюється як матриця часткових похідних правих частин:

```
J = [ -g_d / C,      1 / C    ]
    [ -1 / L,     -R_L / L   ]
```

Траєкторії у фазовому просторі визначаються слідом (Trace) та визначником (Determinant) матриці Якобі:

```
Tr(J) = -g_d / C - R_L / L
Det(J) = (g_d · R_L + 1) / (L · C)
```

За критерієм Рауса-Гурвіца точка рівноваги є асимптотично стійкою тоді і тільки тоді, коли виконуються дві умови:

```
Tr(J) < 0   та   Det(J) > 0
```

Розглянемо випадок елемента N-типу (`g_d = -|g_d| < 0`):

1. **Слід матриці:** `Tr(J) = |g_d| / C - R_L / L`. Слід є від'ємним (`Tr(J) < 0`), якщо `R_L / L > |g_d| / C`, тобто `R_L > L · |g_d| / C`.
2. **Визначник матриці:** `Det(J) = (1 - |g_d| · R_L) / (L · C)`. Визначник є додатним (`Det(J) > 0`), якщо `1 - |g_d| · R_L > 0`, що еквівалентно `R_L < 1 / |g_d| = R_n`.

При зміні параметра `R_L` пара власних значень матриці Якобі `λ₁,₂` перетинає уявну вісь комплексної площини. У точці, де `Tr(J) = 0` (`R_L = L · |g_d| / C`), виникає **м'яка біфуркація Андронова-Гопфа** (Hopf bifurcation): точка рівноваги втрачає стійкість, і з неї народжується стійкий граничний цикл малих коливань.

## 3. Нелінійна динаміка та модель Ван дер Поля

Зростання амплітуди коливань при `R_L > R_n` не може тривати нескінченно, оскільки від'ємний опір приладу є нелінійним і зменшується при великих амплітудах напруги.

Апроксимуємо вольт-амперну характеристику N-елемента кубічним поліномом відносно робочої точки `V₀`:

```
I(v) = -g₁ · v + g₃ · v³
```

де `g₁ = 1 / R_n > 0` — малосигнальна від'ємна провідність, а `g₃ > 0` — коефіцієнт нелінійного обмеження.

Підставляючи кубічну апроксимацію у диференціальне рівняння LC-контуру, отримуємо класичне **рівняння Ван дер Поля**:

```
d²v / dt² - ((g₁ - 1/R_L) / C) · (1 - (3·g₃ / (g₁ - 1/R_L)) · v²) · (dv / dt) + ω₀² · v = 0
```

Ввівши безрозмірний параметр нелінійності `ε` та нормований час `τ = ω₀ · t`:

```
ε = (g₁ - 1/R_L) / (ω₀ · C)
```

рівняння набуває стандартного вигляду:

```
d²x / dτ² - ε · (1 - x²) · (dx / dτ) + x = 0
```

### Стаціонарна амплітуда граничного циклу

Методом усереднення Крилова-Боголюбова знайдемо стаціонарну амплітуду коливань `A_st`. Шукаємо розв'язок у вигляді `x(τ) = A(τ) · cos(τ + φ)`.

Диференціальне рівняння для повільнозмінної амплітуди `A(τ)` має вигляд:

```
dA / dτ = (ε / 2) · A · (1 - A² / 4)
```

У стаціонарному режимі `dA / dτ = 0`, що дає два розв'язки:
1. `A = 0` — нестійка точка тривіального спокою.
2. `A_st = 2` — стійкий граничний цикл.

Переходячи до розмірних фізичних змінних, отримуємо стаціонарну амплітуду напруги на автогенераторі:

```
V_max = 2 · √( (g₁ - 1/R_L) / (3 · g₃) ) = 2 · √( (1/R_n - 1/R_L) / (3 · g₃) )
```

Ця формула доводить, що стаціонарна амплітуда коливань визначається балансом між малим сигналом від'ємного опору та нелінійним коефіцієнтом насичення приладу.

## 4. Фазовий портрет та бістабільні переключення

При підключенні навантаження `R_L`, що перетинає N-подібну характеристику у трьох точках `A, B, C`, динаміка системи описується фазовою площиною `(v, dv/dt)` або `(v, i)`.

Аналіз матриці Якобі у трьох точках перетину:

1. **Точка A (низька напруга, великий струм):** `g_d(V_A) > 0`. Власні значення має від'ємні дійсні частини `Re(λ) < 0`. Траєкторії є стійкими вузлами або фокусами. Система стійко перебуває в стані «УВІМКНЕНО».
2. **Точка B (висока напруга, малий струм):** `g_d(V_B) > 0`. Власні значення має від'ємні дійсні частини `Re(λ) < 0`. Траєкторії є стійкими вузлами або фокусами. Система стійко перебуває в стані «ВИМКНЕНО».
3. **Точка C (проміжна зона NDR):** `g_d(V_C) = -|g_d| < 0` і `|g_d| > 1/R_L`. Визначник матриці Якобі є від'ємним (`Det(J) < 0`), що відповідає **сідловій точці** (нестійка рівновага). Будь-яке найменше збурення відштовхує фазову траєкторію від точки C напряму до одного зі стійких станів A або B.

Сепаратриса сідлової точки C ділить фазову площину на дві області притягання (Attraction Basins): фазові траєкторії, що стартують ліворуч від сепаратриси, збігаються до стану A, а ті, що стартують праворуч, — до стану B. Ця математична топологія є основою роботи швидкісних тригерів, тригерів Шмітта та осередків оперативної пам'яті на тунельних діодах.
