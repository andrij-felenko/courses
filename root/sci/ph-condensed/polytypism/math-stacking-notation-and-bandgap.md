# 🧮 Математика послідовностей укладання та зонної структури

Математичний опис політипізму спирається на дискретну геометрію зсувів щільно упакованих двовимірних шарів у тривимірному просторі та розрахунок структурного фактора рентгенівського розсіювання, який дає змогу однозначно ідентифікувати послідовність укладання. Зміна періодичності та внутрішньої симетрії елементарної комірки уздовж осі c описується зонною теорією як ефективна модуляція кристаллографічного потенціалу, що визначає квантовомеханічну залежність ширини забороненої зони та анізотропії електронних властивостей.

## Геометрія щільного укладання та системи координат

Будь-який політип, утворений двовимірними шарами з гексагональною симетрією (наприклад, площини атомів Кремнію та Вуглецю в SiC або Сірки та Цинку в ZnS), складається з однакових атомних сіток. Атоми в межах одного шару розміщені у вузлах плоскої гексагональної ґратки. Сусідній шар може займати одне з трьох диз'юнктних положень у площині `(0001)`, які у відносних координатах гексагональної комірки `(x, y)` дорівнюють:

```
A = (0, 0)          [базове положення шару]
B = (2/3, 1/3)      [зсув на вектор t1 = 2/3·a1 + 1/3·a2]
C = (1/3, 2/3)      [зсув на вектор t2 = 1/3·a1 + 2/3·a2]
```

Для щільного укладання сферичних або тетраедричних атомних блоків діє географічне правило заборони: два суміжні шари не можуть мати одинакове положення (тобто послідовності AA, BB або CC заборонені через просторове перекриття атомних радіусів). Будь-яка допустима послідовність є ланцюжком символів з алфавіту `{A, B, C}` без двох однакових букв підряд.

Вектор переходу між сусідніми шарами `n` та `n+1` описується циклічною орієнтацією:
- Перехід за годинниковою стрілкою: `A → B → C → A` позначається як циклічний плюс `+1` (або `+`).
- Перехід проти годинникової стрілки: `A → C → B → A` позначається як циклічний мінус `-1` (або `-`).

Математично переходи між позиціями описуються операціями в кільці лишків за модулем 3 (`ℤ₃`):

```
Позиція A = 0 mod 3
Позиція B = 1 mod 3
Позиція C = 2 mod 3

Перехід (+) : pos_{j+1} = (pos_j + 1) mod 3
Перехід (-) : pos_{j+1} = (pos_j - 1) mod 3
```

Це дозволяє представлення будь-якої послідовності шарів у вигляді ряду цілих чисел `S = [s_0, s_1, ..., s_{N-1}]`, де `s_j ∈ {0, 1, 2}`.

## Системи позначень та алгоритми взаємоперетворення

Для формалізації політипних послідовностей використовують три основні математичні системи: номенклатуру Жданова, номенклатуру Ягодзінського та номенклатуру Рамсделла.

### 1. Символи Жданова `(n1, n2, n3, ...)`
Символ Жданова записує кількість послідовних позитивних зсувів `+`, за якими слідує кількість послідовних негативних зсувів `-`.
Наприклад, для 4H-SiC з послідовністю `A B C B A B ...`:
```
Зсуви: A → B (+), B → C (+), C → B (-), B → A (-)
Послідовність знаків: + + - - + + - - ...
Символ Жданова: (2, 2)
```

Для 6H-SiC з послідовністю `A B C A C B A ...`:
```
Зсуви: A → B (+), B → C (+), C → A (+), A → C (-), C → B (-), B → A (-)
Послідовність знаків: + + + - - - ...
Символ Жданова: (3, 3)
```

Для 15R-SiC з послідовністю `A B C B A C A B A C B C A C B ...`:
```
Зсуви: A→B(+), B→C(+), C→B(-), B→A(-), A→C(-), C→A(+), A→B(+), B→A(-), A→C(-), C→B(-)...
Послідовність знаків: ++--- ++--- ++---
Символ Жданова: (3, 2)₃ або (3, 2, 3, 2, 3, 2)
```

### 2. Позначення Ягодзінського `(h / k)`
Символіка Ягодзінського визначає локальне кристаллографічне оточення кожного окремого шару `i` за його двома найближчими сусідами `i-1` та `i+1`:
- Якщо шар `i` знаходиться між двома однаково орієнтованими шарами (тобто `[i-1] == [i+1]`, наприклад `A B A`), шар `i` має гексагональне оточення та позначається як `h`.
- Якщо шар `i` знаходиться між двома різними шарами (тобто `[i-1] != [i+1]`, наприклад `A B C`), шар `i` має кубічне оточення та позначається як `k`.

Формальний алгоритм визначення символу Ягодзінського для шару `j` за знаками зсувів Жданова `σ_j ∈ {+1, -1}` має вигляд:

```
Якщо σ_{j-1} == σ_j     ⇒  шар j позначається як k (кубічний перехід)
Якщо σ_{j-1} != σ_j     ⇒  шар j позначається як h (гексагональний поворот)
```

Математично ступінь гексагональності `α_h` політипу з періодом `N` розраховується як відношення кількості гексагональних шарів `N_h` до загальної кількості шарів у періоді комірки:

```
α_h = (N_h / (N_h + N_k)) · 100%
```

Для основних політипів карбіду кремнію значення `α_h` складають:
```
3C-SiC (k k k)     : N_h = 0, N_k = 3  ⇒  α_h = 0%
8H-SiC (4, 4)      : N_h = 2, N_k = 6  ⇒  α_h = 25%
6H-SiC (3, 3)      : N_h = 2, N_k = 4  ⇒  α_h = 33.3%
15R-SiC (3, 2)3    : N_h = 6, N_k = 9  ⇒  α_h = 40%
4H-SiC (2, 2)      : N_h = 2, N_k = 2  ⇒  α_h = 50%
2H-SiC (h h)       : N_h = 2, N_k = 0  ⇒  α_h = 100%
```

## Структурний фактор рентгенівського розсіювання `F(h,k,l)`

Для ідентифікації політипів за допомогою рентгеноструктурного аналізу обчислюють інтенсивність розсіювання уздовж вузлів оберненої ґратки. Оскільки всі шари політипу однакові в площині `(xy)`, рефлекси з індексами `h - k = 3m` (де `m` — ціле число) не несуть інформації про послідовність укладання.

Політипна послідовність повністю модулює інтенсивність дифракції уздовж стержнів оберненого простору з індексами `h - k ≠ 3m` (зокрема уздовж стержня `10L`).

Структурний амплітудний фактор `F(1, 0, L)` для елементарної комірки з `N` шарів задається виразом:

```
F(1, 0, L) = F_layer · ∑_{j=0}^{N-1} exp[2πi · (x_j + L·j/N)]
```

де `F_layer` — формовий фактор одного двовимірного шару (включаючи атомні фактори Si та C), `x_j` — координата зсуву `j`-го шару:
```
x_j = 0         якщо шар j має тип A
x_j = 2/3       якщо шар j має тип B
x_j = 1/3       якщо шар j має тип C
```

Розкриємо експоненційний сумний вираз для обчислення інтенсивності `I(1, 0, L) = |F(1, 0, L)|²`:

```
S(L) = ∑_{j=0}^{N-1} exp[2πi · (x_j + L·j/N)]
```

Розглянемо виведення фазового сумування для конкретних політипів.

### Виведення для політипу 3C-SiC (N = 3)
Послідовність укладання `A(0), B(2/3), C(1/3)`.
```
S_3C(L) = exp[2πi·(0 + 0)] + exp[2πi·(2/3 + L/3)] + exp[2πi·(1/3 + 2L/3)]
        = 1 + exp[2πi·(2 + L)/3] + exp[2πi·(1 + 2L)/3]
```
При `L = 1`:
```
S_3C(1) = 1 + exp[2πi·3/3] + exp[2πi·3/3]
        = 1 + exp[2πi] + exp[2πi]
        = 1 + 1 + 1 = 3
```
Отже, інтенсивність `|S(1)|² = 9`. Для нецілочисельних `L ≠ 1, 4, 7` сума `S_3C(L) = 0`.

### Виведення для политипу 4H-SiC (N = 4)
Послідовність укладання `A(0), B(2/3), C(1/3), B(2/3)`.
```
S_4H(L) = exp[2πi·(0 + 0)] + exp[2πi·(2/3 + L/4)] + exp[2πi·(1/3 + 2L/4)] + exp[2πi·(2/3 + 3L/4)]
```
При `L = 1`:
```
S_4H(1) = 1 + exp[2πi·(2/3 + 1/4)] + exp[2πi·(1/3 + 2/4)] + exp[2πi·(2/3 + 3/4)]
        = 1 + exp[2πi·11/12] + exp[2πi·10/12] + exp[2πi·17/12]
```
Модуль квадрата цієї суми дорівнює `|S_4H(1)|² = 12.0`, що створює характеристичний дифракційний пік 4H при `L = 1.0, 0.75, 1.25`.

Для політипів 3C, 4H та 6H піки інтенсивності `|S(L)|²` спостерігаються при строго визначених значеннях дробового індексу `L`:
- Для 3C (кубічний, N=3): дифрагує лише при `L = 1/3, 4/3, 7/3, ...` (що відповідає вузлам кубічної FCC-ґратки в гексагональних координатах).
- Для 4H (гексагональний, N=4): вузли інтенсивності розташовані при `L = 1/4, 2/4, 3/4, 5/4, ...`.
- Для 6H (гексагональний, N=6): гострі піки інтенсивності знаходяться при `L = 1/6, 2/6, 3/6, 4/6, 5/6, ...`.

Таким чином, відстань між сусідніми дифракційними максимумами уздовж стержня `10L` в оберненому просторі дорівнює `ΔL = 1/N`, що дає прямий математичний метод визначення періоду укладання `N` з експериментальних дифрактограм.

## Залежність ширини забороненої зони від гексагональності

Електронні властивості політипів карбіду кремнію виказують систематичну залежність від ступеня гексагональності `α_h`. Періодична зміна потенціалу уздовж осі c призводить до розщеплення енергетичних зон та зміни положення абсолютного мінімуму зони провідності в зоні Бріллюена.

Залежність ширини забороненої зони `E_g` при температурі `T = 300 K` описується емпіричним співвідношенням Ву та Гейнса з високою точністю:

```
E_g(α_h) = E_g(3C) + ΔE · α_h
```

Підставляючи експериментальні значення для 3C-SiC (`2.36 еВ`) та 2H-SiC (`3.33 еВ`), отримуємо розрахунок:

```
ΔE = E_g(2H) - E_g(3C)
   = 3.33 еВ - 2.36 еВ
   = 0.97 еВ

E_g(α_h) = 2.36 + 0.97 · (α_h / 100%)    [еВ]
```

Порівняння емпіричного розрахунку з експериментом:
```
Політип   α_h (%)    E_g розраховане (еВ)   E_g експеримент (еВ)
---------------------------------------------------------------
3C-SiC     0.0              2.36                   2.36
8H-SiC    25.0              2.60                   2.80
6H-SiC    33.3              2.68                   3.02
15R-SiC   40.0              2.75                   2.98
4H-SiC    50.0              2.85                   3.26
2H-SiC   100.0              3.33                   3.33
```

Відхилення від чисто лінійної залежності пояснюється нелокальним впливом кристалічного поля та спін-орбітальної взаємодії у гексагональних політипах, що підтверджується першопринципними розрахунками зонної структури за методом функціонала густини (DFT).
