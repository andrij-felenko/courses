# 🧮 Математичний апарат магнітострикції та тензори зв'язку

Математичний опис магнітострикції вимагає сумісного розрахунку механічного стану пружного тіла (тензора деформацій та напружень) і магнітного стану (векторів намагніченості, індукції та напруженості поля). Завдяки феноменологічній теорії магнітоеластичності деформація зв'язується з магнітними векторами через тензори вищих рангів, термодинамічні потенціали та варіацію вільної енергії кристала.

## Тензор деформації та напрямні косинуси намагніченості

Механічний стан суцільного середовища описується симетричним тензором деформації 2-го рангу `S[ij]`, елементи якого виражаються через градієнти вектора зміщення `u = (u[1], u[2], u[3])`:

```
S[ij] = (1/2) · (∂u[i]/∂x[j] + ∂u[j]/∂x[i])      [визначення тензора малих деформацій]
```

Орієнтація вектора намагніченості `M` відносно кристалографічних осей `x[1], x[2], x[3]` задається вектором напрямних косинусів `α = (α[1], α[2], α[3])`:

```
α[1] = M[x] / M[s]
α[2] = M[y] / M[s]
α[3] = M[z] / M[s]
α[1]² + α[2]² + α[3]² = 1                        [умова нормування вектора намагніченості]
```

де `M[s]` — модуль вектора намагніченості насичення.

## Термодинамічний потенціал та магнітоеластична енергія

У термодинаміці феромагнітного середовища використовують термодинамічний потенціал Гіббса `G(T, H)`, за допомогою якого можна вивести як прямий, так і зворотний ефекти. Магнітоеластична густина енергії `E[me]` є частиною вільної енергії, яка залежить від одночасного вибору деформацій `S[ij]` та напрямних косинусів `α[i]`.

Для кристалічної ґратки кубічної симетрії (наприклад, заліза, нікелю або Terfenol-D) магнітоеластичну густину енергії у найнижчому порядку за деформаціями записують через дві константи магнітоеластичного зв'язку `B[1]` та `B[2]`:

```
E[me] = B[1] · (α[1]²·S[11] + α[2]²·S[22] + α[3]²·S[33]) + 2·B[2] · (α[1]·α[2]·S[12] + α[2]·α[3]·S[23] + α[3]·α[1]·S[31])
```

Густина пружної енергії `E[elastic]` для кубічного кристала виражається через модулі пружності `C[11]`, `C[12]`, `C[44]`:

```
E[elastic] = (1/2)·C[11]·(S[11]² + S[22]² + S[33]²) + C[12]·(S[11]·S[22] + S[22]·S[33] + S[33]·S[11]) + 2·C[44]·(S[12]² + S[23]² + S[31]²)
```

Мінімізуючи повну енергію `E = E[me] + E[elastic]` за компонентами деформації `S[ij]` (умова `∂E / ∂S[ij] = 0`), отримуємо рівноважні спонтанні деформації монокристала при даному напрямку вектора намагніченості:

```
S[ii] = - B[1] / (C[11] - C[12]) · (α[i]² - 1/3)        [поздовжня самодеформація вздовж осі i]
S[ij] = - B[2] / (2 · C[44]) · α[i] · α[j]              [зсувна самодеформація при i ≠ j]
```

## Магнітострикційні константи `λ[100]` та `λ[111]`

У монокристалах деформація залежить від того, вздовж якої кристалографічної осі орієнтоване магнітне поле й у якому напрямку вимірюється деформація. Відносне видовження `λ` у напрямку з напрямними косинусами `β = (β[1], β[2], β[3])` виражається формулою Бекерта-Дорінґа:

```
λ = (3/2)·λ[100]·(α[1]²·β[1]² + α[2]²·β[2]² + α[3]²·β[3]² - 1/3) + 3·λ[111]·(α[1]·α[2]·β[1]·β[2] + α[2]·α[3]·β[2]·β[3] + α[3]·α[1]·β[3]·β[1])
```

де:
- `λ[100]` — константа магнітострикції при намагнічуванні та вимірюванні вздовж ребра куба `[100]`;
- `λ[111]` — константа магнітострикції при намагнічуванні та вимірюванні вздовж головної діагоналі куба `[111]`.

Зв'язок феноменологічних констант `λ[100]`, `λ[111]` із мікроскопічними коефіцієнтами `B[1]`, `B[2]` має вигляд:

```
λ[100] = - (2/3) · B[1] / (C[11] - C[12])       [деформація вздовж осі легкого намагнічування 100]
λ[111] = - (1/3) · B[2] / C[44]                 [деформація вздовж осі 111]
```

## Вивід кутової залежності для ізотропного полікристала

У полікристалічному матеріалі хаотична орієнтація кристалітів усереднює анізотропні властивості. Константа насичення полікристала `λ[s]` виражається через константи монокристала як:

```
λ[s] = (2/5) · λ[100] + (3/5) · λ[111]           [усереднення за всіма орієнтаціями кристалітів]
```

Розглянемо полікристалічний стрижень, у якому вектор намагніченості повертається на кут `θ` відносно поздовжньої осі.

1. У нерозмагніченому стані домени розподілені ізотропно по всіх напрямках, тож середня проєкція дорівнює:

```
⟨cos²(θ)⟩ = ∫₀^(π/2) cos²(θ) · sin(θ) dθ = 1/3   [середній квадрат косинуса у 3D розмагніченому стані]
```

2. При обертанні вектора намагніченості під дією зовнішнього поля під кутом `θ` до поздовжньої осі виникає поздовжня деформація:

```
λ(θ) = (3/2) · λ[s] · (cos²(θ) - 1/3)           [формула Джоулевої деформації під кутом θ]
```

Перевірка крайових випадків:
- При `θ = 0` (поведінка вздовж поля): `λ(0) = (3/2) · λ[s] · (1 - 1/3) = λ[s]` (максимальне видовження).
- При `θ = π/2` (поперечний напрямок): `λ(π/2) = (3/2) · λ[s] · (0 - 1/3) = - (1/2) · λ[s]` (стискання вдвічі менше за поздовжнє видовження).

Сума деформацій за трьома ортогональними осями дає зміну об'єму при Джоулевій магнітострикції:

```
ΔV / V = λ[x] + λ[y] + λ[z]
       = λ[s] - (1/2)·λ[s] - (1/2)·λ[s]
       = 0                                      [об'єм залишається сталим]
```

Це доводить, що Джоулева магнітострикція зберігає об'єм тіла, змінюючи лише його геометрію.

## Ефект змінення модуля пружності (ΔE-ефект)

Завдяки зворотному ефекту Вілларі при прикладанні механічного напруження `T` відбувається додаткова переорієнтація доменів, яка створює додаткову деформацію магнітострикційного походження `S[me]`. Внаслідок цього ефективний модуль Юнга матеріалу `E` змінюється при намагнічуванні.

Це явище називається **ΔE-ефектом** (*ΔE effect*). Відносна зміна модуля Юнга між намагніченим до насичення станом `E[s]` та розмагніченим станом `E[0]` визначається формулою:

```
ΔE / E[0] = (E[s] - E[0]) / E[0] = (9/5) · μ[0] · μ[i] · λ[s]² · E[s] / M[s]²
```

де `μ[i]` — початкова магнітна проникність, `M[s]` — намагніченість насичення. Для Terfenol-D модуль Юнга може змінюватися більш ніж удвічі (від 25 ГПа до 65 ГПа) залежно від величини поля підмагнічування та сили преднатягу.

## Лінеаризовані п'єзомагнітні рівняння стану

Для розрахунку силових приводів, акустичних випромінювачів та давачів при малих амплітудах змінного сигналу навколо робочої точки (створеної постійним полем підмагнічування `H[0]` та постійним механічним напруженням `T[0]`) використовують лінійні **п'єзомагнітні рівняння стану** (*piezomagnetic constitutive equations*).

Вони зв'язують вектори деформації `S`, механічного напруження `T`, магнітної індукції `B` та напруженості магнітного поля `H`:

```
S = s[H] · T + d[t] · H                         [механічне рівняння: деформація від напруження та поля]
B = d · T + μ[T] · H                            [магнітне рівняння: індукція від напруження та поля]
```

Де в матричній формі (у позначеннях Фойгта, де `S` та `T` — 6-компонентні вектори):
- `s[H]` — матриця податливості (пружної гнучкості) розміром 6×6 при сталому магнітному полі `H`;
- `d` — матриця п'єзомагнітних модулів розміром 3×6 (`d[t]` — її транспонована матриця 6×3);
- `μ[T]` — тензор магнітної проникності розміром 3×3 при сталому механічному напруженні `T`.

Для одновимірного поздовжнього стержня (працюючого вздовж осі 3) п'єзомагнітні рівняння спрощуються до системи двох скалярних рівнянь:

```
S[3] = (1 / E[H]) · T[3] + d[33] · H[3]          [поздовжня деформація]
B[3] = d[33] · T[3] + μ[33]^[T] · H[3]          [поздовжня індукція]
```

де:
- `E[H]` — модуль Юнга при сталому полі `H`;
- `d[33] = ∂S[3] / ∂H[3] = ∂B[3] / ∂T[3]` — п'єзомагнітний коефіцієнт деформації (м/А або Тл/Па);
- `μ[33]^[T]` — магнітна проникність затиснутого/вільного зразка.

Коефіцієнт електромеханічного (магнітомеханічного) зв'язку `k[33]` визначає ефективність перетворення магнітної енергії в механічну:

```
k[33]² = d[33]² / (s[33]^[H] · μ[33]^[T])        [квадрат коефіцієнта зв'язку, k[33] ∈ [0, 1)]
```

Для високоефективних матеріалів, таких як Terfenol-D, значення `k[33]` сягає 0.70–0.75, що значно вище за п'єзокераміку PZT (0.50–0.65).

## Розрахунок блокиратора сили (Blocking Force)

Коли магнітострикційний актуатор жорстко затиснутий між двома нерухомими стінами (умова `S[3] = 0`), виникає максимальне зусилля блокиратора `F[block]`.

З рівняння `S[3] = (1 / E[H]) · T[3] + d[33] · H[3] = 0` знаходиємо механічне напруження стиску `T[3]`:

```
T[3] = - E[H] · d[33] · H[3]                     [напруження затиснутого актуатора]
```

Для площі поперечного перерізу стрижня `A` максимальна сила блокиратора дорівнює:

```
F[block] = |T[3]| · A = A · E[H] · λ[s]          [максимальна сила зупинки ходу]
```

### Числовий приклад

Розрахуємо силу блокиратора для стрижня з матеріалу Terfenol-D:
- Діаметр стрижня `d_rod = 20 мм` (`A = π · (0.01)² ≈ 3.14 × 10⁻⁴ м²`);
- Модуль Юнга `E[H] = 30 ГПа = 30 × 10⁹ Па`;
- Насичена деформація `λ[s] = 1.2 × 10⁻³` (1200 ppm).

```
F[block] = 3.14 × 10⁻⁴ м² · 30 × 10⁹ Па · 1.2 × 10⁻³
         = 3.14 × 10⁻⁴ · 3.6 × 10⁷
         = 11304 Н ≈ 11.3 кН                   [сила понад 1.1 тонни!]
```

Цей розрахунок доводить, що при невеликих ходах (десятки мікрометрів) магнітострикційний привід здатен розвивати гігантські механічні зусилля, що робить його незамінним для важкої прецизійної механіки.
