# 🧮 Математичний вивід рівняння Беті та тунелювання WKB

Ця математична вставка містить строгий аналітичний вивід рівняння термоелектронної емісії Беті для струму контакту Шотткі, вивід ефекту зниження бар'єра силами дзеркального зображення, а також розрахунок коефіцієнта квантово-механічного тунелювання у наближенні Вентцеля-Крамерса-Бріллюена (WKB) для визначення питомого опору омічних контактів.

---

## 1. Строгий вивід рівняння термоелектронної емісії Беті

Розглянемо випрямний контакт між металом та n-напівпровідником із висотою потенціального бар'єра `q·Φ_Bn` при прикладеній прямій напрузі зміщення `V`.

За теорією Ханса Беті (Hans Bethe), швидкість переносу носіїв визначається процесом подолання електронами самісінької вершины бар'єра на межі розділу. Припускається, що електрони в об'ємі напівпровідника перебувають у стані теплової рівноваги і описуються функцією розподілу Максвелла-Больцмана.

### Потік електронів з напівпровідника в метал

Густина струму електронів `J_s->m`, що рухаються з об'єму напівпровідника в метал уздовж осі `x` (перпендикулярно до площини контакту), дорівнює інтегралу від добутку заряду електрона `q`, складової швидкості `v_x` та елементарної концентрації електронів `dn` з даним вектором швидкості:

```
J_s->m = q · ∫ v_x · dn
```

Інтегрування проводиться за всіма можливими швидкостями `v_x`, `v_y`, `v_z`, при яких кінетична енергія електрона уздовж осі `x` перевищує максимальну висоту потенціального бар'єра в області просторового заряду:

```
(1/2) · m* · v_x² ≥ q · (V_bi - V)
```

де `m*` — ефективна маса провідності електрона в напівпровіднику, `V_bi` — вбудований контактний потенціал. Звідси мінімальна порогова швидкість уздовж осі `x` для подолання бар'єра становить:

```
v_min = √[ (2 · q · (V_bi - V)) / m* ]
```

Для ненасиченого (параболічного) напівпровідника n-типу елементарна концентрація електронів у квантовому просторі швидкостей `dv_x dv_y dv_z` задається статистикою Максвелла-Больцмана:

```
dn = 2 · (m* / h)³ · exp[ -(E - E_F) / (k_B · T) ] · dv_x dv_y dv_z
```

де `h` — стала Планка, `k_B` — стала Больцмана, `T` — абсолютна температура, `E_F` — рівень Фермі.

Повна кінетична енергія електрона відносно дна зони провідності `E_c` виражається сумою трьох квадратів швидкостей:

```
E - E_c = (1/2) · m* · (v_x² + v_y² + v_z²)
```

Враховуючи, що енергетична відстань від дна зони провідності до рівня Фермі в квазінейтральному об'ємі напівпровідника дорівнює `E_c - E_F = q·V_n`, підставляємо вираз для повної енергії в експоненту розподілу:

```
exp[ -(E - E_F) / (k_B·T) ] = exp[ -q·V_n / (k_B·T) ] · exp[ -m*·(v_x² + v_y² + v_z²) / (2·k_B·T) ]
```

Підставляючи елементарну концентрацію `dn` у вираз для густини струму `J_s->m`, розкладаємо потрійний інтеграл за об'ємом швидкостей на добуток трьох незалежних одновимірних інтегралів:

```
J_s->m = 2 · q · (m* / h)³ · exp[ -q·V_n / (k_B·T) ]
         · ∫_[v_min..∞] v_x · exp[ -m*·v_x² / (2·k_B·T) ] dv_x
         · ∫_[-∞..∞] exp[ -m*·v_y² / (2·k_B·T) ] dv_y
         · ∫_[-∞..∞] exp[ -m*·v_z² / (2·k_B·T) ] dv_z
```

### Обчислення трьох інтегралів швидкостей

1. **Інтегрування за поперечними швидкостями `v_y` та `v_z`**:
   Інтеграли за вісями `y` та `z` є стандартними інтегралами Пуассона-Гаусса виду `∫_[-∞..∞] exp(-a·u²) du = √(π / a)`. При `a = m* / (2·k_B·T)` отримуємо:

```
∫_[-∞..∞] exp[ -m*·v_y² / (2·k_B·T) ] dv_y = √[ (2 · π · k_B · T) / m* ]
∫_[-∞..∞] exp[ -m*·v_z² / (2·k_B·T) ] dv_z = √[ (2 · π · k_B · T) / m* ]
```

Добуток двох поперечних інтегралів скорочує ірраціональність і дає лінійний вираз:
```
[ √[ (2 · π · k_B · T) / m* ] ]² = (2 · π · k_B · T) / m*
```

2. **Інтегрування за поздовжньою швидкістю `v_x`**:
   Для обчислення першого інтеграла виконуємо заміну змінної `u = m*·v_x² / (2·k_B·T)`, звідки `du = (m*·v_x / (k_B·T)) dv_x`. Нижнє значення межі при `v_x = v_min` стає рівним `u_min = q·(V_bi - V) / (k_B·T)`:

```
∫_[v_min..∞] v_x · exp[ -m*·v_x² / (2·k_B·T) ] dv_x 
= (k_B·T / m*) · ∫_[u_min..∞] exp(-u) du
= (k_B·T / m*) · exp[ -u_min ]
= (k_B·T / m*) · exp[ -q·(V_bi - V) / (k_B·T) ]
```

3. **Перемножування та алгебраїчний синтез**:
   Об'єднуємо обчислені значення усіх трьох інтегралів у спільний вираз:

```
J_s->m = 2 · q · (m* / h)³ · exp[ -q·V_n / (k_B·T) ]
         · [ (k_B·T / m*) · exp( -q·(V_bi - V) / (k_B·T) ) ]
         · [ (2 · π · k_B · T) / m* ]
```

Скорочуємо масу `m*` у чисельнику та знаменнику та перегруповуємо множники за степенями температури `T`:

```
J_s->m = [ (4 · π · q · m* · k_B²) / h³ ] · T² · exp[ -q·(V_n + V_bi - V) / (k_B·T) ]
```

Зважаючи на те, що за моделлю Шотткі-Мотта сума енергетичних інтервалів `q·V_n + q·V_bi = q·Φ_Bn` дорівнює повній висоті бар'єра Шотткі для електронів з боку металу, виражаємо струм у вигляді:

```
J_s->m = A* · T² · exp( -q·Φ_Bn / (k_B·T) ) · exp( q·V / (k_B·T) )
```

де фундаментальний коефіцієнт **`A*`** називають **константою Річардсона**:

```
A* = (4 · π · q · m* · k_B²) / h³
```

### Потік електронів з металу та результуюча ВАХ

У стані термодинамічної рівноваги за відсутності зовнішньої напруги (`V = 0`) потік електронів із напівпровідника в метал `J_s->m(0)` мусить точно врівноважуватися зустрічним потоком електронів із металу в напівпровідник `J_m->s`.

Оскільки енергетичний бар'єр для електронів металу `q·Φ_Bn` визначається відстані від рівня Фермі `E_F` до дна зони провідності `E_c` на межі і не залежить від прикладеної напруги зміщення `V` (у першому наближенні), зустрічний потік електронів з металу є константним:

```
J_m->s = J_s->m(0) = A* · T² · exp( -q·Φ_Bn / (k_B·T) ) = J_s
```

де `J_s` — густина насичення зворотного струму.

Результуюча густина струму через контакт дорівнює різниці двох протилежних потоків електронів:

```
J = J_s->m - J_m->s
  = J_s · exp( q·V / (k_B·T) ) - J_s
  = J_s · [ exp( q·V / (k_B·T) ) - 1 ]
```

З урахуванням експериментального коефіцієнта неідеальності `n`, який враховує вигин зон під впливом зовнішнього поля та наявність поверхневих станів, підсумкове рівняння Беті набуває вигляду:

```
J = A** · T² · exp( -q·Φ_Bn / (k_B·T) ) · [ exp( q·V / (n·k_B·T) ) - 1 ]
```

## 2. Математика зниження бар'єра силами дзеркального зображення (Ефект Шотткі)

Коли електрон наближається до провідної межі розділу з металом на відстань `x`, він індукує на металевій поверхні позитивний розподілений заряд. Електростатичний потенціал цього заряду дорівнює потенціалу одного фіксованого точкового заряду `+q`, розташованого дзеркально на координаті `-x` у глибині металу.

### Потенціальна енергія дзеркального заряду

Сила електростатичного притягання між електроном та його дзеркальним зображенням обчислюється за законом Кулона:

```
F_img(x) = -q² / [ 4 · π · ε_s · (2x)² ] = -q² / [ 16 · π · ε_s · x² ]
```

де `ε_s = ε_r · ε_0` — діелектрична проникність напівпровідника.

Потенціальна енергія цієї сили `E_img(x)` визначається роботою перенесення електрона з безкінечності до точки `x`:

```
E_img(x) = ∫_[x..∞] F_img(x') dx' = -q² / [ 16 · π · ε_s · x ]
```

### Знаходження максимуму закругленого бар'єра

У виснаженій області напівпровідника на електрон одночасно діє лінійне електричне поле ОПЗ `E_max` та сила дзеркального зображення. Повна потенціальна енергія електрона `PE(x)` відносно рівня Фермі металу дорівнює:

```
PE(x) = q · Φ_Bn0 - q · E_max · x - q² / [ 16 · π · ε_s · x ]
```

Для знаходження вершини закругленого бар'єра беремо першу похідну від потенціальної енергії за координатою `x` і прирівнюємо її до нуля:

```
d(PE) / dx = -q · E_max + q² / [ 16 · π · ε_s · x² ] = 0
```

Розв'язуючи це рівняння, знаходимо координату максимуму бар'єра `x_max`:

```
x_max = √[ q / (16 · π · ε_s · E_max) ]
```

Підставляючи координату `x_max` у вираз для потенціальної енергії `PE(x_max)`, обчислюємо абсолютну величину зниження висоти бар'єра **`ΔΦ_B`**:

```
ΔΦ_B = q · E_max · x_max + q² / [ 16 · π · ε_s · x_max ]
     = 2 · √[ (q³ · E_max) / (16 · π · ε_s) ]
     = √[ (q · E_max) / (4 · π · ε_s) ]
```

Оскільки максимальне поле в ОПЗ залежить від прикладеної напруги зміщення `V` як `E_max = √[ (2·q·N_d / ε_s) · (V_bi - V) ]`, зниження бар'єра `ΔΦ_B` зростає пропорційно `(V_bi - V)^(1/4)`. Це зумовлює слабке зростання зворотного струму діода Шотткі при збільшенні зворотного зміщення.

## 3. Квантово-механічне тунелювання WKB та опір омічного контакту

У високолегованих напівпровідниках (`N_d > 10¹⁹ см⁻³`) товщина виснаженого шару `W` зменшується до декількох нанометрів. Електрони отримують можливість тунелювати крізь потенціальний бар'єр безпосередньо з рівня Фермі.

### Одновимірне рівняння Шредінгера та наближення WKB

Квантово-механічний перенос електрона вздовж осі `x` описується стаціонарним рівнянням Шредінгера:

```
- (ħ² / (2·m*)) · (d²ψ / dx²) + q·V(x)·ψ = E·ψ
```

де `ħ = h / (2π)` — зведена стала Планка, `V(x)` — електростатичний потенціал ОПЗ.

У квазікласичному наближенні Вентцеля-Крамерса-Бріллюена (WKB) хвильова функція під бар'єром шукається у вигляді `ψ(x) = exp[ - ∫ k(x) dx ]`, де локальне хвильове число `k(x)` у класично забороненій області дорівнює:

```
k(x) = (1 / ħ) · √[ 2 · m* · (q·V(x) - E) ]
```

Коефіцієнт квантово-механічного проходження (прозорість бар'єра) `D(E)` для електрона з енергією `E` дорівнює відношенню квадратів амплітуд і виражається інтегралом WKB:

```
D(E) = exp[ -2 · ∫_[0..x_rot] k(x) dx ]
```

де `x_rot` — класична точка повороту, у якій кінетична енергія дорівнює нулю: `q·V(x_rot) = E`.

### Інтегрування прозорості для параболічного бар'єра

У деплеційному наближенні потенціал виснаженого шару має параболічний профіль:

```
q·V(x) = q·V_bi · (1 - x / W)²
```

де товщина ОПЗ `W` дорівнює `W = √[ (2 · ε_s · V_bi) / (q · N_d) ]`.

Розглянемо тунелювання електрона, що перебуває на рівні Фермі (`E = 0`). Точка повороту збігається з товщиною ОПЗ (`x_rot = W`).

Підставляємо потенціал `V(x)` в інтеграл WKB:

```
∫_[0..W] k(x) dx = (1 / ħ) · √[ 2 · m* · q·V_bi ] · ∫_[0..W] (1 - x / W) dx
```

Інтеграл лінійної функції `∫_[0..W] (1 - x/W) dx = [ x - x² / (2W) ]_[0..W] = W / 2`.

Отже, показник експоненти WKB дорівнює:

```
2 · ∫_[0..W] k(x) dx = (1 / ħ) · √[ 2 · m* · q·V_bi ] · W
```

Підставляємо розрахунковий вираз для `W`:

```
(1 / ħ) · √[ 2 · m* · q·V_bi ] · √[ (2 · ε_s · V_bi) / (q · N_d) ]
= (2 / ħ) · √[ (m* · ε_s) / (q · N_d) ] · (q · V_bi)
```

Вводячи характеристичну тунельну енергію Падовані-Стратона **`E_00`**:

```
E_00 = (q · ħ / 2) · √[ N_d / (m* · ε_s) ]
```

отримуємо елегантний за формою результат для прозорості бар'єра на рівні Фермі:

```
D(E_F) = exp[ - q · V_bi / E_00 ] ≈ exp[ - q · Φ_Bn / E_00 ]
```

### Розрахунок питомого контактного опору ρ_c

Густина тунельного струму `J_FE` в режимі польової емісії обчислюється інтегруванням за всіма дозволеними енергетичними станами поблизу рівня Фермі:

```
J_FE = (A* · T / k_B) · ∫ D(E) · [ f_s(E) - f_m(E) ] dE
```

Для малих напруг зміщення (`V → 0`) різниця функцій Фермі-Дірака розкладається в лінійний ряд Тейлора `f_s - f_m ≈ (df/dE) · qV`.

Виконуючи інтегрування, отримуємо вираз для диференціальної провідності contacts:

```
J_FE ≈ [ (q · A* · T) / (k_B) ] · (E_00 / (k_B · T)) · exp[ - q · Φ_Bn / E_00 ] · V
```

За означенням, **питомий контактний опір `ρ_c`** дорівнює оберненій величині похідної `dJ / dV` при `V = 0`:

```
ρ_c = [ dJ / dV ]⁻¹  при V = 0
```

Підставляючи струм `J_FE`, отримуємо остаточну математичну формулу для питомого опору тунельного омічного контакту:

```
ρ_c = [ (k_B) / (q · A* · T) ] · ( (k_B · T) / E_00 ) · exp[ q · Φ_Bn / E_00 ]
```

Підставляючи у показник експоненти формулу для `E_00`, виділяємо ключову залежність від фізичних параметрів матеріалів:

```
ρ_c ∝ exp[ (2 · √[m* · ε_s] / ħ) · ( (q·Φ_Bn) / √N_d ) ]
```

Цей аналітичний результат доводить, що для отримання ультранизького контактного опору (`ρ_c < 10⁻⁸ Ом·см²`) в нанорозмірних напівпровідникових приладах необхідно забезпечити максимальну концентрацію допування `N_d` та обирати металізації з найменшою висотою потенціального бар'єра `q·Φ_Bn`.
