# 🧮 Математична теорія спиново-поляризованого тунелювання та симетрійного згасання

Ця математична вставка містить аналітичний вивід феноменологічної моделі Джульєра, розрахунок оптимістичного та песимістичного коефіцієнтів тунельного магнітоопору (TMR), мікроскопічну теорію Бринкмана — Дайнеса — Роуелла (BDR) для тунельних I-V характеристик, а також квантово-механічний розрахунок показників еванесцентного згасання Блохівських станів різної симетрії у кристалічному бар'єрі MgO.

### 1. Спінова поляризація та провідність у моделі Джульєра

Розглянемо квантово-механічне тунелювання електронів між двома феромагнітними електродами (FM1 та FM2), розділеними надтонким потенціальним бар'єром товщиною `d`.

Відповідно до наближення Фермі для золотої правила (Fermi's Golden Rule), ймовірність квантового переходу електрона зі стану з енергією `E` у першому електроді в доступний стан у другому електроді пропорційна добутку густин станів обох електродів `D₁(E)` та `D₂(E)`, а також квадрату матричного елемента тунелювання `|M|²`:

```
I ∝ |M|² · D₁(E_F) · D₂(E_F) · e·V
```

У феромагнетику d-зона розщеплена на дві спінові підзони зі спіном вгору (`↑`, мажоритарні електрони) та спіном вниз (`↓`, миноритарні електрони). Введемо парціальні густини станів на рівні Фермі:
- `D₁_↑, D₁_↓` — густини станів у першому електроді;
- `D₂_↑, D₂_↓` — густини станів у другому електроді.

Спінова поляризація матеріалу `P` визначається як нормована різниця густин станів зі спінами протилежних напрямків на рівні Фермі `E_F`:

```
P = (D_↑(E_F) - D_↓(E_F)) / (D_↑(E_F) + D_↓(E_F))
```

Звідси парціальні густини станів виражаються через сумарну густину станів `D = D_↑ + D_↓` та поляризацію `P`:

```
D_↑ = (D / 2) · (1 + P)      [вираження мажоритарних станів через поляризацію P]
D_↓ = (D / 2) · (1 - P)      [вираження миноритарних станів через поляризацію P]
```

#### Паралельний стан (P)
У паралельній орієнтації намагніченостей (FM1 ↑, FM2 ↑) напрямки спінів у більшості електродів збігаються. Електрони тунелюють без зміни орієнтації спіну (пружне спіново-зберігаюче тунелювання):
1. Спін-вгору тунелює зі стану `D₁_↑` у стан `D₂_↑`;
2. Спін-вниз тунелює зі стану `D₁_↓` у стан `D₂_↓`.

Сумарна провідність `G_P` є сумою провідностей двох незалежних спінових каналів:

```
G_P
= C · (D₁_↑ · D₂_↑ + D₁_↓ · D₂_↓)                                                    [сума двох спінових каналів]
= C · [(D₁/2)·(1 + P₁) · (D₂/2)·(1 + P₂) + (D₁/2)·(1 - P₁) · (D₂/2)·(1 - P₂)]        [підстановка парціальних густин]
= (C·D₁·D₂ / 4) · [(1 + P₁ + P₂ + P₁·P₂) + (1 - P₁ - P₂ + P₁·P₂)]                   [розкриття дужок]
= (C·D₁·D₂ / 2) · (1 + P₁·P₂)                                                        [зведення подібних доданків]
```

#### Антипаралельний стан (AP)
При перемиканні другого електрода в протилежний стан (FM1 ↑, FM2 ↓) мажоритарний канал першого електрода `D₁_↑` тунелює в миноритарний канал другого електрода `D₂_↓`, і навпаки:

```
G_AP
= C · (D₁_↑ · D₂_↓ + D₁_↓ · D₂_↑)                                                    [сума двох перехресних каналів]
= C · [(D₁/2)·(1 + P₁) · (D₂/2)·(1 - P₂) + (D₁/2)·(1 - P₁) · (D₂/2)·(1 + P₂)]        [підстановка парціальних густин]
= (C·D₁·D₂ / 4) · [(1 + P₁ - P₂ - P₁·P₂) + (1 - P₁ + P₂ - P₁·P₂)]                   [розкриття дужок]
= (C·D₁·D₂ / 2) · (1 - P₁·P₂)                                                        [зведення подібних доданків]
```

### 2. Вивід формули тунельного магнітоопору (TMR)

Електричний опір є оберненою величиною до провідності: `R = 1 / G`. Оскільки `P₁ ≥ 0` та `P₂ ≥ 0`, маємо `G_P > G_AP`, звідки опір в антипаралельному стані є вищим: `R_AP > R_P`.

У науковій літературі використовуються два визначення коефіцієнта TMR:

#### 1. Оптимістичне визначення (Julliere Ratio)
Відношення зміни опору до мінімального опору `R_P`:

```
TMR_opt
= (R_AP - R_P) / R_P                  [означення оптимістичного TMR відносно R_P]
= (1/G_AP - 1/G_P) / (1/G_P)          [заміна опорів на обернену провідність R = 1/G]
= (G_P - G_AP) / G_AP                 [зведення дробу в чисельнику та скорочення]
```

Підставимо отримані вирази для `G_P` та `G_AP`:

```
G_P - G_AP
= (C·D₁·D₂ / 2) · [(1 + P₁·P₂) - (1 - P₁·P₂)]        [різниця двох провідностей]
= C·D₁·D₂ · P₁·P₂                                     [спрощення дужок]

TMR_opt
= (C·D₁·D₂ · P₁·P₂) / [(C·D₁·D₂ / 2) · (1 - P₁·P₂)]   [ділення різниці провідностей на G_AP]
= 2·P₁·P₂ / (1 - P₁·P₂)                              [скорочення спільних множників]
```

Якщо обидва електроди виготовлені з одинакового матеріалу (`P₁ = P₂ = P`):

```
TMR_opt = 2·P² / (1 - P²)              [підстановка P1 = P2 = P]
```

#### 2. Песимістичне визначення (Magnetoresistance Ratio)
Відношення зміни опору до максимального опору `R_AP`:

```
TMR_pess
= (R_AP - R_P) / R_AP                                [означення песимістичного TMR відносно R_AP]
= (G_P - G_AP) / G_P                                 [перехід від опорів до провідностей]
= (C·D₁·D₂ · P₁·P₂) / [(C·D₁·D₂ / 2) · (1 + P₁·P₂)]  [підстановка різниці та G_P]
= 2·P₁·P₂ / (1 + P₁·P₂)                             [скорочення спільних множників]
```

Зауважимо, що при `P₁ = P₂ = 1.0` (ідеальний 100% спіновий фільтр):
- `TMR_opt → ∞` (опір `R_AP → ∞`, струм блокується повністю);
- `TMR_pess → 100%`.

### 3. Кутова залежність провідності Слончевського

У 1989 році Джон Слончевський (John Slonczewski) розширив модель Джульєра на випадок довільного кута `θ` між векторами намагніченості обох феромагнітних шарів.

Якщо вектора намагніченості утворюють кут `θ`, квантовий стан електрона зі спіном вгору першого електрод електрод розкладається у базисі спінових станів другого електрода, повернутого на кут `θ`:

```
|↑_1⟩ = cos(θ/2) |↑_2⟩ + sin(θ/2) |↓_2⟩
|↓_1⟩ = -sin(θ/2) |↑_2⟩ + cos(θ/2) |↓_2⟩
```

Імовірність проходження квантового каналу пропорційна квадратам амплітуд проекцій:

```
P_↑↑(θ) = cos²(θ/2) = (1 + cos(θ)) / 2
P_↑↓(θ) = sin²(θ/2) = (1 - cos(θ)) / 2
```

Сумуючи провідності чотирьох спінових підканалів із ваговими коефіцієнтами густин станів `D_↑` та `D_↓`, отримуємо фундаментальне рівняння Слончевського для кутової залежності провідності `G(θ)`:

```
G(θ)
= G_P · cos²(θ/2) + G_AP · sin²(θ/2)                                      [сума провідностей з вагами Слончевського]
= G_P · [(1 + cos(θ)) / 2] + G_AP · [(1 - cos(θ)) / 2]                    [підстановка тригонометричних тотожностей]
= (G_P + G_AP) / 2 + [(G_P - G_AP) / 2] · cos(θ)                           [групування доданків за cos(θ)]
```

Виражаючи опір `R(θ) = 1 / G(θ)` через парціальні опори `R_P` та `R_AP`:

```
R(θ)
= 1 / [ (1/R_P + 1/R_AP)/2 + ((1/R_P - 1/R_AP)/2) · cos(θ) ]               [заміна G на 1/R]
= 2 / [ (R_AP + R_P)/(R_P · R_AP) + ((R_AP - R_P)/(R_P · R_AP)) · cos(θ) ] [зведення до спільного знаменника]
= (2 · R_P · R_AP) / [ (R_AP + R_P) + (R_AP - R_P) · cos(θ) ]              [перенесення добутку R_P·R_AP у чисельник]
```

Отриманий вираз показує, що провідність `G(θ)` є строго лінійною функцією від `cos(θ)`, тоді як сам опір `R(θ)` є гармонічно опуклою нелінійною функцією від кута `θ`.

### 4. Мікроскопічна теорія Бринкмана — Дайнеса — Роуелла (BDR) для тунельних бар'єрів

У реальних тунельних гетероструктурах потенціальний бар'єр не є прямокутним. При прикладанні зовнішньої напруги `V` потенціальний профіль викривляється електричним полем, утворюючи трапецієподібний або параболічний бар'єр.

Згідно з квазікласичним наближенням Вентцеля — Крамерса — Бріллюена (ВКБ / WKB), коефіцієнт прозорості бар'єру `P(E)` для електронів із поперечним хвильовим вектором `k_∥` обчислюється через інтеграл еванесцентного згасання:

```
P(E) = exp( -2 · ∫_0^d √[ (2·m* / ℏ²) · (V(z) - E) + |k_∥|² ] dz )
```

У 1970 році Бринкман, Дайнес та Роуелл розклали тунельний струм у ряд за степенями прикладеної напруги `V` для прямокутного бар'єру з середньою висотою `Φ_bar` та асиметрією `ΔΦ`:

```
J(V) = G_0 · [ V - (ΔΦ / (2 · Φ_bar)) · e·V² + (16 · m* · d² · e² / (ℏ² · Φ_bar)) · V³ ]
```

де `G_0` — диференціальна провідність при нульовій напрузі:

```
G_0 = (e² / (h · d²)) · √[ 2·m*·Φ_bar / ℏ² ] · exp( -2·d · √[ 2·m*·Φ_bar / ℏ² ] )
```

Звідси випливають важливі фізичні висновки:
1. **Лінійний член (C₁·V):** Описує класичний омічний закон тунелювання при малих напругах (`V < 0.05 В`).
2. **Квадратичний член (C₂·V²):** Виникає виключно за наявності асиметрії потенціального бар'єру (`ΔΦ ≠ 0`), наприклад, коли електроди виготовлені з металів із різною роботою виходу.
3. **Кубічний член (C₃·V³):** Описує ефект звуження потенціального бар'єру при високих напругах. Це призводить до прискореного зростання тунельного струму при `V > 0.5 В`.

### 5. Квантова теорія еванесцентного загасання та симетрійне фільтрування у MgO(001)

Модель Джульєра вважає матричний елемент тунелювання `|M|²` константою, однаковою для всіх електронів. Це наближення працює лише для аморфних бар'єрів. Для кристалічного бар'єру MgO(001) необхідно розв'язувати тривимірне стаціонарне рівняння Шредінгера.

У кристалічній ґратці електрон описується блохівською хвильовою функцією:

```
Ψ(r) = u_k(r) · exp(i · k_∥ · r_∥) · exp(i · k_z · z)
```

де `k_∥ = (k_x, k_y)` — поперечний хвильовий вектор у площині інтерфейсу, `k_z` — поздовжній хвильовий вектор уздовж напрямку тунелювання `z`.

Усередині диелектричного бар'єру MgO з висотою потенціального бар'єру `V₀` та ефективною масою електрона `m*` поздовжній хвильовий вектор стає уявним: `k_z = i · κ`, де `κ` — коефіцієнт еванесцентного згасання хвильової функції:

```
κ(k_∥) = √[ (2·m* / ℏ²) · (V_0 - E) + |k_∥|² ]
```

Коефіцієнт прозорості бар'єру товщиною `d` експоненціально залежить від `κ`:

```
T(k_∥) ∝ exp(-2 · κ(k_∥) · d)
```

Найбільша прозорість досягається при строго нормальному падінні електронів (`k_∥ = 0`), де `κ` є мінімальним:

```
κ_min = √[ 2·m*·(V_0 - E) ] / ℏ
```

#### Залежність згасання від симетрії Блохівських станів у Fe(001)/MgO(001)

У кристалічному залізі орієнтації (001) Блохівські електронні стани на осі симетрії Γ - H (вздовж напрямку тунелювання `z`) розкладаються за непривідними уявленнями точкової групи симетрії C₄ᵥ:

1. **Симетрія Δ₁:** Повністю симетричний стан, сформований гібридизацією атомних s, p_z та d_{z²} орбіталей.
2. **Симетрія Δ₅:** Двічі вироджений стан, сформований d_{xz} та d_{yz} орбіталями.
3. **Симетрія Δ₂':** Двовимірний стан, сформований d_{xy} орбіталями.

Обчислення з перших принципів (DFT) дають наступні значення коефіцієнта згасання `κ` для різних симетрій у зазорі MgO(001):

```
κ(Δ₁)  ≈ 0.85 Å⁻¹
κ(Δ₅)  ≈ 1.05 Å⁻¹
κ(Δ₂') ≈ 1.25 Å⁻¹
```

Обчислимо відносне співвідношення коефіцієнтів пропускання для станів Δ₁ та Δ₅ при товщині бар'єру `d = 1.6 нм` = 16 Å:

```
T(Δ₁) / T(Δ₅)
= exp(-2 · κ(Δ₁) · d) / exp(-2 · κ(Δ₅) · d)           [співвідношення експоненційних коефіцієнтів]
= exp[ -2 · (κ(Δ₁) - κ(Δ₅)) · d ]                      [показники експонент віднімаються]
= exp[ -2 · (0.85 - 1.05) · 16 ]                        [підстановка показників згасання κ та товщини d]
= exp[ -2 · (-0.20) · 16 ]                              [обчислення різниці κ(Δ1) - κ(Δ5)]
= exp(6.4)                                              [перемноження показника: -2 · (-3.2)]
≈ 600                                                   [обчислення експоненти exp(6.4)]
```

Отже, кристалічний шар MgO товщиною всього 1.6 нм пропускає хвилі симетрії Δ₁ у **600 разів ефективніше**, ніж хвилі симетрії Δ₅.

Оскільки у феромагнітному залізі `Fe(001)` при енергії Фермі `E_F` стан симетрії Δ₁ існує **виключно для спіну вгору (↑)**, а для спіну вниз (↓) стан Δ₁ відсутній (зона розщеплена обмінною взаємодією і лежить вище `E_F`), ефективна спінова поляризація провідного каналу дорівнює:

```
P_eff(Δ₁) = (D_↑(Δ₁) - 0) / (D_↑(Δ₁) + 0) = 1.0  (100%)
```

Підставляючи `P_eff = 1.0` у формулу Джульєра, отримуємо теоретичну межу TMR для MgO:

```
TMR_theory = 2·(1.0)·(1.0) / (1 - (1.0)·(1.0)) → ∞
```

У реальних гетероструктурах термодинамічні флуктуації, дефекти на інтерфейсі та наявність некогерентного розсіювання обмежують кімнатно-температурний TMR рівнем 200–604%, що усе одно на два порядки перевищує показники металевих GMR-структур.
