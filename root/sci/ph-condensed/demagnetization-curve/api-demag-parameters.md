# 📋 Довідник розмагнічувальних коефіцієнтів та характеристик матеріалів

Цей інженерно-технічний довідник містить зведені фізичні константи твердомагнітних матеріалів, значення коефіцієнтів розмагнічування `N_d` для стандартних та складних геометрій, формули перерахунку між міжнародною системою одиниць (SI) та гаусовою системою (СГС/EMU), а також розширений аналіз матеріалознавчих та температурних параметрів постійних магнітів.

### 1. Фізичні величини та одиниці вимірювання магнітних характеристик

У магнітостатиці та практичному проектуванні постійних магнітів історично склалося паралельне використання двох систем одиниць: міжнародної системи SI (Тл, А/м, кДж/м³) та традиційної гаусової системи СГС/EMU (Ґаусс, Ерстед, МГс·Е). Нерозуміння співвідношень між ними часто призводить до помилок розрахунку магнітних кіл.

Магнітна індукція `B` у системі SI вимірюється у теслах (Тл), а в СГС — у ґауссах (Гс, G). Точне співвідношення становить `1 Тл = 10 000 Гс = 10 кГс`. Залишкова індукція `B_r` показує рівень індукції, який залишається у магнітному матеріалі після його намагнічування до стану повного магнітного насичення за відсутності зовнішнього розмагнічувального поля (`H = 0`).

Напруженість магнітного поля `H` у SI вимірюється в амперах на метр (А/м) або кілоамперах на метр (кА/м), а в СГС — в ерстедах (Е, Oe). Коефіцієнт зв'язку визначається через число Пі: `1 кА/м = (4·π / 10) Oe ≈ 12.566 Oe`, а `1 Oe = (1000 / 4·π) А/м ≈ 79.577 А/м`.

Коерцитивна сила за індукцією `H_cb` описує напруженість зовнішнього протидіючого поля, яке необхідно прикласти до намагніченого зразка, щоб результуюча індукція `B` усередині матеріалу впала до нуля.

Власна (інтринсивна) коерцитивна сила `H_cj` характеризує внутрішню стійкість спінової структури кристала. Вона вимірює напруженість від'ємного поля, яке повністю руйнує впорядковану намагніченість доменів і повертає інтринсивну намагніченість речовини до нуля (`J = 0` або `M = 0`). Для рідкісноземельних магнітів значення `H_cj` суттєво перевищує `H_cb`.

Максимальний енергетичний добуток `(BH)_max` описує граничну густину магнітної енергії, яку постійний магніт здатен передати у зовнішній повітряний зазор на одиницю власного об'єму. У SI величина вимірюється в кілоджоулях на кубічний метр (кДж/м³), а в СГС — у мега-ґаусс-ерстедах (МГс·Е, MGOe). Точне співвідношення становить `1 МГс·Е = (100 / 4·π) кДж/м³ ≈ 7.9577 кДж/м³`.

### 2. Геометричні коефіцієнти розмагнічування N_d та провідності P_c

Коефіцієнт розмагнічування `N_d` розраховується вздовж головної осі намагнічування `z`. Для будь-якого тривимірного тіла виконується фундаментальне правило нормалізації сліду тензора розмагнічування: `N_x + N_y + N_z = 1`. Відповідний коефіцієнт провідності ізольованого магніту у відкритому просторі визначається співвідношенням `P_c = (1 - N_d) / N_d`.

У практичних розрахунках геометрію магніту описують відношенням його товщини (довжини вздовж осі намагнічування `l_m`) до еквівалентного діаметра або поперечного розміру `d_m`.

Для плоских тонких дисків із малою товщиною (`l_m / d_m < 0.1`) поверхневі магнітні полюси розташовані на близькій відстані один від одного. Це створює всередині матеріалу колосальне внутрішнє розмагнічувальне поле, яке піднімає коефіцієнт `N_d` до значень `0.8...0.95`, а коефіцієнт провідності `P_c` падає нижче `0.2`. Такі геометрії вимагають використання матеріалів із високою власною коерцитивністю `H_cj`.

Для кубічних або рівносторонніх циліндричних магнітів (`l_m / d_m = 1.0`) тривимірна симетрія дає точне значення `N_d = 1/3` та `P_c = 2.0`. Це стандартна геометрія для багатьох статичних тримачів та датчиків.

Для подовжених стержнів (`l_m / d_m > 3.0`) поверхневі полюси рознесені на значну відстань, що суттєво послаблює внутрішнє протиполі. Коефіцієнт розмагнічування падає нижче `0.1`, а коефіцієнт провідності `P_c` зростає до `10...35`. Така геометрія є обов'язковою для сплавів Альніко, чия низька коерцитивність не дозволяє працювати у пологих робочих лініях.

Для прямокутних паралелепіпедів розмірами `a × b × c` (де `c` — товщина вздовж осі намагнічування) коефіцієнт провідності `P_c` можна розрахувати за наближеною інженерною формулою Евершеда — Паркера:

```
P_c ≈ (c / √(a · b)) · [ (a · b) / (c · (a + b)) ]
```

### 3. Матеріалознавчий аналіз та порівняння класів постійних магнітів

Нижче наведено докладну аналітичну характеристику чотирьох основних промислових родин твердомагнітних матеріалів:

#### 3.1. Гексагональні керамічні ферити (BaFe₁₂O₁₉, SrFe₁₂O₁₉)

Феритові магніти виготовляють шляхом високотемпературного спечення порошків оксиду заліза з оксидами барію або стронцію. Вони являють собою керамічні діелектрики з питомим електричним опором `ρ > 10⁶ Ом·м`.

Головними перевагами феритів є їхня надзвичайно низька вартість, абсолютна стійкість до корозії у вологому середовищі та агресивних хімічних речовинах, а також відсутність вихрових струмів при роботі у високочастотних магнітних полях.

Особливою фізичною властивістю феритів є позитивний температурний коефіцієнт власної коерцитивності `β(H_cj) = +0.30... +0.50 %/°C`. При нагріванні від 20°C до 150°C коерцитивна сила фериту зростає майже в півтора раза, що робить його **більш стійким до розмагнічування при високих температурах**.

Головним недоліком феритів є порівняно низька залишкова індукція (`B_r ≈ 0.38...0.42 Тл`) та низький енергетичний добуток (`(BH)_max ≈ 25...34 кДж/м³`). Магнітна система на феритах виходить у 4-8 разів більшою за масою та об'ємом, ніж аналогічна система на рідкісноземельних магнітах.

#### 3.2. Сплави Альніко (Alnico / ЮНДК)

Магніти типу Альніко виготовляють литвом або спеченням порошків сплаву заліза, алюмінію, нікелю та кобальту з домішками міді й титану. Їхня висока коерцитивність обумовлена фазовим розпадом на голчасті однодоменні включення фази Fe-Co у немагнітній матриці Ni-Al.

Головною перевагою Альніко є рекордна температурна стабільність: температурний коефіцієнт залишкової індукції становить лише `α(B_r) = -0.02 %/°C`, а максимальна робоча температура досягає 520...550°C (температура Кюрі перевищує 860°C). Магніти Alnico 5 мають високу залишкову індукцію (`B_r ≈ 1.25...1.35 Тл`).

Основним недоліком Альніко є катастрофічно низька коерцитивна сила (`H_cb ≈ 40...120 кА/м`). Крива розмагнічування має крутий нелінійний згин, тому найменше зовнішнє протидіюче поле легко розмагнічує матеріал.

#### 3.3. Самарій-Кобальтові магніти (SmCo₅ та Sm₂Co₁₇)

Самарій-кобальтові магніти належать до першого покоління рідкісноземельних матеріалів. Вони виготовляються методом порошкової металургії та спечення інтерметалічних сполук `SmCo₅` (тип 1:5) або `Sm₂Co₁₇` (тип 2:17).

Головні переваги SmCo — поєднання високого енергетичного добутку (`(BH)_max ≈ 180...260 кДж/м³`), високої власної коерцитивності (`H_cj > 1500...2500 кА/м`), відмінної температурної стабільності (`α = -0.03 %/°C`) та високої граничної робочої температури (до 300...350°C). Крім того, SmCo не схильний до корозії і не вимагає захисних гальванічних покриттів.

Основний недолік SmCo — дуже висока вартість через дефіцитність самарію та кобальту, а також висока механічна крихкість.

#### 3.4. Неодим-Залізо-Бор (Nd₂Fe₁₄B)

Магніти NdFeB є найпотужнішими постійними магнітами сучасності. Їх виготовляють спеченням тонкодисперсного порошку тетрагональної фази `Nd₂Fe₁₄B`.

Головна перевага неодимових магнітів — колосальний енергетичний добуток (`(BH)_max до 415 кДж/м³` для класу N52, `52 МГс·Е`), висока залишкова індукція (`B_r до 1.45 Тл`) та лінійна крива розмагнічування у всьому другому квадранті.

Слабкі сторони неодиму — висока схильність до атмосферної корозії (обов'язкове гальванічне покриття Ni-Cu-Ni, Zn або епоксидний лак) та чутливість коерцитивності до температури (`β(H_cj) ≈ -0.55...-0.65 %/°C`). Для підвищення температурної стійкості у сплав додають диспрозій (Dy) або тербій (Tb), створюючи високотемпературні серії M (до 100°C), H (до 120°C), SH (до 150°C), UH (до 180°C), EH (до 200°C) та AH (до 230°C).

### 4. Зведення розрахункових інженерних формул

Нижче систематизовано головні інженерні формули, які застосовують під час проектування магнітних систем:

1. **Закон зв'язку векторів стану середовища:**
```
B = μ₀·H + J
```

2. **Формула розмагнічувального поля ізольованого тіла:**
```
H_d = -N_d · (J / μ₀)
```

3. **Рівняння робочої лінії з урахуванням витоків потоку:**
```
P_c = |B_m / H_m| = μ₀ · f_l · (A_g · l_m) / (A_m · l_g)
```
де `f_l` — коефіцієнт розсіювання магнітного потоку (`1.15 ≤ f_l ≤ 1.5`), `A_m, l_m` — площа та довжина магніту, `A_g, l_g` — площа та довжина зазору.

4. **Мінімальний необхідний об'єм магнітного матеріалу V_m:**
```
V_m = (2 · f_l · W_g) / (BH)_max
```
де `W_g = (1 / 2) · B_g · H_g · V_g` — необхідна енергія магнітного поля у зазорі.

5. **Необхідна напруженість поля намагнічування H_sat:**
Для повного намагнічування зразка до технічного насичення зовнішнє поле повинно перевищувати коерцитивність матеріалу щонайменше втричі:
```
H_sat ≥ 3 · H_cj
```

6. **Рівняння траєкторії лінії повернення (Recoil Line):**
```
B_recoil(H) = B_op + μ_rec · μ₀ · (H - H_op)
```

7. **Температурна корекція параметрів:**
```
B_r(T) = B_r(20°C) · [ 1 + (α / 100) · (T - 20) ]
H_cj(T) = H_cj(20°C) · [ 1 + (β / 100) · (T - 20) ]
```
