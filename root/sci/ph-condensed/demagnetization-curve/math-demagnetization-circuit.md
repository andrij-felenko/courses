# 🧮 Виведення рівняння магнітного кола, коефіцієнта N та робочої лінії

Ця вставка містить строгий аналітичний вивід рівнянь магнетостатики для розмагнічувального поля, математичне обґрунтування властивостей тензора розмагнічування `N_d`, системне виведення рівняння робочої лінії (*load line*) для некоаксіальних магнітних кіл із урахуванням витоків магнітного потоку, а також варіаційне доведення умови мінімізації об'єму магнітного матеріалу при максимізації енергетичного добутку `(BH)_max`.

### 1. Фундаментальні рівняння магнетостатики та потенціал Пуассона

У магнітостатиці за відсутності макроскопічних електричних струмів провідності у досліджуваному об'ємі магніту рівняння Максвелла спрощуються до системи двох фундаментальних векторних рівнянь. Перше з них визначає безвихровий характер поля напруженості, а друге — соленоїдальний характер поля магнітної індукції:

```
rot H = 0
div B = 0
```

Оскільки вихровий ротор вектора напруженості дорівнює нулю у всьому просторі, вектор напруженості магнітного поля `H` можна однозначно подати як градієнт скалярного магнітного потенціалу `Ψ`:

```
H = -∇Ψ
```

Вектор магнітної індукції `B` у будь-якому матеріальному середовищі є сумою поля напруженості у вакуумі та власних магнітних моментів одиниці об'єму речовини, які описуються вектором намагніченості `J` (у системі SI намагніченість вимірюється у теслах, або як `M = J / μ₀` в амперах на метр):

```
B = μ₀·H + J
```

Підставивши вираз для напруженості через скалярний потенціал у рівняння нерозривності магнітного потоку `div B = 0`, отримуємо фундаментальне диференціальне рівняння для магнітного потенціалу:

```
div (μ₀·(-∇Ψ) + J) = 0
-μ₀·∇²Ψ + div J = 0
∇²Ψ = (div J) / μ₀
```

Отримане співвідношення є точним аналогом рівняння Пуассона в електростатиці. Це дозволяє ввести поняття фіктивних «магнітних зарядів». Джерелами магнітного потенціалу виступають об'ємна густина магнітних зарядів `ρ_m = -div J` всередині неоднорідно намагніченого тіла та поверхнева густина магнітних зарядів `σ_m = n · J` на межі розділу середовищ, де `n` — орт зовнішньої нормалі до поверхні магніту.

Для однорідно намагніченого постійного магніту намагніченість всередині об'єму є постійним вектором (`J = const`), тому об'ємна густина зарядів дорівнює нулю (`div J = 0`). Все магнітне поле за межами та всередині магніту утворюється виключно поверхневими магнітними полюсами зі щільністю `σ_m`.

У довільній точці простору `r` скалярний магнітний потенціал визначається поверхневим інтегралом типу потенціалу простого шару:

```
Ψ(r) = (1 / (4·π·μ₀)) · ∮ [ (n · J) / |r - r'| ] dS'
```

Взяття градієнта від цього потенціалу `H = -∇Ψ` дозволяє розрахувати магнітне поле у будь-якій точці. Усередині магнітного тіла вектори поля, утворені цими поверхневими зарядами, спрямовані від позитивно зарядженого північного полюса до негативно зарядженого південного полюса. Це поле діє строго назустріч вектору намагніченості `J` і є внутрішнім розмагнічувальним полем `H_d`.

### 2. Математичні властивості тензора розмагнічування N_ij

Для тіл еліпсоїдальної форми (включаючи окремі граничні випадки сфери, циліндра та плоского диска) виявилося, що внутрішнє розмагнічувальне поле `H_d` при однорідній намагніченості `J = const` є строго однорідним по всьому об'єму тіла. У цьому випадку зв'язок між вектором розмагнічувального поля та вектором намагніченості описується лінійним тензорним співвідношенням:

```
H_d = -N_d · (J / μ₀)
```

де `N_d` — симетричний тензор розмагнічування другого рангу. Якщо сумістити декартові осі координат `(x, y, z)` з головними осями симетрії еліпсоїда, тензор `N_d` зводиться до діагонального вигляду з трьома головними компонентами `(N_x, N_y, N_z)`.

Доведемо теорему про суму головних компонент тензора розмагнічування. Для цього розглянемо слід тензора `Tr(N_d) = N_x + N_y + N_z`. Згідно з диференціальним рівнянням Пуассона для потенціалу однорідно зарядженого еліпсоїда, сума других похідних потенціалу по трьох осях дорівнює одиниці. Оскільки сумарний внесок усіх трьох компонент поверхневого інтеграла по замкненій поверхні охоплює повний тілесний кут `4·π` стерадіан, отримуємо фундаментальне правило нормалізації:

```
N_x + N_y + N_z = 1
```

Це співвідношення дає можливість строго вивести коефіцієнти розмагнічування для симетричних тіл без обчислення складних інтегралів:

1. **Ідеальна куля:** Завдяки повній ізотропії та тривимірній симетрії сфери компоненти по всіх трьох осях повинні бути тотожно рівними між собою (`N_x = N_y = N_z`). З умови нормалізації `N_x + N_y + N_z = 3·N_x = 1` негайно випливає точне значення:
```
N_x = N_y = N_z = 1 / 3
```

2. **Тонкий плоский диск (пластина):** Якщо диск розташований у площині `xy`, а його товщина вздовж осі `z` прямує до нуля, то для поздовжніх напрямків поверхневі заряди віддалені на нескінченність, отже розмагнічування у площині відсутнє (`N_x = N_y = 0`). Тоді з умови нормалізації отримуємо значення для поперечного намагнічування:
```
N_z = 1
```

3. **Нескінченно довгий циліндр:** Якщо вісь циліндра збігається з віссю `z`, то при намагнічуванні вздовж осі полюси рознесені на нескінченну відстань, отже `N_z = 0`. З поперечної симетрії `N_x = N_y`. Тоді `N_x + N_y = 2·N_x = 1`, що дає:
```
N_x = N_y = 1 / 2,   N_z = 0
```

Для витягнутого еліпсоїда обертання з піввісями `a = b < c` (де `k = c / a > 1` — співвідношення осей) точний аналітичний вираз для поздовжнього коефіцієнта розмагнічування `N_z` отримують шляхом інтегрування потенціалу в еліптичних координатах:

```
N_z = (1 / (k² - 1)) · [ (k / (2·√(k² - 1))) · ln((k + √(k² - 1)) / (k - √(k² - 1))) - 1 ]
```

При великих відношеннях довжини до діаметра (`k >> 1`) ця формула дає корисне інженерне наближення:

```
N_z ≈ (ln(2·k) - 1) / k²
```

### 3. Системний вивід рівняння магнітного кола з витоками потоку

Розглянемо магнітне коло, що складається з постійного магніту (довжина `l_m`, площа перерізу `A_m`), м'якомагнітного залізного магнітопроводу (довжина `l_y`, площа `A_y`, відносна проникність `μ_y`) та робочого повітряного зазору (довжина `l_g`, площа `A_g`).

Застосуємо циркуляційний закон Ампера для вектора напруженості магнітного поля `H` по замкненому контуру, що проходить через центр магніту, осердя та повітряний зазор:

```
§ H · dl = ∑ I_ext
```

Оскільки зовнішні електричні струми провідності, що охоплюють контур, відсутні (`∑ I_ext = 0`), інтеграл розпадається на суму трьох доданків:

```
H_m·l_m + H_y·l_y + H_g·l_g = 0
```

Виразимо поле у залізному магнітопроводі через магнітну індукцію `B_y` та магнітний опір матеріалу `H_y = B_y / (μ_y · μ₀)`. Оскільки для трансформаторної сталі або пермалою відносна магнітна проникність становить `μ_y ≈ 3000...10000`, падінням магнітного потенціалу в залізі можна знехтувати порівняно з високим опором повітряного зазору:

```
H_y·l_y = (B_y · l_y) / (μ_y · μ₀) ≈ 0
```

Це зводить циркуляційне рівняння до строгого співвідношення між полем усередині магніту та полем у зазорі:

```
H_m·l_m + H_g·l_g = 0  ⇒  H_m = -H_g · (l_g / l_m)
```

Тепер застосуємо теорему Гаусса для вектора магнітної індукції `div B = 0`. Повний магнітний потік, що виходить із північного полюса магніту `Φ_m = B_m · A_m`, ділиться на корисний потік, який проходить через робочий повітряний зазор `Φ_g = B_g · A_g`, та потік розсіювання (витоків) `Φ_leak`, який замикається через повітря довкола магнітопроводу:

```
Φ_m = Φ_g + Φ_leak
B_m · A_m = B_g · A_g + Φ_leak
```

Введемо коефіцієнт розсіювання магнітного потоку `f_l ≥ 1`, який визначається як відношення повного потоку магніту до корисного потоку в зазорі:

```
f_l = Φ_m / Φ_g = (B_m · A_m) / (B_g · A_g)
```

Звідси виразимо індукцію у повітряному зазорі `B_g`:

```
B_g = (B_m · A_m) / (f_l · A_g)
```

У повітряному зазорі середовищем є вакуум або повітря з проникністю `μ₀`, тому напруженість поля в зазорі зв'язана з індукцією прямим співвідношенням `H_g = B_g / μ₀`. Підставимо вираз для `B_g` у рівняння напруженості зазору:

```
H_g = (B_m · A_m) / (μ₀ · f_l · A_g)
```

Тепер підставимо отриманий вираз для `H_g` у циркуляційне рівняння для поля магніту `H_m = -H_g · (l_g / l_m)`:

```
H_m = - [ (B_m · A_m) / (μ₀ · f_l · A_g) ] · (l_g / l_m)
```

Поділивши обидві частини рівняння на `B_m` та перегрупувавши співвідношення величин, отримуємо фундаментальне рівняння **робочої лінії** (*load line*):

```
B_m / H_m = -μ₀ · f_l · (A_g / A_m) · (l_m / l_g)
```

Модуль цього відношення називають **коефіцієнтом провідності** (*permeance coefficient*, `P_c`):

```
P_c = |B_m / H_m| = μ₀ · f_l · (A_g · l_m) / (A_m · l_g)
```

Для окремо розташованого магніту у відкритому просторі (без залізного осердя) коефіцієнт провідності `P_c` зв'язаний із геометричним коефіцієнтом розмагнічування `N_d` через точне співвідношення:

```
P_c = μ₀ · (1 - N_d) / N_d
```

Рівняння `B = -P_c · H` описує пряму лінію, яка проходить через початок координат у другому квадранті. Кут нахилу цієї лінії визначається виключно геометричними параметрами магнітної системи `l_m, A_m, l_g, A_g` та витоками `f_l`.

### 4. Варіаційне доведення умови оптимізації об'єму магніту при (BH)_max

З'ясуємо, як вибрати геометричні параметри магніту `l_m` та `A_m`, щоб створити у зазорі заданий об'єм магнітного поля `V_g = A_g · l_g` із заданою індукцією `B_g` при **мінімально можливому об'ємі магнітного матеріалу `V_m = A_m · l_m`**.

Густина енергії магнітного поля у повітряному зазорі дорівнює:

```
w_g = (1 / 2) · B_g · H_g = (1 / 2 · μ₀) · B_g²
```

Повна магнітна енергія `W_g`, яка зберігається у зазорі, становить:

```
W_g = w_g · V_g = (1 / 2) · B_g · H_g · A_g · l_g
```

Виразимо параметри зазору `B_g` та `H_g` через параметри робочої точки магніту `B_m` та `H_m`, використовуючи виведені раніше співвідношення `B_g = (B_m · A_m) / (f_l · A_g)` та `H_g = -H_m · (l_m / l_g)`:

```
W_g = (1 / 2) · [ (B_m · A_m) / (f_l · A_g) ] · [ -H_m · (l_m / l_g) ] · (A_g · l_g)
```

Скоротивши площу `A_g` та довжину `l_g` у чисельнику та знаменнику, отримуємо:

```
W_g = (1 / 2 · f_l) · (B_m · (-H_m)) · (A_m · l_m)
```

Ураховуючи, що добуток `A_m · l_m` є повним об'ємом постійного магніту `V_m`, виразимо об'єм `V_m` як функцію робочої точки `(H_m, B_m)`:

```
V_m = (2 · f_l · W_g) / (B_m · (-H_m))
```

Щоб знайти мінімум об'єму магніту `V_m` при фіксованій енергії зазору `W_g`, необхідно знайти максимум знаменника `E(H) = B_m(H) · (-H)`. Продиференціюємо функцію `E(H)` по напруженості `H`:

```
d(B · (-H)) / dH = 0
(-H) · (dB / dH) + B · (-1) = 0
H · (dB / dH) + B = 0
dB / dH = -B / H
```

Оскільки за визначенням робочої лінії відношення `-B / H` дорівнює коефіцієнту провідності `P_c`, умова мінімуму об'єму магніту формулюється так: **нахил дотичної до кривої розмагнічування `dB/dH` у робочій точці повинен дорівнювати від'ємному нахилу робочої лінії `-P_c`**.

Геометрично це означає, що точка максимуму енергетичного добутку `(BH)_max` є точкою дотику гіперболи `B · H = const` до індукційної кривої розмагнічування `B(H)` у другому квадранті. Вибір геометрії магніту відповідно до цієї умови дозволяє зменшити масу та вартість магнітної системи до фізично можливого мінімуму.
