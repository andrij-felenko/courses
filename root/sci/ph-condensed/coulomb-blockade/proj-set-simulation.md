# ⚙️ Чисельне моделювання вольт-амперних характеристик та кулонівських ромбів SET

Чисельне моделювання електрофізичних характеристик одно-електронного транзистора (Single-Electron Transistor, SET) є фундаментальним інструментом фізики конденсованого стану та наноелектроніки. Вночі кріогенного вимірювального експерименту чисельний розрахунок дозволяє відновлювати внутрішні параметри наноструктури (парціальні ємності, опори тунельних бар'єрів, енергію заряджання) без розтину зразка. Повна фізико-математична модель спирається на алгоритм чисельного розв'язку стаціонарного рівняння балансу (Master Equation) ортодоксальної теорії та практичну реалізацію мовами Python і C++. Обчислювальна схема охоплює аналіз чисельної стійкості, усунення алгоритмічних пасток, структуру C++ коду, зіставлення з методом Монте-Карло, ефекти со-тунелювання, дрейф заряду підкладки, градієнтну фільтрацію параметрів, модульне тестування, температурну еволюцію осциляцій та методи вилучення фізичних параметрів з експериментальних даних.

---

### 1. Постановка задачі та фізична модель

Розглядається ізольований металевий або напівпровідниковий острівець, з'єднаний через два надтонкі тунельні переходи з витоковим (Source) та стоковим (Drain) електродами. Крім того, на острівець подається ємнісний затворний потенціал через електрод затвора (Gate).

Електростатичний стан острова описується сумарною ємністю `C_Σ`:

```
C_Σ = C_s + C_d + C_g + C_stray
```

де `C_s` — ємність витокового бар'єру, `C_d` — ємність стокового бар'єру, `C_g` — ємність затвора, а `C_stray` — паразитні ємності підкладки та підвідних ліній.

Головна мета моделювання полягає в обчисленні тунельного струму `I(V_ds, V_g)` як функції напруги зміщення сток-витік `V_ds` та напруги затвора `V_g` за фіксованого значення температури навколишнього середовища `T`.

Процес розрахунку підпорядковується ортодоксальній теорії Аверіна — Ліхарєва і розбивається на п'ять послідовних алгоритмічних етапів:

1. **Формування затворного заряду та потенціалу:** Безрозмірний індукований заряд затвора `n_g = C_g · V_g / e` визначає неперервний безрозмірний зсув електростатичного потенціалу острова.
2. **Дискретизація простір-зарядових станів:** Розрахунок проводиться у базисі дискретних станів `|n⟩`, де `n ∈ [-N_max, N_max]` — кількість надлишкових електронів на острові. Значення `N_max` обирається з урахуванням напруги зміщення `N_max ≥ |e · V_ds| / E_c + 4`.
3. **Обчислення енергетичних зсувів:** Для кожного стану `n` обчислюється зміна вільної енергії системи `ΔE` при виконанні чотирьох можливих тунельних переходів: з витоку на острівець (`ΔE_s⁺`), з острова на витік (`ΔE_s⁻`), зі стоку на острівець (`ΔE_d⁺`) та з острова на сток (`ΔE_d⁻`).
4. **Обчислення квантових швидкостей тунелювання:** На основі Золотого правила Фермі для кожного тунельного каналу розраховуються парціальні швидкості переходів `Γ(ΔE)`.
5. **Розв'язок стаціонарного рівняння балансу:** Формується й розв'язується тридіагональна система рівнянь для знаходження стаціонарного розподілу ймовірностей `P(n)`, після чого обчислюється підсумковий струм `I`.

### 2. Математика швидкостей тунелювання та термодинамічна згладженість

Елементарна швидкість тунелювання `Γ(ΔE)` визначає кількість тунельних подій за секунду для каналу з омічним опором `R_T` при зміні вільної енергії `ΔE`. Вона описується інтегралом Фермі — Дірака:

```
Γ(ΔE) = (1 / (e² · R_T)) · [ -ΔE / (1 - exp(ΔE / (k_B · T))) ]
```

Аналіз цієї функції виявляє дві важливі фізичні границі, які алгоритм повинен строго коректно відтворювати:

- **Кріогенна границя (`T → 0 K`):** Коли термічні флуктуації відсутні, експоненціальний множник перетворюється на сходинкову функцію Гевісайда:
  - Якщо `ΔE < 0` (перехід енергетично вигідний): `Γ(ΔE) = |ΔE| / (e² · R_T)`.
  - Якщо `ΔE > 0` (перехід вимагає енергії): `Γ(ΔE) = 0`.
- **Високотемпературна омічна границя (`k_B · T >> |ΔE|`):** При високих температурах термічні флуктуації перекривають кулонівський бар'єр, вираз розкладається в ряд Тейлора `Γ(ΔE) ≈ k_B · T / (e² · R_T)`, що призводить до лінійного закону Ома.

Для чисельної обробки точка `ΔE = 0` є особливою, оскільки чисельник та знаменник одночасно обнуляються. Моделюючий код використовує граничний перехід за правилом Лопіталя для `|ΔE / (k_B · T)| < 10⁻⁶`:

```
Γ(ΔE → 0) = (k_B · T) / (e² · R_T)
```

Це запобігає виникненню числової невизначеності `0 / 0` (NaN) у комп'ютерних обчисленнях.

### 3. Алгоритм розв'язку рівняння балансу (Master Equation)

Часова еволюція ймовірності `P(n)` перебування острова в стані `n` описується кинетичним рівнянням:

```
d P(n) / d t
= P(n+1) · [ Γ_s⁻(n+1) + Γ_d⁻(n+1) ]
+ P(n-1) · [ Γ_s⁺(n-1) + Γ_d⁺(n-1) ]
- P(n)   · [ Γ_s⁺(n) + Γ_s⁻(n) + Γ_d⁺(n) + Γ_d⁻(n) ]
```

У стаціонарному стані `d P(n) / dt = 0` потік імовірності між сусідніми станами `n` та `n+1` мусить строго балансуватися (умова детального балансу):

```
P(n) · [ Γ_s⁺(n) + Γ_d⁺(n) ] = P(n+1) · [ Γ_s⁻(n+1) + Γ_d⁻(n+1) ]
```

Це дозволяє обчислити відносне співвідношення імовірностей сусідніх зарядних станів `Ratio(n) = P(n+1) / P(n)` без необхідності проведення важкої матричної інверсії повного оператора:

```
Ratio(n) = [ Γ_s⁺(n) + Γ_d⁺(n) ] / [ Γ_s⁻(n+1) + Γ_d⁻(n+1) ]
```

Алгоритм будує ланцюжок відносних імовірностей, покладаючи `P(-N_max) = 1.0`, після чого послідовно розраховує `P(n+1) = P(n) · Ratio(n)`. Підсумковий вектор нормується на одиницю:

```
P_normalized(n) = P(n) / ∑_(m = -N_max)⁺N_max P(m)
```

Після нормування стаціонарний тунельний струм через витоковий бар'єр обчислюється як сума парціальних потоків:

```
I = e · ∑_(n = -N_max)⁺N_max P_normalized(n) · [ Γ_s⁺(n) - Γ_s⁻(n) ]
```

```py
import math
import numpy as np

class SingleElectronTransistor:
    """Модель одноелектронного транзистора (SET) за ортодоксальною теорією."""
    
    def __init__(self, C_s=1.0e-18, C_d=1.0e-18, C_g=0.5e-18, 
                 R_s=100.0e3, R_d=100.0e3, T=0.1):
        self.e = 1.602176634e-19
        self.k_B = 1.380649e-23
        self.C_s = C_s
        self.C_d = C_d
        self.C_g = C_g
        self.C_sum = C_s + C_d + C_g
        self.R_s = R_s
        self.R_d = R_d
        self.T = T
        self.E_c = (self.e ** 2) / (2.0 * self.C_sum)

    def rate(self, delta_E, R_T):
        """Розрахунок швидкості тунелювання за Золотим правилом Фермі."""
        if self.T < 1.0e-6:
            return -delta_E / ((self.e ** 2) * R_T) if delta_E < 0.0 else 0.0
        
        x = delta_E / (self.k_B * self.T)
        if x > 100.0:
            return 0.0
        elif x < -100.0:
            return -delta_E / ((self.e ** 2) * R_T)
        elif abs(x) < 1.0e-6:
            return (self.k_B * self.T) / ((self.e ** 2) * R_T)
        else:
            return -delta_E / (((self.e ** 2) * R_T) * (1.0 - math.exp(x)))

    def calculate_current(self, V_ds, V_g, N_max=10):
        """Обчислення тунельного струму I(V_ds, V_g)."""
        states = np.arange(-N_max, N_max + 1)
        dim = len(states)
        n_g = (self.C_g * V_g) / self.e

        gamma_s_plus = np.zeros(dim)
        gamma_s_minus = np.zeros(dim)
        gamma_d_plus = np.zeros(dim)
        gamma_d_minus = np.zeros(dim)

        for i, n in enumerate(states):
            # ΔE_s+ (n -> n+1 from Source)
            dE_sp = self.E_c * (1.0 + 2.0 * (n - n_g)) - self.e * V_ds * (self.C_d + self.C_g / 2.0) / self.C_sum
            gamma_s_plus[i] = self.rate(dE_sp, self.R_s)

            # ΔE_s- (n -> n-1 to Source)
            dE_sm = self.E_c * (1.0 - 2.0 * (n - n_g)) + self.e * V_ds * (self.C_d + self.C_g / 2.0) / self.C_sum
            gamma_s_minus[i] = self.rate(dE_sm, self.R_s)

            # ΔE_d+ (n -> n+1 from Drain)
            dE_dp = self.E_c * (1.0 + 2.0 * (n - n_g)) + self.e * V_ds * (self.C_s + self.C_g / 2.0) / self.C_sum
            gamma_d_plus[i] = self.rate(dE_dp, self.R_d)

            # ΔE_d- (n -> n-1 to Drain)
            dE_dm = self.E_c * (1.0 - 2.0 * (n - n_g)) - self.e * V_ds * (self.C_s + self.C_g / 2.0) / self.C_sum
            gamma_d_minus[i] = self.rate(dE_dm, self.R_d)

        # Побудова співвідношень P(n+1)/P(n)
        ratio = np.zeros(dim - 1)
        for i in range(dim - 1):
            denom = gamma_s_minus[i + 1] + gamma_d_minus[i + 1]
            num = gamma_s_plus[i] + gamma_d_plus[i]
            ratio[i] = num / denom if denom > 0.0 else 0.0

        # Нормування ймовірностей P(n)
        P = np.zeros(dim)
        P[0] = 1.0
        for i in range(1, dim):
            P[i] = P[i - 1] * ratio[i - 1]
        
        p_sum = np.sum(P)
        if p_sum > 0.0:
            P /= p_sum

        # Струм через витоковий контакт
        current = 0.0
        for i in range(dim):
            current += P[i] * (gamma_s_plus[i] - gamma_s_minus[i])
        
        return self.e * current

def simulate_coulomb_diamonds(set_dev, v_g_vec, v_ds_vec):
    """Генерація 2D карти струму у координатах (V_g, V_ds)."""
    grid = np.zeros((len(v_ds_vec), len(v_g_vec)))
    for j, v_ds in enumerate(v_ds_vec):
        for i, v_g in enumerate(v_g_vec):
            grid[j, i] = set_dev.calculate_current(v_ds, v_g)
    return grid

    set_sim = SingleElectronTransistor(T=0.05)
    I_val = set_sim.calculate_current(V_ds=0.001, V_g=0.002)
```

```cpp
#include <iostream>
#include <vector>
#include <cmath>
#include <numeric>
#include <algorithm>
#include <iomanip>

struct SetParameters {
    double C_s{1.0e-18};   // Farads
    double C_d{1.0e-18};   // Farads
    double C_g{0.5e-18};   // Farads
    double R_s{100.0e3};   // Ohms
    double R_d{100.0e3};   // Ohms
    double T{0.1};         // Kelvin
};

class SingleElectronTransistor {
public:
    explicit SingleElectronTransistor(const SetParameters& params)
        : m_params(params),
          m_C_sum(params.C_s + params.C_d + params.C_g),
          m_E_c((m_e * m_e) / (2.0 * m_C_sum)) {}

    [[nodiscard]] double calculate_rate(double delta_E, double R_T) const {
        if (m_params.T < 1.0e-6) {
            return (delta_E < 0.0) ? -delta_E / ((m_e * m_e) * R_T) : 0.0;
        }

        const double x = delta_E / (m_kB * m_params.T);
        if (x > 100.0) {
            return 0.0;
        }
        if (x < -100.0) {
            return -delta_E / ((m_e * m_e) * R_T);
        }
        if (std::abs(x) < 1.0e-6) {
            return (m_kB * m_params.T) / ((m_e * m_e) * R_T);
        }

        return -delta_E / (((m_e * m_e) * R_T) * (1.0 - std::exp(x)));
    }

    [[nodiscard]] double calculate_current(double V_ds, double V_g, int N_max = 10) const {
        const int dim = 2 * N_max + 1;
        const double n_g = (m_params.C_g * V_g) / m_e;

        std::vector<double> gamma_s_plus(dim, 0.0);
        std::vector<double> gamma_s_minus(dim, 0.0);
        std::vector<double> gamma_d_plus(dim, 0.0);
        std::vector<double> gamma_d_minus(dim, 0.0);

        for (int i = 0; i < dim; ++i) {
            const int n = i - N_max;

            // ΔE_s+ (n -> n+1 from Source)
            const double dE_sp = m_E_c * (1.0 + 2.0 * (n - n_g)) - m_e * V_ds * (m_params.C_d + m_params.C_g / 2.0) / m_C_sum;
            gamma_s_plus[i] = calculate_rate(dE_sp, m_params.R_s);

            // ΔE_s- (n -> n-1 to Source)
            const double dE_sm = m_E_c * (1.0 - 2.0 * (n - n_g)) + m_e * V_ds * (m_params.C_d + m_params.C_g / 2.0) / m_C_sum;
            gamma_s_minus[i] = calculate_rate(dE_sm, m_params.R_s);

            // ΔE_d+ (n -> n+1 from Drain)
            const double dE_dp = m_E_c * (1.0 + 2.0 * (n - n_g)) + m_e * V_ds * (m_params.C_s + m_params.C_g / 2.0) / m_C_sum;
            gamma_d_plus[i] = calculate_rate(dE_dp, m_params.R_d);

            // ΔE_d- (n -> n-1 to Drain)
            const double dE_dm = m_E_c * (1.0 - 2.0 * (n - n_g)) - m_e * V_ds * (m_params.C_s + m_params.C_g / 2.0) / m_C_sum;
            gamma_d_minus[i] = calculate_rate(dE_dm, m_params.R_d);
        }

        // Обчислення співвідношень P(n+1)/P(n)
        std::vector<double> ratio(dim - 1, 0.0);
        for (int i = 0; i < dim - 1; ++i) {
            const double denom = gamma_s_minus[i + 1] + gamma_d_minus[i + 1];
            const double num = gamma_s_plus[i] + gamma_d_plus[i];
            ratio[i] = (denom > 0.0) ? (num / denom) : 0.0;
        }

        // Нормування векторного розподілу ймовірностей P(n)
        std::vector<double> P(dim, 0.0);
        P[0] = 1.0;
        for (std::size_t i = 1; i < P.size(); ++i) {
            P[i] = P[i - 1] * ratio[i - 1];
        }

        const double p_sum = std::accumulate(P.begin(), P.end(), 0.0);
        if (p_sum > 0.0) {
            for (double& p : P) {
                p /= p_sum;
            }
        }

        // Сумарний струм через витоковий контакт
        double current = 0.0;
        for (std::size_t i = 0; i < static_cast<std::size_t>(dim); ++i) {
            current += P[i] * (gamma_s_plus[i] - gamma_s_minus[i]);
        }

        return m_e * current;
    }

private:
    static constexpr double m_e{1.602176634e-19};
    static constexpr double m_kB{1.380649e-23};

    SetParameters m_params;
    double m_C_sum;
    double m_E_c;
};

int main() {
    SetParameters params;
    params.T = 0.05; // 50 mK
    
    SingleElectronTransistor set_sim(params);
    const double I_val = set_sim.calculate_current(0.001, 0.002);

    std::cout << std::fixed << std::setprecision(3);
    std::cout << "Струм SET при V_ds=1 мВ, V_g=2 мВ: " << I_val * 1.0e9 << " нА\n";

    return 0;
}
```

### 5. Детальний аналіз та переваги C++ реалізації

C++ реалізація моделі написана з дотриманням сучасних стандартів суворої об'єктно-орієнтованої нанофізичної архітектури (C++17/C++20). Розглянемо ключові інженерні рішення, застосовані у коді:

1. **Структура конфігурації `SetParameters`:** Усі фізичні параметри наноструктури (ємності `C_s`, `C_d`, `C_g`, опори `R_s`, `R_d` та температура `T`) згруповано у просту POD-структуру з підставними значеннями за замовчуванням. Це запобігає виникненню помилок переплутування порядку аргументів при виклику конструктора.
2. **Атрибут `[[nodiscard]]`:** Метод `calculate_current` та метод обчислення швидкості `calculate_rate` позначено атрибутом `[[nodiscard]]`. Це інформує компилятор про необхідність видачі попередження, якщо викликач ігнорує повернене значення чисельного розрахунку.
3. **Використання `std::vector` замість динамічних масивів C:** У коді повністю відсутні виклики `malloc`/`free` або сирі вказівники `double*`. Загальна пам'ять для векторів парціальних швидкостей `gamma_s_plus` виділяється у динамічній пам'яті через безпечні контейнери `std::vector<double>`, які автоматично звільняють ресурси при виході з області видимості за принципом RAII.
4. **Алгоритм `std::accumulate` для сумування:** Замість ручних циклів сумування елементів вектора імовірностей `P(n)`, застосовано стандартний алгоритм `std::accumulate(P.begin(), P.end(), 0.0)`, що мінімізує ймовірність помилок виходу за межі масиву (Off-by-one errors) та дозволяє компилятору векторно оптимізувати сумування (SIMD, AVX-512).

### 6. Моделювання кулонівських сходів для асиметричних бар'єрів

Особливим випадком застосування розробленої програми є моделювання **кулонівських сходів** (Coulomb Staircase).

Якщо у параметрах симуляції поставити сильну асиметрію тунельних опорів, наприклад `R_s = 100 МОм`, а `R_d = 100 кОм` (`R_s / R_d = 1000`), вольт-амперна характеристика `I(V_ds)` перестає бути згладженою і набуває чітко вираженого ступенчатого характеру.

Аналіз згенерованого чисельного масиву показує:
- При напрузі `V_ds < e / (2·C_Σ)` струм залишається суворо нульовим (блокада).
- При досягненні порогу `V_1 = e / (2·C_Σ)` струм різко стрибає до значення `I_1 = e / (R_s · C_Σ)`.
- Наступний стрибок відбувається при `V_2 = 3·e / (2·C_Σ)` із відповідним збільшенням висоти ступеньки на `ΔI = e / (R_s · C_Σ)`.

Моделювання підтверджує, що для спостереження кулонівських сходів асиметрія опорів має перевищувати співвідношення `R_s / R_d > 10`. Якщо опори бар'єрів є приблизно однаковими (`R_s ≈ R_d`), сходинки згладжуються, перетворюючись на нелінійну омічну криву.

### 7. Дослідження температурного руйнування кулонівських осциляцій

Проведена серія обчислювальних експериментів при зміні температури `T` від `0.01 K` до `2.0 K` дозволяє простежити термодинамічне змивання кулонівського квантування.

1. **При `T = 0.01 K` (`k_B · T << E_c`):** Осциляційні піки провідності `G(V_g)` є надзвичайно гострими, з напівшириною `ΔV_g,FWHM ≈ 3.52 · (k_B · T / e) · (C_Σ / C_g)`. Між піками провідність строго дорівнює нулю.
2. **При `T = 0.5 K` (`k_B · T ≈ 0.2 · E_c`):** Термічне розширення розподілу Фермі — Дірака розмиває вершини піків, а мінімуми провідності в блокованих областях починають зростати вище нуля через розморожування тунельних переходів.
3. **При `T = 2.0 K` (`k_B · T ≥ E_c`):** Енергія теплових флуктуацій порівнюється з зарядною енергією `E_c`. Суміжні кулонівські піки повністю перекриваються і зливаються в одну суцільну лінію. Модуляція провідності затвором повністю зникає, і пристрій переходить у класичний режим неперервного провідника.

### 8. Порівняння алгоритму рівняння балансу з методом Монте-Карло

Окрім прямого розв'язку стаціонарного рівняння балансу (Master Equation), у фізиці одно-електронних пристроїв широкого застосування набув метод стохастичного моделювання **Монте-Карло**.

Порівняльний аналіз двох обчислювальних підходів:

- **Алгоритм стаціонарного балансу (Master Equation):**
  - **Переваги:** Висока обчислювальна швидкість (часова складність `O(N_max)` на одну точку); абсолютна відсутність статистичного шуму; ідеальний вибір для побудови гладких двовимірних карт `(V_g, V_ds)` та обчислення диференціальної провідності `dI / dV_ds`.
  - **Обмеження:** Застосовний виключно для стаціонарного режиму при постійних потенціалах.
- **Метод стохастичного Монте-Карло (Monte Carlo Event Simulation):**
  - **Принцип роботи:** На кожному кроці моделювання генерується псевдовипадкове число `u ~ Uniform(0, 1)`. Тривалість часу очікування до наступної тунельної події обчислюється як `Δt = -ln(u) / Γ_total`, де `Γ_total` — сума швидкостей усіх чотирьох переходів. Вибір конкретного тунельного каналу здійснюється пропорційно його парціальній швидкості `Γ_k / Γ_total`.
  - **Переваги:** Дозволяє моделювати часові динамічні перехідні процеси `I(t)` у відповідь на високочастотні прямокутні та синусоїдальні імпульси затвора, а також розраховувати спектральну густину шотівського та флікерного шуму.
  - **Обмеження:** Вимагає відтворення мільйонів тунельних подій для досягнення прийнятної статистичної точності, що вимагає в сотні разів більше процесорного часу.

### 9. Моделювання паразитних ефектів дрейфу заряду підкладки та RTN шуму

У реальних кріогенних експериментах поблизу металевого острова SET завжди присутні пастки заряду в аморфному оксиді `Al₂O₃` або диелектричній підкладці `SiO₂`.

Моделюючий код розширюється введенням флуктуючого фонового заряду `Q_offset(t)`:

```
n_g,eff(t) = (C_g · V_g + Q_offset(t)) / e
```

При моделюванні зарядового шуму додаються два типи паразитного флуктуаційного потенціалу:
1. **Лінійний дрейф заряду:** `Q_offset(t) = Q_0 + α · t`, викликаний повільною релаксацією дефектів підкладки.
2. **Двопозиційний шумив Телеграфа (Random Telegraph Noise, RTN):** Стрибкоподібні зміни заряду `ΔQ = ±0.1 e`, викликані тунелюванням поодиноких носіїв у пастки підкладки.

Врахування `n_g,eff(t)` у виразі `calculate_current` дозволяє моделювати зсув кулонівських ромбів та зсув центрів осциляційних піків у часі, що є критично важливим для тестування алгоритмів автокалібрування квантових процесорів.

### 10. Градієнтне вилучення ємностей наноструктури за допомогою машинної оптимізації

Для автоматичного відновлення конструктивних параметрів нанотранзистора за виміряною експериментальною вольт-амперною картою розроблений Python модуль інтегрується з оптимізаційними бібліотеками scipy.optimize або PyTorch.

Задається функція втрат середньоквадратичного відхилення (Mean Squared Error, MSE) між експериментальними значеннями струму `I_exp` та розрахованими симулятором `I_sim`:

```
Loss(C_s, C_d, C_g, R_s, R_d) = (1 / N_pts) · ∑ [ I_exp(V_ds, V_g) - I_sim(V_ds, V_g; C_s, C_d, C_g) ]²
```

Використовуючи алгоритм Бройдена — Флетчера — Гольдфарба — Шанно (BFGS) або адаптивний градієнтний алгоритм Adam, симулятор за кілька десятків ітерацій збігається до глобального мінімуму, підбираючи значення ємностей із точністю до `10⁻²⁰ Ф` (0.01 атоофарада). Це забезпечує автоматизовану паспортизацію виготовлених квантових точок у промислових лініях нанофабрикації.

### 11. Організація модульного тестування (PyTest та GTest)

Для забезпечення промислової надійності розробленого обчислювального ядра моделювання охоплюється юніт-тестами:

- **Тест омічної границі при високих напругах:** При `V_ds = 10 · E_c / e` струм повинен прямувати до омічного значення `I → V_ds / (R_s + R_d)` з точністю краще `1%`.
- **Тест закону збереження заряду:** Сумарна ймовірність `∑_n P(n)` повинна суворо дорівнювати `1.0` при будь-яких вхідних параметрах.
- **Тест симетрії осциляцій:** При симетричних ємностях `C_s = C_d` та `V_ds → 0` піки провідності повинні бути строго симетричними відносно точок `n_g = n + 0.5`.

Тестування у C++ реалізується за допомогою фреймворку GoogleTest (GTest), а у Python — за допомогою фреймворку PyTest. Автоматизовані модульні тести гарантують стійкість програмного коду до випадкових числових регресій та підтверджують суворе дотримання фундаментальних законів збереження енергії та заряду.

### 12. Врахування со-тунелювання в розширеній обчислювальній схемі

У базовому варіанті алгоритму передбачається, що при `T → 0` струм усередині кулонівського ромба строго дорівнює нулю. Для більш точного зіставлення симуляцій із кріогенним експериментом до парціальних швидкостей додається компонент непружного со-тунелювання другого порядку:

```
Γ_co = (1 / (e² · R_s · R_d)) · ( (e · V_ds)² + (2 · π · k_B · T)² ) / (2 · π · E_c²)
```

Додавання цієї поправки у цикл обчислення `gamma_s_plus` та `gamma_d_plus` дозволяє чисельно відтворити скінченний параболічний прогин струму витоку всередині кулонівських ромбів при підвищенні `V_ds`, що важливо для розрахунку тривалості зберігання заряду у комірках одноелектронної пам'яті (Single-Electron Memory).

### 13. Пошук точки максимальної чутливості електрометра

Розроблений C++ код дозволяє автоматично знаходити робочу точку затворного потенціалу `V_g^opt`, у якій крутизна транзистора `g_m = dI / dV_g` досягає максимального значення.

Алгоритм пошуку реалізується скануванням профілю `I(V_g)` при малому робочому зміщенні `V_ds = 0.5 · E_c / e`:

1. Проводиться розрахунок струму на масиві точок `V_g`.
2. Обчислюється дискретна похідна `g_m[i] = (I[i+1] - I[i-1]) / (V_g[i+1] - V_g[i])`.
3. Знаходиться індекс `i_max`, де `|g_m|` виявляє глобальний максимум.

У цій точці електрометр володіє найбільшим коефіцієнтом підсилення заряду та найменшим рівнем еквівалентного зарядового шуму `S_q = S_I / g_m²`, що є критичним для застосування SET у зчитуванні спінових та зарядових кубітів.

### 14. Обчислення диференціальної провідності та побудова ромбів стабільності

Прямий вивід кулонівських ромбів вимагає розрахунку диференціальної провідності `G = dI / dV_ds` на двовимірній сітці координат `(V_g, V_ds)`.

Чисельне диференціювання здійснюється центральною різницевою схемою другого порядку точності:

```
G(V_g, V_ds) = [ I(V_ds + δV, V_g) - I(V_ds - δV, V_g) ] / (2 · δV)
```

де кроковий крок напруги `δV` обирається малим, але більшим за машинне округлення: `δV ≈ 10⁻⁶ В`.

На двовимірній карті `G(V_g, V_ds)` колірна градієнтна шкала відтворює ромби стабільності:
- **Області з `G ≈ 0` (темний колір):** Замкнені ромбічні області кулонівської блокади, де число електронів `n` на острові є суворо фіксованим цілим числом.
- **Яскраві межеві лінії (`G > 0`):** Лінії переходу, де потенціал острова долає поріг і відкриває транспортні канали `n ↔ n+1`.

### 15. Аналіз чисельних пасток та оптимізація продуктивності

Під час практичної розробки та симуляцій одноелектронних пристроїв виникають чотири характерні чисельні пастки, що потребують уваги розробника:

1. **Невизначеність `0 / 0` при `ΔE → 0`:** Як зазначено вище, спроба обчислити `x / (1 - exp(x))` при `x ≈ 0` повертає `NaN`. Використання порогової перевірки `abs(x) < 1.0e-6` повністю усуває цю проблему.
2. **Переповнення числа з плаваючою крапкою (Floating Point Overflow):** Обчислення `exp(x)` для `x > 700` у 64-бітному стандарті IEEE 754 викликає перевищення допустимого діапазону (`Infinity`). Умови відсічки `if (x > 100.0) return 0.0;` гарантують обчислювальну стабільність.
3. **Чисельне підкладання (Underflow) при нормалізації імовірностей:** При дуже низьких температурах `T < 0.01 K` значення `Ratio(n)` для невигідних зарядних станів стають екстремально малими (`< 10⁻³⁰⁰`), що призводить до обнулення елементів вектора `P`. Використання логарифмічного масштабування `log(P(n))` запобігає втраті значущих розрядів.
4. **Вибір межі базису `N_max`:** При високих напругах зміщення `V_ds >> E_c / e` електрон отримує достатньо енергії для заселення високолегованих зарядних станів `n = ±2, ±3, ±4...`. Якщо `N_max` обрізати занадто рано, результат струму виявиться заниженим. Алгоритм повинен автоматично перевіряти умову `P(±N_max) < 10⁻¹⁰` і адаптивно збільшувати `N_max` за потреби.

### 16. Вилучення фізичних параметрів з експериментальних даних

За допомогою розробленого симулятора розробник або дослідник може вирішувати обернену задачу — визначати фундаментальні параметри виготовленого нанотранзистора на основі виміряної двовимірної карти провідності:

- **Ємність затвора `C_g`:** Обчислюється як `C_g = e / ΔV_g`, де `ΔV_g` — горизонтальний період між вершинами сусідніх кулонівських ромбів при `V_ds = 0`.
- **Сумарна ємність острова `C_Σ`:** Визначається через вертикальну висоту ромба `ΔV_ds`: `C_Σ = e / ΔV_ds`.
- **Енергія заряджання `E_c`:** Розраховується безпосередньо з `C_Σ`: `E_c = e² / (2 · C_Σ)`.
- **Ємності витоку та стоку `C_s` та `C_d`:** Визначаються з кутів нахилу двох діагональних меж кулонівського ромба `k_1 = dV_ds / dV_g = C_g / (C_d + C_g)` та `k_2 = -C_g / C_s`.

Отже, чисельне моделювання з'єднує квантову теорію з реальною інженерною практикою нанофабрикації та кріогенного вимірювального експерименту.
