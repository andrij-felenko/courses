# 🧮 Квантово-механічна зонна структура та вектор хіральності CNT

Ця математична вставка містить аналітичне виведення електронної зонної структури вуглецевих нанотрубок методом зонного згортання (zone folding) у наближенні сильного зв'язку (tight-binding) та математичне доведення умов металічності за індексами хіральності.

## 1. Геометрія графенової ґратки та базисні вектори

Плоска двовимірна ґратка графену складається з двох еквівалентних підґраток `A` та `B` атомів вуглецю. Положення атомів у двовимірному просторі описується двома базисними векторами трансляції `a₁` та `a₂` у декартових координатах:

```
a₁ = (a·√3/2,  a/2)
a₂ = (a·√3/2, -a/2)
```

де `a = |a₁| = |a₂| = a_{C-C}·√3 ≈ 0.24613 нм` — стала ґратки графену, а `a_{C-C} ≈ 0.142 нм` — відстань між найближчими атомами вуглецю.

Вектор хіральності `C_h`, що з'єднує дві еквівалентні точки ґратки при згортанні площини у циліндр, виражається у базисі `(a₁, a₂)` як лінійна комбінація з цілими коефіцієнтами:

```
C_h = n·a₁ + m·a₂
```

Пара цілих чисел `(n, m)` називається індексами хіральності. Довжина вектора `C_h` дорівнює периметру або довжині кола нанотрубки `L`:

```
L = |C_h| = √(C_h · C_h)                           [означення довжини вектора]
= √((n·a₁ + m·a₂) · (n·a₁ + m·a₂))                [скалярний квадрат суми]
= √(n²·a₁² + 2·n·m·(a₁·a₂) + m²·a₂²)                [розкриття дужок]
= a · √(n² + n·m + m²)                            [оскільки a₁·a₂ = a²·cos(60°) = a²/2]
```

Зовнішній діаметр нанотрубки `d` визначається через довжину кола `L`:

```
d = L / π = (a / π) · √(n² + n·m + m²)
```

Кут хіральності `θ` між вектором хіральності `C_h` та вектором `a₁` обчислюється через скалярний добуток:

```
cos(θ) = (C_h · a₁) / (|C_h| · |a₁|)              [означення кута між векторами]
= (n·a₁² + m·a₁·a₂) / (L · a)                      [підстановка C_h = n·a₁ + m·a₂]
= (n·a² + m·a²/2) / (a² · √(n² + n·m + m²))        [оскільки a₁² = a² та a₁·a₂ = a²/2]
= (2n + m) / (2 · √(n² + n·m + m²))                [скорочення на a² та зведення дробу]
```

Кут `θ` лежить у діапазоні `0° ≤ θ ≤ 30°` внаслідок шестикратної ротаційної симетрії графенового листа:
- `θ = 0°` відповідає зигзагоподібним нанотрубкам `(n, 0)`;
- `θ = 30°` відповідає крісловим нанотрубкам `(n, n)`.

Вектор одномірної трансляції `T` вздовж осі циліндра перпендикулярний до `C_h` (`C_h · T = 0`) і розкладається за базисом як `T = t₁·a₁ + t₂·a₂`:

```
t₁ = (2m + n) / d_R
t₂ = -(2n + m) / d_R
```

де `d_R = gcd(2m + n, 2n + m)` — найбільший спільний дільник. Кількість елементарних шестикутників `N` у трансляційній комірці нанотрубки дорівнює:

```
N = (2 · (n² + n·m + m²)) / d_R
```

## 2. Модель сильного зв'язку для двовимірного графена

Для обчислення дисперсії `E(k)` розглянемо `π`-електрони графена у наближенні сильного зв'язку (tight-binding) з урахуванням взаємодії лише між найближчими сусідами. Хвильова функція електрона шукається у вигляді блохівської комбінації `2pz`-орбіталей двох атомів підґраток `A` та `B`:

```
Ψ_k(r) = C_A · Φ_A(k, r) + C_B · Φ_B(k, r)
```

Гамільтоніан системи у базисі атомних орбіталей зводиться до секулярного рівняння:

```
det(H(k) - E · S(k)) = 0
```

При нехтуванні інтегралом перекриття `S(k) ≈ I` діагональні елементи `H_{AA} = H_{BB} = ε_p` (енергія атомного `p`-рівня, прийнята за 0), а недіагональний елемент `H_{AB}(k)` виражається сумуванням за трьома векторами найближчих сусідів `δ₁, δ₂, δ₃`:

```
f(k) = ∑ exp(i · k · δ_j) = exp(i·k_y·a_cc) + 2·exp(-i·k_y·a_cc/2)·cos(k_x·a_cc·√3/2)
```

Енергетичний спектр `π`-зони провідності (`+`) та валентної `π*`-зони (`-`) графена набуває відомого аналітичного вигляду:

```
E(k_x, k_y) = ± t · |f(k)|
= ± t · √(1 + 4·cos(3·k_x·a/2)·cos(√3·k_y·a/2) + 4·cos²(√3·k_y·a/2))
```

де `t ≈ 2.7 еВ` — інтеграл перескоку (hopping integral) між сусідніми `2pz`-орбіталями. 

У вершинах першої зони Бріллюена — точках `K = (2·π/(a·√3), 2·π/(3·a))` та `K' = (2·π/(a·√3), -2·π/(3·a))` — функція `f(K) = 0`. Отже, енергетична щілина у цих точках дорівнює нулю `E(K) = 0`, і спектр біля точок `K` стає лінійним конусом (конус Дірака):

```
E(q) = ± ℏ · v_F · |q|
```

де `q = k - K` — відхилення хвильового вектора від Діракової точки, а `v_F = (3 · t · a_{C-C}) / (2 · ℏ) ≈ 10⁶ м/с` — фермієвська швидкість електрона.

## 3. Метод зонного згортання та граничні умови Борна — фон Кармана

При згортанні двовимірного листа графена у циліндр радіуса `R = d / 2` електричні стани вздовж перпендикулярного до осі напрямку підпорядковуються циклічній граничній умові Борна — фон Кармана:

```
Ψ(r + C_h) = Ψ(r) ⇒ exp(i · k · C_h) = 1
```

Це означає, що проекція хвильового вектора на напрямок вектора хіральності `C_h` дискретизується:

```
k · C_h = 2·π·q                       [q ∈ ℤ — ціле квантове число]
```

У той самий час вздовж осі нанотрубки (у напрямку вектора `T`) трубка вважається безкінечною, тому компонент хвильового вектора `k_z` змінюється неперервно у межах першої зони Бріллюена 1D-кристала: `-π/|T| ≤ k_z ≤ π/|T|`.

Таким образом, неперервна двовимірна зона Бріллюена графену розрізається на `N` паралельних 1D-ліній квантування (підзон), віддалених одна від одної на відстань `Δk_⊥ = 2/d`. 1D енергетичний спектр нанотрубки є набором зрізів двовимірного спектра графену:

```
E_q(k_z) = E_{graphene}(q · K₁ + k_z · K₂)
```

де `K₁` та `K₂` — базисні вектори оберненої ґратки нанотрубки, що відповідають вектором `C_h` та `T`.

## 4. Строге доведення умови металічності (n - m) mod 3 = 0

Нанотрубка є металом тоді й лише тоді, коли хоча б одна з дозволених ліній квантування `k · C_h = 2·π·q` проходить безпосередньо через Діракову точку `K`.

Вектори оберненої ґратки графену `b₁` та `b₂` визначаються умовою `a_i · b_j = 2·π·δ_{ij}`:

```
b₁ = (2·π/(a·√3),  2·π/a)
b₂ = (2·π/(a·√3), -2·π/a)
```

Координати Діракової точки `K` виражаються через вектори оберненої ґратки як:

```
K = (1/3) · (b₁ - b₂) = (2·π/(a·√3), 2·π/(3·a))
```

Обчислимо скалярний добуток точки `K` на вектор хіральності `C_h = n·a₁ + m·a₂`:

```
K · C_h = K · (n·a₁ + m·a₂)                        [дистрибутивність скалярного добутку]
= n · (K · a₁) + m · (K · a₂)                     [лінійність по векторах]
```

Знайдемо окремо скалярні добутки `K · a₁` та `K · a₂`:

```
K · a₁ = (2·π/(a·√3))·(a·√3/2) + (2·π/(3·a))·(a/2) [скалярний добуток координат]
= π + π/3                                         [скорочення спільних множників]
= 4·π/3                                           [додавання дробів]

K · a₂ = (2·π/(a·√3))·(a·√3/2) + (2·π/(3·a))·(-a/2) [скалярний добуток координат]
= π - π/3                                         [скорочення спільних множників]
= 2·π/3                                           [віднімання дробів]
```

Підставимо отримані значення у вираз для `K · C_h`:

```
K · C_h = n·(4·π/3) + m·(2·π/3)                   [підстановка скалярних добутків]
= (2·π/3) · (2n + m)                               [винесення спільного множника 2·π/3]
= (2·π/3) · (3n + m - n)                           [розклад 2n = 3n - n]
= 2·π·n + (2·π/3)·(m - n)                          [розкриття дужок]
```

Для того щоб точка `K` належала одній із дозволених ліній квантування `k · C_h = 2·π·q`, величина `K · C_h` повинна бути кратною `2·π`. Оскільки перша доданок `2·π·n` вже є кратним `2·π` для будь-якого цілого `n`, друга доданок `(2·π/3)·(m - n)` дорівнює `2·π·k` (для цілого `k`) тоді й лише тоді, коли різниця `(n - m)` ділиться на 3 без остачі:

```
(n - m) mod 3 = 0
```

**Висновок доведення:** 
- Усі нанотрубки, що задовольняють умову `(n - m) mod 3 = 0`, проходять через Діракову точку `K` і за теорією зонного згортання є **металевими**.
- Для кріслових нанотрубок `(n, n)` різниця `n - n = 0`, що завжди ділиться на 3. Кріслові нанотрубки є **ідеальними металами** незалежно від діаметра.
- Для нанотрубок із `(n - m) mod 3 ≠ 0` жодна лінія розрізу не проходить через точку `K`. Нанотрубка є **напівпровідником**.

## 5. Обчислення забороненої зони та ефекти кривизни

Для напівпровідникової нанотрубки `((n - m) mod 3 ≠ 0)` найближча лінія квантування розташована на відстані `Δk_⊥` від Діракової точки `K`:

```
Δk_⊥ = 2 / (3 · d)
```

Завдяки лінійній дисперсії графена біля точки `K` мінімальна енергія провідності дорівнює `E_{c,1} = ℏ · v_F · Δk_⊥`, а максимальна енергія валентної зони `E_{v,1} = - ℏ · v_F · Δk_⊥`. Ширина забороненої зони `E_g` становить:

```
E_g = E_{c,1} - E_{v,1} = 2 · ℏ · v_F · Δk_⊥        [подвоєна енергія відхилення від точки K]
= (4 · ℏ · v_F) / (3 · d)                          [підстановка Δk_⊥ = 2 / (3·d)]
= 2 · a_{C-C} · t / d ≈ 0.8 eV / d(nm)             [підстановка ℏ·v_F = (3/2)·t·a_{C-C}]
```

де `t ≈ 2.7 еВ` — інтеграл перескоку `π`-орбіталей.

### Поправка на кривизну стінки (Secondary curvature gap)

У реальних некріслових «металевих» нанотрубках із `(n - m) mod 3 = 0` (крім кріслових `n = m`) схилення стінки викривляє паралельність `2pz`-орбіталей. Це зміщує положення Діракової точки `K` від вихідного кута зони Бріллюена на величину `δk_{curvature}`.

У результаті виникає невелика «повторна» заборонена зона (secondary gap) порядку кількох десятків міліелектронвольт:

```
E_{g, curvature} = (3 · γ · a_{C-C}²) / (8 · R²) · cos(3·θ)
```

де `γ ≈ 3.0 еВ` — параметр деформації зв'язку, `R = d / 2` — радіус трубки, `θ` — кут хіральності. Оскільки для кріслових нанотрубок `θ = 30°`, фактор `cos(3·30°) = cos(90°) = 0`. Кріслові нанотрубки залишаються строго металевими навіть з урахуванням кривизни стінок.
