# 📋 Довідник фізико-механічних та електричних параметрів п'єзоматеріалів та матриць симетрії

Цей довідник містить систематизацію інженерних, пружних, діелектричних та електромеханічних параметрів п'єзоелектричних середовищ відповідно до міжнародного стандарту **IEEE Standard 176 on Piezoelectricity** (ANSI/IEEE Std 176-1987) та класифікації військового стандарту **MIL-STD-1376B (Navy Types I–VI)**. Довідник охоплює матричні форми рівнянь стану, закони взаємного перерахунку між фундаментальними п'єзомодулями, матриці симетрії пружних та п'єзоелектричних констант головних точкових груп, зведені таблиці характеристик монокристалів, керамік, тонких плівок і полімерів, вичерпні числові паспорти матеріалів, параметри акустичних мод і п'єзоелектричного зміцнення, розрахунок еквівалентної схеми Баттерворта — Ван-Дайка (BVD), температурні характеристики й орієнтаційні зрізи монокристалів.

## 1. Міжнародний стандарт IEEE Standard 176 та номенклатура величин

Стандарт IEEE 176 встановлює єдині позначення, правила індексування, формати запису тензорних матриць і методи вимірювання матеріальних констант п'єзоелектриків.

### Правила індексації та термодинамічні умови

У п'єзоелектричних матеріалах механічні та електричні поля є взаємозв'язаними, тому кожна матеріальна стала визначається за строго зафіксованих граничних умов:
- **Верхній індекс** позначає зафіксовану (постійну) термодинамічну величину під час вимірювання:
  - `^E` — електрично закорочений стан або постійне електричне поле (`E = const`, наприклад `s^E`, `c^E`).
  - `^D` — електрично розімкнений стан або постійна електрична індукція (`D = const`, наприклад `s^D`, `c^D`).
  - `^T` — механічно вільний стан без зовнішніх механічних напружень (`T = const` або `T = 0`, наприклад `ε^T`, `β^T`).
  - `^S` — механічно затиснутий або жорстко заблокований стан без деформацій (`S = const` або `S = 0`, наприклад `ε^S`, `β^S`).
- **Нижні індекси:**
  - Одинарні індекси `i, j ∈ {1, 2, 3}` або `X, Y, Z` відповідають просторовим осям декартової системи координат.
  - Подвійні індекси в матричній нотації Фойгта `p, q ∈ {1, 2, 3, 4, 5, 6}` відповідають скороченим компонентам механічних тензорів: `1 ↔ 11`, `2 ↔ 22`, `3 ↔ 33`, `4 ↔ 23, 32`, `5 ↔ 13, 31`, `6 ↔ 12, 21`.

У поляризованих полікристалічних сегнетокераміках вісь `X₃` (або `Z`) за стандартом завжди суміщається з вектором залишкової високовольтної поляризації.

### Чотири фундаментальні форми рівнянь стану

Залежно від вибору термодинамічно незалежних змінних стандарт IEEE 176 визначає 4 матричні форми лінійних рівнянь:

1. **d-форма (Strain-Charge Form):**
   Незалежні змінні — механічне напруження `T` та електричне поле `E`. Застосовується для розрахунку датчиків сили, ваги, прецизійних п'єзоактуаторів та низькочастотних перетворювачів:
   ```
   S[p] = s[p,q]^E · T[q] + d[i,p] · E[i]
   D[i] = d[i,q] · T[q] + ε[i,j]^T · E[j]
   ```

2. **e-форма (Stress-Charge Form):**
   Незалежні змінні — механічна деформація `S` та електричне поле `E`. Застосовується в обчислювальному моделюванні методом скінченних елементів (FEM), а також для аналізу високочастотних резонаторів об'ємних хвиль (BAW/FBAR):
   ```
   T[p] = c[p,q]^E · S[q] - e[i,p] · E[i]
   D[i] = e[i,q] · S[q] + ε[i,j]^S · E[j]
   ```

3. **g-форма (Strain-Voltage Form):**
   Незалежні змінні — механічне напруження `T` та електрична індукція `D`. Застосовується для гідрофонів, мікрофонів та датчиків акустичної емісії, де вимірюється напруга холостого ходу:
   ```
   S[p] = s[p,q]^D · T[q] + g[i,p] · D[i]
   E[i] = -g[i,q] · T[q] + β[i,j]^T · D[j]
   ```

4. **h-форма (Stress-Voltage Form):**
   Незалежні змінні — механічна деформація `S` та електрична індукція `D`. Застосовується для аналізу швидкоплинних ударних навантажень, вибухових п'єзогенераторів імпульсів високої напруги та сильно затиснутих високочастотних шарів:
   ```
   T[p] = c[p,q]^D · S[q] - h[i,p] · D[i]
   E[i] = -h[i,q] · S[q] + β[i,j]^S · D[j]
   ```

### Закони взаємного перерахунку між матрицями констант

П'єзоелектричні модулі `d`, `e`, `g`, `h`, а також пружні та діелектричні матриці пов'язані між собою точними алгебраїчними співвідношеннями:

```
e[i,p] = d[i,q] · c[q,p]^E
d[i,p] = e[i,q] · s[q,p]^E

g[i,p] = β[i,k]^T · d[k,p] = (ε^T)⁻¹[i,k] · d[k,p]
h[i,p] = β[i,k]^S · e[k,p] = (ε^S)⁻¹[i,k] · e[k,p]

d[i,p] = ε[i,k]^T · g[k,p]
e[i,p] = ε[i,k]^S · h[k,p]
```

Зв'язок між затиснутою та вільною діелектричною проникністю:
```
ε[i,j]^S = ε[i,j]^T - d[i,p] · e[j,p]
         = ε[i,j]^T - d[i,p] · d[j,q] · c[p,q]^E
```

Зв'язок між розімкненою (`D = const`) та закороченою (`E = const`) пружною податливістю та жорсткістю:
```
s[p,q]^D = s[p,q]^E - d[i,p] · g[i,q]
         = s[p,q]^E - d[i,p] · d[j,q] · β[i,j]^T

c[p,q]^D = c[p,q]^E + e[i,p] · h[i,q]
         = c[p,q]^E + e[i,p] · e[j,q] · β[i,j]^S
```

**Чисельний приклад розрахунку переходу від d до e для кераміки PZT-4:**
Поздовжній модуль напруження `e₃₃` для трансверсально-ізотропної кераміки класу 6mm обчислюється через компоненти матриць `d` та `c^E`:
```
e₃₃ = d₃₁ · c₁₃^E + d₃₂ · c₂₃^E + d₃₃ · c₃₃^E
    = 2 · d₃₁ · c₁₃^E + d₃₃ · c₃₃^E                 [оскільки d₃₁ = d₃₂, c₁₃^E = c₂₃^E]
    = 2 · (-123 · 10⁻¹² Кл/Н) · (74.3 · 10⁹ Па) + (289 · 10⁻¹² Кл/Н) · (115 · 10⁹ Па)
    = -18.28 Кл/м² + 33.24 Кл/м²
    = 14.96 Кл/м² ≈ 15.0 Кл/м²
```
Отримане значення точно узгоджується з експериментальним паспортним значенням `e₃₃ = 15.1 Кл/м²` для PZT-4.

## 2. Структура матриць симетрії за точковими групами

Внутрішня кристалографічна симетрія середовища істотно скорочує кількість незалежних компонент пружних, п'єзоелектричних та діелектричних матриць.

### 1. Гексагональний клас 6mm та поляризована сегнетокераміка (PZT, BaTiO₃, AlN, ZnO)

Матеріал є трансверсально-ізотропним у площині `X₁-X₂` (`XY`), вісь поляризації — `X₃` (`Z`).

- **Матриця п'єзомодулів d[i,p] (3 × 6):** 3 незалежні константи (`d₃₁ = d₃₂`, `d₃₃`, `d₁₅ = d₂₄`):
  ```
            [   0     0     0     0    d₁₅    0   ]
  d[i,p] =  [   0     0     0    d₁₅    0     0   ]
            [  d₃₁   d₃₁   d₃₃    0     0     0   ]
  ```

- **Матриця п'єзомодулів e[i,p] (3 × 6):** 3 незалежні константи (`e₃₁ = e₃₂`, `e₃₃`, `e₁₅ = e₂₄`):
  ```
            [   0     0     0     0    e₁₅    0   ]
  e[i,p] =  [   0     0     0    e₁₅    0     0   ]
            [  e₃₁   e₃₁   e₃₃    0     0     0   ]
  ```

- **Матриця пружної жорсткості c[p,q]^E (6 × 6):** 5 незалежних констант (`c₁₁ = c₂₂`, `c₁₂`, `c₁₃ = c₂₃`, `c₃₃`, `c₄₄ = c₅₅`, причому `c₆₆ = (c₁₁ - c₁₂)/2`):
  ```
              [ c₁₁   c₁₂   c₁₃    0     0     0   ]
              [ c₁₂   c₁₁   c₁₃    0     0     0   ]
  c[p,q]^E =  [ c₁₃   c₁₃   c₃₃    0     0     0   ]
              [  0     0     0    c₄₄    0     0   ]
              [  0     0     0     0    c₄₄    0   ]
              [  0     0     0     0     0    c₆₆  ]
  ```

- **Матриця діелектричної проникності ε[i,j]^T (3 × 3):** 2 незалежні константи (`ε₁₁ = ε₂₂`, `ε₃₃`):
  ```
              [ ε₁₁   0     0   ]
  ε[i,j]^T =  [  0   ε₁₁    0   ]
              [  0    0    ε₃₃  ]
  ```

### 2. Тригональний клас 32 (Монокристалічний кварц α-SiO₂)

Кристал не має центра інверсії і не є полярним (відсутня спонтанна поляризація `P_sp = 0`).

- **Матриця п'єзомодулів d[i,p] (3 × 6):** 2 незалежні константи (`d₁₁`, `d₁₄`):
  ```
            [  d₁₁  -d₁₁    0    d₁₄    0      0   ]
  d[i,p] =  [   0     0     0     0   -d₁₄  -2·d₁₁ ]
            [   0     0     0     0     0      0   ]
  ```
  Вздовж оптичної осі `X₃` (`Z`) усі компоненти п'єзомодулів дорівнюють нулю (`d₃₃ = 0`, `d₃₁ = 0`, `d₃₂ = 0`), тому поздовжнє стискання вздовж осі Z електричного заряду не створює.

- **Матриця пружної жорсткості c[p,q]^E (6 × 6):** 6 незалежних констант (`c₁₁`, `c₁₂`, `c₁₃`, `c₁₄`, `c₃₃`, `c₄₄`, причому `c₆₆ = (c₁₁ - c₁₂)/2`):
  ```
              [ c₁₁   c₁₂   c₁₃   c₁₄    0     0   ]
              [ c₁₂   c₁₁   c₁₃  -c₁₄    0     0   ]
  c[p,q]^E =  [ c₁₃   c₁₃   c₃₃    0     0     0   ]
              [ c₁₄  -c₁₄    0    c₄₄    0     0   ]
              [  0     0     0     0    c₄₄   c₁₄  ]
              [  0     0     0     0    c₁₄   c₆₆  ]
  ```

### 3. Тригональний клас 3m (Ніобат літію LiNbO₃, Танталат літію LiTaO₃)

Сегнетоелектричні монокристали з полярною віссю `X₃` (`Z`).

- **Матриця п'єзомодулів d[i,p] (3 × 6):** 4 незалежні константи (`d₁₅`, `d₂₂`, `d₃₁`, `d₃₃`):
  ```
            [   0      0      0      0    d₁₅  -2·d₂₂ ]

            [  d₃₁    d₃₁    d₃₃     0     0      0    ]
  ```

- **Матриця пружної жорсткості c[p,q]^E (6 × 6):** 6 незалежних констант (`c₁₁`, `c₁₂`, `c₁₃`, `c₁₄`, `c₃₃`, `c₄₄`):

  ```
              [ c₁₁   c₁₂   c₁₃   c₁₄    0     0   ]

              [ c₁₄  -c₁₄    0    c₄₄    0     0   ]

  ```

### 5. Ромбічний клас mm2 (Полівініліденфторид PVDF, орторомбічна β-фаза)

П'єзополімер після одноосного витягування вздовж осі `X₁` та поляризації по товщині `X₃`.

- **Матриця п'єзомодулів d[i,p] (3 × 6):** 5 незалежних констант (`d₃₁`, `d₃₂`, `d₃₃`, `d₁₅`, `d₂₄`, причому `d₃₁ ≠ d₃₂` через механічну анізотропію витягування):

  ```
            [  d₃₁   d₃₂   d₃₃    0     0     0   ]
  ```

### Феномен п'єзоелектричного зміцнення (Piezoelectric Stiffening)

Коли акустична хвиля поширюється у п'єзоелектричному кристалі, механічна деформація генерує внутрішнє зв'язане електричне поле `E`. Якщо вільні заряди не встигають екранувати це поле (розімкнені електроди або висока частота), це поле створює додаткове механічне напруження через зворотний п'єзоефект. В результаті матеріал стає жорсткішим:

```
c^D = c^E · (1 + k_t²)
```

Фазова швидкість поширення поздовжньої хвилі для електрично розімкненого кристала зростає:

```
v^D = √(c^D / ρ) = √(c^E / ρ) · √(1 + k_t²) = v^E · √(1 + k_t²)
```

Для матеріалів із сильним електромеханічним зв'язком (наприклад, LiNbO₃ з `k_t = 0.49`) п'єзоелектричне зміцнення збільшує швидкість звуку на `√(1 + 0.49²) = 1.113` (+11.3%), що необхідно враховувати при розрахунку геометрії резонаторів.

## 6. Класифікація мод коливань та коефіцієнтів електромеханічного зв'язку

Коефіцієнт електромеханічного зв'язку `k` визначає ефективність перетворення накопиченої енергії між електричною та пружною формами: `k² = E_пперетворена / E_введена`. Залежно від геометрії п'єзоелемента та напрямку прикладання поля діють різні моди коливань:

### 1. Поздовжня мода (33 Mode)
Вектор електричного поля `E₃` та напрямок механічної деформації `S₃` збігаються (довгі тонкі стрижні `l >> d`):
```
k₃₃ = d₃₃ / √(s₃₃^E · ε₃₃^T)
```

### 2. Поперечна мода (31 Mode)
Поле прикладено по товщині `E₃`, деформація виникає вздовж довжини `S₁` (тонкі пластини або балки):
```
k₃₁ = |d₃₁| / √(s₁₁^E · ε₃₃^T)
```

### 3. Планарна радіальна мода (Planar Mode, k_p)
Двовимірні радіальні коливання тонкого круглого диска, поляризованого по товщині:
```
k_p = k₃₁ · √(2 / (1 - ν^E))
```
де `ν^E = -s₁₂^E / s₁₁^E` — коефіцієнт Пуассона п'єзокераміки за постійного поля `E` (`ν^E ≈ 0.31 – 0.35`).

### 4. Товщинна мода (Thickness Extensional Mode, k_t)
Поздовжні коливання широкої тонкої пластини, коли латеральні деформації повністю заблоковані інерцією сусідніх ділянок (`S₁ = S₂ = 0`):
```
k_t = e₃₃ / √(c₃₃^D · ε₃₃^S) = √(1 - c₃₃^E / c₃₃^D)
```
Зв'язок між `k_t`, `k₃₃` та `k_p`: `k_t` завжди менший за `k₃₃` через затискання бічних граней.

### 5. Зсувна мода (15 Shear Mode)
Електричне поле `E₁` прикладено перпендикулярно до осі поляризації `X₃`, викликаючи зсувну деформацію `S₅` у площині `X₁-X₃`:
```
k₁₅ = d₁₅ / √(s₅₅^E · ε₁₁^T)
```
Ця мода забезпечує найвищі коефіцієнти зв'язку в кераміках PZT (`k₁₅ ≈ 0.70 – 0.78`).

## 7. Параметри еквівалентної електричної схеми Баттерворта — Ван-Дайка (BVD)

Поблизу ізольованого механічного резонансу будь-який п'єзоелектричний резонатор описується схемою BVD із чотирьох зосереджених елементів:

```
           ┌───────[ L_m ]───────[ C_m ]───────[ R_m ]───────┐
─( Вхід )──┤                                                 ├──( Вихід )─
           └─────────────────────[ C_0 ]─────────────────────┘
```

### Формули розрахунку компонент BVD-схеми за стандартом IEEE 176

1. **Паралельна статична ємність C₀ (затиснута ємність):**
   ```
   C_0 = (ε₃₃^S · A) / t = ((1 - k_t²) · ε₃₃^T · A) / t
   ```
   де `A` — площа електродів, `t` — товщина пластини.

2. **Динамічна послідовна ємність C_m (пружна податливість):**
   ```
   C_m = C_0 · (8 / π²) · (k_t² / (1 - k_t²))
   ```

3. **Динамічна послідовна індуктивність L_m (інерційна маса):**
   ```
   L_m = 1 / (4 · π² · f_s² · C_m) = (ρ · t³ · π²) / (8 · A · e₃₃²)
   ```

4. **Динамічний послідовний опір R_m (механічні втрати):**
   ```
   R_m = (2 · π · f_s · L_m) / Q_m = 1 / (2 · π · f_s · C_m · Q_m)
   ```

### Точні рівняння резонансних частот

- **Частота послідовного резонансу f_s (Мінімум імпедансу |Z|):**
  ```
  f_s = 1 / (2 · π · √(L_m · C_m)) = (1 / (2 · t)) · √(c₃₃^E / ρ)
  ```

- **Частота паралельного антирезонансу f_p (Максимум імпедансу |Z|):**
  ```
  f_p = f_s · √(1 + C_m / C_0) = (1 / (2 · t)) · √(c₃₃^D / ρ)
  ```

- **Ефективний коефіцієнт зв'язку k_eff через експериментальні частоти f_s та f_p:**
  ```
  k_eff² = (f_p² - f_s²) / f_p²
  ```
  За стандартом IEEE 176 точне значення товщинного коефіцієнта зв'язку `k_t` обчислюється через трансцендентне рівняння:
  ```
  k_t² = (π / 2) · (f_s / f_p) · tan[(π / 2) · ((f_p - f_s) / f_p)]
  ```

## 8. Температурні характеристики: зрізи монокристалів, TCF та термокомпенсація

### Температурний коефіцієнт частоти (TCF)

Температурний дрейф резонансної частоти резонатора описується через температурний коефіцієнт частоти `TCF` (Temperature Coefficient of Frequency, ppm/°C або `10⁻⁶ / °C`):

```
TCF = (1 / f₀) · (df / dT) = α_v - α_L
```
де `α_v = (1 / v) · (dv / dT)` — температурний коефіцієнт швидкості звуку, `α_L = (1 / L) · (dL / dT)` — коефіцієнт лінійного теплового розширення вздовж напрямку поширення.

### Паспортні характеристики орієнтаційних зрізів монокристалів

Анізотропія температурних похідних пружних констант у тригональних кристалах дозволяє підбирати кути орієнтації кристалографічного зрізу так, щоб зміна швидкості звуку точно компенсувала теплове розширення пластини (`α_v = α_L`), забезпечуючи `TCF = 0 ppm/°C`.

## 10. Формули та методики експериментального вимірювання параметрів (IEEE 176-1987)

Відповідно до стандарту IEEE 176, повний набір пружних, п'єзоелектричних та діелектричних констант матеріалу вимірюється на прецизійному аналізаторі імпедансу за резонансно-антирезонансним методом на чотирьох спеціально вирізаних каліброваних зразках:

1. **Тонкий довгий стрижень (поперечна мода 31):**
   - Довжина `l >> w, t`.
   - Вимірюються частоти послідовного `f_s` та паралельного `f_p` резонансів першої гармоніки.
   - Пружна податливість:
     ```
     s₁₁^E = 1 / (4 · ρ · l² · f_s²)
     ```
   - Коефіцієнт поперечного зв'язку `k₃₁`:
     ```
     (k₃₁² / (1 - k₃₁²)) = (π / 2) · (f_p / f_s) · tan[(π / 2) · ((f_p - f_s) / f_s)]
     ```
   - П'єзомодуль деформації:
     ```
     |d₃₁| = k₃₁ · √(s₁₁^E · ε₃₃^T)
     ```

2. **Тонкий круглий диск (радіальна планарна мода p):**
   - Діаметр `2a >> t`.
   - Вимірюються резонансні частоти радіальної моди `f_s` та `f_p`.
   - Планарний коефіцієнт зв'язку `k_p` розраховується з кореня рівняння:
     ```
     (k_p² / (1 - k_p²)) = ((1 - ν^E) · J₁(R_p) - R_p · J₀(R_p)) / ((1 + ν^E) · J₁(R_p))
     ```
     де `R_p = (π · f_p) / f_s`, а `J₀`, `J₁` — функції Бесселя першого роду.
   - Для швидкого інженерного наближення (`ν^E ≈ 0.31`):
     ```
     k_p ≈ √((2.51 · (f_p - f_s)) / f_s)
     ```

3. **Тонка широка пластина (товщинна мода t):**
   - Площа `A >> t²`.
   - Вимірюється товщинний резонанс `f_s` та антирезонанс `f_p`.
   - Пружна жорсткість затиснутого кристала:
     ```
     c₃₃^D = 4 · ρ · t² · f_p²
     c₃₃^E = 4 · ρ · t² · f_s²
     ```
   - Товщинний п'єзомодуль напруження:
     ```
     e₃₃ = 2 · f_p · t · √(ρ · ε₃₃^S · (1 - f_s² / f_p²))
     ```

4. **Механічна добротність Q_m за смугою пропускання імпедансу:**
   ```
   Q_m = f_s / (f₂ - f₁)
   ```
   де `f₁` та `f₂` — частоти, на яких активна провідність (адмітанс `G(f)`) спадає вдвічі від резонансного піка (`G = G_max / 2`, точки половинної потужності -3 дБ).
