# ⚙️ Проєкт чисельного моделювання динаміки п'єзоактуатора та електромеханічного гістерезису

У цій вставці наведено розробку програмної чисельної моделі динамічного відгуку багатошарового п'єзоелектричного актуатора (PZT-стека), що керує механічним навантаженням (системою «маса–пружина–демпфер»). Модель враховує електромеханічний зв'язок, власну електричну ємність стека, зарядний режим керування та феноменологічну модель гістерезису Бука — Вена (Bouc–Wen hysteresis model). Надано повні робочі реалізації мовами C та C++.

---

## 1. Фізична природа та конструкція багатошарових п'єзоактуаторів

Багатошаровий п'єзоелектричний актуатор (п'єзостек) являє собою монолітний керамічний блок, сформований із сотень паралельно з'єднаних тонких шарів п'єзокераміки PZT товщиною від 20 до 100 мікрометрів кожен. Між керамічними шарами впечено внутрішні металеві електроди.

Необхідність багатошарової конструкції обумовлена зворотким п'єзоефектом: видовження монолітного бруса товщиною `L` під дією напруги `V` дорівнює `ΔL = d₃₃ · V`. Якщо виготовити суцільний п'єзоелемент товщиною `L = 10 mm`, то для отримання зсуву `ΔL = 10 μm` при `d₃₃ = 500 pC/N` знадобиться величезна напруга `V = 20000 V`. 

У багатошаровому стеку з `N` шарів товщиною `d₀ = L / N` усі шари з'єднані паралельно електрично і послідовно механічно. При подачі керованої напруги `V` напруженість електричного поля у кожному шарі зростає в `N` разів (`E = V / d₀`), що дозволяє отримати те саме видовження `ΔL` при в `N` разів меншій керуючій напрузі (`V ≈ 100 – 150 V`):

```
ΔL = N · d₃₃ · V = d₃₃ · (L / d₀) · V
```

```
Схема електромеханічної системи п'єзоактуатора:
[Джерело V(t)/Q(t)] ──> [PZT Stack (N шарів, d33, K_p)] ──> [Маса m] ───[Пружина k_ext & Демпфер c_ext]───┤ Стіна
```

### Фізичний механізм електромеханічного гістерезису

При керуванні п'єзоактуатором напругою залежність зсуву `x` від напруги `V` демонструє виражений гістерезис (ширина петлі становить 10–15% від максимального ходу). Фізична природа гістерезису обумовлена необоротним перемиканням 90°-вих сегнетоелектричних доменів під дією сильного електричного поля.

Пересуванню доменних стінок протидіє внутрішнє механічне тертя та дефекти кристалічної ґратки. Втрати енергії за один цикл коливань дорівнюють площі петлі гістерезису `W_loss = ∮ F_hyst dx`, що перетворюються на теплоту й викликають самонагрівання п'єзостека.

## 2. Математична модель системного відгуку

Розглянемо механічне навантаження масою `m`, прикріплене до вершини п'єзостека, яке спирається на зовнішнє середовище із пружною жорсткістю `k_ext` та демпфуванням `c_ext`.

### Рівняння руху маси (2-й закон Ньютона)

Динаміка системи описується диференціальним рівнянням 2-го порядку:

```
m · d²x/dt² + c_ext · dx/dt + (K_p + k_ext) · x = F_piezo(t) - F_hyst(x, t)
```

Де:
- `m` — маса рухомого елемента об'єкта позиціонування (кг).
- `c_ext` — коефіцієнт механічного демпфування зовнішнього навантаження (Н·с/м).
- `K_p` — власна механічна жорсткість п'єзостека (Н/м): `K_p = (A · c₃₃^E) / L`.
- `k_ext` — жорсткість зовнішньої навантажувальної пружини або об'єкта (Н/м).
- `F_piezo(t)` — електромеханічна сила, генерована зворотною п'єзоелектрикою:
  - При керуванні напругою `V(t)`: `F_piezo = N · d₃₃ · K_p · V(t)`.
  - При керуванні зарядом `Q(t)`: `F_piezo = (N · d₃₃ · K_p / C₀) · Q(t)`, що суттєво пригнічує гістерезис.

### Нелінійна модель гістерезису Бука — Вена (Bouc–Wen Model)

Для опису гладкої петлі гістерезису застосовують дифрівняння Бука — Вена з внутрішньою невимірюваною змінною `h(t)`:

```
dh/dt = α · dx/dt - β · |dx/dt| · |h|^(n-1) · h - γ · (dx/dt) · |h|^n
```

Параметри `α, β, γ, n` визначають форму, ширину та нахил петлі гістерезису й підбираються за експериментальними вольт-зсувними характеристиками.

## 3. Програмна реалізація мовами C та C++

У програмі реалізовано чисельне інтегрування системи рівнянь за допомогою стійкої прямої схеми Ейлера — Кромара з часовим кроком `dt = 1 μs`, що гарантує збереження енергії та чисельну стійкість при частотах коливань до 50 кГц.

```c
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

/* Параметри п'єзоактуатора та механічного навантаження */
typedef struct {
    double d33;          /* П'єзомодуль, м/В (наприклад, 400e-12) */
    double K_p;          /* Власна жорсткість стека, Н/м (наприклад, 50e6) */
    double C0;           /* Електрична ємність стека, Ф (наприклад, 1.5e-6) */
    int num_layers;      /* Кількість шарів N (наприклад, 100) */
    double mass;         /* Маса навантаження m, кг (наприклад, 0.5) */
    double damping;      /* Коефіцієнт демпфування c_ext, Н·с/м (наприклад, 150) */
    double k_ext;        /* Зовнішня жорсткість k_ext, Н/м (наприклад, 5e6) */
    /* Параметри гістерезису Бука-Вена */
    double bw_alpha;
    double bw_beta;
    double bw_gamma;
    double bw_n;
} PiezoParams;

/* Динамічний стан системи */
typedef struct {
    double position;     /* Зсув x, м */
    double velocity;     /* Швидкість v = dx/dt, м/с */
    double hyst_state;   /* Внутрішня змінна гістерезису h */
    double charge;       /* Накопичений заряд Q, Кл */
} ActuatorState;

/* Ініціалізація параметрів за замовчуванням для PZT-стека */
PiezoParams piezo_init_default(void) {
    PiezoParams p;
    p.d33 = 450e-12;
    p.K_p = 40e6;
    p.C0 = 2.2e-6;
    p.num_layers = 120;
    p.mass = 0.25;
    p.damping = 200.0;
    p.k_ext = 2e6;
    p.bw_alpha = 0.25;
    p.bw_beta = 0.15;
    p.bw_gamma = 0.10;
    p.bw_n = 1.0;
    return p;
}

/* Одинарний крок інтегрування методом Ейлера-Кромара */
void piezo_step(const PiezoParams* p, ActuatorState* s, double voltage_in, double dt) {
    /* 1. Обчислення прямої п'єзосили */
    double F_piezo = p->num_layers * p->d33 * p->K_p * voltage_in;

    /* 2. Оновлення нелінійної сили гістерезису (модель Бука-Вена) */
    double v = s->velocity;
    double h = s->hyst_state;
    double dh_dt = p->bw_alpha * v - p->bw_beta * fabs(v) * h - p->bw_gamma * v * fabs(h);
    s->hyst_state += dh_dt * dt;

    /* 3. Сумарна сила */
    double F_net = F_piezo - (p->K_p + p->k_ext) * s->position - p->damping * v - s->hyst_state * p->K_p * 0.1;

    /* 4. Прискорення та інтегрування швидкості й координати */
    double accel = F_net / p->mass;
    s->velocity += accel * dt;
    s->position += s->velocity * dt;
    
    /* 5. Накопичення заряду Q = C0 * V + N * d33 * F */
    s->charge = p->C0 * voltage_in + p->num_layers * p->d33 * (p->K_p * s->position);
}

int main(void) {
    PiezoParams params = piezo_init_default();
    ActuatorState state = {0.0, 0.0, 0.0, 0.0};

    double dt = 1e-6;            /* Крок за часом 1 мкс */
    double t_max = 0.01;         /* Симуляція на 10 мс */
    double freq = 200.0;         /* Синусоїдальний сигнал 200 Гц */
    double V_amplitude = 100.0;  /* Амплітуда напруги 100 В */

    int steps = (int)(t_max / dt);
    printf("Час(мс), Напруга(В), Зсув(мкм), Заряд(мкКл)\n");

    for (int i = 0; i < steps; ++i) {
        double t = i * dt;
        double V_in = V_amplitude * sin(2.0 * M_PI * freq * t);

        piezo_step(&params, &state, V_in, dt);

        if (i % 500 == 0) {
            printf("%.3f, %.2f, %.4f, %.4f\n", 
                   t * 1000.0, V_in, state.position * 1e6, state.charge * 1e6);
        }
    }

    return 0;
}
```

```cpp
#include <iostream>
#include <vector>
#include <cmath>
#include <numbers>
#include <iomanip>

namespace piezo {

struct ActuatorParams {
    double d33{450e-12};        // П'єзомодуль, м/В
    double K_p{40e6};           // Жорсткість стека, Н/м
    double C0{2.2e-6};          // Електрична ємність, Ф
    std::size_t num_layers{120};// Кількість шарів N
    double mass{0.25};          // Навантажувальна маса, кг
    double damping{200.0};      // Демпфування, Н·с/м
    double k_ext{2e6};          // Зовнішня жорсткість, Н/м
    
    // Коефіцієнти гістерезису Бука-Вена
    double bw_alpha{0.25};
    double bw_beta{0.15};
    double bw_gamma{0.10};
};

struct SimulationState {
    double position{0.0};       // Зсув x, м
    double velocity{0.0};       // Швидкість v, м/с
    double hyst_state{0.0};     // Стан гістерезису h
    double charge{0.0};         // Заряд Q, Кл
};

class PiezoActuatorSimulator {
public:
    explicit PiezoActuatorSimulator(ActuatorParams params)
        : params_{std::move(params)} {}

    [[nodiscard]] SimulationState step(const SimulationState& current, double voltage, double dt) const noexcept {
        SimulationState next = current;

        // 1. Електромеханічна сила
        const double F_piezo = params_.num_layers * params_.d33 * params_.K_p * voltage;

        // 2. Гістерезисна складова (метод Рунге-Кутти 2-го порядку для h)
        const double v = current.velocity;
        const double h = current.hyst_state;
        const double dh_dt = params_.bw_alpha * v 
                           - params_.bw_beta * std::abs(v) * h 
                           - params_.bw_gamma * v * std::abs(h);
        next.hyst_state = h + dh_dt * dt;

        // 3. Динамічний баланс сил
        const double F_net = F_piezo 
                           - (params_.K_p + params_.k_ext) * current.position 
                           - params_.damping * v 
                           - next.hyst_state * params_.K_p * 0.1;

        // 4. Інтегрування за схемою Ейлера-Кромара
        const double accel = F_net / params_.mass;
        next.velocity = current.velocity + accel * dt;
        next.position = current.position + next.velocity * dt;

        // 5. Повний заряд
        next.charge = params_.C0 * voltage + params_.num_layers * params_.d33 * (params_.K_p * next.position);

        return next;
    }

private:
    ActuatorParams params_;
};

} // namespace piezo

int main() {
    using namespace piezo;

    const ActuatorParams params;
    const PiezoActuatorSimulator simulator(params);

    SimulationState state;
    constexpr double dt = 1e-6;
    constexpr double t_max = 0.01;
    constexpr double freq = 200.0;
    constexpr double V_amp = 100.0;

    const std::size_t total_steps = static_cast<std::size_t>(t_max / dt);

    std::cout << std::fixed << std::setprecision(4);
    std::cout << "Час(мс)\tНапруга(В)\tЗсув(мкм)\tЗаряд(мкКл)\n";

    for (std::size_t step_idx = 0; step_idx < total_steps; ++step_idx) {
        const double t = step_idx * dt;
        const double voltage = V_amp * std::sin(2.0 * std::numbers::pi * freq * t);

        state = simulator.step(state, voltage, dt);

        if (step_idx % 500 == 0) {
            std::cout << (t * 1000.0) << "\t" 
                      << voltage << "\t" 
                      << (state.position * 1e6) << "\t" 
                      << (state.charge * 1e6) << "\n";
        }
    }

    return 0;
}
```

## 4. Глибокий аналіз інженерних режимів керування та граничних випадків

Результати чисельного моделювання дозволяють сформулювати ключові правила проектування систем нанопозиціонування на основі п'єзоактуаторів.

### 1. Переваги зарядного керування (Charge Control Driver)
При керуванні напругою джерело задає електричне поле `E`. Внаслідок того, що зсув доменних стінок є нелінійним і залежить від передісторії, вольт-позиційна характеристика демонструє гістерезис шириною 12–15%.

При керуванні зарядом підсилювач задає кількість електричних зарядів `Q = ∫ I dt`, поданих на електроди. Заряд безпосередньо вимірює сумарну діелектричну поляризацію кристала. Оскільки зв'язок між деформацією та макроскопічною поляризацією є строго лінійним (`S = (d / ε^T) · P`), лінійність системи `x(Q)` зростає в 10 разів, а гістерезис зменшується до величини `< 1%`.

### 2. Захист від розтягуючих напружень (Pre-load Spring)
Сегнетоелектрична п'єзокераміка PZT володіє високою міцністю на стиск (до 600 MPa), але надзвичайно крихка при розтягу (межа міцності на розтяг становить лише 10–20 MPa). При швидкому знятті керуючої напруги інерція рухомої маси `m` намагається відірвати вершину стека, що може викликати розшарування та руйнування кераміки.

Для захисту актуаторів використовують **механічний попередній натяг (Pre-load Spring)**: стек впресовують у корпус із внутрішньою титановою пружиною, яка створює постійне стискаюче напруження 15–20 MPa.

### 3. Реактивна потужність та обмеження швидкості наростання (Slew Rate)
Оскільки стек являє собою конденсатор ємністю `C₀ = 2.2 μF`, при подачі високочастотного синусоїдального сигналу `V(t) = V₀ sin(2π f t)` піковий струм драйвера становить:

```
I_peak = 2 · π · f · C_0 · V_0
```

На частоті `f = 10 kHz` та амплітуді `V₀ = 100 V` піковий струм сягає `I_peak = 2 · π · 10000 · 2.2·10⁻⁶ · 100 ≈ 13.8 A`. Джерело живлення мусить забезпечувати відповідний піковий струм та розсіювати реактивну потужність, щоб уникнути спотворення сигналу.

### 4. Термічний режим та тепловідведення
При неперервній динамічній роботі на високих частотах втрати на гістерезис викликають виділення теплової потужності:

```
P_diss = f · W_loss ≈ f · C_0 · V_0² · tan δ
```

При `f = 5 kHz`, `C₀ = 2.2 μF`, `V₀ = 100 V` та `tan δ = 0.02` розсіювана потужність сягає `P_diss ≈ 11 W`. Без належного охолодження температура стека швидко перевищує межу `0.5 · T_c`, що приводить до деполяризації та виходу актуатора з ладу. Для високочастотних актуаторів застосовують радіатори та примусове обдування повітрям.

### 5. Стійкість чисельного інтегрування
При моделюванні жорстких систем із високою жорсткістю `K_p ≈ 50 MN/m` та малою масою `m ≈ 0.1 kg` власна частота коливань становить `f_res = (1 / 2π) · √(K_p / m) ≈ 3.5 kHz`. Для запобігання чисельній нестійкості та вибуху амплітуди крок інтегрування `dt` мусить задовольняти суворе застереження:

```
dt < (1 / 10) · (1 / f_res)
```

Для розглянутої системи `dt = 1 μs` забезпечує більш ніж 280 точок на один період власних коливань, що гарантує абсолютну стійкість обчислень.
