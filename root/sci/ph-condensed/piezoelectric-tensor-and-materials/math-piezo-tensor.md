## 1. Повний тензорний опис зв'язаних полів та термодинамічна основа

П'єзоелектричний ефект є термодинамічно зв'язаним феноменом між механічними та електричними величинами континууму. Механічний стан тривимірного твердого тіла описується двома симетричними тензорами другого рангу:
- **Тензор механічних напружень** `T[ij]` (паскалі, Pa або N/m²), де `i, j ∈ {1, 2, 3}`.
- **Тензор пружних деформацій** `S[ij]` (безрозмірна величина), визначений через градієнти вектора механічного зміщення `u[i]`: `S[ij] = 1/2 · (∂u[i]/∂x[j] + ∂u[j]/∂x[i])`.

Електричний стан описується двома векторними полями (тензорами першого рангу):
- **Вектор напруженості електричного поля** `E[i]` (В/м, V/m).
- **Вектор електричного зсуву (електричної індукції)** `D[i]` (Кл/м², C/m²).

Через закон парності дотичних напружень тензор напружень є симетричним (`T[ij] = T[ji]`). Тензор деформацій також симетричний за означенням (`S[ij] = S[ji]`). Відповідно, кожен із них містить по 6 незалежних компонент замість 9.

### Термодинамічні потенціали зв'язаної системи

Електромеханічний стан п'єзоелектричного середовища повністю задається чотирма термодинамічними змінними: двома механічними (`T[ij]`, `S[ij]`) та двома електричними (`E[i]`, `D[i]`). Залежно від вибору незалежних змінних формулюють чотири фундаментальні термодинамічні потенціали (густини енергії на одиницю об'єму):

1. **Густина внутрішньої енергії `U(S, D)`:**
   Незалежні змінні — деформація `S[ij]` та електричний зсув `D[i]`.
   ```
   dU = T[ij] · dS[ij] + E[i] · dD[i]
   ```

2. **Електрична ентальпія `H(S, E) = U - E[i] · D[i]`:**
   Незалежні змінні — деформація `S[ij]` та електричне поле `E[i]`.
   ```
   dH = dU - d(E[i] · D[i])
      = T[ij] · dS[ij] + E[i] · dD[i] - E[i] · dD[i] - D[i] · dE[i]   [підстановка dU]
      = T[ij] · dS[ij] - D[i] · dE[i]                                [скорочення E[i]·dD[i]]
   ```

3. **Пружна вільна енергія Гельмгольца `F(T, D) = U - T[ij] · S[ij]`:**
   Незалежні змінні — механічне напруження `T[ij]` та електричний зсув `D[i]`.
   ```
   dF = dU - d(T[ij] · S[ij])
      = T[ij] · dS[ij] + E[i] · dD[i] - T[ij] · dS[ij] - S[ij] · dT[ij]   [підстановка dU]
      = -S[ij] · dT[ij] + E[i] · dD[i]                                    [скорочення T[ij]·dS[ij]]
   ```

4. **Термодинамічний потенціал Гіббса `G(T, E) = U - T[ij] · S[ij] - E[i] · D[i]`:**
   Незалежні змінні — механічне напруження `T[ij]` та електричне поле `E[i]`.
   ```
   dG = dU - d(T[ij] · S[ij]) - d(E[i] · D[i])
      = -S[ij] · dT[ij] - D[i] · dE[i]                                    [розкриття повного диференціала]
   ```

### Виведення конститутивних рівнянь через розклад потенціалу Гіббса

Для ізотермічних процесів диференціал потенціалу Гіббса є повним диференціалом:
```
S[ij] = -(∂G / ∂T[ij])_E
D[i]  = -(∂G / ∂E[i])_T
```

Розкладемо густину потенціалу Гіббса `G(T, E)` у ряд Тейлора поблизу недеформованого та неполяризованого стану `(T = 0, E = 0)` до членів другого порядку малості включно:

```
G(T, E) = G₀ - 1/2 · s[ijkl]^E · T[ij] · T[kl] - d[ijk] · E[i] · T[jk] - 1/2 · ε[ij]^T · E[i] · E[j]
```

Беручи частинні похідні від розкладу `G(T, E)`, отримуємо лінійні рівняння стану:

```
S[jk] = -(∂G / ∂T[jk])_E = d[ijk] · E[i] + s[jklm]^E · T[lm]
D[i]  = -(∂G / ∂E[i])_T  = d[ijk] · T[jk] + ε[ij]^T · E[j]
```

Тут тензорні матеріальні константи визначені як другі похідні термодинамічного потенціалу:
- `s[jklm]^E = -(∂²G / ∂T[jk] ∂T[lm])_E` — **тензор пружної податливості** при постійному електричному полі `E = const` (тензор 4-го рангу, 81 компонента).
- `ε[ij]^T = -(∂²G / ∂E[i] ∂E[j])_T` — **тензор діелектричної проникності** вільного кристала при постійному напруженні `T = const` (тензор 2-го рангу, 9 компонент).
- `d[ijk] = -(∂²G / ∂E[i] ∂T[jk])` — **тензор п'єзоелектричних модулів** (тензор 3-го рангу, 27 компонент).

За теоремою Шварца про рівність мішаних частинних похідних неперервної функції від порядку диференціювання:

```
-(∂²G / ∂E[i] ∂T[jk]) = -(∂²G / ∂T[jk] ∂E[i])
(∂D[i] / ∂T[jk])_E    = (∂S[jk] / ∂E[i])_T = d[ijk]
```

Це співвідношення строго доводить **термодинамічну взаємність**: коефіцієнт пропорційності прямого п'єзоефекту (генерація індукції `D[i]` під дією напруження `T[jk]`, розмірність `C/N`) фізично й чисельно тотожний коефіцієнту зворотного п'єзоефекту (генерація деформації `S[jk]` під дією поля `E[i]`, розмірність `m/V`).

### Внутрішня симетрія тензора d[ijk]

Тензор третього рангу `d[ijk]` у тривимірному просторі має `3 × 3 × 3 = 27` компонент. Оскільки тензор механічних напружень симетричний (`T[jk] = T[kj]`), добуток `d[ijk] · T[jk]` вимагає інваріантності відносно перестановки двох останніх індексів:

```
d[ijk] = d[ikj]
```

Кількість незалежних пар індексів `(j, k)` для симетричного тензора другого рангу дорівнює `3 + (3 · 2) / 2 = 6`. Отже, внутрішня симетрія механічних індексів зменшує число незалежних компонент п'єзоелектричного тензора з 27 до **18 компонент** для найменш симетричного триклінного кристала класу `1`.

## 2. Строге тензорне доведення заборони п'єзоефекту в центросиметричних кристалах

Розглянемо закон перетворення компонент тензора третього рангу при ортогональній зміні декартової системи координат `x'[i] = a[il] · x[l]`, де матриця перетворення `A = (a[il])` задовольняє умову ортогональності `a[il] · a[jl] = δ[ij]` (`δ[ij]` — символ Кронекера, `det(A) = ±1`).

За загальним правилом тензорного аналізу компоненти тензора третього рангу в новій системі координат виражаються через старі компоненти як:

```
d'[ijk] = a[il] · a[jm] · a[kn] · d[lmn]
```

Розглянемо операцію **просторової інверсії** координат `r' = -r` (відображення відносно початку координат `x₁' = -x₁`, `x₂' = -x₂`, `x₃' = -x₃`). Матриця оператора інверсії має вигляд:

```
a[il] = -δ[il] = diag(-1, -1, -1)
```

Застосуємо оператор інверсії до тензора `d[ijk]`:

```
d'[ijk] = (-δ[il]) · (-δ[jm]) · (-δ[kn]) · d[lmn]
        = (-1) · (-1) · (-1) · δ[il] · δ[jm] · δ[kn] · d[lmn]   [факторизація скалярних множників (-1)]
        = -1 · (δ[il] · δ[jm] · δ[kn] · d[lmn])                 [добуток знаків: (-1)³ = -1]
        = -d[ijk]                                               [послідовна згортка з символами Кронекера]
```

Згідно з фундаментальним **принципом Неймана**, симетрія будь-якої макроскопічної фізичної властивості кристала повинна включати в себе точкову групу симетрії самого кристала. Якщо кристал володіє центром симетрії (центросиметричний кристал), операція просторової інверсії є елементом його точкової групи, тому тензор фізичної властивості зобов'язаний бути строго інваріантним відносно цієї трансформації:

```
d'[ijk] = d[ijk]
```

Порівнюючи трансформаційний результат із принципом Неймана, отримуємо алгебраїчну систему:

```
d[ijk] = -d[ijk]
d[ijk] + d[ijk] = 0        [перенесення правої частини ліворуч]
2 · d[ijk] = 0             [зведення подібних доданків]
d[ijk] = 0                 [ділення на 2]
```

Оскільки ця рівність виконується для будь-якої комбінації індексів `i, j, k ∈ {1, 2, 3}`, **усі 27 компонент тензора d[ijk] тотожно дорівнюють нулю**.

> 📌 **Висновок теореми:** Будь-який полярний тензор непарного рангу (зокрема тензор п'єзомодулів 3-го рангу та вектор піроелектричної поляризації 1-го рангу) у середовищах із центром інверсії строго дорівнює нулю. Саме тому з 32 кристалографічних точкових груп усі 11 центросиметричних класів (`-1, 2/m, mmm, 4/m, 4/mmm, -3, -3m, 6/m, 6/mmm, m-3, m-3m`) фундаментально позбавлені п'єзоелектричного ефекту.

## 3. Скорочений матричний запис Фойгта (Voigt Notation) та правила згортки

Для інженерних розрахунків подвійні симетричні індекси механічних величин `(j, k)` згортають в один матричний індекс `p ∈ {1, 2, 3, 4, 5, 6}` за взаємно однозначним правилом Фойгта:

```
Тензорна пара (j, k):    (1,1)  (2,2)  (3,3)  (2,3)=(3,2)  (1,3)=(3,1)  (1,2)=(2,1)
Матричний індекс p:        1      2      3         4            5            6
```

### Співвідношення між тензорними та інженерними величинами

Вектор-стовпець механічних напружень `T[p]` (розмірність 6 × 1) повністю збігається з тензорними компонентами без додаткових числових множників:
```
T₁ = T₁₁,  T₂ = T₂₂,  T₃ = T₃₃,  T₄ = T₂₃,  T₅ = T₁₃,  T₆ = T₁₂
```

Проте для компонент деформації `S[q]` виникає принципова відмінність між тензорною деформацією `S[ij]` та інженерною зсувною деформацією `γ`. Щоб зберегти інваріантність густини пружної енергії `W = 1/2 · ∑∑ T[ij] · S[ij] = 1/2 · ∑ T[p] · S[p]`, розкриємо повну подвійну суму:

```
∑∑ T[ij] · S[ij]
= T₁₁·S₁₁ + T₂₂·S₂₂ + T₃₃·S₃₃ + T₂₃·S₂₃ + T₃₂·S₃₂ + T₁₃·S₁₃ + T₃₁·S₃₁ + T₁₂·S₁₂ + T₂₁·S₂₁   [розкриття 9 доданків]
= T₁₁·S₁₁ + T₂₂·S₂₂ + T₃₃·S₃₃ + 2·T₂₃·S₂₃ + 2·T₁₃·S₁₃ + 2·T₁₂·S₁₂                            [врахування симетрії T[ij]=T[ji], S[ij]=S[ji]]
= T₁·S₁₁ + T₂·S₂₂ + T₃·S₃₃ + T₄·(2·S₂₃) + T₅·(2·S₁₃) + T₆·(2·S₁₂)                            [підстановка T[p]]
= ∑ T[p] · S[p]                                                                              [згортка у фойгтівську форму]
```

Звідси строго випливає означення вектора деформацій Фойгта:
```
S₁ = S₁₁,  S₂ = S₂₂,  S₃ = S₃₃,  S₄ = 2·S₂₃,  S₅ = 2·S₁₃,  S₆ = 2·S₁₂
```

### Формування матриці d[i, p] розмірністю 3 × 6

Розглянемо вираз для прямого п'єзоефекту `D[i] = d[ijk] · T[jk]`. Розкриваючи суму за індексами `j, k`:

```
D[i] = d[i,11]·T₁₁ + d[i,22]·T₂₂ + d[i,33]·T₃₃ + (d[i,23] + d[i,32])·T₂₃ + (d[i,13] + d[i,31])·T₁₃ + (d[i,12] + d[i,21])·T₁₂
     = d[i,11]·T₁ + d[i,22]·T₂ + d[i,33]·T₃ + 2·d[i,23]·T₄ + 2·d[i,13]·T₅ + 2·d[i,12]·T₆   [оскільки d[i,jk] = d[i,kj]]
```

Якщо записати матричне рівняння `D[i] = ∑ d[i,p] · T[p]`, матричні компоненти `d[i,p]` пов'язані з тензорними `d[ijk]` співвідношеннями:
```
d[i,p] = d[ijk]        для p ∈ {1, 2, 3}  (діагональні компоненти розтягу/стиску)
d[i,p] = 2 · d[ijk]    для p ∈ {4, 5, 6}  (зсувні компоненти)
```

Перевіримо зворотний п'єзоефект `S[jk] = d[ijk] · E[i]`:
- Для діагональних компонент (`p = 1, 2, 3`): `S[p] = S[ii] = d[i,ii] · E[i] = d[i,p] · E[i]`.
- Для зсувних компонент (`p = 4, 5, 6`): `S₄ = 2 · S₂₃ = 2 · d[i,23] · E[i] = d[i,4] · E[i]`.

У матричній формі зворотний п'єзоефект записується через транспоновану матрицю `d^t` розміром 6 × 3:
```
S[q] = ∑ d[q,i]^t · E[i] = ∑ d[i,q] · E[i]
```

Завдяки коефіцієнту 2 у визначенні зсувних деформацій та зсувних п'єзомодулів матричні рівняння прямого та зворотного ефектів мають симетричний вигляд:

```
          [ d₁₁  d₁₂  d₁₃  d₁₄  d₁₅  d₁₆ ]
d[i,p] =  [ d₂₁  d₂₂  d₂₃  d₂₄  d₂₅  d₂₆ ]
          [ d₃₁  d₃₂  d₃₃  d₃₄  d₃₅  d₃₆ ]
```

Повна зв'язана лінійна система у d-формі:
```
D[i] = ε[ij]^T · E[j] + ∑ (d[i,p] · T[p])      (i, j = 1..3; p = 1..6)
S[q] = ∑ (d[i,q] · E[i]) + s[qp]^E · T[p]      (q, p = 1..6; i = 1..3)
```

## 4. Покрокове застосування генераторів симетрії для кристалографічних класів

Точкова група симетрії кристала накладає жорсткі обмеження на вигляд матриці `d[i,p]`. Відповідно до принципу Неймана, матриця повинна задовольняти умову інваріантності:
```
d'[ijk] = a[il] · a[jm] · a[kn] · d[lmn] = d[ijk]
```
для кожного генератора точкової групи.

### Клас 32 (Тригональна сингонія: монокристалічний α-кварц)

Точкова група `32` (у позначеннях Шенфліса `D₃`) має два незалежні генератори симетрії:
1. Поворотна вісь другого порядку `C₂` вздовж осі `X (x₁)`.
2. Поворотна вісь третього порядку `C₃` вздовж головної оптичної осі `Z (x₃)`.

#### Крок 1: Застосування осі другого порядку C₂x
Поворот на кут `π (180°)` навколо осі `x₁` задається матрицею перетворення:
```
A₁ = [  1   0   0 ]
     [  0  -1   0 ]
     [  0   0  -1 ]
```
Трансформація координат: `x₁' = x₁`, `x₂' = -x₂`, `x₃' = -x₃`.
Підставляємо коефіцієнти `a₁₁ = 1`, `a₂₂ = -1`, `a₃₃ = -1` у закон перетворення `d'[ijk] = a[il] · a[jm] · a[kn] · d[lmn]`:
- `d'[1,11] = (1)·(1)·(1)·d[1,11] = d[1,11]  =>  d₁₁ = d₁₁` (компонента дозволена).
- `d'[1,22] = (1)·(-1)·(-1)·d[1,22] = d[1,22]  =>  d₁₂ = d₁₂` (дозволена).
- `d'[1,33] = (1)·(-1)·(-1)·d[1,33] = d[1,33]  =>  d₁₃ = d₁₃` (дозволена).
- `d'[1,23] = (1)·(-1)·(-1)·d[1,23] = d[1,23]  =>  d₁₄ = d₁₄` (дозволена).
- `d'[1,13] = (1)·(1)·(-1)·d[1,13] = -d[1,13]  =>  d₁₅ = -d₁₅  =>  d₁₅ = 0`.
- `d'[1,12] = (1)·(1)·(-1)·d[1,12] = -d[1,12]  =>  d₁₆ = -d₁₆  =>  d₁₆ = 0`.

Для другого та третього рядків (`i = 2` або `3`, де `a[ii] = -1`): компоненти з непарною кількістю індексів 2 та 3 змінюють знак і обнуляються:
- `d₂₁ = d₂₂ = d₂₃ = d₂₄ = 0`, лишаються `d₂₅, d₂₆`.
- `d₃₁ = d₃₂ = d₃₃ = d₃₄ = 0`, лишаються `d₃₅, d₃₆`.

#### Крок 2: Застосування осі третього порядку C₃z
Поворот на кут `2π/3 (120°)` навколо осі `x₃` задається матрицею:
```
A₂ = [ -1/2    √3/2   0 ]
     [ -√3/2  -1/2   0 ]
     [   0      0    1 ]
```
Трансформація третього рядка: оскільки `a₃₃ = 1`, а `a₃₁ = a₃₂ = 0`, компоненти `d₃₅` та `d₃₆` перетворюються через самих себе. Розрахунок дає `d₃₅ = 0` та `d₃₆ = 0`. Отже, **весь третій рядок матриці тотожно обнуляється** (`d₃p = 0` для всіх `p = 1..6`). Це означає, що при прикладанні електричного поля вздовж оптичної осі Z кварц не деформується.

Для першого та другого рядків запишемо розклад компоненти `d'[1,11]` при повороті на кут `θ = 2π/3` (`cos(θ) = -1/2`, `sin(θ) = √3/2`):
```
d'[1,11] = cos³(θ)·d[1,11] + 3·cos(θ)·sin²(θ)·d[1,22]   [закон перетворення компоненти при повороті]
d₁₁ = (-1/8)·d₁₁ + 3·(-1/2)·(3/4)·d₁₂                  [підстановка значень cos(2π/3) та sin(2π/3)]
    = -1/8·d₁₁ - 9/8·d₁₂                               [перемноження числових множників]
9/8·d₁₁ = -9/8·d₁₂                                     [перенесення d₁₁ ліворуч та зведення подібних]
d₁₂ = -d₁₁                                             [множення на 8/9 та зміна знака]
```

Аналогічний алгебраїчний розрахунок для інших компонент дає:
```
d₁₃ = 0
d₁₄ = -d₂₅
d₂₆ = -2 · d₁₁
```

В результаті матриця п'єзомодулів монокристалічного кварцу містить лише **2 незалежні компоненти** (`d₁₁` та `d₁₄`):

```
          [  d₁₁  -d₁₁    0    d₁₄    0      0   ]
d[i,p] =  [   0     0     0     0   -d₁₄  -2·d₁₁ ]
          [   0     0     0     0     0      0   ]
```

### Клас 6mm та неперервна симетрія ∞mm (Поляризована кераміка PZT, AlN, ZnO)

Цей клас описує гексагональні кристали вюрцитної структури (`AlN`, `ZnO`) та полікристалічну сегнетокераміку після високовольтної поляризації вздовж осі `Z (x₃)`.

Генератори симетрії включають:
1. Полярну вісь нескінченного порядку `C_∞` (ізотропія у площині XY).
2. Вертикальні площини симетрії `σ_v` (зокрема дзеркальну площину `σ_y`, перпендикулярну до осі `x₂`: `x₁' = x₁`, `x₂' = -x₂`, `x₃' = x₃`).

#### Крок 1: Дзеркальна площина σ_y
Матриця відбиття: `a₁₁ = 1, a₂₂ = -1, a₃₃ = 1`.
Будь-яка компонента `d[ijk]`, що містить індекс `2` непарну кількість разів, змінює знак і обнуляється:
- Перший рядок (`i = 1`): обнуляються `d₁₁, d₁₂, d₁₃, d₁₄, d₁₆ = 0`. Лишається тільки `d₁₅`.
- Другий рядок (`i = 2`): обнуляються `d₂₅, d₂₆ = 0`. Лишається тільки `d₂₄`.
- Третій рядок (`i = 3`): обнуляються `d₃₄, d₃₅, d₃₆ = 0`. Лишаються `d₃₁, d₃₂, d₃₃`.

#### Крок 2: Ізотропія в площині XY (поворот на довільний кут θ)
Поворот у площині `(x₁, x₂)` вимагає:
```
d₃₁ = d₃₂
d₁₅ = d₂₄
```

Отримуємо канонічну матрицю класу `6mm` із **3 незалежними коефіцієнтами** (`d₃₁, d₃₃, d₁₅`):

```
          [   0     0     0     0    d₁₅     0   ]
d[i,p] =  [   0     0     0    d₁₅    0      0   ]
          [  d₃₁   d₃₁   d₃₃    0     0      0   ]
```

### Клас mm2 (Ромбічна сингонія: п'єзополімер PVDF, орторомбічний KNbO₃)

Точкова група `mm2` володіє двома взаємно перпендикулярними площинами дзеркального відбиття `σ_v(xz)` (перпендикулярна до осі Y: `x₁'=x₁, x₂'=-x₂, x₃'=x₃`) та `σ_v(yz)` (перпендикулярна до осі X: `x₁'=-x₁, x₂'=x₂, x₃'=x₃`), а також полярною віссю 2-го порядку `C₂z` на їхньому перетині.

1. Застосування площини `σ_y` обнуляє всі члени з непарним числом входжень осі 2, залишаючи коефіцієнти `d₁₅, d₂₄, d₃₁, d₃₂, d₃₃`.
2. Застосування площини `σ_x` підтверджує стійкість цих п'яти коефіцієнтів.
3. Оскільки поворотна симетрія навколо осі Z обмежується лише кутом 180° (`C₂`), площина XY залишається ортотропною (анізотропною):
   `d₃₁ ≠ d₃₂`, `d₁₅ ≠ d₂₄`.

Матриця класу `mm2` містить **5 незалежних п'єзомодулів**:

```
          [   0     0     0     0    d₁₅     0   ]
d[i,p] =  [   0     0     0    d₂₄    0      0   ]
          [  d₃₁   d₃₂   d₃₃    0     0      0   ]
```

Для моноосьово витягнутої та поляризованої плівки PVDF п'єзомодуль вздовж напрямку витягування `d₃₁ ≈ 20 – 25 pC/N` майже на порядок перевищує поперечний модуль `d₃₂ ≈ 2 – 3 pC/N`, що вимагає врахування анізотропії в сенсорних розрахунках.

### Клас 3m (Тригональні полярні кристали: LiNbO₃, LiTaO₃)

Точкова група `3m` поєднує вісь третього порядку `C₃` вздовж Z та дзеркальну площину `m`, перпендикулярну до осі X (`x₁' = -x₁`, `x₂' = x₂`, `x₃' = x₃`).

В результаті згортки залишається **4 незалежні константи** (`d₁₅, d₂₂, d₃₁, d₃₃`):

```
          [   0      0      0      0    d₁₅  -2·d₂₂ ]
d[i,p] =  [ -d₂₂    d₂₂     0     d₁₅    0      0    ]
          [  d₃₁    d₃₁    d₃₃     0     0      0    ]
```

### Клас -43m (Кубічні напівпровідники: GaAs, InP, ZnS, CdTe)

Кубічна симетрія зі сфалеритними ґратками має інверсійно-поворотні осі четвертого порядку `S₄` вздовж трьох декартових осей та площини дзеркального відбиття вздовж діагоналей куба.
Ця висока симетрія обнуляє всі діагональні та поздовжні модулі розтягу/стиску:
```
d₁₁ = d₂₂ = d₃₃ = 0
d₃₁ = d₃₂ = d₁₂ = 0
```
Єдиними дозволеними компонентами є зсувні п'єзомодулі, причому через рівноправність трьох координатних осей вони строго рівні між собою:
```
d₁₄ = d₂₅ = d₃₆
```

Матриця кубічного класу `-43m` має **лише 1 незалежну компоненту**:

```
          [   0     0     0    d₁₄    0     0   ]
d[i,p] =  [   0     0     0     0    d₁₄    0   ]
          [   0     0     0     0     0    d₁₄  ]
```

Це означає, що чистий одновісний стиск монокристала `GaAs` вздовж головних осей `[100]`, `[010]` або `[001]` не генерує п'єзоелектричного заряду. П'єзоефект збуджується виключно зсувними напруженнями або стиском вздовж просторової діагоналі `[111]`.

### Кубічний клас 432: Чому п'єзоефект заборонений без центра інверсії

Клас `432` є єдиним із 21 нецентросиметричного класу, де п'єзоефект тотожно відсутній. Поворотна вісь `C₂` навколо бісектриси координатних осей вимагає `d₁₄ = d₂₅ = d₃₆`. Проте наявність поворотної осі 4-го порядку `C₄` вздовж осі `x₁` здійснює циклічну перестановку координат `x₂ → x₃`, `x₃ → -x₂`. При цьому зсувна компонента тензора напружень змінює знак `T₂₃' = -T₂₃`, що приводить до рівняння:
```
d₁₄ = -d₁₄
2 · d₁₄ = 0  =>  d₁₄ = 0
```
Оскільки всі інші компоненти зв'язані з `d₁₄`, уся матриця обнуляється: `d[i,p] = 0`.

## 5. Чотири форми конститутивних рівнянь та їхнє аналітичне перетворення

У міжнародному стандарті **IEEE Standard 176 on Piezoelectricity** визначено 4 фундаментальні форми конститутивних рівнянь стану:

```
1. d-форма (Strain-Charge):   S = s^E · T + d^t · E,        D = d · T + ε^T · E
2. e-форма (Stress-Charge):   T = c^E · S - e^t · E,        D = e · S + ε^S · E
3. g-форма (Strain-Voltage):  S = s^D · T + g^t · D,        E = -g · T + β^T · D
4. h-форма (Stress-Voltage):  T = c^D · S - h^t · D,        E = -h · S + β^S · D
```

де матриці жорсткості та непроникності визначені як обернені матриці: `c^E = (s^E)⁻¹`, `c^D = (s^D)⁻¹`, `β^T = (ε^T)⁻¹`, `β^S = (ε^S)⁻¹`.

### Аналітичне виведення e-форми з d-форми

Виразимо вектор напружень `T` з першого рівняння d-форми:

```
S = s^E · T + d^t · E
s^E · T = S - d^t · E                                  [перенесення d^t · E]
T = (s^E)⁻¹ · S - (s^E)⁻¹ · d^t · E                    [множення зліва на обернену матрицю жорсткості c^E]
T = c^E · S - (d · c^E)^t · E                          [використання властивості (A·B)^t = B^t · A^t]
T = c^E · S - e^t · E                                  [введення тензора e = d · c^E]
```

Підставимо отриманий вираз `T` у друге рівняння d-форми для електричного зсуву `D`:

```
D = d · T + ε^T · E
  = d · (c^E · S - c^E · d^t · E) + ε^T · E            [підстановка виразу для T]
  = (d · c^E) · S + (ε^T - d · c^E · d^t) · E          [розкриття дужок та групування за змінними S і E]
  = e · S + ε^S · E                                    [ідентифікація коефіцієнтів e-форми]
```

Звідси отримуємо матричні зв'язки:
```
e = d · c^E                           (e[i,p] = ∑ d[i,q] · c[qp]^E)
ε^S = ε^T - d · c^E · d^t             (ε[ij]^S = ε[ij]^T - ∑∑ d[i,p] · c[pq]^E · d[j,q])
```

Формула `ε^S = ε^T - d · c^E · d^t` має фундаментальний фізичний зміст: **діелектрична проникність затиснутого кристала `ε^S` (clamped permittivity, `S = 0`) завжди менша за діелектричну проникність вільного кристала `ε^T` (free permittivity, `T = 0`)**. У вільному кристалі зовнішнє електричне поле викликає п'єзодеформацію, яка створює додатковий індукований дипольний момент, збільшуючи діелектричну проникність. На високих частотах (вище акустичного резонансу) інерція ґратки блокує механічний рух (`S → 0`), п'єзоелектричний внесок вимикається, і проникність падає до значення `ε^S`.

### Аналітичне виведення g-форми та h-форми

Виражаючи поле `E` з другого рівняння d-форми:
```
D = d · T + ε^T · E
ε^T · E = D - d · T                             [перенесення d · T ліворуч]
E = -((ε^T)⁻¹ · d) · T + (ε^T)⁻¹ · D            [множення зліва на обернений тензор (ε^T)⁻¹]
E = -g · T + β^T · D                            [введення п'єзомодуля напруги g = (ε^T)⁻¹ · d та β^T = (ε^T)⁻¹]
```
де `β^T = (ε^T)⁻¹`, а п'єзомодуль напруги `g` дорівнює:
```
g = β^T · d = (ε^T)⁻¹ · d
```

Підставляючи `E` у рівняння деформації `S`:
```
S = s^E · T + d^t · (-g · T + β^T · D)          [підстановка виразу для E у рівняння деформації]
  = (s^E - d^t · β^T · d) · T + (d^t · β^T) · D [групування доданків за змінними T та D]
  = s^D · T + g^t · D                           [ідентифікація податливості s^D та модуля g^t]
```
Звідки пружна податливість при постійній індукції `s^D`:
```
s^D = s^E - d^t · (ε^T)⁻¹ · d
```

Аналогічно зв'язок для h-форми:
```
h = g · c^D = e · (ε^S)⁻¹ = e · β^S
c^D = c^E + e^t · (ε^S)⁻¹ · e
```

## 6. Вивід коефіцієнта електромеханічного зв'язку k²

Коефіцієнт електромеханічного зв'язку **k** (*electromechanical coupling factor*) є фундаментальною безрозмірною мірою ефективності перетворення енергії в п'єзоматеріалі. За термодинамічним визначенням:

```
k² = (Накопичена перетворена енергія)² / (Підведена пружна енергія · Підведена електрична енергія)
```

### Термодинамічний вивід для одновісного навантаження

Розглянемо густину внутрішньої енергії середовища `U(T, E)` при одночасному прикладанні одновісного напруження `T` та електричного поля `E`:

```
U = 1/2 · s^E · T² + d · T · E + 1/2 · ε^T · E²
```
Тут:
- `U_мех = 1/2 · s^E · T²` — чисто механічна пружна енергія.
- `U_ел = 1/2 · ε^T · E²` — чисто електрична діелектрична енергія.
- `U_взаєм = d · T · E` — зв'язана електромеханічна енергія взаємодії.

Обчислимо квадрат коефіцієнта зв'язку:

```
k² = (U_взаєм)² / (4 · U_мех · U_ел)
   = (d · T · E)² / [4 · (1/2 · s^E · T²) · (1/2 · ε^T · E²)]   [підстановка енергетичних складових]
   = (d² · T² · E²) / (s^E · T² · ε^T · E²)                      [скорочення числових множників: 4 · 1/4 = 1]
   = d² / (s^E · ε^T)                                            [скорочення спільних множників T² та E²]
```

### Аналітичні вирази для головних мод коливань

Залежно від геометричної конфігурації п'єзоелемента та напрямку векторів полів коефіцієнт `k` розраховується за матеріальними константами відповідних мод:

1. **Поздовжня стрижнева мода (k₃₃):**
   Електричне поле та стиск спрямовані вздовж осі поляризації Z (`T₃ ≠ 0`, `E₃ ≠ 0`, бічні грані вільні `T₁ = T₂ = 0`):
   ```
   k₃₃ = d₃₃ / √(s₃₃^E · ε₃₃^T)
   ```

2. **Поперечна стрижнева мода (k₃₁):**
   Електричне поле прикладено вздовж осі Z (`E₃`), а деформація розтягу/стиску виникає вздовж перпендикулярної осі X (`T₁ ≠ 0`):
   ```
   k₃₁ = |d₃₁| / √(s₁₁^E · ε₃₃^T)
   ```

3. **Товщинна зсувна мода (k₁₅):**
   Поперечне поле `E₁` збуджує зсувне напруження `T₅ = T₁₃`:
   ```
   k₁₅ = d₁₅ / √(s₅₅^E · ε₁₁^T)
   ```

4. **Товщинна поздовжня мода тонкої пластини (k_t):**
   Для тонкої пластини великої площі бічна деформація затиснута (`S₁ = S₂ = 0`). Перетворення описується константами жорсткості:
   ```
   k_t = e₃₃ / √(c₃₃^D · ε₃₃^S) = √( e₃₃² / (c₃₃^E · ε₃₃^S + e₃₃²) )
   ```

5. **Планарна радіальна мода диска (k_p):**
   Для тонкого поляризованого диска радіусом `R ≫ t` збуджуються симетричні радіальні коливання у площині XY:
   ```
   k_p = d₃₁ · √( 2 / [(s₁₁^E + s₁₂^E) · ε₃₃^T] ) = k₃₁ · √( 2 / (1 - ν) )
   ```
   де `ν = -s₁₂^E / s₁₁^E` — коефіцієнт Пуассона матеріалу.

### Співвідношення між матеріальними константами вільного та затиснутого станів

Через коефіцієнт зв'язку `k` встановлюються точні алгебраїчні співвідношення:
```
ε^S = ε^T · (1 - k²)
s^D = s^E · (1 - k²)
c^D = c^E / (1 - k²)
```

### Формула Мейсона: Зв'язок k² з резонансними частотами

У динамічному режимі коефіцієнт зв'язку визначається через експериментально виміряні власні частоти паралельного резонансу: послідовну резонансну частоту `f_r` (мінімум імпедансу) та антирезонансну частоту `f_a` (максимум імпедансу):

```
k² / (1 - k²) = (π / 2) · (f_a / f_r) · tan[(π / 2) · (f_a - f_r) / f_r]
```

Для матеріалів із помірним електромеханічним зв'язком (`k < 0.4`, наприклад, кварц або AlN) справедливе високоточне наближення:
```
k² ≈ (π² / 4) · (f_a - f_r) / f_r
```

## 7. Акустичні хвилі в п'єзоелектриках: п'єзоелектричне зміцнення та тензор Крістоффеля

Розглянемо поширення пружних хвиль у п'єзоелектричному кристалі з густиною `ρ`.

Динамічне рівняння руху суцільного середовища (другий закон Ньютона для неперервного середовища):
```
ρ · ∂²u[i]/∂t² = ∂T[ij]/∂x[j]
```

Оскільки фазова швидкість акустичних хвиль (`v ~ 10³ – 10⁴ m/s`) на п'ять порядків менша за швидкість світла, електромагнітні поля розглядають у **квазістатичному наближенні Максвелла**:
```
∇ × E = 0  =>  E[i] = -∂φ/∂x[i]       (електричне поле є потенціальним)
∇ · D = 0  =>  ∂D[i]/∂x[i] = 0        (відсутність вільних об'ємних зарядів у діелектрику)
```

Використаємо e-форму конститутивних рівнянь п'єзоелектрики:
```
T[ij] = c[ijkl]^E · (∂u[k]/∂x[l]) + e[kij] · (∂φ/∂x[k])
D[i]  = e[ikl] · (∂u[k]/∂x[l]) - ε[ik]^S · (∂φ/∂x[k])
```

### Розв'язок для плоскої монохроматичної хвилі

Шукаємо розв'язок для хвилі пружного зміщення `u[i]` та квазістатичного електричного потенціалу `φ` у вигляді:
```
u[i](r, t) = u₀[i] · exp( i·(k · n[j]·x[j] - ω·t) )
φ(r, t)    = φ₀    · exp( i·(k · n[j]·x[j] - ω·t) )
```
де `k = ω / v` — хвильове число, `n` — одиничний вектор нормалі вздовж напрямку поширення хвилі (`n[j]·n[j] = 1`), `u₀` — вектор поляризації акустичного зміщення.

Підставимо розв'язок у рівняння нерозривності індукції `∂D[i]/∂x[i] = 0`:

```
∂D[i]/∂x[i] = 0
i·k·n[i] · [ e[ikl] · (i·k·n[l]·u₀[k]) - ε[ik]^S · (-i·k·n[k]·φ₀) ] = 0
-k² · (e[ikl] · n[i] · n[l] · u₀[k]) - k² · (ε[ik]^S · n[i] · n[k] · φ₀) = 0   [диференціювання експоненти]
φ₀ = (e[ikl] · n[i] · n[l] · u₀[k]) / (ε[rs]^S · n[r] · n[s])                 [вираження потенціалу φ₀ через зміщення u₀]
```

Підставимо знайдений електричний потенціал `φ` у вираз для механічного напруження `T[ij]`, а потім у динамічне рівняння руху:

```
ρ · (-ω²) · u₀[i] = -k² · [ c[ijkl]^E · n[j] · n[l] + (e[m,ij] · n[m] · n[j]) · (e[p,kl] · n[p] · n[l]) / (ε[rs]^S · n[r] · n[s]) ] · u₀[k]
```

Скорочуючи на `-k²` та враховуючи, що `ω² / k² = v²` (де `v` — шукана фазова швидкість хвилі):

```
Γ[ik](n) · u₀[k] = ρ · v² · u₀[i]
```

Тут введено **модифікований акустичний тензор Крістоффеля** `Γ[ik](n)`:

```
Γ[ik](n) = c[ijkl]^E · n[j] · n[l] + (e[m,ij] · n[m] · n[j]) · (e[p,kl] · n[p] · n[l]) / (ε[rs]^S · n[r] · n[s])
```

Умова існування нетривіального розв'язку вектора пружних зміщень `u₀ ≠ 0` зводиться до характеристичного рівняння:

```
det( Γ[ik](n) - ρ · v² · δ[ik] ) = 0
```

### П'єзоелектричне зміцнення (Piezoelectric Stiffening)

Розглянемо два фундаментальні випадки акустичних мод:

1. **Поздовжня акустична хвиля вздовж полярної осі Z (`n = (0, 0, 1)`):**
   ```
   Γ₃₃ = c₃₃^E + (e₃₃)² / ε₃₃^S = c₃₃^D
   ```
   Фазова швидкість поздовжньої хвилі становить:
   ```
   v_l = √(c₃₃^D / ρ)
       = √[ (c₃₃^E + e₃₃² / ε₃₃^S) / ρ ]                 [підстановка жорсткості c₃₃^D]
       = √(c₃₃^E / ρ) · √[ 1 + e₃₃² / (c₃₃^E · ε₃₃^S) ]  [винесення пружної швидкості]
       = v₀ · √(1 + k_t²)                                [введення швидкості v₀ та коефіцієнта зв'язку k_t]
   ```

2. **Зсувна п'єзоактивна акустична хвиля (Thickness-Shear Mode, BAW):**
   Хвиля поширюється вздовж осі `X (x₁)` у кристалі класу `6mm` (`n = (1, 0, 0)`), а зміщення частинок поляризоване вздовж полярної осі `Z (x₃)`: `u = (0, 0, u₃)`.
   Тензор Крістоффеля дає зсувну компоненту `Γ₅₅`:
   ```
   Γ₅₅ = c₅₅^E + (e₁₅ · n₁ · n₁)² / (ε₁₁^S · n₁ · n₁) = c₅₅^E + (e₁₅)² / ε₁₁^S = c₅₅^D
   ```
   Швидкість зсувної хвилі становить:
   ```
   v_s = √(c₅₅^D / ρ)
       = √[ (c₅₅^E + e₁₅² / ε₁₁^S) / ρ ]                 [підстановка жорсткості c₅₅^D]
       = √(c₅₅^E / ρ) · √(1 + k₁₅²)                      [винесення швидкості зсуву та коефіцієнта зв'язку k₁₅]
   ```
   Ця мода є фундаментальною для товщинно-зсувних кварцових мікротерезов (QCM) та акустичних датчиків рідин, оскільки чистий зсув поверхні не збуджує поздовжніх хвиль стиску у рідині, зберігаючи високу добротність `Q > 10⁴` при прямому контакті з рідиною.

> 💡 **Фізичний механізм зміцнення:** Механічна деформація кристала викликає п'єзоелектричну поляризацію, яка генерує внутрішнє протидіюче електричне поле `E`. Це поле створює додаткову електростатичну силу повернення, ефективно збільшуючи пружну жорсткість кристала від `c^E` до `c^D = c^E · (1 + k²)`. Це явище називається **п'єзоелектричним зміцненням** (*piezoelectric stiffening*).

## 8. Динамічний розв'язок крайової задачі та імпеданс резонатора (модель BVD)

Розглянемо тонкий п'єзоелектричний стрижень довжиною `L` вздовж осі `Z (x₃)` з електродами на торцях `z = 0` та `z = L` площею `A`.

Згідно з d-формою одновимірних рівнянь:
```
S₃ = ∂u₃/∂z = s₃₃^E · T₃ + d₃₃ · E₃
D₃ = d₃₃ · T₃ + ε₃₃^T · E₃
```

Виразимо напруження `T₃`:
```
T₃ = (1 / s₃₃^E) · ∂u₃/∂z - (d₃₃ / s₃₃^E) · E₃ = c₃₃^E · (∂u₃/∂z) - e₃₃ · E₃
```

Підставляючи у хвильове рівняння `ρ · ∂²u₃/∂t² = ∂T₃/∂z` при умові однорідності прикладеного електричного поля `∂E₃/∂z = 0`:

```
∂²u₃/∂t² = v² · ∂²u₃/∂z²
```
де фазова швидкість `v = √(1 / (ρ · s₃₃^E))`.

Для гармонічних коливань на круговій частоті `ω` розв'язок для хвилі зміщення шукаємо у формі:
```
u₃(z, t) = [ C₁ · sin(ωz / v) + C₂ · cos(ωz / v) ] · exp(iωt)
```

Крайові умови для вільних ненавантажених торців стрижня (`T₃(0) = 0` та `T₃(L) = 0`):
```
T₃(0) = c₃₃^E · (∂u₃/∂z)|_{z=0} - e₃₃ · E₃ = 0  =>  (∂u₃/∂z)|_{z=0} = (d₃₃ / s₃₃^E) · E₃
T₃(L) = c₃₃^E · (∂u₃/∂z)|_{z=L} - e₃₃ · E₃ = 0  =>  (∂u₃/∂z)|_{z=L} = (d₃₃ / s₃₃^E) · E₃
```

Диференціюючи розв'язок та задовольняючи крайові умови, визначаємо константи інтегрування:
```
C₁ = (d₃₃ · E₃ · v) / (ω · s₃₃^E)
C₂ = - (d₃₃ · E₃ · v) / (ω · s₃₃^E) · [ (1 - cos(ωL / v)) / sin(ωL / v) ] = - (d₃₃ · E₃ · v) / (ω · s₃₃^E) · tan(ωL / (2v))
```

Повний електричний струм через електроди резонатора складається зі струму зміщення:
```
I = A · (∂D₃/∂t) = i·ω·A · [ d₃₃ · T₃ + ε₃₃^T · E₃ ]
```

Інтегруючи електричне поле по товщині для отримання прикладеної напруги `V = E₃ · L`, обчислюємо повний вхідний комплексний електричний адмітанс `Y(ω) = I / V` та імпеданс `Z(ω) = 1 / Y(ω)`:

```
Z(ω) = 1 / (i · ω · C₀) · [ 1 - k₃₃² · tan(ωL / (2v)) / (ωL / (2v)) ]
```
де `C₀ = (ε₃₃^T · (1 - k₃₃²) · A) / L = (ε₃₃^S · A) / L` — статична ємність затиснутого п'єзоконденсатора.

### Аналіз резонансних точок

1. **Послідовний резонанс (Resonance frequency `f_r`):**
   Відповідає нульовому вхідному імпедансу `Z(ω_r) = 0`, тобто полюсу тангенса `tan(ω_r · L / (2v)) → ∞`:
   ```
   ω_r · L / (2v) = π / 2  =>  f_r = v / (2 · L) = 1 / (2 · L · √(ρ · s₃₃^E))
   ```
   На цій частоті на довжині стрижня точно вкладається половина пружної довжини хвилі (`L = λ / 2`).

2. **Паралельний антирезонанс (Antiresonance frequency `f_a`):**
   Відповідає нескінченному імпедансу `Z(ω_a) → ∞` (нульовому адмітансу `Y = 0`):
   ```
   1 - k₃₃² · tan(ω_a · L / (2v)) / (ω_a · L / (2v)) = 0
   ```

### Еквівалентна електрична схема Баттерворта — Ван-Дайка (BVD)

Розкладемо трансцендентну функцію `tan(x) / x` у ряд Лорана біля першого резонансного полюса `x = ωL / (2v) ≈ π / 2`:
```
tan(x) / x ≈ (8 / π²) / (1 - (2x / π)²) = (8 / π²) / (1 - (ω / ω_r)²)
```

Підставляючи це наближення у вираз для вхідного імпедансу та обертаючи його, отримуємо вираз для вхідного адмітансу `Y(ω)`:

```
Y(ω) = i · ω · C₀ + 1 / [ i · ω · L_m + 1 / (i · ω · C_m) + R_m ]
```

Цей результат строго доводить, що поблизу власної частоти п'єзорезонатор еквівалентний паралельному з'єднанню статичної ємності `C₀` та динамічної послідовної гілки `(L_m, C_m, R_m)`:
- **Статична ємність затиснутого кристала:** `C₀ = (ε₃₃^S · A) / L`.
- **Динамічна модальна ємність:** `C_m = (8 / π²) · k₃₃² · C₀`.
- **Динамічна модальна індуктивність:** `L_m = 1 / (ω_r² · C_m) = (ρ · L · A) / (8 · d₃₃² · (c₃₃^E)²)`.
- **Опір механічних втрат:** `R_m = √(L_m / C_m) / Q_m = π / (4 · k₃₃² · ω_r · C₀ · Q_m)`, де `Q_m` — механічна добротність резонатора.

Відношення динамічної ємності до статичної ємності (коефіцієнт зв'язку схеми) визначається виключно матеріальним коефіцієнтом зв'язку:
```
C_m / C₀ = (8 / π²) · k₃₃²
```
Ця формула є базовим інструментом експериментального визначення електромеханічного коефіцієнта зв'язку `k` за виміряними значеннями ємностей на імпедансному аналізаторі.
