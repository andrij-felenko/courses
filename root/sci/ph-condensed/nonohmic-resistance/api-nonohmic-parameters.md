# 📋 Довідник технічних параметрів та розрахункових рівнянь неомічних компонентів

Цей довідник містить систематизовану специфікацію електричних, теплових, конструктивних та математичних параметрів, що описують функціонування нелінійних і неомічних елементів у практичній схемотехніці, високочастотних колах та розрахунках напівпровідникових приладів. Документ охоплює повний інженерний контракт та параметри специфікацій варисторів на основі оксиду цинку (ZnO), NTC термисторів для температурного моніторингу та обмеження пускових струмів, керамічних (CPTC) і полімерних (PPTC) термисторів, а також фундаментальні фізичні константи і пороги провідності в сильних електричних полях (механізми Пуля — Френкеля та Фаулера — Нордгейма).

Кожен розділ надає детальний опис фізичного змісту параметрів, їхні математичні зв'язки, методики вимірювання за стандартними тестовими імпульсами (наприклад, імпульси струму 8/20 мкс та напруги 1.2/50 мкс за стандартом IEC 61000-4-5) та нормативні граничні значення для проектування пристроїв захисту, автоматики та силової перетворювальної техніки.

## 1. Повна специфікація та параметри варисторів (MOV / ZnO)

Для інженерного розрахунку та схемотехнічного вибору варисторів у колах захисту від імпульсних перенапруг, грозових розрядів та комутаційних сплесків індуктивних навантажень використовуються такі ключові параметри:

```
+-------------------+---------------------------------------------------------+
| Параметр          | Фізичний зміст та одиниці вимірювання                   |
+-------------------+---------------------------------------------------------+
| U_N (V_1mA)       | Напруга варистора при струмі 1 мА (Класифікаційна) [В]  |
| U_C (V_clamping)  | Максимальна напруга фіксації (Клампінг) при I_peak [В]  |
| U_rms             | Максимально припустима напруга змінного струму (50/60 Гц) [В]|
| U_dc              | Максимальна робоча напруга постійного струму [В]        |
| α (Alpha)         | Коефіцієнт нелінійності Вольт-амперної характеристики   |
| W_max (E_energy)  | Максимальна поглинальна енергія поодинокого імпульсу [Дж]|
| I_peak (8/20 µs)  | Максимальний піковий струм імпульсу форми 8/20 мкс [А]  |
| P_d (Power)       | Максимальна середня потужність розсіювання [Вт]         |
| C_v               | Власна паразитична ємність на частоті 1 кГц [пФ або нФ] |
| R_leak            | Опір у допробійній області при напрузі 0.8·U_N [МОм]    |
+-------------------+---------------------------------------------------------+
```

### Фізико-математичний контракт та рівняння варистора

Залежність струму `I` від напруги `U` у робочому діапазоні нелінійного пробою описується феноменологічним степеневим законом:

```
I = K_v · U^α
```

або у зручній інженерній формі через класифікаційну напругу `U_N`:

```
U(I) = U_N · (I / I_0)^(1 / α)
```

де `I_0 = 1 мА = 10⁻³ А` — стандартний референтний струм, при якому вимірюється класифікаційна напруга `U_N`.

#### Коефіцієнт нелінійності α
Коефіцієнт нелінійності `α` являє собою відносну логарифмічну похідну вольт-амперної характеристики і визначається через дві експериментальні точки `(U_1, I_1)` та `(U_2, I_2)` у нелінійній зоні пробою:

```
α = log10(I_2 / I_1) / log10(U_2 / U_1)
```

Для якісних промислових ZnO варисторів значення `α` лежить у межах `30 ... 50`. У високострумовій області (`I > 1000 А`) нелінійний міжкристалічний бар'єр повністю звужується, і провідність починає обмежуватися омічним опором тіла зерен оксиду цинку (`R_grain ≈ 0.1 ... 0.5 Ом`). У цій зоні надструмів ефективне значення `α` падає до `2 ... 5`.

#### Коефіцієнт фіксації K_c
Коефіцієнт фіксації (Clamping Ratio) `K_c` показує, наскільки зростає напруга на варисторі при протіканні максимального тестового імпульсу струму `I_peak` відносно класифікаційної напруги `U_N`:

```
K_c = U_C / U_N
```

Чим ближче `K_c` до одиниці, тим ефективніше варистор фіксує перенапругу та захищає напівпровідникові прилади (IGBT, MOSFET, мікроконтролери). Для якісних ZnO варисторів `K_c = 1.4 ... 1.8`, що є суттєвою перевагою порівняно із SiC варисторами (`K_c > 3.0`).

#### Поглинальна енергія імпульсу W_max
Енергія `W`, що виділяється у керамічному об'ємі варистора під час проходження короткочасного імпульсу струму `i(t)` тривалістю `t_pulse`, обчислюється інтегруванням миттєвої потужності:

```
W = ∫ [u(t) · i(t)] dt
```

Для стандартного випробувального імпульсу струму форми 8/20 мкс (час наростання фронту 8 мкс, час спаду до півзначення 20 мкс) поглинальну енергію обчислюють за формулою:

```
W_approx ≈ 1.4 · U_C · I_peak · τ_half
```

де `τ_half = 20 мкс`.

### Розрахунок паразитичної ємності варистора

Паразитична ємність варистора `C_v` визначається діелектричною проникністю збіднених шарів ZnO (`ε_r ≈ 850`) та геометричними розмірами керамічного диска (площею `S` та товщиною `D`):

```
C_v = ε_r · ε_0 · S / D
```

Для варисторів великого діаметра (20 мм) ємність `C_v` може досягати `1 ... 3 нФ`, що обмежує їхнє застосування у високочастотних лініях передачі даних (Ethernet, USB, RS-485) через загасання сигналу. У високочастотних колах застосовують спеціальні малоємнісними варистори (`C_v < 0.5 пФ`).

## 2. Параметри NTC термисторів та розрахунок температури

Для точного вимірювання температури, температурної компенсації напівпровідникових каскадів та схемотехнічного розрахунку кіл обмеження пускових струмів використовуються такі константи та коефіцієнти:

```
+-------------------+---------------------------------------------------------+
| Параметр          | Фізичний зміст та одиниці вимірювання                   |
+-------------------+---------------------------------------------------------+
| R_25 (R_0)        | Номінальний опір при температурі T_0 = 25 °C (298.15 K)  |
| B-value (B_25/85) | Коефіцієнт температурної чутливості (B-константа) [K]   |
| A, B, C           | Коефіцієнти рівняння Стейнхарта — Харта                 |
| α_T (TCR)         | Температурний коефіцієнт опору [%/°C або 1/K]           |
| δ (Dissipation)   | Коефіцієнт розсіювання тепла (Dissipation Constant)[мВт/K]|
| τ (Thermal Tau)   | Теплова стала часу в спокійному повітрі [с]             |
| P_max             | Максимально припустима потужність розсіювання [мВт]     |
| T_max             | Максимальна робоча температура корпусу [°C]             |
+-------------------+---------------------------------------------------------+
```

### Математичні моделі градуювання NTC

#### 1. Рівняння Стейнхарта — Харта (Steinhart-Hart)
Найточніший зв'язок між опором `R` [Ом] та абсолютною температурою `T` [Кельвін] у широкому діапазоні температур (від -50 °C до +150 °C) описується поліномом Стейнхарта — Харта:

```
1 / T = A + B · ln(R) + C · (ln(R))³
```

Для визначення коефіцієнтів `A`, `B`, `C` проводиться вимірювання опору при трьох калібрувальних температурах `T_1`, `T_2`, `T_3` та розв'язується система трьох лінійних рівнянь. Похибка вимірювання температури за цим рівнянням не перевищує `±0.01 °C`.

Зворотне виведення опору `R(T)` за відомою температурою `T`:

```
x = (A - 1/T) / (2 · C)
y = √((B / (3·C))³ + x²)

R(T) = exp(∛(y - x) - ∛(y + x))
```

#### 2. Двопараметрична B-модель
Для менш вимогливих інженерних розрахунків у вузькому температурному діапазоні (0 °C ... +70 °C) застосовують спрощене B-рівняння:

```
R(T) = R_25 · exp(B · (1/T - 1/T_25))
```

де `T_25 = 298.15 K`.

Коефіцієнт `B` обчислюється за двома референтними температурами (зазвичай 25 °C та 85 °C):

```
B_25/85 = (T_1 · T_2 / (T_2 - T_1)) · ln(R_1 / R_2)
```

Температурний коефіцієнт опору `α_T` визначається дифференціюванням B-рівняння:

```
α_T = (1 / R) · (dR / dT) = -B / T²
```

Для типових NTC термисторів `B = 3000 ... 4500 K`, що забезпечує `α_T ≈ -3.3% ... -4.8% / °C` при кімнатній температурі.

### Тепловий розрахунок та обмеження струму вимірювання

Протікання вимірювального струму `I` розігріває корпус термистора на величину `ΔT = T_body - T_ambient`. Виділювана потужність `P = I² · R` у стаціонарному стані компенсується тепловідводом:

```
P = I² · R = δ · (T_body - T_ambient)
```

де `δ` — коефіцієнт розсіювання тепла [мВт/К]. Для малих SMD термисторів (0603) `δ ≈ 1.5 ... 3.0 мВт/К`.

Щоб похилка вимірювання температури через саморозігрів не перевищувала заданого значення `ΔT_err` (наприклад, 0.1 °C), вимірювальний струм обмежений умовою:

```
I_max = √(δ · ΔT_err / R(T))
```

## 3. Параметри PTC термисторів (Самовідновлювані запобіжники та CPTC)

Параметри специфікації PTC термисторів розділяють їх на два режими використання: керамічні нагрівачі/датчики (CPTC) та полімерні саміновлювані запобіжники (PPTC Multifuse).

```
+-------------------+---------------------------------------------------------+
| Параметр          | Фізичний зміст та одиниці вимірювання                   |
+-------------------+---------------------------------------------------------+
| T_s (T_switch)    | Температура перемикання (Точка Кюрі T_c) [°C]           |
| I_hold            | Максимальний струм утримування (без спрацювання) [А]    |
| I_trip            | Мінімальний струм спрацювання (переходу в High-R) [А]   |
| V_max             | Максимальна робоча напруга у спрацьованому стані [В]     |
| I_max             | Максимальний струм короткого замикання [А]              |
| R_min / R_max     | Мінімальний опір у нормі та опір у спрацьованому стані  |
| P_d               | Потужність у розсіяному стані під напругою V_max [Вт]   |
| t_trip            | Час спрацювання при заданому струмі перевантаження [с]  |
+-------------------+---------------------------------------------------------+
```

### Залежність опору CPTC від температури

У температурному діапазоні вище точки Кюрі `T > T_s` опір BaTiO₃ кераміки описується експоненціальним рівнянням:

```
R(T) = R_min · exp(A_ptc · (T - T_s))
```

де `A_ptc ≈ 0.1 ... 0.3 K⁻¹` — крутизна PTC характеристики.

### Динаміка спрацювання PPTC запобіжника

Перехід запобіжника зі стану з низьким опором `R_min` у стан із високим опором `R_max` відбувається при досягненні критичної температури плавлення полімеру `T_switch`. Умова утримування струму без спрацювання:

```
I_hold² · R_min < δ · (T_switch - T_ambient)
```

Умова гарантированного спрацювання при перевантаженні:

```
I_trip² · R_min > δ · (T_switch - T_ambient)
```

Час спрацювання `t_trip` при струмі перевантаження `I_overload` визначається з теплоємності `C_th` та різниці потужностей:

```
t_trip ≈ C_th · (T_switch - T_ambient) / (I_overload² · R_min - δ · (T_switch - T_ambient))
```
