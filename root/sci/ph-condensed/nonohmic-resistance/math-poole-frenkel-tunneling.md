# 🧮 Математична теорія неомічної провідності та польових ефектів

Фізичною основою неомічного опору є зміна концентрації вільних носіїв заряду або їхньої ефективної рухливості під дією зовнішнього електричного поля чи підвищення температури. На відміну від омічних матеріалів, де константа провідності визначається законами розсіювання на фононах та дефектах, у неомічних середовищах напруженість поля деформує потенціальні бар'єри або полегшує квантове тунелювання. 

Ця вставка містить строгі математичні виведення чотирьох головних механізмів нелінійного транспорту: ефекту Пуля — Френкеля, автоелектронної емісії Фаулера — Нордгейма, міжкристалітного бар'єру Шотткі варисторів та моделі Хейванга для PTC-термисторів.

---

## 1. Математична модель ефекту Пуля — Френкеля

Ефект Пуля — Френкеля описує термічне вивільнення електронів із кулонівських ловушок у зону провідності під дією сильного електричного поля `E`.

Розглянемо електрон із зарядом `-e`, затиснутий у потенціальній ямі позитивно зарядженого йона. Без зовнішнього поля потенціальна енергія електрона на відстані `x` описується кулонівським потенціалом:

```
V_0(x) = -e² / (4·π·ε_r·ε_0·x)
```

При накладанні однорідного зовнішнього електричного поля `E`, спрямованого вздовж осі `x`, потенціальна енергія електрона набуває вигляду:

```
V(x) = -e² / (4·π·ε_r·ε_0·x) - e·E·x      [Кулонівський потенціал + енергія поля]
```

Щоб знайти точку максимуму потенціального бар'єру `x_max`, обчислюємо першу похідну потенціалу за `x` і прирівнюємо її до нуля:

```
dV / dx = e² / (4·π·ε_r·ε_0·x²) - e·E = 0   [Умова екстремуму]
```

Розв'язуючи це рівняння відносно `x_max`:

```
e² / (4·π·ε_r·ε_0·x_max²) = e·E             [Дорівняння сил]

x_max = √(e / (4·π·ε_r·ε_0·E))               [Позиція максимуму бар'єру]
```

Підставляючи позицію максимуму `x_max` назад у вираз для потенціалу `V(x)`, знаходимо значення потенціальної енергії у вершині деформованого бар'єру `V_max`:

```
V_max(E) = -e² / (4·π·ε_r·ε_0 · √(e / (4·π·ε_r·ε_0·E))) - e·E · √(e / (4·π·ε_r·ε_0·E))
         = -2 · √(e³ · E / (4·π·ε_r·ε_0))
```

Отже, зниження висоти кулонівського потенціального бар'єру `ΔE_PF` під дією поля `E` становить:

```
ΔE_PF = V_max(0) - V_max(E)
      = 2 · √(e³ · E / (4·π·ε_r·ε_0))       [Формула Пуля — Френкеля]
      = β_PF · √E
```

де `β_PF` — коефіцієнт Пуля — Френкеля:

```
β_PF = √(e³ / (π · ε_r · ε_0))
```

Імовірність термічного викиду електрона з ловушки енергетичною глибиною `E_t` описується больцманівським фактором активації:

```
P ~ exp(-(E_t - ΔE_PF) / (k_B · T))
```

Звідси електрична провідність `σ(E)` та густина струму `J(E)` виражаються експоненціальними залежностями:

```
σ(E) = σ_0 · exp(β_PF · √E / (k_B · T))
J(E) = σ_0 · E · exp(β_PF · √E / (k_B · T))
```

### Фізичне порівняння з ефектом Шотткі

Порівнюючи з ефектом Шотткі (де зниження бар'єру на контактах метал-діелектрик відбувається за рахунок сил дзеркального відображення), відзначимо, що коефіцієнт Шотткі `β_S` точно вдвічі менший за коефіцієнт Пуля — Френкеля:

```
β_S = 0.5 · β_PF = √(e³ / (4 · π · ε_r · ε_0))
```

Це пояснюється тим, що при вильоті електрона з нейтральної ловушки позитивний йон залишається нерухомим у вузлі ґратки, тоді як при віддаленні від металевого електрода дзеркальне зображення рухається разом із електроном, зменшуючи ефективну силу притягання вдвічі.

## 2. Автоелектронне тунелювання Фаулера — Нордгейма

У надсильних електричних полях (`E > 5·10⁶ В/см`) прямокутний потенціальний бар'єр діелектрика товщиною `d` деформується у вузький трикутний бар'єр.

За наближенням Вентцеля — Крамерса — Бріллюена (ВКБ), ймовірність (прозорість) тунелювання електрона з енергією `E_k` крізь потенціальний бар'єр `V(x)` дорівнює:

```
D(E_k) ≈ exp(-2 · ∫ √(2·m*·(V(x) - E_k)) dx / ħ)   [Наближення ВКБ]
```

Для трикутного бар'єру висотою `Φ_B` у полі `E` потенціал має вигляд `V(x) - E_k = Φ_B - e·E·x`. Межі інтегрування простягаються від `x = 0` до точки повороту `x_turn = Φ_B / (e·E)`.

Виконуємо інтегрування підкореневого виразу:

```
∫ √(Φ_B - e·E·x) dx = -(2 / (3·e·E)) · (Φ_B - e·E·x)^(3/2)
```

Підставляючи межі від `0` до `Φ_B / (e·E)`:

```
∫ [0 ... Φ_B/eE] √(Φ_B - e·E·x) dx = (2 / (3·e·E)) · Φ_B^(3/2)
```

Підставляючи результат у показник експоненти ВКБ, отримуємо прозорість трикутного бар'єру `D`:

```
D = exp(-4 · √(2·m*) · Φ_B^(3/2) / (3 · e · ħ · E))
```

Інтегруючи по всіх електронах Фермі-поверхні металу, отримуємо класичне рівняння густини струму Фаулера — Нордгейма `J_FN`:

```
J_FN = A_FN · E² · exp(-B_FN / E)
```

де феноменологічні константи `A_FN` та `B_FN` виражаються через ефективну масу електрона `m*` та висоту бар'єру `Φ_B`:

```
A_FN = e³ / (16 · π² · ħ · Φ_B)             [Перша константа FN]

B_FN = 4 · √(2·m*) · Φ_B^(3/2) / (3 · e · ħ)  [Друга константа FN]
```

Логарифмічна форма рівняння використовується для перевірки наявності тунельного транспорту на експериментальних ВАХ:

```
ln(J_FN / E²) = ln(A_FN) - B_FN / E
```

Побудова графіка залежності `ln(J / E²)` від `1/E` дає пряму лінію з нахилом `-B_FN`.

## 3. Подвійний бар'єр Шотткі в ZnO варисторах

Розглянемо симетричний міжкристалітний контакт двох зерен n-ZnO, розділених тонкими прошарком Bi₂O₃. За рахунок негативного заряду акцепторних ловушок з поверхневою густиною `N_s` (на межі зерна) в обох сусідніх зернах n-ZnO з концентрацією донорів `N_d` утворюються шари збіднення шириною `w`.

Для обчислення потенціалу `V(x)` у шарі збіднення розв'язуємо одновимірне стаціонарне рівняння Пуассона:

```
d²V / dx² = -e · N_d / (ε_r · ε_0)          [Рівняння Пуассона]
```

Перше інтегрування за межею `x = w` (де поле `dV/dx = 0`):

```
dV / dx = (e · N_d / (ε_r · ε_0)) · (w - x)  [Розподіл поля]
```

Друге інтегрування від `x = 0` до `x = w` дає висоту бар'єру Шотткі `V_B` у стані рівноваги (без зовнішнього поля):

```
V_B = e · N_d · w² / (2 · ε_r · ε_0)
```

Оскільки повний негативний поверхневий заряд `e · N_s` на межі зерна компенсується позитивним об'ємним зарядом донорів `2 · e · N_d · w` з обох боків:

```
w = N_s / (2 · N_d)                          [Ширина шару збіднення]
```

Підставляючи `w` у вираз для висоти бар'єру, отримуємо формулу висоти потенціального бар'єру Шотткі:

```
V_B = e · N_s² / (8 · ε_r · ε_0 · N_d)       [Висота бар'єру Шотткі]
```

При прикладанні зовнішньої напруги `U_g` на один міжкристалітний контакт бар'єр зі зворотним зсувом падає:

```
V_B(U_g) = V_B · (1 - U_g / (4 · V_B))²
```

Струм термоемісії крізь бар'єр описується рівнянням:

```
J = J_0 · exp(-e · V_B(U_g) / (k_B · T))
```

Коли напруга на межі досягає критичного значення `U_N ≈ 3.2 В` (що відповідає ширині забороненої зони ZnO `E_g = 3.37 еВ`), бар'єр звужується до кількох нанометрів, викликаючи прямої тунельний пробій та лавинну інжекцію дірок.

Коефіцієнт нелінійності `α` визначається як відносна похідна ВАХ:

```
α = d(ln I) / d(ln U) = (U / I) · (dI / dU)
```

Для якісних ZnO варисторів `α` сягає 30–50 у робочому діапазоні струмів.

## 4. Модель Хейванга для PTC-термисторів на BaTiO₃

У сегнетоелектричній кераміці BaTiO₃ висота міжкристалітного бар'єру `e·V_B` виражається аналогічною формулою:

```
e · V_B = e² · N_s² / (8 · ε_r(T) · ε_0 · N_d)
```

Відмінність полягає у сильній температурній залежності діелектричної проникності `ε_r(T)`. Вище температури Кюрі `T_c ≈ 120 °C` матеріал перебуває у параелектричному стані, де діелектрична проникність описується законом Кюрі — Вейсса:

```
ε_r(T) = C / (T - T_c)                       [Закон Кюрі — Вейсса, T > T_c]
```

де `C` — константа Кюрі (`C ≈ 10⁵ K`).

Підставляючи закон Кюрі — Вейсса у вираз для висоти бар'єру `V_B`:

```
e · V_B(T) = (e² · N_s² / (8 · ε_0 · N_d · C)) · (T - T_c)
```

Отже, висота потенціального бар'єру `V_B(T)` зростає прямо пропорційно різниці температур `(T - T_c)`.

Оскільки опір міжкристалітного контакту `R(T)` виражається експоненціально через висоту бар'єру:

```
R(T) = R_0 · exp(e · V_B(T) / (k_B · T))
     = R_0 · exp(K · (T - T_c) / T)
```

де `K = e² · N_s² / (8 · ε_0 · N_d · C · k_B)`.

Ця експоненціальна залежність спричиняє стрімке зростання опору PTC-термистора на 4–6 порядків при нагріванні лише на 20–30 °C вище температури Кюрі `T_c`.
