# 📜 Історія відкриття обмінної взаємодії та доменів

Відкриття фізичної природи феромагнетизму та мікроскопічної доменної структури стало однією з найдраматичніших сторінок фізики конденсованого стану XX століття. Воно вимагало трьох десятиліть гострих наукових суперечок, подолання тупиків класичної електродинаміки та створення абсолютно нових квантово-механічних концепцій.

## 1. Гіпотеза молекулярного поля П'єра Вейса (1907)

На початку XX століття французький фізик П'єр Вейс (фр. *Pierre-Ernest Weiss*) запропонував першу феноменологічну теорію феромагнетизму. Вейс спробував розв'язати парадокс ненамагніченого заліза, висунувши дві революційні гіпотези:

1. Всередині феромагнетика діє внутрішнє потужне **молекулярне поле `H_m`**, яке пропорційне намагніченості матеріалу: `H_m = λ · M`, де `λ` — внутрішня стала Вейса (безрозмірний коефіцієнт молекулярного поля order of `10³...10⁴`).
2. Будь-який макроскопічний феромагнетик нижче температури Кюрі самочинно розбивається на безліч мікроскопічних областей спонтанного намагнічування — **доменів**. Всередині кожного домену молекулярне поле Вейса орієнтує абсолютно всі атомні магнітні моменти паралельно, створюючи індукцію насичення `B_s`. Проте вектори намагніченості сусідніх доменів спрямовані у різні боки, тому їхній макроскопічний векторний сума дорівнює нулю (`∑ M_i = 0`).

Гіпотеза Вейса блискуче пояснила і спонтанне намагнічування, і макроскопічну нейтральність звичайного заліза. Проте походження самого молекулярного поля `H_m` залишалося для класичної фізики повною загадкою.

Оцінка амплітуди молекулярного поля для заліза за формулою Вейса `H_m = k_B · T_c / μ_B` давала фантастичне значення:

```
H_m ≈ 10⁹ А/м   ( індукція B_m = μ₀ · H_m ≈ 1000 Тесла )
```

У класичній електродинаміці Максвелла не існувало жодних струмів або магнітних диполів, здатних створити внутрішнє магнітне поле в тисячу Тесла. Якби таке поле мало магнітну природу, сила взаємодії між атомами розірвала б кристалічну ґратку заліза. Вейс був змушений чесно визнати: молекулярне поле має немагнітне походження, але пояснити його причудливі властивості класика не змогла.

## 2. Квантовий прорив: Гейзенберг та Дірак (1926–1928)

Лише у 1926–1928 роках, після відкриття принципу заборони Паулі та формулювання хвильової механіки Шредінгера, німецький фізик Вернер Гейзенберг (нім. *Werner Heisenberg*) та англійський фізик Поль Дірак (англ. *Paul Dirac*) незалежно один від одного розгадали природу молекулярного поля Вейса.

Гейзенберг показав, що молекулярне поле — це не магнітне поле, а чисто **електростатична кулонівська взаємодія** електронних хмар сусідніх атомів, скоригована квантовою симетрією спінових хвильових функцій електронів.

Коли два електрони перебувають на незаповнених 3d-оболонках сусідніх атомів, їхня спільна хвильова функція описується квантовим обмінним інтегралом `J_ex`. Якщо просторові оболонки перекриваються так, що паралельна орієнтація спінів зменшує кулонівське відштовхування електронів (згідно з принципом заборони Паулі), енергія системи знижується.

Математична модель Гейзенберга записувалася через спінові оператори:

```
H_ex = -2 · J_ex · ∑ ( S_i · S_j )
```

Зв'язок між феноменологічною сталою Вейса `λ` та квантовим обмінним інтегралом `J_ex` виражається співвідношенням:

```
λ = 2 · z · J_ex / ( N_0 · g² · μ_B² )
```

де `z` — кількість найближчих сусідніх атомів у ґратці, `N_0` — концентрація атомів, а `g ≈ 2` — фактори Ланде для електронного спіну. Таким чином, квантова механіка довела: феромагнетизм є електростатичним за своєю природою, але спіновим за своїм проявом.

## 3. Континуальна теорія доменів та стінок Ландау — Ліфшиця (1935)

Хоча Вейс передбачив існування доменів у 1907 році, теорія їхніх геометричних розмірів, форми та внутрішньої межі була створена у 1935 році радянськими фізиками Левом Ландау та Євгеном Ліфшицем.

У своїй класичній праці «До теорії дисперсії магнітної проникності феромагнітних тіл» Ландау і Ліфшиць довели:
1. Подрібнення на домени є наслідком мінімізації магнітостатичної енергії розсіяного поля `E_ms`.
2. На поверхні монокристала обов'язково утворюються замикаючі трикутні домени (домени замикання), які повністю усувають розсіяне магнітне поле назовні.
3. Межа між доменами не є нескінченно тонкою площиною, а являє собою неперервно розгорнутий шар спінів — **доменну стінку Блоха**, товщина якої `δ_w = π·√(A/K)` становить десятки нанометрів.

## 4. Експериментальне візуальне підтвердження: Порошкові фігури Біттера (1931)

Протягом майже чверті століття домени залишалися теоретичною гіпотезою. У 1931 році американський фізик Френсіс Біттер (англ. *Francis Bitter*) розробив елегантний метод експериментальної візуалізації доменної структури — **метод порошкових фігур (фігури Біттера)**.

Суть методу полягає у нанесенні краплі високодисперсної колоїдної суспензії дрібних частинок магнетиту (`Fe₃O₄` розміром близько 10 нанометрів) на поліровану поверхню феромагнітного монокристала. У місцях, де доменні стінки виходять на поверхню кристала, виникають локальні неоднорідні магнітні поля розсіяння з високим градієнтом `∇B`. Наночастинки магнетиту притягуються градієнтними силами `F = (m · ∇)B` строго до меж між доменами, утворюючи чіткі контрастні смуги, які легко спостерігати під звичайним оптичним мікроскопом.

Пізніше у 1950-х роках для візуалізації доменів почали застосовувати магнітооптичний ефект Керра (MOKE), просвічуючу електронну мікроскопію (Lorentz TEM), а у 1990-х роках — магнітно-силову мікроскопію (MFM), яка дозволила бачити окремі спінові стінки з нанометровим просторовим розділенням.
