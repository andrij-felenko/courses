# 🧮 Фізико-математичне моделювання дифузійного потоку та ефекту Блеха

Цей математичний опис виводить точні вирази для атомного потоку електроміграції, трансформує баланс сил у диференціальне рівняння Корхонена для еволюції механічних напружень та математично доводить існування безелектроміграційного порогу Блеха.

---

### Рівняння атомного потоку Нернста-Ейнштейна

Масоперенос у твердому провіднику під дією зовні прикладеного електричного поля визначається сумою двох фізичних складників: градієнтним дифузійним потоком (перший закон Фіка) та дрейфовим потоком під дією ефективної сили `F_net`:

```
J = J_diff + J_drift
```

Мікроскопічний механізм атомного стрибка у кристалічній ґратці базується на теорії абсолютних швидкостей реакцій. Частота стрибків атома `ν` у сусідню вакансію під дією теплових флуктуацій описується рівнянням:

```
ν = ν_0 · exp( - E_a / ( k_B · T ) )
```

де `ν_0` — частота Дебая (порядку `10¹³ Гц`), `E_a` — енергія активації дифузійного стрибка, `k_B` — стала Больцмана, а `T` — абсолютна температура.

Згідно із співвідношенням Нернста-Ейнштейна, рухливість `μ` атомів або вакансій у кристалічній ґратці пов'язана з коефіцієнтом дифузії `D` виразом:

```
μ = D / ( k_B · T )
```

Дрейфова швидкість атомів `v_drift` під дією результуючої зовні прикладеної сили `F_net` становить:

```
v_drift = μ · F_net = ( D / ( k_B · T ) ) · F_net
```

Підставляючи дрейфову швидкість та вираз для першого закону Фіка `J_diff = - D · ∇C`, отримуємо загальне рівняння атомного потоку:

```
J = - D · ∇C + C · ( D / ( k_B · T ) ) · F_net
```

де `C` — атомарна концентрація металу (число атомів в одиниці об'єму).

---

### Мікроскопічна природа ефективної сили та ефективного заряду Z*

Результуюча сила `F_net`, яка діє на активований іон металу під час його стрибка через енергетичний бар'єр дифузії, складається з двох протилежно спрямованих векторних сил:

```
F_net = F_direct + F_wind
```

1. **Пряма електростатична сила `F_direct`:**
   Прикладне електричне поле `E` діє на позитивний заряд іона `Z_d · e` (де `Z_d` — валентність іона, `e` — елементарний заряд):

   ```
   F_direct = + Z_d · e · E
   ```

2. **Сила електронного вітру `F_wind`:**
   Електрони провідності, дрейфуючи зі швидкістю `v_e` проти напрямку поля `E`, непружно розсіюються на активованому іоні. Імпульс, що передається іону в одиницю часу, пропорційний густині струму `j = n_e · e · v_e` та ефективному перерізу розсіювання `σ_e`:

   ```
   F_wind = - |Z_w*| · e · E
   ```

Впроваджуючи безрозмірний **ефективний заряд** `Z* = Z_d - |Z_w*|`, сумарну силу записують у компактному вигляді:

```
F_net = Z* · e · E = Z* · e · ρ · j
```

де `ρ` — питомий електричний опір металу (`E = ρ · j`). Для більшості металів із високою провідністю (Cu, Al, Au) переважає сила електронного вітру (`|Z_w*| >> Z_d`), тому `Z* < 0` (зазвичай `Z* ≈ -1 ... -10`).

### Рівняння Корхонена: еволюція механічних напружень

Накопичення або збіднення атомів у замкненому об'ємі металевої лінії викликає локальні механічні деформації ґратки. Накопичення надлишкових атомів створює стискаюче гідростатичне напруження (`σ < 0`), тоді як утворення вакансій — розтягуюче напруження (`σ > 0`).

Зміна концентрації вакансій `C_v` пов'язана з деформацією об'єму `ε` через атомарний об'єм `Ω`:

```
ε = Ω · ( C_v - C_v0 )
```

Згідно з законом Гука для стисненого металевого провідника у жорсткому матричному діелектрику, гідростатичне напруження `σ` пропорційне деформації об'єму:

```
σ = - B · ε = - B · Ω · ( C_v - C_v0 )
```

де `B` — ефективний модуль пружності міжз'єднання (що враховує модуль Юнга металу та жорсткість навколишнього діелектрика).

Градієнт механічного напруження `∇σ` породжує додаткову зворотну механічну силу `F_back`, що штовхає атоми з області стиску в область розтягу:

```
F_back = - Ω · ∇σ
```

З урахуванням градієнта напружень повне рівняння атомного потоку уздовж одномірного провідника (координата `x`) набуває вигляду:

```
J(x) = C · ( D / ( k_B · T ) ) · [ Z* · e · ρ · j - Ω · ( ∂σ / ∂x ) ]
```
[нехтуємо градієнтом концентрації ∇C, оскільки C ≈ const в об'ємі металу]

Закон збереження маси пов'язує дивергенцію потоку `∂J / ∂x` зі швидкістю зміни механічного напруження `∂σ / ∂t`. Одномірне диференціальне рівняння Корхонена (*Korhonen equation*) має вигляд:

```
∂σ / ∂t = ( ∂ / ∂x ) [ ( D · B · Ω / ( k_B · T ) ) · ( ∂σ / ∂x - ( Z* · e · ρ · j ) / Ω ) ]
```

### Динаміка релаксації та характеристичний час формування напружень

Розв'язок рівняння Корхонена для провідника довжиною `L` при миттєвому включенні постійного струму `j` шукають у вигляді ряду Фур'є. Часова еволюція розподілу напружень `σ(x, t)` описується сумою експоненційних гармонік:

```
σ(x, t) = σ_steady(x) + ∑ [ A_k · cos( k · π · x / L ) · exp( - t / τ_k ) ]
```

найповільніша гармоніка має **характеристичний час релаксації** `τ_1`:

```
τ_1 = ( L² · k_B · T ) / ( π² · D · B · Ω )
```

Цей час визначає тривалість перехідного процесу накопичення напружень. Якщо довжина провідника `L` мала (наприклад, `L = 10 мкм`), час `τ_1` становить частки секунди, і провідник майже миттєво переходить у стаціонарний стан з рівноважним градієнтом напружень.

### Вивід критичної довжини Блеха (Blech Limit)

Розглянемо металевий провідник скінченної довжини `L`, обмежений з обох кінців тугоплавкими бар'єрними шарами (наприклад, `TaN` або `Via`), крізь які дифузія атомів металу неможлива. Це задає граничні умови нульового потоку на кінцях:

```
J(x = 0) = 0
J(x = L) = 0
```

У стаціонарному стані (`∂σ / ∂t = 0` та `J(x) = 0`) механічний зворотний потік атомів повністю врівноважує потік електронного вітру в кожній точці провідника:

```
Z* · e · ρ · j - Ω · ( ∂σ / ∂x ) = 0
```

Звідси стаціонарний градієнт напруження є суто лінійним і дорівнює:

```
∂σ / ∂x = ( Z* · e · ρ · j ) / Ω
```

Інтегруючи цей градієнт по всій довжині провідника `L`, отримуємо максимальну різницю механічних напружень `Δσ = σ(L) - σ(0)` між анодним та катодним кінцями:

```
Δσ = ( Z* · e · ρ · j · L ) / Ω
```

Руйнування провідника (зародження порожнини на катоді або пробій діелектрика пагорбом на аноді) відбувається лише тоді, коли різниця напружень `Δσ` перевищує критичну межу міцності матеріалу `Δσ_max`:

```
Δσ ≤ Δσ_max
```

Підставляючи `Δσ_max` у вираз для перепаду напружень, отримуємо **критерій імунітету Блеха**:

```
( j · L ) ≤ ( j · L )_c
```

де критичний добуток Блеха `( j · L )_c` визначається фундаментальними константами та параметрами матеріалу:

```
( j · L )_c = ( Ω · Δσ_max ) / ( |Z*| · e · ρ )
```

Для мідних та алюмінієвих міжз'єднань у сучасних мікросхемах критичний добуток Блеха становить приблизно `( j · L )_c ≈ 3000 ... 5000 А/см` (або `3 ... 5 · 10³ А/м`). Якщо реальний добуток густини струму на довжину доріжки у схемі менший за цю величину, електроміграційний руйнівний потік є принципово неможливим — такий провідник є абсолютно стійким («безсмертним»).

### Математична статистика відмов: Логнормальний розподіл

Час до відмови `t` для ансамблю ідентичних провідників під час випробувань описується логнормальним розподілом імовірностей (*Lognormal distribution*). Щільність ймовірності відмови `f(t)` дорівнює:

```
f(t) = ( 1 / ( √ (2 · π) · σ_LN · t ) ) · exp( - ( ln(t) - ln(t_50) )² / ( 2 · σ_LN² ) )
```

де:
- `t_50` — медіанний час до відмови (значення, за якого ламається 50% зразків);
- `σ_LN` — логарифмічна стандартна девіація (параметр розсіювання або логарифмічна дисперсія).

Інтегральна функція накопиченої ймовірності відмов `F(t)` задається через функцію помилок `erf`:

```
F(t) = 0.5 · [ 1 + erf( ( ln(t) - ln(t_50) ) / ( √2 · σ_LN ) ) ]
```

Визначення медіанного часу `t_50` здійснюється за рівнянням Блека, а інтегральна функція дозволяє розраховувати час безвідмовної роботи для заданого відсотка відмов (наприклад, `t_0.1` для 0.1% відмов за 10 років експлуатації):

```
ln( t_0.1 ) = ln( t_50 ) - 3.09 · σ_LN
```
[число 3.09 відповідає квантилю стандартного нормального розподілу для рівня 0.001]

Інтенсивність відмов `λ(t)` (*hazard rate*) для логнормального розподілу виражається співвідношенням `λ(t) = f(t) / (1 - F(t))`. На відміну від експоненційного розподілу з постійною інтенсивністю, `λ(t)` для електроміграції спочатку зростає, досягає максимуму, а потім спадає, що вимагає ретельного контролю параметра дисперсії `σ_LN ≤ 0.3 ... 0.5` під час виготовлення металізації.
