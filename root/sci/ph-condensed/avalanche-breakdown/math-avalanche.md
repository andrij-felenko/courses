# 🧮 Математична модель ударної іонізації та тунелювання Зенера

Для кількісного опису зворотного пробою напівпровідникового p-n переходу застосовують дві фундаментальні математичні моделі: квантовомеханічну модель тунелювання Зенера та феноменологічну модель лавинного множення Таунсенда–Чиновета.

### 1. Квантове тунелювання Зенера (наближення ВКБ)

У сильному електричному полі `E` потенціальний бар'єр між валентною зоною p-області та зоною провідності n-області можна подати у вигляді трикутного або параболічного бар'єра висотою, що дорівнює ширині забороненої зони `E_g`, та просторовою шириною `W`.

Згідно з квазікласичним наближенням Вентцеля–Крамерса–Бріллюена (ВКБ), ймовірність `P` тунельного переходу електрона з ефективною масою `m*` крізь потенціальний бар'єр `V(x)` визначається дією інваріанта:

```
P(E) = exp[ - (2 / ℏ) · ∫₀Ⱳ √( 2·m*·(V(x) - E) ) dx ]
```

Для однорідного електричного поля напруженістю `E`, де потенціал змінюється за лінійним законом `V(x) = E_g - q·E·x`, інтегрування підрадикального виразу від `x = 0` до межі тунелювання `x = W = E_g / (q·E)` дає точний результат для ймовірності трикутного бар'єра:

```
P(E) = exp( - (4 · √(2·m*) · E_g^(3/2)) / (3 · q · ℏ · E) )
```

У разі врахування двобокового вигину зон напівпровідника (модель Кейна з параболічною дисперсією) коефіцієнт перед експонентою дещо змінюється, даючи класичну формулу тунелювання Зенера:

```
P(E) = exp( - (π · √m* · E_g^(3/2)) / (2·√2 · q · ℏ · E) )
```

де:
- `q` — елементарний заряд електрона (`1.602 × 10⁻¹⁹ Кл`),
- `ℏ` — зведена стала Планка (`1.055 × 10⁻³⁴ Дж·с`),
- `E` — напруженість електричного поля у збідненій області (`В/м`).

Густина тунельного струму Зенера `J_Z` розраховується шляхом інтегрування добутку густини станів, ймовірності тунелювання `P(E)` та різниці функцій розподілу Фермі–Дірака по обидва боки переходу:

```
J_Z = ( √2m* · q³ · E · V_R ) / ( 4 · π³ · ℏ² · E_g^(1/2) ) · exp( - E_0 / E )

[де критичне поле E_0 = (π · √m* · E_g^(3/2)) / (2·√2 · q · ℏ)]
```

Для кремнію (`m* ≈ 0.19 m₀`, `E_g = 1.12 еВ`) критична напруженість поля становить `E_0 ≈ 1.88 × 10⁸ В/м` (`1.88 × 10⁶ В/см`). При наближенні реального поля `E` у збідненій зоні до `E_0` тунельний струм `J_Z` зростає за експоненціальним законом.

### 2. Ударна іонізація та коефіцієнти Чиновета

У помірно легованому переході пробій визначається інтенсивністю ударної іонізації. Здатність носія заряда створювати нові електрон-діркові пари описується **коефіцієнтами ударної іонізації** для електронів `α_n` та дірок `α_p`. Коефіцієнт `α` показує середню кількість іонізацій, яку здійснює один носій на одиниці довжини шляху уздовж поля (`см⁻¹`).

Законом Чиновета (*Chynoweth's Law*) встановлено експоненційну залежність `α` від напруженості поля `E`, яка випливає з теорії Бараффа для розсіювання на оптичних фононах:

```
α_n(E) = a_n · exp( - b_n / E )
α_p(E) = a_p · exp( - b_p / E )
```

Для кремнію (`Si`) за кімнатної температури феноменологічні параметри становлять:
- `a_n ≈ 7.03 × 10⁵ см⁻¹`, `b_n ≈ 1.23 × 10⁶ В/см`,
- `a_p ≈ 1.58 × 10⁶ см⁻¹`, `b_p ≈ 2.04 × 10⁶ В/см`.

Принципово важливо, що у кремнії коефіцієнт іонізації електронів `α_n` суттєво перевищує коефіцієнт іонізації дірок `α_p` при однакових полях (`α_n >> α_p`). Це пояснюється відмінностями у зонній структурі: валентна зона кремнію має вищу ефективну масу дірок і сильніше фононне розсіювання, через що діркам важче набрати порогову енергію іонізації `E_th ≈ 1.5 E_g`.

### 3. Коефіцієнт лавинного множення M та інтеграл іонізації

Розглянемо збіднену область шириною `W` від `x = 0` (p-бік) до `x = W` (n-бік). Нехай у точку `x = 0` входить початковий електронний струм `I_n(0)`. Під дією поля на елементарному проміжку `dx` електрони створюють приріст струму за рахунок іонізації:

```
dI_n / dx = α_n · I_n(x) + α_p · I_p(x)
```

Оскільки повний струм `I = I_n(x) + I_p(x)` залишається сталим уздовж усього переходу у стаціонарному режимі, підстановка `I_p(x) = I - I_n(x)` дає диференціальне рівняння першого порядку:

```
dI_n / dx - (α_n - α_p) · I_n(x) = α_p · I
```

Множачи обидва боки на інтегрувальний фактор `exp[ - ∫₀ˣ (α_n - α_p) dx' ]` та інтегруючи від `x = 0` до `x = W` з граничними умовами `I_n(0) = I_in` та `I_n(W) = I`, отримуємо точний вираз для **коефіцієнта лавинного множення електронів** `M_n = I / I_in`:

```
1 - 1/M_n = ∫₀Ⱳ α_n · exp[ - ∫ₓⱲ (α_n - α_p) dx' ] dx
```

Аналогічно, для коефіцієнта множення дірок `M_p`, які входять у точку `x = W`, отримуємо:

```
1 - 1/M_p = ∫₀Ⱳ α_p · exp[ - ∫₀ˣ (α_p - α_n) dx' ] dx
```

#### Умова пробою та інтеграл іонізації

Точка лавинного пробою відповідає математичній умові `M → ∞` (знаменник прямує до нуля). Це дає **умову пробою за інтегралом іонізації**:

```
∫₀Ⱳ α_n · exp[ - ∫ₓⱲ (α_n - α_p) dx' ] dx = 1
```

Для спрощеного випадку симетричних коефіцієнтів іонізації (`α_n = α_p = α`) інтегрувальний фактор перетворюється на одиницю, і умова пробою набуває максимально простого фізичного вигляду:

```
∫₀Ⱳ α(E(x)) dx = 1    ⇒    M → ∞
```

Фізичний зміст цього рівняння: середня кількість нових електрон-діркових пар, породжених первинним носієм на всьому шляху крізь збіднену область, дорівнює точно одиниці. При досягненні цієї межі лавинний розряд стає самопідтримуваним.

### 4. Розрахунок напруги пробою для резкого p⁺-n переходу

Розглянемо різкий однобічний p⁺-n перехід, де `N_A >> N_D`. Збіднена область практично повністю лежить у слабо легованій n-області шириною `W`. Розподіл електричного поля є лінійним:

```
E(x) = E_max · ( 1 - x / W )
```

де максимальне поле `E_max` на межі зв'язане із прикладеною напругою `V_R` та шириною `W`:

```
E_max = ( 2 · V_R ) / W
W = √ ( (2 · ε · ε₀ · V_R) / (q · N_D) )
```

Підставляючи `W` у вираз для `E_max`, маємо співвідношення між максимальною напруженістю поля та концентрацією домішок:

```
E_max = √ ( (2 · q · N_D · V_R) / (ε · ε₀) )
```

Підставляючи лінійний розподіл поля `E(x)` в інтеграл іонізації `∫₀Ⱳ α(E(x)) dx = 1` та використовуючи апроксимацію Фуллопа для кремнію (`α(E) ≈ 1.8 × 10⁻³⁵ · E⁷`), можна виконати аналітичне інтегрування:

```
∫₀Ⱳ α(E) dx = ( ε · ε₀ / (q · N_D) ) · ∫₀ᵉᵐᵃˣ α(E) dE = 1
```

Після підстановки степеневого закону отримуємо підінтегральний вираз, який дає залежність критичного поля `E_crit` та напруги пробою `V_BR` від концентрації домішок `N_D`:

```
V_BR ≈ 60 · ( N_D / 10¹⁶ см⁻³ )^(-3/4)  [Вольт]
```

Ця фундаментальна формула показує:
- Що **нижчий рівень легування** `N_D`, то ширша збіднена область `W` і то **вища напруга пробою** `V_BR`.
- Для високовольтних приладів (наприклад, силних диодів на `1200 В`) кремній легують дуже слабо (`N_D ≈ 10¹⁴ см⁻³`), що вимагає товщини збідненої зони понад `100 мкм`.
- Для низьковольтних стабілітронів (`V_BR ≈ 6 В`) концентрація домішок становить `N_D ≈ 10¹⁷ см⁻³`.

### 5. Емпірична формула Міллера та динамічний опір

Для практичного розрахунку ВАХ діода у передпробійній та пробійній областях використовують емпіричне співвідношення Міллера, яке точно апроксимує розв'язок інтеграла іонізації:

```
M = 1 / ( 1 - (V_R / V_BR)^n )
```

Показник степеня `n` залежить від типу провідності матеріалу та профілю легування:
- Для p⁺-n кремнієвих переходів: `n ≈ 3 ... 4`,
- Для n⁺-p кремнієвих переходів: `n ≈ 5 ... 6`.

Диференціюючи формулу Міллера за напругою `V_R`, можна виразити **динамічний опір** діода `R_z = dV_R / dI_R` через струм пробою `I_R`:

```
dI_R / dV_R = I_s · (dM / dV_R) = I_R · ( (n / V_BR) · (V_R / V_BR)^(n-1) / (1 - (V_R / V_BR)^n) )
```

Оскільки у глибокому пробої `V_R ≈ V_BR`, вираз спрощується до:

```
R_z = dV_R / dI_R ≈ V_BR / ( n · I_R )
```

Ця формула показує, що зi зростанням струму пробою `I_R` динамічний опір стабілітрона `R_z` зменшується обернено пропорційно струму. Саме це пояснює високу якість стабілізації напруги при більших робочих струмах.
