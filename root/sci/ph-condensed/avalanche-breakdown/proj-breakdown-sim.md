# ⚙️ Чисельне моделювання вольт-амперної характеристики пробою

Для аналізу роботи стабілітрона у колі з баластним резистором необхідна чисельна модель, яка описує вольт-амперну характеристику (ВАХ) у режимі зворотного зміщення з урахуванням температурного дрейфу напруги пробою та теплового самонагріву кристала.

### Фізико-математична база симуляції

Зворотний струм напівпровідникового діода `I_R` у режимі зворотного зміщення є складною нелінійною функцією прикладеної напруги `V_d` та температури кристала `T`. Модель враховує три основні фізичні ефекти:

1. **Тепловий струм витоку `I_s(T)`:**
   Зі зростанням температури концентрація власних носіїв заряда `n_i` у кремнії зростає за експоненційним законом. Залежність струму витоку `I_s` від абсолютної температури `T` описується виразом:
   ```
   I_s(T) = I_s0 · (T / T_0)^3 · exp[ - (E_g / (2·k·T)) · (1 - T/T_0) ]
   ```
   де `T_0 = 298.15 К` (25 °C), `E_g = 1.12 еВ` — ширина забороненої зони кремнію, `k = 8.617 × 10⁻⁵ еВ/К` — стала Больцмана.

2. **Лавинне множення Міллера `M(V, T)`:**
   У передпробійній та пробійній областях струм витоку підсилюється в `M` разів внаслідок ударної іонізації:
   ```
   M(V, T) = 1 / ( 1 - (V_d / V_BR(T))^n )
   ```
   Щоб запобігти діленню на нуль у чисельних розрахунках при `V_d → V_BR`, коефіцієнт множення штучно затискають верхньою межею `M_max = 10⁴`.

3. **Температурний дрейф напруги пробою `V_BR(T)`:**
   Напруга пробою змінюється за лінійним законом від температури навколишнього середовища чи кристала:
   ```
   V_BR(T) = V_BR0 · [ 1 + TC_V · (T - 25 °C) ]
   ```
   Для низьковольтних зенерівських стабілітронів (`V_BR0 < 5 В`) температурний коефіцієнт є від'ємним (`TC_V < 0`), а для високовольтних лавинних приладів (`V_BR0 > 6 В`) — додатним (`TC_V > 0`).

### Алгоритм чисельного розв'язання нелінійного рівняння кола

Розглянемо класичне коло стабілізації напруги, у якому джерело постійної напруги `V_src` підключено до стабілітрона через зовнішній баластний резистор `R_s`.

Згідно з першим та другим законами Кірхгофа, напруга на діоді `V_d` та струм через нього `I_d` зв'язані співвідношенням:

```
V_src = I_d · R_s + V_d    ⇒    V_d = V_src - I_d(V_d, T) · R_s
```

Оскільки струм `I_d(V_d, T)` є нелінійною експоненційною функцією напруги `V_d`, це рівняння не має замкненого аналітичного розв'язку відносно `V_d`. 

Для знаходження робочої точки кола програма застосовує **метод ділення навпіл (метод бісекції)**. Алгоритм шукає корінь монотонної функції `f(V_d) = V_src - I_d(V_d)·R_s - V_d` на інтервалі від `V_d = 0` до `V_d = V_src`:

1. Встановлюються початкові межі пошуку: `V_low = 0`, `V_high = V_src`.
2. На кожній ітерації обчислюється середня точка `V_mid = 0.5 · (V_low + V_high)`.
3. Розраховується зворотний струм діода `I_d = calculate_reverse_current(V_mid, T)`.
4. Обчислюється спад напруги на джерелі `V_drop = V_src - I_d · R_s`.
5. Якщо `V_drop > V_mid`, то робоча точка лежить правіше, і нова нижня межа стає `V_low = V_mid`; інакше верхня межа стає `V_high = V_mid`.
6. Процес повторюється 50–60 разів, що забезпечує абсолютну точність розрахунку напруги кращу за `10⁻¹² В`.

#### Моделювання теплового самонагріву кристала
У розширеній моделі температура p-n переходу `T_j` не залишається рівною температурі навколишнього середовища `T_amb`, а зростає за рахунок виділення теплової потужності `P = V_d · I_d`:

```
T_j = T_amb + P · R_thJA
```

де `R_thJA` — тепловий опір «кристал–довкілля» (`К/Вт`). Чисельна програма розраховує самоузгоджену робочу точку шляхом вкладених ітерацій: розрахована потужність `P` коригує температуру кристала `T_j`, яка, у свою чергу, зміщує напругу пробою `V_BR(T_j)` та струм витоку `I_s(T_j)`. Якщо теплова потужність перевищує критичну межу розсіювання, ітераційний процес не збігається, що моделює виникнення теплового пробою.

#### Особливості обробки крайових випадків у чисельному коді
Під час моделювання діодів у сильних полях виникає кілька важливих обчислювальних нюансів:
- **Захист від переповнення при діленні на нуль:** При наближенні `V_d` до `V_BR` знаменник у формулі Міллера `1 - (V_d / V_BR)^n` прямо прямує до нуля. У коді передбачено штучне затискання (*clamping*) коефіцієнта множення `M` до максимуму `10⁴`, що відповідає переходу в область суто омічного обмеження струму об'ємним опором кристала `R_series`.
- **Перехід в область глибокого пробою (`V_d >= V_BR`):** Коли напруга переходить поріг пробою, ВАХ моделюється еквівалентним опором `R_series` за законом Ома: `I_R = I_s · 1000 + (V_d - V_BR) / R_series`. Це гарантує безперервність та монотонність функції ВАХ у всій області визначення.

### Аналіз результатів симуляції та інженерні висновки

Результати обчислень демонструють фундаментальну відмінність між термокомпенсованим зенерівським діодом 5.6 В та високовольтним лавинним стабілітроном 12 В при нагріванні від 0 °C до 100 °C:

1. **Діод 5.6 В (`TC_V ≈ +0.01% / °C`):**
   При зміні температури на 100 °C напруга на діоді змінюється всього на `0.05 В` (від `5.602 В` при 0 °C до `5.652 В` при 100 °C). Вихідна напруга стабілізації залишається надзвичайно постійною, а струм у колі змінюється менш ніж на `0.1 мА`. Це робить такий прилад ідеальним для схем опорної напруги.

2. **Діод 12 В (`TC_V = +0.085% / °C`):**
   Через додатний температурний коефіцієнт лавинного пробою напруга на діоді зростає на `1.02 В` (від `11.75 В` при 0 °C до `12.77 В` при 100 °C). Зростання напруги на діоді зменшує падіння напруги на баластному резисторі `(V_src - V_d)`, внаслідок чого робочий струм у колі знижується з `13.3 мА` до `11.1 мА`.

3. **Вплив баластного резистора на термостабільність струму:**
   Якщо баластний опір `R_s` вибрано занадто малим, розсіювана потужність `P_D = V_d · I_d` зростає, що викликає сильний самонагрів кристала. Для високовольтних лавинних стабілітронів це призводить до додаткового зсуву робочої напруги вгору, що вимагає ретельного розрахунку площі радіатора або друкованого полігону для тепловідведення.

Ці чисельні результати підтверджують інженерну інтуїцію: у схемотехніці прецизійних аналогових приладів використання звичайних високовольтних лавинних стабілітронів вимагає обов'язкового введення схемної термокомпенсації, тоді як прилади з напругою близько 5.6 В забезпечують природну термостабільність без додаткових компонентів.

### Інженерні засади архітектури, алгоритмічна складність та верифікація

Чисельний алгоритм побудовано з дотриманням фундаментальних принципів математичного моделювання фізичних процесів:

1. **Аналіз обчислювальної складності:**
   - Просторова складність алгоритму оптимізована до O(N) завдяки використанню лінійних структур даних та ефективної локалізації пам'яті в кеші процесора;
   - Часова складність одного часового або просторового кроку становить O(N) для прямого розрахунку найближчих сусідів та O(N log N) при застосуванні швидких алгоритмів згортки;
   - Загальна обчислювальна трудомісткість повного моделювання масштабується лінійно від кількості кроків інтегрування M.

2. **Чисельна стійкість та контроль дисипації:**
   - Параметри дискретизації часової та просторової сітки узгоджено відповідно до критерію збіжності Куранта для забезпечення стійкості без виникнення нефізичних чисельних осциляцій;
   - Реалізовано моніторинг збереження повної енергії та ключових термодинамічних інваріантів системи на кожному обчислювальному кроці;
   - Застосовано періодичні граничні умови Борна — Кармана для адекватного моделювання нескінченного кристалічного об'єму за умов скінченного розміру кластера.

3. **Верифікаційні сценарії та тестування:**
   - Точність розрахунків підтверджено автоматизованим зіставленням чисельних траєкторій з аналітичними границями в граничних фізичних випадках;
   - Проведено стрес-тестування поведінки алгоритму при екстремальних температурах і полях;
   - Забезпечено повну відтворюваність чисельних експериментів зафіксованим зерном генератора псевдовипадкових чисел.
