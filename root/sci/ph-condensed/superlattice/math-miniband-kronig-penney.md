# 🧮 Математичний вивід зонної структури, ефективної маси та вольт-амперної характеристики Есакі — Цо

Розглянемо одновимірну квантово-механічну модель носія заряду (електрона з ефективною масою `m*` та зарядом `q = -e`), що рухається уздовж осі росту суперґратки `z` у періодичному потенціалі `V(z) = V(z + d)`, де `d = d_1 + d_2` — період суперґратки (`d_1` — товщина квантової ями, `d_2` — товщина потенціального бар'єра заввишки `V_0`).

---

### 1. Точне матричне виведення закону дисперсії Кроніґа — Пенні

Формування мінізонного спектра суперґратки описується одновимірним стаціонарним рівнянням Шредінгера для електронної хвильової функції `ψ(z)` у періодичному потенційному рельєфі:

```
[ - (ℏ² / (2 · m*)) · (d² / dz²)  +  V(z) ] · ψ(z) = E_z · ψ(z)
```

Розглянемо один період суперґратки від `z = 0` до `z = d`:
- У квантовій ямі (`0 ≤ z < d_1`), де `V(z) = 0`, хвильова функція є комбінацією плоских хвиль із волновим вектором `α = √(2 · m*_1 · E) / ℏ`.
- У потенціальному бар'єрі (`d_1 ≤ z < d`), де `V(z) = V_0` (при енергії електрона `E < V_0`), хвильова функція описується згасаючими експонентами з коефіцієнтом затухання `β = √(2 · m*_2 · (V_0 - E)) / ℏ`.

Згідно з граничними умовами сшивання БенДаніеля — Дюка на гетероінтерфейсах, неперервними мають бути сама хвильова функція `ψ(z)` та зважений потік `(1 / m*) · (dψ / dz)`.

Складаючи матрицю передачі (*transfer matrix*) через період `d` та застосовуючи теорему Блоха `ψ(z + d) = exp(i · k_z · d) · ψ(z)`, отримуємо точне трансцендентне дисперсійне рівняння Кроніґа — Пенні для суперґратки:

```
cos(k_z · d) = cos(α · d_1) · cosh(β · d_2)  +  (1/2) · ( (m*_2 · α) / (m*_1 · β)  -  (m*_1 · β) / (m*_2 · α) ) · sin(α · d_1) · sinh(β · d_2)
```

Цей точний вираз визначає дозволені енергетичні мінізони (де праворуч стоячий вираз за модулем не перевищує одиницю) та заборонені мініщілини (де модуль виразу більший за одиницю, що робить хвильовий вектор `k_z` уявним).

### 2. Наближення сильного зв'язку та косинусоїдальний закон дисперсії

Коли товщина бар'єрів `d_2` або їхня висота `V_0` є достатньо великими (`β · d_2 >> 1`), тунельне зв'язування між сусідніми ямами слабшає, а дозволені мінізони стають вузькими. У цьому випадку точне трансцендентне рівняння Кроніґа — Пенні розкладається у околі дискретного енергетичного рівня `E_0` ізольованої квантової ями.

Розкладаючи хвильову функцію електрона за базисом локалізованих функцій Ванньє `ϕ(z - n · d)`:

```
ψ_{k_z}(z) = (1 / √N) · ∑_n exp(i · n · k_z · d) · ϕ(z - n · d)
```

Підставляючи цей розклад у рівняння Шредінгера та підраховуючи матричні елементи Гамільтоніана, отримуємо:

```
E(k_z) = E_0 - 2 · I_t · cos(k_z · d)                  [наближення найближчих сусідів]
       = E_0 - (Δ / 2) · cos(k_z · d)                 [вираження через ширину мінізони Δ = 4 · I_t]
```

де `I_t` — тунельний інтеграл перекриття функцій Ванньє сусідніх ям:

```
I_t = - ∫ ϕ*(z) · ΔV(z) · ϕ(z - d) dz
```

Фізичний зміст інтеграла `I_t` полягає у вимірюванні ймовірності тунелювання електрона крізь потенціальний бар'єр за одиницю часу. Ширина мінізони `Δ = 4 · I_t` прямо пропорційна коефіцієнту прозорості бар'єра і спадає експоненціально зі зростанням товщини бар'єра `d_2`:

```
Δ ∝ exp( - β · d_2 ) = exp( - d_2 · √(2 · m*_2 · (V_0 - E)) / ℏ )
```

У тривимірному просторі з урахуванням параболічного вільного руху у площині шарів `(x, y)` повний закон дисперсії набуває вигляду:

```
E(k_x, k_y, k_z) = ℏ² · (k_x² + k_y²) / (2 · m*_\perp)  +  E_0 - (Δ / 2) · cos(k_z · d)
```

### 3. Густина станів та анізотропія електронного спектра

Двовимірний характер руху носіїв відображається на енергетичній густині станів `g(E)`.

Густина станів на одиницю об'єму для квазідвовимірної мінізони обчислюється інтегруванням по поверхні постійної енергії у `k`-просторі:

```
g(E) = (m*_\perp / (π² · ℏ² · d)) · arccos( - 2 · (E - E_0) / Δ )
```

У межах мінізони (`E_0 - Δ/2 ≤ E ≤ E_0 + Δ/2`) густина станів має східчастий вигляд із ванхововськими особливостями на межах мінізони. Це різко відрізняє суперґратку від звичайного 3D-напівпровідника, де густина станів зростає за коренєвим законом `g(E) ∝ √(E)`.

### 4. Группова швидкість та тензор ефективної маси

Динамічні властивості електрона у мінізоні визначаються похідними закону дисперсії `E(k_z)`.

Групова швидкість електрона вздовж осі росту суперґратки дорівнює першій похідній енергії за хвильовим вектором:

```
v_z(k_z) = (1 / ℏ) · (∂E / ∂k_z)
         = (Δ · d / (2 · ℏ)) · sin(k_z · d)            [групова швидкість у мінізоні]
```

Аналіз виразу для группової швидкості показує:
1. Біля дна мінізони (`k_z = 0`) та на межі зони Бріллюена (`k_z = ± π/d`) швидкість електрона дорівнює нулю.
2. Максимальна швидкість носія досягається посередині зони Бріллюена (`k_z = π / (2 · d)`):

```
v_{z,max} = Δ · d / (2 · ℏ)
```

Ефективна маса електрона уздовж осі росту `m*_z(k_z)` визначена як обернене значення другої похідної:

```
1 / m*_z(k_z) = (1 / ℏ²) · (∂²E / ∂k_z²)
              = (Δ · d² / (2 · ℏ²)) · cos(k_z · d)      [тензор оберненої ефективної маси]
```

Звідси слідує існування двох протилежних знаків маси:
- У нижній половині мінізони (`|k_z| < π / (2 · d)`): `cos(k_z · d) > 0`, маса є позитивною `m*_z > 0`.
- У верхній половині мінізони (`π / (2 · d) < |k_z| ≤ π / d`): `cos(k_z · d) < 0`, маса стає **негативною** `m*_z < 0`.

Прискорення електрона під дією сили `F_e = -e · F` описується виразом:

```
a_z = (1 / m*_z(k_z)) · (- e · F) = - (e · F · Δ · d² / (2 · ℏ²)) · cos(k_z · d)
```

Коли електрон прискорюється поле у верхню частину зони (`k_z > π / (2 · d)`), його прискорення змінює знак: сила штовхає електрон в один бік, а його швидкість зменшується!

### 5. Квантова динаміка Блохівських осциляцій

У постійному електричному полі `F` напівкласична часова еволюція хвильового вектора має вигляд:

```
ℏ · (dk_z / dt) = - e · F                             [напівкласичне рівняння руху]
k_z(t) = k_z(0) - (e · F · t / ℏ)                     [часова залежність хвильового вектора]
```

Підставляючи `k_z(t)` у вираз для группової швидкості:

```
v_z(t) = (Δ · d / (2 · ℏ)) · sin( k_z(0) · d  -  e · F · d · t / ℏ )
```

Інтегруючи швидкість за часом від `0` до `t`, отримуємо закон зміни координати електрона у реальному просторі:

```
z(t) = z(0) + (Δ / (2 · e · F)) · cos( ω_B · t  -  k_z(0) · d )
```

де `ω_B` — частота Блохівських осциляцій:

```
ω_B = e · F · d / ℏ                                   [блохівська частота]
```

Просторова амплітуда розмаху осциляцій електрона у реальному просторі становить:

```
z_B = Δ / (2 · e · F)                                 [амплітуда блохівських осциляцій]
```

Ці рівняння доводять, що у відсутність розсіювання постійне електричне поле не викликає постійного струму, а змушує електрон локалізовано осцилювати у просторі з частотою `ω_B`.

### 6. Виведення вольт-амперної характеристики Есакі — Цо з рівняння Больцмана

Для врахування процесів розсіювання скористаємося кінетичним рівнянням Больцмана у наближенні часу релаксації `τ`. 

Імовірність того, що електрон рухається без зіткнень протягом часу `t`, описується пуассонівським розподілом `P(t) = (1 / τ) · exp(-t / τ)`. Середня дрейфова швидкість ансамблю електронів `v_d(F)` обчислюється як інтеграл від миттєвої швидкості:

```
v_d(F) = (1 / τ) · ∫₀^∞ v_z(t) · exp(-t / τ) dt        [усереднення швидкості за часом]
```

Припустивши, що після кожного акту розсіювання імпульс електрона повністю релаксує до дна зони (`k_z(0) = 0`):

```
v_d(F) = (Δ · d / (2 · ℏ · τ)) · ∫₀^∞ sin( e · F · d · t / ℏ ) · exp(-t / τ) dt
```

Використовуючи точний інтеграл `∫₀^∞ sin(a · t) · exp(-b · t) dt = a / (a² + b²)`, отримуємо:

```
v_d(F) = (Δ · d / (2 · ℏ · τ)) · ( (e · F · d / ℏ) / ( (e · F · d / ℏ)² + (1 / τ)² ) )
       = (Δ · d / (2 · ℏ)) · ( (e · F · d · τ / ℏ) / ( 1 + (e · F · d · τ / ℏ)² ) )
```

Ввівши позначення критичного поля `F_c` та пикової швидкості `v_max`:

```
F_c = ℏ / (e · d · τ)                                 [критичне поле Есакі — Цо]
v_max = Δ · d / (4 · ℏ)                                [пікова дрейфова швидкість]
```

Отримуємо остаточну закриту формулу вольт-амперної характеристики Есакі — Цо:

```
v_d(F) = v_max · ( 2 · (F / F_c) / ( 1 + (F / F_c)² ) )  [формула транспорту Есакі — Цо]
```

#### Аналіз граничних режимів транспорту:

1. **Малі поля (`F << F_c`):** Знаменник прямує до одиниці, і дрейфова швидкість зростає лінійно з полем:
```
v_d(F) ≈ v_max · (2 · F / F_c) = μ_0 · F              [лінійний омічний режим]
```
де дрейфова рухливість електронів дорівнює `μ_0 = e · d² · Δ · τ / (2 · ℏ²)`.

2. **Великі поля (`F >> F_c`):** У знаменнику домінує квадрат поля, і дрейфова швидкість спадає зворотньо пропорційно полю:
```
v_d(F) ≈ v_max · (2 · F_c / F)                         [режим негативного опору]
```
Диференціальна рухливість `μ_diff = dv_d / dF` стає негативною:
```
μ_diff = (2 · v_max / F_c) · ( (1 - (F / F_c)²) / (1 + (F / F_c)²)² ) < 0
```
Це прямо доводить виникнення ефекту негативного диференціального опору при полях `F > F_c`.
