# 📋 Параметри епітаксійного вирощування та матеріальні специфікації суперґраток

Цей довідник містить детальні системні параметри, фізичні характеристики розривів енергетичних зон, решіткового узгодження, ростових режимах молекулярно-променевої епітаксії (*MBE*) і металоорганічної газофазної епітаксії (*MOCVD*), а також конструктивні специфікації активних областей квантово-каскадних структур.

---

### 1. Механізми епітаксійного росту та вимоги до гетероінтерфейсів

Створення напівпровідникових суперґраток вимагає формування кристалічно досконалих періодичних шарів із товщиною від кількох моношарів до кількох нанометрів. Головною умовою спостереження квантово-розмірних ефектів є атомна гострота гетероінтерфейсів, коли перехід від одного хімічного складу до іншого відбувається на відстані, що не перевищує одного моноатомного шару (`≤ 0.28 нм`).

У термодинаміці кристалічного росту виділяють три основні морфологічні режими епітаксії, що визначаються співвідношенням міжповерхневих енергій підкладки `γ_s`, епітаксійного шару `γ_f` та межі розділу `γ_{i}`:

1. **Двовимірний пошаровий ріст Франка — ван дер Мерве (`γ_s ≥ γ_f + γ_i`):** Атоми, що осідають на поверхню, утворюють стійкі двовимірні острівці заввишки в один атомний шар, які зливаються у суцільний моношар перед початком формування наступного. Це єдиний режим, який забезпечує створення атомно-гладких гетероінтерфейсів суперґраток.
2. **Тривимірний острівковий ріст Вольмера — Вебера (`γ_s < γ_f + γ_i`):** Атоми матеріалу шару сильніше зв'язані між собою, ніж із підкладкою, що призводить до негайного утворення 3D-кластерів. Цей режим непридатний для суперґраток.
3. **Гібридний ріст Странського — Крастанова:** Початковий ріст декількох моношарів відбувається двовимірно (змочувальний шар), після чого через накопичення пружної енергії невідповідності ґраток відбувається спонтанний перехід до формування 3D-квантових точок.

Для забезпечення пошарового росту Франка — ван дер Мерве під час вирощування суперґраток необхідне прецизійне підтримання температури підкладки та співвідношення парціальних тисків молекулярних пучків.

### 2. Фундаментальні параметри напівпровідникових гетеропар

Нижче наведено зведені матеріальні параметри ключових гетеропар, що використовуються у квантовій інженерії суперґраток при температурі `T = 300 К`. Значення розривів зони провідності `ΔE_c` та валентної зони `ΔE_v` визначені відносно вакуумного рівня з урахуванням ефектів решіткових напружень:

| Матеріальна гетеропара | Тип вирівнювання зон | Розрив E_c (ΔE_c, еВ) | Розрив E_v (ΔE_v, еВ) | Постійна ґратки a₀ (нм) | Невідповідність ґраток (Δa / a₀) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **`GaAs / Al_{0.3} Ga_{0.7} As`** | Тип I (Вкладена) | `0.24` | `0.15` | `0.5653 / 0.5656` | `< 0.05%` |
| **`GaAs / AlAs`** | Тип I (Пряма) / Тип II (`X`) | `0.98` | `0.55` | `0.5653 / 0.5660` | `0.12%` |
| **`In_{0.53} Ga_{0.47} As / In_{0.52} Al_{0.48} As`** | Тип I (На підкладці `InP`) | `0.52` | `0.21` | `0.5869 / 0.5869` | `0.00%` (узгоджено) |
| **`InAs / GaSb`** | Тип II (Розірвана) | `-0.15` (перекриття) | `0.51` | `0.6058 / 0.6096` | `0.62%` |
| **`InAs / AlSb`** | Тип II (Зсунута) | `1.35` | `0.40` | `0.6058 / 0.61355` | `1.27%` |
| **`Si / Si_{0.7} Ge_{0.3}`** | Тип II (Напружена) | `0.18` (підкладка `Si`) | `0.15` | `0.5431 / 0.5497` | `1.22%` |
| **`HgTe / CdTe`** | Тип III (Дираківська) | `0.35` | `0.85` | `0.6460 / 0.6480` | `0.31%` |

#### Фізичний опис ключових матеріальних систем:

1. **Система `GaAs / Al_x Ga_{1-x} As`:** Класична еталонна гетеропара для суперґраток. Оскільки постійні кристалічних ґраток `GaAs` та `AlAs` розрізняються менше ніж на `0.12%`, напруження на інтерфейсах практично відсутні. Це дозволяє ростити структури з сотнями періодів без загрози утворення дислокацій.
2. **Система `In_{0.53} Ga_{0.47} As / In_{0.52} Al_{0.48} As` на підкладці `InP`:** Ідеально решітково-узгоджена система, що використовується для створення телекомунікаційних лазерів та підсилювачів на довжинах хвиль `1.33 мкм` та `1.55 мкм`, а також квантово-каскадних лазерів середнього інфрачервоного діапазону. Вона має великий розрив зони провідності `ΔE_c = 0.52 еВ`, що забезпечує глибоке квантове обмеження електронів.
3. **Система `InAs / GaSb` (Розірвана зона):** У цій системі дно зони провідності `InAs` розташоване нижче за верх валентної зони `GaSb`. Це призводить до унікального ефекту самодопування: електрони з валентної зони `GaSb` спонтанно переходять у зону провідності `InAs`, створюючи високу концентровану провідність без внесення легуючих домішок.

### 3. Феноменологічні залежності розривів зон у потрійних розчинах

Для розрахунку глибини потенціальних ям та висоти бар'єрів у гетероструктурах на основі потрійних сполук використовуються емпіричні залежності ширини забороненої зони та розривів енергетичних зон від мольної частки компонентів.

Для прямозонного твердого розчину `Al_x Ga_{1-x} As` при `0 ≤ x ≤ 0.45` залежність ширини забороненої зони при кімнатній температурі описується формулою:

```
ΔE_g(x) = 1.247 · x                                  [зміна ширини забороненої зони, еВ]
ΔE_c(x) = 0.60 · ΔE_g(x) = 0.748 · x                 [розрив зони провідності, еВ]
ΔE_v(x) = 0.40 · ΔE_g(x) = 0.499 · x                 [розрив валентної зони, еВ]
```

Для складових з `x > 0.45` відбуваються зміни у зонній структурі: абсолютний мінімум зони провідності переходить від `Γ`-долини до `X`-долини. Залежність енергії `X`-мінімуму описується співвідношенням:

```
ΔE_c^{(X)}(x) = 0.748 · x - 1.247 · (x - 0.45)        [розрив X-долини, еВ]
```

Цей перехід важливий при проектуванні бар'єрів суперґраток: якщо частка алюмінію перевищує `x = 0.45`, тунелювання електронів починає відбуватися не лише крізь `Γ`-бар'єр, але й за участю інтердолинного розсіювання у `X`-мінімум, що змінює ефективний коефіцієнт прозорості бар'єра.

### 4. Ростові режими молекулярно-променевої епітаксії (MBE)

Молекулярно-променева епітаксія є основним методом вирощування якісних напівпровідникових суперґраток. Процес відбувається у надвисокому вакуумі при тиску залишкових газів менше `10⁻¹⁰ Торр`, що унеможливлює забруднення ростового фронту киснем або вуглецем.

Нижче наведено технологічні параметри ростових процесів для основних класів суперґраток:

| Технологічний параметр | Значення для `GaAs / AlGaAs` | Значення для `InAs / GaSb` | Значення для `Si / SiGe` |
| :--- | :--- | :--- | :--- |
| **Температура підкладки `T_{sub}`** | `580–600 °C` | `490–510 °C` | `500–550 °C` |
| **Швидкість росту (`v_{growth}`)** | `1.0 моношарів/с` (`≈ 0.28 нм/с`) | `0.5 моношарів/с` (`≈ 0.15 нм/с`) | `0.2 нм/с` |
| **Тиск пучка (BEP `As₄ / Ga`)** | `15–20` | `5–10` (`As₂ / Sb₄`) | — |
| **Ширина гетероінтерфейсу** | `≤ 1 моношар` (`≤ 0.3 нм`) | `1–2 моношари` | `2–3 моношари` |
| **Контроль поверхні** | RHEED осциляції | RHEED осциляції | Ellipsometry / LEED |
| **Фоновий тиск у камері** | `< 5 · 10⁻¹¹ Торр` | `< 5 · 10⁻¹¹ Торр` | `< 1 · 10⁻¹⁰ Торр` |

#### Контроль ростового фронту за допомогою RHEED:
Метод дифракції швидких електронів на відбиття (*RHEED — Reflection High-Energy Electron Diffraction*) слугує головним інструментом контролю росту у реальному часі. Електронний пучок з енергією `10–30 кеВ` падає на поверхню росту під ковзним кутом `1–2°`. 

Інтенсивність дзеркально відбитого пучка RHEED зазнає періодичних осциляцій, причому період однієї осциляції точно відповідає часу формування одного атомарного моношару. Загасання амплітуди осциляцій свідчить про накопичення поверхневої шорсткості, що вимагає застосування процедури ростової паузи (*growth interruption*) для атомарного вигладжування поверхні перед вирощуванням наступного гетероінтерфейсу.

### 5. Конструктивна специфікація активної області квантово-каскадного лазера (QCL)

Квантово-каскадний лазер є найбільш складною багатошаровою наноструктурою, яка містить від 500 до 2000 окремих епітаксійних шарів із товщинами, розрахованими з точністю до `0.1 нм`.

Нижче наведено специфікацію одного періоду каскаду активної зони QCL на основі решітково-узгодженої гетеросистеми `In_{0.53} Ga_{0.47} As / In_{0.52} Al_{0.48} As` на підкладці `InP`, що випромінює на довжині хвилі `λ ≈ 9.2 мкм`:

```
Послідовність шарів періоду (товщини у нм):
[ 3.8 / 2.1 / 1.2 / 6.5 / 1.4 / 5.3 / 1.6 / 4.2 / 2.8 / 3.2 / 3.0 / 2.8 ]
```

*Примітка: жирним шрифтом виділено потенціальні бар'єри `InAlAs`, звичайним — квантові ями `InGaAs`.*

#### Функціональне призначення елементів каскаду:

1. **Інжекторний бар'єр (`3.8 нм InAlAs`):** Товстий тунельний бар'єр, який відокремлює релаксаційну мінізону попереднього каскаду від активної зони. Напруженість зовнішнього поля налаштована так, що квазірівень Фермі інжектора збігається за енергією з верхнім лазерним рівнем `E_3`.
2. **Активна трирівнева яма (`2.1 нм InGaAs / 1.2 нм InAlAs / 6.5 нм InGaAs / 1.4 нм InAlAs / 5.3 нм InGaAs`):** Спеціально спроектована асиметрична подвійна квантова яма. Випромінювальний лазерний перехід відбувається між станами `E_3` та `E_2`. Енергетичний зазор `E_3 - E_2 = 135 меВ` відповідає довжині хвилі випромінювання `λ = 9.2 мкм`.
3. **Депопуляційна система та екстрактор (`1.6 нм / 4.2 нм / 2.8 нм / 3.2 нм / 3.0 нм / 2.8 нм`):** Послідовність тунельно-зв'язаних ям, що утворює розширену мінізону екстракції. Енергетичний інтервал між нижнім лазерним рівнем `E_2` та першим рівнем екстрактора `E_1` дорівнює енергії поздовжнього оптичного фонона `ħ · ω_{LO} ≈ 34 меВ`. Це забезпечує резонансну фононну депопуляцію рівня `E_2` за рекордний час `τ_{21} ≈ 0.4 пс`, що значно менше за час життя верхнього лазерного рівня `τ_{32} ≈ 1.8 пс`. Завдяки цьому жорстко виконується критерій інверсії населеностей `τ_{32} > τ_{21}`.

### 6. Контроль напружень та критична товщина епітаксійного шару

При вирощуванні суперґраток із матеріалів із різними постійними ґратки `a_f` та `a_s` (наприклад, `Si / SiGe` або `InAs / GaAs`), епітаксійний шар на початковій стадії пружно деформується, підлаштовуючи свій кристалічний період у площині інтерфейсу під період підкладки. Це створює двовимірне стискальне або розтягувальне напруження.

Накопичена пружна енергія зростає пропорційно товщині шару `h`. При досягненні критичної товщини `h_c` генерація дислокацій невідповідності стає енергетично вигіднішою за збереження пружної деформації, що призводить до деградації структури.

За моделлю Метьюза — Блейкслі, критична товщина `h_c` обчислюється з рівняння рівноваги сил дислокаційного натягу:

```
h_c ≈ ( b / (8 · π · δ · (1 + ν)) ) · ( ln(h_c / b) + 1 )  [критична товщина Метьюза — Блейкслі]
```

де `b` — модуль вектора Бюргерса дислокації (`b ≈ 0.4 нм` для кристалів зі структурою цинкової обманки), `ν` — коефіцієнт Пуассона (`ν ≈ 0.31`), а `δ = |a_f - a_s| / a_s` — відносна невідповідність періодів ґратки.

#### Пружно-компенсовані суперґратки (*Strain-Compensated Superlattices*):
Для обходу обмеження критичної товщини Метьюза — Блейкслі при вирощуванні товстих багатошарових структур застосовують метод пружної компенсації. У таких суперґратках шар зі стискальним напруженням (наприклад, `InAs` на підкладці `InP`, `δ > 0`) чергується із шаром із розтягувальним напруженням (наприклад, `Ga_{0.3} In_{0.7} As`, `δ < 0`). 

За умови точного балансу товщин та величин напружень `d_1 · δ_1 + d_2 · δ_2 = 0` середня пружна енергія періоду суперґратки дорівнює нулю, що дозволяє ростити досконалі квантово-каскадні структури загальною товщиною понад `3–5 мкм`, які містять тисячі гетероінтерфейсів без жодної дислокації.
