# ⚙️ Чисельне моделювання динаміки електрона, блохівських осциляцій та характеристики Есакі — Цо у суперґратці

Чисельне моделювання квантового та напівкласичного транспорту носіїв у напівпровідникових суперґратках дозволяє дослідити часову еволюцію хвильових пакетів, розрахувати спектр блохівських осциляцій, вивчити ефекти релаксації та змоделювати виникнення негативного диференціального опору (НДО) у приладах наноелектроніки.

---

### 1. Фізична постановка задачі та кінетика носіїв у напівпровідниковій суперґратці

Транспорт носіїв у вузьких мінізонах напівпровідникових суперґраток істотно відрізняється від транспорту у звичайних тривимірних напівпровідниках. Оскільки ширина дозволеної мінізони `Δ` становить лише кілька десятків міліелектронвольт, електричне поле помірної напруженості `F ~ 10⁴ В/см` здатне легко перемістити носії через усю зону Бріллюена до її межі `k_z = ± π / d`.

Для опису цієї сильно нерівноважної динаміки використовується напівкласична кінетична теорія на основі рівняння Больцмана для функції розподілу електронів `f(z, k_z, t)` у фазовому просторі. У одновимірній модельній суперґратці з періодом `d` закон дисперсії першої мінізони у наближенні сильного зв'язку має косинусоїдальну форму:

```
E(k_z) = E_0 - (Δ / 2) · cos(k_z · d)
```

де `E_0` — середина мінізони, а `Δ` — її ширина.

На частинку діє зовнішнє електричне поле `F(t)`, яке у загальному випадку містить постійне зміщення `F_{dc}` та високочастотне змінне поле з амплітудою `F_{ac}` і частотою `ω`:

```
F(t) = F_{dc} + F_{ac} · cos(ω · t)
```

Зміна хвильового вектора електрона під дією поля описується динамічним рівнянням:

```
dk_z / dt = - (e / ℏ) · F(t)
```

Миттєва группова швидкість носія визначається першою похідною від енергії за хвильовим вектором:

```
v_z(k_z) = (1 / ℏ) · (dE / dk_z) = (Δ · d / (2 · ℏ)) · sin(k_z · d)
```

Принциповою особливістю цього руху є те, що швидкість частинки не зростає безмежно, а досягає максимуму `v_{z,max} = Δ · d / (2 · ℏ)` при `k_z = π / (2 · d)`. При подальшому зростанні квазіімпульсу у верхній частині мінізони (`k_z > π / (2 · d)`) швидкість зменшується, оскільки ефективна маса носія `m*_z(k_z)` стає негативною:

```
1 / m*_z(k_z) = (1 / ℏ²) · (d²E / dk_z²) = (Δ · d² / (2 · ℏ²)) · cos(k_z · d) < 0
```

### 2. Стохастична модель розсіювання Монте-Карло

У реальному кристалі електрон не рухається безмежно у k-просторі, а зазнає зіткнень з оптичними та акустичними фононами, іонами домішок та гетероінтерфейсними шорсткостями. Для урахування стохастики розсіювання застосовується ансамблевий метод Монте-Карло.

Ймовірність `P_{coll}` того, що електрон зазнає акту розсіювання протягом короткого часового інтервалу `Δt`, визначається за пуассонівською статистикою:

```
P_{coll} = 1 - exp(- Δt / τ)
```

де `τ` — середній час релаксації імпульсу.

Для кожного електрона з ансамблю `N_{part}` на кожному кроці за допомогою датчика псевдовипадкових чисел генерується величина `u`, рівномірно розподілена на півінтервалі `[0, 1)`. 

Якщо виконується умова `u < P_{coll}`, вважається, що відбувся акт розсіювання: хвильовий вектор електрона миттєво релаксує до теплового значення біля дна мінізони `k_z ≈ 0`.

При моделюванні високопольового транспорту враховуються три основні канали розсіювання:
1. **Акустичне фононне розсіювання:** Є квазіпружнім та ізотропним у `k`-просторі, забезпечуючи тепловий розподіл швидкостей при низьких енергіях.
2. **Оптичне фононне розсіювання:** Є непружнім із пороговою енергією випромінювання `ℏ · ω_{LO} ≈ 36 меВ`. Коли кінетична енергія електрона перевищує поріг `E(k_z) ≥ ℏ · ω_{LO}`, електрон миттєво випромінює оптичний фонон і скидає свій квазіімпульс до дна мінізони.
3. **Міжмінізонне тунелювання Зенера:** У надсильних електричних полях `F > 100 кВ/см` електрон може тунелювати крізь мініщілину `E_{mg}` у другу мінізону, що призводить до виходу електрона з режиму Блохівських осциляцій.

### 3. Чисельна схема інтегрування та вибір кроку

Для забезпечення стійкості обчислень та відсутності накопичення чисельної похибки часовий крок `Δt` вибирається з двох фізичних умов:
1. Крок має бути значно меншим за час релаксації імпульсу: `Δt << τ`.
2. Крок має бути значно меншим за період Блохівських осциляцій: `Δt << 2π / ω_B = 2π · ℏ / (e · F · d)`.

Типове значення часового кроку у моделюванні становить `Δt = 1 фс` (`10⁻¹⁵ с`) при часі релаксації `τ = 0.5 пс` (`500 фс`).

Квазіімпульс електрона на `(n+1)`-му кроці обчислюється за схемою Ейлера — Кромера:

```
k_z^{(n+1)} = k_z^{(n)} - (e · F / ℏ) · Δt
```

Після кожного кроку перевіряється умова виходу за межі першої зони Бріллюена `[-π/d, π/d]`. Якщо `k_z` виходить за межу `+π/d`, додається або віднімається обратний вектор суперґратки `G_z = 2π / d` (перенесення Бреґґа).

Дрейфова швидкість ансамблю частинок `v_d(F)` обчислюється усредненням по останній половині симуляційного часу після згасання початкових перехідних процесів:

```
v_d = (1 / T_{sim}) · ∫₀^{T_{sim}} ( (1 / N_{part}) · ∑ v_{z,i}(t) ) dt
```

### 5. Детальний аналіз роботи програми та її архітектури

#### Особливості реалізації мовою C:
1. **Структура `SuperlatticeParams`:** Зберігає всі фізичні та обчислювальні константи структури. Завдяки передачі вказівника `const SuperlatticeParams *` копіювання параметрів у пам'яті відсутнє.
2. **Динамічне виділення пам'яті:** Масив `kz` виділяється у купі за допомогою `malloc` під час кожного виклику функції симуляції та гарантовано звільняється через `free(kz)`.
3. **Обрізання перехідних процесів:** Усереднення швидкості виконується лише для другої половини часових кроків (`step >= total_steps / 2`), що усуває вплив початкового нерівноважного стану заповнення зони.

#### Особливості реалізації мовою C++:
1. **Класовий підхід та безпека типів:** Симулятор реалізовано у вигляді класу `SuperlatticeSimulator` в окремому просторі імен `SuperlatticeSim`.
2. **Управління ресурсами RAII:** Замість сирих вказівників використано контейнер `std::vector<double>`, який автоматично керує пам'яттю та запобігає витокам пам'яті.
3. **Сучасний генератор випадкових чисел:** Замість старого `rand()` застосовано генератор Мерсенна `std::mt19937` у комбінації з `std::uniform_real_distribution`, що гарантує високу якість статистичної рівномірності без періодичних кореляцій.
4. **Стандарт C++20:** Використано константу `std::numbers::pi` та атрибути `[[nodiscard]]` й `noexcept` для максимальної продуктивності та оптимізації компілятором.

### 6. Фізична інтерпретація результатів чисельного розрахунку

1. **Омічна зона (`F < F_c = 3.66 кВ/см`):** При низьких полях середня швидкість носіїв лінійно зростає зі збільшенням поля. Модель чисельного ансамблю Монте-Карло з високою точністю збігається з теоретичною рухливістю `μ_0 ≈ 1.14·10³ см² / (В·с)`.
2. **Максимум швидкості (`F = F_c`):** При досягненні критичного поля `F_c ≈ 3.66 кВ/см` дрейфова швидкість носіїв виходить на максимум `v_max ≈ 2.27·10⁶ см/с`.
3. **Область негативного диференціального опору (`F > F_c`):** При подальшому підвищенні поля дрейфова швидкість спадає. У симуляції виразно простежується ефект накопичення частинок у верхній частині мінізони, де ефективна маса є негативною.
4. **Спектральний аналіз розгортання осциляцій:** Здійснення швидкого перетворення Фур’є (*FFT*) часового запізнення струму `J(t)` у змінному полі `F_{ac}` показує появу резонансного піку на високій частоті Блоха `f_B = e · F_{dc} · d / (2π · ℏ)`, що прямо доводить можливість застосування суперґратки як генератора ТГц-випромінювання.
5. **Генерація вищих гармонік:** У змішаному режимі полів `F(t) = F_{dc} + F_{ac} cos(ω t)` струм носіїв збагачується нелінійними вищими гармоніками `n · ω` та комбінаційними частотами `p · ω_B ± q · ω`. Це робить напівпровідниковими суперґратки високоефективними помножувачами частоти для мікрохвильових та терагерцових гетеродинів.
