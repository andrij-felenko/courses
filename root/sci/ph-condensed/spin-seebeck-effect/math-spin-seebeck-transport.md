# 🧮 Математична модель магнонного транспорту та генерування ЕРС через ISHE

Аналітичний опис спінового ефекту Зеєбека (SSE) вимагає побудови наскрізної фізико-математичної моделі, яка зшиває квантову кінетику магнонного газу в магнітному діелектрику, феноменологічну двотемпературну термодинаміку, міжфазне спін-помпування та дифузію спінового накопичення у важкому металі з урахуванням релятивістської спін-орбітальної взаємодії.

Нижче наведено повний математичний вивід фундаментальних рівнянь, що описують генерацію, транспорт та перетворення спінового кутового моменту в електричний сигнал у гетероструктурі магнітний діелектрик / важкий метал.

## 1. Кінетичне рівняння Больцмана для магнонного газу

У напівкласичному наближенні функція розподілу магнонів `f_k(r, t)` із хвильовим вектором `k` та енергією `ε_k = ℏ·ω_k` за наявності просторового градієнта температури задовольняє кінетичному рівнянню Больцмана в наближенні часу релаксації `τ_k`:

```
v_k · ∇f_k = - (f_k - f_k^0) / τ_k      [рівняння Больцмана у стаціонарному режимі]
```

де `v_k = ∇_k ω_k` — групова швидкість магнона, `f_k^0(T) = 1 / (exp(ℏ·ω_k / (k_B·T)) - 1)` — рівноважна функція розподілу Бозе — Ейнштейна при локальній температурі `T`.

Розкладаючи нерівноважну функцію розподілу по малих відхиленнях `f_k ≈ f_k^0 - τ_k · (v_k · ∇T) · (∂f_k^0 / ∂T)`, густина магнонного струму `J_m` визначається інтегруванням по всьому магнонному спектру першої зони Бріллюена:

```
J_m = ∫ (v_k · f_k) · (d³k / (2π)³) = - D_m · ∇n_m - S_m · ∇T_m
```

де `D_m` — коефіцієнт магнонної дифузії, `n_m` — густина магнонів, `S_m` — магнонний коефіцієнт Зеєбека, який характеризує перенос спінового кутового моменту на одиницю температурного градієнта.

## 2. Двотемпературна модель та магнонно-фононна термалізація

У магнітному ізоляторі (наприклад, `Y₃Fe₅O₁₂` / YIG) тепловий транспорт здійснюється двома зв'язаними квазічастинковими підсистемами: коливаннями кристалічної ґратки (фононами) та коливаннями магнітних моментів (магнонами). При прикладанні зовнішнього градієнта температури уздовж осі `z` локальний тепловий баланс у 1D-геометрії описується системою диференціальних рівнянь другого порядку:

```
-κ_p · (d²T_p / dz²) = g_mp · (T_m - T_p)       [тепловий баланс фононів]
-κ_m · (d²T_m / dz²) = -g_mp · (T_m - T_p)      [тепловий баланс магнонів]
```

де `κ_p` та `κ_m` — коефіцієнти теплопровідності фононної та магнонної підсистем відповідно, `g_mp` — коефіцієнт магнон-фононної об'ємної енергетичної релаксації.

Для оксидних феримагнетиків при кімнатній температурі `κ_p ≈ 6.0 Вт/(м·К)`, тоді як `κ_m ≈ 0.06 Вт/(м·К)`, тобто `κ_p ≫ κ_m`. Додаючи два рівняння, отримуємо закон збереження сумарного теплового потоку:

```
d/dz [ κ_p · (dT_p / dz) + κ_m · (dT_m / dz) ] = 0
```

Визначаючи параметр локальної температурної нерівноваги `ΔT_mp(z) = T_m(z) - T_p(z)`, відніманням співвідношень отримуємо диференціальне рівняння для нерівноважного скачка температури:

```
d²(ΔT_mp) / dz² = λ_mp⁻² · ΔT_mp
```

де характеристична магнон-фононна довжина релаксації `λ_mp` дорівнює:

```
λ_mp = √( (κ_p · κ_m) / (g_mp · (κ_p + κ_m)) ) ≈ √( κ_m / g_mp )    [при κ_p ≫ κ_m]
```

Для монокристалів YIG при 300 К величина `λ_mp` становить від `100 нм` до `1 мкм`.

Загальний розв'язок рівняння нерівноваги у шарі магнітного діелектрика товщиною `d_F` має вигляд:

```
ΔT_mp(z) = C₁ · exp(z / λ_mp) + C₂ · exp(-z / λ_mp)
```

З граничних умов відсутності магнонного потоку на вільній нижній межі `z = -d_F` та наявності спінового помпування на верхній фазовій межі `z = 0` випливає значення температурної нерівноваги на контакті з металом:

```
ΔT_mp(0) = T_m(0) - T_p(0) ≈ - λ_mp · (dT_p / dz) · sinh(d_F / λ_mp) / cosh(d_F / λ_mp)
```

Для товстих шарів (`d_F ≫ λ_mp`) це співвідношення спрощується до прямої пропорційності прикладеному фононному градієнту:

```
ΔT_mp(0) ≈ - λ_mp · (dT_p / dz)
```

## 3. Магнонний спіновий хімічний потенціал і міжфазне спін-помпування

Відхилення магнонної системи від рівноваги породжує нерівноважний спіновий хімічний потенціал `μ_m(z)`. Зв'язок між `μ_m` та температурним скачком `ΔT_mp` визначається через коефіцієнт магнонної термо-ЕРС `S_m`:

```
μ_m(z) = (2e / ℏ) · S_m · ΔT_mp(z)
```

На фазовій межі розділу діелектрик/метал (`z = 0`) магнонний потік передає свій спіновий кутовий момент електронам провідності металу за рахунок міжфазної `s-d` обмінної взаємодії. Густина чистого спінового струму `J_s^z`, що інжектується у метал, обчислюється за формулою міжфазного спін-помпування:

```
J_s^z = (g_↑↓ · k_B / (2π · M_s)) · (T_m(0) - T_e(0))    [густина вхідного спінового струму]
```

де `g_↑↓` — міжфазна комплексна спінова провідність (англ. *spin-mixing conductance*), `M_s` — намагніченість насичення феримагнетика, `T_e(0)` — температура електронів у металі (яка дорівнює фононній температурі `T_p(0)` завдяки сильній міжпідгратковій електрон-фононній термалізації у металі).

Підставляючи вираз для `ΔT_mp(0)`, отримуємо фундаментальну залежність інжектованого спінового струму від перпендикулярного градієнта температури:

```
J_s^z = - (g_↑↓ · k_B · λ_mp / (2π · M_s)) · (dT_p / dz) · tanh(d_F / λ_mp)
```

## 4. Спінова дифузія у важкому металі (Pt)

Інжектований спіновий струм `J_s^z` викликає накопичення спінового хімічного потенціалу `μ_s(z) = μ_↑(z) - μ_↓(z)` у плівці важкого металу товщиною `d_N` (`0 ≤ z ≤ d_N`). Просторовий розподіл спінового накопичення задовольняє одновимірному стаціонарному рівнянню спінової дифузії:

```
d²μ_s / dz² = μ_s / λ_sd²
```

де `λ_sd` — довжина спінової дифузії у металі (для Pt `λ_sd ≈ 1.5 нм`).

Рівняння дифузії розв'язується з наступними граничними умовами:
1. На фазовій межі розділу `z = 0`: спіновий струм у металі дорівнює вхідному магнонному струму:
   ```
   -(σ_N / (2e)) · (dμ_s / dz)|_{z=0} = J_s^z
   ```
2. На вільній зовнішній поверхні металу `z = d_N`: витік спінового струму відсутній:
   ```
   (dμ_s / dz)|_{z=d_N} = 0
   ```

Інтегруванням диференціального рівняння отримуємо точний просторовий профіль спінового накопичення по товщині важкого металу:

```
μ_s(z) = (2e · λ_sd · J_s^z / σ_N) · [ cosh((d_N - z) / λ_sd) / sinh(d_N / λ_sd) ]
```

де `σ_N` — питома електрична провідність металевого шару (`σ_N = 1 / ρ_N`).

## 5. Обернений спіновий ефект Холла (ISHE) та підрахунок вихідної ЕРС

Усередині плівки важкого металу спіновий струм `J_s(z) = -(σ_N / (2e)) · (dμ_s / dz)` за рахунок релятивістської спін-орбітальної взаємодії перетворюється на поперечний струм заряду `J_c(z)` через обернений спіновий ефект Холла:

```
J_c(z) = θ_SH · (2e / ℏ) · J_s(z)
```

де `θ_SH` — кут спінового Холла металу, `ℏ` — зведена стала Планка.

Підставляючи вираз для `J_s(z)`, отримуємо розподіл поперечного струму заряду по товщині металу:

```
J_c(z) = θ_SH · (2e / ℏ) · J_s^z · [ sinh((d_N - z) / λ_sd) / sinh(d_N / λ_sd) ]
```

Інтегруючи густину струму `J_c(z)` по товщині платини від `z = 0` до `z = d_N`, обчислюємо повний поперечний струм заряду `I_c`:

```
I_c = w · ∫₀^{d_N} J_c(z) dz = w · θ_SH · (2e / ℏ) · J_s^z · λ_sd · [ (cosh(d_N / λ_sd) - 1) / sinh(d_N / λ_sd) ]
```

Застосовуючи тригонометричну тотожність `(cosh(x) - 1) / sinh(x) = tanh(x / 2)`, вираз спрощується до вигляду:

```
I_c = w · θ_SH · (2e / ℏ) · J_s^z · λ_sd · tanh(d_N / (2 · λ_sd))
```

де `w` — ширина платинового контакту.

В умовах електрично розімкненого кола (відсутність зовнішнього навантаження) генерується протилежно спрямоване електричне поле `E_ISHE`:

```
E_ISHE = I_c / (w · d_N · σ_N) = (θ_SH · ρ_N · λ_sd / d_N) · (2e / ℏ) · J_s^z · tanh(d_N / (2 · λ_sd))
```

Інтегруванням поля `E_ISHE` вздовж довжини платинового контакту `L` виводиться підсумкова вихідна електрична напруга поздовжнього спінового ефекту Зеєбека (LSSE):

```
V_ISHE = E_ISHE · L = (L / d_N) · θ_SH · ρ_N · λ_sd · (2e / ℏ) · J_s^z · tanh(d_N / (2 · λ_sd))
```

Підставляючи раніше отриманий вираз для вхідного спінового струму `J_s^z`, отримуємо повну аналітичну формулу напруги LSSE:

```
V_ISHE = - (L / d_N) · (θ_SH · ρ_N · λ_sd) · (e · k_B · g_↑↓ · λ_mp / (π · ℏ · M_s)) · (dT_p / dz) · tanh(d_F / λ_mp) · tanh(d_N / (2 · λ_sd))
```

## 6. Аналітичне дослідження максимуму товщини важкого металу

Отримане рівняння дозволяє математично знайти оптимальну товщину металевого детектора `d_N`. Залежність напруги від `d_N` задається функцією:

```
f(d_N) = (1 / d_N) · tanh(d_N / (2 · λ_sd))
```

Дослідимо граничну поведінку цієї функції:
1. **Тонкі плівки (`d_N ≪ λ_sd`):**
   Використовуючи розклад `tanh(x) ≈ x - x³/3`, отримуємо:
   ```
   f(d_N) ≈ (1 / d_N) · (d_N / (2 · λ_sd)) = 1 / (2 · λ_sd) = const
   ```
   У цій області напруга прямує до насичення, однак опір металевого контакту `R = ρ_N · L / (w · d_N)` прямує до нескінченності, що різко зменшує корисну електричну потужність `P = V² / R`.

2. **Товсті плівки (`d_N ≫ λ_sd`):**
   Оскільки `tanh(x) → 1`, маємо:
   ```
   f(d_N) ≈ 1 / d_N
   ```
   Напруга спадає зворотньо пропорційно товщині через шунтування струму неактивним об'ємом металу.

Обчислюючи похідну для вихідної електричної потужності `P(d_N) ∝ V_ISHE² · d_N`, знайдемо точну умову максимуму вихідної потужності:

```
d/d(d_N) [ (1 / d_N) · tanh²(d_N / (2 · λ_sd)) ] = 0
```

Розв'язок трансцендентного рівняння дає оптимальне співвідношення:

```
d_N^{opt} ≈ 2.16 · λ_sd ≈ 3.0 - 4.0 нм   [для Pt з λ_sd = 1.5 нм]
```

Цей аналітичний результат узгоджується з чисельними моделями та експериментальними вимірюваннями.

Фізична інтерпретація та обчислювальні алгоритми даного математичного апарату висвітлені у статті [Спіновий ефект Зеєбека (SSE)](topic:ph-condensed/spin-seebeck-effect).
