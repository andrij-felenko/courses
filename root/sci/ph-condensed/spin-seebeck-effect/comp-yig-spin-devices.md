# 🔌 Магнітні діелектрики YIG, підкладки GGG та важкі метали у спін-калоритроніці

Практична реалізація спін-калоритронічних пристроїв на основі спінового ефекту Зеєбека (SSE) спирається на синтез прецизійних багатошарових гетероструктур. Ключовими елементами таких пристроїв є магнітні діелектричні плівки ітрій-залізистого гранату, монокристалічні підкладки ґадоліній-галієвого гранату та контактні шари важких металів із високою спін-орбітальною взаємодією.

## Ітрій-залізистий гранат (YIG): Молекулярна структура та власності

Ітрій-залізистий гранат (`Y₃Fe₅O₁₂`, YIG) є еталонним матеріалом фізики магнонів та спін-калоритроніки завдяки унікальній сукупності магнітних та електричних властивостей.

### Кристалічна та магнітна підґратка
YIG кристалізується у кубічній просторовій групі `Ia3̄d` із параметром ґратки `a = 12.376 Å`. Елементарна комірка містить 160 атомів (`8` формульних одиниць). Магнітні властивості визначаються іонами заліза `Fe³⁺`, розташованими у двох нееквівалентних кристалографічних позиціях:
- **Октаедричні позиції (a-підґратка):** 2 іони `Fe³⁺` на формульну одиницю.
- **Тетраедричні позиції (d-підґратка):** 3 іони `Fe³⁺` на формульну одиницю.

Між іонами `Fe³⁺` a- та d-підґраток діє сильна непряма обмінна взаємодія через аніони кисню `O²⁻` (суперобмін). Вона орієнтує спинові моменти двох підґраток антипаралельно. Оскільки d-підґратка містить більше іонів заліза, YIG є нескомпенсованим феримагнетиком із результуючим магнітним моментом `1 μ_B` на формульну одиницю при `0 К`. Намагніченість насичення при кімнатній температурі становить `4π M_s ≈ 1750 Гаусс` (`M_s ≈ 1.4e5 А/м`), а температура Кюрі `T_C = 559 К`.

### Фізичні переваги YIG у спін-калоритроніці
1. **Рекордно мала затухання Гілберта (`α ≈ 1e-5`):** YIG володіє найменшим серед усіх відомих речовин коефіцієнтом магнітного дисипативного затухання. Це забезпечує гігантську довжину пробігу магнонів (понад `10 мкм`) та час життя магнонних збуджень до `1 мкс`.
2. **Високий електричний опір (`ρ > 10¹² Ом·см`):** Ширина забороненої зони складає `2.85 еВ`. Матеріал повністю виключає струми витоку носіїв заряду, гарантуючи pure-magnon (чисто магнонний) транспорт кутового моменту.
3. **Низька анізотропія:** Монокристалічні плівки YIG легко перенамагнічуються слабкими магнітними полями (всього кілька ерстед).

## Монокристалічні підкладки GGG (`Gd₃Ga₅O₁₂`)

Для вирощування високоякісних монокристалічних плівок YIG використовують підкладки ґадоліній-галієвого гранату (`Gd₃Ga₅O₁₂`, **GGG**).

### Узгодження кристалічних ґраток
Параметр кубічної ґратки GGG становить `a_GGG = 12.383 Å`. Невідповідність параметрів ґраток між YIG та GGG складає всього:

```
Δa / a = (a_GGG - a_YIG) / a_YIG ≈ (12.383 - 12.376) / 12.376 ≈ +0.05%
```

Така мінімальна невідповідність дозволяє вирощувати бездефектні плівки YIG товщиною від десятків нанометрів до кількох мікрометрів без утворення дислокацій та напружень стиску/розтягу.

### Технології синтезу
- **Рідкофазна епітаксія (LPE):** Класичний метод для отримання товстих плівок YIG (`d > 500 нм`). Вирощування відбувається з розплаву солей при температурі близько `930 °C`. Плівки LPE володіють найменшою шириною лінії феромагнітного резонансу (FMR).
- **Імпульсне лазерне осадження (PLD):** Сучасний метод для створення надтонких плівок YIG (`d = 10 - 100 нм`). Використовує випаровування стехіометричної мішені ексимерним лазером в атмосфері кисню під тиском `0.01 - 0.1 мбар` з подальшим високотемпературним відпалом.

## Метали-детектори (Pt, Ta, W) та міжфазна спінова провідність

Для конвертації магнонного спінового струму в електричну напругу поверх плівки YIG напилюють тонкий шар важкого металу (`3 - 5 нм`).

### Порівняльна характеристика металів-детекторів

1. **Платина (Pt):**
   - Кут спінового Холла: `θ_SH ≈ +0.08` ... `+0.12`.
   - Довжина спінової дифузії: `λ_sd ≈ 1.5 нм`.
   - Питомий опір: `ρ ≈ 20-30 мкОм·см`.
   - Переваги: Хімічна інертність, висока відтворюваність, висока спінова провідність межі. Еталонний матеріал.

2. **Тантал (β-Ta):**
   - Кут спінового Холла: `θ_SH ≈ -0.15`.
   - Довжина спінової дифузії: `λ_sd ≈ 2.5 нм`.
   - Переваги: Від'ємний знак `θ_SH` викликає зміну знаку вихідної ЕРС `V_ISHE`, що є стандартним тестом підтвердження спінового походження сигналу.

3. **Вольфрам (β-W):**
   - Гігантський кут спінового Холла: `θ_SH ≈ -0.30` ... `-0.40`.
   - Довжина спінової дифузії: `λ_sd ≈ 1.0 нм`.
   - Переваги: Максимальна ефективність перетворення спин-в-струм, однак метастабільна фаза β-W вимагає суворого контролю атмосфери осадження.

## Інженерія фазової межі розділу та спінова провідність `g_↑↓`

Ефективність передачі спінового кутового моменту від магнонів YIG до електронів провідності металу визначається міжфазною комплексною спіновою провідністю (англ. *spin-mixing conductance*, `g_↑↓`).

Для ідеальної атомарно-чистої межі YIG/Pt значення `g_↑↓` сягає `(1.0 - 2.0)e19 м⁻²`. Наявність на поверхні YIG забруднень, оксидних плівок чи аморфного шару зменшує `g_↑↓` у десятки разів, повністю пригнічуючи сигнал Зеєбека.

### Стандартний протокол підготовки поверхні
1. **Хімічне очищення:** Промивка підкладки YIG в ультразвуковій ванні в ацетоні та ізопропанолі.
2. **In-situ іонне травлення:** Травлення поверхні YIG пучком іонів аргону `Ar⁺` низької енергії (`100 - 200 еВ`) у вакуумній камері безпосередньо перед напиленням металу.
3. **Кисневий відпал:** Відпал плівок при `500 °C` у чистому кисні для відновлення стехіометрії кисню на поверхні.
4. **Магнетронне напилення:** Нанесення плівки Pt методом постійнострумового (DC) магнетронного розпилення при кімнатній температурі.

Параметри синтезу гетероструктур YIG/Pt та математичні рівняння спінового транспорту розібрані у статті [Спіновий ефект Зеєбека (SSE)](root:ph-condensed/spin-seebeck-effect).
