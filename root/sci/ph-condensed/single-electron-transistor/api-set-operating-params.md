# 📋 Довідник фізичних та операційних параметрів одноелектронних транзисторів

Ця вставка є систематичним технічним довідником фізичних, електростатичних та кріогенних параметрів одноелектронних транзисторів (SET) на основі різних матеріальних платформ (метали, напівпровідникові квантові точки, кремнієві наноструктури), призначеним для проектування експериментальних установок та розрахунку чутливості електрометрів.

## 1. Фундаментальні фізичні константи та масштабні співвідношення

Функціонування одноелектронних транзисторів визначається строгим співвідношенням фундаментальних констант квантової механіки та електродинаміки. На відміну від макроскопічних напівпровідникових приладів, де перенесення заряду описується неперервною густиною струму, у SET ключову роль відіграють квант заряду, квант опору та термічна енергія Больцмана.

```
+--------------------------------------------------------------------------------------------------+
| Таблиця 1. Фундаментальні фізичні константи одноелектронного транспорту                          |
+------------------------------+---------------+------------------------+---------------+----------+
| Фізична величина             | Символ        | Точне значення         | Одиниця       | Роль     |
+------------------------------+---------------+------------------------+---------------+----------+
| Елементарний заряд           | e             | 1.602 176 634 × 10⁻¹⁹  | Кл            | Заряд    |
| Стала Планка                 | h             | 6.626 070 15 × 10⁻³⁴   | Дж·с          | Квантув. |
| Зведена стала Планка         | ℏ             | 1.054 571 817 × 10⁻³⁴  | Дж·с          | Принцип  |
| Квант опору (фон Клітцинга)  | R_q = h/e²    | 25 812.807             | Ом            | Пороговий|
| Квант провідності            | G_0 = 2e²/h   | 7.748 091 × 10⁻⁵       | См            | Макс. G  |
| Стала Больцмана              | k_B           | 1.380 649 × 10⁻²³      | Дж/К          | Терм. T  |
| Еквівалент температури 1 меВ | T_meV         | 11.604                 | К             | Шкала    |
+------------------------------+---------------+------------------------+---------------+----------+
```

Масштабні співвідношення визначають залежність електростатичних параметрів від геометричного радіуса острівця `R`. Для сферичного провідного острівця, зануреного в діелектричне середовище з відносною проникністю `ε_r`, самоємність острівця визначається класичною електростатикою:

```
C_self = 4 · π · ε_0 · ε_r · R
```

Звідси випливає фундаментальний масштабний закон для кулонівської заряджальної енергії `E_C`:

```
E_C = e² / (2 · C_Σ)
∝ 1 / R
```

Зменшення радіуса острівця `R` вдвічі приводить до подвоєння кулонівської енергетичної щілини `E_C` та відповідного підвищення граничної робочої температури пристрою `T_max ∝ 1/R`. Для досягнення робочих температур рідкого азоту (77 К) або кімнатної температури (300 К) необхідний радіус острівця `R` повинен не перевищувати 2–5 нанометрів.

При цьому електростатична ємність затвора `C_g` визначається геометричним перекриттям керувального електрода та острівця. Зменшення відстані між затвором та острівцем `d_g` збільшує ємність `C_g = ε_0 ε_r S_g / d_g`, що зменшує період кулонівських осциляцій `ΔV_g = e / C_g` і підвищує чутливість керування пристроєм.

## 2. Операційні параметри за матеріальними платформами

Фізичні властивості одноелектронних транзисторів істотно відрізняються залежно від матеріально-технологічної платформи, використаної для формування тунельних бар'єрів та провідного острівця.

```
+--------------------------------------------------------------------------------------------------+
| Таблиця 2. Порівняльний аналіз матеріальних платформ одноелектронних транзисторів               |
+--------------------------------+-----------------+-----------------+-----------------+-----------+
| Параметр пристрою              | Металевий SET   | 2DEG GaAs QD    | Кремнієвий SOI  | Молекула  |
+--------------------------------+-----------------+-----------------+-----------------+-----------+
| Геометричний розмір острівця   | 50–200 нм       | 100–300 нм      | 5–20 нм         | 1–2 нм    |
| Загальна ємність C_Σ           | 0.1–1.0 фФ      | 10–50 аФ        | 0.5–3 аФ        | 0.1–0.5 аФ|
| Кулонівська енергія E_C        | 0.08–0.8 меВ    | 1.6–8 меВ       | 25–160 меВ      | 160–800меВ|
| Критична температура T_c       | < 0.3 К         | < 1.5 К         | 15–77 К         | 300 К     |
| Квантово-розмірний інтервал ΔE | ΔE << E_C       | 0.1–1.0 меВ     | 5–30 меВ        | 100–500меВ|
| Типовий тунельний опір R_T     | 50–500 кОм      | 100 кОм — 2 МОм | 100 кОм — 5 МОм | 1–100 МОм |
| Затворна ємність C_g           | 10–100 аФ       | 1–10 аФ         | 0.1–1 аФ        | 0.01–0.1аФ|
| Період осциляцій ΔV_g          | 1.6–16 мВ       | 16–160 мВ       | 0.16–1.6 В      | 1.6–16 В  |
+--------------------------------+-----------------+-----------------+-----------------+-----------+
```

### Детальний аналіз фізичних відмінностей між платформами:

1. **Металеві структури (Al/Al₂O₃/Al):** Створюються за допомогою технології двокутової тіньової евапорації Долана. Густина електронних станів поблизу рівня Фермі у металевому алюмінії є колосальною (`D(E_F) ~ 10⁴ eV⁻¹ nm⁻³`), тому спектр носіїв вважається квазінеперервним. Зарядовий транспорт визначається виключно електростатичною кулонівською енергією `E_C`. Основною перевагою є висока відтворюваність тунельних бар'єрів з оксиду алюмінію Al₂O₃ товщиною ~1.5 нм та стабільність потенціального профілю.
2. **Напівпровідникові квантові точки GaAs/AlGaAs:** Формуються поверхневими металевими затворами над двовимірним електронним газом (2DEG). Негативний потенціал на затворах витісняє носії з-під електродів, створюючи квантову точку (0D резонатор). Завдяки малій ефективній масі електрона у GaAs (`m* = 0.067 m_e`) відстань між дискретними квантовими рівнями `ΔE = ℏ² π² / (2 m* R²)` є співмірною з кулонівською енергією `E_C`. Це дозволяє використовувати квантову точку як штучний атом із регульованою кількістю електронів аж до нуля (`N = 0`).
3. **Кремнієві наноструктури (Silicon-on-Insulator, SOI):** Використовують технологічні процеси планарної кремнієвої наноелектроніки. Завдяки більшій ефективній масі електрона у кремнії (`m* ≈ 0.19 m_e`) та високим діелектричним бар'єрам SiO₂ (3.1 еВ) вдається створювати острівці розміром 3–10 нм з ультрамалою ємністю `C_Σ < 1` аФ (`10⁻¹⁸` Ф). Це забезпечує робочі температури спостереження кулонівських осциляцій понад 77 Кельвінів.
4. **Одномолекулярні та одноатомні транзистори:** Острівцем слугує окрема органічна молекула або поодинокий атом домішки (наприклад, фосфор у кремнії). Енергія додавання електрона визначається хімічним потенціалом іонізації та енергією нижньої незаповненої молекулярної орбіталі (LUMO), перевищуючи 500 міліелектронвольт, що дає змогу спостерігати одноелектронне тунелювання при кімнатній температурі.

## 3. Шумові характеристики та чутливість електрометрії

Гранична роздільна здатність одноелектронного транзистора як електрометра обмежується фундаментальними та технічними джерелами шуму.

```
+--------------------------------------------------------------------------------------------------+
| Таблиця 3. Джерела шуму та спектральна густина флуктуацій                                        |
+-------------------------------+---------------+-------------------+-------------------+----------+
| Характеристика шуму           | Символ        | Значення (DC-SET) | Значення (RF-SET) | Джерело  |
+-------------------------------+---------------+-------------------+-------------------+----------+
| Зарядова чутливість           | δQ            | 10⁻⁴ e / √Гц      | 10⁻⁶–10⁻⁵ e / √Гц | Дробовий |
| Низькочастотний шум 1/f       | S_Q(1 Hz)     | 10⁻³ e / √Гц      | 10⁻⁴ e / √Гц      | TLS      |
| Дробовий шум струму           | S_I           | 2·e·I_ds·F        | 2·e·I_ds·F        | Дискретн.|
| Тепловий шум опору            | S_V           | 4·k_B·T·R_T       | 4·k_B·T·R_T       | Джонсон  |
| Смуга пропускання             | BW            | 1–10 кГц          | 10–100 МГц        | RC-межа  |
| Енергетична роздільна здатність| δE_sens       | 10 ℏ              | 1–3 ℏ             | Квантова |
+-------------------------------+---------------+-------------------+-------------------+----------+
```

### Фізичний механізм флуктуацій та спектральний аналіз:

1. **Дробовий шум (Shot Noise):** Виникає внаслідок дискретності перенесення електронів крізь тунельні бар'єри. Спектральна густина струмового шуму описується формулою Шотткі з урахуванням фактора Фано `F`:

```
S_I(f) = 2 · e · I_ds · F
```

У режимі кулонівської блокади тунелювання електронів є корельованим (електрон чекає, поки попередній залишить острівець), що приводить до придушення дробового шуму (`F < 1`, так званий суб-пуассонівський режим). У симетричному SET на вершинах піків провідності фактор Фано досягає значення `F = 1/2`.

2. **Зарядовий шум `1/f` та дворевневі системи (TLS):** Найсерйозніше технічне обмеження SET. Викликане випадковими перескоками поодиноких електронів між дефектами та пастками в аморфному оксидному діелектрику Al₂O₃ або SiO₂ поблизу острівця. Кожен перескок заряду зміщує робочу точку затвора на величину `ΔV_g = e / C_g`, викликаючи низькочастотні флуктуації струму зі спектром `S_Q(f) ∝ 1 / f`.
3. **Енергетична роздільна здатність електрометра:** Характеризує мінімальну зміну енергії електричного поля, яку пристрій може зареєструвати за час 1 секунду:

```
δE_sens = (δQ)² / (2 · C_g)
```

Найкращі експериментальні зразки RF-SET досягають граничного квантового межі `δE_sens ≈ 1–3 ℏ`, що робить їх квантово-обмеженими підсилювачами.

## 4. Вимоги до кріогенного обладнання, фільтрації та екстракції параметрів

Для забезпечення стабільної роботи одноелектронних транзисторів металевого та напівпровідникового типів необхідне суворе дотримання умов кріогенної температури та захисту від високочастотних наводок.

Експериментальна установка для дослідження SET вимагає застосування розчинних кріостатів на основі ізотопів `³He/⁴He`, здатних підтримувати базову температуру від 10 до 20 мілікельвінів.

### Схема каскадної атенюації та фільтрації ВЧ ліній:

1. **Етап 4 Кельвіна (холодна пальця кріостата):** Встановлюється перший каскад коаксіальних атенюаторів з ослабленням -20 дБ для поглинання теплового випромінювання кімнатної зони (300 К).
2. **Етап 100 мілікельвінів (проміжна плато-сходинка):** Другий каскад атенюаторів -10 дБ для зниження температурного шуму випромінювання кабелів.
3. **Етап 10 мілікельвінів (смішувальна камера):** Фінальний атенюатор -20 дБ та двоступеневі мідно-порошкові фільтри (*copper powder filters*).

### Математичний критерій термодинамічного захисту:

Для відсутності термічного розмивання кулонівського бар'єра необхідне виконання суворого співвідношення:

```
T_expt ≤ E_C / (10 · k_B)
```

Для металевого SET з ємністю `C_Σ = 1` фФ (`E_C = 0.8` меВ ≈ 9.3 К) максимальна температура експерименту повинна не перевищувати:

```
T_expt ≤ 9.3 К / 10
= 0.93 К
```

Крім термічного захисту, вимірювальні лінії повинні захищатися від електромагнітних завад радіочастотного діапазону. Застосовуються багатозвенні `π`-подібні LC-фільтри та циліндричні екрани з пермалою (*μ-metal*) у поєднанні з надпровідними екранами з чистого ніобію для нейтралізації зовнішніх змінних і постійних магнітних полів.

### Процедура екстракції ємностей із геометрії ромбів Кулона:

Для визначення електростатичних параметрів виготовленого транзистора виконують експериментальне вимірювання 2D картографування струму `I_ds(V_g, V_ds)` та застосовують такі алгоритмічні кроки:

1. Визначають період осциляцій по затвору `ΔV_g` між двома сусідніми вершинами ромбів при `V_ds = 0`. Обчислюють ємність затвора: `C_g = e / ΔV_g`.
2. Визначають максимальну напругу кулонівської щілини `V_ds^(max)` у центрі ромба. Обчислюють повну ємність острівця: `C_Σ = e / V_ds^(max)`.
3. Вимірюють тангенси кутів нахилу лівої верхньої грани ромба `k_left` та правої верхньої грани `k_right`. Обчислюють ємності тунельних переходів `C₁` та `C₂`:

```
C₁ = C_g / k_right - C_g
C₂ = - C_g / k_left - C_g
```

Цей метод екстракції забезпечує високу точність визначення еквівалентної ємнісної схеми пристрою без використання зовнішніх калібрувальних еталонів.
