# 🧮 Математична модель транспорту Френкеля — Пуля

Ця вставка містить математичне виведення ефекту Френкеля — Пуля (*Poole-Frenkel emission*), який описує термопольову іонізацію електронних пасток у діелектричних плівках нітриду кремнію (Si₃N₄) 3D NAND пам'яті. Розглянуто зниження потенціального бар'єра кулонівського центра у зовнішньому електричному полі, розраховано густину струму витоку, тривимірне інтегрування за тілесним кутом та умови перетину з емісією Фаулера — Нордгейма.

## 1. Потенціальний профіль кулонівської пастки у полем

Розглянемо електрон з зарядом `q`, що знаходиться в нейтральній потенціальній ямі, створеній точковим позитивним зарядом (наприклад, розірваним кремнієвим зв'язком K⁰-центра у матриці Si₃N₄). Одновимірний кулонівський потенціал без зовнішнього поля описується формулою:

```
V_0(x) = - q / (4 · π · ε_i · x)
```

де `ε_i = ε_r · ε_0` — оптична (високочастотна) діелектрична проникність матеріалу пастки, `x` — відстань від центра дефекту. Оптична діелектрична проникність зв'язана з показником заломлення світла `n` матеріалу співвідношенням `ε_r = n²`. Для нітриду кремнію Si₃N₄ показник заломлення `n ≈ 2.0`, тому оптична діелектрична проникність дорівнює `ε_r ≈ 4.0–5.5`, що суттєво менше за статичну діелектричну проникність (`ε_static ≈ 7.5`).

При прикладанні сильного зовнішнього електричного поля `E`, спрямованого уздовж осі `x`, потенціальна енергія електрона `U(x)` набуває вигляду:

```
U(x) = - q² / (4 · π · ε_i · x) - q · E · x
```

Перший доданок описує приваблювану кулонівську взаємодію електрона з позитивно зарядженим остовом пастки, а другий доданок — потенціал зовнішнього однорідного електричного поля.

## 2. Знаходження максимуму бар'єра та його зниження

Щоб знайти координату `x_max`, у якій потенціальний бар'єр сягає максимуму, продиференціюємо `U(x)` за змінною `x` і прирівняємо похідну до нуля:

```
dU / dx = q² / (4 · π · ε_i · x²) - q · E = 0
```

Виразимо квадрат координати `x_max²`:

```
x_max² = q / (4 · π · ε_i · E)
```

Звідси координата вершини зниженого бар'єра дорівнює:

```
x_max = √(q / (4 · π · ε_i · E))
```

Підставимо отримане значення `x_max` у вираз для потенціальної енергії `U(x)` для розрахунку значення максимуму `U(x_max)`:

```
U(x_max)
= - q² / (4 · π · ε_i · √(q / (4 · π · ε_i · E))) - q · E · √(q / (4 · π · ε_i · E))   [підстановка x_max у вираз U(x)]
= - √(q³ · E / (4 · π · ε_i)) - √(q³ · E / (4 · π · ε_i))                             [спрощення дробових виразів під коренем]
= - √(q³ · E / (π · ε_i))                                                             [додавання двох однакових доданків]
```

Отже, висота потенціального бар'єра для електрона знижується на величину `ΔΦ`:

```
ΔΦ = - U(x_max) = √(q³ · E / (π · ε_i))
```

У вираженні потенціалу в електрон-вольтах (eV) величина зниження бар'єра має вигляд:

```
ΔΦ_eV = β_PF · √E
```

де `β_PF` — коефіцієнт Френкеля — Пуля:

```
β_PF = √(q³ / (π · ε_i))
```

Для аморфного нітриду кремнію з `ε_r ≈ 5.5` величина коефіцієнта Френкеля — Пуля дорівнює `β_PF ≈ 2.2 × 10⁻⁴` еВ·(В/см)⁻¹/². При напруженості електричного поля `E = 1` МВ/см зниження бар'єра складає `ΔΦ ≈ 0.22` еВ, що при кімнатній температурі (`k_B · T ≈ 0.026` еВ) збільшує імовірність вильоту електрона у `exp(0.22 / 0.026) ≈ 4700` разів.

## 3. Одновимірна густина струму Френкеля — Пуля

Імовірність термічного вивільнення електрона з ями глибиною `Φ_B` описується розподілом Больцмана. У присутності зовнішнього поля `E` ефективна висота бар'єра зменшується від `Φ_B` до `(Φ_B - ΔΦ)`:

```
P_emission = ν_0 · exp(- q · (Φ_B - β_PF · √E) / (k_B · T))
```

де `ν_0` — частота спроб коливань електрона в ямі (~10¹³ с⁻¹), `k_B` — стала Больцмана, `T` — абсолютна температура в кельвінах.

Концентрація вільних носіїв `n_c` у зоні провідності діелектрика Si₃N₄ дорівнює добутку повного числа пасток `N_t` на імовірність іонізації:

```
n_c = N_t · exp(- q · (Φ_B - β_PF · √E) / (k_B · T))
```

Густина струму витоку `J_PF` виражається через дрейфовий струм електронів у зоні провідності нітриду:

```
J_PF = q · n_c · μ_n · E
```

де `μ_n` — рухливість електронів у зоні провідності Si₃N₄. Підставивши значення `n_c`, отримуємо класичне одновимірне рівняння Френкеля — Пуля:

```
J_PF = C · E · exp(- q · (Φ_B - √(q · E / (π · ε_i))) / (k_B · T))
```

де `C = q · N_t · μ_n` — константа провідності матеріалу.

## 4. Тривимірне інтегрування за тілесним кутом

У реальній об'ємній матриці Si₃N₄ потенціальний бар'єр знижується не однаково в усіх напрямках, а переважно вздовж вектора електричного поля `E`. Під кутом `θ` до вектора поля ефективна компонента поля дорівнює `E · cos(θ)`.

Для знаходження повного струму необхідно проінтегрувати термоподібну емісію за всім тілесним кутом `Ω`:

```
J_3D = (J_0 / 2) · ∫₀^π exp(a · √(cos θ)) · sin θ dθ
```

де `a = (q · β_PF · √E) / (k_B · T)`.

Виконуючи заміну змінної `u = √(cos θ)`, інтеграл зводиться до аналітичної форми:

```
J_3D = J_PF_1D · (1 / a²) · [ 1 + (a - 1) · exp(a) ]
```

При сильних полях (`a >> 1`) тривимірна модель прямує до одновимірної `J_3D ≈ J_PF_1D / a`, що підтверджує високу точність одновимірної формули для робочих полів 3D NAND (`E > 1` МВ/см).

## 5. Лінеаризація та координатний аналіз (Poole-Frenkel Plot)

Для експериментального визначення глибини пастки `Φ_B` та діелектричної проникності `ε_i` формулу струму лінеаризують у спеціальних координатах Френкеля — Пуля.

Поділимо обидві частини рівняння на `E` та логарифмуємо:

```
ln(J_PF / E) = ln(C) - (q · Φ_B) / (k_B · T) + (q · β_PF / (k_B · T)) · √E
```

У координатах `Y = ln(J_PF / E)` проти `X = √E` залежність перетворюється на пряму лінію:

```
Y = A + B · X
```

з коефіцієнтами:

```
A = ln(C) - (q · Φ_B) / (k_B · T)           [перетин із віссю ординат]
B = (q / (k_B · T)) · √(q / (π · ε_i))       [кутовий нахил прямої]
```

За тангенсом кута нахилу `B` розраховують оптичну діелектричну проникність плівки `ε_i`, а за перетином `A` при різних температурах `T` визначають точну енергію залягання дефекту `Φ_B` у нітриді кремнію.

## 6. Точка перетину струмів: Poole-Frenkel vs Fowler-Nordheim

У 3D NAND пам'яті співіснують два механізми перенесення заряду крізь діелектрики. Порівняємо їхні аналітичні вирази:

```
[Fowler-Nordheim Tunneling (FN)]    J_FN = A_FN · E² · exp(- B_FN / E)
[Poole-Frenkel Emission (PF)]       J_PF = C · E · exp(- q·(Φ_B - β_PF·√E) / (k_B·T))
```

- При високих полях (`E > 7–8` МВ/см, режим запису `V_pgm ≈ 20` В) експоненціальний фактор тунелювання FN `exp(-B_FN / E)` переважає, і струм інжекції електронів визначається виключно квантовим тунелюванням крізь SiO₂.
- При низьких та помірних полях (`E < 3` МВ/см, режим утримання/читання) бар'єр SiO₂ стає занадто товстим для квантового тунелювання FN. Натомість термопольова іонізація пасток PF у Si₃N₄ стає основним джерелом витоку заряду.

Точка перетину `E_crossover`, у якій `J_FN(E) = J_PF(E, T)`, визначає межу між режимом ефективного запису та режимом небезпечного витоку, що використовується при розрахунку товщини ONO-стека.

## 7. Моделювання часового розряду та логарифмічний закон витоку

При тривалому зберіганні заряду накопичений потенціал осередку `V(t)` задовольняє диференціальне рівняння саморозряду:

```
d V(t) / dt = - (S_cell / C_gate) · J_PF(E(t), T)
```

Оскільки `J_PF` пропорційний `exp(β_PF · √E / (k_B · T))`, підстановка зв'язку `E(t) = V(t) / t_dielectric` дає нелінійне диференціальне рівняння першого порядку.

Його аналітичний розв'язок наближається логарифмічною функцією часу:

```
V_th(t) = V_th(0) - A_decay · ln(1 + t / τ_0)
```

де `A_decay = (k_B · T) / (q · β_PF) · (t_dielectric / √E_0)` — коефіцієнт логарифмічного згасання, а `τ_0` — характерна стала часу розрядки. Цей закон пояснює, чому найбільша втрата напруги осередку відбувається у перші години після програмування, після чого швидкість витоку істотно сповільнюється.
