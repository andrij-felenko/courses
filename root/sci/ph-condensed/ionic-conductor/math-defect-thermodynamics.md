# 🧮 Термодинаміка точкових дефектів та рівняння Нернста-Ейнштейна

Ця математична вставка містить строге виведення рівноважної концентрації дефектів Шотткі й Френкеля на основі мінімізації вільної енергії Гіббса, аналіз рівноваги дефектів за формалізмом Крьоґера-Вінка, математичну теорію вакансійних асоціатів, теорію просторового заряду Планка-Пуассона, формалізм феноменологічних коефіцієнтів Онзагера, а також виведення зв'язку між коефіцієнтом дифузії та іонною провідністю (рівняння Нернста-Ейнштейна) і температурної залежності Арреніуса.

## 1. Термодинаміка та рівноважна концентрація дефектів Шотткі

Розглянемо ідеальний стехіометричний кристал складу MX, який складається з N катіонних та N аніонних вузлів. Для утворення n_S пар вакансій Шотткі (катіонної v_M' та аніонної v_X°) необхідно вибити n_S катіонів та n_S аніонів на поверхню кристала.

Зміна вільної енергії Гіббса ΔG при утворенні n_S дефектів Шотткі за постійного тиску й температури становить:

```
ΔG = n_S · ΔH_S - T · ΔS
```

де ΔH_S — ентальпія утворення однієї пари вакансій Шотткі, а ΔS — повна зміна ентропії, яка складається з конфігураційної ентропії ΔS_conf та неконфігураційної (коливальної) ентропії ґратки ΔS_vib.

Коливальна ентропія виникає внаслідок того, що вилучення іона з вузла послаблює міжатомні кулонівські зв'язки навколишніх іонів-сусідів, зменшуючи їхні характерні коливальні частоти від ν_i до ν_i'. За теорією гармонічного осцилятора це дає позитивний ентропійний внесок:

```
ΔS_vib = k_B · ∑_(i=1)^(z) ln( ν_i / ν_i' )
```

де z — координаційне число найближчих сусідів вакансії у кристалічній ґратці.

Конфігураційна ентропія обчислюється за фундаментальною формулою Больцмана через кількість можливих мікростанів W, що відповідають хаотичному розподілу вакансій по кристалу:

```
S_conf = k_B · ln(W)
```

Кількість способів розміщення n_S катіонних вакансій на (N + n_S) катіонних вузлах дорівнює кількості комбінацій W_M:

```
W_M = (N + n_S)! / (n_S! · N!)
```

Аналогічно, для аніонних вакансій кількість комбінацій W_X становить:

```
W_X = (N + n_S)! / (n_S! · N!)
```

Загальна кількість мікростанів системи є добутком статистичних ваг обох підґраток W_total = W_M · W_X. Звідси конфігураційна ентропія дорівнює:

```
ΔS_conf = k_B · ln(W_total)
= 2 · k_B · ln( (N + n_S)! / (n_S! · N!) )
```

Використовуючи формулу Стірлінга для наближення факторіалів великих чисел ln(x!) ≈ x · ln(x) - x, розпишемо логарифм комбінаційного фактора:

```
ln( (N + n_S)! / (n_S! · N!) )
= (N + n_S) · ln(N + n_S) - n_S · ln(n_S) - N · ln(N)
```

Вільна енергія Гіббса системи як функція кількості утворених дефектів n_S набирає вигляду:

```
G(n_S) = G_0 + n_S · ΔH_S - n_S · T · ΔS_vib - 2 · k_B · T · [ (N + n_S) · ln(N + n_S) - n_S · ln(n_S) - N · ln(N) ]
```

У стані термодинамічної рівноваги вільна енергія Гіббса є мінімальною щодо зміни кількості дефектів, тобто хімічний потенціал утворення дефектів дорівнює нулю:

```
dG / dn_S = 0
```

Обчислимо частинну похідну від кожного додатка по n_S:

```
dG / dn_S
= ΔH_S - T · ΔS_vib - 2 · k_B · T · [ ln(N + n_S) + 1 - (ln(n_S) + 1) ]
= ΔH_S - T · ΔS_vib - 2 · k_B · T · ln( (N + n_S) / n_S )
```

Прирівнюючи похідну dG / dn_S до нуля:

```
ΔH_S - T · ΔS_vib = 2 · k_B · T · ln( (N + n_S) / n_S )
```

Оскільки концентрація дефектів набагато менша за кількість вузлів ґратки (n_S << N), маємо наближення N + n_S ≈ N. Звідси отримуємо:

```
ln(N / n_S) = (ΔH_S - T · ΔS_vib) / (2 · k_B · T)
```

Потенціюючи обома частинами рівняння, маємо для мольної частки вакансій Шотткі x_S = n_S / N:

```
x_S = exp( ΔS_vib / (2 · k_B) ) · exp( -ΔH_S / (2 · k_B · T) )
```

Таким чином, рівноважна концентрація дефектів Шотткі експоненційно зростає з температурою із фактором 2 у знаменнику показника, що відображає парний характер утворення дефектів.

## 2. Термодинаміка та рівноважна концентрація дефектів Френкеля

У випадку дефектів Френкеля катіон зміщується з нормального вузла в міжвузловий простір. Нехай кристал має N катіонних вузлів та N_i доступних міжвузлових позицій (пусток). Під час теплової флуктуації утворюється n_F катіонних вакансій v_M' та n_F міжвузлових катіонів M_i°.

Кількість способів розміщення n_F вакансій на N вузлах становить W_vac:

```
W_vac = N! / (n_F! · (N - n_F)!)
```

Кількість способів розміщення n_F міжвузлових іонів на N_i міжвузлях становить W_inter:

```
W_inter = N_i! / (n_F! · (N_i - n_F)!)
```

Загальна конфігураційна ентропія системи:

```
ΔS_conf = k_B · [ ln(W_vac) + ln(W_inter) ]
```

Застосовуючи наближення Стірлінга та мінімізуючи вільну енергію Гіббса dG / dn_F = 0:

```
dG / dn_F = ΔH_F - T · ΔS_vib - k_B · T · [ ln( (N - n_F) / n_F ) + ln( (N_i - n_F) / n_F ) ] = 0
```

Оскільки n_F << N та n_F << N_i, маємо N - n_F ≈ N та N_i - n_F ≈ N_i, що спрощує вираз:

```
ΔH_F - T · ΔS_vib = k_B · T · ln( (N · N_i) / n_F² )
```

Звідси отримуємо вираз для абсолютної кількості дефектів Френкеля n_F:

```
n_F² = N · N_i · exp( ΔS_vib / k_B ) · exp( -ΔH_F / (k_B · T) )
```

Вилучаючи квадратний корінь:

```
n_F = √(N · N_i) · exp( ΔS_vib / (2 · k_B) ) · exp( -ΔH_F / (2 · k_B · T) )
```

Якщо кристал має однакову кількість вузлів і міжвузлів (N_i = N), то мольна частка дефектів Френкеля x_F = n_F / N дорівнює:

```
x_F = exp( ΔS_vib / (2 · k_B) ) · exp( -ΔH_F / (2 · k_B · T) )
```

## 3. Квазіхімічний формалізм Крьоґера-Вінка та асоціація дефектів

Для опису рівноваг точкових дефектів при гетеровалентному легуванні або зміні парціального тиску газу використовують квазіхімічний підхід Крьоґера-Вінка. Основні правила формалізму Крьоґера-Вінка вимагають дотримання трьох інваріантів:
1. **Збереження маси**: Частинка M або вакансія v записується з індексом вузла.
2. **Збереження заряду**: Сума ефективних зарядів лівої частини хімічного рівняння дорівнює сумі ефективних зарядів правої частини.
3. **Збереження співвідношення позицій**: Співвідношення між кількістю катіонних та аніонних вузлів зберігається відповідно до стехіометрії кристала.

Утворення дефекту Френкеля записують як хімічну реакцію між вузлом ґратки M_M^x та порожнім міжвузлям V_i^x:

```
M_M^x + V_i^x ⇄ M_i° + v_M'
```

Константа рівноваги K_F для цієї реакції за законом діючих мас:

```
K_F = [M_i°] · [v_M'] / ([M_M^x] · [V_i^x])
```

Оскільки концентрація заселених вузлів [M_M^x] ≈ 1 та порожніх міжвузлів [V_i^x] ≈ 1 у мольних частках, вираз спрощується:

```
K_F = [M_i°] · [v_M'] = exp( -ΔG_F / (k_B · T) )
```

При гетеровалентному розчиненні тривалентного оксиду Y₂O₃ у чотиривалентному діоксиді цирконію ZrO₂ утворюються штучні вакансії кисню v_O°° для збереження нейтральності:

```
Y₂O₃ ⇄ 2 Y_Zr' + 3 O_O^x + v_O°°
```

З умови електронетральності системи:

```
2 · [v_O°°] = [Y_Zr']
```

Звідси концентрація вакансій кисню задається легуванням [v_O°°] = 0.5 · [Y_Zr'] і є постійною величиною, що не залежить від температури.

### Вплив парціального тиску кисню на дефекти у нестехіометричних оксидах

У нестехіометричних оксидах (наприклад, CeO_(2-x)) утворення кисневих вакансій супроводжується відновленням катіонів церію Ce⁴⁺ до Ce³⁺ та виділенням кисню в газову фазу:

```
O_O^x ⇄ (1/2) O₂(g) + v_O°° + 2 e'
```

Закон діючих мас для цієї реакції обміну з газовою фазою:

```
K_red = [v_O°°] · n_e² · (P_O2)^(1/2)
```

З умови електронетральності n_e = 2 · [v_O°°]. Підставляючи це у вираз константи рівноваги:

```
K_red = 4 · [v_O°°]³ · (P_O2)^(1/2)
```

Виражаючи концентрацію кисневих вакансій через парціальний тиск кисню P_O2:

```
[v_O°°] = (K_red / 4)^(1/3) · (P_O2)^(-1/6)
```

Отже, у відновному середовищі (при низькому тиску кисню P_O2) концентрація кисневих вакансій зростає за законом зваженого кореня шостого ступеня P_O2^(-1/6).

### Термодинаміка вакансійних асоціатів

За низьких температур протилежно заряджені дефекти (наприклад, негативно заряджений іон домішки Y_Zr' та позитивно заряджена вакансія кисню v_O°°) за рахунок кулонівського притягання утворюють дефектні комплекси (асоціати):

```
Y_Zr' + v_O°° ⇄ (Y_Zr · v_O)°
```

Енергія кулонівського зв'язку асоціату U_bound обчислюється за законом Кулона з урахуванням діелектричної проникності середовища ε_r:

```
U_bound = (z_1 · z_2 · e²) / (4 · π · ε_r · ε_0 · r_pair)
```

Законом діючих мас для реакції асоціації задається константа K_assoc:

```
K_assoc = [(Y_Zr · v_O)°] / ([Y_Zr'] · [v_O°°])
= z_coord · exp( ΔH_assoc / (k_B · T) )
```

де z_coord — координаційне число найближчих позицій, а ΔH_assoc — ентальпія зв'язку (асоціації) комплексу.

У випадку повної асоціації за низьких температур більшість вакансій стає зв'язаною у нейтральні комплекси:

```
[v_O°°] ≈ ( [Y_Zr']_total / (2 · K_assoc) )^(1/2)
~ exp( -ΔH_assoc / (2 · k_B · T) )
```

Це приводить до того, що на графіку Арреніуса низькотемпературна область має підвищену енергію активації E_a = E_m + ΔH_assoc / 2.

## 4. Феноменологічні коефіцієнти Онзагера та перехресні ефекти

У нерівноважній термодинаміці перенос іонів та інших частинок описується системними рівняннями Ларса Онзагера. Густина потоку J_i кожної компоненти i пов'язана з обобщеними термодинамічними силами X_j (градієнтами електрохімічних потенціалів X_j = -∇η_j):

```
J_i = ∑_(j) L_ij · X_j
```

де L_ij — феноменологічні коефіцієнти Онзагера. За принципом взаємності Онзагера матриця феноменологічних коефіцієнтів є симетричною:

```
L_ij = L_ji
```

Диагональні коефіцієнти L_ii описують прямий дифузійний або дрейфовий потік компонент (зокрема іонну провідність σ_i = q_i² · L_ii), тоді як недіагональні коефіцієнти L_ij (де i ≠ j) описують перехресні ефекти — зв'язаний потік катіонів та аніонів, ефекти захоплення електронною хмарою або термоелектричний соретівський перенос під дією градієнта температури ∇T.

Врахування коефіцієнтів Онзагера є критично важливим для точного розрахунку перехресних потоків у суперіонних провідниках із високою концентрацією рухливих частинок, де іон-іонна кулонівська кореляція відіграє вирішальну роль. Фізичний зміст недіагонального коефіцієнта L_12 полягає у ступені кореляції між рухом різних іонних підсистем або іонів та вакансій, що прямо визначає фактор Хейвена H_R = D_tracer / D_charge = 1 - (2 · L_12 / L_11).

## 5. Математичний опис просторового заряду Планка-Пуассона

На межі розподілу між твердим електролітом та електродом виникає шар просторового заряду внаслідок відмінності хімічних потенціалів іонів. Розподіл електричного потенціалу V(x) та концентрації носіїв n(x) описується зв'язаною системою рівнянь Планка-Пуассона:

```
d²V / dx² = -(q / ε) · [ n_pos(x) - n_neg(x) ]
```

де ε = ε_r · ε_0 — діелектрична проникність електроліту.

За термодинамічної рівноваги концентрація іонів підпорядковується розподілу Больцмана:

```
n_pos(x) = n_0 · exp( -q · V(x) / (k_B · T) )
n_neg(x) = n_0 · exp(  q · V(x) / (k_B · T) )
```

Підставляючи вирази Больцмана у рівняння Пуассона:

```
d²V / dx² = (2 · q · n_0 / ε) · sinh( q · V(x) / (k_B · T) )
```

Для малих потенціалів (q·V << k_B·T) застосовують наближення Пуассона-Больцмана sinh(z) ≈ z:

```
d²V / dx² = (2 · q² · n_0 / (ε · k_B · T)) · V(x)
= (1 / λ_D²) · V(x)
```

де λ_D — **дебаївська довжина екранування** у твердому електроліті:

```
λ_D = √( (ε · k_B · T) / (2 · q² · n_0) )
```

Розв'язок рівняння для напівнескінченного середовища з граничною умовою V(0) = V_0 на контакті з електродом:

```
V(x) = V_0 · exp( -x / λ_D )
```

Характерна товщина шару просторового заряду λ_D в іонних провідниках із високою концентрацією дефектів (n_0 ~ 10²¹ см⁻³) становить від кількох ангстрем до кількох нанометрів (0.5–2 нм).

## 6. Строге виведення рівняння Нернста-Ейнштейна

Розглянемо шар іонного провідника, у якому існує градієнт концентрації носіїв dn/dx та зовнішнє електричне поле E = -dV/dx. Загальна густина потоку іонів j за рівнянням Нернста-Планка складається з дрейфової та дифузійної компонент:

```
j = j_drift + j_diff
= n · v_drift - D · (dn / dx)
```

де v_drift = μ · E — дрейфова швидкість, μ — дрейфова рухливість, D — коефіцієнт дифузії.

У стані термодинамічної рівноваги за відсутності макроскопічного струму (j = 0):

```
n · μ · E - D · (dn / dx) = 0
```

Замінюючи поле E через градієнт потенціалу -dV/dx:

```
-n · μ · (dV / dx) - D · (dn / dx) = 0
```

Розділимо змінні:

```
(1 / n) · (dn / dx) = -(μ / D) · (dV / dx)
```

Інтегруючи обома частинами від точки x_1 до x_2:

```
ln( n(x_2) / n(x_1) ) = -(μ / D) · [ V(x_2) - V(x_1) ]
```

З іншого боку, згідно з розподілом Больцмана для заряджених частинок у потенціальному полі:

```
n(x_2) / n(x_1) = exp( -q · [V(x_2) - V(x_1)] / (k_B · T) )
```

Беручи логарифм від виразу Больцмана:

```
ln( n(x_2) / n(x_1) ) = -q · [V(x_2) - V(x_1)] / (k_B · T)
```

Порівнюючи два вирази для логарифма співвідношення концентрацій:

```
-(μ / D) · [V(x_2) - V(x_1)] = -q · [V(x_2) - V(x_1)] / (k_B · T)
```

Скорочуючи різницю потенціалів [V(x_2) - V(x_1)], отримуємо **рівняння Нернста-Ейнштейна**:

```
μ / D = q / (k_B · T)
```

або для рухливості μ:

```
μ = (q · D) / (k_B · T)
```

## 7. Загальне рівняння питомої провідності та залежність Арреніуса

Густина електричного струму J, викликаного рухом іонів із зарядом q = z · e, пов'язана з напруженістю електричного поля E законом Ома J = σ · E. З іншого боку, J = q · j_drift = q · n · v_drift = n · q · μ · E.

Порівнюючи вирази, маємо для питомої іонної провідності σ:

```
σ = n · q · μ
```

Підставляючи вираз для рухливості μ з рівняння Нернста-Ейнштейна:

```
σ = n · q · [ (q · D) / (k_B · T) ]
= (n · q² · D) / (k_B · T)
```

Коефіцієнт стрибкової дифузії іонів у кристалічній ґратці описується виразом:

```
D = D_0 · exp( -E_m / (k_B · T) )
```

де D_0 = (1/6) · ν_0 · a² — предекспоненційний фактор дифузії (ν_0 — частота спроб ~10¹² Гц, a — довжина стрибка), а E_m — енергія активації міграції іона.

Концентрація носіїв n залежить від режиму провідності:
1. У **власній області** концентрація термодинамічних дефектів залежить від температури: n = N · exp(-ΔH_f / (2 · k_B · T)).
2. У **домішковій області** (або у суперіонному стані) концентрація носіїв n = n_const зафіксована домішкою або кристалічною структурою.

Для домішкової області підстановка n_const та D у рівняння провідності дає:

```
σ = [ (n_const · q² · D_0) / (k_B · T) ] · exp( -E_m / (k_B · T) )
```

Помноживши обидві частини на температуру T, отримуємо підсумкове рівняння Арреніуса у формі Арреніуса-Поланьї:

```
σ · T = σ_0 · exp( -E_a / (k_B · T) )
```

де σ_0 = (n_const · q² · D_0) / k_B — предекспоненційний фактор провідності, а E_a — повна енергія активації провідності:

```
E_a = E_m                        [для домішкового або суперіонного режиму]
E_a = E_m + ΔH_f / 2             [для власного термодинамічного режиму]
E_a = E_m + ΔH_assoc / 2         [для режиму асоціації дефектів при низьких Т]
```

Логарифмування обох частин рівняння дає лінійну залежність у координатах ln(σ·T) від 1/T:

```
ln(σ · T) = ln(σ_0) - E_a / (k_B · T)
```

Тангенс кута нахилу цієї прямої на графіку Арреніуса безпосередньо визначає активаційний бар'єр E_a іонного транспорту в кристалі.
