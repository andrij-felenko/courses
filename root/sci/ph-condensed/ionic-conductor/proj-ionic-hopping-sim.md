# ⚙️ Симуляція Монте-Карло для стрибкової іонної провідності

Ця практична вставка містить чисельну модель методом Монте-Карло для дослідження стрибкового транспорту іонів у кристалічній ґратці під дією зовнішнього електричного поля. Приведено теоретичний аналіз кінетичного методу Монте-Карло (Kinetic Monte Carlo, KMC), фізичну модель потенціального рельєфу, розбір фактора Хейвена й корельованого блукання, аналіз алгоритмів просування часу, розширення моделі на двовимірну (2D) та тривимірну (3D) ґратку, вплив кристалічної симетрії та анізотропний транспорт, а також вичерпні реалізації мовами C та C++.

## 1. Фізична модель іонного стрибка у потенціальному рельєфі

Мікроскопічний перенос іонів у твердих електролітах відбувається шляхом дискретних термоактивованих стрибків між сусідніми вакансіями або міжвузлями. Оскільки часовий масштаб міжмолекулярних коливань іона у потенціальній ямі становить порядка 10⁻¹³–10⁻¹² секунд (100 фс — 1 пс), а середній час між послідовними стрибками за кімнатної або помірної температури становить від 10⁻⁹ до 10⁻⁶ секунд (від наносекунд до мікросекунд), метод класичної молекулярної динаміки (MD) вимагає величезних обчислювальних витрат для моделювання макроскопічної дифузії.

Кінетичний метод Монте-Карло (Kinetic Monte Carlo, KMC) абстрагується від швидких фононних коливань іона у потенціальній ямі й моделює процес як послідовність марковських переходів між мінімумами потенціальної енергії з розрахованими ймовірностями.

У спрощеній одновимірній кристалічній ґратці з періодом a іон перебуває в потенціальних мінімумах, розділених активаційними бар'єрами висотою E_a. За теорією перехідного стану Він'ярда (Vineyard's Transition State Theory), частота спроб подолання бар'єра ν_0 визначається спектром нормальних коливань ґратки:

```
ν_0 = ∏_(i=1)^(3N) ν_i / ∏_(j=1)^(3N-1) ν_j'
```

де ν_i — частоти коливань іона у мінімумі, а ν_j' — частоти у сідловій точці потенціального бар'єра. Зазвичай ν_0 прийнято вважати величиною порядку 10¹²–10¹³ Гц (1–10 ТГц).

За відсутності зовнішнього електричного поля (E = 0) потенціальний рельєф є строго симетричним. Частота успішних теплових стрибків іона вліво ν_left та вправо ν_right однакова й визначається виразом Арреніуса:

```
ν_left = ν_right = ν_0 · exp( -E_a / (k_B · T) )
```

де k_B — константа Больцмана, T — абсолютна температура. Оскільки ймовірності стрибків в обох напрямках рівні, математичне сподівання зсуву іона за час t дорівнює нулю (<Δx(t)> = 0). У системі відбувається лише симетрична теплова дифузія, яка описується середнім квадратом зсуву:

```
<Δx²(t)> = 2 · D_tracer · t
```

де D_tracer — коефіцієнт міченої дифузії (tracer diffusion coefficient).

При накладенні зовнішнього електричного поля напруженістю E потенціальний рельєф деформується (нахиляється на величину потенціалу електричного поля -q·E·x). Для стрибка вздовж напрямку поля потенціальний бар'єр знижується на величину ΔU = q · a · E / 2, а для стрибка проти напрямку поля — підвищується на ту саму величину:

```
E_a_forward  = E_a - (q · a · E) / 2
E_a_backward = E_a + (q · a · E) / 2
```

Відповідно, парціальні частоти стрибків уперед ν_fwd та назад ν_bwd стають асиметричними:

```
ν_fwd = ν_0 · exp( -(E_a - q·a·E / 2) / (k_B · T) )
ν_bwd = ν_0 · exp( -(E_a + q·a·E / 2) / (k_B · T) )
```

Ймовірність того, що іон здійснить стрибок уперед за малий проміжок часу Δt:

```
p_fwd = ν_fwd · Δt
p_bwd = ν_bwd · Δt
```

Крок за часом Δt обирають з умови p_fwd + p_bwd < 1 (типово p_total ≤ 0.2), щоб уникнути виходу ймовірності за межі одиниці й забезпечити коректність стохастичного опису.

Асиметрія ймовірностей приводить до виникнення направленого дрейфу іонів зі середньою швидкістю v_drift:

```
v_drift = a · (ν_fwd - ν_bwd)
= a · ν_0 · exp( -E_a / (k_B · T) ) · [ exp(q·a·E / (2·k_B·T)) - exp(-q·a·E / (2·k_B·T)) ]
= 2 · a · ν_0 · exp( -E_a / (k_B · T) ) · sinh( (q · a · E) / (2 · k_B · T) )
```

Для слабких електричних полів (q · a · E << k_B · T) застосовують розклад sinh(x) ≈ x, що дає лінійну залежність дрейфової швидкості від поля (Закон Ома):

```
v_drift ≈ (a² · q · ν_0 / (k_B · T)) · exp( -E_a / (k_B · T) ) · E
```

При високих полях (E > 10⁷ В/м) відхилення від закону Ома описується ефектом Пооля-Френкеля та гіперболічним синусом.

## 2. Алгоритми просування часу у KMC: постійний крок проти очікуваного часу

У чисельному моделюванні кінетики стрибків використовуються два основних алгоритми:

1. **Алгоритм із постійним часовим кроком (Constant Time-Step Algorithm)**:
   На кожному часовому кроці тривалістю Δt розраховуються абсолютні ймовірності стрибків p_fwd та p_bwd. Генерується випадкове число r ∈ [0, 1). Якщо r < p_fwd, здійснюється стрибок вперед; якщо p_fwd ≤ r < p_fwd + p_bwd, здійснюється стрибок назад; інакше іон залишається у наявній ямі. Цей підхід є простим для реалізації та паралелізації, проте вимагає ретельного вибору Δt, щоб уникнути перевищення сумарної ймовірності 1.0.

2. **Алгоритм очікуваного часу (Residence Time / BKL Algorithm)**:
   Замість вибору довільного Δt обчислиться сумарна частота всіх можливих переходів для даного стану системи:

```
R_total = ∑_(k) ν_k = ν_fwd + ν_bwd
```

Далі випадкове число r_1 визначає напрямок стрибка (пропорційно часткам ν_k / R_total), а друге випадкове число r_2 визначає точний проміжок часу Δt до наступної події:

```
Δt = -ln(r_2) / R_total
```

Цей алгоритм є строго точним, оскільки кожен виклик генератора випадкових чисел обов'язково приводить до фізичного стрибка, що прискорює симуляцію на 3–5 порядків при низьких температурах, коли звичайні стрипки відбуваються рідко.

## 3. Моделювання транспорту на 2D та 3D ґратках

У двовимірній (2D) квадратній ґратці (наприклад, у проводильних шарах Na-β''-Al₂O₃) кожен рівноважний вузол має чотирьох найближчих сусідів: +x, -x, +y, -y.

За наявності двохвимірного вектора електричного поля E = (E_x, E_y) зміни активаційних бар'єрів для напрямків x та y становлять:

```
ΔU_x = (q · a · E_x) / 2
ΔU_y = (q · a · E_y) / 2
```

Парціальні ймовірності стрибків за один крок Δt для чотирьох можливих напрямків обчислюються як:

```
p_+x = ν_0 · Δt · exp( -(E_a - ΔU_x) / (k_B · T) )
p_-x = ν_0 · Δt · exp( -(E_a + ΔU_x) / (k_B · T) )
p_+y = ν_0 · Δt · exp( -(E_a - ΔU_y) / (k_B · T) )
p_-y = ν_0 · Δt · exp( -(E_a + ΔU_y) / (k_B · T) )
```

Сумарна ймовірність зафіксувати будь-який стрибок у 2D становить p_total = p_+x + p_-x + p_+y + p_-y. Сума квадратичних відхилений по обох координатах описує двовимірний коефіцієнт дифузії:

```
<Δr²(t)> = <Δx²(t)> + <Δy²(t)> = 4 · D_2D · t
```

У тривимірній кубічній ґратці (3D) з 6 найближчими сусідами коефіцієнт дифузії узагальнюється виразом:

```
<Δr²(t)> = <Δx²> + <Δy²> + <Δz²> = 6 · D_3D · t
```

У розширених моделях гранецентрованої (ГЦК) ґратки із 12 найближчими сусідами вектор стрибка дорівнює a_vec = (a/2, a/2, 0) тощо. Кількість можливих векторів зсуву зростає до 12, а сумарна частота R_total враховує проектувальні коефіцієнти скалярного добутку a_vec · E.

## 4. Перехідний режим дифузії та часова залежність MSD

При вивченні іонного транспорту методом Монте-Карло важливо аналізувати часову залежність середнього квадрата зсуву (Mean Squared Displacement, MSD) <Δr²(t)>. Процес дифузії проходити крізь три послідовні часові режими:

1. **Балістичний/Фононний режим (t < 10⁻¹² с)**:
   Іон коливається всередині потенціальної ями. MSD зростає квадратично за часом <Δr²(t)> ~ t². У KMC моделі цей режим відсутній, оскільки час дискретизовано стрибками.

2. **Аномальна/Субдифузійна область (t_hop < t < τ_relax)**:
   При високих концентраціях іонів або за наявності випадкового потенціального рельєфу (склоподібні електроліти) іон випробує ефект локального захоплення. MSD описується дробовим ступенем часу <Δr²(t)> ~ t^α (де α < 1).

3. **Нормальна Ейнштейнівська дифузія (t > τ_relax)**:
   Усі локальні кореляції уссереднюються, а MSD зростає строго лінійно з часом <Δr²(t)> = 2·d·D·t (де d — розмірність простору). Розрахунок коефіцієнта дифузії D необхідно проводити строго в цій лінійній області.

Для складних кристалічних структур (наприклад, поліаніонних каркасів NASICON або LLZO) застосовують підхід розбиття рельєфу на енергетично нееквівалентні вузли (наприклад, позиції Li(1) 24d та Li(2) 96h у гранатах LLZO). Частоти стрибків між різними позиціями ν_(i->j) задовільняють умові детального балансу:

```
ν_(i->j) / ν_(j->i) = exp( -(E_j - E_i) / (k_B · T) )
```

це гарантує термодинамічно коректний рівноважний розподіл іонів по нееквівалентних вузлах кристалічної ґратки. Отриманий коефіцієнт дифузії безпосередньо входить у макроскопічні рівняння нерівноважної переносної термодинаміки, пов'язуючи атомний масштаб із макроскопічними експериментальними величинами іонного струму й дозволяючи точне прогнозування кінетики заряду в реальних твердих електролітах.

## 5. Граничні умови та ефекти блокування на контактах

У моделюванні іонного транспорту залежно від фізичної постановки задачі застосовують два типи граничних умов:

1. **Періодичні граничні умови (Periodic Boundary Conditions, PBC)**:
   Використовуються для моделювання квазінескінченного кристалічного об'єму електроліту. Коли іон виходить за межу області x > L, він повертається з іншого боку x' = x - L. Його повний накопичений зсув при цьому продовжує підраховуватися у безперервних координатах. Це дозволяє розраховувати питому об'ємну провідність σ_bulk без крайових спотворень.

2. **Блокуючі тверді стінки (Blocking Hard Walls)**:
   Моделюють плоскі іонно-блокуючі електроди (наприклад, платинові або золоті контакти), крізь які іони не можуть проникнути (p_jump = 0 на межі). У цьому випадку під дією електричного поля іони накопичуються біля позитивного або негативного електрода, створюючи градієнт концентрації та шар просторового заряду. Це дозволяє спостерігати формування мікроскопічної ємності подвійного електричного шару (ПЕШ) та спад струму з часом до нуля.

## 6. Корельоване блукання, фактор Хейвена та розрахунок статистичних похибок

У реальному кристалі стрибки іонів за вакансійним механізмом не є повністю незалежними (блукання не є чисто марковським для міченого іона). Після того як іон стрибнув у вакансію, ця сама вакансія залишається безпосередньо позаду нього. Тому ймовірність зворотного стрибка іона у щойно звільнену позицію є вищою за ймовірність стрибка в інших напрямках.

Це явище враховується **фактором кореляції** f (або фактором Хейвена H_R):

```
H_R = D_tracer / D_charge
```

де D_tracer — коефіцієнт дифузії мічених атомів (який вимірюють ізотопними індикаторами), а D_charge — коефіцієнт дифузії заряду, що входить до рівняння Нернста-Ейнштейна для питомої провідності:

```
σ = (n · q² · D_charge) / (k_B · T)
```

Для 3D гранецентрованої кубічної ґратки (ГЦК) при вакансійному механізмі f ≈ 0.7815, для об'ємноцентрированої (ОЦК) f ≈ 0.727, а для міжвузлового прямого механізму f = 1.0 (кореляція відсутня). Метод Монте-Карло є ідеальним інструментом для точного чисельного розрахунку фактора Хейвена в складних 3D структурах.

Крім того, за високих концентрацій рухливих іонів виникає **ефект блокування вузлів** (site exclusion effect). Згідно з принципом Паулі у класичному наближенні, кожен потенціальний вузол ґратки може містити не більше одного іона. Це приводить до виникнення фактора заповнення θ: ймовірність стрибка у сусідній вузол пропорційна частці вільних вакансій (1 - θ).

Для оцінки статистичної похибки обчислення коефіцієнта дифузії D в симуляції використовують **метод блочного усереднення** (Block Averaging). Весь часовий ряд розділяють на M блоків тривалістю τ_block. Дисперсія середніх значень блоків дозволяє розраховувати чистий довірчий інтервал без спотворення часовою автокореляцією.

## 7. Алгоритм чисельної симуляції Монте-Карло

Симуляція реалізує стохастичний алгоритм динаміки Монте-Карло (Kinetic Monte Carlo, KMC):

1. **Ініціалізація симуляційного ансамблю**: Створюється масив із N_ions іонів, які у початковий момент часу t = 0 розміщені на вихідних позиціях x_i = 0.
2. **Задання фізичних параметрів**: Задаються температура T (К), енергія активації E_a (еВ), напруженість поля E (В/м), заряд іона q (у одиницях e), період ґратки a (м), спробна частота ν_0 (Гц) та кількість кроків N_steps.
3. **Розрахунок частот і ймовірностей**: Обчислюються енергетичні бар'єри з урахуванням поля E та відповідні парціальні ймовірності p_fwd і p_bwd за один крок Δt.
4. **Ітераційний цикл за часом**: На кожному кроці для кожного іона ансамблю генерується псевдовипадкове число r з рівномірного розподілу на відрізку [0, 1):
   - Якщо r < p_fwd, іон здійснює дискретний зсув на +a.
   - Якщо p_fwd ≤ r < (p_fwd + p_bwd), іон здійснює зсув на -a.
   - Якщо r ≥ (p_fwd + p_bwd), іон залишається у початковому рівноважному стані.
5. **Статистична обробка та усереднення**: Після завершення всіх часових кроків обчислюється середній зсув ансамблю <x(t)>, середній квадрат зсуву <x²(t)>, дрейфова швидкість v_drift = <x(t_total)> / t_total, коефіцієнт дифузії D = (<x²> - <x>²) / (2 · t_total) та дрейфова рухливість μ = v_drift / E.
6. **Перевірка співвідношення Нернста-Ейнштейна**: Обчислюється відношення μ / D і порівнюється з теоретичним значенням q / (k_B · T).

## 9. Фізичний аналіз результатів чисельного експерименту

Результати комп'ютерного моделювання методом Монте-Карло дозволяють зробити кілька важливих фізичних висновків про характер іонного транспорту в кристалічній ґратці:

1. **Точність виконання співвідношення Нернста-Ейнштейна**: У лінійному режимі (слабкі поля E ≤ 10⁵ В/м) відношення симульованої рухливості до коефіцієнта дифузії μ / D збігається з теоретичним значенням q / (k_B · T) з точністю до статистичної похибки моделювання (~1–2%). Це підтверджує термодинамічну узгодженість модельних стрибків.
2. **Сплайновий перехід до нелінійного режиму**: При зростанні напруженості електричного поля вище E > 10⁷ В/м дрейфова швидкість зростає швидше за лінійний закон Ома, описуючись фактором sinh(q·a·E / (2·k_B·T)). У симуляції це проявляється у різкому збільшенні частоти стрибків у напрямку поля та пригніченні зворотних стрибків.
3. **Залежність від температури та активаційного бар'єра**: Зменшення енергії активації E_a з 0.4 еВ до 0.2 еВ або підвищення температури з 300 K до 600 K викликає збільшення коефіцієнта дифузії D та іонної провідності σ більш ніж на три порядки. Це математично підтверджує високу чутливість твердих електролітів до структури проводильних каналів.
