# 🧮 Квазіквантова кінетика тунелювання та захоплення заряду у CTF

Фізичний стан комірки пам'яті на локалізованих пастках заряду (SONOS/CTF) визначається кількістю, просторовим розподілом та енергетичним спектром електронів, захоплених у диелектричному шарі `Si3N4`. Зсув порогової напруги транзистора `ΔV_th`, швидкість запису, час збереження заряду та часові характеристики стирання описуються системою нелінійних диференціальних рівнянь, що пов'язують квантово-механічне тунелювання крізь потенціальний бар'єр `SiO2`, кінетику пасткування носіїв у K-центрах та термічно-полеве депасткування (зняття заряду) за ефектом Пула-Френкеля.

---

### 1. Квантово-механічне тунелювання крізь тунельний оксид

Під дією високого електричного поля в тунельному диелектрику `E_ox` (типово `E_ox = 8 – 12 MV/cm`) прямокутний потенціальний бар'єр дна зони провідності на межі `Si/SiO2` висотою `Φ_B ≈ 3.15 eV` деформується, перетворюючись на трикутний або трапецієподібний.

```
                  ┌────────────────────────┐ дно зони провідності SiO2
                  │                        │
                  │   Трикутний бар'єр     │
                  │   під полем E_ox       │
                  │  /                     │
                  │ /                      │
 дно зони Si      │/                       └────── дно зони Si3N4
──────────┐       │
          │       │
          └───────┴───────────────────────────────
          x = 0   x = x_t                  x = d_tox
```

У напівкласичному наближенні ВЕНК (Вентцеля-Крамерса-Бріллюена) ймовірність тунелювання електрона з енергією `E` крізь потенціальний бар'єр `V(x)` виражається інтегралом дії:

```
P_tunnel = exp(-2 · ∫₀^(x_t) k(x) dx)  [ймовірність тунелювання за ВЕНК]
```

де `k(x)` — квазіімпульс електрона під бар'єром:

```
k(x) = (√(2 · m_ox* · (V(x) - E))) / ℏ   [хвильове число під бар'єром]
```

Для трикутного бар'єра потенціальний профіль має вигляд `V(x) = Φ_B - q · E_ox · x`. Точка повороту `x_t`, де дно зони провідності падає до рівня енергії інжектованого електрона, становить `x_t = Φ_B / (q · E_ox)`.

#### 1.1. Режим тунелювання Фаулера-Нордгейма (FN Tunneling)
Коли товщина тунельного оксиду `d_tox` перевищує точку повороту `x_t` (`d_tox > Φ_B / (q · E_ox)`), електрон виходить безпосередньо у зону провідності `SiO2`. Інтегрування хвильового числа від `x = 0` до `x = x_t` дає класичну виражену формулу густини струму Фаулера-Нордгейма `J_FN`:

```
J_FN = A_FN · E_ox² · exp(-B_FN / E_ox)  [густина струму тунелювання Фаулера-Нордгейма]
```

де феноменологічні константи Фаулера-Нордгейма `A_FN` та `B_FN` визначаються чисто фундаментальними константами та ефективною масою електрона в оксиді `m_ox* ≈ 0.42 · m_0`:

```
A_FN = q³ / (16 · π² · ℏ · Φ_B)          [перша константа Фаулера-Нордгейма]
```

```
B_FN = (4 · √(2 · m_ox*) · Φ_B^(3/2)) / (3 · q · ℏ)  [друга константа Фаулера-Нордгейма]
```

Підставивши числові значення для межі `Si/SiO2` (`Φ_B = 3.15 eV`, `m_ox* = 0.42 · m_0`), отримуємо значення констант:
- `A_FN ≈ 2.2 × 10⁻⁶ A/V²`
- `B_FN ≈ 2.38 × 10⁸ V/cm` (або `238 MV/cm`)

За умов напруженості поля `E_ox = 10 MV/cm` густина струму `J_FN` досягає `10⁻² – 10⁻¹ A/cm²`, що забезпечує швидке заповнення пасток за час порядку десятків мікросекунд.

#### 1.2. Режим прямого тунелювання (Direct Tunneling)
Якщо товщина тунельного оксиду є дуже малою (`d_tox < 2.5 nm`), або напруженість поля помірна (`E_ox < 6 MV/cm`), то точка повороту `x_t` виходить за межі оксидного шару (`x_t > d_tox`). Бар'єр залишається трапецієподібним, а електрон під час тунелювання не потрапляє у зону провідності `SiO2`, а переходить безпосередньо із зони провідності кремнію у зону провідності `Si3N4`.

Густина струму прямого тунелювання `J_DT` описується виразом:

```
J_DT = A_DT · E_ox² · exp(-B_FN / E_ox · [1 - (1 - q · E_ox · d_tox / Φ_B)^(3/2)])  [густина струму прямого тунелювання]
```

При наближенні `E_ox → 0` експоненціальний множник спрощується до прямої залежності від товщини:

```
J_DT(E_ox → 0) ∝ exp(-2 · d_tox · √(2 · m_ox* · Φ_B) / ℏ)  [згасання за відсутності поля]
```

Звідси видно, що кожні додаткові `0.2 nm` товщини тунельного оксиду зменшують струм витоку у стані збереження приблизно в 10 разів.

### 2. Динаміка пасткування носіїв у шарі Si3N4

Електрони, інжектовані через тунельний оксид, потрапляють у зону провідності `Si3N4` з початковою кінетичною енергією. Внаслідок сильного оптичного фононного розсіювання електрони за час `~10⁻¹³ s` релаксують до дна зони провідності нітриду і захоплюються нейтральними та позитивними K-центрами.

Розподіл носіїв описується системою диференціальних рівнянь неперервності для вільних електронів зони провідності `n_c(z, t)` та захоплених електронів `n_t(z, t)`.

```
∂n_c(z, t) / ∂t = (1 / q) · ∂J_n(z, t) / ∂z - ∂n_t(z, t) / ∂t  [баланс вільних електронів]
```

```
∂n_t(z, t) / ∂t = (J_n(z, t) / q) · σ_t · (N_t - n_t(z, t)) - e_p · n_t(z, t)  [кінетика захоплення в пастки]
```

де:
- `N_t` — повна об'ємна концентрація пасток у нітриді (`N_t ≈ 10¹⁹ – 5 × 10²⁰ cm⁻³`);
- `σ_t` — ефективний переріз захоплення пастки (`σ_t ≈ 10⁻¹⁴ – 10⁻¹⁵ cm²`);
- `e_p` — ймовірність депасткування (зняття носія з пастки) за одиницю часу (`s⁻¹`).

#### Аналітичний розв'язок на початковій стадії програмування
При швидкому програмуванні депасткуванням на початкових мікросекундах можна знехтувати (`e_p ≈ 0`). Припустивши рівномірну концентрацію вільних пасток по товщині нітриду `d_nit`, інтегрування диференціального рівняння дає часову залежність накопичення заповнених пасток `n_t(t)`:

```
n_t(t) = N_t · [1 - exp(-σ_t · F_inj(t))]   [заповненість пасток від флюенсу]
```

де `F_inj(t)` — накопичений поверхневий флюенс інжектованих електронів (`cm⁻²`):

```
F_inj(t) = ∫₀ᵗ (J_n(t') / q) dt'          [накопичений інжекційний флюенс]
```

З аналітичного виразу випливає ефект **самолімітування пасткування**: у міру заповнення K-центрів (`n_t → N_t`) кількість вільних пасток `(N_t - n_t)` падає до нуля, а інжектовані електрони пролітають шар нітриду наскрізь, не збільшуючи накопичений заряд.

### 3. Термополева емісія Пула-Френкеля (Poole-Frenkel Emission)

Під час стирання комірки негативною напругою (`V_g < 0`) або при тривалому збереженні за високих температур головним механізмом виходу електронів із потенціальних ям K-центрів у зону провідності є **термополева емісія Пула-Френкеля** (*Poole-Frenkel Emission*).

Потенціальна енергія електрона `U(r)` у кулонівській пастці за наявності зовнішнього електричного поля `E_nit` уздовж осі `r` має вигляд:

```
U(r) = - q² / (4 · π · ε_0 · ε_nit · r) - q · E_nit · r  [потенціал деформованої пастки]
```

Графік потенціалу зображено нижче:

```
               U(r) ▲
                    │      Недеформована кулонівська яма (E = 0)
                    │     /
             ───E_t─┼────/───────────────
                    │   /  \
                    │  /    \ Зниження бар'єра ΔΦ_PF = β_PF · √E
                    │ /      └───┐
                    │/           └───┐
 ───────────────────┼────────────────┴────────► r
                    │                r_max
```

Точка максимуму потенціального бар'єра `r_max` знаходиться з умови `dU/dr = 0`:

```
r_max = √(q / (4 · π · ε_0 · ε_nit · E_nit))   [координата максимуму бар'єра]
```

Значення зниження потенціального бар'єра `ΔΦ_PF = U(∞) - U(r_max)` виражається через коефіцієнт Пула-Френкеля `β_PF`:

```
ΔΦ_PF = β_PF · √E_nit                          [зниження бар'єра Пула-Френкеля]
```

```
β_PF = √(q³ / (π · ε_0 · ε_nit))               [коефіцієнт Пула-Френкеля]
```

Підставивши значення відносної діелектричної проникності нітриду кремнію `ε_nit ≈ 7.5`, отримуємо `β_PF ≈ 2.76 × 10⁻⁴ eV · (V/cm)^(-1/2)`. Для поля `E_nit = 4 MV/cm` зниження бар'єра становить `ΔΦ_PF ≈ 0.55 eV`, що зменшує ефективну глибину пастки з `1.2 eV` до `0.65 eV`.

Густина струму емісії Пула-Френкеля `J_PF` описується рівнянням:

```
J_PF = C_PF · E_nit · exp(-q · (E_t - β_PF · √E_nit) / (k_B · T))  [струм емісії Пула-Френкеля]
```

де:
- `C_PF` — пропорційний коефіцієнт провідності (`Ω⁻¹·cm⁻¹`);
- `E_t` — енергетична глибина пастки за відсутності поля (`~1.2 eV`);
- `k_B` — константа Больцмана;
- `T` — абсолютна температура в кельвінах (K).

Рівняння Пула-Френкеля доводить, що швидкість депасткування залежить від температури за експоненціальним законом Арреніуса. Це пояснює прискорений витік заряду при температурних випробуваннях під час сертифікації SSD-накопичувачів.

### 4. Електростатичний розрахунок зсуву порогової напруги та центроїд заряду

При накопиченні в шарі `Si3N4` просторового заряду електронів з об'ємною густиною `ρ(z) = -q · n_t(z)` розподіл електростатичного потенціалу `ϕ(z)` вздовж товщини ONO-стека підпорядковується одновимірному рівнянню Пуассона:

```
d²ϕ(z) / dz² = - ρ(z) / ε(z)                  [рівняння Пуассона для ONO-стека]
```

Інтегрування рівняння Пуассона від кремнієвого каналу (`z = 0`) до управляючого затвора дає точний вираз для зсуву порогової напруги транзистора `ΔV_th`:

```
ΔV_th = - (1 / ε_ox) · ∫₀^(d_nit) z' · ρ(z') dz'  [загальний зсув порогової напруги]
```

Для аналітичної зручності вводиться фундаментальний параметр розподілу заряду — **центроїд заряду** `z_bar`. Він визначається як середньозважена координата залягання захопленого заряду, відрахована від межі розділу з блокуючим диелектриком:

```
z_bar = (∫₀^(d_nit) z · n_t(z) dz) / (∫₀^(d_nit) n_t(z) dz)  [центри ваги накопиченого заряду]
```

З урахуванням центроїда заряду `z_bar` та повної поверхневої густини захопленого заряду `Q_t = q · ∫₀^(d_nit) n_t(z) dz` (в Кл/см²), зсув порогової напруги `ΔV_th` виражається через геометричні та диелектричні параметри шарів:

```
ΔV_th = (Q_t / ε_nit) · [d_box · (ε_nit / ε_box) + z_bar]  [формула зсуву V_th через центроїд]
```

де:
- `d_box` — товщина блокуючого шару диелектрика;
- `ε_box` — відносна діелектрична проникність блокуючого шару (`3.9` для `SiO2`, `9.0` для `Al2O3`);
- `ε_nit` — відносна діелектрична проникність шару нітриду (`7.5`).

#### Фізичний аналіз формули зсуву порогової напруги
1. **Залежність від центроїда `z_bar`:** Чим глибше електрони проникають у шар нітриду і чим ближче центроїд `z_bar` розташований до тунельного оксиду, тим більшу модулюючу дію накопичений заряд чинить на поверхневий потенціал кремнієвого каналу, і тим більшим є зсув `ΔV_th`.
2. **Вплив High-k диелектрика `Al2O3`:** Заміна `SiO2` на `Al2O3` зменшує ефективну оптичну товщину блокуючого шару `d_box · (ε_nit / ε_box)` у `9.0 / 3.9 ≈ 2.3` раза. Це дозволяє збільшити фізичну товщину блокуючого оксиду `d_box` для придушення витоків, зберігши високу чутливість порогової напруги `ΔV_th` до інжектованого заряду `Q_t`.

### 5. Час ретенції та кінетика деградації вікна пам'яті

Час збереження заряду (ретенція, *Retention time*) визначається часовою залежністю залишкового зсуву порогової напруги `ΔV_th(t)`. Зменшення `ΔV_th(t)` із часом `t` зумовлене сумою двох процесів:
1. Термополивою емісією Пула-Френкеля з пасток у зону провідності `Si3N4`;
2. Прямим тунелюванням електронів із K-центрів крізь тунельний оксид назад у підкладку.

Швидкість втрати порогової напруги описується логарифмічним законом часової деградації:

```
ΔV_th(t) = ΔV_th(0) - S_ret · log10(1 + t / t_0)  [закон деградації порогової напруги]
```

де:
- `ΔV_th(0)` — початковий зсув порогової напруги одразу після програмування;
- `S_ret` — коефіцієнт спаду ретенції (типово `S_ret ≈ 0.05 – 0.15 V/decade`);
- `t_0` — характерний час початку витоку (`t_0 ≈ 10⁻³ – 1 s`).

Коефіцієнт спаду `S_ret` зростає пропорційно абсолютній температурі `T` та щільності поверхневих дефектів у тунельному диелектрику, що виникають під час циклічного перезапису (ефект SILC). Розрахунок за рівнянням Пула-Френкеля дає гарантований термін збереження заряду `t_ret > 10` років за умови, що залишкове вікно пам'яті `ΔV_th(t)` перевищує мінімальний поріг зчитування підсилювача розрізнення (`Sense Amplifier`).
