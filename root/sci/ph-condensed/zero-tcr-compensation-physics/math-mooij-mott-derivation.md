# 🧮 Квантово-механічне виведення ефекту Муя та модель Мотта

У чистих металах питомий опір описується класичним правилом Маттіссена, де домішковий опір `ρ_0` не залежить від температури, а фононне розсіяння надає строго позитивний температурний коефіцієнт `dρ_ph / dT > 0`. Однак у високонеупорядкованих сплавах переходних металів та концентрованих твердих розчинах спостерігається аномальне явище — приглушення або навіть зміна знака температурного коефіцієнта опору (ТКО).

Дослідження механізмів провідності сплавів вимагає відходу від класичного наближення Друде. Необхідно враховувати квантову структуру енергетичних зон, несиметричність густини станів поблизу рівня Фермі та квантові ефекти фазової когерентності електронних хвиль.

Строге квантово-механічне пояснення ефекту компенсації ТКО ґрунтується на двох фундаментальних концепціях: двозонній моделі електрон-електронного s-d розсіяння НевІлла Мотта та теорії квантових кореляцій переносу в неупорядкованих середовищах Джонатана Муя.

## 1. Двозонна модель розсіяння Мотта та температурне розмиття рівня Фермі

Перехідні метали (такі як `Ni`, `Fe`, `Mn`, `Cr`) виявляють складну зонну структуру, у якій широка зона провідності, утворена `s`-електронами з малою ефективною масою `m_s*`, перекривається з вузькою `d`-зоною, що має високу густину станів `N_d(E)` та велику ефективну масу `m_d*`.

Основний вклад у електричний струм вносять високорухливі `s`-електрони, оскільки їхня дрейфова швидкість на кілька порядків перевищує швидкість важких `d`-електронів. Однак через квантовий відбір та деформаційний потенціал ґратки головним каналом розсіяння імпульсу `s`-електронів є не зіткнення з фононами у власній `s`-зоні, а перехід у вільні стани `d`-зони (так званий `s-d` процес розсіяння Мотта).

Згідно із золотим правилом Фермі у теорії квантово-механічних обурень, ймовірність `s-d` розсіяння в одиницю часу `1 / τ_sd(E)` для електрона з енергією `E` прямо пропорційна густині прийнятних кінцевих станів `N_d(E)` у `d`-зоні:

```
1 / τ_sd(E) = (2π / ℏ) · |M_sd|² · N_d(E)
```

де:
- `ℏ` — зведена стала Планка;
- `|M_sd|` — матричний елемент оператора потенціалу обурення для квантового переходу носія між `s`- та `d`-станами під дією флуктуацій кристалічного потенціалу;
- `N_d(E)` — об'ємна густина станів у `d`-зоні при енергії `E`.

Оскільки дрейфова рухливість носіїв обернено пропорційна ймовірності розсіяння `μ_s(E) ∝ τ_sd(E)`, то локальна спектральна провідність `σ(E)` на енергетичному рівні `E` є обернено пропорційною густині `d`-станів:

```
σ(E) = C / N_d(E)
```

де `C` — масштабна константа, що визначається ефективною масою електронів провідності та матричним елементом взаємодії.

Макроскопічна питома електрична провідність `σ(T)` розраховується шляхом усреднення спектральної провідності `σ(E)` по всій зоні провідності з урахуванням температурного розмиття функції розподілу Фермі — Дірака `f(E, T)`:

```
σ(T) = ∫ σ(E) · (-∂f / ∂E) dE
```

При температурах `k_B · T << E_F` функція `-∂f / ∂E` являє собою симетричний дзвоноподібний пик з центром у точці `E = E_F` та ефективною шириною порядку `3.5 · k_B · T`.

Для обчислення цього інтеграла застосовують квантово-статистичний розклад Зоммерфельда для систем із невиродженим або слабовиродженим електронним газом:

```
σ(T) = σ(E_F) + (π² / 6) · (k_B · T)² · [∂²σ(E) / ∂E²]_{E = E_F}
```

Оскільки спектральна провідність пов'язана з густиною станів як `σ(E) = C / N_d(E)`, знайдемо першу та другу похідні від `σ(E)` за енергією в околі рівня Фермі:

```
∂σ / ∂E = -C · (N_d') / (N_d)²
```

```
∂²σ / ∂E² = C · [2·(N_d')² - N_d · N_d''] / (N_d)³
```

де `N_d' = dN_d / dE` та `N_d'' = d²N_d / dE²` позначено першу та другу похідні густини станів `d`-зони за енергією у точці `E = E_F`.

Підставляючи другу похідну `∂²σ / ∂E²` у зоммерфельдівський розклад провідності, маємо:

```
σ(T) = σ(E_F) · [1 + (π² / 6) · (k_B · T)² · K_mott]
```

де кривизновий коефіцієнт зонної структури Мотта `K_mott` визначається формулою:

```
K_mott = (N_d'') / N_d - 2 · (N_d' / N_d)²
```

Оскільки питомий електричний опір є оберненою величиною до провідності `ρ(T) = 1 / σ(T)`, розкладаючи у ряд Тейлора за малим параметром `(k_B · T)²`, отримуємо вираз для температурної залежності опору `s-d` розсіяння:

```
ρ_sd(T) = ρ_sd(0) · [1 - (π² / 6) · (k_B · T)² · K_mott]
```

Диференціюючи опір `ρ_sd(T)` за температурою `T`, отримуємо температурний коефіцієнт `s-d` розсіяння:

```
dρ_sd / dT = - (π² / 3) · ρ_sd(0) · k_B² · T · K_mott
```

Аналіз отриманого виразу показує:
1. Якщо рівень Фермі `E_F` розташований на монотонній ділянці `d`-зони або у локальній западині (де `N_d'' > 0`), коефіцієнт `K_mott` є позитивним або малим, і ТКО залишається позитивним.
2. Якщо ж склад сплаву дібрано так, що рівень Фермі `E_F` припадає строго на локальну вершину (пік) густини `d`-станів, то перша похідна дорівнює нулю (`N_d' ≈ 0`), а друга похідна є строго від'ємною (`N_d'' < 0`).
3. У цьому випадку кривизновий коефіцієнт Мотта стає від'ємним: `K_mott = N_d'' / N_d < 0`.

Отже, температурна похідна опору `s-d` розсіяння стає **строго від'ємною**:

```
dρ_sd / dT = - (π² / 3) · ρ_sd(0) · k_B² · T · |K_mott| < 0
```

Цей фундаментальний висновок доводить: теплове розмиття розподілу Фермі — Дірака при нагріванні розмиває вибірковість електронних переходів і зменшує ефективну густину станів у вершині `d`-зони. Менша густина станів знижує ймовірність розсіяння електронів, що призводить до **зменшення** опору матеріалу при підвищенні температури.

## 2. Кореляція Муя та межа Іоффе — Регеля у сильнонеупорядкованих середовищах

У 1973 році голландський фізик Джонатан Муй (Jonathan Mooij) проаналізував експериментальні температурні залежності опору сотень неупорядкованих металевих сплавів та концентрованих твердих розчинів. Він встановив універсальну кореляцію: знак і абсолютна величина ТКО `α` строго визначаються величиною залишкового питомого опору `ρ_0` при кімнатній температурі.

Математична формулювальна кореляції Муя виражається лінійним рівнянням:

```
α = A · (ρ_c - ρ_0)
```

де:
- `α = (1 / ρ) · (dρ / dT)` — температурний коефіцієнт опору;
- `ρ_0` — питомий опір сплаву при `20 °C`;
- `ρ_c ≈ 130–150 мкОм·см` — феноменологічна критична межа Муя;
- `A` — позитивна константа матеріалу (`A ≈ 10⁻⁶ (мкОм·см)⁻¹·К⁻¹`).

Аналіз кореляції Муя виявляє три режими провідності:
- При `ρ_0 < 100 мкОм·см`: ТКО є позитивним (`α > 0`), домінує класичне фононне розсіяння.
- При `ρ_0 → ρ_c ≈ 130–150 мкОм·см`: ТКО прямує до нуля (`α → 0`), фононне розсіяння повністю компенсується квантовими ефектами.
- При `ρ_0 > 150 мкОм·см`: ТКО стає від'ємним (`α < 0`), опір сплаву зменшується при нагріванні.

Фізичне виведення межі Муя ґрунтується на квантовому критерії **Іоффе — Регеля**. У класичній теорії провідності Као — Друде питомий опір пов'язаний із фермієвським хвильовим вектором `k_F` та середньою довжиною вільного пробігу електрона `ℓ`:

```
ρ_0 = (3π² / e²) · ℏ / (k_F² · ℓ)
```

При збільшенні концентрації домішок та структурного неупорядкування довжина вільного пробігу електрона `ℓ` зменшується. Коли питомий опір досягає межі Муя `ρ_c ≈ 130–150 мкОм·см`, довжина вільного пробігу коротшає до довжини електронної хвилі де Бройля `λ_F = 2π / k_F` та міжатомної відстані `a`:

```
k_F · ℓ ≈ 1
```

Це співвідношення називають **критерієм локалізації Іоффе — Регеля**.

При `k_F · ℓ ≈ 1` електрон втрачає можливість вільного поширення у вигляді квазікласичної хвилі Блоха. Імпульс електрона стає повністю невизначеним на довжині одного кристалічного осередку. За таких умов подальше збільшення інтенсивності фононних коливань при нагріванні вже не може збільшити опір, оскільки довжина вільного пробігу не може стати меншою за міжатомну відстань `a`.

Одночасно у сильно неупорядкованому середовищі виникають ефекти **квантової інтерференції** електронних хвиль, розсіяних на хаотичному потенціалі дефектів. Інтерференція хвиль, що проходять замкнені траєкторії у протилежних напрямках, збільшує ймовірність зворотного розсіяння — явище **слабкої локалізації**.

Внесок слабкої локалізації у питому провідність `Δσ_loc` задається квантовим виразом:

```
Δσ_loc(T) = (e² / (2π² · ℏ)) · (1 / L_φ(T))
```

де `L_φ(T)` — довжина збиття фази електронної хвилі при непружному розсіянні.

Оскільки з підвищенням температури частота непружних зіткнень з фононами зростає, довжина фазової когерентності зменшується за законом `L_φ(T) ∝ T⁻ᵖ/²` (де `p ≈ 1..3`). Зменшення довжини `L_φ` руйнує конструктивну інтерференцію слабкої локалізації, що підвищує провідність матеріалу:

```
dσ_loc / dT > 0   ⇒   dρ_loc / dT < 0
```

Таким чином, у високонеупорядкованих сплавах з `ρ_0 ≥ ρ_c` температурне зруйнування слабкої локалізації накладається на квантове приглушення `s-d` розсіяння Мотта, створюючи стабільну негативну похідну опору, яка тотожно врівноважує позитивний фононний ТКО.

## 3. Математична апроксимація параболічної залежності R(T) для манганіну

Для прецизійного манганіну підсумовування фононного розсіяння `ρ_ph(T) ∝ T` та квантового приглушення Мотта `ρ_sd(T) ∝ -T²` дає параболічну температурну залежність опору навколо кімнатної температури.

Рівняння описується поліномом второго степеня:

```
R(T) = R_20 · [1 + α_20 · (T - 20) + β · (T - 20)²]
```

де:
- `R_20` — опір при базовій температурі `20 °C`;
- `α_20` — лінійний ТКО при `20 °C` (`К⁻¹`);
- `β` — квадратичний температурний коефіцієнт (для манганіну `β ≈ -(3..5) · 10⁻⁷ К⁻²`).

У точці екстремуму (піку параболи) перша похідна опору за температурою дорівнює нулю:

```
dR / dT = R_20 · [α_20 + 2 · β · (T_peak - 20)] = 0
```

Звідси вершина параболи `T_peak` визначається співвідношенням:

```
T_peak = 20 - α_20 / (2 · β)
```

Технологічна мета термообробки та допування манганіну полягає у точній юстировці лінійного коефіцієнта `α_20` таким чином, щоб вершина параболи припадала точно на робочу температуру приладу `T_peak = 20 °C` або `25 °C`. При цьому `α_20 → 0`, і температурна залежність набирає симетричного вигляду:

```
R(T) = R_max · [1 - |β| · (T - T_peak)²]
```

В околі вершини параболи `T = T_peak ± 10 °C` відносна зміна опору обчислюється як:

```
ΔR / R_max = - |β| · (ΔT)² = - (4 · 10⁻⁷) · (10)² = -4 · 10⁻⁵ = -40 ppm
```

Середній ТКО у цьому діапазоні не перевищує:

```
α_avg = (1 / R) · (dR / dT) = - 2 · |β| · ΔT = - 2 · (4 · 10⁻⁷) · 10 = -8 · 10⁻⁶ К⁻¹ = -8 ppm/K
```

Що забезпечує високий клас точності прецизійних еталонів та вимірювальних систем.
