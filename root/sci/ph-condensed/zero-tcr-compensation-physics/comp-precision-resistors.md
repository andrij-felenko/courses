# 🔌 Конструктивні типи та термомеханіка прецизійних резисторів

Отримання нульового температурного коефіцієнта опору у лабораторному зразку сплаву — лише перша половина задачі створення прецизійного вимірювального компонента. Перетворення дріт з манганіну або фольги з карми на стабільний резистор вимагає вирішення термомеханічних проблем: компенсації різниці коефіцієнтів лінійного теплового розширення (КТР), зняття внутрішніх механічних напружень, приглушення паразитної індуктивності та мінімізації термоелектрорушійної сили (термо-РСУ).

Фізика вимірювального компонента визначається взаємодією між електричними, термічними та механічними полями. Навіть найчистіший манганін змінить свій опір при зміні температури, якщо він піддається нерівномірному механічному стисненню з боку каркаса або підкладки.

## 1. Дротяні прецизійні резистори та біфілярна намотка

Дротяні резистори є найстарішою, але досі однією з найстабільніших конструкцій прецизійних опорів. Для їх виготовлення використовують тонкий дріт з манганіну або карми діаметром від `0.02 мм` до `0.5 мм`, вкритий шарлоттенбурзьким шовком або емалевою ізоляцією.

### Механічні напруження та п'єзорезистивний зсув опору
Під час волочіння та намотування дроту на керамічний або пластмасовий каркас метал зазнає пластичної деформації. Зсуви у кристалічній ґратці створюють поля внутрішніх механічних напружень `σ_mech`. П'єзорезистивний ефект (зміна опору від механічного напруження) задається співвідношенням:

```
ΔR / R = K_piezo · σ_mech
```

де `K_piezo` — коефіцієнт тензочутливості сплаву (`K_piezo ≈ 0.5–2.0` для манганіну).

Якщо залишити намотаний дріт без термообробки, внутрішні напруження повільно релаксують протягом місяців і років, що викликає безперервний часовий дрейф опору. Для усунення цього ефекту намотані котушки піддають **термічному стабілізуючому відпалу** при температурах `140–200 °C` протягом 24–72 годин, після чого опір стабілізується з часовим дрейфом менше `1 ppm/рік`.

### Приглушення паразитної індуктивності та ємності
Звичайна спіральна намотка утворює соленоїд із значною власною індуктивністю `L = μ₀ · N² · S / l`, що унеможливлює використання резистора на змінному струмі та викликає фазові зсуви.

Для компенсації магнітного потоку застосовують спеціальні види намотки:
1. **Біфілярна намотка**: дріт складають удвоє перед намотуванням. Струм у двох паралельних жилках тече у протилежних напрямках, завдяки чому створені ними магнітні поля взаємно компенсуються, зменшуючи індуктивність у тисячі разів.
2. **Намотка за Аєртоном — Перрі (Ayrton-Perry)**: два зустрічних шари дроту намотують паралельно в протилежних напрямках на плаский ізоляційний каркас. Перетирання витків під кутом `90°` додатково знижує паразитну міжвиткову ємність.

## 2. Металофольгові резистори та технологія автокомпенсації КТР

У 1962 році Фелікс Зандман (Felix Zandman), засновник компанії *Vishay Intertechnology*, розробив революційну технологію **металофольгових резисторів** (Bulk Metal Foil), яка забезпечила рекордний ТКО менше `0.1 ppm/K`.

Конструкція фольгового резистора складається з холоднокатаної фольги сплаву Карма або Еваном товщиною всього `2–5 мкм`, приклеєної спеціальним епоксидним адгезивом до масивної підкладки з оксиду алюмінію (`Al₂O₃`) або кремнію (`Si`).

### Фізичний механізм автокомпенсації КТР
Стабільність опору фольгового резистора досягається шляхом точного балансу між власним ТКО вільної фольги та термомеханічним стисненням/розтягом від підкладки:

1. **Власний ТКО фольги** `α_bulk` є злегка позитивним (`+2..+5 ppm/K`).
2. **Коефіцієнт лінійного теплового розширення (КТР)** керамічної підкладки `α_sub ≈ 6..8 ppm/K` вибирається більшим за КТР металевої фольги `α_foil ≈ 11 ppm/K`.
3. При нагріванні підкладка розширюється повільніше, ніж намагалася б розширитися вільна металева фольга. Оскільки фольга жорстко приклеєна до підкладки, у металі виникають механічні напруження стиснення:

```
ε_mech(T) = (α_sub - α_foil) · ΔT < 0
```

4. Завдяки позитивній тензочутливості фольги `K_piezo > 0`, механічне стиснення викликає від'ємний п'єзорезистивний зсув опору:

```
(ΔR / R)_mech = K_piezo · ε_mech(T) = K_piezo · (α_sub - α_foil) · ΔT < 0
```

5. Сумарний температурний коефіцієнт розтрачується до нуля за рахунок точного підбору матеріалу підкладки:

```
α_total = α_bulk + K_piezo · (α_sub - α_foil) = 0
```

Завдяки цьому механізму металофольгові резистори серій Vishay VHH/Z-Foil виявляють абсолютну зміну опору менше `0.05 ppm/K` у діапазоні від `0 °C` до `60 °C`.

## 3. Вимірювальні 4-затискачні шунти (схема Кельвіна)

При вимірюванні великих струмів (від `10 А` до `5000 А`) опір шунта має малу величину — від `100 мкОм` до `10 мОм`. У цьому випадку опір підключених підвідних дротів та контактних переходів (які становлять `1–10 мОм`) перевищує опір самого шунта.

Для усунення похибки контактного опору шунти виготовляють строго за **4-провідною схемою Кельвіна**:

1. **Струмові затискачі (C1, C2)**: масивні мідні блоки великого перерізу, призначені для підведення основними силового струму `I_main`.
2. **Потенціальні виводи (P1, P2)**: тонкі вимірювальні затискачі, припаяні безпосередньо до меж пластини з манганіну.

Оскільки вольтметр, підключений до потенціальних виводів `P1–P2`, має високий вхідний опір (`> 10 МОм`), струм через вимірювальні дроти практично дорівнює нулю. Спад напруги вимірюється строго на активній ділянці манганінової пластини між точками паяння:

```
V_sense = I_main · R_manganin
```

### Термо-РСУ та ефект Зеєбека
У колі постійного струму градієнт температури між двома спаями мідь-манганін створює паразитно термоелектрорушійну силу (термо-РСУ) за рахунок ефекту Зеєбека:

```
V_thermo = S_Cu-Mn · (T_junction1 - T_junction2)
```

де `S_Cu-Mn` — коефіцієнт Зеєбека пари мідь-манганін.

Для манганіну `S_Cu-Mn ≈ 1 мкВ/К`, що є надзвичайно малим значенням. Натомість для константану паразитний диференціальний коефіцієнт Зеєбека проти міді сягає `S_Cu-Const ≈ -40 мкВ/К`. Різниця температур між спаями всього у `5 °C` створює на константановому шунті паразитну напругу `200 мкВ`, що викликає величезну похибку вимірювання струму. Саме тому **константан заборонено використовувати у прецизійних шунтах постійного струму**, виділяючи йому сферу термопар та кіл змінного струму.

## 4. Конструктивні виклики та методи герметизації

Окрім температурних та термоелектричних чинників, на довготривалу стабільність прецизійного резистора впливає навколишнє середовище. Вологість повітря викликає адсорбцію молекул води епоксидною смолою та лаковим покриттям. Молекулярне набухання органічних матеріалів створює додатковий механічний тиск на металеву фольгу або дріт, викликаючи деформаційний зсув опору на рівні `5–20 ppm`.

Для захисту від вологи прецизійні компоненти найвищого класу герметизують у металеві або керамічні корпуси з сухим азотом або силіконовим маслом. Герметична конструкція повністю ізолює активний елемент зі сплаву Карма або манганіну від впливу атмосфери, забезпечуючи рекордний часовий дрейф менше `0.1 ppm/рік`.
