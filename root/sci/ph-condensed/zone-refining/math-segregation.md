# 🧮 Математика сегрегації та профілі домішок

У цій вставці виведено диференціальні рівняння масопереносу домішок при зонній перекристалізації, проведено точний розрахунок однопрохідного та багатопрохідного профілів Пфанна та виведено рівняння Бертона — Прімма — Сліхтера для ефективного коефіцієнта сегрегації.

## Термодинамічний коефіцієнт сегрегації та діаграми стану

Під час кристалізації бінарного розплаву кремнію з домішкою співвідношення концентрацій домішки у твердій та рідкій фазах у стані термодинамічної рівноваги визначається рівноважним коефіцієнтом сегрегації `k_0`. За означенням:

```
k_0 = C_S / C_L
```

де `C_S` — атомна концентрація домішки у твердій фазі на межі кристалізації, а `C_L` — атомна концентрація домішки у розплаві.

З точки зору феноменологічної термодинаміки, рівновага між рідким розчином та твердим розчином домішки при температурі `T` вимагає рівності хімічних потенціалів домішки в обох фазах:

```
μ_L = μ_S
μ_L0 + R·T·ln(a_L) = μ_S0 + R·T·ln(a_S)
```

Для розведених розчинів (коли концентрація домішки `C << 1`), коефіцієнти активності прямують до одиниці `a_L ≈ γ_L · C_L`, `a_S ≈ γ_S · C_S`. Тоді рівноважний коефіцієнт сегрегації приймає вигляд експоненціальної залежності від зміни вільної енергії Гіббса `ΔG` при переході атома домішки з рідкої фази у кристалічну ґратку кремнію:

```
ln(k_0) = ln(C_S / C_L) = -ΔG / (R·T)
```

Зсув температури плавлення розплаву та нахил ліній ліквідусу і солідуса на термодинамічній фазовій діаграмі прямо пов'язані з значенням `k_0`. Якщо домішка знижує температуру плавлення матриці кремнію (типовий випадок для більшості домішок у кремнії: `P`, `As`, `Sb`, `Fe`, `Au`), лінія солідуса розташовується лівіше від лінії ліквідусу, і `k_0 < 1`. Якщо домішка підвищує температуру плавлення, `k_0 > 1`.

Фізико-хімічні причини відмінності `k_0` від одиниці обумовлені двома основними факторами:
1. **Енергетичний фактор (різниця хімічних зв'язків)**: Атом домішки може мати інший валентний стан та радіус, ніж атом кремнію. Впровадження домішки створює деформацію кристалічної ґратки кремнію, що збільшує вільну енергію твердої фази й зменшує розчинність домішки у твердому тілі.
2. **Розмірний фактор (розмірний ефект)**: Атомний радіус кремнію становить `0.117 нм`. Атоми з суттєво більшим радіусом (наприклад, сурма `Sb` — `0.136 нм`, золото `Au` — `0.144 нм`) зазнають сильного деформаційного відштовхування з вузлів ґратки, що призводить до вкрай малих значення `k_0 ~ 10^(-2) - 10^(-5)`. Навпаки, бор (`B`) має атомний радіус `0.088 нм`, що ближче до кремнію, завдяки чому його `k_0 = 0.8`.

Для кремнію характерні наступні значення рівноважного коефіцієнта сегрегації `k_0`:
- Бор (`B`): `k_0 = 0.8` (дуже важко видаляється зонною очисткою);
- Фосфор (`P`): `k_0 = 0.35`;
- Арсен (`As`): `k_0 = 0.30`;
- Сурма (`Sb`): `k_0 = 0.023`;
- Алюміній (`Al`): `k_0 = 0.002`;
- Золото (`Au`): `k_0 = 2 · 10^(-5)`;
- Залізо (`Fe`): `k_0 = 8 · 10^(-6)` (ефективно видаляється за один прохід).

## Виведення однопрохідного рівняння Пфанна

Розглянемо вихідний циліндричний зливок довжиною `L` із початковою однорідною концентрацією домішки `C_0`. Нехай вздовж зливка у напрямку вісі `x` рухається розплавлена зона постійної довжини `l`.

Розглянемо баланс маси домішки в розплавленій зоні при переміщенні її фронту на малу відстань `dx`.

Маса домішки, що входить у зону при розплавленні ділянки `dx` на передньому фронті:

```
dM_in = C_0 · A · dx
```

де `A` — площа поперечного перерізу зливка.

Маса домішки, що виходить із зони у кристалізований зливок на задньому фронті:

```
dM_out = C_S(x) · A · dx = k · C_L(x) · A · dx
```

Зміна маси домішки у розплавленій зоні `dM_zone` дорівнює різниці входу та виходу:

```
dM_zone = dM_in - dM_out
dM_zone = (C_0 - k · C_L(x)) · A · dx
```

З іншого боку, об'єм розплавленої зони є постійним і дорівнює `V_zone = A · l`. Отже, маса домішки у зоні пов'язана з її середньою концентрацією у розплаві `C_L` співвідношенням `M_zone = C_L · A · l`. Диференціюючи це співвідношення за `x`, маємо:

```
dM_zone = A · l · dC_L
```

Прирівнюючи два вирази для `dM_zone`, отримуємо диференціальне рівняння першого порядку:

```
A · l · dC_L = (C_0 - k · C_L) · A · dx
l · (dC_L / dx) = C_0 - k · C_L
```

Перепишемо рівняння відносно концентрації у кристалізованому твердому тілі `C_S(x) = k · C_L(x)`:

```
(l / k) · (dC_S / dx) + C_S = C_0
dC_S / dx + (k / l) · C_S = (k / l) · C_0
```

Це лінійне неоднорідне диференціальне рівняння першого порядку. Його інтегрувальний множник дорівнює `exp((k/l)·x)`.

Проінтегруємо рівняння з початковою умовою на початку зливка при `x = 0`. При запуску зони перший об'єм розплаву довжиною `l` утворюється з вихідного матеріалу з концентрацією `C_0`. Отже, початкова концентрація в рідкій зоні дорівнює `C_L(0) = C_0`, а перший закристалізований шар має концентрацію:

```
C_S(0) = k · C_0
```

Інтегрування рівняння дає точний розв'язок:

```
C_S(x) · exp((k/l)·x) = ∫ (k/l) · C_0 · exp((k/l)·x) dx + Const
C_S(x) · exp((k/l)·x) = C_0 · exp((k/l)·x) + Const
```

Використовуючи початкову умову `C_S(0) = k · C_0`:

```
k · C_0 = C_0 + Const
Const = (k - 1) · C_0 = -(1 - k) · C_0
```

Підставляючи `Const` назад і ділячи на `exp((k/l)·x)`, отримуємо класичну **формулу Пфанна для одного проходу**:

```
C_S(x) = C_0 · [ 1 - (1 - k) · exp(-k · x / l) ]
```

Ця формула описує розподіл домішки на основній ділянці зливка `0 ≤ x ≤ L - l`.

## Фінальна ділянка та закон направленої кристалізації Шеїла

Коли передній край розплавленої зони досягає кінця зливка (`x = L - l`), зона більше не може розплавляти новий матеріал. З цього моменту довжина розплавленої зони починає зменшуватися від `l` до нуля, а кристалізація відбувається за механізмом класичного направленого затвердіння.

Нехай `x'` — відстань від початку кінцевої зони (`x' = x - (L - l)`), а `V'` — залишковий об'єм розплаву `V' = A · (l - x')`.

Рівняння балансу домішки для кінцевої ділянки має вигляд:

```
-dM = C_S · A · dx' = k · C_L · A · dx'
```

Оскільки `M = C_L · A · (l - x')`, диференціал `dM = A · (l - x') · dC_L - C_L · A · dx'`. Прирівнюючи вирази:

```
A · (l - x') · dC_L - C_L · A · dx' = -k · C_L · A · dx'
(l - x') · dC_L = (1 - k) · C_L · dx'
dC_L / C_L = (1 - k) · dx' / (l - x')
```

Інтегруючи від `x' = 0` (де концентрація розплаву дорівнює `C_L^(end)`, отриманій наприкінці основного проходу) до `x'`:

```
ln(C_L / C_L^(end)) = -(1 - k) · ln(1 - x' / l) = (k - 1) · ln(1 - x' / l)
C_L(x') = C_L^(end) · (1 - x' / l)^(k - 1)
```

Помноживши на `k`, отримуємо **рівняння Шеїла для кінцевого «хвоста»**:

```
C_S(x) = C_S^(end) · (1 - (x - (L - l)) / l)^(k - 1)
```

Оскільки `k < 1`, показник степеня `k - 1` є від'ємним, тому при наближенні до кінця зливка `x → L` концентрація домішки теоретично прямує до нескінченності (практично — обмежена евтектичною концентрацією).

## Багатопрохідне очищення та диференціально-різницева модель

При `n`-му проході розплавлена зона рухається по матеріалу, який вже має неоднорідну концентрацію `C_S^(n-1)(x)`, сформовану попереднім `(n-1)`-м проходом.

Баланс маси для `n`-го проходу на довільній ділянці `x`:

```
l · (dC_S^(n)(x) / dx) + k · C_S^(n)(x) = k · C_S^(n-1)(x + l)
```

Це рекурентне диференціально-різницеве рівняння. Його виведення показує, що кожна послідовна ітерація згладжує та поглиблює експоненційний профіль очищення.

При розрахунку великої кількості проходів (`n → ∞`) концентраційний профіль прямує до межі — **граничного розподілу (Ultimate Distribution)** `C_∞(x)`. У цьому стані потік домішки, що виноситься зоною вперед завдяки сегрегації, точно врівноважується зворотним дифузійним потоком домішки у розплавленій зоні через вирівнювання концентрацій:

```
C_∞(x) = A · exp(B · x)
```

Підставляючи експоненційний профіль у рівняння балансу `l · dC_∞/dx = k · (C_∞(x+l) - C_∞(x))`:

```
l · A · B · exp(B·x) = k · A · [ exp(B·(x+l)) - exp(B·x) ]
l · B = k · [ exp(B · l) - 1 ]
k = (B · l) / [ exp(B · l) - 1 ]
```

Це трансцендентне рівняння дозволяє визначити константу `B` за відомими значеннями `k` та `l`. Константа `A` визначається з умови збереження повної маси домішки у зливку:

```
∫_0^L C_∞(x) dx = C_0 · L
A · [ exp(B·L) - 1 ] / B = C_0 · L
A = (C_0 · B · L) / [ exp(B · L) - 1 ]
```

## Зонне очищення зі змінною довжиною зони `l(x)`

У реальних бестигельних FZ-процесах довжина розплавленої зони не залишається ідеально константною: на початку зливка при заході на затравку формують витягнутий конус звуження (шийку Даша), де `l(x)` плавно зростає, а наприкінці зливка — звужують зонний переріз.

Диференціальне рівняння зонного очищення зі змінною довжиною зони `l(x)` приймає узагальнений вигляд:

```
dC_L / dx + (k / l(x) + (1 / l(x)) · (dl/dx)) · C_L = C_0(x + l(x)) / l(x)
```

Розв'язок цього рівняння для довільної функції `l(x)` обчислюється методом інтегрувального множника:

```
μ(x) = exp [ ∫ (k / l(x) + (1 / l(x)) · (dl/dx)) dx ] = l(x) · exp [ k · ∫ (dx / l(x)) ]
```

Тобто зміна довжини зони `dl/dx > 0` розмиває профіль очищення, зменшуючи ефективний градус сегрегації. Саме тому в контролерах печей FZ довжину зони `l` намагаються підтримувати константою з точністю до `± 0.5 мм` шляхом автоматичного вимірювання оптичного профілю розплавленого пояса цифровими камери системи САК.

## Вплив дифузії у твердій фазі (модель з урахуванням зворотного дифузійного потоку)

У базовому рівнянні Пфанна передбачається, що коефіцієнт дифузії домішки у твердій фазі кремнію дорівнює нулю (`D_S = 0`). Для більшості елементів заміщення це є гарним наближенням, оскільки `D_S ~ 10^(-11) - 10^(-13) см²/с` при температурі плавлення `1414 °C`, що на 7-9 порядків менше за дифузію у рідкій фазі `D_L ~ 10^(-4) см²/с`.

Однак для деяких швидкодифундуючих елементів впровадження (таких як мідь `Cu`, літій `Li` або водень `H`), де `D_S ~ 10^(-5) см²/с` навіть у твердій фазі поблизу точки плавлення, дифузія у закристалізованому монокристалі розмиває профіль сегрегації.

Враховуючи дифузію у твердому тілі зі швидкістю протягування зони `v`, диф-рівняння масопереносу у кристалі набуває вигляду:

```
D_S · (d²C_S / dx²) + v · (dC_S / dx) = 0
```

Модифікований коефіцієнт сегрегації з урахуванням твердотільної дифузії описується параметром Броди — Флемінгса:

```
k_mod = k_0 / [ 1 - (1 - k_0) · exp(-v · l / D_S) ]
```

Якщо швидкість зони `v` є низькою, а дифузія `D_S` великою, `k_mod → 1`, що сильно погіршує очистку від швидких металевих домішок. Тому для таких елементів швидкість переміщення зони вибирають так, щоб безрозмірний параметр `v · l / D_S >> 1`.

## Модель Бертона — Прімма — Сліхтера (BPS) для ефективного коефіцієнта `k_eff`

У реальному процесі кристалізації рідка зона не є ідеально перемішаною. Біля фронту кристалізації `z = 0` виникає непорушний гідродинамічний дифузійний шар товщиною `δ`, у якому перенос домішки здійснюється виключно дифузією, тоді як поза межами шару (`z > δ`) розплав інтенсивно перемішується конвекцією.

Стаціонарне рівняння дифузії та конвекції у приповерхневому шарі товщиною `δ` має вигляд:

```
D · (d²C / dz²) + v · (dC / dz) = 0
```

де `D` — коефіцієнт дифузії домішки у рідкому кремнії (`~ 10^(-4) см²/с`), `v` — швидкість переміщення фронту кристалізації, а `z` — координата, спрямована від фронту кристалізації у глибину розплаву.

Проінтегруємо це рівняння один раз за `z`:

```
D · (dC / dz) + v · C = Const
```

Межова умова на фронті кристалізації `z = 0`: потік домішки, що відкидається кристалом, має дорівнювати дифузійному потоку в рідину. Тобто `Const = v · C_S`.

```
D · (dC / dz) + v · C = v · C_S
D · (dC / dz) = -v · (C - C_S)
dC / (C - C_S) = -(v / D) · dz
```

Інтегруємо від `z = 0` (де концентрація розплаву дорівнює `C_L(0)`) до `z = δ` (де концентрація дорівнює концентрації в об'ємі розплаву `C_L`):

```
∫_(C_L(0))^(C_L) dC / (C - C_S) = -∫_0^δ (v / D) dz
ln [ (C_L - C_S) / (C_L(0) - C_S) ] = -v · δ / D
(C_L(0) - C_S) / (C_L - C_S) = exp(v · δ / D)
```

Згадуючи, що на самому фронті діє рівноважний коефіцієнт сегрегації `C_S = k_0 · C_L(0)` (тобто `C_L(0) = C_S / k_0`):

```
(C_S / k_0 - C_S) / (C_L - C_S) = exp(v · δ / D)
C_S · (1 / k_0 - 1) / (C_L - C_S) = exp(v · δ / D)
C_S · ((1 - k_0) / k_0) = (C_L - C_S) · exp(v · δ / D)
```

Розділимо обидві частини на `C_L` і позначимо ефективний коефіцієнт сегрегації як `k_eff = C_S / C_L`:

```
k_eff · ((1 - k_0) / k_0) = (1 - k_eff) · exp(v · δ / D)
k_eff · [ (1 - k_0) / k_0 + exp(v · δ / D) ] = exp(v · δ / D)
```

Помножимо чисельник і знаменник на `k_0` та розділимо на `exp(v · δ / D)`:

```
k_eff = k_0 / [ k_0 + (1 - k_0) · exp(-v · δ / D) ]
```

Це підсумкова **формула Бертона — Прімма — Сліхтера (BPS)**.

З гідродинамічної теорії Кохрана для кристала, що обертається з кутовою швидкістю `ω` в рідкому розплаві з кінематичною в'язкістю `ν`, товщина дифузійного шару `δ` обчислюється як:

```
δ ≈ 1.6 · D^(1/3) · ν^(1/6) · ω^(-1/2)
```

Ця формула пояснює, чому збільшення швидкості обертання зливка `ω` зменшує товщину шару `δ`, що наближає `k_eff` до рівноважного коефіцієнта `k_0` та кардинально підвищує ефективність очищення.

## Двовимірна радіальна сегрегація та вплив конвекції Марангоні

У бестигельному зонному розплаві виникає не лише осьовий, а й радіальний розподіл домішок `C_S(r, z)`. Внаслідок термокапілярної конвекції Марангоні розплав рухається від гарячого центра до холодніших периферійних країв рідкої зони.

Кількісно конвекція Марангоні описується безрозмірним числом Марангоні `Ma`:

```
Ma = - (dγ / dT) · (ΔT · l) / (μ · α)
```

де `dγ/dT` — температурний коефіцієнт поверхневого натягу (`~ -0.28 · 10^(-3) Н/(м·К)` для рідкого кремнію), `ΔT` — перепад температур між центром та краєм зони (`~ 30-50 K`), `μ` — динамічна в'язкість (`~ 0.88 · 10^(-3) Па·с`), а `α` — коефіцієнт температуропровідності.

Конвекція Марангоні призводить до того, що товщина дифузійного шару `δ(r)` стає неоднорідною по радіусу `r`: на периферії зливка через інтенсивний рух розплаву `δ(r)` є мінімальною, тоді як у центрі — більшою. Відповідно до формули BPS, це створює радіальну неоднорідність ефективного коефіцієнта сегрегації `k_eff(r)` та виклики радіального викривлення профілю чистоти. Протидія цьому ефекту досягається вибором частоти ВЧ-індуктора (`2-3 МГц`), електромагнітне поле якого створює зустрічні сили Лоренца, що стабілізують гідродинамічні потоки.

## Кінетичне захоплення домішок при високих швидкостях (модель Азіза)

При екстремально високих швидкостях переміщення зони (або у лазерному зонному переплаві, де `v ~ 1 - 10 м/с`) термодинамічне рівняння BPS поступається місцем безпосередньо кінетичній моделі Азіза — Каплана (Aziz solute trapping model).

На мікроскопічному рівні кристал росте шляхом просування атомних сходинок зі швидкістю `v`. Для того щоб домішка виштовхнулася у розплав, атом домішки повинен здійснити дифузійний стрибок від межі розділу назад у рідину за час `t_diff ≈ λ / v_D`, де `λ` — міжбудовальна відстань (`~ 0.3 нм`), а `v_D` — характеристична швидкість атома домішки у міжфазній межі.

Якщо швидкість кристалізації `v` перевищує швидкість міжфазної дифузії домішки `v_D` (`v >> v_D`), ростуча кристалічна ґратка захоплює атоми домішки механічно, перш ніж вони встигнуть перестрибнути у розплав. У цьому випадку ефективний коефіцієнт сегрегації описується безперервною функцією Азіза:

```
k(v) = [ k_0 + (v / v_D) ] / [ 1 + (v / v_D) ]
```

Аналіз моделі Азіза показує:
- При низьких швидкостях `v << v_D`: `k(v) → k_0` (контроль термодинамічною рівновагою).
- При високих швидкостях `v >> v_D`: `k(v) → 1.0` (повне кінетичне захоплення домішки без очищення).

Цей розрахунок доводить фундаментальну фізичну необхідність строгого обмеження максимальної швидкості протягування розплавленої зони у промислових FZ-реакторах величиною не більше 2–3 мм/хв.

## Тепловий баланс на фронті кристалізації (умова Стефана)

Окрім масопереносу домішки, процес зонного очищення строго обмежений рівнянням теплового балансу на фронтах плавлення та кристалізації. 

На фронті кристалізації `z = 0` відбувається виділення прихованої теплоти кристалізації `L_f` (для кремнію `L_f = 1.8 · 10^6 Дж/кг`). Для забезпечення стабільного руху фронту зі швидкістю `v` результуючий тепловий потік через межу розділу фаз повинен задовольняти **умову Стефана**:

```
K_S · (dT / dz)_S - K_L · (dT / dz)_L = ρ · L_f · v
```

де `K_S` та `K_L` — коефіцієнти теплопровідності твердого та рідкого кремнію відповідно, `(dT/dz)_S` — температурний градієнт у ростучому кристалі, а `(dT/dz)_L` — температурний градієнт у розплавленій зоні.

Якщо тепловий потік від ВЧ-індуктора перевищить відведення тепла через твердий шток, температурний градієнт `(dT/dz)_L` впаде, довжина розплавленої зони перевищить критичну межу капілярності `l_max ≈ 2.0 см`, і зона обвалиться під дією сили тяжіння. Навпаки, недостатнє нагрівання призведе до замерзання зони та провалу процесу. Це вимагає прецизійного автоматичного контролю ВЧ-потужності з точністю до 0.1%.
