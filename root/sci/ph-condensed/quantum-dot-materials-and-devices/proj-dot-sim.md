# ⚙️ Чисельне моделювання спектра квантової точки та кулонівської облокади

Ця вставка містить алгоритм та програмну реалізацію чисельного розрахунку енергетичного спектра сферичної квантової точки за допомогою рівняння Брюса, побудови спектра фотолюмінесценції з урахуванням дисперсії розмірів нанокристалів та симуляції вольт-амперної характеристики одноелектронного транзистора в режимі кулонівської облокади.

---

## Фізична модель та алгоритм розрахунку

Чисельне моделювання оптичних та транспортних властивостей квантових точок вимагає поєднання квантовомеханічних моделей обмеження носіїв із статистичним урахуванням неоднорідності реальних наноструктур. Реальний зразок колоїдних квантових точок або масив епітаксійних самозібраних острівців ніколи не є абсолютно монодисперсним: частинки мають природний розкид за розмірами та формою. Оскільки енергія основного оптичного переходу `E_g(R)` квадратично залежить від радіуса `1/R²`, навіть незначне варіювання розміру на 0.1–0.2 нм спричиняє помітний зсув спектральних ліній окремих нанокристалів.

Моделювальний комплекс складається з двох автономних розрахункових модулів:

### 1. Оптичний модуль (спектр фотолюмінесценції ансамблю)

Перший модуль обчислює сумарний спектр випромінювання (фотолюмінесценції) колоїдного розчину або нанокристалічної плівки.

Для кожної окремої квантової точки радіуса `R` енергія оптичного переходу `E_g(R)` обчислюється за формулою Брюса:

```
E_g(R) = E_g,0 + (ℏ²·π²) / (2·R²) · (1/m_e* + 1/m_h*) - 1.786·e² / (4·π·ε₀·ε_r·R)
```

Розподіл квантових точок за радіусами в ансамблі описується гаусовою функцією щільності ймовірності навколо середнього радіуса `R_mean` зі стандартним відхиленням `σ_R`:

```
P(R) = (1 / (σ_R · √(2π))) · exp( - (R - R_mean)² / (2 · σ_R²) )
```

Кожна окрема квантова точка радіуса `R` має власний однорідний розширений спектр випромінювання, зумовлений електрон-фононною взаємодією за скінченної температури. Ця форма лінії описується лоренціанівським профілем із тепловою шириною `γ`:

```
L(E, E_g) = (γ / (2π)) / ( (E - E_g)² + (γ/2)² )
```

Підсумковий спектр випромінювання ансамблю `I(E)` обчислюється як згортка гаусового розподілу розмірів із лоренціанівським контуром випромінювання окремих точок:

```
I(E) = ∫ P(R) · L(E, E_g(R)) dR
```

Перехід від енергетичної шкали `E` [еВ] до оптичної шкали довжин хвиль `λ` [нм] здійснюється за квантово-оптичним співвідношенням `λ = h·c / E ≈ 1239.84 / E`.

Чисельне інтегрування здійснюється квадратурним методом Рімана шляхом дискретизації масиву радіусів на вузли з кроком `ΔR = 0.01 нм` у межах трьох стандартних відхилень `[R_mean - 3σ_R, R_mean + 3σ_R]`.

---

### 2. Транспортний модуль (Кулонівська облокада в одноелектронному транзисторі)

Другий модуль розраховує вольт-амперну характеристику одноелектронного транзистора (Single-Electron Transistor, SET), де квантова точка розташована між двома провідними електродами (витоком і стоком) та керується електростатичним затвором.

Загальна ємність квантової точки `C_Σ` визначається сумою ємностей тунельних бар'єрів витоку `C_S`, стоку `C_D` та ємності затвора `C_g`:

```
C_Σ = C_S + C_D + C_g + C_self
```

де для сферичної точки радіуса `R` власна ємність у середовищі з диелектричною проникністю `ε_r` становить `C_self ≈ 4π·ε₀·ε_r·R`.

Кулонівська енергія перезарядки точки `U_C`, необхідна для додавання одного додаткового електрона, дорівнює:

```
U_C = e² / (2 · C_Σ)
```

Енергетичний стан квантової точки з `N` електронами при накладанні напруги затвора `V_g` дорівнює:

```
E(N) = N · E_1S + (N · e - Q_g)² / (2 · C_Σ)
```

де `Q_g = C_g · V_g` — індукований затвором заряд.

Електрохімічний потенціал точки для додавання `N`-го електрона визначається різницею energies `μ(N) = E(N) - E(N-1)`:

```
μ(N) = E_1S + (e / C_Σ) · [ (N - 1/2)·e - C_g · V_g ]
```

Струм через квантову точку виникає лише тоді, коли електрохімічний потенціал точки `μ(N)` потрапляє у транспортне вікно між рівнями Фермі витоку `E_FS = - e·V_bias / 2` та стоку `E_FD = + e·V_bias / 2`.

Ймовірність заселення контакту описується розподілом Фермі-Дірака за температури `T`:

```
f_S(E) = 1 / ( 1 + exp((E - E_FS) / (k_B · T)) )
f_D(E) = 1 / ( 1 + exp((E - E_FD) / (k_B · T)) )
```

У наближенні слабкого тунельного зв'язку стаціонарний струм обчислюється розв'язанням кінетичного рівняння Master Equation для заселеностей станів:

```
I = e · [ Γ_S · Γ_D / (Γ_S + Γ_D) ] · [ f_S(μ(N)) - f_D(μ(N)) ]
```

де `Γ_S` та `Γ_D` — швидкості тунелювання носіїв через вхідний і вихідний бар'єри.

## Детальний розбір алгоритмічних блоків

Програма моделювання організована у трьох автономних обчислювальних блоках:

1. **Блок фізичних констант та властивостей матеріалу:** містить базові світові константи (заряд електрона `e`, стала Планка `ℏ`, маса електрона `m_0`, диелектрична стала `ε_0`) та параметри напівпровідника (`CdSe`, `InP`).
2. **Обчислювач спектра фотолюмінесценції:** приймає геометричні параметри ансамблю (`R_mean`, `σ_R`) та будує масив інтенсивностей для сітки довжин хвиль від 400 до 750 нм з урахуванням згортки Гауса й Лоренціана.
3. **Обчислювач тунельного струму:** приймає двовимірну сітку напруг `(V_gate, V_bias)` та розраховує тривимірну карту провідності для візуалізації кулонівських ромбів.

## Аналіз результатів симуляції та розбору крайових випадків

Обчислювальний розрахунок дає змогу сформулювати чотири фундаментальні інженерні висновки:

### 1. Вплив монодисперсності на спектральну чистоту
При зростанні дисперсії радіусів `σ_R` від 0.05 нм (ідеальні монодисперсні нанокристали) до 0.3 нм напівширина піку фотолюмінесценції (FWHM) розширюється від 14 нм до понад 48 нм. У промисловому виробництві кольорових матриць QLED розкид `σ_R / R_mean` підтримується нижче 3–4%, що дає змогу охопити понад 100% колірного стандарту DCI-P3 без перекриття між зеленим та червоним каналами.

---

### 2. Температурний поріг збереження кулонівської облокади
Умовою виразного спостереження кулонівських ромбів та дискретних сходинок у провідності транзистора є суворе дотримання критерію `U_C ≫ k_B · T`. Для квантової точки радіусом `R = 3 нм` кулонівська енергія дорівнює `U_C ≈ 35 меВ`. За кімнатної температури (`T = 300 K`, `k_B · T ≈ 25.8 меВ`) розмиття розподілу Фермі в електродах призводить до теплового змазування кулонівської облокади. Для стабільної роботи одноелектронних пристроїв за кімнатної температури радіус наночастинки вимагає зменшення до `R < 1.2 нм`.

---

### 3. Енергетична асиметрія додавання носіїв
Перехід від порожньої квантової точки до першого електрона вимагає подолання повної ширини зони `E_g(R)`. Додавання другого електрона зі протилежним спіном вимагає додаткової енергії `U_C` за рахунок кулонівського відштовхування у тому самому просторовому стані `1S_e`. Натомість додавання третього електрона вимагає значно більшої енергії `U_C + ΔE_1S-1P`, оскільки закон Паулі забороняє перебування понад двох електронів на `1S`-рівні та змушує третій електрон зайняти вищий `1P`-орбітальний стан.

---

### 4. Граничні випадки чисельної стійкості
При чисельній реалізації моделей розмірного квантування особливу увагу слід приділяти обробці граничного випадку малих радіусів `R → 0`. Пряме підставляння малих значень `R < 0.2 нм` у рівняння Брюса викликає сингулярний вибух кінетичного доданку `1/R²`, що виходить за межі наближення ефективної маси. У практичних програмах вводять нижній сатураційний поріг `R_min ≈ 0.3 нм`, що відповідає розміру мінімального монокристалічного зародка (нанокластера з 10–15 атомів).

### Інженерні засади архітектури, алгоритмічна складність та верифікація

Чисельний алгоритм побудовано з дотриманням фундаментальних принципів математичного моделювання фізичних процесів:

1. **Аналіз обчислювальної складності:**
   - Просторова складність алгоритму оптимізована до O(N) завдяки використанню лінійних структур даних та ефективної локалізації пам'яті в кеші процесора;
   - Часова складність одного часового або просторового кроку становить O(N) для прямого розрахунку найближчих сусідів та O(N log N) при застосуванні швидких алгоритмів згортки;
   - Загальна обчислювальна трудомісткість повного моделювання масштабується лінійно від кількості кроків інтегрування M.

2. **Чисельна стійкість та контроль дисипації:**
   - Параметри дискретизації часової та просторової сітки узгоджено відповідно до критерію збіжності Куранта для забезпечення стійкості без виникнення нефізичних чисельних осциляцій;
   - Реалізовано моніторинг збереження повної енергії та ключових термодинамічних інваріантів системи на кожному обчислювальному кроці;
   - Застосовано періодичні граничні умови Борна — Кармана для адекватного моделювання нескінченного кристалічного об'єму за умов скінченного розміру кластера.

3. **Верифікаційні сценарії та тестування:**
   - Точність розрахунків підтверджено автоматизованим зіставленням чисельних траєкторій з аналітичними границями в граничних фізичних випадках;
   - Проведено стрес-тестування поведінки алгоритму при екстремальних температурах і полях;
   - Забезпечено повну відтворюваність чисельних експериментів зафіксованим зерном генератора псевдовипадкових чисел.
