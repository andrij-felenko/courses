# 🧮 Квантово-розмірне обмеження та модель Брюса

Ця вставка містить строге математичне виведення енергетичного спектра квазічастинок у тривимірно обмеженому напівпровіднику (сферичній квантовій точці) та розрахунок зсуву забороненої зони за допомогою наближення Брюса.

---

## Квантовомеханічна задача: частинка у сферичній потенціальній ямі

Для математичного опису поведінки носіїв заряду (електронів та дірок) у напівпровідниковій квантовій точці радіуса `R` використаємо наближення ефективної маси. Припустимо, що квантова точка являє собою ідеальну сферу, оточену нескінченно високим потенціальним бар'єром матриці:

```
V(r) = 0        при r ≤ R  (всередині квантової точки)
V(r) = +∞       при r > R  (поза квантовою точкою)
```

Стаціонарне рівняння Шредінгера для поодинокої квазічастинки з ефективною масою `m*` у сферичній системі координат `(r, θ, φ)` має вигляд:

```
- (ℏ² / 2m*) · ∇² Ψ(r, θ, φ) = E · Ψ(r, θ, φ)
```

Оператор Лапласа у сферичних координатах розкладається на радіальну та кутову частини:

```
∇² = (1/r²) · (∂/∂r)(r² · ∂/∂r) + (1 / (r² · sin θ)) · (∂/∂θ)(sin θ · ∂/∂θ) + (1 / (r² · sin² θ)) · ∂²/∂φ²
```

Завдяки сферичній симетрії потенціалу `V(r)` хвильова функція шукається у вигляді добутку радіальної функції `R_{n,l}(r)` та сферичної гармоніки `Y_lm(θ, φ)`:

```
Ψ_{n,l,m}(r, θ, φ) = R_{n,l}(r) · Y_lm(θ, φ)
```

Сферичні гармоніки є власними функціями оператора квадрата кутового моменту `L² Y_lm = ℏ² · l(l + 1) Y_lm`, де `l = 0, 1, 2, ...` — орбітальне квантове число, а `m = -l, ..., +l` — магнітне квантове число.

Після відокремлення кутових змінних для радіальної функції `R_{n,l}(r)` отримуємо звичайне диференціальне рівняння другого порядку:

```
- (ℏ² / 2m*) · [ (1/r²) · d/dr (r² · dR/dr) - (l(l + 1) / r²) · R(r) ] = E · R(r)
```

Здійснюючи заміну змінної `x = k · r`, де хвильове число `k` пов'язане з енергією частинки `E` співвідношенням:

```
k = √(2 · m* · E) / ℏ
```

переходимо до стандартного канонічного рівняння для сферичних функцій Бесселя:

```
x² · d²R/dx² + 2x · dR/dx + [ x² - l(l + 1) ] · R(x) = 0
```

Загальним розв'язком цього рівняння є лінійна комбінація сферичних функцій Бесселя `j_l(x)` та Неймана `n_l(x)`. Оскільки функція Неймана прямує до нескінченності в центрі `r = 0`, її коефіцієнт повинен дорівнювати нулю. Отже, фізично прийнятний розв'язок має вигляд:

```
R_{n,l}(r) = A_{n,l} · j_l(k · r)
```

де `A_{n,l}` — нормувальна константа, а `j_l(z)` — сферична функція Бесселя порядку `l`.

---

## Дискретний енергетичний спектр та нулі функцій Бесселя

Гранична умова нескінченно високих стінок вимагає повного звернення хвильової функції в нуль на межі сфери `r = R`:

```
R_{n,l}(R) = A_{n,l} · j_l(k · R) = 0   ⇒   j_l(k · R) = 0
```

Отже, дозволені значення хвильового вектора `k_{n,l}` визначаються нулями сферичних функцій Бесселя:

```
k_{n,l} = χ_{n,l} / R
```

де `χ_{n,l}` — `n`-й додатний нуль сферичної функції Бесселя `j_l(x)`.

Підставляючи вираз для `k_{n,l}` у формулу енергії, отримуємо точний дискретний спектр енергетичних рівнів поодинокої частинки в 0D квантовій точці:

```
E_{n,l} = (ℏ² · χ_{n,l}²) / (2 · m* · R²)
```

Розглянемо перші три найважливіші електронні орбіталі:

1. **`1S`-стан (`l = 0, n = 1`):**
   Сферична функція Бесселя нулевого порядку має вигляд `j_0(x) = sin(x) / x`. Перший нуль цієї функції дорівнює `χ_{1,0} = π ≈ 3.14159`.
   Енергія основного `1S`-стану дорівнює:
   ```
   E_1S = (ℏ² · π²) / (2 · m* · R²)
   ```

2. **`1P`-стан (`l = 1, n = 1`):**
   Сферична функція Бесселя першого порядку має вигляд `j_1(x) = sin(x)/x² - cos(x)/x`. Перший нуль цієї функції дорівнює `χ_{1,1} ≈ 4.49341`.
   Енергія `1P`-стану дорівнює:
   ```
   E_1P = (ℏ² · 4.4934²) / (2 · m* · R²) ≈ 2.042 · E_1S
   ```

3. **`1D`-стан (`l = 2, n = 1`):**
   Перший нуль сферичної функції Бесселя другого порядку `j_2(x)` дорівнює `χ_{1,2} ≈ 5.76346`.
   Енергія `1D`-стану дорівнює:
   ```
   E_1D = (ℏ² · 5.7635²) / (2 · m* · R²) ≈ 3.365 · E_1S
   ```

```
Енергетичний рівень   Орбітальне число l   Нуль Бесселя χ_{n,l}   Відносна енергія E/E_1S   Кратність виродження 2(2l+1)
1S                    0                    π ≈ 3.1416             1.000                    2 (спінова)
1P                    1                    4.4934                 2.042                    6 (орбітальна + спін)
1D                    2                    5.7635                 3.365                    10 (орбітальна + спін)
```

Це виведення доводить ключовий фізичний факт: **енергетичні інтервали між станами квантової точки зростають обернено пропорційно квадрату радіуса `1/R²`**.

## Режими квантового обмеження та екситонний радіус Бора

У напівпровідниковій квантовій точці одночасно виникають дві квазічастинки: електрон у зоні провідності з ефективною масою `m_e*` та дірка у валентній зоні з ефективною масою `m_h*`. Вони взаємодіють між собою за допомогою кулонівського притягання, утворюючи зв'язану пару — екситон.

Природним просторовим масштабом екситона є його **екситонний радіус Бора** `a_B`, який визначається зведеною масою екситона `μ` та диелектричною проникністю напівпровідника `ε_r`:

```
1/μ = 1/m_e* + 1/m_h*       [зведена маса екситона]

a_B = (4 · π · ε₀ · ε_r · ℏ²) / (μ · e²) = a_0 · ε_r · (m_0 / μ)
```

де `a_0 ≈ 0.052918 нм` — радіус Бора атома водню, a `m_0 = 9.109×10⁻³¹ кг` — маса вільного електрона.

Залежно від співвідношення між геометричним радіусом квантової точки `R` та екситонним радіусом `a_B` розрізняють три квантовомеханічні режими:

1. **Режим сильного обмеження (`R ≪ a_B`):**
   Кінетична енергія розмірного квантування як електрона, так і дірки значно перевищує енергію їхнього взаємного Кулонівського притягання. Електрон і дірка розглядаються як дві незалежні частинки, затиснуті в потенціальній ямі, а кулонівська взаємодія враховується як мала поправка за теорією збурень.
2. **Проміжний режим обмеження (`a_h < R < a_e`):**
   Оскільки ефективна маса електрона у багатьох напівпровідниках значно менша за масу дірки (`m_e* ≪ m_h*`), радіус Бора електрона `a_e` значно більший за радіус Бора дірки `a_h`. У цьому режимі електрон перебуває в режимі сильного розмірного квантування, а важча дірка рухається у потенціальному полі електрона.
3. **Режим слабкого обмеження (`R ≫ a_B`):**
   Екситон утворюється як цілісна квазічастинка всередині квантової точки, а розмірному квантуванню підпорядковується лише трансляційний рух центру мас екситона з сумарною масою `M = m_e* + m_h*`.

Більшість технологічно важливих колоїдних квантових точок (`CdSe`, `InP`, `PbS`) працюють у режимі сильного обмеження (`R < a_B`), де радіус частинки `R` становить 1.5–5 нм.

## Строге виведення рівняння Брюса (Brus Equation)

У 1984 році Луїс Брюс вивів фундаментальне рівняння для енергії найнижчого оптичного переходу `E_g(R)` у сферичній квантовій точці в режимі сильного обмеження, використавши першу теорію збурень.

Повний двохчастинковий гамільтоніан системи електрон-дірка у сферичній ямі радіуса `R` має вигляд:

```
H = H_e + H_h + V_coul(r_e, r_h) + V_pol(r_e, r_h)

H = - (ℏ² / 2m_e*)·∇_e² - (ℏ² / 2m_h*)·∇_h² - e² / (4π·ε₀·ε_r·|r_e - r_h|) + V_pol(r_e, r_h)
```

де `V_pol` — поляризаційний потенціал сольватації зарядів на межі двох середовищ із різними диелектричними проникностями (`ε_in` квантової точки та `ε_out` оточуючої матриці).

У режимі сильного обмеження незбурена хвильова функція основного стану системи дорівнює добутку одночастинкових `1S`-хвильових функцій електрона й дірки:

```
Ψ_0(r_e, r_h) = Ψ_1Se(r_e) · Ψ_1Sh(r_h)

Ψ_1Se(r_e) = (1 / √(2πR)) · [sin(π · r_e / R) / r_e]
```

Енергія основного стану обчислюється як діагональний матричний елемент гамільтоніана:

```
E_g(R) = E_g,0 + ⟨Ψ_0 | H_e + H_h | Ψ_0⟩ + ⟨Ψ_0 | V_coul | Ψ_0⟩ + ⟨Ψ_0 | V_pol | Ψ_0⟩
```

1. **Обчислення кінетичного внеску `ΔE_conf`:**
   ```
   ⟨Ψ_0 | H_e + H_h | Ψ_0⟩ = (ℏ²·π²) / (2·m_e*·R²) + (ℏ²·π²) / (2·m_h*·R²) = (ℏ²·π²) / (2·R²) · (1/m_e* + 1/m_h*)
   ```

2. **Обчислення Кулонівського інтеграла `ΔE_Coulomb`:**
   ```
   ⟨Ψ_0 | - e² / (4π·ε₀·ε_r·|r_e - r_h|) | Ψ_0⟩ = - (e² / (4π·ε₀·ε_r·R)) · ∬ |Ψ_0|² / |x_e - x_h| d³x_e d³x_h
   ```
   Чисельне інтегрування цього двочастинкового інтеграла дає точний коефіцієнт `1.786`:
   ```
   ΔE_Coulomb = - 1.786 · e² / (4 · π · ε₀ · ε_r · R)
   ```

3. **Обчислення поляризаційного доданку `ΔE_pol`:**
   Розрахунок поляризації диелектричної межі за методом зображень дає поправку:
   ```
   ΔE_pol = (e² / (4 · π · ε₀ · ε_r · R)) · ∑_{n=1}^∞ [ (n+1)(ε_in - ε_out) / (ε_in · (n·ε_out + (n+1)ε_in)) ] ≈ 0.248 · E_R*
   ```

Додаючи всі внески, отримуємо повне **рівняння Брюса**:

```
E_g(R) = E_g,0 + (ℏ²·π²) / (2·R²) · (1/m_e* + 1/m_h*) - 1.786 · e² / (4 · π · ε₀ · ε_r · R) + ΔE_pol
```

## Чисельний порівняльний розрахунок для різних напівпровідників

Проілюструємо фізику рівняння Брюса на прикладі трьох фундаментальних напівпровідникових матеріалів: `CdSe` (видимий діапазон), `InP` (екологічний безкадмієвий матеріал) та `PbS` (ближній інфрачервоний діапазон).

Фізичні параметри матеріалів:

| Матеріал | Об'ємна зона E_g,0 (еВ) | Маса електрона m_e* / m_0 | Маса дірки m_h* / m_0 | Диелектрична проникність ε_r | Радіус Бора екситона a_B (нм) |
|---|---|---|---|---|---|
| **CdSe** | 1.74 еВ | 0.13 | 0.45 | 9.3 | 4.88 нм |
| **InP** | 1.35 еВ | 0.077 | 0.60 | 12.4 | 9.55 нм |
| **PbS** | 0.41 еВ | 0.085 | 0.085 | 172.0 | 18.00 нм |

Спрощені числові формули для енергії фотона `E_g(R)` у залежності від радіуса `R` (в нм):

- **Для CdSe:** `E_g(R) = 1.74 + 3.73 / R² - 0.276 / R`  [еВ]
- **Для InP:**  `E_g(R) = 1.35 + 5.48 / R² - 0.207 / R`  [еВ]
- **Для PbS:**  `E_g(R) = 0.41 + 4.38 / R² - 0.015 / R`  [еВ]

Розрахунок спектральних параметрів для квантових точок різного радіуса:

```
Радіус точки R = 2.0 нм:
- CdSe: E_g = 1.74 + 0.932 - 0.138 = 2.534 еВ   ⇒  λ = 489 нм (Синій колір)
- InP:  E_g = 1.35 + 1.370 - 0.103 = 2.617 еВ   ⇒  λ = 474 нм (Синьо-фіолетовий колір)
- PbS:  E_g = 0.41 + 1.095 - 0.007 = 1.498 еВ   ⇒  λ = 828 нм (Ближній ІЧ)

Радіус точки R = 3.5 нм:
- CdSe: E_g = 1.74 + 0.304 - 0.079 = 1.965 еВ   ⇒  λ = 631 нм (Червоний колір)
- InP:  E_g = 1.35 + 0.447 - 0.059 = 1.738 еВ   ⇒  λ = 713 нм (Далекий червоний)
- PbS:  E_g = 0.41 + 0.357 - 0.004 = 0.763 еВ   ⇒  λ = 1625 нм (Телекомунікаційний ІЧ)
```

Ці чисельні розрахунки висвітлюють важливу закономірність: завдяки малій ефективній масі носіїв у `InP` кінетичне квантування виражене навіть сильніше, ніж у `CdSe`, що дозволяє охопити увесь видимий спектр світла без використання токсичного кадмію. Для вузькозонного `PbS` величезне значення диелектричної проникності `ε_r = 172` майже повністю пригнічує кулонівське притягання, роблячи зсув енергії суто кінетичним і відкриваючи можливість створювати фотодетектори для інфрачервоної оптоелектроніки.
