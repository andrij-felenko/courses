# 📋 Класифікація 20 п'єзоелектричних точкових груп та матриці п'єзомодулів

Ця довідкова вставка містить системний опис 32 кристалографічних точкових груп за їхньою п'єзоелектричною активністю, правила орієнтації кристалографічних осей за стандартом IEEE Standard on Piezoelectricity, явні матричні форми тензорів п'єзомодулів `d[iα]` для всіх 20 п'єзоелектричних класів, детальний прозний розбір кристалографічних особливостей кожної сингонії, співвідношення між різними типами п'єзоконстант (`d`, `e`, `g`, `h`) та розширений каталог фізичних параметрів технологічно важливих п'єзоматеріалів.

## Стандартні системи координат та ортогоналізація за стандартом IEEE 176-1987

Для макроскопічного тензорного опису фізичних властивостей анізотропних кристалів у кристаллофізиці застосовують праву ортогональну декартову систему координат `{X, Y, Z}` (або `{x1, x2, x3}`). Оскільки в багатьох сингоніях (триклінній, моноклінній, тригональній, гексагональній) природні кристалографічні осі `{a, b, c}` є неортогональними, перехід до прямокутної системи координат виконується за єдиними правилами міжнародного стандарту IEEE Standard on Piezoelectricity 176-1987:

1. **Головна вісь Z (`x3`):** Завжди вирівнюється вздовж кристалографічної осі `c` або вздовж вісі симетрії найвищого порядку (осі 3, 4 або 6 порядку). У полярних сегнетоелектриках вісь `Z` спрямовується вздовж вектора спонтанної поляризації або осі макроскопічної текстури поляризації.
2. **Перпендикулярна вісь X (`x1`):** Вирівнюється вздовж кристалографічної осі `a`. Якщо вісь `a` неперпендикулярна до `c`, то вісь `X` обирається у площині `(ab)` перпендикулярно до осі `Y`.
3. **Вісь Y (`x2`):** Доповнює систему осей до правої декартової трійки згідно з вектором векторного добутку `[X × Y = Z]`.

Усі матричні елементи тензорів п'єзомодулів `d[iα]`, пружних компонент `s[αβ]` та диелектричних проникностей `ε[ij]` у довідниках подаються виключно в цій фізичній декартовій системі координат.

## Систематика 32 кристалографічних точкових груп

Усі кристалічні речовини за критеріями точкової макросиметрії розподіляються по 32 точкових кристалографічних групах (класах симетрії), які об'єднуються в 7 кристалографічних сингоній (триклінну, моноклінну, ромбічну, тетрагональну, тригональну, гексагональну та кубічну).

Наявність чи відсутність у кристалічній ґратці центра просторової інверсії визначить можливість існування п'єзоелектричного ефекту:

```
32 кристалографічні точкові групи
 ├── 11 центросиметричних груп (п'єзоелектричний ефект ЗАБОРОНЕНИЙ: d[iα] = 0)
 └── 21 нецентросиметрична група
      ├── 1 група 432 (O) — нецентросиметрична, але d[iα] = 0 через обнулення симетрією куба
      └── 20 п'єзоелектричних точкових груп (d[iα] ≠ 0)
           ├── 10 полярних груп (ПІРОЕЛЕКТРИКИ та П'ЄЗОЕЛЕКТРИКИ): 1, 2, m, mm2, 3, 3m, 4, 4mm, 6, 6mm
           └── 10 неполярних груп (ЛИШЕ П'ЄЗОЕЛЕКТРИКИ): 222, 4-bar, 422, 4-bar 2m, 32, 6-bar, 622, 6-bar m2, 23, 4-bar 3m
```

### Полярні проти неполярних п'єзоелектричних класів

- **Полярні кристалографічні класи (10 груп: `1, 2, m, mm2, 3, 3m, 4, 4mm, 6, 6mm`):**
  Ці кристали володіють виділеним кристалографічним напрямком (полярною віссю), вздовж якого центри мас позитивних і негативних іонних зарядів розділені у просторі навіть за відсутності зовнішніх напружень. Вони мають спонтанну поляризацію `P₀ ≠ 0` і виявляють піроелектричні властивості (зміна `P₀` при нагріванні). Оскільки ці 10 класів позбавлені центра інверсії, вони **одночасно є п'єзоелектриками**. При прикладанні механічного напруження в них виникає додаткова п'єзоелектрична поляризація, яка додається до спонтанної.

- **Неполярні п'єзоелектричні класи (10 груп: `222, 4-bar, 422, 4-bar 2m, 32, 6-bar, 622, 6-bar m2, 23, 4-bar 3m`):**
  У недеформованому стані спонтанна поляризація дорівнює нулю (`P₀ = 0`), оскільки поворотні осі симетрії компенсують дипольні моменти атомних зв'язків. Кристали цих класів не є піроелектриками. Поляризація в них виникає **виключно при прикладанні зовнішнього механічного напруження** `σ[α]`, яке асиметрично викривляє кристалічну решітку й розділяє центри зарядів.

## Матриці п'єзомодулів `d[iα]` (3×6) для 20 п'єзоелектричних класів

Матриця `d[iα]` має 3 рядки (`i = 1, 2, 3` відповідають осям `X, Y, Z`) та 6 стовпчиків (`α = 1, 2, 3, 4, 5, 6` у нотації Фойгта: `1=11`, `2=22`, `3=33`, `4=23`, `5=13`, `6=12`).

Нижче наведено детальний огляд фізичних властивостей і тензорної структури для кожного п'єзоелектричного класу по сингоніях.

### 1. Триклінна сингонія

Кристали триклінної сингонії володіють найнижчою симетрією. Усі трійки кристалографічних осей і кутів є довільними.

#### Клас 1 (C1) — полярний
Відсутні будь-які елементи симетрії, окрім тотожного перетворення. Усі 18 компонент матриці є відмінними від нуля та незалежними між собою. Кристали цього класу виявляють п'єзоелектричний ефект у будь-якому напрямку деформації:

```
        ┌                                  ┐
        │  d11  d12  d13  d14  d15  d16  │
d[iα] = │  d21  d22  d23  d24  d25  d26  │   [18 незалежних коефіцієнтів]
        │  d31  d32  d33  d34  d35  d36  │
        └                                  ┘
```

---

### 2. Моноклінна сингонія

У моноклінній сингонії існує один виділений кристалографічний напрямок — вісь 2-го порядку або нормаль до площини дзеркального відображення `m`.

#### Клас 2 (C2) — полярний (стандартна установка з віссю 2 || Y)
Поворотна вісь 2-го порядку збігається з віссю `Y`. Операція повороту на кут 180° обнуляє 10 компонент і залишає 8 ненульових незалежних елементів матриці:

```
        ┌                                  ┐
        │    0    0    0  d14    0  d16  │
d[iα] = │  d21  d22  d23    0  d25    0  │   [8 незалежних коефіцієнтів]
        │    0    0    0  d34    0  d36  │
        └                                  ┘
```

Фізично це означає, що електричне поле вздовж полярної осі `Y` викликає лише нормальні деформації `ε1, ε2, ε3` та зсув `γ5`, тоді як поле в площині `XZ` викликає зсувні деформації `γ4` та `γ6`.

#### Клас m (Cs) — полярний (стандартна установка з площиною m ⊥ Y)
Площина дзеркального відображення перпендикулярна до осі `Y`. Дзеркальне відображення обнуляє 8 компонент і залишає 10 незалежних коефіцієнтів:

```
        ┌                                  ┐
        │  d11  d12  d13    0  d15    0  │
d[iα] = │    0    0    0  d24    0  d26  │   [10 незалежних коефіцієнтів]
        │  d31  d32  d33    0  d35    0  │
        └                                  ┘
```

---

### 3. Ромбічна (орторомбічна) сингонія

У ромбічній сингонії всі три координатні осі `X, Y, Z` вирівняні за елементами симетрії (осями 2-го порядку або нормалями до площин `m`).

#### Клас 222 (D2) — неполярний (приклади: сегнетова сіль у параелектричній фазі, стибійсульфід)
Присутні три взаємно перпендикулярні поворотні осі 2-го порядку. Усі нормальні п'єзомодулі суворо дорівнюють нулю (`d33 = d11 = d22 = 0`). Матриця містить лише 3 зсувні п'єзомодулі:

```
        ┌                                  ┐
        │    0    0    0  d14    0    0  │
d[iα] = │    0    0    0    0  d25    0  │   [3 незалежні коефіцієнти]
        │    0    0    0    0    0  d36  │
        └                                  ┘
```

Це означає, що стискання кристала вздовж осей `X, Y, Z` не створює поляризації. Поляризація виникає виключно при прикладанні зсувних напружень у площинах `YZ`, `XZ` та `XY`.

#### Клас mm2 (C2v) — полярний (приклади: PVDF полімер, ніобат барію-натрію)
Присутні дві взаємно перпендикулярні площини відображення `m` та полярна вісь 2-го порядку `2 || Z`. Матриця містить 5 ненульових коефіцієнтів:

```
        ┌                                  ┐
        │    0    0    0    0  d15    0  │
d[iα] = │    0    0    0  d24    0    0  │   [5 незалежних коефіцієнти]
        │  d31  d32  d33    0    0    0  │
        └                                  ┘
```

### 4. Тетрагональна сингонія

У тетрагональній сингонії головною віссю є вісь 4-го порядку або інверсійна вісь `4-bar`, яка завжди орієнтується вздовж осі `Z`.

#### Клас 4 (C4) — полярний
Одна вісь 4-го порядку `4 || Z`. Поворот на 90° пов'язує компоненти в площині `XY`, залишаючи 4 незалежні коефіцієнти:

```
        ┌                                  ┐
        │    0    0    0  d14  d15    0  │
d[iα] = │    0    0    0  d15 -d14    0  │   [4 незалежні коефіцієнти: d24=d15, d25=-d14, d32=d31]
        │  d31  d31  d33    0    0    0  │
        └                                  ┘
```

#### Клас 4-bar (S4) — неполярний
Одна інверсійно-поворотна вісь 4-го порядку `4-bar || Z`. Містить 4 незалежні коефіцієнти:

```
        ┌                                  ┐
        │    0    0    0  d14  d15    0  │
d[iα] = │    0    0    0 -d15  d14    0  │   [4 незалежні коефіцієнти: d24=-d15, d25=d14, d32=-d31]
        │  d31 -d31    0    0    0  d36  │
        └                                  ┘
```

#### Клас 422 (D4) — неполярний
Вісь 4-го порядку `4 || Z` та чотири перпендикулярні осі 2-го порядку. Містить лише 1 зсувний коефіцієнт:

```
        ┌                                  ┐
        │    0    0    0  d14    0    0  │
d[iα] = │    0    0    0    0 -d14    0  │   [1 незалежний коефіцієнт: d25 = -d14]
        │    0    0    0    0    0    0  │
        └                                  ┘
```

#### Клас 4mm (C4v) — полярний (типова симетрія тетрагонального BaTiO3 та ЦТС)
Вісь 4-го порядку `4 || Z` та чотири вертикальні площини відображення `m`. Наявність площин обнуляє зсувні модулі `d14`, залишаючи 3 незалежні коефіцієнти:

```
        ┌                                  ┐
        │    0    0    0    0  d15    0  │
d[iα] = │    0    0    0  d15    0    0  │   [3 незалежні коефіцієнти: d24 = d15, d32 = d31]
        │  d31  d31  d33    0    0    0  │
        └                                  ┘
```

#### Клас 4-bar 2m (D2d) — неполярний (кристали KDP — дигідрофосфат калію)
Інверсійна вісь 4-го порядку `4-bar || Z`, две осі 2-го порядку та дві площини `m`. Містить 2 незалежні коефіцієнти:

```
        ┌                                  ┐
        │    0    0    0  d14    0    0  │
d[iα] = │    0    0    0    0  d14    0  │   [2 незалежні коефіцієнти: d25 = d14, d36]
        │    0    0    0    0    0  d36  │
        └                                  ┘
```

### 5. Тригональна сингонія

У тригональній сингонії головною віссю є вісь 3-го порядку `3 || Z`.

#### Клас 3 (C3) — полярний
Одна вісь 3-го порядку `3 || Z`. Містить 6 незалежних коефіцієнтів:

```
        ┌                                            ┐
        │  d11  -d11     0    d14   d15  -2·d22  │
d[iα] = │ -d22   d22     0    d15  -d14  -2·d11  │   [6 незалежних коефіцієнтів]
        │  d31   d31   d33      0     0       0  │
        └                                            ┘
```

#### Клас 3m (C3v) — полярний (ніобат літію LiNbO3, танталат літію LiTaO3)
Вісь 3-го порядку `3 || Z` та три вертикальні площини відображення `m`. Площини обнуляють коефіцієнти `d11` та `d14`, залишаючи 4 незалежні параметри:

```
        ┌                                            ┐
        │    0     0     0      0   d15  -2·d22  │
d[iα] = │ -d22   d22     0    d15     0       0  │   [4 незалежні коефіцієнти]
        │  d31   d31   d33      0     0       0  │
        └                                            ┘
```

#### Клас 32 (D3) — неполярний (кварц α-SiO2)
Вісь 3-го порядку `3 || Z` та три горизонтальні осі 2-го порядку `2 || X`. Наявність осей 2-го порядку повністю обнуляє третій рядок матриці (`d31 = d32 = d33 = 0`), залишаючи лише 2 незалежні коефіцієнти:

```
        ┌                                            ┐
        │  d11  -d11     0    d14     0       0  │
d[iα] = │    0     0     0      0  -d14  -2·d11  │   [2 незалежні коефіцієнти: d11 та d14]
        │    0     0     0      0     0       0  │
        └                                            ┘
```

### 6. Гексагональна сингонія

У гексагональній сингонії головною віссю є вісь 6-го порядку або інверсійна вісь `6-bar`, спрямована вздовж осі `Z`.

#### Клас 6 (C6) — полярний
Одна вісь 6-го порядку `6 || Z`. Матрична форма ідентична класу 4 і містить 4 незалежні коефіцієнти:

```
        ┌                                  ┐
        │    0    0    0  d14  d15    0  │
d[iα] = │    0    0    0  d15 -d14    0  │   [4 незалежні коефіцієнти: d24=d15, d25=-d14, d32=d31]
        │  d31  d31  d33    0    0    0  │
        └                                  ┘
```

#### Клас 6-bar (C3h) — неполярний
Одна інверсійно-поворотна вісь 6-го порядку. Містить 2 незалежні коефіцієнти:

```
        ┌                                            ┐
        │  d11  -d11     0      0     0  -2·d22  │
d[iα] = │ -d22   d22     0      0     0  -2·d11  │   [2 незалежні коефіцієнти: d11 та d22]
        │    0     0     0      0     0       0  │
        └                                            ┘
```

#### Клас 622 (D6) — неполярний
Вісь 6-го порядку `6 || Z` та шість осей 2-го порядку в площині `XY`. Містить 1 зсувний коефіцієнт:

```
        ┌                                  ┐
        │    0    0    0  d14    0    0  │
d[iα] = │    0    0    0    0 -d14    0  │   [1 незалежний коефіцієнт: d25 = -d14]
        │    0    0    0    0    0    0  │
        └                                  ┘
```

#### Клас 6mm (C6v) — полярний (AlN, ZnO вюрцитна структура)
Вісь 6-го порядку `6 || Z` та шість вертикальних площин відображення `m`. Матриця містить 3 незалежні коефіцієнти:

```
        ┌                                  ┐
        │    0    0    0    0  d15    0  │
d[iα] = │    0    0    0  d15    0    0  │   [3 незалежні коефіцієнти: d24 = d15, d32 = d31]
        │  d31  d31  d33    0    0    0  │
        └                                  ┘
```

#### Клас 6-bar m2 (D3h) — неполярний
Інверсійно-поворотна вісь 6-го порядку, три осі 2-го порядку та площини `m`. Містить 1 коефіцієнт:

```
        ┌                                            ┐
        │    0     0     0      0     0  -2·d22  │
d[iα] = │ -d22   d22     0      0     0       0  │   [1 незалежний коефіцієнт: d22]
        │    0     0     0      0     0       0  │
        └                                            ┘
```

### 7. Кубічна сингонія

Кубічні кристали володіють високою симетрією. Усі три координатні осі `X, Y, Z` є еквівалентними.

#### Клас 23 (T) — неполярний
Три осі 2-го порядку та чотири осі 3-го порядку. Містить 1 зсувний коефіцієнт:

```
        ┌                                  ┐
        │    0    0    0  d14    0    0  │
d[iα] = │    0    0    0    0  d14    0  │   [1 незалежний коефіцієнт: d14 = d25 = d36]
        │    0    0    0    0    0  d14  │
        └                                  ┘
```

#### Клас 4-bar 3m (Td) — неполярний (сфалерит ZnS, GaAs, InP, GaP)
Три інверсійні осі 4-го порядку `4-bar`, чотири осі 3-го порядку та шість площин `m`. Матриця має 1 незалежний зсувний коефіцієнт:

```
        ┌                                  ┐

Матриця містить 3 незалежні коефіцієнти і за формою повністю збігається з кристалографічним класом `6mm`:

## Чотири види п'єзоелектричних констант та міжматричні перетворення

У кристаллофізичних та інженерних розрахунках застосовують чотири еквівалентні матричні форми зв'язку між електричними полями (`E`, `D`) та механічними величинами (`σ`, `ε`):

1. **Матриця п'єзомодулів `d[iα]` (поляризація від напруження):** `D[i] = d[iα] · σ[α]`, одиниці вимірювання — Кулон на Ньютон (C/N) або метр на Вольт (m/V).
2. **Матриця п'єзоелектричних напружень `e[iα]` (поляризація від деформації):** `D[i] = e[iα] · ε[α]`, одиниці вимірювання — Кулон на квадратний метр (C/m²).
3. **Матриця п'єзоелектричної напруженості `g[iα]` (поле від напруження):** `E[i] = -g[iα] · σ[α]`, одиниці вимірювання — Вольт-метр на Ньютон (V·m/N).
4. **Матриця жорсткісних п'єзоконстант `h[iα]` (поле від деформації):** `E[i] = -h[iα] · ε[α]`, одиниці вимірювання — Вольт на метр (V/m).

Взаємний перерахунок між цими чотирма матрицями здійснюється через тензори пружних модулів жорсткості `c[αβ]`, пружної піддатності `s[αβ]` та диелектричної проникності `ε[ij]`:

```
e[iα] = d[iβ] · c[βα]ᵀ                   [перерахунок d у e через пружну жорсткість]
g[iα] = d[jα] · β[ij]ᵀ                   [перерахунок d у g через диелектричну непроникність β = ε⁻¹]
h[iα] = e[jα] · β[ij]ˢ                   [перерахунок e у h через диелектричну непроникність]
d[iα] = e[iβ] · s[βα]ᵀ                   [зворотний перерахунок e у d через пружну піддатливість]
```

### Пояснення головних режимів і модальних коливань

- **Коефіцієнт `d33` (повздовжня мода):** Визначає поляризацію вздовж вісі `Z` під дією стискання вздовж осі `Z`. Використовується в балочних випромінювачах, барометричних датчиках та п'єзоінжекторах.
- **Коефіцієнт `d31` (поперечна мода):** Визначає поляризацію вздовж осі `Z` при стисканні кристала у плоскопаралельному напрямку `X`. Використовується в консольних п'єзоелектричних біморфах і згинальних актуаторах.
- **Коефіцієнт `d15` (зсувна мода):** Визначає поляризацію вздовж осі `X` при напруженні зсуву в площині `XZ`. Є наибольшим п'єзомодулем у кераміках PZT і застосовується у зсувних детекторах та крутильних резонаторах.
- **Коефіцієнт електромеханічного зв'язку `k33`:** Безрозмірна характеристика ефективності перетворення накопиченої пружної енергії в електричну:

```
k33 = d33 / √(s33ᵀ · ε33ˢ)               [формула електромеханічного зв'язку для 33-моди]
```

Значення `k33²` визначає частку енергії, яка перетворюється за один цикл деформації кристала.

## Рекомендації з вибору п'єзоелектричних матеріалів для інженерних застосувань

При проектуванні акустоелектронних та електромеханічного приладів вибір кристалічного класу та матеріалу визначається набором цільових вимог:

1. **Для високостабільних генераторів частоти й еталонів часу:** Обирають монокристалічний кварц (`α-SiO2`, клас `32`). Незважаючи на помірний п'єзомодуль, кварц володіє добротністю `Q > 10⁵` та температурно-компенсованими зрізами (`AT`, `SC`).
2. **Для високопотужних ультразвукових випромінювачів та п'єзоактуаторів:** Обирають тверді сегнетокераміки ЦТС (PZT-4, PZT-8, клас `C_∞v`). Вони забезпечують високу механічну міцність, малі диелектричні втрати при великих електричних полях та високі значення `d33 > 250 pC/N`.
3. **Для надчутливих позиціонерів та тунельних мікроскопів:** Застосовують м'які сегнетокераміки (PZT-5H), які володіють максимальним п'єзомодулем `d33 > 590 pC/N` за рахунок інтенсивного руху 90° доменних стінок.
4. **Для високочастотних СВЧ-фільтрів смартфонів (FBAR/SAW):** Застосовують орієнтовані тонкі плівки нітриду алюмінію (`AlN`, клас `6mm`). `AlN` володіє високою швидкістю поширення звукових хвиль (`v ≈ 11000 m/s`), низьким згасанням на частотах 1–6 ГГц та повною сумісністю з кремнієвою технологією КМОН (CMOS).
5. **Для гідрофонів та медичних УЗД-датчиків:** Використовують полімер PVDF та п'єзокомпозити (структури 1-3 з стовпчиків кераміки ЦТС у полімерній матриці). Це дає узгодження акустичного імпедансу з водою та тканинами людини, усуваючи паразитні відбиття звуку на межі розділу.

## Вплив температури та фазові переходи

При зміні температури значення п'єзоелектричних модулів `d[iα]` змінюються за законами анізотропного теплового розширення та м'якшення ґраткових мод. У сегнетоелектричних кристалах та кераміках (BaTiO3, ЦТС, LiNbO3) при наближенні до температури Кюрі `Tc` диелектрична проникність `ε33` різко зростає за законом Кюрі-Вейсса (`ε ~ C / (T - Tc)`), що викликає відповідний піковий зрост п'єзомодуля `d33`. 

Однак при перевищенні температури Кюрі `T > Tc` кристал зазнає структурного переходу у високосиметричну центросиметричну параелектричну фазу (наприклад, кубічну фазу перовськіту `m3m`), у якій спонтанна поляризація зникає (`P₀ = 0`), а всі п'єзоелектричні модулі тотожно обнуляються. Для практичної експлуатації п'єзоелементів верхня робоча температура обмежується значенням `T_max ≈ (0.5...0.7) · Tc`, щоб запобігти тепловій деполяризації матеріалу.

Зі зниженням температури до кріогенних значень (рідкий гелій `T = 4.2 K`) доменна рухливість виморожується, і екстрінсічний внесок зникає. Залишається лише внутрішній іонний п'єзомодуль, який для PZT-5H зменшується приблизно в 4–5 разів.
