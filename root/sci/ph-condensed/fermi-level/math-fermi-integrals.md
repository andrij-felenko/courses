# 🧮 Математичний апарат: розклад Зоммерфельда та температурний зсув хімічного потенціалу

Розрахунок макроскопічних термодинамічних, електричних та магнітних характеристик електронного газу в твердих тілах вимагає підсумовування або інтегрування відповідних квантовомеханічних величин по всій сукупності доступних квантових станів. Роль вагового коефіцієнта при цьому відіграє функція розподілу Фермі — Дірака. Через наявність експоненціального додатка у знаменнику функції розподілу такі інтеграли не виражаються в елементарних функціях і вимагають застосування спеціальних функцій — інтегралів Фермі — Дірака та асимптотичного розкладу Зоммерфельда.

Загальна концентрація електронів `n` у дозволеній енергетичній зоні з об'ємною густиною станів `g(E)` обчислюється за допомогою інтеграла:

```
n = ∫₀^∞ g(E) · f(E) dE
```

де `f(E) = 1 / (exp((E - μ) / (k_B · T)) + 1)` — функція розподілу Фермі — Дірака, а `μ` — хімічний потенціал носіїв заряду.

---

## 1. Густина квантових станів та визначення інтегралів Фермі — Дірака

Щоб обчислити інтеграл концентрації, необхідно спочатку вивести математичний вираз для густини квантових станів `g(E)` залежно від розмірності системи.

У тривимірному кристалі об'ємом `V = L_x · L_y · L_z` з періодичними граничними умовами Борна — фон Кармана дозволені значення волнового вектора `k` утворюють регулярну ґратку в `k`-просторі з об'ємом комірки `ΔV_k = (2π / L_x) · (2π / L_y) · (2π / L_z) = (2π)³ / V`.

Оскільки у кожному просторовому квантовому стані за принципом Паулі може перебувати два електрони з протилежними проекціями спіну (`s = 1/2`), кількість квантових станів у сферичному шарі радіуса `k` та товщини `dk` дорівнює:

```
dN_k = 2 · (4 · π · k² dk) / ((2 · π)³ / V) = (V / π²) · k² dk
```

Для параболічного закону дисперсії вільних електронів або квазічастинок з ефективною масою `m*` зв'язок між кінетичною енергією `E` та волновим вектором `k` має вигляд:

```
E = (ℏ² · k²) / (2 · m*)
```

Виражаючи `k` та `dk` через енергію `E`:

```
k = ((2 · m* · E) / ℏ²)¹ᐟ²
dk = (1 / 2) · ((2 · m*) / ℏ²)¹ᐟ² · E⁻¹ᐟ² dE
```

Підставляючи ці вирази у диференціал `dN_k` і ділячи на об'єм `V`, отримуємо тривимірну об'ємну густину станів `g(E) = (1/V) · (dN_k / dE)`:

```
g(E) = (1 / (2 · π²)) · ((2 · m*) / ℏ²)³ᐟ² · √E
```

Для порівняння, у двовимірному електронному газі (2DEG) густина станів не залежить від енергії і є константою `g_2D(E) = m* / (π · ℏ²)`, а в одновимірному квантовому дроті (1D) спадає за законом `g_1D(E) ∝ 1 / √E`.

Для скінченної температури `T > 0` зручно перейти до безрозмірних змінних: безрозмірної кінетичної енергії `x = (E - E_c) / (k_B · T)` та безрозмірного хімічного потенціалу `η = (μ - E_c) / (k_B · T)`.

Безрозмірний **інтеграл Фермі — Дірака порядку `j`** визначається як:

```
F_j(η) = (1 / Γ(j + 1)) · ∫₀^∞ (x^j / (exp(x - η) + 1)) dx
```

де `Γ(z)` — гамма-функція Ейлера, яка для напівцілих аргументів має значення `Γ(1/2) = √π`, `Γ(3/2) = √π / 2` та `Γ(5/2) = (3 · √π) / 4`.

Порядок інтеграла `j` безпосередньо диктується енергетичною залежністю густини станів `g(E) ∝ E^j`:
* `j = 1/2` відповідає тривимірним об'ємним кристалам (`g_3D ∝ √E`), де концентрація електронів у зоні провідності описується формулою `n = N_c · F₁ᐟ₂(η_c)`;
* `j = 0` відповідає двовимірним квантовим ямам (`g_2D = const`), де інтеграл обчислюється аналітично в елементарних функціях;
* `j = -1/2` виникає в одновимірних квантових провідниках (`g_1D ∝ E⁻¹ᐟ²`), а також визначає похідну концентрації за хімічним потенціалом у 3D кристалах;
* `j = 3/2` використовується для розрахунку повної кінетичної енергії та тиску електронного газу.

### Непараболічність зон (модель Кейна) та узагальнені інтеграли Фермі

У вузькозонних напівпровідниках (InSb, InAs, твердих розчинах кадмій-ртуть-телур Cd_x Hg_{1-x} Te) та при високих рівнях збудження параболічний закон дисперсії `E ∝ k²` порушується через сильну квантовомеханічну взаємодію між зоною провідності та валентною зоною. Двозонна модель Кейна пов'язує хвильовий вектор та енергію співвідношенням:

```
E · (1 + α · E) = (ℏ² · k²) / (2 · m_0*)
```

де `α ≈ 1 / E_g` — коефіцієнт непараболічності, а `m_0*` — ефективна маса електрона на самому дні зони провідності.

Диференціюючи це рівняння, отримуємо модифіковану густину квантових станів для непараболічної зони:

```
g_{NP}(E) = (1 / (2 · π²)) · ((2 · m_0*) / ℏ²)³ᐟ² · √E · (1 + α · E)¹ᐟ² · (1 + 2 · α · E)
```

Концентрація носіїв та кінетичні коефіцієнти в таких матеріалах виражаються через двопараметричні **узагальнені інтеграли Фермі — Дірака Завадського — Колодзеяка `^n F_{k,l}(η, β)`**:

```
^n F_{k,l}(η, β) = ∫₀^∞ (- df / dx) · x^k · (x + β · x²)^l · (1 + 2 · β · x)^n dx
```

де `β = α · k_B · T` — безрозмірний параметр непараболічності. При `β → 0` непараболічні інтеграли плавно перетворюються на класичні одновимірні інтеграли `F_j(η)`.

## 2. Диференціальні властивості та фундаментальна рекурентність

Інтеграли Фермі — Дірака мають властивість пониження порядку при диференціюванні за безрозмірним хімічним потенціалом `η`.

```
dF_j(η) / dη = F_{j-1}(η)      [для будь-якого j > 0]
```

### Математичне доведення рекурентного співвідношення

Продиференціюємо визначення інтеграла `F_j(η)` за параметром `η` під знаком інтеграла:

```
dF_j(η) / dη = (1 / Γ(j + 1)) · ∫₀^∞ x^j · (∂ / ∂η) [1 / (exp(x - η) + 1)] dx
```

Обчислимо частинну похідну підінтегрального виразу:

```
(∂ / ∂η) [1 / (exp(x - η) + 1)]
= exp(x - η) / (exp(x - η) + 1)²
= - (∂ / ∂x) [1 / (exp(x - η) + 1)]
```

Підставляючи цей вираз назад в інтеграл, перетворюємо похідну за хімічним потенціалом на просторову похідну за енергетичною змінною:

```
dF_j(η) / dη = - (1 / Γ(j + 1)) · ∫₀^∞ x^j · (d / dx) [1 / (exp(x - η) + 1)] dx
```

Застосуємо формулу інтегрування частинами, поклавши `u = x^j` та `dv = (d/dx)[1 / (exp(x - η) + 1)] dx`:

```
dF_j(η) / dη
= - (1 / Γ(j + 1)) · [x^j / (exp(x - η) + 1)]₀^∞ + (1 / Γ(j + 1)) · ∫₀^∞ (d(x^j) / dx) · (1 / (exp(x - η) + 1)) dx
```

Оцінимо позаінтегральний член:
* При `x → ∞` знаменник `exp(x - η)` зростає експоненціально швидше за будь-який степінь `x^j`, тому границя на нескінченності строго дорівнює нулю.
* При `x = 0` для будь-якого `j > 0` вираз `0^j = 0`.
* Отже, позаінтегральний член `[x^j / (exp(x - η) + 1)]₀^∞ ≡ 0`.

Обчислюючи похідну `d(x^j)/dx = j · x^{j-1}` та використовуючи фундаментальну властивість гамма-функції `Γ(j + 1) = j · Γ(j)`:

```
dF_j(η) / dη
= (j / Γ(j + 1)) · ∫₀^∞ (x^{j-1} / (exp(x - η) + 1)) dx           [винесення множника j]
= (j / (j · Γ(j))) · ∫₀^∞ (x^{j-1} / (exp(x - η) + 1)) dx         [підстановка Γ(j+1) = j·Γ(j)]
= (1 / Γ(j)) · ∫₀^∞ (x^{j-1} / (exp(x - η) + 1)) dx               [скорочення j]
= F_{j-1}(η)                                                      [за визначенням інтеграла Фермі порядку j-1]
```

### Фізичне значення рекурентності: термодинамічна густина станів та квантова ємність

Для тривимірного напівпровідника концентрація електронів у зоні провідності дорівнює `n = N_c · F₁ᐟ₂(η_c)`. Диференціюючи концентрацію за рівнем Фермі `E_F`:

```
dn / dE_F = N_c · (dF₁ᐟ₂(η_c) / dη_c) · (dη_c / dE_F)
          = (N_c / (k_B · T)) · F₋₁ᐟ₂(η_c)
```

Величина `dn / dE_F` визначає термодинамічну густину станів на рівні Фермі та задає **квантову ємність** каналу польового транзистора або квантової ями на одиницю площі чи об'єму:

```
C_Q = q² · (dn / dE_F) = (q² · N_c / (k_B · T)) · F₋₁ᐟ₂(η_c)
```

де `q` — елементарний електричний заряд.

У невиродженому режимі (`η_c << -1`) виконується асимптотика `F₋₁ᐟ₂(η_c) ≈ exp(η_c) = n / N_c`, що дає класичну больцманівську похідну `dn / dE_F = n / (k_B · T)`.

У сильновиродженому металі або виродженому напівпровіднику (`η_c >> 1`) інтеграл `F₋₁ᐟ₂(η_c) ≈ (2 / √π) · √η_c`, що після підстановки `N_c` дає строгу рівність `dn / dE_F = g(E_F)` — квантова ємність безпосередньо вимірює об'ємну густину квантових станів на поверхні Фермі.

## 3. Аналітичні асимптотики в граничних режимах

Залежно від величини безрозмірного хімічного потенціалу `η` поведінка інтегралів Фермі — Дірака кардинально змінюється.

### А. Невироджена больцманівська границя (η << -1)

Якщо рівень Фермі розташований у забороненій зоні на відстані щонайменше `2–3 · k_B · T` нижче від дна зони провідності (`η ≤ -2`), то для всіх енергій `x ≥ 0` величина `exp(x - η) ≥ exp(2) ≈ 7.4 >> 1`.

Розкладемо підінтегральний дріб у збіжний степеневий ряд за малим параметром `exp(η - x) < 1`:

```
1 / (exp(x - η) + 1)
= exp(η - x) / (1 + exp(η - x))                       [множення чисельника і знаменника на exp(η - x)]
= ∑_{m=1}^∞ (-1)^{m-1} · exp(m · (η - x))             [розклад у геометричний ряд за степенями exp(η - x)]
= exp(η) · exp(-x) - exp(2η) · exp(-2x) + ...         [почленний запис перших доданків ряду]
```

Підставимо цей знакозмінний ряд у визначення інтеграла Фермі `F_j(η)` і виконаємо почленне інтегрування:

```
F_j(η)
= (1 / Γ(j + 1)) · ∑_{m=1}^∞ (-1)^{m-1} · exp(m · η) · ∫₀^∞ x^j · exp(-m · x) dx
```

Зробимо заміну змінної `t = m · x`, `dx = dt / m`:

```
∫₀^∞ x^j · exp(-m · x) dx = (1 / m^{j+1}) · ∫₀^∞ t^j · exp(-t) dt = Γ(j + 1) / m^{j+1}
```

Підставляючи це значення назад у суму, отримуємо загальний розклад інтеграла Фермі — Дірака для невироджених систем:

```
F_j(η) = ∑_{m=1}^∞ (-1)^{m-1} · (exp(m · η) / m^{j+1})
       = exp(η) - (exp(2η) / 2^{j+1}) + (exp(3η) / 3^{j+1}) - (exp(4η) / 4^{j+1}) + ...
```

Для інтеграла напівцілого порядку `j = 1/2`:

```
F₁ᐟ₂(η) = exp(η) - (exp(2η) / 2³ᐟ²) + (exp(3η) / 3³ᐟ²) - (exp(4η) / 4³ᐟ²) + ...
        ≈ exp(η) - (exp(2η) / (2 · √2)) + (exp(3η) / (3 · √3)) - ...
```

Головний член розкладу `F_j(η) ≈ exp(η)` відповідає класичній статистиці Максвелла — Больцмана. Другий доданок `-(exp(2η) / 2^{j+1})` являє собою першу квантову поправку Паулі, яка зменшує ефективну заселеність станів через взаємне виштовхування ферміонів.

Відносна похибка застосування класичної формули Больцмана замість точного інтеграла `F₁ᐟ₂(η)` становить:

```
δ = |F₁ᐟ₂(η) - exp(η)| / F₁ᐟ₂(η) ≈ exp(η) / (2 · √2) ≈ 0.3535 · exp(η)
```

При `η = -2` похибка становить близько `4.8%`, при `η = -1` зростає до `13.0%`, а при `η = 0` (рівень Фермі точно на дні зони) похибка класичного наближення сягає `35.4%`, що робить статистику Больцмана повністю непридатною для точних інженерних розрахунків.

Перемножуючи больцманівські вирази для концентрації електронів `n = N_c · exp(-(E_c - E_F)/(k_B · T))` та дірок `p = N_v · exp(-(E_F - E_v)/(k_B · T))`, отримуємо **закон діючих мас**:

```
n · p = N_c · N_v · exp(- (E_c - E_v) / (k_B · T)) = N_c · N_v · exp(- E_g / (k_B · T)) = n_i²
```

де `n_i` — власна концентрація носіїв заряду в напівпровіднику.

### Б. Двовимірний квантовий газ (j = 0): точний замкнений розв'язок

У двовимірних системах (квантові ями, інверсійні канали MOSFET, гетероструктури AlGaAs/GaAs) інтеграл концентрації має нульовий порядок `j = 0`, оскільки `g_2D(E) = m* / (π · ℏ²) = const`.

Оскільки `Γ(1) = 1`, інтеграл Фермі набуває вигляду:

```
F₀(η) = ∫₀^∞ (1 / (exp(x - η) + 1)) dx
```

Зробимо заміну змінної `u = exp(x - η) + 1`, звідки `du = exp(x - η) dx = (u - 1) dx`, тобто `dx = du / (u - 1)`:

```
F₀(η) = ∫_{exp(-η)+1}^∞ (1 / (u · (u - 1))) du
      = ∫_{exp(-η)+1}^∞ [(1 / (u - 1)) - (1 / u)] du                      [розклад на елементарні дроби]
      = [ln(u - 1) - ln(u)]_{exp(-η)+1}^∞                                 [інтегрування логарифмів]
      = [ln((u - 1) / u)]_{exp(-η)+1}^∞                                   [об'єднання логарифмів]
      = ln(1) - ln(exp(-η) / (exp(-η) + 1))                               [підстановка меж]
      = - ln(1 / (exp(η) + 1))                                            [множення чисельника і знаменника на exp(η)]
      = ln(1 + exp(η))                                                    [інверсія аргументу логарифма]
```

Таким чином, для 2D систем інтеграл Фермі береться строго аналітично в елементарних функціях:

```
F₀(η) = ln(1 + exp(η))
```

Двовимірна концентрація електронів на одиницю площі для однієї підзони розмірного квантування з енергією дна `E_1` дорівнює:

```
n_2D = (m* · k_B · T / (π · ℏ²)) · ln(1 + exp((E_F - E_1) / (k_B · T))) = N_{c,2D} · ln(1 + exp(η_1))
```

де `N_{c,2D} = (m* · k_B · T) / (π · ℏ²)` — двовимірна ефективна густина станів.

Цей вираз можна точно розв'язати відносно рівня Фермі `E_F` без будь-яких наближень чи чисельних ітерацій:

```
1 + exp((E_F - E_1) / (k_B · T)) = exp(n_2D / N_{c,2D})
exp((E_F - E_1) / (k_B · T)) = exp(n_2D / N_{c,2D}) - 1
E_F = E_1 + k_B · T · ln(exp(n_2D / N_{c,2D}) - 1)
```

Це співвідношення є базовим для розрахунку зонних діаграм транзисторів із високою рухливістю електронів (HEMT).

### Квантовий віріальний розклад та тиск ідеального фермі-газу

Взаємна квантова заборона Паулі проявляється у макроскопічному рівнянні стану ідеального газу ферміонів навіть за повної відсутності будь-яких сил міжатомної взаємодії.

Використовуючи термодинамічне співвідношення для великого термодинамічного потенціалу `Ω = - P · V = - (2/3) · U`:

```
P = (2 / 3) · (U / V) = (2 / 3) · (k_B · T) · N_c · F₃ᐟ₂(η)
```

Розкладаючи інтеграл `F₃ᐟ₂(η) = exp(η) - (exp(2η) / 2⁵ᐟ²) + ...` та виключаючи параметр `exp(η)` за допомогою розкладу концентрації `n = N_c · [exp(η) - (exp(2η) / 2³ᐟ²) + ...]`, отримуємо **квантовий віріальний розклад рівняння стану**:

```
P = n · k_B · T · [1 + B₂(T) · n + B₃(T) · n² + ...]
```

де `B₂(T)` — другий квантовий віріальний коефіцієнт:

```
B₂(T) = λ_{th}³ / (2^{5/2}) = (1 / (2^{5/2})) · (h / √(2 · π · m* · k_B · T))³
```

де `λ_{th} = h / √(2 · π · m* · k_B · T)` — теплова довжина хвилі де Бройля електрона. Оскільки `B₂(T) > 0`, квантова статистика Фермі — Дірака створює ефективний додатковий тиск відштовхування порівняно з класичним ідеальним газом Клайперона — Менделєєва `P_{кл} = n · k_B · T`.

## 4. Сильновироджений ліміт: покроковий математичний вивід розкладу Зоммерфельда

У металах та сильнолегованих напівпровідниках рівень Фермі перебуває глибоко всередині дозволеної зони (`μ >> k_B · T` або `η >> 1`). Для обчислення термодинамічних інтегралів вигляду:

```
I = ∫₀^∞ H(E) · f(E) dE
```

де `H(E)` — довільна гладка функція енергії (наприклад, `H(E) = g(E)` для концентрації або `H(E) = E · g(E)` для внутрішньої енергії), застосовують асимптотичний розклад Зоммерфельда по малому параметру `(k_B · T / μ) << 1`.

### Математичний вивід розкладу

Введемо первісну функцію `K(E) = ∫₀^E H(ε) dε`, для якої виконуються умови `K(0) = 0` та `dK/dE = H(E)`. Проінтегруємо початковий інтеграл `I` частинами:

```
I = ∫₀^∞ H(E) · f(E) dE
  = [K(E) · f(E)]₀^∞ - ∫₀^∞ K(E) · (df / dE) dE                      [інтегрування частинами: u=f, dv=H dE]
  = ∫₀^∞ K(E) · (-df / dE) dE                                        [позаінтегральний член дорівнює нулю через f(∞)=0 та K(0)=0]
```

Похідна функції розподілу Фермі — Дірака зі знаком мінус дорівнює:

```
- (df / dE) = (1 / (k_B · T)) · (exp((E - μ) / (k_B · T))) / (exp((E - μ) / (k_B · T)) + 1)²
```

Ця функція є симетричним гострим дзвоном із максимумом у точці `E = μ`, напівшириною `~ 3.5 · k_B · T` та площею під кривою, що строго дорівнює одиниці.

Розкладемо первісну функцію `K(E)` у ряд Тейлора навколо точки `E = μ`:

```
K(E) = K(μ) + K'(μ) · (E - μ) + (1 / 2) · K''(μ) · (E - μ)² + (1 / 6) · K'''(μ) · (E - μ)³ + (1 / 24) · K⁴(μ) · (E - μ)⁴ + ...
```

Враховуючи, що `K'(μ) = H(μ)`, `K''(μ) = H'(μ)`, `K'''(μ) = H''(μ)` та `K⁴(μ) = H'''(μ)`:

```
K(E) = ∫₀^μ H(E) dE + H(μ) · (E - μ) + (1 / 2) · H'(μ) · (E - μ)² + (1 / 6) · H''(μ) · (E - μ)³ + (1 / 24) · H'''(μ) · (E - μ)⁴ + ...
```

Підставимо розклад Тейлора в інтеграл:

```
I = [∫₀^μ H(E) dE] · ∫₀^∞ (-df/dE) dE
  + H(μ) · ∫₀^∞ (E - μ) · (-df/dE) dE
  + (1 / 2) · H'(μ) · ∫₀^∞ (E - μ)² · (-df/dE) dE
  + (1 / 6) · H''(μ) · ∫₀^∞ (E - μ)³ · (-df/dE) dE
  + (1 / 24) · H'''(μ) · ∫₀^∞ (E - μ)⁴ · (-df/dE) dE + ...
```

Зробимо заміну змінної `z = (E - μ) / (k_B · T)`. Оскільки `μ >> k_B · T`, нижню межу інтегрування `z = -μ / (k_B · T)` можна без втрати точності поширити до `-∞`. Тоді інтеграли набувають універсального вигляду:

```
I_n = ∫₋∞^∞ z^n · (exp(z) / (exp(z) + 1)²) dz
```

### Строге обчислення універсальних визначених інтегралів I_n

1. **Непарні степені (`n = 1, 3, 5...`):**
   Функція `(-df/dz) = exp(z) / (exp(z) + 1)²` є строго парною, оскільки:
   ```
   exp(-z) / (exp(-z) + 1)² = exp(-z) / (exp(-2z) · (1 + exp(z))²) = exp(z) / (exp(z) + 1)²
   ```
   Добуток парної функції на непарний степінь `z^n` є непарною функцією. Інтеграл від непарної функції по симетричному інтервалу `[-∞, +∞]` тотожно дорівнює нулю:
   ```
   I_1 = I_3 = I_5 = ... ≡ 0
   ```

2. **Нульовий степінь (`n = 0`):**
   ```
   I_0 = ∫₋∞^∞ (-df/dz) dz = [- 1 / (exp(z) + 1)]₋∞^∞ = (1 - 0) = 1
   ```

3. **Парні степені (`n = 2, 4...`):**
   Оскільки підінтегральна функція парна, перейдемо до інтегрування по півосі `[0, ∞)`:
   ```
   I_n = 2 · ∫₀^∞ z^n · (exp(z) / (exp(z) + 1)²) dz
   ```
   Проінтегруємо частинами, поклавши `u = z^n` та `dv = (exp(z) / (exp(z) + 1)²) dz = - d(1 / (exp(z) + 1))`:
   ```
   I_n = 2 · [- z^n / (exp(z) + 1)]₀^∞ + 2 · n · ∫₀^∞ (z^{n-1} / (exp(z) + 1)) dz
       = 2 · n · ∫₀^∞ (z^{n-1} / (exp(z) + 1)) dz
   ```
   Розкладемо дріб у степеневий ряд: `1 / (exp(z) + 1) = ∑_{k=1}^∞ (-1)^{k-1} · exp(-k · z)`:
   ```
   I_n = 2 · n · ∑_{k=1}^∞ (-1)^{k-1} · ∫₀^∞ z^{n-1} · exp(-k · z) dz   [підстановка степеневого ряду експоненти]
       = 2 · n · ∑_{k=1}^∞ (-1)^{k-1} · (Γ(n) / k^n)                    [обчислення інтеграла через гамма-функцію Γ(n)]
       = 2 · n · (n - 1)! · ∑_{k=1}^∞ (-1)^{k-1} / k^n                  [підстановка тотожності Γ(n) = (n - 1)!]
       = 2 · n! · η_D(n)                                                [вираження через дзета-функцію Діріхле η_D(n)]
   ```
   де `η_D(n) = (1 - 2^{1-n}) · ζ(n)` — дзета-функція Діріхле, а `ζ(n)` — дзета-функція Рімана.

   * Для `n = 2`:
     `I_2 = 2 · 2! · (1 - 1/2) · ζ(2) = 4 · (1/2) · (π² / 6) = π² / 3`.
   * Для `n = 4`:
     `I_4 = 2 · 4! · (1 - 1/8) · ζ(4) = 48 · (7/8) · (π⁴ / 90) = 42 · (π⁴ / 90) = 7 · π⁴ / 15`.

Підставляючи отримані значення `I_0 = 1`, `I_1 = 0`, `I_2 = π² / 3`, `I_3 = 0`, `I_4 = 7 π⁴ / 15` у розклад інтеграла:

```
I = ∫₀^μ H(E) dE + (1 / 2) · H'(μ) · (k_B · T)² · (π² / 3) + (1 / 24) · H'''(μ) · (k_B · T)⁴ · (7 · π⁴ / 15) + O((k_B · T)⁶)
```

Отримуємо **канонічну формулу асимптотичного розкладу Зоммерфельда**:

```
∫₀^∞ H(E) · f(E) dE = ∫₀^μ H(E) dE + (π² / 6) · (k_B · T)² · H'(μ) + (7 · π⁴ / 360) · (k_B · T)⁴ · H'''(μ) + O((k_B · T)⁶)
```

### Асимптотика інтегралів Фермі — Дірака F_j(η) при η >> 1

Покладемо `H(x) = x^j` у розкладі Зоммерфельда для безрозмірних змінних:
* Первісна: `∫₀^η x^j dx = η^{j+1} / (j + 1)`;
* Перша похідна: `H'(η) = j · η^{j-1}`;
* Третя похідна: `H'''(η) = j · (j - 1) · (j - 2) · η^{j-3}`.

Підставляючи ці вирази у визначення `F_j(η) = (1 / Γ(j + 1)) · I`:

```
F_j(η) = (η^{j+1} / Γ(j + 2)) · [1 + (π² / 6) · (j · (j + 1) / η²) + (7 · π⁴ / 360) · (j · (j + 1) · (j - 1) · (j - 2) / η⁴) + ...]
```

Зокрема, для інтеграла напівцілого порядку `j = 1/2`:

```
F₁ᐟ₂(η) = (η³ᐟ² / Γ(5/2)) · [1 + (π² / 6) · ((1/2 · 3/2) / η²) + ...]
        = (4 / (3 · √π)) · η³ᐟ² · [1 + (π² / 8) · (1 / η²) + (7 · π⁴ / 640) · (1 / η⁴) + ...]
```

## 5. Фізичні наслідки розкладу Зоммерфельда

### 1. Температурний зсув хімічного потенціалу μ(T)

Концентрація електронів `n` у кристалі є фіксованою величиною, заданою кількістю іонізованих атомів або валентних електронів, і не залежить від температури: `n(T) = n(0)`.

Застосуємо розклад Зоммерфельда до інтеграла концентрації, поклавши `H(E) = g(E)`:

```
n(T) = ∫₀^μ g(E) dE + (π² / 6) · (k_B · T)² · g'(μ)
```

З іншого боку, при `T = 0 K` хімічний потенціал дорівнює енергії Фермі `E_F0`, а функція Фермі є сходинкою:

```
n(0) = ∫₀^{E_F0} g(E) dE
```

Прирівнюючи `n(T) = n(0)`:

```
∫₀^{E_F0} g(E) dE = ∫₀^μ g(E) dE + (π² / 6) · (k_B · T)² · g'(μ)
```

Розбиваючи інтеграл `∫₀^μ = ∫₀^{E_F0} + ∫_{E_F0}^μ`:

```
∫_{E_F0}^μ g(E) dE = - (π² / 6) · (k_B · T)² · g'(μ)
```

Оскільки при малих температурах зсув `(μ - E_F0)` є малим, лівий інтеграл можна наблизити прямокутником: `∫_{E_F0}^μ g(E) dE ≈ (μ - E_F0) · g(E_F0)`, а в правій частині замінити `g'(μ) ≈ g'(E_F0)`:

```
(μ - E_F0) · g(E_F0) = - (π² / 6) · (k_B · T)² · g'(E_F0)
```

Звідси випливає фундаментальна формула для температурної залежності хімічного потенціалу фермі-газу:

```
μ(T) = E_F0 - (π² / 6) · (k_B · T)² · (g'(E_F0) / g(E_F0))
```

Знак та величина зсуву повністю визначаються логарифмічною похідною густини станів `g'(E_F0) / g(E_F0)` на рівні Фермі:

1. **Тривимірний кристал з параболічною зоною (`g(E) = C · √E`):**
   ```
   g'(E) / g(E) = ((1/2) · C · E⁻¹ᐟ²) / (C · E¹ᐟ²) = 1 / (2 · E)
   ```
   Підставляючи у формулу зсуву:
   ```
   μ(T) = E_F0 · [1 - (π² / 12) · (k_B · T / E_F0)²]
   ```
   Хімічний потенціал 3D газу зменшується з ростом температури за квадратичним законом.

2. **Двовимірний квантовий газ (`g_2D(E) = const`):**
   Похідна `g'(E) = 0`, тому квадратичний зсув хімічного потенціалу відсутній (`μ(T) = E_F0 + O(exp(-E_F/k_B T))`).

3. **Одновимірний квантовий дріт (`g_1D(E) ∝ 1 / √E`):**
   Логарифмічна похідна `g'/g = - 1 / (2 · E_F0) < 0`. Хімічний потенціал зростає з температурою:
   ```
   μ_1D(T) = E_F0 · [1 + (π² / 12) · (k_B · T / E_F0)²]
   ```

4. **Двовимірний безмасовий газ Дірака (графен, `E = ℏ · v_F · k`, `g(E) ∝ E`):**
   Логарифмічна похідна `g'/g = 1 / E_F0`. Хімічний потенціал спадає вдвічі швидше:
   ```
   μ_графен(T) = E_F0 · [1 - (π² / 6) · (k_B · T / E_F0)²]
   ```

### 2. Електронна теплоємність виродженого електронного газу

Покладемо `H(E) = E · g(E)` для обчислення повної внутрішньої енергії `U(T)` електронного газу:

```
U(T) = ∫₀^∞ E · g(E) · f(E) dE
     = ∫₀^μ E · g(E) dE + (π² / 6) · (k_B · T)² · [d(E · g(E)) / dE]_{E=μ}
```

Обчислимо похідну добутку: `d(E · g(E))/dE = g(E) + E · g'(E)`. 

Розкладемо інтеграл `∫₀^μ E · g(E) dE` навколо точки `E_F0`:

```
∫₀^μ E · g(E) dE = ∫₀^{E_F0} E · g(E) dE + (μ - E_F0) · E_F0 · g(E_F0)
                 = U_0 - [(π² / 6) · (k_B · T)² · (g'(E_F0) / g(E_F0))] · E_F0 · g(E_F0)
                 = U_0 - (π² / 6) · (k_B · T)² · E_F0 · g'(E_F0)
```

Підставляючи цей вираз у формулу внутрішньої енергії `U(T)`:

```
U(T) = U_0 - (π² / 6) · (k_B · T)² · E_F0 · g'(E_F0) + (π² / 6) · (k_B · T)² · [g(E_F0) + E_F0 · g'(E_F0)]
     = U_0 + (π² / 6) · (k_B · T)² · g(E_F0)
```

Члени, що містять похідну `g'(E_F0)`, взаємно скорочуються. Диференціюючи внутрішню енергію `U(T)` за температурою `T`, отримуємо електронну теплоємність:

```
C_V,el = (dU / dT) = (π² / 3) · k_B² · T · g(E_F0) = γ · T
```

де `γ = (π² / 3) · k_B² · g(E_F0)` — коефіцієнт Зоммерфельда.

Для тривимірної параболічної зони `g(E_F0) = (3 / 2) · (N / E_F0) = (3 / 2) · (N / (k_B · T_F))`:

```
C_V,el = (π² / 2) · N · k_B · (T / T_F)
```

Цей вираз пояснює квантову малість електронної теплоємності в металах: оскільки температура Фермі `T_F ~ 50 000–100 000 K`, при кімнатній температурі (`T = 300 K`) відношення `T / T_F ~ 0.005`. Лише мала частка електронів у межах енергетичного прошарку `k_B · T` біля поверхні Фермі здатна змінювати свій квантовий стан при нагріванні, тоді як решта електронів заблокована принципом заборони Паулі.

### 3. Паулівський спіновий парамагнетизм виродженого електронного газу

У зовнішньому магнітному полі з індукцією `B` енергія електрона зі спіном, орієнтованим вздовж поля, знижується на `μ_B · B`, а зі спіном проти поля — зростає на `μ_B · B`, де `μ_B = q · ℏ / (2 · m_0)` — магнетон Бора. Рівноважна намагніченість одиниці об'єму `M` дорівнює:

```
M = μ_B · ∫₀^∞ [ (1 / 2) · g(E + μ_B · B) · f(E) - (1 / 2) · g(E - μ_B · B) · f(E) ] dE
```

Розкладаючи підінтегральний вираз у ряд Тейлора за малим магнітним полем `μ_B · B << E_F0` та застосовуючи розклад Зоммерфельда:

```
M = μ_B² · B · ∫₀^∞ g(E) · (- df / dE) dE
  = μ_B² · B · [ g(μ) + (π² / 6) · (k_B · T)² · g''(μ) ]
```

Підставляючи температурний зсув `μ(T) = E_F0 - (π² / 6) · (k_B · T)² · (g'(E_F0) / g(E_F0))` та розкладаючи `g(μ) ≈ g(E_F0) + g'(E_F0) · (μ - E_F0)`:

```
M = μ_B² · B · g(E_F0) · [ 1 - (π² / 6) · (k_B · T)² · ((g'(E_F0) / g(E_F0))² - (g''(E_F0) / g(E_F0))) ]
```

Для тривимірної зони з `g(E) = C · √E`, де `g'/g = 1 / (2 E)` та `g''/g = - 1 / (4 E²)`:

```
(g'/g)² - g''/g = (1 / (4 · E_F0²)) - (- 1 / (4 · E_F0²)) = 1 / (2 · E_F0²)
```

Звідси магнітна сприйнятливість Паулі `χ_{Pauli} = μ₀ · (dM / dB)` набуває вигляду:

```
χ_{Pauli}(T) = μ₀ · μ_B² · g(E_F0) · [ 1 - (π² / 12) · (k_B · T / E_F0)² ]
```

Магнітна сприйнятливість металу слабко спадає з температурою за квадратичним законом, залишаючись практично постійною величиною, на відміну від класичного закону Кюрі `χ ∝ 1 / T` для локалізованих магнітних моментів.

### 4. Формула Мотта для термо-ЕРС (коефіцієнта Зеєбека)

Диференціальна термо-ЕРС (коефіцієнт Зеєбека `S`) металу або виродженого напівпровідника визначається асиметрією енергетичного розподілу струму переносу носіїв заряду. Застосовуючи розклад Зоммерфельда до інтеграла електропровідності:

```
σ = ∫₀^∞ σ(E) · (- df / dE) dE
```

де `σ(E) = q² · v(E)² · τ(E) · g(E)` — спектральна провідність при енергії `E`, отримуємо фундаментальну **формулу Мотта**:

```
S = - (π² / 3) · (k_B / q) · (k_B · T) · [d ln σ(E) / dE]_{E=E_F}
```

Знак коефіцієнта Зеєбека визначається знаком основних носіїв заряду (мінус для електронів, плюс для дірок) та енергетичною похідною часу релаксації `τ(E)`. Лінійна залежність `S ∝ T` при низьких температурах є прямим математичним наслідком розкладу Зоммерфельда.

## 6. Аналітичні та інверсні апроксимації для інженерного моделювання

У чисельних пакетах проектування напівпровідникових приладів (TCAD) багаторазове чисельне інтегрування `F₁ᐟ₂(η)` у кожному вузлі просторової сітки призводить до надмірних обчислювальних витрат. Для прискорення розрахунків використовують прямі та інверсні аналітичні апроксимації.

### Пряма апроксимація Блейкмора та Беднейрека для F₁ᐟ₂(η)

Апроксимація Блейкмора дає просту аналітичну формулу для прямого розрахунку `F₁ᐟ₂(η)`:

```
F₁ᐟ₂(η) ≈ 1 / (exp(-η) + 0.27)
```

Ця формула забезпечує похибку менше `3%` в інтервалі `η ∈ [-∞, +1.3]`.

Більш точна двоточкова апроксимація Беднейрека (Bednarczyk & Bednarczyk) забезпечує максимальну відносну похибку менше `0.4%` на всій осі `η ∈ (-∞, +∞)`:

```
F₁ᐟ₂(η) ≈ [exp(-η) + (a · η + b)⁻ᶜ]⁻¹
```

де коефіцієнти підбираються з умови точного узгодження з больцманівською асимптотикою при `η → -∞` та розкладом Зоммерфельда при `η → +∞`.

### Інверсна апроксимація Джойса — Діксона

На практиці часто виникає зворотна задача: за відомою концентрацією носіїв `n` (заданою легуванням або виміряною за ефектом Холла) обчислити безрозмірне положення рівня Фермі `η_c = (E_F - E_c) / (k_B · T)`.

Введемо нормовану концентрацію `r = n / N_c = F₁ᐟ₂(η_c)`. Розкладемо `r` у степеневий ряд за змінною `x = exp(η_c)`:

```
r = x - (1 / (2 · √2)) · x² + (1 / (3 · √3)) · x³ - (1 / (4 · √4)) · x⁴ + ...
```

Використовуючи метод обернення степеневих рядів Лагранжа, виразимо `x` через `r`:

```
x(r) = r + a₂ · r² + a₃ · r³ + a₄ · r⁴ + ...
```

Підставляючи цей ряд у вихідне рівняння та прирівнюючи коефіцієнти при однакових степенях `r`:

```
r = (r + a₂ · r² + a₃ · r³) - (1 / (2 · √2)) · (r + a₂ · r²)² + (1 / (3 · √3)) · r³ + ...
  = r + [a₂ - 1 / (2 · √2)] · r² + [a₃ - a₂ / √2 + 1 / (3 · √3)] · r³ + ...
```

Звідси знаходимо коефіцієнти ряду:

```
a₂ = 1 / (2 · √2) = 1 / √8 ≈ 0.353553
a₃ = a₂ / √2 - 1 / (3 · √3) = (1 / 4) - (1 / (3 · √3)) ≈ 0.057550
```

Логарифмуючи вираз `η_c = ln(x) = ln(r · (1 + a₂ · r + a₃ · r² + ...)) = ln(r) + ln(1 + a₂ · r + a₃ · r² + ...)` та розкладаючи логарифм у ряд Тейлора `ln(1 + u) = u - u² / 2 + u³ / 3 - ...`:

```
η_c = ln(r) + a₂ · r + [a₃ - (a₂² / 2)] · r² + ...
```

Обчислюючи коефіцієнт при `r²`:

```
A₂ = a₃ - (a₂² / 2) = [(1 / 4) - (1 / (3 · √3))] - (1 / 16) = (3 / 16) - (√3 / 9) ≈ - 0.00495009
```

Отримуємо класичний розклад **Джойса — Діксона (Joyce — Dixon, 1977)**:

```
η_c = ln(r) + A₁ · r + A₂ · r² + A₃ · r³ + A₄ · r⁴
```

з аналітичними коефіцієнтами:

```
A₁ = 1 / √8 ≈ 3.53553 × 10⁻¹
A₂ = (3 / 16) - (√3 / 9) ≈ - 4.95009 × 10⁻³
A₃ = 1.48386 × 10⁻⁴
A₄ = - 4.42563 × 10⁻⁶
```

Ця формула забезпечує відносну похибку менше `0.1%` для всіх значень `r = n / N_c ≤ 10`, що повністю перекриває всі практичні режими легування напівпровідникових кристалів та квантових гетероструктур.

### Універсальна інверсна формула Беднейрека

Для надвисоких концентрацій (`r > 10`), де ряд Джойса — Діксона втрачає збіжність, застосовують універсальну інверсну формулу Беднейрека:

```
η_c ≈ (ln(r)) / (1 - r²) + ( (3 · √π / 4) · r )²ᐟ³ / ( 1 + [0.24 + 1.08 · ((3 · √π / 4) · r)²ᐟ³]⁻² )
```

Ця апроксимація справедлива для всього діапазону `r ∈ (0, ∞)` із максимальною похибкою менше `0.4%`.

## 7. Числовий розрахунок та порівняльний аналіз для Si та GaAs

Розглянемо практичні зонні параметри двох наріжних напівпровідникових матеріалів мікроелектроніки: кремнію (Si) та арсеніду галію (GaAs).

### Параметри густини станів

1. **Кремній (Si):**
   * Непрямозонний напівпровідник; зона провідності має `M_c = 6` еквівалентних еліпсоїдальних долин вздовж напрямків `⟨100⟩`.
   * Поперечна маса `m_t* = 0.19 · m_0`, поздовжня маса `m_l* = 0.98 · m_0`.
   * Ефективна маса густини станів зони провідності:
     ```
     m_de* = (M_c² · m_l* · m_t*²)¹ᐟ³ = (36 · 0.98 · 0.19²)¹ᐟ³ · m_0 ≈ 1.08 · m_0
     ```
   * Валентна зона (важкі та легкі дірки): `m_dh* = (m_hh*³ᐟ² + m_lh*³ᐟ²)²ᐟ³ ≈ 0.81 · m_0`.

2. **Арсенід галію (GaAs):**
   * Прямозонний напівпровідник; зона провідності має одну сферичну долину в центрі зони Бріллюена (`M_c = 1`, точка Γ).
   * Ефективна маса електрона: `m_de* = 0.067 · m_0` (у 16 разів менша, ніж у кремнію!).
   * Ефективна маса дірок: `m_dh* ≈ 0.47 · m_0`.

### Температурна таблиця ефективних густин станів N_c та N_v

Ефективні густини станів масштабуються пропорційно `(m* · T)³ᐟ²`:

```
N_c(T) = 2 · ((2 · π · m_de* · k_B · T) / h²)³ᐟ² = 2.5094 × 10¹⁹ · (m_de* / m_0)³ᐟ² · (T / 300)³ᐟ²  [см⁻³]
```

| Параметр | T = 4.2 K (рідкий He) | T = 77 K (рідкий N₂) | T = 300 K (кімнатна) | T = 600 K (висока) |
|---|---|---|---|---|
| `k_B · T` | `0.362 меВ` | `6.635 меВ` | `25.852 меВ` | `51.704 меВ` |
| **Si: `N_c`** | `4.74 × 10¹⁶ см⁻³` | `3.64 × 10¹⁸ см⁻³` | `2.86 × 10¹⁹ см⁻³` | `8.09 × 10¹⁹ см⁻³` |
| **Si: `N_v`** | `3.08 × 10¹⁶ см⁻³` | `2.37 × 10¹⁸ см⁻³` | `1.86 × 10¹⁹ см⁻³` | `5.26 × 10¹⁹ см⁻³` |
| **GaAs: `N_c`** | `7.36 × 10¹⁴ см⁻³` | `5.66 × 10¹⁶ см⁻³` | `4.45 × 10¹⁷ см⁻³` | `1.26 × 10¹⁸ см⁻³` |
| **GaAs: `N_v`** | `1.34 × 10¹⁶ см⁻³` | `1.03 × 10¹⁸ см⁻³` | `8.11 × 10¹⁸ см⁻³` | `2.29 × 10¹⁹ см⁻³` |

Через малу ефективну масу електронів у GaAs значення `N_c` при кімнатній температурі становить лише `4.45 × 10¹⁷ см⁻³` (на два порядки нижче, ніж у Si). Тому поріг виродження електронів у GaAs настає вже при помірному допуванні, що є визначальним для створення напівпровідникових інжекційних лазерів.

### Розібраний приклад 1. Розрахунок рівня Фермі у виродженому GaAs

**Умова:** Зразок арсеніду галію легований донорами кремнію до концентрації `n = 1.0 × 10¹⁸ см⁻³` при температурі `T = 300 K` (`k_B · T = 0.02585 еВ`, `N_c = 4.45 × 10¹⁷ см⁻³`). Обчислити положення рівня Фермі відносно дна зони провідності `(E_F - E_c)` за класичною статистикою Больцмана, за апроксимацією Джойса — Діксона та оцінити похибку.

**Покрокове обчислення:**

1. Обчислимо нормовану концентрацію:
```
r = n / N_c = (1.0 × 10¹⁸) / (4.45 × 10¹⁷) = 2.2472
```

2. Класичний розрахунок за формулою Максвелла — Больцмана:
```
η_Больцман = ln(r) = ln(2.2472) = 0.8097
E_F - E_c = k_B · T · η_Больцман = 0.025852 еВ · 0.8097 = +0.02093 еВ = +20.93 меВ
```

3. Розрахунок за поліномом Джойса — Діксона:
```
η_JD = ln(r) + A₁ · r + A₂ · r² + A₃ · r³ + A₄ · r⁴                                   [формула полінома Джойса — Діксона]
     = 0.8097 + 0.353553 · 2.2472 - 0.004950 · (2.2472)² + 0.000148 · (2.2472)³     [підстановка коефіцієнтів та нормованої концентрації]
     = 0.8097 + 0.79450 - 0.02500 + 0.00168                                          [обчислення доданків]
     = 1.5809                                                                        [підсумовування компонент]
```
```
E_F - E_c = k_B · T · η_JD = 0.025852 еВ · 1.5809 = +0.04087 еВ = +40.87 меВ
```

**Висновок:** Класична формула Больцмана помилково дає значення `+20.93 меВ`, занижуючи реальне положення рівня Фермі майже вдвічі (похибка `~ 20 меВ`). Точний розрахунок показує, що рівень Фермі занурений у зону провідності на `40.87 меВ`, що забезпечує стан інверсної заселеності для лазерної генерації.

### Розібраний приклад 2. Температурний зсув хімічного потенціалу в металічному алюмінії

**Умова:** Металічний алюміній (Al) має валентність `Z = 3`, густину `ρ = 2.70 г/см³`, молярну масу `M = 26.98 г/моль` та енергію Фермі `E_F0 = 11.7 еВ`. Обчислити зміщення хімічного потенціалу `μ(T) - E_F0` при температурах `T = 300 K` та `T = 900 K` (поблизу точки плавлення `T_пл = 933 K`).

**Покрокове обчислення:**

1. Обчислимо температуру Фермі алюмінію:
```
T_F = E_F0 / k_B = 11.7 еВ / (8.6173 × 10⁻⁵ еВ/К) = 1.3577 × 10⁵ K
```

2. Зсув хімічного потенціалу при кімнатній температурі `T = 300 K` (`k_B · T = 0.025852 еВ`):
```
μ(300) - E_F0 = - E_F0 · (π² / 12) · (k_B · T / E_F0)²                [формула Зоммерфельда для параболічної зони]
              = - 11.7 · (9.8696 / 12) · (0.025852 / 11.7)²           [підстановка числових значень при 300 K]
              = - 11.7 · 0.82247 · 4.881 × 10⁻⁶                       [обчислення квадратичного множника]
              = - 4.70 × 10⁻⁵ еВ = - 0.047 меВ                        [результуючий температурний зсув]
```
Відносне зміщення становить `(4.70 × 10⁻⁵) / 11.7 ≈ 0.0004%`.

3. Зсув хімічного потенціалу при високій температурі `T = 900 K` (`k_B · T = 0.077556 еВ`):
```
μ(900) - E_F0 = - 11.7 · 0.82247 · (0.077556 / 11.7)²                 [підстановка k_B T = 0.077556 еВ при 900 K]
              = - 9.6229 · 4.393 × 10⁻⁵                               [обчислення степеня]
              = - 4.23 × 10⁻⁴ еВ = - 0.423 меВ                        [результуючий температурний зсув]
```
Відносне зміщення становить `(4.23 × 10⁻⁴) / 11.7 ≈ 0.0036%`.

**Висновок:** Навіть при нагріванні металу майже до точки плавлення (`900 K`) хімічний потенціал фермі-газу зміщується менш ніж на `0.5 меВ` (частки сотої відсотка), що підтверджує фізичну стабільність рівня Фермі в металах.

### Розібраний приклад 3. Порівняння моделей при надвисокому легуванні активної області лазерного гетероструктурного діода

**Умова:** Активна область інжекційного квантово-розмірного лазера на основі GaAs легована кремнієм до концентрації `n = 5.0 × 10¹⁸ см⁻³` при кімнатній температурі `T = 300 K` (`k_B · T = 0.025852 еВ`, `N_c = 4.45 × 10¹⁷ см⁻³`). Розрахувати безрозмірний хімічний потенціал `η_c` та фізичне заглиблення рівня Фермі `(E_F - E_c)` за формулами:
1) класичного розподілу Максвелла — Больцмана;
2) полінома Джойса — Діксона;
3) універсальної інверсної формули Беднейрека;
4) точного чисельного обернення інтеграла Фермі `F₁ᐟ₂(η_c) = r`.

**Покрокове обчислення:**

1. Обчислимо параметр нормованої концентрації:
```
r = n / N_c = (5.0 × 10¹⁸ см⁻³) / (4.45 × 10¹⁷ см⁻³) = 11.236
```
Оскільки `r > 10`, система перебуває на крайній межі застосовності полінома Джойса — Діксона.

2. Класичний розрахунок (Максвелл — Больцман):
```
η_Больцман = ln(r) = ln(11.236) = 2.419
E_F - E_c = 0.025852 еВ · 2.419 = +0.0625 еВ = +62.5 меВ
```

3. Розрахунок за рядом Джойса — Діксона:
```
η_JD = ln(r) + A₁ · r + A₂ · r² + A₃ · r³ + A₄ · r⁴                                                                    [поліном Джойса — Діксона]
     = 2.4191 + 0.353553 · 11.236 - 0.00495009 · (11.236)² + 0.00014839 · (11.236)³ - 0.00000443 · (11.236)⁴         [підстановка r = 11.236]
     = 2.4191 + 3.9725 - 0.6250 + 0.2105 - 0.0706                                                                     [обчислення степенів]
     = 5.906                                                                                                           [підсумовування компонент]
```
```
E_F - E_c = k_B · T · η_JD = 0.025852 еВ · 5.906 = +0.1527 еВ = +152.7 меВ
```

4. Розрахунок за універсальною формулою Беднейрека:
Обчислимо допоміжні величини:
```
u_F = (3 · √π / 4) · r = (3 · 1.77245 / 4) · 11.236 = 14.937
u_F²ᐟ³ = (14.937)²ᐟ³ = 6.069
```
```
Знаменник = 1 + [0.24 + 1.08 · 6.069]⁻² = 1 + [6.795]⁻² = 1 + 0.02166 = 1.02166
```
```
η_Bednarczyk = (ln(11.236) / (1 - 11.236²)) + (6.069 / 1.02166)       [підстановка логарифма та знаменника Беднейрека]
             = (2.4191 / (-125.25)) + 5.9404                          [обчислення часток]
             = - 0.0193 + 5.9404                                      [додавання двох складових]
             = 5.921                                                  [результуюче значення]
```
```
E_F - E_c = 0.025852 еВ · 5.921 = +0.1531 еВ = +153.1 меВ
```

5. Еталонний чисельний розв'язок методом бісекції інтеграла `(2/√π) ∫₀^∞ √x / (exp(x - η) + 1) dx = 11.236`:
```
η_точне = 5.926
E_F - E_c = 0.025852 еВ · 5.926 = +0.1532 еВ = +153.2 меВ
```

| Метод розрахунку | Отримане значення `η_c` | Рівень Фермі `E_F - E_c` | Відносна похибка |
|---|---|---|---|
| Максвелл — Больцман | `2.419` | `+62.5 меВ` | `-59.2%` (катастрофічна) |
| Джойс — Діксон (4 члени) | `5.906` | `+152.7 меВ` | `-0.34%` |
| Апроксимація Беднейрека | `5.921` | `+153.1 меВ` | `-0.08%` |
| Еталонне чисельне інтегрування | `5.926` | `+153.2 меВ` | `0.00%` (еталон) |

**Висновок:** При високих рівнях легування (`n = 5 × 10¹⁸ см⁻³`, `r ≈ 11.2`) класична модель Больцмана занижує енергію Фермі майже в 2.5 раза. Ряд Джойса — Діксона навіть на границі збіжності зберігає високу точність (похибка `0.34%`), а універсальна формула Беднейрека дає практично ідеальне узгодження з чисельним еталоном (похибка менше `0.1%`), що робить її надійним аналітичним інструментом для швидкого розрахунку лазерних гетероструктур.
