# 🧮 Вивід Кулонівського логарифма та межі придатності наближення малих кутів

Математична вставка містить послідовний теоретичний вивід формули Кулонівського логарифма `ln Λ`, математичний аналіз інтегрування передачі імпульсу при малик кутах розсіювання, обчислення мінімального та максимального прицільних параметрів взаємодії, а також фізичні межі придатності класичної теорії Спітцера у разі квантового виродження або неідеальності плазми.

## 1. Кинематика кулонівського зіткнення та геометрія відхилення

Розглянемо пружне зіткнення електрона з масою `m⑺`, зарядом `-e` та початковою швидкістю `v` з іоном з зарядом `+Z·e`. Внаслідок того, що маса іона `mᵢ` у тисячі разів перевищує масу електрона (`mᵢ >> m⑺`), іон можна вважати нерухомим точковим силовим центром, розташованим у початку координат.

Прицільний параметр позначимо через `b` — це відстань від іона до лінії початкового руху електрона на нескінченності. Відстань від іона до електрона в поточний момент часу `t` позначимо через `r(t)`.

Сила притягання Кулона, що діє на електрон:

```
F(r) = (Z · e²) / (4π · ε₀ · r²)                                                [закон Кулона]
```

Для знаходження відхилення напрямку руху електрона скористаємося наближенням слабких зіткнень. Оскільки в плазмі переважна більшість взаємодій відбувається при прицільних параметрах, значно більших за класичний радіус зближення (`b >> b_cl`), кут відхилення `θ` є малим значенням (`θ << 1 рад`).

У наближенні малих кутів можна припустити, що електрон рухається вздовж незбуреної прямолінійної траєкторії `x(t) = v · t` з постійною швидкістю `v`, а координата `y` залишається майже рівною прицільному параметру `y(t) ≈ b`.

Поперечна перпендикулярна компонента сили Кулона `F_⊥(t)`, що діє перпендикулярно до початкової траєкторії електрона:

```
F_⊥(t) = F(r) · (b / r)
       = ((Z · e²) / (4π · ε₀ · (b² + v²·t²))) · (b / √(b² + v²·t²))
       = ((Z · e² · b) / (4π · ε₀)) · (1 / (b² + v²·t³⁾²)                     [поперечна сила Кулона]
```

Повний перпендикулярний імпульс `Δp_⊥`, переданий електрону за увесь час прольоту від `t = -∞` до `t = +∞`:

```
Δp_⊥ = ∫₋∞⁺∞ F_⊥(t) dt
     = ((Z · e² · b) / (4π · ε₀)) · ∫₋∞⁺∞ (1 / (b² + v²·t³⁾²) dt
```

Для обчислення цього визначеного інтеграла виконаємо заміну змінної `t = (b / v) · tan φ`, де `dt = (b / v) · sec² φ dφ`:

```
∫₋∞⁺∞ (1 / (b² + v²·t³⁾²) dt = (1 / (v · b²)) · ∫₋π/2⁺π/2 cos φ dφ
                              = (1 / (v · b²)) · [sin φ]₋π/2⁺π/2
                              = 2 / (v · b²)                                   [значення часового інтеграла]
```

Підставляючи результат інтегрування у вираз для поперечного імпульсу `Δp_⊥`:

```
Δp_⊥ = ((Z · e² · b) / (4π · ε₀)) · (2 / (v · b²))
     = (2 · Z · e²) / (4π · ε₀ · v · b)                                       [поперечний імпульс розсіювання]
```

Початковий поздовжній імпульс електрона дорівнює `p = m⑺ · v`. У наближенні малих кутів (`θ << 1`) кут відхилення траєкторії `θ` виражається як відношення переданого поперечного імпульсу до початкового поздовжнього імпульсу:

```
θ ≈ Δp_⊥ / p
  = (2 · Z · e²) / (4π · ε₀ · m⑺ · v² · b)                                    [кут відхилення на малі кути]
```

Введемо характерний параметр — класичну відстань найближчого зближення при лобовому розсіюванні `b_cl`, де потенціальна енергія Кулона дорівнює подвоєній кінетичній енергії:

```
b_cl = (Z · e²) / (4π · ε₀ · m⑺ · v²)                                          [класична межа зближення]
```

Виражаючи кут відхилення через `b_cl`, отримуємо просте співвідношення:

```
θ ≈ 2 · b_cl / b
```

З цієї формули чітко видно, що умова малих кутів `θ << 1` справджується для всіх зіткнень із прицільними параметрами `b >> 2 · b_cl`.

## 2. Математичний вивід транспортного перерізу та виникнення Кулонівського логарифма

Для знаходження електричного опору необхідно обчислити не просто повний переріз розсіювання, а **транспортний переріз передачі імпульсу `σ_p`**, який враховує лише втрату поздовжньої складової швидкості електрона:

```
σ_p = ∫ (1 - cos θ) dσ
```

де `dσ = 2π · b db` — елементарна площа кільця прицільних параметрів від `b` до `b + db`.

Застосуємо розклад у статевий ряд Тейлора для тригонометричної функції `cos θ` при малих кутах `θ << 1`:

```
cos θ ≈ 1 - (θ² / 2)
1 - cos θ ≈ θ² / 2
```

Підставляючи розклад `1 - cos θ` та вираз для кута відхилення `θ = 2 · b_cl / b` в інтеграл транспортного перерізу:

```
1 - cos θ ≈ (1 / 2) · (2 · b_cl / b)² = 2 · (b_cl / b)²
```

Тепер обчислимо інтеграл транспортного перерізу `σ_p` по між прицільними параметрами від мінімального `b_min` до максимального `b_max`:

```
σ_p = ∫_b_min^b_max (2 · (b_cl / b)²) · 2π · b db
    = 4π · b_cl² · ∫_b_min^b_max (1 / b) db                                    [виділення логарифмічного інтеграла]
    = 4π · b_cl² · [ln b]_b_min^b_max
    = 4π · b_cl² · ln(b_max / b_min)                                          [формула транспортного перерізу]
```

Величина `ln Λ = ln(b_max / b_min)` називається **Кулонівським логарифмом**. Вона чисельно визначає, наскільки внесок далеких зіткнень із малими кутами відхилення перевищує внесок рідкісних близьких лобових зіткнень.

## 3. Фізичний зміст та точне обчислення меж інтегрування

Логарифмічна розбіжність інтеграла на обох межах (`b → 0` та `b → ∞`) вимагає строгого фізичного обґрунтування вибору меж `b_min` та `b_max`.

### Верхня межа: Екранування Дебая (`b_max`)

У суцільній плазмі іони не є ізольованими. Навколо кожного позитивного іона утворюється екранувальна електронна хмара. На відстанях, більших за радіус Дебая `λ_D`, електростатичний потенціал іона спадає за експоненційним законом Дебая — Гюккеля:

```
Φ(r) = (Z · e / (4π · ε₀ · r)) · exp(-r / λ_D)
```

де радіус Дебая дорівнює:

```
λ_D = √((ε₀ · k_B · T⑺) / (n⑺ · e²))
```

На відстанях `r > λ_D` електричне поле іона практично повністю нейтралізується екрануванням, тому електрони з прицільним параметром `b > λ_D` взагалі не зазнають відхилення. Звідси отримуємо строге фізичне значення для верхньої межі інтегрування:

```
b_max = λ_D
```

### Нижня межа: Класична проти квантової межі (`b_min`)

Нижня межа `b_min` запобігає розбіжності інтеграла при `b → 0`. Вона вибирається як найбільше з двох фізичних обмежень:

1. **Класична межа (`b_cl`):** Відповідає прицільному параметру, при якому кут відхилення досягає `θ ≈ 1 рад`. Наближення малих кутів у цій точці ламається, і розсіювання стає лобовим:

```
b_cl = (Z · e²) / (4π · ε₀ · m⑺ · v_th²)
```

2. **Квантово-механічна межа (`b_qm`):** Пов'язана з квантовою хвильовою природою електрона. Згідно з принципом невизначеності Гейзенберга, прицільний параметр не може бути визначений із точністю, вищою за теплову довжину хвилі де Бройля електрона `λ_dB`:

```
b_qm = ℏ / (2 · m⑺ · v_th)                                                     [довжина хвилі де Бройля]
```

Остаточне значення нижньої межі береться як максимальне з цих двох значень:

```
b_min = max(b_cl, b_qm)
```

Перехід від класичного до квантового розсіювання визначається температурою електронів:

```
T⑺ < 13.6 · Z² еВ  →  b_min = b_cl (класичний режим)
T⑺ > 13.6 · Z² еВ  →  b_min = b_qm (квантовий режим, характерний для токамаків)
```

## 4. Порівняльний аналіз значення `ln Λ` у різних фізичних системах

Усереднюючи теплову швидкість електронів по максвеллівському розподілу `v_th = √(3 · k_B · T⑺ / m⑺)`, отримуємо практичні формули для обчислення Кулонівського логарифма:

```
Класичний режим (T⑺ < 10 еВ):
ln Λ = 23 - ln(Z · n⑺^(1/2) · T⑺^(-3/2))

Квантовий режим (T⑺ > 10 еВ):
ln Λ = 24 - ln(n⑺^(1/2) · T⑺^(-1))
```

де густина `n⑺` подана в `см⁻³`, а температура `T⑺` — в `еВ`.

| Фізична середа | Температура `T⑺` | Густина `n⑺` | Радіус Дебая `λ_D` | `ln Λ` | Фізичні особливості |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Токамак ITER (ядро)** | `10 кеВ` (`10⁸ K`) | `10²⁰ м⁻³` | `74 мкм` | **17.5** | Квантовий режим, надвисока провідність |
| **Сонячна корона** | `100 еВ` (`10⁶ K`) | `10¹⁵ м⁻³` | `2.4 мм` | **21.0** | Високорозряджена ідеальна плазма |
| **Ядро Сонця** | `1.3 кеВ` (`1.5×10⁷ K`) | `10³² м⁻³` | `0.02 нм` | **2.5** | Помірний зв'язок, границя застосовності |
| **Міжзоряний газ (H II)** | `1 еВ` (`10⁴ K`) | `10⁶ м⁻³` | `7.4 м` | **26.0** | Екстремально розріджена плазма |
| **Лазерна плазма (ICF)** | `1 кеВ` | `10²⁸ м⁻³` | `0.23 нм` | **7.0** | Сильностиснута гаряча плазма |

## 5. Границі застосовності теорії Спітцера та ефекти сильного зв'язку

Теорія Спітцера побудована на припущенні **ідеальності плазми**, тобто припущенні про те, що середня потенціальна енергія взаємодії між частинками значно менша за їхню теплову кінетичну енергію.

Параметр кулонівського зв'язку (безрозмірний параметр неідеальності) `Γ`:

```
Γ = (Z² · e²) / (4π · ε₀ · a_i · k_B · T⑺)
```

де `a_i = (3 / (4π · n⑺))^(1/3)` — середня відстань між іонами (радіус Вігнера — Зейтца).

```
Γ << 1  →  Ідеальна плазма: Теорія Спітцера точна (ln Λ >> 1)
Γ ≥ 1   →  Неідеальна (сильнозв'язана) плазма: Теорія Спітцера ламається (ln Λ → 1)
```

Коли параметр `ln Λ` спадає до значень, менших за `2...3`, екранування Дебая перестає бути колективним електростатичним ефектом і перетворюється на квантову кореляцію сусідніх іонів. У цьому режимі (характерному для надр планет-гігантів, білих карликів та початкових фаз лазерного стиснення) класичні формули Спітцера замінюють на квантові транспортні моделі Лі — Мора (Lee-More model) або формули Займана для рідких металів.
