# 🔌 Порівняльний аналіз колоїдних та епітаксійних квантових точок

Ця вставка надає повномасштабний порівняльний аналіз фізичних властивостей, технологічних методів виготовлення, електронних спектрів та сфери практичного застосування двох головних класів нульвимірних наноструктур: **колоїдних напівпровідникових нанокристалів** (система «рідкий розчин — захисна оболонка й органічні ліганди») та **самозібраних епітаксійних квантових точок** (система «монолітний кристал — напружена кристалічна матриця»).

---

## 1. Фізичні принципи створення та анатомічна будова

Хоча в основі роботи обох класів квантових точок лежить один і той самий фізичний ефект тривимірного розмірного квантування (0D confinement), технологічні шляхи їхнього створення, фізичне оточення та структура поверхонь фундаментально відрізняються.

```
       КОЛОЇДНА КВАНТОВА ТОЧКА                   ЕПІТАКСІЙНА КВАНТОВА ТОЧКА
      (Colloidal Quantum Dot, CQD)               (Epitaxial Quantum Dot, EQD)

           Органічні ліганди                             Кристалічна матриця
             (Олеїнова к-та)                                   (GaAs)
                  \                                              |
               ┌───┴───┐                                      ┌──┴──┐
               │  ZnS  │ ← Оболонка                           │InAs │ ← Наноострівець
               │ ┌───┐ │                                      │  ▲  │
               │ │CdSe│ │ ← Ядро                               └──┬──┘
               │ └───┘ │                                         │
               └───────┘                                 Змочувальний шар (WL)
```

### 1. Колоїдні квантові точки (Colloidal Quantum Dots, CQD)
Колоїдні точки вирощують шляхом хімічного синтезу в рідкій фазі за високих температур (200–350 °C). Анатомічно вони є вільними монокристалічними ядерцями діаметром від 2 до 10 нм (`CdSe`, `InP`, `PbS`, `CsPbBr3`), вкритими двома обов'язковими захисними шарами:
- **Неорганічна пасивуюча оболонка (*shell*):** шар ширшозонного напівпровідника (`ZnS`, `ZnSe`), нанесений поверх ядра. Оболонка створює високий неорганічний потенціальний бар'єр для носіїв заряду, локалізуючи електрон і дірку всередині ядра, та пасивує ненасичені поверхневі зв'язки (ненасичені валентності), запобігаючи нерадіаційній безипромінюваній рекомбінації.
- **Органічна лігандна оболонка (*ligand shell*):** довголанцюгові органічні молекули (олеїнова кислота, триоктилфосфіноксид), ковалентно або координаційно приєднані до катіонів металу на зовнішній поверхні. Ліганди запобігають агломерації (злипанню) частинок і забезпечують їх стійку розчинність у неполярних або полярних органічних розчинниках (толуол, хлороформ, вода).

### 2. Епітаксійні квантові точки (Epitaxial Quantum Dots, EQD)
Епітаксійні точки вирощують у надвисокому вакуумі методами молекулярно-променевої епітаксії (MBE) або газофазної епітаксії з металоорганічних сполук (MOCVD). В їхній основі лежить **самоорганізований механізм Странського — Крастанова**:
1. На кристалічну підкладку (наприклад, арсенід галію `GaAs`) у вакуумі наноситься шар напівпровідника з суттєво більшою сталою кристалічної решітки (наприклад, арсенід індію `InAs`, неузгодженість решіток становить близько 7%).
2. Перші 1–2 атомарні шари лягають як суцільний напружений плівковий шар — **змочувальний шар** (*wetting layer*).
3. При досягненні критичної товщини шару накопичена пружна енергія деформації стискання перешкоджає подальшому планарному росту, і шар самовільно релаксує, розпадаючись на тривимірні бездефектні наноострівці пірамідальної або лінзоподібної форми (база 15–25 нм, висота 3–6 нм).
4. Отримані острівці зверху «поховують» товстим шаром матриці `GaAs`, утворюючи суцільний монокристал із вкрапленими квантовими точками `InAs`.

## 2. Зонування країв зон у гетероструктурах

Для обох типів точок вирішальне значення має архітектура взаємного розташування країв зон ядра та оболонки (або матриці).

```
   Type-I (Ядро-оболонка / Кристал)             Type-II (Просторове розділення)

       Zone C (Shell)                              Zone C (Shell)
       ┌──────────┐                                ┌──────────┐
       │          │                                │   e⁻     │
       │  Zone C  │                                │  ┌───────┴──┐
       │  (Core)  │                                │  │          │
       │  ┌────┐  │                                │  │  Zone C  │
       │  │ e⁻ │  │                                │  │  (Core)  │
       │  │ h⁺ │  │                                └──┼───────┐  │
       │  └────┘  │                                   │  h⁺   │  │
       │  Zone V  │                                   │ Zone V│  │
       │  (Core)  │                                   │(Core) │  │
       │          │                                   └───────┼──┘
       └──────────┘                                           │ Zone V
       Zone V (Shell)                                         │ (Shell)
                                                              └──────────┘
```

- **Гетероструктури Type-I (`CdSe/ZnS`, `InAs/GaAs`):** Край зони провідності оболонки (матриці) лежить вище, а валентної зони — нижче, ніж у ядра. Електрон і дірка локалізовані у спільному об'ємі ядра. Це забезпечує максимальне перекриття хвильових функцій `⟨Ψ_e | Ψ_h⟩ ≈ 1`, високу ймовірність випромінювальної рекомбінації, коротку тривалість життя екситона (1–10 нс) та квантовий вихід понад 90%. Це ідеально для світлодіодів QLED та дисплеїв.
- **Гетероструктури Type-II (`CdTe/CdSe`, `ZnTe/CdSe`):** Перекриття зон зсунуте східчасто: електрон локалізується в одному матеріалі (в оболонці), а дірка — в іншому (в ядрі). Просторове розділення зарядів створює внутрішнє електричне поле, суттєво зменшує перекриття хвильових функцій та подовжує час життя носіїв до мікросекунд. Використовується в сонячних елементах та фотодетекторах.

## 3. Зведена таблиця порівняльних характеристик

| Фізично-технічний параметр | Колоїдні квантові точки (CQD) | Епітаксійні квантові точки (EQD) |
| :--- | :--- | :--- |
| **Фізичний стан і середовище** | Рідкі колоїдні розчини, плівки, полімерні матриці; сферична форма (2–10 нм) | Тверда монокристалічна напівпровідникова матриця; пірамідальні острівці |
| **Монодисперсність та розширення** | Висока монодисперсність (розкид < 5%), але ансамбль має неоднорідне розширення 20–40 мЕв | Суттєвий розкид за розмірами на підкладці; спектральна лінія ансамблю широка (30–50 мЕв) |
| **Ширина лінії одиночної точки (300 K)** | 50–100 мЕв (через сильну електрон-фононну взаємодію та поверхневі заряди) | 1–5 мЕв; при 4 K — ультратонка лінія обмежена природною шириною (< 1–10 мкЕв) |
| **Квантовий вихід люмінесценції** | Дуже високий (> 90–95% у розчинах та світлодіодах) | Середній для ансамблю, але майже 100% для одиночної точки у мікрорезонаторі |
| **Електричний контакт та інжекція** | Складний інжект через ізолюючі органічні ліганди (потрібна заміна лігандів на короткі) | Ідеальний: точки вбудовані безпосередньо у p-n або p-i-n переходи напівпровідника |
| **Ефекти миготіння (Blinking) та Оже** | Сильно виражені: флуктуації заряду викликають миготіння випромінювання (Auger quenching) | Практично відсутні: матриця блокує вихід заряду; стабільна невипромінювальна робота |
| **Дефазування спіну й когерентність** | Короткий час спінової релаксації через поверхневі ядерні спіни та ліганди | Довгий час когерентності спіну електрона (до мікросекунд при низьких T) |
| **Технологічна вартість виробництва** | Низька: хімічний рідинний синтез, рулонний друк (roll-to-roll), спін-коатинг | Дуже висока: вимагає надвисоковакуумних установок MBE/MOCVD та чистих кімнат |
| **Головні області застосування** | Дисплеї (QLED, QD-OLED), сонячні батареї, біомедичні маркери, фотодетектори | Однофотонні джерела для квантової криптографії, лазери на квантових точках, спінові кубіти |

## 4. Інженерні пастки та технологічні обмеження

При розробці оптоелектронних пристроїв необхідно враховувати специфічні інженерні обмеження кожного класу:

### Довжина лігандів проти провідності (у CQD)
Довгі органічні ліганди (олеїнова кислота завдовжки ~2 нм) ізолюють нанокристали в розчині, але у тунельному сухому шарі створюють високий потенціальний бар'єр. Опір тунелювання зростає експоненційно з довжиною ліганда `R_T ∝ exp(2κd)`. Для виготовлення сонячних батарей та світлодіодів первинні довгі ліганди під час виготовлення плівки замінюють на короткі неорганічні іони (галогеніди `I⁻, Br⁻`, сульфіди `S²⁻`), що піднімає рухливість носіїв на кілька порядків.

### Ефект миготіння та Оже-рекомбінація (у CQD)
Під дією інтенсивного оптичного накачування у квантовій точці може утворитися біекситон (дві пари електрон-дірка). При рекомбінації однієї пари енергія передається третьому носію (безвипромінювальна рекомбінація Оже). Якщо один із носіїв вилітає на поверхневу пастку, точка стає зарядженою. У зарядженій точці будь-яка наступна пара електрон-дірка миттєво гаситься Оже-процесом, і точка «погасає» (Off-state). Це викликає оптичне миготіння (*blinking*).

### Змочувальний шар та неоднорідне розширення (у EQD)
У епітаксійних точках Странського — Крастанова наявність двовимірного змочувального шару (*wetting layer*) створює неперервний квантоворозмірний підрівень під точкою. Це призводить до витоку носіїв із точки у змочувальний шар при підвищенні температури. Крім того, природний розкид висоти й бази наноострівців спричиняє неоднорідне розширення спектральних ліній ансамблю, що вимагає спектрального відбору одиночних точок за допомогою мікрозондів чи кріогенних матриць.
