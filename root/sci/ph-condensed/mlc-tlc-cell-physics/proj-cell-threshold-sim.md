# ⚙️ Моделювання розподілу порогових напруг та помилок RBER у комірках NAND

Для фізичного аналізу надійності твердотільних накопичувачів та обчислення рівня первинних бітових помилок (Raw Bit Error Rate, RBER) необхідно повністю змоделювати статистичний розподіл порогових напруг `V_th` у масиві з десятків тисяч напівпровідникових комірок. У натурному мікропроцесорному контролері SSD функція відстеження порогових піків виконується фізичним контролером Flash Translation Layer (FTL) для вибору оптимальних затримок та опорних напруг зчитування `V_ref`.

У цьому проекті розроблено числову модель, яка відтворює повний фізичний життєвий цикл масиву з `100 000` комірок NAND (для архітектур SLC, MLC, TLC та QLC):
1. **Початковий стан стирання (Erased state)** — формування гауссового розподілу порогових напруг після заземлення затворів та подачі імпульсу стирання `V_erase = 20 В`.
2. **Інкрементальне програмування імпульсами ISPP** — покрокове дозоване інжектування електронів серією програмуючих імпульсів з приростом `ΔV_pgm = 0.20 В` до досягнення цільової напруги верифікації `V_verify`.
3. **Паразитне перехресне наведення (Program Disturb)** — ємнісний зсув порогової напруги сусідніх комірок `C_fg-fg` при програмуванні суміжних бітових ліній.
4. **Дискретний шум RTN (Random Telegraph Noise)** — флуктуації `V_th` внаслідок поодиноких перезахоплень електронів пастками діелектрика.
5. **Температурний витік заряду (Retention Decay)** — деградація порогового вікна у часі за логарифмічним законом розряджання.
6. **Декодування станів та розрахунок RBER** — порівняння порогових напруг з опорними рівнями `V_ref` та оцінка кількості помилково зчитаних бітів.

### Математичний опис фізичних етапів симуляції

#### 1. Початковий розподіл стирання та формування піку Erased

У вихідному стираному стані (Erased state `E`) порогова напруга комірки `V_th` описується нормальним розподілом Гаусса із від'ємним середнім значенням `μ_E ≈ -2.5 В` та дисперсією `σ_E ≈ 0.30 В`. Негативне значення порогової напруги обумовлене тим, що під час блочного стирання з затвора вилучаються всі вільні електрони, і в каналі транзистора залишається лишковий позитивний потенціал. Дисперсія `σ_E` виникає через фізичну нерівномірність товщини тунельного оксиду та локальні розкиди концентрації доповідових домішок уздовж кремнієвого каналу.

Формула щільності ймовірності початкового піку стирання дорівнює:

```
P(V_th) = ( 1 / ( √(2·π) · σ_E ) ) · exp( - ( V_th - μ_E )² / ( 2 · σ_E² ) )
```

#### 2. Динаміка ISPP та фінальна ширина програмованого піку

Під час програмування імпульси напруги `V_pgm` з приростом `ΔV_pgm` подаються на керівний затвор доти, доки порогова напруга комірки не перетне рівень верифікації `V_verify,k` для цільового стану `k`. Процес супроводжується внутрішнім інжекційним шумом, який викликається статистичними флуктуаціями кількості тунелюючих електронів у кожному імпульсі.

Підсумкова дисперсія програмованого порогового піку `σ_pgm` визначається величиною кроку приросту `ΔV_pgm` та інжекційним шумом:

```
σ_pgm ≈ ( ΔV_pgm / 2 ) + σ_inject
```

Зменшення `ΔV_pgm` дозволяє зробити порогові піки вужчими, проте це збільшує кількість імпульсів програмування та погіршує затримку запису сторінки (`t_PROG`). Наприклад, зменшення `ΔV_pgm` з `0.40 В` до `0.15 В` звужує стандартне відхилення піку `σ` на 60%, але подвоює час програмування `t_PROG`.

#### 3. Перехресне наведення (Program Disturb) та паразитний зв'язок

Програмування сусідньої комірки викливає паразитне збільшення порогової напруги розглянутої комірки на величину `δV_disturb` через ємнісний зв'язок між затворами:

```
δV_disturb = γ_cross · ΔV_th_neighbor
```

де `γ_cross ≈ 0.05 - 0.10` — коефіцієнт паразитної ємнісної наводки (у 3D CTF зменшений до `< 0.01`).

#### 4. Флуктуації RTN та логарифмічний витік retention

Випадкове захоплення та вивільнення поодиноких електронів у пастках тунельного оксиду викликає дискретний флуктуючий шум RTN (Random Telegraph Noise) з нульовим середнім та дисперсією `σ_RTN`, яка зростає зі збільшенням кількості P/E циклів.

Тепловий витік заряду через дефекти оксиду за час `t` викликає зсув порогової напруги вниз за логарифмічним законом розряджання:

```
ΔV_retention(t) = - α_ret · ln( 1 + t / t_0 )
```

де `α_ret` — коефіцієнт деградації оксиду (пропорційний `√N_PE`), а `t_0 ≈ 1 сек` — характеристичний час релаксації.

#### 5. Температурний коефіцієнт прискорення Arrhenius

Високі температури суттєво прискорюють термічну десорбцію електронів із пасток. Для симуляції збереження даних при високій температурі (наприклад, `T_stress = 85 °C`) використовується модель Арреніуса з еквівалентним прискоренням часу `A_T`:

```
A_T = exp( ( E_a / k_B ) · ( ( 1 / T_use ) - ( 1 / T_stress ) ) )
```

де `E_a ≈ 1.1 еВ` — енергія активації дефектів оксиду, `k_B = 8.617 · 10⁻⁵ еВ/К` — стала Больцмана, `T_use = 298 К` (`25 °C`), `T_stress = 358 К` (`85 °C`). Фізичний розрахунок показує, що витримка накопичувача при `85 °C` протягом 100 годин еквівалентна зберіганню даних при кімнатній температурі `25 °C` упродовж понад 2 років!

### Апаратна фізика підсилювача зчитування (Sense Amplifier Dynamics)

Фізичне вимірювання порогової напруги `V_th` напівпровідникової комірки у складі матриці здійснюється за допомогою аналогово-цифрового підсилювача зчитування (Sense Amplifier).

Зчитування відбувається у три послідовні фізичні фази:
1. **Попередня зарядка бітової лінії (Precharge Phase)** — бітова лінія `Bit Line` (BL) заряджається джерелом струму до фіксованого потенціалу `V_BL ≈ 0.7 В`, після чого вхід підсилювача переводиться в режим високого імпедансу.
2. **Подача опорної напруги зчитування (Sensing Phase)** — до керуючого затвора `CG` обраної комірки прикладається опорна напруга `V_ref,k`, а до затворів усіх інших необраних комірок струни — напруга пропускання `V_pass ≈ 6.0 В`.
   - Якщо порогова напруга комірки `V_th > V_ref,k`, транзистор залишається закритим. Бітова лінія не розряджається, і потенціал `V_BL` залишається високим (`1`).
   - Якщо порогова напруга комірки `V_th ≤ V_ref,k`, транзистор відкривається, створюючи інверсійний канал. Струм каналу `I_cell ≈ 10-50 нА` розряджає ємність бітової лінії `C_BL`, і потенціал `V_BL` падає до нуля (`0`).
3. **Стробування та порівняння (Strobe Phase)** — після закінчення часу інтегрування `t_SENSE ≈ 15-25 μs` компаратор підсилювача порівнює напругу `V_BL` з порогом спрацьовування тригера.

```
       Фаза зарядки BL                   Фаза інтегрування струму каналу
 V_BL ───┐                                 V_BL ───┐
         │                                         │  (Якщо V_th > V_ref: Закрито, V_BL стабільна)
         │ I_precharge                             ├───------------------------- V_BL_high
         ▼                                         │ ╲
      ───┴─── C_BL                                 │  ╲ (Якщо V_th <= V_ref: Відкрито, струм I_cell)
      ───────                                      └───┴──────────────────────── V_BL_low
                                                        t_SENSE
```

Час інтегрування `t_SENSE` зв'язаний з ємністю бітової лінії `C_BL` та струмом комірки `I_cell` співвідношенням:

```
t_SENSE = ( C_BL · ΔV_BL_sense ) / I_cell
```

У багатобітних комірках TLC та QLC для визначення логічного стану однієї фізичної комірки необхідно провести кілька послідовних фаз зчитування `t_SENSE` з різними опорними напругами `V_ref`, що пояснює зростання затримки зчитування сторінки (`t_R`) від `25 μs` у SLC до `80-120 μs` у QLC.

### Фізична організація логічних сторінок (Page Mapping)

У багатобітних комірках один фізичний транзистор зберігає кілька бітів інформації, які належать до **різних логічних сторінок** пам'яті (Lower Page, Middle Page, Upper Page, Top Page).

Для 3-бітної комірки TLC (8 станів) розподіл бітів по трьох сторінках підпорядковується кодуванню Грея:

```
Стан комірки    Порогова напруга V_th       Lower Page (LSB)    Middle Page (CSB)   Upper Page (MSB)
E ('111')       V_th < V_R1                 1                   1                   1
P1 ('110')      V_R1 <= V_th < V_R2         1                   1                   0
P2 ('101')      V_R2 <= V_th < V_R3         1                   0                   0
P3 ('100')      V_R3 <= V_th < V_R4         1                   0                   1
P4 ('011')      V_R4 <= V_th < V_R5         0                   0                   1
P5 ('010')      V_R5 <= V_th < V_R6         0                   0                   0
P6 ('001')      V_R6 <= V_th < V_R7         0                   1                   0
P7 ('000')      V_th >= V_R7                0                   1                   1
```

З аналізу кодування видно принципову відмінність у швидкості зчитування різних сторінок:
- Для зчитування **Lower Page (LSB)** контролеру достатньо провести лише **1 вимірювання** при опорній напрузі `V_R4`, оскільки біт LSB змінюється з `1` на `0` рівно один раз посередині діапазону. Затримка зчитування LSB є мінімальною (`t_R ≈ 35 μs`).
- Для зчитування **Middle Page (CSB)** необхідно виконати **2 вимірювання** при напругах `V_R2` та `V_R6`.
- Для зчитування **Upper Page (MSB)** необхідно виконати **4 вимірювання** при напругах `V_R1`, `V_R3`, `V_R5`, `V_R7`, що вимагає максимального часу (`t_R ≈ 90 μs`).

Ця асиметрія затримок враховується FTL-контролером: критичні системні таблиці метаданих та операції швидкого кешування завжди записуються в нижні сторінки (Lower Pages) або в спеціальний режим SLC-кешу.

### Детальний аналіз алгоритму та використаних математичних методів

Перед розглядом вихідного коду розберемо ключові інженерні та математичні рішення, покладені в основу симулятора:

1. **Генерація нормального розподілу Гаусса.** Для відтворення фізичних флуктуацій `V_th`, шуму RTN та інжекційного шуму необхідно генерувати випадкові числа з нормальним розподілом. У вкладці C++ використано стандартну бібліотеку `<random>` з генератором Mersenne Twister `std::mt19937` та обгорткою `std::normal_distribution`. У вкладці C реалізовано алгоритм Бокса-Мюллера (Box-Muller transform), який перетворює два незалежних рівномірно розподілених випадкових числа `u_1, u_2 ∈ (0, 1]` у пару стандартних нормальних випадкових величин:
   ```
   z_0 = √( -2 · ln(u_1) ) · cos( 2 · π · u_2 )
   ```
2. **Кодування Грея (Gray Code Mapping).** У багатобітних комірках MLC, TLC та QLC сусідні порогові рівні відрізняються кодуванням лише в оцідному біті. Наприклад, для 2-бітної MLC використано послідовність `'11'` (Erased), `'10'`, `'01'`, `'00'`. Це гарантує, що при помилковому зміщенні порогової напруги в сусідній рівень виникає лише 1 бітова помилка замість двох, що знижує RBER удвічі.
3. **Обчислення бітових помилок через XOR.** Перевірка розбіжностей між записаним станом `cell.target_state` та декодованим станом `detected_state` виконується через побітову операцію виключного АБО (`target ^ detected`), після чого підраховується кількість одиничних бітів у масці різниці.
4. **Структурна уніфікація багатобітного вимірювання.** Модель автоматично масштабує кількість цільових станів `N_states = 2^N` залежно від вибраного типу комірки (SLC = 2, MLC = 4, TLC = 8, QLC = 16), вираховуючи сітку порогових напруг `V_verify` та опорних рівнів `V_ref` у заданому фізичному вікні `6.0 В`.
5. **Фізична адаптація зношування (Wear Leveling)**. Числова симуляція відстежує рівень накопиченого оксидного пошкодження `oxide_damage = √(pe_cycles / 1000)`. Це відтворює спостережувану в експериментах залежність генерації пасток `N_ot ∝ √N_PE`, за якою першие 100 P/E циклів створюють найбільшу відносну деструкцію оксиду.
6. **Ітеративна математична графова модель Tanner LDPC**. Ітеративний процес декодування LDPC розгортається на біпартній структурі графа Таннера, де бітові вузли (Variable Nodes) та перевірочні вузли (Check Nodes) обмінюються LLR-повідомленнями. Застосування м'якого зчитування додає аналогову надійність до початкових імовірностей, що піднімає коефіцієнт корекції помилок на 1-2 порядки.
7. **Оптимізація пам'яті для масиву з 100,000 комірок**. У програмній реалізації структура `Cell` вирівняна до 16 байтів. Виділення пам'яті під 100 000 комірок вимагає всього 1.6 Мегабайта оперативної пам'яті, що забезпечує ідеальну локальність кешу процесора (L1/L2 Cache locality) та високу швидкість симуляції (понад 1 мільйон комірок за секунду).
8. **Симуляція виснаження динамічного SLC-кешу (SLC Cache Exhaustion Physics)**. У комерційних накопичувачах TLC/QLC частка заблокованих блоків виділяється під SLC-режим, де кодується лише 1 біт на комірку з розширеним пороговим вікном `ΔV_state ≈ 4 В`. Коли SLC-кеш виснажується під час тривалого послідовного запису, контролер змушений проводити пряме TLC/QLC програмування (Direct-to-TLC/QLC write) з фоновим витісненням даних (Folding), що знижує швидкість запису в 5–10 разів і подвоює показник зношування WAF (Write Amplification Factor).
9. **Паралельне сканування сторінок (Multi-Plane Operations Physics)**. У реальних кристалах NAND масив комірок розділено на 2 або 4 незалежні фізичні площини (Planes). Моделювання паралельного зчитування показує, що подача однакових опорних напруг `V_ref` на всі площини одночасно подвоює пропускну здатність шини даних, проте вимагає подвійної потужності підсилювачів зчитування.

### Детальний аналіз та інтерпретація фізичних результатів

Результати числового моделювання 100 000 комірок демонструють стрімке зростання рівня первинних бітових помилок (RBER) при переході від однобітних комірок SLC до багатобітних QLC.

```
Тип комірки      Кількість станів   Ширина порогового вікна   RBER після 1000 год (55°C)
SLC (1 біт)      2 стани            ΔV_state ≈ 4.0 В          RBER < 10⁻⁸ (практично 0)
MLC (2 біти)     4 стани            ΔV_state ≈ 1.5 В          RBER ≈ 10⁻⁵
TLC (3 біти)     8 станів           ΔV_state ≈ 0.7 В          RBER ≈ 2.5 · 10⁻³
QLC (4 біти)     16 станів          ΔV_state ≈ 0.35 В         RBER ≈ 1.8 · 10⁻²
```

Фізична причина цієї закономірності полягає у звуженні порогового вікна між сусідніми логічними станами. Загальний робочий діапазон напруг `V_th` контролера обмежений величиною `6.0 В` (від `-2.0 В` до `+4.0 В`), оскільки вищі напруги викликали б прискорений пробій тунельного оксиду.
- У пам'яті **SLC** 6 Вольт діляться всього на 2 стани. Запас відстані між піками становить понад 4 Вольти. Навіть при сильному розмитті `V_th` через RTN-шум чи витік заряду гаусові піки не перекриваються, і рівень помилок RBER прямує до нуля.
- У пам'яті **QLC** ті самі 6 Вольт діляться вже на 16 дискретних станів. Відстань між центрами сусідніх піків зменшується до `0.35 В` (350 мілівольт). Оскільки дисперсія піку після ISPP становить `σ ≈ 0.10 В`, витік заряду всього на `0.15 В` переміщує хвіст гауссового розподілу за межу опорної напруги `V_ref`, створюючи масивні бітові помилки.

#### Математична модель м'якого декодування LDPC та відношення правдоподібності LLR

Коли рівень помилок RBER перевищує поріг жесткого декодування (`> 10⁻³` у TLC та QLC), контролер SSD переходить від жорстких бінарних рішень (`0` або `1`) до імовірнісного декодування LDPC за допомогою відношення логарифмів правдоподібності (Log-Likelihood Ratio, LLR).

Значення `LLR` для зчитаної напруги комірки `V_th` обчислюється контролером на основі умовної ймовірності Гаусса:

```
LLR( V_th ) = ln( P( b = 0 | V_th ) / P( b = 1 | V_th ) )
            = ( ( V_th - μ_1 )² / ( 2 · σ_1² ) ) - ( ( V_th - μ_0 )² / ( 2 · σ_0² ) ) + ln( σ_1 / σ_0 )
```

Якщо зчитана напруга знаходиться глибоко всередині порогового піку другого стану, значення `LLR` є високим позитивним числом, що свідчить про високу впевненість декодера. Якщо ж напруга `V_th` опинилася в зоні перекриття двох сусідніх піків, `LLR` наближається до нуля, повідомляючи ітеративному декодеру LDPC про низький ступінь довіри до даного біта.

Для отримання точності LLR контролер виконує процедуру **Read Retry** — повторне зчитування сторінки пам'яті зі зсувом опорних напруг `V_ref` на `±20 мВ`, `±40 мВ`, `±60 мВ`, збираючи 3–4 біти м'якої квантованої інформації (Soft-decision bits) про кожен осередковий аналоговий рівень.

#### Динамічне відстеження порогових піків (Threshold Tracking)

З часом під дією високої температури та накопичення P/E циклів центри гауссових піків `μ_k` зсуваються вліво внаслідок витоку електронів, а їхні ширини `σ_k` розширюються. Зчитування за замовчувальними фіксованими напругами `V_ref` призводить до того, що опорний поріг опиняється не в точці мінімуму перетинів щільностей імовірностей, а на схилі одного з піків, що драматично підвищує RBER.

У сучасних накопичувачах FTL-контролер постійно виконує адаптивне калібрування порогових напруг (Threshold Tracking). За допомогою фонових статистичних вимірювань контролер визначає оптимальні точки перетину сусідніх гауссових розподілів `V_ref,opt`:

```
V_ref,opt : P_k( V_ref,opt ) = P_{k+1}( V_ref,opt )
```

Обчислення оптимуму `V_ref,opt` для двох сусідніх піків із параметрами `(μ_k, σ_k)` та `(μ_{k+1}, σ_{k+1})` зводиться до розв'язання квадратного рівняння:

```
( V_ref,opt - μ_k )² / ( 2 · σ_k² ) + ln( σ_k ) = ( V_ref,opt - μ_{k+1} )² / ( 2 · σ_{k+1}² ) + ln( σ_{k+1} )
```

Адаптивне зсунення напруг зчитування `V_ref` дозволяє знизити первинний RBER в 5–10 разів, повертаючи пошкоджену сторінку в зону ефективної корекції LDPC-декодера та продовжуючи реальний фізичний термін служби твердотільних накопичувачів на роки.

#### Вплив завади Read Disturb при тривалому зчитуванні

Окремим практичним ефектом деградації є шум Read Disturb. Під час зчитування обраного слова пам'яті до затворів усіх необраних комірок тієї самої струни NAND прикладається підвищена напруга пропускання `V_pass ≈ 6.0 В` для відкриття їхніх каналів у режим високої провідності.

Хоча напруга `V_pass = 6.0 В` є значно нижчою за програмуючу напругу `V_pgm = 20 В`, тривале повторення мільйонів операцій зчитування створює слабке поле Фаулера-Нордгейма. Електрони повільно інжектуються у плаваючий затвор необраних комірок, поступово зміщуючи їхні порогові напруги праворуч вгору (`ΔV_th,read ∝ N_reads`). Для запобігання пошкодженню даних FTL-контролер підраховує кількість зчитувань кожного блоку і при досягненні порогу `N_read,max ≈ 10⁵ - 10⁶` виконує фонове перезаписування даних у новий блок (Read Refresh).
