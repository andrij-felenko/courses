# 🧮 Математична модель підпорогового та запорогового підсилення

Ця вставка містить виведення математичних рівнянь, що описують оптичне підсилення в напівпровідниковому середовищі, умову виникнення квазіінверсії населеності Бернарда-Дюрафура, статичні та динамічні рівняння швидкостей (Rate Equations), пороговий стан резонатора Фабрі-Перо, розрахунок релаксаційних коливань, асиметрію відбиття дзеркал, спектральне звуження ліній, теплову модель та квантово-розмірну густину станів.

### 1. Квантовий транспорт, густина станів та критерій Бернарда-Дюрафура

У напівпровіднику процес поглинання або випромінювання фотона з енергією `E = h·ν` визначається спільною густиною станів валентної зони та зони провідності, а також ймовірностями заповнення цих станів електронами та дірками. Для тривимірного об'ємного напівпровідника (Bulk Semiconductor) зважена спільна густина станів `ρ_r(h·ν - E_g)` залежить від ефективних мас електрона `m_e*` та дірки `m_h*`:

```
ρ_r(h·ν - E_g) = (1 / (2·π²)) · ((2·m_r*) / ℏ²)³ᐟ² · √(h·ν - E_g)
```

де `m_r* = (m_e* · m_h*) / (m_e* + m_h*)` — зведена ефективна маса носіїв заряду.

Під дією сильної інжекції носіїв рівноважний розподіл Фермі-Дірака розпадається на два окремі квазірівноважні розподіли з квазірівнями Фермі `F_c` (для електронів у зоні провідності) та `F_v` (для дірок у валентній зоні):

```
f_c(E_c) = 1 / (1 + exp((E_c - F_c) / (k_B·T)))
f_v(E_v) = 1 / (1 + exp((E_v - F_v) / (k_B·T)))
```

Швидкість вимушеного випромінювання на одиницю об'єму пропорційна ймовірності заповнення верхнього стану електроном `f_c` та незаповнення нижнього стану діркою `(1 - f_v)`. Натомість швидкість поглинання пропорційна ймовірності наявності електрона внизу `f_v` та вільного стану вгорі `(1 - f_c)`. Чистий коефіцієнт матеріального підсилення `g_mat(h·ν)` пропорційний різниці цих двох швидкостей:

```
g_mat(h·ν)
∝ f_c·(1 - f_v) - f_v·(1 - f_c)   [різниця швидкостей випромінювання та поглинання]
= f_c - f_c·f_v - f_v + f_c·f_v     [розкриття дужок]
= f_c - f_v                         [взаємне скорочення доданків f_c·f_v]
```

Щоб отримати додатне матеріальне підсилення (`g_mat > 0`), вимагається виконання умови `f_c(E_c) > f_v(E_v)`:

```
1 / (1 + exp((E_c - F_c) / (k_B·T))) > 1 / (1 + exp((E_v - F_v) / (k_B·T)))
⇒ (E_c - F_c) < (E_v - F_v)          [обернення нерівності для знаменників]
⇒ E_c - E_v < F_c - F_v              [перегрупування доданків]
```

Оскільки енергія випроміненого або поглинутого фотона становить `h·ν = E_c - E_v`, отримана нерівність виражає фундаментальний **критерій Бернарда-Дюрафура** (*Bernard-Duraffourg condition*):

```
F_c - F_v > h·ν > E_g
```

Цей критерій показує, що для виникнення оптичного підсилення енергетичний розрив між квазірівнями Фермі повинен перевищувати квант випромінюваного світла `h·ν`, який сам по собі є більшим за ширину забороненої зони `E_g`. При підключенні напівпровідника до джерела напруги `V` різниця квазірівнів Фермі прямо пов'язана з прикладеним потенціалом: `F_c - F_v = q·V`. Отже, мінімальна електрична напруга на p-n переході для виникнення підсилення становить `V_min = E_g / q`.

### 2. Лінеаризована модель матеріального підсилення та насичення

У прямозонному напівпровідникові матеріальне підсилення `g_mat` залежить від загальної концентрації інжектованих електронів `n`. У робочому діапазоні поблизу порогу генерації цю залежність лінеаризують:

```
g_mat(n) = a·(n - n_tr)
```

де:
- `a = dg/dn` — диференціальне підсилення (*differential gain*), яке описує ефективність зростання підсилення при збільшенні концентрації носіїв (для об'ємного `GaAs` значення `a ≈ (2.0 – 2.5)·10⁻¹⁶ см²`, для квантових ям `a ≈ (3.5 – 5.0)·10⁻¹⁶ см²`);
- `n_tr` — прозора концентрація носіїв (*transparency carrier density*), при якій швидкість поглинання точно дорівнює швидкості вимушеного випромінювання (`g_mat = 0`). Для `GaAs` прозора концентрація становить `n_tr ≈ (1.2 – 1.8)·10¹⁸ см⁻³`.

При високих інтенсивностях світлового поля у резонаторі виникає феномен **насичення підсилення** (*gain saturation*). Через обмежену швидкість внутрішньозонної релаксації носіїв фотони вимушено виснажують електронні стани швидше, ніж вони поповнюються електричним струмом. Для врахування цього ефекту коефіцієнт підсилення модифікують формулою:

```
g(n, S) = (a · (n - n_tr)) / (1 + ε_s · S)
```

де `S` — концентрація фотонів у резонаторі, а `ε_s` — коефіцієнт нелінійного насичення підсилення (типово `ε_s ≈ 10⁻¹⁷ см³`).

Оскільки світлова хвиля лише частково перекривається з геометричним об'ємом активної зони, вводять **коефіцієнт оптичного утримання** `Γ` (*confinement factor*). Модове підсилення `g_mod`, яке безпосередньо діє на хвилю в хвилеводі, дорівнює:

```
g_mod = Γ · g_mat = Γ · a · (n - n_tr)
```

### 3. Рівняння швидкостей (Rate Equations) лазерного діода

Динаміка та стаціонарний стан напівпровідникового лазера описуються системою двох зв'язаних диференціальних **рівнянь швидкостей** (*rate equations*). Перше рівняння визначає баланс концентрації носіїв `n(t)`, а друге — баланс концентрації фотонів `S(t)` в об'ємі резонатора.

```
dn/dt = J / (q · d) - R(n) - v_g · g_mod(n) · S
dS/dt = Γ · v_g · g_mod(n) · S - S / τ_p + Γ · R_sp
```

де:
- `J = I / (w · L)` — густина прямого струму інжекції (А/см²);
- `d` — товщина активної зони (см);
- `v_g = c / n_g` — групова швидкість світла у хвилеводі (см/с);
- `R(n)` — повна швидкість спонтанної та безипромінювальної рекомбінації (см⁻³·с⁻¹);
- `τ_p` — час життя фотона в резонаторі (с);
- `R_sp = β_sp · B · n²` — внесок спонтанного випромінювання у лазерну моду (`β_sp ≈ 10⁻⁴`).

Час життя фотона в резонаторі `τ_p` визначається сумарними втратами на внутрішнє поглинання `α_i` та дзеркальне випромінювання `α_m`:

```
τ_p = 1 / (v_g · (α_i + α_m))
```

У стаціонарному режимі генерації похідні за часом дорівнюють нулю (`dn/dt = 0`, `dS/dt = 0`). Із нехтуванням дрібним спонтанним доданком `R_sp` у другому рівнянні отримуємо умову стаціонарності фотонного поля:

```
Γ · v_g · g_mod(n_th) · S - S / τ_p = 0
⇒ Γ · v_g · g_mod(n_th) = 1 / τ_p
⇒ Γ · v_g · g_mod(n_th) = v_g · (α_i + α_m)       [підставили вираз для 1/τ_p]
⇒ g_mod_th = (α_i + α_m) / Γ                      [скоротили групову швидкість v_g]
```

Отже, порогове матеріальне підсилення `g_mat_th` точно компенсує суму внутрішніх та дзеркальних втрат, поділену на коефіцієнт утримання `Γ`.

### 4. Умова балансу підсилення та втрат у резонаторі Фабрі-Перо

Розглянемо оптичний резонатор Фабрі-Перо довжиною `L` з коефіцієнтами відбиття за інтенсивністю на торцевих гранях `R₁` та `R₂`. 

Нехай хвиля з початковою інтенсивністю `I₀` стартує від лівого дзеркала і робить повний прохід туди й назад (дистанція `2·L`). Зміна інтенсивності хвилі підпорядковується закону Бугера-Ламберта-Бера з урахуванням внутрішніх втрат `α_i` (втрати на вільних носіях та розсіювання):

```
I(2L) = I₀ · R₁ · R₂ · exp(2 · (g_mod - α_i) · L)
```

Для виникнення стаціонарної лазерної генерації інтенсивність після обходу резонатора повинна точно дорівнювати початковій `I(2L) = I₀`:

```
I₀ · R₁ · R₂ · exp(2 · (g_mod_th - α_i) · L) = I₀
⇒ R₁ · R₂ · exp(2 · (g_mod_th - α_i) · L) = 1      [скоротили початкову інтенсивність I₀]
⇒ exp(2 · (g_mod_th - α_i) · L) = 1 / (R₁ · R₂)     [поділили на коефіцієнти відбиття R₁·R₂]
⇒ 2 · (g_mod_th - α_i) · L = ln(1 / (R₁ · R₂))       [взяли натуральний логарифм від обох частин]
⇒ g_mod_th - α_i = (1 / (2·L)) · ln(1 / (R₁ · R₂))   [поділили на 2L]
```

Отже, **порогове модове підсилення** `g_mod_th` дорівнює сумі внутрішніх та дзеркальних втрат:

```
g_mod_th = α_i + α_m
```

де дзеркальні втрати `α_m` виражаються формулою:

```
α_m = (1 / (2·L)) · ln(1 / (R₁ · R₂))
```

Для асиметрично покритих граней резонатора (наприклад, заднє дзеркало з високим відбиттям `R₁ = 0.95` та переднє вихідне дзеркало `R₂ = 0.05`) дзеркальні втрати в резонаторі довжиною `L = 300 мкм` становить:

```
α_m = (1 / (2 · 0.03 см)) · ln(1 / (0.95 · 0.05))
= 16.67 см⁻¹ · ln(21.05)                             [обчислили коефіцієнт 1/(2L) та добуток R1·R2]
= 16.67 · 3.047                                      [взяли логарифм ln(21.05)]
= 50.8 см⁻¹                                         [підсумкове значення дзеркальних втрат]
```

### 5. Рекомбінаційна модель ABC та розрахунок порогового струму

Порогова концентрація носіїв `n_th` знаходиться підставленням `g_mod_th` у лінеаризовану модель підсилення:

```
Γ · a · (n_th - n_tr) = α_i + α_m
⇒ n_th - n_tr = (α_i + α_m) / (Γ · a)               [поділили на (Γ · a)]
⇒ n_th = n_tr + (α_i + α_m) / (Γ · a)               [перенесли n_tr у праву частину]
```

Для визначення порогового струму інжекції `I_th` необхідно просумувати всі канали електронної рекомбінації в активній зоні при пороговій концентрації `n = n_th`. У напівпровідниках використовують феноменологічну **ABC-модель рекомбінації**:

```
R(n) = R_SRH + R_rad + R_Auger = A·n + B·n² + C·n³
```

де:
- `A` — коефіцієнт безипромінювальної рекомбінації Шокли-Рида-Холла на дефектах та пастках кристалічної ґратки (типово `A ≈ 10⁷ – 10⁸ с⁻¹`);
- `B` — коефіцієнт межзонної спонтанної випромінювальної рекомбінації (для `GaAs` значення `B ≈ 10⁻¹⁰ см³/с`);
- `C` — коефіцієнт тричастинкової безипромінювальної Оже-рекомбінації (*Auger recombination*), при якій енергія рекомбінації електронно-діркової пари віддається третьому носію (для `GaAs` значення `C ≈ 10⁻³⁰ см⁶/с`, проте у довгохвильових лазерах на `InGaAsP` `λ = 1.55 мкм` значення `C` зростає на два порядки, визначаючи основні втрати при нагріванні).

Загальний пороговий струм інжекції `I_th` для геометричного об'єму активної зони `V = w · d · L` визначається рівнянням:

```
I_th = q · V · R(n_th) = q · w · d · L · (A·n_th + B·n_th² + C·n_th³)
```

У разі використання квантових ям товщину `d` зменшують із `100 нм` до `8 нм`, що знижує об'єм `V` у 12 разів, приводячи до пропорційного падіння порогового струму від 50 мА до 4 мА.

### 6. Диференціальна ефективність та вихідна оптична потужність

Вище порогу (`I > I_th`) концентрація носіїв затискається на пороговому рівні `n = n_th`, оскільки будь-яка додаткова інжекція носіїв миттєво знімається вимушеним випромінюванням. Усі додатково інжектовані електрони перетворюються на лазерні фотони.

Зовнішня диференціальна квантова ефективність `η_d` виражає частку генерованих фотонів, що виходять крізь дзеркала назовні:

```
η_d = η_i · (α_m / (α_i + α_m))
```

де `η_i` — внутрішній квантовий вихід рекомбінації (типово `η_i ≈ 0.90 – 0.95`).

Оскільки кожен випромінений фотон має енергію `E = h·ν`, похідна потужності за струмом (крутизна ват-амперної характеристики) становить:

```
dP / dI = η_d · (h·ν / q)
```

Інтегруючи це рівняння від порогу `I_th`, отримуємо підсумкову формулу для **вихідної оптичної потужності** лазерного діода:

```
P(I) = 0 ,  при I ≤ I_th
P(I) = (h·ν / q) · η_d · (I - I_th) ,  при I > I_th
```

Для лазерного діода з довжиною хвилі `λ = 808 нм` енергія фотона становить `h·ν / q = 1.535 В`. При диференціальній ефективності `η_d = 0.8` нахил ват-амперної характеристики дорівнює `dP/dI = 1.535 · 0.8 = 1.23 Вт/А` (або `1.23 мВт/мА`).

### 7. Динамічний відгук та розрахунок частоти релаксаційних коливань

При малих збуреннях прямого струму інжекції `I(t) = I₀ + δI(t)` концентрація носіїв та фотонів зазнає згасаючих релаксаційних коливань. Для знаходження частоти цих коливань лінеаризують систему рівнянь швидкостей відносно стаціонарних значень `n₀ = n_th` та `S₀`:

```
d(δn)/dt = -γ_n · δn - v_g · a · S₀ · δn - v_g · g_th · δS
d(δS)/dt = Γ · v_g · a · S₀ · δn
```

Шукаючи розв'язок у вигляді `exp(s·t)`, отримуємо характеристичне рівняння другого порядку:

```
s² + 2·γ_r·s + ω_r² = 0
```

де резонансна колова частота релаксаційних коливань `ω_r` виражається через стаціонарну концентрацію фотонів `S₀`:

```
ω_r = √(Γ · v_g² · a · g_th · S₀) = √((v_g · a · S₀) / τ_p)
```

Оскільки стаціонарна концентрація фотонів `S₀` прямо пропорційна надлишковому струму інжекції `(I - I_th)`, резонансна частота зростає пропорційно квадратному кореню зі струму: `f_r ∝ √(I - I_th)`. 

Максимальна смуга прямої модуляції лазерного діода за рівнем -3 дБ прямо пов'язана з релаксаційною частотою:

```
f_3dB ≈ 1.55 · f_r = (1.55 / (2·π)) · √((v_g · a · S₀) / τ_p)
```

Для досягнення надвисоких швидкостей модуляції (понад 25 Гбіт/с у сучасних волоконно-оптичних лініях) інженери прагнуть максимізувати диференціальне підсилення `a` шляхом застосування деформованих квантових ям та зменшення часу життя фотона `τ_p`.

### 8. Асиметрія вихідної потужності граней кристала

У практичних лазерних діодах задню грань кристала покривають високовідбивним дзеркальним покриттям (High Reflectivity, HR з `R₁ ≈ 0.90 – 0.98`), а передню грань — просвітлюючим або частково відбиваючим покриттям (Anti-Reflective / Partial Reflective, AR з `R₂ ≈ 0.02 – 0.10`).

Асиметрія відбиття граней дозволяє спрямувати майже всю оптичну потужність крізь переднє вихідне вікно. Співвідношення оптичних потужностей, що випромінюються крізь передню `P_front` та задню `P_rear` грані, розраховується за формулою:

```
P_front / P_rear = ((1 - R₂) / (1 - R₁)) · √(R₁ / R₂)
```

Якщо задня грань має `R₁ = 0.95`, а передня `R₂ = 0.05`, то співвідношення потужностей становить:

```
P_front / P_rear = ((1 - 0.05) / (1 - 0.95)) · √(0.95 / 0.05)   [підставили чисельні значення R1=0.95 та R2=0.05]
= (0.95 / 0.05) · √19                                         [спростили різниці у дужках]
= 19 · 4.359                                                  [обчислили частку 0.95/0.05 та корінь √19]
= 82.8                                                        [підсумкове значення співвідношення потужностей]
```

Отже, понад 98.8% усієї генерованої лазерної потужності виходить крізь передню грань, тоді як слабкий вихід крізь задню грань (1.2%) використовують для освітлення вбудованого фотодіода зворотної связі (Monitor Photodiode), який забезпечує автоматичне регулювання потужності лазера у процесі роботи.

### 9. Аналітичний спектральний контур та звуження лінії над порогом

У підпороговому режимі лазерний діод випромінює спонтанний спектр, ширина якого задається температурною енергією носіїв `k_B·T` і становить 20–40 нм. При досягненні порогу генерації оптичне підсилення середовища `g_mod` наближається до загальних втрат `α_loss = α_i + α_m`.

Інтенсивність окремої поздовжньої моди резонатора з порядковим номером `m` під час проходження крізь підсилююче середовище описується співвідношенням Фабрі-Перо:

```
I_m(ν) = I_sp / (1 - 2 · R · exp(g_mod(ν) · L) · cos(2·π·ν·n_eff·L / c) + R² · exp(2·g_mod(ν)·L))
```

Для центральної моди, де умова резонансу виконується точно (`cos(...) = 1`), знаменник наближається до нуля при `g_mod → g_th`. В результаті інтенсивність центральної моди вибухово зростає, тоді як бічні моди підсилюються значно слабше.

Це призводить до спектрального звуження (*spectral narrowing*): напівширина спектрального контуру випромінювання `Δν_laser` зменшується обернено пропорційно вихідній оптичній потужності `P_opt`, що задається напівпровідниковою модифікацією формули Шокли-Таунса-Генрі:

```
Δν_laser = ((h · ν · v_g² · α_m · g_th · n_sp) / (4 · π · P_opt)) · (1 + α_H²)
```

де `n_sp` — коефіцієнт неповного інверсного заповнення (*spontaneous emission factor* `n_sp = n / (n - n_tr)`), а `α_H` — фактор розширення лінії Генрі. Наявність додаткового множника `(1 + α_H²)` (де `α_H ≈ 3 – 6`) є унікальною рисою напівпровідникових лазерів, пояснюючи, чому їхня спектральна лінія є у 10–50 разів ширшою за спектральні лінії газових або твердотільних лазерів із такою самою потужністю.

### 10. Теплова модель P-N гетеропереходу та розрахунок температури активної зони

Вся споживана електрична потужність, яка не перетворилася на оптичне випромінювання, перетворюється на тепло безпосередньо в об'ємі активної зони та на омічних опорах контактів. Теплова потужність `Q_heat` виражається формулою:

```
Q_heat = I · V - P_opt = I · (E_g / q + I · R_s) - P_opt
```

Стаціонарна температура активної зони `T_j` перевищує температуру радіатора чи підкладки `T_sub` на величину, пропорційну тепловому опору структури `R_th` (вимірюється в К/Вт):

```
T_j = T_sub + R_th · Q_heat
```

Для стандартного лазерного діода у корпусі TO-can тепловий опір становить `R_th ≈ 20 – 40 К/Вт`. При електричній потужності 200 мВт та ККД 40% (оптична потужність 80 мВт, теплова потужність 120 мВт) температура активної зони зростає на `ΔT = 35 К/Вт · 0.12 Вт = 4.2 К`.

Зростання температури `T_j` призводить до двох негативних наслідків:
1. **Зростання порогового струму**: Оскільки безипромінювальна рекомбінація та витікання носіїв зростають експоненційно, порогова густина струму описується формулою Фікса `J_th(T_j) = J_0 · exp(T_j / T_0)`.
2. **Падіння диференціального ККД**: Внутрішній квантовий вихід `η_i(T_j)` зменшується через розмивання квазірівнів Фермі за формулою `η_i(T_j) = η_i0 · exp(-T_j / T_eta)`.

Поєднання цих двох факторів створює нелінійну позитивний зворотний зв'язок між струмом та температурою, що призводить до теплового обриву генерації (Thermal Rollover) та задає абсолютну межу максимальної вихідної оптичної потужності лазерного діода.

### 11. Квантово-розмірний ефект та густина станів 2D-газу

При зменшенні товщини активного шару `d` до величин порядку де Бройлівської довжини хвилі електрона (`d ≈ 5 – 10 нм`) рух носіїв уздовж осі `x` стає квантованим. Енергетичний спектр розділяється на дискретні квантові підзони:

```
E_n = (ℏ² · π² · n²) / (2 · m* · d²)
```

Густина станів для кожної підзони в двовимірному електронному газі (2D Electron Gas) перестає залежати від енергії, перетворюючись на східчасту функцію Хевісайда:

```
ρ_2D(E) = (m_r* / (π · ℏ²)) · ∑_n Θ(E - E_n)
```

Це надає квантовим ямам фундаментальні переваги над об'ємними (3D) напівпровідниками:
- **Зменшення прозорої концентрації**: Східчаста густина станів усуває паразітний "хвіст" станів із низькою енергією, які поглинають світло, але не беруть участі в підсиленні. Це знижує `n_tr` з `1.5·10¹⁸ см⁻³` до `4.0·10¹⁷ см⁻³`.
- **Зростання диференціального підсилення**: Диференціальне підсилення `a = dg/dn` зростає у 2–3 рази, що пропорційно підвищує граничну частоту модуляції `f_r` та зменшує фактор розширення лінії Генрі `α_H`.
- **Вплив деформаційного стиснення (Strained Quantum Wells)**: Механічне стиснення квантової ями (наприклад, шар `In₀.₂Ga₀.₈As` на підкладці `GaAs`) розщеплює підзони важких та легких дірок, зменшуючи ефективну масу дірок у площині шару `m_hh*` до величини, близької до маси електрона `m_e*`. Це вирівнює швидкості заповнення квазірівнів Фермі у валентній зоні та зоні провідності, додатково піднімаючи диференціальне підсилення `a` та зменшуючи пороговий струм на 30–50%. Усі ці квантові та деформаційні ефекти лежать в основі проектування високостійких напівпровідникових лазерів для сучасних волоконно-оптичних систем зв'язку та нанофотоніки.
