# 🧮 Математична модель перколяції SILC та статистика пробою Вейбула

Математичний опис деградації тунельного діелектрика SiO₂ у Flash-пам'яті базується на двох суміжних теоріях: електростатиці накопичення об'ємного заряду пасток та квантово-статистичній моделі перколяції витоків SILC і часового пробою діелектрика (TDDB — Time-Dependent Dielectric Breakdown). Ця вставка містить аналітичний вивід формул зсуву порогової напруги, двопасткового тунелювання, перколяційного порогу та статистики Вейбула для ресурсу запису.

## 1. Електростатика зсуву порогової напруги ΔV_th

Розглянемо шар діоксиду кремнію товщиною `t_ox`, розміщений між кремнієвим каналом (`x = 0`) та управляючим затвором або накопичувальним шаром (`x = t_ox`). Під дією тунельного струму Фаулера — Нордгейма в об'ємі діелектрика формується просторовий розподіл негативного захопленого заряду з об'ємною густиною `ρ_ot(x)` [Кл/см³].

Для розрахунку електричного потенціалу `V(x)` скористаємося одновимірним рівнянням Пуассона:

```
d²V(x) / dx² = - ρ_ot(x) / (ε_ox · ε₀)
```

де `ε_ox = 3.9` — відносна діелектрична проникність діоксиду кремнію, а `ε₀ = 8.854·10⁻¹⁴ Ф/см` — електрична стала.

Двічі інтегруючи це рівняння від каналу `x = 0` до затвора `x = t_ox` із граничними умовами для потенціалу на каналі `V(0) = 0`, отримуємо зміну потенціалу на межі з затвором:

```
V(t_ox) = - (1 / (ε_ox · ε₀)) · ∫₀ᵗᵒˣ (t_ox - x) · ρ_ot(x) dx
```

Зсув порогової напруги `ΔV_th`, необхідний для компенсації цього внутрішнього електростатичного поля і збереження початкової інверсії каналу, дорівнює зміні затворного потенціалу, взятому протилежним знаком. Застосовуючи питому ємність тунельного оксиду `C_ox = (ε_ox · ε₀) / t_ox` [Ф/см²], отримуємо загальну інтегральну формулу:

```
ΔV_th = - (1 / C_ox) · ∫₀ᵗᵒˣ (x / t_ox) · ρ_ot(x) dx
```

Ця формула показує фізично важливий факт: пастки, розташовані ближче до затвора (`x → t_ox`), дають максимальний внесок у зсув порогової напруги `ΔV_th`, оскільки множник `x / t_ox` наближається до одиниці. Пастки безпосередньо біля каналу (`x → 0`) майже не створюють електростатичного екранування затворного поля.

Якщо припустити, що генерація об'ємних пасток `N_ot` [см⁻³] відбувається рівномірно по товщині діелектрика (`ρ_ot(x) = - q · N_ot`), то інтеграл спрощується:

```
ΔV_th = (q · N_ot / C_ox) · ∫₀ᵗᵒˣ (x / t_ox) dx
      = (q · N_ot / C_ox) · [x² / (2 · t_ox)]₀ᵗᵒˣ     [первісна від x]
      = (q · N_ot · t_ox) / (2 · C_ox)                [підстановка меж інтегрування]
```

Підставляючи вираз для ємності `C_ox = (ε_ox · ε₀) / t_ox`, отримуємо підсумкову квадратичну залежність від товщини:

```
ΔV_th = (q · N_ot · t_ox²) / (2 · ε_ox · ε₀)
```

Проведемо числовий розрахунок для реальних параметрів сучасних комірок Flash: `t_ox = 8 нм = 8·10⁻⁷ см`, `N_ot = 10¹⁸ см⁻³`, `q = 1.602·10⁻¹⁹ Кл`:

```
ΔV_th = (1.602·10⁻¹⁹ Кл · 10¹⁸ см⁻³ · (8·10⁻⁷ см)²) / (2 · 3.9 · 8.854·10⁻¹⁴ Ф/см)
      = (1.602·10⁻¹⁹ · 10¹⁸ · 6.4·10⁻¹³) / (6.906·10⁻¹³)     [піднесено до квадрата товщину та обчислено знаменник]
      = 1.025·10⁻¹³ / 6.906·10⁻¹³                            [перемножено чисельник]
      ≈ 0.148 В                                             [знайдено частку]
```

Поверхневі стани `N_it` [см⁻²], що локалізовані безпосередньо на межі `x = 0`, додають прямий лінійний зсув, оскільки весь їхній заряд зосереджений на межі розділу:

```
ΔV_th^(it) = (q · N_it) / C_ox = (q · N_it · t_ox) / (ε_ox · ε₀)
```

Для густини поверхневих станів `N_it = 10¹² см⁻²`:

```
ΔV_th^(it) = (1.602·10⁻¹⁹ Кл · 10¹² см⁻² · 8·10⁻⁷ см) / (3.9 · 8.854·10⁻¹⁴ Ф/см)
          ≈ 0.371 В
```

Отже, сумарний зсув порогової напруги від двох типів дефектів становить `ΔV_th = ΔV_th^(ot) + ΔV_th^(it) ≈ 0.519 В`, що вже викликає відчутне звуження вікна пам'яті.

## 2. Квантове двопасткове тунелювання (SILC)

При низькому електричному полі `E_ox < 4 МВ/см` (режим зчитування або зберігання) пряме тунелювання Фаулера — Нордгейма через трикутний бар'єр `SiO₂` є неможливим, оскільки довжина тунелювання перевищує товщину оксиду. Проте наявність згенерованих пасток `N_ot` створює ступінчастий шлях тунелювання через проміжні енергетичні рівні (Trap-Assisted Tunneling, TAT).

За квантовою механікою, ймовірність тунелювання електрона між двома сусідніми пастками, розташованими на відстані `r`, описується у наближенні Вентцеля — Крамерса — Бріллюена (ВКБ):

```
P_tunnel = exp(- 2 · α · r)
```

де `α` — коефіцієнт згасання хвильової функції електрона під потенціальним бар'єром:

```
α = √(2 · m* · Φ_t) / ℏ
```

Тут `m* ≈ 0.42 · m_e = 0.42 · 9.109·10⁻³¹ кг = 3.826·10⁻³¹ кг` — ефективна маса електрона в забороненій зоні `SiO₂`, `Φ_t ≈ 1.5 еВ = 2.403·10⁻¹⁹ Дж` — енергетична глибина пастки відносно дна зони провідності `SiO₂`, а `ℏ = 1.0546·10⁻³⁴ Дж·с` — зведена стала Планка.

Обчислимо числове значення коефіцієнта згасання `α`:

```
2 · m* · Φ_t = 2 · 3.826·10⁻³¹ кг · 2.403·10⁻¹⁹ Дж = 1.838·10⁻⁴⁹ кг·Дж [перемножено масу та глибину ями]
√(2 · m* · Φ_t) = √(1.838·10⁻⁴⁹) ≈ 4.288·10⁻²⁵ кг·м/с                  [добуто квадратний корінь]
α = (4.288·10⁻²⁵ кг·м/с) / (1.0546·10⁻³⁴ Дж·с)                          [поділено на сталу Планка]
  ≈ 4.066 · 10⁹ м⁻¹ = 4.066 нм⁻¹                                        [переведено в нм⁻¹]
```

Якщо в оксиді товщиною `t_ox = 8 нм` сформувалися дві пастки на відстанях `x₁ = 2.5 нм` та `x₂ = 5.5 нм` від каналу, середня відстань тунельних стрибків становить `r₁ = 2.5 нм`, `r₂ = 3.0 нм`, `r₃ = 2.5 нм`. Ймовірність подолання першого проміжку:

```
P₁ = exp(- 2 · 4.066 нм⁻¹ · 2.5 нм) = exp(- 20.33) ≈ 1.48 · 10⁻⁹
```

Густина струму SILC через двопастковий ланцюжок описується формулою:

```
J_SILC = q · ν_attempt · N_path · P_total
```

де `ν_attempt ≈ 10¹³ с⁻¹` — частота спроб тунелювання електрона в потенціальній ямі, a `N_path` — площадна густина виникнення двопасткових ланцюжків у діелектрику:

```
N_path = C_stat · (N_ot · t_ox)² · r_capt³
```

де `r_capt ≈ 0.4 нм` — радіус захоплення пастки. Зростання густини пасток `N_ot` зі збільшенням кількості P/E-циклів викликає **квадратичне зростання** струму витоку SILC (`J_SILC ∝ N_ot²`), що призводить до швидкої втрати заряду з затвора.

При урахуванні енергетичного розподілу пасток у забороненій зоні `SiO₂` вираз для струму SILC узагальнюється інтегруванням по всьому енергетичному спектру `E_t`:

```
J_SILC(E_ox) = q · ∫₀ᵗᵒˣ dx · ∫ (D_ot(x, E_t) · f_occupation(E_t) · P_WKB(x, E_t, E_ox)) dE_t
```

де `D_ot(x, E_t)` — просторово-енергетична густина станів пасток [см⁻³ еВ⁻¹], а `f_occupation(E_t)` — функція заповнення пасток за статистикою Фермі — Дірака.

## 3. Тривимірна модель перколяції пробою (Percolation Model)

Нехай діелектрик об'ємом `V = A · t_ox` розбито на елементарні кубічні комірки з ребром `a_cell ≈ 0.8–0.9 нм` (характерний розмір дефекту $E'$-центра). Кількість шарів комірок по товщині становить `k = t_ox / a_cell`. Для товщини оксиду `t_ox = 8 нм` значення `k = 8 / 0.8 = 10`.

Під час кожного P/E-циклу з імовірністю `p` в довільній комірці генерується дефект. Частка дефектних комірок в об'ємі дорівнює:

```
p = N_ot / N_sites = N_ot · a_cell³
```

Перколяційний пробій (Hard Breakdown) виникає тоді, коли в принаймні одному з вертикальних стовпчиків площею `a_cell²` **усі** `k` комірок стають дефектними, утворюючи суцільний провідний місток.

Імовірність `P_column` того, що один конкретний стовпчик товщиною `k` комірок має суцільний ланцюжок з `k` пасток:

```
P_column = p^k = (N_ot · a_cell³)^k
```

Якщо площа комірки Flash становить `A`, кількість паралельних стовпчиків у масиві дорівнює `M = A / a_cell²`. Для комірки площею `A = 0.0025 мкм² = 2.5·10⁻¹¹ см²` та `a_cell = 0.8 нм = 8·10⁻⁸ см`:

```
M = (2.5·10⁻¹¹ см²) / (8·10⁻⁸ см)² = 2.5·10⁻¹¹ / 6.4·10⁻¹⁵ ≈ 3.9 · 10³ стовпчиків
```

Імовірність того, що хоча б один із `M` стовпчиків замкне перколяційний місток (кумулятивна імовірність пробою комірки `F_BD`):

```
F_BD = 1 - (1 - P_column)^M = 1 - (1 - p^k)^M
```

Застосовуючи наближення `(1 - x)^M ≈ exp(- M · x)` для малих `x`:

```
F_BD = 1 - exp( - M · p^k )
     = 1 - exp( - (A / a_cell²) · (N_ot · a_cell³)^(t_ox / a_cell) )
```

З цієї квантово-статистичної формули випливають два фундаментальні закони зносу Flash:

1. **Масштабування за площею (Area Scaling):** Збільшення площі комірки `A` зрощує кількість паралельних випробувальних стовпчиків `M`, що піднімає імовірність раннього пробою `F_BD`. Для масивів пам'яті великого об'єму (наприклад, 1 Тбіт) сумарна площа всіх комірок збільшує ймовірність появи найслабшої комірки з раннім пробоєм.
2. **Масштабування за товщиною (Thickness Scaling):** Показник степеня `k = t_ox / a_cell` прямо залежить від товщини оксиду. Зменшення `t_ox` з 10 нм (`k = 12`) до 6 нм (`k = 7`) знижує степінь `p^k` на 5 порядків. Це означає, що у тонших оксидах критична густина пасток `N_ot^\mathrm{crit}`, необхідна для утворення перколяційного містка, падає в десятки разів.

Точний розрахунок перколяційного порогу у 3D сітці з урахуванням сусідніх діагональних зв'язків (26 найближчих сусідів куба) вимагає чисельного моделювання методом Монте-Карло. Чисельний поріг перколяції для 3D просторової задачі вузлів становить `p_c ≈ 0.311`. Коли середня об'ємна частка пасток досягає 31.1% від густини сайтів `N_sites`, провідний кластер охоплює весь діелектрик з ймовірністю, близькою до 1.

## 4. Статистика Вейбула для часового пробою (TDDB)

Ресурс P/E-циклів `N_PE` та час до пробою під дією електричного напруження (TDDB) підкоряються двопараметричному розподілу Вейбула:

```
F(N_PE) = 1 - exp( - (N_PE / η)^β )
```

де:
- `β` — параметр форми Вейбула (Weibull slope / shape parameter), який визначає дисперсію розподілу ресурсу;
- `η` — характерний ресурс (scale parameter), при якому пробивається 63.2% комірок масиву (`F(η) = 1 - e⁻¹ ≈ 0.632`).

Переходячи до вейбулівських координат `W(F)`:

```
W(F) = ln( - ln(1 - F) ) = β · ln(N_PE) - β · ln(η)
```

Графік `W(F)` від `ln(N_PE)` являє собою пряму лінію з нахилом, що дорівнює `β`.

Зв'язок між параметром форми Вейбула `β` та критичною кількістю пасток перколяційного містка `k = t_ox / a_cell` випливає з кінетики накопичення дефектів `N_ot ∝ N_PE^α`:

```
p^k ∝ (N_PE^α)^k = N_PE^(α · k)
```

Порівнюючи з показником у розподілі Вейбула, отримуємо фундаментальне співвідношення:

```
β = α · k = α · (t_ox / a_cell)
```

Оскільки експериментальний показник степеня накопичення пасток становить `α ≈ 0.4–0.45`, для тунельного оксиду `t_ox = 8 нм` (`k = 10`) отримуємо вейбулівський нахил:

```
β = 0.4 · 10 = 4.0
```

Високе значення `β ≈ 4` свідчить про високу однорідність матеріалу: більшість комірок пробиваються практично одночасно при наближенні до ресурсу `η`. Проте при геометричному зменшенні товщини оксиду до `t_ox = 5 нм` (`k = 6`) нахил падає до `β = 2.4`. Це призводить до появи довгого вейбулівського «хвоста» ранніх пробоїв при малих значеннях `N_PE`, що вимагає впровадження резервних блоків і потужніших алгоритмів LDPC ECC для забезпечення надійності SSD.

З врахуванням температурного прискорення за законом Арреніуса та польового прискорення за моделью E-моделі, характерний ресурс `η` змінюється за формулою:

```
η(T, E_ox) = A₀ · exp( E_a / (k_B · T) ) · exp( - γ_field · E_ox )
```

де `E_a ≈ 1.1 еВ` — енергія активації деструкції зв'язків SiO₂, `γ_field ≈ 1.2 (МВ/см)⁻¹` — коефіцієнт польового прискорення пробою, а `k_B = 8.617·10⁻⁵ еВ/К` — стала Больцмана.

Розрахуємо коефіцієнт температурного прискорення (Thermal Acceleration Factor, TAF) при переході від робочої температури `T₁ = 300 K` (27 °C) до випробувальної температури `T₂ = 358 K` (85 °C):

```
TAF = exp( (E_a / k_B) · (1/T₁ - 1/T₂) )
    = exp( (1.1 / 8.617·10⁻⁵) · (1/300 - 1/358) )              [підставили значення E_a, k_B та температури]
    = exp( 12765.4 · (0.003333 - 0.002793) )                  [обчислено частку енергії та обернені температури]
    = exp( 12765.4 · 0.000540 )                               [знайдено різницю обернених температур]
    = exp( 6.893 )                                            [перемножено множники у показнику степеня]
    ≈ 985.3                                                   [піднесено до експоненти]
```

Це свідчить про те, що підвищення температури до 85 °C прискорює втрату заряду через витоки SILC майже в 1000 разів, що вимагає застосування частіших операцій перезапису читування (Read Reclaim) у SSD-накопичувачах серверного класу.
