# 🧮 Математичне виведення закону Шміда, фактора Тейлора та макроскопічних критеріїв плинності

Ця вставка містить строге математичне виведення геометрії закону Шміда для монокристалів, розрахунок фактора Тейлора для полікристалічних агрегатів, а також формальне виведення феноменологічних критеріїв плинності Треска та фон Мізеса в умовах складного тривісного напруженого стану.

---

### 1. Текстуальне та тензорне виведення закону Шміда

Розглянемо циліндричний монокристал з початковою площею поперечного перерізу `A₀`, до якого вздовж осі циліндра прикладено розтягувальне зусилля `F`.

Позначимо одиничний вектор уздовж напрямку дії сили як `n` (осьовий напрямок). Кристалографічна система ковзання задається двома векторами у тривимірному евклідовому просторі R³:
- `n_s` — одиничний вектор нормалі до площини ковзання;
- `s` — одиничний вектор напрямку ковзання, що лежить у площині ковзання (`n_s · s = 0`).

Кут між віссю розтягу `n` та нормаллю до площини ковзання `n_s` позначимо як `φ`:

```
cos φ = n · n_s                           [скалярний добуток нормалі та осі сили]
```

Кут між віссю розтягу `n` та напрямком ковзання `s` позначимо як `λ`:

```
cos λ = n · s                             [скалярний добуток напрямку ковзання та осі сили]
```

#### Геометрія площини ковзання та проекція сил

Площина ковзання перетинає циліндр під кутом `φ` до нормального перерізу. Площа утвореного еліптичного перерізу площини ковзання `A_s` зв'язана з площею нормального перерізу `A₀` співвідношенням:

```
A_s = A₀ / cos φ                          [площа похилого перерізу]
```

Розкладемо вектор зовнішньої сили `F = F · n` на дві складові: нормальну до площини ковзання та паралельну напрямку ковзання `s`. Модуль проекції сили на напрямок ковзання `s` дорівнює:

```
F_s = F · (n · s) = F · cos λ             [проекція сили на напрямок ковзання]
```

#### Розраховане зсувне напруження (Resolved Shear Stress)

Дотичне (зсувне) напруження `τ`, що діє у площині ковзання в напрямку `s`, за визначенням дорівнює відношенню зсувної сили `F_s` до площі похилого перерізу `A_s`:

```
τ = F_s / A_s                             [визначення зсувного напруження]
  = (F · cos λ) / (A₀ / cos φ)            [підстановка складових]
  = (F / A₀) · cos φ · cos λ              [групування множників]
  = σ · cos φ · cos λ                     [заміна σ = F / A₀ — макроскопічне напруження]
```

Позначивши безрозмірний геометрічний коефіцієнт як **фактор Шміда** `m`:

```
m = cos φ · cos λ                         [визначення фактора Шміда]
τ = σ · m                                 [закон Шміда у компактній формі]
```

#### Максимум фактора Шміда та умова початку плинності

Оскільки `n_s` та `s` взаємно перпендикулярні у кристалографічному триграннику, кути `φ` та `λ` пов'язані геометричним обмеженням. Зі сферичної тригонометрії випливає, що `φ + λ ≥ 90°`.

Знайдемо абсолютний максимум функції `m(φ, λ) = cos φ · cos λ` за умови `λ = 90° - φ`:

```
m(φ) = cos φ · cos(90° - φ) = cos φ · sin φ = 1/2 · sin(2φ)   [тригонометричне перетворення]
```

Максимум досягається при `sin(2φ) = 1`, тобто `2φ = 90° ⇒ φ = 45°` та `λ = 45°`:

```
m_max = 1/2 · sin(90°) = 0.5               [максимальне значення фактора Шміда]
```

Отже, границя плинності монокристала на розтяг `σ_y` залежить від кристалографічної орієнтації:

```
σ_y = τ_crss / m                          [залежність границі плинності від m]
σ_y_min = τ_crss / m_max = 2 · τ_crss     [найменша можлива границя плинності]
```

Якщо площина ковзання паралельна вісі розтягу (`φ = 90° ⇒ cos φ = 0`) або перпендикулярна (`λ = 90° ⇒ cos λ = 0`), фактор Шміда `m = 0`. У цьому разі дотичне напруження `τ = 0`, і пластична деформація за даною системою ковзання є математично неможливою.

### 2. Перехід до полікристалу: Тензорний аналіз та фактор Тейлора

У реальному полікристалічному металі (сталь, алюміній, мідь) матеріал складається з мільйонів хаотично орієнтованих кристалічних зерен. Для забезпечення суцільності матеріалу кожне зерно під час деформації змушене змінювати форму узгоджено із сусідніми зернами.

За геометрією фон Мізеса — Тейлора, для довільної зміни форми зерна без утворення мікропорожнин необхідно одночасно задіяти **щонайменше 5 незалежних систем ковзання**.

Середнє макроскопічне напруження плинності полікристалу `σ_y` зв'язане з критичним зсувним напруженням `τ_crss` через усреднений **фактор Тейлора** `M`:

```
σ_y = M · τ_crss                          [зв'язок плинності полікристала та τ_crss]
```

#### Математичне усереднення за орієнтаційним простором (ODF)

Фактор Тейлора обчислюється як інтегральне усереднення величини `1 / m(g)` за всім простором тривимірних кутів Ейлера `g = (φ₁, Φ, φ₂)` з урахуванням функції розподілу орієнтацій зерен (Orientation Distribution Function, ODF) `f(g)`:

```
M = ∫ (1 / m(g)) · f(g) dg                [інтегрування за текстурою матеріалу]
```

Для хаотично орієнтованого ГЦК-полікристала із 12 системами ковзання `{111}<110>` чисельне інтегрування за сферою орієнтацій дає строге значення:

```
M = ⟨1 / m⟩ ≈ 3.06                        [значення фактора Тейлора для ГЦК полікристала]
```

Для ОЦК-полікристала при ковзанні по площинах `{110}` та `{112}` усреднений фактор Тейлора становить `M ≈ 2.73–3.0`. Це означає, що полікристалічний матеріал через зернограничні обмеження має втричі вищу макроскопічну границю плинності, ніж ізольований монокристал.

### 3. Формальне виведення макроскопічних критеріїв плинності

У загальному випадку тривісного напруженого стану напруження в точці тіла описується тензором напружень другої валентності `σ_ij`. Шляхом знаходження власних значень тензора знаходять три **головні напруження**: `σ₁ ≥ σ₂ ≥ σ₃`.

Тензор напружень `σ_ij` розкладають на сферичну (гідростатичну) частину `p · δ_ij` та девіатор напружень `s_ij`:

```
p = 1/3 · (σ₁ + σ₂ + σ₃)                  [середній гідростатичний тиск]
s_ij = σ_ij - p · δ_ij                    [тензор-девіатор напружень]
```

Оскільки гідростатичний тиск `p` викликає лише пружну зміну об'єму і не здатен змістити дислокації, пластична плинність металів визначається інваріантами девіатора напружень `s_ij`.

#### 1. Критерій максимальних зсувних напружень Треска (Tresca Yield Criterion)

Анрі Треска (1864) припустив, що пластична течія починається тоді, коли максимальне зсувне напруження у матеріалі `τ_max` досягає критичного значення `τ_y = σ_y / 2`:

```
τ_max = (σ₁ - σ₃) / 2                     [максимальне зсувне напруження в тілі]
σ₁ - σ₃ = σ_y                             [критерій плинності Треска]
```

У просторі головних напружень `(σ₁, σ₂, σ₃)` поверхня плинності Треска являє собою правильну шестигранну призму, вісь якої збігається з гідростатичною віссю `σ₁ = σ₂ = σ₃`.

#### 2. Критерій енергії формозміни фон Мізеса (Von Mises Yield Criterion)

Ричард фон Мізес (1913) запропонував критерій, базований на другому інваріанті девіатора напружень `J₂ = 1/2 · s_ij · s_ij`. Плинність починається тоді, коли еквівалентне напруження фон Мізеса `σ_vm = √(3 · J₂)` досягає одноксиальної границі плинності `σ_y`:

```
σ_vm = √[ 1/2 · ((σ₁ - σ₂)² + (σ₂ - σ₃)² + (σ₃ - σ₁)²) ]   [еквівалентне напруження фон Мізеса]
```

Для довільних компонент тензора напружень у декартовій системі координат `(x, y, z)` вираз має вигляд:

```
σ_vm = √[ 1/2 · ((σ_xx - σ_yy)² + (σ_yy - σ_zz)² + (σ_zz - σ_xx)²) + 3·(τ_xy² + τ_yz² + τ_zx²) ]
```

Поверхня плинності фон Мізеса являє собою гладкий коловий циліндр, що описаний навколо шестигранної призми Треска.

#### Точний розрахунок чистого зсуву за критеріями Треска та фон Мізеса

При чистому зсуві напружений стан описується головними напруженнями `σ₁ = τ`, `σ₂ = 0`, `σ₃ = -τ`.

- За критерієм Треска:
```
σ₁ - σ₃ = τ - (-τ) = 2τ = σ_y   ⇒   τ_y = 0.500 · σ_y      [границя зсуву за Треска]
```

- За критерієм фон Мізеса:
```
σ_vm = √[ 1/2 · (τ² + τ² + (2τ)²) ] = √[ 1/2 · (6τ²) ] = √3 · τ = σ_y
τ_y = σ_y / √3 ≈ 0.577 · σ_y                               [границя зсуву за фон Мізесом]
```

Експерименти на пластичних металах показують, що значення `τ_y ≈ 0.577 σ_y` за критерієм фон Мізеса на 15% точніше описує реальну плинність міді, алюмінію та сталі, ніж критерій Треска.

### 4. Динаміка щільності дислокацій та рівняння Тейлора

Для опису зростання границі плинності під час пластичної деформації використовується мікроскопічне рівняння Тейлора:

```
τ(ρ) = τ₀ + α · G · b · √ρ                [залежність зсувного напруження від щільності дислокацій]
```

Еволюція щільності дислокацій `ρ` з ростом пластичної деформації `ε_p` описується двопараметричним диференціальним рівнянням Кокса — Мекінга (Kocks — Mecking model):

```
dρ / dε_p = k₁ · √ρ - k₂ · ρ              [баланс накопичення та анігіляції дислокацій]
```

де:
- `k₁ · √ρ` описує генерацію нових дислокацій джерелами Франка — Рида та їх накопичення на перешкодах (агеометричне зміцнення);
- `k₂ · ρ` описує динамічне повернення (анігіляцію протилежно орієнтованих дислокацій шляхом поперечного ковзання та переповзання).

Інтегрування цього диференціального рівняння дає насичувану криву деформаційного зміцнення, що точно моделює ділянку наклепу на макроскопічній діаграмі розтягу.
