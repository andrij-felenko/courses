# 🧮 Вивід термоелектронної емісії, ефекту Шотткі та вольт-фарадних характеристик

Ця математична вставка містить розгорнутий аналітичний вивід фундаментальних виразів, що описують фізику контакту метал-напівпровідник. У ній послідовно виведено розподіл електричного поля та потенціалу у виснаженій області з рівняння Пуассона, отримано вираз для струму термоелектронної емісії за квантово-механічною моделлю Ханса Бете, розраховано величину зниження потенціального бар'єра силами дзеркального відображення (ефект Шотткі) та сформульовано теорію вольт-фарадного C-V профілювання для вимірювання параметрів напівпровідникових структур.

## 1. Електростатика шару просторового заряду

Розглянемо плоский контакт між металом та однорідно легованим n-напівпровідником із рівномірною концентрацією донорної домішки `N_d`. Вважаємо межу розділу атомарно плоскою й розташованою у точці `x = 0`. Напівпровідник займає напівпростір `x > 0`.

У стані термодинамічної рівноваги електрони з приповерхневої області напівпровідника перетікають у метал, залишаючи позитивно заряджений шар некомпенсованих іонізованих донорних атомів. Припускаємо виконання модельних умов деплеційного наближення (наближення Шотткі):
1. Усередині виснаженої області `0 ≤ x ≤ W` концентрація вільних носіїв заряду `n(x)` знехтовно мала порівняно з концентрацією донорів `N_d`.
2. Поза виснаженою областю `x > W` напівпровідник є квазінейтральним, тобто `n(x) = N_d`, а електричне поле відсутнє.

Об'ємна густина заряду у збідненому шарі записується як `ρ(x) = q · N_d`. Одновимірне статичне рівняння Пуассона для електростатичного потенціалу `V(x)` приймає вигляд:

```
d²V / dx² = -ρ(x) / ε_s = -q · N_d / ε_s
```

де `ε_s = ε_r · ε_0` — абсолютна діелектрична проникність напівпровідникового матеріалу.

Для визначення розподілу напрямленого вздовж осі `x` електричного поля `E(x) = -dV/dx` інтегруємо рівняння Пуассона по координаті від довільної точки `x` до зовнішньої межі виснаженої області `W`:

```
∫_x^W (d²V / dt²) dt = -q · N_d / ε_s · ∫_x^W dt
```

Використовуючи фізичну граничну умову відсутності електричного поля на межі квазінейтрального об'єму `E(W) = -(dV/dx)|_{x=W} = 0`, отримуємо співвідношення для напрямку й величини електричного поля:

```
d V(x) / dx = (q · N_d / ε_s) · (W - x)      [інтегрування: E(x) = -dV/dx]
```

Отже, електричне поле `E(x) = -(q · N_d / ε_s) · (W - x)` спадає за лінійним законом від межі розділу углиб напівпровідника. Свого абсолютного максимального значення поле досягає безпосередньо на металевому контакті `x = 0`:

```
E_max = |E(0)| = (q · N_d · W) / ε_s        [максимальне поле на межі контакту]
```

Повторне інтегрування похідної потенціалу `dV/dx` від межі `x = 0` до довільної точки `x` з вибором опорного нуля потенціалу на металі `V(0) = 0` визначає параболічний профіль потенціальної енергії у збідненій зоні:

```
V(x) = ∫₀ˣ (q · N_d / ε_s) · (W - t) dt
     = (q · N_d / ε_s) · (W · x - x² / 2)     [квадратичний профіль потенціалу]
```

Повне падіння потенціалу на всій товщині виснаженого шару `x = W` відповідає різниці між вбудованим контактним потенціалом `V_bi` та зовнішньою напругою `V`, прикладеною до металу (де `V > 0` відповідає прямому зміщенню, яке зменшує бар'єр):

```
V(W) = V_bi - V = (q · N_d / (2 · ε_s)) · W²
```

З цього рівняння прямо виражаємо товщину області просторового заряду `W` як функцію електричного зміщення:

```
W = √((2 · ε_s · (V_bi - V)) / (q · N_d))   [ширина області просторового заряду]
```

Підставляючи отриманий вираз для товщини `W` у формулу максимального поля, виводимо фундаментальну залежність напряженості поля на межі розділу від прикладеного потенціалу:

```
E_max = √((2 · q · N_d · (V_bi - V)) / ε_s) [максимальне електричне поле на контактові]
```

Ці вирази формують електростатичну основу для опису як бар'єрної ємності, так і ефектів зниження потенціального бар'єра.

## 2. Квантово-механічний вивід термоелектронної емісії Бете

На відміну від p-n переходу, де струм обмежений дифузією неосновних носіїв у квазінейтральних областях, перенос носіїв у бар'єрі Шотткі визначається основними носіями (електронами у напівпровіднику n-типу). Ханс Бете показав, що якщо товщина виснаженого шару `W` менша за довжину вільного пробігу електронів, носії долають бар'єр без зіткнень, і струм визначається швидкістю термодинамічної емісії над вершиною бар'єра.

Розглянемо потік електронів із зони провідності напівпровідника в метал. Нехай вісь `x` перпендикулярна до площини контакту. Для того щоб електрон зміг перетнути межу раздела `x = 0`, його кінетична енергія, пов'язана з перпендикулярною складовою швидкості `v_x`, повинна перевищувати висоту потенціального бар'єра над дном зони провідності в об'ємі.

Гратична критична швидкість електрона `v_x0` біля межі квазінейтральної зони визначається з енергетичної рівності:

```
(1/2) · m* · v_x0² = q · (V_bi - V)
```

звідки отримуємо мінімальну необхідну швидкість:

```
v_x0 = √((2 · q · (V_bi - V)) / m*)
```

де `m*` — ефективна маса маси електрона у зоні провідності напівпровідника.

Густина електричного струму `J_s->m`, створювана електронами, які рухаються з напівпровідника в метал, дорівнює інтегралу від добутку елементарного заряду `-q`, нормальної швидкості `v_x` та функції розподілу електронів за швидкостями `n(v_x)`:

```
J_s->m = q · ∫_{v_x0}^∞ v_x · n(v_x) dv_x
```

Припускаючи панування невиродженої статистики Максвелла-Больцмана у зоні провідності, диференціальна концентрація електронів у інтервалі швидкостей `[v_x, v_x + dv_x]` становить:

```
n(v_x) dv_x = N_c · (m* / (2 · π · k_B · T))^(1/2) · exp(-m* · v_x² / (2 · k_B · T)) dv_x
```

де `N_c = 2 · (2 · π · m* · k_B · T / h³)^(3/2)` — ефективна густина станів у зоні провідності напівпровідника, `h` — стала Планка, `k_B` — стала Больцмана, `T` — абсолютна температура.

Підставляємо вираз для `n(v_x)` у вираз густини струму:

```
J_s->m = q · N_c · (m* / (2 · π · k_B · T))^(1/2) · ∫_{v_x0}^∞ v_x · exp(-m* · v_x² / (2 · k_B · T)) dv_x
```

Для обчислення визначеного інтеграла виконаємо заміну змінної `u = (m* · v_x²) / (2 · k_B · T)`:

```
∫_{v_x0}^∞ v_x · exp(-m* · v_x² / (2 · k_B · T)) dv_x 
= (k_B · T / m*) · ∫_{u_min}^∞ exp(-u) du             [заміна змінної u = m*·v_x² / (2·k_B·T)]
= (k_B · T / m*) · exp(-u_min)                        [інтегрування експоненти: ∫ exp(-u) du = exp(-u_min)]
= (k_B · T / m*) · exp(-q · (V_bi - V) / (k_B · T))   [підстановка нижньої межі u_min = q·(V_bi - V) / (k_B·T)]
```

Множимо знайдений інтеграл на зовнішній префактор:

```
J_s->m = q · N_c · (k_B · T / (2 · π · m*))^(1/2) · exp(-q · (V_bi - V) / (k_B · T))
```

Тепер підставимо квантово-механічний вираз для ефективної густини станів `N_c`:

```
J_s->m = q · [2 · (2 · π · m* · k_B · T / h²)^(3/2)] · (k_B · T / (2 · π · m*))^(1/2) · exp(-q · (V_bi - V) / (k_B · T))
```

Перемножуючи степеневі члени при температурі `T` та масі `m*`, отримуємо впорядкований вираз:

```
J_s->m = ((4 · π · q · m* · k_B²) / h³) · T² · exp(-q · (V_bi - V + V_n) / (k_B · T))
```

де `q · V_n = E_c - E_F` — енергетичний інтервал між дном зони провідності та рівнем Фермі у нейтральному напівпровіднику. Зважаючи на зонне співвідношення `q · Φ_Bn = q · V_bi + q · V_n`, сума `q · (V_bi + V_n)` дорівнює повній висоті бар'єра Шотткі `q · Φ_Bn`.

Отже, вираз для струму з напівпровідника в метал набуває вигляду:

```
J_s->m = [A* · T² · exp(-q · Φ_Bn / (k_B · T))] · exp(q · V / (k_B · T))
```

де параметр `A*` називається ефективною сталою Річардсона для даного напівпровідника:

```
A* = (4 · π · q · m* · k_B²) / h³         [ефективна стала Річардсона]
```

Для вільного електрона (`m* = m_0`) вакуумна стала Річардсона становить `A_0 ≈ 120.17 А / (см² · К²)`. У напівпровідниках через еліпсоїдальну форму ізоенергетичних поверхонь та наявність декількох екстремумів зонне значення `A*` відрізняється (наприклад, для n-Si `A* ≈ 112 А / (см² · К²)`, а для n-GaAs `A* ≈ 8.1 А / (см² · К²)`).

Зворотний потік електронів з металу в напівпровідник `J_m->s` дорівнює термодинамічному струму емісії при нульовому зміщенні `V = 0`, оскільки висота бар'єра з боку металу `q · Φ_Bn` є фіксованою величинаною, незалежною від прикладеної напруги `V`:

```
J_m->s = J_s = A* · T² · exp(-q · Φ_Bn / (k_B · T))  [густина струму насичення]
```

Повний результуючий струм діода Шотткі дорівнює різниці двох зустрічних потоків:

```
J = J_s->m - J_m->s = J_s · [exp(q · V / (η · k_B · T)) - 1]
```

де `η` — емпіричний фактор ідеальності (англ. *ideality factor*), який враховує зниження бар'єра під дією напруги, наявність тонких оксидних шарів та рекомбінаційні процеси.

## 3. Математичний опис ефекту Шотткі (Image-Force Lowering)

Коли негативно заряджений електрон наближається до межі провідного металу, він перерозподіляє вільні електрони металу, створюючи на поверхні напівпростору позитивний індукований заряд. За класичною електростатикою цей шар залишків еквівалентний позитивному дзеркальному заряду `+q`, розміщеному симетрично у точці `-x` всередині металу.

Кулонівська сила притягання між електроном у точці `x` та його дзеркальним відображенням у точці `-x` становить:

```
F_img(x) = -q² / (4 · π · ε_s · (2x)²) = -q² / (16 · π · ε_s · x²)
```

Робота, яку необхідно виконати проти сил дзеркального відображення для перенесення електрона з точки `x` у нескінченність, визначає потенціальну енергію дзеркального взаємодії `E_img(x)`:

```
E_img(x) = ∫_x^∞ F_img(t) dt = ∫_x^∞ (-q² / (16 · π · ε_s · t²)) dt = -q² / (16 · π · ε_s · x)
```

За наявності у виснаженій області однорідного електричного поля `E` потенціальна енергія електрона `E_pot(x)` складається з потенціалу поля та потенціалу дзеркальних сил:

```
E_pot(x) = -q · E · x - q² / (16 · π · ε_s · x)
```

Знайдемо точку `x_m`, у якій потенціальна енергія досягає свого максимуму (найвищої точки бар'єра). Диференціюємо `E_pot(x)` за координатою `x` і прирівнюємо похідну до нуля:

```
d E_pot / dx = -q · E + q² / (16 · π · ε_s · x_m²) = 0
```

Виражаємо координату максимуму бар'єра `x_m`:

```
x_m = √(q / (16 · π · ε_s · E))            [координата максимуму бар'єра]
```

Значення потенціальної енергії у точці екстремуму `x_m` обчислюємо підстановкою `x_m`:

```
E_pot(x_m) = -q · E · √(q / (16 · π · ε_s · E)) - q² / (16 · π · ε_s) · √(16 · π · ε_s · E / q)  [підстановка x_m]
           = -q · √(q · E / (16 · π · ε_s)) - q · √(q · E / (16 · π · ε_s))                 [спрощення кожної дробової частини]
           = -2 · q · √(q · E / (16 · π · ε_s))                                            [додавання двох однакових доданків]
           = -q · √(q · E / (4 · π · ε_s))                                                 [внесення коефіцієнта 2 під корінь: 2/√16 = 1/√4]
```

Спад висоти потенціального бар'єра `ΔΦ` (у вольтах) дорівнює відношенню зсуву максимуму потенціальної енергії до заряду електрона `q`:

```
ΔΦ = -E_pot(x_m) / q = √(q · E / (4 · π · ε_s))  [величина зниження бар'єра Шотткі]
```

Оскільки максимальне електричне поле на межі розділу `E_max` зростає при збільшенні зворотної напруги `V_R`, ефективна висота бар'єра зменшується за законом:

```
Φ_B(V_R) = Φ_Bn - ΔΦ = Φ_Bn - (q / (4 · π · ε_s))^(1/2) · ((2 · q · N_d · (V_bi + V_R)) / ε_s)^(1/4)
```

Це залежність пояснює, чому зворотний струм реального діода Шотткі не залишається суворо константним при зростанні зворотної напруги, а монотонно підвищується.

## 4. Вольт-фарадна характеристика та C-V профілювання

Збіднений шар напівпровідника з товщиною `W` утворює бар'єрну ємність (ємність шару просторового заряду). Оскільки некомпенсований заряд іонізованих донорів на одиницю площі контакта дорівнює:

```
Q_sc = q · N_d · W = √(2 · q · ε_s · N_d · (V_bi - V))
```

Диференціальна питома ємність `C` визначається як відношення зміни об'ємного заряду до зміни прикладеної напруги:

```
C = |dQ_sc / dV| = √(q · ε_s · N_d / (2 · (V_bi - V))) = ε_s / W
```

Для вимірюваного діода площею `A` загальна макроскопічна ємність дорівнює `C_tot = A · C`. Піднесемо обернену ємність `1 / C_tot²` до квадрата:

```
1 / C_tot² = (2 · (V_bi - V)) / (q · ε_s · N_d · A²)
```

Замінюючи пряму напругу `V` через зворотне зміщення `V_R = -V`, отримуємо лінійне рівняння вольт-фарадної характеристики:

```
1 / C_tot² = (2 / (q · ε_s · N_d · A²)) · (V_bi - k_B · T / q + V_R)
```

де додатковий терм `-k_B · T / q` враховує дифузійне розмиття гранічного розродження електронів біля края виснаженої області (поправка на тепловий рух).

На основі виміряної залежності `1 / C_tot²` від `V_R` будується пряма лінія, за геометричними параметрами якої екстрагують фундаментальні характеристики напівпровідника:

1. **Концентрацію донорної домішки `N_d`** визначають за кутовим нахилом лінії `S = d(1/C_tot²) / dV_R`:

```
N_d = 2 / (q · ε_s · A² · S)               [розрахунок легування з нахилу C-V]
```

2. **Вбудований потенціал `V_bi`** знаходять за відрізком `V_int`, який пряма відтинає на горизонтальній осі напруг при `1 / C_tot² = 0`:

```
V_bi = V_int + k_B · T / q                  [визначення V_bi з відсічки на осі]
```

Після обчислення `V_bi` та `N_d` висоту бар'єра Шотткі `Φ_Bn` знаходять із термодинамічної рівності:

```
Φ_Bn = V_bi + (k_B · T / q) · ln(N_c / N_d) [висота бар'єра Шотткі з C-V даних]
```

Сформований аналітичний апарат уможливлює не руйнуючий точний аналіз профілю легування та параметрів бар'єрів у напівпровідниковому виробництві.
