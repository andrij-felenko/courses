# ⚙️ Моделювання та апроксимація експериментальних даних закону Кюрі — Вейсса

Визначення фундаментальних параметрів магнітного матеріалу — температури Кюрі `T_C`, константи Кюрі `C` та ефективного магнітного моменту атома `μ_eff` — спирається на обробку експериментальних вимірювань магнітної сприйнятливості `χ(T)` у парамагнітній області. У реальних фізичних вимірюваннях експериментальні дані містять тепловий шум, а поблизу точки Кюрі спостерігаються відхилення від ідеальної прямої лінії через флуктуаційні ефекти. Цей обчислювальний модуль надає чисельні алгоритми розв'язання трансцендентного рівняння Вейсса `m = tanh(m · T_C / T)`, алгоритми побудови графіків Арротта, синтезу експериментальних кривих з шумом та автоматизованої апроксимації даних методом найменших квадратів.

---

### 1. Математичні алгоритми розв'язання трансцендентного рівняння Вейсса

Рівняння самоузгодження Вейсса `m = tanh(m · T_C / T)` є нелінійним трансцендентним рівнянням. Змінна відносної спонтанної намагніченості `m ∈ [0, 1]` входить одночасно в ліву частину та аргумент гіперболічного тангенса у правій частині. В елементарних алгебраїчних функціях розв'язок цього рівняння не виражається, тому для його обчислення застосовують чисельні методи.

#### Метод простої ітерації (Fixed-Point Iteration)
Запишемо рівняння у формі нерухомої точки `m_{k+1} = g(m_k)`, де ітераційна функція має вигляд:

```
g(m) = tanh( m · (T_C / T) )
```

Аналіз збіжності за теоремою про стискаюче відображення спирається на обчислення похідної `g'(m)`:

```
g'(m) = (T_C / T) · sech²( m · (T_C / T) )
```

1. **Режим `T > T_C` (Парамагнетик):**
   У точці `m = 0` похідна `g'(0) = T_C / T < 1`. За теоремою про нерухому точку, тривіальний корінь `m = 0` є **притягувальним атрактором**. Будь-яке початкове наближення `m_0 ∈ [0, 1]` монотонно збігається до `m = 0`.

2. **Режим `T < T_C` (Феромагнетик):**
   У точці `m = 0` похідна `g'(0) = T_C / T > 1`, тому тривіальний корінь `m = 0` є **нестійким репелером**. 
   Для ненульового кореня `m_s > 0` аргумент `y = m_s · (T_C / T) > 1`, тому `sech²(y) = 1 - tanh²(y) = 1 - m_s²`.
   Похідна у ненульовій нерухомій точці дорівнює `g'(m_s) = (T_C / T) · (1 - m_s²)`.
   Оскільки при `T < T_C` значення `m_s` задовольняє умову `0 < g'(m_s) < 1`, ненульовий корінь `m_s` є **стійким атрактором**. 

Це гарантує, що для будь-якого початкового наближення `m_0 ∈ (0, 1]` метод простої ітерації монотонно й швидко збігається до фізично стійкої спонтанної намагніченості `m_s(T)`.

#### Метод Ньютона — Рафсона (Newton-Raphson Method)
Для прискорення квадратичної збіжності поблизу критичної точки `T → T_C⁻` формулюють нелінійну функцію `f(m) = 0`:

```
f(m) = m - tanh( m · (T_C / T) ) = 0
f'(m) = 1 - (T_C / T) · sech²( m · (T_C / T) )
```

Ітераційний крок Ньютона — Рафсона задається співвідношенням:

```
m_{k+1} = m_k - [ m_k - tanh( m_k · T_C / T ) ] / [ 1 - (T_C / T) · sech²( m_k · T_C / T ) ]
```

Метод Ньютона дає квадратичну швидкість збіжності (подвоєння кількості точних значущих цифр на кожному кроці), що особливо важливо при розрахунках фазових діаграм на сітках високої роздільності.

### 2. Експериментальні протоколи вимірювання та обробка даних

У фізиці конденсованого стану вимірювання магнітної сприйнятливості виконують на сучасних автоматизованих вимірювальних комплексах SQUID або VSM. Для отримання достовірних фізичних результатів експериментатор дотримується двох основних протоколів термомагнітного циклювання:

1. **Охолодження у нульовому полі (Zero-Field Cooling, ZFC):**
   Зразок охолоджують від кімнатної температури до кріогенного мінімуму (наприклад, 2 K) за відсутності зовнішнього магнітного поля (`H = 0`). Це заморожує хаотичну доменну структуру з мінімальною залишковою намагніченістю. Потім вмикають слабке вимірювальне поле (зазвичай `H = 100 - 1000 Естед`) і знімають криву `M(T)` при повільному нагріванні.

2. **Охолодження у полі (Field-Cooling, FC):**
   Зразок охолоджують від парамагнітної області нижче точки Кюрі при постійно увімкненому зовнішньому магнітному полі `H`. Це змушує магнітні домени формуватися у переважному напрямку поля, що мінімізує доменний гістерезис.

Розходження кривих `M_ZFC(T)` та `M_FC(T)` нижче точки Кюрі є чітким маркером доменного зачеплення (pinning) на дефектах кристалічної ґратки або виникнення стану спінового скла.

#### Метод апроксимації Левенберга — Маркварда

Для знаходження констант `C` та `T_C` з нелінійного рівняння `χ(T) = χ_0 + C / (T - T_C)` алгоритм оптимізації мінімізує суму квадратів відхилень `S(C, T_C)`:

```
S = ∑_{i=1}^{N} w_i · [ χ_exp(T_i) - χ_model(T_i; C, T_C) ]²
```

де `w_i = 1 / σ_i²` — вагові коефіцієнти вимірювальної похибки кожної експериментальної точки.

Алгоритм Левенберга — Маркварда поєднує метод найшвидшого градієнтного спуску далеко від мінімуму та метод Гаусса — Ньютона поблизу оптимальної точки. Поправка до вектора параметрів `Δp` на кожному кроці обчислюється розв'язанням системи лінійних рівнянь:

```
[ J^T · J + μ · diag(J^T · J) ] · Δp = J^T · r
```

де `J` — матриця Якобі часткових похідних `∂χ / ∂p_j`, `r` — вектор залишків, а `μ` — параметр загасання, який динамічно коригується залежно від зменшення цільової функції.

Після досягнення критерію зупинки `||Δp|| < tol` обчислюється коваріаційна матриця `pcov = (J^T · J)⁻¹ · (S / (N - 2))`. Діагональні елементи `pcov[0][0]` та `pcov[1][1]` дають точні дисперсії знайдених параметрів `σ_C²` та `σ_{T_C}²`, що дозволяє формулювати висновок про фізичну точність експерименту із довірчим інтервалом 95%.

### 3. Алгоритм графіків Арротта (Arrott Plots)

У реальних вимірюваннях при `T ≈ T_C` зовнішнє магнітне поле `H > 0` розмиває фазовий перехід, через що пряме визначення `T_C` з графіка `1 / χ(T)` ускладнюється.

За методом Арротта експериментальні ізотерми будують у координатах `(M², H / M)`:

```
H / M = (a_0 / C) · (T - T_C) + (b / C) · M²
```

У цих координатах кожна ізотермічна крива являє собою пряму лінію. Точна температура Кюрі `T_C` відповідає тій єдиній ізотермі, яка проходить строго через початок координат `(0, 0)`.

### 5. Крайові випадки та обчислювальна стійкість

При практичній чисельній обробці закону Кюрі — Вейсса слід враховувати кілька важливих обчислювальних нюансів:

1. **Ділення на нуль при `T → T_C`:**
   У точці Кюрі `1 / χ(T_C) = 0`, що означає прямувати сприйнятливості до нескінченності. На комп'ютері це викликає помилку ділення на нуль (`ZeroDivisionError` або `Inf`). У коді точки з `T - T_C < ε` захищають порогам `tol`.

2. **Вибір температурного вікна апроксимації:**
   Використання точок у вузькій узбічній області `(T_C, T_C + 10 K)` призводить до викривлення значень `T_C` та `C` через вплив критичних флуктуацій. Оптимальне вікно для лінійної регресії відповідає інтервалу `1.1 · T_C ≤ T ≤ 2.0 · T_C`.

3. **Стійкість ітерацій при `T → 0 K`:**
   При дуже низьких температурах `T → 0` аргумент гіперболічного тангенса `m · T_C / T` прямує до нескінченності. Переповнення розряду `exp(x)` у системних бібліотеках обходиться за допомогою функції `std::tanh`, яка стандартно обробляє великі аргументи та повертає `1.0` при `x > 20.0`.
