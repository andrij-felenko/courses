# 📜 Історія відкриття молекулярного поля Вейсса та квантового обміну

У 1895 році французький фізик П'єр Кюрі захистив докторську дисертацію, присвячену магнітним властивостям речовин при різних температурах. Провівши серію філігранних експериментів із парамагнітними сполуками, він сформулював емпіричний закон: магнітна сприйнятливість таких речовин обернено пропорційна абсолютній температурі. Вільні магнітні диполі в атомах під дією зовнішнього поля прагнуть вишикуватися уздовж силових ліній, тоді як хаотичний тепловий рух перешкоджає цій орієнтації. Проте спроба применити закон Кюрі до заліза, кобальту чи нікелю в області вище температури їхнього знемагнічування зазнала нищівного краху. Виміряна сприйнятливість виявилася на кілька порядків вищою, а при наближенні до критичної температури вона прямувала до нескінченності, а не спадала за пропорцією `1 / T`. У 1907 році П'єр Вейсс висунув геніальну гіпотезу про існування внутрішнього «молекулярного поля», яка пояснила цей парадокс за два десятиліття до виникнення квантової механіки.

---

### 1. Парадокс експериментів П'єра Кюрі та теорія Поля Ланжевена

До кінця XIX століття фізика розділяла магнітні речовини на дві абсолютно несхожі категорії:
- **Парамагнетики:** Слабо магнітні матеріали (наприклад, платина чи солі марганцю), чия намагніченість виникала лише у зовнішньому полі й зникала одразу після його вимкнення.
- **Феромагнетики:** Речовини (залізо, нікель, кобальт), які здатні зберігати потужну спонтанну намагніченість у повній відсутності зовнішнього магнітного поля.

Досліджуючи нагрівання заліза, П'єр Кюрі виявив дивовижне явище. При досягненні критичної температури 770 °C (яку згодом назвуть точкою Кюрі) залізо раптово втрачає свої феромагнітні властивості й перетворюється на звичайний парамагнетик. Проте вимірювання магнітної сприйнятливості `χ = M / H` у цій високотемпературній парамагнітній фазі виявили глибоку відмінність від звичайних парамагнетиків:

```
Звичайний парамагнетик (закон Кюрі, 1895):
χ = C / T

Парамагнітна фаза заліза (закон Кюрі — Вейсса, 1907):
χ = C / (T - θ_p)
```

Графік оберненої сприйнятливості `1 / χ` від температури `T` для заліза утворював пряму лінію, але вона перетинала вісь температур не в абсолютному нулі (`0 K`), як вимагав класичний закон Кюрі, а в додатній точці `θ_p ≈ 1043 K`.

У 1905 році французький теоретик Поль Ланжевен розробив першу класичну статистичну теорію парамагнетизму. Спираючись на статистику Больцмана, він розглянув систему незалежних атомних магнітних диполів `μ` у зовнішньому полі `H`. Середня намагніченість описувалася функцією Ланжевена `L(x) = coth(x) - 1/x`, де `x = μ · H / (k_B · T)`. У слабких полях або при високих температурах (`x << 1`) функція Ланжевена розкладалася в ряд `L(x) ≈ x / 3`, що строго давало класичний закон Кюрі з константою:

```
C = N · μ² / (3 · k_B)
```

Теорія Ланжевена блискуче працювала для розведених парамагнітних солей. Проте для феромагнетиків вона була безпорадною: класична теплова енергія `k_B · T` при кімнатній температурі перевищувала взаємодію між атомними диполями у сотні разів. Класична теорія передбачала, що залізо має втрачати спонтанну намагніченість вже при температурі близько `1 K`.

### 2. Прорив П'єра Вейсса: гіпотеза молекулярного поля (1907)

У 1907 році професор Страсбурзького університету П'єр Вейсс (фр. *Pierre Weiss*) опублікував фундаментальну працю «Гіпотеза молекулярного поля та феромагнітна властивість» (*L'hypothèse du champ moléculaire et la propriété ferromagnétique*). 

Вейсс припустив, що всередині феромагнетика кожен атомний магнітний диполь відчуває дію не лише зовнішнього магнітного поля `H_ext`, але й гігантського внутрішнього поля, яке створюється всіма іншими оточуючими атомами кристала. Це поле Вейсс назвав **молекулярним полем** (`H_mol`) і висунув сміливу постулативну формулу: воно прямо пропорційне локальній намагніченості речовини `M`:

```
H_mol = λ · M
```

де `λ` — феноменологічна константа молекулярного поля Вейсса.

Отже, повне ефективне поле, що діє на кожен атомний диполь, становить:

```
H_eff = H_ext + λ · M
```

Підставивши це ефективне поле в формулу Ланжевена для парамагнітної області, Вейсс миттєво отримав математичне виведення спостережуваного відхилення від закону Кюрі:

```
M = C · H_eff / T = C · (H_ext + λ · M) / T
M · T = C · H_ext + C · λ · M
M · (T - C · λ) = C · H_ext
χ = M / H_ext = C / (T - C · λ)
```

Визначивши критичну температуру як `T_C = C · λ`, Вейсс отримав знаменитий **закон Кюрі — Вейсса**:

```
χ = C / (T - T_C)
```

Цей висновок був феноменальним: коли температура знижується й наближається до `T_C`, знаменник `(T - T_C)` прямує до нуля, а магнітна сприйнятливість `χ` прямує до нескінченності! Це означало, що навіть нескінченно мале зовнішнє поле при `T = T_C` викликає скінченну намагніченість. Нижче точки Кюрі (`T < T_C`) молекулярне поле стає настільки потужним, що здатне підтримувати впорядковану орієнтацію спінів самостійно, без жодного зовнішнього поля — матеріалізується спонтанна намагніченість.

### 3. Загадка «тисячі Тесла» та дебати з Камерлінг-Оннесом

Хоча гіпотеза Вейсса ідеально пояснила термодинаміку фазового переходу, вона поставила перед фізикою нову глибоку загадку, яка лишалася нерозгаданою понад 20 років.

Оцінимо величину молекулярного поля для металевого заліза. Для заліза точка Кюрі становить `T_C = 1043 K`, а константа Кюрі `C ≈ 2.1 K`. Це дає феноменологічний коефіцієнт Вейсса:

```
λ = T_C / C ≈ 1043 / 2.1 ≈ 500
```

Оскільки насичена намагніченість заліза становить близько `M_0 ≈ 1.7 · 10⁶ А/м`, магнітна індукція внутрішнього поля Вейсса досягає астрономічного значення:

```
B_mol = μ_0 · H_mol = μ_0 · λ · M_0
B_mol ≈ (4π · 10⁻⁷ Гн/м) · 500 · (1.7 · 10⁶ А/м) ≈ 1000 Тесла
```

Для порівняння: найпотужніші постійні магніти у лабораторіях того часу створювали поля не більше 2–3 Тесла, а власне класичне магнітне диполь-дипольне поле від сусіднього електрона на відстані 0.2 нм становить лише бл. **0.1 Тесла**. 

Внутрішнє поле Вейсса виявилося у **10 000 разів сильнішим** за будь-які можливі класичні магнітні сили між атомами! Якби молекулярне поле мало класичну магнітну природу, два магнітні електрони мали б розташовуватися на відстанях, значно менших за розмір самих атомів, що було очевидним абсурдом.

У 1910–1920-х роках видатний голландський експериментатор Гейке Камерлінг-Оннес, який щойно зріджив гелій і відкрив надпровідність, провів вимірювання намагніченості заліза та нікелю при кріогенних температурах до 4.2 K. Його результати підтвердили, що намагніченість прямує до насичення `M_0`, проте термодинамічні характеристики поблизу абсолютного нуля не узгоджувалися з класичними розкладами Вейсса. Фізичне походження цього колосального поля лишалося повною таємницею, і сам Вейсс чесно визнавав у своїх працях, що молекулярне поле є лише математичною гіпотезою, чия справжня фізична природа невідома класичній електродинаміці.

### 4. Квантова розгадка: принцип Паулі та обмін Гейзенберга (1926–1928)

Справжній фізичний механізм молекулярного поля був розшифрований лише після створення квантової механіки.

У 1925 році Вольфганг Паулі сформулював принцип заборони для ферміонів: два електрони не можуть перебувати в одному й тому самому квантовому стані. Коли хвильові функції двох сусідніх електронів у кристалічній ґратці перекриваються, їхня повна хвильова функція мусить бути антисиметричною щодо перестановки частинок.

У 1926–1928 роках видатний німецький теоретик Вернер Гейзенберг та англійський фізик Поль Дірак незалежно довели, що взаємна орієнтація електронних спінів драматично впливає на їхнє просторове розподілення в об'ємі атома і, як наслідок, на енергію їхнього кулонівського електричного відштовхування.

Якщо спіни двох електронів паралельні (`↑↑`), спінова хвильова функція є симетричною, тому просторова хвильова функція мусить бути антисиметричною. Це означає, що електрони з однаковими спінами середньо статистично уникають один одного у просторі, що знижує потенційну енергію їхнього електричного відштовхування. 

Ця чисто квантова поправка до кулонівської енергії отримала назву **обмінної взаємодії** (*exchange interaction*). Гейзенберг записав оператор обмінної енергії для кристалічної ґратки:

```
H_ex = -2 · J · (S_i · S_j)
```

де `J` — квантовий **обмінний інтеграл** (*exchange integral*), який описує перекриття електронних хмарин.

Гейзенберг довів, що внутрішнє «молекулярне поле» Вейсса — це взагалі **не магнітне поле**. Це **чисто електрична кулонівська взаємодія**, скоригована квантовим принципом Паулі!

Зіставляючи енергію обмінного оператора Гейзенберга з енергією спіна у молекулярному полі Вейсса `E = -μ_B · B_mol`, можна строго виразити коефіцієнт Вейсса `λ` через квантовий обмінний інтеграл `J`:

```
λ = (2 · z · J) / (N · g² · μ_B²)
```

де `z` — кількість найближчих сусідніх атомів у ґратці, `N` — концентрація атомів, `g` — g-фактор Ланде, `μ_B` — магнетон Бора.

Звідси точка Кюрі `T_C` безпосередньо виражається через квантовий обмінний інтеграл:

```
k_B · T_C = (2 / 3) · z · J · S · (S + 1)
```

Таємницю гігантського поля у 1000 Тесла було остаточно розгадано. Обмінна взаємодія має електричну природу (кулонівські сили між зарядами електронів), а електричні сили між атомами на три-чотири порядки потужніші за класичні магнітні дипольні сили.

У 1937 році американський теоретик Джон Ван Влек розвинув квантову теорію малого магнетизму (за що згодом отримав Нобелівську премію 1977 року), показавши, як теорія молекулярного поля Вейсса випливає з точних量子 квантових гамільтоніанів у наближенні локалізованих та колектизованих d-електронів.

### 5. Узагальнення Нееля та спадщина теорії Вейсса

Гіпотеза молекулярного поля Вейсса стала фундаментальним містком між емпіричними вимірюваннями XIX століття та сучасною квантовою фізикою конденсованого стану.

У 1932 році Луї Неель узагальнив концепцію молекулярного поля Вейсса на системи з від'ємним обмінним інтегралом (`J < 0`). Розділивши кристалічну ґратку на дві вкладені спінові підґратки, Неель передбачив існування **антиферомагнетизму** та **феримагнетизму**, де молекулярне поле змушує сусідні спіни орієнтуватися антипаралельно.

Сьогодні метод молекулярного поля Вейсса розглядають як найпростіший класичний приклад **теорії середнього поля** (*Mean-Field Theory*, MFT) у фізиці фазових переходів. Попри те, що теорія Вейсса не враховує локальні флуктуації спінів поблизу точок фазових переходів, вона надає надзвичайно точний, прозорий та фізично наочний опис парамагнітної області й слугує базовим фундаментом для всієї сучасної теорії магнетизму.
