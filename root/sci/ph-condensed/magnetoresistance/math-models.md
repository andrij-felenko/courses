# 🧮 Математичні моделі магнітоопору: Колер, Мотт та Жюльєр

Математичний опис магнітоопору охоплює декілька фізичних масштабів: від класичної кінетики носіїв у зовнішньому магнітному полі до квантово-механічного тунелювання спін-поляризованих електронів та динаміки намагніченості Ландау — Ліфшиця. У цій вставці наведено строгі виведення та математичні моделі трьох головних класів магнітоопору: звичайного (OMR), гігантського (GMR) та тунельного (TMR).

---

### 1. Кількісні характеристики та тензор провідності

Зміна опору провідника в магнітному полі `B` описується безрозмірним коефіцієнтом відносного магнітоопору `MR`:

```
MR = (R(B) - R0) / R0 = ΔR / R0
```

де `R(B)` — опір провідника у магнітному полі з індукцією `B`, а `R0 = R(0)` — опір у нульовому полі. Аналогічно через питомий опір `ρ` або провідність `σ`:

```
Δρ / ρ0 = (ρ(B) - ρ0) / ρ0
```

У тривимірному анізотропному середовищі зв'язок між вектором густини струму `j` та електричним полем `E` задається тензором питомого опору `ρ_ij(B)`:

```
E_i = ∑_j ρ_ij(B) · j_j
```

Згідно з принципом симетрії кінетичних коефіцієнтів Онсагера, компоненти тензора задовольняють співвідношення `ρ_ij(B) = ρ_ji(-B)`. Симетрична частина тензора відповідає за поздовжній опір (магнітоопір), а антисиметрична — за поперечну ЕРС (ефект Холла).

### 2. Звичайний магнітоопір (OMR) та масштабне правило Колера

Розглянемо провідник у магнітному полі `B = (0, 0, B_z)`. Рівняння руху носія заряду `q` з ефективною масою `m*` та середнім часом релаксації імпульсу `τ` має вигляд:

```
m* · (d v / dt + v / τ) = q · (E + v × B)
```

У стаціонарному стані `d v / dt = 0`. Позначаючи циклотронну частоту `ω_c = (q · B_z) / m*` та дрейфову рухливість `μ = (q · τ) / m*`, виразимо компоненти густини струму `j = n · q · v`:

```
j_x = σ0 / (1 + (ω_c · τ)²) · E_x - (ω_c · τ) · σ0 / (1 + (ω_c · τ)²) · E_y
j_y = (ω_c · τ) · σ0 / (1 + (ω_c · τ)²) · E_x + σ0 / (1 + (ω_c · τ)²) · E_y
```

де `σ0 = (n · q² · τ) / m*` — класична провідність Друде.

#### Парадокс звичайного металу
Якщо провідник має прямокутну форму і струм тече вздовж осі `x` (`j_y = 0`), то з другого рівняння випливає виникнення поперечного поля Холла:

```
E_y = - (ω_c · τ) · E_x      [рівновага струмів вздовж осі y: j_y = 0]
```

Підставивши вираз для `E_y` у перше рівняння для `j_x`, простежимо алгебраїчні перетворення:

```
j_x = σ0 / (1 + (ω_c · τ)²) · E_x - (ω_c · τ) · σ0 / (1 + (ω_c · τ)²) · (- ω_c · τ · E_x)  [підстановка E_y]
    = σ0 / (1 + (ω_c · τ)²) · E_x + (ω_c · τ)² · σ0 / (1 + (ω_c · τ)²) · E_x                [розкриття дужок та добутку (-ω_c·τ)·(-ω_c·τ)]
    = σ0 / (1 + (ω_c · τ)²) · (1 + (ω_c · τ)²) · E_x                                        [винесення спільного множника σ0/(1+(ω_c·τ)²)]
    = σ0 · E_x                                                                              [скорочення однаковим чисельником та знаменником]
```

Поздовжній опір `ρ_xx = E_x / j_x = 1 / σ0 = ρ0` **зовсім не залежить від магнітного поля**! Це фундаментальний результат: в ідеально ізотропній однозоновій моделі з постійним часом релаксації `τ` поперечне поле Холла точно компенсацією гасить відхиляючу силу Лоренца для всіх електронів, і звичайний магнітоопір дорівнює нулю.

#### Двозонна модель провідності
Звичайний магнітоопір виникає у металах через анізотропію поверхні Фермі або наявність кількох типів носіїв (наприклад, електронів 1 та дірок 2). Застосувавши тензори провідності для двох груп носіїв, отримуємо підсумковий питомий опір:

```
ρ(B) = ρ0 · [1 + (σ1 · σ2 / (σ1 + σ2)²) · (μ1 - μ2)² · B²]      [двозонний вираз Друде]
```

Оскільки `μ1` та `μ2` мають протилежні знаки (для електронів і дірок), різниця `(μ1 - μ2)²` суттєво відмінна від нуля. Відносний магнітоопір зростає квадратично в слабких полях:

```
Δρ / ρ0 = A · B²      [квадратичний режим для слабких полів, μ·B << 1]
```

#### Масштабне правило Колера
Едуард Колер (1938) показав, що для одного й того самого металу за різних температур відносний магнітоопір є універсальною функцією відношення поля до питомого опору за відсутності поля:

```
Δρ / ρ0 = F( B / ρ0 )      [закон Колера]
```

Оскільки `ρ0 ∝ 1 / τ`, аргумент `B / ρ0` пропорційний безрозмірному добутку циклотронної частоти на час вільного пробігу `ω_c · τ`.

### 3. Двокаліберна модель Мотта та розрахунок GMR

У феромагнітних металах струм переносять дві групи електронів із орієнтацією спіну «вгору» (`↑`, паралельно внутрішній намагніченості) та «вниз» (`↓`, антипаралельно). Згідно з моделлю Мотта, загальна провідність є сумою провідностей двох незалежних спінових каналів:

```
σ_tot = σ_up + σ_dn
1 / R_tot = 1 / R_up + 1 / R_dn
```

Позначимо питомий опір шару для електронів зі спіном «вгору» як `ρ_up`, а для електронів зі спіном «вниз» як `ρ_dn`. Коефіцієнт асиметрії спінового розсіювання `α`:

```
α = ρ_dn / ρ_up
```

#### Магніторезистивний спіновий вентиль (GMR)
Розглянемо двошарову систему з двох однакових феромагнітних шарів товщиною `d`.

1. **Паралельний стан (P):** Обидва шари намагнічені вгору (`↑ ↑`).
   - Канал `↑`: опір в обох шарах низький (`R_up = 2 · ρ_up · d`).
   - Канал `↓`: опір в обох шарах високий (`R_dn = 2 · ρ_dn · d = 2 · α · ρ_up · d`).

   Підсумковий опір паралельного стану `R_P`:

```
R_P = (R_up · R_dn) / (R_up + R_dn)                                             [паралельне з'єднання опорів]
    = (2 · ρ_up · d) · (2 · α · ρ_up · d) / (2 · ρ_up · d · (1 + α))             [підстановка R_up та R_dn]
    = 2 · d · ρ_up · [α / (1 + α)]                                               [скорочення спільного множника 2·ρ_up·d]
```

2. **Антипаралельний стан (AP):** Перший шар `↑`, другий шар `↓`.
   - Електрони `↑` у першому шарі зазнають малого розсіювання (`ρ_up`), а у другому — великого (`ρ_dn`).
   - Електрони `↓` у першому шарі зазнають великого розсіювання (`ρ_dn`), а у другому — малого (`ρ_up`).

   Опір кожного з двох каналів стає однаковим: `R_up' = R_dn' = (ρ_up + ρ_dn) · d = ρ_up · d · (1 + α)`.

   Підсумковий опір антипаралельного стану `R_AP`:

```
R_AP = R_up' / 2 = d · ρ_up · [(1 + α) / 2]                                     [еквівалентний опір рівних гілок]
```

#### Кількісний коефіцієнт GMR
Обчислимо відносний гігантський магнітоопір:

```
GMR = (R_AP - R_P) / R_P                                                         [визначення відносного ефекту]
    = [((1 + α) / 2) - (2 · α / (1 + α))] / [2 · α / (1 + α)]                   [підстановка виразів для R_AP та R_P]
    = [ (1 + α)² - 4 · α ] / [ 4 · α ]                                           [зведення чисельника до спільного знаменника 2·(1+α)]
    = (α - 1)² / (4 · α)                                                        [згортання за формулою квадрата різниці]
```

Якщо асиметрія розсіювання велика (наприклад, `α = 5`), то:

```
GMR = (5 - 1)² / (4 · 5) = 16 / 20 = 0.80   (тобто 80%)
```

### 4. Модель тунельного магнітоопору (Формула Жюльєра) та симетрійна фільтрація

У магнітному тунельному переході (MTJ) два феромагнітні електроди розділені тонким діелектричним бар'єром. Тунельний струм йде зі збереженням спіну.

Ймовірність тунелювання електрона зі спіном `σ` пропорційна добутку густини станів вихідного електрода `N1_σ(E_F)` та густини вільних станів приймального електрода `N2_σ(E_F)` на рівні Фермі:

```
I_σ ∝ N1_σ(E_F) · N2_σ(E_F)
```

Введемо коефіцієнт спінової поляризації Фермі-рівня для кожного електрода:

```
P_1 = (N1_up - N1_dn) / (N1_up + N1_dn)
P_2 = (N2_up - N2_dn) / (N2_up + N2_dn)
```

Звідси густини станів виражаються через поляризацію:

```
N_up = (N_tot / 2) · (1 + P)
N_dn = (N_tot / 2) · (1 - P)
```

#### Струм у паралельному та антипаралельному станах

1. **Паралельна орієнтація (P):**
```
G_P ∝ N1_up · N2_up + N1_dn · N2_dn                                             [сума двох спінових каналів]
    ∝ (1/4) · N1_tot · N2_tot · [(1 + P1)·(1 + P2) + (1 - P1)·(1 - P2)]         [підстановка N_up та N_dn]
    ∝ (1/2) · N1_tot · N2_tot · [1 + P1 · P2]                                   [розкриття дужок та спрощення]
```

2. **Антипаралельна орієнтація (AP):**
```
G_AP ∝ N1_up · N2_dn + N1_dn · N2_up                                            [сума двох перехресних каналів]
     ∝ (1/4) · N1_tot · N2_tot · [(1 + P1)·(1 - P2) + (1 - P1)·(1 + P2)]        [підстановка N_up та N_dn]
     ∝ (1/2) · N1_tot · N2_tot · [1 - P1 · P2]                                  [розкриття дужок та спрощення]
```

#### Співвідношення Жюльєра для TMR

Оскільки опір обернено пропорційний провідності `R = 1 / G`, обчислимо відносний тунельний магнітоопір:

```
TMR = (R_AP - R_P) / R_P                                                        [визначення відносного TMR]
    = (G_P - G_AP) / G_AP                                                       [перехід від опорів до провідностей]
    = [(1 + P1 · P2) - (1 - P1 · P2)] / [1 - P1 · P2]                           [підстановка G_P та G_AP]
    = (2 · P1 · P2) / (1 - P1 · P2)                                             [віднімання у чисельнику: 1 - 1 + 2·P1·P2]
```

Цей вираз називають **формулою Жюльєра**. Для однакових феромагнітних електродів (`P1 = P2 = P`):

```
TMR = (2 · P²) / (1 - P²)                                                        [формула Жюльєра для однакових електродів]
```

#### Квантова симетрійна фільтрація у бар'єрах MgO

Модель Жюльєра припускає аморфний бар'єр із розсіяним тунелюванням. Якщо ж виростити монокристалічний бар'єр оксиду магнію `MgO(001)` між електродами `Fe(001)` чи `CoFeB(001)`, то тунелювання стає симетрійно-залежним (*symmetry-filtered tunneling*).

Хвильові функції електронів у зоні Фермі заліза класифікуються за симетрією: `Δ1` (s-p-d гібридизовані стани), `Δ5` та `Δ2'`. У кристалічному `MgO` загасання хвильових функцій симетрії `Δ1` відбувається набагато повільніше, ніж для інших симетрій. 

Оскільки на рівні Фермі заліза електрони зі спіном «вгору» мають 100% поляризацію за симетрією `Δ1`, бар'єр `MgO` працює як ідеальний квантовий фільтр. Це забезпечує ефективну поляризацію `P_eff → 1`, піднімаючи теоретичний TMR до тисяч відсотків, а практичний — понад 600%.

### 5. Динаміка намагніченості та рівняння Ландау — Ліфшиця — Гільберта (LLG)

У швидкісній спінтроніці (перемикання MRAM за частки наносекунди) розсіювання та перемагнічування вільного магнітного шару описується диференціальним рівнянням Ландау — Ліфшиця — Гільберта (LLG):

```
d m / dt = - γ · (m × H_eff) + α_d · (m × d m / dt) + T_STT              [Рівняння LLG зі спіновим моментом]
```

де `m = M / M_s` — нормований вектор намагніченості, `γ` — гіромагнітне відношення, `H_eff` — ефективне магнітне поле, `α_d` — безрозмірний коефіцієнт демпфування Гільберта, а `T_STT` — спіновий обертальний момент (*Spin-Transfer Torque*):

```
T_STT = γ_s · (m × (m × m_pin))                                         [Член Слончевського для STT]
```

де `m_pin` — вектор намагніченості зафіксованого шару. Рівняння LLG описує прецесію вектора намагніченості навколо ефективного поля з поступовим згасанням спінових хвиль та перекиданням домену.
