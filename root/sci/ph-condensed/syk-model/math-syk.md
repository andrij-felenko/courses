# 🧮 Математичне виведення рівнянь Швінгера-Дайсона та перевальна точка

Ця вставка містить точне математичне виведення рівнянь Швінгера-Дайсона, ефективної дії та термодинамічних параметрів моделі Зачдева-Є-Кітаєва (SYK) у границі великої кількості Майоранівських ферміонів `N → ∞` за допомогою формалізму функціонального інтегрування та методу перевальної точки.

## 1. Функціональний інтеграл та усереднення за загартованим безпорядком

Розглянемо квантову систему з `N` дійсних Майоранівських ферміонів `χ_i(τ)` (де `i = 1, 2, ..., N`), які задовольняють алгебрі Кліффорда `{χ_i, χ_j} = 2·δ_ij`. У формалізмі континуального інтегрування за антикомутуючими Грассмановими змінними на евклідовому часовому колі `τ ∈ [0, β]` (де `β = 1 / (k_B T)` — обернена температура), статистична сума `Z` для конкретної реалізації випадкових зв'язків має вигляд:

```
Z[J] = ∫ Dχ · exp( - S[χ, J] )
```

Евклідова дія `S[χ, J]` складається з вільного кінетичного терма та чотиричастинкового терма взаємодії:

```
S[χ, J] = ∫₀^β dτ [ (1/2) · ∑_{i=1}^{N} χ_i(τ) · ∂_τ χ_i(τ) + (1 / 4!) · ∑_{i,j,k,l=1}^{N} J_ijkl · χ_i(τ) χ_j(τ) χ_k(τ) χ_l(τ) ]
```

Грассманові поля `χ_i(τ)` задовольняють антиперіодичним граничним умовам у часі `χ_i(β) = -χ_i(0)`.

Оскільки константи зв'язку `J_ijkl` вибираються незалежно з випадкового гаусового ансамблю з нульовим середнім `⟨J_ijkl⟩ = 0` та дисперсією `⟨ (J_ijkl)² ⟩ = 6·J² / N³`, розрахунок термодинамічних властивостей вимагає обчислення усередненого за безпорядком логарифма статистичної суми `⟨ ln Z ⟩_J`.

Завдяки тому, що у границі `N → ∞` флуктуації між різними реалізаціями безпорядку пригнічуються як `O(1/N)`, ми можемо виконувати усереднення безпосередньо для самої статистичної суми `⟨ Z ⟩_J` (що відповідає усередненню ув'язаних реплік при кількості реплік `n → 0`).

Використовуючи формулу точного гаусового інтегрування по скалярних змінних `⟨ exp(- A · J) ⟩_J = exp( (1/2) · A² · ⟨J²⟩ )`, усереднення виразу `exp(- S[χ, J])` по усім комбінаціям `J_ijkl` приносить чотирипаровий терм взаємодії, який є білокальним по двох моментах уявного часу `τ₁` та `τ₂`:

```
⟨ Z ⟩_J = ∫ Dχ · exp( - S_eff^(1)[χ] )

S_eff^(1)[χ] = (1/2) · ∫₀^β dτ ∑_{i=1}^{N} χ_i(τ) · ∂_τ χ_i(τ)
  - (J² / (2·q·N^(q-1))) · ∫₀^β dτ₁ dτ₂ [ ∑_{i=1}^{N} χ_i(τ₁) · χ_i(τ₂) ]^q
```

для випадку чотиричастинкової взаємодії `q = 4`.

Ключовий математичний момент полягає у тому, що нелінійний терм взаємодії залежить виключно від скалярного комбінованого добутку по усім `N` ферміонних індексах `∑_{i=1}^{N} χ_i(τ₁) χ_i(τ₂)`.

## 2. Введення білокальних колективних полів G(τ₁, τ₂) та Σ(τ₁, τ₂)

Щоб перетворити четвертий ступінь Грассманових полів на квадратичну форму, введемо колективне білокальне поле `G(τ₁, τ₂)` (функцію Гріна), яке описує середній парний корелятор ферміонів:

```
G(τ₁, τ₂) = (-1 / N) · ∑_{i=1}^{N} χ_i(τ₁) · χ_i(τ₂)
```

Для суворого введення цього поля під функціональний інтеграл вставимо тотожність одиниці за допомогою функціональної дельта-функції `δ( N·G(τ₁, τ₂) + ∑_i χ_i(τ₁)χ_i(τ₂) )`. Записуючи дельта-функцію через її інтегральне представлення Фур'є з множником Лагранжа — білокальним полем самоенергії `Σ(τ₁, τ₂)` — отримуємо:

```
1 = ∫ DG DΣ · exp( (N/2) · ∫₀^β dτ₁ dτ₂ Σ(τ₁, τ₂) · [ G(τ₁, τ₂) + (1/N) · ∑_{i=1}^{N} χ_i(τ₁) χ_i(τ₂) ] )
```

Підставляючи це розширення під континуальний інтеграл, вихідний функціонал повністю розпадається на суму суто Грассманової дії та білокальної дії колективних полів:

```
⟨ Z ⟩_J = ∫ DG DΣ Dχ · exp( - S_tot[G, Σ, χ] )

S_tot = (1/2) · ∫ dτ₁ dτ₂ ∑_{i=1}^{N} χ_i(τ₁) · [ δ(τ₁ - τ₂)·∂_τ₂ - Σ(τ₁, τ₂) ] · χ_i(τ₂)
  + (N/2) · ∫ dτ₁ dτ₂ [ Σ(τ₁, τ₂) G(τ₁, τ₂) - (J² / q) · [G(τ₁, τ₂)]^q ]
```

Тепер Грассманові змінними `χ_i` входять у дію строго квадратично через білокальний диференціальний оператор `K = ∂_τ - Σ`. Це дозволяє виконати точне функціональне інтегрування за ферміонними полями `Dχ` за допомогою стандартної формули березінського інтегрування по Грассманових змінах `∫ Dχ exp(- (1/2) χ K χ) = [det(K)]^(N/2) = exp( (N/2) · Tr ln K )`.

## 3. Точна ефективна дія великого N та варіаційні рівняння

Після інтегрування по ферміонних ступенях вільності отримуємо точний функціонал **ефективної дії колективних полів** `S_eff[G, Σ]`:

```
S_eff[G, Σ] / N = - (1/2) · Tr ln ( ∂_τ - Σ )
  + (1/2) · ∫₀^β dτ₁ dτ₂ [ Σ(τ₁, τ₂) · G(τ₁, τ₂) - (J² / q) · [G(τ₁, τ₂)]^q ]
```

Зверніть увагу: перед усім функціоналом ефективної дії виникає множник `N` (кількість частинок).

У термодинамічній границі `N → ∞` квантовий функціональний інтеграл `∫ DG DΣ exp(- N · S_eff[G, Σ])` точно обчислюється **методом перевальної точки** (saddle-point approximation). Класичний перевальний розв'язок відповідає мінімуму ефективної дії і шукається з умови обнулення перших варіаційних похідних:

```
δ S_eff / δ G(τ₁, τ₂) = 0
δ S_eff / δ Σ(τ₁, τ₂) = 0
```

Виконаємо функціональне диференціювання по полю `G(τ₁, τ₂)`:

```
δ S_eff / δ G(τ₁, τ₂) = (N/2) · [ Σ(τ₁, τ₂) - J² · [G(τ₁, τ₂)]^(q - 1) ] = 0
```

Звідси отримуємо перше фундаментальне самоузгоджене рівняння для самоенергії:

```
Σ(τ₁, τ₂) = J² · [G(τ₁, τ₂)]^(q - 1)
```

Тепер виконаємо функціональне диференціювання по полю самоенергії `Σ(τ₁, τ₂)`:

```
δ S_eff / δ Σ(τ₁, τ₂) = (N/2) · [ G(τ₁, τ₂) - (∂_τ - Σ)⁻¹(τ₁, τ₂) ] = 0
```

Оскільки за визначенням операторної оберненої матриці `(∂_τ - Σ) * G = I`, це варіаційне рівняння задає інтегральне рівняння Дайсона у часовому просторі:

```
∫₀^β dτ' [ δ(τ₁ - τ')·∂_τ' - Σ(τ₁, τ') ] · G(τ', τ₂) = δ(τ₁ - τ₂)
```

Завдяки трансляційній інваріантності за часом при термічній рівновазі, поля залежать лише від різниці часів `τ = τ₁ - τ₂`. Переходячи до дискретних частот Мацубари `ω_n = (2n + 1)·π / β`, варіаційні рівняння перевальної точки набувають закритий вигляд:

```
G(ω_n)⁻¹ = i · ω_n - Σ(ω_n)
Σ(τ) = J² · [G(τ)]^(q - 1)
```

Отже, рівняння Швінгера-Дайсона є **точними рівняннями перевальної точки** фундаментальної ефективної дії при `N → ∞`.

## 4. Конформний розв'язок у низькоенергетичній границі

У низькотемпературному режимі `J·τ ≫ 1` (або `ω ≪ J`) ми можемо знехтувати кінетичним членам `i·ω_n` у рівнянні Дайсона. Рівняння перетворюється на чисто інтегральне співвідношення:

```
∫₀^β dτ' Σ(τ - τ') · G(τ' - τ'') = -δ(τ - τ'')
```

Це рівняння володіє нескінченновимірною репараметризаційною симетрією `τ ↦ f(τ)`. Для шуканої функції Гріна у степенному вигляді `G_c(τ) = C · sgn(τ) / |τ|^(2 Δ)` підстановка у рівняння дає значення масштабувальної розмірності ферміона `Δ = 1/q` (для `q = 4` маємо `Δ = 1/4`).

Амплітуда `C` визначається з умов конформного інтегрування:

```
C = [ (1 - 2Δ) · tan(π Δ) / (2 π J²) ]^(Δ) = ( 1 / (2 π J²) )^(1/4)    [при q = 4]
```

Виконуючи конформне перетворення з дійсної осі `ℝ` на термічне коло `S¹` товщиною `β` за допомогою функції `f(τ) = tan(π·τ / β)`, отримуємо точний тепловий розв'язок для функції Гріна при скінченній температурі:

```
G_c(τ) = C · sgn(τ) · [ π / (β · sin(π·τ / β)) ]^(2 Δ)
```

## 5. Обчислення залишкової ентропії S₀

Підставляючи знайдений конформний розв'язок `G_c(τ)` та `Σ_c(τ)` у функціонал ефективної дії `S_eff`, можна обчислити значення вільної енергії системи `F = k_B T · S_eff[G_c, Σ_c]`.

Диференціюючи вільну енергію по температурі `S = - ∂F / ∂T` і спрямовуючи температуру до нуля `T → 0`, знаходимо точну величину залишкової питомої ентропії основного стану `S₀ = N · s₀`:

```
s₀ = ∫₀^(1/q) π · (1/2 - x) · tan(π x) dx
```

Для чотиричастинкової моделі SYK (`q = 4`) виконуємо інтегрування:

```
s₀ = (G / π) + (1/2) · ln 2 ≈ 0.464848...
```

де `G = ∑_{k=0}^∞ (-1)^k / (2k + 1)² ≈ 0.915965...` — стала Каталана.

## 6. Чотириточкові кореляційні функції та спектр конформних розмірностей

Для дослідження флуктуацій понад перевальною точкою та обчислення квантового хаосу необхідно вивчити чотириточкову функцію Гріна:

```
G₄(τ₁, τ₂, τ₃, τ₄) = (1 / N²) · ∑_{i,j=1}^{N} ⟨ T_τ χ_i(τ₁) χ_i(τ₂) χ_j(τ₃) χ_j(τ₄) ⟩
```

Розклад цієї функції за порядками малості `1/N` має вигляд `G₄ = G(τ₁₂) G(τ₃₄) + (1/N) · F(τ₁, τ₂, τ₃, τ₄) + O(1/N²)`.

Незбурена частина `F` описується сумуванням драбинкових діаграм (ladder diagrams), яке зводиться до інтегрального рівняння Бете-Солпітера із драбинковим ядром `K`:

```
∫ dτ₅ dτ₆ K(τ₁, τ₂; τ₅, τ₆) · F(τ₅, τ₆, τ₃, τ₄) = F(τ₁, τ₂, τ₃, τ₄)
```

Оператор ядра `K` діє на білокальні функції як `K = (q - 1) · J² · G(τ₁₅) G(τ₂₆) [G(τ₅₆)]^(q - 2)`.

Завдяки емерджентній симетрії `SL(2, ℝ)` власні функції ядра `K` є інваріантними відносно конформних перетворень і характеризуються конформною розмірністю `h`. Власні значення ядра `k(h)` описуються аналітичною функцією:

```
k(h) = - (q - 1) · ( tan(π h / 2 - π / q) / tan(π h / 2 + π / q) ) · ( (γ(1 - 2/q) · γ(h)) / (γ(1 - 2/q + h)) )
```

Умова `k(h) = 1` визначає фізичний спектр конформних операторів у моделі SYK.

Найважливішим розв'язком цієї умови є значення **`h = 2`**, для якого `k(2) = 1` для будь-яких значеннях `q`. Конформна розмірність `h = 2` відповідає оператору енергії-імпульсу та зсувам уявного часу, тобто саме цей модальний розв'язок породжує псевдоґолдстоунівський режим **похідної Шварціана**.

Аналітичне продовження розв'язку з `h = 2` на дійсну часову вісь дає експоненційне зростання квантового хаосу `e^(λ_L · t)` із показником Ляпунова `λ_L = 2·π·k_B·T / ℏ`, що підтверджує строге насичення межі хаосу MSS.
