# 🔌 Конструкція автоклавних реакторів високого тиску

Конструкція, розрахунки напружень, матеріалознавство, ущільнювальні затвори високого тиску та інженерні вузли безпеки автоклавних реакторів забезпечують гідротермальний синтез монокристалів при температурах до 500 °C та тисках до 300 МПа.

---

### 1. Механічний розрахунок корпусу та вибір конструктивних сталей

Гідротермальний автоклав являє собою вертикальний товстостінний циліндричний сусуд високого тиску, призначений для тривалої безперервної роботи (від 30 до 120 діб за один технологічний цикл) у середовищі гарячих лужних флюїдів.

При робочих параметрах `T = 350–420 °C` та тиску `P = 100–150 МПа` у стінках циліндричного корпусу виникає складний триаксіальний напружений стан. Згідно з класичними формулами Ламе для товстостінних судин, розподіл окружних (тангенціальних) напружень `σ_θ` та радіальних напружень `σ_r` по радіусу стінки `r` (від внутрішнього радіуса `r_int` до зовнішнього `r_ext`) описується виразами:

```
σ_θ(r) = P · (r_int² / (r_ext² - r_int²)) · (1 + r_ext² / r²)
σ_r(r) = P · (r_int² / (r_ext² - r_int²)) · (1 - r_ext² / r²)
```

Максимальне окружне напруження розтягу `σ_θ_max` виникає на внутрішній поверхні корпусу (`r = r_int`):

```
σ_θ_max = P · (r_ext² + r_int²) / (r_ext² - r_int²)
```

Еквівалентне напруження за гіпотезою Губера — Мизеса (`σ_eq`) на внутрішній стінці автоклава становить:

```
σ_eq = √ (σ_θ² - σ_θ · σ_r + σ_r²)
```

Для забезпечення допустимого коефіцієнта запасу міцності `n ≥ 2.5` проти границі плинності сталі при робочій температурі 400 °C співвідношення зовнішнього та внутрішнього діаметрів становить `D_ext / D_int = 1.8–2.5`.

Наприклад, при внутрішньому діаметрі автоклава `D_int = 400 мм` (об'єм порожнини близько 1000 літрів) товщина сталевої стінки сягає `180–220 мм`, а зовнішній діаметр корпуса — `800–840 мм`. Загальна маса порожнього автоклава такого розміру перевищує 15–20 тонн.

```
Внутрішній діаметр D_int = 400 мм  <==  Товщина стінки t = 200 мм  ==>  Зовнішній діаметр D_ext = 800 мм
```

#### Матеріалознавство корпусу
Корпус автоклава виготовляють методом суцільного кування з суцільної сталевої зливки з подальшим термозміцненням (загартування з високотемпературним відпуском). Застосовують високоміцні леговані сталі:
- **Хромомолібденванадієві сталі (25Х3МФС, 15Х5М, AISI 4140, 4340):** Забезпечують високу границю плинності (`σ_0.2 > 750 МПа`) та високий опір ползучості при температурах до 450 °C.
- **Нікель-хромові жароміцні сплави (Inconel 718, Nimonic 80A):** Застосовують для лабораторних автоклавів надвисокого тиску (`P > 250 МПа`), оскільки вони зберігають виключну міцність та стійкість до водневого крихчення при температурах понад 500 °C.

### 2. Затвор Бріджмена та вузли ущільнення під тиском

Найкритичнішим та найвідповідальнішим вузлом автоклава є верхній кришковий затвор. Звичайні фланцеві з'єднання з болтовим затягуванням нездатні утримати тиск 150 МПа при підвищеній температурі через релаксацію напружень у шпильках та релаксацію прокладок.

У промислових гідротермальних автоклавах застосовують **самоущільнюваний затвор Бріджмена** (*Bridgman self-sealing closure*), розроблений американським фізиком Персі Бріджменом (Нобелівська премія 1946 року). Принцип його дії базується на ефекті нескомпенсованої площі.

```
+---------------------------------------------------+
|               Верхня нажимна гайка                |
+---------------------------------------------------+
       ||                                   ||
       \/                                   \/
+---------------------------------------------------+
|                Поршень (Кришка)                   |
|                   Площа A_p                       |
+---------------------------------------------------+
        ||                                 ||
        \/                                 \/
+---------------------------------------------------+
|            Ущільнювальне кільце (A_r)              | <--- Тиск у кільці:
+---------------------------------------------------+      P_ring = P · (A_p / A_r) > P
  ||                                             ||
  ||====== Внутрішній флюїд під тиском P =======||
```

#### Принцип дії нескомпенсованої площі
1. Внутрішній тиск флюїду `P` давить на нижній торець рухомого поршня (кришки) площею `A_p = π · r_int²`.
2. Повна сила тиску `F = P · A_p` передається через виступ поршня на м'якше металеве ущільнювальне кільце.
3. Ущільнювальне кільце спирається на упорний бурт корпусу, але має меншу площу контакта `A_r < A_p` (частина площі поршня залишається нескомпенсованою).
4. Внаслідок цього тиск усередині матеріалу ущільнювального кільця `P_ring` стає більшим за тиск флюїду всередині автоклава:

```
P_ring = P · (A_p / A_r) > P
```

Оскільки `P_ring > P`, матеріал кільця пластично деформується і герметично заповнює мікронерівності між поршнем і стінкою корпусу, повністю унеможливлюючи витік середовища. Чим вищий тиск всередині автоклава, тим сильніше стискається ущільнювальний елемент (самоущільнення).

Матеріал ущільнювальних кілець: відпалена червона мідь (`Cu 99.9%`), чистий нікель (`Ni 99.5%`), м'яке армко-залізо або сріблені нікелеві прокладки.

### 3. Внутрішній захист від корозії та протикорозійні лайнери

Гарячі лужні розчини (`Na₂CO₃`, `NaOH`) при температурах вище 300 °C виявляють високу хімічну агресивність щодо легованих сталей. Контакт розчину зі сталевою стінкою викликає лужний корозійний розтріскування (міжкристалічну корозію) та розчинення заліза з утворенням аніонів гематиту або магнетиту (`NaFeO₂`), що забруднює ростучий кристал кварцю домішками заліза та надає йому зеленого або коричневого забарвлення.

Для захисту застосовують два методи:
1. **Пасивація стінок (промисловий метод):** Предварне формування на внутрішній поверхні автоклава щільного суцільного захисного шару магнетиту (`Fe₃O₄`) шляхом пасивуючої обробки концентрованими лугами при високій температурі без шихти.
2. **Внутрішні вкладиші (лайнери):** Для росту високочистих оптичних монокристалів всередину автоклава вставляють тонкостінний герметичний вкладиш із чистого срібла (`Ag 99.99%`), золота, платини або платинованого титану. Срібло є абсолютно інертним у гарячих карбонатних розчинах і запобігає перенесенню домішок важких металів у кристал.

### 4. Системи нагріву, бафли та засоби аварійного захисту

#### Зональні нагрівачі
Для створення точного температурного градієнта автоклав оснащують зовнішніми багатосекційними електричними нагрівачами опору (або індукційними нагрівачами). Нижній нагрівач зони розчинення має підвищену потужність для підтримки `T_diss = 380–410 °C`, а верхній нагрівач підтримує `T_grow = 330–350 °C`. Зовні автоклав закривається потужним шарнірним теплоізоляційним кожухом із мінеральної вати.

#### Знімні перфоровані бафли
Бафл являє собою круглясту сталеву або срібну пластину товщиною 5–12 мм із просвердленими вертикальними отворами. Він встановлюється на розпірних ніжках строго на межі між шихтою та затравочними рамами. Відсоток перфорації `f_baffle` підбирається під тип розчинника та геометричний масштаб автоклава:
- Для розчинів `Na₂CO₃` застосовують `f_baffle = 2–5%`;
- Для в'язкіших розчинів `NaOH` — `f_baffle = 5–8%`.

#### Запобіжні розривні мембрани (Safety Burst Discs)
Оскільки перевищення коефіцієнта заповнення автоклава водою або локальний перегрів може призвести до скачкоподібного зростання тиску вище 250 МПа (через малу стисливість води при відсутності парової фази), кожен автоклав обов'язково обладнують аварійною розривною мембраною із нікелю або термостійких сплавів.

Мембрана розрахована на калібрований зріз при перевищенні тиску `P_burst = 1.3 · P_work` (наприклад, 180 МПа) і скидає пароводяну суміш у захисний амортизаційний бункер, запобігаючи руйнуванню корпусу автоклава.

### 5. Регламент технічного обслуговування та моніторинг ползучості

Автоклави високого тиску належать до обладнання підвищеної небезпеки. У процесі експлуатації проводиться постійний моніторинг стану корпусу:
- **Ультразвукова дефектоскопія (УЗД):** Перевірка стінок на наявність внутрішніх міжкристалічних мікротріщин після кожного 3–5 циклів синтезу.
- **Вимірювання залишкової деформації ползучості:** Контроль зовнішнього діаметра корпусу за допомогою мікрометричних скоб. Якщо накопичена пластична деформація ползучості сталі перевищує `0.2%` від початкового діаметра, автоклав підлягає виведенню з експлуатації.

Дотримання цих інженерних вимог забезпечує надійну роботу автоклавів протягом десятків років експлуатації.
