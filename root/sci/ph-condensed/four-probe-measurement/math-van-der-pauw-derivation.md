# 🧮 Виведення теореми Ван дер Пау та геометричних коефіцієнтів

Ця математична вставка містить аналітичне виведення розподілу електричного потенціалу від точкових зондів у напівнескінченному 3D масиві та 2D тонкій плівці, строге виведення геометричного поправкового коефіцієнта товщини `F(s/w)` методом дзеркальних відображень та повне математичне доведення теореми Ван дер Пау з використанням теорії конформних відображень.

## 1. Потенціал точкового джерела струму у 3D напівнескінченному середовищі

Розглянемо ізотропне однорідне середовище з об'ємним питомим опором `ρ`, яке займає нижній півпростір `z ≥ 0` (межа з повітрям розташована в площині `z = 0`). У точку `r = 0` на поверхні вводиться постійний вимірювальний струм `I` від зовнішнього джерела через точковий контакт (зондову голку).

Оскільки повітря над поверхнею `z < 0` є ідеальним діелектриком, струм не може виходити у верхній півпростір. Нормальна складова густини струму на межі дорівнює нулю (`J_z(x, y, 0) = 0`). Через осьову та радіальну симетрію струм розтікається від точки інжекції рівномірно в усіх напрямках усередині півпростору.

Для обчислення потенціалу скористаємося дифенціальною формою закону збереження заряду в стаціонарному випадку (рівнянням неперервності):

```
∇ · J = 0               [рівняння неперервності для стаціонарного струму]
```

За диференціальним законом Ома густина струму `J` пов'язана з напруженістю електричного поля `E` та потенціалом `V` співвідношенням:

```
J = σ · E = (1 / ρ) · (-∇V)
```

Підставляючи вираз для `J` у рівняння неперервності при сталому питомому опорі `ρ = const`, отримуємо рівняння Лапласа для скалярного потенціалу `V`:

```
∇²V = 0                 [рівняння Лапласа у провідному середовищі]
```

У сферичній системі координат із центром у точці інжекції струму рівняння Лапласа завдяки сферичній симетрії полегшується, оскільки потенціал залежить лише від радіальної відстані `r`:

```
(1 / r²) · (d/dr) (r² · dV/dr) = 0
```

Інтегруючи це диференціальне рівняння, отримуємо загальний вигляд розв'язку:

```
dV/dr = C₁ / r²
V(r) = -C₁ / r + C₂
```

Для визначення константи `C₁` скористаємося граничною умовою проходження повного струму `I` через півсферичну поверхню радіуса `r` у півпросторі. Площа півсфери становить `A(r) = 2π·r²`. Повний струм через півсферу обчислюється як інтеграл від густини струму:

```
I = ∫ J · dA = J(r) · (2π·r²)
```

Звідси густина струму `J(r)` на відстані `r` дорівнює:

```
J(r) = I / (2π·r²)      [густина струму на півсфері радіуса r]
```

За диференціальним законом Ома напруженість електричного поля `E(r)` дорівнює:

```
E(r) = ρ · J(r) = ρ·I / (2π·r²)
```

Оскільки `E(r) = -dV/dr`, порівнюємо вирази й знаходимо константу `C₁ = ρ·I / (2π)`. Приймаючи потенціал на нескінченності рівним нулю (`V(∞) = 0`, що дає `C₂ = 0`), отримуємо остаточний вираз для потенціалу точкового джерела на поверхні півпростору:

```
V(r) = ρ·I / (2π·r)     [потенціал точкового джерела струму у півпросторі]
```

## 2. Потенціальний розподіл для колінеарної 4-зондової геометрії

Розглянемо чотири зонди, розташовані вздовж однієї прямої лінії з однаковим кроком `s`. Зонди позначимо номерами 1, 2, 3, 4. 

Постійний струм `+I` подається через зонд 1, а виходить `-I` через зонд 4. Оскільки рівняння Лапласа є лінійним, підсумковий потенціал `V_total` у будь-якій точці поверхні дорівнює алгебраїчній сумі потенціалів, створених кожним із двох струмових джерел окремо (принцип суперпозиції):

```
V_total(r₁, r₄) = V₁(r₁) + V₄(r₄)
                = (ρ·I / 2π) · (1/r₁ - 1/r₄)
```

де `r₁` — відстань від даної точки до зонда 1 (`+I`), а `r₄` — відстань до зонда 4 (`-I`).

Обчислимо потенціал `V₂` у точці розташування потенціального зонда 2:
* Відстань від зонда 1 до зонда 2 дорівнює `r₁ = s`.
* Відстань від зонда 4 до зонда 2 дорівнює `r₄ = 2s`.

Покроковий розрахунок потенціалу `V₂`:

```
V₂ = (ρ·I / 2π) · (1/s - 1/(2s))
   = (ρ·I / 2π) · (2/(2s) - 1/(2s))     [зведення до спільного знаменника]
   = (ρ·I / 2π) · (1 / (2s))
   = ρ·I / (4π·s)                       [перемноження знаменників]
```

Обчислимо потенціал `V₃` у точці розташування потенціального зонда 3:
* Відстань від зонда 1 до зонда 3 дорівнює `r₁ = 2s`.
* Відстань від зонда 4 до зонда 3 дорівнює `r₄ = s`.

Покроковий розрахунок потенціалу `V₃`:

```
V₃ = (ρ·I / 2π) · (1/(2s) - 1/s)
   = (ρ·I / 2π) · (1/(2s) - 2/(2s))     [зведення до спільного знаменника]
   = (ρ·I / 2π) · (-1 / (2s))
   = -ρ·I / (4π·s)                      [знак мінус через близькість від'ємного джерела]
```

Різниця потенціалів `ΔV = V₂ - V₃`, яка реєструється вольтметром між зондами 2 та 3:

```
ΔV = V₂ - V₃
   = ρ·I / (4π·s) - (-ρ·I / (4π·s))
   = ρ·I / (4π·s) + ρ·I / (4π·s)        [раскриття подвійного мінуса]
   = 2·ρ·I / (4π·s)
   = ρ·I / (2π·s)                       [скорочення на 2]
```

Виражаємо питомий опір `ρ` через виміряні величини струму `I`, напруги `ΔV` та геометричний крок зондів `s`:

```
ρ = 2π·s · (ΔV / I)                     [класична формула Вальдеса для 3D]
```

## 3. Границя тонкої плівки (2D середовище) та розрахунок R_s

Якщо товщина зразка `w` є набагато меншою за міжзондову відстань `s` (`w << s`), розтікання струму стає двовимірним. На верхній та нижній поверхнях плівки нормальна складова струму дорівнює нулю (`J_z = 0`), тому лінії струму орієнтовані строго паралельно поверхні плівки.

Для 2D джерела струму геометрія розтікання є циліндричною. Струм `I` проходить через бічну поверхню циліндра радіуса `r` та висоти `w`. Площа бічної поверхні становить `A(r) = 2π·r·w`.

Густина струму `J(r)` на відстані `r` дорівнює:

```
J(r) = I / (2π·r·w)                     [струм через бічну поверхню циліндра]
```

Напруженість електричного поля `E(r)` за диференціальним законом Ома:

```
E(r) = ρ · J(r) = ρ·I / (2π·r·w)
```

Потенціал `V(r)` обчислюється шляхом інтегрування напруженості поля `E(r)`:

```
V(r) = -∫ E(r') dr'
     = -(ρ·I / (2π·w)) · ∫ (1/r') dr'
     = -(ρ·I / (2π·w)) · ln(r) + C      [логарифмічний потенціал 2D джерела]
```

За принципом суперпозиції для струмових зондів 1 (`+I`) та 4 (`-I`) потенціал у довільній точці 2D плівки дорівнює:

```
V_total(r₁, r₄) = -(ρ·I / (2π·w)) · ln(r₁) + (ρ·I / (2π·w)) · ln(r₄)
                = (ρ·I / (2π·w)) · ln(r₄ / r₁)
```

Обчислимо потенціал `V₂` на зонді 2 (`r₁ = s`, `r₄ = 2s`):

```
V₂ = (ρ·I / (2π·w)) · ln(2s / s)
   = (ρ·I / (2π·w)) · ln(2)             [скорочення s]
```

Обчислимо потенціал `V₃` на зонді 3 (`r₁ = 2s`, `r₄ = s`):

```
V₃ = (ρ·I / (2π·w)) · ln(s / (2s))
   = (ρ·I / (2π·w)) · ln(1/2)
   = -(ρ·I / (2π·w)) · ln(2)            [властивість логарифма ln(1/2) = -ln(2)]
```

Обчислимо вимірювану різницю потенціалів `ΔV = V₂ - V₃`:

```
ΔV = V₂ - V₃
   = (ρ·I / (2π·w)) · ln(2) - (-(ρ·I / (2π·w)) · ln(2))
   = (ρ·I / (2π·w)) · ln(2) + (ρ·I / (2π·w)) · ln(2)
   = 2 · (ρ·I / (2π·w)) · ln(2)
   = (ρ·I / (π·w)) · ln(2)              [скорочення на 2]
```

Виражаємо поверхневий (листковий) опір `R_s = ρ / w`:

```
R_s = ρ / w
    = (π / ln 2) · (ΔV / I)             [точний алгебраїчний вираз]
```

Обчислюємо чисельний коефіцієнт `π / ln 2`:

```
π / ln 2 = 3.141592653589793 / 0.6931471805599453
         = 4.532360141827194            [чисельне значення коефіцієнта]
```

Таким чином, для 2D тонкої плівки поверхневий опір визначається формулою:

```
R_s = 4.53236 · (ΔV / I)                [практична формула для тонких плівок]
```

## 4. Виведення поправкового коефіцієнта F(s/w) методом дзеркальних відображень

Коли товщина зразка `w` стає порівнянною з міжзондовою відстанню `s` (`0.5 ≤ w/s ≤ 3.0`), розподіл електричного струму перебуває у проміжному стані між 2D та 3D. 

На верхній поверхні `z = 0` та нижній поверхні `z = w` струм не може виходити у навколишнє диелектричне середовище. Це формує межеву умову другого роду (умову Неймана):

```
∂V/∂z |_(z=0) = 0,    ∂V/∂z |_(z=w) = 0
```

Для задоволення цих умов застосовується метод нескінченного ряду дзеркальних відображень. Джерело струму `+I`, розташоване у точці `(0, 0, 0)`, відбивається відносно площин `z = 0` та `z = w`, утворюючи нескінченний ряд дзеркальних джерел у точках `z_n = ±2n·w` для всіх `n = 1, 2, 3, ...`.

Відстань від n-го дзеркального зображення струмового зонда до потенціального зонда визначається за теоремою Піфагора:
* Від дзеркального зображення зонда 1 (`+I`) на відстані `s` до зонда 2: `d₁,ₙ = √(s² + (2n·w)²)`.
* Від дзеркального зображення зонда 4 (`-I`) на відстані `2s` до зонда 2: `d₄,ₙ = √((2s)² + (2n·w)²) = √(4s² + (2n·w)²)`.

Сумуючи внески від первинних джерел та всіх їхніх дзеркальних зображень, отримуємо вираз для різниці потенціалів `ΔV`:

```
ΔV = (ρ·I / (2π·s)) · [ 1 + 4 · ∑_{n=1}^∞ ( 1 / √(1 + (2n·w/s)²) - 1 / √(4 + (2n·w/s)²) ) ]
```

Позначимо суму нескінченного ряду як геометричну поправкову функцію `S(w/s)`:

```
S(w/s) = 1 + 4 · ∑_{n=1}^∞ ( 1 / √(1 + (2n·w/s)²) - 1 / √(4 + (2n·w/s)²) )
```

Тоді виражаємо питомий опір `ρ`:

```
ρ = 2π·s · (ΔV / I) · [ 1 / S(w/s) ]
```

Для переходу до поверхневого опору `R_s = ρ / w` перепишемо вираз через відношення `w/s`:

```
R_s = (ρ / w) = (2π · (s/w) / S(w/s)) · (ΔV / I)
```

Порівнюючи з формулою для ідеальної плівки `R_s = (π / ln 2) · (ΔV / I)`, отримуємо точний вираз для геометричного поправкового коефіцієнта `F₁(w/s)`:

```
F₁(w/s) = ((w/s) / (2 · ln 2)) · [ 1 / S(w/s) ]
```

Розглянемо граничні випадки цього коефіцієнта:
1. **Граничний випадок тонкої плівки (`w/s → 0`):**
   При малій товщині ряд `S(w/s)` наближається до асимптотичного значення `S(w/s) ≈ (2·ln 2) / (w/s)`. Підставляючи це у формулу, отримуємо `F₁(w/s) → (π / (2·ln 2)) · (w/s)`, що дає класичний розрахунок `R_s = 4.53236 · (ΔV/I)`.
2. **Граничний випадок масивного тіла (`w/s → ∞`):**
   При великій товщині внесок дзеркальних зображень прямує до нуля, оскільки `(2n·w/s) >> 1`. Ряд `S(w/s) → 1.0`, і коефіцієнт `F₁(w/s)` забезпечує точний перехід до 3D формули `ρ = 2π·s·(ΔV/I)`.

## 5. Доведення теореми Ван дер Пау через конформне відображення

Нехай плоский зразок однорідної товщини `w` займає довільну однозв'язну область `Ω` у площині комплексної змінної `z = x + i·y`. На крайці зразка `∂Ω` розташовано чотири точкові контакти A, B, C, D у порядку обходу проти годинникової стрілки.

За теоремою Рімана про конформне відображення існує єдина аналітична функція `w = f(z)`, яка конформно відображає внутрішність області `Ω` на верхню півплощину `ℍ = {w ∈ ℂ : Im(w) > 0}`, а межу `∂Ω` — на дійсну вісь `Im(w) = 0`.

При цьому контакти A, B, C, D переходять у дійсні точки `a < b < c < d` на дійсному промені.

Оскільки рівняння Лапласа `∇²V = 0` та межеві умови Неймана `∂V/∂n = 0` є інваріантними відносно конформних перетворень у 2D, поверхневий опір між контактами у півплощині точно дорівнює опору початкового зразка довільної форми.

Для обчислення опору конфігурації A у півплощині (струм `I_AB` підводиться до точок `a` та `b`, напруга `V_DC` знімається між `d` та `c`) скористаємося методом зеленої функції для півплощини:

```
V_DC = (R_s · I_AB / π) · ln( ((b - a)·(d - c)) / ((c - a)·(d - b)) + 1 )
```

Введемо геометричний параметр `μ`, який є подвійним відношенням (Cross-Ratio) чотирьох точок `a, b, c, d` на дійсній осі:

```
μ = ((b - a)·(d - c)) / ((c - a)·(d - b))
```

Тоді вираз для опору `R_A = V_DC / I_AB` набуває вигляду:

```
R_A = (R_s / π) · ln(1 + μ)             [опір першої конфігурації]
```

Виразимо параметер `μ` через `R_A`:

```
-π·R_A / R_s = -ln(1 + μ)               [помножили на -π / R_s]
exp(-π·R_A / R_s) = exp(ln((1 + μ)⁻¹))
exp(-π·R_A / R_s) = 1 / (1 + μ)         [перша експоненціальна тотожність]
```

Для другої ортогональної конфігурації B (струм `I_BC` підводиться до точок `b` та `c`, напруга `V_AD` знімається між `a` та `d`) аналогічне конформне виведення дає:

```
R_B = V_AD / I_BC = (R_s / π) · ln( (1 + μ) / μ )
```

Виразимо подібну експоненційну функцію для `R_B`:

```
-π·R_B / R_s = -ln((1 + μ) / μ)         [помножили на -π / R_s]
exp(-π·R_B / R_s) = exp(ln(μ / (1 + μ)))
exp(-π·R_B / R_s) = μ / (1 + μ)         [друга експоненціальна тотожність]
```

Додамо дві отримані експоненційні тотожності для `R_A` та `R_B`:

```
exp(-π·R_A / R_s) + exp(-π·R_B / R_s)
= 1 / (1 + μ) + μ / (1 + μ)             [підстановка виразів через μ]
= (1 + μ) / (1 + μ)                     [зведення під спільний знаменник]
= 1                                     [скорочення чисельника та знаменника]
```

Таким чином, геометричний параметр `μ` повністю скоротився. Це означає, що фундаментальне рівняння Ван дер Пау:

```
exp(-π·R_A / R_s) + exp(-π·R_B / R_s) = 1
```

є абсолютно інваріантним відносно вибору точок `a, b, c, d`, а отже — доведено для зразка **будь-якої** однозв'язної конфігурації.
