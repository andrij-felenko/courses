# 🧮 Виведення квантового коефіцієнта передачі струму (CTR) та оптичних втрат

Цей матеріал містить математичне виведення коефіцієнта передачі струму (Current Transfer Ratio, CTR) оптрона на основі квантових та оптичних характеристик напівпровідникових матеріалів, розрахунок кута повного внутрішнього відбиття та оцінку світлозбору у діелектричному каналі.

## Математична декомпозиція коефіцієнта CTR

Коефіцієнт передачі струму визначається як відношення вихідного струму детектора `I_out` до вхідного струму світлодіода `I_in`:

```
CTR = (I_out / I_in) · 100%
```

Фізично перетворення струму в струм являє собою п'ятикаскадний послідовний процес, у якому кожен попередній етап формує вхідний потік для наступного. Кожен каскад характеризується власним коефіцієнтом корисної дії та квантовими втратами:

```
CTR = η_int · η_ext_LED · η_opt · η_det · β
```

де значення кожного з коефіцієнтів визначаються наступними фізичними величинами:
- `η_int` — внутрішня квантова ефективність світлодіода, яка описує ймовірність того, що інжектована електронно-діркова пара рекомбінує випромінювально з випусканням фотона, а не безипромінювально через центри Шокли — Рида — Холла чи оже-процеси.
- `η_ext_LED` — коефіцієнт оптичного виведення фотонів із кристала світлодіода у діелектричний середовищний бар'єр з урахуванням геометричного конуса виходу та френелівського відбиття.
- `η_opt` — геометричний коефіцієнт передачі світлового потоку через ізоляційний бар'єр до детектора з урахуванням перехоплення кутового розподілу випромінювання та відбиття від внутрішніх стінок корпуса.
- `η_det` — внутрішня квантова ефективність фотодетектора, яка задає кількість згенерованих фотоелектронів на один поглинутий у збедненій зоні фотон.
- `β` — коефіцієнт підсилення за струмом фототранзистора (для схем із первинним фотодіодом `β = 1`).

## Розрахунок коефіцієнта виведення світла з кристала (закон Снелла та ПВВ)

Кристал арсеніду галію (`GaAs`) має високий показник заломлення `n_semi ≈ 3.5`, тоді як прозорий ізоляційний силікон має `n_barrier ≈ 1.45`.

Згідно із законом заломлення Снелла, для світлового променя, який падає з всередині кристала на межу поділу із силіконом під кутом `θ_1`, кут заломлення у силіконі `θ_2` підпорядковується співвідношенню:

```
n_semi · sin(θ_1) = n_barrier · sin(θ_2)
```

Граничний критичний кут падіння `θ_c`, при перевищенні якого відбувається повне внутрішнє відбиття (ПВВ) і фотон не може вийти з кристала, визначається з умови, що кут заломлення досягає граничного значення `θ_2 = 90°`:

```
sin(θ_c) = n_barrier / n_semi
```

Підставивши числові значення показників заломлення для межі `GaAs` — силікон, отримуємо величину критичного кута:

```
sin(θ_c) = 1.45 / 3.50 = 0.4143
θ_c = arcsin(0.4143) ≈ 24.47°
```

Усі фотони, які падають на плоску поверхню кристала під кутами `θ > 24.47°`, зазнають повного внутрішнього відбиття і поглинаються у підкладці напівпровідника.

Тілесний кут конуса виходу фотонів `Ω_cone` обчислюється шляхом інтегрування елементарного тілесного кута у сферичних координатах від 0 до критичного кута `θ_c`:

```
Ω_cone = ∫₀^(2π) dφ ∫₀^(θ_c) sin(θ) dθ
= 2π · (1 - cos(θ_c))                          [інтегрування за сферичними кутами]
```

Скориставшись тригонометричним тотожністю `cos(θ_c) = √(1 - sin²(θ_c))`, виразимо косинус критичного кута через відношення показників заломлення середовищ:

```
cos(θ_c) = √(1 - (n_barrier / n_semi)²)
```

Для малих кутів виходу застосовується розвинення в ряд Тейлора для квадратного кореня:

```
1 - cos(θ_c) ≈ (1/2) · sin²(θ_c) = (1/2) · (n_barrier / n_semi)²
```

Отже, частка світлового потоку `η_cone`, що потрапляє у конус виходу з ізотропно випромінюючого кристала (повний тілесний кут сфери становить `4π` стерадіан), дорівнює відношенню відповідних тілесних кутів:

```
η_cone = Ω_cone / (4π)
= (2π · (1 - cos(θ_c))) / (4π)                 [підстановка тілесного кута конуса]
= (1/2) · (1 - √(1 - (n_barrier / n_semi)²))   [підстановка тригонометричної тотожності]
≈ (1/4) · (n_barrier / n_semi)²                [наближення для малих кутів]
```

Обчислимо геометричне виведення без урахування френелівського відбиття:

```
η_cone ≈ (1/4) · (1.45 / 3.50)²
= 0.25 · (0.4143)²                             [підстановка показників заломлення]
= 0.0429                                       [значення 4.29%]
```

Додатково на межі виникає френелівське відбиття при нормальному падінні світла через неузгодженість хвильових опорів напівпровідника та діелектрика:

```
R_Fresnel = ((n_semi - n_barrier) / (n_semi + n_barrier))²
= ((3.50 - 1.45) / (3.50 + 1.45))²             [підстановка n_semi = 3.50 та n_barrier = 1.45]
= (2.05 / 4.95)²                               [обчислення різниці та суми]
= 0.1715                                       [значення відбиття 17.15%]
```

Повний коефіцієнт виведення світла з плоского кристала `η_ext_LED` задається добутком частки конуса виходу на коефіцієнт пропускання межі:

```
η_ext_LED = η_cone · (1 - R_Fresnel)
= 0.0429 · (1 - 0.1715)                        [підстановка η_cone та R_Fresnel]
= 0.0355                                       [підсумковий коефіцієнт 3.55%]
```

Це математично пояснює, чому без спеціального текстурування поверхні та формування купольних лінз виведення світла з плоскої площини світлодіода не перевищує 3–4%.

## Розрахунок фотопоглинання у кремнієвому детекторі

Світло з довжиною хвилі `λ = 850 нм` поглинається у кремнії (`Si`, ширина забороненої зони `E_g = 1.12 еВ`) за законом Бера — Ламберта — Бугера:

```
I(x) = I_0 · (1 - R_Si) · exp(-α_Si · x)
```

де `α_Si ≈ 600 см⁻¹` — коефіцієнт поглинання кремнію на довжині хвилі 850 нм, `R_Si ≈ 0.30` — коефіцієнт відбиття від незахищеного кремнію при показникові заломлення `n_Si ≈ 3.4`.

Глибина проникнення світла `δ_pen`, на якій інтенсивність випромінювання спадає в `e` разів внаслідок генерації електронно-діркових пар:

```
δ_pen = 1 / α_Si
= 1 / (600 см⁻¹)                               [підстановка коефіцієнта поглинання]
= 1.67 · 10⁻³ см                               [значення в сантиметрах]
= 16.7 мкм                                     [значення в мікрометрах]
```

Щоб забезпечити високу квантову ефективність фотодетектування `η_det > 80%`, товщина збедненої зони просторового заряду p-n фотодіода `W_dep` повинна перевищувати подвійну глибину проникнення світла `2 · δ_pen ≈ 33 мкм`.

## Температурна залежність квантового коефіцієнта CTR

При зміні температури абсолютне значення CTR зазнає дрейфу через конкуренцію двох протилежних фізичних ефектів. З одного боку, внутрішня квантова ефективність світлодіода `η_int(T)` зменшується з підвищенням температури за експоненціальним законом внаслідок підсилення безипромінювальної рекомбінації SRH та фононного розсіяння:

```
η_int(T) = η_int(T_0) · exp(-(T - T_0) / T_LED)
```

де `T_LED ≈ 110–140 К` — характерна температурна константа випромінювача.

З іншого боку, коефіцієнт підсилення кремнієвого фототранзистора `β(T)` зростає з температурою через збільшення часу життя неосновних носіїв у базі `τ_b(T)` та дифузійної довжини `L_b`:

```
β(T) = β(T_0) · (T / T_0)^m
```

де експонента `m ≈ 1.5–2.1` залежить від рівня легування базової області.

Шляхом дифференціювання каскадної формули CTR отримуємо температурний коефіцієнт зміщення:

```
(1 / CTR) · (dCTR / dT) = (1 / η_int) · (dη_int / dT) + (1 / β) · (dβ / dT)
```

У фототранзисторних оптронах при помірних температурах (`0...50°C`) ці два члени практично взаємно компенсуються, що забезпечує відносну стабільність CTR. Однак при високих температурах (`T > 85°C`) падіння квантової ефективності світлодіода стає домінуючим, що призводить до падіння CTR на 20–40%.

## Обчислювальна модель підсумкового коефіцієнта CTR

Розглянемо реальний оптичний ізолятор із наступними фізичними параметрами компонентів:
- Внутрішня квантова ефективність випромінювального кристала `GaAs` LED: `η_int = 0.70` (70%).
- Виведення світла зі сферично текстурованого випромінювача у силікон: `η_ext_LED = 0.12` (12%).
- Геометричний оптичний транспорт у відбивному компаунді: `η_opt = 0.85` (85%).
- Внутрішня квантова ефективність кремнієвого фотодіода з антивідбивним покриттям: `η_det = 0.80` (80%).
- Коефіцієнт підсилення фототранзистора за струмом: `β = 150`.

Обчислимо підсумковий коефіцієнт передачі струму CTR для фототранзисторного оптрона шляхом каскадного множення:

```
CTR = η_int · η_ext_LED · η_opt · η_det · β
= 0.70 · 0.12 · 0.85 · 0.80 · 150              [підстановка каскадних коефіцієнтів]
= 0.05712 · 150                                [добуток первинних квантових ефективностей]
= 8.568                                        [значення CTR = 856.8%]
```

Для оптрона з фотодіодним виходом (де підсилення транзистора відсутнє і `β = 1`):

```
CTR_diode = 0.70 · 0.12 · 0.85 · 0.80 · 1
= 0.05712                                      [значення CTR = 5.71%]
```

Ці розрахунки демонструють фізичну основу того, чому фотодіодні оптрони потребують зовнішнього операційного підсилювача для досягнення нормальних рівнів сигналів, але мають смугу пропускання до 50 МГц через відсутність ефекту Міллера в колекторному переході фототранзистора.
