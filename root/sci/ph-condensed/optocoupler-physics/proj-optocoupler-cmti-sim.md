# ⚙️ Моделювання паразитного струму зміщення та вимірювання CMTI

У цій практичній реалізації розглядається обчислювальна модель паразитної ємності ізоляційного бар'єру оптрона (`C_iso`), розрахунок імпульсного струму зміщення при високовольтних фронтах `dV/dt` та алгоритм цифрової фільтрації хибних спрацьовувань.

## Фізика високовольтного фронту dV/dt та паразитного струму

При перемиканні силових ключів (IGBT, SiC MOSFET) у мостових інверторах потенціал ізольованого плаваючого вузла змінюється від `0` до `400–800 В` за час від `10` до `50 нс`. Це створює екстремальну швидкість зміни напруги на бар'єрі ізоляції:

```
dV/dt = 800 В / 20 нс = 40 кВ/мкс = 4 · 10¹⁰ В/с
```

Паразитна ємність між вхідною та вихідною контактними рамками оптрона `C_iso` (зазвичай `0.2–1.0 пФ`) проникає крізь товщу діелектрика. Згідно з рівняннями Максвелла, змінне електричне поле індукує емкостійний струм зміщення:

```
I_disp = C_iso · (dV/dt)
```

Для типових параметрів `C_iso = 0.5 пФ` та `dV/dt = 40 кВ/мкс` розраховане значення струму становить:

```
I_disp = 0.5 · 10⁻¹² Ф · 4 · 10¹⁰ В/с = 0.020 А = 20 мА
```

Струм `20 мА` є порівнянним або навіть перевищує корисний фотострум світлодіода (`10–15 мА`). Якщо оптрон не має внутрішнього оптичного екрана Фарадея, цей струм потрапляє безпосередньо в базу фототранзистора, викликаючи хибне відмикання силового верхнього плеча та коротке замикання стійки інвертора (*shoot-through fault*).

## Математична специфікація фронту та чисельне моделювання

Для точного відтворення реальних комутаційних процесів у силових схемах випробувальний фронт напруги моделюється за допомогою сгладженого трапецеїдального або експоненціального сигналу. Нехай `V_ISO(t)` виражається як:

```
V_ISO(t) = V_STEP · (1 / (1 + exp(-(t - t_0) / τ_rise)))
```

де `τ_rise` задає тривалість фронту наростання, `V_STEP` — амплітуду випробувального імпульсу (наприклад, 600 В), `t_0` — момент моменту початку комутаційного перепадку.

Похідна напруги за часом `dV/dt` визначає часову форму імпульсу струму зміщення:

```
dV/dt = (V_STEP / τ_rise) · (exp(-(t - t_0) / τ_rise) / (1 + exp(-(t - t_0) / τ_rise))²)
```

Максимальне значення струму зміщення `I_disp_max` досягається у середині фронту при `t = t_0`:

```
I_disp_max = C_ISO · (V_STEP / (4 · τ_rise))
```

Впровадження прозорого провідного екрана Фарадея перехоплює ємнісні лінії напруженості електричного поля. Коефіцієнт ефективності екранування `η_shield` задає частку струму зміщення, яка відводиться у вихідну землю `GND_out`:

```
I_residual = I_disp · (1 - η_shield)
```

Для якісного напиленого екрана з оксиду індію-олова (`ITO`) або полікремнію ефективність становить `η_shield = 0.995` (99.5%), що знижує залишковий струм у базі у 200 разів.

## Програмна модель аналізу CMTI та фільтрації

Нижче наведено програмний код, який моделює часову діаграму напруги на бар'єрі, розраховує динамічний струм зміщення `I_disp` та порівнює поведінку неекранованого та екранованого фотодетектора. Модель будується на чисельному диференціюванні профілю напруги та обчисленні залишкового струму в базі фотодетектора після проходження оптичного екрана Фарадея.

```c
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

#define NUM_POINTS 1000
#define DT_SEC     1.0e-9 // 1 наносекунда крок

typedef struct {
    double time_ns;
    double v_iso_volts;
    double dv_dt_v_per_us;
    double i_disp_ma;
    int unshielded_trigger;
    int shielded_trigger;
} cmti_point_t;

void simulate_cmti(double c_iso_pf, double v_step_volts, double rise_time_ns, cmti_point_t *out_data) {
    double c_iso_farads = c_iso_pf * 1.0e-12;
    double i_photodiode_threshold_ma = 2.0; // Поріг спрацьовування детектора
    
    for (int i = 0; i < NUM_POINTS; i++) {
        double t = i * DT_SEC * 1.0e9; // у наносекундах
        double v_iso = 0.0;
        double dv_dt = 0.0;

        // Формування імпульсу напруги з лінійним фронтом
        if (t >= 10.0 && t <= (10.0 + rise_time_ns)) {
            double progress = (t - 10.0) / rise_time_ns;
            v_iso = v_step_volts * progress;
            dv_dt = (v_step_volts / (rise_time_ns * 1.0e-9)) / 1.0e6; // В/мкс
        } else if (t > (10.0 + rise_time_ns)) {
            v_iso = v_step_volts;
            dv_dt = 0.0;
        }

        // I_disp = C_iso * dV/dt (у міліамперах)
        double i_disp = (c_iso_farads * (dv_dt * 1.0e6)) * 1000.0;

        out_data[i].time_ns = t;
        out_data[i].v_iso_volts = v_iso;
        out_data[i].dv_dt_v_per_us = dv_dt;
        out_data[i].i_disp_ma = i_disp;

        // Для неекранованого оптрона струм зміщення потрапляє у детектор
        out_data[i].unshielded_trigger = (i_disp > i_photodiode_threshold_ma) ? 1 : 0;
        
        // Для екранованого оптрона струм шунтується екраном Фарадея на 99.5%
        double i_shielded_residual = i_disp * 0.005;
        out_data[i].shielded_trigger = (i_shielded_residual > i_photodiode_threshold_ma) ? 1 : 0;
    }
}

int main(void) {
    cmti_point_t *results = (cmti_point_t *)malloc(sizeof(cmti_point_t) * NUM_POINTS);
    if (!results) {
        fprintf(stderr, "Помилка виділення пам'яті\n");
        return 1;
    }

    // Симуляція фронту 600 В за 15 нс (dV/dt = 40 кВ/мкс) при C_iso = 0.6 пФ
    simulate_cmti(0.6, 600.0, 15.0, results);

    printf("Час(нс) | V_iso(В) | dV/dt(кВ/мкс) | I_disp(мА) | Без екрана | З екраном\n");
    printf("-----------------------------------------------------------------------\n");
    for (int i = 8; i <= 28; i += 2) {
        printf("%7.1f | %8.1f | %13.1f | %10.2f | %10s | %9s\n",
               results[i].time_ns,
               results[i].v_iso_volts,
               results[i].dv_dt_v_per_us,
               results[i].i_disp_ma,
               results[i].unshielded_trigger ? "ПОМИЛКА!" : "ОК",
               results[i].shielded_trigger ? "ПОМИЛКА!" : "ОК");
    }

    free(results);
    return 0;
}
```

```cpp
#include <iostream>
#include <vector>
#include <iomanip>
#include <memory>
#include <string_view>

struct CmtiPoint {
    double time_ns{0.0};
    double v_iso_volts{0.0};
    double dv_dt_v_per_us{0.0};
    double i_disp_ma{0.0};
    bool unshielded_trigger{false};
    bool shielded_trigger{false};
};

class CmtiSimulator {
public:
    explicit CmtiSimulator(double c_iso_pf, double threshold_ma = 2.0)
        : c_iso_farads_(c_iso_pf * 1.0e-12), threshold_ma_(threshold_ma) {}

    [[nodiscard]] std::vector<CmtiPoint> run_simulation(double v_step_volts, double rise_time_ns, size_t points = 1000) const {
        std::vector<CmtiPoint> results;
        results.reserve(points);

        constexpr double dt_sec = 1.0e-9;

        for (size_t i = 0; i < points; ++i) {
            double t = static_cast<double>(i) * dt_sec * 1.0e9;
            double v_iso = 0.0;
            double dv_dt = 0.0;

            if (t >= 10.0 && t <= (10.0 + rise_time_ns)) {
                double progress = (t - 10.0) / rise_time_ns;
                v_iso = v_step_volts * progress;
                dv_dt = (v_step_volts / (rise_time_ns * 1.0e-9)) / 1.0e6;
            } else if (t > (10.0 + rise_time_ns)) {
                v_iso = v_step_volts;
                dv_dt = 0.0;
            }

            double i_disp = (c_iso_farads_ * (dv_dt * 1.0e6)) * 1000.0;
            double i_shielded_residual = i_disp * 0.005;

            results.push_back(CmtiPoint{
                .time_ns = t,
                .v_iso_volts = v_iso,
                .dv_dt_v_per_us = dv_dt,
                .i_disp_ma = i_disp,
                .unshielded_trigger = (i_disp > threshold_ma_),
                .shielded_trigger = (i_shielded_residual > threshold_ma_)
            });
        }

        return results;
    }

private:
    double c_iso_farads_;
    double threshold_ma_;
};

int main() {
    CmtiSimulator simulator(0.6, 2.0); // C_iso = 0.6 pF, поріг 2.0 мА
    auto results = simulator.run_simulation(600.0, 15.0);

    std::cout << std::fixed << std::setprecision(1);
    std::cout << "Час(нс) | V_iso(В) | dV/dt(кВ/мкс) | I_disp(мА) | Без екрана | З екраном\n";
    std::cout << "-----------------------------------------------------------------------\n";

    for (size_t i = 8; i <= 28; i += 2) {
        const auto& p = results[i];
        std::cout << std::setw(7) << p.time_ns << " | "
                  << std::setw(8) << p.v_iso_volts << " | "
                  << std::setw(13) << p.dv_dt_v_per_us << " | "
                  << std::setw(10) << std::setprecision(2) << p.i_disp_ma << " | "
                  << std::setw(10) << (p.unshielded_trigger ? "ПОМИЛКА!" : "ОК") << " | "
                  << std::setw(9) << (p.shielded_trigger ? "ПОМИЛКА!" : "ОК") << "\n";
    }

    return 0;
}
```

## Результати обчислення та фізичний аналіз моделі

Проведена чисельна симуляція чітко демонструє розподіл часових інтервалів та критичні точки виникнення завад:
1. **Зона спакою (`0–10 нс`)**: Напруга на ізоляційному бар'єрі є постійною (`V_iso = 0 В`), тому похідна `dV/dt = 0`. Струм зміщення дорівнює нулю, а вихідний стан обох оптичних детектора визначається виключно світловим потоком вхідного LED.
2. **Зона високовольтного фронту (`10–25 нс`)**: Напруга лінійно зростає від 0 до 600 В за 15 нс. Швидкість наростання потенціалу становить `40 кВ/мкс`. Внаслідок неперервності електричного зсуву у діелектрику паразитний струм зміщення `I_disp` стрибкоподібно зростає до **24.0 мА**.
3. **Реакція неекранованого детектора**: Струм зміщення 24.0 мА проникає у базу фототранзистора. Оскільки порівняльний поріг спрацьовування становить лише `2.0 мА`, пристрій хибно фіксує активний рівень («ПОМИЛКА!») протягом усього інтервалу наростання імпульсу. У силовому інверторі це викликає відкриття обох ключів фази та руйнівне коротке замикання.
4. **Реакція екранованого детектора**: Завдяки наявності прозорого екрана Фарадея (`ITO` або полікремній), заземленого на вихідну землю `GND_out`, 99.5% екмостійного струму зміщення шунтується у землю. Залишковий струм у базі детектора становить лише `0.12 мА`, що значно нижче порогу спрацьовування (`2.0 мА`). Вихідний сигнал залишається повністю стабільним («ОК»).

Таким чином, розрахована модель підтверджує фізичну необхідність застосування оптичних екранів Фарадея у будь-яких високочастотних інверторних системах. Впровадження захисного екранування дозволяє підняти поріг стійкості CMTI до `50–100 кВ/мкс`, що гарантує беззбійну роботу промислової перетворювальної техніки.

## Диференціальна схемотехніка цифрових ізоляторів

У надшвидкісних цифрових ізоляторах (наприклад, серії HCPL-0721 чи ACPL-W61L), які працюють на частотах до 50 Мбіт/с, для забезпечення максимальної стійкості до завад застосовують підхід диференціального оптичного каналу.

Замість одного випромінювача використовується пара світлодіодів та пара симетричних PIN-фотодіодів, підключених до диференціального підсилювача-компаратора. При появі високовольтного перепаду `dV/dt` паразитний струм зміщення `I_disp` затікає одночасно в обидва фотодіоди у вигляді синфазного сигналу однакової амплітуди та фази:

```
I_disp_1 = I_disp_2 = C_ISO_half · (dV/dt)
```

Диференціальний підсилювач віднімає вихідні струми фоторамок:

```
ΔI_out = I_disp_1 - I_disp_2 = 0
```

Завдяки симетрії паразитна завада повністю пригнічується на рівні диференціального входу підсилювача, тоді як корисний оптичний сигнал випромінюється лише одним із світлодіодів, створюючи протифазну оптичну генерацію `ΔI_photo = I_photo`. Ця архітектура дозволяє досягати рекордних показників CMTI понад `150 кВ/мкс` при збереженні наносекундної швидкодії.

## Правила друкованого монтажу для збереження стійкості CMTI

Навіть найдосконаліший оптрон із екраном Фарадея втрачає свої ізоляційні властивості у разі помилок при трасуванні друкованої плати (PCB). Для збереження високих показників CMTI та безпеки необхідно дотримуватися трьох фізичних правил:
- **Зона відчуження під корпусом (Keep-out zone)**: Під корпусом оптрона на усіх шарах друкованої плати забороняється прокладати будь-які провідникові доріжки, полігони заземлення чи перехідні отвори. Створення вікна без міді шириною не менше значення *Clearance* (7–8 мм) мінімізує додаткову паразитну ємність між первинним та вторинним колами друкованого монтажу.
- **Слот ізоляційного розрізу (Isolation Slot)**: Вифрезерована наскрізна щілина у склотекстоліті FR-4 безпосередньо під корпусом оптрона перериває можливий поверхневий шлях витоку струмів по забрудненій поверхні плати (*Creepage path*). Це запобігає виникненню поверхневого трекінгу та мікроіскрінь під дією високої напруги чи вологості.
- **Шунтуючі керамічні конденсатори виходу**: Для живлення вихідного підсилювача та тригера оптрона необхідно встановлювати керамічний конденсатор з низьким еквівалентним послідовним опором (ESR) ємністю `0.1 мкФ` безпосередньо біля виводів живлення `V_CC` та `GND_out` (відстань не більше 2 мм). Це відфільтровує залишкові мікроімпульси струму зміщення і запобігає просіданню живлення під час високовольтних перепадів `dV/dt`.
