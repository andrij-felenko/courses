# 🧮 Квантово-механічна теорія випромінювальної рекомбінації та ефективності

Опис швидкості спонтанного випромінювання та конкуруючих невипромінювальних процесів у напівпровіднику базується на квантово-механічному золотому правилі Фермі та статистичній фізиці носіїв заряду. Тут наведено систематичне виведення випромінювального коефіцієнта, співвідношення Ван Русброка — Шоклі, кінетики Шоклі — Рида — Холла, тричастинкового Оже-процесу та аналітичне визначення максимуму внутрішнього квантового виходу.

### 1. Золоте правило Фермі та коефіцієнт випромінювальної рекомбінації

Імовірність переходів за одиницю часу між початковим станом електрона у зоні провідності `|i⟩` та кінцевим станом у валентній зоні `|f⟩` із випромінюванням фотона енергією `hν` визначається у першому порядку теорії збурень квантово-механічним золотим правилом Фермі:

```
W_if = (2π / ℏ) · |⟨f| H_int |i⟩|² · δ(E_f - E_i + hν)
```

де `H_int = (q / m_0) · (A · p)` — оператор дипольної взаємодії електрона з векторним потенціалом електромагнітного поля `A`.

У напівпровідниковому кристалі хвильові функції електрона описуються функціями Блоха `ψ_{n,k}(r) = u_{n,k}(r) · exp(i · k · r)`. Обчислення матричного елемента дипольного переходу приводить його до виразу через міжзонний матричний елемент імпульсу `P_{cv}`:

```
|⟨f| H_int |i⟩|² = (q² · A_0² / (4 · m_0²)) · |e_pol · P_{cv}|² · δ_{k_i, k_f + k_ph}
```

Кронекерівська дельта `δ_{k_i, k_f + k_ph}` виражає закон збереження квазіімпульсу. Оскільки хвильовий вектор фотона `k_ph` набагато менший за розміри зони Бріллюена, перехід можна вважати строго вертикальним в `k`-просторі: `k_i ≈ k_f`.

Для обчислення повної об'ємної швидкості випромінювальної рекомбінації `R_r` проінтегруємо імовірність `W_if` за всіма можливими квантовими станами у зоні провідності та валентній зоні з урахуванням імовірностей їх заповнення носіями:

```
R_r = ∫ ∫ W_if · f_e(E_i) · f_h(E_f) · g_c(E_i) · g_v(E_f) dE_i dE_f
```

При невисоких рівнях заповнення розсунуті квазірівні Фермі знаходяться всередині забороненої зони, тож функції заповнення Фермі — Дірака `f_e` та `f_h` підпорядковуються класичній статистиці Максвелла — Больцмана:

```
f_e(E_i) ≈ exp(-(E_i - E_Fn) / (k_B · T))
f_h(E_f) ≈ exp(-(E_Fp - E_f) / (k_B · T))
```

Підставляючи ці розподіли у потрійний інтеграл, виражаємо загальну швидкість випромінювальної рекомбінації через добуток концентрацій вільних електронів `n` та дірок `p`:

```
R_r = B · n · p
```

де `B` — коефіцієнт випромінювальної рекомбінації (вимірюється в `см³/с`), який залежить від ефективних мас носіїв `m_e*`, `m_h*`, показника заломлення `n_r` та матричного елемента оптичного переходу.

### 2. Співвідношення Ван Русброка — Шоклі

За умов повної термодинамічної рівноваги без зовнішньої напруги та оптичного збудження (`n · p = n_i²`) у кристалі встановлюється мобільна динамічна рівновага: швидкість спонтанного випромінювання `R_0` точно дорівнює швидкості оптичного генераційного поглинання теплового фотонного газу, що пронизує напівпровідник.

Це фундаментальне твердження дозволило Ван Русброку та Шоклі пов'язати коефіцієнт `B` із коефіцієнтом спектрального оптичного поглинання `α(hν)` кристала:

```
R_0 = B · n_i² = ∫₀^∞ G_ph(hν) · α(hν) d(hν)
```

Звідси коефіцієнт випромінювальної рекомбінації `B` виражається як:

```
B = (1 / n_i²) · ∫₀^∞ G_ph(hν) · α(hν) d(hν)
```

де `G_ph(hν)` — густина спектрального потоку рівноважних чорнотільних фотонів у середовищі з показником заломлення `n_r`:

```
G_ph(hν) = (8π · n_r² · (hν)²) / (h³ · c²) · exp(-hν / (k_B · T))
```

Для прямозонного напівпровідника (`GaAs`), де коефіцієнт поглинання поблизу краю зони зростає за законом `α(hν) = A_0 · √(hν - E_g)` і досягає `10⁴ см⁻¹`, інтеграл дає величину `B ≈ 10⁻¹⁰ см³/с`. Для непрямозонного напівпровідника (`Si`), де поглинання вимагає участі фононів і поблизу краю зони становить лише `10–100 см⁻¹`, коефіцієнт `B` падає до `10⁻¹⁵ см³/с`.

### 3. Кінетика рекомбінації Шоклі — Рида — Холла (SRH)

Невипромінювальний канал рекомбінації через глибокі локалізовані рівні дефектів у забороненій зоні (з концентрацією `N_t` та енергією `E_t`) визначається послідовним захопленням електрона з зони провідності та дірки з валентної зони.

Швидкість захоплення електронів пастками `r_cn` та швидкість емісії `r_en` дорівнюють:

```
r_cn = C_n · n · N_t · (1 - f_t)
r_en = e_n · N_t · f_t
```

де `f_t` — частка пасток, заповнених електронами, `C_n = σ_n · v_th` — коефіцієнт захоплення електрона, `σ_n` — переріз захоплення, `v_th` — теплова швидкість.

У стаціонарному режимі рекомбінації струм електронів на пастки дорівнює струму дірок (`r_cn - r_en = r_cp - r_ep`). Розв'язуючи це рівняння відносно стаціонарного ступеня заповнення пасток `f_t`, знаходимо:

```
f_t = (C_n · n + C_p · p_1) / (C_n · (n + n_1) + C_p · (p + p_1))
```

Підставляючи `f_t` назад у вираз для чистої швидкості рекомбінації `R_SRH = r_cn - r_en`, отримуємо класичну формулу Шоклі — Рида — Холла:

```
R_SRH = (n · p - n_i²) / (τ_p0 · (n + n_1) + τ_n0 · (p + p_1))
```

де `τ_n0 = 1 / (N_t · C_n)` та `τ_p0 = 1 / (N_t · C_p)` — мінімальні часи життя носіїв, а `n_1 = N_c · exp(-(E_c - E_t) / k_B T)` та `p_1 = N_v · exp(-(E_t - E_v) / k_B T)` — приведені концентрації.

При високому рівні інжекції в активній зоні світлодіода (`n ≈ p ≫ n_i, n_1, p_1`) вираз для швидкості SRH спрощується до суто лінійної залежності:

```
R_SRH ≈ A · n   [де A = 1 / (τ_n0 + τ_p0) — коефіцієнт SRH-рекомбінації]
```

### 4. Фізика та математика тричастинкової Оже-рекомбінації

Оже-рекомбінація є невипромінювальним безелектронним переходом, у якому енергія рекомбінуючої електронно-діркової пари квантово передається у вигляді кінетичного поштовху третьому носієві. Розрізняють два основні типи Оже-процесів:

1. **Процес CCCH (Electron-initiated):** рекомбінують електрон і дірка, а енергія передається другому електрону зони провідності, який відлітає високо в зону `E_c`. Швидкість описується виразом `R_CCCH = C_n · n² · p`.
2. **Процес CCHH (Hole-initiated):** енергія рекомбінації передається другій дірці, яка відлітає глибоко у спін-орбітально розщеплену валентну зону. Швидкість описується виразом `R_CCHH = C_p · n · p²`.

З міркувань збереження енергії та імпульсу Оже-процес вимагає порогової енергії активації `E_th ≈ E_g · (m_e* / (m_e* + m_h*))`, тому коефіцієнт Оже зростає зі зменшенням ширини забороненої зони та зростанням температури:

```
C(T) = C_0 · exp(-E_th / (k_B · T))
```

У квазінейтральній активній зоні при високій інжекції (`n ≈ p`) сумарна швидкість Оже-рекомбінації є пропорційною кубу концентрації:

```
R_Auger = R_CCCH + R_CCHH = (C_n + C_p) · n³ = C · n³
```

де `C` — коефіцієнт Оже-рекомбінації (вимірюється в `см⁶/с`). Для нітриду галію (`GaN`) `C ≈ 10⁻³⁰ см⁶/с`, для арсеніду галію (`GaAs`) `C ≈ 10⁻³¹ см⁶/с`.

### 5. Рівняння ABC та аналіз внутрішнього квантового виходу

Загальне рівняння балансу носіїв в активній зоні світлодіода (модель ABC) визначає зв'язок між густиною струму інжекції `J` (при товщині активного шару `d`) та концентрацією носіїв `n`:

```
J / (q · d)
= R_total
= R_SRH + R_r + R_Auger                  [сума швидкостей трьох рекомбінаційних каналів]
= A · n + B · n² + C · n³                [підстановка моделей SRH, випромінювальної та Оже]
```

Внутрішній квантовий вихід `η_int` є відношенням швидкості випромінювальної рекомбінації до сумарної швидкості всіх процесів:

```
η_int
= R_r / R_total                          [означення квантового виходу]
= (B · n²) / (A · n + B · n² + C · n³)   [підстановка виразів швидкостей]
= 1 / (1 + (A / (B · n)) + (C / B) · n)  [ділення чисельника і знаменника на B·n²]
```

Щоб знайти значення концентрації `n_max`, при якому квантовий вихід досягає свого абсолютного максимуму, дослідимо знаменник виразу на мінімум:

```
f(n) = (A / (B · n)) + (C / B) · n
df/dn = -A / (B · n²) + C / B = 0        [диференціювання за n і прирівнювання до нуля]
```

Звідси отримуємо оптимальну концентрацію носіїв `n_max`:

```
n_max = √(A / C)                         [розв'язок рівняння відносно n]
```

Підставивши `n_max` назад у вираз для `η_int`, знаходимо максимальний досяжний внутрішній квантовий вихід:

```
η_max = B / (B + 2 · √(A · C))          [підстановка n_max у формулу квантового виходу]
```

### 6. Висновок і фізичний зміст ефекту Droop

З виведених співвідношень випливають три чіткі фізичні режими роботи світлодіода:

1. **Режим низьких струмів (`n ≪ n_max`):** `A · n ≫ B · n²`, домінує невипромінювальна рекомбінація на дефектах SRH. Квантовий вихід зростає лінійно з ростом струму (`η_int ≈ (B / A) · n`).
2. **Оптимальний режим (`n ≈ n_max`):** `B · n²` домінує, квантовий вихід досягає піку `η_max`.
3. **Режим високих струмів (`n ≫ n_max`):** `C · n³ ≫ B · n²`, кубічна Оже-рекомбінація перевищує квадратну випромінювальну. Квантовий вихід спадає за законом `η_int ≈ B / (C · n) ∝ J^(-1/3)`. Це явище в фізиці напівпровідників називають **Auger Droop** (Оже-згасанням).
