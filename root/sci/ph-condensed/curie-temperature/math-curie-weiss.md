# 🧮 Математичне виведення закону Кюрі — Вейсса та теорія Ландау

Ця вставка містить точний та послідовний математичний вивід температурної залежності спонтанної намагніченості та магнітної сприйнятливості у наближенні молекулярного поля Вейсса (Mean Field Theory), аналіз розкладу вільної енергії Ландау для фазового переходу II роду, концепцію спонтанного порушення симетрії, розрахунок критичних індексів та критерій Гінзбурга для вивчення флуктуацій.

---

### 1. Мікроскопічна модель та статистична сума спінової системи

Розглянемо макроскопічний кристал, що складається з `N` однакових магнітних іонів, розташованих у вузлах кристалічної ґратки. Нехай кожен іон володіє нескомпенсованим квантовим спіновим моментом `S` та відповідним магнітним моментом `μ = g · μ_B · S`, де `g` — спектроскопічний g-фактор Ланде, а `μ_B = e·ℏ / (2·m_e)` — магнетон Бора.

Згідно з量子-механічною моделлю Гейзенберга, мікроскопічна взаємодія між магнітними моментами сусідніх атомів описується обмінним гамільтоніаном:

```
H = -2·J · ∑ [i,j] (S[i] · S[j]) - g·μ_B · B_ext · ∑ [i] S[i]^z
```

де сума `[i,j]` проводиться по всіх парах найближчих сусідніх атомів, `Z` — координаційне число кристалічної ґратки (кількість найближчих сусідів одного атома), `J` — квантовий обмінний інтеграл, а `B_ext` — зовнішнє магнітне поле, спрямоване вздовж осі `Z`.

#### Наближення молекулярного поля Вейсса (Mean Field Approximation):
У наближенні середнього поля ми замінюємо точну квантову взаємодію кожного спіна з його оточенням на дію ефективного однорідного молекулярного поля `B_eff`. Оператор спіна сусідів `S[j]` замінюється його середнім статистичним значенням `⟨S^z⟩`. В результаті ефективне поле, що діє на кожен окремий спін `S[i]`, дорівнює:

```
B_eff = B_ext + B_mol
      = B_ext + λ · M
```

де `M = n · g · μ_B · ⟨S^z⟩` — макроскопічна намагніченість одиниці об'єму (тут `n = N / V` — об'ємна концентрація магнітних іонів), а `λ` — постійна молекулярного поля Вейсса, яка виражається через мікроскопічні параметри кристала:

```
λ = 2 · Z · J / (n · g² · μ_B²)
```

### 2. Квантово-статистичний розрахунок для спіна S = 1/2

Розглянемо найпростіший та найважливіший випадок спіна `S = 1/2` (наприклад, для одного нескомпенсованого валентного електрона на зовнішній оболонці). Квантове проекційне число спіна на вісь квантування може набувати лише двох дискретних значень: `σ = +1/2` (спін «вгору») та `σ = -1/2` (спін «вниз»).

Енергетичні рівні такого спіна у зовнішньому та молекулярному полі `B_eff` розщеплюються (зеєманівське розщеплення) на два рівні:

```
E(σ) = -σ · g · μ_B · B_eff
```

Одночастинкова статистична сума `Z_1` системи за термодинамічної температури `T` дорівнює сумі больцманівських множників за обома можливими станами:

```
Z_1 = ∑ [σ=±1/2] exp( -E(σ) / (k_B · T) )
    = exp( g·μ_B·B_eff / (2·k_B·T) ) + exp( -g·μ_B·B_eff / (2·k_B·T) )
    = 2 · cosh( g·μ_B·B_eff / (2·k_B·T) )
```

Знайдемо середнє значення проекції спіна `⟨S^z⟩` через канонічний розподл Больцмана:

```
⟨S^z⟩ = (1/2) · [ exp(y) - exp(-y) ] / [ exp(y) + exp(-y) ]
      = (1/2) · tanh(y)
```

де позначено безрозмірну комбінацію полів та температури `y = g · μ_B · B_eff / (2 · k_B · T)`.

Отже, макроскопічна намагніченість одиниці об'єму `M(T)` становить:

```
M = n · g · μ_B · ⟨S^z⟩
  = (1/2) · n · g · μ_B · tanh( g·μ_B·(B_ext + λ·M) / (2·k_B·T) )
```

Позначимо максимально можливу намагніченість повного насичення при абсолютному нулі (`T = 0 K`), коли всі спіни вишикувані паралельно, як `M_0 = (1/2) · n · g · μ_B`. Ввівши безрозмірну намагніченість `m = M / M_0` (яка змінюється в межах від `0` до `1`), отримуємо само узгоджене трансцендентне рівняння Вейсса:

```
m = tanh( (g · μ_B · B_ext / (2 · k_B · T)) + (T_C / T) · m )
```

де температура Кюрі `T_C` у наближенні молекулярного поля виражається через мікроскопічний обмінний інтеграл `J` та координаційне число ґратки `Z`:

```
T_C = Z · J / (2 · k_B)    [для S = 1/2]
```

Для довільного значення спіна `S` аналогічний математичний вивід із використанням функції Бріллюена `B_S(x)` дає загальну формулу для температури Кюрі:

```
T_C = 2 · Z · J · S · (S + 1) / (3 · k_B)
```

### 3. Графічне та аналітичне рішення самоузгодженого рівняння для B_ext = 0

За відсутності зовнішнього магнітного поля (`B_ext = 0`) рівняння для відносної намагніченості спрощується до чисто самоузгодженого вигляду:

```
m = tanh( (T_C / T) · m )
```

Це рівняння описує графічний перетин прямої лінії `y = m` та гіперболічного тангенса `y = tanh(k · m)`, де кутовий коефіцієнт тангенса біля нуля дорівнює `k = T_C / T`.

#### Поведінка розв'язків у різних температурних режимах:
1. **При `T > T_C`** кутовий коефіцієнт `k = T_C / T < 1`. Похідна `d(tanh(k·m))/dm` при `m = 0` менша за одиницю, тому графіки перетинаються лише в одній точці `m = 0`. Спонтанна намагніченість відсутня — речовина перебуває в парамагнітному стані.
2. **При `T < T_C`** кутовий коефіцієнт `k = T_C / T > 1`. Похідна біля нуля більша за одиницю, і крім нестійкого розв'язку `m = 0` з'являються два симетричні ненульові корені `m = ±m(T)`, які відповідають стійкій феромагнітній фазі.

#### Аналітичний розклад поблизу точки переходу (T → T_C знизу):
Поблизу точки Кюрі спонтанна намагніченість мала (`m ≪ 1`), тому ми можемо розкласти гіперболічний тангенс у ряд Тейлора:

```
tanh(x) = x - (1/3)·x³ + (2/15)·x⁵ - O(x⁷)
```

Підставивши `x = (T_C / T) · m`:

```
m = (T_C / T) · m - (1/3) · (T_C / T)³ · m³
```

Розділивши обидві частини на `m ≠ 0`:

```
1 = (T_C / T) - (1/3) · (T_C / T)³ · m²
(1/3) · (T_C / T)³ · m² = (T_C / T) - 1
(1/3) · (T_C / T)³ · m² = (T_C - T) / T
```

Виражаємо `m²`:

```
m² = 3 · (T / T_C)² · (T_C - T) / T_C
   = 3 · (T / T_C) · (1 - T / T_C)
```

Враховуючи, що поблизу `T_C` співвідношення `(T / T_C) ≈ 1`, отримуємо підсумкову асимптотичну формулу для спонтанної намагніченості:

```
m(T) = √3 · (1 - T / T_C)^(1/2)     [при T → T_C знизу]
```

Це доводить, що в наближенні молекулярного поля спонтанна намагніченість прямує до нуля за степенем `(1 - T/T_C)^β` з критичним індексом `β = 1/2`.

### 4. Точний вивід закону Кюрі — Вейсса для сприйнятливості (T > T_C)

Розглянемо парамагнітну область вище точки Кюрі (`T > T_C`). При накладанні слабкого зовнішнього магнітного поля `B_ext > 0` у матеріалі наводиться мала намагніченість `m ≪ 1`.

Аргумент гіперболічного тангенса малий, тому обмежимося лінійним членом розкладу `tanh(x) ≈ x`:

```
m = (g · μ_B · B_ext / (2 · k_B · T)) + (T_C / T) · m
```

Згрупуємо доданки з намагніченістю `m` у лівій частині:

```
m · (1 - T_C / T) = g · μ_B · B_ext / (2 · k_B · T)
m · ( (T - T_C) / T ) = g · μ_B · B_ext / (2 · k_B · T)
```

Помноживши обидві частини на `T`:

```
m · (T - T_C) = g · μ_B · B_ext / (2 · k_B)
```

Перейдемо від безрозмірної намагніченості `m` до об'ємної намагніченості `M = M_0 · m = (1/2) · n · g · μ_B · m`:

```
M = (n · g² · μ_B² / (4 · k_B)) · B_ext / (T - T_C)
```

Визначаємо магнітну сприйнятливість парамагнітної фази `χ = μ_0 · M / B_ext`:

```
χ(T) = C / (T - T_C)
```

де константа Кюрі `C` виражається через мікроскопічні параметри матеріалу:

```
C = μ_0 · n · g² · μ_B² · S · (S + 1) / (3 · k_B)
```

Це є суворий математичний вивід **закону Кюрі — Вейсса**. Сприйнятливість розбігається при наближенні до точки Кюрі згори (`T → T_C^+`) за законам `χ ∝ (T - T_C)^(-γ)` з критичним індексом `γ = 1`.

### 5. Феноменологічна теорія фазових переходів Ландау та спонтанне порушення симетрії

Лев Ландау розробив універсальний феноменологічний підхід до опису фазових переходів II роду, розкладаючи вільну енергію системи `F` у степеневий ряд за параметром порядку `M`.

З міркувань симетрії відносно інверсії часу (заміна напрямку полів та моментів `M → -M`) вільна енергія ізотропного магнетика за відсутності зовнішнього поля не може містити непарних степенів `M`:

```
F(M, T) = F_0(T) + (1/2) · A(T) · M² + (1/4) · B · M⁴ + (1/6) · D · M⁶ - M · B_ext
```

де `B > 0` забезпечує термодинамічну стійкість при великих намагніченостях.

Ландау припустив, що коефіцієнт `A(T)` є гладкою функцією температури і змінює знак строго при перетині точки фазового переходу `T_C`:

```
A(T) = a_0 · (T - T_C),    де a_0 > 0
```

#### Геометрія потенціалу вільної енергії Ландау:
- **При `T > T_C`**: Коефіцієнт `A(T) > 0`. Графік `F(M)` є параболічною кривою з єдиним мінімумом при `M = 0`. Система симетрична відносно напрямку намагніченості.
- **При `T = T_C`**: Коефіцієнт `A(T) = 0`. Дно потенціалу стає надзвичайно плоским (`F ∝ M⁴`), що пояснює колосальні критичні флуктуації.
- **При `T < T_C`**: Коефіцієнт `A(T) < 0`. Точка `M = 0` перетворюється на нестійкий локальний максимум («мексиканський капелюх»), а мінімуми вільної енергії зсуваються у два симетричні значення `M = ±M_s`. 

Вибір системою одного конкретного напрямку намагніченості `+M_s` або `-M_s` є класичним прикладом **спонтанного порушення симетрії** (*spontaneous symmetry breaking*).

#### Пошук рівноважного значення M(T):
Рівноважний стан відповідає мінімуму вільної енергії `∂F / ∂M = 0` (при `B_ext = 0`):

```
∂F / ∂M = a_0 · (T - T_C) · M + B · M³ = 0
M · [ a_0 · (T - T_C) + B · M² ] = 0
```

Для `T < T_C` ненульовий розв'язок дає значення спонтанної намагніченості:

```
M(T) = ± √( (a_0 / B) · (T_C - T) )
```

#### Розрахунок аномалії теплоємності (Стрибок λ-піка):
Підставимо рівноважне значення `M(T)` назад у розклад вільної енергії для феромагнітної фази (`T < T_C`):

```
F_mag = (1/2) · a_0 · (T - T_C) · [ (a_0 / B) · (T_C - T) ] + (1/4) · B · [ (a_0 / B) · (T_C - T) ]²
      = -(1/4) · (a_0² / B) · (T_C - T)²
```

Магнітна частина ентропії `S_mag = -∂F_mag / ∂T`:

```
S_mag = -(1/2) · (a_0² / B) · (T_C - T)
```

Магнітна теплоємність `C_mag = T · ∂S_mag / ∂T`:

```
C_mag(T) = (1/2) · (a_0² / B) · T    [для T < T_C]
C_mag(T) = 0                          [для T > T_C]
```

Таким чином, феноменологічна теорія Ландау передбачає скачок теплоємності при перетині точки Кюрі:

```
ΔC_p = (1/2) · a_0² · T_C / B
```

### 6. Порівняння критичних індексів та критерій Гінзбурга

Наближення середнього поля Вейсса та теорія Ландау нехтують флуктуаціями параметра порядку. У реальних 2D та 3D системах флуктуації біля `T_C` змінюють значення критичних індексів:

| Велична | Математичний закон | Наближення поля (Ландау) | 2D модель Ізінга (Онсагер) | 3D модель Гейзенберга |
| :--- | :--- | :--- | :--- | :--- |
| **Намагніченість M(T)** | `(T_C - T)^β` | `β = 0.5` | `β = 0.125 (1/8)` | `β ≈ 0.365` |
| **Сприйнятливість χ(T)** | `|T - T_C|^(-γ)` | `γ = 1.0` | `γ = 1.75 (7/4)` | `γ ≈ 1.386` |
| **Теплоємність C_p(T)** | `|T - T_C|^(-α)` | `α = 0` (скачок) | `α = 0` (логарифм) | `α ≈ -0.115` |
| **Радіус кореляції ξ(T)** | `|T - T_C|^(-ν)` | `ν = 0.5` | `ν = 1.0` | `ν ≈ 0.705` |

Лев Гінзбург вивів критерій (критерій Гінзбурга), за якого наближення середнього поля є точним. Межова розмірність простору становить `d_c = 4` (верхня критична розмірність). Для фізичного тривимірного простору `d = 3` флуктуації є важливими в безпосередній близькості від `T_C`, що й пояснює відмінність реальних виміряних індексів від середнього поля.
