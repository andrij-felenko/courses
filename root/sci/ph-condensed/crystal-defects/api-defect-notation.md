# 📋 Нотація Крьогера-Вінка та квазіхімічні рівноваги точкових дефектів

Нотація Крьогера-Вінка (Kröger-Vink Notation) — це уніфікований міжнародний стандарт символьного опису точкових дефектів, електронних збуджень та квазіхімічних реакцій у твердих тілах (іонних кристалах, оксидах, напівпровідниках та кераміках). Система розроблена Ф. А. Крьогером та Г. Ю. Вінком у 1956 році для застосування закону діючих мас до дефектних кристалічних фаз.

Головна особливість нотації полягає у вимірюванні електричного заряду дефекту не відносно вакууму, а відносно **ідеального (недеформованого) кристалічного оточення**. Цей заряд називають **ефективним (або відносним) зарядом**.

## 1. Загальна структура символу Крьогера-Вінка

Будь-який дефект у нотації Крьогера-Вінка кодується трьома елементами у формі `M_S^C`:

```
 [ Основний символ M ] _ [ Нижній індекс S ] ^ [ Верхній індекс C ]
```

1. **Основний символ `M` (Що перебуває в даній позиції):**
   - Хімічний символ елемента (`Fe`, `O`, `Si`, `Al`), якщо позицію зайнято атомом чи іоном.
   - Символ `V` (від англ. *Vacancy*), якщо позиція в ґратці є порожньою (вакансія).
   - Символи `e` та `h` для вільних електронів провідності та валентних дірок відповідно.

2. **Нижній індекс `S` (Де розташований дефект):**
   - Хімічний символ елемента, якому **в ідеальному кристалі належить даний вузол** (`O`, `Fe`, `Si`).
   - Буква `i` (від англ. *Interstitial*), якщо дефект перебуває в міжвузловому просторі.

3. **Верхній індекс `C` (Ефективний електричний заряд відносно ідеального ґраткового вузла):**
   - Крапка (`•`) означає одиничний **позитивний** ефективний заряд (`+1 e`).
   - Штрих (`'`) означає одиничний **негативний** ефективний заряд (`-1 e`).
   - Хрестик (`x`) означає **ефективно нейтральний** стан (`0 e`).

## 2. Довідкова таблиця базових типів дефектів

Нижче наведено зведену довідкову таблицю фундаментальних дефектів у кристалах із різними типами хімічного зв'язку.

| Символ Крьогера-Вінка | Назва дефекту | Фізична суть дефекту | Ефективний заряд |
| :--- | :--- | :--- | :--- |
| `V_M'` | Катіонна вакансія (однозарядна) | Відсутність двовалентного катіона `M²⁺`, замість якого залишився від'ємний заряд | `-1` (штрих) |
| `V_M''` | Катіонна вакансія (двозарядна) | Повна відсутність двовалентного катіона `M²⁺` у вузлі | `-2` (два штрихи) |
| `V_O<sup>••</sup>` | Аніонна вакансія (оксидна) | Відсутність іона оксиду `O²⁻`, утворює двократний позитивний центр | `+2` (дві крапки) |
| `V_Si<sup>x</sup>` | Нейтральна вакансія кремнію | Порожній вузол у кристалі кремнію без захоплених носіїв | `0` (хрестик) |
| `M_i<sup>••</sup>` | Міжвузловий катіон | Катіон `M²⁺`, що перейшов у міжвузлову позицію `i` | `+2` (дві крапки) |
| `O_i''` | Міжвузловий аніон кисню | Надлишковий іон `O²⁻` у міжвузлі | `-2` (два штрихи) |
| `Al_Si'` | Замісна домішка алюмінію | Тривалентний `Al³⁺` у вузлі чотиривалентного `Si⁴⁺` (акцептор) | `-1` (штрих) |
| `P_Si<sup>•</sup>` | Замісна домішка фосфору | П'ятивалентний `P⁵⁺` у вузлі чотиривалентного `Si⁴⁺` (донор) | `+1` (крапка) |
| `Fe_Cu<sup>x</sup>` | Ізовалентна домішка заліза | Іон `Fe²⁺` у вузлі іона `Cu²⁺` | `0` (хрестик) |
| `e'` | Електрон провідності | Електрон у зоні провідності | `-1` (штрих) |
| `h<sup>•</sup>` | Дільниця (дірка) | Відсутність електрона у валентній зоні | `+1` (крапка) |

## 3. Чотири законні правила квазіхімічних реакцій

При складанні рівнянь утворення, анігіляції чи взаємодії дефектів (квазіхімічних рівнянь) **обов'язково виконуються чотири закони збереження**:

### 1. Закон збереження маси
Сума атомів кожного хімічного елемента у лівій частині рівняння має дорівнювати сумі відповідних атомів у правій частині. Вакансії `V` не мають маси і в балансі маси беруть участь як нуль.

### 2. Закон збереження ефективного заряду
Сума ефективних зарядів (крапок та штрихів) у лівій частині рівняння має дорівнювати алгебраїчній сумі ефективних зарядів у правій частині:

```
Σ C_left = Σ C_right
```

### 3. Закон збереження співвідношення ґраткових вузлів (Стехіометрія ґратки)
Співвідношення кількості катіонних вузлів до аніонних вузлів має лишатися постійним і відповідати стехіометрії ідеального кристала. Наприклад, у `Al₂O₃` на кожні два створені катіонні вузли `Al` має створюватися три аніонні вузли `O`.

```
Nodes(Kation) / Nodes(Anion) = Constant
```

### 4. Закон збереження міжвузлових позицій
Кількість міжвузлових позицій `i` у кристалі є необмеженою або визначається кристалографією (наприклад, 1 тетраедричний та 2 октаедричні міжвузла на формульну одиницю). Міжвузлові позиції не вимагають дотримання суворого співвідношення з основними вузлами.

## 4. Типові квазіхімічні рівняння утворення власних дефектів

### Утворення дефектів Шотткі в бинарному оксиді MO

При утворенні дефекту Шотткі атоми з об'єму виходять на поверхню, добудовуючи нові осередки кристала, що створює пару вакансій `V_M''` та `V_O<sup>••</sup>` в об'ємі. Символ `0` у лівій частині означає ідеальний бездефектний кристал:

```
0 ⇄ V_M'' + V_O<sup>••</sup>                                  [рівновага дефектів Шотткі в MO]
```

Закон діючих мас для цієї квазіхімічної реакції записується через константу рівноваги `K_S`:

```
K_S = [V_M''] · [V_O<sup>••</sup>]
    = exp( -ΔG_S / (k_B · T) )                            [добуток розчинності дефектів Шотткі]
```

З умови електронейтральності чистейшого кристала `[V_M''] = [V_O<sup>••</sup>]` випливає:

```
[V_M''] = [V_O<sup>••</sup>] = √K_S = exp( -ΔG_S / (2 · k_B · T) )
```

### Утворення дефектів Френкеля в катіонній підґратці

Атом катіона `M` з регулярного вузла `M_M<sup>x</sup>` виходить у міжвузол `i`:

```
M_M<sup>x</sup> ⇄ V_M'' + M_i<sup>••</sup>                                [рівновага дефектів Френкеля]
```

Константа рівноваги `K_F` має вигляд:

```
K_F = [V_M''] · [M_i<sup>••</sup>] / [M_M<sup>x</sup>]
```

Оскільки концентрація регулярних вузлів майже постійна (`[M_M<sup>x</sup>] ≈ 1`), рівняння спрощується до:

```
[V_M''] · [M_i<sup>••</sup>] = K_F = exp( -ΔG_F / (k_B · T) )
```

## 5. Нестехіометрія та окисно-відновні рівняння в оксидах

Властивості багатьох технічних оксидів (наприклад, `TiO₂-x`, `ZnO₁-x`, `NiO₁+x`) визначаються відхиленням від стехіометрії при взаємодії з газовою фазою кисню `O₂`.

### Нестехіометричне відновлення оксиду (утворення аніонних вакансій)

При відпалі оксиду `MO` у відновній атмосфері (низький парціальний тиск кисню `P_O₂`) кисень залишає кристал у вигляді газу `O₂`, залишаючи в кристалі аніонні вакансії та вільні електрони:

```
O_O<sup>x</sup> ⇄ (1/2) · O₂(газ) + V_O<sup>••</sup> + 2 e'             [відновлення оксиду]
```

Застосовуючи закон діючих мас до цього рівняння:

```
K_red = [V_O<sup>••</sup>] · [e']² · (P_O₂)^(1/2)
```

З рівняння електронейтральності `[e'] = 2 · [V_O<sup>••</sup>]` знаходимо залежність концентрації вільних електронів від парціального тиску кисню:

```
[V_O<sup>••</sup>] · (2 · [V_O<sup>••</sup>])² · (P_O₂)^(1/2) = K_red
4 · [V_O<sup>••</sup>]³ = K_red · (P_O₂)^(-1/2)
[V_O<sup>••</sup>] = (K_red / 4)^(1/3) · (P_O₂)^(-1/6)          [залежність концентрації вакансій від тиску]
```

Отже, електронна провідність `σ ∝ [e']` відновленого n-тип оксиду зростає обернено пропорційно тиску кисню в ступені `-1/6`:

```
σ ∝ (P_O₂)^(-1/6)
```

### Нестехіометричне окиснення оксиду (утворення катіонних вакансій)

При високому тиску кисню `P_O₂` оксид `MO` поглинає кисень з газової фази, створюючи катіонні вакансії та дірки (провідність p-типу, наприклад у `NiO`):

```
(1/2) · O₂(газ) ⇄ O_O<sup>x</sup> + V_M'' + 2 h<sup>•</sup>               [окиснення оксиду]
```

Константа рівноваги:

```
K_ox = [V_M''] · [h<sup>•</sup>]² / (P_O₂)^(1/2)
```

З умови електронейтральності `[h<sup>•</sup>] = 2 · [V_M'']` знаходимо залежність концентрації дірок від тиску кисню:

```
[h<sup>•</sup>] = (2 · K_ox)^(1/3) · (P_O₂)^(1/6)               [зростання p-провідності від тиску]
```

## 6. Легування та акцепторно-донорний баланс

### Легування напівпровідника кремнію

1. **Донорна домішка фосфору (P):**
   ```
   P ⇄ P_Si<sup>•</sup> + e'                                    [іонизація донора у Si]
   ```
2. **Акцепторна домішка бор (B):**
   ```
   B ⇄ B_Si' + h<sup>•</sup>                                    [іонизація акцептора у Si]
   ```

Загальне рівняння електронейтральності легованого напівпровідника:

```
n + [B_Si'] = p + [P_Si<sup>•</sup>]
```

де `n = [e']` — концентрація електронів, а `p = [h<sup>•</sup>]` — концентрація дірок.

### Алиовалентне легування оксидів (Правила Веста-Крьогера)

При введенні домішки з іншою валентністю в іонний кристал компенсація заряду відбувається утворенням точкових дефектів матриці.

1. **Введення `CaCl₂` у `NaCl` (розчинення двовалентного катіона `Ca²⁺` у одновалентній ґратці):**
   Для збереження електронейтральності на кожен іон `Ca²⁺` створюється одна катіонна вакансія `V_Na'`:
   ```
   CaCl₂ ⇄ Ca_Na<sup>•</sup> + V_Na' + 2 Cl_Cl<sup>x</sup>                [утворення вакансій катіона]
   ```

2. **Легування оксиду цирконію `ZrO₂` оксидом ітрію `Y₂O₃` (утворення оксидно-вакансійного керамічного провідника YSZ):**
   Заміщення чотиривалентного `Zr⁴⁺` тривалентним `Y³⁺` вимагає утворення аніонних вакансій кисню `V_O<sup>••</sup>`:
   ```
   Y₂O₃ ⇄ 2 Y_Zr' + V_O<sup>••</sup> + 3 O_O<sup>x</sup>                      [утворення кисневих вакансій у YSZ]
   ```
   Ця квазіхімічна реакція забезпечує високу киснево-іонну провідність твердого електроліту YSZ, який використовується в паливних елементах (SOFC) та кисневих датчиках (лямбда-зондах).

## 7. Зведені діаграми Броуера (Brouwer Diagrams)

Діаграми Броуера логарифмічно показують залежність концентрацій усіх типів дефектів `ln[C_i]` від парціального тиску кисню `ln(P_O₂)` за постійної температури.

Залежно від тиску кисню кристалічний оксид проходить три графічні області електронейтральності:

1. **Область низького тиску `P_O₂` (Низький кисень, відновий режим):**
   Превалює умова електронейтральності `[e'] = 2 · [V_O<sup>••</sup>]`. Концентрація електронів та аніонних вакансій спадає як `(P_O₂)^(-1/6)`.

2. **Стехіометрична область (Проміжні тиски `P_O₂`):**
   Превалюють власні дефекти Шотткі `[V_M''] = [V_O<sup>••</sup>]`. Концентрація вакансій не залежить від тиску кисню (`(P_O₂)⁰`), а концентрації носіїв `e'` та `h<sup>•</sup>` змінюються як `(P_O₂)^(-1/4)` та `(P_O₂)^(1/4)` відповідно.

3. **Область високого тиску `P_O₂` (Високий кисень, окисний режим):**
   Превалює умова електронейтральності `[h<sup>•</sup>] = 2 · [V_M'']`. Концентрація дірок та катіонних вакансій зростає як `(P_O₂)^(1/6)`.

## 8. Кластери дефектів та асоційовані комплекси

При високих концентраціях точкові дефекти протилежного ефективного заряду кулонівськи притягуються, утворюючи асоційовані дефектні комплекси (кластери).

### Запис нейтральних та заряджених комплексів

Для позначення комплексів використовують круглі дужки `(...)`, всередині яких через пробіл перелічують дефекти, що входять до кластера. Верхній індекс після дужок вказує результуючий ефективний заряд комплексу:

1. **Нейтральна дивакансія Шотткі у `NaCl`:**
   Катіонна вакансія `V_Na'` та аніонна вакансія `V_Cl<sup>•</sup>` утворюють нейтральний комплекс:
   ```
   V_Na' + V_Cl<sup>•</sup> ⇄ (V_Na V_Cl)<sup>x</sup>                             [асоціація дивакансії]
   ```
   Енергія зв'язку комплексу `E_assoc ≈ 0.4..0.6 еВ` зменшує рухливість вільних вакансій.

2. **Заряджений домішково-вакансійний комплекс у легованому `NaCl`:**
   Катіон `Ca²⁺` у вузлі натрію `Ca_Na<sup>•</sup>` притягує вакансію натрію `V_Na'`:
   ```
   Ca_Na<sup>•</sup> + V_Na' ⇄ (Ca_Na V_Na)<sup>x</sup>                             [нейтральна пара Коттрелла-Райнера]
   ```

3. **Комплекси Вілліса у нестехіометричному диоксиді урану `UO₂+x`:**
   При надлишку кисню утворюються складні кластери Вілліса 2:2:2 (дві міжвузлові вакансії кисню `V_i<sup>x</sup>`, два міжвузлові атоми кисню `O_i''` та дві вакансії у регулярній підґратці `V_O<sup>••</sup>`):
   ```
   2 O_i'' + 2 V_O<sup>••</sup> + 2 O_i' ⇄ (2O_i 2V_O 2O_i)'                  [кластер Вілліса]
   ```

## 9. Нотація Крьогера-Вінка у перовськітах та напівпровідниках A³B⁵

### Перовськітні оксиди (наприклад, титанат барію `BaTiO₃` та титанат стронцію `SrTiO₃`)

Оксиди зі структурою перовськіту `ABO₃` мають дві катіонні підґратки (позиції A та B) і одну аніонну підґратку O.

| Дефект у перовськіті `ABO₃` | Позначення Крьогера-Вінка | Заряд | Фізичне походження |
| :--- | :--- | :--- | :--- |
| Вакансія позиції A | `V_A''` | `-2` | Відсутність двовалентного катіона `A²⁺` (`Ba²⁺`, `Sr²⁺`) |
| Вакансія позиції B | `V_B''''` | `-4` | Відсутність чотиривалентного катіона `B⁴⁺` (`Ti⁴⁺`) |
| Аніонна вакансія кисню | `V_O<sup>••</sup>` | `+2` | Відсутність іона `O²⁻` у кисневому октаедрі |
| Акцепторна домішка в позиції B | `Fe_Ti'` | `-1` | Іон `Fe³⁺` у вузлі `Ti⁴⁺` (акцепторне легування) |
| Донорна домішка в позиції A | `La_Ba<sup>•</sup>` | `+1` | Іон `La³⁺` у вузлі `Ba²⁺` (донорна донорна домішка) |
| Електронний центр (полярон) | `Ti_Ti'` | `-1` | Відновлений іон `Ti³⁺` у вузлі `Ti⁴⁺` |

Квазіхімічна реакція акцепторного легування `BaTiO₃` залізом `Fe₂O₃` з компенсацією кисневими вакансіями:

```
Fe₂O₃ ⇄ 2 Fe_Ti' + 3 O_O<sup>x</sup> + V_O<sup>••</sup>                          [акцепторне легування BaTiO₃]
```

### Напівпровідникові сполуки арсеніду галію `GaAs` та нітриду галію `GaN`

У бінарних напівпровідниках A³B⁵ можливе виникнення антиструктурних дефектів (Antisite defects), коли атом елемента A займає вузол підґратки B, або навпаки.

| Дефект у `GaAs` | Позначення Крьогера-Вінка | Заряд | Фізичний зміст |
| :--- | :--- | :--- | :--- |
| Антиструктурний дефект арсену | `As_Ga<sup>x</sup>` / `As_Ga<sup>•</sup>` / `As_Ga<sup>••</sup>` | `0 / +1 / +2` | Атом `As` у вузлі `Ga` (глибокий донор EL2) |
| Антиструктурний дефект галію | `Ga_As<sup>x</sup>` / `Ga_As'` / `Ga_As''` | `0 / -1 / -2` | Атом `Ga` у вузлі `As` (акцепторний дефект) |
| Вакансія галію | `V_Ga'''` | `-3` | Порожній вузол галію |
| Вакансія арсену | `V_As<sup>•</sup>` | `+1` | Порожній вузол арсену |
| Амфотерна домішка кремнію | `Si_Ga<sup>•</sup>` (донор) / `Si_As'` (акцептор) | `+1 / -1` | `Si` у вузлі `Ga` є донором, у вузлі `As` — акцептором |

Рівняння самокомпенсації амфотерної домішки кремнію у `GaAs`:

```
2 Si ⇄ Si_Ga<sup>•</sup> + Si_As'                                   [самокомпенсація кремнію у GaAs]
```

## 10. Практичний алгоритм складання квазіхімічних рівнянь

Щоб безпомилково скласти квазіхімічне рівняння для будь-якої системи, виконайте 5 послідовних кроків:

1. **Визначте вихідний та кінцевий кристалічний стан:** запишіть речовини, що вступають у реакцію (газовий кисень, домішка, кристалічна матриця).
2. **Оберіть відповідні підґратки:** уточніть, у які вузли (катіонні, аніонні чи міжвузлові) входять реагенти.
3. **Запишіть базові дефекти із символами Крьогера-Вінка:** на підставі різниці формальних валентностей визначте ефективні заряди (крапки `•` та штрихи `'`).
4. **Урівняйте масу елементів:** перевірте баланс хімічних елементів у лівій і правій частинах.
## 11. Довідкові термодинамічні параметри утворення дефектів

У таблиці нижче наведено експериментальні та розрахункові значення ентальпії утворення `H_f` та ентальпії міграції `H_m` точкових дефектів для характерних представників основних класів твердих тіл.

| Матеріал | Тип ґратки | Панівний дефект | Ентальпія утворення `H_f` (еВ) | Ентальпія міграції `H_m` (еВ) | Енергія активації дифузії `Q` (еВ) |
| :--- | :--- | :--- | :--- | :--- | :--- |

| **Кремній (`Si`)** | Алмаз | Вакансія `V_Si<sup>x</sup>` / Міжвузол | `3.60` | `0.45` | `4.05` |

| **Флуорит кальцію (`CaF₂`)** | Іонна (CaF₂) | Аніонний Френкель `(F_i' + V_F<sup>•</sup>)`| `2.80` | `0.90 (F_i) / 0.55 (V_F)`| `2.30` |
| **Диоксид цериту (`CeO₂`)** | Флуорит | Вакансія кисню `V_O<sup>••</sup>` | `4.10` | `0.52` | `2.57` |

### Практичне використання термодинамічних параметрів

1. **Розрахунок концентрації дефектів при заданій температурі:**
   Концентрація вакансій у міді `Cu` при кімнатній температурі (`300 K`, `k_B · T ≈ 0.0259 еВ`):
   ```
   c_v(300 K) = exp( -1.28 / 0.0259 ) ≈ exp( -49.4 ) ≈ 3.5 · 10⁻²²
   ```
   При температурі плавлення міді (`1356 K`, `k_B · T ≈ 0.1169 еВ`):
   ```
   c_v(1356 K) = exp( -1.28 / 0.1169 ) ≈ exp( -10.95 ) ≈ 1.7 · 10⁻⁵
   ```
   Отже, при нагреві від кімнатної температури до точки плавлення концентрація вакансій у міді зростає на 17 порядків!

2. **Температурний поріг відпалу радіаційних дефектів:**
   Оскільки ентальпія міграції міжвузлових атомів у металах є надзвичайно малою (`H_m(i) ≈ 0.05..0.15 еВ`), міжвузлові атоми стають рухливими вже при кріогенних температурах (`30..50 K`, І стадія відпалу), анігілюючи з вакансіями. Вакансії з вищою ентальпією міграції (`H_m(v) ≈ 0.6..1.0 еВ`) починають активно дифундувати лише при температурах вище `0.3 · T_melt` (III та IV стадії відпалу), утворюючи порові кластери та дислокаційні петлі.

## 12. Нотація Крьогера-Вінка у складних шпінелях та гранатах

У складних багатокомпонентних оксидах (шпінелі `AB₂O₄`, гранати `A₃B₅O₁₂`) катіони розподілені по декількох кристалографічних підґратках (тетраедричних `[T]`, октаедричних `[O]` та додекаедричних `[D]`).

### Шпінелі (наприклад, магній-алюмінієва шпінель `MgAl₂O₄`)

У нормальній шпінелі двовалентний `Mg²⁺` займає тетраедричні позиції `(t)`, а тривалентний `Al³⁺` — октаедричні позиції `[o]`. У разі часткової інверсії атоми обмінюються позиціями, створюючи дефекти інверсії ґратки:

```
Mg_(t)<sup>x</sup> + Al_[o]<sup>x</sup> ⇄ Mg_[o]' + Al_(t)<sup>•</sup>                           [дефект інверсії шпінелі]
```

Заміщення катіонів та створення вакансій у нестехіометричній шпінелі з надлишком `Al₂O₃`:

```
Al₂O₃ ⇄ (2/3) Al_[o]<sup>x</sup> + (4/3) Al_(t)<sup>•</sup> + (1/3) V_(t)'' + 3 O_O<sup>x</sup>           [надлишок Al2O3 у шпінелі]
```

### Легування рутилу `TiO₂` донорними та акцепторними домішками

Рутил `TiO₂` є класичним об'єктом фізики оксидних напівпровідників.

1. **Донорно-акцепторне легування ніобієм `Nb₂O₅` (донор `Nb⁵⁺` у вузлі `Ti⁴⁺`):**
   При низькому тиску кисню компенсація заряду відбувається утворенням електронів провідності `e'` (підвищення електронної n-провідності):
   ```
   Nb₂O₅ ⇄ 2 Nb_Ti<sup>•</sup> + 2 e' + 4 O_O<sup>x</sup> + (1/2) O₂(газ)               [донорна домішка низького кисню]
   ```
   При високому тиску кисню компенсація відбувається утворенням титанових вакансій `V_Ti''''`:
   ```
   2 Nb₂O₅ ⇄ 4 Nb_Ti<sup>•</sup> + V_Ti'''' + 10 O_O<sup>x</sup>                         [донорна домішка високого кисню]
   ```

2. **Акцепторне легування оксидом алюмінію `Al₂O₃` (акцептор `Al³⁺` у вузлі `Ti⁴⁺`):**
   Компенсація недостатнього заряду при низькому тиску кисню відбувається утворенням кисневих вакансій `V_O<sup>••</sup>`:
   ```
   Al₂O₃ ⇄ 2 Al_Ti' + V_O<sup>••</sup> + 3 O_O<sup>x</sup>                            [акцепторне легування TiO2]
   ```

## 14. Електронні збудження та генерація носіїв провідності

Точкові дефекти є не лише структурними локальними порушеннями ґратки, але й створюють енергетичні рівні у забороненій зоні напівпровідника або діелектрика.

### Власна генерація електронно-діркових пар

Електронно-діркова пара утворюється переходом електрона з валентної зони у зону провідності:

```
0 ⇄ e' + h<sup>•</sup>                                           [власна міжзонна генерація]
```

Закон діючих мас для міжзонної теплової генерації носіїв записується як:

```
K_i = n · p = N_c · N_v · exp( -E_g / (k_B · T) )         [добуток концентрацій вільних носіїв]
```

де `E_g` — ширина забороненої зони, `N_c` та `N_v` — ефективні густини станів у зоні провідності та валентній зоні.

### Іонизація та термодинамічне виморажування дефектних рівнів

1. **Термічна іонізація аніонної вакансії кисню `V_O<sup>x</sup>`:**
   Нейтральна киснева вакансія `V_O<sup>x</sup>` містить два захоплених електрони і виступає двократним донором:
   ```
   V_O<sup>x</sup> ⇄ V_O<sup>•</sup> + e'                                         [перша іонізація кисневої вакансії]
   V_O<sup>•</sup> ⇄ V_O<sup>••</sup> + e'                                        [друга іонізація кисневої вакансії]
   ```
   Перша енергія іонізації становить `E_d1 ≈ 0.05..0.1 еВ` (мілка донорна позиція), тоді як друга енергія іонізації `E_d2 ≈ 0.3..0.8 еВ` є значно більшою через кулонівське відштовхування.

2. **Термічна іонізація катіонної вакансії `V_M<sup>x</sup>`:**
   Нейтральна катіонна вакансія виступає двократним акцептором:
   ```
   V_M<sup>x</sup> ⇄ V_M' + h<sup>•</sup>                                         [перша іонізація катіонної вакансії]
   V_M' ⇄ V_M'' + h<sup>•</sup>                                        [друга іонізація катіонної вакансії]
   ```

## 15. Експериментальний аналіз дефектних рівнів методом Мотта-Шотткі

Для визначення типу панівного дефекту та концентрації домішок або вакансій у виснаженому шарі напівпровідникового оксиду застосовують вольт-фарадні вимірювання (метод Мотта-Шотткі).

Залежність обратного квадрата питомої ємності бар'єра Шотткі або p-n переходу `1 / C²` від прикладеної напруги зміщення `U` описується рівнянням Мотта-Шотткі:

```
1 / C² = [ 2 / (ε · ε_0 · e_0 · N_eff) ] · [ U - U_fb - (k_B · T / e_0) ]
```

де `ε` — діелектрична проникність оксиду, `U_fb` — напруга пласких зон, а `N_eff` — ефективна концентрація іонізованих точкових дефектів.

1. **Додатний нахил кривої `d(1/C²)/dU > 0`:** свідчить про напівпровідник n-типу, де панівними є донорні дефекти (`V_O<sup>••</sup>`, `M_i<sup>••</sup>`, `Nb_Ti<sup>•</sup>`).
2. **Від'ємний нахил кривої `d(1/C²)/dU < 0`:** свідчить про напівпровідник p-типу, де панівними є акцепторні дефекти (`V_M''`, `Al_Ti'`).

Кут нахилу прямої Мотта-Шотткі дозволяє прямо обчислити абсолютну концентрацію іонізованих точкових дефектів `N_eff` в об'ємі матеріалу.

У таблиці нижче наведено кутові коефіцієнти (тангенси нахилу `m` у залежності `log[C_i] ∝ m · log(P_O₂)`) для різних дефектних спектрів у чистому бінарному оксиді `MO`.

Аналіз тангенсів нахилу на спектральних графіках залежності електропровідності від тиску кисню дозволяє безпосередньо ідентифікувати закономірності квазіхімічного утворення дефектів у будь-якому новому функціональному матеріалі.

Знання кутових коефіцієнтів та реакційних констант Крьогера-Вінка є практичною основою для спрямованого синтезу керамічних мембран, високоефективних паливних елементів, варисторів та сенсорів газу. Складені квазіхімічні системи дозволяють моделювати високотемпературну деградацію матеріалів та розробляти оксидні напівпровідники зі стабільними електронно-іонними характеристиками.
