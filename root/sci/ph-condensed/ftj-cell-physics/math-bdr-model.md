# 🧮 Модель Брінкмана — Дайна — Роуелла та математичний вивід TER

Ця математична вставка містить строгий аналітичний розрахунок квантового транспорту електронів крізь асиметричний сегнетоелектричний бар'єр у наближенні Вентцеля — Крамерса — Бріллюена (ВКБ) на основі моделі Брінкмана — Дайна — Роуелла (BDR). Вона пояснює, як вектор спонтанної поляризації та довжини екранування Томаса — Фермі формують експоненційний контраст тунельного електроопору (TER).

## 1. Геометрія трапецієподібного бар'єра Брінкмана — Дайна — Роуелла

У квантово-механічній теорії тунельного транспорту опис проходження електронів крізь ультратонкий діелектрик вимагає знаходження профілю потенціальної енергії `U(x)`. 

Розглянемо сегнетоелектричну плівку товщиною `d`, затиснуту між двома металевими електродами: верхнім (TE, `x = 0`) та нижнім (BE, `x = d`). 

У відсутності зовнішньої напруги потенціальний бар'єр `U(x)` вздовж осі транспорту `x` (де `0 ≤ x ≤ d`) описується асиметричною трапецією. Граничні висоти бар'єра на межах `x = 0` та `x = d` відносно рівня Фермі дорівнюють відповідно `φ_1` та `φ_2`. 

Висота бар'єра `U(x)` у довільній точці всередині сегнетоелектрика має вигляд:

```
U(x) = φ_1 + (φ_2 - φ_1)·(x / d)
```

Середня висота потенціального бар'єра `φ̄` визначається як алгебраїчне середнє граничних значень:

```
φ̄ = (φ_1 + φ_2) / 2
```

Параметр асиметрії бар'єра `Δφ` дорівнює різниці потенціалів на його межах:

```
Δφ = φ_2 - φ_1
```

Виразимо граничні значення висот бар'єра `φ_1` та `φ_2` через середню висоту `φ̄` та асиметрію `Δφ`:

```
φ_1 = φ̄ - Δφ/2
φ_2 = φ̄ + Δφ/2
```

Рівняння потенціального бар'єра можна переписати в симетричній формі відносно центра плівки:

```
U(x) = φ̄ + Δφ·(x / d - 1/2)
```

## 2. Квантове проходження у наближенні ВКБ

Для знаходження ймовірності проходження електрона `D(E_z)` з енергією `E_z` (пов'язаною з рухом вздовж осі `x`) скористаємося наближенням Вентцеля — Крамерса — Бріллюена (ВКБ).

Інтеграл дії у квазікласичному наближенні має вигляд:

```
γ = 2/ħ · ∫₀ᵈ √[ 2·m*·(U(x) - E_z) ] dx
```

де `m*` — ефективна маса електрона в зоні провідності сегнетоелектрика.

Розглянемо випадок малої прикладеної напруги, коли електрони тунелюють переважно з рівня Фермі (`E_z ≈ E_F`, де `E_F` прийнято за нуль відліку, `E_z = 0`):

```
γ = 2/ħ · √(2·m*) · ∫₀ᵈ √[ φ̄ + Δφ·(x/d - 1/2) ] dx
```

Обчислимо визначений інтеграл `I = ∫₀ᵈ √[ φ̄ + Δφ·(x/d - 1/2) ] dx`. Виконуємо заміну змінної `u = φ̄ + Δφ·(x/d - 1/2)`:

```
∫₀ᵈ √[ φ̄ + Δφ·(x/d - 1/2) ] dx
= d / Δφ · ∫_{φ_1}^{φ_2} √u du                                [заміна змінної: u = φ̄ + Δφ·(x/d - 1/2), du = (Δφ/d) dx]
= d / Δφ · [ (2/3) · u^(3/2) ]_{φ_1}^{φ_2}                    [первісна від √u дорівнює (2/3)·u^(3/2)]
= (2/3) · (d / Δφ) · ( φ_2^(3/2) - φ_1^(3/2) )                 [формула Ньютона — Лейбніца]
```

Розкладемо різницю `φ_2^(3/2) - φ_1^(3/2)` за степенями малого параметра асиметрії (`|Δφ| << φ̄`):

```
φ_1 = φ̄ · (1 - Δφ / (2·φ̄))
φ_2 = φ̄ · (1 + Δφ / (2·φ̄))
```

Скористаємося степенним розкладом Тейлора `(1 ± y)^(3/2) ≈ 1 ± (3/2)·y + (3/8)·y²`:

```
φ_2^(3/2) - φ_1^(3/2)
= φ̄^(3/2) · [ (1 + Δφ / (2·φ̄))^(3/2) - (1 - Δφ / (2·φ̄))^(3/2) ]             [підстановка виразів φ_1 та φ_2]
= φ̄^(3/2) · [ (1 + (3/4)·(Δφ/φ̄) + (3/32)·(Δφ/φ̄)²) - (1 - (3/4)·(Δφ/φ̄) + (3/32)·(Δφ/φ̄)²) ]  [розклад Тейлора (1 ± y)^(3/2)]
= φ̄^(3/2) · [ (3/2) · (Δφ / φ̄) ]                                             [зведення подібних доданків]
= (3/2) · Δφ · √φ̄                                                            [скорочення на φ̄]
```

Підставляємо знайдений результат розкладу назад у вираз для інтеграла дії `γ`:

```
γ = 2/ħ · √(2·m*) · (2/3) · (d / Δφ) · [ (3/2) · Δφ · √φ̄ ]
= 2/ħ · √(2·m*·φ̄) · d                                                       [скорочення множників 2/3 · 3/2 та Δφ]
```

Коефіцієнт квантового проходження `D` у першому наближенні описується експонентою:

```
D ≈ exp(-γ) = exp( - (2·d / ħ) · √(2·m*·φ̄) )
```

Позначивши фундаментальну тунельну сталу через `A`:

```
A = (2·√(2·m*)) / ħ
```

отримуємо базову залежність проходження від товщини й середньої висоти бар'єра:

```
D ≈ exp( - A · d · √φ̄ )
```

## 3. Густина тунельного струму та формулювання BDR

У 1970 році Вільям Брінкман, Дональд Дайн та Джон Роуелл (англ. *W. F. Brinkman, R. C. Dynes, J. M. Rowell*) розробили теорію тунельного транспорту для асиметричних бар'єрів при довільній напрузі зміщення `V`. 

Густина тунельного струму `J(V)` обчислюється шляхом інтегрування за станами електронів у провідниках:

```
J(V) = (e · m*) / (2·π²·ħ³) · ∫ D(E_z) · (E_F - E_z) dE_z
```

Для малих вимірювальних напруг (`V → 0`) аналітичне інтегрування за методом BDR дає наступний розклад густини струму:

```
J(V) = C_0 · (V / d) · √φ̄ · exp( - A · d · √φ̄ ) · [ 1 + B_1 · V + B_2 · V² ]
```

де `C_0 = e² · √(2·m*) / (4·π²·ħ²)`.

Питомий тунельний опір осередку на одиницю площі при нульовій напрузі `R(0) = V / J(V)` описується фундаментальним рівнянням BDR:

```
R(0) = (d / (C_0 · √φ̄)) · exp( A · d · √φ̄ )
```

## 4. Електростатична модуляція висоти бар'єра поляризацією

Розглянемо тепер вплив розвороту вектора спонтанної поляризації `P` у сегнетоелектрику.

Поляризація `P` створює зв'язані поверхневі заряди `σ_P = ± P` на межах плівки. Через неповне екранування в металевих електродах на довжинах Томаса — Фермі `λ_1` та `λ_2` виникає приповерхневий потенціал `V_P`, який змінює положення дна зони провідності.

Падіння потенціалу у приповерхневих екранувальних шарах металів `δV_1` та `δV_2` описується рівняннями:

```
δV_1 = (P · λ_1) / (ε_0 · ε_1)
δV_2 = (P · λ_2) / (ε_0 · ε_2)
```

де `ε_1` та `ε_2` — відносні діелектричні проникності приповерхневих шарів відповідних електродів.

Зсув середньої висоти бар'єра `δφ_P` при наявності поляризації `P` дорівнює:

```
δφ_P = (e · P / (ε_0 · ε_r)) · [ (λ_1 / ε_1 - λ_2 / ε_2) / (d + λ_1/ε_1 + λ_2/ε_2) ]
```

Позначаємо екранувальний коефіцієнт асиметрії гетероструктури через `K_scr`:

```
K_scr = (e / (ε_0 · ε_r)) · [ (λ_1 / ε_1 - λ_2 / ε_2) / (d + λ_1/ε_1 + λ_2/ε_2) ]
```

Тоді для двох протилежних напрямків поляризації (`P_up = +P` та `P_down = -P`) середня висота тунельного бар'єра становить:

```
φ_ON = φ_0 - K_scr · P        [стан низького опору: середня висота знижена]
φ_OFF = φ_0 + K_scr · P       [стан високого опору: середня висота підвищена]
```

де `φ_0` — середня висота бар'єра у відсутності поляризації.

## 5. Точний алгебраїчний вивід коефіцієнта TER

Обчислимо відношення тунельних опорів у станах `OFF` та `ON`:

```
r_TER = R_OFF / R_ON
= ( (d / (C_0 · √φ_OFF)) · exp( A · d · √φ_OFF ) ) / ( (d / (C_0 · √φ_ON)) · exp( A · d · √φ_ON ) )   [підстановка формули R(0) для двох станів]
= √(φ_ON / φ_OFF) · exp( A · d · (√φ_OFF - √φ_ON) )                                                   [скорочення d/C_0 та об'єднання експонент]
```

Розкладемо різницю квадратних коренів `√φ_OFF - √φ_ON`:

```
√φ_OFF - √φ_ON
= √(φ_0 + K_scr·P) - √(φ_0 - K_scr·P)                                          [підстановка φ_OFF та φ_ON]
= √φ_0 · [ √(1 + K_scr·P / φ_0) - √(1 - K_scr·P / φ_0) ]                       [винесення √φ_0 за дужки]
```

Застосовуємо Тейлорівський розклад `√(1 ± y) ≈ 1 ± y/2`:

```
√(1 + K_scr·P / φ_0) - √(1 - K_scr·P / φ_0)
≈ (1 + K_scr·P / (2·φ_0)) - (1 - K_scr·P / (2·φ_0))                           [розклад Тейлора √(1 ± y) ≈ 1 ± y/2]
= (K_scr · P) / φ_0                                                           [різниця дужок]
```

Підставляємо розклад назад у вираз для різниці коренів:

```
√φ_OFF - √φ_ON ≈ (K_scr · P) / √φ_0
```

Підставляємо цей результат у показник експоненти для `r_TER`:

```
r_TER ≈ √(φ_ON / φ_OFF) · exp( (A · d · K_scr · P) / √φ_0 )
```

Оскільки експоненційний множник на кілька порядків перевищує степеневий пред'експоненційний фактор `√(φ_ON / φ_OFF) ≈ 1`, отримуємо підсумкову формулу ефекту TER:

```
r_TER = R_OFF / R_ON ≈ exp( (2·√(2·m*) / ħ) · d · (K_scr · P) / √φ_0 )
```

Коефіцієнт TER через відносну зміну опору `TER = (R_OFF - R_ON) / R_ON`:

```
TER = r_TER - 1 ≈ exp( α · d · P ) - 1
```

де `α = (2·√(2·m*) · K_scr) / (ħ · √φ_0)`.

## 6. Перехід до режиму Фаулера — Нордгейма при сильних полях

Коли прикладена напруга `V` зростає до рівня, коли енергія `e·V` перевищує граничну висоту бар'єра `φ_1` чи `φ_2`, геометрія потенціалу переходить від трапецієподібного бар'єра крізь увесь проміжок `d` до трикутного бар'єра товщиною `x_tunnel < d`.

Цей режим називається **автоелектронною емісією Фаулера — Нордгейма** (англ. *Fowler-Nordheim emission*, FN). 

Ефективна товщина тунелювання `x_tunnel` у режимі Фаулера — Нордгейма залежить від напруженості поля `E = V / d`:

```
x_tunnel = φ / (e · E)
```

Густина струму Фаулера — Нордгейма `J_FN` описується рівнянням:

```
J_FN = (e³ · E²) / (8·π·h·φ) · exp( - (4·√(2·m*)·φ^(3/2)) / (3·e·ħ·E) )
```

У сегнетоелектричному бар'єрі внутрішнє полярне поле `E_P = P / (ε_0·ε_r)` додається до зовнішнього поля `E_ext`. В результаті порогова напруга переходу в режим Фаулера — Нордгейма є неоднаковою для станів `ON` та `OFF`:

```
V_FN_ON = (φ_ON / e)
V_FN_OFF = (φ_OFF / e)
```

Оскільки `φ_ON < φ_OFF`, стан `ON` переходить у режим Фаулера — Нордгейма при значно менших напругах, ніж стан `OFF`. Це викликає додатковий нелінійний сплеск тунельного струму `J_ON`, підвищуючи ефект TER у режимі сильних полів.

## 7. Вплив температурного розширення розподілу Фермі — Дірака

При кімнатній температурі (`T > 0 K`) електрони в металевих електродах володіють тепловим розмиттям енергетичного розподілу Фермі — Дірака `f(E) = 1 / (exp((E - E_F)/k_B T) + 1)`.

Згідно з моделлю Скраттона (Stratton, 1962), температурна залежність тунельного струму описується температурним фактором:

```
J(V, T) = J(V, 0) · ( (π·k_B·T / E_0) / sin(π·k_B·T / E_0) )
```

де `E_0 = ħ / (d · √(2·m* / φ̄))`.

Для ультратонких плівок HZO значення `E_0` становить близько 0.15–0.20 еВ, що значно перевищує теплову енергію при кімнатній температурі (`k_B T ≈ 0.0259 еВ`). Це гарантує, що квантовий тунельний опір `R_ON` та `R_OFF` залишається винятково стабільним у широкому діапазоні робочих температур (від -40 °C до +125 °C), демонструючи слабку температурну залежність порівняно з напівпровідниковими переносами.

## 8. Фізичний підсумок математичного результату

Отримана формула демонструє три фундаментальні закономірності:

1. **Експоненційна залежність від товщини `d`**: Збільшення товщини сегнетоелектричного бар'єра `d` призводить до експоненційного зростання коефіцієнта `TER`. Проте товщина `d` не може перевищувати критичну товщину `d_crit`, оскільки вище `d_crit` струм тунелювання стає зневажливо малим.

2. **Пряма пропорційність поляризації `P`**: Чим більшою є спонтанна поляризація кристала `P`, тим сильнішою є модуляція висоти бар'єра `Δφ` і тим вищим є контраст опорів `R_OFF / R_ON`.

3. **Критична роль асиметрії екранування (`K_scr`)**: Якщо електроди ідентичні (`λ_1 / ε_1 = λ_2 / ε_2`), параметр `K_scr = 0`. При цьому `r_TER = exp(0) = 1`, а `TER = 0%`. Ефект TER принципово вимагає асиметрії матеріальних параметрів меж розділу.
