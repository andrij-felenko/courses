# 🧮 Математичний вивід осциляцій Фріделя та функції РККЙ

Ця вставка розв'язує задачу строгого квантовомеханічного виводу ефективного гамільтоніана взаємодії РККЙ та просторового розподілу осцилюючої спінової поляризації електронів провідності. Потреба в цьому математичному апараті виникла через те, що феноменологічні та напівкласичні наближення не здатні пояснити виникнення просторових осциляцій знака обмінного інтеграла та його степеневе згасання `~ 1/r³`: лише формалізм другого порядку теорії збурень із розрахунком сприйнятливості Ліндхарда показує, як саме сингулярність ступеня Фермі `f(k)` породжує осциляції Фріделя. Читач відкриває цю вставку, щоб отримати повне математичне обґрунтування залежності константи РККЙ від хвильового вектора Фермі `k_F`, а також порівняльний аналіз асимптотик у трьох-, дво- та одновимірних металевих системах.

---

### 1. Гамільтоніан s-d обміну та вторинне квантування

Розглянемо вироджений газ електронів провідності з ефективною масою `m*` у кристалічному об'ємі `Ω`. У цей газ поміщено два локалізовані атомні спіни `S₁` та `S₂`, розташовані у координатах `R₁` та `R₂`.

Контактна s-d (або s-f) обмінна взаємодія між локалізованим спіном `Sᵢ` у точці `Rᵢ` та спіновим оператором електрона провідності `s(r)` описується потенціалом Фермі — Кондо:

```
H_sd = - J_sd · ∑ [ Sᵢ · s(r) ] · δ(r - Rᵢ)
```

де `J_sd` — константа s-d обмінного інтеграла, `δ(r - Rᵢ)` — трьохвимірна дельта-функція Дірака, яка відображає локалізований точковий характер обміну.

У поданні вторинного квантування одноелектронні хвильові функції плоских хвиль мають вигляд:

```
|k, σ⟩ = (1 / √Ω) · exp(i · k · r) · |σ⟩
```

де `k` — хвильовий вектор електрона, `σ ∈ {↑, ↓}` — спіновий індекс. 

Спіновий оператор електрона провідності виражається через вектор матриць Паулі `σ = (σ_x, σ_y, σ_z)` як `s = (ħ / 2) · σ`. У термодинамічному межі оператор взаємодії у просторі імпульсів записується через оператори народження `c⁺_{k', σ'}` та знищення `c_{k, σ}` електронів у станах з відповідними імпульсами та спінами:

```
H_sd = - (J_sd / Ω) · ∑ ∑ exp[-i · (k' - k) · Rᵢ] · (c⁺_{k', σ'} · Sᵢ · s_{σ' σ} · c_{k, σ})
```

де `q = k' - k` — хвильовий вектор передачі імпульсу під час розсіяння електрона на локалізованому спінові.

Матричний елемент переходу електрона зі стану `|k, σ⟩` у стан `|k', σ'⟩` за рахунок розсіяння на спінові `Sᵢ` дорівнює:

```
⟨k', σ'| H_sd |k, σ⟩ = - (J_sd / Ω) · exp[-i · (k' - k) · Rᵢ] · ⟨σ'| (Sᵢ · s) |σ⟩
```

### 2. Другий порядок теорії збурень та середня енергія електронного моря

У незбуреному стані електронний газ описується гамільтоніаном вільних ферміонів із кінетичною енергією `ε_k = ħ² k² / (2 m*)`. Спіновий стан незарядженого моря Фермі є повністю симетричним, тому зміна енергії у першому порядку теорії збурень дорівнює нулю (`ΔE⁽¹⁾ = 0`).

Ефективний обмінний зв'язок між двома віддаленими спінами виникає у другому порядку теорії збурень Релея — Шредінгера шляхом переходу через віртуальні електронно-діркові збудження:

```
ΔE⁽²⁾ = ∑ ∑ [ |⟨k', σ'| H_sd |k, σ⟩|² / (ε_k - ε_k') ] · f_k · (1 - f_k')
```

де `f_k` — функція розподілу Фермі — Дірака при абсолютному нулю температур (`T = 0 K`):

```
f_k = 1  при  k ≤ k_F
f_k = 0  при  k > k_F
```

Підставляючи вираз для матричного елемента та виконуючи підсумовування по спінових проекціях електронів `σ` та `σ'`, виділяємо перехресний доданок, що залежить від відносного розташування двох спінів `R₁` та `R₂`:

```
H_RKKY = - J_RKKY(r) · (S₁ · S₂)
```

де `r = |R₁ - R₂|` — відстань між локалізованими моментивно домішками.

Ефективний обмінний інтеграл `J_RKKY(r)` виражається через фур'є-образ статичної оборотної сприйнятливості електронного газу `χ(q)`:

```
J_RKKY(r) = (J_sd² / Ω²) · ∑ [ exp(i · q · r) · χ(q) ]
```

де оборотна сприйнятливість електронного газу (функція Ліндхарда) виражається через суму по усіх зайнятих та вільних станах:

```
χ(q) = ∑ [ (f_k - f_{k+q}) / (ε_{k+q} - ε_k) ]
```

### 3. Точне інтегрування функції Ліндхарда у 3D та походження сингулярності

Для тривимірного ізотропного електронного газу з кулястою сферою Фермі радіуса `k_F` перехід від підсумовування по `k` до потрійного інтегрування у сферичних координатах дає:

```
χ_3D(q) = ∫ [ d³k / (4 · π³) ] · [ (f_k - f_{k+q}) / (ε_{k+q} - ε_k) ]
```

Інтегрування по куту між векторами `k` та `q` та по модулю `k` від `0` до `k_F` приводить до аналітичного виразу Ліндхарда для 3D-металла:

```
χ_3D(q) = (m* · k_F / (4 · π² · ħ²)) · [ 1 + ((4·k_F² - q²) / (4·k_F·q)) · ln| (2·k_F + q) / (2·k_F - q) | ]
```

Аналіз аналітичного виразу `χ_3D(q)` показує існування фундаментальної математичної особливості при передачі імпульсу `q = 2 k_F`. 

Хоча сама сприйнятливість `χ_3D(q)` залишається скінченною та неперервною для усіх `q`, її перша похідна по імпульсу `dχ / dq` має логарифмічну сингулярність у точці `q = 2 k_F`:

```
dχ / dq = (m* · k_F / (4 · π² · ħ²)) · [ (1 / (2·k_F)) - (1 / q) + ((4·k_F² - q²) / (4·k_F·q²)) · ln| (2·k_F + q) / (2·k_F - q) | ]

lim_(q → 2 k_F) [ dχ / dq ] → - ∞
```

Ця сингулярність спричинена тим, що при `q = 2 k_F` вектор передачі імпульсу з'єднує дві строго протилежні точки сфери Фермі (діаметр сфери Фермі). При перевищенні порогу `q > 2 k_F` можливі фазові об'єми для електрон-діркових збуджень скачкоподібно зменшуються.

Згідно з теоремою про фур'є-перетворення, логарифмічна сингулярність похідної у k-просторі приводить до появи просторових осциляцій у реальному координатному просторі з періодом `λ = π / k_F`.

### 4. Обернене перетворення Фур'є та отримання функції РККЙ

Для обчислення обмінного інтеграла у координатному просторі підставляємо функцію `χ_3D(q)` у формулу оберненого фур'є-перетворення:

```
J_RKKY(r) = (J_sd² / (8 · π³)) · ∫₀^∞ [ q² · dq · χ_3D(q) · (sin(q · r) / (q · r)) ]
```

Для обчислення цього інтеграла зручно використати тотожність для похідної від логарифмічного доданка та двічі проінтегрувати по частинах. Виконуючи заміну змінних `x = 2 k_F r` та `y = q / (2 k_F)`, отримуємо:

```
J_RKKY(r) = - (J_sd² · m* · k_F⁴ / (8 · π³ · ħ²)) · F(2 · k_F · r)
```

де безрозмірна універсальна функція РККЙ `F(x)` задається аналітичним виразом:

```
F(x) = (x · cos(x) - sin(x)) / x⁴,      x = 2 · k_F · r
```

Аналіз поведінки функції `F(x)` при малих та великих значеннях аргументу:

1. **Границя малих відстаней (`x → 0`):**
   Використовуючи розклад Тейлора для `sin(x)` та `cos(x)`:
   ```
   sin(x) = x - x³ / 6 + x⁵ / 120 - ...
   cos(x) = 1 - x² / 2 + x⁴ / 24 - ...
   
   x · cos(x) - sin(x) = x · (1 - x² / 2 + x⁴ / 24) - (x - x³ / 6 + x⁵ / 120)
   = - x³ / 3 + x⁵ / 30 - ...
   
   F(x) ≈ (- x³ / 3) / x⁴ = - 1 / (3 · x)
   ```
   При `x → 0` функція `F(x)` прямує до від'ємної нескінченності, що означає пригасання при наближенні до точкового джерела та превалювання феромагнітного обміну `J_RKKY > 0`.

2. **Асимптотика великих відстаней (`x ≫ 1`):**
   При `x ≫ 1` чисельник описується першим доданком `x · cos(x)`, оскільки він лінійно зростає відносно `sin(x)`:
   ```
   F(x) = (x · cos(x) - sin(x)) / x⁴ ≈ (x · cos(x)) / x⁴ = cos(x) / x³
   ```
   Отже, на великих відстанях обмінний інтеграл РККЙ у тривимірному металі згасає за зворотним кубічним законом:
   ```
   J_RKKY_3D(r) ≈ - (J_sd² · m* · k_F⁴ / (8 · π³ · ħ²)) · [ cos(2 · k_F · r) / (2 · k_F · r)³ ]
   ```

### 5. Вивід функції РККЙ для 2D- та 1D-систем

Зниження вимірності електронного газу принципово змінює вигляд функції Ліндхарда та характер просторового згасання осциляцій.

#### Двовимірний електронний газ (2D)

У двовимірних системах (квантові ями, інтерфейси гетероструктур, ґрафен) інтегрування по двовимірній сфері (колу) Фермі дає функцію Ліндхарда вигляд:

```
χ_2D(q) = (m* / (2 · π · ħ²)) · [ 1 - √(1 - (2·k_F / q)²) · Θ(q - 2·k_F) ]
```

де `Θ(...)` — ступенчата функція Хевісайда.

У 2D-випадку похідна `dχ / dq` має не логарифмічну сингулярність, а сходинкову розривність типу `1 / √(q - 2 k_F)` при `q → 2 k_F⁺`. 

Обернене двовимірне перетворення Фур'є через функції Бесселя першого `J₀(z)` та другого `Y₀(z)` роду дає вираз:

```
J_RKKY_2D(r) = - (J_sd² · m* · k_F² / (8 · π · ħ²)) · [ J₀(k_F · r) · Y₀(k_F · r) + J₁(k_F · r) · Y₁(k_F · r) ]
```

Для великих відстаней (`k_F r ≫ 1`) асимптотика бесселевих функцій дає:

```
J_RKKY_2D(r) ≈ - (J_sd² · m* · k_F / (4 · π² · ħ²)) · [ sin(2 · k_F · r) / r² ]
```

Амплітуда осциляцій у 2D-системах згасає пропорційно `1 / r²`.

#### Одновимірний квантовий дріт (1D)

В одновимірному провіднику (вуглецеві нанотрубки, напівпровідникові нанодроти) поверхня Фермі складається лише з двох точок `+k_F` та `-k_F`. Інтегрування дає сприйнятливість із логарифмічною розбіжністю самої функції `χ_1D(q)` при `q = 2 k_F`:

```
χ_1D(q) = (m* / (2 · π · ħ² · q)) · ln| (2·k_F + q) / (2·k_F - q) |
```

Обернене одновимірне перетворення Фур'є дає найповільніше згасання амплітуди:

```
J_RKKY_1D(r) ≈ - (J_sd² · m* / (2 · π · ħ²)) · [ sin(2 · k_F · r) / r ]
```

### 6. Теорема суми Фріделя та зв'язок із зарядовою поляризацією

Осциляції спінової густини `σ_spin(r)` тісно пов'язані з осциляціями зарядової густини `Δρ(r)`, які виникають при екрануванні зарядженої домішки у металі.

Згідно з теоремою про суму Фріделя (*Friedel sum rule*), повний заряд екранування `ΔZ`, індукований домішкою, виражається через парціальні фазові зсуви `η_l(E_F)` електронних хвильових хвиль на рівні Фермі:

```
ΔZ = (2 / π) · ∑ (2·l + 1) · η_l(E_F)
```

Асимптотичний вигляд осциляцій зарядової густини на великих відстанях виражається через фазовий зсув s-хвилі `η₀`:

```
Δρ(r) ≈ (1 / (2 · π² · r³)) · ∑ (-1)ˡ · (2·l + 1) · sin(2 · k_F · r + η_l)
```

Для спінової поляризації взаємодія s-d обміну діє як ефективний спіново-залежний потенціал, де електрони зі спіном "вгору" та "вниз" отримують протилежні за знаком фазові зсуви `η_l^up` та `η_l^down`.

Різниця між зарядовими та спіновими осциляціями виражається як:

```
σ_spin(r) = ρ_up(r) - ρ_down(r) ≈ (J_sd · m* · k_F² / (4 · π³ · ħ² · r³)) · cos(2 · k_F · r + δ)
```

де `δ` — фазовий зсув, визначений структурою потенціалу розсіяння на домішковому атомі. Цей вираз повністю узгоджується з асимптотикою функції РККЙ, підтверджуючи єдину квантовомеханічну природу екранування заряду та непрямого обміну спінів у металевому морі електронів провідності.
