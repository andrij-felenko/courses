# 🧮 Квантовомеханічне виведення обмінного інтеграла та спінового гамільтоніана

Цей математичний вивід деталізує квантовомеханічний розрахунок двох-електронної системи на прикладі молекули водню (модель Гайтлера — Лондона), інтегрування в еліптичних координатах за методом Сугіури, симетричну ортогоналізацію орбіталей за Льовдіном, строге виведення ефективного гамільтоніана через канонічне перетворення Шріффера — Вольфа у моделі Габбарда, розрахунок суперобміну Андерсона четвертого порядку, мікроскопічне виведення анізотропного обміну Дзялошинського — Морія (DMI) за спін-орбітальним зв'язком, непрямий обмін Рудермана — Кіттеля — Касуї — Йосиди (РККІ) через спінову сприйнятливість Ліндхарда, виведення спинової дисперсії магнонів у феромагнетиках та антиферомагнетиках через перетворення Гольштейна — Примакова та Боголюбова, а також термодинаміку магнонного газу і температурний закон Блоха `T^(3/2)`.

### 1. Постановка двоцентрової задачі двох електронів

Розглянемо два точкові ядра `A` та `B` із зарядами `+e`, які закріплені у просторі на фіксованій міжатомній відстані `R_AB` (наближення Борна — Оппенгеймера), та два електрони `1` та `2` з масою `m` і зарядом `-e`. Одночастинкові гамільтоніани для кожного електрона у кулонівських полях відповідних ізольованих ядер мають вигляд:

```
Ĥ₀(1) = -ħ²/(2m) · ∇₁² - e² / (4π·ε₀ · r_A1)      [електрон 1 у кулонівському полі ядра A]
Ĥ₀(2) = -ħ²/(2m) · ∇₂² - e² / (4π·ε₀ · r_B2)      [електрон 2 у кулонівському полі ядра B]
```

де `r_A1 = |r₁ - R_A|` — відстань першого електрона від ядра `A`, а `r_B2 = |r₂ - R_B|` — відстань другого електрона від ядра `B`. Повний двох-електронний гамільтоніан системи враховує кінетичну енергію обох частинок, пряме кулонівське відштовхування електронів між собою, відштовхування двох позитивних ядер та перехресне притягання електронів до чужих ядер:

```
Ĥ = Ĥ₀(1) + Ĥ₀(2) + V̂_int                         [повний нерелятивістський гамільтоніан]
```

де оператор електростатичної взаємодії `V̂_int` виділяє всі взаємні члени збурення:

```
V̂_int = e² / (4π·ε₀) · [ 1/r₁₂ + 1/R_AB - 1/r_A2 - 1/r_B1 ]
```

де `r₁₂ = |r₁ - r₂|` — миттєва міжелектронна відстань, `r_A2 = |r₂ - R_A|` — відстань від другого електрона до ядра `A`, а `r_B1 = |r₁ - R_B|` — відстань від першого електрона до ядра `B`.

Позначимо нормовані одноелектронні атомарні орбіталі ізольованих атомів як `φ_A(r)` та `φ_B(r)`. Для воднеподібних 1s-станів із радіусом Бора `a₀ = 4π·ε₀·ħ² / (m·e²)` ці хвильові функції мають вигляд:

```
φ_A(r) = 1 / √(π · a₀³) · exp( - |r - R_A| / a₀ )
φ_B(r) = 1 / √(π · a₀³) · exp( - |r - R_B| / a₀ )
```

Кожна з цих орбіталей є власним станом відповідного незбуреного одноелектронного гамільтоніана з енергією основного стану `E_1s = - m·e⁴ / (32·π²·ε₀²·ħ²) ≈ -13.6 eV`:

```
Ĥ₀(1) · φ_A(r₁) = E_1s · φ_A(r₁)
Ĥ₀(2) · φ_B(r₂) = E_1s · φ_B(r₂)
```

Сумарна енергія двох нескінченно віддалених ізольованих атомів водню складає `E₀ = 2 · E_1s`.

### 2. Симетризовані просторові хвильові функції та ортогоналізація Льовдіна

У наближенні Гайтлера — Лондона (метод валентних зв'язків, *valence bond*) базис двох-електронної системи будується з добутків атомних орбіталей:

```
ψ₁(r₁, r₂) = φ_A(r₁) · φ_B(r₂)      [електрон 1 локалізований біля ядра A, електрон 2 біля ядра B]
ψ₂(r₁, r₂) = φ_A(r₂) · φ_B(r₁)      [електрон 2 локалізований біля ядра A, електрон 1 біля ядра B]
```

Оскільки електрони є тотожними нерозрізними ферміонами, просторовий гамільтоніан комутує з оператором просторової перестановки координат `P̂₁₂^r`:

```
[Ĥ, P̂₁₂^r] = 0
```

Отже, власні стани гамільтоніана повинні одночасно бути власними станами оператора перестановки з власними значеннями `+1` (симетричний стан) або `-1` (антисиметричний стан). Побудуємо лінійні комбінації:

```
ψ_S(r₁, r₂) = C_S · [ φ_A(r₁)·φ_B(r₂) + φ_A(r₂)·φ_B(r₁) ]      [симетрична просторова функція]
ψ_A(r₁, r₂) = C_A · [ φ_A(r₁)·φ_B(r₂) - φ_A(r₂)·φ_B(r₁) ]      [антисиметрична просторова функція]
```

Одночастинковий інтеграл просторового перекриття електронних оболонок двох атомів позначається як `l`:

```
l = ⟨φ_A|φ_B⟩ = ∫ φ_A*(r) · φ_B(r) d³r
```

Обчислимо інтеграл нормування для симетричної просторової функції `⟨ψ_S|ψ_S⟩ = 1`:

```
⟨ψ_S|ψ_S⟩
= |C_S|² · ∬ [φ_A*(r₁)·φ_B*(r₂) + φ_A*(r₂)·φ_B*(r₁)] · [φ_A(r₁)·φ_B(r₂) + φ_A(r₂)·φ_B(r₁)] d³r₁ d³r₂
= |C_S|² · [ ⟨φ_A|φ_A⟩·⟨φ_B|φ_B⟩ + ⟨φ_A|φ_B⟩·⟨φ_B|φ_A⟩ + ⟨φ_B|φ_A⟩·⟨φ_A|φ_B⟩ + ⟨φ_B|φ_B⟩·⟨φ_A|φ_A⟩ ]
= |C_S|² · [ 1 · 1 + l · l* + l* · l + 1 · 1 ]                                                          [нормованість φ_A, φ_B]
= |C_S|² · 2 · (1 + |l|²) = 1                                                                           [умова нормування]
```

Для дійсних хвильових функцій водню `l* = l`, звідки нормувальні константи дорівнюють:

```
C_S = 1 / √(2 · (1 + l²))      [нормувальний множник симетричної функції]
C_A = 1 / √(2 · (1 - l²))      [нормувальний множник антисиметричної функції]
```

Оскільки вихідні добутки `ψ₁` та `ψ₂` не є взаємно ортогональними (`⟨ψ₁|ψ₂⟩ = l² ≠ 0`), у багаточастинковій квантовій теорії та квантовій хімії застосовують процедуру **симетричної ортогоналізації Льовдіна** (*Löwdin orthogonalization*). Матриця перекриття в базисі `{φ_A, φ_B}` має вигляд:

```
S = [ 1   l ]
    [ l   1 ]
```

Власні значення матриці `S` дорівнюють `s₁ = 1 + l` (для симетричної комбінації) та `s₂ = 1 - l` (для антисиметричної комбінації). Симетрична матриця `S^(-1/2)` генерує нову пару строго ортонормованих орбіталей `χ_A(r)` та `χ_B(r)`:

```
χ_A(r) = [ (1 + √(1 - l²)) · φ_A(r) - l · φ_B(r) ] / [ 2 · √(1 - l²) · √(1 + √(1 - l²)) ]
χ_B(r) = [ (1 + √(1 - l²)) · φ_B(r) - l · φ_A(r) ] / [ 2 · √(1 - l²) · √(1 + √(1 - l²)) ]
```

При слабкому перекритті (`l ≪ 1`) розклад у ряд Тейлора дає:

```
χ_A(r) = φ_A(r) - (l / 2) · φ_B(r) + (3·l² / 8) · φ_A(r) + O(l³)      [орбіталь Льовдіна]
χ_B(r) = φ_B(r) - (l / 2) · φ_A(r) + (3·l² / 8) · φ_B(r) + O(l³)
```

Орбіталі Льовдіна задовольняють строгі умови ортонормованості `⟨χ_A|χ_B⟩ = 0` та `⟨χ_A|χ_A⟩ = ⟨χ_B|χ_B⟩ = 1`, що спрощує побудову багатоелектронних детермінантів Слейтера без втрати вихідної точкової симетрії системи.

### 3. Точний розрахунок матричних елементів, кулонівського та обмінного інтегралів

Обчислимо матричні елементи повного гамільтоніана `Ĥ = Ĥ₀(1) + Ĥ₀(2) + V̂_int` у базисі Гайтлера — Лондона. Дія незбуреної частини `Ĥ₀ = Ĥ₀(1) + Ĥ₀(2)` на вихідні добутки:

```
Ĥ₀ · ψ₁ = [Ĥ₀(1) + Ĥ₀(2)] · φ_A(r₁)·φ_B(r₂) = 2·E_1s · φ_A(r₁)·φ_B(r₂) = E₀ · ψ₁
Ĥ₀ · ψ₂ = [Ĥ₀(1) + Ĥ₀(2)] · φ_A(r₂)·φ_B(r₁) = 2·E_1s · φ_A(r₂)·φ_B(r₁) = E₀ · ψ₂
```

Матричні елементи повної енергії розпадаються на діагональні та недіагональні внески:

```
⟨ψ₁| Ĥ |ψ₁⟩ = ⟨ψ₁| Ĥ₀ |ψ₁⟩ + ⟨ψ₁| V̂_int |ψ₁⟩ = E₀ · ⟨ψ₁|ψ₁⟩ + K = E₀ + K
⟨ψ₂| Ĥ |ψ₂⟩ = ⟨ψ₂| Ĥ₀ |ψ₂⟩ + ⟨ψ₂| V̂_int |ψ₂⟩ = E₀ + K
⟨ψ₁| Ĥ |ψ₂⟩ = ⟨ψ₁| Ĥ₀ |ψ₂⟩ + ⟨ψ₁| V̂_int |ψ₂⟩ = E₀ · ⟨ψ₁|ψ₂⟩ + J = E₀ · l² + J
⟨ψ₂| Ĥ |ψ₁⟩ = ⟨ψ₂| Ĥ₀ |ψ₁⟩ + ⟨ψ₂| V̂_int |ψ₁⟩ = E₀ · l² + J
```

де `K` та `J` — два фундаментальні матричні інтеграли взаємодії:

- **Прямий кулонівський інтеграл `K`** (описує класичну електростатичну енергію взаємодії двох стаціонарних електронних густин `|φ_A(r₁)|²` та `|φ_B(r₂)|²` з урахуванням ядерних полів):

```
K = ∬ |φ_A(r₁)|² · V̂_int · |φ_B(r₂)|² d³r₁ d³r₂
```

Розпишемо інтеграл `K` за чотирма доданками оператора `V̂_int`:

```
K = Q_ee + V_nn - 2 · I_at
```

де:
- `Q_ee = e²/(4π·ε₀) · ∬ |φ_A(r₁)|² · (1/r₁₂) · |φ_B(r₂)|² d³r₁ d³r₂` — відштовхування між двома розпростертими електронними хмарами;
- `V_nn = e² / (4π·ε₀ · R_AB)` — пряме кулонівське відштовхування позитивних ядер;
- `I_at = e²/(4π·ε₀) · ∫ |φ_A(r₁)|² · (1/r_B1) d³r₁` — енергія притягання електронної густини атома `A` до позитивного ядра `B`.

- **Квантовий обмінний інтеграл `J`** (описує енергію перехресних інтерференційних квантових густин `φ_A*(r)·φ_B(r)`):

```
J = ∬ φ_A*(r₁)·φ_B*(r₂) · V̂_int · φ_A(r₂)·φ_B(r₁) d³r₁ d³r₂
```

Розклад інтеграла `J` за складовими потенціалу:

```
J = J_ee + l² · V_nn - 2 · l · I_ex
```

де:
- `J_ee = e²/(4π·ε₀) · ∬ φ_A*(r₁)·φ_B*(r₂) · (1/r₁₂) · φ_A(r₂)·φ_B(r₁) d³r₁ d³r₂` — обмінне самовідштовхування перехресної густини заряду;
- `I_ex = e²/(4π·ε₀) · ∫ φ_A*(r₁) · (1/r_B1) · φ_B(r₁) d³r₁` — обмінне перекриття взаємодії з ядром.

Обчислимо повну квантову енергію симетричного стану `E_S = ⟨ψ_S| Ĥ |ψ_S⟩`:

```
E_S
= |C_S|² · [ ⟨ψ₁|Ĥ|ψ₁⟩ + ⟨ψ₂|Ĥ|ψ₂⟩ + ⟨ψ₁|Ĥ|ψ₂⟩ + ⟨ψ₂|Ĥ|ψ₁⟩ ]
= |C_S|² · [ (E₀ + K) + (E₀ + K) + (E₀·l² + J) + (E₀·l² + J) ]
= |C_S|² · [ 2·E₀·(1 + l²) + 2·(K + J) ]
= [ 2·E₀·(1 + l²) + 2·(K + J) ] / [ 2 · (1 + l²) ]                 [підстановка C_S]
= E₀ + (K + J) / (1 + l²)                                          [точна енергія синглету]
```

Аналогічно обчислимо енергію антисиметричного стану `E_A = ⟨ψ_A| Ĥ |ψ_A⟩`:

```
E_A
= |C_A|² · [ ⟨ψ₁|Ĥ|ψ₁⟩ + ⟨ψ₂|Ĥ|ψ₂⟩ - ⟨ψ₁|Ĥ|ψ₂⟩ - ⟨ψ₂|Ĥ|ψ₁⟩ ]
= |C_A|² · [ 2·E₀·(1 - l²) + 2·(K - J) ]
= [ 2·E₀·(1 - l²) + 2·(K - J) ] / [ 2 · (1 - l²) ]                 [підстановка C_A]
= E₀ + (K - J) / (1 - l²)                                          [точна енергія триплету]
```

Знайдемо точну різницю енергій між антисиметричним (триплетним) та симетричним (синглетним) просторовими станами `ΔE = E_A - E_S`:

```
ΔE
= [ E₀ + (K - J)/(1 - l²) ] - [ E₀ + (K + J)/(1 + l²) ]
= [ (K - J)·(1 + l²) - (K + J)·(1 - l²) ] / [ (1 - l²)·(1 + l²) ]
= [ K + K·l² - J - J·l² - K + K·l² - J + J·l² ] / (1 - l⁴)
= [ 2·K·l² - 2·J ] / (1 - l⁴)
= -2 · [ J - K · l² ] / (1 - l⁴)                                   [точне квантове розщеплення]
```

### 4. Інтегрування у конфокальних еліптичних координатах (Формули Сугіури)

Для аналітичного обчислення двоцентрових інтегралів молекули водню переходять до конфокальних еліптичних координат `(ξ, η, φ)`:

```
ξ = (r_A + r_B) / R_AB          де 1 ≤ ξ < ∞
η = (r_A - r_B) / R_AB          де -1 ≤ η ≤ 1
φ = азимутальний кут навколо осі зв'язку A-B (0 ≤ φ < 2π)
```

Елемент тривимірного об'єму в еліптичних координатах дорівнює:

```
d³r = (R_AB / 2)³ · (ξ² - η²) · dξ dη dφ
```

Атомарні орбіталі 1s виражаються через безрозмірну між'ядерну відстань `ρ = R_AB / a₀`:

```
φ_A(r) = 1/√(π·a₀³) · exp( - ρ/2 · (ξ + η) )
φ_B(r) = 1/√(π·a₀³) · exp( - ρ/2 · (ξ - η) )
φ_A(r) · φ_B(r) = 1/(π·a₀³) · exp( - ρ · ξ )
```

Обчислимо інтеграл перекриття `l(ρ) = ⟨φ_A|φ_B⟩`:

```
l(ρ)
= 1/(π·a₀³) · (R_AB/2)³ · ∫₀^(2π) dφ · ∫₋₁¹ dη · ∫₁^∞ dξ · (ξ² - η²) · exp(-ρ·ξ)
= (ρ³/8) · 2 · 2 · [ ∫₁^∞ ξ² · exp(-ρ·ξ) dξ - (1/3) · ∫₁^∞ exp(-ρ·ξ) dξ ]
= (ρ³/2) · [ exp(-ρ)/ρ · (1 + 2/ρ + 2/ρ²) - (1/3) · exp(-ρ)/ρ ]
= exp(-ρ) · [ 1 + ρ + ρ²/3 ]                                       [точний інтеграл перекриття]
```

Обчислення прямого кулонівського інтеграла `K(ρ)` та обмінного інтеграла `J(ρ)` у роботах Йошікацу Сугіури (1927) базується на розкладі міжелектронного потенціалу `1/r₁₂` за формулою Неймана через приєднані функції Лежандра `P_k^m(η)` та функції другого роду `Q_k^m(ξ)`. Точні аналітичні вирази в атомних одиницях енергії `Ry = e² / (8π·ε₀·a₀) = 13.6 eV`:

```
K(ρ) = e² / (4π·ε₀·a₀) · [ 1/ρ - exp(-2ρ) · ( 1/ρ + 11/8 + 3ρ/4 + ρ²/6 ) ]
```

Обмінний інтеграл `J(ρ)` містить логарифмічний внесок від розкладу Неймана зі сталою Ейлера — Маскероні `C ≈ 0.57721566`:

```
J(ρ)
= e² / (4π·ε₀·a₀) · [ l²(ρ)/ρ + exp(-2ρ) · ( 5/8 - 23ρ/24 - 11ρ²/12 - ρ³/6 )
  + 6/(5·ρ) · [ l²(ρ) · ( C + ln(ρ) ) + l'²(ρ) · Ei(-4ρ) - 2·l(ρ)·l(-ρ) · Ei(-2ρ) ] ]
```

де `Ei(x) = - ∫_(-x)^∞ (exp(-t)/t) dt` — інтегральна показникова функція.

На рівноважній міжатомній відстані молекули водню `ρ = 1.4` (`R_AB = 0.74 Å`) числові значення інтегралів становлять:
- Інтеграл перекриття: `l(1.4) ≈ 0.753`;
- Прямий кулонівський інтеграл: `K(1.4) ≈ -0.58 eV`;
- Обмінний інтеграл: `J(1.4) ≈ -3.15 eV`.

Оскільки `J - K·l² = -3.15 - (-0.58) · (0.753)² = -2.82 eV < 0`, енергетичний розщеп `ΔE = E_A - E_S = -2·(J - K·l²)/(1 - l⁴) ≈ +8.3 eV > 0`. Синглетний зв'язувальний стан лежить значно нижче за енергією, ніж триплетний розпушувальний стан.

На асимптотично великих відстанях (`ρ ≫ 1`) Коньєрс Геррінг та Майкл Флікер (1964) строго довели за допомогою методу поверхневих інтегралів багаточастинкового рівняння Шредінгера, що обмінне розщеплення водню має точну асимптотику:

```
E_A(R) - E_S(R) = 1.636 · (R / a₀)^(5/2) · exp( - 2·R / a₀ ) · [ 1 + O(a₀ / R) ]
```

Цей фундаментальний результат показує, що для двох нейтральних атомів водню синглетний стан лишається основним на всіх фізичних відстанях, а обмінний інтеграл експоненційно згасає з міжатомною відстанню `R`.

### 5. Порівняння з методом молекулярних орбіталей (МО ЛКАО) та конфігураційною взаємодією

Щоб зрозуміти переваги та межі наближення Гайтлера — Лондона, порівняємо його з одночастинковим методом молекулярних орбіталей (МО ЛКАО / наближення Хартрі — Фока).

У методі МО ЛКАО спочатку будуються одноелектронні молекулярні орбіталі — симетрична зв'язувальна `ψ_g` та антисиметрична розпушувальна `ψ_u`:

```
ψ_g(r) = [ φ_A(r) + φ_B(r) ] / √(2 · (1 + l))      [герне, парна зв'язувальна орбіталь]
ψ_u(r) = [ φ_A(r) - φ_B(r) ] / √(2 · (1 - l))      [унгерне, непарна розпушувальна орбіталь]
```

Основний синглетний стан у наближенні простого молекулярного детермінанта формується розміщенням обох електронів з протилежними спінами на нижчу орбіталь `ψ_g`:

```
Ψ_MO(r₁, r₂)
= ψ_g(r₁) · ψ_g(r₂)
= 1 / [ 2·(1 + l) ] · [ φ_A(r₁) + φ_B(r₁) ] · [ φ_A(r₂) + φ_B(r₂) ]
= 1 / [ 2·(1 + l) ] · [ ( φ_A(r₁)·φ_B(r₂) + φ_A(r₂)·φ_B(r₁) ) + ( φ_A(r₁)·φ_A(r₂) + φ_B(r₁)·φ_B(r₁) ) ]
= C_cov · Ψ_covalent + C_ion · Ψ_ionic
```

де:
- `Ψ_covalent = φ_A(r₁)·φ_B(r₂) + φ_A(r₂)·φ_B(r₁)` — нейтральна ковалентна конфігурація Гайтлера — Лондона `H ··· H`;
- `Ψ_ionic = φ_A(r₁)·φ_A(r₂) + φ_B(r₁)·φ_B(r₂)` — полярна іонна конфігурація `H⁻H⁺ + H⁺H⁻`.

У методі простого детермінанта МО вага іонних станів фіксована на рівні рівно 50% (`C_cov = C_ion`). При розведенні атомів на нескінченну відстань (`R_AB → ∞`) це приводить до катастрофічної помилки дисоціації: метод МО помилково передбачає, що молекула водню дисоціює на пару іонів `H⁺ + H⁻` з імовірністю 50%, що завищує повну енергію системи на величину `(I - A) / 2 = (13.6 - 0.75) / 2 ≈ 6.4 eV` (де `I` — потенціал іонізації, а `A` — спорідненість до електрона).

Навпаки, метод Гайтлера — Лондона повністю ігнорує іонні конфігурації, правильно описуючи дисоціацію на нейтральні атоми при `R → ∞`, проте недооцінює екранну кореляцію на малих відстанях зв'язку.

Точний розв'язок дає метод **конфігураційної взаємодії (Configuration Interaction, CI)**, де повна просторова хвильова функція шукається як варіаційна лінійна комбінація двох синглетних конфігурацій:

```
Ψ_CI(r₁, r₂) = c₁ · |ψ_g(r₁)·ψ_g(r₂)⟩ + c₂ · |ψ_u(r₁)·ψ_u(r₂)⟩
```

Мінімізація функціонала повної енергії `⟨Ψ_CI| Ĥ |Ψ_CI⟩ / ⟨Ψ_CI|Ψ_CI⟩` дає світську систему рівнянь секулярного детермінанта:

```
| H_gg - E    H_gu   | = 0
| H_ug        H_uu - E |
```

На малих відстанях `c₁ ≫ c₂` (домінує стан МО `ψ_g²`), а при `R_AB → ∞` коефіцієнти прямують до `c₁ = - c₂ = 1/√2`, що тотожно обнуляє іонні члени `φ_A(1)φ_A(2)` і повертає систему до чистого ковалентного стану Гайтлера — Лондона.

### 6. Виведення спінового оператора Дірака та операторних тотожностей

Згідно з принципом нерозрізності ферміонів повна хвильова функція двох електронів `Ψ(1, 2) = ψ_space(r₁, r₂) · χ_spin(s₁, s₂)` повинна бути строго антисиметричною щодо повної перестановки частинок: `P̂₁₂ · Ψ = -Ψ`.

Для системи двох спінів `s₁ = s₂ = 1/2` простір спінових станів є 4-вимірним і складається з одночастинкових спінорів `|↑⟩` та `|↓⟩`. Додавання моментів `1/2 ⊗ 1/2 = 0 ⊕ 1` породжує 1 синглетний стан (`S = 0`) та 3 триплетні стани (`S = 1`):

- **Антисиметричний синглетний стан (`S = 0, M_S = 0`):**

```
χ_S = (1/√2) · [ |↑⟩₁|↓⟩₂ - |↓⟩₁|↑⟩₂ ]
```

- **Симетричні триплетні стани (`S = 1, M_S = +1, 0, -1`):**

```
χ_T,+1 = |↑⟩₁|↑⟩₂
χ_T,0  = (1/√2) · [ |↑⟩₁|↓⟩₂ + |↓⟩₁|↑⟩₂ ]
χ_T,-1 = |↓⟩₁|↓⟩₂
```

Оскільки повна функція `Ψ` мусить бути антисиметричною, симетрична просторова функція `ψ_S` комбінується виключно з антисиметричним спіновим синглетом `χ_S`, а антисиметрична просторова функція `ψ_A` — виключно з симетричним спіновим триплетом `χ_T`:

```
Ψ_singlet = ψ_S(r₁, r₂) · χ_S(s₁, s₂)      [повний спін S = 0, симетричний простір]
Ψ_triplet = ψ_A(r₁, r₂) · χ_T(s₁, s₂)      [повний спін S = 1, антисиметричний простір]
```

Знайдемо матричне представлення квантового оператора скалярного добутку спінів `Ŝ₁ · Ŝ₂`. Оператор повного спіну дорівнює `Ŝ_tot = Ŝ₁ + Ŝ₂`. Підносячи до квадрата:

```
Ŝ_tot² = (Ŝ₁ + Ŝ₂)² = Ŝ₁² + Ŝ₂² + 2 · (Ŝ₁ · Ŝ₂)
```

Оскільки квадрат одночастинкового спіна електрона фіксований квантовим числом `s = 1/2`:

```
Ŝ₁² = Ŝ₂² = s · (s + 1) · ħ² = 1/2 · (1/2 + 1) · ħ² = 3/4 · ħ²
```

Виразимо скалярний добуток через квадрати повного та індивідуальних спінів:

```
Ŝ₁ · Ŝ₂ = 1/2 · [ Ŝ_tot² - Ŝ₁² - Ŝ₂² ] = 1/2 · [ Ŝ_tot² - 3/2 · ħ² ]
```

Підставляючи власні значення квадрата повного спіну `Ŝ_tot² = S · (S + 1) · ħ²`:

```
(Ŝ₁ · Ŝ₂)_singlet = 1/2 · [ 0·(0 + 1)·ħ² - 3/2·ħ² ] = -3/4 · ħ²      [для синглету S = 0]
(Ŝ₁ · Ŝ₂)_triplet = 1/2 · [ 1·(1 + 1)·ħ² - 3/2·ħ² ] = +1/4 · ħ²      [для триплету S = 1]
```

Перевіримо цей результат прямою дією оператора через підвищувальні та понижувальні компоненти `Ŝ_i^± = Ŝ_i^x ± i·Ŝ_i^y`:

```
Ŝ₁ · Ŝ₂ = Ŝ₁^z · Ŝ₂^z + 1/2 · [ Ŝ₁^+ · Ŝ₂^- + Ŝ₁^- · Ŝ₂^+ ]
```

Діючи на базисні стани добутків:

```
Ŝ₁ · Ŝ₂ |↑↑⟩
= (ħ/2)·(ħ/2) |↑↑⟩ + 0 = +1/4 · ħ² |↑↑⟩                                 [триплет M_S = +1]

Ŝ₁ · Ŝ₂ |↓↓⟩
= (-ħ/2)·(-ħ/2) |↓↓⟩ + 0 = +1/4 · ħ² |↓↓⟩                               [триплет M_S = -1]

Ŝ₁ · Ŝ₂ |↑↓⟩
= (ħ/2)·(-ħ/2) |↑↓⟩ + 1/2 · (ħ·|↓⟩₁) · (ħ·|↑⟩₂) = -1/4·ħ² |↑↓⟩ + 1/2·ħ² |↓↑⟩

Ŝ₁ · Ŝ₂ |↓↑⟩
= (-ħ/2)·(ħ/2) |↓↑⟩ + 1/2 · (ħ·|↑⟩₁) · (ħ·|↓⟩₂) = -1/4·ħ² |↓↑⟩ + 1/2·ħ² |↑↓⟩
```

Діючи на синглетний стан `χ_S = (|↑↓⟩ - |↓↑⟩) / √2`:

```
Ŝ₁ · Ŝ₂ χ_S
= 1/√2 · [ (-1/4·ħ² |↑↓⟩ + 1/2·ħ² |↓↑⟩) - (-1/4·ħ² |↓↑⟩ + 1/2·ħ² |↑↓⟩) ]
= 1/√2 · [ (-1/4 - 1/2)·ħ² |↑↓⟩ - (-1/4 - 1/2)·ħ² |↓↑⟩ ]
= -3/4 · ħ² · (1/√2) · [ |↑↓⟩ - |↓↑⟩ ]
= -3/4 · ħ² · χ_S                                                       [доведено для S = 0]
```

Оператор перестановки спінових координат `P̂₁₂^σ` діє на симетричний триплет як `+1`, а на антисиметричний синглет як `-1`. Шукаємо лінійну операторну форму `P̂₁₂^σ = A + B · (Ŝ₁ · Ŝ₂)`:

```
A + B · (-3/4 · ħ²) = -1      [власне значення на синглетному стані]
A + B · (+1/4 · ħ²) = +1      [власне значення на триплетному стані]
```

Віднімаючи перше рівняння від другого:

```
B · [ 1/4 · ħ² - (-3/4 · ħ²) ] = 1 - (-1)
B · ħ² = 2  ⇒  B = 2 / ħ²
```

Підставляючи коефіцієнт `B` у перше рівняння:

```
A = 1 - (2 / ħ²) · (1/4 · ħ²) = 1 - 1/2 = 1/2
```

Отримуємо фундаментальну **тотожність Дірака для спінового оператора перестановки**:

```
P̂₁₂^σ = 1/2 + 2/ħ² · (Ŝ₁ · Ŝ₂)
```

Використовуючи безрозмірні матриці Паулі `σ = (2/ħ) · Ŝ`:

```
P̂₁₂^σ = 1/2 · [ Î + σ₁ · σ₂ ] = 1/2 · [ Î + σ₁_x·σ₂_x + σ₁_y·σ₂_y + σ₁_z·σ₂_z ]
```

### 7. Спіновий гамільтоніан Гейзенберга — Дірака — Ван Флека

Побудуємо проєкційні оператори на синглетний підпростір `P̂_S` та триплетний підпростір `P̂_T`:

```
P̂_S = (1 - P̂₁₂^σ) / 2 = 1/4 - (Ŝ₁ · Ŝ₂) / ħ²      [проєктор на стан S = 0]
P̂_T = (3 + P̂₁₂^σ) / 4 = 3/4 + (Ŝ₁ · Ŝ₂) / ħ²      [проєктор на стан S = 1]
```

Ці оператори мають фундаментальні властивості проєкторів:

```
P̂_S + P̂_T = Î                                     [повнота базису]
P̂_S² = P̂_S,   P̂_T² = P̂_T                          [ідемпотентність]
P̂_S · P̂_T = P̂_T · P̂_S = 0                         [взаємна ортогональність]
```

Спроєктуємо вихідний електростатичний гамільтоніан, який не залежить від спіну у координатному просторі, на 4-вимірний спіновий простір станів:

```
Ĥ_spin
= E_S · P̂_S + E_A · P̂_T
= E_S · [ 1/4 - (Ŝ₁·Ŝ₂)/ħ² ] + E_A · [ 3/4 + (Ŝ₁·Ŝ₂)/ħ² ]
= 1/4 · (E_S + 3·E_A) - [ (E_A - E_S) / ħ² ] · (Ŝ₁ · Ŝ₂)
= E_const - 2 · J_eff / ħ² · (Ŝ₁ · Ŝ₂)             [спіновий гамільтоніан Дірака — Ван Флека]
```

де скалярний енергетичний зсув `E_const` та ефективний обмінний інтеграл `J_eff` дорівнюють:

```
E_const = (E_S + 3·E_A) / 4
J_eff = (E_A - E_S) / 2 = - (J - K · l²) / (1 - l⁴)
```

Відкидаючи несуттєву константу зсуву енергії `E_const` та приймаючи одиниці `ħ = 1`, отримуємо класичний парний **гамільтоніан Гейзенберга**:

```
Ĥ_ex = -2 · J_eff · (Ŝ₁ · Ŝ₂)
```

Для багатоатомного кристала підсумовування за всіма взаємодіючими вузлами ґратки дає повний твердотільний спіновий гамільтоніан:

```
Ĥ_Heisenberg = -2 · ∑_(⟨i,j⟩) J_ij · (Ŝ_i · Ŝ_j) - g · μ_B · ∑_i (B_ext · Ŝ_i)
```

де `⟨i,j⟩` — пари найближчих магнітних сусідів, `g` — фактор Ланде, `μ_B = e·ħ / (2m)` — магнетон Бора, а `B_ext` — зовнішнє магнітне поле.

### 8. Канонічне перетворення Шріффера — Вольфа у моделі Габбарда

У твердих тілах із сильною кулонівською кореляцією `U` прямий обмін `J` є надто малим. Домінуючим стає **кінетичний обмін**, який виводиться з одновузлової **моделі Габбарда** за допомогою операторного **перетворення Шріффера — Вольфа** (*Schrieffer-Wolff transformation*).

Розглянемо гамільтоніан Габбарда на ґратці:

```
Ĥ = Ĥ₀ + Ĥ_t
Ĥ₀ = U/2 · ∑_i n_i · (n_i - 1)                      [кулонівське відштовхування]
Ĥ_t = - ∑_(i,j,σ) t_ij · c_iσ† · c_jσ               [кінетичне тунелювання електронів]
```

де `c_iσ†` та `c_iσ` — ферміонівські оператори, `n_i = n_i↑ + n_i↓` — повне число електронів на вузлі `i`, а `t_ij` — матричний елемент перескоку.

Розкладемо оператор тунелювання `Ĥ_t` на три складові за зміною кількості двічі зайнятих вузлів (двійок):

```
Ĥ_t = T₀ + T₊₁ + T₋₁
```

де:
- `T₀` зберігає число подвійно заселених вузлів;
- `T₊₁ = - ∑_(i,j,σ) t_ij · n_i,-σ · c_iσ† · c_jσ · (1 - n_j,-σ)` створює одну двійку (збільшує потенціальну енергію на `+U`);
- `T₋₁ = - ∑_(i,j,σ) t_ij · (1 - n_i,-σ) · c_iσ† · c_jσ · n_j,-σ` знищує одну двійку (зменшує енергію на `-U`).

Ці оператори задовольняють комутаційні співвідношення з `Ĥ₀`:

```
[Ĥ₀, T₀] = 0
[Ĥ₀, T₊₁] = + U · T₊₁
[Ĥ₀, T₋₁] = - U · T₋₁
```

Шукаємо антиермітовий генератор унітарного перетворення `Ŝ† = -Ŝ`, який усуває процеси першого порядку `T₊₁` та `T₋₁`, що зв'язують нейтральний підпростір із високоенергетичним іонним підпростором:

```
H̃ = exp(Ŝ) · Ĥ · exp(-Ŝ) = Ĥ + [Ŝ, Ĥ] + 1/2 · [Ŝ, [Ŝ, Ĥ]] + O(t³/U²)
```

Вимагаємо обнулення недіагональних членів першого порядку:

```
Ĥ_t + [Ŝ, Ĥ₀] = 0
```

Оскільки `[Ŝ, Ĥ₀] = - [Ĥ₀, Ŝ]`, підставляємо анзац `Ŝ = (1/U) · (T₊₁ - T₋₁)`:

```
[Ŝ, Ĥ₀] = 1/U · [T₊₁, Ĥ₀] - 1/U · [T₋₁, Ĥ₀] = - (T₊₁ + T₋₁)
```

Тоді в другому порядку за параметром `t/U` ефективний гамільтоніан у підпросторі без подвійної заселеності (проектор Гутцвіллера `P̂_G`) набуває вигляду:

```
Ĥ_eff = P̂_G · [ Ĥ₀ + T₀ + 1/2 · [Ŝ, T₊₁ + T₋₁] ] · P̂_G
```

Обчислимо комутатор `1/2 · [Ŝ, T₊₁ + T₋₁] = - (1/U) · T₋₁ · T₊₁`:

```
- 1/U · T₋₁ · T₊₁
= - ∑_(i,j,σ,σ') (t_ij² / U) · [ c_iσ† · c_jσ · c_jσ'† · c_iσ' ]
= - ∑_(⟨i,j⟩,σ,σ') (t_ij² / U) · [ c_iσ† · (δ_σσ' - c_jσ'† · c_jσ) · c_iσ' ]
= - ∑_(⟨i,j⟩) (2·t_ij² / U) · [ 1/2 · n_i · n_j + 2 · (Ŝ_i · Ŝ_j) - 1/2 · n_i · n_j ]
= + ∑_(⟨i,j⟩) (4·t_ij² / U) · [ (Ŝ_i · Ŝ_j) - 1/4 · n_i · n_j ]
```

При половинному заповненні (`n_i = n_j = 1`) отримуємо точний ефективний спіновий гамільтоніан Гейзенберга:

```
Ĥ_kin = - 2 · ∑_(⟨i,j⟩) J_kin · (Ŝ_i · Ŝ_j) = ∑_(⟨i,j⟩) (4·t_ij² / U) · (Ŝ_i · Ŝ_j)
```

де константа кінетичного обміну дорівнює `J_kin = - 2·t_ij² / U < 0` (строго антиферомагнітна взаємодія).

### 9. Теорія збурень четвертого порядку: Суперобмін Андерсона через діамагнітний аніон

У діелектриках перехідних металів (наприклад, `MnO`, `NiO`, `LaMnO₃`, купратні ВТНП) прямий контакт між d-орбіталями катіонів перехідного металу `M₁` та `M₂` відсутній. Магнітні катіони розділені діамагнітним аніоном (типово `O²⁻` або `F⁻`) із повністю заповненою p-оболонкою. Взаємодія між ними реалізується через **суперобмін Андерсона** (*Anderson superexchange*).

Розглянемо 180-градусний місток `M₁ — O — M₂`. Базис складається з:
- d-орбіталей катіона `M₁` та катіона `M₂` з енергією `E_d`;
- p-орбіталі аніона кисню з енергією `E_p`, яка спочатку зайнята двома електронами `p_↑ p_↓`.

Енергетичні параметри системи:
- `Δ = E_d - E_p` — енергія переносу заряду (*charge-transfer energy*);
- `U_d` — одновузлове кулонівське відштовхування двох електронів на d-орбіталі одного катіона;
- `t_pd` — матричний елемент гібридизації (перескоку) між p-орбіталлю кисню та d-орбіталлю катіона.

Взаємодія виникає у четвертому порядку теорії збурень за оператором тунелювання `t_pd` через віртуальний перенос двох електронів:

```
Стан 0 (основний):      | d_1(↑) ,  p(↑↓) ,  d_2(↓) ⟩           E₀ = 0
Стан 1 (збудження 1):   | d_1²(↑↓) , p(↓) ,  d_2(↓) ⟩           E₁ = Δ
Стан 2 (збудження 2):   | d_1²(↑↓) , p(0) ,  d_2²(↑↓) ⟩         E₂ = 2Δ + U_d (або 2Δ)
Стан 3 (збудження 3):   | d_1(↑) ,   p(↑) ,  d_2²(↑↓) ⟩         E₃ = Δ
Стан 4 (релаксація):    | d_1(↓) ,  p(↑↓) ,  d_2(↑) ⟩           E₄ = 0
```

Якщо спіни вихідних катіонів паралельні (`d_1(↑)` та `d_2(↑)`), електрон з кисневої p-орбіталі зі спіном `↑` не може перескочити на катіон `M₂`, оскільки d-орбіталь уже зайнята електроном `↑` (блокування Паулі). Отже, для триплетного стану енергетична поправка четвертого порядку тотожно зникає: `ΔE_T^(4) = 0`.

Для синглетного стану антипаралельних спінів переходи дозволені. Формула четвертого порядку Релея — Шредінгера:

```
ΔE_S^(4) = - ∑_(m,n,k) [ ⟨0|Ĥ_hop|m⟩·⟨m|Ĥ_hop|n⟩·⟨n|Ĥ_hop|k⟩·⟨k|Ĥ_hop|0⟩ ] / [ (E_m - E₀)·(E_n - E₀)·(E_k - E₀) ]
```

Підставляючи проміжні матричні елементи `t_pd` та знаменники `E₁ = Δ`, `E₂ = 2Δ + U_d`, `E₃ = Δ`:

```
ΔE_S^(4)
= - 2 · [ t_pd⁴ / (Δ · (2Δ + U_d) · Δ) + t_pd⁴ / (Δ · U_d · Δ) ]
≈ - 4 · t_pd⁴ / Δ² · [ 1 / U_d + 1 / (2Δ) ]                         [енергія синглетної делокалізації]
```

Ефективний обмінний параметр суперобміну для лінійного зв'язку 180° набуває вигляду:

```
J_super^(180°) = - 2 · t_pd⁴ / (Δ² · U_d) - 2 · t_pd⁴ / Δ³          [сильний антиферомагнітний суперобмін]
```

Якщо кут зв'язку `M₁ — O — M₂` становить 90°, перескоки електронів відбуваються на взаємно ортогональні p-орбіталі кисню `p_x` та `p_y`. Проміжний стан на аніоні кисню містить два неспарені електрони `p_x(↑) p_y(↑)`, які взаємодіють через внутрішньоатомний обмін Гунда `J_H(O) > 0`. Це приводить до **правил Гуденафа — Канаморі**:

```
J_super^(90°) = + 2 · t_pd⁴ · J_H(O) / Δ⁴ > 0                       [феромагнітний суперобмін під кутом 90°]
```

### 10. Анізотропний обмін Дзялошинського — Морія (DMI) з теорії збурень за спін-орбітальним зв'язком

У кристалах без центра просторової інверсії на середині міжатомного зв'язку релятивістська **спін-орбітальна взаємодія (СОВ)** породжує антисиметричний неколінеарний обмін — взаємодію Дзялошинського — Морія (DMI).

Одночастинковий оператор СОВ для електронів на магнітних іонах:

```
Ĥ_SO = ∑_i λ_i · (L̂_i · Ŝ_i)
```

де `λ_i` — константа спін-орбітального зв'язку, `L̂_i` — оператор орбітального моменту, а `Ŝ_i` — оператор спіну.

У кристалічному полі орбітальний момент основного стану `|g⟩` часто є замороженим (`⟨g|L̂|g⟩ = 0`). Проте СОВ підмішує збуджені орбітальні стани `|e⟩` з енергією збудження `ΔE_e = E_e - E_g`:

```
|g_i'⟩ = |g_i⟩ + ∑_(e ≠ g) [ ⟨e_i| λ · (L̂_i · Ŝ_i) |g_i⟩ / (E_g - E_e) ] · |e_i⟩
```

Тору Морія (1960) показав, що комбінація тунелювання `t_ij` у моделі Габбарда та спін-орбітального збурення у 3-му порядку теорії збурень породжує ефективний гамільтоніан:

```
Ĥ_DM = D_ij · (Ŝ_i × Ŝ_j)
```

де вектор Дзялошинського — Морія `D_ij` задається комутатором матричних елементів:

```
D_ij = 2 · i · λ · [ ⟨g_i| L̂_i |e_i⟩ · t_ij / (E_e - E_g) ] · (4·t_ij / U) - (i ↔ j)
```

За порядком величини модуль вектора `D_ij` пропорційний релятивістському відхиленню фактора Ланде `Δg = |g - 2.0023|` від значення для вільного електрона:

```
|D_ij| ≈ 2 · (Δg / g) · |J_ij|
```

Орієнтація вектора `D_ij` строго визначається елементами локальної кристалографічної точкової симетрії (п'ять правил Морія):

1. **Центр інверсії:** Якщо точка інверсії лежить на середині відрізка, що з'єднує вузли `i` та `j`, то `D_ij = 0` тотожно.
2. **Дзеркальна площина `σ`, що містить зв'язок `i-j`:** Вектор `D_ij` спрямований строго перпендикулярно до цієї площини (`D_ij ⊥ σ`).
3. **Дзеркальна площина `σ`, що перетинає середину зв'язку `i-j` перпендикулярно:** Вектор `D_ij` лежить у цій площині (`D_ij ∥ σ`).
4. **Вісь обертання другого порядку `C₂`, перпендикулярна до зв'язку `i-j` на його середині:** Вектор `D_ij` перпендикулярний до осі `C₂` (`D_ij ⊥ C₂`).
5. **Вісь обертання `C_n` (`n ≥ 2`), спрямована вздовж зв'язку `i-j`:** Вектор `D_ij` паралельний лінії зв'язку (`D_ij ∥ C_n`).

Гамільтоніан DMI енергетично сприяє взаємному перпендикулярному розвороту сусідніх спінів під кутом `θ ≈ |D_ij| / (2·J_ij)`, що формує хіральні магнітні текстури: спіральні спінові хвилі, магнітні скірміони та неколінеарні антиферомагнетики.

### 11. Непрямий обмін РККІ (Рудермана — Кіттеля — Касуї — Йосиди)

У металах із локалізованими магнітними моментами (наприклад, рідкісноземельні елементи `Gd`, `Tb`, `Dy` або розбавлені магнітні напівпровідники) 4f- чи d-оболонки сильно стиснуті й не перекриваються у просторі. Обмінна взаємодія між віддаленими вузлами `R_i` та `R_j` передається через поляризацію електронів провідності зони Фермі — **механізм РККІ** (*RKKY indirect exchange*).

Контактний s-d (або s-f) обмінний гамільтоніан локалізованого спіна `S_i` з електронами провідності має вигляд:

```
Ĥ_sd = - J_sd / N · ∑_i Ŝ_i · [ ∑_(k,k',σ,σ') exp( -i·(k - k')·R_i ) · c_kσ† · σ_σσ' · c_k'σ' ]
```

де `J_sd` — внутрішньоатомний інтеграл прямого обміну між локалізованим та делокалізованим електроном, а `σ` — вектор матриць Паулі.

У другому порядку теорії збурень ефективна взаємодія між двома локалізованими спінами визначається статичною спіновою сприйнятливістю електронного газу (функцією Ліндхарда) `χ(q)`:

```
Ĥ_RKKY = - ∑_(i,j) J_RKKY(R_ij) · (Ŝ_i · Ŝ_j)
J_RKKY(R) = (J_sd² / N²) · ∑_q exp( i · q · R ) · χ(q)
```

Функція сприйнятності вільного тривимірного електронного газу Фермі при абсолютному нулі `T = 0 K` дорівнює:

```
χ(q) = (m · k_F) / (2π² · ħ²) · [ 1/2 + (4·k_F² - q²) / (8·k_F·q) · ln | (2·k_F + q) / (2·k_F - q) | ]
```

де `k_F = (3π²·n)^(1/3)` — ферміївський хвильовий вектор.

Обчислюючи зворотне просторове перетворення Фур'є в сферичних координатах `∫₀^∞ q² dq · sin(qR)/(qR) · χ(q)`:

```
J_RKKY(R) = - (J_sd² · m · k_F⁴) / (8π³ · ħ²) · F( 2 · k_F · R )
```

де безрозмірна осцилююча функція РККІ задається явною аналітичною формулою:

```
F(x) = [ sin(x) - x · cos(x) ] / x⁴       де x = 2 · k_F · R
```

На великих міжатомних відстанях (`x ≫ 1`) функція РККІ спадає з відстанню за степеневим законом із чергуванням знаку:

```
F(x) ≈ - cos(x) / x³ = - cos( 2 · k_F · R ) / ( 2 · k_F · R )³
```

Залежність асимптотичного спадання обміну РККІ суттєво залежить від ефективної просторової розмірності електронної системи `d`:
- **У 1D металевих квантових дротах та вуглецевих нанотрубках:** інтегрування одновимірної сприйнятливості дає функцію інтегрального синуса `F_1D(x) = - Si(x) + π/2 ≈ cos(2·k_F·R) / (2·k_F·R)`. Спадання відбувається дуже повільно за законом `1/R`, що робить непряму взаємодію далекодійною на макроскопічних масштабах.
- **У 2D електронному газі (графен, гетероструктури GaAs/AlGaAs):** функція Ліндхарда містить циліндричні функції Бесселя `F_2D(x) = [ J₀(x)·Y₀(x) + J₁(x)·Y₁(x) ] ∝ sin(2·k_F·R) / (2·k_F·R)²`, спадаючи як `1/R²`.
- **У 3D об'ємних металах:** функція спадає найшвидше за кубічним законом `1/R³`.

Ці просторові осциляції є прямим наслідком сингулярності похідної `dχ/dq` при хвильовому векторі `q = 2·k_F` (осциляції Фріделя густини спінової поляризації). Залежно від між'ядерної відстані `R_ij` знак взаємодії періодично змінюється з періодом `λ_F / 2 = π / k_F`, стабілізуючи феромагнітний порядок при малих `R`, антиферомагнітний на проміжних відстанях, або неколінеарні гелікоїдальні спінові структури у важких лантаноїдах.

У розбавлених магнітних сплавах (наприклад, домішки марганцю у міді `Cu_Mn` або заліза в золоті `Au_Fe`) випадкове просторове розташування магнітних атомів призводить до одночасної наявності як феромагнітних, так і антиферомагнітних зв'язків між різними парами. Це породжує колосальну магнітну фрустрацію та формує стан **спінового скла** (*spin glass*), де спіни хаотично заморожуються без жодного далекого просторового порядку.

### 12. Виведення дисперсії спинових хвиль (Магнонів) у феромагнетиках

Розглянемо квантування низькоенергетичних збуджень основного феромагнітного стану з гамільтоніана Гейзенберга:

```
Ĥ = -2 · J · ∑_(⟨i,j⟩) (Ŝ_i · Ŝ_j) = -2 · J · ∑_(⟨i,j⟩) [ Ŝ_i^z · Ŝ_j^z + 1/2 · (Ŝ_i^+ · Ŝ_j^- + Ŝ_i^- · Ŝ_j^+) ]
```

де `J > 0`, а `Ŝ_i^± = Ŝ_i^x ± i·Ŝ_i^y`.

Застосуємо нелінійне квантове **перетворення Гольштейна — Примакова** (1940), яке точно відображає алгебру кутового моменту `SU(2)` на бозонні оператори народження `â_i†` та знищення `â_i` спінових відхилень (`[â_i, â_j†] = δ_ij`):

```
Ŝ_i^z = S - â_i† · â_i
Ŝ_i^+ = √(2S) · √(1 - â_i†·â_i / (2S)) · â_i
Ŝ_i^- = √(2S) · â_i† · √(1 - â_i†·â_i / (2S))
```

При низьких температурах середня кількість збуджених магнонів мала (`⟨â_i†·â_i⟩ ≪ 2S`), тому квадратний корінь розкладається в ряд Тейлора:

```
√(1 - â_i†·â_i / (2S)) = 1 - â_i†·â_i / (4S) + O(S⁻²)
```

Зберігаючи квадратичні за бозонами члени:

```
Ŝ_i^+ ≈ √(2S) · â_i
Ŝ_i^- ≈ √(2S) · â_i†
```

Підставимо ці вирази у скалярний добуток спінів:

```
Ŝ_i^z · Ŝ_j^z = (S - â_i†·â_i) · (S - â_j†·â_j) = S² - S · (â_i†·â_i + â_j†·â_j) + O(a⁴)
1/2 · (Ŝ_i^+ · Ŝ_j^- + Ŝ_i^- · Ŝ_j^+) ≈ S · (â_i·â_j† + â_i†·â_j) = S · (â_j†·â_i + â_i†·â_j)
```

Гамільтоніан набуває вигляду:

```
Ĥ ≈ -2·J · ∑_(⟨i,j⟩) [ S² - S · (â_i†·â_i + â_j†·â_j - â_i†·â_j - â_j†·â_i) ]
```

Позначимо координаційне число ґратки як `z` (кількість найближчих сусідів кожного вузла), а загальну кількість вузлів як `N`. Кількість зв'язків дорівнює `N·z / 2`. Тоді:

```
Ĥ = - J·N·z·S² + 2·J·S·z · ∑_i â_i†·â_i - 2·J·S · ∑_(⟨i,j⟩) (â_i†·â_j + â_j†·â_i)
```

Здійснимо просторове перетворення Фур'є до хвильових векторів `k` першої зони Бріллюена:

```
â_i = 1/√N · ∑_k exp( i · k · R_i ) · â_k
â_i† = 1/√N · ∑_k exp( - i · k · R_i ) · â_k†
```

Підставляючи у гамільтоніан:

```
∑_i â_i†·â_i = ∑_k â_k†·â_k
∑_(⟨i,j⟩) â_i†·â_j = 1/2 · ∑_i ∑_δ â_i†·â_(i+δ) = 1/2 · ∑_k â_k†·â_k · ∑_δ exp( i · k · δ )
```

де `δ` — вектори найближчих сусідів. Введемо безрозмірний структурний геометричний фактор ґратки `γ_k`:

```
γ_k = (1 / z) · ∑_δ exp( i · k · δ )
```

Гамільтоніан діагоналізується у формі суми незалежних квантових гармонічних осциляторів:

```
Ĥ = E_G + ∑_k ħ·ω(k) · â_k† · â_k
```

де `E_G = - J·N·z·S²` — енергія основного феромагнітного стану, а квантова енергія феромагнітного магнона `ħ·ω(k)` дорівнює:

```
ħ·ω(k) = 2 · J · S · z · [ 1 - γ_k ]
```

Розглянемо закон дисперсії для різних кристалічних ґраток із періодом `a`:

- **1D феромагнітний ланцюжок (`z = 2`, `δ = ±a`):**

```
γ_k = 1/2 · [ exp(i·k·a) + exp(-i·k·a) ] = cos(k·a)
ħ·ω(k) = 4 · J · S · [ 1 - cos(k·a) ] = 8 · J · S · sin²(k·a / 2)
```

- **2D квадратна ґратка (`z = 4`, `δ = (±a, 0), (0, ±a)`):**

```
γ_k = 1/2 · [ cos(k_x·a) + cos(k_y·a) ]
ħ·ω(k) = 4 · J · S · [ 2 - cos(k_x·a) - cos(k_y·a) ]
```

- **3D проста кубічна ґратка (`z = 6`, `δ = (±a, 0, 0), (0, ±a, 0), (0, 0, ±a)`):**

```
γ_k = 1/3 · [ cos(k_x·a) + cos(k_y·a) + cos(k_z·a) ]
ħ·ω(k) = 2 · J · S · [ 6 - 2·cos(k_x·a) - 2·cos(k_y·a) - 2·cos(k_z·a) ]
```

У довгохвильовій границі (`|k|·a ≪ 1`) розкладемо косинус у ряд Тейлора `cos(k_x·a) ≈ 1 - (k_x·a)²/2`:

```
ħ·ω(k)
= 2 · J · S · [ (k_x·a)² + (k_y·a)² + (k_z·a)² ]
= (2 · J · S · a²) · k²
= D · k²                                                            [квадратична дисперсія феромагнітних магнонів]
```

де `D = 2 · J · S · a²` — квантова **спінова жорсткість** (*spin stiffness*) феромагнетика.

### 13. Термодинаміка феромагнітних магнонів і температурний закон Блоха

Оскільки магнони є квазічастинками бозе-статистики з нульовим хімічним потенціалом (`μ = 0`), їхня рівноважна функція розподілу за температури `T` задається статистикою Планка — Бозе — Ейнштейна:

```
n_k = 1 / [ exp( ħ·ω(k) / (k_B·T) ) - 1 ]
```

Загальна кількість збуджених магнонів у 3D об'ємі `V` при низьких температурах:

```
N_mag(T) = ∑_k n_k = V / (2π)³ · ∫₀^∞ 4π·k² dk / [ exp( D·k² / (k_B·T) ) - 1 ]
```

Зробимо заміну безрозмірної змінної `x = D·k² / (k_B·T)`, звідки `k = √(k_B·T / D) · √x` та `dk = 1/2 · √(k_B·T / D) · x^(-1/2) dx`:

```
N_mag(T)
= V / (4π²) · ( k_B·T / D )^(3/2) · ∫₀^∞ x^(1/2) dx / [ exp(x) - 1 ]
```

Табличний бозе-інтеграл виражається через гамма-функцію Ейлера `Γ(3/2) = √π / 2` та дзета-функцію Рімана `ζ(3/2) ≈ 2.612375`:

```
∫₀^∞ x^(1/2) dx / [ exp(x) - 1 ] = Γ(3/2) · ζ(3/2) = (√π / 2) · 2.612375 ≈ 2.31516
```

Підставляючи у вираз для концентрації магнонів `n_mag = N_mag / V`:

```
n_mag(T) = ζ(3/2) / (8·π^(3/2)) · ( k_B·T / D )^(3/2) ≈ 0.0587 · ( k_B·T / D )^(3/2)
```

Кожен збуджений магнон зменшує проєкцію повного спіну системи на `1` (тобто магнітний момент на `g·μ_B`). Температурна залежність спонтанної намагніченості феромагнетика набуває форми **закону Блоха T^(3/2)** (Фелікс Блох, 1930):

```
M(T) = M(0) · [ 1 - (g · μ_B) / M(0) · n_mag(T) ] = M(0) · [ 1 - B · T^(3/2) ]
```

де коефіцієнт Блоха `B` дорівнює:

```
B = (g · μ_B) / (S · ρ_spin) · ζ(3/2) / (8·π^(3/2)) · ( k_B / D )^(3/2)
```

Магнонна теплоємність феромагнетика при низьких температурах знаходиться з повної енергії теплових спінових збуджень `E_mag(T) = ∑_k ħ·ω(k) · n_k`:

```
E_mag(T) = V / (4π²) · (k_B·T)^(5/2) / D^(3/2) · ∫₀^∞ x^(3/2) dx / [ exp(x) - 1 ]
```

Оскільки `∫₀^∞ x^(3/2) dx / [ exp(x) - 1 ] = Γ(5/2) · ζ(5/2) = (3√π / 4) · 1.341 ≈ 1.783`:

```
E_mag(T) ∝ T^(5/2)
C_mag(T) = dE_mag / dT ∝ T^(3/2)                                    [магнонна теплоємність феромагнетика]
```

### 14. Виведення дисперсії антиферомагнітних магнонів через перетворення Боголюбова

В антиферомагнетиках (`J < 0`, позначимо `J_AF = |J| > 0`) кристалічна ґратка розбивається на дві взаємопроникні магнітні підґратки `A` (спіни `↑`) та `B` (спіни `↓`).

Гамільтоніан Гейзенберга для зв'язків між підґратками:

```
Ĥ = 2 · J_AF · ∑_(i∈A, δ) (Ŝ_i · Ŝ_(i+δ))
```

Виразимо спіни підґратки `A` через бозони `â_i`, а спіни підґратки `B` — через бозони `b̂_j`:

```
Вузол i ∈ A (спін вгору):     Ŝ_i^z = S - â_i†·â_i ,    Ŝ_i^+ ≈ √(2S)·â_i ,   Ŝ_i^- ≈ √(2S)·â_i†
Вузол j ∈ B (спін вниз):     Ŝ_j^z = -S + b̂_j†·b̂_j ,   Ŝ_j^+ ≈ √(2S)·b̂_j† ,  Ŝ_j^- ≈ √(2S)·b̂_j
```

Підставляючи у скалярний добуток:

```
Ŝ_i^z · Ŝ_j^z = (S - â_i†·â_i)·(-S + b̂_j†·b̂_j) = -S² + S·(â_i†·â_i + b̂_j†·b̂_j) + O(a⁴)
1/2 · (Ŝ_i^+·Ŝ_j^- + Ŝ_i^-·Ŝ_j^+) = S · (â_i·b̂_j + â_i†·b̂_j†)
```

Переходячи до Фур'є-образів `â_k` та `b̂_k` у k-просторі:

```
Ĥ = - J_AF·N·z·S² + 2·J_AF·z·S · ∑_k [ â_k†·â_k + b̂_k†·b̂_k + γ_k · (â_k†·b̂_-k† + â_k·b̂_-k) ]
```

Аномальні члени `â_k†·b̂_-k†` та `â_k·b̂_-k` створюють та знищують пари магнонів одночасно на обох підґратках. Для діагоналізації застосуємо канонічне **бозонне перетворення Боголюбова**:

```
â_k = u_k · α̂_k + v_k · β̂_-k†
b̂_-k† = v_k · α̂_k + u_k · β̂_-k†
```

де `α̂_k` та `β̂_k` — нові бозонні оператори елементарних збуджень. Щоб перетворення зберігало канонічні комутаційні співвідношення бозонів `[α̂_k, α̂_k'†] = δ_kk'`, коефіцієнти повинні задовольняти гіперболічну умову нормування:

```
u_k² - v_k² = 1  ⇒  u_k = cosh(θ_k),   v_k = sinh(θ_k)
```

Підставимо це перетворення в гамільтоніан та згрупуємо недіагональні члени `α̂_k†·β̂_-k†`:

```
Коефіцієнт при (α̂_k†·β̂_-k† + α̂_k·β̂_-k) = 2·u_k·v_k + γ_k · (u_k² + v_k²) = 0
```

Використовуючи гіперболічні тотожності `2·u_k·v_k = sinh(2θ_k)` та `u_k² + v_k² = cosh(2θ_k)`:

```
sinh(2θ_k) + γ_k · cosh(2θ_k) = 0  ⇒  tanh(2θ_k) = - γ_k
```

Звідси знаходимо:

```
cosh(2θ_k) = 1 / √(1 - γ_k²)
sinh(2θ_k) = - γ_k / √(1 - γ_k²)
```

Діагоналізований гамільтоніан антиферомагнетика набуває канонічного вигляду:

```
Ĥ = E_GS + ∑_k ħ·ω(k) · [ α̂_k†·α̂_k + β̂_k†·β̂_k ]
```

де закон дисперсії антиферомагнітних магнонів дорівнює:

```
ħ·ω(k) = 2 · J_AF · z · S · √(1 - γ_k²)
```

Розглянемо довгохвильову границю (`|k|·a ≪ 1`). Розклад структурного фактора у d-вимірній кубічній ґратці:

```
1 - γ_k ≈ (1 / (2·d)) · (k·a)²
1 - γ_k² = (1 - γ_k) · (1 + γ_k) ≈ [ (k·a)² / (2·d) ] · 2 = (k·a)² / d
```

Підставляючи цей вираз у дисперсію:

```
ħ·ω(k) ≈ 2 · J_AF · z · S · √[ (k·a)² / d ] = ( 2 · J_AF · S · a · √(z / d) ) · |k| = c_s · |k|
```

де `c_s = 2 · J_AF · S · a · √(z / d)` — лінійна **швидкість антиферомагнітних спінових хвиль** (аналог швидкості звуку для акустичних фононів).

На відміну від феромагнетика, де дисперсія є квадратичною (`ω ∝ k²`), в антиферомагнетику закон дисперсії магнонів є строго **лінійним** за хвильовим вектором (`ω ∝ |k|`). Внаслідок лінійності дисперсії теплоємність антиферомагнітного магнонного газу спадає з температурою як куб температури:

```
C_mag^(AF)(T) = dE_mag^(AF) / dT ∝ T³                               [кубічна теплоємність антиферомагнетика]
```

Перетворення Боголюбова також розкриває фундаментальне явище **квантових нульових флуктуацій** (*zero-point spin fluctuations*). Середня намагніченість підґратки в основному стані при `T = 0 K` менша за номінальне значення `S`:

```
⟨Ŝ_i^z⟩ = S - ⟨â_i†·â_i⟩ = S - ΔS
```

де квантове зменшення спіну дорівнює:

```
ΔS = 1/N · ∑_k v_k² = 1/(2N) · ∑_k [ 1 / √(1 - γ_k²) - 1 ]
```

У 1D антиферомагнітному ланцюжку цей інтеграл логарифмічно розбігається при `k → 0`, що означає повну відсутність класичного далекого магнітного порядку Нееля для квантового спіну `S = 1/2` (теорема Мерміна — Вагнера та Ліба — Шульца — Маттіса). У 3D кубічній ґратці `ΔS ≈ 0.078` для `S = 1/2`, що зменшує спостережуваний магнітний момент підґратки приблизно на 15%.

### 15. Вищі порядки розкладу: Біквадратичний та кільцевий 4-спіновий обмін

У системах із більшими спінами (`S ≥ 1`) або при наближенні до межі металізації (`t/U` не є нескінченно малим) розклад теорії збурень за тунелюванням `t/U` у моделі Габбарда породжує члени 4-го порядку за спіновими операторами:

```
Ĥ_4th = - j_bq · ∑_(⟨i,j⟩) (Ŝ_i · Ŝ_j)² + K_ring · ∑_plaq [ (Ŝ₁·Ŝ₂)(Ŝ₃·Ŝ₄) + (Ŝ₁·Ŝ₄)(Ŝ₂·Ŝ₃) - (Ŝ₁·Ŝ₃)(Ŝ₂·Ŝ₄) ]
```

де:
- **Біквадратичний обмін `j_bq`** (виникає у 4-му порядку `j_bq = 4·t⁴ / U³`): стабілізує спін-нематичні та мультиполярні квантові стани;
- **Кільцевий 4-спіновий обмін `K_ring`** (*ring exchange*): описує скоординований циклічний рух чотирьох електронів по замкненому контуру квадратної плакетки `1 → 2 → 3 → 4 → 1` у купратних шарах `CuO₂` високотемпературних надпровідників та у твердому квантовому гелії ³He.

### 16. Багатоорбітальний обмін Канаморі та внутрішньоатомні правила Гунда

В атомах перехідних металів d-оболонка містить 5 вироджених орбіталей, які у кристалічному полі октаедричного оточення розщеплюються на триплет `t_2g` (`d_xy, d_yz, d_zx`) та дублет `e_g` (`d_x²-y², d_3z²-r²`). Взаємодія між електронами на різних орбіталях одного вузла описується **гамільтоніаном Канаморі** (Дзюн Канаморі, 1963):

```
Ĥ_Kanamori
= U · ∑_m n_m↑ · n_m↓ + U' · ∑_(m ≠ m') n_m↑ · n_m'↓ + (U' - J_H) · ∑_(m < m', σ) n_mσ · n_m'σ
  - J_H · ∑_(m ≠ m') [ c_m↑† · c_m↓ · c_m'↓† · c_m'↑ - c_m↑† · c_m'↓† · c_m↑ · c_m'↓ ]
```

де `U` — внутрішньоорбітальне кулонівське відштовхування, `U'` — міжорбітальне відштовхування, а `J_H` — внутрішньоатомний обмінний інтеграл Гунда. З умови інваріантності кулонівської взаємодії щодо орбітальних обертань у кубічному полі випливає строге алгебраїчне співвідношення:

```
U' = U - 2 · J_H
```

Розглянемо два електрони, розміщені на двох різних орбіталях `m = 1, 2`. Енергетичний спектр можливих двоелектронних квантових станів складається з:

1. **Триплетний стан (`S = 1`, паралельні спіни на різних орбіталях):**
   Енергія відштовхування двох електронів становить:

```
E_triplet = U' - J_H = (U - 2·J_H) - J_H = U - 3 · J_H
```

2. **Міжорбітальний синглетний стан (`S = 0`, антипаралельні спіни на різних орбіталях):**
   З урахуванням обмінного перевороту спінів енергія дорівнює:

```
E_singlet1 = U' + J_H = (U - 2·J_H) + J_H = U - J_H
```

3. **Внутрішньоорбітальні синглетні стани (`S = 0`, пара електронів на одній орбіталі):**
   Внаслідок парного переносу `c_1↑† c_1↓† c_2↓ c_2↑` симетрична та антисиметрична комбінації мають енергії:

```
E_singlet2(+) = U + J_H
E_singlet2(-) = U - J_H
```

Різниця енергій між триплетним станом та найнижчим синглетним станом дорівнює:

```
ΔE_Hund = E_singlet - E_triplet = (U - J_H) - (U - 3·J_H) = + 2 · J_H > 0
```

Цей результат строго доводить **перше правило Гунда**: стан із максимальним повним спіном `S = 1` має енергію, яка рівно на `2·J_H` менша за енергію будь-якого синглетного стану. Проєкція гамільтоніана Канаморі на підпростір спінів двох орбіталей дає ефективний оператор обміну Гунда:

```
Ĥ_Hund = - 2 · J_H · (Ŝ₁ · Ŝ₂) - 1/2 · J_H · n₁ · n₂
```

### 17. Двійний обмін Зінера (Double Exchange) у манганітах

У манганітах зі змішаною валентністю типу `La_(1-x)Sr_xMnO₃` іони марганцю знаходяться у двох зарядових станах: `Mn³⁺` (електронна конфігурація `t_2g³ e_g¹`, кор-спін `S = 2`) та `Mn⁴⁺` (конфігурація `t_2g³ e_g⁰`, кор-спін `S = 3/2`). 

Локалізовані `t_2g`-електрони формують жорсткий кор-спін `S_core = 3/2`, тоді як рухливий `e_g`-електрон може вільно тунелювати між вузлами `Mn³⁺` та `Mn⁴⁺` через проміжний аніон кисню `O²⁻`. Внутрішньоатомний обмін Гунда на кожному вузлі є колосальним (`J_H ≈ 1 – 2 eV ≫ t`), тому спін рухливого `e_g`-електрона жорстко зафіксований паралельно локальному кор-спіну того вузла, на якому він перебуває.

Нехай класичні кор-спіни на сусідніх вузлах `i` та `j` орієнтовані під відносним кутом `θ_ij`. Спінори електрона на відповідних вузлах у власній системі відліку мають вигляд:

```
|χ_i⟩ = cos(θ_i / 2) · |↑⟩ + sin(θ_i / 2) · |↓⟩
|χ_j⟩ = cos(θ_j / 2) · |↑⟩ + sin(θ_j / 2) · |↓⟩
```

Квантова амплітуда переходу (перекриття спінорів) між двома повернутими станами дорівнює:

```
⟨χ_i | χ_j⟩
= cos(θ_i / 2) · cos(θ_j / 2) + sin(θ_i / 2) · sin(θ_j / 2)    [скалярний добуток спінорів Паулі]
= cos( (θ_i - θ_j) / 2 )                                       [тригонометрична формула косинуса різниці]
= cos( θ_ij / 2 )                                              [визначення кута між кор-спінами θ_ij = θ_i - θ_j]
```

Отже, ефективний матричний елемент тунелювання `e_g`-електрона між сусідніми іонами зменшується пропорційно косинусу половинного кута:

```
t_eff(θ_ij) = t₀ · cos( θ_ij / 2 )
```

де `t₀` — незбурений інтеграл перескоку для строго паралельних спінів.

Повна кінетична енергія зони провідності `e_g`-електронів пропорційна ефективному перескоку:

```
E_kinetic(θ) = - 2 · z · t₀ · cos( θ / 2 ) · (1 - x)
```

де `x` — концентрація дірок (доля іонів `Mn⁴⁺`), а `z` — координаційне число.

З іншого боку, між кор-спінами `t_2g` діє слабкий антиферомагнітний суперобмін Андерсона:

```
E_AF(θ) = + J_AF · (S_core)² · cos(θ)
```

Повна енергія магнітного зв'язку на вузол дорівнює:

```
E_total(θ) = - 2 · z · t₀ · (1 - x) · cos( θ / 2 ) + J_AF · S² · cos(θ)
```

Оскільки при малих кутах `cos(θ/2) ≈ 1 - θ²/8`, а `cos(θ) ≈ 1 - θ²/2`, кінетичний виграш від паралельної орієнтації (`θ = 0`, `cos(0) = 1`) значно переважає антиферомагнітний суперобмін при концентраціях `0.2 < x < 0.5`. Це явище отримало назву **двійного обміну Зінера** (*Zener double exchange*, Кларенс Зінер, 1951): делокалізація електронів провідності породжує феромагнетизм, безпосередньо супроводжуваний переходом метал — діелектрик та гігантським магнітоопором (CMR).

### 18. Спін-хвильове представлення Дайсона — Малєєва та взаємодія магнонів

Перетворення Гольштейна — Примакова містить нелінійні радикали `√(1 - a†a/2S)`, що ускладнює розрахунок взаємодії між магнонами у вищих порядках теорії збурень. Фрімен Дайсон (1956) та Сергій Малєєв (1957) запропонували альтернативне точне відображення спінової алгебри на бозонні оператори, яке має строго поліноміальну форму:

```
Ŝ_i^z = S - b̂_i† · b̂_i
Ŝ_i^+ = √(2S) · [ 1 - (b̂_i† · b̂_i) / (2S) ] · b̂_i
Ŝ_i^- = √(2S) · b̂_i†
```

Перевіримо точне виконання фундаментального комутаційного співвідношення `[Ŝ_i^+, Ŝ_i^-] = 2 · Ŝ_i^z`:

```
[Ŝ_i^+, Ŝ_i^-]
= 2S · [ ( 1 - b̂_i†·b̂_i / (2S) ) · b̂_i , b̂_i† ]                                            [підстановка бозонних операторів]
= 2S · [ b̂_i·b̂_i† - b̂_i†·b̂_i - (1 / (2S)) · (b̂_i†·b̂_i·b̂_i·b̂_i† - b̂_i†·b̂_i†·b̂_i·b̂_i) ] [розкриття комутатора]
= 2S · [ 1 - (1 / (2S)) · 2 · b̂_i†·b̂_i ]                                                  [бозонні комутації [b, b†] = 1]
= 2 · (S - b̂_i†·b̂_i)                                                                     [винесення множника]
= 2 · Ŝ_i^z                                                                               [комутатор строго точний]
```

Ціною строгої поліноміальності є неермітовість перетворення: `(Ŝ_i^+)† ≠ Ŝ_i^-`. Проте в підпросторі фізичних станів із числом бозонів `b̂_i†·b̂_i ≤ 2S` усі власні значення енергії є строго дійсними.

Підставляючи оператори Дайсона — Малєєва у гамільтоніан Гейзенберга `Ĥ = -2J ∑ (S_i · S_j)`, отримуємо точний розклад на квадратичну та четвертну частини:

```
Ĥ = E_G + Ĥ_mag^(2) + Ĥ_int^(4)
```

де член магнон-магнонної взаємодії четвертого порядку має вигляд:

```
Ĥ_int^(4) = - J / N · ∑_(k₁,k₂,k₃,k₄) δ(k₁+k₂ - k₃-k₄) · [ γ_(k₁) + γ_(k₄-k₂) - 2·γ_(k₁-k₄) ] · b̂_k₁† · b̂_k₂† · b̂_k₃ · b̂_k₄
```

Усереднення оператора `Ĥ_int^(4)` за рівноважним ансамблем теплових магнонів дає перенормування спінової жорсткості з температурою за рахунок теплового зіткнення спінових хвиль:

```
D(T) = D(0) · [ 1 - C_D · ( k_B · T / D(0) )^(5/2) ]
```

де коефіцієнт `C_D = π · ζ(5/2) · v₀ / S` (де `v₀ = a³` — об'єм елементарної комірки). Цей розрахунок доводить, що магнони слабо взаємодіють між собою при низьких температурах, проте при нагріванні взаємне розсіяння магнонів пом'якшує спінову жорсткість кристала.

### 19. Точний розв'язок 1D квантового XY-ланцюжка через перетворення Йордана — Вігнера

Розглянемо одновимірний квантовий ланцюжок спінів `S = 1/2` з анізотропною обмінною взаємодією у зовнішньому магнітному полі `h` вздовж осі `z` (модель Ліба — Шульца — Маттіса, 1961):

```
Ĥ_XY = - J · ∑_i [ (1 + γ) · Ŝ_i^x · Ŝ_(i+1)^x + (1 - γ) · Ŝ_i^y · Ŝ_(i+1)^y ] - h · ∑_i Ŝ_i^z
```

де `γ` — параметр анізотропії у площині `xy`.

Виразимо гамільтоніан через спінові драбинкові оператори `Ŝ_i^± = Ŝ_i^x ± i·Ŝ_i^y`:

```
Ĥ_XY = - J/2 · ∑_i [ (Ŝ_i^+ · Ŝ_(i+1)^- + Ŝ_i^- · Ŝ_(i+1)^+) + γ · (Ŝ_i^+ · Ŝ_(i+1)^+ + Ŝ_i^- · Ŝ_(i+1)^-) ] - h · ∑_i Ŝ_i^z
```

Для точної діагоналізації застосуємо нелокальне квантове **перетворення Йордана — Вігнера** (Паскуаль Йордан, Юджин Вігнер, 1928), яке відображає локальні спінові оператори на безспінові ферміонівські оператори `c_i†` та `c_i`:

```
Ŝ_i^+ = c_i† · exp( + i · π · ∑_(j < i) c_j†·c_j )
Ŝ_i^- = exp( - i · π · ∑_(j < i) c_j†·c_j ) · c_i
Ŝ_i^z = c_i† · c_i - 1/2
```

Фазовий нелокальний множник `K_i = exp( i·π·∑_(j<i) n_j ) = ∏_(j<i) (1 - 2·n_j)` змінює знак при перестановці частинок, що гарантує виконання строгих канонічних антикомутаційних співвідношень ферміонів:

```
{ c_i , c_j† } = c_i · c_j† + c_j† · c_i = δ_ij
{ c_i , c_j } = { c_i† , c_j† } = 0
```

Підставляючи це перетворення у парні спінові добутки найближчих сусідів:

```
Ŝ_i^+ · Ŝ_(i+1)^- = c_i† · K_i · K_(i+1) · c_(i+1) = c_i† · (1 - 2·n_i) · c_(i+1) = c_i† · c_(i+1)
Ŝ_i^+ · Ŝ_(i+1)^+ = c_i† · K_i · K_(i+1)† · c_(i+1)† = c_i† · c_(i+1)†
```

Гамільтоніан набуває строго квадратичної ферміонівської форми:

```
Ĥ_XY = - J/2 · ∑_i [ (c_i†·c_(i+1) + c_(i+1)†·c_i) + γ · (c_i†·c_(i+1)† + c_(i+1)·c_i) ] - h · ∑_i (c_i†·c_i - 1/2)
```

Переходячи до Фур'є-простору `c_i = 1/√N · ∑_k exp(i·k·R_i) · c_k`:

```
Ĥ_XY = ∑_k [ - (J · cos(k·a) + h) · c_k†·c_k - i/2 · γ·J · sin(k·a) · (c_k†·c_-k† + c_-k·c_k) ] + N·h / 2
```

Застосовуючи унітарне ферміонівське перетворення Боголюбова `η_k = u_k · c_k - i · v_k · c_-k†` з умовою нормування `u_k² + v_k² = 1`, повністю діагоналізуємо гамільтоніан:

```
Ĥ_XY = ∑_k ε(k) · ( η_k† · η_k - 1/2 )
```

де закон дисперсії елементарних ферміонівських квазічастинок дорівнює:

```
ε(k) = √[ ( J · cos(k·a) + h )² + γ² · J² · sin²(k·a) ]
```

При критичному значенні магнітного поля `h_c = J` енергетична щілина на межі зони Бріллюена `k = π/a` обнуляється:

```
ε(π/a) = √[ (-J + J)² + 0 ] = 0
```

Це обнулення щілини знаменує квантовий фазовий перехід другого роду між феромагнітною фазою з ненульовим далеким порядком за параметром порядку `⟨S_x⟩` та парамагнітною квантово-поляризованою фазою вздовж осі `z`.
