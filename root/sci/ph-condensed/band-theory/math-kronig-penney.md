# 🧮 Математична модель Кроніґа — Пенні та розв'язок рівняння Шредінгера

Ця математична вставка містить повний аналітичний вивід зонної структури електрона в одновимірному періодичному потенціалі Кроніґа — Пенні. Вона показує, як саме граничні умови для хвильової функції у поєднанні з теоремою Блоха приводять до трансцендентного дисперсійного рівняння, дає точний алгебраїчний розрахунок детермінанта, виводить аналітичні вирази для групової швидкості, ефективної маси, нормування блохівських амплітуд, аналізує стани вище потенціального бар'єра (`E > V₀`), густину квантових станів та особливості Ван Хова, виводить затухаючі еванесцентні блохівські хвилі всередині заборонених зон, розкриває секулярне рівняння моделі майже вільних електронів, спин-орбітальні поправки та зіставляє розв'язок із методом сильного зв'язку (LCAO).

## Постановка задачі та математична модель

Розглядається одновимірний рух електрона маси `m` у періодичному потенційному полі `V(x) = V(x + a + b)`, створеному нескінченним ланцюжком прямокутних потенціальних бар'єрів висотою `V₀` і шириною `b`, що розділені потенціальними ямами шириною `a`. Період ґратки дорівнює `d = a + b`.

Рівняння Шредінгера для стаціонарного стану з енергією `E` (`0 < E < V₀`) має вигляд:

```
-[ħ² / (2m)] · (d²ψ / dx²) + V(x)·ψ(x) = E·ψ(x)
```

Введемо дві характеристики хвильового числа:
- Всередині потенціальної ями (`0 < x < a`), де `V(x) = 0`:

```
α = √[2mE] / ħ
```

- Всередині потенціального бар'єра (`-b < x < 0`), де `V(x) = V₀`:

```
β = √[2m(V₀ - E)] / ħ
```

Рівняння Шредінгера ділиться на дві області в межах першого періоду:

```
Область I (0 < x < a):     d²ψ₁ / dx² + α²·ψ₁ = 0
Область II (-b < x < 0):   d²ψ₂ / dx² - β²·ψ₂ = 0
```

Загальні розв'язки для кожної області записуються у вигляді суми двох експоненціальних хвиль:

```
ψ₁(x) = A · e^(i·α·x) + B · e^(-i·α·x)              [0 < x < a]
ψ₂(x) = C · e^(β·x) + D · e^(-β·x)                 [-b < x < 0]
```

де `A, B, C, D` — невизначені комплексні коефіцієнти.

## Застосування теореми Блоха та граничні умови

Згідно з теоремою Блоха, хвильова функція у періодичному полі задовольняє умову трансляційної симетрії з блохівським хвильовим вектором `k`:

```
ψ(x + d) = e^(i·k·d) · ψ(x)
```

Це дозволяє зв'язати значення хвильової функції та її похідної на лівій межі другого періоду (`x = a`) зі значеннями на лівій межі першого періоду (`x = -b`):

```
ψ₁(a) = e^(i·k·d) · ψ₂(-b)
ψ₁'(a) = e^(i·k·d) · ψ₂'(-b)
```

Для забезпечення неперервності хвильової функції та її першої похідної у точках стику `x = 0` та `x = a` необхідно виконати чотири граничні умови:

```
1) ψ₁(0) = ψ₂(0):
   A + B = C + D

2) ψ₁'(0) = ψ₂'(0):
   i·α·(A - B) = β·(C - D)

3) ψ₁(a) = e^(i·k·d) · ψ₂(-b):
   A·e^(i·α·a) + B·e^(-i·α·a) = e^(i·k·d) · [C·e^(-β·b) + D·e^(β·b)]

4) ψ₁'(a) = e^(i·k·d) · ψ₂'(-b):
   i·α·[A·e^(i·α·a) - B·e^(-i·α·a)] = e^(i·k·d) · β · [C·e^(-β·b) - D·e^(β·b)]
```

Перенесемо всі доданки у ліву частину, щоб сформувати однорідну систему 4×4 відносно вектора коефіцієнтів `X = (A, B, C, D)ᵀ`:

```
[1                      1                     -1                    -1                  ] [A]   [0]
[i·α                    -i·α                  -β                    β                   ] [B] = [0]
[e^(i·α·a)              e^(-i·α·a)            -e^(i·k·d - β·b)      -e^(i·k·d + β·b)    ] [C]   [0]
[i·α·e^(i·α·a)          -i·α·e^(-i·α·a)       -β·e^(i·k·d - β·b)     β·e^(i·k·d + β·b)   ] [D]   [0]
```

## Алгебраїчний вивід трансцендентного рівняння

Однорідна система чотирьох лінійних рівнянь має нетривіальний (ненульовий) розв'язок тоді й лише тоді, коли детермінант матриці системи дорівнює нулю:

```
det M(α, β, k) = 0
```

Для обчислення детермінанта розкладемо матрицю за мінорами або виконаємо елементарні перетворення рядків. Виразимо коефіцієнти `C` та `D` через `A` та `B` з перших двох рівнянь:

```
C = (1/2) · [ (1 + i·α/β)·A + (1 - i·α/β)·B ]
D = (1/2) · [ (1 - i·α/β)·A + (1 + i·α/β)·B ]
```

Підставляючи вирази для `C` та `D` у третє й четверте рівняння, отримуємо систему двох рівнянь відносно `A` та `B`:

```
A · [ e^(i·α·a) - e^(i·k·d)·cosh(β·b) - (i·α/β)·e^(i·k·d)·sinh(β·b) ]
  + B · [ e^(-i·α·a) - e^(i·k·d)·cosh(β·b) + (i·α/β)·e^(i·k·d)·sinh(β·b) ] = 0
```

Прирівнюючи до нуля детермінант цієї системи 2×2 та застосовуючи гіперболічні ототожнення `cosh²(x) - sinh²(x) = 1` і формулу Ейлера `e^(i·α·a) = cos(α·a) + i·sin(α·a)`, після спрощення отримуємо неявне дисперсійне співвідношення:

```
[(β² - α²) / (2·α·β)] · sinh(β·b) · sin(α·a) + cosh(β·b) · cos(α·a) = cos(k·d)
```

## Граничний перехід до дельта-подібних бар'єрів (Модель Кроніґа — Пенні)

Щоб отримати явний простий критерій існування зон, Кроніґ та Пенні розглянули граничний перехід, у якому потенціальні бар'єри стають нескінченно вузькими (`b → 0`) та нескінченно високими (`V₀ → ∞`), проте добуток їхньої висоти на ширину (площа або потужність бар'єра `V₀·b`) залишається скінченною константою.

У цьому граничному переході:
- Ширина періоду прямує до ширини ями: `d = a + b → a`
- Оскільки `V₀ ≫ E`, параметр `β = √[2m(V₀ - E)] / ħ ≈ √[2mV₀] / ħ → ∞`
- `cosh(β·b) → 1`
- `sinh(β·b) → β·b`
- Коефіцієнт при синусі спрощується: `(β² - α²)/(2·α·β) ≈ β / (2·α)`

Тоді перший доданок набуває вигляду:

```
[(β² - α²) / (2·α·β)] · sinh(β·b) · sin(α·a) → [β² · b / (2·α)] · sin(α·a)
                                            = [m · V₀ · b / (ħ² · α)] · sin(α·a)
```

Введемо безрозмірний параметр потужності потенціалу ґратки `P`:

```
P = m · V₀ · a · b / ħ²
```

Підставляючи `P` у співвідношення, отримуємо класичне **дисперсійне рівняння Кроніґа — Пенні**:

```
P · [sin(α·a) / (α·a)] + cos(α·a) = cos(k·a)
```

## Математичний аналіз розв'язків та поява зонних щілин

Позначимо ліву частину рівняння як характеристичну функцію `F(α·a)`:

```
F(y) = P · [sin(y) / y] + cos(y)       [де y = α·a]
```

Оскільки права частина рівняння дорівнює `cos(k·a)`, для дійсних значень хвильового вектора `k` вона обмежена інтервалом:

```
-1 ≤ cos(k·a) ≤ 1
```

Звідси випливає фундаментальна математична умова існування стаціонарних блохівських хвиль, які розповсюджуються кристалом без згасання: **дійсні розв'язки існують тоді й лише тоді, коли значення характеристичної функції задовольняють нерівність**:

```
-1 ≤ F(α·a) ≤ 1
```

Графічний аналіз функції `F(y)` виявляє наступні фізико-математичні властивості:

1. **Дозволені зони (Allowed Bands)**: інтервали значень `y = α·a` (і відповідно енергій `E = ħ²y² / (2ma²)`), для яких `|F(y)| ≤ 1`. Всередині цих інтервалів кожному значенню `E` відповідає дійсне значення квазіімпульсу `k`, яке обчислюється як:
   ```
   k(E) = (1/a) · arccos[ F(α·a) ]
   ```
2. **Заборонені зони (Forbidden Gaps / Bandgaps)**: інтервали, де `|F(y)| > 1`. У цих областях дійсних розв'язків для `k` не існує. 

Для малих значень `y` перший доданок `P·sin(y)/y` збільшує амплітуду коливань `F(y)` за межі `±1`. Це призводить до утворення широких заборонених зон при низьких енергіях. Зі зростанням енергії (`y → ∞`) амплітуда згасає як `1/y`, і ширини заборонених зон монотонно зменшуються.

## Дисперсія для станів над потенціальним бар'єром (E > V₀)

Що відбувається з електронними хвилями при енергіях, що перевищують висоту потенціального бар'єра (`E > V₀`)?

У класичній фізиці частинка з енергією `E > V₀` просто безперешкодно проходить над бар'єром. Проте у квантовій фізиці навіть над бар'єром відбувається хвильове відбиття.

Для області `E > V₀` параметр `β` стає уявним:

```
β = i · γ,   де γ = √[2m(E - V₀)] / ħ
```

Застосовуючи тригонометричні співвідношення `cosh(i·γ·b) = cos(γ·b)` та `sinh(i·γ·b) = i·sin(γ·b)`, початкове дисперсійне співвідношення трансформується у вираз з чисто тригонометричними функціями:

```
cos(k·d) = cos(α·a) · cos(γ·b) - [(α² + γ²) / (2·α·γ)] · sin(α·a) · sin(γ·b)
```

Математичний аналіз цього рівняння показує, що коефіцієнт `(α² + γ²)/(2·α·γ)` завжди більший або дорівнює одиниці.

Через це амплітуда правої частини періодично перевищує одиницю за модулем і при енергіях `E > V₀`. Отже, **заборонені енергетичні зони продовжують існувати навіть над потенціальним бар'єром**. Вони виникають внаслідок надбар'єрного бреґґівського відбиття електронних хвиль від періодичного рельєфу потенціалу.

## Загасаючі блохівські хвилі всередині заборонених зон

Що відбувається з квантовим станом, якщо енергія електрона `E` потрапляє всередину забороненої зони, де `|F(α·a)| > 1`?

У цьому випадку рівняння `cos(k·a) = F(α·a)` не має дійсних розв'язків для `k`. Проте воно має комплексні розв'язки:

```
k = (n·π / a) + i·κ
```

де `n` — номер забороненої зони, а `κ` — уявна частина хвильового вектора.

Підставляючи комплексне `k` у косинус:

```
cos(k·a) = cos(n·π + i·κ·a) = (-1)ⁿ · cosh(κ·a)
```

Отже, величина згасання `κ` обчислюється з рівняння:

```
cosh(κ·a) = |F(α·a)|
```

Хвильова функція електрона всередині забороненої зони набуває вигляду **загасаючої (еванесцентної) блохівської хвилі**:

```
ψ(x) = u_k(x) · e^(i·n·π·x / a) · e^(-κ·x)
```

Фізичний зміст цього розв'язку полягає в тому, що електрон з енергією всередині забороненої зони не може вільно поширюватися кристалом. Якщо такий електрон падає на межу кристала ззовні, його хвильова функція експоненціально згасає углиб об'єму на глибині проникнення `δ = 1 / κ`.

Саме ці комплексні стани визначають фізику поверхневих станів Тамма — Шокли та тунелювання електронів через зонні щілини в напівпровідникових p-n переходах під дією сильних полів (зженерівське тунелювання).

## Аналітичний розрахунок амплітуди u_k(x) та її нормування

Для повного опису блохівського стану `ψ_k(x) = u_k(x) · e^(i·k·x)` розрахуємо явний вигляд періодичного огинаючого множника `u_k(x)`.

Зауважимо, що з граничних умов співвідношення коефіцієнтів `B/A` виражається через розв'язок трансцендентного рівняння:

```
B / A = - [ e^(i·α·a) - e^(i·k·a) ] / [ e^(-i·α·a) - e^(i·k·a) ]
```

Позначаючи це фазове відношення як `e^(2·i·δ_k)`, хвильова функція у потенціальній ямі (`0 < x < a`) набуває простого синусоїдального вигляду з фазовим зсувом `δ_k`:

```
ψ₁(x) = C_k · cos(α·x + δ_k)
```

Відповідно, періодичний амплітудний множник `u_k(x) = ψ_k(x) · e^(-i·k·x)` дорівнює:

```
u_k(x) = C_k · cos(α·x + δ_k) · e^(-i·k·x)    [0 < x < a]
```

Константа `C_k` визначається з умови нормування хвильової функції на один період ґратки:

```
∫₀ᵃ |u_k(x)|² dx = |C_k|² · ∫₀ᵃ cos²(α·x + δ_k) dx = 1
```

Обчислення інтеграла дає:

```
|C_k|² = 2 / [ a + (1/(2α)) · ( sin(2α·a + 2δ_k) - sin(2δ_k) ) ]
```

Це дає точний нормований вигляд хвильової функції Блоха, який використовується при обчисленні матричних елементів оптичних переходів та ймовірностей розсіяння електронів на фононах.

## Аналітичний розрахунок групової швидкості та ефективної маси

Трансцендентне рівняння `F(α·a) = cos(k·a)` дозволяє аналітично обчислити похідні дисперсійного спектра `E(k)`.

Продиференціюємо обидві частини рівняння за хвильовим вектором `k`:

```
d/dk [ F(α·a) ] = d/dk [ cos(k·a) ]
```

Застосовуючи правило диференціювання складеної функції:

```
F'(α·a) · a · (dα / dk) = -a · sin(k·a)
```

Оскільки `α = √[2mE] / ħ`, його похідна дорівнює:

```
dα / dE = m / (ħ² · α)   ⇒   dα / dk = (dα / dE) · (dE / dk) = [m / (ħ² · α)] · (dE / dk)
```

Підставляючи це значення, отримуємо аналітичний вираз для **групової швидкості електрона `v_g`**:

```
v_g = (1/ħ) · (dE / dk) = - [ħ · α · sin(k·a)] / [m · F'(α·a)]
```

де `F'(y) = dF/dy = P · [y·cos(y) - sin(y)] / y² - sin(y)`.

Повторне диференціювання за `k` дає точну аналітичну формулу для **тензора зворотної ефективної маси `1 / m*`**:

```
1 / m* = (1/ħ²) · (d²E / dk²) = [1 / m] · [ (α / F') · ( -cos(k·a) + (sin²(k·a) / sin(α·a)) · (F'' / F') ) ]
```

З цієї формули видно:
- Біля дна зони (`k → 0`), де `cos(k·a) ≈ 1`, ефективна маса `m* > 0` є додатною.
- На межі зони Бріллюена (`k → π/a`), де `sin(k·a) = 0` та `cos(k·a) = -1`, ефективна маса змінює знак:
  ```
  m*(π/a) = m · [ F'(α₀·a) / (α₀ · cos(k·a)) ] < 0
  ```
  що прямо підтверджує виникнення діркових станів з від'ємною ефективною масою біля верху дозволеної зони.

## Густина квантових станів та особливості Ван Хова в одновимірній ґратці

В одновимірній модельній ґратці Кроніґа — Пенні густина станів `D(E)` на одиницю довжини обчислюється як:

```
D_1D(E) = (1/π) · (dk / dE) = 1 / [ π · ħ · |v_g(E)| ]
```

Підставляючи раніше отриману формулу для групової швидкості `v_g`, маємо:

```
D_1D(E) = [m · |F'(α·a)|] / [π · ħ² · α · |sin(k·a)|]
```

Оскільки на межах кожної дозволеної зони (`k → 0` або `k → π/a`) групова швидкість спрямовується до нуля (`sin(k·a) → 0`), густина станів прямує до нескінченності за корінним законом:

```
D_1D(E) ∝ 1 / √|E - E_edge|
```

Ці математичні розриви густини станів при `E → E_edge` є класичним прикладом **особливостей Ван Хова** в одновимірних системах. Вузькі піки густини станів пояснюють унікальні оптичні та електронні властивості одновимірних наноструктур — вуглецевих нанотрубок та напівпровідникових квантових дротів.

## Зв'язок із методом сильного зв'язку (LCAO)

Паралельно з моделлю Кроніґа — Пенні, яка використовує хвилі вільного електрона як базис, існує протилежний математичний підхід — **метод сильного зв'язку (LCAO)**.

У цьому підході блохівська хвильова функція будується як лінійна комбінація атомних орбіталей `ϕ(r - R_n)` окремих вузлів:

```
ψ_k(r) = (1/√N) · ∑_n e^(i·k·R_n) · ϕ(r - R_n)
```

Обчислення матричних елементів гамільтоніана у наближенні взаємодії лише із найближчими сусідами для одновимірного ланцюжка з періодом `a` дає наступне аналітичне дисперсійне співвідношення:

```
E(k) = E₀ - C - 2·t · cos(k·a)
```

де `E₀` — енергія ізольованого атомного рівня, `C` — кулонівський інтеграл зміщення, а `t` — **інтеграл перескоку (перекриття)** між сусідніми атомами:

```
t = - ∫ ϕ*(x) · V_(atom)(x - a) · ϕ(x - a) dx
```

Звідси випливає, що ширина дозволеної зони в підході сильного зв'язку прямо дорівнює четверній величині інтеграла перескоку:

```
W = 4 · t
```

Зіставляючи результат сильного зв'язку `E(k) = E₀ - C - 2t·cos(ka)` з формулою Кроніґа — Пенні при великих значеннях потенційного бар'єра `P ≫ 1`, бачимо їхню повну математичну еквівалентність біля дна й верху зон. Інтеграл перескоку `t` у моделі Кроніґа — Пенні прямо пропорційний коефіцієнту тунельного проходження через прямокутний бар'єр `t ∝ e^(-β·b)`.

## Секулярне рівняння у моделі майже вільних електронів

Альтернативним математичним підходом до обчислення зонного спектра при слабкому періодичному потенціалі є метод теорії збурень у просторі оберненої ґратки.

Розкладемо періодичний потенціал `V(x)` та хвильову функцію електрона `ψ(x)` у ряди Фур'є за векторами оберненої ґратки `G = 2πn / a`:

```
V(x) = ∑_G V_G · e^(i·G·x)
ψ_k(x) = ∑_G C_(k-G) · e^(i·(k-G)·x)
```

Підставляючи ці розклади у стаціонарне рівняння Шредінгера, отримуємо нескінченну систему алгебраїчних рівнянь для Фур'є-коефіцієнтів `C_(k-G)`:

```
[ (ħ² / 2m)·(k - G)² - E ] · C_(k-G) + ∑_{G'} V_(G - G') · C_(k - G') = 0
```

Біля межі першої зони Бріллюена (`k ≈ π/a`) стан з `G = 0` та стан з `G = 2π/a` мають майже однакові кінетичні енергії:

```
E₀(k) = ħ²k² / (2m) ≈ E₀(k - G) = ħ²(k - G)² / (2m)
```

Усіма іншими Фур'є-компонентами можна знехтувати. Тоді нескінченна система спрощується до двох зв'язаних рівнянь (двоххвильове наближення):

```
[ E₀(k) - E ] · C_k + V_G · C_(k-G) = 0
V_(-G) · C_k + [ E₀(k-G) - E ] · C_(k-G) = 0
```

Прирівнюючи до нуля детермінант цієї матриці 2×2 (**секулярне рівняння**):

```
det | E₀(k) - E       V_G            | = 0
    | V_(-G)          E₀(k-G) - E    |
```

отримуємо квадратне рівняння відносно енергії `E`. Його точні розв'язки мають вигляд:

```
E_±(k) = (1/2) · [ E₀(k) + E₀(k-G) ] ± √[ (1/4) · (E₀(k) - E₀(k-G))² + |V_G|² ]
```

Безпосередньо на межі зони Бріллюена (`k = G/2 = π/a`), де `E₀(k) = E₀(k-G)`:

```
E_±(π/a) = E₀(π/a) ± |V_G|
```

Величина зонної щілини строго дорівнює подвоєному модулю Фурьє-компоненти потенціалу:

```
E_g = E₊ - E₋ = 2 · |V_G|
```

Цей елегантний вивід прямо підтверджує результат, отриманий з моделі Кроніґа — Пенні, і виявляє глибоку математичну єдність зонної теорії незалежно від обраного формалізму.

## Спін-орбітальний внесок у гамільтоніан ґратки

При точному квантоворелятивістському описі електрона до гамільтоніана кристалічної ґратки додається оператор спін-орбітальної взаємодії Паулі:

```
H_so = [ħ / (4 · m² · c²)] · (∇V × p) · σ
```

де `σ = (σ_x, σ_y, σ_z)` — вектори паулівських спінових матриць.

У тривимірній Кроніґ-Пенні або tight-binding моделі це призводить до додаткового розщеплення коефіцієнтів детермінанта на розширені матриці 8×8 для `p`-орбіталей. 

Зокрема, у центрі зони Бріллюена (`k = 0`) спін-орбітальний внесок знімає виродження валентної зони, розщеплюючи її на підзони важких і легких дірок та спін-орбітально відщеплену зону на величину `Δ_so`.

## Аналіз граничних випадків та ширина дозволених зон

Аналітична модель Кроніґа — Пенні дозволяє точно простежити граничні переходи до двох крайніх фізичних станів.

### 1. Вільний електрон (`P → 0`)
Якщо потенціал ґратки відсутній (`V₀ = 0`), параметр потужності `P = 0`. Дисперсійне рівняння спрощується до:

```
cos(α·a) = cos(k·a)   ⇒   α = k
```

Підставляючи вираз для `α = √[2mE]/ħ`, отримуємо звичайну суцільну параболу дисперсії вільного електрона без жодних заборонених зон:

```
E(k) = ħ² · k² / (2m)
```

### 2. Ізольовані атоми (`P → ∞`)
Якщо бар'єр стає нескінченно непроникним (`P → ∞`), амплітуда першого доданка `P·sin(α·a)/(α·a)` прямує до нескінченності. Рівняння має скінченні розв'язки лише тоді, коли синус дорівнює нулю:

```
sin(α·a) = 0   ⇒   α·a = n·π    (n = 1, 2, 3, ...)
```

Виражаючи енергію `E`, отримуємо дискретний спектр нескінченно глибокої потенціальної ями шириною `a`:

```
E_n = n² · π² · ħ² / (2 · m · a²)
```

У цьому граничному випадку ширини всіх дозволених зон вироджуються у неспряжені дискретні атомні рівні, а заборонені зони розширюються на весь міжрівневий простір, що відповідає повній локалізації електронів на окремих атомах.

### 3. Ширина зон при слабкому та сильному потенціалі
Для слабкого потенціалу (`P ≪ 1`) ширина забороненої зони біля першої межі `k = π/a` пропорційна параметр потужності `P`:

```
E_g ≈ 2 · P · [ħ² / (m·a²)] = 2 · V₀ · (b / a)
```

Для сильного потенціалу (`P ≫ 1`) ширина дозволеної зони `ΔE_n` біля `n`-го рівня є прямо пропорційною квадрату номера зони і обернено пропорційною потужності бар'єра `P`:

```
ΔE_n ≈ (2 · n² · π² · ħ²) / (m · a² · P)
```

Ця формула математично доводить, що вищі енергетичні зони (більше `n`) є значно ширшими за глибокі остовні зони (малі `n`), що повністю узгоджується з фізичною картиною розщеплення атомних рівнів.
