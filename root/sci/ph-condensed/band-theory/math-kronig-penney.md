# 🧮 Математична модель Кроніґа — Пенні та розв'язок рівняння Шредінгера

Рух електрона у кристалічній ґратці описується рівнянням Шредінгера з періодичним потенціалом `V(x + d) = V(x)`. Модель Кроніґа — Пенні (1931) є точно розв'язуваною одновимірною моделлю квантової теорії твердого тіла, яка аналітично пояснює утворення дозволених і заборонених енергетичних зон із перших принципів квантової механіки.

## Постановка одновимірної крайової задачі для періодичного потенціалу

Розглядається стаціонарний рух електрона маси `m` в одновимірному періодичному полі прямокутних потенціальних бар'єрів висоти `V₀` і ширини `b`, розділених ямами ширини `a`. Період ґратки дорівнює `d = a + b`.

Потенційна енергія `V(x)` у межах одного періоду `[-b, a]` задається кусково-сталою функцією:

```
V(x) = 0,     при  0 < x < a     [Область I: потенціальна яма]
V(x) = V₀,    при -b < x < 0     [Область II: потенціальний бар'єр]
```

Періодичність усього кристала задається умовою трансляційної інваріантності:

```
V(x + n·d) = V(x)      [n ∈ ℤ]
```

Стаціонарне одновимірне рівняння Шредінгера для стану з енергією `E` має вигляд:

```
-[ħ² / (2m)] · (d²ψ(x) / dx²) + V(x)·ψ(x) = E·ψ(x)
```

Розглянемо випадок підбар'єрного руху, коли енергія електрона менша за висоту потенційного бар'єра (`0 < E < V₀`).

Введемо два дійсні хвильові параметри:

1. Хвильове число вільного руху в потенціальній ямі (`0 < x < a`), де `V(x) = 0`:

```
α = √[2mE] / ħ
```

2. Коефіцієнт згасання під бар'єром (`-b < x < 0`), де `V(x) = V₀`:

```
β = √[2m(V₀ - E)] / ħ
```

Рівняння Шредінгера зводиться до двох лінійних диференціальних рівнянь другого порядку зі сталими коефіцієнтами:

```
Область I (0 < x < a):     d²ψ₁ / dx² + α²·ψ₁ = 0
Область II (-b < x < 0):   d²ψ₂ / dx² - β²·ψ₂ = 0
```

Характеристичні рівняння для цих областей:

```
Область I:   r² + α² = 0   ⇒   r = ±i·α
Область II:  r² - β² = 0   ⇒   r = ±β
```

Загальні розв'язки записуються у вигляді лінійних комбінацій базисних функцій:

```
ψ₁(x) = A · e^(i·α·x) + B · e^(-i·α·x)              [0 < x < a]
ψ₂(x) = C · e^(β·x) + D · e^(-β·x)                 [-b < x < 0]
```

Тут `A` і `B` — комплексна амплітуда хвилі, що біжить праворуч (`e^(iαx)`), та хвилі, що біжить ліворуч (`e^(-iαx)`), всередині потенціальної ями. Коефіцієнти `C` і `D` описують зростаючу (`e^(βx)`) та спадну (`e^(-βx)`) експоненціальні хвилі під бар'єром.

## Застосування теореми Блоха та формулювання системи граничних умов

Оскільки гамільтоніан системи `H = -[ħ²/(2m)]·(d²/dx²) + V(x)` комутує з оператором просторової трансляції `T_d` на період ґратки (`[H, T_d] = 0`), їхні власні функції збігаються.

Згідно з теоремою Блоха, стаціонарний стан у періодичному потенціалі описується блохівською хвилею з дійсним квазіімпульсом `p = ħk` (де `k` — блохівський хвильовий вектор у першій зоні Бріллюена `-π/d ≤ k ≤ π/d`):

```
ψ(x + d) = e^(i·k·d) · ψ(x)
ψ'(x + d) = e^(i·k·d) · ψ'(x)
```

Для хвильової функції у гільбертовому просторі `L²(ℝ)` оператор кінетичної енергії є самоспряженим тоді й лише тоді, коли функція `ψ(x)` та її перша похідна `ψ'(x)` є неперервними у кожній точці простору.

У межах розширеного періоду `[-b, a]` точки стику потенціалу відповідають `x = 0` та межі комірки `x = a` (яка через трансляцію зв'язана з `x = -b`).

Сформулюємо 4 граничні умови:

1. Неперервність хвильової функції при `x = 0`:

```
ψ₁(0) = ψ₂(0)
A + B = C + D
```

2. Неперервність першої похідної при `x = 0`:

```
ψ₁'(0) = ψ₂'(0)
i·α·(A - B) = β·(C - D)
```

3. Умова Блоха для значення функції на межі `x = a` та `x = -b`:

```
ψ₁(a) = e^(i·k·d) · ψ₂(-b)
A·e^(i·α·a) + B·e^(-i·α·a) = e^(i·k·d) · [C·e^(-β·b) + D·e^(β·b)]
```

4. Умова Блоха для першої похідної на межі `x = a` та `x = -b`:

```
ψ₁'(a) = e^(i·k·d) · ψ₂'(-b)
i·α·[A·e^(i·α·a) - B·e^(-i·α·a)] = e^(i·k·d) · β · [C·e^(-β·b) - D·e^(β·b)]
```

Перенесемо всі члени в ліву частину, отримавши однорідну систему лінійних алгебраїчних рівнянь відносно вектора невідомих амплітуд `X = (A, B, C, D)ᵀ`:

```
1) A + B - C - D = 0
2) i·α·A - i·α·B - β·C + β·D = 0
3) A·e^(i·α·a) + B·e^(-i·α·a) - C·e^(i·k·d - β·b) - D·e^(i·k·d + β·b) = 0
4) i·α·A·e^(i·α·a) - i·α·B·e^(-i·α·a) - β·C·e^(i·k·d - β·b) + β·D·e^(i·k·d + β·b) = 0
```

Матрична форма системи має вигляд `M · X = 0`:

```
[ 1                 1                -1                    -1                 ] [A]   [0]
[ i·α               -i·α             -β                    β                  ] [B]   [0]
[ e^(i·α·a)         e^(-i·α·a)       -e^(i·k·d - β·b)      -e^(i·k·d + β·b)   ] [C] = [0]
[ i·α·e^(i·α·a)     -i·α·e^(-i·α·a)  -β·e^(i·k·d - β·b)     β·e^(i·k·d + β·b)  ] [D]   [0]
```

## Точний алгебраїчний розрахунок детермінанта та дисперсійне рівняння

Однорідна система рівнянь має ненульовий розв'язок тоді й лише тоді, коли детермінант матриці `M(α, β, k)` тотожно дорівнює нулю:

```
det M(α, β, k) = 0
```

### Метод виключення змінних та зведення до матриці 2×2

Виразимо коефіцієнти `C` та `D` підбар'єрної області через амплітуди `A` та `B` з перших двох рівнянь системи.

Додамо та віднімемо рівняння 1 і 2:

```
C + D = A + B
C - D = (i·α / β) · (A - B)
```

Звідси знаходимо явні вирази для `C` та `D`:

```
C = (1/2) · [ (1 + i·α/β)·A + (1 - i·α/β)·B ]
D = (1/2) · [ (1 - i·α/β)·A + (1 + i·α/β)·B ]
```

Підставимо ці вирази у третє та четверте рівняння системи.

Розглянемо праві частини третього і четвертого рівнянь:

```
R₃ = e^(i·k·d) · [ C·e^(-β·b) + D·e^(β·b) ]
R₄ = e^(i·k·d) · (β / (i·α)) · [ C·e^(-β·b) - D·e^(β·b) ]
```

Обчислимо лінійні комбінації експонент `e^(-βb)` та `e^(βb)`:

```
C·e^(-β·b) + D·e^(β·b)
= (A/2)·[ (1 + i·α/β)·e^(-β·b) + (1 - i·α/β)·e^(β·b) ] + (B/2)·[ (1 - i·α/β)·e^(-β·b) + (1 + i·α/β)·e^(β·b) ]    [підстановка виразів для C та D]
= A·[ cosh(β·b) - (i·α/β)·sinh(β·b) ] + B·[ cosh(β·b) + (i·α/β)·sinh(β·b) ]                                     [використання формул Ейлера для cosh та sinh]
```

Аналогічно для різниці коефіцієнтів у четвертому рівнянні:

```
C·e^(-β·b) - D·e^(β·b)
= (A/2)·[ (1 + i·α/β)·e^(-β·b) - (1 - i·α/β)·e^(β·b) ] + (B/2)·[ (1 - i·α/β)·e^(-β·b) + (1 + i·α/β)·e^(β·b) ]    [підстановка C та D]
= A·[ -sinh(β·b) - (i·α/β)·cosh(β·b) ] + B·[ -sinh(β·b) + (i·α/β)·cosh(β·b) ]                                     [зведення до гіперболічних функцій]
```

Підставляючи ці вирази, зводимо систему 4×4 до однорідної системи 2×2 відносно вектора `(A, B)ᵀ`:

```
[ M₁₁   M₁₂ ] [A] = [0]
[ M₂₁   M₂₂ ] [B]   [0]
```

де елементи матриці мають вигляд:

```
M₁₁ = e^(i·α·a) - e^(i·k·d)·[ cosh(β·b) - (i·α/β)·sinh(β·b) ]
M₁₂ = e^(-i·α·a) - e^(i·k·d)·[ cosh(β·b) + (i·α/β)·sinh(β·b) ]
M₂₁ = e^(i·α·a) - e^(i·k·d)·[ cosh(β·b) + (i·β/α)·sinh(β·b) ]
M₂₂ = -e^(-i·α·a) + e^(i·k·d)·[ cosh(β·b) - (i·β/α)·sinh(β·b) ]
```

Прирівнюємо детермінант матриці 2×2 до нуля:

```
det M₂₂ = M₁₁·M₂₂ - M₁₂·M₂₁ = 0
```

Розкриємо добуток `M₁₁·M₂₂ - M₁₂·M₂₁` покроково:

```
M₁₁·M₂₂ - M₁₂·M₂₁
= { e^(i·α·a) - e^(i·k·d)·[cosh(β·b) - (i·α/β)·sinh(β·b)] } · { -e^(-i·α·a) + e^(i·k·d)·[cosh(β·b) - (i·β/α)·sinh(β·b)] }
  - { e^(-i·α·a) - e^(i·k·d)·[cosh(β·b) + (i·α/β)·sinh(β·b)] } · { e^(i·α·a) - e^(i·k·d)·[cosh(β·b) + (i·β/α)·sinh(β·b)] }
```

Перемножимо дужки у першому доданку:

```
-1 + e^(i·α·a + i·k·d)·[cosh(β·b) - (i·β/α)·sinh(β·b)] + e^(-i·α·a + i·k·d)·[cosh(β·b) - (i·α/β)·sinh(β·b)]
- e^(2·i·k·d)·[cosh(β·b) - (i·α/β)·sinh(β·b)]·[cosh(β·b) - (i·β/α)·sinh(β·b)]
```

Перемножимо дужки у другому доданку:

```
1 - e^(-i·α·a + i·k·d)·[cosh(β·b) + (i·β/α)·sinh(β·b)] - e^(i·α·a + i·k·d)·[cosh(β·b) + (i·α/β)·sinh(β·b)]
+ e^(2·i·k·d)·[cosh(β·b) + (i·α/β)·sinh(β·b)]·[cosh(β·b) + (i·β/α)·sinh(β·b)]
```

Віднімемо другий вираз від першого:

```
-2 + e^(i·k·d) · { e^(i·α·a)·[2·cosh(β·b) - i·(β/α - α/β)·sinh(β·b)] + e^(-i·α·a)·[2·cosh(β·b) + i·(β/α - α/β)·sinh(β·b)] }
- e^(2·i·k·d) · { [cosh²(β·b) - sinh²(β·b)] } · 2 = 0
```

Оскільки `cosh²(β·b) - sinh²(β·b) = 1`, коефіцієнт при `e^(2·i·k·d)` дорівнює `-2`.

Розділимо все рівняння на `-2·e^(i·k·d)`:

```
e^(-i·k·d) + e^(i·k·d)
= cosh(β·b)·[e^(i·α·a) + e^(-i·α·a)] - (i/2)·(β/α - α/β)·sinh(β·b)·[e^(i·α·a) - e^(-i·α·a)]
```

Застосовуючи формули Ейлера `e^(i·k·d) + e^(-i·k·d) = 2·cos(k·d)`, `e^(i·α·a) + e^(-i·α·a) = 2·cos(α·a)` та `e^(i·α·a) - e^(-i·α·a) = 2·i·sin(α·a)`:

```
2·cos(k·d) = 2·cos(α·a)·cosh(β·b) - (i/2)·[(β² - α²)/(α·β)]·sinh(β·b)·[2·i·sin(α·a)]
```

Оскільки `i · i = -1`, знак мінус змінюється на плюс:

```
cos(k·d) = cos(α·a)·cosh(β·b) + [(β² - α²) / (2·α·β)] · sin(α·a)·sinh(β·b)
```

Це фундаментальне **дисперсійне рівняння Кроніґа — Пенні** для енергетичних станів під бар'єром (`E < V₀`).

### Виведення через матрицю переносу (T-матрицю)

Той самий результат отримується через формалізм матриці переносу. Вектор стану `Ψ(x) = [ψ(x), ψ'(x)]ᵀ` на стиках перетворюється матрицями:

1. Матриця проходження через яму довжини `a`:

```
M_well = [ cos(α·a)          (1/α)·sin(α·a) ]
         [ -α·sin(α·a)       cos(α·a)       ]
```

2. Матриця проходження через бар'єр довжини `b`:

```
M_barrier = [ cosh(β·b)         (1/β)·sinh(β·b) ]
            [ β·sinh(β·b)       cosh(β·b)       ]
```

Повна матриця переносу на період `d`:

```
M_total = M_barrier · M_well
```

Оскільки рівняння Шредінгера не містить першої похідної, вронскіан зберігається, і `det(M_total) = det(M_barrier)·det(M_well) = 1·1 = 1`.

Згідно з теоремою Блоха, власні значення матриці `M_total` дорівнюють `λ = e^(±i·k·d)`. Характеристичне рівняння для унімодулярної матриці 2×2 має вигляд:

```
λ² - Tr(M_total)·λ + 1 = 0
```

Підставляючи `λ = e^(i·k·d)` і ділячи на `e^(i·k·d)`:

```
e^(i·k·d) + e^(-i·k·d) = Tr(M_total)
2·cos(k·d) = Tr(M_barrier · M_well)
```

Обчислення сліду матриці:

```
Tr(M_total) = M_total[1,1] + M_total[2,2]
= [ cosh(β·b)·cos(α·a) - (1/β)·sinh(β·b)·α·sin(α·a) ] + [ (β)·sinh(β·b)·(1/α)·sin(α·a) + cosh(β·b)·cos(α·a) ]    [сума діагональних елементів добутку матриць]
= 2·cosh(β·b)·cos(α·a) + [ β/α - α/β ]·sinh(β·b)·sin(α·a)                                                          [зведення подібних доданків]
= 2·[ cos(α·a)·cosh(β·b) + ((β² - α²)/(2·α·β))·sin(α·a)·sinh(β·b) ]                                               [винесення множника 2]
```

Ділення на 2 дає тотожний дисперсійний вираз.

## Граничний перехід до гребінки дельта-функцій Дірака

Для якісного та аналітичного аналізу зонної структури Кроніґ і Пенні запропонували границю, у якій бар'єри стають нескінченно вузькими (`b → 0`) та нескінченно високими (`V₀ → ∞`), тоді як їхня потужність (інтегральна площа бар'єра) залишається сталою:

```
lim_(b→0, V₀→∞) (V₀ · b) = const
```

У цій границі потенціал кристала стає періодичною гребінкою дельта-функцій Дірака:

```
V(x) = (ħ²·P / (m·a)) · ∑_(n=-∞)^(+∞) δ(x - n·a)
```

Розглянемо поведінку параметрів при `b → 0`:

- Період ґратки: `d = a + b → a`
- Оскільки `V₀ ≫ E`, коефіцієнт `β`:
```
β = √[2m(V₀ - E)] / ħ ≈ √[2mV₀] / ħ → ∞
```
- Безрозмірний добуток `β·b`:
```
β·b = (√[2mV₀] / ħ) · b = (√[2m / ħ²]) · √(V₀·b²) = (√[2m·V₀·b / ħ²]) · √b → 0    [при b → 0]
```

Розкладемо гіперболічні функції у ряди Тейлора за малим аргументом `β·b ≪ 1`:

```
cosh(β·b) = 1 + (β·b)²/2 + ... → 1
sinh(β·b) = β·b + (β·b)³/6 + ... → β·b
```

Оцінимо коефіцієнт перед синусом у дисперсійному рівнянні:

```
[(β² - α²) / (2·α·β)] · sinh(β·b)
≈ [β² / (2·α·β)] · (β·b)                      [оскільки β ≫ α]
= (β² · b) / (2·α)
= [2m·(V₀ - E) / ħ²] · b / (2·α)
≈ (2m·V₀·b / ħ²) / (2·α)
= (m·V₀·b / ħ²) · (1 / α)
```

Введемо безрозмірний параметр потужності потенціального бар'єра `P`:

```
P = lim_(b→0, V₀→∞) [ m · V₀ · a · b / ħ² ]
```

Тоді амплітудний множник набуває вигляду:

```
(m·V₀·b / ħ²) · (1 / α) = P / (α·a)
```

Підставляючи граничні значення `cosh(β·b) → 1`, `sinh(β·b)·(β²-α²)/(2αβ) → P·sin(αa)/(αa)` та `d → a` в точне рівняння, отримуємо класичне **рівняння Кроніґа — Пенні для дельта-бар'єрів**:

```
P · [sin(α·a) / (α·a)] + cos(α·a) = cos(k·a)
```

### Пряме виведення з дельта-потенціалу через стрибок похідної

Це ж рівняння можна отримати безпосередньо з рівняння Шредінгера з потенціалом `V(x) = (ħ²P/(ma))·δ(x)`.

Інтегруючи рівняння `-[ħ²/(2m)]·ψ'' + V(x)·ψ = E·ψ` по нескінченно малому околу `[-ε, +ε]` при `ε → 0`:

```
-[ħ² / (2m)] · [ ψ'(+0) - ψ'(-0) ] + (ħ²·P / (m·a)) · ψ(0) = 0
```

Звідси випливає умова стрибка першої похідної на дельта-бар'єрі:

```
ψ'(+0) - ψ'(-0) = (2·P / a) · ψ(0)
```

Усередині інтервалу `(0, a)` хвильова функція вільного електрона:

```
ψ(x) = A · e^(i·α·x) + B · e^(-i·α·x)
```

Застосовуючи теорему Блоха `ψ(-0) = e^(-i·k·a)·ψ(a - 0)` та `ψ'(-0) = e^(-i·k·a)·ψ'(a - 0)` разом із неперервністю `ψ(+0) = ψ(-0) = ψ(0)`, отримуємо аналогічну характеристичну систему, визначник якої безпосередньо дає `P·[sin(αa)/(αa)] + cos(αa) = cos(ka)`.

## Трансцендентний аналіз характеристичної функції та формування зонної структури

Позначимо ліву частину дисперсійного рівняння як характеристичну функцію Кроніґа — Пенні `F(y)`:

```
F(y) = P · [sin(y) / y] + cos(y)       [де y = α·a = √[2mE]·a / ħ]
```

Оскільки квазіімпульс `k` для стаціонарних делокалізованих станів є суто дійсним числом, права частина рівняння `cos(k·a)` жорстко обмежена фундаментальною тригонометричною нерівністю:

```
-1 ≤ cos(k·a) ≤ 1
```

Звідси випливає центральний критерій зонної теорії: **квантовий стан з енергією `E` може існувати у кристалі тоді й лише тоді, коли характеристична функція потрапляє в інтервал `[-1, 1]`**:

```
-1 ≤ F(y) ≤ 1      [Критерій дозволених енергетичних зон]
```

### Властивості функції F(y) та механізм утворення щілин

1. **Поведінка при нульовій енергії (`y → 0`)**:

```
lim_(y→0) F(y) = lim_(y→0) [ P · (sin(y)/y) + cos(y) ]
= P · 1 + 1 = 1 + P > 1      [оскільки P > 0]
```

Оскільки при `y = 0` значення `F(0) = 1 + P > 1`, найнижчий енергетичний стан кристала (`E = 0`) завжди лежить усередині забороненої зони. Перша дозволена зона починається лише при скінченному значенні енергії `y₁ > 0`, де крива `F(y)` вперше перетинає рівень `+1`.

2. **Огинаючі амплітудні криві**:
Функцію `F(y)` можна подати у фазовій формі:

```
F(y) = A(y) · cos(y - φ(y))
```

де амплітуда коливань дорівнює:

```
A(y) = √[ 1 + 2·P·(sin(y)·cos(y)/y) + P²·(sin²(y)/y²) ] ≤ √[ 1 + P²/y² ]
```

Оскільки `√[1 + P²/y²] > 1` для будь-якого скінченного `y`, екстремуми функції `F(y)` систематично виходять за межі коридору `[-1, +1]`.

3. **Точки дотику та межі зон Бріллюена**:
У точках `y = n·π` (де `n = 1, 2, 3, ...`):

```
sin(n·π) = 0
cos(n·π) = (-1)ⁿ
F(n·π) = P · [0 / (n·π)] + (-1)ⁿ = (-1)ⁿ
```

Це означає, що в точках `y = n·π` характеристична функція **завжди набуває значень `+1` або `-1`**, тобто точки `α·a = n·π` завжди є межами дозволених або заборонених зон:
- При парних `n = 2, 4, 6...`: `F(n·π) = +1 ⇒ cos(k·a) = +1 ⇒ k = 0` (центр зони Бріллюена, точка `Γ`).
- При непарних `n = 1, 3, 5...`: `F(n·π) = -1 ⇒ cos(k·a) = -1 ⇒ k = ±π/a` (межа зони Бріллюена, точка `X`).

4. **Структура дозволених і заборонених зон**:
- **Дозволена зона (Allowed Band)**: неперервний інтервал значень `y`, де `|F(y)| ≤ 1`. Кожному значенню `y` у цьому інтервалі відповідає дійсний хвильовий вектор:
```
k(E) = (1/a) · arccos[ F(√[2mE]·a / ħ) ]
```
- **Заборонена зона (Bandgap / Forbidden Gap)**: інтервал енергій, де `|F(y)| > 1`. Рівняння не має дійсних розв'язків для `k`, і стаціонарні хвилі, що біжать, у кристалі поширюватися не можуть.

5. **Звуження щілин при високих енергіях**:
Зі зростанням енергії (`y = α·a → ∞`) перший доданок згасає:

```
P · [sin(y) / y] ∝ 1/y → 0
```

Тому при `y ≫ P` характеристична функція прямує до чистого косинуса `F(y) → cos(y)`. Ширини заборонених зон асимптотично зменшуються до нуля, а дозволені зони розширюються, наближаючись до неперервного спектра вільного електрона.

## Енергетичний спектр для надбар'єрних станів (E > V₀)

Коли енергія електрона перевищує висоту потенційного бар'єра (`E > V₀`), рух електрона над бар'єром стає класично дозволеним. Проте у квантовій механіці стрибок потенціалу викликає хвильове відбиття навіть при `E > V₀`.

У надбар'єрній області кінетична енергія під бар'єром додатна: `E - V₀ > 0`. Хвильове число стає дійсним:

```
γ = √[2m(E - V₀)] / ħ
```

Формальний перехід від підбар'єрного до надбар'єрного випадку здійснюється аналітичним продовженням параметра `β`:

```
β = -i · γ
```

Використовуючи тотожності між гіперболічними та тригонометричними функціями комплексного аргументу:

```
cosh(β·b) = cosh(-i·γ·b) = cos(γ·b)
sinh(β·b) = sinh(-i·γ·b) = -i · sin(γ·b)
```

Перетворимо коефіцієнт перед синусом:

```
[(β² - α²) / (2·α·β)] · sinh(β·b)
= [(-γ² - α²) / (-2·i·α·γ)] · [-i · sin(γ·b)]
= - [(α² + γ²) / (2·α·γ)] · sin(γ·b)
```

Підставляючи у загальне дисперсійне співвідношення, отримуємо **рівняння для надбар'єрних станів (`E > V₀`)**:

```
cos(k·d) = cos(α·a)·cos(γ·b) - [(α² + γ²) / (2·α·γ)] · sin(α·a)·sin(γ·b)
```

### Доведення збереження заборонених зон при E > V₀

Дослідимо коефіцієнт `K_(ab) = (α² + γ²) / (2·α·γ)`. Розглянемо різницю:

```
(α² + γ²) / (2·α·γ) - 1
= (α² + γ² - 2·α·γ) / (2·α·γ)    [зведення дробів до спільного знаменника]
= (α - γ)² / (2·α·γ) ≥ 0         [виділення повного квадрата у чисельнику: (α-γ)² ≥ 0]
```

Оскільки `α > 0` та `γ > 0`, а квадрат дійсної різниці `(α - γ)² ≥ 0`, маємо строгу нерівність:

```
(α² + γ²) / (2·α·γ) ≥ 1
```

Рівність одиниці досягається лише тоді, коли `α = γ`, тобто `V₀ = 0` (повна відсутність потенційного бар'єра). Для будь-якого `V₀ > 0` коефіцієнт строго більший за 1.

Через це амплітуда коливань правої частини перевищує одиницю за модулем скрізь, де добуток `sin(α·a)·sin(γ·b) ≠ 0`.

Отже, **заборонені енергетичні зони продовжують існувати й при енергіях `E > V₀`**. Їхнє фізичне походження полягає у бреґґівській квантовій інтерференції хвиль, відбитих від періодичних стрибків потенціалу (надбар'єрне бреґґівське відбиття).

Заборонені зони зникають лише в точках квантового резонансу Рамзауера — Таунсенда, коли на ширині бар'єра вкладається ціле число напівхвиль:

```
γ·b = n·π   ⇒   sin(γ·b) = 0   ⇒   cos(k·d) = cos(α·a)·cos(n·π) = ±cos(α·a)
```

У цих резонансних точках бар'єр стає повністю прозорим для електронної хвилі, і коефіцієнт проходження дорівнює одиниці.

## Комплексна зонна структура та загасаючі (еванесцентні) блохівські хвилі

Що відбувається з квантовим станом, якщо енергія `E` потрапляє всередину забороненої зони, де `|F(α·a)| > 1`?

У цьому випадку дисперсійне рівняння не має розв'язків із суто дійсним квазіімпульсом `k`. Розв'язок існує у просторі комплексного хвильового вектора:

```
k = k_r + i · κ       [де k_r, κ ∈ ℝ, κ > 0]
```

Підставимо комплексне `k` у косинус:

```
cos(k·d) = cos((k_r + i·κ)·d)
= cos(k_r·d)·cosh(κ·d) - i · sin(k_r·d)·sinh(κ·d)
```

Оскільки ліва частина дисперсійного рівняння `F(α·a)` є суто дійсною функцією, уявна частина правої частини повинна дорівнювати нулю:

```
sin(k_r·d) · sinh(κ·d) = 0
```

Оскільки всередині забороненої зони коефіцієнт згасання `κ ≠ 0`, маємо `sinh(κ·d) ≠ 0`. Отже, повинна виконуватися умова:

```
sin(k_r·d) = 0   ⇒   k_r·d = n·π   ⇒   k_r = n·π / d      [n ∈ ℤ]
```

Це доводить фундаментальну теорему: **всередині `n`-ї забороненої зони дійсна частина квазіімпульсу фіксована на межі зони Бріллюена (`k_r = n·π/d`), а змінюється лише уявна частина `κ`**.

Підставляючи `k_r·d = n·π` у вираз для дійсної частини:

```
cos(n·π) · cosh(κ·d) = (-1)ⁿ · cosh(κ·d) = F(α·a)
```

Оскільки `cosh(κ·d) ≥ 1`, знак `(-1)ⁿ` точно збігається зі знаком `F(α·a)` у даній забороненій зоні:

```
cosh(κ·d) = |F(α·a)|
```

Звідси коефіцієнт просторового згасання `κ(E)` виражається явно:

```
κ(E) = (1/d) · arccosh[ |F(α·a)| ] = (1/d) · ln[ |F| + √(|F|² - 1) ]
```

Хвильова функція електрона із забороненою енергією набуває вигляду **еванесцентної (загасаючої) блохівської хвилі**:

```
ψ(x) = u_k(x) · e^(i · (n·π/d) · x) · e^(-κ·x)
```

### Фізичний зміст еванесцентних станів

1. **Глибина проникнення**: якщо на поверхню кристала падає електрон з енергією із забороненої зони, його густина ймовірності `|ψ(x)|² ∝ e^(-2κx)` спадає експоненціально на характерній довжині `δ = 1 / (2κ)`.
2. **Комплексні петлі (Complex Band Loops)**: залежність `E(κ)` утворює замкнені комплексні петлі в комплексному просторі `k`, що плавно з'єднують вершину нижньої дозволеної зони з дном наступної дозволеної зони.
3. **Поверхневі стани Тамма та Шокли**: обрив періодичного потенціалу на поверхні кристала створює граничні умови, які зшивають спадні розв'язки всередині кристала (`e^(-κx)`) зі спадними розв'язками у вакуумі. Це породжує локалізовані поверхневі рівні, розташовані всередині забороненої зони.
4. **Зженерівське міжзонне тунелювання**: у сильному зовнішньому електричному полі електрон долає заборонену зону шляхом квантового тунелювання крізь еванесцентні стани комплексної зони.

## Точний аналітичний вигляд блохівських хвильових функцій та їх нормування

Для повного квантового опису знайдемо явний аналітичний вигляд блохівської амплітуди `u_k(x) = ψ_k(x)·e^(-i·k·x)`.

З граничних умов на дельта-бар'єрі співвідношення амплітуд `A` і `B` у ямі `(0 < x < a)` визначається як:

```
A · [e^(i·α·a) - e^(i·k·a)] + B · [e^(-i·α·a) - e^(i·k·a)] = 0
```

Звідси фазове відношення коефіцієнтів дорівнює:

```
B / A = - [ e^(i·α·a) - e^(i·k·a) ] / [ e^(-i·α·a) - e^(i·k·a) ]
```

Помножимо чисельник і знаменник на `e^(-i·k·a/2)`:

```
B / A = - [ e^(i·α·a - i·k·a/2) - e^(i·k·a/2) ] / [ e^(-i·α·a - i·k·a/2) - e^(i·k·a/2) ]
```

Обчислимо квадрат модуля відношення `|B/A|²`:

```
|B/A|² = |e^(i·α·a) - e^(i·k·a)|² / |e^(-i·α·a) - e^(i·k·a)|²
= [ (cos(α·a) - cos(k·a))² + (sin(α·a) - sin(k·a))² ] / [ (cos(α·a) - cos(k·a))² + (-sin(α·a) - sin(k·a))² ]
= [ 2 - 2·cos(α·a - k·a) ] / [ 2 - 2·cos(α·a + k·a) ]
```

Оскільки `cos(k·a) = F(α·a)`, можна записати `B/A = e^(2·i·δ_k)`, де `δ_k` — дійсний фазовий зсув:

```
tan(δ_k) = - [ sin(α·a) - sin(k·a) ] / [ cos(α·a) - cos(k·a) ] = cot[ (α·a + k·a) / 2 ]
```

Тоді хвильова функція у ямі набуває форми дійсної стоячої хвилі з фазовим зсувом:

```
ψ₁(x) = C_k · [ e^(i·(α·x + δ_k)) + e^(-i·(α·x + δ_k)) ] = 2·C_k · cos(α·x + δ_k)
```

Нормувальний коефіцієнт `C_k` визначається з умови нормування хвильової функції на один період ґратки `a`:

```
∫₀ᵃ |ψ₁(x)|² dx = 4·|C_k|² · ∫₀ᵃ cos²(α·x + δ_k) dx = 1
```

Обчислимо інтеграл:

```
∫₀ᵃ cos²(α·x + δ_k) dx = ∫₀ᵃ [ 1/2 + (1/2)·cos(2·α·x + 2·δ_k) ] dx
= a/2 + [ sin(2·α·a + 2·δ_k) - sin(2·δ_k) ] / (4·α)
```

Звідси нормувальна константа дорівнює:

```
|C_k| = 1 / √[ 2·a + (1/α)·( sin(2·α·a + 2·δ_k) - sin(2·δ_k) ) ]
```

Блохівський періодичний фактор `u_k(x) = ψ₁(x)·e^(-i·k·x)` набуває вигляду:

```
u_k(x) = 2·C_k · cos(α·x + δ_k) · e^(-i·k·x)      [0 < x < a]
```

Цей розв'язок задовольняє умову періодичності `u_k(x + a) = u_k(x)` і є базисом для обчислення матричних елементів оптичного поглинання, дипольних переходів та ймовірностей електрон-фононного розсіяння.

## Аналітичне диференціювання дисперсії: групова швидкість та ефективна маса

Дисперсійне рівняння `F(α·a) = cos(k·a)` задає неявну залежність енергії електрона `E` від хвильового вектора `k`. Обчислимо першу та другу похідні дисперсійного закону за правилами диференціювання неявних функцій.

### Виведення групової швидкості

Продиференціюємо обидві частини рівняння за квазіімпульсом `k`:

```
d/dk [ F(α·a) ] = d/dk [ cos(k·a) ]
```

Застосовуючи ланцюгове правило:

```
F'(α·a) · a · (dα / dk) = -a · sin(k·a)
```

де похідна характеристичної функції `F'(y) = dF/dy`:

```
F'(y) = d/dy [ P·(sin(y)/y) + cos(y) ]
= P · [ y·cos(y) - sin(y) ] / y² - sin(y)
```

Звідси знаходимо похідну хвильового числа за хвильовим вектором:

```
dα / dk = - sin(k·a) / F'(α·a)
```

Оскільки енергія зв'язана з хвильовим числом як `E = ħ²·α² / (2m)`, знайдемо зв'язок між похідними:

```
dE / dα = ħ² · α / m
```

Застосовуючи формулу повної похідної `dE/dk = (dE/dα) · (dα/dk)`:

```
dE / dk = (ħ²·α / m) · [ - sin(k·a) / F'(α·a) ] = - [ ħ²·α·sin(k·a) ] / [ m·F'(α·a) ]
```

**Групова швидкість електрона `v_g(k)`** (швидкість руху хвильового пакета Блоха) дорівнює:

```
v_g(k) = (1/ħ) · (dE / dk) = - [ ħ·α · sin(k·a) ] / [ m · F'(α·a) ]
```

Аналіз формули групової швидкості:
- У центрі зони Бріллюена (`k = 0`): `sin(0) = 0 ⇒ v_g(0) = 0`.
- На межі зони Бріллюена (`k = ±π/a`): `sin(±π) = 0 ⇒ v_g(±π/a) = 0`.
- Обнулення групової швидкості на межах зон виникає внаслідок бреґґівського відбиття: падаюча і відбита хвилі мають однакові амплітуди, утворюючи чисту **стоячу хвилю**, яка не переносить енергію вздовж кристала.

### Виведення ефективної маси

Ефективна маса електрона `m*` описує динамічний відгук квазічастинки на зовнішню силу `F_ext` згідно з квантовим рівнянням руху `ħ·(dk/dt) = F_ext`:

```
a_accel = dv_g / dt = (1/ħ) · d/dt (dE/dk) = (1/ħ) · (d²E/dk²) · (dk/dt) = [ (1/ħ²)·(d²E/dk²) ] · F_ext
```

Звідси тензор зворотної ефективної маси визначається через другу похідну закону дисперсії:

```
1 / m*(k) = (1/ħ²) · (d²E / dk²)
```

Обчислимо другу похідну, диференціюючи вираз `dE/dk = - (ħ²·α/m)·[sin(ka)/F'(αa)]` за `k`:

```
d²E / dk² = d/dk [ - (ħ² / m) · (α · sin(k·a) / F'(α·a)) ]
= - (ħ² / m) · [ (dα/dk) · (sin(k·a) / F') + α · d/dk(sin(k·a) / F') ]
```

Розкриємо похідну дробу:

```
d/dk [ sin(k·a) / F'(α·a) ]
= [ a·cos(k·a)·F'(α·a) - sin(k·a)·F''(α·a)·a·(dα/dk) ] / [F'(α·a)]²
```

Підставляючи `dα/dk = - sin(ka) / F'(αa)`:

```
d²E / dk² = - (ħ² / m) · [ - sin²(k·a) / [F']² + (a·α·cos(k·a)) / F' + (a·α·sin²(k·a)·F'') / [F']³ ]
```

Звідси отримуємо точну аналітичну формулу **зворотної ефективної маси**:

```
1 / m*(k) = (1/m) · [ (sin²(k·a) / [F'(α·a)]²) - (a·α·cos(k·a) / F'(α·a)) - (a·α·sin²(k·a)·F''(α·a) / [F'(α·a)]³) ]
```

### Значення ефективної маси на межах зон

1. **Біля дна дозволеної зони (`k → 0`, `cos(ka) → 1`, `sin(ka) → 0`)**:

```
1 / m*(0) = - (a · α₀) / [ m · F'(α₀·a) ]
```

Оскільки на нижній межі зони похідна `F'(α₀·a) < 0` є від'ємною, ефективна маса є строго додатною:

```
m*(0) = m · [ |F'(α₀·a)| / (a·α₀) ] > 0
```

Електрон біля дна зони поводиться як звичайна позитивно інертна частинка, проте його маса відрізняється від маси вільного електрона через взаємодію з ґраткою.

2. **Біля верху дозволеної зони (`k → π/a`, `cos(ka) → -1`, `sin(ka) → 0`)**:

```
1 / m*(π/a) = (a · α₁) / [ m · F'(α₁·a) ]
```

Оскільки на верхній межі зони похідна `F'(α₁·a) > 0` є додатною, значення `1/m* < 0` є від'ємним:

```
m*(π/a) = - m · [ F'(α₁·a) / (a·α₁) ] < 0
```

**Від'ємна ефективна маса** означає, що під дією зовнішньої сили електрон біля верху зони прискорюється у напрямку, протилежному силі. Це відбувається тому, що бреґґівське відбиття від ґратки створює реакцію кристала, яка перевищує зовнішню дію. У фізиці твердого тіла такі стани описуються як квазічастинки з додатним зарядом — **дірки**.

## Густина квантових станів та особливості Ван Хова в одновимірній системі

Густина станів `D(E)` визначає кількість квантових рівнів на одиничний енергетичний інтервал `dE` в одиниці об'єму (або довжини в 1D) кристала.

В одновимірному кристалі довжини `L` з циклічними граничними умовами Борна — фон Кармана дозволені значення квазіімпульсу дискретизовані з кроком `Δk = 2π / L`. Кількість просторових станів в інтервалі `dk`:

```
dN = (L / 2π) · dk
```

Враховуючи двократне спінове виродження (`s_z = ±1/2`), густина станів на одиницю довжини дорівнює:

```
D_1D(E) = (2 / L) · (dN / dE) = (2 / L) · (L / 2π) · |dk / dE| = (1 / π) · |dk / dE|
```

Оскільки групова швидкість `v_g = (1/ħ)·(dE/dk)`:

```
D_1D(E) = 1 / [ π · ħ · |v_g(E)| ]
```

Підставляючи раніше отриманий аналітичний вираз для `v_g(E)`:

```
D_1D(E) = [ m · |F'(α·a)| ] / [ π · ħ² · α · |sin(k·a)| ]
```

Виразимо `sin(k·a)` через характеристичну функцію `F(α·a)`:

```
sin(k·a) = √[ 1 - cos²(k·a) ] = √[ 1 - F²(α·a) ]
```

Отримуємо замкнену формулу густини станів у моделі Кроніґа — Пенні:

```
D_1D(E) = [ m · |F'(α·a)| ] / [ π · ħ² · α · √[ 1 - F²(α·a) ] ]
```

### Поведінка біля меж зон та сингулярності Ван Хова

Біля краю зони (`E → E_edge`), де `F(α·a) → ±1`, знаменник виразу прямує до нуля. Розкладемо `F(α·a)` у ряд Тейлора біля точки краю `E₀`:

```
F(E) ≈ ±1 + F'_E · (E - E₀)
1 - F²(E) ≈ 1 - [ 1 ± 2·F'_E·(E - E₀) ] ≈ 2·|F'_E|·|E - E₀|
```

Тоді густина станів набуває кореневої сингулярності:

```
D_1D(E) ≈ [ m · √|F'_E| ] / [ π · ħ² · α₀ · √(2·|E - E₀|) ] ∝ 1 / √|E - E_edge|
```

Ці розбіжності густини станів типу `(E - E_edge)^(-1/2)` є **особливостями Ван Хова (Van Hove singularities)** в одновимірних системах. На відміну від 3D кристалів, де `D_3D(E) ∝ √|E - E_edge|` прямує до нуля на межі зони, в 1D структурах (квантових дротах, вуглецевих нанотрубках) густина станів різко злітає до нескінченності.

Перевіримо повну ємність зони шляхом інтегрування густини станів:

```
N_states = ∫_(E_min)^(E_max) D_1D(E) dE = (1/π) · ∫₀^(π/a) 2 · dk = (2/π) · (π/a) = 2/a
```

Повний інтеграл густини станів по будь-якій ізольованій дозволеній зоні суворо дорівнює **`2/a` станів на одиницю довжини** (рівно 2 електрони на кожну елементарну комірку), що повністю узгоджується з принципом Паулі.

## Асимптотичний міст між моделлю Кроніґа — Пенні та методом сильного зв'язку (LCAO)

Зіставимо розв'язок Кроніґа — Пенні з протилежним теоретичним підходом — методом сильного зв'язку (Tight-Binding / LCAO), у якому зона розглядається як результат слабкого перекриття атомних орбіталей глибоких потенціальних ям.

У моделі Кроніґа — Пенні режим сильного зв'язку відповідає високим і слабопроникним бар'єрам:

```
P ≫ 1
```

При великих `P` дозволені зони є дуже вузькими і розташовані безпосередньо під атомними рівнями нескінченно глибокої ями:

```
α·a = n·π - ε_n(k)       [де n = 1, 2, 3, ... та ε_n ≪ 1]
```

Розкладемо тригонометричні функції характеристичного рівняння за малим параметром `ε_n`:

```
sin(α·a) = sin(n·π - ε_n) = (-1)^(n-1) · sin(ε_n) ≈ (-1)^(n-1) · ε_n
cos(α·a) = cos(n·π - ε_n) = (-1)ⁿ · cos(ε_n) ≈ (-1)ⁿ · (1 - ε_n²/2)
```

Підставимо ці розклади в рівняння `P·[sin(αa)/(αa)] + cos(αa) = cos(ka)`:

```
P · [ (-1)^(n-1) · ε_n / (n·π) ] + (-1)ⁿ = cos(k·a)
```

Помножимо обидві частини на `(-1)ⁿ`:

```
- P · [ ε_n / (n·π) ] + 1 = (-1)ⁿ · cos(k·a)
```

Звідси знаходимо явний вираз для корекції хвильового числа `ε_n(k)`:

```
ε_n(k) = (n·π / P) · [ 1 - (-1)ⁿ · cos(k·a) ]
```

Виразимо повну енергію стану `E_n(k) = ħ²·α² / (2m)`:

```
E_n(k) = [ ħ² / (2m·a²) ] · [ n·π - ε_n(k) ]²
≈ [ ħ²·n²·π² / (2m·a²) ] · [ 1 - (2·ε_n(k) / (n·π)) ]
= E_n^(0) · [ 1 - (2/P) · ( 1 - (-1)ⁿ · cos(k·a) ) ]
```

де `E_n^(0) = n²·π²·ħ² / (2m·a²)` — енергетичний рівень електрона в ізольованій нескінченній прямокутній ямі ширини `a`.

Перегрупуємо доданки:

```
E_n(k) = E_n^(0) · [ 1 - 2/P ] + (-1)ⁿ · [ (2 · E_n^(0)) / P ] · cos(k·a)
```

Порівняємо отриманий результат з класичною формулою методу сильного зв'язку для одновимірного атомного ланцюжка:

```
E_LCAO(k) = E₀ - 2·t · cos(k·a)
```

де `E₀` — центрована енергія рівня в кристалі, а `t` — резонансний інтеграл перескоку між сусідніми атомами.

Отримуємо строгу аналітичну відповідність:

```
1. Центр сформованої зони:
   E₀ = E_n^(0) · [ 1 - 2/P ]

2. Інтеграл перескоку (тунелювання):
   t_n = (-1)^(n-1) · [ E_n^(0) / P ] = (-1)^(n-1) · [ n²·π²·ħ² / (2m·a²·P) ]
```

Повна ширина дозволеної зони в обох моделях:

```
W_n = 4 · |t_n| = (2 · n²·π²·ħ²) / (m·a²·P)
```

Це доводить, що **модель Кроніґа — Пенні при великих значеннях `P ≫ 1` математично строго переходить у модель сильного зв'язку**. При цьому інтеграл перескоку `t` виникає природно як квантова амплітуда підбар'єрного тунелювання крізь дельта-бар'єр.

## Секулярне рівняння у моделі майже вільних електронів

Для слабкого потенціалу ґратки протилежним аналітичним підходом є теорія збурень у просторі оберненої ґратки (модель майже вільних електронів / Nearly Free Electron Model).

Розкладемо періодичний потенціал `V(x)` та хвильову функцію Блоха `ψ_k(x)` у ряди Фур'є за векторами оберненої ґратки `G = 2π·n / a`:

```
V(x) = ∑_G V_G · e^(i·G·x)
ψ_k(x) = ∑_G C_(k-G) · e^(i·(k-G)·x)
```

де Фур'є-компоненти потенціалу дорівнюють:

```
V_G = (1/a) · ∫₀ᵃ V(x) · e^(-i·G·x) dx
```

Підставляючи ці розклади у стаціонарне рівняння Шредінгера `-[ħ²/(2m)]·ψ'' + V·ψ = E·ψ`, дістаємо нескінченну систему лінійних алгебраїчних рівнянь для амплітуд `C_(k-G)`:

```
[ (ħ² / 2m)·(k - G)² - E ] · C_(k-G) + ∑_(G') V_(G - G') · C_(k - G') = 0
```

Позначимо кінетичну енергію вільного стану як `E₀(k - G) = ħ²·(k - G)² / (2m)`.

### Двохвильове наближення біля межі зони Бріллюена

Біля межі першої зони Бріллюена (`k ≈ π/a = G₁/2`, де `G₁ = 2π/a`) кінетичні енергії двох станів з векторами `G = 0` та `G = G₁` є майже виродженими:

```
E₀(k) = ħ²·k² / (2m) ≈ E₀(k - G₁) = ħ²·(k - 2π/a)² / (2m)
```

Внеском усіх інших розсіяних хвиль можна знехтувати як вищими порядками теорії збурень. Система спрощується до двох взаємозв'язаних рівнянь (двохвильове секулярне рівняння):

```
[ E₀(k) - E ] · C_k + V_(G₁) · C_(k-G₁) = 0
V_(-G₁) · C_k + [ E₀(k-G₁) - E ] · C_(k-G₁) = 0
```

Умова існування ненульових розв'язків — рівність нулю детермінанта секулярної матриці 2×2:

```
det | E₀(k) - E       V_(G₁)         | = 0
    | V_(-G₁)         E₀(k-G₁) - E   |
```

Оскільки потенціал `V(x)` є дійсним, `V_(-G) = V_G*`, отже `V_(G₁) · V_(-G₁) = |V_(G₁)|²`.

Розкриваємо визначник:

```
(E₀(k) - E) · (E₀(k-G₁) - E) - |V_(G₁)|² = 0
E² - [ E₀(k) + E₀(k-G₁) ]·E + E₀(k)·E₀(k-G₁) - |V_(G₁)|² = 0
```

Корені цього квадратного рівняння дають дві розщеплені гілки дисперсії:

```
E_±(k) = (1/2)·[ E₀(k) + E₀(k-G₁) ] ± √[ (1/4)·(E₀(k) - E₀(k-G₁))² + |V_(G₁)|² ]
```

Безпосередньо на межі зони Бріллюена (`k = π/a`), де `E₀(π/a) = E₀(-π/a)`:

```
E_±(π/a) = E₀(π/a) ± |V_(G₁)|
```

Ширина забороненої зони (зонної щілини `E_g`) на межі зони Бріллюена строго дорівнює:

```
E_g = E₊(π/a) - E₋(π/a) = 2 · |V_(G₁)|
```

### Обчислення V_G для дельта-гребінки Кроніґа — Пенні

Обчислимо Фур'є-коефіцієнт для дельта-потенціалу `V(x) = (ħ²P/(ma))·δ(x)`:

```
V_(G₁) = (1/a) · ∫₀ᵃ [ (ħ²·P / (m·a)) · δ(x) ] · e^(-i·(2π/a)·x) dx
= (1/a) · (ħ²·P / (m·a)) · 1
= (ħ²·P) / (m·a²)
```

Підставляючи це значення у формулу зонної щілини:

```
E_g = 2 · |V_(G₁)| = 2 · [ (ħ² · P) / (m · a²) ]
```

Це значення точно збігається з шириною забороненої зони, отриманою з точного рівняння Кроніґа — Пенні при малих `P ≪ 1`.

## Релятивістські поправки та спін-орбітальне розщеплення зон

Для точного опису зонної структури напівпровідникових матеріалів до нерелятивістського гамільтоніана додається оператор спін-орбітальної взаємодії Паулі:

```
H_so = [ ħ / (4 · m² · c²) ] · (∇V × p) · σ
```

де `σ = (σ_x, σ_y, σ_z)` — вектор матриць Паулі, а `p = -i·ħ·∇` — оператор імпульсу.

У періодичному потенціалі `V(r)` блохівські хвильові функції розширюються до двокомпонентних спінорів:

```
Ψ_(n,k)(r) = [ ψ_(n,k,↑)(r) ]
             [ ψ_(n,k,↓)(r) ]
```

Внаслідок одночасного збереження просторової інверсії `P` (`V(-r) = V(r)`) та часової реверсії `T`:

```
E(k, ↑) = E(-k, ↑)       [Інверсія простору P]
E(k, ↑) = E(-k, ↓)       [Інверсія часу T]
```

Звідси випливає рівність:

```
E(k, ↑) = E(k, ↓)        [Крамерсове виродження зон]
```

У центросиметричних кристалах кожен енергетичний рівень у кожній точці `k`-простору лишається двократно виродженим за спіном.

### Спін-орбітальне розщеплення у нецентросиметричних системах (Ефект Рашби)

Якщо просторова інверсія порушена (наприклад, на гетеропереході або під дією поверхневого електричного поля `E_z = -∂V/∂z`), виникає ефективний спін-орбітальний гамільтоніан Рашби:

```
H_Rashba = α_R · (σ_x · k_y - σ_y · k_x)
```

де `α_R` — константа спін-орбітального зв'язку Рашби.

Дисперсійний закон параболічної зони розщеплюється на дві спін-поляризовані гілки:

```
E_±(k) = (ħ²·k² / (2m*)) ± α_R · |k|
```

Спінове виродження повністю знімається скрізь, крім точки `k = 0`. Дві параболи зміщуються у `k`-просторі на величину `k_R = m*·α_R / ħ²`, що лежить в основі роботи спінтронного транзистора Датти — Даса.

## Ортогональний базис локалізованих функцій Ваньє та матричні елементи гамільтоніана

Блохівські функції `ψ_(n,k)(x) = u_(n,k)(x) · e^(i·k·x)` є делокалізованими хвилями, густина ймовірності яких `|ψ_(n,k)(x)|²` рівномірно розподілена по всьому нескінченному об'єму кристала. Для переходу до локального квантовохімічного опису та розрахунку міжатомних матричних елементів використовують ортонормований базис **функцій Ваньє** `w_n(x - R_m)`.

Функція Ваньє `n`-ї енергетичної зони, центрована на вузлі ґратки `R_m = m · a` (`m ∈ ℤ`), визначається як дискретне перетворення Фур'є блохівських функцій по першій зоні Бріллюена:

```
w_n(x - R_m) = (1 / √N) · ∑_k e^(-i · k · R_m) · ψ_(n,k)(x)
```

У неперервній границі макроскопічного кристала сума переходить в інтеграл:

```
w_n(x - R_m) = (a / 2π) · ∫_(-π/a)^(+π/a) e^(-i · k · R_m) · ψ_(n,k)(x) dk
```

Обернене перетворення виражає блохівську функцію як суперпозицію локалізованих орбіталей Ваньє з блохівськими фазовими множниками:

```
ψ_(n,k)(x) = (1 / √N) · ∑_m e^(i · k · R_m) · w_n(x - R_m)
```

### Ортогональність та просторова локалізація

Перевіримо ортонормованість функцій Ваньє на різних вузлах `R_m` та `R_l`:

```
∫_(-∞)^(+∞) w_n*(x - R_m) · w_n'(x - R_l) dx
= (1 / N) · ∑_k ∑_(k') e^(i · k · R_m - i · k' · R_l) · ∫_(-∞)^(+∞) ψ_(n,k)*(x) · ψ_(n',k')(x) dx    [підстановка розкладу Ваньє за блохівськими станами]
= (1 / N) · ∑_k ∑_(k') e^(i · k · R_m - i · k' · R_l) · δ_(nn') · δ_(kk')                            [ортонормованість блохівських хвильових функцій]
= δ_(nn') · (1 / N) · ∑_k e^(i · k · (R_m - R_l))                                                   [зняття підсумовування за k' через дельта-символ]
= δ_(nn') · δ_(ml)                                                                                   [умова повноти та ортогональності дискретних експонент]
```

Функції Ваньє утворюють строго ортонормований базис у гільбертовому просторі станів кристала. Для ізольованих енергетичних зон у діелектриках та напівпровідниках функції Ваньє експоненціально локалізовані біля своїх вузлів:

```
|w_n(x)| ∝ e^(-κ_w · |x|)      [при |x| → ∞]
```

де параметр згасання `κ_w` визначається шириною комплексної забороненої зони.

### Точний розрахунок матричних елементів гамільтоніана у базисі Ваньє

Обчислимо матричний елемент повного гамільтоніана кристала `H` між функціями Ваньє, центрованими на вузлах `R_m` та `R_l`:

```
H_(ml)^(n) = ⟨w_n(x - R_m)| H |w_n(x - R_l)⟩
= (1 / N) · ∑_k ∑_(k') e^(i · k · R_m - i · k' · R_l) · ⟨ψ_(n,k)| H |ψ_(n,k')⟩    [розклад функцій Ваньє за власними блохівськими функціями]
= (1 / N) · ∑_k ∑_(k') e^(i · k · R_m - i · k' · R_l) · E_n(k) · δ_(kk')          [дія гамільтоніана на власний стан: H|ψ_k⟩ = E_n(k)|ψ_k⟩]
= (1 / N) · ∑_k E_n(k) · e^(i · k · (R_m - R_l))                                  [підсумовування за k' з урахуванням дельта-символу]
```

Переходячи до інтегрування по першій зоні Бріллюена:

```
H_(ml)^(n) = (a / 2π) · ∫_(-π/a)^(+π/a) E_n(k) · e^(i · k · (m - l) · a) dk
```

Звідси отримуємо фізичний зміст матричних елементів:

1. **Діагональний матричний елемент (`m = l`)** — навузлова середня енергія зони:

```
ε_n = ⟨w_n(x)| H |w_n(x)⟩ = (a / 2π) · ∫_(-π/a)^(+π/a) E_n(k) dk = Ē_n
```

2. **Матричний елемент перескоку між найближчими сусідами (`|m - l| = 1`)**:

```
t_n = - ⟨w_n(x)| H |w_n(x ± a)⟩ = - (a / 2π) · ∫_(-π/a)^(+π/a) E_n(k) · cos(k·a) dk
```

3. **Матричний елемент перескоку через один вузол (`|m - l| = 2`)**:

```
t_n' = - ⟨w_n(x)| H |w_n(x ± 2a)⟩ = - (a / 2π) · ∫_(-π/a)^(+π/a) E_n(k) · cos(2·k·a) dk
```

Це доводить, що коефіцієнти Фур'є точного закону дисперсії Кроніґа — Пенні `E_n(k)` є точними інтегралами перекриття та перескоку у формалізмі ортогональних орбіталей Ваньє:

```
E_n(k) = ε_n - 2·t_n · cos(k·a) - 2·t_n' · cos(2·k·a) - ...
```

## Міжзонні оптичні переходи та комбінована густина станів (JDOS)

Квантові переходи електронів між валентною зоною `v` та зоною провідності `c` під дією змінного електромагнітного поля світлової хвилі `E(t) = E₀ · cos(ω·t)` визначаються оператором взаємодії:

```
H_int = - (e / m) · A · p
```

де `A` — векторний потенціал світлової хвилі, а `p = -i·ħ·(d/dx)` — квантовий оператор імпульсу.

### Матричний елемент оптичного дипольного переходу

Матричний елемент переходу між початковим станом `|v, k_v⟩` та кінцевим станом `|c, k_c⟩`:

```
M_(cv)(k_c, k_v) = ⟨ψ_(c,k_c)| p |ψ_(v,k_v)⟩
= ∫_(-∞)^(+∞) u_(c,k_c)*(x) · e^(-i·k_c·x) · [ -i·ħ · d/dx ( u_(v,k_v)(x) · e^(i·k_v·x) ) ] dx
```

Оскільки довжина хвилі оптичного фотона `λ_phot ≈ 500–1000 нм` на три порядки перевищує період ґратки `a ≈ 0.5 нм`, хвильовий вектор фотона `q_phot = 2π / λ_phot ≈ 0` є знехтовно малим. Закон збереження квазіімпульсу вимагає:

```
k_c = k_v + q_phot ≈ k_v ≡ k      [Прямі / вертикальні оптичні переходи]
```

Матричний елемент зводиться до інтеграла по елементарній комірці:

```
M_(cv)(k) = (1/a) · ∫₀ᵃ u_(c,k)*(x) · [ -i·ħ · (du_(v,k)/dx) + ħ·k · u_(v,k)(x) ] dx
```

Оскільки функції `u_(c,k)` та `u_(v,k)` належать різним ортогональним зонам при однаковому `k`, другий доданок обнуляється через ортогональність `∫ u_c* u_v dx = 0`. Лишається суто дипольний міжзонний матричний елемент:

```
P_(cv)(k) = - (i·ħ / a) · ∫₀ᵃ u_(c,k)*(x) · (du_(v,k) / dx) dx
```

### Комбінована густина станів (Joint Density of States)

Ймовірність поглинання фотона з енергією `ħω` згідно з золотим правилом Фермі пропорційна **комбінованій густині станів (Joint Density of States, JDOS)** `J_1D(ħω)`:

```
J_1D(ħω) = (2 / L) · ∑_k δ( E_c(k) - E_v(k) - ħω )
= (1 / π) · ∫ | d(E_c(k) - E_v(k)) / dk |^(-1) · δ(k - k₀) dk
= (1 / π) · 1 / | ħ · [ v_gc(k₀) - v_gv(k₀) ] |
```

де `k₀` — резонансний хвильовий вектор, для якого різниця енергій зон дорівнює енергії фотона:

```
E_c(k₀) - E_v(k₀) = ħω
```

Розглянемо оптичні переходи біля краю фундаментального поглинання (`k ≈ 0`):

```
E_c(k) ≈ E_c(0) + ħ²·k² / (2·m_e*)
E_v(k) ≈ E_v(0) - ħ²·k² / (2·m_h*)
```

Різниця енергій дорівнює:

```
E_c(k) - E_v(k) = E_g + (ħ²·k² / 2) · [ (1 / m_e*) + (1 / m_h*) ] = E_g + ħ²·k² / (2·μ*)
```

де `μ* = (m_e* · m_h*) / (m_e* + m_h*)` — **зведена ефективна маса** електронно-діркової пари.

Виразимо хвильовий вектор через різницю енергій:

```
k(ħω) = √[ 2·μ* · (ħω - E_g) ] / ħ
```

Похідна міжзонної енергії за квазіімпульсом:

```
d(E_c - E_v) / dk = ħ²·k / μ* = (ħ / μ*) · √[ 2·μ* · (ħω - E_g) ] = ħ · √[ 2·(ħω - E_g) / μ* ]
```

Підставляючи у вираз для JDOS, отримуємо:

```
J_1D(ħω) = (1 / π) · [ 1 / (d(E_c - E_v)/dk) ] = [ √μ* ] / [ π·ħ · √(2·(ħω - E_g)) ]
```

Коефіцієнт оптичного поглинання одновимірної квантової системи `α_opt(ω)` набуває вигляду:

```
α_opt(ω) = [ 4·π²·e² / (n_r · c · m² · ω) ] · |P_(cv)|² · J_1D(ħω) ∝ 1 / √[ ħω - E_g ]
```

Коренева сингулярність комбінованої густини станів на краю зони `ħω → E_g` зумовлює гігантський резонансний пік міжзонного оптичного поглинання в одновимірних квантових нанодротах та періодичних напівпровідникових надґратках.

## Вплив магнітного поля та калібрувальне рівняння Гарпера

Розглянемо рух електрона у двовимірній періодичній ґратці `(x, y)` з періодами `a` та `b` під дією перпендикулярного однорідного магнітного поля `B = (0, 0, B)`.

У симетричному калібруванні Ландау для векторного потенціалу `A = (0, B·x, 0)` гамільтоніан набуває вигляду:

```
H = (1 / (2m)) · [ p_x² + (p_y + e·B·x)² ] + V(x, y)
```

Згідно з методом калібрувальної підстановки Паєрлса (Peierls substitution), вплив магнітного поля на стрибки електрона між вузлами зводиться до появи координатно-залежної фази хвильової функції:

```
t_(m,n) → t · exp[ i · (e/ħ) · ∫_(R_m)^(R_n) A · dr ]
```

Для вузла з координатами `(m·a, n·a)` векторний потенціал вздовж напрямку `y` додає фазовий зсув `(e·B / ħ) · (m·a) · a = 2π · m · (Φ / Φ₀)`, де:
- `Φ = B · a²` — магнітний потік крізь одну елементарну комірку ґратки.
- `Φ₀ = h / e` — фундаментальний квант магнітного потоку.

Шукаючи хвильову функцію у формі блохівської хвилі вздовж осі `y`:

```
ψ(m, n) = ψ_m · e^(i · k_y · n · a)
```

отримуємо одновимірне різницеве **рівняння Гарпера (Harper equation)** для амплітуд `ψ_m`:

```
t_x · [ ψ_(m+1) + ψ_(m-1) ] + 2·t_y · cos( 2π · m · (Φ / Φ₀) - k_y·a ) · ψ_m = E · ψ_m
```

### Фрактальний спектр Гофштадтера

Структура розв'язків рівняння Гарпера кардинально залежить від безрозмірного відношення магнітного потоку до кванта потоку `α_mag = Φ / Φ₀`:

1. **Раціональне відношення `α_mag = p / q` (де `p, q` — взаємно прості цілі числа)**:
   Період магнітної трансляційної симетрії зростає до `q · a`. Кожна вихідна дозволена зона Кроніґа — Пенні розщеплюється на **рівно `q` магнітних підзон**, розділених `q - 1` магнітними щілинами.
2. **Ірраціональне відношення `α_mag ∉ ℚ`**:
   Періодичність потенціалу ґратки стає несумірною з магнітною довжиною `l_B = √(ħ / eB)`. Енергетичний спектр стає всюди розривним канторовим фракталом — знаменитим **«метеликом Гофштадтера» (Hofstadter butterfly)**.

## Покроковий числовий розрахунок напівпровідникової надґратки (Worked-приклад)

Для наочної демонстрації роботи аналітичних формул моделі Кроніґа — Пенні виконаємо повний числовий розрахунок параметрів зонної структури для модельної одновимірної квантової надґратки на основі арсеніду галію (GaAs).

### Параметри системи

- Період надґратки: `a = 0.5 нм = 5.0 × 10⁻¹⁰ м`
- Ефективна маса електрона: `m = 0.067 · m₀ = 0.067 · 9.109 × 10⁻³¹ кг = 6.103 × 10⁻³² кг`
- Безрозмірний параметр потужності бар'єра: `P = 3π / 2 ≈ 4.7124`
- Стала Планка: `ħ = 1.05457 × 10⁻³⁴ Дж·с`, `1 еВ = 1.60218 × 10⁻¹⁹ Дж`

### Крок 1. Розрахунок енергетичного масштабу системи

Обчислимо характерну енергію першого квантового рівня нескінченної ями `E_scale = ħ²·π² / (2·m·a²)`:

```
E_scale
= [ (1.05457 × 10⁻³⁴ Дж·с)² · π² ] / [ 2 · (6.103 × 10⁻³² кг) · (5.0 × 10⁻¹⁰ м)² ]    [підстановка числових параметрів ħ, m, a]
= [ 1.1121 × 10⁻⁶⁷ · 9.8696 ] / [ 3.0515 × 10⁻⁵⁰ ]                                     [обчислення чисельника та знаменника]
= 1.0976 × 10⁻⁶⁶ / 3.0515 × 10⁻⁵⁰                                                     [перемноження констант чисельника]
= 3.597 × 10⁻¹⁷ Дж                                                                    [ділення чисельника на знаменник у системі SI]
= 3.597 × 10⁻¹⁷ / 1.60218 × 10⁻¹⁹ еВ                                                  [переведення джоулів в електронвольти]
= 2.245 еВ                                                                            [остаточне числове значення масштабу енергії]
```

### Крок 2. Розрахунок меж першої дозволеної зони (n = 1)

Характеристичне рівняння: `F(y) = 4.7124 · [sin(y)/y] + cos(y) = cos(k·a)`.

1. **Нижня межа першої зони (`k = 0`, `cos(ka) = +1`)**:
Розв'язуємо трансцендентне рівняння `F(y) = 1`:

```
4.7124 · [sin(y) / y] + cos(y) = 1
```

Чисельний розв'язок методом ітерацій Ньютона дає корінь:

```
y₁^(min) ≈ 1.9564 рад
```

Енергія дна першої зони:

```
E₁^(min)
= E_scale · (y₁^(min) / π)²         [зв'язок енергії стану з безрозмірним хвильовим числом y]
= 2.245 еВ · (1.9564 / 3.14159)²    [підстановка числових значень масштабу та кореня]
= 2.245 еВ · (0.6227)²              [ділення на число π]
= 2.245 еВ · 0.3878                 [піднесення відношення до квадрата]
= 0.8706 еВ                         [обчислення енергії дна першої зони]
```

2. **Верхня межа першої зони (`k = π/a`, `cos(ka) = -1`)**:
У точці `y = π`: `sin(π) = 0`, `cos(π) = -1`, отже `F(π) = -1`.

```
y₁^(max) = π ≈ 3.14159 рад
E₁^(max) = E_scale · (π / π)² = 2.245 еВ
```

3. **Ширина першої дозволеної зони**:

```
W₁ = E₁^(max) - E₁^(min) = 2.245 еВ - 0.8706 еВ = 1.3744 еВ
```

### Крок 3. Розрахунок меж другої зони та ширини забороненої зони (n = 2)

1. **Нижня межа другої зони (`k = π/a`, `cos(ka) = -1`)**:
Розв'язуємо трансцендентне рівняння `F(y) = -1` для `y > π`:

```
4.7124 · [sin(y) / y] + cos(y) = -1
```

Чисельний розв'язок дає корінь:

```
y₂^(min) ≈ 4.1202 рад
```

Енергія дна другої зони:

```
E₂^(min)
= E_scale · (y₂^(min) / π)²         [зв'язок енергії стану з хвильовим параметром y]
= 2.245 еВ · (4.1202 / 3.14159)²    [підстановка масштабу та кореня другої зони]
= 2.245 еВ · (1.3115)²              [ділення на число π]
= 2.245 еВ · 1.7200                 [піднесення до квадрата]
= 3.8614 еВ                         [обчислення енергії дна другої зони]
```

2. **Ширина першої забороненої зони (зонної щілини `E_g1`)**:

```
E_g1 = E₂^(min) - E₁^(max) = 3.8614 еВ - 2.2450 еВ = 1.6164 еВ
```

### Крок 4. Розрахунок ефективних мас на межах зони

1. **Ефективна маса на дні першої зони (`k = 0`, `y = 1.9564`)**:

Обчислимо похідну `F'(y)`:

```
F'(1.9564)
= 4.7124 · [ 1.9564 · (-0.3741) - 0.9274 ] / (1.9564)² - 0.9274    [підстановка значень sin та cos у формулу похідної F'(y)]
= 4.7124 · [ -0.7319 - 0.9274 ] / 3.8275 - 0.9274                 [обчислення добутку y·cos(y) та квадрата y²]
= 4.7124 · [ -1.6593 ] / 3.8275 - 0.9274                          [додавання від'ємних доданків у чисельнику]
= -2.0430 - 0.9274                                                [ділення та множення першого доданка]
= -2.9704                                                         [остаточне значення похідної]
```

Ефективна маса на дні зони:

```
m*(0) = m · [ |F'(y₁^(min))| / y₁^(min) ]
= 0.067 · m₀ · [ 2.9704 / 1.9564 ]
= 0.067 · m₀ · 1.5183
= 0.1017 · m₀
```

Ефективна маса електрона на дні зони зросла на `51.8%` порівняно з масою в об'ємному GaAs через додаткову інерцію, зумовлену періодичним потенціалом надґратки.

2. **Ефективна маса на вершині першої зони (`k = π/a`, `y = π`)**:

Обчислимо похідну `F'(π)`:

```
F'(π) = 4.7124 · [ π · (-1) - 0 ] / π² - 0 = - 4.7124 / π = - 1.5000
```

Ефективна маса на межі зони:

```
m*(π/a) = m · [ F'(π) / (π · cos(π)) ] = m · [ -1.5000 / (π · (-1)) ] = - m · (1.5000 / 3.1416) = - 0.4775 · m
= - 0.4775 · (0.067 · m₀) = - 0.0320 · m₀
```

Ефективна маса набула від'ємного значення `m* = -0.032 m₀`, що кількісно підтверджує виникнення легких діркових станів на межі зони Бріллюена.

## Повний аналіз асимптотичних границь та еволюція енергетичного спектра

Аналітична розв'язуваність моделі Кроніґа — Пенні дозволяє точно простежити неперервну еволюцію енергетичного спектра між двома фундаментальними границями фізики.

### 1. Границя вільного електронного газу (`P → 0`)

Коли висота бар'єрів прямує до нуля (`V₀ → 0`), параметр потужності `P = 0`. Характеристичне рівняння спрощується:

```
cos(α·a) = cos(k·a)
```

Звідси маємо тотожність хвильових чисел:

```
α = ±k + (2π·n / a)
```

Виражаючи енергію `E = ħ²·α² / (2m)`:

```
E(k) = ħ² · (k + 2π·n/a)² / (2m)
```

У схемі приведеної зони це набір парабол, а в схемі розгорнутої зони — єдина суцільна парабола вільного електрона `E = ħ²·k² / (2m)`. Ширини всіх заборонених зон тотожно дорівнюють нулю (`E_g = 0`), а ефективна маса електрона скрізь дорівнює масі спокою `m* = m`.

### 2. Границя ізольованих атомних потенціальних ям (`P → ∞`)

Коли бар'єри стають абсолютно непроникними (`P → ∞`), ліва частина `P·[sin(αa)/(αa)] + cos(αa)` може набувати скінченних значень `[-1, 1]` лише за умови:

```
sin(α·a) = 0   ⇒   α·a = n·π    (n = 1, 2, 3, ...)
```

Підставляючи `α = √[2mE] / ħ`:

```
√[2mE] · a / ħ = n·π   ⇒   E_n = n² · π² · ħ² / (2 · m · a²)
```

Енергетичний спектр повністю вироджується у нескінченний набір незв'язаних дискретних рівнів квантової ями ширини `a`. Ширина дозволених зон колапсує до нуля (`W_n = 0`), групова швидкість скрізь обнуляється (`v_g = 0`), а ефективна маса прямує до нескінченності (`m* → ∞`), що описує повну просторову локалізацію електронів на окремих атомних вузлах.

### Порівняльна таблиця граничних режимів моделі Кроніґа — Пенні

| Характеристика | Вільний електрон (`P = 0`) | Слабкий потенціал (`P ≪ 1`) | Сильний потенціал (`P ≫ 1`) | Ізольовані атоми (`P → ∞`) |
|---|---|---|---|---|
| **Дисперсійне рівняння** | `cos(αa) = cos(ka)` | `P·(sin(αa)/αa) + cos(αa) = cos(ka)` | `E(k) = E₀ - 2t·cos(ka)` | `sin(αa) = 0` |
| **Енергетичний спектр** | Суцільний `E = ħ²k²/(2m)` | Зонний із вузькими щілинами | Зонний із вузькими дозволеними смугами | Дискретний `E_n = n²π²ħ²/(2ma²)` |
| **Ширина першої щілини `E_g1`** | `0` | `2·P·[ħ²/(m·a²)] = 2·V₀·(b/a)` | `E_n^(0) - W_n` | Весь міжрівневий простір |
| **Ширина дозволеної зони `W_n`** | `∞` | Співмірна з енергією зони | `W_n ≈ (2n²π²ħ²)/(ma²P)` | `0` (чистий рівень) |
| **Ефективна маса біля дна `m*`** | `m` | `m / (1 - 2P/π²)` | `m · [P / (2n²π²)] ≫ m` | `∞` (локалізація) |
| **Групова швидкість `v_g`** | `ħk / m` | Параболічна з обнуленням на межах | `(2t·a/ħ)·sin(ka)` | `0` |
| **Хвильова функція** | Плоска хвиля `e^(ikx)` | Модульована блохівська хвиля | Лінійна комбінація орбіталей (LCAO) | Стояча хвиля ями `sin(nπx/a)` |

Математична модель Кроніґа — Пенні дає єдиний послідовний формалізм, який неперервно пов'язує фізику вільних хвиль із фізикою локалізованих атомних станів, формуючи теоретичний фундамент сучасної зонної теорії кристалів.
