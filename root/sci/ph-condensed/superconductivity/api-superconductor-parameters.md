# 📋 Довідник параметрів надпровідних матеріалів

У довіднику зведено розширений фізичний, електромагнітний та термодинамічний аналіз параметрів надпровідних матеріалів: від елементарних металів I роду до технічних сплавів II роду, керамічних купратів, залізовмісних пніктидів та гідридних сполук під надвисоким тиском. Інженерне проектування надпровідних магнітних систем, кріогенних кабелів, високочастотних прискорювальних резонаторів, джозефсонівських квантових пристроїв та систем захисту від квенчу вимагає суворого врахування взаємозв'язку між мікроскопічними квантовими довжинами та макроскопічними межами стійкості.

---

### Фундаментальні фізичні параметри та їхній мікроскопічний зміст

Електродинамічна та термодинамічна поведінка будь-якого надпровідника у зовнішньому магнітному полі визначається трьома взаємопов'язаними масштабами: критичною температурою `T_c`, лондонівською глибиною проникнення `λ_L` та довжиною когерентності `ξ`.

#### Критична температура `T_c`, енергетична щілина `Δ` та режими зв'язку БКШ
Критична температура `T_c` визначає енергію теплового руху `k_B T_c`, при досягненні якої термодинамічні флуктуації розрубують куперівські пари. Згідно з мікроскопічною теорією Бардіна — Купера — Шріффера (БКШ), зв'язок між шириною надпровідної енергетичної щілини `Δ(0)` при абсолютному нулю та критичною температурою у слабкому електрон-фононному зв'язку описується універсальним безрозмірним співвідношенням:

```
2 · Δ(0) = 3.53 · k_B · T_c        [універсальне співвідношення слабкого зв'язку БКШ]
```

Для матеріалів із сильним електрон-фононним зв'язком (теорія Еліашберга), де фононні моди низькочастотні й ефективно пом'якшують ґратку (свинець `Pb`, ртуть `Hg` або інтерметалід `Nb_3Sn`), числове значення коефіцієнта зростає до `4.0–4.8`. У високотемпературних купратах із неконвенційним `d_{x²-y²}`-спарюванням максимальне значення щілини досягає `2Δ_max / (k_B · T_c) ≈ 5.0–8.0`.

Температурна залежність енергетичної щілини поблизу критичної точки `T_c` спадає за універсальним кореневим законом середнього поля:

```
Δ(T) ≈ 3.2 · k_B · T_c · √(1 - T / T_c)   [поведінка щілини поблизу T_c]
```

Термодинамічне критичне поле `B_c(0)` визначає питому густину енергії конденсації надпровідного стану `u_cond = B_c²(0) / (2 · μ_0) = (1/2) · N(E_F) · Δ²(0)`, де `N(E_F)` — густина електронних станів на рівні Фермі для обох напрямків спіну. Воно пов'язане з коефіцієнтом електронної теплоємності Зоммерфельда `γ` та критичною температурою співвідношенням:

```
B_c(0) = √(2 · μ_0 · γ / V_m) · T_c [зв'язок критичного поля з теплоємністю]
```

де `V_m` — молярний об'єм речовини, а `μ_0 = 4π × 10⁻⁷ Гн/м` — магнітна стала вакууму.

#### Екранування та лондонівська глибина проникнення `λ_L`
Глибина проникнення магнітного поля `λ_L` визначає просторовий масштаб, на якому експоненціально згасають зовнішнє магнітне поле та мейснерівські поверхневі струми. У мікроскопічній теорії значення `λ_L(0)` визначається ефективною масою носіїв `m*` та їхньою об'ємною концентрацією `n_s`:

```
λ_L(0) = √(m* / (μ_0 · n_s · q²))   [лондонівська глибина проникнення при T=0]
```

де `q = 2e` та `m* = 2m_e` — заряд та маса куперівської пари.

Зі зростанням температури концентрація надпровідних електронів зменшується за дворідинною моделлю Гортера — Казимира `n_s(T) = n_s(0) · [1 - (T / T_c)⁴]`, що викликає температурне розширення екрануючого шару `λ_L(T) = λ_L(0) / √(1 - (T / T_c)⁴)`. При наближенні `T → T_c` глибина проникнення прямує до нескінченності, і зовнішнє поле вільно проникає в увесь об'єм зразка.

#### Довжина когерентності `ξ` та нелокальна електродинаміка Піппарда
Довжина когерентності `ξ` вимірює просторовий розмір куперівської пари та характерну відстань, на якій макроскопічний параметр порядку `Ψ(r)` змінюється при переході через межу розділу нормальної та надпровідної фаз. У чистих надпровідниках (межа Піппарда, де довжина вільного пробігу електронів `l >> ξ_0`) внутрішня довжина когерентності визначається швидкістю Фермі `v_F` та енергетичною щілиною:

```
ξ_0 = 0.18 · (ħ · v_F / (k_B · T_c)) [довжина когерентності чистих металів]
```

У «брудних» надпровідниках (сплави, леговані матеріали, тонкі плівки), де довжина вільного пробігу електронів `l` через розсіювання на домішках стає меншою за `ξ_0` (`l << ξ_0`), ефективна довжина когерентності та глибина проникнення перенормуються за формулами Горькова:

```
ξ_dirty ≈ 0.855 · √(ξ_0 · l)         [довжина когерентності у брудній межі]
λ_dirty ≈ λ_L · √(ξ_0 / l)           [глибина проникнення у брудній межі]
```

Зменшення довжини пробігу `l` дозволяє інженерно трансформувати слабо-надпровідний метал I роду у високопольний технічний надпровідник II роду із гігантським верхнім критичним полем.

#### Безрозмірний параметр Гінзбурга — Ландау `κ` та критичні поля
Співвідношення двох характерних довжин `κ = λ / ξ` розділяє всі надпровідні матеріали за знаком міжфазної поверхневої енергії `σ_ns ≈ (μ_0 · H_c² / 2) · (ξ - λ)`:

```
κ = λ / ξ                          [параметр Гінзбурга — Ландау]
```

1. **Матеріали I роду (`κ < 1 / √2 ≈ 0.707`):** поверхнева енергія є додатною (`σ_ns > 0`). Фазова межа вимагає затрат енергії, тому проникнення магнітного поля у вигляді ниток енергетично заборонене. Зразок демонструє повний ефект Мейснера аж до єдиного термодинамічного поля `B_c(0)`.
2. **Матеріали II роду (`κ > 1 / √2 ≈ 0.707`):** поверхнева енергія є від'ємною (`σ_ns < 0`). Речовині термодинамічно вигідно подрібнювати структуру на вихори Абрикосова, кожен з яких несе квант магнітного потоку `Φ_0 = h / (2e) ≈ 2.0678 × 10⁻¹⁵ Вб`.

Для надпровідників II роду існують три фундаментальні критичні поля:
- **Нижнє критичне поле `B_c1`:** поле початку термодинамічного проникнення одиничних вихорів:
  ```
  B_c1(0) = (Φ_0 / (4π · λ²)) · (ln κ + 0.08)  [нижнє критичне поле]
  ```
- **Верхнє критичне поле `B_c2`:** поле, при якому нормальні осереддя вихорів радіусом `ξ` перекриваються, руйнуючи об'ємну надпровідність:
  ```
  B_c2(0) = Φ_0 / (2π · ξ²)                    [верхнє критичне поле]
  ```
- **Поверхневе критичне поле `B_c3` (ефект Сен-Жама — де Жена):** критичне поле зародження поверхневого надпровідного шару товщиною `~ ξ` у паралельному полі:
  ```
  B_c3(0) = 1.695 · B_c2(0)                    [поверхневе критичне поле]
  ```

#### Мікроструктура, центри піннінгу та стабілізація кабелів
1. **Сплав Nb-Ti (Nb-47wt%Ti / Nb-50wt%Ti):** пластичний сплав, який піддають багаторазовому холодному волочінню з проміжними термообробками при `380–420 °C` протягом `40–80 годин`. Це формує щільну мережу стрічкоподібних виділень немагнітної α-фази титану товщиною `3–5 нм` та періодом `10–15 нм`. Оскільки розмір виділень збігається з діаметром осереддя вихору `2ξ ≈ 10 нм`, об'ємна сила піннінгу досягає максимуму `F_p,max = j_c × B` при відносному полі `b = B / B_c2 ≈ 0.5`.
   Для захисту від термомагнітної нестійкості (стрибків потоку) сотні й тисячі волокон Nb-Ti діаметром `5–10 мкм` запресовують у матрицю з надчистої міді (співвідношення Cu:NbTi від 1:1 до 4:1) та скручують із кроком твістування `L_p = 10–25 мм`. Скручування жил розриває контури індукційних струмів між волокнами, кардинально знижуючи динамічні втрати на змінному струмі:
   ```
   P_c = (Ḃ² / ρ_eff) · (L_p / (2π))²   [питомі втрати зв'язку у багатожильному кабелі]
   ```
2. **Інтерметаліди серії A15 (`Nb_3Sn`, `V_3Ga`, `Nb_3Al`):** мають стехіометрію `A_3B` та кубічну ґратку типу `Cr_3Si` (група `Pm3̄n`), де атоми ніобію утворюють ортогональні лінійні ланцюжки. Основними центрами піннінгу у `Nb_3Sn` виступають межі зерен із розміром зерна `50–100 нм`.
   Сполуки A15 є надзвичайно крихкими й чутливими до тензора механічних деформацій `ε`. При поздовжній деформації розтягу чи поперечному стиску `ε > 0.4%` критичний струм знижується за універсальним законом Айкіна:
   ```
   I_c(ε) / I_c(0) = 1 - a · |ε_intrinsic|^1.7 [залежність струму Nb_3Sn від деформації]
   ```
   Кабелі виготовляють у вихідному пластичному стані за бронзовою технологією (*bronze process*) або методом внутрішнього олова (*internal tin*), де олово дифундує в ніобієві стрижні під час фінального реакційного відпалу готової обмотки при `650–700 °C` протягом `50–150 годин` (метод *Wind-and-React*).
3. **Диборид магнію (`MgB_2`):** перший відкритий двощілинний надпровідник (Джун Акіміцу, 2001 р.). Кристалічна ґратка складається з чергування гексагональних шарів бору та магнію. В електронному транспорті беруть участь дві незалежні зони:
   - Двовимірна ковалентна `σ`-зона зв'язків бор-бор: має сильну електрон-фононну взаємодію з оптичними модами ґратки `E_2g`, формуючи велику анізотропну щілину `Δ_σ(0) ≈ 7.1 меВ` (`2Δ_σ / k_B T_c ≈ 4.24`);
   - Тривимірна металева `π`-зона зв'язків: має слабкий міжзонний зв'язок та меншу енергетичну щілину `Δ_π(0) ≈ 2.3 меВ` (`2Δ_π / k_B T_c ≈ 1.37`).
   Легування порошків `MgB_2` наночастинками карбіду кремнію `SiC` або вуглецем `C` (до `5–10 ат.%`) скорочує довжину вільного пробігу електронів у `σ`-зоні, піднімаючи верхнє критичне поле `B_c2(0)` від вихідних `18 Тл` до понад `35 Тл`, а `B_c2(4.2 K)` — до `28 Тл`.

### Детальний розбір високотемпературних надпровідників (ВТНП / Cuprates & Hydrides)

Купратні ВТНП матеріали переступили межу кипіння рідкого азоту (`77.4 K` / `-195.75 °C`), а високотискові гідриди наблизилися до кімнатних температур.

#### Анізотропія та кристалічна структура купратів
Усі купратні ВТНП мають виражену шарувату перовськітоподібну кристалічну структуру, у якій надпровідність локалізована у двовимірних мідно-кисневих площинах `CuO_2`. Це зумовлює виражену анізотропію маси носіїв `m_c* >> m_ab*` та різницю квантових довжин: лондонівська глибина проникнення вздовж площин `λ_ab` у рази менша за глибину для струмів між площинами `λ_c`.

Коефіцієнт просторової анізотропії `γ = λ_c / λ_ab = ξ_ab / ξ_c = √(m_c* / m_ab*)` змінюється від помірного `5–7` для YBCO до екстремального `50–150` для родини BSCCO. Якщо довжина когерентності вздовж осі `c` (`ξ_c ≈ 0.1–0.3 нм`) менша за міжатомну відстань між мідно-кисневими блоками `d_layer ≈ 1.2–1.5 нм`, тривимірний вихор розпадається на стек слабо зв'язаних двовимірних точкових вихорів — «млинців» (вихорів Лоуренса — Доніаха / *pancake vortices*).

#### Фізика пніктидів та гідридів надвисокого тиску
1. **Залізовмісні пніктиди та халькогеніди (Fe-based):** відкриті у 2008 році (Хідео Хосоно). Спарювання має багатозонну симетрію `s_±`, де знак параметра порядку змінюється на протилежний між електронними кишенями в кутах та дірковими кишенями в центрі зони Бріллюена. Вони мають малу анізотропію (`γ ≈ 1.5–3` для родини `122`), високі критичні поля `B_c2(0) > 100–200 Тл` та чисті межі зерен, що робить їх головними конкурентами купратів для соленоїдів понад `30 Тл`.
2. **Гідридні клатрати надвисокого тиску (`H_3S`, `LaH_10`, `YH_9`):** спарювання підпорядковується конвенційній теорії БКШ — Еліашберга сильного електрон-фононного зв'язку (`λ_ep > 2.0`). Завдяки малій масі ядер водню характеристична дебаївська частота коливань ґратки досягає `ω_D / k_B ≈ 1500–2000 К`. Фази синтезуються в алмазних ковадлах (*DAC*) при тисках `150–200 Гігапаскалів` (`1.5–2.0 млн атм`). Квантова природа спарювання підтверджена гігантським ізотоп-ефектом при заміні водню на дейтерій (для `D_3S` температура `T_c` падає від `203 K` до `147 K`).

### Архітектура 2G HTS стрічок (REBCO): шари, критичні струми та інженерна густина

Високотемпературні надпровідники другого покоління (2G HTS / Coated Conductors) виготовляють у вигляді багатошарових гнучких металокерамічних стрічок. Оскільки разорієнтація кристалічних зерен купрату на кут понад `4–5°` експоненціально знижує міжзеренний критичний струм через утворення джозефсонівських меж, осадження вимагає створення штучної кристалографічної біаксіальної текстури.

```
[Захисний шар міді Cu (гальванічний або ламінований)]        20–50 мкм
[Омічний контактний шар срібла Ag (магнетронний)]            1–2 мкм
[Надпровідний шар REBCO (MOCVD / PLD)]                        1–3 мкм
[Текстурований буферний шар (LaMnO_3 / CeO_2 / IBAD-MgO)]    0.1–0.3 мкм
[Дифузійний бар'єр Al_2O_3 / Y_2O_3]                         0.05–0.1 мкм
[Міцна підкладка: немагнітний сплав Hastelloy C-276]         30–50 мкм
[Нижній шар мідного стабілізатора Cu]                        20–50 мкм
```

#### Пошарова функціональна структура
1. **Несуча підкладка (Hastelloy C-276):** нікелевий аустенітний сплав (товщина `30–50 мкм`), немагнітний, має високу границю плинності (`σ_y > 800 МПа`) та стійкість до розриву при вигинах.
2. **Буферний наностек (IBAD / RABiTS):**
   - Бар'єр `Al_2O_3` (`50 нм`): блокує термодифузію нікелю та хрому з підкладки;
   - Зародковий шар `Y_2O_3` (`20 нм`);
   - Біаксіально орієнтований шар оксиду магнію `IBAD-MgO` (`5–10 нм`): формується бомбардуванням похилим іонним пучком аргону під час осадження, створюючи монокристальну орієнтацію площин із розорієнтацією зерен `ΔΦ < 3–5°`;
   - Гомоепітаксійний `MgO` (`30 нм`) та узгоджувальний шар `LaMnO_3` або `CeO_2` (`30 нм`): передають параметр кристалічної ґратки купрату.
3. **Функціональний шар REBCO (`YBa_2Cu_3O_7-δ` або `GdBa_2Cu_3O_7-δ`):** товщина `1.0–3.0 мкм`, вирощується методом хімічного осадження з газової фази (MOCVD) або імпульсного лазерного осадження (PLD). Локальна густина струму досягає `J_c(77 K, 0 Т) = 3–5 × 10⁶ А/см²`.
4. **Пасивуючий шар срібла (Ag, `1–2 мкм`):** осаджується магнетронним напиленням безпосередньо після синтезу REBCO, забезпечуючи омічний перехід із наднизьким контактним опором `ρ_c < 10⁻⁸ Ом·см²`.
5. **Мідний стабілізатор (Cu, `20–100 мкм`):** електролітично нарощується навколо всієї стрічки для теплового шунтування та захисту провідника під час квенчу.

#### Критичний струм `I_c` проти інженерної густини струму `J_e`
В інженерних розрахунках розрізняють фізичну густину струму в надпровідній плівці `J_c` та повну інженерну густину по всьому перерізу багатошарового композиту `J_e`:

```
J_c = I_c / A_sc               [густина струму у надпровідному шарі]
J_e = I_c / A_total            [інженерна густина струму всього провідника]
```

Для стандартної 2G HTS стрічки шириною `w = 4 мм`, повною товщиною `t_tot = 100 мкм` (`A_total = 0.4 мм²`) та товщиною шару YBCO `t_sc = 1.5 мкм` (`A_sc = 0.006 мм²`), яка несе струм `I_c = 240 А` при `77 K` у власному полі:
- Густина струму в шарі надпровідника: `J_c = 240 / 0.006 = 40 000 А/мм² = 4.0 × 10⁶ А/см²`;
- Інженерна густина струму стрічки: `J_e = 240 / 0.4 = 600 А/мм² = 6.0 × 10⁴ А/см²`.

#### Штучні центри піннінгу (APC) та кутова залежність `J_c(B, θ)`
У купратах критичний струм залежить від кута `θ` між вектором магнітного поля `B` та кристалографічною віссю `c` (перпендикулярною до площини стрічки):
- **Поле `B ∥ ab` (`θ = 90°` до осі `c`):** вихори фіксуються природними діелектричними проміжками між площинами `CuO_2` (внутрішній піннінг), і `J_c` залишається максимальним;
- **Поле `B ∥ c` (`θ = 0°`):** вихори протинають надпровідні площини, і за відсутності штучних дефектів критичний струм швидко деградує.

Для придушення спаду `J_c(B ∥ c)` у матрицю REBCO вводять штучні центри піннінгу (*APC — Artificial Pinning Centers*): самоорганізовані наноколони з `BaZrO_3` (BZO) або `BaHfO_3` (BHO) діаметром `5–8 нм`, орієнтовані вздовж осі `c`. Наноколони перетинають площини `CuO_2` з періодом `15–20 нм`, підвищуючи критичний струм у сильних полях `B ∥ c` при `4.2 K` та `77 K` у `3–5 разів`.

### Електродинаміка надвисоких частот: Поверхневий опір SRF-резонаторів

Надпровідні високочастотні резонатори (SRF — *Superconducting Radio Frequency*) із надчистого ніобію є ключовими вузлами сучасних лінійних прискорювачів електронів, протонів та рентгенівських лазерів на вільних електронах (European XFEL, LCLS-II, CEBAF, SNS).

На відміну від постійного струму (`R_DC ≡ 0`), на надвисоких частотах надпровідник має скінченний активний поверхневий опір `R_s > 0`. Це зумовлено тим, що змінне електричне поле індукується всередині глибини проникнення `λ_L` і прискорює неспарені нормальні електрони, що породжує дисипацію енергії.

```
R_s(T, f) = R_BCS(T, f) + R_res       [повний поверхневий опір SRF-резонатора]
```

#### Теорія Маттіса — Бардіна та БКШ-опір
Внесок теплових квазічастинок описується теорією Маттіса — Бардіна. При `T < T_c / 2` опір `R_BCS` строго експоненціально спадає з охолодженням:

```
R_BCS(T, f) = A · (f² / T) · exp( - Δ(0) / (k_B · T) )
```

де `f` — резонансна частота поля, а `A` — коефіцієнт, що залежить від довжини вільного пробігу електронів та опору нормального стану.

Для ніобієвого резонатора на стандартній частоті `f = 1.3 ГГц`:
- При `T = 4.2 K`: `R_BCS ≈ 500 нОм` (`0.5 мкОм`);
- При охолодженні до `T = 2.0 K` (надплинний гелій He-II): `R_BCS` падає до `10–15 нОм`.

#### Залишковий опір `R_res` та інженерні механізми втрат
Залишковий поверхневий опір `R_res` не залежить від температури і визначається дефектами структури, домішками та локальним оточенням:
1. **Захоплений магнітний потік (Trapped Flux):** залишкове геомагнітне поле під час проходження фронту фазового переходу захоплюється у вигляді вихорів. Опір захопленого потоку становить `R_mag ≈ 0.3 · B_trap [нОм / мГс]`. Для досягнення `R_res < 2 нОм` резонатори захищають двошаровими екранами з пермалою, знижуючи зовнішнє поле до `B_trap < 5–10 мГс` (`0.5–1.0 мкТл`).
2. **Воднева хвороба ніобію (Q-disease):** при вмісті розчиненого водню понад `2 ppm` під час повільного охолодження в діапазоні `100–150 K` на поверхні випадають втратні ненадпровідні гідриди ніобію (`Nb_4H_3`). Ефект усувають високотемпературним вакуумним відпалом резонаторів при `800 °C` протягом `2–3 годин`.
3. **Оксидний субшар:** природний оксид `Nb_2O_5` товщиною `3–5 нм` містить дефектні напівпровідникові фази `NbO_2` та `NbO`, які підвищують діелектричні втрати.

#### Азотне легування (N-doping) та добротність
Безрозмірна добротність резонатора `Q_0` пов'язана з геометричним фактором форми комірки `G` (для типових 1.3 ГГц комірок типу TESLA `G ≈ 270 Ом`) виразом:

```
Q_0 = G / R_s                         [власна добротність SRF-резонатора]
```

При традиційній електрополіровці при `2.0 K` досягається опір `R_s ≈ 10 нОм` (`Q_0 ≈ 2.7 × 10¹⁰`). Застосування технології азотного легування (відпал при `800 °C` у середовищі азоту з парціальним тиском `25–30 мТорр` з наступною мікрополіровкою `5 мкм`) створює ефект анти-Q-спаду (*anti-Q-slope*), при якому опір зменшується зі зростанням прискорювального градієнта до `E_acc = 16–30 МВ/м`, досягаючи рекордних добротностей `Q_0 > 3.5 × 10¹⁰` при сумарному опорі `R_s < 6–7 нОм`.

### Хімічна деградація, квенч-динаміка та захисне шунтування

Експлуатаційна надійність надпровідних систем визначається стійкістю до деградації та ефективністю захисту від теплового квенчу (*quench*) — аварійного переходу в нормальний стан із виділенням запасеної магнітної енергії.

#### Механізми хімічної та механічної деградації купратів
1. **Чутливість до вологи та вуглекислого газу:** керамічні купрати YBCO реагують з парами води `H_2O` та вуглекислим газом `CO_2` повітря з руйнуванням надпровідної фази:
   ```
   2 YBa_2Cu_3O_7 + 3 H_2O + 3 CO_2 → Y_2BaCuO_5 + 5 BaCO_3 + 5 CuO + 3 H_2O + O_2
   ```
   Утворення діелектричного карбонату барію `BaCO_3` та зеленої фази `Y_2BaCuO_5` локалізується на міжзеренних межах, що приводить до необоротного падіння міжзеренного критичного струму `J_c` на десятки відсотків за кілька місяців перебування у відкритому повітрі. Для консервації стрічки покривають безпористими шарами срібла та міді або герметизують поліімідними плівками.
2. **Розшарування по осі `c` (Delamination):** міцність купратних шарів на поперечний розрив уздовж площин `CuO_2` (вісь `c`) становить лише `15–25 МПа`. При дії значних радіальних електродинамічних сил Лоренца або термомеханічних напружень при охолодженні стрічка зазнає розшарування.

#### Фізика квенчу: порівняння LTS та HTS систем
Перехід надпровідника у нормальний стан супроводжується двома параметрами: мінімальною енергією ініціювання квенчу (MQE) та швидкістю поширення нормальної зони (NZPV).

| Параметр стійкості | Низькотемпературні надпровідники (LTS: Nb-Ti / `Nb_3Sn`, 4.2 K) | Високотемпературні надпровідники (HTS: YBCO, 77 K) | Інженерний наслідок |
| :--- | :--- | :--- | :--- |
| **Енергія ініціювання (MQE)** | Дуже мала: `1–10 мкДж` | Колосальна: `1–10 мДж` (у 1000 разів вища) | HTS надзвичайно стійкі до мікрорухів жил і теплових стрибків. |
| **Швидкість зони (NZPV)** | Висока: `10–100 м/с` | Екстремально низька: `1–50 мм/с` | Нормальна зона в HTS залишається локалізованою в точці виникнення. |
| **Виявлення квенчу** | Легке: напруга на соленоїді зростає за мілісекунди (`> 100 мВ`). | Критично важке: локальна зона плавиться до того, як з'явиться вимірна напруга. | Потрібні оптоволоконні давачі температури та активні системи підігріву (CLIQ). |

Низька швидкість розростання нормальної зони в HTS стрічках породжує «парадокс квенчу ВТНП»: велика питома теплоємність матеріалів при `77 K` захищає провідник від випадкових збоїв, проте якщо квенч виник, усе виділення тепла Джоуля локалізується у плямі розміром у кілька міліметрів. Без активного захисту температура гарячої точки (*hot spot*) за `100–300 мс` перевищує `500–800 °C`, спалюючи провідник.

#### Адіабатичний інтеграл струму та захисне шунтування
Для обмеження температури гарячої точки безпечним рівнем `T_hot < 200–250 K` система захисту повинна скинути струм соленоїда за час `t_decay`. Гранично допустимий інтеграл струму розраховується за тепловим балансом мідного шунта:

```
∫_0^t_decay I²(t) dt = A_cu · A_tot · ∫_T_0^T_hot (γ_m · C_p(T) / ρ_cu(T, B)) dT
```

де `A_cu` — переріз мідного шунта, `γ_m` — густина міді, `C_p(T)` — її питома теплоємність, а `ρ_cu(T, B)` — питомий опір міді з урахуванням магнітоопору Колера.

### Промислові застосування: кабелі, обмежувачі струму та SMES

Параметри надпровідних матеріалів визначають їхню вузьку спеціалізацію у силовій електроенергетиці та промисловості.

#### 1. Надпровідні кабелі електропередачі (HTS Power Cables)
Надпровідні кабелі на основі 2G HTS стрічок YBCO виготовляють у вигляді коаксіальних жил, омиваних рідким азотом (`77 K`).
- При напрузі `20 кВ` надпровідний кабель здатний передавати струм до `5000 А` (потужність `100 МВт`), що еквівалентно повітряній лінії напругою `110 кВ`;
- Поперечний переріз надпровідної лінії у 4–6 разів менший за мідний аналог, що дозволяє прокладати надпотужні енерговводи у міських колекторах без розкопування вулиць.

#### 2. Надпровідні обмежувачі струму короткого замикання (SFCL)
Обмежувачі струму резистивного типу (SFCL — *Superconducting Fault Current Limiter*) використовують явище раптової втрати надпровідності при перевищенні критичного струму `I > I_c`.
- У штатному режимі мережі струм тече крізь YBCO стрічки з нульовим опором;
- При короткому замиканні струм зростає у 10–20 разів, перевищуючи `I_c`. Стрічка за мілісекунди переходить у нормальний стан із опором сотні Ом;
- SFCL природним чином обмежує струм короткого замикання до безпечного рівня ще до спрацьовування механічних вимикачів, запобігаючи руйнуванню трансформаторів та підстанцій.

#### 3. Надпровідні магнітні накопичувачі енергії (SMES)
Накопичувачі SMES (*Superconducting Magnetic Energy Storage*) зберігають енергію у вигляді магнітного поля надпровідного соленоїда: `E_m = (1/2) L I²`.
- ККД циклу «заряд — збереження — розряд» перевищує `95–97%`, що недосяжно для хімічних акумуляторів;
- Час відгуку на запит потужності становить менше `1–2 мілісекунд`, що робить SMES ідеальним інструментом для компенсації провалів напруги у чутливих напівпровідникових фабриках та захисту енергосистем від динамічних коливань.

### Кріогенні теплоприпливи та оптимізація токовводів

Забезпечення стабільної роботи надпровідних систем вимагає мінімізації теплоприпливів у кріостат із кімнатної температури (`300 K`). Тепловий баланс кріостата складається з трьох основних компонентів:
1. **Радіаційний теплообмін (`Q_rad`):** випромінювання тепла від зовнішніх стінок кріостата. Зменшується за допомогою багатошарової екранно-вакуумної теплоізоляції (ЕВОТ / MLI — *Multi-Layer Insulation*), що складається з 30–50 шарів алюмінізованої майларової плівки у глибокому вакуумі (`p < 10⁻⁵ мбар`).
2. **Кондуктивний теплоприплив по опорних елементах (`Q_cond`):** передача тепла по механічних підвісах та трубопроводах. Визначається інтегралом теплопровідності `Q_cond = (A / L) · ∫_T_low^T_high k(T) dT`. Опорні елементи виготовляють із склопластику (G10/G11) або титанових сплавів, які мають малу теплопровідність при високій механічній міцності.
3. **Теплоприплив по струмопроводах (токовводах):** струмові введення передають транспортний струм `I` від зовнішнього джерела живлення при `300 K` до надпровідного магніту у гелієвій ванні (`4.2 K`).

#### Оптимізація Макфі для класичних металевих токовводів
Металевий токоввід зазнає двох протилежних процесів: кондуктивного теплоприпливу з гарячого кінця та Джоулевого самонагрівання `I² R`. Річард Макфі (1959 рік) довів, що для кожної величини струму `I` існує геометричний оптимум співвідношення довжини до площі перерізу `(L / A)_opt`:

```
(I · L / A)_opt ≈ 3 × 10⁵ А / м    [оптимум Макфі для мідних токовводів]
```

При дотриманні оптимуму Макфі мінімальний теплоприплив у рідкий гелій становить близько `1.14 Ват` на кожні `1000 Ампер` транспортного струму (що викликає випаровування `1.6 літра` рідкого гелію на годину на кожні 1000 А).

#### Гібридні ВТНП-токовводи
Для кардинального зменшення втрат гелію у сучасних прискорювачах (LHC) та токамаках використовують **гібридні токовводи**:
- Верхня секція (від `300 K` до `50 K` або `77 K`) виготовляється із профільованої міді, омиваної парами холодного азоту чи гелію;
- Нижня секція (від `77 K` до `4.2 K`) виготовляється із ВТНП-елементів на основі BSCCO-2223 або YBCO.

Оскільки у надпровідному стані `R ≡ 0`, Джоулеве нагрівання в нижній секції повністю відсутнє, а питома теплопровідність кераміки BSCCO у десятки разів менша за мідь. Застосування гібридних ВТНП-токовводів зменшує теплоприплив у рідкий гелій на `80–90%` (до `0.15 Вт` на 1000 А), що забезпечує колосальну економію рідкого гелію у великомасштабних наукових комплексах.

### Розрахунковий приклад: Тепловий баланс МРТ-соленоїда

Розглянемо практичний інженерний розрахунок кріогенного забезпечення надпровідного соленоїда медичного томографа з індуктивністю `L = 12 Гн` та робочим струмом `I = 400 А`, який створює магнітне поле `B = 1.5 Тл` при температурі `4.2 K`.

1. **Запасена магнітна енергія:**
   `E_m = (1/2) · L · I² = 0.5 · 12 · (400)² = 960 000 Дж = 0.96 МДж`.
2. **Оцінка теплоприпливів у кріостат:**
   - Радіаційний теплоприплив крізь 40 шарів ЕВОТ-ізоляції: `Q_rad ≈ 0.8 Вт`;
   - Кондуктивний теплоприплив по склопластикових підвісах: `Q_cond ≈ 0.4 Вт`;
   - Теплоприплив по двох оптимізованих гібридних ВТНП-токовводах при струмі `400 А`: `Q_leads ≈ 0.3 Вт`.
   - Сумарний тепловий приплив у гелієву ванну: `Q_total = 0.8 + 0.4 + 0.3 = 1.5 Вт`.
3. **Розрахунок витрати рідкого гелію:**
   Питома теплота випаровування рідкого гелію при `4.2 K` дорівнює `L_vap = 2.56 кДж/л` (або `20.9 Дж/г` при густині `ρ_He = 125 г/л`).
   Витрата рідкого гелію на випаровування становить:
   `V_boil = (Q_total / L_vap) · 3600 = (1.5 / 2560) · 3600 ≈ 2.11 літра на годину` (`50.6 літрів на добу`).

Застосування замкнених кріоохолоджувачів другого ступеня (рефрижераторів Джиффорда — Макмагона або пульсаційних трубок) дозволяє конденсувати випаруваний гелій назад у рідкий стан безпосередньо у кріостаті, забезпечуючи «нульове випаровування» (*zero boil-off*) протягом років експлуатації томографа.
