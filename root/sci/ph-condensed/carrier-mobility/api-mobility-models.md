# 📋 Довідник емпіричних моделей та параметрів рухливості носіїв

Цей довідник містить зведені формули, систематизовані набори параметрів та текстові роз'яснення фізичних моделей рухливості носіїв заряду, які застосовуються в інженерному аналізі напівпровідникових приладів та сабмікронних систем комп'ютерного моделювання (TCAD, Technology Computer-Aided Design, таких як Silvaco ATLAS та Synopsys Sentaurus). Довідник охоплює розрахунок низькопольової рухливості, ефектів сильнолегованого розсіяння, температурної деградації, поверхневого розсіяння у каналах транзисторів та насичення дрейфової швидкості у сильних електричних полях для кремнію (`Si`), германію (`Ge`), арсеніду галію (`GaAs`), карбіду кремнію (`4H-SiC`) та нітриду галію (`GaN`).

Моделювання транспортних властивостей напівпровідників у сучасних TCAD пакетах вимагає точного підбору емпіричних коефіцієнтів, оскільки від них безпосередньо залежать розраховані значення вольт-амперних характеристик, граничні частоти перемикання та теплові режими інтегральних схем.

## 1. Об'ємна модель низького поля Коугі — Томаса (Caughey — Thomas Model)

Модель Коугі — Томаса призначена для розрахунку ефективної рухливості носіїв у слабких електричних полях, де дрейфова швидкість змінюється прямо пропорційно напруженості поля, а основним чинником деградації виступає кулонівське розсіяння на іонізованих донорах та акцепторах. Вона описує плавний монотонний перехід від максимуму рухливості у чистому кристалі `μ_max` до мінімального насиченого значення `μ_min` у сильнолегованому матеріалі.

Математично формула Коугі — Томаса для рівноважної кімнатної температури (`T = 300 К`) виражається через загальну концентрацію іонізованих домішок `N_total = N_d + N_a`:

```
μ_low = μ_min + (μ_max - μ_min) / [ 1 + (N_total / N_ref)^α ]
```

Фізичний зміст параметрів розкривається через кінетику розсіяння:
- **`μ_max`** (см²/(В·с)) — межа рухливості для абсолютно чистого кристала, де основним і єдиним механізмом є розсіяння на теплових акустичних фононах ґратки.
- **`μ_min`** (см²/(В·с)) — асимптотичний нижній поріг рухливості при екстремально високому допуванні, де кулонівська частота зіткнень із домішковими іонами досягає свого фізичного максимуму.
- **`N_ref`** (см⁻³) — характерна реферна концентрація домішок, при якій рухливість зменшується рівно наполовину від свого максимального діапазону `(μ_max - μ_min) / 2`.
- **`α`** (безрозмірний) — показник ступеня крутизни кривої переходу, що визначає ефективність квантового екранування кулонівських потенціалів Дебая.

## 2. Температурна залежність рухливості та моделювання температурних режимів

При зміні робочої температури напівпровідникового кристала від кріогенних значень до термодинамічного нагріву силових елементів (`T > 450 К`) інтенсивність розсіяння кардинально змінюється. Для врахування цього ефекту параметри Коугі — Томаса модифікуються температурними коефіцієнтами `γ`.

Чисте решіткове розсіяння на фононах описується температурним коефіцієнтом `γ_2`:

```
μ_max(T) = μ_max(300 K) · (T / 300)^(- γ_2)
```

Загальне рівняння Коугі — Томаса з урахуванням температури та допування набуває двовимірного вигляду:

```
μ_low(N, T) = μ_min · (T / 300)^(γ_1) + ( μ_max · (T / 300)^(- γ_2) - μ_min · (T / 300)^(γ_1) ) / [ 1 + (N / N_ref)^α · (T / 300)^(γ_3) ]
```

### Степеневі коефіцієнти температурної залежності для кремнію (`Si`)

| Показник | Електрони у Si | Дірки у Si | Фізичний зміст і температурна динаміка |
| :--- | :--- | :--- | :--- |
| **`γ_2` (решітка)** | `2.42` | `2.20` | Зменшення фононної рухливості через підсилення амплітуди коливань ґратки |
| **`γ_1` (мінімум)** | `- 0.57` | `- 0.50` | Зміна асимптотичного мінімуму при поглинанні кінетичної енергії |
| **`γ_3` (домішки)** | `- 0.70` | `- 0.70` | Температурна модифікація радіуса екранування Дебая `λ_D` |

Значення `γ_2 = 2.42` для електронів кремнію перевищує класичне теоретичне значення `1.5` через суттєвий внесок міждолинного розсіяння (інтерваллейних фононів), яке вмикається при високих температурах.

## 3. Модель ультрависокого допування Масетті (Masetti Model)

У сучасних інтегральних мікросхемах витоки, стоки, важколеговані емітери та омічні контактні шари мають рівні легування `N_total > 10¹⁹ см⁻³`, що перевищують межу виродження. При таких концентраціях іони домішок починають кластеризуватися, утворюючи нейтральні комплекси та подвійні розсіювальні центри. 

Класична модель Коугі — Томаса в цій області дає завищені значення рухливості, оскільки вона не враховує додаткову деградацію на нейтральних та кластеризованих домішках. Модель Масетті розширює формулу Коугі — Томаса додатковим корекційним доданком:

```
μ_low_Masetti = μ_min1 · exp(- P_c / N_total) + (μ_0 - μ_min1) / [ 1 + (N_total / C_cr)^α ] - μ_min2 / [ 1 + (C_cr2 / N_total)^β ]
```

де `C_cr2` — критична концентрація початку кластеризації домішок, `μ_min2` — додаткова деградація рухливості на кластерах, а `P_c` — параметр витискання.

### Параметри моделі Масетті для монокристалічного кремнію (`Si`) при `T = 300 К`

| Параметр | Значення (електрони) | Значення (дірки) | Фізична роль у симуляторі TCAD |
| :--- | :--- | :--- | :--- |
| **`μ_0`** | `1414.0 см²/(В·с)` | `470.5 см²/(В·с)` | Чиста решіткова рухливість |
| **`μ_min1`** | `52.2 см²/(В·с)` | `44.9 см²/(В·с)` | Перший рівень домішкового насичення |
| **`μ_min2`** | `52.2 см²/(В·с)` | `29.0 см²/(В·с)` | Другий рівень деградації на кластерах |
| **`C_cr`** | `9.68 × 10¹⁶ см⁻³` | `2.23 × 10¹⁷ см⁻³` | Перша критична концентрація |
| **`C_cr2`** | `3.43 × 10¹⁹ см⁻³` | `6.10 × 10²⁰ см⁻³` | Поріг активації кластерного розсіяння |
| **`α`** | `0.680` | `0.719` | Перший показник кривизни |
| **`β`** | `2.000` | `2.000` | Показник швидкості кластеризації |

Використання моделі Масетті є обов'язковим при моделюванні ультранеглибоких `p-n` переходів, контактних опорів та витоково-стокових областей нанорозмірних MOSFET та FinFET транзисторів.

## 4. Польова модель нелінійного дрейфу та насичення швидкості

У сильних електричних полях (`E > 10⁴ В/см`) дрейфова швидкість носіїв перестає зростати лінійно за законом `v_d = μ · E` і виходить на насичення `v_sat` через інтенсивне генераційне випромінювання оптичних фононів. Для математичного опису нелінійної характеристичної кривої у TCAD симуляторах використовують емпіричну формулу Коугі — Томаса для сильного поля:

```
v_d(E) = (μ_low · E) / [ 1 + (μ_low · E / v_sat)^β ]^(1 / β)
```

Польова рухливість `μ(E) = v_d(E) / E` визначається як диференційна величина:

```
μ(E) = μ_low / [ 1 + (μ_low · E / v_sat)^β ]^(1 / β)
```

### Параметри насичення швидкості та критичних полів при `T = 300 К`

| Матеріал | Носій | Швидкість насичення `v_sat` (см/с) | Показник поля `β` | Критичне поле `E_crit` (В/см) |
| :--- | :--- | :--- | :--- | :--- |
| **Кремній (`Si`)** | Електрони | `1.07 × 10⁷` | `1.11` | `1.0 × 10⁴` |
| **Кремній (`Si`)** | Дірки | `8.37 × 10⁶` | `1.21` | `2.0 × 10⁴` |
| **Арсенід галію (`GaAs`)** | Електрони | `1.20 × 10⁷` | `2.00` | `3.5 × 10³` (пік NDM) |
| **Карбід кремнію (`4H-SiC`)** | Електрони | `2.20 × 10⁷` | `1.00` | `2.0 × 10⁵` |
| **Нітрид галію (`GaN`)** | Електрони | `2.50 × 10⁷` | `1.00` | `1.5 × 10⁵` |

Для арсеніду галію (`GaAs`) при полях понад `3.5 кВ/см` спостерігається ефект Ганна (негативна диференціальна рухливість, NDM), тому стандартний показник `β = 2` використовується зі спеціальним модифікатором міждолинного перенесення Джилса.

## 5. Поверхнева модель Ломбарді (Lombardi Surface Mobility Model)

У каналах польових транзисторів (MOSFET, MISFET, HEMT) носії заряду рухаються у вузькому інверсійному або збагаченому шарі товщиною `2–5 нм` поблизу діелектрика `SiO₂` або `High-k` затвора. Поперечне нормальне електричне поле затвора `E_n` притискає електрони безпосередньо до поверхні розділу фаз.

У цій області об'ємна рухливість суттєво деградує через два додаткові поверхневі механізми:
1. **Розсіяння на поверхневих акустичних фононах (`μ_ac`)** — теплові коливання приповерхневих атомів підсилені через обмеженість тривимірних мод.
2. **Розсіяння на геометричній шорсткості поверхні (`μ_sr`)** — атомні ступені та шорсткість межі розділу `Si/SiO₂` створюють квантовий потенціал розсіяння.

Модель Ломбарді об'єднує всі три компоненти за правилом Маттіссена:

```
1 / μ_surface = 1 / μ_bulk + 1 / μ_ac + 1 / μ_sr
```

Аналітичні вирази для поверхневих компонент мають вигляд:

```
μ_ac = B / E_n + (C · N_total^η) / (E_n^(1/3) · T)
```

```
μ_sr = δ / E_n²
```

### Коефіцієнти поверхневої моделі Ломбарді для кремнієвих MOSFET транзисторів

| Параметр | Значення (електрони) | Значення (дірки) | Фізичний зміст у моделюванні затвора |
| :--- | :--- | :--- | :--- |
| **`B`** | `4.75 × 10⁷ см/с` | `9.93 × 10⁶ см/с` | Амплітуда фононного поверхневого розсіяння |
| **`C`** | `5.80 × 10²` | `2.94 × 10²` | Коефіцієнт взаємодії домішок та поверхні |
| **`δ`** | `5.82 × 10¹⁸ В/с` | `2.05 × 10¹⁸ В/с` | Амплітуда шорсткості межі `Si/SiO₂` |

Оскільки поверхневе розсіяння на шорсткості пропорційне квадрату нормального поля `E_n²`, при високих напругах на затворі (`V_gs > 2 В`) саме компонент `μ_sr` стає домінуючим, що спричиняє насичення крутизни вольт-амперної характеристики транзистора.

## 6. Рекомендації щодо вибору моделей у TCAD проектуванні

Під час побудови чисельних фізичних моделей пристроїв у середовищах Silvaco ATLAS або Synopsys Sentaurus рекомендується дотримуватися наступних правил вибору комплексу моделей:
- **Об'ємні силові діоди та тиристори:** поєднання низькопольової моделі Коугі — Томаса з польовим насиченням швидкості та носій-носій розсіянням Клаассена.
- **Субмікронні планарні та FinFET MOSFET:** обов'язкове включення поверхневої моделі Ломбарді разом із моделлю Масетті для сильнолегованих витоків/стоків та модель Коугі — Томаса для поздовжнього сильного поля.
- **Гетеротранзистори HEMT на `AlGaAs/GaAs` або `AlGaN/GaN`:** застосування двовимірних моделей розсіяння у квантовій ямі 2DEG із врахуванням п'єзоелектричного та поляризаційного розсіяння на гетеромежі.
