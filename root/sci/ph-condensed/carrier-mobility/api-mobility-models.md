# 📋 Довідник емпіричних моделей та параметрів рухливості носіїв

У системах приладо-технологічного комп'ютерного моделювання напівпровідників (TCAD, Technology Computer-Aided Design, зокрема Synopsys Sentaurus Device, Silvaco ATLAS, Cogenda Genius та Minimos) розрахунок перенесення заряду ґрунтується на сумісному розв'язанні фундаментальної системи диференціальних рівнянь у частинних похідних: рівняння Пуассона для електростатичного потенціалу `ψ` та рівнянь неперервності для електронів `n` і дірок `p`.

У квазікласичному дрейфово-дифузійному наближенні густини електронного `j_n` та діркового `j_p` струмів визначаються виразами:

```
j_n = - q · n · μ_n · ∇ψ + q · D_n · ∇n
j_p = - q · p · μ_p · ∇ψ - q · D_p · ∇p
```

де `ψ` — локальний електростатичний потенціал, `D_n = μ_n · (k_B T / q)` та `D_p = μ_p · (k_B T / q)` — коефіцієнти дифузії носіїв заряду згідно з фундаментальним співвідношенням Ейнштейна, `k_B` — стала Больцмана, `T` — термодинамічна температура ґратки, `q = 1.602 × 10⁻¹⁹ Кл` — елементарний електричний заряд.

У чисельних дискретизаціях просторової сітки TCAD за методом скінченних боксів (Finite Box Method) та схемою Шарфеттера — Гуммеля (Scharfetter — Gummel scheme) проєкція струму на ребро сітки між вузлами `i` та `j` обчислюється через функцію Бернуллі `B(x) = x / (exp(x) - 1)`:

```
j_{n, ij} = (q · μ_{n, ij} · V_t / L_{ij}) · [ n_j · B(Δ_{ij}) - n_i · B(- Δ_{ij}) ]
```

де `V_t = k_B T / q` — тепловий потенціал (`≈ 0.0259 В` при 300 К), `L_{ij}` — відстань між сусідніми вузлами просторової сітки, `Δ_{ij} = (ψ_j - ψ_i) / V_t` — нормована безрозмірна різниця електростатичних потенціалів, а `μ_{n, ij}` — ефективна локальна рухливість на ребрі дискретизації, яка знаходиться гармонійним або зваженим інтегральним усередненням.

Локальна рухливість носіїв `μ_n` та `μ_p` не є константою матеріалу: вона зазнає сильної нелінійної деградації під впливом концентрації легуючих домішок, локальної температури ґратки, поперечних притискальних електричних полів на межах напівпровідник-діелектрик та сильних поздовжніх тягнучих полів.

Цей довідник містить повні аналітичні формулювання, замкнені математичні структури, калібровані матриці коефіцієнтів, діапазони валідності, граничні інваріанти та алгоритмічні контракти емпіричних моделей рухливості для кремнію (`Si`), германію (`Ge`), арсеніду галію (`GaAs`), карбіду кремнію (`4H-SiC`, `6H-SiC`), нітриду галію (`GaN`), фосфіду індію (`InP`), потрійних сполук (`In₀.₅₃Ga₀.₄₇As`) та діаманту (`Diamond`).

## 1. Об'ємні низькопольові моделі концентраційної залежності (Low-Field Doping Models)

У квазірівноважних умовах та слабких електричних полях (`E < 10³ В/см`) набута дрейфова швидкість носіїв прямо пропорційна напруженості поля `v_d = μ_low · E`. Головними фізичними чинниками деградації виступають розсіяння на теплових акустичних фононах кристалічної ґратки та кулонівська взаємодія з іонізованими домішками (донорами `N_d⁺` і акцепторами `N_a⁻`).

### 1.1. Модель Коугі — Томаса (Caughey — Thomas Model)

Модель Коугі — Томаса (1967) є базовим аналітичним індустріальним стандартом для моделювання об'ємних областей напівпровідників при концентраціях легування до межі виродження (`N_total < 10¹⁹ см⁻³`). Формула описує плавний перехід від максимальної фононної рухливості в нелегованому кристалі `μ_max` до мінімальної асимптотичної рухливості `μ_min` у сильнолегованому матеріалі:

```
μ_low(N_total) = μ_min + (μ_max - μ_min) / [ 1 + (N_total / N_ref)^α ]
```

де `N_total = N_d⁺ + N_a⁻` — сумарна концентрація іонізованих домішкових іонів (у `см⁻³`).

Фізичний зміст параметрів та їхній зв'язок із мікроскопічною кінетикою:
- **`μ_max`** (см²/(В·с)) — фононна межа ідеального чистого кристала, де єдиним каналом втрати імпульсу є розсіяння на довжинохвильових акустичних коливаннях ґратки з перерізом розсіяння Брукса.
- **`μ_min`** (см²/(В·с)) — нижній поріг кулонівського розсіяння, коли частота зіткнень із домішковими іонами обмежується мінімальним прицільним параметром Резерфорда та просторовим перекриттям потенціалів.
- **`N_ref`** (см⁻³) — характерна концентрація допування, при якій частота фононного розсіяння точно врівноважує частоту кулонівських зіткнень, а рухливість становить рівно половину робочого розмаху: `μ_low(N_ref) = (μ_max + μ_min) / 2`.
- **`α`** (безрозмірний) — фактор крутизни перехідної області. Для ковалентних кристалів із дебаївським екрануванням (`Si`, `Ge`) величина `α ≈ 0.6–0.8`, тоді як для іонних сполук (`GaN`) через сильне поляризаційне розсіяння Фреліха `α ≈ 1.0`.

Математичні граничні інваріанти:
```
lim_{N_total → 0} μ_low(N_total) = μ_max
lim_{N_total → ∞} μ_low(N_total) = μ_min
d μ_low / d N_total < 0, для всіх N_total > 0
```

### 1.2. Модель Арори (Arora Mobility Model)

Модель Арори (1982) є спеціалізованою аналітичною модифікацією для монокристалічного кремнію, оптимізованою для розрахунку транспортних властивостей у діапазоні температур `200...500 К`. Модель прямо розділяє температурні внески домішкового насичення та фононного перепаду:

```
μ_low_Arora = μ_min + μ_d / [ 1 + (N_total / N_ref)^α ]
```

де температурні залежності задаються у формі явних степеневих співвідношень:

```
μ_min = A_min · (T / 300)^α_m
μ_d   = A_d   · (T / 300)^α_d
N_ref = A_N   · (T / 300)^α_N
α     = A_a   · (T / 300)^α_a
```

### 1.3. Модель ультрависокого допування Масетті (Masetti Model)

У витоково-стокових областях транзисторів, емітерах BJT та полікремнієвих затворах рівень легування перевищує `10²⁰ см⁻³`. У цій зоні кулонівські потенціали сусідніх іонів перекриваються, утворюючи нейтральні кластери та преципітати (наприклад, кластери `SiP` або комплекси `B_i-B_s`), що спричиняє додаткову деградацію рухливості.

Модель Масетті (1983) вводить експоненційний фактор квантового витискання та від'ємний корекційний кластерний доданок:

```
μ_low_Masetti = μ_min1 · exp(- P_c / N_total) + (μ_0 - μ_min1) / [ 1 + (N_total / C_cr)^α ] - μ_min2 / [ 1 + (C_cr2 / N_total)^β ]
```

Фізична структура трьох доданків:
1. `μ_min1 · exp(- P_c / N_total)` — рівень розсіяння на іонізованих домішках, де множник `exp(- P_c / N_total)` враховує деінтенсифікацію розсіяння внаслідок квантового екранування виродженим електронним газом.
2. `(μ_0 - μ_min1) / [ 1 + (N_total / C_cr)^α ]` — стандартний перехід від фононного розсіяння до домішкового.
3. `- μ_min2 / [ 1 + (C_cr2 / N_total)^β ]` — спад рухливості при `N_total > C_cr2` через розсіяння на кластерах та структурних дефектах кристала.

### 1.4. Уніфікована модель Клаассена (Klaassen's Unified Mobility Model, UMM)

Уніфікована модель Клаассена (Philips UMM, 1992) забезпечує замкнений фізичний опис низькопольового перенесення заряду, одночасно враховуючи:
1. Решіткове розсіяння на фононах (`μ_L`).
2. Розсіяння на іонізованих донорах (`N_d⁺`) та акцепторах (`N_a⁻`) з урахуванням статистики Фермі — Дірака.
3. Електрон-діркове розсіяння (носій-носійне гальмування `μ_e_h` / drag-effect) в умовах сильної інжекції або оптичної генерації.
4. Ефекти квантового екранування вільними носіями заряду (`n + p`).
5. Зниження розсіяння у компенсованих напівпровідниках через кореляцію розташування донорно-акцепторних пар.

Загальне об'єднання компонентів виконується за модифікованим правилом:

```
1 / μ_low_Klaassen = 1 / μ_L + 1 / μ_DA_e_h
```

де решіткова складова має температурний вигляд:

```
μ_L = μ_max · (300 / T)^θ
```

Домішково-носійна складова описується рівнянням:

```
μ_DA_e_h = μ_N · (N_sc / N_sc_eff) · (N_ref / N_sc)^α + μ_c · ( (n + p) / N_sc_eff )
```

де `N_sc = N_d⁺ + N_a⁻ + p` (для електронів) або `N_sc = N_d⁺ + N_a⁻ + n` (для дірок) — загальна густина заряджених розсіювальних центрів, а `N_sc_eff` — ефективна густина з урахуванням екранування:

```
N_sc_eff = N_d⁺ · G(P_D) + N_a⁻ · G(P_A) + (n + p) · F(P_carr)
```

Функції екранування Брукса — Герінга розраховуються за співвідношенням:

```
G(P) = 1 - 0.892 / [ 1.0 + (P / P_0)^0.5 ]
```

де параметр екранування `P` залежить від відношення радіуса Дебая `r_D = √( (ε_s k_B T) / (q² (n + p)) )` до теплової довжини хвилі де Бройля носія заряду `λ_th = ℏ / √(3 m* k_B T)`.

## 2. Моделі сильного поля, розігріву носіїв та насичення швидкості (High-Field Models)

У сильних електричних полях (`E > 10⁴ В/см`) носії заряду накопичують кінетичну енергію, що значно перевищує рівноважну теплову енергію ґратки `(3/2) k_B T`. Середня ефективна температура носіїв `T_e` або `T_h` сягає кількох тисяч кельвінів (явище гарячих носіїв), що активує інтенсивне спонтанне випромінювання оптичних фононів (`ℏω_opt ≈ 63 меВ` у кремнії, `35 меВ` у GaAs, `92 меВ` у GaN). Дрейфова швидкість перестає зростати лінійно за законом Ома і насичується на постійній величині `v_sat`.

### 2.1. Формула Коугі — Томаса для сильного поля

Для зв'язку між локальним поздовжнім електричним полем `E = |∇ψ_parallel|` та ефективною польовою рухливістю `μ(E)` у TCAD використовують емпіричну функцію переходу Коугі — Томаса:

```
v_d(E) = (μ_low · E) / [ 1 + (μ_low · E / v_sat)^β ]^(1 / β)
```

Польова рухливість `μ(E) = v_d(E) / E` визначається виразом:

```
μ(E) = μ_low / [ 1 + (μ_low · E / v_sat)^β ]^(1 / β)
```

де `E_crit = v_sat / μ_low` — критична напруженість електричного поля, що позначає початок вираженого відхилення від лінійного закону Ома.

Асимптотичні властивості та диференціальні межі:
- Слабке поле (`E ≪ E_crit`): `v_d(E) ≈ μ_low · E · [ 1 - (1/β) · (E / E_crit)^β ] → μ_low · E`;
- Сильне поле (`E ≫ E_crit`): `v_d(E) ≈ v_sat · [ 1 - (1/β) · (E_crit / E)^β ] → v_sat`;
- Гранична диференціальна рухливість прямує до нуля: `lim_{E → ∞} (d v_d / d E) = 0`.

### 2.2. Температурно-залежна модель Каналі (Canali High-Field Model)

Модель Каналі (1975) є загальновизнаним індустріальним стандартом TCAD для кремнієвих приладів у діапазоні температур `77...500 К`. Вона модифікує швидкість насичення `v_sat` та показник кривизни `β` як аналітичні функції локальної температури ґратки:

```
v_sat(T) = v_sat_300 · (300 / T)^γ_vsat
β(T)     = β_300     · (T / 300)^β_exp
```

| **`β_exp`** | `0.66` | `0.17` | безрозмірний | Температурний показник зміни кривизни поля |

При охолодженні кремнію до кріогенної температури рідкого азоту (`T = 77 К`) швидкість насичення електронів зростає від `1.07 × 10⁷ см/с` до `3.45 × 10⁷ см/с`, що забезпечує значний приріст швидкодії кріогенних CMOS інтегральних схем.

### 2.3. Модель негативної диференціальної рухливості (NDM) для GaAs та GaN

У прямозонних напівпровідниках групи `AᴵᴵᴵBⱽ` зона провідності має центральну долину `Γ` з малою ефективною масою `m_Γ* = 0.067 m_0` (висока рухливість) та бічні долини `L` і `X` (`ΔE_{Γ-L} ≈ 0.29 еВ` у GaAs) з великою ефективною масою `m_L* = 0.22 m_0` (низька рухливість).

При перевищенні порогового поля `E > E_peak` гарячі електрони розсіюються у важкі бічні долини. Це спричиняє ефект Ганна — виникнення ділянки з **негативною диференціальною рухливістю** (`d v_d / d E < 0`).

Для опису NDM у TCAD застосовують формулу Джилса — Барнеса:

```
v_d(E) = [ μ_low · E + v_sat · (E / E_crit)^δ ] / [ 1 + (E / E_crit)^δ ]
```

і відповідно:

```
μ(E) = [ μ_low + (v_sat / E) · (E / E_crit)^δ ] / [ 1 + (E / E_crit)^δ ]
```

#### Параметри NDM моделі Джилса для n-GaAs та n-GaN (`T = 300 К`)

| :--- | :--- | :--- | :--- | :--- |
| **`μ_low`** | `8500.0` | `1250.0` | `см²/(В·с)` | Низькопольова рухливість |
| **`v_sat`** | `1.20 × 10⁷` | `2.50 × 10⁷` | `см/с` | Асимптотична швидкість сильного поля |
| **`E_crit`** | `3.50 × 10³` | `1.50 × 10⁵` | `В/см` | Критичне поле початку міждолинного переходу |
| **`v_peak`** | `2.10 × 10⁷` | `2.80 × 10⁷` | `см/с` | Максимальна пікова швидкість дрейфу |
| **`δ`** | `4.0` | `3.0` | безрозмірний | Показник крутизни спаду швидкості |

### 2.4. Анізотропія польового дрейфу в гексагональному карбіді кремнію (`4H-SiC`, `6H-SiC`)

У гексагональних політипах карбіду кремнію кристалічна структура спричиняє анізотропію тензора ефективної маси. У `4H-SiC` рухливість уздовж кристалографічної осі `c` ([0001]) перевищує рухливість у базисній площині `(0001)`: `μ_{parallel_c} / μ_{perp_c} ≈ 1.15–1.20`. Натомість у політипі `6H-SiC` спостерігається зворотна глибока анізотропія: рухливість уздовж осі `c` у 3.5–4 рази нижча за базисну (`μ_{parallel_c} / μ_{perp_c} ≈ 0.25`).

У TCAD тензор польової рухливості розраховується з урахуванням орієнтації кристала:

```
μ_xx(E) = μ_{low, ⊥} / [ 1 + (μ_{low, ⊥} · E_x / v_{sat, ⊥})^β ]^(1 / β)
μ_zz(E) = μ_{low, ∥} / [ 1 + (μ_{low, ∥} · E_z / v_{sat, ∥})^β ]^(1 / β)
```

## 3. Поверхневі моделі інверсійних шарів польових транзисторів (Surface & Inversion Layer Models)

У планарних MOSFET, FinFET, GAAFET та HEMT носії заряду рухаються у вузькому квантовому інверсійному каналі товщиною `1–4 нм` біля межі розділу напівпровідник-діелектрик (`Si/SiO₂`, `Si/HfO₂`, `AlGaN/GaN`). Сильне нормальне електричне поле затвора `E_perp` притискає носії до межі розділу, розщеплюючи зону провідності на дискретні двовимірні квантові підзони.

У приповерхневій області об'ємна рухливість деградує внаслідок трьох специфічних механізмів:
1. **Розсіяння на поверхневих акустичних фононах (`μ_ac`)** — локалізовані моди решітки межі розділу фаз.
2. **Розсіяння на геометричній шорсткості поверхні (`μ_sr`)** — флуктуації товщини діелектрика з середньоквадратичною висотою атомних сходинок `Δ ≈ 0.2–0.5 нм` та довжиною кореляції `Λ ≈ 1.5–3.0 нм`.
3. **Розсіяння на поверхневих зарядах та пастках (`μ_coul`)** — кулонівські пастки на межі з густиною `D_it ≈ 10¹⁰–10¹² еВ⁻¹·см⁻²`.
4. **Розсіяння на м'яких оптичних фононах High-k діелектрика (`μ_remote_ph`)** — дипольна взаємодія з коливаннями полярних зв'язків `Hf-O` або `Zr-O`.

### 3.1. Поверхнева модель Ломбарді (Lombardi CVT Model)

Модель Ломбарді (Canali, Ventura, Tasca, 1988) синтезує локальну рухливість за правилом Маттіссена:

```
1 / μ_surface = 1 / μ_bulk + 1 / μ_ac + 1 / μ_sr
```

Аналітичні компоненти поверхневої деградації:

```
μ_ac = B / E_perp + ( C · (N_total / N_0)^η ) / ( E_perp^(1/3) · (T / 300)^γ_ac )
```

```
μ_sr = δ / E_perp^γ_sr
```

де `E_perp` — локальна напруженість електричного поля, перпендикулярного до межі діелектрик-напівпровідник (у `В/см`), `N_0 = 1 см⁻³`.

### 3.2. Універсальна польова модель Дарвіша (Darwish / Lucent Model)

Модель Дарвіша (Bell Labs / Lucent, 1997) спирається на інтегральну концепцію ефективного нормального поля `E_eff`, розрахованого через поверхневий заряд збідненої області `Q_dep` та інверсійного шару `Q_inv`:

```
E_eff = ( |Q_dep| + η_eff · |Q_inv| ) / ε_si
```

де `η_eff = 1/2` для електронів у n-MOSFET та `η_eff = 1/3` для дірок у p-MOSFET, `ε_si = 11.7 · ε_0`.

Універсальна формула Дарвіша має вигляд:

```
μ_univ = μ_0 / [ 1 + (E_eff / E_ref1)^α1 + (E_eff / E_ref2)^α2 ]
```

| :--- | :--- | :--- | :--- | :--- |
| **`μ_0`** | `1040.0` | `415.0` | `см²/(В·с)` | Низькопольова інверсійна межа |
| **`E_ref1`** | `7.0 × 10⁵` | `5.5 × 10⁵` | `В/см` | Порогове поле фононного розсіяння |
| **`α1`** | `0.33` | `0.33` | безрозмірний | Показник фононного нахилу (`E_eff^(1/3)`) |
| **`E_ref2`** | `1.2 × 10⁶` | `1.0 × 10⁶` | `В/см` | Порогове поле розсіяння на шорсткості |
| **`α2`** | `2.60` | `2.60` | безрозмірний | Показник крутизни шорсткості поверхні |

### 3.3. Модель розсіяння на поверхневих кулонівських пастках (Surface Coulomb Model)

При слабкій інверсії (підпороговий режим `V_gs < V_th`) густина вільних носіїв у каналі мала, тому екранування заряджених поверхневих пасток `D_it` та фіксованого заряду оксиду `Q_ox` є слабким. Модель Таша — Енза розраховує цей компонент:

```
μ_coul = μ_c0 · (T / 300)^α_c · ( 1 + N_inv / N_inv_crit )^β_c / ( N_it / 10¹¹ )
```

де `N_inv` — двовимірна концентрація інверсійних носіїв (у `см⁻²`), `N_it` — сумарна поверхнева густина пасток (у `см⁻²`), `N_inv_crit = 1.0 × 10¹² см⁻²`.

Повна синтезована рухливість каналу в сучасних TCAD пакетах визначається чотирикомпонентною сумою:

```
1 / μ_channel = 1 / μ_bulk + 1 / μ_ac + 1 / μ_sr + 1 / μ_coul
```

### 4.2. Математичні інваріанти та алгоритмічні гарантії чисельної збіжності

Для забезпечення надійної квадратичної збіжності методу Ньютона — Рафсона функції рухливості повинні відповідати чотирьом суворим вимогам:

1. **Неперервність класу `C¹` за електричним полем:**
   Функція польової рухливості `μ(E)` та її аналітична похідна `∂μ / ∂E` повинні бути строго неперервними на всьому інтервалі `E ∈ [0, ∞)`. Для усунення невизначеності `0/0` при `E → 0` похідна обчислюється через аналітичні границі:
   ```
   lim_{E → 0} (∂v_d / ∂E) = μ_low
   lim_{E → 0} (∂μ / ∂E)   = 0
   ```

2. **Строга додатність рухливості:**
   Для будь-яких комбінацій вхідних параметрів `T`, `N_total`, `E` значення рухливості повинно задовольняти обмеження знизу:
   ```
   μ_calc ≥ μ_absolute_min = 1.0 см²/(В·с)
   ```
   що запобігає діленню на нуль при формуванні матриці дифузійної провідності.

3. **Векторна ортогоналізація полів на гетеромежах:**
   У кожному вузлі сітки вектор електричного поля `E` розкладається на нормальну складову `E_perp = |E · n_interface|` (де `n_interface` — одиничний вектор нормалі до межі з оксидом) та поздовжню складову `E_parallel = |E - (E · n_interface) · n_interface|`. Поверхнева рухливість `μ_surface` обчислюється за `E_perp`, а польове насичення швидкості — за `E_parallel`:
   ```
   μ_final = μ_surface(E_perp) / [ 1 + (μ_surface(E_perp) · E_parallel / v_sat)^β ]^(1 / β)
   ```

4. **Кріогенне замерзання домішок (Carrier Freeze-out):**
   При температурах `T < 150 К` концентрація активних іонізованих донорів `N_d⁺` зменшується за законом неповної іонізації:
   ```
   N_d⁺ = N_d / [ 1 + g_d · exp((E_F - E_d) / (k_B T)) ]
   ```
   де `g_d = 2` — фактор виродження донорного рівня, `E_d` — енергія залягання домішки (45 меВ для фосфору в Si). Усі формули розсіяння повинні використовувати саме активну іонізовану густину `N_d⁺`.

## 5. Покрокові числові приклади розрахунку параметрів

### 5.1. Приклад 1: Низькопольова рухливість у кремнієвій базі n-p-n транзистора

**Умова:**
Розрахувати низькопольову рухливість дірок `μ_p` у базовій області кремнієвого транзистора, легованій бором з концентрацією `N_a = 2.5 × 10¹⁷ см⁻³` (`N_d = 0`), при кімнатній температурі `T = 300 К` та при підвищеній температурі `T = 400 К`.

**Розрахунок за моделлю Коугі — Томаса:**

Крок 1. Вихідні параметри для дірок у кремнії: `μ_min = 47.7 см²/(В·с)`, `μ_max = 470.5 см²/(В·с)`, `N_ref = 2.23 × 10¹⁷ см⁻³`, `α = 0.719`.

Крок 2. Обчислення відношення концентрацій при `T = 300 К`:
```
N_total / N_ref
= (2.50 × 10¹⁷) / (2.23 × 10¹⁷)
= 1.1211                          [нормоване допування]
```

Крок 3. Обчислення знаменника формули:
```
1 + (N_total / N_ref)^α
= 1 + (1.1211)^0.719
= 1 + 1.0857
= 2.0857                          [кулонівський фактор екранування]
```

Крок 4. Розрахунок рухливості при `T = 300 К`:
```
μ_p(300 K)
= 47.7 + (470.5 - 47.7) / 2.0857
= 47.7 + 422.8 / 2.0857
= 47.7 + 202.71
= 250.41 см²/(В·с)                [результуюча низькопольова рухливість]
```

Крок 5. Температурний перерахунок для `T = 400 К` (`T / 300 = 1.3333`):
```
μ_max(400 K) = 470.5 · (1.3333)^(- 2.20) = 470.5 · 0.5309 = 249.79 см²/(В·с)
μ_min(400 K) = 47.7  · (1.3333)^(- 0.50) = 47.7  · 0.8660 = 41.31 см²/(В·с)
N_ref(400 K) = (2.23 × 10¹⁷) · (1.3333)^(- 0.70) = (2.23 × 10¹⁷) · 0.8179 = 1.824 × 10¹⁷ см⁻³
```

Крок 6. Розрахунок рухливості при `T = 400 К`:
```
N_total / N_ref(400 K) = (2.50 × 10¹⁷) / (1.824 × 10¹⁷) = 1.3706
Знаменник = 1 + (1.3706)^0.719 = 1 + 1.2536 = 2.2536
μ_p(400 K)
= 41.31 + (249.79 - 41.31) / 2.2536
= 41.31 + 208.48 / 2.2536
= 41.31 + 92.51
= 133.82 см²/(В·с)                [деградація на 46.5% внаслідок нагріву]
```

### 5.2. Приклад 2: Дрейфова швидкість електронів у субмікронному каналі Si MOSFET

**Умова:**
В інверсійному каналі n-MOSFET транзистора при `T = 300 К` та легуванні підкладки `N_a = 1.0 × 10¹⁷ см⁻³` нормальне поле затвора становить `E_perp = 5.0 × 10⁵ В/см`, а поздовжнє тягнуче поле стоку дорівнює `E_parallel = 3.0 × 10⁴ В/см`. Розрахувати ефективну польову рухливість та дрейфову швидкість електронів з урахуванням поверхневих ефектів Ломбарді та насичення швидкості Каналі.

**Покроковий розрахунок:**

Крок 1. Об'ємна низькопольова рухливість у підкладці за моделлю Коугі — Томаса:
```
N_total / N_ref = (1.0 × 10¹⁷) / (9.68 × 10¹⁶) = 1.033
Знаменник = 1 + (1.033)^0.680 = 1 + 1.0224 = 2.0224
μ_bulk = 65.0 + (1417.0 - 65.0) / 2.0224 = 65.0 + 668.51 = 733.51 см²/(В·с)
```

Крок 2. Розрахунок поверхневого фононного компонента `μ_ac` за моделлю Ломбарді (`E_perp = 5.0 × 10⁵ В/см`):
```
Доданок 1 = B / E_perp = (4.75 × 10⁷) / (5.0 × 10⁵) = 95.00 см²/(В·с)
Доданок 2 = ( C · N_total^η ) / ( E_perp^(1/3) · (T/300) )
          = ( 580 · (10¹⁷)^0.125 ) / ( (5.0 × 10⁵)^(1/3) )
          = ( 580 · 133.35 ) / ( 79.37 )
          = 77343 / 79.37 = 974.46 см²/(В·с)
μ_ac = 95.00 + 974.46 = 1069.46 см²/(В·с)
```

Крок 3. Розрахунок поверхневої шорсткості `μ_sr`:
```
μ_sr = δ / E_perp² = (5.82 × 10¹⁸) / (5.0 × 10⁵)² = (5.82 × 10¹⁸) / (2.50 × 10¹¹) = 23280.0 см²/(В·с)
```

Крок 4. Синтез низькопольової поверхневої рухливості за правилом Маттіссена:
```
1 / μ_surface
= 1 / μ_bulk + 1 / μ_ac + 1 / μ_sr
= 1 / 733.51 + 1 / 1069.46 + 1 / 23280.0
= 0.0013633 + 0.0009350 + 0.0000430
= 0.0023413 (В·с)/см²

μ_surface = 1 / 0.0023413 = 427.11 см²/(В·с)    [поверхнева деградація на 41.8% від об'єму]
```

Крок 5. Врахування сильного поздовжнього поля стоку за моделлю Каналі (`v_sat = 1.07 × 10⁷ см/с`, `β = 1.11`, `E_parallel = 3.0 × 10⁴ В/см`):
```
μ_surface · E_parallel / v_sat
= (427.11 · 3.0 × 10⁴) / (1.07 × 10⁷)
= (1.2813 × 10⁷) / (1.07 × 10⁷)
= 1.1975                                         [відношення до швидкості насичення]

Польовий знаменник = [ 1 + (1.1975)^1.11 ]^(1 / 1.11)
                   = [ 1 + 1.2227 ]^0.9009
                   = [ 2.2227 ]^0.9009 = 2.0514

μ_final = 427.11 / 2.0514 = 208.20 см²/(В·с)     [підсумкова ефективна рухливість носія]
```

Крок 6. Результуюча дрейфова швидкість:
```
v_d = μ_final · E_parallel
    = 208.20 · 3.0 × 10⁴
    = 6.246 × 10⁶ см/с                          [58.4% від абсолютної швидкості насичення v_sat]
```

### 5.3. Приклад 3: Порівняльний розрахунок дрейфу в сильному полі для GaN HEMT та Si LDMOS

**Умова:**
Порівняти дрейфову швидкість електронів у потужному надвисокочастотному транзисторі на нітриді галію (`GaN`, `μ_low = 1500 см²/(В·с)`, `v_sat = 2.5 × 10⁷ см/с`, `β = 1.0`) та кремнієвому силовому LDMOS (`Si`, `μ_low = 1000 см²/(В·с)`, `v_sat = 1.07 × 10⁷ см/с`, `β = 1.11`) при напруженості поздовжнього поля в області дрейфу `E = 8.0 × 10⁴ В/см`.

**Розрахунок для Si LDMOS:**
```
1. Нормований дрейфовий параметр = (1000 · 8.0 × 10⁴) / (1.07 × 10⁷) = 8.0 × 10⁷ / 1.07 × 10⁷ = 7.4766
2. Знаменник Каналі = [ 1 + (7.4766)^1.11 ]^(1 / 1.11) = [ 1 + 9.380 ]^0.9009 = [ 10.380 ]^0.9009 = 8.2435
3. Польова рухливість μ_Si = 1000 / 8.2435 = 121.31 см²/(В·с)
4. Дрейфова швидкість v_d_Si = 121.31 · 8.0 × 10⁴ = 9.705 × 10⁶ см/с  (90.7% від v_sat)
```

**Розрахунок для GaN HEMT:**
```
1. Нормований дрейфовий параметр = (1500 · 8.0 × 10⁴) / (2.5 × 10⁷) = 1.20 × 10⁸ / 2.5 × 10⁷ = 4.8000
2. Знаменник Коугі-Томаса (β = 1.0) = 1 + 4.8000 = 5.8000
3. Польова рухливість μ_GaN = 1500 / 5.8000 = 258.62 см²/(В·с)
4. Дрейфова швидкість v_d_GaN = 258.62 · 8.0 × 10⁴ = 2.069 × 10⁷ см/с  (82.8% від v_sat)
```

**Висновки розрахунку:**
При однаковому електричному полі `80 кВ/см` швидкість носіїв у нітриді галію перевищує кремнієвий показник у `2.13 рази` (`2.069 × 10⁷ см/с` проти `0.9705 × 10⁷ см/с`). Це забезпечує вдвічі менший час прольоту носіїв крізь область просторового заряду і підтверджує перевагу GaN у силових НВЧ перемикачах на частотах понад `10 ГГц`.

### 5.4. Приклад 4: Вплив розсіяння на м'яких оптичних фононах High-k діелектрика в FinFET

**Умова:**
У 7-нм FinFET каналі кремнієвого транзистора діелектрик затвора `SiO₂` замінено на стек `SiO₂/HfO₂`. Ефективна діелектрична проникність оксиду зросла, але з'явилося розсіяння на м'яких оптичних фононах діелектрика з ефективною рухливістю `μ_remote_ph = 600 см²/(В·с)`. Об'ємна та поверхнева рухливості становлять `μ_bulk = 800 см²/(В·с)`, `μ_ac = 900 см²/(В·с)`, `μ_sr = 1200 см²/(В·с)`. Оцінити підсумкову деградацію рухливості за правилом Маттіссена.

**Покроковий розрахунок:**

Крок 1. Рухливість без High-k діелектрика (стандартний оксид `SiO₂`):
```
1 / μ_SiO2
= 1 / μ_bulk + 1 / μ_ac + 1 / μ_sr
= 1 / 800 + 1 / 900 + 1 / 1200
= 0.001250 + 0.001111 + 0.000833
= 0.003194 (В·с)/см²

μ_SiO2 = 1 / 0.003194 = 313.09 см²/(В·с)
```

Крок 2. Рухливість із врахуванням High-k стека `HfO₂`:
```
1 / μ_High_k
= 1 / μ_SiO2 + 1 / μ_remote_ph
= 0.003194 + 1 / 600
= 0.003194 + 0.001667
= 0.004861 (В·с)/см²

μ_High_k = 1 / 0.004861 = 205.72 см²/(В·с)
```

**Висновок:**
Впровадження High-k діелектрика знижує рухливість носіїв на `34.3%` внаслідок дипольного розсіяння на низькочастотних коливаннях решітки `HfO₂`, що компенсується у FinFET геометрії зменшенням еквівалентної товщини оксиду (EOT) та зростанням ємності затвора.

### 5.5. Приклад 5: Розрахунок рухливості в умовах ультрависокого легування за моделлю Масетті

**Умова:**
Розрахувати рухливість електронів у сильнолегованому витоку кремнієвого транзистора, легованому миш'яком до концентрації `N_d = 2.0 × 10²⁰ см⁻³` (`N_a = 0`), при `T = 300 К`. Порівняти результати моделей Коугі — Томаса та Масетті.

**Розрахунок за моделлю Коугі — Томаса:**
```
N_total / N_ref = (2.0 × 10²⁰) / (9.68 × 10¹⁶) = 2066.12
Знаменник = 1 + (2066.12)^0.680 = 1 + 179.35 = 180.35
μ_CT = 65.0 + (1417.0 - 65.0) / 180.35 = 65.0 + 7.50 = 72.50 см²/(В·с)
```

**Розрахунок за моделлю Масетті:**
Параметри для As у Si: `μ_0 = 1414.0`, `μ_min1 = 52.2`, `μ_min2 = 52.2`, `C_cr = 9.68 × 10¹⁶`, `C_cr2 = 3.43 × 10¹⁹`, `P_c = 0`, `α = 0.680`, `β = 2.0`.

```
Доданок 1 = μ_min1 · exp(- 0) = 52.20 см²/(В·с)

Доданок 2 = (1414.0 - 52.2) / [ 1 + (2.0 × 10²⁰ / 9.68 × 10¹⁶)^0.680 ]
          = 1361.8 / 180.35 = 7.55 см²/(В·с)

Доданок 3 (кластеризація) = μ_min2 / [ 1 + (C_cr2 / N_total)^β ]
                         = 52.2 / [ 1 + (3.43 × 10¹⁹ / 2.0 × 10²⁰)² ]
                         = 52.2 / [ 1 + (0.1715)² ]
                         = 52.2 / [ 1 + 0.0294 ]
                         = 52.2 / 1.0294 = 50.71 см²/(В·с)

μ_Masetti = Доданок 1 + Доданок 2 - Доданок 3
          = 52.20 + 7.55 - 50.71
          = 9.04 см²/(В·с)
```

**Висновок:**
Модель Коугі — Томаса при `N_d = 2 × 10²⁰ см⁻³` прогнозує `72.5 см²/(В·с)`, завищуючи рухливість у `8 разів` порівняно з експериментально верифікованою моделлю Масетті (`9.04 см²/(В·с)`). Це доводить критичну необхідність використання моделі Масетті при проектуванні омічних контактів та ультранеглибоких переходів сучасних транзисторів.

### 4.2. Математичні інваріанти та алгоритмічні гарантії чисельної збіжності

Для забезпечення монотонної та квадратичної збіжності розв'язувача Ньютона — Рафсона функції рухливості повинні задовольняти наступні чисельні інваріанти:

1. **Неперервність класу `C¹` за електричним полем:**
   Функція польової рухливості `μ(E)` та її перша похідна `∂μ / ∂E` повинні бути строго неперервними на всьому інтервалі `E ∈ [0, ∞)`. Для усунення невизначеності типу `0/0` при `E → 0` похідна обчислюється через аналітичну границю:
   ```
   lim_{E → 0} (∂v_d / ∂E) = μ_low
   lim_{E → 0} (∂μ / ∂E)   = 0
   ```

2. **Строга додатність рухливості:**
   Для будь-яких комбінацій вхідних параметрів `T`, `N_total`, `E` значення рухливості повинно задовольняти строгу умову:
   ```
   μ_calc ≥ μ_absolute_min > 0
   ```
   де `μ_absolute_min = 1.0 см²/(В·с)` — захисний поріг від ділення на нуль у рівнянні дифузії.

3. **Векторна ортогоналізація полів на межах розділу:**
   При розрахунку поверхневих моделей повний вектор електричного поля `E` у кожному вузлі розкладається на нормальну складову `E_perp = |E · n_interface|` (де `n_interface` — одиничний вектор нормалі до найближчої діелектричної межі) та поздовжню складову `E_parallel = |E - (E · n_interface) · n_interface|`. Поверхнева рухливість розраховується за `E_perp`, після чого насичення швидкості обчислюється за `E_parallel`:
   ```
   μ_final = μ_surface(E_perp) / [ 1 + (μ_surface(E_perp) · E_parallel / v_sat)^β ]^(1 / β)
   ```

4. **Кріогенне замерзання домішок (Carrier Freeze-out):**
   При температурах `T < 150 К` концентрація іонізованих домішок `N_d⁺` менша за загальну металургійну концентрацію `N_d` через локалізацію електронів на донорних рівнях з енергією іонізації `ΔE_d`:
   ```
   N_d⁺ = N_d / [ 1 + g_d · exp((E_F - E_d) / (k_B T)) ]
   ```
   де `g_d = 2` — фактор виродження донорного рівня. Усі формули розсіяння повинні використовувати саме активну іонізовану концентрацію `N_d⁺`.

## 5. Покрокові числові приклади розрахунку параметрів

### 5.1. Приклад 1: Низькопольова рухливість у кремнієвій базі n-p-n транзистора

**Умова:**
Розрахувати низькопольову рухливість дірок `μ_p` у базовій області кремнієвого транзистора, легованій бором з концентрацією `N_a = 2.5 × 10¹⁷ см⁻³` (`N_d = 0`), при кімнатній температурі `T = 300 К` та при підвищеній температурі `T = 400 К`.

**Розрахунок за моделлю Коугі — Томаса:**

Крок 1. Вихідні параметри для дірок у кремнії: `μ_min = 47.7 см²/(В·с)`, `μ_max = 470.5 см²/(В·с)`, `N_ref = 2.23 × 10¹⁷ см⁻³`, `α = 0.719`.

Крок 2. Обчислення відношення концентрацій при `T = 300 К`:
```
N_total / N_ref
= (2.50 × 10¹⁷) / (2.23 × 10¹⁷)
= 1.1211                          [нормоване допування]
```

Крок 3. Обчислення знаменника формули:
```
1 + (N_total / N_ref)^α
= 1 + (1.1211)^0.719
= 1 + 1.0857
= 2.0857                          [кулонівський фактор екранування]
```

Крок 4. Розрахунок рухливості при `T = 300 К`:
```
μ_p(300 K)
= 47.7 + (470.5 - 47.7) / 2.0857
= 47.7 + 422.8 / 2.0857
= 47.7 + 202.71
= 250.41 см²/(В·с)                [результуюча низькопольова рухливість]
```

Крок 5. Температурний перерахунок для `T = 400 К` (`T / 300 = 1.3333`):
```
μ_max(400 K) = 470.5 · (1.3333)^(- 2.20) = 470.5 · 0.5309 = 249.79 см²/(В·с)
μ_min(400 K) = 47.7  · (1.3333)^(- 0.50) = 47.7  · 0.8660 = 41.31 см²/(В·с)
N_ref(400 K) = (2.23 × 10¹⁷) · (1.3333)^(- 0.70) = (2.23 × 10¹⁷) · 0.8179 = 1.824 × 10¹⁷ см⁻³
```

Крок 6. Розрахунок рухливості при `T = 400 К`:
```
N_total / N_ref(400 K) = (2.50 × 10¹⁷) / (1.824 × 10¹⁷) = 1.3706
Знаменник = 1 + (1.3706)^0.719 = 1 + 1.2536 = 2.2536
μ_p(400 K)
= 41.31 + (249.79 - 41.31) / 2.2536
= 41.31 + 208.48 / 2.2536
= 41.31 + 92.51
= 133.82 см²/(В·с)                [деградація на 46.5% внаслідок нагріву]
```

### 5.2. Приклад 2: Дрейфова швидкість електронів у субмікронному каналі Si MOSFET

**Умова:**
В інверсійному каналі n-MOSFET транзистора при `T = 300 К` та легуванні підкладки `N_a = 1.0 × 10¹⁷ см⁻³` нормальне поле затвора становить `E_perp = 5.0 × 10⁵ В/см`, а поздовжнє тягнуче поле стоку дорівнює `E_parallel = 3.0 × 10⁴ В/см`. Розрахувати ефективну польову рухливість та дрейфову швидкість електронів з урахуванням поверхневих ефектів Ломбарді та насичення швидкості Каналі.

**Покроковий розрахунок:**

Крок 1. Об'ємна низькопольова рухливість у підкладці за моделлю Коугі — Томаса:
```
N_total / N_ref = (1.0 × 10¹⁷) / (9.68 × 10¹⁶) = 1.033
Знаменник = 1 + (1.033)^0.680 = 1 + 1.0224 = 2.0224
μ_bulk = 65.0 + (1417.0 - 65.0) / 2.0224 = 65.0 + 668.51 = 733.51 см²/(В·с)
```

Крок 2. Розрахунок поверхневого фононного компонента `μ_ac` за моделлю Ломбарді (`E_perp = 5.0 × 10⁵ В/см`):
```
Доданок 1 = B / E_perp = (4.75 × 10⁷) / (5.0 × 10⁵) = 95.00 см²/(В·с)
Доданок 2 = ( C · N_total^η ) / ( E_perp^(1/3) · (T/300) )
          = ( 580 · (10¹⁷)^0.125 ) / ( (5.0 × 10⁵)^(1/3) )
          = ( 580 · 133.35 ) / ( 79.37 )
          = 77343 / 79.37 = 974.46 см²/(В·с)
μ_ac = 95.00 + 974.46 = 1069.46 см²/(В·с)
```

Крок 3. Розрахунок поверхневої шорсткості `μ_sr`:
```
μ_sr = δ / E_perp² = (5.82 × 10¹⁸) / (5.0 × 10⁵)² = (5.82 × 10¹⁸) / (2.50 × 10¹¹) = 23280.0 см²/(В·с)
```

Крок 4. Синтез низькопольової поверхневої рухливості за правилом Маттіссена:
```
1 / μ_surface
= 1 / μ_bulk + 1 / μ_ac + 1 / μ_sr
= 1 / 733.51 + 1 / 1069.46 + 1 / 23280.0
= 0.0013633 + 0.0009350 + 0.0000430
= 0.0023413 (В·с)/см²

μ_surface = 1 / 0.0023413 = 427.11 см²/(В·с)    [поверхнева деградація на 41.8% від об'єму]
```

Крок 5. Врахування сильного поздовжнього поля стоку за моделлю Каналі (`v_sat = 1.07 × 10⁷ см/с`, `β = 1.11`, `E_parallel = 3.0 × 10⁴ В/см`):
```
μ_surface · E_parallel / v_sat
= (427.11 · 3.0 × 10⁴) / (1.07 × 10⁷)
= (1.2813 × 10⁷) / (1.07 × 10⁷)
= 1.1975                                         [відношення до швидкості насичення]

Польовий знаменник = [ 1 + (1.1975)^1.11 ]^(1 / 1.11)
                   = [ 1 + 1.2227 ]^0.9009
                   = [ 2.2227 ]^0.9009 = 2.0514

μ_final = 427.11 / 2.0514 = 208.20 см²/(В·с)     [підсумкова ефективна рухливість носія]
```

Крок 6. Результуюча дрейфова швидкість:
```
v_d = μ_final · E_parallel
    = 208.20 · 3.0 × 10⁴
    = 6.246 × 10⁶ см/с                          [58.4% від абсолютної швидкості насичення v_sat]
```

### 5.3. Приклад 3: Порівняльний розрахунок дрейфу в сильному полі для GaN HEMT та Si LDMOS

**Умова:**
Порівняти дрейфову швидкість електронів у потужному надвисокочастотному транзисторі на нітриді галію (`GaN`, `μ_low = 1500 см²/(В·с)`, `v_sat = 2.5 × 10⁷ см/с`, `β = 1.0`) та кремнієвому силовому LDMOS (`Si`, `μ_low = 1000 см²/(В·с)`, `v_sat = 1.07 × 10⁷ см/с`, `β = 1.11`) при напруженості поздовжнього поля в області дрейфу `E = 8.0 × 10⁴ В/см`.

**Розрахунок для Si LDMOS:**
```
1. Нормований дрейфовий параметр = (1000 · 8.0 × 10⁴) / (1.07 × 10⁷) = 8.0 × 10⁷ / 1.07 × 10⁷ = 7.4766
2. Знаменник Каналі = [ 1 + (7.4766)^1.11 ]^(1 / 1.11) = [ 1 + 9.380 ]^0.9009 = [ 10.380 ]^0.9009 = 8.2435
3. Польова рухливість μ_Si = 1000 / 8.2435 = 121.31 см²/(В·с)
4. Дрейфова швидкість v_d_Si = 121.31 · 8.0 × 10⁴ = 9.705 × 10⁶ см/с  (90.7% від v_sat)
```

**Розрахунок для GaN HEMT:**
```
1. Нормований дрейфовий параметр = (1500 · 8.0 × 10⁴) / (2.5 × 10⁷) = 1.20 × 10⁸ / 2.5 × 10⁷ = 4.8000
2. Знаменник Коугі-Томаса (β = 1.0) = 1 + 4.8000 = 5.8000
3. Польова рухливість μ_GaN = 1500 / 5.8000 = 258.62 см²/(В·с)
4. Дрейфова швидкість v_d_GaN = 258.62 · 8.0 × 10⁴ = 2.069 × 10⁷ см/с  (82.8% від v_sat)
```

**Висновок:**
При однаковому електричному полі `80 кВ/см` швидкість носіїв у нітриді галію перевищує кремнієвий показник у `2.13 рази` (`2.069 × 10⁷ см/с` проти `0.9705 × 10⁷ см/с`), що забезпечує пропорційно менший час прольоту носіїв крізь область просторового заряду і пояснює перевагу GaN у силових НВЧ комутаторах з робочими частотами понад `10 ГГц`.

## 6. Зведені рекомендації щодо вибору моделей у TCAD проектуванні

Під час побудови чисельних моделей напівпровідникових структур у середовищах Silvaco ATLAS, Synopsys Sentaurus та Cogenda Genius комплекс моделей рухливості обирають відповідно до фізичного типу приладу та домінуючих режимів перенесення:

| Клас напівпровідникового приладу | Рекомендований низькопольовий блок | Блок сильного поля | Поверхневий / квантовий блок | Обґрунтування вибору |
| :--- | :--- | :--- | :--- | :--- |
| **Планарні субмікронні MOSFET** | Масетті (витоки/стоки) + Коугі — Томас (тіло) | Каналі (Canali) | Ломбарді (CVT) або Дарвіш | Врахування деградації на шорсткості оксиду `μ_sr` та насичення швидкості |
| **FinFET, GAAFET, нанодроти** | Масетті + Клаассен (UMM) | Каналі з корекцією `β` | 2D/1D квантова модель розсіяння | Домінування багатоповерхневого розсіяння та квантового обмеження |
| **Силові діоди, IGBT, тиристори** | Уніфікована модель Клаассена (UMM) | Каналі / Коугі — Томас | Не потрібен (об'ємний дрейф) | Врахування носій-носійного розсіяння `μ_e_h` при високих густинах струму |
| **Високовольтні SiC MOSFET та SBD** | Коугі — Томас для 4H-SiC | Модель Коугі — Томаса (`β = 1.0`) | Модель поверхневих пасток Hatakeyama | Висока щільність пасток `D_it` на межі `4H-SiC/SiO₂` |
| **НВЧ гетеротранзистори GaN HEMT** | Модель решіткового розсіяння 2DEG | Модель Джилса (NDM) | Поляризаційна модель розсіяння | Наявність двовимірного газу на гетеромежі `AlGaN/GaN` та ефектів NDM |
| **Фотодіоди, сонячні елементи** | Клаассен UMM + Арора | Стандартний Коугі — Томас | Поверхнева рекомбінація | Точний розрахунок дифузійних довжин при оптичній генерації |
