# 🧮 Квантово-механічна теорія розсіяння носіїв та доведення правила Маттіссена

Ця вставка містить суворе квантово-механічне та статистичне виведення коефіцієнта рухливості носіїв заряду з кінетичного рівняння Больцмана, фундаментальне розмежування квантового часу життя стану та транспортного часу релаксації імпульсу, точний розрахунок інтенсивностей розсіяння на екранованих іонізованих домішках (моделі Брукса — Геррінга та Конуелл — Вайскопфа), акустичних деформаційних та полярних оптичних фононах, п'єзоелектричних полях і двовимірній шорсткості гетеромеж, а також математичне дослідження похибки правила Маттіссена та кінетики гарячих носіїв у сильних полях.

## 1. Рівняння Больцмана, квантовий час життя та час релаксації імпульсу

У квазікласичному наближенні кінетичної теорії стан електронного ансамблю в кристалі описується одночастинковою функцією розподілу `f(r, p, t)`, яка визначає ймовірність знаходження електрона в елементі шестивимірного фазового об'єму `d³r d³p` поблизу координати `r` та квазіімпульсу `p = ℏk`. 

Повна похідна функції розподілу за часом описує перенесення частинок у фазовому просторі під дією зовнішніх сил та зіткнень, що виражається кінетичним рівнянням Больцмана:

```
df / dt
= ∂f/∂t + v · ∇_r f + q · E · ∇_p f    [повна конвективна похідна у фазовому просторі]
= (∂f/∂t)_coll                        [швидкість зміни розподілу внаслідок зіткнень]
```

де `v = (1/ℏ) · ∇_k E(k)` — групова швидкість блохівського електрона, `E` — напруженість зовнішнього електричного поля, `q` — заряд носія (`-e` для електрона, `+e` для дірки), а `(∂f/∂t)_coll` — інтеграл зіткнень.

У загальному квантовому вигляді інтеграл зіткнень враховує баланс прямих переходів зі станів `k'` у стан `k` («прихід») та зворотних переходів зі стану `k` у стани `k'` («відхід»):

```
(∂f/∂t)_coll
= ∫ [ W(k', k) · f(k') · (1 - f(k)) - W(k, k') · f(k) · (1 - f(k')) ] · (d³k' / (2π)³)
```

де `W(k, k')` — мікроскопічна ймовірність квантового переходу за одиницю часу зі стану `k` у стан `k'`, а множники `(1 - f)` враховують принцип заборони Паулі для ферміонів.

У стані термодинамічної рівноваги функція розподілу перетворюється на рівноважну функцію Фермі — Дірака `f_0(E) = [ 1 + exp((E - E_F) / (k_B T)) ]⁻¹`, а інтеграл зіткнень тотожно перетворюється на нуль завдяки принципу детального квантового балансу:

```
f_0(k) · (1 - f_0(k')) · W(k, k')
= f_0(k') · (1 - f_0(k)) · W(k', k)
```

Для невиродженого електронного газу (`f ≪ 1`, тобто `1 - f ≈ 1`) або для пружних зіткнень (`W(k, k') = W(k', k)`), інтеграл зіткнень спрощується:

```
(∂f/∂t)_coll
= ∫ W(k, k') · [ f(k') - f(k) ] · (d³k' / (2π)³)
```

### Розмежування квантового та транспортного часів релаксації

У квантовій теорії кінетичних явищ суворо розрізняють два фундаментальні часи релаксації, які мають принципово різний фізичний зміст:

1. **Квантовий час життя стану `τ_q` (quantum scattering lifetime)**:
Визначає повну швидкість виходу електрона зі стану `k` у будь-які інші кінцеві стани `k'` у результаті будь-якого зіткнення:

```
1 / τ_q 
= ∫ W(k, k') · (d³k' / (2π)³)          [інтегрування за всіма кінцевими станами k']
= ∫ W(k, k') · dΩ                      [перехід до інтегрування за тілесним кутом]
```

Квантовий час `τ_q` визначає квантове заширювання енергетичних рівнів за принципом невизначеності Гейзенберга `ΔE ≈ ℏ / τ_q`, розмиття рівнів Ландау в магнітному полі та згасання амплітуди осциляцій Шубнікова — де Гааза, що характеризується температурою Дінґла `T_D = ℏ / (2π · k_B · τ_q)`. Будь-яке розсіяння, навіть на нескінченно малий кут `θ → 0`, повністю руйнує квантовий стан `k`.

2. **Транспортний час релаксації імпульсу `τ_m` (momentum relaxation time)**:
Визначає швидкість дисипації спрямованого квазіімпульсу та згасання макроскопічного електричного струму вздовж напрямку зовнішнього поля. Він містить кутовий ваговий фактор `(1 - cos θ)`:

```
1 / τ_m 
= ∫ W(k, k') · (1 - cos θ) · (d³k' / (2π)³)    [зважування на частку втраченого імпульсу]
= ∫ W(k, k') · (1 - cos θ) · dΩ                [інтегрування за сферою розсіяння]
```

де `θ` — кут розсіяння між початковим хвильовим вектором `k` та кінцевим вектором `k'`. 

Геометричний фактор `(1 - cos θ)` показує частку втраченого поздовжнього імпульсу:
- При розсіянні вперед на малий кут (`θ ≈ 0`): `1 - cos θ ≈ θ² / 2 → 0`. Електрон практично зберігає свій початковий напрямок руху, тому макроскопічний струм не гальмується.
- При розсіянні під прямим кутом (`θ = π/2`): `1 - cos(π/2) = 1`. Електрон повністю втрачає початкову складову імпульсу вздовж поля.
- При зворотному розсіянні назад (`θ = π`): `1 - cos(π) = 2`. Напрямок швидкості змінюється на протилежний, що дає подвійний внесок у гальмування струму.

Для ізотропного розсіяння (наприклад, на деформаційному потенціалі акустичних фононів) середнє `⟨cos θ⟩ = 0`, тому `τ_m = τ_q`. Однак при домінуванні розсіяння на кулонівських центрах або при розсіянні в просторово модульованих двовимірних гетероструктурах переважає розсіяння вперед на малі кути, через що транспортний час може перевищувати квантовий у десятки разів: `τ_m / τ_q ≈ 10–100`.

### Лінеаризація рівняння Больцмана та закон Ома

У слабкому електричному полі функція розподілу відхиляється від рівноважної на малу анізотропну поправку `f_1(k)`:

```
f(k) = f_0(E) + f_1(k),    де |f_1(k)| ≪ f_0(E)
```

У стаціонарному та просторово однорідному випадку ліва частина кінетичного рівняння набуває вигляду:

```
q · E · ∇_p f
≈ q · E · ∇_p f_0(E)                   [нехтування похідною від малого збурення f_1]
= q · (E · ∇_p E) · (∂f_0 / ∂E)        [диференціювання складеної функції f_0(E(p))]
= q · (E · v) · (∂f_0 / ∂E)            [визначення групової швидкості v = ∇_p E]
```

У наближенні часу релаксації імпульсу інтеграл зіткнень зводиться до релаксації збурення `f_1`:

```
(∂f/∂t)_coll = - f_1(k) / τ_m(E)
```

Прирівнюючи польовий член до інтеграла зіткнень, знаходимо стаціонарну анізотропну поправку функції розподілу:

```
f_1(k)
= - q · τ_m(E) · (v · E) · (∂f_0 / ∂E)    [лінеаризоване збурення функції розподілу]
```

Густина електричного струму `j` обчислюється як інтеграл за станами всієї зони Бріллюена:

```
j 
= - (q / 4π³) · ∫ v(k) · f(k) · d³k                     [інтегрування густини заряду та швидкості]
= - (q / 4π³) · ∫ v(k) · [ f_0(E) + f_1(k) ] · d³k      [розклад функції розподілу на f_0 та f_1]
= - (q / 4π³) · ∫ v(k) · f_1(k) · d³k                   [інтеграл від парної f_0 за непарною v дорівнює нулю]
```

Підставляючи вираз для `f_1(k)`:

```
j
= (q² / 4π³) · ∫ v(k) · [ τ_m(E) · (v(k) · E) · (- ∂f_0 / ∂E) ] · d³k
```

Для ізотропної параболічної зони зі сферичними ізоенергетичними поверхнями `E = ℏ² k² / (2 m*)` кутове інтегрування добутку компонентів швидкості дає `⟨v_i · v_j⟩ = (1/3) · v² · δ_{ij}`, де `v² = 2 E / m*`. Переходячи до інтегрування за енергіями з урахуванням тривимірної густини станів `g(E) = (m*³ᐟ² · √E) / (√2 · π² · ℏ³)`:

```
j
= [ (2 · q² / (3 · m*)) · ∫₀^∞ g(E) · E · τ_m(E) · (- ∂f_0 / ∂E) · dE ] · E    [інтегрування за кутами сферичної зони]
= σ · E                                                                        [макроскопічний диференціальний закон Ома]
```

Звідси питома електропровідність дорівнює `σ = q · n · μ`, де дрейфова рухливість виражається через статистично усереднений час релаксації імпульсу:

```
μ 
= q · ⟨τ_m⟩ / m*                          [фундаментальний зв'язок Друде — Больцмана]
```

## 2. Статистичне усереднення часу релаксації

Формула зв'язку провідності та рухливості вимагає точного статистичного усереднення залежного від енергії часу релаксації `τ(E)` за ансамблем носіїв:

```
⟨τ⟩
= (∫₀^∞ τ(E) · E³ᐟ² · (- ∂f_0 / ∂E) · dE) / (∫₀^∞ E³ᐟ² · (- ∂f_0 / ∂E) · dE)
```

Інтегруючи знаменник по частинах при умові `f_0(∞) = 0` та `E³ᐟ² · f_0(E) → 0` при `E → 0`:

```
∫₀^∞ E³ᐟ² · (- ∂f_0 / ∂E) · dE
= [ - E³ᐟ² · f_0(E) ]₀^∞ + (3/2) · ∫₀^∞ E¹ᐟ² · f_0(E) · dE    [інтегрування по частинах за енергією]
= (3/2) · ∫₀^∞ E¹ᐟ² · f_0(E) · dE                             [підстановка нульових граничних значень]
```

Для невиродженого електронного газу функція розподілу описується статистикою Максвелла — Больцмана `f_0(E) = exp(-(E - E_F) / (k_B T))`. Її похідна за енергією дорівнює:

```
- ∂f_0 / ∂E
= (1 / (k_B T)) · exp(-(E - E_F) / (k_B T))    [похідна експоненти максвеллівського розподілу]
= (1 / (k_B T)) · f_0(E)                       [зв'язок похідної з функцією розподілу]
```

Вводячи безрозмірну кінетичну енергію `x = E / (k_B T)`, інтеграл знаменника зводиться до значення гамма-функції Ейлера `Γ(3/2) = (1/2) · √π`:

```
∫₀^∞ E¹ᐟ² · f_0(E) · dE
= (k_B T)³ᐟ² · ∫₀^∞ x¹ᐟ² · exp(-x) · dx    [перехід до безрозмірної змінної x = E / (k_B T)]
= (k_B T)³ᐟ² · Γ(3/2)                      [означення гамма-функції Ейлера Γ(z)]
= (1/2) · √π · (k_B T)³ᐟ²                  [значення гамма-функції Γ(3/2) = (1/2) · √π]
```

Тоді повний знаменник дорівнює `(3/2) · (1/2) · √π · (k_B T)³ᐟ² = (3/4) · √π · (k_B T)³ᐟ²`.

Підставляючи цей вираз у загальне означення усереднення, отримуємо робочу формулу статистичного усереднення для невироджених носіїв:

```
⟨τ⟩
= (4 / (3 · √π)) · ∫₀^∞ τ(x · k_B T) · x³ᐟ² · exp(-x) · dx
```

### Аналітичне усереднення для степеневих законів розсіяння

Якщо мікроскопічний час релаксації має степеневу залежність від кінетичної енергії електрона `τ(E) = τ_0 · (E / (k_B T))^s = τ_0 · x^s`, інтеграл обчислюється через гамма-функцію `Γ(z) = ∫₀^∞ x^(z-1) · exp(-x) · dx`:

```
⟨τ⟩
= τ_0 · (4 / (3 · √π)) · ∫₀^∞ x^(s + 3/2) · exp(-x) · dx    [підстановка степеневого закону τ(x) = τ_0 · x^s]
= τ_0 · (4 / (3 · √π)) · Γ(s + 5/2)                         [інтегрування через гамма-функцію Ейлера]
```

Розглянемо точні значення усереднення для ключових фізичних механізмів:

1. **Розсіяння на акустичних фононах (`s = -1/2`)**:
```
⟨τ_ac⟩
= τ_0 · (4 / (3 · √π)) · Γ(-1/2 + 5/2)    [підстановка показника s = -1/2 для акустичних фононів]
= τ_0 · (4 / (3 · √π)) · Γ(2)             [обчислення аргументу гамма-функції: -1/2 + 5/2 = 2]
= τ_0 · (4 / (3 · √π)) · 1!               [властивість факторіала для цілих чисел Γ(n) = (n-1)!]
= (4 / (3 · √π)) · τ_0                    [спрощення коефіцієнта]
≈ 0.752 · τ_0                             [числове значення коефіцієнта]
```

2. **Розсіяння на іонізованих домішках (`s = +3/2`)**:
```
⟨τ_imp⟩
= τ_0 · (4 / (3 · √π)) · Γ(3/2 + 5/2)     [підстановка показника s = 3/2 для іонізованих домішок]
= τ_0 · (4 / (3 · √π)) · Γ(4)             [обчислення аргументу гамма-функції: 3/2 + 5/2 = 4]
= τ_0 · (4 / (3 · √π)) · 3!               [значення факторіала Γ(4) = 3! = 6]
= τ_0 · (4 / (3 · √π)) · 6                [підстановка факторіала]
= (8 / √π) · τ_0                          [скорочення коефіцієнта на 3]
≈ 4.514 · τ_0                             [числове значення коефіцієнта]
```

3. **П'єзоелектричне розсіяння (`s = +1/2`)**:
```
⟨τ_pe⟩
= τ_0 · (4 / (3 · √π)) · Γ(1/2 + 5/2)     [підстановка показника s = 1/2 для п'єзоелектрики]
= τ_0 · (4 / (3 · √π)) · Γ(3)             [обчислення аргументу гамма-функції: 1/2 + 5/2 = 3]
= τ_0 · (4 / (3 · √π)) · 2!               [значення факторіала Γ(3) = 2! = 2]
= (8 / (3 · √π)) · τ_0                    [множення на чисельник]
≈ 1.505 · τ_0                             [числове значення коефіцієнта]
```

4. **Розсіяння на нейтральних домішках та флуктуаціях сплаву (`s = 0`, `τ(E) = const`)**:
```
⟨τ_neutral⟩
= τ_0 · (4 / (3 · √π)) · Γ(5/2)             [підстановка показника s = 0 для нейтральних центрів]
= τ_0 · (4 / (3 · √π)) · ((3/4) · √π)       [значення Γ(5/2) = (3/2) · (1/2) · √π = (3/4) · √π]
= τ_0                                       [точне взаємне скорочення коефіцієнтів]
```

### Вироджений електронний газ

Для сильно виродженого газу носіїв (високий рівень легування або гетероструктури з двовимірним електронним газом при низьких температурах) енергія Фермі `E_F ≫ k_B T`. 

У цій границі похідна функції Фермі перетворюється на дельта-функцію Дірака, зосереджену на рівні Фермі:

```
- ∂f_0 / ∂E → δ(E - E_F)
```

Підстановка дельта-функції в інтеграл усереднення дає точну рівність:

```
⟨τ⟩ = τ(E_F)
```

Отже, кінетичні коефіцієнти та рухливість виродженого газу визначаються виключно часом релаксації електронів на поверхні Фермі:

```
μ = q · τ(E_F) / m*
```

## 3. Квантово-механічне золоте правило Фермі та борнівське наближення

Квантовий опис розсіяння електрона на локальному або розподіленому збуренні кристалічного потенціалу `V(r)` базується на нестаціонарній теорії збурень Дірака. Початковий та кінцевий стани електрона в кристалі описуються блохівськими хвильовими функціями:

```
ψ_k(r) = (1 / √V) · u_k(r) · exp(i k · r)
```

де `V` — нормувальний об'єм кристала, `u_k(r)` — періодична амплітуда Блоха.

За **золотим правилом Фермі** ймовірність переходу за одиницю часу між початковим станом `|k⟩` та кінцевим станом `|k'⟩` під дією збурення `V` становить:

```
W(k, k')
= (2π / ℏ) · |⟨k'| V |k⟩|² · δ(E(k') - E(k) ∓ ℏω_q)
```

де `δ(E)` забезпечує квантовий закон збереження повної енергії системи, а `ℏω_q` — енергія поглинутого чи випроміненого кванта збудження (фонона). Для пружного розсіяння `ℏω_q = 0`.

Матричний елемент квантового переходу обчислюється інтегруванням за об'ємом:

```
⟨k'| V |k⟩
= (1 / V) · ∫ exp(-i k' · r) · u_{k'}*(r) · V(r) · u_k(r) · exp(i k · r) · d³r
```

У наближенні повільно змінних огинаючих для станів поблизу дна зони (`k, k' ≪ π/a`), блохівські множники `u_k(r) ≈ u_{k'}(r)` інтегруються по елементарній комірці в одиницю внаслідок умови ортонормованості. Тоді матричний елемент зводиться до тривимірного просторового перетворення Фур'є розсіювального потенціалу (перше борнівське наближення):

```
⟨k'| V |k⟩
= (1 / V) · ∫ V(r) · exp(-i q · r) · d³r    [наближення плоских хвиль для дна зони]
= (1 / V) · V(q)                            [означення просторового Фур'є-образу V(q)]
```

де `q = k' - k` — переданий хвильовий вектор.

Диференціальний переріз квантового розсіяння `dσ / dΩ` пов'язаний із матричним елементом співвідношенням:

```
dσ / dΩ
= (V² · m*² / (4π² · ℏ⁴)) · |⟨k'| V |k⟩|²    [зв'язок перерізу з матричним елементом у борнівському наближенні]
= (m* / (2π · ℏ²))² · |V(q)|²                [підстановка Фур'є-образу V(q) = V · ⟨k'|V|k⟩]
```

Для ансамблю з об'ємною концентрацією незалежних розсіювачів `N_sc` транспортна частота зіткнень обчислюється інтегруванням перерізу:

```
1 / τ_m(E)
= N_sc · v · ∫ (1 - cos θ) · (dσ / dΩ) · dΩ                     [інтеграл зіткнень для ансамблю розсіювачів N_sc]
= 2π · N_sc · v · ∫₀^π (1 - cos θ) · (dσ / dΩ) · sin θ · dθ     [інтегрування за азимутальним кутом φ від 0 до 2π]
```

## 4. Розсіяння на іонізованих домішках: теорії Брукса — Геррінга та Конуелл — Вайскопфа

### Модель Брукса — Геррінга (екранований потенціал Юкави)

Коли в кристалі присутній іон домішки із зарядом `Z · q`, вільні електрони та дірки перерозподіляються в просторі, екрануючи кулонівське поле. 

Розподіл електростатичного потенціалу `Φ(r)` описується рівнянням Пуассона — Больцмана в лінійному наближенні:

```
∇² Φ - q_D² · Φ = - (Z · q / ε) · δ(r)
```

де `q_D = 1 / λ_D` — дебаївське хвильове число екранування. Радіус екранування Дебая для невиродженого напівпровідника дорівнює `λ_D = √( (ε · k_B T) / (q² · n) )`, а для виродженого — визначається радіусом Томаса — Фермі `λ_TF = √( (2 ε · E_F) / (3 q² · n) )`.

Розв'язком цього рівняння є центрально-симетричний потенціал Юкави:

```
V(r) = q · Φ(r) = (Z · q²) / (4π · ε · r) · exp(- q_D · r)
```

Обчислимо просторовий Фур'є-образ цього потенціалу у сферичних координатах `(r, θ_r, φ)`:

```
V(q_s)
= ∫₀^∞ r² dr ∫₀^π sin θ_r dθ_r ∫₀²π dφ · [ (Z · q²) / (4π · ε · r) · exp(- q_D · r) · exp(-i q_s · r · cos θ_r) ]    [тривимірний інтеграл Фур'є у сферичних координатах]
= (Z · q² / (4π · ε)) · 2π · ∫₀^∞ r · exp(- q_D · r) · [ ∫₀^π exp(-i q_s · r · cos θ_r) · sin θ_r · dθ_r ] · dr      [інтегрування за азимутальним кутом φ від 0 до 2π]
= (Z · q² / (2 · ε)) · ∫₀^∞ r · exp(- q_D · r) · [ (exp(i q_s · r) - exp(-i q_s · r)) / (i q_s · r) ] · dr           [інтегрування за полярним кутом θ_r]
= (Z · q² / (2 · ε · i · q_s)) · ∫₀^∞ [ exp(-(q_D - i q_s) · r) - exp(-(q_D + i q_s) · r) ] · dr                     [скорочення радіуса r під інтегралом]
= (Z · q² / (2 · ε · i · q_s)) · [ 1 / (q_D - i q_s) - 1 / (q_D + i q_s) ]                                            [взяття експоненціальних інтегралів на межах від 0 до ∞]
= (Z · q² / (2 · ε · i · q_s)) · [ (2 · i · q_s) / (q_s² + q_D²) ]                                                    [зведення до спільного знаменника]
= (Z · q²) / (ε · (q_s² + q_D²))                                                                                      [скорочення уявного множника 2 i q_s]
```

Квадрат матричного елемента розсіяння:

```
|⟨k'| V |k⟩|² = (Z² · q⁴) / [ ε² · V² · (q_s² + q_D²)² ]
```

Для пружного зіткнення `|k| = |k'| = k`, а переданий хвильовий вектор пов'язаний із кутом розсіяння `θ`:

```
q_s = 2 k · sin(θ / 2)
q_s² = 4 k² · sin²(θ / 2) = (8 m* · E / ℏ²) · sin²(θ / 2)
```

Підставляючи матричний елемент у формулу для диференціального перерізу розсіяння:

```
dσ / dΩ
= (m* / (2π · ℏ²))² · [ (Z · q²) / (ε · (4 k² · sin²(θ/2) + q_D²)) ]²          [підстановка Фур'є-образу екранованого кулонівського потенціалу]
= (Z² · q⁴ · m*²) / [ 4π² · ℏ⁴ · ε² · 16 k⁴ · (sin²(θ/2) + q_D² / (4 k²))² ]   [винесення множника (4 k²)² зі знаменника]
= (Z² · q⁴) / [ 16 · ε² · (2 E)² · (sin²(θ/2) + 1/b)² ]                         [підстановка енергії E = ℏ² k² / (2 m*) та параметра b = 4 k² / q_D²]
```

де безрозмірний параметр екранування Брукса — Геррінга дорівнює:

```
b = 4 k² / q_D² = (8 m* · E · λ_D²) / ℏ²
```

Інтегруємо транспортний час релаксації:

```
1 / τ_BH(E)
= 2π · N_i · v · ∫₀^π (1 - cos θ) · (dσ / dΩ) · sin θ · dθ
```

Використовуючи тотожності `1 - cos θ = 2 sin²(θ/2)` та `sin θ · dθ = 4 sin(θ/2) · cos(θ/2) · d(θ/2) = 2 · d(sin²(θ/2))`, робимо заміну змінної `u = sin²(θ/2)`, де межі інтегрування переходять від `0` до `1`:

```
1 / τ_BH(E)
= 2π · N_i · v · [ (Z² · q⁴) / (64 · ε² · E²) ] · ∫₀¹ [ 2 u / (u + 1/b)² ] · (2 du)          [заміна змінної u = sin²(θ/2) з якобіаном 2 du]
= [ (π · N_i · Z² · q⁴) / (8 · ε² · E² · (m* / (2 E))¹ᐟ²) ] · ∫₀¹ [ u / (u + 1/b)² ] · du   [підстановка швидкості електрона v = √(2 E / m*)]
= [ (π · N_i · Z² · q⁴) / (2³ᐟ² · ε² · m*¹ᐟ² · E³ᐟ²) ] · F_BH(b)                              [спрощення степеневих множників енергії та маси]
```

Інтеграл кутового екранування обчислюється аналітично:

```
∫₀¹ [ u / (u + 1/b)² ] · du
= ∫₀¹ [ (u + 1/b - 1/b) / (u + 1/b)² ] · du                     [виділення цілої частини в чисельнику]
= ∫₀¹ [ 1 / (u + 1/b) ] · du - (1/b) · ∫₀¹ [ 1 / (u + 1/b)² ] · du    [розбиття на два табличні інтеграли]
= [ ln(u + 1/b) ]₀¹ + (1/b) · [ 1 / (u + 1/b) ]₀¹               [первісні логарифма та степеневої функції]
= [ ln(1 + 1/b) - ln(1/b) ] + (1/b) · [ 1 / (1 + 1/b) - b ]     [підстановка верхньої та нижньої меж інтегрування]
= ln( (1 + 1/b) / (1/b) ) + (1/b) · [ b / (b + 1) - b ]         [властивість різниці логарифмів та спрощення дробу]
= ln(1 + b) + [ 1 / (1 + b) - 1 ]                               [скорочення множника 1/b]
= ln(1 + b) - b / (1 + b)                                       [зведення до спільного знаменника]
```

Таким чином, функція екранування Брукса — Геррінга набуває остаточного вигляду:

```
F_BH(b) = ln(1 + b) - b / (1 + b)
```

Час релаксації зростає з енергією як `τ_BH(E) ∝ E³ᐟ² / (N_i · F_BH(b))`. 

Виконуючи статистичне усереднення за розподілом Максвелла — Больцмана з підстановкою теплової енергії `E_th = 3 k_B T` у слабко змінний логарифмічний фактор, отримуємо формулу Брукса — Геррінга для рухливості:

```
μ_BH
= (2⁷ᐟ² · ε² · (k_B T)³ᐟ²) / (π³ᐟ² · Z² · q³ · m*¹ᐟ² · N_i · [ ln(1 + b_th) - b_th / (1 + b_th) ])
∝ ε² · T³ᐟ² / (m*¹ᐟ² · N_i)
```

де `b_th = (24 m* · ε · (k_B T)²) / (ℏ² · q² · n)`.

### Модель Конуелл — Вайскопфа (обрізання прицільного параметра)

Історично перша теорія Естер Конуелл та Віктора Вайскопфа (1950 р.) розглядає класичне резерфордівське розсіяння на чистому кулонівському потенціалі `V(r) = Z q² / (4π ε r)`. 

Щоб уникнути інфрачервоної розбіжності інтеграла розсіяння на великих відстанях, вводиться геометричне обрізання максимального прицільного параметра `b_max`, рівного половині середньої відстані між іонами домішки в кристалі:

```
b_max = 1 / (2 · N_i¹ᐟ³)
```

Зв'язок між кутом розсіяння `θ` та прицільним параметром `b_imp` у кулонівському полі описується класичною формулою Резерфорда:

```
tg(θ / 2) = (Z · q²) / (8π · ε · E · b_imp)
```

Мінімальний кут розсіяння відповідає максимальному прицільному параметру:

```
θ_min = 2 · arctg( (Z · q²) / (8π · ε · E · b_max) )
```

Інтегруючи диференціальний переріз Резерфорда від `θ_min` до `π`, отримуємо час релаксації Конуелл — Вайскопфа:

```
1 / τ_CW(E)
= [ (π · N_i · Z² · q⁴) / (2³ᐟ² · ε² · m*¹ᐟ² · E³ᐟ²) ] · ln(1 + (8π · ε · E · b_max / (Z · q²))²)
```

Усереднення за розподілом Максвелла — Больцмана дає формулу Конуелл — Вайскопфа:

```
μ_CW
= (2⁷ᐟ² · ε² · (k_B T)³ᐟ²) / (π³ᐟ² · Z² · q³ · m*¹ᐟ² · N_i · ln(1 + b_CW²))
```

де `b_CW = (8π · ε · k_B T) / (Z · q² · N_i¹ᐟ³)`.

### Порівняння моделей:
- **Модель Конуелл — Вайскопфа** краще описує напівпровідники при низьких температурах та високих ступенях компенсації, де концентрація вільних носіїв є вкрай малою (`n ≪ N_i`), і колективне дебаївське екранування вільними носіями не встигає сформуватися.
- **Модель Брукса — Геррінга** є фізично суворішою при помірних і високих температурах (`T > 77 К`) та високих концентраціях вільних носіїв, оскільки базується на квантовій квантово-механічній теорії збурень Борна та враховує динамічний просторовий перерозподіл електронної плазми.

## 5. Розсіяння на акустичних фононах через деформаційний потенціал Бардіна — Шоклі

Теплові коливання ґратки викликають періодичні стиснення та розтягнення елементарних комірок кристала. Локальна відносна зміна об'єму описується дивергенцією вектора зміщення атомів `ΔV / V = ∇ · u(r)`.

Згідно з теорією деформаційного потенціалу Джона Бардіна та Вільяма Шоклі (1950 р.), зсув краю енергетичної зони прямо пропорційний локальній деформації:

```
V_def(r) = E_d · ∇ · u(r)
```

де `E_d` — константа акустичного деформаційного потенціалу (типово `~5–15 еВ`).

### Квантування фононного поля та матричний елемент

Оператор зміщення кристалічної ґратки розкладається за плоскими фононними модами з хвильовим вектором `q` та частотою `ω_q`:

```
u(r)
= ∑_q √( ℏ / (2 · ρ · V · ω_q) ) · e_q · [ a_q · exp(i q · r) + a_q⁺ · exp(-i q · r) ]
```

де `ρ` — густина маси напівпровідника, `e_q` — одиничний вектор поляризації фонона, а `a_q` та `a_q⁺` — оператори знищення та народження фононів.

Оскільки для поздовжніх акустичних фононів вектор поляризації паралельний до хвильового вектора (`e_q || q`), дивергенція зміщення дорівнює:

```
∇ · u(r)
= ∑_q i q · √( ℏ / (2 · ρ · V · ω_q) ) · [ a_q · exp(i q · r) - a_q⁺ · exp(-i q · r) ]
```

Дія операторів на фононні фоківські стани `|N_q⟩` дає матричні елементи:
- Поглинання фонона (`k' = k + q`): `⟨N_q - 1| a_q |N_q⟩ = √N_q`
- Випромінювання фонона (`k' = k - q`): `⟨N_q + 1| a_q⁺ |N_q⟩ = √(N_q + 1)`

Квадрат матричного елемента взаємодії:

```
|⟨k ± q, N_q ∓ 1| V_def |k, N_q⟩|²
= (E_d² · ℏ · q²) / (2 · ρ · V · ω_q) · (N_q + 1/2 ∓ 1/2)
```

Для поздовжнього звуку закон дисперсії лінійний `ω_q = v_s · q`, де `v_s` — швидкість звуку в кристалі:

```
|M_ac(q)|²
= (E_d² · ℏ · q) / (2 · ρ · v_s · V) · (N_q + 1/2 ∓ 1/2)
```

### Високотемпературна межа Релея — Джинса

При температурах вище кількох десятків кельвінів енергія фононів, що беруть участь у розсіянні носіїв, набагато менша за теплову енергію електрона (`ℏω_q ≈ 2 ℏ v_s k ≪ k_B T`). 

У цій межі зіткнення є квазіпружними (`E(k') ≈ E(k)`), а середня кількість фононів описується розподілом Планка в наближенні Релея — Джинса:

```
N_q = [ exp(ℏω_q / (k_B T)) - 1 ]⁻¹ ≈ k_B T / (ℏω_q) = k_B T / (ℏ · v_s · q) ≫ 1
```

Сумарний квадрат матричного елемента для поглинання та випромінювання дорівнює:

```
|M_ac|²_{total}
= 2 · [ (E_d² · ℏ · q) / (2 · ρ · v_s · V) ] · [ (k_B T) / (ℏ · v_s · q) ]    [множення на два для процесів поглинання та випромінювання]
= (E_d² · k_B T) / (c_L · V)                                                  [скорочення ℏ q та підстановка модуля пружності c_L = ρ v_s²]
```

де `c_L = ρ · v_s²` — поздовжній модуль пружності кристала. 

Зверніть увагу: залежність від хвильового вектора фонона `q` повністю скоротилася. Це означає, що розсіяння на акустичних фононах є абсолютно **ізотропним** у просторі імпульсів (`⟨cos θ⟩ = 0`), звідки `τ_m(E) = τ_q(E)`.

### Час релаксації та температурна залежність рухливості

Частота розсіяння обчислюється множенням квадрата матричного елемента на густину кінцевих квантових станів зони провідності `g(E) = (m*³ᐟ² · √E) / (√2 · π² · ℏ³)`:

```
1 / τ_ac(E)
= (2π / ℏ) · |M_ac|²_{total} · V · g(E)                                       [золоте правило Фермі з повною густиною кінцевих станів]
= (2π / ℏ) · [ (E_d² · k_B T) / c_L ] · [ (m*³ᐟ² · √E) / (√2 · π² · ℏ³) ]      [підстановка густини станів 3D параболічної зони]
= (E_d² · k_B T · m*³ᐟ² · √E) / (√2 · π · ℏ⁴ · c_L)                            [скорочення констант 2π та ℏ]
```

Звідси час релаксації має степеневу залежність `τ_ac(E) = τ_0 · (E / (k_B T))⁻¹ᐟ²`, де:

```
τ_0 = (√2 · π · ℏ⁴ · c_L) / (E_d² · m*³ᐟ² · (k_B T)³ᐟ²)
```

Використовуючи результат статистичного усереднення для `s = -1/2`:

```
⟨τ_ac⟩
= (4 / (3 · √π)) · τ_0                                                 [усереднення за розподілом Максвелла — Больцмана при s = -1/2]
= (2√2 · π · ℏ⁴ · c_L) / (3 · E_d² · m*³ᐟ² · (k_B T)³ᐟ²)               [підстановка виразу для τ_0 акустичного розсіяння]
```

Підставляючи `⟨τ_ac⟩` у формулу рухливості Друде `μ_ac = q · ⟨τ_ac⟩ / m*`, отримуємо аналітичний квантовий закон Бардіна — Шоклі:

```
μ_ac
= (2√2 · π · q · ℏ⁴ · c_L) / (3 · E_d² · m*⁵ᐟ² · (k_B T)³ᐟ²)
∝ (m*)⁻⁵ᐟ² · T⁻³ᐟ²
```

### Фізична природа показників степенів:
- **`T⁻¹`** виникає через лінійне зростання густини заселеності фононних мод `N_q ∝ T`.
- **`T⁻¹ᐟ²`** виникає через зростання середньої кінетичної енергії електронів `⟨E⟩ ∝ k_B T`, що збільшує густину доступних кінцевих станів `g(E) ∝ √E`. Разом вони дають сумарний спад `T⁻³ᐟ²`.
- **`(m*)⁻⁵ᐟ²`** складається з `(m*)⁻³ᐟ²` (від густини квантових станів у фазовому об'ємі) та `(m*)⁻¹` (від прискорення носія зовнішнім полем за другим законом Ньютона).

## 6. Полярне оптичне розсіяння Фрьоліха та п'єзоелектричне розсіяння

### Полярне оптичне розсіяння Фрьоліха (POPS)

У напівпровідниках зі значною часткою іонного зв'язку (сполуки `III-V`: `GaAs`, `GaN`, `InP`, `InSb` та `II-VI`: `ZnSe`, `CdTe`) поздовжні оптичні коливання (LO-фонони) супроводжуються взаємним зсувом протилежно заряджених підґраток. Це генерує макроскопічну електричну поляризацію `P(r)` та далекодійне внутрішнє електричне поле.

Гамільтоніан взаємодії електрона з полем LO-фононів описується моделлю Герберта Фрьоліха:

```
H_Fr = ∑_q (i · C_Fr / q) · [ a_q · exp(i q · r) - a_q⁺ · exp(-i q · r) ]
```

де константа зв'язку Фрьоліха визначається діелектричною дисперсією кристала:

```
|C_Fr|² = (q_e² · ℏ · ω_LO / (2 · V)) · (1 / ε_∞ - 1 / ε_s)
```

де `ε_∞` — високочастотна (оптична) діелектрична проникність, `ε_s` — статична діелектрична проникність, а `ℏω_LO` — характеристична енергія поздовжнього оптичного фонона (`36.2 меВ` у `GaAs`, `92.0 меВ` у `GaN`).

Безрозмірна константа зв'язку Фрьоліха `α_F` характеризує силу електрон-фононної взаємодії:

```
α_F = (q_e² / (4π · ε_0 · ℏ)) · √( m* / (2 · ℏ · ω_LO) ) · (1 / ε_∞ - 1 / ε_s)
```

Для `GaAs` `α_F ≈ 0.068` (слабкий зв'язок), для `GaN` `α_F ≈ 0.49`, а для сильних іонних діелектриків `α_F > 1` (утворення автолокалізованих станів — поляронів).

Оскільки енергія LO-фонона порівнянна з кімнатною тепловою енергією (`ℏω_LO / k_B ≈ 420 К` у `GaAs`, `~1060 К` у `GaN`), зіткнення є принципово непружними:
1. **При низьких температурах (`k_B T ≪ ℏω_LO`)**: оптичні фонони не збуджені, тому випромінювання фононів неможливе для теплових електронів (`E < ℏω_LO`). Розсіяння лімітується рідкісними актами поглинання фононів, що дає експоненційне зростання рухливості:
```
μ_pop ∝ exp(ℏω_LO / (k_B T)) / (α_F · m*)
```
2. **При високих температурах (`k_B T ≫ ℏω_LO`)**: процеси поглинання та випромінювання стають інтенсивними, даючи температурну залежність `μ_pop ∝ T⁻¹ᐟ²` або `T⁻¹`.

### П'єзоелектричне розсіяння

У кристалах без центру інверсії (цинкова обманка, вюрцит) зсувна акустична деформація генерує п'єзоелектричну поляризацію `P_i = e_{ijk} · S_{jk}`. 

Електростатичний потенціал, породжений цією поляризацією, спадає як `1/q`, що дає екранований матричний елемент:

```
|M_pe(q)|² = (q_e² · K_av² · k_B T) / (2 · ε_s · V · (q² + q_D²))
```

де `K_av` — безрозмірний електромеханічний коефіцієнт зв'язку кристала.

Час релаксації імпульсу для п'єзоелектричного розсіяння зростає з енергією як `τ_pe(E) ∝ E¹ᐟ² · T⁻¹`. Використовуючи формулу статистичного усереднення для `s = +1/2`:

```
μ_pe
= (16√2 · π · ℏ² · ε_s) / (3 · q_e · m*³ᐟ² · K_av² · (k_B T)¹ᐟ²)
∝ (m*)⁻³ᐟ² · T⁻¹ᐟ²
```

П'єзоелектричне розсіяння домінує над деформаційним акустичним розсіянням у сполуках `III-V` при низьких температурах (`10 К < T < 77 К`).

## 7. Розсіяння на шорсткості поверхні у 2D каналах

У польових транзисторах (MOSFET, FinFET) та гетероструктурах з високою рухливістю електронів (HEMT на основі `AlGaAs/GaAs` або `AlGaN/GaN`) сильне поперечне електричне поле притискання `E_eff` створює квантову потенціальну яму, локалізуючи електрони у двовимірному шарі товщиною в кілька нанометрів поблизу гетеромежі.

Хвильова функція основної підзони розмірного квантування описується варіаційним наближенням Фанга — Говарда:

```
ψ(z) = √(b³ / 2) · z · exp(- b · z / 2)
```

де варіаційний параметр `b` визначається поперечним електричним полем: `b = [ (12 · q_e² · m_z*) / (ε_s · ℏ²) · (N_depl + (11/32) · n_s) ]¹ᐟ³`.

### Статистика флуктуацій рельєфу межі

Атомний рельєф межі розділу описується випадковою функцією висоти відхилення `Δ(r)` від ідеальної площини `z = 0` у двовимірному просторі координат каналу `r = (x, y)`.

Статистичні кореляції поверхневого профілю моделюються автокореляційною функцією `C(r) = ⟨Δ(r') · Δ(r' + r)⟩`:
1. **Гаусова автокореляція**: `C_Gauss(r) = Δ² · exp(- r² / L²)`
2. **Експоненціальна автокореляція**: `C_exp(r) = Δ² · exp(- √2 · r / L)`

де `Δ` — середньоквадратична висота шорсткості (типово `0.2–0.5 нм`), а `L` — просторова довжина кореляції (типово `1.5–3.0 нм`).

Спектральна густина потужності шорсткості (двовимірний Фур'є-образ корелятора):

```
|Δ(q)|²
= ∫ C_Gauss(r) · exp(-i q · r) · d²r    [двовимірний Фур'є-інтеграл від автокореляційної функції]
= π · Δ² · L² · exp(- q² · L² / 4)      [аналітичне інтегрування 2D гаусіани]
```

де `q = 2 k_F · sin(θ/2)` — переданий хвильовий вектор у площині двовимірного каналу.

### Матричний елемент та квадратичний закон поля

Локальне просторове зміщення потенційного бар'єра на величину `Δ(r)` породжує локальне збурення квантового потенціалу:

```
V_sr(r, z) = q_e · E_eff · Δ(r) · δ(z)
```

Матричний елемент переходу між двовимірними хвильовими функціями плоских хвиль з урахуванням 2D діелектричного екранування електронами дорівнює:

```
|M_sr(q)|²
= (q_e · E_eff)² · |Δ(q)|² / ε_2D(q)²
```

де `ε_2D(q) = 1 + q_TF / q` — діелектрична функція Томаса — Фермі для 2D газу, де `q_TF = (q_e² · m*) / (2π · ε_s · ℏ²)`.

Транспортний час релаксації на поверхні Фермі виродженого 2D газу обчислюється інтегруванням за плоским кутом розсіяння `θ`:

```
1 / τ_sr(E_F)
= (m* / ℏ³) · ∫₀^π (1 - cos θ) · [ |M_sr(2 k_F · sin(θ/2))|² / ε_2D(2 k_F · sin(θ/2))² ] · (dθ / π)
```

Оскільки квадрат матричного елемента прямо пропорційний квадрату напруженості поперечного притискального поля `E_eff²`, рухливість, обмежена шорсткістю поверхні, підкоряється універсальному квантовому закону:

```
μ_sr
= q · τ_sr(E_F) / m*
∝ Δ⁻² · L⁻² · E_eff⁻²
```

Цей результат пояснює стрімку деградацію крутизни польових транзисторів при високих напругах на затворі: сильне поле притискає електрони впритул до шорсткої межі, спричиняючи квадратичне падіння рухливості каналу.

## 8. Строге обґрунтування та межі застосовності правила Маттіссена

Коли в кристалі одночасно діє `N` незалежних мікроскопічних механізмів розсіяння, квантово-механічні ймовірності переходів додаються відповідно до правила додавання амплітуд для некогерентних процесів:

```
W_total(k, k') = ∑_i W_i(k, k')
```

Це призводить до суворого додавання мікроскопічних зворотних часів релаксації для кожного окремого енергетичного стану `E`:

```
1 / τ_total(E) = ∑_i 1 / τ_i(E)
```

Точна макроскопічна рухливість обчислюється шляхом статистичного усереднення сумарного часу:

```
μ_exact
= (q / m*) · ⟨ τ_total(E) ⟩
= (q / m*) · ⟨ [ ∑_i 1 / τ_i(E) ]⁻¹ ⟩
```

У той самий час інженерне **правило Маттіссена** стверджує, що додаються зворотні величини окремо усереднених парціальних рухливостей:

```
1 / μ_Matthiessen
= ∑_i 1 / μ_i                           [додавання зворотних парціальних рухливостей]
= (m* / q) · ∑_i ⟨τ_i(E)⟩⁻¹             [підстановка виразу Друде для кожної парціальної рухливості]
```

### Математична похибка та нерівність усереднення

Математично точна рухливість та наближення Маттіссена пов'язані співвідношенням між гармонійним та статистичним середнім. Для довільних додатних функцій `A(E)` та `B(E)` зі статистичною вагою `w(E)` нерівність Коші — Буняковського — Шварца стверджує:

```
⟨ (A(E) + B(E))⁻¹ ⟩ ≠ ( ⟨A(E)⟩⁻¹ + ⟨B(E)⟩⁻¹ )⁻¹
```

Рівність досягається лише тоді, коли енергетичні залежності всіх парціальних часів релаксації є строго пропорційними: `τ_i(E) = c_i · τ_j(E)`.

### Аналітичний розрахунок відхилення для фононів та іонізованих домішок

Розглянемо випадок одночасної дії акустичного фононного розсіяння (`τ_ac(E) = a · E⁻¹ᐟ²`) та розсіяння на іонізованих домішках (`τ_imp(E) = b · E³ᐟ²`).

Сумарний мікроскопічний час релаксації:

```
τ_total(E)
= [ 1 / (a · E⁻¹ᐟ²) + 1 / (b · E³ᐟ²) ]⁻¹    [сумування зворотних часів релаксації для енергії E]
= (a · b · E³ᐟ²) / (b · E² + a)             [зведення до спільного знаменника]
= τ_ac(E) · [ (E / E_0)² / (1 + (E / E_0)²) ] [факторизація через характерну енергію кросовера E_0]
```

де `E_0 = √(a / b)`. Вводячи безрозмірну енергію `x = E / (k_B T)` та параметр співвідношення інтенсивностей `z² = 6 · μ_ac / μ_imp`, точний інтеграл усереднення записується через інтеграл Фішера:

```
μ_exact / μ_ac
= (4 / (3 · √π)) · ∫₀^∞ [ x³ / (x² + z²) ] · exp(-x) · dx
```

У той самий час наближення Маттіссена дає:

```
μ_Matthiessen / μ_ac
= 1 / (1 + μ_ac / μ_imp)                [нормування суми зворотних величин на рухливість μ_ac]
= 1 / (1 + z² / 6)                      [вираження через безрозмірний параметр z² = 6 · μ_ac / μ_imp]
```

### Аналіз режимів:
1. **Область високих температур (`z ≪ 1`)**: домінує фононне розсіяння, `μ_exact → μ_ac`, похибка наближення прямує до нуля.
2. **Область низьких температур (`z ≫ 1`)**: домінує розсіяння на домішках, `μ_exact → μ_imp`, похибка наближення прямує до нуля.
3. **Область кросовера (`z ≈ 1–3`, `T ≈ 50–100 К`)**: інтенсивності фононного та домішкового розсіяння стають порівнянними. Оскільки `τ_ac(E)` спадає з енергією, а `τ_imp(E)` зростає, нахили функцій протилежні. 

Точний числовий розрахунок інтеграла показує, що в області кросовера правило Маттіссена **занижує** реальну рухливість:

```
(μ_exact - μ_Matthiessen) / μ_exact ≈ 12–17%
```

## 9. Фізика сильного поля, гарячі носії та границя насичення швидкості

У сильних електричних полях (`E > 10³–10⁴ В/см`) лінійний закон Ома порушується, оскільки середня швидкість надходження кінетичної енергії від поля до носія перевищує швидкість її передачі акустичним фононам ґратки. Носії розігріваються до ефективної температури `T_e > T_lattice`.

Рівняння балансу потужності, що надходить від поля та дисипується в ґратку за час релаксації енергії `τ_E` (`τ_E ≈ 10⁻¹¹–10⁻¹² с ≫ τ_m`), має вигляд:

```
q · v_d · E = (⟨E⟩ - (3/2) · k_B · T_L) / τ_E
```

де `T_L` — температура ґратки.

Звідси ефективна температура гарячих електронів зростає квадратично за полем:

```
T_e = T_L + (2 · q · μ · τ_E / (3 · k_B)) · E²
```

### Порогова емісія оптичних фононів та швидкість насичення

Коли кінетична енергія гарячого електрона досягає порогової енергії оптичного фонона `ℏω_opt` (`63 меВ` у Si, `36 меВ` у GaAs), різко вмикається квазімиттєве випромінювання оптичних фононів за час `τ_opt ≈ 10⁻¹³ с`.

Електрон миттєво втрачає майже всю кінетичну енергію та накопичений спрямований імпульс, повертаючись на дно енергетичної зони, після чого цикл прискорення полем повторюється.

Максимальна швидкість носія перед емісією оптичного фонона визначається співвідношенням:

```
(1/2) · m* · v_max² = ℏω_opt  ⇒  v_max = √( (2 · ℏω_opt) / m* )
```

Оскільки в сильному полі дрейф носіїв має пилкоподібний характер у часі (лінійне прискорення від `0` до `v_max` з наступним миттєвим скиданням швидкості в нуль), середня стаціонарна дрейфова швидкість дорівнює половині максимальної:

```
v_sat
= (1/2) · v_max
= √( ℏω_opt / (2 · m*) )                 [теоретична квантова швидкість насичення]
```

Для кремнію з ефективною масою провідності `m* ≈ 0.26 m_0` та оптичним фононом `ℏω_opt ≈ 63 меВ`:

```
v_sat
= √( (0.063 еВ · 1.602 × 10⁻¹⁹ Дж/еВ) / (2 · 0.26 · 9.109 × 10⁻³¹ кг) )    [підстановка констант кремнію та енергії фонона]
= √( (1.009 × 10⁻²⁰ Дж) / (4.737 × 10⁻³¹ кг) )                             [обчислення чисельника та знаменника під коренем]
= √( 2.130 × 10¹⁰ м²/с² )                                                   [ділення енергії на ефективну масу носія]
≈ 1.46 × 10⁵ м/с = 1.46 × 10⁷ см/с                                          [добування квадратного кореня]
```

З урахуванням еліпсоїдальної анізотропії долин та міждолинного оптичного розсіяння точний розрахунок методом Монте-Карло дає `v_sat ≈ 1.05 × 10⁷ см/с`, що бездоганно узгоджується з експериментальними вольт-амперними характеристиками напівпровідникових транзисторів.
