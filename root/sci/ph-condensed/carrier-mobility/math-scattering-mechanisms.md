# 🧮 Квантово-механічна теорія розсіяння носіїв та доведення правила Маттіссена

Ця вставка містить квантово-механічне та статистичне виведення коефіцієнта рухливості носіїв заряду з кінетичного рівняння Больцмана, макроскопічний розрахунок інтенсивностей розсіяння на акустичних та оптичних фононах, іонізованих домішках, а також суворе математичне обґрунтування меж застосовності правила Маттіссена.

## 1. Рівняння Больцмана та час релаксації імпульсу

У квазікласичному наближенні стан електронного газу в кристалі описується функцією розподілу `f(r, p, t)`, яка визначає ймовірність знайти електрон у фазовому об'ємі `d³r d³p`. Під дією зовнішнього електричного поля `E` динаміка функції розподілу описується кінетичним рівнянням Больцмана:

```
df/dt = ∂f/∂t + v · ∇_r f + q · E · ∇_p f = (∂f/∂t)_coll
```

У стаціонарному та просторово однорідному випадку (`∂f/∂t = 0`, `∇_r f = 0`) рівняння спрощується до балансу між польовим прискоренням та зіткненнями:

```
q · E · ∇_p f = (∂f/∂t)_coll
```

У наближенні часу релаксації інтеграл зіткнень моделюється як прагнення системи до рівноважного розподілу Фермі — Дірака `f_0(E)` за характерний час релаксації імпульсу `τ(E)`:

```
(∂f/∂t)_coll = - (f - f_0) / τ(E)
```

Розкладаючи функцію розподілу за малим макроскопічним дрейфом у слабкому електричному полі, маємо `f(p) = f_0(E) + f_1(p)`, де симетрична частина `f_0(E)` не дає внеску в струм, а анізотропне відхилення `f_1(p)` дорівнює:

```
f_1(p)
= - q · E · v · τ(E) · (∂f_0 / ∂E)      [лінеаризація рівняння Больцмана за полем E]
```

Густина дрейфового струму `j` обчислюється шляхом інтегрування за всіма станами у просторі імпульсів:

```
j 
= q · ∫ v · f(p) · d³p
= q · ∫ v · (f_0 + f_1) · d³p
= - q² · E · ∫ v² · τ(E) · (∂f_0 / ∂E) · d³p    [інтеграл від симетричної f_0 дорівнює нулю]
```

Для параболічної ізотропної зони зі співвідношенням квазіімпульсу та енергії `E = p² / (2 m*)` середня квадратна швидкість пов'язана з кінетичною енергією через `v² = 2 E / m*`. Після інтегрування по частинах густина струму зводиться до макроскопічного закону Ома `j = σ · E`, де провідність `σ = q · n · μ`. Звідси отримуємо фундаментальний вираз для рухливості через усреднений час релаксації імпульсу `⟨τ⟩`:

```
μ 
= q · ⟨τ⟩ / m*                           [зв'язок рухливості з середнім часом релаксації]
```

де усреднення за енергіями для невиродженого електронного газу підкоряється статистиці Максвелла — Больцмана і здійснюється за формулою:

```
⟨τ⟩ 
= (∫ τ(E) · E³ᐟ² · (∂f_0 / ∂E) · dE) / (∫ E³ᐟ² · (∂f_0 / ∂E) · dE)
```

## 2. Квантове виведення розсіяння на акустичних фононах

Розсіяння носіїв на теплових коливаннях ґратки (фононах) описується золотим правилом Фермі для ймовірності квантового переходу зі стану з хвильовим вектором `k` у стан `k'`:

```
W(k, k') 
= (2π / ℏ) · |M(k, k')|² · δ(E(k') - E(k) ∓ ℏω_q)
```

де `ℏω_q` — енергія акустичного фонона з хвильовим вектором `q = k' - k`.

Згідно з теорією деформаційного потенціалу Джон Бардіна та Вільяма Шокли, зсув краю енергетичної зони пропорційний локальній об'ємній деформації кристалічної ґратки `∇ · u`. Матричний елемент взаємодії електрона з акустичним фононом дорівнює:

```
|M(k, k±q)|² 
= (E_d² · ℏ · q) / (2 · ρ · v_s · V) · (N_q + 1/2 ± 1/2)
```

де `E_d` — константа деформаційного потенціалу, `ρ` — густина напівпровідника, `v_s` — поздовжня швидкість звуку в кристалі, `V` — об'єм зразка, а `N_q` — число фононів у моді `q`.

При високих і кімнатних температурах енергія акустичного фонона набагато менша за середню теплову енергію електрона (`ℏω_q ≪ k_B T`), тому зіткнення можна вважати високопружними (`E(k') ≈ E(k)`), а середня кількість фононів описується класичною межею Релея — Джинса: `N_q ≈ k_B T / (ℏω_q)`.

Підставляючи вираз для `N_q` у матричний елемент, отримуємо квадратичний модуль взаємодії, який не залежить від хвильового вектора фонона `q`:

```
|M|² 
= (E_d² · k_B T) / (c_L · V)            [де c_L = ρ · v_s² — пружна константа решітки]
```

Частота розсіяння `1 / τ_ph(E)` обчислюється множенням квадратного матричного елемента на квантову густину станів зони провідності `g(E) = (m*³ᐟ² · √E) / (√2 · π² · ℏ³)`:

```
1 / τ_ph(E)
= (2π / ℏ) · |M|² · g(E)
= (E_d² · k_B T · m*³ᐟ² · √E) / (√2 · π · ℏ⁴ · c_L)    [інтенсивність пропорційна √E та T]
```

Отже, час релаксації імпульсу для акустичного фононного розсіяння зменшується зі зростанням кінетичної енергії носія як `τ_ph(E) ∝ E⁻¹ᐟ² · T⁻¹`. Швидші електрони мають більшу густину кінцевих станів для розсіяння, тому зіштовхуються частіше. Обчислюючи температурне усреднення за максвеллівським розподілом `⟨E⟩ = (3/2) k_B T`, отримуємо:

```
⟨τ_ph⟩ 
= C_ph · m*⁻³ᐟ² · (k_B T)⁻³ᐟ²            [температурне інтегрування за енергіями]
```

де `C_ph = (2√2 · π · ℏ⁴ · c_L) / (3 · E_d² · k_B)`.

Підставляючи `⟨τ_ph⟩` у фундаментальне співвідношення для рухливості `μ = q · ⟨τ_ph⟩ / m*`, отримуємо класичний температурний та масовий закон акустичного фононного розсіяння:

```
μ_ph 
∝ m*⁻⁵ᐟ² · T⁻³ᐟ²                         [температурна залежність фононної рухливості]
```

Цей результат пояснює, чому носії з меншою ефективною масою `m*` (наприклад, електрони в арсеніді галію `GaAs`, де `m_n* ≈ 0.067 m_0`) мають колосально вищу фононну рухливість порівняно з носіями у кремнії (`m_n* ≈ 0.26 m_0`).

## 3. Квантове виведення розсіяння на іонізованих домішках (Брукс — Геррінг)

Коли в кристалічну ґратку введено донорні або акцепторні домішки, вони іонізуються при кімнатній температурі, створюючи точкові заряди `Z · q`. Електричний потенціал іона Кулона екранується рухомою хмарою вільних носіїв. Екранований потенціал Юкави у просторовому зображенні має вигляд:

```
V(r) = (Z · q) / (4π · ε · r) · exp(- r / λ_D)
```

де `λ_D = √( (ε · k_B T) / (q² · n) )` — радіус екранування Дебая.

Фурьє-образ цього потенціалу визначає матричний елемент квантового розсіяння в першому борнівському наближенні при передачі імпульсу `q_s = k' - k`:

```
|M(q_s)|² 
= (Z² · q⁴) / [ ε² · V² · (q_s² + q_D²)² ]    [де q_D = 1 / λ_D — хвильове число Дебая]
```

Інтегрування кутового розподілу розсіяння з ваговим фактором `(1 - cos θ)` дає залежність часу релаксації від кінетичної енергії електрона `E`:

```
1 / τ_imp(E) 
= [ π · N_i · Z² · q⁴ / (2³ᐟ² · ε² · m*¹ᐟ² · E³ᐟ²) ] · [ ln(1 + b) - b / (1 + b) ]
```

де параметр екранування дорівнює `b = (8 m* · E · λ_D²) / ℏ²`.

На відміну від фононного випадку, повільні носії з малою кінетичною енергією пролітають поблизу іона повільніше, зазнають тривалішого кулонівського впливу і відхиляються на більші кути. Тому час релаксації зростає з енергією як `τ_imp(E) ∝ E³ᐟ² / N_i`. Усереднення за розподілом Максвелла — Больцмана виявляє зростаючу температурну залежність:

```
⟨τ_imp⟩ 
∝ ε² · (k_B T)³ᐟ² / (N_i · m*¹ᐟ²)
```

Підставляючи під загальну рухливість, отримуємо знамениту температурну та допінгову формулу Брукса — Геррінга:

```
μ_imp 
∝ ε² · T³ᐟ² / (m*¹ᐟ² · N_i)              [зростання рухливості з температурою на домішках]
```

## 4. П'єзоелектричне та міждолинне розсіяння у складних напівпровідниках

У напівпровідниках сполук `III-V` та `II-VI` (таких як `GaAs`, `GaN`, `ZnO`), які позбавлені інверсійної симетрії кристалічної ґратки, акустичні деформації викликають додаткові внутрішні електричні поля. Це явище описується п'єзоелектричним розсіянням.

Матричний елемент п'єзоелектричної взаємодії залежить від хвильового вектора як `|M_pe|² ∝ 1 / q`, що дає час релаксації `τ_pe(E) ∝ E¹ᐟ² · T⁻¹`. Відповідно, рухливість, обмежена п'єзоелектричним розсіянням, підкоряється закону:

```
μ_pe 
∝ m*⁻³ᐟ² · T⁻¹ᐟ²                         [температурний закон п'єзоелектричного розсіяння]
```

П'єзоелектричне розсіяння грає помітну роль у широкозонних матеріалах (`GaN`) при помірних та низьких температурах.

У багатодолинних напівпровідниках (кремній `Si`, германій `Ge`) важливим механізмом є **міждолинне розсіяння** (intervalley scattering). Під час цього процесу електрон поглинає або випромінює фонон із великим імпульсом `q ≈ q_zone_boundary` і переходить з однієї екстремальної долини зони провідності в іншу (наприклад, між `X`-долинами у `Si`). Оскільки міждолинний фонон має високу енергію `ℏω_iv`, це розсіяння вмикається порогово при підвищенні температури і призводить до стрімкішого падіння фононної рухливості кремнію: `μ_ph ∝ T⁻²·³` замість класичного закону `T⁻¹·⁵`.

## 5. Строге обґрунтування та межі застосовності правила Маттіссена

Якщо в напівпровіднику одночасно діють кілька незалежних механізмів розсіяння (наприклад, акустичні фонони, іонізовані домішки та шорсткість гетеромежі), квантово-механічні ймовірності переходу у збуджені стани додаються математично:

```
W_total(k, k') = W_ph(k, k') + W_imp(k, k') + W_sr(k, k')
```

Це означає, що мікроскопічні частоти зіткнень для конкретного енергетичного рівня `E` додаються суворо для кожного електрона:

```
1 / τ_total(E) 
= 1 / τ_ph(E) + 1 / τ_imp(E) + 1 / τ_sr(E)    [мікроскопічне сумування частот зіткнень]
```

Макроскопічне **правило Маттіссена** стверджує, що зворотні величини парціальних рухливостей сумуються:

```
1 / μ_total 
≈ 1 / μ_ph + 1 / μ_imp + 1 / μ_sr          [макроскопічне правило Маттіссена]
```

Проте виведення показує точну межу цього наближення. Обчислюючи точну підсумкову рухливість, слід спочатку підсумувати частоти для рівня `E`, а потім взяти термодинамічне усреднення:

```
μ_exact 
= (q / m*) · ⟨ ( 1/τ_ph(E) + 1/τ_imp(E) )⁻¹ ⟩
```

У той самий час макроскопічна формула Маттіссена бере усреднення від кожного додатка окремо:

```
μ_Matthiessen 
= (q / m*) · [ 1 / ⟨τ_ph(E)⟩ + 1 / ⟨τ_imp(E)⟩ ]⁻¹
```

Математично `⟨ (A(E) + B(E))⁻¹ ⟩ ≠ ( ⟨A(E)⟩⁻¹ + ⟨B(E)⟩⁻¹ )⁻¹`, якщо функціональні залежності `τ_ph(E) ∝ E⁻¹ᐟ²` та `τ_imp(E) ∝ E³ᐟ²` мають протилежні нахили від енергії.

Точна числова інтеграція показує, що максимальна похибка правила Маттіссена виникає в переходній температурній області (`T ≈ 50–100 К`), де інтенсивності фононного та домішкового розсіяння є порівнюваними. На цій межі правило Маттіссена занижує реальну рухливість на `10–15%`. В областях однозначного домінування одного з механізмів похибка прямує до нуля.

## 6. Фізика сильного поля та границя насичення швидкості

У сильних електричних полях (`E > 10⁴ В/см`) носій набуває від поля енергію швидше, ніж встигає віддавати її акустичним фононам. Середня енергія электронного газу зростає, носії стають «гарячими» (`T_e > T_lattice`).

Коли кінетична енергія носія досягає порогової енергії оптичного фонона `ℏω_opt` (`~63 меВ` у кремнії), відкривається новий надшвидкий канал розсіяння — випромінювання оптичних фононів за час `τ_opt ≈ 10⁻¹³ с`.

Баланс енергії між надходженням від поля та дисипацією в ґратку описується рівнянням:

```
q · v_d · E 
= (E_electron - E_lattice) / τ_energy 
≈ ℏω_opt / τ_opt
```

Звідси випливає фізична межа максимальної дрейфової швидкості (насичення):

```
v_sat 
= √( ℏω_opt / (2 m*) )                   [гранична швидкість насичення у сильному полі]
```

Для кремнію з `m* ≈ 0.26 m_0` та `ℏω_opt ≈ 63 меВ` це теоретичне значення дає `v_sat ≈ 1.05 · 10⁷ см/с`, що повністю відповідає емпірично спостережуваній межі.
