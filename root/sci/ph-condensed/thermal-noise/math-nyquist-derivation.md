# Виведення формули Найквіста для теплового шуму

У 1928 році американський фізик та інженер Гаррі Найквіст (Harry Nyquist) опублікував фундаментальну працю, у якій термодинамічно вивів формулу для спектральної щільності теплового шуму в провідниках. Емпіричне відкриття цього явища належить Джону Джонсону (John B. Johnson), який експериментально виміряв шумові флуктуації в резисторах різної природи.

Виведення Найквіста є одним з найелегантніших результатів прикладної фізики: воно спирається виключно на перший та другий закони термодинаміки, теорему про рівнорозподіл енергії та класичну електродинаміку ліній передачі. Завдяки такому підходу формула $S_v(f) = 4 k_B T R$ є абсолюдно універсальною і не залежить від матеріалу, геометричної форми чи механізму провідності елемента.

---

## 1. Фізична модель уявного досліду

Розглянемо уявний експеримент Найквіста. Нехай маємо два однакових резистори з активним опором $R$, які перебувають у стані термодинамічної рівноваги при абсолютній температурі $T$.

Резистори з'єднані між собою ідеальною двопровідною довгою лінією передачі (без втрат) довжиною $L$, яка має хвильовий опір $Z_0 = R$.

```
[Резистор R1 (T)] <==== Лінія передачі L, Z0 = R ====> [Резистор R2 (T)]
```

### Ключові умови рівноваги:
1. **Узгодження навантаження ($Z_0 = R$)**: Будь-яка хвиля, що випромінюється резистором $R_1$ і поширюється вздовж лінії, повністю поглинається резистором $R_2$ без відбиття на кінці.
2. **Другий закон термодинаміки**: У стані рівноваги середня потужність $P_1$, що передається від $R_1$ до $R_2$, повинна дорівнювати середній потужності $P_2$, що передається від $R_2$ до $R_1$. Якби $P_1 \neq P_2$, виник би односпрямований потік енергії між тілами однакової температури, що призвело б до створення вічного двигуна другого роду.

---

## 2. Дискретизація та лічба електромагнітних мод у лінії

Якщо на мить замкнути лінію передачі довжиною $L$ з двох кінців ідеальними короткозамикачами, у ній виникнуть стоячі електромагнітні хвилі. Моди коливань відповідають умові, що на довжині лінії $L$ вкладається ціле число півхвиль:

$$L = n \cdot \frac{\lambda_n}{2}, \quad n = 1, 2, 3, \dots$$

Оскільки довжина хвилі $\lambda_n = v / f_n$ (де $v$ — швидкість поширення електромагнітної хвилі в лінії), частоти допустимих мод дорівнюють:

$$f_n = n \cdot \frac{v}{2L}$$

Інтервал між сусідніми модами по частоті є постійною величиною:

$$\Delta f = f_{n+1} - f_n = \frac{v}{2L}$$

Кількість мод $dN$, які припадають на вузький частотний інтервал $df$:

$$dN = \frac{df}{\Delta f} = \frac{2L}{v} df$$

---

## 3. Застосування теореми про рівнорозподіл енергії

Згідно з класичною статистичною механікою (теорема про рівнорозподіл енергії), на кожен квадратичний ступінь вільності в системі, що перебуває в термодинамічній рівновазі при температурі $T$, припадає середня енергія $\frac{1}{2} k_B T$.

Кожна стояча електромагнітна мода має два квадратичних ступені вільності (електрична енергія $\frac{1}{2} C U^2$ та магнітна енергія $\frac{1}{2} L I^2$). Отже, середня енергія однієї моди в рівновазі становить:

$$\bar{E}_{\text{mode}} = \frac{1}{2} k_B T + \frac{1}{2} k_B T = k_B T$$

Загальна енергія шуму $dE$, закладена у модах лінії в діапазоні частот $df$:

$$dE = \bar{E}_{\text{mode}} \cdot dN = (k_B T) \cdot \left( \frac{2L}{v} df \right)$$

---

## 4. Перехід від енергії лінії до шумової потужності

Енергія $dE$ у лінії складається з двох рівних частин: хвиль, що рухаються вправо (від $R_1$ до $R_2$), та хвиль, що рухаються вліво (від $R_2$ до $R_1$):

$$dE_{\text{right}} = \frac{1}{2} dE = k_B T \cdot \frac{L}{v} df$$

Час прольоту хвилі вздовж лінії від одного кінця до іншого становить $\tau = L / v$. Отже, середня шумова потужність $P$, яку резистор $R_1$ випромінює в узгоджену лінію в смузі $df$:

$$P df = \frac{dE_{\text{right}}}{\tau} = \frac{k_B T \cdot \frac{L}{v} df}{\frac{L}{v}} = k_B T df$$

У результаті довжина лінії $L$ та швидкість хвилі $v$ повністю скорочуються! Доступна шумова потужність (available noise power) резистора в узгодженому режимі становить:

$$P = k_B T B \quad [\text{Вт}]$$

де $B = df$ — ширина смуги частот (Гц).

---

## 5. Розрахунок ЕРС шуму через закон Ома

Подамо резистор як еквівалентне джерело напруги (ЕРС шуму $V_n$) із послідовним внутрішнім опором $R$. При підключенні до узгодженого навантаження $R_L = R$ струм у колі дорівнює:

$$I = \frac{V_n}{R + R_L} = \frac{V_n}{2R}$$

Потужність $P_{R_L}$, яка виділяється на узгодженому навантаженні:

$$P_{R_L} = I^2 R = \left( \frac{V_n}{2R} \right)^2 R = \frac{V_n^2}{4R}$$

Прирівнюючи потужність з еквівалентної схеми до термодинамічно виведеної доступної потужності $P_{R_L} = k_B T B$:

$$\frac{V_n^2}{4R} = k_B T B \implies V_n^2 = 4 k_B T R B$$

Отже, спектральна щільність напруги теплового шуму становить:

$$S_v(f) = \frac{V_n^2}{B} = 4 k_B T R \quad [\text{В}^2 / \text{Гц}]$$

### Пояснення множника 4
Множник **4** з'являється виключно через ефект проходження сигналу через узгоджений дільник напруги:
- Множник 2 у знаменнику струму ($I = V_n / 2R$) підноситься до квадрата при обчисленні потужності ($2^2 = 4$), даючи $P = V_n^2 / 4R$.
- Перенесення знаменника 4 у праву частину формули дає підсумкове $4 k_B T R$.

## 6. Симуляція виведення Найквіста на C++

Нижче подано C++ програму, яка числово моделює 1D лінію передачі з дискретним спектром мод, обчислює статистичний розподіл енергії та підтверджує точний збіг із формулою $4kTR$.

```cpp
#include <iostream>
#include <vector>
#include <cmath>
#include <numeric>
#include <iomanip>

static const double K_B = 1.380649e-23; // Стала Больцмана (Дж/К)

struct LineMode {
    int mode_index;
    double frequency_hz;
    double energy_joules;
};

class NyquistTransmissionLineSim {
private:
    double length_m;
    double velocity_m_s;
    double resistance_ohm;
    double temp_kelvin;

public:
    NyquistTransmissionLineSim(double len, double vel, double r, double temp)
        : length_m(len), velocity_m_s(vel), resistance_ohm(r), temp_kelvin(temp) {}

    // Обчислення кількості мод у смузі B
    double calculate_theoretical_mode_count(double bandwidth_hz) const {
        return (2.0 * length_m * bandwidth_hz) / velocity_m_s;
    }

    // Доступна шумова потужність (P = k_B * T * B)
    double calculate_available_noise_power(double bandwidth_hz) const {
        return K_B * temp_kelvin * bandwidth_hz;
    }

    // Розрахунок RMS напруги шуму за формулою Найквіста (V_rms = sqrt(4 * k_B * T * R * B))
    double calculate_nyquist_vrms(double bandwidth_hz) const {
        return std::sqrt(4.0 * K_B * temp_kelvin * resistance_ohm * bandwidth_hz);
    }

    // Симуляція генерації мод у смузі від 0 до B_max
    std::vector<LineMode> generate_modes(double max_freq_hz) const {
        std::vector<LineMode> modes;
        double delta_f = velocity_m_s / (2.0 * length_m);
        int mode_count = static_cast<int>(max_freq_hz / delta_f);

        modes.reserve(mode_count);
        for (int n = 1; n <= mode_count; ++n) {
            LineMode m;
            m.mode_index = n;
            m.frequency_hz = n * delta_f;
            // У термодинамічній рівновазі середня енергія моди = k_B * T
            m.energy_joules = K_B * temp_kelvin;
            modes.push_back(m);
        }
        return modes;
    }
};

int main() {
    double line_len = 100.0;    // Довжина лінії 100 метрів
    double wave_speed = 2.0e8;  // 200,000 км/с в діелектрику
    double r_val = 50.0;        // 50 Ом узгоджена система
    double temp_k = 300.0;      // 300 Кельвінів
    double target_bw = 1.0e6;   // 1 МГц смуга

    NyquistTransmissionLineSim sim(line_len, wave_speed, r_val, temp_k);

    double th_modes = sim.calculate_theoretical_mode_count(target_bw);
    double p_avail = sim.calculate_available_noise_power(target_bw);
    double vrms = sim.calculate_nyquist_vrms(target_bw);

    std::cout << std::scientific << std::setprecision(5);
    std::cout << "=== Термодинамічна симуляція Найквіста ===" << std::endl;
    std::cout << "Довжина лінії L:           " << line_len << " м" << std::endl;
    std::cout << "Опір резисторів R:        " << r_val << " Ом" << std::endl;
    std::cout << "Температура T:            " << temp_k << " K" << std::endl;
    std::cout << "Аналізована смуга B:       " << target_bw << " Гц" << std::endl;
    std::cout << "------------------------------------------" << std::endl;
    std::cout << "Кількість мод N (2LB/v):  " << th_modes << std::endl;
    std::cout << "Доступна потужність kTB:  " << p_avail << " Вт" << std::endl;
    std::cout << "Шумова ЕРС V_rms:         " << vrms << " В RMS" << std::endl;
    std::cout << "Густина e_n (nV/sqrt(Hz)):" << (vrms / std::sqrt(target_bw)) * 1e9 << " нВ/sqrt(Гц)" << std::endl;

    // Перевірка незалежності доступної потужності від довжини лінії
    std::vector<LineMode> modes = sim.generate_modes(target_bw);
    double total_line_energy = modes.size() * K_B * temp_k;
    double transit_time = line_len / wave_speed;
    double p_extracted = (total_line_energy / 2.0) / transit_time;

    std::cout << "\n--- Перевірка скорочення параметрів лінії ---" << std::endl;
    std::cout << "Фактична кількість мод:   " << modes.size() << std::endl;
    std::cout << "Час прольоту лінії tau:   " << transit_time << " с" << std::endl;
    std::cout << "Вилучена потужність:      " << p_extracted << " Вт" << std::endl;
    std::cout << "Відхилення від kTB:       " << std::abs(p_extracted - p_avail) << " Вт (Ідеальний збіг)" << std::endl;

    return 0;
}
```

---

## 7. Підсумок

- Формула Найквіста випливає з термодинамічної рівноваги та принципу рівнорозподілу енергії по модах коливань.
- Доступна шумова потужність $P = k_B T B$ є універсальною межею для будь-якого пасивного резистора.
- Множник 4 та поява опору $R$ у формулі $S_v(f) = 4 k_B T R$ є прямим наслідком закону Ома для узгодженої передачі потужності на навантаження.
