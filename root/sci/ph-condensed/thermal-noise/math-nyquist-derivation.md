# 🧮 Математичне виведення закону Найквіста та флуктуаційно-дисипативної теореми

Математичний апарат опису теплового шуму базується на двох фундаментальних і взаємодоповнювальних підходах: макроскопічному термодинамічному аналізі рівноважного електромагнітного випромінювання у довгій лінії передачі та мікроскопічному кінетичному описі стохастичних флуктуацій дрейфової швидкості вільних носіїв заряду через стохастичне рівняння Ланжевена та спектральну теорему Вінера — Хінчина.

## 1. Макроскопічне термодинамічне виведення Найквіста (модель одновимірного резонатора)

Розглянемо термодинамічну модель, запропоновану Гаррі Найквістом у 1928 році. Нехай дві однакові активні провідності або резистори з активним опором `R` розташовані на протилежних кінцях ідеальної двопровідної лінії передачі довжиною `L`, яка володіє хвильовим опором `Z₀ = R`. Вся система замкнена у суцільний термостат і перебуває в стані строгої термодинамічної рівноваги при абсолютній температурі `T`.

Оскільки хвильовий опір лінії `Z₀` точно дорівнює опору навантажень `R`, на обох кінцях лінії виконується умова повного узгодження імпедансів. Це означає, що будь-яка електромагнітна хвиля, яка випромінюється лівим резистором, без відбиття проходить через лінію і повністю поглинається правим резистором, де її енергія дисипує в тепло. Аналогічно, шумова ЕРС правого резистора випромінює хвилю, що рухається у зворотному напрямку і повністю поглинається лівим резистором.

У такій лінії передачі виникає ансамбль стоячих електромагнітних хвиль. Нульові граничні умови для потенціалу чи струму на кінцях резонатора довжиною `L` визначають дискретний спектр власних частот мод:

```
f_n = n · v / (2 · L)      [власна частота n-ї моди]
```

де `v` — швидкість поширення електромагнітної хвилі в ізоляторі лінії передачі, a `n = 1, 2, 3…` — цілочисельний номер моди.

Інтервал частот між двома сусідніми модами дорівнює `Δf_mode = f_{n+1} - f_n = v / (2 · L)`. Отже, кількість власних мод `Δn`, що припадає на довільний вузький частотний інтервал `Δf`, становить:

```
Δn = Δf / Δf_mode = (2 · L / v) · Δf      [кількість хвильових мод у смузі Δf]
```

Згідно з класичною статистичною механікою Больцмана та теоремою про рівнорозподіл енергії по ступенях вільності, на кожну стоячу електромагнітну моду в стані термодинамічної рівноваги припадає середня кінетична та потенціальна енергія:

```
⟨E_mode⟩ = k_B · T      [середня енергія однієї моди у класичній межі]
```

де `k_B = 1.380649 × 10⁻²³ J/K` — стала Больцмана. По `k_B · T / 2` припадає на флуктуації електричного поля та `k_B · T / 2` — на флуктуації магнітного поля моди.

Отже, повна електромагнітна енергія `E_line`, накопичена у довгій лінії в інтервалі частот `Δf`, дорівнює добутку кількості мод на середню енергію однієї моди:

```
E_line = Δn · ⟨E_mode⟩ = (2 · L / v) · k_B · T · Δf      [повна теплова енергія хвиль]
```

Ця накопичена енергія утворена двома незалежними біжучими хвилями однакової інтенсивності, які рухаються в протилежних напрямках зі швидкістю `v`. Потік енергії однієї хвилі, що рухається зліва направо, дорівнює половині загальної енергії лінії `(1 / 2) · E_line`. Час проходження хвилі від лівого до правого резистора становить `τ_pass = L / v`.

Отже, шумова потужність `P`, яку лівий резистор постійно випромінює в лінію передачі у напрямку правого резистора в смузі частот `Δf`, дорівнює відношенню енергії біжучої хвилі до часу її прольоту:

```
P = ( (1 / 2) · E_line ) / τ_pass
  = [ (1 / 2) · (2 · L / v) · k_B · T · Δf ] / (L / v)
  = k_B · T · Δf      [потужність шуму в узгодженій смузі Δf]
```

З іншого боку, розглянемо схематичний опис лівого резистора за схемою Тевеніна як ідеального безшумного опору `R`, підключеного послідовно з джерелом випадкової шумової ЕРС `U_th(t)`. Якщо цей еквівалентний генератор замкнений на узгоджений зовнішній опір `Z₀ = R`, то за теоремою про максимальну передачу потужності активна потужність, яка виділяється у зовнішньому навантаженні у смузі `Δf`, становить:

```
P_max = ⟨U_th²⟩ / (4 · R)      [максимальна передана потужність]
```

Прирівнюючи макроскопічний термодинамічний вираз для потужності `P = k_B · T · Δf` до електричного виразу `P_max`, отримуємо строгу математичну рівність:

```
⟨U_th²⟩ / (4 · R) = k_B · T · Δf
⇒ ⟨U_th²⟩ = 4 · k_B · T · R · Δf      [закон Найквіста для напруги]
```

Ділення обидвох частин рівняння на ширину частотної смуги `Δf` визначає односторонню спектральну щільність потужності напруги `S_V(f)`:

```
S_V(f) = d⟨U_th²⟩ / df = 4 · k_B · T · R      [спектральна щільність напруги]
```

Цей результат показує, що спектральна щільність теплового шуму є строго константою і визначається виключно трьома фундаментальними величинами: температурою `T`, активним опором `R` та сталою Больцмана `k_B`.

## 2. Мікроскопічне виведення через рівняння Ланжевена та модель Друде

Мікроскопічний підхід розглядає виникнення теплового шуму як результантну суму стохастичних дрейфових переміщень великого ансамблю `N` вільних носіїв заряду (електронів) у провіднику об'ємом `V` та довжиною `l`.

Розглянемо хаотичний рух одного електрона масою `m` та зарядом `e` уздовж осі провідника. Динаміка його проекції швидкості `v(t)` під дією теплових поштовхів із боку атомарної кристалічної ґратки описується феноменологічним стохастичним рівнянням Ланжевена:

```
m · dv/dt + (m / τ) · v = F_fl(t)      [рівняння Ланжевена для електрона]
```

де `τ` — час релаксації імпульсу електрона між двома послідовними розсіяннями на фононах чи домішках, a `F_fl(t)` — випадкова теплова сила, яка описує миттєві мікроскопічні удари ґратки.

Для випадкової сили `F_fl(t)` виконуються стандартні умови дельта-корельованого гаусового білого шуму:

```
⟨F_fl(t)⟩ = 0      [відсутність систематичного напрямку сил]
⟨F_fl(t) · F_fl(t + t')⟩ = C_F · δ(t')      [відсутність тривалої часової пам'яті]
```

де `δ(t')` — дельта-функція Дірака, а `C_F` — амплітудний інтенсивнісний коефіцієнт шуму сили.

Множення рівняння Ланжевена на початкову швидкість `v(0)` та процедура статистичного усереднення по ансамблю частинок дають диференціальне рівняння для автокореляційної функції швидкості `R_v(t') = ⟨v(t) · v(t + t')⟩`:

```
d/dt' R_v(t') + (1 / τ) · R_v(t') = 0      [диференційне рівняння для кореляції]
```

Розв'язком цього рівняння при початковій умові `R_v(0) = ⟨v²⟩` є згасаюча експонента:

```
R_v(t') = ⟨v²⟩ · exp(-|t'| / τ)      [автокореляційна функція швидкості]
```

Згідно з теоремою класичної статистичної механіки про рівнорозподіл енергії, середня кінетична енергія одновимірного хаотичного руху електрона дорівнює:

```
(1 / 2) · m · ⟨v²⟩ = (1 / 2) · k_B · T  ⇒  ⟨v²⟩ = k_B · T / m      [дисперсія теплової швидкості]
```

За теоремою Вінера — Хінчина, одностороння спектральна щільність потужності флуктуацій швидкості електрона `S_v(f)` дорівнює подвоєному косинус-перетворенню Фур'є від її автокореляційної функції `R_v(t')`:

```
S_v(f) = 4 · ∫₀^∞ R_v(t') · cos(2π · f · t') dt'
        = 4 · (k_B · T / m) · ∫₀^∞ exp(-t' / τ) · cos(2π · f · t') dt'
        = 4 · (k_B · T / m) · [ τ / (1 + (2π · f · τ)²) ]      [спектральна щільність швидкості]
```

У низькочастотному діапазоні, де частота спостереження набагато менша за частоту зіткнень електронів (`2π · f · τ ≪ 1`), знаменник прямує до одиниці `1 + (2π · f · τ)² ≈ 1`. Оскільки для металів час релаксації становить `τ ~ 10⁻¹⁴ s`, ця умова виконується аж до терагерцових частот (`f ≪ 16 THz`). У цій області спектральна щільність швидкості поодинокої частинки стає строго пласкою:

```
S_v(0) = 4 · (k_B · T / m) · τ      [низькочастотне плато спектра швидкості]
```

Тепер перейдемо від руху одного електрона до сумарного макроскопічного струму `I(t)` у провіднику довжиною `l`. Миттєвий струм створюється сумою дрейфових переміщень усіх `N` вільних електронів:

```
I(t) = (e / l) · ∑_{i=1}^N v_i(t)      [макроскопічний струм ансамблю]
```

Оскільки зіткнення окремих електронів із кристалічною ґраткою відбуваються статистично незалежно одне від одного, крос-кореляційні доданки видами `⟨v_i(t) · v_j(t')⟩` при `i ≠ j` перетворюються на нуль при усередненні. Отже, спектральна щільність флуктуацій сумарного струму `S_I(f)` дорівнює просто сумі спектральних щільностей швидкості окремих частинок:

```
S_I(f) = (e / l)² · N · S_v(0)
        = (e / l)² · N · [ 4 · (k_B · T / m) · τ ]
        = 4 · k_B · T · [ (N · e² · τ) / (m · l²) ]      [спектральна щільність струму]
```

Згадаємо класичну формулу Друде для електропровідності та сумарної провідності провідника `G = 1 / R`:

```
G = (N · e² · τ) / (m · l²)      [провідність провідника за моделлю Друде]
```

Підставляючи вираз для провідності `G` у формулу спектральної щільності струму, отримуємо формулу Найквіста для флуктуацій струму (модель Нортона):

```
S_I(f) = 4 · k_B · T · G      [спектральна щільність струму шуму]
```

Застосовуючи закон Ома для шумових амплітуд `S_V(f) = S_I(f) · R² = 4 · k_B · T · G · R²`, ми знову приходимо до формули Найквіста для напруги:

```
S_V(f) = 4 · k_B · T · R      [закон Найквіста]
```

Таким чином, кінетичний мікроскопічний підхід Ланжевена — Друде дає точний результат, який повністю збігається з макроскопічним термодинамічним виведенням Найквіста.

## 3. Флуктуаційно-дисипативна теорема Каллена — Велтона та узагальнений імпеданс

У 1951 році Герберт Каллен та Теодор Велтон узагальнили закон Найквіста на довільні квантові та класичні дисипативні системи, сформулювавши **флуктуаційно-дисипативну теорему (ФДТ)**.

Нехай термодинамічна система описується узагальненою координованою величиною `x(t)` та зовнішньою узагальненою силою `f_ext(t)`. Лінійне рівняння відгуку системи у частотній області має вигляд `x(ω) = χ(ω) · f_ext(ω)`, де `χ(ω) = χ'(ω) + i · χ''(ω)` — комплексне сприйняття (динамічна сприйнятливість системи).

Уявна частина сприйнятливості `χ''(ω)` відповідає за незворотну дисипацію енергії зовнішнього впливу у тепловий резервуар. Згідно з теоремою Каллена — Велтона, одностороння спектральна щільність рівноважних спонтанних флуктуацій величини `x(t)` строго визначається уявною частиною дисипативного відгуку:

```
S_x(f) = 4 · k_B · T · [ χ''(2π · f) / (2π · f) ]      [класична форма ФДТ]
```

Для електричних кіл узагальненою силою виступає струм `I(t)`, а узагальненою реакцією — напруга `U(t)`. Роль коефіцієнта пропорційності відіграє комплексний імпеданс кола `Z(ω) = R(ω) + i · X(ω)`. Дисипація енергії задається дійсною частиною імпедансу `Re[Z(ω)] = R(ω)`.

У результаті ФДТ для комплексного двохполюсника набере вигляду:

```
S_V(f) = 4 · k_B · T · Re[ Z(2π · f) ]      [ФДТ для електричного імпедансу]
```

Якщо коло містить кілька активних і реактивних елементів, сумарний шум на виході обчислюється шляхом знаходження еквівалентного опіру дисипації `Re[Z_eq(ω)]` всієї схеми на даній частоті.

### Теорема Онсагера та матричний узагальнений шум багатополюсників

Для складних багатотермінальних електричних кіл або багатокомпонентних конденсованих середовищ (наприклад, анізотропних кристалів) шумові флуктуації описуються матрицею спектральних щільностей `S_{ij}(f) = d⟨U_i · U_j⟩ / df`.

Згідно з принципом мікроскопічної оборотності Онсагера та квантовою ФДТ у формулюванні Рього Кубо (1957), матриця шумових спектральних щільностей зв'язана з матрицею комплексних імпедансів `Z_{ij}(ω)` співвідношенням:

```
S_{ij}(f) = 2 · k_B · T · [ Z_{ij}(2π · f) + Z_{ji}^*(2π · f) ]      [теорема Онсагера — Кубо]
```

де `Z_{ji}^*` — комплексно-спряжена матриця взаємних імпедансів. У разі відсутності зовнішнього магнітного поля `B = 0` матриця імпедансів є симетричною `Z_{ij} = Z_{ji}`, що спрощує матричний шум до залежності від дійсних частин елементів `Re[Z_{ij}]`.

При наявності зовнішнього магнітного поля `B` принцип симетрії кінетичних коефіцієнтів Онсагера набирає вигляду `Z_{ij}(B) = Z_{ji}(-B)`, що описує взаємний шум у системі при квантовому ефекті Холла та магнітоопорі.

## 4. Квантове узагальнення Планка — Найквіста

При надвисоких частотах або кріогенних температурах класичний вираз для середньої енергії модального осцилятора `⟨E⟩ = k_B · T` замінюється квантово-механічним виразом Планка.

У квантовій статистиці середня енергія електромагнітної моди частотою `f` складається з енергії вимушених теплових фотонів та енергії нульових коливань вакууму:

```
⟨E_quant⟩ = h · f / (exp(h · f / (k_B · T)) - 1) + (1 / 2) · h · f      [квантова енергія осцилятора]
```

де `h = 6.62607015 × 10⁻³⁴ J·s` — стала Планка.

Підставляючи квантову енергію осцилятора у термодинамічну формулу Найквіста, отримуємо **формулу Планка — Найквіста**:

```
S_V(f) = 4 · R · [ h · f / (exp(h · f / (k_B · T)) - 1) + (1 / 2) · h · f ]      [квантова формула Найквіста]
```

Проаналізуємо граничні випадки цієї фундаментальної формули:

1. **Класичний границя (`h · f ≪ k_B · T`)**:
   Використовуючи розклад експоненти у степеневий ряд `exp(x) ≈ 1 + x + x² / 2`, отримуємо:
   ```
   h · f / (exp(h · f / (k_B · T)) - 1) ≈ h · f / (1 + h · f / (k_B · T) - 1) = k_B · T
   ```
   У цій області квантовий доданок `(1 / 2) · h · f` є знехтовно малим, і формула Планка — Найквіста точно перетворюється на класичну формулу Найквіста `S_V(f) = 4 · k_B · T · R`.

2. **Квантова границя (`h · f ≫ k_B · T`)**:
   Тепловий доданок експоненціально прямує до нуля `exp(h · f / (k_B · T)) → ∞`, і в спектрі залишається лише член нульових квантових коливань:
   ```
   S_V_quantum(f) = 2 · h · f · R      [спектральна щільність нульового квантового шуму]
   ```

Цей член визначає фундаментальну квантову межу шуму, яку неможливо усунути жодним охолодженням. Вона задає межу чутливості надпровідних кріогенних підсилювачів, квантових обчислювальних систем та оптичних фотодетекторів.
