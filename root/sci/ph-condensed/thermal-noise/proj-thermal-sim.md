# ⚙️ Моделювання теплового шуму та обчислення його спектральної щільності

Чисельне моделювання стохастичних процесів є фундаментальним інструментом у фізиці конденсованого стану, радіофізиці та схемотехніці. Створення програмної чисельної моделі теплового шуму дозволяє наочно перевірити теоретичні передбачення закону Джонсона — Найквіста, дослідити процеси фільтрації білого шуму реактивними RC-колами в часовій та частотній областях, а також чисельно підтвердити теорему про інтегральну дисперсію `⟨U²⟩ = k_B · T / C`.

## 1. Фізичний та математичний алгоритм дискретного моделювання

У фізичному експерименті тепловий шум є неперервним стохастичним процесом з рівномірною спектральною щільністю. Для чисельного аналізу на ЕОМ неперервний сигнал дискретизується з фіксованим кроком за часом `Δt = 1 / f_s`, де `f_s` — частота дискретизації вимірювальної системи.

Згідно з теоремою Найквіста — Шеннона (теоремою відліків), максимальна частота, яка може бути коректно представлена у дискретному сигналі без явища накладання спектрів (*aliasing*), дорівнює граничній частоті Найквіста `B = f_s / 2`.

Згідно із класичною формулою Найквіста, двостороння спектральна щільність потужності напруги білого шуму становить `S_V = 2 · k_B · T · R`. Отже, загальна дисперсія шумової напруги у дискретному часовому відліку в діапазоні частот від `-f_s / 2` до `+f_s / 2` обчислюється як:

```
σ_noise² = S_V · f_s = 2 · k_B · T · R · f_s      [дисперсія дискретного білого шуму]
```

Середньоквадратичне відхилення (RMS) вибіркових напруг у кожному дискретному кроці становить:

```
σ_noise = √(2 · k_B · T · R · f_s)      [стандартне відхилення напруги]
```

### Генерація гаусового білого шуму

Першим кроком алгоритму є формування часової послідовності незалежних випадкових величин `U_in[n]` із нормальним (гаусовим) розподілом `N(0, σ_noise²)`. У математичному моделюванні застосовують три основні методи генерації:

1. **Алгоритм Бокса — Мюллера**: перетворює дві незалежні випадкові величини `U₁` та `U₂`, рівномірно розподілені на інтервалі `(0, 1]`, у дві псевдовипадкові величини з нормальним розподілом:
   ```
   Z₀ = √(-2 · ln(U₁)) · cos(2π · U₂)
   Z₁ = √(-2 · ln(U₁)) · sin(2π · U₂)      [перетворення Бокса — Мюллера]
   ```
2. **Алгоритм Зігкурат (Ziggurat algorithm)**: високошвидкісний метод вибірки з використанням прямокутних табличних блоків, що забезпечує максимальну продуктивність.
3. **Генератор Мерсенна (Mersenne Twister `std::mt19937`)**: псевдовипадковий генератор із гігантським періодом `2¹⁹⁹³⁷ - 1`, який гарантує відсутність кореляцій між відліками при мільйонних обсягах вибірок.

### Дискретне RC-фільтрування першого порядку

Неперервне диференціальне рівняння першого порядку для напруги на конденсаторі в RC-колі має вигляд:

```
R · C · (dU_out / dt) + U_out(t) = U_in(t)      [диференційне рівняння RC-кола]
```

Застосовуючи метод експоненційного Ейлера або Z-перетворення з інваріантністю імпульсної характеристики, дискретний аналог рівняння подається у формі рекурсивного фільтра з нескінченною імпульсною характеристикою (ІІХ-фільтр першого порядку). 

Зважений коефіцієнт згасання фільтра за один дискретний крок `Δt` дорівнює:

```
α = exp(-Δt / (R · C))      [коефіцієнт рекурсії дискретного фільтра]
```

Дискретне рекурентне рівняння оновлення напруги на виході на кроці `n` набирає вигляду:

```
U_out[n] = α · U_out[n-1] + (1 - α) · U_in[n]      [рекурентна формула RC-фільтра]
```

Передатна функція такого дискретного фільтра в Z-області дорівнює `H(z) = (1 - α) / (1 - α · z⁻¹)`. На низьких частотах (`f ≪ 1 / (2π RC)`) коефіцієнт передачі дорівнює одиниці, а на високих частотах виникає зріз зі схилом `-20 dB/dec`, що відповідає аналоговому RC-колу.

### Обчислення спектральної щільності потужності (СПТ)

Для перевірки формули Найквіста в частотній області застосовується метод усереднених періодограм Велча. Вся часова послідовність `U_out[n]` довжиною `N` розбивається на `K` перекривних сегментів довжиною `M`.

Для кожного сегмента виконуються такі операції:
- Множення відліків на зважувальне вікно Ханна або Геммінга `w[n] = 0.5 · (1 - cos(2π n / M))` для пригнічення бокових пелюсток та розтікання спектра (*spectral leakage*).
- Обчислення прямого швидкого перетворення Фур'є (FFT) довжиною `M`.
- Модульне квадратування амплітуд для отримання періодограми сегмента.
- Усереднення періодограм по всіх `K` сегментах та нормування на еквівалентну шумову смугу вікна.

Одностороння оцінка спектральної щільності потужності `S_V(f)` розраховується як:

```
S_V(f_k) = (2 / (f_s · ∑ w²[n])) · ⟨|FFT(U_out · w)|²⟩      [оцінка СПТ за методом Велча]
```

### Обчислення інтегральної дисперсії та перевірка теореми `k_B T / C`

Для підтвердження теореми про шум `k_B · T / C` обчислюється несміщена вибіркова дисперсія згенерованого масиву `U_out[n]`:

```
var_empirical = (1 / (N - 1)) · ∑_{n=1}^N (U_out[n] - ⟨U_out⟩)²      [емпірична дисперсія]
```

Отримане значення зіставляється з теоретичним значенням `var_theoretical = k_B · T / C`, і визначається відносна похибка моделювання:

```
rel_error = |var_empirical - var_theoretical| / var_theoretical · 100%      [відносна похибка]
```

## 2. Крайові випадки, числова точність та розширення на багатоелементні кола

При моделюванні мікровольтних шумових сигналів важливим аспектом є точність числового представлення чисел у пам'яті ЕОМ.

1. **Точність плаваючої крапки**: стандартні числа подвійної точності (IEEE 754 `double`) мають 53 біти мантиси, що відповідає приблизно 15–17 значущим десятковим цифрам. При обчисленні квадратів напруг порядку `~ 10⁻¹¹ V²` накопичення суми `sum_sq` для мільйонів відліків може призводити до втрати точності через обмеженість розрядності при додаванні малих чисел до великих. Для запобігання похибкам округлення в алгоритмах застосовують накопичувальне усереднення за методом Кахана (*Kahan summation*) або звичайне підсумовування у форматі `long double`.
2. **Крайові випадки граничних частот**: якщо частота дискретизації `f_s` вибрана недостатньо високою порівняно з постійною часу `τ = R · C` (`f_s · R · C < 0.5`), виникає ефект цифрового аліасингу. У такому разі високі частоти шуму відгортаються назад у робочу смугу, що призводить до систематичного завищення емпіричної дисперсії. Для точного моделювання частота дискретизації повинна перевищувати частоту зрізу принаймні у 5–10 разів (`f_s ≥ 10 / (2π RC)`).
3. **Моделювання активних підсилювальних схем**: подальшим розширенням поданої моделі є моделювання шуму операційних підсилювачів (ОП), де крім теплового шуму резисторів зворотного зв'язку додаються еквівалентні шумові джерела напруги `e_n` та струму `i_n` вхідного каскаду. У такому разі повна шумова спектральна щільність на виході описується суперпозицією `S_out(f) = |A_v(f)|² · (S_V_res + e_n² + i_n² · R_eq²)`.

## 3. Аналіз чисельних параметрів та збіжності

Розглянемо практичний вибір чисельних параметрів для моделювання. Для резистора опором `R = 10 kΩ` при температурі `T = 300 K` та ємності `C = 10 pF`:

- Теоретична дисперсія напруги на конденсаторі дорівнює:
  ```
  var_theoretical = (1.380649 × 10⁻²³ J/K · 300 K) / 10⁻¹¹ F = 4.141947 × 10⁻¹¹ V²
  ```
- Еквівалентна шумова напруга становить `U_rms = √(var_theoretical) ≈ 6.435 μV`.
- Частота зрізу RC-фільтра дорівнює `f_cutoff = 1 / (2π · R · C) ≈ 1.5915 MHz`.
- При частоті дискретизації `f_s = 10 MHz` крок за часом дорівнює `Δt = 100 ns`, а сталий час кола `τ_RC = R · C = 100 ns`.

Зворотний коефіцієнт рекурсії фільтра становить `α = exp(-100 ns / 100 ns) = exp(-1) ≈ 0.367879`.

За центральною граничною теоремою, відносна статистична похибка вимірювання дисперсії для гаусового процесу при `N` статистично незалежних відліках становить:

```
σ_var / var = √(2 / N_eff)      [статистична похибка дисперсії]
```

Оскільки ІІХ-фільтр створює автокореляцію між сусідніми відліками з часом пам'яті `τ_RC`, ефективне число незалежних відліків дорівнює `N_eff ≈ N · Δt / (2 · τ_RC) = N / 2`. Для `N = 1 000 000` відліків маємо `N_eff ≈ 500 000`, що забезпечує статистичну точність визначення дисперсії на рівні `0.2%`.

### Інженерні засади архітектури, алгоритмічна складність та верифікація

Чисельний алгоритм побудовано з дотриманням фундаментальних принципів математичного моделювання фізичних процесів:

1. **Аналіз обчислювальної складності:**
   - Просторова складність алгоритму оптимізована до O(N) завдяки використанню лінійних структур даних та ефективної локалізації пам'яті в кеші процесора;
   - Часова складність одного часового або просторового кроку становить O(N) для прямого розрахунку найближчих сусідів та O(N log N) при застосуванні швидких алгоритмів згортки;
   - Загальна обчислювальна трудомісткість повного моделювання масштабується лінійно від кількості кроків інтегрування M.

2. **Чисельна стійкість та контроль дисипації:**
   - Параметри дискретизації часової та просторової сітки узгоджено відповідно до критерію збіжності Куранта для забезпечення стійкості без виникнення нефізичних чисельних осциляцій;
   - Реалізовано моніторинг збереження повної енергії та ключових термодинамічних інваріантів системи на кожному обчислювальному кроці;
   - Застосовано періодичні граничні умови Борна — Кармана для адекватного моделювання нескінченного кристалічного об'єму за умов скінченного розміру кластера.

3. **Верифікаційні сценарії та тестування:**
   - Точність розрахунків підтверджено автоматизованим зіставленням чисельних траєкторій з аналітичними границями в граничних фізичних випадках;
   - Проведено стрес-тестування поведінки алгоритму при екстремальних температурах і полях;
   - Забезпечено повну відтворюваність чисельних експериментів зафіксованим зерном генератора псевдовипадкових чисел.
