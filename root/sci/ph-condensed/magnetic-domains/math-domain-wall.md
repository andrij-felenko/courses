# 🧮 Математика доменної стінки

Ця вставка містить строгий математичний розрахунок внутрішньої структури 180-градусної доменної стінки Блоха, варіаційне виведення рівняння профілю кута повороту спінів, порівняльний енергетичний розрахунок стінок Блоха та Нееля в тонких плівках, обчислення ефективної товщини, поверхневої густини енергії, а також аналіз динамічної рухливості та межі Волкера у зовнішньому магнітному полі з покроковими чисельними прикладами.

## Модель безперервного середовища та густина енергії

Розглянемо 180-градусну доменну стінку в монокристалічному одновісному феромагнетику. Нехай перпендикулярна до площини стінки координатна вісь орієнтована вздовж `x`. При `x → -∞` вектор намагніченості `M` спрямований уздовж легкої осі `+z` (кут відхилення `θ = 0`), а при `x → +∞` — уздовж протилежного напрямку `-z` (кут `θ = π`).

У мікромагнітному наближенні безперервного середовища локальний напрямок векторів намагніченості описується плавною функцією `θ(x)`. Повна густина вільної енергії на одиницю площі стінки `w(x)` виражається як сума двох основних фізичних внесків — квантової обмінної енергії та енергії магнітокристалічної анізотропії:

```
w(x) = w_ex(x) + w_a(x)               [сумарна густина енергії доменної стінки]
```

Розберемо фізичний зміст та джерела кожного з двох компонентів:

1. **Густина обмінної енергії `w_ex(x)`:**
   У дискретній атомній решітці з постійною ґратки `a` обмінна енергія двох сусідніх спінів під кутом `Δθ` дорівнює `J · (Δθ)²`. Переходячи до безперервної межі, де `Δθ ≈ a · (dθ/dx)`, отримуємо обмінну густину енергії через мікромагнітний параметр обмінного зв'язку `A` (вимірюється в Дж/м):
   ```
   w_ex(x) = A · (dθ/dx)²             [густина обмінної енергії в безперервному середовищі]
   ```
   Параметр `A` пов'язаний з інтегралом обміну `J`, величиною спіна `S` та геометричним фактором решітки формулою `A ≈ 2 J S² / a` для простої кубічної решітки (`A ≈ 4 J S² / a` для ОЦК і `A ≈ 2 J S² / a` для ГЦК).

2. **Густина енергії анізотропії `w_a(x)`:**
   Для одновісного кристала з константою анізотропії `K` (вимірюється в Дж/м³) енергія відхилення вектора намагніченості на кут `θ` від легкої осі `z` дорівнює:
   ```
   w_a(x) = K · sin²(θ)               [густина енергії одновісної анізотропії]
   ```

Повна поверхнева густина енергії доменної стінки `γ_dw` (вимірюється в Дж/м²) виражається у вигляді варіаційного інтеграла по всьому простору вздовж координати `x`:

```
γ_dw = ∫₋∞⁺∞ [ A · (dθ/dx)² + K · sin²(θ) ] dx   [фундаментальний варіаційний інтеграл стінки]
```

## Варіаційне виведення рівняння профілю стінки

Рівноважна конфігурація спінів `θ(x)` відповідає стану, який мінімізує функціонал поверхневої енергії `γ_dw`. Для знаходження екстремуму застосуємо класичний метод варіаційного числення.

Позначимо підінтегральну функцію як `F(θ, θ') = A · (θ')² + K · sin²(θ)`, де `θ' = dθ/dx`. Рівняння Ейлера-Лагранжа для цього функціоналу має вигляд:

```
∂F/∂θ - d/dx ( ∂F/∂θ' ) = 0           [рівняння Ейлера-Лагранжа для варіаційного функціоналу]
```

Обчислимо частинні похідні функції `F`:

```
∂F/∂θ = 2K · sin(θ) · cos(θ) = K · sin(2θ)   [похідна за кутом від енергії анізотропії]
∂F/∂θ' = 2A · θ'                       [похідна за градієнтом кута від обмінної енергії]
d/dx ( ∂F/∂θ' ) = 2A · θ''             [повна похідна по координаті x]
```

Підставивши знайдені похідні у рівняння Ейлера-Лагранжа, отримуємо нелінійне диференціальне рівняння другого порядку для просторового профілю доменної стінки:

```
2A · (d²θ/dx²) - K · sin(2θ) = 0       [нелінійне диференціальне рівняння профілю стінки]
```

Для першого інтегрування помножимо обидві частини рівняння на `(dθ/dx)`:

```
2A · (d²θ/dx²) · (dθ/dx) = K · sin(2θ) · (dθ/dx)  [множення на похідну]
A · d/dx [ (dθ/dx)² ] = K · d/dx [ sin²(θ) ]      [згортання у повні похідні]
```

Проінтегрувавши обидві частини за координатою `x` з граничними умовами асимптотики `dθ/dx → 0` при `θ → 0` (всередині об'єму домену при `x → -∞`), отримуємо перше інтегральне співвідношення:

```
A · (dθ/dx)² = K · sin²(θ)             [точна локальна рівність обмінної та анізотропної енергій]
```

Цей важливий фізичний результат означає: у кожній точці рівноважної доменної стінки локальна густина обмінної енергії строго дорівнює локальній густині енергії анізотропії.

## Точне інтегрування профілю Блохівської стінки

Добудемо квадратний корінь з обох частин отриманого співвідношення:

```
dθ/dx = √(K / A) · sin(θ)              [диференціальне рівняння першого порядку]
```

Введемо фундаментальний характеристичний масштаб довжини `δ₀`:

```
δ₀ = √(A / K)                          [характеристичний мікромагнітний масштаб]
```

Розділимо змінні в диференціальному рівнянні та запишемо інтеграл:

```
dθ / sin(θ) = (1 / δ₀) · dx           [розділення змінних]
```

Обчислимо первісну лівої частини:

```
∫ dθ / sin(θ) = ln | tan(θ / 2) |     [табличний інтеграл тригонометричної підстановки]
```

Приймаючи центр доменної стінки в точці `x = 0`, де кут повороту дорівнює `θ(0) = π / 2` (і відповідно `tan(π/4) = 1`, `ln(1) = 0`), отримуємо аналітичну залежність:

```
ln(tan(θ / 2)) = x / δ₀                [логарифмічна форма розв'язку]
tan(θ / 2) = exp(x / δ₀)               [експоненціальна форма розв'язку]
```

Взявши арктангенс від обох частин, отримуємо точний аналітичний профіль 180-градусної доменної стінки Блоха:

```
θ(x) = 2 · arctan( exp(x / δ₀) )        [точний аналітичний профіль стінки Блоха]
```

Знайдемо градієнт повороту спінів (похідну `dθ/dx`), використавши властивість гіперболічного секанса:

```
dθ/dx = (1 / δ₀) · (1 / cosh(x / δ₀))   [градієнт кута повороту спінів]
```

Градієнт досягає свого максимуму в центрі стінки при `x = 0`: `(dθ/dx)_max = 1 / δ₀`.

Звідси тригонометричні компоненти вектора намагніченості `m_z(x) = cos(θ)` та `m_y(x) = sin(θ)` виражаються через гіперболічні функції:

```
m_z(x) = -tanh(x / δ₀)                 [компонента намагніченості вздовж легкої осі]
m_y(x) = 1 / cosh(x / δ₀)              [поперечна компонента в площині стінки]
```

## Обчислення ефективної товщини та поверхневої енергії

Оскільки функція `θ(x)` наближається до `0` та `π` асимптотично на нескінченності, формально стінка має нескінченну протяжність. За загальноприйнятим визначенням Євгена Ліфшиця, **ефективна товщина доменної стінки `δ`** визначається як ширина інтервалу, який відсікає дотична до профілю `θ(x)` у її центрі `x = 0`:

```
(dθ/dx)_[x=0] = 1 / δ₀ = √(K / A)     [максимальний градієнт кута в центрі]
δ = π / (dθ/dx)_[x=0]                  [визначення ефективної товщини за Ліфшицем]
```

Звідси отримуємо точну формулу для ефективної товщини доменної стінки:

```
δ = π · δ₀ = π · √(A / K)               [формула товщини доменної стінки]
```

Тепер обчислимо повну поверхневу енергію стінки `γ_dw`. Використовуючи співвідношення `A · (dθ/dx)² = K · sin²(θ)`:

```
γ_dw = ∫₋∞⁺∞ [ A · (dθ/dx)² + K · sin²(θ) ] dx  [початковий інтеграл поверхневої енергії]
γ_dw = 2 · ∫₋∞⁺∞ K · sin²(θ) dx        [заміна обмінного додатка на анізотропний]
```

Виконуємо заміну змінної інтегрування з `x` на кут `θ`, підставивши `dx = δ₀ · dθ / sin(θ)`:

```
γ_dw = 2K · δ₀ · ∫₀^π sin²(θ) · (dθ / sin(θ))  [заміна змінної інтегрування x на кут θ]
γ_dw = 2K · √(A / K) · ∫₀^π sin(θ) dθ          [спрощення підінтегрального виразу]
γ_dw = 2 · √(A · K) · [ -cos(θ) ]₀^π           [первісна від синуса]
γ_dw = 2 · √(A · K) · [ 1 - (-1) ]             [обчислення за формулою Ньютона-Лейбніца]
γ_dw = 4 · √(A · K)                              [поверхнева густина енергії доменної стінки]
```

## Покрокові чисельні приклади розрахунку

Розглянемо покроковий розрахунок товщини та енергії стінки для двох принципово різних магнітних матеріалів при `T = 293` К.

### Приклад 1. М'якомагнітне α-залізо (`α-Fe`)

Вихідні фізичні параметри матеріалу:
- Параметр обмінного зв'язку: `A = 2.1 · 10⁻¹¹` Дж/м
- Константа магнітокристалічної анізотропії: `K = 4.8 · 10⁴` Дж/м³
- Намагніченість насичення: `M_s = 1.71 · 10⁶` А/м (`B_s ≈ 2.15` Тл)

Крок 1. Обчислення характеристичного мікромагнітного масштабу `δ₀`:
```
δ₀ = √( (2.1 · 10⁻¹¹) / (4.8 · 10⁴) )   [підстановка чисельних значень A та K]
   = √( 4.375 · 10⁻¹⁶ )                  [ділення підкореневого виразу]
   ≈ 2.0917 · 10⁻⁸ м                     [добування квадратного кореня]
   = 20.92 нм                            [переведення в нанометри]
```

Крок 2. Обчислення ефективної товщини стінки Блоха `δ`:
```
δ = π · δ₀                             [формула ефективної товщини Ліфшиця]
  = 3.14159 · 20.917 нм                [підстановка значення числового пі]
  ≈ 65.71 нм                           [перемноження величин]
```
Оскільки постійна кристалічної ґратки α-заліза дорівнює `a ≈ 0.286` нм, товщина стінки охоплює близько `65.71 / 0.286 ≈ 230` атомних шарів.

Крок 3. Обчислення поверхневої густини енергії стінки `γ_dw`:
```
γ_dw = 4 · √( (2.1 · 10⁻¹¹) · (4.8 · 10⁴) )   [формула поверхневої енергії Блоха]
     = 4 · √( 1.008 · 10⁻⁶ )                   [перемноження підкореневих величин]
     = 4 · 1.00399 · 10⁻³                      [добування квадратного кореня]
     = 4.016 · 10⁻³ Дж/м²                      [підсумкове множення]
     ≈ 4.016 мДж/м²                           [переведення в міліджоулі на кв. метр]
```

### Приклад 2. Висококоерцитивний постійний магніт неодим-залізо-бор (`Nd₂Fe₁₄B`)

Вихідні фізичні параметри матеріалу:
- Параметр обмінного зв'язку: `A = 7.7 · 10⁻¹²` Дж/м
- Константа одновісної анізотропії: `K = 4.9 · 10⁶` Дж/м³

Крок 1. Обчислення характеристичного мікромагнітного масштабу `δ₀`:
```
δ₀ = √( (7.7 · 10⁻¹²) / (4.9 · 10⁶) )   [підстановка значень для Nd2Fe14B]
   = √( 1.5714 · 10⁻¹⁸ )                  [ділення підкореневих чисельних значень]
   ≈ 1.2535 · 10⁻⁹ м                     [добування квадратного кореня]
   = 1.254 нм                            [переведення в нанометри]
```

Крок 2. Обчислення ефективної товщини стінки Блоха `δ`:
```
δ = π · δ₀                             [формула товщини стінки]
  = 3.14159 · 1.2535 нм                [підстановка значень]
  ≈ 3.94 нм                            [перемноження результату]
```
У Nd₂Fe₁₄B стінка надзвичайно тонка і охоплює всього близько 8-12 атомних шарів!

Крок 3. Обчислення поверхневої густини енергії стінки `γ_dw`:
```
γ_dw = 4 · √( (7.7 · 10⁻¹²) · (4.9 · 10⁶) )   [формула поверхневої енергії стінки]
     = 4 · √( 3.773 · 10⁻⁵ )                   [перемноження підкореневого виразу]
     = 4 · 6.1425 · 10⁻³                       [добування квадратного кореня]
     = 24.57 · 10⁻³ Дж/м²                      [підсумкове множення]
     ≈ 24.57 мДж/м²                           [переведення в мДж/м²]
```
Енергія стінки в Nd₂Fe₁₄B у 6 разів вища, ніж у м'якому залізі, через гігантську кристалічну анізотропію.

## Математичне зіставлення стінок Блоха та Нееля в тонких плівках

У тонких магнітних плівках товщиною `d` повертання вектора намагніченості у стінці Нееля створює внутрішні магнітостатичні заряди із додатковою густиною демагнетизуючої енергії `w_d`.

Луї Неель показав, що для стінки Нееля в плівці товщиною `d` повна густина поверхневої енергії `γ_Néel` дорівнює:

```
γ_Néel ≈ 4 · √(A · K) + (μ₀ · M_s² · d · δ) / (d + δ)   [поверхнева енергія стінки Нееля]
```

У той же час для стінки Блоха у тонкій плівці виникає додаткова поверхнева магнітостатична енергія через вихід вектора `M` за межі плівки:

```
γ_Bloch ≈ 4 · √(A · K) + (μ₀ · M_s² · δ²) / (2 · (d + δ)) [поверхнева енергія стінки Блоха]
```

Порівнюючи значення `γ_Néel` та `γ_Bloch`, бачимо:
- При `d << δ` (дуже тонкі плівки): `γ_Néel < γ_Bloch`, тобто **стінка Нееля є енергетично стійкішою**.
- При `d >> δ` (масивні зразки): `γ_Bloch < γ_Néel`, тобто **стінка Блоха є енергетично стійкішою**.

Критична товщина переходу від стінки Нееля до стінки Блоха `d_cross` визначається точкою рівності їхніх енергій `γ_Néel(d_cross) = γ_Bloch(d_cross)`.

## Динаміка руху доменних стінок та межа Волкера

При накладенні зовнішнього магнітного поля `H > H_c` на стінку діє магнітний тиск `P_mag = 2 · μ₀ · M_s · H`. У феноменологічній теорії Ландау-Ліфшиця-Гільберта (LLG) швидкість зсуву стінки `v` у слабких полях лінійно залежить від поля:

```
v = μ_dw · (H - H_c)                   [стаціонарна швидкість зсуву доменної стінки]
```

де `μ_dw` — рухливість доменної стінки (вимірюється в м/(с·А)):

```
μ_dw = (γ_e · δ₀) / α                  [формула рухливості доменної стінки]
```

тут `γ_e` — ґіромагнітне співвідношення електрона (`γ_e ≈ 2.21 · 10⁵` м/(А·с)), а `α` — безрозмірний коефіцієнт загасання Гільберта (`α ≈ 0.01…0.1`).

Проте при збільшенні зовнішнього поля `H` швидкість стінки не може зростати нескінченно. При досягненні критичного поля Волкера `H_W = α · 2π · M_s` внутрішня структура стінки перестає бути стаціонарною: спіни всередині стінки починають прецесувати навколо зовнішнього поля, викликаючи періодичні коливання структури (перехід від Блохівського профілю до Неелівського).

Максимально можлива стаціонарна швидкість зсуву доменної стінки називається **межею Волкера (Walker breakdown limit)**:

```
v_W = γ_e · δ₀ · 2π · M_s              [межа швидкості Волкера]
```

Для масивного заліза `v_W ≈ 100…300` м/с. Перевищення межі Волкера призводить до різкого падіння середньої швидкості зсуву стінки та виникнення турбулентної прецесії спінів.

## Табличні параметри реальних феромагнетиків

У наведеній нижче таблиці подано фундаментальні мікромагнітні константи та розраховані значення товщини `δ` і поверхневої енергії `γ_dw` для основних промислових матеріалів при `T = 293` К:

| Матеріал | Параметр обміну `A` (пДж/м) | Константа анізотропії `K` (кДж/м³) | Намагніченість `M_s` (кА/м) | Товщина стінки `δ` (нм) | Енергія стінки `γ_dw` (мДж/м²) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Залізо (α-Fe)** | 21.0 | 48.0 | 1710 | 65.7 | 4.02 |
| **Нікель (Ni)** | 9.0 | 4.5 | 485 | 140.5 | 0.80 |
| **Кобальт (Co, hcp)** | 15.0 | 410.0 | 1440 | 19.0 | 9.92 |
| **Магнетит (Fe₃O₄)** | 7.0 | 11.0 | 480 | 79.2 | 1.75 |
| **Самарій-кобальт (SmCo₅)** | 12.0 | 17000.0 | 860 | 2.6 | 57.10 |
| **Неодим-залізо-бор (Nd₂Fe₁₄B)** | 7.7 | 4900.0 | 1280 | 3.9 | 24.50 |

З порівняльного аналізу видно: матеріали для постійних магнітів (SmCo₅, Nd₂Fe₁₄B) мають гігантські константи анізотропії `K`, що робить їхні доменні стінки надзвичайно тонкими (від 2.6 до 3.9 нм, що відповідає всього 8-12 атомним шарам) та забезпечує колосальну поверхневу енергію `γ_dw > 20` мДж/м².
