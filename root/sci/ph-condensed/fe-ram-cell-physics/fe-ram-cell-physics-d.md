Сучасна обчислювальна техніка потерпає від фундаментального розриву між швидкодією оперативної пам'яті та енергонезалежністю накопичувачів. Динамічна оперативна пам'ять (DRAM, від грецького `dynamikos` — рухливий) забезпечує наносекундний доступ до даних, але втрачає інформацію при вимкненні живлення та вимагає безперервного регенераційного перезаряджання кожні кілька десятків мілісекунд через струми витоку. Флеш-пам'ять зберігає стан без живлення, проте потребує мікросекундних таймінгів запису, високих напруг імпульсів та швидко деградує після `10⁴–10⁵` циклів перезапису. Енергонезалежна сегнетоелектрична оперативна пам'ять (FeRAM, від латинського `ferrum` — залізо та `electrum` — бурштин) докорінно змінює цю парадигму, поєднуючи наносекундне зчитування та запис при низьких напругах із багаторічним утриманням даних без зовнішнього джерела енергії.

Фізична основа класичного осередку FeRAM конфігурації 1T1C (один доступний транзистор, один накопичувальний конденсатор) схемотехнічно нагадує DRAM, проте принципово відрізняється природою збереження заряду. Замість накопичення вільних електронів на обкладках лінійного діелектрика з високою діелектричною проникністю, осередок FeRAM кодує логічні стани («0» та «1») напрямком вектора спонтанної за залишкової поляризації в об'ємі сегнетоелектричного кристала. Орієнтація дипольних моментів іонної ґратки зберігається невизначено довго без підведення зовнішньої енергії. Однак зчитування цієї поляризації вимагає її примусового перемикання електричним полем, що робить процес зчитування руйнівним і визначає унікальну фізику електродинамічних, матеріалознавчих та деградаційних процесів у сегнетоелектричному конденсаторі.

### 1. Електродинаміка та термодинаміка заряду переключення Q_sw

Фундаментальною характеристикою сегнетоелектричного конденсатора є нелінійна залежність електричного зміщення `D` від напруженості прикладеного зовнішнього електричного поля `E`. У системі SI вектор електричного зміщення описується сумою лінійного поляризаційного відгуку вакууму та спонтанної поляризації середовища `P(E)`:

```
D = ε₀·E + P(E)
```

де `ε₀` — електрична стала (`8.854 · 10⁻¹² Ф/м`), а `P(E)` — вектор поляризації середовища, який у сегнетоелектриках демонструє гістерезис (від грецького `hysteresis` — запізнення, відставання). На відміну від параелектрика, де поляризація зникає при знятті зовнішнього поля, сегнетоелектрик після прикладання та зняття сильного електричного поля зберігає ненульову залишкову поляризацію `Pᵣ` (від англійського `remnant polarization`).

![Петля гістерезису сегнетоелектрика та траєкторії зчитування станів](img/hysteresis-qsw-diagram.svg)
*Петля гістерезису P-E: відгук перемикання залишкової поляризації для станів «1» (-Pᵣ) та «0» (+Pᵣ) із виділенням корисного заряду Q_sw.*

#### А. Компоненти заряду: лінійний виток та перемикання диполів

При подачі на обкладки конденсатора площею `A_cap` та товщиною діелектрика `d` зчитувального імпульсу напруги `V_read`, що створює електричне поле `E_read = V_read / d`, яке перевищує коерцитивне поле кристала `E_c` (від латинського `coercitio` — утримування), підсумковий заряд `Q_total`, виділений у зовнішнє коло, складається з двох фізично різних внесків:

1. **Лінійний діелектричний заряд (`Q_nsw` або `Q_lin`):** викликаний швидким електронним та іонним зсувом без зміни орієнтації сегнетоелектричних доменів. Описується високочастотною лінійною діелектричною проникністю ґратки `ε_r`:
   ```
   Q_nsw = C_lin · V_read = (ε₀ · ε_r · A_cap / d) · V_read
   ```
2. **Перемикальний заряд (`Q_sw`):** пов'язаний із переорієнтацією (перевертанням) вектора спонтанної поляризації сегнетоелектричних доменів на `180°` під дією зовнішнього поля.

Значення виділеного заряду докорінно залежить від початкового логічного стану комірки:

- **Логічний стан «0» (полярність `+Pᵣ` напрямлена вздовж поля зчитування):** Зовнішнє додатне поле лише додатково стискає диполі в бік насичення `P_sat`. Перемикання векторів не відбувається. Зчитувальний імпульс генерує тільки лінійний заряд:
  ```
  Q_read(0) = Q_nsw = (P_sat - Pᵣ) · A_cap + C_lin · V_read
  ```
- **Логічний стан «1» (полярність `-Pᵣ` протилежна полю зчитування):** Зовнішнє поле долає коерцитивний бар'єр `E_c` і перекидає поляризацію від `-Pᵣ` до `+P_sat`. Сумарна зміна поляризації дорівнює `ΔP = P_sat - (-Pᵣ) = P_sat + Pᵣ`. Сумарний заряд дорівнює:
  ```
  Q_read(1) = Q_total = (P_sat + Pᵣ) · A_cap + C_lin · V_read
  ```

#### Б. Диференціальний заряд переключення та сигнал розрядної шини

Корисний фізичний сигнал, який використовується для розрізнення логічних станів, є різницею між зарядами зчитування станів «1» та «0». Ця величина називається **чистим зарядом переключення** (`Q_sw` або `ΔQ`):

```
Q_sw = Q_read(1) - Q_read(0) = 2 · Pᵣ · A_cap
```

Ця формула описує фундаментальне правило: корисний заряд FeRAM прямо пропорційний подвійній залишковій поляризації `2Pᵣ` та фізичній площі конденсатора `A_cap`. З точки зору термодинаміки, енергія, яка витрачається на одне перемикання доменного об'єму, визначається інтегралом роботи поля `W = ∫ E dD` по циклу гістерезису і становить `W_sw ≈ 2 · E_c · Pᵣ · A_cap · d`.

Під час операції зчитування конденсатор FeRAM підключається до довгої розрядної шини Bitline із власною паразитною ємністю `C_bitline`. Заряд перерозподіляється між ємністю осередку та шиною. Зсув потенціалу розрядної шини `ΔV_sense` для станів «1» та «0» визначається співвідношеннями:

```
V_BL(0) = Q_read(0) / (C_cell_lin + C_bitline)
V_BL(1) = [Q_read(0) + Q_sw] / (C_cell_lin + C_bitline)

ΔV_sense = V_BL(1) - V_BL(0) = (2 · Pᵣ · A_cap) / (C_cell_lin + C_bitline)
```

Для надійної роботи аналогового дифпідсилювача зчитування величина `ΔV_sense` повинна становити щонайменше `150–200 мВ`. Оскільки при зменшенні технологічного вузла площа конденсатора `A_cap` неухильно падає, матеріалознавство сегнетоелектриків змушене шукати матеріали з якомога вищим значенням залишкової поляризації `Pᵣ` та стабільною диференціальною відповіддю.

### 2. Фізика руйнівного зчитування (Destructive Readout) та цикл відновлення

На відміну від стандартної DRAM, де потенціал на конденсаторі вимірюється через плавний перетік вільних електронів, зчитування інформації в FeRAM є **фізично руйнівним** (*destructive readout*).

#### А. Покрокова фізика циклу зчитування

Розглянемо послідовність фізичних процесів при зчитуванні комірки 1T1C:

1. **Стан очікування (Standby):** Словесна шина WL перебуває під потенціалом `0 В`, транзистор закритий. Пластинна шина PL та розрядна шина BL заземлені (`0 В`). Сегнетоелектричний конденсатор утримує поляризацію `+Pᵣ` (стан «0») або `-Pᵣ` (стан «1»).
2. **Активація осередку:** На словесну шину WL подається напруга відкривання транзистора `V_DD + V_th` (щоб уникнути падіння напруги на каналі). Канал NMOS-транзистора відкривається, з'єднуючи обкладку конденсатора з розрядною шиною BL.
3. **Імпульс пластинної шини (PL Pulse):** На пластинну шину PL подається імпульс напруги живлення `V_DD`. Це створює на сегнетоелектричному діелектрику електричне поле `E = (V_PL - V_BL) / d`.
4. **Перерозподіл заряду та генерація струму:**
   - Якщо в комірці зберігався логічний нуль (`+Pᵣ`), поле напрямлене за солярністю поляризації. Струм перемикання відсутній, шина BL заряджається лише лінійним зарядом до низького напругового рівня `V_BL(0)`.
   - Якщо зберігалася логічна одиниця (`-Pᵣ`), поле протилежне поляризації. В об'ємі діелектрика виникає лавиноподібне перемикання сегнетоелектричних доменів. Процес супроводжується потужним імпульсом струму перемикання `I_sw(t) = A_cap · (dP/dt)`, який додатково інжектує заряд `Q_sw` у розрядну шину. Напруга на шині швидко зростає до високого рівня `V_BL(1)`.
5. **Стробування підсилювача зчитування (Sense Amp Latch):** Диференціальний підсилювач порівнює напругу `V_BL` із опорним рівнем `V_ref = [V_BL(0) + V_BL(1)] / 2`. Опорна напруга створюється спеціальними опорними комірками (*reference cells*) або ємнісними дільниками. Якщо `V_BL > V_ref`, підсилювач защіпає на шині BL повний рівень напруги живлення `V_DD` (логічна «1»); якщо `V_BL < V_ref` — скидає шину BL у `0 В` (логічний «0»).

#### Б. Механізм втрати стану «1» та автоматичний зворотний запис (Write-Back)

У результаті зчитування імпульс `V_DD` на пластинній шині PL перевів усі домени осередку в полярність `+Pᵣ`. Це означає, що якщо в комірці вихідно зберігався стан «1» (`-Pᵣ`), то в процесі зчитування він був **повною мірою знищений** і перезаписаний у стан «0» (`+Pᵣ`).

Щоб зберегти енергонезалежність, кожна операція зчитування FeRAM обов'язково супроводжується автоматичним циклом відновлення (*restore / write-back phase*):

- **Регенериційний запис стану «1»:** Поки словесна шина WL ще відкрита, пластинна шина PL примусово скидається в `0 В`, тоді як підсилювач зчитування утримує на розрядній шині BL потенціал `V_DD`. Це створює на конденсаторі інверсне електричне поле `E = -V_DD / d`. Оскільки `|-V_DD / d| > E_c`, вектор поляризації примусово повертається з положення `+Pᵣ` назад у стан `-Pᵣ`.
- **Збереження стану «0»:** Якщо зчитано нуль, підсилювач утримує на BL `0 В`. При скиданні PL у `0 В` різниця потенціалів дорівнює нулю, і стан `+Pᵣ` залишається незмінним.

Процес зчитування та відновлення детально проілюстровано на часовій діаграмі вище. Фізичний розрахунок динаміки проходження зчитувального імпульсу та виведення часових залежностей перемикання доменів наведено у вставці [Математична модель кінетики перемикання KAI](root:ph-condensed/fe-ram-cell-physics/math-kai-switching-kinetics.md).

### 3. Мікроскопічний механізм перемикання поляризації

Зміна напрямку поляризації в твердому тілі не відбувається одночасно по всьому об'єму кристала. Миттєве повернення мільйонів елементарних комірок вимагало б подолання колосального енергетичного бар'єру. Замість цього перемикання розгортається як термічно активований термодинамічний процес зародкоутворення (нуклеації) та подальшого розростання сегнетоелектричних доменів.

#### А. Зародкоутворення та рух доменних стінок: Моделі KAI та NLS

Мікроскопічна динаміка розгортається у три послідовні фази:

1. **Зародкоутворення (Nucleation):** Під дією зовнішнього поля `E > E_c` на межі розділу між металевим електродом та сегнетоелектриком (де локальне поле підсилене дефектами або крайовими неоднорідностями) виникають мікроскопічні зародки протилежної фази поляризації з клиноподібною формою.
2. **Поздовжнє проростання (Forward Growth):** Зародки з високою швидкістю (близькою до швидкості звуку в кристалі, `10³–10⁴ м/с`) проростають гострими голками крізь товщу плівки від одного електрода до іншого.
3. **Бічне розростання (Sideways Domain Wall Motion):** Після того як голки торкнулися протилежного електрода, починається відносно повільне бічне розширення доменних стінок у радіальному напрямку, що призводить до повного злиття нових доменів та охоплення всього об'єму конденсатора.

Для монокристалічних та великокристалічних плівок цей процес описується класичною моделлю Колмогорова — Аврамі — Ішібаші (KAI). Об'ємна частка переключеної фази `μ(t)` у часі `t` описується рівнянням:

```
μ(t) = 1 - exp[ - (t / τ₀)ⁿ ]
```

де `τ₀` — характерний час перемикання, а `n` — показник Аврамі (зазвичай `n = 2–3` для двовимірного бічного росту доменів).

Проте сучасні тонкі сегнетоелектричні плівки є високодисперсними полікристалами. У них розміри зерен становлять `5–20 нм`, а межі зерен створюють широкий спектр локальних енергетичних бар'єрів. Для таких систем застосовується модель нуклеації, обмеженої локальними зародками (**Nucleation-Limited Switching, NLS**). У NLS-моделі загальний час перемикання описується не єдиним значенням `τ₀`, а інтегральним розподілом часів нуклеації `g(log τ)` за лоренцівським або нормальним законом, що пояснює розтягнутий логарифмічний хвіст струму перемикання в тонких плівках.

```
μ(t) = ∫ [ 1 - exp( - t / τ ) ] · g(log τ) · d(log τ)
```

#### Б. Струм перемикання та швидкодія комірки

Перемикальний струм `I_sw(t)`, що протікає у зовнішньому колі під час зчитування або запису, прямо пропорційний швидкості зміни поляризації:

```
I_sw(t) = A_cap · (dP / dt) = 2 · Pᵣ · A_cap · (dμ / dt)
```

Форма імпульсу струму має характерний куполоподібний вигляд із піковим значенням `I_peak`, яке досягається в момент масового злиття доменних стінок. Швидкість рухомості доменних стінок `v_dw` описується експоненційним законом Мерца через поле активації `E_act`:

```
v_dw = v_inf · exp( - E_act / E )
τ_sw = τ_inf · exp( E_act / E )
```

При збільшенні робочої напруги час перемикання `τ_sw` падає до **1–5 наносекунд**, що робить FeRAM фундаментально здатною змагатися за швидкодією з DRAM. Ознайомитися з реалізацією чисельного алгоритму симуляції імпульсу струму `I_sw(t)` мовами C та C++ можна у вставці [Чисельна симуляція струму перемикання FeRAM](root:ph-condensed/fe-ram-cell-physics/proj-kai-switching-sim.md).

### 4. Фізика матеріалів: Класичний PZT проти орторомбічного HfO₂

Протягом кількох десятиліть головним матеріалом FeRAM слугували складні оксиди зі структурою перовськіту (від прізвища російського мінералога Олексія Перовського). Проте на початку XXI століття стався фундаментальний технологічний зсув у бік безелементних флюоритоподібних оксидів на основі гафнію.

![Кристалічні структури PZT та орторомбічної фази Pca2_1 HfO2](img/pzt-vs-hfo2-crystal.svg)
*Зсув катіонів у перовськіті PZT та зміщення аніонів оксигену вздовж полярної осі c в орторомбічній фазі Pca2_1 HfO₂.*

#### А. Перовськітові матеріали: PZT та SBT

Класичним сегнетоелектричним матеріалом FeRAM є титанат-цирконат свинцю `Pb[ZrₓTi₁₋ₓ]O₃` (PZT), а також танталат вісмуту-стронцію `SrBi₂Ta₂O₉` (SBT).

У кристалічній ґратці PZT зі структурою перовськіту `ABO₃` іони свинцю `Pb²⁺` займають вершини куба (позиція A), іони кислороду `O²⁻` — центри граней, а катіон `Ti⁴⁺` або `Zr⁴⁺` розміщений у центрі октаедра (позиція B). Нижче температури Кюрі (`T_c ≈ 350–450 °C`) відбувається центральносиметричний фазовий перехід: центральний катіон `Ti⁴⁺/Zr⁴⁺` зміщується відносно оксидного октаедра вздовж осі `[001]` або `[111]`. Це створює спонтанний електричний дипольний момент.

PZT володіє чудовими сегнетоелектричними параметрами:
- Висока залишкова поляризація: `Pᵣ = 20–45 мкКл/см²`;
- Низьке коерцитивне поле: `E_c = 50–100 кВ/см` (дозволяє керувати низькими напругами `1.8–3.3 В`).

Проте PZT володіє трьома критичними фізико-технологічними вадами, які зупинили його масштабування на рівні технологічного вузла **130 нм**:

1. **Руйнування поляризації при малій товщині (розмірний ефект):** При зменшенні товщини плівки PZT нижче `50–80 нм` на межах метал-діелектрик формується так званий «мертвий шар» (*dead layer*) з низькою діелектричною проникністю. Поляризація `P` створює на неідеально екранованих електродах деполяризаційне поле `E_depol = -P / (ε₀ · ε_depol)`, яке стає порівнянним із коерцитивним і повністю руйнує сегнетоелектричний стан.
2. **Низька ширина забороненої зони:** Заборонена зона PZT становить лише `E_g ≈ 3.4 еВ`, що призводить до високих струмів витоку Шотткі та Пуля — Френкеля при малій товщині.
3. **Несумісність із кремнієвою технологією:** Свинець `Pb` та вісмут `Bi` є важкими отруйними елементами, які легко дифундують у кремній і отруюють затвори транзисторів, унеможливлюючи нанесення PZT методами атомарно-шарового осадження (ALD) у 3D-структурах.

#### Б. Революція орторомбічної фази Pca2₁ в оксиді гафнію (HfO₂)

У 2011 році група дослідників під керівництвом Тімо Міколайока (Namlab, Дрезден) відкрила сегнетоелектрика у плівках оксиду гафнію `HfO₂`, легованого цирконієм, кремнієм або алюмінієм. Це відкриття зробило революцію у мікроелектроніці, оскільки `HfO₂` вже використовувався в транзисторах як High-k діелектрик затвора.

У вільному стані за нормальних умов чистий `HfO₂` є моноклінним (`P2₁/c`) і не має сегнетоелектричних властивостей (є параелектриком). Проте при зменшенні товщини плівки до `4–10 нм`, легуванні (наприклад, у твердому розчині `Hf₀.₅Zr₀.₅O₂`, HZO) та проведенні швидкого термічного відпалу (RTA) під механічним напруженням верхнього електрода TiN, у плівці стабілізується метастабільна **нецентричносиметрична орторомбічна фаза** (від грецького `orthos` — прямий та `rhombos` — ромб) з просторовою групою симетрії **Pca2₁** (група № 29).

У фазі `Pca2₁` поляризація виникає внаслідок зміщення аніонів оксигену `O²⁻` відносно важких катіонів гафнію `Hf⁴⁺` вздовж полярної осі `c`.

Переваги `HfO₂`-сегнетоелектриків:
- **Екстремальне масштабування товщини:** Стабільна сегнетоелектрична фаза `Pca2₁` зберігається при товщинах від **4 до 10 нм** без прояву шкідливого розмірного ефекту «мертвого шару».
- **Широка заборонена зона:** `E_g ≈ 5.3–5.7 еВ`, що знижує струми витоку на 4–5 порядків порівняно з PZT.
- **Сумісність із CMOS та ALD:** Можливість нанесення прецизійними конформними шарами методами ALD всередині глибоких 3D-канавок та тривимірних стеків BEOL (Back-End-Of-Line).
- **Високе коерцитивне поле:** `E_c ≈ 1–2 МВ/см` (у 10–20 разів вище за PZT). Завдяки малій товщині (`6 нм`) коерцитивна напруга становить `V_c = E_c · d ≈ 0.6–1.2 В`, що ідеально узгоджується із низковольтним живленням сучасних чипів (`1.2 В`).

Докладну хронологію розвитку технології, боротьбу наукових шкіл та перехід від PZT до HZO висвітлено у вставці [Історія розвитку сегнетоелектричної пам'яті](root:ph-condensed/fe-ram-cell-physics/hist-ferroelectric-ram.md).

### 5. Фізичні механізми деградації: Втома, Вкарбування та Утримання

Надійність осередку FeRAM визначається трьома фундаментальними деградаційними явищами в сегнетоелектричному конденсаторі: втомою, вкарбуванням (імпринтом) та втратою утримання даних.

![Фізико-структурні механізми деградації: втома та імпринт](img/degradation-mechanisms.svg)
*Мікроскопічні механізми деградації: (А) Накопичення вакансій оксигену V_O та пінінг доменних стінок при втомі; (Б) Зсув петлі V_shift внаслідок імпринту.*

#### А. Втома (Fatigue)

**Втома** — це явище зменшення значення залишкової поляризації `2Pᵣ` при багаторазовому циклуванні перемикання (запис/зчитання).

- **Мікроскопічна природа:** При подачі мільйонів біполярних імпульсів напруги високе електричне поле стимулює дрейф та накопичення вакансій оксигену `V_O²⁺` (позитивно заряджених точкових дефектів ґратки) поблизу металевих електродів TiN. У позначеннях Крьоґера — Вінка утворення дворазово іонізованої вакансії описується реакцією `O_O ⇄ V_O•• + 2e' + (1/2)O₂`.
- **Закріплення стінок (Domain Wall Pinning):** Скупчення дефектів та захоплених електронів створюють глибокі потенціальні ями, які «приклинюють» (закріплюють) доменні стінки. Зв'язані домени втрачають здатність перевертатися під дією зовнішнього поля.
- **Фазове розшарування в HfO₂:** У HZO-плівках тривале циклування також може викликати локальний фазовий перехід сегнетоелектричної орторомбічної фази `Pca2₁` у параелектричну моноклінну (`P2₁/c`) або моноклінно-тетрагональну фазу.

Використання струмопровідних оксидних електродів (`IrO₂`, `RuO₂`) замість чистих металів (Pt, TiN) дозволяє PZT-пам'яті витримувати понад `10¹⁵` циклів, оскільки оксидні електроди слугують резервуаром кислороду і поглинають вакансії. У плівках `HfO₂` додатково спостерігається ефект «пробудження» (*wake-up effect*): протягом перших `10³–10⁴` циклів залишкова поляризація `Pᵣ` спочатку **зростає** за рахунок перерозподілу вакансій оксигену та зняття початкових механічних напружень, і лише після `10⁷–10¹⁰` циклів починається класична втома.

#### Б. Вкарбування (Imprint)

**Вкарбування (імпринт)** — це фізична схильність сегнетоелектричного конденсатора «запам'ятовувати» один конкретний логічний стан («0» або «1»), якщо осередок тривалий час (дні, місяці) зберігається в цьому стані за підвищеної температури.

- **Фізичний механізм:** Тривале перебування поляризації в одному напрямку створює внутрішнє локальне електричне поле `E_imp`. Це поле формується за рахунок повільного термоактивованого дрейфу вакансій оксигену та орієнтації дефектних диполів (наприклад, комплексів `V_O²⁺ - V_metal'`), які шикуються паралельно до поляризації.
- **Наслідки для зчитування:** Внутрішнє поле `E_imp` зсуває петлю гістерезису вздовж осі напруги на величину `V_shift`. У результаті коерцитивна напруга для перемикання в один бік зростає (`V_c+ = V_c + V_shift`), а в протилежний — падає (`V_c- = V_c - V_shift`).

При значному `V_shift` напруга зчитування `V_read` стає недостатньою для подолання підвищеного коерцитивного порогу `V_c+`. При зчитуванні стан «1» не перемикається, викликаючи критичну помилку втрати даних (*imprint failure*).

#### В. Утримання заряду (Retention)

**Утримання (ретеншн)** характеризує здатність осередку зберігати помітну величину `2Pᵣ` протягом 10 років при експлуатаційних температурах (`85–125 °C`). Головним чинником релаксації поляризації є **деполяризаційне поле** `E_depol`, яке виникає через неповне екранування вільними носіями заряду електродів зв'язаного сегнетоелектричного заряду на гетеромежах. `E_depol` повільно розвертає найменш стабільні домени у зворотний бік, зменшуючи `Pᵣ(t)` за логарифмічним законом:

```
Pᵣ(t) = Pᵣ(0) - k · log(1 + t / t₀)
```

Систематизовані кількісні значення таймінгів, енергетичних бар'єрів, температурних коефіцієнтів та стандартів надійності FeRAM зведені у вставці [Довідник фізичних та інженерних параметрів FeRAM](root:ph-condensed/fe-ram-cell-physics/api-ferram-parameters-ref.md).

### 6. Схемотехнічне моделювання та перспективи розвитку (1T FeFET та FTJ)

Для інженерного проектування масивів пам'яті FeRAM використовують еквівалентні схемотехнічні моделі сегнетоелектричного конденсатора у середовищах SPICE.

#### А. Еквівалентна заступна схема осередку

Сегнетоелектричний конденсатор моделюється як паралельне з'єднання трьох елементів:

1. **Нелінійне джерело керованого заряду `Q_ferro(V, t)`:** описує перемикальну поляризацію за рівняннями KAI/NLS;
2. **Лінійна ємність `C_lin`:** відповідає високочастотній діелектричній проникності ґратки;
3. **Нелінійний резистор витоку `R_leak(V)`:** описує тунельні струми витоку підкладка-електрод (струми Пуля — Френкеля та термоелектронну емісію Шотткі).

Завдяки цьому інженери моделюють точний часовий відгук розрядної шини, шукають оптимальні значення напруги пластинної шини `V_PL` та розраховують завадостійкість підсилювача зчитування.

> 🔧 **Навіщо це.** Схемотехнічна модель FeRAM дозволяє розраховувати динамічні часові вікна зчитування (*read margin windows*) при проектуванні контролерів пам'яті, враховуючи розкид технологічних параметрів `Pᵣ` та `E_c` по площі кремнієвої пластини.

#### Б. Еволюція: від 1T1C FeRAM до 1T FeFET та тунельних переходів FTJ

Необхідність проведення руйнівного зчитування та наявність відносно великого накопичувального конденсатора 1T1C обмежують далі щільність упаковки FeRAM. Тому фізика твердого тіла активно розвиває два нових напрямки на основі сегнетоелектричного `HfO₂`:

1. **Сегнетоелектричний польовий транзистор (FeFET):** Сегнетоелектричний діелектрик `HfO₂` інтегрується безпосередньо в затворний стек польового транзистора. Напрямок поляризації зміщує порогову напругу транзистора `V_th`. Зчитування здійснюється вимірюванням струму стоку `I_DS` без прикладання високої напруги на затвор — це забезпечує **неруйнівне зчитування** (*non-destructive readout*) та зменшує осередок до розміру одного транзистора (структура 1T).
2. **Сегнетоелектричний тунельний перехід (FTJ, Ferroelectric Tunnel Junction):** Ультратонка плівка `HfO₂` (`2–4 нм`) затискається між двома різними металевими електродами. Перемикання поляризації змінює висоту потенціального бар'єра квантового тунелювання електронів, викликаючи ефект гігантського сегнетоелектричного опору (GER, *Giant Electroresistance*). Густина тунельного струму описується рівнянням `J_tunnel ∝ exp(- α · d · √Φ)`, де `Φ` — середня висота тунельного бар'єра, яка змінюється на `ΔΦ` при розвороті диполів. Стан зчитується вимірюванням слабкого тунельного струму при низькій напрузі.

Оригінальні фізико-математичні принципи 1T1C FeRAM, закладені в класичній електродинаміці перемикання заряду `Q_sw`, залишаються фундаментальним базисом для розуміння всіх новітніх концепцій сегнетоелектричної наноелектроніки.
