# 🧮 Математичний вивід частоти Ленгмюра та термодинамічної дисперсії хвиль Bohm-Gross

Математичний апарат опису плазмових коливань дає змогу суворо простежити, як із трьох фундаментальних законів — рівняння неперервності збереження заряду, другого закону Ньютона та рівняння Пуассона електродинаміки — випливає існування власних високочастотних коливань електронного газу.

---

### 1. Гідродинамічний вивід плазмової частоти (модель холодної плазми)

Розглянемо вихідну систему трьох рівнянь класичної гідродинаміки та електродинаміки для однорідного електронного газу з середньою концентрацією `n_0`, який заповнює нерухомий позитивний іонний фон такої ж густини (модель «желе»):

1. **Рівняння неперервності** (збереження кількості електронів):

```
∂n / ∂t + ∇ · (n · v) = 0
```

2. **Рівняння руху електронів** (без урахування зіткнень та теплового тиску):

```
m · (∂v / ∂t + (v · ∇)v) = -e · E
```

3. **Рівняння Пуассона** для напрямку електричного поля, викликаного розділенням зарядів:

```
∇ · E = ρ / ε_0 = -e · (n - n_0) / ε_0
```

де `e` — абсолютна величина заряду електрона (`1.602 × 10⁻¹⁹ Кл`), `m` — маса електрона, `ε_0` — електрична стала (`8.854 × 10⁻¹² Ф/м`), `n` — локальна концентрація електронів, `v` — вектор макроскопічної швидкості електронної рідини.

#### Метод малих збурень (лінеаризація)

Нехай у системі виникає мале відхилення концентрації електронів `n_1(r, t)` від рівноважного значення `n_0`, яке супроводжується появою малої швидкості `v_1(r, t)` та напруженості електричного поля `E_1(r, t)`:

```
n(r, t) = n_0 + n_1(r, t),      де |n_1| ≪ n_0
v(r, t) = 0 + v_1(r, t),        де |v_1| мале
E(r, t) = 0 + E_1(r, t),        де |E_1| мале
```

Підставимо ці вирази у вихідну систему рівнянь і знехтуємо квадратичними добутками малих величин (`n_1 · v_1 ≪ n_0 · v_1` та `(v_1 · ∇)v_1 ≪ ∂v_1 / ∂t`):

1. Лінеаризоване рівняння неперервності:

```
∂n_1 / ∂t + n_0 · (∇ · v_1) = 0
```

2. Лінеаризоване рівняння руху:

```
m · (∂v_1 / ∂t) = -e · E_1
```

3. Лінеаризоване рівняння Пуассона:

```
∇ · E_1 = -(e / ε_0) · n_1
```

#### Виведення рівняння осцилятора

Продиференціюємо лінеаризоване рівняння неперервності за часом `t`:

```
∂²n_1 / ∂t² + n_0 · ∇ · (∂v_1 / ∂t) = 0
```

Замінимо часову похідну швидкості `∂v_1 / ∂t` з рівняння руху:

```
∂v_1 / ∂t = -(e / m) · E_1
```

Отримуємо:

```
∂²n_1 / ∂t² - (n_0 · e / m) · (∇ · E_1) = 0     [підставили похідну швидкості]
```

Тепер підставимо дивергенцію електричного поля `∇ · E_1` з рівняння Пуассона:

```
∇ · E_1 = -(e / ε_0) · n_1
```

Отримуємо підсумкове диференціальне рівняння для збурення густини `n_1`:

```
∂²n_1 / ∂t² + (n_0 · e² / (ε_0 · m)) · n_1 = 0    [підставили рівняння Пуассона]
```

Це рівняння є класичним рівнянням **гармонічного осцилятора** вигляду `∂²n_1 / ∂t² + ω_p² · n_1 = 0`. Отже, будь-якое мале збурення електронної густини не поширюється як хвиля у холодній плазмі, а здійснює власні незатухаючі гармонічні коливання з фіксованою **плазмовою частотою Ленгмюра**:

```
ω_p = √ ( (n_0 · e²) / (ε_0 · m) )
```

У твердому тілі (металі чи напівпровіднику) фундаментальна формула модифікується двома чинниками:
- Заміною маси вільного електрона `m` на **ефективну масу** `m*` електрона в кристалічній ґратці.
- Врахуванням високочастотної диелектричної проникності остова іонів `ε_∞` (поляризація зв'язаних електронів внутрішніх оболонок):

```
ω_p = √ ( (n_0 · e²) / (ε_0 · ε_∞ · m*) )
```

### 2. Врахування газодинамічного тиску: хвилі Бома-Ґросса

У реальному газовому розряді або напівпровіднику електрони володіють тепловою енергією і здійснюють хаотичний рух із тепловою швидкістю. Зміщення електронів створює не лише електричне поле, а й градієнт електронного тиску `∇P`, який намагається розмити згущення зарядів.

Додамо член градієнта тиску `-∇P / (m · n)` у лінеаризоване рівняння руху електронів:

```
m · n_0 · (∂v_1 / ∂t) = -e · n_0 · E_1 - ∇P_1
```

Для високочастотних плазмових коливань стиснення та розрядження електронного газу відбуваються настільки швидко, що теплообмін між сусідніми елементами об'єму не встигає відбутися. Процес можна вважати **адіабатичним**.

Рівняння стану для ідеального електронного газу при одновимірному стисненні (ступінь вільності `γ = 3`):

```
P = C · n³
```

Диференціюючи це рівняння, виразимо малий градієнт тиску через градієнт густини:

```
∇P_1 = (dP / dn) · ∇n_1 = 3 · k_B · T_e · ∇n_1
```

де `k_B` — стала Больцмана, `T_e` — температура електронного газу.

Підставимо `∇P_1` у рівняння руху і застосуємо оператор дивергенції:

```
m · n_0 · ∇ · (∂v_1 / ∂t) = -e · n_0 · (∇ · E_1) - 3 · k_B · T_e · ∇²n_1
```

Застосовуючи рівняння неперервності та Пуассона, як у розділі 1, отримуємо хвильове диференціальне рівняння:

```
∂²n_1 / ∂t² + ω_p² · n_1 - (3 · k_B · T_e / m) · ∇²n_1 = 0
```

Шукатимемо розв'язок у формі плоскої гармонічної хвилі `n_1(r, t) = n_10 · exp(i · (k · r - ω · t))`. Застосування операторів похідних дає `∂² / ∂t² → -ω²` та `∇² → -k²`:

```
-ω² · n_1 + ω_p² · n_1 + (3 · k_B · T_e / m) · k² · n_1 = 0
```

Скорочуючи на `n_1`, отримуємо знамените **дисперсійне співвідношення Бома-Ґросса** (*Bohm-Gross dispersion relation*) для плазмових хвиль у теплій класичній плазмі:

```
ω² = ω_p² + 3 · v_th² · k²
```

де `v_th = √ (k_B · T_e / m)` — середня теплова швидкість електронів.

З виведеної формули випливають два фундаментальні наслідки:
1. **Просторова дисперсія:** У теплій плазмі плазмові коливання перестають бути локалізованими — вони поширюються у просторі у вигляді поздовжніх плазмових хвиль з груповою швидкістю `v_g = dω / dk = (3 · v_th² / ω) · k`.
2. **Низькочастотна відсічка:** При прямуванні хвильового вектора до нуля (`k → 0`) частота хвилі прямує до чистої плазмової частоти `ω → ω_p`. Хвилі з частотою `ω < ω_p` не можуть поширюватися в плазмі.

### 3. Дебаївське екранування та термодинамічний зв'язок з плазмовою частотою

Для статичного або низькочастотного випадку (`ω → 0`) макроскопічні коливання не встигають збуджуватися, проте тепловий рух електронів створює статичне екранування сторонніх зарядів.

Розглянемо сторонній позитивний точковий заряд `q`, вміщений у плазму. Потенціал поля `Φ(r)` задовольняє рівняння Пуассона з розподілом Больцмана для електронної густини:

```
n(r) = n_0 · exp( e · Φ(r) / (k_B · T_e) ) ≈ n_0 · ( 1 + e · Φ(r) / (k_B · T_e) )
```

Підстановка в рівняння Пуассона для сферично симетричного випадку дає:

```
∇²Φ = (e / ε_0) · (n - n_0) = (n_0 · e² / (ε_0 · k_B · T_e)) · Φ
```

Визначаючи **дебаївський радіус екранування** `λ_D`:

```
λ_D = √ ( (ε_0 · k_B · T_e) / (n_0 · e²) )
```

отримуємо розв'язок у вигляді екранованого потенціалу Юкави:

```
Φ(r) = ( q / (4 · π · ε_0 · r) ) · exp( -r / λ_D )
```

Порівнюючи формули для радіуса Дебая `λ_D` та плазмової частоти `ω_p`, бачимо фундаментальне співвідношення між ними через теплову швидкість електронів:

```
λ_D = v_th / ω_p
```

Це співвідношення показує, що радіус екранування Дебая є відстанню, яку електрон зі середньою тепловою швидкістю проходить за один період плазмових коливань `T = 1 / ω_p`. Для відстаней, більших за `λ_D`, кулонівське поле повністю екранується, а для частот, вищих за `ω_p`, плазмовий газ реагує як динамічний осцилятор.

### 4. Квантовий електронний газ у металі та дисперсія Томаса-Фермі

У металі за кімнатних температур електронний газ є сильно виродженим квантовим Фермі-газом. Енергія електронів визначається не класичною температурою `T`, а квантовою **енергією Фермі** `E_F` та відповідною **швидкістю Фермі** `v_F`:

```
v_F = (ℏ / m*) · (3 · π² · n_0)^(1/3)
```

Застосовуючи квантово-механічне наближення хаотичних фаз (RPA — *Random Phase Approximation*), розрахунок адіабатичної стискуваності квантового Фермі-газу замінює коефіцієнт `3 · v_th²` на `(3/5) · v_F²`. 

Дисперсійне співвідношення для об'ємних плазмонів у металі набуває вигляду:

```
ω²(k) = ω_p² + (3/5) · v_F² · k²
```

Розклавши квадратний корінь за малими `k`, отримаємо практичну лінеаризовану формулу дисперсії плазмона:

```
ω(k) ≈ ω_p · ( 1 + (3/10) · (v_F / ω_p)² · k² )
```

Квантовий радіус екранування Томаса-Фермі `r_TF` пов'язаний зі швидкістю Фермі виразом:

```
r_TF = v_F / (√3 · ω_p)
```

#### Межа ландауівського затухання та критичний хвильовий вектор

Дисперсійне співвідношення плазмонів існує не для всіх хвильових векторів `k`. У квантовому Фермі-газі існує так звана континуум-область одночастинкових збуджень (утворення пар «електрон-дірка»). Енергія, необхідна для переходу електрона зі стану під поверхнею Фермі `k_F` у стан над поверхнею Фермі `k_F + k`, становить:

```
E_single(k) = (ℏ² / (2 · m*)) · ( (k_F + k)² - k_F² ) = ℏ · v_F · k + (ℏ² · k²) / (2 · m*)
```

Коли крива дисперсії плазмона `ℏ · ω(k)` перетинає верхню межу області одночастинкових збуджень при критичному хвильовому векторі `k_c`:

```
k_c ≈ ω_p / v_F
```

колективний плазмон миттєво розпадається, передаючи свою енергію одному конкретному електрону провідності. Це явище є твердотільним аналогом **беззіткнувального затухання Ландау** (*Landau damping*). Для хвильових чисел `k > k_c` колективні плазмові коливання не існують як довгоживучі квазічастинки.

### 5. Топологічне виведення поверхневих плазмонів з граничних умов Максвелла

Розглянувши плоску межу розподілу між металевим напівпростором (`z < 0`, диелектрична проникність `ε_m(ω) < 0`) та діелектриком (`z > 0`, диелектрична проникність `ε_d > 0`), виведемо дисперсійне співвідношення для поверхневих хвиль з перших принципів electrodynamics.

Шукаємо розв'язок рівнянь Максвелла у формі поверхнево-зв'язаної електромагнітної хвилі поперечно-магнітного типу (TM-поляризація), що поширюється вздовж осі `x` і спадає за експонентою вздовж осі `z`:

У діелектрику (`z > 0`):

```
H_y1(x, z, t) = A_1 · exp(i · k_x · x - κ_1 · z - i · ω · t)
E_x1(x, z, t) = i · (κ_1 / (ω · ε_0 · ε_d)) · A_1 · exp(i · k_x · x - κ_1 · z - i · ω · t)
```

У металі (`z < 0`):

```
H_y2(x, z, t) = A_2 · exp(i · k_x · x + κ_2 · z - i · ω · t)
E_x2(x, z, t) = -i · (κ_2 / (ω · ε_0 · ε_m)) · A_2 · exp(i · k_x · x + κ_2 · z - i · ω · t)
```

де `κ_1 = √ (k_x² - (ω/c)² · ε_d)` та `κ_2 = √ (k_x² - (ω/c)² · ε_m)` — коефіцієнти згасання поля углиб відповідних середовищ.

Неперервність тангенціальних компонент поля `H_y` та `E_x` на межі `z = 0` вимагає:

1. `A_1 = A_2` (з неперервності `H_y`)
2. `κ_1 / ε_d = -κ_2 / ε_m` (з неперервності `E_x`)

Оскільки коефіцієнти згасання `κ_1 > 0` та `κ_2 > 0` за визначенням мусять бути додатними (щоб хвиля згасала по обидва боки від межі), рівність можлива лише тоді, коли діелектричні проникності двох середовищ мають **протилежні знаки**:

```
ε_m(ω) < 0      і      ε_d > 0
```

Це доводить, що поверхневі плазмонні хвилі можуть існувати виключно на межі між металом (де `Re(ε_m) < 0`) та діелектриком.

Підставляючи вирази для `κ_1` та `κ_2` і підносячи до квадрата:

```
(k_x² - (ω/c)² · ε_d) / ε_d² = (k_x² - (ω/c)² · ε_m) / ε_m²
```

Після алгебраїчних перетворень та зведення подібних членів отримуємо точне **дисперсійне співвідношення поверхневих плазмон-поляритонів (SPP)**:

```
k_spp² = (ω / c)² · ( (ε_m(ω) · ε_d) / (ε_m(ω) + ε_d) )
```

або у вигляді хвильового вектора:

```
k_spp = (ω / c) · √ ( (ε_m(ω) · ε_d) / (ε_m(ω) + ε_d) )
```

При малих частотах (`ε_m → -∞`) хвильовий вектор `k_spp → (ω/c) · √ε_d`, тобто крива SPP зливається зі світловою лінією в діелектрику. При наближенні частоти до поверхневої плазмової частоти `ω → ω_sp`, коли `ε_m(ω_sp) + ε_d = 0`, знаменник під коренем прямує до нуля, а хвильовий вектор `k_spp → ∞`. Це відповідає уповільненню хвилі, локалізації її напруженості на межі та перетворенню електромагнітної хвилі у чисті поверхневі плазмові коливання електронів.
