# 🔌 Будова та матеріалознавство pMTJ стека

Сучасний перпендикулярний магнітний тунельний перехід (pMTJ) побудований як складнокомпонентна гетероструктура із 15–20 нанометрових шарів різних матеріалів, вирощених методом магнетронного напилення з атомарною точністю. Кожен шар стека pMTJ виконує чітку фізико-хімічну функцію: високотемпературний відпал викликає твердофазну епітаксію та кристалізацію MgO, границя CoFeB/MgO формує інтерфейсну перпендикулярну магнітну анізотропію (iPMA), а синтетичний антиферомагнетик (SAF) взаємно компенсує магнітні моменти для пригнічення паразитичних дипольних розсіяних полів.

## 1. Пошарова геометрія та функціональний склад pMTJ гетероструктури

Типовий промисловий стек pMTJ для вбудованої пам'яті eMRAM технологічного вузла 22/14 нм вирощується на металізованому шар-підкладці мікросхеми. Повна пошарова будова зверху вдолу має вигляд:

```
 ┌────────────────────────────────────────────────────────────────────────┐
 │ Top Contact / Hard Mask (W, Ta, Ru)                       [50–100 нм]  │
 ├────────────────────────────────────────────────────────────────────────┤
 │ Heavy Metal Cap (W, Ta)                                   [2–5 нм]     │
 ├────────────────────────────────────────────────────────────────────────┤
 │ Upper Free Layer: CoFeB                                   [0.8–1.0 нм] │
 ├────────────────────────────────────────────────────────────────────────┤
 │ Non-magnetic Metallic Spacer (W / Mo / Ta)                [0.3–0.4 нм] │
 ├────────────────────────────────────────────────────────────────────────┤
 │ Lower Free Layer: CoFeB                                   [0.8–1.0 нм] │
 ├────────────────────────────────────────────────────────────────────────┤
 │ Crystalline Tunnel Barrier (MgO)                          [0.8–1.1 нм] │
 ├────────────────────────────────────────────────────────────────────────┤
 │ Reference Layer (CoFeB)                                   [1.0–1.3 нм] │
 ├────────────────────────────────────────────────────────────────────────┤
 │ Coupling / Transition Layer (Ta, Mo, W)                   [0.3–0.5 нм] │
 ├────────────────────────────────────────────────────────────────────────┤
 │ Synthetic Antiferromagnet (SAF):                                       │
 │   - Upper Ferromagnet AP2 (Co/Pt або Co/Pd multilayers)   [2–4 нм]     │
 │   - Non-magnetic RKKY Spacer (Ru)                         [0.85 нм]    │
 │   - Lower Ferromagnet AP1 (Co/Pt multilayers)             [3–6 нм]     │
 ├────────────────────────────────────────────────────────────────────────┤
 │ Bottom Seed Layer (Ta, Ru, Pt)                            [5–20 нм]    │
 └────────────────────────────────────────────────────────────────────────┘
```

## 2. Пошаровий аналіз фізичних функцій матеріалів

### 1. Захисні та поглинаючі шари (Cap & Seed Layers)
* **Нижній буферний шар (Seed Layer: Ta / Ru):** Забезпечує гладку атомарну текстуру `(111)` для подальшого росту багатошарових плівок Co/Pt та запобігає дифузії атомів міді з нижніх міжз'єднань чипа.
* **Верхній шар-пастка (Cap Layer: W / Ta):** Виконує роль хімічного поглинача (гетируючого матеріалу) для атомів бору при термообробці та формує надійний омічний контакт з верхньою шиною.

### 2. Складений вільний шар (Composite Free Layer: CoFeB / W / CoFeB)
Вільний шар є основним елементом збереження інформаційного стану («0» чи «1»).
* **Формула сплаву `Co₄₀Fe₄₀B₂₀`:** Початковий склад вибирається аморфним. Аморфна фаза під час напилення магнетроном гарантує атомарно гладку поверхню без міжзернових меж дефектів, що є критичним для осадження надтонкого бар'єра MgO.
* **Роль прокладки вольфраму W (~0.3 нм):** У тонкому шарі CoFeB при товщині понад 1.5 нм об'ємний член розмагнічування перемагає інтерфейсну анізотропію, і шар повертається у плоский стан (in-plane). Застосування сендвіча `CoFeB (0.9 нм) / W (0.3 нм) / CoFeB (0.9 нм)` створює дві гетеромежі CoFeB/MgO (нижню та верхню при використанні подвійного бар'єра), збільшуючи загальну площу інтерфейсу та подвоюючи інтерфейсну анізотропію. При цьому тонка плівка W зберігає феромагнітний обмінний зв'язок між двома шарами CoFeB, змушуючи їх переключатися як єдиний монолітний магнітний момент.

### 3. Кристалічний тунельний бар'єр (MgO)
Тонкий шар оксиду магнію товщиною 0.8–1.1 нанометра (що відповідає 4–6 атомарним моношарам).
* **Епітаксіальне узгодження решіток:** MgO кристалізується у структурі NaCl з параметром решітки `a_MgO = 0.421` нм. Рекристалізований сплав CoFe утворює об'ємно-центровану кубічну решітку (ОЦК) з `a_CoFe = 0.286` нм. При повороті комірки CoFe на 45° відносно MgO гранерада `a_CoFe · √2 ≈ 0.404` нм узгоджується з решіткою MgO з невеликим неузгодженням всього 4%, що забезпечує низьку щільність дислокацій.
* **Характеристичний опір `RA`:** Добуток опору на площу (*Resistance-Area product*, `RA`) вибирається у діапазоні `2 – 10` Ом·мкм². Точне значення `RA` контролюється час-тиском оксидування магнію: нижче 2 Ом·мкм² виникають pinhole-дефекти (короткі замикання), а вище 15 Ом·мкм² струм запису створює напругу, близьку до електричного пробою.

### 4. Синтетичний антиферомагнетик (SAF)
Для усунення паразитичного дипольного поля розсіяння, яке б створював суцільний фіксований шар на вільний шар, застосовується система **Synthetic Antiferromagnet (SAF)**:

```
               Взаємне згашення полів у структурі SAF:

    Вільний шар M_free (вільно обертається)             ▲ (або ▼)
  ─────────────────────────────────────────────────────────
    Тунельний бар'єр MgO (1 нм)
  ─────────────────────────────────────────────────────────
    Фіксований шар Reference CoFeB                     ▲  ───► Створює H_stray1 (+25 мТл)
  ─────────────────────────────────────────────────────────
    Прокладка Ru (0.85 нм) - РККІ зв'язок              [Антипаралельне зчеплення]
  ─────────────────────────────────────────────────────────
    Нижній шар SAF AP1 (Co/Pt multilayers)             ▼  ───► Створює H_stray2 (-25 мТл)
  ─────────────────────────────────────────────────────────
    Результат на вільному шарі:                        H_net = H_stray1 + H_stray2 ≈ 0 мТл
```

* **Осциляції Рудермана — Киттеля — Касуї — Йосіди (РККІ):** Міжплівкова обмінна взаємодія між металевими феромагнетиками крізь немагнітну прокладку рутенію Ru осцилює за знаком і амплітудою залежно від товщини Ru. При товщині `t_Ru = 0.85` нм обмінна енергія досягає негативного максимуму (`J_RKKY ≈ -1.5` мДж/м²), створюючи жорстке антипаралельне зчеплення між шарами `AP1` та `AP2`.
* **Багатошарові структури `[Co/Pt]_n`:** Шари AP1 та AP2 будуються з послідовно начергованих надтонких плівок кобальту (0.3 нм) та платини (0.6 нм). Інтерфейси Co/Pt забезпечують потужну перпендикулярну анізотропію, завдяки чому фіксована система не змінює свого напрямку навіть під дією сильних зовнішніх полів до 1 Тл.

## 3. Кінетика термообробки та кристалізація при 400 °C

Критичним етапом виготовлення pMTJ є високотемпературний відпал при температурі `350 – 400 °C` у магнітному полі 1–2 Тл протягом 1 години. Під час цієї термообробки відбуваються три ключові фізико-хімічні процеси:

1. **Дифузія та поглинання бору (Boron Out-Diffusion):**
   Атоми бору мають малий атомарний радіус і підвищену рухливість. При 400 °C бор мігрує з аморфного сплаву `Co₄₀Fe₄₀B₂₀` у сусідній шар-пастку з вольфраму W або танталу Ta.
2. **Solid-Phase Epitaxy (Твердофазна епітаксія):**
   Утративши бор, збіднений сплав `CoFe` рекристалізується, використовуючи кристалічну решітку MgO(001) як шаблону матрицю. Утворюється ідеальна орієнтація `CoFe(001) || MgO(001)`, що є необхідною умовою для когерентного тунелювання `Δ₁` станів.
3. **Формування інтерфейсу iPMA:**
   На межі `CoFe / MgO` атоми заліза займають місця строго над атомами кисню, формуючи хімічні зв'язки `Fe-O`, які створюють перпендикулярну магнітну анізотропію.

## 4. Фізичний механізм інтерфейсної анізотропії (iPMA)

У перпендикулярних pMTJ перетворення осі анізотропії з площинної на перпендикулярну відбувається завдяки квантово-хімічному ефекту на гетеромежі **CoFeB / MgO**.

```
                   Орбітальна гібридизація на межі Fe / MgO:

         Кисень (O)      (O²⁻)         (O²⁻)         (O²⁻)   [MgO barrier]
                           │             │             │
                    Гібридизація 3d(Fe) - 2p(O) орбіталей
                           │             │             │
         Залізо (Fe)     (Fe²⁺)        (Fe²⁺)        (Fe²⁺)  [CoFeB layer]
```

1. **Гібридизація орбіталей:** На інтерфейсі атоми заліза `Fe` утворюють хімічні зв'язки з атомами кисню `O`. Відбувається масштабна гібридизація між незаповненими `3d_z²` орбіталями Fe та `2p_z` орбіталями O.
2. **Спін-орбітальна взаємодія:** Порушення просторової симетрії на межі розділу та сильній спін-орбітальний зв'язок створюють інтерфейсну енергію анізотропії `K_s ≈ 1.3 – 2.0` мДж/м².
3. **Ефективна анізотропія `K_eff`:**

```
K_eff = K_v - 2π·M_s² + (K_s1 + K_s2) / t_fl
```

де `K_v` — об'ємна анізотропія, `-2π·M_s²` — розмагнічуючий член форми, `K_s1, K_s2` — інтерфейсні внески нижньої (`CoFeB/MgO`) та верхньої (`CoFeB/W`) меж.

Для того щоб `K_eff > 0` (намагніченість встала перпендикулярно), товщина вільного шару `t_fl` має бути меншою за критичну товщину `t_crit ≈ 1.5` нм. Якщо потовстити шар CoFeB до 2.0 нм, об'ємний розмагнічуючий член переважить, і шар повернеться у плоский стан.
