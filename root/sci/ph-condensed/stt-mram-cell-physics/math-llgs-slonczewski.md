# 🧮 Рівняння Ландау — Ліфшиця — Гільберта — Слонашевського (LLGS) та математика критичного струму

Динаміка векторного поля намагніченості у безпосередній присутності спіново-поляризованого струму описується диференціальним рівнянням Ландау — Ліфшиця — Гільберта розширеним додатком Слонашевського (LLGS). Ця математична вставка розгортає строге виведення критичної густини струму `J_c0`, демонструє скасування демагнетизуючого поля у геометрії pMTJ та формулює температурну кінетику Арреніуса — Неєля для оцінки часу збереження даних.

## 1. Векторна форма рівняння LLGS та векторні математичні перетворення

Розглянемо тонкий феромагнітний шар товщиною `t_fl` із вектором намагніченості `M`, модуль якого дорівнює намагніченості насичення `M_s`. Визначимо безрозмірний одиничний вектор намагніченості `m = M / M_s`, так що `|m| = 1`.

У відсутності струму еволюція `m` визначається ефективним магнітним полем `H_eff` (яке включає зовнішнє поле, магнітно-кристалічну анізотропію, обмінне поле та поле демагнетизації). Ефективне поле розраховується як варіаційна похідна від густини вільній енергії Вольфарта `F`:

```
H_eff = -(1 / μ_0) · (∂F / ∂M)
```

При проходженні спіново-поляризованого струму з густиною `J` рівняння LLGS у неявному вигляді записується як:

```
dm/dt = -γ_0 · (m × H_eff) + α · (m × dm/dt) + τ_STT
```

де:
* `γ_0 = μ_0 · |γ_e|` — гіромагнітне відношення для вільного електрона (`γ_0 ≈ 2.211 × 10⁵` м/(А·с)),
* `α` — безрозмірний коефіцієнт загасання Гільберта (для сплавів CoFeB `α ≈ 0.005 – 0.015`),
* `τ_STT` — векторний момент переносу спінового моменту.

Слонашевський показав, що при взаємодії спінового потоку з орієнтацією `m_p` (орієнтація фіксованого шару) момент `τ_STT` розкладається на дві ортогональні компоненти:

```
τ_STT = γ_0 · a_J · m × (m × m_p) + γ_0 · b_J · (m × m_p)
```

1. **Адіабатичний (In-plane) спіновий момент `a_J`:** Домінуюча компонента, спрямована у площині, утвореній векторами `m` та `m_p`. Вона безпосередньо протидіє загатуванню Гільберта.
2. **Неадіабатичний (Field-like) спіновий момент `b_J`:** Діє аналогічно до додаткового магнітного поля вздовж `m_p`. У тонких переходах CoFeB/MgO `b_J` становить 5–15% від `a_J`.

Амплітуда адіабатичного моменту `a_J` виводиться з закону збереження спінового кутового моменту:

```
a_J = (ℏ · J · P) / (2 · e · M_s · t_fl)
```

де `ℏ` — зведена стала Планка, `e` — елементарний заряд, `P` — ефективна спінова поляризація струму.

### Виведення явного вигляду рівняння LLGS для чисельного розв'язку

Щоб виразити похідну `dm/dt` у явному вигляді, виконаємо векторне множення обох частин неявного рівняння на `m ×`:

```
m × (dm/dt) 
= -γ_0 · m × (m × H_eff) + α · m × (m × dm/dt) + m × τ_STT      [Векторне множення на m]
```

Використовуючи векторну тотожність `m × (m × A) = (m · A)·m - (m · m)·A = -A` (оскільки `m · dm/dt = 0` через фіксовану довжину `|m| = 1` та `m · m = 1`):

```
m × (dm/dt) = -γ_0 · m × (m × H_eff) - α · (dm/dt) + m × τ_STT
```

Підставивши цей вираз назад у вихідне рівняння LLGS для заміни члена `α · (m × dm/dt)`:

```
dm/dt 
= -γ_0 · (m × H_eff) + α · [ -γ_0 · m × (m × H_eff) - α · (dm/dt) + m × τ_STT ] + τ_STT

(1 + α²) · (dm/dt) 
= -γ_0 · (m × H_eff) - α · γ_0 · m × (m × H_eff) + τ_STT + α · (m × τ_STT)

dm/dt 
= -(γ_0 / (1 + α²)) · [ m × H_eff + α · m × (m × H_eff) - (1/γ_0) · τ_STT - (α/γ_0) · (m × τ_STT) ]   [Явне рівняння LLGS]
```

Отримана формула є фундаментальною: вона показує, що коефіцієнт `1 / (1 + α²)` зменшує швидкість прецесії, а момент Слонашевського додається безпосередньо до динамічних векторів прецесії та загасання.

## 2. Математичне виведення критичного струму J_c0 при T = 0 K

Для переключення намагніченості спіново-поляризований момент `τ_STT` повинен компенсувати дисипативний момент Гільберта при відхиленні вектора `m` від легкої осі. Розглянемо виведення критичної густини струму `J_c0` для двох геометрій.

### А. Перпендикулярна магнітна анізотропія (pMTJ)

У pMTJ легка вісь анізотропії спрямована уздовж осі Z (перпендикулярно до плівки). Ефективне поле анізотропії `H_k_eff` включає перпендикулярну анізотропію `H_k` та віднімає поле демагнетизації `4π·M_s`:

```
H_k_eff = H_k - 4π·M_s
```

Розглянемо малі відхилення вектора намагніченості від осі Z: `m = (sin θ cos φ, sin θ sin φ, cos θ)`. Енергія анізотропії на одиницю об'єму виражається як `F(θ) = K_eff · sin² θ`.

Рівняння балансу потужності дисипації на вершині енергетичного бар'єра (`θ = 90°`):

```
a_J = α · H_k_eff
```

Підставляючи вираз для `a_J`, отримуємо строгу формулу критичної густини струму `J_c0` при абсолютному нулю температур:

```
(ℏ · J_c0 · P) / (2 · e · M_s · t_fl) = α · H_k_eff

J_c0 = (2 · e · α · M_s · t_fl · H_k_eff) / (ℏ · P)    [Критична густина струму pMTJ]
```

Виразимо висоту потенціального енергетичного бар'єра `E_b = (1/2) · μ_0 · M_s · H_k_eff · V`, де `V = A · t_fl` — об'єм вільного шару, `A` — площа переходу. Підставивши `M_s · H_k_eff = 2 · E_b / (μ_0 · V)`:

```
J_c0 = (2 · e / ℏ) · (α / P) · (2 · E_b / A)          [Залежність J_c0 від бар'єра E_b у pMTJ]
```

Звідси видно ключову фізичну перевагу pMTJ: **критичний струм прямо пропорційний енергетичному бар'єру `E_b` та не містить жодних додаткових демагнетизуючих членів!**

### Б. Поздовжня магнітна анізотропія (iMTJ)

У випадку in-plane анізотропії вектор `m` лежить у площині X-Y. При прецесії під дією STT вектор `m` змушений виходити з площини плівки, протидіючи гігантському полю демагнетизації `4π·M_s`. 

Ефективна енергія враховує два різні поля анізотропії: поле у площині `H_k` та перпендикулярне розмагнічуюче поле `4π·M_s`. Математичний розрахунок власного значення лінеаризованого рівняння LLGS дає:

```
J_c0_iMTJ = (2 · e · α · M_s · t_fl / (ℏ · P)) · (H_k + 4π·M_s / 2)   [Критичний струм iMTJ]
```

Порівняємо два вирази для `J_c0`:

```
J_c0_iMTJ / J_c0_pMTJ 
= (H_k + 4π·M_s / 2) / H_k_eff       [ділення виразів J_c0 для iMTJ та pMTJ]
= (H_k + 2π·M_s) / (H_k - 4π·M_s)    [підстановка H_k_eff = H_k - 4π·M_s]
```

Оскільки для тонких плівок `4π·M_s ≈ 1.0 – 1.8` Тл, а `H_k ≈ 0.05` Тл, член `2π·M_s` перевищує `H_k` у 20–40 разів! Це змушувало проганяти крізь iMTJ величезні струми лише для того, щоб подолати розмагнічування форми, що призводило до швидкої деградації тунельного діелектрика.

## 3. Стохастичне рівняння Ланжевена — ЛЛГС та температурна кінетика

При скінченній температурі `T > 0 K` термічні флуктуації атомарних спінів генерують флуктуюче магнітне поле `H_th(t)`, яке додається до `H_eff`:

```
H_eff_total = H_eff + H_th(t)
```

Поле `H_th(t)` є білим гауссовим шумом із нульовим середнім значенням та кореляційною функцією, що задовольняє флуктуаційно-дисипаційну теорему (FDТ):

```
< H_th_i(t) · H_th_j(t') > = (2 · α · k_B · T / (γ_0 · M_s · V)) · δ_ij · δ(t - t')
```

де `δ_ij` — символ Кронекера, `δ(t - t')` — дельта-функція Дірака, `V` — об'єм шару.

### Залежність критичного струму від тривалості імпульсу J_c(t_pulse)

Аналіз стохастичного рівняння Ланжевена дає два математичні режими залежності необхідної густини струму від тривалості прямокутного імпульсу `t_pulse`:

```
                                    Залежність J_c від тривалості імпульсу t_pulse:

  J_c ▲
      │
      │  Прецесійний режим (t_pulse < 1 нс)
      │  J_c ∝ J_c0 + C / t_pulse
      │   \
      │    \
      │     \      Термічно-активований режим (t_pulse > 10 нс)
      │      └──────────────────────────────────────────────── J_c0
      │        J_c = J_c0 · [ 1 - (1/Δ) · ln(t_pulse / τ_0) ]
      │
      └─────────────────────────────────────────────────────────────► t_pulse
        0.1 нс            1 нс             10 нс           100 нс
```

#### 1. Термічно-активований режим (`t_pulse > 10` нс)
У цьому режимі тривалість імпульсу значно перевищує період природної прецесії (10–100 пс). Переключення описується статистикою Арреніуса — Неєля:

```
J_c(t_pulse) = J_c0 · [1 - (1 / Δ) · ln(t_pulse / τ_0)]
```

де:
* `Δ = E_b / (k_B · T)` — безрозмірний фактор термічної стабільності,
* `k_B` — стала Больцмана (`1.3806 × 10⁻²³` Дж/К),
* `τ_0 ≈ 1` нс — характерна спроба термічної релаксації (attempt time).

Для забезпечення 10-річного збереження даних у промислових чипах без втрати бітів вимагається `Δ ≥ 60`. При `Δ = 60` та імпульсі запису `t_pulse = 10` нс необхідний струм становить `J_c ≈ 0.63 · J_c0`.

#### 2. Динамічний прецесійний режим (`t_pulse < 1` нс)
При ультракоротких імпульсах термічна активація не встигає спрацювати. Струм повинен передати необхідний спіновий кутовий момент за декілька обертів прецесії:

```
J_c(t_pulse) = J_c0 + (q_sw / t_pulse)
```

де `q_sw` — густина заряду, необхідна для динамічного повертання намагніченості. При `t_pulse → 0.2` нс густина струму зростає у 3–5 разів порівняно з `J_c0`, підвищуючи ризик електричного пробою діелектрика MgO.

## 4. Розрахунок імовірності помилки переключення (Write Error Rate — WER)

Для напівпровідникової пам'яті критичною характеристикою є імовірність того, що імпульс запису заданої амплітуди `J` та тривалості `t_p` не зможе переключити комірку. Ця характеристика називається **Write Error Rate (WER)**.

Розв'язок рівняння Фоккера — Планка для щільності ймовірності кута намагніченості `P(θ, t)` дає вираз для WER у термічно-активованому режимі:

```
WER(J, t_p) = exp[ - (t_p / τ_0) · exp( - Δ · (1 - J / J_c0) ) ]
```

Прологарифмувавши формулу двічі:

```
ln( -ln(WER) ) = ln(t_p / τ_0) - Δ · (1 - J / J_c0)
```

Графік `ln(-ln(WER))` від напруги або струму являє собою пряму лінію (так звану лінію Ланжевена — Фоккера — Планка). Щоб досягти промислової вимоги `WER ≤ 10⁻⁹` (одна помилка на мільярд операцій), робочий струм запису повинен перевищувати критичний струм `J_c0` приблизно на 30–40%:

```
J_operating ≥ J_c0 · [ 1 + (1 / Δ) · ln( (t_p / τ_0) / ln(1 / WER) ) ]
```

Цей розрахунок визначає точне нижнє значення струму для проектування селекторних транзисторів у масивах пам'яті.
