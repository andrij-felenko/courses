# 🧮 Термодинаміка, тепловий баланс та кінетика кристалізації

Ця вставка містить детальний математико-фізичний вивід теплового балансу на межі розплав-кристал, розрахунок граничної швидкості витягування монокристала, а також математичний аналіз кінетики сегрегації домішок за моделлю Бартона-Прима-Сліхтера (BPS) та капілярної рівноваги меніска.

## Рівняння теплового балансу на фронті кристалізації

Процес витягування монокристала з розплаву за методом Чохральського регулюється збереженням енергії на рухомій міжфазній межі (фронті кристалізації). Вважаємо, що фронт є планарним або слабкоопуклим і рухається вгору вздовж осі `z` зі швидкістю витягування `v_p`.

У сталому режимі росту вільна прихована теплота кристалізації `L_m`, яка виділяється при переході рідкої фази кремнію у тверду, має повністю відводитися через твердий кристал за рахунок теплопровідності та радіаційного випромінювання у навколишній простір вакуумної камери. 

Рівняння зберігання енергії у вигляді балансу теплових потоків на міжфазній поверхні кристалізації `z = z_f` виражається як:

```
Q_S = Q_L + Q_latent
```

де значення складових потоків на одиницю площі фронту дорівнюють:
- `Q_S = k_S · (dT/dz)_S` — потік тепла, що відводиться теплопровідністю вгору через ростучий твердий кристал (`k_S` — коефіцієнт теплопровідності твердого кремнію при температурі плавлення `T_m = 1687 K`, що становить близько 22 Вт/(м·К); `(dT/dz)_S` — аксіальний градієнт температури у твердій фазі);
- `Q_L = k_L · (dT/dz)_L` — потік тепла, що надходить до фронту з перегрітого розплаву (`k_L` — коефіціент теплопровідності рідкого кремнію, близько 67 Вт/(м·К); `(dT/dz)_L` — температурний градієнт у рідкій фазі безпосередньо біля фронту);
- `Q_latent = L_m · ρ_S · v_p` — швидкість виділення прихованої теплоти плавлення на одиницю площі фронту (`L_m = 1.8 × 10⁶ Дж/кг` — питома прихована теплота плавлення кремнію, `ρ_S = 2330 кг/м³` — густина твердого кремнію).

Підставляючи вирази для теплових потоків за законом Фур'є, отримуємо основне диференціальне рівняння кінетики витягування:

```
k_S · (dT/dz)_S = k_L · (dT/dz)_L + L_m · ρ_S · v_p
```

Звідси лінійна швидкість витягування кристала `v_p` безпосередньо виражається через різницю температурних градієнтів по обидва боки від міжфазної межі:

```
v_p = [ k_S · (dT/dz)_S - k_L · (dT/dz)_L ] / (L_m · ρ_S)
```

Фізичний зміст цього рівняння полягає у тому, що швидкість кристалізації прямо пропорційна здатності твердого зливка відводити теплову енергію вгору і обернено пропорційна нагріву рідкої фази.

## Гранична (максимальна) швидкість витягування кристала

Щоб кристал рос із постійним радіусом `R_c`, температура розплаву безпосередньо біля межі повинна бути близькою до температури кристалізації `T_m`. Якщо зменшити нагрів розплаву до мінімуму, при якому градієнт температури в рідині прямує до нуля `(dT/dz)_L → 0`, вся теплота, що відводиться кристалом, витрачається виключно на поглинання прихованої теплоти кристалізації.

У цьому граничному випадку отримуємо абсолютну максимальну швидкість витягування `v_max`:

```
v_max = (k_S · (dT/dz)_S) / (L_m · ρ_S)
```

Для оцінки величини градієнта `(dT/dz)_S` розглядаємо тепловідведення від циліндричного зливка радіусом `R_c` за рахунок теплопровідності вздовж осі `z` та радіаційного випромінювання з його бічної поверхні у вакуум за законом Стефана-Больцмана. 

Рівняння теплового балансу для елементарного диска зливка товщиною `dz`:

```
k_S · π · R_c² · (d²T/dz²) = 2 · π · R_c · ε · σ · (T⁴ - T_env⁴)
```

де:
- `ε` — випромінювальна здатність поверхні твердого кремнію (близько 0.6);
- `σ = 5.67 × 10⁻⁸ Вт/(м²·К⁴)` — стала Стефана-Больцмана;
- `T_env` — температура водоохолоджуваних стінок камери печі (близько 300 K).

Враховуючи, що у високотемпературній зоні `T⁴ >> T_env⁴`, перша інтегральна форма цього диференціального рівняння від поверхні фронту `T = T_m` дає квадрат температурного градієнта на основі твердої фази:

```
(dT/dz)_S = √[ (4 · ε · σ · T_m⁵) / (5 · k_S · R_c) ]
```

Підставляючи отриманий вираз для градієнта у формулу граничної швидкості `v_max`, маємо залежність максимальної швидкості витягування від радіуса кристала `R_c`:

```
v_max = (1 / (L_m · ρ_S)) · √[ (4 · ε · σ · k_S · T_m⁵) / (5 · R_c) ]
```

Звідси випливає важливе фізичне співвідношення: **максимальна швидкість росту обернено пропорційна квадратному кореню з радіуса кристала**:

```
v_max ∝ 1 / √(R_c)
```

Чисельні розрахунки висвітлюють масштаб цього ефекту:
- Для тонкої шийки Деша (`R_c = 1.5–2.0 мм`) градієнт `(dT/dz)_S` перевищує 150–200 K/см, а гранична швидкість становить понад `12–15 мм/хв`.
- Для масивного зливка діаметром 300 мм (`R_c = 150 мм`) градієнт `(dT/dz)_S` падає до `10–20 K/см`, що обмежує максимальну швидкість стаціонарного росту величиною близько `1.2–1.5 мм/хв`. Спроба перевищити цю швидкість викликає підплавлення і відрив зливка від розплаву.

## Модель Бартона-Прима-Сліхтера (BPS) для ефективного коефіцієнта сегрегації

При витягуванні кристала зі швидкістю `v_p` на межі поділу фаз утворюється пристінний гідродинамічний дифузійний шар товщиною `δ`. Оскільки рівноважний коефіцієнт сегрегації домішки `k_0 = C_S / C_L(0) < 1`, ростучий кристал відштовхує домішку у розплав. У дифузійному шарі `0 ≤ z ≤ δ` виникає градієнт концентрації домішки.

Стаціонарне диференціальне рівняння переносу домішки у дифузійному шарі враховує конвективний потік домішки до фронту за рахунок витягування та зустрічний дифузійний потік:

```
D · (d²C/dz²) + v_p · (dC/dz) = 0
```

де `D` — коефіцієнт дифузії домішкових атомів у рідкому кремнії (порядок `10⁻⁴ см²/с`).

Граничні умови для цього рівняння:
1. При `z = 0` (на безпосередній межі кристалізації):
   ```
   D · (dC/dz)|_{z=0} + v_p · (C_L(0) - C_S) = 0
   ```
2. При `z = δ` (на зовнішній межі дифузійного шару):
   ```
   C(δ) = C_L
   ```
   де `C_L` — концентрація домішки у суцільному об'ємі інтенсивно перемішуваного розплаву.

Інтегрування рівняння дифузії з цими граничними умовами дає вираз для **ефективного коефіцієнта сегрегації** `k_eff = C_S / C_L`:

```
k_eff = k_0 / [ k_0 + (1 - k_0) · exp(-v_p · δ / D) ]
```

Аналіз формули BPS показує два граничні режими:

1. **Повільне витягування (`v_p → 0`) або інтенсивне обертання (`δ → 0`)**:
   ```
   exp(-v_p · δ / D) → 1  ⇒  k_eff → k_0
   ```
   Дифузійний шар не перешкоджає відведенню домішки, і розділення домішок відбувається з максимальною термодинамічною ефективністю `k_0`.

2. **Швидке витягування (`v_p · δ / D >> 1`)**:
   ```
   exp(-v_p · δ / D) → 0  ⇒  k_eff → 1
   ```
   Домішка повністю накопичується у тонкому пристінному шарі і механічно захоплюється кристалом. Ефект сегрегації зникає, кристал виростає з такою ж концентрацією домішки, як і в розплаві.

Товщина дифузійного шару `δ` за теорією Кохрана визначається кутовою швидкістю обертання кристала `ω_c` та кінематичною в'язкістю розплаву `ν`:

```
δ = 1.6 · D^(1/3) · ν^(1/6) · ω_c^(-1/2)
```

Збільшення швидкості обертання кристала `ω_c` зменшує товщину шару `δ ∝ 1 / √(ω_c)`, що наближає `k_eff` до рівноважного значення `k_0` і покращує радіальну однорідність розподілу домішок.

## Капілярна рівновага та формоутворення меніска

Форма ростучого зливка та стабільність його діаметра визначаються капілярною рівновагою рідкого меніска у точці трифазного контакту (кристал, розплав, газова атмосфера).

Висота рідкого меніска `h_m` визначається рівнянням Юнга-Лапласа для капілярного підйому рідини:

```
h_m = √[ (2 · γ_LV · (1 - cos θ_0)) / (ρ_L · g) ]
```

де:
- `γ_LV` — коефіцієнт поверхневого натягу рідкого кремнію (близько 0.73 Дж/м²);
- `ρ_L = 2570 кг/м³` — густина рідкого кремнію (рідкий кремній щільніший за твердий, `ρ_L > ρ_S`);
- `g = 9.81 м/с²` — прискорення вільного падіння;
- `θ_0` — кут контакту розплаву з ростучим кристалом (для кремнію характерний кут ріст конуса `φ₀ ≈ 11°`).

Для забезпечення строго циліндричної форми зливка (`d R_c / dz = 0`) кут нахилу меніска у точці трифазного контакту `φ` повинен дорівнювати характерному кутові рівноваги `φ₀`. Якщо кут `φ > φ₀`, кристал розширюється; якщо `φ < φ₀`, діаметр зливка зменшується. Оптичні пирометричні камери системи авторегулювання безперервно вимірюють кут меніска та висоту `h_m`, корегуючи потужність нагрівача та швидкість витягування `v_p`.
