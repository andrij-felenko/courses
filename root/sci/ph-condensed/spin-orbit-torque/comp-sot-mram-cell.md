# 🔌 Будова та топологія тритермінальної SOT-MRAM комірки

Цей компонентний опис присвячено фізичній топології, матеріалознавчому стеку шарів, маршруту нанофабрикації, інженерії інтерфейсів, схемотехнічній організації периферійних ліній та режимам експлуатації тритермінальної комірки пам'яті SOT-MRAM (3-Terminal SOT-MRAM Cell).

---

### 1. Матеріалознавчий стек шарів гетероструктури SOT-MTJ

Комірка SOT-MRAM складається з двох ключових функціональних суб-структур: горизонтального провідного каналу важкого металу (SOT-трек) та вертикального магнітного тоннельного переходу (MTJ), вирощеного безпосередньо поверх треку.

Послідовність осадження матеріалів у вертикальному стеку (знизу вгору) має наступну структуру:

```
[ Верхній електрод (Top Contact: Ta / Ru) ]
[ Фіксуючий антиферомагнетик (Hard Pinning: PtMn або IrMn, ~10-15 нм) ]
[ Синтетичний антиферомагнетик SAF (CoFe / Ru / CoFeB, ~3 нм) ]
[ Тунельний бар'єр (MgO, товщина 0.8 - 1.1 нм) ]
[ Вільний магнітний шар (Free Layer: CoFeB, товщина 0.9 - 1.4 нм) ]  <-- Інжекція спінів!
[ Шар важкого металу (SOT Channel: β-W, Ta або Pt, товщина 3 - 6 нм) ]
[ Буферний / адгезійний шар (Substrate / Seed Layer: Ta / SiO₂) ]
```

#### Роль кожного шару в стеку:

1. **Буферний шар (Seed Layer):** Забезпечує високу гладкість поверхні (шорсткість `RMS < 0.1 нм`) та формує необхідну текстуру кристалографічної орієнтації (наприклад, кубічну текстуру `(111)` для платини або тетрагональну β-фазу для вольфраму). Гладкість підкладки є критичною: навіть атомні сходинки заввишки 0.3 нм викликають локальне розсіювання спінового струму та створюють паразитну помаранчеву анізотропію (Orange-peel coupling).
2. **Канал важкого металу (SOT Channel):** Нижній горизонтальний провідник, у якому генерується спиновий струм. Товщина шару `d_HM` вибирається близькою до довжини спинової релаксації `λ_sd` (`d_HM ≈ 3.5–5 нм`). Якщо `d_HM < λ_sd`, частина зарядового струму розсіюється на межі підкладки; якщо `d_HM >> λ_sd`, надлишковий товстий метал просто шунтує струм, марно витрачаючи енергію.
3. **Вільний шар (Free Layer):** Магнітний шар із аморфного сплаву кобальт-залізо-бор (`Co₄₀Fe₄₀B₂₀`). Він має високий коефіцієнт спінової поляризації та перпендикулярну магнітну анізотропію (PMA), обумовлену гібридизацією d-орбіталей заліза та p-орбіталей кисню на межі з оксидом магнію (`CoFeB/MgO`).
4. **Туннельний діелектричний бар'єр (MgO):** Епітаксійний шар оксиду магнію `MgO(001)`. Завдяки квантовомеханічному фільтруванню симетрії хвильових функцій електронів (`Δ₁`-симетрія), `MgO` забезпечує високий коефіцієнт тунельного магнітоопору (`TMR = (R_AP - R_P) / R_P ≈ 150–250%`).
5. **Синтетичний антиферомагнетик (Synthetic Antiferromagnet, SAF):** Складний тришаровий зафіксований стек `CoFe / Ru / CoFeB`. Двома шарами феромагнетика затиснуто надтонкий шар рутенію `Ru` (товщиною 0.8 нм), який створює потужне антипаралельне міжшарове обмінне зв'язування Рудермана — Киттеля — Касуї — Йосіди (RKKY). Стек SAF повністю взаємно компенсує власні магнітні поля розсіювання, гарантуючи, що зафіксований шар не створює паразитного магнітного поля на вільному шарі.

### 2. Інженерія гетеромежі HM/FM: Вставні шари (Dusting Layers)

Для досягнення максимальної ефективності SOT-перемикання при збереженні високого коефіцієнта тунельного магнітоопору (TMR) у промислових стеках застосовують інженерію інтерфейсів. Безпосередній контакт між деякими важкими металами (наприклад, танталом `Ta` або вольфрамом `W`) та вільним шаром `CoFeB` може призводити до часткового поглинання атомів бору з `CoFeB` під час термообробки (відпалу при 350–400 °C), що погіршує кристалізацію `MgO` та знижує TMR.

Щоб вирішити цю проблему, на межу розподілу HM/FM вводять надтонкі вставні шари (Dusting Layers) товщиною від 0.2 до 0.5 нм:

- **Інтерфейсні вставки `Hafnium (Hf)` або `Zirconium (Zr)`:** Вставка 0.2 нм гафнію між шаром `β-W` та `CoFeB` діє як поглинач бору (Boron sink), але не перешкоджає спиновому транспорту. Вона підвищує константу перпендикулярної анізотропії `K_u_eff` на 30% та збільшує TMR з 120% до 190%.
- **Вставки `Ta / Pt` з градієнтом складу:** Утворення підкладки з градієнтним переходом концентрації атомів дозволяє одночасно оптимізувати кут спинового Холла `θ_SH` та мінімізувати опір інтерфейсного розсіювання.

### 3. Схемотехніка комірки: Схема 2T-1MTJ та розведення ліній

Оскільки для керування тритермінальною коміркою необхідно окремо комутувати струм запису через нижній канал та струм зчитування через вертикальний стек, елементарна комірка SOT-MRAM містить **два ключові МОН-транзистори та один MTJ (архітектура 2T-1MTJ)**.

```
                  Read Bit Line (RBL)
                           │
                           │
                        [ MTJ ]
                           │
        ┌──────────────────┴──────────────────┐
        │       SOT Heavy Metal Channel       │
        └───────┬─────────────────────┬───────┘
                │                     │
            (T1/Node A)           (T2/Node B)
                │                     │
          ┌─────┴─────┐         ┌─────┴─────┐
          │  Trans 1  │         │  Trans 2  │
          └─────┬─────┘         └─────┬─────┘
                │                     │
                │                     │
        Write Bit Line        Write Source Line
            (WBL)                   (WSL)
```

#### Керування провідними лініями:

1. **Word Line Write (WL_W):** Загальний затвор, що відкриває транзистори `Trans 1` та `Trans 2` під час операцій запису.
2. **Word Line Read (WL_R):** Керує окремим транзистором зчитування (якщо використовується схемотехніка 2T1MTJ із розділеними затворами).
3. **Write Bit Line (WBL) та Write Source Line (WSL):** Лінії живлення каналу запису.
   - Для запису **"0"** (перемикання у `+z`): На `WBL` подається високий потенціал `V_DD`, на `WSL` — земля `GND`. Струм протікає зліва направо (`+x`), генеруючи спінову поляризацію `σ` вздовж `+y`.
   - Для запису **"1"** (перемикання у `-z`): На `WSL` подається `V_DD`, на `WBL` — `GND`. Струм протікає справа наліво (`-x`), змінюючи знак поляризації `σ` на `-y`.
4. **Read Bit Line (RBL):** Лінія зчитування, підключена до верхнього термінала MTJ (T3). Під час зчитування транзистор `Trans 1` відкривається, на `RBL` подається мала напруга `V_read ≈ 0.1 В`, а вимірювальний підсилювач (Sense Amplifier) порівнює струм із опорним значенням.

Хоча площа комірки SOT-MRAM (`14–20 F²`, де `F` — мінімальний технологічний розмір норми) перевищує площу двотермінальної STT-MRAM (`6–10 F²`), вона залишається у 3–5 разів меншою за площу статичної комірки 6T-SRAM (`60–90 F²`), надаючи величезну перевагу при виготовленні щільних кеш-масивів.

### 4. Маршрут нанофабрикації та інтеграції у Back-End-of-Line (BEOL)

Виготовлення масивів SOT-MRAM здійснюється у рамках стандартого напівпровідникового процесу BEOL (Back-End-of-Line), після формування кремнієвих транзисторів фронтальної зони (FEOL). Модуль SOT-MRAM вбудовується між металевими рівнями M4 та M5.

Основоположні етапи маршруту нанофабрикації включають:

1. **Магнетронне напилення (PVD Sputtering):** У надвисокому вакуумі (`P < 10⁻⁸ мбар`) послідовно напилюється весь суцільний тонкоплівковий стек від нижнього важкого металу `Ta/W` до верхнього покривного шару `Ru`.
2. **Літографія та ечінгування SOT-треку (Step 1):** За допомогою фотолітографії екстремального ультрафіолету (EUV) або електронно-променевої літографії формується маска смужок важкого металу. За допомогою іонно-променевого травлення (Ion Beam Etching, IBE) аргоновими іонами витравлюються горизонтальні канали важкого металу.
3. **Селективне травлення стовпчиків MTJ (Step 2):** Формується друга маска у вигляді круглих наноострівців діаметром `D = 20–40 нм`. Травлення IBE зупиняється за допомогою оптичної емісійної спектроскопії (OES) строго на верхній межі шару важкого металу. Зупинка травлення з точністю до одного атомного шару є критичною: підтравлення SOT-треку збільшить його опір, а недотравлення створить електричне коротке замикання.
4. **Пасивація та інкапсуляція:** Наностовпчики MTJ покриваються конформним захисним діелектриком з нітриду кремнію (`Si₃N₄`) або оксиду алюмінію (`Al₂O₃`) за допомогою атомно-шарового осадження (ALD) для захисту від окиснення повітрям.
5. **Хіміко-механічна поліровка (CMP) та верхні контакти:** Простір заповнюється оксидом `SiO₂`, після чого здійснюється планарізація CMP до оголення верхніх контактів `Ru` з наступним формуванням металевих розводка RBL.

### 5. Термодинамічна стабільність та фактори надійності

Головною умовою надійного збереження інформації в комірці пам'яті протягом 10 років при температурі 125 °C є високий **коефіцієнт термодинамічної стабільності `Δ`**:

```
Δ = E_b / (k_B · T) = (K_u_eff · V) / (k_B · T) ≥ 60      [фактор термостабільності]
```

де `E_b` — висота енергетичного бар'єра анізотропії між станами `+z` та `-z`, `K_u_eff` — ефективна константа перпендикулярної анізотропії, `V = (π / 4) · D² · d` — об'єм вільного шару (де `D` — діаметр наноострівця, `d` — його товщина), `k_B` — стала Больцмана, `T` — абсолютна температура.

Ймовірність самовільного теплового перекидання спіна за час `t` описується законом Нееля — Брауна:

```
P_error(t) = 1 - exp( - (t / τ_0) · exp(-Δ) )      [ймовірність самовільної втрати даних]
```

де `τ_0 ≈ 10⁻⁹ с` — спроба прецесійного частотного відгуку. При `Δ = 60` ймовірність виникнення самовільної помилки протягом 10 років не перевищує `10⁻¹⁵`.

### 6. Схемотехніка зчитування та диференціальні підсилювачі (Sense Amplifiers)

Оскільки зміна опору MTJ при тунельному магніторезистивному ефекті становить `ΔR / R_P ≈ 150%`, різниця опорів між станом "0" (`R_P ≈ 5 кОм`) та станом "1" (`R_AP ≈ 12.5 кОм`) становить кілька кілоом.

Для швидкісного зчитування за затримки < 1 нс використовується диференціальна токова схемотехніка:

```
                     ┌───────────────────┐
                     │ Sense Amplifier   │
                     └─┬───────────────┬─┘
                       │               │
                       ▼               ▼
                 [ SOT-MTJ ]     [ Ref-MTJ ]
                 (R_cell)        (R_ref = (R_P + R_AP)/2)
```

Вимірювальний підсилювач прикладає однакову напругу `V_read = 0.1 В` до вимірювальної комірки `R_cell` та до еталонної комірки `R_ref`. Еталонна комірка виготовляється із двох паралельних MTJ, зафіксованих у станах `R_P` та `R_AP`, утворюючи середній опір `R_ref = (R_P + R_AP) / 2`. Диференціальний струм `ΔI = I_cell - I_ref` перетворюється тригером Шмітта у цифровий логічний рівень 0 або 1.

Мінімізація паразитної ємності провідних ліній `RBL` досягається шляхом локального заземлення неактивних колонок масиву, що знижує RC-затримку зчитування до 300 пікосекунд.

### 7. Фізичні механізми деградації та відмов SOT-MRAM

На відміну від STT-MRAM, де основним фактором відмови є пробій тонкого діелектрика `MgO`, у SOT-MRAM бар'єр `MgO` захищений від перенапруг. Проте у 3-термінальних комірках виникають власні специфічні фізичні механізми старіння:

1. **Електроміграція у важкому металі:** Високі густини струму `J_c ≈ 10⁷–10⁸ А/см²`, які імпульсно протікають крізь канал важкого металу (`Pt` або `W`), створюють високий електронний вітер. Передача імпульсу від електронів до атомів металу може спричиняти поступове переміщення іонів важкого металу, утворюючи мікропорожнини (voids) або горби (hillocks) у каналі. Це змінює локальний опір SOT-треку.
2. **Джоулеве самонагрівання (Joule Heating):** Оскільки опір металевого треку становить кілька сотень Ом, проходження наносекундного струму амплітудою 100–300 мкА викликає локальний сплеск температури у вільному шарі на 50–150 °C. Це тимчасово знижує ефективне поле анізотропії `H_k_eff`, що, з одного боку, полегшує перемикання, але з іншого — вимагає суворого контролю теплового відводу.
3. **Міждифузія атомів на інтерфейсі HM/FM:** Тривала експлуатація при підвищених температурах може спричинити часткове взаємне проникнення атомів платини або танталу в шар `CoFeB`. Це призводить до "магнітного отруєння" (magnetic dead layer formation) та падіння константи PMA.

Для запобігання цим явищам у промислових процесах товщину шару важкого металу та геометрію контакту підганяють так, щоб робоча напруга запису не перевищувала 0.4–0.6 В, що забезпечує практично необмежену ресурсоємність (> `10¹⁵` циклів запису).
