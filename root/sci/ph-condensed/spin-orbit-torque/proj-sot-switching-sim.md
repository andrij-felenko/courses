### 1. Фізико-математична модель та чисельний метод інтегрування

Чисельне моделювання магнітної динаміки наноелементів із перпендикулярною анізотропією (PMA) під дією спин-орбітального обертального моменту (SOT) спирається на розв'язання системи нелінійних звичайних диференціальних рівнянь Ландау — Ліфшиця — Гільберта (LLGS). У наближенні макроспіна вважається, що усі електронні спіни всередині феромагнітного шару об'ємом `V = A · d` орієнтовані когерентно та описуються єдиним нормованим вектором намагніченості `m(t) = (m_x(t), m_y(t), m_z(t))` зі строгим обмеженням на збереження довжини `|m(t)| = 1`.

У момент часу `t = 0` вектор намагніченості перебуває поблизу вертикальної осі легкого намагнічення `m = (0, 0, +1)`. До системи прикладається прямокутний електричний імпульс тривалістю `τ_pulse` із густиною струму `J_c` у важкому металі, а також постійне допоміжне магнітне поле `B_x` вздовж осі `x` для зняття енергетичної дегенерації.

Динамічне рівняння руху вектора `m` у явній формі записується у вигляді:

```
d m / d t = (1 / (1 + α²)) · [ -γ · (m × H_eff) - γ · α · m × (m × H_eff) + τ_DL_eff · m × (m × σ) + τ_FL_eff · (m × σ) ]
```

де effective SOT коефіцієнти визначаються виразами:
- `τ_DL_eff = γ · H_DL - α · γ · H_FL`
- `τ_FL_eff = γ · H_FL + α · γ · H_DL`
- `H_DL = (ħ · θ_SH · J_c) / (2 · e · M_s · d)` — амплітуда Damping-like поля (А/м),
- `H_FL = (ħ · θ_FL · J_c) / (2 · e · M_s · d)` — амплітуда Field-like поля (А/м),
- `σ = (0, 1, 0)` — орт поляризації спінового потоку, інжектованого із важкого металу.

#### Схема інтегрування Рунге — Кутти 4-го порядку (RK4) та нормалізація

Для інтегрування нелінійної системи диференціальних рівнянь використовується класичний метод Рунге — Кутти 4-го порядку (RK4). Простіші однокрокові методи (наприклад, явний метод Ейлера) є непридатними для задач спінової динаміки через низьку чисельну стійкість: при розрахунку прецесії з частотами порядку `10–50 ГГц` явний метод Ейлера штучно збільшує радіус прецесійної траєкторії, викликаючи фальшиву самозбуджувану нестійкість.

Математична межа стійкості часового кроку `dt` для алгоритму RK4 визначається максимальною прецесійною частотою Гільберта:

```
dt < 2.0 / ( γ · H_eff_max · (1 + α) )      [критерій Куранта-Фрідріхса-Леві]
```

При ефективних полях анізотропії `H_k_eff ≈ 4.0 · 10⁵ А/м` максимум поля досягає `0.5 Тл`, що дає межу стійкості `dt_max ≈ 2.5 пс`. Вибір кроку інтегрування `dt = 0.1 пс` (10⁻¹³ с) гарантує запаси стійкості понад 25 разів.

Метод RK4 на кожному часовому кроці `dt` обчислює чотири проміжні оцінки похідної `k₁, k₂, k₃, k₄`:

```
k₁ = f( t_n, m_n )
k₂ = f( t_n + dt/2, m_n + (dt/2) · k₁ )
k₃ = f( t_n + dt/2, m_n + (dt/2) · k₂ )
k₄ = f( t_n + dt, m_n + dt · k₃ )

m_(n+1)_raw = m_n + (dt / 6) · ( k₁ + 2·k₂ + 2·k₃ + k₄ )
```

Після обчислення сирого значення `m_(n+1)_raw` виконується обов'язкова операція строгої геометричної нормалізації:

```
m_(n+1) = m_(n+1)_raw / | m_(n+1)_raw |      [нормалізація вектора намагніченості]
```

Ця операція є фізично виправданою, оскільки вона компенсує накопичення чисельної похибки округлення та гарантує збереження закону збереження модуля намагніченості `|m| = 1` на довільних часових інтервалах.

### 2. Врахування флуктуацій Ланжевена та монте-карлівські розрахунки (WER)

У реальних умовах при кімнатній температурі (`T = 300 K`) намагніченість відчуває постійні хаотичні флуктуації під дією теплових коливань кристалічної ґратки. Для моделювання ненульової температури у вираз для ефективного поля `H_eff` додають стохастичне магнітне поле Ланжевена `H_th(t)`:

```
H_eff_total = H_eff + H_th(t)      [ефективне поле з урахуванням теплового шуму]
```

Стохастичне поле `H_th(t)` моделюється як тривимірний білий гаусівський шум із середнім значенням `⟨H_th,i(t)⟩ = 0` та кореляційною функцією, що підпорядковується флуктуаційно-дисипативній теоремі (FD-теорема Кубо):

```
⟨ H_th,i(t) · H_th,j(t') ⟩ = D · δ_ij · δ(t - t')
D = (2 · α · k_B · T) / (γ · M_s · V)      [інтенсивність флуктуацій Ланжевена]
```

де `k_B` — стала Больцмана, `T` — температура в Кельвінах, `V` — об'єм магнітного елемента, `δ_ij` — символ Кронекера, `δ(t - t')` — дельта-функція Дірака.

У чисельних алгоритмах дискретні компоненти стохастичного поля на кожному кроці `dt` обчислюються через генератор нормального розподілу `N(0, 1)`:

```
H_th,i = √( (2 · α · k_B · T) / (γ · M_s · V · dt) ) · G_i      [дискретне поле Ланжевена]
```

де `G_i` — випадкова величина з нульовим середнім та одиничною дисперсією. Проведення Монте-Карло симуляцій (запуск 10,000–100,000 незалежних траєкторій з різними реалізаціями генератора випадкових чисел) дозволяє обчислити статистичний розподіл затримок перемикання та точний коефіцієнт помилок запису (Write Error Rate, WER).

### 4. Фізичний аналіз етапів траєкторії перемикання

Програмування чисельної симуляції дозволяє наочно простежити траєкторію вектора намагніченості у тривимірному просторі `(m_x, m_y, m_z)` та виділити три послідовні фази динамічного відгуку:

1. **Фаза початкового індукованого відхилення (0 – 0.25 нс):** У перші пікосекунди після подачі струмового імпульсу `J_c = 1.2 · 10¹¹ А/м²` Damping-like обертальний момент `τ_DL` створює виштовхувальну силу, яка змушує намагніченість відхилятися від вертикальної осі `z`. Вертикальна компонента спадає від `m_z = +1.0` до `m_z = +0.7`.
2. **Фаза швидкого екваторіального розвороту (0.25 – 0.55 нс):** Під спільною дією Damping-like моменту та зовнішнього поля `B_x = 0.05 Тл`, вектор намагніченості перетинає екваторіальну площину (`m_z = 0`). Наявність поля `B_x` забезпечує поздовжній зсув `m_x > 0`, що гарантує однозначний напрямок перетирання екватора і запобігає симетричному розгалуженню.
3. **Фаза релаксації та стабілізації (0.55 – 1.0 нс):** Намагніченість входить у нижню півсферу (`m_z < 0`) і швидко прямує до другого стійкого стану `m_z = -1.0`. Навіть після припинення дії струму при `t = 1.0 нс`, внутрішнє ефективне поле анізотропії `H_k_eff` утримує намагніченість у стані логічної "1".

Аналіз чутливості показує, що при збільшенні кута спинового Холла `θ_SH` від 0.10 (платина) до 0.35 (вольфрам) час перемикання скорочується у 3.2 раза при ідентичному струмі запису, а критична енергія перемикання знижується майже на порядок.

### 5. Практичні поради щодо оптимізації симуляцій

При використанні чисельних моделей для проектування схем пам'яті слід враховувати наступні крайові випадки та обчислювальні нюанси:

- **Вибір початкового кута відхилення `m_z(0)`:** Чисто вертикальний стан `m = (0, 0, 1)` є точкою нестійкої рівноваги у векторному рівнянні LLGS (оскільки `m × (m × y_hat) = 0` при `m = z_hat`). Тому у розрахунках необхідно задавати початковий кут флуктуації `θ_0 ≈ 1°–3°` (наприклад, `m_x = 0.05, m_z = 0.9987`), що моделює природні теплові коливання при `T > 0 K`.
- **Контроль чисельної дисипації:** Якщо в алгоритмі відсутня процедура нормалізації `m = m / |m|`, амплітуда вектора намагніченості під дією схем інтегрування вищого порядку може штучно зростати або зменшуватися, порушуючи умову `|m| = 1`.
- **Аналіз крайових доменних процесів:** Описана макроспінова модель є точною для елементів діаметром `D < 20–30 нм`. Для пристроїв більшого розміру слід використовувати мікромагнітні пакети моделювання (наприклад, Mumax3 або OOMMF), які розбивають об'єм елемента на сітку комірок розміром `2 × 2 × 1 нм³` для урахування зародження доменних стінок.
