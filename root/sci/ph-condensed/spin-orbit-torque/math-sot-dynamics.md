# 🧮 Квантовий та феноменологічний розрахунок динаміки SOT

Ця математична вставка містить аналітичне виведення систем диференціальних рівнянь Ландау — Ліфшиця — Гільберта з урахуванням моментів SOT, квантовомеханічний розрахунок коефіцієнтів проходження спінового струму крізь гетеромежу, аналіз енергетичного профілю Стонера — Вольфарта, розрахунок ширин ліній ST-FMR, а також виведення критичної густини струму для детермінованого перемикання намагніченості.

---

### 1. Квантовомеханічна теорія спінового транспорту та провідність змішування

Для точного математичного описання передачі спінового кутового моменту від важкого металу до феромагнетика недостатньо класичного поняття провідності. Спіновий потік, що генерується в об'ємі важкого металу (HM) завдяки спиновому ефекту Холла (SHE), зазнає часткового відбиття на межі розподілу (Spin Backflow).

Повна квантовомеханічна провідність гетеромежі описується за допомогою комплексного параметра **комплексної спінової провідності змішування** (Spin Mixing Conductance, `G_mix`):

```
G_mix = G_r + i · G_i      [спінова провідність змішування]
```

Дійсна частина `G_r` характеризує поглинання поперечної компоненти спінового струму на межі розподілу (що створює Damping-like обертальний момент), а уявна частина `G_i` описує прецесію накопичених спінів навколо інтерфейсного обмінного поля (що створює Field-like обертальний момент). Для металевих гетероструктур `Pt/Co` або `W/CoFeB` величина `G_r` становить `10¹⁴–10¹⁵ м⁻²`, тоді як уявна частина є малою (`G_i << G_r`).

З урахуванням ефекту зворотного зливу спінів (Spin Backflow), ефективний кут спинового Холла `θ_SH_eff`, який реально передається феромагнетику, зменшується порівняно з істинним об'ємним значенням `θ_SH_0`:

```
θ_SH_eff = θ_SH_0 · [ 2 · g_↑↓ · tanh(d_HM / (2 · λ_sd)) ] / [ 1 + 2 · g_↑↓ · coth(d_HM / λ_sd) ]
```

де `g_↑↓ = (e² / h) · (G_r / σ_HM)` — безрозмірна інтерфейсна провідність змішування, `σ_HM` — питома електрична провідність важкого металу, `d_HM` — товщина шару важкого металу, `λ_sd` — довжина релаксації спінового моменту у важкому металі (для Pt `λ_sd ≈ 1.4 нм`, для W `λ_sd ≈ 2.1 нм`).

Ця формула показує важливий геометричний параметр:
1. Якщо товщина важкого металу занадто мала (`d_HM << λ_sd`), спиновий струм не встигає сформуватися в об'ємі, і `θ_SH_eff → 0`.
2. Якщо товщина занадто велика (`d_HM >> λ_sd`), значення `tanh` прямує до 1, однак надлишковий метал шунтує електричний струм, марно розсіюючи джоулеве тепло.
3. Оптимальна товщина важкого металу відповідає умові `d_HM ≈ 1.5–2.0 · λ_sd` (приблизно 3.5–5.0 нм для більшості важких металів).

### 2. Рівняння Ландау — Ліфшиця — Гільберта з додаванням моментів SOT

Динаміка безрозмірного орта намагніченості `m = (m_x, m_y, m_z)` з урахуванням об'ємних та інтерфейсних спін-орбітальних моментів описується розширеним рівнянням LLGS. У векторній формі рівняння має вигляд:

```
d m / d t = -γ · (m × H_eff) + α · (m × d m / d t) + τ_DL0 · m × (m × σ) + τ_FL0 · (m × σ)
```

де `γ = g · μ_B / ħ` — гіромагнітне відношення, `α` — безрозмірний коефіцієнт загасання Гільберта, `σ` — орт спінової поляризації струму.

При протіканні зарядового струму густиною `J_c` вздовж осі `x` у площині гетероструктури, напрямок спінової поляризації утворює вектор `σ = (0, 1, 0) = y_hat`.

Для проведення практичних обчислень переведемо рівняння у явну форму Ландау — Ліфшиця:

```
(1 + α²) · d m / d t
= -γ · (m × H_eff)
  - γ · α · m × (m × H_eff)
  + (τ_DL0 + α · τ_FL0) · m × (m × σ)
  + (τ_FL0 - α · τ_DL0) · (m × σ)      [явне рівняння LLGS з SOT]
```

Звідси видно, що Damping-like момент `τ_DL0` діє безпосередньо у напрямку члена загасання Гільберта, модифікуючи ефективну дисипацію системи, а Field-like момент `τ_FL0` діє аналогічно консервативній прецесії у додатковому магнітному полі.

### 3. Розрахунок ефективних полів SOT та компонентів поля анізотропії

Згенерований об'ємним спиновим ефектом Холла (SHE) спиновий струм `J_s` зв'язаний із зарядовим струмом `J_c` через безрозмірний кут спинового Холла `θ_SH`:

```
J_s = θ_SH · (ħ / (2 · e)) · J_c      [спіновий струм SHE]
```

При проходження цього спинового струму крізь гетеромежу товщиною `d` і площею `A`, передача спинового імпульсу на одиницю об'єму феромагнетика за одиницю часу описується амплітудою Damping-like торка `τ_DL0`:

```
τ_DL0 = γ · H_DL = γ · (ħ · θ_SH_eff · J_c) / (2 · e · M_s · d)      [амплітуда DL-торка]
```

Аналогічно, для Field-like торка `τ_FL0` виражається відповідне ефективне поле `H_FL`:

```
τ_FL0 = γ · H_FL = γ · (ħ · θ_FL · J_c) / (2 · e · M_s · d)      [амплітуда FL-торка]
```

Тут `M_s` — намагніченість насичення феромагнетика (вимірюється в А/м), `d` — товщина магнітного шару (в метрах), `e` — заряд електрона, `θ_FL` — ефективний коефіцієнт інтерфейсного перетворення Рашби — Едельштейна.

Ефективне магнітне поле системи `H_eff` включає чотири класи взаємодій:

```
H_eff = H_ext + H_k + H_demag + H_exch
```

1. **Зовнішнє магнітне поле:** `H_ext = (B_x / μ_0, 0, 0)`.
2. **Поле перпендикулярної анізотропії:** `H_k = (0, 0, H_k0 · m_z)`.
3. **Поле размагнічування (форма):** `H_demag = (0, 0, -M_s · m_z)`.
4. **Поле обмінної взаємодії:** `H_exch = (2 · A_ex / (μ_0 · M_s)) · ∇²m`.

Об'єднуючи поле анізотропії та размагнічування, вводимо ефективне поле перпендикулярної анізотропії:

```
H_k_eff = H_k0 - M_s      [ефективне поле PMA]
```

### 4. Лінеаризовані рівняння малих прецесій та теорія вимірювання ST-FMR

Для вимірювання амплітуд SOT у лабораторних умовах застосовують високочастотну методику **спин-орбітального токового феромагнітного резонансу (Spin-Torque Ferromagnetic Resonance, ST-FMR)**.

Під дією високовольтного змінного струму `I_rf = I_0 · cos(2π · f · t)` вектора намагніченості здійснює малі коливання навколо рівноважної осі. Лінеаризація рівняння LLGS для кутових відхилень `δm_x, δm_y << 1` дає формулу для ефективної ширини лінії резонансу `ΔH`:

```
ΔH = ΔH_intrinsic + ( 2π · f / γ ) · α_eff      [ширина лінії ST-FMR]
```

де ефективне загасання `α_eff` лінійно змінюється під дією постійної складової струму зсуву `I_dc`:

```
α_eff = α_0 + ( (g · μ_B) / (4 · e · M_s · d · f) ) · H_DL(I_dc)      [модуляція загасання SOT]
```

Вимірюючи нахил залежності `α_eff(I_dc)`, експериментатори безпосередньо вираховують кут спинового Холла `θ_SH_eff`. Симетрична компонента лінії резонансу визначається Damping-like торком, а асиметрична — Field-like торком та полем Ерстеда.

### 5. Динамічні рівняння у сферичній системі координат

Для аналітичного дослідження траєкторій інверсії намагніченості зручно перейти від декартових компонент `(m_x, m_y, m_z)` до сферичних кутів `(θ, φ)`:

```
m_x = sin(θ) · cos(φ)
m_y = sin(θ) · sin(φ)
m_z = cos(θ)
```

де `θ` — полярний кут відносно вертикальної осі `z` (`θ = 0` відповідає `m_z = +1`, `θ = π` відповідає `m_z = -1`), а `φ` — азимутальний кут у площині `(xy)` відносно осі `x`.

Підставляючи сферичні компоненти у явне рівняння LLGS, отримуємо систему двох зв'язаних диференціальних рівнянь першого порядку:

```
d θ / d t
= (γ / (1 + α²)) · [ H_eff_φ + α · H_eff_θ ]
  + (γ / (1 + α²)) · H_DL · [ cos(θ) · sin(φ) + α · cos(φ) ]
  + (γ / (1 + α²)) · H_FL · [ cos(φ) - α · cos(θ) · sin(φ) ]

d φ / d t
= (γ / ((1 + α²) · sin(θ))) · [ -H_eff_θ + α · H_eff_φ ]
  + (γ / ((1 + α²) · sin(θ))) · H_DL · [ cos(φ) - α · cos(θ) · sin(φ) ]
  + (γ / ((1 + α²) · sin(θ))) · H_FL · [ -cos(θ) · sin(φ) - α · cos(φ) ]
```

де сферичні компоненти ефективного внутрішнього поля дорівнюють:

```
H_eff_θ = (B_x / μ_0) · cos(θ) · cos(φ) - H_k_eff · sin(θ) · cos(θ)
H_eff_φ = -(B_x / μ_0) · sin(φ)
```

### 6. Аналіз енергетичного потенціалу Стонера — Вольфарта

Енергетичний рельєф одиниці об'єму тонкої магнітної плівки з перпендикулярною анізотропією та зовнішнім полем `B_x` описується потенціалом Стонера — Вольфарта:

```
E(θ, φ) = K_u_eff · sin²(θ) - M_s · B_x · sin(θ) · cos(φ)      [потенціал Стонера-Вольфарта]
```

де `K_u_eff = (1/2) · μ_0 · M_s · H_k_eff` — ефективна константа анізотропії.

У відсутності струму потенціал має два глибоких мінімуми при `θ = 0` (стан `+z`) та `θ = π` (стан `-z`), які розділені високим енергетичним бар'єром:

```
E_barrier = K_u_eff · V · [ 1 - (B_x / (μ_0 · H_k_eff)) ]²      [енергетичний бар'єр]
```

При протіканні струму SOT Damping-like момент виконує роботу над магнітною системою, додаючи оборотний зовнішній потік енергії `P_SOT`:

```
P_SOT = -d E / d t = M_s · H_DL · [ m · (d m / d t × σ) ]      [потужність SOT]
```

Коли потужність `P_SOT` перевищує природну швидкість дисипації енергії Гільбертом `P_diss = α · M_s · γ · |m × H_eff|²`, енергетичний бар'єр повністю вирівнюється, і намагніченість безупинно переходить через екватор.

### 7. Рівняння Фоккера — Планка для ймовірності перемикання при T > 0 K

Для розрахунку теплових флуктуацій використовують рівняння Фоккера — Планка для функції щільності ймовірності `P(m, t)` знаходження вектора намагніченості у просторовому куті `Ω`:

```
∂ P / ∂ t = ∇ · [ (γ / (1 + α²)) · ( (m × H_eff + α · m × (m × H_eff) - H_DL · m × (m × σ)) · P + (D_th / γ) · ∇P ) ]
```

де `D_th = α · k_B · T / (M_s · V)` — коефіцієнт теплової дифузії.

Розв'язок рівняння Фоккера — Планка визначає залежність ймовірності помилки запису (Write Error Rate, WER) від напруги та тривалості імпульсу струму `τ`:

```
WER(J_c) = 1 - exp( - exp( - Δ_0 · (1 - J_c / J_c0) ) )      [формула ймовірності помилки WER]
```

### 8. Виведення критичної густини струму SOT-перемикання

Щоб відбулася інверсія намагніченості шару з PMA від `m_z = +1` до `m_z = -1`, Damping-like поле `H_DL` має подолати результуючий бар'єр анізотропії та дію допоміжного магнітного поля `B_x`.

У наближенні макроспіна критичний стан відповідає точці втрати стійкості початкового полярного стану (`θ → 0`). Умова рівноваги моментів дає критичне поле Damping-like:

```
H_DL_c = (α / 2) · H_k_eff + (2 / π) · (B_x / μ_0)      [критичне поле SOT]
```

Прирівнюючи вираз для `H_DL` до значення `H_DL_c`, отримуємо **критичну густину зарядового струму SOT (`J_c0`)**:

```
J_c0 = (2 · e · M_s · d / (ħ · θ_SH_eff)) · [ (α / 2) · H_k_eff + (2 / π) · (B_x / μ_0) ]
```

Вианалізуємо фундаментальні наслідки отриманої формули:

1. **Залежність від кута спинового Холла:** Критичний струм є обернено пропорційним до `θ_SH_eff`. Використання матеріалів із високим значенням `θ_SH` (наприклад, вольфраму `β-W` з `|θ_SH| ≈ 0.35` або топологічного ізолятора `Bi₂Se₃` з `θ_SH > 1.5`) дозволяє знизити `J_c0` в рази при збереженні геометричних розмірів.
2. **Вплив товщини магнітного шару `d`:** На відміну від STT, де струм тече крізь увесь стек, у SOT струм тече у важкому металі, а передача моментів є поверхневою. Тому критична густина струму прямо пропорційна товщині вільного шару `d`. Зменшення `d` до `0.9–1.2 нм` оптимізує енергоспоживання.
3. **Роль допоміжного поля `B_x`:** Додавання поля `B_x` є необхідним для порушення симетрії при `m_z = 0`. Однак занадто велике поле `B_x` збільшує другий доданок у дужках, підвищуючи критичний струм `J_c0`. Оптимальне значення поля становить `B_x ≈ 0.1–0.2 · H_k_eff`.

### 9. Аналітичний розрахунок енергії та затримки перемикання

У режим надшвидкого наносекундного перемикання (коли тривалість імпульсу `τ < 2 нс`) час перемикання `τ_sw` визначається не термофлуктуаційною активацією, а прямою прецесійною динамікою. Аналітична формула для затримки перемикання під дією імпульсу з амплітудою `J_c > J_c0` описується виразом:

```
τ_sw = (1 / (γ · (H_DL - H_DL_c))) · ln( π / (2 · θ_0) )      [часова затримка SOT]
```

де `θ_0` — початковий кут теплового відхилення намагніченості від осі `z`, який визначається з коефіцієнта Больцмана:

```
θ_0 = √( k_B · T / (2 · K_u_eff · V) )      [початковий кут теплових флуктуацій]
```

Тут `K_u_eff` — ефективна константа анізотропії, `V` — об'єм магнітного елемента.

Оцінка енергії `E_write`, що розсіюється у формі джоулевого тепла в каналі важкого металу з опором `R_HM` під час імпульсу тривалістю `τ_sw`:

```
E_write = I_write² · R_HM · τ_sw = J_c² · A_HM² · (ρ_HM · L_HM / A_HM) · τ_sw
```

```
E_write = J_c² · ρ_HM · V_HM · τ_sw      [енергія запису SOT]
```

де `ρ_HM` — питомий електричний опір важкого металу, `V_HM` — об'єм каналу важкого металу. Для стандартної комірки з геометрією `50 × 100 нм²` та товщиною `Pt` 4 нм, енергія запису становить `E_write ≈ 150–250 фДж`, що на порядок менше порівняно з двотермінальною STT-MRAM (`~2–5 пДж`).
