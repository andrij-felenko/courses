# 🧮 Математичне виведення співвідношень взаємності з гіпотези регресії флуктуацій

Математичне виведення співвідношень взаємності Онсагера є одним із найгарніших здобутків статистичної фізики XX століття. Воно поєднує макроскопічні феноменологічні рівняння переносу з мікроскопічною симетрією рівнянь механіки щодо інверсії часу та теорією термодинамічних флуктуацій Людвига Больцмана й Альберта Ейнштейна. Нижче наведено розгорнуте математичне виведення симетрії коефіцієнтів переносу `L_ij = L_ji`.

## 1. Термодинамічний стан, флуктуації та матриця ентропії

Розглянемо замкнену макроскопічну систему, яка перебуває у стані термодинамічної рівноваги. Нехай стан системи описується сукупністю макроскопічних параметрів `α = (α₁, α₂, ..., αₙ)`. Ці параметри вибрано так, щоб у стані повної термодинамічної рівноваги їхні середні значення дорівнювали нулю: `<αᵢ> = 0`. Прикладами змінних `αᵢ` можуть слугувати локальні відхилення густини маси, густини внутрішньої енергії, концентрації хімічних компонентів або електричного заряду у малі об'ємі.

У стані рівноваги ентропія системи `S(α)` досягає свого абсолютного максимуму `S₀`. Розкладемо зміну ентропії `ΔS(α) = S(α) − S₀` у багатовимірний ряд Тейлора за параметрами `αᵢ` в околі рівноважного стану `α = 0`:

```
ΔS(α) = S(0) + ∑ᵢ (∂S/∂αᵢ)₀ · αᵢ + (1/2) · ∑ᵢ ∑ⱼ (∂²S / (∂αᵢ ∂αⱼ))₀ · αᵢ · αⱼ + ...
```

Оскільки ентропія досягає максимуму при `α = 0`, усі перші похідні дорівнюють нулю: `(∂S/∂αᵢ)₀ = 0`. Нехтуючи членами вищих порядків (що є виправданим для малих макроскопічних флуктуацій), отримуємо квадратичну форму:

```
ΔS(α) = −(1/2) · ∑ᵢ ∑ⱼ gᵢⱼ · αᵢ · αⱼ
```

де `gᵢⱼ = −(∂²S / (∂αᵢ ∂αⱼ))₀` — симетрична (`gᵢⱼ = gⱼᵢ`) та додатно визначена матриця ентропійного термодинамічного потенціалу. Додатна визначеність матриці `g` є наслідком вовігнутості ентропії у стані стійкої рівноваги.

За статистичною формулою Ейнштейна, ймовірність `W(α) dα₁...dαₙ` того, що система внаслідок теплового руху відхилиться від рівноваги й опиниться в елементі фазового об'єму `dα`, пропорційна експоненті від зміни ентропії, поділеної на сталу Больцмана `k_B`:

```
W(α) = C · exp( ΔS(α) / k_B )
     = C · exp( −1/(2·k_B) · ∑ᵢ ∑ⱼ gᵢⱼ · αᵢ · αⱼ )
```

де `C` — нормувальний константний множник, який визначається з умови `∫ W(α) dα = 1`. Отриманий розподіл є багатовимірним гауссовим розподілом флуктуацій.

## 2. Термодинамічні сили та кореляційні властивості

Спряженими термодинамічними силами `Xᵢ` за Онсагером називаються частинні похідні від зміни ентропії системи по відповідних флуктуаційних змінних `αᵢ`:

```
Xᵢ = ∂(ΔS) / ∂αᵢ
   = −∑ⱼ gᵢⱼ · αⱼ            [похідна квадратичної форми ΔS(α)]
```

Звернувши матричне співвідношення, ми можемо виразити відхилення `αᵢ` через термодинамічні сили `Xⱼ`:

```
αᵢ = −∑ⱼ (g⁻¹)ᵢⱼ · Xⱼ
```

де `(g⁻¹)ᵢⱼ` — елементи матриці, оберненої до ентропійної матриці `g`.

Обчислимо тепер статистичне середнє (кореляцію) від добутку флуктуаційного параметра `αᵢ` та термодинамічної сили `Xⱼ` у рівноважному ансамблі:

```
< αᵢ · Xⱼ > = ∫ ... ∫ αᵢ · (∂ΔS / ∂αⱼ) · W(α) dα₁...dαₙ
```

Зауважимо, що з виразу для ймовірності Ейнштейна випливає тотожність:

```
∂W / ∂αⱼ = (1 / k_B) · (∂ΔS / ∂αⱼ) · W(α)   ⇒   (∂ΔS / ∂αⱼ) · W(α) = k_B · (∂W / ∂αⱼ)
```

Підставимо цю тотожність у вираз для кореляції та застосуємо багатовимірне інтегрування частинами:

```
< αᵢ · Xⱼ >
= k_B · ∫ ... ∫ αᵢ · (∂W / ∂αⱼ) dα₁...dαₙ
= k_B · [ ∫ αᵢ W |₋∞⁺∞ dα' − ∫ W · (∂αᵢ / ∂αⱼ) dα ]  [інтегрування частинами за змінною αⱼ]
= −k_B · δᵢⱼ                                        [згортка за символом Кронекера δᵢⱼ]
```

Поверхневий член на нескінченності зникає через швидке експоненційне згасання гауссового розподілу `W(α) → 0`, а похідна `∂αᵢ / ∂αⱼ` дорівнює символу Кронекера `δᵢⱼ` (`δᵢⱼ = 1` при `i = j` та `δᵢⱼ = 0` при `i ≠ j`).

Таким чином, ми вивели фундаментальні кореляційні співвідношення Ейнштейна — Онсагера:

```
< αᵢ · Xⱼ > = −k_B · δᵢⱼ
< αᵢ · αⱼ > = k_B · (g⁻¹)ᵢⱼ
< Xᵢ · Xⱼ > = k_B · gᵢⱼ
```

Ці формули показують, що кожна термодинамічна сила `Xᵢ` у середньому корелює лише зі своєю власною спряженою змінною `αᵢ` з коефіцієнтом пропорційності `-k_B`.

## 3. Мікроскопічна зворотність часу для часових кореляційних функцій

Розглянемо часову еволюцію системи. Нехай `αᵢ(t)` — значення макроскопічного параметра у момент часу `t`. Усереднення добутку двох параметрів `αᵢ` та `αⱼ`, виміряних у моменти часу `t` та `t + τ`, по стаціонарному рівноважному ансамблю задає часову автокореляційну функцію:

```
Φᵢⱼ(τ) = < αᵢ(t) · αⱼ(t + τ) >
```

У стаціонарному стані кореляційна функція залежить лише від часового інтервалу `τ = (t₂ − t₁)`, але не від вибору початкового моменту часу `t`. Тому ми можемо зробити зсув часу на `-τ`:

```
< αᵢ(t) · αⱼ(t + τ) > = < αᵢ(t − τ) · αⱼ(t) >
```

Тепер застосуємо фундаментальну властивість мікроскопічної фізики — **інваріантність рівнянь руху відносно інверсії часу (t → −t)**. Сформулюємо її так: якщо ми інвертуємо швидкості всіх частинок системи у момент часу `t`, система пройде у зворотному напрямку точно таку саму послідовність мікростанів.

Для термодинамічних змінних `αᵢ`, які є парними за часом (тобто не змінюють свій знак при інверсії часу `t → −t`, як-от температура, густини маси, концентрація), інверсія часу дає:

```
< αᵢ(t − τ) · αⱼ(t) > = < αᵢ(t + τ) · αⱼ(t) >
```

Об'єднуючи це з попереднім співвідношенням зсуву часу, отримуємо **умову мікроскопічної зворотності для кореляційних функцій**:

```
< αᵢ(t) · αⱼ(t + τ) > = < αᵢ(t + τ) · αⱼ(t) >
```

Фізичний зміст цієї формули є глибинним: ймовірність того, що система перейде зі стану з флуктуацією `αᵢ` у стан з флуктуацією `αⱼ` за час `τ`, строго дорівнює ймовірності зворотного переходу зі стану `αⱼ` у стан `αᵢ` за той самий час `τ`.

## 4. Гіпотеза регресії Онсагера та доведення симетрії

Для того щоб вивести макроскопічну симетрію коефіцієнтів переносу, Онсагер пов'язав мікроскопічні флуктуації з макроскопічною кінетикою за допомогою своєї знаменитої **гіпотези регресії флуктуацій**:

> *Середнє згасання (регресія) спонтанної флуктуації `α(τ)` за умови, що у момент часу `τ = 0` вона мала значення `α(0)`, описується тими самими феноменологічними рівняннями переносу, що й згасання макроскопічного нерівноважного стану.*

Згідно з феноменологічною нерівноважною термодинамікою, швидкість зміни параметрів переносу `dα/dτ` задається лінійними феноменологічними рівняннями:

```
dαⱼ(t + τ) / dτ = ∑ₖ Lⱼₖ · Xₖ(t + τ)
```

де `Lⱼₖ` — макроскопічні кінетичні коефіцієнти, а `Xₖ` — термодинамічні сили.

Візьмемо умову мікроскопічної зворотності `< αᵢ(t) · αⱼ(t + τ) > = < αᵢ(t + τ) · αⱼ(t) >`, продиференціюємо її по часовому інтервалу `τ` та розглянемо границю при `τ → 0⁺`.

Продиференціюємо ліву частину по `τ`:

```
d/dτ < αᵢ(t) · αⱼ(t + τ) >
= < αᵢ(t) · (dαⱼ(t + τ) / dτ) >
= < αᵢ(t) · (∑ₖ Lⱼₖ · Xₖ(t + τ)) >       [застосування макроскопічних рівнянь переносу]
= ∑ₖ Lⱼₖ · < αᵢ(t) · Xₖ(t + τ) >       [винесення константних коефіцієнтів Lⱼₖ під знак усереднення]
```

Спрямуємо `τ → 0⁺` та підставимо виведене раніше кореляційне співвідношення Ейнштейна `< αᵢ · Xₖ > = −k_B · δᵢₖ`:

```
lim_{τ→0⁺} d/dτ < αᵢ(t) · αⱼ(t + τ) >
= lim_{τ→0⁺} ∑ₖ Lⱼₖ · < αᵢ(t) · Xₖ(t + τ) >   [перехід до границі при τ → 0⁺]
= ∑ₖ Lⱼₖ · (−k_B · δᵢₖ)                       [підстановка граничного кореляційного співвідношення <αᵢ Xₖ> = −k_B δᵢₖ]
= −k_B · Lⱼᵢ                                  [згортка за індексом k з використанням символу Кронекера]
```

Тепер продиференціюємо праву частину умови зворотності `< αᵢ(t + τ) · αⱼ(t) >` по `τ`:

```
d/dτ < αᵢ(t + τ) · αⱼ(t) >
= < (dαᵢ(t + τ) / dτ) · αⱼ(t) >
= < (∑ₖ Lᵢₖ · Xₖ(t + τ)) · αⱼ(t) >       [застосування феноменологічного закону переносу]
= ∑ₖ Lᵢₖ · < Xₖ(t + τ) · αⱼ(t) >       [винесення константних коефіцієнтів Lᵢₖ під знак усереднення]
```

Спрямуємо `τ → 0⁺` та підставимо кореляційне співвідношення `< Xₖ · αⱼ > = −k_B · δₖⱼ`:

```
lim_{τ→0⁺} d/dτ < αᵢ(t + τ) · αⱼ(t) >
= lim_{τ→0⁺} ∑ₖ Lᵢₖ · < Xₖ(t + τ) · αⱼ(t) >   [перехід до границі при τ → 0⁺]
= ∑ₖ Lᵢₖ · (−k_B · δₖⱼ)                       [підстановка граничного кореляційного співвідношення <Xₖ αⱼ> = −k_B δₖⱼ]
= −k_B · Lᵢⱼ                                  [згортка за індексом k з використанням символу Кронекера]
```

Оскільки ліва та права частини умови зворотності є тотожно рівними для будь-якого `τ`, їхні похідні у точці `τ → 0⁺` також повинні збігатися:

```
−k_B · Lⱼᵢ = −k_B · Lᵢⱼ
```

Поділивши обидві частини рівняння на ненульову сталу `-k_B`, ми отримуємо шукане **співвідношення взаємності Онсагера**:

```
Lᵢⱼ = Lⱼᵢ
```

Це доведення є абсолютним триумфом теоретичної фізики: воно показує, що симетрія макроскопічної матриці коефіцієнтів переносу `L` є прямим наслідком симетрії інверсії часу в мікроскопічних рівняннях руху частинок!

## 5. Узагальнення Онсагера — Казимира для магнітних полів та обертання

У 1945 році нідерландський фізик Гендрік Казимир (Hendrik Casimir) звернув увагу на те, що класичне виведення Онсагера вимагає уточнення у двох важливих випадках:
1. Коли система перебуває у зовнішньому магнітному полі `B` або обертається з кутовою швидкістю `Ω`.
2. Коли деякі термодинамічні змінні `αᵢ` є **непарними за часом** (тобто змінюють знак при інверсії `t → −t`, наприклад, макроскопічні швидкості, імпульси або магнітні моменти: `αᵢ(−t) = −αᵢ(t)`).

Якщо на частинки діє сила Лоренца `F = q · (v × B)` або сила Коріоліса `F_c = 2m · (v × Ω)`, то при зміні напрямку руху частинок (`v → −v`) для збереження тієї самої траєкторії необхідно одночасно інвертувати напрямок зовнішнього магнітного поля (`B → −B`) або вектора обертання (`Ω → −Ω`).

Враховуючи часову парність параметрів `εᵢ` (`εᵢ = +1` для парних величин та `εᵢ = −1` для непарних), вирази для мікроскопічної зворотності беруть вигляд:

```
< αᵢ(0, B, Ω) · αⱼ(τ, B, Ω) > = εᵢ · εⱼ · < αᵢ(τ, −B, −Ω) · αⱼ(0, −B, −Ω) >
```

Повторюючи процедуру диференціювання за часовим інтервалом `τ` та переходу до макроскопічних коефіцієнтів переносу, отримуємо **співвідношення взаємності Онсагера — Казимира**:

```
Lᵢⱼ(B, Ω) = εᵢ · εⱼ · Lⱼᵢ(−B, −Ω)
```

### Основні окремі випадки співвідношень Онсагера — Казимира:

1. **Скалярні парні параметри (`εᵢ = εⱼ = +1`) за відсутності поля (`B = 0, Ω = 0`):**
   ```
   Lᵢⱼ = Lⱼᵢ                         [класичні співвідношення Онсагера]
   ```
2. **Гальваномагнітні та термомагнітні явища у магнітному полі `B`:**
   Для компонент тензора електропровідності чи теплопровідності `L_xy` у магнітному полі (наприклад, для ефекту Холла або ефекту Нернста — Еттінгсгаузена):
   ```
   L_xy(B) = L_yx(−B)
   ```
   Це означає, що поперечна провідність `L_xy` у полі `B` дорівнює зворотній поперечній провідності `L_yx` у протилежному полі `−B`.

3. **Спряження між парною та непарною змінними (`εᵢ · εⱼ = −1`):**
   Якщо сила `X_j` є парною за часом, а потік `J_i` описує непарну величину (наприклад, потік імпульсу чи гідродинамічну швидкість):
   ```
   Lᵢⱼ = −Lⱼᵢ                        [антисиметричне співвідношення]
   ```

Таким чином, узагальнена теорія Онсагера — Казимира повністю покриває весь спектр процесів переносу в суцільних середовищах, магнітоактивній плазмі, твердих тілах та квантових рідинах.
