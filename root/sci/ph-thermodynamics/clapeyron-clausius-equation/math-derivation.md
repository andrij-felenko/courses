# 🧮 Термодинамічне виведення рівняння Клапейрона — Клаузіуса

Рівняння Клапейрона — Клаузіуса зв'язує нахил кривої співіснування двох фаз `dP/dT` на площині станових змінних тиск–температура з прихованою теплотою переходу `L` та стрибком молярного (або питомого) об'єму `Δv`. Отримати це фундаментальне співвідношення можна трьома незалежними термодинамічними шляхами: через рівність хімічних потенціалів, через нескінченно малий цикл Карно та за допомогою співвідношень Максвелла. Крім того, інтегральні форми цього рівняння дають практичні формули залежності тиску насиченої пари від температури.

## Метод 1: Рівність хімічних потенціалів рівноважних фаз

Розглянемо однокомпонентну систему, яка перебуває у стані фазової рівноваги (наприклад, рідина та пара або лід і вода). Умова термодинамічної рівноваги двох фаз при заданих тиску `P` та температурі `T` вимагає рівності їхніх молярних потенціалів Гіббса або хімічних потенціалів `μ_1` та `μ_2`:

```
μ_1(T, P) = μ_2(T, P)
```

При зміні температури на нескінченно малу величину `dT` тиск рівноважної системи неминуче змінюється на `dP` уздовж лінії співіснування фаз `P(T)`, щоб система не вийшла зі стану рівноваги. Отже, у новій точці `(T + dT, P + dP)` хімічні потенціали обох фаз знову мають бути рівними:

```
μ_1(T + dT, P + dP) = μ_2(T + dT, P + dP)
```

Розкладаючи обох членів у диференціали першого порядку, отримуємо:

```
dμ_1 = dμ_2
```

Зазначимо фундаментальне термодинамічне співвідношення для диференціала хімічного потенціалу одиниці маси чи одного моля речовини через молярну ентропію `s` та молярний об'єм `v`:

```
dμ = -s·dT + v·dP
```

Підставивши цей вираз окремо для першої та другої фази у молярне співвідношення рівноваги `dμ_1 = dμ_2`, маємо:

```
-s_1·dT + v_1·dP = -s_2·dT + v_2·dP
```

Групуємо члени з однаковими диференціалами `dT` та `dP`:

```
(v_2 - v_1)·dP = (s_2 - s_1)·dT
```

Розділивши обидві частини на `dT` та `(v_2 - v_1)`, отримуємо проміжне виведення для нахилу лінії фазової рівноваги:

```
dP / dT = (s_2 - s_1) / (v_2 - v_1) = Δs / Δv
```

Оскільки фазовий перехід I роду відбувається при постійній температурі `T`, зміна ентропії `Δs = s_2 - s_1` пов'язана з поглинутою або виділеною молярною прихованою теплотою переходу `L` відомим співвідношенням Другого закону термодинаміки:

```
L = T·Δs  ⇒  Δs = L / T
```

Підставивши вираз для `Δs` у похідну `dP/dT`, отримуємо точне **рівняння Клапейрона — Клаузіуса**:

```
dP / dT = L / (T·(v_2 - v_1)) = L / (T·Δv)
```

## Метод 2: Елементарний цикл Карно у двофазній області

Другий спосіб виведення спирається на геометрію нескінченно малого оборотного циклу Карно, виконаного робочим тілом безпосередньо у двофазній гетерогенній області.

Нехай `1` моль речовини перебуває у двофазній області при температурі `T` і тиску насичення `P`. Проведемо чотири оборотні такти:
1. **Ізотермічне розширення (при T + dT):** Речовина отримує кількість теплоти `Q_H = L` від нагрівача, повністю випаровуючись (або плавлячись). Тиск залишається незмінним і дорівнює `P + dP`. Зміна об'єму становить `Δv = v_2 - v_1`.
2. **Адіабатичне розширення:** Система теплоізолюється і розширюється, при цьому температура знижується від `T + dT` до `T`, а тиск падає від `P + dP` до `P`.
3. **Ізотермічне стискання (при T):** Система віддає теплоту `Q_C = L - dL` холодильнику при постійній температурі `T` та тиску `P`, повністю повертаючись у вичатковий фазовий стан.
4. **Адіабатичне стискання:** Система стискається без теплообміну, нагріваючись від `T` назад до `T + dT`, замикаючи цикл.

Площа отриманого тонкого паралелограма на `P-V` діаграмі є виконаною корисною роботою за цикл `dW`:

```
dW = dP · Δv = dP · (v_2 - v_1)
```

Згідно з теоремою Карно, ККД `η` будь-якого оборотного циклу, що працює між температурами `T + dT` та `T`, строго дорівнює:

```
η = dW / Q_H = (dP · Δv) / L
```

З іншого боку, ККД циклу Карно через абсолютні температури термостатів визначається як:

```
η = ((T + dT) - T) / (T + dT) ≈ dT / T
```

Прирівнюючи два незалежні вирази для ККД `η`:

```
(dP · Δv) / L = dT / T
```

Перегрупувавши члени, отримуємо те саме підсумкове співвідношення:

```
dP / dT = L / (T · Δv)
```

## Метод 3: Диференціальні співвідношення Максвелла

Третій спосіб виведення виходить із термодинамічного співвідношення Максвелла для вільних потенціалів. З диференціала вільної енергії Гельмгольца `dF = -S·dT - P·dV` випливає рівність других мішаних похідних:

```
(∂S / ∂V)_T = (∂P / ∂T)_V
```

Під час фазового переходу першого роду при сталій температурі `T` тиск насиченої пари `P` є суворо незалежним від об'єму `V` і залежить виключно від температури `T`. Тому частинна похідна `(∂P / ∂T)_V` вироджується в повну похідну уздовж лінії співіснування фаз:

```
(∂P / ∂T)_V = dP / dT
```

Інтегруємо ліву частину співвідношення Максвелла по об'єму від початкового об'єму першої фази `v_1` до кінцевого об'єму другої фази `v_2` при сталій температурі `T`:

```
∫_(v_1)^(v_2) (∂S / ∂V)_T dV = (dP / dT) · ∫_(v_1)^(v_2) dV
```

Ліва частина дає повний стрибок ентропії `Δs = s_2 - s_1 = L / T`, а права частина дорівнює `(dP / dT) · (v_2 - v_1)`:

```
L / T = (dP / dT) · (v_2 - v_1)  ⇒  dP / dT = L / (T · Δv)
```

## Інтегрування для фазового переходу «Рідина — Пара»

При розгляді фазового переходу випаровування (або сублімації) при температурах, далеких від критичної точки, можна застосувати два обґрунтовані спрощення:
1. Молярний об'єм газу `v_2` є значно більшим за молярний об'єм рідини `v_1` (`v_2 ≫ v_1`), тому `Δv = v_2 - v_1 ≈ v_2`.
2. Газову фазу можна з високою точністю описувати рівнянням стану ідеального газу `v_2 = R·T / P`.

Підставивши ці наближення у рівняння Клапейрона — Клаузіуса:

```
dP / dT = (L_vap · P) / (R · T²)
```

Розділивши змінні `P` та `T`:

```
dP / P = (L_vap / R) · (dT / T²)  ⇒  d(ln P) / dT = L_vap / (R · T²)
```

Якщо припустити, що молярна прихована теплота випаровування `L_vap` є постійною величиною у вузькому температурному інтервалі від `T_1` до `T_2`, інтегрування дає інтегральну форму **формули Клаузіуса — Краперона**:

```
ln(P_2 / P_1) = - (L_vap / R) · (1 / T_2 - 1 / T_1)
```

Або в експоненційній формі для залежності тиску насиченої пари від температури:

```
P(T) = P_0 · exp( - (L_vap / R) · (1/T - 1/T_0) )
```

У ширшому діапазоні температур слід враховувати температурну залежність прихованої теплоти за законом Кірхгофа: `L(T) = L_0 + ΔC_p · (T - T_0)`, де `ΔC_p = C_p,gas - C_p,liq` є різницею молярних теплоємностей. Інтегрування з урахуванням `ΔC_p` дає уточнено трьохпараметричну залежність:

```
ln P = A - B / T + C · ln T
```

Цей математичний результат лежить в основі напівемпіричних інженерних формул тиску насиченої пари, таких як рівняння Антуана.

## Поправка на реальний газ (Рівняння Ван дер Ваальса)

При високому тиску, наближаючись до критичної точки, газова фаза істотно відхиляється від моделі ідеального газу. Для врахування власних об'ємів молекул `b` та сил міжмолекулярного притягання `a` застосовують рівняння Ван дер Ваальса:

```
(P + a / v²) · (v - b) = R · T
```

Виражаючи молярний об'єм пари `v_gas` через тиск та температуру з урахуванням коефіцієнта стисливості `Z = P·v / (R·T)`:

```
v_gas = (Z · R · T) / P
```

Підставивши цей вираз у диференціальне рівняння Клапейрона — Клаузіуса, отримуємо узагальнене рівняння для реальних газів:

```
dP / dT = (L_vap · P) / (Z · R · T² · (1 - v_liq / v_gas))
```

При помірних тисках коефіцієнт стисливості `Z < 1` за рахунок переважання сил міжмолекулярного притягання, що робить зростання тиску з температурою дещо більш крутим, ніж передбачає модель ідеального газу. При наближенні до критичної точки `Z` падає до значення близько `0.28`, а різниця об'ємів `(v_gas - v_liq)` прямує до нуля.

## Поліморфні фазові переходи у твердому тілі

Рівняння Клапейрона — Клаузіуса є однаково чинним не лише для змін агрегатного стану (плавлення, випаровування, сублімація), але й для **поліморфних перетворень** у твердій фазі, коли одна кристалічна модифікація переходить у іншу при зміні тиску та температури.

Розглянемо фазовий перехід графіт → алмаз. Оскільки густина алмазу (`3.51 г/см³`) є суттєво більшою за густину графіту (`2.26 г/см³`), молярний об'єм алмазу є меншим:

```
Δv = v_алмаз - v_графіт = -1.88 см³/моль < 0
```

Оскільки ентальпія фазового переходу є додатною (`L = 1.9 кДж/моль`), з рівняння Клапейрона — Клаузіуса випливає позитивний нахил кривої співіснування фаз при високих тисках:

```
dP / dT = L / (T · Δv) < 0
```

При кімнатній температурі графіт є термодинамічно стійкою фазою при атмосферному тиску, а алмаз є метастабільним. Для штучного синтезу алмазу з графіту необхідно прикласти тиск понад `50 000 атмосфер` (`5 ГПа`) при температурі понад `1500 °C`, що точно розраховується за лінією рівноваги Клапейрона — Клаузіуса.

Аналогічний аналіз застосовується до поліморфних фаз льоду (лід `I_h`, лід `III`, лід `V`, лід `VI`), де для високонапірних модифікацій `Δv > 0`, і нахил кривої плавлення `dP/dT` знову стає додатним.
