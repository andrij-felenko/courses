# 🧮 Квантовомеханічне та термодинамічне виведення тиску виродженого фермі-газу

Ця вставка містить строгий математичний вивід густини квантових станів, ферміївського імпульсу, повної внутрішньої енергії, термодинамічних потенціалів та тиску виродженого фермі-газу у нерелятивістському, ультрарелятивістському та загальному релятивістському режимах при абсолютному нулю (`T = 0 K`) та низьких температурах (`T ≪ T_F`).

## 1. Квантові стани у тривимірному потенціальному ящику та фазовий об'єм

Розглянемо квантовомеханічну систему з `N` вільних тотожних ферміонів масою `m` і спіном `s = 1/2`, що знаходяться у тривимірному прямокутному об'ємі `V = L_x · L_y · L_z`.

Одночастинкове стаціонарне рівняння Шредінгера описується виразом:

```
- (ℏ² / (2 m)) · ∇² Ψ(x, y, z) = E · Ψ(x, y, z)
```

При застосуванні періодичних граничних умов Борна — Кармана (`Ψ(x + L_x, y, z) = Ψ(x, y, z)`) розв'язками рівняння є плоскі хвилі `Ψ_k(r) = (1 / √V) · exp(i k · r)`. Складові хвильового вектора `k = (k_x, k_y, k_z)` приймають дискретні значення:

```
k_x = (2 π / L_x) · n_x
k_y = (2 π / L_y) · n_y
k_z = (2 π / L_z) · n_z
```

де `n_x, n_y, n_z` — довільні цілі числа (`0, ±1, ±2, ...`).

Об'єм однієї елементарної комірки у хвильовому `k`-просторі, яка відповідає одному просторовому квантовому стану, обчислюється як добуток кроків дискретизації по трьох осях:

```
ΔV_k = Δk_x · Δk_y · Δk_z
= (2 π / L_x) · (2 π / L_y) · (2 π / L_z)    [підстановка кроків дискретизації по трьох осях]
= (8 π³ / V)                                 [перемноження та підстановка об'єму V = Lx Ly Lz]
```

Оскільки частинки мають півцілий спін `s = 1/2`, кратність спінового виродження становить `g_s = 2s + 1 = 2` (два можливі значення проєкції спіну `m_s = ±1/2`). За принципом заборони Паулі у кожній елементарній комірці фазового простору `ΔV_k` може перебувати не більше ніж `g_s = 2` ферміони.

Кількість квантових станів `dN`, що знаходяться у тонкому сферичному шарі хвильового простору радіуса `k` товщиною `dk`, дорівнює добутку спінового фактора `g_s` на відношення об'єму шару `4 π k² dk` до об'єму однієї комірки `ΔV_k`:

```
dN = g_s · (4 π k² dk / ΔV_k)
= 2 · (4 π k² dk / (8 π³ / V))      [підстановка g_s = 2 та ΔV_k = 8π³/V]
= (V / π²) · k² dk                [скорочення 8π / 8π³ = 1 / π²]
```

Виражаючи імпульс частинки через хвильовий вектор `p = ℏ k` (`dk = dp / ℏ`), знайдемо кількість квантових станів в інтервалі імпульсів від `p` до `p + dp`:

```
dN(p) = (V / (π² ℏ³)) · p² dp
```

Для вираження через кінетичну енергію `E` скористаємося нерелятивістським законом дисперсії `E = p² / (2m)` (`p = √(2mE)`, `dp = √(m / (2E)) dE`):

```
dN(E) = g(E) dE
= (V / (2 π²)) · (2 m / ℏ²)³/² · √E dE
```

Функція `g(E) = dN / dE` називається **густиною квантових станів**. У тривимірному нерелятивістському газі густина станів зростає як квадратний корінь з енергії `g(E) ∝ √E`.

## 2. Інтегрування сфери Фермі та параметри при T = 0 K

При абсолютному нулю температур `T = 0 K` функція розподілу Фермі — Дірака є строгою сходинкою Хевісайда:

```
f(E) = 1  при E ≤ E_F
f(E) = 0  при E > E_F
```

Усі квантові стани у `k`-просторі з радіусом `k ≤ k_F` повністю заповнені, а стани з `k > k_F` є абсолютно порожніми. Загальна кількість частинок у газі `N` дорівнює інтегралу від густини станів по всій сфері Фермі:

```
N = ∫₀^{k_F} dN
= ∫₀^{k_F} (V / π²) · k² dk
= (V / π²) · [k³ / 3]₀^{k_F}       [інтегрування k² dk = k³/3]
= (V · k_F³) / (3 π²)               [підстановка верхньої межі]
```

Звідси отримуємо вираз для граничного хвильового вектора Фермі `k_F` та граничного імпульсу Фермі `p_F` через числову концентрацію частинок `n = N / V`:

```
k_F = (3 π² · n)¹/³
p_F = ℏ · (3 π² · n)¹/³
```

Для нерелятивістських частинок гранична енергія Фермі `E_F` визначається як:

```
E_F = p_F² / (2 m)
= (ℏ² / (2 m)) · (3 π² · n)²/³
```

Густина квантових станів безпосередньо на поверхні сфери Фермі `g(E_F)` дорівнює:

```
g(E_F) = (3 N) / (2 E_F)
```

Цей вираз показує, що більша частина енергетичних рівнів зосереджена поблизу поверхні Фермі, що є фундаментальним фактором для обчислення теплоємності та сприйнятливості.

## 3. Обчислення внутрішньої енергії та тиску у нерелятивістському режимі

Повна кінетична енергія `U_0` абсолютно виродженого нерелятивістського фермі-газу обчислюється підсумовуванням енергій усіх заповнених станів від центра сфери Фермі до її поверхні:

```
U_0 = ∫₀^{k_F} E(k) · dN(k)
= ∫₀^{k_F} ((ℏ² k²) / (2 m)) · ((V / π²) k² dk)
= (V ℏ² / (2 m π²)) · ∫₀^{k_F} k⁴ dk
= (V ℏ² / (2 m π²)) · (k_F⁵ / 5)     [інтегрування k⁴ dk = k⁵/5]
= (V ℏ² k_F⁵) / (10 m π²)            [перемноження знаменників]
```

Виразимо `U_0` через повну кількість частинок `N` та енергію Фермі `E_F`, виділивши множник `N = V k_F³ / (3 π²)`:

```
U_0 = (3/5) · (V k_F³ / (3 π²)) · ((ℏ² k_F²) / (2 m))
= (3/5) · N · E_F
```

Середня кінетична енергія однієї частинки у виродженому нерелятивістському фермі-газі дорівнює `⟨E⟩ = (3/5) E_F`. Це означає, що при квантовому виродженні середня енергія частинки становить понад половину максимальної енергії Фермі.

За законами термодинаміки при `T = 0 K` ентропія дорівнює нулю `S = 0`, а термодинамічний потенціал Гельмгольца збігається з внутрішньою енергією `F = U_0`. Тиск виродження `P` задається від'ємною похідною за об'ємом `V` при постійному числі частинок `N`:

```
P = - (∂U_0 / ∂V)_N
```

Виразимо внутрішню енергію `U_0` через об'єм `V`:

```
U_0 = (3/5) N · (ℏ² / (2m)) · (3 π² N / V)²/³
= C_NR · N⁵/³ · V⁻²/³               [де C_NR = (3/5) (ℏ²/2m) (3π²)²/³]
```

Візьмемо похідну за об'ємом `V`:

```
P = - C_NR · N⁵/³ · ((-2/3) · V⁻⁵/³)
= (2/3) · (C_NR · N⁵/³ · V⁻²/³) / V
= (2/3) · (U_0 / V)                 [фундаментальне нерелятивістське співвідношення]
```

Підставляючи вираз для `U_0 / V = (3/5) n E_F`:

```
P = (2/3) · (3/5) · n · E_F
= (1/5) · (3 π²)²/³ · (ℏ² / m) · n⁵/³
```

Записуючи концентрацію `n` через масову густину `ρ = μ_e m_u n`, отримуємо нерелятивістський закон:

```
P = K_1 · ρ⁵/³
```

де `K_1 = ((3 π²)²/³ ℏ²) / (5 m_e (μ_e m_u)⁵/³) ≈ 1.003 × 10⁶ (в одиницях CGS)`.

## 4. Обчислення у ультрарелятивістському режимі

Коли концентрація частинок зростає настільки, що граничний імпульс Фермі значно перевищує масу спокою `p_F ≫ m c`, закон дисперсії стає лінійним `E(p) = c p = ℏ c k`.

Обчислимо повну внутрішню енергію ультрарелятивістського газу `U_{0,UR}` при `T = 0 K`:

```
U_{0,UR} = ∫₀^{k_F} (ℏ c k) · ((V / π²) k² dk)
= (V ℏ c / π²) · ∫₀^{k_F} k³ dk
= (V ℏ c / π²) · (k_F⁴ / 4)          [інтегрування k³ dk = k⁴/4]
= (V ℏ c k_F⁴) / (4 π²)              [обчислення інтеграла]
```

Виразимо `U_{0,UR}` через число частинок `N = V k_F³ / (3 π²)` та граничну енергію Фермі `E_{F,UR} = ℏ c k_F`:

```
U_{0,UR} = (3/4) · (V k_F³ / (3 π²)) · (ℏ c k_F)
= (3/4) · N · E_{F,UR}
```

Середня кінетична енергія частинки в ультрарелятивістському газі дорівнює `⟨E⟩ = (3/4) E_{F,UR}`.

Обчислимо тиск як похідну за об'ємом:

```
U_{0,UR} = (3/4) N · ℏ c · (3 π² N / V)¹/³ ∝ V⁻¹/³
```

```
P_UR = - (∂U_{0,UR} / ∂V)_N
= (1/3) · (U_{0,UR} / V)            [фундаментальне ультрарелятивістське співвідношення]
```

Підставляючи вираз для `U_{0,UR} / V = (3/4) n E_{F,UR}`:

```
P_UR = (1/3) · (3/4) · n · (ℏ c (3 π² n)¹/³)
= ((3 π²)¹/³ · ℏ c) / 4 · n⁴/³
```

Враховуючи `ρ = μ_e m_u n`, отримуємо ультрарелятивістський закон Чандрасекара:

```
P_UR = K_2 · ρ⁴/³
```

де `K_2 = ((3 π²)¹/³ ℏ c) / (4 (μ_e m_u)⁴/³) ≈ 1.243 × 10¹⁵ (в одиницях CGS)`.

Порівняння двох режимів показує фундаментальний зв'язок між тиском та густиною кінетичної енергії `u = U / V`:
- Нерелятивістський режим: `P = (2/3) u`;
- Ультрарелятивістський режим: `P = (1/3) u`.

Зменшення множника з `2/3` до `1/3` безпосередньо відображає релятивістську граничну швидкість переносу імпульсу частинками, яка не може перевищувати швидкість світла `c`.

## 5. Точне релятивістське виведення Чандрасекара для довільних імпульсів

У загальному випадку довільної густини релятивістська кінетична енергія частинки дорівнює `E(p) = √(p² c² + m² c⁴) - m c²`.

Повна внутрішня енергія `U_0` задається точним інтегралом:

```
U_0 = (V / (π² ℏ³)) · ∫₀^{p_F} (√(p² c² + m² c⁴) - m c²) · p² dp
```

Введемо безрозмірну змінну імпульсу `y = p / (m c)` та граничний параметр `x = p_F / (m c) = (ℏ / (m c)) (3 π² n)¹/³`:

```
U_0 = ((V m⁴ c⁵) / (π² ℏ³)) · ∫₀^{x} (√(1 + y²) - 1) · y² dy
```

Виконуючи точне інтегрування частинами для виразу `∫₀^{x} y² √(1 + y²) dy`:

```
∫ y² √(1 + y²) dy = (1/8) · [ y (2 y² + 1) √(1 + y²) - ln(y + √(1 + y²)) ]
```

Тиск `P = - ∂U_0 / ∂V` обчислюється диференціюванням інтеграла за верхньою межею `x ∝ V⁻¹/³`:

```
P(x) = A · f(x)
```

де константа `A` дорівнює:

```
A = (π m_e⁴ c⁵) / (3 h³)
```

а точна тотожна функція тиску Чандрасекара `f(x)` дорівнює:

```
f(x) = x · (2 x² - 3) · √(1 + x²) + 3 · ln(x + √(1 + x²))
```

Розклад цієї функції в ряд Тейлора при `x ≪ 1` дає нерелятивістську границі `f(x) = (8/15) x⁵ - (4/105) x⁷ + ...`, а при `x ≫ 1` — ультрарелятивістську границі `f(x) = 2 x⁴ - 2 x² + ...`, що строго підтверджує перехід від `P ∝ ρ⁵/³` до `P ∝ ρ⁴/³`.

## 6. Великий термодинамічний потенціал та зв'язок із тиском

У термодинаміці системи з змінним числом частинок зручно користуватися великим термодинамічним потенціалом `Ω(T, V, μ) = F - μ N = - P V`.

При `T = 0 K` потенціал `Ω_0` для виродженого фермі-газу виражається точним інтегралом:

```
Ω_0 = - (2/3) · ∫₀^{E_F} E · g(E) dE = - (2/3) · U_0
```

Це співвідношення підтверджує, що для будь-якого нерелятивістського виродженого газу тиск становить строго `P = - Ω_0 / V = (2/3) U_0 / V`.

В ультрарелятивістському режимі аналогічне інтегрування дає:

```
Ω_{0,UR} = - (1/3) · U_{0,UR}
```

звідки випливає `P = (1/3) U_{0,UR} / V`.

## 7. Теплові поправки при низьких температурах (розклад Зоммерфельда)

При скінченній низькій температурі `0 < T ≪ T_F` функція розподілу Фермі — Дірака розмивається у вузькій смузі енергій товщиною `k_B T` біля поверхні Фермі:

```
f(E) = 1 / (exp((E - μ) / (k_B T)) + 1)
```

де `μ(T)` — хімічний потенціал газу.

За допомогою математичного розкладу Зоммерфельда для інтегралів виду `∫₀^{∞} H(E) f(E) dE`:

```
∫₀^{∞} H(E) f(E) dE ≈ ∫₀^{μ} H(E) dE + (π² / 6) (k_B T)² H'(μ)
```

знаходимо температурну поправку до хімічного потенціалу `μ(T)`:

```
μ(T) ≈ E_F · [ 1 - (π² / 12) · (k_B T / E_F)² ]
```

Хімічний потенціал зменшується зі зростанням температури, оскільки частина частинок переходить у стани з вищою енергією понад `E_F`.

Внутрішня енергія газу із урахуванням малих теплових збуджень дорівнює:

```
U(T) ≈ U_0 + (π² / 6) · g(E_F) · (k_B T)²
= U_0 · [ 1 + (5 π² / 12) · (k_B T / E_F)² ]
```

Звідси електронна теплоємність виродженого фермі-газу при постійному об'ємі `C_v = (∂U / ∂T)_v` дорівнює:

```
C_v = (π² / 2) · N k_B · (k_B T / E_F)
```

Оскільки `k_B T / E_F ≪ 1`, електронна теплоємність виродженого газу строго лінійно залежить від температури `C_v ∝ T` і становить лише малу частку від класичного значення `(3/2) N k_B`.

Парамагнітна сприйнятливість Паулі `χ_P` виродженого електронного газу обчислюється як поправка до енергії у зовнішньому магнітному полі `B`:

```
χ_P = μ_B² · g(E_F) = (3 N μ_B²) / (2 E_F)
```

де `μ_B = (e ℏ) / (2 m_e)` — магнетон Бора. Парамагнетизм Паулі практично не залежить від температури при `T ≪ T_F`, що слугує прямим експериментальним доказом виродження електронного газу у металах.
