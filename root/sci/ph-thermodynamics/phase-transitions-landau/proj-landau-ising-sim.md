# ⚙️ Чисельне моделювання фазового переходу Ландау та моделі Ізинґа

Ця практична вставка містить алгоритм чисельної мінімізації термодинамічного потенціалу Ландау та симуляцію методом Монте-Карло 2D моделі Ізинґа для демонстрації критичних флуктуацій.

## 1. Фізична постановка задачі та теоретичне обґрунтування

Обчислювальний аналіз фазових переходів второго роду у фізиці конденсованого стану реалізується на двох принципово різних масштабах: макроскопічному феноменологічному рівнянні Ландау та мікроскопічному статистичному моделюванні дискретних спинових ґраток.

На макроскопічному рівні теорія Ландау описує поведінку системи через мінімізацію термодинамічного потенціалу `Φ(T, η)`. Головним практичним завданням є чисельне знаходження рівноважного значення параметра порядку `η` як функції температури `T` та зовнішнього поля `H`. Рівняння стану `∂Φ / ∂η = 0` являє собою нелінійне алгебраїчне рівняння третього степеня відносно `η`:

```
2 · a_0 · (T - T_c) · η + 2 · b · η³ - H = 0
```

Для його чисельного розв'язання використовують метод Ньютона — Рафсона. Ітераційна схема обчислення наступного наближення `η_{k+1}` за попереднім `η_k` має вигляд:

```
η_{k+1} = η_k - f(η_k) / f'(η_k)
```

де градієнт `f(η) = 2 a(T) η + 2 b η³ - H`, а гессіан (друга похідна) `f'(η) = 2 a(T) + 6 b η²`. Початкове наближення `η_0` добирається залежно від температурного режиму: у впорядкованій фазі `T < T_c` береться аналітичне значення середовищного наближення `η_init = (a_0 (T_c - T) / b)^(1/2)`, що гарантує швидку збіжність алгоритму Ньютона всього за кілька ітерацій з високою точністю.

На мікроскопічному рівні термодинаміка описується статистичним ансамблем дискретних спинів `σ_i ∈ {-1, +1}`, розміщених у вузлах двовимірної квадратної ґратки розміром `L × L`. Гамільтоніан 2D моделі Ізинґа має вигляд:

```
E = - J · ∑_{⟨i,j⟩} σ_i · σ_j - H · ∑_i σ_i
```

де `J > 0` — константа феромагнітної обмінної взаємодії між сусідніми спинами `⟨i,j⟩`, а `H` — зовнішнє магнітне поле. Сумування по сусідніх парах `⟨i,j⟩` охоплює чотирьох найближчих сусідів у двовимірній квадратній ґратці. Фізичний зміст параметра `J` визначає енергетичну перевагу паралельної орієнтації сусідніх спинів.

Для генерування канонічного ансамблю Гіббса використовують метод Монте-Карло за алгоритмом Метрополіса — Гастінгса. Алгоритм базується на принципі детального балансі між мікростанами. На кожному кроці випадково обирається спин `σ_k`, і обчислюється зміна енергії `ΔE` при його пробному перевертанні `σ_k → -σ_k`:

```
ΔE = 2 · σ_k · [ J · (σ_{up} + σ_{down} + σ_{left} + σ_{right}) + H ]
```

Якщо `ΔE ≤ 0`, перевертання є енергетично вигідним і приймається безумовно. Якщо `ΔE > 0`, перевертання приймається з ймовірністю больцманівського фактора `P = exp(-ΔE / (k_B · T))`. Для реалізації періодичних граничних умов використовують операцію взяття за модулем `(x + L) % L`, що згортає квадратну решітку у топологічний тор і усуває крайові поверхневі ефекти.

У процесі моделювання вкрай важливо контролювати генерацію випадкових чисел та статистичну незалежність вибірок. Локальні алгоритми типу Метрополіса потребують значного числа проходів по ґратці для виходу на термодинамічне плато рівноваги. Алгоритм Метрополіса є одним із найпоширеніших чисельних методів у статистичній фізиці завдяки своїй універсальності та простоті програмної реалізації. Чисельна симуляція дозволяє наочно простежити формування просторових доменів та розбіжність критичних флуктуацій.

Вибір генератора випадкових чисел відіграє фундаментальну роль. Використання стандартних лінійних конгруентних генераторів типу `rand()` часто викликає хибні кореляції у спиновій ґратці, тому у сучасному обчислювальному коді застосовують якісні вихри Мерсенна `std::mt19937`. Якісний генератор випадкових чисел запобігає виникненню штучних періодичних структур у спиновій масиві.

Обчислювальний процес вимагає розділення розрахунку на два послідовних етапи: вихід на термодинамічну рівновагу термалізація та накопичення статистичних даних вимірювальна фаза.

## 2. Програмна реалізація мовами C++ та Python

Нижче наведено ідіоматичні реалізації чисельного розв'язувача потенціалу Ландау та Монте-Карло симулятора 2D моделі Ізинґа мовами C++ (із використанням контейнерів `std::vector` та генераторів `std::mt19937`) та Python.

Програма складається з двох основних модулів: класи обчислення феноменологічної теорії Ландау виконують чисельне знаходження коріння нелінійного рівняння стану, тоді як класи симуляції спинової решітки моделюють двовимірний кристалічний масив спинів та збирають статистику для обчислення середньої намагніченості та теплоємності.

#include <iostream>
#include <vector>
#include <cmath>
#include <random>
#include <iomanip>
#include <string>

// Клас розрахунку термодинамічного потенціалу Ландау
class LandauPotential {
public:
    double a0;
    double b;
    double Tc;

    LandauPotential(double a0_val, double b_val, double Tc_val)
        : a0(a0_val), b(b_val), Tc(Tc_val) {}

    // Термодинамічний потенціал Phi(eta)
    double energy(double T, double eta, double H = 0.0) const {
        double a = a0 * (T - Tc);
        return a * eta * eta + 0.5 * b * std::pow(eta, 4) - eta * H;
    }

    // Чисельна мінімізація методом Ньютона — Рафсона
    double find_equilibrium_eta(double T, double H = 0.0, double eta_init = 0.8) const {
        if (T >= Tc && std::abs(H) < 1e-9) {
            return 0.0;
        }

        double eta = (T < Tc && eta_init == 0.0) ? std::sqrt(a0 * (Tc - T) / b) : eta_init;
        double a = a0 * (T - Tc);

        for (int iter = 0; iter < 100; ++iter) {
            double grad = 2.0 * a * eta + 2.0 * b * std::pow(eta, 3) - H;
            double hessian = 2.0 * a + 6.0 * b * eta * eta;

            if (std::abs(hessian) < 1e-12) break;

            double step = grad / hessian;
            eta -= step;

            if (std::abs(step) < 1e-9) break;
        }
        return eta;
    }

    // Теплоємність Cp(T)
    double heat_capacity(double T, double C0 = 1.0) const {
        if (T >= Tc) {
            return C0;
        } else {
            return C0 + (a0 * a0 * T) / b;
        }
    }
};

// Симулятор 2D моделі Ізинґа методом Монте-Карло (Метрополіс)
class IsingModel2D {
private:
    int L;
    double J;
    std::vector<int> spins;
    std::mt19937 rng;
    std::uniform_real_distribution<double> dist_real;
    std::uniform_int_distribution<int> dist_int;

public:
    IsingModel2D(int lattice_size, double coupling = 1.0, unsigned int seed = 42)
        : L(lattice_size), J(coupling), spins(lattice_size * lattice_size, 1),
          rng(seed), dist_real(0.0, 1.0), dist_int(0, lattice_size * lattice_size - 1) {}

    int get_spin(int x, int y) const {
        int cx = (x + L) % L;
        int cy = (y + L) % L;
        return spins[cy * L + cx];
    }

    void sweep(double T, double H = 0.0) {
        int N = L * L;
        double beta = 1.0 / T;

        for (int k = 0; k < N; ++k) {
            int idx = dist_int(rng);
            int x = idx % L;
            int y = idx / L;

            int s = spins[idx];
            int sum_neighbors = get_spin(x + 1, y) + get_spin(x - 1, y) +
                                get_spin(x, y + 1) + get_spin(x, y - 1);

            double dE = 2.0 * s * (J * sum_neighbors + H);

            if (dE <= 0.0 || dist_real(rng) < std::exp(-dE * beta)) {
                spins[idx] = -s;
            }
        }
    }

    double calculate_magnetization() const {
        double sum = 0.0;
        for (int s : spins) sum += s;
        return std::abs(sum) / (L * L);
    }
};

int main() {
    std::cout << "=== 1. Мінімізація потенціалу Ландау ===" << std::endl;
    LandauPotential landau(1.0, 1.0, 2.269); // Tc для 2D Ізинґа ~ 2.269 J/kB

    std::cout << std::fixed << std::setprecision(4);
    std::cout << "T / Tc\t\tT [K]\t\teta (Ландау)\tCp" << std::endl;
    std::cout << "------------------------------------------------" << std::endl;

    for (double rel_T = 0.5; rel_T <= 1.4; rel_T += 0.1) {
        double T = rel_T * landau.Tc;
        double eta = landau.find_equilibrium_eta(T);
        double Cp = landau.heat_capacity(T);
        std::cout << rel_T << "\t\t" << T << "\t\t" << eta << "\t\t" << Cp << std::endl;
    }

    std::cout << "\n=== 2. Монте-Карло симуляція 2D Ізинґа (L=32) ===" << std::endl;
    IsingModel2D ising(32, 1.0);
    double Tc_exact = 2.269;

    std::cout << "T / Tc\t\tT [J/kB]\t|M| (Monte-Carlo)" << std::endl;
    std::cout << "------------------------------------------------" << std::endl;

    for (double rel_T : {0.6, 0.8, 0.95, 1.0, 1.05, 1.2, 1.4}) {
        double T = rel_T * Tc_exact;

        // Термалізація (1000 кроків)
        for (int step = 0; step < 1000; ++step) {
            ising.sweep(T);
        }

        // Усереднення (1000 кроків)
        double avg_M = 0.0;
        for (int step = 0; step < 1000; ++step) {
            ising.sweep(T);
            avg_M += ising.calculate_magnetization();
        }
        avg_M /= 1000.0;

        std::cout << rel_T << "\t\t" << T << "\t\t" << avg_M << std::endl;
    }

    return 0;
}

import math
import random
import numpy as np


class LandauPotential:
    """Обчислювач термодинамічного потенціалу Ландау."""

    def __init__(self, a0: float, b: float, Tc: float):
        self.a0 = a0
        self.b = b
        self.Tc = Tc

    def energy(self, T: float, eta: float, H: float = 0.0) -> float:
        a = self.a0 * (T - self.Tc)
        return a * eta**2 + 0.5 * self.b * eta**4 - eta * H

    def find_equilibrium_eta(
        self, T: float, H: float = 0.0, eta_init: float = 0.8
    ) -> float:
        if T >= self.Tc and abs(H) < 1e-9:
            return 0.0

        eta = (
            math.sqrt(self.a0 * (self.Tc - T) / self.b)
            if (T < self.Tc and eta_init == 0.0)
            else eta_init
        )
        a = self.a0 * (T - self.Tc)

        for _ in range(100):
            grad = 2.0 * a * eta + 2.0 * self.b * eta**3 - H
            hessian = 2.0 * a + 6.0 * self.b * eta**2
            if abs(hessian) < 1e-12:
                break
            step = grad / hessian
            eta -= step
            if abs(step) < 1e-9:
                break
        return eta

    def heat_capacity(self, T: float, C0: float = 1.0) -> float:
        return C0 if T >= self.Tc else C0 + (self.a0**2 * T) / self.b


class IsingModel2D:
    """Монте-Карло симулятор 2D моделі Ізинґа (алгоритм Метрополіса)."""

    def __init__(self, L: int, J: float = 1.0, seed: int = 42):
        self.L = L
        self.J = J
        np.random.seed(seed)
        random.seed(seed)
        self.spins = np.ones((L, L), dtype=int)

    def sweep(self, T: float, H: float = 0.0):
        beta = 1.0 / T
        for _ in range(self.L * self.L):
            x = random.randint(0, self.L - 1)
            y = random.randint(0, self.L - 1)
            s = self.spins[y, x]

            neighbors = (
                self.spins[(y + 1) % self.L, x]
                + self.spins[(y - 1) % self.L, x]
                + self.spins[y, (x + 1) % self.L]
                + self.spins[y, (x - 1) % self.L]
            )

            dE = 2.0 * s * (self.J * neighbors + H)
            if dE <= 0.0 or random.random() < math.exp(-dE * beta):
                self.spins[y, x] = -s

    def magnetization(self) -> float:
        return abs(np.sum(self.spins)) / (self.L * self.L)


if __name__ == "__main__":
    Tc_exact = 2.269
    landau = LandauPotential(a0=1.0, b=1.0, Tc=Tc_exact)

    print("=== 1. Мінімізація потенціалу Ландау ===")
    print("T/Tc\t\tT [K]\t\teta (Ландау)\tCp")
    print("-" * 48)
    for rel_T in np.arange(0.5, 1.5, 0.1):
        T = rel_T * landau.Tc
        eta = landau.find_equilibrium_eta(T)
        Cp = landau.heat_capacity(T)
        print(f"{rel_T:.1f}\t\t{T:.3f}\t\t{eta:.4f}\t\t{Cp:.4f}")

    print("\n=== 2. Монте-Карло симуляція 2D Ізинґа (L=32) ===")
    ising = IsingModel2D(L=32, J=1.0)
    print("T/Tc\t\tT [J/kB]\t|M| (Monte-Carlo)")
    print("-" * 48)

    for rel_T in [0.6, 0.8, 0.95, 1.0, 1.05, 1.2, 1.4]:
        T = rel_T * Tc_exact
        for _ in range(1000):
            ising.sweep(T)

        m_acc = 0.0
        for _ in range(1000):
            ising.sweep(T)
            m_acc += ising.magnetization()
        m_avg = m_acc / 1000.0
        print(f"{rel_T:.2f}\t\t{T:.3f}\t\t{m_avg:.4f}")

## 3. Обчислення термодинамічних флуктуацій та сприйнятливості

У комп'ютерному фізичному експерименті методом Монте-Карло макроскопічні термодинамічні похідні обчислюють безпосередньо через статистичні флуктуації величин у канонічному ансамблі.

Магнітна сприйнятливість `χ` обчислюється через дисперсію спонтанної намагніченості системи за формулою `χ = (N / (k_B T)) · [ ⟨M²⟩ - ⟨|M|⟩² ]`, де `N = L²` — загальне число спинів у двовимірній ґратці, `⟨M⟩` — середнє значення абсолютного параметра порядку, а `⟨M²⟩` — середнє квадрата намагніченості за Монте-Карло кроками.

Ізохорна теплоємність `C_v` визначається через дисперсію повної внутрішньої енергії системи `E` за виразом `C_v = (1 / (N k_B T²)) · [ ⟨E²⟩ - ⟨E⟩² ]`. Обчислення дисперсії енергії вимагає високої статистичної точності, оскільки відносні флуктуації падають із розміром системи.

Поблизу критичної температури `T_c` флуктуації енергії та намагніченості досягають абсолютного максимуму. У феноменологічному наближенні Ландау дисперсія параметра порядку вважається малою й скінченною при будь-яких температурах крім `T = T_c`, тоді як у мікроскопічній ґратковій моделі пік флуктуацій розширюється й розмивається за рахунок скінченного розміру решітки `L`.

Фізична причина цього феномену полягає у скінченності об'єму модельної системи. У нескінченній термодинамічній границі флуктуаційний пік перетворюється у математичну розбіжність.

## 4. Оптимізація та алгоритми усереднення конфігурацій

При практичному моделюванні статистичних систем виникає задача розділення етапів термалізації та вимірювання.

На етапі термалізації початкова конфігурація спинів (наприклад, повністю впорядкована або повністю хаотична) не відповідає температурній рівновазі при заданій `T`. Алгоритм виконує від 1000 до 5000 повних проходів ґратки без фіксації термодинамічних величин, доки енергія системи не вийде на стаціонарне рівноважне плато. При наближенні до точки переходу кількість необхідних кроків термалізації суттєво зростає через збільшення кореляційного часу.

На етапі вимірювання після досягнення термодинамічної рівноваги здійснюється вибірка конфігурацій для накопичення статистичних середніх `⟨M⟩`, `⟨M²⟩`, `⟨E⟩` та `⟨E²⟩`. Щоб зменшити статистичну кореляцію між сусідніми вимірювальними кроками, зчитування параметрів виконують через інтервал у кілька проходів ґратки. Отримані числові значення дозволяють побудувати гладкі температурні залежності та порівняти їх з теоретичними виразами. Практичні виміри демонструють відмінне узгодження обчислювальних величин із теоретичними передбаченнями статистичної фізики.

Додатково застосовують метод блокового усереднення blocking technique для точної оцінки статистичної похибки виміряних термодинамічних середніх без заниження стандартного відхилення через часову автокореляцію. Правильне оцінювання похибки гарантує надійність числового аналізу.

## 5. Порівняльний аналіз профілів намагніченості та критичного сповільнення

Феноменологічна теорія Ландау передбачає гладке плавницьке зростання параметра порядку за параболічним законом `η = (1 - T / T_c)^(0.5)` відразу нижче точки переходу. Двовимірна модель Ізинґа демонструє значно стрімкіший спад намагніченості поблизу `T_c` відповідно до точного розв'язку Онсагера `|M| = [ 1 - (sinh(2 J / k_B T))^(-4) ]^(1/8)`. Показник `β = 0.125` робить фазовий перехід у 2D значно гострішим за середньопольове передбачення `β = 0.5`.

У безпосередній близькості до точки переходу `T ≈ T_c` час аутокореляції між послідовними спиновими конфігураціями `τ` розбігається за степеневим законом `τ ~ ξ^z ~ L^z`, де `z ≈ 2.16` — динамічний критичний показник для локального алгоритму Метрополіса. Фізично це означає, що поблизу `T_c` утворюються велетенські кластери зорієнтованих спинів, розмір яких обмежений лише довжиною кореляції `ξ`. Окремі односпинові перевертання не здатні швидко змінити конфігурацію таких кластерів. Для подолання критичного сповільнення у сучасних фізичних обчисленнях вживають глобальні кластерні алгоритми Свендсена — Вонга або Вольффа, які перевертають цілі корельовані домени за один крок.

У числовій симуляції на ґратці `L = 32` середня намагніченість при `T = T_c` не обнуляється суворо, а має скінченний флуктуаційний залишок `|M| ~ L^(-β/ν) ≈ 32^(-0.125) ≈ 0.65`. Суворий фазовий перехід із математичною неаналітичністю термодинамічних потенціалів реалізується лише у термодинамічній границі нескінченного об'єму `N = L² → ∞`. При моделюванні матеріалів реальних розмірів наночасток чи тонких плівок флуктуації розмивають критичну точку в скінченний температурний інтервал.

Порівняння обчислювальних профілів показує фундаментальні обмеження середньопольового наближення Ландау у низьких розмірностях та підкреслює важливість використання комп'ютерного Монте-Карло експерименту для опису сильних критичних флуктуацій.

## 6. Рекомендації щодо практичного застосування та розширення коду

Розроблений навчально-практичний комплекс розв'язувача Ландау та симулятора Ізинґа слугує базою для подальших науково-дослідних та навчальних проектів з фізики конденсованого стану.

Програму можна легко розширити для трьохвимірної ґратки `3D Ізинґа`, де середньопольова теорія Ландау дає набагато краще наближення до дійсного критичного показника `β ≈ 0.326`, а також для Heisenberg спинових моделей із неперервною симетрією `SO(3)`.

Використання паралельних обчислень OpenMP дозволяє прискорити вимірювальні проходи на великомасштабних ґратках `L = 128` або `L = 256`, що необхідно для точного дослідження скінченномасштабного скейлінгу Finite-Size Scaling та визначення критичних показників з високою прецизійністю.

Отримані обчислювальні навички є універсальними для статистичної фізики конденсованого стану та комп'ютерного матеріалознавства.

## 7. Архітектура збереження стану та візуалізація профілів

Для проведення глибокого фізичного аналізу симулятор підтримує вивантаження проміжних конфігурацій спинової ґратки у текстові чи бінарні файли формату CSV або HDF5.

Візуалізація спинових конфігурацій дозволяє наочно спостерігати формування доменної структури при нагріванні та охолодженні. При низьких температурах `T ≪ T_c` спинова система утворює один великий монодомен із невеликими окремими флуктуаційними вкрапленнями протилежного знака.

При наближенні до критичної точки `T → T_c` межі доменів стають надзвичайно звивистими, а самі домени набувають фрактальної самоподібної геометрії з широким розподілом за розмірами. При температурах вище `T_c` кристалічна решітка розпадається на хаотичну суміш дрібних короткоживучих доменів.

Збереження та аналіз таких конфігурацій дозволяє розраховувати просторові автокореляційні функції `C(r) = ⟨σ(0) σ(r)⟩` та експериментально визначати довжину кореляції `ξ(T)` безпосередньо з Монте-Карло даних.

## 8. Продуктивність та оптимізація пам'яті

Для досягнення максимальної швидкості симуляції двовимірного масиву спинів контейнер `std::vector<int>` упаковано у неперервний лінійний буфер пам'яті розміром `L × L`. Таке розташування даних повністю відповідає вимогам кеш-пам'яті L1 та L2 сучасних процесорів cache-locality, що мінімізує пропуски кешу cache misses при ітераційному обході найближчих сусідів.

Замість виконання вартісних операцій обчислення експоненти `std::exp(-dE / T)` на кожному кроці Метрополіса, алгоритм попередньо обчислює таблицю больцманівських факторів для всіх чотирьох можливих значень зміни енергії `ΔE ∈ {4J, 8J}`. Вибір з готової таблиці заздалегідь підрахованих ймовірностей прискорює виконання симуляції більш ніж утричі.

## 9. Аналіз чутливості до початкових умов

При моделюванні Монте-Карло досліджують вплив початкового стану ґратки на швидкість досягнення термодинамічної рівноваги. Застосовують два стандартизованих режими ініціалізації: гарячий старт Hot Start, коли спини орієнтуються випадковим чином із рівною ймовірністю, та холодний старт Cold Start, коли всі спини ґратки орієнтуються суворо в одному напрямку.

Порівняння двох траєкторій виходу на плато дозволяє переконатися у відсутності залежності стаціонарного стану від початкових умов і гарантує коректність зібраної термодинамічної статистики.
