# 🧮 Математичний вивід термодинамічного потенціалу Ландау та критичних показників

Ця математична вставка містить строгий аналітичний вивід температурної залежності параметра порядку, термодинамічних сприйнятливостей, стрибка теплоємності та розбіжності довжини кореляцій у наближенні середовищного поля Ландау.

## 1. Симетрійні обмеження та розклад Тейлора

Розглянемо макроскопічну термодинамічну систему поблизу точки фазового переходу другого роду з критичною температурою `T_c`. Нехай стан системи описується однокомпонентним скалярним параметром порядку `η`.

У термодинамічно рівноважному стані при фіксованій температурі `T`, тиску `P` та зовнішньому збурювальному полі `H` термодинамічний потенціал системи `Φ(T, P, η)` досягає свого абсолютного мінімуму. Поблизу критичної точки параметр порядку є малим величиною (`|η| ≪ 1`), що дозволяє розкласти потенціал `Φ` у степеневий ряд Тейлора за степенями `η`:

```
Φ(T, η) = Φ_0(T) + a_1 · η + a_2 · η² + a_3 · η³ + a_4 · η⁴ + a_5 · η⁵ + a_6 · η⁶ - η · H
```

Вимоги фундаментальної симетрії та термодинамічної стійкості накладають суворі обмеження на коефіцієнти цього розкладу:

1. **Симетрія відносно інверсії (Z_2 симетрія):** якщо у відсутності зовнішнього поля (`H = 0`) вища (симетрична) фаза є інваріантною відносно зміни знака параметра порядку `η ↔ -η` (наприклад, перевертання усіх спинів у феромагнетику), потенціал `Φ(η)` мусить бути парною функцією. Це означає, що всі коефіцієнти при непарних степенях дорівнюють нулю:

```
a_1 = 0,   a_3 = 0,   a_5 = 0
```

2. **Стандартна перепозначена форма (при H = 0):**

```
Φ(T, η) = Φ_0(T) + a(T) · η² + (1/2) · b(T) · η⁴ + (1/3) · c(T) · η⁶
```

де для зручності подальшого диференціювання введені множники `1/2` та `1/3` при старших степенях.

3. **Термодинамічна стійкість при великих η:** щоб потенціал `Φ(η)` не прямував до `-∞` при `|η| → ∞`, коефіцієнт при найвищому степені розкладу мусить бути суворо додатним. Якщо розклад обмежується четвертим степенем (`c = 0`), потрібна умова `b(T) > 0`.

## 2. Температурна залежність коефіцієнтів та рівняння стану

Дослідимо умови мінімуму потенціалу `Φ(η)` у відсутності зовнішнього поля (`H = 0`):

```
∂Φ / ∂η = 2 · a(T) · η + 2 · b(T) · η³ = 0
```

Винесемо `2 · η` за дужки:

```
2 · η · [ a(T) + b(T) · η² ] = 0
```

Це рівняння має дві принципово різні групи розв'язків:
1. Тривіальний розв'язок: `η = 0` (симетрична фаза).
2. Нетривіальний розв'язок: `η² = - a(T) / b(T)` (впорядкована фаза).

Щоб нетривіальний розв'язок реалізувався лише при `T < T_c` і був відсутній при `T > T_c`, коефіцієнт `a(T)` мусить змінювати знак у точці `T = T_c`. Розкладаючи `a(T)` у ряд Тейлора поблизу `T_c` і обмежуючись першим лінійним членом, маємо:

```
a(T) = a_0 · (T - T_c)      [де a_0 > 0 — стала величина]
```

Коефіцієнт `b(T)` поблизу `T_c` вважаємо слабко залежним від температури і приймаємо за сталу додатну величину `b(T) ≈ b > 0`.

Проаналізуємо другу похідну потенціалу `∂²Φ / ∂η²` для перевірки стійкості розв'язків:

```
∂²Φ / ∂η² = 2 · a(T) + 6 · b · η²
```

1. **Режим T > T_c (a(T) > 0):**
   - Для `η = 0`: `∂²Φ / ∂η² = 2 a(T) > 0` ⇒ одиничний глобальний мінімум при `η_0 = 0`.
   - Розв'язок `η² = -a/b < 0` є уявним і не має фізичного змісту.

2. **Режим T = T_c (a(T) = 0):**
   - Потенціал набуває вигляду `Φ(η) = Φ_0 + (1/2) b η⁴`.
   - Точка `η = 0` є надзвичайно пласким мінімумом (`∂²Φ / ∂η² = 0`, `∂⁴Φ / ∂η⁴ = 12 b > 0`).

3. **Режим T < T_c (a(T) < 0):**
   - Для `η = 0`: `∂²Φ / ∂η² = 2 a(T) < 0` ⇒ точка `η = 0` стає неустійким максимумом (енергетичним бар'єром).
   - Для двох нетривіальних розв'язків `η_0 = ± (a_0 · (T_c - T) / b)^(1/2)`:

```
∂²Φ / ∂η² = 2 · a_0 · (T - T_c) + 6 · b · [ a_0 · (T_c - T) / b ]
          = -2 · a_0 · (T_c - T) + 6 · a_0 · (T_c - T)
          = 4 · a_0 · (T_c - T) > 0
```

Отже, при `T < T_c` стан з `η = 0` втрачає стійкість, і система спонтанно переходить в один із двох еквівалентних мінімумів `+η_0` або `-η_0`.

Звідси отримуємо температурну залежність параметра порядку та критичний показник `β`:

```
η_0(T) = 0                                при T ≥ T_c
η_0(T) = (a_0 / b)^(1/2) · (T_c - T)^(1/2) при T < T_c   ⇒  β = 1/2
```

## 3. Обчислення ентропії та стрибка теплоємності

Знайдемо термодинамічний потенціал рівноважного стану `Φ_eq(T)` шляхом підстановки рівноважного значення `η_0(T)` у вираз для `Φ(T, η)`:

```
При T ≥ T_c:
Φ_eq(T) = Φ_0(T)

При T < T_c:
Φ_eq(T) = Φ_0(T) + a_0 · (T - T_c) · [ a_0 · (T_c - T) / b ] + (1/2) · b · [ a_0 · (T_c - T) / b ]²
        = Φ_0(T) - (a_0² / b) · (T_c - T)² + (1/2) · (a_0² / b) · (T_c - T)²
        = Φ_0(T) - a_0² · (T_c - T)² / (2 · b)
```

Ентропія системи `S(T)` знаходиться як перша від'ємна похідна потенціалу за температурою `S = - ∂Φ_eq / ∂T`:

```
При T > T_c:
S_+(T) = - ∂Φ_0 / ∂T = S_0(T)

При T < T_c:
S_-(T) = - ∂ / ∂T [ Φ_0(T) - a_0² · (T_c - T)² / (2 · b) ]
       = S_0(T) - a_0² · (T_c - T) / b
```

У самій точці переходу `T = T_c` ентропія є неперервною функцією: `S_+(T_c) = S_-(T_c) = S_0(T_c)`. Це підтверджує відсутність прихованої теплоти плавлення (`L = T_c · ΔS = 0`).

Знайдемо ізобарну теплоємність `C_p = T · (∂S / ∂T)` вище та нижче точки переходу:

```
При T > T_c:
C_{p+}(T) = T · ∂S_0 / ∂T = C_{p0}(T)

При T < T_c:
C_{p-}(T) = T · [ ∂S_0 / ∂T + a_0² / b ] = C_{p0}(T) + a_0² · T / b
```

Обчислимо стрибок теплоємності `ΔC_p` у критичній точці `T = T_c`:

```
ΔC_p = C_{p-}(T_c) - C_{p+}(T_c)
     = [ C_{p0}(T_c) + a_0² · T_c / b ] - C_{p0}(T_c)
     = a_0² · T_c / b
```

Стрибок теплоємності `ΔC_p > 0` є суворо додатним і скінченним. Оскільки теплоємність зазнає розриву першого роду (стрибка), критичний показник теплоємності у теорії Ландау дорівнює нулю: `α = 0`.

## 4. Оборотна сприйнятливість та «закон двійки» Ландау

У присутності слабкого зовнішнього поля `H` рівняння стану здобуває вигляд:

```
∂Φ / ∂η = 2 · a(T) · η + 2 · b · η³ - H = 0
```

Визначимо оборотну термодинамічну сприйнятливість `χ` як похідну параметра порядку за зовнішнім полем у границі `H → 0`:

```
χ = (∂η / ∂H)_{H → 0}
```

Продиференціюємо рівняння стану за `H`:

```
2 · a(T) · (∂η / ∂H) + 6 · b · η² · (∂η / ∂H) - 1 = 0
⇒ (∂η / ∂H) · [ 2 · a(T) + 6 · b · η² ] = 1
⇒ χ = 1 / [ 2 · a(T) + 6 · b · η² ]
```

Підставимо рівноважні значення `η_0` для обох температурних областей:

1. **Вище точки переходу (T > T_c, η_0 = 0):**

```
χ_+(T) = 1 / [ 2 · a_0 · (T - T_c) ] = C_W / (T - T_c)
```

Це вираз закону Кюрі — Вейсса з константою Кюрі `C_W = 1 / (2 a_0)`. Сприйнятливість розбігається при `T → T_c^+` за степеневим законом `χ ~ (T - T_c)^(-γ)` з критичним показником `γ = 1`.

2. **Нижче точки переходу (T < T_c, η_0² = a_0 (T_c - T) / b):**

```
χ_-(T) = 1 / [ 2 · a_0 · (T - T_c) + 6 · b · (a_0 · (T_c - T) / b) ]
       = 1 / [ -2 · a_0 · (T_c - T) + 6 · a_0 · (T_c - T) ]
       = 1 / [ 4 · a_0 · (T_c - T) ]
```

Порівняємо коефіцієнти перед температурною різницею у знаменниках `χ_+` та `χ_-` при однакових відстанях від критичної точки `|T - T_c|`:

```
χ_-(T_c - ΔT) / χ_+(T_c + ΔT) = [ 1 / (4 a_0 ΔT) ] / [ 1 / (2 a_0 ΔT) ] = 1 / 2
```

Цей фундаментальний результат називається **«законом двійки» Ландау**: при однаковій температурній відстані від критичної точки сприйнятливість у впорядкованій фазі є вдвічі меншою, ніж у симетричній фазі (`χ_+ = 2 · χ_-`).

На критичній ізотермі (`T = T_c`, `a = 0`) рівняння стану набуває вигляду:

```
2 · b · η³ = H   ⇒   η ~ H^(1/3)   ⇒   δ = 3
```

де `δ = 3` — критичний показник ізотерми.

## 5. Градієнтний член та довжина кореляції Ґінзбурга — Ландау

Якщо параметр порядку не є просторово однорідним (`η = η(r)`), у термодинамічному потенціалі виникає додаткова енергетична ціна просторових неоднорідностей (неоднорідний обмінний взаємозв'язок). З міркувань ізотропії найнижчим інваріантним членом за просторовими похідними є квадрат градієнта `(∇η)²`.

Повний функціонал вільної енергії Ґінзбурга — Ландау має вигляд:

```
F[η] = ∫ d³r [ f_0 + a_0 · (T - T_c) · η²(r) + (1/2) · b · η⁴(r) + g · (∇η(r))² - η(r) · H(r) ]
```

де `g > 0` — коефіцієнт просторового жорсткості.

Мінімізація функціоналу `F[η]` за варіаційним принципом `δF / δη(r) = 0` приводить до диференціального рівняння Ейлера — Лагранжа:

```
- 2 · g · ∇²η + 2 · a(T) · η + 2 · b · η³ = H(r)
```

Розглянемо малі флуктуації `δη(r)` навколо однорідного рівноважного стану `η_0` під дією точкового зовнішнього збурення `H(r) = H_0 · δ(r)`:

```
- g · ∇²(δη) + [ a(T) + 3 · b · η_0² ] · δη = (1/2) · H_0 · δ(r)
```

Ввівши позначення `A_{eff} = a(T) + 3 b η_0²` (де `A_{eff} = a_0 (T - T_c)` при `T > T_c` та `A_{eff} = 2 a_0 (T_c - T)` при `T < T_c`), перепишемо рівняння у стандартній формі рівняння Орнштейна — Церніке:

```
[ - ∇² + 1 / ξ² ] δη(r) = (H_0 / (2 g)) · δ(r)
```

де `ξ(T)` — **довжина кореляції** (англ. *correlation length*):

```
ξ(T) = ( g / A_{eff} )^(1/2)
```

Звідси отримуємо температурну залежність довжини кореляції вище та нижче точки переходу:

```
При T > T_c:   ξ_+(T) = ( g / (a_0 · (T - T_c)) )^(1/2) ~ (T - T_c)^(-1/2)
При T < T_c:   ξ_-(T) = ( g / (2 a_0 · (T_c - T)) )^(1/2) ~ (T_c - T)^(-1/2)
```

Розв'язок рівняння для кореляційної функції у тривимірному просторі `d = 3` задається потенціалом Юкави:

```
G(r) = ⟨δη(0) δη(r)⟩ = (k_B · T / (8 π · g)) · exp(-r / ξ) / r
```

При наближенні до критичної точки `T → T_c` довжина кореляції розбігається до нескінченності (`ξ(T) → ∞`), а критичний показник кореляційної довжини дорівнює `ν = 1/2`.

## 6. Підсумкова таблиця критичних показників середовищного поля

Зведемо обчислені теоретичні показники наближення Ландау у порівняльну таблицю з точними значеннями для двовимірної та тривимірної моделей Ізинґа:

| Фізична величина | Показник | Визначення | Теорія Ландау (d ≥ 4) | 2D Ізинґ (точний) | 3D Ізинґ (чисельний) |
| :--- | :---: | :--- | :---: | :---: | :---: |
| **Теплоємність** | `α` | `C_p ~ \|T - T_c\|^(-α)` | `0` (стрибок) | `0` (логарифм) | `0.110` |
| **Параметр порядку** | `β` | `η ~ (T_c - T)^β` | `1/2 = 0.5` | `1/8 = 0.125` | `0.326` |
| **Сприйнятливість** | `γ` | `χ ~ \|T - T_c\|^(-γ)` | `1` | `7/4 = 1.75` | `1.237` |
| **Критична ізотерма** | `δ` | `η ~ H^(1/δ)` при `T = T_c` | `3` | `15` | `4.789` |
| **Довжина кореляції** | `ν` | `ξ ~ \|T - T_c\|^(-ν)` | `1/2 = 0.5` | `1` | `0.630` |
| **Кореляційний спад** | `η_{corr}` | `G(r) ~ 1 / r^(d - 2 + η_{corr})` | `0` | `1/4 = 0.25` | `0.036` |

Ця таблиця показує, що середовищна теорія Ландау дає точний розв'язок для вимірностей `d ≥ 4` (де верхня критична вимірність `d_c = 4`), тоді як для `d = 3` флуктуації вносять помітні поправки у критичні показники.
