# 📋 Довідник термінів, констант та інтерфейсу термодинаміки інформації

Термодинаміка інформації об'єднує фундаментальні величини класичної статистичної механіки (температуру, термодинамічну ентропію, вільну енергію Гельмгольца, виділене тепло) та поняття теорії інформації (біти, нати, умовну ентропію, взаємну інформацію Шеннона та відносну ентропію Кульбака-Лейблера). У цьому довіднику наведено розширений опис фізичних та інформаційних констант, зведені таблиці енергетичних меж Ландауера для різних температурних режимів, математичні формули співвідношення одиниць вимірювання та специфікований програмний інтерфейс для моделювання інформаційних двигунів.

---

### 1. Фізико-інформаційні константи та коефіцієнти перетворення

У статистичній фізиці й теорії інформації використовують різні системи одиниць вимірювання. Фізична ентропія вимірюється в джоулях на кельвін або електронвольтах на кельвін, тоді як інформаційна ентропія Шеннона вимірюється в безрозмірних одиницях — двійкових бітах або натуральних натах.

#### Стала Больцмана
Стала Больцмана слугує містком між мікроскопічною енергією хаотичного руху частинок та макроскопічною температурою. У термодинаміці інформації вона визначає масштаб енергії, що припадає на один нат невизначеності. Вона зв'язує мікроскопічний фазовий простір із термодинамічними потенціалами. Коли демон вимірює стан мікроскопічної системи, кожна отримана одиниця інформації дозволяє змістити термодинамічну рівновагу на макроскопічному рівні саме в масштабі цієї константи.

Стала Больцмана визначає середню теплову енергію однієї ступені вільності частинки. Її значення зафіксоване в міжнародній системі одиниць SI як точне число.

#### Натуральний логарифм двійки
Число натурального логарифма двійки є перевідним коефіцієнтом між двійковою системою числення (логарифми за основою два) та природною системою неперервного аналізу (натуральні логарифми). Оскільки один біт дорівнює натуральному логарифму двійки натів, термодинамічний еквівалент одного біта невизначеності дорівнює добутку сталої Больцмана на логарифм двійки.

Цей коефіцієнт зринає щоразу, коли ми переводимо інформацію, виражену в двійкових регістрах комп'ютера чи квантового кубіта, у термодинамічні величини виділеного тепла або виконаної роботи.

#### Заряд електрона та електронвольт
Оскільки енергії мікроскопічних частинок у джоулях виражаються вкрай малими числами, у фізиці наноструктур та інформаційної термодинаміки зручно використовувати електронвольти. Співвідношення між тепловою енергією та зарядом електрона визначає тепловий потенціал, який за кімнатної температури триста кельвінів становить близько двадцяти шести міллівольт. 

Тепловий потенціал визначає амплітуду теплових напругових флуктуацій у напівпровідникових каналах і визначає мінімальний потенціальний бар'єр, необхідний для надійного збереження одного біта пам'яті в умовах теплового шуму.

### 2. Енергетичні межі Ландауера для різних температурних режимів

Фундаментальний принцип Ландауера встановлює, що логічно незворотна операція стирання одного біта інформації за температури середовища T вимагає виділення в це середовище тепла, не меншого за межу Ландауера, яка дорівнює добутку сталої Больцмана, температури та натурального логарифма двійки.

Ця межа лінійно залежить від абсолютної температури. У нанофізичних експериментах та інженерних розрахунках використовують різні температурні діапазони:

#### Кріогенний режим надпровідності та розчинення
При наднизьких температурах у кріостатах розчинення гелію теплові флуктуації стають мізерними, а межа Ландауера знижується до часток мікроелектронвольта. При температурі рідкого гелію при атмосферному тиску чотири цілих дві десятих кельвіна, де працюють надпровідні квантові процесори на джозефсонівських переходах, стирання біта коштує чверть мілліелектронвольта. Завдяки настільки низьким значенням розсіювання тепла, кріогенні обчислювальні системи здатні виконувати велетенську кількість логічних операцій без перегріву елементів.

#### Азотний та біологічний режими
У середовищі рідкого азоту при сімдесяти семи кельвінах межа Ландауера становить близько чотирьох мілліелектронвольт. У біологічних клітинах та молекулярних моторах (наприклад, ферментах АТФ-синтази чи РНК-полімерази), що функціонують за температури людського тіла триста десять кельвінів, термодинамічна ціна стирання одного молекулярного біта становить вісімнадцять з половиною мілліелектронвольт. Молекулярна біологія використовує цей поріг як нижню енергетичну межу для забезпечення точності зчитування та трансляції генетичного коду в умовах інтенсивного броунівського шуму.

#### Напівпровідникові мікропроцесори та високотемпературні середовища
Сучасні напівпровідникові кристали високої інтеграції працюють при робочих температурах кристала близько вісімдесяти п'яти градусів Цельсія. На цьому рівні мінімальна термодинамічна плата за стирання одного біта в регістрі пам'яті дорівнює понад двадцять один мілліелектронвольт. У середовищі киплячої води при ста градусах Цельсія межа досягає двадцяти двох мілліелектронвольт.

### 3. Формульний довідник термодинамічних співвідношень

Термодинамічні обчислення в системах зі зворотним зв'язком описуються набором взаємопов'язаних співвідношень між інформаційними та фізичними величинами:

#### Взаємна інформація Шеннона
Взаємна інформація оцінює кількісний рівень кореляції між мікроскопічним станом фізичної системи та записаним станом пам'яті демона. Вона визначається через різницю повної невизначеності та умовної невизначеності. Взаємна інформація є строго невід'ємною величиною. Вона дорівнює нулю лише тоді, коли вимірювання демона зовсім не пов'язане зі станом системи (тобто демон вгадує наосліп).

Взаємна інформація квантифікує зменшення ентропії системи після того, як демон зробив вимірювання. Чим вища точність вимірювального приладу, тим ближче взаємна інформація до теоретичного максимуму в один біт.

#### Максимальна вилучена робота
Узагальнена межа вилучення корисного механічного зусилля з системи з початковою зміною вільної енергії Гельмгольца за наявності взаємної інформації описується рівністю Сагави-Уеди. Ця формула вказує, що інформація діє як додатковий вільний термодинамічний потенціал, дозволяючи вилучати корисну роботу з ізотермічного термостата.

Вільна енергія Гельмгольца вказує на кількість енергії системи, яка доступна для виконання корисної роботи при сталій температурі й об'ємі.

#### Тепло стирання Ландауера
Мінімальне тепло, що виділяється у навколишній термостат при незворотному скиданні бітів неочищеної пам'яті до початкового еталонного стану, визначається продуктом числа бітів на теплову межу Ландауера одного біта.

Це виділення тепла слугує термодинамічною ціною за повернення обчислювача у вихідний стан, захищаючи Другий закон термодинаміки від порушення.

#### Зміна ентропії середовища та замкненого Всесвіту
При поглинанні тепла розширення та виділенні тепла стирання ентропія середовища змінюється відповідно. Сумарний баланс ентропії замкненої системи за один повний повторюваний цикл задовольняє Другому закону термодинаміки і є завжди невід'ємним.

### 4. Програмний специфікований інтерфейс (API Contract)

Нижче наведено специфікацію програмного інтерфейсу мовами C та C++20 для обчислення термодинамічних параметрів інформаційних двигунів, реалізованих у симуляторах та обчислювальних модулях.

#### Класифікація та семантика кодів помилок
Інтерфейс визначає чітку систему повернення кодів помилок для запобігання нефізичним обчисленням:
- У разі успішного виконання операції повертається нулевий код, що підтверджує фізичну коректність обчислених результатів.
- У разі передачі від'ємної чи нульової абсолютної температури повертається код помилки температури, оскільки за абсолютного нуля теплові флуктуації падають до квантового градієнта.
- У разі передачі від'ємного значення взаємної інформації повертається код помилки інформаційного параметра, оскільки взаємна інформація Шеннона є математично невід'ємною величиною.
- У разі передачі нульового вказівника на результат або параметри повертається код помилки некоректної адреси пам'яті.

/* main.c - Приклад використання C-інтерфейсу */
#include <stdio.h>
#include "info_thermo_api.h"

int main(void) {
    InfoEngineParams params = {
        .temperature_K = 300.0,       /* 300 K кімнатна температура */
        .mutual_info_bits = 1.0,      /* 1 біт інформації */
        .free_energy_diff_J = 0.0,    /* Ізотермічний процес без зміни F */
        .efficiency_factor = 1.0      /* Ідеальний термодинамічний ккд */
    };
    
    InfoEngineResult result;
    InfoThermoError err = info_thermo_calculate(&params, &result);
    
    if (err != INFO_THERMO_OK) {
        printf("Помилка розрахунку: %d\n", err);
        return 1;
    }
    
    printf("Теоретично вилучена робота : %.4e Дж (%.4f meV)\n",
           result.max_work_theoretical_J,
           (result.max_work_theoretical_J / INFO_THERMO_ELEM_CHARGE) * 1000.0);
    printf("Мінімальне тепло стирання  : %.4e Дж (%.4f meV)\n",
           result.min_erasure_heat_J, result.min_erasure_heat_meV);
    printf("Баланс ентропії Всесвіту   : %.4e Дж/К\n",
           result.net_entropy_universe_JK);
           
    return 0;
}

// main.cpp - Приклад використання C++20 інтерфейсу
#include <iostream>
#include <iomanip>
#include "info_thermo_api.hpp"

int main() {
    thermo::api::EngineParams params{
        .temperature_K = 300.0,
        .mutual_info_bits = 1.0,

        .efficiency_factor = 1.0

    if (!res) {
        std::cerr << "Помилка розрахунку: " << static_cast<int>(res.error()) << "\n";

    return 0;
}
