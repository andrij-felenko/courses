# 🧮 Точний розв'язок теорії перколації на решітці Беті та теорія скайлінгу

Математична строгість у теорії перколації досягається двома принциповими шляхами: побудовою exact аналітичних розв'язків для спеціальних топологічних структур без циклів (дерев Келі та решіток Беті) та формулюванням феноменологічної ренормалізаційної групи та масштабних гіпотез (скейлінгу) в околі критичних точок.

Решітка Беті (або нескінченне дерево Келі) з координаційним числом `z` являє собою регулярну графову структуру, у якій кожна вершина має точно `z` сусідів і у якій повністю відсутні замкнені цикли (петлі). Відсутність циклів робить окремі гілки решітки статистично незалежними, що дає змогу вивести точні замкнені вирази для критичного порогу `p_c`, параметра порядку `P_∞(p)`, середнього розміру кластера `χ(p)` та розподілу кластерів за розмірами `n_s(p)`.

---

## 1. Точний розрахунок порогу перколації p_c

Розглянемо узлову перколацію на решітці Беті з координаційним числом `z`. Позначимо через `γ = z - 1` коефіцієнт розгалуження (кількість нових гілок, що виходять із кожного наступного вузла при віддаленні від обраного кореня).

Позначимо через `Q(p)` ймовірність того, що, рухаючись від даного вузла у вибраному напрямку вздовж однієї з гілок, ми потрапимо лише у **скінченне дерево** (тобто цей напрямок не містить нескінченного шляху відкритих вузлів).

Аналізуючи перший вузол у вибраній гілці, розглядаємо два виключні випадки:
1. Вузол є **закритим** (імовірність `1 - p`). У цьому разі шлях негайно переривається, що гарантовано створює скінченне дерево.
2. Вузол є **відкритим** (імовірність `p`). У цьому разі він сам розгалужується на `γ = z - 1` нових гілок. Щоб увесь шлях лишався скінченним, **кожна** з цих `γ` нових гілок мусить незалежно вести лише до скінченних піддерев (імовірність чого дорівнює `[Q(p)]ᵍ`).

Записуємо точне самоузгоджене рівняння для ймовірності `Q(p)`:

```
Q(p) = (1 - p) + p · [Q(p)]ᶻ⁻¹      [самоузгоджена ймовірність скінченного дерева]
```

Тривіальним розв'язком цього рівняння для будь-яких значеннях `p` є `Q = 1` (що відповідає відсутності нескінченного протікаючого кластера). Щоб знайти критичну точку `p_c`, при якій з'являється нетривіальний фізичний розв'язок `Q < 1`, дослідимо поведінку функції `f(Q) = (1 - p) + p Qᶻ⁻¹` в околі точки `Q = 1`.

Покладемо `Q = 1 - ε`, де `ε → 0⁺` характеризує відхилення від тривіального стану:

```
1 - ε = (1 - p) + p · (1 - ε)ᶻ⁻¹
1 - ε ≈ 1 - p + p · [1 - (z - 1)·ε]      [лінеаризація за ε через розклад Бінома]
1 - ε ≈ 1 - p + p - p·(z - 1)·ε
1 - ε ≈ 1 - p·(z - 1)·ε
```

Скорочуємо одиниці з обох боків рівняння та ділимо на `ε`:

```
1 = p · (z - 1)                          [умова виникнення нетривіального розв'язку]
p_c = 1 / (z - 1)                        [точний поріг перколації на решітці Беті]
```

Отриманий результат має фізично наочний зміст: перколаційний перехід на деревній структурі виникає тоді, коли середня кількість нових відкритих зв'язків у кожному наступному кроці розгалуження `⟨k⟩ = p · (z - 1)` досягає критичної одиничної межі.

## 2. Потужність нескінченного кластера P_∞(p)

Вузол належить до нескінченного кластера тоді і тільки тоді, коли він сам є відкритим (імовірність `p`) і принаймні одна з його `z` вихідних гілок веде до нескінченності. Ймовірність того, що **усі** `z` гілок ведуть лише до скінченних дерев, дорівнює `[Q(p)]ᶻ`.

Отже, потужність нескінченного кластера (параметр порядку) виражається точним співвідношенням:

```
P_∞(p) = p · [1 - Q(p)ᶻ]                [частка вузлів у протікаючому кластері]
```

Для знаходження критичного показника `β` розкладемо `Q(p)` поблизу `p_c` у надкритичній області (`p > p_c`). Покладемо `p = p_c + Δp` та `Q = 1 - c · Δp`. Підставляючи цей розклад у самоузгоджене рівняння й утримуючи квадратичні члени, отримуємо:

```
1 - c·Δp = (1 - p_c - Δp) + (p_c + Δp)·[1 - (z - 1)·c·Δp + (z - 1)(z - 2)/2 · c²·(Δp)²]
```

Після спрощення отримуємо залежність `c ∝ Δp`, звідки випливає поведінка параметра порядку:

```
P_∞(p) ≈ 2·z / (z - 2) · (p - p_c)¹      [поведінка параметра порядку при p → p_c⁺]
```

Отже, для решітки Беті критичний показник параметра порядку дорівнює строго `β = 1` (значення середнього поля).

## 3. Середній розмір скінченного кластера χ(p)

Розглянемо середню кількість вузлів `χ(p)`, які належать до того самого скінченного кластера, що й вибраний початковий відкритий вузол.

Нехай `T(p)` — середня кількість вузлів у піддереві, що росте з однієї гілки. Якщо початковий вузол цієї гілки є відкритим, він сам додає `1` до розміру і розгалужується на `z - 1` нових гілок, кожна з яких у середньому містить `T(p)` вузлів:

```
T(p) = p · [1 + (z - 1)·T(p)]            [рівняння для середнього розміру піддерева]
T(p) · [1 - p·(z - 1)] = p
T(p) = p / [1 - p·(z - 1)]               [підсумовування геометрії піддерева]
```

Повний середній розмір кластера `χ(p)` враховує центральний відкритий вузол та `z` його незалежних гілок:

```
χ(p) = 1 + z · T(p)
χ(p) = 1 + z·p / [1 - p·(z - 1)]
χ(p) = [1 + p] / [1 - (z - 1)·p]         [точний середній розмір кластера]
```

При наближенні `p` до критичного порогу `p_c = 1 / (z - 1)` знаменник прямує до нуля:

```
χ(p) ∝ |p - p_c|⁻¹                        [розбіжність середнього розміру кластера]
```

Отже, критичний показник середнього розміру кластера на решітці Беті дорівнює `γ = 1`.

## 4. Розподіл кластерів за розмірами n_s(p) на дереві

Використовуючи метод твірних функцій (*generating functions*), можна знайти точну кількість кластерів `n_s` розміру `s` у точці порогу `p = p_c`.

Для решітки Беті точна кількість конфігурацій кластера з `s` вузлів підпорядковується формулі Кейлі для дерев. Поблизу порогу `p = p_c` підсумовування комбінаторних коефіцієнтів через наближення Стирлінга дає асимптотичний закон:

```
n_s(p_c) ∝ s⁻⁵/²                         [розподіл кластерів за розміром при p = p_c]
```

Звідси випливає, що на решітці Беті критичний показник розподілу кластерів дорівнює `τ = 5/2`.

Далеко від порогу розклад доповнюється експоненційним згасанням:

```
n_s(p) ∝ s⁻⁵/² · exp(-c · s)              [згасання кластерів поза критичною точкою]
```

## 5. Метод речової ренормалізаційної групи (Real-Space RG)

Для двовимірних ґраток із зацикленими ребрами точні аналітичні розв'язки отримують за допомогою методів **ренормалізаційної групи (РГ)**.

Розглянемо РГ-трансформацію блочних вузлів на трикутній ґратці. Об'єднаємо трійки сусідніх вузлів у один макроскопічний «блочний вузол» з масштабним фактором `b = √3`.

За правилом більшості (мажоритарне правило): блочний вузол вважається відкритим, якщо принаймні 2 з 3 його внутрішніх вузлів є відкритими.

```
p' = R(p) = p³ + 3·p²·(1 - p)            [РГ-перетворення для блоку з 3 вузлів]
p' = 3·p² - 2·p³                         [масштабне рівняння ренормалізації]
```

### Знаходження нерухомих точок (Fixed Points)

Шукаємо непорушні точки рівняння `p* = R(p*)`:

```
p* = 3·(p*)² - 2·(p*)³
2·(p*)³ - 3·(p*)² + p* = 0
p* · (2·p* - 1) · (p* - 1) = 0
```

Рівняння має три розв'язки:
- `p* = 0` (стійка атракторна точка: повністю заблокована фаза).
- `p* = 1` (стійка атракторна точка: повністю провідна фаза).
- `p* = 1/2` (**нестійка критична точка** `p_c`).

Отримане значення `p_c = 1/2` точно збігається з теоретичним порогом узлової перколації на трикутній ґратці!

### Обчислення критичного показника ν

Лінеаризуємо РГ-трансформацію в околі критичної точки `p* = 1/2`:

```
λ = [dR(p)/dp]|_{p=p*} = [6·p - 6·p²]|_{p=1/2} = 6*(1/2) - 6*(1/4) = 3 - 3/2 = 3/2
```

Критичний показник радіуса кореляції `ν` обчислюється через масштабний фактор `b = √3` та значення eigenvalues `λ = 1.5`:

```
ν = ln(b) / ln(λ) = ln(√3) / ln(1.5) = (0.5 · ln 3) / (ln 1.5 - ln 1) ≈ 0.5493 / 0.4055 ≈ 1.35
```

Отримане наближене значення `ν ≈ 1.35` надзвичайно близьке до точного значення теорії конформного поля `ν = 4/3 ≈ 1.333`!

## 6. Феноменологічна масштабна теорія (Скейлінг Стауффера)

Для реальних ґраток у скінченній розмірності `d` (наприклад, `d = 2` або `d = 3`) середня кількість кластерів розміру `s` на один вузол `n_s(p)` підпорядковується універсальній масштабній гіпотезі Стауффера:

```
n_s(p) ≈ s⁻ᵗ · f((p - p_c) · sˢ)         [масштабне співвідношення для n_s(p)]
```

Тут:
- `τ` — критичний показник розподілу кластерів за розміром.
- `σ` — критичний показник масштабної змінної.
- `f(z)` — універсальна масштабна функція, яка швидко згасає при `z ≫ 1`.

Усі макроскопічні критичні показники виражаються через два базові показники `τ` та `σ`:

```
β = (τ - 2) / σ                           [показник параметра порядку]
γ = (3 - τ) / σ                           [показник середнього розміру кластера]
ν = (τ - 1) / (d · σ)                     [показник радіуса кореляції]
```

Звідси випливає фундаментальне **співвідношення гіперскейлінгу**:

```
d · ν = 2 - α = β · (τ - 1) / (τ - 2)     [зв'язок розмірності простору та показників]
```

### Порівняльна таблиця критичних показників

| Величина | Показник | 2D (квадратна ґратка) | 3D (кубічна ґратка) | d ≥ 6 (Середнє поле / Беті) |
| :--- | :---: | :---: | :---: | :---: |
| Потужність кластера `P_∞` | `β` | `5 / 36 ≈ 0.139` | `≈ 0.41` | `1` |
| Середній розмір `χ` | `γ` | `43 / 18 ≈ 2.389` | `≈ 1.80` | `1` |
| Радіус кореляції `ξ` | `ν` | `4 / 3 ≈ 1.333` | `≈ 0.88` | `1 / 2` |
| Розподіл кластерів | `τ` | `187 / 91 ≈ 2.055` | `≈ 2.18` | `5 / 2` |
| Масштабний показник | `σ` | `36 / 91 ≈ 0.396` | `≈ 0.45` | `1 / 2` |
| Фрактальна розмірність `d_f` | `d_f` | `91 / 48 ≈ 1.896` | `≈ 2.52` | `4` |

Значення `d_c = 6` є **верхньою критичною розмірністю** для перколації. При `d ≥ 6` флуктуації перестають відігравати вирішальну роль, і критичні показники системи строго збігаються з точним розв'язком на решітці Беті (наближення середнього поля).

## 7. Конформна інваріантність та формула Карді у 2D

У двовимірному просторі критична перколація описується конформною теорією поля (*Conformal Field Theory, CFT*) з центральним зарядом `c = 0`.

У 1992 році Джон Карді (*John Cardy*) сформулював точну математичну формулу для ймовірності протікання `П(r)` між протилежними сторонами прямокутника зі співвідношенням сторін `r = a / b` у критичній точці `p = p_c`. Формула виражається через гіпергеометричну функцію Гаусса:

```
П(r) = 3·Γ(2/3) / [Γ(1/3)²] · η¹/³ · ₂F₁ (1/3, 2/3; 4/3; η)
```

Де `η` — конформний модулярний інваріант прямокутника.

У 2001 році Станіслав Смирнов довів цю формулу для плоских трикутних ґраток, встановивши строгий математичний міст між геометричною перколацією та теорією **стохастичних еволюцій Шрамма — Льовнера** (*Schramm-Loewner Evolution, SLE_κ*) із параметром `κ = 6`.
