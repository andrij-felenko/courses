# 🧮 Теорема Вінера — Хінчина та автокореляція білого шуму

Ця математична вставка містить строге виведення теореми Вінера — Хінчина, яка встановлює фундаментальну дуальність між автокореляційною функцією випадкового процесу у часовій області та його спектральною щільністю потужності у частотній області, а також розглядає граничний випадок дельта-подібної автокореляції білого шуму.

---

### Фізична та математична постановка задачі

Аналіз випадкових процесів вимагає спеціального математичного апарату, оскільки звичайні класичні функції розкладу Фурьє є незастосовними до незагасаючих випадкових траєкторій. Якщо спробувати обчислити інтеграл Фурьє від неперервної реалізації випадкового шуму на всьому нескінченному часовому інтервалі від мінус нескінченності до плюс нескінченності, інтеграл не буде збігатися в жодному класичному сенсі, оскільки середня енергія процесу на нескінченному інтервалі є нескінченно великою величиною.

Щоб подолати цю математичну перешкоду та будувати строгу теорію, досліджують не окремі випадкові траєкторії, а статистичні характеристики ансамблю реалізацій процесу. Для стаціонарного випадкового процесу розглядають дві фундаментальні характеристики: автокореляційну функцію `R_x(τ)`, яка вимірює часову пам'ять та статистичний зв'язок між значеннями сигналу у різні моменти часу, та спектральну щільність потужності `S_x(f)`, яка описує розподіл середньої шумової потужності за частотними гармоніками. Теорема Вінера — Хінчина є головним математичним містком, що пов'язане ці два представлення у єдину цілісну систему.

Розглянемо дійсний випадковий процес `X(t)`, який задовольняє умови **стаціонарності у широкому сенсі (weak stationarity)**:
1. Математичне сподівання сигналу існує і є постійною величиною, яка абсолютно не залежить від вибору моменту часу. Без втрати загальності вважаємо `E[X(t)] = 0` (центрикований процес). Якщо процес має постійне середнє значення `m_x ≠ 0`, його завжди можна легко відняти перед проведенням спектрального аналізу.
2. Дисперсія процесу є скінченною константою у будь-який момент часу: `E[X²(t)] = σ² < ∞`.
3. Автокореляційна функція `R_x(t₁, t₂) = E[X(t₁) · X(t₂)]` залежить виключно від часового інтервалу між спостереженнями `τ = t₁ - t₂`, але зовсім не залежить від абсолютного вибору початку відліку часу `t₁`:

```
R_x(τ) = E[ X(t) · X(t + τ) ]
```

Аналіз математичних властивостей автокореляційної функції показує, що вона зобов'язана бути парною функцією `R_x(-τ) = R_x(τ)`, а її максимальне абсолютне значення досягається на початку координат при нульовому часовому зсуві: `|R_x(τ)| ≤ R_x(0) = σ²`.

Оскільки випадковий процес існує на нескінченному інтервалі часу, для побудови строгої спектральної теорії застосовують операцію часового зрізання. Вводиться **зрізаний процес** `X_T(t)` на інтервалі спостереження тривалістю `T` (від `-T/2` до `T/2`):

```
X_T(t) = X(t)      [при -T/2 ≤ t ≤ T/2]
X_T(t) = 0         [поза цим інтервалом]
```

---

### Крок 1. Комплексний спектр зрізаного процесу та подвійне інтегрування

Завдяки фінітному характеру функції `X_T(t)` (вона дорівнює нулю поза скінченним інтервалом `T`), її енергія є скінченною величиною з ймовірністю одиниця. Це гарантує існування прямого комплексного перетворення Фурьє для даної реалізації:

```
F_T(f) = ∫_{-T/2}^{+T/2} X(t) · e^{-j·2·π·f·t} dt
```

Квадрат модуля комплексного спектра `|F_T(f)|²` виражає енергетичний спектр конкретної реалізації сигналу. Використовуючи тотожність `|z|² = z · z*`, де `z*` означає комплексно-спряжене число, розпишемо модуль спектра через подвійний інтеграл за двома незалежними часовими змінними `t₁` та `t₂`:

```
|F_T(f)|² = [ ∫_{-T/2}^{+T/2} X(t₁) · e^{-j·2·π·f·t₁} dt₁ ] · [ ∫_{-T/2}^{+T/2} X(t₂) · e^{+j·2·π·f·t₂} dt₂ ]
= ∫_{-T/2}^{+T/2} ∫_{-T/2}^{+T/2} X(t₁) · X(t₂) · e^{-j·2·π·f·(t₁ - t₂)} dt₁ dt₂
```

Цей подвійний інтеграл являє собою суму добутків значень сигналу у всі можливі пари моментів часу `t₁` та `t₂`, зважених відповідними гармонійними фазовими множниками.

---

### Крок 2. Статистичне усереднення за ансамблем реалізацій

Оскільки `|F_T(f)|²` залежить від випадкової реалізації процесу і флуктує від одного досліду до іншого, для отримання стійкої спектральної характеристики застосуємо оператор математичного сподівання `E[...]` (усереднення за нескінченним ансамблем усіх можливих реалізацій).

Оскільки оператор математичного сподівання `E[...]` та оператор інтегрування є лінійними операторами, ми можемо поміняти порядок їхнього виконання і внести математичне сподівання безпосередньо під знаки інтегралів:

```
E[ |F_T(f)|² ] = ∫_{-T/2}^{+T/2} ∫_{-T/2}^{+T/2} E[ X(t₁) · X(t₂) ] · e^{-j·2·π·f·(t₁ - t₂)} dt₁ dt₂
```

Використовуючи фундаментальне означення автокореляційної функції стаціонарного процесу `E[X(t₁) · X(t₂)] = R_x(t₁ - t₂)`, підставимо його у подвійний інтеграл:

```
E[ |F_T(f)|² ] = ∫_{-T/2}^{+T/2} ∫_{-T/2}^{+T/2} R_x(t₁ - t₂) · e^{-j·2·π·f·(t₁ - t₂)} dt₁ dt₂
```

Отриманий інтеграл показує, що середня енергія зрізаного сигналу повністю визначається автокореляційною функцією процесу `R_x(τ)`.

### Крок 3. Геометрична заміна змінних та спрощення області інтегрування

Двовимірна область інтегрування у вихідних координатах `(t₁, t₂)` являє собою квадрат зі стороною `T`, розташований у центрі початку координат від `-T/2` до `T/2`.

Виконаємо геометрію заміни змінних, переходячи від координат `(t₁, t₂)` до нових координат `(τ, t)`:
* `τ = t₁ - t₂` (часовий зсув або лаг між спостереженнями)
* `t = t₂` (поточний абсолютний час)

Зворотно, `t₁ = t + τ` та `t₂ = t`. Якобіан цього лінійного перетворення координат дорівнює одиниці:

```
J = | ∂(t₁, t₂) / ∂(τ, t) | = | det [ 1  1 ; 0  1 ] | = 1
```

Область інтегрування у нових координатах `(τ, t)` перетворюється з квадрата на паралелограм. Проаналізуємо межі зміни змінної `t` при фіксованому значення часового зсуву `τ`:
* Для додатних зсувів `τ > 0` змінна `t` змінюється від `-T/2` до `T/2 - τ`. Довжина інтервалу інтегрування дорівнює `T - τ`.
* Для від'ємних зсувів `τ < 0` змінна `t` змінюється від `-T/2 - τ` до `T/2`. Довжина інтервалу інтегрування дорівнює `T + τ = T - |τ|`.

В обох випадках довжина інтервалу інтегрування за змінною `t` для заданого `τ` дорівнює `(T - |τ|)`. Загальний діапазон зміни часового зсуву `τ` лежить у межах від `-T` до `+T`.

Оскільки підінтегральний вираз `R_x(τ) · e^{-j·2·π·f·τ}` залежить виключно від `τ` і зовсім не залежить від `t`, внутрішнє інтегрування за змінною `t` зводиться до простого множення на довжину інтервалу `(T - |τ|)`:

```
E[ |F_T(f)|² ] = ∫_{-T}^{+T} (T - |τ|) · R_x(τ) · e^{-j·2·π·f·τ} dτ
```

Поділивши обидві частини рівності на час спостереження `T`, отримуємо вираз для усередненої потужності:

```
E[ |F_T(f)|² / T ] = ∫_{-T}^{+T} [ 1 - (|τ| / T) ] · R_x(τ) · e^{-j·2·π·f·τ} dτ
```

Множник `[1 - (|τ| / T)]` можна інтерпретувати як трикутне згладжувальне вікно Бартлетта, яке природним чином виникає при часовому обмеженні сигналу.

### Крок 4. Граничний перехід при T → ∞ та формулювання теореми

За строгим означенням, двостороння спектральна щільність потужності `S_x(f)` дорівнює границі середньої спектральної потужності при прямуванні часу спостереження до нескінченності:

```
S_x(f) = lim_{T → ∞} E[ |F_T(f)|² / T ]
= lim_{T → ∞} ∫_{-T}^{+T} [ 1 - (|τ| / T) ] · R_x(τ) · e^{-j·2·π·f·τ} dτ
```

Якщо автокореляційна функція `R_x(τ)` спадає достатньо швидко при `|τ| → ∞` (зокрема, якщо вона є абсолютно інтегровною функцією `∫_{-∞}^{+∞} |R_x(τ)| dτ < ∞`), то за теоремою Лебега про мажоровану збіжність ми можемо внести знак границі під знак інтеграла.

Оскільки для будь-якого фіксованого значення `τ` границя множника дорівнює одиниці:

```
lim_{T → ∞} [ 1 - (|τ| / T) ] = 1
```

ми отримуємо остаточну пряму формулу **теореми Вінера — Хінчина**:

```
S_x(f) = ∫_{-∞}^{+∞} R_x(τ) · e^{-j·2·π·f·τ} dτ
```

Оскільки `R_x(τ)` є дійсною та парною функцією `R_x(-τ) = R_x(τ)`, уявна частина комплексної експоненти `sin(2·π·f·τ)` при інтегруванні у симетричних межах від `-∞` до `+∞` тотожно перетворюється на нуль. Це дозволяє переписати теорему у вигляді дійсного косинус-перетворення Фурьє:

```
S_x(f) = ∫_{-∞}^{+∞} R_x(τ) · cos(2·π·f·τ) dτ
```

Зворотне перетворення Фурьє виражає автокореляційну функцію `R_x(τ)` через спектральну щільність потужності `S_x(f)`:

```
R_x(τ) = ∫_{-∞}^{+∞} S_x(f) · e^{+j·2·π·f·τ} df
= ∫_{-∞}^{+∞} S_x(f) · cos(2·π·f·τ) df
```

Ці два вирази утворюють симетричну пару перетворень Фурьє і доводять, що автокореляційна функція та спектральна щільність потужності містять абсолютно тотожну інформацію про випадковий процес, але подану у двох різних математичних областях — часовій та частотній.

### Невід'ємна визначеність та теорема Бохнера — Хінчина

Важливою математичною властивістю будь-якої автокореляційної функції стаціонарного процесу є її **невід'ємна визначеність** (positive semi-definiteness). Для довільного набору моментів часу `t₁, t₂, ..., t_N` та довільних комплексних коефіцієнтів `c₁, c₂, ..., c_N` виконується нерівність:

```
∑_{i=1}^{N} ∑_{j=1}^{N} c_i · c_j* · R_x(t_i - t_j) ≥ 0
```

Доведення цієї фундаментальної математичної властивості негайно випливає з розгляду середнього квадрата лінійної комбінації значень сигналу у різні моменти часу: `E[ | ∑ c_i · X(t_i) |² ] ≥ 0`. Оскільки квадрат модуля випадкової величини завжди є невід'ємним, його математичне сподівання також не може бути меншим за нуль.

Згідно з видатною математичною **теоремою Бохнера — Хінчина** (Salomon Bochner, 1932 рік), неперервна функція `R(τ)` є невід'ємно визначеною тоді й лише тоді, коли її перетворення Фурьє `S_x(f)` є невід'ємною мірою: `S_x(f) ≥ 0` для всіх частот `f`. Це строго гарантує, що спектральна щільність потужності реального фізичного процесу ніколи не може набувати від'ємних значень, що повністю відповідає фізичному змісту енергії та потужності.

### Взаємна спектральна щільність потужності двох процесів

Для двох сумісно стаціонарних випадкових процесів `X(t)` та `Y(t)` вводиться **взаємна автокореляційна функція**:

```
R_xy(τ) = E[ X(t) · Y(t + τ) ]
```

Взаємна спектральна щільність потужності `S_xy(f)` за теоремою Вінера — Хінчина дорівнює перетворенню Фурьє від взаємної автокореляції:

```
S_xy(f) = ∫_{-∞}^{+∞} R_xy(τ) · e^{-j·2·π·f·τ} dτ
```

На відміну від автокореляції одного процесу, взаємна автокореляційна функція `R_xy(τ)` взагалі кажучи не є парною `R_xy(-τ) ≠ R_xy(τ)`, але задовольняє умову симетрії `R_xy(-τ) = R_yx(τ)`.

Відповідно, взаємна спектральна щільність `S_xy(f)` є в загальному випадку комплексною функцією `S_xy(f) = C_xy(f) - j · Q_xy(f)`, де дійсна частина `C_xy(f)` називається **ко-спектром** (синфазною складовою), а уявна частина `Q_xy(f)` — **квадратурним спектром**.

Якщо два білих шуми `X(t)` та `Y(t)` є статистично незалежними, їхній взаємний спектр тотожно дорівнює нулю `S_xy(f) = 0`. Якщо ж вони утворені з одного джерела через різні фільтри, когерентність між ними виражається функцією когерентності:

```
γ_xy²(f) = |S_xy(f)|² / [ S_x(f) · S_y(f) ]
```

Функція когерентності задовольняє нерівність `0 ≤ γ_xy²(f) ≤ 1` і показує ступінь лінійної пов'язаності процесів на кожній частоті.

### Спектральний розклад векторних стаціонарних процесів

Коли розглянуто багатовимірний випадковий вектор `X(t) = [X₁(t), X₂(t), ..., X_M(t)]ᵀ`, його кореляційні властивості описуються матрицею автокореляційних функцій розміром `M × M`:

```
R_XX(τ) = E[ X(t) · Xᵀ(t + τ) ]
```

Діагональні елементи `R_ii(τ)` являють собою звичайні автокореляційні функції окремих компонент вектора, а позадіагональні елементи `R_ij(τ)` є взаємними автокореляційними функціями між компонентами `X_i(t)` та `X_j(t)`.

Покомпонентне застосування перетворення Вінера — Хінчина дає спектральну матрицю щільності потужності `S_XX(f)`:

```
S_XX(f) = ∫_{-∞}^{+∞} R_XX(τ) · e^{-j·2·π·f·τ} dτ
```

Спектральна матриця `S_XX(f)` задовольняє умову ермітовості `S_XX^H(f) = S_XX(f)` (де `H` означає ермітове спряження) та є невід'ємно визначеною матрицею для будь-якої частоти `f`. Практичне застосування векторної теореми Вінера — Хінчина знаходять у фазованих антенних решітках, системах MIMO у бездротовому зв'язку та багатовимірній фільтрації Калмана.

### Карунена — Лоєва розклад і спектральні спектри

Альтернативним ортогональним розкладом випадкових процесів на скінченному інтервалі `[0, T]` є **теорема Карунена — Лоєва** (Kari Karhunen, 1946; Michel Loève, 1955). Вона дозволяє розкласти випадковий процес `X(t)` у ряд за власними функціями `e_k(t)` кореляційного інтегрального оператора:

```
X(t) = ∑_{k=1}^{∞} Z_k · e_k(t)
```

де `Z_k` — некорельовані випадкові величини з дисперсіями `λ_k`, а `e_k(t)` — ортонормовані власні функції інтегрального рівняння Фредгольма другого роду:

```
∫_{0}^{T} R_x(t, s) · e_k(s) ds = λ_k · e_k(t)
```

Для білого шуму з кореляцією `R_x(t, s) = (N₀/2) · δ(t - s)` будь-яка ортонормована система функцій є власною, а всі власні значення однакові `λ_k = N₀ / 2`. Це математично пояснює, чому білий шум має максимальну інформаційну ентропію і не піддається стисненню без втрат.

---

### Дискретна теорема Вінера — Хінчина (DTFT)

Для дискретизованих випадкових процесів `x[n] = x(n · Δt)` із частотою дискретизації `f_s = 1 / Δt` автокореляційна функція описується послідовністю `R_d[k] = E[x[n] · x[n + k]]`.

Дискретна теорема Вінера — Хінчина пов'язує `R_d[k]` зі спектральною щільністю через дискретне перетворення Фурьє (DTFT):

```
S_d(f) = Δt · ∑_{k=-∞}^{+∞} R_d[k] · e^{-j·2·π·f·k·Δt}     [для -f_s/2 ≤ f ≤ f_s/2]
```

Зворотне перетворення дає вибіркові значення автокореляції:

```
R_d[k] = ∫_{-f_s/2}^{+f_s/2} S_d(f) · e^{+j·2·π·f·k·Δt} df
```

Ці формули є основою цифрового спектрального аналізу в процесорах обробки сигналів (DSP).

---

### Математичний випадок ідеального білого шуму та дельта-функція Дірака

Розглянемо випадок ідеального білого шуму. За означенням, двостороння спектральна щільність потужності ідеального білого шуму є константою на всіх частотах: `S_x(f) = N₀ / 2`.

Застосуємо зворотне перетворення Вінера — Хінчина для знаходження автокореляційної функції ідеального білого шуму:

```
R_x(τ) = ∫_{-∞}^{+∞} (N₀ / 2) · e^{+j·2·π·f·τ} df
= (N₀ / 2) · ∫_{-∞}^{+∞} e^{+j·2·π·f·τ} df
```

З математичного аналізу обобщених функцій (теорія дистрибуцій Лорана Шварца) відомо, що інтеграл від комплексної експоненти по всій осі частот являє собою математичне представлення дельта-функції Дірака `δ(τ)`:

```
∫_{-∞}^{+∞} e^{+j·2·π·f·τ} df = δ(τ)
```

Таким чином, отримуємо фундаментальну формулу для автокореляції білого шуму:

```
R_x(τ) = (N₀ / 2) · δ(τ)
```

Якщо використовувати односторонню спектральну щільність `G_x(f) = N₀` (визначену при `f ≥ 0`), вираз набуває вигляду:

```
R_x(τ) = (G_x / 2) · δ(τ)
```

Цей математичний результат має колосальне значення для фізики:
1. Для будь-якого `τ ≠ 0` значення автокореляційної функції дорівнює нулю `R_x(τ) = 0`. Це означає, що миттєві значення білого шуму у два різних моменти часу є повністю некорельованими.
2. При `τ = 0` значення автокореляції прямує до нескінченності `R_x(0) = ∞`, що відображає нескінченну дисперсію та нескінченну потужність ідеального білого шуму у нескінченній смузі частот.

### Автокореляція фільтрованого шуму: процес Орнштейна — Уленбека

Щоб побачити, як дельта-подібна автокореляція білого шуму перетворюється на неперервну гладку функцію при проходженні через фізичну систему, розглянемо проходження білого шуму `X(t)` із односторонньою спектральною щільністю `G_x = N₀` через аналоговий RC-фільтр низьких частот з часовою сталою `T_c = R · C`.

Передавальна функція RC-фільтра дорівнює: `H(f) = 1 / (1 + j · 2 · π · f · T_c)`.

Відповідно до теорії лінійних систем, спектральна щільність шуму на виході `Y(t)` становить:

```
S_y(f) = (N₀ / 2) · |H(f)|²
= (N₀ / 2) / [ 1 + (2 · π · f · T_c)² ]
```

Знайдемо автокореляційну функцію вихідного процесу `R_y(τ)` за зворотним перетворенням Вінера — Хінчина:

```
R_y(τ) = ∫_{-∞}^{+∞} [ (N₀ / 2) / (1 + (2 · π · f · T_c)²) ] · e^{j·2·π·f·τ} df
```

Для обчислення цього інтеграла застосуємо метод лишків у комплексній площині змінного `z = f`. Знаменник підінтегральної функції має два простих полюси у точках `z = +j / (2·π·T_c)` та `z = -j / (2·π·T_c)`. Замикаючи контур інтегрування у верхній напівплощині для `τ > 0` та застосовуючи теорему про лишки, отримуємо:

```
R_y(τ) = [ N₀ / (4 · T_c) ] · e^{-|τ| / T_c}
```

Підставивши значення часової сталої RC-кола `T_c = R · C` та спектральної щільності теплового шуму резистора `N₀ = 4 · k_B · T · R`, отримуємо остаточний вираз для автокореляційної функції напруги на конденсаторі:

```
R_y(τ) = [ (4 · k_B · T · R) / (4 · R · C) ] · e^{-|τ| / (R·C)}
= (k_B · T / C) · e^{-|τ| / (R·C)}
```

Цей математичний результат описує так званий **процес Орнштейна — Уленбека** (стаціонарний марківський гауссів процес) і демонструє два важливі висновки:
1. При `τ = 0` дисперсія шуму дорівнює `R_y(0) = k_B · T / C`, що є скінченною величиною, яка не залежить від опору `R`.
2. Наявність інерційного елемента (ємності `C`) згладжує миттєві флуктуації білого шуму, розтягуючи некорельований дельта-імпульс у неперервну експоненційну пам'ять із часом кореляції `τ_c = R · C`. При `C → 0` час кореляції прямує до нуля, і вираз знову перетворюється на дельта-функцію ідеального білого шуму.
