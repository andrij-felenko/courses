# ⚙️ Моделювання білого шуму та оцінювання спектральної щільності

Чисельне моделювання гауссового білого шуму охоплює генерування випадкових відліків, обчислення часової автокореляційної функції та оцінювання спектральної щільності потужності (PSD) методом Велча з використанням алгоритму Швидкого Перетворення Фурьє (FFT).

---

### Фізична та алгоритмічна концепція чисельного моделювання

При моделюванні фізичних систем на комп'ютері неперервний аналоговий шум замінюють дискретною послідовністю випадкових відліків `x[n] = x(n · Δt)`, взятих із фіксованим кроком за часом `Δt = 1 / f_s`, де `f_s` — частота дискретизації у герцах.

Процес чисельного аналізу складається з трьох послідовних етапів:

1. **Генерація дискретного білого шуму із заданою аналоговою спектральною щільністю `G_0`:**
   Вбудовані генератори випадкових чисел більшості мов програмування (наприклад, стандартні функції `rand()`) генерують рівномірно розподілені псевдовипадкові числа у діапазоні від `0` до `1`. Для моделювання реального фізичного шуму їх необхідно перетворити на гауссів (нормальний) розподіл із нульовим середнім значенням та заданою дисперсією `σ_d²`. 
   
   Найбільш поширеним, точним та елегантним математичним методом є **перетворення Бокса — Мюллера** (*Box-Muller transform*). воно виходить із того, що двовимірний двомісний гауссів розподіл у полярній системі координат виражається через експоненціальний та рівномірний кутовий розподіли. Перетворення приймає дві незалежні рівномірно розподілені величини `u₁` та `u₂` у напіввідкритому інтервалі `(0, 1]` і повертає дві ортогональні незалежні стандартні нормальні величини `z₀` та `z₁`:
   ```
   z₀ = √( -2 · ln(u₁) ) · cos( 2 · π · u₂ )
   z₁ = √( -2 · ln(u₁) ) · sin( 2 · π · u₂ )
   ```
   Зв'язок між необхідною дисперсією дискретних відліків `σ_d²` та аналоговою односторонньою спектральною щільністю `G_0` задається теоремою Котельникова — Найквіста: `σ_d² = G_0 · (f_s / 2)`. Отже, середньоквадратичне відхилення (стандартне відхилення) для генератора нормальних чисел зобов'язане дорівнювати `std_dev = √( G_0 · f_s / 2 )`.

   Для високоефективних обчислювальних систем замість Бокса — Мюллера застосовують **алгоритм Зіккурат (Ziggurat algorithm)** Джорджа Марсальї, який базується на відкиданні ступенів прямокутних шарів і працює у 3-5 разів швидше за рахунок мінімізації викликів обчислювально містких математичних функцій `log()` та `cos()`.

2. **Обчислення вибіркової автокореляційної функції:**
   Для перевірки некорельованості згенерованих відліків обчислюють вибіркову часову автокореляційну функцію за `N` відліками:
   ```
   R_d[k] = (1 / N) · ∑_{n=0}^{N-1-k} x[n] · x[n + k]
   ```
   Для ідеального білого шуму графік `R_d[k]` повинен мати чіткий пік у точці `k = 0`, який дорівнює дисперсії `σ_d²`, і коливатися навколо нуля для всіх часових лагів `k ≠ 0`.

3. **Оцінювання спектральної щільності потужності методом Велча:**
   Пряме застосування БПФ до всього сигналу тривалістю `N` відліків дає сиру періодограму. Проте періодограма має відносну середньоквадратичну похибку `100%`, яка не зменшується при збільшенні тривалості запису `N`. Щоб отримати стійку й згладжену оцінку спектральної щільності, застосовують **метод Велча** (*Welch's method*):
   * Вхідний масив ділять на `K` частково перекритих сегментів довжиною `L` (типово `50%` перекриття).
   * Кожен сегмент множать на згладжувальне вікно Хенна `w[n] = 0.5 · [1 - cos(2·π·n / (L-1))]` для усунення стрибків на межах сегмента та зменшення розтікання спектра.
   * Для кожного взваженого вікном сегмента обчислюють БПФ та квадрат модуля спектра.
   * Отримані `K` періодограм усереднюють і нормують на норму вікна `S_w = ∑ w²[n]` та частоту дискретизації `f_s`.

### Порівняльний аналіз чисельних методів оцінювання спектра (Велч vs Періодограма vs Блекман — Тьюкі)

У практичній цифровій обробці сигналів вибір конкретного алгоритму оцінювання спектральної щільності потужності визначається компромісом між трьома ключовими факторами: частотною роздільністю, вибірковою дисперсією оцінки та обчислювальною складністю.

1. **Пряма періодограма Стекстона — Шустера (Periodogram):**
   Обчислюється як квадрат модуля БПФ від усього вхідного сигналу довжиною `N`: `P(f_k) = (1 / (N·f_s)) · |X[k]|²`. Вона забезпечує максимальну доступну частотну роздільну здатність `Δf = f_s / N`. Проте періодограма є неузгодженою оцінкою: її дисперсія дорівнює квадрату істинного значення спектральної щільності, і флуктуації графіка не зменшуються зі збільшенням довжини масиву `N`. 

2. **Метод Велча (Welch's Averaged Periodogram):**
   Розбиває масив `N` на `K` перекритих сегментів довжиною `L` і усереднює їхні взважені періодограми. Частотна роздільність знижується до `Δf = f_s / L`, але дисперсія флуктуацій зменшується у `K` разів (або приблизно у `1.78 · K` разів при `50%` перекритті з вікном Хенна). Саме метод Велча є абсолютним стандартом для вимірювання спектральної щільності білого та забарвленого шуму у вимірювальних приладах та інженерних пакетах (SciPy, MATLAB, LabVIEW).

3. **Метод Блекмана — Тьюкі (Blackman-Tukey Method):**
   Спершу обчислює вибіркову автокореляційну функцію `R_d[k]` для часових лагів від `-M` до `+M` (де `M << N`), множить її на симетричне згладжувальне вікно і бере пряме перетворення Фурьє. Метод дає високу якість оцінки для гладких спектрів, але вимагає додаткових обчислень для знаходження автокореляції.

### Детальний розбір реалізації та пастки цифрової обробки сигналів

Розглянемо простір інженерних деталей та типових помилок при програмуванні спектрального аналізу:

1. **Масштабування дисперсії випадкових відліків:**
   Поширеною похибкою розробників є генерування випадкових відліків із одиничною дисперсією `σ² = 1.0` без урахування частоти дискретизації `f_s`. Проте, як випливає з теорії Найквіста, дискретна дисперсія `σ_d²` розмазується по смузі Найквіста від `0` до `f_s / 2`. Якщо ви збільшуєте частоту дискретизації `f_s` у `10` разів, а дисперсію відліків залишаєте незмінною, спектральна щільність вхідного шуму `G_0 = 2·σ_d² / f_s` впаде у `10` разів! Щоб зберегти постійний фізичний рівень спектральної щільності `G_0` (наприклад, `нВ/√Гц`), необхідно масштабувати амплітуду генератора випадкових чисел як `std_dev = √( G_0 · f_s / 2 )`.

2. **Нормування вікна та витікання спектра (Spectral Leakage):**
   При діленні сигналу на сегменти прямокутні межі викликають ефект витікання спектра через високі бокові пелюстки функції `sin(x)/x` (перша бокова пелюстка становить всього `-13.3 дБ`). Застосування згладжувального вікна Хенна `w[n]` пригнічує бокові пелюстки до `-31.5 дБ`, але зменшує повну потужність сегмента. Щоб компенсувати це зменшення, у коді обчислюється норма вікна `win_sum_sq = ∑ w²[n]`, на яку ділиться накопичений квадрат модуля спектра.

3. **Односторонній спектр та подвоєння потужності:**
   Алгоритм БПФ повертає двосторонній комплексний спектр для від'ємних та додатних частот від `0` до `N-1`. Для отримання односторонньої спектральної щільності `G(f)` значення для всіх частотних комірок `k` від `1` до `N/2 - 1` помножуються на `2.0`, оскільки додатні та від'ємні частотні складові утворюють симетричні пари. Постійна складова `k = 0` та частота Найквіста `k = N/2` не подвоюються.

4. **Вибір коефіцієнта перекриття сегментів (Overlap Ratio):**
   Використання `50%` перекриття у методі Велча дозволяє використати ті відліки сигналу, які були пригнічені крайніми ділянками вікна Хенна у попередньому сегменті. Це дозволяє майже подвоїти кількість усереднюваних сегментів `K` за той самий час спостереження, що зменшує вибіркову дисперсію виміряного спектра у `√K` разів без втрати частотного розрізнення. Доведено, що для вікна Хенна саме `50%` перекриття мінімізує дисперсію оцінки до рівня `(9/16) / K`.

### Параметричний спектральний аналіз (Методи Юла — Вокера та Бурга)

Окрім непараметричних методів на основі перетворення Фурьє (періодограма, Велч), у цифровій обробці сигналів застосовують **параметричні методи спектрального оцінювання**. Вони моделюють випадковий процес як вихід авторегресійного (АР) фільтра порядків `p`, на вхід якого подається білий шум з дисперсією `σ_w²`.

Оцінка спектральної щільності за методом Юла — Вокера описується виразом:

```
P_AR(f) = ( σ_w² · Δt ) / | 1 + ∑_{k=1}^{p} a_k · e^{-j·2·π·f·k·Δt} |²
```

де `a_k` — коефіцієнти авторегресії, знайти які можна розв'язанням системи лінійних рівнянь Юла — Вокера з використанням вибіркових значень автокореляції `R_d[k]`.

Параметричні методи забезпечують набагато вищу частотну роздільну здатність при коротких масивах даних `N`, оскільки вони не вимагають віконної обробки й усувають розтікання спектра. Проте для суцільного білого шуму параметричні методи не мають переваг перед методом Велча, оскільки для білого шуму порядок авторегресії `p = 0`.

### Визначення імпульсної характеристики систем за допомогою білого шуму

Завдяки дельта-подібній автокореляції білого шуму `R_x(τ) = (N₀/2) · δ(τ)`, білий шум є ідеальним зондувальним сигналом для експериментального визначення імпульсної характеристики `h(t)` невідомих динамічних систем.

Якщо подати білий шум `X(t)` на вхід лінійної стаціонарної системи, то взаємна автокореляційна функція між вхідним шумом та вихідним сигналом `Y(t)` дорівнює імпульсній характеристиці системи, помноженій на інтенсивність шуму:

```
R_xy(τ) = ( N₀ / 2 ) · h(τ)
```

Цей результат лежить в основі методів активної ідентифікації систем та акустичного зондування приміщень за допомогою псевдовипадкового білого шуму.

### Генерація квантового білого шуму (QRNG)

У криптографії та квантовій інформатиці псевдовипадкові генератори шумів (PRNG) замінюють **апаратними генераторами істинного квантового білого шуму (Quantum Random Number Generators, QRNG)**. 

Квантовий білий шум утворюється на фундаментальному квантовомеханічному рівні при розщепленні одиночних фотонів на напівпрозорому світлодільнику, де ймовірність проходження чи відбиття фотона дорівнює строго `50%`. Іншим фізичним принципом є вимірювання флуктуацій фази вакуумного стану світла за допомогою гомодинного детектування. Квантовий шум є принципово детерміновано непередбачуваним і створює ідеальний гауссів білий шум із максимальною ентропією, що відповідає найсуворішим криптографічним стандартам (NIST SP 800-90B та AIS-31).

Сучасні генератори квантового білого шуму інтегруються в єдиному напівпровідниковому чипі (Photonic Integrated Circuit, PIC). Вони забезпечують швидкість генерації ентропії понад `1 Гбіт/с`, що дозволяє використовувати квантовий білий шум у хмарних центрах обробки даних та критичній інфраструктурі в реальному часі. Використання таких компонентів дозволяє проводити генерацію криптографічно стійких ключів та чисельне моделювання квантових флуктуацій у складних фізичних системах із безпрецедентною точністю та високою швидкістю обробки даних.

### Апаратна реалізація БПФ у системах реального часу (DSP та FPGA)

При розробці вбудованих систем обробки сигналів на базі цифрових сигнальних процесорів (DSP) або ПЛІС (FPGA) обчислення спектральної щільності шуму реалізують з урахуванням апаратних обмежень:

1. **Арифметика з фіксованою комою (Fixed-Point Arithmetic):**
   У недорогих DSP та FPGA обчислення виконуються в розрядній сітці `16` або `24` біт. Для запобігання арифметичному переповненню під час виконання операцій додавання у метеликах БПФ застосовують алгоритм арифметичного зсуву праворуч (`>> 1`) на кожному ітераційному каскаді БПФ. Отриманий спектр масштабується на множник `2^K`, де `K = log₂ N`.

2. **Таблиці поворотних множників (Twiddle Factor LUT):**
   Обчислення значень `cos(2πk/N)` та `sin(2πk/N)` у реальному часі на кожній ітерації є занадто повільним. Тому поворотні множники обчислюють заздалегідь на етапі компіляції та зберігають у швидкій внутрішній пам'яті ROM або Block RAM ПЛІС.

3. **Конвеєризація та подвійна буферизація (Ping-Pong Buffering):**
   Для забезпечення безперервного аналізу вхідного потоку даних без пропуску відліків (Zero-Gap Processing) використовують два масиви оперативної пам'яті. Поки Direct Memory Access (DMA) контролер записує нові відліки з АЦП у перший буфер («Ping»), процесор або апаратний ядро БПФ обробляє та усереднює дані у другому буфері («Pong»). На наступному кроці буфери міняються ролями.

### Формування забарвлених шумів із гауссового білого шуму

Проходження гауссового білого шуму `x[n]` через цифровий рекурсивний FIR або IIR фільтр змінює його спектр у відповідності до передавальної функції фільтра `H(z)`.

#### 2. Генерація коричневого шуму (Brownian Noise, 1/f²)
Коричневий (або червоний) шум утворюється простим цифровим інтегруванням білого шуму, що моделює випадкове блукання броунівської частинки:

```
y[n] = y[n - 1] + x[n]
```

Для запобігання постійного дрейфу й виходу з ладу динамічного діапазону застосовують фільтр із витіканням (leaky integrator): `y[n] = 0.99 · y[n - 1] + x[n]`.

### Тестування та верифікація білого шуму

При розробці генераторів псевдовипадкового білого шуму для фізичного моделювання застосовують три обов'язкові статистичні перевірки:

#### 1. Перевірка нормальності розподілу (Тест хі-квадрат)
Згенеровану послідовність `x[n]` розбивають на `M` інтервалів (гістограму) і порівнюють експериментальні частоти влучання `O_i` з теоретичними ймовірностями `E_i` для гауссової щільності:
```
χ² = ∑_{i=1}^{M} (O_i - E_i)² / E_i
```
Якщо обчислене значення `χ²` перевищує критичне значення для `M - 3` ступенів вільності при рівні значущості `α = 0.05`, то генератор відхиляється як такий, що не відповідає гауссовому розподілу.

#### 2. Перевірка некорельованості (Тест Люнга — Бокса)
Для перевірки відсутності статистичної пам'яті у згенерованій послідовності обчислюють статистику Люнга — Бокса (Ljung-Box test) за першими `m` лагами автокореляції:
```
Q = N · (N + 2) · ∑_{k=1}^{m} R_d²[k] / (N - k)
```
Для ідеального білого шуму статистика `Q` має розподіл `χ²` з `m` ступенями вільності. Якщо `Q` перевищує критичну межу, у генераторі є прихована періодичність або кореляція.

#### 3. Тест на плоскість спектра (Spectral Flatness Test)
Спектральна плоскість (Spectral Flatness або Wiener entropy) обчислюється як відношення геометричного середнього спектральної щільності до її арифметичного середнього:
```
Flatness = exp[ (1 / N_f) · ∑_{k=0}^{N_f-1} ln( G[k] ) ] / [ (1 / N_f) · ∑_{k=0}^{N_f-1} G[k] ]
```
Для ідеального білого шуму спектральна плоскість тотожно дорівнює `1.0`. Для забарвлених шумів та тональних сигналів це значення прямує до `0.0`.

### Алгоритмічна складність та оптимізація продуктивності

Для обчислення спектральної щільності сигналів великої тривалості (наприклад, супутникових або гідроакустичних записів) кричуще важливу роль відіграє обчислювальна складність:

1. **Пряме обчислення ДПФ (DFT):**
   Має складність `O(N²)`. Для масиву тривалістю `N = 10⁶` відліків обчислення вимагає порядку `10¹²` комплексних операцій множення, що займає кілька хвилин екранного часу навіть на потужних процесорах.

2. **Швидке Перетворення Фурьє (FFT):**
   Завдяки розділенню масиву на парні й непарні елементи за схемою Кулі — Тьюкі складність зменшується до `O(N · log₂ N)`. Для `N = 10⁶` це вимагає всього близько `2 × 10⁷` операцій, що виконується за лічені мілісекунди.

3. **Векторизація та використання SIMD:**
   У промислових C/C++ бібліотеках (наприклад, FFTW або Intel MKL) циклічні метелики БПФ розпаралелюються за допомогою векторних інструкцій AVX-512 та FMA, що дає додаткове 4-8 кратне прискорення обчислень на сучасних процесорних архітектурах. Для оптимальної вибірки даних масиви комплексної пам'яті вирівнюють за межами 64 байтів (пам'ять кеш-лінії).
