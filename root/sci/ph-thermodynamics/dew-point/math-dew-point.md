# 🧮 Математичний апарат точки роси: від Клапейрона-Клаузіуса до формул Магнуса та Тетенса

Математичний опис фазового переходу між водяною парою та рідким конденсатом базується на законах класичної термодинаміки та емпіричних апроксимаціях тиску насичення. У цій вставці наведено послідовний математичний вивід виразів для тиску насиченої пари, аналітичне виведення температури точки роси та розрахунок термодинамічного бар'єра зародкоутворення крапель (рівняння Кельвіна).

## 1. Термодинамічна рівновага та рівняння Клапейрона — Клаузіуса

Фазова рівновага між рідкою водою та її насиченою парою визначається рівністю їхніх молярних термодинамічних потенціалів Гіббса (хімічних потенціалів): `μ_liq(T, p) = μ_gas(T, p)`. При малій зміні температури `dT` та відповідній зміні тиску насичення `dp_sat` уздовж кривої рівноваги приріст потенціалів обох фаз має залишатися однаковим:

```
dμ_liq = dμ_gas                        [умова збереження фазової рівноваги]
- s_liq · dT + v_liq · dp_sat = - s_gas · dT + v_gas · dp_sat  [диференціал хімічного потенціалу]
(v_gas - v_liq) · dp_sat = (s_gas - s_liq) · dT                 [групування доданків]
```

де `s` — молярна ентропія, `v` — молярний об'єм відповідної фази.

Оскільки зміна ентропії при ізотермічному фазовому переході зв'язана з молярною прихованою теплотою випаровування `L_v` співвідношенням `s_gas - s_liq = L_v / T`, отримуємо точне диференціальне рівняння Клапейрона — Клаузіуса:

```
dp_sat / dT
= L_v / (T · (v_gas - v_liq))        [рівняння Клапейрона — Клаузіуса]
```

де `L_v` — питома молярна теплота випаровування води (приблизно 40.65 кДж/моль при 100 °C або 44.0 кДж/моль при 25 °C), `v_gas` та `v_liq` — молярні об'єми газоподібної та рідкої фаз відповідно.

Оскільки за умов низьких тисків (поблизу атмосферного) молярний об'єм пари на три порядки перевищує об'єм рідини (`v_gas >> v_liq`), величиною `v_liq` можна знехтувати. Вважаючи пару ідеальним газом, підставимо `v_gas = R_v · T / p_sat`:

```
dp_sat / dT
= L_v / (T · (R_v · T / p_sat))      [знехтували v_liq та виразили v_gas]
= L_v · p_sat / (R_v · T²)           [спрощення дробу]
```

Перенесемо тиск у ліву частину для розділення змінних:

```
(1 / p_sat) · (dp_sat / dT)
= d(ln p_sat) / dT
= L_v / (R_v · T²)                   [диференціальна форма рівняння]
```

Проінтегруємо отриманий вираз від початкового стану `(T_0, p_0)` до поточного `(T, p_sat)`, припускаючи, що теплота випаровування `L_v` є сталою у розглянутому температурному інтервалі:

```
∫[p_0..p_sat] d(ln p)
= ∫[T_0..T] (L_v / R_v) · (dT / T²)  [інтегрування обох частин]

ln(p_sat / p_0)
= (L_v / R_v) · (1/T_0 - 1/T)        [первісна від 1/T² дорівнює -1/T]

p_sat(T)
= p_0 · exp( (L_v / R_v) · (1/T_0 - 1/T) )  [потенціювання]
```

Це теоретичне рівняння добре описує якісний експоненційний характер зростання тиску насичення, проте не враховує слабку температурну залежність `L_v(T)`. За законом Кірхгофа термохімії теплота випаровування змінюється з температурою як `L_v(T) = L_0 - (c_pl - c_pv) · T`, де `c_pl` та `c_pv` — ізобарні теплоємності рідкої та газоподібної води. Враховуючи це, інтегрування приводить до трипараметричного рівняння Антуана `ln p_sat = A - B / (T + C)`.

## 2. Формули Магнуса, Тетенса та Бака

Німецький фізик Генріх Магнус у 1844 році запропонував напівемпіричне співвідношення для обчислення тиску насиченої пари води `p_sat` (у кілопаскалях, кПа) за температури `T` (у градусах Цельсія, °C):

```
p_sat(T)
= a · exp( (b · T) / (c + T) )       [формула Магнуса — Тетенса]
```

Стандартні конфігураційні коефіцієнти (за даними WMO — Всесвітньої метеорологічної організації для діапазону від -40 °C до +50 °C над рідкою водою):

```
a = 0.61078  кПа  (610.78 Па)
b = 17.27
c = 237.3    °C
```

Якщо конденсація відбувається при субнульових температурах у формі інею (кристалізація пара → лід), використовують коефіцієнти для сублімації над поверхнею льоду:

```
a_ice = 0.61078  кПа
b_ice = 21.875
c_ice = 265.5    °C
```

Для прецизійних розрахунків аерокосмічних і лабораторних систем застосовують модифіковане рівняння Ардена Бака (Arden Buck, 1981/1996), яке враховує фактор стисливості вологого повітря `f(p)` при атмосферному тиску `p_atm`:

```
p_sat_buck(T)
= 0.61121 · exp( (18.678 - T / 234.5) · T / (257.14 + T) )

p_v_real
= p_sat_buck(T) · f(p)               [корекція на барометричний тиск]
```

де `f(p) = 1 + 10⁻⁴ · (7.2 + p_atm · (0.0353 + 0.0000000000000000001 · T²))` для звичайного повітря під тиском `p_atm` у гектопаскалях (гПа).

## 3. Точний аналітичний вивід температури точки роси

Відносна вологість повітря `RH` (у відсотках, %) визначається як відношення поточного парціального тиску водяної пари `p_v` до тиску насичення `p_sat(T)` при даній температурі повітря `T`:

```
RH = (p_v / p_sat(T)) · 100%
p_v = (RH / 100) · p_sat(T)
```

За означенням, температура точки роси `T_d` — це така температура, до якої треба ізобарно охолодити повітря, щоб поточний тиск пари `p_v` став тиском насичення: `p_sat(T_d) = p_v`.

Підставимо формулу Магнуса у співвідношення для `p_v`:

```
p_sat(T_d) = p_v
a · exp( (b · T_d) / (c + T_d) ) = (RH / 100) · a · exp( (b · T) / (c + T) )
```

Поділимо обидві частини на `a` та прологарифмуємо:

```
(b · T_d) / (c + T_d)
= ln(RH / 100) + (b · T) / (c + T)
```

Позначимо праву частину рівняння як допоміжний параметр `α(T, RH)`:

```
α(T, RH) = (b · T) / (c + T) + ln(RH / 100)
```

Тепер рівняння набуває простого алгебраїчного вигляду відносно невідомої `T_d`:

```
(b · T_d) / (c + T_d) = α
b · T_d = α · (c + T_d)              [помножили на знаменник]
b · T_d = α · c + α · T_d            [розкрили дужки]
T_d · (b - α) = c · α                [перенесли доданки з T_d вліво]
T_d = (c · α) / (b - α)              [точна формула точки роси]
```

### Числовий приклад розрахунку

Нехай температура повітря `T = 25.0 °C`, а відносна вологість `RH = 50.0%`.

```
1. Обчислюємо (b · T) / (c + T):
   17.27 · 25.0 / (237.3 + 25.0)
   = 431.75 / 262.3
   = 1.646016

2. Обчислюємо ln(RH / 100):
   ln(50.0 / 100) = ln(0.5) = -0.693147

3. Обчислюємо параметр α:
   α = 1.646016 - 0.693147 = 0.952869

4. Знаходимо T_d:
   T_d = (237.3 · 0.952869) / (17.27 - 0.952869)
   = 226.1158 / 16.317131
   = 13.857 °C
```

Отже, при 25 °C та 50% вологості конденсація розпочнеться на будь-якій поверхні, охолодженій до 13.86 °C або нижче.

## 4. Рівняння Кельвіна та зародкоутворення крапель

Сформована сферична крапля радіуса `r` має викривлену поверхню розділу фаз. Завдяки поверхневому натягу `γ` усередині краплі виникає додатковий капілярний тиск Лапласа: `ΔP = 2·γ / r`.

Це спричиняє збільшення тиску насиченої пари над опуклою поверхнею краплі `p_r` порівняно з тиском над плоскою поверхнею `p_sat`. Рівняння Кельвіна описує цей ефект:

```
ln(p_r / p_sat)
= (2 · γ · V_m) / (r · R · T)        [рівняння Кельвіна]

p_r = p_sat · exp( (2 · γ · V_m) / (r · R · T) )
```

де `V_m` — молярний об'єм рідкої води (1.8 · 10⁻⁵ м³/моль), `γ` — коефіцієнт поверхневого натягу води (0.0728 Н/м при 20 °C), `R` — універсальна газова стала (8.314 Дж/(моль·К)).

З рівняння Кельвіна випливає концепція **критичного радіуса зародка** `r_c`. Якщо пара є перенасиченою із ступенем перенасичення `S = p_v / p_sat > 1`, то вільна енергія Гіббса утворення краплі `ΔG(r)` має максимум при:

```
r_c = (2 · γ · V_m) / (R · T · ln S)  [критичний радіус краплі]
```

Краплі з радіусом `r < r_c` мають тиск насичення `p_r > p_v` і неминуче випаровуються. Краплі з `r > r_c` мають `p_r < p_v` і неконтрольовано зростають, перетворюючись на видимий туман чи росу.

Висота термодинамічного бар'єра гомогенного зародкоутворення дорівнює:

```
ΔG* = (4/3) · π · r_c² · γ           [енергетичний бар'єр Гіббса]
```

При гетерогенній конденсації на твердій поверхні з кутом змочування `θ` бар'єр знижується в `f(θ)` разів:

```
f(θ) = (2 + cos θ) · (1 - cos θ)² / 4
```

Для повністю змочуваної поверхні (`θ → 0`) коефіцієнт `f(θ) → 0`, що пояснює, чому реальна конденсація на стінках відбувається миттєво при досягненні 100% відносної вологості (`S = 1`), без необхідності гігантського перенасичення.

## 5. Порівняльний аналіз математичних моделей та похибок

Для вибору оптимальної моделі при проектуванні програмних систем порівняємо похибки різних формул тиску насичення `p_sat(T)` у діапазоні від -40 °C до +60 °C відносно еталонного фундаментального рівняння стану IAPWS-95 (International Association for the Properties of Water and Steam):

1. **Просте рівняння Клапейрона — Клаузіуса (`L_v = const`):** Середня абсолютна похибка становить 3.5–5.0%, що занадто багато для прецизійної метеорології.
2. **Класична формула Магнуса — Тетенса:** Відносна похибка обчислення тиску насичення не перевищує ±0.3% у діапазоні від 0 °C до +50 °C, що дає похибку точки роси не більше ±0.1 °C.
3. **Модель Ардена Бака (Arden Buck, 1996):** Відносна похибка не перевищує ±0.05% у широкому діапазоні від -40 °C до +50 °C, враховуючи барометричний тиск суміші.
4. **Рівняння Ґоффа — Ґретча (Goff-Gratch, WMO standard):** Шестипараметрична математична модель з поліноміальними логарифмічними членами. Воно забезпечує похибку менше ±0.01%, проте вимагає значних ресурсів процесора через велику кількість піднесень до степеня.
