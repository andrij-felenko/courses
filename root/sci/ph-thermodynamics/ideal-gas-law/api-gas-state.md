# 📋 Інтерфейс та параметри розрахунку термодинамічного стану газу

У цій специфікації наведено довідкові фізичні константи, одиниці вимірювання, поправкові параметри реальних газів Ван-дер-Ваальса та програмний інтерфейс (API) бібліотеки розрахунку параметрів стану газу для інженерних засобів обчислення.

## 1. Фундаментальні константи та одиниці вимірювання

Розрахунки стану газових систем у термодинаміці спираються на фундаментальні фізичні константи, що пов'язують макроскопічні вимірювані величини (тиск, об'єм, температуру) із мікроскопічними параметрами окремих молекул.

Універсальна газова стала `R = 8.314462618 Дж / (моль · К)` визначає роботу розширення одного моля ідеального газу при ізобарному нагріванні на один Кельвів. Вона виступає сполучною ланкою між термодинамікою та хімічною кінетикою. Фізичний зміст універсальної газової сталої випливає з добутку двох мікроскопічних констант: сталої Больцмана `k_B` та числа Авогадро `N_A`.

Стала Больцмана `k_B = 1.380649 · 10⁻²³ Дж / К` є фундаментальним квантовим та статистичним масштабуючим коефіцієнтом, який переводить абсолютну температуру за шкалою Кельвіна у величину енергії на один ступінь вільності. Вона задає зв'язок між середовищною енергією хаотичного руху частинок та макроскопічною температурою термодинамічної системи.

Число Авогадро `N_A = 6.02214076 · 10²³ моль⁻¹` фіксує дискретне число атомарних чи молекулярних структурних елементів у одному молі речовини. Молярний об'єм ідеального газу за стандартних термодинамічних умов (`T = 273.15 K`, `P = 101325 Pa`) становить `V_m0 = 0.02241397 м³ / моль` (або `22.414 літрів на моль`).

| Константа / Величина | Позначення | Значення (СІ) | Опис та розмірність |
| :--- | :--- | :--- | :--- |
| Універсальна газова стала | `R` | `8.314462618` | `Дж / (моль · К)` |
| Стала Больцмана | `k_B` | `1.380649 · 10⁻²³` | `Дж / К` |
| Число Авогадро | `N_A` | `6.02214076 · 10²³` | `моль⁻¹` |
| Молярний об'єм ідеального газу | `V_m0` | `0.02241397` | `м³ / моль` (при `T = 273.15 K`, `P = 101325 Pa`) |
| Стандартний атмосферний тиск | `P_std` | `101325` | `Па` (`1.0 atm`) |
| Стандартна температура | `T_std` | `273.15` | `К` (`0.0 °C`) |

### Коефіцієнти переведення одиниць тиску та об'єму

Для забезпечення сумісності з міжнародними інженерними стандартами, промисловими вимірювальними приладами та цифровими давачами тиску специфікація визначає суворі співвідношення між різними одиницями вимірювання.

Один Паскаль (`1 Па = 1 Н/м²`) є базова одиниця тиску в міжнародній системі СІ, яка описує розподілений нормальний розподіл сили в один Ньютон на площу один квадратний метр. У промисловій автоматиці та гідравліці часто використовують бар (`1 бар = 100 000 Па`), який за величиною близький до нормального атмосферного тиску. Стандартна фізична атмосфера (`1 атм = 101 325 Па`) дорівнює усередненому тиску земної атмосфери на рівні моря. У вакуумній техніці традиційно використовують міліметри ртутного стовпчика (`1 Торр = 133.322 Па`). Одиниці об'єму виражаються в кубічних метрах (`м³`) та літрах (`1 Л = 0.001 м³`).

```
1 Па (Паскаль)     = 1 Н / м²
1 бару (bar)       = 100 000 Па = 10⁵ Па
1 атм (атмосфера)  = 101 325 Па
1 мм рт. ст. (Torr)= 133.322368 Па
1 літр (Л)         = 10⁻³ м³ = 0.001 м³
```

## 2. Поправкові параметри реальних газів Ван-дер-Ваальса

Для розрахунку відхилень від рівняння ідеального газу при підвищеному тиску та низьких температурах використовується рівняння Ван-дер-Ваальса:

```
(P + a / V_m²) · (V_m − b) = R · T
```

Фізичний зміст коефіцієнта `a` полягає у врахуванні міжмолекулярного притягання (так званого внутрішнього чи когезійного тиску). Коли молекули рухаються всередині об'єму газу, сила притягання з боку сусідніх частинок компенсується з усіх боків. Проте коли молекула наближається до стінки посудини, сумарне міжмолекулярне притягання з боку товщі газу направлене всередину. Це зменшує нормальну швидкість зіткнення та знижує вимірюваний тиск на стінку на величину `a / V_m²`. Чим більша поляризованість та дипольний момент молекули, тим вищим є значення `a`. Для інертного гелію `He` коефіцієнт притягання є найменшим серед усіх речовин (`a = 0.00346 Па·м⁶/моль²`), оскільки його електронна оболонка є сферично симетричною та важко поляризовною. Натомість для полярних молекул водяної пари `H₂O` значення `a` є дуже високим (`a = 0.5536 Па·м⁶/моль²`) через наявність сильних постійних диполів та водневих зв'язків.

Коефіцієнт `b` характеризує власний несжимаємий об'єм моля молекул (так званий об meзований об'єм). У геометричному наближенні твердих сфер коефіцієнт `b` дорівнює чотирикратному власному об'єму молекул (`b = 4 · N_A · (4/3)·π·r³`). Великі багатоатомні молекули (такі як пропан `C₃H₈` чи етан `C₂H₆`) мають значні геометричні розміри, що відображається у високих значеннях `b` (`b = 9.05 · 10⁻⁵ м³/моль` для пропану проти `2.37 · 10⁻⁵ м³/моль` для гелію).

## 3. Алгоритм розв'язання кубічного рівняння Ван-дер-Ваальса

При відомих тиску `P` та температурі `T` розрахунок молярного об'єму `V_m` газу Ван-дер-Ваальса зводиться до розв'язання кубічного рівняння відносно `V_m`:

```
V_m³ − (b + (R · T) / P) · V_m² + (a / P) · V_m − (a · b) / P = 0
```

Математичний аналіз цього рівняння показує два принципово різних фізичних режими залежно від температури системи:

1. **Надкритичний режим (`T > T_c`):** Рівняння має один дійсний корінь `V_m`, який відповідає однорідній газуватій фазі. У цьому стані речовина не може бути перетворена на рідину за жодного зовнішнього тиску, оскільки кінетична енергія молекул перевищує глибину потенціальної ями притягання.
2. **Двофазний докритичний режим (`T < T_c`):** При тиску рівноваги фаз рівняння має три дійсних корені. Найменший корінь відповідає молярному об'єму рідкої фази `V_{liquid}`, найбільший — молярному об'єму насиченої пари `V_{vapor}`, а середній є математично нестійким розв'язком, якому відповідає від'ємна стискуваність (`∂P/∂V > 0`), що фізично нереалізуємо в природі.

Для обчислення дійсних коренів застосовується аналітичний метод Кардано або чисельний метод Ньютона — Рафсона з початковим наближенням ідеального газу `V_m^{(0)} = (R · T) / P`.

## 4. Специфікація програмного інтерфейсу (API)

Програмний інтерфейс розроблено з дотриманням принципів найменшого здивування та суворої перевірки вхідних даних. Модульна структура дозволяє виконувати розрахунки як для ідеального газу, так і для реальних газів із поправками Ван-дер-Ваальса.

Всі функції API виконують попередню валідацію термодинамічних параметрів:
- **Перевірка маси та молярної маси:** Маса `m` та молярна маса `M` повинні бути строго додатними величинами (`m > 0`, `M > 0`). Спроба передати нульову чи від'ємну масу повертає помилку розрахунку.
- **Перевірка абсолютної температури:** Температура `T` виражається виключно в Кельвінах і повинна перевищувати абсолютний нуль (`T > 0 K`).
- **Перевірка допустимого об'єму:** При розрахунку реального газу Ван-дер-Ваальса молярний об'єм `V_m` повинен строго перевищувати власний об'єм молекул `b` (`V_m > b`). Якщо об'єм посудини менший за `b`, обчислення тиску повертає помилку через фізичну неможливість стиснення твердих ядер молекул.

Нижче подано декларацію структур даних та функцій мовами C та C++.

```cpp
#pragma once

#include <string>
#include <optional>
#include <stdexcept>
#include <span>

namespace physics::thermodynamics {

constexpr double R_GAS_CONST = 8.314462618;
constexpr double KB_BOLTZMANN = 1.380649e-23;
constexpr double NA_AVOGADRO = 6.02214076e23;

enum class GasType {
    Ideal,
    Helium,
    Hydrogen,
    Nitrogen,
    Oxygen,
    Air,
    CO2,
    Methane,
    WaterVapor
};

struct VanDerWaalsParams {
    double a_pa_m6_mol2; // Па·м⁶/моль²
    double b_m3_mol;     // м³/моль
    double molar_mass;   // кг/моль
};

class GasState {
public:
    GasState(double mass_kg, double molar_mass_kg_mol, GasType type = GasType::Ideal)
        : mass_kg_(mass_kg), molar_mass_(molar_mass_kg_mol), type_(type) {
        if (mass_kg <= 0.0 || molar_mass_kg_mol <= 0.0) {
            throw std::invalid_argument("Маса та молярна маса повинні бути додатними!");
        }
    }

    double moles() const noexcept { return mass_kg_ / molar_mass_; }
    double mass() const noexcept { return mass_kg_; }
    double molar_mass() const noexcept { return molar_mass_; }
    GasType type() const noexcept { return type_; }

    // Обчислення тиску за рівнянням ідеального газу
    double solve_pressure(double volume_m3, double temp_k) const {
        check_positive(volume_m3, temp_k);
        return (moles() * R_GAS_CONST * temp_k) / volume_m3;
    }

    // Обчислення об'єму за рівнянням ідеального газу
    double solve_volume(double pressure_pa, double temp_k) const {
        check_positive(pressure_pa, temp_k);
        return (moles() * R_GAS_CONST * temp_k) / pressure_pa;
    }

    // Обчислення температури за рівнянням ідеального газу
    double solve_temperature(double pressure_pa, double volume_m3) const {
        check_positive(pressure_pa, volume_m3);
        return (pressure_pa * volume_m3) / (moles() * R_GAS_CONST);
    }

    // Обчислення тиску за рівнянням Ван-дер-Ваальса
    double solve_vdw_pressure(double volume_m3, double temp_k, const VanDerWaalsParams& params) const {
        check_positive(volume_m3, temp_k);
        double n = moles();
        double v_m = volume_m3 / n; // Молярний об'єм
        if (v_m <= params.b_m3_mol) {
            throw std::domain_error("Молярний об'єм менший за власний об'єм молекул b!");
        }
        double term1 = (R_GAS_CONST * temp_k) / (v_m - params.b_m3_mol);
        double term2 = params.a_pa_m6_mol2 / (v_m * v_m);
        return term1 - term2;
    }

    // Коефіцієнт стискуваності Z = P * V / (n * R * T)
    static double compressibility_factor(double pressure_pa, double volume_m3, double moles, double temp_k) {
        return (pressure_pa * volume_m3) / (moles * R_GAS_CONST * temp_k);
    }

private:
    static void check_positive(double a, double b) {
        if (a <= 0.0 || b <= 0.0) {
            throw std::invalid_argument("Термодинамічні параметри повинні бути строго додатними!");
        }
    }

    double mass_kg_;
    double molar_mass_;
    GasType type_;
};

} // namespace physics::thermodynamics
```

## 5. Область застосування та межі похибки

Рівняння ідеального газу Клапейрона — Менделєєва забезпечує високу точність розрахунків (відносна похибка обчислення тиску чи об'єму менше `1%`) за дотримання двох інженерних критеріїв:

1. **Критерій помірного тиску:** Знічний зовнішній тиск `P` не перевищує `10` атмосфер (`1.0 МПа`). При вищих тисках середня відстань між молекулами скорочується, і власний об'єм молекул `b` дає відчутне зростання вимірюваного тиску.
2. **Критерій температури:** Робоча температура `T` системи суттєво перевищує критичну температуру зрідження даного газу (`T > 1.5 · T_c`). При наближенні до `T_c` сили міжмолекулярного притягання викликають утворення локальних асоціатів та кластерів молекул, що знижує фактичний тиск порівняно з ідеальним розрахунком.

При тисках понад `5–10 МПа` або при наближенні температури до точки роси необхідно застосовувати поправки Ван-дер-Ваальса чи розраховувати коефіцієнт стискуваності `Z(P, T)`. Для надвисоких тисків (понад `100 МПа`) в промисловості використовують розширені віріальні рівняння стану Редліха — Квонга чи Пенга — Робінсона.
