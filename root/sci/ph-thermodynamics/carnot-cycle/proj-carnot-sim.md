# ⚙️ Чисельне моделювання та розрахунок параметрів циклу Карно

У цій практичній вставці наведено алгоритм чисельного розрахунку термодинамічних станів, роботи, підведеного та відведеного тепла, а також ККД і теплових коефіцієнтів прямого та зворотного циклів Карно мовами Python та C++.

## Фізико-математична модель та постановка задачі

Чисельне моделювання циклу Карно з ідеальним газом є важливим інструментом для кількісної оцінки термодинамічної ефективності енергетичних систем. У той час як теоретичні формули дають загальні аналітичні залежності, програмний розрахунок дозволяє отримати точні значення тиску, об'єму та температури у кожній із чотирьох точок циклу, а також вирахувати баланс енергетичних потоків для довільних робочих тіл та реальних умов експлуатації.

Математична модель спирається на рівняння стану ідеального газу Клапейрона-Менделєєва та рівняння адіабати Пуассона. Система визначається сукупністю початкових термодинамічних параметрів та фізичних властивостей робочого газу.

Вхідні параметри моделі:
- `n` — кількість речовини газу, моль;
- `T_H` — температура гарячого джерела (нагрівача), К;
- `T_C` — температура холодного джерела (холодильника), К;
- `P_1` — початковий тиск у точці 1 (початок ізотермічного розширення), Па;
- `V_1` — початковий об'єм у точці 1, м³;
- `r_v` — ступінь ізотермічного розширення `r_v = V_2 / V_1 > 1`;
- `gamma` — показник адіабати `γ = C_p / C_v` (1.667 для одноатомних газів, таких як гелій або аргон; 1.400 для двоатомних газів, таких як азот або кисень).

## Математичний алгоритм обчислення точок циклу

Програма послідовно розраховує чотири вектори термодинамічного стану `(P, V, T)` у вершинах контуру циклу:

1. **Вершина 1 (Початок ізотермічного розширення при температурі T_H):**
   Початковий стан визначається заданими вхідними значеннями:
   - `T_1 = T_H`
   - `V_1` задано
   - `P_1` задано (або обчислюється через рівняння стану `P_1 = n · R · T_H / V_1`)

2. **Вершина 2 (Кінець ізотермічного розширення при T_H):**
   Газ розширюється при постійній температурі в `r_v` разів:
   - `T_2 = T_H`
   - `V_2 = V_1 · r_v`
   - `P_2 = P_1 / r_v`

3. **Вершина 3 (Кінець адіабатичного розширення при температурі T_C):**
   Газ розширюється без обміну теплом із довкіллям. Співвідношення об'ємів визначається з рівняння адіабати Пуассона `T_H · V_2^(γ - 1) = T_C · V_3^(γ - 1)`:
   - `T_3 = T_C`
   - `V_3 = V_2 · (T_H / T_C)^(1 / (γ - 1))`
   - `P_3 = (n · R · T_C) / V_3`

4. **Вершина 4 (Кінець ізотермічного стискання / Початок адіабатичного стискання):**
   Газ стискається при температурі холодильника `T_C`. Точка 4 лежить на тій самій адіабаті, що й точка 1 (`T_C · V_4^(γ - 1) = T_H · V_1^(γ - 1)`):
   - `T_4 = T_C`
   - `V_4 = V_1 · (T_H / T_C)^(1 / (γ - 1))`
   - `P_4 = (n · R · T_C) / V_4`

### Розрахунок енергетичних характеристик

Після визначення координат усіх чотирьох вершин алгоритм обчислює інтегральні енергетичні параметри циклу:

- **Підведена теплота від нагрівача `Q_H`:**
  `Q_H = n · R · T_H · ln(r_v)`
- **Скинута теплота в холодильник `Q_C`:**
  `Q_C = n · R · T_C · ln(r_v)`
- **Корисна механічна робота `W`:**
  `W = Q_H - Q_C = n · R · (T_H - T_C) · ln(r_v)`
- **Термічний ККД прямого циклу `η`:**
  `η = 1 - T_C / T_H`
- **Холодильний коефіцієнт (COP refrigeration) зворотної машини:**
  `COP_ref = T_C / (T_H - T_C)`
- **Опалювальний коефіцієнт (COP heating) теплового насоса:**
  `COP_heat = T_H / (T_H - T_C)`

import math
from dataclasses import dataclass
from typing import List, Tuple

R_GAS = 8.314462618  # Універсальна газова стала, Дж/(моль·К)

@dataclass
class StatePoint:
    name: str
    pressure_pa: float
    volume_m3: float
    temp_k: float

@dataclass
class CarnotResults:
    points: List[StatePoint]
    q_h_j: float
    q_c_j: float
    work_j: float
    efficiency: float
    cop_ref: float
    cop_heat: float

def simulate_carnot_cycle(
    n_moles: float,
    t_h: float,
    t_c: float,
    p1_pa: float,
    v1_m3: float,
    r_v: float,
    gamma: float = 1.4
) -> CarnotResults:
    """Обчислює чотири стани та енергетичні параметри циклу Карно."""
    if t_c <= 0 or t_h <= 0:
        raise ValueError("Температури повинні бути строго додатними в Кельвінах")
    if t_c >= t_h:
        raise ValueError("Температура холодильника T_C мусить бути меншою за T_H")
    if r_v <= 1.0:
        raise ValueError("Ступінь розширення r_v мусить бути більшим за 1.0")

    # Точка 1
    p1, v1 = p1_pa, v1_m3
    
    # Точка 2: ізотермічне розширення при T_H
    v2 = v1 * r_v
    p2 = p1 / r_v
    
    # Точка 3: адіабатичне розширення до T_C
    vol_ratio_adiabat = (t_h / t_c) ** (1.0 / (gamma - 1.0))
    v3 = v2 * vol_ratio_adiabat
    p3 = (n_moles * R_GAS * t_c) / v3
    
    # Точка 4: ізотермічне стискання при T_C
    v4 = v1 * vol_ratio_adiabat
    p4 = (n_moles * R_GAS * t_c) / v4

    points = [
        StatePoint("1 (Початок розширення)", p1, v1, t_h),
        StatePoint("2 (Кінець ізотерми T_H)", p2, v2, t_h),
        StatePoint("3 (Кінець адіабати)", p3, v3, t_c),
        StatePoint("4 (Кінець ізотерми T_C)", p4, v4, t_c),
    ]

    # Енергетичні величини
    q_h = n_moles * R_GAS * t_h * math.log(r_v)
    q_c = n_moles * R_GAS * t_c * math.log(r_v)
    work = q_h - q_c
    
    efficiency = 1.0 - (t_c / t_h)
    cop_ref = t_c / (t_h - t_c)
    cop_heat = t_h / (t_h - t_c)

    return CarnotResults(points, q_h, q_c, work, efficiency, cop_ref, cop_heat)

#include <iostream>
#include <vector>
#include <cmath>
#include <string>
#include <iomanip>
#include <stdexcept>

constexpr double R_GAS = 8.314462618; // Універсальна газова стала, Дж/(моль·К)

struct StatePoint {
    std::string name;
    double pressure_pa;
    double volume_m3;
    double temp_k;
};

struct CarnotResults {
    std::vector<StatePoint> points;
    double q_h_j;
    double q_c_j;
    double work_j;
    double efficiency;
    double cop_ref;
    double cop_heat;
};

CarnotResults simulate_carnot_cycle(
    double n_moles,
    double t_h,
    double t_c,
    double p1_pa,
    double v1_m3,
    double r_v,
    double gamma = 1.4)
{
    if (t_c <= 0.0 || t_h <= 0.0) {
        throw std::invalid_argument("Температури мають бути строго додатними в Кельвінах");
    }
    if (t_c >= t_h) {
        throw std::invalid_argument("T_C має бути меншою за T_H");
    }
    if (r_v <= 1.0) {
        throw std::invalid_argument("r_v має бути більшим за 1.0");
    }

    double p1 = p1_pa;
    double v1 = v1_m3;

    double v2 = v1 * r_v;
    double p2 = p1 / r_v;

    double vol_ratio_adiabat = std::pow(t_h / t_c, 1.0 / (gamma - 1.0));
    double v3 = v2 * vol_ratio_adiabat;
    double p3 = (n_moles * R_GAS * t_c) / v3;

    double v4 = v1 * vol_ratio_adiabat;
    double p4 = (n_moles * R_GAS * t_c) / v4;

    std::vector<StatePoint> points = {
        {"1 (Початок розширення)", p1, v1, t_h},
        {"2 (Кінець ізотерми T_H)", p2, v2, t_h},
        {"3 (Кінець адіабати)", p3, v3, t_c},
        {"4 (Кінець ізотерми T_C)", p4, v4, t_c}
    };

    double q_h = n_moles * R_GAS * t_h * std::log(r_v);
    double q_c = n_moles * R_GAS * t_c * std::log(r_v);
    double work = q_h - q_c;

    double efficiency = 1.0 - (t_c / t_h);
    double cop_ref = t_c / (t_h - t_c);
    double cop_heat = t_h / (t_h - t_c);

    return CarnotResults{points, q_h, q_c, work, efficiency, cop_ref, cop_heat};
}

int main() {
    try {
        CarnotResults res = simulate_carnot_cycle(1.0, 600.0, 300.0, 1e6, 0.0025, 2.0, 1.667);

        std::cout << std::fixed << std::setprecision(3);

        std::cout << "COP холодильника      : " << res.cop_ref << "\n";
        std::cout << "COP теплового насоса  : " << res.cop_heat << "\n";

        return 1;
    }
    return 0;

## Детальний аналіз результатів та фізичні висновки

Отримані чисельні дані дозволяють детально зінтерпретувати термодинамічні процеси та зрозуміти практичні межі функціонування реальних теплових установок:

### 1. Вплив температурного перепаду на ККД та холодильні коефіцієнти
При розрахункових параметрах `T_H = 600 К` (326.85 °C) та `T_C = 300 К` (26.85 °C) граничний термічний ККД становить точно `50.00%`. Якщо температура нагрівача зростає до `900 К` при стабільному `T_C = 300 К`, ККД досягає `66.67%`. І навпаки, занурення холодильника до кріогенних температур `T_C = 77 К` (рідкий азот) дає ККД понад `87.17%`.

Для зворотного циклу (режим теплового насоса) невеликий температурний перепад `T_H - T_C` дає колосальну ефективність. При `T_H = 295 К` (+22 °C) та `T_C = 280 К` (+7 °C) різниця становить лише 15 К. За формулою `COP_heat = T_H / (T_H - T_C)` значення `COP` досягає `19.67`. Тобто на кожен 1 кВт·год затраченої електроенергії у приміщення перекачується майже 20 кВт·год тепла з довкілля. Проте при зниженні зовнішньої температури до `T_C = 253 К` (-20 °C) перепад зростає до 42 К, і `COP_heat` падає до `7.02` (а в реальних необоротних приладах — до `2.2–2.5`).

### 2. Залежність тисків і об'ємів від показника адіабати
Вибір типу робочого газу суттєво впливає на об'ємний коефіцієнт розширення під час адіабатичного такту `(T_H / T_C)^(1 / (γ - 1))`:
- Для одноатомного газу (гелій, аргон), де `γ = 1.667`, сила `1 / (γ - 1) = 1.5`. При `T_H / T_C = 2` відношення об'ємів на адіабаті дорівнює `2^1.5 ≈ 2.828`. Загальне розширення системи `V_3 / V_1 = r_v · 2.828 = 5.656`.
- Для двоатомного газу (повітря, азот), де `γ = 1.400`, сила `1 / (γ - 1) = 2.5`. При тому самому перепаді температур `T_H / T_C = 2` відношення об'ємів досягає `2^2.5 ≈ 5.657`. Загальне розширення становить `V_3 / V_1 = r_v · 5.657 = 11.314`.

Це означає, що для двоатомного газу циліндр двигуна мусить мати у два рази більший робочий об'єм, ніж для одноатомного при аналогічних температурах і виконуваній роботі.

### 3. Крайові випадки та обчислювальні границі
При чисельному аналізі важливо опрацьовувати крайові випадки:
- **Границя `r_v → 1`:** Якщо ізотермічне розширення відсутнє (`r_v = 1`), то `ln(r_v) = 0`. Підведена теплота `Q_H` та корисна робота `W` стають рівними нулю. Двигун не виробляє енергії, хоча формальне значення `η = 1 - T_C / T_H` залишається постійним.
- **Границя `T_C → T_H`:** При зближенні температур нагрівача та холодильника ККД прямує до нуля (`η → 0`), а холодильний коефіцієнт `COP` прямує до нескінченності. У чисельних розрахунках це вимагає обробки винятків через можливе ділення на нуль при обчисленні `(T_H - T_C)`.
