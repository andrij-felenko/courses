# 🧮 Математичне виведення закону Планка та випромінювальних законів

Цей математичний додаток містить строге та послідовне виведення спектральної формули Планка для об'ємної густини енергії випромінювання абсолютно чорного тіла. У документі детально розібрано геометричний розрахунок густини електромагнітних мод у тривимірній замкненій порожнині, застосування математичного апарату статистичної фізики для знаходження середньої енергії квантового гармонічного осцилятора, а також точне математичне виведення закону Стефана-Больцмана та закону зміщення Віна через аналітичне інтегрування та диференціювання розподілу Планка.

## 1. Геометрія стоячих хвиль та густина електромагнітних мод

Розглянемо замкнену кубічну порожнину з довжиною ребра `L` та об'ємом `V = L³`, стінки якої є ідеальними провідниками. Закони класичної електродинаміки Максвелла вимагають, щоб на поверхні провідника тангенціальна компонента електричного поля оберталася на нуль. Усередині порожнини електромагнітне поле описується тривимірним хвильовим рівнянням для векторного потенціалу у вакуумі:

```
∇² E - (1 / c²) · (∂² E / ∂ t²) = 0
```

Застосовуючи метод відокремлення змінних (метод Фур'є), розв'язок цього рівняння подається у вигляді системи стоячих електромагнітних хвиль (хвильових мод). Кожна мода описується гармонічною функцією від просторових координат `x, y, z` та часу `t`:

```
E_x = E₀_x · cos(k_x · x) · sin(k_y · y) · sin(k_z · z) · cos(ω · t)
E_y = E₀_y · sin(k_x · x) · cos(k_y · y) · sin(k_z · z) · cos(ω · t)
E_z = E₀_z · sin(k_x · x) · sin(k_y · y) · cos(k_z · z) · cos(ω · t)
```

Граничні умови обернення на нуль тангенціальних компонент на стінках `x = 0, L`, `y = 0, L`, `z = 0, L` фіксують дискретний набір допустимих компонент хвильового вектора `k = (k_x, k_y, k_z)`:

```
k_x = (π / L) · n_x,   n_x = 1, 2, 3, ...
k_y = (π / L) · n_y,   n_y = 1, 2, 3, ...
k_z = (π / L) · n_z,   n_z = 1, 2, 3, ...
```

де `n_x, n_y, n_z` — додатні цілі числа, кожне з яких відповідає кількості півхвиль, що вкладаються вздовж відповідного ребра куба. Модуль хвильового вектора `k` пов'язаний із цикличною частотою `ω = 2 · π · ν` та лінійною частотою `ν`:

```
k² = k_x² + k_y² + k_z² = (π / L)² · (n_x² + n_y² + n_z²) = (2 · π · ν / c)²
```

Ввівши безрозмірний радіус `n = √(n_x² + n_y² + n_z²)`, ми отримуємо пряму пропорційну залежність між радіусом `n` у просторі квантових чисел та частотою випромінювання `ν`:

```
n = (2 · L · ν) / c
```

Знайдемо кількість можливих потрійних наборів цілих чисел `(n_x, n_y, n_z)` у проміжку частот від `0` до `ν`. У тривимірному просторі квантових чисел `(n_x, n_y, n_z)` кожній комбінації відповідає один елементарний кубик об'ємом `1 · 1 · 1 = 1`. Оскільки квантові числа `n_x, n_y, n_z` можуть бути лише додатними, допустимі точки знаходяться в одному октанті (тобто в `1/8` частині) кулі радіуса `n`:

```
N_просторова(ν) = (1 / 8) · (4 / 3) · π · n³
= (1 / 8) · (4 / 3) · π · ((2 · L · ν) / c)³
= (4 / 3) · π · V · (ν³ / c³)     [підставили V = L³]
```

Урахуємо векторний характер електромагнітного поля. З рівняння Максвелла `div E = 0` (умова відсутності вільних зарядів) випливає, що напрямок вектора електричного поля `E` повинен бути перпендикулярним до хвильового вектора `k` (`k · E = 0`). Для кожного фіксованого хвильового вектора `k` існують два взаємно перпендикулярні напрямки поляризації. Помноживши кількість просторових хвиль на 2 поляризаційні стани, отримуємо повну кількість мод `N(ν)` з частотами до `ν`:

```
N(ν) = 2 · N_просторова(ν) = (8 / 3) · π · V · (ν³ / c³)
```

Диференціюючи функцію `N(ν)` за частотою `ν`, знаходимо кількість електромагнітних хвиль у вузькому інтервалі частот від `ν` до `ν + dν`:

```
dN = (d N(ν) / d ν) dν = (8 · π · V · ν² / c³) dν
```

Густина електромагнітних мод у розрахунку на одиницю об'єму порожнини `g(ν) = (1 / V) · (dN / dν)` визначається універсальною формулою:

```
g(ν) dν = (8 · π · ν² / c³) dν
```

Цей геометричний результат є суто класичним і не залежить від квантових властивостей енергії, описуючи кількість доступних ступенів вільності електромагнітного поля на частоті `ν`. В альтернативному формалізмі квазікласичного фазового простору той самий результат отримують шляхом розрахунку об'єму фазового простору `d³ x d³ p = V · 4 π p² dp`, де імпульс фотона `p = h ν / c`. Поділивши об'єм фазового простору на величину елементарної комірки `h³` та врахувавши 2 стани поляризації, маємо точний збіг формул.

## 2. Статистична сума та квантовий розподіл Планка

За квантовою гіпотезою Планка, електромагнітна мода частоти `ν` не може мати довільну неперервну енергію. Її енергетичний спектр є дискретним і задається виразом:

```
E_n = n · h · ν,   n = 0, 1, 2, 3, ...
```

Для обчислення середньої енергії `⟨E⟩` моди при термодинамічній температурі `T` скористаємося канонічним розподілом Больцмана. Імовірність того, що мода перебуває у `n`-му квантовому стані з енергією `E_n`, дорівнює:

```
P(E_n) = (1 / Z) · exp(-n · h · ν / (k_B · T))
```

де `Z` — канонічна статистична сума моди, яка нормалізує суму ймовірностей до одиниці. Позначивши безрозмірний параметр `β = 1 / (k_B · T)` та `x = β · h · ν = h · ν / (k_B · T)`:

```
Z = ∑ [n=0..∞] exp(-n · x)
```

Це сума нескінченно спадної геометричної прогресії зі першим членом `a₁ = 1` та знаменником `q = exp(-x) < 1`. За стандартною формулою сумування `∑ qⁿ = 1 / (1 - q)`:

```
Z = 1 / (1 - exp(-h · ν / (k_B · T)))
```

У статистичній фізиці середня енергія системи `⟨E⟩` обчислюється як логарифмічна похідна від статистичної суми за параметром `β`:

```
⟨E⟩ = - (∂ / ∂ β) ln Z
= - (∂ / ∂ β) [- ln(1 - exp(-β · h · ν))]
= (1 / (1 - exp(-β · h · ν))) · (h · ν · exp(-β · h · ν))
```

Поділивши чисельник та знаменник отриманого дробу на `exp(-β · h · ν)`, маємо підсумкову виражену середню енергію квантового осцилятора:

```
⟨E⟩ = h · ν / (exp(h · ν / (k_B · T)) - 1)
```

Помноживши кількість мод на одиницю об'єму `g(ν) dν` на середній запас енергії однієї моди `⟨E⟩`, ми отримуємо **формулу Планка для спектральної густини енергії випромінювання**:

```
u(ν, T) dν = g(ν) · ⟨E⟩ dν
= (8 · π · h · ν³ / c³) / (exp(h · ν / (k_B · T)) - 1) dν
```

В альтернативному формулюванні через статистику Бозе-Ейнштейна з нульовим хімічним потенціалом `μ = 0` (газ незбережуваних фотонів) середнє число фотонів у стані з частотою `ν` дорівнює `⟨n_бозе⟩ = 1 / (exp(h ν / (k_B T)) - 1)`. Множення числа фотонів на енергію одного фотона `h ν` та на густину мод `g(ν)` призводить до тотожної формули Планка.

Знайдемо вільну енергію Гельмгольца для однієї електромагнітної моди:

```
F_i = - k_B T ln Z = k_B T ln(1 - exp(-h ν / (k_B T)))
```

Ентропія однієї моди дорівнює похідній `S_i = - (∂ F_i / ∂ T)_V`:

```
S_i = k_B · [ (x / (exp(x) - 1)) - ln(1 - exp(-x)) ]
```

де `x = h ν / (k_B T)`. При `x >> 1` (високочастотні моди) ентропія `S_i ∝ x exp(-x) → 0`, що математично підтверджує пригнічення термодинамічних флуктуацій у короткохвильовій області.

## 3. Математичний аналіз граничних асимптотик

Аналітична формула Планка володіє унікальною математичною властивістю: вона гладко з'єднує два протилежні граничні режими поведінки електромагнітного поля.

### Асимптотика низьких частот (Закон Релея-Джинса)

Розглянемо область частот, де енергія кванта значно менша за середня теплову енергію: `h · ν << k_B · T`. Це відповідає умові `x = h · ν / (k_B · T) << 1`.

Розкладемо показникову функцію `exp(x)` у степеневий ряд Тейлора в околі точки `x = 0`:

```
exp(x) = 1 + x + (x² / 2!) + (x³ / 3!) + ...
```

Обмежуючись першими двома членами розкладу при `x << 1`:

```
exp(h · ν / (k_B · T)) - 1 ≈ 1 + (h · ν / (k_B · T)) - 1 = h · ν / (k_B · T)
```

Підставивши цей розклад у знаменник середньої енергії квантового осцилятора:

```
⟨E⟩ ≈ h · ν / (h · ν / (k_B · T)) = k_B · T
```

Підставляючи середню енергію `⟨E⟩ = k_B · T` у вираз для спектральної густини енергії `u(ν, T)`:

```
u(ν, T) = (8 · π · ν² / c³) · k_B · T
```

Це доводить, що у низькочастотній області квантовий розподіл Планка строго переходить у класичний **закон Релея-Джинса**. Поправка першого порядку за параметром `x` становить `u(ν, T) ≈ (8 π ν² / c³) k_B T (1 - h ν / (2 k_B T))`, що показує незначне зниження енергії порівняно з класичною межею.

### Асимптотика високих частот (Формула Віна)

Розглянемо протилежну область високих частот (ультрафіолетовий та рентгенівський діапазон), де енергія кванта багаторазово перевищує тепловий фон: `h · ν >> k_B · T`. Це відповідає умові `x = h · ν / (k_B · T) >> 1`.

Оскільки `exp(x) >> 1`, одиницею у знаменнику формули Планка можна знехтувати у порівнянні з величезним значенням експоненти:

```
exp(h · ν / (k_B · T)) - 1 ≈ exp(h · ν / (k_B · T))
```

Підставивши це наближення у формулу Планка:

```
u(ν, T) ≈ (8 · π · h · ν³ / c³) · exp(-h · ν / (k_B · T))
```

Позначивши сталі коефіцієнти `A = 8 · π · h / c³` та `B = h / k_B`, отримуємо **емпіричну формулу Віна 1896 року**:

```
u(ν, T) = A · ν³ · exp(-B · ν / T)
```

## 4. Спектральний розподіл за довжиною хвилі

У практичних оптичних та спектроскопічних вимірюваннях спектр частіше описують залежністю від довжини хвилі `λ`, а не від частоти `ν`.

Зв'язок між частотою та довжиною хвилі у вакуумі задається виразом `ν = c / λ`. Звідси диференціал частоти дорівнює:

```
dν = - (c / λ²) dλ
```

Знак мінус показує, що зростанню частоти відповідає зменшення довжини хвилі. Оскільки елемент енергії випромінювання у відповідному інтервалі спектра є додатним значенням `|u(ν, T) dν| = |u(λ, T) dλ|`:

```
u(λ, T) = u(ν(λ), T) · |dν / dλ|
```

Підставивши `ν = c / λ` та `|dν / dλ| = c / λ²` у формулу Планка для `u(ν, T)`:

```
u(λ, T) = (8 · π · h · (c / λ)³ / c³) / (exp(h · c / (λ · k_B · T)) - 1) · (c / λ²)
```

Після скорочення степенів швидкості світла `c` та об'єднання степенів довжини хвилі `λ` отримуємо **спектральну густину енергії за довжиною хвилі**:

```
u(λ, T) dλ = (8 · π · h · c / λ⁵) / (exp(h · c / (λ · k_B · T)) - 1) dλ
```

Зв'язок між об'ємною густиною енергії у порожнині `u(λ, T)` та спектральною яскравістю випромінювання поверхні чорного тіла `B_λ(λ, T)` задається виразом `B_λ(λ, T) = (c / 4π) · u(λ, T)`:

```
B_λ(λ, T) dλ = (2 · h · c² / λ⁵) / (exp(h · c / (λ · k_B · T)) - 1) dλ
```

## 5. Точне виведення закону Стефана-Больцмана та дзета-функція Рімана

Для обчислення повної об'ємної густини енергії випромінювання `u_total(T)` необхідно проінтегрувати спектральну густину Планка по всьому нескінченному інтервалу частот від `0` до `∞`:

```
u_total(T) = ∫₀^∞ u(ν, T) dν
= ∫₀^∞ (8 · π · h · ν³ / c³) / (exp(h · ν / (k_B · T)) - 1) dν
```

Виконаємо безрозмірну заміну змінної інтегрування:

```
x = h · ν / (k_B · T)  ⇒  ν = (k_B · T / h) · x,   dν = (k_B · T / h) dx
```

Підставивши `ν` та `dν` в інтеграл:

```
u_total(T) = (8 · π · h / c³) · (k_B · T / h)⁴ · ∫₀^∞ (x³ / (exp(x) - 1)) dx
= ((8 · π · k_B⁴ · T⁴) / (c³ · h³)) · I₄
```

де `I₄` — фундаментальний математичний інтеграл вигляду:

```
I₄ = ∫₀^∞ (x³ / (exp(x) - 1)) dx
```

Обчислимо точне значення цього інтеграла. Для цього розкладемо підінтегральний дріб `1 / (exp(x) - 1)` у суму нескінченно спадної геометричної прогресії:

```
1 / (exp(x) - 1) = exp(-x) / (1 - exp(-x)) = ∑ [n=1..∞] exp(-n · x)
```

Підставивши цей розклад в інтеграл та помінявши місцями операції підсумовування та інтегрування:

```
I₄ = ∫₀^∞ x³ · (∑ [n=1..∞] exp(-n · x)) dx
= ∑ [n=1..∞] ∫₀^∞ x³ · exp(-n · x) dx
```

Зробимо заміну змінної `y = n · x`, звідси `dx = dy / n`:

```
I₄ = ∑ [n=1..∞] (1 / n⁴) · ∫₀^∞ y³ · exp(-y) dy
```

Знайдений інтеграл `∫₀^∞ y³ · exp(-y) dy` являє собою гамма-функцію Ейлера `Γ(4) = 3! = 6`. Сума `∑ [n=1..∞] (1 / n⁴)` за означенням є значенням дзета-функції Рімана `ζ(4)`. З аналітичної теорії чисел відомо точне значення `ζ(4) = π⁴ / 90`, яке виводиться з розкладу функцій у ряди Фур'є через числа Бернуллі `B₄ = -1/30`.

Таким чином, значення інтеграла `I₄` дорівнює:

```
I₄ = 6 · ζ(4) = 6 · (π⁴ / 90) = π⁴ / 15
```

Підставляючи обчислене значення `I₄ = π⁴ / 15` у вираз для `u_total(T)`:

```
u_total(T) = ((8 · π · k_B⁴ · T⁴) / (c³ · h³)) · (π⁴ / 15)
= ((8 · π⁵ · k_B⁴) / (15 · c³ · h³)) · T⁴
```

Інтегральна випромінювальна здатність поверхні чорного тіла `j* = (c / 4) · u_total` дорівнює:

```
j* = (c / 4) · ((8 · π⁵ · k_B⁴) / (15 · c³ · h³)) · T⁴
= ((2 · π⁵ · k_B⁴) / (15 · c² · h³)) · T⁴ = σ · T⁴
```

Ми отримали точне математичне виведення **закону Стефана-Больцмана** та виразили константу Стефана-Больцмана `σ` через фундаментальні сталі:

```
σ = (2 · π⁵ · k_B⁴) / (15 · c² · h³) ≈ 5.670374 × 10⁻⁸ Вт / (м² · К⁴)
```

## 6. Точне виведення закону зміщення Віна та метод Ньютона-Рафсона

Знайдемо довжину хвилі `λ_max`, при якій спектральна яскравість випромінювання `B_λ(λ, T)` досягає свого абсолютного максимуму. Для цього диференціюємо функцію `B_λ(λ, T)` за змінною `λ` та прирівнюємо похідну до нуля.

Запишемо функцію `B_λ(λ, T)` у вигляді:

```
B_λ(λ, T) = C₁ · λ⁻⁵ / (exp(C₂ / (λ · T)) - 1)
```

де `C₁ = 2 · h · c²` та `C₂ = h · c / k_B`.

Позначимо безрозмірний аргумент `x = C₂ / (λ · T) = (h · c) / (λ · k_B · T)`. Тоді довжина хвилі виражається як `λ = C₂ / (T · x)`. Перепишемо `B_λ` через змінну `x`:

```
B_λ(x) = C₁ · (T / C₂)⁵ · (x⁵ / (exp(x) - 1))
```

Для знаходження максимуму обчислимо похідну від функції `g(x) = x⁵ / (exp(x) - 1)` за змінною `x` і прирівняємо її до нуля:

```
d g / d x = (5 · x⁴ · (exp(x) - 1) - x⁵ · exp(x)) / (exp(x) - 1)² = 0
```

Оскільки `x ≠ 0` та `exp(x) ≠ 1`, прирівнюємо чисельник до нуля та ділимо обидві частини рівняння на `x⁴ · exp(x)`:

```
5 · (1 - exp(-x)) - x = 0
```

Це дає фундаментальне трансцендентне рівняння закону зміщення Віна:

```
x / (1 - exp(-x)) = 5
```

Розв'яжемо це рівняння чисельним методом Ньютона-Рафсона. Запишемо функцію `f(x) = x + 5 · exp(-x) - 5 = 0`. Похідна цієї функції дорівнює `f'(x) = 1 - 5 · exp(-x)`.

Ітераційна формула Ньютона-Рафсона має вигляд:

```
x_{k+1} = x_k - (f(x_k) / f'(x_k))
```

Обраємо початкове наближення `x₀ = 5.0`:
- **Ітерація 1:** `f(5.0) = 5.0 + 5·exp(-5.0) - 5 = 0.0336897`
  `f'(5.0) = 1 - 5·exp(-5.0) = 0.9663102`
  `x₁ = 5.0 - (0.0336897 / 0.9663102) = 4.9651359`
- **Ітерація 2:** `f(4.9651359) = 0.0000213`, `f'(4.9651359) = 0.9652718`
  `x₂ = 4.9651359 - (0.0000213 / 0.9652718) = 4.96511423`

З точністю до дев'яти значущих цифр розв'язоком є:

```
x = (h · c) / (λ_max · k_B · T) ≈ 4.96511423
```

Виражаючи `λ_max`, отримуємо строгий **закон зміщення Віна**:

```
λ_max · T = (h · c) / (4.96511423 · k_B) = b
```

Обчислимо значення фундаментальної константи Віна `b`:

```
b = (6.62607015 × 10⁻³⁴ · 2.99792458 × 10⁸) / (4.96511423 · 1.380649 × 10⁻²³)
≈ 2.897771955 × 10⁻³ м · К
```

Аналогічне виведення для максимуму спектра за частотою `B_ν(ν, T)` прирівнює похідну `d/dx [x³ / (exp(x) - 1)] = 0`, що дає трансцендентне рівняння `x / (1 - exp(-x)) = 3` з розв'язком `x_ν ≈ 2.82143937`. Звідси частота максимуму становить `ν_max = 2.82143937 · (k_B T / h)`.

Це завершує строгий математичний аналіз випромінювальних законів чорного тіла.
