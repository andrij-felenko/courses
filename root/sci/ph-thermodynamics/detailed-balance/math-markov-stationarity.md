# 🧮 Математичний формалізм детального балансу в ланцюгах Маркова

Принцип детального балансу встановлює математичний зв'язок між мікроскопічними ймовірностями переходів та стаціонарним розподілом ймовірностей у марковських процесах. Ця вставка містить алгебраїчне виведення еквівалентності детального балансу та симетризації матриці переходів, доведення дійсності спектра релаксаційного оператора, а також критерій Колмогорова для колових потоків у дискретних системах.

## 1. Кинетичне рівняння та умови стаціонарності

Розглянемо дискретну систему з множиною станів `S = {1, 2, ..., N}`. Еволюція вектор-рядка ймовірностей `P(t) = (P₁(t), P₂(t), ..., P_N(t))` описується дискретним або безперервним марковським процесом. У безперервному часі основне кінетичне рівняння (Master Equation) описує часову зміну ймовірностей кожного стану:

```
d P_i(t) / d t = ∑_j [ P_j(t) · W_{ji} - P_i(t) · W_{ij} ]
```

тут `W_{ij} ≡ W(i → j) ≥ 0` — інтенсивність ймовірності переходу зі стану `i` у стан `j` за одиницю часу для `i ≠ j`. За діагональні елементи приймають суму зі зворотним знаком `W_{ii} = - ∑_{j ≠ i} W_{ij}`, що забезпечує точне збереження повної ймовірності `∑_i P_i(t) = 1` у будь-який момент часу.

У матричному записі Master Equation має компактний вигляд:

```
d P(t) / d t = P(t) · W
```

де `W` — матриця інтенсивностей переходів (генератор марковського ланцюга), у якій сума елементів у кожному рядку дорівнює нулю: `∑_j W_{ij} = 0`.

Стаціонарний розподіл `P_eq` за визначенням задовольняє умову **глобального балансу**, яка вимагає обнулення повної похідної по часу:

```
d P_eq / d t = 0   ⇒   ∑_j P_eq(j) · W_{ji} = ∑_j P_eq(i) · W_{ij}      [глобальний баланс]
```

Умова **детального балансу** (detailed balance condition) є набагато суворішою обмеженістю: вона вимагає обнулення кожного доданка суми попарно:

```
P_eq(i) · W_{ij} = P_eq(j) · W_{ji}      [для всіх і, j ∈ S]
```

Очевидно, що з детального балансу підсумовуванням по всіх `j` миттєво випливає глобальний баланс. Обернене твердження загалом невірне: глобальний баланс допускає існування циклічних струмів імовірності `J_{ij} = P_eq(i) · W_{ij} - P_eq(j) · W_{ji} ≠ 0`.

Фізичний зміст принципу детального балансу полягає у відсутності макроскопічного переносу ймовірності між будь-якою парою станів у рівновазі. Це гарантує, що система не генерує ентропію і перебуває у стані справжнього термодинамічного спокою.

## 2. Ермітизація та оператор подібності

Нехай марковський ланцюг задовольняє умову детального балансу із строго додатною стаціонарною ймовірністю `P_eq(i) > 0` для всіх станів `i`. Введемо діагональну матрицю вагових коефіцієнтів `R = diag( √P_eq(1), √P_eq(2), ..., √P_eq(N) )`.

Виконаємо перетворення подібності генератора `W` за допомогою матриці `R`:

```
S = R · W · R⁻¹
```

Обчислимо елементи матриці `S`:

```
S_{ij} = √P_eq(i) · W_{ij} · (1 / √P_eq(j))
```

Перевіримо симетричність матриці `S`, транспонуючи її елементи:

```
S_{ji} = √P_eq(j) · W_{ji} · (1 / √P_eq(i))
```

Застосуємо умову детального балансу `P_eq(j) · W_{ji} = P_eq(i) · W_{ij}` для перетворення виразу `S_{ji}`:

```
S_{ji} = (P_eq(i) · W_{ij}) / (√P_eq(j) · √P_eq(i))
       = √P_eq(i) · W_{ij} · (1 / √P_eq(j))
       = S_{ij}      [доведено: S є симетричною матрицею]
```

Оскільки симетрична дійсне матриця `S` є самоспряженим (ермітовим) оператором, з цього випливають важливі спектральні наслідки для динаміки релаксації системи.

### Важливі наслідки ермітичності

1. **Дійсність спектра:** Усі власні значення `λ_k` оператора `W` є чисто дійсними числами (відсутні уявні частини, отже релаксація до рівноваги не містить осциляцій та згасаючих коливань).
2. **Невід'ємність визначеності:** Усі власні значення є від'ємними або нулем: `0 = λ₀ > λ₁ ≥ λ₂ ≥ ... ≥ λ_{N-1}`.
3. **Ортонормований базис:** Оператор `W` має повну систему дійсних власних векторів.
4. **Спектральний зазор і час релаксації:** Швидкість наближення системи до рівноважного стану визначається найменшим за модулем ненульовим власним значенням `λ₁`. Час релаксації (спектральна пауза) дорівнює:

```
τ_rel = 1 / |λ₁|
```

Будь-який відхилений від рівноваги стан `P(t)` розкладається у суму монотонно згасаючих експонент без осциляцій:

```
P_i(t) = P_eq(i) + ∑_{k=1}^{N-1} c_k · v_{k,i} · exp(- |λ_k| · t)
```

Математична відсутність уявних частин у спектрі гарантує, що релаксація статистичного ансамблю є строго аперіодичною. У системах із детальним балансом принципово відсутні спіралеподібні траєкторії чи обертові фазові хвилі.

## 3. Функціонал Ліапунова та монотонне спадання відносної ентропії

Доведемо строгу математичну теорему про те, що дивергенція Кульбака-Лейблера (відносна ентропія) є строгим функціоналом Ліапунова для системи з детальним балансом. Введемо функціонал відносної ентропії:

```
K( P(t) || P_eq ) = ∑_i P_i(t) · ln( P_i(t) / P_eq(i) ) ≥ 0
```

Обчислимо повну похідну по часу `d K / d t`:

```
d K / d t = ∑_i ( d P_i / d t ) · [ 1 + ln( P_i / P_eq(i) ) ]
```

Підставимо Master Equation `d P_i / d t = ∑_j [ P_j W_{ji} - P_i W_{ij} ]`:

```
d K / d t = ∑_{i,j} [ P_j W_{ji} - P_i W_{ij} ] · ln( P_i / P_eq(i) )
```

Симетризуємо вираз під знаками суми по індексах `i` та `j`:

```
d K / d t = (1/2) · ∑_{i,j} [ P_j W_{ji} - P_i W_{ij} ] · [ ln( P_i / P_eq(i) ) - ln( P_j / P_eq(j) ) ]
```

Застосуємо умову детального балансу у формі `P_eq(j) W_{ji} = P_eq(i) W_{ij}`. Введемо позначення відносних заселеностей `u_i = P_i / P_eq(i)` та `u_j = P_j / P_eq(j)`:

```
d K / d t = - (1/2) · ∑_{i,j} P_eq(i) W_{ij} · [ u_i - u_j ] · [ ln(u_i) - ln(u_j) ]
```

Оскільки логарифмічна функція є строго монотонно зростаючою, різниця чисел `(u_i - u_j)` та різниця їх логарифмів `(ln u_i - ln u_j)` завжди мають однаковий знак для будь-яких додатних `u_i, u_j > 0`. Отже, добуток `(u_i - u_j) · (ln u_i - ln u_j) ≥ 0` є строго невід'ємним.

Оскільки всі коефіцієнти `P_eq(i) W_{ij} ≥ 0` є невід'ємними, вираз під знаком суми зі знаком мінус гарантує:

```
d K( P(t) || P_eq ) / d t ≤ 0      [функціонал Ліапунова]
```

Це доводить, що відносна ентропія монотонно спадає до нуля, а стаціонарний розподіл `P_eq` є єдиним асимптотично стійким атрактором динаміки Master Equation.

## 4. Критерій циклів Колмогорова

Як визначити, чи задовольняє дискретний марковський ланцюг детальному балансу, якщо стаціонарний розподіл `P_eq` заздалегідь невідомий? Для цього Андрій Колмогоров у 1936 році довів необхідну й достатню умову, що базується лише на матриці переходів `W`.

### Теорема Колмогорова

Марковський ланцюг із незвідною матрицею переходів задовольняє принципу детального балансу для деякого розподілу `P_eq` тоді й лише тоді, коли для будь-якої замкненої послідовності станів (циклу) `C = (i₁ → i₂ → i₃ → ... → i_k → i₁)` добуток ймовірностей переходів у прямому напрямку дорівнює добутку ймовірностей переходів у зворотному напрямку:

```
W_{i₁ i₂} · W_{i₂ i₃} · ... · W_{i_k i₁} = W_{i₁ i_k} · ... · W_{i₃ i₂} · W_{i₂ i₁}      [критерій Колмогорова]
```

### Доведення (в один бік)

Нехай у системі виконується детальний баланс. Запишемо співвідношення для кожного ребра циклу:

```
P_eq(i₁) · W_{i₁ i₂} = P_eq(i₂) · W_{i₂ i₁}
P_eq(i₂) · W_{i₂ i₃} = P_eq(i₃) · W_{i₃ i₂}
...
P_eq(i_k) · W_{i_k i₁} = P_eq(i₁) · W_{i₁ i_k}
```

Перемножимо всі ліві частини та всі праві частини цих рівностей:

```
[ ∏_{m=1}^k P_eq(i_m) ] · [ W_{i₁ i₂} · W_{i₂ i₃} · ... · W_{i_k i₁} ]
= [ ∏_{m=1}^k P_eq(i_m) ] · [ W_{i₂ i₁} · W_{i₃ i₂} · ... · W_{i₁ i_k} ]
```

Оскільки `P_eq(i_m) > 0`, скоротимо добуток стаціонарних ймовірностей у лівій і правій частині:

```
W_{i₁ i₂} · W_{i₂ i₃} · ... · W_{i_k i₁} = W_{i₁ i_k} · ... · W_{i₃ i₂} · W_{i₂ i₁}      [що й треба було довести]
```

Якщо в системі існує хоча б один цикл, для якого добуток прямоходу не дорівнює зворотній сумі, система знаходиться в нерівноважному стані з коловим циркулюючим потоком імовірності (NESS), що супроводжується постійною генерацією ентропії.

Критерій Колмогорова є надзвичайно зручним інструментом для обчислювальної фізики, оскільки він дозволяє перевірити виконання детального балансу за матрицею переходів `W` без необхідності явного знаходження власного вектора `P_eq`.
