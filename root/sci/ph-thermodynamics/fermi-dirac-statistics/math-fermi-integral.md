# 🧮 Математичний апарат: інтеграли Фермі — Дірака та розклад Зоммерфельда

Аналітичний розрахунок термодинамічних величин квантового виродженого газу потребує знаходження інтегралів від добутку гладкої функції стану (такої як густина станів `g(E)`) на функцію розподілу Фермі — Дірака `f(E)`. У цій вставці наведено строгий математичний апарат інтегралів Фермі — Дірака, виведення асимптотичного розкладу Зоммерфельда для температур `T ≪ T_F` та детальний розрахунок температурної залежності хімічного потенціалу `μ(T)` і електронної теплоємності `C_v(T)`.

---

### 1. Означення та властивості інтегралів Фермі — Дірака

У статистичній фізиці квантових фермі-систем повна кількість частинок `N` та середня внутрішня енергія `U` визначаються інтегралами типу згортки:

```
I_H = ∫₀^∞ H(E) · f(E) dE
```

де `H(E)` — неперервна гладка функція енергії (наприклад, `H(E) = g(E)` для кількості частинок, або `H(E) = E · g(E)` для енергії), а `f(E) = 1 / (exp((E - μ) / (k_B · T)) + 1)` — функція розподілу Фермі — Дірака.

Безрозмірний **інтеграл Фермі — Дірака** порядку `j` визначається виразом:

```
F_j(η) = (1 / Γ(j + 1)) · ∫₀^∞ (x^j / (exp(x - η) + 1)) dx
```

де `η = μ / (k_B · T)` — приведений хімічний потенціал, `x = E / (k_B · T)` — безрозмірна енергія, а `Γ(j + 1)` — ейлерівська гамма-функція.

#### Математичні властивості інтегралів Фермі — Дірака:
1. **Рекурентне диференціювання:** Похідна інтеграла Фермі — Дірака порядку `j` по приведеному хімічному потенціалу `η` знижує або підвищує його порядок згідно зі тотожністю:

```
d/dη [F_j(η)] = F_{j-1}(η)     [диференціювання за приведеним потенціалом η]
```

2. **Класична асимптотика (відсутність виродження, η ≪ -1):** Коли приведений хімічний потенціал прямує до мінус нескінченності (`η → -∞`), одиницею у знаменнику підінтегрального виразу можна знехтувати. Тоді інтеграл зводиться до звичайного гаусового чи гамма-інтеграла статистики Максвелла — Больцмана:

```
F_j(η) ≈ exp(η)     [класичний ліміт Больцмана]
```

3. **Сильновироджена квантова асимптотика (η ≫ 1):** За низьких температур (`η → +∞`) інтеграли Фермі — Дірака можна розкласти у степеневий ряд за оберненими степенями `η⁻¹`. Інтегрування частинами дає головні асимптотичні члени:

```
F_j(η) ≈ (η^(j+1) / Γ(j + 2)) · [1 + (π² / 6) · (j + 1) · j · η⁻² + ...]
```

Для тривимірного електронного газу густина станів має вигляд `g(E) = C · √E`. Тоді:
- Повна кількість частинок `N` описується інтегралом `F_{1/2}(η)` (порядок `j = 1/2`).
- Повна внутрішня енергія `U` описується інтегралом `F_{3/2}(η)` (порядок `j = 3/2`).

### 2. Строгий вивід теореми розкладу Зоммерфельда

У випадку сильного квантового виродження (`k_B · T ≪ μ`, що відповідає `η ≫ 1`), функція розподілу Фермі — Дірака `f(E)` близька до монотонної сходинки Хевісайда. Її від'ємна похідна по енергії `-(∂f/∂E)` є симетричною дзвоноподітною функцією, зфокусованою довкола енергетичної точки `E = μ`, з ефективною шириною `~ 4 k_B · T` та амплітудою `1 / (4 k_B · T)`. При `T → 0 K` ця похідна строго прямує до дельта-функції Дірака `δ(E - μ)`.

Нехай `K(E)` — первісна функції `H(E)`, тобто `K(E) = ∫₀^E H(E') dE'`, причому `K(0) = 0`. Інтегруючи вирази частинами, отримуємо:

```
I_H = ∫₀^∞ H(E) · f(E) dE
= [K(E) · f(E)]₀^∞ - ∫₀^∞ K(E) · (∂f/∂E) dE     [інтегрування частинами]
= 0 + ∫₀^∞ K(E) · (-∂f/∂E) dE                    [граничні умови: f(∞)=0, K(0)=0]
```

Виконаємо заміну безрозмірної змінної `x = (E - μ) / (k_B · T)`. Тоді `E = μ + x · k_B · T`, а похідна набуває симетричного виразу:

```
-(∂f/∂E) = (k_B · T)⁻¹ · exp(x) / (exp(x) + 1)²
```

оскільки `exp(x) / (exp(x) + 1)² = 1 / (4 cosh²(x / 2))`.

Розкладемо гладку функцію `K(E)` у ряд Тейлора довкола точки `E = μ`:

```
K(μ + x · k_B · T)
= K(μ) + K'(μ) · (x · k_B · T) + (1 / 2) · K''(μ) · (x · k_B · T)² + (1 / 6) · K'''(μ) · (x · k_B · T)³ + (1 / 24) · K''''(μ) · (x · k_B · T)⁴ + ...
```

Підставляючи розклад Тейлора у вихідний інтеграл, нижню межу інтегрування по `x` можна поширити від `-μ / (k_B T)` до `-∞` з експоненціальною точністю `O(exp(-η))`.

Завдяки симетрії ядерної функції `1 / (4 cosh²(x / 2))` відносно точки `x = 0`, усі інтеграли від непарних степенів `x` (`x¹`, `x³`, `x⁵`...) строго дорівнюють нулю. Враховуючи тільки парні степені `x²`, `x⁴`, отримуємо:

```
I_H = K(μ) · ∫₋∞^∞ (1 / (4 cosh²(x / 2))) dx 
      + (1 / 2) · K''(μ) · (k_B · T)² · ∫₋∞^∞ (x² / (4 cosh²(x / 2))) dx 
      + (1 / 24) · K''''(μ) · (k_B · T)⁴ · ∫₋∞^∞ (x⁴ / (4 cosh²(x / 2))) dx + ...
```

Обчислюємо табличні визначені інтеграли через значення дзету-функції Рімана `ζ(s)`:

```
∫₋∞^∞ (1 / (4 cosh²(x / 2))) dx = 1                                         [умова нормування ядерної функції]

∫₋∞^∞ (x² / (4 cosh²(x / 2))) dx = 2 · ∫₀^∞ (x² · exp(x) / (exp(x) + 1)²) dx  [симетрія підінтегральної функції]
= 4 · (1 - 2⁻¹) · Γ(3) · ζ(2)                                               [зведення до дзета-функції Рімана ζ(2)=π²/6]
= 4 · (1/2) · 2 · (π² / 6) = π² / 3                                         [обчислення добутку]

∫₋∞^∞ (x⁴ / (4 cosh²(x / 2))) dx = 2 · ∫₀^∞ (x⁴ · exp(x) / (exp(x) + 1)²) dx  [симетрія підінтегральної функції]
= 8 · (1 - 2⁻³) · Γ(5) · ζ(4)                                               [зведення до дзета-функції Рімана ζ(4)=π⁴/90]
= 8 · (7/8) · 24 · (π⁴ / 90) = 7π⁴ / 15                                     [обчислення добутку]
```

Згадуючи, що `K'(μ) = H(μ)`, `K''(μ) = H'(μ)`, `K''''(μ) = H'''(μ)`, підставляємо обчислені коефіцієнти в підсумковий вираз:

```
∫₀^∞ H(E) · f(E) dE
≈ ∫₀^μ H(E) dE + (π² / 6) · (k_B · T)² · H'(μ) + (7π⁴ / 360) · (k_B · T)⁴ · H'''(μ)
```

Це і є загальна фундаментальна **формула розкладу Зоммерфельда**. 

Перший член визначає термодинамічне заповнення станів за абсолютного нуля `T = 0 K`, а другий доданок дає головну квантову температурну поправку порядку `(k_B · T / μ)²`.

### 3. Аналітичний розрахунок температурного зсуву хімічного потенціалу μ(T)

Для обчислення температурного зсуву хімічного потенціалу скористаємося умовою збереження повної кількості частинок `N`.

Покладемо `H(E) = g(E)` у формулі Зоммерфельда:

```
N = ∫₀^∞ g(E) · f(E) dE
≈ ∫₀^μ g(E) dE + (π² / 6) · (k_B · T)² · g'(μ)     [формула Зоммерфельда]
```

Оскільки повна кількість частинок `N` є фіксованою величиною, за абсолютного нуля `T = 0 K` вона дорівнює заповненню інтеграла до енергії Фермі `E_F = μ(0)`:

```
N = ∫₀^{E_F} g(E) dE
```

Прирівнюємо вирази для кількості частинок:

```
∫₀^{E_F} g(E) dE = ∫₀^μ g(E) dE + (π² / 6) · (k_B · T)² · g'(μ)
```

Переносимо інтеграл та апроксимуємо різницю на малому проміжку `[E_F, μ]`:

```
∫_{E_F}^μ g(E) dE ≈ g(E_F) · (μ - E_F)
```

Звідси виражаємо різницю хімічного потенціалу відносно енергії Фермі:

```
g(E_F) · (E_F - μ) ≈ (π² / 6) · (k_B · T)² · g'(E_F)
```

Виражаємо температурну поправку до хімічного потенціалу:

```
μ(T) ≈ E_F - (π² / 6) · (k_B · T)² · [g'(E_F) / g(E_F)]
```

Для тривимірного електронного газу густина станів дорівнює `g(E) = C · √E`. Обчислюємо логарифмічну похідну:

```
g'(E) = C / (2 √E) ⇒ g'(E_F) / g(E_F) = (C / (2 √E_F)) / (C √E_F) = 1 / (2 E_F)
```

Підставляючи логарифмічну похідну, отримуємо остаточну точну формулу Зоммерфельда для **хімічного потенціалу**:

```
μ(T) ≈ E_F · [1 - (π² / 12) · (k_B · T / E_F)²]
```

Зсув хімічного потенціалу відносно `E_F` є від'ємним і зростає параболічно з підвищенням температури. Для міді за кімнатної температури (`T = 300 K`, `T_F = 81 600 K`) відносна поправка становить:

```
(π² / 12) · (300 / 81600)² ≈ 1.1 · 10⁻⁵
```

Це підтверджує, що для звичайних металів хімічний потенціал з високою точністю збігається з енергією Фермі `μ(T) ≈ E_F`.

### 4. Точний розрахунок внутрішньої енергії U(T) та електронної теплоємності C_v(T)

Для знаходження внутрішньої енергії системи `U(T)` покладемо `H(E) = E · g(E)` у формулі Зоммерфельда:

```
U(T) = ∫₀^∞ E · g(E) · f(E) dE
≈ ∫₀^μ E · g(E) dE + (π² / 6) · (k_B · T)² · [d(E · g(E)) / dE]_{E=μ}
```

Обчислюємо похідну за правилом добутку при `E = μ ≈ E_F`:

```
[d(E · g(E)) / dE]_{E=E_F} = g(E_F) + E_F · g'(E_F)
```

Розкладемо перший інтеграл поблизу точки `E_F`:

```
∫₀^μ E · g(E) dE ≈ ∫₀^{E_F} E · g(E) dE + E_F · g(E_F) · (μ - E_F)
```

Згадуємо виражений раніше зсув хімічного потенціалу `(μ - E_F) = -(π² / 6) · (k_B · T)² · [g'(E_F) / g(E_F)]`. Підставляємо його в інтеграл:

```
E_F · g(E_F) · (μ - E_F) = -E_F · (π² / 6) · (k_B · T)² · g'(E_F)
```

Тепер збираємо разом усі доданки у виразі для внутрішньої енергії `U(T)`:

```
U(T) ≈ U₀ - E_F · (π² / 6) · (k_B · T)² · g'(E_F) + (π² / 6) · (k_B · T)² · [g(E_F) + E_F · g'(E_F)]
```

Доданки, що містять похідну `E_F · g'(E_F)`, взаємно **скорочуються**:

```
U(T) ≈ U₀ + (π² / 6) · g(E_F) · (k_B · T)²
```

де `U₀ = (3/5) N E_F` — внутрішня енергія виродженого газу за абсолютного нуля `T = 0 K`.

Диференціюючи внутрішню енергію `U(T)` за температурою `T`, отримуємо остаточну формулу **електронної теплоємності**:

```
C_v = dU / dT
= (π² / 3) · g(E_F) · k_B² · T      [диференціювання U(T) за T]
```

Оскільки для тривимірного газу густина станів дорівнює `g(E_F) = (3 N) / (2 E_F)`, перепишемо вираз через температуру Фермі `T_F = E_F / k_B`:

```
C_v = (π² / 3) · ((3 N) / (2 k_B T_F)) · k_B² · T
= (π² / 2) · N · k_B · (T / T_F)
```

Цей строгий математичний результат суворо доводить, що електронна теплоємність квантового виродженого газу є строго лінійною за температурою `C_v = γ · T`, де коефіцієнт Зоммерфельда `γ = (π² / 3) · g(E_F) · k_B²`.

### 5. Особлівості двовимірного випадку (2D)

Для двовимірного квантового газу (2DEG) густина станів є константою: `g_2D(E) = m* / (π ħ²) = C_2D`. 

Завдяки постійності `g_2D`, інтеграл Фермі — Дірака для кількості частинок обчислюється **строго аналітично у замкненому вигляді** за будь-яких температур без використання розкладу Зоммерфельда:

```
n_2D = C_2D · ∫₀^∞ (dE / (exp((E - μ) / (k_B T)) + 1))
= C_2D · k_B · T · ln(1 + exp(μ / (k_B T)))
```

Прирівнюючи це значення до заповнення при `T = 0 K` (`n_2D = C_2D · E_F_2D`), отримуємо точну формулу для хімічного потенціалу двовимірного газу:

```
μ_2D(T) = k_B · T · ln(exp(E_F_2D / (k_B · T)) - 1)
```

При `T → 0` вираз точно прямує до `E_F_2D`, а при виких температурах дає плавний класичний перехід до значення `μ_2D ≈ k_B T ln(n_2D / (C_2D k_B T))`.
