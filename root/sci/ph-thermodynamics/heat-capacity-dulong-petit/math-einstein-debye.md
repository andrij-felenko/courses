# 🧮 Математичний вивід моделей Ейнштейна та Дебая

Строгий математичний вивід термодинамічних функцій класичної теорії Дюлонга — Пті, квантової моделі Ейнштейна та фононної моделі Дебая базується на аналізі статистичних сум та рівнянь стану. Кожен із трьох підходів демонструє еволюцію теоретичної фізики: від класичного розподілу енергії за ступенями вільності до квантування атомних осциляторів та колективних звукових збуджень у кристалічній ґратці.

## 1. Класичне виведення закону Дюлонга — Пті

Розглянемо кристал із `N` однаковими атомами масою `m`, закріпленими у вузлах кристалічної ґратки. У гармонічному наближенні зміщення кожного атома з положення рівноваги викликає відновлювальну силу, пропорційну зміщенню. Гамільтоніан такої системи дорівнює сумі кінетичної та потенціальної енергій `3N` незалежних одновимірних гармонічних осциляторів:

```
H = ∑ [ p[i]² / (2m) + (1/2) m ω² x[i]² ]
```

де сумування проводиться по всіх ступенях вільності від `i = 1` до `3N`.

У класичній статистичній механіці ймовірність перебування системи в мікростані з енергією `H` задається канонічним розподілом Гіббса. Канонічна статистична сума одноатомного одновимірного осцилятора `Z_1` обчислюється як інтеграл за фазовим простором імпульсів `p` та координат `x`:

```
Z_1 = (1 / h) ∫ exp(-β [ p²/(2m) + (1/2) m ω² x² ]) dp dx
```

де `β = 1 / (k_B T)` — зворотна температура. Інтеграл розпадається на добуток двох незалежних інтегралів Гаусса (Пуассона):

```
∫ exp(-β p² / (2m)) dp = √(2 π m / β)
∫ exp(-(1/2) β m ω² x²) dx = √(2 π / (β m ω²))
```

Перемноживши результати обох інтегрувань, отримуємо вираз для статистичної суми одного класичного осцилятора:

```
Z_1 = (1 / h) · √(2 π m / β) · √(2 π / (β m ω²))
= (2 π / (h ω β))             [скорочення маси m та винесення β]
= k_B T / (ℏ ω)               [з урахуванням зведеної сталої Планка ℏ = h / (2π)]
```

Оскільки всі `3N` осциляторів є розрізнюваними за їхнім розташуванням у вузлах кристалічної ґратки, повна статистична сума кристала `Z` становить добуток індивідуальних статистичних сум:

```
Z = (Z_1)³ⁿ = [ k_B T / (ℏ ω) ]³ⁿ
```

Середня внутрішня енергія системи `U` обчислюється як температурна логарифмічна похідна від статистичної суми за параметром `β`:

```
U = - ∂(ln Z) / ∂β
= - ∂ / ∂β [ 3N ln(k_B / (ℏ ω)) - 3N ln(β) ]      [логарифмування добутку та степеня]
= 3N / β                                         [похідна від ln(β) дорівнює 1/β]
= 3 N k_B T                                      [підстановка β = 1 / (k_B T)]
```

Для одного моля речовини число атомів дорівнює числу Авогадро `N = N_A`. Знаючи, що універсальна газова стала дорівнює добутку `R = N_A k_B`, внутрішня енергія моля дорівнює:

```
U_molar = 3 R T
```

Молярна теплоємність при постійному об'ємі `C_v` визначається як похідна від внутрішньої енергії за температурою:

```
C_v = (∂U_molar / ∂T)_V
= ∂ / ∂T [ 3 R T ]
= 3 R ≈ 24.94 J / (mol·K)     [закон Дюлонга — Пті]
```

Таким чином, класична механіка неминуче приводить до незалежності теплоємності від температури та її сталості для всіх простих кристалічних речовин.

## 2. Строгий вивід квантової моделі Ейнштейна

Альберт Ейнштейн у 1907 році усунув суперечність із експериментом, припустивши, що атоми в кристалі є квантовими осциляторами з однаковою характерною частотою `ω_E` (частота Ейнштейна). Квантові рівні енергії гармонічного осцилятора є дискретними:

```
E[n] = (n + 1/2) ℏ ω_E,    де n = 0, 1, 2, ...
```

Для обчислення теплоємності нульова енергія `(1/2) ℏ ω_E` не відіграє ролі, оскільки вона не змінюється з температурою. Статистична сума одного квантового осцилятора обчислюється як сума нескінченної спадної геометричної прогресії:

```
Z_1 = ∑ exp(-β n ℏ ω_E)                           [сумування за рівнями n = 0, 1, 2...]
= 1 + exp(-β ℏ ω_E) + exp(-2 β ℏ ω_E) + ...       [розкриття суми квантових станів]
= 1 / (1 - exp(-β ℏ ω_E))                         [сума геометричної прогресії: S = a1 / (1 - q)]
```

Середня енергія одного квантового осцилятора знаходиться диференціюванням логарифма статистичної суми:

```
<E> = - ∂(ln Z_1) / ∂β
= - ∂ / ∂β [ -ln(1 - exp(-β ℏ ω_E)) ]             [підстановка виразу Z_1]
= (ℏ ω_E · exp(-β ℏ ω_E)) / (1 - exp(-β ℏ ω_E))   [диференціювання за β]
= ℏ ω_E / (exp(β ℏ ω_E) - 1)                      [ділення чисельника і знаменника на exp(-β ℏ ω_E)]
```

Сумуючи внески всіх `3N` незалежних атомних осциляторів, отримуємо повну внутрішню енергію квантового кристала:

```
U(T) = 3 N ℏ ω_E / (exp(ℏ ω_E / (k_B T)) - 1)
```

Для зручності аналізу введемо поняття **температури Ейнштейна** `Θ_E = ℏ ω_E / k_B`, яка задає температурний масштаб квантових ефектів для даної речовини. Для одного моля кристала вираз приймає вигляд:

```
U(T) = 3 R Θ_E / (exp(Θ_E / T) - 1)
```

Диференціюючи внутрішню енергію за температурою, отримуємо молярну теплоємність Ейнштейна `C_v(T)`:

```
C_v = ∂U / ∂T
= 3 R Θ_E · [ -1 / (exp(Θ_E / T) - 1)² ] · exp(Θ_E / T) · (-Θ_E / T²)   [правило диференціювання частки]
= 3 R · (Θ_E / T)² · [ exp(Θ_E / T) / (exp(Θ_E / T) - 1)² ]             [групування множників]
```

### Дослідження граничних режимів моделі Ейнштейна:

**1. Високотемпературна границя (`T ≫ Θ_E`):**
При `T ≫ Θ_E` безрозмірний параметр `x = Θ_E / T ≪ 1`. Розкладаючи експоненціальну функцію у степеневий ряд Тейлора `exp(x) = 1 + x + x²/2 + ...`:

```
exp(x) / (exp(x) - 1)²
≈ (1 + x) / (1 + x - 1)²      [лінійне наближення exp(x) ≈ 1 + x]
≈ (1 + x) / x²                [спрощення знаменника]
≈ 1 / x²                      [нехтуємо членами вищого порядку]
```

Підставляючи отримане наближення у вираз для теплоємності:

```
C_v ≈ 3 R · x² · (1 / x²) = 3 R
```

Модель Ейнштейна при високих температурах плавно переходить у класичний закон Дюлонга — Пті.

**2. Низькотемпературна границя (`T ≪ Θ_E`):**
При `T ≪ Θ_E` параметр `x = Θ_E / T ≫ 1`, тому одиницею у знаменнику можна знехтувати порівняно з великою експонентою `exp(x) ≫ 1`:

```
exp(x) / (exp(x) - 1)²
≈ exp(x) / exp(2x)            [хвора експонента переважає одиницю]
= exp(-x) = exp(-Θ_E / T)     [скорочення степенів]
```

Теплоємність Ейнштейна при наближенні до абсолютного нуля експоненціально прямує до нуля:

```
C_v ≈ 3 R · (Θ_E / T)² · exp(-Θ_E / T)
```

Експоненціальний спад відображає явище «виморожування» ступенів вільності: при `k_B T ≪ ℏ ω_E` середня теплова енергія середовища стає недостатньою навіть для збудження першого квантового рівня осцилятора.

## 3. Строгий вивід фононної моделі Дебая

Модель Дебая враховує міжатомну взаємодію, розглядаючи тепловий рух атомів як сукупність пружних акустичних хвиль (фононів), які поширюються у суцільному середовищі з лінійним законом дисперсії:

```
ω = v · k
```

де `v` — ефективна швидкість звуку в кристалі, `k = 2π / λ` — хвильовий вектор.

### Обчислення спектральної щільності станів `g(ω)`:

У тривимірній ґратці об'ємом `V` граничні умови періодичності квантують допустимі значення хвильового вектора `k`. Об'єм одного стану в `k`-просторі дорівнює `(2π)³ / V`. Число хвиль із модою від `0` до `k` для 3 можливих поляризацій (одної поздовжньої та двох поперечних хвиль) дорівнює:

```
N(k) = 3 · [ (4/3) π k³ ] / [ (2π)³ / V ]
= (V k³) / (2 π²)             [скорочення пі та чисел 3 і 4]
```

Використовуючи закон дисперсії `k = ω / v`, виразимо підсумкову кількість мод через частоту `ω`:

```
N(ω) = (V ω³) / (2 π² v³)
```

Диференціюючи `N(ω)` за частотою, знайдемо **спектральну щільність станів** `g(ω) = dN / dω`:

```
g(ω) = (3 V ω²) / (2 π² v³)
```

Спектральна щільність станів акустичних хвиль у тривимірному середовищі зростає пропорційно квадрату частоти `g(ω) ~ ω²`.

### Нормування та гранична частота Дебая `ω_D`:

Оскільки реальний кристал складається з скінченного числа атомів `N`, загальна кількість коливальних мод не може перевищувати `3N`. Дебай зрізав спектр частот на такій граничній **частоті Дебая** `ω_D`, за якої загальна кількість мод дорівнює `3N`:

```
∫₀^(ω_D) g(ω) dω = 3N

∫₀^(ω_D) [ (3 V ω²) / (2 π² v³) ] dω = (V ω_D³) / (2 π² v³) = 3N
```

Звідси отримуємо математичний вираз для граничної частоти Дебая:

```
ω_D = v · [ (6 π² N) / V ]^(1/3)
```

Введемо характерну **температуру Дебая** `Θ_D`:

```
Θ_D = (ℏ ω_D) / k_B
```

Завдяки нормалізації, коефіцієнт при `ω²` у спектральній щільності станів можна переписати безпосередньо через `3N` та `ω_D`:

```
g(ω) = (9 N ω²) / ω_D³       [для 0 ≤ ω ≤ ω_D; при ω > ω_D: g(ω) = 0]
```

### Повна внутрішня енергія кристала в моделі Дебая:

Внутрішня енергія є інтегралом за всіма частотами фононного спектра від добутку квантової енергії моди `ℏ ω`, її середнього числа заповнення Планка та спектральної щільності станів `g(ω)`:

```
U(T) = ∫₀^(ω_D) [ (ℏ ω) / (exp(ℏ ω / (k_B T)) - 1) ] · [ (9 N ω²) / ω_D³ ] dω
= (9 N ℏ / ω_D³) ∫₀^(ω_D) [ ω³ / (exp(ℏ ω / (k_B T)) - 1) ] dω
```

Перейдемо до безрозмірної змінної інтегрування `x = (ℏ ω) / (k_B T)`:

```
x = (ℏ ω) / (k_B T),   звідси ω = (k_B T x) / ℏ,   dω = (k_B T / ℏ) dx
Верхня межа інтегрування: x_D = (ℏ ω_D) / (k_B T) = Θ_D / T
```

Підставляючи нову змінну в інтеграл внутрішньої енергії:

```
U(T) = (9 N ℏ / ω_D³) · (k_B T / ℏ)⁴ · ∫₀^(Θ_D/T) [ x³ / (exp(x) - 1) ] dx
= 9 N k_B T · (T / Θ_D)³ · ∫₀^(Θ_D/T) [ x³ / (exp(x) - 1) ] dx
```

через стандартну інтегральну функцію Дебая `D_3(y) = (3 / y³) ∫₀^y [ x³ / (exp(x) - 1) ] dx`, молярна внутрішня енергія дорівнює:

```
U_molar(T) = 3 R T · D_3(Θ_D / T)
```

### Математичний вивід теплоємності `C_v(T)`:

Диференціюючи молярну внутрішню енергію по температурі `T`, отримуємо точну формулу Дебая для теплоємності:

```
C_v = (∂U / ∂T)_V
= 9 R · (T / Θ_D)³ · ∫₀^(Θ_D/T) [ (x⁴ exp(x)) / (exp(x) - 1)² ] dx
```

### Асимптотичний аналіз моделі Дебая:

**1. Низькотемпературна границя (Закон `T³` Дебая при `T ≪ Θ_D`):**
При наближенні до абсолютного нуля (`T → 0 K`) верхня межа інтегрування `x_D = Θ_D / T` прямує до нескінченності (`x_D → ∞`). Визначений інтеграл стає невласним і точне значення обчислюється через спеціальні функції:

```
∫₀^∞ [ x³ / (exp(x) - 1) ] dx = Γ(4) · ζ(4)
= 6 · (π⁴ / 90)              [значення гамма- та дзета-функцій]
= π⁴ / 15                    [скорочення 6 та 90]
```

Підставляючи це числове значення у вираз для внутрішньої енергії:

```
U(T) ≈ 9 N k_B T · (T / Θ_D)³ · (π⁴ / 15)
= (3 π⁴ N k_B T⁴) / (5 Θ_D³) [спрощення коефіцієнтів 9/15]
```

Диференціювання за температурою приводить до знаменитого **закону кубу температури Дебая**:

```
C_v = (∂U / ∂T)_V = (12 π⁴ / 5) R · (T / Θ_D)³
≈ 234.5 R · (T / Θ_D)³
```

Закон `T³` математично відображає той факт, що при низьких температурах у кристалі збуджуються лише довгохвильові фонони з малими хвильовими векторами `k`, об'єм фазового простору яких у 3D пропорційний `k³ ~ T³`.

**2. Високотемпературна границя (`T ≫ Θ_D`):**
При високих температурах верхня межа `x_D = Θ_D / T ≪ 1`. Підінтегральний вираз для малих `x` спрощується: `exp(x) - 1 ≈ x`.

```
∫₀^(x_D) [ x³ / (exp(x) - 1) ] dx ≈ ∫₀^(x_D) (x³ / x) dx
= ∫₀^(x_D) x² dx              [ділення x³ / x = x²]
= x_D³ / 3 = (1/3) (Θ_D / T)³ [в взяття первісної від x²]
```

Підставляючи це значення в інтеграл внутрішньої енергії:

```
U(T) ≈ 9 N k_B T · (T / Θ_D)³ · [ (1/3) (Θ_D / T)³ ]
= 3 N k_B T = 3 R T          [скорочення степенів (T/Θ_D)³]
```

Звідси молярна теплоємність при високих температурах знову прямує до класичної границі Дюлонга — Пті:

```
C_v = (∂U / ∂T)_V = 3 R
```

Модель Дебая є фундаментальним математичним містком між квантовою теорією довгих акустичних хвиль при низьких температурах та класичним законом рівнорозподілу енергії при високих температурах.
