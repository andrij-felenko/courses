# ⚙️ Чисельне моделювання теплоємності за Ейнштейном та Дебаєм

Чисельне моделювання молярної теплоємності кристалічних матеріалів вимагає розрахунку визначеного інтеграла з параметричною верхньою межею та порівняння трьох фундаментальних теоретичних моделей: класичного закону Дюлонга — Пті (`C_v = 3R`), одночастотної квантової моделі Ейнштейна та фононної моделі Дебая з безперервним параболічним спектром.

## 1. Алгоритм та математична основа чисельного інтегрування

Головна обчислювальна складність при моделюванні температурної залежності в моделі Дебая полягає в обчисленні визначеного інтеграла з параметричною верхньою межею, яка змінюється залежно від температури:

```
C_v(T) / (3R) = 3 · (T / Θ_D)³ · ∫₀^(Θ_D/T) [ (x⁴ exp(x)) / (exp(x) - 1)² ] dx
```

Для чисельного обчислення цього інтеграла застосовується **адаптивний метод Сімпсона** (параболічна квадратура) на рівномірній сітці розбиття з `N_steps` кроків. Метод Сімпсона забезпечує четвертий порядок точності `O(h⁴)`, що гарантує високу точність обчислень навіть при помірній кількості вузлів розбиття.

### Покрокова обробка особливих точок та чисельної стабілізації:

1. **Поведінка в околі нуля (`x → 0`)**:
   Підінтегральна функція `f(x) = (x⁴ exp(x)) / (exp(x) - 1)²` при `x → 0` містить невизначеність вигляду `0 / 0`. Застосовуючи розклад Тейлора для експоненти `exp(x) - 1 ≈ x`, знаходимо граничне значення:

```
f(x) ≈ (x⁴ · 1) / x² = x² → 0   при x → 0
```

   У програмі при `x ≤ 1e-7` підінтегральний вираз явно прирівнюється до нуля, що відвертає помилки ділення на нуль (`DivisionByZero`).

2. **Запобігання чисельному переповненню (`Overflow`) при низьких температурах**:
   При глибокому кріогенному охолодженні (`T ≪ Θ_D`) верхня межа інтегрування `x_D = Θ_D / T` досягає значень `50...100` і більше. Обчислення значення `exp(x)` для `x > 80` у стандартних числах із подвійною точністю (`double`) призводить до чисельного переповнення.
   
   Для вирішення цієї проблеми алгоритм застосовує фізично обґрунтоване перемикання: для відносних температур `T / Θ_D < 0.08` інтегрування замінюється обчисленням асимптотичної формули **закону кубу температури Дебая**:

```
C_v / (3R) ≈ (4 π⁴ / 5) · (T / Θ_D)³
```

   Це гарантує гладкість і математичну стабільність розрахунку на всьому діапазоні від абсолютного нуля до надвисоких температур.

3. **Оцінка похибки чисельного інтегрування та вибір кроку**:
   Залишкова похибка параболічного методу Сімпсона визначається четвертою похідною підінтегральної функції `R_n = - (b - a)⁵ / (180 N⁴) · f⁴(ξ)`. Оскільки підінтегральна функція Дебая є гладкою та обмеженою на всьому інтервалі `[0, x_D]`, розбиття на `N = 200` інтервалів забезпечує відносну точність обчислення інтеграла вище `1e-6`, що повністю перекриває практичні потреби теплофізичного моделювання.

## 2. Архітектура моделі та покроковий розбір програмних модулів

Система чисельного аналізу складається з п'яти ключових функціональних модулів:

1. **Модуль класичного ліміту `heat_capacity_dulong_petit()`**: повертає точне значення газової константи `3R ≈ 24.9415 J/(mol·K)`, яке відповідає класичній теоремі рівнорозподілу енергії.

2. **Модуль квантового осцилятора Ейнштейна `heat_capacity_einstein(t_rel)`**: обчислює аналітичне значення Ейнштейна від відносної температури `t_rel = T / Θ_E`. Захищений перевіркою відносної температури на рівність нулю та перевищення порогу переповнення (`x > 80`).

3. **Модуль підінтегральної функції `debye_integrand(x)`**: реалізує захищене обчислення квадратурної функції `f(x) = (x⁴ exp(x)) / (exp(x) - 1)²` з автоматичним відсіканням нечисельних значений `NaN` та невизначеностей `Inf` в околі нуля.

4. **Квадратурний модуль Сімпсона `simpson_integrate(func, a, b, steps)`**: реалізує числове інтегрування методом Сімпсона за формулою `(h/3) * [f(a) + 4 f(x1) + 2 f(x2) + ... + f(b)]` з примусовим округленням кількості кроків до парного числа.

5. **Модуль Дебая `heat_capacity_debye(t_rel)`**: виконує інтегральний розрахунок фононного спектра з плавним перемиканням між чисельною параболічною квадратурою та аналітичним критерієм закона кубів `T³` при низьких температурах (`t_rel < 0.08`).

### Деталі програмної реалізації на C++ та Python:

- **C++ (стандарт C++17)**: використовує `std::function` для передачі функціональних об'єктів у квадратурний модуль, математичні константи `constexpr`, а також оптимізоване форматоване виведення через `std::fixed` та `std::setprecision`. Застосування `constexpr` дозволяє компілятору обчислювати константу Дюлонга — Пті ще на етапі компіляції без витрат часу виконання.
- **Python (версія 3.8+)**: застосовує анотації типів (`type hints`), стандартний модуль `math` для обчислення високоточних математичних функцій та експонент, а також форматовані f-рядки для побудови структурованої таблиці результатів. Такий підхід робить код простим для порівняння між мовами та портування у науково-дослідні обчислювальні бібліотеки.

### Детальний аналіз фізичних закономірностей за результатами симуляції:

1. **Кріогенний діапазон (`T / Θ ≤ 0.10`)**:
   - Модель Ейнштейна повертає практично нульове значення (`0.0000 J/(mol·K)` при `T/Θ = 0.05`), оскільки експоненціальний фактор `exp(-20)` прямує до нуля надто швидко через одночастотне припущення.
   - Модель Дебая демонструє ненульовий спад за законами `T³` (`0.0701 J/(mol·K)` при `T/Θ = 0.05`), що точно відображає наявність збуджених акустичних фононів низької частоти з малими квантами енергії `ℏ ω`.

2. **Проміжний середовищний діапазон (`0.20 ≤ T / Θ ≤ 0.50`)**:
   - При `T / Θ = 0.30` теплоємність за Дебаєм сягає `~38.5%` від класичної границі (`9.6053 J/(mol·K)`), тоді як модель Ейнштейна дає лише `5.9557 J/(mol·K)`. Відхилення виникає через те, що модель Ейнштейна ігнорує акустичну дисперсію і занижує щільність станів на низьких частотах.

3. **Високотемпературне насичення (`T / Θ ≥ 1.00`)**:
   - При `T = Θ` модель Дебая досягає `93.2%` від класичного ліміту Дюлонга — Пті (`23.2384 J/(mol·K)`).
   - При `T = 1.50 Θ` обидві квантові моделі збігаються до класичного значення `24.9415 J/(mol·K)` з точністю вище `95%`, підтверджуючи справедливість закону Дюлонга — Пті при високих температурах.

### Практичне значення для обчислювальної фізики:

Створення подібних симуляційних модулів є стандартним етапом аналізу теплофізичних властивостей нових сплавів, напівпровідникових гетероструктур та металокерамічних композитів. Знаючи виміряну швидкість звуку та густину нового матеріалу, модель дозволяє безкоштовно прогнозувати його теплоємність у діапазоні від кріогенних `4 K` до високих робочих температур.
