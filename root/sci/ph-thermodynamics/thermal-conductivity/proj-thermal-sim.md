# ⚙️ Моделювання одновимірного та двовимірного переносу тепла сітковим методом

Ця вставка містить розробку чисельного алгоритму розв'язання нестаціонарного рівняння теплопровідності методом скінченних різниць (явна схема FTCS та неявна схема Кранка-Ніколсона) для композитного стрижня з різними матеріалами, аналіз критерію стійкості Куранта-Фрідріхса-Леві (числа Фур'є), математичний вивід прогонки Томаса, а також готові реалізації мовами C та C++.

---

### 1. Математичне обґрунтування сіткового методу скінченних різниць

Диференціальне рівняння теплопровідності в одновимірному випадку при відсутності внутрішніх джерел тепла має вигляд:

```
∂T/∂t = α · (∂²T/∂x²)
```

де `α = λ / (ρ · c_p)` — коефіцієнт температуропровідності матеріалу [м²/с].

Для чисельного розв'язання цього рівняння на ЕОМ неперервну просторово-часову область `(x, t)` замінюють дискретною розрахунковою сіткою. Позначимо:
- Крок просторової сітки: `Δx` (індекси вузлів `i = 0, 1, 2, ..., N-1`).
- Крок часової сітки: `Δt` (індекси часових шарів `n = 0, 1, 2, ...`).
- Значення температури у вузлі `i` на часовому шарі `n`: `T_i^n = T(i·Δx, n·Δt)`.

#### 1.1. Апроксимація похідних за допомогою рядів Тейлора

Щоб перейти від диференціальних похідних до різницевих аналогів, розкладемо функцію температури `T(x, t)` у ряд Тейлора за просторовою координатою `x` довкола вузла `i`:

```
T_{i+1}^n = T_i^n + (∂T/∂x)_i · Δx + (1/2) · (∂²T/∂x²)_i · (Δx)² + (1/6) · (∂³T/∂x³)_i · (Δx)³ + O((Δx)⁴)
T_{i-1}^n = T_i^n - (∂T/∂x)_i · Δx + (1/2) · (∂²T/∂x²)_i · (Δx)² - (1/6) · (∂³T/∂x³)_i · (Δx)³ + O((Δx)⁴)
```

Додаючи ці два рівняння, отримуємо центрально-різницеву апроксимацію другої просторової похідної другого порядку точності `O((Δx)²)`:

```
(∂²T/∂x²)_i ≈ [ T_{i+1}^n - 2·T_i^n + T_{i-1}^n ] / (Δx)²
```

Для часової похідної використуємо праву різницю першого порядку точності `O(Δt)`:

```
(∂T/∂t)_i ≈ [ T_i^{n+1} - T_i^n ] / Δt
```

#### 1.2. Явна різницева схема FTCS

Підставляючи отримані різницеві вирази у вихідне диференціальне рівняння, отримуємо явну схему FTCS (*Forward-Time Central-Space*):

```
[ T_i^{n+1} - T_i^n ] / Δt = α · [ T_{i+1}^n - 2·T_i^n + T_{i-1}^n ] / (Δx)²
```

Виразивши температуру на новому часовому кроці `T_i^{n+1}`, отримуємо підсумкову розрахункову формулу:

```
T_i^{n+1} = T_i^n + Fo · [ T_{i+1}^n - 2·T_i^n + T_{i-1}^n ]
```

де `Fo` — безрозмірне чисельне **число Фур'є сітки**:

```
Fo = α · Δt / (Δx)²
```

Схема називається **явною**, оскільки температура `T_i^{n+1}` у кожному вузлі на новому часовому шарі обчислюється безпосередньо через відомі значення температур `T_{i-1}^n`, `T_i^n`, `T_{i+1}^n` на попередньому часовому шарі.

### 2. Спектральний аналіз стійкості Фон Неймана та пастка CFL

Незважаючи на простоту програмування, явна схема FTCS має сувору математичну межу стійкості. Якщо вибрати занадто великий крок за часом `Δt`, розв'язок стає чисельно нестійким: помилки заокруглення швидко зростають від кроку до кроку, утворюючи фантомні високочастотні коливання з нескінченною амплітудою.

#### 2.1. Аналіз методом Фон Неймана

Дослідимо поширення гармоніки чисельної помилки вигляду `E_i^n = ξ^n · exp(I · k · i · Δx)`, де `I = √(-1)` — уявна одиниця, `k` — хвильове число помилки, а `ξ` — множник підсилення за один крок часу.

Підставляючи гармоніку у різницеву формулу FTCS, маємо:

```
ξ^(n+1) · exp(I·k·i·Δx) = ξ^n · exp(I·k·i·Δx) + Fo · ξ^n · [ exp(I·k·(i+1)·Δx) - 2·exp(I·k·i·Δx) + exp(I·k·(i-1)·Δx) ]
```

Поділивши обидві частини на `ξ^n · exp(I·k·i·Δx)`, отримуємо вираз для множника підсилення `ξ`:

```
ξ = 1 + Fo · [ exp(I·k·Δx) - 2 + exp(-I·k·Δx) ]
```

Використовуючи формулу Ейлера `exp(I·θ) + exp(-I·θ) = 2·cos(θ) = 2 - 4·sin²(θ/2)`:

```
ξ = 1 - 4 · Fo · sin²(k · Δx / 2)
```

Для того щоб чисельна помилка не зростала з часом, модуль множника підсилення повинен задовольняти умову стійкості `|ξ| ≤ 1` для будь-яких хвильових чисел `k`:

```
-1 ≤ 1 - 4 · Fo · sin²(k · Δx / 2) ≤ 1
```

Права нерівність задовольняється завжди (оскільки `Fo > 0`). З лівої нерівності у найгіршому випадку (`sin²(k·Δx/2) = 1` для найкоротшої сіткової хвилі) отримуємо:

```
1 - 4 · Fo ≥ -1     ⇒     4 · Fo ≤ 2     ⇒     Fo ≤ 1/2
```

Таким чином, **умова стійкості Куранта-Фрідріхса-Леві (CFL) для явної 1D схеми теплопровідності** має вигляд:

```
Fo = α · Δt / (Δx)² ≤ 1/2      ⇒      Δt ≤ (Δx)² / (2 · α)
```

#### 2.2. Наслідки умовної стійкості для обчислювальної складності

З критерію CFL випливає важливий практичний висновок: **дозволений крок часу `Δt` пропорційний КВАДРАТУ просторового кроку `(Δx)²`**.

Якщо ви вирішите подвоїти точність симуляції (зменшити `Δx` удвічі, наприклад із 1 мм до 0.5 мм), то для збереження стійкості вам доведеться зменшити крок часу `Δt` у **чотири рази**. А оскільки кількість просторових вузлів подвоїться, сумарна обчислювальна складність симуляції зросте у **вісім разів** (`2³ = 8`)!

При моделюванні високопровідних матеріалів (наприклад, міді з `α ≈ 117 мм²/с`) на дрібній сітці `Δx = 0.1 мм` граничний крок часу становить лише:

```
Δt_max = (0.1)² / (2 · 117) = 0.01 / 234 ≈ 0.0000427 с = 42.7 мкс
```

Для симуляції 10 секунд фізичного часу програмі доведеться виконати понад 230 000 часових кроків.

### 3. Дискретизація граничних умов та неоднорідних контактів

У реальних інженерних задачах геометрія складається з декількох матеріалів, а на поверхнях діють розмаїті граничні умови.

#### 3.1. Реалізація граничних умов I, II та III роду

- **Граничні умови I роду (задана температура Діріхле):**
  Вузли на межах `i = 0` та `i = N-1` мають примусово фіксовані значення:
  `T_0^{n+1} = T_left(t)`, `T_{N-1}^{n+1} = T_right(t)`.

- **Граничні умови II роду (заданий тепловий потік Неймана):**
  На адіабатичній (ізольованій) границі густина потоку дорівнює нулю `(∂T/∂x) = 0`. Апроксимація через фіктивний вузол `i = -1` дає `T_{-1} = T_1`. Підставляючи у формулу FTCS для граничного вузла `i = 0`, маємо:
  `T_0^{n+1} = T_0^n + 2 · Fo · (T_1^n - T_0^n)`

- **Граничні умови III роду (конвективний теплообмін Робіна):**
  На межі діє баланс `-λ · (∂T/∂x) = h · (T_0 - T_amb)`. Використовуючи фіктивний вузол `T_{-1} = T_1 + 2·Δx·(h/λ)·(T_amb - T_0^n)`, отримуємо різницеве рівняння для вузла поверхні:
  `T_0^{n+1} = T_0^n + 2 · Fo · [ T_1^n - T_0^n + (h · Δx / λ) · (T_amb - T_0^n) ]`

#### 3.2. Гармонійне усереднення на стику двох матеріалів

Якщо у вузлі `i_int` стикаються два матеріали з різними теплопровідностями `λ₁` та `λ₂` (наприклад, мідь і нержавіюча сталь), пряме арифметичне усереднення `(λ₁ + λ₂)/2` створює фальшиві витоки тепла.

Умова безперервності теплового потоку `q_left = q_right` на контактній грані вимагає обчислення **гармонійного середнього коефіцієнта теплопровідності**:

```
λ_interface = 2 · λ₁ · λ₂ / (λ₁ + λ₂)
```

Це гармонійне усереднення гарантує суворе дотримання закону збереження енергії у кожній комірці дискретної сітки.

### 4. Неявна схема Кранка-Ніколсона та алгоритм прогонки Томаса (TDMA)

Щоб зняти жорстке обмеження стійкості `Fo ≤ 0.5`, використовують **неявну схему Кранка-Ніколсона** (*Crank-Nicolson Scheme*).

#### 4.1. Математичне формування неявної схеми

Схема Кранка-Ніколсона апроксимує другу просторову похідну як середнє арифметичне між поточним шаром `n` та майбутнім шаром `n+1`:

```
[ T_i^{n+1} - T_i^n ] / Δt = (α / 2) · [ ( T_{i+1}^{n+1} - 2·T_i^{n+1} + T_{i-1}^{n+1} ) / (Δx)² + ( T_{i+1}^n - 2·T_i^n + T_{i-1}^n ) / (Δx)² ]
```

Переносячи невідомі значення на шарі `n+1` у ліву частину, а відомі на шарі `n` — у праву, отримуємо тридіагональну систему лінійних рівнянь:

```
- (Fo / 2) · T_{i-1}^{n+1} + ( 1 + Fo ) · T_i^{n+1} - (Fo / 2) · T_{i+1}^{n+1} = (Fo / 2) · T_{i-1}^n + ( 1 - Fo ) · T_i^n + (Fo / 2) · T_{i+1}^n
```

Схема Кранка-Ніколсона є **абсолютно чисельно стійкою** при будь-яких значеннях кроку часу `Δt` і має другий порядок точності за часом і простором `O((Δt)² + (Δx)²)`!

#### 4.2. Алгоритм прогонки Томаса (TDMA — Tri-Diagonal Matrix Algorithm)

Для ефективного розв'язання тридіагональної системи `a_i · T_{i-1}^{n+1} + b_i · T_i^{n+1} + c_i · T_{i+1}^{n+1} = d_i` із складності `O(N³)` методу Ґаусса використовують спеціалізований алгоритм Томаса зі складністю **`O(N)`**:

1. **Прямий хід прогонки:** Обчислюються прогонкові коефіцієнти `P_i` та `Q_i` від `i = 1` до `N-1`:
   ```
   P_i = - c_i / ( b_i + a_i · P_{i-1} )
   Q_i = ( d_i - a_i · Q_{i-1} ) / ( b_i + a_i · P_{i-1} )
   ```
2. **Обернений хід прогонки:** Знаходяться температури від `i = N-1` до `0`:
   ```
   T_i^{n+1} = P_i · T_{i+1}^{n+1} + Q_i
   ```

### 5. Розширення на двовимірний випадок (2D FTCS)

У двовимірному випадку для сітки `(x_i, y_j)` із кроками `Δx` та `Δy` диференціальне рівняння має вигляд `∂T/∂t = α · (∂²T/∂x² + ∂²T/∂y²)`. 

Явна різницева формула FTCS набуває вигляду:

```
T_{i,j}^{n+1} = T_{i,j}^n + Fo_x · [ T_{i+1,j}^n - 2·T_{i,j}^n + T_{i-1,j}^n ] + Fo_y · [ T_{i,j+1}^n - 2·T_{i,j}^n + T_{i,j-1}^n ]
```

де `Fo_x = α · Δt / (Δx)²` та `Fo_y = α · Δt / (Δy)²`.

Умова стійкості CFL для 2D явної схеми стає ще суворішою:

```
Fo_x + Fo_y ≤ 1/2
```

Якщо крок сітки однаковий по двох осях (`Δx = Δy`), граничний крок часу зменшується у два рази порівняно з одновимірним випадком:

```
Δt ≤ (Δx)² / (4 · α)
```

### 6. Програмна реалізація мовами C та C++

Нижче наведено робочі програмні модулі симуляції нестаціонарного прогрівання композитного стрижня (Мідь + Нержавіюча сталь завдовжки 10 см), лівий кінець якого утримується при 100 °C, а правий — при 20 °C.

:::tabs
```c
/* thermal_sim.c — Симуляція 1D теплопровідності методом FTCS мовою C */
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

typedef struct {
    double lambda; /* Вт/(м·К) */
    double rho;    /* кг/м³ */
    double cp;     /* Дж/(кг·К) */
    double alpha;  /* м²/с */
} Material;

int main(void) {
    const double length = 0.10;    /* 10 см */
    const int N = 100;             /* 100 вузлів сітки */
    const double dx = length / (N - 1);
    const double total_time = 5.0; /* 5 секунд симуляції */

    /* Властивості матеріалів */
    Material copper = {390.0, 8960.0, 385.0, 390.0 / (8960.0 * 385.0)};
    Material steel  = {15.0,  7900.0, 500.0, 15.0  / (7900.0 * 500.0)};

    /* Максимальна температуропровідність визначає крок часу */
    double max_alpha = (copper.alpha > steel.alpha) ? copper.alpha : steel.alpha;
    double dt = 0.45 * (dx * dx) / max_alpha; /* Запасовий коефіцієнт 0.45 < 0.5 */

    int steps = (int)(total_time / dt);

    double *T = (double *)malloc(N * sizeof(double));
    double *T_new = (double *)malloc(N * sizeof(double));
    double *alpha_grid = (double *)malloc(N * sizeof(double));

    if (!T || !T_new || !alpha_grid) {
        fprintf(stderr, "Помилка виділення пам'яті\n");
        free(T); free(T_new); free(alpha_grid);
        return 1;
    }

    /* Ліва половина (0..N/2) — мідь, права (N/2..N) — сталь */
    int mid = N / 2;
    for (int i = 0; i < N; i++) {
        alpha_grid[i] = (i < mid) ? copper.alpha : steel.alpha;
        T[i] = 20.0; /* Початкова температура 20 °C */
    }

    /* Граничні умови */
    T[0] = 100.0;     /* Лівий кінець 100 °C */
    T[N - 1] = 20.0;  /* Правий кінець 20 °C */

    /* Часовий цикл */
    for (int step = 0; step < steps; step++) {
        T_new[0] = 100.0;
        T_new[N - 1] = 20.0;

        for (int i = 1; i < N - 1; i++) {
            double fo = alpha_grid[i] * dt / (dx * dx);
            T_new[i] = T[i] + fo * (T[i + 1] - 2.0 * T[i] + T[i - 1]);
        }

        /* Оновлення масиву */
        for (int i = 0; i < N; i++) {
            T[i] = T_new[i];
        }
    }

    printf("=== Профіль температури через %.1f с ===\n", total_time);
    printf("x = 0.00 м (Вхід Cu):   %.2f °C\n", T[0]);
    printf("x = 0.025 м (Середина Cu): %.2f °C\n", T[N / 4]);
    printf("x = 0.050 м (Стик Cu-Steel): %.2f °C\n", T[N / 2]);
    printf("x = 0.075 м (Середина Steel): %.2f °C\n", T[3 * N / 4]);
    printf("x = 0.100 м (Вихід Steel): %.2f °C\n", T[N - 1]);

    free(T);
    free(T_new);
    free(alpha_grid);
    return 0;
}
```
```cpp
// thermal_sim.cpp — Симуляція 1D теплопровідності методом FTCS мовою C++
#include <iostream>
#include <vector>
#include <algorithm>
#include <iomanip>
#include <stdexcept>
#include <span>

struct Material {
    double lambda; // Вт/(м·К)
    double rho;    // кг/м³
    double cp;     // Дж/(кг·К)

    [[nodiscard]] constexpr double alpha() const noexcept {
        return lambda / (rho * cp);
    }
};

class ThermalSimulator1D {
private:
    double length_;
    size_t nodes_;
    double dx_;
    std::vector<double> T_;
    std::vector<double> alpha_grid_;

public:
    ThermalSimulator1D(double length, size_t nodes, const Material& mat_left, const Material& mat_right)
        : length_(length), nodes_(nodes), dx_(length / (nodes - 1)), T_(nodes, 20.0), alpha_grid_(nodes) {
        if (nodes < 3) {
            throw std::invalid_argument("Кількість вузлів сітки має бути не менше 3");
        }
        
        size_t mid = nodes / 2;
        for (size_t i = 0; i < nodes; ++i) {
            alpha_grid_[i] = (i < mid) ? mat_left.alpha() : mat_right.alpha();
        }
    }

    void set_boundary_conditions(double t_left, double t_right) noexcept {
        T_.front() = t_left;
        T_.back() = t_right;
    }

    void run(double total_time) {
        double max_alpha = *std::max_element(alpha_grid_.begin(), alpha_grid_.end());
        double dt = 0.45 * (dx_ * dx_) / max_alpha; // Захисний запас стійкості CFL
        size_t steps = static_cast<size_t>(total_time / dt);

        std::vector<double> T_next = T_;

        for (size_t step = 0; step < steps; ++step) {
            T_next.front() = T_.front();
            T_next.back() = T_.back();

            for (size_t i = 1; i < nodes_ - 1; ++i) {
                double fo = alpha_grid_[i] * dt / (dx_ * dx_);
                T_next[i] = T_[i] + fo * (T_[i + 1] - 2.0 * T_[i] + T_[i - 1]);
            }
            T_ = T_next;
        }
    }

    [[nodiscard]] std::span<const double> temperature_profile() const noexcept {
        return T_;
    }
};

int main() {
    try {
        constexpr Material copper{390.0, 8960.0, 385.0};
        constexpr Material steel{15.0, 7900.0, 500.0};

        constexpr double bar_length = 0.10;
        constexpr size_t grid_nodes = 100;
        constexpr double simulation_time = 5.0;

        ThermalSimulator1D sim(bar_length, grid_nodes, copper, steel);
        sim.set_boundary_conditions(100.0, 20.0);
        sim.run(simulation_time);

        auto profile = sim.temperature_profile();

        std::cout << std::fixed << std::setprecision(2);
        std::cout << "=== Профіль температури (C++) через " << simulation_time << " с ===\n";
        std::cout << "x = 0.00 м (Вхід Cu):     " << profile[0] << " °C\n";
        std::cout << "x = 0.025 м (Середина Cu):   " << profile[grid_nodes / 4] << " °C\n";
        std::cout << "x = 0.050 м (Стик Cu-Steel): " << profile[grid_nodes / 2] << " °C\n";
        std::cout << "x = 0.075 м (Середина Steel): " << profile[3 * grid_nodes / 4] << " °C\n";
        std::cout << "x = 0.100 м (Вихід Steel):   " << profile.back() << " °C\n";

    } catch (const std::exception& e) {
        std::cerr << "Помилка виконання: " << e.what() << '\n';
        return 1;
    }
    return 0;
}
```

### 7. Аналіз підходів до оптимізації та апаратного прискорення

1. **Метод змінних напрямків (ADI — Alternating Direction Implicit):**
   Використовується для 2D та 3D задач. На кожному напівкроці за часом неявно розв'язується диференціальне рівняння вздовж однієї осі (наприклад, `x`), а на другому напівкроці — вздовж осі `y`. Це дозволяє звести 2D задачу до набору простих 1D тридіагональних систем, зберігаючи абсолютну стійкість.
2. **Апаратна оптимізація (SIMD та OpenMP):**
   При обчисленні явної схеми FTCS внутрішній цикл `for (size_t i = 1; i < N - 1; ++i)` не має міжциклових залежностей даних на поточному кроці. Це дозволяє компілятору векторизувати обчислення за допомогою процесорних інструкцій AVX2/AVX-512 (обробка 4 чи 8 чисел типу `double` за один такт) та паралелити розрахунок між ядрами CPU через інструкції OpenMP (`#pragma omp parallel for`).
3. **Кеш-локальність та вирівнювання пам'яті:**
   У 2D і 3D симуляціях масиви слід зберігати у неперервній пам'яті (row-major order у C/C++), щоб внутрішній обхід ішов уздовж неперервних адрес. Це забезпечує 100% влучання у L1/L2 кеш процесора.
