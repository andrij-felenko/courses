# 📋 Довідник теплофізичних властивостей матеріалів

Цей довідник містить систематизовані числові дані щодо коефіцієнта теплопровідності `λ` [Вт/(м·К)], температуропровідності `α` [мм²/с], густини `ρ` [кг/м³], питомої теплоємності `c_p` [Дж/(кг·К)], чисел Лоренца `L` та температурних коефіцієнтів для широкого спектра конструкційних металів, напівпровідників, діелектриків, рідин, газів і новітніх теплоізоляційних матеріалів при стандартній температурі (293–300 K) та у розширених температурних діапазонах.

---

### 1. Фізична структуризація та огляд матеріальних класів

Теплофізичні параметри речовини є результатом комплексної взаємодії її електронної підсистеми, фононного спектра та структурного впорядкування. При виборі матеріалу для інженерних розрахунків необхідно враховувати не лише номінальне значення теплопровідності `λ` за кімнатної температури, але й температурну залежність `λ(T)`, механізм розсіювання носіїв та анізотропію провідності.

Нижче наведено п'ять основних матеріальних класів, розмежованих за панівним мікроскопічним носієм теплової енергії:

1. **Кристалічні монокристали та наноматеріали (фононна та електронна надпровідність тепла):** Алмаз, графен, вуглецеві нанотрубки, чисте срібло та мідь. Вони демонструють коефіцієнти теплопровідності від 400 до 5000 Вт/(м·К). У монокристалічному алмазі довжина вільного пробігу фононів за кімнатної температури перевищує 0.5 мкм завдяки виключно жорстким ковалентним зв'язкам і малій атомній масі вуглецю.
2. **Конструкційні метали та промислові сплави:** Алюмінієві, мідні, залізні та титанові сплави. У чистих металах перенос здійснюється вільними електронами (`λ_e >> λ_ph`). Впровадження легуючих елементів створює хаотичні центри розсіювання для електронів провідності, що зменшує теплопровідність сплавів у 3–10 разів порівняно з чистими елементами.
3. **Широкозонні напівпровідники та високопровідна кераміка:** Карбід кремнію (4H-SiC), нітрид алюмінію (AlN), оксид берилію (BeO), монокристалічний кремній (Si). Вони поєднують високу теплопровідність (150–490 Вт/(м·К)) із високим електричним опором, що робить їх незамінними субстратами для силової напівпровідникової електроніки.
4. **Аморфні діелектрики, полімери та будівельні матеріали:** Силікатні й кварцові стекла, пластики, бетон, цегла, деревина. Через відсутність далекого порядку розташування атомів середня довжина вільного пробігу фононів падає до міжатомних відстаней (`l ≈ 0.5–1 нм`), спричиняючи низькі значення `λ` у діапазоні 0.1–1.5 Вт/(м·К).
5. **Гази, рідини та нанопористі суперізолятори:** Повітря, гелій, аргон, елегаз, вода, масла, аерогелі та вакуумні панелі. Теплопровідність газів описується кінетичними зіткненнями молекул і лежить у межах 0.005–0.18 Вт/(м·К). Кремнеземні аерогелі пригнічують газову теплопровідність за рахунок нанорозмірних пор (`d_pore < 40 нм`), що викликає ефект Кнудсена.

### 3. Аналітичні моделі температурних залежностей

При розрахунку теплових режимів обладнання у широкому діапазоні температур табличних даних при 300 K недостатньо. Нижче наведено три математичні моделі для апроксимації залежності `λ(T)`.

#### 3.1. Електронний перенос у металах (Модель Блоха-Ґрюнайзена)

Для чистих металів при високих температурах (`T > θ_D`, де `θ_D` — температура Дебая) електронна теплопровідність слабко змінюється з температурою, оскільки електричний опір зростає лінійно `ρ_e ∝ T`, що компенсує множник `T` у формулі Віддемана-Франца `λ = L · T / ρ_e`. Лінійний температурний коефіцієнт `β` [1/K] застосовується для вузьких інтервалів (250–500 K):

```
λ(T) = λ_0 · [ 1 + β · (T - T_0) ]
```

Типові значення `β` при `T_0 = 293 K`:
- Чиста мідь: `β = -0.0003 1/K` (слабке падіння)
- Чистий алюміній: `β = -0.0002 1/K`
- Нержавіюча сталь 304: `β = +0.0015 1/K` (зростання через зменшення розсіювання на хаотичних домішках)
- Титановий сплав ВТ6: `β = +0.0018 1/K`

#### 3.2. Решітковий перенос у кристалічних діелектриках (Процеси Умкляппа)

У кристалічних діелектриках при високих температурах (`T > θ_D`) домінують трифононні процеси перекиду (процеси Умкляппа), які зменшують довжину вільного пробігу фононів як `l ∝ 1/T`. Залежність описується степеневим законом:

```
λ_lattice(T) = λ_300 · ( 300 / T )^m
```

Показник степеня `m` становить:
- Ідеальний монокристал кремнію: `m = 1.33` (при `T > 200 K`)
- Монокристал оксиду алюмінію (сапфір): `m = 1.10`
- Кераміка AlN: `m = 0.75` (зменшення через розсіювання на межах зерен)

#### 3.3. Кінетична теорія газів (Формула Сазерленда для теплопровідності)

Температурна залежність теплопровідності газів визначається зростанням середньої швидкості молекул `v_avg ∝ √T` та ефективним перерізом зіткнень:

```
λ_gas(T) = λ_0 · ( T / T_0 )^(3/2) · [ (T_0 + S) / (T + S) ]
```

де `S` — константа Сазерленда для даного газу:
- Повітря: `S = 110.4 K`, `λ_0 = 0.0262 Вт/(м·К)` при `T_0 = 293.15 K`
- Гелій: `S = 79.4 K`, `λ_0 = 0.151 Вт/(м·К)`
- Вуглекислий газ CO₂: `S = 222.0 K`, `λ_0 = 0.0168 Вт/(м·К)`

### 4. Інженерні приклади використання довідникових даних

#### Приклад 4.1: Розрахунок витоку тепла у кріогенному трубопроводі рідкого азоту

**Постановка задачі:** Тонкостінний трубопровід із нержавіючої сталі AISI 304 (зовнішній діаметр `D = 50 мм`, товщина стінки `δ = 1.5 мм`, довжина `L = 1.0 м`) з'єднує внутрішній бак із рідким азотом (`T_1 = 77 K`) із зовнішньою оболонкою кріостата (`T_2 = 293 K`). Визначити тепловий потік `P` [Вт], що затікає у кріогенний бак за рахунок теплопровідності металу стінки.

**Розв'язання:**
Для нержавіючої сталі 304 теплопровідність суттєво спадає при кріогенних температурах: при 293 K `λ = 16.2 Вт/(м·К)`, а при 77 K `λ = 8.2 Вт/(м·К)`. Використовувати значення при кімнатній температурі не можна — це призведе до значної помилки!

Обчислимо середню інтегральну теплопровідність `λ_avg` у діапазоні від 77 K до 293 K за формулою:

```
λ_avg = (1 / (T_2 - T_1)) · ∫_{T_1}^{T_2} λ(T) dT
```

Для сталі AISI 304 інтегральна середня теплопровідність на інтервалі 77–293 K становить `λ_avg ≈ 12.5 Вт/(м·К)`.

Площа поперечного перерізу металевої стінки труби:

```
A = π · D · δ = 3.14159 · 0.050 м · 0.0015 м = 2.356 × 10⁻⁴ м²
```

Обчислюємо затікання теплової потужності за законом Фурьє:

```
P = λ_avg · A · (T_2 - T_1) / L
= 12.5 Вт/(м·К) · (2.356 × 10⁻⁴ м²) · (293 - 77 K) / 1.0 м
= 12.5 · 0.0002356 · 216
= 0.636 Вт
```

Витік тепла крізь трубу становить 0.636 Вт. Оскільки питома теплота випаровування рідкого азоту становить `r = 199 кДж/кг`, цей витік теплоти призведе до випаровування `m = (0.636 Дж/с · 86400 с) / 199000 Дж/кг ≈ 0.276 кг` рідкого азоту на добу.

#### Приклад 4.2: Розрахунок пригнічення теплопровідності газу у нанопорах аерогелю (Ефект Кнудсена)

**Постановка задачі:** Кремнеземний аерогель має середній діаметр пор `d_pore = 20 нм`. Обчислити ефективну теплопровідність газу `λ_gas_eff` всередині пор аерогелю за атмосферного тиску (`P = 101.3 кПа`, `T = 293 K`), якщо середня довжина вільного пробігу молекул повітря становить `l_0 = 68 нм`, а теплопровідність вільного повітря `λ_gas_0 = 0.0262 Вт/(м·К)`.

**Розв'язання:**
Число Кнудсена `Kn` визначається як відношення довжини вільного пробігу молекул газу до характерного розміру пори:

```
Kn = l_0 / d_pore = 68 нм / 20 нм = 3.4
```

Оскільки `Kn > 1`, домінує нанопористий ефект Кнудсена: молекули газу частіше зіштовхуються зі стінками пор, ніж одна з одною. Ефективна теплопровідність газу у порах описується формулою Каганера:

```
λ_gas_eff = λ_gas_0 / ( 1 + 2 · β_kn · Kn )
```

де `β_kn ≈ 1.8` — коефіцієнт ефективності передачі енергії при зіткненні молекул зі стінкою пори.

```
λ_gas_eff = 0.0262 / ( 1 + 2 · 1.8 · 3.4 )
= 0.0262 / ( 1 + 12.24 )
= 0.0262 / 13.24
= 0.00198 Вт/(м·К)
```

Завдяки ефекту Кнудсена газова складова теплопровідності у порах аерогелю зменшилася з 0.0262 до 0.00198 Вт/(м·К) — тобто більше ніж у **13 разів**! Саме це забезпечує аерогелям феноменально низьку підсумкову теплопровідність (`λ_total = λ_solid + λ_gas_eff + λ_rad ≈ 0.014 Вт/(м·К)`).

### 5. Методики вимірювання теплопровідності та стандарти випробувань

Для експериментального визначення теплофізичних властивостей матеріалів застосовують стандартизовані вимірювальні установки.

#### 5.1. Метод захищеної гарячої пластини (Guarded Hot Plate, GHP) — ISO 8302 / ASTM C177
- **Принцип:** Стаціонарний метод. Зразок матеріалу затискають між нагрівачем і холодильником. Навколо центрального нагрівача розміщують охоронне кільце з однаковою температурою, що усуває бокові витоки тепла.
- **Сфера застосування:** Теплоізоляційні матеріали, будівельні блоки, аерогелі (`λ = 0.001 – 2.0 Вт/(м·К)`).
- **Точність:** Висока (до 1%), є абсолютним первинним стандартом.

#### 5.2. Метод лазерного спалаху (Laser Flash Analysis, LFA) — ISO 22007-4 / ASTM E1461
- **Принцип:** Нестаціонарний метод. Короткий світловий імпульс лазера (тривалістю < 1 мс) нагріває передню поверхню плоского диска зразка (діаметром 10 мм, товщиною 1–3 мм). Інфрачервоний детектор фіксує криву підйому температури на задній поверхні `T(t)`.
- **Вимірювана величина:** Температуропровідність `α = 0.1388 · d² / t_{1/2}` (де `t_{1/2}` — час напівпідйому температури). Далі теплопровідність обчислюється як `λ = α · ρ · c_p`.
- **Сфера застосування:** Метали, кераміка, полімери, напівпровідники при температурах від -150 °C до +2800 °C.

#### 5.3. Метод переходного планарного джерела (Transient Plane Source, TPS / Hot Disk) — ISO 22007-2
- **Принцип:** Двофункціональний сенсор у вигляді плоскої подвійної спіралі з нікелевої фольги затискають між двома зразками. Сенсор одночасно слугує нагрівачем і термометром опору.
- **Переваги:** Дозволяє виміряти `λ` та `α` в одному експерименті тривалістю 2–10 секунд без руйнування зразка.

#### 5.4. Метод 3-омега (3-Omega Method)
- **Принцип:** Гармонійний електричний метод для вимірювання тонких плівок та мікроструктур. Через вузьку металеву смужку, напилену на зразок, пропускають змінний струм із частотою `ω`. Джоулів нагрів викликає коливання температури на подвійній частоті `2ω`, що змінює опір смужки й створює третю гармоніку напруги з частотою `3ω`.
- **Переваги:** Висока чутливість до плівок товщиною від 10 нм до 100 мкм на субстратах.
