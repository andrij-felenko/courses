Ця практична вставка містить детальні математичні алгоритми та повністю працюючі програмні реалізації мовами C та C++ для чисельного розрахунку температурних залежностей теплоємності газів та твердих тіл у класичних та квантових моделях Дюлонга — Пті, Ейнштейна та Дебая. ## 1. Постановка обчислювальної задачі та термодинамічні алгоритми

Чисельне моделювання теплоємності макроскопічних фізичних систем у широкому температурному діапазоні від 0.1 К до 1000 К вимагає врахування різноманітних мікроскопічних механізмів поглинання теплової енергії. Розроблений обчислювальний комплекс виконує чотири основні розрахункові задачі, кожна з яких описує специфічний квантовий або термодинамічний процес:

1. **Гази з орто- та пара- модифікаціями та квантовим виморожуванням:**
   Для двоатомних газів (зокрема водню `H₂`) молярна теплоємність `C_V(T)` описується сумою поступального (`1.5 R`), обертального та коливального внесків. Обертальна статистична сума `Z_rot` обчислюється явним підсумовуванням за дискретними квантовими рівнями з моментом `J`:
   ```
   Z_{rot} = ∑_{J=0}^∞ (2J + 1) · exp( - J(J + 1) · T_{rot} / T )
   ```
   Для гомоядерних молекул з урахуванням спіну ядра (орто-водень зі спіном 1 та пара-водень зі спіном 0) виникає характерний аномальний пік обертальної теплоємності при температурі близько 50 К, який вимагає окремого статистичного сумування парних та непарних рівнів `J`.

2. **Модель Ейнштейна для оптичних фононів:**
   Моделює теплоємність оптичних гілок коливань кристалічної ґратки. Описується аналітичною формулою:
   ```
   C_V^E(T) = 3 R · (T_E / T)² · exp(T_E / T) / [ exp(T_E / T) - 1 ]²
   ```
   При `T → 0` виникає проблема числової нестійкості (ділення на зникаюче мале значення або переповнення експоненти), тому в програмі реалізовано автоматичне перемикання на асимптотичний Тейлорівський або експоненційний розклад.

3. **Модель Дебая та чисельне інтегрування акустичних фононів:**
   Молярна теплоємність за моделлю Дебая виражається через інтеграл:
   ```
   C_V^D(T) = 9 R · (T / Θ_D)³ · ∫₀^(Θ_D/T) [ x⁴ · exp(x) / (exp(x) - 1)² ] dx
   ```
   Цей інтеграл не виражається у елементарних функціях. Для його обчислення застосовується чисельне інтегрування методом Сімпсона або квадратурою Гаусса — Лежандра. При великих значеннях верхньої межі `x_D = Θ_D / T > 40` (низькі температури) інтеграл замінюється точним граничним значенням `4 π⁴ / 15 ≈ 25.97576`, що запобігає втраті точності та переповненню типу з плаваючою крапкою.

4. **Обробка даних диференціальної скануючої калориметрії (ДСК):**
   При аналізі експериментальних калориметричних кривих програма здійснює віднімання базисної лінії калориметра, обчислює приховану теплоту фазового переходу `ΔH = ∫ C_p dT` та зміну ентропії `ΔS = ∫ (C_p / T) dT`. Для металів при низьких температурах застосовується метод найменших квадратів (МНК) у координатах `C/T` від `T²`, що дозволяє надійно виділити коефіцієнт Зоммерфельда `γ` та температуру Дебая `Θ_D`.

## 3. Простеження кроків виконання та фізична інтерпретація результатів

Для глибокого розуміння того, як код відображає фундаментальну фізику теплоємності, простежимо результат роботи програми на конкретному прикладі міді (`Θ_D = 343 К`, `T_E = 240 К`, `γ = 0.695 мДж/(моль·К²)`) при переході від зліченних кріогенних температур до кімнатних умов:

1. **Область наднизьких температур (`T = 1.0 К`):**
   На цій точці обчислений фононний внесок за моделлю Дебая становить `C_deb ≈ 0.000057 Дж/(моль·К)`, а за моделлю Ейнштейна — абсолютний нуль через нестійку експоненту `exp(-240) ≈ 0`. Водночас електронний внесок Зоммерфельда дорівнює `C_el = γ · T = 0.000695 Дж/(моль·К)`. В електронному газі металу за цієї температури зосереджено понад 92% усієї теплоємності зразка. Програма показує, що без урахування електронів розрахунок теплоємності металу за кріогенних температур давав би похибку у 12 разів.

2. **Область кросоверу та росту ґратки (`T = 10.0 К` та `T = 20.0 К`):**
   При нагріванні до 10 К дебаївський кубічний внесок `C_deb ∝ T³` зростає в 1000 разів і досягає `0.0575 Дж/(моль·К)`, тоді як електронний внесок зростає лише у 10 разів (`0.00695 Дж/(моль·К)`). Точка кросоверу, де електронний та фононний внески зрівнюються, для міді лягає поблизу `T ≈ 3.48 К`. Вище цієї температури ґратка повністю домінує в теплоємності.

3. **Область класичного плато Дюлонга — Пті (`T = 300.0 К` та `T = 500.0 К`):**
   При кімнатній температурі `T = 300 К` (`T / Θ_D ≈ 0.875`) програма видає значення `C_deb ≈ 24.15 Дж/(моль·К)`, що становить 96.8% від класичної межі Дюлонга — Пті `3 R ≈ 24.94 Дж/(моль·К)`. Модель Ейнштейна дає `C_einst ≈ 23.82 Дж/(моль·К)`. При `T = 500 К` обидві квантові модели прямують до спільного асимптотичного плато `24.7 Дж/(моль·К)`.

4. **Розморожування обертань молекули водню `H₂` (`T_rot = 85.4 К`):**
   Другий розрахунковий блок обчислює квантову суму `heat_capacity_rotational` для газу `H₂`. При `T = 10 К` (`y = 8.54`) обертальна теплоємність дорівнює 0, оскільки молекули перебувають виключно у засадничому стані `J = 0`. При `T = 85.4 К` обертання активно розморожується, даючи сплеск `C_rot ≈ 1.1 R`, а при `T = 300 К` досягає класичної межі `1.0 R` (`8.314 Дж/(моль·К)`), додаючи 2 обертальні ступені вільності до 3 поступальних.

## 4. Детальний аналіз обчислювальних алгоритмів та інженерних крайових випадків

Розроблений програмний комплекс розв'язує декілька фундаментальних проблем чисельної стійкості, які виникають при комп'ютерному моделюванні фізичних систем у екстремальних термодинамічних умовах:

1. **Запобігання числовому виродженню при експоненційному виморожуванні:**
   У квантових моделях Ейнштейна та Дебая при наближенні до абсолютного нуля (`T → 0`) аргумент показникової функції `x = ℏ ω / (k_B T)` зростає до нескінченності. Обчислення значення `exp(x)` при `x > 709` у форматі з плаваючою комою подвійної точності IEEE 754 призводить до виклику апаратної виняткової ситуації переповнення (`overflow`), перетворюючи результат на `INFINITY`, що далі при діленні дає невизначеність `NaN`. У наведених програмах реалізовано жорстку перевірку: при `x > 80.0` функція повертає точний нуль `0.0`, оскільки фізичний внесок високих енергетичних рівнів `exp(-80) ≈ 1.8 × 10⁻³⁵` є меншим за машинну точність `double`.

2. **Розкриття неоднозначностей виду `0 / 0` при високих температурах:**
   У високотемпературній межі (`T >> Θ_D` або `x → 0`) чисельник підінтегрального виразу `x⁴ exp(x)` прямує до нуля як `x⁴`, а знаменник `(exp(x) - 1)²` прямує до нуля як `x²`. Безпосередній розрахунок частки малих чисел спричиняє катастрофічну втрату значущих розрядів мантиси через віднімання близьких чисел у знаменнику. Для усунення цього ефекту в алгоритмі реалізовано автоматичне перемикання на асимптотичний розклад Тейлора: при `x < 10⁻⁶` підінтегральний вираз замінюється значенням `x²`, що дає абсолютну числову гладкість та точність до 16 десяткових знаків.

3. **Адаптивна швидкість чисельного інтегрування та похибка Сімпсона:**
   Обчислення інтеграла Дебая методом Сімпсона вимагає розбиття інтервалу `[0, x_max]` на `N` дискретних кроків з кроком `h = x_max / N`. Залишкова похибка методом Сімпсона описується формулою `E_S = - (h⁴ / 180) · x_max · f^{(4)}(ξ)`. При низьких температурах верхня межа `x_max = Θ_D / T` стає дуже великою (наприклад, при `T = 1 К` та `Θ_D = 343 К` маємо `x_max = 343`). Інтегрування на такому величезному проміжку вимагало б сотень тисяч обчислювальних кроків. Оскільки підінтегральна функція згасає експоненційно, в програмі застосовано теорему про нескінченну межу: при `x_max > 40.0` інтеграл вважається повністю збіжним до константи `4 π⁴ / 15`. Це знижує обчислювальну складність алгоритму з `O(x_max)` до константного часу `O(1)`, забезпечуючи миттєвий розрахунок для кріогенних температур.

4. **Квантоване обчислення обертальних сум для газів:**
   Функція `heat_capacity_rotational` виконує пряме сумування термодинамічних флуктуацій енергії для квантового ротатора. Оскільки обертальні рівні мають виродження `2J + 1` та енергію `E_J = J(J + 1) k_B T_rot`, дисперсія енергії `⟨(ΔE)²⟩ = ⟨E²⟩ - ⟨E⟩²` обчислюється через перші два моменти больцманівського розподілу. Сума обривається природним чином, коли фактор Больцмана спадає нижче `exp(-80)`, що забезпечує точне відтворення квантової кривої без потреби збереження величезних таблиць рівнів.

5. **Статистична стійкість методів регресійного аналізу:**
   Функція `fit_low_temp_capacity` реалізує метод найменших квадратів для експериментальних даних у змінних `X = T²` та `Y = C / T`. Оскільки вихідні калориметричні дані завжди містять експериментальний шум, така лінеаризація є оптимальною з точки зору математичної статистики, оскільки відхилення виміряних точок від прямої описуються гаусовим розподілом похибок. Відновлення температури Дебая `Θ_D = (1944 / A)^(1/3)` через кубічний корінь додатково згладжує відносні похибки експерименту втричі.

## 5. Калориметрична обробка експериментальних ДСК даних

Диференціальна скануюча калориметрія (ДСК) є основним інструментальним методом вимірювання теплоємностей та теплових ефектів фазових переходів у сучасній фізиці конденсованого стану та матеріалознавстві. У калориметрі досліджуваний зразок масою `m` та еталонний зразок нагріваються з однаковою швидкістю `β = dT/dt`. Прилад вимірює різницю теплових потоків `ΔP(T)` (у міліватах), необхідну для підтримки однаковості температур обох комірок.

Питома теплоємність зразка `c_p(T)` обчислюється за базовим співвідношенням:

```
c_p(T) = ( ΔP(T) - ΔP_blank(T) ) / ( m · β )
```

де `ΔP_blank(T)` — сигнал порожнього тигля (базисна лінія вимірювання).

Для обчислення зміни ентропії `ΔS` та ентальпії `ΔH` у діапазоні температур від `T_1` до `T_2` виконується чисельне інтегрування експериментального масиву точок `(T_i, c_{p,i})`:

```
ΔH = ∫_{T_1}^{T_2} c_p(T) dT ≈ ∑_i ½ ( c_{p,i} + c_{p,i+1} ) · ( T_{i+1} - T_i )
```

```
ΔS = ∫_{T_1}^{T_2} ( c_p(T) / T ) dT ≈ ∑_i ½ ( c_{p,i} / T_i + c_{p,i+1} / T_{i+1} ) · ( T_{i+1} - T_i )
```

При наявності фазового переходу першого роду (танення, кристалізація, структурний перехід) на кривій `c_p(T)` спостерігається пік. Площа під піком за вирахуванням фонової теплоємності ґратки відповідає прихованій теплоті фазового переходу `L = ΔH_trans`, що дозволяє високоточно аналізувати фазовий склад та чистоту хімічних сполук у матеріалознавстві.

1. **Тестування межі Дюлонга — Пті для важких металів:**
   При `T = 300 К` для свинцю (`Θ_D = 105 К`, `T / Θ_D = 2.85`) програма видає молярну теплоємність `C_deb = 24.84 Дж/(моль·К)`, що відрізняється від класичної стелі `3R = 24.94 Дж/(моль·К)` менше ніж на 0.4%, що повністю узгоджується з вимірами.

2. **Перевірка надвисоких температур Дебая для алмазу:**
   Для алмазу (`Θ_D = 2230 К`) при кімнатній температурі `T = 300 К` (`x_max = 7.43`) програма розраховує `C_deb = 6.12 Дж/(моль·К)`. Це відтворює експериментальний факт, що алмаз при 300 К поглинає лише 24.5% від класичної норми Дюлонга — Пті через високу жорсткість ковалентних зв'язків C-C.

3. **Аналіз похибок при некоректних газових константах:**
   Використання молярної газової константи `R` з точністю менше ніж 5 значущих цифр (наприклад, `8.31` замість `8.31446`) призводить до накопиченої похибки у розрахунках фазових ентальпій до `0.05%` за один термодинамічний цикл. У наведеному коді гарантується подвійна точність усіх фізичних констант, що виключає алгоритмічну систематичну похибку.

## 7. Архітектурні рекомендації щодо векторної оптимізації розрахунків

При обробці масивних експериментальних даних калориметрії або проведенні тривимірного чисто модального термодинамічного розрахунку сіток скінченних елементів (FEM-моделювання теплопередачі в мікропроцесорах) функції обчислення теплоємності викликаються мільйони разів на секунду.

Для забезпечення максимальної обчислювальної швидкодії рекомендується застосовувати такі техніки кодування:
- **Векторизація SIMD (Single Instruction Multiple Data):** Обчислення дебаївського інтеграла для масиву точок температур `T[i]` векторизується за допомогою інструкцій AVX-512 або ARM Neon, обробляючи по 8 елементів типів `double` паралельно за один тактовий цикл процесора.
- **Табуляція та сплайн-інтерполяція:** Для складних матеріалів із кількома фазовими переходами функція `C_p(T)` табулюється з кроком 1 К, після чого під час моделювання застосовується швидка кубічна сплайн-інтерполяція `O(1)`, що позбавляє потреби постійно обчислювати трансендентні функції `exp()` та `pow()`.
- **Безвиняткова оптимізація (`noexcept` в C++):** Оголошення обчислювальних лямбда-функцій та чисто математичних процедур як `noexcept` дозволяє компілятору (GCC, Clang, MSVC) будувати оптимізований машинний код без збереження стек-фреймів для обробки винятків C++.
- **Управління пам'яттю та відсутність динамічних алокацій:** Застосування `std::span` у C++20 дозволяє передавати масиви температур без створення тимчасових векторів у копіювальній пам'яті купи (heap memory), що гарантує виконання обчислювальних циклів виключно у регістрах процесора та кеш-пам'яті L1.
- **Багатопотокова паралелізація:** Обробка незалежних температурних точок розподіляється між ядрами процесора за допомогою OpenMP в C (`#pragma omp parallel for`) або стандартних потоків `std::jthread` та обчислювальних операторів `std::execution::par` в C++, що забезпечує лінійне прискорення розрахунку пропорційно кількості доступних ядер ЕОМ.

Розроблений алгоритмічний модуль може бути легко інтегрований у сторонні термодинамічні бібліотеки для моделювання теплових систем та проектування матеріалів із заданою теплоємністю.
