# ⚙️ Моделювання Ланжевенової динаміки та числова перевірка ТФД

У цій практичній вставці ми реалізуємо чисельний експеримент: змоделюємо термодинамічний рух гармонічного осцилятора (або Броунівської частки в потенціалі) під дією в'язкого тертя та хаотичної теплової сили (стохастичне рівняння Ланжевена). З отриманої часової траєкторії ми розрахуємо автокореляційну функцію та спектральну густину флуктуацій і чисельно перевіримо виконання теореми флуктуацій і дисипації (ТФД).

### 1. Фізична та стохастична модель

Рівняння Ланжевена описує динаміку виділеного макроскопічного ступеня вільності (зміщення `x(t)` частинки масою `m` у потенціалі `U(x) = (1/2) · k · x²`), зануреного у тепловий резервуар із температурою `T` та коефіцієнтом в'язкого тертя `γ`:

```
m · (d²x / dt²) + γ · (dx / dt) + k · x = ξ(t)
```

де `ξ(t)` — стохастична сила гауссівського білого шуму, яка моделює хаотичні зіткнення з молекулами середовища. Згідно з теоремою флуктуацій і дисипації та умовою термодинамічної рівноваги, статистичні моменти шумові сили задовольняють співвідношення:

```
⟨ξ(t)⟩ = 0
⟨ξ(t) · ξ(t')⟩ = 2 · γ · k_B · T · δ(t - t')
```

Це означає, що інтенсивність хаотичних поштовхів `2 · γ · k_B · T` повністю визначається коефіцієнтом дисипації `γ` та температурою `T`.

Аналітичний вираз для уявної частини комплексної сприйнятливості `Im[χ(ω)]` нашого осцилятора дорівнює:

```
Im[χ(ω)] = (γ · ω) / ((k - m · ω²)² + γ² · ω²)
```

Згідно з ТФД, теоретична спектральна густина спонтанних флуктуацій зміщення `S_x(ω)` має вигляд:

```
S_x(ω) = (2 · k_B · T / ω) · Im[χ(ω)] = (2 · k_B · T · γ) / ((k - m · ω²)² + γ² · ω²)
```

### 2. Чисельна схема дискретизації Ейлера — Маруями

Для комп'ютерного моделювання ми переходимо від неперервного диференціального рівняння до дискретної системи першого порядку за часом із кроком `dt`. Нехай `x_n` та `v_n` — зміщення та швидкість на `n`-му кроці. Рівняння руху дискретизуються за допомогою стохастичної схеми Ейлера — Маруями:

```
v_{n+1} = v_n + [ (-γ · v_n - k · x_n) / m ] · dt + (σ / m) · R_n · √dt
x_{n+1} = x_n + v_{n+1} · dt
```

де `R_n` — незалежні стандартні нормальні випадкові величини з нульовим середнім і одиничною дисперсією `R_n ~ N(0, 1)`, а дисперсія шумового імпульсу становить:

```
σ = √(2 · γ · k_B · T / dt)
```

Множник `1 / √dt` є фундаментальною рисою вінерівських процесів: оскільки дисперсія випадокового блукання росте пропорційно часу `dt`, миттєва амплітуда дискретної сили повинна масштабуватися як `1 / √dt`, щоб інтегральний імпульс за інтервал `dt` зберігав правильну дисперсію `2 · γ · k_B · T · dt`.

### 3. Алгоритм спектрального оцінювання та теорема Вінера — Хінчина

За теоремою Вінера — Хінчина, спектральна густина потужності `S_x(ω)` є фур'є-перетворенням автокореляційної функції зміщення `C_x(τ) = ⟨x(t + τ) · x(t)⟩₀`. У чисельному експерименті автокореляцію можна обчислити або через пряме усереднення за часом, або за допомогою Швидкого Перетворення Фур'є (FFT):

```
C_x(τ) = (1 / N) · ∑ₙ x_{n + τ} · x_n
```

Після генерації часової траєкторії тривалістю `N` кроків система спочатку проходить фазу термалізації (відкидається початковий транзиєнт), після чого обчислюється спектральна густина флуктуацій. Замість чистого Швидкого Перетворення Фур'є (FFT) однієї довгої траєкторії, яке дає зашумлений оцінювач із великою дисперсією, застосовується метод Велча:

1. Траєкторія ділиться на `M` перекриваних сегментів тривалістю `L` точок.
2. Кожен сегмент множиться на згладжувальне вікно Ханна `w_n = 0.5 · (1 - cos(2πn / L))` для усунення витоку спектрального вмісту на межах.
3. Для кожного віконного сегмента обчислюється дискретне перетворення Фур'є `X_m(ω)`.
4. Спектральні густини потужності окремих сегментів усереднюються за всім ансамблем:
   ```
   S_x(ω) = (2 · dt / (L · U)) · (1 / M) · ∑ₘ₌₁ᴹ |X_m(ω)|²
   ```
   де `U = (1 / L) · ∑ w_n²` — нормувальний фактор потужності вікна.

### 4. Фізична термалізація, аналіз похибок та часові масштаби

Під час чисельного розв'язування стохастичних диференціальних рівнянь надзвичайноважливо контролювати три фундаментальні часові масштаби:

1. **Крок дискретизації `dt`**: має бути набагато меншим за період власних коливань осцилятора `T_0 = 2π / ω_0`, де `ω_0 = √(k/m)`. Типово обирають `dt ≤ T_0 / 100`, щоб запобігти виникненню числової нестійкості стохастичного інтегратора.
2. **Час релаксації системи `τ_rel = m / γ`**: це характерний час, за який система забуває свої початкові умови й приходить у стан термодинамічної рівноваги з резервуаром. Моделювання обов'язково повинно містити фазу термалізації тривалістю не менше `10 · τ_rel` перед початком збору статистичних даних.
3. **Загальна тривалість траєкторії `T_total = N · dt`**: визначає спектральне розділення `Δf = 1 / T_total`. Щоб надійно вирізнити резонансний пік поглинання, тривалість спостереження повинна багаторазово перевищувати час згасання коливань.

Для перевірки термодинамічної рівноваги обчислюється середня кінетична енергія системи `⟨E_kin⟩ = (1/2) · m · ⟨v²⟩`. Згідно з теоремою рівнорозподілу energy, отримана з траєкторії величина повинна збігатися з `(1/2) · k_B · T` з відносною точністю вище 99%.

Аналогічно перевіряється середня потенціальна енергія осцилятора `⟨E_pot⟩ = (1/2) · k · ⟨x²⟩ = (1/2) · k_B · T`. Збіг обох середніх величин є надійним тестом того, що чисельна схема Ейлера — Маруями правильно зберегла канонічний розподіл Ґіббса в фазовому просторі.

#### Порівняння алгоритмів інтегрування: Ейлер — Маруями vs Гронбеч — Йєнсен

Проста схема Ейлера — Маруями є першого порядку точності за кроком `dt` і привеликих `dt` може показувати штучний чисельний дрейф енергії. У прецизійних молекулярно-динамічних розрахунках застосовують алгоритми другого порядку точності, зокрема схему Гронбеча — Йєнсена та Фараґо (Gronbech-Jensen & Farago, GJF):

```
x_{n+1} = x_n + b · v_n · dt + (b · dt² / (2m)) · F_n + (b · dt / (2m)) · ξ^{n+1}
```

де `b = 1 / (1 + γ dt / (2m))` — коефіцієнт згасання. Схема GJF є строго термодинамічно стійкою для будь-яких кроків `dt < 2 / ω_0` і точніше відтворює кореляційні функції швидкісних флуктуацій.

### 6. Інженерний аналіз результатів та типові пастки

1. **Термалізація та початкові умови**: Якщо запустити модель із нульовими початковими зміщенням і швидкістю `x(0)=0, v(0)=0`, системи потрібен час релаксації `τ_rel ≈ m / γ`, щоб розігрітися до середньої кінетичної енергії `(1/2) · k_B · T`. Обчислення спектра до завершення термалізації призводить до заниження амплітуди шуму.
2. **Крок дискретизації `dt` та вибір частоти Найквіста**: Частота дискретизації `f_s = 1 / dt` виражає верхню межу розрахованого спектра `f_Nyquist = f_s / 2`. Для правильного відтворення резонансного піку осцилятора `ω₀ = √(k/m)` крок `dt` повинен задовольняти умову `dt ≪ 2π / ω₀`.
3. **Чисельне підтвердження ТФД**: Порівняння розрахованого чисельного спектра `S_x(ω)` із теоретичною кривою `(2 · k_B · T · γ) / ((k - m · ω²)² + γ² · ω²)` показує ідеальний збіг у межах статистичної похибки. Це експериментально підтверджує, що дисипація (тертя `γ`) є єдиним джерелом спонтанного шуму у термодинамічній рівновазі.
