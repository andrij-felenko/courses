# 📋 Інтерфейс аналізу лінійного відгуку та спектральних характеристик (FDT Toolkit)

Цей документ описує C++20 та Python інтерфейси програмної бібліотеки `fdt_toolkit`, призначеної для обчислення причинних функцій відгуку, перетворення Крамерса — Кроніґа, аналізу спектральної густини потужності (PSD) та перевірки виконання теореми флуктуацій і дисипації (ТФД) у експериментальних дослідженнях конденсованого стану та чисельному моделюванні.

### 1. Огляд архітектури та концепція проєктування

Програмна бібліотека `fdt_toolkit` розроблена для фізиків і інженерів, які займаються обробкою сигналів у надчутливих експериментах (сканувальна зондова мікроскопія, гравітаційно-хвильові інтерферометри LIGO, надпровідникові квантові схеми). Головна мета бібліотеки — надати надійні, високопродуктивні та квантово-точні обчислювальні алгоритми для реконструкції фізичних параметрів середовища за спостережуваним спонтанним шумом.

Архітектура бібліотеки спирається на сучасні стандарти C++20 та надає три ключові компоненти:

1. **Модуль лінійного відгуку (`LinearResponseCalculator`)**: реалізує обчислення комплексної сприйнятливості `χ(ω) = χ'(ω) + i · χ''(ω)` за експериментально виміряними часовими рядами сили та відгуку за допомогою спектральної згортки та квантового фактора Каллена — Велтона `coth(ℏω / (2 k_B T))`.
2. **Модуль Крамерса — Кроніґа (`KramersKronigTransform`)**: виконує чисельну реконструкцію дійсної частини сприйнятливості `Re[χ(ω)]` за відомою уявною частиною `Im[χ(ω)]` (і навпаки) за допомогою спеціалізованого чисельного інтегрування головного значення за Коші (Principal Value Integration).
3. **Модуль валідації ТФД (`FDTValidator`)**: порівнює емпіричну спектральну густину потужності флуктуацій `S_A(ω)` із теоретичним ТФД-прогнозом при заданій температурі `T`, вираховуючи частотно-залежну ефективну температуру `T_eff(ω)` для виявлення нерівноважних процесів.

Всі класи бібліотеки дотримуються принципів безпеки відносно винятків, не використовують сирих вказівників та динамічного виділення пам'яті всередині обчислювальних циклів (RAII-концепція).

### 2. Детальний опис класів та математичних алгоритмів

#### Клас `LinearResponseCalculator`

Клас відповідає за перетворення між часовим та частотним уявленнями функцій відгуку. Він приймає структуру `PhysicalEnvironment`, яка містить температуру середовища `T`, сталу Планка `ℏ` та сталу Больцмана `k_B`.

Метод `compute_response_function` обчислює часову сприйнятливість `χ(t)` шляхом деконволюції часових рядів зовнішньої сили `h(t)` та зміщення `A(t)`. Згортка здійснюється у частотній області за допомогою алгоритму Швидкого Перетворення Фур'є (FFT).Для запобігання крайовим ефектам розриву фази масиви даних автоматично згладжуються вікном Ханна або Блекмана — Харріса.

Метод `callen_welton_factor` розраховує квантовий коефіцієнт `coth(ℏω / (2 k_B T))`. Для забезпечення числової стійкості при дуже малих частотах `ℏω ≪ k_B T` використовується асимптотичний розклад Тейлора `coth(x) ≈ 1/x + x/3 - x³/45`, що запобігає втраті точності числового представлення чисел з рухомою комою `double`.

#### Клас `KramersKronigTransform`

Перетворення Крамерса — Кроніґа пов'язує дійсну `χ'(ω)` та уявну `χ''(ω)` частини сприйнятливості через інтеграл принципового значення Коші (Principal Value):

```
χ'(ω) = (2 / π) · P.V. ∫₀⁺∞ (x · χ''(x) / (x² - ω²)) dx
```

Чисельне інтегрування ускладнюється наявністю полюса першого порядку у точці `x = ω`. Модуль `KramersKronigTransform` застосовує метод сингулярного вилучення: інтеграл ділиться на симетричний окіл точки сингулярності `[ω - Δω, ω + Δω]` та зовнішні області. У вузькому околі сингулярності функція `χ''(x)` апроксимується лінійним сплайном, що дозволяє обчислити внутрішній інтеграл аналітично. Зовнішні області інтегруються за допомогою адаптивного методу Гаусса — Кронрода.

#### Клас `FDTValidator` та розрахунок ефективної температури

Модуль надає засоби для чисельної перевірки виконання ТФД у складних або виведених з рівноваги системах. На вхід подається виміряна спектральна густина `S_A(ω)` та дисипативний відгук `Im[χ(ω)]`. Модуль обчислює частотно-залежну ефективну температуру:

```
T_eff(ω) = (ℏ · ω / (2 · k_B)) · coth⁻¹( S_A(ω) / (ℏ · Im[χ(ω)]) )
```

Якщо система перебуває у стані термодинамічної рівноваги, `T_eff(ω) = T_env = const` для всіх частот. Відхилення `T_eff(ω)` від постійного значення свідчить про наявність активних нетеплових сил або тривалого процесу релаксації (старіння).

#### Оптимізація обчислень та ефективність використання пам'яті

Для досягнення максимальної обчислювальної продуктивності під час обробки тривалих експериментальних траєкторій (понад `10⁷` точок) у бібліотеці застосовуються такі інженерні рішення:
* **Кешування вагових коефіцієнтів**: тригонометричні сітки для перетворення Фур'є та вагові коефіцієнти вікон розраховуються один раз під час ініціалізації екземпляра класу та зберігаються у неперервній пам'яті.
* **Векторизація SIMD**: математичні операції піднесення до квадрата та комплексного множення оптимізовані за допомогою сучасних векторних інструкцій процесора (AVX-512 / ARM Neon).
* **Сумісність із паралельними обчисленнями**: внутрішні стани функцій є константними (`const` та `noexcept`), що дозволяє викликати метод `compute_response_function` одночасно з кількох потоків виконання без блокувальних примітивів синхронізації.

### 6. Обробка граничних випадків та чисельні особливості

1. **Миттєва сингулярність у принципі Коші**: При обчисленні перетворення Крамерса — Кроніґа в точці `x = ω` виникає ділення на нуль. Бібліотека використовує симетричне обнулення околу сингулярності `[ω - Δω, ω + Δω]` та метод трапецій з вилученим вузлом (Principal Value Integration).
2. **Нульова температура `T → 0 K`**: При `T = 0 K` гіперболічний котангенс прямує до 1 (`coth(x) → 1`), а фактор Каллена — Велтона зводиться до чисто квантових нульових флуктуацій `S_A(ω) = ℏ · Im[χ(ω)]`. Інтерфейс автоматично обробляє цю границю без виникнення винятку ділення на нуль.
3. **Класична границя низьких частот `ℏω ≪ k_B T`**: Щоб уникнути втрати точності з плаваючою комою при обчисленні `tanh(x)` для дуже малих аргументів `x < 10⁻⁴`, бібліотека автоматично перемикається на асимптотичний розклад Тейлора `coth(x) ≈ 1/x + x/3`.
4. **Гарантії потокобезпеки**: Класи `LinearResponseCalculator` та `KramersKronigTransform` є константними та безпосередньо придатними для паралельних обчислень за допомогою OpenMP чи `std::execution::par` без використання блокувальних м'ютексів.

Цей інтерфейс забезпечує повний цикл аналізу спектральної дисипації та спонтанного шуму у науково-дослідних C++20 та Python програмах.
