# 🧮 Математичне виведення теореми Каллена — Велтона та квантова форма ТФД

Ця вставка містить суворе математичне виведення теореми флуктуацій і дисипації (ТФД) у формалізмі Каллена — Велтона та Кубо. Мета виведення — довести, що уявна частина лінійної сприйнятливості `Im[χ(ω)]`, яка описує незворотне поглинання енергії зовнішнього поля, математично тотожна спектральній густині рівноважних флуктуацій `S_A(ω)`.

### 1. Постановка задачі та квантовий Гамільтоніан

Розглянемо квантово-механічну систему з незбуреним Гамільтоніаном `H₀`, яка перебуває у стані термодинамічної рівноваги при абсолютній температурі `T`. Рівноважна матриця густини описується канонічним розподілом Ґіббса:

```
ρ₀ = (1 / Z) · exp(-H₀ / (k_B · T))
Z = Sp(exp(-H₀ / (k_B · T)))
```

де `Z` — статистична сума, `k_B` — стала Больцмана, а `Sp` позначає шпур (слід) оператора по всьому гільбертовому простору станів. Оскільки матриця густини `ρ₀` виражається функцією від Гамільтоніана `H₀`, вона комутує з ним `[ρ₀, H₀] = 0`, що гарантує стаціонарність рівноважного стану у відсутності зовнішніх дій.

Нехай на систему починаючи з далекого минулого `t = -∞` діє слабке зовнішнє часозалежне збудження вида `V(t) = -h(t) · A`, де `h(t)` — класична зовнішня сила (наприклад, змінне електричне чи магнітне поле), а `A` — ермітів оператор спостережуваної физичної величини системи. Повний Гамільтоніан має вигляд:

```
H(t) = H₀ - h(t) · A
```

Еволюція матриці густини `ρ(t)` у часі під дією повного Гамільтоніана описується диференціальним рівнянням фон Неймана (квантовим рівнянням Ліувілля):

```
i · ℏ · (dρ / dt) = [H(t), ρ(t)] = [H₀ - h(t) · A, ρ(t)]
```

### 2. Лінійний відгук у представленні взаємодії та формула Кубо

Перейдемо до представлення взаємодії (picture of Dirac), де оператори еволюціонують з незбуреним Гамільтоніаном `A(t) = exp(i H₀ t / ℏ) · A · exp(-i H₀ t / ℏ)`, а відхилення матриці густини `Δρ(t) = ρ(t) - ρ₀` за теорією збурень першого порядку за силою `h(t)` розв'язується інтегруванням:

```
Δρ(t) = (i / ℏ) · ∫₋∞ᵗ h(τ) · [A(τ - t), ρ₀] dτ
```

Обчислимо відхилення середнього значення оператора `⟨A(t)⟩ = Sp(ρ(t) · A)` від його рівноважного значення `⟨A⟩₀ = Sp(ρ₀ · A) = 0`:

```
⟨A(t)⟩ = Sp(Δρ(t) · A) = ∫₋∞ᵗ χ(t - τ) · h(τ) dτ
```

де `χ(t)` — функція відгуку (чи сприйнятливість у часовому уявленні), яка виражається через квантовий комутатор оператора `A` в уявленні Гейзенберга (формула Кубо):

```
χ(t) = (i / ℏ) · θ(t) · ⟨[A(t), A(0)]⟩₀
```

де `θ(t)` — одинична функція Хевісайда (`θ(t) = 1` при `t > 0` і `0` при `t < 0`), яка гарантує причинність відгуку.

Перейдемо до частотного уявлення за допомогою фур'є-перетворення:

```
χ(ω) = ∫₀⁺∞ χ(t) · exp(i · ω · t) dt
```

Комплексна сприйнятливість розкладається на дійсну та уявну частини:

```
χ(ω) = χ'(ω) + i · χ''(ω)
```

Покажемо, що саме уявна частина `χ''(ω) = Im[χ(ω)]` визначає дисипацію. Нехай зовнішнє збудження є монохроматичним: `h(t) = h₀ · cos(ω · t)`. Середня потужність `P(ω)`, яка поглинається системою від зовнішнього джерела й дисипується в тепло, дорівнює:

```
P(ω) = ⟨dW/dt⟩
P(ω) = -⟨A(t) · (dh/dt)⟩
P(ω) = (1/2) · ω · h₀² · Im[χ(ω)]
```

[Обгрунтування: дійсна частина χ'(ω) відповідає фазі збурення і описує реактивне запасання енергії, тоді як уявна частина Im[χ(ω)] зсунута по фазі на π/2 і дає незворотні втрати потужності]

### 3. Мікроскопічний розрахунок поглинання через квантові стани

Нехай `|n⟩` та `|m⟩` — повна система власних станів Гамільтоніана `H₀` з енергетичними рівнями `E_n` та `E_m`: `H₀ |n⟩ = E_n |n⟩`. Ймовірність знаходження системи у стані `|n⟩` визначається фактором Больцмана:

```
w_n = (1 / Z) · exp(-E_n / (k_B · T))
```

Розглянемо переходи між квантовими станами під дією зовнішнього гармонічного поля `V(t) = -h₀ · cos(ω · t) · A`. Згідно з золотою формулою Фермі, ймовірність переходу за одиницю часу зі стану `|n⟩` у стан `|m⟩` під дією поглинання кванту `ℏω` дорівнює:

```
W_{n → m} = (π / (2 ℏ)) · h₀² · |⟨m|A|n⟩|² · δ(E_m - E_n - ℏω)
```

Повна середня потужність, яка поглинається системою, дорівнює різниці між темпом поглинання квантів `E_m > E_n` та темпом вимушеного випромінювання `E_n > E_m`:

```
P(ω) = ∑ₙ,ₘ (E_m - E_n) · w_n · W_{n → m}
P(ω) = (π / (2 ℏ)) · ω · h₀² · ∑ₙ,ₘ (w_n - w_m) · |⟨n|A|m⟩|² · δ(ω - ω_mn)
```

де `ω_mn = (E_m - E_n) / ℏ` — частота квантового переходу між станами. Зіставляючи цей результат із макроскопічним виразом для дисипації `P(ω) = (1/2) · ω · h₀² · Im[χ(ω)]`, знаходимо мікроскопічний вираз для уявної частини сприйнятливості:

```
Im[χ(ω)] = (π / ℏ) · ∑ₙ,ₘ (w_n - w_m) · |⟨n|A|m⟩|² · δ(ω - ω_mn)
```

Зауважимо важливе співвідношення між рівноважними населеностями станів `w_n` та `w_m`:

```
w_m = (1 / Z) · exp(-E_m / (k_B · T))
= (1 / Z) · exp(-(E_n + ℏ · ω_mn) / (k_B · T))     [підстановка E_m = E_n + ℏ · ω_mn]
= w_n · exp(-ℏ · ω_mn / (k_B · T))                [виділення фактора Больцмана w_n]
```

Тому різниця населеностей дорівнює:

```
w_n - w_m = w_n · (1 - exp(-ℏ · ω_mn / (k_B · T)))   [винесення w_n за дужки]
```

Підставляючи це у вираз для `Im[χ(ω)]`, отримуємо:

```
Im[χ(ω)] = (π / ℏ) · (1 - exp(-ℏ · ω / (k_B · T))) · ∑ₙ,ₘ w_n · |⟨n|A|m⟩|² · δ(ω - ω_mn)
```

### 4. Спектральна густина рівноважних флуктуацій

Тепер розрахуємо спонтанні флуктуації оператора `A` у стані термодинамічної рівноваги (без зовнішнього поля `h = 0`). Автокореляційна функція флуктуацій виражається як:

```
C_A(t) = ⟨A(t) · A(0)⟩₀ = Sp(ρ₀ · A(t) · A(0))
```

Розкладаючи за власним базисом `|n⟩` та вставляючи одиничний оператор `∑ |m⟩⟨m| = I`, маємо:

```
C_A(t) = ∑ₙ,ₘ w_n · ⟨n|A(t)|m⟩ · ⟨m|A(0)|n⟩
= ∑ₙ,ₘ w_n · |⟨n|A|m⟩|² · exp(-i · ω_mn · t)
```

Спектральна густина флуктуацій `S_A(ω)` за визначенням є фур'є-перетворенням автокореляційної функції:

```
S_A(ω) = ∫₋∞⁺∞ C_A(t) · exp(i · ω · t) dt
S_A(ω) = 2 · π · ∑ₙ,ₘ w_n · |⟨n|A|m⟩|² · δ(ω - ω_mn)
```

[Зауваження: в літературі вживають також симетризовану спектральну густину, але фізичний зміст спектра квадрата флуктуацій лишається незмінним]

### 5. Об'єднання: теорема Каллена — Велтона

Порівняємо отримані мікроскопічні вирази для `Im[χ(ω)]` та `S_A(ω)`:

```
Im[χ(ω)] = (1 / (2 · ℏ)) · (1 - exp(-ℏ · ω / (k_B · T))) · S_A(ω)
```

Виразимо спектральну густину `S_A(ω)` через `Im[χ(ω)]`:

```
S_A(ω) = (2 · ℏ / (1 - exp(-ℏ · ω / (k_B · T)))) · Im[χ(ω)]
```

Скориставшись тригонометричною тотожністю для гіперболічних функцій:

```
1 / (1 - exp(-2x)) = (1/2) · (coth(x) + 1)
```

отримуємо остаточну точну квантову форму **теореми Каллена — Велтона**:

```
S_A(ω) = ℏ · (coth(ℏ · ω / (2 · k_B · T)) + 1) · Im[χ(ω)]
```

Якщо розглядати симетризований за частотами спектр (або класичне спостереження), доданок 1 приводить до стандартної симетричної квантової форми:

```
S_A(ω) = 2 · ℏ · (n(ω) + 1/2) · Im[χ(ω)]
```

де `n(ω) = 1 / (exp(ℏ · ω / (k_B · T)) - 1)` — середня кількість квантових збуджень (фононів, фотонів) за розподілом Бозе — Ейнштейна, а доданок `1/2` відповідає нульовим квантовим флуктуаціям (Zero-Point Fluctuations).

### 6. Співвідношення Крамерса — Кроніґа та інтегральні правила сум

Функція відгуку `χ(t)` задовольняє принцип причинності `χ(t) = 0` при `t < 0`. Це означає, що її спектральне перетворення `χ(z)` є аналітичною функцією у верхній півплощині комплексної частоти `z = ω + i·η` (`η > 0`).

Застосовуючи теорему Коші про лишки до контуру, що охоплює верхню півплощину, отримуємо співвідношення Крамерса — Кроніґа:

```
χ'(ω) = (2 / π) · P.V. ∫₀⁺∞ (x · χ''(x) / (x² - ω²)) dx
χ''(ω) = -(2 · ω / π) · P.V. ∫₀⁺∞ (χ'(x) / (x² - ω²)) dx
```

де `P.V.` позначує головне значення інтеграла за Коші.

Звідси випливає фундаментальне **правило сум для сприйнятливості**: статична сприйнятливість `χ'(0)` повністю визначається інтегралом від дисипативної уявної частини по всіх частотах:

```
χ'(0) = (2 / π) · ∫₀⁺∞ (Im[χ(x)] / x) dx
```

Поєднуючи це із класичною формулою ТФД `S_A(ω) = (2 · k_B · T / ω) · Im[χ(ω)]`, ми бачимо, що середня квадратна амплітуда рівноважних флуктуацій `⟨A²⟩` пов'язана зі статичною сприйнятливістю `χ'(0)`:

```
⟨A²⟩ = (1 / 2π) · ∫₋∞⁺∞ S_A(ω) dω = k_B · T · χ'(0)
```

Це співвідношення є узагальненням класичної теореми рівнорозподілу енергії на будь-які лінійні фізичні системи.

### 7. Класична границя (формула Найквіста)

У класичній області низьких частот або високих температур, коли `ℏ · ω ≪ k_B · T`, виконується наближення:

```
exp(ℏ · ω / (k_B · T)) ≈ 1 + ℏ · ω / (k_B · T)
1 - exp(-ℏ · ω / (k_B · T)) ≈ ℏ · ω / (k_B · T)
```

Підставляючи це у формулу ТФД, отримуємо класичну теорему флуктуацій і дисипації:

```
S_A(ω) = (2 · ℏ / (ℏ · ω / (k_B · T))) · Im[χ(ω)]
= (2 · k_B · T / ω) · Im[χ(ω)]                        [скорочення ℏ у чисельнику й знаменнику]
```

Для електричного кола, де збудженням є струм `I`, відгуком — напруга `V`, а сприйнятливістю — імпеданс `Z(ω)`, маємо `Im[χ(ω)] / ω = Re[Z(ω)] = R`. Підставляючи це у класичну ТФД, отримуємо точну формулу Джонсона — Найквіста для двосторонньої спектральної густини:

```
S_V(ω) = 2 · k_B · T · R
```

Для односторонньої спектральної густини в смузі частот `B` (де інтегрування ведеться лише по додатних частотах `f > 0`):

```
U_ш² = 4 · k_B · T · R · B
```

Математичне виведення повністю доведено: спонтанні теплові флуктуації системи математично зафіксовані й строго пропорційні її уявній частині лінійної сприйнятливості `Im[χ(ω)]`.
