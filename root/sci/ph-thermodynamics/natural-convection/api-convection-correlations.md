# 📋 Інженерний довідник емпіричних співвідношень природної конвекції

Цей довідник містить структурований інженерний опис емпіричних співвідношень, розрахункових формул, крайових випадків та таблиць теплофізичних властивостей для визначення коефіцієнта тепловіддачі `h` при природній конвекції у найпоширеніших фізичних і технічних геометріях.

## 1. Фундаментальна методологія та алгоритм розрахунку

Природно-конвективний теплообмін визначається взаємодією сили плавучості та в'язко-теплової дисипації. Загальна кількість тепла `Q`, яка відводиться від твердої поверхні площею `A` до навколишнього середовища з температурою `T_ambient`, підпорядковується закону охолодження Ньютона:

```
Q = h · A · (T_wall - T_ambient)
```

Коефіцієнт тепловіддачі `h` залежить від режиму течії (ламінарний чи турбулентний), геометрії тіла, орієнтації у просторі відносно вектора гравітації та фізичних властивостей флюїду. Розрахунок `h` проводиться через безрозмірне число Нуссельта `Nu`:

```
h = (Nu · k) / L
```

де `k` — коефіцієнт теплопровідності флюїду, а `L` — характерний геометричний розмір системи.

### Покрокова інженерна процедура:

1. **Визначення температури плівки (`T_film`):** Усі теплофізичні властивості флюїду (густина, в'язкість, теплопровідність) обчислюються при середній температурі пристінкового примежового шару:

```
T_film = (T_wall + T_ambient) / 2
```

2. **Оцінка теплофізичних параметрів флюїду:** За температурою `T_film` визначаються кінематична в'язкість `ν`, температуропровідність `α`, теплопровідність `k` та число Прандтля `Pr = ν / α`. Для ідеальних газів коефіцієнт об'ємного розширення визначається через абсолютну температуру плівки у Кельвінах: `β = 1 / T_film`. Для рідин `β` береться з фізичних довідникових таблиць.

3. **Обчислення чисел Грасгофа (`Gr_L`) та Релея (`Ra_L`):**

```
Gr_L = (g · β · (T_wall - T_ambient) · L³) / ν²
Ra_L = Gr_L · Pr = (g · β · (T_wall - T_ambient) · L³) / (ν · α)
```

4. **Вибір емпіричного співвідношення `Nu = f(Ra_L, Pr)` та обчислення `h`.**

## 2. Вертикальна плоска пластина та вертикальний циліндр

Для вертикальної поверхні висотою `H` характерним розміром є її повна вертикальна висота `L = H`. Потік прискорюється знизу вгору вздовж усієї висоти пластини, тому товщина примежового шару зростає як `δ(x) ∝ x^(1/4)`.

### Емпіричні критеріальні рівняння:

1. **Ламінарний режим (`10⁴ < Ra_H < 10⁹`):**
Для ламінарної природної конвекції вздовж вертикальної стінки використовується співвідношення Мак-Адамса:

```
Nu_H = 0.59 · Ra_H^(1/4)
```

Ця формула описує помірне зростання коефіцієнта тепловіддачі при збільшенні температурного напору.

2. **Турбулентний режим (`10⁹ < Ra_H < 10¹³`):**
При перевищенні критичного числа Релея `Ra_H ≈ 10⁹` у примежовому шарі виникають вихори та активне турбулентне перемішування:

```
Nu_H = 0.10 · Ra_H^(1/3)
```

Оскільки число Нуссельта пропорційне `Ra_H^(1/3)`, підстановка виразу для `Ra_H` показує, що коефіцієнт тепловіддачі `h` перестає залежати від висоти пластини `H`. Це пояснюється тим, що у розвиненій турбулентності основний тепловий опір зосереджений у тонкому ламінарному підшарі біля стінки.

3. **Універсальне співвідношення Черчілля — Чу (1975):**
Для покриття всього діапазону чисел Релея від мікророзмірних систем до величезних промислових стін (`10⁻¹ < Ra_H < 10¹²`) застосовується точна формула Черчілля — Чу:

```
Nu_H = [ 0.825 + (0.387 · Ra_H^(1/6)) / (1 + (0.492 / Pr)^(9/16))^(8/27) ]²
```

### Вертикальний циліндр:
Вертикальний циліндр зовнішнім діаметром `D` можна розраховувати за формулами для плоскої вертикальної пластини тої ж висоти `H`, якщо ефектом поперечної кривизни поверхні можна знехтувати. Кривизна є несуттєвою при виконанні геометричної умови:

```
D / H >= 35 / (Gr_H^(1/4))
```

Якщо циліндр є дуже тонким (наприклад, вертикальний дріт чи голка), кривизна посилює теплообмін, і до числа Нуссельта додається поправка: `Nu_cyl = Nu_plate + 0.37 · (H / D)`.

## 3. Горизонтальна плоска пластина

Для горизонтальних пластин вектор гравітації є перпендикулярним до поверхні. Характерним розміром для таких поверхностей є співвідношення площі пластини `A` до її периметра `P`: `L = A / P`.

Інтенсивність конвекції суттєво залежить від того, куди спрямований потік нагрітого чи охолодженого флюїду:

### А. Гаряча поверхня спрямована догори (`T_w > T_∞`) або холодна донизу:
У цьому випадку нагрітий флюїд прагне вспливти вгору від поверхні, не зустрічаючи перешкод. Виникає активний нестаціонарний конвективний рух.

- **Ламінарний режим (`10⁴ < Ra_L < 10⁷`):**

```
Nu_L = 0.54 · Ra_L^(1/4)
```

- **Турбулентний режим (`10⁷ < Ra_L < 10¹¹`):**

```
Nu_L = 0.15 · Ra_L^(1/3)
```

### Б. Гаряча поверхня спрямована донизу (`T_w > T_∞`) або холодна догори:
У цій конфігурації нагрітий легший флюїд опиняється під горизонтальною пластиною і не може вспливти вгору. Гаряче повітря блокується під пластиною, створюючи стійку стратифіковану подушку. Тепло відводиться лише шляхом повільного розтікання флюїду вбоки через краї пластини.

- **Стабільний режим (`10⁴ < Ra_L < 10⁹`):**

```
Nu_L = 0.27 · Ra_L^(1/4)
```

Порівняння показників показує, що тепловіддача від гарячої поверхні, повернутої донизу, є у два рази нижчою, ніж від повернутої догори.

## 4. Горизонтальний довгомірний циліндр та сфера

### Горизонтальний циліндр:
Для горизонтальних труб, кабелів та дротів діаметром `D` характерним розміром є `L = D`. Нагріте повітря огинає циліндр з двох боків і змикається зверху у конвективний шлейф.

Для всього діапазону чисел Релея (`10⁻⁵ < Ra_D < 10¹²`) застосовується точна формула Черчілля — Бернштейна:

```
Nu_D = [ 0.60 + (0.387 · Ra_D^(1/6)) / (1 + (0.559 / Pr)^(9/16))^(8/27) ]²
```

Для простих практичних розрахунків використовуються спрощені форми Мак-Адамса:
- Ламінарний режим (`10⁴ < Ra_D < 10⁸`): `Nu_D = 0.48 · Ra_D^(1/4)`.
- Турбулентний режим (`10⁸ < Ra_D < 10¹²`): `Nu_D = 0.125 · Ra_D^(1/3)`.

### Сфера:
Для ізольованої сфери діаметром `D` у нескінченному середовищі формула Черчілля має вигляд:

```
Nu_D = 2.0 + (0.589 · Ra_D^(1/4)) / [ 1 + (0.469 / Pr)^(9/16) ]^(4/9)
```

Перший член `2.0` являє собою фундаментальну теоретичну межу чистісінької молекулярної теплопровідності від сфери у нерухоме середовище при відсутності гравітації (`Ra -> 0`).

## 5. Замкнені прямокутні порожнини та склопакети

У замкнених прошарках (наприклад, повітряні зазори у двокамерних склопакетах або між платами у корпусі) характерним розміром є товщина прошарку `L = d`, а геометрія характеризується форм-фактором `A = H / d`.

При малих значеннях Релея (`Ra_d < 2000`) конвекція у зазорі повністю пригнічена, і тепло передається чистою теплопровідністю: `Nu_d = 1.0`.

При `Ra_d > 2000` у порожнині виникає замкнений циркуляційний контур (нагрітий потік піднімається вздовж гарячої стінки, а охолоджений опускається вздовж протилежної холодної).

Для вертикальних склопакетів з форм-фактором `10 < A < 40` застосовується формула Беренсона:

```
Nu_d = max( 1.0,  0.42 · Ra_d^(1/4) · Pr^(0.012) · A^(-0.3) )
```

Звідси видно, що збільшення товщини склопакета `d` понад оптимальну межу (близько 16–20 мм) не зменшує втрати тепла, оскільки зростання `Ra_d` підсилює конвективну циркуляцію, компенсуючи зростання товщини шару.

## 6. Проектування пасивних ребристих радіаторів

Для пасивного охолодження електронних компонентів вертикальними паралельними ребрами висотою `L` з кроком між ребрами `S` існує оптимальна відстань `S_opt`, яка максимізує сумарне знімання тепла.

### Формули розрахунку оптимального кроку ребер радіатора (Еленібаас, 1942; Бар-Коен, 1984):

1. **Число Еленібааса (`El`):**

```
El = (S / L) · Ra_S = (g · β · ΔT · S⁴) / (ν · α · L)
```

2. **Оптимальний міжреберний зазор (`S_opt`):**

```
S_opt = 2.71 · L / (Ra_L^(1/4)) = 2.71 · [ (ν · α · L) / (g · β · ΔT) ]^(1/4)
```

3. **Максимальний коефіцієнт тепловіддачі при `S = S_opt`:**

```
h_max ≈ 1.3 · (k / S_opt)
```

4. **Загальний конвективний тепловий потік від П-подібного радіатора шириною `W`, висотою `L` та товщиною ребер `t`:**

```
N_fins = floor( W / (S_opt + t) )
A_total = 2 · N_fins · L · H_fin + W · L
Q_conv = h_max · A_total · (T_wall - T_ambient)
```

## 7. Довідкові теплофізичні властивості повітря при `p = 101.3 кПа`

Для швидких практичних обчислень коефіцієнта тепловіддачі наведено таблицю фізичних властивостей сухого повітря при атмосферному тиску залежно від температури плівки `T_film`:

- **Температура T = -20 °C:** густина `ρ = 1.394 кг/м³`, в'язкість `ν = 11.79·10⁻⁶ м²/с`, температуропровідність `α = 16.2·10⁻⁶ м²/с`, теплопровідність `k = 0.0224 Вт/(м·К)`, число Прандтля `Pr = 0.728`.
- **Температура T = 0 °C:** густина `ρ = 1.293 кг/м³`, в'язкість `ν = 13.28·10⁻⁶ м²/с`, температуропровідність `α = 18.9·10⁻⁶ м²/с`, теплопровідність `k = 0.0240 Вт/(м·К)`, число Прандтля `Pr = 0.715`.
- **Температура T = 20 °C:** густина `ρ = 1.205 кг/м³`, в'язкість `ν = 15.11·10⁻⁶ м²/с`, температуропровідність `α = 21.4·10⁻⁶ м²/с`, теплопровідність `k = 0.0257 Вт/(м·К)`, число Прандтля `Pr = 0.713`.
- **Температура T = 40 °C:** густина `ρ = 1.127 кг/м³`, в'язкість `ν = 16.97·10⁻⁶ м²/с`, температуропровідність `α = 24.3·10⁻⁶ м²/с`, теплопровідність `k = 0.0271 Вт/(м·К)`, число Прандтля `Pr = 0.711`.
- **Температура T = 60 °C:** густина `ρ = 1.060 кг/м³`, в'язкість `ν = 18.90·10⁻⁶ м²/с`, температуропровідність `α = 27.3·10⁻⁶ м²/с`, теплопровідність `k = 0.0285 Вт/(м·К)`, число Прандтля `Pr = 0.709`.
- **Температура T = 80 °C:** густина `ρ = 1.000 кг/м³`, в'язкість `ν = 20.94·10⁻⁶ м²/с`, температуропровідність `α = 30.5·10⁻⁶ м²/с`, теплопровідність `k = 0.0299 Вт/(м·К)`, число Прандтля `Pr = 0.708`.
- **Температура T = 100 °C:** густина `ρ = 0.946 кг/м³`, в'язкість `ν = 23.06·10⁻⁶ м²/с`, температуропровідність `α = 33.8·10⁻⁶ м²/с`, теплопровідність `k = 0.0314 Вт/(м·К)`, число Прандтля `Pr = 0.707`.
