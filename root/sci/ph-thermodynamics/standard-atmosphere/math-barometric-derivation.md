# 🧮 Математичне виведення барометричного закону та геопотенціального перетворення

Математична модель Стандартної атмосфери ISA спирається на точне аналітичне інтегрування диференціального рівняння гідростатичної рівноваги газового стовпа у поєднанні з рівнянням стану ідеального газу та геометрично-гравітаційним перетворенням координати висоти. У цьому математичному описі відсутні емпіричні підгоночні параметри високого порядку: весь вертикальний профіль тиску, густини, швидкості звуку та в'язкості виводиться з кількох фундаментальних фізичних констант та заданого лінійно-шматкового профілю температури.

### 1. Перетворення геометричної висоти у геопотенціальну

Реальна геометрична висота `Z` є фізичною відстані від рівня моря до точки вимірювання, вимірюваною вздовж радіального напрямку від центра Землі. Оскільки Земля має скінченний радіус, прискорення вільного падіння `g` зменшується з віддаленням від її центра за законом всесвітнього тяжіння Ньютона. Якщо знехтувати малими еліпсоїдальними поправками та розглядати кулясто-симетричну модель Землі, прискорення сили тяжіння спадає за обернено-квадратичним законом:

```
g(Z) = g_0 · ( R_E / (R_E + Z) )²
```

де `g_0 = 9.80665 м/с²` — стандартне прискорення вільного падіння на широтній межі 45°45' (що враховує як гравітаційне притягання маси Землі, так і відцентрову силу її добового обертання), а `R_E = 6356.766 км` — ефективний геопотенціальний радіус Землі.

Якби ми інтегрували рівняння гідростатики безпосередньо за геометричною висотою `Z`, у знаменнику під інтегралом опинився би змінний коефіцієнт `g(Z)`, що суттєво ускладнило б підсумкові аналітичні вирази. Для усунення цієї залежності та спрощення подальших обчислень вводиться фундаментальне поняття **геопотенціальної висоти** `h`. Вона визначається через диференціал роботи гравітаційного поля з переміщення одиничної маси вгору на відстань `dZ`:

```
dΦ = g(Z) · dZ = g_0 · dh
```

де `Φ` — питомий гравітаційний потенціал. З цього співвідношення безпосередньо випливає диференціал геопотенціальної висоти:

```
dh = ( g(Z) / g_0 ) · dZ = ( R_E / (R_E + Z) )² · dZ
```

Для знаходження явної функціональної залежності `h(Z)` проінтегруємо цей диференціал від поверхні моря (де за вихідну точку прийнято `Z = 0` та `h = 0`) до довільної геометричної висоти `Z`:

```
h = ∫₀^Z ( R_E / (R_E + z) )² dz
= R_E² · [ -1 / (R_E + z) ]₀^Z      [інтегрування степеневої функції]
= R_E² · ( 1 / R_E - 1 / (R_E + Z) )
= R_E² · ( (R_E + Z - R_E) / (R_E · (R_E + Z)) )
= ( R_E · Z ) / ( R_E + Z )
```

Обернене перетворення для обчислення реальної геометричної висоти `Z` за відомою геопотенціальною `h` виводиться шляхом послідовних алгебраїчних перетворень:

```
h · (R_E + Z) = R_E · Z
h · R_E + h · Z = R_E · Z
Z · (R_E - h) = R_E · h
Z = ( R_E · h ) / ( R_E - h )
```

Фізичний зміст геопотенціальної висоти `h` полягає у створенні такої штучної математичної шкали висоти, у якій прискорення вільного падіння вважається строго постійним і дорівнює `g_0` на будь-якій висоті, а потенціальна енергія підйому одиничної маси на висоту `h` у фіксованому однорідному полі `g_0` точно дорівнює потенціальній енергії підйому на реальну геометричну висоту `Z` у спадному полі `g(Z)`.

Кількісна різниця між геометричною `Z` та геопотенціальною `h` висотами зростає квадратично з висотою. Обчислимо цю різницю для кількох характерних висот:
- На тропопаузі (`Z = 11.0 км`): `h = (6356.766 · 11.0) / (6356.766 + 11.0) = 10.981 км` (різниця складає лише 19 метрів).
- На стратопаузі (`Z = 50.0 км`): `h = (6356.766 · 50.0) / (6356.766 + 50.0) = 49.609 км` (різниця досягає 391 метра).
- На мезопаузі (`Z = 80.0 км`): `h = (6356.766 · 80.0) / (6356.766 + 80.0) = 79.006 км` (різниця становить вже 994 метри, тобто майже цілий кілометр).

Якби аеродинамічні чи термодинамічні розрахунки на висоті 80 км проводилися за геометричною висотою без перетворення в геопотенціал, похибка обчисленого тиску перевищила б 1.24%, а густини — понад 2.5%, що є недопустимим для розрахунку балістичного гальмування космічних апаратів.

### 2. Диференціальне рівняння гідростатичної рівноваги

Розглянемо нерухомий горизонтальний шар повітря площею `A` та товщиною `dh` на геопотенціальній висоті `h`. На цей елементарний об'єм діють дві протилежно спрямовані сили:
- Сила тиску нижніх шарів `P(h) · A`, спрямована вертикально вгору;
- Сила тиску вищележачих шарів `P(h + dh) · A` та сила ваги самого елементарного шару `dF_g = dm · g_0 = ρ · A · dh · g_0`, спрямовані вертикально вниз.

Умова стаціонарної гідростатичної рівноваги газового стовпа вимагає, щоб сума всіх діючих сил була строго дорівнювала нулю:

```
P(h) · A - P(h + dh) · A - ρ · A · g_0 · dh = 0
( P(h + dh) - P(h) ) = - ρ · g_0 · dh
dP / dh = - ρ · g_0                 [диференціальне рівняння гідростатики]
```

Для вираження густини `ρ` через тиск `P` та абсолютну температуру `T` застосовуємо рівняння стану ідеального газу (закон Клапейрона-Менделєєва):

```
P = ρ · R_spec · T
ρ = P / ( R_spec · T )
```

де `R_spec` — індивідуальна питома газова стала сухого повітря. Вона пов'язана з універсальною газовою сталою `R = 8.3144626 Дж/(моль·К)` та молярною масою сухого повітря `M_air = 0.0289644 кг/моль`:

```
R_spec = R / M_air = 8.3144626 / 0.0289644 ≈ 287.05287 Дж/(кг·К)
```

Варто зауважити, чому в моделі ISA використовується молярна маса саме сухого повітря. Реальне атмосферне повітря завжди містить певну кількість водяної пари. Оскільки молярна маса води `M_H2O = 0.018015 кг/моль` значно менша за молярну масу сухого повітря `M_air = 0.0289644 кг/моль`, вологе повітря завжди є легшим і менш щільним за сухе повітря при тій самій температурі й тиску. Проте вміст вологи стрімко падає з висотою і вище 3–5 км стає мізерно малим. Для уніфікації розрахунків модель ISA прийняла фундаментальне припущення про абсолютну сухість повітря на всіх висотах. У реальних метеорологічних розрахунках вологість враховують через так звану **віртуальну температуру** `T_v = T · (1 + 0.608 · q)`, де `q` — питома вологість.

Підставляючи вираз для густини у рівняння гідростатики, отримуємо фундаментальне диференціальне рівняння атмосферної рівноваги зі відокремлюваними змінними:

```
dP / dh = - ( P · g_0 ) / ( R_spec · T(h) )
dP / P = - ( g_0 / (R_spec · T(h)) ) · dh
```

Точний аналітичний розв'язок цього рівняння залежить від термодинамічного режиму конкретного атмосферного шару, тобто від функціонального вигляду `T(h)`.

### 3. Сухий адіабатичний градієнт та модельний градієнт ISA

Перш ніж інтегрувати диференціальне рівняння, з'ясуємо фізичне походження значення температурного градієнта в тропосфері `L = -0.0065 K/м`.

Якщо елементарний об'єм сухого повітря піднімається вертикально вгору без теплообміну з навколишнім середовищем (адіабатичний процес), розширення газу проти зовнішнього тиску виконує роботу за рахунок внутрішньої енергії:

```
dq = C_p · dT - v_spec · dP = 0
C_p · dT = v_spec · dP = (1 / ρ) · dP
```

Підставляючи диференціал гідростатичного тиску `dP = -ρ · g_0 · dh`, отримуємо **сухий адіабатичний температурний градієнт**:

```
C_p · dT = - g_0 · dh
( dT / dh )_dry = - g_0 / C_p
```

Для сухого повітря питома ізобарна теплоємність дорівнює `C_p ≈ 1004.68 Дж/(кг·К)`. Звідси теоретичний сухий адіабатичний градієнт становить:

```
( dT / dh )_dry = - 9.80665 / 1004.68 ≈ - 0.00976 K/м = - 9.76 K/км
```

Однак реальна атмосфера Землі містить водяну пару, яка при підйомі охолоджується та конденсується в хмари. Конденсація вологи супроводжується виділенням прихованої теплоти пароутворення (`L_v ≈ 2.5 × 10⁶ Дж/кг`), яка додатково підігріває піднімальне повітря. Як наслідок, вологий адіабатичний градієнт біля землі становить лише від -4.0 до -6.0 K/км.

Усереднене за всією земною кулею та сезонами значення фактичного градієнта становить саме `-6.5 K/км`. Саме це середньопланетарне значення `L = -0.0065 K/м` було покладено в основу моделі ISA для тропосферного шару від 0 до 11 км.

### 4. Точна інтеграція для градієнтного шару (L ≠ 0)

У шарах із лінійною зміною температури (тропосфера, середня стратосфера, мезосфера) вертикальний профіль температури задається рівнянням:

```
T(h) = T_b + L · (h - h_b)
```

де `h_b` — геопотенціальна висота основи шару, `T_b` — абсолютна температура на основі шару, а `L = dT/dh` — постійний температурний градієнт (вертикальна градієнтна швидкість).

Диференціюючи рівняння температури за геопотенціальною висотою, отримуємо `dT = L · dh`, звідки маємо `dh = dT / L`. Підставляємо цей диференціал у базове рівняння тиску:

```
dP / P = - ( g_0 / (R_spec · (T_b + L·(h - h_b))) ) · dh
dP / P = - ( g_0 / (R_spec · L) ) · ( dT / T )
```

Інтегруємо обидві частини рівняння від умов на нижній межі шару `(h_b, T_b, P_b)` до довільної висоти `(h, T, P)` усередині цього шару:

```
∫[P_b to P] (1 / P') dP' = - ( g_0 / (R_spec · L) ) · ∫[T_b to T] (1 / T') dT'
ln(P) - ln(P_b) = - ( g_0 / (R_spec · L) ) · ( ln(T) - ln(T_b) )     [інтегрування 1/x]
ln( P / P_b ) = ln( ( T / T_b ) ^ ( - g_0 / (R_spec · L) ) )         [властивість логарифма]
```

Потенціюючи ліву та праву частини за основою `e`, отримуємо точну барометричну формулу тиску для градієнтного шару:

```
P(h) = P_b · ( T(h) / T_b ) ^ ( - g_0 / (R_spec · L) )
```

Густина повітря `ρ(h)` обчислюється підстановкою закону тиску у рівняння стану ідеального газу:

```
ρ(h) = P(h) / ( R_spec · T(h) )
ρ(h) = ( P_b · ( T(h) / T_b ) ^ ( - g_0 / (R_spec · L) ) ) / ( R_spec · T_b · ( T(h) / T_b ) )
ρ(h) = ( P_b / (R_spec · T_b) ) · ( T(h) / T_b ) ^ ( - g_0 / (R_spec · L) - 1 )
ρ(h) = ρ_b · ( T(h) / T_b ) ^ ( - ( g_0 / (R_spec · L) + 1 ) )
```

Введемо безрозмірний показник степеня тиску `n_p = - g_0 / (R_spec · L)`. Для тропосфери (`L = -0.0065 K/м = -0.0065 K/км`):

```
n_p = - 9.80665 / ( 287.05287 · (-0.0065) )
n_p = 9.80665 / 1.86584365 ≈ 5.25588
```

Показник степеня для густини в тропосфері дорівнює:

```
n_ρ = n_p - 1 = 5.25588 - 1 = 4.25588
```

Таким чином, у тропосфері тиск спадає пропорційно температурі у степені 5.25588, а густина — у степені 4.25588.

### 5. Точна інтеграція для ізотермічного шару (L = 0) та граничний перехід

У шарах із постійною температурою `T(h) = T_b` (тропопауза 11–20 км, стратопауза 47–51 км) температурний градієнт дорівнює нулю `L = 0`. Диференціальне рівняння спрощується:

```
dP / P = - ( g_0 / (R_spec · T_b) ) · dh
```

Інтегруючи від `h_b` до `h`:

```
∫[P_b to P] (1 / P') dP' = - ( g_0 / (R_spec · T_b) ) · ∫[h_b to h] dh'
ln( P / P_b ) = - ( g_0 · (h - h_b) ) / ( R_spec · T_b )
P(h) = P_b · exp( - ( g_0 · (h - h_b) ) / ( R_spec · T_b ) )
```

Оскільки температура постійна, з рівняння ідеального газу випливає, що густина падає з висотою за суворо тотожним експоненційним законом:

```
ρ(h) = ρ_b · exp( - ( g_0 · (h - h_b) ) / ( R_spec · T_b ) )
```

Цікаво показати математичну строгість зв'язку між градієнтною та ізотермічною формулами через граничний перехід при `L → 0`. Перепишемо відношення тиску у вигляді:

```
P(h) / P_b = ( 1 + (L · Δh) / T_b ) ^ ( - g_0 / (R_spec · L) )
```

Введемо малий параметр `ε = (L · Δh) / T_b`. Тоді показник степеня дорівнює `- (g_0 · Δh) / (R_spec · T_b · ε)`. Застосовуючи першу чудову границю `lim_{ε → 0} (1 + ε)^(1/ε) = e`, маємо:

```
lim_{L → 0} ( 1 + ε ) ^ ( - (g_0 · Δh) / (R_spec · T_b · ε) )
= [ lim_{ε → 0} ( 1 + ε ) ^ (1/ε) ] ^ ( - (g_0 · Δh) / (R_spec · T_b) )
= exp( - (g_0 · Δh) / (R_spec · T_b) )
```

Це доводить, що ізотермічне експоненційне рішення є не окремим випадковим законом, а строгим математичним граничним випадком градієнтного степеневого закону при прямуванні градієнта до нуля.

Введемо характеристичну **масштабну висоту ізотермічної атмосфери** `H_s = (R_spec · T_b) / g_0`. Для нижньої стратосфери (`T_b = 216.65 K`):

```
H_s = ( 287.05287 · 216.65 ) / 9.80665 ≈ 6341.6 м ≈ 6.342 км
```

Фізичний зміст масштабної висоти `H_s` полягає у тому, що при підйомі на кожні 6.342 км усередині ізотермічного шару 11–20 км атмосферний тиск та густина зменшуються строго в `e ≈ 2.71828` рази.

### 6. Неперервність умов на міжшарових межах та рекурентний алгоритм

Складні багатошарові атмосферні моделі вимагають суворої неперервності фізичних полів на межах між суміжними шарами. Нехай атмосфера розбита на `N` шарів із висотами меж `h_0, h_1, h_2, ..., h_N`.

На кожній межі `h_i` повинні виконуватися три граничні умови неперервності:
1. **Неперервність температури:**
```
T(h_i) = T_{b, i} = T_{b, i-1} + L_{i-1} · (h_i - h_{i-1})
```
2. **Неперервність тиску:**
```
P_{b, i} = P(h_i)
```
значення `P_{b, i}` обчислюється за формулою попереднього `(i-1)`-го шару на висоті `h_i`.
3. **Неперервність густини:**
```
ρ_{b, i} = P_{b, i} / ( R_spec · T_{b, i} )
```

Завдяки цьому рекурентному зшиванню уся модель атмосфери являє собою єдиний гладкий монотонно спадний профіль тиску та густини без жодного стрибка чи розриву на межах шарів.

Для знаходження тиску на довільній висоті `h` обчислювальний алгоритм спершу визначає порядковий номер активного шару `k`, для якого `h_{k} ≤ h < h_{k+1}`. Після цього послідовно розраховуються базові параметри `(T_b, P_b, ρ_b)` для всіх попередніх шарів від `0` до `k`, і лише потім застосовується підсумкова формула для шару `k`.

### 7. Виведення барометричної висоти та висоти за густиною

Для розв'язання обернених задач авіаційної навігації виникає потреба знаходження геопотенціальної висоти за виміряним тиском `P` (барометрична висота `h_p`) або виміряною густиною `ρ` (висота за густиною `h_d`).

Для тропосферного шару (де `L = -0.0065 K/м`), виразивши температуру `T(h)` через тиск `P` з барометричної формули градієнтного шару:

```
P / P_0 = ( T / T_0 ) ^ n_p
T = T_0 · ( P / P_0 ) ^ ( 1 / n_p )
```

Підставляючи це у формулу температури `T = T_0 + L · h_p`, отримуємо явне вираження **барометричної висоти** `h_p`:

```
h_p = ( T_0 / (-L) ) · ( 1 - ( P / P_0 ) ^ ( 1 / n_p ) )
```

З урахуванням числових значень `T_0 = 288.15 K`, `L = -0.0065 K/м` та `1 / n_p = 1 / 5.25588 ≈ 0.190263`:

```
h_p = ( 288.15 / 0.0065 ) · ( 1 - ( P / P_0 )^0.190263 )
h_p = 44330.77 · ( 1 - ( P / P_0 )^0.190263 )
```

Аналогічно виводиться **висота за густиною** `h_d` за відомою місцевою густиною `ρ`:

```
h_d = ( T_0 / (-L) ) · ( 1 - ( ρ / ρ_0 ) ^ ( 1 / n_ρ ) )
h_d = 44330.77 · ( 1 - ( ρ / ρ_0 )^0.234956 )
```

Ці математичні вирази утворюють фундамент обчислювачів повітряних сигналів (Air Data Computers) сучасних літаків.

### 8. Виведення швидкості звуку з тривимірної акустичної хвильової динаміки

Швидкість поширення малих акустичних збурень (звукових хвиль) у суцільному середовищі визначається з хвильового рівняння, виведеного з рівнянь гідродинаміки Ейлера та рівняння неперервності.

Запишемо одновимірне рівняння руху Ейлера без урахування в'язкості та сили ваги для малих збурень тиску `p'` та швидкості `u'`:

```
ρ_0 · ( ∂u' / ∂t ) = - ∂p' / ∂x      [рівняння руху Ейлера]
```

Рівняння неперервності для малого збурення густини `ρ'`:

```
∂ρ' / ∂t + ρ_0 · ( ∂u' / ∂x ) = 0     [рівняння неперервності]
```

Диференціюючи рівняння неперервності за часом `t`, а рівняння руху за координатою `x`, та виключаючи швидкість `u'`, отримуємо:

```
∂²ρ' / ∂t² = ∂²p' / ∂x²
```

Оскільки мале збурення тиску пов'язане зі збуренням густини через похідну стискальності `dp' = (dP / dρ)|_s · dρ'`, підставляємо це у хвильове співвідношення:

```
∂²p' / ∂t² = ( (dP / dρ)|_s ) · ( ∂²p' / ∂x² )
```

Порівнюючи це з класичним хвильовим рівнянням `∂²p'/∂t² = a² · ∂²p'/∂x²`, маємо фундаментальну формулу швидкості звуку:

```
a = √( (dP / dρ)|_s )
```

Поширення звукових хвиль у повітрі є адіабатичним процесом, оскільки частота акустичних коливань занадто висока для проходження помітного теплообміну між суміжними зонами стиснення та розрідження. Рівняння адіабати ідеального газу має вигляд:

```
P · ρ^(-γ) = const  =>  P = C · ρ^γ
```

де `γ = C_p / C_v` — показник адіабати (адіабатичний індекс). Для двохатомних газів (азот $N_2$ та кисень $O_2$, що складають 99% повітря) теоретичне значення показника адіабати за ступенями вільності дорівнює:

```
γ = (i + 2) / i = (5 + 2) / 5 = 7 / 5 = 1.40
```

Диференціюємо тиск за густиною уздовж адіабати:

```
dP / dρ = C · γ · ρ^(γ - 1)
dP / dρ = γ · ( C · ρ^γ ) / ρ
dP / dρ = γ · ( P / ρ )
```

Підставляючи це у формулу швидкості звуку та застосовуючи рівняння стану ідеального газу `P / ρ = R_spec · T`, отримуємо точний вираз:

```
a(T) = √( γ · (P / ρ) ) = √( γ · R_spec · T )
```

Важливо підкреслити: **швидкість звуку в ідеальному газі залежить виключно від абсолютної температури `T`** і абсолютно не залежить від барометричного тиску `P` або густини `ρ`.

Для стандартних умов на рівні моря (`T_0 = 288.15 K`):

```
a_0 = √( 1.40 · 287.05287 · 288.15 )
a_0 = √( 115797.1 ) ≈ 340.294 м/с ≈ 1225.06 км/год
```

### 9. Молекулярно-кінетичне виведення в'язкості Сазерленда та межі суцільного середовища

Динамічна в'язкість повітря `μ` описує внутрішнє тертя між суміжними шарами газу, що рухаються з різними швидкостями. Згідно з молекулярно-кінетичною теорією, перенос імпульсу здійснюється хаотичним тепловим рухом молекул:

```
μ = (1 / 3) · ρ · v_mean · λ
```

де `v_mean = √( (8 · R_spec · T) / π )` — середня теплова швидкість молекул, а `λ` — середня довжина вільного пробігу:

```
λ = 1 / ( √2 · π · d_eff² · n )
```

де `n = ρ / m_mol` — числова концентрація молекул, а `d_eff` — ефективний газодинамічний діаметр молекули.

У класичній моделі твердих сфер діаметр `d_eff` вважався б постійним, і в'язкість росла б пропорційно `√T`. Проте реальні молекули оточені привабливими ван-дер-ваальсовими силами. При низьких температурах повільні молекули сильніше відхиляються привабливим потенціалом, що ефективно збільшує переріз зіткнення. Англійський фізик Вільям Сазерленд у 1893 році врахував цей привабливий потенціал та отримав ефективний переріз:

```
σ_eff(T) = σ_0 · ( 1 + S / T )
```

де `S` — константа Сазерленда (характеристична температура притягання молекул). З урахуванням цього температурна залежність динамічної в'язкості набуває вигляду:

```
μ(T) = β_s · T^(3/2) / ( T + S )
```

Для повітря у моделі ISA використано точні емпіричні константи стандарту ISO 2533:
- `β_s = 1.458 × 10⁻⁶ кг/(м·с·K¹/²)`
- `S = 110.4 K`

Кінематична в'язкість `ν(h)`, яка визначає аеродинамічне дифузне розмивання вихорів та число Рейнольдса `Re = v · L / ν`, обчислюється як відношення динамічної в'язкості до місцевої густини:

```
ν(h) = μ( T(h) ) / ρ(h)
```

Оскільки густина `ρ(h)` спадає з висотою набагато стрімкіше, ніж динамічна в'язкість `μ(T)`, кінематична в'язкість `ν` зростає з висотою на кілька порядків. На висоті 40 км кінематична в'язкість повітря перевищує значення біля землі майже у 300 разів, що призводить до кардинальної зміни аеродинамічних режимів обтікання літальних апаратів.

На висотах понад 86 км довжина вільного пробігу молекул `λ` досягає кількох сантиметрів і метрів. Безрозмірне **число Кнудсена** `Kn = λ / L_char` (де `L_char` — характерний розмір літака) перевищує межу `Kn > 0.01`, що знаменує вихід з області застосовності механіки суцільного середовища (рівнянь Нав'є-Стокса) і перехід до молекулярної газової динаміки.
