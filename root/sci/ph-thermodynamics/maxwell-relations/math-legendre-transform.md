# 🧮 Математичний апарат потенціалів та перетворень Лежандра

Математична структура термодинаміки базується на двох фундаментальних поняттях аналізу багатьох змінних: точних диференціалах скалярних функцій стану та класичному перетворенні Лежандра (*Legendre transformation*), яке дозволяє змінювати незалежні змінні функції без втрати інформації про геометрію системи. Завдяки цьому апарату абстрактні геометричні властивості багатовимірних поверхонь енергії перетворюються на строгі співвідношення між спостережуваними величинами.

### 1. Точні диференціали та теорема Ейлера — Шварца

Розглянемо диференціальну 1-форму двох змінних `x` та `y` у просторі `R²`:

```
dZ = M(x, y) dx + N(x, y) dy
```

Цей вираз називається **точним диференціалом** (*exact differential*), якщо існує така неперервно диференційована скалярна функція стану `Z(x, y)` класу `C²`, що її повний диференціал збігається з даною формою. З визначення часткових похідних випливає:

```
M(x, y) = (∂Z / ∂x)ᵧ
N(x, y) = (∂Z / ∂y)ₓ
```

Якщо функція `Z(x, y)` має неперервні часткові похідні другого порядку, то за теоремою Шварца (теоремою Ейлера про симетрію мішаних похідних) порядок диференціювання не має значення:

```
∂²Z / (∂y ∂x) = ∂²Z / (∂x ∂y)
```

Підставляючи вирази для `M` та `N`, отримуємо **умову точності диференціала**:

```
(∂M / ∂y)ₓ = (∂N / ∂x)ᵧ
```

У термодинаміці ця чисто математична тотожність має вирішальне значення. Якщо якась величина `Z` є функцією стану (наприклад, внутрішня енергія `U`, ентропія `S` або енергія Гіббса `G`), то її приріст у будь-якому замкненому циклі дорівнює нулю `∮ dZ = 0`, а коефіцієнти її диференціала задовольняють умову Ейлера — Шварца. Натомість елементарна робота `δW` та елементарна теплота `δQ` **не є точними диференціалами** (вони залежать від шляху процесу), тому для них такі співвідношення не виконуються.

### 2. Формалізм перетворення Лежандра

Припустимо, що функція `f(x)` описує стан системи через незалежну змінну `x`. У багатьох фізичних задачах зручніше оперувати не самою змінною `x`, а ухилом дотичної до графіка цієї функції `p = df/dx`. Проста заміна змінної у виразі `f(x(p))` призводить до втрати інформації: різні функції можуть мати однакову залежність ухилу від значення, відрізняючись лише зсувом.

Щоб зберегти повну інформацію про функцію при переході до нової змінної `p`, застосовують **перетворення Лежандра**.

#### Одновимірне перетворення Лежандра

Для гладкої строго опуклої функції `f(x)` перетворення Лежандра визначається як нова функція `g(p)` спряженої змінної `p = f'(x)`:

```
g(p) = p · x(p) − f(x(p))
```

Знайдемо повний диференціал нової функції `g(p)`:

```
dg = d(p·x − f)
   = p dx + x dp − df
   = p dx + x dp − p dx        [бо df = p dx]
   = x dp
```

Отже, похідна нової функції за новою змінною дорівнює вихідній змінній:

```
dg / dp = x
```

Геометрично перетворення Лежандра відповідає переходу від опису кривої як множини точок `(x, y)` до її опису як огинаючої родини дотичних прямих `y = p·x − g(p)`. Величина `g(p)` має зміст відрізка, який дотична пряма відтинає на осі ординат.

#### Багатовимірне перетворення Лежандра

Для функції багатьох змінних `f(x, y)` диференціал має вигляд:

```
df = u dx + v dy,   де u = (∂f/∂x)ᵧ,  v = (∂f/∂y)ₓ
```

Ми можемо виконати перетворення Лежандра за однією змінною `x`, замінивши її на спряжену змінну `u`, або за обома змінними одночасно.

1. Перетворення за змінною `x`:
   `g(u, y) = u · x − f(x, y)  ⇒  dg = x du − v dy`

2. Подвійне перетворення за `x` та `y`:
   `h(u, v) = u · x + v · y − f(x, y)  ⇒  dh = x du + y dv`

Саме цей формалізм дозволяє побудувати всі чотири класичні термодинамічні потенціали з вихідної внутрішньої енергії.

### 3. Строге виведення чотирьох співвідношень Максвелла

Застосуємо апарат перетворень Лежандра та теорему Шварца до термодинаміки закритих систем.

#### 1. Внутрішня енергія U(S, V)

Перше і друге начала термодинаміки для зворотних процесів визначають диференціал внутрішньої енергії `U`:

```
dU = T dS − P dV
```

Природними змінними внутрішньої енергії є ентропія `S` та об'єм `V`. Звідси часткові похідні дорівнюють:

```
(∂U / ∂S)ᵥ = T
(∂U / ∂V)ₛ = −P
```

Застосовуючи теорему Шварца про рівність мішаних похідних `∂²U / (∂V ∂S) = ∂²U / (∂S ∂V)`:

```
∂/∂V [(∂U/∂S)ᵥ]ₛ = ∂/∂S [(∂U/∂V)ₛ]ᵥ
```

Підставляючи значення часткових похідних, отримуємо **перше співвідношення Максвелла**:

```
(∂T / ∂V)ₛ = −(∂P / ∂S)ᵥ
```

#### 2. Ентальпія H(S, P)

Виконаємо перетворення Лежандра внутрішньої енергії `U(S, V)` за змінною об'єму `V`. Спряженою змінною до `V` є `-P`. Новий потенціал називається **ентальпією** `H`:

```
H(S, P) = U − (−P)·V = U + P·V
```

Диференціюємо ентальпію:

```
dH = dU + P dV + V dP            [диференціювання добутку P·V]
   = (T dS − P dV) + P dV + V dP  [підстановка dU = T dS − P dV]
   = T dS + V dP                [взаємне скасування членів P dV]
```

Природними змінними ентальпії є ентропія `S` та тиск `P`. Звідси:

```
(∂H / ∂S)ₚ = T
(∂H / ∂P)⛛ = V
```

Рівність мішаних похідних `∂²H / (∂P ∂S) = ∂²H / (∂S ∂P)` дає **друге співвідношення Максвелла**:

```
(∂T / ∂P)⛛ = (∂V / ∂S)ₚ
```

#### 3. Вільна енергія Гельмгольца F(T, V)

Виконаємо перетворення Лежандра внутрішньої енергії `U(S, V)` за ентропією `S`. Спряженою змінною до `S` є температура `T`. Отриманий потенціал є **вільною енергією Гельмгольца** `F`:

```
F(T, V) = U − T·S
```

Обчислимо диференціал:

```
dF = dU − T dS − S dT            [диференціювання добутку T·S]
   = (T dS − P dV) − T dS − S dT  [підстановка dU = T dS − P dV]
   = −S dT − P dV               [взаємне скасування членів T dS]
```

Природними змінними вільної енергії є температура `T` та об'єм `V`. Звідси:

```
(∂F / ∂T)ᵥ = −S
(∂F / ∂V)ₜ = −P
```

Застосовуючи теорему Шварца `∂²F / (∂V ∂T) = ∂²F / (∂T ∂V)`:

```
∂/∂V [−S]ₜ = ∂/∂T [−P]ᵥ
```

Множачи обидві частини на `-1`, отримуємо **третє співвідношення Максвелла**:

```
(∂S / ∂V)ₜ = (∂P / ∂T)ᵥ
```

#### 4. Енергія Гіббса G(T, P)

Виконаємо подвійне перетворення Лежандра за обома змінними `S` та `V` (або однократне перетворення ентальпії `H` за ентропією `S`). Отриманий потенціал називається **енергією Гіббса** `G`:

```
G(T, P) = H − T·S = U + P·V − T·S
```

Знаходимо диференціал:

```
dG = dH − T dS − S dT            [диференціювання добутку T·S]
   = (T dS + V dP) − T dS − S dT  [підстановка dH = T dS + V dP]
   = −S dT + V dP               [взаємне скасування членів T dS]
```

Природними змінними енергії Гіббса є температура `T` та тиск `P`. Звідси:

```
(∂G / ∂T)ₚ = −S
(∂G / ∂P)ₜ = V
```

Рівність мішаних похідних `∂²G / (∂P ∂T) = ∂²G / (∂T ∂P)` визначає **четверте співвідношення Максвелла**:

```
−(∂S / ∂P)ₜ = (∂V / ∂T)ₚ   ⇒   (∂S / ∂P)ₜ = −(∂V / ∂T)ₚ
```

### 4. Метод Якобіанів (визначників Якобі)

Алгебраїчно найбільш вишуканим способом маніпулювання частковими похідними у термодинаміці є **метод Якобіанів**.

Для двох функцій `u(x, y)` та `v(x, y)` двох змінних `x` та `y` Якобіан (визначник матриці Якобі) визначається як:

```
∂(u, v) / ∂(x, y) = det | ∂u/∂x  ∂u/∂y |
                        | ∂v/∂x  ∂v/∂y |
                  = (∂u/∂x)ᵧ · (∂v/∂y)ₓ − (∂u/∂y)ₓ · (∂v/∂x)ᵧ
```

#### Основні властивості Якобіанів

1. **Антисиметричність:**
   `∂(u, v) / ∂(x, y) = − ∂(v, u) / ∂(x, y) = − ∂(u, v) / ∂(y, x)`

2. **Запис часткової похідної:**
   `(∂u / ∂x)ᵧ = ∂(u, y) / ∂(x, y)`

3. **Ланцюгове правило для Якобіанів:**
   `∂(u, v) / ∂(x, y) = [ ∂(u, v) / ∂(t, w) ] · [ ∂(t, w) / ∂(x, y) ]`

4. **Тотожність обернення:**
   `∂(u, v) / ∂(x, y) = 1 / [ ∂(x, y) / ∂(u, v) ]`

#### Виведення співвідношень Максвелла через Якобіани

Використовуючи 1-ше і 2-ге начала термодинаміки, елементарна теплота дорівнює `dQ = T dS`. Елементарна робота дорівнює `dW = P dV`. У канонічній площині `(T, S)` та `(P, V)` площа елементарного циклу інваріантна:

```
∂(T, S) / ∂(P, V) = 1
```

Застосовуємо ланцюгове правило для будь-якої пари незалежних змінних `(x, y)`:

```
∂(T, S) / ∂(x, y) = ∂(P, V) / ∂(x, y)
```

Розкриваємо цю тотожність для конкретних виборів змінних:

- Якщо `x = T`, `y = V`:
  `∂(T, S) / ∂(T, V) = (∂S / ∂V)ₜ`
  `∂(P, V) / ∂(T, V) = (∂P / ∂T)ᵥ`
  Звідси негайно маємо третє співвідношення Максвелла: `(∂S/∂V)ₜ = (∂P/∂T)ᵥ`.

- Якщо `x = T`, `y = P`:
  `∂(T, S) / ∂(T, P) = (∂S / ∂P)ₜ`
  `∂(P, V) / ∂(T, P) = −(∂V / ∂T)ₚ`
  Звідси маємо четверте співвідношення Максвелла: `(∂S/∂P)ₜ = −(∂V/∂T)ₚ`.

Метод Якобіанів автоматизує навіть найскладніші перетворення часткових похідних у термодинаміці, зводячи їх до стандартних правил лінійної алгебри.

### 5. Матриця Гессе та критерії термодинамічної стабільності

Другі похідні термодинамічних потенціалів утворюють симетричну **матрицю Гессе** (Гессіан). Для внутрішньої енергії `U(S, V)` Гессіан має вигляд:

```
H_U = | ∂²U/∂S²    ∂²U/(∂S ∂V) |   =   | (∂T/∂S)ᵥ    (∂T/∂V)⛥ |
      | ∂²U/(∂V ∂S)  ∂²U/∂V²   |       | −(∂P/∂S)ᵥ  −(∂P/∂V)⛥ |
```

Згідно з другим началом термодинаміки, стан рівноваги ізольованої системи відповідає мінімуму потенціалу (або максимуму ентропії). За критерієм Сильвестра, для мінімуму функціонала матриця Гессе повинна бути позитивно визначеною. Це вимагає:

1. **Головний кутовий мінор 1-го порядку:**
   `(∂²U / ∂S²)ᵥ = (∂T / ∂S)ᵥ = T / Cᵥ > 0  ⇒  Cᵥ > 0`
   Теплоємність при сталому об'ємі повинна бути строго додатною (теплова стабільність).

2. **Визначник Гессіана (мінор 2-го порядку):**
   `det(H_U) = (∂T/∂S)ᵥ · [−(∂P/∂V)⛥] − [(∂T/∂V)⛥]² > 0`

Оскільки `−(∂P/∂V)⛥ = 1 / (V · κ⛥)`, де `κ⛥` — адіабатична стисливість, ця умова вимагає `κ⛥ > 0` (механічна стабільність: при стисканні речовини тиск мусить зростати, інакше система вибухне або колапсує).

### 6. Узагальнені співвідношення для відкритих, магнітних та пружних систем

Математичний формалізм Лежандра легко узагальнюється на системи із додатковими ступенями вільності.

#### Відкриті системи (змінна кількість частинок N)

Якщо система обмінюється речовиною із середовищем, диференціал внутрішньої енергії містить хімічний потенціал `μ`:

```
dU = T dS − P dV + μ dN
```

Виконуючи перетворення Лежандра за `N`, отримуємо Великий канонічний потенціал `Ω(T, V, μ) = F − μ·N`:

```
dΩ = −S dT − P dV − N dμ
```

За теоремою Шварца для пари `(T, μ)` та `(V, μ)` маємо перехресні співвідношення Максвелла для відкритих систем:

```
(∂S / ∂μ)ₜ,ᵥ = (∂N / ∂T)ᵥ,ᵤ
(∂P / ∂μ)ₜ,ᵥ = (∂N / ∂V)ₜ,ᵤ
```

#### Магнітні системи

Для магнітного середовища у зовнішньому полі `H` з намагніченістю `M` елементарна робота дорівнює `dW_mag = −H dM`. Диференціал внутрішньої енергії набуває вигляду `dU = T dS + H dM`.

Виконуючи перетворення Лежандра за намагніченістю `M`, отримуємо магнітний потенціал Ґіббса `G_mag(T, H) = U − T·S − H·M` з диференціалом:

```
dG_mag = −S dT − M dH
```

За теоремою Шварца для `G_mag(T, H)` маємо магнітне співвідношення Максвелла:

```
(∂S / ∂H)ₜ = (∂M / ∂T)ₕ
```

Це рівняння лежить в основі **магнітокалоричного ефекту**: зміна зовнішнього магнітного поля в ізотермічних умовах викликає зміну ентропії, яка пропорційна температурному коефіцієнту намагніченості.

#### Пружні одновимірні деформації

Для стержня з натягом `σ` та відносною деформацією `ε` елементарна робота дорівнює `dW_el = σ dε`. Диференціал потенціалу Ґіббса для пружного тіла `dG_el = −S dT − ε dσ` дає п'єзотермічне співвідношення Максвелла:

```
(∂S / ∂σ)ₜ = (∂ε / ∂T)ᵱ
```

Швидкість зміни ентропії при механічному напруженні дорівнює коефіцієнту лінійного теплового розширення стержня.

### 7. Математичне виведення різниці теплоємностей Cₚ − Cᵥ

Застосуємо третє співвідношення Максвелла `(∂S/∂V)ₜ = (∂P/∂T)ᵥ` для строгого розрахунку різниці ізобарної та ізохорної теплоємностей.

За визначенням:

```
Cₚ = T · (∂S / ∂T)ₚ
Cᵥ = T · (∂S / ∂T)ᵥ
```

Записуємо ентропію як функцію `S(T, V)` з повним диференціалом:

```
dS = (∂S / ∂T)ᵥ dT + (∂S / ∂V)ₜ dV
```

Ділимо цей вираз на `dT` при сталому тиску `P`:

```
(∂S / ∂T)ₚ = (∂S / ∂T)ᵥ + (∂S / ∂V)ₜ · (∂V / ∂T)ₚ
```

Множимо обидві частини на `T`:

```
T·(∂S / ∂T)ₚ = T·(∂S / ∂T)ᵥ + T · (∂S / ∂V)ₜ · (∂V / ∂T)ₚ
Cₚ = Cᵥ + T · (∂S / ∂V)ₜ · (∂V / ∂T)ₚ
```

Підставляємо третє співвідношення Максвелла `(∂S/∂V)ₜ = (∂P/∂T)ᵥ`:

```
Cₚ − Cᵥ = T · (∂P / ∂T)ᵥ · (∂V / ∂T)ₚ
```

Виразимо похідну `(∂P/∂T)ᵥ` через вимірювані коефіцієнти: ізобарний коефіцієнт розширення `α = (1/V)·(∂V/∂T)ₚ` та ізотермічну стисливість `κₜ = −(1/V)·(∂V/∂P)ₜ`. За тотожністю циклічної перестановки для `P, V, T`:

```
(∂P / ∂T)ᵥ · (∂T / ∂V)ₚ · (∂V / ∂P)ₜ = −1
⇒ (∂P / ∂T)ᵥ = − (∂V / ∂T)ₚ / (∂V / ∂P)ₜ = (V·α) / (V·κₜ) = α / κₜ
```

Підставляючи це у формулу для різниці теплоємностей:

```
Cₚ − Cᵥ = T · (α / κₜ) · (V · α) = (T · V · α²) / κₜ
```

Оскільки температура `T > 0`, об'єм `V > 0`, а для стійких систем `κₜ > 0`, квадрат `α² ≥ 0` стверджує, що ізобарна теплоємність **завжди більша або дорівнює** ізохорній `Cₚ ≥ Cᵥ`.

### 8. Математичне виведення ефекту Джоуля — Томсона

При дроселюванні (продавлюванні газу через пористу перегородку) ентальпія системи зберігається `H = const`. Коефіцієнт Джоуля — Томсона визначається як:

```
μ_JT = (∂T / ∂P)ₕ
```

Записавши диференціал ентальпії `H(T, P)`:

```
dH = (∂H / ∂T)ₚ dT + (∂H / ∂P)ₜ dP = Cₚ dT + (∂H / ∂P)ₜ dP
```

Оскільки `dH = 0`:

```
Cₚ dT = − (∂H / ∂P)ₜ dP  ⇒  μ_JT = (∂T / ∂P)ₕ = − (1 / Cₚ) · (∂H / ∂P)ₜ
```

Знайдемо часткову похідну `(∂H / ∂P)ₜ`. Скористаємося диференціалом `dH = T dS + V dP` і розділимо його на `dP` при сталому `T`:

```
(∂H / ∂P)ₜ = T · (∂S / ∂P)ₜ + V
```

Застосуємо четверте співвідношення Максвелла `(∂S / ∂P)ₜ = −(∂V / ∂T)ₚ`:

```
(∂H / ∂P)ₜ = − T · (∂V / ∂T)ₚ + V
```

Підставляємо цей результат у вираз для `μ_JT`:

```
μ_JT = − (1 / Cₚ) · [ − T · (∂V / ∂T)ₚ + V ]
     = (1 / Cₚ) · [ T · (∂V / ∂T)ₚ − V ]
```

Виражаючи `(∂V / ∂T)ₚ = V · α`, отримуємо остаточну математичну формулу ефекту Джоуля — Томсона:

```
μ_JT = (V / Cₚ) · (T · α − 1)
```

Для ідеального газу `P·V = R·T ⇒ α = 1/T ⇒ T·α − 1 = 0 ⇒ μ_JT = 0`. Ідеальний газ при дроселюванні не змінює температури. Для реальних газів знак `μ_JT` залежить від того, чи перевищує добуток `T·α` одиницю (нагрівання при `T·α < 1` чи охолодження при `T·α > 1`), що визначається температурою інверсії.

### 9. Математичний аналіз для газу Ван-дер-Ваальса та акустичних хвиль

Розглянемо застосування отриманих математичних похідних до газу Ван-дер-Ваальса, рівняння стану якого має вигляд:

```
(P + a / V²) · (V − b) = R · T
```

Виразимо тиск `P`:

```
P(T, V) = [ R·T / (V − b) ] − [ a / V² ]
```

Обчислимо термічний коефіцієнт тиску при сталому об'ємі `(∂P / ∂T)ᵥ`:

```
(∂P / ∂T)ᵥ = R / (V − b)
```

За третім співвідношенням Максвелла `(∂S / ∂V)ₜ = (∂P / ∂T)ᵥ = R / (V − b)`. Звідси обчислюємо калоричне рівняння стану — залежність внутрішньої енергії `U` від об'єму:

```
(∂U / ∂V)ₜ = T · (∂S / ∂V)ₜ − P
           = T · [ R / (V − b) ] − [ R·T / (V − b) − a / V² ]
           = a / V²
```

Інтегруючи це рівняння за `V`, отримуємо внутрішню енергію реального газу:

```
U(T, V) = Cᵥ · T − a / V + U₀
```

Член `-a / V` прямо описує потенціальну енергію міжмолекулярного притягання: при ізотермічному розширенні об'єму `V` молекули віддаляються одна від одної, подолаючи сили притягання, тож внутрішня енергія реального газу зростає.

Також часткові похідні Максвелла дозволяють вивести швидкість поширення звукових хвиль у середовищі. Швидкість звуку `cₛ` визначається адіабатичною стисливістю `κ⛥`:

```
cₛ² = (∂P / ∂ρ)⛛ = 1 / (ρ · κ⛥)
```

Оскільки `κ⛥ = κₜ / γ`, де `γ = Cₚ / Cᵥ`, зв'язок термодинамічних похідних Максвелла з ізотермічною стисливістю `κₜ` дає остаточний вираз для швидкості акустичних коливань:

```
c⛛ = √[ (γ / ρ) · (∂P / ∂ρ)ₜ ]
```

### 10. Паралелізм з класичною механікою: Гамільтоніан та Лагранжіан

Математичний формалізм перетворення Лежандра у термодинаміці є абсолютно точним аналогом канонічного формалізму у теоретичній механіці.

У класичній механіці стан системи описується функцією Лагранжа `L(q, q̇, t)`, де `q` — узагальнена координата, а `q̇` — узагальнена швидкість. Щоб перейти від швидкості `q̇` до узагальненого імпульсу `p`, виконують перетворення Лежандра за зміною `q̇`:

```
p = ∂L / ∂q̇
```

Трансформована функція називається **функцією Гамільтона** (Гамільтоніаном) `H(q, p, t)`:

```
H(q, p, t) = p · q̇(p) − L(q, q̇(p), t)
```

Обчислюючи диференціал Гамільтоніана `dH = q̇ dp − (∂L/∂q) dq − (∂L/∂t) dt`, отримуємо канонічні рівняння Гамільтона:

```
q̇ = ∂H / ∂p
ṗ = − ∂H / ∂q
```

Порівняємо це з термодинамікою:
- Перехід `L(q, q̇) → H(q, p)` у механіці тотожний переходу `U(S, V) → F(T, V)` у термодинаміці, де `S` відповідає координаті `q`, а температура `T = (∂U/∂S)ᵥ` — спряженому імпульсу `p`.
- Двоїстість термодинамічних потенціалів через перетворення Лежандра показує, що термодинаміка та гамільтонова механіка мають єдину симплектичну та геометричну природу.

### 11. Вищі часткові похідні теплоємностей

Застосовуючи теорему Шварца до других похідних потенціалів Гельмгольца `F(T, V)` та Гіббса `G(T, P)`, можна отримати співвідношення Максвелла для вищих похідних калоричних величин.

Диференціюємо теплоємність при сталому об'ємі `Cᵥ = T · (∂S / ∂T)ᵥ` за об'ємом `V`:

```
(∂Cᵥ / ∂V)ₜ = ∂/∂V [ T · (∂S / ∂T)ᵥ ]ₜ
           = T · ∂²S / (∂V ∂T)
           = T · ∂/∂T [ (∂S / ∂V)ₜ ]ᵥ
```

Підставляючи третє співвідношення Максвелла `(∂S / ∂V)ₜ = (∂P / ∂T)ᵥ`:

```
(∂Cᵥ / ∂V)ₜ = T · (∂²P / ∂T²)ᵥ
```

Аналогічно, диференціюючи ізобарну теплоємність `Cₚ = T · (∂S / ∂T)ₚ` за тиском `P`:

```
(∂Cₚ / ∂P)ₜ = ∂/∂P [ T · (∂S / ∂T)ₚ ]ₜ
           = T · ∂²S / (∂P ∂T)
           = T · ∂/∂T [ (∂S / ∂P)ₜ ]ₚ
```

Підставляючи четверте співвідношення Максвелла `(∂S / ∂P)ₜ = −(∂V / ∂T)ₚ`:

```
(∂Cₚ / ∂P)ₜ = − T · (∂²V / ∂T²)ₚ
```

Ці вищі тотожності Максвелла показують, як залежність теплоємності від тиску й об'єму виражається через другу температурну похідну об'єму та тиску. Вони активно використовуються у прикладній термодинаміці для побудови високоточних рівнянь стану речовин.

### 12. Точний розрахунок для фотонного газу (випромінювання чорного тіла)

Розглянемо рівноважне електромагнітне випромінювання (фотонний газ) в об'ємі `V` при температурі `T`. Густина енергії рівноважного випромінювання залежить лише від температури `u = u(T)`, тож внутрішня енергія дорівнює:

```
U(T, V) = V · u(T)
```

З електродинаміки Максвелла відомо, що тиск фотонного газу дорівнює одній третині густини енергії:

```
P(T) = u(T) / 3
```

Застосуємо третє співвідношення Максвелла `(∂U / ∂V)ₜ = T · (∂P / ∂T)ᵥ − P`. Обчислимо часткові похідні:

```
(∂U / ∂V)ₜ = u(T)
(∂P / ∂T)ᵥ = (1 / 3) · (du / dT)
```

Підставляємо їх у калоричне рівняння стану:

```
u(T) = T · [ (1 / 3) · (du / dT) ] − (u(T) / 3)
```

Переносимо `-u(T)/3` у ліву частину:

```
(4 / 3) · u(T) = (T / 3) · (du / dT)
```

Скорочуємо на `1/3` та розділяємо змінні:

```
4 · u(T) = T · (du / dT)  ⇒  du / u = 4 · (dT / T)
```

Інтегруючи це диференціальне рівняння:

```
ln(u) = 4 · ln(T) + const  ⇒  u(T) = a · T⁴
```

Цей строгий математичний результат описує **закон Стефана — Больцмана**. Він доводить, що співвідношення Максвелла дозволяють виводити точні закони випромінювання без розв'язання мікроскопічних рівнянь поля, спираючись виключно на математичну симетрію точних диференціалів.

### 13. Зведена таблиця перетворень Лежандра та співвідношень Максвелла

Для швидкого орієнтування зведемо основні параметри чотирьох термодинамічних потенціалів, їхній математичний зв'язок через перетворення Лежандра та відповідні рівняння Максвелла у єдину таблицю:

| Термодинамічний потенціал | Визначення через U | Природні змінні | Диференціал 1-форми | Похідні Максвелла |
| :--- | :--- | :--- | :--- | :--- |
| **Внутрішня енергія** `U(S, V)` | `U` (вихідний) | `S, V` | `dU = T dS − P dV` | `(∂T/∂V)⛥ = −(∂P/∂S)ᵥ` |
| **Ентальпія** `H(S, P)` | `H = U + P·V` | `S, P` | `dH = T dS + V dP` | `(∂T/∂P)⛥ = (∂V/∂S)ₚ` |
| **Вільна енергія Гельмгольца** `F(T, V)` | `F = U − T·S` | `T, V` | `dF = −S dT − P dV` | `(∂S/∂V)ₜ = (∂P/∂T)ᵥ` |
| **Енергія Гіббса** `G(T, P)` | `G = H − T·S` | `T, P` | `dG = −S dT + V dP` | `(∂S/∂P)ₜ = −(∂V/∂T)ₚ` |

Ця математична симетрія гарантує, що знання одного фундаментального потенціалу у своїх природних змінних дозволяє знайти всі макроскопічні та калоричні характеристики будь-якої фізичної системи.

Отже, математичний апарат точних диференціалів, перетворень Лежандра та Гессіанів не лише дає формули для заміни похідних, але й задає фундаментальні межі стійкості фізичних фаз матерії, швидкість звуку та калоричні характеристики реальних речовин.
