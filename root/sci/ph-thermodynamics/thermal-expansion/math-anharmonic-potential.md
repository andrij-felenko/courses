# 🧮 Математичний вивід ангармонічного потенціалу та параметра Ґрюнайзена

Класична та статистична термодинаміка доводять, що теплове розширення твердих тіл є прямим математичним наслідком асиметрії (ангармонізму) потенціалу міжатомної взаємодії. Нижче наведено послідовний вивід зміщення середньої координати частинки в асиметричній потенціальній ямі через метод збурень класичної статистичної механіки, а також термодинамічний вивід зв'язку коефіцієнта розширення з параметром Ґрюнайзена та фононним спектром кристала.

---

### 1. Теорія збурень для зміщення координати у потенційній ямі

Розглянемо двохатомну систему або одну частинку у потенціальному полі суміжних атомів ґратки. Позначимо відхилення міжатомної відстані від рівноважного значення `r₀` (що відповідає мінімуму потенціальної енергії при `T = 0 K`) як `x = r - r₀`.

Розкладемо потенціальну енергію `U(x)` у степеневий ряд Тейлора в околі точки мінімуму `x = 0`:

```
U(x) = U(0) + U'(0)·x + ½ U''(0)·x² + ⅙ U'''(0)·x³ + 1/24 U⁴(0)·x⁴ + ...
```

Оскільки `x = 0` є точкою мінімуму, маємо `U'(0) = 0`. Приймемо `U(0) = 0` за початок відліку енергії. Позначимо коефіцієнти розкладу:
- `c = U''(0) > 0` — гармонічна жорсткість зв'язку (квадратичний член);
- `g = - ⅙ U'''(0)` — кубічний коефіцієнт ангармонізму (асиметрія потенціалу);
- `f = 1/24 U⁴(0)` — квартечний коефіціент ангармонізму (м'якість/жорсткість при великих амплітудах).

Тоді потенціал набуває вигляду:

```
U(x) = ½ c x² - g x³ - f x⁴
```

Середнє значення координати `⟨x⟩` за канонічним розподілом Ґіббса визначається як статистичне середнє за всіма можливими мікростанами систем:

```
        ∫_{-∞}^{+∞} x · exp(- U(x) / (k_B · T)) dx
⟨x⟩ = ----------------------------------------------
        ∫_{-∞}^{+∞} exp(- U(x) / (k_B · T)) dx
```

При помірних температурах ангармонічні члени `g x³` та `f x⁴` значно менші за гармонічний член `½ c x²`. Розкладемо експоненту збурення у ряд Тейлора поблизу нульового наближення:

```
exp(- U(x) / (k_B T)) = exp(- c x² / (2 k_B T)) · exp((g x³ + f x⁴) / (k_B T))
                       ≈ exp(- c x² / (2 k_B T)) · [1 + (g x³ + f x⁴) / (k_B T) + ½ (g x³ / (k_B T))²]
```

Підставимо цей розклад у чисельник та знаменник виразу для `⟨x⟩`.

#### Обчислення чисельника

```
Чисельник = ∫_{-∞}^{+∞} x · exp(- c x² / (2 k_B T)) · [1 + g x³ / (k_B T) + f x⁴ / (k_B T)] dx
```

Розглянемо симетрію окремих інтегралів:
1. `∫_{-∞}^{+∞} x · exp(- c x² / (2 k_B T)) dx = 0` (інтеграл непарної функції `x` у симетричних межах);
2. `∫_{-∞}^{+∞} x · (f x⁴ / k_B T) · exp(- c x² / (2 k_B T)) dx = 0` (інтеграл непарної функції `x⁵`);
3. Головний ненульовий внесок дає кубічний член: `(g / (k_B T)) ∫_{-∞}^{+∞} x⁴ · exp(- c x² / (2 k_B T)) dx`.

Використаємо стандартний гауссів інтеграл четвертого степеня:

```
I₄ = ∫_{-∞}^{+∞} x⁴ · exp(- a x²) dx = (3 / (4 a²)) · √(π / a)
```

де `a = c / (2 k_B T)`.

Підставляючи `a` та `a² = c² / (4 k_B² T²)`:

```
I₄ = (3 / (4 · c² / (4 k_B² T²))) · √(2 π k_B T / c)
   = (3 k_B² T² / c²) · √(2 π k_B T / c)
```

Отже, чисельник у першому порядку теорії збурень дорівнює:

```
Чисельник = (g / (k_B T)) · (3 k_B² T² / c²) · √(2 π k_B T / c)
          = (3 g k_B T / c²) · √(2 π k_B T / c)
```

#### Обчислення знаменника (Статистична сума)

Знаменник являє собою конфігураційну статистичну суму `Z_conf`:

```
Z_conf = ∫_{-∞}^{+∞} exp(- c x² / (2 k_B T)) · [1 + g x³ / (k_B T) + f x⁴ / (k_B T)] dx
```

Інтеграл від непарного члена `g x³` дорівнює нулю. Член `f x⁴` дає малу поправку другого порядку `O(k_B T / c)`, якою у першому наближенні можна знехтувати:

```
Знаменник ≈ ∫_{-∞}^{+∞} exp(- c x² / (2 k_B T)) dx = √(2 π k_B T / c)
```

#### Остаточне співвідношення для зміщення

Ділячи чисельник на знаменник:

```
        (3 g k_B T / c²) · √(2 π k_B T / c)     3 g k_B T
⟨x⟩ = ------------------------------------- = -----------
              √(2 π k_B T / c)                    c²
```

### 2. Лінійний коефіцієнт теплового розширення

Згідно з макроскопічним означенням, лінійний коефіцієнт теплового розширення `α` дорівнює:

```
α = (1 / r₀) · (d⟨x⟩ / dT)
```

Підставляючи виведене значення `d⟨x⟩/dT = 3 g k_B / c²`:

```
        3 g k_B
α = -------------
       c² · r₀
```

**Фундаментальні висновки з отриманої формули:**
1. Якщо потенціал строго симетричний (гармонічний осцилятор), то `g = 0`, що означає `α = 0`. **У суто гармонічній решітці теплове розширення повністю відсутнє**, незалежно від температури та амплітуди коливань.
2. Коефіцієнт розширення `α` прямо пропорційний кубічному коефіцієнту ангармонізму `g`. Що асиметричніша потенціальна яма, то сильніше розширюється матеріал.
3. Коефіцієнт `α` обернено пропорційний квадрату жорсткості зв'язку `c²`. Матеріали з високим модулем пружності та високою енергією зв'язку (алмаз, вольфрам, кераміка) мають малі значення `α`.

### 3. Квантово-механічне розширення та поправка на енергію нульових коливань

У квантовій механіці середня енергія гармонічного осцилятора частотою `ω` визначається формулою Планка з урахуванням нульових коливань:

```
⟨E⟩_квант = ½ ℏ ω + ℏ ω / (exp(ℏ ω / (k_B T)) - 1)
```

Підставляючи середню квантову енергію `⟨E⟩_квант` замість класичного `k_B T` у вираз для середньої координати, отримуємо квантову формулу теплового розширення:

```
        3 g
⟨x⟩ = ------- · [ ½ ℏ ω + ℏ ω / (exp(ℏ ω / (k_B T)) - 1) ]
        c²
```

При абсолютному нулю температур (`T = 0 K`) середня енергія не перетворюється на нуль, а дорівнює енергії нульових коливань `E_0 = ½ ℏ ω`. Через це рівноважна відстань між атомами при `T = 0 K` виявляється більшою за абсолютний мінімум потенціальної ями `r_min` на величину квантового нульового розширення:

```
Δx_0 = (3 g ℏ ω) / (2 c²)
```

Цей ефект особливо відчутний для легких ізотопів (наприклад, у рідкому гелії та ізотопах водню `H₂` і `D₂`), де енергія нульових коливань порівнянна з глибиною потенціальної ями.

### 4. Термодинамічний вивід та параметр Ґрюнайзена

Розглянемо об'ємний коефіцієнт розширення `γ_V` з точки зору феноменологічної термодинаміки:

```
α_V = (1 / V) · (∂V / ∂T)_P
```

Використовуючи співвідношення між частковими похідними для трьох змінних `(∂V/∂T)_P · (∂T/∂P)_V · (∂P/∂V)_T = -1`, виразимо `α_V`:

```
α_V = - (1 / V) · (∂P / ∂V)_T · (∂P / ∂T)_V = K_T · (∂P / ∂T)_V
```

де `K_T = - (1 / V) · (∂V / ∂P)_T` — ізотермічна стисливість. Тоді:

```
        K_T      / ∂P \
α_V = ------- · | ---- |
         V       \ ∂T /_V
```

Зі співвідношень Максвелла для вільної енергії Гельмгольца `F(T, V)` відомо:

```
/ ∂P \     / ∂S \
| ---- | = | ---- |
\ ∂T /_V   \ ∂V /_T
```

У статистичній фізиці твердого тіла вільна енергія фононного газу виражається через суму по всіх нормальних модах коливань ґратки із частотами `ω_i(V)`:

```
F(T, V) = U_0(V) + ∑_i [ ½ ℏ ω_i(V) + k_B T · ln(1 - exp(- ℏ ω_i(V) / (k_B T))) ]
```

Тиск `P = - (∂F / ∂V)_T` містить фононний внесок. Введемо **модовий параметр Ґрюнайзена** `γ_i`, який характеризує зміну частоти `i`-ї моди при деформації об'єму кристала:

```
        V      d ω_i
γ_i = - --- · ------- = - d(ln ω_i) / d(ln V)
        ω_i     d V
```

Диференціюючи тиск по температурі при постійному об'ємі, отримуємо:

```
/ ∂P \     1             d ω_i
| ---- | = - · ∑_i γ_i · ------- · c_i(T)
\ ∂T /_V   V              d T
```

де `c_i(T) = ℏ ω_i · (∂n_i / ∂T)` — внесок `i`-ї моди у теплоємність.

Осереднений **параметр Ґрюнайзена кристала** `γ_G` визначається як зважене середнє модових параметрів:

```
        ∑_i (γ_i · c_i)
γ_G = ------------------
            C_v
```

де `C_v = ∑_i c_i` — повна ізохорна теплоємність кристала.

Підставляючи це значення у формулу для `α_V`, отримуємо співвідношення Ґрюнайзена:

```
        γ_G · C_v · K_T
α_V = -------------------
               V
```

або у зручній формі через модуль об'ємного стиснення `B_T = 1 / K_T`:

```
α_V · B_T · V = γ_G · C_v
```

### 5. Анізотропний тензор Ґрюнайзена у монокристалах

Для анізотропного кристала низької симетрії модовий параметр Ґрюнайзена узагальнюється до тензорної форми `γ_ij(m)` за компонентами деформації `ε_ij`:

```
γ_ij(m) = - (1 / ω_m) · (∂ ω_m / ∂ ε_ij)
```

Матричні коефіцієнти розширення `α_ij` зв'язані з тензором жорсткості `C_ijkl` та модовими параметрами співвідношенням:

```
α_ij = ∑_kl S_ijkl · (1/V) · ∑_m γ_kl(m) · c_m(T)
```

де `S_ijkl` — тензор податливості кристала (обернений до тензора пружності `C_ijkl`).

У шаруватих або ланцюжкових кристалах (графіт, `Se`, `Te`, монокристалічні полімери) модові параметри Ґрюнайзена `γ_k` для акустичних мод уздовж зв'язків можуть бути від'ємними (`γ_∥ < 0`), що пояснює макроскопічне стискання кристала вздовж жорстких осей при нагріванні.

### 6. Низькотемпературна границя (Закон Дебая)

За кубічним законом Дебая при низьких температурах (`T << Θ_D`, де `Θ_D` — температура Дебая) ізохорна теплоємність решітки пропорційна кубу температури:

```
C_v(T) = (12 π⁴ / 5) · N · k_B · (T / Θ_D)³
```

Оскільки параметр Ґрюнайзена `γ_G` та модуль стиснення `B_T` при `T → 0 K` виходять на температурне плато (константу), то з рівняння Ґрюнайзена випливає:

```
α_V(T) ∝ T³    при T → 0 K
```

Це доводить, що коефіцієнт теплового розширення будь-якого ізотропного кристала строго прямує до нуля при наближенні до абсолютного нуля:

```
lim_{T → 0} α_V(T) = 0
```

що узгоджується з третім засадом термодинаміки (теоремою Нернста).
