# 🧮 Математичний вивід термодинамічних наслідків теореми Нернста

Ця вставка містить строгі математичні виводи головних термодинамічних наслідків Третього закону термодинаміки (теореми Нернста та постулату Планка). Ми детально розбираємо чотири фундаментальні математичні результати: пряме зникнення теплоємностей при наближенні до абсолютного нуля, прямування до нуля коефіцієнтів теплового розширення та тиску, комбінаторний вивід залишкової ентропії кристалічного льоду за моделлю Полінга, а також строге доведення принципу недосяжності абсолютного нуля температур.

## 1. Доведення обов'язкового зникнення теплоємностей при T → 0 K

Розглянемо вираз для абсолютної ентропії макроскопічної системи при температурі `T` та сталому тиску `p` (або сталому об'ємі `V`). За першим і другим законами термодинаміки елементарна кількість теплоти `dQ`, надана системі при оберненому нагріванні, пов'язана з теплоємністю `C_p(T)` співвідношенням:

```
dQ = C_p(T) · dT
```

Зміна ентропії при нагріванні системи від абсолютного нуля `T = 0 K` до скінченної температури `T` описується інтегралом:

```
S(T) - S(0) = ∫_0^T (C_p(T') / T') dT'
```

Згідно з постулатом Планка, ентропія системи при `T = 0 K` є скінченною константою `S(0) = S_0` (і приймається рівною нулю для чистих кристалів). Отже, інтеграл у правій частині повинен бути математично збіжним на нижній межі `T' = 0`:

```
∫_0^T (C_p(T') / T') dT' < ∞
```

Проаналізуємо умови збіжності цього інтеграла. Розкладемо функцію теплоємності `C_p(T')` у степеневий ряд у правому околі точки `T' = 0`:

```
C_p(T') = A_0 + A_1 · (T')ⁿ + ...
```

де `A_0 = C_p(0)` — значення теплоємності при точному абсолютному нулю, `A_1` — коефіцієнт при першому ненульовому члені розкладу, а `n > 0` — показник степеня.

Підставимо цей розклад у підінтегральний вираз для ентропії:

```
C_p(T') / T' = A_0 / T' + A_1 · (T')ⁿ⁻¹ + ...
```

Проінтегруємо цей вираз доданок за доданком біля нижньої межі `T' → 0`:

```
∫_0^T (A_0 / T') dT' = A_0 · ln T' |₀ᵀ = A_0 · [ ln T - lim_{ε → 0} ln ε ]
```

Оскільки границя `lim_{ε → 0} ln ε = -∞`, цей інтеграл розходиться до нескінченності для будь-якого ненульового значення `A_0 ≠ 0`. Отже, єдиною умовою збіжності інтеграла ентропії та скінченності `S(0)` є строга рівність нулю першого члена розкладу:

```
A_0 = 0    =>    lim_{T → 0} C_p(T) = 0
```

Більше того, для збіжності другого доданку `∫ A_1 · (T')ⁿ⁻¹ dT' = [ A_1 / n ] · Tⁿ` показник степеня `n` у першому ненульовому доданку розкладу повинен бути суворо додатним (`n > 0`):

```
∫_0^T Tⁿ⁻¹ dT' = [ Tⁿ / n ]₀ᵀ < ∞    при n > 0
```

Аналогічне математичне доведення виконується для теплоємності при сталому об'ємі `C_v(T)`:

```
lim_{T → 0} C_v(T) = 0
```

### Порівняння з фізичними моделями теплоємності

Цей математичний результат є винятково важливим: він показує, що класичний закон Дюлонга — Пті (`C_v = 3R = const`), згідно з яким теплоємність твердого тіла не залежить від температури, принципово порушує Третій закон термодинаміки. Якби класичний закон виконувався при `T → 0`, ентропія будь-якого кристалу прямувала б до мінус нескінченності `S(T) ~ 3R · ln T → -∞`.

Квантові теорії повністю задовольняють доведену умову `n > 0`:
- **Модель Ейнштейна:** `C_v(T) ~ (1/T²) · exp(-ħω / (k_B · T)) → 0` (експоненційне згасання, `n → ∞`).
- **Модель Дебая для діелектриків:** `C_v(T) = A_Debye · T³ → 0` (`n = 3 > 0`).
- **Модель Зоммерфельда для електронів у металах:** `C_v(T) = γ_el · T → 0` (`n = 1 > 0`).

## 2. Вивід поведінки коефіцієнтів розширення та тиску через співвідношення Максвелла

Розглянемо термодинамічний потенціал Ґіббса `G(T, p) = H - T·S`. Його повний диференціал дорівнює:

```
dG = V · dp - S · dT
```

Оскільки `G(T, p)` є гладкою функцією стану, її друга мішана похідна не залежить від порядку диференціювання (теорема Шварца):

```
(∂ / ∂T) (∂G / ∂p)_T = (∂ / ∂p) (∂G / ∂T)_p
```

Підставляючи частинні похідні `(∂G / ∂p)_T = V` та `(∂G / ∂T)_p = -S`, отримуємо перше співвідношення Максвелла:

```
(∂V / ∂T)_p = -(∂S / ∂p)_T
```

За теоремою Нернста, при `T → 0 K` ентропія системи `S(0, p)` є універсальною константою `S_0` (або `0`), яка взагалі не залежить від тиску `p`:

```
lim_{T → 0} (∂S / ∂p)_T = 0
```

Підставляючи цю границю у співвідношення Максвелла, ми миттєво отримуємо:

```
lim_{T → 0} (∂V / ∂T)_p = 0
```

Ізобарний коефіцієнт об'ємного теплового розширення `α` визначається як відносна зміна об'єму при нагріванні на 1 Кельвін:

```
α = (1 / V) · (∂V / ∂T)_p
```

Оскільки об'єм кристалу `V(0, p) > 0` залишається скінченним і ненульовим при `T = 0 K`, маємо строге підтвердження:

```
lim_{T → 0} α(T) = 0
```

Аналогічно, розглянемо вільну енергію Гельмгольца `F(T, V) = U - T·S`, повний диференціал якої дорівнює `dF = -p · dV - S · dT`. 

Друге співвідношення Максвелла дає:

```
(∂p / ∂T)_V = (∂S / ∂V)_T
```

Оскільки ентропія при `T → 0 K` є константою і не залежить від об'єму `(∂S / ∂V)_T → 0`, ми отримуємо зникнення термічного коефіцієнта тиску `γ`:

```
lim_{T → 0} (∂p / ∂T)_V = 0
```

### Узагальнення для магнітних та електричних систем

Аналогічні термодинамічні співвідношення виконуються для магнітних та електричних векторних параметрів стану:
- Для намагнічуваності `M` у магнітному полі `H` співвідношення Максвелла `(∂M / ∂T)_H = (∂S / ∂H)_T` разом з теоремою Нернста `(∂S / ∂H)_T → 0` дає:
  ```
  lim_{T → 0} (∂M / ∂T)_H = 0
  ```
- Для електричної поляризації `P` у полі `E` співвідношення `(∂P / ∂T)_E = (∂S / ∂E)_T` дає:
  ```
  lim_{T → 0} (∂P / ∂T)_E = 0
  ```

Це означає, що при наближенні до absolute нуля макроскопічна намагнічуваність та дипольна поляризація речовини припиняють змінюватися під впливом теплових коливань.

## 3. Комбінаторний вивід залишкової ентропії льоду за Полінгом

Для більшості речовин при `T = 0 K` ентропія є строго нульовою (`S_0 = 0`). Проте у кристалічному льоді `H₂O` експериментально спостерігається залишкова ентропія `S_0 ≈ 3.41 Дж/(моль·К)`. Лауреат Нобелівської премії Лайнус Полінг у 1935 році дав комбінаторне пояснення цьому явищу на основі квантово-хімічних правил Бернала — Фаулера.

Розглянемо моль кристалічного льоду (фаза I_h), що містить `N` атомів Оксигену та `2N` атомів Гідрогену (протонів).

### Правила Бернала — Фаулера:
1. Атоми Оксигену утворюють тетраедричну кристалічну решітку, де кожен атом O з'єднаний водневими зв'язками з 4 сусідніми атомами O.
2. На кожному з `2N` водневих зв'язків знаходиться рівно один протон `H`. На зв'язку є 2 симетричні потенціальні ями (ближче до лівого або праворуч атому O).
3. Біля кожного атому Оксигену знаходиться **рівно 2 ближніх (ковалентно зв'язаних) протони**, що утворюють нейстральну молекулу `H₂O`.

### Математичний вивід кількості мікростанів:

Кількість водневих зв'язків у кристалі з `N` атомів Оксигену дорівнює:

```
N_bonds = (4 · N) / 2 = 2N
```

Якби розташування протонів на зв'язках не обмежувалося правилом 3, то загальна кількість можливих просторових конфігурацій протонів була б дорівнювала:

```
Ω_raw = 2^(2N) = 4ᴺ
```

Тепер врахуємо суворе правило 3 для кожного з `N` атомів Оксигену. Навколо одного центрального атома Оксигену знаходиться 4 водневих зв'язки. Загальна кількість способів довільно розмістити 4 протони на 4 зв'язках дорівнює `2⁴ = 16`.

З цих 16 конфігурацій фізично допустимими (відповідно до молекули `H₂O`) є лише ті, де біля Оксигену знаходиться *рівно 2 протони*. Кількість таких варіантів визначається числом комбінацій з 4 по 2:

```
C₄² = 4! / (2! · 2!) = (4 · 3) / 2 = 6
```

Отже, імовірність того, що випадково обраний вузол Оксигену випадково задовольняє правилу молекули `H₂O`, дорівнює відношенню:

```
p_valid = 6 / 16 = 3 / 8
```

У наближенні незалежних вузлів сукупна імовірність того, що всі `N` вузлів кристалу одночасно задовольняють правилу `H₂O`, становить `(p_valid)ᴺ = (3/8)ᴺ`.

Загальна кількість допустимих рівноважних мікростанів кристалу `Ω` становить:

```
Ω = Ω_raw · (p_valid)ᴺ = 4ᴺ · (3 / 8)ᴺ = (4 · 3 / 8)ᴺ = (12 / 8)ᴺ = (3 / 2)ᴺ
```

Використовуючи формулу Больцмана `S = k_B · ln Ω`, обчислимо залишкову молярну ентропію для `N = N_A` (число Авогадро):

```
S_0 = k_B · ln [ (3 / 2)ᴺ_A ] = N_A · k_B · ln(3 / 2) = R · ln(1.5)
```

Підставимо значення газової сталої `R = 8.31446 Дж/(моль·К)`:

```
S_0 = 8.31446 · ln(1.5) = 8.31446 · 0.405465 ≈ 3.371 Дж/(моль·К)
```

Точніші математичні розрахунки методом матриць передачі (рядкові розклади Наґла 1966 року) дають `S_0^exact = 3.41 Дж/(моль·К)`, що з ідеальною точністю збігається з експериментальним калориметричним значенням `3.41 ± 0.05 Дж/(моль·К)`.

## 4. Математичне доведення принципу недосяжності абсолютного нуля

Принцип недосяжності стверджує, що неможливо охолодити систему до точного значення `T = 0 K` за скінченне число термодинамічних кроків.

Розглянемо процес охолодження методом адіабатичного розмагнічування. Нехай параметр керування (зовнішнє магнітне поле) змінюється між двома значеннями `B_1` та `B_2` (де `B_2 > B_1`).

Охолодження складається з послідовності двох типів процесу:
1. **Ізотермічна зміна поля** `B_1 → B_2` при температурі `T_k`: ентропія системи зменшується від `S(T_k, B_1)` до `S(T_k, B_2)`.
2. **Адіабатичне розмагнічування** `B_2 → B_1`: ентропія залишається сталою `S = const`, а температура системи знижується від `T_k` до `T_{k+1}`.

Рівняння адіабатичного кроку має вигляд:

```
S(T_{k+1}, B_1) = S(T_k, B_2)
```

Розкладемо ентропію `S(T, B)` у степеневий ряд поблизу `T = 0 K`. Для низьких температур теплоємність спінової системи підпорядковується степеневому закону `C(T, B) = a(B) · Tᵐ` (де `m ≥ 1`).

Тоді ентропія дорівнює:

```
S(T, B) = S_0 + ∫_0^T (a(B) · (T')ᵐ / T') dT' = S_0 + [ a(B) / m ] · Tᵐ
```

За теоремою Нернста константа `S_0` є однаковою для обох полів `B_1` та `B_2`. Підставимо цей вираз у рівняння адіабатичного кроку:

```
S_0 + [ a(B_1) / m ] · (T_{k+1})ᵐ = S_0 + [ a(B_2) / m ] · (T_k)ᵐ
```

Скорочуємо однакову константу `S_0` з обох боків рівняння та множимо на `m`:

```
a(B_1) · (T_{k+1})ᵐ = a(B_2) · (T_k)ᵐ
```

Звідси знаходимо співвідношення між температурами на двох послідовних кроках:

```
T_{k+1} = [ a(B_2) / a(B_1) ]^(1/m) · T_k
```

Позначимо константу згасання як `q = [ a(B_2) / a(B_1) ]^(1/m) < 1`. Оскільки `a(B_2) < a(B_1)` через орієнтаційне впорядкування спінів у полі `B_2`, ми отримуємо нескінченну спадну геометричну прогресію:

```
T_N = T_0 · qᴺ
```

Знайдемо кількість кроків `N`, необхідну для досягнення бажаної температури `T_N`:

```
N = [ ln(T_N / T_0) ] / ln q
```

Щоб досягти точної температури `T_N = 0 K`, необхідно знайти границю `N` при `T_N → 0`:

```
lim_{T_N → 0} N = lim_{T_N → 0} [ ln(T_N / T_0) / ln q ] = -∞ / ln q = +∞
```

Отже, кількість термодинамічних циклів `N`, необхідних для досягнення абсолютної температури `T = 0 K`, є нескінченною (`N = ∞`). Це складає строге математичне доведення принципу недосяжності абсолютного нуля.
