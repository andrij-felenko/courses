# 📜 Історія відкриття третього закону: від хімічної спорідненості до квантового стану

На межі XIX та XX століть фізична хімія зіткнулася з принциповим розривом між чистою термодинамікою та хімічною практикою. Перший і Другий закони термодинаміки дозволяли обчисляти зміну ентропії `ΔS` у будь-якому процесі через теплові ефекти, проте вони залишали абсолютне значення ентропії неозначеним. У класичному формулюванні Рудольфа Клаузіуса ентропія визначалася лише з точністю до довільної константи інтегрування `S_0`.

Для класичної механіки або теплотехніки це не становило проблеми, адже в більшості фізичних процесів (нагрівання, розширення газу, виконання механічної роботи) вимірюються лише різниці ентропій між двома станами. Однак у хімії ця довільність мала катастрофічні наслідки: вона унеможливлювала теоретичний розрахунок хімічної рівноваги без проведення складних і дороговартісних вимірювань для кожної конкретної реакції.

## 1. Проблема хімічної спорідненості у хімії XIX століття

У середині XIX століття французький хімік Марселлен Бертло та данський дослідник Юліус Томсен висунули термохімічний принцип, згідно з яким усяка хімічна реакція самочинно перебігає у напрямку найбільшого виділення тепла. Цей принцип отримав назву «принципу максимальної роботи Бертло — Томсона». Згідно з ним, мірою хімічної спорідненості вважали тепловий ефект реакції `ΔH`.

Проте наприкінці XIX століття було відкрито численні ендотермічні реакції (реакції, що перебігають із поглинанням тепла при кімнатній температурі), що повністю спростувало гіпотезу Бертло. 

Центральною задачею фізичної хімії стало створення математичної теорії, здатної передбачати напрямок хімічних реакцій та точку рівноваги за будь-яких умов. За термодинамікою Германа фон Ґельмгольца та Джозайї Вілларда Ґіббса, справжньою мірою хімічної спорідненості (здібності речовин вступати в реакцію) є максимальна корисна робота, яку може виконати система в ізотермічно-ізобарному процесі. Ця величина дорівнює зміні вільної енергії Ґіббса:

```
ΔG = ΔH - T·ΔS
```

Тут `ΔH` — тепловий ефект реакції (зміна ентальпії при сталому тиску), а `ΔS` — зміна ентропії. 

Якоб Гендрік вант-Гофф показав, що константа хімічної рівноваги `K_p` безпосередньо пов'язана з вільною енергією Ґіббса:

```
ΔG = -R·T·ln K_p
```

Щоб обчислити `K_p` при довільній температурі `T`, необхідно знати `ΔG(T)`. Диференціювання рівняння Ґельмгольца за температурою дає фундаментальне співвідношення Ґіббса — Ґельмгольца:

```
ΔG = ΔH + T·(∂ΔG / ∂T)_p
```

Порівнюючи це з визначенням `ΔG = ΔH - T·ΔS`, отримуємо фундаментальний зв'язок між зміною ентропії та температурним коефіцієнтом вільної енергії:

```
(∂ΔG / ∂T)_p = -ΔS
```

Інтегрування цього рівняння для знаходження `ΔG(T)` вимагає знання константи інтегрування. Хіміки могли легко виміряти тепловий ефект реакції `ΔH` за допомогою калориметра при одній температурі, але не мали жодного теоретичного шляху для обчислення `ΔS` без прямих вимірювань рівноваги при різних температурах. Потрібен був новий фундаментальний принцип, який зафіксував би константу інтегрування.

## 2. Прорив Вальтера Нернста (1905–1906)

У 1905 році німецький фізико-хімік Вальтер Нернст (Walther Nernst), працюючи в Фізико-хімічному інституті Берлінського університету, звернув увагу на емпіричні дані про реакції в конденсованих фазах (твердих тілах та рідинах) при низьких температурах.

Для проведення досліджень Нернст заснував у Берліні сучасну кріогенну лабораторію, обладнану ожижнювачами водню та азоту, а також розробив високоточні платинові термометри опору.

Нернст проаналізував графіки залежності `ΔG(T)` та `ΔH(T)` від температури. При високих температурах ці дві криві суттєво розходяться через член `T·ΔS`. Проте при зниженні температури `T → 0 K` виявилося, що вони не просто прямують до однієї точки (бо `T·ΔS → 0` при `T → 0` для будь-якого скінченного `ΔS`), а наближаються одна до одної асимптотично: вони торкаються одна одної під нульовим кутом.

Це означало, що похідні обох функцій за температурою прямують до нуля при наближенні до абсолютного нуля:

```
lim (∂ΔG / ∂T)_p = lim (∂ΔH / ∂T)_p = 0    при T → 0 K
```

Оскільки `(∂ΔG / ∂T)_p = -ΔS`, Нернст сформулював своє знамените гіпотетичне припущення, яке отримало назву **Теплова теорема Нернста** (опублікована в грудні 1905 року та детально представлена у доповіді перед Королівським науковим товариством у Ґеттінгені у 1906 році):

> *Зміна ентропії `ΔS` у будь-якій ізотермічній оберненій фізико-хімічній трансформації конденсату наближається до нуля при наближенні абсолютної температури до нуля.*

```
lim ΔS = 0    при T → 0 K
```

Це було видатне відкриття. Воно означало, що ізотерми та адіабати на `S-T` діаграмі зливаються при `T = 0 K`. Тепер константа інтегрування для ентропії реакції ставала нульовою, і хіміки отримали можливість обчисляти хімічні рівноваги суто з калориметричних вимірювань теплоємностей та теплових ефектів реакцій.

## 3. Узагальнення Макса Планка та абсолютна ентропія (1911)

Нернст сформулював теорему для *зміни* ентропії `ΔS = S_2 - S_1` під час хімічних реакцій або фазових переходів у конденсованих системах. Видатний німецький фізик-теоретик Макс Планк у 1911 році зробив наступний радикальний крок.

Планк запропонував, що якщо зміна ентропії `ΔS` для будь-якого процесу між рівноважними станами прямує до нуля при `T → 0 K`, це означає, що ентропія *кожної окремої* чистої конденсованої речовини прямує до однієї й тієї самої універсальної константи `S_0`.

Планк запропонував покласти цю універсальну константу рівною нулю для всіх хімічно однорідних чистих речовин у досконалому кристалічному стані:

```
lim S(T) = 0    при T → 0 K
```

Це формулювання стало відомим як **Постулат Планка** або сучасне формулювання **Третього закону термодинаміки**. Завдяки Планку ентропія перетворилася з відносної величини на абсолютну фізичну характеристику стану речовини.

## 4. Квантовий контекст і роль Альберта Ейнштейна

Відкриття теореми Нернста відбувалося паралельно з народженням квантової фізики. У класичній термодинаміці теорема Нернста здавалася штучною домішкою. Більше того, класична фізика прямо суперечила теоремі Нернста: за законом рівнорозподілу Ейнштейна — Больцмана теплоємність ідеального газу чи твердого тіла (закон Дюлонга — Пті `C_v = 3R`) залишається сталою аж до `T = 0 K`.

Якби теплоємність `C_v` була сталою при `T → 0 K`, то ентропія прямувала б до мінус нескінченності:

```
S(T) = ∫ (C_v / T') dT' = C_v · ln T → -∞    при T → 0 K
```

Це виявило глибоку кризу класичної фізики. Нернст швидко зрозумів: його теорема виконується лише тоді, коли теплоємності речовин `C_v` та `C_p` самі прямують до нуля при `T → 0 K`.

У 1907 році Альберт Ейнштейн опублікував свою квантову теорію теплоємності твердого тіла, де вперше застосував квантову гіпотезу Планка до коливань атомів у кристалічній ґратці. Ейнштейн довів, що квантування енергії осциляторів примушує теплоємність експоненційно згасати до нуля при низьких температурах:

```
C_v(T) → 0    при T → 0 K
```

Це було першим блискучим підтвердженням того, що Третій закон термодинаміки є прямим макроскопічним проявом квантової природи нашого світу. Потім у 1912 році Петер Дебай уточнив теорію Ейнштейна, вивівши знаменитий закон кубів Дебая (`C_v ~ T³`), який ідеально узгоджувався з вимірюваннями Нернста при наднизьких температурах.

## 5. Сольвеївський конгрес 1911 року, формулювання Саймона та Нобелівська премія

У жовтні 1911 року в Брюсселі відбувся Перший Сольвеївський конгрес, організований за ініціативи та активної участі Вальтера Нернста та промисловця Ернеста Сольве. Темою конгресу була «Теорія випромінювання та кванти». На цій історичній зустрічі Нернст, Планк, Ейнштейн, Лоренц, Пуанкаре та Марія Кюрі обговорювали фундаментальний зв'язок між теоремою Нернста, квантуванням енергії та теплоємностями при низьких температурах.

У 1930-х роках британсько-німецький фізик Френсіс Саймон (Francis Simon) запропонував уточнене формулювання Третього закону, яке явним чином враховувало умову термодинамічної рівноваги, пояснивши залишкову ентропію у склі та заморожених розчинах.

За обґрунтування теплової теореми та проведення надточних кріогенних вимірювань теплоємностей Вальтер Нернст у 1920 році був удостоєний **Нобелівської премії з хімії** з формулюванням: *«На знак визнання його праць з термодинаміки»*.

Сьогодні Третій закон термодинаміки стоїть в одному ряду з Першим та Другим законами, утворюючи фундамент сучасної хімічної термодинаміки, кріогенної фізики та квантової статистичної механіки.
