# 📋 Довідник термодинамічних потенціалів та співвідношень хімічного потенціалу

Цей довідник містить систематизоване зведення фундаментальних співвідношень термодинамічних потенціалів, математичні вирази хімічного потенціалу `μ` для різних агрегатних станів речовини (ідеальні та реальні гази, ідеальні й неідеальні розчини, розчини електролітів, квантові системи та напівпровідники), а також довідкові таблиці стандартних термодинамічних величин для практичних інженерних та термодинамічних розрахунків.

---

### 1. Фундаментальні термодинамічні потенціали та часткові похідні

Усі п'ять основних термодинамічних потенціалів зв'язані з хімічним потенціалом `μ_i` через часткові похідні відповідних потенціалів по числу частинок або кількості молей `N_i` при фіксованих природних змінних. Хімічний потенціал характеризує інтенсивність зміни відповідної енергетичної функції при додаванні одного моля або однієї частинки `i`-го компонента у відкриту термодинамічну систему.

| Потенціал | Символ | Природні змінні | Повний диференціал | Часткова похідна для `μ_i` |
| :--- | :--- | :--- | :--- | :--- |
| **Внутрішня енергія** | `U` | `S, V, {N_i}` | `dU = T·dS - P·dV + ∑ μ_i·dN_i` | `μ_i = (∂U / ∂N_i)_(S, V, N_j≠i)` |
| **Вільна енергія Гельмгольца** | `F` | `T, V, {N_i}` | `dF = -S·dT - P·dV + ∑ μ_i·dN_i` | `μ_i = (∂F / ∂N_i)_(T, V, N_j≠i)` |
| **Енергія Гіббса** | `G` | `T, P, {N_i}` | `dG = -S·dT + V·dP + ∑ μ_i·dN_i` | `μ_i = (∂G / ∂N_i)_(T, P, N_j≠i)` |
| **Ентальпія** | `H` | `S, P, {N_i}` | `dH = T·dS + V·dP + ∑ μ_i·dN_i` | `μ_i = (∂H / ∂N_i)_(S, P, N_j≠i)` |
| **Великий потенціал (Омега)** | `Ω` | `T, V, {μ_i}` | `dΩ = -S·dT - P·dV - ∑ N_i·dμ_i` | `N_i = -(∂Ω / ∂μ_i)_(T, V, μ_j≠i)` |

#### Фундаментальні термодинамічні тотожності та правила використання:
- **Однокомпонентна система:** Енергія Гіббса є аддитивною функцією кількості речовини: `G(T, P, N) = N · μ(T, P)`, звідки випливає, що хімічний потенціал однокомпонентної системи дорівнює молярній (або питомій) вільній енергії Гіббса: `μ = G / N = g(T, P)`.
- **Рівняння Гіббса — Дугема:** Зв'язує інтенсивні параметри системи: `S·dT - V·dP + ∑ N_i·dμ_i = 0`. В ізобарно-ізотермічних умовах (`dT = 0`, `dP = 0`) зміна хімічних потенціалів компонентів обмежена рівністю: `∑ N_i·dμ_i = 0`.
- **Зв'язок із ентропією:** У мікроканонічному ансамблі хімічний потенціал визначається через похідну ентропії при сталій енергії та об'ємі: `μ = -T · (∂S / ∂N)_(U, V)`.
- **Співвідношення Максвелла:** `(∂μ_i / ∂P)_(T, {N}) = V_i⁻` (парціальний молярний об'єм), `(∂μ_i / ∂T)_(P, {N}) = -S_i⁻` (парціальна молярна ентропія).

Математична еквівалентність усіх цих визначень випливає з перетворень Лежандра. Вибір конкретної формули залежить від того, які макроскопічні параметри системи підтримуються сталими в експерименті: для процесів у жорсткій герметичній судині вибирають функцію Гельмгольца `F`, для відкритих лабораторних судин при атмосферному тиску — потенціал Гіббса `G`, а для теоретичного опису квантових заповнень у великому ансамблі — великий потенціал `Ω`.

### 2. Хімічний потенціал за середовищами та станами речовини

Залежно від фізико-хімічної природи середовища хімічний потенціал складається зі стандартного значення `μ°` (що відповідає обраному стандартному стану) та поправкових членів, що враховують концентрацію, тиск або міжмолекулярні взаємодії.

| Середовище / Модель | Формула хімічного потенціалу `μ_i` | Пояснення параметрів |
| :--- | :--- | :--- |
| **Ідеальний газ (за тиском)** | `μ_i(T, P_i) = μ_i°(T) + k_B·T · ln(P_i / P°)` | `P_i` — парціальний тиск, `P° = 101325` Па |
| **Ідеальний газ (за густиною)** | `μ_i(T, n_i) = k_B·T · ln(n_i · λ_{dB, i}³)` | `n_i = N_i / V`, `λ_dB` — довжина хвилі де Бройля |
| **Реальний газ (леткість)** | `μ_i(T, P_i) = μ_i°(T) + k_B·T · ln(f_i / P°)` | `f_i = φ_i · P_i`, `φ_i` — коефіцієнт леткості (*fugacity*) |
| **Ідеальний розчин** | `μ_i(T, P, x_i) = μ_i*(T, P) + k_B·T · ln(x_i)` | `x_i = N_i / N_{tot}` — мольна частка, `μ_i*` — чистий компонент |
| **Реальний розчин (активність)** | `μ_i(T, P, a_i) = μ_i*(T, P) + k_B·T · ln(a_i)` | `a_i = γ_i · x_i`, `γ_i` — коефіцієнт активності |
| **Розведений розчин (Закон Генрі)** | `μ_i(T, P, m_i) = μ_i,m°(T, P) + k_B·T · ln(m_i / m°)` | `m_i` — моляльність (моль/кг), `m° = 1` моль/кг |
| **Електроліт в електричному полі** | `μ_{el, i} = μ_i + z_i · e · Φ` | `z_i` — валентність іона, `e` — заряд, `Φ` — потенціал |

#### Моделювання коефіцієнтів активності та леткості:
1. Для реальних газів коефіцієнт леткості `φ_i` виражається через рівняння стану реального газу (наприклад, рівняння Ван дер Ваальса або Редліха — Квонга):
   ```
   ln φ_i = ∫₀^P [ (V_m, i / (R·T)) - 1 / P ] dP
   ```
2. Для розчинів електролітів середній іонний коефіцієнт активності `γ_±` у межевому законі Дебая — Хюккеля для розведених розчинів обчислюється через іонну силу розчину `I = (1/2) · ∑ c_i · z_i²`:
   ```
   ln γ_± = -A · |z_+ · z_-| · √I
   ```
   де `A ≈ 1.172` (кг/моль)¹⁺² для води при 298.15 К.
3. Для бінарних неідеальних розчинів коефіцієнти активності описуються двопараметричною моделлю Маргулеса:
   ```
   ln γ_1 = [ A_12 + 2·(A_21 - A_12)·x_1 ] · x_2²
   ln γ_2 = [ A_21 + 2·(A_12 - A_21)·x_2 ] · x_1²
   ```
4. Для сильних розчинів електролітів у широкому діапазоні концентрацій використовують розширене рівняння Пітцера, яке враховує парні та трійчасті іонні зіткнення у розчиннику.

Стандартний стан вибирається залежно від агрегатного стану: для газів — гіпотетичний ідеальний газ при тиску 1 бар; для розчинників — чистий розчинник при тій самій температурі і тиску (`x_i = 1`); для розчинених речовин — гіпотетичний розчин з моляльністю 1 моль/кг, що поводиться як нескінченно розведений.

### 3. Квантові гази та напівпровідники

У квантових системах хімічний потенціал визначається статистикою квантових частинок і виникає безпосередньо з нормування функції розподілу на загальну кількість частинок.

#### 3.1. Фермі-газ (електрони в металах)
- **При `T = 0 K`:** Хімічний потенціал досягає максимального значення і дорівнює енергії Фермі: `μ(0) = E_F = (ℏ² / (2·m*)) · (3·π² · n)²⁺³`.
- **При `0 < k_B·T << E_F` (розклад Зоммерфельда):**
  ```
  μ(T) = E_F · [ 1 - (π² / 12) · (k_B·T / E_F)² - (π⁴ / 80) · (k_B·T / E_F)⁴ + ... ]
  ```
- **Температура Фермі:** `T_F = E_F / k_B`. Для міді (`E_F = 7.0` ев): `T_F ≈ 81 200` К.

#### 3.2. Бозе-газ (бозони)
- **Фундаментальне обмеження:** `μ ≤ 0` завжди (для забезпечення додатності чисел заповнення `n(ε) ≥ 0`).
- **При `T > T_c`:** `μ(T) < 0`, визначається з рівняння `n · λ_dB³ = Li₃⁺₂(exp(μ / (k_B·T)))`.
- **При `T ≤ T_c` (конденсат Бозе — Ейнштейна):** `μ = 0`.
- **Критична температура БКЕ:**
  ```
  T_c = (h² / (2·π·m·k_B)) · (n / 2.612)²⁺³
  ```

#### 3.3. Напівпровідники (рівень Фермі `E_F ≡ μ`)
- **Власний напівпровідник:**
  ```
  μ_i = E_v + E_g / 2 + (3/4) · k_B·T · ln(m_h* / m_e*)
  ```
  де `E_v` — верх валентної зони, `E_g` — ширина забороненої зони, `m_e*`, `m_h*` — ефективні маси електронів та дірок.
- **Легований n-тип (концентрація донорів `N_d`):** `μ = μ_i + k_B·T · ln(N_d / n_i)`.
- **Легований p-тип (концентрація акцепторів `N_a`):** `μ = μ_i - k_B·T · ln(N_a / n_i)`.

### 4. Електрохімія та гальванічні елементи

У хімічних джерелах струму (літій-іонних акумуляторах, паливних елементах та гальванічних комірках) різниця хімічних потенціалів реагентів і продуктів перетворюється на електричну роботу.

#### Основні вирази електрохімії:
- **Електрохімічний потенціал:** `μ_{el, i} = μ_i° + R·T · ln a_i + z_i · F · Φ`.
- **Умова електрохімічної рівноваги на межі фаз:** `Δμ_{el} = 0`.
- **Електрорушійна сила (ЕРС) елемента `E_{emf}`:**
  ```
  E_{emf} = -ΔG_r / (z · F) = - (∑ ν_i · μ_i) / (z · F)
  ```
- **Рівняння Нернста для відновного потенціалу електрода:**
  ```
  E = E° - (R·T / (z·F)) · ln(a_red / a_ox)
  ```
- **Фундаментальні електрохімічні константи:**
  - Постійна Фарадея: `F = N_A · e = 96485.3321` Кл/моль.
  - Термічний потенціал при 298.15 К: `R·T / F = 0.02569` В (`k_B·T / e = 25.69` мВ).
  - Нахил Нернста для десятичного логарифма при 298.15 К: `2.3026 · R·T / F = 0.05916` В/декаду.

Рівноважний стан електрохімічного кола виникає тоді, коли електричне поле компенсує відмінність вільних хімічних потенціалів іонів між електродом та електролітом. У кінетиці електродних процесів швидкість розряду іонів описується рівнянням Батлера — Фольмера.

### 6. Умови фазової та хімічної рівноваги

1. **Фазова рівновага k компонентів у m фазах:**
   Для досягнення повної фазової рівноваги необхідно виконання трьох умов: рівність температур `T_1 = T_2 = ... = T_m`, рівність тисків `P_1 = P_2 = ... = P_m` та рівність хімічних потенціалів кожного компонента в усіх фазах:
   ```
   μ_i^{(1)}(T, P) = μ_i^{(2)}(T, P) = ... = μ_i^{(m)}(T, P),   i = 1, 2, ..., k
   ```
   - **Правило фаз Гіббса:** Число незалежних інтенсивних змінних (ступенів вільності) дорівнює:
     ```
     f = k - m + 2
     ```
     де `k` — число незалежних хімічних компонентів, `m` — число співіснуючих фаз.

2. **Хімічна рівновага оборотній реакції вида `∑ ν_i · A_i = 0`:**
   Умовою хімічної рівноваги є рівність нулю алгебраїчної суми хімічних потенціалів з урахуванням стехіометричних коефіцієнтів `ν_i` (для реагентів `ν_i < 0`, для продуктів `ν_i > 0`):
   ```
   ∑ ν_i · μ_i = 0
   ```
   - **Зв'язок між хімічними потенціалами та константою рівноваги `K_p(T)`:**
     ```
     ΔG_r° = ∑ ν_i · μ_i° = -R·T · ln K_p
     K_p(T) = exp(-ΔG_r° / (R·T))
     ```
   - **Рівняння Вант-Гоффа для температурної залежності `K_p`:**
     ```
     d(ln K_p) / dT = ΔH_r° / (R · T²)
     ```
