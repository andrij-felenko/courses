# ⚙️ Чисельне моделювання бозе-конденсату та температурної залежності макроскопічних параметрів

Ця вставка містить детальний алгоритм, чисельні методи та закінчену розрахункову програму на мові Python для розрахунку термодинамічних характеристик ідеального та слабковзаємодіючого бозе-газу, чисельного розв'язання нелінійного рівняння для хімічного потенціалу, знаходження частки бозе-конденсату, розрахунку просторового розподілу густини у магніто-оптичній пастці та моделювання розльоту атомарного хмари при вимкненні пастки (time-of-flight imaging).

## 1. Фізична модель та розрахункова методика

Чисельне моделювання квантового бозе-газу вимагає розв'язання нелінійного рівняння балансу кількості частинок відносно хімічного потенціалу `μ`:

```
N = N_0 + ∑_{k > 0} 1 / [ exp((ε_k - μ) / (k_B · T)) - 1 ]
```

Для макроскопічної системи у тривимірній потенціальній ямі з жорсткими стінками (модель однорідного газу в об'ємі `V`) сума за збудженими станами замінюється інтегралом за допомогою полілогарифмів `g_{3/2}(z)`. Для систем у магнітно-оптичних пастках з анізотропним гармонічним потенціалом `V(r) = (m/2)·(ω_x² x² + ω_y² y² + ω_z² z²)` густина станів має вигляд `g(ε) = ε² / (2 · (ħ ω̄)³)` (де `ω̄ = (ω_x ω_y ω_z)¹ᐟ³`), що змінює показник ступеня у залежності критичної температури від `T³ᐟ²` на `T³`.

Програма реалізує чотири ключові обчислювальні модулі:
1. **Модуль спецфункцій:** Точне обчислення полілогарифмів Бозе — Ейнштейна (`g_{3/2}(z)` та `g_{5/2}(z)`) через швидкозбіжні степеневі ряди з адаптивним контролем точності.
2. **Модуль нелінійного розв'язувача:** Знаходження хімічного потенціалу `μ(T)` методом бісекції (ділення навпіл інтервалу фугітивності `z ∈ (0, 1)`) для високотемпературної та виродженої фази `T > T_c`.
3. **Модуль термодинамічних профілів:** Обчислення частки бозе-конденсату `N_0 / N` та безрозмірної теплоємності `C_V / (N k_B)` для однорідного газу й пасткового потенціалу.
4. **Модуль просторового розподілу:** Розрахунок двокомпонентного профілю густини (двошарова модель «конденсат + теплова хмара») у наближенні Томаса — Фермі для взаємодіючого газу.

## 2. Алгоритм розрахунку профілів густини та методу time-of-flight

У реальних експериментах основними спостережуваними величинами є не абстрактні числові статсуми, а розподіл густини атомів, який вимірюють за допомогою оптичного поглинання тінні від лазерного променя.

### Просторовий профіль Томаса — Фермі

Для слабковзаємодіючого бозе-конденсату при `T → 0` кінетичним членом тиску в рівнянні Гросса — Пітаєвського можна знехтувати у порівнянні з енергією відштовхування `g |Ψ|²`. Це називається наближенням Томаса — Фермі. Профіль густини бозе-конденсату `n_0(r)` має характерний інвертований параболічний профіль:

```
n_0(r) = max( 0, (μ - V_{ext}(r)) / g )
```

де `g = 4π ħ² a_s / m` — константа контактної взаємодії (`a_s` — s-хвильова довжина розсіяння), а радіуси Томаса — Фермі уздовж осей задаються виразом `R_i = (2 μ / (m ω_i²))^(1/2)`.

Натомість теплова хмара атомів `N_{th}` описується звичайним класичним або квантово-дегенерованим розподілом Гаусса — Бозе:

```
n_{th}(r) = (1 / λ_{dB}³) · g_{3/2}[ exp((μ - V_{ext}(r)) / (k_B · T)) ]
```

При наближенні до критичної температури `T_c` спостерігається чіткий двокомпонентний профіль: вузький гострий пік конденсату в центрі, оточений ширшою гауссоподібною тепловою «підкладкою».

### Анізотропний балістичний розліт (Time-of-Flight)

Коли магнітну пастку раптово вимикають, атоми починають вільно розлітатися у просторі під дією початкових імпульсів.
- **Теплова хмара атомів** розлітається ізотропно в усіх напрямках зі швидкістю, пропорційною тепловій швидкості `v_{th} ~ (k_B T / m)^(1/2)`. Співвідношення осей теплової хмари швидко прямує до сферичного `1:1`.
- **Бозе-конденсат**, навпаки, розлітається за рахунок вивільнення накопиченої потенціальної енергії відштовхування `g n_0`. Відповідно до рівнянь гідродинаміки надплинної рідини, прискорення розльоту найбільше уздовж тієї осі, де пастка була **найсуворішою** (де частота `ω_i` була найбільшою).

У результаті анізотропний бозе-конденсат після вимкнення пастки інвертує свою геометричну форму: видовжена вздовж осі `z` «сосиска» перетворюється на плоский «млинець» у середньому полі. Саме ця анізотропія балістичного розльоту є не спростовним експериментальним доказом утворення бозе-конденсату (експеримент Корнелла та Вімана 1995 року).

## 3. Алгоритми спецфункцій та чисельне розв'язання

Для знаходження чисел заповнення та термодинамічних потенціалів використовуються полілогарифми (функції Бозе — Ейнштейна) порядку `ν`:

```
g_ν(z) = ∑_{k=1}^∞ (z^k / k^ν)
```

При `z → 1` ряд збігається повільніше, тому програма використовує розклад із контролем залишку ряду `ε < 10⁻¹²`. У точці `z = 1` значення полілогарифма `g_{3/2}(1)` дорівнює дзета-функції Рімана `ζ(3/2) ≈ 2.61237537`, а `g_{5/2}(1) = ζ(5/2) ≈ 1.34148725`.

Рівняння балансу для фугітивності `z = exp(μ / k_B T)` при `T > T_c` має вигляд:

```
g_{3/2}(z) = ζ(3/2) / (T / T_c)^(3/2)
```

Оскільки ліва частина є монотонно зростаючою функцією `z` на інтервалі `[0, 1]`, розв'язок існує і є єдиним для будь-якого `T > T_c`. Метод бісекції надійно знаходить корінь за 40–50 ітерацій з відносною точністю `10⁻⁹`.

## 5. Траєкторії ефектів у пастках та крайові випадки

1. **Ефекти скінченного числа частинок (`N < ∞`):**
   У реальних експериментах з атомами у пастці кількість частинок становить `N ~ 10³ – 10⁶` (на відміну від термодинамічної межі `N → ∞`). Це приводить до того, що фазовий перехід розмивається: макроскопічна населеність `N_0` починає поступово зростати ще трохи вище `T_c`, а скачок теплоємності стає гладким піком. Для гармонічної пастки зміщення критичної температури через скінченне число частинок описується поправкою:

```
ΔT_c / T_c ≈ - (ζ(2) / (3 · ζ(3))) · N⁻¹ᐟ³ ≈ - 0.73 · N⁻¹ᐟ³
```

2. **Вплив геометричної розмірності та теорема Мерміна — Вагнера:**
   - **У 3D системі:** бозе-конденсація відбувається при `T > 0` як в однорідному газі, так і в пастці.
   - **У 2D та 1D однорідних системах:** відповідно до теореми Мерміна — Вагнера — Гогенберга, довжинохвильові теплові флуктуації фази руйнують далекий порядок при будь-якій температурі `T > 0`, і бозе-конденсація в нескінченному однорідному двовимірному чи одновимірному газі неможлива.
   - **У 2D гармонічній пастці:** обмежувальний параболічний потенціал змінює густину станів `g(ε) ∝ ε`, завдяки чому бозе-конденсація стає можливою при скінченній температурі `T_c > 0`.

3. **Практична інтерпретація результатів табулювання та моделювання Томаса — Фермі:**
   Сформована програмою таблиця безпосередньо відображає фізичну картини фазового переходу. При охолодженні від `T = 2.0 T_c` до `T_c` фугітивність `z` зростає від значення `0.32` до `1.0`, а безрозмірний хімічний потенціал наближається до нуля. При подальшому зниженні температури `T < T_c` фугітивність залишається строго рівною одиниці `z ≡ 1`, а частка конденсату `N_0 / N` монотонно зростає, досягаючи `99.2%` при `T = 0.2 T_c`. Розрахований псевдографічний профіль Томаса — Фермі демонструє інвертований параболічний розподіл атомів від центра пастки `r = 0` до межі `r = R_TF`.
