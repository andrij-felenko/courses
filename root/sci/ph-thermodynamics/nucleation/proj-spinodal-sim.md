# ⚙️ Чисельне моделювання 2D спінодального розпаду мовами C та C++

---

### 1. Фізико-математична постановка задачі та модельний потенціал

Рівняння Кана—Гілліарда описує часову еволюцію поля концентрації `c(x, y, t)` у двовимірній області безпосередньо у стані нестійкості (всередині спінодалі). Система описується парою зв'язаних диференціальних рівнянь:

```
∂c / ∂t = M · ∇² μ
μ = f'(c) − κ · ∇²c
```

де `μ` — локальний градієнтний хімічний потенціал, `M` — феноменологічний коефіцієнт рухливості атомів (мобільність), а `κ > 0` — градієнтний коефіцієнт, який задає енергетичну плату за утворення розмитої межі розділу фаз.

Для комп'ютерного моделювання зручно використати безрозмірну формалізацію двомінімумного потенціалу вільної енергії однорідного стану `f(c)` у формі симетричного полінома четвертого степеня:

```
f(c) = (1/4) · c⁴ − (1/2) · c²
```

Перша похідна потенціалу `f'(c)` (яка визначає хімічний потенціал однорідної фази) виражається як:

```
f'(c) = c³ − c
```

Коріння першої похідної `f'(c) = 0` відповідають рівноважним бінодальним концентраціям двох співіснуючих фаз `c = −1` (фаза α) та `c = +1` (фаза β). Друга похідна `f''(c) = 3 c² − 1` визначає межі термодинамічної стійкості: у діапазоні концентрацій між `− 1 / √3 ≈ − 0.577` та `+ 1 / √3 ≈ + 0.577` друга похідна від'ємна (`f''(c) < 0`), що відповідає нестійкій спінодальній області.

Таким чином, підсистема рівнянь для послідовного чисельного розрахунку на сітці набуває вигляду:

```
μ(x,y,t) = c³ − c − κ · ∇²c
∂c / ∂t = M · ∇²μ
```

Фізичний зміст цього чисельного підходу полягає у тому, що система самоорганізується без потреби явно відстежувати міжфазну межу. Поле концентрації автоматично формує гладкий перехідний шар товщиною порядку кореня з градієнтного коефіцієнта. Це робить метод фазового поля надзвичайно зручним для обчислювального моделювання у порівнянні з класичними методами відстеження меж. Сучасні обчислювальні системи забезпечують високу швидкість розрахунку таких моделей.

#### Безрозмірні змінні та масштабування одиниць

Для підвищення чисельної точності та виключення малого масштабу фізичних величин (таких як `10⁻⁹` м або `10⁻⁶` с) проведемо безрозмірне масштабування. Введемо безрозмірну довжину `x' = x / L_0`, безрозмірний час `t' = t / t_0` та масштабований хімічний потенціал `μ' = μ / E_0`.

Обираючи характерний масштаб довжини як товщину межі `L_0 = √(κ)`, а масштаб часу як `t_0 = L_0⁴ / (M κ) = κ / M`, рівняння Кана—Гілліарда набуває абсолютно чистої безрозмірної форми без жодних фізичних коефіцієнтів:

```
μ' = (c'³) − c' − ∇'² c'
∂c' / ∂t' = ∇'² μ'
```

Таке обезрозмірення дозволяє писати узагальнений чисельний код, який однаково підходить як для металевих сплавів на нанометровому масштабі, так і для полімерних сумішей на мікронних відстанях.

### 2. Чисельна схема дискретизації та математичний алгоритм

Розглянемо квадратну двовимірну ґратку розміром `N × N` вузлів із однаковим кроком просторової сітки `Δx = Δy = h`.

#### 1. Дискретизація оператора Лапласа `∇²`

Для довільного двовимірного скалярного поля `Φ(i, j)` стандартний п'ятиточковий шаблон оператора Лапласа другого порядку точності має вигляд:

```
(∇² Φ)_(i,j) = [ Φ_(i+1,j) + Φ_(i-1,j) + Φ_(i,j+1) + Φ_(i,j-1) − 4 · Φ_(i,j) ] / h²
```

Похибка апроксимації цього п'ятиточкового шаблону становить `O(h²)`. Для підвищення анізотропної симетрії у двовимірному просторі іноді застосовують дев'ятиточковий шаблон Лапласа, проте для завдань спінодального розпаду п'ятиточковий шаблон є цілком достатнім і забезпечує високу обчислювальну швидкість.

Для розрахунку рівняння Кана—Гілліарда оператор Лапласа застосовується **двічі на кожному кроці за часом**:
1. На першому етапі за поточним полем концентрацій `c_(i,j)` обчислюється хімічний потенціал `μ_(i,j)` через оператор `∇² c`.
2. На другому етапі за обчисленим полем хімічного потенціалу `μ_(i,j)` обчислюється праве крило рівняння неперервності `∇² μ`, яке визначає часову похідну `∂c / ∂t`.

#### 2. Періодичні та альтернативні граничні умови

Для усунення крайових ефектів стінок та імітації макроскопічно безмежного об'єму матеріалу застосовуються періодичні граничні умови за обома просторовими координатами. Індекси сусідніх вузлів зациклюються за модулем розміру сітки `N`:

```
i_next = (i + 1) mod N
i_prev = (i − 1 + N) mod N
```

Застосування періодичних умов ґарантує точне збереження повної маси речовини у замкненій системі `∑_(i,j) c_(i,j) = const` на кожному кроці розрахунку, оскільки сумарний дифузійний потік через зовнішні межі строго дорівнює нулю.

При моделюванні розшарування тонких плівок на твердих підкладках застосовують нейтральні граничні умови третього роду для крайового кута змочування `θ`:

```
n · ∇c = − (1 / κ) · ( dγ_s / dc )
n · ∇μ = 0
```

де `n` — орт нормалі до поверхні підкладки, а `γ_s(c)` — поверхнева енергія взаємодії сплаву з підкладкою.

Для реалізації таких поверхонь у різничній схемі застосовують метод фиктивних вузлів (*ghost cells padding*), заповнюючи граничні елементи значеннями з урахуванням нормального похідного.

#### 3. Тривимірне розширення (3D Спінодальний розпад)

У тривимірному об'ємі `N × N × N` вузлів оператор Лапласа апроксимується семиточковим різничним шаблоном:

```
(∇² Φ)_(i,j,k) = [ Φ_(i+1,j,k) + Φ_(i-1,j,k) + Φ_(i,j+1,k) + Φ_(i,j-1,k) + Φ_(i,j,k+1) + Φ_(i,j,k-1) − 6 · Φ_(i,j,k) ] / h²
```

Перехід від 2D до 3D моделювання кардинально змінює топологію лабіринтної структури: у тривимірному просторі двобезперервні домени утворюють складну тривимірну сітку каналів (губчату структуру), стійку до топологічних розривів на набагато більших часах.

#### 4. Явна часова схема Ейлера та критерій стійкості

Для оновлення поля концентрації на новому часовому кроці `t + Δt` використовується явна схема Ейлера:

```
c_(i,j)^(n+1) = c_(i,j)^(n) + Δt · M · (∇² μ)_(i,j)^(n)
```

Оскільки рівняння Кана—Гілліарда містить четверту просторову похідну `∇⁴ c` (через подвійне застосування оператора Лапласа), явна схема має жорстке обмеження на крок за часом для забезпечення чисельної стійкості. Аналіз спектрального радіуса дискретного оператора Лапласа показує, що максимальне власне значення дорівнює `λ_max = 8 / h²` у 2D (та `12 / h²` у 3D). Отже, умова фон Неймана для стійкості схеми Ейлера вимагає:

```
Δt ≤ h⁴ / ( 8 · M · κ )   [у 2D]
Δt ≤ h⁴ / ( 12 · M · κ )  [у 3D]
```

Якщо обрати крок сітки `h = 1.0`, мобільність `M = 1.0` та градієнтний коефіцієнт `κ = 1.0`, то граничний крок за часом становить `Δt_crit = 0.125`. На практиці для надійності та запобігання чисельним осциляціям обирають крок `Δt = 0.01…0.03`.

#### 5. Адаптивний вибір кроку за часом

Для прискорення розрахунку на пізній стадії коалесенції (коли відносна швидкість зміни полів зменшується у сотні разів), застосовують адаптивний контроль кроку `Δt`. На кожному кроці обчислиться максимальний приріст концентрації `Δc_max = max_{i,j} | c_(i,j)^(n+1) − c_(i,j)^(n) |`. Якщо `Δc_max < ε_min`, крок за часом збільшується у множник `1.1`, а якщо `Δc_max > ε_max`, крок зменшується у 2 рази з відкатом стану.

#### 6. Альтернативний напівнеявний спектральний метод (FFT)

Для обходу суворого часового обмеження `Δt ∝ h⁴` у промислових симуляторах застосовують напівнеявні розв'язувачі у просторі Фур'є (за допомогою алгоритмів Швидкого Перетворення Фур'є — FFT).

Переходячи у спектральний простір хвильових векторів `k`, рівняння Кана—Гілліарда набуває вигляду:

```
d ĉ_k / dt = − M · k² · [ F{ f'(c) }_k + κ · k² · ĉ_k ]
```

Застосовуючи напівнеявну схему інтегрування (неявну для жорсткої четвертої похідної `κ k⁴` та явну для нелінійного терма `f'(c)`), отримуємо точну алгоритмічну формулу оновлення гармонік:

```
ĉ_k^(n+1) = [ ĉ_k^(n) − Δt · M · k² · F{ f'(c^n) }_k ] / [ 1 + Δt · M · κ · k⁴ ]
```

Спектральний метод забезпечує абсолютну чисельну стійкість лінійної частини, дозволяючи збільшити крок за часом у `100–1000` разів порівняно з явними скінченно-різницевими схемами Ейлера, зберігаючи при цьому спектральну точність `O(N log N)`.

#### 7. Дискретний аналог монотонного згасання вільної енергії

Важливою перевіркою коректності чисельної схеми є розрахунок повної вільної енергії системи `F[c]` на кожному кроці. Дискретний апроксимант функціонала вільної енергії має вигляд:

```
F_discrete = ∑_(i,j) [ (1/4)·c_(i,j)⁴ − (1/2)·c_(i,j)² + (1/2)·κ·( (∇c)_(i,j) )² ] · h²
```

де квадратичний градієнт обчислюється через центральні скінченні різниці:

```
(∇c)_(i,j)² = [ (c_(i+1,j) − c_(i-1,j)) / (2h) ]² + [ (c_(i,j+1) − c_(i,j-1)) / (2h) ]²
```

У фізично правильній симуляції величина `F_discrete` повинна строго монотонно зменшуватися з часом (`dF / dt <= 0`), що відповідає другому закону термодинаміки для дисипативних континуальних систем.

### 4. Анатомія розв'язку, аналіз продуктивності та інженерні пастки

#### 1. Еволюція мікроструктури та згасання вільної енергії

Під час виконання симуляції спостерігаються три чіткі фізичні стадії розвитку системи:
- **Початкова інкубаційна стадія (кроки 0–500):** флуктуації концентрації малого розміру згладжуються короткохвильовим пригніченням `κ ∇⁴ c`, а моди з довжиною хвилі поблизу `λ_m` починають експоненційно підсилюватися.
- **Стадія формування доменів (кроки 500–2000):** амплітуда концентрації локально досягає рівноважних значень `c = ± 1`. Формується класична лабіринтна (двобезперервна) мікроструктура. На цьому етапі повна вільна енергія `F[c]` швидко падає через зникнення нестійких станів із `c ≈ 0`.
- **Стадія коалесенції та укрупнення (кроки 2000–5000+):** хвильовий характер зникає, а еволюція визначається зменшенням сумарної площі міжфазних меж. Дрібні петлі розпрямляються, викривлення міжфазних меж зменшується, а характерний масштаб доменів виходить на кубічний закон укрупнення `L(t) ∝ t¹/³`.

Така послідовність еволюції доводить високу відповідність математичної моделі Кана—Гілліарда реальним фізичним процесам у загартованих металлографічних зразках та бінарних рідких сумішах.

#### 2. Детальний порівняльний аналіз реалізацій на C та C++

Розглянемо ключові відмінності архітектурних рішень між двома мовними вкладками:

- **Управління пам'яттю та ресурсами:**
  - У C-реалізації використовуються статичні одновимірні масиви `c[N*N]`, `mu[N*N]`, `c_next[N*N]`. Це просто й ефективно, проте виділяє пам'ять у глобальній області стабільного сегмента BSS і робить програму непотокобезпечною.
  - У C++ реалізації використовується динамічний клас `CahnHilliardSolver2D`, який зберігає буфери у двоїстих контейнерах `std::vector<double>`. Це ґарантує строгий життєвий цикл RAII: пам'ять виділяється у купі під час конструювання об'єкта та автоматично звільняється у деструкторі без ризику витоків.

- **Операція перемикання буферів (Buffer Swap):**
  - У Си-коді на кожному кроці здійснюється поелементне копіювання `c[i] = c_next[i]` у циклі за `N*N` ітерацій, що створює додаткове навантаження на шину пам'яті.
  - У C++ коді застосовується метод `c_.swap(c_next_)`, який за `O(1)` обмінюється внутрішніми вказівниками на масиви у векторі. Це повністю ліквідує операцію копіювання пам'яті.

- **Специфікація типу та абстракції:**
  - Си-код покладається на сирі масиви `double*` та власні макроси `pidx(i, j)`.
  - C++ код використовує сучасні абстракції C++20 `std::span<const double>`, що дозволяє передавати зрізи масивів у функції без копіювання та з повним контролем меж у режим зневадження.

#### 3. Паралелізація OpenMP та векторні SIMD інструкції

Оскільки обчислення у кожному вузлі сітки `(i, j)` на одному етапі залежать виключно від значень сусідніх вузлів на попередньому кроці, алгоритм є ідеально придатним для паралельного виконання на багатоядерних процесорах.

У C++ реалізації паралельне розпаралелювання зовнішнього циклу за допомогою OpenMP додається однією директивою препроцесора:

```cpp
#pragma omp parallel for collapse(2) schedule(static)
for (std::size_t i = 0; i < N; ++i) {
    for (std::size_t j = 0; j < N; ++j) {
        // обчислення лапласіана та хімічного потенціалу
    }
}
```

Використання `collapse(2)` розгортає двовимірний цикл у єдиний ітераційний простір розміром `N²`, забезпечуючи рівномірне завантаження всіх ядер процесора та прискорення розрахунку у `4–8` разів. Крім того, неперервне розташування даних у контейнерах `std::vector` дозволяє компілятору виконувати автоматичну SIMD-векторизацію (AVX2/AVX-512) для одночасного виконання операцій над 4 або 8 числами з плаваючою комою за один такт процесора.

#### 5. Вимірювання продуктивності та профілювання пам'яті

Вимірювання швидкості обчислень на сітці `512 × 512` демонструє, що 90% часу витрачається на розрахунок лапласіана хімічного потенціалу `∇² μ`. Використання вирівнювання пам'яті за межею 64 байти (`alignas(64)`) та прапорців компілятора `-O3 -march=native -ffast-math` дозволяє процесору виконувати до 4 векторних інструкцій FMA (Fused Multiply-Add) за такт.

Профілювання пропускної здатності шини пам'яті підтверджує, що чисельний код обмежений швидкістю читання даних із RAM (так звана *Memory Bandwidth Bound* проблема). Тому поділ великої сітки на невеликі обчислювальні блоки розміром `32 × 32`, які повністю вміщаються у L1 кеш процесора (техніка *cache tiling*), підвищує підсумкову обчислювальну швидкість ще на 30–40%. Обчислювальний симулятор показує стабільне прискорення при масштабуванні кількості ядер CPU.

Для розрахунків вищого масштабу на високопродуктивних суперкомп'ютерах чисельне ядро портується на графічні прискорювачі NVIDIA GPU за допомогою технології CUDA або HIP, де кожному вузлу сітки відповідає окремий обчислювальний потік у двовимірній сітці блоків (*Grid of Thread Blocks*).

#### 6. Оцінка похибки чисельного диференціювання

Аналіз похибки дискретизації за методом розкладу в ряд Тейлора показує, що п'ятиточковий шаблон оператора Лапласа має похибку `O(h²)`. Тобто при зменшенні кроку сітки `h` удвічі похибка апроксимації просторових похідних зменшується у 4 рази. Явна схема Ейлера за часом має перший порядок точності `O(Δt)`. Застосування вищих схем інтегрування (таких як чотирьохкроковий метод Рунге—Кутти TVD-RK4) дозволяє підвищити часову точність до `O(Δt⁴)`, що гарантує високу фізичну вірність результатів при тривалому обчисленні еволюції доменів.

Завдяки впровадженню цих алгоритмічних та архітектурних оптимізацій створюється надійне обчислювальне середовище для моделювання матеріалознавчих процесів, яке дозволяє прогнозувати кінетику розшарування багатокомпонентних сплавів у промислових застосуваннях.

#### 7. Типові пастки чисельної реалізації

1. **Нехтування числовою нестійкістю вищого порядку (`∇⁴ c`).** Рівняння Кана—Гілліарда є жорстким диференціальним рівнянням у частинних похідних. При перевищенні критичного кроку за часом `DT > h⁴ / (8 M κ)` розв'язок не просто викривляється, а вибухає до нескінченності за кілька кроків. Для збільшення часового кроку у 10–100 разів у професійних пакетах використовують **напівнеявну схему Ейлера у спектральному просторі** (за допомогою швидкого перетворення Фур'є — FFTW) або неявні багатокрокові методи.
2. **Порушення закону збереження маси.** Застосування невідповідних граничних умов (наприклад, фіксованих значень `c = const` на межах без урахування нормального похідного потоку) призводить до штучного створення або знищення речовини. Перевірка збереження `∑ c_(i,j)` на кожному кроці розрахунку є обов'язковим інваріантом чисельного ядра.
3. **Ефективне управління пам'яттю та кеш-промахи.** У C++ реалізації замість створення нових масивів на кожному часовому кроці використовується швидка операція `std::vector::swap(c_next_)`, яка обмінюється вказівниками на внутрішні буфери за `O(1)` без жодного виділення пам'яті в купі (*heap*). При обході 2D сітки зовнішній цикл завжди виконується по рядках `i`, а внутрішній — по стовпчиках `j` для забезпечення послідовного завантаження даних у L1/L2 кеш-пам'ять процесора.
