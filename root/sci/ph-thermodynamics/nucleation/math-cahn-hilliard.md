# 🧮 Математика фазових переходів: виведення CNT та аналіз стійкості Кана—Гілліарда

Ця вставка містить строгі математичні виведення двох фундаментальних концепцій фізичної кінетики фазових переходів першого роду: виведення критичного радіуса та термодинамічного бар'єра у класичній теорії зародкоутворення (CNT), виведення кінетичного фактора Зельдовича, узагальнення для 2D дисків, а також варіаційне виведення рівняння Кана—Гілліарда, точного профілю міжфазної межі, розрахунок пружних напружень, стохастичні флуктуації Кука, аналіз дифракційного фактора та лінійний аналіз стійкості у спінодальній області.

### 1. Математика класичної теорії зародкоутворення (CNT)

Розглянемо метастабільну однорідну фазу (наприклад, переохолоджену пару або метастабільний розчин), у якій шляхом теплової флуктуації виникає сферична крапля нової стабільної фази радіуса `r`.

#### Зміна вільної енергії при утворенні зародка

Повна зміна вільної енергії системи `ΔG(r)` при появі краплі радіуса `r` складається з двох конкуруючих внесків:
1. **Об'ємний внесок:** виграш вільної енергії за рахунок переходу об'єму краплі `V = (4/3) π r³` у термодинамічно вигідніший стан із меншою питомою вільною енергією. Зміна вільної енергії на одиницю об'єму дорівнює `− Δg_v` (де `Δg_v > 0` — різниця питомих об'ємних енергій фаз, пропорційна глибині переохолодження `ΔT`).
2. **Поверхневий внесок:** витрата енергії на утворення міжфазної межі площею `A = 4 π r²` із питомою вільною поверхневою енергією (поверхневим натягом) `γ > 0`.

Загальна функція вільної енергії утворення зародка має вигляд:

```
ΔG(r) = 4·π·r²·γ − (4/3)·π·r³·Δg_v
```

#### Пошук критичного радіуса `r*`

Для знаходження екстремуму функції `ΔG(r)` обчислимо її першу похідну по радіусу `r` і прирівняємо її до нуля:

```
dΔG / dr = d/dr [ 4·π·r²·γ − (4/3)·π·r³·Δg_v ]
         = 8·π·r·γ − 4·π·r²·Δg_v = 0
```

Розв'язуємо отримане алгебраїчне рівняння відносно `r`:

```
8·π·r·γ = 4·π·r²·Δg_v
8·γ = 4·r·Δg_v
r* = 2·γ / Δg_v
```

Перевіримо знак другої похідної в точці `r*`:

```
d²ΔG / dr² = 8·π·γ − 8·π·r·Δg_v
d²ΔG / dr² |_(r=r*) = 8·π·γ − 8·π·(2·γ / Δg_v)·Δg_v
                   = 8·π·γ − 16·π·γ = − 8·π·γ < 0
```

Оскільки друга похідна від'ємна, точка `r* = 2 γ / Δg_v` є **максимумом** вільної енергії. Зародок радіуса `r*` перебуває у стані нестійкої термодинамічної рівноваги:
- якщо `r < r*`, `dΔG/dr > 0`, і зменшення радіуса зменшує вільну енергію (кластер розчиняється);
- якщо `r > r*`, `dΔG/dr < 0`, і збільшення радіуса зменшує вільну енергію (зародок незворотно зростає).

#### Обчислення роботи утворення критичного зародка `ΔG*`

Підставимо значення критичного радіуса `r* = 2 γ / Δg_v` у вихідний вираз для `ΔG(r)`:

```
ΔG* = ΔG(r*)                                              [значення у критичній точці]
    = 4·π·(2·γ / Δg_v)²·γ − (4/3)·π·(2·γ / Δg_v)³·Δg_v   [підстановка r* = 2γ / Δg_v]
    = 4·π·(4·γ² / (Δg_v)²)·γ − (4/3)·π·(8·γ³ / (Δg_v)³)·Δg_v [піднесення до квадрата і куба]
    = 16·π·γ³ / (Δg_v)² − (32/3)·π·γ³ / (Δg_v)²          [перемноження чисельників]
    = (48/3 − 32/3)·π·γ³ / (Δg_v)²                       [зведення дробу]
    = (16/3)·π·γ³ / (Δg_v)²                              [остаточне віднімання]
```

Виразивши поверхню критичної сфери `A* = 4 π (r*)²`, отримаємо відоме співвідношення Гіббса:

```
ΔG* = (1/3) · γ · A*
```

#### Гетерогенне зародкоутворення: геометричний фактор змочування `f(θ)`

Якщо зародок утворюється на плоскій твердій підкладці (або на поверхні сторонньої частинки), його форма являє собою сферичний сегмент із крайовим кутом змочування `θ`. Зміна вільної енергії при гетерогенному зародкоутворенні зв'язана з гомогенним бар'єром через геометричний фактор змочування `f(θ)`:

```
ΔG*_het = ΔG*_hom · f(θ)
```

Виведемо математичний вираз для `f(θ)`. Об'єм сферичного сегмента радіуса `r` з крайовим кутом `θ` дорівнює:

```
V_seg = (1/3)·π·r³·(2 + cos θ)·(1 − cos θ)²
```

Площа поверхні межі зародок-середовище дорівнює:

```
A_cap = 2·π·r²·(1 − cos θ)
```

Площа межі між зародком та підкладкою дорівнює:

```
A_base = π·r²·sin² θ = π·r²·(1 − cos² θ)
```

Залежність поверхневих натягів задається рівнянням Юнга:

```
γ_sub-med = γ_sub-nuc + γ · cos θ
```

Підставляючи ці об'єми та площі у повний баланс вільної енергії та мінімізуючи його по `r`, отримуємо критичний радіус `r* = 2 γ / Δg_v` (такий самий, як і при гомогенному зародкоутворенні!), але об'єм зародка зменшується у множник `f(θ)`:

```
f(θ) = V_seg / V_sphere
     = [ (1/3)·π·r³·(2 + cos θ)·(1 − cos θ)² ] / [ (4/3)·π·r³ ]
     = (2 + cos θ)·(1 − cos θ)² / 4
```

Аналіз крайових випадків:
- при повному незмочуванні (`θ = 180°`, `cos θ = −1`): `f(180°) = (2 − 1)(1 + 1)² / 4 = 4 / 4 = 1`. Гетерогенний бар'єр дорівнює гомогенному.
- при повному змочуванні (`θ = 0°`, `cos θ = 1`): `f(0°) = (2 + 1)(1 − 1)² / 4 = 0`. Бар'єр повністю зникає (`ΔG*_het = 0`), і зародкоутворення відбувається безбар'єрно.

#### Зародкоутворення на межах зерен у кристалах

При фазових перетвореннях у твердих сплавах зародки другої фази часто виникають на межах між кристалічними зернами. Якщо енергія межі зерна дорівнює `γ_gb`, то зародкоутворення ліквідує ділянку цієї межі, зменшуючи активаційний бар'єр. Для двоопуклої сочевицеподібної краплі зі спільним кутом при вершині `2 Ψ` (де `cos Ψ = γ_gb / (2 γ)`) фактор зниження бар'єра `f_gb(Ψ)` задається формулою:

```
f_gb(Ψ) = (1/2) − (3/4)·cos Ψ + (1/4)·cos³ Ψ
```

Якщо зародок формується у лінійному стику трьох зерен (потрійна точка), бар'єр знижується ще сильніше. Це пояснює, чому нові фази у металургії випадають сіткою вздовж меж зерен.

#### Кинетичний фактор Зельдовича `Z`

Кінетичне рівняння Зельдовича описує еволюцію функції розподілу кластерів `f(n,t)` за кількістю атомів `n` як дифузію у просторі розмірів. В околі вершини термодинамічного бар'єра `n*` розклад профілю вільної енергії `ΔG(n)` у ряд Тейлора має вигляд:

```
ΔG(n) ≈ ΔG* + (1/2) · ( d²ΔG / dn² |_(n*) ) · (n − n*)²
```

Оскільки друга похідна від'ємна, введемо фактор Зельдовича `Z`, що характеризує ширину бар'єра на тепловому рівні `k_B T`:

```
Z = √ [ ( − 1 / (2·π·k_B·T) ) · ( d²ΔG / dn² |_(n*) ) ]
```

Підставляючи формулу для сферичного зародка `n = (4/3) π r³ / v_a` (де `v_a` — атомний об'єм), отримуємо вираз для фактора Зельдовича через критичне число атомів `n*`:

```
Z = √ [ ΔG* / (3·π·k_B·T·(n*)²) ]
```

Фізичний зміст фактора Зельдовича полягає у тому, що лише частка кластерів порядку `Z` (типово `Z ≈ 10⁻²…10⁻³`), які досягли вершини бар'єра `n*`, продовжує зростати далі, тоді як решта `1 − Z` розпадається назад через броунівські теплові флуктуації.

#### Двовимірне зародкоутворення дисків на поверхнях

У випадку гетерогенної епітаксії тонких плівок зародок має форму двовимірного диска висоти `h` та радіуса `r`. Повний баланс вільної енергії утворення диска задається рівнянням:

```
ΔG_2D(r) = 2·π·r·h·γ_edge + π·r²·Δg_surface
```

де `γ_edge` — лінійний натяг ребра диска [Дж/м], а `Δg_surface < 0` — виграш поверхневої енергії підкладки.

Беручи похідну по `r` та прирівнюючи до нуля:

```
dΔG_2D / dr = 2·π·h·γ_edge + 2·π·r·Δg_surface = 0
```

Отримуємо 2D критичний радіус та 2D активаційний бар'єр:

```
r*_2D = − h · γ_edge / Δg_surface = h · γ_edge / |Δg_surface|
ΔG*_2D = π · h · (γ_edge)² / |Δg_surface|
```

Це співвідношення показує, що при осадженні плівок активаційний бар'єр зростає лінійно з висотою шару `h`, що визначає перехід від пошарового росту Франка—ван дер Мерве до острівкового росту Фольмера—Вебера.

### 2. Варіаційне числення та рівняння Кана—Гілліарда

У просторово неоднорідній системі склад `c(r)` змінюється від точки до точки. За підходом Кана та Гілліарда повна вільна енергія системи описується функціоналом:

```
F[c] = ∫_V [ f(c) + (1/2)·κ·(∇c)² ] dV
```

де `f(c)` — питома вільна енергія однорідного стану, а `κ > 0` — градієнтний коефіцієнт (параметр міжфазного натягу).

#### Варіаційне виведення градієнтного хімічного потенціалу `μ`

Хімічний потенціал речовини `μ(r)` визначається як варіаційна похідна функціонала вільної енергії по локальній концентрації `δF / δc`:

```
δF = ∫_V [ δf(c) + (1/2)·κ·δ((∇c)²) ] dV
```

Варіюємо кожен доданок окремо:

```
δf(c) = (df / dc) · δc = f'(c) · δc
```

Для другого доданка маємо:

```
(1/2)·κ·δ((∇c)²) = κ · (∇c) · ∇(δc)
```

Застосуємо першу формулу Гріна (інтегрування за частинами для градієнта):

```
∫_V κ · (∇c) · ∇(δc) dV = ∫_∂V κ · (∇c) · n · δc dA − ∫_V κ · ∇²c · δc dV
```

Припускаючи періодичні межі або нульовий потік через зовнішню межу (`(∇c) · n = 0` на `∂V`), поверхневий інтеграл перетворюється на нуль. Збираємо варіацію `δF`:

```
δF = ∫_V [ f'(c) − κ · ∇²c ] · δc dV
```

Отже, варіаційна похідна (графічний або градієнтний хімічний потенціал `μ`) дорівнює:

```
μ = δF / δc = f'(c) − κ · ∇²c
```

#### Точний профіль плоскаї міжфазної межі та аналітичний розрахунок міжфазного натягу `γ`

Розглянемо стаціонарну міжфазну межу розділу між двома рівноважними фазами `c = −1` та `c = +1`, орієнтовану перпендикулярно до осі `z`. Стан рівноваги відповідає сталості хімічного потенціалу `μ = f'(c) − κ (d²c/dz²) = 0`.

Для поліноміального потенціалу `f(c) = (1/4)(c² − 1)²` маємо `f'(c) = c³ − c`. Диференціальне рівняння профілю межі має вигляд:

```
κ · (d²c / dz²) = c³ − c
```

Помножимо обидві частини на `dc/dz` та зінтегруємо по `z`:

```
(1/2) · κ · (dc / dz)² = f(c) = (1/4) · (c² − 1)²
```

Беручи квадратний корінь:

```
√(κ/2) · (dc / dz) = (1/2) · (1 − c²)
dc / (1 − c²) = dz / √(2·κ)
```

Інтегруючи це диференціальне рівняння з початковою умовою `c(0) = 0`, отримуємо точний аналітичний профіль міжфазної межі Кана—Гілліарда у вигляді гіперболічного тангенса:

```
c(z) = tanh( z / W )
```

де ефективна товщина розмитої міжфазної межі `W` дорівнює:

```
W = √( 2·κ )
```

Обчислимо повну вільну поверхневу енергію (міжфазний натяг `γ`) шляхом інтегрування надлишкової енергії вздовж вісі `z`:

```
γ = ∫_{−∞}^{+∞} [ f(c(z)) + (1/2)·κ·(dc/dz)² ] dz
  = 2 · ∫_{−∞}^{+∞} (1/2)·κ·(dc/dz)² dz
  = κ · ∫_{−1}^{+1} (dc/dz) dc
  = κ · ∫_{−1}^{+1} [ (1 − c²) / √(2·κ) ] dc
  = √(κ/2) · [ c − (c³/3) ]|_{−1}^{+1}
  = √(κ/2) · [ (1 − 1/3) − (−1 + 1/3) ]
  = √(κ/2) · (4/3) = (2·√2 / 3) · √κ
```

Отриманий формула `γ = (2√2 / 3) √κ` демонструє глибокий термодинамічний зв'язок між мікроскопічним градієнтним коефіцієнтом `κ` та макроскопічним поверхневим натягом `γ`.

#### Рівняння збереження маси та неперервності

Дифузійний потік речовини `J` пропорційний градієнту хімічного потенціалу (перший закон Фіка у термодинамічній формі):

```
J = − M · ∇μ = − M · ∇ [ f'(c) − κ · ∇²c ]
```

де `M > 0` — феноменологічна мобільність (рухливість) атомів.

Підставляємо потік `J` у закон збереження маси (рівняння неперервності `∂c / ∂t = − ∇ · J`):

```
∂c / ∂t = − ∇ · [ − M · ∇μ ]
        = ∇ · [ M · ∇ ( f'(c) − κ · ∇²c ) ]
```

Припускаючи мобільність `M` постійною вздовж об'єму, отримуємо нелінійне диференціальне рівняння Кана—Гілліарда у частинних похідних четвертого порядку:

```
∂c / ∂t = M · ∇² [ f'(c) − κ · ∇²c ]
        = M · ∇² f'(c) − M · κ · ∇⁴c
```

#### Врахування пружних напружень у кристалічних сплавах

При спінодальному розпаді у твердих кристалах різниця атомних радіусів компонентів створює когерентні пружні напруження. Якщо розширення ґратки пропорційне концентрації `ε_ij = η · δ_ij · (c − c_0)`, то пружна енергія додає до функціонала вільної енергії терм:

```
F_elastic = ∫_V [ E' · η² · (c − c_0)² ] dV
```

де `E' = E / (1 − ν)` для ізотропного кристала (де `E` — модуль Юнга, `ν` — коефіцієнт Пуассона). Враховуючи пружний терм, ефективна друга похідна вільної енергії зміщується:

```
f''(c_0)_eff = f''(c_0) + 2 · E' · η²
```

Це означає, що когерентні пружні напруження **звужують спінодальну область** та знижують критичну температуру розпаду (когерентна спінодаль лежить нижче хімічної спінодалі).

#### Узагальнення Кана—Гілліарда—Кука з урахуванням стохастичного шуму

На початковій стадії спінодального розпаду теплові флуктуації відіграють вирішальну роль у виникненні первинних хвиль розшарування. Глен Кук (1970) модифікував рівняння Кана—Гілліарда, додавши стохастичний тепловий шум `ξ(r,t)`:

```
∂c / ∂t = M · ∇² [ f'(c) − κ · ∇²c ] + ξ(r,t)
```

За флуктуаційно-дисипативною теоремою стохастичний потік маси задовольняє умови нульового середнього та дельта-кореляції у часі й просторі:

```
< ξ(r,t) > = 0
< ξ(r,t) · ξ(r',t') > = − 2 · k_B · T · M · ∇² δ(r − r') · δ(t − t')
```

Оператор `− ∇²` у кореляторі ґарантує, що стохастичний шум `ξ(r,t)` строго зберігає локальну масу системи `∫ ξ dV = 0`.

### 3. Лінійний аналіз стійкості спінодального розпаду

Розглянемо систему з початковою однорідною концентрацією `c_0`, розміщену в нестійкій спінодальній області (`f''(c_0) < 0`). Накладемо на неї мале просторове збурення `δc(r,t)`:

```
c(r,t) = c_0 + δc(r,t),   де |δc| << c_0
```

#### Лінеаризація рівняння Кана—Гілліарда

Розкладемо похідну вільної енергії `f'(c)` у ряд Тейлора в околі точки `c_0`, обмежуючись першим порядком за малими відхиленнями `δc`:

```
f'(c) = f'(c_0 + δc) ≈ f'(c_0) + f''(c_0) · δc
```

Підставимо розклад у рівняння Кана—Гілліарда:

```
∂(c_0 + δc) / ∂t = M · ∇² [ f'(c_0) + f''(c_0) · δc − κ · ∇²(δc) ]
```

Оскільки `c_0` та `f'(c_0)` є просторовими константами, їхні лапласіани дорівнюють нулю (`∇² c_0 = 0`, `∇² f'(c_0) = 0`). Отримуємо лінеаризоване рівняння для збурення `δc`:

```
∂(δc) / ∂t = M · f''(c_0) · ∇²(δc) − M · κ · ∇⁴(δc)
```

#### Метод гармонічних мод (аналіз Фур'є)

Будемо шукати розв'язок лінеаризованого рівняння у вигляді площини хвилі (моди Фур'є):

```
δc(r,t) = ĉ_k · exp( R(k)·t + i · k · r )
```

де `k` — хвильовий вектор флуктуації (`k = |k| = 2π / λ`), `R(k)` — інкремент наростання (інкремент стійкості) моди з хвильовим числом `k`, а `i` — уявна одиниця.

Обчислимо просторові похідні від гармонічної моди:

```
∇(δc) = i · k · δc
∇²(δc) = (i · k)² · δc = − k² · δc
∇⁴(δc) = ∇²(∇²(δc)) = ∇²(− k² · δc) = (− k²)² · δc = k⁴ · δc
```

Часова похідна дорівнює:

```
∂(δc) / ∂t = R(k) · δc
```

Підставляємо обчислині похідні у лінеаризоване рівняння Кана—Гілліарда:

```
R(k) · δc = M · f''(c_0) · (− k² · δc) − M · κ · (k⁴ · δc)
```

Скорочуємо обидві частини рівняння на ненульовий множник `δc`:

```
R(k) = − M · f''(c_0) · k² − M · κ · k⁴
     = M · k² · [ − f''(c_0) − κ · k² ]
```

Це фундаментальне **дисперсійне співвідношення Кана—Гілліарда**.

#### Аналіз дисперсійного співвідношення та критерій нестійкості

Дослідимо знак інкременту `R(k)` залежно від другої похідної вільної енергії `f''(c_0)`:

1. **Метастабільна або стабільна область (`f''(c_0) > 0`):**
   Оскільки `f''(c_0) > 0` та `κ > 0`, дужка `[ − f''(c_0) − κ k² ]` є строго від'ємною для будь-яких `k > 0`. Отже, `R(k) < 0` для всіх хвиль: будь-які флуктуації експоненційно затухають у часі (`exp(R t) → 0`), і однорідний стан є стійким до малих збурень.

2. **Спінодальна область (`f''(c_0) < 0`):**
   Позначимо `|f''(c_0)| = − f''(c_0) > 0`. Дисперсійне співвідношення набуває вигляду:
   ```
   R(k) = M · k² · [ |f''(c_0)| − κ · k² ]
   ```

   Інкремент `R(k) > 0` (флуктуації експоненційно зростають), якщо дужка додатна:

   ```
   |f''(c_0)| − κ · k² > 0
   κ · k² < |f''(c_0)|
   k² < |f''(c_0)| / κ
   ```

#### Критичне хвильове число `k_c` та критична довжина хвилі `λ_c`

Критичне хвильове число `k_c`, при якому `R(k_c) = 0`, дорівнює:

```
k_c = √( |f''(c_0)| / κ )
```

Усі просторові моди з хвильовими числами `k < k_c` (довгі хвилі з `λ > λ_c = 2π / k_c`) є нестійкими і наростають з часом. Моди з `k > k_c` (короткі хвилі) гасяться градієнтною енергією `κ k⁴`.

#### Пошук домінантної хвилі `k_m` та максимальної швидкості наростання `R_max`

Знайдемо хвильове число `k_m`, для якого швидкість наростання `R(k)` є максимальною. Беремо похідну від `R(k)` по `k` і прирівнюємо її до нуля:

```
dR / dk = d/dk [ M · |f''(c_0)| · k² − M · κ · k⁴ ]
        = 2 · M · |f''(c_0)| · k − 4 · M · κ · k³ = 0
```

Скорочуємо на `2 M k` (шукаємо ненульовий розв'язок `k ≠ 0`):

```
|f''(c_0)| − 2 · κ · k² = 0
2 · κ · k² = |f''(c_0)|
k_m² = |f''(c_0)| / (2·κ) = (k_c)² / 2
k_m = k_c / √2
```

Домінантна довжина хвилі структури `λ_m`, яка виростає швидше за всі інші моди у початковий період спінодального розпаду, дорівнює:

```
λ_m = 2·π / k_m = 2·π · √( 2·κ / |f''(c_0)| ) = √2 · λ_c
```

Обчислимо максимальний інкремент наростання `R_max = R(k_m)`:

```
R_max = M · (k_c / √2)² · [ |f''(c_0)| − κ · (k_c / √2)² ]
      = M · ( |f''(c_0)| / (2·κ) ) · [ |f''(c_0)| − κ · ( |f''(c_0)| / (2·κ) ) ]
      = M · ( |f''(c_0)| / (2·κ) ) · [ |f''(c_0)| / 2 ]
      = M · [f''(c_0)]² / (4·κ)
```

#### Динамічний фактор структури `S(k,t)` та аналіз дифракційних методів

Експериментальне спостереження спінодального розпаду методами малокутового рентгенівського (SAXS) або нейтронного (SANS) розсіювання вимірює інтенсивність розсіювання `I(q,t)`, яка прямо пропорційна динамічному структурному фактору `S(k,t) = < |ĉ_k(t)|² >`.

У лінійній теорії Кана—Гілліарда часова еволюція структурного фактора задовольняє диференціальне рівняння:

```
dS(k,t) / dt = 2 · R(k) · S(k,t) + 2 · k_B · T · M · k²
```

Розв'язок цього рівняння з урахуванням початкового флуктуаційного спектра `S(k,0)` має вигляд:

```
S(k,t) = [ S(k,0) + k_B·T / ( |f''| − κ·k² ) ] · exp( 2·R(k)·t ) − k_B·T / ( |f''| − κ·k² )
```

Вимір часового зростання пику логарифма інтенсивності `ln I(q,t)` на конкретних хвильових векторах `q` дозволяє прямо експериментально визначати коефіцієнт атомної мобільності `M` та градієнтний коефіцієнт `κ` у реальних інженерних матеріалах.

Варто відзначити, що при зміні температури `T` значення `|f''(c_0)|` прямує до нуля поблизу спінодалі як `|f''| ∝ (T_s − T)`. Це призводить до критичного уповільнення кінетики розшарування та необмеженого зростання домінантної довжини хвилі `λ_m ∝ (T_s − T)⁻¹/²`, що є класичним проявом критичних явищ другого роду на межі термодинамічної лабільності. Траєкторія росту амплітуди хвиль Фур'є демонструє універсальний характер для багатьох бінарних сплавів, полімерних блендів та рідких сумішей.

Крім того, аналіз дифракційного максимального кільця дозволяє точно відстежувати часовий поріг переходу від лінійної кінетики Кана до нелінійної коалесенції. Математичні методи обробки спектрів розсіювання створюють надійний зв'язок між теорією Кана та практичним вимірюванням у фізичних лабораторіях. Вони дозволяють аналізувати як металеві матеріали, так і складні колоїдні системи й термотропні полімери.

#### Масштабний закон коалесенції ЛСВ на пізній стадії

На пізній стадії нелінійного розшарування (коли концентрації фаз досягають рівноважних бінодальних значень `c_α` та `c_β`), зростання доменів описується кінетикою Ліфшиця—Сльозова—Вагнера (ЛСВ). Різниця Лапласівського тиску між краплями радіуса `R` створює концентраційний градієнт розчиненої речовини в матриці:

```
Δc(R) = c_eq(R) − c_eq(∞) = 2·γ·v_a·c_eq(∞) / (k_B·T·R)
```

Дифузійний потік речовини від дрібних крапель до великих описується законами дифузії:

```
dR / dt = D · Δc(R) / R = 2·D·γ·v_a·c_eq(∞) / (k_B·T·R²)
```

Інтегруючи це диференціальне рівняння по часу `t`, отримуємо кубічний масштабний закон укрупнення:

```
R(t)³ − R(0)³ = K_LSW · t
```

де коефіцієнт коалесенції `K_LSW = (8 / 9) · D · γ · v_a · c_eq(∞) / (k_B T)`. Цей математичний результат доводить узагальненість кубічного зростання доменів `L(t) ∝ t¹/³` для пізніх стадій як зародкоутворення, так і спінодального розпаду.
