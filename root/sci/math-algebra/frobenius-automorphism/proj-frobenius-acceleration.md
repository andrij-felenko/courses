# ⚙️ Прискорення скалярного множення на кривих Кобліца через тау-адичний розклад

В обчислювальній криптографії на еліптичних кривих (протоколи цифрового підпису ECDSA та Ed25519, протокол узгодження ключів Діффі — Геллмана на еліптичних кривих ECDH) головним ресурсомістким вузлом є обчислення скалярного добутку точки:

```
Q = k · P = P + P + … + P  (k разів)
```

де `k` — 256-бітне секретне ціле число (приватний ключ), а `P` — фіксована базова точка еліптичної кривої. У класичному двійковому алгоритмі «Double-and-Add» на кожен біт скаляра потрібно виконати геометричне подвоєння точки `[2]Q`, а для кожного одиничного біта — геометричне додавання `Q + P`. Подвоєння точки в афінних координатах скінченного поля вимагає від 5 до 10 операцій множення та одну важку операцію знаходження оберненого елемента (ділення в полі). Для 256-бітного ключа це вимагає приблизно 256 подвоєнь та в середньому 128 додавань, що створює значну затримку при обробці тисяч криптографічних запитів на секунду.

Для подолання цього обчислювального бар'єру в 1991 році американський криптограф Ніл Кобліц запропонував спеціальний клас еліптичних кривих над двійковими полями розширення `GF(2ᵐ)` — **криві Кобліца** (або аномальні двійкові криві). Головна перевага цих кривих полягає в тому, що операція піднесення координат до квадрата є ендоморфізмом Фробеніуса `τ(x, y) = (x², y²)`. У спеціальних базисах поля піднесення до квадрата виконується практично безкоштовно (як циклічний зсув бітів у процесорному регістрі за один такт), а операція подвоєння точки `[2]P` повністю виключається з обчислювального конвеєра і замінюється дією `τ`.

Нижче наведено повний математичний аналіз кривих Кобліца, алгебраїчну теорію кільця `ℤ[τ]`, алгоритм тау-адичного несусіднього розкладу (τ-NAF, *τ-adic Non-Adjacent Form*), аналіз проєктивних координат Лопеса — Дахаба, віконні методи прискорення, аналіз мікроархітектурних витрат, оптимізацію для вбудованих процесорів, захист від атак за енергоспоживанням та завершену еталонну реалізацію мовами C та C++.

### 1. Алгебраїчна будова кривих Кобліца та оператор Фробеніуса

Двійкова крива Кобліца `E_a` над полем розширення `GF(2ᵐ)` задається канонічним рівнянням у формі Вейєрштрасса для характеристики 2:

```
y² + x·y = x³ + a·x² + 1,     де коефіцієнт a ∈ {0, 1}
```

Ключова особливість цієї кривої полягає в тому, що всі її коефіцієнти належать простому двійковому полю `GF(2) = {0, 1}`. Завдяки цьому автоморфізм Фробеніуса поля `z ↦ z²` покомпонентно діє на афінні координати точок:

```
τ: E_a → E_a,    τ(x, y) = (x², y²),    τ(𝒪) = 𝒪
```

де `𝒪` — нейтральна нескінченно віддалена точка кривої.

Перевіримо, що образ точки `τ(x, y)` завжди лежить на тій самій кривій. Піднесемо обидві частини рівняння кривої до квадрата:

```
(y² + x·y)² = (x³ + a·x² + 1)²
(y²)² + (x·y)² = (x³)² + a²·(x²)² + 1²       [адитивність піднесення до квадрата у характеристиці 2]
(y²)² + x²·y² = (x²)³ + a·(x²)² + 1          [оскільки a² = a та 1² = 1 у GF(2)]
```

Отриманий вираз показує, що пара чисел `(x², y²)` у точності задовольняє рівняння кривої `E_a`. Отже, відображення `τ` переводить будь-яку точку кривої в іншу точку цієї самої кривої.

Оскільки формули групового додавання точок на еліптичній кривій складаються виключно з раціональних операцій (додавання, множення та ділення координат), а піднесення до квадрата є гомоморфізмом поля, відображення `τ` комутує з груповим додаванням точок:

```
τ(P + Q) = τ(P) + τ(Q)    для будь-яких точок P, Q ∈ E_a
```

На кільці ендоморфізмів кривої `End(E_a)` оператор Фробеніуса `τ` задовольняє квадратичне характеристичне рівняння:

```
τ² - μ·τ + 2 = 0
```

де цілочисельний параметр `μ` (грецька літера «мю») визначається формулою `μ = (-1)^(1 - a)`:
- Якщо `a = 0`, то `μ = (-1)¹ = -1`, і рівняння має вигляд `τ² + τ + 2 = 0`.
- Якщо `a = 1`, то `μ = (-1)⁰ = 1`, і рівняння має вигляд `τ² - τ + 2 = 0`.

Виразимо ціле число 2 через оператор Фробеніуса з характеристичного рівняння:

```
2 = μ·τ - τ² = τ · (μ - τ)
```

Це рівняння має фундаментальний практичний зміст: операція подвоєння точки `[2]P = P + P` еквівалентна дії алгебраїчного оператора `μ·τ(P) - τ²(P)`. Коренем характеристичного рівняння у полі комплексних чисел є число:

```
τ = (μ + √(-7)) / 2
```

з комплексною нормою `N(τ) = τ · τ̄ = (μ² + 7) / 4 = (1 + 7) / 4 = 2`.

### 2. Кільце цілих чисел ℤ[τ] та тау-адичний розклад

Оскільки число `τ` задовольняє нормоване квадратичне рівняння з цілими коефіцієнтами `τ² - μ·τ + 2 = 0`, множина чисел вигляду `r₀ + r₁·τ` (де `r₀, r₁ ∈ ℤ`) утворює евклідове кільце цілих алгебраїчних чисел, яке позначається `ℤ[τ]`.

Комплексна норма елемента `r = r₀ + r₁·τ` у цьому кільці обчислюється як:

```
N(r₀ + r₁·τ) = (r₀ + r₁·τ) · (r₀ + r₁·τ̄) = r₀² + μ·r₀·r₁ + 2·r₁²
```

Оскільки норма `N(τ) = 2`, елемент `τ` ділить число 2 у кільці `ℤ[τ]`. Це дозволяє побудувати систему числення з основою `τ`, аналогічну класичній двійковій системі числення з основою 2.

Будь-який скаляр `k ∈ ℤ` можна однозначно подати у вигляді скінченної суми за степенями `τ`:

```
k = ∑ᵢ₌₀ˡ⁻¹ uᵢ · τⁱ,     де коефіцієнти uᵢ ∈ {-1, 0, 1}
```

Щоб мінімізувати кількість операцій додавання точок при скалярному множенні, розклад будують у так званій **несусідній формі** (англ. *τ-adic Non-Adjacent Form*, τ-NAF). У несусідній формі добуток будь-яких двох сусідніх цифр строго дорівнює нулю:

```
uᵢ · uᵢ₊₁ = 0    для всіх індексів i
```

Завдяки умові несусідності середня щільність ненульових цифр у розкладі становить лише `1/3` (тобто приблизно кожна третя цифра є ненульовою), тоді як у звичайному двійковому поданні щільність одиниць становить `1/2`. Це зменшує середню кількість операцій додавання точок на 33%.

### 3. Алгоритм побудови τ-NAF розкладу та доведення збіжності

Розглянемо покроковий алгоритм розкладу довільного елемента `r = r₀ + r₁·τ ∈ ℤ[τ]` за основою `τ`:

1. Дослідимо подільність елемента `r` на `τ`. Оскільки `N(τ) = 2`, елемент `r` ділиться на `τ` без остачі тоді й лише тоді, коли його норма `N(r) = r₀² + μ·r₀·r₁ + 2·r₁²` є парним числом.
   - Вираз `r₀² + μ·r₀·r₁ + 2·r₁²` є парним тоді й лише тоді, коли коефіцієнт `r₀` є парним числом (`r₀ ≡ 0 (mod 2)`).
   - Якщо `r₀` парне, то `r` ділиться на `τ` націло, і поточна цифра розкладу дорівнює `u = 0`.
2. Якщо `r₀` є непарним числом, то `r` не ділиться на `τ`. Тоді ми віднімаємо ненульову цифру `u ∈ {-1, 1}`, щоб зробити різницю `r - u` кратною `τ²`.
   - Умова подільності `(r - u)` на `τ² = μ·τ - 2` еквівалентна конгруенції:
   ```
   u = 2 - ((r₀ - 2·r₁) mod 4)
   ```
   Якщо отримане значення `u` дорівнює 3, ми замінюємо його на `-1` за модулем 4.
3. Після вибору цифри `u` різниця `r - u = (r₀ - u) + r₁·τ` точно ділиться на `τ`. Виконаємо ділення на `τ`:
   ```
   (r₀' + r₁'·τ) = ((r₀ - u) + r₁·τ) / τ
   ```
   Помноживши чисельник і знаменник на спряжений елемент `τ̄ = μ - τ` та скориставшись тим, що `τ · τ̄ = 2`, отримуємо точні формули перерахунку коефіцієнтів:
   ```
   r₀_new = r₁ + μ · (r₀ - u) / 2
   r₁_new = - (r₀ - u) / 2
   ```
4. Цикл повторюється доти, доки обидва коефіцієнти не стануть нульовими: `r₀ = 0` та `r₁ = 0`.

Доведемо строгу збіжність цього алгоритму. Обчислимо норму нового елемента `r_new`:

```
N(r_new)
= N((r - u) / τ)                                 [визначення нового залишку]
= N(r - u) / N(τ)                                [мультиплікативність норми]
= N(r - u) / 2                                   [оскільки N(τ) = 2]
```

Оскільки вибір цифри `u` забезпечує подільність `r - u` на `τ²`, на наступному кроці алгоритм гарантовано обере `u_{next} = 0`, і елемент буде поділено на `τ` ще раз:

```
N(r_{new2}) = N(r_new) / 2 = N(r - u) / 4
```

Для будь-якого елемента з нормою `N(r) ≥ 4` величина `N(r - u) / 4 < N(r)`. Отже, норма монотонно та строго спадає на кожному другому кроці, що гарантує завершення алгоритму за скінченну кількість ітерацій.

### 4. Числовий приклад трасування розкладу для скаляра k = 7

Простежимо роботу алгоритму для кривої з параметрами `a = 1` (`μ = 1`) та скаляра `k = 7`:

- **Крок 0**: Початковий стан `r₀ = 7, r₁ = 0`.
  - Число `r₀ = 7` непарне. Обчислюємо цифру: `u₀ = 2 - ((7 - 0) mod 4) = 2 - 3 = -1`.
  - Віднімаємо `u₀`: `r₀ - u₀ = 7 - (-1) = 8`.
  - Ділення на `τ`: `r₀ = 0 + 1 · (8/2) = 4`, `r₁ = -(8/2) = -4`.
  - Записано цифру `u₀ = -1`.

- **Крок 1**: Стан `r₀ = 4, r₁ = -4`.
  - Число `r₀ = 4` парне. Цифра: `u₁ = 0`.
  - Ділення на `τ`: `r₀ = -4 + 1 · (4/2) = -2`, `r₁ = -(4/2) = -2`.
  - Записано цифру `u₁ = 0`.

- **Крок 2**: Стан `r₀ = -2, r₁ = -2`.
  - Число `r₀ = -2` парне. Цифра: `u₂ = 0`.
  - Ділення на `τ`: `r₀ = -2 + 1 · (-2/2) = -3`, `r₁ = -(-2/2) = 1`.
  - Записано цифру `u₂ = 0`.

- **Крок 3**: Стан `r₀ = -3, r₁ = 1`.
  - Число `r₀ = -3` непарне. Вираз `(r₀ - 2·r₁) = -3 - 2 = -5 ≡ 3 (mod 4)`.
  - Цифра: `u₃ = 2 - 3 = -1`.
  - Віднімаємо `u₃`: `r₀ - u₃ = -3 - (-1) = -2`.
  - Ділення на `τ`: `r₀ = 1 + 1 · (-2/2) = 0`, `r₁ = -(-2/2) = 1`.
  - Записано цифру `u₃ = -1`.

- **Крок 4**: Стан `r₀ = 0, r₁ = 1`.
  - Число `r₀ = 0` парне. Цифра: `u₄ = 0`.
  - Ділення на `τ`: `r₀ = 1 + 1 · 0 = 1`, `r₁ = 0`.
  - Записано цифру `u₄ = 0`.

- **Крок 5**: Стан `r₀ = 1, r₁ = 0`.
  - Число `r₀ = 1` непарне. `(r₀ - 2·r₁) = 1 ≡ 1 (mod 4)`.
  - Цифра: `u₅ = 2 - 1 = 1`.
  - Віднімаємо `u₅`: `r₀ - u₅ = 0`.
  - Ділення на `τ`: `r₀ = 0 + 0 = 0`, `r₁ = 0`.
  - Записано цифру `u₅ = 1`.

- **Крок 6**: Стан `r₀ = 0, r₁ = 0`. Алгоритм зупиняється.

Отриманий τ-NAF розклад для `k = 7`:

```
u = [u₅, u₄, u₃, u₂, u₁, u₀] = [1, 0, -1, 0, 0, -1]
```

Перевіримо розклад за степенями `τ`:
`τ⁵ - τ³ - 1 = τ³(τ² - 1) - 1`. Оскільки `τ² = τ - 2`, маємо `τ² - 1 = τ - 3`.
`τ³(τ - 3) - 1 = τ⁴ - 3τ³ - 1 = (τ - 2)² - 3(τ² - 2τ) - 1 = 7`.
Рівність виконується абсолютно точно.

### 5. Поліноміальний проти нормального базису для обчислення Фробеніуса

Для апаратної та програмної реалізації поля `GF(2ᵐ)` критично важливим є спосіб кодування польових елементів:

1. **Поліноміальний базис** `{1, x, x², …, xᵐ⁻¹}`: польовий елемент подається як бітовий масив коефіцієнтів многочлена `A(x) = ∑ aᵢ · xⁱ`. Піднесення до квадрата полягає у вставленні нульового біта між кожними двома бітами вихідного числа (розрідження бітів, bit-dilation) з подальшим зведенням за модулем незвідного многочлена `f(x)`. Завдяки табличній попередній редукції операція виконується за кілька десятків тактів процесора.
2. **Нормальний базис** `{β, β², β⁴, β⁸, …, β^(2ᵐ⁻¹)}`: польовий елемент подається як лінійна комбінація послідовних квадратів примітивного елемента `β`. У цьому базисі операція піднесення до квадрата є точним **циклічним зсувом бітів у регістрі**:
   ```
   (∑ cᵢ · β^(2ⁱ))² = ∑ cᵢ · β^(2ⁱ⁺¹) = c_{m-1}·β + c₀·β² + c₁·β⁴ + … + c_{m-2}·β^(2ᵐ⁻¹)
   ```
   В апаратних мікросхемах FPGA/ASIC циклічний зсув виконується нульовою кількістю логічних вентилів через просте перепідключення провідників, що робить операцію Фробеніуса повністю безкоштовною за часом та енергоспоживанням.

### 6. Проєктивні координати Лопеса — Дахаба

У реальних криптосистемах обчислення в афінних координатах вимагають знаходження оберненого елемента (інверсії в полі) на кожному кроці додавання точок. Оскільки операція інверсії в полі за алгоритмом Евкліда вимагає приблизно в 5–10 разів більше часу, ніж польове множення, точки кривої подають у спеціальних **проєктивних координатах Лопеса — Дахаба** (англ. *López-Dahab projective coordinates*).

Точка кривої подається трійкою координат `(X : Y : Z)`, де відновлення афінних координат здійснюється за правилом:

```
x = X / Z,      y = Y / Z²
```

Підстановка цих співвідношень у рівняння кривої Кобліца дає проєктивне рівняння:

```
Y² + X·Y·Z = X³·Z + a·X²·Z² + Z⁴
```

Нейтральна точка на нескінченності подається трійкою `(1 : 0 : 0)`.

Головна перевага координат Лопеса — Дахаба полягає в тому, що ендоморфізм Фробеніуса та додавання точок виконуються повністю без інверсій:
- Дія автоморфізму Фробеніуса: `τ(X : Y : Z) = (X² : Y² : Z²)`. Усі три координати підносяться до квадрата окремо.
- Додавання афінної точки `P = (x, y)` до проєктивної точки `Q = (X₁ : Y₁ : Z₁)` вимагає лише 8 множень та 5 піднесень до квадрата у полі без жодного ділення.
- Єдина інверсія в полі виконується лише один раз наприкінці всього скалярного множення для повернення результату в афінні координати.

### 7. Віконний метод w-τ-NAF для максимальної швидкості

Для подальшого прискорення скалярного множення застосовують узагальнення алгоритму — **віконний метод** (англ. *windowed τ-NAF*, w-τ-NAF).

У віконному методі з шириною вікна `w` скаляр розкладається за основою `τ` з коефіцієнтами з розширеної множини непарних елементів кільця `ℤ[τ]`:

```
k = ∑ᵢ uᵢ · τⁱ,     де uᵢ ∈ {0, ±α₁, ±α₂, …, ±α_{2^(w-1) - 1}}
```

де `α_j` — попередньо обчислені непарні елементи кільця `ℤ[τ]` з мінімальною нормою. Умова несусідності узагальнюється: серед будь-яких `w` послідовних цифр розкладу міститься не більше однієї ненульової цифри:

```
якщо uᵢ ≠ 0, то u_{i+1} = u_{i+2} = … = u_{i+w-1} = 0
```

Щільність ненульових цифр у `w`-τ-NAF розкладі падає до `1 / (w + 1)`. Наприклад, при виборі ширини вікна `w = 4`:
- Щільність ненульових цифр становить лише `1 / 5 = 20%`.
- Для стандартної кривої `sect233k1` (233 біти) загальна кількість додавань точок зменшується зі 116 до приблизно 47 операцій!
- Усі проміжні подвоєння повністю замінюються швидкими піднесеннями координат до квадрата.

### 8. Апаратна мікроархітектура та порівняння криптопроцесорів

При проектуванні криптографічних співпроцесорів для смарт-карт та апаратних модулів безпеки (HSM) використання кривих Кобліца забезпечує радикальну економію кремнієвої площі та енергії.

Типова мікроархітектура апаратного рушія Кобліца містить:
1. **Зсувний конвеєр Фробеніуса**: 233-бітний регістр з циклічним перекомутуванням ліній для реалізації операції `τ` за 1 такт.
2. **Сегментований помножувач Каратсуби**: обчислює добуток у полі `GF(2²³³)` за 4–7 тактів замість 233 тактів послідовного зсуву.
3. **Блок інверсії Іто — Цудзі (Itoh-Tsujii)**: знаходить обернений елемент `a⁻¹ = a^(2ᵐ - 2)` виключно через ланцюжок піднесень до квадрата (Фробеніус) та множень у полі.

Порівняння реалізацій на кристалі FPGA (Xilinx Artix-7) для різних стандартів безпеки NIST/SECG:
- Крива `sect163k1` (80-бітний рівень стійкості): ~1850 LUTs, час множення 14.2 мкс при частоті 150 МГц.
- Крива `sect233k1` (112-бітний рівень стійкості): ~2640 LUTs, час множення 28.6 мкс при частоті 140 МГц.
- Крива `sect283k1` (128-бітний рівень стійкості): ~3410 LUTs, час множення 42.1 мкс при частоті 135 МГц.
- Крива `sect571k1` (256-бітний рівень стійкості): ~7800 LUTs, час множення 138.4 мкс при частоті 110 МГц.

Порівняно з кривими над простими полями `secp256k1` тієї самої стійкості, криві Кобліца вимагають у 3.2 раза менше логічних вентилів та споживають у 4 рази менше мікроджоулів енергії на один цифровий підпис. На вбудованих мікроконтролерах ARM Cortex-M4 та процесорах Intel x86_64 для захисту від атак сторонніми каналами застосовують інструкції умовного пересилання даних без розгалужень (`CSEL` та `CMOV`), забезпечуючи сталий час обчислень незалежно від ваги Хеммінга приватного ключа.

У промислових смарт-картах стандарту EMV та захищених мікроконтролерах захист від диференційного аналізу потужності (DPA) доповнюють рандомізацією координат Лопеса — Дахаба: точка `(X, Y, Z)` перед початком скалярного множення перетворюється у випадково масштабовану еквівалентна трійку `(λ · X, λ² · Y, λ · Z)` для випадкового ненульового елемента `λ ∈ GF(2ᵐ)`. Оскільки всі внутрішні координати набувають випадкових значень під час кожного запуску, спектр споживання струму повністю згладжується, унеможливлюючи відновлення бітів секретного ключа.

### 9. Повна еталонна реалізація алгоритму на C та C++

Нижче наведено завершену реалізацію арифметики кривої Кобліца `y² + xy = x³ + x² + 1` (`a = 1, μ = 1`) над полем `GF(2⁴)` з незвідним многочленом `f(x) = x⁴ + x + 1`. Реалізація містить функції множення та піднесення до квадрата у полі, групове додавання точок, обчислення τ-NAF розкладу скаляра та функцію швидкого множення без подвоєння точок.

#include <stdio.h>
#include <stdint.h>
#include <stdbool.h>
#include <stdlib.h>

/* Незвідний многочлен x⁴ + x + 1 (маска 0x13 = 10011₂) для поля GF(2⁴) */
#define POLY_GF16 0x13
#define FIELD_MASK 0x0F

/* Множення двох елементів у полі GF(2⁴) */
static uint8_t gf16_mul(uint8_t a, uint8_t b) {
    uint8_t res = 0;
    a &= FIELD_MASK;
    b &= FIELD_MASK;
    while (b > 0) {
        if (b & 1) {
            res ^= a;
        }
        bool carry = (a & 0x08) != 0;
        a = (a << 1) & FIELD_MASK;
        if (carry) {
            a ^= (POLY_GF16 & FIELD_MASK);
        }
        b >>= 1;
    }
    return res;
}

/* Піднесення до квадрата у GF(2⁴) — оператор Фробеніуса для поля */
static uint8_t gf16_sqr(uint8_t a) {
    return gf16_mul(a, a);
}

/* Обернений елемент у GF(2⁴) за малою теоремою Ферма: a⁻¹ = a¹⁴ */
static uint8_t gf16_inv(uint8_t a) {
    if (a == 0) return 0;
    uint8_t a2 = gf16_sqr(a);
    uint8_t a4 = gf16_sqr(a2);
    uint8_t a8 = gf16_sqr(a4);
    /* a¹⁴ = a⁸ · a⁴ · a² */
    return gf16_mul(a8, gf16_mul(a4, a2));
}

/* Точка на кривій Кобліца y² + xy = x³ + x² + 1 над GF(2⁴) */
typedef struct {
    uint8_t x;
    uint8_t y;
    bool is_infinity;
} Point;

static const Point POINT_INFINITY = {0, 0, true};

/* Перевірка рівності двох точок */
static bool point_equals(Point p1, Point p2) {
    if (p1.is_infinity && p2.is_infinity) return true;
    if (p1.is_infinity || p2.is_infinity) return false;
    return (p1.x == p2.x) && (p1.y == p2.y);
}

/* Протилежна точка на двійковій кривій: -P = (x, x + y) */
static Point point_negate(Point p) {
    if (p.is_infinity) return p;
    Point res;
    res.x = p.x;
    res.y = p.x ^ p.y;
    res.is_infinity = false;
    return res;
}

/* Ендоморфізм Фробеніуса на точці кривої: τ(x, y) = (x², y²) */
static Point point_frobenius(Point p) {
    if (p.is_infinity) return p;
    Point res;
    res.x = gf16_sqr(p.x);
    res.y = gf16_sqr(p.y);
    res.is_infinity = false;
    return res;
}

/* Геометричне додавання двох точок на кривій Кобліца */
static Point point_add(Point p1, Point p2) {
    if (p1.is_infinity) return p2;
    if (p2.is_infinity) return p1;

    /* Випадок P1 == -P2 або P1 == P2 */
    if (p1.x == p2.x) {
        if (p1.y != p2.y || p1.x == 0) {
            return POINT_INFINITY;
        }
        /* Подвоєння точки: λ = x + y / x */
        uint8_t lambda = p1.x ^ gf16_mul(p1.y, gf16_inv(p1.x));
        uint8_t x3 = gf16_sqr(lambda) ^ lambda ^ 1; /* a = 1 */
        uint8_t y3 = gf16_mul(lambda, p1.x ^ x3) ^ x3 ^ p1.y;
        Point res = {x3, y3, false};
        return res;
    }

    /* Додавання різних точок: λ = (y1 + y2) / (x1 + x2) */
    uint8_t dx = p1.x ^ p2.x;
    uint8_t dy = p1.y ^ p2.y;
    uint8_t lambda = gf16_mul(dy, gf16_inv(dx));
    uint8_t x3 = gf16_sqr(lambda) ^ lambda ^ dx ^ 1; /* a = 1 */
    uint8_t y3 = gf16_mul(lambda, p1.x ^ x3) ^ x3 ^ p1.y;

    Point res = {x3, y3, false};
    return res;
}

/* Обчислення τ-NAF розкладу для скаляра k на кривій з μ = 1 */
static int compute_tau_naf(int k, int8_t *u_out, int max_len) {
    int r0 = k;
    int r1 = 0;
    int len = 0;
    const int mu = 1;

    while ((r0 != 0 || r1 != 0) && len < max_len) {
        if (r0 % 2 != 0) {
            int val = 2 - ((r0 - 2 * r1) % 4);
            if (val < -1) val += 4;
            if (val > 1)  val -= 4;
            u_out[len] = (int8_t)val;
            r0 -= val;
        } else {
            u_out[len] = 0;
        }
        int next_r0 = r1 + mu * (r0 / 2);
        int next_r1 = - (r0 / 2);
        r0 = next_r0;
        r1 = next_r1;
        len++;
    }
    return len;
}

/* Швидке скалярне множення через τ-NAF розклад Фробеніуса (нуль подвоєнь точок) */
static Point scalar_mul_tau_naf(Point p, int k) {
    if (k == 0 || p.is_infinity) return POINT_INFINITY;
    int8_t u[64];
    int len = compute_tau_naf(k, u, 64);

    Point q = POINT_INFINITY;
    for (int i = len - 1; i >= 0; i--) {
        q = point_frobenius(q); /* τ(Q) — піднесення координат до квадрата замість подвоєння */
        if (u[i] == 1) {
            q = point_add(q, p);
        } else if (u[i] == -1) {
            q = point_add(q, point_negate(p));
        }
    }
    return q;
}

int main(void) {
    /* Базова точка на кривій y² + xy = x³ + x² + 1 над GF(2⁴): P = (2, 8) */
    Point p = {2, 8, false};
    int k = 7;

    int8_t u[64];
    int naf_len = compute_tau_naf(k, u, 64);

    printf("Скаляр k = %d у τ-NAF поданні:\n", k);
    printf("u = [ ");
    for (int i = naf_len - 1; i >= 0; i--) {
        printf("%d ", u[i]);
    }
    printf("] (довжина розкладу: %d)\n", naf_len);

    Point res = scalar_mul_tau_naf(p, k);
    printf("Результат скалярного множення %d · P = (%d, %d)\n", k, res.x, res.y);

    return 0;
}

#include <iostream>
#include <vector>
#include <array>
#include <optional>
#include <span>
#include <cstdint>

namespace koblitz {

// Арифметика поля GF(2⁴) з незвідним многочленом x⁴ + x + 1 (маска 0x13)
class Field16 {
public:
    static constexpr uint8_t Poly = 0x13;
    static constexpr uint8_t Mask = 0x0F;

    static constexpr uint8_t add(uint8_t a, uint8_t b) noexcept {
        return (a ^ b) & Mask;
    }

    static uint8_t mul(uint8_t a, uint8_t b) noexcept {
        uint8_t res = 0;
        a &= Mask;
        b &= Mask;
        while (b > 0) {
            if (b & 1) {
                res ^= a;
            }
            bool carry = (a & 0x08) != 0;
            a = (a << 1) & Mask;
            if (carry) {
                a ^= (Poly & Mask);
            }
            b >>= 1;
        }
        return res;
    }

    // Оператор Фробеніуса для поля: піднесення до квадрата z ↦ z²
    static uint8_t sqr(uint8_t a) noexcept {
        return mul(a, a);
    }

    // Знаходження оберненого елемента a¹⁴ = a⁻¹ за малою теоремою Ферма
    static uint8_t inv(uint8_t a) noexcept {
        if (a == 0) return 0;
        uint8_t a2 = sqr(a);
        uint8_t a4 = sqr(a2);
        uint8_t a8 = sqr(a4);
        return mul(a8, mul(a4, a2));
    }
};

// Точка на кривій Кобліца y² + xy = x³ + x² + 1 над GF(2⁴)
struct Point {
    uint8_t x{0};
    uint8_t y{0};
    bool is_infinity{true};

    static Point infinity() noexcept {
        return Point{0, 0, true};
    }

    static Point affine(uint8_t x_val, uint8_t y_val) noexcept {
        return Point{x_val, y_val, false};
    }

    bool operator==(const Point& other) const noexcept {
        if (is_infinity && other.is_infinity) return true;
        if (is_infinity || other.is_infinity) return false;
        return x == other.x && y == other.y;
    }

    // Протилежна точка на двійковій кривій: -P = (x, x + y)
    Point operator-() const noexcept {
        if (is_infinity) return *this;
        return Point::affine(x, Field16::add(x, y));
    }

    // Дія автоморфізму Фробеніуса: τ(x, y) = (x², y²)
    Point frobenius() const noexcept {
        if (is_infinity) return *this;
        return Point::affine(Field16::sqr(x), Field16::sqr(y));
    }

    // Додавання точок на кривій Кобліца
    Point operator+(const Point& other) const noexcept {
        if (is_infinity) return other;
        if (other.is_infinity) return *this;

        if (x == other.x) {
            if (y != other.y || x == 0) {
                return Point::infinity();
            }
            // Подвоєння точки: λ = x + y / x
            uint8_t lambda = Field16::add(x, Field16::mul(y, Field16::inv(x)));
            uint8_t x3 = Field16::add(Field16::add(Field16::sqr(lambda), lambda), 1);
            uint8_t y3 = Field16::add(Field16::add(Field16::mul(lambda, Field16::add(x, x3)), x3), y);
            return Point::affine(x3, y3);
        }

        uint8_t dx = Field16::add(x, other.x);
        uint8_t dy = Field16::add(y, other.y);
        uint8_t lambda = Field16::mul(dy, Field16::inv(dx));
        uint8_t x3 = Field16::add(Field16::add(Field16::add(Field16::sqr(lambda), lambda), dx), 1);
        uint8_t y3 = Field16::add(Field16::add(Field16::mul(lambda, Field16::add(x, x3)), x3), y);

        return Point::affine(x3, y3);
    }
};

// Обчислення τ-NAF розкладу скаляра k (μ = 1 для кривої з параметром a = 1)
inline std::vector<int8_t> compute_tau_naf(int k) {
    std::vector<int8_t> naf;
    int r0 = k;
    int r1 = 0;
    constexpr int mu = 1;

    while (r0 != 0 || r1 != 0) {
        if (r0 % 2 != 0) {
            int val = 2 - ((r0 - 2 * r1) % 4);
            if (val < -1) val += 4;
            if (val > 1)  val -= 4;
            naf.push_back(static_cast<int8_t>(val));
            r0 -= val;
        } else {
            naf.push_back(0);
        }
        int next_r0 = r1 + mu * (r0 / 2);
        int next_r1 = -(r0 / 2);
        r0 = next_r0;
        r1 = next_r1;
    }
    return naf;
}

// Скалярне множення через автоморфізм Фробеніуса (нуль подвоєнь точок)
inline Point scalar_mul_tau_naf(const Point& p, int k) {
    if (k == 0 || p.is_infinity) {
        return Point::infinity();
    }
    const auto naf = compute_tau_naf(k);
    Point q = Point::infinity();

    for (auto it = naf.rbegin(); it != naf.rend(); ++it) {
        q = q.frobenius(); // Заміна операції подвоєння точки на піднесення до квадрата
        if (*it == 1) {
            q = q + p;
        } else if (*it == -1) {
            q = q + (-p);
        }
    }
    return q;
}

    }
    std::cout << "] (довжина розкладу: " << naf.size() << ")\n";

    const Point res = scalar_mul_tau_naf(p, k);
    std::cout << "Результат скалярного множення " << k << " · P = (" 
              << static_cast<int>(res.x) << ", " 
              << static_cast<int>(res.y) << ")\n";

    return 0;
}

### 10. Захист від атак сторонніми каналами та підсумкова ефективність

При практичному розгортанні криптографічних протоколів на кривих Кобліца розробники повинні враховувати вразливість базового алгоритму τ-NAF до атак сторонніми каналами за часом виконання (timing attacks) та енергоспоживанням (Simple Power Analysis, SPA). Оскільки стандартний розклад τ-NAF має змінну довжину залежно від значення скаляра `k`, а операція додавання точки викликається лише для ненульових розрядів `uᵢ ≠ 0`, зловмисник може відновити біти приватного ключа шляхом вимірювання часу обчислень або профілю споживання струму процесором.

Для захисту від таких атак застосовують спеціальні модифікації алгоритму:

1. **Регулярні віконні форми (Fixed-length w-τ-NAF)**: скаляр `k` розкладається на фіксовану кількість цифр із попередньо обчисленою таблицею кратних точок, де на кожному кроці циклу гарантовано виконується однаковий набір операцій.
2. **Алгоритм «драбини Монтгомері» для кривих Кобліца**: на кожній ітерації одночасно обчислюються операція Фробеніуса та умовне додавання за допомогою маскованих порожніх операцій (dummy operations) без розгалужень у коді.

Порівняння обчислювальної складності множення точки на 256-бітний скаляр показує разючу перевагу методу Кобліца:

1. **Класичний двійковий Double-and-Add**:
   - 256 операцій подвоєння точок `[2]Q`
   - ~128 операцій додавання точок `Q + P`
   - Загальна вартість: `256 · (1I + 2M + 1S) + 128 · (1I + 2M) ≈ 384 I + 768 M` (де `I` — інверсія, `M` — множення, `S` — піднесення до квадрата).

2. **Тау-адичний розклад Кобліца (τ-NAF)**:
   - **0 операцій подвоєння точок!**
   - 256 застосувань автоморфізму Фробеніуса `τ(Q) = (x², y²)` (у нормальному базисі — 0 або 1 такт CPU на регістровий зсув).
   - Лише ~85 операцій додавання/віднімання точок `Q ± P` (завдяки зниженій щільності ненульових цифр `1/3`).
   - Загальна вартість: `85 · (1I + 2M) ≈ 85 I + 170 M`.

Застосування автоморфізму Фробеніуса скорочує сумарну кількість важких польових множень та інверсій більш ніж у **4.5 раза**, перетворюючи криві Кобліца на один із найшвидших стандартизованих криптографічних інструментів у стандартах NIST та SECG (криві Sect233k1, Sect283k1, Sect409k1, Sect571k1).
