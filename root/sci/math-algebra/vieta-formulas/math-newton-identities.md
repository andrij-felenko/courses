# 🧮 Виведення тотожностей Ньютона — Жирара

У багатьох розділах теоретичної фізики, спектрального аналізу матриць, теорії графів та цифрової обробки сигналів виникає фундаментальна потреба обчислити суму однакових степенів коренів алгебраїчного многочлена без попереднього знаходження самих коренів. Якщо початковий многочлен має високий степінь (п'ятий і вище), знайти його корені у замкненій аналітичній формі через радикали неможливо за теоремою Абеля — Руффіні, а прямі чисельні методи пошуку коренів призводять до неминучого накопичення похибок округлення та катастрофічної втрати точності. Тотожності Ньютона — Жирара (англ. *Newton's identities*, *Newton–Girard formulas*) встановлюють точний рекурентний міст між сумами степенів коренів та елементарними симетричними многочленами, дозволяючи обчислювати довільні степені коренів суто через вихідні коефіцієнти рівняння за допомогою елементарних арифметичних операцій.

## 1. Позначення та постановка задачі

Візьмімо довільний приведений многочлен `P(x)` степеня `n` з комплексними або дійсними коефіцієнтами, старший коефіцієнт якого перед найвищим степенем дорівнює одиниці:

```
P(x) = xⁿ − e₁ xⁿ⁻¹ + e₂ xⁿ⁻² − e₃ xⁿ⁻³ + ... + (−1)ⁿ eₙ
```

де літерою `x` позначено незалежну комплексну або дійсну змінну, число `n` є натуральним степенем многочлена, а коефіцієнти `e₁, e₂, ..., eₙ` є елементарними симетричними многочленами від коренів `r₁, r₂, ..., rₙ`.

Кожен елементарний симетричний многочлен `eₖ` утворюється як сума всіх можливих добутків по `k` різних коренів без урахування порядку множників:

```
e₁ = r₁ + r₂ + ... + rₙ = ∑ rᵢ
e₂ = ∑ rᵢ rⱼ  (для всіх пар 1 ≤ i < j ≤ n)
e₃ = ∑ rᵢ rⱼ rₖ  (для всіх трійок 1 ≤ i < j < k ≤ n)
...
eₙ = r₁ r₂ ... rₙ
```

Загальна кількість доданків у многочлені `eₖ` дорівнює комбінаторному числу сполучень `C(n, k) = n! / (k! · (n − k)!)`.

Визначимо суму `k`-х степенів коренів і позначимо її символом `sₖ` (від англійського *sum* або латинського *summa*):

```
sₖ = r₁ᵏ + r₂ᵏ + r₃ᵏ + ... + rₙᵏ = ∑ᵢ₌₁ⁿ rᵢᵏ
```

Для нульового показника степеня `k = 0` кожен окремий доданок `rᵢ⁰` дорівнює одиниці (для будь-якого ненульового кореня `rᵢ`), тому сума нульових степенів строго дорівнює кількості коренів многочлена:

```
s₀ = r₁⁰ + r₂⁰ + ... + rₙ⁰ = 1 + 1 + ... + 1 = n
```

Суми степенів мають прямий фізичний та математичний зміст:
- **У лінійній алгебрі:** Якщо `r₁, ..., rₙ` є власними значеннями квадратної матриці `A` розміру `n × n`, то сума `sₖ` дорівнює сліду `k`-го степеня матриці `A`: `sₖ = tr(Aᵏ)`.
- **У теорії ймовірностей та статистиці:** Величини `sₖ` пропорційні вибірковим моментам розподілу даних.
- **У цифровій обробці інформації та теорії кодування:** Суми степенів виникають як синдроми помилок у кодах Ріда — Соломона та БЧХ.

Задача полягає в тому, щоб вивести точну рекурентну залежність, яка дозволяє обчислювати послідовність `s₁, s₂, s₃, ...` безпосередньо через коефіцієнти `e₁, e₂, ..., eₙ`.

## 2. Алгебраїчний контекст: п'ять базисів простору симетричних многочленів

У вищій алгебрі та теорії представлень многочлени від `n` змінних `r₁, ..., rₙ`, які не змінюються при будь-якій перестановці змінних, утворюють градуйоване комутативне кільце `Λₙ`. У цьому кільці існують п'ять фундаментальних лінійних базисів над полем раціональних чисел:

1. **Елементарні симетричні многочлени `eₖ`:** добутки без повторення змінних.
2. **Степеневі суми `sₖ` (або `pₖ`):** суми однакових степенів коренів.
3. **Повні однорідні симетричні многочлени `hₖ`:** суми всіх можливих мономів степеня `k` з повтореннями.
4. **Мономіальні симетричні многочлени `m_λ`:** суми мономів, породжені розбиттям числа `k`.
5. **Многочлени Шура `s_λ`:** характери незвідних зображень загальної лінійної групи `GL(n)`.

Тотожності Ньютона — Жирара виступають формулами переходу між базисом елементарних многочленів `eₖ` та базисом степеневих сум `sₖ`.

## 3. Аналітичне виведення через твірні функції та похідну

Найглибший спосіб виведення тотожностей Ньютона базується на апараті твірних функцій та логарифмічному диференціюванні многочлена. Цей підхід розкриває внутрішню аналітичну природу симетрії без громіздких комбінаторних переборів.

За основною теоремою алгебри приведений многочлен `P(x)` розкладається на добуток `n` лінійних множників:

```
P(x) = (x − r₁) · (x − r₂) · (x − r₃) · ... · (x − rₙ)
```

Знайдемо першу похідну многочлена `P'(x)` за змінною `x`. За правилом Лейбніца для диференціювання добутку кількох функцій похідна дорівнює сумі добутків, у кожному з яких диференціюється рівно один лінійний множник:

```
P'(x) = ∑ᵢ₌₁ⁿ ∏ⱼ≠ᵢ (x − rⱼ)
```

Поділимо обидві частини рівності на вихідний многочлен `P(x)`. Оскільки кожен доданок у сумі ділиться на повний добуток усіх `n` множників, у ньому скорочуються всі множники, крім єдиної дужки `(x − rᵢ)`:

```
P'(x) / P(x) = ∑ᵢ₌₁ⁿ 1 / (x − rᵢ)
```

Цей вираз є сумою простих дробів. Розглянемо один окремий дріб `1 / (x − rᵢ)` і винесемо змінну `x` за дужки в знаменнику:

```
1 / (x − rᵢ)
= (1 / x) · (1 / (1 − rᵢ / x))                 [винесення x за дужки]
= (1 / x) · ∑ₘ₌₀^∞ (rᵢ / x)ᵐ                  [розклад у суму нескінченної геометричної прогресії]
= ∑ₘ₌₀^∞ rᵢᵐ · x⁻ᵐ⁻¹                           [внесення 1/x під знак суми]
= x⁻¹ + rᵢ x⁻² + rᵢ² x⁻³ + rᵢ³ x⁻⁴ + ...
```

Підставимо отриманий степеневий ряд для кожного кореня `rᵢ` у загальну суму дробів для відношення `P'(x) / P(x)`:

```
P'(x) / P(x)
= ∑ᵢ₌₁ⁿ (∑ₘ₌₀^∞ rᵢᵐ · x⁻ᵐ⁻¹)                  [підстановка розкладу кожного дробу]
= ∑ₘ₌₀^∞ (∑ᵢ₌₁ⁿ rᵢᵐ) · x⁻ᵐ⁻¹                  [зміна порядку сумування]
= ∑ₘ₌₀^∞ sₘ · x⁻ᵐ⁻¹                            [заміна внутрішньої суми на sₘ за означенням]
= s₀ x⁻¹ + s₁ x⁻² + s₂ x⁻³ + s₃ x⁻⁴ + ...
```

Ми отримали представлення логарифмічної похідної многочлена `P(x)` у вигляді твірної функції для сум степенів `sₘ`.

Тепер помножимо обидві частини отриманої тотожності на многочлен `P(x)`:

```
P'(x) = P(x) · (s₀ x⁻¹ + s₁ x⁻² + s₂ x⁻³ + s₃ x⁻⁴ + ...)
```

Розпишемо ліву та праву частини цієї рівності через коефіцієнти `eᵢ`:

Ліва частина рівності є звичайною похідною степеневого многочлена:
```
P'(x) = n xⁿ⁻¹ − (n − 1) e₁ xⁿ⁻² + (n − 2) e₂ xⁿ⁻³ − ... + (−1)ᵏ (n − k) eₖ xⁿ⁻ᵏ⁻¹ + ...
```

Права частина рівності є добутком многочлена на нескінченний ряд:
```
P(x) · ∑ₘ₌₀^∞ sₘ x⁻ᵐ⁻¹
= (xⁿ − e₁ xⁿ⁻¹ + e₂ xⁿ⁻² − e₃ xⁿ⁻³ + ... + (−1)ⁿ eₙ) · (s₀ x⁻¹ + s₁ x⁻² + s₂ x⁻³ + ...)
```

Перемножимо ці два вирази за дистрибутивним законом алгебри та згрупуємо доданки при однакових степенях змінної `x`.

### Покрокове прирівнювання коефіцієнтів

Прирівняємо коефіцієнти при однакових степенях `x` у лівій та правій частинах:

**1. Коефіцієнт при `xⁿ⁻¹`:**
```
Ліва частина:   n
Права частина:  s₀ · 1 = n · 1 = n               [тотожність n = n, оскільки s₀ = n]
```

**2. Коефіцієнт при `xⁿ⁻²`:**
```
Ліва частина:   −(n − 1) e₁ = −n e₁ + e₁
Права частина:  s₁ · 1 − e₁ · s₀ = s₁ − n e₁
Прирівнюємо:
−n e₁ + e₁ = s₁ − n e₁
s₁ − e₁ = 0
s₁ = e₁                                          [перша тотожність Ньютона]
```

**3. Коефіцієнт при `xⁿ⁻³`:**
```
Ліва частина:   (n − 2) e₂ = n e₂ − 2 e₂
Права частина:  s₂ · 1 − e₁ · s₁ + e₂ · s₀ = s₂ − e₁ s₁ + n e₂
Прирівнюємо:
n e₂ − 2 e₂ = s₂ − e₁ s₁ + n e₂
−2 e₂ = s₂ − e₁ s₁
s₂ − e₁ s₁ + 2 e₂ = 0
s₂ = e₁ s₁ − 2 e₂                                [друга тотожність Ньютона]
```

**4. Коефіцієнт при `xⁿ⁻⁴`:**
```
Ліва частина:   −(n − 3) e₃ = −n e₃ + 3 e₃
Права частина:  s₃ · 1 − e₁ · s₂ + e₂ · s₁ − e₃ · s₀ = s₃ − e₁ s₂ + e₂ s₁ − n e₃
Прирівнюємо:
−n e₃ + 3 e₃ = s₃ − e₁ s₂ + e₂ s₁ − n e₃
3 e₃ = s₃ − e₁ s₂ + e₂ s₁
s₃ − e₁ s₂ + e₂ s₁ − 3 e₃ = 0
s₃ = e₁ s₂ − e₂ s₁ + 3 e₃                        [третя тотожність Ньютона]
```

Простежимо загальну закономірність для довільного номера `k ≤ n`. Прирівнюючи коефіцієнти при степені `xⁿ⁻ᵏ⁻¹`, член `n eₖ` скорочується з обох боків рівності завдяки присутності `s₀ = n`, залишаючи множник `k eₖ`:

```
sₖ − e₁ sₖ₋₁ + e₂ sₖ₋₂ − e₃ sₖ₋₃ + ... + (−1)ᵏ⁻¹ eₖ₋₁ s₁ + (−1)ᵏ k eₖ = 0
```

Виразивши шукану величину `sₖ`, маємо загальну формулу Ньютона — Жирара:

```
sₖ = e₁ sₖ₋₁ − e₂ sₖ₋₂ + e₃ sₖ₋₃ − ... + (−1)ᵏ eₖ₋₁ s₁ + (−1)ᵏ⁻¹ k eₖ   (для 1 ≤ k ≤ n)
```

## 4. Зв'язок із контурними інтегралами Коші та принципом аргументу

В комплексному аналізі логарифмічна похідна `P'(z) / P(z)` має винятково прості полюси першого порядку в кожному з нулів (коренів) многочлена `rᵢ`, причому лишок (res) у кожному такому полюсі строго дорівнює алгебраїчній кратності відповідного кореня. За класичною інтегральною теоремою Коші про лишки, якщо замкнений контур `Γ` у комплексній площині охоплює всі корені многочлена `P(z)` у додатній орієнтації проти годинникової стрілки, то контурний інтеграл від добутку `zᵏ · (P'(z) / P(z))` дає пряме аналітичне інтегральне представлення сум степенів:

```
sₖ = (1 / 2πi) ∮_Γ zᵏ · (P'(z) / P(z)) dz
```

Якщо розкласти раціональний дріб `P'(z) / P(z)` у ряд Лорана в околі нескінченно віддаленої точки та проінтегрувати кожен моном почленно, отримуємо тотожності Ньютона безпосередньо з інтегральної формули Коші. Це вибудовує глибокий міст між дискретною симетричною алгеброю та геометричною топологією контурного інтегрування в комплексному просторі.

## 5. Індуктивне алгебраїчне доведення без похідних

Для глибшого розуміння розглянемо друге, суто алгебраїчне доведення тотожностей Ньютона, яке спирається на розбиття симетричних сум на частини.

Розглянемо добуток елементарного многочлена `eₖ` на суму перших степенів `s₁ = ∑ rᵢ`:

```
eₖ · s₁ = (∑ r_{i₁} r_{i₂} ... r_{iₖ}) · (∑ rⱼ)
```

Розкриваючи дужки, кожен моном `r_{i₁} ... r_{iₖ}` множиться на кожен доданок `rⱼ`:
1. Якщо індекс `j` входить до набору `{i₁, ..., iₖ}`, утворюється моном, у якому одна зі змінних піднесена до квадрата: `r_{i₁}² r_{i₂} ... r_{iₖ}`. Позначимо суму всіх таких мономів як `M_{2, 1, ..., 1}`.
2. Якщо індекс `j` не входить до набору `{i₁, ..., iₖ}`, утворюється моном із `k + 1` різними змінними: `r_{i₁} ... r_{iₖ} rⱼ`. Кожен такий моном утворюється `k + 1` різними способами (приєднуючи будь-яку з `k + 1` змінних до решти `k`), тому їхня сума дорівнює `(k + 1) e_{k+1}`.

Отримуємо фундаментальне розщеплення:

```
eₖ · s₁ = M_{2, 1, ..., 1} + (k + 1) e_{k+1}
```

Аналогічно перемножуючи `e_{k-1} · s₂`, ми отримуємо зв'язок між мономом `M_{2, 1, ..., 1}` та добутками вищих степенів. Складаючи знакозмінну суму добутків `eₖ s₁ − e_{k-1} s₂ + e_{k-2} s₃ − ...`, усі проміжні комбінаторні мономи взаємно знищуються завдяки біноміальним коефіцієнтам, залишаючи в залишку виключно чисту степеневу суму `s_{k+1}` та член `(k + 1) e_{k+1}`.

Це алгебраїчне доведення показує, що тотожності Ньютона справедливі не лише над полем дійсних чи комплексних чисел, але й у будь-якому абстрактному комутативному кільці з одиницею.

## 6. Виведення для вищих степенів (k > n)

Коли показник степеня `k` строго більший за степінь многочлена `n` (`k > n`), елементарні симетричні многочлени `eₖ` для `k > n` за означенням дорівнюють нулю (`eₖ = 0`), оскільки неможливо обрати більше ніж `n` множників із `n` наявних коренів.

Для виведення формули при `k ≥ n` застосуємо прямий алгебраїчний підхід. За означенням кореня кожне число `rᵢ` перетворює многочлен на нуль:

```
rᵢⁿ − e₁ rᵢⁿ⁻¹ + e₂ rᵢⁿ⁻² − ... + (−1)ⁿ eₙ = 0
```

Помножимо цю тотожність на степінь `rᵢᵏ⁻ⁿ` (де `k ≥ n`):

```
rᵢᵏ − e₁ rᵢᵏ⁻¹ + e₂ rᵢᵏ⁻² − ... + (−1)ⁿ eₙ rᵢᵏ⁻ⁿ = 0
```

Просумуємо отримані рівності для всіх `n` коренів від `i = 1` до `i = n`:

```
∑ᵢ₌₁ⁿ rᵢᵏ − e₁ ∑ᵢ₌₁ⁿ rᵢᵏ⁻¹ + e₂ ∑ᵢ₌₁ⁿ rᵢᵏ⁻² − ... + (−1)ⁿ eₙ ∑ᵢ₌₁ⁿ rᵢᵏ⁻ⁿ = 0
```

Оскільки сума `∑ᵢ₌₁ⁿ rᵢᵐ` за означенням є сумою степенів `sₘ`, отримуємо однорідне лінійне рекурентне рівняння зі сталими коефіцієнтами:

```
sₖ − e₁ sₖ₋₁ + e₂ sₖ₋₂ − e₃ sₖ₋₃ + ... + (−1)ⁿ eₙ sₖ₋ₙ = 0   (для всіх k ≥ n)
```

Це означає, що починаючи зі степеня `k = n + 1`, суми степенів `sₖ` обчислюються суто за правилом лінійної рекурентної послідовності довжини `n` без появи додаткових множників `k`.

## 7. Двоїсті тотожності для повних однорідних многочленів h_k

Поряд з елементарними многочленами `eₖ` у теорії симетричних функцій важливу роль відіграють повні однорідні многочлени `hₖ`, які містять усі можливі добутки степеня `k` з повторенням змінних:

```
h₁ = ∑ rᵢ = e₁
h₂ = ∑ rᵢ² + ∑ rᵢ rⱼ
h₃ = ∑ rᵢ³ + ∑ rᵢ² rⱼ + ∑ rᵢ rⱼ rₖ
```

Твірні функції для `eₖ` та `hₖ` пов'язані простим відношенням оберненості: `E(t) · H(−t) = 1`, де `E(t) = ∑ eₖ tᵏ`, а `H(t) = ∑ hₖ tᵏ`.

Диференціюючи логарифм функції `H(t)`, отримуємо двоїсті тотожності Ньютона для повних однорідних многочленів:

```
k hₖ = s₁ hₖ₋₁ + s₂ hₖ₋₂ + s₃ hₖ₋₃ + ... + sₖ h₀
```

Зверніть увагу, що у двоїстих формулах усі знаки є строго додатними, а коефіцієнт `k` стоїть перед старшим членом `hₖ`.

## 8. Обернення формул Ньютона: знаходження e_k за сумами степенів

У багатьох задачах оберненого проектування та декодування виникає протилежна задача: відомі значення сум степенів `s₁, s₂, ..., sₖ`, і потрібно знайти коефіцієнти многочлена `eₖ`.

Перегруповуючи рекурентні тотожності, отримуємо послідовність виразів для `eₖ`:

```
e₁ = s₁
e₂ = (e₁ s₁ − s₂) / 2 = (s₁² − s₂) / 2
e₃ = (e₁ s₂ − e₂ s₁ + s₃) / 3 = (s₁³ − 3 s₁ s₂ + 2 s₃) / 6
e₄ = (e₁ s₃ − e₂ s₂ + e₃ s₁ − s₄) / 4 = (s₁⁴ − 6 s₁² s₂ + 3 s₂² + 8 s₁ s₃ − 6 s₄) / 24
```

У загальному випадку коефіцієнт при довільному розбитті степеня задається явною комбінаторною формулою Едварда Варінга (1762):

```
eₖ = ∑ (−1)^{k − ∑ cᵢ} · (s₁^{c₁} · s₂^{c₂} · ... · sₖ^{cₖ}) / (1^{c₁} · c₁! · 2^{c₂} · c₂! · ... · k^{cₖ} · cₖ!)
```

де сумування ведеться за всіма наборами невід'ємних цілих чисел `(c₁, c₂, ..., cₖ)`, для яких виконується умова розбиття `1·c₁ + 2·c₂ + ... + k·cₖ = k`.

## 9. Алгоритм Фаддєєва — Левер'є для матричного аналізу

Прямим і надзвичайно важливим чисельним застосуванням формул Ньютона є **алгоритм Фаддєєва — Левер'є** (відомий також як алгоритм Левер'є — Сурйо — Фаддєєва) в обчислювальній лінійній алгебрі.

Нехай задано квадратну матрицю `A` розміру `n × n`. Традиційне обчислення характеристичного многочлена через розкриття визначника `det(λI − A)` є комбінаторно складним і вимагає `O(n!)` операцій або складних символьних перетворень.

Алгоритм Левер'є використовує той факт, що суми степенів власних значень `sₖ = ∑ λᵢᵏ` точно дорівнюють сліду відповідного степеня матриці:

```
sₖ = tr(Aᵏ)
```

Алгоритм будує послідовність допоміжних матриць `Bₖ` та коефіцієнтів `cₖ`:

```
B₁ = A,                  c₁ = tr(B₁)
B₂ = A · (B₁ − c₁ I),    c₂ = (1/2) · tr(B₂)
B₃ = A · (B₂ − c₂ I),    c₃ = (1/3) · tr(B₃)
...
Bₙ = A · (Bₙ₋₁ − cₙ₋₁ I), cₙ = (1/n) · tr(Bₙ)
```

У результаті виконання алгоритму:
1. Отримані числа `c₁, c₂, ..., cₙ` є в точності коефіцієнтами характеристичного многочлена `p(λ) = λⁿ − c₁ λⁿ⁻¹ − c₂ λⁿ⁻² − ... − cₙ`.
2. Обернена матриця `A⁻¹` обчислюється автоматично без виконання методу Гаусса:
```
A⁻¹ = (1 / cₙ) · (Bₙ₋₁ − cₙ₋₁ I)
```

Це демонструє колосальну практичну силу тотожностей Ньютона: вони зводять задачу знаходження спектрального многочлена та оберненої матриці до звичайного множення матриць і взяття сліду.

## 10. Матрично-визначникове представлення

Рекурентні формули Ньютона можна згрупувати у вигляді лінійної алгебраїчної системи рівнянь з трикутною матрицею коефіцієнтів. Застосовуючи правило Крамера, отримуємо компактне зображення елементарних симетричних многочленів `eₖ` через визначники матриць Тепліца:

```
          ┌                                       ┐
          │  s₁    1     0     0    ...    0      │
          │  s₂    s₁    2     0    ...    0      │
eₖ = 1/k! │  s₃    s₂    s₁    3    ...    0      │
          │  ...   ...   ...   ...  ...   ...     │
          │  sₖ₋₁  sₖ₋₂  sₖ₋₃  ...  ...  k − 1    │
          │  sₖ    sₖ₋₁  sₖ₋₂  ...  ...   s₁     │
          └                                       ┘
```

І навпаки, сума степенів `sₖ` виражається через симетричні многочлени `e₁, e₂, ..., eₖ` у вигляді визначника квазітрикутної матриці Гессенберга (формула Вронського — Гессенберга):

```
     ┌                                       ┐
     │  e₁    1     0     0    ...    0      │
     │ 2e₂    e₁    1     0    ...    0      │
sₖ = │ 3e₃    e₂    e₁    1    ...    0      │
     │ ...   ...   ...   ...  ...   ...     │
     │keₖ    eₖ₋₁  eₖ₋₂  ...  ...    e₁     │
     └                                       ┘
```

Ці визначникові тотожності відіграють ключову роль у комбінаторній теорії поліномів Шура та теорії симетричних функцій у квантовій механіці.

## 11. Застосування в алгоритмах декодування та аналізі даних

У сучасній цифровій техніці тотожності Ньютона — Жирара є серцем алгоритмів виправлення помилок (коди Ріда — Соломона, які використовуються у накопичувачах SSD, дисках, QR-кодах та космічному зв'язку).

При прийомі зашумленого сигналу приймач обчислює синдроми помилок, які математично є сумами степенів `sₖ` локаторів пошкоджених бітів. Щоб знайти позиції помилок, алгоритм за формулами Ньютона відновлює коефіцієнти `eₖ` так званого многочлена локаторів помилок, корені якого вказують на точні координати спотворених байтів. Це дозволяє миттєво виправити пакетні помилки без повного перебору даних.

## 12. Чисельна стійкість та обмеження плаваючої крапки

Попри алгебраїчну елегантність, застосування формул Ньютона в комп'ютерній арифметиці з плаваючою крапкою вимагає обережності. Коли абсолютні значення коренів `|rᵢ| > 1`, величини `sₖ` зростають експоненціально як `O(r_maxᵏ)`.

При обчисленні коефіцієнтів `eₖ` через формулу `eₖ = (1/k) · (eₖ₋₁ s₁ − eₖ₋₂ s₂ + ...)` відбувається віднімання дуже великих близьких чисел. В арифметиці IEEE-754 це призводить до катастрофічного скасування розрядів (англ. *catastrophic cancellation*), коли молодші біти мантиси втрачаються. Тому для великих степенів `n > 20` в чисельних методах використовують факторизацію через QR-алгоритм або обчислення в арифметиці довільної точності (наприклад, над полем раціональних чисел `ℚ` або скінченними полями Галуа `GF(2ᵐ)`).

## 13. Повний числовий приклад розрахунку

Розглянемо кубічний многочлен (`n = 3`), корені якого дорівнюють `r₁ = 1, r₂ = 2, r₃ = 3`:

```
P(x) = (x − 1) · (x − 2) · (x − 3) = x³ − 6x² + 11x − 6
```

Звідси коефіцієнти Вієта:
- `e₁ = 6`
- `e₂ = 11`
- `e₃ = 6`

Обчислимо суми степенів `s₁, s₂, s₃, s₄` за формулами Ньютона крок за кроком:

**Крок 1. Розрахунок s₁:**
```
s₁ = e₁ = 6
Перевірка через корені: 1¹ + 2¹ + 3¹ = 1 + 2 + 3 = 6  [збігається]
```

**Крок 2. Розрахунок s₂:**
```
s₂ = e₁ s₁ − 2 e₂
   = 6 · 6 − 2 · 11
   = 36 − 22 = 14
Перевірка через корені: 1² + 2² + 3² = 1 + 4 + 9 = 14  [збігається]
```

**Крок 3. Розрахунок s₃:**
```
s₃ = e₁ s₂ − e₂ s₁ + 3 e₃
   = 6 · 14 − 11 · 6 + 3 · 6
   = 84 − 66 + 18 = 36
Перевірка через корені: 1³ + 2³ + 3³ = 1 + 8 + 27 = 36  [збігається]
```

**Крок 4. Розрахунок s₄ (випадок k > n, k = 4 > 3):**
```
s₄ = e₁ s₃ − e₂ s₂ + e₃ s₁
   = 6 · 36 − 11 · 14 + 6 · 6
   = 216 − 154 + 36 = 98
Перевірка через корені: 1⁴ + 2⁴ + 3⁴ = 1 + 16 + 81 = 98  [збігається]
```

Тепер розв'яжемо обернену задачу: припустимо, що нам задано суми степенів трьох невідомих величин `s₁ = 6, s₂ = 14, s₃ = 36`. Знайдемо коефіцієнти `e₁, e₂, e₃`:

```
e₁ = s₁ = 6
e₂ = (s₁² − s₂) / 2 = (36 − 14) / 2 = 22 / 2 = 11
e₃ = (s₁³ − 3 s₁ s₂ + 2 s₃) / 6 = (216 − 3 · 6 · 14 + 2 · 36) / 6 = (216 − 252 + 72) / 6 = 36 / 6 = 6
```

Отримані значення коефіцієнтів `e₁ = 6, e₂ = 11, e₃ = 6` формують многочлен `t³ − 6t² + 11t − 6 = 0`, розв'язуючи який, ми однозначно відновлюємо початкові величини `1, 2, 3`.

Усі аналітичні результати ідеально узгоджуються з прямим піднесенням коренів до степенів, демонструючи точність та універсальність рекурентного розрахунку без обчислення самих коренів.
