# 🧮 Математичні доведення та алгебраїчна структура підалгебри Берлекампа

У цьому розділі наведено вичерпне математичне обґрунтування властивостей алгоритму Берлекампа: теорему про ізоморфізм Китайської теореми про остачі для поліноміальних кілець, алгебраїчну структуру розв'язків рівняння Фробеніуса у скінченних розширеннях полів Галуа, строге доведення теореми про розмірність ядра матриці оператора, гарантію нетривіального розщеплення многочлена через найбільший спільний дільник, а також аналіз крайових випадків для полів непарної характеристики та кратних коренів.

---

### Ізоморфізм Китайської теореми про остачі для кілець многочленів

Нехай `GF(q)` — скінченне поле з `q = pᵐ` елементів, де `p` — просте число (характеристика поля), а `m ≥ 1` — ціле число. Розглянемо кільце многочленів від однієї змінної `GF(q)[x]` з коефіцієнтами з поля `GF(q)`. Це кільце є областю головних ідеалів та евклідовим кільцем, у якому кожен ненульовий многочлен однозначно розкладається на добуток незвідних нормованих многочленів із точністю до порядку множників.

Нехай `f(x) ∈ GF(q)[x]` — нормований многочлен степеня `n = deg(f) ≥ 1`, який не має кратних множників (безквадратний многочлен). Його канонічний розклад на попарно різні незвідні нормовані множники має вигляд:

```
f(x) = f₁(x) · f₂(x) · ... · f_k(x)
```

де кожен множник `f_i(x)` є незвідним многочленом степеня `d_i = deg(f_i) ≥ 1`, причому всі `f_i(x)` є попарно взаємно простими:

```
НСД(f_i(x), f_j(x)) = 1   для всіх 1 ≤ i < j ≤ k
```

Сума степенів усіх незвідних множників дорівнює степеню вхідного многочлена:

```
d₁ + d₂ + ... + d_k = n
```

Розглянемо фактор-кільце класів лишків многочленів за модулем головного ідеалу `(f(x))`:

```
R = GF(q)[x] / (f(x))
```

Як векторний простір над базовим полем `GF(q)`, фактор-кільце `R` має розмірність:

```
dim_{GF(q)}(R) = n
```

Канонічним базисом цього простору є мономи:

```
Базис R = { 1, x, x², ..., xⁿ⁻¹ }
```

Оскільки ідеали `(f₁(x)), (f₂(x)), ..., (f_k(x))` є попарно взаємно простими (їхня сума дорівнює всьому кільцю `GF(q)[x]`), за Китайською теоремою про остачі для комутативних кілець існує природне канонічне відображення:

```
φ: GF(q)[x] / (f(x)) ⟶ (GF(q)[x] / (f₁(x))) × (GF(q)[x] / (f₂(x))) × ... × (GF(q)[x] / (f_k(x)))
```

яке кожному класу лишків `v(x) mod f(x)` зіставляє кортеж його остач від ділення на кожен із незвідних дільників:

```
φ(v(x) mod f(x)) = (v(x) mod f₁(x), v(x) mod f₂(x), ..., v(x) mod f_k(x))
```

Оскільки кожен многочлен `f_i(x)` є незвідним над полем `GF(q)`, відповідний головний ідеал `(f_i(x))` є максимальним ідеалом у кільці `GF(q)[x]`. Тому кожне фактор-кільце:

```
K_i = GF(q)[x] / (f_i(x))
```

є полем — скінченним розширенням поля `GF(q)` степеня `d_i = deg(f_i)`. Кількість елементів у цьому полі дорівнює `q^{d_i}`:

```
K_i ≅ GF(q^{d_i})
```

Таким чином, Китайська теорема про остачі встановлює канонічний ізоморфізм між фактор-кільцем `R` та прямим добутком `k` скінченних полів:

```
φ: R ⟶ K₁ × K₂ × ... × K_k
```

Цей ізоморфізм зберігає як операції додавання та множення елементів, так і операцію множення на скаляри з базового поля `GF(q)`. Тобто `φ` є ізоморфізмом `GF(q)`-алгебр.

### Рівняння Фробеніуса та структура підалгебри Берлекампа

Означимо **підалгебру Берлекампа** `B` як підмножину фактор-кільця `R`, що складається з усіх елементів `v(x) ∈ R`, які задовольняють модульне рівняння піднесення до степеня `q`:

```
B = { v(x) ∈ GF(q)[x] / (f(x)) | v(x)^q ≡ v(x) mod f(x) }
```

Дослідимо, як виглядає умова `v(x)^q ≡ v(x) mod f(x)` через призму ізоморфізму `φ`. 

Оскільки відображення `φ` зберігає операцію піднесення до степеня, рівність `v(x)^q = v(x)` у кільці `R` виконується тоді й лише тоді, коли вона виконується покомпонентно у кожному з полів `K_i`:

```
φ(v(x)^q) = ( (v(x) mod f₁(x))^q, (v(x) mod f₂(x))^q, ..., (v(x) mod f_k(x))^q )
```

Отже, рівність `v(x)^q ≡ v(x) mod f(x)` рівносильна системі з `k` незалежних рівнянь:

```
y_i^q = y_i   у полі K_i   для кожного i = 1, 2, ..., k
```

де `y_i = v(x) mod f_i(x) ∈ K_i`.

Доведемо фундаментальну лему про множину коренів цього рівняння:

> **Лема про розв'язки рівняння Фробеніуса:** У будь-якому полі `K_i ≅ GF(q^{d_i})` рівняння `y^q - y = 0` має рівно `q` розв'язків, і всі ці розв'язки є елементами базового поля `GF(q) ⊆ K_i`.

**Доведення леми:**
1. Розглянемо многочлен `P(Y) = Y^q - Y` як многочлен над полем `K_i`. Степінь многочлена дорівнює `q`. За основною теоремою алгебри для полів, будь-який многочлен степеня `q` може мати не більше ніж `q` різних коренів у полі `K_i`.
2. З іншого боку, згідно з малою теоремою Ферма для скінченних полів, мультиплікативна група ненульових елементів базового поля `GF(q)*` містить `q - 1` елементів і є циклічною групою порядку `q - 1`. Отже, для будь-якого ненульового елемента `s ∈ GF(q)*` виконується рівність `s^{q-1} = 1`, звідки:
   ```
   s^q = s · s^{q-1} = s · 1 = s
   ```
3. Для нульового елемента `s = 0` рівність `0^q = 0` виконується тривіально.
4. Таким чином, усі `q` елементів базового поля `GF(q)` задовольняють рівняння `s^q - s = 0`.
5. Оскільки базове поле `GF(q)` є підполем поля `K_i`, ми знайшли рівно `q` різних коренів многочлена `P(Y)` у полі `K_i`.
6. Оскільки многочлен степеня `q` не може мати більше ніж `q` коренів, у полі `K_i` не існує жодного іншого елемента за межами базового поля `GF(q)`, який задовольняв би рівняння `y^q = y`.

**Висновок:** Елемент `y_i = v(x) mod f_i(x)` задовольняє рівняння `y_i^q = y_i` тоді й тільки тоді, коли `y_i` є скалярною константою з базового поля `GF(q)`:

```
v(x) mod f_i(x) = s_i,   де s_i ∈ GF(q)
```

### Розмірність простору та кількість незвідних множників

Завдяки ізоморфізму `φ`, кожен елемент `v(x)` підалгебри Берлекампа `B` однозначно зіставляється з кортежем із `k` скалярів базового поля:

```
φ(v(x)) = (s₁, s₂, ..., s_k) ∈ (GF(q))^k
```

Оскільки для кожного незвідного множника `f_i(x)` значення `s_i ∈ GF(q)` можна обрати абсолютно незалежно від інших (існує `q` варіантів вибору для кожної координати), загальна кількість елементів у підалгебрі Берлекампа дорівнює:

```
|B| = q · q · ... · q = q^k
```

Оскільки `B` є векторним підпростором простору `R` над полем `GF(q)`, його розмірність визначається формулою:

```
dim_{GF(q)}(B) = log_q(|B|) = log_q(q^k) = k
```

З іншого боку, за означенням матриці Берлекампа `Q`, умова `v(x)^q ≡ v(x) mod f(x)` у матричному вигляді еквівалентна лінійній однорідній системі рівнянь:

```
v · (Q - I) = 0
```

де `v = [v₀, v₁, ..., vₙ₋₁]` — рядок коефіцієнтів многочлена `v(x)`. Простір усіх таких векторів є лівим нуль-простором (ядром) матриці `Q - I`:

```
B ≅ ker(Q - I)
```

Звідси випливає фундаментальна теорема Берлекампа:

> **Теорема про розмірність ядра:** Розмірність ядра матриці `dim ker(Q - I)` строго дорівнює кількості `k` незвідних множників многочлена `f(x)`.

Це дає точний алгебраїчний критерій:
- Якщо `dim ker(Q - I) = 1`, многочлен `f(x)` є незвідним над полем `GF(q)`.
- Якщо `dim ker(Q - I) = k > 1`, многочлен `f(x)` розкладається рівно на `k` незвідних множників.

### Теорема про розщеплення через найбільший спільний дільник

Розглянемо тотожність розкладу многочлена `Y^q - Y` над полем `GF(q)`:

```
Y^q - Y = ∏_{s ∈ GF(q)} (Y - s)
```

Підставимо замість змінної `Y` многочлен `v(x) ∈ B`. Отримуємо тотожність у кільці `GF(q)[x]`:

```
v(x)^q - v(x) = ∏_{s ∈ GF(q)} (v(x) - s)
```

Оскільки `v(x) ∈ B`, за означенням різниця `v(x)^q - v(x)` ділиться на `f(x)` без остачі:

```
f(x) | ∏_{s ∈ GF(q)} (v(x) - s)
```

Дослідимо взаємну простоту співмножників `(v(x) - s)`. Нехай `s₁, s₂ ∈ GF(q)` — два різні елементи поля (`s₁ ≠ s₂`). Обчислимо їхню лінійну комбінацію:

```
(v(x) - s₁) - (v(x) - s₂)
= v(x) - s₁ - v(x) + s₂   [розкрили дужки]
= s₂ - s₁                 [звели подібні члени]
```

Оскільки `s₁ ≠ s₂`, різниця `s₂ - s₁` є ненульовим скаляром з поля `GF(q)`. Будь-який спільний поліноміальний дільник многочленів `(v(x) - s₁)` та `(v(x) - s₂)` зобов'язаний ділити їхню різницю `s₂ - s₁ ∈ GF(q) \ {0}`. Оскільки ненульовий скаляр є оборотним елементом кільця многочленів, його дільниками можуть бути лише константи нульового степеня.

Отже, многочлени `(v(x) - s)` є попарно взаємно простими:

```
НСД(v(x) - s₁, v(x) - s₂) = 1   для будь-яких s₁ ≠ s₂
```

Оскільки многочлен `f(x)` є безквадратним, за лемою Евкліда для многочленів кожен його незвідний множник `f_i(x)` зобов'язаний ділити рівно один множник із правої частини.

З'ясуємо, який саме множник ділить `f_i(x)`. Оскільки `φ(v(x)) = (s₁, s₂, ..., s_k)`, за означенням маємо:

```
v(x) ≡ s_i mod f_i(x)   ⟺   v(x) - s_i ≡ 0 mod f_i(x)   ⟺   f_i(x) | (v(x) - s_i)
```

Для будь-якого іншого скаляра `s ≠ s_i` маємо:

```
v(x) - s ≡ s_i - s ≠ 0 mod f_i(x)
```

Оскільки `s_i - s` є ненульовою константою, а `f_i(x)` є незвідним многочленом степеня принаймні 1, многочлен `f_i(x)` не ділить `v(x) - s` при `s ≠ s_i`.

Звідси випливає точна формула для найбільшого спільного дільника:

```
НСД(f(x), v(x) - s) = ∏_{i: s_i = s} f_i(x)
```

Добуток усіх таких найбільших спільних дільників за всіма `s ∈ GF(q)` точно відновлює початковий многочлен:

```
f(x) = ∏_{s ∈ GF(q)} НСД(f(x), v(x) - s)
```

### Гарантія нетривіального розщеплення для неконстантних векторів

Нехай кількість незвідних множників `k ≥ 2`. Тоді простір `B` має розмірність `k ≥ 2`.

Простір `B` завжди містить одновимірний тривіальний підпростір констант:

```
B_const = { c · 1 | c ∈ GF(q) }
```

Для будь-якого константного вектора `v(x) = c` його образ має вигляд `φ(c) = (c, c, ..., c)`. При підстановці `s = c` ми отримаємо `НСД(f(x), c - c) = НСД(f(x), 0) = f(x)`, а для всіх інших `s ≠ c` отримаємо `НСД(f(x), c - s) = 1`. Такий тривіальний вектор не дає розщеплення многочлена.

Проте оскільки `dim(B) = k ≥ 2`, існує щонайменше `k - 1` лінійно незалежних векторів, які не належать підпростору констант. Нехай `v(x) ∈ B \ B_const` — будь-який такий неконстантний вектор.

Оскільки `v(x)` не є константою, його образ `φ(v(x)) = (s₁, s₂, ..., s_k)` не може складатися з однакових елементів. Існують принаймні два індекси `1 ≤ a < b ≤ k` такі, що:

```
s_a ≠ s_b
```

Розглянемо многочлен:

```
g(x) = НСД(f(x), v(x) - s_a)
```

1. Оскільки `s_a = s_a`, незвідний множник `f_a(x)` ділить `v(x) - s_a` і ділить `f(x)`. Отже, `f_a(x)` ділить `g(x)`. Звідси степінь знайденого дільника задовольняє умову:
   ```
   deg(g(x)) ≥ deg(f_a(x)) ≥ 1
   ```
2. Оскільки `s_b ≠ s_a`, незвідний множник `f_b(x)` не ділить `v(x) - s_a`, а отже `f_b(x)` не ділить `g(x)`.
3. Оскільки `f_b(x)` ділить `f(x)`, але не ділить `g(x)`, многочлен `g(x)` не може дорівнювати `f(x)`:
   ```
   deg(g(x)) ≤ deg(f(x)) - deg(f_b(x)) < deg(f(x))
   ```

Таким чином, для будь-якого неконстантного елемента підалгебри Берлекампа `v(x)` обчислення `НСД(f(x), v(x) - s)` при `s = s_a` гарантовано дає **нетривіальний дільник** `g(x)` многочлена `f(x)`:

```
1 ≤ deg(g(x)) < deg(f(x))
```

### Чому алгоритм вимагає безквадратного многочлена: нільпотентні елементи

Дослідимо, що відбувається з алгебраїчною структурою фактор-кільця `R`, якщо вхідний многочлен `f(x)` має кратний множник, наприклад `f(x) = (g(x))² · h(x)`.

У цьому разі ідеал `(f(x))` не розкладається у добуток максимальних ідеалів. За Китайською теоремою про остачі фактор-кільце ізоморфне:

```
GF(q)[x] / (f(x)) ≅ (GF(q)[x] / (g(x)²)) × (GF(q)[x] / (h(x)))
```

Компонента `GF(q)[x] / (g(x)²)` не є полем, оскільки вона містить ненульові **нільпотентні елементи**. Розглянемо залишок `e(x) = g(x) mod g(x)²`. Він не дорівнює нулю у фактор-кільці, проте його квадрат:

```
(e(x))² = (g(x))² ≡ 0 mod g(x)²
```

Якщо характеристика поля `p = 2`, то `(g(x))² ≡ 0 mod g(x)²`, що спричиняє появу додаткових штучних розв'язків рівняння `v(x)^q ≡ v(x) mod f(x)`, які не є константами базового поля. У результаті розмірність ядра `dim ker(Q - I)` перестає дорівнювати кількості незвідних дільників, а обчислення `НСД(f(x), v(x) - s)` може давати дільники з кратними степенями або зациклюватися.

Саме тому попередня процедура безквадратного розкладу через формальну похідну `НСД(f, f')` є обов'язковою передумовою коректності алгоритму Берлекампа.

### Крайові випадки характеристики поля: формальна похідна та чисто несепарабельні многочлени

У скінченному полі характеристики `p` операція взяття формальної похідної має алгебраїчну особливість, яка відрізняє її від класичного аналізу над полем дійсних чисел.

Розглянемо моном `x^{p·m}`. Його формальна похідна дорівнює:

```
(x^{p·m})'
= (p · m) · x^{p·m - 1}
= (0 · m) · x^{p·m - 1}   [оскільки p ≡ 0 mod p у характеристиці p]
= 0
```

Якщо всі мономи многочлена `f(x)` мають степені, кратні `p`:

```
f(x) = a₀ + a_p x^p + a_{2p} x^{2p} + ... + a_{k·p} x^{k·p}
```

то його формальна похідна тотожно перетворюється на нуль:

```
f'(x) = 0
```

У цьому випадку найбільший спільний дільник `НСД(f(x), f'(x)) = НСД(f(x), 0) = f(x)` не дає дільника меншого степеня. Проте це не глухий кут, а пряме свідчення того, що многочлен є чисто несепарабельним — тобто є `p`-м степенем деякого іншого многочлена `g(x)`:

```
f(x) = (g(x))^p
```

де `g(x) = b₀ + b₁ x + b₂ x² + ... + b_k x^k`, а коефіцієнти задовольняють співвідношення `b_j = (a_{j·p})^{1/p} = (a_{j·p})^{p^{m-1}}` за малою теоремою Ферма. Для двійкового поля `GF(2)` добування квадратного кореня полягає в простому зсуві степенів мономів: `x^{2j} ↦ xʲ`.

Після добування кореня `p`-го степеня многочлен `g(x)` має степінь `n / p < n`, і до нього знову рекурсивно застосовується перевірка на кратні множники. Це гарантує повну математичну замкненість алгоритму для будь-яких многочленів над довільними скінченними полями.
