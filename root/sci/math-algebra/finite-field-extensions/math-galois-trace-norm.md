# 🧮 Алгебраїчна теорія розширень: від незвідних многочленів до сліду і норми

Усі скінченні поля повністю класифікуються своєю характеристикою `p` (простим числом) та степенем розширення `n` (натуральним числом). Формальна побудова скінченного поля спирається на теорію кілець многочленів, теорію Ґалуа та лінійну алгебру над скінченними структурами. Нижче наведено строгі математичні виведення ключових алгебраїчних теорем розширень скінченних полів.

---

## 1. Критерій поля для фактор-кільця поліномів

Нехай `F_p = ℤ/pℤ` — базове просте поле залишків за простим модулем `p`, а `F_p[x]` — кільце многочленів від однієї змінної з коефіцієнтами з `F_p`. Нехай `f(x) ∈ F_p[x]` — многочлен степеня `n ≥ 1`.

Головний ідеал `(f(x)) = { q(x) · f(x) : q(x) ∈ F_p[x] }` задає відношення конгруенції:

```
a(x) ≡ b(x) (mod f(x)) ⇔ f(x) | (a(x) - b(x))
```

Фактор-кільце `K = F_p[x] / (f(x))` складається з класів суміжності `[a(x)] = a(x) + (f(x))`. Оскільки кільце `F_p[x]` є кільцем евклідових кілець (а отже, кільцем головних ідеалів), кожен поліном `a(x)` можна однозначно поділити на `f(x)` з остачею:

```
a(x) = q(x) · f(x) + r(x)      [ділення з остачею в F_p[x]]
```

де `deg(r) < deg(f) = n` або `r(x) = 0`. Отже, кожен клас суміжності має рівно одного канонічного представника — многочлен степеня менше ніж `n`:

```
r(x) = a_{n-1} x^{n-1} + a_{n-2} x^{n-2} + ... + a_1 x + a_0,   де a_i ∈ F_p
```

Кількість таких многочленів дорівнює `p · p · ... · p = p^n`.

### Доведення критерію поля

**Теорема.** Фактор-кільце `F_p[x] / (f(x))` є полем тоді й лише тоді, коли многочлен `f(x)` є незвідним над `F_p`.

**Доведення в бік «⇒» (необхідність):**  
Припустимо супротивне: нехай `K = F_p[x] / (f(x))` — поле, але `f(x)` є звідним, тобто розкладається у добуток:

```
f(x) = g(x) · h(x)
```

де `1 ≤ deg(g) < n` та `1 ≤ deg(h) < n`. У фактор-кільці `K` образи цих многочленів ненульові, оскільки їхній степінь строго менший за степінь `f(x)`: `[g(x)] ≠ [0]` та `[h(x)] ≠ [0]`. Проте їхній добуток:

```
[g(x)] · [h(x)]
= [g(x) · h(x)]                [гомоморфізм факторизації]
= [f(x)]                       [розклад f(x)]
= [0]                          [оскільки f(x) ділиться на f(x)]
```

Ми отримали добуток двох ненульових елементів, рівний нулю, тобто дільники нуля. Але в полі дільників нуля не існує, оскільки множення на `[g(x)]^{-1}` дає:

```
[h(x)]
= [g(x)]^{-1} · ([g(x)] · [h(x)])   [визначення оберненого елемента]
= [g(x)]^{-1} · [0]                 [значення добутку]
= [0]                               [властивість нуля]
```

Отримали суперечність `[h(x)] = [0]`. Отже, `f(x)` зобов'язаний бути незвідним.

**Доведення в бік «⇐» (достатність):**  
Нехай `f(x)` — незвідний многочлен степеня `n`. Візьмемо будь-який ненульовий елемент `[a(x)] ∈ K`, де `deg(a) < n` і `a(x) ≠ 0`. 

Оскільки `f(x)` незвідний, а степінь `a(x)` менший за степінь `f(x)`, єдиними спільними дільниками `a(x)` та `f(x)` є константи з `F_p^*`. Тому найбільший спільний дільник:

```
НСД(a(x), f(x)) = 1
```

За розширеним алгоритмом Евкліда для поліномів над полем існують такі многочлени `u(x), v(x) ∈ F_p[x]`, що виконується співвідношення Безу:

```
u(x) · a(x) + v(x) · f(x) = 1
```

Перейдемо до класів суміжності за модулем `f(x)`:

```
[u(x) · a(x) + v(x) · f(x)] = [1]
[u(x)] · [a(x)] + [v(x)] · [f(x)] = [1]    [гомоморфізм фактор-кільця]
[u(x)] · [a(x)] + [0] = [1]                [оскільки f(x) ≡ 0 mod f(x)]
[u(x)] · [a(x)] = [1]                      [нейтральний елемент множення]
```

Отже, елемент `[u(x)]` є мультиплікативним оберненим до `[a(x)]` у кільці `K`: `[a(x)]^{-1} = [u(x)] mod f(x)`. Кожен ненульовий елемент має обернений, тому `K` — поле потужності `p^n`. Теорему доведено.

## 2. Поле розкладу многочлена X^{p^n} - X

**Теорема.** Скінченне поле `F_{p^n}` є полем розкладу многочлена `P(X) = X^{p^n} - X` над `F_p`.

**Доведення:**  
Нехай `E` — поле розкладу многочлена `P(X) = X^{p^n} - X` над `F_p`. Розглянемо множину всіх коренів цього многочлена в `E`:

```
S = { α ∈ E : α^{p^n} = α }
```

Перевіримо, що множина `S` утворює підполе в `E`. Візьмемо будь-які `α, β ∈ S`:

1. **Додавання:** за властивістю характеристики `p` (біноміальний розклад Фробеніуса):
```
(α - β)^{p^n}
= α^{p^n} - β^{p^n}            [біноміальні коефіцієнти C(p^n, k) ≡ 0 mod p]
= α - β                        [оскільки α, β ∈ S за визначенням]
```
Отже, `(α - β) ∈ S`.

2. **Множення:**
```
(α · β)^{p^n}
= α^{p^n} · β^{p^n}            [комутативність множення в полі E]
= α · β                        [оскільки α, β ∈ S за визначенням]
```
Отже, `(α · β) ∈ S`.

3. **Обернення для `β ≠ 0`:**
```
(β^{-1})^{p^n}
= (β^{p^n})^{-1}               [властивість степеня в мультиплікативній групі]
= β^{-1}                       [оскільки β ∈ S за визначенням]
```
Отже, `β^{-1} ∈ S`.

Таким чином, `S` є підполем поля `E`. Оскільки `E` є найменшим полем, що містить усі корені `P(X)`, маємо `S = E`.

Знайдемо кількість елементів у `S`. Поліном `P(X) = X^{p^n} - X` має степінь `p^n`. Його формальна похідна дорівнює:

```
P'(X)
= p^n · X^{p^n - 1} - 1        [диференціювання одночленів]
= 0 · X^{p^n - 1} - 1          [оскільки p^n ≡ 0 в полі характеристики p]
= -1 ≠ 0                       [ненульова константа в F_p]
```

Оскільки похідна `P'(X) = -1` не має спільних коренів із `P(X)` (тобто `НСД(P(X), P'(X)) = 1`), многочлен `P(X)` не має кратних коренів. Отже, він має рівно `p^n` попарно різних коренів. Це означає, що поле `E = S` містить рівно `p^n` елементів.

## 3. Критерій вкладення підполів: d | n

**Теорема.** Поле `F_{p^d}` є підполем поля `F_{p^n}` тоді й лише тоді, коли `d | n`.

**Доведення в бік «⇒»:**  
Нехай `F_{p^d} ⊆ F_{p^n}`. Тоді більше поле `F_{p^n}` можна розглядати як векторний простір над меншим полем `F_{p^d}`. Нехай вимір цього векторного простору дорівнює `k = [F_{p^n} : F_{p^d}]`.

Кількість елементів у векторному просторі виміру `k` над полем потужності `q = p^d` дорівнює `q^k = (p^d)^k = p^{d · k}`.  
З іншого боку, кількість елементів дорівнює `p^n`. Звідси:

```
p^{d · k} = p^n
d · k = n                      [логарифмування за основою p]
d | n                          [оскільки k є цілим виміром простору]
```

**Доведення в бік «⇐»:**  
Нехай `d | n`, тобто `n = d · m` для деякого натурального `m ≥ 1`.

Доведемо алгебраїчну подільність многочленів:

```
(p^d - 1) | (p^n - 1)
```

Застосуємо тотожність ділення геометричної прогресії:

```
p^n - 1
= (p^d)^m - 1                                                      [підстановка n = d · m]
= (p^d - 1) · ((p^d)^{m-1} + (p^d)^{m-2} + ... + (p^d) + 1)       [розклад різниці m-х степенів]
```

Отже, ціле число `(p^d - 1)` ділить число `(p^n - 1)` без остачі: `p^n - 1 = c · (p^d - 1)` для деякого цілого `c`.

Звідси випливає подільність многочленів:

```
X^{p^n - 1} - 1
= (X^{p^d - 1})^c - 1                                              [підстановка p^n - 1 = c(p^d - 1)]
= (X^{p^d - 1} - 1) · ((X^{p^d - 1})^{c-1} + ... + 1)             [розклад різниці c-х степенів]
```

Помноживши обидві частини на `X`, отримуємо:

```
X · (X^{p^n - 1} - 1) = Q(X) · X · (X^{p^d - 1} - 1)
X^{p^n} - X = Q(X) · (X^{p^d} - X)
```

Це означає, що кожен корінь многочлена `X^{p^d} - X` є також коренем многочлена `X^{p^n} - X`. Оскільки поле `F_{p^d}` складається саме з коренів `X^{p^d} - X`, а поле `F_{p^n}` — з коренів `X^{p^n} - X`, маємо вкладення `F_{p^d} ⊆ F_{p^n}`. Теорему доведено.

## 4. Структура групи Ґалуа Gal(F_{p^n} / F_p)

Автоморфізм Фробеніуса `σ_p : F_{p^n} → F_{p^n}` задається правилом `σ_p(α) = α^p`.

**Властивості автоморфізму:**
1. `σ_p(α + β) = (α + β)^p = α^p + β^p = σ_p(α) + σ_p(β)` (лінійність).
2. `σ_p(α · β) = (α · β)^p = α^p · β^p = σ_p(α) · σ_p(β)` (мультиплікативність).
3. `σ_p` є ін'єктивним, оскільки `α^p = 0 ⇒ α = 0` (у полі немає дільників нуля). Оскільки поле `F_{p^n}` скінченне, ін'єкція скінченної множини в себе є бієкцією.
4. Для будь-якого елемента базового поля `c ∈ F_p` за малою теоремою Ферма виконується `c^p = c`, тобто `σ_p(c) = c`.

Отже, `σ_p` є автоморфізмом поля `F_{p^n}`, що фіксує кожен елемент `F_p`, тобто `σ_p ∈ Gal(F_{p^n} / F_p)`.

**Порядок автоморфізму:**  
Розглянемо `k`-ту степінь автоморфізму: `σ_p^k(α) = α^{p^k}`.  
Тотожність `σ_p^k = id` означає, що для всіх `α ∈ F_{p^n}` виконується `α^{p^k} - α = 0`. Многочлен степеня `p^k` не може мати більше ніж `p^k` коренів. Оскільки все поле містить `p^n` елементів, умова `α^{p^k} = α` для всіх елементів поля можлива лише тоді, коли `p^k ≥ p^n`, тобто `k ≥ n`.

При `k = n` маємо `σ_p^n(α) = α^{p^n} = α` для всіх `α ∈ F_{p^n}`, отже `σ_p^n = id`. Таким чином, порядок елемента `σ_p` у групі Ґалуа дорівнює точно `n`.

Оскільки степінь розширення `[F_{p^n} : F_p] = n`, порядок групи Ґалуа не перевищує `n`:

```
|Gal(F_{p^n} / F_p)| = [F_{p^n} : F_p] = n
```

Оскільки підгрупа, породжена `σ_p`, має порядок `n`, вона збігається з усією групою Ґалуа:

```
Gal(F_{p^n} / F_p) = ⟨σ_p⟩ = { id, σ_p, σ_p^2, ..., σ_p^{n-1} } ≅ ℤ_n
```

Група Ґалуа будь-якого скінченного розширення скінченного поля є циклічною групою порядку `n`.

## 5. Алгебраїчні властивості сліду та норми

Для довільного елемента `α ∈ F_{p^n}` його слід та норма відносно базового поля `F_p` визначаються через дію групи Ґалуа:

```
Tr_{F_{p^n}/F_p}(α) = ∑_{i=0}^{n-1} σ_p^i(α) = α + α^p + α^{p^2} + ... + α^{p^{n-1}}
N_{F_{p^n}/F_p}(α)  = ∏_{i=0}^{n-1} σ_p^i(α) = α · α^p · α^{p^2} · ... · α^{p^{n-1}} = α^{(p^n - 1)/(p - 1)}
```

### Доведення належності базовому полю

Застосуємо автоморфізм Фробеніуса `σ_p` до сліду `Tr(α)`:

```
σ_p(Tr(α))
= (α + α^p + α^{p^2} + ... + α^{p^{n-1}})^p
= α^p + α^{p^2} + α^{p^3} + ... + α^{p^n}       [лінійність Фробеніуса]
= α^p + α^{p^2} + ... + α^{p^{n-1}} + α        [оскільки α^{p^n} = α]
= Tr(α)                                        [комутативність додавання]
```

Оскільки `σ_p(Tr(α)) = Tr(α)`, елемент `Tr(α)` є нерухомою точкою автоморфізму Фробеніуса. Єдиними нерухомими точками `σ_p(x) = x` у полі `F_{p^n}` є корені рівняння `x^p - x = 0`, які за визначенням утворюють базове поле `F_p`. Отже, `Tr(α) ∈ F_p`.

Аналогічно для норми:

```
σ_p(N(α))
= (α · α^p · ... · α^{p^{n-1}})^p
= α^p · α^{p^2} · ... · α^{p^n}                [мультиплікативність]
= α^p · α^{p^2} · ... · α^{p^{n-1}} · α        [оскільки α^{p^n} = α]
= N(α)                                         [комутативність множення]
```

Отже, `N(α) ∈ F_p`.

### Лінійність та несингулярність сліду

Слід є лінійною формою на векторному просторі `F_{p^n}` над `F_p`:

```
Tr(c_1 α + c_2 β) = c_1 Tr(α) + c_2 Tr(β),   ∀ c_1, c_2 ∈ F_p,  α, β ∈ F_{p^n}
```

Слід не є тотожно нульовим відображенням. Рівняння `Tr(X) = X + X^p + ... + X^{p^{n-1}} = 0` має степінь `p^{n-1}`, тому воно має щонайбільше `p^{n-1}` коренів у полі `F_{p^n}`. Оскільки поле містить `p^n > p^{n-1}` елементів, існує щонайменше `p^n - p^{n-1}` елементів `α ∈ F_{p^n}`, для яких `Tr(α) ≠ 0`.

Звідси білінійна форма:

```
⟨α, β⟩ = Tr(α · β)
```

є несингулярною (невиродженою). Це дозволяє для будь-якого базису `{α_0, α_1, ..., α_{n-1}}` побудувати єдиний дуальний базис `{β_0, β_1, ..., β_{n-1}}`, що задовольняє умову ортогональності `Tr(α_i · β_j) = δ_{ij}` (де `δ_{ij}` — символ Кронекера).
