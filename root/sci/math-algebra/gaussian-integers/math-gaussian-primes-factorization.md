# 🧮 Норма, подільність і класифікація простих чисел у ℤ[i]

Ця вставка містить повні математичні доведення фундаментальних властивостей кільця гауссових цілих чисел `ℤ[i]`. Ми послідовно виведемо властивості алгебраїчної норми, доведемо евклідовість та факторіальність кільця `ℤ[i]`, детально розберемо класифікаційну теорему про три класи простих чисел Гаусса, виведемо формулу кількості розкладів натурального числа на суму двох квадратів та дослідимо алгебраїчну структуру фактор-кілець `ℤ[i]/(α)` і функцію Ейлера для комплексних чисел.

---

### 1. Алгебраїчна норма та її властивості

Для будь-якого гауссового цілого числа `α = a + bi` (де `a, b ∈ ℤ`) алгебраїчна норма визначається як добуток числа на його комплексне спряження `ᾱ = a - bi`:

```
N(α) = α · ᾱ = (a + bi)·(a - bi) = a² + b²
```

**Теорема 1 (Мультиплікативність норми).** Для будь-яких двох гауссових чисел `α, β ∈ ℤ[i]` норма їхнього добутку дорівнює добутку їхніх окремих норм:

```
N(α · β) = N(α) · N(β)
```

*Доведення.* Нехай `α = a + bi` та `β = c + di`. Їхній добуток дорівнює `α · β = (ac - bd) + (ad + bc)i`. Обчислимо норму добутку безпосередньо за означенням:

```
N(α · β)
= (ac - bd)² + (ad + bc)²                                       [означення норми: N(x + yi) = x² + y²]
= (a²c² - 2acbd + b²d²) + (a²d² + 2adbc + b²c²)                 [піднесення до квадрата]
= a²c² + b²d² + a²d² + b²c²                                     [скорочення протилежних доданків 2abcd]
= a²·(c² + d²) + b²·(c² + d²)                                   [групування доданків за спільними множниками]
= (a² + b²) · (c² + d²)                                         [винесення спільної дужки (c² + d²)]
= N(α) · N(β)                                                   [згортання у вихідні норми множників]
```

Твердження повністю доведено.

**Теорема 2 (Критерій оборотності елемента).** Елемент `u ∈ ℤ[i]` є оборотною одиницею кільця тоді й тільки тоді, коли його норма дорівнює одиниці:

```
u ∈ ℤ[i]× ⇔ N(u) = 1
```

*Доведення.*
1. **Необхідність (⇒):** Нехай `u` — оборотна одиниця. За означенням оборотності існує такий елемент `v ∈ ℤ[i]`, що `u · v = 1`. Застосуємо норму до обох частин рівності:

```
N(u · v) = N(1)
N(u) · N(v) = 1² = 1                                            [мультиплікативність норми]
```

Оскільки `N(u)` та `N(v)` — невід'ємні звичайні цілі числа, рівність `N(u) · N(v) = 1` у множині `ℤ` можлива лише тоді, коли `N(u) = 1` та `N(v) = 1`.

2. **Достатність (⇐):** Нехай `N(u) = 1` для деякого `u = a + bi`. За означенням норми:

```
u · ū = N(u) = 1
```

Оскільки `ū = a - bi` також належить `ℤ[i]` (бо `a, -b ∈ ℤ`), елемент `ū` є шуканим оберненим до `u`. Отже, `u` є оборотною одиницею.

Оскільки рівняння `a² + b² = 1` у цілих числах має рівно чотири розв'язки `(±1, 0)` та `(0, ±1)`, група оборотних одиниць кільця `ℤ[i]` складається точно з 4 елементів: `ℤ[i]× = { 1, i, -1, -i }`.

### 2. Евклідовість та однозначність факторизації

**Теорема 3 (Ділення з остачею).** Для будь-яких двох гауссових цілих чисел `α, β ∈ ℤ[i]` при `β ≠ 0` існують такі числа `q, r ∈ ℤ[i]`, що:

```
α = β · q + r,    причому N(r) ≤ ½ · N(β) < N(β)
```

*Доведення.*
Обчислимо точну частку двох чисел у полі комплексних чисел `ℂ`:

```
z = α / β = (α · β̄) / (β · β̄) = (α · β̄) / N(β) = x + yi
```

Тут `x, y ∈ ℚ` — раціональні дійсні числа. Оберемо найближчі цілі числа `q₀, q₁ ∈ ℤ` до дійсних чисел `x` та `y` відповідно:

```
|x - q₀| ≤ ½,    |y - q₁| ≤ ½
```

Покладемо `q = q₀ + q₁·i ∈ ℤ[i]`. Визначимо остачу `r = α - β · q ∈ ℤ[i]`. Оцінимо норму остачі:

```
N(r)
= N(α - β · q)                                                  [означення остачі r = α - βq]
= N(β · (α/β - q))                                              [винесення дільника β за дужки]
= N(β) · N(z - q)                                               [мультиплікативність норми]
= N(β) · ((x - q₀)² + (y - q₁)²)                                [розписування норми різниці]
≤ N(β) · ((½)² + (½)²)                                          [оскільки |x - q₀| ≤ ½ та |y - q₁| ≤ ½]
= N(β) · (¼ + ¼) = N(β) · ½                                     [арифметичне додавання часток]
< N(β)                                                          [оскільки N(β) > 0 для ненульового β]
```

Оскільки `N(r) ≤ ½ · N(β) < N(β)`, норма залишку строго спадає, що гарантує завершення алгоритму Евкліда за скінченну кількість кроків.

**Наслідок 1 (Кільце головних ідеалів).** Кільце `ℤ[i]` є кільцем головних ідеалів (PID). Кожен ідеал `I ⊆ ℤ[i]` має вигляд `I = (d) = d · ℤ[i]`, де `d` — ненульовий елемент ідеалу `I` з мінімальною додатною нормою `N(d)`.

*Доведення.* Нехай `I ≠ {0}` — довільний ненульовий ідеал у `ℤ[i]`. Оскільки норми ненульових елементів є натуральними числами, серед них існує елемент `d ∈ I \ {0}` із найменшою можливою нормою `N(d)`. Очевидно, що `(d) ⊆ I`.

Візьмемо довільний елемент `a ∈ I`. Розділимо `a` на `d` з остачею в `ℤ[i]`:

```
a = d · q + r,    де N(r) < N(d)
```

Оскільки `a ∈ I` та `d ∈ I`, остача `r = a - d · q` також зобов'язана належати ідеалу `I`. Але якщо `r ≠ 0`, то `r` є ненульовим елементом ідеалу `I` з нормою `N(r) < N(d)`, що суперечить вибору `d` як елемента з мінімальною додатною нормою. Отже, `r = 0`, звідки `a = d · q ∈ (d)`. Таким чином, `I = (d)`.

**Наслідок 2 (Лема Евкліда для ℤ[i]).** Якщо незвідний елемент `π ∈ ℤ[i]` ділить добуток `α · β`, то `π` ділить принаймні один із множників: `π | α` або `π | β`.

*Доведення.* Нехай `π | (α · β)` і припустимо, що `π` не ділить `α`. Оскільки `π` — незвідний елемент, єдиними спільними дільниками `π` та `α` є оборотні одиниці, отже `gcd(π, α) = 1`. За співвідношенням Безу в кільці головних ідеалів існують такі `u, v ∈ ℤ[i]`, що:

```
u · π + v · α = 1
```

Помножимо обидві частини рівності на `β`:

```
u · π · β + v · α · β = β
π · (u · β) + (α · β) · v = β
```

Перший доданок `π · (u · β)` ділиться на `π`. Другий доданок `(α · β) · v` також ділиться на `π`, оскільки за умовою `π | (α · β)`. Отже, їхня сума `β` ділиться на `π`. Лему доведено.

З леми Евкліда та існування розкладу стандартним індуктивним шляхом за величиною норми `N(α)` випливає **однозначність розкладу на прості множники** в `ℤ[i]`.

### 3. Класифікація простих чисел Гаусса

Назвемо ненульовий необоротний елемент `π ∈ ℤ[i]` **простим гауссовим числом**, якщо при будь-якому розкладі `π = α · β` один із множників є оборотною одиницею (`N(α) = 1` або `N(β) = 1`).

**Лема 1.** Якщо норма гауссового числа `N(π) = p` є звичайним простим числом у `ℤ`, то `π` є простим гауссовим числом у `ℤ[i]`.

*Доведення.* Нехай `π = α · β`. Тоді `N(π) = N(α) · N(v) = p`. Оскільки `p` — звичайне просте число, його єдиними дільниками в `ℤ` є `1` та `p`. Отже, або `N(α) = 1` (і тоді `α ∈ ℤ[i]×`), або `N(β) = 1` (і тоді `β ∈ ℤ[i]×`). Це означає, що `π` не розкладається на менші множники і є простим числом у `ℤ[i]`.

**Лема 2.** Кожне просте гауссове число `π` ділить рівно одне раціональне просте число `p ∈ ℤ`.

*Доведення.* Розглянемо норму `N(π) = π · π̄ = n ∈ ℤ`. Оскільки `n > 1`, розкладемо `n` на звичайні прості множники в `ℤ`: `n = p₁ · p₂ · ... · pₖ`. Тоді `π | (p₁ · p₂ · ... · pₖ)`. За лемою Евкліда в `ℤ[i]`, просте число `π` зобов'язане ділити принаймні один із множників `pⱼ`. Якби `π` ділило два різні прості числа `p` та `q` (для яких `gcd(p, q) = 1`), то за тотожністю Безу `u·p + v·q = 1` випливало б, що `π | 1`, що неможливо для простого числа. Отже, таке просте число `p` єдине.

Тепер з'ясуймо, як кожне раціональне просте число `p` поводиться в `ℤ[i]`.

**Теорема 4 (Повна класифікація простих чисел Гаусса).**
Усі прості числа кільця `ℤ[i]` (з точністю до множення на оборотні одиниці `{±1, ±i}`) вичерпуються такими трьома взаємовиключними класами:

1. **Розгалужений дільник двійки:** число `1 + i` (норма `N(1 + i) = 2`).
2. **Розщеплені прості числа:** пара комплексно-спряжених чисел `π = a + bi` та `π̄ = a - bi` для кожного раціонального простого `p ≡ 1 (mod 4)` (де `a² + b² = p`, норма `N(π) = p`).
3. **Інертні прості числа:** самі раціональні прості числа `p ≡ 3 (mod 4)` (норма `N(p) = p²`).

#### Строге доведення класифікаційної теореми:

**Випадок 1: p = 2.**
Обчислимо добуток:
```
(1 + i)·(1 - i) = 1² - i² = 1 - (-1) = 2
```
Зауважимо, що `1 - i = -i · (1 + i)`. Оскільки `-i` — оборотна одиниця, множники `1 + i` та `1 - i` асоційовані. Норма `N(1 + i) = 1² + 1² = 2` — просте число, тому за Лемою 1 число `1 + i` є простим гауссовим числом. Отже:
```
2 = -i · (1 + i)²
```
Число 2 розгалужується на квадрат простого гауссового числа.

**Випадок 2: p ≡ 1 (mod 4).**
За критерієм Ейлера значення символу Лежандра для -1 дорівнює:

```
(-1 / p) ≡ (-1)^((p - 1)/2) (mod p)
```

Для `p ≡ 1 (mod 4)` степінь `(p - 1)/2 = 2k` є парним числом, тому `(-1)^2k = 1`. Отже, `-1` є квадратичним лишком за модулем `p`. Це означає, що існує таке ціле число `x ∈ ℤ`, що:

```
x² ≡ -1 (mod p)    ⇒    x² + 1 ≡ 0 (mod p)
```

Отже, ціле число `p` ділить вираз `x² + 1 = (x + i)·(x - i)` у кільці `ℤ[i]`.

Припустимо від супротивного, що `p` залишається простим числом у `ℤ[i]`. Тоді за лемою Евкліда `p` зобов'язане ділити або `x + i`, або `x - i`. Розглянемо частку:

```
(x ± i) / p = (x/p) ± (1/p)·i
```

Щоб це число належало `ℤ[i]`, його уявна частина `±1/p` мала б бути цілим числом. Але для будь-якого простого `p ≥ 5` дріб `1/p` не є цілим числом. Отримали суперечність.

Отже, припущення хибне, і число `p` є складеним у `ℤ[i]`. Нехай `p = α · β`, де `α, β` — необоротні елементи. Застосуємо норму:

```
N(p) = N(α) · N(β)
p² = N(α) · N(β)                                                [оскільки N(p) = p²]
```

Оскільки `α` та `β` необоротні (`N(α) > 1` та `N(β) > 1`), єдиною можливістю в натуральних числах є:

```
N(α) = p    та    N(β) = p
```

Нехай `α = a + bi`. Тоді `N(α) = a² + b² = p`. Оскільки `N(α) = p` — просте число, за Лемою 1 число `α = a + bi` є простим гауссовим числом. Більше того:

```
α · ᾱ = a² + b² = p
```

Отже, другим множником є в точності комплексно-спряжене число `ᾱ = a - bi`.

Перевіримо, чи можуть `α = a + bi` та `ᾱ = a - bi` бути асоційованими. Якщо `ᾱ = u · α`, то:
- Якщо `u = 1`: `a - bi = a + bi` ⇒ `2b = 0` ⇒ `b = 0`, тоді `p = a²` — неможливо для простого числа.
- Якщо `u = -1`: `a - bi = -a - bi` ⇒ `2a = 0` ⇒ `a = 0`, тоді `p = b²` — неможливо.
- Якщо `u = i`: `a - bi = i(a + bi) = -b + ai` ⇒ `a = -b` та `-b = a`, тоді `p = a² + (-a)² = 2a²`, отже `p` ділиться на 2, що суперечить умові `p ≡ 1 (mod 4)`.
- Якщо `u = -i`: аналогічно `p = 2a²` — суперечність.

Отже, прості гауссові числа `π = a + bi` та `π̄ = a - bi` є **неасоційованими**. Число `p` розщеплюється на два різні прості множники.

**Випадок 3: p ≡ 3 (mod 4).**
Припустимо, що `p` розкладається на нетривіальні множники в `ℤ[i]`: `p = α · β` при `N(α) > 1, N(β) > 1`. Тоді з рівності `N(α) · N(β) = p²` знову випливає, що `N(α) = p`.

Нехай `α = a + bi`. Тоді:

```
a² + b² = p
```

Розглянемо квадрати цілих чисел за модулем 4:
- `0² ≡ 0 (mod 4)`
- `1² ≡ 1 (mod 4)`
- `2² ≡ 0 (mod 4)`
- `3² ≡ 1 (mod 4)`

Сума двох квадратів `a² + b² (mod 4)` може набувати лише значень `0 + 0 = 0`, `0 + 1 = 1` або `1 + 1 = 2`.

Значення `3` за модулем 4 отримати неможливо за жодного вибору цілих чисел `a` та `b`.

Отже, рівність `a² + b² = p` для `p ≡ 3 (mod 4)` не має розв'язків у цілих числах `ℤ`. Це означає, що число `p` не має дільників з нормою `p`, а отже є незвідним і простим у `ℤ[i]`. Його норма в `ℤ[i]` дорівнює `N(p) = p²`. Теорему повністю доведено.

### 4. Кількість розкладів на суму двох квадратів

Спираючись на факторіальність `ℤ[i]`, виведемо точну кількість способів представлення натурального числа `n` у вигляді суми двох квадратів цілих чисел: `n = x² + y²`.

Нехай канонічний розклад числа `n` на прості множники в `ℤ` має вигляд:

```
n = 2^k · ∏ pⱼ^aⱼ · ∏ qₘ^bₘ
```

де `pⱼ ≡ 1 (mod 4)` — прості числа, що розщеплюються, а `qₘ ≡ 3 (mod 4)` — інертні прості числа.

У кільці `ℤ[i]` кожен простий множник розкладається на прості гауссові множники:
- `2 = -i · (1 + i)²`
- `pⱼ = πⱼ · π̄ⱼ`
- `qₘ` — залишається простим елементом.

Отже, повний розклад числа `n` у `ℤ[i]` має вигляд:

```
n = u · (1 + i)^(2k) · ∏ (πⱼ · π̄ⱼ)^aⱼ · ∏ qₘ^bₘ
```

Представлення `n = x² + y²` еквівалентне пошуку гауссового числа `α = x + yi`, для якого `N(α) = α · ᾱ = n`.

Щоб добуток `α · ᾱ` дав число `n`:
1. Для кожного інертного простого `qₘ`: оскільки `qₘ` не розкладається в `ℤ[i]`, його степінь `bₘ` у розкладі `α` має дорівнювати степеню в `ᾱ`. Отже, щоб норма `N(α)` містила `qₘ^bₘ`, степінь `bₘ` **обов'язково має бути парним**: `bₘ = 2cₘ`. Тоді `α` містить `qₘ^cₘ`. Якщо хоча б одне `bₘ` непарне, кількість розкладів дорівнює 0.
2. Множник `(1 + i)^(2k)` дає для `α` рівно один вибір дільника `(1 + i)^k` з точністю до оборотної одиниці (оскільки `1 + i` та `1 - i` асоційовані).
3. Для кожного розщепленого простого `pⱼ = πⱼ · π̄ⱼ`: у число `α` можна включити `πⱼ^m · π̄ⱼ^(aⱼ - m)`, де степінь `m` можна незалежно обрати будь-яким цілим числом від `0` до `aⱼ`. Це дає рівно `aⱼ + 1` варіантів вибору для кожного множника `pⱼ`.
4. Будь-яке знайдене число `α` можна помножити на 4 оборотні одиниці `{1, i, -1, -i}`, що відповідає 4 змінам знаків та перестановок `(±x, ±y)`.

**Теорема Якобі про суму двох квадратів.** Загальна кількість пар цілих чисел `(x, y) ∈ ℤ²`, для яких `x² + y² = n` (позначається `r₂(n)`), дорівнює:

```
r₂(n) = 4 · ∏ (aⱼ + 1)    (якщо всі bₘ парні; інакше r₂(n) = 0)
```

Еквівалентно, через суму за дільниками:

```
r₂(n) = 4 · (d₁(n) - d₃(n))
```

де `d₁(n)` — кількість дільників числа `n`, які дають остачу 1 за модулем 4, а `d₃(n)` — кількість дільників числа `n`, які дають остачу 3 за модулем 4.

Наприклад, для `n = 65 = 5¹ · 13¹`:
- `a₁ = 1` (для `p₁ = 5`)
- `a₂ = 1` (для `p₂ = 13`)
- `r₂(65) = 4 · (1 + 1) · (1 + 1) = 4 · 2 · 2 = 16`.

Ці 16 пар розбиваються на 2 принципово різні розклади `65 = 1² + 8²` та `65 = 4² + 7²`, кожен із яких за рахунок перестановок доданків та знаків дає `2 × 2 × 2 = 8` варіантів координат `(±1, ±8), (±8, ±1)` та `(±4, ±7), (±7, ±4)`.

### 5. Структура фактор-кілець та комплексна функція Ейлера

Дослідимо будову фактор-кільця `ℤ[i]/(α)` за головним ідеалом, породженим ненульовим гауссовим числом `α = a + bi`.

**Теорема 5 (Кількість класів лишків).** Кількість елементів у фактор-кільці `ℤ[i]/(α)` точно дорівнює алгебраїчній нормі елемента `α`:

```
|ℤ[i]/(α)| = N(α) = a² + b²
```

*Геометричне обґрунтування.* Ідеал `(α) = α · ℤ[i]` утворює підрешітку на комплексній площині, отриману з вихідної решітки `ℤ[i]` поворотом на кут `arg(α)` та масштабуванням у `|α| = √(a² + b²)` разів. Площа фундаментальної комірки вихідної решітки дорівнює 1. Площа фундаментального паралелограма підрешітки `(α)` дорівнює квадрату довжини базисного вектора, тобто `|α|² = a² + b² = N(α)`. Оскільки кожен клас лишків відповідає рівно одній цілій точці всередині фундаментального паралелограма, кількість класів лишків точно дорівнює площі `N(α)`.

**Теорема 6 (Ізоморфізм фактор-кілець за простими модулями).**
Для простих гауссових чисел `π` фактор-кільце `ℤ[i]/(π)` є скінченним полем (полем Галуа):

1. Якщо `π = 1 + i` (розгалужене просте):
```
ℤ[i]/(1 + i) ≅ 𝔽₂
```
Фактор-поле складається рівно з двох елементів `{0, 1}`.

2. Якщо `π = a + bi` (розщеплене просте, `N(π) = p ≡ 1 mod 4`):
```
ℤ[i]/(π) ≅ 𝔽_p
```
Фактор-поле ізоморфне стандартному скінченному полю лишків `ℤ/pℤ` з `p` елементами.

3. Якщо `p ≡ 3 (mod 4)` (інертне просте, `N(p) = p²`):
```
ℤ[i]/(p) ≅ 𝔽_{p²}
```
Фактор-кільце є полем Галуа з `p²` елементів, яке утворюється приєднанням кореня многочлена `x² + 1` до простого поля `𝔽_p`.

**Комплексна функція Ейлера.** За аналогією зі звичайною теорією чисел, функція Ейлера `φ(α)` для гауссового числа `α` визначається як порядок мультиплікативної групи оборотних елементів фактор-кільця: `φ(α) = |(ℤ[i]/(α))×|`.

Завдяки китайській теоремі про залишки та мультиплікативності для довільного розкладу `α = u · ∏ πⱼ^(kⱼ)` функція Ейлера обчислюється за формулою:

```
φ(α) = N(α) · ∏ (1 - 1/N(πⱼ))
```

Для будь-якого елемента `β`, взаємно простого з `α` (`gcd(β, α) = 1`), виконується теорема Ейлера в `ℤ[i]`:

```
β^(φ(α)) ≡ 1 (mod α)
```

Ця формула повністю переносить апарат модульної арифметики на комплексну площину і лежить в основі комплексних криптографічних протоколів та теоретико-числових перетворень.

### 6. Китайська теорема про залишки та максимальність простих ідеалів

**Теорема 7 (Максимальність простих ідеалів у ℤ[i]).** Кожен ненульовий простий ідеал `(π)` в кільці `ℤ[i]` є максимальним ідеалом.

*Доведення.* Нехай `π` — просте гауссове число і нехай `J` — такий ідеал, що `(π) ⊆ J ⊆ ℤ[i]`.
Оскільки `ℤ[i]` є кільцем головних ідеалів (PID), існує такий елемент `δ ∈ ℤ[i]`, що `J = (δ)`.
Умова `(π) ⊆ (δ)` означає, що `δ | π`.
Оскільки `π` є незвідним (простим) елементом, його єдиними дільниками є або оборотні одиниці, або числа, асоційовані з `π`:
1. Якщо `δ` є оборотною одиницею (`N(δ) = 1`), то `J = (δ) = ℤ[i]`.
2. Якщо `δ` асоційоване з `π`, то `J = (δ) = (π)`.
Отже, між `(π)` та `ℤ[i]` не існує жодного проміжного ідеалу, що й означає максимальність ідеалу `(π)`. За загальною теоремою теорії кілець, фактор-кільце за максимальним ідеалом `ℤ[i]/(π)` обов'язково є полем.

**Теорема 8 (Китайська теорема про залишки для ℤ[i]).** Нехай `α₁, α₂, ..., αₖ` — попарно взаємно прості гауссові цілі числа (`gcd(αⱼ, αₘ) = 1` для всіх `j ≠ m`). Тоді для будь-якого набору лишків `γ₁, γ₂, ..., γₖ ∈ ℤ[i]` система порівнянь:

```
x ≡ γ₁ (mod α₁)
x ≡ γ₂ (mod α₂)
...
x ≡ γₖ (mod αₖ)
```

має єдиний розв'язок за модулем добутку `M = α₁ · α₂ · ... · αₖ`.

Фактор-кільце ізоморфне прямому добутку фактор-кілець:

```
ℤ[i]/(M) ≅ ℤ[i]/(α₁) × ℤ[i]/(α₂) × ... × ℤ[i]/(αₖ)
```

Явна конструкція розв'язку будується за аналогією з класичною арифметикою: для кожного індексу `j` покладаємо `Mⱼ = M / αⱼ`. Оскільки `gcd(Mⱼ, αⱼ) = 1`, за співвідношенням Безу в `ℤ[i]` існують такі коефіцієнти `uⱼ, vⱼ ∈ ℤ[i]`, що `uⱼ · Mⱼ + vⱼ · αⱼ = 1`. Позначимо `eⱼ = uⱼ · Mⱼ`. Тоді `eⱼ ≡ 1 (mod αⱼ)` та `eⱼ ≡ 0 (mod αₘ)` для всіх `m ≠ j`. Шуканий розв'язок системи порівнянь задається явною сумою:

```
x = ∑ (γⱼ · eⱼ) = γ₁·e₁ + γ₂·e₂ + ... + γₖ·eₖ (mod M)
```

Цей результат дозволяє розпаралелювати будь-які складні модульні обчислення над гауссовими числами на незалежні обчислення у скінченних полях `𝔽_p` та `𝔽_{p²}`, що має вирішальне значення для оптимізації алгоритмів цифрової обробки сигналів та теоретико-числових перетворень.
