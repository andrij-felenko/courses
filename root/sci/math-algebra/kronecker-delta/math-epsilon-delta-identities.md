# 🧮 Тотожності Епсилон-Дельта: покрокові виведення, визначники та векторні згортки

У векторному аналізі, механіці суцільних середовищ, електродинаміці Максвелла та загальній теорії відносності обчислення векторних добутків і операцій ротора постійно призводить до виразів із кількома антисиметричними символами Леві-Чивіти `ε_ijk`. Якщо розкривати такі векторні комбінації прямим перебором координат у тривимірному просторі, виникають десятки громіздких алгебраїчних доданків, у яких легко припуститися помилки зі знаком.

Математичним фундаментом, який спрощує ці перетворення до механічної заміни індексів, є сімейство **тотожностей Епсилон-Дельта**. Вони перетворюють добутки антисиметричних символів Леві-Чивіти на комбінації простих символів Кронекера, перекладаючи геометрію просторових поворотів на мову елементарної індексної алгебри.

### Орієнтований об'єм та мішаний добуток трьох векторів

Перед тим як перейти до згорток, з'ясуємо геометричний зміст самого символу Леві-Чивіти `ε_ijk`. У тривимірному евклідовому просторі три вектори `a`, `b`, `c` натягують просторовий паралелепіпед. Його орієнтований об'єм визначається як **мішаний (скалярно-векторний) добуток**:

```
V = a · (b × c)
```

Алгебраїчно цей об'єм є полілінійною кососиметричною формою від трьох векторних аргументів. Знак результату залежить від просторової орієнтації: парна кількість перестановок векторів зберігає праву трійку (`+1`), непарна перестановка обертає орієнтацію на ліву (`-1`), а будь-яка лінійна залежність між векторами стягує об'єм паралелепіпеда в нуль.

Розпишемо цей добуток в індексній формі, скориставшись означенням скалярного та векторного добутків:

```
a · (b × c)
= ∑_i a_i · (b × c)_i                   [скалярний добуток в індексній формі]
= ∑_i a_i · ( ∑_j ∑_k ε_ijk · b_j · c_k ) [розклад векторного добутку через символ Леві-Чивіти]
= ∑_i ∑_j ∑_k ε_ijk · a_i · b_j · c_k   [об'єднання знаків підсумовування]
```

Ця потрійна сума точно дорівнює визначнику матриці розміру `3 × 3`, утвореної координатами векторів `a`, `b`, `c`, розташованими у рядках:

```
det [
    [ a_1  a_2  a_3 ]
    [ b_1  b_2  b_3 ]
    [ c_1  c_2  c_3 ]
]
= ∑_i ∑_j ∑_k ε_ijk · a_i · b_j · c_k
```

Символ Леві-Чивіти виступає універсальним тензором орієнтованого об'єму. Якщо вектори `a, b, c` утворюють праву трійку, визначник додатний; якщо ліву — від'ємний; а якщо всі три вектори лежать в одній площині (компланарні), визначник тотожно дорівнює нулю.

### Фундаментальне представлення через визначник 3×3

Вихідним пунктом для всіх тотожностей епсилон-дельта є точний вираз для добутку двох незалежних символів Леві-Чивіти `ε_ijk` та `ε_lmn` через визначник квадратної матриці розміру `3 × 3`, складеної з попарних символів Кронекера:

```
ε_ijk · ε_lmn = det [
    [ δ_il  δ_im  δ_in ]
    [ δ_jl  δ_jm  δ_jn ]
    [ δ_kl  δ_km  δ_kn ]
]
```

Цей вираз стверджує, що взаємодія двох просторових орієнтацій повністю описується матрицею парних скалярних добутків між відповідними осями координат. Доведемо справедливість цієї рівності, послідовно перевіривши всі її фундаментальні алгебраїчні властивості:

1. **Повна антисиметрія за першим набором індексів `(i, j, k)`:** якщо поміняти місцями будь-які два індекси з трійки `(i, j, k)` (наприклад, поміняти перший індекс `i` та другий індекс `j`), у матриці Кронекера міняються місцями перший і другий рядки. За базовою властивістю [визначників матриць](root:math-algebra/matrix-determinant) обмін двох рядків змінює знак визначника на протилежний. Ліва частина `ε_ijk · ε_lmn` також строго змінює свій знак на протилежний через антисиметрію першого символу Леві-Чивіти.
2. **Повна антисиметрія за другим набором індексів `(l, m, n)`:** перестановка двох індексів із правої трійки `(l, m, n)` (наприклад, `l` та `m`) призводить до взаємного обміну першого та другого стовпчиків матриці. Це знову змінює знак визначника на протилежний, що ідеально узгоджується зі зміною знака другого символу Леві-Чивіти `ε_lmn`.
3. **Збіг індексів (виродження):** якщо хоча б два індекси в лівій або правій трійці виявляються однаковими (наприклад, `i = j`), відповідні два рядки матриці стають повністю ідентичними. Визначник матриці з двома однаковими рядками тотожно дорівнює нулю. Ліва частина також тотожно перетворюється на нуль через умову `ε_iik = 0`.
4. **Нормувальна точка канонічного базису:** перевіримо значення виразу для прямої орієнтації координат, поклавши `(i, j, k) = (1, 2, 3)` та `(l, m, n) = (1, 2, 3)`. Ліва частина дорівнює добутку двох одиниць `ε_123 · ε_123 = 1 · 1 = 1`. Права частина перетворюється на визначник тривимірної одиничної матриці:

```
det [
    [ δ_11  δ_12  δ_13 ]       det [
    [ δ_21  δ_22  δ_23 ]   =       [ 1  0  0 ]
    [ δ_31  δ_32  δ_33 ]           [ 0  1  0 ]   = 1
]                                  [ 0  0  1 ]
                               ]
```

Оскільки обидві частини рівності є кососиметричними за обома наборами індексів і повністю збігаються в нормувальній точці, рівність доведена строго для будь-яких можливих комбінацій усіх шести індексів.

### Згортка першого порядку: один спільний індекс

Найважливіша операція у тривимірному векторному численні виникає тоді, коли два символи Леві-Чивіти мають один спільний індекс підсумовування (покладемо `l = i` і виконаємо підсумовування за індексом `i` від `1` до `3`):

```
S_{jkmn} = ∑_{i=1}^3 ε_ijk · ε_imn
```

Щоб отримати явний вираз цієї згортки, розкриємо визначник матриці `3 × 3` за елементами першого рядка через алгебраїчні доповнення:

```
det [
    [ δ_il  δ_im  δ_in ]
    [ δ_jl  δ_jm  δ_jn ]
    [ δ_kl  δ_km  δ_kn ]
]
= δ_il · ( δ_jm · δ_kn - δ_jn · δ_km )   [алгебраїчне доповнення до елемента δ_il]
- δ_im · ( δ_jl · δ_kn - δ_jn · δ_kl )   [алгебраїчне доповнення до елемента δ_im зі знаком мінус]
+ δ_in · ( δ_jl · δ_km - δ_jm · δ_kl )   [алгебраїчне доповнення до елемента δ_in зі знаком плюс]
```

Тепер покладемо `l = i` та виконаємо явне підсумовування за індексом `i` від `1` до `3`:

```
∑_i ε_ijk · ε_imn
= ∑_i δ_ii · ( δ_jm · δ_kn - δ_jn · δ_km )
- ∑_i δ_im · ( δ_ji · δ_kn - δ_jn · δ_ki )
+ ∑_i δ_in · ( δ_ji · δ_km - δ_jm · δ_ki )
```

Обчислимо кожен із трьох доданків окремо:

1. **Перший доданок:** сума `∑_{i=1}^3 δ_ii = δ_11 + δ_22 + δ_33 = 1 + 1 + 1 = 3` дорівнює сліду тривимірної одиничної матриці (розмірності простору `n = 3`):

```
∑_i δ_ii · ( δ_jm · δ_kn - δ_jn · δ_km )
= 3 · ( δ_jm · δ_kn - δ_jn · δ_km )      [слід одиничної матриці дорівнює 3]
```

2. **Другий доданок:** завдяки фільтруючій властивості символу Кронекера за індексом `i`, символ `δ_im` перетворює індекс `i` на `m`:

```
∑_i δ_im · ( δ_ji · δ_kn - δ_jn · δ_ki )
= δ_jm · δ_kn - δ_jn · δ_km              [підстановка i = m у внутрішні дельти]
```

3. **Третій доданок:** аналогічно, символ `δ_in` перетворює індекс `i` на `n`:

```
∑_i δ_in · ( δ_ji · δ_km - δ_jm · δ_ki )
= δ_jn · δ_km - δ_jm · δ_kn              [підстановка i = n у внутрішні дельти]
= - ( δ_jm · δ_kn - δ_jn · δ_km )        [винесення знака мінус]
```

Зберемо всі три доданки разом:

```
∑_i ε_ijk · ε_imn
= 3 · ( δ_jm · δ_kn - δ_jn · δ_km )
- 1 · ( δ_jm · δ_kn - δ_jn · δ_km )
- 1 · ( δ_jm · δ_kn - δ_jn · δ_km )      [підстановка розкритих доданків]
= (3 - 1 - 1) · ( δ_jm · δ_kn - δ_jn · δ_km ) [зведення подібних членів]
= δ_jm · δ_kn - δ_jn · δ_km              [підсумковий коефіцієнт дорівнює 1]
```

Отримано фундаментальну **тотожність Епсилон-Дельта першого порядку**:

```
∑_i ε_ijk · ε_imn = δ_jm · δ_kn - δ_jn · δ_km
```

Вона стверджує, що згортка двох символів Леві-Чивіти за одним спільним індексом дорівнює різниці добутків двох пар символів Кронекера: «прямі пари індексів мінус перехресні пари». Геометрично це відповідає проєктуванню векторного добутку на базисні напрямки.

### Згортки другого та третього порядку

Якщо два символи Леві-Чивіти мають два спільних індекси підсумовування, ми виконуємо згортку отриманого виразу ще за одним індексом. Покладемо `m = j` та підсумуємо за індексом `j` від `1` до `3`:

```
∑_i ∑_j ε_ijk · ε_ijn
= ∑_j ( δ_jj · δ_kn - δ_jn · δ_kj )      [підстановка m = j у тотожність першого порядку]
= ( ∑_j δ_jj ) · δ_kn - ∑_j δ_jn · δ_kj  [розділення на дві суми]
= 3 · δ_kn - δ_kn                        [слід δ_jj = 3 та згортка δ_jn δ_kj = δ_kn]
= 2 · δ_kn                               [підсумкова тотожність другого порядку]
```

Коефіцієнт `2` точно дорівнює `(3 - 1)!` (кількості перестановок двох вільних індексів, що залишилися). Цей результат показує, що згортка за двома осями залишає подвоєний одиничний оператор уздовж третьої осі.

Якщо виконати повну згортку за всіма трьома індексами (поклавши `n = k` та підсумувавши за `k`):

```
∑_i ∑_j ∑_k ε_ijk · ε_ijk
= ∑_k 2 · δ_kk                           [підстановка n = k у тотожність другого порядку]
= 2 · ( ∑_k δ_kk )                       [винесення двійки за знак суми]
= 2 · 3                                  [слід тривимірної матриці дорівнює 3]
= 6                                      [повна сума квадратів усіх компонентів]
```

Результат `6` дорівнює `3!` (повному числу ненульових елементів символу Леві-Чивіти у тривимірному просторі, кожен з яких у квадраті дає `1`). Це перевіряє повноту простору орієнтацій.

### Виведення подвійного векторного добутку: правило BAC-CAB

Розглянемо класичну задачу векторної алгебри: розкрити подвійний векторний добуток `a × (b × c)`. Геометрично результуючий вектор ортогональний до вектора `a` і лежить у площині, натягнутій на вектори `b` та `c`, отже мусить виражатися як їхня лінійна комбінація.

Запишемо `i`-ту просторову координату результату, послідовно застосувавши індексне представлення векторного добутку:

```
( a × (b × c) )_i
= ∑_j ∑_k ε_ijk · a_j · (b × c)_k        [зовнішній векторний добуток]
= ∑_j ∑_k ε_ijk · a_j · ( ∑_m ∑_n ε_kmn · b_m · c_n ) [внутрішній векторний добуток]
= ∑_j ∑_m ∑_n ( ∑_k ε_ijk · ε_kmn ) · a_j · b_m · c_n [об'єднання сум за спільним індексом k]
```

Здійснимо циклічну перестановку індексів у першому символі Леві-Чивіти `ε_ijk = ε_kij`, щоб поставити індекс `k` на першу позицію:

```
∑_k ε_ijk · ε_kmn
= ∑_k ε_kij · ε_kmn                      [циклічна перестановка індексів не змінює знак]
= δ_im · δ_jn - δ_in · δ_jm              [застосування тотожності Епсилон-Дельта першого порядку]
```

Підставимо цю різницю назад у загальну суму:

```
( a × (b × c) )_i
= ∑_j ∑_m ∑_n ( δ_im · δ_jn - δ_in · δ_jm ) · a_j · b_m · c_n [підстановка різниці символів Кронекера]
= ∑_j ∑_m ∑_n δ_im · δ_jn · a_j · b_m · c_n                   [перший доданок суми]
- ∑_j ∑_m ∑_n δ_in · δ_jm · a_j · b_m · c_n                   [другий доданок суми]
```

Виконаємо фільтрацію сум за допомогою властивості заміни індексів дельти Кронекера:

1. **Перший доданок:** символ `δ_im` замінює `m` на `i`, а символ `δ_jn` замінює `n` на `j`:

```
∑_j ∑_m ∑_n δ_im · δ_jn · a_j · b_m · c_n
= ∑_j a_j · b_i · c_j                    [заміна m -> i та n -> j]
= b_i · ( ∑_j a_j · c_j )                [винесення b_i за знак суми за j]
= b_i · (a · c)                          [згортка суми у скалярний добуток векторів a та c]
```

2. **Другий доданок:** символ `δ_in` замінює `n` на `i`, а символ `δ_jm` замінює `m` на `j`:

```
∑_j ∑_m ∑_n δ_in · δ_jm · a_j · b_m · c_n
= ∑_j a_j · b_j · c_i                    [заміна n -> i та m -> j]
= c_i · ( ∑_j a_j · b_j )                [винесення c_i за знак суми за j]
= c_i · (a · b)                          [згортка суми у скалярний добуток векторів a та b]
```

Віднімемо другий результат від першого:

```
( a × (b × c) )_i = b_i · (a · c) - c_i · (a · b)
```

Оскільки це співвідношення виконується для кожної координати `i ∈ {1, 2, 3}`, воно справедливе для векторного виразу в цілому:

```
a × (b × c) = b · (a · c) - c · (a · b)
```

Ми вивели знамениту формулу подвійного векторного добутку (правило BAC-CAB) суто алгебраїчним шляхом, без жодного геометричного креслення. Лінійні коефіцієнти розкладу виявилися простими скалярними добутками.

### Скалярний добуток векторних добутків: тотожність Біне-Коші

Розглянемо ще одне класичне співвідношення векторної алгебри — скалярний добуток двох векторних добутків чотирьох векторів `(a × b) · (c × d)`.

Розпишемо цей вираз в індексних позначеннях:

```
(a × b) · (c × d)
= ∑_i (a × b)_i · (c × d)_i              [скалярний добуток в індексній формі]
= ∑_i ( ∑_j ∑_k ε_ijk · a_j · b_k ) · ( ∑_m ∑_n ε_imn · c_m · d_n ) [розклад обох векторних добутків]
= ∑_j ∑_k ∑_m ∑_n ( ∑_i ε_ijk · ε_imn ) · a_j · b_k · c_m · d_n     [групування суми за спільним індексом i]
```

Застосуємо тотожність Епсилон-Дельта першого порядку до внутрішньої суми за `i`:

```
∑_i ε_ijk · ε_imn = δ_jm · δ_kn - δ_jn · δ_km
```

Підставивши це в загальну суму, маємо:

```
(a × b) · (c × d)
= ∑_j ∑_k ∑_m ∑_n ( δ_jm · δ_kn - δ_jn · δ_km ) · a_j · b_k · c_m · d_n [підстановка тотожності Епсилон-Дельта]
= ( ∑_j a_j c_j ) · ( ∑_k b_k d_k ) - ( ∑_j a_j d_j ) · ( ∑_k b_k c_k ) [фільтрація та розділення сум]
= (a · c) · (b · d) - (a · d) · (b · c)                                 [згортка у скалярні добутки]
```

Це співвідношення називають **тотожністю Лагранжа для векторів**, або окремим випадком формули Біне-Коші для матриць `2 × 2`. Вона показує, що скалярний добуток площ паралелограмів можна розрахувати виключно через попарні довжини та кути між окремими векторами-сторонами.

Якщо покласти `c = a` та `d = b`, ми дістаємо зв'язок між квадратом площі паралелограма та скалярними добутками його сторін:

```
|a × b|² = |a|² · |b|² - (a · b)²
```

Ця формула лежить в основі тригонометричної тотожності `sin² θ = 1 - cos² θ` і показує, як символ Кронекера об'єднує векторну алгебру з тригонометрією.

### Алгебра Лі групи поворотів SO(3) та комутатори генераторів

У квантовій теорії кутового моменту та геометрії групи поворотів простору `SO(3)` символ Леві-Чивіти та символ Кронекера утворюють алгебраїчний скелет генераторів інфінітезимальних обертань.

Генератори поворотів навколо трьох координатних осей `(J_1, J_2, J_3)` можна представити антисиметричними матрицями розміру `3 × 3`, елементи яких задаються символом Леві-Чивіти:

```
(J_k)_ij = - ε_ijk
```

Обчислимо комутатор двох таких матричних генераторів `[J_a, J_b] = J_a · J_b - J_b · J_a`:

```
( [J_a, J_b] )_ij
= ∑_k ( (J_a)_ik · (J_b)_kj - (J_b)_ik · (J_a)_kj )                  [матричне множення та комутатор]
= ∑_k ( (- ε_aik) · (- ε_bkj) - (- ε_bik) · (- ε_akj) )              [підстановка матричних елементів]
= ∑_k ( ε_kai · ε_kbj - ε_kbi · ε_kaj )                              [циклічна перестановка індексів]
```

Застосуємо тотожність Епсилон-Дельта першого порядку до обох добутків:

```
∑_k ε_kai · ε_kbj = δ_ab · δ_ij - δ_aj · δ_ib
∑_k ε_kbi · ε_kaj = δ_ba · δ_ij - δ_bj · δ_ia
```

Віднімемо другий вираз від першого:

```
( [J_a, J_b] )_ij
= ( δ_ab · δ_ij - δ_aj · δ_ib ) - ( δ_ba · δ_ij - δ_bj · δ_ia )      [підстановка результатів згорток]
= δ_ia · δ_jb - δ_ib · δ_ja                                          [скорочення симетричних доданків δ_ab δ_ij]
= - ∑_c ε_abc · ε_cij                                                [згортка через тотожність Епсилон-Дельта]
= ∑_c ε_abc · (J_c)_ij                                               [повернення до генераторів (J_c)_ij = - ε_cij]
```

Отримано фундаментальне комутаційне співвідношення алгебри Лі `so(3)`:

```
[J_a, J_b] = ∑_c ε_abc · J_c
```

Константи структури групи тривимірних просторових поворотів виявляються тотожними символу Леві-Чивіти саме завдяки тотожностям Епсилон-Дельта.

### Числовий приклад розрахунку подвійного векторного добутку

Для остаточної перевірки виведеної тотожності обчислимо подвійний векторний добуток на конкретних числових векторах двома незалежними шляхами: за прямим геометричним означенням та за отриманою формулою Епсилон-Дельта.

Нехай задано три вектори:

```
a = (1, 2, 3)
b = (4, 0, 1)
c = (2, 1, 0)
```

**Шлях 1: пряме покрокове обчислення через векторні добутки.**

Спочатку обчислимо внутрішній добуток `d = b × c` через визначники координат:

```
d_1 = b_2 · c_3 - b_3 · c_2 = 0 · 0 - 1 · 1 = -1
d_2 = b_3 · c_1 - b_1 · c_3 = 1 · 2 - 4 · 0 = 2
d_3 = b_1 · c_2 - b_2 · c_1 = 4 · 1 - 0 · 2 = 4
```

Отримали проміжний вектор `d = (-1, 2, 4)`. Тепер обчислимо зовнішній добуток `res = a × d`:

```
res_1 = a_2 · d_3 - a_3 · d_2 = 2 · 4 - 3 · 2 = 8 - 6 = 2
res_2 = a_3 · d_1 - a_1 · d_3 = 3 · (-1) - 1 · 4 = -3 - 4 = -7
res_3 = a_1 · d_2 - a_2 · d_1 = 1 · 2 - 2 · (-1) = 2 + 2 = 4
```

Прямий розрахунок дає вектор `res = (2, -7, 4)`.

**Шлях 2: обчислення за формулою BAC-CAB через скалярні добутки.**

Обчислимо два скалярні добутки:

```
a · c = 1 · 2 + 2 · 1 + 3 · 0 = 2 + 2 + 0 = 4
a · b = 1 · 4 + 2 · 0 + 3 · 1 = 4 + 0 + 3 = 7
```

Тепер складемо лінійну комбінацію векторів `b · (a · c) - c · (a · b)`:

```
res = 4 · (4, 0, 1) - 7 · (2, 1, 0)
    = (16, 0, 4) - (14, 7, 0)           [множення векторів на відповідні скаляри]
    = (16 - 14,  0 - 7,  4 - 0)         [покомпонентне віднімання векторів]
    = (2, -7, 4)                        [остаточний векторний результат]
```

Обидва незалежні шляхи дали абсолютно однаковий вектор `(2, -7, 4)`. Формула, отримана через згортку символу Кронекера, повністю підтверджена числовим тестом.

### Диференціальні векторні тотожності та електродинаміка

У математичній фізиці оператор набла `∇` діє на просторові поля як вектор частинних похідних `∂_i = ∂/∂x_i`. Завдяки тотожності Епсилон-Дельта складні диференціальні векторні операції зводяться до лінійних комбінацій градієнта, дивергенції та лапласіана.

Розглянемо виведення **подвійного ротора** векторного поля `A`:

```
( rot(rot A) )_i = ( ∇ × (∇ × A) )_i
```

В індексній формі:

```
( ∇ × (∇ × A) )_i
= ∑_j ∑_k ε_ijk · ∂_j · ( ∇ × A )_k                                    [зовнішній ротор]
= ∑_j ∑_k ε_ijk · ∂_j · ( ∑_m ∑_n ε_kmn · ∂_m A_n )                    [внутрішній ротор]
= ∑_j ∑_m ∑_n ( ∑_k ε_kij · ε_kmn ) · ∂_j ∂_m A_n                      [групування за індексом k]
= ∑_j ∑_m ∑_n ( δ_im δ_jn - δ_in δ_jm ) · ∂_j ∂_m A_n                  [тотожність Епсилон-Дельта]
= ∑_j ∑_m ∑_n δ_im δ_jn ∂_j ∂_m A_n - ∑_j ∑_m ∑_n δ_in δ_jm ∂_j ∂_m A_n [розподіл на два доданки]
```

Застосуємо символ Кронекера для зняття підсумовування:

1. У першому доданку `δ_im` замінює `m` на `i`, а `δ_jn` замінює `n` на `j`:

```
∑_j ∂_j ∂_i A_j = ∂_i · ( ∑_j ∂_j A_j ) = ∂_i · (div A) = ( grad(div A) )_i
```

2. У другому доданку `δ_in` перетворює `n` на `i`, а `δ_jm` перетворює `m` на `j`:

```
∑_j ∂_j ∂_j A_i = ( ∑_j ∂_j² ) · A_i = ∇² A_i = ( ΔA )_i
```

Підсумкова рівність:

```
rot(rot A) = grad(div A) - ΔA
```

Це рівняння лежить в основі класичної електродинаміки: у вакуумі без зарядів і струмів (`div E = 0`) рівняння Максвелла перетворюються на хвильове рівняння швидкості світла `ΔE - (1/c²) ∂²E/∂t² = 0`. Саме відсутність джерел заряду дозволяє ротору ротора перетворитися на чистий просторовий лапласіан.

У гідродинаміці ідеальної нестисливої рідини (рівняння Ейлера та Нав'є — Стокса) аналогічне розкриття ротора від векторного добутку швидкості `v` на вектор завихреності `ω = rot v` формує динамічне рівняння еволюції вихорів (теорема Гельмгольца про збереження вихрових ліній):

```
rot(v × ω) = (ω · ∇)v - (v · ∇)ω + v · (div ω) - ω · (div v)
```

Оскільки завихреність є ротором, її дивергенція тотожно дорівнює нулю `div ω = div(rot v) = 0`, а для нестисливої рідини `div v = 0`. Чотиричленний векторний вираз завдяки символу Кронекера спрощується до двох членів конвективного переносу та розтягування вихрових ниток `(ω · ∇)v - (v · ∇)ω`.

Ще одна важлива диференціальна тотожність стосується **градієнта скалярного добутку** двох векторних полів:

```
grad(a · b) = (a · ∇)b + (b · ∇)a + a × (rot b) + b × (rot a)
```

Її розгортання в індексній формі через символ Кронекера `∂_i (a_j b_j) = (∂_i a_j) b_j + a_j (∂_i b_j)` і наступне застосування тотожності Епсилон-Дельта до векторних добутків `a × (rot b)` повністю підтверджує взаємне скорочення всіх перехресних просторових похідних.

### Збереження моменту імпульсу в класичній механіці

Простежимо, як за допомогою символу Леві-Чивіти та властивостей симетрії дельти Кронекера доводиться закон збереження моменту імпульсу матеріальної точки у центральному силовому полі.

Вектор моменту імпульсу частинки масою `m` з радіус-вектором `r` та імпульсом `p = m · v` визначається як `L = r × p`. В індексній формі:

```
L_i = ∑_j ∑_k ε_ijk · r_j · p_k
```

Обчислимо похідну моменту імпульсу за часом `t`:

```
d L_i / dt
= ∑_j ∑_k ε_ijk · ( (dr_j / dt) · p_k + r_j · (dp_k / dt) )            [похідна добутку за часом]
= ∑_j ∑_k ε_ijk · ( v_j · (m · v_k) + r_j · F_k )                      [підстановка швидкості v та сили F]
= m · ( ∑_j ∑_k ε_ijk · v_j · v_k ) + ∑_j ∑_k ε_ijk · r_j · F_k       [винесення маси m за знак суми]
```

Розглянемо перший доданок `∑_j ∑_k ε_ijk · v_j · v_k`. Вираз `v_j · v_k` є повністю симетричним щодо перестановки індексів `j` та `k` (`v_j · v_k = v_k · v_j`), тоді як символ Леві-Чивіти `ε_ijk` є антисиметричним (`ε_ikj = - ε_ijk`). Згортка будь-якого симетричного тензора з антисиметричним строго дорівнює нулю:

```
∑_j ∑_k ε_ijk · v_j · v_k
= (1/2) · ∑_j ∑_k ( ε_ijk + ε_ikj ) · v_j · v_k                        [симетризація суми за індексами j та k]
= (1/2) · ∑_j ∑_k ( ε_ijk - ε_ijk ) · v_j · v_k                        [властивість антисиметрії символу Леві-Чивіти]
= 0                                                                    [множення на нуль]
```

Залишається другий доданок — векторний момент зовнішньої сили `M = r × F`:

```
d L_i / dt = ( r × F )_i = M_i
```

Якщо сила є центральною (напрямлена вздовж радіус-вектора `F = f(r) · r`), то `r × F = f(r) · (r × r) = 0`, і момент імпульсу є строгою інтегральною константою руху.

### Узагальнення на n-вимірний простір

У довільному `n`-вимірному евклідовому або псевдорімановому просторі символ Леві-Чивіти стає тензором рангу `n` з індексами `ε_{i_1 i_2 ... i_n}`.

Повний добуток двох таких антисиметричних символів виражається через визначник квадратної матриці розміру `n × n`, складеної з простих символів Кронекера:

```
ε_{i_1 i_2 ... i_n} · ε_{j_1 j_2 ... j_n} = det [
    [ δ_{i_1 j_1}  δ_{i_1 j_2}  ...  δ_{i_1 j_n} ]
    [ δ_{i_2 j_1}  δ_{i_2 j_2}  ...  δ_{i_2 j_n} ]
    [     ...            ...    ...        ...    ]
    [ δ_{i_n j_1}  δ_{i_n j_2}  ...  δ_{i_n j_n} ]
]
```

Якщо виконати згортку за першими `k` індексами (`1 ≤ k ≤ n`), результат виражається через факторіал кількості згорнутих індексів та узагальнений символ Кронекера порядку `n - k`:

```
∑_{i_1 ... i_k} ε_{i_1 ... i_k j_{k+1} ... j_n} · ε_{i_1 ... i_k m_{k+1} ... m_n}
= k! · δ^{j_{k+1} ... j_n}_{m_{k+1} ... m_n}
```

Зокрема, при повній згортці за всіма `n` індексами (`k = n`):

```
∑_{i_1 ... i_n} ( ε_{i_1 i_2 ... i_n} )² = n!
```

У чотиривимірному просторі-часі Мінковського (спеціальна теорія відносності, `n = 4`) повна згортка тензора електромагнітного поля `F_μν` з його дуальним тензором Ходжа `*F_μν = (1/2) · ε_μναβ F^αβ` формує релятивістські інваріанти поля:

```
ε_μναβ · ε^μνγδ = - 2! · ( δ^γ_α · δ^δ_β - δ^γ_β · δ^δ_α )
```

Знак мінус тут виникає через псевдоевклідову сигнатуру метрики простору-часу `(-, +, +, +)` або `(+, -, -, -)`.

Тотожності Епсилон-Дельта є універсальним алгебраїчним мостом, який перетворює важкі багатовимірні перестановки на механічні операції з дельтами Кронекера, утворюючи фундамент сучасного векторного та тензорного аналізу. Вони дозволяють звести складні геометричні, гідродинамічні та релятивістські співвідношення до послідовності чітких, алгоритмічно замкнених операцій заміни та скорочення індексів.
