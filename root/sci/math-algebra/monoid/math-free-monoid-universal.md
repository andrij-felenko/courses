# 🧮 Вільний моноїд та універсальна властивість

Вільні алгебраїчні структури займають особливе місце в сучасній математиці: вони містять рівно стільки співвідношень між своїми елементами, скільки вимагають аксіоми самої теорії, і жодного додаткового зв'язку чи обмеження. Для теорії моноїдів такою універсальною конструкцією є **вільний моноїд** слів над алфавітом. Усі інші моноїди у всесвіті математики можна отримати з вільного моноїда шляхом факторизації за відповідними конгруенціями.

### Формальна побудова моноїда слів

Нехай `Σ` — довільна непорожня множина, яку ми називатимемо **алфавітом** (лат. *alphabetum*), а її елементи — **символами** або буквами. Алфавіт може бути як скінченним (наприклад, двійковий алфавіт `{0, 1}` або символи ASCII), так і нескінченним.

**Словом** довжини `k ≥ 0` над алфавітом `Σ` називають скінченну впорядковану послідовність символів `w = (a₁, a₂, …, aₖ)`, де кожен `aᵢ ∈ Σ`.
- Якщо `k = 0`, послідовність не містить жодного символу. Таке слово називають **порожнім словом** і позначають грецькою літерою `ε` (епсилон).
- Довжину слова `w` позначають через `|w|`. Зокрема, `|ε| = 0`, а для слова `w = (a₁, …, aₖ)` маємо `|w| = k`.

Множину всіх слів скінченної довжини над алфавітом `Σ` позначають через `Σ*` (зірочка Кліні на честь Стівена Кліні):

```
Σ* = {ε} ∪ Σ ∪ (Σ × Σ) ∪ (Σ × Σ × Σ) ∪ …
```

Визначимо бінарну операцію **конкатенації** (зчеплення, склеювання) слів `· : Σ* × Σ* → Σ*`. Для довільних двох слів `u = (a₁, a₂, …, aₘ)` та `v = (b₁, b₂, …, bₙ)` їхній добуток `u · v` (який часто записують просто як `uv`) визначається як послідовне приписування символів слова `v` після символів слова `u`:

```
u · v = (a₁, a₂, …, aₘ, b₁, b₂, …, bₙ)
```

Для порожнього слова `ε` операція визначається за природним правилом нейтральності:

```
u · ε = u
ε · u = u
```

**Твердження 1.** *Трійка `(Σ*, ·, ε)` утворює моноїд.*

*Доведення.*
1. **Замкненість:** Зчеплення двох скінченних послідовностей довжин `m` та `n` дає нову скінченну послідовність довжини `m + n`, яка за означенням належить `Σ*`.
2. **Асоціативність:** Нехай `u = (a₁, …, aₘ)`, `v = (b₁, …, bₙ)`, `w = (c₁, …, cₖ)` — три довільні слова. Обчислимо обидва варіанти групування:

```
(u · v) · w
= (a₁, …, aₘ, b₁, …, bₙ) · (c₁, …, cₖ)             [за означенням операції u · v]
= (a₁, …, aₘ, b₁, …, bₙ, c₁, …, cₖ)                 [конкатенація результату зі словом w]
= (a₁, …, aₘ) · (b₁, …, bₙ, c₁, …, cₖ)                 [виділення префікса u]
= u · (v · w)                                         [за означенням операції v · w]
```

3. **Нейтральний елемент:** За безпосереднім означенням операції з `ε`, для будь-якого `w ∈ Σ*` маємо `w · ε = ε · w = w`.

Структуру `(Σ*, ·, ε)` називають **вільним моноїдом**, породженим множиною `Σ`.

### Теорема про універсальну властивість

Канонічним вкладенням алфавіту `Σ` у вільний моноїд `Σ*` є відображення `i: Σ → Σ*`, яке кожному символу `a ∈ Σ` зіставляє одноелементне слово `(a)` довжини 1:

```
i(a) = (a)
```

**Теорема (Універсальна властивість вільного моноїда).**
*Нехай `Σ` — довільна множина, а `(M, ⋆, e_M)` — довільний моноїд із бінарною операцією `⋆` та нейтральним елементом `e_M`. Для будь-якого відображення множин `f: Σ → M` існує єдиний гомоморфізм моноїдів `f̄: Σ* → M` такий, що діаграма комутує, тобто:*

```
f̄ ∘ i = f
```

*Іншими словами, для кожного символу `a ∈ Σ` виконується `f̄(i(a)) = f(a)`.*

```
       i
  Σ ───────→ Σ*
   \        │
    \       │ ∃! f̄
   f \      │
      ↘     ↓
         M
```

### Покрокове доведення теореми

Доведення розпадається на дві послідовні логічні ланки: побудову (доведення існування) шуканого відображення `f̄` та строге доведення його єдиності.

#### 1. Існування гомоморфізму `f̄`

Визначимо відображення `f̄: Σ* → M` за математичною індукцією на основі довжини слова `w ∈ Σ*`:
- Для порожнього слова `w = ε` (довжина 0):
  ```
  f̄(ε) = e_M
  ```
- Для слова `w = (a₁, a₂, …, aₖ)` довжини `k ≥ 1`:
  ```
  f̄(a₁, a₂, …, aₖ) = f(a₁) ⋆ f(a₂) ⋆ … ⋆ f(aₖ)
  ```
  Оскільки операція `⋆` у моноїді `M` асоціативна, результат цього скінченного ланцюжка добутків визначений абсолютно однозначно і не залежить від порядку розставляння проміжних дужок.

Перевіримо виконання трьох необхідних властивостей:

**А. Комутативність трикутника `f̄ ∘ i = f`:**
Для будь-якого окремого символу `a ∈ Σ` слово `i(a) = (a)` має довжину 1. Обчислимо його значення за формулою:
```
(f̄ ∘ i)(a)
= f̄(i(a))       [за означенням композиції відображень]
= f̄((a))        [за означенням вкладення i(a) = (a)]
= f(a)          [за базовою формулою f̄ для слів довжини 1]
```
Рівність виконується для всіх `a ∈ Σ`.

**Б. Збереження нейтрального елемента:**
За прямим означенням побудови:
```
f̄(ε) = e_M
```

**В. Збереження бінарної операції (властивість гомоморфізму):**
Нехай `u = (a₁, …, aₘ)` та `v = (b₁, …, bₙ)` — два довільні слова із `Σ*`.
- Якщо одне зі слів порожнє, наприклад `v = ε`, то `u · ε = u` і:
  ```
  f̄(u · ε) = f̄(u) = f̄(u) ⋆ e_M = f̄(u) ⋆ f̄(ε)
  ```
- Якщо обидва слова непорожні (`m ≥ 1` та `n ≥ 1`), то їхня конкатенація має вигляд `u · v = (a₁, …, aₘ, b₁, …, bₙ)`. Обчислимо значення `f̄(u · v)`:

```
f̄(u · v)
= f̄(a₁, …, aₘ, b₁, …, bₙ)                                         [за означенням конкатенації u · v]
= f(a₁) ⋆ … ⋆ f(aₘ) ⋆ f(b₁) ⋆ … ⋆ f(bₙ)                             [за означенням відображення f̄]
= (f(a₁) ⋆ … ⋆ f(aₘ)) ⋆ (f(b₁) ⋆ … ⋆ f(bₙ))                         [асоціативність операції ⋆ у моноїді M]
= f̄(u) ⋆ f̄(v)                                                     [за означенням f̄(u) та f̄(v)]
```

Отже, відображення `f̄` є коректним гомоморфізмом моноїдів.

---

#### 2. Єдиність гомоморфізму `f̄`

Припустимо тепер, що існує ще один гомоморфізм моноїдів `g: Σ* → M`, який задовольняє ту саму умову комутативності: `g ∘ i = f`, тобто `g((a)) = f(a)` для кожного символу `a ∈ Σ`.

Доведемо за математичною індукцією за довжиною слова `k = |w|`, що `g(w) = f̄(w)` для всіх без винятку слів `w ∈ Σ*`.

- **База індукції (`k = 0`):**
  Слово `w = ε`. Оскільки `g` є гомоморфізмом моноїдів, воно за аксіомою гомоморфізму зобов'язане зберігати нейтральний елемент:
  ```
  g(ε) = e_M = f̄(ε)
  ```

- **Крок індукції (`k = 1`):**
  Для одноелементного слова `w = (a)` довжини 1 маємо `g((a)) = g(i(a)) = f(a) = f̄((a))`.

- **Індукційний перехід (`k > 1`):**
  Нехай твердження вже доведено для всіх слів довжини, строго меншої за `k`. Розглянемо довільне слово `w = (a₁, a₂, …, aₖ)` довжини `k`.
  Це слово можна розбити на конкатенацію префікса довжини `k − 1` та останнього символу: `w = u · (aₖ)`, де `u = (a₁, …, aₖ₋₁)`.

Обчислимо значення `g(w)`:

```
g(w)
= g(u · (aₖ))          [подання слова w як конкатенації u та (aₖ)]
= g(u) ⋆ g((aₖ))       [властивість гомоморфізму g для операції конкатенації]
= f̄(u) ⋆ f̄((aₖ))       [припущення індукції для u та база для (aₖ)]
= f̄(u · (aₖ))          [властивість гомоморфізму f̄ для операції конкатенації]
= f̄(w)                 [оскільки u · (aₖ) = w]
```

З принципу математичної індукції випливає, що `g(w) = f̄(w)` для будь-якого слова `w ∈ Σ*`. Отже, шуканий гомоморфізм єдиний.

Теорему доведено повністю. ∎

### Окремі випадки та розбір прикладів

Щоб універсальна властивість набула відчутного фізичного змісту, розгляньмо кілька показових конкретних прикладів.

#### 1. Вільний моноїд з одним генератором (`|Σ| = 1`)

Нехай алфавіт складається лише з одного символу: `Σ = {x}`.
Словами над цим алфавітом є скінченні послідовності `ε, (x), (x, x), (x, x, x), …`, тобто степені `x⁰, x¹, x², x³, …`.
Конкатенація слів зводиться до додавання їхніх довжин: `xᵐ · xⁿ = xᵐ⁺ⁿ`.

Якщо взяти як цільовий моноїд натуральні числа з додаванням `(ℕ, +, 0)` і задати відображення `f(x) = 1`, то єдиний індукований гомоморфізм `f̄` відображає кожне слово `xⁿ` у число `n`:
```
f̄(xⁿ) = n
```
Цей гомоморфізм є бієкцією. Отже, вільний моноїд з одним генератором **ізоморфний моноїду натуральних чисел за додаванням**:
```
{x}* ≅ (ℕ, +, 0)
```

#### 2. Обчислення значення виразу як гомоморфізм

Нехай алфавіт складається з двох символів `Σ = {0, 1}`, а цільовим моноїдом є мультиплікативний моноїд цілих чисел `(ℤ, ·, 1)`.
Задамо відображення символів: `f(0) = −1`, `f(1) = 1`.
Тоді єдиний гомоморфізм `f̄: {0, 1}* → ℤ` обчислює парність кількості нулів у бітовому рядку:
```
f̄("10101") = f(1) · f(0) · f(1) · f(0) · f(1) = 1 · (−1) · 1 · (−1) · 1 = 1
f̄("10111") = 1 · (−1) · 1 · 1 · 1 = −1
```
Будь-який парсер, компілятор чи обчислювач виразів над послідовністю токенів є нічим іншим, як застосуванням універсального гомоморфізму `f̄`, гарантованого цією теоремою.

### Категорний погляд: спряження забувального та вільного функторів

Мовою теорії категорій універсальна властивість вільного моноїда означає існування **спряження** (*adjunction*) між двома категоріями: категорією множин `Set` та категорією моноїдів `Mon`.

Розглянемо **забувальний функтор** `U: Mon → Set`, який кожному моноїду `(M, ⋆, e)` зіставляє його множину-носій `M` (забуваючи про операцію множення та одиницю), а кожному гомоморфізму моноїдів — відповідне відображення множин.

Тоді конструкція вільного моноїда визначає **вільний функтор** `F: Set → Mon`, який кожній множині `Σ` зіставляє вільний моноїд `Σ*`.

Універсальна властивість стверджує, що для будь-якої множини `Σ` та будь-якого моноїда `M` існує природна бієкція між множинами відображень:

```
Hom_Set(Σ, U(M)) ≅ Hom_Mon(F(Σ), M)
```

Це означає, що вільний функтор `F` є **лівим спряженим** до забувального функтора `U` (записується як `F ⊣ U`).

### Алгебраїчний наслідок: представлення моноїдів твірними та співвідношеннями

Універсальна властивість має ще один глибокий наслідок для алгебри:

**Теорема про представлення.** *Будь-який моноїд `M` ізоморфний фактор-моноїду деякого вільного моноїда.*

*Схема доведення:*
Візьмемо як алфавіт `Σ` саму множину елементів моноїда `M` (або зручну систему його твірних елементів), а як відображення `f: Σ → M` — тотожне відображення `f(m) = m`.
За універсальною властивістю існує єдиний сюр'єктивний гомоморфізм:

```
f̄ : Σ* → M
```

Ядром цього гомоморфізму є конгруенція `∼`, визначена рівністю значень:

```
u ∼ v  ⟺  f̄(u) = f̄(v)
```

За теоремою про перший ізоморфізм для моноїдів, вихідний моноїд `M` ізоморфний фактор-моноїду вільного моноїда за цією конгруенцією:

```
M ≅ Σ* / ∼
```

Це означає, що будь-який моноїд можна строго задати **системою твірних та співвідношень** `⟨Σ | R⟩`, де `Σ` — базові генератори, а `R` — скінченний або нескінченний набір рівнянь вигляду `u = v`, що породжують конгруенцію `∼`. Наприклад, моноїд додавання за модулем `n` задається як `⟨{x} | xⁿ = ε⟩`.
