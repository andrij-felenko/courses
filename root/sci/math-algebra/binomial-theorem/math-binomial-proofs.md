# 🧮 Строгі доведення біноміальної теореми: комбінаторика, індукція та аналіз

Математичне доведення біноміальної теореми є фундаментальним прикладом того, як одна й та сама тотожність може бути обґрунтована з трьох абсолютно різних точок зору: комбінаторного підрахунку підмножин, строгой алгебраїчної індукції у кільцях та аналітичного розкладу функцій у нескінченні степенні ряди Тейлора. 

Вибір методу доведення суворо визначається тим, у якій числовій або алгебраїчній системі розглядається показник степеня `n`: для цілих натуральних показників `n ∈ ℕ` застосовують комбінаторику та алгебру, а для від'ємних чи дробових дійсних показників `α ∈ ℝ` — апарат математичного аналізу.

### 1. Комбінаторне доведення для натуральних n

Розглянемо добуток `n` однакових двочленних множників у комутативному кільці з одиницею:

```
(a + b)ⁿ = (a + b)₁ · (a + b)₂ · (a + b)₃ · … · (a + b)♙
```

За дистрибутивним законом множення відносно додавання, при повній розкритті дужок підсумковий багаточлен утворюється як сума всіх можливих одночленних добутків, складених шляхом вибору **одного** з двох елементів (`a` або `b`) з кожної із `n` дужок.

Кожен такий окремий доданок являє собою слово довжини `n`, вибудуване з літер `a` та `b`. Якщо у даному виборі літера `b` була взята з точно `k` дужок, то з решти `n - k` дужок автоматично була взята літера `a`. Оскільки елементи комутують (`a·b = b·a`), кожен такий добуток дорівнює `aⁿ⁻ᵏ · bᵏ`.

Загальна кількість доданків вигляду `aⁿ⁻ᵏ · bᵏ` точно дорівнює кількості способів обрати `k` дужок із загальної множини з `n` дужок, з яких буде вилучено елемент `b`. За класичним комбінаторним означенням, кількість сполучень з `n` елементів по `k` елементів (тобто кількість `k`-елементних підмножин у `n`-елементній множині) дорівнює біноміальному коефіцієнту:

```
C(n, k) = n! / (k! · (n - k)!)
```

Оскільки параметр `k` незалежно пробігає всі цілі значення від `0` (жодна дужка не дала `b`) до `n` (усі дужки дали `b`), за правилом додавання комбінаторики підсумковий багаточлен задовольняє тотожність:

```
(a + b)ⁿ = ∑ₖ₌₀ⁿ C(n, k) · aⁿ⁻ᵏ · bᵏ
```

#### Доведення комбінаторних тотожностей через розклад двочлена

Завдяки комбінаторному доведенню ми можемо миттєво виводити фундаментальні співвідношення для біноміальних коефіцієнтів без проведення довгої алгебраїчної індукції:

1. **Тотожність Вандермонда (Vandermonde's Identity):**
   Розглянемо тотожність `(1 + x)ᵐ⁺ⁿ = (1 + x)ᵐ · (1 + x)ⁿ`. Знайдемо коефіцієнт при `xʳ` з двох боків. У лівій частині він дорівнює `C(m + n, r)`. У правій частині за правилом дискретної згортки коефіцієнт при `xʳ` утворюється як сума добутків `C(m, k) · C(n, r - k)`. Це дає знамениту тотожність Вандермонда:
   ```
   C(m + n, r) = ∑ₖ₌₀ʳ C(m, k) · C(n, r - k)
   ```

2. **Тотожність вибору голови комісії (Absorption Identity):**
   ```
   k · C(n, k) = n · C(n - 1, k - 1)
   ```
   *Комбінаторне доведення:* Нехай із групи в `n` осіб потрібно обрати комісію з `k` людей та призначити одного з них головою. Ми можемо зробити це двома еквівалентними способами:
   - Спочатку обрати комісію з `k` людей (`C(n, k)` способів), а потім обрати голову з поміж `k` членів (`k` способів). Це дає `k · C(n, k)` варіантів.
   - Спочатку обрати голову з-поміж усіх `n` осіб (`n` способів), а потім дообрати `k - 1` членів комісії з решти `n - 1` людей (`C(n - 1, k - 1)` способів). Це дає `n · C(n - 1, k - 1)` варіантів.

   Оскільки обидва шляхи рахують одну й ту саму кількість конфігурацій, ліва і права частини тотожно рівні.

### 2. Алгебраїчне доведення методом математичної індукції

Алгебраїчний підхід не спирається на комбінаторні міркування про підмножини і працює в будь-якому комутативному кільці з одиницею `R`.

#### База індукції (n = 1):

Обчислимо праву частину формули для `n = 1`:

```
∑ₖ₌₀¹ C(1, k) · a¹⁻ᵏ · bᵏ = C(1, 0)·a¹·b⁰ + C(1, 1)·a⁰·b¹ = 1·a + 1·b = a + b
```

Оскільки ліва частина `(a + b)¹ = a + b`, база індукції виконується тотожно.

#### Індукційне припущення:
Припустимо, що біноміальна формула виконується для деякого довільного натурального `n = m`:

```
(a + b)ᵐ = ∑ₖ₌₀ᵐ C(m, k) · aᵐ⁻ᵏ · bᵏ
```

#### Крок індукції (n = m + 1):
Доведемо, що з виконання формули для `n = m` випливає її правильність для `n = m + 1`. Помножимо обидві частини індукційного припущення на двочлен `(a + b)`:

```
(a + b)ᵐ⁺¹ = (a + b) · [ ∑ₖ₌₀ᵐ C(m, k) · aᵐ⁻ᵏ · bᵏ ]
           = a · [ ∑ₖ₌₀ᵐ C(m, k) · aᵐ⁻ᵏ · bᵏ ] + b · [ ∑ₖ₌₀ᵐ C(m, k) · aᵐ⁻ᵏ · bᵏ ]
```

Внесемо множники `a` та `b` всередину відповідних сум:

```
(a + b)ᵐ⁺¹ = ∑ₖ₌₀ᵐ C(m, k) · aᵐ⁺¹⁻ᵏ · bᵏ + ∑ₖ₌₀ᵐ C(m, k) · aᵐ⁻ᵏ · bᵏ⁺¹
```

Виділимо перші та останні доданки для того, щоб вирівняти степені `a` і `b`:
- У першій сумі при `k = 0` маємо доданок `C(m, 0)·aᵐ⁺¹ = aᵐ⁺¹`.
- У другій сумі при `k = m` маємо доданок `C(m, m)·bᵐ⁺¹ = bᵐ⁺¹`.

У другій сумі виконаємо зміну індексу підсумовування `j = k + 1` (тоді `k = j - 1`, і межі змінюються від `j = 1` до `j = m + 1`). Перейменувавши змінну `j` назад у `k`, вираз набуває вигляду:

```
(a + b)ᵐ⁺¹ = aᵐ⁺¹ + ∑ₖ₌₁ᵐ C(m, k)·aᵐ⁺¹⁻ᵏ·bᵏ + ∑ₖ₌₁ᵐ C(m, k - 1)·aᵐ⁺¹⁻ᵏ·bᵏ + bᵐ⁺¹
```

Об'єднаємо дві внутрішні суми під один знак підсумовування за однаковими одночленними множниками `aᵐ⁺¹⁻ᵏ · bᵏ`:

```
(a + b)ᵐ⁺¹ = aᵐ⁺¹ + ∑ₖ₌₁ᵐ [ C(m, k) + C(m, k - 1) ] · aᵐ⁺¹⁻ᵏ · bᵏ + bᵐ⁺¹
```

За тотожністю Паскаля сума двох сусідніх біноміальних коефіцієнтів задовольняє фундаментальне співвідношення:

```
C(m, k) + C(m, k - 1) = C(m + 1, k)
```

Підставивши співвідношення Паскаля у внутрішній коефіцієнт суми, отримуємо:

```
(a + b)ᵐ⁺¹ = aᵐ⁺¹ + ∑ₖ₌₁ᵐ C(m + 1, k) · aᵐ⁺¹⁻ᵏ · bᵏ + bᵐ⁺¹
```

Зауваживши, що `aᵐ⁺¹ = C(m + 1, 0)·aᵐ⁺¹·b⁰`, а `bᵐ⁺¹ = C(m + 1, m + 1)·a⁰·bᵐ⁺¹`, ми можемо вкласти крайні доданки у знак суми:

```
(a + b)ᵐ⁺¹ = ∑ₖ₌₀ᵐ⁺¹ C(m + 1, k) · aᵐ⁺¹⁻ᵏ · bᵏ
```

Отже, біноміальна формула правильна для `n = m + 1`. За принципом математичної індукції біноміальна теорема доведена для всіх цілих натуральних показників `n ∈ ℕ`.

### 3. Виведення узагальненого біноміального ряду Ньютона через ряд Маклорена

Розглянемо функцію `f(x) = (1 + x)α`, де `α ∈ ℝ` — довільне дійсне число, а `x` належить відкритому інтервалу `(-1, 1)`.

Розкладемо функцію `f(x)` у нескінченний степеней ряд Маклорена (ряд Тейлора в околі нуля):

```
f(x) = ∑ₖ₌₀∞ [ f⁽ᵏ⁾(0) / k! ] · xᵏ
```

Обчислимо послідовні похідні порядку `k` для функції `f(x)`:

```
f⁽⁰⁾(x) = (1 + x)α                 ⇒  f⁽⁰⁾(0) = 1
f⁽¹⁾(x) = α · (1 + x)α⁻¹           ⇒  f⁽¹⁾(0) = α
f⁽²⁾(x) = α · (α - 1) · (1 + x)α⁻² ⇒  f⁽²⁾(0) = α · (α - 1)
f⁽³⁾(x) = α · (α - 1) · (α - 2) · (1 + x)α⁻³ ⇒ f⁽³⁾(0) = α · (α - 1) · (α - 2)
```

За допомогою математичної індукції неважко довести, що `k`-та похідна для довільного цілого `k ≥ 1` задовольняє вираз:

```
f⁽ᵏ⁾(x) = α · (α - 1) · (α - 2) · … · (α - k + 1) · (1 + x)α⁻ᵏ
```

Підставивши точку `x = 0`, отримуємо точне значення `k`-ї похідної на початку координат:

```
f⁽ᵏ⁾(0) = α · (α - 1) · (α - 2) · … · (α - k + 1)
```

Ввівши узагальнений біноміальний коефіцієнт Ньютона:

```
C(α, k) = f⁽ᵏ⁾(0) / k! = [ α · (α - 1) · (α - 2) · … · (α - k + 1) ] / k!
```

отримуємо степеней ряд Ньютона:

```
(1 + x)α = ∑ₖ₌₀∞ C(α, k) · xᵏ
```

#### Доведення абсолютної збіжності за ознакою Даламбера

Перевіримо область збіжності утвореного нескінченного степенного ряду. Позначимо загальний член ряду як `uₖ = C(α, k) · xᵏ`.

Знайдемо абсолютне значення відношення двух послідовних членів ряду `uₖ⁺¹ / uₖ`:

```
| uₖ⁺¹ / uₖ | = | [ C(α, k + 1) · xᵏ⁺¹ ] / [ C(α, k) · xᵏ ] |
            = | C(α, k + 1) / C(α, k) | · |x|
```

Розпишемо відношення узагальнених біноміальних коефіцієнтів:

```
C(α, k + 1) / C(α, k) = [ α · (α - 1) · … · (α - k + 1) · (α - k) ] / (k + 1)!
                       ---------------------------------------------------------
                       [ α · (α - 1) · … · (α - k + 1) ] / k!
                     = (α - k) / (k + 1)
```

Обчислим границю відношення членів ряду при `k → ∞`:

```
lim_{k → ∞} | [ (α - k) / (k + 1) ] | · |x| = lim_{k → ∞} | (α/k - 1) / (1 + 1/k) | · |x| = |-1| · |x| = |x|
```

За ознакою Даламбера, якщо границя відношення `L = |x| < 1`, степенний ряд збігається абсолютно. Якщо `|x| > 1`, ряд розбігається.

Отже, узагальнений біноміальний ряд Ньютона доведено для всіх `x ∈ (-1, 1)` і довільних дійсних показників `α ∈ ℝ`.

### 4. Доведення через формальні диференціальні рівняння

Ще одним витонченим алгебраїчним доведенням узагальненої біноміальної теореми є метод формальних диференціальних рівнянь у кільці степеневих рядів `K[[x]]`.

Розглянемо функцію `y(x) = (1 + x)α`. Обчислимо її першу похідну:

```
y'(x) = α · (1 + x)α⁻¹
```

Помножимо обидві частини на `(1 + x)`:

```
(1 + x) · y'(x) = α · (1 + x)α = α · y(x)
```

Отже, функція `y(x)` є єдиним розв'язком диференціального рівняння `(1 + x) · y' = α · y` з початковою умовою `y(0) = 1`.

Припустимо, що розв'язок шукається у вигляді формального степенного ряду `y(x) = ∑ₖ₌₀∞ aₖ · xᵏ`. Його формальна похідна дорівнює:

```
y'(x) = ∑ₖ₌₁∞ k · aₖ · xᵏ⁻¹
```

Підставимо ряд та його похідну у диференціальне рівняння:

```
(1 + x) · [ ∑ₖ₌₁∞ k · aₖ · xᵏ⁻¹ ] = α · [ ∑ₖ₌₀∞ aₖ · xᵏ ]
```

Розкриємо дужки у лівій частині:

```
∑ₖ₌₁∞ k · aₖ · xᵏ⁻¹ + ∑ₖ₌₁∞ k · aₖ · xᵏ = ∑ₖ₌₀∞ α · aₖ · xᵏ
```

Зсунемо індекс у першій сумі, замінивши `k` на `k + 1`:

```
∑ₖ₌₀∞ (k + 1) · aₖ⁺¹ · xᵏ + ∑ₖ₌₀∞ k · aₖ · xᵏ = ∑ₖ₌₀∞ α · aₖ · xᵏ
```

Прирівняємо коефіцієнти при однакових степенях `xᵏ` з обох боків рівняння:

```
(k + 1) · aₖ⁺¹ + k · aₖ = α · aₖ
```

Виразимо рекурентне співвідношення для коефіцієнтів `aₖ⁺¹`:

```
(k + 1) · aₖ⁺¹ = (α - k) · aₖ   ⇒   aₖ⁺¹ = [ (α - k) / (k + 1) ] · aₖ
```

Враховуючи початкову умову `a₀ = y(0) = 1`, послідовно знаходимо коефіцієнти:
- `a₁ = α / 1 = α`
- `a₂ = a₁ · (α - 1) / 2 = α · (α - 1) / 2!`
- `a₃ = a₂ · (α - 2) / 3 = α · (α - 1) · (α - 2) / 3!`
- `aₖ = [ α · (α - 1) · … · (α - k + 1) ] / k! = C(α, k)`

Це дає суто алгебраїчне виведення узагальнених біноміальних коефіцієнтів без прямого обчислення похідних вищих порядків.
