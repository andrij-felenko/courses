# 🧮 Теорема Ріса про представлення лінійного функціоналу

Теорема Ріса — Фреше встановлює фундаментальний місток між векторами та лінійними функціоналами: у просторі зі скалярним добутком будь-яке лінійне вимірювання зводиться до скалярного множення на єдиний фіксований вектор.

### Постановка задачі та геометрична інтуїція

Нехай `H` — гільбертів простір (або звичайний скінченновимірний евклідів простір) над полем дійсних чисел `ℝ` зі скалярним добутком `⟨·, ·⟩`. Якщо ми зафіксуємо довільний вектор `u ∈ H`, то відображення:

```
φᵤ(v) = ⟨u, v⟩
```

автоматично є лінійним функціоналом на `H`. Справді, лінійність скалярного добутку за другим аргументом гарантує:

```
φᵤ(v₁ + v₂)
= ⟨u, v₁ + v₂⟩      [підстановка суми векторів]
= ⟨u, v₁⟩ + ⟨u, v₂⟩ [дистрибутивність скалярного добутку]
= φᵤ(v₁) + φᵤ(v₂)   [означення функціоналів]

φᵤ(c·v)
= ⟨u, c·v⟩          [підстановка масштабованого вектора]
= c·⟨u, v⟩          [винесення скаляра зі скалярного добутку]
= c·φᵤ(v)           [означення функціонала]
```

Нерівність Коші — Буняковського `|⟨u, v⟩| ≤ ‖u‖ · ‖v‖` показує, що такий функціонал є неперервним (обмеженим), а його операторна норма дорівнює довжині вектора `‖φᵤ‖ = ‖u‖`.

Теорема Ріса — Фреше (доведена незалежно Францем Рісом (*Frigyes Riesz*) та Морісом Фреше (*Maurice Fréchet*) у 1907 році) стверджує обернене: **будь-який** неперервний лінійний функціонал на `H` має саме такий вигляд. Тобто не існує жодного іншого лінійного правила оцінки векторів, крім проекції на деякий заздалегідь обраний напрямок `u`.

### Формулювання теореми

Нехай `H` — гільбертів простір над полем `ℝ` зі скалярним добутком `⟨·, ·⟩`. Для кожного неперервного лінійного функціонала `φ ∈ H*` існує єдиний вектор `u ∈ H`, такий що:

```
∀ v ∈ H:   φ(v) = ⟨u, v⟩
```

При цьому операторна норма функціонала точно збігається з нормою вектора:

```
‖φ‖ = ‖u‖
```

### Покрокове доведення

Розгляньмо будову ядра функціонала `φ`. Ядром називають множину всіх векторів, на яких функціонал перетворюється на нуль:

```
ker(φ) = { v ∈ H | φ(v) = 0 }
```

**Крок 1. Тривіальний випадок.**
Якщо `φ = 0` (функціонал тотожно дорівнює нулю для всіх векторів), то шуканим вектором є нульовий вектор `u = 0`. Тоді `φ(v) = 0 = ⟨0, v⟩` для будь-якого `v`, і теорема виконується.

**Крок 2. Нетривіальний випадок: виділення ортогонального напрямку.**
Нехай `φ ≠ 0`. Оскільки функціонал лінійний і неперервний, його ядро `ker(φ)` є замкненим власним підпростором у `H`. За теоремою про ортогональний розклад гільбертового простору:

```
H = ker(φ) ⊕ (ker(φ))⊥
```

Оскільки `φ ≠ 0`, ортогональне доповнення `(ker(φ))⊥` містить ненульові вектори. Оберімо довільний ненульовий вектор `z ∈ (ker(φ))⊥` такий, що `z ≠ 0`. Оскільки `z ∉ ker(φ)`, маємо `φ(z) ≠ 0`.

**Крок 3. Доведення одновимірності ортогонального доповнення.**
Візьмімо довільний вектор `v ∈ H`. Сконструюймо комбінацію:

```
w = v - (φ(v) / φ(z)) · z
```

Застосуймо функціонал `φ` до вектора `w`:

```
φ(w)
= φ(v - (φ(v) / φ(z)) · z)        [підстановка означення w]
= φ(v) - (φ(v) / φ(z)) · φ(z)     [лінійність функціонала φ]
= φ(v) - φ(v)                     [скорочення на φ(z) ≠ 0]
= 0                               [арифметичне віднімання]
```

Отже вектор `w` належить ядру `ker(φ)`. Оскільки вектор `z` ортогональний до всього ядра `ker(φ)`, скалярний добуток `⟨z, w⟩ = 0`:

```
⟨z, w⟩
= ⟨z, v - (φ(v) / φ(z)) · z⟩      [підстановка виразу для w]
= ⟨z, v⟩ - (φ(v) / φ(z)) · ⟨z, z⟩ [лінійність скалярного добутку]
= 0                               [ортогональність z до ker(φ)]
```

**Крок 4. Явний вираз для вектора u.**
З отриманої рівності `⟨z, v⟩ - (φ(v) / φ(z)) · ‖z‖² = 0` виразимо значення `φ(v)`:

```
(φ(v) / φ(z)) · ‖z‖² = ⟨z, v⟩     [перенесення доданка]
φ(v) = (φ(z) / ‖z‖²) · ⟨z, v⟩     [множення на φ(z) / ‖z‖²]
φ(v) = ⟨(φ(z) / ‖z‖²) · z, v⟩     [внесення скаляра в перший аргумент]
```

Позначимо шуканий вектор `u` як:

```
u = (φ(z) / ‖z‖²) · z
```

Цей вектор лежить у `(ker(φ))⊥` і повністю визначається функціоналом `φ`. Ми отримали рівність `φ(v) = ⟨u, v⟩`, справедливу для будь-якого `v ∈ H`.

**Крок 5. Доведення єдиності.**
Припустімо, що існують два вектори `u₁` та `u₂`, які представляють той самий функціонал:

```
∀ v ∈ H:   ⟨u₁, v⟩ = φ(v) = ⟨u₂, v⟩
```

Віднімемо одну рівність від іншої:

```
⟨u₁, v⟩ - ⟨u₂, v⟩ = 0             [віднімання рівностей]
⟨u₁ - u₂, v⟩ = 0                  [дистрибутивність скалярного добутку]
```

Ця рівність має виконуватися для **всіх** `v ∈ H`. Підставимо зокрема вектор `v = u₁ - u₂`:

```
⟨u₁ - u₂, u₁ - u₂⟩ = 0            [підстановка v = u₁ - u₂]
‖u₁ - u₂‖² = 0                    [означення норми через скалярний добуток]
u₁ - u₂ = 0                       [аксіома додатної визначеності норми]
u₁ = u₂                           [додавання u₂ до обох частин]
```

Отже вектор `u` єдиний.

**Крок 6. Рівність норм.**
Оцінимо норму функціонала `φ`. З нерівності Коші — Буняковського:

```
|φ(v)| = |⟨u, v⟩| ≤ ‖u‖ · ‖v‖
```

Звідси за означенням операторної норми:

```
‖φ‖ = sup { |φ(v)| / ‖v‖ при v ≠ 0 } ≤ ‖u‖
```

З іншого боку, підставимо ненульовий вектор `v = u`:

```
φ(u)
= ⟨u, u⟩                          [означення представлення Ріса]
= ‖u‖²                            [квадрат норми вектора]
```

Тоді відношення значення до довжини дорівнює:

```
|φ(u)| / ‖u‖
= ‖u‖² / ‖u‖                      [підстановка φ(u) = ‖u‖²]
= ‖u‖                             [скорочення дробу]
```

Оскільки супремум не може бути меншим за значення на конкретному векторі `u`, маємо `‖φ‖ ≥ ‖u‖`. Поєднуючи дві нерівності `‖φ‖ ≤ ‖u‖` та `‖φ‖ ≥ ‖u‖`, отримуємо строгу рівність:

```
‖φ‖ = ‖u‖
```

Теорему доведено.

### Комплексний випадок: антилінійність ізоморфізму

Якщо гільбертів простір задано над полем комплексних чисел `ℂ`, скалярний добуток є ермітовим (напівлінійним за першим аргументом): `⟨c·u, v⟩ = c̄ · ⟨u, v⟩`, де `c̄` — комплексне спряження.

У комплексному просторі теорема Ріса набуває форми:

```
φ(v) = ⟨u, v⟩,   де u = (φ(z)̄ / ‖z‖²) · z
```

Зіставлення `u ↦ φᵤ` стає **антилінійним** (спряжено-лінійним) ізоморфізмом між `H` та `H*`:

```
φ_{c·u}(v)
= ⟨c·u, v⟩                        [означення функціонала]
= c̄ · ⟨u, v⟩                      [винесення скаляра з першого аргументу]
= c̄ · φᵤ(v)                       [комплексне спряження скаляра]
```

Саме тому у квантовій механіці перехід від кет-вектора `|ψ⟩` до бра-вектора `⟨ψ|` супроводжується комплексним спряженням усіх амплітуд: `⟨ψ| = (|ψ⟩)†`.

### Музичні ізоморфізми: опускання та підняття індексів

Теорема Ріса дозволяє ототожнити простір `H` з його дуальним `H*`, якщо задано метрику. В диференціальній геометрії та тензорному аналізі ці відображення називають **музичними ізоморфізмами** (*musical isomorphisms*) через схожість позначень на нотні знаки бемоль `♭` та дієз `♯`.

**Опускання індексів (бемоль `♭ : H → H*`):**
Вектору `v ∈ H` зіставляється ковектор `v♭ ∈ H*` за правилом:

```
v♭(w) = ⟨v, w⟩
```

Якщо обрано базис `(e₁, e₂, ..., eₙ)`, матриця скалярних добутків утворює метричний тензор `g[i, j] = ⟨eᵢ, eⱼ⟩`. У координатній формі ковекторні компоненти `pᵢ` виражаються через векторні координати `vʲ`:

```
pᵢ = ∑ g[i, j] · vʲ
```

Ця операція перетворює контраваріантний вектор (стовпчик) на коваріантний ковектор (рядок).

**Підняття індексів (дієз `♯ : H* → H`):**
Обернене відображення перетворює ковектор `p ∈ H*` на вектор `p♯ ∈ H`:

```
p(w) = ⟨p♯, w⟩
```

У координатах використовують обернену метричну матрицю `gⁱʲ` (де `∑ g[i, k] · gᵏʲ = δ[i, j]`):

```
vⁱ = ∑ gⁱʲ · pⱼ
```

### Числовий приклад: опускання та підняття індексів

Щоб побачити дію музичних ізоморфізмів на практиці, розгляньмо двовимірний простір `ℝ²` з косокутним базисом, у якому метричний тензор має недіагональний вигляд:

```
g = [ [ 2,  1 ],
      [ 1,  3 ] ]
```

Нехай задано вектор швидкості `v` зі стовпчиковими координатами `v = [ 3, -1 ]ᵀ`. Знайдемо відповідний йому ковектор (1-форму) `p = v♭` за правилом опускання індексів `pᵢ = ∑ g[i, j] · vʲ`:

```
p₁
= g[1, 1]·v¹ + g[1, 2]·v² [розгортання суми за індексом j]
= 2·(3) + 1·(-1)          [підстановка елементів матриці g та координат v]
= 6 - 1                   [множення чисел]
= 5                       [арифметична різниця]

p₂
= g[2, 1]·v¹ + g[2, 2]·v² [розгортання другого рядка метрики]
= 1·(3) + 3·(-1)          [підстановка компонент]
= 3 - 3                   [множення чисел]
= 0                       [арифметична різниця]
```

Отримали ковектор-рядок `p = [ 5,  0 ]`. Зверніть увагу: друга компонента ковектора дорівнює нулю (`p₂ = 0`), хоча вектор `v` мав ненульову другу координату `v² = -1`. Це сталося через взаємну косокутність базисних векторів: вектор `v` виявився ортогональним до другого базисного вектора `e₂` в даній метриці `⟨v, e₂⟩ = 1·3 + 3·(-1) = 0`.

Тепер виконаємо зворотну дію — піднімемо індекси ковектора `p = [ 5,  0 ]` за допомогою оберненого метричного тензора `g⁻¹ = gⁱʲ`. Знайдемо визначник і обернену матрицю:

```
det(g)
= g[1, 1]·g[2, 2] - g[1, 2]·g[2, 1] [формула визначника 2х2]
= 2·3 - 1·1                         [підстановка значень]
= 6 - 1                             [множення чисел]
= 5                                 [визначник матриці метрики]
```

Обернена матриця метрики дорівнює:

```
gⁱʲ = [ [  3/5, -1/5 ],
        [ -1/5,  2/5 ] ]
```

Обчислимо відновлений вектор `v′ = p♯` через `v′ⁱ = ∑ gⁱʲ · pⱼ`:

```
v′¹
= g¹¹·p₁ + g¹²·p₂         [перша компонента вектора]
= (3/5)·5 + (-1/5)·0      [підстановка елементів gⁱʲ та ковектора p]
= 3 + 0                   [множення чисел]
= 3                       [перша відновлена координата]

v′²
= g²¹·p₁ + g²²·p₂         [друга компонента вектора]
= (-1/5)·5 + (2/5)·0      [підстановка значень]
= -1 + 0                  [множення чисел]
= -1                      [друга відновлена координата]
```

Отримали початковий вектор `v′ = [ 3, -1 ]ᵀ`. Музичні ізоморфізми працюють як взаємно обернені операції, що зберігають довжину вектора та норму ковектора:

```
‖v‖²
= vᵀ · g · v              [квадрат норми вектора у метриці g]
= [ 3, -1 ] · [ 5, 0 ]ᵀ   [згортка вектора з ковектором p = g·v]
= 3·5 + (-1)·0            [скалярний добуток]
= 15                      [значення квадрата довжини]

‖p‖²
= p · g⁻¹ · pᵀ            [квадрат норми ковектора в дуальній метриці]
= [ 5, 0 ] · [ 3, -1 ]ᵀ   [згортка ковектора з вектором v = g⁻¹·p]
= 5·3 + 0·(-1)            [скалярний добуток]
= 15                      [значення квадрата норми функціонала]
```

Значення довжини та норми абсолютно однакові: `‖v‖² = ‖p‖² = 15`.

### Чому повнота простору є критичною: контрприклад неповного передгільбертового простору

У формулюванні теореми Ріса принциповою є вимога **повноти** простору (тобто що простір є гільбертовим, а не просто передгільбертовим зі скалярним добутком). Якщо простір не є повним, існують неперервні лінійні функціонали, які неможливо представити жодним вектором цього простору.

Розгляньмо простір усіх дійсних поліномів `P[-1, 1]` на відрізку `[-1, 1]` зі стандартним скалярним добутком простору `L²`:

```
⟨p, q⟩ = ∫_{-1}^{1} p(t) · q(t) dt
```

Цей простір є передгільбертовим, але не є повним (границі збіжних послідовностей поліномів можуть бути розривними функціями, що не є поліномами).

Зафіксуймо довільну точку `t₀ ∈ (-1, 1)`, наприклад `t₀ = 0`, і розгляньмо функціонал обчислення значення полінома в цій точці (дельта-функціонал Дірака):

```
δ₀(p) = p(0)
```

Чи існує поліном `u(t) ∈ P[-1, 1]`, такий що для будь-якого полінома `p(t)` виконується інтегральна рівність:

```
p(0) = ∫_{-1}^{1} u(t) · p(t) dt
```

Припустимо, що такий поліном `u(t)` існує. Розгляньмо послідовність поліномів `pₙ(t) = (1 - t²ⁿ) · (1 - t²)ⁿ`. При `n → ∞` значення `pₙ(0) = 1`, але сама функція стрімко спадає до нуля скрізь поза малою околицею нуля, прямуючи до нуля в інтегральному сенсі `L²`.

Якщо підставити поліноми `qₙ(t) = (1 - t²)ⁿ · u(t)`, то при зростанні `n` інтеграл прямує до нуля значно швидше, ніж значення у нулі. Безпосереднє інтегрування показує: єдиною «функцією», здатною задовольнити таку рівність для всіх неперервних пробних функцій, є узагальнена дельта-функція Дірака `δ(t)`, яка взагалі не є класичною функцією, а тим більше поліномом.

У неповному просторі `P[-1, 1]` вектор `u` «випадає» за межі простору в його поповнення `L²[-1, 1]`. Але навіть у `L²[-1, 1]` дельта-функціонал `p ↦ p(0)` перестає бути неперервним, оскільки значення в окремій точці не контролюється інтегральною нормою.

Цей контрприклад підкреслює: **теорема Ріса спирається на геометрію ортогональної проекції, яка вимагає повноти простору для гарантованого існування проекції на замкнене ядро**.

### Узагальнення: лема Лакса — Мільграма та варіаційні задачі

Теорема Ріса дає представлення для лінійних функціоналів, коли форма `⟨u, v⟩` є симетричним додатно визначеним скалярним добутком. У теорії диференціальних рівнянь із частинними похідними виникають несиметричні білінійні форми, для яких діє фундаментальне узагальнення теореми Ріса — **лема Лакса — Мільграма** (*Lax–Milgram lemma*, Пітер Лакс та Артур Мільграм, 1954 рік).

Нехай `H` — дійсний гільбертів простір, а `a(u, v) : H × H → ℝ` — білінійна форма (не обов'язково симетрична), яка задовольняє дві умови:

1. **Неперервність (обмеженість):** існує константа `C > 0`, така що для всіх `u, v ∈ H`:
```
|a(u, v)| ≤ C · ‖u‖ · ‖v‖
```

2. **Коерцитивність (еліптичність):** існує стала `α > 0`, така що для всіх `u ∈ H`:
```
a(u, u) ≥ α · ‖u‖²
```

Тоді для будь-якого неперервного лінійного функціонала `φ ∈ H*` існує **єдиний** вектор `u ∈ H`, такий що:

```
∀ v ∈ H:   a(u, v) = φ(v)
```

При цьому розв'язок задовольняє апріорну оцінку стійкості:

```
‖u‖ ≤ (1 / α) · ‖φ‖_{H*}
```

**Схема доведення через теорему Ріса:**
Для кожного фіксованого `u ∈ H` відображення `v ↦ a(u, v)` є неперервним лінійним функціоналом на `H` (завдяки неперервності форми `|a(u, v)| ≤ (C·‖u‖) · ‖v‖`). За класичною теоремою Ріса існує єдиний вектор `A(u) ∈ H`, такий що:

```
a(u, v) = ⟨A(u), v⟩
```

Відображення `A : H → H` є лінійним обмеженим оператором із нормою `‖A‖ ≤ C`. Коерцитивність форми гарантує ін'єктивність та замкненість образу оператора `A`:

```
⟨A(u), u⟩ = a(u, u) ≥ α · ‖u‖²
```

Застосовуючи нерівність Коші — Буняковського `‖A(u)‖ · ‖u‖ ≥ ⟨A(u), u⟩ ≥ α · ‖u‖²`, дістаємо `‖A(u)‖ ≥ α · ‖u‖`. Це доводить, що образ `Im(A)` є замкненим підпростором у `H`. Якщо припустити, що образ `Im(A) ≠ H`, то існує ненульовий вектор `w ∈ (Im(A))⊥`. Тоді `0 = ⟨A(w), w⟩ = a(w, w) ≥ α · ‖w‖² > 0`, що дає суперечність. Отже оператор `A` є сюр'єктивним бієктивним ізоморфізмом.

Застосовуючи теорему Ріса до самого функціонала `φ`, знаходимо вектор `w_φ ∈ H`, де `φ(v) = ⟨w_φ, v⟩`. Тоді шуканий розв'язок задачі задається формулою `u = A⁻¹(w_φ)`.

### Застосування до рівняння Пуассона у просторі Соболєва

Лема Лакса — Мільграма є фундаментом методу скінченних елементів для розв'язання крайових задач. Розгляньмо рівняння Пуассона з однорідними крайовими умовами Діріхле в області `Ω ⊂ ℝⁿ`:

```
-Δu = f   усередині Ω,
 u = 0    на межі ∂Ω.
```

Помножимо рівняння на довільну гладку пробну функцію `v(x)` із `v = 0` на `∂Ω` та проінтегруємо частинами за формулою Ґріна:

```
∫_{Ω} (-Δu) · v dx
= ∫_{Ω} ∇u · ∇v dx - ∫_{∂Ω} (∂u/∂n) · v ds [формула Ґріна]
= ∫_{Ω} ∇u · ∇v dx - 0                     [крайова умова v = 0 на ∂Ω]
= ∫_{Ω} ∇u · ∇v dx                         [спрощення виразу]
```

Отримуємо так зване **слабке (варіаційне) формулювання** задачі: знайти функцію `u ∈ H¹_0(Ω)` у просторі Соболєва, таку що для всіх пробних функцій `v ∈ H¹_0(Ω)`:

```
a(u, v) = φ(v)
```

де білінійна форма `a(u, v)` та функціонал правої частини `φ(v)` мають вигляд:

```
a(u, v) = ∫_{Ω} ∑ (∂u/∂xᵢ) · (∂v/∂xᵢ) dx
φ(v)    = ∫_{Ω} f(x) · v(x) dx
```

За нерівністю Пуанкаре `∫_{Ω} |v|² dx ≤ C_P · ∫_{Ω} |∇v|² dx`, тому форма `a(u, v)` є строго коерцитивною у просторі `H¹_0(Ω)` зі скалярним добутком `⟨u, v⟩_{H¹_0} = ∫_{Ω} ∇u · ∇v dx`. Лема Лакса — Мільграма миттєво ґарантує існування та єдиність слабкого розв'язку крайової задачі для будь-якої правої частини `f ∈ L²(Ω)`.

### Дуальність просторів Лебега: теорема Ріса для просторів Lᵖ

Найвідомішим узагальненням теореми Ріса на банахові простори (де немає скалярного добутку, але є норма) є класична **теорема Ріса про спряжені простори Лебега** (*Riesz representation theorem for Lᵖ spaces*, 1909 рік).

Нехай `(X, Σ, μ)` — простір із мірою, а `p` та `q` — спряжені показники, пов'язані співвідношенням:

```
1/p + 1/q = 1,   де 1 < p < ∞
```

Тоді для будь-якого неперервного лінійного функціонала `φ ∈ (Lᵖ(μ))*` існує єдина функція `g ∈ L^q(μ)`, така що для всіх `f ∈ Lᵖ(μ)` дія функціонала виражається інтегралом:

```
φ(f) = ∫_{X} f(x) · g(x) dμ(x)
```

При цьому норма функціонала точно дорівнює нормі породжувальної функції `g` у просторі `L^q`:

```
‖φ‖_{(Lᵖ)*} = ‖g‖_{L^q} = ( ∫_{X} |g(x)|^q dμ )^{1/q}
```

**Зв'язок із нерівністю Гельдера:**
Для будь-яких функцій `f ∈ Lᵖ` та `g ∈ L^q` нерівність Гельдера стверджує:

```
|∫_{X} f · g dμ| ≤ ‖f‖_{Lᵖ} · ‖g‖_{L^q}
```

Теорема Ріса гарантує, що ця нерівність є точною: норма функціонала досягається на функції `f(x) = sign(g(x)) · |g(x)|^{q-1} / ‖g‖_{L^q}^{q/p}`, для якої:

```
∫_{X} f · g dμ
= ∫_{X} |g(x)|^q dμ / ‖g‖_{L^q}^{q/p}  [підстановка функції f]
= ‖g‖_{L^q}^q / ‖g‖_{L^q}^{q/p}        [означення норми простору L^q]
= ‖g‖_{L^q}^{q - q/p}                  [віднімання показників степеня]
= ‖g‖_{L^q}^1                          [оскільки q - q/p = q·(1 - 1/p) = q·(1/q) = 1]
= ‖g‖_{L^q}                            [точне значення норми функціонала]
```

Цей результат встановлює ізометричний канонічний ізоморфізм `(Lᵖ)* ≅ L^q`. Оскільки спряженим до `q` є знову `p`, другий дуальний простір `(Lᵖ)** ≅ (L^q)* ≅ Lᵖ` збігається з вихідним простором, що доводить **рефлексивність** просторів `Lᵖ` при `1 < p < ∞`.

Для граничного випадку `p = 1` спряженим простором є `(L¹)* ≅ L_∞` (простір суттєво обмежених функцій). Проте для `p = ∞` простір `(L_∞)*` є значно ширшим за `L¹` і складається з адитивних скінченних мір (простір `ba(X)`), тому `L¹` та `L_∞` **не є рефлексивними**.

### Самоспряжені оператори та спектральний зв'язок у гільбертовому просторі

Теорема Ріса дозволяє перевизначити поняття спряженого (дуального) оператора суто геометрично всередині самого гільбертового простору `H`, не виходячи в абстрактний дуальний простір `H*`.

Нехай `A : H → H` — лінійний неперервний оператор. Для кожного фіксованого вектора `w ∈ H` відображення:

```
v ↦ ⟨w, A(v)⟩
```

є неперервним лінійним функціоналом на `H`. За теоремою Ріса існує єдиний вектор, який позначимо як `A*(w) ∈ H`, такий що для всіх `v ∈ H`:

```
⟨A*(w), v⟩ = ⟨w, A(v)⟩
```

Оператор `A* : H → H` називають **гільбертовим спряженим оператором** до `A`.

Якщо `A = A*`, оператор називають **самоспряженим** (або ермітовим у комплексному випадку):

```
∀ u, v ∈ H:   ⟨A(u), v⟩ = ⟨u, A(v)⟩
```

Самоспряжені оператори є математичним апаратом квантових спостережуваних величин (енергія, імпульс, координата). За спектральною теоремою для компактних самоспряжених операторів простір `H` розпадається в ортогональну пряму суму одновимірних власних підпросторів:

```
H = ⨁_{i} Ker(A - λᵢ · I)
```

Будь-який вектор розкладається за ортонормованим базисом власних векторів `A(eᵢ) = λᵢ · eᵢ`, а дія оператора зводиться до зваженої суми одновимірних проекторів:

```
A = ∑_{i} λᵢ · (eᵢ ⊗ eᵢ♭)
```

де `eᵢ♭(v) = ⟨eᵢ, v⟩` — дуальний ковектор за теоремою Ріса. Це остаточно замикає коло між абстрактним дуальним простором `V*`, метричним ізоморфізмом Ріса та спектральною теорією операторів.

### Чому без скалярного добутку ізоморфізм не працює

Поширена помилка — вважати, що вектори й ковектори завжди можна перетворювати один в одного за теоремою Ріса. Це працює **лише** тоді, коли в просторі є заздалегідь узгоджений скалярний добуток (метрика).

Розгляньмо дійсний простір `ℝ²` з нормою `L₁` (мангеттенська відстань):

```
‖(x₁, x₂)‖₁ = |x₁| + |x₂|
```

Дуальний простір до `(ℝ², ‖·‖₁)` ізометрично ізоморфний простору `(ℝ², ‖·‖_∞)` з нормою максимуму:

```
‖(p₁, p₂)‖_∞ = max(|p₁|, |p₂|)
```

Одинична сфера у просторі `L₁` є ромбом із вершинами `(±1, 0)` та `(0, ±1)`. Одинична сфера в дуальному просторі `L_∞` є квадратом зі сторонами, паралельними осям координат. Для норм `L₁` та `L_∞` **не виконується тотожність паралелограма**:

```
‖x + y‖² + ‖x - y‖² = 2·‖x‖² + 2·‖y‖²
```

Перевіримо для векторів `x = (1, 0)` та `y = (0, 1)` у нормі `L₁`:

```
‖x + y‖₁² + ‖x - y‖₁²
= ‖(1, 1)‖₁² + ‖(1, -1)‖₁² [додавання та віднімання векторів]
= (1 + 1)² + (1 + 1)²      [обчислення норми L₁]
= 4 + 4                    [піднесення до квадрата]
= 8                        [арифметична сума]

2·‖x‖₁² + 2·‖y‖₁²
= 2·(1)² + 2·(1)²          [норми базисних векторів]
= 2 + 2                    [множення на 2]
= 4                        [арифметична сума]
```

Оскільки `8 ≠ 4`, норма `L₁` принципово не може бути породжена жодним скалярним добутком. Без скалярного добутку не існує канонічного способу перетворити лінійний функціонал `φ` на вектор `u`: вибір вектора буде повністю залежати від довільної системи координат, руйнуючи геометричну інваріантність.

Теорема Ріса чітко розмежовує: **дуальність — це загальна властивість будь-якого лінійного простору, тоді як ототожнення простору з його дуальним — це привілей просторів зі скалярним добутком**.
