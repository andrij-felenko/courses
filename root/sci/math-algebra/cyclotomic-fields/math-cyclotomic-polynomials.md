# 🧮 Кругові многочлени, незвідність і теорема Кронекера — Вебера

Алгебраїчні властивості кругових полів тримаються на одному фундаментальному сімействі многочленів — кругових многочленах `Φₙ(x)`, чиї корені є рівно всіма примітивними коренями `n`-го степеня з одиниці на комплексній площині. Будь-яке питання про структуру поля `ℚ(ζₙ)`, його степінь, симетрії групи Ґалуа чи розклад простих чисел у ньому зводиться до властивостей відповідного многочлена `Φₙ(x)`.

Тут виведено точні формули для побудови `Φₙ(x)`, доведено його незвідність над полем раціональних чисел `ℚ`, встановлено будову групи Ґалуа як мультиплікативної групи лишків `(ℤ/nℤ)*`, обчислено дискримінант кругового поля, знайдено квадратичні підполя через суми Ґаусса, розібрано факторизацію простих чисел за теоремою Дедекінда — Куммера та обґрунтовано фундаментальну теорему Кронекера — Вебера.

### Означення та відокремлення примітивних коренів

Розгляньмо рівняння `xⁿ − 1 = 0`. У полі комплексних чисел воно має рівно `n` попарно різних коренів, розташованих на одиничному колі:

```
ζ[n, k] = cos(2·π·k / n) + i·sin(2·π·k / n)      [k = 0, 1, 2, ..., n−1]
```

Число `ζ[n, k]` називають **примітивним коренем** `n`-го степеня з одиниці (англ. *primitive root of unity*), якщо найменшим натуральним степенем, що перетворює його на одиницю, є саме число `n`. Це виконується тоді й тільки тоді, коли показник `k` є взаємно простим із `n`, тобто найбільший спільний дільник `НСД(k, n) = 1`. Кількість таких примітивних коренів задається функцією Ейлера `φ(n)`.

**Круговим многочленом** (англ. *cyclotomic polynomial*) порядку `n` називають унітарний многочлен, коренями якого є всі примітивні корені `n`-го степеня з одиниці:

```
Φₙ(x) = ∏ (x − ζ[n, k])      [добуток за всіма 1 ≤ k ≤ n, де НСД(k, n) = 1]
```

Ступінь многочлена `Φₙ(x)` за означенням дорівнює значенню функції Ейлера: `deg(Φₙ) = φ(n)`.

Оскільки кожен із `n` коренів рівняння `xⁿ − 1 = 0` має деякий точний порядок `d`, де `d` обов'язково є дільником числа `n` (`d | n`), весь многочлен `xⁿ − 1` розпадається на добуток кругових многочленів за всіма дільниками `d`:

```
xⁿ − 1 = ∏ Φ[d](x)      [добуток за всіма d, що ділять n]
```

Це співвідношення дає рекурентний спосіб обчислення будь-якого `Φₙ(x)`:

```
Φₙ(x) = (xⁿ − 1) / ∏ Φ[d](x)      [добуток у знаменнику за всіма власними дільниками d | n, d < n]
```

### Спеціальні алгебраїчні тотожності для швидкого обчислення

Перш ніж ділити многочлени вручну, корисно вивести три загальні тотожності, які дозволяють миттєво записувати `Φₙ(x)` для великих класів чисел:

1. **Степінь простого числа `n = pᵏ`:**
Якщо `n = p` — просте число, то єдиним власним дільником є `d = 1`, тому:
```
Φₚ(x) = (xᵖ − 1) / (x − 1) = x^(p−1) + x^(p−2) + ... + x + 1
```
Якщо ж `n = pᵏ` є степенем простого числа, то всі дільники `pᵏ` є дільниками `p^(k−1)`, крім самого `pᵏ`. Звідси:
```
x^(pᵏ) − 1 = (x^(p^(k−1)) − 1) · Φ[pᵏ](x)
Φ[pᵏ](x)   = (x^(pᵏ) − 1) / (x^(p^(k−1)) − 1) = Φₚ( x^(p^(k−1)) )
```
Тобто круговий многочлен степеня простого числа отримують простою заміною змінної `x ↦ x^(p^(k−1))` у многочлені `Φₚ(x)`.

2. **Подвоєння непарного індексу `n = 2·m` (де m — непарне число, m > 1):**
Корені `Φ₂ₘ(x)` — це числа вигляду `−ζ`, де `ζ` — примітивний корінь `m`-го степеня. Тому:
```
Φ₂ₘ(x) = Φₘ(−x)      [для непарного m > 1]
```

3. **Множення на простий дільник, що вже входить до розкладу:**
Якщо просте число `p` ділить `m` (`p | m`), то:
```
Φ[p·m](x) = Φₘ(xᵖ)
```

### Покрокове обчислення кругових многочленів

Застосуймо ці правила та базове ділення для перших значень `n`.

**Випадок n = 1:**
```
Φ₁(x) = x − 1
```

**Випадок n = 2:**
```
Φ₂(x) = (x² − 1) / (x − 1) = x + 1
```

**Випадок n = 3:**
```
Φ₃(x) = (x³ − 1) / (x − 1) = x² + x + 1
```

**Випадок n = 4 (степінь двійки 2²):**
```
Φ₄(x) = Φ₂(x²) = x² + 1
```

**Випадок n = 5:**
```
Φ₅(x) = x⁴ + x³ + x² + x + 1
```

**Випадок n = 6 (подвоєння непарного 3):**
```
Φ₆(x) = Φ₃(−x) = (−x)² + (−x) + 1 = x² − x + 1
```

**Випадок n = 7:**
```
Φ₇(x) = x⁶ + x⁵ + x⁴ + x³ + x² + x + 1
```

**Випадок n = 8 (степінь двійки 2³):**
```
Φ₈(x) = Φ₂(x⁴) = x⁴ + 1
```

**Випадок n = 9 (квадрат трійки 3²):**
```
Φ₉(x) = Φ₃(x³) = (x³)² + x³ + 1 = x⁶ + x³ + 1
```

**Випадок n = 10 (подвоєння непарного 5):**
```
Φ₁₀(x) = Φ₅(−x) = x⁴ − x³ + x² − x + 1
```

**Випадок n = 12 (добуток 2 · 6, де 2 ділить 6):**
```
Φ₁₂(x) = Φ₆(x²)                                                [за правилом подвоєння індексу Φ₂ₘ(x) = Φₘ(x²)]
       = (x²)² − (x²) + 1                                      [підстановка x² у Φ₆(t) = t² − t + 1]
       = x⁴ − x² + 1                                           [розкриття степенів]
```

**Випадок n = 15 (добуток двох різних непарних простих 3 · 5):**
Дільники 15: `d = 1, 3, 5, 15`. Добуток многочленів для власних дільників дорівнює:
```
Φ₁(x) · Φ₃(x) · Φ₅(x) = (x³ − 1) · (x⁴ + x³ + x² + x + 1)      [оскільки Φ₁ · Φ₃ = x³ − 1]
                      = (x¹⁵ − 1) / Φ₁₅(x)                     [за властивістю x¹⁵ − 1 = ∏_{d|15} Φ_d]
Φ₁₅(x) = (x¹⁵ − 1) · (x − 1) / ((x³ − 1) · (x⁵ − 1))           [підстановка формули Мьобіуса]
       = x⁸ − x⁷ + x⁵ − x⁴ + x³ − x + 1                         [результат ділення в стовпчик]
```

### Формула обернення Мьобіуса для Φₙ(x)

Рекурентне співвідношення `xⁿ − 1 = ∏_{d | n} Φ[d](x)` можна обернути в явний мультиплікативний вираз за допомогою функції Мьобіуса `μ(m)`:

```
μ(m) =  1,  якщо m = 1
μ(m) =  0,  якщо m ділиться на квадрат простого числа (a² | m, a > 1)
μ(m) = (−1)ᵏ, якщо m є добутком k попарно різних простих чисел
```

**Теорема (явна формула кругового многочлена):**
Для будь-якого натурального числа `n ≥ 1` справджується рівність:

```
Φₙ(x) = ∏ (xᵈ − 1)^(μ(n / d))      [добуток за всіма d, що ділять n]
```

**Доведення:**
Підставмо розклад кожного множника `xᵈ − 1 = ∏_{c | d} Φ[c](x)` у праву частину формули:

```
∏[d | n] (xᵈ − 1)^(μ(n / d))
= ∏[d | n] ( ∏[c | d] Φ[c](x) )^(μ(n / d))          [підставили розклад xᵈ − 1]
= ∏[c | n] Φ[c](x)^( ∑[c | d | n] μ(n / d) )        [переставили порядок множення за парами (c, d)]
```

Розгляньмо суму в показнику степеня для фіксованого дільника `c | n`. Нехай `m = n / c`, а `k = n / d`. Тоді умова `c | d | n` рівносильна умові `k | m`. Сума набуває вигляду:

```
∑[k | m] μ(k)
```

За базовою властивістю функції Мьобіуса:
- Якщо `m = 1` (тобто `c = n`), сума складається з одного доданка `μ(1) = 1`.
- Якщо `m > 1` (тобто `c < n`), сума `∑_{k | m} μ(k) = 0`.

Отже, для `c < n` показник степеня дорівнює нулю (`Φ[c](x)⁰ = 1`), а для `c = n` показник степеня дорівнює одиниці:

```
∏[c | n] Φ[c](x)^( ∑[k | n/c] μ(k) ) = Φₙ(x)¹ = Φₙ(x)      [усі інші члени зникли]
```

Формулу доведено.

### Цілочисельність коефіцієнтів та феномен Φ₁₀₅(x)

З формули ділення многочленів за індукцією випливає, що **всі коефіцієнти кожного кругового многочлена `Φₙ(x)` є цілими числами**: `Φₙ(x) ∈ ℤ[x]`.

Для малих значень `n` (усіх `n < 105`) коефіцієнти `Φₙ(x)` набувають виключно значень `0, 1, −1`. Тривалий час математики першої половини XIX століття вважали, що це правило є універсальним. Проте у 1838 році було виявлено, що для найменшого числа `n`, яке є добутком трьох різних непарних простих чисел, а саме `n = 3 · 5 · 7 = 105`, коефіцієнти виходять за межі `{−1, 0, 1}`:

```
Φ₁₀₅(x) = x⁴⁸ + x⁴⁷ + x⁴⁶ − x⁴³ − x⁴² − 2·x⁴¹ − x⁴⁰ − x³⁹ + x³⁶ + x³⁵ + ... + 1
```

Коефіцієнт при `x⁴¹` та `x⁷` дорівнює **−2**. Ба більше, зі зростанням кількості простих дільників числа `n` абсолютні значення коефіцієнтів `Φₙ(x)` можуть бути як завгодно великими. Шура (Issai Schur) довів, що для будь-якого наперед заданого натурального числа `M` існує такий круговий многочлен, коефіцієнт якого за модулем перевищує `M`.

### Доведення незвідності Φₙ(x) над ℚ

Фундаментальний факт алгебри полягає в тому, що круговий многочлен `Φₙ(x)` є **незвідним** (англ. *irreducible*) над полем раціональних чисел `ℚ`. Це означає, що його неможливо розкласти в добуток двох многочленів меншого степеня з раціональними коефіцієнтами.

Доведімо спочатку незвідність для простого числа `p`.

**Лема 1 (Незвідність Φₚ(x)):**
Для будь-якого простого числа `p` круговий многочлен `Φₚ(x) = x^(p−1) + x^(p−2) + ... + x + 1` є незвідним над `ℚ`.

**Доведення:**
Зробімо заміну змінної `x = y + 1`:

```
Φₚ(y + 1) = ((y + 1)ᵖ − 1) / ((y + 1) − 1)
          = ((y + 1)ᵖ − 1) / y                         [спростили знаменник]
          = ( yᵖ + (p choose 1)·y^(p−1) + (p choose 2)·y^(p−2) + ... + p·y + 1 − 1 ) / y   [біном Ньютона]
          = y^(p−1) + (p choose 1)·y^(p−2) + (p choose 2)·y^(p−3) + ... + (p choose p−1)·1
```

Розгляньмо коефіцієнти отриманого многочлена за степенями `y`:
1. Старший коефіцієнт (при `y^(p−1)`) дорівнює 1 і не ділиться на `p`.
2. Кожен проміжний коефіцієнт `(p choose k) = p! / (k! · (p − k)!)` для `1 ≤ k ≤ p−1` ділиться на `p`, оскільки `p` — просте число, і воно не скорочується зі знаменником.
3. Вільний член дорівнює `(p choose p−1) = p`. Він ділиться на `p`, але **не ділиться на `p²`**.

Усі три умови критерію Ейзенштейна для простого числа `p` виконано. Отже, многочлен `Φₚ(y + 1)` є незвідним над `ℚ`. Звідси випливає, що й початковий многочлен `Φₚ(x)` є незвідним над `ℚ`.

**Теорема (Незвідність Φₙ(x) для довільного n):**
Для будь-якого натурального числа `n` круговий многочлен `Φₙ(x)` є незвідним над полем `ℚ`.

**Доведення:**
Нехай `ζ` — примітивний корінь `n`-го степеня з одиниці, а `f(x) ∈ ℚ[x]` — його мінімальний многочлен над `ℚ`. За лемою Ґаусса можна вважати, що `f(x)` є унітарним многочленом із цілими коефіцієнтами (`f(x) ∈ ℤ[x]`). Оскільки `Φₙ(ζ) = 0`, многочлен `f(x)` ділить `Φₙ(x)`, тобто `Φₙ(x) = f(x) · g(x)` для деякого `g(x) ∈ ℤ[x]`.

Покажемо, що для будь-якого простого числа `p`, яке не ділить `n` (`p ∤ n`), елемент `ζᵖ` також є коренем `f(x)`.

Припустімо супротивне: `f(ζᵖ) ≠ 0`. Оскільки `(ζᵖ)ⁿ = (ζⁿ)ᵖ = 1`, а порядок `ζᵖ` дорівнює `n` (бо `НСД(p, n) = 1`), число `ζᵖ` є коренем `Φₙ(x)`. З рівності `Φₙ(ζᵖ) = f(ζᵖ) · g(ζᵖ) = 0` випливає, що `g(ζᵖ) = 0`.

Отже, `ζ` є коренем многочлена `g(xᵖ)`. Оскільки `f(x)` є мінімальним многочленом для `ζ`, `f(x)` зобов'язаний ділити `g(xᵖ)` у кільці `ℤ[x]`:

```
g(xᵖ) = f(x) · h(x)      [де h(x) ∈ ℤ[x]]
```

Редукуймо цю рівність за модулем простого числа `p` у кільце `𝔽ₚ[x]`. За малою теоремою Ферма та властивістю автоморфізму Фробеніуса для будь-якого многочлена справджується `g(x)ᵖ ≡ g(xᵖ) (mod p)`. Тоді в `𝔽ₚ[x]`:

```
ḡ(x)ᵖ = f̄(x) · h̄(x)
```

Звідси випливає, що будь-який незвідний дільник многочлена `f̄(x)` у полі `𝔽ₚ[x]` також ділить `ḡ(x)`. Отже, многочлен `Φ̄ₙ(x) = f̄(x) · ḡ(x)` має кратний корінь у полі розкладу над `𝔽ₚ`.

Але `Φₙ(x)` ділить `xⁿ − 1`. Похідна `(xⁿ − 1)' = n·xⁿ⁻¹` у полі `𝔽ₚ[x]` не має спільних коренів із `xⁿ − 1`, оскільки `p ∤ n` (коефіцієнт `n ≠ 0` в `𝔽ₚ`). Отже, `xⁿ − 1` не має кратних коренів над `𝔽ₚ`, що суперечить наявності кратного кореня у `Φ̄ₙ(x)`.

Отримане протиріччя доводить, що `f(ζᵖ) = 0`.

Оскільки будь-який примітивний корінь `n`-го степеня має вигляд `ζᵐ`, де `НСД(m, n) = 1`, а число `m` можна розкласти в добуток простих чисел `m = p₁ · p₂ · ... · p[k]`, кожне з яких не ділить `n`, послідовне застосування доведеного твердження показує, що всі примітивні корені є коренями `f(x)`.

Отже, ступінь `f(x)` дорівнює кількості примітивних коренів: `deg(f) = deg(Φₙ) = φ(n)`. Це означає, що `f(x) = Φₙ(x)`, і круговий многочлен `Φₙ(x)` є незвідним над `ℚ`.

### Ступінь розширення та група Ґалуа

З незвідності `Φₙ(x)` безпосередньо випливають два фундаментальні наслідки:

1. **Ступінь кругового поля:**
Поле `ℚ(ζₙ)` є полем розкладу многочлена `Φₙ(x)`. Його ступінь над полем раціональних чисел дорівнює ступеню його мінімального многочлена:

```
[ℚ(ζₙ) : ℚ] = deg(Φₙ) = φ(n)
```

2. **Ізоморфізм групи Ґалуа:**
Будь-який автоморфізм `σ` поля `ℚ(ζₙ)`, що залишає нерухомими елементи `ℚ`, повністю визначається тим, куди він переводить твірний елемент `ζₙ`. Оскільки `σ(ζₙ)` також зобов'язаний бути примітивним коренем `n`-го степеня, існує єдиний лишок `a ∈ (ℤ/nℤ)*` такий, що:

```
σ[a](ζₙ) = ζₙᵃ      [де НСД(a, n) = 1]
```

Композиція двох автоморфізмів відповідає множенню лишків:

```
(σ[a] ∘ σ[b])(ζₙ) = σ[a](ζₙᵇ) = (ζₙᵇ)ᵃ = ζₙ^(a·b) = σ[a·b](ζₙ)
```

Отже, група Ґалуа кругового поля `Gal(ℚ(ζₙ) / ℚ)` канонічно ізоморфна мультиплікативній групі кільця лишків:

```
Gal(ℚ(ζₙ) / ℚ) ≅ (ℤ/nℤ)*
```

Оскільки група `(ℤ/nℤ)*` є комутативною (абелевою), **будь-яке кругове поле є абелевим розширенням поля раціональних чисел**.

### Дискримінант кругового поля

Дискримінант `Δ` поля `ℚ(ζₙ)` вимірює об'єм фундаментальної комірки кільця цілих `ℤ[ζₙ]` та показує, які саме прості числа розгалужуються в цьому розширенні.

**Теорема (Дискримінант кругового поля):**
Для кругового поля `K = ℚ(ζₙ)` степеня `φ(n)` над `ℚ` дискримінант задається формулою:

```
Δ[K] = (−1)^(φ(n) / 2) · n^(φ(n)) / ∏[p | n] p^(φ(n) / (p − 1))
```

Зокрема:
- Для простого `p`: `Δ[ℚ(ζₚ)] = (−1)^((p − 1) / 2) · p^(p − 2)`.
  Наприклад, для `p = 3`: `Δ[ℚ(ζ₃)] = (−1)¹ · 3¹ = −3`.
  Для `p = 5`: `Δ[ℚ(ζ₅)] = (−1)² · 5³ = +125`.
- Для степеня простого `pᵏ`: єдиним простим дільником дискримінанта є саме число `p`.

З теореми Дедекінда про дискримінант випливає фундаментальний факт: **раціональне просте число `q` розгалужується в круговому полі `ℚ(ζₙ)` тоді й тільки тоді, коли `q` ділить `n`** (`q | n`). Усі інші прості числа залишаються нерозгалуженими!

### Проміжні підполя та квадратичні розширення через суми Ґаусса

За фундаментальною теоремою теорії Ґалуа кожній підгрупі `H ⊆ (ℤ/nℤ)*` взаємно однозначно відповідає проміжне підполе фіксованих елементів `K = ℚ(ζₙ)ᴴ`.

Зокрема, оскільки група `(ℤ/pℤ)*` для простого непарного `p` є циклічною групою парного порядку `p − 1`, вона містить єдину підгрупу індексу 2 (підгрупу квадратичних лишків). Їй відповідає єдине **квадратичне підполе** `K ⊂ ℚ(ζₚ)`.

Знайти твірний елемент цього квадратичного поля дозволяє **квадратична сума Ґаусса**:

```
g = ∑[k=1..p−1] (k / p) · ζ[p]ᵏ      [де (k / p) — символ Лежандра]
```

Обчислімо значення `g²` крок за кроком для розуміння внутрішнього механізму.

**Явний розрахунок g²:**
```
g² = ( ∑[a=1..p−1] (a / p) · ζᵃ ) · ( ∑[b=1..p−1] (b / p) · ζᵇ )
   = ∑[a=1..p−1] ∑[b=1..p−1] ( (a·b) / p ) · ζ^(a + b)          [мультиплікативність символу Лежандра]
```

Зробімо заміну змінної підсумовування `b ≡ a·u (mod p)`. Коли `b` пробігає лишки від 1 до `p−1`, число `u` також пробігає від 1 до `p−1`:

```
g² = ∑[a=1..p−1] ∑[u=1..p−1] ( (a²·u) / p ) · ζ^(a·(1 + u))
   = ∑[u=1..p−1] (u / p) · ( ∑[a=1..p−1] ζ^(a·(1 + u)) )       [оскільки (a²/p) = 1]
```

Розгляньмо внутрішню суму за `a`:
1. Якщо `1 + u ≡ 0 (mod p)` (тобто `u ≡ −1 ≡ p − 1 mod p`), то `ζ^(a·0) = 1`, і внутрішня сума дорівнює `∑[a=1..p−1] 1 = p − 1`.
2. Якщо `1 + u ≢ 0 (mod p)`, то показник `a·(1 + u)` пробігає всі ненульові лишки, і сума всіх коренів дорівнює `−1`.

Підставмо ці значення у вираз для `g²`:
```
g² = (−1 / p) · (p − 1) + ∑[u ≠ p−1] (u / p) · (−1)
   = (−1 / p) · (p − 1) − ( ∑[u=1..p−1] (u / p) − (−1 / p) )
   = (−1 / p) · (p − 1) − ( 0 − (−1 / p) )                     [сума символів Лежандра за повним періодом дорівнює 0]
   = (−1 / p) · (p − 1 + 1)
   = (−1 / p) · p
```

Оскільки за критерієм Ейлера `(−1 / p) = (−1)^((p − 1) / 2)`, ми отримуємо точне співвідношення Ґаусса:

```
g² = (−1)^((p − 1) / 2) · p = p*
```

де `p* = p`, якщо `p ≡ 1 (mod 4)`, і `p* = −p`, якщо `p ≡ 3 (mod 4)`.

Звідси випливає, що квадратний корінь `√p*` завжди лежить усередині кругового поля `ℚ(ζₚ)`:

```
ℚ(√p*) ⊂ ℚ(ζₚ)
```

Наприклад:
- Для `p = 5` (`5 ≡ 1 mod 4`): `g² = 5`, отже `√5 ∈ ℚ(ζ₅)`.
- Для `p = 3` (`3 ≡ 3 mod 4`): `g² = −3`, отже `√−3 = i·√3 ∈ ℚ(ζ₃)`.
- Оскільки `i = ζ₄ ∈ ℚ(ζ₄)`, будь-який квадратний корінь `√m` для довільного цілого `m` можна отримати комбінацією коренів із простих чисел, а отже, **кожне квадратичне поле `ℚ(√m)` лежить у деякому круговому полі**.

### Розклад простих чисел у круговому полі (Теорема Дедекінда — Куммера)

Теорія кругових полів дає вичерпний опис того, як звичайне просте число `q ∈ ℤ` факторизується на прості ідеали в кільці цілих `ℤ[ζₙ]`.

**Теорема (Факторизація простих чисел):**
Нехай `q` — просте число, яке не ділить `n` (`q ∤ n`). Нехай `f` — мультиплікативний порядок числа `q` за модулем `n` (тобто найменше натуральне число таке, що `qᶠ ≡ 1 mod n`).

Тоді в кільці `ℤ[ζₙ]` головний ідеал `(q)` розкладається в добуток `g = φ(n) / f` попарно різних простих ідеалів однакової норми `qᶠ`:

```
(q) = 𝔮₁ · 𝔮₂ · ... · 𝔮[g]
де deg(𝔮[j]) = f,  і  f · g = φ(n)
```

Число `f` називають **степенем інерції** (англ. *inertial degree*), а `g` — **кількістю простих множників**.

**Конкретні числові приклади в полі ℚ(ζ₅) (де n = 5, φ(5) = 4):**
1. **Просте число q = 11:**
   `11 ≡ 1 (mod 5)`. Порядок `f = 1`.
   Тоді `g = 4 / 1 = 4`.
   Ідеал `(11)` повністю розпадається на 4 різні прості ідеали першого степеня:
   `(11) = 𝔮₁ · 𝔮₂ · 𝔮₃ · 𝔮₄`. Це випадок **повного розпаду** (англ. *complete splitting*).

2. **Просте число q = 2:**
   Послідовні степені: `2¹ = 2`, `2² = 4`, `2³ = 8 ≡ 3`, `2⁴ = 16 ≡ 1 (mod 5)`.
   Порядок `f = 4`.
   Тоді `g = 4 / 4 = 1`.
   Ідеал `(2)` залишається простим ідеалом у `ℤ[ζ₅]`. Це випадок **інертності** (англ. *inert prime*).

3. **Просте число q = 5 (ділить n):**
   `5 ≡ 0 (mod 5)` — це розгалужене число.
   У кільці `ℤ[ζ₅]` справджується розклад:
   `(5) = (1 − ζ₅)⁴`.
   Ідеал стає 4-м степенем одного простого ідеалу `𝔭 = (1 − ζ₅)`. Індекс розгалуження `e = 4 = φ(5)`.

### Теорема Кронекера — Вебера

Той факт, що кожне квадратичне поле (яке є абелевим розширенням степеня 2) міститься в деякому круговому полі, підштовхнув Леопольда Кронекера у 1853 році до сміливої гіпотези, яку остаточно довів Генріх Вебер у 1886 році.

**Теорема Кронекера — Вебера (Kronecker–Weber Theorem):**
Будь-яке скінченне абелеве розширення поля раціональних чисел `K / ℚ` (тобто розширення Ґалуа, чия група Ґалуа `Gal(K / ℚ)` є комутативною) є підполем деякого кругового поля:

```
K ⊆ ℚ(ζₙ)      [для деякого натурального n]
```

Найменше таке число `n` називають **провідником** (англ. *conductor*) поля `K`.

**Значення теореми Кронекера — Вебера:**
1. Вона повністю класифікує всі абелеві розширення над полем раціональних чисел `ℚ`. Замість абстрактного пошуку невідомих числових полів теорема стверджує, що будь-яке абелеве числове поле є алгебраїчною комбінацією значень тригонометричних функцій `cos(2·π / n)` та `sin(2·π / n)`.
2. Вона стала першим прикладом і джерелом натхнення для **теорії полів класів** (англ. *class field theory*), розробленої Гільбертом, Артіном і Такаґі у XX столітті, яка узагальнила цей принцип на довільні базові числові поля.
3. Вона розв'язала дванадцяту проблему Гільберта для випадку поля раціональних чисел: аналітичні функції, що породжують усі абелеві розширення над `ℚ`, — це експоненційна функція `e^(2·π·i·z)`.

Теорема Кронекера — Вебера є однією з вершин алгебри: вона стверджує, що вся комутативна алгебраїчна теорія чисел над `ℚ` повністю вичерпується геометрією ділення кола на рівні частини. Будь-яке алгебраїчне число, чиї симетрії комутують між собою, є лінійною комбінацією коренів з одиниці `ζₙ` із раціональними коефіцієнтами.
