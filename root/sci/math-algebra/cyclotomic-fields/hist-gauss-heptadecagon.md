# 📜 Гаусс, 17-кутник і народження ідеальних чисел

Понад дві тисячі років, від античної Греції до кінця вісімнадцятого століття, геометрія знала лише три класи правильних многокутників, які можна побудувати виключно за допомогою циркуля та лінійки: рівносторонній трикутник, квадрат, правильний п'ятикутник та їхні подвоєння (а також складений п'ятнадцятикутник). Евклід у своїх «Началах» описав ці побудови бездоганно, але запитання, чи існують інші прості числа `p`, для яких правильний `p`-кутник піддається такій самій побудові, залишалося повною загадкою. Жоден геометр античності, середньовіччя чи раннього нового часу не зміг ані побудувати правильний семикутник чи одинадцятикутник, ані довести неможливість такої побудови.

Вранці 30 березня 1796 року дев'ятнадцятирічний студент Геттінгенського університету Карл Фрідріх Гаусс зробив відкриття, яке не просто розв'язало давню геометричну загадку, а визначило всю його подальшу долю і дало початок сучасній алгебраїчній теорії чисел. Гаусс довів, що правильний сімнадцятикутник будується циркулем і лінійкою. Цей запис став першим у його знаменитому щоденнику відкриттів і переконав юнака відмовитися від філології на користь математики.

### Щоденниковий запис 1796 року та перехід від креслення до алгебри

Гаусс зрозумів те, чого не бачили геометри попередніх двох тисячоліть: геометрична побудова правильного `n`-кутника циркулем і лінійкою повністю еквівалентна знаходженню дійсних координат його вершин на площині. Якщо розташувати центр многокутника на початку координат, а одну з вершин помістити в точку `(1, 0)`, то всі `n` вершин будуть точками перетину одиничного кола з кутами, кратними `2·π / n`.

Мовою комплексних чисел ці вершини є коренями рівняння `xⁿ − 1 = 0`. Корені мають вигляд:

```
ζ[k] = cos(2·π·k / n) + i·sin(2·π·k / n)      [k = 0, 1, ..., n−1]
```

Циркуль і лінійка дозволяють виконувати лише обмежений набір операцій: додавати й віднімати відрізки, множити й ділити їхні довжини, а також добувати квадратні корені (знаходячи точки перетину прямих і кіл). Операція добування кубічного кореня чи кореня довільного непарного степеня за допомогою циркуля та лінійки нездійсненна. Отже, число можна побудувати геометрично тоді й тільки тоді, коли воно лежить у вежі розширень поля раціональних чисел, кожне з яких має ступінь 2 над попереднім:

```
ℚ = K₀ ⊂ K₁ ⊂ K₂ ⊂ ... ⊂ K[m]
де [K[j+1] : K[j]] = 2
```

Повний ступінь такого складеного поля над полем раціональних чисел `ℚ` обов'язково є степенем двійки: `[K[m] : ℚ] = 2ᵐ`.

Для простого числа `p = 17` рівняння `x¹⁷ − 1 = 0` після відокремлення тривіального кореня `x = 1` перетворюється на круговий многочлен шістнадцятого степеня:

```
x¹⁶ + x¹⁵ + x¹⁴ + ... + x² + x + 1 = 0
```

Ступінь цього рівняння дорівнює шістнадцяти, а `16 = 2⁴` є точним степенем двійки. Гаусс поставив питання: чи можна розв'язати це рівняння шістнадцятого степеня, не розв'язуючи жодних рівнянь вищих степенів, а послідовно застосувавши рівно чотири квадратні рівняння одне за одним?

### Періоди Гаусса: як приборкати симетрію

Ключем до розв'язання стала теорія періодів. Візьмімо первісний корінь за модулем 17, тобто число, степені якого пробігають усі ненульові лишки. Для модуля 17 таким числом є `g = 3`:

```
3⁰  = 1,   3¹  = 3,   3²  = 9,   3³  = 10,  3⁴  = 13,  3⁵  = 5,   3⁶  = 15,  3⁷  = 11,
3⁸  = 16,  3⁹  = 14,  3¹⁰ = 8,   3¹¹ = 7,   3¹² = 4,   3¹³ = 12,  3¹⁴ = 2,   3¹⁵ = 6   (mod 17)
```

Позначимо через `ζ` будь-який примітивний корінь сімнадцятого степеня з одиниці. Гаусс згрупував шістнадцять коренів `ζ, ζ², ζ³, ..., ζ¹⁶` у дві суми по вісім доданків кожна (так звані 8-елементні періоди `η₁` та `η₂`), чергуючи парні й непарні степені генератора `g = 3`:

```
η₁ = ζ¹ + ζ⁹ + ζ¹³ + ζ¹⁵ + ζ¹⁶ + ζ⁸ + ζ⁴ + ζ²      [парні степені трійки: 3⁰, 3², 3⁴, ...]
η₂ = ζ³ + ζ¹⁰ + ζ⁵ + ζ¹¹ + ζ¹⁴ + ζ⁷ + ζ¹² + ζ⁶     [непарні степені трійки: 3¹, 3³, 3⁵, ...]
```

Якщо скласти ці два періоди, ми отримаємо суму всіх шістнадцяти коренів кругового многочлена:

```
η₁ + η₂ = ζ¹ + ζ² + ζ³ + ... + ζ¹⁶ = −1
```

Якщо ж перемножити ці дві суми і скористатися періодичністю `ζ¹⁷ = 1`, усі перехресні добутки перегруповуються в сталу цілу величину:

```
η₁ · η₂ = −4
```

Знаючи суму `η₁ + η₂ = −1` та добуток `η₁ · η₂ = −4`, за теоремою Вієта знаходимо, що `η₁` та `η₂` є коренями звичайного квадратного рівняння `y² + y − 4 = 0`. Його розв'язки мають вигляд:

```
η₁ = (−1 + √17) / 2
η₂ = (−1 − √17) / 2
```

Далі Гаусс розбив кожен 8-елементний період на два 4-елементні періоди. Вони задовольнили наступну пару квадратних рівнянь, коефіцієнти яких залежали вже від `η₁` та `η₂`. Наступним кроком кожен 4-елементний період розпався на пару 2-елементних періодів. Нарешті, сума двох комплексно спряжених коренів `ζ¹ + ζ¹⁶ = 2·cos(2·π / 17)` дала значення косинуса центрального кута сімнадцятикутника:

```
cos(2·π / 17) = −1/16 + (1/16)·√17 + (1/16)·√(34 − 2·√17)
                + (1/8)·√(17 + 3·√17 − √(34 − 2·√17) − 2·√(34 + 2·√17))
```

Цей монументальний вираз містить лише чотири вкладені квадратні корені й жодної операції вищого порядку. Отже, довжину сторони сімнадцятикутника можна побудувати циркулем і лінійкою за скінченну кількість кроків.

Гаусс узагальнив цей результат у праці *«Disquisitiones Arithmeticae»* (1801): правильний `n`-кутник можна побудувати циркулем і лінійкою тоді й лише тоді, коли число `n` є добутком степеня двійки та попарно різних простих чисел Ферма, тобто простих чисел вигляду:

```
F[k] = 2^(2^k) + 1
```

Відомими простими числами Ферма є `F₀ = 3`, `F₁ = 5`, `F₂ = 17`, `F₃ = 257`, `F₄ = 65537`. Необхідність цієї умови (що інших простих чисел для побудови бути не може) остаточно довів П'єр Ванцель у 1837 році.

### Французька академія 1847 року: фатальна помилка Ламе

Через півстоліття після відкриття Гаусса кругові поля опинилися в центрі іншої великої математичної драми — спроби доведення Великої теореми Ферма:

```
xⁿ + yⁿ = zⁿ      [не має ненульових цілих розв'язків для n ≥ 3]
```

Для простого показника степеня `p` ліву частину рівняння Ферма `xᵖ + yᵖ` над звичайними цілими числами розкласти на лінійні множники неможливо. Але якщо вийти за межі раціональних чисел у кругове кільце `ℤ[ζ]`, де `ζ = e^(2·π·i / p)`, сума степенів розпадається на добуток `p` простих дужок:

```
xᵖ + yᵖ = (x + y)·(x + ζ·y)·(x + ζ²·y)· ... ·(x + ζ^(p−1)·y) = zᵖ
```

1 березня 1847 року французький математик Габріель Ламе урочисто оголосив на засіданні Паризької академії наук, що знайшов повне доведення Великої теореми Ферма для всіх простих показників. Його міркування виглядало простим і переконливим: якщо добуток взаємно простих чисел дорівнює `p`-му степеню `zᵖ`, то кожен із множників сам по собі зобов'язаний бути `p`-м степенем деякого числа в тому самому числовому кільці:

```
x + ζᵏ·y = u · t[k]ᵖ      [де u — оборотний елемент кільця]
```

Одразу після доповіді Ламе слово взяв Оґюстен-Луї Коші. Він повідомив, що працював над схожою ідеєю і готовий підтвердити правильність підходу. Проте присутній на засіданні Жозеф Ліувілль охолодив ентузіазм колег. Ліувілль зауважив, що все доведення неявно спирається на одне припущення: в кільці кругових цілих чисел `ℤ[ζ]` діє основна теорема арифметики, тобто кожен елемент розкладається на прості множники єдиним чином (з точністю до порядку та оборотних множників).

Коші та Ламе кілька тижнів намагалися довести однозначність розкладу, публікуючи поспішні замітки, доки наприкінці травня 1847 року Ліувілль не зачитав листа від німецького математика Ернста Едуарда Куммера.

### Куммер і крах однозначної факторизації для p = 23

Куммер повідомив Паризьку академію, що однозначний розклад на прості множники в кругових кільцях `ℤ[ζ[p]]` зазнає краху. Ще у 1844 році Куммер ретельно досліджував кругові поля і виявив, що для всіх простих чисел `p < 23` розклад залишається однозначним, але для першого ж простого числа `p = 23` усе руйнується.

У кільці `ℤ[ζ₂₃]` існують елементи, які можна розкласти на незвідні множники принципово різними способами. Наприклад, число 2 можна подати через різні комбінації незвідних кругових чисел, які не перетворюються одне в одне множенням на жодні оборотні елементи кільця.

Цей контрприклад знищив надію на просте доведення теореми Ферма, але відкрив набагато глибший пласт математичної реальності. Куммер поставив запитання: чому однозначність розкладу ламається і як її відновити?

### Винахід ідеальних чисел та регулярні прості числа

Куммер запропонував геніальну ідею: якщо самі числа кільця `ℤ[ζ]` більше не поводяться як однозначні будівельні блоки, це означає, що існують «невидимі» дільники, які не є елементами самого кільця, але проявляються у їхніх добутках. Куммер назвав ці фіктивні множники **ідеальними числами** (нім. *ideale Zahlen*).

Згодом Ріхард Дедекінд переклав інтуїтивні ідеальні числа Куммера на точну мову підмножин кільця, які ми сьогодні називаємо **ідеалами**. Ідеал `I ⊂ ℤ[ζ]` — це підмножина, замкнена щодо додавання, яка поглинає множення на будь-які елементи кільця. У мові ідеалів закон однозначного розкладу відновився у бездоганному вигляді:

> У будь-якому кільці цілих алгебраїчних чисел кожен ненульовий ідеал однозначно розкладається в добуток простих ідеалів:
> `I = 𝔭₁ · 𝔭₂ · ... · 𝔭[k]`

Щоб виміряти, наскільки сильно кільце кругових цілих `ℤ[ζ[p]]` відхиляється від звичайного однозначного розкладу, Куммер увів поняття **групи класів ідеалів** та її порядку — **числа класів** `h[p]`.
- Якщо `h[p] = 1`, то кожен ідеал є головним (породженим одним елементом), і в кільці діє звичайна однозначна факторизація чисел.
- Якщо `h[p] > 1`, кільце має нетривіальні класи ідеалів, і факторизація чисел перестає бути однозначною.

Куммер назвав просте число `p` **регулярним** (англ. *regular prime*), якщо число `p` не ділить число класів `h[p]` відповідного кругового поля `ℚ(ζ[p])`.

Куммер знайшов дивовижний аналітичний критерій регулярності: просте число `p` є регулярним тоді й тільки тоді, коли воно не ділить чисельники перших `(p − 3) / 2` чисел Бернуллі `B₂, B₄, B₆, ..., B[p-3]`.

Ось кілька перших простих чисел та їхній статус регулярності:
- `p = 3`: регулярне (`h₃ = 1`)
- `p = 5`: регулярне (`h₅ = 1`)
- `p = 7`: регулярне (`h₇ = 1`)
- `p = 23`: регулярне, хоча `h₂₃ = 3` (число 23 не ділить 3!)
- `p = 37`: **нерегулярне**, оскільки чисельник числа Бернуллі `B₃₂` ділиться на 37 (`h₃₇ = 37`).
- `p = 59`, `p = 67`: також нерегулярні числа.

Спираючись на теорію ідеалів, Куммер у 1850 році довів Велику теорему Ферма для **всіх регулярних простих чисел**:

```
xᵖ + yᵖ = zᵖ      [не має ненульових цілих розв'язків для будь-якого регулярного p]
```

Це було найбільшим проривом у дослідженні теореми Ферма за понад два століття від її формулювання. За цей результат Паризька академія наук у 1857 році присудила Куммеру Гран-прі з математики, хоча премія призначалася за повне розв'язання проблеми.

Створена Куммером техніка дослідження кругових полів через ідеали заклала підвалини всієї сучасної алгебраїчної теорії чисел, комутативної алгебри та теорії полів класів. Ділення кола, розпочате Гауссом як геометрична вправа для сімнадцятикутника, виросло в універсальний інструмент вивчення фундаментальних законів арифметики.
