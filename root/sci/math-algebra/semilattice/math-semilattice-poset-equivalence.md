# 🧮 Доведення еквівалентності алгебраїчної напіврешітки та часткового порядку

Будь-яка абстрактна алгебраїчна система з однією асоціативною, комутативною та ідемпотентною операцією однозначно визначає частковий порядок із точними гранями, і навпаки — будь-який частковий порядок із точними нижніми (або верхніми) гранями для кожної пари елементів породжує таку алгебраїчну структуру. Доведення цієї фундаментальної еквівалентності розкриває, чому властивості обчислень та геометричні властивості ієрархій є двома сторонами однієї математичної істини.

Нижче наведено строгі доведення прямої та оберненої теорем для нижніх і верхніх напіврешіток, а також аналіз збереження структури порядку при гомоморфізмах, теорему представлення та зв'язок з ідеалами.

---

### 1. Пряма теорема: від алгебри до часткового порядку

Нехай задано алгебраїчну систему `(S, ⋆)`, де множина `S` замкнена відносно бінарної операції `⋆ : S × S → S`, яка задовольняє три аксіоми для всіх елементів `a, b, c ∈ S`:

```
(a ⋆ b) ⋆ c = a ⋆ (b ⋆ c)      [аксіома А1: асоціативність]
a ⋆ b = b ⋆ a                  [аксіома А2: комутативність]
a ⋆ a = a                      [аксіома А3: ідемпотентність]
```

Введемо на множині `S` бінарне відношення `≤` за таким канонічним правилом:

```
a ≤ b  ⇔  a ⋆ b = a
```

Потрібно довести два фундаментальні твердження:
1. Відношення `≤` є строгим частковим порядком (воно є рефлексивним, антисиметричним та транзитивним).
2. Для будь-яких двох елементів `a, b ∈ S` елемент `a ⋆ b` є точною нижньою гранню (інфімумом) двоелементної множини `{a, b}` відносно порядку `≤`, тобто `a ⋆ b = inf{a, b}`.

---

#### Доведення рефлексивності порядку

Потрібно довести, що для будь-якого довільного елемента `a ∈ S` обов'язково виконується умова `a ≤ a`.

За прийнятим означенням відношення `≤` твердження `a ≤ a` є рівносильним алгебраїчній рівності `a ⋆ a = a`.

```
a ⋆ a
= a                            [за аксіомою ідемпотентності А3]
```

Оскільки ця рівність виконується тотожно для кожного елемента множини `S`, ми отримуємо `a ≤ a`. Отже, властивість рефлексивності повністю доведена.

---

#### Доведення антисиметричності порядку

Нехай для деякої пари елементів `a, b ∈ S` одночасно справджуються дві умови: `a ≤ b` та `b ≤ a`. Необхідно довести, що ці елементи є тотожно рівними: `a = b`.

Розпишемо обидві вихідні умови за означенням порядку:

```
a ⋆ b = a                      [рівність 1: випливає з умови a ≤ b]
b ⋆ a = b                      [рівність 2: випливає з умови b ≤ a]
```

Тепер виконаємо прямий ланцюжок алгебраїчних перетворень для елемента `a`, скориставшись комутативністю операції:

```
a
= a ⋆ b                        [за рівністю 1]
= b ⋆ a                        [за аксіомою комутативності А2]
= b                            [за рівністю 2]
```

Оскільки `a = b`, властивість антисиметричності доведена. Впорядковані пари не можуть утворювати взаємних циклів без повної тотожності елементів.

---

#### Доведення транзитивності порядку

Нехай для довільної трійки елементів `a, b, c ∈ S` виконуються два відношення слідування: `a ≤ b` та `b ≤ c`. Необхідно довести, що звідси неминуче випливає `a ≤ c`, тобто довести алгебраїчну рівність `a ⋆ c = a`.

Випишемо вихідні умови мовою алгебраїчної операції:

```
a ⋆ b = a                      [рівність 1: випливає з умови a ≤ b]
b ⋆ c = b                      [рівність 2: випливає з умови b ≤ c]
```

Підставимо вираз `a ⋆ b` замість першого входження `a` у добуток `a ⋆ c` та застосуємо асоціативність:

```
a ⋆ c
= (a ⋆ b) ⋆ c                  [підстановка a = a ⋆ b за рівністю 1]
= a ⋆ (b ⋆ c)                  [за аксіомою асоціативності А1]
= a ⋆ b                        [підстановка b ⋆ c = b за рівністю 2]
= a                            [підстановка a ⋆ b = a за рівністю 1]
```

Оскільки в результаті отримано точну рівність `a ⋆ c = a`, за означенням маємо `a ≤ c`. Транзитивність повністю доведена.

Таким чином, структура `(S, ≤)` є повноцінною частково впорядкованою множиною (посетом).

---

#### Доведення того, що добуток `a ⋆ b` є інфімумом `inf{a, b}`

Щоб довести, що елемент `m = a ⋆ b` є точною нижньою гранню множини `{a, b}`, необхідно перевірити дві класичні умови теорії порядку:
1. Елемент `m` є нижньою гранню (лежить нижче або дорівнює кожному з аргументів: `m ≤ a` та `m ≤ b`).
2. Елемент `m` є найбільшою серед усіх можливих нижніх граней: якщо деякий `c ∈ S` задовольняє `c ≤ a` та `c ≤ b`, то обов'язково `c ≤ m`.

**Крок 1: перевірка, що `a ⋆ b` є нижньою гранню.**

Перевіримо умову `(a ⋆ b) ≤ a`, що за означенням порядку означає `(a ⋆ b) ⋆ a = a ⋆ b`:

```
(a ⋆ b) ⋆ a
= a ⋆ (a ⋆ b)                  [за комутативністю А2]
= (a ⋆ a) ⋆ b                  [за асоціативністю А1]
= a ⋆ b                        [за ідемпотентністю А3]
```

Рівність виконується, тому `a ⋆ b ≤ a`.

Аналогічно перевіримо другу умову `(a ⋆ b) ≤ b`, тобто `(a ⋆ b) ⋆ b = a ⋆ b`:

```
(a ⋆ b) ⋆ b
= a ⋆ (b ⋆ b)                  [за асоціативністю А1]
= a ⋆ b                        [за ідемпотентністю А3]
```

Отже, `a ⋆ b ≤ b`. Елемент `a ⋆ b` дійсно є спільною нижньою гранню для пари `{a, b}`.

**Крок 2: доведення максимальності нижньої грані.**

Нехай елемент `c ∈ S` є довільною спільною нижньою гранню для `a` та `b`, тобто `c ≤ a` і `c ≤ b`. Це означає виконання двох рівнянь:

```
c ⋆ a = c                      [з умови c ≤ a]
c ⋆ b = c                      [з умови c ≤ b]
```

Потрібно довести, що `c ≤ a ⋆ b`, тобто що `c ⋆ (a ⋆ b) = c`. Обчислимо цей вираз:

```
c ⋆ (a ⋆ b)
= (c ⋆ a) ⋆ b                  [за асоціативністю А1]
= c ⋆ b                        [підстановка c ⋆ a = c]
= c                            [підстановка c ⋆ b = c]
```

Оскільки `c ⋆ (a ⋆ b) = c`, маємо `c ≤ a ⋆ b`. 

Це завершує доведення: будь-яка інша нижня грань `c` лежить не вище за `a ⋆ b`. Отже, елемент `a ⋆ b` є точною найбільшою нижньою гранню: `a ⋆ b = inf{a, b}` (позначається також `a ∧ b` або `a ⊓ b`).

### 2. Обернена теорема: від часткового порядку до алгебри

Нехай задано частково впорядковану множину `(S, ≤)`, у якій для будь-якої пари елементів `a, b ∈ S` гарантовано існує єдина точна нижня грань `inf{a, b}`.

Визначимо бінарну операцію `∧ : S × S → S` як:

```
a ∧ b = inf{a, b}
```

Доведемо, що побудована операція `∧` автоматично задовольняє аксіоми ідемпотентності, комутативності та асоціативності.

---

#### Доведення ідемпотентності: `a ∧ a = a`

За означенням, `a ∧ a = inf{a, a}`.
1. Оскільки порядок `≤` є рефлексивним, маємо `a ≤ a`. Отже, елемент `a` є нижньою гранню для одноелементної множини `{a}`.
2. Якщо `x ∈ S` — довільна нижня грань для `{a}`, то за означенням нижньої грані `x ≤ a`.

Оскільки `a` є нижньою гранню і перевершує будь-яку іншу нижню грань `x`, саме `a` є найбільшою нижньою гранню:

```
a ∧ a
= inf{a, a}                    [за означенням операції]
= a                            [оскільки a є найбільшим елементом у множині нижніх граней {a}]
```

Ідемпотентність доведена.

---

#### Доведення комутативності: `a ∧ b = b ∧ a`

Множина як математичний об'єкт не залежить від порядку переліку її елементів: `{a, b} = {b, a}`.

Множина всіх спільних нижніх граней `L(a, b)` визначається як:

```
L(a, b) = {x ∈ S : x ≤ a і x ≤ b}
```

Оскільки логічна кон'юнкція умов `(x ≤ a) ∧ (x ≤ b)` є симетричною, множина `L(a, b)` тотожно збігається з множиною `L(b, a) = {x ∈ S : x ≤ b і x ≤ a}`. Оскільки множини нижніх граней тотожні, їхній єдиний найбільший елемент (якщо він існує) також збігається:

```
a ∧ b
= inf{a, b}                    [за означенням операції ∧]
= max(L(a, b))                 [інфімум як найбільший елемент множини спільних нижніх граней]
= max(L(b, a))                 [оскільки множини L(a, b) та L(b, a) тотожні]
= inf{b, a}                    [за означенням інфімуму]
= b ∧ a                        [за означенням операції ∧]
```

Комутативність повністю доведена.

---

#### Доведення асоціативності: `(a ∧ b) ∧ c = a ∧ (b ∧ c)`

Доведемо, що обидва вирази дорівнюють точній нижній грані триелементної підмножини `inf{a, b, c}`.

Позначимо `u = (a ∧ b) ∧ c`.
1. За означенням інфімуму для пари `{a ∧ b, c}` маємо: `u ≤ a ∧ b` та `u ≤ c`.
2. Оскільки `u ≤ a ∧ b`, а для пари `{a, b}` інфімум задовольняє `a ∧ b ≤ a` та `a ∧ b ≤ b`, за транзитивністю порядку маємо `u ≤ a` та `u ≤ b`.
3. Отже, `u` є спільною нижньою гранню для всієї трійки `{a, b, c}`.

Тепер нехай `z ∈ S` — довільна нижня грань множини `{a, b, c}`, тобто `z ≤ a`, `z ≤ b` та `z ≤ c`.
- Оскільки `z ≤ a` і `z ≤ b`, за властивістю інфімуму маємо `z ≤ a ∧ b`.
- Оскільки `z ≤ a ∧ b` і `z ≤ c`, знову за властивістю інфімуму для пари `{a ∧ b, c}` маємо `z ≤ (a ∧ b) ∧ c = u`.

Таким чином, `u` є найбільшою серед усіх нижніх граней трійки `{a, b, c}`:

```
(a ∧ b) ∧ c = inf{a, b, c}
```

Повністю симетричні міркування для правої розстановки дужок дають:

```
a ∧ (b ∧ c) = inf{a, b, c}
```

Зіставляючи обидві рівності, отримуємо:

```
(a ∧ b) ∧ c
= inf{a, b, c}                 [інфімум триелементної множини]
= a ∧ (b ∧ c)                  [за симетрією побудови]
```

Асоціативність доведена. Отже, кожна порядкова нижня напіврешітка є строгою алгебраїчною напіврешіткою.

### 3. Двоїстість для верхніх напіврешіток (Join-Semilattices)

Для верхніх напіврешіток порядок визначається дуальним алгебраїчним співвідношенням через операцію взяття точної верхньої грані `⊔` (супремуму):

```
a ≤ b  ⇔  a ⊔ b = b
```

Усі доведення переносяться дзеркально завдяки **принципу двоїстості порядків**: якщо частково впорядковану множину `(S, ≤)` замінити на множину з оберненим порядком `(S, ≥)`, де `x ≥ y ⇔ y ≤ x`, то:
1. Інфімум у системі `(S, ≤)` стає супремумом у системі `(S, ≥)`.
2. Нижня напіврешітка `(S, ⊓)` перетворюється на верхню напіврешітку `(S, ⊔)` над тим самим носієм `S`.

Ця симетрія дозволяє доводити твердження лише для одного типу напіврешіток — для іншого вони виконуються автоматично.

### 4. Гомоморфізми напіврешіток та монотонність

Нехай задано дві алгебраїчні напіврешітки `(S, ⋆)` та `(T, ∘)`. Відображення `f : S → T` називається **гомоморфізмом напіврешіток**, якщо воно зберігає бінарну операцію для всіх пар елементів:

```
f(a ⋆ b) = f(a) ∘ f(b)
```

**Теорема:** Будь-який гомоморфізм напіврешіток є монотонним відображенням відносно асоційованих часткових порядків:

```
a ≤_S b  ⇒  f(a) ≤_T f(b)
```

**Доведення:**
Нехай `a ≤_S b`. За означенням породженого порядку в множині `S` це означає точну алгебраїчну рівність:

```
a ⋆ b = a
```

Застосуємо функцію `f` до обох частин цієї рівності:

```
f(a)
= f(a ⋆ b)                     [підстановка a = a ⋆ b]
= f(a) ∘ f(b)                  [за означенням алгебраїчного гомоморфізму]
```

Оскільки отримано рівність `f(a) ∘ f(b) = f(a)`, за означенням часткового порядку в множині `T` це означає:

```
f(a) ≤_T f(b)
```

Отже, збереження алгебраїчного згортку автоматично гарантує збереження структури порядку та монотонність відображення.
