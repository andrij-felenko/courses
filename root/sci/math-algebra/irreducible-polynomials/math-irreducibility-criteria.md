# 🧮 Критерії та алгоритми перевірки незвідності: від Ейзенштейна до Рабіна

З'ясування того, чи є заданий многочлен нерозкладним на простіші множники, лежить в основі побудови числових полів, доведення трансцендентності чисел, створення завадостійких кодів та криптографічних протоколів. Прямий перебір можливих дільників швидко стає нездійсненним навіть для невеликих степенів через комбінаторний вибух. У цьому математичному дослідженні детально виведено фундаментальні критерії незвідності над кільцем цілих чисел `ℤ`, полем раціональних чисел `ℚ` та скінченними полями Галуа `F_q`, включаючи лему Гаусса, критерій Шенемана — Ейзенштейна, методи функціональних перетворень, формулу кількості непривідних поліномів через обернення Мьобіуса та ефективний алгоритм Рабіна.

## 1. Лема Гаусса та поняття змісту многочлена

Нехай `ℤ[x]` позначає кільце многочленів від однієї змінної `x` із цілими коефіцієнтами, а `ℚ[x]` — кільце многочленів із раціональними коефіцієнтами. Довільний ненульовий многочлен `f(x) ∈ ℤ[x]` записується у вигляді:

```
f(x) = aₙ·xⁿ + aₙ₋₁·xⁿ⁻¹ + ... + a₁·x + a₀
```

де число `n` (найвищий показник степеня при ненульовому коефіцієнті) називається степенем многочлена `deg(f) = n`, а коефіцієнти `aₙ, aₙ₋₁, ..., a₀` є цілими числами.

### Зміст многочлена та примітивні поліноми

Змістом (лат. *contentus*) цілочисельного многочлена `f(x)`, що позначається як `cont(f)`, називається найбільший спільний дільник (НСД) усіх його коефіцієнтів:

```
cont(f) = НСД(aₙ, aₙ₋₁, ..., a₁, a₀)
```

Многочлен `f(x) ∈ ℤ[x]` називається **примітивним**, якщо його зміст дорівнює одиниці: `cont(f) = 1`. Довільний цілочисельний многочлен можна однозначно подати у вигляді добутку його змісту на примітивний многочлен `f₀(x)`:

```
f(x) = cont(f) · f₀(x),   де cont(f₀) = 1
```

### Теорема про мультиплікативність змісту (Лема Гаусса)

> **Лема Гаусса.** Добуток двох примітивних многочленів із цілими коефіцієнтами є примітивним многочленом. У загальному вигляді для довільних многочленів `f(x), g(x) ∈ ℤ[x]` виконується рівність:
> `cont(f · g) = cont(f) · cont(g)`

**Доведення.** Нехай `f(x)` та `g(x)` — два примітивні многочлени:

```
f(x) = aₙ·xⁿ + aₙ₋₁·xⁿ⁻¹ + ... + a₀
g(x) = bₘ·xᵐ + bₘ₋₁·xᵐ⁻¹ + ... + b₀
```

Припустимо від супротивного, що їхній добуток `h(x) = f(x) · g(x)` не є примітивним. Це означає, що існує деяке просте число `p`, яке ділить усі коефіцієнти многочлена `h(x)`.

Оскільки `f(x)` є примітивним, число `p` не може ділити одночасно всі коефіцієнти `aᵢ`. Нехай `aₖ` — перший коефіцієнт многочлена `f(x)` (починаючи від молодших степенів при індексі `k`), який не ділиться на `p`. Тобто `p | a₀, p | a₁, ..., p | aₖ₋₁`, але `p ∤ aₖ`.

Аналогічно, оскільки `g(x)` є примітивним, нехай `bₘ` — перший коефіцієнт многочлена `g(x)`, який не ділиться на `p`. Тобто `p | b₀, p | b₁, ..., p | bₘ₋₁`, але `p ∤ bₘ`.

Розглянемо коефіцієнт `cₖ₊ₘ` при степені `xᵏ⁺ᵐ` у добутку `h(x) = f(x) · g(x)`. За правилом множення многочленів:

```
cₖ₊ₘ = ∑ (aᵢ · bⱼ)   [де сумування ведеться за всіма парами індексів i + j = k + m]
```

Розгорнемо цю суму, виділивши ключовий доданок `aₖ · bₘ`:

```
cₖ₊ₘ = (a₀·bₖ₊ₘ + a₁·bₖ₊ₘ₋₁ + ... + aₖ₋₁·bₘ₊₁) + aₖ·bₘ + (aₖ₊₁·bₘ₋₁ + ... + aₖ₊ₘ·b₀)
```

Проаналізуємо подільність кожного доданка на просте число `p`:
1. Усі доданки лівої дужки містять коефіцієнти `aᵢ` з індексами `i < k`. За вибором індексу `k`, усі ці коефіцієнти діляться на `p`. Отже, уся ліва дужка ділиться на `p`.
2. Усі доданки правої дужки містять коефіцієнти `bⱼ` з індексами `j < m`. За вибором індексу `m`, усі ці коефіцієнти діляться на `p`. Отже, уся права дужка ділиться на `p`.
3. За нашим початковим припущенням, сам коефіцієнт `cₖ₊ₘ` ділиться на `p`, оскільки `p` ділить усі коефіцієнти добутку `h(x)`.

Запишемо рівність для виділеного доданка:

```
aₖ · bₘ = cₖ₊ₘ - ∑_{i < k} aᵢ·bₖ₊ₘ₋ᵢ - ∑_{j < m} aₖ₊ₘ₋ⱼ·bⱼ
```

Оскільки права частина цієї рівності є різницею чисел, кожне з яких ділиться на `p`, то й ліва частина `aₖ · bₘ` зобов'язана ділитися на `p`. Але `p` — просте число, тому з подільності добутку `aₖ · bₘ` випливає, що або `p | aₖ`, або `p | bₘ`. Це прямо суперечить вибору коефіцієнтів `aₖ` та `bₘ`.

Отримане протиріччя доводить, що добуток двох примітивних многочленів не може мати простого дільника серед своїх коефіцієнтів і, отже, є примітивним. Мультиплікативність для довільних многочленів випливає з винесення їхніх змістів: `f = cont(f)·f₀`, `g = cont(g)·g₀`, звідки `f·g = cont(f)·cont(g)·(f₀·g₀)`.

### Зв'язок незвідності над `ℤ` та над `ℚ`

> **Наслідок.** Якщо многочлен `f(x) ∈ ℤ[x]` із цілими коефіцієнтами є примітивним і розкладається у добуток двох многочленів менших степенів із раціональними коефіцієнтами `f(x) = G(x) · H(x)`, де `G(x), H(x) ∈ ℚ[x]`, то існують такі цілочисельні многочлени `g(x), h(x) ∈ ℤ[x]`, що:
> `f(x) = g(x) · h(x),   причому deg(g) = deg(G) та deg(h) = deg(H)`

Це означає, що перевірка незвідності цілочисельного многочлена над полем раціональних чисел `ℚ` повністю зводиться до перевірки його нерозкладності на цілочисельні множники в кільці `ℤ[x]`.

## 2. Критерій Шенемана — Ейзенштейна

Критерій Ейзенштейна надає потужну достатню умову незвідності цілочисельного многочлена через поведінку його коефіцієнтів відносно простого числа `p`.

> **Теорема (Критерій Ейзенштейна).** Нехай задано многочлен із цілими коефіцієнтами:
> `f(x) = aₙ·xⁿ + aₙ₋₁·xⁿ⁻¹ + ... + a₁·x + a₀ ∈ ℤ[x],   де aₙ ≠ 0, n ≥ 1`
> Якщо існує таке просте число `p`, для якого одночасно виконуються три умови:
> 1. Число `p` **не ділить** старший коефіцієнт: `p ∤ aₙ`;
> 2. Число `p` **ділить усі інші коефіцієнти**: `p | aᵢ` для всіх `0 ≤ i ≤ n - 1`;
> 3. Квадрат числа `p` **не ділить** вільний член: `p² ∤ a₀`;
> 
> тоді многочлен `f(x)` є непривідним над полем раціональних чисел `ℚ` (а якщо `f(x)` примітивний, то й над кільцем `ℤ`).

### Строге доведення

Припустимо від супротивного, що многочлен `f(x)` є звідним над `ℚ`. За наслідком із леми Гаусса, його можна розкласти на добуток двох многочленів менших степенів із цілими коефіцієнтами:

```
f(x) = g(x) · h(x)
```

де многочлени мають вигляд:

```
g(x) = bᵣ·xʳ + bᵣ₋₁·xʳ⁻¹ + ... + b₁·x + b₀,   bᵣ ≠ 0, r ≥ 1
h(x) = cₛ·xˢ + cₛ₋₁·xˢ⁻¹ + ... + c₁·x + c₀,   cₛ ≠ 0, s ≥ 1
```

причому сума їхніх степенів дорівнює степеню вихідного многочлена: `r + s = n`.

Розглянемо канонічний гомоморфізм редукції коефіцієнтів за модулем простого числа `p`, що зіставляє кожному цілому коефіцієнту його клас залишків у полі `ℤ_p = ℤ / pℤ`. Позначимо редуковані многочлени рискою зверху:

```
f̄(x) = ḡ(x) · h̄(x)   у кільці ℤ_p[x]
```

Застосуємо умову 2 критерію: оскільки `p | aᵢ` для всіх `0 ≤ i ≤ n - 1`, усі молодші коефіцієнти многочлена `f̄(x)` стають нулями в полі `ℤ_p`. Враховуючи умову 1 (`p ∤ aₙ`), старший коефіцієнт `āₙ ≠ 0`. Отже:

```
f̄(x) = āₙ · xⁿ   у кільці ℤ_p[x]
```

Оскільки `ℤ_p` є полем, кільце многочленів `ℤ_p[x]` є факторіальним кільцем (кільцем з однозначним розкладом на прості множники). Одночлен `āₙ · xⁿ` розкладається на незвідні множники виключно як добуток незвідних лінійних множників `x`. 

З рівності `ḡ(x) · h̄(x) = āₙ · xⁿ` випливає, що кожен із многочленів `ḡ(x)` та `h̄(x)` зобов'язаний бути одночленом відповідного степеня:

```
ḡ(x) = b̄ᵣ · xʳ   [усі молодші коефіцієнти b̄₀, b̄₁, ..., b̄ᵣ₋₁ дорівнюють 0 у ℤ_p]
h̄(x) = c̄ₛ · xˢ   [усі молодші коефіцієнти c̄₀, c̄₁, ..., c̄ₛ₋₁ дорівнюють 0 у ℤ_p]
```

Зокрема, для вільних членів маємо:

```
b̄₀ = 0 у ℤ_p   ⇒   p | b₀
c̄₀ = 0 у ℤ_p   ⇒   p | c₀
```

Тепер обчислимо вільний член вихідного цілочисельного многочлена `f(x)`. За правилом множення:

```
a₀ = b₀ · c₀
```

Оскільки `p | b₀` та `p | c₀`, ми можемо записати `b₀ = p · u` та `c₀ = p · v` для деяких цілих чисел `u` та `v`. Тоді:

```
a₀ = (p · u) · (p · v)
= p² · (u · v)      [законність: пряме підставлення b₀ та c₀]
```

Звідси випливає, що число `a₀` обов'язково ділиться на `p²`. Проте це прямо суперечить умові 3 критерію Ейзенштейна, згідно з якою `p² ∤ a₀`.

Отримане протиріччя доводить, що многочлен `f(x)` не можна розкласти на множники додатних степенів над полем `ℚ`.

## 3. Функціональні перетворення та збереження незвідності

Часто многочлен є незвідним, але безпосередньо не задовольняє умов Ейзенштейна. У таких випадках застосовують алгебраїчні перетворення, які зберігають властивість незвідності.

### Зсув аргументу (підстановка `x = y + c`)

> **Лема про інваріантність незвідності при зсуві.** Многочлен `f(x)` є непривідним над полем `F` тоді й лише тоді, коли многочлен `g(y) = f(y + c)` є непривідним над `F` для довільної фіксованої константи `c ∈ F`.

**Приклад: незвідність кругових многочленів `Φ_p(x)`.**
Розглянемо круговий многочлен ділення кола для простого числа `p`:

```
Φ_p(x) = (xᵖ - 1) / (x - 1) = xᵖ⁻¹ + xᵖ⁻² + ... + x + 1
```

Безпосередньо для `Φ_p(x)` критерій Ейзенштейна не працює, оскільки всі коефіцієнти дорівнюють 1. Виконаємо зсув змінної `x = y + 1`:

```
g(y) = Φ_p(y + 1)
= ((y + 1)ᵖ - 1) / ((y + 1) - 1)   [підстановка x = y + 1]
= ((y + 1)ᵖ - 1) / y               [спрощення знаменника]
```

Застосуємо біноміальну теорему Ньютона для розкриття виразу `(y + 1)ᵖ`:

```
(y + 1)ᵖ = yᵖ + C(p, 1)·yᵖ⁻¹ + C(p, 2)·yᵖ⁻² + ... + C(p, p-1)·y + 1
```

де біноміальні коефіцієнти мають вигляд:

```
C(p, k) = p! / (k! · (p - k)!)
```

Підставимо біном у вираз для `g(y)` та поділимо на `y`:

```
g(y) = (yᵖ + p·yᵖ⁻¹ + C(p, 2)·yᵖ⁻² + ... + p·y) / y
= yᵖ⁻¹ + p·yᵖ⁻² + C(p, 2)·yᵖ⁻³ + ... + C(p, p-2)·y + p
```

Перевіримо умови Ейзенштейна для многочлена `g(y)` відносно простого числа `p`:
1. Старший коефіцієнт при `yᵖ⁻¹` дорівнює 1, отже `p ∤ 1` (умова 1 виконана);
2. Усі проміжні коефіцієнти є біноміальними коефіцієнтами `C(p, k)` для `1 ≤ k ≤ p - 1`. Оскільки `p` — просте число, чисельник `p!` ділиться на `p`, а знаменник `k!(p-k)!` не містить множника `p`. Тому `p | C(p, k)` для всіх проміжних коефіцієнтів (умова 2 виконана);
3. Вільний член дорівнює `C(p, p-1) = p`. Він ділиться на `p`, але не ділиться на `p²` (умова 3 виконана).

За критерієм Ейзенштейна многочлен `g(y)` є непривідним над `ℚ`. Отже, і вихідний круговий многочлен `Φ_p(x)` є непривідним над `ℚ`.

### Обернений многочлен (реверс коефіцієнтів)

> **Лема про обернений многочлен.** Нехай `f(x) = aₙ·xⁿ + ... + a₀` — многочлен із `a₀ ≠ 0`. Його взаємно зворотний (реверсивний) многочлен визначається формулою:
> `f*(x) = xⁿ · f(1 / x) = a₀·xⁿ + a₁·xⁿ⁻¹ + ... + aₙ₋₁·x + aₙ`
> Тоді многочлен `f*(x)` є непривідним над полем `F` тоді й лише тоді, коли `f(x)` є непривідним над `F`.

**Доведення.** Якщо `f(x) = g(x)·h(x)` з `deg(g) = r` та `deg(h) = s` (`r + s = n`), то підставивши `1/x` та помноживши на `xⁿ = xʳ · xˢ`, отримуємо `f*(x) = g*(x) · h*(x)`. Оскільки `a₀ ≠ 0`, маємо `g(0) ≠ 0` та `h(0) ≠ 0`, тому `deg(g*) = r` та `deg(h*) = s`. Це забезпечує взаємну однозначність факторизації.

Цей прийом дозволяє застосовувати критерій Ейзенштейна «з іншого кінця», коли умови виконуються для коефіцієнтів відносно старшого члена `aₙ` замість вільного `a₀`.

## 4. Редукція коефіцієнтів над скінченними полями `ℤ_p`

Ще одним ефективним методом перевірки є редукція за простим модулем `p`.

> **Теорема (Редукційний критерій).** Нехай `f(x) = aₙ·xⁿ + ... + a₀ ∈ ℤ[x]` — цілочисельний многочлен степеня `n`. Нехай `p` — просте число, яке не ділить старший коефіцієнт: `p ∤ aₙ`.
> Якщо редукований многочлен `f̄(x) ∈ ℤ_p[x]` є непривідним над полем `ℤ_p`, то початковий многочлен `f(x)` є непривідним над полем раціональних чисел `ℚ`.

**Доведення.** Припустимо від супротивного, що `f(x)` розкладається над `ℚ`: `f(x) = g(x) · h(x)`, де `g, h ∈ ℤ[x]` і `deg(g) ≥ 1, deg(h) ≥ 1`. Тоді `deg(f) = deg(g) + deg(h) = n`.

При редукції за модулем `p` старший коефіцієнт `āₙ ≠ 0`, тому `deg(f̄) = n`. Оскільки `f̄ = ḡ · h̄`, маємо:

```
n = deg(f̄) = deg(ḡ) + deg(h̄) ≤ deg(g) + deg(h) = n
```

Звідси `deg(ḡ) = deg(g) ≥ 1` та `deg(h̄) = deg(h) ≥ 1`. Ми отримали нетривіальний розклад многочлена `f̄(x)` на множники менших степенів над полем `ℤ_p`, що суперечить умові його непривідності над `ℤ_p`.

**Приклад застосування:**
Дослідимо многочлен `f(x) = x⁴ + 10x + 1` над `ℚ`. Виберемо модуль `p = 3`:
- Старший коефіцієнт 1 не ділиться на 3.
- Редукований многочлен над `F₃`: `f̄(x) = x⁴ + x + 1`.
- Перевірка на корені у `F₃`:
  `f̄(0) = 1 ≠ 0`, `f̄(1) = 1 + 1 + 1 = 0` (над `F₃` це 0! Значить `x = 1` є коренем над `F₃`).
  Модуль `p = 3` дав звідний многочлен, тому беремо наступний простий модуль `p = 2`.
- Над `F₂`: `f̄(x) = x⁴ + 0·x + 1 = x⁴ + 1 = (x + 1)⁴` (звідний).
- Спробуємо `p = 5`: `f̄(x) = x⁴ + 1`. Над `F₅` перевіримо:
  `f̄(0)=1`, `f̄(1)=2`, `f̄(2)=16+1=17≡2`, `f̄(3)=81+1=82≡2`, `f̄(4)=256+1=257≡2`. Коренів немає.
  Квадратичні незвідні многочлени над `F₅`: `x² + 2`, `x² + 3`, `x² + x + 1`, `x² + x + 2`, тощо.
  Ділення `x⁴ + 1 = (x² + 2)(x² + 3) - 5 ≡ (x² + 2)(x² + 3) (mod 5)` показує розклад.
- Візьмемо `p = 7`: `f̄(x) = x⁴ + 3x + 1` над `F₇`. Він не має коренів і не ділиться на жоден незвідний квадратичний многочлен над `F₇`. Отже, `f(x)` непривідний над `ℚ`.

## 5. Многочлени над скінченними полями `F_q` та формула Гаусса

Розглянемо скінченне поле Галуа `F_q`, де `q = pᵏ` — степінь простого числа.

### Фундаментальна теорема про розклад `x^(qⁿ) - x`

> **Теорема.** Многочлен `x^(qⁿ) - x` над полем `F_q` розкладається на добуток усіх нормованих непривідних многочленів над `F_q`, степені `d` яких ділять `n`:
> `x^(qⁿ) - x = ∏_{d | n} ∏_{p(x) ∈ I_q(d)} p(x)`
> де `I_q(d)` — множина всіх нормованих непривідних многочленів степеня `d` над `F_q`.

**Обґрунтування.** Елементи поля розширення `F_(qⁿ)` є коренями рівняння `x^(qⁿ) - x = 0`. Кожен елемент `α ∈ F_(qⁿ)` має над полем `F_q` свій мінімальний многочлен `p_α(x)`, який є непривідним, і степінь якого `d = deg(p_α)` є дільником степеня розширення: `d | n`. Оскільки всі корені `x^(qⁿ) - x` прості (формальна похідна дорівнює `(x^(qⁿ) - x)' = -1 ≠ 0`, тому спільних дільників із похідною немає), кожен непривідний многочлен входить у розклад рівно один раз.

### Виведення формули кількості непривідних многочленів (Формула Гаусса)

Порівняємо степені обох частин розкладу `x^(qⁿ) - x`. Степінь лівої частини дорівнює `qⁿ`. Степінь правої частини дорівнює сумі степенів усіх непривідних множників:

```
qⁿ = ∑_{d | n} d · N_q(d)
```

де `N_q(d)` позначає кількість нормованих непривідних многочленів степеня `d` над полем `F_q`.

Введемо функцію `g(n) = n · N_q(n)` та `f(n) = qⁿ`. Рівність набуває вигляду суми за дільниками:

```
f(n) = ∑_{d | n} g(d)
```

Застосуємо класичну формулу обернення Мьобіуса:

```
g(n) = ∑_{d | n} μ(d) · f(n / d)
```

де `μ(d)` — функція Мьобіуса, яка набуває значень:
- `μ(1) = 1`;
- `μ(d) = (-1)ʳ`, якщо `d` є добутком `r` різних простих чисел;
- `μ(d) = 0`, якщо `d` ділиться на квадрат будь-якого простого числа.

Підставивши вирази для `g(n)` та `f(n / d)`, отримуємо точну формулу Гаусса:

```
n · N_q(n) = ∑_{d | n} μ(d) · qⁿᐟᵈ
```

Поділивши на `n`, маємо аналітичний вираз для кількості непривідних многочленів:

```
N_q(n) = (1 / n) · ∑_{d | n} μ(d) · qⁿᐟᵈ
```

### Асимптотична оцінка та існування

Оцінимо кількість непривідних многочленів знизу. Виділимо головний доданок при `d = 1` (де `μ(1) = 1`):

```
N_q(n) = (1 / n) · (qⁿ + ∑_{d | n, d > 1} μ(d) · qⁿᐟᵈ)
```

Оскільки найбільший власний дільник числа `n` не перевищує `n/2`, сума всіх інших доданків за модулем обмежена величиною:

```
|∑_{d | n, d > 1} μ(d) · qⁿᐟᵈ| ≤ ∑_{k=1}^{⌊n/2⌋} qᵏ < q^(n/2 + 1) / (q - 1) ≤ q^(n/2 + 1)
```

Отже:

```
N_q(n) ≥ (1 / n) · (qⁿ - q^(n/2 + 1)) > 0   [для всіх n ≥ 1 та q ≥ 2]
```

> **Висновок.** Для будь-якого скінченного поля `F_q` та будь-якого натурального степеня `n ≥ 1` завжди існує хоча б один (а практично — багато) нормований непривідний многочлен степеня `n`.

**Конкретні числові розрахунки для `F₂`:**
1. Для `n = 3` над `F₂` (показник `q = 2`): дільники числа 3 це `d = 1` та `d = 3`.
   ```
   N₂(3) = (1 / 3) · (μ(1)·2³ + μ(3)·2¹)          [підстановка дільників 1 і 3 у формулу Гаусса]
   = (1 / 3) · (1·8 + (-1)·2)                     [обчислення значень μ(1)=1 та μ(3)=-1]
   = (1 / 3) · (8 - 2)                            [арифметичне спрощення виразу]
   = 6 / 3                                        [ділення на степінь n=3]
   = 2                                            [кількість незвідних кубічних поліномів]
   ```
   Два непривідні кубічні многочлени над `F₂`: це `x³ + x + 1` та `x³ + x² + 1`.

2. Для `n = 4` над `F₂`: дільники числа 4 це 1, 2, 4.
   `μ(1) = 1`, `μ(2) = -1`, `μ(4) = 0`.
   ```
   N₂(4) = (1 / 4) · (μ(1)·2⁴ + μ(2)·2² + μ(4)·2¹) [підстановка дільників 1, 2, 4 у формулу]
   = (1 / 4) · (1·16 - 1·4 + 0)                    [значення μ(1)=1, μ(2)=-1, μ(4)=0]
   = (1 / 4) · 12                                  [арифметичне спрощення різниці]
   = 3                                             [кількість незвідних поліномів 4-го степеня]
   ```
   Три непривідні многочлени 4-го степеня над `F₂`: це `x⁴ + x + 1`, `x⁴ + x³ + 1` та `x⁴ + x³ + x² + x + 1`.

3. Для `n = 8` над `F₂` (степінь для криптографічного стандарту AES): дільники числа 8 це 1, 2, 4, 8.
   Значення функції Мьобіуса: `μ(1) = 1`, `μ(2) = -1`, `μ(4) = 0`, `μ(8) = 0`.
   ```
   N₂(8) = (1 / 8) · (μ(1)·2⁸ + μ(2)·2⁴ + μ(4)·2² + μ(8)·2¹) [підстановка дільників 1, 2, 4, 8]
   = (1 / 8) · (1·256 - 1·16 + 0 + 0)                         [значення μ(1)=1, μ(2)=-1, μ(4)=μ(8)=0]
   = (1 / 8) · 240                                            [спрощення різниці 256 - 16]
   = 30                                                       [кількість незвідних поліномів 8-го степеня]
   ```
   Існує рівно 30 непривідних многочленів 8-го степеня над `F₂`, один із яких (`x⁸ + x⁴ + x³ + x + 1`) стандартизовано в AES Rijndael.

## 6. Алгоритм Рабіна для детермінованої перевірки незвідності

У 1980 році Майкл Рабін (Michael O. Rabin) запропонував швидкий детермінований алгоритм перевірки незвідності многочлена `f(x) ∈ F_q[x]` степеня `n`.

> **Критерій Рабіна.** Многочлен `f(x) ∈ F_q[x]` степеня `n` є непривідним над полем `F_q` тоді й лише тоді, коли виконуються дві умови:
> 1. `f(x)` ділить многочлен `x^(qⁿ) - x` у кільці `F_q[x]`:
>    `x^(qⁿ) ≡ x (mod f(x))`
> 2. Для кожного простого дільника `pᵢ` числа `n` найбільший спільний дільник многочленів дорівнює одиниці:
>    `НСД(x^(qⁿᐟᵖⁱ) - x, f(x)) = 1`

### Доведення коректності критерію Рабіна

**Необхідність (⇒).** Нехай `f(x)` непривідний степеня `n`. Тоді за теоремою про розклад `x^(qⁿ) - x`, оскільки `n | n`, `f(x)` входить у добуток, тобто ділить `x^(qⁿ) - x` (умова 1 виконана).
Далі, для будь-якого простого дільника `pᵢ | n` частка `n / pᵢ < n` є строго меншою за `n`. Оскільки `f(x)` непривідний степеня `n`, він не може ділити жоден многочлен `x^(qⁿᐟᵖⁱ) - x`, який розкладається на непривідні степенів `d | (n / pᵢ)`. Оскільки `f(x)` не має дільників меншого степеня, його НСД із цим многочленом дорівнює 1 (умова 2 виконана).

**Достатність (⇐).** Припустимо, що обидві умови виконані, але `f(x)` є звідним. Нехай `g(x)` — його незвідний дільник деякого степеня `d = deg(g) < n`.
З умови 1 `f(x) | (x^(qⁿ) - x)`, отже й `g(x) | (x^(qⁿ) - x)`. За властивістю розкладу це можливо тоді й лише тоді, коли `d | n`.
Оскільки `d < n` та `d | n`, число `d` обов'язково ділить хоча б одне з чисел `n / pᵢ`, де `pᵢ` — деякий простий дільник `n`.
Але якщо `d | (n / pᵢ)`, то незвідний многочлен `g(x)` зобов'язаний ділити `x^(qⁿᐟᵖⁱ) - x`.
Тоді `g(x)` є спільним дільником для `f(x)` та `x^(qⁿᐟᵖⁱ) - x`, що означає:

```
deg(НСД(x^(qⁿᐟᵖⁱ) - x, f(x))) ≥ deg(g) = d ≥ 1
```

Це прямо суперечить умові 2, згідно з якою цей НСД має дорівнювати 1. Отже, многочлен `f(x)` не має дільників меншого степеня і є непривідним.

### Покроковий приклад виконання тесту Рабіна

Перевіримо незвідність многочлена `f(x) = x³ + x + 1` над полем `F₂`:
- Параметри: `q = 2`, степінь `n = 3`.
- Прості дільники числа `n = 3`: єдиний простий дільник `p₁ = 3`, тоді `n / p₁ = 1`.

**Крок 1: Перевірка умови 1 (`x^(2³) mod f(x)`).**
Обчислимо `x⁸ mod (x³ + x + 1)` над `F₂`:
```
x³ ≡ x + 1 (mod f)
x⁶ ≡ (x + 1)² ≡ x² + 1 (mod f)       [оскільки (a+b)² = a² + b² у характеристиці 2]
x⁸ = x⁶ · x² ≡ (x² + 1) · x²
= x⁴ + x²                            [розкриття дужок]
= x · (x³) + x²
≡ x · (x + 1) + x²                   [підстановка x³ ≡ x + 1]
= x² + x + x²
= x                                  [оскільки x² + x² = 0 над F₂]
```
Отримали `x⁸ ≡ x (mod f(x))`. Першу умову виконано.

**Крок 2: Перевірка умови 2 для `p₁ = 3` (`n / p₁ = 1`).**
Обчислимо `x^(2¹) - x = x² - x = x² + x` над `F₂`.
Знайдемо найбільший спільний дільник через алгоритм Евкліда:
```
f(x) = x³ + x + 1
= (x + 1) · (x² + x) + 1             [ділення з остачею над F₂]
```
Остача дорівнює 1, отже:
```
НСД(x² + x, x³ + x + 1) = 1
```
Другу умову виконано. 

**Висновок:** Многочлен `x³ + x + 1` гарантовано є непривідним над полем `F₂`.

### Аналіз алгоритмічної складності

Алгоритм Рабіна виконує:
1. Бінарне піднесення до степеня `x^(qⁿ) mod f(x)`: потребує `O(n · log q)` множень многочленів степеня менше `n`.
2. Обчислення найбільшого спільного дільника `k` разів (де `k` — кількість різних простих дільників числа `n`). Кожен виклик алгоритму Евкліда потребує `O(n²)` операцій у полі `F_q`.

Загальна бітова складність алгоритму становить `O(n² · log n · log q + k · n² · log q)`, що робить тест Рабіна надзвичайно швидким і придатним для роботи з многочленами степенів у сотні та тисячі в сучасній криптографії.
