# ⚙️ Алгоритм факторизації та пошук непривідних многочленів над скінченними полями

Факторизація многочленів над скінченними полями `F_p` є фундаментом сучасної криптографії на еліптичних кривих, побудови апаратних генераторів псевдовипадкових послідовностей на регістрах зсуву з лінійним зворотним зв'язком (LFSR), завадостійкого кодування в телекомунікаціях (коди Ріда — Соломона, БЧХ) та обчислювальних ядер систем комп'ютерної алгебри. Без швидкого та надійного алгоритму розкладання на непривідні множники неможливо знайти примітивні многочлени для розширення полів Галуа `GF(pⁿ)` або виконати розкодування спотвореного пакета даних.

У цій практичній роботі детально розібрано повний трифазний конвеєр факторизації, математичне обґрунтування кожного етапу, матричний підхід Берлекампа, імовірнісний поділ Кантора — Цассенхауза, алгоритм Юна для безквадратного розкладу, покрокове простеження стану та повну реалізацію мовами C та C++ з використанням сучасних ідіом.

## 1. Архітектура повного конвеєра факторизації

Прямий перебір можливих дільників для многочлена степеня `n` над полем із `p` елементів вимагає перевірки порядку `pⁿ/²` поліноміальних комбінацій. Для криптографічних застосувань (де `n ≥ 128` або `p` є великим простим числом) такий комбінаторний перебір неможливо реалізувати на жодному обчислювальному кластері.

Сучасний підхід комп'ютерної алгебри розбиває складну загальну задачу розкладу на три послідовні алгоритмічні фази з поліноміальною складністю:

```
                  Довільний вхідний многочлен f(x) ∈ F_p[x]
                                    │
                                    ▼
      ┌───────────────────────────────────────────────────────────┐
      │  Фаза 1: Square-Free Factorization (Вилучення квадратів)  │
      │  Перетворює f(x) на добуток вільних від квадратів блоків  │
      │  f(x) = f₁¹(x) · f₂²(x) · ... · fₖᵏ(x), де НСД(fᵢ, f'ᵢ) = 1│
      └───────────────────────────────────────────────────────────┘
                                    │
                                    ▼
      ┌───────────────────────────────────────────────────────────┐
      │  Фаза 2: Distinct-Degree Factorization (DDF)              │
      │  Розбиває кожен вільний від квадратів блок на добутки     │
      │  незвідних множників однакового степеня:                  │
      │  g_d(x) = ∏ pᵢ(x),  де deg(pᵢ) = d, через gcd(x^(pᵈ)-x, f)│
      └───────────────────────────────────────────────────────────┘
                                    │
                                    ▼
      ┌───────────────────────────────────────────────────────────┐
      │  Фаза 3: Equal-Degree Factorization (EDF)                 │
      │  Розщеплює многочлен g_d(x) на окремі незвідні множники   │
      │  степеня d (метод Кантора — Цассенхауза або Берлекампа)   │
      └───────────────────────────────────────────────────────────┘
                                    │
                                    ▼
          Повний розклад f(x) = c · p₁ᵉ¹(x) · p₂ᵉ²(x) · ... · pₘᵉᵐ(x)
```

Кожна фаза звужує клас многочленів, усуваючи конкретні структурні перешкоди (кратні корені, різноманітність степенів дільників).

## 2. Фаза 1: Відокремлення квадратів та алгоритм Юна

Многочлен `f(x)` називається вільним від квадратів (англ. *square-free*), якщо у його канонічному розкладі на незвідні множники жоден поліном `pᵢ(x)` не зустрічається у степені `eᵢ ≥ 2`.

Головним інструментом виявлення кратних множників є формальна алгебраїчна похідна. Якщо многочлен має кратний множник `f(x) = p(x)² · h(x)`, то за правилом диференціювання добутку:

```
f'(x) = 2 · p(x) · p'(x) · h(x) + p(x)² · h'(x)
= p(x) · [2 · p'(x) · h(x) + p(x) · h'(x)]
```

Спільний множник `p(x)` обов'язково ділить і сам многочлен `f(x)`, і його похідну `f'(x)`. Отже, найбільший спільний дільник `НСД(f(x), f'(x))` виділяє всі кратні множники.

### Специфіка скінченної характеристики

У полях з характеристикою `p > 0` диференціювання має критичну особливість: похідна одночлена, степінь якого кратний `p`, перетворюється на нуль:

```
(xᵏᵖ)' = k · p · xᵏᵖ⁻¹ ≡ 0 (mod p)
```

Через це можливі три випадки при аналізі `g(x) = НСД(f(x), f'(x))`:
1. `g(x) = 1`: многочлен `f(x)` вже є вільним від квадратів, додаткова обробка не потрібна.
2. `g(x) ≠ 1` та `f'(x) ≠ 0`: многочлен ділиться на `g(x)`, виділяється безквадратна частина `f(x) / g(x)` і рекурсивно факторизується.
3. `f'(x) = 0` тотожно: це означає, що всі степені ненульових коефіцієнтів діляться на `p`, тобто `f(x) = h(xᵖ)`. За малою теоремою Ферма над полем `F_p` маємо `aᵖ = a`, тому `f(x) = (h(x))ᵖ`. Алгоритм вилучає корінь `p`-го степеня, замінюючи індекси `c[i · p] ↦ c[i]`, і рекурсивно факторизує поліном `h(x)`.

### Алгоритм Юна (Yun's Algorithm)

Для одночасного обчислення всіх компонентів `f₁(x), f₂(x), ..., fₖ(x)` розкладу `f(x) = f₁¹ · f₂² · ... · fₖᵏ` Давід Юн у 1976 році запропонував елегантний ітераційний процес:
1. Нехай `a₀ = f(x)` та `b₀ = f'(x)`. Обчислюється `c₀ = НСД(a₀, b₀)`.
2. Задаємо `w₀ = a₀ / c₀` (це добуток усіх різних незвідних дільників `f₁ · f₂ · ... · fₖ`) та `y₀ = b₀ / c₀`.
3. На кожному кроці `i = 1, 2, ...`:
   - Обчислюємо `zᵢ = y_{i-1} - w'_{i-1}`.
   - Визначаємо `fᵢ = НСД(w_{i-1}, zᵢ)`.
   - Оновлюємо `wᵢ = w_{i-1} / fᵢ` та `yᵢ = zᵢ / fᵢ`.
   - Процес зупиняється, коли `wᵢ = 1`.

Алгоритм Юна уникає повторних обчислень похідних від великих многочленів і є стандартом для комп'ютерної алгебри.

## 3. Фаза 2: Розділення за різними степенями (Distinct-Degree Factorization)

Нехай многочлен `f(x)` вже вільний від квадратів. На цьому кроці ми групуємо всі незвідні дільники за їхніми степенями.

Теоретичною опорою виступає теорема про розклад `x^(pᵈ) - x`: цей многочлен над полем `F_p` ділиться на всі незвідні многочлени, степені яких ділять `d`. 

Якщо обчислити найбільший спільний дільник `НСД(x^(pᵈ) - x, f(x))`, то отриманий результат міститиме всі незвідні дільники многочлена `f(x)`, чиї степені ділять `d`. Оскільки на попередніх ітераціях для `1, 2, ..., d - 1` дільники менших степенів уже були знайдені й поділені у вихідному многочлені, поточний НСД міститиме рівно добуток усіх незвідних дільників степеня рівно `d`.

Покроковий процес:
1. Задаємо початкове значення `h₀(x) = x`.
2. Для кожного `d = 1, 2, ..., ⌊deg(f) / 2⌋`:
   - Обчислюємо `h_d(x) = (h_{d-1}(x))ᵖ mod f(x)` за допомогою швидкого модульного бінарного піднесення до степеня.
   - Знаходимо `g_d(x) = НСД(h_d(x) - x, f(x))`.
   - Якщо `deg(g_d) > 0`, записуємо `g_d(x)` як блок степеня `d` і оновлюємо `f(x) ← f(x) / g_d(x)`.
3. Якщо наприкінці `deg(f) > 0`, то залишок `f(x)` сам є незвідним многочленом степеня `deg(f)`.

## 4. Фаза 3: Розділення рівностепеневих множників (Equal-Degree Factorization)

Якщо блок `g(x)` степеня `m = k · d` містить `k > 1` різних незвідних множників однакового степеня `d`, необхідно їх розщепити на індивідуальні поліноми.

### Алгоритм Кантора — Цассенхауза для `p = 2`

Над полем двох елементів `F₂` мультиплікативна група розширення `GF(2ᵈ)` є циклічною порядку `2ᵈ - 1`. За китайською теоремою про залишки фактор-кільце розкладається у прямий добуток полів:

```
F₂[x] / (g(x)) ≅ GF(2ᵈ) × GF(2ᵈ) × ... × GF(2ᵈ)   [k копій полів]
```

Для випадкового многочлена `a(x)` степеня `< m` будується поліноміальний слід (англ. *trace*):

```
T(x) = a(x) + a(x)² + a(x)⁴ + ... + a(x)^(2^(d-1)) mod g(x)
```

Оператор сліду проектує кожен незвідний множник у базове поле `F₂`, тобто для кожного незвідного множника `pᵢ(x)` значення `T(x) mod pᵢ(x)` дорівнює або 0, або 1 з імовірністю близько 1/2. 

Обчислення `НСД(T(x), g(x))` виділяє добуток тих множників `pᵢ(x)`, на яких слід обнулився (`T(x) ≡ 0 mod pᵢ`). Імовірність того, що випадковий многочлен `a(x)` розділить множники нетривіально (тобто не дасть одночасно всі 0 або всі 1), дорівнює `1 - (1/2)^k - (1/2)^k = 1 - 2^(1-k)`. Для `k = 2` множників це дає успіх у 50% спроб, що в середньому вимагає всього 2 випадкові спроби.

### Алгоритм Кантора — Цассенхауза для непарних `p > 2`

Для непарної характеристики `p` мультиплікативна група `GF(pᵈ)*` має парний порядок `pᵈ - 1`. Половина ненульових елементів є квадратичними лишками, а інша половина — нелишками. Піднесення до степеня `(pᵈ - 1) / 2` дає символ Лежандра:

```
a(x)^((pᵈ - 1) / 2) ≡ 1 (mod pᵢ(x))   або   a(x)^((pᵈ - 1) / 2) ≡ -1 (mod pᵢ(x))
```

Тому обчислення `НСД(a(x)^((pᵈ - 1) / 2) - 1, g(x))` відщеплює множники, для яких випадковий поліном виявився квадратичним лишком.

## 5. Матричний метод Берлекампа

Для задач, де потрібен строго детермінований розв'язок без генератора випадкових чисел, застосовується класичний метод Елвіна Берлекампа (1967).

Берлекамп розглянув підалгебру многочленів `v(x) ∈ F_p[x] / (f(x))`, що задовольняють рівняння Фробеніуса:

```
v(x)ᵖ ≡ v(x) (mod f(x))
```

За китайською теоремою про залишки розв'язками цього рівняння є такі многочлени `v(x)`, які на кожному незвідному множнику `pᵢ(x)` конгруентні деякій константі `cᵢ ∈ F_p`. Якщо многочлен `f(x)` має `k` незвідних множників, простір розв'язків утворює векторний простір над `F_p` розмірності рівно `k`.

### Побудова матриці Берлекампа `Q`

Для знаходження розв'язків будується квадратна матриця `Q` розміру `n × n` (де `n = deg(f)`):
- Для кожного степеня `i = 0, 1, ..., n - 1` обчислюється залишок:
  `x^(i·p) mod f(x) = q_{i, n-1}·xⁿ⁻¹ + ... + q_{i, 1}·x + q_{i, 0}`.
- Коефіцієнти цього залишку утворюють `i`-й рядок матриці `Q`.

Рівняння `v(x)ᵖ ≡ v(x) (mod f(x))` у векторному вигляді перетворюється на однорідну систему лінійних рівнянь:

```
v · Q = v   ⟺   v · (Q - I) = 0
```

де `I` — одинична матриця розміру `n × n`.

Знайшовши базис ядра матриці `(Q - I)` за допомогою звичайного методу Гауса, ми отримуємо:
1. Кількість базисних векторів дорівнює точній кількості `k` незвідних множників многочлена `f(x)` (якщо `dim = 1`, многочлен є непривідним).
2. Для будь-якого небазисного розв'язку `v(x)` (відмінного від константи) обчислення:
   `НСД(v(x) - c, f(x))` для `c ∈ F_p` дає нетривіальні дільники `f(x)`.

## 6. Практичні інженерні застосування

### 1. Генератори псевдовипадкових послідовностей LFSR та алгоритм Берлекампа — Мессі
Регістр зсуву з лінійним зворотним зв'язком (LFSR) довжини `n` задається характеристичним многочленом `P(x) = cₙ·xⁿ + cₙ₋₁·xⁿ⁻¹ + ... + c₁·x + 1`. Якщо многочлен `P(x)` є не лише непривідним, а й **примітивним** (його корінь `α` породжує всю мультиплікативну групу `GF(2ⁿ)*`), то згенерована послідовність бітів має максимальний можливий період `2ⁿ - 1` без повторів (M-послідовність). Такі генератори використовуються в GPS, Wi-Fi скремблерах (802.11a/g/n) та потокових шифрах (A5/1 у GSM).

Зворотна задача — знаходження мінімального многочлена LFSR за відомим фрагментом вихідної бітової послідовності довжини `2n` — розв'язується знаменитим алгоритмом Берлекампа — Мессі (James Massey, 1969). Цей алгоритм є фундаментальним для декодування кодів БЧХ та Ріда — Соломона, оскільки він відновлює многочлен локаторів помилок із синдромних рівнянь за час `O(n²)`. Непривідність та взаємна простота знайдених многочленів гарантують однозначність визначення позицій спотворених бітів у каналі зв'язку.

### 2. Арифметика стандарту шифрування AES Rijndael
У стандарті симетричного шифрування AES кожен байт розглядається як елемент поля `GF(2⁸) = F₂[x] / (x⁸ + x⁴ + x³ + x + 1)`. Операція заміни байта (SubBytes) вимагає знаходження мультиплікативного оберненого елемента `a(x)⁻¹ mod m(x)` через розширений алгоритм Евкліда. Без гарантованої незвідності многочлена `m(x)` для деяких ненульових байтів обернений елемент не існував би, що унеможливило б дешифрування.

### 3. Завадостійкі коди Ріда — Соломона
Кодер Ріда — Соломона `RS(n, k)` будує кодові слова як значення полінома повідомлення над полем `GF(2ᵐ)`. Породжувальний многочлен коду `g(x) = (x - α)(x - α²) ... (x - α²ᵗ)` обчислюється множенням лінійних біномів над розширенням поля, побудованим за допомогою непривідного многочлена степеня `m`. Це забезпечує виправлення до `t` помилок у зчитуванні QR-кодів, супутникових знімків та SSD-накопичувачів.

## 7. Покроковий числовий приклад розкладу над `F₂`

Розгляньмо детально всі кроки факторизації для многочлена сьомого степеня над полем двох елементів:

```
f(x) = x⁷ + x⁶ + x⁵ + x⁴ + x³ + x² + 1 ∈ F₂[x]
```

### Крок 1: Перевірка на наявність квадратів
Обчислимо формальну похідну над `F₂`:

```
f'(x) = (x⁷ + x⁶ + x⁵ + x⁴ + x³ + x² + 1)'
= 7·x⁶ + 6·x⁵ + 5·x⁴ + 4·x³ + 3·x² + 2·x
= x⁶ + 0·x⁵ + x⁴ + 0·x³ + x² + 0·x     [оскільки парні коефіцієнти стають 0 над F₂]
= x⁶ + x⁴ + x²
```

Знайдемо найбільший спільний дільник через алгоритм Евкліда:
`НСД(f(x), x⁶ + x⁴ + x²) = 1`. Многочлен вільний від квадратів.

### Крок 2: Distinct-Degree факторизація
1. **Степінь d = 1 (пошук лінійних множників / коренів):**
   Обчислюємо `x² mod f(x) = x²`.
   `НСД(x² - x, f(x)) = НСД(x² + x, f(x)) = 1`.
   Лінійних множників немає (значення `f(0) = 1` та `f(1) = 1 + 1 + 1 + 1 + 1 + 1 + 1 = 1 ≠ 0`).

2. **Степінь d = 2 (пошук квадратичних незвідних множників):**
   Обчислюємо `x⁴ mod f(x) = x⁴`.
   `НСД(x⁴ - x, f(x)) = НСД(x⁴ + x, f(x)) = 1`.
   Квадратичних дільників (єдиного незвідного квадратичного полінома `x² + x + 1`) немає.

3. **Степінь d = 3 (пошук кубічних незвідних множників):**
   Обчислюємо `x⁸ mod f(x)`:
   Поділимо `x⁸` на `f(x)` з остачею:
   `x⁸ = x · f(x) + (x⁷ + x⁶ + x⁵ + x⁴ + x³ + x² + x)`.
   Остача: `(x⁷ + x⁶ + x⁵ + x⁴ + x³ + x² + x) - f(x) = x + 1`.
   Отже, `x⁸ ≡ x + 1 (mod f(x))`.
   Тоді `x⁸ - x ≡ (x + 1) + x = 1` (над `F₂`).
   Перевіримо ділення на кубічні незвідні кандидати:
   Єдиними незвідними кубічними поліномами над `F₂` є `p₁(x) = x³ + x + 1` та `p₂(x) = x³ + x² + 1`.
   Виконаємо пряме ділення стовпчиком `f(x)` на `x³ + x + 1`:
   ```
   (x⁷ + x⁶ + x⁵ + x⁴ + x³ + x² + 1) : (x³ + x + 1) = x⁴ + x³ + 1
   ```
   Ділення пройшло без остачі. Ми виділили кубічний незвідний множник `g₃(x) = x³ + x + 1`.

4. **Залишковий многочлен:**
   Частка дорівнює `q(x) = x⁴ + x³ + 1`. Її степінь дорівнює 4. Оскільки ми вже перевірили відсутність дільників степенів 1 і 2, а для степеня 4 можливі дільники могли б мати степені лише 1 або 2, залишковий многочлен `x⁴ + x³ + 1` гарантовано є непривідним.

**Остаточний канонічний розклад:**

```
f(x) = (x³ + x + 1) · (x⁴ + x³ + 1)
```

## 8. Порівняльний аналіз підходів: Кантор — Цассенхауз проти Берлекампа

Вибір алгоритму факторизації у практичних системах комп'ютерної алгебри (SageMath, PARI/GP, NTL, FLINT) визначається характеристикою поля та степенем многочлена:

| Критерій | Алгоритм Берлекампа (1967) | Алгоритм Кантора — Цассенхауза (1981) |
| :--- | :--- | :--- |
| **Тип алгоритму** | Детермінований | Імовірнісний (Лас-Вегас) |
| **Оптимальні характеристики** | Малі прості (`p = 2, 3, 5`) | Будь-які, особливо великі `p > 10⁹` |
| **Складність за часом** | `O(n³ + p · n²)` | `O(n² · d · log p)` |
| **Витрати оперативної пам'яті**| `O(n²)` (матриця `Q` розміру `n × n`)| `O(n)` (кілька робочих поліномів) |
| **Потреба у генераторі випадковості**| Не потрібен (чиста лінійна алгебра) | Потрібен якісний генератор `PRNG` |

Для вбудованих систем на мікроконтролерах із суворим обмеженням пам'яті (наприклад, криптографічні смарт-карти або чіпи безпеки TPM) алгоритм Кантора — Цассенхауза є переважним завдяки мінімальному споживанню RAM: для степеня `n = 1000` матриця Берлекампа потребує мегабайт пам'яті, тоді як Кантор — Цассенхауз оперує кількома кілобайтами.

## 9. Інженерний чеклист для розробника криптографічних примітивів

1. **Парність кількості одиниць у двійкових поліномах**: якщо многочлен `f(x) ∈ F₂[x]` має парну кількість ненульових коефіцієнтів (наприклад, `x⁴ + x² + x + 1`), то `f(1) = 0`, що означає, що він гарантовано ділиться на `x + 1`. Непривідні многочлени степеня `n ≥ 2` над `F₂` завжди мають непарну кількість членів.
2. **Вибір розріджених поліномів (триноми та пентаноми)**: у криптографії та апаратній реалізації завжди намагаються обирати непривідні многочлени з мінімальною кількістю доданків — триноми `xⁿ + xᵏ + 1` або пентаноми `xⁿ + xᵃ + xᵇ + xᶜ + 1`. Це мінімізує кількість вентилів XOR та затримку поширення сигналу в комбінаційній логіці ASIC/FPGA.
3. **Уніфікація порядку бітів (Endianness)**: у телекомунікаційних специфікаціях многочлени часто записують у шістнадцятковому вигляді. Слід розрізняти прямий порядок бітів (старший степінь `xⁿ` у MSB) та дзеркальний (старший степінь у LSB), прийнятий у протоколах Ethernet CRC32 (поліном `0xEDB88320` для віддзеркаленого представлення `x³² + x²⁶ + x²³ + x²² + x¹⁶ + x¹² + x¹¹ + x¹⁰ + x⁸ + x⁷ + x⁵ + x⁴ + x² + x + 1`). Сучасні процесори x86 (SSE4.2) містять апаратну інструкцію `CRC32`, яка обчислює контрольні суми зі швидкістю понад 10 ГБ/с безпосередньо в апаратурі.
4. **Захист від атак сторонніми каналами (Side-Channel Attacks)**: під час обчислення мультиплікативного оберненого елемента в полі `GF(2⁸)` для блокового шифру AES алгоритм Евкліда має змінний час виконання залежно від вхідного байта, що створює витік інформації через таймінг. У промислових криптографічних бібліотеках (OpenSSL, BoringSSL) замість алгоритму Евкліда застосовують піднесення до степеня за малою теоремою Ферма `a⁻¹ = a^(2⁸ - 2) = a²⁵⁴` за допомогою фіксованого ланцюжка множень Іто — Цудзіі з постійним часом виконання (constant-time execution).

## 10. Деталі реалізації арифметики: C проти C++

Порівняння архітектурних рішень мовами C та C++ у реалізації поліноміальної алгебри:
- **Управління пам'яттю**: версія на мові C використовує статичний масив фіксованого розміру `MAX_DEG` усередині структури, що усуває накладні витрати на динамічне виділення пам'яті (`malloc`/`free`) на мікроконтролерах. Версія на C++ використовує динамічний вектор `std::vector<int>` з автоматичним керуванням ресурсами (RAII), що дозволяє працювати з многочленами довільно високих степенів без ризику переповнення буфера.
- **Перевантаження операторів та безпека типів**: у C++ арифметичні вирази `(a * b) % m` записуються у природній математичній нотації зі збереженням інваріанта нормалізації степеня при кожній мутації, тоді як у C викликаються явні процедури `poly_mul` та `poly_div_rem`.
- **Обробка виняткових ситуацій**: спроба ділення на нульовий многочлен у C++ генерує стандартний виняток `std::invalid_argument`, дозволяючи викликаючому коду безпечно перехопити помилку, тоді як у C функція безпечно повертає нульовий результат.

```c
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>
#include <string.h>

#define MAX_DEG 128

/* Структура для представлення многочлена над F_p */
typedef struct {
    int deg;
    int c[MAX_DEG + 1]; /* c[i] - коефіцієнт при x^i */
} Poly;

/* Нормалізація степеня многочлена */
static void poly_normalize(Poly *p, int mod) {
    for (int i = 0; i <= p->deg; i++) {
        p->c[i] = (p->c[i] % mod + mod) % mod;
    }
    while (p->deg > 0 && p->c[p->deg] == 0) {
        p->deg--;
    }
}

/* Ініціалізація нульового многочлена */
static Poly poly_zero(void) {
    Poly p;
    p.deg = 0;
    memset(p.c, 0, sizeof(p.c));
    return p;
}

/* Додавання многочленів над F_p */
static Poly poly_add(const Poly *a, const Poly *b, int mod) {
    Poly r = poly_zero();
    r.deg = (a->deg > b->deg) ? a->deg : b->deg;
    for (int i = 0; i <= r.deg; i++) {
        int ca = (i <= a->deg) ? a->c[i] : 0;
        int cb = (i <= b->deg) ? b->c[i] : 0;
        r.c[i] = (ca + cb) % mod;
    }
    poly_normalize(&r, mod);
    return r;
}

/* Віднімання многочленів над F_p */
static Poly poly_sub(const Poly *a, const Poly *b, int mod) {
    Poly r = poly_zero();
    r.deg = (a->deg > b->deg) ? a->deg : b->deg;
    for (int i = 0; i <= r.deg; i++) {
        int ca = (i <= a->deg) ? a->c[i] : 0;
        int cb = (i <= b->deg) ? b->c[i] : 0;
        r.c[i] = (ca - cb + mod) % mod;
    }
    poly_normalize(&r, mod);
    return r;
}

/* Обернений елемент у полі F_p за малою теоремою Ферма */
static int mod_inv(int a, int mod) {
    a = (a % mod + mod) % mod;
    int res = 1, base = a, exp = mod - 2;
    while (exp > 0) {
        if (exp & 1) res = (res * base) % mod;
        base = (base * base) % mod;
        exp >>= 1;
    }
    return res;
}

/* Множення многочленів над F_p */
static Poly poly_mul(const Poly *a, const Poly *b, int mod) {
    Poly r = poly_zero();
    if ((a->deg == 0 && a->c[0] == 0) || (b->deg == 0 && b->c[0] == 0)) {
        return r;
    }
    r.deg = a->deg + b->deg;
    if (r.deg > MAX_DEG) r.deg = MAX_DEG;
    for (int i = 0; i <= a->deg; i++) {
        for (int j = 0; j <= b->deg && (i + j) <= MAX_DEG; j++) {
            r.c[i + j] = (r.c[i + j] + a->c[i] * b->c[j]) % mod;
        }
    }
    poly_normalize(&r, mod);
    return r;
}

/* Ділення многочленів з остачею: a = q * b + rem */
static void poly_div_rem(const Poly *a, const Poly *b, Poly *q, Poly *rem, int mod) {
    *rem = *a;
    *q = poly_zero();
    if (b->deg == 0 && b->c[0] == 0) return; /* Помилка ділення на нуль */
    if (a->deg < b->deg) return;

    q->deg = a->deg - b->deg;
    int b_lead_inv = mod_inv(b->c[b->deg], mod);

    while (rem->deg >= b->deg && !(rem->deg == 0 && rem->c[0] == 0)) {
        int shift = rem->deg - b->deg;
        int factor = (rem->c[rem->deg] * b_lead_inv) % mod;
        q->c[shift] = factor;

        for (int i = 0; i <= b->deg; i++) {
            int sub_val = (factor * b->c[i]) % mod;
            rem->c[i + shift] = (rem->c[i + shift] - sub_val + mod) % mod;
        }
        poly_normalize(rem, mod);
    }
    poly_normalize(q, mod);
}

/* Найбільший спільний дільник многочленів (Алгоритм Евкліда) */
static Poly poly_gcd(const Poly *a, const Poly *b, int mod) {
    Poly x = *a, y = *b;
    while (!(y.deg == 0 && y.c[0] == 0)) {
        Poly q, rem;
        poly_div_rem(&x, &y, &q, &rem, mod);
        x = y;
        y = rem;
    }
    /* Нормування: старший коефіцієнт робимо 1 */
    if (x.c[x.deg] != 0) {
        int inv = mod_inv(x.c[x.deg], mod);
        for (int i = 0; i <= x.deg; i++) {
            x.c[i] = (x.c[i] * inv) % mod;
        }
    }
    return x;
}

/* Модульне піднесення: (base^exp) mod m */
static Poly poly_pow_mod(Poly base, int exp, const Poly *m, int mod) {
    Poly res = poly_zero();
    res.c[0] = 1; /* Одиничний многочлен */
    Poly q, rem;

    poly_div_rem(&base, m, &q, &base, mod);
    while (exp > 0) {
        if (exp & 1) {
            Poly prod = poly_mul(&res, &base, mod);
            poly_div_rem(&prod, m, &q, &res, mod);
        }
        Poly base_sq = poly_mul(&base, &base, mod);
        poly_div_rem(&base_sq, m, &q, &base, mod);
        exp >>= 1;
    }
    return res;
}

/* Друк многочлена */
static void poly_print(const Poly *p) {
    bool first = true;
    for (int i = p->deg; i >= 0; i--) {
        if (p->c[i] == 0 && p->deg > 0) continue;
        if (!first && p->c[i] > 0) printf(" + ");
        if (i == 0) printf("%d", p->c[i]);
        else if (i == 1) {
            if (p->c[i] == 1) printf("x");
            else printf("%d*x", p->c[i]);
        } else {
            if (p->c[i] == 1) printf("x^%d", i);
            else printf("%d*x^%d", p->c[i], i);
        }
        first = false;
    }
    printf("\n");
}

/* Перевірка многочлена на незвідність за алгоритмом Рабіна */
static bool poly_is_irreducible(const Poly *f, int p) {
    if (f->deg <= 1) return (f->deg == 1);

    /* Формуємо x */
    Poly x_poly = poly_zero();
    x_poly.deg = 1;
    x_poly.c[1] = 1;

    /* Обчислюємо x^(p^n) mod f(x) послідовними піднесеннями */
    Poly h = x_poly;
    for (int i = 0; i < f->deg; i++) {
        h = poly_pow_mod(h, p, f, p);
    }
    Poly diff = poly_sub(&h, &x_poly, p);
    if (!(diff.deg == 0 && diff.c[0] == 0)) {
        return false; /* f(x) не ділить x^(p^n) - x */
    }

    /* Перевірка НСД для дільників n */
    int n = f->deg;
    for (int d = 1; d <= n / 2; d++) {
        if (n % d == 0) {
            Poly hd = x_poly;
            for (int i = 0; i < d; i++) {
                hd = poly_pow_mod(hd, p, f, p);
            }
            Poly diff_d = poly_sub(&hd, &x_poly, p);
            Poly g = poly_gcd(&diff_d, f, p);
            if (g.deg > 0) {
                return false; /* Знайдено спільний дільник меншого степеня */
            }
        }
    }
    return true;
}

int main(void) {
    printf("=== Факторизація та перевірка незвідності над F_2 ===\n\n");

    /* Тестовий многочлен: AES irreducible poly x^8 + x^4 + x^3 + x + 1 */
    Poly aes_poly = poly_zero();
    aes_poly.deg = 8;
    aes_poly.c[8] = 1; aes_poly.c[4] = 1; aes_poly.c[3] = 1; aes_poly.c[1] = 1; aes_poly.c[0] = 1;

    printf("Многочлен 1: ");
    poly_print(&aes_poly);
    printf("Статус незвідності: %s\n\n", poly_is_irreducible(&aes_poly, 2) ? "НЕПРИВІДНИЙ" : "ЗВІДНИЙ");

    /* Складений многочлен: (x^3 + x + 1) * (x^4 + x + 1) над F_2 */
    Poly p1 = poly_zero(); p1.deg = 3; p1.c[3] = 1; p1.c[1] = 1; p1.c[0] = 1;
    Poly p2 = poly_zero(); p2.deg = 4; p2.c[4] = 1; p2.c[1] = 1; p2.c[0] = 1;
    Poly composite = poly_mul(&p1, &p2, 2);

    printf("Многочлен 2 (добуток): ");
    poly_print(&composite);
    printf("Статус незвідності: %s\n", poly_is_irreducible(&composite, 2) ? "НЕПРИВІДНИЙ" : "ЗВІДНИЙ");

    /* Distinct-Degree факторизація для composite */
    printf("Пошук незвідних множників (Distinct-Degree):\n");
    Poly current = composite;
    Poly x_poly = poly_zero(); x_poly.deg = 1; x_poly.c[1] = 1;
    Poly h = x_poly;

    for (int d = 1; d <= current.deg / 2; d++) {
        h = poly_pow_mod(h, 2, &current, 2);
        Poly diff = poly_sub(&h, &x_poly, 2);
        Poly factor = poly_gcd(&diff, &current, 2);
        if (factor.deg > 0) {
            printf("  Знайдено множник степеня %d: ", d);
            poly_print(&factor);
            Poly q, rem;
            poly_div_rem(&current, &factor, &q, &rem, 2);
            current = q;
        }
    }
    if (current.deg > 0) {
        printf("  Залишковий незвідний множник степеня %d: ", current.deg);
        poly_print(&current);
    }

    return 0;
}
```

```cpp
#include <iostream>
#include <vector>
#include <span>
#include <optional>
#include <algorithm>
#include <numeric>
#include <string>
#include <stdexcept>

/* Клас многочлена над скінченним полем F_p із семантикою значень */
class Polynomial {
private:
    int mod_;
    std::vector<int> coeffs_; /* coeffs_[i] - коефіцієнт при x^i */

    void normalize() {
        for (auto &c : coeffs_) {
            c = (c % mod_ + mod_) % mod_;
        }
        while (coeffs_.size() > 1 && coeffs_.back() == 0) {
            coeffs_.pop_back();
        }
    }

    static int mod_inverse(int a, int m) {
        a = (a % m + m) % m;
        int res = 1, base = a, exp = m - 2;
        while (exp > 0) {
            if (exp & 1) res = (res * base) % m;
            base = (base * base) % m;
            exp >>= 1;
        }
        return res;
    }

public:
    Polynomial(int mod = 2) : mod_(mod), coeffs_{0} {}
    Polynomial(std::initializer_list<int> list, int mod = 2) : mod_(mod), coeffs_(list) {
        normalize();
    }
    Polynomial(std::vector<int> coeffs, int mod = 2) : mod_(mod), coeffs_(std::move(coeffs)) {
        if (coeffs_.empty()) coeffs_.push_back(0);
        normalize();
    }

    [[nodiscard]] int degree() const noexcept {
        return static_cast<int>(coeffs_.size()) - 1;
    }

    [[nodiscard]] int mod() const noexcept { return mod_; }
    [[nodiscard]] int operator[](size_t i) const noexcept {
        return (i < coeffs_.size()) ? coeffs_[i] : 0;
    }

    [[nodiscard]] bool is_zero() const noexcept {
        return coeffs_.size() == 1 && coeffs_[0] == 0;
    }

    [[nodiscard]] bool is_one() const noexcept {
        return coeffs_.size() == 1 && coeffs_[0] == 1;
    }

    Polynomial& operator+=(const Polynomial &rhs) {
        size_t max_sz = std::max(coeffs_.size(), rhs.coeffs_.size());
        coeffs_.resize(max_sz, 0);
        for (size_t i = 0; i < rhs.coeffs_.size(); ++i) {
            coeffs_[i] = (coeffs_[i] + rhs.coeffs_[i]) % mod_;
        }
        normalize();
        return *this;
    }

    Polynomial& operator-=(const Polynomial &rhs) {
        size_t max_sz = std::max(coeffs_.size(), rhs.coeffs_.size());
        coeffs_.resize(max_sz, 0);
        for (size_t i = 0; i < rhs.coeffs_.size(); ++i) {
            coeffs_[i] = (coeffs_[i] - rhs.coeffs_[i] + mod_) % mod_;
        }
        normalize();
        return *this;
    }

    friend Polynomial operator+(Polynomial lhs, const Polynomial &rhs) {
        lhs += rhs;
        return lhs;
    }

    friend Polynomial operator-(Polynomial lhs, const Polynomial &rhs) {
        lhs -= rhs;
        return lhs;
    }

    friend Polynomial operator*(const Polynomial &a, const Polynomial &b) {
        if (a.is_zero() || b.is_zero()) return Polynomial(a.mod_);
        std::vector<int> res(a.coeffs_.size() + b.coeffs_.size() - 1, 0);
        for (size_t i = 0; i < a.coeffs_.size(); ++i) {
            for (size_t j = 0; j < b.coeffs_.size(); ++j) {
                res[i + j] = (res[i + j] + a.coeffs_[i] * b.coeffs_[j]) % a.mod_;
            }
        }
        return Polynomial(std::move(res), a.mod_);
    }

    /* Ділення з остачею: повертає пару {частка, остача} */
    static std::pair<Polynomial, Polynomial> div_rem(const Polynomial &a, const Polynomial &b) {
        if (b.is_zero()) {
            throw std::invalid_argument("Ділення на нульовий многочлен");
        }
        if (a.degree() < b.degree()) {
            return {Polynomial(a.mod_), a};
        }

        Polynomial rem = a;
        std::vector<int> q_coeffs(a.degree() - b.degree() + 1, 0);
        int b_lead_inv = mod_inverse(b.coeffs_.back(), a.mod_);

        while (rem.degree() >= b.degree() && !rem.is_zero()) {
            int shift = rem.degree() - b.degree();
            int factor = (rem.coeffs_.back() * b_lead_inv) % a.mod_;
            q_coeffs[shift] = factor;

            for (size_t i = 0; i < b.coeffs_.size(); ++i) {
                int sub_val = (factor * b.coeffs_[i]) % a.mod_;
                rem.coeffs_[i + shift] = (rem.coeffs_[i + shift] - sub_val + a.mod_) % a.mod_;
            }
            rem.normalize();
        }

        return {Polynomial(std::move(q_coeffs), a.mod_), rem};
    }

    friend Polynomial operator/(const Polynomial &a, const Polynomial &b) {
        return div_rem(a, b).first;
    }

    friend Polynomial operator%(const Polynomial &a, const Polynomial &b) {
        return div_rem(a, b).second;
    }

    /* Найбільший спільний дільник (НСД) */
    static Polynomial gcd(Polynomial a, Polynomial b) {
        while (!b.is_zero()) {
            a = a % b;
            std::swap(a, b);
        }
        if (!a.is_zero() && a.coeffs_.back() != 1) {
            int inv = mod_inverse(a.coeffs_.back(), a.mod_);
            for (auto &c : a.coeffs_) {
                c = (c * inv) % a.mod_;
            }
        }
        return a;
    }

    /* Піднесення до степеня за модулем многочлена */
    static Polynomial pow_mod(Polynomial base, int exp, const Polynomial &mod_poly) {
        Polynomial res({1}, base.mod_);
        base = base % mod_poly;
        while (exp > 0) {
            if (exp & 1) {
                res = (res * base) % mod_poly;
            }
            base = (base * base) % mod_poly;
            exp >>= 1;
        }
        return res;
    }

    /* Перевірка незвідності за алгоритмом Рабіна */
    [[nodiscard]] bool is_irreducible() const {
        if (degree() <= 1) return degree() == 1;

        Polynomial x_poly({0, 1}, mod_); /* x */
        Polynomial h = x_poly;

        /* Перевірка умови: x^(p^n) mod f(x) == x */
        for (int i = 0; i < degree(); ++i) {
            h = pow_mod(h, mod_, *this);
        }
        if (!(h - x_poly).is_zero()) {
            return false;
        }

        /* Перевірка відсутності спільних дільників зі степенями d | n */
        int n = degree();
        for (int d = 1; d <= n / 2; ++d) {
            if (n % d == 0) {
                Polynomial hd = x_poly;
                for (int i = 0; i < d; ++i) {
                    hd = pow_mod(hd, mod_, *this);
                }
                Polynomial g = gcd(hd - x_poly, *this);
                if (g.degree() > 0) {
                    return false;
                }
            }
        }
        return true;
    }

    void print() const {
        bool first = true;
        for (int i = degree(); i >= 0; --i) {
            if (coeffs_[i] == 0 && degree() > 0) continue;
            if (!first) std::cout << " + ";
            if (i == 0) std::cout << coeffs_[i];
            else if (i == 1) {
                if (coeffs_[i] == 1) std::cout << "x";
                else std::cout << coeffs_[i] << "*x";
            } else {
                if (coeffs_[i] == 1) std::cout << "x^" << i;
                else std::cout << coeffs_[i] << "*x^" << i;
            }
            first = false;
        }
        std::cout << "\n";
    }
};

int main() {
    std::cout << "=== Факторизація та перевірка незвідності на C++20 ===\n\n";

    /* Стандартний непривідний многочлен AES Rijndael: x^8 + x^4 + x^3 + x + 1 над F_2 */
    Polynomial aes_poly({1, 1, 0, 1, 1, 0, 0, 0, 1}, 2);
    std::cout << "Многочлен AES: ";
    aes_poly.print();
    std::cout << "Статус: " << (aes_poly.is_irreducible() ? "НЕПРИВІДНИЙ" : "ЗВІДНИЙ") << "\n\n";

    /* Складений многочлен: (x^3 + x + 1) * (x^4 + x + 1) над F_2 */
    Polynomial factor_a({1, 1, 0, 1}, 2);       // x^3 + x + 1
    Polynomial factor_b({1, 1, 0, 0, 1}, 2);    // x^4 + x + 1
    Polynomial composite = factor_a * factor_b;

    std::cout << "Складений многочлен: ";
    composite.print();
    std::cout << "Статус: " << (composite.is_irreducible() ? "НЕПРИВІДНИЙ" : "ЗВІДНИЙ") << "\n\n";

    /* Розділення множників за методом Distinct-Degree */
    std::cout << "Факторизація Distinct-Degree:\n";
    Polynomial current = composite;
    Polynomial x_poly({0, 1}, 2);
    Polynomial h = x_poly;

    for (int d = 1; d <= current.degree() / 2; ++d) {
        h = Polynomial::pow_mod(h, 2, current);
        Polynomial diff = h - x_poly;
        Polynomial factor = Polynomial::gcd(diff, current);
        if (factor.degree() > 0) {
            std::cout << "  Виділено незвідний множник степеня " << d << ": ";
            factor.print();
            current = current / factor;
        }
    }
    if (current.degree() > 0) {
        std::cout << "  Залишковий незвідний множник степеня " << current.degree() << ": ";
        current.print();
    }

    return 0;
}
```

## 12. Детальний аналіз часової складності та апаратна оптимізація

Розглянемо обчислювальні витрати кожної операції для вхідного многочлена степеня `n` над полем `F_p`:
1. **Множення многочленів**: класичне множення виконується за `O(n²)` операцій над полем `F_p`. Для великих степенів (`n > 64`) алгоритм Карацуби знижує складність до `O(n^(1.585))`, а швидке перетворення Фур'є / числове теоретичне перетворення (NTT) — до `O(n · log n · log log n)`.
2. **Ділення з остачею**: класичний алгоритм виконує `O(n · (n - m + 1)) = O(n²)` дій.
3. **Обчислення НСД (Алгоритм Евкліда)**: кожен крок знижує степінь щонайменше на 1, загальна складність становить `O(n²)`. Швидкий напів-розширений алгоритм Евкліда (Half-GCD) дозволяє знизити час до `O(n · log² n)`.
4. **Модульне піднесення до степеня `x^(pᵈ) mod f(x)`**: вимагає `O(d · log p)` модульних множень, що за класичної арифметики дає `O(d · log p · n²)`.

### Апаратні оптимізації для `F₂[x]`

Для поля двох елементів `F₂` кожен многочлен степеня `n ≤ 63` вміщується в один 64-бітний машинний регістр `uint64_t`:
- Додавання та віднімання поліномів стають однією процесорною інструкцією `XOR` (`^`).
- Множення без перенесення (англ. *carry-less multiplication*) реалізується спеціальною інструкцією процесора x86-64 `_mm_clmulepi64_si128` (PCLMULQDQ) або ARM NEON `vmull_p64`, що виконує множення 64-бітних поліномів за 1–3 такти процесора.
- Обчислення залишків за фіксованим непривідним многочленом виконується через апаратно згенеровані таблиці Barret reduction або shift-and-xor конвеєр.

Завдяки цим властивостям пошук та обробка непривідних многочленів у ядрі операційної системи (наприклад, у криптографічних драйверах підсистеми `crypto/` ядра Linux для AES-GCM та CRC32) виконуються на швидкостях у десятки гігабайт на секунду.
