# 🧮 Алгебра модуля Тейта, спарювання Вейля та многочлен Фробеніуса

Модуль Тейта є фундаментальною лінеаризацією алгебраїчної структури еліптичної кривої. Він перетворює дискретну геометрію точок кручення на неперервний вільний модуль над кільцем цілих `ℓ`-адичних чисел `Z_ℓ`, на якому абсолютна група Галуа діє через матриці розміру 2 × 2.

### Проєктивна границя та ранг модуля Тейта

Нехай `E` — еліптична крива, задана над числовим полем `K` (наприклад, полем раціональних чисел `Q`), і нехай `ℓ` — фіксоване просте число.

Для кожного натурального числа `n ≥ 1` група точок `ℓⁿ`-кручення `E[ℓⁿ]` над алгебраїчним замиканням `K̄` визначається як ядро гомоморфізму множення на `ℓⁿ`:

```
E[ℓⁿ] = { P ∈ E(K̄) : ℓⁿ · P = O }      [O — нейтральний елемент, нескінченно віддалена точка]
```

З комплексної теорії еліптичних кривих відомо, що над полем комплексних чисел `C` еліптична крива ізоморфна комплексному тору `C / Λ`, де `Λ = Z · ω₁ ⊕ Z · ω₂` — двовимірна ґратка періодів. Точки кручення порядку `ℓⁿ` відповідають точкам вигляду:

```
(a/ℓⁿ) · ω₁ + (b/ℓⁿ) · ω₂  (mod Λ),   де a, b ∈ {0, 1, ..., ℓⁿ − 1}
```

Звідси випливає фундаментальний алгебраїчний ізоморфізм скінченних абелевих груп:

```
E[ℓⁿ] ≅ (Z / ℓⁿZ) ⊕ (Z / ℓⁿZ)      [пряма сума двох циклічних груп порядку ℓⁿ]
```

Ця група містить рівно `(ℓⁿ)² = ℓ^{2n}` точок. Якщо ми збільшуємо показник степеня від `n` до `n+1`, точки утворюють нескінченну ієрархічну вежу. Групи `E[ℓⁿ]` пов'язані між собою гомоморфізмами множення на `ℓ`:

```
[·ℓ]: E[ℓⁿ⁺¹] → E[ℓⁿ]      [множення точки на ℓ переводить кручення порядку ℓⁿ⁺¹ у кручення ℓⁿ]
```

Ці відображення є сюр'єктивними, а їхні ядра збігаються з групою точок простого кручення `E[ℓ]`.

Система груп `{E[ℓⁿ]}` разом із гомоморфізмами `[·ℓ]` утворює проєктивну систему. **Модулем Тейта** `T_ℓ(E)` називають проєктивну границю (інверсну границю) цієї системи:

```
T_ℓ(E) = lim_inv E[ℓⁿ] = { (P₁, P₂, P₃, ...) : Pₙ ∈ E[ℓⁿ],  ℓ · Pₙ₊₁ = Pₙ }
```

Оскільки проєктивна границя кілець `lim_inv (Z / ℓⁿZ)` за означенням є кільцем цілих `ℓ`-адичних чисел `Z_ℓ`, ми отримуємо структуру вільного `Z_ℓ`-модуля рангу 2:

```
T_ℓ(E) ≅ Z_ℓ ⊕ Z_ℓ = Z_ℓ²      [вільний модуль рангу 2 над кільцем Z_ℓ]
```

Тензорний добуток модуля Тейта з полем `ℓ`-адичних чисел `Q_ℓ` дає 2-вимірний векторний простір над `Q_ℓ`, який позначають `V_ℓ(E)` (раціональний модуль Тейта):

```
V_ℓ(E) = T_ℓ(E) ⊗_{Z_ℓ} Q_ℓ ≅ Q_ℓ²      [2-вимірний лінійний простір над полем Q_ℓ]
```

### Дія абсолютної групи Галуа та лінеаризація

Будь-який автоморфізм `σ ∈ Gal(K̄/K)` діє на однорідні координати точок еліптичної кривої `P = (x : y : z)`:

```
σ(P) = (σ(x) : σ(y) : σ(z))
```

Оскільки рівняння кривої та коефіцієнти раціональних функцій групового закону додавання точок `+` визначені над базовим полем `K`, дія `σ` зберігає групову операцію:

```
σ(P + Q) = σ(P) + σ(Q)      [автоморфізм зберігає додавання точок на еліптичній кривій]
σ(ℓⁿ · P) = ℓⁿ · σ(P)        [автоморфізм комутує з множенням на ціле число ℓⁿ]
```

Якщо `P ∈ E[ℓⁿ]`, тобто `ℓⁿ · P = O`, то:

```
ℓⁿ · σ(P) = σ(ℓⁿ · P) = σ(O) = O      [образ точки кручення лишається точкою кручення]
```

Це означає, що скінченна підгрупа `E[ℓⁿ]` є інваріантною щодо дії `Gal(K̄/K)`. Узгодженість дій на кожному поверсі вежі дозволяє підняти дію на весь модуль Тейта `T_ℓ(E)`:

```
σ((P₁, P₂, ...)) = (σ(P₁), σ(P₂), ...)
```

Оскільки дія `σ` є лінійним `Z_ℓ`-автоморфізмом модуля `T_ℓ(E) ≅ Z_ℓ²`, фіксація довільного базису `{e₁, e₂}` у `T_ℓ(E)` задає неперервне матричне зображення Галуа:

```
ρ_{E,ℓ}: Gal(K̄/K) → GL₂(Z_ℓ) ⊂ GL₂(Q_ℓ)
```

Зміна вибору базису відповідає переходу до спряженої матриці `M ↦ U · M · U⁻¹` за допомогою унімодулярної матриці `U ∈ GL₂(Z_ℓ)`. Таким чином, клас ізоморфізму зображення Галуа не залежить від вибору координат.

### Алгебраїчна конструкція спарювання Вейля

Для дослідження визначника матриці `ρ_{E,ℓ}(σ)` та вивчення внутрішньої геометрії точок кручення використовують **спарювання Вейля** (англ. *Weil pairing*).

Нехай `n = ℓᵏ`. Візьмемо точку `T ∈ E[n]`. Оскільки `n · T = O`, дивізор `n · (T) − n · (O)` є головним дивізором на кривій `E`. Отже, існує така раціональна функція `f_T` на кривій `E`, що її дивізор дорівнює:

```
div(f_T) = n · (T) − n · (O)      [нуль порядку n у точці T та полюс порядку n у точці O]
```

Тепер візьмемо іншу точку `S ∈ E[n]`. Знайдемо таку точку `S' ∈ E(K̄)`, що `n · S' = S`. Тоді дивізор суми точок `∑_{R ∈ E[n]} (S' + R) − ∑_{R ∈ E[n]} (R)` є головним, тобто існує раціональна функція `g_S` на `E`, для якої:

```
div(g_S) = [n]^* (S) − [n]^* (O) = ∑_{R ∈ E[n]} (S' + R) − ∑_{R ∈ E[n]} (R)
```

Композиція функції `f_T` з відображенням множення на `n` дає функцію `f_T ∘ [n]`, дивізор якої дорівнює:

```
div(f_T ∘ [n]) = n · div(g_S) = div(g_Sⁿ)
```

Це означає, що функції `f_T ∘ [n]` та `g_Sⁿ` відрізняються лише ненульовим константним множником. Тому для будь-якої точки `X ∈ E`, де функції визначені й не перетворюються на нуль чи нескінченність, значення відношення:

```
e_n(S, T) = g_S(X + T) / g_S(X)
```

є коренем `n`-го степеня з одиниці в полі `K̄`. Відображення:

```
e_n: E[n] × E[n] → μ_n = { ζ ∈ K̄ : ζⁿ = 1 }
```

називають **спарюванням Вейля порядку `n`**.

### Фундаментальні властивості спарювання Вейля

Спарювання Вейля має чотири визначальні властивості, які роблять його головним інструментом алгебраїчної теорії еліптичних кривих:

1. **Білінійність**:
   Для будь-яких точок `S₁, S₂, T ∈ E[n]`:
   ```
   e_n(S₁ + S₂, T) = e_n(S₁, T) · e_n(S₂, T)
   e_n(S, T₁ + T₂) = e_n(S, T₁) · e_n(S, T₂)
   ```

2. **Кососиметричність (знакозмінність)**:
   Для будь-якої точки `P ∈ E[n]`:
   ```
   e_n(P, P) = 1
   ```
   З білінійності випливає властивість антисиметрії:
   ```
   1 = e_n(P + Q, P + Q) = e_n(P, P) · e_n(P, Q) · e_n(Q, P) · e_n(Q, Q) = e_n(P, Q) · e_n(Q, P)
   ```
   звідки для будь-яких `P` та `Q`:
   ```
   e_n(P, Q) = (e_n(Q, P))⁻¹
   ```

3. **Невиродженість**:
   Якщо для фіксованої точки `P ∈ E[n]` рівність `e_n(P, Q) = 1` виконується для абсолютно всіх точок `Q ∈ E[n]`, то точка `P` є нейтральним елементом: `P = O`.

4. **Галуа-еквіваріантність**:
   Дія будь-якого автоморфізму Галуа `σ ∈ Gal(K̄/K)` комутує зі спарюванням Вейля:
   ```
   e_n(σ(P), σ(Q)) = σ(e_n(P, Q))
   ```

### Точне виведення визначника зображення Галуа

Переходячи до проєктивної границі за всіма степенями `n = ℓᵏ`, ми отримуємо неперервне `Z_ℓ`-білінійне незвіджене спарювання на модулях Тейта:

```
e_ℓ: T_ℓ(E) × T_ℓ(E) → T_ℓ(μ) ≅ Z_ℓ(1)
```

де `T_ℓ(μ) = lim_inv μ_{ℓⁿ}` — модуль Тейта коренів з одиниці (на якому група Галуа діє через круговий характер `χ_ℓ`).

Нехай `{e₁, e₂}` — вільний `Z_ℓ`-базис модуля `T_ℓ(E)`. Тоді елемент `ζ = e_ℓ(e₁, e₂)` є твірним елементом вільного `Z_ℓ`-модуля `T_ℓ(μ)`.

Нехай `σ ∈ Gal(K̄/K)` — довільний автоморфізм Галуа. Запишемо дію `σ` на базисні вектори через елементи матриці зображення `ρ_{E,ℓ}(σ)`:

```
σ(e₁) = a · e₁ + c · e₂      [де a, b, c, d ∈ Z_ℓ]
σ(e₂) = b · e₁ + d · e₂
```

Обчислимо значення спарювання Вейля образів `e_ℓ(σ(e₁), σ(e₂))` покроково:

```
e_ℓ(σ(e₁), σ(e₂))
= e_ℓ(a · e₁ + c · e₂,  b · e₁ + d · e₂)                 [підставили розклад за базисом]
= e_ℓ(e₁, e₁)^{a·b} · e_ℓ(e₁, e₂)^{a·d} · e_ℓ(e₂, e₁)^{c·b} · e_ℓ(e₂, e₂)^{c·d} [білінійність форми]
= 1^{a·b} · (e_ℓ(e₁, e₂))^{a·d} · (e_ℓ(e₁, e₂))^{-b·c} · 1^{c·d}  [кососиметричність e_ℓ(eᵢ, eᵢ) = 1 та e_ℓ(e₂, e₁) = e_ℓ(e₁, e₂)⁻¹]
= (e_ℓ(e₁, e₂))^{a·d − b·c}                             [додали показники степенів]
= ζ^{det(ρ_{E,ℓ}(σ))}                                   [за означенням визначника: ad − bc]
```

З іншого боку, за фундаментальною властивістю Галуа-еквіваріантності та означенням кругового характеру `χ_ℓ`:

```
e_ℓ(σ(e₁), σ(e₂)) = σ(e_ℓ(e₁, e₂)) = σ(ζ) = ζ^{χ_ℓ(σ)}  [дія автоморфізму на корінь з одиниці]
```

Оскільки `ζ` є вільним твірним елементом рангу 1 над `Z_ℓ`, рівність `ζ^{det(ρ_{E,ℓ}(σ))} = ζ^{χ_ℓ(σ)}` означає точну числову рівність показників у кільці `Z_ℓ`:

```
det(ρ_{E,ℓ}(σ)) = χ_ℓ(σ)      [визначник матриці зображення дорівнює круговому характеру]
```

Це доводить, що визначник 2-вимірного зображення Галуа еліптичної кривої не залежить від геометрії самої кривої і завжди збігається з універсальним круговим характером `χ_ℓ`.

### Ендоморфізм Фробеніуса та локальний характеристичний многочлен

Нехай `p` — просте число доброї редукції для еліптичної кривої `E` (тобто `p ∤ ℓ · Δ_E`).

Розглянемо редукцію кривої `Ẽ = E mod p` над скінченним полем `F_p`. Ендоморфізм Фробеніуса `ϕ_p: Ẽ → Ẽ`, що діє на афінні координати як `(x, y) ↦ (xᵖ, yᵖ)`, індукує лінійний оператор на модулі Тейта `T_ℓ(Ẽ) ≅ T_ℓ(E)`:

```
ρ_{E,ℓ}(Frob_p) = ϕ_p^* ∈ End_{Z_ℓ}(T_ℓ(E))
```

Знайдемо його характеристичний многочлен `P(T) = det(T · I − ϕ_p^*)`.

З властивостей спарювання Вейля визначник оператора Фробеніуса дорівнює його геометричному степеню як ендоморфізма алгебраїчної кривої:

```
det(ϕ_p^*) = deg(ϕ_p) = p      [степінь несепарабельного відображення Фробеніуса дорівнює p]
```

Кількість точок редукції еліптичної кривої над полем `F_p` дорівнює кількості нерухомих точок автоморфізму Фробеніуса, тобто кількості точок у ядрі ендоморфізму `1 − ϕ_p`:

```
#E(F_p) = #Ker(1 − ϕ_p) = deg(1 − ϕ_p) = det(I − ϕ_p^*)
```

Розпишемо визначник матриці `I − ϕ_p^*` розміру 2 × 2 через слід `Tr(ϕ_p^*)` та визначник `det(ϕ_p^*)`:

```
#E(F_p)
= det(I − ϕ_p^*)               [кількість точок дорівнює ступеню відображення]
= 1 − Tr(ϕ_p^*) + det(ϕ_p^*)   [формула визначника матриці 2 × 2: det(I − M) = 1 − Tr(M) + det(M)]
= 1 − Tr(ϕ_p^*) + p            [підставили det(ϕ_p^*) = p]
```

Позначивши слід ендоморфізму Фробеніуса через `a_p = Tr(ϕ_p^*)`, отримуємо фундаментальну формулу для дефекту кількості точок:

```
a_p = p + 1 − #E(F_p)      [слід Фробеніуса виражається через кількість точок над скінченним полем]
```

Звідси характеристичний многочлен матриці `ρ_{E,ℓ}(Frob_p)` має вигляд:

```
P(T) = T² − a_p · T + p      [характеристичний многочлен у прямій змінній T]
```

А зворотний характеристичний многочлен, який використовується в ейлерових множниках L-функцій, дорівнює:

```
det(I − T · ρ_{E,ℓ}(Frob_p)) = 1 − a_p · T + p · T²
```

Власні значення `α_p, β_p ∈ C` матриці `ρ_{E,ℓ}(Frob_p)` є комплексними коренями квадратного рівняння `T² − a_p T + p = 0`. За теоремою Вієта:

```
α_p + β_p = a_p
α_p · β_p = p
```

За теоремою Гассе про еліптичні криві над скінченними полями, модуль кожного власного значення строго дорівнює:

```
|α_p| = |β_p| = √p      [аналог гіпотези Рімана для локальних дзета-функцій кривих Вейля]
```

Звідси негайно випливає нерівність Гассе:

```
|a_p| = |α_p + β_p| ≤ |α_p| + |β_p| = √p + √p = 2√p
```

### Теорема Тейта про ізогенії

Грандіозний результат Джона Тейта (1966 рік для скінченних полів) та Герда Фальтінгса (1983 рік для числових полів над `Q`) стверджує, що модуль Тейта повністю визначає криву з точністю до ізогенії.

Гомоморфізм груп:

```
Hom(E₁, E₂) ⊗_Z Z_ℓ → Hom_{G_K}(T_ℓ(E₁), T_ℓ(E₂))
```

є **ізоморфізмом вільних `Z_ℓ`-модулів**. 

Це означає, що дві еліптичні криві `E₁` та `E₂` над числовим полем `K` є ізогенними (існує ненульовий раціональний алгебраїчний гомоморфізм між ними) тоді й лише тоді, коли їхні зображення Галуа `V_ℓ(E₁)` та `V_ℓ(E₂)` є ізоморфними як лінійні зображення над полем `Q_ℓ`. Більше того, це рівносильно тому, що сліди Фробеніуса `a_p(E₁) = a_p(E₂)` збігаються для майже всіх простих чисел `p`.

Таким чином, модуль Тейта перетворює нелінійну алгебраїчну геометрію еліптичних кривих на лінійну спектральну теорію матриць Галуа без будь-якої втрати інформації про клас ізогенії.
