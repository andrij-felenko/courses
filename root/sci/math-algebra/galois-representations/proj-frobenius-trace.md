# ⚙️ Обчислення слідів Фробеніуса та перевірка модулярності

Цей практичний алгоритм демонструє пряму числову перевірку теореми модулярності. Він обчислює арифметичні сліди автоморфізму Фробеніуса `a_p(E)` для еліптичної кривої шляхом підрахунку кількості точок над скінченними полями `F_p` і зіставляє їх із аналітичними коефіцієнтами Фур'є `a_p(f)` відповідної параболічної модулярної форми ваги 2.

### Математична постановка задачі

Розглянемо еліптичну криву з кондуктором `N = 11` (мінімально можливий кондуктор для еліптичних кривих над полем `Q`). У глобальній базі даних кривих Кремони вона позначається як `11a1` і є модулярною кривою `X₀(11)`:

```
E: y² + y = x³ − x² − 10x − 20
```

Для кожного простого числа `p` ми шукаємо кількість розв'язків `(x, y) ∈ F_p²` цього рівняння, додаємо 1 (точку `O` на нескінченності) і визначаємо дефект кількості точок — слід оператора Фробеніуса `a_p(E)`:

```
a_p(E) = p + 1 − #E(F_p)
```

З аналітичного боку, простір параболічних форм `S₂(Γ₀(11))` є 1-вимірним і породжується єдиною новою формою, що виражається через добуток функцій Дедекінда `η(q)² · η(q¹¹)²`:

```
f(q) = q · ∏_{n=1}^∞ (1 − qⁿ)² · (1 − q¹¹ⁿ)² = ∑_{n=1}^∞ a_n(f) · qⁿ
```

Теорема модулярності стверджує, що для кожного простого числа `p` геометричне число `a_p(E)` має точно дорівнювати коефіцієнту ряду Фур'є `a_p(f)`.

### Типи редукції еліптичних кривих та кондуктор

Поведінка еліптичної кривої за модулем простого числа `p` визначається її типом редукції. Кондуктор кривої `N = ∏ p^{f_p}` складається з показників розгалуження `f_p`:

1. **Добра редукція (good reduction)**, `f_p = 0`:
   Крива залишається гладкою (неособливою) кубічною кривою над полем `F_p`. Її дискримінант не ділиться на `p`. Це відбувається для всіх простих чисел `p`, які не ділять кондуктор `N` (у нашому випадку для всіх `p ≠ 11`). Кількість точок задовольняє нерівність Гассе `|a_p(E)| ≤ 2√p`.

2. **Мультиплікативна (нодальна) редукція (multiplicative reduction)**, `f_p = 1`:
   Крива набуває вузлової точки самоперетину (ноди). Якщо дотичні у вузлі визначені над базовим полем `F_p`, редукцію називають розщеплюваною (split), і `a_p(E) = 1`; якщо дотичні спряжені над квадратичним розширенням `F_{p²}`, редукція є нерозщеплюваною (non-split), і `a_p(E) = −1`. Для нашої кривої `11a1` при `p = 11` маємо саме нерозщеплювану мультиплікативну редукцію, тому `a₁₁(E) = −1`.

3. **Адитивна (каспідальна) редукція (additive reduction)**, `f_p ≥ 2`:
   Крива набуває точки загострення (каспа). У цьому випадку слід Фробеніуса строго дорівнює нулю: `a_p(E) = 0`. Такі криві вимагають вищих степенів простих чисел у кондукторі.

### Алгоритм підрахунку точок над скінченним полем

Рівняння кривої у загальній формі Вейєрштрасса:

```
y² + a₁·x·y + a₃·y = x³ + a₂·x² + a₄·x + a₆
```

для непарних простих чисел `p > 2` зводиться до квадратного рівняння відносно змінної `Y = 2y + a₁ x + a₃`:

```
Y² = 4x³ + b₂·x² + 2b₄·x + b₆  (mod p)
```

де коефіцієнти обчислюються через стандартні інваріанти Вейєрштрасса:
- `b₂ = a₁² + 4a₂`
- `b₄ = a₁ a₃ + 2a₄`
- `b₆ = a₃² + 4a₆`

Для кожного значення `x ∈ {0, 1, ..., p − 1}` обчислюємо кубічний многочлен `rhs(x) = (4x³ + b₂ x² + 2b₄ x + b₆) mod p`. Кількість розв'язків `Y` визначається символом Лежандра `(rhs(x) / p)`:
- якщо `rhs(x) ≡ 0 (mod p)`, існує рівно один розв'язок `Y = 0`;
- якщо `rhs(x)` є квадратичним лишком за модулем `p`, існує рівно два протилежні розв'язки `±Y`;
- якщо `rhs(x)` є квадратичним нелишком, дійсних розв'язків у полі `F_p` немає.

Загальна кількість афінних точок дорівнює:

```
#E_{aff}(F_p) = ∑_{x=0}^{p-1} ( 1 + (rhs(x) / p) ) = p + ∑_{x=0}^{p-1} (rhs(x) / p)
```

Додаючи 1 для нескінченно віддаленої точки `O`, отримуємо загальну кількість точок `#E(F_p) = p + 1 − a_p(E)`, де слід Фробеніуса виражається сумою характерів:

```
a_p(E) = −∑_{x=0}^{p-1} (rhs(x) / p)
```

Для характеристики `p = 2` загальне перетворення не працює, оскільки ділення на 2 у полі `F_2` неможливе. У цьому випадку алгоритм виконує прямий перебір усіх чотирьох пар `(x, y) ∈ F₂²` безпосередньо у вихідному рівнянні.

Для великих простих чисел `p` прямий перебір зі складністю `O(p)` замінюють на поліноміальний **алгоритм Схуфа** (англ. *Schoof's algorithm*) зі складністю `O(log⁸ p)` або алгоритм **Схуфа — Елкіса — Аткіна (SEA)** зі складністю `O(log⁴ p)`. Вони обчислюють дію автоморфізму Фробеніуса на многочленах ділення `f_ℓ(x)` і знаходять `a_p mod ℓ` для малих простих `ℓ`, після чого відновлюють `a_p` через Китайську теорему про залишки. Для навчальних та перевірочних цілей при малих `p ≤ 50` прямий перебір з таблицею лишків є найбільш наочним і швидким.

### Покроковий ручний розбір для малих простих чисел

Розглянемо перші три простих числа, щоб побачити роботу алгоритму на рівні конкретних чисел:

1. **Випадок `p = 2`**:
   Перевіряємо 4 можливі точки на кривій `y² + y = x³ − x² − 10x − 20 ≡ x³ + x² (mod 2)`:
   - `(0, 0)`: `0 ≡ 0` (точка лежить на кривій);
   - `(0, 1)`: `1 + 1 = 0 ≡ 0` (точка на кривій);
   - `(1, 0)`: `0 ≡ 1 + 1 = 0` (точка на кривій);
   - `(1, 1)`: `1 + 1 = 0 ≡ 1 + 1 = 0` (точка на кривій).
   Усі 4 афінні точки задовольняють рівняння. Разом із точкою `O` маємо `#E(F₂) = 5`.
   Слід Фробеніуса: `a₂(E) = 2 + 1 − 5 = −2`.

2. **Випадок `p = 3`**:
   Рівняння за модулем 3: `y² + y ≡ x³ − x² − x − 2 ≡ x³ + 2x² + 2x + 1 (mod 3)`.
   Перевіряємо пари: знаходяться точки `(0, 1), (0, 2), (1, 1), (1, 2)`.
   Разом з `O` отримуємо `#E(F₃) = 5` точок.
   Слід Фробеніуса: `a₃(E) = 3 + 1 − 5 = −1`.

3. **Випадок `p = 5`**:
   Рівняння за модулем 5: `y² + y ≡ x³ + 4x² (mod 5)`.
   Афінні розв'язки: `(0, 0), (0, 4), (1, 0), (1, 4)`.
   Разом з `O` маємо `#E(F₅) = 5` точок.
   Слід Фробеніуса: `a₅(E) = 5 + 1 − 5 = 1`.

### Алгоритм розгортання нескінченного добутку Дедекінда

Модулярна форма `f(q)` є добутком степенів дедекіндових ета-функцій. Щоб знайти коефіцієнти Фур'є `a_n(f)`, розгортаємо формальний степеневий ряд:

```
P(q) = ∏_{n=1}^M (1 − qⁿ)² · ∏_{k=1}^{M/11} (1 − q¹¹ᵏ)²  (mod q^{M+1})
```

Множення поточного многочлена `P(q)` на множник `(1 − q^d)` виконується за лінійний час від довжини масиву коефіцієнтів:

```
P_{нов}(q) = P_{стар}(q) − q^d · P_{стар}(q)
```

Повторивши цю операцію двічі для кожного степеня `n` від 1 до `M` та двічі для кожного степеня `11k` від 11 до `M`, ми отримуємо поліном `P(q)`. Оскільки `f(q) = q · P(q)`, шуканий коефіцієнт Фур'є `a_n(f)` є в точності коефіцієнтом при члені `q^{n-1}` у многочлені `P(q)`.

Оператори Гекке `T_n` визначають мультиплікативні співвідношення між коефіцієнтами:
- якщо `(m, n) = 1`, то `a_{mn}(f) = a_m(f) · a_n(f)`;
- для степенів простих чисел `a_{p^k}(f) = a_p(f) · a_{p^{k-1}}(f) − p · a_{p^{k-2}}(f)`.

Тому знання коефіцієнтів `a_p(f)` для простих `p` повністю відновлює весь нескінченний ряд Фур'є.


Зверніть увагу на особливий випадок `p = 11`: це число ділить кондуктор кривої `N = 11`. У цьому простому числі редукція кривої є нодальною (мультиплікативною), і коефіцієнт `a₁₁(E) = −1` точно збігається з коефіцієнтом при `q¹¹` у розкладі форми Дедекінда.

Для всіх інших простих чисел діє нерівність Гассе `|a_p| ≤ 2√p`:
- для `p = 2`: `|-2| ≤ 2√2 ≈ 2.82` (виконується);
- для `p = 41`: `|-8| ≤ 2√41 ≈ 12.80` (виконується);
- для `p = 47`: `|-7| ≤ 2√47 ≈ 13.71` (виконується).

Цей числовий експеримент демонструє, що два повністю незалежні математичні об'єкти — геометрична крива над скінченними полями та комплексний ряд Дедекінда — породжують одну й ту саму послідовність цілих чисел `a_p`. Це є найпереконливішим прямим доказом існування мосту між зображеннями Галуа та аналітичними модулярними формами.
