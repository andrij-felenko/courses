# 🧮 Вивід інтеграла густини енергії електричного поля

Математичний вивід виразу для енергії електричного поля базується на послідовному переході від дискретної системи точкових зарядів до суцільного об'ємного розподілу заряду та подальшому застосуванні векторного аналізу й диференціальної форми закону Гаусса. Нижче наведено суворий крок-за-кроком вивід, що доводить тотожність потенціальної енергії взаємодії зарядів та об'ємного інтеграла густини напруженості поля.

### Фізична постановка та математичні передумови

У класичній електростатиці вихідною точкою розрахунку енергії є потенціальна енергія взаємодії заряджених частинок, що обчислюється як робота зовнішніх сил, виконана при збиранні конфігурації зарядів з нескінченності. Для дискретної системи частинок ця робота є сумою парних кулонівських потенціалів. Проте для розв'язання задач поля та електродинаміки суцільних середовищ необхідно перетворити вираз, заданий через джерела поля (заряди), у локальний об'ємний інтеграл, залежний виключно від вектора напруженості електричного поля `E` у кожній точці простору.

### Крок 1: Енергія системи дискретних точкових зарядів

Розглянемо процес збирання системи з `N` точкових зарядів `q₁, q₂, ..., qₙ`, які початково перебувають на нескінченно великій відстані один від одного, де електричне поле відсутнє, а потенціал дорівнює нулю.

1. Перенесення першого заряду `q₁` з нескінченності в точку з радіус-вектором `r₁` не потребує виконання роботи, оскільки інші заряди відсутні і зовнішнє електростатичне поле дорівнює нулю:
   `W₁ = 0`.
2. Перенесення другого заряду `q₂` в точку `r₂` відбувається у полі, створеному першим зарядом `q₁`. Виконана зовнішніми силами робота дорівнює добутку заряду `q₂` на потенціал `V₁(r₂)` у точці його розташування:
   `W₂ = q₂ · V₁(r₂) = (1 / 4πε₀) · (q₁ q₂ / r₁₂)`.
3. Перенесення третього заряду `q₃` в точку `r₃` відбувається у сумарному полі перших двох зарядів `q₁` та `q₂`:
   `W₃ = q₃ · [V₁(r₃) + V₂(r₃)] = (1 / 4πε₀) · (q₁ q₃ / r₁₃ + q₂ q₃ / r₂₃)`.

Повна робота `W`, виконана проти електростатичних сил при послідовній збірці всіх `N` зарядів системи, дорівнює сумі робіт на кожному проміжному кроці:

```
W = (1 / 4πε₀) · ∑_{i < j} (q_i · q_j / r_ij)
```

Щоб зняти обмеження `i < j` та зробити підсумовування симетричним за всіма індексами, перепишемо суму через усі пари `i ≠ j`, поділивши результат на 2:

```
W = ½ · ∑_{i=1}^N q_i · [ (1 / 4πε₀) · ∑_{j ≠ i} (q_j / r_ij) ]
```

Вираз у квадратних дужках — це потенціал `V_i`, створений **усіма іншими** зарядами системи у точці розташування заряду `q_i`. Отже, енергія дискретної системи зарядів набуває компактного вигляду:

```
W = ½ · ∑_{i=1}^N q_i · V_i
```

Множник `½` має чіткий фізичний сенс: потенціальна енергія належить кожній парі зарядів один раз, тоді як сума `∑ q_i V_i` враховує взаємодію кожної пари двічі (як дію `q_i` на `q_j` і як дію `q_j` на `q_i`).

### Крок 2: Перехід до суцільного об'ємного розподілу заряду

Якщо заряд розподілений у просторі суцільно з об'ємною густиною `ρ(r)` (наприклад, усередині дифузного провідного середовища або зарядженого діелектричного блоку), ми ділимо область на нескінченно малі елементи об'єму `dV`, кожен з яких містить точковий елементарний заряд `dq = ρ(r) dV`. Замінюючи суму інтегралом по всьому об'єму `V_vol`, де існує заряд, отримуємо:

```
W = ½ · ∫_{V_vol} ρ(r) · V(r) dV
```

Тут `V(r)` — електричний потенціал у точці `r`, створений усім об'ємним розподілом заряду `ρ`.

### Крок 3: Підстановка закону Гаусса у диференціальній формі

Згідно з диференціальною формою першого рівняння Максвелла (закон Гаусса для електростатичного поля у вакуумі):

```
∇ · E = ρ / ε₀   ⇒   ρ = ε₀ · (∇ · E)
```

Підставимо вираз для густини заряду `ρ` через дивергенцію напруженості поля `∇ · E` в об'ємний інтеграл енергії:

```
W = ½ · ε₀ · ∫_{V_vol} (∇ · E) · V dV
```

### Крок 4: Застосування векторної тотожності дивергенції

Використаємо відому формулу векторного аналізу для дивергенції добутку скалярної функції `V` на векторне поле `E`:

```
∇ · (V · E) = V · (∇ · E) + E · (∇ V)
```

Звідси виразимо підінтегральний добуток `V · (∇ · E)`:

```
V · (∇ · E) = ∇ · (V · E) − E · (∇ V)
```

Згадаємо фундаментальний зв'язок між напруженістю потенціального електричного поля та градієнтом скалярного потенціалу: `E = − ∇ V`. Замінюючи градієнт `∇ V = − E`, отримуємо скалярний квадрат поля:

```
− E · (∇ V) = − E · (− E) = E²
```

Підставивши це назад у векторну тотожність, маємо підінтегральну формулу:

```
V · (∇ · E) = ∇ · (V · E) + E²
```

### Крок 5: Розділення інтеграла та теорема Остроградського — Ґаусса

Підставимо отриманий вираз в інтеграл енергії `W`:

```
W = ½ · ε₀ · ∫_{V_vol} ∇ · (V · E) dV + ½ · ε₀ · ∫_{V_vol} E² dV
```

За теоремою Остроградського — Ґаусса (теорема про дивергенцію), перший об'ємний інтеграл від дивергенції `∇ · (V · E)` перетворюється на поверхневий інтеграл по замкненій межі `S`, яка охоплює об'єм `V_vol`:

```
∫_{V_vol} ∇ · (V · E) dV = ∮_{S} (V · E) · dA
```

### Крок 6: Доведення зникання поверхневого інтеграла на нескінченності

Розширимо область інтегрування `V_vol` на весь нескінченний простір, спрямувавши радіус замкненої сферичної поверхні `S` до нескінченності (`R → ∞`).

Проаналізуємо асимптотичну поведінку полів для будь-якої фінітної (обмеженої у просторі) системи зарядів на великих відстанях `R`:
1. Потенціал спадає як `V(R) ∝ 1 / R`.
2. Напруженість поля спадає як `E(R) ∝ 1 / R²`.
3. Площа поверхні сфери зростає як `A(R) = 4π R² ∝ R²`.

Оцінимо поверхневий інтеграл при `R → ∞`:

```
∮_{S} (V · E) · dA  ∝  (1 / R) · (1 / R²) · R² = 1 / R
```

При спрямуванні радіуса сфери до нескінченності `R → ∞` значення виразу `1 / R` прямує до нуля. Отже, поверхневий інтеграл по нескінченно віддаленій сфері строго дорівнює нулю:

```
lim_{R → ∞} ∮_{S} (V · E) · dA = 0
```

Це доводить, що вся енергія взаємодії без залишку зосереджена в об'ємному інтегралі другого доданка.

### Крок 7: Остаточний вираз для густини енергії

Оскільки поверхневий інтеграл зникає, в інтегралі енергії залишається тільки другий доданок, обчислений по всьому нескінченному простору `ℝ³`:

```
W = ½ · ε₀ · ∫_{ℝ³} E² dV
```

Підінтегральний вираз дає **об'ємну густину енергії електричного поля** `w_e`:

```
w_e = ½ · ε₀ · E²          (у вакуумі, Дж/м³)
```

Для середовища з лінійним діелектричним відгуком, де вектор електричної індукції дорівнює `D = ε₀ εᵣ E`, вивід аналогічно дає:

```
w_e = ½ · (D · E) = ½ · ε₀ εᵣ · E²      (у діелектрику, Дж/м³)
```

Цей вивід строгим математичним шляхом доводить точну еквівалентність опису енергії через джерела зарядів й потенціали `½ ∫ ρ V dV` та опису через локалізоване у кожній точці простору електричне поле `½ ∫ E · D dV`.
