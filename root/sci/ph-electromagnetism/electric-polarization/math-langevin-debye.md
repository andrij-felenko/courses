# 🧮 Статистична теорія поляризації полярних діелектриків: виведення функції Ланжевена та формули Дебая

Цей математичний розрахунок будує точний статистичний вивід макроскопічного вектора поляризації `P` для полярних діелектриків із постійними дипольними моментами молекул `p_0`. У цьому математичному описі ми послідовно кроками виведемо функцію Ланжевена `L(x)`, знайдемо її лінійне та кубічне наближення для слабких та помірних полів, обчислимо термодинамічний потенціал Вільній енергії Гільмгольца, виведемо аналітичну формулу електрокалоричного ефекту та одержимо підсумкове узагальнене співвідношення Дебая — Клаузіуса — Моссотті.

---

### 1. Потенційна енергія диполя та канонічний розподіл Больцмана

Розглянемо макроскопічний об'єм полярного газу або рідини, що складається з `N` однакових жорстких молекул в одиниці об'єму. Кожна з цих молекул володіє власним постійним електричним дипольним моментом `p_0`. Середовище перебуває у стані термодинамічної рівноваги за абсолютної температури `T` під дією локального електричного поля `E_loc`.

Потенційна енергія `U` окремого диполя, вектор моменту якого орієнтовано під кутом `θ` до напрямку локального електричного поля `E_loc`, визначається скалярним добутком вектором диполя та вектора поля:

```
U(θ) = - p_0 · E_loc · cos(θ)           [потенційна енергія диполя в полі]
```

Згідно з фундаментальними принципами статистичної механіки Гіббса та Больцмана, ймовірність `dP(θ)` знайти вектор дипольного моменту молекули у вузькому тілесному куті `dΩ = 2·π · sin(θ) · dθ` пропорційна больцманівському експоненціальному множнику:

```
dP(θ) = C · exp(- U(θ) / (k_B · T)) · sin(θ) · dθ
      = C · exp(p_0 · E_loc · cos(θ) / (k_B · T)) · sin(θ) · dθ     [розподіл Больцмана]
```

де `k_B = 1.380649 · 10⁻²³` Дж/К — стала Больцмана, а `C` — нормувальна стала статистичної суми. Нормувальна стала розраховується з умови повного охоплення всіх можливих орієнтацій у просторі: сумарна ймовірність інтеграла по кутах від `θ = 0` до `θ = π` повинна строго дорівнювати одиниці.

### 2. Обчислення статистичної суми Z(x) та вільної енергії Гільмгольца

Обчислимо одночастинкову статистичну суму орієнтацій `Z(x)` шляхом інтегрування больцманівського множника по поверхні одиничної сфери:

```
Z(x) = ∫₀^π exp(x · cos(θ)) · 2·π · sin(θ) dθ     [статистична сума орієнтацій]
```

де для спрощення математичного запису введено безрозмірний параметр Ланжевена `x`. Цей параметр описує безпосереднє співвідношення між орієнтувальною енергією електричного поля та дезорієнтувальною кінетичною енергією хаотичного теплового руху:

```
x = p_0 · E_loc / (k_B · T)             [безрозмірний параметр Ланжевена]
```

Виконаємо математичну заміну змінної інтегрування: нехай `u = cos(θ)`. Тоді диференціал `du = - sin(θ) dθ`. Межі інтегрування змінюються від `u = 1` (при `θ = 0`) до `u = -1` (при `θ = π`).

Перепишемо знаменник `Z` (статистичну суму по орієнтаціях):

```
Z = 2 · π · ∫₋₁¹ exp(x · u) du           [інтегрування по куту]
  = (2 · π / x) · [exp(x) - exp(-x)]    [інтегрування експоненти]
  = (4 · π / x) · sinh(x)               [вираження через гіперболічний синус]
```

Вільна енергія Гільмгольца `F` систем з `N` орієнтованих диполів в одиниці об'єму визначається через логарифм статистичної суми:

```
F(T, E) = - N · k_B · T · ln(Z(x))
        = - N · k_B · T · [ ln(4 · π) + ln(sinh(x)) - ln(x) ]   [вільна енергія]
```

Знання вільної енергії дає змогу обчислити всі термодинамічні характеристики середовища, включаючи макроскопічну поляризованість `P = - ∂F / ∂E` та ентропію системи `S = - ∂F / ∂T`.

### 3. Обчислення середнього значення проекції дипольного моменту

Середнє значення проекції дипольного моменту на напрямок зовнішнього електричного поля `⟨p_z⟩` визначається як інтегральне усереднення величини `p_0 · cos(θ)` по всіх просторових кутах сфери:

```
⟨p_z⟩ = p_0 · ⟨cos(θ)⟩
```

Запишемо точний математичний вираз для середнього косинуса `⟨cos(θ)⟩` через відношення відповідних інтегралів:

```
⟨cos(θ)⟩ = ∫₀^π cos(θ) · exp(x · cos(θ)) · sin(θ) dθ / ∫₀^π exp(x · cos(θ)) · sin(θ) dθ
```

Позначимо чисельник цього дробу як інтеграл `I_num`:

```
I_num = ∫₋₁¹ u · exp(x · u) du           [інтеграл чисельника]
```

Зауважимо, що підінтегральний вираз у чисельнику можна одержати через диференціювання статистичної суми `Z(x)` за безрозмірним параметром `x`:

```
I_num = dZ / dx                         [диференціювання за параметром x]
      = (d / dx) [ (4 · π / x) · sinh(x) ]
      = (4 · π / x) · cosh(x) - (4 · π / x²) · sinh(x)     [результат інтегрування]
```

### 4. Точне виведення функції Ланжевена L(x)

Знайдемо відношення чисельника `I_num` до знаменника `Z` для остаточного розрахунку середнього косинуса орієнтації `⟨cos(θ)⟩`:

```
⟨cos(θ)⟩ = I_num / Z
         = [ (4 · π / x) · cosh(x) - (4 · π / x²) · sinh(x) ] / [ (4 · π / x) · sinh(x) ]
         = (cosh(x) / sinh(x)) - (1 / x)    [ділення кожного доданка]
         = coth(x) - (1 / x)             [функція Ланжевена L(x)]
```

Цю математичну функцію в класичній теоретичній фізиці називають **функцією Ланжевена** `L(x)`:

```
L(x) = coth(x) - (1 / x)                 [класична функція Ланжевена]
```

Отже, точний вираз для середнього дипольного моменту однієї полярної молекули вздовж напрямку поля має вигляд:

```
⟨p_z⟩ = p_0 · L(x)                      [середній дипольний момент молекули]
```

Аналіз асимптотичної поведінки функції Ланжевена `L(x)` показує дві фізичні границі:
1. При `x → 0` (слабке поле або дуже висока температура) функція `L(x) → 0`. Поляризація прямує до нуля через дезорієнтувальний тепловий рух.
2. При `x → ∞` (нескінченно сильне поле або абсолютний нуль температур) гіперболічний котангенс `coth(x) → 1`, а `1/x → 0`, тому `L(x) → 1`. Це відповідає стану повного насичення, коли всі молекулярні диполі вишикувалися строго паралельно до векторів поля.

### 5. Розклад Тейлора для слабких полів та кубічна нелінійність

Розкладемо функцію Ланжевена `L(x)` у степеневий ряд Тейлора для випадку помірних електричних полів або кімнатних температур, коли орієнтувальна енергія поля значно менша за енергію теплового хаосу (`x << 1`).

Запишемо розклади гіперболічних функцій `sinh(x)` та `cosh(x)` в околі нуля до членів п'ятого порядку включно:

```
sinh(x) = x + x³ / 6 + x⁵ / 120 + O(x⁷)   [розклад гіперболічного синуса]
cosh(x) = 1 + x² / 2 + x⁴ / 24 + O(x⁶)    [розклад гіперболічного косинуса]
```

Підставимо ці розклади у вираз для гіперболічного котангенса `coth(x) = cosh(x) / sinh(x)`:

```
coth(x) = (1 / x) + x / 3 - x³ / 45 + 2·x⁵ / 945 - ...   [асимптотичний розклад coth(x)]
```

Віднімемо доданок `1 / x` та знайдемо степеневий розклад функції Ланжевена `L(x)`:

```
L(x) = coth(x) - (1 / x)
     = x / 3 - x³ / 45 + 2·x⁵ / 945 - ...   [ряд Тейлора для функції Ланжевена]
```

Перший лінійний член `x / 3` визначає класичний лінійний відгук діелектрика у слабких полях, а другий член `- x³ / 45` описує першу кубічну нелінійність поляризації (ефект насичення та електрооптичний ефект Керра).

Підставивши вираз для параметра `x = p_0 · E_loc / (k_B · T)` у перше лінійне наближення, одержуємо середня проекція дипольного моменту в слабкому полі:

```
⟨p_z⟩ = p_0 · (x / 3)
      = p_0² · E_loc / (3 · k_B · T)     [середній дипольний момент у слабкому полі]
```

### 6. Обчислення макроскопічної орієнтаційної поляризації

Макроскопічний вектор поляризації `P_orient` визначається як сумарний дипольний момент одиниці об'єму для `N` молекул:

```
P_orient = N · ⟨p_z⟩
         = N · p_0² · E_loc / (3 · k_B · T)   [орієнтаційна поляризація середовища]
```

Оригінальна орієнтаційна поляризованість однієї молекули `α_orient` визначається з рівняння `⟨p_z⟩ = α_orient · E_loc`. Звідси випливає знаменита **формула Дебая** для орієнтаційної поляризованості:

```
α_orient = p_0² / (3 · k_B · T)          [орієнтаційна поляризованість Дебая]
```

### 7. Електрокалоричний ефект у полярних діелектриках

Орієнтація диполів у зовнішньому електричному полі зменшує кутовий безпорядок системи, що призводить до падіння ентропії середовища. 

Обчислимо орієнтаційну частину ентропії `S_orient` шляхом диференціювання вільної енергії `F` за температурою:

```
S_orient = - ∂F / ∂T
         = N · k_B · [ ln(4 · π · sinh(x) / x) - x · L(x) ]   [ентропія орієнтованих диполів]
```

При адіабатичному (швидкому) прикладненні електричного поля `ΔE` ентропія системи повинна залишатися постійною (`ΔS_total = 0`). Зміна орієнтаційної ентропії компенсується зміною теплоємності кристалічної ґратки або рідини, що спричиняє зміну температури середовища `ΔT`:

```
ΔT = - (T / C_p) · (∂P / ∂T)_E · ΔE     [електрокалоричний ефект]
```

Оскільки для полярних діелектриків `∂P / ∂T < 0` (поляризація спадає при нагріванні), при прикладненні поля матеріал розігрівається (`ΔT > 0`), а при швидкому знятті поля — охолоджується (`ΔT < 0`). Це явище називають **електрокалоричним ефектом** і використовують у твердотільних кріогенних охолоджувачах без застосування фреону.

### 8. Узагальнене співвідношення Дебая — Клаузіуса — Моссотті

Повна молекулярна поляризованість середовища `α_total` складається з пружної деформаційної частини `α_def = α_e + α_i` (електронна + іонна поляризації, які не залежать від температури) та температурно-залежної орієнтаційної частини `α_orient`:

```
α_total = α_def + p_0² / (3 · k_B · T)   [повна молекулярна поляризованість]
```

Підставивши узагальнену поляризованість `α_total` у формулу Клаузіуса — Моссотті, одержуємо повне рівняння Дебая:

```
(ε_r - 1) / (ε_r + 2) = (N / (3 · ε_0)) · [ α_e + α_i + p_0² / (3 · k_B · T) ]
```

Це рівняння дає змогу експериментально розділити внесок різних мікроскопічних механізмів:
1. Якщо побудувати графік залежності виміряної величини `(ε_r - 1) / (ε_r + 2)` від оберненої температури `1/T`, кут нахилу одержаної прямої дає змогу обчислити квадрат постійного дипольного моменту молекули `p_0²`.
2. Відрізок, що відтинається прямою на осі ординат при `1/T → 0` (при нескінченно високій температурі, коли орієнтація повністю зруйнована тепловим хаосом), визначає сумарну деформаційну поляризованість `α_e + α_i`.
