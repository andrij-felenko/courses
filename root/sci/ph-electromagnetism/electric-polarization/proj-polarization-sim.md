# ⚙️ Чисельне моделювання поляризаційного відгуку та діелектричної релаксації

Цей проєктний модуль присвячений практичній чисельній імітації часового та частотного відгуку діелектричного середовища на довільну зовнішню електричну напругу. Тут реалізовано чисельний розв'язок диференціального рівняння діелектричної релаксації Дебая, що описує перехідні процеси увімкнення електричного поля, та обчислення спектра комплексної діелектричної проникності `ε*(ω) = ε'(ω) - i · ε''(ω)` через розклади Фур'є.

---

### 1. Фізична та математична модель релаксації

Динаміка орієнтаційної поляризації `P(t)` у полярному діелектрику описується лінійним релаксаційним рівнянням першого порядку Дебая:

```
dP(t) / dt = - (P(t) - P_eq(E(t))) / τ    [рівняння діелектричної релаксації Дебая]
```

де `τ` — характерний час релаксації диполів (час, за який поляризація зменшується в `e ≈ 2.718` раза після вимкнення зовнішнього поля), а `P_eq(E(t))` — миттєве рівноважне значення поляризації за формулою Ланжевена або лінійним наближенням:

```
P_eq(E(t)) = ε_0 · χ_stat · E(t)          [статична рівноважна поляризація]
```

При накладанні гармонічного зовнішнього поля `E(t) = E_0 · cos(ω · t)` усталений розв'язок для поляризації дає комплексну діелектричну проникність:

```
ε'(ω) = ε_inf + (ε_s - ε_inf) / (1 + ω² · τ²)        [дійсна частина проникності]
ε''(ω) = (ε_s - ε_inf) · ω · τ / (1 + ω² · τ²)       [уявна частина (втрати)]
```

Розробка чисельних симуляторів діелектричного відгуку є критично важливою для сучасної мікроелектроніки, проєктування високочастотних коаксіальних ліній, розрахунку нагріву біологічних тканин у радіочастотній гіпертермії та моделювання багатошарових керамічних конденсаторів.

### 2. Чисельні схеми інтегрування релаксаційного рівняння

Для чисельного розв'язання рівняння Дебая у часовій області виконують дискретизацію розрахункового інтервалу за часом із постійним кроком `dt`. Нехай `P[k]` — значення вектора поляризації на кроці `k`, а `E[k]` — напруженість електричного поля в момент часу `t_k = k · dt`.

Розглянемо порівняльний аналіз трьох чисельних схем інтегрування:

#### Явнорізницева схема Ейлера
Апроксимуючи першу похідну за часом `dP / dt` за допомогою правої різницевої схеми `(P[k+1] - P[k]) / dt`, одержуємо рекурентне співвідношення для обчислення поляризації на наступному часовому кроці `P[k+1]`:

```
(P[k+1] - P[k]) / dt = (P_eq(E[k]) - P[k]) / τ

P[k+1] = P[k] + (dt / τ) · (P_eq(E[k]) - P[k])    [явнорізницева схема Ейлера]
```

Явна схема Ейлера є простою у програмуванні та вимагає мінімуму арифметичних операцій. Проте вона має обмеження щодо числової стійкості: якщо обраний крок по часу перевищує подвійний час релаксації (`dt > 2 · τ`), чисельний розв'язок розходиться із виникненням нефізичних осциляцій. Для забезпечення стійкості вимагається суворе дотримання умови `dt << τ`.

#### Неявна схема Ейлера
Для усунення обмежень стійкості правосторонню частину рівняння обчислюють на новому часовому кроці `k+1`:

```
(P[k+1] - P[k]) / dt = (P_eq(E[k+1]) - P[k+1]) / τ

P[k+1] = (P[k] + (dt / τ) · P_eq(E[k+1])) / (1 + dt / τ)   [неявна схема Ейлера]
```

Неявна схема є абсолютно чисельно стійкою при будь-якому кроці `dt > 0`, що дає змогу швидко проходити тривалі ділянки стаціонарного поля без ризику накопичення помилок.

#### Точна аналітична дискретна схема
Оскільки рівняння Дебая на кожному окремому кроці `[t_k, t_k + dt]` при припущенні постійності поля `E[k]` є лінійним диференціальним рівнянням першого порядку, його можна інтегрувати аналітично строго:

```
P[k+1] = P_eq(E[k]) + (P[k] - P_eq(E[k])) · exp(- dt / τ)    [точна дискретна схема]
```

Точна аналітична схема забезпечує абсолютну точність збігу з фізичною теорією при будь-яких співвідношеннях між кроком по часу `dt` та часом релаксації `τ`. Вона повністю усуває похибки апроксимації похідної і є ідеальним вибором для побудови високоточних програмних модулів.

### 4. Комплексний частотний аналіз та спектри Кола — Кола

У практичному матеріалознавстві експериментальні дані діелектричної спектроскопії часто відхиляються від ідеальної монорелаксаційної моделі Дебая. У реальних полімерах, пористих кераміках та біологічних мембранах існує не один час релаксації `τ`, а широкий розподіл часів релаксації `g(τ)`.

Для опису таких розширених спектрів поглинання використовують емпіричне узагальнене рівняння Кола — Кола (*Cole-Cole equation*):

```
ε*(ω) = ε_inf + (ε_s - ε_inf) / (1 + (i · ω · τ)^(1 - α))    [рівняння Кола — Кола]
```

де `α` (`0 ≤ α < 1`) — параметр розширення спектра релаксації. При `α = 0` рівняння Кола — Кола строго збігається з класичною формулою Дебая.

Побудова діаграми Кола — Кола (параметричного графіка уявної частини `ε''` від дійсної частини `ε'`) для ідеального дебаївського середовища дає точне півколо з центром на осі абсцис:

```
                  ε'' (Втрати)
                     ^
         (ε_s - ε_inf)/2 ┼       ,---.
                     │      /     \
                     │     /       \
                     └────+─────────+───────> ε'
                        ε_inf      ε_s
```

Радіус півкола дорівнює `(ε_s - ε_inf) / 2`, а вершина півкола відповідає критичній частоті релаксації `ω_max = 1 / τ`. У випадку реальних полімерів із розширеним спектром Кола — Кола центр півкола опускається нижче осі абсцис на кут `α · π / 2`.

### 5. Практичний аналіз результатів та застосування у моделюванні

Аналіз обчислених чисельних даних дає змогу зробити наступні фізичні та інженерні висновки:

1. **Часова інерційність релаксаційного відгуку:** При імпульсному скачку напруженості поля вектор поляризації `P(t)` досягає величини `63.2%` (`1 - 1/e`) від свого статичного рівноважного значення через час `t = τ`. Для досягнення `99%` від рівноважного значення поляризації вимагається час близько `4.6 · τ`.
2. **Частотний максимум втрат у мікрохвильовому діапазоні:** На резонансній частоті `f_max = 1 / (2·π·τ) ≈ 19.4` ГГц (для дистильованої води при 25 °C) уявна частина комплексної проникності `ε''(ω)` досягає свого абсолютного максимуму. На частоті побутових мікрохвильових печей (2.45 ГГц) уявна частина `ε''` становить близько `12.0`, що забезпечує інтенсивний розігрів води за рахунок в'язкого тертя обертальних диполів під дією змінної напруженості поля.
3. **Обчислювальна складність та оптимізація:** Застосування неявних та точних аналітичних дискретних схем дає змогу виконувати симуляцію діелектричної релаксації у реальному часі без втрати чисельної стійкості, що є критично важливим при розробці САПР для моделювання НВЧ-пристроїв та планарних багатошарових конденсаторів.

Чисельне моделювання поляризаційного відгуку є незамінним інструментом при розробці НВЧ-компонентів, розрахунку антенних покриттів та оптимізації високочастотних конденсаторів.
