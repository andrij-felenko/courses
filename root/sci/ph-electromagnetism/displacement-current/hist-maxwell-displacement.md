# 📜 Історія відкриття струму зміщення та механічної моделі ефіру Максвелла

У середині XIX століття електродинаміка перебувала у стані роздробленого набору емпіричних законів. Експерименти Майкла Фарадея продемонстрували, що зміна магнітного поля породжує електричний струм, але зворотний зв'язок вважався виключно прерогативою рухомих електричних зарядів: закон Ампера стверджував, що джерелом магнітного поля є лише струм провідності. У 1861–1865 роках шотландський фізик Джеймс Клерк Максвелл (James Clerk Maxwell) зробив теоретичний прорив, додавши до рівнянь поля доданок струму зміщення. Це доповнення не лише усунуло внутрішню математичну суперечність класичної електродинаміки, а й уперше об'єднало оптику, електрику та магнетизм у єдину теорію електромагнітного поля.

---

## 1. Парадокс закону Ампера й логічний глухий кут теорії 1860-х років

До робіт Максвелла фундаментальним законом магнетостатики був закон циркуляції Ампера, розроблений Андре-Марі Ампером (André-Marie Ampère) та сформульований у диференціальній формі Жозефом Ліувіллем та Жозефом Фур'є:

```
∇ × H = J
```

де `H` — вектор напруженості магнітного поля, а `J` — густина струму провідності (рух вільних носіїв заряду, таких як електрони у металі).

Однак у математичному апараті векторного аналізу існує фундаментальна тотожність: дивергенція ротора будь-якого векторного поля завжди тотожно дорівнює нулю (`∇ · (∇ × H) = 0`). Застосувавши операцію дивергенції до обидвох частин закону Ампера, фізики отримали вимогу:

```
∇ · J = 0
```

Ця рівність означає, що струм провідності `J` мусить бути строго незмінним уздовж будь-якого замкненого контуру, а силові лінії струму не можуть мати ні початку, ні кінця. Для стаціонарних кіл постійного струму ця умова виконувалася бездоганно. Проте розгляд звичайного кола зі змінним струмом та конденсатором призводив до нерозв'язного парадоксу.

Під час заряджання або розряджання конденсатора по дротах протікає реальний струм провідності `J ≠ 0`. Але у проміжку між пластинами конденсатора носії заряду відсутні, тому густина струму провідності строго дорівнює нулю (`J = 0`). Якщо натягнути воображаєму відкриту поверхню на контур навколо провідника так, щоб вона проходила через проміжок між пластинами, то потік струму крізь неї виявиться нульовим, і закон Ампера передбачить відсутність магнітного поля. Якщо ж натягнути плоску поверхню, яка перетинає дріт, потік струму дорівнюватиме `I`, і закон передбачить наявність магнітного поля. 

Виникала катастрофічна суперечність: циркуляція магнітного поля вздовж одного й того самого контуру давала два різні значення залежно від вибору геометричної поверхні. Крім того, закон збереження заряду описується рівнянням безперервності:

```
∇ · J + ∂ρ/∂t = 0
```

де `ρ` — об'ємна густина електричного заряду. При нестаціонарних процесах `∂ρ/∂t ≠ 0`, тому `∇ · J ≠ 0`. Закон Ампера у своїй початковій формі суперечив фундаментальному закону збереження електричного заряду.

## 2. Гідродинамічна та механічна модель Максвелла: вихрові комірки й «паразитні шестерні»

На відміну від сучасного абстрактного опису полів через векторні оператори, Максвелл доходив своїх відкриттів через побудову наочних механічних моделей фізичного вакууму (ефіру). У своїй фундаментальній праці «Про фізичні лінії сили» (*On Physical Lines of Force*), опублікованій у чотирьох частинах у журналі *Philosophical Magazine* протягом 1861–1862 років, Максвелл запропонував деталізовану механічну модель ефіру.

Максвелл уявив магнітне поле як сукупність обертальних молекулярних вихорів у пружному середовищі. Вісь обертання кожного вихору збігалася з напрямком векторів магнітної індукції `B`, а кутова швидкість обертання була пропорційна величині поля.

```
       Модель вихрових комірок ефіру Максвелла (1861 р.)

   [Вихор 1: ↻ ]  ← (Кулька-прокладка: ↺) →  [Вихор 2: ↻ ]
   (Магнітне поле)    (Електричний заряд)     (Магнітне поле)
```

Щоб суміжні вихори могли обертатися в один бік без взаємного гальмування за рахунок тертя, Максвелл ввів між ними шар дрібних пружних частинок — «проміжних коліщаток» (idle wheels), які могли як обертатися на місці, так і поступально переміщатися. 

1. **Поступальний рух частинок-прокладок** відповідав струму провідності `J`. Коли частинки вільно пересувалися між вихорами у провіднику, це створювало електричний струм, який змушував сусідні вихори обертатися, генеруючи магнітне поле.
2. **Пружна деформація комірок ефіру** відповідала електричному полю. У діелектриках та вакуумі частинки-прокладки не могли вільно переміщатися, але під дією прикладеної електричної сили вони зміщувалися зі своїх положень рівноваги, деформуючи пружні стінки вихорів.

Під час зміни прикладеного електричного поля зміщення цих частинок змінювалося в часі (`∂D/∂t`). Оскільки зміщення частинок призводило до їхнього короткочасного руху, це викликало обертальну деформацію суміжних вихорів ефіру. Механічний рух зміщених частинок створював такий самий обертальний момент на вихорах, як і їхнє повне поступальне переміщення у провіднику!

Отже, Максвелл дійшов висновку: **зміна пружної деформації ефіру (зміна електричного поля) еквівалентна електричному струму й мусить породжувати таке саме магнітне поле, як і звичайний струм провідності.** Цей додатковий потік пружного руху Максвелл назвав **струмом зміщення** (*displacement current*).

## 3. Математичне оформлення та велике об'єднання оптико-електромагнітних явищ

Додавши струм зміщення `J_d = ∂D/∂t` до закону Ампера, Максвелл отримав узагальнене рівняння циркуляції магнітного поля, яке зараз називається рівнянням Максвелла-Ампера:

```
∇ × H = J + ∂D/∂t
```

Взявши дивергенцію від обидвох частин узагальненого рівняння, отримуємо:

```
∇ · (∇ × H) = ∇ · J + ∇ · (∂D/∂t) = 0
```

Змінивши порядок диференціювання в другому доданку та застосувавши закон Гаусса для електричного зміщення (`∇ · D = ρ`), Максвелл одержав:

```
∇ · J + ∂/∂t (∇ · D) = ∇ · J + ∂ρ/∂t = 0
```

Суперечність зникла! Узагальнене рівняння Максвелла повністю узгоджувалося з рівнянням безперервності та законом збереження заряду при будь-яких швидких динамічних процесах.

У 1865 році у праці «Динамічна теорія електромагнітного поля» (*A Dynamical Theory of the Electromagnetic Field*) Максвелл відкинув конкретні механічні деталі зі шестернями й вихорами, зберігши лише математичні зв'язки полів. Об'єднавши чотири фундаментальні рівняння для вакууму (`J = 0`, `ρ = 0`), він вивів хвильове рівняння для електричного поля:

```
∇²E − μ₀·ε₀ · (∂²E / ∂t²) = 0
```

Це рівняння описувало хвилю, яка поширюється у просторі зі фазовою швидкістю:

```
v = 1 / √(μ₀ · ε₀)
```

Підставивши значення магнітної сталої `μ₀` та електричної сталої `ε₀`, виміряні раніше у лабораторних дослідах Вільгельмом Вебером (Wilhelm Weber) та Рудольфом Кольраушем (Rudolph Kohlrausch) у 1856 році, Максвелл отримав теоретичне значення швидкості хвилі:

```
v ≈ 310 740 км/с
```

Це значення вражаючо збігалося зі швидкістю світла, виміряною Арманом Фізо (Armand Fizeau) у 1849 році за допомогою обертового зубчастого колеса (`315 300 км/с`). У грудні 1864 року Максвелл написав свої знамениті слова:

> *«Узгодженість результатів свідчить про те, що світло та магнетизм є проявами однієї й тієї самої речовини, і що світло є електромагнітним збуренням, яке поширюється через поле відповідно до електромагнітних законів.»*

## 4. Сприйняття сучасниками та експериментальне підтвердження Герца

Відкриття струму зміщення було настільки революційним, що більшість провідних фізиків другої половини XIX століття сприйняли його з великою недовірою. Видатні вчені того часу, зокрема Вільям Томсон (лорд Кельвін) та Людвіг Больцман, критикували концепцію Максвелла за гіпотетичний характер та відсутність прямого експериментального підтвердження струму зміщення у порожнечі. У континентальній Європі панувала концепція дальнодії Вебера-Неймана, яка взагалі не потребувала поняття поля чи струму зміщення.

Ситуація докорінно змінилася у 1886–1888 роках, коли німецький фізик Генріх Герц (Heinrich Hertz) у серії блискучих експериментів у Карлсруе сконструював перший високочастотний осцилятор та передавач електромагнітних хвиль. Герц експериментально довів існування електромагнітних хвиль у вільному просторі, виміряв їхню швидкість, довжину, явища відбивання, заломлення та поляризації.

Оскільки у вільному просторі між передавачем і приймачем Герца були відсутні будь-які носії заряду (`J = 0`), випромінювання й поширення електромагнітних хвиль відбувалося **виключно завдяки струму зміщення** `J_d = ε₀ · (∂E/∂t)`. Без доданого Максвеллом струму зміщення електромагнітні хвилі існувати не можуть: зміна магнітного поля породжує вихрове електричне поле, а зміна електричного поля породжує вихрове магнітне поле, утворюючи самопідтримну хвилю. 

Досліди Герца стали остаточним триумфом теорії Максвелла й відкрили еру радіозв'язку, бездротових технологій та сучасної фізики поля.

## 5. Доказ очевидності: чому струм зміщення є реальним фізичним полем

Протягом десятиліть після відкриття Максвелла тривала дискусія: чи є струм зміщення лише математичною формальністю («фіктивним струмом»), доданою для збереження симетрії рівнянь, чи це реальний фізичний процес?

Експерименти Хендріка Лоренца та подальший розвиток квантової електродинаміки показали, що струм зміщення складається з двох фізично відмінних частин:

```
J_d = ∂D/∂t = ε₀ · (∂E/∂t) + ∂P/∂t
```

1. **Струм поляризації `∂P/∂t`** у речовині є абсолютно реальним зсувом зв'язаних електричних зарядів (електронів у атомах та іонів у ґратці діелектрика). Цей струм супроводжується фізичним переміщенням маси й заряду на мікроскопічні відстані.
2. **Струм зміщення вакууму `ε₀ · (∂E/∂t)`** не пов'язаний із рухом жодних носіїв чи речовини. Проте він є реальним у тому сенсі, що **створює тотожне магнітне поле**, що й звичайний струм у металевому провіднику. Вимірювання магнітного поля всередині вакуумного конденсатора під час його заряджання повністю підтвердили вирази Максвелла: вихрове магнітне поле існує в порожнечі там, де протікає лише струм зміщення.

Таким чином, гіпотеза Максвелла 1861 року перетворилася на один із найміцніших фундаментів сучасної фізичного картини світу.
