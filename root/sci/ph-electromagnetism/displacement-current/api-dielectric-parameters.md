# 📋 Параметри діелектричних середовищ та частотні характеристики струму зміщення

Цей довідник містить фундаментальні фізико-технічні характеристики діелектричних матеріалів, математичні формули для розрахунку реактивних і активних складових полів, таблиці інженерних параметрів матеріалів, частотні границі переходу між струмом провідності `J_c` та струмом зміщення `J_d`, аналіз релаксаційних явищ Дебая та Крамерса-Кроніга, а також практичні інженерні рекомендації для проектування високочастотних друкованих плат, мікрохвильових ліній передачі та нанорозмірних напівпровідникових структур.

---

## 1. Комплексна діелектрична проникність та тангенс кута втрат

У реальних матеріальних середовищах під дією змінного електромагнітного поля виникають як струми зміщення (зумовлені часовою зміною електричного поля та релаксаційною поляризацією речовини), так і малі струми провідності (зумовлені наявністю вільних носіїв заряду чи мікроскопічних витоків).

Густина повного струму в матеріалі описується диференціальним виразом:

```
J_total = J_c + J_d = σ · E + ε₀ · ε_r · (∂E / ∂t)
```

Для гармонічного поля `E(t) = E₀ · e^(i·ω·t)` часова похідна дорівнює `∂E/∂t = i·ω·E`. Вираз для густини повного струму набуває виду:

```
J_total = (σ + i · ω · ε₀ · ε_r) · E = i · ω · ε₀ · ε* · E
```

де `ε*` — **комплексна відносна діелектрична проникність** матеріалу:

```
ε* = ε' − i · ε''
```

1. **Дійсна частина комплексної проникності (`ε' = ε_r`):** Описує здатність діелектричного середовища накопичувати реактивну енергію електричного поля за рахунок поляризації. Вона визначає ємність конденсаторів та фазову швидкість поширення електромагнітних хвиль у середовищі (`v = c₀ / √ε'`).
2. **Уявна частина комплексної проникності (`ε''`):** Описує дисипацію (активні втрати) енергії електромагнітного поля в середовищі. Вона об'єднує як питому провідність вільних носіїв `σ`, так і високочастотні релаксаційні втрати діелектричного тертя `ε_loss`:
   ```
   ε'' = (σ + ω · ε_loss) / (ω · ε₀)
   ```

### Тангенс кута діелектричних втрат (`tan δ`)

Співвідношення між амплітудами активного струму провідності (що викликає нагрів матеріалу) та реактивного струму зміщення (що накопичує енергію поля) визначає **тангенс кута втрат** (`loss tangent` або `dissipation factor, Df`):

```
tan δ = |J_c| / |J_d| = σ / (ω · ε₀ · ε_r) = ε'' / ε'
```

Фізична класифікація середовищ за величиною `tan δ`:
- Якщо `tan δ ≪ 1` (`|J_d| ≫ |J_c|`) — середовище є **високоякісним діелектриком**. У ньому повністю домінує струм зміщення, а згасання хвиль є нехтовно малим.
- Якщо `tan δ ≫ 1` (`|J_c| ≫ |J_d|`) — середовище є **хорошим провідником**. У ньому домінує струм провідності, а електромагнітна хвиля швидко згасає на глибині скін-шару.

## 2. Частотна дисперсія діелектриків: модель релаксації Дебая та співвідношення Крамерса-Кроніга

Діелектрична проникність більшості реальних матеріалів не є постійною величиною, а залежить від частоти прикладеного електричного поля `ω`. Ця залежність називається **дисперсією діелектричної проникності**.

При низьких частотах усі механізми поляризації (електронна, іонна, дипольна та міжшарова) встигають повністю сформуватися за період коливання поля. При зростанні частоти важкі молекулярні диполі перестають встигати за змінами поля, що викликає спад дійсної частини `ε'(ω)` та виникнення піку втрат уявної частини `ε''(ω)`.

### Релаксаційна модель Дебая

Для полярних діелектриків (наприклад, води, спиртів, рідких полімерів) залежність комплексної проникності від частоти описується рівнянням Дебая:

```
ε*(ω) = ε_∞ + (ε_s − ε_∞) / (1 + i · ω · τ)
```

де:
- `ε_s` — статична діелектрична проникність при низьких частотах (`ω → 0`).
- `ε_∞` — високочастотна оптична проникність (`ω → ∞`), зумовлена лише електронною поляризацією.
- `τ` — характерний час релаксації дипольних молекул (с).

Розділивши дійсну та уявну частини рівняння Дебая, отримуємо формули для обчислення накопичення та дисипації енергії:

```
ε'(ω) = ε_∞ + (ε_s − ε_∞) / (1 + ω² · τ²)
ε''(ω) = (ε_s − ε_∞) · ω · τ / (1 + ω² · τ²)
```

Максимум діелектричних втрат `ε''` досягається строго на резонансній частоті релаксації `ω_res = 1 / τ`. На цій частоті струм зміщення відстає за фазою від напруженості електричного поля на `45°`, що призводить до максимального виділення теплоти у середовищі.

### Дисперсійні співвідношення Крамерса-Кроніга

Дійсна `ε'(ω)` та уявна `ε''(ω)` частини комплексної діелектричної проникності не є незалежними функціями. Вони зв'язані між собою фундаментальними інтегральними співвідношеннями Крамерса-Кроніга, які випливають із принципу причинності (наслідок не може передувати причині):

```
ε'(ω) − 1 = (2 / π) · P ∫₀^∞ [ (x · ε''(x)) / (x² − ω²) ] dx
ε''(ω)    = − (2 · ω / π) · P ∫₀^∞ [ (ε'(x) − 1) / (x² − ω²) ] dx
```

де `P` означає головне значення інтеграла за Коші.

Практичне значення співвідношень Крамерса-Кроніга полягає у тому, що будь-яка зміна проникності діелектрика `ε'` з частотою неминуче супроводжується активними втратами енергії `ε''`. Неможливо створити середовище зі сильною дисперсією без виникнення діелектричних втрат.

## 3. Гранична частота релаксаційного переходу `f_trans` (`J_d = J_c`)

Частота, на якій густина струму зміщення дорівнює густині струму провідності (`tan δ = 1`, `|J_d| = |J_c|`), називається **граничною частотою переходу середовища**:

```
f_trans = σ / (2 · π · ε₀ · ε_r)
```

```
               Характерні зони домінування струмів за частотою

      f < f_trans                              f > f_trans
  ┌───────────────────────────────┬───────────────────────────────┐
  │  Панує струм провідності J_c  │   Панує струм зміщення J_d    │
  │  (Поле квазістаціонарне)      │   (Електромагнітні хвилі)     │
  └───────────────────────────────┴───────────────────────────────┘
                                  ▲
                             f = f_trans
```

Значення `f_trans` кардинально різниться для різних матеріалів:
- Для **металевих провідників (мідь, алюміній)** питома провідність є величезною (`σ ≈ 6e7` См/м), тому гранична частота прямує до оптичного та ультрафіолетового діапазонів (`f_trans ~ 10¹⁸` Гц). При всіх практичних радіочастотах у металах домінує струм провідності.
- Для **діелектриків (FR-4, тефлон, кераміка)** провідність є нехтовно малою (`σ ~ 10⁻¹² .. 10⁻¹⁶` См/м), тому гранична частота є ближчою до часток герца (`f_trans < 0.01` Гц). Усередині діелектриків при всіх робочих частотах повністю домінує струм зміщення.

## 5. Хвильовий імпеданс та провідність скін-шару у провідниках

У провідних середовищах (металах), де панує струм провідності `J_c ≫ J_d`, електромагнітна хвиля згасає за експоненційним законом `e^(−z / δ)`. Глибина проникнення поля (товщина скін-шару `δ`) обчислюється за формулою:

```
δ = √( 2 / (ω · μ · σ) )
```

Для міді на частоті 50 Гц товщина скін-шару становить `δ ≈ 9.3` мм, на частоті 1 МГц — `δ ≈ 66` мкм, а на частоті 10 ГГц — лише `δ ≈ 0.66` мкм.

Хвильовий імпеданс провідного середовища має комплексну природу зі рівними дійсною та уявною частинами:

```
η_metal = √( (i · ω · μ) / σ ) = (1 + i) · √( (ω · μ) / (2 · σ) ) = (1 + i) / (σ · δ)
```

Цей імпеданс визначає поверхневий опір металевих стінок хвилеводів та екранних оболонок кабелів при високих частотах.

## 6. Інженерні формули та прикладні розрахунки

### 1. Розрахунок паразитного струму зміщення у лініях друкованих плат

Для двох паралельних сигнальних доріжок чи шарів друкованої плати площею `A`, віддалених на товщину діелектрика `d`:

```
I_d = C · (dV / dt) = (ε₀ · ε_r · A / d) · (dV / dt)
```

- `I_d` — імпульсний струм зміщення (А)
- `dV/dt` — швидкість наростання фронту напруги (В/с)

**Практичний розрахунок:** Швидкісний перепад напруги у шині PCIe Gen5 з `dV/dt = 20` В/нс (`20e9` В/с) протікає по доріжці друкованої плати, що має ємність міжшарової перехресної наводки `C = 3` пФ.

```
I_d = 3e-12 Ф · 20e9 В/с = 0.06 А = 60 мА !
```

Цей струм зміщення величиною 60 мА протікає крізь склотекстоліт FR-4 безпосередньо у сусідню лінію даних, породжуючи значні наводки (crosstalk) та збої у зчитуванні сигналів.

### 2. Розрахунок теплових втрат (дисипація теплоти від струму зміщення)

Виділення питомої теплової потужності у діелектрику (Вт/м³) за наявності змінного електричного поля з амплітудою `E₀` та частотою `ω`:

```
P_V = (1/2) · ω · ε₀ · ε_r · tan δ · E₀²
```

Ця формула описує високочастотний нагрів діелектриків у мікрохвильових печах (на частоті 2.45 ГГц для дипольних молекул води `tan δ ≈ 0.12`), а також визначає гранично допустиму реактивну потужність ВЧ-конденсаторів.

## 7. Проектні рекомендації для розробників високочастотних систем

1. **Вибір діелектрика для високошвидкісних планок (High-Speed PCB Stackup):**
   - Для сигналів із частотами понад 5 ГГц стандартний склотекстоліт FR-4 (`tan δ ≈ 0.02`) спричиняє неприпустимо високе загасання струму зміщення. Необхідно застосовувати спеціалізовані високочастотні ламінати (Rogers RO4003C / Megtron 6 з `tan δ < 0.003`).
2. **Мінімізація витоків струму зміщення за допомогою захисних кілець (Guard Rings):**
   - У високоімпедансних підсилювачах (наприклад, у прецизійних електрометрах та фотодіодних підсилювачах) навколо чутливої доріжки викладається захисне кільце, на яке подається потенціал, рівний потенціалу сигналу (`V_guard = V_in`). Оскільки різниця потенціалів `ΔV = 0`, то `dV/dt = 0`, і паразитивний струм зміщення `I_d = C · (dV/dt)` стає строго нульовим.
3. **Використання діелектриків з високою проникністю (High-k Dielectrics) у КМОН-технологіях:**
   - Для запобігання квантово-механічному тунелюванню носіїв заряду (струму провідності) крізь надто тонкий підзатворний діелектрик `SiO₂` (`d < 1.2` нм) у сучасних процесорах (Intel, TSMC) застосовують оксид гафнію `HfO₂` (`ε_r ≈ 25`). Це дозволяє збільшити фізичну товщину діелектрика при збереженні високої ємності затвора та високого струму зміщення керування.
