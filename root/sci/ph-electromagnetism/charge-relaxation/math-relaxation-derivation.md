# 🧮 Математичний вивід рівняння релаксації заряду та міжфазних граничних умов

Математичний апарат теорії релаксації заряду базується на диференціальних рівняннях макроскопічної електродинаміки суцільних середовищ. У цій вставці наведено строгий вивід рівняння згасання об'ємного заряду, математичне доведення точного збереження повного заряду системи при міграції носіїв на поверхню, строгий вивід динаміки міжфазного накопичення заряду Максвелла-Вагнера, розклад для анізотропних середовищ та аналіз коефіцієнтів екранування у напівпровідниках.

## 1. Строгий вивід дифрівняння релаксації об'ємного заряду

Розглянемо однорідне, ізотропне середовище з питомою електричною провідністю `σ = const` та відносною діелектричною проникністю `ε_r = const`. Абсолютна діелектрична проникність середовища дорівнює `ε = ε_r · ε₀`.

У вихідний момент часу `t = 0` у декартовій області `V` задано довільний розподіл об'ємної густини вільного заряду `ρ(r, 0) = ρ₀(r)`.

Основою виводу є три фундаментальні співвідношення електродинаміки:

1. **Диференціальний закон Ома:**
   ```
   J(r, t) = σ · E(r, t)
   ```
2. **Диференціальна форма закону Гаусса:**
   ```
   ∇ · E(r, t) = ρ(r, t) / ε
   ```
3. **Диференціальне рівняння неперервності струму (закон збереження заряду):**
   ```
   ∇ · J(r, t) + ∂ρ(r, t) / ∂t = 0
   ```

Підставимо вектор густини струму `J` із закону Ома в рівняння неперервності:

```
∇ · (σ · E) + ∂ρ / ∂t = 0
```

Оскільки середовище є однорідним (`σ = const`), скалярний множник `σ` виноситься за оператор дивергенції `∇ ·`:

```
σ · (∇ · E) + ∂ρ / ∂t = 0      [властивість лінійності дивергенції]
```

Застосуємо теорему Гаусса, замінивши `∇ · E` на `ρ / ε`:

```
σ · (ρ / ε) + ∂ρ / ∂t = 0      [підстановка рівняння Гаусса]
```

Перегрупуємо доданки для отримання диференціального рівняння з відокремлюваними змінними:

```
∂ρ / ∂t = - (σ / ε) · ρ
```

Поділимо обидві частини на `ρ` (припустивши `ρ ≠ 0`) та проінтегруємо по часу від `0` до `t`:

```
∫ (1 / ρ) dρ = - ∫ (σ / ε) dt
ln(ρ(r, t)) - ln(ρ₀(r)) = - (σ / ε) · t      [інтегрування]
ln(ρ(r, t) / ρ₀(r)) = - t / τ_m
```

де введено позначення максвеллівського часу релаксації `τ_m`:

```
τ_m = ε / σ = (ε_r · ε₀) / σ
```

Потенціюючи обидві частини рівняння, отримуємо остаточний закон часової еволюції об'ємного заряду у кожній точці середовища:

```
ρ(r, t) = ρ₀(r) · exp(-t / τ_m)
```

Цей розв'язок показує, що згасання заряду в кожній точці є суворо експоненціальним, а просторовий профіль `ρ₀(r)` зберігає свою форму, змінюючись лише за амплітудою.

## 2. Узагальнення для анізотропних середовищ (Тензорна провідність)

У кристалічних провідниках та монокристалах напівпровідників питома провідність та діелектрична проникність є тензорами другого рангу `σ̂` та `ε̂`.

Закон Ома та рівняння Гаусса в індексній нотації мають вигляд:

```
J_i = σ_ij · E_j
D_i = ε_ij · E_j
```

Рівняння неперервності у координатному розкладі:

```
∂J_i / ∂x_i + ∂ρ / ∂t = 0  ⇒  σ_ij · (∂E_j / ∂x_i) + ∂ρ / ∂t = 0
```

Якщо головні осі тензора провідності `σ_ij` та тензора діелектричної проникності `ε_ij` збігаються, то відношення компонент по головних осях `(x, y, z)` задає три анізотропні часи релаксації:

```
τ_x = ε_xx / σ_xx,   τ_y = ε_yy / σ_yy,   τ_z = ε_zz / σ_zz
```

У цьому випадку початковий сферично симетричний розподіл заряду `ρ₀(r)` під час релаксації деформується в еліпсоїдальний, оскільки вздовж осі з найменшим часом `τ_min` заряд розсмоктується значно швидше.

## 3. Доведення збереження повного заряду та утворення поверхневої густини

Виникає фундаментальне питання: якщо об'ємна густина заряду `ρ(r, t)` експоненціально прямує до нуля у кожній внутрішній точці середовища, чи не порушується при цьому закон збереження електричного заряду?

Доведемо математично, що повний заряд об'єму `Q_total` зберігається строго, переходячи у поверхневий шар на межі `S`.

Розглянемо замкнений об'єм `V` з межею `S`. Повний заряд усередині об'єму в момент часу `t`:

```
Q_bulk(t) = ∫_V ρ(r, t) dV = exp(-t / τ_m) · ∫_V ρ₀(r) dV = Q₀ · exp(-t / τ_m)
```

Швидкість зміни об'ємного заряду в об'ємі `V`:

```
dQ_bulk / dt = - (1 / τ_m) · Q_bulk(t) = - (σ / ε) · Q_bulk(t)
```

З іншого боку, згідно з теоремою Остроградського-Гаусса, повний струм `I_out`, що витікає через поверхню `S`, дорівнює:

```
I_out(t) = ∮_S J · dS = ∮_S (σ · E) · dS = σ · ∮_S E · dS
```

За теоремою Гаусса в інтегральній формі, потік вектора `E` через замкнену поверхню `S` дорівнює витоку об'ємного заряду:

```
∮_S E · dS = Q_bulk(t) / ε
```

Підставляючи цей потік у вираз для струму:

```
I_out(t) = σ · (Q_bulk(t) / ε) = (σ / ε) · Q_bulk(t) = (1 / τ_m) · Q_bulk(t)
```

Порівнюючи з часовою похідною `dQ_bulk / dt`, бачимо:

```
dQ_bulk / dt + I_out(t) = 0
```

Струм `I_out(t)`, прибуваючи на поверхню `S`, формує поверхневу густину заряду `σ_surf(r, t)`. Диференціальне рівняння балансу на поверхні має вигляд:

```
∂σ_surf / ∂t = J_n = σ · E_n
```

Інтегруючи за часом від `0` до `∞`:

```
σ_surf(r, ∞) = ∫₀^∞ J_n(r, t) dt = J_n(r, 0) · ∫₀^∞ exp(-t / τ_m) dt = J_n(r, 0) · τ_m
```

Інтегруючи поверхневу густину по всій межі `S`, отримуємо:

```
Q_surface(∞) = ∮_S σ_surf(r, ∞) dS = ∫₀^∞ I_out(t) dt = Q₀ · ∫₀^∞ (1 / τ_m) · exp(-t / τ_m) dt = Q₀
```

Таким чином, строго доведено:

```
Q_bulk(t) + Q_surface(t) = Q₀ = const
```

Об'ємний заряд не знищується, а повністю переноситься струмом провідності у безкінечно тонкий поверхневий шар.

## 4. Вивід міжфазної релаксації Максвелла-Вагнера

Розглянемо плоскопаралельну систему з двох плоских шарів матеріалів (Середовище 1 та Середовище 2), розміщених між електродами під постійною зовнішньою напругою `V₀`.

- Шару 1 притаманні товщина `d₁`, проникність `ε₁` та провідність `σ₁`.
- Шару 2 притаманні товщина `d₂`, проникність `ε₂` та провідність `σ₂`.

Позначимо через `E₁(t)` та `E₂(t)` напруженості полів у шарах, а через `σ_f(t)` — густину вільного заряду на межі розділу шарів.

Граничні умови макроскопічної електродинаміки на межі розділу:

1. **Неперервність потенціалу (повна напруга):**
   ```
   E₁(t) · d₁ + E₂(t) · d₂ = V₀
   ```
2. **Стрибок нормальної компоненти електричної індукції:**
   ```
   D₂(t) - D₁(t) = σ_f(t)  ⇒  ε₂ · E₂(t) - ε₁ · E₁(t) = σ_f(t)
   ```
3. **Баланс струмів на межі розділу:**
   ```
   ∂σ_f / ∂t = J₁(t) - J₂(t) = σ₁ · E₁(t) - σ₂ · E₂(t)
   ```

Виразимо поля `E₁` та `E₂` через `V₀` та `σ_f`. З системи рівнянь (1) та (2):

```
E₁(t) = (ε₂ · V₀ - d₂ · σ_f(t)) / (ε₁ · d₂ + ε₂ · d₁)
E₂(t) = (ε₁ · V₀ + d₁ · σ_f(t)) / (ε₁ · d₂ + ε₂ · d₁)
```

Підставимо `E₁` та `E₂` у рівняння балансу струмів `∂σ_f / ∂t`:

```
∂σ_f / ∂t = σ₁ · [ (ε₂ · V₀ - d₂ · σ_f) / Δ ] - σ₂ · [ (ε₁ · V₀ + d₁ · σ_f) / Δ ]
```

де `Δ = ε₁ · d₂ + ε₂ · d₁`. Звівши подібні доданки:

```
∂σ_f / ∂t + [ (σ₁ · d₂ + σ₂ · d₁) / Δ ] · σ_f = [ (σ₁ · ε₂ - σ₂ · ε₁) / Δ ] · V₀
```

Це лінійне неоднорідне диференціальне рівняння першого порядку щодо `σ_f(t)`.

Звідси визначаємо характерний **час міжфазної релаксації Максвелла-Вагнера `τ_MW`**:

```
τ_MW = (ε₁ · d₂ + ε₂ · d₁) / (σ₁ · d₂ + σ₂ · d₁)
```

У стаціонарному граничному стані (`t → ∞`, `∂σ_f / ∂t = 0`) густина накопиченого міжфазного заряду дорівнює:

```
σ_f(∞) = V₀ · (σ₁ · ε₂ - σ₂ · ε₁) / (σ₁ · d₂ + σ₂ · d₁)
```

У частинному випадку при однакових товщинах `d₁ = d₂`:

```
τ_MW = (ε₁ + ε₂) / (σ₁ + σ₂)
```

Якщо відношення параметрів матеріалів одинакове (`ε₁ / σ₁ = ε₂ / σ₂`), тобто `τ₁ = τ₂`, то `σ_f(∞) = 0` — міжфазний заряд не накопичується, оскільки струми провідності в обох шарах строго збалансовані напруженостями полів з першої ж секунди.

## 5. Двокомпонентний розклад: просторова розсіяність та довжина Дебая

У напівпровідниках та електролітах поряд із дрейфовим струмом носіїв `J_drift = σ · E` діє дифузійний струм `J_diff = -D_n · ∇ρ`, де `D_n` — коефіцієнт дифузії.

Рівняння релаксації з урахуванням дифузії набуває вигляду рівняння Фоккера-Планка / Дрейфу-Дифузії:

```
∂ρ / ∂t = D_n · ∇²ρ - (σ / ε) · ρ
```

Шукаючи розв'язок у вигляді просторових гармонік `ρ(r, t) = ρ_k · exp(i · k · r - t / τ_k)`, отримуємо спектральний час релаксації:

```
1 / τ_k = (1 / τ_m) + D_n · k² = (1 / τ_m) · (1 + k² · λ_D²)
```

де `λ_D` — **дебаївський радіус екранування**:

```
λ_D = √(D_n · τ_m) = √((ε · k_B · T) / (q² · n₀))
```

Цей вивід показує: флуктуації заряду з малими просторовими масштабами (`k · λ_D ≫ 1`, хвилі з довжиною менше дебаївського радіуса) розсмоктуються за рахунок дифузії значно швидше за звичайний максвеллівський час `τ_m`. Для великомасштабних розподілів (`k · λ_D ≪ 1`) домінує максвеллівський дрейфовий час `τ_m = ε / σ`.
