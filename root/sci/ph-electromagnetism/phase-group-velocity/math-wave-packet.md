# 🧮 Математичний аналіз хвильового пакета та хроматичної дисперсії

Строгий математичний опис фазової та групової швидкості будується на теорії хвильових пакетів, перетворенні Фур'є та розкладі частотної залежності хвильового числа у ряд Тейлора. Однорідна плоска хвиля, що поширюється вздовж осі `x` у лінійному середовищі, описується комплексним виразом:

```
E(x, t) = Re { A · exp(j·(ω·t - k·x)) }
```

де `ω` — колова частота, `k` — хвильове число, а `j` — уявна одиниця. Загальний розв'язок для довільного хвильового імпульсу є суперпозицією (інтегралом Фур'є) монохроматичних плоских хвиль з амплітудним спектром `A(ω)`:

```
E(x, t) = (1 / 2π) · ∫_{-∞}^{+∞} A(ω) · exp(j·(ω·t - k(ω)·x)) dω
```

## Суперпозиція двох гармонік та утворення біть

Розглянемо найпростіший випадок утворення хвильового пакета: інтерференцію двох монохроматичних хвиль однакової амплітуди `E_0` із близькими частотами `ω_1 = ω_0 + Δω` та `ω_2 = ω_0 - Δω`, яким відповідають хвильові числа `k_1 = k_0 + Δk` та `k_2 = k_0 - Δk`:

```
E(x, t) = E_0 · cos(ω_1·t - k_1·x) + E_0 · cos(ω_2·t - k_2·x)
```

Застосовуючи тригонометричну тотожність суми косинусів `cos α + cos β = 2 · cos((α - β)/2) · cos((α + β)/2)`, отримуємо:

```
α = ω_1·t - k_1·x = (ω_0 + Δω)·t - (k_0 + Δk)·x
β = ω_2·t - k_2·x = (ω_0 - Δω)·t - (k_0 - Δk)·x

(α - β) / 2 = Δω·t - Δk·x          [амплітудна огинаюча]
(α + β) / 2 = ω_0·t - k_0·x        [високочастотна несуча]
```

Підстановка дає підсумковий вираз для результуючої хвилі:

```
E(x, t) = [ 2·E_0 · cos(Δω·t - Δk·x) ] · cos(ω_0·t - k_0·x)
```

Цей результат описує амплітудно-модульовану хвилю. У ній можна чітко розрізнити дві швидкості:

1. **Фазова швидкість несучої `v_p`**: фіксує постійну фазу несучого коливання `ω_0·t - k_0·x = const`. Продиференціювавши за часом, маємо:

```
d(ω_0·t - k_0·x) / dt = 0
⇒ ω_0 - k_0 · (dx / dt) = 0
⇒ v_p = dx / dt = ω_0 / k_0
```

2. **Групова швидкість огинаючої `v_g`**: фіксує постійну фазу повільно мінливої огинаючої `Δω·t - Δk·x = const`:

```
d(Δω·t - Δk·x) / dt = 0
⇒ Δω - Δk · (dx / dt) = 0
⇒ v_g = dx / dt = Δω / Δk
```

У граничному переході для вузького частотного спектра (`Δω → 0`) відношення приростів перетворюється на першу похідну залежності `ω(k)`:

```
v_g = lim_{Δk → 0} (Δω / Δk) = dω / dk
```

## Розклад дисперсійного співвідношення у ряд Тейлора

Для довільного квазімонохроматичного хвильового пакета з центральною частотою `ω_0` розкладемо хвильове число `k(ω)` у ряд Тейлора в околі `ω_0`:

```
k(ω) = k(ω_0) + k'(ω_0)·(ω - ω_0) + (1/2)·k''(ω_0)·(ω - ω_0)² + (1/6)·k'''(ω_0)·(ω - ω_0)³ + ...
```

Позначимо коефіцієнти розкладу:

- `k_0 = k(ω_0)` — фазова константа на центральній частоті.
- `β_1 = k'(ω_0) = (dk / dω)|_{ω_0} = 1 / v_g` — величина, обернена до групової швидкості. Вона задає затримку огинаючої імпульсу на одиницю довжини шляху (вимірюється у секундах на метр, с/м).
- `β_2 = k''(ω_0) = (d²k / dω²)|_{ω_0}` — параметрична дисперсія групової швидкості (Group Velocity Dispersion, GVD; вимірюється у с²/м або пс²/км).
- `β_3 = k'''(ω_0) = (d³k / dω³)|_{ω_0}` — дисперсія третього порядку (Third-Order Dispersion, TOD; вимірюється у с³/м або пс³/км).

Підставимо розклад Тейлора першого порядку (`β_2 = 0`) у загальний інтеграл Фур'є:

```
E(x, t) = (1 / 2π) · ∫ A(ω) · exp(j·[ (ω·t - (k_0 + β_1·(ω - ω_0))·x ) ]) dω
```

Виносячи за знак інтеграла фазовий множник центральної частоти `exp(j·(ω_0·t - k_0·x))`, маємо:

```
E(x, t) = exp(j·(ω_0·t - k_0·x)) · [ (1 / 2π) · ∫ A(ω) · exp(j·(ω - ω_0)·(t - β_1·x)) dω ]
E(x, t) = exp(j·(ω_0·t - k_0·x)) · U(t - x / v_g)
```

де `U(t)` — початкова профільно-амплітудна функція огинаючої при `x = 0`. Цей вираз математично доводить: у першому наближенні дисперсії хвильовий пакет рухається як єдине ціле зі швидкістю `v_g = 1 / β_1` без зміни своєї амплітудної форми.

## Метод стаціонарної фази та асимптотика імпульсу

Для аналізу поширення хвильового пакета на великих відстанях `x >> λ` використовується метод стаціонарної фази (розроблений лордом Кельвіном). Розглянемо інтеграл:

```
E(x, t) = ∫ A(ω) · exp(j · Φ(ω; x, t)) dω
```

де фазова функція дорівнює `Φ(ω; x, t) = ω·t - k(ω)·x`.

Коли `x` та `t` великі, осциляції множника `exp(j · Φ)` стають надзвичайно швидкими, і взаємне гасіння сусідніх ділянок призводить до того, що інтеграл прямує до нуля скрізь, крім окілу точки стаціонарної фази `ω_s`, де похідна фази по частоті дорівнює нулю:

```
dΦ / dω = 0
⇒ d(ω·t - k(ω)·x) / dω = 0
⇒ t - (dk / dω)|_{ω_s} · x = 0
⇒ (dx / dt)_{st} = 1 / (dk / dω)|_{ω_s} = v_g(ω_s)
```

Це рівняння показує, що спостерігач, який перебуває у точці `x` в момент часу `t`, фіксує переважно ту спектральну гармоніку `ω_s`, групова швидкість якої задовольняє умові `v_g(ω_s) = x / t`. Таким чином, дисперсійне середовище просторово сортує («розкладає») спектральні складові імпульсу пропорційно їхнім груповим швидкостям.

## Точне інтегрування Гаусового пакета у другому порядку дисперсії

Якщо врахувати другий член розкладу `β_2 ≠ 0`, різні частотні складові всередині імпульсу починають рухатися з різними груповими швидкостями. Розглянемо Гаусів імпульс із початковою тривалістю `τ_0`:

```
U(0, t) = U_0 · exp(-t² / (2·τ_0²))
```

Спектр Фур'є цього імпульсу на вході `x = 0` є також гаусовим:

```
A(ω - ω_0) = U_0 · τ_0 · √(2π) · exp(- (ω - ω_0)² · τ_0² / 2)
```

Підставляючи цей спектр в інтеграл поширення з фазовим множником `exp(-j · (1/2) · β_2 · (ω - ω_0)² · x)`, отримуємо підінтегральний вираз:

```
E(x, t) = exp(j·(ω_0·t - k_0·x)) · (U_0 · τ_0 / √(2π)) · ∫ exp(-a·Ω² + j·b·Ω) dΩ
```

де позначено `Ω = ω - ω_0`, `a = (τ_0² / 2) + j · (1/2) · β_2 · x`, а `b = t - β_1·x`.

Використовуючи точну формулу інтеграла Ґаусса `∫_{-∞}^{+∞} exp(-a·Ω² + j·b·Ω) dΩ = √(π / a) · exp(-b² / (4a))`, після розділення дійсної та уявної частин маємо точну комплексну огинаючу на відстані `x`:

```
U(x, t) = U_0 · (τ_0 / √(τ_0² - j·β_2·x)) · exp( - (t - x/v_g)² / (2·(τ_0² - j·β_2·x)) )
```

Обчислюючи квадрат модуля амплітуди `|U(x, t)|²`, отримуємо еволюцію профілю інтенсивності:

```
|U(x, t)|² = U_0² · (τ_0 / τ(x)) · exp( - (t - x/v_g)² / τ(x)² )
```

де поточна тривалість імпульсу `τ(x)` зростає за гіперболічним законом:

```
τ(x) = τ_0 · √(1 + (x / L_D)²)
```

Тут `L_D` — дисперсійна довжина лінії, на якій тривалість імпульсу зростає у `√2` рази:

```
L_D = τ_0² / |β_2|
```

Коли `x >> L_D`, ширина імпульсу зростає лінійно з відстаню `τ(x) ≈ |β_2| · x / τ_0`. Еволюція фази також створює часовий чирп — лінійну зміну миттєвої частоти всередині пакета:

```
ω_inst(t) = ω_0 + d(arg U) / dt = ω_0 + ( β_2 · x / (τ_0⁴ + β_2²·x²) ) · (t - x/v_g)
```

## Дисперсія третього порядку (TOD) та асиметрія імпульсу

Коли робоча частота лежить поблизу точки нульової дисперсії (Zero Dispersion Wavelength, ZDW), де `β_2 = 0`, визначальним стає член третього порядку `β_3 = d³k / dω³`.

У цьому випадку диференціальне рівняння еволюції огинаючої набуває вигляду:

```
∂U / ∂z = (β_3 / 6) · (∂³U / ∂t³)
```

Розв'язок цього рівняння виражається через спеціальну функцію Ейрі `Ai(x)`:

```
U(z, t) ~ Ai( (t - z/v_g) / (3 · |β_3| · z / 2)^(1/3) )
```

На відміну від симетричного розпливання у другому порядку (`β_2`), дисперсія третього порядку призводить до різкої асиметрії імпульсу: на його хвості утворюються згасаючі осциляційні «хвилі» (Airy ringing), а основний пік імпульсу зміщується у часі.

## Дисперсія фононів у двоатомній кристалічній ґратці

В акустиці та фізиці твердого тіла дисперсія звукових хвиль (фононів) виникає внаслідок дискретної атомної структури речовини. Розглянемо 1D кристалічний ланцюжок з атомів двох мас `m` та `M`, з'єднаних пружинами жорсткості `K` з періодом ґратки `a`.

Дисперсійне співвідношення для фононів містить дві гілки — акустичну та оптичну:

```
ω² = (K / (m·M)) · [ (m + M) ± √((m + M)² - 4·m·M · sin²(k·a / 2)) ]
```

1. **Акустична гілка (знак мінус):** При довгих хвилях (`k → 0` або `λ >> a`):
   - `sin(k·a / 2) ≈ k·a / 2`.
   - `ω(k) ≈ a · √(K / (2·(m + M))) · k`.
   - Фазова й групова швидкості збігаються: `v_p = v_g = a · √(K / (2·(m + M)))`.
   Це звичайний бездисперсний звук у суцільному середовищі. На межі зони Бріллюена (`k = π / a`) групова швидкість падає до нуля: `v_g = dω / dk = 0` (виникає стояча хвиля).

2. **Оптична гілка (знак плюс):** При `k → 0` частота прямує до скінченного значення `ω_opt = √(2·K · (m + M) / (m·M))`.
   - Фазова швидкість прямує до нескінченності: `v_p = ω / k → ∞`.
   - Групова швидкість дорівнює нулю: `v_g = dω / dk → 0`.
   В оптичній гілці сусідні атоми коливаються у протифазі, тому енергія коливань залишається локалізованою в комірці ґратки й не переноситься у просторі.
