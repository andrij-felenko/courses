# ⚙️ Чисельне моделювання фазової та групової швидкості

При теоретичному вивченні хвильових процесів розрізнити рух окремих фазових гребнів та загальне переміщення огинаючої буває складно без наочної візуалізації або обчислювального експерименту. Чисельне моделювання дозволяє не лише простежити еволюцію хвильового пакета в часі та просторі, а й безпосередньо виміряти фазову `v_p` та групову `v_g` швидкості для різних типів дисперсійних середовищ (бездисперсного вакууму, хвилеводної плазми, середовища з хроматичною дисперсією другого порядку `β_2` та нелінійних солітонних структур).

## Ідея чисельного алгоритму та фізична математика

Моделювання будується на трьох доповнюючих алгоритмічних підходах, кожен із яких розкриває свій грань хвильової динаміки:

1. **Дискретне моделювання біть двох гармонік (`simulate_beats`).** Обумовлюється прямим обчисленням суми двох синусоїд із частотами `ω_1` та `ω_2` на просторовій сітці `x` для послідовних моментів часу `t`. Швидкість зміщення точки перетину нульового рівня несучої визначає фазову швидкість `v_p`, а швидкість зміщення локального максимуму амплітудної обвідної — групову швидкість `v_g`. Це дозволяє наочно побачити, як при `v_p > v_g` окремі гребені зароджуються на хвості обвідної, рухаються уперед крізь пакет і зникають на його передньому фронті.

2. **Спектральний метод швидкого перетворення Фур'є (FFT) для лінійного Гаусового імпульсу (`simulate_gvd_pulse`).** Початковий Гаусів імпульс у часовій або просторовій області переводиться у частотний спектр через FFT. Далі кожна гармоніка спектра множиться на оператор фазового набігу середовища `exp(-j · k(ω) · z)`, після чого обернене перетворення Фур'є (IFFT) повертає імпульс у просторову область на відстані `z`.

   Для хвилеводу або плазми дисперсійне співвідношення описується формулою:
   ```
   k(ω) = (1 / c) · √(ω² - ω_p²)
   ```
   Для нормальної хроматичної дисперсії другого порядку хвильове число апроксимується виразом:
   ```
   k(ω) = k_0 + (ω - ω_0) / v_g + (1 / 2) · β_2 · (ω - ω_0)²
   ```

   Математична частота в дискретному спектрі обчислюється через крок дискретизації за часом `dt` та кількість точок `n_pts`: `df = 2π / (n_pts · dt)`. Кожна частотна гармоніка набуває фазового зсуву `Φ(ω) = -0.5 · β_2 · ω² · z`.

3. **Спліт-степ метод Фур'є (Split-Step Fourier Method, SSFM) для оптичних солітонів (`simulate_soliton_ssfm`).** Для розв'язання нелінійного рівняння Шредінгера (NLSE), яке враховує сумісну дію дисперсії `β_2` та Керрівської нелінійності `γ`:
   ```
   j · (∂A / ∂z) = (β_2 / 2) · (∂²A / ∂T²) - γ · |A|² · A
   ```
   Диференціальний оператор розбивається на дисперсійний `D_hat = -j · (β_2 / 2) · ∂²/∂T²` та нелінійний `N_hat = j · γ · |A|²`. Крок по дистанції `h` виконується у три етапи: півкроку дисперсії у спектральному просторі, повний крок нелінійності у часовому просторі, і ще півкроку дисперсії у спектральному просторі (симетрична схема другого порядку точності `O(h²)`).

   Для фундаментального солітона `A(0, t) = sech(t)` точний період солітона дорівнює `Z_sol = (π / 2) · L_D = π · τ_0² / (2 · |β_2|)`. Чисельна симуляція підтверджує, що амплітудний профіль зберігає свою ширину й висоту на відстанях `z >> Z_sol`.

## Реалізація симуляції у програмі

Нижче наведено робочий програмний код моделювання біть, імпульсного розпливання та солітонної динаміки у двох варіантах: Python (із використанням обчислювальної бібліотеки `numpy`) та сучасний ідіоматичний C++20 (з використанням `std::vector` та `std::complex`).

У C++ варіанті реалізовано алгоритм швидкого перетворення Фур'є Кулі-Тьюкі (Cooley-Tukey FFT) з проріджуванням за часом для комплексних масивів розміру `2^N`. Програма автоматично обчислює теоретичні значення фазової `v_p` та групової `v_g` швидкостей, знаходить просторове положення максимуму огинаючої у часі, розраховує середньоквадратичну RMS-ширину імпульсу після проходження дисперсійного середовища, а також демонструє стійке солітонне поширення без розпливання.

Обидві версії коду виводять результати безпосередньо в консоль. У версії Python обчислення виконуються з використанням векторизованих масивів `numpy.ndarray`, а у версії C++ — із забезпеченням нульових додаткових виділень пам'яті у внутрішніх циклах обчислення.

## Фізичні пастки та обмеження чисельного моделювання

При проведений чисельного моделювання хвильових пакетів у дисперсійних середовищах виникає кілька типових обчислювальних пасток, які можуть спотворити результат і дати хибні фізичні висновки:

1. **Ефект накладання спектрів (Aliasing).** При високих значеннях параметру дисперсії `β_2` або великих дистанціях поширення `z` фазовий зсув сусідніх частотних дискретів перевищує `π` рад (`|β_2 · ω · Δω · z| > π`). Це призводить до хибного відбиття частотних компонент від країв обчислювальної сітки та утворення хибної високочастотної рябі. Для запобігання необхідно збільшувати кількість точок сітки `n_pts` та зменшувати крок дискретизації `dt`.
2. **Крайові періодичні умови FFT.** Оскільки дискретне перетворення Фур'є неявно припускає періодичність сигналу, розпливчастий хвіст Гаусового пакета при виході за праву межу часового вікна `t_max` з'являється з лівого краю `t_min`. Це імітує хибний «передвісник» хвилі. Щоб уникнути цього спотворення, розраховане часове вікно симуляції має бути як мінімум у 5–8 разів ширшим за початкову тривалість імпульсу `τ_0`.
3. **Градієнт фази та точність січки.** При прямому визначенні групової швидкості `v_g` за просторовим максимумом огинаючої дискретний крок сітки `dx` визначає граничну роздільну здатність вимірювання. Для підвищення точності без надмірного згущення січки застосовують параболічну або сплайнову інтерполяцію трьох сусідніх дискретів навколо локального максимуму.
4. **Консервація енергії (Норма збереження повної потужності).** Для перевірки стійкості чисельної схеми SSFM у кожній точці за дистанцією `z` необхідно контролювати збереження повної оптичної енергії `E_tot = ∫ |A(z, t)|² dt`. Відхилення `E_tot` від початкового значення свідчить про занадто великий крок за дистанцією `dz` або накопичення помилок округлення. При коректно обраних параметрах схема зберігає норму поля `E_tot` з точністю до `10^-6`.
