# 🧮 Математичний вивід кругового двозаломлення та формули Беккереля

Математичний апарат магнітооптичного обертання Фарадея ґрунтується на двох послідовних кроках: макроскопічному розкладі лінійно поляризованого світла на дві кругові моди та мікроскопічному розрахунку розщеплення їхніх показників заломлення під дією сили Лоренца на зв'язані електрони середовища.

## 1. Суперпозиція колових мод та геометрія кута обертання

Розглянемо плоску монохроматичну світлову хвилю з частотою `ω`, яка поширюється у прозорому середовищі вздовж осі `z`. Нехай у точці входу в середовище (`z = 0`) хвиля має лінійну поляризацію, а напрямок її електричного поля орієнтований суворо вздовж осі `x`:

```
E(0, t) = E₀ · x̂ · e^(-i·ω·t)
```

За законами векторної алгебри, будь-який лінійний орт `x̂` можна подати як точну математичну суперпозицію двох базисних векторів з коловою поляризацією — правоколового орта `e₊` (Right Circular Polarization, RCP) та лівоколового орта `e₋` (Left Circular Polarization, LCP):

```
x̂ = (1/2) · (e₊ + e₋)
де e₊ = x̂ + i·ŷ   [правоколова поляризаційна мода]
   e₋ = x̂ - i·ŷ   [лівоколова поляризаційна мода]
```

Фізичний зміст цього розкладу полягає у тому, що коливання вздовж однієї осі `x` можна уявити як результат синхронного обертання двох векторів однакової довжини, які крутяться у протилежні боки з однаковою кутовою швидкістю `ω`. У будь-який момент часу їхні `y`-компоненти взаємно гасяться, а `x`-компоненти додаються.

Під час проходження середовища довжиною `L` у поздовжньому магнітному полі `B₀ = B₀ · ẑ` кожна з колових мод відчуває власний показник заломлення середовища: `n₊` для правої моди та `n₋` для лівої моди. Внаслідок цього фазові швидкості поширення мод `v₊ = c / n₊` та `v₋ = c / n₋` виявляються різними. 

За час проходження товщини середовища `L` кожна мода накопичує свій фазовий набіг:

```
ϕ₊ = k₊ · L = (ω / c) · n₊ · L
ϕ₋ = k₋ · L = (ω / c) · n₋ · L
```

У точці виходу з середовища (`z = L`) сумарне електричне поле хвилі є суперпозицією двох зсунутих за фазою колових компонент:

```
E(L, t) = (E₀ / 2) · [ e₊ · e^(i·ϕ₊) + e₋ · e^(i·ϕ₋) ] · e^(-i·ω·t)
```

Винесемо середній фазовий множник `e^(i·(ϕ₊ + ϕ₋)/2)` за дужки:

```
E(L, t) = (E₀ / 2) · e^(i·(ϕ₊ + ϕ₋)/2) · [ e₊ · e^(i·Δϕ/2) + e₋ · e^(-i·Δϕ/2) ] · e^(-i·ω·t)
```

де `Δϕ = ϕ₊ - ϕ₋ = (ω · L / c) · (n₊ - n₋)` — повна різниця фазового набігу між правою й лівою коловими модами.

Перейдемо назад від базису колових ортів `e₊, e₋` до декартових компонент `x̂, ŷ`. Для цього розкриємо вираз під дужками:

```
e₊ · e^(i·Δϕ/2) + e₋ · e^(-i·Δϕ/2)
= (x̂ + i·ŷ) · e^(i·Δϕ/2) + (x̂ - i·ŷ) · e^(-i·Δϕ/2)      [підстановка ортів]
= x̂ · (e^(i·Δϕ/2) + e^(-i·Δϕ/2)) + i·ŷ · (e^(i·Δϕ/2) - e^(-i·Δϕ/2))
= 2 · [ x̂ · cos(Δϕ/2) - ŷ · sin(Δϕ/2) ]               [за формулами Ейлера]
```

Підставивши цей вираз у загальне поле хвилі, отримуємо:

```
E(L, t) = E₀ · e^(i·ϕ_avg) · [ x̂ · cos(Δϕ/2) - ŷ · sin(Δϕ/2) ] · e^(-i·ω·t)
```

де `ϕ_avg = (ϕ₊ + ϕ₋)/2` — середній фазовий зсув хвилі.

Отриманий вираз описує **лінійно поляризовану хвилю**, вектор напруженості якої утворений компонентами `E_x = E₀ · cos(Δϕ/2)` та `E_y = -E₀ · sin(Δϕ/2)`. Це означає, що початкова площина поляризації повернулася відносно осі `x` на кут `θ`:

```
θ = - Δϕ / 2 = (ω · L / (2 · c)) · (n₋ - n₊)
```

Виразивши кутову частоту світла `ω` через довжину хвилі у вакуумі `λ₀` за співвідношенням `ω = 2·π·c / λ₀`, маємо фундаментальну формулу для кута обертання Фарадея:

```
θ = (π · L / λ₀) · (n₋ - n₊)
```

Таким чином, макроскопічне обертання площини поляризації прямо пропорційне різниці показників заломлення для ліво- та правоколово поляризованих хвиль — явище, що називається **магнітним круговим двозаломленням**.

## 2. Класична динаміка електронного осцилятора під дією сили Лоренца

Розглянемо мікроскопічне походження різниці показників заломлення `(n₋ - n₊)`. За класичною електронною теорією Лоренца, прозорий діелектрик містить `N` зв'язаних атомних електронів у одиниці об'єму. Кожен електрон має масу `m_e`, модуль заряду `e` і зв'язаний з ядром квазіпружною силою з власною частотою коливань `ω₀`.

Нехай у середовищі поширюється світлова хвиля з електричним полем `E`, а вздовж осі `z` прикладено постійне магнітне поле `B₀ = B₀ · ẑ`. Рівняння руху електрона за другим законом Ньютона з урахуванням сили Лоренца має вигляд:

```
m_e · (d²r / dt²) + m_e · ω₀² · r = -e · E - e · ( (dr/dt) × B₀ )
```

де `r = (x, y, z)` — вектор зміщення електрона з положення рівноваги.

Розглянемо окремо випадок, коли світлова хвиля має колову поляризацію `E_±(t) = E₀ · (x̂ ± i·ŷ) · e^(-i·ω·t)`. Шукаємо вимушені коливання електрона у вигляді колового зсуву `r_±(t) = r₀_± · (x̂ ± i·ŷ) · e^(-i·ω·t)`.

Обчислимо першу та другу похідні від вектора зміщення `r_±` за часом:

```
dr_± / dt = -i · ω · r_±
d²r_± / dt² = -ω² · r_±
```

Обчислимо векторний добуток швидкості електрона `v = dr/dt` на магнітне поле `B₀ = B₀ · ẑ`:

```
(dr_± / dt) × B₀ = (-i · ω · r₀_±) · [ (x̂ ± i·ŷ) × ẑ ]
```

Зважаючи на векторні добутки декартових ортів `x̂ × ẑ = -ŷ` та `ŷ × ẑ = x̂`, отримуємо:

```
(x̂ ± i·ŷ) × ẑ = -ŷ ± i·x̂ = ± i · (x̂ ∓ i·ŷ) = ∓ i · (x̂ ± i·ŷ)
```

Підставляючи це назад у векторний добуток, маємо:

```
(dr_± / dt) × B₀ = (-i · ω · r₀_±) · [ ∓ i · (x̂ ± i·ŷ) ] = ∓ ω · B₀ · r_±
```

Тепер підставимо обчислені похідні та векторний добуток у вихідне рівняння руху електрона:

```
-m_e · ω² · r_± + m_e · ω₀² · r_± = -e · E_± ∓ e · ω · B₀ · r_±
```

Перенесемо член із магнітним полем у ліву частину рівняння й винесемо `m_e · r_±` за дужки:

```
m_e · [ ω₀² - ω² ∓ (e · B₀ / m_e) · ω ] · r_± = -e · E_±
```

Величина `ω_c = e · B₀ / m_e` являє собою **циклотронну частоту** (*cyclotron frequency*) вільного електрона у магнітному полі `B₀`. Заставивши це позначення, маємо:

```
m_e · [ ω₀² - ω² ∓ ω_c · ω ] · r_± = -e · E_±
```

Звідси знаходимо амплітуду вимушеного зміщення електрона під дією правої та лівої колових хвиль:

```
r_± = (-e / m_e) · E_± / (ω₀² - ω² ∓ ω_c · ω)
```

Фізичний зміст знаку `∓` полягає у тому, що для правоколової хвиль сила Лоренца діє в одному напрямку з відновлювальною силою атома, збільшуючи ефективну жорсткість зв'язку, а для лівоколової — у протилежному напрямку, зменшуючи її. Резонансна частота атома розщеплюється на дві величини: `ω_res_± ≈ ω₀ ± ω_c / 2`.

## 3. Тензор діелектричної проникності та вивід формули Беккереля

Обчислене зміщення електронів `r_±` визначає макроскопічну поляризованість середовища `P_± = -N · e · r_±`. Діелектрична проникність середовища для кожної з двох мод дорівнює `ε_± = 1 + P_± / (ε₀ · E_±)`:

```
ε_± = 1 + (N · e² / (ε₀ · m_e)) / (ω₀² - ω² ∓ ω_c · ω)
```

Показник заломлення середовища пов'язаний із діелектричною проникністю співвідношенням `n_± = √ε_±`. За відсутності магнітного поля (`B₀ = 0`, `ω_c = 0`) маємо незбурений показник заломлення `n(ω)`:

```
n²(ω) - 1 = (N · e² / (ε₀ · m_e)) / (ω₀² - ω²)
```

Оскільки в оптичному діапазоні для реальних магнітних полів (декілька тесла) циклотронна частота `ω_c ≈ 10¹¹ рад/с` є на п'ять порядків меншою за частоту світла `ω ≈ 3×10¹⁵ рад/с` (`ω_c « ω`), розкладемо `n_±(ω)` у ряд Тейлора за малим параметром `ω_c`:

```
n_±(ω) ≈ n(ω) ± (dn / dω) · (ω_c / 2)
```

Віднявши один вираз від іншого, знаходимо різницю показників заломлення для двох колових мод:

```
n₋ - n₊ = (dn / dω) · ω_c = (dn / dω) · (e · B₀ / m_e)
```

Перейдемо від похідної за частотою `dn/dω` до похідної за довжиною хвилі у вакуумі `dn/dλ`. Скориставшись співвідношенням `ω = 2·π·c / λ`, маємо `dω = -(2·π·c / λ²) · dλ`, звідки:

```
dn / dω = - (λ² / (2·π·c)) · (dn / dλ)
```

Підставимо отриманий вираз у формулу для різниці показників заломлення:

```
n₋ - n₊ = - (e · B₀ / (2·π·c · m_e)) · λ² · (dn / dλ)
```

Тепер підставимо вираз для `(n₋ - n₊)` у макроскопічну формулу кута обертання `θ = (π · L / λ) · (n₋ - n₊)`:

```
θ = (π · L / λ) · [ - (e · B₀ / (2·π·c · m_e)) · λ² · (dn / dλ) ]
θ = - [ e / (2 · m_e · c) ] · λ · (dn / dλ) · B₀ · L
```

Порівнявши отримане співвідношення із феноменологічним законом Верде `θ = V · B₀ · L`, отримуємо класичну **формулу Беккереля** (*Becquerel's formula*, сформульовану Анрі Беккерелем у 1897 році):

```
V = - (e / (2 · m_e · c)) · λ · (dn / dλ)
```

Формула Беккереля демонструє глибокий фізичний факт: у діамагнітних речовинах стала Верде прямо пропорційна **оптичній дисперсії** середовища `dn/dλ`. Що сильніше середовище заломлює й розсіює світло за довжинами хвиль, тим сильнішим є в ньому магнітооптичне обертання Фарадея.

## 4. Чисельний розрахунок та межі класичного наближення

Проведемо числову перевірку формули Беккереля для двох практичних оптичних матеріалів.

### Приклад 1: Важке свинцеве скло (TF-3)
- Заряд електрона: `e = 1.602 × 10⁻¹十九 Кл`
- Маса електрона: `m_e = 9.109 × 10⁻³¹ кг`
- Швидкість світла: `c = 2.998 × 10⁸ м/с`
- Для свинцевого скла TF-3 на довжині хвилі `λ = 589 нм` (жовта лінія натрію) виміряна дисперсія складає `dn/dλ ≈ -6.8 × 10⁴ м⁻¹`.

Обчислимо сталу Верде за формулою Беккереля:

```
V_calc = [ 1.602×10⁻¹⁹ / (2 · 9.109×10⁻³¹ · 2.998×10⁸) ] · (589×10⁻⁹) · (6.8×10⁴)
       = [ 2.933 × 10² ] · 0.04005
       ≈ +11.7 рад / (Т·м)
```

Експериментально виміряна стала Верде для скла TF-3 становить `+25.5 рад/(Т·м)`. Збіг за порядком величини та знаком підтверджує, що в діамагнітному склі головним механізмом дійсно є сила Лоренца, а відхилення у 2 рази пояснюється тим, що класичний електронний осцилятор не враховує мультиплетну структуру електронних оболонок іона свинцю `Pb²⁺`.

### Приклад 2: Парамагнітний монокристал TGG (Tb₃Ga₅O₁₂)
Для кристала TGG на довжині хвилі `λ = 633 нм` дисперсія становить `dn/dλ ≈ -5.2 × 10⁴ м⁻¹`.
Обчислена за формулою Беккереля класична стала Верде складає `V_calc ≈ 9.65 рад/(Т·м)`.

Проте експериментальне значення для TGG дорівнює **`-134 рад/(Т·м)`** — воно перевищує класичний розрахунок більше ніж у 13 разів і має протилежний знак!

Це розходження пояснюється тим, що в парамагнітних іонах тербію (`Tb³⁺`) вирішальний внесок робить квантовомеханічне розщеплення електронних `f-d` переходів під дією внутрішньокристалічного поля та орієнтаційна поляризація спінів за розподілом Больцмана (парамагнетизм Ван Флека). Квантова теорія враховує ці переходи, даючи повне узгодження з експериментом.
