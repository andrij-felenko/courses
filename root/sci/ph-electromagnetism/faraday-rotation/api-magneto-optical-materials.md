# 📋 Характеристики магнітооптичних середовищ та специфікація ізоляторів

Цей довідник містить числові параметри магнітооптичних матеріалів (сталу Верде, показники заломлення, пробійні пороги, температурні коефіцієнти, коефіцієнти оптичного поглинання), порівняльні параметри якості та паспортні специфікації промислових ротаторів й оптичних ізоляторів Фарадея.

## 1. Фізико-хімічні параметри магнітооптичних середовищ

### Докладний фізико-технічний аналіз матеріальних класів:

1. **Тербій-галієвий гранат (TGG / Terbium Gallium Garnet):**
   Визнаний світовий стандарт для лазерних систем видимого та ближнього інфрачервоного діапазонів (`400 – 1100 нм`). Кристал володіє високою сталого Верде, низьким коефіцієнтом оптичного поглинання (`α < 0.0015 см⁻¹`) та відносно високою теплопровідністю (`4.5 Вт/(м·К)`). Завдяки цьому кристал TGG здатен працювати у лазерних пучках високої середньої потужності без виникнення паразитного ефекту теплової лінзи та деформації поляризації.

2. **Ітрій-залізистий гранат (YIG / Yttrium Iron Garnet):**
   Ферримагнітний монокристал кубічної симетрії, який є основою для телекомунікаційних оптичних ізоляторів діапазонів `1310 нм` (O-band) та `1550 нм` (C-band). Завдяки наявності спонтанної внутрішньої намагніченості підграток заліза `Fe³⁺` кристал YIG володіє гігантським піковим обертанням Фарадея. Це дозволяє використовувати елементи товщиною менше `1 мм`, які досягають повного магнітного насичення у слабких полях постійних магнітів (`~0.1 Тл`). У видимому спектральному діапазоні YIG є абсолютно непрозорим через потужні електронні переходи між розщепленими рівнями іонів заліза.

3. **Скло, леговане іонами тербію (MOS-10 / FR-5):**
   Аморфне боросилікатне або силікатне скло із високою концентрацією іонів `Tb³⁺` (до 30–40% за масою). Виступає економічною та виготовлюваною альтернативою монокристалу TGG при проектуванні оптичних пристроїв великої світлової апертури (понад `20–50 мм`). Оскільки виростити монокристал TGG великого діаметра без оптичних свищів та внутрішніх напружень надзвичайно складно, для крупноапертурних лазерних підсилювачів застосовують саме тербієве скло.

4. **Важке свинцеве скло (TF-3 / Heavy Lead Glass):**
   Класичний діамагнітний матеріал з додатною сталого Верде. Характеризується дуже низькою вартістю, гарною оптичною однорідністю та високим показником заломлення (`n ≈ 1.82`). Проте через малу величину сталої Верде використання свинцевого скла вимагає створення сильних магнітних полів (понад `2 Тл`) або використання значної довжини скляного бруска (понад `10 см`), що збільшує масу й габарити магнітної системи.

5. **Кадмій-марганець-телур (CdMnTe / Разбавленный магнитно-полупроводник):**
   Напівпровідниковий монокристал із гігантською парамагнітною сталою Верде у червоно-інфрачервоному діапазоні (`630 – 1500 нм`). Велике обертання досягається за рахунок сильної спін-обмінної взаємодії між електронами провідності/дірками та `d`-електронами іонів марганцю `Mn²⁺`. Застосовується у спеціалізованих ізоляторах для титаново-сапфірових та напівпровідникових лазерів.

## 2. Добротність магнітооптичних матеріалів (Figure of Merit)

Під час вибору матеріалу для оптичного ізолятора важливо враховувати не лише величину сталої Верде `V`, але й оптичні втрати на поглинання `α`. Для цього використовують **магнітооптичний коефіцієнт добротності** (*Figure of Merit*, `FOM`):

```
FOM = |V| / α   [рад / (Т · дБ) або град / (Т · дБ)]
```

Коефіцієнт добротності показує, який кут обертання площини поляризації удається отримати на один децибел втраченої оптичної потужності. Для ідеального ротатора Фарадея значення `FOM` має бути якомога вищим. 

Для монокристала TGG на довжині хвилі `1064 нм` добротність досягає рекордних `FOM > 300 град/(Т·дБ)`, тоді як для тербієвого скла вона становить близько `120 град/(Т·дБ)`.

## 3. Спектральна залежність сталої Верде V(λ)

Стала Верде суттєво залежить від довжини хвилі випромінювання `λ`. Для парамагнітних матеріалів (TGG, тербієве скло) у діапазоні прозорості діє емпірична формула однорезонансної дисперсії:

```
V(λ) = A / (λ² - λ₀²)
```

де `A` — приладова матеріальна константа, а `λ₀` — ефективна довжина хвилі електронного резонансного переходу в ультрафіолетовій області (для TGG `λ₀ ≈ 258 нм`, `A ≈ -4.56 × 10⁷ рад·нм²/(Т·м)`).

### Одиниці вимірювання сталої Верде та коефіцієнти перерахунку

У науково-технічній літературі використовуються різні системи одиниць для сталої Верде. Нижче наведено коефіцієнти перерахунку між ними:

```
1 рад / (Т · м) = 10⁻⁴ рад / (Гс · см)
1 мінута / (Е · см) ≈ 2.909 × 10⁻⁴ рад / (Гс · см) ≈ 2.909 рад / (Т · м)
1 рад / (Т · м) ≈ 0.3437 мінути / (Е · см)
```

## 4. Специфікація промислових оптичних ізоляторів Фарадея

Нижче наведено структуру технічного паспорта для двох класів нереципрокних оптичних пристроїв: вільнопросторових покаскадних ізоляторів для високопотужних лазерів та волоконно-оптичних мікроізоляторів для телекомунікацій.

## 5. Фактори деградації ізоляції та термооптичні пастки

При експлуатації реальних оптичних ізоляторів фактичний рівень ізоляції зворотного променя може відхилятися від теоретичних `40–60 дБ`. Основними фізичними причинами деградації є:

1. **Термооптична лінза та фотопружний ефект:**
   Під дією лазерного випромінювання високої потужності (понад `50–100 Вт`) навіть мізерне за залишкове поглинання кристала (`α ≈ 0.001 см⁻¹`) призводить до нагрівання центру кристала TGG відносно периферії. Градієнт температури викликає нерівномірне розширення та напруження, що створює термооптичну лінзу та термоіндуковане двозаломлення (*photoelastic birefringence*). Це спотворює поляризаційний стан світла й знижує рівень ізоляції до `20–25 дБ`.

2. **Неоднорідність магнітного поля:**
   Коли магнітна система створює неоднорідне поле вздовж перерізу світлового променя, крайові промені світлового пучка зазнають іншого кута обертання, ніж центральні. У результаті сумарна ізоляція інтегрованого лазерного пучка знижується.

3. **Якість противідбивальних покриттів (AR Coating):**
   Торці кристала TGG або YIG повинні бути покриті високоякісними багатошаровими противідбивальними покриттями. Залишкове відбиття від торців створює інтерференційні бліки, які повертаються в лазер в обхід поляризаторів.

## 6. Покроковий інженерний розрахунок ізолятора Фарадея

Під час проектування магнітооптичного обертача Фарадея під задану довжину хвилі `λ` розрахунок проводиться за такою алгоритмічною послідовністю:

1. **Розрахунок необхідного кута обертання `θ`:**
   - Для класичного оптичного ізолятора потрібен кут `θ = 45°` (`π/4 рад ≈ 0.7854 рад`).
   - Для обертача подвійного проходу (дзеркальний каскад): `θ = 22.5°` (`π/8 рад ≈ 0.3927 рад`).

2. **Обчислення необхідного добутку `(B · L)_req`:**
   ```
   (B · L)_req = θ / V(λ)
   ```
   *Приклад:* Для монокристала TGG на довжині хвилі `1064 нм` (`V = -38 рад/(Т·м)`):
   ```
   (B · L)_req = 0.7854 / 38 ≈ 0.0207 Т·м = 207 Т·мм
   ```

3. **Оптимізація геометрії кристала й магнітного поля:**
   - Якщо обрано кристал довжиною `L = 20 мм` (`0.02 м`), необхідна середня індукція магнітного поля вздовж осі становить `B = 0.0207 / 0.02 ≈ 1.035 Тл`.
   - Застосування конфігурації постійних магнітів NdFeB N52 (збірка Галбаха) дозволяє створити на осі апертури поле `B ≈ 1.1 – 1.3 Тл`. Це дає змогу зменшити довжину кристала `L` до `16–18 мм`, знижуючи власне поглинання світла кристалом і зменшуючи втрати на вставку до рівня `IL < 0.15 дБ`.
