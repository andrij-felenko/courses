# ⚙️ Чисельне моделювання індукції: метод дзеркальних зображень та розрахунок заряду

Обчислення параметрів електростатичної індукції у системах зі складною геометричною формою провідників часто унеможливлює отримання простих аналітичних формул у замкненому вигляді. У реальних інженерних задачах — розрахунку розподілу статики на корпусі літака, екрануванні чутливих ліній зв'язку на друкованій платі чи проектуванні високовольтних ізоляторів — застосовують чисельні методи математичного моделювання: метод межових елементів (*Boundary Element Method*, BEM), метод скінченних елементів (*FEM*) або метод чисельного інтегрування напруженостей поля.

Навіть для базісного випадку точкового заряду біля заземленої металевої площини чисельна дискретизація поверхні провідника та обчислення індукованого заряду через сумування за елементарними ділянками дозволяє наочно продемонструвати перехід від безперервної теорії до обчислювального алгоритму, перевірити точність дискретизації та оцінити похибки обрізання обчислювальної області.

---

### Фізична та обчислювальна постановка задачі

Розглядається точковий заряд `q`, розміщений у точці `(0, 0, d)` над нескінченною заземленою провідною площиною `z = 0`. 

Завдяки осьовій симетрії системи відносно осі Z, поверхнева густина наведеного заряду `σ(r)` залежить виключно від радіальної відстані `r = √(x² + y²)` від проекції заряду на площину.

Програма повинна вирішувати такі чотири обчислювальні завдання:
1. **Табулювання поверхневої густини заряду**: Розрахунок аналітичного виразу `σ(r) = − q·d / [2·π·(r² + d²)^(3/2)]` на радіальних відстанях `r` від осі симетрії.
2. **Чисельне інтегрування за полярною сіткою**: Обчислення сумарного індукованого заряду `Q_ind` шляхом розбиття площини на тонкі кільцеві концентричні смуги шириною `dr` і застосування двоточкової формули трапецій:
   ```
   dQ = 2 · π · r · σ(r) · dr
   Q_ind = ∫₀^(R_max) dQ ≈ ∑_(i=0)^(N-1) 0.5 · [ 2·π·r_i·σ(r_i) + 2·π·r_(i+1)·σ(r_(i+1)) ] · dr
   ```
3. **Оцінка кулонівської сили притягання**: Обчислення сили притягання між зарядом `q` та його дзеркальним зображенням `−q` на відстані `2d` за формулою `F = q² / (16·π·ε₀·d²)`.
4. **Аналіз похибки обрізання (Truncation Error)**: Порівняння знайденого чисельного значення `Q_ind` із теоретичною межею `−q` та розрахунок відносної похибки залежно від обраного радіуса обрізання `R_max` та кількості кроків дискретизації `N`.

```c
/* electrostatic_sim.c - Чисельне моделювання індукції на заземленій площині (C) */
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

#ifndef M_PI
#define M_PI 3.14159265358979323846
#endif

/* Електрична стала ε₀ (Ф/м) */
#define EPSILON_0 8.8541878128e-12

/* Структура результатів моделювання */
typedef struct {
    double analytical_q_coulombs;
    double numerical_q_coulombs;
    double relative_error_percent;
    double attraction_force_newtons;
} sim_result_t;

/* Обчислення поверхневої густини заряду sigma(r) у Кл/м² */
double surface_charge_density(double q, double d, double r) {
    double denom = pow(r * r + d * d, 1.5);
    return -(q * d) / (2.0 * M_PI * denom);
}

/* Чисельне інтегрування наведеного заряду методом трапецій */
double integrate_induced_charge(double q, double d, double r_max, size_t steps) {
    if (steps == 0 || r_max <= 0.0) return 0.0;

    double dr = r_max / (double)steps;
    double total_q = 0.0;

    for (size_t i = 0; i < steps; i++) {
        double r1 = (double)i * dr;
        double r2 = (double)(i + 1) * dr;
        double sigma1 = surface_charge_density(q, d, r1);
        double sigma2 = surface_charge_density(q, d, r2);

        /* Інтегральний елемент кільця dQ = 2*pi*r*sigma(r)*dr */
        double dq1 = 2.0 * M_PI * r1 * sigma1;
        double dq2 = 2.0 * M_PI * r2 * sigma2;
        total_q += 0.5 * (dq1 + dq2) * dr;
    }

    return total_q;
}

/* Сила притягання точкового заряду до площини */
double calculate_attraction_force(double q, double d) {
    double k = 1.0 / (4.0 * M_PI * EPSILON_0);
    return k * (q * q) / (4.0 * d * d);
}

/* Запуск повного циклу моделювання */
sim_result_t run_simulation(double q, double d, double r_max, size_t steps) {
    sim_result_t res;
    res.analytical_q_coulombs = -q;
    res.numerical_q_coulombs = integrate_induced_charge(q, d, r_max, steps);
    res.relative_error_percent = fabs((res.numerical_q_coulombs - res.analytical_q_coulombs) / q) * 100.0;
    res.attraction_force_newtons = calculate_attraction_force(q, d);
    return res;
}

int main(void) {
    double q = 1.0e-6;      /* 1 мкКл (10⁻⁶ Кл) */
    double d = 0.05;        /* Відстань d = 5 см (0.05 м) */
    double r_max = 2.0;     /* Радіус інтегрування 2.0 м */
    size_t steps = 50000;

    printf("====================================================\n");
    printf("  Моделювання індукції: Точковий заряд біля площини  \n");
    printf("====================================================\n");
    printf("Заряд q = %.2e Кл, Відстань d = %.3f м\n\n", q, d);

    printf("Табулювання густини σ(r) біля осі симетрії:\n");
    printf("  r (м)       σ(r) (Кл/м²)\n");
    printf("  -------------------------\n");
    for (double r = 0.0; r <= 0.20; r += 0.04) {
        printf("  %.2f        %.5e\n", r, surface_charge_density(q, d, r));
    }

    sim_result_t res = run_simulation(q, d, r_max, steps);

    printf("\nРезультати чисельного інтегрування:\n");
    printf("  Теоретичний наведений заряд:  %.6e Кл\n", res.analytical_q_coulombs);
    printf("  Чисельно обчислений заряд:    %.6e Кл\n", res.numerical_q_coulombs);
    printf("  Відносна похибка обчислення:  %.4f %%\n", res.relative_error_percent);
    printf("  Сила притягання до площини:   %.6e Н\n", res.attraction_force_newtons);

    return 0;
}
```

```cpp
// electrostatic_sim.cpp - Чисельне моделювання індукції (Ідіоматичний C++20)
#include <iostream>
#include <cmath>
#include <vector>
#include <numbers>
#include <iomanip>
#include <concepts>

namespace electrodynamics {

template <std::floating_point T>
class InductionSimulator {
public:
    static constexpr T kEpsilon0 = static_cast<T>(8.8541878128e-12);

    struct SimulationReport {
        T analytical_charge_c;
        T numerical_charge_c;
        T error_percent;
        T force_newtons;
    };

    constexpr InductionSimulator(T charge_c, T distance_m) noexcept
        : q_(charge_c), d_(distance_m) {}

    [[nodiscard]] constexpr T surface_charge_density(T r) const noexcept {
        const T denom = std::pow(r * r + d_ * d_, static_cast<T>(1.5));
        return -(q_ * d_) / (static_cast<T>(2.0) * std::numbers::pi_v<T> * denom);
    }

    [[nodiscard]] SimulationReport compute(T r_max, std::size_t steps) const {
        const T dr = r_max / static_cast<T>(steps);
        T total_q = static_cast<T>(0.0);

        for (std::size_t i = 0; i < steps; ++i) {
            const T r1 = static_cast<T>(i) * dr;
            const T r2 = static_cast<T>(i + 1) * dr;
            const T dq1 = static_cast<T>(2.0) * std::numbers::pi_v<T> * r1 * surface_charge_density(r1);
            const T dq2 = static_cast<T>(2.0) * std::numbers::pi_v<T> * r2 * surface_charge_density(r2);
            total_q += static_cast<T>(0.5) * (dq1 + dq2) * dr;
        }

        const T k = static_cast<T>(1.0) / (static_cast<T>(4.0) * std::numbers::pi_v<T> * kEpsilon0);
        const T force = k * (q_ * q_) / (static_cast<T>(4.0) * d_ * d_);
        const T analytical = -q_;
        const T error = std::abs((total_q - analytical) / q_) * static_cast<T>(100.0);

        return {analytical, total_q, error, force};
    }

private:
    T q_;
    T d_;
};

} // namespace electrodynamics

int main() {
    using namespace electrodynamics;

    constexpr double charge = 1.0e-6;   // 1 мкКл
    constexpr double distance = 0.05;   // 5 см
    constexpr double r_max = 2.0;       // Інтегруємо до R_max = 2 м
    constexpr std::size_t steps = 50000;

    const InductionSimulator<double> sim(charge, distance);
    const auto report = sim.compute(r_max, steps);

    std::cout << std::scientific << std::setprecision(5);
    std::cout << "=== Чисельне моделювання електростатичної індукції (C++20) ===\n";
    std::cout << "Аналітичний індукований заряд: " << report.analytical_charge_c << " Кл\n";
    std::cout << "Обчислений чисельний заряд:    " << report.numerical_charge_c << " Кл\n";
    std::cout << std::fixed << std::setprecision(4);
    std::cout << "Відносна похибка інтегрування: " << report.error_percent << " %\n";
    std::cout << std::scientific << std::setprecision(5);
    std::cout << "Сила притягання до площини:    " << report.force_newtons << " Н\n";

    return 0;
}
```

### Аналіз алгоритму та покроковий розбір коду

Для детального розуміння структури програми та обчислювальної математики розглянемо кожну з функціональних частин алгоритму:

1. **Математична функція густини `surface_charge_density(r)`**:
   Обчислює точний аналітичний вираз для поверхневої густини заряду в кожній вузловій точці полярної сітки. Функція приймає величину реального заряду `q`, відстань `d` та радіальну координату `r`. У чисельних розрахунках особлива увага приділяється відсутності ділення на нуль, оскільки знаменник `(r² + d²)^(3/2)` завжди є додатним і більшим або рівним `d³`.
2. **Алгоритм чисельного інтегрування `integrate_induced_charge()`**:
   Площина розбивається на `steps` концентричних кілець радіальною товщиною `dr = R_max / steps`. Для кожного кільця обчислюються його внутрішній радіус `r1` та зовнішній радіус `r2`. Замість простого прямокутного сумування використовується формула трапецій, яка усереднює значення диференціального заряду `dq1 = 2·π·r1·σ(r1)` та `dq2 = 2·π·r2·σ(r2)` на межах кільця. Це забезпечує квадратичну збіжність алгоритму по кроку сітки `O(dr²)`.
3. **Оцінка кулонівської сили притягання `calculate_attraction_force()`**:
   Обчислює силу притягання між точковим зарядом та заземленою площиною через еквівалентну систему із дзеркальним зарядом `−q`. Результат повертається у ньютонах (Н).

### Порівняння методу трапецій та Симпсона

У запропонованій реалізації застосовано правило трапецій. Якщо змінити схему інтегрування на параболічне правило Симпсона (*Simpson's 1/3 rule*), чисельна похибка дискретизації спадає як `O(dr⁴)`. 

Для правила Симпсона площа елементарної полярної смуги між `r_(i)` та `r_(i+2)` обчислюється за формулою:

```
ΔQ_simpson = (dr / 3) · [ f(r_i) + 4 · f(r_(i+1)) + f(r_(i+2)) ]

де f(r) = 2 · π · r · σ(r)
```

При використанні правила Симпсона досягнення відносної похибки `10⁻⁶%` вимагає лише `N = 500` кроків замість `N = 50000` при трапеції, що значно прискорює обчислення у тривимірних задачах BEM.

### Оцінка продуктивності та обчислювальна складність

Програма має лінійну обчислювальну складність `O(N)` по кількості кроків дискретизації `N = steps`. Пам'ять становить `O(1)`, оскільки інтегрування виконується у потоковому режимі без збереження всього масиву сітки.

При використанні сучасних компіляторів (GCC/Clang з прапором `-O3`) векторний цикл обчислення математичних функцій `pow()` автоматично векторизується інструкціями AVX2/AVX-512, що дозволяє виконувати 50 000 кроків інтегрування менше ніж за 0.2 мілісекунди.

### Обчислювальні пастки та крайові випадки

1. **Вплив скінченності радіуса обрізання `R_max`**:
   Оскільки поверхневий заряд спадає з віддаленням від осі за кубічним законом `σ(r) ∝ 1 / r³`, нехтування периферійною областю `r > R_max` занижує величину обчисленого заряду `Q_ind`. Аналітична похибка обрізання становить `ΔQ / q = d / √(R_max² + d²)`. При `d = 0.05 м` та `R_max = 2.0 м` теоретична похибка обрізання становить `0.05 / 2.0006 ≈ 2.49%`. Щоб зменшити похибку до `0.01%`, потрібно обирати `R_max ≥ 100 · d`.
2. **Сингулярності на кутах та вістрях (Corner Singularities)**:
   При моделюванні реальних провідників скінченної товщини або з гострими ребрами методом межових елементів (BEM) густина заряду на вістрях формально прямує до нескінченності `σ ∝ r^(α−1)`. У таких зонах стандартна рівномірна сітка дає велику похибку. Обчислювальні алгоритми вимагають геометричного згущення сітки дискретизації біля вістрів (адаптивна сітка).
3. **Чисельна нестійкість при малих відстанях `d → 0`**:
   Коли заряд підходить дуже близько до поверхні (`d << dr`), функція `σ(r)` перетворюється на вузький імпульс дельта-подібної форми. Якщо крок сітки `dr` перевищує відстань `d`, чисельний інтеграл повністю втрачає пік густини, даючи похибку до 90%. Для збереження точності необхідно забезпечити умову `dr ≤ d / 10`.
