# 🧮 Математика індукції: метод дзеркальних зарядів

Обчислення просторового розподілу наведеного поверхневого заряду та напруженості електричного поля біля провідників довільної форми належить до класичних крайових задач математичної фізики. Узагальнена постановка вимагає розв'язання рівняння Пуассона для електростатичного потенціалу `∇²V = −ρ / ε₀` у просторі поза провідниками або рівняння Лапласа `∇²V = 0` за відсутності вільних об'ємних зарядів. При цьому поверхня будь-якого ідеального провідника задає граничну умову Діріхле: потенціал на ній є сталим `V|_S = V₀ = const` (а для заземленого провідника `V|_S = 0`).

Безпосередній аналітичний розв'язок таких диференціальних рівнянь у частинних похідних через розкладання за ортогональними функціями є надзвичайно громіздким. Проте для систем із високою геометричною симетрією (нескінченна площина, сфера, циліндр, перетин двох площин під прямим кутом) застосовують витончений та потужний математичний прийом — **метод дзеркальних зарядів (зображень)**.

Суть методу ґрунтується на **першій теоремі єдиності електростатики**: якщо у деякій обмеженій або напівбезмежній області знайдено розв'язок рівняння Лапласа/Пуассона, який задовольняє заданим граничним умовам на межах цієї області, то цей розв'язок є **єдино можливим**. Це означає, що якщо ми подумки приберемо провідник і замінимо його фіктивними (дзеркальними) точковими зарядами, розміщеними *поза* розглядуваною областю так, щоб на колишній межі провідника потенціал залишався тотожно рівним `V₀`, то знайдений розподіл поля у робочій області буде математично точним і єдиним.

### 1. Точковий заряд біля нескінченної заземленої провідної площини

Розглянемо точковий заряд `q`, розміщений у точці з координатами `(0, 0, d)` у напівпросторі `z > 0`. Нескінченна ідеально провідна металева площина збігається з площиною `z = 0` і заземлена, тобто її потенціал фіксовано на рівні `V(x, y, 0) = 0`.

#### Формування дзеркальної системи

Щоб забезпечити граничну умову `V = 0` на всій площині `z = 0`, видалимо металеву площину і помістимо фіктивний дзеркальний заряд `q' = −q` у від'ємну напівпростір у точку `(0, 0, −d)`, розташовану симетрично відносно межі.

Потенціал у довільній точці `P(x, y, z)` у робочому напівпросторі `z > 0` утворюється суперпозицією полів реального та фіктивного зарядів:

```
V(x, y, z) = (q / 4·π·ε₀) · [ 1 / r₁ − 1 / r₂ ]

де:
r₁ = √[ x² + y² + (z − d)² ] — відстань від точки P до реального заряду +q;
r₂ = √[ x² + y² + (z + d)² ] — відстань від точки P до дзеркального заряду −q.
```

З точки зору функції Гріна `G(r⃗, r⃗')`, це відповідає застосуванню функції Гріна для напівпростору з умовою Діріхле:

```
G(r⃗, r⃗') = 1 / |r⃗ − r⃗'| − 1 / |r⃗ − r⃗''|
```

де `r⃗''` — дзеркальне відображення джерела `r⃗'` відносно площини.

Перевіримо виконання граничної умови на межі `z = 0`. Для будь-якої точки площини `(x, y, 0)` відстані від обох зарядів є абсолютно однаковими: `r₁ = r₂ = √[ x² + y² + d² ]`.

```
V(x, y, 0) = (q / 4·π·ε₀) · [ 1 / √[x² + y² + d²] − 1 / √[x² + y² + d²] ] = 0   [виконано]
```

Оскільки вираз задовольняє рівняння Пуассона `∇²V = −q·δ(r⃗ − d·k̂)/ε₀` при `z > 0` та дорівнює нулю при `z = 0`, за теоремою єдиності він описує істинний потенціал у всьому напівпросторі `z > 0`.

#### Густина індукованого поверхневого заряду σ(r)

Напруженість електричного поля біля поверхні провідника має лише нормальну складову `E_z`, оскільки тангенціальна складова `E_t` на еквіпотенціальній поверхні дорівнює нулю. За теоремою Гаусса нормальне поле зв'язане з густиною поверхневого заряду співвідношенням `E_z = σ / ε₀`, звідки `σ = ε₀ · E_z = −ε₀ · (∂V / ∂z)`.

Обчислимо частинну похідну потенціалу по `z` у точці `z = 0`:

```
∂V/∂z = (q / 4·π·ε₀) · [ −(z − d) / [x² + y² + (z − d)²]^(3/2) + (z + d) / [x² + y² + (z + d)²]^(3/2) ]
```

Підставляючи `z = 0` та ввівши радіальну координату в площині `r = √[x² + y²]`:

```
∂V/∂z |_(z=0) = (q / 4·π·ε₀) · [ d / (r² + d²)^(3/2) + d / (r² + d²)^(3/2) ]
              = (q · d) / (2·π·ε₀ · [r² + d²]^(3/2))
```

Отже, густина наведеного заряду на заземленій площині є від'ємною і дорівнює:

```
σ(r) = − ε₀ · ∂V/∂z |_(z=0) = − (q · d) / (2·π · [r² + d²]^(3/2))
```

Максимальна абсолютна густина індукованого заряду спостерігається у центрі площини безпосередньо під точковим зарядом (`r = 0`):

```
σ_max = − q / (2·π·d²)
```

При віддаленні від центру (`r >> d`) густина заряду швидко спадає за кубічним законом: `σ(r) ∝ 1 / r³`.

#### Повний індукований заряд Q_ind

Для знаходження сумарного заряду, наведеного на всій нескінченній площині, виконаємо інтегрування густини `σ(r)` у полярних координатах по всій площині від `r = 0` до `r = ∞`:

```
Q_ind = ∫₀^∞ σ(r) · 2·π·r dr
      = ∫₀^∞ [ − (q · d) / (2·π · (r² + d²)^(3/2)) ] · 2·π·r dr
      = − q · d ∫₀^∞ [ r / (r² + d²)^(3/2) ] dr
```

Застосуємо заміну змінної `u = r² + d²`, `du = 2r dr`:

```
Q_ind = − (q · d / 2) ∫_(d²)^∞ u^(−3/2) du
      = − (q · d / 2) · [ − 2 / √u ]_(d²)^∞
      = − (q · d / 2) · [ 0 − (− 2 / d) ]
      = − q
```

Таким чином, сумарний заряд, індукований на нескінченній заземленій площині, **точно дорівнює за величиною і протилежний за знаком** реальному заряду `q`, що його викликав.

#### Сила кулонівського притягання та енергія взаємодії

Сила, з якою наведений поверхневий заряд притягує точковий заряд `q` до площини, обчислюється як кулонівська сила між реальним зарядом `q` та його фіктивним зображенням `−q` на відстані `2d`:

```
F = (1 / 4·π·ε₀) · |q · (−q)| / (2d)² = (1 / 4·π·ε₀) · q² / (4·d²)
```

Робота, яку необхідно виконати проти сил поля для віддалення заряду `q` від площини з відстані `d` до нескінченності:

```
W = ∫_d^∞ F dr = (q² / 16·π·ε₀) ∫_d^∞ (1 / z²) dz = q² / (16·π·ε₀·d)
```

Зауважимо, що потенціальна енергія системи «заряд — провідник» дорівнює `W_pot = − q² / (16·π·ε₀·d)`, що вдвічі менше за енергію взаємодії двох реальних точкових зарядів `+q` та `−q` на відстані `2d`. Це пояснюється тим, що поле існує лише в одному напівпросторі `z > 0`.

### 2. Точковий заряд біля заземленої провідної сфери

Розглянемо заземлену металеву сферу радіуса `R` з центром у початку координат `(0, 0, 0)`. Точковий заряд `q` розташований на осі Z у точці `(0, 0, a)`, де `a > R`.

Гранична умова вимагає, щоб потенціал на всій поверхні сфери дорівнював нулю: `V(R, θ, φ) = 0`.

#### Розрахунок параметрів дзеркального заряду

Спробуємо задовольнити граничну умову, помістивши один фіктивний заряд `q'` усередині сфери на осі Z у точці `(0, 0, d')`, де `d' < R`.

Потенціал у довільній точці `P` з радіус-вектором `r⃗` поза сферою:

```
V(r⃗) = (1 / 4·π·ε₀) · [ q / |r⃗ − a·k̂| + q' / |r⃗ − d'·k̂| ]
```

Розглянемо точку на поверхні сфери `r⃗_S` під кутом `θ` до осі Z. Відстані від зарядів `q` та `q'` до цієї точки дорівнюють:

```
r₁ = √[ R² + a² − 2·R·a·cos(θ) ] = √a · √[ R²/a + a − 2·R·cos(θ) ]
r₂ = √[ R² + d'² − 2·R·d'·cos(θ) ]
```

Вимагатимемо, щоб вираз `q / r₁ + q' / r₂` дорівнював нулю для всіх кутів `θ`. Це можливо лише тоді, коли трикутники є подібними, що дає умову:

```
d' = R² / a                      [відстань дзеркального заряду від центру]
q' = − q · (R / a)               [величина дзеркального заряду]
```

Оскільки `a > R`, дзеркальний заряд за модулем завжди менший за реальний (`|q'| < q`) і розміщений усередині сфери (`d' < R`).

#### Густина поверхневого заряду на сфері σ(θ)

Диференціюванням потенціалу `V(r, θ)` за радіусом `r` при `r = R` отримуємо кутовий розподіл наведеного заряду на поверхні сфери:

```
σ(θ) = − ε₀ · ∂V/∂r |_(r=R) = − [ q · (a² − R²) ] / [ 4·π·R · (R² + a² − 2·a·R·cos θ)^(3/2) ]
```

Максимальна від'ємна густина досягається на ближчому полюсі сфери (`θ = 0`):

```
σ(0) = − [ q · (a + R) ] / [ 4·π·R · (a − R)² ]
```

На протилежному полюсі (`θ = π`) густина є мінімальною за модулем:

```
σ(π) = − [ q · (a − R) ] / [ 4·π·R · (a + R)² ]
```

#### Повний індукований заряд та сила взаємодії

За теоремою Гаусса повний заряд, наведений на заземленій сфері, дорівнює сумі зарядів усередині поверхні, тобто точно дорівнює дзеркальному заряду:

```
Q_ind = q' = − q · (R / a)
```

Сила притягання між точковим зарядом `q` та заземленою сферою дорівнює кулонівській силі між зарядом `q` та зображенням `q'`:

```
F = (1 / 4·π·ε₀) · |q · q'| / (a − d')²
  = (1 / 4·π·ε₀) · [ q² · (R / a) ] / [ a − R²/a ]²
  = (1 / 4·π·ε₀) · (q² · R · a) / (a² − R²)²
```

При наближенні заряду до самої поверхні сфери (`a → R + δ`, де `δ << R`) сила притягання прямує до виразу для плоскої межі: `F ≈ q² / (16·π·ε₀·δ²)`.

Якщо сфера є **ізольованою та незарядженою** (`Q_total = 0`), то для збереження нульового сумарного заряду у її центр `(0, 0, 0)` додають другий дзеркальний заряд `q'' = −q' = +q · (R/a)`. Потенціал такої сфери стає відмінним від нуля: `V_sphere = q / (4·π·ε₀·a)`.

### 3. Точковий заряд у двогранному куті з двох площин (прямий кут)

Якщо заземлена провідна поверхня утворена двома перпендикулярними площинами `x = 0` (при `y ≥ 0`) та `y = 0` (при `x ≥ 0`), то для точкового заряду `+q` у точці `(a, b, 0)` гранична умова `V = 0` вимагає введення **трьох дзеркальних зарядів**:

1. Заряд `q₁ = −q` у точці `(−a, b, 0)` — дзеркальне відображення відносно площини `x = 0`.
2. Заряд `q₂ = −q` у точці `(a, −b, 0)` — дзеркальне відображення відносно площини `y = 0`.
3. Заряд `q₃ = +q` у точці `(−a, −b, 0)` — подвійне дзеркальне відображення.

Сумарний потенціал у першому квадранті `x > 0, y > 0`:

```
V(x, y, z) = (q / 4·π·ε₀) · [ 1/r₁ − 1/r₂ − 1/r₃ + 1/r₄ ]
```

де `r₁...r₄` — відстані від спостережуваної точки до реального та трьох дзеркальних зарядів. Сумарний індукований заряд на кутовому екрані дорівнює `-q`.
