# ⚙️ Чисельна симуляція потенціалу дії за моделлю Годжкіна-Гакслі

Ця вставка містить практичну реалізацію алгоритму чисельного інтегрування нелінійної системи диференціальних рівнянь Годжкіна-Гакслі. Код моделює виникнення, спайковий овершут та реполяризацію потенціалу дії нервової мембрани у відповідь на зовнішній стимулюючий імпульс струму.

## 1. Фізична та біологічна сутність ворітних змінних

У 1952 році Алан Годжкін та Ендрю Гакслі висловили геніальну гіпотезу: трансмембранні іонні струми регулюються не суцільною зміною властивостей мембрани, а рухом заряджених частинок (частин білкових молекул), які під дією електричного поля перемикають іонні канали між закритим та відкритим станами.

### Натрієвий канал (`Na_v`): кооперування активації та інактивації

Натрієвий канал описується двома незалежними процесами: швидкою активацією та повільнішою інактивацією.

1. **Змінна активації `m`**: Годжкін і Гакслі припустили, що для відкриття проходу іону натрію необхідно, щоб три незалежні частинки всередині білкової пори одночасно перейшли у відкрите положення. Якщо ймовірність перебування однієї частинки у відкритому стані дорівнює `m` (де `0 ≤ m ≤ 1`), то ймовірність того, що всі три частинки відкриті одночасно, дорівнює добутку їхніх ймовірностей: `m · m · m = m³`.
2. **Змінна інактивації `h`**: Натрієвий канал володіє додатковою заслінкою («кулькою на ланцюжку»), яка при деполяризації повільно закриває пор зсередини клітини. Ймовірність того, що інактиваційна заслінка відкрита (не заблокована), позначається як `h`.
3. **Підсумкова провідність натрію**: Загальна натрієва провідність мембрани в кожен момент часу пропорційна добутку імовірностей активації та не-інактивації: `g_Na(V, t) = g_Na_max · m³ · h`.

### Калієвий канал (`K_v`): тетрамерна симетрія

Калієвий канал утворений чотирма однаковими білковими субодиницями, кожна з яких містить свій вольт-сенсорний домен.
1. **Змінна активації `n`**: Для відкриття калієвої пори всі чотири субодиниці мусять одночасно змінити свою конформацію. Якщо ймовірність відкритого стану однієї субодиниці дорівнює `n`, то ймовірність проходження іона калію дорівнює `n⁴`.
2. **Підсумкова провідність калію**: `g_K(V, t) = g_K_max · n⁴`.

Калієві канали не мають швидкої інактивації (в класичному аксоні кальмара), тому їхнє закривання відбувається природним шляхом при поверненні напруги до від'ємних значень.

### Температурна корекція `Q_10`

Швидкості конформаційних перебудов білкових каналів сильно залежать від температури середовища. Класичні експерименти Годжкіна та Гакслі проводилися на аксоні кальмара при температурі `T = 6.3 °C`. Для перерахунку швидкостей `α_y(V)` та `β_y(V)` на іншу температуру `T` використовують температурний коефіцієнт `Q_10 = 3.0`:

```
ϕ = Q_10^((T - 6.3) / 10) = 3.0^((T - 6.3) / 10)
```

Усі константи швидкостей помножуються на масштабувальний коефіцієнт `ϕ`, що прискорює генерацію потенціалу дії при підвищенні температури тіла.

## 2. Математична структура моделі

Динаміка напруги на мембрані `V` (мВ) описується рівнянням збереження струму (перший закон Кірхгофа для мембранного вузла):

```
dV/dt = (1 / C_m) · [ I_ext - g_Na·m³·h·(V - E_Na) - g_K·n⁴·(V - E_K) - g_L·(V - E_L) ]
```

де `m`, `h`, `n` — безрозмірні ворітні змінні, кожна з яких змінюється згідно з диференціальним рівнянням першого порядку:

```
dy/dt = α_y(V) · (1 - y) - β_y(V) · y
```

Це рівняння можна переписати у більш прозорій фізичній формі через стаціонарну ймовірність `y_inf` та часову константу `τ_y`:

```
dy/dt = (y_inf(V) - y) / τ_y(V)
y_inf(V) = α_y(V) / ( α_y(V) + β_y(V) )
τ_y(V)   = 1.0 / ( α_y(V) + β_y(V) )
```

Функції швидкості конформаційних переходів `α_y(V)` та `β_y(V)` (1/мс) залежать від поточної напруги на мембрані `V`:

```
α_m(V) = 0.1 · (V + 40) / ( 1 - exp(-(V + 40)/10) )
β_m(V) = 4.0 · exp(-(V + 65)/18)

α_h(V) = 0.07 · exp(-(V + 65)/20)
β_h(V) = 1.0 / ( 1 + exp(-(V + 35)/10) )

α_n(V) = 0.01 · (V + 55) / ( 1 - exp(-(V + 55)/10) )
β_n(V) = 0.125 · exp(-(V + 65)/80)
```

Таблиця фізичних параметрів аксона кальмара (для `T = 6.3 °C`):

| Параметр | Значення | Фізичний зміст та одиниці вимірювання |
| :--- | :--- | :--- |
| `C_m` | `1.0 мкФ/см²` | Питома електрична ємність ліпідного бішару |
| `g_Na_max` | `120.0 мСм/см²` | Максимальна питома провідність відкритих натрієвих каналів |
| `g_K_max` | `36.0 мСм/см²` | Максимальна питома провідність відкритих калієвих каналів |
| `g_L` | `0.3 мСм/см²` | Незмінна питома провідність каналів витоку |
| `E_Na` | `+50.0 мВ` | Нернстівський рівноважний потенціал для іонів натрію |
| `E_K` | `-77.0 мВ` | Нернстівський рівноважний потенціал для іонів калію |
| `E_L` | `-54.387 мВ` | Рівноважний потенціал каналів витоку (забезпечує `dV/dt = 0` при `V = -65 мВ`) |

## 3. Чисельні методи інтегрування: Ейлер проти Раша-Ларсена

Рівняння Годжкіна-Гакслі належать до категорії **жорстких диференціальних рівнянь**. При швидкому зльоті напруги часова константа натрієвої активації `τ_m` стає коротшою за `0.1 мс`. Якщо використати занадто великий крок інтегрування у звичайному методі Ейлера (`dt > 0.05 мс`), чисельне рішення втрачає стійкість і починає нефізично осцилювати.

Для забезпечення стійкості застосовують два підходи:
1. **Явний метод Ейлера з малим кроком** (`dt ≤ 0.01 мс`): найпростіший в реалізації, вимагає мінімум обчислень на один крок.
2. **Алгоритм Раша-Ларсена (Rush-Larsen)**: оскільки рівняння для ворітних змінних `dy/dt = (y_inf - y)/τ_y` є лінійними відносно `y` при зафіксованій напрузі `V`, їх можна інтегрувати **аналітично** на кожному кроці за часом:

```
y(t + dt) = y_inf(V) + ( y(t) - y_inf(V) ) · exp(-dt / τ_y(V))
```

Алгоритм Раша-Ларсена є абсолютно стійким щодо ворітних змінних навіть при кроках `dt = 0.1 мс`, що робить його стандартом у масштабних біофізичних симуляціях серця та мозку.

```c
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

/* Фізичні константи моделі Годжкіна-Гакслі */
static const double C_M = 1.0;
static const double G_NA = 120.0;
static const double G_K = 36.0;
static const double G_L = 0.3;
static const double E_NA = 50.0;
static const double E_K = -77.0;
static const double E_L = -54.387;

/* Обхід сингулярності вида x / (1 - exp(-x/10)) при x -> 0 */
static double alpha_m(double V) {
    double x = V + 40.0;
    if (fabs(x) < 1e-6) return 1.0;
    return 0.1 * x / (1.0 - exp(-x / 10.0));
}

static double beta_m(double V) {
    return 4.0 * exp(-(V + 65.0) / 18.0);
}

static double alpha_h(double V) {
    return 0.07 * exp(-(V + 65.0) / 20.0);
}

static double beta_h(double V) {
    return 1.0 / (1.0 + exp(-(V + 35.0) / 10.0));
}

static double alpha_n(double V) {
    double x = V + 55.0;
    if (fabs(x) < 1e-6) return 0.1;
    return 0.01 * x / (1.0 - exp(-x / 10.0));
}

static double beta_n(double V) {
    return 0.125 * exp(-(V + 65.0) / 80.0);
}

typedef struct {
    double V;
    double m;
    double h;
    double n;
} HHState;

static HHState hh_init(double V_rest) {
    HHState s;
    s.V = V_rest;
    double a_m = alpha_m(V_rest);
    double b_m = beta_m(V_rest);
    double a_h = alpha_h(V_rest);
    double b_h = beta_h(V_rest);
    double a_n = alpha_n(V_rest);
    double b_n = beta_n(V_rest);

    s.m = a_m / (a_m + b_m);
    s.h = a_h / (a_h + b_h);
    s.n = a_n / (a_n + b_n);
    return s;
}

/* Інтегрування ворітних змінних методом Раша-Ларсена для максимальної стійкості */
static void hh_step_rush_larsen(HHState *s, double I_ext, double dt) {
    double V = s->V;
    double m = s->m;
    double h = s->h;
    double n = s->n;

    /* Обчислення струмів за поточними значеннями воріт */
    double I_Na = G_NA * (m * m * m) * h * (V - E_NA);
    double I_K  = G_K * (n * n * n * n) * (V - E_K);
    double I_L  = G_L * (V - E_L);

    /* Оновлення напруги за методом Ейлера */
    double dVdt = (I_ext - I_Na - I_K - I_L) / C_M;
    s->V += dVdt * dt;

    /* Аналітичне інтегрування воріт Раша-Ларсена */
    double a_m = alpha_m(V), b_m = beta_m(V);
    double m_inf = a_m / (a_m + b_m);
    double tau_m = 1.0 / (a_m + b_m);
    s->m = m_inf + (m - m_inf) * exp(-dt / tau_m);

    double a_h = alpha_h(V), b_h = beta_h(V);
    double h_inf = a_h / (a_h + b_h);
    double tau_h = 1.0 / (a_h + b_h);
    s->h = h_inf + (h - h_inf) * exp(-dt / tau_h);

    double a_n = alpha_n(V), b_n = beta_n(V);
    double n_inf = a_n / (a_n + b_n);
    double tau_n = 1.0 / (a_n + b_n);
    s->n = n_inf + (n - n_inf) * exp(-dt / tau_n);
}

int main(void) {
    double t_max = 50.0; /* 50 мс */
    double dt = 0.01;   /* 0.01 мс */
    HHState state = hh_init(-65.0);

    printf("# t(ms)\tV(mV)\tm\th\tn\n");

    for (double t = 0.0; t <= t_max; t += dt) {
        /* Стимулюючий струм 10 мкА/см² між t = 10 мс та t = 12 мс */
        double I_ext = (t >= 10.0 && t <= 12.0) ? 10.0 : 0.0;

        if ((int)(t / dt) % 100 == 0) {
            printf("%.2f\t%.2f\t%.3f\t%.3f\t%.3f\n", t, state.V, state.m, state.h, state.n);
        }

        hh_step_rush_larsen(&state, I_ext, dt);
    }

    return 0;
}
```

```cpp
#include <iostream>
#include <vector>
#include <cmath>
#include <iomanip>

class HodgkinHuxleyNeuron {
public:
    struct State {
        double V = -65.0; // Напруга мембрани (мВ)
        double m = 0.05;  // Натрієва активація
        double h = 0.60;  // Натрієва інактивація
        double n = 0.32;  // Калієва активація
    };

    explicit HodgkinHuxleyNeuron(double V_rest = -65.0) {
        state_.V = V_rest;
        initializeGatingAtRest(V_rest);
    }

    // Інтегрування воріт за точною схемою Раша-Ларсена
    void step(double I_ext_uA_cm2, double dt_ms) {
        const double V = state_.V;
        const double m = state_.m;
        const double h = state_.h;
        const double n = state_.n;

        const double I_Na = g_Na_max_ * (m * m * m) * h * (V - E_Na_);
        const double I_K  = g_K_max_ * (n * n * n * n) * (V - E_K_);
        const double I_L  = g_L_ * (V - E_L_);

        const double dVdt = (I_ext_uA_cm2 - I_Na - I_K - I_L) / C_m_;
        state_.V += dVdt * dt_ms;

        updateGatingVariable(state_.m, alphaM(V), betaM(V), dt_ms);
        updateGatingVariable(state_.h, alphaH(V), betaH(V), dt_ms);
        updateGatingVariable(state_.n, alphaN(V), betaN(V), dt_ms);
    }

    [[nodiscard]] const State& getState() const noexcept { return state_; }

private:
    static constexpr double C_m_ = 1.0;
    static constexpr double g_Na_max_ = 120.0;
    static constexpr double g_K_max_ = 36.0;
    static constexpr double g_L_ = 0.3;
    static constexpr double E_Na_ = 50.0;
    static constexpr double E_K_ = -77.0;
    static constexpr double E_L_ = -54.387;

    State state_;

    static void updateGatingVariable(double& y, double alpha, double beta, double dt) noexcept {
        const double sum = alpha + beta;
        const double y_inf = alpha / sum;
        const double tau = 1.0 / sum;
        y = y_inf + (y - y_inf) * std::exp(-dt / tau);
    }

    static double alphaM(double V) {
        const double x = V + 40.0;
        return (std::abs(x) < 1e-6) ? 1.0 : (0.1 * x / (1.0 - std::exp(-x / 10.0)));
    }

    static double betaM(double V) {
        return 4.0 * std::exp(-(V + 65.0) / 18.0);
    }

    static double alphaH(double V) {
        return 0.07 * std::exp(-(V + 65.0) / 20.0);
    }

    static double betaH(double V) {
        return 1.0 / (1.0 + std::exp(-(V + 35.0) / 10.0));
    }

    static double alphaN(double V) {
        const double x = V + 55.0;
        return (std::abs(x) < 1e-6) ? 0.1 : (0.01 * x / (1.0 - std::exp(-x / 10.0)));
    }

    static double betaN(double V) {
        return 0.125 * std::exp(-(V + 65.0) / 80.0);
    }

    void initializeGatingAtRest(double V_rest) {
        const double a_m = alphaM(V_rest);
        const double b_m = betaM(V_rest);
        const double a_h = alphaH(V_rest);
        const double b_h = betaH(V_rest);
        const double a_n = alphaN(V_rest);
        const double b_n = betaN(V_rest);

        state_.m = a_m / (a_m + b_m);
        state_.h = a_h / (a_h + b_h);
        state_.n = a_n / (a_n + b_n);
    }
};

int main() {
    HodgkinHuxleyNeuron neuron(-65.0);
    constexpr double dt = 0.01;
    constexpr double t_max = 50.0;

    std::cout << std::fixed << std::setprecision(2);
    std::cout << "# Time(ms)\tVoltage(mV)\tm\th\tn\n";

    for (double t = 0.0; t <= t_max; t += dt) {
        const double I_ext = (t >= 10.0 && t <= 12.0) ? 10.0 : 0.0;
        
        if (static_cast<int>(t / dt) % 100 == 0) {
            const auto& s = neuron.getState();
            std::cout << t << "\t\t" << s.V << "\t\t" 
                      << std::setprecision(3) << s.m << "\t" << s.h << "\t" << s.n << "\n";
        }

        neuron.step(I_ext, dt);
    }

    return 0;
}
```

## 5. Фізико-аналітичний розбір траєкторії симуляції

Аналіз чисельних результатів симуляції показує строгу послідовність фізичних фаз потенціалу дії:

1. **Фаза спокою (`0 – 10 мс`)**: Мембрана стабільна при `V = -65 мВ`. Провідність калію `g_K` значно перевищує провідність натрію `g_Na`. Струм через мембрану дорівнює нулю.
2. **Пасивне деполяризаційне заряджання (`10 – 12 мс`)**: Зовнішній інжектований струм `I_ext = 10 мкА/см²` заряджає ємність мембрани `C_m`, збільшуючи напругу від `-65 мВ` до порогового рівня близько `-55 мВ`.
3. **Вибухова деполяризація та овершут (`12 – 14 мс`)**: При перетині порогової напруги `-55 мВ` швидкість активації натрію `α_m(V)` різко зростає. Змінна `m` лавиноподібно злітає від `0.05` до `0.98`. Провідність натрію `g_Na` стрибає від `0.1` до `40 мСм/см²`. Потужний вхідний струм `I_Na` перезаряджає ємність мембрани, стрімко зміщуючи напругу до `+40 мВ` (наближаючись до нернстівського потенціалу натрію `E_Na = +50 мВ`).
4. **Інактивація та калієва реполяризація (`14 – 17 мс`)**: Додатне значення напруги вмикає повільний процес інактивації натрію: змінна `h` падає від `0.60` до `0.05`, замикаючи натрієві канали, незважаючи на високе `m`. Одночасно відкриваються калієві канали: змінна `n` зростає від `0.32` до `0.78`. Вхідний струм натрію припиняється, а потужний вихідний струм калію `I_K` швидко виносить додатний заряд з клітини, повертаючи напругу у від'ємну область.
5. **Гіперполяризація та рефрактерність (`17 – 30 мс`)**: Оскільки калієві канали закриваються з запізненням (повільне `β_n(V)`), провідність калію лишається підвищеною навіть після досягнення рівноважного рівня спокою `-65 мВ`. Це викликає слідову гіперполяризацію — напруга опускається до `-75 мВ` (близько до `E_K = -77 мВ`). У цей період нейрон перебуває в **рефрактерному стані**: інактивовані натрієві канали (`h ≈ 0`) унеможливлюють повторне збудження доки напруга не повернеться до від'ємних значень і `h` не відновиться.

### Поведінка системи при тривалому стимуляційному струмі (f-I крива)

Якщо подати не короткий імпульс, а тривалий постійний струм `I_ext = 15 мкА/см²`, симуляція демонструє автоколивальний режим — нейрон генерує регулярну серію спайків із постійною частотою (приблизно `70 Гц`). Залежність частоти розрядів `f` від величини інжектованого струму `I_ext` називають **f-I характеристикою нейрона**. У моделі Годжкіна-Гакслі генерація спайків виникає через субкритичну біфуркацію Гопфа при досягненні критичного струму `I_crit ≈ 9.8 мкА/см²`.
