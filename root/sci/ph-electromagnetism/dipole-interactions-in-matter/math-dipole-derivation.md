# 🧮 Математичний вивід потенціалу та поля електричного диполя

Математичний опис електричного диполя ґрунтується на принципі суперпозиції полів двох точкових зарядів `+q` та `−q`, рознесених у просторі на малу відстань `d`. Оскільки будь-який макроскопічний або молекулярний розподіл зарядів можна подати у вигляді суми простіших конфігурацій, дипольний наближений вираз є першим за порядком ненульовим членом розкладу потенціалу для нейтральних систем. У цій вставці наведено детальний аналітичний вивід потенціалу, напруженості, градієнтних сил, моменту та квадрупольних поправок з повними поясненнями кожного кроку.

## 1. Геометрія системи та точний скалярний потенціал

Розглянемо систему з двох протилежних точкових зарядів. Позитивний заряд `+q` знаходиться у точці з радіус-вектором `r₊ = (d / 2) · ẑ`, а негативний заряд `−q` — у точці `r₋ = −(d / 2) · ẑ`. Геометричний центр системи збігається з початком координат `O(0, 0, 0)`.

Нехай точка спостереження `P` розташована на довільній відстані `r` від початку координат, а вектор `r` утворює кут `θ` з віссю `z` (полярна вісь диполя). Відстані від зарядів `+q` та `−q` до точки `P` позначимо як `r₊` та `r₋` відповідно. Для знаходження цих відстаней скористаємося теоремою косинусів для трикутників `O-(+q)-P` та `O-(-q)-P`:

```
r₊² = r² + (d/2)² − 2 · r · (d/2) · cos θ = r² − r·d·cos θ + d²/4     [квадрат відстані від +q до P]
r₋² = r² + (d/2)² + 2 · r · (d/2) · cos θ = r² + r·d·cos θ + d²/4     [квадрат відстані від -q до P]
```

За принципом суперпозиції кулонівських полів, скалярний потенціал `φ(r)` у точці `P` дорівнює алгебраїчній сумі потенціалів точкових зарядів:

```
φ(r)
= (q / (4·π·ε₀·r₊)) − (q / (4·π·ε₀·r₋))                     [суперпозиція скалярних потенціалів]
= (q / (4·π·ε₀)) · ( (1 / r₊) − (1 / r₋) )                  [винесення константи за дужки]
```

У практичних застосуваннях відстань до точки спостереження `r` є значно більшою за геометричні розміри самого диполя (`r >> d`). Це дозволяє розкласти величини `1 / r₊` та `1 / r₋` у збіжний степеневий ряд Тейлора за малим безрозмірним параметром `d / r`.

## 2. Степеневий розклад Тейлора та апроксимація далекого поля

Винесемо модуль радіус-вектора `r` за дужки у виразах для обернених відстаней `1 / r₊` та `1 / r₋`:

```
1 / r₊
= (1 / r) · [ 1 − (d/r)·cos θ + (d/(2r))² ]⁻¹/²             [винесення r з-під квадратного кореня]

1 / r₋
= (1 / r) · [ 1 + (d/r)·cos θ + (d/(2r))² ]⁻¹/²             [винесення r з-під квадратного кореня]
```

Скористаємося узагальненою формулою біноміального розкладу Ньютона для малого значення `x = ∓(d/r)·cos θ + (d/(2r))²`:

```
(1 + x)⁻¹/² = 1 − (1/2)·x + (3/8)·x² − (5/16)·x³ + ...       [біноміальний розклад Тейлора]
```

Підставляючи параметр `x` для `r₊` та `r₋` й обмежуючись членами першого порядку малості по `d / r`:

```
1 / r₊
= (1 / r) · [ 1 + (1/2)·(d/r)·cos θ + O((d/r)²) ]            [лінійне наближення для 1/r₊]

1 / r₋
= (1 / r) · [ 1 − (1/2)·(d/r)·cos θ + O((d/r)²) ]            [лінійне наближення для 1/r₋]
```

Обчислимо різницю двох обернених відстаней:

```
(1 / r₊) − (1 / r₋)
= (1 / r) · [ (1 + (d/(2r))·cos θ) − (1 − (d/(2r))·cos θ) ]  [віднімання лінійних членів]
= (1 / r) · ( (d / r) · cos θ )                              [зведення подібних доданків]
= (d · cos θ) / r²                                            [остаточний вираз для різниці]
```

Підставивши знайдене значення різниці в загальну формулу суперпозиції, отримуємо фундаментальний вираз для потенціалу точкового диполя:

```
φ(r, θ)
= (q / (4·π·ε₀)) · ( (d · cos θ) / r² )                      [підстановка різниці обернених відстаней]
= (1 / (4·π·ε₀)) · ( (q·d · cos θ) / r² )                    [об'єднання величини заряду та плеча]
= (1 / (4·π·ε₀)) · ( (p · cos θ) / r² )                      [введення дипольного моменту p = q·d]
```

Перейдемо від сферичних координат до безкоординатної векторної форми. Позначивши одиничний вектор напрямку спостереження як `r̂ = r / r`, а вектор дипольного моменту як `p = q · d`:

```
φ(r)
= (1 / (4·π·ε₀)) · ( (p · r̂) / r² )                           [скалярний добуток p · r̂ = p cos θ]
= (1 / (4·π·ε₀)) · ( (p · r) / r³ )                           [заміна одиничного вектора r̂ = r / r]
```

Фізичний зміст цього результату полягає у тому, що потенціал диполя зменшується з відстанню як `1 / r²`, що є прямим наслідком інтерференції та часткової взаємокомпенсації протилежних зарядів на великих відстанях.

## 3. Диференціальний вивід поля у сферичних координатах

Вектор напруженості електричного поля `E` пов'язаний зі скалярним потенціалом `φ` фундаментальним диференціальним співвідношенням `E = −∇φ`.

У сферичній системі координат `(r, θ, φ)` з метричним тензором `g_ij = diag(1, r², r² sin² θ)` оператор градієнта розкладається по ортах `r̂`, `θ̂`, `φ̂`:

```
∇φ = (∂φ / ∂r) · r̂ + (1 / r) · (∂φ / ∂θ) · θ̂ + (1 / (r · sin θ)) · (∂φ / ∂φ) · φ̂
```

Обчислимо кожну з трьох частинних похідних для скалярної функції `φ(r, θ) = (p / (4·π·ε₀)) · cos θ · r⁻²`:

```
∂φ / ∂r
= (p / (4·π·ε₀)) · cos θ · (−2 · r⁻³)                       [диференціювання ступеня r⁻² по r]
= −(1 / (4·π·ε₀)) · (2·p · cos θ) / r³                       [спрощення коефіцієнта]

∂φ / ∂θ
= (p / (4·π·ε₀)) · r⁻² · (−sin θ)                          [диференціювання функції cos θ по θ]
= −(1 / (4·π·ε₀)) · (p · sin θ) / r²                         [спрощення коефіцієнта]

∂φ / ∂φ
= 0                                                           [потенціал не залежить від азимутального кута φ]
```

Звідси отримуємо компоненти вектора напруженості `E = −∇φ`:

```
E_r
= −(∂φ / ∂r)                                                  [радіальна компонента]
= (1 / (4·π·ε₀)) · (2·p · cos θ) / r³                        [підстановка частинної похідної ∂φ/∂r]

E_θ
= −(1 / r) · (∂φ / ∂θ)                                       [полярна кутова компонента]
= (1 / (4·π·ε₀)) · (p · sin θ) / r³                          [підстановка частини похідної ∂φ/∂θ]

E_φ
= 0                                                           [азимутальна компонента дорівнює нулю]
```

Модуль повного вектора напруженості поля `E = √(E_r² + E_θ²)` обчислюється шляхом додавання квадратів компонент:

```
E(r, θ)
= √[ ((1/(4πε₀)) · (p/r³))² · (4·cos² θ + sin² θ) ]          [піднесення компонент до квадрата]
= (1 / (4·π·ε₀)) · (p / r³) · √(3·cos² θ + (cos² θ + sin² θ)) [розклад 4 cos² θ = 3 cos² θ + cos² θ]
= (1 / (4·π·ε₀)) · (p / r³) · √(1 + 3·cos² θ)                [застосування тотожності sin² θ + cos² θ = 1]
```

Ця формула показує, що напруженість поля досягає максимуму на полюсах (`θ = 0, π`), де `cos² θ = 1` і `E = 2p / (4πε₀r³)`, і мінімуму на екваторі (`θ = π/2`), де `cos² θ = 0` і `E = p / (4πε₀r³)`.

## 4. Вивід інваріантної векторної формули поля

Для довільно орієнтованого диполя зручно виразити поле `E(r)` без прив'язки до кутів сферичної системи. Скористаємося оператором градієнта у декартових координатах від скалярного добутку:

```
∇( (p · r) / r³ )
= (1 / r³) · ∇(p · r) + (p · r) · ∇(r⁻³)                      [правило диференціювання добутку]
```

Обчислимо окремо два градієнти:
1. Оскільки `p` — константний вектор, `∇(p · r) = p`.
2. Градієнт від степеня відстані `∇(r⁻³) = −3 · r⁻⁴ · ∇r = −3 · r⁻⁵ · r`.

Підставимо обчислені градієнти назад у вираз:

```
∇( (p · r) / r³ )
= (1 / r³) · p + (p · r) · (−3 · r⁻⁵ · r)                      [підстановка градієнтів]
= (p / r³) − (3 · (p · r) · r) / r⁵                            [спрощення дробу]
```

Ураховуючи, що `E = −(1 / (4·π·ε₀)) · ∇((p · r) / r³)`, змінюємо знаки на протилежні:

```
E(r)
= (1 / (4·π·ε₀)) · [ (3 · (p · r) · r) / r⁵ − p / r³ ]       [винесення за дужки r⁻³]
= (1 / (4·π·ε₀·r³)) · [ 3 · (p · r̂) · r̂ − p ]                [заміна r / r = r̂]
```

Ця інваріанта векторна формула дозволяє обчислювати поле диполя в будь-якій декартовій точці простору без обчислення полярних кутів.

## 5. Повна енергія електростатичного поля диполя

Обчислимо повну електростатичну енергію `W`, збережену в полі диполя у всьому просторі поза сферою радіуса `a` (де `a` — радіус дипольного ядра). Густина енергії поля дорівнює `w = (1/2) · ε₀ · E²`.

Інтегруючи по всьому об'єму поза сферою `r >= a`:

```
W
= (1/2) · ε₀ · ∫ E² · dV                                      [інтеграл густини енергії по всьому об'єму]
= (1/2) · ε₀ · ∫ ( (1/(4πε₀)) · (p/r³) · √(1 + 3 cos² θ) )² · r² sin θ dr dθ dφ [підстановка модуля E]
= (p² / (32·π·ε₀)) · ∫ (1/r⁴) dr · ∫ (1 + 3 cos² θ) sin θ dθ · ∫ dφ [розділення змінних у потрійному інтегралі]
```

Обчислимо визначені інтеграли по кожній координаті окремо:

```
∫ (1/r⁴) dr (від a до ∞) = 1 / (3·a³)                         [радіальний інтеграл]
∫ (1 + 3 cos² θ) sin θ dθ (від 0 до π) = [ −cos θ − cos³ θ ] (від 0 до π) = 4 [кутовий інтеграл]
∫ dφ (від 0 до 2π) = 2·π                                      [азимутальний інтеграл]
```

Перемножуючи результати трьох інтегралів:

```
W
= (p² / (32·π·ε₀)) · (1 / (3·a³)) · 4 · (2·π)                 [перемноження кутових та радіальних інтегралів]
= p² / (12 · π · ε₀ · a³)                                    [підсумкова електростатична енергія поля]
```

Цей результат є фундаментальним: скінченне значення повної енергії поля вимагає наявності скінченного радіуса диполя `a > 0`. Для точкового диполя (`a -> 0`) власна електростатична енергія прямує до нескінченності.

## 6. Взаємодія двох диполів: потенціальна енергія та сили

Розглянемо два диполі `p₁` та `p₂`, розташовані на відстані `r` один від одного (вектор від першого до другого дорівнює `r`). Потенціальна енергія взаємодії `U₁₂` дорівнює енергії другого диполя у полі першого `U₁₂ = −p₂ · E₁`:

```
U₁₂
= −p₂ · ( (1 / (4·π·ε₀·r³)) · [ 3 · (p₁ · r̂) · r̂ − p₁ ] )     [підстановка поля першого диполя]
= (1 / (4·π·ε₀·r³)) · [ (p₁ · p₂) − 3 · (p₁ · r̂) · (p₂ · r̂) ] [розкриття скалярного добутку]
```

Сила `F₁₂`, що діє на другий диполь з боку першого, обчислюється як від'ємний градієнт потенціальної енергії `F₁₂ = −∇U₁₂`:

```
F₁₂
= (3 / (4·π·ε₀·r⁴)) · [ (p₁·p₂)·r̂ + (p₁·r̂)·p₂ + (p₂·r̂)·p₁ − 5·(p₁·r̂)·(p₂·r̂)·r̂ ] [диференціювання енергії]
```

Ці рівняння показують комплексну просторову залежність диполь-дипольних сил: вони спадають як `1 / r⁴`, а їхній знак (притягання чи відштовхування) повністю визначається взаємною орієнтацією трьох векторів `p₁`, `p₂` та `r`.

## 7. Сферичні гармоніки та поліноми Лежандра

У загальній теорії потенціалу розклад оберненої відстані `1 / |r − r'|` виконується за допомогою ортогональних поліномів Лежандра `P_l(cos θ)`:

```
1 / |r − r'| = ∑ (r'^l / r^{l+1}) · P_l(cos θ)                [розклад за поліномами Лежандра]
```

Перші поліноми Лежандра мають вигляд:
- `P₀(cos θ) = 1` (монопольний внесок);
- `P₁(cos θ) = cos θ` (дипольний внесок);
- `P₂(cos θ) = (1/2) · (3 cos² θ − 1)` (квадрупольний внесок).

Таким чином, дипольний потенціал відповідає точно другому члену розкладу `l = 1`. Кутова залежність `cos θ` є першою сферичною гармонікою `Y₁₀(θ, φ)`.

## 8. Квадрупольний тензор та метод дзеркальних зображень

Якщо сумарний заряд системи дорівнює нулю (`Q = 0`) і дипольний момент також дорівнює нулю (`p = 0`), головним членом розкладу потенціалу стає квадрупольний доданок `φ_квадр ~ 1 / r³`.

Тензор квадрупольного моменту `Q_ij` описується симетричною матрицею `3x3` із нульовим следом:

```
Q_ij = ∫ (3 · x_i · x_j − r² · δ_ij) · ρ(r) · dV            [визначення тензора квадрупольного моменту]
```

де `δ_ij` — символ Кронекера (`1` при `i = j`, та `0` при `i ≠ j`). Внесок квадруполя у потенціал визначається формулою:

```
φ_квадр(r) = (1 / (8·π·ε₀·r³)) · ∑ ∑ Q_ij · r̂_i · r̂_j         [квадрупольний потенціал]
```

При розрахунку взаємодії диполя `p`, розташованого у вакуумі на відстані `h` від нескінченної провідної площини `z = 0`, застосовується метод дзеркальних зображень. Дзеркальний диполь `p_img` має компоненти `p_img = (−p_x, −p_y, +p_z)`, що створює притягальну силу між диполем та провідною поверхнею.
