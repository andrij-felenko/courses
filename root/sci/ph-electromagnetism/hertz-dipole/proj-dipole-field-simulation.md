# ⚙️ Проєкт: Чисельне моделювання полів диполя та візуалізація зони випромінювання

Цей проєкт присвячено розробці чисельного двигуна для розрахунку та візуалізації тривимірної структури електромагнітного поля довкола осцилювального диполя Герца. Програма обчислює миттєві значення компонент полів `E_r`, `E_θ`, `H_φ` та вектора Пойнтінга `S_r` на просторовій сітці координат `(r, θ)`, що охоплює реактивну ближню зону, проміжну зону індукції та віддалену хвильову зону.

Чисельне моделювання полів диполя Герца є незамінним інструментом при проектуванні сучасних бездротових систем, виконанні розрахунків електромагнітної сумісності (EMC) та оцінці паразитного випромінювання високочастотних друкованих провідників.

---

## 1. Фізико-математична база розрахункового двигуна

В основі чисельного ядра покладено аналітичні вирази Герца для точкового диполя довжиною `dl`, розташованого уздовж осі `z`. Диполь живиться гармонічним струмом `I(t) = I₀ · sin(ω · t)`.

Для будь-якої точки простору з координатами `(r, θ)` обчислюються три ненульові компоненти електромагнітного поля у сферичній системі координат:

```
E_r(r, θ, t) = (2 · I₀ · dl / (4π · ε₀ · ω)) · cos(θ) · [ (cos(ω · t') / r³) − (k · sin(ω · t') / r²) ]
E_θ(r, θ, t) = (I₀ · dl / (4π · ε₀ · ω)) · sin(θ) · [ (cos(ω · t') / r³) − (k · sin(ω · t') / r²) − (k² · cos(ω · t') / r) ]
H_φ(r, θ, t) = (I₀ · dl / (4π)) · sin(θ) · [ (sin(ω · t') / r²) + (k · cos(ω · t') / r) ]
```

де `t' = t − r/c` — запізнілий час, `k = ω / c = 2π / λ` — хвильове число, `c ≈ 2.99792458e8 м/с` — швидкість світла у вакуумі, `ε₀ ≈ 8.85418781e-12 Ф/м` — електрична стала.

Густина потоку випромінюваної енергії описується радіальною компонентою вектора Пойнтінга `S_r`:

```
S_r(r, θ, t) = E_θ(r, θ, t) · H_φ(r, θ, t)
```

Математичний алгоритм обчислення повинен не просто оцінювати ці формули для кількох обраних точок, а будувати цілісну картину просторового розподілу. У ближній зоні (`r < λ / (2π)`) фази компонент `E` та `H` зсунуті на 90 градусів, внаслідок чого вектор Пойнтінга коливається зі подвоєною частотою `2ω`, зміщуючи енергію туди й назад без її реального віддалення від джерела. Натомість у дальній зоні (`r > 2λ`) доданки `1/r³` та `1/r²` згасають, фази полів збігаються, і потік Пойнтінга стає строго позитивним, описуючи автономну хвилю, що біжить геть.

> 🔧 **Навіщо це.** Чисельне оцінювання полів диполя необхідне при розрахунку ближньопольових завад (EMC/EMI) у високочастотній електроніці та платах, де провідники та траси друкованих плат виступають у ролі небажаних диполів Герца.

## 2. Алгоритм розрахунку та логарифмічна сітка

Оскільки напруженість електричного поля у ближній зоні спадає за законом `1/r³`, а у дальній зоні за законом `1/r`, динамічний діапазон значень полів при переході від `r = 0.01 λ` до `r = 10 λ` становить понад 6 порядків (120 дБ).

Звичайне рівномірне крокування по радіусу `Δr = const` виявляється некоректним: воно або дає занадто грубу сітку у ближній зоні, втрачаючи деталізацію реактивного поля, або генерує мільйони надлишкових точок у дальній зоні, марно витрачаючи пам'ять і процесорний час.

Тому для чисельного аналізу застосовують **логарифмічну радіальну сітку**, де відстань кожної наступної точки обчислюється за геометричною прогресією:

```
r_i = r_min · (r_max / r_min)^(i / N)
```

Це дозволяє одночасно з високою точністю деталізувати реактивне поле біля самого провідника й простежити поширення хвильового фронту на великих відстанях.

### Декартове перетворення для графічного відображення

Оскільки графічні бібліотеки працюють у декартових координатах `(x, z)`, отримані сферичні поля `(E_r, E_θ)` перераховуються у компоненти `(E_x, E_z)` за формулами повернутого базису:

```
E_x = E_r · sin(θ) + E_θ · cos(θ)
E_z = E_r · cos(θ) − E_θ · sin(θ)
```

Ці координатні перетворення дозволяють будувати векторні поля ліній напруженості у звичайному двовимірному зрізі плоскості `xz`.

## 5. Пастки, крайові випадки та оптимізація чисельного коду

При розробці високопродуктивних чисельних симуляторів електродинаміки виникає низка специфічних обчислювальних проблем, які вимагають ретельного інженерного контролю:

1. **Сингулярність у центральній точці (`r → 0`):**
   При наближенні до джерела доданки `1/r³` прямують до нескінченності. В реальному залізі диполь має скінченний радіус провідника `a`, тому обчислення виконують лише для `r > a`. У чисельному коді слід встановлювати відсічку (cutoff): якщо `r < r_min`, обчислення повертає нуль або граничне значення, щоб запобігти діленню на нуль або виклику плаваючої переповненості (`NaN` чи `Inf`).

2. **Втрата значущих розрядів (Catastrophic Cancellation):**
   У проміжній зоні (`kr ~ 1`) доданок реактивного поля `1/r³` та доданок випромінювання `-k²/r` мають близькі абсолютні значення з протилежними знаками. При відніманні двох близьких чисел у змінних із плаваючою комою 32-бітної точності (`float`) відбувається втрата значущих розрядів мантиси. Обов'язково використовуйте змінні `double` (64 біти) або `long double`.

3. **Дискретизація за часом (Критерій Куранта):**
   При побудові часової анімації поширення електромагнітної хвилі крок за часом `Δt` повинен задовольняти умову `c · Δt < Δr_min`, де `Δr_min` — найменший крок просторової сітки. Нехтування цією умовою призводить до чисельної нестійкості та розгону полів у симуляції.

4. **Розпаралелювання обчислень за допомогою OpenMP:**
   Оскільки обчислення полів у кожному вузлі сітки є повністю незалежним (відсутня міжвузлова залежність за даними), алгоритм ідеально піддається векторній оптимізації SIMD (AVX-512) та розпаралелюванню за допомогою OpenMP чи CUDA при розрахунку мільйонів точок для побудови 3D моделей випромінювання складних планарних систем.

## 7. Архітектура FDTD-чисельного двигуна та граничні умови PML

При моделюванні диполя Герца у часовій області найпоширенішим методологічним підходом є **метод сіток у часовій області (Finite-Difference Time-Domain, FDTD)**, розроблений Кейном І простір дискретизується на тривимірній комірчастій сітці Йі (Yee grid).

У кожному вузлі сітки електричні `E` та магнітні `H` компоненти рознесені у просторі на півкроку сітки `Δx/2, Δy/2, Δz/2` та у часі на півкроку `Δt/2`. Це дозволяє замінити неперервні роторні рівняння Максвелла на явні центрально-різницеві різницеві схеми другого порядку точності:

```
H_x^(n+1/2)(i, j, k) = H_x^(n-1/2)(i, j, k) − (Δt / μ₀) · [ (E_z^n(i, j+1, k) − E_z^n(i, j, k))/Δy − (E_y^n(i, j, k+1) − E_y^n(i, j, k))/Δz ]
```

### Абсорбуючі граничні умови (PML)

Оскільки розрахункова область є скінченною, для запобігання штучному відбиттю хвиль від зовнішніх меж розрахункового куба застосовують **ідеально узгоджені шари (Perfectly Matched Layers, PML)** за рецептурою Беренже. У шарі PML уводять анізотропні електричні й магнітні втрати `σ_e` та `σ_m`, пропорційні відстані від внутрішньої межі:

```
σ_e(x) = σ_max · (x / d_pml)^m
```

де `d_pml` — товщина поглинального шару (зазвичай 8–12 комірок сітки), а `m = 3..4` — показник градації втрат. Це забезпечує поглинання випромінюваної диполем хвилі з коефіцієнтом відбиття менше `−80 dB`.

## 8. Трасування ліній напруженості поля методом Рунге-Кутти (RK4)

Для візуалізації силових ліній електричного поля, які утворюють замкнені петлі у процесі відриву від диполя Герца, обчислюють векторні лінії (траєкторії), дотичні до вечора `E` у кожній точці простору.

Рівняння силової лінії задається диференціальним співвідношенням `dr / ds = E(r) / |E(r)|`, де `s` — натуральний параметр вздовж лінії.

Для трасування силових ліній у чисельному коді застосовують **метод Рунге-Кутти 4-го порядку (RK4)**:

```
k₁ = f(r_n)
k₂ = f(r_n + 0.5·Δs·k₁)
k₃ = f(r_n + 0.5·Δs·k₂)
k₄ = f(r_n + Δs·k₃)
r_(n+1) = r_n + (Δs / 6) · (k₁ + 2·k₂ + 2·k₃ + k₄)
```

де `f(r) = E(r) / |E(r)|` — нормований вектор електричного поля.

При наближенні крок `Δs` адаптивно зменшується пропорційно градієнту поля `|∇E|`, що дозволяє з високою точністю відтворювати вершини перетяжок і точні точки самоперетину силових ліній біля диполя.

## 9. Обчислення S-параметрів та вхідного імпетдансу Z_in(f)

У чисельному розрахунковому двигуні для визначення характеристик узгодження диполя з передавачем виконують швидке перетворення Фур'є (FFT) часових сигналів напруги `V(t)` та струму `I(t)` у порту живлення диполя:

```
V(f) = ∫_0^T V(t) · e^(−j·2π·f·t) dt
I(f) = ∫_0^T I(t) · e^(−j·2π·f·t) dt
```

Вхідний комплексний імпеданс диполя обчислюється як `Z_in(f) = V(f) / I(f) = R_in(f) + j · X_in(f)`.

Коефіцієнт відбиття за напругою `S₁₁` відносно стандартного опорного імпедансу `Z₀ = 50 Ом` задається формулою:

```
S₁₁(f) = (Z_in(f) − Z₀) / (Z_in(f) + Z₀)
```

У логарифмічному масштабі `S₁₁_dB = 20 · log₁₀(|S₁₁|)`. Чисельний розрахунок підтверджує, що для елементарного диполя Герца `dl ≪ λ` значення `S₁₁` дорівнює майже `0 dB` (повне відбиття), що підтверджує необхідність зовнішніх LC-кіл узгодження.
