# 🧮 Математична формалізація псевдовекторів та тензор Леві-Чивіти

Для точного опису геометричних та фізичних властивостей векторних величин математичний апарат диференціює вектори за їхньою поведінкою під час ортогональних перетворень координат. У тривимірному евклідовому просторі будь-яку зміну базису можна представити ортогональною матрицею `Q`, яка належить до ортогональної групи `O(3)` і задовольняє умову:

```
Qᵀ · Q = I      [умова ортогональності матриці]
```

Взявши детермінант від обох частин цієї матричної рівності, отримуємо `det(Qᵀ · Q) = det(Q)² = det(I) = 1`, звідки випливає, що детермінант будь-якої ортогональної матриці може набувати лише двох значень: `det(Q) = +1` або `det(Q) = -1`. 

Ортогональна група `O(3)` розпадається на дві зв'язані компоненти:

1. **Група власних обертань `SO(3)`:** Множина матриць із `det(Q) = +1`. Ці перетворення зберігають орієнтацію базису (праворучна система залишається праворучною) і описують фізичні повороти абсолютно твердого тіла навколо будь-якої осі.
2. **Невласні перетворення `O(3) \ SO(3)`:** Множина матриць із `det(Q) = -1`. Ці перетворення змінюють орієнтацію базису на протилежну (праворучна система переходить у ліворучну) і описують дзеркальні відображення та просторову інверсію.

Саме детермінант матриці перетворення `det(Q)` є фундаментальним математичним критерієм, що розділяє полярні вектори, аксіальні вектори та псевдоскаляри.

## Закони трансформації полярних та аксіальних векторів

Ззвичайний (**полярний**) вектор `v` при переході до нової системи координат за допомогою ортогональної матриці `Q` трансформується за стандартним лінійним законом тензора першого рангу:

```
v' = Q · v      [трансформація полярного вектора]
```

Аксіальний вектор (**псевдовектор**) `b` при тому самому переході отримує додатковий скалярний множник, що дорівнює детермінанту матриці перетворення `det(Q)`:

```
b' = det(Q) · (Q · b)      [трансформація аксіального вектора]
```

Під час власних обертань простору (`Q ∈ SO(3)`), коли `det(Q) = +1`, обидва види векторів поводяться абсолютно однаково: `v' = Q · v` та `b' = Q · b`. Тому в геометрії обертань без віддзеркалень відмінність між ними залишається непомітною. Різниця проявляється виключно під час невласних перетворень.

Розглянемо операцію центральної просторової інверсії (віддзеркалення всіх трьох осей координат відносно початку координат), яка задається матрицею `Q_inv = -I`:

```
Q_inv = ⎡ -1   0   0 ⎤
        ⎢  0  -1   0 ⎥
        ⎣  0   0  -1 ⎦

det(Q_inv) = (-1) · (-1) · (-1) = -1      [визначник інверсії]
```

Підставляючи матрицю `Q_inv` у закони трансформації обох векторів, отримуємо:

```
v' = (-I) · v = -v                         [полярний вектор змінює знак]
b' = (-1) · (-I) · b = +I · b = +b        [аксіальний вектор зберігає знак]
```

Аналогічно виникає поняття **псевдоскаляра** `s` — величини, яка не змінюється при власних поворотах, але змінює свій знак на протилежний під дією інверсії чи віддзеркалення:

```
s' = det(Q) · s      [закон трансформації псевдоскаляра]
```

Прикладом псевдоскаляра є мішаний добуток трьох полярних векторів `u · (v × w)`, який визначає орієнтований об'єм паралелепіпеда, або спіральність частинки `s · p` (скалярний добуток спіну на імпульс).

## Дзеркальне відображення відносно довільної площини

Розглянемо загальніше невласне перетворення — дзеркальне відображення відносно площини з одиничним вектором нормалі `n` (`|n| = 1`). Оператор відображення `R_n` описується матрицею:

```
R_n = I - 2 · (n ⊗ n)      [матриця віддзеркалення відносно нормалі n]
```

Матричні елементи цієї матриці дорівнюють `(R_n)_ij = δ_ij - 2 n_i n_j`. Обчислимо детермінант матриці `R_n`:

```
det(R_n) = det(I - 2 n ⊗ n) = 1 - 2 = -1      [детермінант віддзеркалення]
```

Застосуємо оператор `R_n` до полярного вектора `v`:

```
v' = R_n · v = v - 2 (n · v) n      [відображення полярного вектора]
```

Компонента вектора `v`, паралельна площині дзеркала (перпендикулярна до `n`), залишається незмінною, а нормальна компонента `(n · v) n` змінює знак на протилежний.

Тепер застосуємо оператор відображення до аксіального вектора `b`:

```
b' = det(R_n) · (R_n · b)
   = (-1) · [b - 2 (n · b) n]
   = -b + 2 (n · b) n      [відображення аксіального вектора]
```

Тут ситуація дзеркально протилежна: нормальна до дзеркала компонента аксіального вектора залишається незмінною, а тангенціальні компоненти змінюють свої знаки на протилежні. 

Це чітко пояснює поведінку колового струму у дзеркалі: якщо рамка зі струмом лежить у площині дзеркала (нормаль `n` перпендикулярна площині рамки), вектор магнітного моменту `μ` спрямований уздовж `n`. При дзеркальному відображенні вектор `μ'` залишається спрямованим точно так само, оскільки нормальна компонента аксіального вектора знака не змінює.

## Символ Леві-Чивіти та векторний добуток

Фундаментальним алгебраїчним інструментом побудови псевдовекторів у тривимірному евклідовому просторі є повністю антисиметричний тензор Леві-Чивіти `ε_ijk`.

Символ Леві-Чивіти задається трійкою індексів `(i, j, k ∈ {1, 2, 3})` і визначається наступними умовами:

```
ε_ijk = +1,  якщо (i, j, k) є парною перестановкою індексів (1, 2, 3)
ε_ijk = -1,  якщо (i, j, k) є непарною перестановкою індексів (1, 2, 3)
ε_ijk =  0,  якщо принаймні два індекси збігаються (i=j, j=k, i=k)
```

За допомогою символу Леві-Чивіти `i`-та компонента векторного добутку двох полярних векторів `u` та `w` записується у вигляді суми за індексами, що повторюються (за правилом Ейнштейна):

```
c_i = (u × w)_i = ∑_j ∑_k ε_ijk · u_j · w_k      [векторний добуток через ε_ijk]
```

Строго доведемо трансформаційні властивості утвореної величини `c` при застосуванні довільного ортогонального перетворення `Q`. 

Компоненти векторів у новій системі координат дорівнюють `u'_j = ∑_m Q_jm u_m` та `w'_k = ∑_n Q_kn w_n`. Обчислимо компоненти результуючого вектора `c'` у новій системі координат:

```
c'_i = ∑_j ∑_k ε_ijk · u'_j · w'_k
     = ∑_j ∑_k ε_ijk · (∑_m Q_jm u_m) · (∑_n Q_kn w_n)
     = ∑_m ∑_n (∑_j ∑_k ε_ijk Q_jm Q_kn) · u_m · w_n      [згруповано матричні елементи]
```

З лінійної алгебри відома фундаментальна тотожність, що пов'язує символ Леві-Чивіти з матричними елементами ортогонального перетворення `Q`:

```
∑_j ∑_k ε_ijk Q_jm Q_kn = det(Q) · ∑_p Q_ip ε_pmn      [тотожність тензорного перетворення]
```

Підставляючи це співвідношення у вираз для `c'_i`, отримуємо:

```
c'_i = det(Q) · ∑_p Q_ip (∑_m ∑_n ε_pmn u_m w_n)
     = det(Q) · ∑_p Q_ip c_p      [закон трансформації псевдовектора]
```

Цей математичний вивід строго доводить, що векторний добуток двох полярних векторів `u × w` є псевдовектором: під дією невласного перетворення з `det(Q) = -1` він набуває додаткового мінуса, ніж звичайний вектор.

## Тотожності згортання символу Леві-Чивіти та правилу BAC-CAB

Для точних розрахунків у векторному аналізі ключовою є тотожність згортання двох символів Леві-Чивіти за спільним першим індексом:

```
∑_i ε_ijk · ε_imn = δ_jm · δ_kn - δ_jn · δ_km      [тотожність згортання тензора]
```

Де `δ_ij` — символ Кронекера (`δ_ij = 1` при `i=j`, та `δ_ij = 0` при `i ≠ j`).

Виведемо відоме тотожність потрійного векторного добутку `A × (B × C) = B(A · C) - C(A · B)` (правило BAC-CAB) у компонентах за допомогою тензора Леві-Чивіти:

```
[A × (B × C)]_i = ∑_j ∑_k ε_ijk A_j (B × C)_k
                = ∑_j ∑_k ε_ijk A_j (∑_m ∑_n ε_kmn B_m C_n)
                = ∑_j ∑_m ∑_n (∑_k ε_ijk ε_kmn) A_j B_m C_n      [згруповано символи]
```

Оскільки `ε_ijk = ε_kij`, використаємо тотожність згортання `∑_k ε_kij ε_kmn = δ_im δ_jn - δ_in δ_jm`:

```
[A × (B × C)]_i = ∑_j ∑_m ∑_n (δ_im δ_jn - δ_in δ_jm) A_j B_m C_n
                = (∑_j A_j C_j) B_i - (∑_j A_j B_j) C_i
                = B_i (A · C) - C_i (A · B)      [доведення правила BAC-CAB]
```

Цей вивід показує, що потрійний векторний добуток `A × (B × C)` двох полярних векторів `B, C` та одного полярного `A` дає полярний вектор, оскільки `B × C` є аксіальним, а `Полярний × Аксіальний = Полярний`.

## Алгебра Лі so(3) та матричне представлення векторного добутку

Будь-якому полярному або аксіальному вектору `a = (a_1, a_2, a_3)` у тривимірному просторі відповідає кососиметрична матриця `[a]_×`, яка є елементом алгебри Лі `so(3)` (дотичного простору до групи обертань `SO(3)` у одиниці):

```
[a]_× = ⎡   0   -a_3   a_2 ⎤
        ⎢  a_3    0   -a_1 ⎥
        ⎣ -a_2   a_1    0  ⎦      [кососиметрична матриця]
```

Векторний добуток `c = a × b` записується як дія матриці `[a]_×` на вектор-стовпчик `b`:

```
a × b = [a]_× · b      [матричний добуток]
```

Генератори обертань навколо осей X, Y, Z задаються матрицями `J_x, J_y, J_z`:

```
J_x = ⎡  0  0  0 ⎤       J_y = ⎡  0  0  1 ⎤       J_z = ⎡  0 -1  0 ⎤
      ⎢  0  0 -1 ⎥             ⎢  0  0  0 ⎥             ⎢  1  0  0 ⎥
      ⎣  0  1  0 ⎦             ⎣ -1  0  0 ⎦             ⎣  0  0  0 ⎦
```

Комутаційні співвідношення алгебри Лі `so(3)` точно відтворюють векторний добуток базисних ортомів:

```
[J_i, J_j] = J_i · J_j - J_j · J_i = ∑_k ε_ijk J_k      [комутаційні співвідношення]
```

Матрична експонента кососиметричної матриці `exp(θ [n]_×)` задає конечний поворот на кут `θ` навколо одиничної осі `n` за формулою Родріга:

```
exp(θ [n]_×) = I + sin(θ) [n]_× + (1 - cos(θ)) [n]_×²      [формула повороту Родріга]
```

## Квантовомеханічні оператори моменту імпульсу та парність

У квантовій механіці оператор орбітального моменту імпульсу частинки `L = r × p` задається векторним добутком оператора координати `r` та оператора імпульсу `p = -i ℏ ∇`.

Оскільки `r` та `p` є полярними операторами (`P r P⁻¹ = -r`, `P p P⁻¹ = -p`), оператор моменту імпульсу `L` є аксіальним оператором і комутує з оператором просторової інверсії `P`:

```
P L P⁻¹ = (-r) × (-p) = +L      [аксіальний квантовий оператор]
```

Власні функції оператора кутового моменту (сферичні гармоніки `Y_l^m(θ, φ)`) володіють певною просторовою парністю, яка визначається орбітальним квантовим числом `l`.

Стани з парним значенням `l` (s-, d-стани) мають додатну парність `P = +1`, а стани з непарним `l` (p-, f-стани) мають від'ємну парність `P = -1`. Тій факт, що оператор `L` зберігає свій знак при інверсії, гарантує збереження орбітального моменту в усіх симетричних квантових системах. Фізичний спін електронних та ядерних систем також описується аксіальним оператором спінового моменту `S`, що дає повний вектор моменту `J = L + S`. Для електронних хвильових функцій в атомі Гейзенберга це встановлює суворі правила відбору за парністю для дипольних оптичних переходів між енергетичними рівнями.

## Геометрична алгебра Клиффорда: Альтернатива без правил рук

Сучасним підходом у теоретичній фізиці та комп'ютерній графіці, який повністю звільняє математику від штучного вибору орієнтації правої або лівої руки, є геометрична алгебра Клиффорда (англ. *Geometric Algebra* `Cl_3,0`).

У геометричній алгебри двох векторів `a` та `b` визначається геометричний добуток `a b`, який розкладається на скалярну та двовекторну (бівекторну) частини:

```
a b = a · b + a ∧ b      [геометричний добуток Клиффорда]
```

Тут:
- `a · b = 1/2 (a b + b a)` — симетричний скалярний добуток (число).
- `a ∧ b = 1/2 (a b - b a)` — антисиметричний зовнішній добуток Грассмана (бівектор).

Бівектор `a ∧ b` описує орієнтований фрагмент площини, обмежений векторами `a` та `b`. Він має площу `|a||b|sin(θ)` та напрямок обертання в цій площині, але **не містить жодної перпендикулярної стрілки**!

Зв'язок між бівектором `a ∧ b` та класичним псевдовектором `a × b` задається через псевдоскаляр об'єму `I = e₁ e₂ e₃`:

```
a ∧ b = I · (a × b)      [зв'язок бівектора з псевдовектором]
```

Оскільки псевдоскаляр `I` задовольняє умову `I² = -1`, він відіграє роль уявної одиниці у тривимірному просторі.

Застосуємо просторову інверсію `P: a → -a, b → -b` до бівектора `a ∧ b`:

```
P(a ∧ b) = (-a) ∧ (-b) = + (a ∧ b)      [бівектор природно зберігає знак]
```

Геометрична алгебра розкриває принципову істину: аксіальні вектори виникли в історії фізики виключно як спосіб представити орієнтовані площини (бівектори) у вигляді векторних стрілок. Бівектор є чисто геометричним об'єктом, який взагалі не вимагає вибору орієнтації базису чи правил правої руки. Наприклад, обертальна динаміка твердого тіла описується ротором `R` та бівектором кутової швидкості `Ω = I ω`, що повністю усуває необхідність у псевдовекторах та векторі кутової швидкості `ω`.

## Дуальність Ходжа та зовнішні диференціальні форми

Глибше розуміння математичної природи псевдовекторів дає апарат диференціальних форм та дуальності Ходжа.

У тривимірному просторі псевдовектор взагалі не є істинним елементом векторного простору `V`. Насправді він є репрезентацією двовимірного зовнішнього елемента — **2-форми** або антисиметричного тензора другого рангу.

За допомогою оператора дуальності Ходжа `★` (зірочка Ходжа) кожному псевдовектору `b = (b_x, b_y, b_z)` ставить у відповідність кососиметричний (антисиметричний) тензор другого рангу `B_ij`:

```
B_ij = ∑_k ε_ijk b_k      [дуальний тензор за Ходжем]

B = ⎡   0    b_z  -b_y ⎤
    ⎢ -b_z    0    b_x ⎥
    ⎣  b_y  -b_x    0  ⎦      [кососиметрична матриця 3×3]
```

У мові диференціальних форм:
- **0-форма:** Скалярне поле `φ(x, y, z)`.
- **1-форма:** Полярне векторне поле `E = E_x dx + E_y dy + E_z dz`.
- **2-форма:** Аксіальне векторне поле (магнітна індукція) `B = B_x dy ∧ dz + B_y dz ∧ dx + B_z dx ∧ dy`.
- **3-форма:** Густина об'єму (скалярна густина заряду) `ρ dx ∧ dy ∧ dz`.

Зовнішній диференціал `d` діє на 1-форму електричного поля `E` і повертає 2-форму ротора:

```
dE = (∂E_y/∂x - ∂E_x/∂y) dx ∧ dy + (∂E_z/∂y - ∂E_y/∂z) dy ∧ dz + (∂E_x/∂z - ∂E_z/∂x) dz ∧ dx
   = ★ (∇ × E)      [ротор як 2-форма]
```

Оскільки для зовнішнього диференціала завжди виконується тотожність `d² = 0`, звідси негайно випливають фундаментальні векторні тотожності:

```
d(dφ) = 0   =>   ∇ × (∇ φ) = 0      [ротор градієнта дорівнює нулю]
d(dE) = 0   =>   ∇ · (∇ × E) = 0    [дивергенція ротора дорівнює нулю]
```

Кососиметричний тензор `B_ij` є справжнім полярним тензором другого рангу і трансформується за тензорним законом `B' = Q · B · Qᵀ`.

Застосуємо до тензора `B` матрицю просторової інверсії `Q = -I`:

```
B' = (-I) · B · (-I)ᵀ = (-I) · B · (-I) = +B      [збереження тензора при інверсії]
```

Звідси стає очевидною причина ізоморфізму: у тривимірному просторі `N = 3` кількість незалежних компонент антисиметричної матриці `3×3` дорівнює `N(N-1)/2 = 3(2)/2 = 3`. Оскільки кількість компонент кососиметричної матриці 3×3 точно збігається з кількістю компонент 3D-вектора, фізики у XIX столітті об'єднали ці 3 компоненти у векторну стрілку, назвавши її псевдовектором.

## Псевдотензори та релятивістські інваріанти Фарадея

У чотиривимірному просторі-часі Мінковського з метричним тензором `η_μν = diag(1, -1, -1, -1)` 4-тензор Леві-Чивіти `ε_αβγδ` задає псевдотензорні інваріанти електромагнітного поля.

Детермінант 4D метрики дорівнює `-1`, тому 4-тензор Леві-Чивіти трансформується з урахуванням детермінанта лоренцевих перетворень `det(Λ) = ±1`. 

З тензора електромагнітного поля `F_μν` та дуального тензора `★ F^μν = 1/2 ε^μναβ F_αβ` можна побудувати два фундаментальні лоренц-інваріанти:

```
I₁ = F_μν · F^μν = 2 (B² - E²/c²)                  [істинний скалярний інваріант]
I₂ = F_μν · (★ F^μν) = - (4 / c) · (E · B)         [псевдоскалярний інваріант]
```

Аналіз другого інваріанта `I₂ = - (4 / c) · (E · B)` демонструє важливий фізичний факт:

1. Якщо `E · B ≠ 0` (електричне та магнітне поля утворюють гострий або тупий кут у даній точці), електромагнітне поле володіє **вродженою геометричною хіральністю** (псевдоскаляр `I₂ ≠ 0`). Жоден лоренців перехід до іншої інерціальної системи координат не здатний обнулити жодне з цих полів.
2. Якщо `E · B = 0` (поля перпендикулярні, як у плоскій електромагнітній хвилі або для статичного заряду у магнітному полі), то псевдоскаляр `I₂ = 0`. У цьому випадку завжди існує система відліку, у якій або `E' = 0`, або `B' = 0`.

Це дає вищий математичний інструмент класифікації електромагнітних конфігурацій без використання штучних просторових векторних малюнків.

## Теорема Гурвіца та унікальність 3D та 7D просторів

У вищій алгебрі виникає запитання: у яких ще просторах існує операція векторного добутку, що повертає вектор, перпендикулярний до двох множників?

За теоремою Гурвіца про нормовані алгебри з діленням (алгебри дійсних чисел `R`, комплексних чисел `C`, кватерніонів `H` та октоніонів `O`), векторний добуток векторів можна визначити **виключно у 3-вимірному та 7-вимірному евклідовому просторах**.

У 7-вимірному просторі векторний добуток базується на уявній частині октоніонів і визначається через зв'язки плоскої геометрії Фано. Проте у 7D векторний добуток не задовольняє тотожність Якобі, що робить 3-вимірний простір єдиним евклідовому простором, де векторний добуток утворює алгебру Лі `so(3)`.

У просторах усіх інших вимірностей (`N ≠ 3, 7`) результат зовнішнього множення двох векторів `u ∧ w` залишається двовектором (бівектором 2-ї ступені) і не може бути зведеним до єдиного вектора.

## Псевдотензори вищих рангів

Поняття парності поширюється на тензори довільного рангу. Псевдотензор `T` рангу `k` трансформується при зміні базису з урахуванням детермінант `det(Q)`:

```
T'_i1_i2...ik = det(Q) · ∑_j1 ∑_j2 ... ∑_jk Q_i1j1 Q_i2j2 ... Q_ikjk T_j1j2...jk      [псевдотензор]
```

1. **Псевдоскаляр (ранг 0):** `s' = det(Q) · s`. Змінює знак при віддзеркаленні. Приклад: `(u · (v × w))` (полярні `u,v,w`).
2. **Псевдовектор (ранг 1):** `b' = det(Q) · (Q · b)`. Зберігає знак при інверсії. Приклад: `B = ∇ × A`.
3. **Псевдотензор другого рангу (ранг 2):** `M' = det(Q) · (Q · M · Qᵀ)`. Змінює знак при інверсії. Приклад: тензор п'єзоелектричних або гіротропних властивостей кристала.

## Алгебраїчна замкненість парності

Множення векторів різних типів задовольняє строгу алгебраїчну групу відносно парності. Введемо парність `p = +1` для аксіальних об'єктів та `p = -1` для полярних об'єктів. При множенні векторів їхні значення парності перемножуються:

### 1. Полярний × Полярний = Аксіальний
```
p = (-1) · (-1) = +1      [приклад: r × p = L, ∇ × E = -∂B/∂t]
```
Векторний добуток двох полярних векторів (радіус-вектора `r` та імпульсу `p`) дає аксіальний вектор (момент імпульсу `L`).

### 2. Полярний × Аксіальний = Полярний
```
p = (-1) · (+1) = -1      [приклад: v × B → F, E × B → S]
```
Векторний добуток полярного вектора швидкості `v` на аксіальний вектор магнітного поля `B` повертає справжній полярний вектор сили Лоренца `F`.

### 3. Аксіальний × Аксіальний = Аксіальний
```
p = (+1) · (+1) = +1      [приклад: ω × L → τ]
```
Векторний добуток двох аксіальних векторів (кутової швидкості `ω` та моменту імпульсу `L`) дає аксіальний вектор прецесійного крутного моменту `τ`.

Така алгебраїчна замкненість гарантує однорідність за парністю у всіх рівняннях фізики: ліва та права частини будь-якого коректного фізичного закону завжди належать до одного й того самого типу математичних об'єктів.
