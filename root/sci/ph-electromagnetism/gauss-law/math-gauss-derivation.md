# 🧮 Математичний вивід закону Гаусса та геометрія симетрій

Ця вставка містить строгий математичний вивід закону Гаусса, починаючи від закону Кулона та концепції тілесного кута, розгляд чотирьох класичних симетрій (сферичної, циліндричної, плоскої та оболонкової), а також доведення еквівалентності інтегральної та диференціальної форм через теорему дивергенції Остроградського-Гаусса, мультипольне розкладення, функції Ґріна та граничні умови на межі двох середовищ.

## 1. Математичне виведення з закону Кулона

### Точковий заряд у центрі сфери

Розглянемо точковий заряд `q`, розміщений у початку координат. За законом Кулона напруженість електричного поля `E` на відстані `r` від заряду дорівнює:

```
E = (q / (4 · π · ε₀ · r²)) · r̂
```

де `r̂` — одиничний вектор (орт), спрямований радіально від заряду `q` до точки спостереження, а `ε₀` — електрична стала (`ε₀ ≈ 8.854 · 10⁻¹² Ф/м`).

Оберемо гауссову поверхню `S` у вигляді сфери радіуса `r` з центром у точці розташування заряду `q`. Вектор елементарної площі `dA` на цій сферичній поверхні спрямований по зовнішній нормалі `n̂`, тобто паралельний орт-вектору `r̂`:

```
dA = n̂ · dA = r̂ · dA
```

Обчислимо скалярний добуток `E · dA`:

```
E · dA = (q / (4 · π · ε₀ · r²)) · (r̂ · r̂) · dA
       = (q / (4 · π · ε₀ · r²)) · dA    [бо r̂ · r̂ = 1]
```

Інтегруємо цей вираз по всій замкненій сферичній поверхні `S`:

```
∮ S E · dA = ∮ S (q / (4 · π · ε₀ · r²)) · dA
           = (q / (4 · π · ε₀ · r²)) · ∮ S dA    [бо r стале на поверхні сфери]
           = (q / (4 · π · ε₀ · r²)) · (4 · π · r²) [площа сфери A = 4·π·r²]
           = q / ε₀
```

Таким чином, потік кулонівського поля через сферичну поверхню дорівнює `q / ε₀` і зовсім не залежить від радіуса сфери `r`.

### Довільна замкнена поверхня та геометричний тілесний кут

Тепер узагальнимо результат на замкнену поверхню `S` довільної форми, усередині якої лежить заряд `q`.

Розглянемо елементарний майданчик `dA` на поверхні `S`. Скалярний добуток `E · dA` дорівнює:

```
E · dA = E · cos(θ) · dA
```

де `θ` — кут між вектором поля `E` та зовнішньою нормаллю `n̂` до майданчика `dA`.

Величина `dA · cos(θ)` являє собою проекцію майданчика `dA` на площину, перпендикулярну до радіус-вектора `r`. Означення елементарного тілесного кута `dΩ`, під яким майданчик `dA` видно з точки розташування заряду `q`, має вигляд:

```
dΩ = (dA · cos(θ)) / r² = (r̂ · n̂ · dA) / r²
```

Підставляючи вираз для `E` та `dΩ` у формулу потоку, отримуємо:

```
dΦ_E = E · dA    [за означенням елементарного потоку]
     = (q / (4 · π · ε₀ · r²)) · cos(θ) · dA    [підстановка поля Кулона та скалярного добутку]
     = (q / (4 · π · ε₀)) · ((cos(θ) · dA) / r²)    [перегрупування множників біля r²]
     = (q / (4 · π · ε₀)) · dΩ    [підстановка означення тілесного кута dΩ]
```

Інтегрування елементарного потоку по всій замкненій поверхні `S` зводиться до інтегрування тілесного кута по всьому повному телескопічному простору навколо внутрішньої точки:

```
∮ S dΦ_E = (q / (4 · π · ε₀)) · ∮ S dΩ
```

Оскільки повний тілесний кут навколо будь-якої внутрішньої точки дорівнює `4·π` стерадіан (`∮ dΩ = 4·π`), отримуємо:

```
Φ_E = ∮ S E · dA = (q / (4 · π · ε₀)) · (4 · π) = q / ε₀
```

Це доводить, що потік електричного поля не залежить від конкретної геометричної форми замкненої поверхні `S`.

### Випадок заряду поза замкненою поверхнею

Якщо точковий заряд `q` лежить **зовні** замкненої поверхні `S`, будь-який вузький конус тілесного кута `dΩ` з вершиною в точці `q` перетинає поверхню `S` парну кількість разів (щонайменше двічі: під час входу в об'єм і під час виходу з нього).

1. На вхідній ділянці `dA1` вектор нормалі `n̂1` спрямований назустріч полю `E1` (кут `θ1 > 90°`), тому `cos(θ1) < 0` і потік `dΦ1 < 0`.
2. На вихідній ділянці `dA2` вектор нормалі `n̂2` спрямований за полем `E2` (кут `θ2 < 90°`), тому `cos(θ2) > 0` і потік `dΦ2 > 0`.

Оскільки обидва майданчики вирізаються одним і тим самим конусом тілесного кута `dΩ`:

```
dΦ1 = - (q / (4 · π · ε₀)) · dΩ
dΦ2 = + (q / (4 · π · ε₀)) · dΩ
dΦ1 + dΦ2 = 0
```

Сума вхідного та вихідного потоків точно дорівнює нулю. Відтак зовнішній заряд не дає жодного внеску в результуючий потік через замкнену поверхню:

```
∮ S E · dA = 0   [якщо q зовні S]
```

### Суперпозиція та неперервний розподіл зарядів

За принципом суперпозиції, напруженість поля результуючої системи зарядів дорівнює векторній сумі полів кожного окремого заряду `E = ∑ Ei`. Тоді потік дорівнює:

```
∮ S E · dA = ∮ S (∑ Ei) · dA = ∑ (∮ S Ei · dA)
```

Заряд `qi`, що лежить усередині `S`, дає внесок `qi / ε₀`, а зовнішні заряди дають `0`. Підсумовуючи всі внутрішні заряди `Q_enclosed = ∑ q_in`, отримуємо загальну інтегральну форму закону Гаусса:

```
∮ S E · dA = (1 / ε₀) · ∑ q_in = Q_enclosed / ε₀
```

Для неперервного розподілу заряду з об'ємною густиною `ρ(r)` повний внутрішній заряд обчислюється як об'ємний інтеграл:

```
Q_enclosed = ∭ V ρ(r) dV
```

Формалізм дельта-функції Дірака `δ(r - r₀)` дозволяє уявити точковий заряд `q` як граничний випадок об'ємного розподілу з густиною `ρ(r) = q · δ(r - r₀)`. Тоді об'ємний інтеграл дає точне значення `q`, а закон Гаусса зберігає свою єдину математичну форму як для точкових, так і для розподілених зарядів:

```
∮ S E · dA = (1 / ε₀) · ∭ V ρ(r) dV
```

## 2. Строгий розрахунок фундаментальних геометрій

### Сферична симетрія: суцільна куля та тонка сфера

#### А. Суцільна рівномірно заряджена куля

Розглянемо суцільну кулю радіуса `R`, рівномірно заряджену по об'єму з постійною густиною `ρ = Q / ((4/3)·π·R³)`.

З міркувань сферичної симетрії вектор поля `E` у будь-якій точці спрямований уздовж радіус-вектора `r`, а його модуль `E(r)` залежить лише від відстані `r` до центру кулі. Як гауссову поверхню оберемо концентричну сферу радіуса `r`.

1. **Зовнішнє поле (`r ≥ R`)**: Гауссова сфера повністю охоплює весь заряд кулі `Q_enclosed = Q`:
   ```
   ∮ S E · dA = E(r) · ∮ S dA = E(r) · (4 · π · r²)
   E(r) · (4 · π · r²) = Q / ε₀
   E(r) = Q / (4 · π · ε₀ · r²)    [для r ≥ R]
   ```
   Зовні куля створює таке саме поле, як і точковий заряд `Q`, розміщений у її центрі.

2. **Внутрішнє поле (`r < R`)**: Гауссова сфера радіуса `r` охоплює лише частину заряду, що міститься в об'ємі радіуса `r`:
   ```
   Q_enclosed = ρ · V(r) = ρ · (4/3) · π · r³ = Q · (r³ / R³)
   E(r) · (4 · π · r²) = (Q / ε₀) · (r³ / R³)
   E(r) = (Q · r) / (4 · π · ε₀ · R³)    [для r < R]
   ```
   Поле всередині кулі зростає строго лінійно від `0` в центрі до максимального значення `E_max = Q / (4·π·ε₀·R²)` на її поверхні.

#### Б. Тонка заряджена сферична оболонка

Розглянемо тонку сферу радіуса `R`, по поверхні якої рівномірно розподілено заряд `Q` з поверхневою густиною `σ = Q / (4·π·R²)`.

1. **Всередині оболонки (`r < R`)**: Оберемо гауссову сферу радіуса `r < R`. Оскільки весь заряд знаходиться на зовнішній оболонці, усередині гауссової сфери заряду немає (`Q_enclosed = 0`). Отже:
   ```
   E(r) · (4 · π · r²) = 0  →  E(r) = 0    [для r < R]
   ```
   Усередині будь-якої сферично симетричної зарядженої оболонки електричне поле повністю відсутнє.
2. **Зовні оболонки (`r > R`)**: Гауссова сфера охоплює весь заряд `Q`, тому поле збігається з полем точкового заряду:
   ```
   E(r) = Q / (4 · π · ε₀ · r²)    [для r > R]
   ```

### Циліндрична симетрія: нитка, циліндр та коаксіальна лінія

#### А. Нескінченна заряджена нитка

Розглянемо нескінченну пряму нитку з лінійною густиною заряду `λ = dQ / dz`.

Як гауссову поверхню оберемо співвісний циліндр радіуса `r` та висоти `L`. Поверхня складається з двох плоских кришок `A_caps` та бічної стінки `A_side`.

1. **Потік через кришки**: нормаль до кришок `n̂_caps` паралельна осі циліндра, тоді як поле `E` перпендикулярне до осі. Кут `θ = 90°`, `cos(90°) = 0`:
   ```
   ∬ A_caps E · dA = 0
   ```
2. **Потік через бічну стінку**: поле `E` скрізь перпендикулярне до бічної поверхні (`E ∥ n̂_side`), а модуль `E(r)` сталий по всій бічній поверхні площею `2·π·r·L`:
   ```
   ∬ A_side E · dA = E(r) · (2 · π · r · L)
   ```

Внутрішній заряд усередині циліндра висотою `L` дорівнює `Q_enclosed = λ · L`. За законом Гаусса:

```
E(r) · (2 · π · r · L) = (λ · L) / ε₀
E(r) = λ / (2 · π · ε₀ · r)
```

#### Б. Об'ємний циліндр та коаксіальний кабель

Для суцільного циліндра радіуса `R` з об'ємною густиною заряду `ρ`:
- Зовні (`r ≥ R`): `E(r) = (ρ · R²) / (2 · ε₀ · r) = λ / (2 · π · ε₀ · r)`
- Всередині (`r < R`): `Q_enclosed = ρ · π · r² · L`, отже:
  ```
  E(r) · (2 · π · r · L) = (ρ · π · r² · L) / ε₀
  E(r) = (ρ · r) / (2 · ε₀)
  ```

У коаксіальному кабелі з внутрішньою жилою заряду `+λ` та зовнішнім екраном `-λ` поле між жилою та екраном дорівнює `E = λ / (2·π·ε₀·r)`, а зовні екрана `E = 0`, оскільки сумарний заряд усередині гауссового циліндра радіуса `r > R_outer` дорівнює `(+λ) + (-λ) = 0`.

### Плоска симетрія: одинарна площина та плоский конденсатор

#### А. Одинарна нескінченна площина

Розглянемо нескінченну тонку площину з поверхневою густиною заряду `σ = dQ / dA`.

Побудуємо гауссову поверхню у вигляді циліндрика («таблетки»), що прошиває площину. Денця таблетки площею `A` паралельні зарядженій площині й розміщені симетрично по обидва боки, а бічні стінки перпендикулярні до площини.

1. **Потік через бічні стінки**: поле `E` паралельне стінкам (`E ⊥ n̂_wall`), тому потік дорівнює нулю.
2. **Потік через два денця**: на кожному з двох денець поле `E` напрямлене по зовнішній нормалі `n̂`, даючи однаковий потік `E · A`:
   ```
   Φ_E = E · A + E · A = 2 · E · A
   ```

Заряд усередині таблетки `Q_enclosed = σ · A`. За законом Гаусса:

```
2 · E · A = (σ · A) / ε₀
E = σ / (2 · ε₀)
```

Модуль поля нескінченної площини **не залежить від відстані** — поле є строго однорідним.

#### Б. Плоский конденсатор (дві різнойменно заряджені площини)

Розглянемо дві паралельні площини з густинами заряду `+σ` та `-σ`. За принципом суперпозиції:
1. **Усередині між пластинами**: поля обох пластин напрямлені в один бік (від позитивної до негативної):
   ```
   E_total = E_+ + E_- = σ / (2·ε₀) + σ / (2·ε₀) = σ / ε₀
   ```
2. **Зовні конденсатора**: поля двох пластин напрямлені в протилежні боки і взаємно компенсуються:
   ```
   E_total = E_+ - E_- = σ / (2·ε₀) - σ / (2·ε₀) = 0
   ```

## 3. Перехід від інтегральної до диференціальної форми

Для переходу від інтегрального опису по поверхні до диференціального опису в точці розглянемо нескінченно малий прямокутний паралелепіпед із ребрами `dx`, `dy`, `dz` та об'ємом `dV = dx · dy · dz`, розташований біля точки `(x, y, z)`.

Обчислимо потік векторного поля `E = (Ex, Ey, Ez)` через дві грані, перпендикулярні до осі `X`:

1. Ліва грань при `x`: вхідний потік через зовнішню нормаль `-i`:
   ```
   dΦ_x1 = - Ex(x, y, z) · dy · dz
   ```
2. Права грань при `x + dx`: вихідний потік через зовнішню нормаль `+i`. Розкладемо `Ex` у ряд Тейлора першого порядку:
   ```
   Ex(x + dx, y, z) ≈ Ex(x, y, z) + (∂Ex / ∂x) · dx
   dΦ_x2 = (Ex(x, y, z) + (∂Ex / ∂x) · dx) · dy · dz
   ```

Результуючий потік через пару граней по осі `X`:

```
dΦ_x = dΦ_x1 + dΦ_x2 = (∂Ex / ∂x) · dx · dy · dz = (∂Ex / ∂x) · dV
```

Аналогічно обчислюємо внески від пар граней, перпендикулярних до осей `Y` та `Z`:

```
dΦ_y = (∂Ey / ∂y) · dV
dΦ_z = (∂Ez / ∂z) · dV
```

Сумарний потік з нескінченно малого об'єму `dV` дорівнює:

```
dΦ_E = dΦ_x + dΦ_y + dΦ_z = (∂Ex / ∂x + ∂Ey / ∂y + ∂Ez / ∂z) · dV
```

Операторну суму частинних похідних називають **дивергенцією** векторного поля `E` і позначають `∇ · E` (або `div E`):

```
∇ · E = ∂Ex / ∂x + ∂Ey / ∂y + ∂Ez / ∂z
```

З іншого боку, за законом Гаусса потік з елементарного об'єму `dV` визначається зарядом `dQ = ρ · dV`, що міститься в ньому:

```
dΦ_E = dQ / ε₀ = (ρ · dV) / ε₀
```

Прирівнюючи два вирази для `dΦ_E`:

```
(∇ · E) · dV = (ρ / ε₀) · dV  →  ∇ · E = ρ / ε₀
```

### Доведення загальної теореми Остроградського-Гаусса

Інтегруючи диференціальне співвідношення `(∇ · E) · dV` по довільному скінченному об'єму `V` та помічаючи, що потоки через внутрішні суміжні грані елементарних осередків взаємно знищуються, отримуємо загальну теорему дивергенції:

```
∭ V (∇ · E) dV = ∮ S E · dA
```

де `S = ∂V` — замкнена границя об'єму `V`.

### Граничні умови для векторів E та D на межі поділу середовищ

Побудувавши гауссову таблетку нескінченно малої висоти `Δh → 0` на межі двох діелектриків із проникностями `ε1` та `ε2`, отримуємо граничну умову для нормальних компонент вектора електричного зсуву `D = ε₀ · ε_r · E`:

```
D2n - D1n = σ_free
```

де `σ_free` — густина вільних поверхневих зарядів на межі. Якщо вільний заряд на межі відсутній (`σ_free = 0`), нормальна компонента вектора зсуву є неперервною: `D1n = D2n`. Нормальна ж компонента поля напруженості `E` зазнає стрибка:

```
ε2 · E2n - ε1 · E1n = σ_free / ε₀
```

### Енергія електростатичного поля та її вивід через закон Гаусса

Закон Гаусса дозволяє отримати важливе математичне співвідношення для повної енергії електростатичного поля `W`. Початково потенціальна енергія системи розподілених зарядів записується через потенціал `V`:

```
W = (1 / 2) · ∭ V ρ · V dV
```

Застосовуючи диференціальний закон Гаусса `ρ = ε₀ · (∇ · E)` та тотожність векторного аналізу `(∇ · E) · V = ∇ · (V · E) - E · (∇V) = ∇ · (V · E) + E²`, перетворюємо об'ємний інтеграл:

```
W = (ε₀ / 2) · ∭ V [ ∇ · (V · E) + E² ] dV
```

За теоремою Остроградського-Гаусса перший член перетворюється у поверхневий інтеграл по нескінченно віддаленій сфері:

```
∭ V ∇ · (V · E) dV = ∮ S (V · E) · dA
```

Для обмеженого розподілу зарядів на великих відстанях `V ~ 1/r`, `E ~ 1/r²`, а площа сфери `A ~ r²`. Отже, добуток `(V · E) · A ~ 1/r`, який прямує до нуля при `r → ∞`. Залишається лише другий член:

```
W = ∭ V (1 / 2) · ε₀ · E² dV
```

Звідси об'ємна густина енергії електричного поля дорівнює `u = (1 / 2) · ε₀ · E²`, що підтверджує локалізацію енергії в самому електричному полі.

### Мультипольне розкладення скалярного потенціалу

Для розрахунку поля довільної обмеженої системи зарядів у далекій зоні (`r >> r'`) відстань `|r - r'|` у знаменнику потенціалу розкладають у ряд за поліномами Лежандра `Pn(cos γ)`:

```
1 / |r - r'| = (1 / r) · ∑ (l=0..∞) (r' / r)ˡ · Pl(cos γ)
```

Підставляючи це розкладення у вираз для потенціалу, отримуємо мультипольний ряд:

```
V(r) = (1 / (4·π·ε₀)) · [ Q_monopole / r + (p · r̂) / r² + (1 / (2·r³)) · ∑ Qij · r̂i · r̂j + ... ]
```

де:
1. **Монопольний член**: `Q_monopole = ∭ ρ(r') dV'` — повний заряд системи. Якщо `Q ≠ 0`, на великих відстанях поле є сферично симетричним і визначається першим рівнянням Гаусса.
2. **Дипольний член**: `p = ∭ r' · ρ(r') dV'` — електричний дипольний момент. Якщо нейтральна система має `Q = 0` (наприклад, молекула води чи електричний диполь), головний внесок у поле дає дипольний момент, що спадає як `1/r²` для потенціалу та `1/r³` для поля.
3. **Квадрупольний член**: `Qij = ∭ (3·r'i·r'j - (r')²·δij) · ρ(r') dV'` — тензор квадрупольного моменту.

Закон Гаусса пояснює, чому монопольний член визначається виключно повним зарядом: потік поля через сферу великого радіуса виділяє інтеграл `Q_monopole = ∭ ρ dV`, а всі вищі мультипольні внески (диполь, квадруполь, октополь) у поверхневому інтегруванні по замкненій сфері дають точний нуль.

### Метод дзеркальних зображень як наслідок закону Гаусса

Закон Гаусса та теорема єдиності розв'язку рівняння Пуассона утворюють основу **методу дзеркальних зображень**. Розглянемо точковий заряд `+q`, розміщений на відстані `d` від нескінченної провідної заземленої площини (`V = 0`).

Для задоволення граничної умови `V = 0` на площині `x = 0` удавану систему будують заміною провідника на фіктивний заряд-зображення `-q`, розміщений симетрично в точці `-d`:

```
V(x, y, z) = (q / (4·π·ε₀)) · (1 / √((x - d)² + y² + z²) - 1 / √((x + d)² + y² + z²))
```

За допомогою диференціального закону Гаусса на поверхні провідника обчислюється індукована поверхнева густина заряду `σ_ind`:

```
σ_ind = - ε₀ · (∂V / ∂x)|_{x=0} = - (q · d) / (2 · π · (d² + y² + z²)^(3/2))
```

Інтегруючи густину індукованого заряду `σ_ind` по всій площині, отримуємо за законом Гаусса:

```
Q_induced = ∬ σ_ind dy dz = -q
```

Заряд, індукований на провідній площині, точно дорівнює за модулем і протилежний за знаком точковому заряду `+q`, що випливає безпосередньо з замкнення силових ліній поля у напівпросторі.

### Функція Ґріна для рівняння Пуассона

Фундаментальний розв'язок диференціального закону Гаусса відповідає функції Ґріна `G(r, r')`, яка задовольняє рівняння з дельта-джерелом:

```
∇² G(r, r') = - δ(r - r')
```

Тривимірним розв'язком цього рівняння в нескінченному просторі є кулонівський потенціал точкового джерела:

```
G(r, r') = 1 / (4 · π · |r - r'|)
```

Тоді для довільного об'ємного розподілу зарядів `ρ(r')` загальний розв'язок рівняння Пуассона `∇²V = -ρ / ε₀` виражається у вигляді просторової згортки з функцією Ґріна:

```
V(r) = (1 / (4 · π · ε₀)) · ∭ (ρ(r') / |r - r'|) dV'
```

Цей розв'язок наочно демонструє, що інтегральний закон Гаусса, диференціальне рівняння Пуассона та розв'язок через функцію Ґріна є трьома еквівалентними мовами опису того самого фізичного закону електростатики.

### Дискретизація потоку для сіткових обчислень

У чисельних методах (метод скінченних об'ємів, FVM) закон Гаусса застосовується безпосередньо до кожної комірки тривимірної сітки. Для полігональної комірки з `N` гранями площами `Ak` та зовнішніми нормалями `n̂k` потік дискретизується як скінченна сума:

```
∑ (k=1..N) (Ek · n̂k) · Ak = Q_cell / ε₀
```

де `Ek` — вектор напруженості поля в центрі `k`-ї грані комірки. Такий дискретний запис гарантує точне збереження електричного заряду у чисельній схемі незалежно від кроку сітки, унеможливлюючи появу нефізичних чисельних джерел або стоків поля. Для кубічної комірки сітки з кроком `h` дискретний лапласіан дорівнює:

```
(V[i+1,j,k] + V[i-1,j,k] + V[i,j+1,k] + V[i,j-1,k] + V[i,j,k+1] + V[i,j,k-1] - 6·V[i,j,k]) / h² = - ρ[i,j,k] / ε₀
```

Ця формулювання утворює математичне підґрунтя для всіх чисельних сіткових алгоритмів розрахунку електростатичних полів у тривимірному просторі, забезпечуючи точне дотримання законів збереження на кожному кроці розрахунку.
