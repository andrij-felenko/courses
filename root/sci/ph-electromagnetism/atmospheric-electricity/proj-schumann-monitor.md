# ⚙️ Алгоритм обробки сигналів для моніторингу резонансів Шумана

Резонанси Шумана — це наднизькочастотні (ELF) електромагнітні хвилі у діапазоні 1–40 Гц, які постійно циркулюють у сферичному хвилеводному резонаторі між провідною поверхнею Землі та іоносферою. Неперервний спектральний аналіз цих сигналів є головним інструментом безперервного глобального моніторингу інтенсивності грозової діяльності, стану нижньої іоносфери та космічної погоди.

Інженерне завдання полягає в розробці високоефективного та надійного модуля цифрової обробки сигналів (DSP), який отримує оцифрований масив напруги з датчика наднизькочастотного магнітного або електричного поля (із частотою дискретизації `f_s = 256 Гц`), пригнічує потужну мережеву заваду 50 Гц за допомогою цифрового режекторного фільтра, застосовує віконну обробку Ганна, обчислює спектральну густину потужності (PSD) та виділяє амплітуди і частоти перших трьох резонансних піків (7.83 Гц, 14.3 Гц, 20.8 Гц).

### 1. Фізика та архітектура вимірювального тракту

Наднизькочастотні сигнали атмосферної електрики в діапазоні Шумана мають надзвичайно малу амплітуду. Електрична компонента поля `E_z` вимірюється одиницями мікровольтів на метр (`1–10 мкВ/м`), а магнітна індукція `B` становить лише частки пікотесла (`0.1–3.0 пТл = 10⁻¹³–10⁻¹² Тл`). Для порівняння, постійне магнітне поле Землі становить близько `50 000 000 пТл` (`50 мкТл`), що на 7–8 порядків перевищує амплітуду корисного сигналу резонансів.

Апаратний контур геофізичної вимірювальної станції будується за двоканальною схемою для паралельної реєстрації північно-південної (`B_NS`) та східно-західної (`B_EW`) компонент магнітного поля:

1. **Індукційний магнітний датчик:** являє собою котушку з високим числом витків (`N = 100 000–200 000`), намотану на осердя з мю-металу або пермалою довжиною 1–2 метри із високою початковою магнітною проникністю (`μ_r ≈ 100 000`). Згідно із законом електромагнітної індукції Фарадея `e = −N · dΦ/dt`, ЕРС на клемах котушки пропорційна частоті `f` та швидкості зміни магнітної індукції `dB/dt`. Для вирівнювання АЧХ на частотах нижче 1 Гц використовується підсилювач із від'ємним інтегруючим зворотним зв'язком.
2. **Електрична вертикальна антена:** вимірює змінну вертикальну компоненту електричного поля `E_z` через струм зміщення `i_disp = ε₀ · S_ant · dE_z/dt`, що протікає на ємність антени. Антена є металевим диском або сферою, піднятою на щогли заввишки 2–3 метри, підключеною до підсилювача з надвисоким вхідним опором (`R_in > 10¹² Ом`) на польових транзисторах із затвором p-n переходу (JFET) або CMOS.
3. **Аналоговий ФНЧ (Anti-Aliasing Filter):** активний аналоговий фільтр Баттерворта 6-го порядку з частотою зрізу `f_c = 45 Гц`, який пригнічує високочастотні завади понад `f_s / 2 = 128 Гц` не менше ніж на 80 дБ, запобігаючи спотворенню спектра через аліасинг.
4. **Аналого-цифровий перетворювач (АЦП):** 24-бітний прецизійний дельта-сигма АЦП (наприклад, ADS1282 або AD7768) із частотою дискретизації `f_s = 256 Гц` та динамічним діапазоном понад 130 дБ, що дозволяє реєструвати як слабкі фонові резонанси, так і потужні сплески від близьких блискавок без насичення.

#### Порівняльний аналіз архітектур АЦП для ELF-сигналів

При виборі АЦП для системи реєстрації наднизькочастотних сигналів вирішальну роль відіграє спектральна густина власного шуму перетворювача. АЦП послідовного наближення (SAR) мають високу швидкість перетворення, проте їхній спектральний шум рівномірно розподілений у широкій смузі частот, що дає відносно низьке співвідношення сигнал/шум (SNR ≈ 85–95 дБ).

Дельта-сигма АЦП (ΣΔ ADC) є ідеальним вибором для діапазону Шумана завдяки двом фундаментальним перевагам:
- **Передискретизація (Oversampling):** АЦП працює на внутрішній частоті модулятора `f_mod = 1–10 МГц`. Коефіцієнт передискретизації `OSR = f_mod / (2 · f_s) ≈ 2000` знижує спектральну густину квантувального шуму у корисній смузі `0–45 Гц` на `10 · log10(OSR) ≈ 33 дБ`.
- **Формування шуму (Noise Shaping):** дельта-сигма модулятор діє як ФВЧ для власного шуму квантування, витісняючи його основну енергію в область високих частот (понад 100 кГц), де він легко зрізається цифровим внутрішнім фільтром децимації.

#### Розведення друкованої плати та топологія заземлення (PCB Layout Guidelines)

Для досягнення межевої чутливості 0.1 пТл при розробці аналогового фронтенду станції обов'язково дотримуються таких інженерних правил:
- **Охоронні кільця (Guard Rings):** високоомний вхідний вузол підсилювача антени оточується суцільною провідною доріжкою охоронного кільця, підключеною до потенціалу екрана (Driven Guard), для нейтралізації витоків струму по поверхні текстоліту FR-4.
- **Одноточкова схема заземлення (Star Grounding):** силова земля живильного модуля, цифрова земля мікроконтролера та аналогова земля чутливого підсилювача з'єднуються строго в одній точці під АЦП для запобігання паразитним контурам заземлення (Ground Loops), які наводять завади 50 Гц.
- **Екранування Фарадея:** аналоговий платарний модуль розміщується всередині суцільного фрезерованого алюмінієвого або латунного екрана товщиною не менше 2 мм.

### 2. Алгоритмічний конвеєр цифрової обробки сигналів

Цифровий модуль обробки одержує безперервний потік 24-бітних відліків `x[n]` з АЦП. Обробка виконується послідовними блоками (кадрами) довжиною `N = 1024` відліків, що відповідає часовому вікну спостереження `T = N / f_s = 1024 / 256 = 4.0 секунди`.

#### Крок 1: Видалення постійної складової (DC Removal)

Низькочастотні дрейфи електроду та термічний дрейф АЦП створюють постійне зміщення `x_dc`. Його усунення виконується відніманням середнього арифметичного значення поточного кадру:

```
x_dc = (1 / N) · ∑ [n=0..N-1] x[n]
x_zero[n] = x[n] − x_dc
```

#### Крок 2: Цифрова режекторна фільтрація завади 50 Гц (IIR Notch Filter)

Для пригнічення завади мережі 50 Гц застосовується режекторний IIR-фільтр 2-го порядку (біквадратний осередковий фільтр). Передавальна функція фільтра в z-області має вигляд:

```
H(z) = B · (1 − 2·cos(ω₀)·z⁻¹ + z⁻²) / (1 − 2·r·cos(ω₀)·z⁻¹ + r²·z⁻²)
```

де `ω₀ = 2 · π · f_notch / f_s = 2 · π · 50 / 256 ≈ 1.2272 рад`, `r = 0.995` — радіус полюсів, що визначає ширину смуги вирізання (`Δf ≈ 0.4 Гц`), а `B = (1 + r²) / 2` — нормувальний коефіцієнт підсилення на постійному струмі. 

Різницеве рівняння у часовій області для обчислення відфільтрованого сигналу `y[n]`:

```
y[n] = B · [ x_zero[n] − 2·cos(ω₀)·x_zero[n-1] + x_zero[n-2] ] + 2·r·cos(ω₀)·y[n-1] − r²·y[n-2]
```

#### Крок 3: Застосування зважувального вікна Ганна та порівняння віконних функцій

Обрізання безперервного сигналу прямокутним часовим вікном призводить до виникнення сильних бічних пелюсток у частотній області (розтікання спектра), які затоплюють слабкі сусідні гармоніки. 

У цифровому аналізі геоелектромагнітних сигналів застосовують такі віконні функції:
1. **Прямокутне вікно (Rectangular):** максимальна роздільна здатність по частоті (`Δf = 1.0 bin`), проте рівень першої бічної пелюстки становить лише `−13 дБ`. Для слабких піків Шумана це неприпустимо, оскільки завада 50 Гц створить спектральні «хвости», що перекриють гармоніку 33.8 Гц.
2. **Вікно Блекмана-Харріса (Blackman-Harris):** пригнічення бічних пелюсток перевищує `−92 дБ`, проте еквівалентна ширина смуги шумів зростає до `1.81 bin`, що розмиває вершини резонансних піків.
3. **Вікно Ганна (Hann):** оптимальний компроміс. Пригнічення бічних пелюсток досягає `−32 дБ` зі швидкістю спадання `18 дБ/октаву`, а ширина головної пелюстки становить `1.5 bin`.

Формула вікна Ганна:

```
w[n] = 0.5 · [ 1 − cos(2 · π · n / (N − 1)) ]
```

Сигнал після віконної обробки: `x_win[n] = y[n] · w[n]`. Для збереження точного нормування спектральної енергії обчислимо норму суми квадратів ваг вікна:

```
S_w = ∑ [n=0..N-1] w[n]² ≈ 0.375 · N
```

#### Крок 4: Обчислення спектральної густини потужності (PSD) за методом Уелча

Оскільки корисний геофізичний діапазон резонансів Шумана обмежений частотами `0–45 Гц`, з усього спектра `N/2 = 512` відліків обчислюються лише перші `k_max = 180` частотних елементів. 

Для обчислення спектра використовується прямо обчислення точкових гармонік або рекурсивний алгоритм Герцеля (Goertzel Algorithm). Алгоритм Герцеля для кожної частотної біни `k` потребує лише `N` множень та додавань без необхідності виділення пам'яті під повну бабочкову матрицю FFT, що робить його ідеальним для малопотужних вбудованих мікроконтролерів Cortex-M4/M7:

```
s[n] = x_win[n] + 2 · cos(2·π·k / N) · s[n-1] − s[n-2]
X[k] = s[N-1] − s[N-2] · exp(−i · 2·π·k / N)
```

Після обчислення амплітуд `X[k]` односторонній спектр спектральної густини потужності (PSD) з урахуванням нормування на ширину смуги аналізу обчислюється за формулою:

```
PSD[k] = (2 / (f_s · S_w)) · |X[k]|²   (для k = 1, 2, ..., N/2 − 1)
```

Для зменшення дисперсії шуму спектри `PSD[k]` усереднюються за `K` послідовними часовими вікнами з 50% перекриттям (метод Уелча). Дисперсія усередненого спектра зменшується в `√K` разів, що дозволяє чітко виділити слабкі резонансні максимуми з фонового шуму.

#### Крок 5: Крос-спектральний аналіз двох ортогональних каналів

Для визначення напрямку (азимута) на головний грозовий осередк обчислюється взаємна спектральна густина потужності (Cross-PSD) між північно-південним каналом `X[k]` та східно-західним `Y[k]`:

```
P_xy[k] = (2 / (f_s · S_w)) · X*[k] · Y[k]
```

де `X*[k]` — комплексно-спряжене значення. Коефіцієнт когерентності `γ_xy²(f)` описує ступінь зв'язку між двома поляризаціями:

```
γ_xy²[k] = |P_xy[k]|² / (P_xx[k] · P_yy[k])
```

Значення `γ_xy² ≈ 1` на частоті `7.83 Гц` підтверджує, що зареєстрований сигнал є когерентною ЕМ-хвилею від грозового джерела, а не локальним коронним розрядом чи білим шумом підсилювача. Азимут `θ` на джерело визначається за формулою `tan(θ) = √(P_yy / P_xx)`.

#### Крок 6: Субпіксельна локалізація та оцінка параметрів піків

У частотних діапазонах пошуку перших трьох гармонік (`6.0–10.0 Гц`, `12.0–16.0 Гц`, `18.0–24.0 Гц`) знаходиться индекс `k_max` дискретного максимуму `PSD[k]`. Для подолання дискретності сітки `0.25 Гц` виконується параболічна субпіксельна інтерполяція за трьома суміжними точками `α = PSD[k_max - 1]`, `β = PSD[k_max]`, `γ = PSD[k_max + 1]`:

```
δ = 0.5 · (α − γ) / (α − 2·β + γ)
```

Точне значення частоти резонансного піку `f_peak` та його амплітуди `PSD_peak`:

```
f_peak = (k_max + δ) · (f_s / N)
PSD_peak = β − 0.25 · (α − γ) · δ
```

Добротність резонансу `Q` обчислюється через ширину піку по рівню половини потужності `Δf_3dB`: `Q = f_peak / Δf_3dB`.

### 4. Інженерні пастки та крайові випадки обробки

Під час розгортання цифрових станцій моніторингу атмосфери на базі даного алгоритму розробники зіштовхуються з низкою специфічних фізичних, апаратних та обчислювальних проблем:

#### Вплив сейсмічних вібрацій та вітрового шуму

Вітер, що хитає дерев'яні або металеві щогли з встановленими індукційними магнітометрами у постійному геомагнітному полі Землі (`B_earth ≈ 50 000 пТл`), генерує індукційну заваду на частотах 0.1–5.0 Гц за законом Фарадея. Оскільки величина постійного поля Землі на 7 порядків більша за амплітуду Шумана, навіть мікроскопічне відхилення кута антени на `0.001°` створює заваду `ΔB = B_earth · sin(0.001°) ≈ 0.87 пТл`, що повністю засліплює АЦП і спотворює першу гармоніку 7.83 Гц.

*Рішення:* Розміщення індукційних котушок у підземних бункерах або герметичних пластикових трубах, закопаних горизонтально у ґрунт на глибину не менше 1.5–2.0 метрів далеко від дерев та споруд.

#### Мережева завада 50/60 Гц та гармонійне накладання

Гармоніки промислової електромережі (50 Гц в Європі, 60 Гц у США) мають амплітуду, що у сотні тисяч разів перевищує корисний сигнал Шумана. Навіть при застосуванні аналогових фільтрів висока напруженість завади викликає бічне розтікання спектра (*spectral leakage*), яке здатне повністю затопити піки 4-ї та 5-ї гармонік (27.3 Гц та 33.8 Гц). 

*Рішення:* Використання подвійного каскаду режекторних цифрових IIR-фільтрів біквадратної структури (*IIR Biquad Notch*) безпосередньо після АЦП перед віконною обробкою, або проведення вимірювань у віддалених геофізичних обсерваторіях далеко від ліній електропередач.

#### Калібрування та переведення в абсолютні фізичні одиниці

Вихідний спектр АЦП вимірюється у цифрових відліках `В²/Гц`. Для отримання фундаментальних геофізичних одиниць `пТл²/Гц` необхідне урахування передавальної функції індукційного датчика `H_sensor(f)` (чийна чутливість зростає пропорційно частоті `f` до частоти резонансу котушки):

```
PSD_physical(f) = PSD_adc(f) / |H_sensor(f)|²
```

Без точного калібрування за допомогою тестової кільцевої котушки Гельмгольца виміряні амплітуди піків неможливо зіставити з даними міжнародних геофізичних мереж.

#### Імпульсні завади від близьких блискавок (Outlier Rejection)

Якщо за декілька кілометрів від станції виникає прямий розряд блискавки, вхідний підсилювач отримує потужний одиночний імпульс (Q-burst). У спектральному домені такий одиночний імпульс розгортається у виражений білий шум по всьому діапазону частот, що спотворює усереднене значення `PSD`.

*Рішення:* Впровадження блоку попередньої бракування кадрів перед усередненням Уелча: якщо амплітуда піка у часовому вікні перевищує `5 · σ_rms` (де `σ_rms` — середньоквадратичне відхилення за останні 10 хвилин), поточний кадр повністю виключається з обчислення усередненого спектра.

#### Компенсація фазових імпульсних стрибків (Phase Jump Compensation)

Різкі скачки температури навколишнього середовища або комутаційні завади в колах жилення створюють стрибки фази вхідного сигналу. Якщо обчислити FFT над буфером із стрибком фази посередині, розрахована добротність `Q` падає у 2–3 рази. Алгоритм автоматично виявляє стрибок фази через перевірку неперервності першої похідної `dy/dt` і ділить кадр на дві рівні частини або заповнює згладжувальною інтерполяцією.

#### GPS-синхронізація часу та часове мічення вибірок (GPS Time Tagging)

Для міжстанційної інтерферометрії та глобальної пеленгації блискавок вибірки АЦП повинні прив'язуватися до світового координованого часу (UTC) з точністю не гірше 1 мікросекунди. 

Апаратний модуль оцифрування синхронізується від імпульсу PPS (Pulse Per Second) супутникового приймача GPS/Galileo:
- Сигнал PPS подається на вхід зовнішнього переривання або апаратного захоплення таймера мікроконтролера.
- Таймер вимірює реальну частоту генератора АЦП між послідовними імпульсами PPS і здійснює цифрове коригування коефіцієнта децимації для усунення кварцового дрейфу.
- Кожен кадр `N = 1024` відліків отримує заголовок із міткою UTC (секунди, наносекунди та географічні координати станції).

#### Процедура тестування та контрольні вхідні дані

Для автоматизованого юніт-тестування DSP-модуля генерується синтетичний вхідний вектор `test_signal[n]` тривалістю `N = 1024` відліків (`f_s = 256 Гц`), що містить суму двох гармонік із додаванням білого шуму:
```
test_signal[n] = 2.0 · sin(2·π · 7.83 · n / f_s) + 1.2 · sin(2·π · 14.3 · n / f_s) + noise[n]
```
При подачі цього вектора у модуль `schumann_analyze_buffer` розраховане значення частоти першої гармоніки становить `7.83 ± 0.05 Гц`, а другої — `14.30 ± 0.05 Гц`, що підтверджує працездатність субпіксельного алгоритму інтерполяції.

### 5. Практичне застосування та інтерпретація геофізичних даних

Моніторинг параметрів резонансів Шумана (напруженості, центральної частоти `f_n` та добротності `Q_n`) дає змогу розв'язувати фундаментальні геофізичні завдання:

- **Глобальна грозопеленгація та кліматологія:** інтегральна потужність піка `n=1` прямо пропорційна кількості розрядів блискавок у тропічних грозових осередках. Зміна середньої частоти першої гармоніки `f₁` на `0.1–0.2 Гц` свідчить про зміщення центрів грозової активності між Африкою, Південною Америкою та Азією.
- **Діагностика космічної погоди:** під час рентгенівських спалахів на Сонці підвищується іонізація D-шару іоносфери, що знижує ефективну висоту резонатора `h_eff`. Це викликає негайне зростання резонансних частот Шумана на `0.2–0.5 Гц` по всій денній півкулі Землі.
- **Сейсмо-іоносферні провісники:** за 1–3 доби до руйнівних землетрусів над сейсмічно активними розломами спостерігається вихід радіоактивного радону, що змінює провідність приземного шару і викликає локальні аномалії амплітуди резонансів Шумана.
- **Формат збереження та потокова передача даних (IoT Integration):** для передачі результатів аналізу в реальному часі на наукові сервери використовується протокол MQTT або потоковий UDP з JSON-структурою кадру. Для забезпечення довготривалого збереження результатів у геофізичних архівах використовують бінарні файли формату NetCDF4 або HDF5. Збереження лише усереднених 5-хвилинних спектрів PSD замість сирих відліків АЦП зменшує обсяг добового архіву з 88 МБ до 1.2 МБ на канал. Завдяки цьому глобальні мережі спостереження можуть працювати роками у автономному режимі.
