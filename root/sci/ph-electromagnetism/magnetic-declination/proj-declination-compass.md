# ⚙️ Алгоритм виправлення курсу за картою магнітного схилення

Практичний алгоритм комп'ютерного обчислення істинного географічного курсу на борту автопілота чи мобільного пристрою поєднує тривимірне компенсаційне горизонтальне повертання даних магнітометра (з урахуванням крену й тангажу) та внесення локальної поправки магнітного схилення.

---

### Фізико-математичний тракт обробки магнітометричних даних

У реальних автопілотах (наприклад, PX4, ArduPilot, або комерційних суднових системах) інформація з 3-осьового магнітометра (наприклад, давачів Honeywell HMC5883L, PNI RM3100 або iSensTek IST8310) проходить багаторівневу обробку перед тим, як стати значенням курсу.

```
 [3D Магнітометр (Raw Bx, By, Bz)]
                 │
                 ▼
 [Калібрування завад: Вектор Hard-Iron та Матриця Soft-Iron]
                 │
                 ▼
 [Компенсація нахилу за кутами крену (Roll) та тангажу (Pitch)]
                 │
                 ▼
 [Проєкція на горизонтальну площину: Обчислення (Hx, Hy)]
                 │
                 ▼
 [Обчислення магнітного курсу Ψ_mag = atan2(-Hy, Hx)]
                 │
                 ▼
 [Внесення магнітного схилення D з таблиці WMM за координатами GPS]
                 │
                 ▼
 [Нормалізація в діапазон [0°..360°) → Істинний курс Ψ_true]
```

1. **Попереднє калібрування завад корпусу**:
   Перед обчисленням нахилу сирі показання магнітометра `B_raw` коригують на вектор зміщення твердого заліза `V_hard` (Hard-Iron offset) та матрицю викривлення м'якого заліза `W_soft` (Soft-Iron matrix):

   ```
   B_calib = W_soft · (B_raw - V_hard)
   ```

   Процедура визначення вектора `V_hard` полягає у підгону виміряних точок поля при повному тривимірному обертанні апарата до ідеальної сфери радіуса `F` (метод найменших квадратів / підгін сфери). Центр сфери визначає стале зміщення намагнічених металевих деталей корпусу та силових дротів живлення.

2. **Конструктивне компонування давача на борту**:
   З огляду на слабкість земного поля (близько 50 мкТл), давач магнітометра критично чутливий до постійних і змінних струмів силових шин живлення двигунів. Проходження струму в 50–100 А через силову плату живлення (PDB) генерує за законом Ерстеда навколишнє магнітне поле індукцією у десятки мікротесла, що повністю викривляє показання компаса. З цієї причини виносний магнітометр у мультироторних і крилатих БПЛА завжди встановлюють на окремій виносній щоглі (бомі) заввишки 15–20 см подалі від силових регуляторів ходу (ESC), безколекторних моторів та батарейних шлейфів.

3. **Компенсація кутів крену та тангажу**:
   Якщо апарат нахилений на кут крену `φ` (Roll) або тангажу `θ` (Pitch), осі давача не збігаються з місцевою горизонтальною площиною. Пряме обчислення арктангенса від показань осі давача спричинить велетенську похибку (до 30°–50° при нахилі всього на 10°). Тому первинний вектор `B_calib` повертають на кути `-φ` та `-θ` за допомогою матриці повороту `R_body_to_level`:

   ```
   Hx = Bx · cos(θ) + By · sin(φ) · sin(θ) + Bz · cos(φ) · sin(θ)
   Hy = By · cos(φ) - Bz · sin(φ)
   ```

4. **Обчислення авіаційного курсу та корекція схилення**:
   У відповідності до авіаційного та морського стандарту, кут курсу відраховується від півночі (0°) за годинниковою стрілкою (Схід = 90°, Південь = 180°, Захід = 270°). Для такої системи орієнтації вектор `(Hx, Hy)` обробляється формулою `Ψ_mag = atan2(-Hy, Hx)`. Після цього додається значення магнітного схилення `D`, отримане за географічними координатами апарата (від GPS) з таблиці WMM.

5. **Дрейф орієнтації та калібрування в польоті**:
   У польотних контролерах високого класу (наприклад, PX4 EKF3) значення курсу не подається безпосередньо на приводи рулів. Натомість курс від магнітометра подається як вектор спостереження у розширений фільтр Калмана (EKF). Фільтр Калмана безперервно порівнює курс магнітометра з вектором швидкості, обчисленим GPS-приймачем за ефектом Доплера. Якщо GPS показує, що безпілотник рухається під кутом 90°, а компенсований курс компаса дорівнює 82°, фільтр оцінює інноваційне відхилення магнітного язика (`mag_yaw_innovation`). Якщо відхилення триває понад кілька секунд, EKF автоматично коригує оцінку внутрішнього зсуву магнітометра чи схилення, запобігаючи втраті керованості.

### Оптимізація інтерполяції WMM для слабопотужних мікроконтролерів (MCU)

Повний аналітичний розрахунок сферичних гармонік Гаусса моделі WMM вимагає понад 150 тригонометричних викликів та поліномів Лежандра, що становить суттєве обчислювальне навантаження для мікроконтролерів серій ARM Cortex-M0/M3 без апаратного блоку FPU.

Для оптимізації у прошивках бортових обчислювачів застосовують **двовимірну дволінійну інтерполяцію (Bilinear Interpolation)** за заздалегідь згенерованою сіткою карт схилення.

```
(lat2, lon1) ─────────────── (lat2, lon2)
     │                             │
     │      ★ (lat, lon)           │
     │      Точка безпілотника     │
     │                             │
(lat1, lon1) ─────────────── (lat1, lon2)
```

Матриця схилення зберігається у флеш-пам'яті MCU із кроком сітки `10° × 10°` (або `5° × 5°`). Для поточних координат безпілотника `(lat, lon)` знаходять чотири найближчі вузли сітки та виконують швидку дволінійну інтерполяцію:

```
t = (lat - lat1) / (lat2 - lat1)
u = (lon - lon1) / (lon2 - lon1)

D = (1 - t)·(1 - u)·D11 + t·(1 - u)·D21 + (1 - t)·u·D12 + t·u·D22
```

Такий підхід дозволяє обчислити магнітне схилення `D` всього за 4 операції множення та додавання з плаваючою комою, що займає менше 1 мікросекунди на мікроконтролері з частотою 48 МГц.

### Пастки реалізації та крайові випадки

1. **Знаковий розрив при переході через 0° / 360°**. Під час обчислення різниці між поточним курсом та цільовим азимутом безпосереднє віднімання кутів може утворити скачок на `360°` (наприклад, при переході з `359°` на `1°`). У прошивках автопілотів відхилення курса обчислюють через арктангенс синуса й косинуса різниці:

   ```
   error_deg = atan2(sin(target - current), cos(target - current)) * (180 / π)
   ```

2. **Запізнення оновлення геодезичної позиції GNSS**. Якщо безпілотник здійснює тривалий політ на велику відстань (понад 500 км) зі швидкістю 200 км/год, значення схилення в його пам'яті має динамічно оновлюватися за GPS-координатами. Фіксоване статичне значення схилення, закладене перед зльотом, накопичить похибку курсу в кілька градусів, що змістить кінцеву точку маршруту на десятки кілометрів.

3. **Низька горизонтальна інтенсивність поля `H < 2000 нТл`**. У полярних широтах або поблизу магнітних полюсів вертикальна компонента `Z` прямує до максимумів (до 60 000 нТл), тоді як горизонтальна складова `H` прямує до нуля. При цьому відношення сигнал/шум магнітометра стрімко падає, і будь-яка спроба розрахувати курс за формулою `atan2(-Hy, Hx)` призводить до обчислювального шторму. Обчислювач повинен автоматично вимикати компас як джерело курсу та переходити на використання інерціальної системи з корекцією за вектором швидкості GPS або оптичним потоком.
