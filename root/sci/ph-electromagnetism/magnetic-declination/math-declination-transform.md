# 🧮 Математика перетворення координат та тривимірна геометрія схилення

Математичний розрахунок магнітного схилення полягає у визначенні кута між горизонтальною проєкцією вектора геомагнітної індукції `B` та географічним меридіаном, а також у переведенні курсу між магнітною та справжньою системами координат.

---

### Сферичний гармонічний розклад потенціалу Гаусса (Модель WMM)

У геофізиці вектор геомагнітного поля `B` описують через скалярний магнітний потенціал `V`. Оскільки у просторі поза джерелами поля (на поверхні Землі та в атмосфері) густина електричних струмів дорівнює нулю (`j = 0`), з рівнянь Максвелла випливає, що ротор індукції рівний нулю (`∇ × B = 0`). Отже, поле є потенціальним:

```
B = -∇V
```

Оскільки поле задовольняє умову відсутності магнітних монополів (`∇ · B = 0`), скалярний потенціал `V` задовольняє рівняння Лапласа у сферичних координатах:

```
∇²V = 0
```

Розв'язок рівняння Лапласа у сферичній системі координат `(r, θ, φ)` (де `r` — геоцентричний радіус, `θ` — геоцентрична коширота `θ = 90° - lat`, `φ` — географічна довгота) виражається у вигляді розкладу сферичних гармонік Гаусса:

```
V(r, θ, φ) = a · ∑ (a/r)ⁿ⁺¹ · ∑ [gₙᵐ · cos(mφ) + hₙᵐ · sin(mφ)] · Pₙᵐ(cos θ)
```

де:
* `a = 6371.2 км` — екваторіальний радіус Землі;
* `gₙᵐ` та `hₙᵐ` — коефіцієнти Гаусса (вимірюються в нанотеслах нТл);
* `Pₙᵐ(cos θ)` — приєднані поліноми Лежандра ступеня `n` та порядку `m` у нормалізації Шмідта;
* `n` — ступінь розкладу (`n = 1..12` у моделі WMM).

Обрізання розкладу сферичних гармонік саме на ступені `N = 12` (що відповідає 168 коефіцієнтам Гаусса) має строге фізичне обґрунтування. Гармоніки нижчих ступенів (`n = 1..12`) описують великомасштабне геомагнітне поле, породжене конвективним геодинамо в рідкому залізному ядрі Землі. Вищі гармоніки (`n > 12`) описують дрібномасштабні локальні аномалії намагніченості земної кори, які не піддаються глобальному часовому моделюванню і вимагають локальної аеромагнітної зйомки.

Приєднані поліноми Лежандра `Pₙᵐ(x)` у прошивках обчислюють за допомогою рекурентних співвідношень для забезпечення максимальної швидкодії:

```
Pₙᵐ(x) = √((2n - 1) / (n - m)) · x · Pₙ₋₁ᵐ(x) - √(((n - 1)² - m²) / ((2n - 1)(n - m))) · Pₙ₋₂ᵐ(x)
```

Компоненти вектора магнітної індукції `B` у геоцентричній системі координат обчислюють через градієнт скалярного потенціалу `V`:

```
X_gc = (1 / r) · (∂V / ∂θ)      [північна геоцентрична компонента]
Y_gc = - (1 / (r · sin θ)) · (∂V / ∂φ)   [східна геоцентрична компонента]
Z_gc = ∂V / ∂r                  [вертикальна геоцентрична компонента, спрямована до центра]
```

### Геодезичне перетворення WGS-84 у геоцентричну систему

Оскільки Земля не є ідеальною сферою, а описується еліпсоїдом обертання WGS-84 з екваторіальним радіусом `a_wgs = 6378.137 км` та стисненням `f = 1 / 298.257223563`, геодезична широта спостерігача `lat` не дорівнює геоцентричній широті `lat'`.

Для обчислення геоцентричних координат спочатку обчислюють радіус кривини у першому вертикалі `N(lat)`:

```
N(lat) = a_wgs / √(1 - e² · sin²(lat))
```

де `e² = 2f - f² ≈ 0.00669437999` — квадрат першого ексцентриситету еліпсоїда.

Прямокутні геоцентричні координати `(X_ecef, Y_ecef, Z_ecef)` обчислюють через висоту `h` над еліпсоїдом:

```
X_ecef = (N(lat) + h) · cos(lat) · cos(lon)
Y_ecef = (N(lat) + h) · cos(lat) · sin(lon)
Z_ecef = (N(lat) · (1 - e²) + h) · sin(lat)
```

Відповідно геоцентричний радіус `r` та геоцентрична коширота `θ` обчислюються як:

```
r = √(X_ecef² + Y_ecef² + Z_ecef²)
θ = acos(Z_ecef / r)
```

Після обчислення геоцентричних компонент поля `(X_gc, Y_gc, Z_gc)` виконують геодезичний поворот у локальну систему **NED** (*North-East-Down*):

```
X = X_gc · cos(lat - lat') - Z_gc · sin(lat - lat')
Y = Y_gc
Z = X_gc · sin(lat - lat') + Z_gc · cos(lat - lat')
```

### Трьохвимірне розкладання вектора поля та формула двоаргументного арктангенса

У локальній прямокутній системі координат **NED** вектор індукції земного поля `B` записують трьома компонентами:

```
B_NED = [ X ]   (Північна складова вздовж географічного меридіана)
        [ Y ]   (Східна складова вздовж географічної паралелі)
        [ Z ]   (Вертикальна складова, спрямована вглиб Землі)
```

Горизонтальна складова поля `H` описується вектором у горизонтальній площині `H_vec = (X, Y)`. Довжина цього вектора (горизонтальна інтенсивність) становить:

```
H = √(X² + Y²)
```

За визначенням, **магнітне схилення `D`** є азимутом вектора `H_vec` відносно осі `X` (напряму на географічну північ). Математично кут `D` обчислюють через двоаргументний арктангенс `atan2(Y, X)`:

```
D = atan2(Y, X)
```

Використання саме функції `atan2(Y, X)` замість звичайного `arctan(Y / X)` є принциповим, оскільки вона однозначно визначає кут у діапазоні `[-π, +π)` (або `[-180°, +180°)`), зберігаючи правильні знаки залежно від квадранта проєкцій `X` та `Y`:

```
 квадрант I   (X > 0, Y > 0)  →  D > 0   (Східне схилення,  0° < D < +90°)
 квадрант II  (X < 0, Y > 0)  →  D > 0   (Східне схилення, +90° < D < +180°)
 квадрант III (X < 0, Y < 0)  →  D < 0   (Західне схилення, -180° < D < -90°)
 квадрант IV  (X > 0, Y < 0)  →  D < 0   (Західне схилення,  -90° < D < 0°)
```

### Навігаційне рівняння курсу та перетворення систем координат

Для довільного орієнтованого апарата (корабля, літака, безпілотника) кут курсу задається відносно орієнтира півночі.

1. **Магнітний курс `Ψ_mag`** — кут між горизонтальною проєкцією поздовжньої осі апарата та магнітною північчю `N_mag`.
2. **Істинний (географічний) курс `Ψ_true`** — кут між поздовжньою віссю апарата та географічною північчю `N_geo`.

Зв'язок між курсами виражається фундаментальним навігаційним рівнянням:

```
Ψ_true = Ψ_mag + D
```

де `D` береться зі своїм знаком (`D > 0` для східного схилення, `D < 0` для західного).

Якщо обчислений істинний курс `Ψ_true` виходить за межі `[0°, 360°)`, його нормалізують за допомогою модуля від ділення на `360°`:

```
Ψ_true = (Ψ_mag + D + 360°) mod 360°
```

### Математичне виведення чутливості схилення біля магнітних полюсів

Оцінимо чутливість обчислення кута схилення `D` до збурень чи похибок вимірювання компонент `X` та `Y`. Для цього обчислимо часткові похідні функції `D = atan2(Y, X)`:

```
∂D / ∂X
= ∂(arctan(Y / X)) / ∂X
= (1 / (1 + (Y / X)²)) · (-Y / X²)       [похідна арктангенса за X]
= (1 / ((X² + Y²) / X²)) · (-Y / X²)     [зведення до спільного знаменника]
= -Y / (X² + Y²)                         [скорочення X²]
= -Y / H²                                [підстановка H² = X² + Y²]
```

Аналогічно для часткової похідної за `Y`:

```
∂D / ∂Y
= ∂(arctan(Y / X)) / ∂Y
= (1 / (1 + (Y / X)²)) · (1 / X)         [похідна арктангенса за Y]
= (1 / ((X² + Y²) / X²)) · (1 / X)       [зведення до спільного знаменника]
= X / (X² + Y²)                          [скорочення X]
= X / H²                                 [підстановка H² = X² + Y²]
```

Повний диференціал кута схилення `dD` виражається через варіації компонент `dX` та `dY`:

```
dD = (∂D / ∂X)·dX + (∂D / ∂Y)·dY
= (-Y · dX + X · dY) / H²
```

Звідси видно сингулярну природу магнітного схилення: при наближенні до магнітного полюса Землі горизонтальна складова `H = √(X² + Y²)` прямує до нуля (`H → 0`). Знаменник `H²` у формулі диференціала прямує до нуля зі квадратичною швидкістю. Це означає, що у високоширотних та полярних регіонах навіть мікроскопічна похибка чи флуктуація магнітного вимірювання `dX` або `dY` у кілька нанотесла викликає велетенські скачки кута схилення `dD` на десятки градусів.

### Полярна картографічна конвергенція та грідовий азимут

У високоширотній полярній навігації (широта `|lat| > 80°`) для стереографічної проєкції розраховують кут **збіжності меридіанів `γ`** (*grid convergence angle*):

```
tan(γ) = tan(lon - lon₀) · sin(lat)
```

де `lon₀` — центральний меридіан полярної картографічної сітки.

Магнітний грідовий азимут (`GV`, *Grid Variation* або *Gnav*) визначає кут між горизонтальним вектором поля `H` та вертикальною сіткою карт полярної стереографічної проєкції:

```
GV = D - γ
```

Використання величини `GV` дозволяє літакам та суднам прокладати курс по прямолінійній сітці полярних карт без виникнення математичних сингулярностей при перетині географічного Північного полюса.

### Лінійна модель секулярного дрейфу

Магнітне схилення не є статичною величиною. У першому наближенні для конкретної точки з географічними координатами `(lat, lon)` схилення на дату `t` (у десяткових роках) обчислюють за лінійною модельною формулою секулярного дрейфу відносно базової епохи `t₀` (наприклад, `t₀ = 2025.0`):

```
D(t) = D₀ + (t - t₀) · (dD / dt)
```

де `D₀` — значення схилення на початкову епоху `t₀`, а `dD / dt` — річна швидкість секулярного зміщення (вимірюється у мінусах дуги на рік або градусах на рік, зазвичай `0.02°..0.15° / рік`).
