# 🧮 Вивід законів Кірхгофа з рівнянь Максвелла

Ця вставка містить суворий математичний вивід двох законів Кірхгофа (KCL і KVL) та точних співвідношень для компонентів (`R`, `L`, `C`) безпосередньо з рівнянь Максвелла в інтегральній та диференціальній формах за умов квазістаціонарності та малого хвильового запізнення.

---

## 1. Початкові рівняння Максвелла та потенціали електродинаміки

У загальному тривимірному випадку векторне електромагнімне поле у суцільному середовищі з діелектричною проникністю `ε` та магнітною проникністю `μ` описується чотирма диференціальними рівняннями Максвелла:

```
1. Закон Гаусса для електричного поля:       div(D) = ρ
2. Закон Гаусса для магнітного поля:         div(B) = 0
3. Закон індукції Фарадея:                   rot(E) = −∂B/∂t
4. Закон Ампера-Максвелла:                   rot(H) = J + ∂D/∂t
```

де `D = ε₀ · ε · E` — вектор електричної індукції, `B = μ₀ · μ · H` — вектор магнітної індукції, `J` — густина струму провідності, а `ρ` — об'ємна густина електричного заряду.

Для математичного розв'язку цих рівнянь вводять скалярний електричний потенціал `Φ(r,t)` та векторний магнітний потенціал `A(r,t)`. З урахуванням відсутності магнітних монополів (`div(B) = 0`), магнітну індукцію завжди можна виразити через ротор векторного потенціалу:

```
B = rot(A)
```

Підставляючи цей вираз у закон індукції Фарадея `rot(E) = −∂(rot(A))/∂t = −rot(∂A/∂t)`, отримуємо, що ротор комбінованого вектора дорівнює нулю:

```
rot(E + ∂A/∂t) = 0
```

Оскільки векторне поле з нульовим ротором є потенціальним, вектор у дужках можна подати як градієнт скалярної функції `Φ`:

```
E = −∇Φ − ∂A/∂t
```

Це рівняння є фундаментальним зв'язком між напряженістю електричного поля `E` та потенціалами `Φ` і `A`. З нього чітко видно, що напряженість електричного поля складається з двох частин:
- **Потенціальна (електростатична) складова (`−∇Φ`):** Породжується накопиченими електричними зарядами `ρ`.
- **Вихрова (вихрова індукційна) складова (`−∂A/∂t`):** Породжується часовою зміною струмів і магнітного поля.

## 2. Математичний вивід Першого закону Кірхгофа (KCL)

Для виводу Першого закону Кірхгофа застосуємо оператор дивергенції до обох частин рівняння Ампера-Максвелла (4):

```
div(rot(H)) = div(J) + div(∂D/∂t)
```

З векторного аналізу відомо, що дивергенція ротора будь-якого гладкого векторного поля тотожно дорівнює нулю (`div(rot(H)) ≡ 0`). Міняючи порядок диференціювання за часом та простором у другому доданку й підставляючи закон Гаусса `div(D) = ρ`, отримуємо **диференціальне рівняння неперервності (закон збереження заряду)**:

```
div(J) + ∂ρ/∂t = 0
```

Проінтегруємо це рівняння по деякому об'єму `V`, що містить у собі вузол електричної схеми (з'єднання кількох провідників) і обмежений замкненою поверхнею `S`. За теоремою Остроградського-Гаусса інтеграл від дивергенції перетворюється на поверхневий інтеграл:

```
∫_V div(J) dV = ∮_S J · dA = − d/dt (∫_V ρ dV) = − dQ_int / dt
```

де `Q_int = ∫_V ρ dV` — повний електричний заряд, локалізований усередині об'єму `V`.

### Умова квазістаціонарного вузла (Перша аксіома зосередженості)

У моделі зосереджених елементів металевий вузол (стик дротів) розглядається як ідеальний провідник без власної ємності. Заряд на ньому не може накопичуватися у часі, тому часова похідна внутрішнього заряду строго дорівнює нулю:

```
dQ_node / dt = 0
```

Поверхневий інтеграл розбивається на суму інтегралів по `N` окремих провідних гілках з площею перерізу `A_k`, які перетинають поверхню `S`. Оскільки електричний струм у `k`-тій гілці за означенням дорівнює потоку вектора густини струму `I_k = ∫_{A_k} J · dA`, інтегральне рівняння неперервності спрощується до тотожності:

```
∑_{k=1}^N I_k = 0      [KCL: Перший закон Кірхгофа]
```

Якщо ж вузол містить обкладку конденсатора `C`, накопичення заряду є відмінним від нуля (`dQ_node/dt = I_D = C · dV/dt`), і струм провідності `J` збалансовується струмом зміщення `J_D = ∂D/∂t` всередині діелектрика.

## 3. Математичний вивід Другого закону Кірхгофа (KVL)

Розглянемо закон індукції Фарадея в інтегральній формі для замкненого орієнтованого контуру `Γ`, який спирається на поверхню `S_Γ`:

```
∮_Γ E · dl = − d/dt (∫_{S_Γ} B · dA) = − dΦ_B / dt
```

де `Φ_B = ∫_{S_Γ} B · dA` — повний магнітний потік, що пронизує площу контуру `Γ`.

Підставимо у цей інтеграл фундаментальний вираз для електричного поля через потенціали `E = −∇Φ − ∂A/∂t`:

```
∮_Γ (−∇Φ − ∂A/∂t) · dl = − ∮_Γ ∇Φ · dl − ∂/∂t (∮_Γ A · dl)
```

Оскільки градієнт скалярного потенціалу `∇Φ` уздовж будь-якого замкненого контуру тотожно дорівнює нулю (`∮_Γ ∇Φ · dl ≡ 0`), циркуляція електричного поля повністю визначається вихровим додаванням векторного потенціалу:

```
∮_Γ E · dl = − ∂/∂t (∮_Γ A · dl) = − dΦ_B / dt
```

### Умова зосередженого контуру (Друга аксіома зосередженості)

Абстракція зосереджених елементів вимагає, щоб часова зміна магнітного поля була повністю замкнена всередині спеціальних індуктивних елементів (котушок індуктивності `L`). У просторі **поза елементами** (вздовж з'єднувальних провідників та вузлів) магнітне поле відсутнє або не змінюється в часі:

```
∂B / ∂t = 0   [у просторі між елементами]
```

За цієї умови векторне поле `E` у просторі між елементами стає строго **потенціальним**:

```
rot(E) = 0  ⇒  E = −∇Φ
```

Різниця потенціалів (напруга) між терміналами `A_k` та `B_k` для `k`-того елемента визначається як:

```
V_k = Φ(A_k) − Φ(B_k) = − ∫_{A_k}^{B_k} E · dl
```

Сумуючи спади напруг уздовж замкненого контуру із `M` послідовно з'єднаних елементів, отримуємо **Другий закон Кірхгофа (KVL)**:

```
∑_{k=1}^M V_k = 0      [KVL: Другий закон Кірхгофа]
```

## 4. Суворий вивід компонентних рівнянь з полів

### А. Резистор (Закон Ома у диференціальній та інтегральній формах)

У провідному матеріалі з питомою провідністю `σ` та питочним опором `ρ_res = 1 / σ` виконується диференціальний закон Ома `J = σ · E`. Розглянемо однорідний провідник довжиною `l` та площею поперечного перерізу `A`.

Проінтегруємо густину струму по перерізу провідника:

```
I = ∫_A J · dA = ∫_A σ · E · dA = σ · A · E_avg
```

Проінтегруємо напруженість електричного поля уздовж довжини провідника `l`:

```
V = ∫_0^l E · dl = E_avg · l
```

Виражаючи напруженість `E_avg = V / l` та підставляючи у вираз для струму, отримуємо:

```
I = σ · A · (V / l)  ⇒  V = I · (l / (σ · A)) = I · R
```

де зосереджений опис опору резистора визначається геометричними та матеріальними параметрами:

```
R = l / (σ · A) = ρ_res · l / A
```

### Б. Конденсатор (Струм зміщення Максвелла)

У конденсаторі між двома металевими обкладками площею `A`, віддаленими на відстань `d`, міститься діелектрик із проникністю `ε`. Струм провідності `J` всередині діелектрика дорівнює нулю, однак при зміні напруги виникає струм зміщення `J_D = ∂D/∂t = ε · ∂E/∂t`.

Напруженість однорідного електричного поля між обкладками дорівнює `E(t) = V(t) / d`. Повний струм, що протікає через конденсатор, дорівнює потоку вектора густини струму зміщення через Площу обкладки `A`:

```
I_C(t) = ∫_A J_D · dA = ∫_A (ε · ∂E/∂t) · dA = ε · A · d/dt (V(t) / d) = (ε · A / d) · (dV(t) / dt)
```

Звідси отримуємо компонентне рівняння ємності:

```
I_C(t) = C · (dV(t) / dt)      [де зосереджена ємність C = ε₀ · ε · A / d]
```

### В. Індуктивність (Закон індукції та потік індукції)

Розглянемо соленоїд або котушку із `N` витків, площею перерізу `A` та довжиною `l`. Магнітне поле всередині котушки при протіканні струму `I` дорівнює `B = μ₀ · μ · N · I / l`.

Повний магнітний потік (зчеплення потоку), що пронизує всі `N` витків:

```
Ψ = N · Φ_B = N · B · A = (μ₀ · μ · N² · A / l) · I = L · I
```

Згідно із законом Фарадея, напруга на терміналах котушки `V_L(t)` дорівнює ЕРС самоіндукції, взятій із протилежним знаком (за правилом Ленца):

```
V_L(t) = dΨ / dt = d(L · I(t)) / dt = L · (dI(t) / dt)
```

де зосереджена індуктивність котушки дорівнює:

```
L = μ₀ · μ · N² · A / l
```

## 5. Тейлорівське розкладання запізнення та межа згасання зосередженості

Для системи, що коливається з коловою частотою `ω`, хвильове число у середовищі дорівнює `k = ω / c = 2π / λ`. Запізнення електромагнітного потенціалу описується множником Гріна `exp(−j · k · r)`.

Розкладемо цей фазовий множник у ряд Тейлора за малим безрозмірним параметром `(k · r ≪ 1)`:

```
exp(−j · k · r) = 1 − j · (k · r) − (k · r)² / 2 + j · (k · r)³ / 6 + ...
```

Фізичний зміст кожного члена розкладу:

1. **Член 0-го порядку (`1`):** Фізично відповідає нескінченній швидкості світла (`c → ∞`). Він задає класичну електростатику Кулона та стаціонарні закони Кірхгофа без реактивних запізнень.
2. **Член 1-го порядку (`−j·k·r`):** Ураховує лінійне запізнення за фазою на 90°. Він описує реактивні індуктивні та ємнісні ефекти (зосереджені елементи `L` і `C`), що зберігають енергію без випромінювання.
3. **Член 2-го порядку (`−(k·r)² / 2`):** Ураховує втрати на випромінювання електромагнітних хвиль у відкритий простір. Він породжує **опір випромінювання `R_rad ∝ ω²`**.
4. **Члени вищих порядків:** Описують мультипольні випромінювальні ефекти (квадрупольне та октупольне випромінювання).

Зосереджена модель залишається правомірною доти, доки ми можемо знехтувати членами 2-го та вищих порядків. Це задає строгий математичний критерій:

```
(k · r)² / 2 ≪ k · r  ⇒  k · r ≪ 1  ⇒  r ≪ λ / (2π) ≈ 0.159 · λ
```
