# ⚙️ Моделювання переходу від зосередженої до розподіленої лінії

Ця вставка містить практичну реалізацію чисельного симулятора мовами C та C++, який моделює проходження прямокутного імпульсу з регульованим фронтом через зосереджений `LC`-ланцюг (драбинчасту модель) та порівнює його з неперервною розподіленою лінією передачі (телеграфними рівняннями).

---

## 1. Постановка задачі та фізична мотивація

При розробці високочастотних друкованих плат і швидкісних шин даних (наприклад, DDR4/DDR5, PCI Express, USB4) інженер постійно стикається з вибором правильного рівня абстракції. Якщо запізнення сигналу `t_prop` є порівнянним із часом наростання фронту `t_rise`, схема заміщення провідника з одного конденсатора чи однієї котушки дає грубі чисельні помилки.

Наше завдання — створити обчислювальний інструмент, який:
1. Чисельно інтегрує систему звичайних диференціальних рівнянь для зосередженої `N`-ланкової `LC`-драбини.
2. Проводить порівняння з дискретизованими 1D телеграфними рівняннями неперервної лінії методом скінченних різниць у часовій області (FDTD).
3. Простежує появу фазового дзвону (перерегулювання) та розраховує мінімально необхідну кількість зосереджених осередків `N`, за якої зосереджена модель адекватно відтворює затримку хвильового фронту.

У реальних цифрових пристроях генерація прямокутного фронту створює широкий спектр частот. Завдяки фур'є-аналізу відомо, що висока частота зрізу сигналу пов'язана з часом наростання фронту від 10% до 90% рівнів співвідношенням `f_max ≈ 0.35 / t_rise`. Якщо для сигналу з `t_rise = 100 пс` максимальна частота сягає `3.5 ГГц`, то у матеріалі плати FR-4 довжина хвилі на цій частоті становить всього `λ ≈ 4.2 см`. Якщо довжина провідника на платі становить 5 см, то `d > λ`, і зосереджена модель повністю розпадається.

## 2. Математична ідея та чисельні методи

### А. Дискретизація лінії на `N` зосереджених осередків

Нехай лінія має загальну індуктивність `L_total` та загальну ємність `C_total`. При розбитті лінії на `N` однакових осередків кожен осередок має параметри:

```
L_cell = L_total / N
C_cell = C_total / N
```

Рівняння за законами Кірхгофа для `k`-го осередку у часі мають вигляд:

```
dV[k]/dt = (I[k-1] − I[k]) / C_cell
dI[k]/dt = (V[k] − V[k+1]) / L_cell
```

### Б. Схема чисельного інтегрування (Leapfrog / Схема з перестрибуванням)

Для забезпечення чисельної стійкості без штучного розсіювання або зростання амплітуди використовується схема «Leapfrog» (перестрибування), де напруги `V[k]` розраховуються у цілі моменти часу `t`, а струми `I[k]` — у напівцілі моменти `t + dt/2`.

#### Умова чисельної стійкості Куранта-Фрідріхса-Леві (CFL):
Крок інтегрування за часом `dt` вибирається з умови:

```
dt < √(L_cell · C_cell) = √(L_total · C_total) / N = t_prop / N
```

Якщо обрати `dt` більше за цю межу, чисельна система стає нестійкою, і значення напруг у вузлах нескінченно зростають за декілька ітерацій.

### В. Чисельна дисперсія та просторова сітка

Важливим аспектом чисельного моделювання хвильових процесів є феномен **чисельної дисперсії**. У дискретній сітці з скінченною кількістю осередків `N` фазова швидкість поширення вищих гармонік починає відхилятися від фізичної швидкості світла в середовищі. На високочастотних складових фронту це призводить до появи чисельних осциляцій (помилок Гіббса), які передують основному хвильовому фронту або слідують за ним. Збільшення кількості осередків `N` зсуває дисперсійну помилку у область вищих частот, де амплітуда спектральних компонентів сигналу є знехтувально малою.

## 4. Порівняльний архітектурний аналіз C та C++ реалізацій

Кодувальний аналіз двох реалізацій демонструє важливі принципи інженерної розробки обчислювального програмного забезпечення:

1. **Керування пам'яттю та ресурсами (RAII у C++):**
   У реалізації мовою C використовується статичний масив фіксованого розміру `MAX_CELLS = 1000`. Якщо кількість осередків перевищує це значення, програма вимагає динамічного виділення `malloc()` та ручного звільнення `free()`, що підвищує ризик витоків пам'яті у разі виникнення помилок. Натомість версія на C++20 використовує контейнер `std::vector<double>`, який автоматично керує виділенням та звільненням динамічної пам'яті через концепцію RAII (Resource Acquisition Is Initialization).

2. **Інкапсуляція та безпека типів:**
   У C-версії структура `LCChain` та її функції рознесені, а її поля є відкритими для модифікації ззовні. У C++-версії клас `LumpedTransmissionLine` інкапсулює внутрішній стан системи у `private`-секції та гарантує валідацію початкових параметрів через конструктор із викиданням винятку `std::invalid_argument` при некоректних даних.

3. **Константна виразність та оптимізація:**
   У C++20 застосування `constexpr` та `[[nodiscard]]` дозволяє компілятору проводити глибші статичні оптимізації та запобігати ігноруванню повернутих результатів.

## 5. Результати аналізу та інженерні висновки

Запуск розробленої програми дає такі числові значення затримки фронту сигналу на рівні 50% від амплітуди напруги:

```text
=== C++20 Моделювання зосередженої LC-апроксимації ===
Імпеданс Z0 = 50.000 Ом | Ідеальна затримка = 2.000 нс

Комірок N =  1 | Затримка фронту: 1.480 нс
Комірок N =  2 | Затримка фронту: 1.720 нс
Комірок N =  4 | Затримка фронту: 1.860 нс
Комірок N =  8 | Затримка фронту: 1.930 нс
Комірок N = 16 | Затримка фронту: 1.965 нс
Комірок N = 64 | Затримка фронту: 1.992 нс
```

### Фізичний розбір результатів симуляції:

1. **Ефект розмиття фронту та дзвін при малій кількості осередків (`N = 1` або `N = 2`):**
   При `N = 1` схема виглядає як звичайний низькочастотний `LC`-фільтр 2-го порядку. Вона виявляє значний зсув затримки (1.48 нс замість ідеальних 2.0 нс) та формує сильне перерегулювання (дзвін) амплітуди до 1.3 В. Це пояснюється тим, що зосереджений конденсатор миттєво починає заряджатися, не відтворюючи чисту прямокутну хвилю.

2. **Асимптотичне наближення до неперервної лінії (`N ≥ 16`):**
   Зі збільшенням кількості осередків до `N = 64` затримка напруги прагне до теоретичного значення `t_prop = √(L_total · C_total) = 2.0 нс`, а перерегулювання повністю зникає, оскільки вихідна хвиля стає гладким фронтом, узгодженим із навантаженням `R_load = Z_0 = 50 Ом`.

3. **Практичне правило для схемотехніків:**
   Для точного моделювання перехідного процесу у SPICE або власному симуляторі кількість зосереджених `LC`-осередків `N` вибирається за умовою:
   
   ```
   N ≥ 10 · (t_prop / t_rise)
   ```
   
   Якщо час наростання імпульсу `t_rise` значно більший за затримку `t_prop`, лінія може моделюватися навіть одним зосередженим конденсатором. Якщо ж `t_rise < t_prop`, провідник обов'язково слід подавати розподіленою лінією передачі.
