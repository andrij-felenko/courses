# 📋 Специфікація опису зосереджених елементів у SPICE

Ця вставка містить повнофункціональний довідковий інтерфейс та синтаксичну специфікацію мови опису схемних сіток (**SPICE Netlist Format**) для зосереджених `RLC`-елементів, неідеальних паразитних компонентів, взаємної індуктивності, нелінійних моделей матеріалів, керованих джерел та ліній передачі у сучасних промислових симуляторах (ngspice, LTspice, HSPICE, Cadence Spectre).

---

## 1. Архітектурні засади симулятора SPICE та матричний формалізм

Перед розглядом окремих синтаксичних конструкцій необхідно збагнути, як саме симулятор SPICE (Simulation Program with Integrated Circuit Emphasis) перетворює текстовий опис зосереджених елементів на часовий або частотний відклик схеми.

В основі всіх симуляторів сімейства SPICE лежить **модифікований вузловий аналіз (Modified Nodal Analysis, MNA)**. Кожен зосереджений елемент, доданий у текстовий файл сітки (netlist), перетворюється на відповідну локальну матрицю провідності та джерел струму, яка вбудовується у глобальну систему алгебраїчних чи диференціально-алгебраїчних рівнянь:

```
G · V(t) + C · dV(t)/dt = I(t)
```

де `G` — матриця кондуктансів (статичних опорів), `C` — матриця реактивних елементів (ємностей та індуктивностей), `V(t)` — вектор невідомих вузлових потенціалів, а `I(t)` — вектор зовнішніх джерел струму та напруги.

Для нелінійних компонентів (діодів, транзисторів, нелінійних ємностей) SPICE використовує ітераційний метод Ньютона-Рафсона на кожному часовому кроці. Для чисельного інтегрування часових залежностей застосовуються неявні методи: метод трапецій або класичні методи Гіра (Gear integration). Розуміння цього матричного формалізму пояснює, чому синтаксичний опис кожного зосередженого елемента вимагає чіткої вказівки номерів або імен вузлів підключення — вони задають індекси рядків і стовпчиків у глобальній матриці MNA.

Усі вузли електричної схеми ідентифікуються довільними текстовими або числовими мітками. Винятком є **нульовий вузол (`0` або `GND`)**, який вважається загальним опорним потенціалом (землею) із фіксованою напругою `V(0) = 0.0 В`. Наявність хоча б одного нульового вузла є обов'язковою умовою для забезпечення невиродженості матриці провідності `G`.

## 2. Синтаксис пасивних зосереджених елементів

Усі зосереджені компоненти у форматі SPICE позначаються за жорстким правилом: перша буква позиційного позначення (RefDes) однозначно визначає фізичний тип елемента (`R` — резистор, `C` — конденсатор, `L` — індуктивність, `K` — магнітний зв'язок, `V`/`I` — джерела).

### А. Резистор (`R` — Resistor)

Резистор є найпростішим дисипативним елементом, який додає діагональні елементи `1/R` у матрицю провідностей `G`.

#### Стандартна форма запису:
```text
R<name> <node_pos> <node_neg> <value> [tc1=<val>] [tc2=<val>] [temp=<val>]
```

#### Напівпровідникова (розширена) форма запису:
```text
R<name> <node_pos> <node_neg> [model_name] L=<length> W=<width> [temp=<val>]
```

#### Параметри елемента:

| Параметр | Фізичний зміст та опис | Одиниці вимірювання | За замовчуванням |
| :--- | :--- | :--- | :--- |
| `<node_pos>` | Позитивний вузол підключення (анод) | Рядок / Число | Обов'язкове |
| `<node_neg>` | Негативний вузол підключення (катод) | Рядок / Число | Обов'язкове |
| `<value>` | Номінальний опір компонента | Ом (`Ω`) | Обов'язкове |
| `tc1` | Перший (лінійний) температурний коефіцієнт опору (ТКС) | `1 / °C` | `0.0` |
| `tc2` | Другий (квадратичний) температурний коефіцієнт опору | `1 / °C²` | `0.0` |
| `temp` | Індивідуальна робоча температура даного компонента | `°C` | `27.0` |

#### Фізична модель температурного розрахунку:
Значення опору в процесі симуляції автоматично перераховується залежно від робочої температури схемного середовища `T` за рівнянням:

```
R(T) = R_nominal · (1 + tc1 · (T − T_ref) + tc2 · (T − T_ref)²)
```

де `T_ref` — базова температура вимірювань (зазвичай `27 °C` або `300.15 K`).

#### Моделювання шуму резистора:
Під час аналізу малих сигналів у частотній області (`.NOISE`) SPICE автоматично підключає паралельно до кожного резистора `R` джерело білого теплового шуму Джонсона-Найквіста з спектральною густиною потужності струму:

```
S_i = 4 · k_B · T / R  (А² / Гц)
```

де `k_B = 1.380649 e-23 Дж/К` — стала Больцмана.

### Б. Конденсатор (`C` — Capacitor)

Конденсатор додає елементи у матрицю реактивностей `C`. У SPICE підтримуються як ідеальні лінійні конденсатори, так і нелінійні полупровідникові ємності, значення яких залежить від прикладеної напруги.

#### Стандартна форма запису:
```text
C<name> <node_pos> <node_neg> <value> [ic=<initial_voltage>]
```

#### Нелінійна поліноміальна форма запису:
```text
C<name> <node_pos> <node_neg> POLY C0 C1 C2 ...
```

#### Параметри елемента:

| Параметр | Фізичний зміст та опис | Одиниці вимірювання | За замовчуванням |
| :--- | :--- | :--- | :--- |
| `<value>` | Номінальна зосереджена ємність | Фарад (`F`) | Обов'язкове |
| `ic` | Початкова напруга на конденсаторі для аналізу `.tran` | Вольт (`V`) | `0.0` |
| `m` | Коефіцієнт паралельного множення (кількість паралельних деталей) | Абсолютне число | `1.0` |
| `scale` | Масштабний коефіцієнт геометричних розмірів | Абсолютне число | `1.0` |

#### Фізична модель поліноміальної нелінійної ємності:
У багатьох напівпровідникових структурованих елементах (наприклад, бар'єрній ємності p-n переходу чи сегнетоелектриках) ємність змінюється залежно від миттєвої напруги `V(t)`:

```
C(V) = C0 + C1 · V(t) + C2 · V²(t) + C3 · V³(t) + ...
```

Під час розрахунку перехідного процесу (`.tran`) прапорець `UIC` (Use Initial Conditions) у директиві `.TRAN` змушує симулятор використовувати значення `ic=<initial_voltage>` як початкову умову у момент `t = 0`, уникнувши попереднього розрахунку точок постійного струму (`.op`).

---

### В. Індуктивність (`L` — Inductor)

Індуктивність створює додатковий рядок у матриці MNA для прохідного струму та моделює накопичення магнітного потоку `Φ = L · I`.

#### Стандартна форма запису:
```text
L<name> <node_pos> <node_neg> <value> [ic=<initial_current>]
```

#### Параметри елемента:

| Параметр | Фізичний зміст та опис | Одиниці вимірювання | За замовчуванням |
| :--- | :--- | :--- | :--- |
| `<value>` | Номінальна зосереджена індуктивність | Генрі (`H`) | Обов'язкове |
| `ic` | Початковий струм через індуктивність для аналізу `.tran` | Ампер (`A`) | `0.0` |
| `nt` | Кількість витків (для інтегральних індуктивностей) | Абсолютне число | `1.0` |

## 3. Залежні та поведінкові джерела (VCVS, VCCS, CCCS, CCVS, B-Sources)

У зосереджених еквівалентних схемах широко використовуються лінійні та нелінійні залежні джерела для моделювання підсилювальних каскадів, операційних підсилювачів, зворотних зв'язків та складних математичних залежностей.

### А. Чотири класи лінійних залежних джерел

1. **`E` — Джерело напруги, кероване напругою (VCVS):**
   `E<name> <n+> <n-> <nc+> <nc-> <gain>`
   Напруга між `n+` та `n-` дорівнює: `V_out = gain · (V(nc+) − V(nc-))`.

2. **`G` — Джерело струму, кероване напругою (VCCS):**
   `G<name> <n+> <n-> <nc+> <nc-> <transconductance>`
   Струм від `n+` до `n-` дорівнює: `I_out = transconductance · (V(nc+) − V(nc-))`.

3. **`F` — Джерело струму, кероване струмом (CCCS):**
   `F<name> <n+> <n-> <v_control_name> <current_gain>`
   Струм залежить від струму, що протікає через вимірювальне джерело напруги `v_control_name`.

4. **`H` — Джерело напруги, кероване струмом (CCVS):**
   `H<name> <n+> <n-> <v_control_name> <transresistance>`
   Напруга виходу дорівнює добутку струму через `v_control_name` на трансопір.

### Б. Нелінійні поведінкові джерела (`B` — Arbitrary Behavioral Source)

Поведінкові джерела дозволяють задавати довільні математичні вирази для струму або напруги залежно від будь-яких вузлових потенціалів чи струмів гілок.

#### Приклади синтаксису в ngspice / LTspice:
```text
* Джерело напруги як нелінійна функція (помножувач або квадрат)
B1 node_out 0 V = V(node_a) * V(node_b) + PWR(V(node_c), 2)

* Джерело струму з функцією обмежувача (насичення)
B2 node_i 0 I = LIMIT(V(ctrl) * 1.5mA, -10mA, 10mA)

* Джерело з температурною залежністю та математичними функціями
B3 out 0 V = 1.0V * EXP(-TIME / 1.0us) * SIN(2 * 3.1415926 * 1e6 * TIME)
```

## 4. Взаємна індуктивність та нелінійні магнітні осердя (`K`)

Магнітний зв'язок між двома або кількома зосередженими котушками індуктивності реалізується за допомогою спеціального елемента зв'язку `K`.

### А. Лінійний магнітний зв'язок двох котушок

```text
K<name> L<inductor1> L<inductor2> <coupling_coefficient>
```

#### Фізичний зміст коефіцієнта зв'язку:
Коефіцієнт магнітного зв'язку `k` визначає частку магнітного потоку, спільного для обох котушок:

```
0.0 ≤ k ≤ 1.0
```

Значення взаємної індуктивності `M` обчислюється симулятором як:

```
M = k · √(L1 · L2)
```

#### Приклад опису 3-фазного або багатообмоточного трансформатора:
```text
* Первинна та дві вторинні обмотки
L1 in1 in2 100uH
L2 out1 0   25uH
L3 out2 0   25uH

* Задання коефіцієнтів зв'язку між усіма парами
K12 L1 L2 0.998
K23 L2 L3 0.995
K13 L1 L3 0.998
```

### Б. Нелінійне магнітне осердя з гістерезисом (Модель Джайлса-Атертона)

У просунутих симуляторах (LTspice, ngspice) елемент `K` може посилатися на модель магнітного матеріалу `.MODEL <name> CORE`, що моделює насичення осердя та петлю гістерезису:

```text
K1 L1 L2 0.999 CORE_FERRITE
.MODEL CORE_FERRITE CORE(Bs=0.45 Br=0.15 Hc=25 Area=0.5 Path=3.5)
```

| Параметр | Фізичний зміст | Одиниці |
| :--- | :--- | :--- |
| `Bs` | Індукція насичення фериту | Тесла (`T`) |
| `Br` | Залишкова магнітна індукція | Тесла (`T`) |
| `Hc` | Коерцитивна сила | Ампер / метр (`A/m`) |
| `Area` | Площа поперечного перерізу магнітопроводу | `см²` |
| `Path` | Середня довжина магнітної лінії | `см` |

## 5. Моделювання неідеальних компонентів через підсхеми (`.SUBCKT`)

Оскільки реальні фізичні деталі містять паразитичні індуктивності виводів (ESL), опір втрат (ESR/DCR) та міжвиткові ємності, у графічних та текстових САПР їх оформлюють у вигляді зосереджених еквівалентних підсхем (Subcircuits).

Виклик підсхеми у головній схемі здійснюється елементом `X`:
```text
X<name> <node1> <node2> ... <subckt_name> [PARAMS: param1=val1 ...]
```

### А. Малоіндуктивний керамічний конденсатор (MLCC 0603 100 нФ)

Підсхема описує послідовну еквівалентну `RLC`-модель з урахуванням опору витоку діелектрика:

```text
* Високочастотний керамічний конденсатор SMD 0603
.SUBCKT C_MLCC_0603_100N node_a node_b
* Послідовне з'єднання: C_ideal + ESR + ESL + опір витоку R_leak
C_ideal node_a 1      100nF
R_esr   1      2      12mOhm
L_esl   2      node_b 750pH
R_leak  node_a node_b 100MOhm
.ENDS C_MLCC_0603_100N
```

### Б. Високочастотний силовий дросель (10 мкГн з міжвитковою ємністю)

```text
* Силовий дросель для DC-DC перетворювача
.SUBCKT L_POWER_10UH node_a node_b
* Основна гілка: L_ideal + DCR (опір обмотки)
L_ideal node_a 1      10uH
R_dcr   1      node_b 35mOhm

* Паралельна паразитна міжвиткова ємність
C_parasitic node_a node_b 8.5pF

* Паралельний опір втрат у сердечнику на високих частотах
R_core_loss node_a node_b 2.2kOhm
.ENDS L_POWER_10UH
```

## 6. Перехід до розподілених ліній передачі (`T` та `LTRA`)

Коли просторовий розмір провідника `d` перевищує `0.1 · λ`, застосування єдиного зосередженого елемента призводить до грубих помилок. У цьому разі SPICE пропонує спеціалізовані моделі ліній передачі.

### А. Ідеальна лінія без втрат (`T` — Lossless Transmission Line)

Ідеальна лінія описує хвильове запізнення без спотворення форми імпульсу.

```text
T<name> <node_in+> <node_in-> <node_out+> <node_out-> Z0=<val> TD=<val>
```

#### Параметри лінії:

| Параметр | Фізичний зміст | Одиниці |
| :--- | :--- | :--- |
| `Z0` | Характеристичний (хвильовий) опір лінії | Ом (`Ω`) |
| `TD` | Однократний час затримки поширення хвилі (Time Delay) | Секунди (`s`) |
| `F` | Робоча частота (альтернатива TD) | Герц (`Hz`) |
| `NL` | Нормована довжина хвилі на частоті F (по замовчуванню 0.25) | Безрозмірне |

### Б. Модель розподіленої лінії з втратами (`LTRA` — Lossy Transmission Line)

Для врахування омичких втрат у міді та дисипації у діелектрику використовується чотириполюсник `O` або макромодель `LTRA`:

```text
O<name> <node_in+> <node_in-> <node_out+> <node_out-> <model_name>
.MODEL <model_name> LTRA(R=<val> L=<val> C=<val> G=<val> LEN=<val>)
```

#### Параметри первинних елементів лінії:

| Параметр | Фізичний зміст | Одиниці |
| :--- | :--- | :--- |
| `R` | Погонний опір провідника на одиницю довжини | Ом / метр (`Ω/m`) |
| `L` | Погонна індуктивність на одиницю довжини | Генрі / метр (`H/m`) |
| `C` | Погонна ємність на одиницю довжини | Фарад / метр (`F/m`) |
| `G` | Погонна провідність витоку ізоляції | Сіменс / метр (`S/m`) |
| `LEN` | Фізична довжина лінії передачі | Метри (`m`) |

## 7. Директиви керування симуляцією таналаштування збіжності

Для виконання обчислень над заповненою сіткою SPICE використовує спеціальні керуючі директиви, що починаються з крапки (`.`).

### А. Основні типи розрахунків

- **`.TRAN <tstep> <tstop> [tstart] [tmax]`** — розрахунок перехідного процесу у часовій області.
- **`.AC <dec|oct|lin> <npoints> <fstart> <fstop>`** — аналіз малих сигналів у частотній області (АЧХ та ФЧХ).
- **`.DC <src_name> <vstart> <vstop> <vstep>`** — розрахунок передавальних характеристик постійного струму.
- **`.NOISE V(node_out) <src_name> <dec|oct|lin> <npoints> <fstart> <fstop>`** — розрахунок спектральних густин внутрішніх шумів.

### Б. Параметри збіжності чисельних методів (`.OPTIONS`)

При моделюванні високоелементних схем із паразитними параметрами чисельні методи Ньютона-Рафсона або Гіра можуть зазнавати збоїв збіжності (Singular Matrix або No Convergence in Transient Analysis). Для вирішення цих проблем застосовуються параметри директиви `.OPTIONS`:

```text
.OPTIONS RELTOL=1e-4 ABSTOL=1e-12 VNTOL=1e-6 GMIN=1e-12 ITL4=100 RAMPTIME=10ns
```

| Опція | Фізичний та чисельний зміст | Значення за замовчуванням |
| :--- | :--- | :--- |
| `RELTOL` | Відносна похибка для розрахунку напруг та струмів | `1e-3` (0.1%) |
| `ABSTOL` | Абсолютна похибка струму в амперах | `1e-12` (1 пА) |
| `VNTOL` | Абсолютна похибка вузлової напруги в вольтах | `1e-6` (1 мкВ) |
| `GMIN` | Мінімальна шунтуюча провідність, що додається до кожного p-n переходу | `1e-12` См |
| `ITL4` | Максимальна кількість ітерацій Ньютона-Рафсона на одному часовому кроці | `10` (для проблемних схем збільшують до `100`) |

## 8. Повний приклад схемної сітки SPICE для симуляції перехідних процесів

Нижче наведено повністю працездатний тестовий netlist-файл для симулятора ngspice/LTspice, який порівнює відклик зосередженої `RLC`-схеми та розподіленої лінії передачі при подачі крутого фронту напруги.

```text
* SPICE Netlist: Порівняння зосередженої та розподіленої моделей
.OPTIONS RELTOL=1e-4 ABSTOL=1e-12
.PARAM V_STEP=3.3V
.PARAM T_RISE=50p

* 1. Джерело імпульсної напруги (генератор прямокутних імпульсів)
V_SRC in 0 PULSE(0 {V_STEP} 0 {T_RISE} {T_RISE} 5n 10n)

* 2. Ланцюг А: Зосереджена 1-ланкова RLC-модель
R_src_a in node_a1 50.0
L_lump_a node_a1 node_a2 10.0nH
C_lump_a node_a2 0       4.0pF
R_load_a node_a2 0       50.0

* 3. Ланцюг Б: Ідеальна розподілена лінія передачі (Z0 = 50 Ом, TD = 700 пс)
R_src_b in node_b1 50.0
T_line_b node_b1 0 node_b2 0 Z0=50.0 TD=700p
R_load_b node_b2 0       50.0

* 4. Директиви аналізу та виводу
.TRAN 1p 3n
.CONTROL
  run
  plot v(node_a2) v(node_b2) title 'Порівняння зосередженого RLC та лінії T'
.ENDC
.END
```
