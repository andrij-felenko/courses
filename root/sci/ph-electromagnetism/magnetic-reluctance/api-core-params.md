# 📋 Довідник параметрів магнітопроводів та геометрії осердей

Цей довідник містить систематизовані нормовані формули, нормативні таблиці геометричних параметрів стандартних типорозмірів феритових і сталевих осердей, фізичні характеристики магнітом'яких матеріалів та опис коефіцієнта індуктивності `A_l`. Матеріал розрахований на інженерів-розробників моточних вузлів, трансформаторів та силових дроселів.

---

### 1. Геометричні константи та фізичні формули осердя

Магнітні осердя реальних електротехнічних пристроїв мають складну геометричну форму: округлі центральні керни, прямокутні ярма, закруглені кути та вікна для вкладання обмотки. Для спрощення тривимірних розрахунків міжнародні стандарти (IEC 60205) описують геометрію будь-якого осердя за допомогою двох загальних геометричних констант `C_1` та `C_2`. Ці константи дозволяють звести складну геометрію до еквівалентного тороїдального осердя з ефективною довжиною лінії `l_e`, ефективною площею перерізу `A_e` та ефективним об'ємом `V_e`.

Перша геометрична константа `C_1` визначає загальний геометричний опір форми осердя при одиничній проникності:

```
C_1 = ∑ (l_i / A_i)
```

Друга геометрична константа `C_2` враховує нерівномірність розподілу площі перерізу вздовж довжини осердя:

```
C_2 = ∑ (l_i / A_i²)
```

За знайденими константами `C_1` та `C_2` ефективні параметри магнітопроводу розраховуються за формулами:

| Геометрична величина | Позначення | Формула обчислення | Одиниці SI | Фізичний зміст |
| :--- | :--- | :--- | :--- | :--- |
| Перша константа осердя | `C_1` | `∑ (l_i / A_i)` | м⁻¹ (мм⁻¹) | Відношення сумарної довжини до площі |
| Друга константа осердя | `C_2` | `∑ (l_i / A_i²)` | м⁻³ (мм⁻³) | Фактор нерівномірності перерізу |
| Ефективна довжина лінії | `l_e` | `C_1² / C_2` | м (мм) | Довжина серединної лінії потоку |
| Ефективна площа перерізу | `A_e` | `C_1 / C_2` | м² (мм²) | Площа еквівалентного тороїда |
| Ефективний об'єм осердя | `V_e` | `C_1³ / C_2² = l_e · A_e` | м³ (мм³) | Об'єм активного феромагнетика |

Обчислення геометричних констант проводиться шляхом розбиття об'єму осердя на прості геометричні ділянки з постійним перерізом. Для кутових ділянок застосовують усереднені радіуси закруглення силових ліній магнітної індукції. Знання ефективної площі `A_e` є критичним для розрахунку індукції насичення, тоді як ефективна довжина `l_e` визначає загальну намагнічувальну силу, необхідну для створення заданого магнітного потоку.

### 2. Основні інженерні формули магнітного кола

У розрахунках моточних елементів застосовують комплекс зв'язаних формул, що поєднують електричні та магнітні параметри.

#### Співвідношення між магнітним опором, провідністю та індуктивністю

Магнітний опір однорідного осердя розраховується через ефективні параметри:

```
R_m = l_e / (μ_0 · μ_e · A_e)
```

де `μ_0 = 4π · 10⁻⁷` Гн/м — магнітна стала, а `μ_e` — ефективна відносна магнітна проникність осердя (з урахуванням зазору або без нього).

Магнітна провідність (пермеанс) є оберненою величиною до опору:

```
Λ = 1 / R_m = (μ_0 · μ_e · A_e) / l_e
```

Основним інженерним параметром для розрахунку індуктивності є коефіцієнт індуктивності `A_l` (AL-factor). Він чисельно дорівнює магнітній провідності й показує індуктивність у наногенрі, яку дає обмотка в один виток:

```
A_l = Λ = L / N²
```

За відомим паспортом осердя `A_l` індуктивність котушки з `N` витків обчислюється як:

```
L = N² · A_l
```

Якщо інженеру необхідно отримати задану індуктивність `L`, кількість витків обмотки знаходять за зворотним виразом:

```
N = √(L / A_l)
```

#### Формули для розрахунку повітряного зазору

При внесенні у магнітний шлях повітряного зазору завтовшки `l_g` опір зазору обчислюється як:

```
R_m,gap = l_g / (μ_0 · A_eff)
```

Ефективна площа зазору `A_eff` перевищує геометричну площу керна `A_e` через ефект випучування силових ліній у повітряному просторі. За моделлю Маклаймана для прямокутного керна зі сторонами `w` та `h`:

```
A_eff = (w + l_g) · (h + l_g)
```

Ефективний коефіцієнт індуктивності осердя із зазором `A_l,gap` визначається переважно товщиною зазору:

```
A_l,gap ≈ (μ_0 · A_e) / l_g
```

Необхідна довжина повітряного зазору `l_g` для отримання заданого значення `A_l` обчислюється за формулою:

```
l_g ≈ (μ_0 · A_e) / A_l - l_e / μ_r
```

### 3. Геометричні типорозміри феритових осердей (ETD, E, PQ, RM)

Різні геометричні серії феритових осердей спроектовані під специфічні інженерні задачі та вимоги до щільності компонування:

Серія E (EF) являє собою найдешевшу та найпоширенішу геометрію для універсальних трансформаторів та дроселів. Її прямокутний центральний керн зручний у виготовленні, проте має підвищену довжину витка обмотки, що збільшує втрати на активному опорі міді.

Серія ETD (Economic Transformer Design) спеціально розроблена для силових імпульсних джерел живлення. Вона має круглий центральний керн, що оптимізує довжину середнього витка й зменшує опір обмотки `R_cu` на 15–20%. Крім того, ширші бічні вікна полегшують намотування товстого дроту та багатожильного літцендрату, що покращує охолодження.

Серія PQ (Power Quality) розроблена для досягнення максимального співвідношення між ефективною площею перерізу `A_e` та об'ємом осердя `V_e`. Вона забезпечує максимальну передавану потужність при мінімальній висоті компонента на платі, а також має чудові показники магнітного екранування.

Серія RM (Rectangular Modul) призначена для надщільного монтажу на друковані плати. Квадратна форма забезпечує максимальне використання площі плати, а майже закритий феритовий корпус мінімізує наведення паразитного магнітного поля на сусідні чутливі аналогові компоненти.

### 4. Фізичні параметри магнітом'яких матеріалів

Магнітом'які матеріали, що застосовуються в електротехніці, поділяються на чотири основні технологічні класи:

Марганець-Цинкові ферити (MnZn) мають високу початкову проникність (`μ_i = 2000...10000`) та високий питомий електричний опір (до `10` Ом·м). Вони є основним матеріалом для силових імпульсних трансформаторів та дроселів, що працюють на частотах від 20 до 500 кГц.

Нікель-Цинкові ферити (NiZn) характеризуються помірною початковою проникністю (`μ_i = 100...800`), але надзвичайно високим електричним опором (до `10⁵` Ом·м). Це робить їх ідеальними для високочастотних застосувань (від 1 до 100 МГц) та фільтрів електромагнітних завад (EMC/EMI).

Порошкові залізні осердя (Powder Iron) виготовляють шляхом пресування мікроскопічних частинок чистого заліза, ізольованих діелектричною органічною плівкою. Вони мають так званий розподілений повітряний зазор (*distributed air gap*), надзвичайно високу індукцію насичення (`B_sat = 1.2...1.5` Тл) та душевну стійкість до постійнострумового підмагнічування.

Сплави Sendust (Kool Mµ), MPP та High Flux являють собою пресовані порошки сплавів заліза, кремнію, алюмінію та нікелю. Вони поєднують високу індукцію насичення порошкового заліза з надзвичайно низькими втратами на гістерезис, що робить їх ідеальними для силових дроселів корекції коефіцієнта потужності (PFC) та вихідних фільтрів інверторів.

### 5. Практичні граничні обмеження та розрахункові правила

При проектуванні магнітних кіл силових елементів інженер повинен контролювати три фундаментальні обмеження:

#### 1. Температурна дерадіація індукції насичення
Магнітна індукція насичення `B_sat` феритів суттєво зменшується при зростанні температури. Для фериту N87 значення `B_sat` становить `0.49` Тл при кімнатній температурі `25°C`, але обвалюється до `0.39` Тл при робочій температурі `100°C`. Розрахункову пікову індукцію `B_max` вибирають із запасом не менше 20–30% від гарячого насичення:

```
B_max ≤ 0.7...0.8 · B_sat(100°C)
```

Для більшості силових феритів це дає безпечний робочий діапазон `B_max = 0.25...0.30` Тл.

#### 2. Перевірка коефіцієнта заповнення вікна міддю `K_u`
Сумарна площа, яку займає обмотка у вікні осердя `W_a`, обмежена геометричною упаковкою дротів та товщиною міжшарової ізоляції. Коефіцієнт заповнення вікна міддю `K_u`:

```
K_u = (N · A_cond) / W_a ≤ 0.35...0.40
```

де `A_cond` — площа поперечного перерізу мідної жили провідника. Перевищення значення `K_u > 0.4` свідчить про те, що обмотка фізично не поміститься у каркас осердя, тому необхідно вибрати більший типорозмір осердя (наприклад, перейти від ETD39 до ETD44).

#### 3. Обмеження втрат на перемагнічування (Формула Штейнметца)
Питомі об'ємні втрати у фериті `P_v` (Вт/м³ або мВт/см³) при синусоїдальному перемагнічуванні описуються емпіричною формулою Штейнметца:

```
P_v = C_m · f^x · B_max^y
```

де `f` — частота переключення, `B_max` — амплітуда індукції, а `C_m, x, y` — коефіцієнти матеріалу (для фериту N87: `x ≈ 1.3`, `y ≈ 2.5`). Інженер повинен обмежувати `B_max` так, щоб сумарні втрати в осерді не викликали перегрів компонента понад допустимі 100–115°C.
