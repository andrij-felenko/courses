# 🧮 Виведення густини енергії електричного поля та механічних сил

Математичний аналіз електростатичних систем дозволяє здійснити фундаментальний і строго обґрунтований перехід від дискретного опису взаємодії точкових зарядів через кулонівські сили до континуального опису суцільного середовища через об'ємне інтегрування скалярного потенціалу `φ` та вектора напруженості електричного поля `E`.

У цій математичній вставці послідовно виведено тотожні перетворення енергії системи зарядів, доведено формулу об'ємної густини енергії поля `w = (1/2) ε₀ E²`, детально обчислено власну енергію конкретних континуутальних розподілів зарядів (суцільна куля, тонка сферична оболонка, плоский і циліндричний конденсатори), розглянуто розклад енергії на власну та взаємну складові, виведено вирази для мультипольних енергій у зовнішніх полях, а також виведено узагальнені електростатичні сили з градієнтів потенціальної енергії при постійному заряді й постійному потенціалі та через розбіжність тензора напружень Максвелла.

## 1. Крокове виведення роботи зі складання системи N точкових зарядів

Розглянемо процес послідовної побудови конфігурації з `N` точкових зарядів `q₁, q₂, ..., q_N`, розташованих у довільно обраних точках тривимірного простору з радіус-векторами `r₁, r₂, ..., r_N`. Початковим станом системи вважається стан, у якому всі `N` зарядів нескінченно віддалені один від одного і від точки спостереження. У цьому вихідному стані кулонівська взаємодія між частками відсутня, а скалярний потенціал та вектор напруженості електричного поля у всьому просторі тотожно дорівнюють нулю: `E = 0`, `φ = 0`.

Процес збирання системи здійснюється квазістатично — тобто з нескінченно малою швидкістю переміщення часток у кожній точці траєкторії, щоб кінетична енергія часток залишалася тотожно нульовою, а електромагнітне випромінювання не виникало. Зовнішні сили переміщують заряди, повністю долаючи протидію кулонівських сил електростатичного поля.

Простежимо роботу зовнішніх сил на кожному кроці встановлення часток:

1. **Принесення першого заряду `q₁`:**
При перенесенні першого заряду `q₁` з нескінченності у точку `r₁` електростатичне поле у просторі ще відсутнє. Сили протидії дорівнюють нулю, тому робота зовнішніх сил є тотожно нульовою:

```
W₁ = 0
```

2. **Принесення другого заряду `q₂`:**
При перенесенні другого заряду `q₂` з нескінченності у точку `r₂` зовнішні сили мусять долати кулонівське поле першого вже встановленого заряду `q₁`. Заряд `q₁` створює у точці `r₂` скалярний потенціал `φ₁(r₂) = q₁ / (4π ε₀ |r₂ - r₁|)`:

```
W₂ = q₂ · φ₁(r₂) = (1 / (4π ε₀)) · (q₁ q₂ / r₁₂)                [робота переміщення q₂ у полі q₁]
```

де `r₁₂ = |r₂ - r₁|` — евклідова відстань між першим і другим зарядами.

3. **Принесення третього заряду `q₃`:**
При перенесенні третього заряду `q₃` у точку `r₃` робота виконується проти суперпозиції полів перших двох вже встановлених зарядів, які створюють у точці `r₃` потенціал `φ₁₂(r₃) = φ₁(r₃) + φ₂(r₃)`:

```
W₃ = q₃ · [ φ₁(r₃) + φ₂(r₃) ]
   = (1 / (4π ε₀)) · [ (q₁ q₃ / r₁₃) + (q₂ q₃ / r₂₃) ]          [робота переміщення q₃ у полі q₁ та q₂]
```

4. **Принесення `k`-го заряду `q_k`:**
Узагальнюючи цей послідовний процес на довільний `k`-й заряд, робота з його внесення в поле попередньо встановлених `(k - 1)` зарядів дорівнює добутку його заряду `q_k` на сумарний потенціал, створений у точці `r_k` усіма попередніми частками:

```
W_k = q_k ∑ [i=1 -> k-1] φ_i(r_k) = (1 / (4π ε₀)) q_k ∑ [i=1 -> k-1] (q_i / r_ik)
```

Повна потенціальна енергія конфігурації `U`, яка за фундаментальним законом збереження енергії дорівнює сумарній роботі зовнішніх сил `W = ∑ [k=1->N] W_k`, виражається алгебраїчною сумою по всіх унікальних неповторюваних парах зарядів:

```
U = (1 / (4π ε₀)) ∑ [1 ≤ i < j ≤ N] (q_i q_j / r_ij)             [сума по унікальних парах i < j]
```

Для зняття незручного математичного обмеження `i < j` симетризуємо цей вираз. Якщо здійснювати подвійне підсумовування по всіх индексах `i` від 1 до `N` та по всіх `j` від 1 до `N` при умові `i ≠ j`, то кожна унікальна пара `(i, j)` буде врахована рівно двічі: один раз як вкладення `(i, j)` і один раз як вкладення `(j, i)`. Оскільки відстані симетричні `r_ij = r_ji` та добутки зарядів комутативні `q_i q_j = q_j q_i`, така подвійна сума виявляється рівно вдвічі більшою за справжню енергію взаємодії. Щоб зберегти математичну тотожність, перед подвійною сумою вводиться нормувальний коефіцієнт `1/2`:

```
U = (1/2) ∑ [i=1->N] ∑ [j ≠ i] (1 / (4π ε₀)) (q_i q_j / r_ij)    [симетричне подвійне підсумовування]
```

Винесемо заряд `q_i` за знак внутрішнього підсумовування по индексу `j`:

```
U = (1/2) ∑ [i=1->N] q_i ( ∑ [j ≠ i] (q_j / (4π ε₀ r_ij)) )     [винесення q_i за внутрішню суму]
```

Вираз у внутрішніх дужках являє собою результуючий скалярний потенціал `φ_i`, створений у точці розміщення `i`-го заряду усіма **іншими** зарядами системи, крім самого `i`-го заряду:

```
φ_i(r_i) = ∑ [j ≠ i] (q_j / (4π ε₀ r_ij))                       [значення потенціалу φ_i у точці r_i]
```

У результаті отримуємо компактну класичну формулу потенціальної енергії взаємодії системи дискретних точкових зарядів:

```
U = (1/2) ∑ [i=1->N] q_i φ_i                                   [дискретна потенціальна енергія]
```

Ця формула є надзвичайно зручною для чисельних розрахунків дискретних систем часток, однак вона описує лише енергію взаємодії між окремими точками й повністю ігнорує енергію, витрачену на створення самих цих часток.

## 2. Перехід до неперервного розподілу зарядів і полевого інтеграла

При переході від точкових часток до макроскопічних тіл із неперервним розподілом заряду з об'ємною густиною `ρ(r)` дискретна сума перетворюється на тривимірний об'ємний інтеграл по області `V`, у якій зосереджено електричні заряди:

```
U = (1/2) ∫ [V] ρ(r) φ(r) dV                                   [потенціальна енергія неперервного розподілу]
```

Щоб здійснити фундаментальний перехід від джерел поля (густини заряду `ρ`) до самого векторного поля `E`, використаємо диференціальну форму закону Гаусса (рівняння Пуассона у вакуумі):

```
ρ = ε₀ ∇·E                                                     [закон Гаусса: ∇·E = ρ / ε₀]
```

Підставляємо вираз для об'ємної густини `ρ` у формулу об'ємної потенціальної енергії:

```
U = (ε₀ / 2) ∫ [V] φ (∇·E) dV                                 [підстановка дивергенції поля]
```

Застосовуємо відому векторну тотожність математичного аналізу для дивергенції добутку скалярної функції `φ` на векторне поле `E`: `∇·(φ E) = φ (∇·E) + E · (∇φ)`. Виразимо звідси підінтегральний добуток `φ (∇·E)`:

```
φ (∇·E) = ∇·(φ E) - E · (∇φ)                                   [розклад дивергенції добутку]
```

З огляду на потенціальний характер електростатичного поля, вектор напруженості пов'язаний зі скалярним потенціалом через його градієнт зі знаком мінус: `E = -∇φ`. Підставимо градієнт потенціалу `∇φ = -E` у другий доданок:

```
-E · (∇φ) = -E · (-E) = E² = |E|²                             [зв'язок напруженості з градієнтом потенціалу]
```

Завдяки цьому вираз для потенціальної енергії розкладається на суму двох окремих об'ємних інтегралів:

```
U = (ε₀ / 2) ∫ [V] ∇·(φ E) dV + (ε₀ / 2) ∫ [V] E² dV           [розбиття інтеграла на два доданки]
```

За теоремою Остроградського — Гаусса перший об'ємний інтеграл від дивергенції векторного поля `(φ E)` перетворюється на поверхневий інтеграл по замкненій межі `S`, яка повністю охоплює об'єм `V`:

```
∫ [V] ∇·(φ E) dV = ∮ [S] φ E · dS                              [теорема Остроградського — Гаусса]
```

Тепер зробимо вирішальний математичний крок: розширимо область інтегрування `V` з локальної області розташування зарядів на весь нескінченний простір `V_∞`. При такому розширенні замкнена поверхня `S` стає сферою нескінченно великого радіуса `R → ∞`.

Дослідимо асимптотичну поведінку підінтегральних величин на нескінченно віддаленій поверхні `S_∞` для будь-якої скінченної локалізованої системи зарядів:
- Скалярний потенціал на великих відстанях спадає як `φ ∝ 1/R`;
- Вектор напруженості електричного поля спадає як `E ∝ 1/R²`;
- Елемент площадки поверхні сфери зростає пропорційно квадрату радіуса `dS = R² dΩ ∝ R²`.

Обчислимо граничне значення поверхневого інтеграла при `R → ∞`:

```
lim_[R -> ∞] ∮ [S_∞] φ E · dS ∝ lim_[R -> ∞] ( (1/R) · (1/R²) · R² ) = lim_[R -> ∞] (1/R) = 0
```

Це доводить, що поверхневий інтеграл на нескінченній межі простору тотожно дорівнює нулю. Отже, у загальному виразі для потенціальної енергії залишається лише один об'ємний інтеграл від квадрата напруженості електричного поля по всьому простору:

```
U = ∫ [V_∞] ( (1/2) ε₀ E² ) dV                                 [повна потенціальна енергія електричного поля]
```

Підінтегральний вираз у цій формулі має чіткий фізичний зміст — він виражає **об'ємну густину енергії електричного поля** `w`:

```
w = (1/2) ε₀ E²                                               [об'ємна густина енергії у вакуумі]
```

У лінійному однорідному й ізотропному діелектричному середовищі з відносною проникністю `ε` та вектором електричного зсуву `D = ε ε₀ E` густина енергії акумулюється в середовищі й дорівнює:

```
w = (1/2) D · E = (1/2) ε ε₀ E²                               [густина енергії в середовищі]
```

Цей строгий висновок означає, що кожен кубічний метр простору, у якому існує електричне поле напруженістю `E`, зберігає в собі елементарну потенціальну енергію `dW = w dV`.

## 3. Математичне обчислення власної енергії неперервних конфігурацій

На відміну від формули для точкових часток, польова формула `U = (ε₀ / 2) ∫ E² dV` враховує як енергію взаємодії окремих частин розподілу, так і власну енергію створення самого розподілу. Розглянемо детальний розрахунок для фундаментальних конфігурацій.

### 1. Рівномірно заряджена суцільна куля

Розглянемо кулю радіуса `R`, у об'ємі якої рівномірно розподілено електричний заряд `Q` з постійною об'ємною густиною `ρ = Q / ((4/3) π R³) = 3 Q / (4 π R³)`.

Завдяки сферичній симетрії розподілу вектор напруженості поля `E` у кожній точці напрямлений уздовж радіус-вектора, а його модуль залежить лише від відстані `r` до центра кулі. За застосуванням закону Гаусса модуль напруженості дорівнює:
- Усередині кулі (`r < R`): `E_внутр(r) = Q r / (4π ε₀ R³)`
- Поза кулею (`r ≥ R`): `E_зовн(r) = Q / (4π ε₀ r²)`

Обчислимо повну електростатичну енергію поля шляхом роздільного інтегрування густини енергії по внутрішній та зовнішній областях простору:

```
U = (ε₀ / 2) ∫ [0 -> R] E_внутр² (4π r² dr) + (ε₀ / 2) ∫ [R -> ∞] E_зовн² (4π r² dr)
```

Обчислимо перший внутрішній інтеграл energy усередині кулі (`r < R`):

```
U_внутр = (ε₀ / 2) 4π ∫ [0 -> R] (Q r / (4π ε₀ R³))² r² dr
        = (Q² / (8π ε₀ R⁶)) ∫ [0 -> R] r⁴ dr
        = (Q² / (8π ε₀ R⁶)) · (R⁵ / 5)
        = Q² / (40π ε₀ R)                                      [внутрішня енергія суцільної кулі]
```

Обчислимо другий зовнішній інтеграл energy поза межами кулі (`r ≥ R`):

```
U_зовн = (ε₀ / 2) 4π ∫ [R -> ∞] (Q / (4π ε₀ r²))² r² dr
       = (Q² / (8π ε₀)) ∫ [R -> ∞] (1 / r²) dr
       = (Q² / (8π ε₀)) · (1 / R)
       = Q² / (8π ε₀ R)                                        [зовнішня енергія суцільної кулі]
```

Сумуємо обидві складові й отримуємо точний вираз для повної власної потенціальної енергії зарядженої кулі:

```
U_куля = U_внутр + U_зовн = (Q² / (40π ε₀ R)) + (Q² / (8π ε₀ R)) = (3 Q²) / (20π ε₀ R)
```

### 2. Рівномірно заряджена тонка сферична оболонка

Для тонкостінної сферичної оболонки радіуса `R` із поверхневим зарядом `Q` поле у внутрішній області тотожно дорівнює нулю `E_внутр = 0` при `r < R`. Поле у зовнішній області `r ≥ R` повністю збігається з полем точкового заряду `E_зовн(r) = Q / (4π ε₀ r²)`.

Тому вся потенціальна енергія зарядженої оболонки зосереджена виключно у зовнішньому просторі:

```
U_оболонка = U_зовн = Q² / (8π ε₀ R)                           [власна енергія сферичної оболонки]
```

Порівнюючи значення `U_куля = (3/5) (Q² / 4π ε₀ R)` та `U_оболонка = (1/2) (Q² / 4π ε₀ R)`, ми бачимо, що процес стискання того самого заряду `Q` з поверхні сфери в її суцільний об'єм вимагає виконання додаткової роботи й збільшує загальну енергію поля на `20%` через появу внутрішнього поля.

## 4. Математичний розклад енергії на власна та взаємна складові

Розглянемо фізичну систему, що утворена двома окремими розподілами зарядів, які утворюють у просторі власні векторні поля `E₁` та `E₂`. За фундаментальним принципом суперпозиції підсумкове напруженість поля у кожній точці простору дорівнює векторній сумі: `E = E₁ + E₂`.

Обчислимо повну об'ємну густину енергії результуючого поля:

```
w = (1/2) ε₀ (E₁ + E²)²
  = (1/2) ε₀ (E₁² + 2 E₁ · E₂ + E₂²)
  = (1/2) ε₀ E₁² + (1/2) ε₀ E₂² + ε₀ (E₁ · E₂)                 [розклад квадрата суми]
```

Інтегруючи цей вираз по всьому нескінченному простору `V_∞`, отримуємо строгий розклад повної енергії поля на три незалежні доданки:

```
U_повна = U₁_власна + U₂_власна + U_взаємодії                  [розклад енергії системи]
```

де:
- `U₁_власна = (1/2) ε₀ ∫ E₁² dV` — незмінна власна енергія першого джерела (робота на його створення з нескінченно малих елементів);
- `U₂_власна = (1/2) ε₀ ∫ E₂² dV` — незмінна власна енергія другого джерела;
- `U_взаємодії = ε₀ ∫ (E₁ · E₂) dV` — перехресна енергія взаємодії двох полів у просторі.

Доведемо тотожність перехресного польового інтеграла класичній кулонівській енергії взаємодії двох точкових зарядів `q₁` та `q₂`, розташованих у точках `r₁` та `r₂`:

```
U_взаємодії = ε₀ ∫ [V_∞] (E₁ · E₂) dV
```

Виразимо перше поле через градієнт його скалярного потенціалу `E₁ = -∇φ₁`:

```
U_взаємодії = -ε₀ ∫ (∇φ₁ · E₂) dV = -ε₀ ∫ [ ∇·(φ₁ E₂) - φ₁ (∇·E₂) ] dV
```

За теоремою Остроградського — Гаусса поверхневий інтеграл від дивергенції `∇·(φ₁ E₂)` перетворюється на інтеграл по нескінченно віддаленій сфері й зникає. Застосовуючи закон Гаусса для другого поля `ε₀ ∇·E₂ = ρ₂`:

```
U_взаємодії = ∫ [V] φ₁(r) ρ₂(r) dV
```

Для точкового заряду `ρ₂(r) = q₂ δ(r - r₂)` (де `δ` — дельта-функція Дірака), інтеграл згортається у значення потенціалу першого заряду в точці розміщення другого заряду:

```
U_взаємодії = q₂ φ₁(r₂) = (1 / (4π ε₀)) · (q₁ q₂ / |r₂ - r₁|)
```

Це доводить абсолютну математичну тотожність між об'ємним перехресним інтегралом векторних полів `ε₀ ∫ (E₁ · E₂) dV` та кулонівською енергією взаємодії часток.

## 5. Потенціальна енергія електричних мультиполів у зовнішньому полі

### 1. Електричний диполь

Розглянемо електричний диполь — систему з двох точкових зарядів `+q` та `-q`, розташованих у точках `r_+` та `r_-`, з'єднаних вектором плеча `l = r_+ - r_-`. Дипольний момент визначається як `p = q l`.

Якщо диполь внесено у зовнішнє електростатичне поле зі скалярним потенціалом `φ(r)`, його потенціальна енергія складається з енергій обох зарядів:

```
U = (+q) φ(r_+) + (-q) φ(r_-) = q [ φ(r_+) - φ(r_-) ]
```

Розкладаючи різницю потенціалів у ряд Тейлора по малому вектору зміщення `l`:

```
φ(r_+) - φ(r_-) ≈ l · ∇φ = -l · E
```

Отримуємо підсумкову формулу потенціальної енергії диполя у зовнішньому полі:

```
U = -q (l · E) = -p · E = -p E cos θ                            [потенціальна енергія диполя]
```

де `θ` — кут між вектором дипольного моменту `p` та вектором напруженості поля `E`.

### 2. Мультипольний розклад енергії довільного розподілу зарядів

Для довільного локалізованого розподілу заряду з об'ємною густиною `ρ(r')` у зовнішньому потенціалі `φ(r')`, розкладемо потенціал у ряд Тейлора навколо початку координат `r' = 0`:

```
φ(r') = φ(0) + r' · ∇φ(0) + (1/2) ∑ [i,j] x'_i x'_j (∂²φ / ∂x_i ∂x_j)|₀ + ...
```

Підставляючи цей розклад у загальний інтеграл потенціальної енергії `U = ∫ ρ(r') φ(r') dV'`, отримуємо мультипольний ряд енергії:

```
U = Q_сум · φ(0) - p · E(0) - (1/6) ∑ [i,j] Q_ij (∂E_j / ∂x_i)|₀ + ...
```

де:
- `Q_сум = ∫ ρ dV'` — повний монопольний заряд системи;
- `p = ∫ r' ρ dV'` — векторний дипольний момент системи;
- `Q_ij = ∫ (3 x'_i x'_j - r'² δ_ij) ρ dV'` — квадрупольний тензор розподілу заряду.

Цей розклад є основою мікроскопічної теорії поляризації діелектриків та міжмолекулярних взаємодій у молекулярній фізиці.

## 6. Обчислення узагальнених механічних сил з градієнта енергії

Для обчислення узагальненої електростатичної сили `F_x`, яка діє на провідник або діелектрик уздовж вільної просторової координати `x`, використовують варіаційні енергетичні принципи.

### Режим 1: Постійний заряд (`Q = const`, ізольована система)

У цьому режимі система є ізольованою від зовнішніх джерел струму. Механічна робота `dW_мех = F_x dx` виконується виключно за рахунок зменшення потенціальної енергії поля `dU`:

```
F_x dx = -dU_Q  ⇒  F_x = -(∂U / ∂x)_Q                          [сила при постійному заряді]
```

Для плоского конденсатора з ємністю `C(x)` та постійним зарядом `Q`, потенціальна енергія дорівнює `U(x) = Q² / (2 C(x))`. Диференціюємо за координатою `x`:

```
F_x = -(∂ / ∂x) [ Q² / (2 C(x)) ]
    = -(Q² / 2) · [ -1 / C²(x) ] · (dC / dx)
    = (1/2) (Q² / C²(x)) (dC / dx)
    = (1/2) V² (dC / dx)                                       [електростатична сила втягування]
```

### Режим 2: Постійна напруга (`V = const`, підключена батарея)

При підключеній батареї з постійною напругою `V`, зміна координати `dx` викликає зміну ємності `dC`. Джерело живлення подає на обкладки додатковий заряд `dQ = V dC` і виконує роботу:

```
dW_бат = V dQ = V² dC
```

Загальний баланс енергії за першим законом термодинаміки має вигляд:

```
dW_бат = dW_мех + dU_V
```

Зміна потенціальної енергії поля у конденсаторі при `V = const` дорівнює:

```
dU_V = d [ (1/2) C(x) V² ] = (1/2) V² dC = (1/2) dW_бат
```

Підставляємо значення `dU_V` у загальний баланс енергії:

```
dW_мех = dW_бат - dU_V = 2 dU_V - dU_V = +dU_V
```

Отже, механічна сила дорівнює **додатній** частковій похідній від потенціальної енергії поля:

```
F_x = +(∂U / ∂x)_V = +(∂ / ∂x) [ (1/2) C(x) V² ] = (1/2) V² (dC / dx) [збіг сил в обох режимах]
```

Обидва математичні підходи дають тотожну фізичну силу `F_x = (1/2) V² (dC/dx)`.

## 7. Тензор напружень Максвелла та формула об'ємної сили Гельмгольца

Для обчислення об'ємних механічних сил у тривимірних діелектричних середовищах використовують **тензор напружень Максвелла** `T_ij`:

```
T_ij = ε ε₀ E_i E_j - (1/2) ε ε₀ E² δ_ij                       [тензор напружень Максвелла]
```

де `δ_ij` — символ Кронекера (`δ_ij = 1` при `i = j` та `0` при `i ≠ j`).

Об'ємна густина електростатичної сили `f = dF / dV` виражається як дивергенція тензора напружень (формула Гельмгольца):

```
f = ∇·T = ρ E - (1/2) ε₀ E² ∇ε + (1/2) ∇ [ ε₀ E² (∂ε / ∂ρ_м) ρ_м ]  [об'ємна сила Гельмгольца]
```

Фізичний зміст трьох доданків:
1. `ρ E` — звичайна кулонівська сила, що діє на вільні об'ємні заряди у середовищі;
2. `-(1/2) ε₀ E² ∇ε` — пондеромоторна сила, яка діє на межу розділу діелектриків із різною проникністю `∇ε` та втягує речовину з вищою `ε` в область сильнішого поля;
3. `(1/2) ∇ [ ε₀ E² (∂ε / ∂ρ_м) ρ_м ]` — сила електрострикції (*electrostriction*), яка виникає через механічну деформацію речовини у неоднорідному електричному полі під дією залежності діелектричної проникності від густини маси `ρ_м`.
