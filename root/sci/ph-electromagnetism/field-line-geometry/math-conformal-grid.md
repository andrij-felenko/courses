# 🧮 Комплексний потенціал і методика криволінійних квадратів

Ця математична вставка містить суворе виведення ортогональності сітки полів у двовимірних електростатичних задачах за допомогою апарату аналітичних функцій комплексної змінної, покрокове розв'язання задачі для коаксіального кабелю та інженерну методику розрахунку погонної ємності й опору методом криволінійних квадратів.

## Комплексний потенціал та рівняння Коші — Рімана

Розглянемо плоску двовимірну задачу електростатики, у якій геометрія електродів продовжена безконечно вздовж осі `z`, а скалярний потенціал `V(x, y)` не залежить від координати `z` (`∂V / ∂z = 0`). У просторі між провідниками, в якому відсутній об'ємний електричний заряд (`ρ = 0`), скалярний потенціал задовольняє двовимірне рівняння Лапласа:

```
∇²V = ∂²V / ∂x² + ∂²V / ∂y² = 0
```

У теорії функцій комплексної змінної будь-яка двічі диференційовна гармонічна функція `V(x, y)` може бути розглядана як дійсна частина деякої аналітичної (голоморфної) функції комплексної змінної `z = x + i·y`:

```
W(z) = V(x, y) + i · U(x, y)
```

Тут `W(z)` називається **комплексним потенціалом** електростатичного поля. 

1. Дійсна частина `Re{W(z)} = V(x, y)` являє собою скалярний електричний потенціал. Геометричне місце точок `V(x, y) = C_1 = const` описує **родину еквіпотенціальних ліній**.
2. Уявна частина `Im{W(z)} = U(x, y)` являє собою **силову функцію** (або функцію потоку). Геометричне місце точок `U(x, y) = C_2 = const` описує **родину силових ліній** напруженості електричного поля.

З вимоги аналітичності (наявності однозначної похідної `dW/dz`) випливає, що дійсна та уявна частини `W(z)` мусять строго задовольняти **умови Коші — Рімана**:

```
∂V / ∂x =  ∂U / ∂y
∂V / ∂y = −∂U / ∂x
```

Похідна комплексного потенціалу `dW/dz` безпосередньо пов'язана з вектором напруженості електричного поля `E = (E_x, E_y)`:

```
dW / dz = ∂V / ∂x + i · (∂U / ∂x) = ∂V / ∂x − i · (∂V / ∂y) = E_x − i · E_y
```

Величина `dW/dz` називається **комплексною напруженістю поля**. Модуль похідної `|dW/dz|` дорівнює модулю вектора напруженості поля `|E| = √(E_x² + E_y²)`.

## Математичне доведення ортогональності

Доведемо, що родина еквіпотенціалей `V(x, y) = const` та родина силових ліній `U(x, y) = const` є взаємно ортогональними у кожній точці простору.

Обчислимо скалярний добуток градієнтів функцій `V` та `U`. Вектори градієнтів у декартових координатах мають вигляд:

```
∇V = (∂V / ∂x, ∂V / ∂y)
∇U = (∂U / ∂x, ∂U / ∂y)
```

Обчислимо скалярний добуток `∇V · ∇U`:

```
∇V · ∇U
= (∂V / ∂x) · (∂U / ∂x) + (∂V / ∂y) · (∂U / ∂y)      [скалярний добуток градієнтів]
= (∂V / ∂x) · (−∂V / ∂y) + (∂V / ∂y) · (∂V / ∂x)      [підстановка умов Коші — Рімана]
= −(∂V / ∂x) · (∂V / ∂y) + (∂V / ∂y) · (∂V / ∂x)      [перестановка множників]
= 0                                                    [взаємне скорочення доданків]
```

Скалярний добуток дорівнює нулю в усіх точках, де похідні не перетворюються на нуль одночасно (`|∇V| ≠ 0`). Це виводить математичний факт: **родини ліній рівного потенціалу V(x, y) = const та ліній потоку U(x, y) = const є взаємно ортогональними в кожній точці простору**.

Оскільки вектор напруженості поля `E = −∇V`, він спрямований строго уздовж градієнта `∇V`, а отже — вздовж дотичної до силових ліній `U(x, y) = const`.

## Комплексний потенціал точкового заряду та коаксіального кабелю

Розглянемо приклад логарифмічного комплексного потенціалу, який описує поле довгої зарядженої нитки або коаксіального кабелю з внутрішнім радіусом `r_a` та зовнішнім радіусом `r_b`:

```
W(z) = −(q_L / (2 · π · ε₀)) · ln(z)
```

Перейдемо до полярних координат `z = r · e^(i·θ)`:

```
W(z) = −(q_L / (2 · π · ε₀)) · (ln(r) + i · θ)
```

Відокремлюючи дійсну та уявну частини, отримуємо:

```
V(r, θ) = −(q_L / (2 · π · ε₀)) · ln(r)
U(r, θ) = −(q_L / (2 · π · ε₀)) · θ
```

1. **Еквіпотенціалі (`V = const`):** рівняння `ln(r) = const` задає `r = const` — родина концентричних кіл навколо центральної осі.
2. **Силові лінії (`U = const`):** рівняння `θ = const` задає родин радіальних променів, що виходять із центра під кутом `θ`.

Концентричні кола `r = const` та радіальні промені `θ = const` перетинаються під кутом `90°` у кожній точці, що демонструє ортогональну сітку полів.

## Геометрія криволінійних квадратів

Розглянемо сітку, утворену родинами еквіпотенціалей `V_k = V_0 + k · ΔV` та силових ліній `U_m = U_0 + m · ΔU` з постійними кроками квантування `ΔV` та `ΔU`.

Нехай `Δn` — нормальна відстань між двома сусідніми еквіпотенціалями вздовж силової лінії, а `Δs` — відстань між двома сусідніми силовими лініями вздовж еквіпотенціалі.

Модуль напруженості поля `E` можна виразити двома шляхами:

1. Через градієнт скалярного потенціалу:
   ```
   E ≈ ΔV / Δn
   ```
2. Через густину потоку вектору напруженості (визначення функції потоку `U`):
   ```
   E ≈ ΔU / Δs
   ```

Зрівнюючи обидва вирази для `E`, отримаємо співвідношення сторін елементарного осередку сітки:

```
ΔV / Δn = ΔU / Δs  ⇒  Δn / Δs = ΔV / ΔU
```

Якщо при побудові сітки ми обираємо однаковий крок квантування потенціалу та потоку (`ΔV = ΔU`), то співвідношення сторін будь-якого осередку прямує до одиниці:

```
Δn / Δs = 1
```

Осередок, обмежений двома дугами еквіпотенціалей та двома дугами силових ліній із прямокутними кутами `90°` у вершинах та однаковими середніми довжинами сторін (`Δn = Δs`), називається **криволінійним квадратом**.

## Практична методика розрахунку ємності та опору

Методика криволінійних квадратів дозволяє обчислити погонну ємність `C'` (у Ф/м) та погонний опір `R'` (у Ом·м) для провідників довільної складної конфігурації без розв'язання диференціальних рівнянь — лише підрахунком осередків графічної сітки:

1. Побудуємо ортогональну сітку криволінійних квадратів між двома провідниками.
2. Нехай `N_parallel` — кількість силових каналів (коридорів між силовими лініями), що йдуть паралельно від одного електрода до іншого.
3. Нехай `N_series` — кількість еквіпотенціальних шарів (смуг між еквіпотенціалями), розташованих послідовно між електродами.

### Формула погонної ємності:
Погонна ємність одиниці довжини (уздовж осі `z`) обчислюється за формулою:

```
C' = ε₀ · ε_r · (N_parallel / N_series)
```

### Формула погонного опору витоку:
Якщо простір між тими самими електродами заповнений слабопровідним середовищем із питомим опором `ρ`, погонний опір витоку ізоляції виражається формулою:

```
R' = ρ · (N_series / N_parallel)
```

### Числовий приклад (розрахунок коаксіального кабелю):
Розглянемо коаксіальний кабель із радіусом центральної жили `r_a = 1.0` мм та внутрішнім радіусом екрана `r_b = 3.5` мм у діелектрику з `ε_r = 2.3` (поліетилен).

Обчислимо ємність за аналітичною формулою:

```
C'_analytical
= (2 · π · ε₀ · ε_r) / ln(r_b / r_a)               [аналітична формула коаксіального кабелю]
= (2 · 3.14159 · 8.854e-12 · 2.3) / ln(3.5 / 1.0)  [підстановка констант та геометрії]
= (1.279e-10) / 1.25276                            [обчислення чисельника та знаменника]
≈ 1.021e-10 Ф/м = 102.1 пФ/м                       [остаточне значення погонної ємності]
```

Тепер застосуємо метод криволінійних квадратів. Розділимо окружність кабелю на `N_parallel = 16` радіальних силових секторів. Кількість еквіпотенціальних шарів рівного потенціалу виражається як `N_series = (N_parallel / 2π) · ln(r_b / r_a) = (16 / 6.283) · 1.25276 ≈ 3.19`.

За формулою криволінійних квадратів:

```
C'_grid
= ε₀ · ε_r · (N_parallel / N_series)               [формула методу криволінійних квадратів]
= (8.854e-12 · 2.3) · (16 / 3.19)                   [підстановка кількості осередків сітки]
= 2.036e-11 · 5.015                                [множення коефіцієнтів]
≈ 102.1 пФ/м                                       [результат графічного розрахунку]
```

Графічний підрахунок осередків сітки дає точно той самий результат, що й суворий математичний інтеграл.

## Існування дуальної силової функції та диференціальні форми

Виведемо математичне існування скалярної силової функції `U(x, y)` за допомогою апарату диференціальних форм. Векторне поле напруженості електростатичного поля `E = (E_x, E_y)` можна представити через 1-форму роботи `ω = E_x · dx + E_y · dy`. 

Потенціальність поля означає, що 1-форма є точної: `ω = −dV`, звідки `dω = 0` (умова відсутності ротора `∇ × E = 0`).

З іншого боку, відсутність об'ємного заряду у порожнечі означає соленоїдальність поля `∇ · E = 0`. Розглянемо дуальну 1-форму потоку `η = −E_y · dx + E_x · dy`. Обчислимо її зовнішній диференціал:

```
dη
= d(−E_y · dx + E_x · dy)                          [зовнішній диференціал 1-форми]
= (−(∂E_y / ∂x) · dx ∧ dx − (∂E_y / ∂y) · dy ∧ dx) + ((∂E_x / ∂x) · dx ∧ dy + (∂E_x / ∂y) · dy ∧ dy) [розгортання похідних]
= (∂E_x / ∂x + ∂E_y / ∂y) · dx ∧ dy               [врахування dx∧dx = 0 та dy∧dx = −dx∧dy]
= (∇ · E) · dx ∧ dy                               [визначення дивергенції]
= 0                                               [умова відсутності джерел]
```

Оскільки 1-форма `η` є замкненою у однозв'язній області (`dη = 0`), за лемою Пуанкаре вона є точної. Отже, існує така скалярна функція `U(x, y)`, що `η = dU`, тобто:

```
dU = −E_y · dx + E_x · dy
```

Порівнюючи коефіцієнти при диференціалах `dx` та `dy`, отримуємо зв'язок напруженості поля із силовою функцією:

```
E_x = ∂U / ∂y
E_y = −∂U / ∂x
```

Оскільки одночасно `E_x = −∂V / ∂x` та `E_y = −∂V / ∂y`, прирівнюючи відповідні компоненти, ми строго отримуємо **умови Коші — Рімана**:

```
∂V / ∂x =  ∂U / ∂y
∂V / ∂y = −∂U / ∂x
```

Единність розв'язку рівняння Лапласа `∇²V = 0` у закритій області гарантується першою теоремою єдиності (теоремою Діріхле). Якщо на границях області задано значення потенціалу `V_bound`, або другою теоремою єдиності (теоремою Неймана), коли на границях задано нормальну похідну `∂V/∂n = −E_n` (густину заряду), розв'язок всередині області визначається строго однозначно. Конформні відображення зберігають граничні умови обох типів: еквіпотенціальна межа Першої граничної задачі `V = const` відображається в еквіпотенціальну межу у площині `W`, а провідна або ізолююча межа Другої граничної задачі з `E_n = 0` відображається у лінію потоку `U = const`.

Головна перевага апарату аналітичних функцій комплексної змінної полягає у **конформності** відображення. Якщо функція `W(z)` є голоморфною і її похідна не перетворюється на нуль (`dW/dz ≠ 0`), то таке відображення зберігає кути між будь-якими двома перетинними кривими на комплексій площині як за величиною, так і за напрямком обходу. Оскільки у плоскопаралельному потенціальному полі ізолінії `V = const` та `U = const` у площині комплексного потенціалу `W = V + i·U` утворюють декартову ортогональну сітку з кутами `90°`, їхні прообрази у фізичній площині `z = x + i·y` також обов'язково перетинаються під кутом `90°`.

## Двовимірне конформне відображення ексцентричного коаксіального кабелю

Розглянемо задачу розрахунку поля між двома паралельними провідними циліндрами зі зміщеними осями (ексцентричний коаксіальний кабель), де внутрішній циліндр радіуса `R₁` перебуває під потенціалом `V₁`, а зовнішній циліндр радіуса `R₂` — під потенціалом `V₂`, з відстанню між осями `d`. При практичному виготовленні високочастотних радіочастотних кабелів технологічне відхилення центральної жили від геометричного центра екрана (ексцентриситет) призводить до нерівномірного згущення силових ліній і зміни хвильового опору.

Для розв meння цієї задачі застосовують дробово-лінійне **перетворення Мебіуса**:

```
w = W(z) = C · ln((z + a) / (z − a))
```

де `a` — дійсне число (фокусна відстань), яка визначається геометричними параметрами циліндрів:

```
a = √(d₁² − R₁²) = √(d₂² − R₂²)
```

тут `d₁` та `d₂` — відстані від фокальних точок `±a` до центрів циліндрів.

Розділимо комплексний потенціал `W(z)` на дійсну та уявну частини. Запишемо комплексне відношення у полярній формі `(z + a) / (z − a) = r₁/r₂ · e^(i · (θ₁ − θ₂))`:

```
V(x, y) = C · ln(r₁ / r₂)
U(x, y) = C · (θ₁ − θ₂)
```

1. **Еквіпотенціалі (`V = const`):** рівняння `r₁ / r₂ = k = const` описує родин **апполонієвих кіл**. Всі еквіпотенціальні поверхні є строгими колами з центрами на осі `x`, проте вони вже не є концентричними. Їхні радіуси та позиції центрів задаються параметром `k`:
   ```
   R(k) = 2 · a · k / |k² − 1|
   x_center(k) = a · (k² + 1) / (k² − 1)
   ```
2. **Силові лінії (`U = const`):** рівняння `θ₁ − θ₂ = α = const` описує родин кіл, що проходять через дві фіксовані фокальні точки `(+a, 0)` та `(−a, 0)`.

Обидві родини кіл (Апполонієві кола `V = const` та фокальні кола `U = const`) перетинаються під кутом `90°` у кожній точці простору.

За допомогою цієї методики обчислюють погонну ємність ексцентричного коаксіального кабелю:

```
C'
= (2 · π · ε₀ · ε_r) / arcosh((R₁² + R₂² − d²) / (2 · R₁ · R₂)) [точна формула ємності]
```

Зміщення центральної жили на відстань `d` зменшує знаменник формули, що викликає зростання погонної ємності `C'` та падіння хвильового опору кабелю `Z₀ = √(L'/C')`. Силові лінії електричного поля сильно згущуються у вузькій щілині між жилою та екраном, створюючи зону підвищеного електричного напруження.

## Двовимірне поле провідного циліндра у однорідному полі (Перетворення Жуковського)

Розглянемо класичну проблему обтікання електростатичним полем провідного циліндра радіуса `R`, вміщеного у зовнішнє однорідне електричне поле з напруженістю `E₀`, спрямоване уздовж осі `x`.

У фізичному відношенні ця задача являє собою суперпозицію двох полів: первинного однорідного поля `E₀` та вторичного поля поляризаційних поверхових зарядів, наведених на металевому циліндрі. З математичної точки зору, наведені заряди створюють двовимірний дипольний момент, розташований у центрі циліндра, тому комплексний потенціал шукається як сума потенціалу однорідного поля `−E₀·z` та потенціалу двовимірного диполя `−E₀·R²/z`.

Комплексний потенціал цього поля будується за допомогою перетворення Жуковського `w = z + R² / z`:

```
W(z) = −E₀ · (z + (R² / z))
```

Перейдемо до полярних координат `z = r · e^(i·θ)`:

```
W(r, θ)
= −E₀ · (r · e^(i·θ) + (R² / r) · e^(−i·θ))           [перехід до полярних координат]
= −E₀ · (r · (cos(θ) + i · sin(θ)) + (R² / r) · (cos(θ) − i · sin(θ))) [формула Ейлера]
= −E₀ · (r + (R² / r)) · cos(θ) − i · E₀ · (r − (R² / r)) · sin(θ)      [групування дійсної та уявної частин]
```

Відокремлюючи скалярні функції, отримуємо:

```
V(r, θ) = −E₀ · (r + (R² / r)) · cos(θ)
U(r, θ) = −E₀ · (r − (R² / r)) · sin(θ)
```

Перевіримо граничні умови:
1. **Поверхня циліндра (`r = R`):**
   ```
   V(R, θ) = −E₀ · (R − (R² / R)) · cos(θ) = −E₀ · (R − R) · cos(θ) = 0
   ```
   Поверхня циліндра `r = R` є строго еквіпотенціальною з потенціалом `V = 0`.

2. **Силові лінії на поверхні (`r = R`):**
   Обчислимо тангенціальну та нормальну компоненти поля на поверхні циліндра:
   ```
   E_r = −∂V / ∂r = E₀ · (1 − (R² / r²)) · cos(θ)
   E_θ = −(1 / r) · (∂V / ∂θ) = −E₀ · (1 + (R² / r²)) · sin(θ)
   ```
   На поверхні `r = R`:
   ```
   E_r(R, θ) = E₀ · (1 − 1) · cos(θ) = 0
   E_θ(R, θ) = −2 · E₀ · sin(θ)
   ```

Оскільки радіальна складова `E_r` дорівнює нулю, поле на поверхні циліндра має лише нормальну (тангенціальну у сферичних координатах) складову `E_surf = 2·E₀·sin(θ)`. 

Максимальне значення напруженості досягається на полюсах циліндра (`θ = ±π/2`):

```
E_max = 2 · E₀
```

Це суворо доводить математичний факт: **внесення провідного циліндра у однорідне електричне поле точно подвоює локальну напруженість поля на його екваторіальних виступах**, згущуючи силові лінії у два рази.

## Крайові ефекти та крайова ємність напівбезконечного конденсатора

При проектуванні плоских конденсаторів та мікросмукових ліній передачі на друкованих платах поле між провідниками є однорідним лише далеко від країв. Біля краю пластини силові лінії вигинаються назовні, випинаючись у навколишній діелектрик, що утворює так зване **крайове поле** (*fringing field*).

Розглянемо крайовий ефект випинання силових ліній на краю плоского плоского конденсатора із пластинами на відстані `2h` одна від одної.

Для математичного розрахунку геометрії випинання силових ліній застосовують конформне відображення Шварца — Крістоффеля, яке переводить прямокутну область між пластинами у верхню півплощину допоміжної комплексної змінної `w`. Інтеграл Шварца — Крістоффеля в даній геометрії зводиться до відображення:

```
z = (h / π) · (w + 1 + e^w)
```

де `w = U + i·V` — комплексний потенціал.

Еквіпотенціалі утворюють родину вигнутих дуг, що виходять із внутрішнього простору конденсатора назовні. Погонна крайова ємність `ΔC'`, яка описує додаткову ємність за рахунок випинання силових ліній у навколишній простір, виражається точним співвідношенням:

```
ΔC' = (ε₀ · ε_r / π) · (1 + ln(2 · π · d / h))
```

де `d` — глибина заходження пластини. Ця формула використовується у прецизійних розрахунках паразитної ємності країв мікросмукових ліній на друкованих платах. Крайове випинання силових ліній викликає ємнісні перехресні наводки (*crosstalk*) між сусідніми доріжками плати. Для зменшення цих наводок у високочастотній техніці між силовими доріжками прокладають захисні земляні провідники (*guard traces*), які «перехоплюють» випинаючі силові лінії та замикають їх на землю під прямим кутом `90°`.

## Чисельні методи конформного мапування та генерації сіток

У випадках, коли геометрія провідників та діелектриків є надзвичайно складною і не описується елементарними аналітичними функціями, конформні сітки будують чисельними методами. Для цього розв'язують обернену задачу граничних значень — систему двох зв'язаних рівнянь Лапласа для координат `x(V, U)` та `y(V, U)` у площині потенціалів. 

Оскільки перетворення є конформним, координати `x` та `y` у просторі `(V, U)` також задовольняють диференціальне рівняння Лапласа `∂²x/∂V² + ∂²x/∂U² = 0` та `∂²y/∂V² + ∂²y/∂U² = 0`. Чисельне розв'язання цієї системи сітковими методами (метод скінченних різниць або методом граничних елементів, BEM) автоматично генерує гладку ортогональну сітку криволінійних квадратів для довільних складних профілів електродів. Це дозволяє розраховувати ємності мікросмукових ліній та профілі високовольтних ізоляторів у сучасних CAD-системах автоматизованого проектування.
