# 🧮 Математична кінетика електронної лавини та порогові рівняння іонізації

Ця вставка містить строгий математичний вивід диференціальних рівнянь кінетики електронної лавини, першого коефіцієнта Таунсенда, порогової умови розгону гарячих електронів за критерієм Ґіппеля–Фреліха, квантового тунелювання Фаулера–Нордгейма та статистичного розподілу Вейбулла.

## 1. Диференціальне рівняння розмноження носіїв

Розглянемо суцільний шар діелектрика товщиною `d`, розташований між двома плоскими паралельними електродами. Нехай уздовж осі `x` прикріплено однорідне електричне поле напруженістю `E`. Початкова концентрація затравочних електронів поблизу катода (`x = 0`) дорівнює `n_0`.

Коли вільний електрон рухається у напрямку анода під дією електричного поля, імовірність здійснення ним акту ударної іонізації на одиниці шляху визначається першим коефіцієнтом іонізації Таунсенда `α`. Приріст кількості електронів `dn_e` на нескінченно малому проміжку `dx` є пропорційним поточному числу електронів `n_e(x)` та коефіцієнту `α`:

```
dn_e / dx = α(E) · n_e
```

Відокремлюючи змінні та інтегруючи від `x = 0` до `x`:

```
∫ (1 / n_e) dn_e = ∫ α(E) dx      [межі: від n_0 до n_e(x) та від 0 до x]
ln(n_e(x) / n_0) = α(E) · x
n_e(x) = n_0 · exp(α(E) · x)       [експоненційне зростання концентрації]
```

Загальне число електронів, що досягають анода на відстані `x = d`, визначає коефіцієнт лавинного підсилення `M`:

```
M = n_e(d) / n_0 = exp(α(E) · d)
```

Умова Таунсенда для самостійного лавинного розряду враховує також вторинну емісію електронів з катода під дією позитивних іонів (коефіцієнт `γ`). Кожен з `(n_e(d) - n_0)` утворених іонів, повертаючись до катода, вибиває в середньому `γ` нових електронів. Розряд стає самостійним, коли число вторинних електронів досягає одиниці:

```
γ · (n_e(d) - n_0) = n_0
γ · (exp(α(E) · d) - 1) = 1       [сувора умова самопідтримуваної лавини]
```

## 2. Фізичний вивід першого коефіцієнта іонізації Таунсенда

Ударна іонізація відбувається лише тоді, коли вільний електрон на довжині вільного пробігу `λ` набере від поля кінетичну енергію, яка перевищує порогову енергію іонізації `W_i` (для твердого діелектрика `W_i ≈ (1.5…2.0) · E_g` через закон збереження імпульсу):

```
e · E · λ ≥ W_i                   [поріг ударної іонізації]
λ ≥ W_i / (e · E)
```

Розподіл довжин вільного пробігу електронів між зіткненнями з атомами ґратки підпорядковується класичній статистиці Пуассона. Імовірність того, що електрон пролетить відстань не меншу за критичну `λ_cr = W_i / (e · E)` без пружних розсіювань, дорівнює:

```
P(λ ≥ λ_cr) = exp(-λ_cr / λ_mean)
P(λ ≥ λ_cr) = exp(-W_i / (e · E · λ_mean))
```

де `λ_mean` — середня довжина вільного пробігу електрона. Оскільки середня довжина вільного пробігу обернено пропорційна густині матеріалу або тиску газу `p` (`λ_mean = 1 / (B' · p)`), а загальне число зіткнень на одиниці шляху пропорційне тиску `p` (`1 / λ_mean = A · p`), отримуємо класичну формулу Таунсенда для коефіцієнта `α(E)`:

```
α(E) = A · p · exp(-B · p / E)
```

тут `A` та `B` — константи середовища:
* `A = 1 / (e · λ_mean · p)` — максимальний коефіцієнт іонізації при безмежно сильному полі;
* `B = W_i / (e · λ_mean · p)` — характеристична напруженість поля іонізації.

Для твердих діелектриків формулу зручно записувати без відношення до тиску через базовий коефіцієнт `α_0` та характеристичне поле `E_0`:

```
α(E) = α_0 · exp(-E_0 / E)
```

## 3. Енергетичний баланс Ґіппеля–Фреліха та порогове поле

У твердому діелектрику електрон провідності неперервно обмінюється енергією з кристалічною ґраткою через розсіювання на оптичних та акустичних фононах. Швидкість набуття енергії від електричного поля `P_gain` дорівнює добутку сили Поля на дрейфову швидкість `v_d`:

```
P_gain = e · E · v_d
v_d = μ(E) · E                     [де μ(E) — рухливість електрона]
P_gain = e · μ(E) · E²
```

З іншого боку, електрон втрачає енергію, випромінюючи поздовжні оптичні фонони з енергією `ħ · ω_LO`. Швидкість втрати енергії `P_loss` визначається часом релаксації імпульсу й енергії `τ_ph(W)`:

```
P_loss = (ħ · ω_LO) / τ_ph(W)
```

Співвідношення між `P_gain` та `P_loss` залежить від кінетичної енергії електрона `W`. У слабких полях для малих енергій `P_loss > P_gain`, тому середня енергія електронів залишається близькою до теплової `(3/2) · k_B · T`.

Проте при зростанні напруженості поля до критичного значення `E_cr` досягається точка, у якій при найнесприятливішій енергії розсіювання швидкість набору енергії стає строго більшою за максимальну швидкість релаксації на фононах:

```
P_gain(E_cr) ≥ max(P_loss)
e · μ · E_cr² ≥ (ħ · ω_LO) / τ_ph_min
E_cr = √((ħ · ω_LO) / (e · μ · τ_ph_min))
```

Коли `E > E_cr`, виникає явище **електронного розгону** (*electron runaway*): енергія електронів зростає безперервно, поки не досягне ширини забороненої зони `W_i ≈ E_g`. З цього моменту кожне зіткнення спричиняє ударну іонізацію, і концентрація носіїв наростає за законами лавинного розмноження.

## 4. Квантово-механічне тунелювання Фаулера–Нордгейма

Коли товщина діелектрика `d` зменшується до декількох нанометрів, тунелювання носіїв крізь потенціальний бар'єр випереджає лавинне множення. Розглянемо потенціальний бар'єр трикутної форми на межі `Метал-Діелектрик` з висотою `Ф_b` у полі напруженістю `E`.

Згідно з квазікласичним наближенням ВКБ (Вентцеля–Крамерса–Бріллюена), коефіцієнт прозорості бар'єра `D_bar` для електрона з енергією `W` визначається інтегралом:

```
D_bar = exp(-2/ħ · ∫ √(2 · m* · (V(x) - W)) dx)   [інтегрування від 0 до x_1]
```

Для трикутного бар'єра `V(x) = Ф_b - e · E · x` точка повороту дорівнює `x_1 = Ф_b / (e · E)`. Взявши інтеграл, отримуємо:

```
∫ √(Ф_b - e · E · x) dx = (2 / (3 · e · E)) · Ф_b^(3/2)
```

Підставляючи це значення у формулу ВКБ, отримуємо імовірність тунелювання:

```
D_bar = exp(-(4 · √(2 · m*) · Ф_b^(3/2)) / (3 · e · ħ · E))
```

Множачи імовірність тунелювання на частоту підходу електронів до стінки бар'єра, отримуємо суворе рівняння Фаулера–Нордгейма для густини тунельного струму `J_FN`:

```
J_FN = A_FN · E² · exp(-B_FN / E)
```

де константи Фаулера–Нордгейма дорівнюють:

```
A_FN = e³ / (16 · π² · ħ · Ф_b)
B_FN = (4 · √(2 · m*) · Ф_b^(3/2)) / (3 · e · ħ)
```

Логарифмуючи рівняння Фаулера–Нордгейма у координатах `ln(J_FN / E²)` проти `1 / E` (так званий графік Фаулера–Нордгейма), отримуємо пряму лінію, кут нахилу якої прямо міряє висоту потенціального бар'єра `Ф_b` на межі розділу матеріалів.

## 5. Статистичний розподіл Вейбулла для ймовірності пробою

Оскільки діелектричний пробій у реальних зразках є деструктивним статистичним процесом, викликаним наявністю найслабшої ланки (дефекту чи пори), кумулятивна імовірність руйнування ізолятора `P_f(E)` описується двопараметричним розподілом Вейбулла:

```
P_f(E) = 1 - exp(-(E / η)^β)
```

тут:
* `E` — прикладена напруженість електричного поля;
* `η` — масштабний параметр Вейбулла (значення поля, при якому імовірність пробою досягає `1 - exp(-1) ≈ 63.2%`);
* `β` — параметр форми Вейбулла, що характеризує однорідність матеріалу та розсіювання експериментальних даних.

Параметр форми `β` є ключовим індикатор якості діелектрика:
* При `β = 1…2` маємо велике розсіювання даних, зумовлене наявністю випадкових технологічних дефектів та домішок.
* При `β = 10…20` маємо високооднорідний матеріал, пробій якого визначається фундаментальними властивостями самої матриці діелектрика.

Щоб знайти параметри `η` та `β` з серії `N` експериментальних випробувань, кумулятивну формулу Вейбулла двічі логарифмують:

```
1 - P_f(E) = exp(-(E / η)^β)
ln(1 - P_f(E)) = -(E / η)^β
ln(-ln(1 - P_f(E))) = β · ln(E) - β · ln(η)
```

Побудувавши експериментальні точки у координатах `Y = ln(-ln(1 - P_f))` від `X = ln(E)`, отримуємо пряму лінію. Тангенс кута нахилу цієї прямої дорівнює параметру форми `β`, а точка перетину з віссю `Y = 0` визначає масштабний параметр `η`.
