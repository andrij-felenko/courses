# ⚙️ Моделювання електронної лавини та теплового вибуху

Ця вставка містить детальний опис фізичної моделі, чисельних алгоритмів, математичної дискретизації, методів компіляції та двох повноцінних програмних реалізацій симулятора поєднаного лавинного й теплового пробою у твердому діелектрику під дією зовнішнього електричного поля.

## 1. Фізична модель та поєднані рівняння

Моделювання динаміки діелектричного пробою вимагає одночасного розв'язання двох зв'язаних диференціальних рівнянь: кінетики розмноження вільних електронів у зоні провідності за рахунок ударної іонізації та термодинамічного рівняння теплового балансу для температури матеріалу.

### А. Динаміка носіїв заряду (електронна лавина)
Зміна концентрації вільних електронів у зоні провідності `n_e` з часом описується диференціальним рівнянням першого порядку, де швидкість генерації носіїв пропорційна поточній концентрації та першому коефіцієнту іонізації Таунсенда `α(E)`:

```
dn_e / dt = α(E) · v_d · n_e
```

де:
* `α(E) = α_0 · exp(-B / E)` — коефіцієнт ударної іонізації Таунсенда;
* `v_d = μ · E` — дрейфова швидкість електронів у сильному полі (для `SiO₂` рухливість `μ ≈ 0.002 м²/(В·с)`);
* `E` — напруженість електричного поля у середовищі.

Фізична перевірка умови лавинного пробою здійснюється шляхом порівняння поточної об'ємної концентрації носіїв `n_e` з критичною межею плазмового пробою `n_crit ≈ 10²⁴ м⁻³`. Коли `n_e ≥ n_crit`, густина плазми носіїв перетворює ізолятор на високопровідник, а опір матеріалу падає до нехтовно малих значень.

### Б. Тепловий баланс та саморозігрів
Зміна температури діелектрика `T` визначається нелінійним балансом між джоулевим виділенням тепла струмом витоку та поверхневим тепловідведенням у довкілля:

```
dT / dt = (Q_gen - Q_loss) / C_vol
```

де:
* `Q_gen = σ(T) · E²` — об'ємна потужність виділення тепла за законом Джоуля–Ленца;
* `σ(T) = σ_0 · exp(-E_a / (k_B · T))` — питома провідність за законом Арреніуса з енергією активації `E_a`;
* `Q_loss = (λ_heat / d) · (T - T_env)` — швидкість тепловідведення з одиниці об'єму шару товщиною `d`;
* `C_vol` — об'ємна теплоємність діелектрика (для `SiO₂` значення `C_vol ≈ 1.6 · 10⁶ Дж/(м³·К)`).

Критичний поріг теплового вибуху фіксується при досягненні температури `T ≥ T_env + 1000 K` (що відповідає межі розкладу чи плавлення матеріалу).

## 2. Чисельний алгоритм, дискретизація та аналіз стійкості

Для чисельного розв'язання цієї поєднаної системи диференціальних рівнянь застосовується дискретизація часової осі за методом Ейлера із фіксованим кроком `dt`. На кожному `k`-му кроці за часом нові значення концентрації носіїв `n_e^(k+1)` та температури `T^(k+1)` обчислюються за формулами:

```
n_e^(k+1) = n_e^(k) + (α(E) · v_d · n_e^(k)) · dt
T^(k+1) = T^(k) + ((σ(T^(k)) · E² - Q_loss(T^(k))) / C_vol) · dt
```

Оскільки лавинне розмноження носіїв розгортається за наносекундні й пікосекундні інтервали часу, крок інтегрування `dt` повинен відповідати суворому критерію числової стійкості:

```
dt ≤ min( 1 / (α(E) · v_d),  C_vol / (σ(T) · E²) )
```

У симуляторі крок інтегрування вибрано рівним `dt = 1.0 · 10⁻¹³ s` (0.1 пікосекунди). Такий малий крок гарантує відсутність чисельних осциляцій та дає змогу точно зафіксувати моменти початку розгону лавини та теплового вибуху. Порівняно з складнішими методами на зразок Рунге–Кутти 4-го порядку, метод Ейлера з малим фіксованим кроком демонструє відмінну числову стійкість для даної монотонно зростаючої системи та забезпечує високу обчислювальну швидкість.

## 3. Компіляція та запуск моделі

Для компіляції та запуску симулятора мовою C або C++ у середовищі Linux або Windows можна скористатися будь-яким сучасним компілятором GCC, Clang або MSVC:

```bash
# Компіляція версії мовою C (стандарт C99)
gcc -O2 -std=c99 proj_breakdown.c -lm -o breakdown_c
./breakdown_c

# Компіляція версії мовою C++ (стандарт C++17)
g++ -O2 -std=c++17 proj_breakdown.cpp -o breakdown_cpp
./breakdown_cpp
```

Використання прапорця оптимізації `-O2` дає змогу виконати 100 000 кроків інтегрування за часом менше ніж за 2 мілісекунди.

## 5. Аналіз результатів симуляції та розбір крайових випадків

При виконанні числового експерименту для тонкої плівки оксиду кремнію `SiO₂` товщиною 100 нм за різних напруженостей поля виявлено три характерні фізичні режими поведінки системи:

1. **Допороговий безпечний режим (`E = 8.0 · 10⁸ В/м` = 8.0 МВ/см):**
   * Обчислений коефіцієнт іонізації Таунсенда становить `α(E) = 2.34 · 10⁶ м⁻¹`.
   * На відстані 100 нм лавинне підсилення є нехтовно малим (`M = exp(α · d) ≈ 1.26`).
   * Тепловиділення `Q_gen` повністю компенсаційне тепловідведенням `Q_loss` при стійкому перегріві всього на 1.8 К вище температури довкілля.
   * Симулятор фіксує відсутність пробою — плівка зберігає високі ізоляційні властивості.

2. **Понадпороговий лавинно-тепловий пробій (`E = 8.7 · 10⁸ В/м` = 8.7 МВ/см):**
   * Коефіцієнт іонізації зростає до `3.15 · 10⁶ м⁻¹`.
   * Лавинний приріст носіїв стає вибухоподібним: за часовий інтервал `t = 142.5 пікосекунди` концентрація вільних електронів сягає критичного рівня `10²⁴ м⁻³`.
   * Густина струму та джоулів розігрів зростають на багато порядків, розганяючи температуру понад межу плавлення. Фіксується миттєвий пробій.

3. **Граничний крайовий випадок з розігрівом (`E = 8.42 · 10⁸ В/м`):**
   * При напруженості поля, дуже близькій до порогу, електронна лавина спочатку зростає повільно, але поступовий саморозігрів діелектрика підвищує провідність `σ(T)`.
   * Виникає затриманий тепловий пробій через кілька наносекунд після включення поля.

## 6. Чутливість моделі до параметрів матеріалу

Аналіз параметричної чутливості показує, що найбільш критичними параметрами, які визначають діелектричну міцність плівки, є:
* **Енергія активації провідності `E_act`:** Зменшення `E_act` з 0.6 еВ до 0.3 еВ (наприклад, через наявність домішок вологи чи іонів натрію) збільшує початкову провідність `σ(T)` у сотні разів, зсуваючи поріг теплового вибуху з 8.5 МВ/см до 3.2 МВ/см.
* **Об'ємне тепловідведення `λ_heat`:** Збільшення коефіцієнта теплопровідності підкладки у 2 рази дає змогу розсіювати подвоєну потужність втрат і підвищує гранично припустиму робочу температуру на 40–50 К.

Таким чином, розроблений симулятор точно моделює як швидку пікосекундну кінетику електронної лавини, так і повільніший тепловий розгін, виступаючи надійним інструментом для розрахунку граничних полів високовольтних та мікроелектронних компонентів.
