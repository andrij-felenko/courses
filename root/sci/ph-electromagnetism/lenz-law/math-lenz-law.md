# 🧮 Математичний вивід та збереження енергії

Математичне формулювання правила Ленца виражається знаком «мінус» у законі електромагнітної індукції Фарадея. Цей мінус не є випадковим вибором орієнтації координатної системи — він суворо випливає з закону збереження енергії та фундаментальних рівнянь електродинаміки. При зміні знак на протилежний математична модель описує фізично неможливу систему з нескінченним генератором енергії. 

Нижче наведено кроки математичного виведення цього зв'язку як на макроскопічному рівні (механічна робота й джоулеве тепло), так і на мікроскопічному рівні (сила Лоренца та рівняння Максвелла).

## 1. Геометрія магнітного потоку та вибір орієнтації контуру

Розглянемо замкнений провідний контур площею `S`, розміщений у магнітному полі з індукцією `B`. Магнітний потік `Φ` через поверхню `S` визначається поверхневим інтегралом другого роду від вектора магнітної індукції:

```
Φ = ∫ B · n dA
```

де:
- `dA` — диференціальний елемент площі поверхні, обмеженої контуром;
- `n` — одиничний вектор нормалі до поверхні `S`.

Орієнтація вектору нормалі `n` пов'язана з напрямком обходу контуру `dl` за правилом правого гвинта: якщо пальці правої руки вказують обраний додатний напрямок обходу контуру, то відігнутий великий палець вказує напрямок нормалі `n`.

Закон електромагнітної індукції Фарадея зв'язує індуковану електрорушійну силу (ЕРС) `E_i` зі швидкістю зміни магнітного потоку `dΦ/dt`:

```
E_i = - dΦ/dt      [закон Фарадея — Ленца]
```

Знак мінус вказує на геометрію протидії: якщо магнітний потік зростає (`dΦ/dt > 0`), індукована ЕРС від'ємна (`E_i < 0`), тобто створює струм, напрямлений **проти** обраного додатного напрямку обходу контуру. Цей струм утворює власне магнітне поле, вектор індукції якого спрямований проти зовнішнього магнітного поля, що зменшує сумарний потік.

## 2. Строгий вивід зі збереження енергії для прямокутного контуру

Щоб математично довести необхідність знака мінус, розглянемо модель прямокутного провідного контуру шириною `L` та довжиною `w`, що рухається у площині `xy` зі швидкістю `v` убік однорідного магнітного поля `B`, перпендикулярного до площини контуру.

```
+------------------+------------------+
|  Поле відсутнє   |     Поле B       |
|                  |   (від нас)      |
|                  |                  |
|        +---------+---------+        |
|        |         |  сторона|        |
|        |         |    L    |        |  --> v (рух праворуч)
|        +---------+---------+        |
|                  |                  |
+------------------+------------------+
```

Нехай у момент часу `t` у зоні магнітного поля знаходиться ділянка контуру довжиною `x`. Тоді площа контуру у зоні поля дорівнює `S = L · x`, а магнітний потік через контур становить:

```
Φ(t) = B · L · x(t)
```

Диференціюючи по часу, отримуємо швидкість зміни магнітного потоку, яка прямо пропорційна швидкості руху контуру `v = dx/dt`:

```
dΦ/dt = B · L · (dx/dt) = B · L · v
```

Тепер припустимо узагальнену математичну форму закону індукції зі невизначеним коефіцієнтом `k` (де `k` може дорівнювати `+1` або `-1`):

```
E_i = k · (dΦ/dt) = k · B · L · v
```

Якщо повний опір контуру дорівнює `R`, то за законом Ома для замкненого кола індукований струм дорівнює:

```
I = E_i / R = k · (B · L · v) / R
```

Цей індукований струм протікає через вертикальну сторону контуру довжиною `L`, яка знаходиться всередині магнітного поля. За законом Ампера на провідник зі струмом у магнітному полі діє сила Ампера `F_A`:

```
F_A = I · (L × B)
```

Оскільки вектор струму `I` у правій стороні рамки спрямований вздовж `L`, а поле `B` перпендикулярне до площини, модуль сили Ампера дорівнює:

```
|F_A| = |I| · L · B = |k| · (B² · L² · v) / R
```

Визначимо векторний напрямок сили Ампера відносно вектора швидкості `v`:

```
F_A = k · (B² · L² / R) · v
```

Тепер обчислимо механічну потужність `P_мех`, яку повинна виконувати зовнішня сила `F_зовн` для підтримки сталого руху контуру зі швидкістю `v` без прискорення:

```
F_зовн = - F_A = - k · (B² · L² / R) · v

P_мех = F_зовн · v = - k · (B² · L² · v²) / R
```

З іншого боку, обчислимо електричну потужність `P_електр`, яка виділяється у контурі у вигляді джоулевого тепла на опорі `R`:

```
P_електр = I² · R = (k · B · L · v / R)² · R = (B² · L² · v²) / R
```

За фундаментальним законом збереження енергії механічна потужність, яка вводиться в систему зовнішньою силою, повинна точно дорівнювати виділеній тепловій потужності (`P_мех = P_електр`):

```
- k · (B² · L² · v²) / R = (B² · L² · v²) / R
```

Оскільки величина `(B² · L² · v²) / R` є строго додатною при `v ≠ 0`, скорочуємо її з обох боків рівняння і отримуємо єдино можливе значення для коефіцієнта `k`:

```
- k = 1  ==>  k = -1
```

Математичне виведення доведено строго: **знак мінус у законі електромагнітної індукції є необхідним і єдиним математичним наслідком виконання закону збереження енергії**.

## 3. Диференціальна форма та рівняння Максвелла

У польовому формулюванні Максвелла правило Ленца відображене у другому рівнянні Максвелла (диференціальній формі закону індукції Фарадея):

```
∇ × E = - ∂B/∂t      [рівняння Максвелла — Фарадея]
```

Застосовуючи математичну теорему Стокса до довільної замкненої кривої `C`, що обмежує поверхню `S`:

```
∫_C E · dl = ∫_S (∇ × E) · n dA = - ∫_S (∂B/∂t) · n dA
```

Оскільки ліва частина являє собою циркуляцію векторного електричного поля (тобто індуковану ЕРС `E_i`), а права частина — мінус часткова похідна від магнітного потоку по часу, ми отримуємо інтегральну форму закону Фарадея:

```
E_i = - dΦ/dt
```

Знак мінус гарантує, що ротор індукованого вихрового електричного поля `∇ × E` орієнтований протилежно до вектора часової похідної магнітної індукції `∂B/∂t`. Це означає, що вихрове електричне поле прискорює заряди у такому напрямку, щоб їхнє власне магнітне поле протидіяло змінам вихідного поля `B`.

## 4. Математичний аналіз катастрофи при хибному знаку (k = +1)

Щоб остаточно оцінити роль знака Ленца, проведемо математичний аналіз дифрівняння руху вільного провідного контуру масою `m` у випадку гіпотетичного світу зі знаком `k = +1` (`E_i = + dΦ/dt`).

Рівняння руху контуру за відсутності зовнішніх механічних сил за другим законом Ньютона мало б вигляд:

```
m · (dv/dt) = F_A = + (B² · L² / R) · v
```

Це лінійне однорідне диференціальне рівняння першого порядку з постійними коефіцієнтами:

```
dv/dt - (B² · L² / (m · R)) · v = 0
```

Загальний розв'язок цього диференціального рівняння для початкової швидкості `v(0) = v_0`:

```
v(t) = v_0 · exp(+ t / τ)
```

де характеристичний час системи `τ = (m · R) / (B² · L²)`.

Цей розв'язок описує **необмежене експоненційне самоприскорення**: найменший початковий поштовх викликає зростання швидкості контуру до нескінченності. Кінетична енергія контуру `E_k(t) = 0.5 · m · v_0² · exp(2t / τ)` виникає з нічого.

Тільки реальний знак мінус (`k = -1`) дає стійке фізичне диференціальне рівняння з від'ємним власним значенням:

```
dv/dt + (1 / τ) · v = 0  ==>  v(t) = v_0 · exp(- t / τ)     [реальне гальмування Ленца]
```

Траєкторія `v(t) = v_0 · exp(- t / τ)` описує асимптотичне сповільнення, при якому повна інтегральна робота сил гальмування `∫₀^∞ F_A · v dt` точно дорівнює початковій кінетичній енергії `0.5 · m · v_0²`. Таким чином, знак Ленца є математичною основою динамічної стійкості фізичних систем.
