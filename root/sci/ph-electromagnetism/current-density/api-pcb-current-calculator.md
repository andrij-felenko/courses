# 📋 Розрахунок струмового навантаження доріжок друкованих плат за IPC-2221

Цей довідник містить формули, таблиці струмового навантаження, допустимі граничні значення щільності струму `J_max`, інженерні коефіцієнти розрахунку перегріву, правила витискування теплових отворів, високовольтні зазори, правила дерайтингу та інтерфейси програмування (API) для автоматизації проектування друкованих плат відповідно до стандарту IPC-2221.

## 1. Розрахункові формули та фізика стандарту IPC-2221

Стандарт IPC-2221 (Generic Standard on Printed Board Design) розроблено Міжнародною асоціацією електронної промисловості (IPC) на основі великої серії експериментальних вимірювань тепловиділення на друкованих платах із склотекстоліту FR-4.

Основне завдання стандарту — обчислити максимально допустимий постійний (або низькочастотний) струм `I` [А] для прямокутної мідної доріжки залежно від її площі поперечного перерізу `A` [мил²] та допустимого підвищення температури `ΔT` [°C] над температурою навколишнього середовища.

Емпірична формула IPC-2221 має вигляд:

```
I = k · ΔT^0.44 · A^0.725
```

де:
- `I` — допустимий струм навантаження [А];
- `ΔT` — допустимий перегрів доріжки [°C] над температурою оточуючого середовища (типові інженерні норми `ΔT = 10 °C`, `20 °C` або `30 °C`);
- `A` — площа поперечного перерізу мідної доріжки в квадратних милах (`mil²`, де `1 mil = 0.0254 мм`, `1 mil² = 6.4516 · 10⁻⁴ мм²`);
- `k` — емпіричний коефіцієнт тепловідведення, що враховує умови конвекції та теплопровідності:
  - `k = 0.048` — для **зовнішніх** (поверхневих) шарів (Top / Bottom), де тепло вільно розсіюється у повітря конвекцією та випромінюванням;
  - `k = 0.024` — для **внутрішніх** шарів (Internal Layers), які затиснуті у диелектрику FR-4 із низькою теплопровідністю (`k_th ≈ 0.25` Вт/(м·К)).

Для визначення необхідної площі перерізу `A` [mil²] при відомому робочому струмі `I` формула інвертується:

```
A = [ I / ( k · ΔT^0.44 ) ]^( 1 / 0.725 )    [mil²]
```

Оскільки площа перерізу прямокутної доріжки дорівнює добутку її ширини `W` на товщину мідної фольги `h` (`A = W · h`), необхідна ширина доріжки `W` [мм] обчислюється як:

```
W = ( A / ( h / 0.0254 ) ) · 0.0254            [мм]
```

Стандартні маси міді на квадратний фут та відповідні товщини фольгування у виробництві друкованих плат:
- `0.5 oz/ft²` ≈ `17.5 мкм` (`0.689 mil`) — тонка фольга для високощільних цифрових плат;
- `1.0 oz/ft²` ≈ `35.0 мкм` (`1.378 mil`) — стандартна фольга для більшості аналого-цифрових плат;
- `2.0 oz/ft²` ≈ `70.0 мкм` (`2.756 mil`) — силова фольга для перетворювачів живлення та драйверів двигунів;
- `3.0 oz/ft²` ≈ `105.0 мкм` (`4.134 mil`) — важка силова мідь (Heavy Copper) для промислової електроніки.

При проектуванні важливо враховувати технологічний допуск на витравлювання доріжок та зменшення товщини міді при гальванічній обробці. Зазвичай реальна товщина міді на стінках і поверхні після травлення може бути на 10–15% меншою за номінальну товщину фольги. Для відповідальних силових застосувань розрахунковий струм множать на технологічний коефіцієнт запасу `k_mfg = 0.85`.

У сучасній електроніці для нових проектів також використовують оновлений стандарт IPC-2152 (Standard for Determining Current Carrying Capacity in Printed Board Design). На відміну від IPC-2221, IPC-2152 враховує масу плати, наявність суцільних внутрішніх заземлювальних полігонів (які діють як додаткові тепловодні радіатори) та відстань до сусідніх гарячих компонентів. Наявність суцільного мідного полігону під силовою доріжкою збільшує її допустимий струм на 20–40% за рахунок ефективного розсіювання тепла углиб диелектрика.

| **Друковані плати (PCB Inner, 1 oz мідь, ΔT=10°C)** | `15 ... 25 А/мм²` (`1.5·10⁷ ... 2.5·10⁷ А/м²`) | Брак конвекції всередині диелектрика FR-4 |

| **Надпровідникові магніти (NbTi, 4.2 K)** | `10³ ... 10⁵ А/мм²` (`10⁹ ... 10¹¹ А/м²`) | Критичне магнітне поле B_c2 |

## 4. Розрахунок перехідних отворів (Via Thermal & Current Capacity)

Перехідний отвір (Via) є циліндричною трубкою з мідним покриттям на внутрішніх стінках свердління. Товщина електролітичної металізації стінок зазвичай становить `h_plated ≈ 18 ... 25` мкм (0.7–1.0 mil).

Площа поперечного перерізу міді у циліндричному перехідному отворі з зовнішнім діаметром свердління `D_via` та товщиною стінки `h_plated` обчислюється за формулою кільця:

```
A_via = π · ( D_via · h_plated - h_plated² )
```

Для стандартного силового перехідного отвору `D_via = 0.3` мм з товщиною металізації `h_plated = 20` мкм:
`A_via = π · ( 0.3 · 0.02 - 0.02² ) ≈ 0.0176` мм² (що за струмовим навантаженням відповідає зовнішній доріжці шириною близько `0.5` мм).

При проектуванні високострумових ліній живлення виключно важливим є використання масивів паралельних перехідних отворів (Via Arrays). Кількість отворів `N_vias` обчислюється як:

```
N_vias = ceil( I_total / I_via_max )
```

де `I_via_max` вибирається з розрахунку не більше `1.2 ... 1.5` А на один отвір `0.3` мм для запобігання термічному відшаруванню мідної стінки від текстоліту та розриву міжрівневого контакту.

## 5. Вплив високої частоти та дерайтинг за скіновим ефектом

При імпульсних струмах або високочастотних сигналах ефективна площа перерізу доріжки `A_eff` зменшується через виштовхування струму до зовнішньої поверхні. Якщо глибина скінового шару `δ = √( ρ_e / (π · f · μ) )` виявляється меншою за півтовщини мідної фольги `h / 2`, розрахунковий струм за IPC-2221 слід множити на високочастотний дерайтинг-коефіцієнт `k_f`:

```
k_f = √( 2 · δ / h )    [при δ < h / 2]
```

Для уникнення перевищення допустимої щільності струму `J_max` на високих частотах використовують широкі полігони замість вузьких доріжок або застосовують багатошарове паралельне трасування.

## 6. Тепловий дерайтинг у герметичних корпусах та на висоті

При роботі електроніки у герметичних невентильованих корпусах або при експлуатації на великій висоті (авіоніка, космічні апарати) естественне конвекційне охолодження повітрям різко ослабляється через розрідження атмосфери.

У цих умовах розрахований допустимий струм за формулою IPC-2221 необхідно множити на коефіцієнт висотного та корпусного дерайтингу `k_env`:
- **Герметичний корпус без обдуву (Still Air):** `k_env = 0.70 ... 0.80`;
- **Висота 10 000 м (авіоніка):** `k_env = 0.60 ... 0.70`;
- **Вакуум (космічна електроніка):** `k_env = 0.40 ... 0.50` (охолодження відбувається виключно кондукцією через корпус та випромінюванням).

Також, якщо друкована плата покрита товстим шаром конформного захисного лаку (Conformal Coating) або заповнена компаундом (Potting), коефіцієнт теплопровідності змінюється, що вимагає коригування допустимого перегріву `ΔT`.

## 7. Високовольтні зазори IPC-2221 (Clearance & Creepage)

Окрім щільності струму у провіднику, стандарт IPC-2221 визначає мінімальні безпечні ізоляційні відстані між сусідніми доріжками для запобігання поверхневому пробою діелектрика та коронованню.

| Робоча напруга (DC або AC peak) | Повітряний зазов (Clearance, непокрито) | Поверхневий зазор (Creepage, під маскою) |
| :---: | :---: | :---: |
| `0 ... 15 В` | `0.10 мм` | `0.05 мм` |
| `16 ... 30 В` | `0.10 мм` | `0.05 мм` |
| `31 ... 50 В` | `0.60 мм` | `0.13 мм` |
| `51 ... 100 В` | `0.60 мм` | `0.13 мм` |
| `101 ... 150 В` | `0.60 мм` | `0.25 мм` |
| `151 ... 300 В` | `1.50 мм` | `0.40 мм` |
| `301 ... 500 В` | `2.50 мм` | `0.80 мм` |

## 8. Специфікація параметрів C/C++ API для розрахунку

Для автоматизованого проектування плати та впровадження автоматичних перевірок правил проектування (DRC) у розрахункових модулях використовуються наступні типи даних та функціональні інтерфейси.

```cpp
#ifndef PCB_CURRENT_CALCULATOR_HPP
#define PCB_CURRENT_CALCULATOR_HPP

#include <cmath>
#include <stdexcept>
#include <string>

namespace pcb::design {

enum class LayerLocation {
    Outer, // Зовнішній шар (k = 0.048)
    Inner  // Внутрішній шар (k = 0.024)
};

struct TraceDesignInput {
    double target_current_a{1.0};       // Струм навантаження [А]
    double allowed_temp_rise_c{10.0};   // Допустимий перегрів ΔT [°C]
    double copper_thickness_um{35.0};   // Товщина мідної фольги [мкм]
    LayerLocation layer{LayerLocation::Outer}; // Тип шару
};

struct TraceDesignOutput {
    double min_width_mm{0.0};           // Мінімально допустима ширина доріжки [мм]
    double cross_section_mm2{0.0};      // Площа поперечного перерізу [мм²]
    double current_density_a_mm2{0.0};  // Ефективна щільність струму J [А/мм²]
    double trace_resistance_ohm_m{0.0}; // Опір на один метр довжини [Ом/м]
    double power_loss_w_m{0.0};         // Теплові втрати на метр довжини [Вт/м]
};

class PcbCurrentCalculator {
public:
    static constexpr double COPPER_RESISTIVITY_20C = 1.724e-8; // Ом·м (питомий опір міді)
    static constexpr double COPPER_TEMP_COEFF = 0.00393;       // 1/°C (ТКО міді)

    static TraceDesignOutput calculate_trace_width(const TraceDesignInput& input) {
        if (input.target_current_a <= 0.0) {
            throw std::invalid_argument("Струм повинен бути більшим за нуль.");
        }
        if (input.allowed_temp_rise_c <= 0.0) {
            throw std::invalid_argument("Перегрів повинен бути більшим за нуль.");
        }

        const double k = (input.layer == LayerLocation::Outer) ? 0.048 : 0.024;
        
        // Розрахунок площі A у mil² за формулою IPC-2221
        const double temp_factor = std::pow(input.allowed_temp_rise_c, 0.44);
        const double area_mil2 = std::pow(input.target_current_a / (k * temp_factor), 1.0 / 0.725);

        // Переведення площі у мм² (1 mil² = 6.4516e-4 мм²)
        const double area_mm2 = area_mil2 * 6.4516e-4;

        // Товщина міді у мм
        const double thickness_mm = input.copper_thickness_um / 1000.0;
        const double width_mm = area_mm2 / thickness_mm;

        // Ефективна щільність струму J
        const double density_a_mm2 = input.target_current_a / area_mm2;

        // Опір з урахуванням температури (20 °C + ΔT)
        const double temp_c = 20.0 + input.allowed_temp_rise_c;
        const double rho_actual = COPPER_RESISTIVITY_20C * (1.0 + COPPER_TEMP_COEFF * (temp_c - 20.0));
        const double resistance_per_m = rho_actual / (area_mm2 * 1e-6);

        // Теплова потужність втрат P = I² · R
        const double power_loss_per_m = std::pow(input.target_current_a, 2) * resistance_per_m;

        return TraceDesignOutput{
            width_mm,
            area_mm2,
            density_a_mm2,
            resistance_per_m,
            power_loss_per_m
        };
    }
};

} // namespace pcb::design

#endif // PCB_CURRENT_CALCULATOR_HPP
```

Даний API дозволяє вбудовувати автоматичний розрахунок допустимих доріжок та щільності струму `J` у будь-які CAD/EDA системи та скрипти перевірки топології друкованих плат.
