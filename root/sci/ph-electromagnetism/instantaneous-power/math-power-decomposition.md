# 🧮 Виведення розкладу миттєвої потужності та сталість у трифазній мережі

Математичний опис миттєвої потужності в колах змінного струму спирається на тригонометричні перетворення, комплексно-векторний аналіз та матричні перетворення координат. Головна мета цього матеріалу — строго вивести розклад миттєвої потужності на активну й реактивну складові у часовій області, довести геометричний зв'язок у трикутнику потужностей через комплексно-спряжений фазор, розглянути розклад через векторну проєкцію струму, а також математично обґрунтувати фундаментальну властивість симетричних трифазних систем — строгу сталість сумарної миттєвої потужності в часі, її розбаланс у несиметричних режимах та математику гармонійного спотворення.

---

### 1. Тригонометричний розклад миттєвої потужності для однофазного кола

Розглянемо лінійний двополюсник (електричне навантаження), підключений до джерела однофазного синусоїдального струму. Нехай миттєва напруга на клемах електричного навантаження змінюється за гармонічним законом із кутовою частотою `ω`:

```
v(t) = Vₘ · cos(ωt)
```

де `Vₘ` — пікова амплітуда напруги (у вольтах), а `ω = 2πf` — кутова частота мережі (рад/с). Якщо навантаження містить індуктивний або ємнісний реактивний елемент, миттєвий струм `i(t)` матиме ту саму частоту, але відставатиме або випереджатиме напругу на кут зсуву фаз `φ`:

```
i(t) = Iₘ · cos(ωt − φ)
```

де `Iₘ` — пікова амплітуда струму (в амперах), а `φ` — кут зсуву фаз між напругою та струмом (за загальноприйнятою угодою для індуктивного навантаження струм відстає від напруги, тож `φ > 0`, для ємнісного навантаження струм випереджає напругу, тож `φ < 0`).

Миттєва потужність `p(t)` за фізичним означенням виражає швидкість передачі електричної енергії в кожний розщеплений момент часу `t` і дорівнює добутку миттєвих значень напруги та струму:

```
p(t) = v(t) · i(t)                                    [за фіз. означенням потужності]
= V☵ · cos(ωt) · I☵ · cos(ωt − φ)                      [підстановка виразів v(t) та i(t)]
= V☵ · I☵ · cos(ωt) · cos(ωt − φ)                       [перегрупування скалярних множників]
```

Щоб розплутати добуток двох змінних тригонометричних функцій, застосуємо фундаментальну тотожність для добутку двох косинусів `cos A · cos B = (1/2) · [cos(A − B) + cos(A + B)]`. У нашому випадку підставимо значення аргументів `A = ωt` та `B = ωt − φ`:

```
A − B = ωt − (ωt − φ) = φ
A + B = ωt + (ωt − φ) = 2ωt − φ
```

Завдяки цьому тригонометричному перетворенню добуток двох хвиль із частотою `ω` розпадається на суму двох доданків — одного сталого відносно часу та одного пульсуючого з подвоєною частотою `2ω`:

```
p(t) = Vₘ·Iₘ · (1/2) · [cos(φ) + cos(2ωt − φ)]
= (Vₘ·I☵ / 2) · cos(φ) + (V☵·I☵ / 2) · cos(2ωt − φ)          [розкриття дужок]
```

Згадаємо фундаментальний зв'язок між амплітудними значеннями `Vₘ, Iₘ` та діючими (середньоквадратичними, RMS) значеннями синусоїди: `Vᵣₘ⛛ = V☵ / √2` та `Iᵣₘ⛛ = I☵ / √2`. Добуток амплітуд, поділений навпіл, дорівнює добутку діючих значень:

```
(V☵ · I☵) / 2 = (V☵ / √2) · (I☵ / √2) = Vᵣₘ⛛ · Iᵣₘ⛛
```

Перепишемо вираз для миттєвої потужності через RMS-значення:

```
p(t) = Vᵣₘ⛛ · Iᵣₘ⛛ · cos(φ) + Vᵣₘ⛛ · Iᵣₘ⛛ · cos(2ωt − φ)
```

Тепер розкриємо другий доданок `cos(2ωt − φ)` за тригонометричною формулою косинуса різниці двох кутів `cos(X − Y) = cos X · cos Y + sin X · sin Y`, де `X = 2ωt`, `Y = φ`:

```
cos(2ωt − φ) = cos(2ωt) · cos(φ) + sin(2ωt) · sin(φ)
```

Підставимо цей розклад назад у підсумкове рівняння для `p(t)`:

```
p(t) = Vᵣₘ⛛·Iᵣₘ⛛·cos(φ) + Vᵣₘ⛛·Iᵣₘ⛛ · [cos(2ωt)·cos(φ) + sin(2ωt)·sin(φ)]
= Vᵣₘ⛛·Iᵣₘ⛛·cos(φ) + Vᵣₘ⛛·Iᵣₘ⛛·cos(φ)·cos(2ωt) + Vᵣₘ⛛·Iᵣₘ⛛·sin(φ)·sin(2ωt)
```

Винесемо в перших двох доданочках спільний множник `Vᵣₘ⛛·Iᵣₘ⛛·cos(φ)` за дужки:

```
p(t) = Vᵣₘ⛛·Iᵣₘ⛛·cos(φ) · [1 + cos(2ωt)] + Vᵣₘ⛛·Iᵣₘ⛛·sin(φ) · sin(2ωt)
```

Введемо класичні електротехнічні визначення **активної потужності `P`** та **реактивної потужності `Q`**:

```
P = Vᵣₘ⛛ · Iᵣₘ⛛ · cos(φ)        [Активна потужність, вимірюється у Ватах, Вт]
Q = Vᵣₘ⛛ · Iᵣₘ⛛ · sin(φ)        [Реактивна потужність, вимірюється у варах, вар]
```

Завдяки цьому ми отримуємо канонічний розклад миттєвої потужності `p(t)` на дві ортогональні часові складові — активну миттєву складову `pₐ(t)` та реактивну миттєву складову `pᵦ(t)`:

```
p(t) = pₐ(t) + pᵦ(t)
= P · [1 + cos(2ωt)] + Q · sin(2ωt)
```

#### Глибокий аналіз фізичної суті двох складових:

1. **Активна миттєва складова `pₐ(t) = P · [1 + cos(2ωt)]`**:
   - Оскільки косинус упевнено обмежений у межах `−1 ≤ cos(2ωt) ≤ 1`, величина у квадратних дужках `[1 + cos(2ωt)]` змінюється у діапазоні від `0` до `2` і **ніколи не стає від'ємною**.
   - Це означає, що `pₐ(t) ≥ 0` у будь-який момент часу `t`. Напрямок передачі енергії цієї складової завжди один і той самий: від джерела до навантаження.
   - Середнє значення функції `cos(2ωt)` за період `T = 2π/ω` дорівнює нулю (`(1/T) ∫ cos(2ωt) dt = 0`). Тому середня потужність активної складової дорівнює точно `P`.
   - Саме ця складова описує незворотний процес перетворення електричної енергії на інші види корисної роботи: нагрівання елемента ТЕНу, випромінювання світла або механічне обертання вала двигуна.

2. **Реактивна миттєва складова `pᵦ(t) = Q · sin(2ωt)`**:
   - Являє собою чисто синусоїдальні коливання з амплітудою `Q` на подвоєній частоті `2ω`.
   - Середнє значення цієї складової за період дорівнює нулю: `(1/T) ∫ Q·sin(2ωt) dt = 0`.
   - Фізичний зміст: протягом однієї чверті періоду напруги, коли `pᵦ(t) > 0`, джерело віддає енергію на створення магнітного поля котушки або електричного поля конденсатора. Протягом наступної чверті періоду, коли `pᵦ(t) < 0`, накопичена у полі енергія повністю повертається назад у джерело.
   - Реактивна складова не виконує жодної корисної роботи в середньому за період, але вона змушує додатковий струм протікати крізь генератор, трансформатори та дроти лінії електропередачі, створюючи додаткові втрати на нагрівання провідників `I²·R`.

### 2. Альтернативне виведення через векторну проєкцію струму (метод Фризе)

Існує інший, дуже наочний спосіб отримати той самий розклад, який запропонував польський електротехнік Станіслав Фризе. Замість тригонометричного перетворення добутку двох хвиль розкладемо сам миттєвий струм `i(t)` на две ортогональні складові — активний струм `iₐ(t)` та реактивний струм `iᵦ(t)`.

Представимо струм `i(t) = I☵ · cos(ωt − φ)` за формулою косинуса різниці:

```
i(t) = I☵ · cos(ωt) · cos(φ) + I☵ · sin(ωt) · sin(φ)
```

Позначимо першу складову як активну складову струму `iₐ(t)`, а другу — як реактивну складову струму `iᵦ(t)`:

```
iₐ(t) = [I☵ · cos(φ)] · cos(ωt)
iᵦ(t) = [I☵ · sin(φ)] · sin(ωt)
```

Зверніть увагу: активний струм `iₐ(t)` за фазовою формою точно збігається з напругою `v(t) = V☵ · cos(ωt)`, а реактивний струм `iᵦ(t)` зсунутий відносно напруги на `90°` (оскільки `sin(ωt) = cos(ωt − π/2)`).

Перемножимо обидві складові струму окремо на миттєву напругу `v(t) = V☵ · cos(ωt)`:

```
pₐ(t) = v(t) · iₐ(t) = V☵ · cos(ωt) · [I☵ · cos(φ)] · cos(ωt)
= V☵ · I☵ · cos(φ) · cos²(ωt)
```

Застосувавши формулу пониження степеня `cos²(θ) = (1 + cos(2θ)) / 2`, отримуємо:

```
pₐ(t) = [ (V☵ · I☵) / 2 ] · cos(φ) · [1 + cos(2ωt)]
= P · [1 + cos(2ωt)]
```

Аналогічно обчислимо миттєву потужність реактивного струму:

```
pᵦ(t) = v(t) · iᵦ(t) = V☵ · cos(ωt) · [I☵ · sin(φ)] · sin(ωt)
= V☵ · I☵ · sin(φ) · [cos(ωt) · sin(ωt)]
```

Застосувавши тотожність подвійного кута `cos(θ) · sin(θ) = sin(2θ) / 2`, отримуємо:

```
pᵦ(t) = [ (V☵ · I☵) / 2 ] · sin(φ) · sin(2ωt)
= Q · sin(2ωt)
```

Цей метод виведення чітко демонструє: активна потужність виникає суто від тієї частини струму, яка перебуває у фазі з напругою, а реактивна потужність — від тієї частини струму, яка перебуває в квадратурі (під 90°) до напруги.

### 3. Накопичення енергії у реактивних елементах та зв'язок із величиною Q

Корисно проаналізувати граничні випадки чисто реактивних елементів, де опір `R = 0`.

#### Чисто індуктивне навантаження (котушка індуктивності L)

Для чистої котушки індуктивності струм відстає від напруги точно на `φ = 90°` (`cos 90° = 0`, `sin 90° = 1`). Активна потужність `P = 0`, а реактивна потужність досягає максимуму `Q = Vᵣₘ⛛ · Iᵣₘ⛛ = Vᵣₘ⛛² / (ωL) = Iᵣₘ⛛² · ωL`.

Миттєва потужність котушки дорівнює:

```
p_L(t) = Q · sin(2ωt) = Iᵣₘ⛛² · ωL · sin(2ωt)
```

Обчислимо миттєву енергію `W_L(t)`, яка зберігається в магнітному полі котушки в момент часу `t`:

```
W_L(t) = ∫ p_L(t) dt = (1/2) · L · i(t)²
= (1/2) · L · [I☵ · cos(ωt − π/2)]²
= (1/2) · L · I☵² · sin²(ωt)
```

Максимальна енергія, яка запасається у магнітному полі котушки на піку струму:

```
W_L,max = (1/2) · L · I☵² = L · Iᵣₘ⛛² = Q / ω
```

Ось фундаментальний фізичний зміст реактивної потужності: **реактивна потужність `Q` дорівнює максимальній енергії `W_max`, що накопичується в реактивному полі за цикл, помноженій на кутову частоту `ω`**:

```
Q = ω · W_max
```

Аналогічне співвідношення діє і для конденсатора ємністю `C`, де максимальна енергія електричного поля дорівнює `W_C,max = (1/2) · C · V☵² = Q / ω`.

Зауважимо також важливий практичний наслідок для розрахунку фільтрових конденсаторів у джерелах живлення: для згладжування пульсацій миттєвої потужності `p(t)` на подвоєній частоті мережі `2f = 100 Гц` ємність конденсатора повинна розраховуватися виходячи з розмаху коливань миттєвої енергії `ΔW = P / ω`, а не лише з середнього значення струму споживання. Саме тому в однофазних перетворювачах згладжувальний конденсатор має значно більші габарити, ніж у трифазних інверторах одинакової потужності, де пульсації миттєвої потужності повністю відсутні завдяки фазовій симетрії.

### 4. Комплексна потужність та комплексно-спряжений фазор

У символічному методі розрахунку синусоїдальних кіл напруга та струм подаються комплексними числами — фазорами у показниковій формі:

```
V = Vᵣₘ⛛ · e^(jθᵥ)
I = Iᵣₘ⛛ · e^(jθᵢ)
```

де `θᵥ` та `θᵢ` — початкові фази напруги й струму, а `j` — уявна одиниця (`j² = −1`). Кут зсуву фаз дорівнює `φ = θᵥ − θᵢ`.

Якщо спробувати обчислити комплексний добуток `V · I`, виникне помилка:

```
V · I = Vᵣₘ⛛·Iᵣₘ⛛ · e^(j(θᵥ + θᵢ))
```

Кути додаються, тому результат залежить від довільного вибору нуля відліку часу `t = 0`, що є фізично неприпустимим для характеристик потужності.

Щоб фази віднімалися (`θᵥ − θᵢ = φ`), вектор струму комплексно спрягають `I* = Iᵣₘ⛛ · e^(−jθᵢ)`. Здійснимо множення:

```
S = V · I*
= [Vᵣₘ⛛ · e^(jθᵥ)] · [Iᵣₘ⛛ · e^(−jθᵢ)]
= Vᵣₘ⛛ · Iᵣₘ⛛ · e^(j(θᵥ − θᵢ))
= Vᵣₘ⛛ · Iᵣₘ⛛ · e^(jφ)
```

Використавши формулу Ейлера `e^(jφ) = cos(φ) + j · sin(φ)`, маємо:

```
S = Vᵣₘ⛛ · Iᵣₘ⛛ · [cos(φ) + j · sin(φ)]
= Vᵣₘ⛛ · Iᵣₘ⛛ · cos(φ) + j · Vᵣₘ⛛ · Iᵣₘ⛛ · sin(φ)
= P + j · Q
```

Комплексна потужність `S` узагальнює всі енергетичні параметри кола:
- **Дійсна частина**: `Re{S} = P = Vᵣₘ⛛ · Iᵣₘ⛛ · cos φ` — активна потужність (Вт).
- **Уявна частина**: `Im{S} = Q = Vᵣₘ⛛ · Iᵣₘ⛛ · sin φ` — реактивна потужність (вар).
- **Модуль комплексної потужності**: `|S| = √(P² + Q²) = Vᵣₘ⛛ · Iᵣₘ⛛` — повна потужність (В·А).

Завдяки теоремі Піфагора для прямокутного трикутника з катетами `P` і `Q` та гіпотенузою `S` виконується співвідношення `S² = P² + Q²`.

### 5. Доведення сталості миттєвої потужності у трифазній симетричній системі

Розглянемо симетричну трифазну систему напруг, де три фази `A`, `B`, `C` зсунуті одна відносно одної на кут `120°` (`2π/3` радіан):

```
vₐ(t) = V☵ · cos(ωt)
vᵦ(t) = V☵ · cos(ωt − 2π/3)
v꜀(t) = V☵ · cos(ωt − 4π/3)
```

При симетричному навантаженні струми в усіх трьох фазах мають однаковий модуль `I☵` та однаковий кут фазового зсуву `φ` відносно відповідних фазних напруг:

```
iₐ(t) = I☵ · cos(ωt − φ)
iᵦ(t) = I☵ · cos(ωt − 2π/3 − φ)
i꜀(t) = I☵ · cos(ωt − 4π/3 − φ)
```

Сумарна миттєва потужність трифазної системи `pₜₒₜₐₗ(t)` дорівнює сумі миттєвих потужностей усіх трьох фаз:

```
pₜₒₜₐₗ(t) = vₐ(t)·iₐ(t) + vᵦ(t)·iᵦ(t) + v꜀(t)·i꜀(t)
```

Використавши виведений раніше тригонометричний розклад для кожної з трьох фаз `pₖ(t) = P₁ + (V☵I☵ / 2) · cos(2θₖ − φ)`, де `P₁ = Vᵣₘ⛛Iᵣₘ⛛ cos φ` — активна потужність однієї фази, запишемо внесок кожної фази:

```
pₐ(t) = P₁ + (V☵I☵ / 2) · cos(2ωt − φ)
pᵦ(t) = P₁ + (V☵I☵ / 2) · cos(2ωt − 4π/3 − φ)
p꜀(t) = P₁ + (V☵I☵ / 2) · cos(2ωt − 8π/3 − φ)
```

Складемо всі три вирази для обчислення `pₜₒₜₐₗ(t)`:

```
pₜₒₜₐₗ(t) = 3·P₁ + (V☵I☵ / 2) · [cos(2ωt − φ) + cos(2ωt − 4π/3 − φ) + cos(2ωt − 8π/3 − φ)]
```

Проаналізуємо суму трьох косинусів у квадратних дужках. Вона має вигляд `cos(α) + cos(α − 2π/3) + cos(α − 4π/3)`, де позначено `α = 2ωt − φ`.

Розкриємо кожен косинус за формулою різниці кутів:

```
cos(α − 2π/3) = cos α · cos(2π/3) + sin α · sin(2π/3) = −(1/2)·cos α + (√3/2)·sin α
cos(α − 4π/3) = cos α · cos(4π/3) + sin α · sin(4π/3) = −(1/2)·cos α − (√3/2)·sin α
```

Додамо всі три доданки:

```
cos α + [−(1/2)·cos α + (√3/2)·sin α] + [−(1/2)·cos α − (√3/2)·sin α]
= cos α − (1/2)·cos α − (1/2)·cos α + (√3/2)·sin α − (√3/2)·sin α
= (1 − 1/2 − 1/2)·cos α + (√3/2 − √3/2)·sin α
= 0 · cos α + 0 · sin α = 0
```

Сума хвильових пульсацій зсунутих на 120° дорівнює **тотожному нулю** для будь-якого моменту часу `t`!

Отже, пульсуюча частина зникає абсолютно, і сумарна трифазна потужність виявляється строго постійною в часі:

```
pₜₒₜₐₗ(t) = 3 · P₁ = 3 · Vᵣₘ⛛ · Iᵣₘ⛛ · cos(φ)
```

Це фундаментальний висновок теорії електроенергетики: **у симетричному трифазному колі миттєва потужність взагалі не пульсує**. Реактивні коливання окремих фаз взаємно компенсують одне одного у фазному просторі. Завдяки цьому трифазний електродвигун створює абсолютний постійний обертальний момент на валу без акустичного гулу й вібрацій.

### 6. Несиметричний режим трифазної мережі та виникнення пульсацій

А що відбувається, якщо трифазне навантаження стає несиметричним (наприклад, одна фаза завантажена дужче за інші або має інший зсув фази `φₐ ≠ φᵦ ≠ φ꜀`)?

У несиметричному режимі амплітуди `I☵ₐ, I☵ᵦ, I☵꜀` або кути `φₐ, φᵦ, φ꜀` перестають бути рівними. Тоді сума трьох косинусів подвоєної частоти у квадратних дужках більше не перетворюється на тотожний нуль:

```
cos(2ωt − φₐ) + cos(2ωt − 4π/3 − φᵦ) + cos(2ωt − 8π/3 − φ꜀) ≠ 0
```

У результаті сумарна миттєва потужність `pₜₒₜₐₗ(t)` набуває коливальної складової на подвоєній частоті мережі `2ω` (100 Гц):

```
pₜₒₜₐₗ(t) = Pₜₒₜₐₗ + P_puls · cos(2ωt − ψ)
```

де `P_puls` — амплітуда пульсації потужності, пропорційна ступеню несиметрії (складовим зворотної послідовності за методом симетричних складових Фортеск'ю).

Саме ця пульсація потужності при розбалансі фаз викликає механічні вібрації в генераторах та потужних трифазних трансформаторах, підвищений акустичний шум та додатковий нагрів нейтрального провідника.

### 7. Перетворення Кларк та миттєва потужність у двофазній системі α-β (Теорія Акагі)

Для швидкого цифрового обчислення миттєвої потужності в силових активних фільтрах використовують ортогональне перетворення Кларк, яке переводить трифазні величини `a-b-c` у нерухому двофазну систему координат `α-β`:

```
v_α = √(2/3) · [ vₐ − (1/2)·vᵦ − (1/2)·v꜀ ]
v_β = √(2/3) · [ (√3/2)·vᵦ − (√3/2)·v꜀ ]
```

Аналогічно перетворюються і струми `i_α, i_β`. У цій двофазній системі координат миттєва активна потужність `p(t)` та миттєва реактивна потужність `q(t)` визначаються в матричному вигляді:

```
[ p ]   [  v_α   v_β ] [ i_α ]
[ q ] = [ −v_β   v_α ] [ i_β ]
```

Розкриваючи матричне множення, отримуємо миттєві потужності Акагі:

```
p(t) = v_α(t) · i_α(t) + v_β(t) · i_β(t)
q(t) = v_β(t) · i_α(t) − v_α(t) · i_β(t)
```

Ці дві формули дозволяють цифровій системі керування обчислювати миттєві активну й реактивну потужності в реальному часі на кожному такті АЦП без жодної затримки на усереднення за період.

### 8. Математика несинусоїдальних режимів та гармонійний розклад потужності

Коли напруга або струм описуються несинусоїдними функціями (наприклад, струм, споживаний імпульсним блоком живлення з діодним мостом), сигнали розкладають у ряд Фур'є:

```
v(t) = V₀ + √2 · ∑ Vₖ,rms · cos(kωt − θᵥ,ₖ)
i(t) = I₀ + √2 · ∑ I☵,rms · cos(mωt − θᵢ,☵)
```

де `k` та `m` — номери гармонік (`1` — фундаментальна частота 50 Гц, `3, 5, 7...` — вищі гармоніки).

Обчислимо миттєву потужність `p(t) = v(t) · i(t)` як добуток двох нескінченних рядів. Усереднення цього добутку за період `T` показує важливу властивість ортогональності гармонік різної частоти:

```
(1/T) ∫ cos(kωt) · cos(mωt) dt = 0    при k ≠ m
```

Це означає, що **активну потужність `P` створюють лише добутки гармонік однакового порядку `k = m`**:

```
P = V₀ · I₀ + ∑ Vₖ,rms · Iₖ,rms · cos(φₖ)
```

де `φₖ = θᵥ,ₖ − θᵢ,ₖ` — кут зсуву фази для `k`-ї гармоніки.

Проте миттєвий добуток `p(t)` містить перехресні доданки від гармонік різних порядків `k ≠ m`, які пульсують на комбінаційних частотах `(k + m)ω` та `|k − m|ω`. Ці перехресні коливання не переносять середньої енергії за період, але збільшують розмах пульсацій миттєвої потужності та збільшують діюче значення струму `Iᵣₘ⛛ = √(I₁² + I₃² + I₅² + ...)`.

Саме це перехресне пульсування створює додаткові втрати у провідниках та визначає потужність спотворення Будеану `D = √(S² − P² − Q₁²)`.

### 9. Обчислювальний приклад із числовими значеннями

Проілюструємо отримані математичні формули конкретними обчисленнями для стандартної однофазної мережі.

**Умова:** Однофазне навантаження підключено до напруги з RMS-значенням `Vᵣₘ⛛ = 230 В` і частотою `f = 50 Гц` (`ω = 2π · 50 = 100π ≈ 314.16 рад/с`). Струм навантаження має RMS-значення `Iᵣₘ⛛ = 10 А` і відстає від напруги на кут `φ = 60°` (`π/3 радіан`, `cos 60° = 0.5`, `sin 60° = √3/2 ≈ 0.866`).

#### Крок 1. Амплітудні значення напруги й струму

```
V☵ = Vᵣₘ⛛ · √2 = 230 · 1.4142 ≈ 325.27 В
I☵ = Iᵣₘ⛛ · √2 = 10 · 1.4142  ≈ 14.14 А
```

#### Крок 2. Активна, реактивна та повна потужність

```
P = Vᵣₘ⛛ · Iᵣₘ⛛ · cos(60°) = 230 · 10 · 0.5 = 1150 Вт
Q = Vᵣₘ⛛ · Iᵣₘ⛛ · sin(60°) = 230 · 10 · 0.866 = 1991.8 вар
S = Vᵣₘ⛛ · Iᵣₘ⛛ = 230 · 10 = 2300 В·А
```

Перевіримо геометричне співвідношення `S = √(P² + Q²)`:

```
√(1150² + 1991.8²) = √(1 322 500 + 3 967 267) = √5 289 767 ≈ 2300 В·А
```

#### Крок 3. Рівняння миттєвої потужності `p(t)`

```
p(t) = P · [1 + cos(200π t)] + Q · sin(200π t)
= 1150 · [1 + cos(200π t)] + 1991.8 · sin(200π t)
```

#### Крок 4. Розрахунок миттєвих значень у ключові моменти часу

Обчислимо миттєву потужність `p(t)` протягом одного напівперіоду мережі (`T/2 = 10 мс`):

1. **`t = 0 мс`** (`200π t = 0`):
   `cos(0) = 1`, `sin(0) = 0`
   `p(0) = 1150 · (1 + 1) + 1991.8 · 0 = 2300 Вт` (дорівнює піковій потужності).

2. **`t = 2.5 мс`** (`200π t = π/2`):
   `cos(π/2) = 0`, `sin(π/2) = 1`
   `p(2.5 мс) = 1150 · (1 + 0) + 1991.8 · 1 = 1150 + 1991.8 = 3141.8 Вт`.

3. **`t = 5 мс`** (`200π t = π`):
   `cos(π) = −1`, `sin(π) = 0`
   `p(5 мс) = 1150 · (1 − 1) + 1991.8 · 0 = 0 Вт`.

4. **`t = 7.5 мс`** (`200π t = 3π/2`):
   `cos(3π/2) = 0`, `sin(3π/2) = −1`
   `p(7.5 мс) = 1150 · (1 + 0) + 1991.8 · (−1) = 1150 − 1991.8 = −841.8 Вт`.

Зверніть увагу: у момент `t = 7.5 мс` миттєва потужність від'ємна (`−841.8 Вт`). У цей момент індуктивне поле навантаження повністю віддає раніше накопичену магнітну енергію назад у мережу зі швидкістю 841.8 джоулів за секунду, тим самим розвантажуючи генератор на цьому короткому проміжку часу.
