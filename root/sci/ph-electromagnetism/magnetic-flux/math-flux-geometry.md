# 🧮 Обчислення магнітного потоку для фундаментальних геометрій та закону Гаусса

Магнітний потік `Φ` є кількісною інтегральною мірою векторного поля індукції `B`, що пронизує обрану поверхню `S`. Для розрахунку фізичних процесів у силових трансформаторах, коаксіальних кабелях, вимірювальних контурах та друкованих платах необхідні точні математичні виведення потоку в різних геометріях. 

Ця вставка містить виклад математичного апарату для обчислення магнітного потоку, виведення потокозчеплення та індуктивності, а також строге доведення закону Гаусса для магнітного поля за допомогою векторного аналізу.

---

### 1. Плоский контур у довільно орієнтованому однорідному полі

Розглянемо базову геометричну задачу: плоский замкнений контур площею `A`, розміщений у просторі з однорідним магнітним полем, де вектор індукції `B` є однаковим у всіх точках за величиною та напрямком.

Просторова орієнтація площини контуру визначається одиничним вектором зовнішньої нормалі `n̂` (`|n̂| = 1`). Напрямок вектора `n̂` обирається відповідно до обраного напрямку обходу межі контуру за правилом правого гвинта: якщо пальці правої руки вказують напрямок обходу контуру, то відігнутий великий палець вказує додатний напрямок нормалі `n̂`. Векторний елемент площі визначається як:

```
dA = n̂ · dA
```

Елементарний потік `dΦ` через майданчик `dA` за визначенням дорівнює скалярному добутку векторів магнітної індукції та орієнтованого елемента площі:

```
dΦ = B · dA
   = B · n̂ · dA             [визначення елемента площі: dA = n̂ · dA]
   = B · cos(θ) · dA        [скалярний добуток: |n̂| = 1, кут θ між B та n̂]
```

Оскільки поле `B` та вектор нормалі `n̂` є константними в усіх точках плоського контуру, кут `θ` між ними не змінюється по всій площі `A`. Виконуючи інтегрування по всій поверхні контуру `A`, отримуємо:

```
Φ = ∫_A B · dA 
  = B · cos(θ) · ∫_A dA     [сталі величини B та cos(θ) винесено за знак інтеграла]
  = B · A · cos(θ)          [інтегрування елементів площі: ∫_A dA = A]
```

Математичний зміст скалярного добутку полягає в тому, що потік визначається нормальною компонентою вектора індукції `B_n = B · cos(θ)`. Тангенціальна компонента `B_t = B · sin(θ)`, яка лежить у площині контуру, не перетинає поверхню й не робить внеску в інтеграл.

#### Докладний аналіз кутових режимів

1. **Максимальний потік (`θ = 0°` або `cos(θ) = 1`):** Вектор магнітного поля `B` перпендикулярний до площини контуру й напрямлений уздовж нормалі `n̂`. Усі силові лінії перетинають контур під прямим кутом. Потік є максимально можливим для цієї площі: `Φ_max = B · A`.
2. **Наклонений контур (`θ = 60°` або `cos(θ) = 0.5`):** Ефективна проекція поверхні, перпендикулярна до вектора індукції, зменшується вдвічі, тому потік дорівнює: `Φ = 0.5 · B · A`.
3. **Нульовий потік (`θ = 90°` або `cos(θ) = 0`):** Вектор поля `B` перпендикулярний до нормалі `n̂`, тобто паралельний самій площині контуру. Силові лінії ковзають уздовж контуру й не пронизують його: `Φ = 0`.
4. **Від'ємний потік (`θ = 180°` або `cos(θ) = -1`):** Поле спрямоване проти обраного напрямку нормалі, силові лінії входять з тильного боку контуру: `Φ = -B · A`.

Якщо поверхня не є плоскою, але вектор поля `B` залишається строго однорідним у всьому об'ємі, магнітний потік дорівнює добутку модуля `B` на площу проекції цієї викривленої поверхні `A_proj` на площину, перпендикулярну до напрямку вектора індукції. З математичної точки зору проекція обчислюється як інтеграл від косинуса кута між нормалями `∫_S (n̂ · k̂) dA = A_proj`. Така проекційна властивість суттєво спрощує інтегрування неоднорідних поверхонь у складно орієнтованих зовнішніх магнітних полях.

### 2. Прямокутний контур поруч із нескінченним прямим провідником

У задачах електромагнітної сумісності (EMC) та розрахунку паразитного взаємного наведення між доріжками друкованих плат часто виникає конфігурація, коли прямокутний вимірювальний контур розташований паралельно до довгого провідника зі струмом.

Розглянемо нескінченно довгий прямий провідник, по якому протікає постійний струм `I`. За законом Біо-Савара-Лапласа або законом циркуляції Ампера, магнітні лінії утворюють концентричні кола навколо провідника. Модуль магнітного поля на відстані `r` від осі провідника дорівнює:

```
B(r) = (μ₀ · I) / (2 · π · r)
```

Поруч із провідником у тій самій площині розташовано плоский прямокутний контур висотою `h` та шириною `(b - a)`. Ближча поздовжня сторона контуру знаходиться на відстані `a` від провідника, а віддалена — на відстані `b`.

Оскільки поле `B(r)` зменшується обернено пропорційно відстані `r`, воно є неоднорідним уздовж ширини контуру. Розіб'ємо прямокутний контур на безліч вузьких поздовжніх смужок шириною `dr` та довжиною `h`, розташованих на відстані `r` від провідника. Елемент площі такої смужки дорівнює `dA = h · dr`.

За правилом правого гвинта, лінії поля `B(r)` у площині контуру перпендикулярні до цієї площини, тому кут `θ = 0°` і `cos(θ) = 1`.

Для обчислення повного потоку виконуємо інтегрування елементарного потоку `dΦ = B(r) · h · dr` по всій ширині контуру від `r = a` до `r = b`:

```
Φ = ∫_A B(r) · dA
  = ∫_{a}^{b} [ (μ₀ · I) / (2 · π · r) ] · h · dr       [підстановка поля B(r) та елемента площі dA = h · dr]
  = [ (μ₀ · I · h) / (2 · π) ] · ∫_{a}^{b} (1 / r) · dr [винесення констант μ₀, I, h за знак інтеграла]
```

Застосовуючи формулу для визначеного інтеграла від оберненої функції `1 / r`, отримуємо первісну в вигляді натурального логарифма:

```
∫_{a}^{b} (1 / r) · dr = [ ln(r) ]_{a}^{b} = ln(b) - ln(a) = ln(b / a) [визначений інтеграл первісної ln(r)]
```

Підставляючи отримане значення інтеграла, маємо остаточний вираз для магнітного потоку прямокутного контуру:

```
Φ = (μ₀ · I · h / (2 · π)) · ln(b / a)                  [остаточна формула магнітного потоку]
```

Взаємна індуктивність `M` між прямим провідником та прямокутним контуром визначається як відношення магнітного потоку до струму `I`, що його створив:

```
M = Φ / I = (μ₀ · h / (2 · π)) · ln(b / a)              [взаємна індуктивність провідника та контуру]
```

Ця формула має важливе значення для інженерного аналізу паразитного наведення в друкованих платах: логарифмічна залежність показує, що зближення контуру з силовим провідником (зменшення відстані `a`) викликає різке зростання наведеного потоку та імпульсних завад. Якщо змістити контур так, що провідник проходить крізь його центр, інтегрування дасть алгебраїчну суму двох запозичених потоків протилежного знака.

### 3. Потік у коаксіальному кабелі, тороїді та соленоїді

Розглянемо фундаментальні електротехнічні геометрії: коаксіальний кабель, багатовитковий соленоїд та тороїдальну котушку.

#### Магнітний потік у коаксіальному кабелі

Коаксіальний кабель складається з внутрішнього суцільного провідника радіусом `r₁` та зовнішньої циліндричної оболонки радіусом `r₂`. По внутрішньому провіднику протікає струм `I`, а по зовнішньому — такий самий струм `I` у зворотному напрямку.

У діелектричному просторі між провідниками (`r₁ < r < r₂`) магнітне поле створюється лише струмом внутрішньої жили й дорівнює `B(r) = (μ₀ · I) / (2 · π · r)`. Поза межами зовнішньої оболонки (`r > r₂`) сумарний охоплений струм дорівнює нулю (`I - I = 0`), тому магнітне поле зовні коаксіального кабелю тотожно дорівнює нулю.

Обчислимо потік `Φ` усередині діелектричного шару кабелю довжиною `L`. Площа поздовжнього перерізу між жилою та оболонкою розбивається на прямокутні елементи `dA = L · dr`.

```
Φ = ∫_{r₁}^{r₂} B(r) · L · dr
  = ∫_{r₁}^{r₂} [ (μ₀ · I) / (2 · π · r) ] · L · dr     [підстановка поля B(r) коаксіального кабелю]
  = (μ₀ · I · L / (2 · π)) · ln(r₂ / r₁)                [інтегрування по радіусу від r₁ до r₂]
```

Погонна індуктивність (індуктивність одиниці довжини) коаксіального кабелю визначається як відношення потоку до струму та довжини:

```
L' = Φ / (I · L) = (μ₀ / (2 · π)) · ln(r₂ / r₁)         [індуктивність на один метр довжини кабелю]
```

Отриманий вираз дозволяє обчислювати хвильовий опір кабелю `Z_0 = √(L' / C')` та аналізувати високочастотні лінії передачі даних. Якщо врахувати проникнення магнітного поля всередину жили на низьких частотах (внутрішню індуктивність), до виразу додається константна поправка `μ₀ / (8 · π)`.

#### Потокозчеплення та індуктивність соленоїда

Розглянемо соленоїд довжиною `L`, радіусом `R` (площа перерізу `A = π · R²`), що містить `N` щільно намотаних витків і по якому протікає струм `I`.

Усередині довгого соленоїда (`L >> R`) магнітне поле можна вважати строго однорідним і спрямованим уздовж його осі:

```
B = μ₀ · n · I = μ₀ · (N / L) · I                       [магнітна індукція всередині соленоїда]
```

Магнітний потік `Φ₁`, який пронизує один виток соленоїда:

```
Φ₁ = B · A = μ₀ · (N / L) · I · A                       [потік через один виток площею A]
```

Оскільки соленоїд складається з `N` одинакових витків, з'єднаних послідовно, силові лінії поля пронизують кожен з них. Сумарне потокозчеплення `Ψ` дорівнює:

```
Ψ = N · Φ₁
  = N · [ μ₀ · (N / L) · I · A ]                        [підстановка потоку одного витка Φ₁]
  = [ (μ₀ · N² · A) / L ] · I                           [підсумкова формула потокозчеплення]
```

Власна індуктивність соленоїда `L_ind` визначається як відношення потокозчеплення до струму:

```
L_ind = Ψ / I
      = (μ₀ · N² · A) / L                               [індуктивність соленоїда через геометрію]
```

Магнітна енергія `W_m`, накопичена в об'ємі соленоїда `V = A · L`:

```
W_m = 0.5 · L_ind · I²
    = 0.5 · [ (μ₀ · N² · A) / L ] · I²                  [підстановка індуктивності L_ind]
    = 0.5 · (B² / μ₀) · V                               [вираження через густину енергії поля w_m]
```

Для соленоїдів скінченної довжини крайовий ефект виходу силових ліній на кінцях котушки враховують за допомогою коефіцієнта Нагаоки `K_N < 1`, який обчислюють через повні еліптичні інтеграли першого та другого роду: `L_real = K_N · L_ind`.

#### Потік у тороїдальній котушці прямокутного перерізу

Розглянемо тороїдальне феромагнітне осереддя з прямокутним поперечним перерізом, внутрішнім радіусом `R₁`, зовнішнім радіусом `R₂` та висотою `h`. На тороїд рівномірно намотано `N` витків зі струмом `I`.

За законом циркуляції Ампера магнітна індукція всередині осереддя на радіусі `r` (`R₁ < r < R₂`) дорівнює:

```
B(r) = (μ₀ · μ_r · N · I) / (2 · π · r)
```

Елемент площі поперечного перерізу дорівнює `dA = h · dr`. Потік `Φ₁` через один виток тороїда обчислюється шляхом інтегрування від `r = R₁` до `r = R₂`:

```
Φ₁ = ∫_{R₁}^{R₂} B(r) · h · dr
   = [ (μ₀ · μ_r · N · I · h) / (2 · π) ] · ∫_{R₁}^{R₂} (1 / r) · dr
   = [ (μ₀ · μ_r · N · I · h) / (2 · π) ] · ln(R₂ / R₁)
```

Потокозчеплення `Ψ` та індуктивність тороїда `L_tor` дорівнюють:

```
Ψ = N · Φ₁ = [ (μ₀ · μ_r · N² · h) / (2 · π) ] · I · ln(R₂ / R₁)
L_tor = Ψ / I = (μ₀ · μ_r · N² · h / (2 · π)) · ln(R₂ / R₁)
```

Тороїдальна геометрія забезпечує майже повну відсутність зовнішнього поля розсіювання, що робить тороїдальні трансформатори та дроселі еталонними за рівнем електромагнітної сумісності.

### 4. Потік магнітного диполя через півсферу та котушки Гельмгольца

Розглянемо математичні виведення для двох важливих просторових конфігурацій: магнітного диполя та системи з двох котушок Гельмгольца.

#### Магнітний потік диполя через півсферичну поверхню

Магнітне поле точкового магнітного диполя з магнітним моментом `m`, спрямованим уздовж осі `Z`, у сферичній системі координат `(r, θ, φ)` має векторні компоненти:

```
B_r(r, θ) = (μ₀ · m · cos(θ)) / (2 · π · r³)
B_θ(r, θ) = (μ₀ · m · sin(θ)) / (4 · π · r³)
B_φ = 0
```

Обчислимо потік `Φ` радіальної компоненти індукції `B_r` через верхню півсферу радіусом `R` (`0 ≤ θ ≤ π/2`, `0 ≤ φ ≤ 2π`). Елемент площі сфери дорівнює `dA = R² sin(θ) dθ dφ`, а вектор нормалі `n̂` спрямований уздовж радіуса:

```
Φ = ∬_S B_r(R, θ) · R² sin(θ) dθ dφ
  = ∫_{0}^{2π} dφ · ∫_{0}^{π/2} [ (μ₀ · m · cos(θ)) / (2 · π · R³) ] · R² sin(θ) dθ
  = 2π · [ (μ₀ · m) / (2 · π · R) ] · ∫_{0}^{π/2} cos(θ) sin(θ) dθ
```

Застосовуючи заміну змінної `u = sin(θ)`, `du = cos(θ) dθ`, маємо:

```
∫_{0}^{π/2} cos(θ) sin(θ) dθ = [ 0.5 · sin²(θ) ]_{0}^{π/2} = 0.5 · (1 - 0) = 0.5
```

Підставляючи значення інтеграла, отримуємо підсумковий потік диполя через верхню півсферу:

```
Φ = 2π · [ (μ₀ · m) / (2 · π · R) ] · 0.5 = (μ₀ · m) / (2 · R)
```

Потік через нижню півсферу дорівнює `-(μ₀ · m) / (2 · R)`, що дає в сумі по всій замкненій сфері радіусом `R` нульовий потік `Φ_total = 0`, як того вимагає закон Гаусса.

#### Однорідність поля в котушках Гельмгольца

Котушки Гельмгольца складаються з двох одинакових кругових витків радіусом `R`, розташованих на спільній осі на відстані `d = R` один від одного. Така відстань обрана не випадково: вона забезпечує рівність нулю як першої, так і другої похідної магнітної індукції за осьовою координатою `z` в центральній точці `z = 0`.

Розклад індукції `B_z(z)` у ряд Тейлора навколо центральної точки:

```
B_z(z) = B(0) + (dB/dz)₀ · z + 0.5 · (d²B/dz²)₀ · z² + (1/6) · (d³B/dz³)₀ · z³ + (1/24) · (d⁴B/dz⁴)₀ · z⁴ + ...
```

Завдяки симетрії розстави котушок на `d = R` маємо `(dB/dz)₀ = 0` та `(d²B/dz²)₀ = 0`. Отже, першим ненульовим членом відхилення від однорідності є четверта похідна `z⁴`, що забезпечує надзвичайно високу однорідність поля `B_z ≈ (8 / (5 · √5)) · (μ₀ · N · I / R)` у центральній області між котушками. Інтегрування потоку через плоский вимірювальний контур, розміщений у цій зоні, дає похибку менше `0.01%`.

#### Циркуляція векторного потенціалу у циліндричних координатах

Обчислимо потік у круговому контурі радіусом `r_0` через векторний потенціал `A`. Для вихрового магнітного поля азимутальна компонента векторного потенціалу `A_φ(r)` пов'язана з індукцією `B_z` співвідношенням ротора в циліндричних координатах:

```
B_z = (1 / r) · (d(r · A_φ) / dr)
```

Інтегруючи це диференціальне рівняння по радіусу `r` від `0` до `r_0`:

```
∫_{0}^{r_0} B_z · r dr = [ r · A_φ(r) ]_{0}^{r_0} = r_0 · A_φ(r_0)
```

Повний магнітний потік `Φ` через круг радіусом `r_0` обчислюється як:

```
Φ = ∬ B_z · r dr dφ = 2π · ∫_{0}^{r_0} B_z · r dr = 2π · r_0 · A_φ(r_0)
```

З іншого боку, циркуляція `A_φ` вздовж кола радіусом `r_0` за теоремою Стокса дає той самий результат:

```
∮ A · dl = A_φ(r_0) · (2π · r_0) = Φ
```

Це доводить абсолютну математичну еквівалентність обчислення магнітного потоку через поверхневий інтеграл від поля індукції `B` або через лінійну циркуляцію векторного потенціалу `A`.

### 5. Строге доведення закону Гаусса для магнітного поля

Закон Гаусса для магнітного поля стверджує, що потік вектора індукції `B` через довільну замкнену поверхню `S` тотожно дорівнює нулю:

```
∮_S B · dA = 0
```

Для математичного обґрунтування цього фундаментального закону виходимо із закону Біо-Савара-Лапласа для магнітного поля, створеного довільним тривимірним розподілом струму зі щільністю `J(r')` у джерельному об'ємі `V'`:

```
B(r) = (μ₀ / (4 · π)) · ∫_V' [ J(r') × (r - r') ] / |r - r'|³ dV'
```

де `r` — вектор точки спостереження, а `r'` — вектор точки джерела струму.

Використаємо векторне співвідношення для градієнта від оберненої відстані між точками спостереження та джерела:

```
(r - r') / |r - r'|³ = -∇ (1 / |r - r'|)               [градієнт від оберненої відстані по координатах r]
```

Застосовуючи векторну тотожність для ротора добутку скаляра на вектор `∇ × (f · A) = f · (∇ × A) + (∇f) × A`, а також враховуючи, що густина струму `J(r')` не залежить від координат точки спостереження `r` (`∇ × J(r') = 0`), отримуємо:

```
[ J(r') × (r - r') ] / |r - r'|³ = ∇ × [ J(r') / |r - r'| ]  [перетворення векторного добутку під інтегралом]
```

Тут оператор набла `∇` диференціює лише за координатами точки спостереження `r`, тоді як інтегрування виконується за координатами джерела `r'`. Оскільки операції диференціювання по `r` та інтегрування по `r'` є абсолютно незалежними, винесемо оператор ротора `∇ ×` за знак інтеграла:

```
B(r) = ∇ × A(r)                                         [представлення поля B через ротор векторного потенціалу]
```

де `A(r)` — магнітний векторний потенціал:

```
A(r) = (μ₀ / (4 · π)) · ∫_V' [ J(r') / |r - r'| ] dV'   [інтегральне визначення векторного потенціалу A]
```

Тепер обчислимо дивергенцію (розбіжність) векторного поля індукції `B(r)`:

```
∇ · B = ∇ · (∇ × A)
      = 0                                                [векторна тотожність: дивергенція ротора завжди тотожний нуль]
```

У векторному аналізі для будь-якого двічі неперервно диференційовного векторного поля `A` дивергенція його ротора тотожно дорівнює нулю (`div rot A ≡ 0`). Звідси випливає **диференціальна форма закону Гаусса для магнітного поля**:

```
∇ · B = 0
```

Для переходу до інтегральної форми застосуємо **теорему Остроградського-Гаусса** (теорему про дивергенцію) для об'єму `V`, обмеженого замкненою поверхнею `S`:

```
∮_S B · dA = ∫_V (∇ · B) dV                             [теорема Остроградського-Гаусса]
           = ∫_V 0 dV                                   [підстановка ∇ · B = 0]
           = 0                                          [інтеграл від нуля по об'єму дорівнює нулю]
```

Це доведення строго підтверджує, що в природі відсутні магнітні заряди (монополі), джерелами магнітного поля `B` є замкнені вихрові струми, а всі лінії індукції `B` є неперервними самі на себе.

Векторний аналіз дивергенції ротора `div rot A ≡ 0` є фундаментальним алгебраїчним інваріантом у теорії диференціальних форм. В мові тензорного аналізу магнітне поле подається як 2-форма `F = dA`, а дивергенція `div B = 0` еквівалентна тотожності Зора-Б'янкі `dF = d(dA) = 0`, що гарантує топологічну замкненість магнітного потоку у довільному диференційовному многовиді. Математична неперервність потоку забезпечує виконання законів збереження в електродинаміці. Таким чином, фундаментальна відсутність магнітних зарядів отримує строге математичне обґрунтування через неперервну симетрію векторного потенціалу у розшарованому просторі електромагнітної взаємодії. Отримані аналітичні співвідношення утворюють теоретичний фундамент для сучасних обчислювальних методів розрахунку електромагнітних полів у складних просторових конфігураціях електротехнічних пристроїв, від мініатюрних індукторів до потужних надпровідних магнітів. Фізична незмінність закону Гаусса забезпечує стійкість розв'язків рівнянь Максвелла у будь-якій системі координат. Отримані аналітичні інтеграли гарантують точність подальшого чисельного моделювання.
