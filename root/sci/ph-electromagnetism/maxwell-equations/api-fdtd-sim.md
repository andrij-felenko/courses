## 1. Загальна архітектура контракту солвера та розподіл ресурсів

Чисельний солвер представляє собою високопродуктивний програмний модуль, який приймає конфігурацію розрахункової області, виконує дискретне інтегрування рівнянь Максвелла у часі та повертає просторово-часові масиви векторів напруженостей електричного `E(x, y, z, t)` та магнітного `H(x, y, z, t)` полів. При проектуванні архітектури контракту закладено принцип чіткого розмежування фаз: ініціалізація та валідація конфігурації, виділення aligned-пам'яті, часовий розрахунковий цикл «чехарди», та обробка накопичених даних.

Основним обчислювальним завданням солвера є мінімізація накладних витрат на передачу даних між оперативною пам'яттю та реєстрами процесора або відеокарти. Для цього контракт передбачає використання суцільних неперервних буферів пам'яті для кожної з шести компонент полів `Ex, Ey, Ez, Hx, Hy, Hz`. Це дозволяє уникнути фрагментації пам'яті та забезпечує лінійний послідовний доступ під час виконання ітерацій.

```
+-------------------------------------------------------------------+
|                        Вхідна конфігурація                        |
|  - Параметри сітки (dx, dy, dz, dt, Nx, Ny, Nz, Nt)               |
|  - Карта матеріалів (eps_r, mu_r, sigma_e, sigma_m)               |
|  - Профіль джерел (тип, частота, позиція, амплітуда)              |
|  - Межеві умови (Mur ABC, PML, PEC, PMC)                          |
+-------------------------------------------------------------------+
                                  │
                                  ▼
+-------------------------------------------------------------------+
|                       Ядро FDTD Розрахунку                        |
|  - Перевірка критерію стійкості CFL                               |
|  - Ініціалізація та розподіл пам'яті сітки Йі                      |
|  - Ітераційний цикл «чехарди» (Leapfrog updates)                   |
+-------------------------------------------------------------------+
                                  │
                                  ▼
+-------------------------------------------------------------------+
|                        Вихідні результати                         |
|  - Спектральні характеристики (S-параметри, Fourier transform)     |
|  - Зрізи просторових полів (Ez, Hy) у часі                        |
|  - Статус виконання та діагностика стійкості                      |
+-------------------------------------------------------------------+
```

### Спектральні монітори полів у частотній області (DFT Monitors)
Для отримання амплітудно-частотних характеристик (АЧХ) та матриць розсіювання (S-параметрів `S11`, `S21`) антен і мікрохвильових пристроїв немає потреби зберігати тривимірні вектори полів на кожному часовому кроці, що вимагало б терабайтів оперативної пам'яті. Замість цього солвер інтегрує дискретне перетворення Фур'є (DFT) безпосередньо під час розрахунку часового циклу. На кожному часовому кроці `n` для заданих контрольних частот `ω_k` обчислюється комплексне накопичення:

```
E(r, ω_k) += E(r, n·Δt) · exp(-i · ω_k · n · Δt) · Δt
```

Завдяки нагромадженню суми DFT у пам'яті безпосередньо в ході обчислень, вихідний монітор повертає комплексні вектори поля `E(r, ω)` одразу після завершення FDTD розрахунку. Це дозволяє здійснювати точний спектральний аналіз (наприклад, визначення частоти резонансу або ширини смуги пропускання хвилеводу) без збереження гігабайтних часових масивів на диск.

## 2. Специфікація конфігураційних параметрів сітки

Конфігурація просторово-часової дискретизації визначається структурою `FdtdGridConfig`. Вона задає геометричні розміри обчислювальної області, число осередків сітки Йі вздовж кожного з трьох просторових вимірів та параметри часового кроку.

Для забезпечення високої точності моделювання просторовий крок сітки `dx` обирається з міркувань роздільної здатності: він має бути принаймні у 10–20 разів меншим за найменшу довжину хвилі у досліджуваному матеріалі. При переході в діелектричні середовища з високою відносною проникністю `ε_r` довжина хвилі зменшується у `√ε_r` разів, що вимагає відповідного ущільнення сітки у діелектрику.

### Розрахунок граничного кроку часу CFL
Граничне значення кроку часу `dt_cfl` обчислюється автоматично солвером на основі умови Куранта — Фрідріхса — Леві. Солвер розраховує максимальну можливу швидкість світла у моделювальному об'ємі `c_max = 1 / √(ε₀ · ε_min · μ₀ · μ_min)`. Для прямокутної тривимірної сітки граничний крок часу виражається як:

```
dt_cfl = S / (c_max · √((1/dx²) + (1/dy²) + (1/dz²)))
```

де `S` — число Куранта (за замовчуванням `0.99`). Якщо користувач задає власне значення `dt`, яке перевищує `dt_cfl`, солвер автоматично блокує запуск моделювання і повертає помилку `FDTD_ERROR_CFL_VIOLATION`. Це запобігає витратам обчислювального часу на моделювання, яке неминуче розвалиться через числову нестійкість.

## 3. Специфікація властивостей середовища (карта матеріалів)

Кожна комірка просторової сітки `(i, j, k)` асоціюється з локальним матеріальним контейнером `MaterialProperties`. Карта матеріалів задає діелектричні, магнітні та провідні властивості об'єктів усередині обчислювального об'єму.

Матеріал може бути як однорідним, так і неоднорідним або анізотропним. Для металевих конструкцій із високою провідністю (мідь, алюміній, золото) використовується модель ідеального провідника (PEC) або реальна питома провідність `σ_e > 1e6` См/м.

У разі наявності згасання (`σ_e > 0`) коефіцієнти оновлення поля `Ez` модифікуються з урахуванням напівнеявного інтегрування дисипативних членів:

```
Ca = (1 - (σ_e · dt) / (2 · ε₀ · ε_r)) / (1 + (σ_e · dt) / (2 · ε₀ · ε_r))
Cb = (dt / (ε₀ · ε_r · dx)) / (1 + (σ_e · dt) / (2 · ε₀ · ε_r))

Ezⁿ⁺¹[i] = Ca · Ezⁿ[i] + Cb · (Hyⁿ⁺¹/²[i + 1/2] - Hyⁿ⁺¹/²[i - 1/2])
```

### Моделювання диспергуючих матеріалів (Моделі Друде та Лоренца)
Для моделювання плазми, металів на оптичних частотах (плазмоніка) та диспергуючих біологічних тканин у МРТ-сканерах солвер реалізує додатковий модуль ADE-FDTD (Auxiliary Differential Equation).

Часова залежність діелектричної проникності у моделі Друде записується як:

```
ε(ω) = ε₀ · [ ε_inf - ω_p² / (ω² + i · γ · ω) ]
```

де `ε_inf` — високочастотна діелектрична проникність, `ω_p` — плазмова частота електронів, `γ` — частота релаксаційних зіткнень. Контракт АПІ передбачає передачу параметрів `ε_inf`, `ω_p`, `γ` через додаткову структуру `DispersiveMaterialSpec`, що активує накопичення векторів поляризованості `Pⁿ[i]` у пам'яті осередка.

### Усереднення діелектричної проникності на межах осередків
При описі об'єктів складної геометрії межі діелектриків неминуче перетинають осередки сітки Йі. Пряме присвоєння ступенчатих значень `ε_r` викликає ступенчату похибку апроксимації (геометричний джиттер). Для збереження другого порядку точності `O(Δx²)` солвер застосовує процедуру гармонічного або гармонічно-арифметичного усереднення проникностей на межах комірок.

Нормальна компонента вектора електричного зміщення `D_n` на межі двох середовищ із діелектричними проникностями `ε₁` та `ε₂` вимагає використання гармонічного усереднення:

```
ε_eff = 2 · ε₁ · ε₂ / (ε₁ + ε₂)
```

Тангенційна ж компонента `E_t` є неперервною на межі, тому для неї використовується класичне арифметичне усереднення:

```
ε_eff = (ε₁ + ε₂) / 2
```

Вибір гармонічного усереднення для нормальних компонент полів має вирішальне значення для запобігання виникненню штучних накопичень вільних зарядів на чисельних межах середовищ, що в іншому випадку викликало б хибне паразитне випромінювання.

### Параметри матеріалу комірки
| Поле | Тип | Символ | Описи та фізичний зміст | Значення за замовчуванням |
| :--- | :--- | :--- | :--- | :--- |
| `eps_r` | `double` | `ε_r` | Відносна діелектрична проникність | `1.0` (вакуум) |
| `mu_r` | `double` | `μ_r` | Відносна магнітна проникність | `1.0` (вакуум) |

| `sigma_m` | `double` | `σ_m` | Еквівалентна магнітна провідність (Ом/м) | `0.0` (без втрат) |

## 4. Інтерфейс джерел випромінювання та межевих умов

Солвер підтримує кілька механізмів збудження полів у розрахунковій області. Правильний вибір типу джерела визначає точність отриманих результатів.

### Типи джерел (`SourceType`)
1. **Жорстке джерело (`FDTD_SOURCE_HARD`)**: значення поля у заданому вузлі насильно прирівнюється до часової функції `E(t)`. Таке джерело поводиться як ідеальний генератор напруги з нульовим внутрішнім опором. Головним недоліком жорсткого джерела є те, що хвилі, які відбиваються від інших об'єктів і повертаються назад до точки інжекції, повністю відбиваються від нього як від металевої стінки.
2. **М'яке джерело (`FDTD_SOURCE_SOFT`)**: значення часового сигналу додається до вже наявного поля у комірці (`Ez[i] += E(t)`). Таке джерело еквівалентне генератору струму з нескінченним внутрішнім опором. Відбиті хвилі вільно проходять крізь точку розташування м'якого джерела без жодних викривлень чи відбиттів.
3. **Джерело TFSF (`FDTD_SOURCE_TFSF`)**: розділяє розрахунковий об'єм замкненою віртуальною поверхнею. Усередині поверхні існує повна хвиля (сума падаючої хвилі та хвилі, розсіяної об'єктом), а зовні — лише розсіяна хвиля. Це єдиний коректний спосіб моделювання падіння плоскої хвилі на скінченне тіло у відкритому просторі.

### Профілі часового сигналу (`WaveformProfile`)
- **Гаусів імпульс** (`FDTD_WAVEFORM_GAUSSIAN`): забезпечує гладкий широкосмуговий спектр від постійного струму до граничної частоти `f_max = 1 / (π · tau)`. Не має бічних пелюсток у часовій та частотній областях.
- **Модульований гаусів імпульс** (`FDTD_WAVEFORM_MODULATED_GAUSSIAN`): обмежує спектр випромінювання вузькою смугою навколо заданої несучої частоти `f0`, що важливо для аналізу радіочастотних пристроїв Wi-Fi та 5G.

### Допустимі типи меж (`BoundaryCondition`)
| Тип | Назва | Механізм роботи | Застосування |
| :--- | :--- | :--- | :--- |
| `FDTD_BC_PEC` | Ідеальний провідник | `E_tangential = 0` | Металеві стінки, екрани, хвилеводи |
| `FDTD_BC_PMC` | Ідеальний магнетик | `H_tangential = 0` | Площини симетрії магнітного поля |
| `FDTD_BC_MUR_1ST` | Поглинальна межа Мура 1-го порядку | Односпрямоване хвильове рівняння | Прості відкриті межі у 1D/2D |
| `FDTD_BC_PML` | Ідеально узгоджений шар | Комплексне масштабування координат | Фізично відкритий необмежений простір |

## 5. Перетворення ближнього поля у далеке (NTFF Transform)

Для визначення діаграми спрямованості антен та ефективної площі розсіювання (ЕПР) об'єктів у дальній зоні (зоні Фраунгофера) контракт АПІ надає функціонал NTFF (Near-to-Far-Field Transformation).

Оскільки безпосередній розрахунок сітки FDTD до далекого поля вимагав би мільйонів додаткових осередків вакууму, солвер інтегрує еквівалентні поверхневі електричні `J_s = n × H` та магнітні `M_s = -n × E` струми на віртуальній поверховності у ближній зоні.

За теоремою еквівалентності Еквівалентні струми перераховуються у векторні потенціали Шелкунова у частотній області:

```
N(θ, φ, ω) = ∯_S J_s(r') · exp(i · k · r' · r̂) dS'
L(θ, φ, ω) = ∯_S M_s(r') · exp(i · k · r' · r̂) dS'
```

Після закінчення часового циклу модуль NTFF обчислює сферичні компоненти електричного поля у дальній зоні `E_theta` та `E_phi` на довільній відстані `R >> λ`:

```
E_theta(R, θ, φ) = -i · k · exp(-i k R) / (4 π R) · (L_phi + Z0 · N_theta)
E_phi(R, θ, φ)   =  i · k · exp(-i k R) / (4 π R) · (L_theta - Z0 · N_phi)
```

Це дозволяє одразу отримувати коефіцієнт підсилення антени `G(θ, φ)` та коефіцієнт спрямованої дії (КСД) без втрат пам'яті.

## 7. Вирівнювання пам'яті, SIMD-векторизація та діагностика

Для досягнення граничної обчислювальної потужності на сучасних процесорних архітектурах x86-64 та ARM64 буфери полів `Ex`, `Ey`, `Ez`, `Hx`, `Hy`, `Hz` виділяються у пам'яті з вирівнюванням за межею 64 байт (англ. *64-byte alignment*). Вирівнювання пам'яті є обов'язковою вимогою для безпечного використання векторальних інструкцій AVX-512 та ARM Neon: невирівняний доступ до двомісних векторних масивів може призвести до падіння продуктивності або апаратної виняткової ситуації (Bus Error).

### Контроль числової стійкості та перевірка NaN/Inf
Під час тривалого розрахунку високоенергетичних імпульсів або моделювання середовищ із від'ємними значеннями проникності (метаматеріали) існує ризик виникнення експоненціального зростання амплітуди через накопичення чисельних похибок заокруглення. Для запобігання псуванню масивів даних і передчасного виходу з ладу суміжних систем солвер впроваджує періодичний діагностичний моніторинг.

Кожні `N_diag` часових кроків (за замовчуванням `N_diag = 50`) ядро обчислень перевіряє максимальне абсолютне значення вектора електричного поля `E_max = max(|Ez[i]|)`. Якщо значення `E_max` перевищує умовний фізичний поріг `1e10` В/м або повертає вираз `std::isnan(E_max)` / `std::isinf(E_max)`, солвер негайно перериває обчислювальний цикл, повертає статусний код `FDTD_ERROR_UNSTABLE_SIMULATION` та записує діагностичний зріз останнього стійкого стану сітки у файл логування.
