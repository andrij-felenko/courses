# ⚙️ Чисельне моделювання хвильових процесів методом FDTD (Yee Grid)

Чисельне розв'язання рівнянь Максвелла методом скінченно-різницевої часової області (англ. *Finite-Difference Time-Domain*, **FDTD**) є базовим стандартом у сучасній радіофізиці, антенній техніці та мікрохвильовій інженерії. Метод запропонований Кейном Йі (англ. *Kane Yee*) у 1966 році. У цій вставці описано математичну дискретизацію рівнянь Максвелла на просторово-часовій сітці Йі, алгебраїчну схему оновлення полів («чехарду», або *leapfrog scheme*), аналіз чисельної дисперсії та умов стійкості Куранта — Фрідріхса — Леві, методологію інжекції полів TFSF, алгоритм поглинальних шарів CPML, тривимірне розширення схеми, а також наведено працюючі реалізації мовами C та C++.

## 1. Дискретизація 1D/2D/3D-рівнянь Максвелла та просторово-часова сітка Йі

Розглянемо плоску поперечну електромагнітну хвилю, що поширюється вздовж осі `x` у середовищі з діелектричною проникністю `ε` та магнітною проникністю `μ`. Припускаємо, що вектор електричного поля орієнтований вздовж осі `z` (`Ez`), а магнітне поле — вздовж осі `y` (`Hy`).

Закони Фарадея та Ампера — Максвелла у 1D набувають вигляду системи двох зв'язаних диференціальних рівнянь першого порядку:

```
∂Ez / ∂t = (1 / ε) · (∂Hy / ∂x)
∂Hy / ∂t = (1 / μ) · (∂Ez / ∂x)
```

Метод Йі спирається на просторово-часовий розсув осередків. Поле `Ez` обчислюється у цілі моменти часу `n · Δt` у цілих просторових вузлах `i · Δx`. Поле `Hy` обчислюється у напівцілі моменти часу `(n + 1/2) · Δt` у напівцілих вузлах `(i + 1/2) · Δx`. Такий розсув вузлів гарантує, що похідні за часом та простором апроксимуються симетричними центральними різницями второго порядку точності `O(Δx² + Δt²)`.

```
Вузол Ez(i, n)      ───(Δx/2)───> Вузол Hy(i + 1/2, n + 1/2)
Час t = n·Δt                      Час t = (n + 1/2)·Δt
```

Замінивши часткові похідні центральними скінченними різницями, отримуємо **різницеві рівняння оновлення**:

### Оновлення магнітного поля `Hy`:
```
Hyⁿ⁺¹/²[i + 1/2] = Hyⁿ⁻¹/²[i + 1/2] + (Δt / (μ · Δx)) · (Ezⁿ[i + 1] - Ezⁿ[i])
```

### Оновлення електричного поля `Ez`:
```
Ezⁿ⁺¹[i] = Ezⁿ[i] + (Δt / (ε · Δx)) · (Hyⁿ⁺¹/²[i + 1/2] - Hyⁿ⁺¹/²[i - 1/2])
```

### Математичне обґрунтування центральних скінченних різниць
Апроксимація часткових похідних у методі Йі базується на розкладі неперервних функцій полів у тригонометричний ряд Тейлора у околі вузла сітки `x_i`:

```
Ez(x_i + Δx/2) = Ez(x_i) + (Δx/2) · (∂Ez/∂x) + 1/2 (Δx/2)² · (∂²Ez/∂x²) + 1/6 (Δx/2)³ · (∂³Ez/∂x³) + ...
Ez(x_i - Δx/2) = Ez(x_i) - (Δx/2) · (∂Ez/∂x) + 1/2 (Δx/2)² · (∂²Ez/∂x²) - 1/6 (Δx/2)³ · (∂³Ez/∂x³) + ...
```

Віднімаючи друге рівняння від першого, парні степені `Δx` скорочуються, що дає вираз для першої похідної з похибкою апроксимації другого порядку:

```
∂Ez / ∂x = (Ez(x_i + Δx/2) - Ez(x_i - Δx/2)) / Δx + O(Δx²)
```

Завдяки симетричному розсуву вузлів `Ez` та `Hy` на півкроку простору `Δx/2` та часу `Δt/2`, непарні члени високих порядків апроксимації взаємно знищуються. Це дозволяє отримати другий порядок точності за простором та часом `O(Δx² + Δt²)`, користовуючи лише найближчі сусідні вузли.

### Розширення до 2D (TMz мода)
У двовимірному випадку для TMz модалізованої хвилі вектори полів об'єднують компоненти `Ez`, `Hx`, `Hy`. Рівняння оновлення набувають вигляду:

```
Hxⁿ⁺¹/²[i, j+1/2] = Hxⁿ⁻¹/²[i, j+1/2] - (Δt / (μ Δy)) · (Ezⁿ[i, j+1] - Ezⁿ[i, j])
Hyⁿ⁺¹/²[i+1/2, j] = Hyⁿ⁻¹/²[i+1/2, j] + (Δt / (μ Δx)) · (Ezⁿ[i+1, j] - Ezⁿ[i, j])

Ezⁿ⁺¹[i, j] = Ezⁿ[i, j] + (Δt / ε) · [ (Hyⁿ⁺¹/²[i+1/2, j] - Hyⁿ⁺¹/²[i-1/2, j])/Δx 
                                     - (Hxⁿ⁺¹/²[i, j+1/2] - Hxⁿ⁺¹/²[i, j-1/2])/Δy ]
```

### Повна 3D сітка Йі та топологія 6 компонент полів
У тривимірному випадку елементарна чарунка Йі представляє собою прямокутний паралелепіпед розмірами `Δx × Δy × Δz`. Компоненти електричного поля `Ex, Ey, Ez` розташовуються у центрах ребер чарунки, а компоненти магнітного поля `Hx, Hy, Hz` — у центрах граней.

Така топологія забезпечує природне виконання законів Гаусса `∇ · B = 0` та `∇ · D = ρ` на чисельному рівні без додаткової корекції: циркуляція компонент `E` по контуру грані прямо дорівнює зміні магнітного потоку крізь цю грань.

Повний комплект 3D рівнянь оновлення магнітного поля включає 3 скалярні рівняння:

```
Hxⁿ⁺¹/²[i, j+1/2, k+1/2] = Hxⁿ⁻¹/²[i, j+1/2, k+1/2] + (Δt / μ) · [ (Eyⁿ[i, j+1/2, k+1] - Eyⁿ[i, j+1/2, k])/Δz - (Ezⁿ[i, j+1, k+1/2] - Ezⁿ[i, j, k+1/2])/Δy ]
Hyⁿ⁺¹/²[i+1/2, j, k+1/2] = Hyⁿ⁻¹/²[i+1/2, j, k+1/2] + (Δt / μ) · [ (Ezⁿ[i+1, j, k+1/2] - Ezⁿ[i, j, k+1/2])/Δx - (Exⁿ[i+1/2, j, k+1] - Exⁿ[i+1/2, j, k])/Δz ]
Hzⁿ⁺¹/²[i+1/2, j+1/2, k] = Hzⁿ⁻¹/²[i+1/2, j+1/2, k] + (Δt / μ) · [ (Exⁿ[i+1/2, j+1, k] - Exⁿ[i+1/2, j, k])/Δy - (Eyⁿ[i+1, j+1/2, k] - Eyⁿ[i, j+1/2, k])/Δx ]
```

### Обчислювальна складність та алгоритмічні переваги
Явна схема «чехарда» на сітці Йі має ключову алгоритмічну перевагу над неявними скінченно-елементними (FEM) чи інтегральними (MoM) методами: вона **не вимагає розв'язання систем лінійних алгебраїчних рівнянь** і не потребує обернення великих розріджених матриць. Обчислювальна складність одного часового кроку FDTD становить `O(N)`, де `N` — загальна кількість просторових осередків.

```
Складність FDTD (явна схема):   O(N)   операцій на крок  [ідеально для GPU/SIMD]
Складність FEM/MoM (неявна):   O(N²) ... O(N³)  [потребує розв'язувача матриць]
```

Це робить метод FDTD ідеально пристосованим для розпаралелювання на графічних процесорах (GPU) за допомогою технологій CUDA або OpenCL, де кожен просторовий осередок `(i, j, k)` оновлюється незалежним обчислювальним потоком.

### Структура пам'яті та кеш-ефективність розрахунку
При переході від 1D до 2D та 3D FDTD моделей висуваються суворі вимоги до локальності даних у кеш-пам'яті L1/L2 процесора. У 1D випадку вектор полів розміщується у неперервних одномірних масивах `Ez[i]` та `Hy[i]`. Для 3D моделей масиви компонент `Ex`, `Ey`, `Ez`, `Hx`, `Hy`, `Hz` виділяються у вигляді плоских одномірних буферів розміром `NX * NY * NZ` з індексацією `idx(i, j, k) = (k * NY + j) * NX + i`.

Послідовний обхід просторових осередків у внутрішньому циклі по індексу `i` запевнює ефективне завантаження кеш-ліній процесора (англ. *cache prefetching*) та дозволяє векторному компілятору застосовувати SIMD-інструкції (AVX-2 / AVX-512) для одночасної обробки кількох вузлів сітки.

## 2. Чисельна стійкість, дисперсія та метод TFSF

### Умова стійкості Куранта — Фрідріхса — Леві (CFL)
Чисельна схема є явною і підпорядковується умові чисельної стійкості фон Ноймана. Схема є стійкою тоді й лише тоді, коли крок за часом `Δt` задовольняє умову Куранта:

```
Δt ≤ S_cfl / (c_max · √((1/Δx²) + (1/Δy²) + (1/Δz²)))
```

де `S_cfl ≤ 1.0` — число Куранта, `c_max = 1 / √(ε_min · μ_min)` — максимальна швидкість поширення хвилі у середовищі. У 1D випадку з `Δx = Δy = Δz` формула спрощується до `c · Δt / Δx ≤ 1.0`. Якщо `S > 1.0`, чисельна помилка зростає експоненціально і розрахунок розвалюється («вибухає»). Зазвичай обирають `S = 0.99` або `S = 0.5`.

### Чисельна дисперсія
Оскільки неперервний простір замінюється дискретною сіткою, фазова швидкість чисельної хвилі `v_phase` починає залежати від довжини хвилі `λ` та напрямку поширення. Дисперсійне співвідношення на сітці Йі у 1D має вигляд:

```
[ (1 / (c · Δt)) · sin(ω · Δt / 2) ]² = [ (1 / Δx) · sin(k_num · Δx / 2) ]²
```

Щоб мінімізувати викривлення форми імпульсу та фазові зсуви, просторовий крок сітки обирають за правилом:

```
Δx ≤ λ_min / 10 ... λ_min / 20
```

тобто мінімальна довжина хвилі у спектрі джерела має покриватися щонайменше 10–20 осередками сітки.

### Техніка розділення полів TFSF (Total-Field / Scattered-Field)
Для моделювання падіння плоских хвиль на розсіювальні об'єкти (антени, наночастинки, літальні апарати) використовується методологія TFSF. Вона розділяє розрахункову область віртуальною замкненою поверхнею на дві зони:

1. **Внутрішня область повної хвилі (Total-Field)**: містить як падаючу хвилю джерела `E_inc`, так і розсіяну об'єктом хвилю `E_scat`: `E_total = E_inc + E_scat`.
2. **Зовнішня область розсіяної хвилі (Scattered-Field)**: містить виключно хвилю, розсіяну об'єктом `E_scat`. Падаюча хвиля джерела математично віднімається на межі TFSF.

На межі між областями до рівнянь оновлення Йі додаються поправкові члени, обчислені за допомогою допоміжної 1D сітки падаючої хвилі. Це дозволяє генерувати ідеальні плоскі хвилі довільної тривалості без штучного відбиття від меж.

## 3. Комплексно-частотні поглинальні шари CPML та паралелізація MPI

Оскільки обчислювальна сітка має скінченний розмір `N`, на зовнішніх межах виникає відбиття хвиль назад у розрахунковий об'єм. Найсучаснішим методом поглинання є нерозщеплений комплексно-частотний шар CPML (англ. *Convolutional Perfectly Matched Layer*).

У CPML просторові похідні у рівняннях Максвелла модифікуються множниками комплексно-частотного масштабування:

```
∂ / ∂x̃ = (1 / s_x(ω)) · (∂ / ∂x)
```

де `s_x(ω) = κ_x + σ_x / (α_x + i · ω · ε₀)`.

У часовій області дія множника `1 / s_x(ω)` перетворюється на згортку за часом, яка реалізується через допоміжні рекурентні змінні `Ψ`:

```
Ezⁿ⁺¹[i] = Ca · Ezⁿ[i] + Cb · (Hyⁿ⁺¹/²[i+1/2] - Hyⁿ⁺¹/²[i-1/2]) + Cb · Ψ_Ez,xⁿ⁺¹/²[i]
```

де рекурентна змінна `Ψ` оновлюється на кожному кроці без збереження передісторії:

```
Ψ_Ez,xⁿ⁺¹/²[i] = b_x · Ψ_Ez,xⁿ⁻¹/²[i] + a_x · (Hyⁿ⁺¹/²[i+1/2] - Hyⁿ⁺¹/²[i-1/2])
```

Коефіцієнти `a_x` та `b_x` обчислюються перед початком розрахунку:

```
b_x = exp(- (σ_x / κ_x + α_x) · (Δt / ε₀))
a_x = (σ_x / (σ_x · κ_x + α_x · κ_x²)) · (b_x - 1.0)
```

CPML забезпечує коефіцієнт відбиття менше `-80 dB` при товщині шару всього у 8–12 осередків.

### Багатопроцесорна декомпозиція областей за допомогою MPI
При розрахунку великих 3D задач (понад 100 мільйонів осередків) обчислювальна область розбивається на піддомени між вузлами кластера за допомогою стандарту MPI. Обмін даними між сусідніми процесами виконується лише для граничних шарів осередків («гало-зони», англ. *halo regions*).

На кожному часовому кроці процес обмінюється тангенційними компонентами полів `E` та `H` на межі декомпозиції через неблокуючі виклики `MPI_Isend` та `MPI_Irecv`, що дозволяє суміщати передачу даних по мережі InfiniBand з обчисленнями у внутрішній частині піддомену.

## 4. Практична реалізація: C та C++

Нижче наведено повноцінні реалізації 1D FDTD солвера, які моделюють поширення гаусового електромагнітного імпульсу з центру сітки.

:::tabs
```c
/* 1D FDTD Simulation of Maxwell's Equations in Free Space (C99) */
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

#define NX 400            /* Кількість осередків просторової сітки */
#define NT 600            /* Кількість кроків за часом */
#define S_COURANT 0.99    /* Число Куранта S = c * dt / dx */

/* Фізичні константи вакууму */
static const double EPS0 = 8.854187817e-12;
static const double MU0  = 1.256637061e-6;

int main(void) {
    const double c0 = 1.0 / sqrt(EPS0 * MU0);
    const double dx = 1e-3;                   /* Крок простору: 1 мм */
    const double dt = S_COURANT * dx / c0;    /* Крок часу за умовою CFL */

    /* Виділення пам'яті під вектори полів */
    double *Ez = (double *)calloc(NX, sizeof(double));
    double *Hy = (double *)calloc(NX - 1, sizeof(double));

    if (!Ez || !Hy) {
        fprintf(stderr, "Помилка виділення пам'яті!\n");
        return 1;
    }

    /* Коефіцієнти оновлення в різницевих рівняннях */
    const double ch = dt / (MU0 * dx);
    const double ce = dt / (EPS0 * dx);

    /* Змінні для поглинальних межевих умов Мура (Mur ABC) */
    const double abc_coef = (c0 * dt - dx) / (c0 * dt + dx);
    double ez_left_prev = 0.0;
    double ez_right_prev = 0.0;

    /* Параметри Гаусового джерела у центрі сітки */
    const int src_pos = NX / 2;
    const double t0 = 40.0 * dt;
    const double tau = 12.0 * dt;

    /* Головний часловий цикл FDTD */
    for (int n = 0; n < NT; n++) {
        /* 1. Оновлення магнітного поля Hy (крок n + 1/2) */
        for (int i = 0; i < NX - 1; i++) {
            Hy[i] += ch * (Ez[i + 1] - Ez[i]);
        }

        /* Збереження граничних значень для поглинальних умов */
        ez_left_prev = Ez[1];
        ez_right_prev = Ez[NX - 2];

        /* 2. Оновлення електричного поля Ez (крок n + 1) */
        for (int i = 1; i < NX - 1; i++) {
            Ez[i] += ce * (Hy[i] - Hy[i - 1]);
        }

        /* 3. Інжекція Гаусового імпульсу джерела */
        const double time_curr = n * dt;
        const double src_val = exp(-pow((time_curr - t0) / tau, 2.0));
        Ez[src_pos] += src_val;

        /* 4. Застосування поглинальних межевих умов (Mur ABC) */
        Ez[0] = ez_left_prev + abc_coef * (Ez[1] - Ez[0]);
        Ez[NX - 1] = ez_right_prev + abc_coef * (Ez[NX - 2] - Ez[NX - 1]);

        /* Консольний моніторинг кожні 100 кроків */
        if (n % 100 == 0) {
            printf("Крок %3d / %d | Ez[src] = %+.4f | Ez[center+50] = %+.4f\n",
                   n, NT, Ez[src_pos], Ez[src_pos + 50]);
        }
    }

    free(Ez);
    free(Hy);
    return 0;
}
```
```cpp
// 1D FDTD Simulation of Maxwell's Equations using Modern C++ (C++20)
#include <iostream>
#include <vector>
#include <cmath>
#include <numbers>
#include <memory>

class FdtdSolver1D {
public:
    struct Config {
        std::size_t grid_size{400};
        std::size_t time_steps{600};
        double dx{1e-3};           // 1 мм
        double courant_factor{0.99};
    };

    explicit FdtdSolver1D(Config config)
        : cfg_(config),
          c0_(1.0 / std::sqrt(eps0_ * mu0_)),
          dt_(cfg_.courant_factor * cfg_.dx / c0_),
          Ez_(cfg_.grid_size, 0.0),
          Hy_(cfg_.grid_size - 1, 0.0)
    {
        ce_ = dt_ / (eps0_ * cfg_.dx);
        ch_ = dt_ / (mu0_ * cfg_.dx);
        abc_coef_ = (c0_ * dt_ - cfg_.dx) / (c0_ * dt_ + cfg_.dx);
    }

    void run_simulation() {
        const std::size_t src_pos = cfg_.grid_size / 2;
        const double t0 = 40.0 * dt_;
        const double tau = 12.0 * dt_;

        for (std::size_t n = 0; n < cfg_.time_steps; ++n) {
            // 1. Оновлення магнітного поля Hy
            for (std::size_t i = 0; i < Hy_.size(); ++i) {
                Hy_[i] += ch_ * (Ez_[i + 1] - Ez_[i]);
            }

            const double ez_left_prev = Ez_[1];
            const double ez_right_prev = Ez_[cfg_.grid_size - 2];

            // 2. Оновлення електричного поля Ez
            for (std::size_t i = 1; i < cfg_.grid_size - 1; ++i) {
                Ez_[i] += ce_ * (Hy_[i] - Hy_[i - 1]);
            }

            // 3. Додавання м'якого джерела випромінювання (Gaussian pulse)
            const double current_time = static_cast<double>(n) * dt_;
            const double pulse = std::exp(-std::pow((current_time - t0) / tau, 2.0));
            Ez_[src_pos] += pulse;

            // 4. Застосування межевих умов Mur ABC
            Ez_[0] = ez_left_prev + abc_coef_ * (Ez_[1] - Ez_[0]);
            Ez_[cfg_.grid_size - 1] = ez_right_prev + abc_coef_ * (Ez_[cfg_.grid_size - 2] - Ez_[cfg_.grid_size - 1]);

            if (n % 100 == 0) {
                std::cout << "Крок " << n << " / " << cfg_.time_steps
                          << " | E_max = " << Ez_[src_pos] << "\n";
            }
        }
    }

    [[nodiscard]] const std::vector<double>& get_electric_field() const noexcept {
        return Ez_;
    }

private:
    static constexpr double eps0_{8.854187817e-12};
    static constexpr double mu0_{1.256637061e-6};

    Config cfg_;
    double c0_;
    double dt_;
    double ce_{0.0};
    double ch_{0.0};
    double abc_coef_{0.0};

    std::vector<double> Ez_;
    std::vector<double> Hy_;
};

int main() {
    FdtdSolver1D::Config config{.grid_size = 400, .time_steps = 600, .dx = 1e-3, .courant_factor = 0.99};
    FdtdSolver1D solver(config);
    solver.run_simulation();
    return 0;
}
```
