# 🧮 Математичне виведення хвильового рівняння, 4-тензорного формулювання та граничних умов

Математична стрункість електродинаміки Максвелла ґрунтується на апараті векторного та тензорного аналізу, який пов'язує локальні характеристики полів (дивергенцію, ротор та 4-похідні у точці) з інтегральними потоками й циркуляціями вздовж замкнених поверхонь і контурів. У цій вставці наведено строгі математичні виведення хвильового рівняння електромагнітного поля у вакуумі, граничних умов на межі середовищ, закону збереження електромагнітної енергії (теореми Пойнтінга), тензора напружень Максвелла, калібрувально-інваріантних потенціалів, варіаційного принципу Лагранжа та 4-вимірного коваріантного формулювання у просторі Мінковського.

---

## 1. Векторні еквівалентності: від інтегралів до диференціалів

Перехід між інтегральною та диференціальною формами рівнянь Максвелла здійснюється за допомогою двох фундаментальних теорем векторного аналізу: **теореми Гаусса — Остроградського** (для дивергенції) та **теореми Стокса** (для ротора).

### Теорема Гаусса — Остроградського
Потік векторного поля `F` крізь довільну замкнену поверхню `S`, що обмежує об'єм `V`, дорівнює потрійному інтегралу від дивергенції цього поля по об'єму `V`:

```
∯_S F · dS = ∭_V (∇ · F) dV
```

Застосуємо цю теорему до закону Гаусса для електричного поля. Повний заряд `Q_encl` усередині об'єму `V` виражається через об'ємну густину заряду `ρ`:

```
∯_S D · dS = Q_encl
∭_V (∇ · D) dV = ∭_V ρ dV          [застосовано теорему Гаусса]
∭_V (∇ · D - ρ) dV = 0
```

Оскільки об'єм `V` обирається абсолютно довільно, підінтегральний вираз мусить тотожно дорівнювати нулю у кожній точці простору:

```
∇ · D = ρ
```

Аналогічно, застосовуючи теорему Гаусса до магнітного поля `∯_S B · dS = 0`, отримуємо умову відсутності магнітних зарядів у диференціальній формі:

```
∇ · B = 0
```

### Теорема Стокса
Циркуляція векторного поля `F` вздовж довільного замкненого контуру `L` дорівнює потоку ротора цього поля крізь натягнуту на контур відкриту поверхню `S`:

```
∮_L F · dl = ∬_S (∇ × F) · dS
```

Застосуємо теорему Стокса до закону електромагнітної індукції Фарадея:

```
∮_L E · dl = -d/dt ∬_S B · dS
∬_S (∇ × E) · dS = ∬_S (-∂B/∂t) · dS     [застосовано теорему Стокса]
∬_S (∇ × E + ∂B/∂t) · dS = 0
```

У силу довільності вибору поверхні `S` отримуємо диференціальне рівняння Фарадея — Максвелла:

```
∇ × E = -∂B / ∂t
```

Застосовуючи теорему Стокса до закону циркуляції Ампера — Максвелла `∮_L H · dl = ∬_S (J + ∂D/∂t) · dS`, маємо:

```
∇ × H = J + ∂D / ∂t
```

### Диференціальні оператори у криволінійних системах координат
Для розв'язання задач із циліндричною (хвилеводи, коаксіальні кабелі) або сферичною (випромінювання антен, розсіяння хвиль краплями води) симетрією векторні оператори дивергенції та ротора записуються через коефіцієнти Ламе `h_1, h_2, h_3`.

У циліндричних координатах `(r, φ, z)` дивергенція та ротор набувають вигляду:

```
∇ · F = (1/r) · ∂(r · Fr)/∂r + (1/r) · ∂Fφ/∂φ + ∂Fz/∂z

(∇ × F)_r = (1/r) · ∂Fz/∂φ - ∂Fφ/∂z
(∇ × F)_φ = ∂Fr/∂z - ∂Fz/∂r
(∇ × F)_z = (1/r) · ∂(r · Fφ)/∂r - (1/r) · ∂Fr/∂φ
```

У сферичних координатах `(r, θ, φ)` оператор дивергенції виражається формулою:

```
∇ · F = (1/r²) · ∂(r² · Fr)/∂r + (1/(r · sin θ)) · ∂(sin θ · Fθ)/∂θ + (1/(r · sin θ)) · ∂Fφ/∂φ
```

Ці вирази дозволяють розділяти змінні при розв'язанні рівнянь Максвелла методом фур'є-аналізу та виводити власні моди круглих металевих хвилеводів (TE_nm, TM_nm) і дипольного випромінювання.

## 2. Виведення тривимірного векторного хвильового рівняння

Розглянемо випадок однорідного, ізотропного та непровідного середовища або вакууму, де відсутні вільні електричні заряди (`ρ = 0`) та струми провідності (`J = 0`). Матеріальні співвідношення набувають лінійного вигляду:

```
D = ε₀ · E
B = μ₀ · H
```

Рівняння Максвелла у такій області спрощуються до симетричного вигляду:

```
(1) ∇ · E = 0
(2) ∇ · B = 0
(3) ∇ × E = -∂B / ∂t
(4) ∇ × B = μ₀ε₀ (∂E / ∂t)
```

Щоб відокремити змінні й отримати рівняння лише для електричного поля `E`, застосуємо оператор ротора `∇ ×` до обидвох частин рівняння (3):

```
∇ × (∇ × E) = ∇ × (-∂B / ∂t)
```

У лівій частині використаємо відому тотожність векторного аналізу для подвійного ротора довільного поля `A`: `∇ × (∇ × A) ≡ ∇(∇ · A) - ∇²A`. У правій частині змінимо порядок диффереціювання за часом і простором:

```
∇(∇ · E) - ∇²E = -∂/∂t (∇ × B)           [застосовано подвійний ротор]
0 - ∇²E = -∂/∂t [μ₀ε₀ (∂E / ∂t)]        [підставлено ∇·E = 0 з (1) та ∇×B з (4)]
-∇²E = -μ₀ε₀ (∂²E / ∂t²)
```

Переносячи всі члени в одну частину, отримуємо **тривимірне однорідне хвильове рівняння** для вектора напруженості електричного поля:

```
∇²E - μ₀ε₀ (∂²E / ∂t²) = 0
```

Аналогічним чином, застосовуючи оператор ротора `∇ ×` до рівняння (4), отримуємо ідентичне хвильове рівняння для вектора магнітної індукції `B`:

```
∇²B - μ₀ε₀ (∂²B / ∂t²) = 0
```

У класичній хвильовій механіці тривимірне хвильове рівняння для функції `Ψ(r, t)` з фазовою швидкістю `v` має стандартну форму:

```
∇²Ψ - (1 / v²) (∂²Ψ / ∂t²) = 0
```

Порівнюючи коефіцієнти при часовій похідній другого порядку, ми математично виводимо фазову швидкість `c` поширення електромагнітних хвиль у вакуумі:

```
1 / c² = μ₀ε₀  ⇒  c = 1 / √(μ₀ · ε₀)
```

## 3. Граничні умови на межі двох середовищ

Під час переходу електромагнітного поля крізь межу поділу двох середовищ із різними діелектричними (`ε₁, ε₂`) та магнітними (`μ₁, μ₂`) проникностями вектори полів зазнають стрибків. Граничні умови виводяться з інтегральної форми рівнянь Максвелла за допомогою граничного переходу.

```
       Середовище 1 (ε₁, μ₁)
───────────────────────────────── Межа поділу (нормаль n)
       Середовище 2 (ε₂, μ₂)
```

### Нормальні компоненти векторів індукції
Побудуємо циліндричний об'єм малого радіуса `r` та висоти `h`, орієнтований так, що його верхній торець лежить у середовищі 1, а нижній — у середовищі 2.

Для електричного зміщення `D`:
```
∯_S D · dS = Q_encl
(D₁n - D₂n) · ΔS = σ_free · ΔS     [при h → 0 бічна поверхня не дає внеску]
D₁n - D₂n = σ_free
```
де `σ_free` — поверхнева густина вільних зарядів на межі. Для двох діелектриків за відсутності вільних зарядів (`σ_free = 0`): `D₁n = D₂n`.

Для магнітної індукції `B`:
```
∯_S B · dS = 0
(B₁n - B₂n) · ΔS = 0  ⇒  B₁n = B₂n
```
Нормальна компонента магнітної індукції завжди неперервна на будь-якій межі.

### Тангенційні компоненти векторів напруженості
Побудуємо прямокутний контур довжини `Δl` та ширини `h`, який перетинає межу поділу.

Для електричного поля `E`:
```
∮_L E · dl = -d/dt ∬_S B · dS
(E₁t - E₂t) · Δl = 0               [при h → 0 потік B крізь контур прямує до 0]
E₁t = E₂t
```
Тангенційна компонента напруженості електричного поля завжди неперервна.

Для магнітного поля `H`:
```
∮_L H · dl = ∬_S (J + ∂D/∂t) · dS
(H₁t - H₂t) · Δl = K_surf · Δl     [K_surf — поверхневий струм провідності]
H₁t - H₂t = K_surf × n
```
Для ідеальних діелектриків поверхневі струми відсутні (`K_surf = 0`), тому `H₁t = H₂t`.

## 4. Закони збереження, теорема Пойнтінга та тензор напружень Максвелла

### Теорема Пойнтінга
Обчислимо скалярний добуток рівняння Фарадея на вектор `H` та рівняння Ампера — Максвелла на вектор `E`:

```
(1) H · (∇ × E) = -H · (∂B / ∂t)
(2) E · (∇ × H) = E · J + E · (∂D / ∂t)
```

Віднімемо від рівняння (1) рівняння (2) і використаємо векторну тотожність `∇ · (A × B) ≡ B · (∇ × A) - A · (∇ × B)`:

```
H · (∇ × E) - E · (∇ × H) = -H · (∂B / ∂t) - E · (∂D / ∂t) - E · J
∇ · (E × H) = -∂/∂t [1/2 (ε₀ E² + μ₀ H²)] - E · J
```

Уведемо **вектор Пойнтінга** `S` та об'ємну густину енергії `w`:

```
S = E × H                      [Густина потоку енергії, Вт/м²]
w = 1/2 (E · D + B · H)        [Об'ємна густина енергії, Дж/м³]
```

Отримуємо **диференціальну форму теореми Пойнтінга**:

```
∇ · S + ∂w / ∂t = -J · E
```

Інтегруючи по замкненому об'єму `V` і застосовуючи теорему Гаусса, отримуємо закон збереження енергії у інтегральній формі:

```
∯_S S · dS + d/dt ∭_V w dV = -∭_V (J · E) dV
```

### Густина енергії у середовищах із часовою дисперсією (Формула Бріллюена)
У середовищах, де діелектрична проникність залежить від частоти `ε(ω)`, класичний вираз `w = 1/2 ε E²` стає некоректним через теплові втрати та затримку поляризації. Для квазімонохроматичного сигналу з повільно змінюваною огинаючою `E(t) = Re[ E₀(t) exp(-i ω t) ]` Леон Бріллюен (франц. *Léon Brillouin*) вивів середню об'ємну густину енергії поля:

```
w_avg = 1/4 [ d(ω · ε)/dω · |E₀|² + d(ω · μ)/dω · |H₀|² ]
```

Похідна `d(ω · ε)/dω > ε(ω)` гарантує, що у диспергуючих середовищах (наприклад, у плазмі або металах) повна густина енергії поля залишається строго додатною величиною, навіть коли відносна діелектрична проникність стає від'ємною `ε_r < 0`.

### Тензор напружень Максвелла та збереження імпульсу
Об'ємна густина сили Лоренца, що діє на заряди та струми, дорівнює:

```
f = ρ E + J × B
```

Підставивши `ρ = ε₀ (∇ · E)` та `J = (1/μ₀)(∇ × B) - ε₀ (∂E/∂t)` і застосувавши векторні тотожності, отримуємо вираження сили через дивергенцію **тензора напружень Максвелла** `σ_ij`:

```
σ_ij = ε₀ (Ei Ej - 1/2 δ_ij E²) + 1/μ₀ (Bi Bj - 1/2 δ_ij B²)
```

де `δ_ij` — символ Кронекера (`δ_ij = 1` при `i = j`, та `0` при `i ≠ j`).

Закон збереження імпульсу системи «речовина + електромагнітне поле» у компонентній формі має вигляд:

```
f_i = ∑_j (∂σ_ij / ∂x_j) - (1 / c²) (∂S_i / ∂t)
```

де член `g_i = S_i / c²` описує об'ємну густину імпульсу самого електромагнітного поля.

## 5. Потенціали, калібрування Лоренца та запізнілі розв'язки

Оскільки `∇ · B = 0`, магнітну індукцію можна виразити через ротор **векторного потенціалу** `A`:

```
B = ∇ × A
```

Підставивши цей вираз у закон Фарадея `∇ × E = -∂(∇ × A)/∂t`, отримуємо:

```
∇ × (E + ∂A / ∂t) = 0  ⇒  E = -∇φ - ∂A / ∂t
```

де `φ` — **скалярний потенціал**. Потенціали визначені з точністю до калібрувальних перетворень:

```
A' = A + ∇χ
φ' = φ - ∂χ / ∂t
```

Застосовуючи **калібрувальну умову Лоренца**:

```
∇ · A + μ₀ε₀ (∂φ / ∂t) = 0
```

система рівнянь Максвелла розчеплюється на два незалежні тривимірні хвильові рівняння Д'Аламбера:

```
∇²φ - (1 / c²) (∂²φ / ∂t²) = -ρ / ε₀
∇²A - (1 / c²) (∂²A / ∂t²) = -μ₀ J
```

За допомогою функції Ґріна оператора Д'Аламбера `□ = ∇² - (1/c²) ∂²/∂t²` отримуємо **запізнілі розв'язки Єфіменка**:

```
φ(r, t) = (1 / (4π ε₀)) ∭ [ ρ(r', t - |r - r'|/c) / |r - r'| ] dV'
A(r, t) = (μ₀ / (4π))   ∭ [ J(r', t - |r - r'|/c) / |r - r'| ] dV'
```

Ці інтеграли описують фундаментальний фізичний факт: збурення полів поширюються у просторі зі скінченною швидкістю `c`, тому потенціал у точці `r` у момент часу `t` визначається станом джерел у віддаленій точці `r'` у попередній момент часу `t' = t - |r - r'|/c`.

## 6. Варіаційний принцип Лагранжа для електромагнітного поля

Електродинаміку Максвелла можна математично сформулювати на основі варіаційного принципу найменшої дії Гамільтона. Густина функції Лагранжа (лагрангіан) `L` для вільного електромагнітного поля та його взаємодії з 4-струмом `J_μ` дорівнює:

```
L = -1 / (4 · μ₀) · F_μν F^μν - J_μ A^μ
```

де `F_μν F^μν = 2 (B² - E²/c²)` — лоренц-інваріантний скаляр поля.

Припускаючи, що варіація 4-потенціалу `δA_μ` дорівнює нулю на межах об'єму інтегрування у просторі-часі, вимагаємо мінімуму дії `S_action = ∭ L d⁴x`:

```
δS_action = ∭ [ ∂L/∂A_ν - ∂_μ (∂L / ∂(∂_μ A_ν)) ] δA_ν d⁴x = 0
```

Обчисливши часткові похідні лагрангіана:

```
∂L / ∂A_ν = -J^ν
∂L / ∂(∂_μ A_ν) = -1 / μ₀ · F^μν
```

підставляємо їх у рівняння Ейлера — Лагранжа й отримуємо неоднорідну пару рівнянь Максвелла у коваріантній формі:

```
∂_μ F^μν = μ₀ J^ν
```

Варіаційний метод підтверджує, що рівняння Максвелла є єдино можливими лінійними релятивістськими рівняннями першого порядку для безмасового векторного поля спіну 1.

## 7. 4-вимірне коваріантне формулювання у просторі Мінковського

У Спеціальній теорії відносності 4-вимірний простір-час описується контраваріантним радіус-вектором `x^μ = (ct, x, y, z)` та метричним тензором Мінковського зі сигнатурою `(+ - - -)`:

```
η_μν = diag(1, -1, -1, -1)
```

### 4-вектори та 4-тензор полів
Скалярний `φ` та векторний `A` потенціали об'єднуються у **4-потенціал**:

```
A^μ = (φ / c, Ax, Ay, Az)
```

Густина заряду `ρ` та густина струму `J` утворюють **4-вектор струму**:

```
J^μ = (c · ρ, Jx, Jy, Jz)
```

Рівняння безперервності збереження заряду у 4-векторній формі згортається до вигляду:

```
∂_μ J^μ = 0
```

Компоненти електричного `E` та магнітного `B` полів утворюють антисиметричний **4-тензор електромагнітного поля** `F^μν = ∂^μ A^ν - ∂^ν A^μ`:

```
F^μν =
|    0       -Ex/c    -Ey/c    -Ez/c  |
|   Ex/c       0       -Bz       By   |
|   Ey/c      Bz        0       -Bx   |
|   Ez/c     -By       Bx        0    |
```

Коваріантний тензор `F_μν = η_μα η_νβ F^αβ` отримується зміною знаків компонент електричного поля: `F_0i = -F^0i`.

### Коваріантні рівняння Максвелла
Всі чотири рівняння Максвелла у 4-вимірному просторі Мінковського записуються у вигляді двох компактних тензорних рівнянь:

1. **Неоднорідна пара рівнянь** (Закон Гаусса та закон Ампера — Максвелла):
   ```
   ∂_μ F^μν = μ₀ J^ν
   ```

2. **Однорідна пара рівнянь** (Закон Гаусса для B та закон індукції Фарадея):
   ```
   ∂_μ F̃^μν = 0
   ```
   де `F̃^μν = 1/2 ε^μναβ F_αβ` — дуальний тензор електромагнітного поля, `ε^μναβ` — повністю антисиметричний одиничний тензор Леві-Чивіта у 4D.

Тензорне формулювання доводить, що рівняння Максвелла є природно інваріантними відносно лоренцевих перетворень координат і не потребують концепції абсолютного світлоносного ефіру.
