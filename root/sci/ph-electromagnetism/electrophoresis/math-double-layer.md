# 🧮 Математика подвійного електричного шару та рівняння Смолуховського

Математичний опис руху зарядженої частинки у рідкому електроліті вимагає одночасного розв'язання рівнянь електростатики та гідродинаміки в'язкої рідини. На відміну від руху заряду у вакуумі, частинка у розчині оточена хмарою протиіонів (подвійним електричним шаром), яка екранує її заряд та створює додаткове гідродинамічне гальмування.

## 1. Рівняння Пуассона — Больцмана та довжина Дебая

Розподіл електричного потенціалу `ψ(x)` біля зарядженої поверхні у 1D-напрямку `x` (перпендикулярно до поверхні) описується рівнянням Пуассона:

```
d²ψ / dx² = − ρₑ(x) / (εᵣ · ε₀)
```

де `ρₑ(x)` — об'ємна густина електричного заряду іонів у розчині, `εᵣ` — відносна діелектрична проникність розчинника (для води при 25 °C `εᵣ ≈ 78.5`), `ε₀` — електрична стала (8.854 × 10⁻¹² Ф/м).

Концентрація іонів `nᵢ(x)` у тепловій рівновазі підпорядковується розподілу Больцмана:

```
nᵢ(x) = nᵢ₀ · exp( − zᵢ · e · ψ(x) / (k_B · T) )
```

де `zᵢ` — валентність іона, `e` — елементарний заряд (1.602 × 10⁻¹⁹ Кл), `k_B` — стала Больцмана (1.381 × 10⁻²³ Дж/К), `T` — абсолютна температура.

Для симетричного 1:1 електроліту (наприклад, NaCl, де z₊ = +1, z₋ = −1) густина заряду дорівнює:

```
ρₑ(x) = e · n₀ · [ exp(− e·ψ / k_B T) − exp(e·ψ / k_B T) ]
      = − 2 · e · n₀ · sinh( e·ψ(x) / (k_B · T) )
```

Підставивши густину заряду у рівняння Пуассона, отримуємо **нелінійне рівняння Пуассона — Больцмана**:

```
d²ψ / dx² = (2 · e · n₀ / (εᵣ · ε₀)) · sinh( e · ψ(x) / (k_B · T) )
```

### Точний перший інтеграл рівняння Пуассона — Больцмана

Для знаходження точного розподілу потенціалу помножимо обидві частини рівняння на `2 · (dψ/dx)` скориставшись тотожністю `2 · (dψ/dx) · (d²ψ/dx²) = d/dx (dψ/dx)²`:

```
d/dx (dψ/dx)² = (4 · e · n₀ / (εᵣ · ε₀)) · sinh( e·ψ / (k_B·T) ) · (dψ/dx)
```

Проінтегрувавши від нескінченності (де `ψ = 0` та `dψ/dx = 0`) до точки `x`, отримуємо точний градієнт потенціалу:

```
dψ / dx = − √[ (8 · k_B · T · n₀) / (εᵣ · ε₀) ] · sinh( e · ψ / (2 · k_B · T) )
```

Знайдений вираз дозволяє обчислити повну об'ємну густину поверхневого заряду частинки `σ_M` за **формулою Ґрехема**:

```
σ_M = − ∫₀^∞ ρₑ(x) dx = εᵣ · ε₀ · (dψ/dx)|ₓ₌₀
    = √[ 8 · εᵣ · ε₀ · k_B · T · n₀ ] · sinh( e · ψ₀ / (2 · k_B · T) )
```

### Наближення Дебая — Гюккеля (слабкі потенціали)

При малих потенціалах, коли електрична енергія значна менша за теплову (|z · e · ψ| ≪ k_B · T ≈ 25.7 мВ при 298 K), можна виконати лінеаризацію `sinh(x) ≈ x`:

```
d²ψ / dx² = κ² · ψ(x)
```

де `κ` — **параметр Дебая — Гюккеля** (обернена довжина Дебая):

```
κ = √[ (2 · z² · e² · n₀) / (εᵣ · ε₀ · k_B · T) ]
```

Величина `λ_D = 1 / κ` називається **дебаївським радіусом екранування** (товщиною дифузного шару). Для молярної концентрації електроліту `C` (в моль/л) у воді при 25 °C товщина Дебая оцінюється спрощеною формулою:

```
λ_D ≈ 0.304 / √(C)   [нанометрів]
```

Наприклад, при `C = 0.1 M` (NaCl) товщина Дебая становить близько 0.96 нм, а при `C = 0.001 M` розширюється до 9.6 нм.

Розв'язок лінеаризованого рівняння з межовими умовами `ψ(0) = ψ₀` (потенціал поверхні) та `ψ(∞) = 0`:

```
ψ(x) = ψ₀ · exp( − κ · x )
```

Потенціал експоненціально спадає вглиб розчину на відстані порядку кілька `λ_D`.

## 2. Гідродинаміка електрофорезу та дзета-потенціал

Під дією зовнішнього електричного поля `E` заряджена частинка рухається в один бік, а протиіони в дифузному шарі разом із захопленою водою дрейфують у протилежний бік (електрофоретичне гальмування).

На межі між рідиною, що рухається разом із частинкою, та вільним розчином лежить **площина ковзання** (slip plane). Електричний потенціал на цій площині називається **дзета-потенціалом** (`ζ`).

### Граничний випадок Смолуховського (великі частинки, thin double layer)

Якщо радіус частинки `r` значно більший за товщину подвійного шару (`κ · r ≫ 1`), площина ковзання вважається локально плоскою. Рівняння руху рідини у шарнірно зсувному потоці Нав'є — Стокса з джоулевою електричною силою описується балансом:

```
η · (d²v / dx²) + ρₑ(x) · E = 0
```

Замінивши `ρₑ(x)` з рівняння Пуассона `ρₑ = − εᵣ ε₀ (d²ψ/dx²)`:

```
η · (d²v / dx²) − εᵣ · ε₀ · E · (d²ψ / dx²) = 0
```

Проінтегрувавши це рівняння двічі від площини ковзання (x = 0, де v = 0 відносно частинки, ψ = ζ) до вільного об'єму розчину (x → ∞, де v = −v_еф, ψ = 0), отримуємо знамениту **формулу Смолуховського**:

```
v_еф = (εᵣ · ε₀ · ζ / η) · E

μ_e = v_еф / E = (εᵣ · ε₀ · ζ) / η
```

Формула Смолуховського дивовижна тим, що електрофоретична рухливість `μ_e` **не залежить від розміру або форми частинки**, а визначається виключно дзета-потенціалом `ζ`, діелектричною проникністю `εᵣ` та в'язкістю `η`.

### Граничний випадок Гюккеля (малі частинки, thick double layer)

Якщо частинка дуже мала або розчин дуже розведений (`κ · r ≪ 1`), товщина шару Дебая набагато більша за радіус частинки. У цьому разі екранування протиіонами слабке, і частинку можна розглядати як точковий заряд `q`, що підпорядковується чистому закону Стокса:

```
q · E = 6 · π · η · r · v_еф
```

Оскільки точковий заряд зв'язаний із дзета-потенціалом співвідношенням `q = 4 · π · εᵣ · ε₀ · r · ζ`, підстановка дає **формулу Гюккеля**:

```
μ_e = (2 · εᵣ · ε₀ · ζ) / (3 · η)
```

### Загальна формула Генрі

У проміжному діапазоні розгортається **функція Генрі** `f(κ · r)`:

```
μ_e = [ (2 · εᵣ · ε₀ · ζ) / (3 · η) ] · f(κ · r)
```

- Для сферичних частинок `f(κ·r)` плавно зростає від 1.0 (при `κ·r → 0`, межа Гюккеля) до 1.5 (при `κ·r → ∞`, межа Смолуховського).
- Для циліндричних частинок (наприклад, довгих стрижнеподібних молекул ДНК) функція Генрі залежить від орієнтації стрижня відносно вектора поля `E`: при паралельній орієнтації `f = 1.5`, при перпендикулярній `f = 1.0`.

## 3. Ефект релаксації та поправка Овербека — Бута

При вищих напруженостях поля або великих значеннях дзета-потенціалу (|ζ| > 50 мВ) сферично симетрична іонна хмара не встигає миттєво відновлюватися попереду частини і розпадатися позаду неї. Час релаксації іонної хмари дорівнює:

```
τ_rel = λ_D² / D_іон
```

Оскільки за час `τ_rel` частинка встигає промігрувати на деяку відстань, вхідний шар протиіонів зміщується назад, утворюючи електричний диполь з моментом `p_ind`. Цей диполь генерує гальмівне поле `E_ind`, яке знижує видиму електрофоретичну рухливість. Поправка Овербека — Бута — Вірсеми (OBW theory) враховує ефект релаксації у вигляді множника:

```
μ_e = μ_Смолуховського · [ 1 − E_rel(ζ, κr, zᵢ) ]
```

## 4. Практичний розрахунок дрейфової швидкості

**Постановка задачі:** Колоїдна частинка білка має дзета-потенціал `ζ = −35 мВ` у водному буфері при 25 °C (`εᵣ = 78.5`, `η = 1.002 × 10⁻³ Па·с`). Радіус частинки `r = 50 нм`, товщина Дебая у розчині `λ_D = 1 нм` (`κ · r = 50 ≫ 1`). До капіляра довжиною L = 20 см прикладено напругу U = 400 В (E = 2000 В/м). Обчислити електрофоретичну рухливість та швидкість дрейфу частинки.

```
Крок 1: Переведення одиниць у систему СІ
  ζ = −0.035 В
  ε₀ = 8.854 × 10⁻¹² Ф/м
  εᵣ = 78.5
  η = 1.002 × 10⁻³ Па·с
  E = 400 В / 0.20 м = 2000 В/м

Крок 2: Застосування формули Смолуховського (оскільки κ·r = 50 ≫ 1)
  μ_e = (εᵣ · ε₀ · ζ) / η
      = (78.5 × 8.854 × 10⁻¹² × (−0.035)) / (1.002 × 10⁻³)
      = (−2.433 × 10⁻¹²) / (1.002 × 10⁻³)
      = −2.43 × 10⁻⁸ м² / (В · с)

Крок 3: Обчислення швидкості дрейфу v
  v = μ_e · E
    = −2.43 × 10⁻⁸ м²/(В·с) × 2000 В/м
    = −4.86 × 10⁻⁵ м/с = −48.6 мкм/с

Знак «мінус» означає, що негативно заряджена частинка рухається проти напрямку вектора напруженості поля E (тобто до анода).
```
