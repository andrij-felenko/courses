# 🧮 Математичний вивід поверхневих зарядів і полів у колі

Ця математична вставка містить строгий аналітичний апарат класичної електродинаміки провідників. У ній виведено потенціальні рівняння тонких провідних жил, розраховано розподіл поверхневої густини заряду `σ_s`, сформульовано граничні умови на межах матеріалів із різною електропровідністю, розраховано поля у коаксіальному кабелі та проведено інтегрування вектора Пойнтінга для резистивного елемента.

### 1. Інтегральне рівняння потенціалу та логарифмічна густина заряду

Розглянемо циліндричний провідник радіуса `r`, вісь якого збігається з просторовою кривою `C` загальної довжини `L`. Припустимо, що радіус провідника значно менший за радіус кривизни та загальну довжину контуру (`r << L`). Позначимо дугову координату вздовж провідника як `s ∈ [0, L]`.

Електричний потенціал `Φ(s)` у точці `s` на зовнішній бічній поверхні циліндра створюється розподілом лінійної густини заряду `λ(s')` вздовж усього замкненого контуру. Враховуючи симетрію циліндра, запишемо інтеграл Кулона:

```
Φ(s) = (1 / (4 · π · ε₀)) · ∫₀ᴸ [ λ(s') / sqrt((s - s')² + r²) ] ds'
```

Для аналітичного розв'язання цього інтегрального рівняння розіб'ємо інтервал інтегрування на дві окремі зони: близьку локальну область `|s' - s| ≤ δ` (де обрано масштаб `r << δ << L`) та віддалену область контуру `|s' - s| > δ`.

У близькій області значення густини заряду `λ(s')` змінюється повільно, тому його можна винести за знак інтеграла як постійний коефіцієнт `λ(s)`:

```
Φ_local(s) ≈ (λ(s) / (4 · π · ε₀)) · ∫_{-δ}^{+δ} [ 1 / sqrt(u² + r²) ] du
```

Здійснюємо інтегрування за допомогою табличного первісного інтеграла `∫ [ 1 / sqrt(u² + r²) ] du = ln(u + sqrt(u² + r²))`:

```
∫_{-δ}^{+δ} [ 1 / sqrt(u² + r²) ] du = ln( (δ + sqrt(δ² + r²)) / (-δ + sqrt(δ² + r²)) )
                                     = 2 · ln( (δ + sqrt(δ² + r²)) / r )
                                     ≈ 2 · ln( 2 · δ / r )    [ураховуючи умову δ >> r]
```

Внесок віддалених ділянок контуру `|s' - s| > δ` додає до логарифма постійний геометрічний фактор порядку `ln(L / δ)`. Додаючи локальний та віддалений внески, отримуємо, що залежність від проміжного параметра `δ` повністю скорочується, залишаючи строге логарифмічне співвідношення між потенціалом та густиною заряду:

```
Φ(s) = (λ(s) / (2 · π · ε₀)) · ln(L / r)           [логарифмічне рівняння потенціалу тонкого провідника]
```

Звідси виражаємо лінійну густину заряду `λ(s)` як функцію скалярного потенціалу `Φ(s)` відносно віддаленої точки:

```
λ(s) = [ (2 · π · ε₀) / ln(L / r) ] · Φ(s)
```

Оскільки поверхневий заряд тонкого циліндричного провідника радіуса `r` рівномірно розподілений по його бічній поверхні з периметром `2 · π · r`, перейдемо від лінійної густини заряду `λ(s)` до поверхневої густини заряду `σ_s(s)`:

```
λ(s) = 2 · π · r · σ_s(s)                          [визначення лінійної густини заряду]
σ_s(s) = λ(s) / (2 · π · r)                        [вираження поверхневої густини]
σ_s(s) = [ ε₀ / (r · ln(L / r)) ] · Φ(s)           [остаточна формула поверхневого заряду]
```

Ця формула доводить, що поверхнева густина заряду у будь-якій точці однорідного тонкого провідника строго пропорційна місцевому потенціалу `Φ(s)`. Зміна радіуса дроту `r` чи геометричної форми контуру додає лише повільну логарифмічну поправку `ln(L / r)`.

```
          Потенціал Φ(s)                  Поверхневий заряд σ_s(s)
    ───────────────────────────       ───────────────────────────────
    Високий потенціал (+V₀/2)    ───→ Позитивний заряд (σ_s > 0)
    Нульовий потенціал (0 V)     ───→ Нейтральна поверхня (σ_s = 0)
    Низький потенціал (-V₀/2)    ───→ Негативний заряд (σ_s < 0)
```

### 2. Точне рішення для коаксіальної лінії передачі

Для демонстрації строгого математичного розрахунку полів та поточної енергії розглянемо коаксіальний кабель довжиною `L`, який складається з центрального суцільного провідника радіуса `a` та зовнішньої тонкостінної оболонки внутрішнім радіусом `b > a`. Кабель живиться від джерела напруги `V₀` і навантажений на опір `R`. Через центральну жилу протікає струм `I` у напрямку `+z`, а через зовнішню оболонку протікає зворотний струм `-I` у напрямку `-z`.

Потенціал у діелектрику між провідниками (`a ≤ r ≤ b`) задовольняє двомірне рівняння Лапласа `∇²Φ = 0`:

```
(1 / r) · (d / dr) [ r · (dΦ / dr) ] = 0           [рівняння Лапласа в циліндричних координатах]
r · (dΦ / dr) = C₁                                 [перше інтегрування]
Φ(r) = C₁ · ln(r) + C₂                             [друге інтегрування]
```

Застосуємо граничні умови: потенціал центральної жили `Φ(a) = V₀`, потенціал зовнішньої оболонки `Φ(b) = 0`:

```
C₁ · ln(a) + C₂ = V₀
C₁ · ln(b) + C₂ = 0
C₁ = - V₀ / ln(b / a)                              [знаходження константи C₁]
C₂ = V₀ · ln(b) / ln(b / a)                         [знаходження константи C₂]
```

Отримуємо точний розподіл скалярного потенціалу у діелектричному зазорі кабелю:

```
Φ(r) = V₀ · [ ln(b / r) / ln(b / a) ]
```

Радіальне електричне поле `E_r(r)` обчислюється як від'ємний градієнт скалярного потенціалу по радіальній координаті `r`:

```
E_r(r) = - dΦ / dr = V₀ / [ r · ln(b / a) ]
```

Використовуючи граничну умову теореми Гаусса на бічній поверхні центрального провідника `r = a`, знайдемо точне значення поверхневої густини заряду `σ_s(a)`:

```
σ_s(a) = ε₀ · E_r(a) = (ε₀ · V₀) / [ a · ln(b / a) ]
```

Аналогічно, на внутрішній поверхні зовнішньої оболонки `r = b` утворюється негативний поверхневий заряд компенсуючої густини:

```
σ_s(b) = - ε₀ · E_r(b) = - (ε₀ · V₀) / [ b · ln(b / a) ]
```

Магнітне поле `B_θ(r)` у діелектрику створюється струмом центральної жили `I` і за теоремою про циркуляцію вектора `B` становить:

```
B_θ(r) = (μ₀ · I) / (2 · π · r)
```

Тепер розрахуємо вектор Пойнтінга `S(r)` у будь-якій точці діелектричного простору коаксіальної лінії:

```
S = (1 / μ₀) · (E × B)                             [визначення вектора Пойнтінга]
S_z(r) = (1 / μ₀) · E_r(r) · B_θ(r)                 [компонента уздовж осі z]
S_z(r) = (1 / μ₀) · [ V₀ / (r · ln(b / a)) ] · [ (μ₀ · I) / (2 · π · r) ]
S_z(r) = (V₀ · I) / [ 2 · π · ln(b / a) · r² ]
```

Інтегруємо потік вектора Пойнтінга крізь повний поперечний переріз кабелю від `r = a` до `r = b`:

```
P_transferred = ∫ₐᵇ S_z(r) · (2 · π · r) dr        [повний потік електромагнітної потужності]
              = ∫ₐᵇ [ (V₀ · I) / (2 · π · ln(b / a) · r²) ] · (2 · π · r) dr
              = [ (V₀ · I) / ln(b / a) ] · ∫ₐᵇ (1 / r) dr
              = [ (V₀ · I) / ln(b / a) ] · ln(b / a)
              = V₀ · I
```

Цей результат строгим аналітичним шляхом доводить, що 100% електромагнітної потужності `P = V₀ · I` передається крізь діелектричний зазор між провідниками за допомогою полів, створених саме поверхневими зарядами та струмами.

### 3. Граничні умови на межі поділу двох провідних середовищ

Розглянемо плоску межу поділу двох провідних матеріалів із питомими електропровідностями `σ₁`, `σ₂` та діелектричними проникностями `ε₁`, `ε₂`. Через межу у нормальному напрямку протікає стаціонарний струм густиною `J_n = J₁_n = J₂_n`.

З диференціального закону Ома `J_n = σ₁ · E₁_n = σ₂ · E₂_n` виразимо нормальні компоненти електричного поля з двох боків від межі:

```
E₁_n = J_n / σ₁
E₂_n = J_n / σ₂
```

За теоремою Гаусса для вектора електричного зсуву `D = ε · E`, вільний поверхневий заряд `σ_s_free` дорівнює стрибку нормальної компоненти `D`:

```
σ_s_free = D₂_n - D₁_n = ε₂ · E₂_n - ε₁ · E₁_n    [гранична умова для вектора D]
σ_s_free = J_n · [ (ε₂ / σ₂) - (ε₁ / σ₁) ]          [підстановка E₁_n та E₂_n]
```

Якщо перший провідник є металевою жилою (мідь, `σ₁ → ∞`, `ε₁ ≈ ε₀`), а другий — резистивним матеріалом (`σ₂ << σ₁`), формула спрощується до:

```
σ_s_free ≈ J_n · (ε₂ / σ₂) = ε₂ · E₂_n
```

Це доводить, що при переході струму у високорезистивний матеріал на граничній площині автоматично виникає поверхневий заряд, який забезпечує підтримку високої напруженості поля `E₂_n` всередині резистора.

### 4. Аналітичний розрахунок поперечного поля на вигині дроту

Розглянемо коловий вигин дроту радіуса `r` із радіусом повороту осі `R_bend >> r`. Припустимо, що уздовж дроту тече стаціонарний струм `I`. Для повороту носіїв заряду на кут `dθ` необхідна наявність поперечного електричного поля `E_transverse`.

Розкладемо поверхневий заряд на вигині у тригонометричний ряд по азимутальному куту перерізу `ϕ` (де `ϕ = 0` відповідає зовнішній стінці вигину, а `ϕ = π` — внутрішній стінці):

```
σ_s(ϕ) = σ₀ + σ_bend · cos(ϕ)
```

Поперечне електричне поле всередині дроту, утворене дипольним компонентом `σ_bend · cos(ϕ)`, дорівнює:

```
E_transverse = σ_bend / (2 · ε₀)
```

Для створення доцентрової сили, яка повертає електрон маси `m*` та заряду `e`, що рухається з дрейфовою швидкістю `v_d = J / (n · e)`, поле `E_transverse` має задовольняти рівняння руху:

```
e · E_transverse = (m* · v_d²) / R_bend
E_transverse = (m* · J²) / (e · n² · e² · R_bend)
```

Звідси отримуємо необхідну амплітуду поверхневого дипольного заряду на повороті:

```
σ_bend = [ (2 · ε₀ · m* · J²) / (n² · e³ · R_bend) ]
```

Цей розрахунок доводить, що навіть на мікроскопічному рівні квантово-механічні параметри носіїв (ефективна маса `m*` та концентрація `n`) чітко визначають величину поверхневого заряду, необхідного для здійснення повороту струму.

### 5. Повний баланс Пойнтінга для циліндричного резистора

Розглянемо резистивний циліндр радиуса `a`, довжини `L`, опору `R = L / (σ · π · a²)`. Струм `I` викликає спад напруги `V = I · R`.

Поздовжнє електричне поле усередині та на бічній поверхні резистора дорівнює:

```
E_z = V / L = (I · R) / L
```

Магнітне поле на бічній поверхні `r = a` створюється струмом `I`:

```
B_θ = (μ₀ · I) / (2 · π · a)
```

Вектор Пойнтінга на бічній поверхні спрямований радіально всередину резистора:

```
S_in = (1 / μ₀) · E_z · B_θ = (1 / μ₀) · (V / L) · [ (μ₀ · I) / (2 · π · a) ]
     = (V · I) / (2 · π · a · L)
```

Обчислимо повний потік потужності крізь бічну поверхню площею `A_side = 2 · π · a · L`:

```
P_flux = S_in · A_side = [ (V · I) / (2 · π · a · L) ] · (2 · π · a · L)
       = V · I = I² · R
```

Вивід доводить точний математичний баланс між потоком електромагнітного поля Пойнтінга з навколишнього середовища та величиною джоулевого дисипативного нагріву `I² · R`.
