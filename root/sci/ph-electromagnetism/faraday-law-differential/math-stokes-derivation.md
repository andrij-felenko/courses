# 🧮 Виведення ротора електричного поля з інтегрального закону індукції

Ця математична вставка містить строге виведення диференціальної форми закону Фарадея `∇ × E = −∂B/∂t` з макроскопічного інтегрального закону індукції за допомогою теореми Стокса, розгляд випадку рухомих та деформованих контурів через теорему переносу Рейнольдса (похідну Лі), а також детальний аналіз розкладу Гельмгольца та калібрувальних перетворень потенціалів.

## 1. Строгий граничний перехід та теорема Стокса

Перехід від макроскопічних вимірювань у колі до локальних рівнянь поля вимагає строгого застосування математичного апарату векторного аналізу.

Розглянемо макроскопічний інтегральний закон індукції Фарадея для замкненого орієнтованого контуру `∂S`, який спирає двовимірну гладку поверхню `S`:

```
∮ [∂S] E · dl = − (d / dt) ∬ [S] B · dA
```

Припустимо спочатку, що геометричний контур `∂S` є **нерухомим у просторі** та **не деформується з часом**. Оскільки межі області інтегрування `S` є абсолютно стаціонарними, операції просторового інтегрування по поверхні `S` та часового диференціювання `d/dt` є комутативними. Це дозволяє внести операцію повної похідної по часу під знак поверхневого інтеграла у вигляді часткової похідної по часу від векторного поля магнітної індукції:

```
(d / dt) ∬ [S] B(r, t) · dA = ∬ [S] (∂B(r, t) / ∂t) · dA
```

Таким чином, інтегральний закон індукції набуває наступного вигляду:

```
∮ [∂S] E · dl = − ∬ [S] (∂B / ∂t) · dA
```

Тепер застосуємо фундаментальну математичну **теорему Стокса**, яка пов'язує циркуляцію неперервно диференційовного векторного поля `E` вздовж замкненої межі `∂S` із потоком ротора цього ж поля через довільну орієнтовану поверхню `S`, що спирається на даний контур:

```
∮ [∂S] E · dl = ∬ [S] (∇ × E) · dA
```

Прирівнюючи ліві та праві частини обох рівнянь, ми приводимо їх до єдиного поверхневого інтеграла:

```
∬ [S] (∇ × E) · dA = − ∬ [S] (∂B / ∂t) · dA
```

Перенесемо обидва доданки під один підінтегральний знак:

```
∬ [S] ( ∇ × E + ∂B / ∂t ) · dA = 0
```

Ця рівність має виконуватися для **довільної** замкненої поверхні `S` з будь-якою ортогональною орієнтацією елементарного вектора площадки `dA = n dA`.

З математичного аналізу відомо важливу теорему про об'ємні та поверхневі інтеграли: якщо поверхневий інтеграл від неперервної векторної функції `F(r) = ∇ × E + ∂B/∂t` по будь-якій відкритій підповерхні `S` тотожно дорівнює нулю, то сам векторний підінтегральний вираз у кожній внутрішній точці даної області мусить тотожно дорівнювати нулю:

```
∇ × E + ∂B / ∂t = 0   ⇒   ∇ × E = − ∂B / ∂t
```

Це повністю доводить диференціальну форму закону Фарадея для стаціонарного контуру.

## 2. Локальне визначення ротора через границю циркуляції

Диференціальну форму `∇ × E = −∂B/∂t` можна також отримати безпосередньо через класичне геометричне визначення ротора у точці як граничної густини циркуляції.

Розглянемо нескінченно малий плоский майданчик `ΔS` із нормальним вектором `n`, розташований навколо обраної точки `P(x, y, z)`. За класичним математичним визначенням оператора ротора, скалярна проекція `(∇ × E) · n` на напрямок нормалі `n` дорівнює границі відношення циркуляції поля до площі майданчика при прямуванні `ΔS -> 0`:

```
(∇ × E) · n = lim[ΔS -> 0] ( 1 / ΔS ) ∮ [∂ΔS] E · dl
```

Підставимо в це вираження значення циркуляції через часову зміну магнітного потоку з макроскопічного закону Фарадея:

```
(∇ × E) · n = lim[ΔS -> 0] ( 1 / ΔS ) [ − (d / dt) ∬ [ΔS] B · n dA ]
```

Оскільки майданчик `ΔS` є нескінченно малим, значення векторного магнітного поля `B` та його часткової похідної `∂B/∂t` у межах цього майданчика можна вважати постійними і винести за знак інтеграла:

```
∬ [ΔS] (∂B / ∂t) · n dA ≈ (∂B / ∂t) · n · ΔS
```

Підставляючи цей апроксимований вираз у граничне співвідношення, отримуємо точну рівність:

```
(∇ × E) · n = lim[ΔS -> 0] ( 1 / ΔS ) [ − (∂B / ∂t) · n · ΔS ] = − (∂B / ∂t) · n
```

Оскільки це рівність виконується для трьох взаємно ортогональних напрямків нормалі `n` (вздовж декартових осей `x`, `y`, `z`), самі векторні величини є тотожно рівними у кожній точці простору:

```
∇ × E = − ∂B / ∂t
```

## 3. Рухомі та деформовані контури: теорема переносу Рейнольдса

Якщо замкнений контур `∂S(t)` рухається у просторі зі локальною швидкістю `v(r, t)` або деформується у часі, повна похідна по часу `d/dt` від магнітного потоку більше не дорівнює простій частковій похідній під підінтегральним знаком.

За **теоремою переносу Рейнольдса** (або через похідну Лі для диференціальних 2-форм) повна похідна по часу від потоку векторного поля `B` через рухому поверхню `S(t)` розкладається на дві фізично різні складові:

```
(d / dt) ∬ [S(t)] B · dA = ∬ [S(t)] (∂B / ∂t) · dA + ∮ [∂S(t)] B · (v × dl)
```

Перший доданок у правій частині відповідає локальній зміні магнітного поля у часі (індукційний внесок), а другий доданок описує замітання нових силових ліній магнітного поля при русі контуру зі швидкістю `v` (конвективний внесок).

Застосуємо циклічну векторну тотожність для мішаного скалярно-векторного добутку:

```
B · (v × dl) = − (v × B) · dl
```

Інтегральний закон Фарадея для рухомого контуру в лабораторії набуває вигляду:

```
∮ [∂S(t)] E' · dl = − ∬ [S(t)] (∂B / ∂t) · dA + ∮ [∂S(t)] (v × B) · dl
```

Перенесемо контурний інтеграл з правої частини у ліву:

```
∮ [∂S(t)] ( E' − v × B ) · dl = − ∬ [S(t)] (∂B / ∂t) · dA
```

Позначивши `E = E' − v × B` як напруженість електричного поля у нерухомій лабораторії, ми повертаємося до стандартного співвідношення Стокса:

```
∮ [∂S] E · dl = − ∬ [S] (∂B / ∂t) · dA   ⇒   ∇ × E = − ∂B / ∂t
```

Це суворо доводить, що диференціальна форма закону Фарадея `∇ × E = −∂B/∂t` залишається незмінною локальною властивістю силового поля у будь-якій нерухомій точці простору, незалежно від того, чи рухається вимірювальний макроскопічний контур.

## 4. Розклад Гельмгольца та потенціали електромагнітного поля

Згідно з фундаментальною теоремою векторного аналізу (теорема Гельмгольца), будь-яке достатньо гладке векторне поле `E(r)`, яке прямує до нуля на нескінченності, можна однозначно розкласти на суму двох ортогональних компонент — потенціальної (безвихрової) та вихрової (соленоїдальної):

```
E = E_потенціальне + E_вихрове
```

де для компонент виконуються умовою:

```
∇ × E_потенціальне = 0
∇ · E_вихрове = 0
```

Оскільки ротор потенціальної компоненти тотожно дорівнює нулю, її можна подати як градієнт скалярного електричного потенціалу `φ`:

```
E_потенціальне = − ∇φ
```

Для магнітного поля закон Гаусса `∇ · B = 0` гарантує, що магнітна індукція є суворо соленоїдальним полем. Отже, її можна виразити через ротор допоміжного векторного потенціалу `A`:

```
B = ∇ × A
```

Підставимо цей вираз у диференціальну форму закону Фарадея:

```
∇ × E = − ∂ / ∂t ( ∇ × A ) = − ∇ × ( ∂A / ∂t )
```

Перенесемо всі доданки в один бік і об'єднаємо під одним оператором ротора:

```
∇ × ( E + ∂A / ∂t ) = 0
```

Оскільки ротор вектора `E + ∂A/∂t` тотожно дорівнює нулю, цей вектор є потенціальним і його можна подати як градієнт скалярної функції `−∇φ`:

```
E + ∂A / ∂t = − ∇φ   ⇒   E = − ∇φ − (∂A / ∂t)
```

Це співвідношення є основою всього потенціального опису класичної електродинаміки. Вно розкладає повне електричне поле на кулонівську компоненту `−∇φ` та індукційну вихрову компоненту `−∂A/∂t`.

## 5. Калібрувальна інваріантність та хвильові рівняння

Векторний потенціал `A` та скалярний потенціал `φ` визначені з точністю до **калібрувальних перетворень** (Gauge Transformations). Якщо здійснити заміну:

```
A' = A + ∇Λ
φ' = φ − (∂Λ / ∂t)
```

де `Λ(r, t)` — довільна неперервно диференційовна скалярна функція, то спостережувані силові поля `B` та `E` залишаються абсолютно інваріантними:

```
B' = ∇ × ( A + ∇Λ ) = ∇ × A + 0 = B
E' = − ∇( φ − ∂Λ/∂t ) − (∂ / ∂t)( A + ∇Λ ) = − ∇φ + ∇(∂Λ/∂t) − ∂A/∂t − ∇(∂Λ/∂t) = − ∇φ − ∂A/∂t = E
```

Для спрощення рівнянь електродинаміки найчастіше використовують **калібрування Лоренца**:

```
∇ · A + (1 / c²) · (∂φ / ∂t) = 0
```

Застосування калібрування Лоренца дозволяє розчепити рівняння Максвелла у два незалежних неоднорідних хвильових рівняння для потенціалів `A` та `φ`:

```
∇² A − (1 / c²) · (∂²A / ∂t²) = − μ₀ J
∇² φ − (1 / c²) · (∂²φ / ∂t²) = − ρ / ε₀
```

Розв'язки цих рівнянь виражаються через запаздовуючі потенціали (Retarded Potentials):

```
φ(r, t) = (1 / (4π ε₀)) ∬ [V] ( ρ(r', t − R/c) / R ) dV'
A(r, t) = (μ₀ / (4π)) ∬ [V] ( J(r', t − R/c) / R ) dV'
```

де `R = |r − r'|` — відстань від джерела до точки спостереження. Це остаточно змикає математичний опарат диференційного закону Фарадея з хвильовою теорією полів.
