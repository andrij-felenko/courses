# 🧮 Математичне виведення розв'язку векторного рівняння Пуассона та зв'язок із законом Біо–Савара

Математичний апарат векторного потенціалу дозволяє звести складну систему диференціальних рівнянь першого порядку для компонент магнітного поля `B` до трьох незалежних скалярних рівнянь Пуассона, що розв'язуються за допомогою фундаментального розв'язку (функції Гріна).

## 1. Теорема Гельмгольца про розклад векторних полів

Фундаментальною математичною основою введення електромагнітних потенціалів є теорема Германа фон Гельмгольца (Helmholtz decomposition theorem). Згідно з цією теоремою, будь-яке достатньо гладке векторне поле `F(r)` у тривимірному просторі, яке спадає на нескінченності швидше за `1/r`, можна однозначно розкласти на суму двох ортогональних компонент: поздовжньої (безвихрової, irrotational) та поперечної (соленоїдальної, solenoidal):

```
F(r) = F_long(r) + F_trans(r) [розклад Гельмгольца]
```

де для поздовжньої частини ротор тотожно дорівнює нулю (`∇ × F_long = 0`), а для поперечної частини дивергенція тотожно дорівнює нулю (`∇ · F_trans = 0`).

Оскільки поздовжнє поле `F_long` є безвихровим, за теоремою Пуанкаре його завжди можна подати як градієнт скалярного потенціалу `F_long = -∇φ`. Оскільки поперечне поле `F_trans` є соленоїдальним, його завжди можна подати як ротор деякого векторного потенціалу `F_trans = ∇ × A`, причому на поле `A` можна накласти додаткову умову `∇ · A = 0`.

У випадку магнітної індукції `B` експериментально встановлено закон Гаусса `∇ · B = 0`. Це означає, що поздовжня частина магнітного поля тотожно дорівнює нулю (`B_long = 0`), а все магнітне поле є чисто поперечним (соленоїдальним):

```
B(r) = B_trans(r) = ∇ × A(r)  [представлення магнітного поля через ротор A]
```

## 2. Векторне рівняння Пуассона в калібруванні Кулона

У стаціонарному випадку (коли струми та поля не змінюються з часом) диференціальний закон Ампера пов'язує ротор магнітної індукції з густиною струму:

```
∇ × B = μ₀ J                  [диференціальний закон Ампера]
```

Підставляючи вираз магнітної індукції через векторний потенціал `B = ∇ × A` у закон Ампера, отримуємо рівняння другого порядку:

```
∇ × (∇ × A) = μ₀ J            [підстановка B = ∇ × A у закон Ампера]
```

Застосовуємо відому тотожність векторного аналізу для подвійного ротора (векторний лапласіан):

```
∇ × (∇ × A) = ∇(∇ · A) - ∇² A   [розклад подвійного ротора через градієнт дивергенції та лапласіан]
```

Підставляючи цей розклад у рівняння Ампера, отримуємо загальне рівняння для векторного потенціалу:

```
∇(∇ · A) - ∇² A = μ₀ J        [рівняння для векторного потенціалу у загальному вигляді]
```

У кулонівському калібруванні ми усуваємо калібрувальну неоднозначність векторного потенціалу, накладаючи на нього додаткову умову соленоїдальності:

```
∇ · A = 0                     [умова кулонівського калібрування]
```

При виконанні цієї умови градієнт дивергенції тотожно перетворюється на нуль (`∇(0) = 0`), і векторне диференціальне рівняння зводиться до векторного рівняння Пуассона:

```
∇² A = -μ₀ J                  [векторне рівняння Пуассона]
```

У декартовій системі координат тривимірний векторний оператор Лапласа `∇² = ∂²/∂x² + ∂²/∂y² + ∂²/∂z²` діє на кожну просторову компоненту вектора `A` повністю незалежно:

```
∇² Ax = -μ₀ Jx                [скалярне рівняння Пуассона для x-компоненти]
∇² Ay = -μ₀ Jy                [скалярне рівняння Пуассона для y-компоненти]
∇² Az = -μ₀ Jz                [скалярне рівняння Пуассона для z-компоненти]
```

## 3. Інтегрування за допомогою функції Гріна для необмеженого простору

Кожне з отриманих компонентних рівнянь має точну математичну структуру, аналогічну скалярному рівнянню Пуассона в електростатиці:

```
∇² φ = -ρ / ε₀                [електростатичне рівняння Пуассона]
```

Для знаходження розв'язку в необмеженому тривимірному просторі використовується метод функції Гріна (Green's function). Функція Гріна `G(r, r')` для оператора Лапласа визначається як розв'язок рівняння з точковим одиничним джерелом (дельта-функцією Дірака `δ(r - r')`):

```
∇² G(r, r') = -δ(r - r')      [диференціальне рівняння для функції Гріна]
```

Враховуючи сферичну симетрію точкового джерела та граничну умову затухання поля на нескінченності (`G → 0` при `|r - r'| → ∞`), розв'язком цього рівняння є класичний ньютонівсько-кулонівський потенціал:

```
G(r, r') = 1 / (4π |r - r'|)  [функція Гріна оператора Лапласа у тривимірному просторі]
```

Завдяки лінійності оператора Лапласа загальний розв'язок для довільного просторового розподілу джерел знаходиться інтегруванням згортки густини джерела з функцією Гріна:

```
A(r)
= ∫ G(r, r') · (μ₀ J(r')) d³r'       [інтеграл суперпозиції з функцією Гріна]
= (μ₀ / 4π) ∫ (J(r') / |r - r'|) d³r' [інтегральне вираження векторного потенціалу]
```

Цей інтеграл визначає значення векторного потенціалу `A` у точці спостереження `r` як зважену векторну суму елементарних внесків від усіх об'ємних елементів струму `J(r') d³r'`, інтенсивність яких спадає обернено пропорційно до відстані `|r - r'|`.

## 4. Доведення самоузгодженості калібрування Кулона (∇ · A = 0)

Перевіримо, чи дійсно отриманий інтегральний вираз для `A(r)` строго задовольняє накладену умову соленоїдальності `∇ · A = 0`. Обчислимо дивергенцію за координатами точки спостереження `r`:

```
∇ · A(r)
= ∇ · [ (μ₀ / 4π) ∫ (J(r') / |r - r'|) d³r' ]
= (μ₀ / 4π) ∫ ∇ · (J(r') / |r - r'|) d³r'     [внесення оператора дивергенції під інтеграл]
```

Оскільки оператор дивергенції `∇` диференціює лише за координатами точки спостереження `r = (x, y, z)`, а густина струму `J(r')` залежить виключно від координат джерела `r' = (x', y', z')`, застосовуємо векторне тотожнество дивергенції добутку скаляра на вектор `∇ · (f v) = f (∇ · v) + v · (∇f)`:

```
∇ · (J(r') / |r - r'|)
= (1 / |r - r'|) (∇ · J(r')) + J(r') · ∇(1 / |r - r'|)
= 0 + J(r') · ∇(1 / |r - r'|)                [оскільки ∇ · J(r') = 0 за змінними точки спостереження]
= -J(r') · ∇'(1 / |r - r'|)                  [властивість антисиметрії похідних ядра: ∇(1/R) = -∇'(1/R)]
```

Підставляючи це співвідношення під інтеграл:

```
∇ · A(r) = -(μ₀ / 4π) ∫ J(r') · ∇'(1 / |r - r'|) d³r'
```

Застосовуємо операцію інтегрування частинами у тривимірному об'ємі за допомогою векторного тотожнества `∇' · (f J) = f (∇' · J) + J · ∇'f`:

```
J(r') · ∇'(1 / |r - r'|) = ∇' · (J(r') / |r - r'|) - (∇' · J(r')) / |r - r'|
```

Підставляючи цей розклад назад у вираз для дивергенції:

```
∇ · A(r)
= -(μ₀ / 4π) ∫ ∇' · (J(r') / |r - r'|) d³r' + (μ₀ / 4π) ∫ ((∇' · J(r')) / |r - r'|) d³r'
```

Перший доданок за теоремою Остроградського–Гаусса перетворюється на поверхневий інтеграл по нескінченно віддаленій замкненій межі `S_∞`:

```
∫ ∇' · (J(r') / |r - r'|) d³r' = ∮_{S_∞} (J(r') / |r - r'|) · dS' = 0   [струми зосереджені у скінченній ділянці]
```

Другий доданок тотожно перетворюється на нуль завдяки фундаментальному рівнянню неперервності для стаціонарних електричних струмів (відсутність накопичення зарядів у часі `∂ρ/∂t = 0`):

```
∇' · J(r') = -∂ρ/∂t = 0       [умова стаціонарності струму]
```

Отже:

```
∇ · A(r) = 0 + 0 = 0          [умова калібрування Кулона виконується тотожно]
```

Це доводить, що для будь-якої замкненої локалізованої системи стаціонарних струмів отриманий інтегральний розв'язок автоматично є бездивергентним, що підтверджує строгу математичну самоузгодженість калібрування Кулона.

## 5. Виведення закону Біо–Савара взяттям ротора від векторного потенціалу

Знайдемо магнітну індукцію `B(r)` як ротор від інтегрального виразу векторного потенціалу:

```
B(r)
= ∇ × A(r)
= ∇ × [ (μ₀ / 4π) ∫ (J(r') / |r - r'|) d³r' ]
= (μ₀ / 4π) ∫ ∇ × (J(r') / |r - r'|) d³r'     [внесення ротора під інтеграл]
```

Застосовуємо векторне тотожнество для ротора добутку скалярної функції на вектор `∇ × (f v) = f (∇ × v) + (∇f) × v`:

```
∇ × (J(r') / |r - r'|)
= (1 / |r - r'|) (∇ × J(r')) + ∇(1 / |r - r'|) × J(r')
= 0 + (- (r - r') / |r - r'|³) × J(r')       [бо ∇ × J(r') = 0 за змінними r]
= (J(r') × (r - r')) / |r - r'|³              [антикомутативність векторного добутку: -a × b = b × a]
```

Підставляючи цей векторний добуток під інтеграл, отримуємо класичний диференціальний закон Біо–Савара:

```
B(r) = (μ₀ / 4π) ∫ (J(r') × (r - r')) / |r - r'|³ d³r'   [диференціальний закон Біо–Савара]
```

Для тонкого замкненого провідника зі струмом `I`, де елемент об'ємного струму `J(r') d³r'` замінюється векторним елементом контуру `I dl'`, інтеграл набуває канонічної форми:

```
B(r) = (μ₀ I / 4π) ∮ (dl' × (r - r')) / |r - r'|³        [закон Біо–Савара для лінійного контуру]
```

Таким чином, закон Біо–Савара є прямим математичним наслідком взяття ротора від інтегрального розв'язку векторного рівняння Пуассона.

## 6. Мультипольний розклад векторного потенціалу на великих відстанях

На великих відстанях від системи струмів (`|r| = r ≫ |r'| = r'`) дріб `1 / |r - r'|` можна розкласти в поліноміальний ряд за степенями малого геометричного параметра `r'/r`:

```
1 / |r - r'|
= 1 / √(r² - 2 r · r' + r'²)
= (1 / r) · [ 1 - 2 (r · r') / r² + (r'/r)² ]^(-1/2)
= (1 / r) + (r · r') / r³ + (3 (r · r')² - r² r'²) / (2 r⁵) + ...   [розклад у ряд Тейлора]
```

Підставляючи цей розклад у вираз для векторного потенціалу:

```
A(r) = A_mono(r) + A_dip(r) + A_quad(r) + ...
```

### Монопольний член (l = 0)
```
A_mono(r) = (μ₀ / 4π r) ∫ J(r') d³r'
```
Для будь-якого стаціонарного замкненого струму об'ємний інтеграл від густини струму тотожно дорівнює нулю (`∫ J d³r' = 0`). Це означає, що монопольний векторний потенціал завжди дорівнює нулю (`A_mono = 0`), що відображає фундаментальну відсутність магнітних монополів у природі.

### Дипольний член (l = 1)
```
A_dip(r) = (μ₀ / 4π r³) ∫ J(r') (r · r') d³r'
```
Застосовуючи векторне тотожнество `(r · r') J = (1/2) [ (r · r') J + (r · J) r' ] - (1/2) r × (r' × J)` та враховуючи, що інтеграл від першої симетричної частини занулюється для замкнених струмів, отримуємо:

```
∫ J(r') (r · r') d³r' = - (1 / 2) r × ∫ (r' × J(r')) d³r' = m × r / 1
```

де векторний магнітний дипольний момент системи струмів визначається як:

```
m = (1 / 2) ∫ (r' × J(r')) d³r'   [означення магнітного дипольного моменту]
```

Звідси векторний потенціал магнітного диполя набуває компактного вигляду:

```
A_dip(r) = (μ₀ / 4π) (m × r) / r³ [векторний потенціал точкового магнітного диполя]
```

Обчислюючи ротор `B = ∇ × A_dip`, знаходимо класичне поле магнітного диполя:

```
B_dip(r) = (μ₀ / 4π) [ 3 (m · r) r / r⁵ - m / r³ ]   [індукція магнітного диполя]
```

## 7. Граничні умови для векторного потенціалу на межі середовищ

На межі поділу двох середовищ із різними магнітними проникностями `μ₁` та `μ₂` векторний потенціал `A` задовольняє фундаментальні граничні умови, що випливають із неперервності фізичних полів:

1. **Неперервність вектора `A`:** Оскільки магнітна індукція `B = ∇ × A` є скінченною величиною в усьому просторі, векторний потенціал `A` не може мати стрибків (розривів першого роду). На межі розділу двох середовищ усі три компоненти векторного потенціалу є строго неперервними:
```
A₁(межа) = A₂(межа)           [неперервність векторного потенціалу]
```

2. **Стрибок похідних (ротора):** За законом Ампера стрибок тангенціальної компоненти напруженості магнітного поля `H = B / μ` визначається поверхневою густиною струму `j_surf`:
```
n × (H₂ - H₁) = j_surf
n × ( (1/μ₂) ∇ × A₂ - (1/μ₁) ∇ × A₁ ) = j_surf   [гранична умова для ротора потенціалу]
```

де `n` — одиничний вектор нормалі до поверхні поділу середовищ.

Ці граничні умови складають повну основу для аналітичного та чисельного моделювання магнітних кіл, електричних машин і трансформаторів за допомогою методу скінченних елементів (FEM).
