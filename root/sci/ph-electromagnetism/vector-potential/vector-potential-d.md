# Векторний потенціал

<preknowlist>
- [Магнітне поле](root:ph-electromagnetism/magnetic-field) — вихровий характер магнітної індукції B та відсутність магнітних зарядів.
- [Електричний потенціал](root:ph-electromagnetism/electric-potential) — скалярне поле φ, зв'язок напруженості та потенціалу в статиці E = -∇φ.
- [Закон Біо–Савара](root:ph-electromagnetism/biot-savart-law) — розрахунок індукції B через просторовий розподіл струмів.
- [Магнітний потік](root:ph-electromagnetism/magnetic-flux) — потік індукції B крізь поверхню та теорема Стокса.
- [Калібрувальна симетрія](root:ph-electromagnetism/gauge-symmetry) — інваріантність фізичних полів щодо перетворень потенціалів.
</preknowlist>

Оскільки дивергенція магнітної індукції в кожній точці простору тотожно дорівнює нулю (`∇ · B = 0`), магнітні силові лінії не мають ані джерел, ані стоків — вони завжди утворюють нерозривні замкнені петлі. Ця експериментальна відсутність магнітних зарядів (монополів) унеможливлює опис магнітного поля за допомогою простого скалярного потенціалу, як це робиться в електростатиці. Навколо будь-якого провідника зі струмом циркуляція магнітного поля не дорівнює нулю (`∮ B · dl = μ₀ I ≠ 0`), тому робота магнітних сил залежить від шляху переміщення, а спроба ввести скалярний магнітний потенціал призводить до нескінченної багатозначності після кожного повного обходу струму. Проте фундаментальна теорема векторного аналізу стверджує: будь-яке векторне поле з нульовою дивергенцією завжди можна тотожно подати як ротор іншого допоміжного векторного поля `A`. Це поле називається векторним потенціалом магнітного поля (`B = ∇ × A`).

Векторний потенціал `A` спрощує розрахунок тривимірних магнітних полів, перетворюючи систему зв'язаних векторних рівнянь першого порядку на незалежні рівняння Пуассона або хвильові рівняння. Водночас у квантовій фізиці векторний потенціал виявляється не просто математичною зручністю, а фундаментальною локальною характеристикою поля, яка безпосередньо взаємодіє з квантовою фазою хвильової функції частинок.

## 1. Неможливість скалярного опису та виникнення векторного потенціалу

В електростатиці напруженість електричного поля `E` є безвихровою (`∇ × E = 0`). За теоремою Стокса циркуляція вектора `E` вздовж будь-якого замкненого контуру дорівнює нулю, а робота з переміщення заряду між двома точками не залежить від форми траєкторії. Це дозволяє однозначно ввести скалярний електричний потенціал `φ` (scalar potential), пов'язаний із полем співвідношенням `E = -∇φ`. Скалярний потенціал значно спрощує розрахунки: замість трьох компонент вектора `E` достатньо знайти одну скалярну функцію координат `φ(x, y, z)`.

Спроба застосувати такий самий підхід до магнітного поля стикається з принциповою фізичною перешкодою. За законом повного струму Ампера циркуляція вектора магнітної індукції `B` вздовж замкненого контуру `L`, що охоплює провідник зі струмом `I`, завжди дорівнює добутку магнітної сталої на повний охоплений струм:

```
∮_L B · dl = μ₀ · I           [циркуляція магнітної індукції за законом Ампера]
```

Якщо формально припустити існування скалярного магнітного потенціалу `ψ_m`, такого що `B = -∇ψ_m`, то інтеграл від градієнта по замкненому контуру повинен був би дорівнювати нулю:

```
∮_L B · dl = - ∮_L ∇ψ_m · dl = ψ_m(початок) - ψ_m(кінець) = 0   [суперечність із законом Ампера]
```

Отримуємо пряму математичну суперечність: нуль дорівнює `μ₀ I`. Якщо ми обійдемо провідник зі струмом один раз, скалярний потенціал зміниться на `μ₀ I`, після другого обходу — на `2 μ₀ I`, а після `N` обходів — на `N μ₀ I`. Скалярний магнітний потенціал виявляється багатозначною функцією просторових координат, якою неможливо користуватися в областях, де протікають струми. Хоча в обмежених ділянках простору без струмів (`J = 0`) магнітне поле дійсно є локально потенціальним (`∇ × B = 0`), глобально в усьому просторі ввести однозначний скалярний потенціал неможливо.

Вихід із цього глухого кута дає друге рівняння Максвелла — закон відсутності магнітних зарядів (теорема Гаусса для магнітного поля):

```
∇ · B = 0                     [диференціальна форма закону Гаусса для магнетизму]
```

У векторному аналізі існує фундаментальне диференціальне тотожнество: дивергенція від ротора будь-якого двічі неперервно диференційовного векторного поля `A(r)` тотожно дорівнює нулю:

```
∇ · (∇ × A)
= ∂/∂x (∂Az/∂y - ∂Ay/∂z) + ∂/∂y (∂Ax/∂z - ∂Az/∂x) + ∂/∂z (∂Ay/∂x - ∂Ax/∂y)
= ∂²Az/∂x∂y - ∂²Ay/∂x∂z + ∂²Ax/∂y∂z - ∂²Az/∂y∂x + ∂²Ay/∂z∂x - ∂²Ax/∂z∂y
= 0                           [тотожне скорочення мішаних похідних]
```

За теоремою Пуанкаре та загальною теоремою розкладу Гельмгольца умова `∇ · B = 0` є не лише необхідною, але й достатньою для того, щоб у будь-якій однозв'язній просторовій області векторне поле `B` можна було подати як ротор деякого іншого векторного поля:

```
B = ∇ × A                     [вираження магнітної індукції через векторний потенціал]
```

Векторне поле `A(r)` отримало назву векторного потенціалу (vector potential, від латинського *vector* — «той, що несе», та *potentialis* — «дієвий, спроможний»). Оскільки рівність `∇ · (∇ × A) = 0` виконується автоматично для будь-якого поля `A`, рівняння `∇ · B = 0` задовольняється тотожно, що гарантує відсутність ізольованих магнітних монополів у всій електродинаміці.

## 2. Геометрія векторного потенціалу та зв'язок із магнітним потоком

Як просторово орієнтований векторний потенціал `A` відносно струмів та ліній магнітної індукції `B`?

У стаціонарному кулонівському калібруванні лінії векторного потенціалу `A` у просторі завжди спрямовані паралельно до ліній густини електричного струму `J`, який породжує це поле. Якщо струм тече вздовж прямого довгого провідника вертикально вгору вздовж осі `z` (`J = Jz · e_z`), векторний потенціал також має лише вертикальну компоненту `A = Az · e_z`, спрямовану вгору.

Ротор від такого вертикально спрямованого векторного поля `A` створює поле індукції `B = ∇ × A`, лінії якого утворюють концентричні горизонтальні кола в площині `xy`, закручуючись навколо осі провідника за правилом правого гвинта.

Якщо ж струм протікає по круговому кільцю радіуса `R` у горизонтальній площині, векторний потенціал `A` циркулює по концентричних кільцях у тій самій горизонтальній площині співнапрямлено зі струмом. Обчислення ротора `∇ × A` від такого азимутального поля дає вихрове поле магнітної індукції `B`, що пронизує центральну частину кільця вертикально вгору та замикається зовні кільця вниз.

![Геометричний зв'язок струму I, векторного потенціалу A та індукції B](/root/sci/ph-electromagnetism/vector-potential/img/fig1-vector-potential-geometry.svg)
*Векторний потенціал A циркулює паралельно до ліній струму, а його ротор створює соленоїдальне поле індукції B.*

Глибокий геометричний та фізичний зміст векторного потенціалу розкривається через поняття магнітного потоку `Φ` (magnetic flux). Нехай у просторі задана довільна відкрита орієнтована поверхня `S`, обмежена замкненим контуром `L = ∂S`. За означенням, магнітний потік крізь поверхню `S` дорівнює поверхневому інтегралу від вектора індукції `B`:

```
Φ = ∬_S B · dS                [означення магнітного потоку крізь поверхню S]
```

Підставляючи вираз `B = ∇ × A` та застосовуючи фундаментальну теорему Стокса для циркуляції векторного поля:

```
Φ
= ∬_S (∇ × A) · dS            [підстановка B = ∇ × A]
= ∮_{∂S} A · dl               [теорема Стокса: потік ротора дорівнює циркуляції]
```

Магнітний потік крізь будь-яку поверхню `S` тотожно дорівнює лінійній циркуляції векторного потенціалу `A` вздовж замкненої межі `∂S` цієї поверхні.

Це дає фундаментальну геометричну інтерпретацію: якщо магнітне поле `B` є «густиною вихорів» у кожній точці, то векторний потенціал `A` є «лінійною мірою» сумарного магнітного потоку, що пронизує контур. Значення циркуляції `∮ A · dl` не залежить від вибору форми натягнутої на контур поверхні `S`, оскільки для замкненої об'ємної оболонки інтеграл від соленоїдального поля `B` завжди дорівнює нулю.

Розглянемо циліндричний нескінченно довгий соленоїд радіуса `R_sol` із поздовжнім однорідним магнітним полем `B_0` усередині. Повний магнітний потік крізь соленоїд дорівнює `Φ = π R_sol² B_0`. Застосуємо теорему Стокса для кругового контуру радіуса `r` зовні соленоїда (`r > R_sol`):

```
∮ A · dl = A_θ · (2π r) = Φ
A_θ(r) = Φ / (2π r) = (B_0 R_sol²) / (2 r)   [векторний потенціал зовні соленоїда]
```

Поза соленоїдом магнітна індукція строго дорівнює нулю (`B = 0`), оскільки ротор від поля, що спадає як `1/r` у циліндричних координатах, тотожно занулюється:

```
(∇ × A)_z = (1/r) ∂(r A_θ)/∂r = (1/r) ∂(Φ / 2π)/∂r = 0   [нульова індукція зовні соленоїда]
```

Проте сам векторний потенціал `A_θ` зовні не дорівнює нулю. Це демонструє разючу нелокальність: векторний потенціал відчуває весь магнітний потік, зосереджений усередині соленоїда, навіть у тих віддалених областях простору, куди жодна лінія магнітної індукції не проникає.

## 3. Диференціальні рівняння для A та калібрувальна інваріантність

Підставимо векторний потенціал у закон Ампера для стаціонарних полів `∇ × B = μ₀ J`:

```
∇ × (∇ × A) = μ₀ J            [диференціальний закон Ампера для потенціалу]
```

Використовуючи тотожність векторного аналізу `∇ × (∇ × A) = ∇(∇ · A) - ∇² A`, перепишемо це рівняння у формі:

```
∇(∇ · A) - ∇² A = μ₀ J        [рівняння для векторного потенціалу у розгорнутому вигляді]
```

У цьому рівнянні векторний потенціал входить одночасно через свій векторний лапласіан `∇² A` та через градієнт дивергенції `∇(∇ · A)`. Ця складна структура пов'язана з тим, що саме лише співвідношення `B = ∇ × A` не фіксує векторний потенціал `A` однозначно.

Припустимо, що ми замінили векторний потенціал `A` на нове поле `A'`, додавши до нього градієнт довільної двічі диференційовної скалярної функції `λ(x, y, z)`:

```
A' = A + ∇λ                   [калібрувальне перетворення векторного потенціалу]
```

Обчислимо індукцію магнітного поля `B'` для нового векторного потенціалу:

```
B' = ∇ × A'
= ∇ × (A + ∇λ)
= ∇ × A + ∇ × (∇λ)            [лінійність оператора ротора]
= B + 0 = B                   [властивість: ∇ × (∇λ) тотожно дорівнює 0]
```

Оскільки ротор від градієнта будь-якої скалярної функції тотожно дорівнює нулю, додавання до `A` градієнтного доданка `∇λ` взагалі не змінює фізичного магнітного поля `B`. Ця фундаментальна математична свобода називається калібрувальною інваріантністю (gauge invariance).

![Калібрувальна свобода векторного потенціалу](/root/sci/ph-electromagnetism/vector-potential/img/fig2-gauge-freedom.svg)
*Додавання довільного градієнта ∇λ змінює геометрію векторного потенціалу, але залишає магнітну індукцію B незмінною завдяки тотожності ∇ × ∇λ = 0.*

Оскільки ми маємо право вільно вибирати калібрувальну функцію `λ`, ми можемо накласти на векторний потенціал `A` додаткову диференціальну умову, яка спростить рівняння поля.

У магнітостатиці найзручнішим є кулонівське калібрування (Coulomb gauge), у якому векторний потенціал обирають строго соленоїдальним:

```
∇ · A = 0                     [умова калібрування Кулона]
```

Якщо початковий векторний потенціал мав ненульову дивергенцію `∇ · A = f(r) ≠ 0`, ми завжди можемо знайти таку калібрувальну функцію `λ`, яка занулить дивергенцію нового поля `A' = A + ∇λ`:

```
∇ · A' = ∇ · (A + ∇λ) = ∇ · A + ∇² λ = 0
∇² λ = -f(r)                  [рівняння Пуассона для калібрувальної функції λ]
```

Це скалярне рівняння Пуассона завжди має єдиний регулярний розв'язок для спадних на безмежності джерел.

Підставляючи умову кулонівського калібрування `∇ · A = 0` у рівняння Ампера, отримуємо зникнення члена `∇(∇ · A) = ∇(0) = 0`, і складне векторне рівняння вироджується у векторне рівняння Пуассона (Poisson equation):

```
∇² A = -μ₀ J                  [векторне рівняння Пуассона для A у калібруванні Кулона]
```

У декартовій системі координат це рівняння розпадається на три повністю незалежні скалярні рівняння Пуассона для кожної просторової компоненти:

```
∇² Ax = -μ₀ Jx
∇² Ay = -μ₀ Jy
∇² Az = -μ₀ Jz
```

Кожне з цих трьох рівнянь має таку саму математичну структуру, як і рівняння Пуассона для електростатичного скалярного потенціалу `∇² φ = -ρ / ε₀`. Інтегральний розв'язок для необмеженого простору з нульовими граничними умовами на нескінченності знаходиться за допомогою функції Гріна:

```
A(r) = (μ₀ / 4π) ∫ (J(r') / |r - r'|) d³r'   [інтегральний розв'язок для векторного потенціалу]
```

Для тонкого лінійного провідника зі струмом `I`, де об'ємний елемент струму `J(r') d³r'` замінюється на `I dl'`, інтеграл спрощується до одновимірного контурного інтегрування:

```
A(r) = (μ₀ · I / 4π) ∮ (dl' / |r - r'|)      [векторний потенціал тонкого замкненого контуру]
```

На межі поділу двох магнітних середовищ векторний потенціал задовольняє важливі граничні умови: він є всюди неперервним (`A₁ = A₂`), а стрибок нормальної похідної пов'язаний із поверхневою густиною струму.

Повний математичний вивід функції Гріна, доведення збереження умови `∇ · A = 0`, граничні умови та мультипольний розклад наведено у вставці [🧮 Математичне виведення розв'язку векторного рівняння Пуассона](root:ph-electromagnetism/vector-potential/math-vector-potential-poisson.md).

## 4. Векторний потенціал у типових фізичних конфігураціях

Розглянемо аналітичний вигляд векторного потенціалу для базових електромагнітних систем, що найчастіше зустрічаються в теоретичній фізиці та радіотехніці.

### 1. Прямий циліндричний провідник зі струмом
Нехай по нескінченному прямому циліндричному дроту радіуса `R_0` протікає рівномірно розподілений постійний струм `I` вздовж осі `z` з густиною `Jz = I / (π R_0²)`. Завдяки осьовій симетрії векторний потенціал має лише `z`-компоненту `A = Az(r) e_z`, що залежить виключно від циліндричного радіуса `r`.

Рівняння Пуассона в циліндричних координатах має вигляд:

```
(1 / r) d/dr (r dAz/dr) = -μ₀ Jz
```

Інтегруючи це диференціальне рівняння з граничною умовою неперервності потенціалу та його похідної на поверхні провідника `r = R_0`, отримуємо розподіл векторного потенціалу:

```
Az(r) = - (μ₀ I / 4π) · (r / R_0)²               [всередині провідника: r ≤ R_0]
Az(r) = - (μ₀ I / 2π) · ln(r / R_0) - (μ₀ I / 4π) [зовні провідника: r > R_0]
```

Обчислюючи магнітну індукцію `B = ∇ × A = - (dAz/dr) e_θ`, знаходимо класичні формули закону повного струму:

```
B_θ(r) = (μ₀ I r) / (2π R_0²)   [лінійне зростання поля всередині провідника]
B_θ(r) = (μ₀ I) / (2π r)        [гіперболічний спад поля зовні провідника]
```

### 2. Однорідне магнітне поле
Для однорідного магнітного поля `B = B_0 e_z`, спрямованого вздовж осі `z`, векторний потенціал можна вибрати кількома різними способами залежно від розв'язуваної задачі:

1. **Симетричне калібрування (symmetric gauge):**
```
A_sym = (1 / 2) · (B × r) = (1 / 2) · (-B_0 y, B_0 x, 0)
```
Це калібрування зберігає обертальну симетрію навколо осі `z` і є найбільш природним для опису кругового руху заряджених частинок у циклотронах та спектрометрах.

2. **Калібрування Ландау (Landau gauge):**
```
A_Landau = (-B_0 y, 0, 0)   або   A_Landau = (0, B_0 x, 0)
```
Це калібрування розриває обертальну симетрію на користь трансляційної інваріантності вздовж однієї з осей. Саме в калібруванні Ландау розв'язується квантове рівняння Шредінгера для електрона в магнітному полі, що дозволяє отримати дискретні енергетичні рівні Ландау та пояснити квантовий ефект Холла.

Перевіримо, що обидва калібрування дійсно описують одне й те саме поле `B`:

```
∇ × A_sym = (0, 0, ∂Ay/∂x - ∂Ax/∂y) = (0, 0, B_0/2 - (-B_0/2)) = (0, 0, B_0)
∇ × A_Landau = (0, 0, 0 - (-B_0)) = (0, 0, B_0)
```

Калібрувальна функція, що переводить симетричне калібрування в калібрування Ландау `A_Landau = A_sym + ∇λ`, дорівнює `λ(x, y) = - (1 / 2) B_0 x y`.

## 5. Часово-змінні поля, хвильові рівняння та калібрування Лоренца

Коли електромагнітні поля змінюються з часом, класичний електростатичний зв'язок `E = -∇φ` порушується через закон електромагнітної індукції Фарадея:

```
∇ × E = -∂B/∂t                [диференціальний закон індукції Фарадея]
```

Підставимо у закон Фарадея вираз магнітної індукції через векторний потенціал `B = ∇ × A`:

```
∇ × E = -∂(∇ × A)/∂t = -∇ × (∂A/∂t)   [перестановка просторових і часових похідних]
```

Перенесемо всі доданки в ліву частину:

```
∇ × (E + ∂A/∂t) = 0           [безвихровий характер узагальненого електричного поля]
```

Оскільки ротор комбінованого векторного поля `E + ∂A/∂t` тотожно дорівнює нулю у всьому просторі, за теоремою Гельмгольца це поле можна однозначно виразити як градієнт деякого скалярного потенціалу `-∇φ`.

Звідси випливає фундаментальний вираз для напруженості електричного поля у часово-змінній електродинаміці:

```
E = -∇φ - ∂A/∂t               [повний зв'язок електричного поля з потенціалами]
```

Електричне поле тепер складається з двох компонент: потенційної частини `-∇φ`, породженої розподілом електричних зарядів, та індукційної вихрової частини `-∂A/∂t`, викликаної зміною магнітного векторного потенціалу в часі.

При часово-залежних полях калібрувальне перетворення вимагає одночасної узгодженої зміни як векторного, так і скалярного потенціалів:

```
A' = A + ∇λ                   [калібрувальне перетворення векторного потенціалу]
φ' = φ - ∂λ/∂t                [калібрувальне перетворення скалярного потенціалу]
```

Перевіримо напруженість електричного поля після такого сумісного перетворення:

```
E' = -∇φ' - ∂A'/∂t
= -∇(φ - ∂λ/∂t) - ∂(A + ∇λ)/∂t
= -∇φ + ∇(∂λ/∂t) - ∂A/∂t - ∇(∂λ/∂t)   [скорочення мішаних градієнтних членів]
= -∇φ - ∂A/∂t = E             [інваріантність спостережуваного електричного поля]
```

Підставимо вирази для `E` та `B` через потенціали `(φ, A)` у повну систему рівнянь Максвелла:

1. Рівняння Гаусса для електричного поля `∇ · E = ρ / ε₀`:
```
∇ · (-∇φ - ∂A/∂t) = ρ / ε₀
-∇² φ - ∂(∇ · A)/∂t = ρ / ε₀  [перше зв'язане рівняння для потенціалів]
```

2. Закон Ампера–Максвелла зі струмом зміщення `∇ × B = μ₀ J + μ₀ ε₀ ∂E/∂t`:
```
∇ × (∇ × A) = μ₀ J + μ₀ ε₀ ∂(-∇φ - ∂A/∂t)/∂t
∇(∇ · A) - ∇² A = μ₀ J - μ₀ ε₀ ∇(∂φ/∂t) - μ₀ ε₀ ∂²A/∂t²
∇² A - (1/c²) ∂²A/∂t² - ∇(∇ · A + (1/c²) ∂φ/∂t) = -μ₀ J   [друге рівняння, де c² = 1/(μ₀ ε₀)]
```

Ці два рівняння виявляються перехресно зв'язаними між собою через наявність доданків `∂(∇ · A)/∂t` та `∇(∂φ/∂t)`. Щоб повністю розчепити ці рівняння на незалежні хвильові процеси, застосовують релятивістськи інваріантне калібрування Лоренца (Lorenz gauge), назване на честь данського фізика Людвіга Лоренца:

```
∇ · A + (1 / c²) ∂φ/∂t = 0    [умова калібрування Лоренца]
```

При накладанні умови Лоренца перехресні зв'язки в обох рівняннях повністю зникають, і система Максвелла зводиться до двох незалежних неоднорідних хвильових рівнянь (рівнянь Даламбера):

```
∇² φ - (1 / c²) ∂²φ/∂t² = -ρ / ε₀   [хвильове рівняння для скалярного потенціалу]
∇² A - (1 / c²) ∂²A/∂t² = -μ₀ J     [хвильове рівняння для векторного потенціалу]
```

Розв'язками цих хвильових рівнянь є запізнілі потенціали (retarded potentials), які описують електромагнітне випромінювання та поширення хвиль зі швидкістю світла `c`:

```
A(r, t) = (μ₀ / 4π) ∫ (J(r', t - |r - r'| / c) / |r - r'|) d³r'   [запізнілий векторний потенціал]
φ(r, t) = (1 / 4πε₀) ∫ (ρ(r', t - |r - r'| / c) / |r - r'|) d³r'   [запізнілий скалярний потенціал]
```

У релятивістській 4-вимірній формі Мінковського потенціали об'єднуються в єдиний 4-вектор потенціалу `A^μ = (φ/c, A)`, а умова калібрування Лоренца набуває компактного коваріантного вигляду `∂_μ A^μ = 0`. Антисиметричний 4-тензор електромагнітного поля `F^μν` визначається виключно через 4-потенціал як `F^μν = ∂^μ A^ν - ∂^ν A^μ`.

## 6. Фізичний статус векторного потенціалу: ефект Ааронова–Бома

У класичній механіці Ньютона та рівняннях сили Лоренца `F = q(E + v × B)` векторний потенціал `A` вважався чисто допоміжним математичним інструментом. Оскільки будь-яке вимірювання сили на класичній траєкторії частинки залежить лише від локальних значень `E` та `B`, у класичній фізиці стверджувалося, що «реальними» є виключно напруженості полів, а потенціал `A` позбавлений безпосереднього фізичного змісту через калібрувальну неоднозначність `A → A + ∇λ`.

Проте у квантовій механіці ситуація кардинально змінюється. Стан квантової частинки описується комплексною хвильовою функцією `Ψ(r, t)`. При переході від класичної механіки до квантової узагальнений канонічний імпульс частинки з масою `m` і електричним зарядом `q` набуває вигляду:

```
P = p_мех + q · A = m · v + q · A   [канонічний імпульс у присутності векторного потенціалу]
```

Гамільтоніан взаємодії зарядженої частинки з електромагнітним полем має вигляд:

```
H = (1 / 2m) (P - q A)² + q φ       [класичний гамільтоніан частинки у полі]
```

Під час квантування оператор канонічного імпульсу замінюється просторовим градієнтом `P → -i ℏ ∇`. Рівняння Шредінгера для електрона у векторному потенціалі `A` записується через подовжену коваріантну похідну:

```
(1 / 2m) (-i ℏ ∇ - q A)² Ψ + q φ Ψ = i ℏ ∂Ψ/∂t   [рівняння Шредінгера з векторним потенціалом]
```

У 1959 році Якір Ааронов та Девід Бом опублікували фундаментальну статтю, у якій довели, що векторний потенціал `A` викликає спостережувані квантові явища навіть у таких областях простору, де вектори магнітної індукції `B` та електричної напруженості `E` тотожно дорівнюють нулю!

![Ефект Ааронова–Бома](/root/sci/ph-electromagnetism/vector-potential/img/fig3-aharonov-bohm.svg)
*Квантові електрони відчувають різницю фаз через векторний потенціал A в ділянці простору, де індукція B тотожно дорівнює нулю.*

Розглянемо схему експерименту Ааронова–Бома:
1. У просторі встановлено довгий тонкий циліндричний соленоїд або магнітний тор радіуса `R_sol`.
2. Усередині соленоїда протікає постійний струм, який створює всередині однорідне магнітне поле `B ≠ 0` із сумарним магнітним потоком `Φ_B`.
3. Зовні соленоїда магнітне поле спадає до нуля (`B = 0` при `r > R_sol`).
4. Повний магнітний потік дорівнює циркуляції векторного потенціалу по контуру радіуса `r > R_sol`:
```
Φ_B = ∮ A · dl = A_θ · (2π r)
A_θ(r) = Φ_B / (2π r)         [векторний потенціал зовні ідеального соленоїда]
```

Хоча магнітна індукція зовні дорівнює нулю (`B = ∇ × A = 0`), сам векторний потенціал `A_θ ≠ 0` спадає як `1/r` і не може бути занулений у всій області одночасно.

Когерентний пучок електронів розщеплюється на два рукави: шлях 1 проходить над соленоїдом, а шлях 2 — під соленоїдом, після чого обидва пучки зводяться разом на екрані детектора для спостереження інтерференції.

Вздовж усього шляху електронів `B = 0` та `E = 0`, тому класична сила Лоренца, що діє на електрон, тотожно дорівнює нулю (`F = 0`). Електрони не зазнають жодного класичного прискорення чи відхилення.

Проте векторний потенціал модифікує фазу хвильової функції електрона. Вздовж траєкторії фазовий набіг становить:

```
Ψ_1 = Ψ_0 · exp( (i q / ℏ) ∫_{шлях 1} A · dr )
Ψ_2 = Ψ_0 · exp( (i q / ℏ) ∫_{шлях 2} A · dr )
```

Коли пучки перетинаються на екрані, результуюча різниця фаз між двома квантовими хвилями визначається замкненим контурним інтегралом:

```
Δθ = (q / ℏ) [ ∫_{шлях 1} A · dr - ∫_{шлях 2} A · dr ]
= (q / ℏ) ∮_{L_1 - L_2} A · dl
= (q / ℏ) ∬_S (∇ × A) · dS
= (q / ℏ) Φ_B                 [квантовий фазовий зсув Ааронова–Бома]
```

Різниця фаз `Δθ` пропорційна повному магнітному потоку `Φ_B`, схованому всередині соленоїда. Цей фазовий зсув призводить до чіткого зміщення інтерференційних максимумів і мінімумів на екрані.

Зверніть увагу: хоча сам векторний потенціал `A` є калібрувально неоднозначним (`A → A + ∇λ`), замкнений контурний інтеграл `∮ A · dl = ∮ (A + ∇λ) · dl = ∮ A · dl + [λ(кін) - λ(поч)] = ∮ A · dl` є строго калібрувально інваріантною фізичною величиною!

Ефект Ааронова–Бома лежить в основі функціонування надпровідних квантових інтерферометрів (СКВІД, SQUID — Superconducting Quantum Interference Device) та квантування магнітного потоку в надпровідниках кратно фундаментальному кванту потоку `Φ₀ = h / (2e) ≈ 2.0678 · 10⁻¹⁵` Вб.

Історію протистояння концепцій поля та потенціалу від Фарадея і Максвелла до експериментів Тономури детально розкрито у вставці [📜 Еволюція концепції векторного потенціалу](root:ph-electromagnetism/vector-potential/hist-maxwell-vector-potential.md).

## 7. Розрахунковий приклад: векторний потенціал та індукція кругового струму

Розглянемо практичний алгоритм чисельного розрахунку тривимірного поля векторного потенціалу `A` та магнітної індукції `B = ∇ × A` для тонкого кругового витка радіуса `R = 0.1` м, розташованого в площині `xy`, по якому тече постійний струм `I = 10` А.

Для будь-якої точки спостереження `r = (x, y, z)` розбиваємо коло на `N = 1000` сегментів:

```
x_k = R · cos(θ_k),  y_k = R · sin(θ_k),  z_k = 0
dl_k = (-R · sin(θ_k) · Δθ,  R · cos(θ_k) · Δθ,  0)
```

Векторний потенціал обчислюється чисельним інтегруванням:

```
A(r) = (μ₀ · I / 4π) ∑_{k=0}^{N-1} (dl_k / |r - r_k|)
```

А компоненти магнітної індукції `B` визначаються через центральні скінченні різниці з просторовим кроком `h = 10⁻⁴` м:

```
Bx = (Az(y+h) - Az(y-h)) / (2h) - (Ay(z+h) - Ay(z-h)) / (2h)
By = (Ax(z+h) - Ax(z-h)) / (2h) - (Az(x+h) - Az(x-h)) / (2h)
Bz = (Ay(x+h) - Ay(x-h)) / (2h) - (Ax(y+h) - Ax(y-h)) / (2h)
```

Нижче наведено робочі реалізації алгоритму мовами C та C++:

```c
#include <stdio.h>
#include <math.h>

#ifndef M_PI
#define M_PI 3.14159265358979323846
#endif

#define MU_0 (4.0 * M_PI * 1e-7)

typedef struct {
    double x, y, z;
} Vec3;

Vec3 compute_A(Vec3 r, double R, double I, int N) {
    Vec3 a = {0.0, 0.0, 0.0};
    double dtheta = 2.0 * M_PI / (double)N;

    for (int k = 0; k < N; ++k) {
        double theta = (double)k * dtheta;
        double rx = R * cos(theta), ry = R * sin(theta);
        double dl_x = -R * sin(theta) * dtheta;
        double dl_y =  R * cos(theta) * dtheta;

        double dx = r.x - rx, dy = r.y - ry, dz = r.z;
        double dist = sqrt(dx*dx + dy*dy + dz*dz);
        if (dist > 1e-12) {
            a.x += dl_x / dist;
            a.y += dl_y / dist;
        }
    }
    double c = (MU_0 * I) / (4.0 * M_PI);
    a.x *= c; a.y *= c; a.z *= c;
    return a;
}

Vec3 compute_B_curl(Vec3 r, double R, double I, int N, double h) {
    Vec3 r_yp = {r.x, r.y+h, r.z}, r_ym = {r.x, r.y-h, r.z};
    Vec3 r_zp = {r.x, r.y, r.z+h}, r_zm = {r.x, r.y, r.z-h};
    Vec3 r_xp = {r.x+h, r.y, r.z}, r_xm = {r.x-h, r.y, r.z};

    Vec3 a_yp = compute_A(r_yp, R, I, N), a_ym = compute_A(r_ym, R, I, N);
    Vec3 a_zp = compute_A(r_zp, R, I, N), a_zm = compute_A(r_zm, R, I, N);
    Vec3 a_xp = compute_A(r_xp, R, I, N), a_xm = compute_A(r_xm, R, I, N);

    Vec3 b;
    b.x = (a_yp.z - a_ym.z)/(2*h) - (a_zp.y - a_zm.y)/(2*h);
    b.y = (a_zp.x - a_zm.x)/(2*h) - (a_xp.z - a_xm.z)/(2*h);
    b.z = (a_xp.y - a_xm.y)/(2*h) - (a_yp.x - a_ym.x)/(2*h);
    return b;
}

int main(void) {
    const double R = 0.1, I = 10.0, h = 1e-4;
    const int N = 1000;

    printf("Перевірка обчислення B = rot A на осі кільця Z:\n");
    for (double z = 0.02; z <= 0.10; z += 0.02) {
        Vec3 r = {0.0, 0.0, z};
        Vec3 b_num = compute_B_curl(r, R, I, N, h);
        double b_exact = (MU_0 * I * R * R) / (2.0 * pow(R * R + z * z, 1.5));
        printf("z = %.2f м: B_curl = %.6e Тл, B_exact = %.6e Тл (похибка %.4f%%)\n",
               z, b_num.z, b_exact, fabs(b_num.z - b_exact)/b_exact * 100.0);
    }
    return 0;
}
```

```cpp
#include <iomanip>

struct Vec3 {
    double x{0.0}, y{0.0}, z{0.0};

    constexpr Vec3 operator+(const Vec3& o) const noexcept { return {x + o.x, y + o.y, z + o.z}; }
    constexpr Vec3 operator-(const Vec3& o) const noexcept { return {x - o.x, y - o.y, z - o.z}; }
    constexpr Vec3 operator*(double s) const noexcept { return {x * s, y * s, z * s}; }
};

class CircularCurrentLoop {
public:
    constexpr CircularCurrentLoop(double radius, double current, std::size_t segments = 1000) noexcept
        : radius_(radius), current_(current), segments_(segments) {}

    [[nodiscard]] Vec3 vectorPotential(const Vec3& r) const noexcept {
        Vec3 a{};
        const double d_theta = (2.0 * std::numbers::pi) / static_cast<double>(segments_);

        for (std::size_t k = 0; k < segments_; ++k) {
            const double theta = static_cast<double>(k) * d_theta;
            const double rx = radius_ * std::cos(theta);
            const double ry = radius_ * std::sin(theta);
            const double dl_x = -radius_ * std::sin(theta) * d_theta;
            const double dl_y =  radius_ * std::cos(theta) * d_theta;

            const double dx = r.x - rx, dy = r.y - ry, dz = r.z;
            const double dist = std::sqrt(dx * dx + dy * dy + dz * dz);
            if (dist > 1e-12) {
                a.x += dl_x / dist;
                a.y += dl_y / dist;
            }
        }
        constexpr double mu_0 = 4.0 * std::numbers::pi * 1e-7;
        return a * ((mu_0 * current_) / (4.0 * std::numbers::pi));
    }

    [[nodiscard]] Vec3 magneticFieldCurl(const Vec3& r, double h = 1e-4) const noexcept {
        const auto a_yp = vectorPotential({r.x, r.y + h, r.z}), a_ym = vectorPotential({r.x, r.y - h, r.z});
        const auto a_zp = vectorPotential({r.x, r.y, r.z + h}), a_zm = vectorPotential({r.x, r.y, r.z - h});
        const auto a_xp = vectorPotential({r.x + h, r.y, r.z}), a_xm = vectorPotential({r.x - h, r.y, r.z});

        return {
            (a_yp.z - a_ym.z) / (2.0 * h) - (a_zp.y - a_zm.y) / (2.0 * h),
            (a_zp.x - a_zm.x) / (2.0 * h) - (a_xp.z - a_xm.z) / (2.0 * h),
            (a_xp.y - a_xm.y) / (2.0 * h) - (a_yp.x - a_ym.x) / (2.0 * h)
        };
    }

    [[nodiscard]] double exactOnAxisFieldZ(double z) const noexcept {
        constexpr double mu_0 = 4.0 * std::numbers::pi * 1e-7;
        return (mu_0 * current_ * radius_ * radius_) /
               (2.0 * std::pow(radius_ * radius_ + z * z, 1.5));
    }

private:
    double radius_;
    double current_;
    std::size_t segments_;
};

int main() {
    const CircularCurrentLoop loop(0.1, 10.0, 1000);
    constexpr double h = 1e-4;

    std::cout << std::fixed << std::setprecision(6);
    std::cout << "Перевірка обчислення B = rot A на осі кільця Z:\n";
    for (double z = 0.02; z <= 0.10; z += 0.02) {
        const Vec3 r{0.0, 0.0, z};
        const Vec3 b_num = loop.magneticFieldCurl(r, h);
        const double b_exact = loop.exactOnAxisFieldZ(z);
        const double err = std::abs(b_num.z - b_exact) / b_exact * 100.0;

        std::cout << "z = " << z << " м: B_curl = " << b_num.z
                  << " Тл, B_exact = " << b_exact
                  << " Тл (похибка " << std::setprecision(4) << err << "%)\n";
    }
    return 0;
}
```

## 8. Термінологічний і концептуальний підсумок

Векторний потенціал пов'язує воєдино векторний аналіз, теорію диференціальних рівнянь, спеціальну теорію відносності та квантову механіку:

1. **Векторний потенціал** (vector potential) — походить від латинського *vector* («той, що несе, перевізник», від дієслова *vehere* — везти, нести) та *potentialis* («можливий, дієвий», від *potentia* — сила, спроможність). Векторне поле `A`, ротор якого задає магнітну індукцію `B = ∇ × A`.
2. **Ротор / Вихор** (curl / rotor) — походить від латинського *rotare* («обертатися, кружляти», від *rota* — колесо). Диференціальний оператор `∇ ×`, що вимірює густину локального обертання або циркуляції векторного поля навколо точки.
3. **Дивергенція** (divergence) — походить від латинського *divergere* (*dis-* — врізнобіч + *vergere* — схилятися, спрямовуватися). Скалярна міра густини витоку або входу силових ліній векторного поля в нескінченно малий об'єм (наявність джерел чи стоків).
4. **Калібрування** (gauge) — термін запровадив Герман Вайль від німецького *Eichung* (початково — перевірка еталонів мір і ваг, калібрування залізничної колії). У сучасній фізиці — процедура фіксації математичної свободи у виборі потенціалів без зміни фізичних спостережуваних величин.
5. **Соленоїдальність** (solenoidal field) — походить від грецького *σωλήν* (*solen* — труба, канал) та *εἶδος* (*eidos* — вигляд, форма). Векторне поле з нульовою дивергенцією (`∇ · v = 0`), силові лінії якого не мають кінців і утворюють замкнені трубчасті контури.
6. **Запізнілі потенціали** (retarded potentials) — від латинського *retardare* (*re-* — назад + *tardus* — повільний, запізнілий). Розв'язки хвильових рівнянь, у яких збурення поля в точці спостереження враховують скінченний час поширення сигналу зі швидкістю світла від віддалених джерел.

Векторний потенціал є центральним об'єктом калібрувальних теорій сучасної фундаментальної фізики. У квантовій електродинаміці (QED) та теорії калібрувальних полів Янга–Міллса саме 4-вектор потенціалу виступає фундаментальним полем переносника взаємодії (фотона чи калібрувального бозона), а класичні напруженості електричного й магнітного полів є лише компонентами антисиметричного тензора напруженості електромагнітного поля `F_μν = ∂_μ A_ν - ∂_ν A_μ`.
