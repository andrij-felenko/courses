# 🧮 Виведення польової густини енергії та розбіжність власної енергії точкового заряду

Цей математичний додаток містить строге покрокове виведення еквівалентності між потенціальною енергією неперервного розподілу електричних зарядів та об'ємним інтегралом від квадрата напруженості поля, аналітичний асимптотичний аналіз мультипольного розкладу для зникання поверхневого інтеграла на нескінченності, порівняльне обчислення власної енергії для суцільної та оболонкової моделей заряду, а також варіаційне доведення теореми Томсона про мінімум енергії електростатичного поля.

---

## 1. Строге перетворення об'ємного інтеграла джерел у польовий інтеграл

Розглянемо неперервний розподіл електричного заряду у обмеженій області простору `V` з об'ємною густиною `ρ(r)`. Потенціальна енергія взаємодії цього розподілу зарядів задається виразом:

```
W = ½ ∫_V ρ(r) · φ(r) dV
```

де `φ(r)` — скалярний потенціал електростатичного поля у точці `r`.

### Крок 1. Заміна густини заряду за диференціальним законом Гаусса

За диференціальною формою закону Гаусса у вакуумі об'ємна густина заряду пов'язана з дивергенцією вектора напруженості електричного поля `E`:

```
∇ · E = ρ / ε₀   ⇒   ρ = ε₀ · (∇ · E)
```

Підставляємо вираз для `ρ` в інтеграл енергії:

```
W = ½ · ε₀ ∫_V φ · (∇ · E) dV      [заміна ρ на ε₀ · (∇ · E)]
```

### Крок 2. Застосування векторного диференціального тотожності

З векторного аналізу відома формула для дивергенції добутку скаляра `φ` на вектор `E`:

```
∇ · (φ · E) = E · ∇φ + φ · (∇ · E)
```

Виражаємо підінтегральний добуток `φ · (∇ · E)` через решту доданків:

```
φ · (∇ · E) = ∇ · (φ · E) − E · ∇φ
```

Підставляємо це співвідношення у вираз для енергії `W`:

```
W = ½ · ε₀ ∫_V ∇ · (φ · E) dV − ½ · ε₀ ∫_V E · ∇φ dV
```

### Крок 3. Використання зв'язку між напруженістю та потенціалом

Електростатичне поле є потенціальним, тому напруженість поля виражається через градієнт скалярного потенціалу:

```
E = − ∇φ   ⇒   ∇φ = − E
```

Підставляємо `∇φ = − E` у другий інтеграл:

```
− E · ∇φ = − E · (− E) = E²
```

Отже, вираз для енергії набуває вигляду:

```
W = ½ · ε₀ ∫_V ∇ · (φ · E) dV + ½ · ε₀ ∫_V E² dV
```

## 2. Асимптотичний аналіз та доказ зникання поверхневого інтеграла

За застосуванням теореми Остроградського-Гаусса (теореми про дивергенцію) перший інтеграл від дивергенції перетворюється на поверхневий інтеграл по замкненій межі `S = ∂V`, яка обмежує об'єм `V`:

```
∫_V ∇ · (φ · E) dV = ∮_S φ · E · dS
```

Розширимо область інтегрування `V` до замкненої кулі `V_R` радіуса `R` з центром у початку координат, охоплюючи всі електричні заряди системи. Поверхня `S_R` є сферою радіуса `R`.

Здійснимо граничний перехід при `R → ∞`. Оскільки весь електричний заряд `Q_total` зосереджений у скінченній області простору, при `R → ∞` на великих відстанях асимптотична поведінка потенціалу та поля описується формулами мультипольного розкладу:

```
φ(R) = Q_total / (4 · π · ε₀ · R) + (p · n) / (4 · π · ε₀ · R²) + O(1 / R³)
E(R) = Q_total / (4 · π · ε₀ · R²) · n + [3(p · n)n − p] / (4 · π · ε₀ · R³) + O(1 / R⁴)
```

де `p` — дипольний момент системи, а `n = R / R` — одиничний нормальний вектор.

Головний (монопольний) доданок підінтегрального добутку `φ · E` на поверхні сфери радіуса `R` має асимптотику:

```
φ(R) · E(R) ~ [ Q_total / (4 · π · ε₀ · R) ] · [ Q_total / (4 · π · ε₀ · R²) ] ∝ 1 / R³
```

Площа елемента сферичної поверхні `dS` та повна площа сфери `S_R` зростають як:

```
dS = R² · sin θ dθ dϕ   ⇒   Area(S_R) = 4 · π · R²   [асимптотика ∝ R²]
```

Оцінимо величину поверхневого інтеграла по сфері радіуса `R`:

```
| ∮_S_R φ · E · dS | ≤ max|φ| · max|E| · Area(S_R)
                   ∝ (1 / R³) · R² = 1 / R
```

Виконуємо граничний перехід при `R → ∞`:

```
lim_(R → ∞) ∮_S_R φ · E · dS = lim_(R → ∞) O(1 / R) = 0
```

Поверхневий інтеграл строго прямує до нуля! Таким чином, при поширенні інтегрування на увесь нескінченний тривимірний простір `ℝ³` залишається лише другий об'ємний інтеграл:

```
W = ½ · ε₀ ∫_ℝ³ E² dV
```

Це доводить, що об'ємна густина енергії електростатичного поля у кожній точці простору дорівнює:

```
w_e = ½ · ε₀ · E²
```

## 3. Власна енергія заряджених сфер: тонкостінна оболонка проти суцільної кулі

Обчислимо власну електростатичну енергію поля для двох різних фізичних моделей розподілу заряду `Q`: тонкої сферичної оболонки та суцільної рівномірно зарядженої кулі радіуса `R₀`.

### 1. Тонкостінна сферична оболонка радіуса `R₀`

Весь заряд `Q` розподілений по поверхні сфери `r = R₀`.

Напруженість поля у просторі:
- Усередині сфери (`r < R₀`): `E(r) = 0`
- Зовні сфери (`r > R₀`): `E(r) = Q / (4 · π · ε₀ · r²)`

Обчислимо об'ємний інтеграл поля у сферичних координатах `dV = 4 · π · r² dr`:

```
W_shell = ½ · ε₀ ∫_R₀^∞ ( Q / (4 · π · ε₀ · r²) )² · 4 · π · r² dr   [підстановка E(r) у польовий інтеграл]
        = (Q² / (8 · π · ε₀)) ∫_R₀^∞ (1 / r²) dr                    [винесення сталих коефіцієнтів]
        = (Q² / (8 · π · ε₀)) · [ − 1 / r ]_R₀^∞                   [інтегрування первісної 1/r²]
        = Q² / (8 · π · ε₀ · R₀)                                    [підстановка границь інтегрування]
```

### 2. Суцільна рівномірно заряджена куля радіуса `R₀`

Заряд `Q` рівномірно розподілений по всьому об'єму кулі з постійною густиною `ρ₀ = Q / ((4/3) · π · R₀³)`.

Напруженість поля за законом Гаусса:
- Усередині кулі (`r ≤ R₀`): `E_in(r) = Q · r / (4 · π · ε₀ · R₀³)`
- Зовні кулі (`r > R₀`): `E_out(r) = Q / (4 · π · ε₀ · r²)`

Повна енергія розбивається на два інтеграли — внутрішній `W_in` та зовнішній `W_out`:

```
W_in  = ½ · ε₀ ∫₀^R₀ ( Q · r / (4 · π · ε₀ · R₀³) )² · 4 · π · r² dr   [інтеграл поля усередині кулі]
      = (Q² / (8 · π · ε₀ · R₀⁶)) ∫₀^R₀ r⁴ dr                         [винесення сталих за знак інтеграла]
      = (Q² / (8 · π · ε₀ · R₀⁶)) · [ r⁵ / 5 ]₀^R₀                    [обчислення первісної від r⁴]
      = Q² / (40 · π · ε₀ · R₀)                                        [підстановка верхньої межі R₀]

W_out = ½ · ε₀ ∫_R₀^∞ ( Q / (4 · π · ε₀ · r²) )² · 4 · π · r² dr       [інтеграл поля зовні кулі]
      = Q² / (8 · π · ε₀ · R₀)                                         [інтегрування за межами кулі]
```

Додаючи внутрішню та зовнішню частини енергії, отримуємо повну власну енергію суцільної зарядженої кулі:

```
W_ball = W_in + W_out = (Q² / (40 · π · ε₀ · R₀)) + (Q² / (8 · π · ε₀ · R₀))   [сумування двох внесків]
       = Q² / (40 · π · ε₀ · R₀) · (1 + 5)                                     [зведення до спільного знаменника 40]
       = 6 · Q² / (40 · π · ε₀ · R₀) = 3 · Q² / (20 · π · ε₀ · R₀)             [скорочення дробу на 2]
```

Порівняння двох моделей показано нижче:

```
 Модель розподілу заряду Q (радіус R₀)            Повна власна енергія W
┌──────────────────────────────────────────────┬───────────────────────────────┐
│ 1. Поверхнева оболонка (r = R₀)              │  W = 1/2 · Q² / (4πε₀ R₀)     │
│ 2. Суцільна рівномірно заряджена куля        │  W = 3/5 · Q² / (4πε₀ R₀)     │
└──────────────────────────────────────────────┴───────────────────────────────┘
```

Упевнимося, що при спрямуванні радіуса `R₀ → 0` обидва вирази прямують до плюс нескінченності:

```
lim_(R₀ → 0) W_shell = + ∞
lim_(R₀ → 0) W_ball  = + ∞
```

Це строго доводить неминучість розбіжності власної енергії класичного точкового заряду незалежно від внутрішньої геометричної моделі розподілу заряду.

## 4. Теорема Томсона про мінімум енергії електростатичного поля

Теорема Томсона стверджує: **Якщо система з `N` провідних тіл має задані незмінні заряди `Q₁, Q₂, ..., Q_N`, то електростатичний розподіл зарядів `σ(r)` по поверхнях провідників, що встановлюється у стані рівноваги, мінімізує повну енергію поля `W` порівняно з будь-яким іншим нерівноважним розподілом тих самих зарядів.**

### Доведення варіаційним методом

Нехай `E` — істинне рівноважне електростатичне поле, створене рівноважним поверхневим зарядом `σ`. Усередині провідників `E = 0`, а на поверхнях `E` перпендикулярне до тангенціальних площин.

Розглянемо будь-яке інше припустиме поле `E' = E + δE`, яке створюється іншим розподілом тих самих зарядів `Q_i`. Для кожного провідника `i` варіація заряду задовольняє умову:

```
∮_S_i δσ dS = ε₀ ∮_S_i δE · dS = 0
```

Обчислимо енергію нового поля `W'`:

```
W' = ½ · ε₀ ∫ (E + δE)² dV = ½ · ε₀ ∫ E² dV + ½ · ε₀ ∫ (δE)² dV + ε₀ ∫ (E · δE) dV
   = W + ½ · ε₀ ∫ (δE)² dV + ε₀ ∫ (E · δE) dV
```

Оскільки варіаційне поле `δE` є потенціальним (`δE = − ∇(δφ)`), перехресний доданок перетворюється за допомогою інтегрування частинами:

```
∫ (E · δE) dV = − ∫ E · ∇(δφ) dV = − ∫ ∇ · (δφ · E) dV + ∫ δφ · (∇ · E) dV
```

Уся порожня область поза провідниками має `∇ · E = 0`. Інтеграл від дивергенції за теоремою Остроградського-Гаусса зводиться до суми поверхневих інтегралів по поверхнях провідників `S_i`:

```
∫ (E · δE) dV = ∑_(i=1)^N δφ_i · ( ∮_S_i E · dS ) = ∑_(i=1)^N V_i · ( ∮_S_i δE · dS ) = 0
```

Оскільки на поверхні кожного провідника потенціал `V_i = const`, а `∮ δE dS = 0`, перехресний інтеграл строго дорівнює нулю!

Отже, зміна енергії дорівнює:

```
W' = W + ½ · ε₀ ∫ (δE)² dV
```

Оскільки підінтегральний вираз `(δE)² ≥ 0` є строго додатним для будь-якої відмінної від нуля варіації поля `δE ≠ 0`, маємо:

```
W' > W
```

Це доводить, що рівноважний статичний стан електричного поля відповідає **абсолютному мінімуму повної електростатичної енергії системи**.

## 5. Обчислення класичного радіуса електрона

Якщо припустити, що вся маса спокою електрона `m_e` має чисто електромагнітне походження (тобто енергія спокою Ейнштейна `E_rest = m_e · c²` дорівнює власній електростатичній енергії сферичної оболонки з зарядом `e`), отримаємо співвідношення:

```
m_e · c² = e² / (4 · π · ε₀ · r_e)
```

Звідси виражаємо масштаб **класичного радіуса електрона** `r_e`:

```
r_e = e² / (4 · π · ε₀ · m_e · c²)
```

Підставляючи фундаментальні фізичні константи:
- Заряд електрона `e ≈ 1.60217663e-19` Кл
- Електрична стала `ε₀ ≈ 8.85418781e-12` Ф/м
- Маса електрона `m_e ≈ 9.10938370e-31` кг
- Швидкість світла `c ≈ 2.99792458e8` м/с

Отримуємо чисельне значення:

```
r_e ≈ (1.60218e-19)² / (4 · π · 8.85419e-12 · 9.10938e-31 · (2.99792e8)²)
    ≈ 2.81794e-15 м = 2.81794 фм  (фермі)
```

Для суцільної кулі з тими самими умовами `m_e c² = (3/5) · e² / (4 π ε₀ r_ball)` аналогічний радіус становив би `r_ball = (3/5) · r_e ≈ 1.69` фм. Масштаб `r_e ≈ 2.82` фм визначає межу класичної електродинаміки, де ефекти квантової флуктуації вакууму стають визначальними.
