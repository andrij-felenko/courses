# 📋 Довідник формул енергії, ємнісних матриць та пондеромоторних сил

Цей довідник містить систематизовані математичні формули для обчислення електростатичної енергії фундаментальних геометричних конфігурацій, матричний формалізм потенціальних та ємнісних коефіцієнтів для систем з `N` провідників, формули пондеромоторних сил і тензора натягів Максвелла, а також таблицю інженерних параметрів діелектричних середовищ та практичні приклади розрахунків для мікроелектромеханічних систем (MEMS) і суперконденсаторів.

## 1. Сводна таблиця формул енергії базових геометрій

У таблиці нижче наведено аналітичні вирази для повної електростатичної енергії `W` та об'ємної густини енергії `w_e` для класичних геометричних конфігурацій у вакуумі або однорідному діелектрику з відносною проникністю `ε_r`.

| Конфігурація | Параметри геометрії | Електричне поле `E(r)` | Повна енергія `W` | Об'ємна густина `w_e` |
| :--- | :--- | :--- | :--- | :--- |
| **Плоский конденсатор** | Площа `S`, відстань `d` | `E = V / d` | `W = ½ · C · V² = Q² / (2 C)` | `w_e = ½ · ε₀ · ε_r · (V / d)²` |
| **Сферичний конденсатор** | Радиуси `R₁ < R₂` | `E = Q / (4 π ε r²)` | `W = Q² (R₂ − R₁) / (8 π ε R₁ R₂)` | `w_e = Q² / (32 π² ε r⁴)` |
| **Циліндричний конденсатор**| Довжина `L`, радіуси `R₁ < R₂` | `E = Q / (2 π ε L r)` | `W = Q² ln(R₂ / R₁) / (4 π ε L)` | `w_e = Q² / (8 π² ε L² r²)` |
| **Рівномірно заряджена куля**| Радіус `R₀`, сумарний заряд `Q` | `r < R₀: E ∝ r`<br>`r > R₀: E ∝ 1/r²` | `W = 3 Q² / (20 π ε₀ R₀)` | `w_e(r < R₀) = Q² r² / (32 π² ε₀ R₀⁶)` |
| **Тонка сферична оболонка** | Радіус `R₀`, заряд `Q` | `r < R₀: E = 0`<br>`r > R₀: E ∝ 1/r²` | `W = Q² / (8 π ε₀ R₀)` | `w_e(r > R₀) = Q² / (32 π² ε₀ r⁴)` |
| **Дві паралельні нитки** | Довжина `L`, радіус `a`, відстань `d` | `E(r)` двовимірне | `W = (π ε L V²) / ln(d / a)` | `w_e(x, y)` |
| **Диполь у зовнішньому полі**| Дипольний момент `p`, поле `E_ext` | — | `W = − p · E_ext · cos θ` | — |

### Фізичні особливості розподілу енергії у фундаментальних геометріях

1. **Плоский конденсатор:** Поле між обкладками є строго однорідним (якщо не враховувати крайові ефекти), а об'ємна густина енергії `w_e` є постійною у кожній точці діелектрика між пластинами. Усе поле зосереджене усередині об'єму `V = S · d`.
2. **Сферичний конденсатор:** Поле існує лише у сферичному проміжку `R₁ < r < R₂`. Об'ємна густина енергії стрімко спадає від внутрішньої обкладки до зовнішньої за законом `w_e ∝ 1/r⁴`. Основними накопичувачами енергії є безпосередні приповерхневі шари внутрішнього провідника.
3. **Циліндричний конденсатор:** Поле спадає як `1/r`, а густина енергії — як `1/r²`. Ця геометрія є базовою для розрахунку ємності та енергетичних втрат у коаксіальних радіочастотних кабелях та високовольтних силових кабелях.
4. **Рівномірно заряджена куля:** Енергія розбивається на дві частини: 1/6 повної енергії накопичена всередині самої зарядженої кулі (`r < R₀`), а 5/6 повної енергії зосереджено у навколишньому просторі (`r > R₀`).

## 2. Матричний формалізм систем з N провідників

Для системи з `N` довільних провідних тіл складної форми у лінійному діелектричному середовищі зв'язок між зарядами провідників `Q = (Q₁, Q₂, ..., Q_N)ᵀ` та їхніми потенціалами `V = (V₁, V₂, ..., V_N)ᵀ` описується системою лінійних алгебраїчних рівнянь.

### 1. Матриця потенціальних коефіцієнтів `P`

```
V_i = ∑_(k=1)^N p_ik · Q_k      або у матричній формі:  V = P · Q
```

Властивості та фізичний зміст потенціальних коефіцієнтів `p_ik`:
- **Фізичний зміст:** Коефіцієнт `p_ik` виражає потенціал `V_i`, який виникає на `i`-му провіднику, коли `k`-му провіднику надають одиничний заряд `Q_k = 1` Кл, а всі інші провідники незаряджені (`Q_j = 0` при `j ≠ k`).
- **Симетрія (Теорема взаємності Гріна):** `p_ik = p_ki` для всіх `i, k`. Потенціал `i`-го провідника від заряду на `k`-му строго дорівнює потенціалу `k`-го провідника від такого самого заряду на `i`-му.
- **Строга додатність:** `p_ii > 0` та `p_ik > 0` для всіх елементів.
- **Діагональне домінування:** `p_ii ≥ p_ik` для будь-якого `k ≠ i`. Якщо провідник `i` повністю охоплює провідник `k` (як зовнішній екран), то `p_ik = p_ii`.

### 2. Матриця ємнісних коефіцієнтів `C` (Матриця наводки)

Матриця `C` є оберненою до матриці потенціальних коефіцієнтів: `C = P⁻¹`.

```
Q_i = ∑_(k=1)^N C_ik · V_k      або у матричній формі:  Q = C · V
```

Властивості та фізичний зміст ємнісних коефіцієнтів `C_ik`:
- **Власні ємнісні коефіцієнти (`C_ii`):** Завжди строго додатні (`C_ii > 0`). Вони виражають заряд `i`-го провідника при потенціалі `V_i = 1` В, коли потенціали всіх інших провідників заземлені (`V_k = 0`).
- **Взаємні ємності наводки (`C_ik` при `i ≠ k`):** Завжди від'ємні або дорівнюють нулю (`C_ik ≤ 0`). Вони виражають від'ємний індукований заряд на `i`-му заземленому провіднику при подачі потенціалу `V_k = 1` В на `k`-й провідник.
- **Симетрія:** `C_ik = C_ki`.
- **Умова екранування:** Якщо провідник `i` повністю екранований від провідника `k` заземленим металевим корпусом, то взаємний коефіцієнт наводки дорівнює нулю (`C_ik = 0`).

### 3. Квадратичні форми потенціальної енергії

Повна електростатична енергія системи `N` провідників виражається у трьох еквівалентних математичних формах:

```
Енергія через заряди та потенціали: W = ½ ∑_(i=1)^N Q_i · V_i
Енергія через заряди (квадратична): W(Q) = ½ · Qᵀ · P · Q = ½ ∑_(i=1)^N ∑_(k=1)^N p_ik · Q_i · Q_k
Енергія через потенціали (квадратична): W(V) = ½ · Vᵀ · C · V = ½ ∑_(i=1)^N ∑_(k=1)^N C_ik · V_i · V_k
```

Приклад розгортки квадратичної форми для системи з двох провідників (`N = 2`):

```
W(V₁, V₂) = ½ · C₁₁ · V₁² + C₁₂ · V₁ · V₂ + ½ · C₂₂ · V₂²
```

Ця формула є базовою для підрахунку перехресних наводок (crosstalk) у багатопровідних шинах даних друкованих плат.

## 3. Пондеромоторні сили та Тензор натягів Максвелла

Механічні сили, що діють на заряджені провідні тіла або діелектрики у полях, називаються **пондеромоторними силами**.

### 1. Механічна сила за методом віртуальних переміщень

Для узагальненої координати `x` (зміщення провідника або діелектричного блока) сила `F_x` обчислюється залежно від термодинамічних умов підключення:

```
Ізольована система (Q = const):    F_x = − ( ∂W / ∂x )_Q
Підключене джерело напруги (V = const):  F_x = + ( ∂W / ∂x )_V
```

Зв'язок між похідними через ємність системи `C(x)`:

```
( ∂W / ∂x )_V = ½ · V² · ( dC / dx ) = + ( ∂W / ∂x )_Q = − ½ · Q² / C² · ( dC / dx )
```

> **Важливе інженерне правило:** Пондеромоторні сили електростатики завжди спрямовані у бік **збільшення ємності системи** (`dC/dx > 0`).

### 2. Тензор натягів Максвелла (Maxwell Stress Tensor)

Пондеромоторна сила, що діє на елемент поверхні `dS` діелектрика або провідника, обчислюється через компоненти тензора натягів Максвелла `T_ik`:

```
T_ik = ε₀ · ε_r · E_i · E_k − ½ · ε₀ · ε_r · E² · δ_ik
```

де `δ_ik` — символ Кронекера (`δ_ik = 1` при `i = k`, `δ_ik = 0` при `i ≠ k`).

- **Натяг вздовж силових ліній поля:** У напрямку, паралельному до вектора `E`, поле створює **позитивний натяг (розтягнення)** з величиною `f_pull = ½ · ε₀ · ε_r · E²` (Н/м²).
- **Тиск перпендикулярно до силових ліній:** У напрямку, перпендикулярному до вектора `E`, поле створює **бічний тиск** з величиною `P_side = ½ · ε₀ · ε_r · E²` (Н/м²).

Результуюча сила `F`, що діє на будь-яке тіло усередині об'єму `V`, обчислюється інтегруванням тензора по замкненій поверхні `S`, яка охоплює це тіло:

```
F_i = ∮_S ∑_(k=1)^3 T_ik · dS_k
```

## 5. Прикладні інженерні розрахунки

### 1. Розрахунок сили притягання у MEMS-актюаторі

Плоский мікроактюатор має площу пластин `A = 1` мм² (`1e-6` м²), початковий зазор `d = 2` мкм (`2e-6` м) та підключений до напруги `V = 10` Вольт у повітрі (`ε_r = 1`).

Ємність конденсатора як функція зазору `x`:

```
C(x) = (ε₀ · A) / x
```

Похідна ємності по зазору `x`:

```
dC / dx = − (ε₀ · A) / x²
```

Сила притягання пластин `F_x` при фіксованій напрузі `V = 10` В:

```
|F_x| = ½ · V² · |dC / dx| = ½ · V² · (ε₀ · A) / d²
      = ½ · (10)² · (8.854e-12 · 1e-6) / (2e-6)²
      = 50 · (8.854e-18) / (4e-12)
      = 1.106e-4 Н = 110.6 мкН !
```

Ця сила величиною 110.6 мікроньютона дозволяє керувати мікродзеркалами у проекторах та оптичних перемикачах.

### 2. Запасену енергію у суперконденсаторному модулі

Суперконденсаторний модуль ємністю `C = 3000` Фарад розрахований на робочу напругу `V = 2.7` Вольт.

Обчислимо повну накопичену електростатичну енергію:

```
W = ½ · C · V² = ½ · 3000 · (2.7)² = 1500 · 7.29 = 10935 Дж ≈ 10.94 кДж
```

У перерахунку у ват-години (`1 Вт·год = 3600 Дж`):

```
W_wh = 10935 / 3600 ≈ 3.037 Вт·год
```

Ця енергія вивільняється при розрядці за рахунок зняття подвійного електричного шару іонних зарядів на поверхні активованого вугілля.

### 3. Розрахунок максимальної енергії лінії передачі FR-4

Сигнальна лінія друкованої плати зі склотекстоліту FR-4 (`ε_r = 4.4`, `E_bd = 25` КВ/мм = `25e6` В/м) має товщину міжшарового діелектрика `h = 0.2` мм (`2e-4` м) та ширину доріжки `w = 0.3` мм (`3e-4` м) при довжині `L = 0.1` м.

Обчислимо ємність цієї лінії:

```
C = (ε₀ · ε_r · w · L) / h = (8.854e-12 · 4.4 · 3e-4 · 0.1) / (2e-4) = 5.84e-12 Ф = 5.84 пФ
```

Гранично допустима напруга пробою:

```
V_bd = E_bd · h = 25e6 · 2e-4 = 5000 В = 5 КВ
```

Гранична накопичена електростатична енергія лінії до моменту пробою:

```
W_max = ½ · C · V_bd² = ½ · (5.84e-12) · (5000)² = 2.92e-12 · 2.5e7 = 7.3e-5 Дж = 73 мкДж
```

Цей параметр визначає граничну стійкість міжшарової ізоляції плати при імпульсних сплесках перенапруги.
