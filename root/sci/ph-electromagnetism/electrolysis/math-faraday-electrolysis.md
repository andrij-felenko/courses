# 🧮 Математичний розрахунок електролізу: термодинаміка, кінетика та баланс енергії

Ця математична вставка містить розворот формул і виведень для кількісного розрахунку маси й об'єму продуктів електролізу, математичний опис міжфазної кінетики Батлера-Фольмера та Тафеля, виведення граничного дифузійного струму, потенціалів за рівнянням Нернста та обчислення повного енергетичного ККД електролітичних установок.

## Виведення об'єднаного закону Фарадея

Кожен іон у розчині чи розплаві має специфічний заряд `z·e`, де `z` — валентне число (або цілочисловий заряд іона), а `e = 1.60217663 × 10⁻¹⁹ Кл` — елементарний електричний заряд. Під час наближення до поверхні електрода іон бере участь у гетерогенній реакції переносу заряду: катіон приймає `z` електронів від катода, а аніон віддає `z` електронів аноду.

Якщо крізь електролітичне коло протягом часу `t` протікає сталий струм `I`, то загальний електричний заряд `q`, що пройшов крізь міжфазну межу, становить:

```
q = I · t
```

Загальна кількість електронів `N[e]`, які пройшли крізь зовнішнє металеве коло й були передані на межі електродів:

```
N[e] = q / e = (I · t) / e
```

Перейдемо від поштучного відліку частинок до молярної кількості електронів `n[e]`, поділивши `N[e]` на число Авогадро `N[A] = 6.02214076 × 10²³ моль⁻¹`:

```
n[e] = N[e] / N[A] 
     = (I · t) / (e · N[A])      [підстановка виразу для N[e]]
     = (I · t) / F               [введення сталої Фарадея: F = e · N[A] ≈ 96485.33 Кл/моль]
```

Оскільки для нейтралізації або виділення одного моля речовини потрібні `z` молей електронів, молярна кількість утвореного продукту `n` дорівнює:

```
n = n[e] / z 
  = (I · t) / (z · F)            [залежність кількості речовини від струму й часу]
```

Помноживши молярну кількість `n` на молярну масу речовини `M` (у грамах на моль або кілограмах на моль), отримуємо підсумкову масу осадженого чи виділеного продукту `m`:

```
m = n · M 
  = (M · I · t) / (z · F)        [об'єднаний закон Фарадея]
```

У цій формулі величина `k = M / (z · F)` називається **електрохімічним еквівалентом** речовини (вимірюється в г/Кл або кг/Кл). Вона показує, яка маса речовини трансформується при проходженні крізь електроліт одного Кулона електричного заряду.

### Числовий приклад розрахунку осадження міді

Розрахуємо масу чистої міді Cu (молярна маса `M = 63.546 г/моль`), яка осаджується з розчину сульфату міді `CuSO₄` (де іон двовалентний `Cu²⁺`, тобто `z = 2`) на катоді при струмі `I = 10.0 А` протягом `t = 3 годин = 10800 с`:

```
m = (63.546 · 10.0 · 10800) / (2 · 96485.33)
  = 6862968 / 192970.66
  ≈ 35.565 грама
```

Якщо площа катодної пластини становить `S = 200 см²`, а густина міді `ρ = 8.96 г/см³`, то середня товщина утвореного покриття `h` дорівнює:

```
V[layer] = m / ρ = 35.565 / 8.96 ≈ 3.969 см³
h = V[layer] / S = 3.969 / 200 = 0.01984 см = 198.4 мкм
```

## Розрахунок об'єму виділених газів (H₂, Cl₂, O₂)

Якщо результатом електрохімічної реакції є газ, його кількість зручно обчислювати у барометричних одиницях об'єму за нормальних умов (тиск `P⁰ = 101325 Па`, температура `T⁰ = 273.15 К`), де один моль ідеального газу займає молярний об'єм `V[m] ≈ 22.414 л/моль`.

Для реакції виділення водню на катоді `2H⁺ + 2e⁻ → H₂` на один моль молекулярного газу `H₂` витрачається `z = 2` молі електронів. Об'єм виділеного водню `V[H₂]` становить:

```
V[H₂] = n[H₂] · V[m]
      = (V[m] · I · t) / (2 · F)
```

Для реакції виділення кисню на аноді `2H₂O → O₂ + 4H⁺ + 4e⁻` на один моль молекулярного кисню `O₂` витрачається `z = 4` молі електронів:

```
V[O₂] = n[O₂] · V[m]
      = (V[m] · I · t) / (4 · F)
```

Звідси стехіометричне співвідношення виділених об'ємів при електролітичному розкладі води:

```
V[H₂] / V[O₂] 
= ((V[m] · I · t) / (2 · F)) / ((V[m] · I · t) / (4 · F))
= 4 / 2 
= 2
```

Для реальних умов (температура `T`, тиск `P`), відмінних від нормальних, виділений об'єм перераховується за універсальним рівнянням стану ідеального газу Клапейрона-Менделєєва `P · V = n · R · T`:

```
V(P,T) = (n · R · T) / P 
        = (I · t · R · T) / (z · F · P)
```

де `R = 8.31446 Дж/(моль·К)` — універсальна газова стала.

## Термодинаміка електролітичної комірки та потенціали Нернста

Електроліз є термодинамічно несамочинним процесом, що протікає зі збільшенням вільної енергії Гіббса системи (`ΔG > 0`).

Мінімальна енергія, яку необхідно підвести від зовнішнього джерела струму для хімічного перетворення одного моля речовини, дорівнює зміні вільної енергії Гіббса `ΔG`. Звідси мінімальна термодинамічна напруга розкладу `E⁰[cell]` пов'язана з `ΔG` співвідношенням:

```
E⁰[cell] = ΔG / (z · F)
```

Рівноважна різниця потенціалів комірки обчислюється як різниця відновних потенціалів анодного та катодного процесів:

```
E⁰[cell] = E⁰[anode] - E⁰[cathode]
```

### Рівняння Нернста для нестандартних концентрацій

За умов, що відрізняються від стандартних (активності іонів `a ≠ 1 моль/л`), електродні потенціали змінюються згідно з рівнянням Нернста:

```
E = E⁰ + (R · T / (z · F)) · ln( a[ox] / a[red] )
```

При киснево-водневому електролізі води потенціал катода залежить від кислотності розчину (pH):

```
E[cathode] = 0.000 - 0.05916 · pH      [В при 25°C]
E[anode]   = 1.229 - 0.05916 · pH      [В при 25°C]
```

Різниця потенціалів `E⁰[cell] = E[anode] - E[cathode] = 1.229 В` лишається сталою за будь-якого значення pH у нейтральному, кислому чи лужному середовищі, якщо тиски газів дорівнюють `1 атм`.

## Кінетика міжфазного переносу: Рівняння Батлера-Фольмера та Тафеля

У реальних умовах при проходженні струму електроди поляризуються: потенціал катода зсувається у від'ємний бік, а анода — у додатний. Величина цього зсуву називається **перенапругою** `η = |E[real] - E[eq]|`.

Зв'язок між густиною струму `j = I / S` (А/м²) та активаційною перенапругою `η` описується фундаментальним **рівнянням Батлера-Фольмера**:

```
j = j₀ · [ exp( (α · z · F · η) / (R · T) ) - exp( -((1 - α) · z · F · η) / (R · T) ) ]
```

де `j₀` — густина струму обміну (характеристика жвавості реакції в рівновазі), а `α` — коефіцієнт переносу заряду (симетрія активаційного бар'єра, зазвичай `α ≈ 0.5`).

### Наближення високих перенапруг (Рівняння Тафеля)

При високих густинах струму (`η > 0.05 В`) зворотна реакція стає нехтувно малою, і рівняння Батлера-Фольмера спрощується до напівлогарифмічного **рівняння Тафеля**:

```
η = a + b · lg(j)
```

де константи Тафеля `a` та `b` виражаються через теоретичні параметри:

```
b = (2.303 · R · T) / (α · z · F)
a = -b · lg(j₀)
```

Наприклад, для виділення водню на гладкій платині густина струму обміну велетенська (`j₀ ≈ 10⁻³ А/см²`), тому перенапруга `η` майже нульова. На ртуті ж струм обміну мізерний (`j₀ ≈ 10⁻¹² А/см²`), що створює велетенську перенапругу водню (`η > 1.0 В`).

## Концентраційна поляризація та граничний струм

При високих струмах іони у приелектродному шарі товщиною `δ` (дифузійний шар Нернста) вичерпуються швидше, ніж дифузія доправляє нові іони з товщі електроліту.

Згідно з першим законом Дифузії Фіка, граничний дифузійний струм `j[lim]` досягається, коли концентрація іонів біля поверхні електрода падає до нуля (`c[surface] → 0`):

```
j[lim] = (z · F · D · c[bulk]) / δ
```

де `D` — коефіцієнт дифузії іона (м²/с), а `c[bulk]` — концентрація в об'ємі розчину (моль/м³).

Виникаюча **концентраційна перенапруга** `η[conc]` обчислюється за формулою:

```
η[conc] = (R · T / (z · F)) · ln( 1 - j / j[lim] )
```

Коли робочий струм наближається до `j[lim]`, концентраційна перенапруга стрімко прямує до нескінченності, змушуючи систему вмикати нові, енергетично невигідні побічні реакції (наприклад, розклад води).

## Повний баланс напруги та енергетичний ККД

Загальна напруга `V[applied]`, яку має подати зовнішнє джерело живлення на клеми електролізера, обчислюється як сума всіх термодинамічних, кінетичних та омічних складників:

```
V[applied] = E⁰[cell] + η[anode] + η[cathode] + I · R[cell]
```

де `R[cell] = (ρ · d) / S` — омічний опір шару електроліту товщиною `d`, питомим опором `ρ` та площею перерізу `S`.

### Електрохімічний вихід за струмом (ККД Фарадея)

Через наявність побічних реакцій реальна маса осадженого продукту `m[actual]` є меншою за теоретичну `m[theo]`:

```
η[Faraday] = m[actual] / m[theo] = (m[actual] · z · F) / (M · I · t)
```

### Енергетичний ККД установки

Енергетичний ККД `η[Energy]` показує, яка частка спожитої з електромережі електроенергії витратилася безпосередньо на хімічне перетворення:

```
η[Energy] = η[Faraday] · (E⁰[cell] / V[applied])
```

### Питома витрата електроенергії на одиницю маси

Питома витрата енергії `W[spec]` (у кВт·год на кг продукту):

```
W[spec] = (z · F · V[applied]) / (3.6 × 10⁶ · M · η[Faraday])
```

#### Наскрізний приклад: Розрахунок промислового електролізера алюмінію

Для виплавки алюмінію (`Al³⁺`, `z = 3`, `M = 0.02698 кг/моль`) при прикладеній напрузі `V[applied] = 4.2 В` та виході за струмом `η[Faraday] = 0.94` (94%):

```
W[spec] = (3 · 96485.33 · 4.2) / (3.6 × 10⁶ · 0.02698 · 0.94)
        = 1215715 / 91321
        ≈ 13.31 кВт·год / кг Al
```

При річному випуску заводу у 100 000 тонн алюмінію це відповідає колосальному споживанню `1.331 млрд кВт·год` електроенергії, що підкреслює критичну важливість кожного мілівольта зменшення перенапруги та омічного опору комірки.
