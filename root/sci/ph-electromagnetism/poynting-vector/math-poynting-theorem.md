# 🧮 Математичне виведення теореми Пойнтінга та комплексного вектора

Ця вставка надає строге математичне виведення теореми Пойнтінга з диференціальних рівнянь Максвелла для довільних матеріальних середовищ, а також розгортає апарат комплексного вектора Пойнтінга для гармонічних у часі електромагнітних полів.

---

## 1. Векторна тотожність та диференціальна форма теореми Пойнтінга

Розглянемо диференціальні рівняння Максвелла для напруженості електричного поля `E`, напруженості магнітного поля `H`, електричного зміщення `D`, магнітної індукції `B` та сторонньої густини струму провідності `J`:

```
∇ × E = - ∂B / ∂t           [закон електромагнітної індукції Фарадея]
∇ × H = J + ∂D / ∂t         [закон Максвелла-Ампера]
```

Для обчислення дивергенції векторного добутку `E × H` застосуємо фундаментальну векторну тотожність диференціального числення для двох векторних полів:

```
∇ · (E × H)
= H · (∇ × E) - E · (∇ × H)   [векторна тотожність для дивергенції ротора]
```

Ця векторна тотожність є прямою аналогією правила диференціювання добутку двох скалярних функцій `(f · g)' = f' · g + f · g'`, розповсюдженого на векторні операції з оператором Гамільтона `∇`. У тензорній нотації Ейнштейна з використанням символу Леві-Чивіта `e_{ijk}` ця тотожність розгортається у вигляд:

```
∇_i (e_{ijk} E_j H_k) = e_{ijk} (∇_i E_j) H_k + e_{ijk} E_j (∇_i H_k)
```

Перший доданок `H · (∇ × E)` описує взаємодію магнітного поля з вихровим електричним полем, утвореним часовою зміною магнітного потоку. Другий доданок `- E · (∇ × H)` описує взаємодію електричного поля з повним струмом, який складається зі струму провідності та струму зміщення.

Підставимо у праву частину векторної тотожності вирази роторів з рівнянь Максвелла:

```
∇ · (E × H)
= H · (- ∂B / ∂t) - E · (J + ∂D / ∂t)             [підстановка рівнянь Максвелла]
= - H · (∂B / ∂t) - E · (∂D / ∂t) - E · J          [розкриття дужок та групування]
```

Для лінійних, ізотропних та недиспергуючих середовищ матеріальні співвідношення мають вигляд `D = ε · E` та `B = μ · H`, де діелектрична проникність `ε` та магнітна проникність `μ` є сталими у часі скалярами.

Обчислимо скалярні добутки векторів з їхніми часовими похідними:

```
E · (∂D / ∂t)
= E · (∂(ε E) / ∂t)
= ε · E · (∂E / ∂t)
= ∂ / ∂t (½ ε E²)                                  [похідна квадрата вектора E]

H · (∂B / ∂t)
= H · (∂(μ H) / ∂t)
= μ · H · (∂H / ∂t)
= ∂ / ∂t (½ μ H²)                                  [похідна квадрата вектора H]
```

Математичне обґрунтування цього кроку спирається на диференціювання скалярного квадрата будь-якого вектора `A · A = A²`: похідна від квадрата дорівнює `d/dt (A²) = 2 A · (dA/dt)`. Завдяки цьому співвідношенню скалярний добуток вектора напруженості на похідну вектора індукції можна звести під спільний знак часової похідної від квадратичної форми.

Підставляючи отримані часові похідні назад у розкриту векторну тотожність, отримуємо:

```
∇ · (E × H)
= - ∂ / ∂t (½ ε E²) - ∂ / ∂t (½ μ H²) - E · J
= - ∂ / ∂t (½ ε E² + ½ μ H²) - E · J                [винесення часової похідної]
```

Уведемо стандартні фізичні визначення:
- **Вектор Пойнтінга**: `S = E × H` (Густина потоку енергії, Вт/м²).
- **Об'ємна густина енергії поля**: `u = u_e + u_m = ½ ε E² + ½ μ H²` (Дж/м³).
- **Потужність роботи поля над зарядами**: `w_J = E · J` (Об'ємна густина джоулевих втрат, Вт/м³).

Отримуємо **диференціальну форму теореми Пойнтінга**:

```
- ∇ · S = ∂u / ∂t + E · J
```

Фізичний зміст рівняння: зменшення об'ємної густини енергії електромагнітного поля у даній точці простору `(- ∂u/∂t)` витрачається на вхідний потік енергії `(∇ · S)` та на виконання механічної/теплової роботи над носіями заряду `(E · J)`.

Для анізотропних середовищ матеріальні співвідношення набувають тензорного вигляду `D_i = ∑_j ε_{ij} E_j` та `B_i = ∑_j μ_{ij} H_j`. Якщо тензори діелектричної та магнітної проникностей є симетричними (`ε_{ij} = ε_{ji}` та `μ_{ij} = μ_{ji}`), що виконується для будь-яких недисипативних кристалів без зовнішнього магнітного поля, квадратична форма об'ємної густини енергії зберігає вигляд `u = ½ E · D + ½ H · B`, а диференціальне рівняння Пойнтінга залишається строго точним.

У випадку диспергуючих середовищ (де діелектрична проникність залежить від частоти `ε(ω)`), миттєве значення об'ємної густини енергії розраховується за формулою Бріллюена-Ландау:

```
u_disp = ½ d(ω ε) / dω · |E|² + ½ d(ω μ) / dω · |H|²
```

Ця формула враховує енергію, витрачену електромагнітним полем на розкачування внутрішніх атомарних осциляторів та середовища під час поширення хвильового пакета.

Для біанізотропних (кіральних) середовищ матеріальні рівності зв'язують вектори зміщення через перехресні кіральні тензори `D = ε E + ξ H` та `B = ζ E + μ H`. В таких середовищах теорема Пойнтінга вимагає врахування уявних компонент кіральних параметрів `ξ` та `ζ`, які описують обертання площини поляризації світла та оптичну активність речовини.

## 2. Інтегральна форма теореми Пойнтінга

Проінтегруємо диференціальне рівняння Пойнтінга по довільному замкненому об'єму `V`, обмеженому гладкою замкненою поверхнею `A`:

```
∫_V (- ∇ · S) dV = ∫_V (∂u / ∂t) dV + ∫_V (E · J) dV
```

Застосуємо теорему Остроградського-Гаусса до лівої частини інтегрального рівняння, перетворивши об'ємний інтеграл від дивергенції вектора Пойнтінга на поверхневий інтеграл по граничній поверхні `A`:

```
∫_V (∇ · S) dV = ∮_A S · dA
```

де `dA = n · dA` — вектор елемента поверхні, спрямований по зовнішній нормалі `n` з об'єму `V`.

Зауважимо важливу математичну деталь: знак мінус перед поверхневим інтегралом виникає через те, що вектори нормалі `n` за математичною угодою спрямовані *зовні* з замкненого об'єму `V`. Отже, скалярний добуток `S · n > 0` відповідає виходу енергії з об'єму (випромінюванню), а `- S · n > 0` — входу енергії в об'єм.

Переставимо знак часової похідної та інтегрування у правому першому інтегралі:

```
- ∮_A S · dA = ∂ / ∂t (∫_V u dV) + ∫_V (E · J) dV
```

Позначимо повну енергію електромагнітного поля у замкненому об'ємі `V` як `W_field = ∫_V u dV`, а повну потужність втрат на джоулеве нагрівання/прискорення зарядів як `P_loss = ∫_V (E · J) dV`.

Тоді інтегральна теорема Пойнтінга має вигляд:

```
- ∮_A S · dA = ∂W_field / ∂t + P_loss
```

Повний вхідний потік векторної енергії Пойнтінга крізь зовнішню поверхню `A` в об'єм `V` дорівнює швидкості накопичення енергії полів усередині цього об'єму плюс повна потужність дисипації у провідному матеріалі.

Розглянемо граничні умови для поверхневого інтеграла Пойнтінга на межі розділу двох середовищ. З диференціальних рівнянь Максвелла випливає, що тангенціальні складові напруженостей полів є неперервними при переході через межу діелектриків:

```
E_t1 = E_t2
H_t1 = H_t2
```

Оскільки нормальна складова вектора Пойнтінга до межі розділу `S_n` визначається саме добутком тангенціальних складових полів (`S_n = E_t · H_t · sin(θ)`), нормальна складова вектора Пойнтінга є строго неперервною на гладкій межі двох середовищ за відсутності поверхневих струмів:

```
S_n1 = S_n2
```

Це доводить, що вектор Пойнтінга не утворює математичних розривів на межах розділу діелектриків, що забезпечує збереження енергетичного потоку при дзеркальному заломленні та відбиванні світлових променів на оптичних межах.

Для неперіодичних або періодичних несинусоїдальних полів (наприклад, у цифрових високочастотних сигнальних лініях) усереднений за часом вектор Пойнтінга обчислюється через розклад полів у ряд Фур'є:

```
E(t) = ∑_n E_n · e^(j n ω t)
H(t) = ∑_m H_m · e^(j m ω t)
```

Завдяки ортогональності гармонічних функцій перехресні добутки різних гармонік `n ≠ m` при інтегруванні за період `T` зникають, і повний усереднений вектор Пойнтінга дорівнює сумі активних векторів Пойнтінга кожної окремої гармоніки:

```
<S> = ∑_n ½ Re { E_n × H_n* }
```

Ця теорема парсевалівського типу гарантує, що спектральні компоненти електромагнітного сигналу переносять енергію незалежно одна від одної у лінійних середовищах.

## 3. Комплексний вектор Пойнтінга для гармонічних полів

У більшості практичних задач радіотехніки, антенної техніки та оптики поля змінюються за гармонічним (синусоїдальним) законом із кутовою частотою `ω`. Для аналізу таких полів застосовується комплексний метод (метод амплітудно-фазових комплексорів).

Представимо дійсні вектори полів через їхні комплексні амплітуди `E_c(r)` та `H_c(r)`:

```
E(r, t) = Re { E_c(r) · e^(j ω t) } = ½ [ E_c(r) · e^(j ω t) + E_c*(r) · e^(-j ω t) ]
H(r, t) = Re { H_c(r) · e^(j ω t) } = ½ [ H_c(r) · e^(j ω t) + H_c*(r) · e^(-j ω t) ]
```

де `*` позначає комплексне спряження, а `j = √(-1)` — уявна одиниця.

Обчислимо миттєвий вектор Пойнтінга `S(r, t) = E(r, t) × H(r, t)`:

```
S(r, t)
= ¼ [ E_c e^(j ω t) + E_c* e^(-j ω t) ] × [ H_c e^(j ω t) + H_c* e^(-j ω t) ]
= ¼ [ E_c × H_c* + E_c* × H_c ] + ¼ [ E_c × H_c e^(j 2ω t) + E_c* × H_c* e^(-j 2ω t) ]
= ½ Re { E_c × H_c* } + ½ Re { E_c × H_c · e^(j 2ω t) }
```

Усереднимо миттєвий вектор Пойнтінга за період коливань `T = 2π / ω`:

```
<S>
= (1 / T) ∫_0^T S(r, t) dt
= ½ Re { E_c × H_c* }                         [гармонічні осциляції 2ω усреднюються в 0]
```

Уведемо фундаментальне поняття **комплексного вектора Пойнтінга** `S_c`:

```
S_c = ½ (E_c × H_c*)
```

Комплексний вектор Пойнтінга розкладається на дійсну та уявну частини:

```
S_c = P_avg + j Q_reactive
```

де:
- **`P_avg = Re { S_c } = ½ Re { E_c × H_c* }`** — середня за часом густина активного потоку потужності (активний потік Пойнтінга, Вт/м²). Описує незворотний випромінювальний або передавальний потік енергії у далекій зоні антен чи вздовж лінії передачі.
- **`Q_reactive = Im { S_c } = ½ Im { E_c × H_c* }`** — густина реактивного потоку потужності (реактивний потік Пойнтінга, вар/м²). Описує пульсуючу енергію, яка безповоротно не випромінюється, а лише коливається туди-сюди між електричним та магнітним полями у реактивній ближній зоні антен чи біля елементів кола.

Фізична суть розкладу комплексного вектора Пойнтінга полягає у тому, що у звичайних колах змінного струму активна потужність `P = V · I · cos(φ)` переносить корисну енергію до навантаження, тоді як реактивна потужність `Q = V · I · sin(φ)` описує циркуляцію енергії між реактивними елементами та джерелом. Комплексний вектор Пойнтінга розповсюджує це узагальнення на тривимірне просторове електромагнітне поле.

## 4. Комплексна теорема Пойнтінга

Застосуємо операцію дивергенції до комплексного вектора Пойнтінга `S_c`:

```
∇ · S_c
= ∇ · (½ E_c × H_c*)                   [підстановка визначення комплексного вектора S_c]
= ½ H_c* · (∇ × E_c) - ½ E_c · (∇ × H_c*) [дивергенція векторного добутку комплексних полів]
```

Підставимо комплексні рівняння Максвелла для гармонічного поля (`∇ × E_c = - j ω μ H_c` та `∇ × H_c* = J_c* - j ω ε* E_c*`):

```
∇ · S_c
= ½ H_c* · (- j ω μ H_c) - ½ E_c · (J_c* - j ω ε* E_c*) [підстановка комплексних рівнянь Максвелла]
= - j 2 ω (¼ μ |H_c|²) + j 2 ω (¼ ε* |E_c|²) - ½ E_c · J_c* [перетворення скалярних добутків у квадрати модулів]
= j 2 ω (u_e,c - u_m,c) - ½ E_c · J_c*                   [підстановка усереднених густин енергій]
```

де `u_e,c = ¼ ε |E_c|²` та `u_m,c = ¼ μ |H_c|²` — усереднені за часом густини енергій електричного та магнітного полів.

Розділивши дійсну та уявну частини комплексної теореми Пойнтінга, отримуємо два незалежних енергетичних закони збереження:

```
- Re { ∇ · S_c } = ½ Re { E_c · J_c* }            [активний баланс: середня випромінена потужність = джоулеві втрати]
- Im { ∇ · S_c } = 2 ω (u_m,c - u_e,c)            [реактивний баланс: реактивний потік пропорційний різниці магнітної та електричної енергій]
```

Це рівняння лежить в основі розрахунку вхідного імпедансу антен, коефіцієнта стоячої хвилі (КСХ) у фідерних лініях та добротності електродинамічних резонаторів.

З рівняння реактивного балансу випливає фундаментальний висновок: якщо у деякому об'ємі середовища усереднена магнітна енергія дорівнює усередненій електричній енергії (`u_m,c = u_e,c`), уявна частина дивергенції комплексного вектора Пойнтінга перетворюється на нуль (`Im { ∇ · S_c } = 0`). Це явище відповідає **об'ємному резонансу** електродинамічної системи, при якому реактивні потоки повністю замикаються усередині об'єму й не потребують реактивного струму від зовнішнього фідерного джерела.

Розглянемо визначення добротності `Q_factor` об'ємного металевого резонатора через комплексну теорему Пойнтінга. За визначенням, добротність дорівнює відношенню запасеної енергії полів `W_stored = ∫_V (u_e,c + u_m,c) dV` до втрат енергії за один радіан коливань:

```
Q_factor = ω · W_stored / P_loss = ω · ∫_V (u_e,c + u_m,c) dV / ( ∮_A Re { S_c } · dA + ∫_V ½ σ |E_c|² dV )
```

Отриманий вираз дозволяє інженерам обчислювати смугу пропускання та згасання резонаторів надвисоких частот безпосередньо з чисельного розподілу полів вектора Пойнтінга на поверхні металевих стінок.

У задачах дифракції та розсіювання електромагнітних хвиль на перешкодах (наприклад, на сферичних краплях води або на металевих літаках) комплексний вектор Пойнтінга розкладається на потік падаючої хвилі `S_inc`, потік розсіяної хвилі `S_sca` та перехресну інтерференційну складову `S_ext = ½ Re { E_inc × H_sca* + E_sca × H_inc* }`. Проінтегрований по перерізу об'єкта потік інтерференційної складової `∮ S_ext · dA` дає повний переріз ослаблення (extinction cross-section) випромінювання за теоремою оптичної тотожності.

## 5. Тензор енергії-імпульсу Белінфанте-Розенфельда та 4-вектор Пойнтінга

У спеціальній теорії відносності вектор Пойнтінга є складовою чотиривимірного тензора енергії-імпульсу електромагнітного поля `T^{μν}` (тензор Белінфанте-Розенфельда). Цей 4-тензор є симетричним тензором другого рангу в просторі Мінковського з коваріантними компонентами:

```
T^{μν} = ε₀ ( F^{μα} F^ν_α - ¼ g^{μν} F^{αβ} F_{αβ} )
```

де `F^{μν}` — 4-тензор електромагнітного поля, а `g^{μν} = diag(1, -1, -1, -1)` — метричний тензор простору-часу.

Компоненти тензора `T^{μν}` мають чіткий фізичний зміст:
- `T⁰⁰ = u = ½ (ε₀ E² + μ₀ H²)` — об'ємна густина енергії полів (часова компонента).
- `c · T⁰ⁱ = S_i = (E × H)_i` — компоненти вектора Пойнтінга (густина потоку енергії вздовж осі `i`).
- `T^{ij} = - σ_{ij}` — тензор натягів Максвелла, що описує густину потоку `j`-ї компоненти імпульсу вздовж напрямку `i`.

Чотиривимірний закон збереження енергії-імпульсу описується диференційним рівнянням неперервності у тензорному вигляді:

```
∂_μ T^{μν} = - (1 / c) F^{να} J_α
```

Часова компонента цього 4-векторного рівняння (`ν = 0`) точно збігається з тривимірною теоремою Пойнтінга `- ∇ · S = ∂u / ∂t + E · J`, тоді як просторові компоненти (`ν = 1, 2, 3`) дають закон збереження імпульсу електромагнітного поля та лоренцеву силу.

Розглянемо релятивістські перетворення Лоренца для вектора Пойнтінга при переході від лабораторної системи відліку `K` до рухомої системи `K'`, що рухається зі швидкістю `V_rel` вздовж осі X. Оскільки вектор Пойнтінга утворює просторові компоненти `T⁰ⁱ`, його поздовжня та поперечні складові перетворюються за законом:

```
S'_x = S_x
S'_y = γ ( S_y - V_rel · u )
S'_z = γ ( S_z )
```

де `γ = 1 / √(1 - V_rel² / c²)` — фактор Лоренца.

З цих релятивістських формул випливає, що потік векторної енергії Пойнтінга трансформується при зміні системи відліку внаслідок релятивістського ефекту Доплера та аберації світла, що підтверджує фізичну реальність вектора Пойнтінга як складової релятивістського 4-імпульсу поля.

У загальній теорії відносності (ЗТВ) Ейнштейна тензор енергії-імпульсу електромагнітного поля `T^{μν}` виступає правим джерелом у диференціальних рівняннях гравітаційного поля `G^{μν} = (8 π G / c⁴) T^{μν}`. З цього випливає, що потік вектора Пойнтінга `S` викривляє геометричний простір-час, створюючи гравітомагнітні ефекти закручування інерціальних систем (ефект Лензе-Тиррінга) навколо інтенсивних обертальних електромагнітних потоків у поблизу нейтронних зірок та чорних дірок.

Розглянемо узагальнене рівняння руху матерії під дією гравітаційного поля та вектора Пойнтінга в екстремальних упливах космологічних масштабів. В астрофізиці акреційних дисків чорних дірок вектор Пойнтінга релятивістських джетів переносить колосальні обсяги магнітної енергії (`P_jet ≈ 1e38` Вт), причому геодезичні лінії руху частинок плазми викривляються під дією натягів тензора Максвелла та релятивістського тиску випромінювання.

## 6. Зведення фундаментальних векторних співвідношень

Наведемо підсумкову систематику виразів для вектора Пойнтінга у різних середовищах та режимах:

1. **Ізотропне вакуумне середовище**:
   `S = E × H = (1 / μ₀) (E × B)`
2. **Комплексний активний потік для гармонічного поля**:
   `P_avg = ½ Re { E_c × H_c* }`
3. **Реактивна складова комплексного вектора**:
   `Q_reactive = ½ Im { E_c × H_c* }`
4. **Об'ємна густина імпульсу електромагнітного поля**:
   `g_field = S / c² = (1 / c²) (E × H)`
5. **Густина потоку енергії у МГД-плазмі**:
   `S_mhd = - (v_plasma × B) × H`

Цей математичний фундамент забезпечує аналітичну та чисельну строгість розв'язання будь-яких задач електродинаміки у неперервних середовищах.

Строгий аналіз математичних тотожностей доводить, що теорема Пойнтінга є прямим наслідком симетрії рівнянь Максвелла щодо просторово-часових зсувів (теорема Нетер для квантованих та класичних векторних полів). Інваріантність диференціальної форми теореми Пойнтінга підтверджує узгодженість класичної векторної теорії з релятивістською електродинамікою.

Остаточне математичне узагальнення теореми Пойнтінга для диференціальних форм описується 3-формою потоку енергії `S_form = E ∧ *H`, дивергенція якої є зовнішньою похідною `d S_form`, що відкриває можливості застосування даного апарату в сучасній топологічній електродинаміці та калібрувальних теоріях полів.

Усі математичні виведення даної вставки доводять строгу логічну замкненість фундаментальних законів збереження енергії у класичній електродинаміці.

Таким чином, сформований аналітичний апарат слугує універсальним містком між теоретичною фізикою Максвелла та обчислювальними методами моделювання полів у новітніх технологічних застосуваннях.
