# 🧮 Виведення теореми Пойнтінга та густини енергії

Математичний опис енергетичних перетворень в електромагнітному полі ґрунтується на фундаментальній системі диференціальних рівнянь Максвелла та теоремах векторного аналізу. Строге виведення закону збереження енергії дозволяє однозначно визначити об'ємну густину енергії електричного та магнітного полів, а також вектор густини потоку енергії (вектор Пойнтінга).

Ця вставка містить доказ векторних тотожностей, виведення локальної та інтегральної форм теореми Пойнтінга, аналіз комплексного вектора Пойнтінга для гармонічних полів, виведення формули Брилюена для густини енергії у середовищах із часовою дисперсією, а також чотиривимірне релятивістське формулювання через тензор енергії-імпульсу.

---

## 1. Векторна тотожність для дивергенції векторного добутку

Для довільних диференційовних векторних полів `A` та `B` у тривимірному евклідовому просторі виконується тотожність векторного аналізу:

```
∇ · (A × B) = B · (∇ × A) − A · (∇ × B)
```

### Доказ у тензорних позначеннях (символ Леві-Чивіта):

Запишемо `k`-ту компоненту векторного добутку `(A × B)_k = ε_{kmn} · A_m · B_n`, де `ε_{kmn}` — повністю антисиметричний тензор Леві-Чивіта. Тоді дивергенція становить:

```
∇ · (A × B) = ∂_k (ε_{kmn} · A_m · B_n)
= ε_{kmn} · (∂_k A_m) · B_n + ε_{kmn} · A_m · (∂_k B_n)   [правило диференціювання добутку]
```

Перегрупуємо індекси у першому та другому доданках, ураховуючи циклічну симетрію тензора Леві-Чивіта `ε_{kmn} = ε_{nmk} = −ε_{nkm}`:

```
ε_{kmn} · (∂_k A_m) · B_n = B_n · (ε_{nmk} · ∂_k A_m) = B · (∇ × A)
ε_{kmn} · A_m · (∂_k B_n) = − A_m · (ε_{mkn} · ∂_k B_n) = − A · (∇ × B)
```

Сумуючи обидві частини, отримуємо вихідну тотожність. Застосуємо її до векторів напруженості електричного поля `E` та напруженості магнітного поля `H`:

```
∇ · (E × H) = H · (∇ × E) − E · (∇ × H)
```

## 2. Підстановка рівнянь Максвелла

Згадаймо два диференціальні рівняння Максвелла для матеріального середовища:

1. **Закон електромагнітної індукції Фарадея:**
   ```
   ∇ × E = − ∂B/∂t
   ```

2. **Закон Ампера — Максвелла:**
   ```
   ∇ × H = j + ∂D/∂t
   ```

де `j` — вектор густини сторонніх струмів провідності, `D` — вектор електричного зсуву, `B` — вектор магнітної індукції.

Підставимо вирази для роторів `∇ × E` та `∇ × H` у векторну тотожність:

```
∇ · (E × H)
= H · (− ∂B/∂t) − E · (j + ∂D/∂t)               [підстановка роторів з рівнянь Максвелла]
= − E · j − E · (∂D/∂t) − H · (∂B/∂t)             [розкриття дужок та угруповання Доданків]
```

Перенесемо скалярний добуток `E · j` у ліву частину, а скалярний добуток `∇ · (E × H)` — у праву:

```
− E · j = E · (∂D/∂t) + H · (∂B/∂t) + ∇ · (E × H)
```

## 3. Перехід до густини енергії у лінійному середовищі

Розглянемо лінійне недиспергуюче середовище, для якого виконуються матеріальні співвідношення:

```
D = ε₀ · ε · E
B = μ₀ · μ · H
```

де `ε` та `μ` — сталі діелектрична та магнітна проникності.

Обчислимо частинну похідну за часом від скалярного квадрата вектора `E`:

```
∂(E · D)/∂t = ∂(ε₀ · ε · E²)/∂t = 2 · ε₀ · ε · E · (∂E/∂t) = 2 · E · (∂D/∂t)
```

Звідси отримуємо важливу тотожність:

```
E · (∂D/∂t) = ½ · ∂(E · D)/∂t                   [вказівка на лінійність D = ε·E]
```

Аналогічно для магнітного поля:

```
H · (∂B/∂t) = ½ · ∂(B · H)/∂t                   [вказівка на лінійність B = μ·H]
```

Сума двох часових похідних дорівнює:

```
E · (∂D/∂t) + H · (∂B/∂t)
= ½ · ∂(E · D)/∂t + ½ · ∂(B · H)/∂t             [перехід до похідної від квадратичних форм]
= ∂/∂t [ ½ · (E · D + B · H) ]                  [винесення часової похідної за дужки]
```

## 4. Означення густини енергії та вектора Пойнтінга

Введемо скалярну величину **об'ємної густини електромагнітної енергії** `w`:

```
w = w_e + w_m = ½ · (E · D + B · H)
```

де:
- `w_e = ½ · E · D = ½ · ε₀ · ε · E²` — густина енергії електричного поля;
- `w_m = ½ · B · H = ½ · (1 / (μ₀ · μ)) · B²` — густина енергії магнітного поля.

Введемо вектор **густини потоку електромагнітної енергії (вектор Пойнтінга)** `S`:

```
S = E × H
```

Тоді отримана рівність набуває вигляду **диференціальної форми теореми Пойнтінга**:

```
∂w/∂t + ∇ · S = − j · E
```

---

## 5. Інтегральна форма теореми Пойнтінга

Проінтегруємо диференціальне рівняння балансу по нерухомому об'єму `V`, обмеженому гладкою замкненою поверхнею `S_bound`:

```
∭_V (∂w/∂t) dV + ∭_V (∇ · S) dV = − ∭_V (j · E) dV
```

Застосуємо теорему Остроградського — Гаусса до другого додатка:

```
∭_V (∇ · S) dV = ∬_{S_bound} S · dS_bound
```

Оскільки геометричні межі об'єму `V` не змінюються з часом, оператор частинної похідної `∂/∂t` у першому доданку можна винести за знак об'ємного інтеграла як повну похідну по часу:

```
∭_V (∂w/∂t) dV = d/dt [ ∭_V w dV ] = dW_field / dt
```

де `W_field = ∭_V w dV` — повна електромагнітна енергія всередині об'єму `V`.

Отримуємо **інтегральну форму теореми Пойнтінга**:

```
− dW_field / dt = ∬_{S_bound} S · dS_bound + ∭_V (j · E) dV
```

### Фізичний зміст членів:
1. `− dW_field / dt` — швидкість зменшення електромагнітної енергії всередині об'єму `V`.
2. `∬_{S_bound} S · dS_bound` — потік енергії поля, що випромінюється або витікає з об'єму `V` назовні через граничну поверхню `S_bound`.
3. `∭_V (j · E) dV` — потужність роботи поля над зарядами (дисипація джоулевого тепла або прискорення частинок).

## 6. Комплексний вектор Пойнтінга для гармонічних полів

У радіотехніці та оптиці поля змінюються за гармонічним законом із частотою `ω`. Зручно застосовувати комплексні амплітуди `E_complex` та `H_complex`:

```
E(t) = Re [ E_complex · e^{i·ω·t} ]
H(t) = Re [ H_complex · e^{i·ω·t} ]
```

Миттєвий вектор Пойнтінга `S(t) = E(t) × H(t)` містить як постійну складову, так і коливання на подвійній частоті `2ω`. Середнє за періодом `T = 2π/ω` значення вектора Пойнтінга `⟨S⟩` обчислюється через **комплексний вектор Пойнтінга** `S_complex`:

```
S_complex = ½ · (E_complex × H_complex*)
```

де `H_complex*` — комплексно-спряжений вектор напруженості магнітного поля.

Тоді середня густина потоку енергії дорівнює дійсній частині комплексного вектора Пойнтінга:

```
⟨S⟩ = Re [ S_complex ] = ½ · Re [ E_complex × H_complex* ]
```

Уявна частина `Im[S_complex]` описує реактивний потік енергії, який осцилює туди й назад між електричним та магнітним полями без безповоротного випромінювання назовні (наприклад, у ближній зоні антен або у стоячих хвилях).

## 7. Формула Брилюена для середовищ із часовою дисперсією

У середовищах із часовою дисперсією діелектрична проникність залежить від частоти `ε = ε(ω)`. Матеріальне співвідношення у часовій області стає інтегральним (із запізненням поляризації):

```
D(t) = ε₀ · ∫₀^∞ ε(τ) · E(t − τ) dτ
```

через це вираз `½ E · D` більше не задає фізичну густину енергії. Розглянемо вузькосмуговий хвильовий пакет із повільно мінливою амплітудою `E₀(t)` близько несучої частоти `ω₀`:

```
E(t) = Re [ E₀(t) · e^{-i·ω₀·t} ]
```

Розкладаючи діелектричну проникність у ряд Тейлора довкола несучої частоти `ω₀`:

```
ε(ω) ≈ ε(ω₀) + (ω − ω₀) · (dε/dω)|_{ω₀}
```

Леон Брилюен (Léon Brillouin) довів, що середня за періодом коливань об'ємна густина енергії `⟨w⟩` у диспергуючому середовищі без сильного поглинання виражається формулою:

```
⟨w⟩ = ½ · ε₀ · d[ω · ε(ω)]/dω · |E₀|² + ½ · μ₀ · d[ω · μ(ω)]/dω · |H₀|²
```

де величини:

```
ε_en = d[ω · ε(ω)]/dω = ε(ω) + ω · (dε/dω)
μ_en = d[ω · μ(ω)]/dω = μ(ω) + ω · (dμ/dω)
```

називаються **енергетичними діелектричною та магнітною проникностями**. У зоні прозорості (побутова оптика, плазма при `ω > ω_p`) похідна `dε/dω > 0`, тому середня густина енергії в середовищі завжди більша за густину енергії поля у вакуумі. Цей надлишок відповідає кінетичній енергії поляризованих електронів речовини.

## 8. Тензор натягів Максвелла та релятивістське формулювання

Локальний баланс імпульсу електромагнітного поля виражається через **тензор натягів Максвелла** `T_{ij}`:

```
T_{ij} = ε₀ · E_i · E_j + (1 / μ₀) · B_i · B_j − ½ · ( ε₀ · E² + (1 / μ₀) · B² ) · δ_{ij}
```

де `δ_{ij}` — символ Кронекера. Об'ємна густина лоренцівської сили `f_Lorentz = ρ · E + j × B`, що діє на заряди у речовині, пов'язана із тензором натягів та вектором Пойнтінга співвідношенням:

```
f_Lorentz = ∇ · T − (1 / c²) · ∂S/∂t
```

У чотиривимірному псевдоевклідовому просторі Минковського (спеціальна теорія відносності) густина енергії `w`, потік Пойнтінга `S` та тензор натягів `T_{ij}` об'єднуються у симетричний **чотири-тензор енергії-імпульсу** `T^{μν}`:

```
T^{00} = w = ½ · ( ε₀ · E² + (1 / μ₀) · B² )
T^{0i} = S_i / c
T^{ij} = − T_{ij}
```

Чотиривимірна дивергенція тензора енергії-імпульсу дорівнює чотири-вектору густини сили Лоренца `f^ν`:

```
∂_μ T^{μν} = − (1 / c) · F^{νλ} · j_λ
```

де `F^{νλ}` — 4-тензор електромагнітного поля, `j_λ` — 4-вектор густини струму.

Цей релятивістський запис остаточно демонструє, що теорема Пойнтінга є часовою 0-компонентою єдиного чотиривимірного закону збереження енергії та імпульсу електромагнітного поля у просторі-часі.
