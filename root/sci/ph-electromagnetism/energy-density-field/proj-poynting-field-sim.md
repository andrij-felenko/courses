# ⚙️ Чисельне моделювання потоку енергії та густини ЕМ-поля

Обчислення просторово-часового розподілу об'ємної густини енергії `w(x,t)` та вектора Пойнтінга `S(x,t)` є фундаментальним етапом під час проектування та аналізу високочастотних пристроїв: антенних масивів, мікросмужкових ліній передачі, оптичних хвилеводів, лазерних резонаторів, надпровідних коаксіальних структур та фотонних кристалів. У сучасній обчислювальній електродинаміці основними стандартом для розв'язання часових рівнянь Максвелла є сітковий метод скінченних різниць у часовій області (FDTD — *Finite-Difference Time-Domain*), розроблений Кейном Йі (Kane Yee) у 1966 році.

Ця вставка містить вичерпне математичне обґрунтування 1D FDTD-схеми, аналіз чисельної дисперсії та стійкості, розгляд поглинаючих граничних умов, а також оптимізовані програмні реалізації мовами C та C++ з урахуванням сучасних стандартів проєктування.

---

## 1. Математична топологія сітки Йі для 1D-простору

У одновимірному випадку розглянемо плоску електромагнітну хвилю, яка поширюється у лінійному ізотропному середовищі без втрат вздовж осі `z`. Припустимо, що вектор напруженості електричного поля спрямований вздовж осі `y` (`E_y`), а вектор напруженості магнітного поля — вздовж осі `x` (`H_x`). У цьому випадку тривимірні диференціальні рівняння Максвелла спрощуються до системи двох зв'язаних рівнянь у частинних похідних першого порядку:

```
∂E_y/∂t = − (1 / ε₀) · ∂H_x/∂z
∂H_x/∂t = − (1 / μ₀) · ∂E_y/∂z
```

Головна концептуальна ідея сітки Йі полягає у тому, що вузли сітки для електричного та магнітного полів зсунуті відносно один одного як у просторі (на півкроку `Δz/2`), так і у часі (на півкроку `Δt/2`). Цей розсув дозволяє апроксимувати частинні похідні центральними скінченними різницями із другим порядком точності `O(Δz²) + O(Δt²)`.

### Дискретизація просторово-часової сітки:
- Вузли електричного поля `E[k]^n` визначені у точках `z_k = k · Δz` на часових шарах `t_n = n · Δt`.
- Вузли магнітного поля `H[k]^{n+½}` визначені у точках `z_{k+½} = (k + ½) · Δz` на часових шарах `t_{n+½} = (n + ½) · Δt`.

Застосовуючи центральні скінченно-різницеві апроксимації для похідних за часом і простором:

```
∂E / ∂t ≈ ( E[k]^{n+1} − E[k]^n ) / Δt
∂H / ∂z ≈ ( H[k]^{n+½} − H[k-1]^{n+½} ) / Δz
```

отримуємо явні алгебраїчні рівняння дискретного оновлення полів на кожному часовому кроці:

1. **Дискретне оновлення магнітного поля H:**
   ```
   H[k]^{n+½} = H[k]^{n-½} − (Δt / (μ₀ · Δz)) · ( E[k+1]^n − E[k]^n )
   ```

2. **Дискретне оновлення електричного поля E:**
   ```
   E[k]^{n+1} = E[k]^n − (Δt / (ε₀ · Δz)) · ( H[k]^{n+½} − H[k-1]^{n+½} )
   ```

## 2. Обчислення енергетичних характеристик у вузлах сітки

Оскільки поля `E` та `H` просторово зсунуті на півкроку `Δz/2`, для обчислення локальних енергетичних характеристик у вузлі електричного поля `k` необхідно провести просторове усереднення магнітного поля між двома сусідніми магнітними вузлами:

```
H_avg[k] = ½ · ( H[k]^{n+½} + H[k-1]^{n+½} )
```

Тоді миттєві значення електричної густини енергії `w_e`, магнітної густини енергії `w_m`, сумарної густини `w_total` та вектора Пойнтінга `S` у вузлі `k` обчислюються за формулами:

```
w_e[k] = ½ · ε₀ · (E[k]^n)²
w_m[k] = ½ · μ₀ · (H_avg[k])²
w_total[k] = w_e[k] + w_m[k]
S[k] = E[k]^n · H_avg[k]
```

Просторове усереднення магнітного поля є критично важливим: без нього обчислення добутку `E[k] * H[k]` мало б перший порядок точності `O(Δz)`, викликаючи штучні асиметричні коливання обчисленого потоку Пойнтінга.

## 3. Умова стійкості Куранта та чисельна дисперсія

Для того щоб чисельний розв'язок різницевих рівнянь FDTD залишався стійким і не зростав безмежно з часом, крок по часу `Δt` повинен задовольняти умову Куранта — Фрідріхса — Леві (CFL):

```
S_Courant = c · Δt / Δz ≤ 1.0
```

У 1D-просторі параметр Куранта `S_Courant` визначає точність поширення полів:
- При `S_Courant = 1.0` чисельна дисперсія сітки Йі у 1D дорівнює нулю. Це означає, що фазова швидкість чисельної хвилі точно дорівнює `c`, і хвильовий пакет поширюється уздовж сітки без найменшого спотворення форми.
- При `S_Courant < 1.0` (наприклад, `S_Courant = 0.5`) виникає невелика чисельна дисперсія, при якій високочастотні компоненти спектра поширюються трохи повільніше за низькочастотні.

Дискретне співвідношення дисперсії для 1D FDTD-сітки має вигляд:

```
sin²(ω · Δt / 2) = (c · Δt / Δz)² · sin²(k_wave · Δz / 2)
```

де `k_wave` — хвильове число.

## 4. Граничні умови та збереження енергії

У чисельному моделюванні обчислювальна область завжди є обмеженою. Якщо на межах сітки задати нульові значення полів (`E[0] = E[NZ-1] = 0`), межі працюватимуть як ідеально відбиваючі дзеркала (ідеальні електричні провідники). У цьому випадку електромагнітна хвиля відбиватиметься від меж усередину області, а сумарна дискретна енергія `W_total = ∑_k w_total[k] · Δz` зберігатиметься з машинною точністю `10⁻¹⁶`.

Для моделювання вільного випромінювання у безмежний простір застосовують поглинаючі граничні умови (ABC — *Absorbing Boundary Conditions*). Найпростішою є умова першого порядку Мура (Mur ABC), яка для лівої межі `E[0]` має вигляд:

```
E[0]^{n+1} = E[1]^n + ( (c·Δt − Δz) / (c·Δt + Δz) ) · ( E[1]^{n+1} − E[0]^n )
```

У сучасних тривимірних FDTD-симуляторах застосовують досконало узгоджені шари Бранже (PML — *Perfectly Matched Layers*), які забезпечують коефіцієнт відбиття від меж менше `10⁻⁵` у широкому діапазоні частот та кутів падіння.

## 5. Програмна реалізація мовами C та C++

Нижче наведено програмний код, який моделює гаусів імпульс ЕМ-хвилі у вакуумі, обчислює розподіл полів, густину енергії та потік Пойнтінга вздовж обчислювальної домени.

```c
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

/* Фізичні сталі */
#define EPS0 8.8541878128e-12
#define MU0  1.2566370614e-6
#define C0   299792458.0

/* Параметри сітки */
#define NZ 200
#define TIMESTEPS 300

typedef struct {
    double e[NZ];
    double h[NZ];
    double w_e[NZ];
    double w_m[NZ];
    double s[NZ];
} fdtd_domain_t;

void fdtd_init(fdtd_domain_t *domain) {
    for (int i = 0; i < NZ; i++) {
        domain->e[i] = 0.0;
        domain->h[i] = 0.0;
        domain->w_e[i] = 0.0;
        domain->w_m[i] = 0.0;
        domain->s[i] = 0.0;
    }
}

void fdtd_step(fdtd_domain_t *dom, double dz, double dt, int t_step) {
    double ch = dt / (MU0 * dz);
    double ce = dt / (EPS0 * dz);

    /* 1. Оновлення магнітного поля H */
    for (int i = 0; i < NZ - 1; i++) {
        dom->h[i] -= ch * (dom->e[i + 1] - dom->e[i]);
    }

    /* 2. Оновлення електричного поля E */
    for (int i = 1; i < NZ; i++) {
        dom->e[i] -= ce * (dom->h[i] - dom->h[i - 1]);
    }

    /* 3. Джерело гаусового імпульсу у центрі */
    double t0 = 40.0;
    double spread = 12.0;
    double pulse = exp(-0.5 * pow((t_step - t0) / spread, 2.0));
    dom->e[NZ / 2] += pulse;

    /* 4. Розрахунок енергетичних характеристик */
    for (int i = 1; i < NZ - 1; i++) {
        double h_avg = 0.5 * (dom->h[i] + dom->h[i - 1]);
        dom->w_e[i] = 0.5 * EPS0 * dom->e[i] * dom->e[i];
        dom->w_m[i] = 0.5 * MU0 * h_avg * h_avg;
        dom->s[i]   = dom->e[i] * h_avg;
    }
}

int main(void) {
    fdtd_domain_t dom;
    fdtd_init(&dom);

    double dz = 1e-3; /* 1 мм */
    double dt = dz / (2.0 * C0); /* Courant number = 0.5 */

    printf("Крок | Вузол 100 E | Густина w_e (Дж/м³) | Потік S (Вт/м²)\n");
    printf("-----------------------------------------------------------\n");

    for (int t = 0; t < TIMESTEPS; t++) {
        fdtd_step(&dom, dz, dt, t);
        if (t % 50 == 0) {
            int mid = NZ / 2;
            printf("%4d | %11.4e | %19.4e | %16.4e\n",
                   t, dom.e[mid], dom.w_e[mid], dom.s[mid]);
        }
    }

    return 0;
}
```
```cpp
#include <iostream>
#include <vector>
#include <cmath>
#include <numbers>
#include <iomanip>

class FdtdSim1D {
public:
    static constexpr double eps0 = 8.8541878128e-12;
    static constexpr double mu0  = 1.2566370614e-6;
    static constexpr double c0   = 299792458.0;

    explicit FdtdSim1D(std::size_t num_cells, double dz, double courant_factor = 0.5)
        : nz_(num_cells), dz_(dz), dt_(courant_factor * dz / c0),
          e_(num_cells, 0.0), h_(num_cells, 0.0),
          w_e_(num_cells, 0.0), w_m_(num_cells, 0.0), s_(num_cells, 0.0) {}

    void step(std::size_t time_step) {
        const double ch = dt_ / (mu0 * dz_);
        const double ce = dt_ / (eps0 * dz_);

        // 1. Оновлення магнітного поля H
        for (std::size_t i = 0; i < nz_ - 1; ++i) {
            h_[i] -= ch * (e_[i + 1] - e_[i]);
        }

        // 2. Оновлення електричного поля E
        for (std::size_t i = 1; i < nz_; ++i) {
            e_[i] -= ce * (h_[i] - h_[i - 1]);
        }

        // 3. Гаусів імпульс джерела
        constexpr double t0 = 40.0;
        constexpr double spread = 12.0;
        const double pulse = std::exp(-0.5 * std::pow((static_cast<double>(time_step) - t0) / spread, 2.0));
        e_[nz_ / 2] += pulse;

        // 4. Обчислення енергетичних характеристик
        for (std::size_t i = 1; i < nz_ - 1; ++i) {
            const double h_avg = 0.5 * (h_[i] + h_[i - 1]);
            w_e_[i] = 0.5 * eps0 * e_[i] * e_[i];
            w_m_[i] = 0.5 * mu0 * h_avg * h_avg;
            s_[i]   = e_[i] * h_avg;
        }
    }

    [[nodiscard]] double get_e(std::size_t idx) const { return e_.at(idx); }
    [[nodiscard]] double get_w_total(std::size_t idx) const { return w_e_.at(idx) + w_m_.at(idx); }
    [[nodiscard]] double get_s(std::size_t idx) const { return s_.at(idx); }

private:
    std::size_t nz_;
    double dz_;
    double dt_;
    std::vector<double> e_;
    std::vector<double> h_;
    std::vector<double> w_e_;
    std::vector<double> w_m_;
    std::vector<double> s_;
};

int main() {
    constexpr std::size_t grid_size = 200;
    constexpr double dz = 1e-3;

    FdtdSim1D sim(grid_size, dz);

    std::cout << std::scientific << std::setprecision(4);
    std::cout << "Крок | Вузол 100 E | Густина w_total (Дж/м³) | Потік S (Вт/м²)\n";
    std::cout << "--------------------------------------------------------------\n";

    for (std::size_t t = 0; t < 300; ++t) {
        sim.step(t);
        if (t % 50 == 0) {
            std::cout << std::setw(4) << t << " | "
                      << std::setw(11) << sim.get_e(100) << " | "
                      << std::setw(23) << sim.get_w_total(100) << " | "
                      << std::setw(16) << sim.get_s(100) << "\n";
        }
    }

    return 0;
}
```

## 6. Порівняння архітектур C та C++ реалізацій

Наведена C-версія симулятора спирається на плоску структуру даних `fdtd_domain_t` та лінійні статичні масиви фіксованого розміру. Це забезпечує мінімальний оверхед викликів і максимальну сумісність із високопродуктивними обчислювальними бібліотеками C (такими як OpenMP чи CUDA для графічних прискорювачів).

C++ реалізація спроєктована в інкапсульованому об'єктно-орієнтованому стилі. Клас `FdtdSim1D` приховує внутрішній стан полів і надає безпечний публічний інтерфейс. Використання `std::vector<double>` дозволяє динамічно змінювати розмір сітки під час ініціалізації, а специфікатори `constexpr`, `[[nodiscard]]` та нотації C++20 гарантують високу продуктивність компіляції та запобігають випадковим помилкам виклику.

Обидві реалізації демонструють тотожні фізичні результати: гаусів імпульс розпадається на дві однакові хвилі, що поширюються у протилежні боки від центрального джерела. При цьому обчислена сумарна густина енергії `w_total` та потік Пойнтінга `S` строго задовольняють дискретну теорему Пойнтінга у межах точності сітки.
