# 🧮 Математичне виведення формули Лармора та релятивістського узагальнення Льєнара

Розрахунок електромагнітної енергії, яку випромінює прискорена заряджена частинка, вимагає строгого математичного розв'язання системи мікроскопічних рівнянь Максвелла для точкового джерела з урахуванням скінченної швидкості поширення інформації у просторі.

---

## 1. Неоднорідні хвильові рівняння та запізнілі потенціали

У вакуумі скалярний потенціал `Φ` та векторний потенціал `A` у калібруванні Лоренца `∇ · A + (1/c²) · (∂Φ/∂t) = 0` задовольняють лінійні неоднорідні хвильові рівняння Д'Аламбера:

```
∇²Φ - (1 / c²) · (∂²Φ / ∂t²) = - ρ / ε₀
∇²A - (1 / c²) · (∂²A / ∂t²) = - μ₀ · J
```

де `ρ(r, t)` та `J(r, t)` — густина заряду та густина струму джерела.

Для точкової частинки з зарядом `q`, що рухається за траєкторією `r₀(t)` зі швидкістю `v(t) = dr₀ / dt`, мікроскопічні джерела записуються через тривимірну дельта-функцію Дірака `δ³(r)`:

```
ρ(r, t) = q · δ³(r - r₀(t))
J(r, t) = q · v(t) · δ³(r - r₀(t))
```

Розв'язок хвильових рівнянь за допомогою причинної функції Гріна Д'Аламбера `G(r - r', t - t') = δ(t - t' - |r - r'| / c) / (4 · π · |r - r'|)` зводить інтеграли до стану частинки в єдиний **запізнілий момент часу** `t_ret`:

```
t_ret = t - R(t_ret) / c
```

де `R = r - r₀(t_ret)` — вектор, напрямлений від точки випромінювання заряду в минулому до точки спостереження в теперішньому часі, а `R = |R|` — відповідна відстань. Одиничний вектор спостереження позначається `n = R / R`.

Інтегрування дельта-функції з урахуванням складної залежності аргументу від часу вимагає ділення на похідну за часом:

```
d/dt' [ t' - (t - |r - r₀(t')| / c) ] = 1 - (n · v(t')) / c = 1 - n · β
```

де введено безрозмірну швидкість `β = v / c`. Це породжує точні **потенціали Льєнара-Віхерта**:

```
Φ(r, t) = q / (4 · π · ε₀ · R · (1 - n · β))
A(r, t) = (q · v) / (4 · π · ε₀ · c² · R · (1 - n · β)) = (v / c²) · Φ(r, t)
```

Знаменник `κ = 1 - n · β` є кінематичним фактором стискання поля. Він відображає просторове ущільнення хвильових фронтів у напрямку руху частинки внаслідок класичного ефекту Доплера.

## 2. Диференціювання потенціалів та структура полів Фейнмана-Гевісайда

Фізичні напруженості електричного `E` та магнітного `B` полів обчислюються як просторові та часові градієнти потенціалів:

```
E = - ∇Φ - ∂A / ∂t
B = ∇ × A
```

Оскільки запізнілий час `t_ret` неявно залежить від координат `r` та часу спостереження `t`, оператори диференціювання діють як на явні координати, так і через запізнілу часову змінну:

```
∂t_ret / ∂t = 1 / (1 - n · β)
∇t_ret = - n / (c · (1 - n · β))
```

Виконавши пряме векторне диференціювання потенціалів Льєнара-Віхерта, отримуємо строгий розклад напруженості електричного поля на дві складові з кардинально різною просторовою поведінкою:

```
E(r, t) = E_vel + E_rad
```

### 1. Поле швидкості (квазістатичне кулонівське поле)
```
E_vel = (q / (4 · π · ε₀ · γ²)) · (n - β) / (R² · (1 - n · β)³)
```
Поле швидкості спадає обернено пропорційно квадрату відстані `1 / R²`. Воно залишається жорстко прив'язаним до рівномірного руху заряду і не виносить енергію на просторову нескінченність.

### 2. Поле прискорення (поле випромінювання)
```
E_rad = (q / (4 · π · ε₀ · c)) · (n × ((n - β) × a)) / (R · (1 - n · β)³)
```
Поле прискорення прямо пропорційне прискоренню заряду `a = dv/dt` і спадає як `1 / R`. Саме ця повільно спадна хвиля формує випромінювання.

Магнітне поле у хвильовій зоні повністю визначається поперечною компонентою електричного поля:

```
B_rad = (1 / c) · (n × E_rad)
```

## 3. Виведення нерелятивістської формули Лармора

Розглянемо нерелятивістську границю, коли швидкість частинки набагато менша за швидкість світла у вакуумі (`v ≪ c`, тобто `β → 0`, `γ → 1`). У цьому граничному режимі доплерівський знаменник перетворюється на одиницю `1 - n · β ≈ 1`, а вираз для поля випромінювання набуває простого вигляду:

```
E_rad = (q / (4 · π · ε₀ · c² · R)) · [ n × (n × a) ]
```

Розкриємо подвійний векторний добуток за стандартним векторним правилом Бац-Мінус-Цаб:

```
n × (n × a) = (n · a) · n - a
```

Модуль цього вектора дорівнює проекції прискорення на площину, перпендикулярну до напрямку спостереження `n`:

```
|n × (n × a)| = a · sin θ
```

де `θ` — кут між вектором прискорення `a` та вектором спостереження `n`. Тоді амплітуда поперечного електричного поля дорівнює:

```
E_rad = (q · a · sin θ) / (4 · π · ε₀ · c² · R)
```

Вектор Пойнтінга `S`, що визначає миттєвий потік електромагнітної енергії через одиницю площі, спрямований строго радіально назовні вздовж вектора `n`:

```
S = (1 / μ₀) · (E_rad × B_rad)
= (1 / (μ₀ · c)) · |E_rad|² · n    [підстановка ортогонального поля B_rad = (1/c) n × E_rad]
= ε₀ · c · |E_rad|² · n            [використання електродинамічного зв'язку c² = 1 / (ε₀ · μ₀)]
```

Підставляючи модуль напруженості поля `E_rad`:

```
S = (q² · a² · sin²θ) / (16 · π² · ε₀ · c³ · R²) · n
```

Диференціальна потужність у тілесному куті `dΩ = sin θ dθ dφ` дорівнює:

```
dP / dΩ = R² · (S · n) = (q² · a² · sin²θ) / (16 · π² · ε₀ · c³)
```

Для знаходження повної інтегральної потужності `P` виконаємо інтегрування по сфері повного тілесного кута `4π` стерадіан:

```
P = ∮ (dP / dΩ) dΩ
= ∫₀²π dφ · ∫₀π (q² · a² · sin²θ / (16 · π² · ε₀ · c³)) · sin θ dθ  [перехід до сферичних кутів dΩ = sin θ dθ dφ]
= (q² · a² / (16 · π² · ε₀ · c³)) · 2π · ∫₀π sin³θ dθ               [інтегрування за кутом φ від 0 до 2π]
```

Обчислимо визначений інтеграл за допомогою підстановки `u = cos θ`, `du = - sin θ dθ`:

```
∫₀π sin³θ dθ
= ∫₀π (1 - cos²θ) · sin θ dθ      [тригонометрична тотожність sin²θ = 1 - cos²θ]
= ∫₋₁¹ (1 - u²) du                [заміна u = cos θ, межі від 1 до -1 з урахуванням мінуса]
= [u - u³ / 3]₋₁¹                 [первісна многочлена]
= (1 - 1/3) - (-1 - (-1)/3)       [підстановка меж інтегрування]
= (2/3) - (-2/3)                  [арифметика дробів]
= 4 / 3                           [остаточне значення інтеграла]
```

Підставивши значення `4/3` у вираз для повної потужності, отримуємо класичну **формулу Лармора**:

```
P
= (q² · a² / (16 · π² · ε₀ · c³)) · 2π · (4 / 3)   [підстановка обчисленого інтеграла]
= (q² · a² · 8π) / (48 · π² · ε₀ · c³)             [множення чисельників та знаменників]
= (q² · a²) / (6 · π · ε₀ · c³)                    [скорочення на спільний дільник 8π]
```

## 4. Лоренц-інваріантне 4-векторне виведення формули Льєнара

У спеціальній теорії відносності повна випромінена 4-енергія-імпульс `d P^μ` частинки за інтервал власного часу `dτ = dt / γ` утворює 4-вектор. Оскільки у власній системі спокою частинка випромінює симетрично вперед і назад, просторовий імпульс випромінювання дорівнює нулю `d P = 0`. Отже, потужність випромінювання `P = dE / dτ` є скалярним релятивістським інваріантом.

Єдиним лоренц-інваріантним скаляром, пропорційним квадрату похідних швидкості частинки, є 4-квадрат 4-прискорення `a^μ = d u^μ / dτ`, де `u^μ = γ · (c, v)` — 4-швидкість.

У просторі Мінковського з метричним тензором `η_{μν} = diag(1, -1, -1, -1)` інваріантна потужність виражається як:

```
P = - (q² / (6 · π · ε₀ · c³)) · (a_μ a^μ)
```

Знак мінус забезпечує додатність потужності, оскільки для дійсного руху простороподібне 4-прискорення задовольняє умову `a_μ a^μ ≤ 0`.

Обчислимо компоненти 4-прискорення через звичайні тривимірні швидкість `v` та прискорення `a = dv/dt`:

```
a⁰ = d u⁰ / dτ = γ · d/dt (γ · c) = (γ⁴ / c) · (v · a)
a = d u / dτ = γ · d/dt (γ · v) = γ² · a + (γ⁴ / c²) · (v · a) · v
```

Знайдемо 4-скалярний добуток:

```
a_μ a^μ
= (a⁰)² - |a|²                                              [розкриття часової та просторової компонент]
= (γ⁸ / c²) · (v · a)² - |γ² · a + (γ⁴ / c²) · (v · a) · v|² [підстановка явних компонент 4-прискорення]
= - γ⁴ · a² - (γ⁶ / c²) · (v · a)²                           [спрощення та приведення подібних членів]
```

Скористаємося векторною тотожністю Лагранжа для векторного добутку `(v × a)² = v² · a² - (v · a)²`:

```
(v · a)² = v² · a² - (v × a)²
```

Підставляючи це співвідношення у 4-квадрат прискорення:

```
a_μ a^μ
= - γ⁴ · a² - (γ⁶ / c²) · [ v² · a² - (v × a)² ]
= - γ⁶ · [ a² · (γ⁻² + v²/c²) - (v × a)² / c² ]
= - γ⁶ · [ a² · (1 - v²/c² + v²/c²) - (v × a)² / c² ]
= - γ⁶ · [ a² - (v × a)² / c² ]
```

Підставляючи отриманий інваріант у вираз для потужності, приходимо до фундаментальної **релятивістської формули Льєнара**:

```
P = (q² · γ⁶ / (6 · π · ε₀ · c³)) · [ a² - |v × a|² / c² ]
```

## 5. Фізичний аналіз граничних випадків формули Льєнара

### А. Поздовжній рух (v ∥ a, лінійне гальмування)
При лінійному прискоренні швидкість паралельна прискоренню, отже, векторний добуток зникає: `v × a = 0`. Формула спрощується до:

```
P_long = (q² · a² · γ⁶) / (6 · π · ε₀ · c³)
```

Виразимо цю потужність через силу `F = dp/dt = m · γ³ · a`:

```
P_long = (q² / (6 · π · ε₀ · m² · c³)) · (dp / dt)²
```

### Б. Поперечний рух (v ⊥ a, синхротронний рух по колу)
У поворотному магнітному полі прискорення є доцентровим і перпендикулярним до швидкості: `v · a = 0`, а `|v × a| = v · a`. Дужка Льєнара спрощується:

```
a² - (v² · a²) / c² = a² · (1 - v² / c²) = a² / γ²
```

Підставляючи у формулу Льєнара:

```
P_trans
= (q² · γ⁶ / (6 · π · ε₀ · c³)) · (a² / γ²)    [підстановка скороченої дужки для доцентрового руху]
= (q² · a² · γ⁴) / (6 · π · ε₀ · c³)           [скорочення степенів фактора Лоренца γ⁶ / γ² = γ⁴]
= (q² · v⁴ · γ⁴) / (6 · π · ε₀ · c³ · R²)      [підстановка доцентрового прискорення a = v² / R]
```

Для ультрарелятивістських частинок (`v ≈ c`), виражаючи енергію через `E = γ · m · c²`:

```
P_synch = (q² · c · γ⁴) / (6 · π · ε₀ · R²) = (q² / (6 · π · ε₀ · m⁴ · c⁷ · R²)) · E⁴
```

Це доводить, що синхротронні втрати зростають як четвертий степінь енергії частинки `E⁴` і обернено пропорційні четвертому степеню її маси спокою `m⁴`.

## 6. Мультипольний розклад випромінювання та квадрупольна поправка

Якщо джерелом поля є не одна точкова частинка, а просторово розподілена система зарядів розміру `d`, векторний потенціал у хвильовій зоні (`R ≫ d`) розкладається в ряд Тейлора за малим просторовим параметром запізнення `(d / λ) ≪ 1` (де `λ` — довжина хвилі випромінювання):

```
A(r, t) = (μ₀ / (4 · π · R)) · ∫ J(r', t - R/c + (n · r') / c) dr'
```

Розкладемо густину струму в ряд за малим зсувом часу `Δt = (n · r') / c`:

```
J(r', t_ret + Δt) ≈ J(r', t_ret) + (1 / c) · (n · r') · (∂J / ∂t) + ...
```

### 1. Нульовий порядок: Електричне дипольне випромінювання (E1)
Головний член розкладу зводиться до інтеграла від густини струму, який за рівнянням неперервності `∇ · J = - ∂ρ/∂t` виражається через другу похідну повного електричного дипольного моменту системи `d(t) = ∫ r' · ρ(r', t) dr'`:

```
∫ J(r', t_ret) dr' = ḋ(t_ret)
```

Векторний потенціал та поля у дипольному наближенні мають вигляд:

```
A_E1 = (μ₀ / (4 · π · R)) · ḋ(t_ret)
E_E1 = (μ₀ / (4 · π · R)) · [ n × (n × d̈) ]
```

Інтегрування вектора Пойнтінга по сфері дає узагальнену формулу Лармора для диполя:

```
P_E1 = (μ₀ · |d̈|²) / (6 · π · c) = |d̈|² / (6 · π · ε₀ · c³)
```

### 2. Перший порядок: Магнітний диполь (M1) та електричний квадруполь (E2)
Другий член розкладу струму розпадається на симетричну та антисиметричну тензорні частини. Антисиметрична частина відповідає випромінюванню магнітного дипольного моменту `m = ½ ∫ (r' × J) dr'`:

```
P_M1 = (μ₀ · |m̈|²) / (6 · π · c³) = (μ₀ · ω⁴ · |m|²) / (6 · π · c³)
```

Симетрична частина визначається тензором електричного квадрупольного моменту системи `Q_{ij} = ∫ ρ(r') · (3 x_i' x_j' - r'² δ_{ij}) dr'`:

```
P_E2 = (μ₀ / (360 · π · c³)) · ∑_{i,j} (d³Q_{ij} / dt³)²
```

Потужність квадрупольного випромінювання пропорційна шостому степеню частоти `P_E2 ∝ ω⁶`, що менше за дипольне випромінювання `P_E1 ∝ ω⁴` у `(d / λ)² ∝ (v / c)²` разів.

Цей висновок є фундаментальним: для систем частинок з однаковим питомим зарядом `q/m` (наприклад, при пружному зіткненні двох електронів), де дипольний момент не прискорюється (`d̈ = 0`), електричне квадрупольне випромінювання `P_E2` стає головним каналом втрати енергії.
