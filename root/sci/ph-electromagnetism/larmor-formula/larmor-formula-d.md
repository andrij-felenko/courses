# Формула Лармора

<preknowlist>
- [Вектор Пойнтінга](root:ph-electromagnetism/poynting-vector) — потік густини електромагнітної енергії у просторі.
- [Рівняння Максвелла](root:ph-electromagnetism/maxwell-equations) — диференціальні закони взаємозв'язку електричного та магнітного полів.
- [Закон Кулона](root:ph-electromagnetism/coulomb-law) — статичне поле та взаємодія нерухомих точкових зарядів.
- [Сила Лоренца](root:ph-electromagnetism/lorentz-force) — дія електромагнітного поля на рухомий заряд.
- [Електромагнітна хвиля](root:ph-electromagnetism/em-wave) — хвильове рівняння та поперечні коливання полів зі швидкістю світла.
</preknowlist>

Електричний заряд, що рухається у вакуумі з постійною швидкістю вздовж прямої лінії, переносить разом із собою власне електричне та магнітне поле, не втрачаючи жодного джоуля енергії на випромінювання у навколишній простір. У супутній системі відліку такий заряд перебуває у спокої, створюючи виключно статичне кулонівське поле `E ∝ 1/r²`. При переході в лабораторну систему через релятивістське перетворення Лоренца з'являється вихрове магнітне поле `B = (1/c²) · (v × E)`, а вектор Пойнтінга `S = (1/μ₀) · (E × B)` спадає з відстанню як `1/r⁴`. Якщо оточити заряд уявною сферою радіуса `r`, площа якої зростає як `r²`, повний інтегральний потік енергії через цю сферу прямує до нуля: `∮ S · dA ∝ (1/r⁴) · r² = 1/r² → 0` при `r → ∞`. Електромагнітне поле залишається жорстко «прив'язаним» до носія заряду, утворюючи його невіддільну динамічну оболонку. Проте варто заряду отримати навіть найменше прискорення `a = dv/dt ≠ 0`, як ситуація зазнає фундаментальної зміни: зміна швидкості не може передатися в навколишній простір миттєво через скінченну швидкість поширення електромагнітної взаємодії `c`. У структурі силових ліній виникає поперечний зсув (перегин), який зі швидкістю світла біжить назовні. У цьому шарі збурення амплітуда поперечного електричного поля спадає набагато повільніше — як `1/r`. Вектор Пойнтінга набуває вигляду `S ∝ 1/r²`, а повний потік енергії через довільно далеку сферу `∮ S · dA` виявляється строго постійною, ненульовою величиною. Електромагнітна енергія назавжди відривається від джерела й виноситься у простір у вигляді вільної хвилі. У 1897 році британський фізик Джозеф Лармор довів, що миттєва потужність випромінювання нерелятивістського точкового заряду `q` пропорційна квадрату його прискорення:

```
P = (q² · a²) / (6 · π · ε₀ · c³)
```

де `ε₀` — електрична стала, а `c` — швидкість світла у вакуумі.

## 1. Геометрія перегину силових ліній: модель Томсона-Перселла

Щоб зрозуміти, чому прискорення породжує повільно спадне поле `1/r`, розглянемо геометричну модель поширення інформації про стан заряду, запропоновану Джозефом Джоном Томсоном та розвинену Едвардом Перселлом.

Нехай точковий заряд `q` перебуває у спокої на початку координат `x = 0` до моменту часу `t = 0`. Його електричні силові лінії розходяться строго радіально в усіх напрямках, а модуль напруженості задається законом Кулона `E_r = q / (4 · π · ε₀ · r²)`.

![Геометрія перегину силових ліній прискореного заряду](/root/sci/ph-electromagnetism/larmor-formula/img/field-kink.svg)
*Геометрія виникнення поперечного поля випромінювання в моделі Томсона-Перселла: розрив радіальних ліній у шарі запізнення товщиною c·Δt*

Упродовж короткого проміжку часу `Δt` зовнішня сила надає заряду постійне прискорення `a`, після чого частинка продовжує рівномірний рух із набутою швидкістю `Δv = a · Δt` (вважаємо `Δv ≪ c`). Розглянемо конфігурацію силових ліній у момент часу `t ≫ Δt`:

1. **Зовнішня область (`r > c · t`):** Світловий сигнал про те, що заряд взагалі зрушив з місця, ще не встиг дійти до цих точок простору. Силові лінії в цій області залишаються строго радіальними й спрямованими так, ніби заряд досі нерухомо спочиває в початковій точці `x = 0`.
2. **Внутрішня область (`r < c · (t - Δt)`):** Сюди дійшла інформація про те, що прискорення припинилося і частинка рухається рівномірно. Силові лінії тут є радіальними відносно поточного положення заряду `x = Δv · t`.
3. **Перехідний шар товщиною `Δr = c · Δt`:** Оскільки у вакуумі немає вільних сторонніх зарядів, за теоремою Гаусса `∇ · E = 0` силові лінії електричного поля не можуть обриватися у порожнечі. Отже, радіальні лінії внутрішньої області зобов'язані неперервно з'єднатися з лініями зовнішньої області всередині сферичного шару радіуса `r ≈ c · t`.

Через просторове зміщення центру внутрішніх ліній на відстань `Δx_perp = (a · t · Δt) · sin θ` відносно зовнішніх ліній, кожна силова лінія у перехідному шарі зазнає різкого тангенціального зламу (перегину). З подібності трикутників відношення поперечної компоненти електричного поля `E_perp` до радіальної кулонівської компоненти `E_r` дорівнює відношенню зміщення до товщини шару:

```
E_perp / E_r
= (Δv · t · sin θ) / (c · Δt)            [відношення геометричних зміщень у шарі]
= (a · Δt · t · sin θ) / (c · Δt)        [підстановка швидкості Δv = a · Δt]
= (a · t · sin θ) / c                    [скорочення на часовий інтервал прискорення Δt]
= (a · (r / c) · sin θ) / c              [підстановка часу поширення фронту t = r / c]
= (a · r · sin θ) / c²                   [групування констант швидкості світла]
```

Оскільки радіальне поле заряду є кулонівським `E_r = q / (4 · π · ε₀ · r²)`, виразимо поперечну складову електричного поля:

```
E_perp
= E_r · ((a · r · sin θ) / c²)                     [множення кулонівського поля на геометричне відношення]
= (q / (4 · π · ε₀ · r²)) · ((a · r · sin θ) / c²) [підстановка кулонівського закону для E_r]
= (q · a · sin θ) / (4 · π · ε₀ · c² · r)          [скорочення радіуса r у чисельнику та знаменнику]
```

Цей результат розкриває головну таємницю випромінювання: **радіус `r` у чисельнику виник через накопичення просторового зсуву за час `t = r/c`, що скоротило один степінь `r` у знаменнику кулонівського закону.** Поперечне поле виявилося пропорційним `1/r`, а не `1/r²`.

Супутнє магнітне поле породжується зміщенням силових ліній і розраховується з рівняння Максвелла-Фарадея `∇ × E = - ∂B/∂t`. У хвильовій зоні воно строго ортогональне до електричного вектора `E_perp` та одиничного вектора поширення `n`:

```
B_rad = (1 / c) · (n × E_perp)
|B_rad| = E_perp / c = (q · a · sin θ) / (4 · π · ε₀ · c³ · r)
```

Детальніше про історію розвитку цих уявлень, відхід від концепцій механічного ефіру та суперечки Джозефа Лармора з Гендріком Лоренцом можна дізнатися у статті про [історію відкриття формули Лармора та концепції рухомих електронів в ефірі](root:ph-electromagnetism/larmor-formula/hist-larmor.md).

## 2. Вектор Пойнтінга та інтегрування потужності випромінювання

Густина потоку електромагнітної енергії у будь-якій точці простору визначається вектором Пойнтінга:

```
S = (1 / μ₀) · (E_rad × B_rad)
```

Оскільки у хвильовій зоні вектори `E_rad` та `B_rad` взаємно перпендикулярні та лежать у площині хвильового фронту (перпендикулярно до напрямку поширення `n`), векторний добуток перетворюється на скалярний добуток модулів із напрямком вздовж `n`:

```
S
= (1 / μ₀) · |E_rad| · (|E_rad| / c) · n    [підстановка модуля магнітного поля |B| = |E|/c]
= (1 / (μ₀ · c)) · |E_rad|² · n             [групування амплітуди електричного поля]
= ε₀ · c · |E_rad|² · n                     [використання співвідношення c² = 1 / (ε₀ · μ₀)]
```

Підставивши вираз для поперечного електричного поля `E_perp`:

```
S(r, θ)
= ε₀ · c · [ (q · a · sin θ) / (4 · π · ε₀ · c² · r) ]² · n
= ε₀ · c · (q² · a² · sin²θ) / (16 · π² · ε₀² · c⁴ · r²) · n
= (q² · a² · sin²θ) / (16 · π² · ε₀ · c³ · r²) · n
```

![Діаграма спрямованості та вектори полів випромінювання](/root/sci/ph-electromagnetism/larmor-formula/img/dipole-pattern.svg)
*Кутовий розподіл потужності випромінювання Лармора: характерна тороїдальна діаграма sin²θ з максимумом перпендикулярно до прискорення*

Диференціальна потужність `dP`, що випромінюється через елемент площі `dA = r² · dΩ` сферичної оболонки у тілесний кут `dΩ = sin θ dθ dφ`, не залежить від відстані `r`:

```
dP / dΩ = r² · (S · n) = (q² · a² · sin²θ) / (16 · π² · ε₀ · c³)
```

Аналіз діаграми спрямованості показує:
- **Вздовж осі прискорення (`θ = 0` та `θ = π`):** `sin θ = 0`, тому `dP / dΩ = 0`. Прискорений заряд ніколи не випромінює енергію вздовж лінії свого прискорення (ні вперед, ні назад).
- **У перпендикулярній площині (`θ = π/2`):** `sin θ = 1`, потужність сягає абсолютного максимуму `(dP/dΩ)_max = (q² · a²) / (16 · π² · ε₀ · c³)`.
- **Поляризація:** Вектор `E_rad` завжди лежить у площині, утвореній вектором прискорення `a` та вектором спостереження `n`. Це означає, що випромінювання нерелятивістського заряду є строго лінійно поляризованим.

Для отримання повної потужності `P`, що випромінюється за одиницю часу в усій сфері, виконаємо інтегрування по повному тілесному куту `4π` стерадіан:

```
P
= ∮ (dP / dΩ) dΩ                                                           [інтеграл по всій замкненій сфері]
= ∫₀²π dφ · ∫₀π (q² · a² · sin²θ / (16 · π² · ε₀ · c³)) · sin θ dθ        [розкриття елемента тілесного кута dΩ = sin θ dθ dφ]
= (q² · a² / (16 · π² · ε₀ · c³)) · 2π · ∫₀π sin³θ dθ                     [інтегрування за азимутальним кутом φ від 0 до 2π]
```

Інтеграл `∫₀π sin³θ dθ` обчислюється аналітично за допомогою розкладу `sin³θ = (1 - cos²θ) sin θ` і дорівнює `4/3`. Тоді повна випромінювана потужність становить:

```
P
= (q² · a² · 2π / (16 · π² · ε₀ · c³)) · (4 / 3)   [підстановка значення визначеного інтеграла 4/3]
= (q² · a² · 8π) / (48 · π² · ε₀ · c³)             [множення чисельників та знаменників дробів]
= (q² · a²) / (6 · π · ε₀ · c³)                    [скорочення на спільний дільник 8π]
```

У системі СГС (гауссовій системі одиниць), де електрична стала відсутня, а `4πε₀` замінюється на `1`, формула Лармора записується у вигляді `P = (2 · q² · a²) / (3 · c³)`.

Повний математичний апарат, включно з виведенням потенціалів Льєнара-Віхерта через функції Гріна для тривимірного хвильового рівняння, наведено у статті про [строге математичне виведення потенціалів Льєнара-Віхерта та релятивістської формули](root:ph-electromagnetism/larmor-formula/math-larmor-derivation.md).

## 3. Розсіювання Томсона: виведення класичного перерізу з формули Лармора

Фундаментальним застосуванням формули Лармора є пояснення пружного розсіювання електромагнітних хвиль на вільних заряджених частинках — явища, відкритого Джозефом Джоном Томсоном.

Нехай плоска монохроматична електромагнітна хвиля з амплітудою електричного поля `E(t) = E₀ · cos(ω · t)` падає на вільний електрон маси `m_e` та заряду `e`. Електричне поле хвилі змушує електрон коливатися з вимушеним прискоренням:

```
m_e · a(t) = - e · E₀ · cos(ω · t)  ⇒  a(t) = - (e · E₀ / m_e) · cos(ω · t)
```

Підставимо це прискорення у формулу Лармора для обчислення миттєвої потужності вторинного випромінювання електрона:

```
P(t)
= (e² · a(t)²) / (6 · π · ε₀ · c³)
= (e² / (6 · π · ε₀ · c³)) · [ (e · E₀ / m_e) · cos(ω · t) ]²
= (e⁴ · E₀² / (6 · π · ε₀ · m_e² · c³)) · cos²(ω · t)
```

Середня за періодом коливань потужність випромінювання враховує середнє значення `⟨cos²(ω t)⟩ = 1/2`:

```
⟨P⟩ = (e⁴ · E₀²) / (12 · π · ε₀ · m_e² · c³)
```

Густина потоку енергії падаючої первинної хвилі задається усередненим вектором Пойнтінга:

```
⟨S_inc⟩ = ½ · ε₀ · c · E₀²
```

Повний ефективний переріз розсіювання `σ_T` (томсонівський переріз) визначається як відношення повної випроміненої потужності до густини падаючого потоку:

```
σ_T = ⟨P⟩ / ⟨S_inc⟩
= [ (e⁴ · E₀²) / (12 · π · ε₀ · m_e² · c³) ] / [ ½ · ε₀ · c · E₀² ]
= e⁴ / (6 · π · ε₀² · m_e² · c⁴)
```

Виразимо цей переріз через **класичний радіус електрона** `r₀ = e² / (4 · π · ε₀ · m_e · c²) ≈ 2.818 · 10⁻¹⁵` м:

```
σ_T = (8 · π / 3) · r₀² ≈ 6.652 · 10⁻²⁹ м² (0.665 барн)
```

Цей дивовижний результат демонструє: **переріз томсонівського розсіювання на вільному електроні взагалі не залежить від частоти падаючого випромінювання `ω`.** Він є універсальною фундаментальною константою електродинаміки, що визначає оптичну непрозорість зоряних надр, перенесення променистої енергії в плазмі Сонця та поляризацію реліктового мікрохвильового випромінювання Всесвіту.

## 4. Заборона дипольного випромінювання для однакових частинок

Розглянемо систему з двох довільних заряджених частинок з масами `m₁, m₂` та зарядами `q₁, q₂`, які взаємодіють між собою за допомогою внутрішніх сил `F₁₂` та `F₂₁`.

Сумарний електричний дипольний момент системи визначається як `d = q₁ · r₁ + q₂ · r₂`. Диференціюючи його двічі за часом:

```
d̈ = q₁ · r̈₁ + q₂ · r̈₂ = q₁ · (F₁₂ / m₁) + q₂ · (F₂₁ / m₂)
```

За третім законом Ньютона внутрішні сили взаємодії рівні за модулем та протилежні за напрямком `F₂₁ = - F₁₂`. Тоді:

```
d̈ = ( q₁/m₁ - q₂/m₂ ) · F₁₂
```

Звідси випливає фундаментальна теорема класичної електродинаміки:
- Якщо частинки мають **різний питомий заряд** `q₁/m₁ ≠ q₂/m₂` (наприклад, електрон та протон або електрон та іон), то `d̈ ≠ 0`. Система інтенсивно випромінює дипольні електромагнітні хвилі з потужністю Лармора `P ∝ d̈²`.
- Якщо ж частинки є **тотожними або мають однаковий питомий заряд** `q₁/m₁ = q₂/m₂` (наприклад, зіткнення двох електронів `e⁻ - e⁻` або двох протонів `p - p`), то `d̈ ≡ 0`.

**Зіткнення однакових заряджених частинок повністю позбавлене дипольного випромінювання.** Енергія може випромінюватися лише через значно слабше електричне квадрупольне або магнітне дипольне випромінювання, інтенсивність якого менша у `(v/c)²` разів. Саме тому в установках керованого термоядерного синтезу (токамаках) теплове випромінювання плазми визначається зіткненнями електронів з іонами домішок (де `q/m` кардинально різняться), тоді як взаємні зіткнення електронів практично не призводять до радіаційного охолодження шнура.

## 5. Термінологічний апарат та етимологія понять

Зрозумівши фізичну природу виникнення поперечного поля та енергетичного потоку, введемо канонічні терміни електродинаміки випромінювання:

- **Формула Лармора** (англ. *Larmor formula*, на честь сера Джозефа Лармора) — фундаментальний закон класичної електродинаміки, що пов'язує повну потужність електромагнітного випромінювання нерелятивістської точкової зарядженої частинки з квадратом її прискорення.
- **Поле випромінювання / хвильова зона** (лат. *radiatio* — проміння, сяйво) — асимптотична область простору на великих відстанях від джерела (`r ≫ c/ω`), де напруженість полів спадає як `1/r`, а локальна густина енергії повністю відокремлена від джерела.
- **Поле швидкості / кулонівське поле** (лат. *velocitas* — швидкість) — частина власного електромагнітного поля заряду, що спадає як `1/r²`, супроводжує рух частинки за законом інерції та не виконує незворотного перенесення енергії на нескінченність.
- **Запізнілий час** (лат. *retardatio* — уповільнення, запізнення) — момент часу `t_ret = t - R/c`, у який електромагнітний сигнал мав вийти з положення заряду, щоб досягти точки спостереження у момент `t`.
- **Радіаційне тертя / самогальмування** (лат. *radiatio* та прасл. *terti*) — ефективна сила опору, що діє на прискорену заряджену частинку з боку її власного створюваного електромагнітного поля внаслідок віднесення енергії та імпульсу випромінюванням.
- **Гальмівне випромінювання** (нім. *Bremsstrahlung*, від *bremsen* — гальмувати та *Strahlung* — випромінювання) — електромагнітні хвилі, що виникають при розсіюванні та гальмуванні зарядженої частинки в кулонівському полі атомного ядра чи іона.
- **Синхротронне випромінювання** (від грец. *syn* — разом та *chronos* — час) — електромагнітне випромінювання ультрарелятивістських заряджених частинок, що рухаються по викривлених магнітним полем траєкторіях.

## 6. Релятивістське узагальнення Льєнара

Коли швидкість руху зарядженої частинки стає порівнянною зі швидкістю світла (`v → c`, фактор Лоренца `γ = (1 - v²/c²)^(-1/2) ≫ 1`), нерелятивістська формула Лармора перестає бути точною. У 1898 році Альфред-Марі Льєнар отримав лоренц-інваріантний вираз для потужності випромінювання, записавши його через 4-вектор прискорення Мінковського `a^μ = d u^μ / dτ`:

```
P = - (q² / (6 · π · ε₀ · c³)) · (a_μ a^μ)
```

Перехід від компонент 4-векторів до звичайних тривимірних векторів швидкості `v` та прискорення `a = dv/dt` у лабораторній системі відліку дає загальну **формулу Льєнара**:

```
P = (q² · γ⁶ / (6 · π · ε₀ · c³)) · [ a² - (v × a)² / c² ]
```

![Релятивістський прожекторний ефект випромінювання](/root/sci/ph-electromagnetism/larmor-formula/img/relativistic-beaming.svg)
*Трансформація діаграми випромінювання: від нерелятивістського симетричного тороїда до ультрарелятивістського прожекторного конуса з кутом розкриву 1/γ*

Залежно від взаємної орієнтації векторів швидкості `v` та прискорення `a`, релятивістське випромінювання реалізується у двох діаметрально протилежних фізичних режимах:

### А. Поздовжнє прискорення (v ∥ a, лінійне гальмування)
Якщо частинка розганяється або гальмується вздовж напрямку свого руху (наприклад, у лінійному прискорювачі LINAC або під час лобового зіткнення з кулонівським бар'єром ядра), векторний добуток перетворюється на нуль: `v × a = 0`. Формула Льєнара набуває вигляду:

```
P_long = (q² · a² · γ⁶) / (6 · π · ε₀ · c³)
```

Оскільки релятивістська сила пов'язана з прискоренням через похідну імпульсу `F = dp/dt = m · γ³ · a`, потужність лінійного випромінювання можна виразити через темп зміни енергії:

```
P_long = (q² / (6 · π · ε₀ · m² · c³)) · (dp / dt)² = (q² / (6 · π · ε₀ · m² · c³)) · (dE / dx)²
```

Звідси випливає важливий наслідок для прискорювальної техніки: **при лінійному прискоренні частка втрат енергії на випромінювання `dE_rad / dE_gain` є надзвичайно малою і практично не залежить від абсолютної енергії частинки `γ`.**

### Б. Поперечне прискорення (v ⊥ a, синхротронний режим)
Якщо заряд рухається по колу радіуса `R` у магнітному полі `B`, вектор швидкості ортогональний до прискорення: `v · a = 0`, а модуль доцентрового прискорення дорівнює `a = v² / R ≈ c² / R`. Модуль векторного добутку становить `|v × a| = v · a`. Дужка у формулі Льєнара скорочується:

```
a² - (v² · a²) / c² = a² · (1 - v² / c²) = a² / γ²
```

Підставляючи цей вираз, отримуємо потужність **синхротронного випромінювання**:

```
P_synch = (q² · a² · γ⁴) / (6 · π · ε₀ · c³) = (q² · v⁴ · γ⁴) / (6 · π · ε₀ · c³ · R²)
```

Для ультрарелятивістських частинок (`v ≈ c`), виражаючи фактор Лоренца через повну енергію частинки `E = γ · m · c²`:

```
P_synch = (q² · c · γ⁴) / (6 · π · ε₀ · R²) = (q² / (6 · π · ε₀ · m⁴ · c⁷ · R²)) · E⁴
```

Ця формульна залежність несе в собі колосальні фізичні наслідки:
1. **Катастрофічне масштабування за енергією `E⁴`:** Збільшення енергії пучка в накопичувальному кільці у 2 рази збільшує потужність радіаційних втрат у `2⁴ = 16` разів.
2. **Обернена пропорційність четвертому степеню маси `1/m⁴`:** Якщо порівняти випромінювання електрона та протона однакової енергії, відношення втрат становить:

```
P_електрон / P_протон = (m_протон / m_електрон)⁴ = (1836.15)⁴ ≈ 1.137 · 10¹³
```

Електрон випромінює в 11 трильйонів разів інтенсивніше за протон! Саме тому Великий адронний колайдер (LHC) у CERN побудовано як протонний синхротрон на енергію 7 ТеВ (радіаційні втрати протонів становлять лише кілька кіловатів на все 27-кілометрове кільце), тоді як колишній електрон-позитронний колайдер LEP на тій самій трасі при енергії електронів 104 ГеВ втрачав понад 23 Мегавати потужності, яка повністю йшла на синхротронне випромінювання.

## 7. Прожекторний ефект (Relativistic Beaming)

Ультрарелятивістський рух принципово змінює не лише повну потужність, але й просторову діаграму спрямованості. Завдяки релятивістській аберації світла електромагнітні хвилі, які в супутній системі відліку випромінювалися симетрично вперед і назад за законом `sin²θ'`, у лабораторній системі згортаються у надзвичайно вузький конус, спрямований строго за вектором миттєвої швидкості частинки.

Кут напіврозкриву цього випромінювального конуса визначається виключно фактором Лоренца:

```
Δθ ≈ 1 / γ = (m · c²) / E
```

Для електронів з енергією `E = 6` ГеВ (наприклад, у джерелі синхротронного випромінювання ESRF в Греноблі) `γ ≈ 11740`, а кут розкриву становить лише `Δθ ≈ 8.5 · 10⁻⁵` радіан (менше 0.005 градуса!).

Непорушний спостерігач у площині орбіти бачить синхротронне випромінювання не як неперервну хвилю, а як послідовність ультракоротких інтенсивних спалахів (імпульсів), що виникають щоразу, коли прожекторний конус електрона чиркає по лінії зору детектора. Тривалість такого імпульсу становить `Δt_pulse ≈ R / (c · γ³)`. Завдяки фур'є-перетворенню такий короткий імпульс генерує надширокий неперервний спектр електромагнітних хвиль — від інфрачервоного діапазону до жорсткого рентгенівського випромінювання з критичною частотою `ω_c = (3/2) · γ³ · (c/R)`.

Зведені формули для розрахунку критичних частот, спектральної густини та втрат на оберт наведено у [довіднику формул класичного та релятивістського випромінювання](root:ph-electromagnetism/larmor-formula/api-radiation-formulas.md).

## 8. Радіаційне тертя: рівняння Абрагама-Лоренца та межі класики

Оскільки прискорений заряд неперервно випромінює енергію зі швидкістю `P = dE_rad / dt`, за фундаментальним законом збереження енергії на саму частинку має діяти реактивна гальмівна сила — **сила радіаційного тертя** (radiation reaction force) `F_rad`.

Розрахуємо цю силу з балансу роботи над зарядом за період квазіперіодичного руху від `t₁` до `t₂`:

```
∫_{t₁}^{t₂} (F_rad · v) dt = - ∫_{t₁}^{t₂} P dt = - (q² / (6 · π · ε₀ · c³)) · ∫_{t₁}^{t₂} a² dt
```

Скористаємося інтегруванням частинами, враховуючи, що `a² = a · (dv/dt)`:

```
∫_{t₁}^{t₂} a² dt
= [ a · v ]_{t₁}^{t₂} - ∫_{t₁}^{t₂} (da / dt · v) dt
```

Для обмеженого або періодичного руху інтегральний позаінтегральний член зникає `[a · v] = 0`. Порівнюючи підінтегральні вирази, отримуємо знамениту **силу Абрагама-Лоренца**:

```
F_rad = (q² / (6 · π · ε₀ · c³)) · (da / dt) = m · τ₀ · d²v / dt²
```

де введено характерний масштаб **електродинамічного часу**:

```
τ₀ = q² / (6 · π · ε₀ · m · c³)
```

Для електрона `τ₀ = (1.602 · 10⁻¹⁹)² / (6 · π · 8.854 · 10⁻¹² · 9.109 · 10⁻³¹ · (2.998 · 10⁸)³) ≈ 6.256 · 10⁻²⁴` секунди. Це час, за який світло долає відстань, що дорівнює класичному радіусу електрона `r₀ = c · τ₀ ≈ 2.82 · 10⁻¹⁵` м.

Рівняння руху частинки з урахуванням радіаційного самогальмування набуває вигляду:

```
m · ( dv/dt - τ₀ · d²v/dt² ) = F_ext
```

Це рівняння містить глибокі парадокси, що оголили межі застосовності класичної фізики:
1. **Самогальмування та нефізичне самоприскорення (Runaway solutions):** За відсутності зовнішньої сили `F_ext = 0` рівняння має розв'язок `a(t) = a₀ · exp(t / τ₀)`. Частинка спонтанно розганяється до нескінченної енергії за рахунок власного поля за частки пікосекунди.
2. **Порушення причинності (Pre-acceleration):** Якщо штучно накласти граничну умову відсутності самоприскорення на нескінченності, розв'язок показує, що частинка починає прискорюватися за час `∼ τ₀` **до того**, як зовнішня сила взагалі була прикладена!

Фізичне розв'язання цих парадоксів полягає у тому, що класична електродинаміка точкового заряду втрачає фізичний зміст на просторових масштабах, менших за класичний радіус електрона `r₀`, та часових інтервалах, менших за `τ₀`. На цих відстанях домінують квантові флуктуації вакууму та комптонівська довжина хвилі `λ_C = ħ / (m · c) ≈ 137 · r₀`, що вимагає переходу до квантової електродинаміки (КЕД).

Для практичних розрахунків використовують регуляризоване наближення Ландау-Ліфшиця, де третя похідна замінюється на похідну від зовнішньої сили вздовж незбуреної траєкторії: `d²v/dt² ≈ (1/m) · dF_ext/dt`.

Чисельний алгоритм та програмну реалізацію розв'язання рівнянь руху з демпфуванням Ландау-Ліфшиця наведено у проєкті про [чисельне моделювання траєкторії частинки із самогальмуванням Ландау-Ліфшиця](root:ph-electromagnetism/larmor-formula/proj-radiation-damping.md).

## 9. Теплове гальмівне випромінювання в астрофізиці та плазмі

Гальмівне випромінювання вільних електронів під час кулонівських зіткнень з іонами у високотемпературній плазмі (так звані вільно-вільні переходи, англ. *free-free emission*) відіграє ключову роль у фізиці космосу та термоядерного синтезу.

Якщо максвеллівський ансамбль електронів із концентрацією `n_e` та температурою `T` хаотично рухається серед іонів із зарядом `Z` та густиною `n_i`, інтегрування формули Лармора за всіма прицільними параметрами зіткнень `b` дає об'ємну випромінювальну здатність плазми (потужність на одиницю об'єму):

```
ε_ff = (2⁵ · π · e⁶ / (3 · m_e · c³ · h)) · sqrt(2 · π · k_B · T / (3 · m_e)) · Z² · n_e · n_i · g_ff
```

де `g_ff` — квантовий фактор Гаунта (поправка порядку одиниці, що враховує хвильову природу електронів).

Цей механізм має виняткове практичне значення:
1. **Вимірювання маси скупчень галактик:** Міжгалактичний газ у гігантських скупченнях галактик розігрітий гравітаційним стисканням до температур `T ∼ 10⁷ - 10⁸` Кельвінів. Завдяки тепловому гальмівному випромінюванню цей газ яскраво світиться у рентгенівському діапазоні (спостереження орбітальних телескопів Chandra та XMM-Newton). Аналіз рентгенівської світності за формулою Лармора дозволяє астрофізикам точно визначати масу звичайного газу та реконструювати розподіл невидимої темної матерії.
2. **Радіаційний бар'єр у термоядерних реакторах:** У токамаках гальмівне випромінювання на ядрах дейтерію та тритію створює неперервні енергетичні втрати. Для запалювання керованої термоядерної реакції потужність термоядерного синтезу альфа-частинок має перевищувати ларморове теплове випромінювання (критерій Лоусона та радіаційна межа температури).

## 10. Періодичні структури: когерентне ондуляторне випромінювання

Вершиною практичного використання релятивістської електродинаміки випромінювання стали магнітні **ондулятори** (від франц. *onduler* — хвилясто коливатися) — періодичні ґратки з чергуванням північних і південних полюсів постійних магнітів із періодом `λ_u ∼ 1 - 5` см.

Коли релятивістський електрон із фактором Лоренца `γ ≫ 1` пролітає крізь ондулятор, періодичне магнітне поле надає йому поперечне синусоїдальне прискорення. Завдяки подвійному релятивістському стисканню (лоренцівське скорочення довжини періоду ондулятора в супутній системі та ефект Доплера при випромінюванні вперед у лабораторну систему), довжина хвилі генерованого світла скорочується у `2 γ²` разів:

```
λ = (λ_u / (2 · γ²)) · [ 1 + K² / 2 + γ² · θ² ]
```

де `K = (e · B₀ · λ_u) / (2 · π · m_e · c)` — безрозмірний параметр сили ондулятора.

Оскільки електрон випромінює на кожному з `N` періодів ондулятора строго синфазно, виникає конструктивна інтерференція хвиль. Амплітуда електричного поля зростає пропорційно кількості періодів `E_total = N · E₁`, а інтенсивність та яскравість випромінювання масштабуються пропорційно квадрату кількості періодів:

```
P_undulator ∝ N²
```

Це дозволило перетворити прискорювачі на лазери на вільних електронах (XFEL), що генерують когерентні рентгенівські імпульси гігаватної пікової потужності.

## 11. Класична катастрофа атома Резерфорда

Найяскравішим проявом формули Лармора в історії науки став розрахунок стійкості класичного атома. Після відкриття атомного ядра Ернестом Резерфордом у 1911 році фізики уявляли атом водню як мініатюрну Сонячну систему: електрон маси `m_e` та заряду `-e` обертається навколо нерухомого протона з зарядом `+e` по коловій орбіті радіуса `r`.

![Радіаційний колапс класичного атома Резерфорда](/root/sci/ph-electromagnetism/larmor-formula/img/rutherford-collapse.svg)
*Класична криза моделі Резерфорда: безперервне випромінювання Лармора призводить до падіння електрона на ядро за 16 пікосекунд*

Проведемо строгий аналітичний розрахунок часу життя такого класичного атома:

1. **Доцентрове прискорення електрона:**
   Кулонівська сила притягання надає електрону доцентрове прискорення:
   ```
   m_e · a = e² / (4 · π · ε₀ · r²)  ⇒  a = e² / (4 · π · ε₀ · m_e · r²)
   ```

2. **Повна механічна енергія:**
   За теоремою віріалу кінетична енергія дорівнює половині модуля потенціальної енергії `E_kin = - ½ E_pot = e² / (8 · π · ε₀ · r)`:
   ```
   E_total = E_kin + E_pot = - e² / (8 · π · ε₀ · r)
   ```

3. **Швидкість втрати енергії за формулою Лармора:**
   Підставимо прискорення `a` у формулу Лармора:
   ```
   P
   = (e² · a²) / (6 · π · ε₀ · c³)                                [підстановка загальної формули Лармора]
   = (e² / (6 · π · ε₀ · c³)) · [ e² / (4 · π · ε₀ · m_e · r²) ]² [підстановка доцентрового прискорення кулонівської орбіти]
   = e⁶ / (96 · π³ · ε₀³ · m_e² · c³ · r⁴)                        [розкриття квадратів та групування сталих]
   ```

4. **Диференціальне рівняння радіуса орбіти:**
   За законом збереження енергії `dE_total / dt = - P`:
   ```
   d / dt [ - e² / (8 · π · ε₀ · r) ] = (e² / (8 · π · ε₀ · r²)) · (dr / dt) = - P
   ```
   Прирівнюючи до потужності випромінювання:
   ```
   (e² / (8 · π · ε₀ · r²)) · (dr / dt) = - e⁶ / (96 · π³ · ε₀³ · m_e² · c³ · r⁴)
   ```
   Звідси швидкість стягування радіуса орбіти дорівнює:
   ```
   dr / dt = - e⁴ / (12 · π² · ε₀² · m_e² · c³ · r²)
   ```

5. **Інтегрування часу падіння на ядро:**
   Розділимо змінні та проінтегруємо від початкового борівського радіуса `r₀ ≈ 0.529 · 10⁻¹⁰` м (0.53 Å) до `r = 0`:
   ```
   ∫_{r₀}⁰ r² dr = - ∫₀^{τ_collapse} (e⁴ / (12 · π² · ε₀² · m_e² · c³)) dt
   ```
   ```
   [ r³ / 3 ]_{r₀}⁰ = - r₀³ / 3 = - (e⁴ / (12 · π² · ε₀² · m_e² · c³)) · τ_collapse
   ```
   Звідси повний час колапсу атома становить:
   ```
   τ_collapse = (4 · π² · ε₀² · m_e² · c³ · r₀³) / e⁴
   ```

Підставимо фундаментальні фізичні сталі:
- `ε₀ = 8.8541878 · 10⁻¹²` Ф/м
- `m_e = 9.1093837 · 10⁻³¹` кг
- `c = 2.99792458 · 10⁸` м/с
- `e = 1.60217663 · 10⁻¹⁹` Кл
- `r₀ = 0.529177 · 10⁻¹⁰` м

```
τ_collapse
= (4 · π² · (8.854 · 10⁻¹²)² · (9.109 · 10⁻³¹)² · (3.0 · 10⁸)³ · (0.529 · 10⁻¹⁰)³) / (1.602 · 10⁻¹⁹)⁴ [підстановка числових значень фізичних констант]
= 1.56 · 10⁻¹¹ секунди                                                                          [остаточний час падіння електрона]
```

**Класичний електрон зобов'язаний упасти на ядро за 16 пікосекунд!**

При цьому випромінювання мало б неперервний спектр зростаючої частоти (рентгенівський та гамма-спалах), а вся стабільна матерія у Всесвіті миттєво колапсувала б. Незмінне існування стабільних атомів стало прямим експериментальним доказом того, що класична електродинаміка непридатна для опису зв'язаних мікросистем, що змусило Нільса Бора у 1913 році постулювати квантування моменту імпульсу та існування невипромінювальних стаціонарних орбіт.

## 12. Практичне застосування та інженерне значення

> 🔧 **Навіщо це.**
> 
> Формула Лармора та її релятивістські узагальнення є базовим розрахунковим інструментом у багатьох галузях сучасної високих технологій та фізики:
> 
> 1. **Джерела синхротронного випромінювання 4-го покоління та XFEL:** Установки на кшталт ESRF-EBS, MAX IV та європейського XFEL використовують синхротронне випромінювання релятивістських електронів для генерації надяскравих рентгенівських імпульсів фемтосекундної тривалості. Це дозволяє здійснювати рентгеноструктурний аналіз білків, спостерігати хімічні реакції в реальному часі та проводити нанолітографію субнанометрової роздільності.
> 2. **Проєктування накопичувальних кілець та колайдерів:** При розрахунку радіочастотних прискорювальних резонаторів для майбутнього колайдера FCC-ee (Future Circular Collider) інженери за формулою Льєнара обчислюють необхідну потужність ВЧ-генераторів для компенсації гігаватних втрат енергії на випромінювання пучка.
> 3. **Високоенергетична астрофізика:** Випромінювання релятивістських електронів у магнітних полях нейтронних зірок, пульсарів та акреційних дисків чорних дір формує спостережуваний спектр пульсарних туманностей (наприклад, Крабоподібної туманності) та джетів активних ядер галактик.
> 4. **Медичні та промислові рентгенівські трубки:** Генерація рентгенівських променів у медичних томографах базується на гальмівному випромінюванні (bremsstrahlung) швидких електронів під час різкого гальмування у вольфрамових анодах.

## 13. Чисельне моделювання випромінювання прискореного заряду

Для демонстрації динаміки випромінювання розглянемо алгоритм розрахунку траєкторії, прискорення та миттєвої потужності Лармора для заряду, що рухається у неоднорідному електричному та магнітному полі.

```c
#include <stdio.h>
#include <math.h>

/* Фізичні константи */
#define C_LIGHT 2.99792458e8
#define EPS0    8.8541878128e-12
#define Q_ELEM  1.602176634e-19
#define M_ELEM  9.1093837015e-31
#define PI_VAL  3.141592653589793

/* Миттєва потужність Лармора за 3D-вектором прискорення */
double larmor_power(double ax, double ay, double az) {
    double a_sq = ax * ax + ay * ay + az * az;
    return (Q_ELEM * Q_ELEM * a_sq) / (6.0 * PI_VAL * EPS0 * C_LIGHT * C_LIGHT * C_LIGHT);
}

int main(void) {
    /* Моделювання електрона, що коливається в полі світлової хвилі E = E0 * sin(omega * t) */
    const double E0 = 1.0e6;                  /* Амплітуда поля, В/м */
    const double FREQ = 5.0e14;               /* Оптична частота, Гц */
    const double OMEGA = 2.0 * PI_VAL * FREQ;
    const double DT = 1.0e-17;                /* Крок часу, с */
    const int STEPS = 1000;

    double t = 0.0;
    double total_energy = 0.0;

    printf("Час (фс) | Поле (кВ/м) | Прискорення (10^17 м/с^2) | Потужність (пВт)\n");
    printf("--------------------------------------------------------------------\n");

    for (int i = 0; i <= STEPS; ++i) {
        double E_field = E0 * sin(OMEGA * t);
        double a_x = (-Q_ELEM * E_field) / M_ELEM;
        double P_rad = larmor_power(a_x, 0.0, 0.0);

        total_energy += P_rad * DT;

        if (i % 200 == 0) {
            printf("%8.3f | %11.2f | %26.4f | %16.4e\n",
                   t * 1.0e15, E_field * 1.0e-3, a_x * 1.0e-17, P_rad * 1.0e12);
        }
        t += DT;
    }

    printf("\nПовна випромінена енергія за період: %.6e Дж\n", total_energy);
    return 0;
}
```

```cpp
namespace electrodynamics {

constexpr double C_LIGHT = 2.99792458e8;     // м/с
constexpr double EPS0    = 8.8541878128e-12; // Ф/м
constexpr double Q_ELEM  = 1.602176634e-19; // Кл
constexpr double M_ELEM  = 9.1093837015e-31; // кг

[[nodiscard]] double calculate_larmor_power(double ax, double ay, double az) noexcept {
    const double a_sq = ax * ax + ay * ay + az * az;
    return (Q_ELEM * Q_ELEM * a_sq) /
           (6.0 * std::numbers::pi * EPS0 * C_LIGHT * C_LIGHT * C_LIGHT);
}

} // namespace electrodynamics

int main() {
    using namespace electrodynamics;

    constexpr double E0    = 1.0e6;           // 1 МВ/м
    constexpr double FREQ  = 5.0e14;          // 500 ТГц (видиме світло)
    constexpr double OMEGA = 2.0 * std::numbers::pi * FREQ;
    constexpr double DT    = 1.0e-17;         // 10 аттосекунд

    double current_time = 0.0;
    double total_energy = 0.0;

    std::cout << std::left
              << std::setw(10) << "Час (фс)"
              << std::setw(14) << "Поле (кВ/м)"

    for (int i = 0; i <= STEPS; ++i) {
        const double e_field = E0 * std::sin(OMEGA * current_time);
        const double a_x = (-Q_ELEM * e_field) / M_ELEM;
        const double p_rad = calculate_larmor_power(a_x, 0.0, 0.0);

        total_energy += p_rad * DT;

        if (i % 200 == 0) {

    std::cout << "\nПовна випромінена енергія за розрахунковий інтервал: "
```
