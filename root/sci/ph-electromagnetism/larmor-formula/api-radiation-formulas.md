# 📋 Довідник формул класичного та релятивістського випромінювання

Цей інженерно-фізичний довідник містить систематизований звід формул, аналітичних виразів, характеристичних масштабів та граничних співвідношень класичної та релятивістської електродинаміки випромінювання. Матеріал структуровано для практичного використання при проєктуванні прискорювачів заряджених частинок, розрахунку рентгенівських оптичних ліній синхротронів, моделюванні високотемпературної плазми та аналізі астрофізичних джерел.

---

## 1. Загальні формули миттєвої потужності випромінювання

У класичній електродинаміці миттєва потужність випромінювання точкового заряду `q` визначається його кінематичним станом — швидкістю `v` та прискоренням `a`. Нижче наведено зіставлення основних співвідношень у Міжнародній системі одиниць (SI) та гауссовій системі (СГС):

| Фізичний режим | Формула повної потужності (SI) | Формула потужності (СГС/Гаусс) | Область фізичної застосовності |
| :--- | :--- | :--- | :--- |
| **Нерелятивістський (Лармор)** | `P = (q² · a²) / (6 · π · ε₀ · c³)` | `P = (2 · q² · a²) / (3 · c³)` | Швидкість частинки `v ≪ c`, фактор Лоренца `γ ≈ 1` |
| **Релятивістський загальний (Льєнар)** | `P = (q² · γ⁶ / (6 · π · ε₀ · c³)) · [a² - (v × a)² / c²]` | `P = (2 · q² · γ⁶ / (3 · c³)) · [a² - (v × a)² / c²]` | Довільна швидкість `v < c`, довільний кут між `v` та `a` |
| **Поздовжнє прискорення (v ∥ a)** | `P_∥ = (q² · γ⁶ · a²) / (6 · π · ε₀ · c³)` | `P_∥ = (2 · q² · γ⁶ · a²) / (3 · c³)` | Лінійне гальмування/прискорення (`v × a = 0`) |
| **Поперечне прискорення (v ⊥ a)** | `P_⊥ = (q² · γ⁴ · a²) / (6 · π · ε₀ · c³)` | `P_⊥ = (2 · q² · γ⁴ · a²) / (3 · c³)` | Рух по колу або в магнітному полі (`v · a = 0`) |

### Правила перерахунку між системами одиниць
Для переходу від формул у системі SI до системи СГС діють стандартні правила заміни електродинамічних сталих:
- Електрична стала `4 · π · ε₀` замінюється на одиницю `1`.
- Магнітна проникність вакууму `μ₀` замінюється на `4 · π / c²`.
- Електричний заряд `q` перераховується у франкліни (статкулони): `1 Кл = 2.99792458 · 10⁹ СГС_q`.
- Напруженість електричного поля `E` (В/м) перераховується у стативольти на сантиметр: `1 СГС_E = 2.99792458 · 10⁴ В/м`.
- Магнітна індукція `B` перераховується з Тесла в Гауси: `1 Тл = 10⁴ Гс`.

## 2. Кутовий розподіл та діаграма спрямованості

Диференціальна потужність `dP / dΩ`, яка випромінюється в одиничний тілесний кут `dΩ = sin θ dθ dφ`, описує просторову анізотропію випромінювання:

### А. Нерелятивістський режим Лармора
Для повільного заряду кутовий розподіл має вигляд симетричного тороїда:
```
dP / dΩ = (q² · a² · sin²θ) / (16 · π² · ε₀ · c³)
```
- `θ` — кут між вектором прискорення `a` та одиничним вектором на спостерігача `n`.
- **Вузли діаграми:** При `θ = 0` та `θ = π` (вздовж вектора прискорення) `dP / dΩ = 0`.
- **Максимум випромінювання:** При `θ = π / 2` (у площині, перпендикулярній до `a`), потужність сягає піка `(dP/dΩ)_max = (q² · a²) / (16 · π² · ε₀ · c³)`.
- **Повна інтегральна потужність:** `P = ∫ (dP/dΩ) dΩ = (q² · a²) / (6 · π · ε₀ · c³)`.

### Б. Релятивістський режим Льєнара (прожекторний ефект)
Для частинки, що рухається зі швидкістю `v = β · c` під кутом `θ` до напрямку спостереження:
```
dP / dΩ = (q² · a² / (16 · π² · ε₀ · c³)) · (sin²θ / (1 - β · cos θ)⁵)
```
- **Знаменник Доплера `(1 - β · cos θ)⁵`:** Створює екстремальне підсилення випромінювання вперед за вектором швидкості.
- **Характерний кут розкриву конуса:** `Δθ ≈ 1 / γ = (m · c²) / E`.
- **Кут точного максимуму випромінювання:** `θ_max ≈ arccos( (sqrt(1 + 15 β²) - 1) / (3 β) ) ≈ 1 / (2 · γ)`.

## 3. Параметри синхротронного випромінювання

Ультрарелятивістські електрони (`γ ≫ 1`), що рухаються в поворотному магнітному полі `B` накопичувального кільця з радіусом кривини орбіти `R`, випромінюють синхротронне світло з такими характеристиками:

| Параметр | Позначення | Формула (SI) | Практична інженерна формула |
| :--- | :--- | :--- | :--- |
| **Радіус орбіти (гірорадіус)** | `R` | `R = (γ · m · v) / (q · B) ≈ E / (q · c · B)` | `R [м] ≈ 3.3356 · E [ГеВ] / B [Тл]` |
| **Орбітальна циклотронна частота** | `ω₀` | `ω₀ = (q · B) / (γ · m) = c / R` | `f₀ [МГц] ≈ 47.7 / R [м]` |
| **Критична циклічна частота** | `ω_c` | `ω_c = (3 / 2) · γ³ · (c / R)` | `ω_c = 1.5 · γ³ · ω₀` |
| **Критична енергія фотонів** | `ε_c = ħω_c` | `ε_c = (3 · ħ · c · γ³) / (2 · R)` | `ε_c [кеВ] ≈ 0.665 · B [Тл] · (E [ГеВ])²` |
| **Критична довжина хвилі** | `λ_c` | `λ_c = (4 · π · R) / (3 · γ³)` | `λ_c [нм] ≈ 1.864 / (B [Тл] · (E [ГеВ])²)` |
| **Втрати енергії за 1 оберт** | `ΔE_оберт` | `ΔE = (q² · γ⁴) / (3 · ε₀ · R)` | `ΔE [кеВ] = 88.463 · (E [ГеВ])⁴ / R [м]` |
| **Потужність випромінювання пучка** | `P_beam` | `P_beam = ΔE_оберт · (I_beam / q)` | `P [кВт] = 88.463 · (E [ГеВ])⁴ · I [А] / R [м]` |

### Спектральний розподіл синхротронного випромінювання
Повна спектральна густина потужності описується функцією Бесселя другого роду дробового порядку:
```
dP / dω = (sqrt(3) · q² · γ / (4 · π · ε₀ · R)) · (ω / ω_c) · ∫_{ω/ω_c}^∞ K_{5/3}(ξ) dξ
```
- **Низькочастотна асимптотика (`ω ≪ ω_c`):** `dP / dω ∝ (ω / ω_c)^{1/3}` (пологий підйом інтенсивності).
- **Максимум спектра:** Досягається на частоті `ω_max ≈ 0.2858 · ω_c`.
- **Високочастотний квантовий хвіст (`ω ≫ ω_c`):** `dP / dω ∝ sqrt(ω / ω_c) · exp(- ω / ω_c)` (експоненційне обривання).

## 4. Мультипольний розклад та випромінювання систем частинок

Якщо випромінювальна система складається з кількох частинок, повна потужність випромінювання розкладається за мультипольними моментами джерела:

| Тип мультиполя | Визначальний момент джерела | Потужність випромінювання (SI) | Залежність від частоти `ω` |
| :--- | :--- | :--- | :--- |
| **Електричний диполь (E1)** | `d = ∑ q_i · r_i` | `P_E1 = (μ₀ · d̈²) / (6 · π · c) = (ω⁴ · |d|²) / (12 · π · ε₀ · c³)` | `P ∝ ω⁴` |
| **Магнітний диполь (M1)** | `m = ½ ∑ q_i · (r_i × v_i)` | `P_M1 = (μ₀ · m̈²) / (6 · π · c³) = (μ₀ · ω⁴ · |m|²) / (6 · π · c³)` | `P ∝ ω⁴` (менше за E1 у `(v/c)²` разів) |
| **Електричний квадруполь (E2)** | `Q_{ij} = ∑ q (3 x_i x_j - r² δ_{ij})` | `P_E2 = (μ₀ · ∭ Q_{ij}²) / (360 · π · c³)` | `P ∝ ω⁶` (менше за E1 у `(d/λ)²` разів) |

### Теорема про заборону дипольного випромінювання однакових частинок
Для замкненої системи з двох однакових заряджених частинок з однаковим питомим зарядом `q₁/m₁ = q₂/m₂` (наприклад, два електрони або два протони):
```
d̈ = q₁ · r̈₁ + q₂ · r̈₂ = (q/m) · (F₁₂ + F₂₁) = (q/m) · 0 = 0
```
За третім законом Ньютона `F₁₂ = - F₂₁`, тому друга похідна дипольного моменту тотожно дорівнює нулю. Звідси випливає важливий закон: **зіткнення однакових заряджених частинок не супроводжується дипольним випромінюванням; розсіювання енергії відбувається лише через значно слабше квадрупольне випромінювання `P_E2 ≪ P_E1`.**

## 5. Радіаційне гальмування та характерні масштаби електродинаміки

| Характеристична величина | Символ | Аналітичний вираз (SI) | Числове значення для електрона |
| :--- | :--- | :--- | :--- |
| **Електродинамічний час Лармора** | `τ₀` | `q² / (6 · π · ε₀ · m · c³)` | `6.2565 · 10⁻²⁴` с |
| **Класичний радіус електрона** | `r₀` | `q² / (4 · π · ε₀ · m · c²)` | `2.81794 · 10⁻¹⁵` м |
| **Комптонівська довжина хвилі** | `λ_C` | `ħ / (m · c)` | `3.86159 · 10⁻¹³` м |
| **Борівський радіус водню** | `a₀` | `(4 · π · ε₀ · ħ²) / (m · e²)` | `5.29177 · 10⁻¹¹` м (0.53 Å) |
| **Переріз томсонівського розсіювання** | `σ_T` | `(8 · π / 3) · r₀²` | `6.65246 · 10⁻²⁹` м² (0.665 барн) |

### Співвідношення фундаментальних масштабів довжини
Масштаби довжин в електродинаміці електрона утворюють геометричну прогресію зі знаменником, рівним сталій тонкої структури `α = e² / (4 · π · ε₀ · ħ · c) ≈ 1 / 137.036`:
```
r₀ = α · λ_C = α² · a₀
```
1. `r₀ ≈ 2.82 · 10⁻¹⁵` м — масштаб класичної електродинаміки та сили Абрагама-Лоренца.
2. `λ_C ≈ 3.86 · 10⁻¹³` м — масштаб квантових релятивістських ефектів та народження віртуальних пар.
3. `a₀ ≈ 5.29 · 10⁻¹¹` м — масштаб нерелятивістської квантової механіки атомів.

## 6. Критерії застосовності та квантові межі

Класичний опис випромінювання за формулами Лармора та Льєнара є строго коректним лише за виконання трьох фундаментальних умов:

1. **Відсутність квантової віддачі електрона (Критерій класичності):**
   Енергія випромінюваного кванта світла `ħω_c` має бути знехтовно малою порівняно з повною кінетичною енергією частинки `E = γ · m · c²`:
   ```
   χ = (ħ · ω_c) / E = (3 / 2) · (ħ / (m · c)) · (γ² / R) = (3 / 2) · (B / B_cr) · γ ≪ 1
   ```
   де `B_cr = (m² · c²) / (q · ħ) ≈ 4.414 · 10⁹` Тл — критичне швінгерівське магнітне поле (квантова межа електродинаміки). Якщо параметр `χ ≳ 1`, класична формула завищує втрати, і необхідно застосовувати квантову формулу Баєра-Каткова з урахуванням квантового спінового перевертання та квантової віддачі.

2. **Точковість джерела (Дипольний критерій):**
   Розмір системи `d` набагато менший за довжину випромінюваної електромагнітної хвилі `λ`:
   ```
   d ≪ λ = (2 · π · c) / ω  ⇒  v ≪ c
   ```

## 7. Періодичні магнітні структури: ондулятори та вігглери

У сучасних накопичувальних кільцях та лазерах на вільних електронах (XFEL) для багаторазового підсилення випромінювання використовують періодичні магнітні структури з чергуванням полюсів — ондулятори та вігглери з просторовим періодом `λ_u` та амплітудою поля `B₀`.

Характер випромінювання визначається безрозмірним **параметром ондулятора**:
```
K = (q · B₀ · λ_u) / (2 · π · m · c) ≈ 0.934 · B₀ [Тл] · λ_u [см]
```

1. **Режим ондулятора (`K ≲ 1`):**
   - Кут відхилення пучка менший за кут розкриву конуса випромінювання `1/γ`.
   - Електромагнітні хвилі, випромінені на кожному періоді структури, когерентно інтерферують між собою.
   - Спектр складається з вузьких квазімонохроматичних ліній (гармонік) з довжиною хвилі:
     ```
     λ_n = (λ_u / (2 · n · γ²)) · [ 1 + K² / 2 + γ² · θ² ]
     ```
   - Яскравість випромінювання ондулятора масштабується пропорційно квадрату кількості періодів `P ∝ N²`.

2. **Режим вігглера (`K ≫ 1`):**
   - Траєкторія частинки має значні просторові вигини.
   - Когерентна інтерференція руйнується, а випромінювання перетворюється на широкосмуговий неперервний спектр високої жорсткості.
   - Повна потужність є простою сумою випромінювання від окремих полюсів: `P = 2 · N · P_synch`.

## 8. Практичні вказівки для інженерного захисту та розрахунку тепловідводу

При проєктуванні рентгенівських оптичних ліній та радіаційного захисту прискорювачів інженери керуються такими нормативними співвідношеннями:

- **Лінійна густина теплового навантаження:** На першій оптичній дзеркальній поверхні синхротронного променя густина теплового потоку може досягати `100` Вт/мм², що вимагає застосування криогенного охолодження дзеркал із монокристалічного кремнію рідким азотом.
- **Швидкість радіаційного демпфування пучка:** Час затухання амплітуди бетатронних коливань пучка за рахунок випромінювання становить `τ_damp = (2 · E₀ · T_rev) / ΔE_оберт`, де `T_rev` — час одного оберту частинки в кільці.
- **Радіаційне поглинання гальмівного випромінювання:** Товщина свинцевого біологічного захисту `X` розраховується за довжиною радіаційного пробігу `X₀` (для свинцю `X₀ ≈ 0.56` см): потік гамма-квантів послаблюється за законом `I(x) = I₀ · exp(- 7/9 · x / X₀)`.
