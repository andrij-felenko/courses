# ⚙️ Чисельне моделювання коефіцієнта магнітного екранування

Аналітичні класичні формули коефіцієнтів екранування дають точні результати лише для ідеалізованих геометрій — нескінченно довгих циліндрів або суцільних сфер із постійною відносною магнітною проникністю `μ_r = const`. 

Проте при розробці реальних інженерних захисних систем виникають три фундаментальні нелінійні фактори, які унеможливлюють прямий аналітичний розрахунок і вимагають чисельного моделювання:
1. **Ефект магнітного насичення:** Відносна магнітна проникність реальних сплавів `μ_r(H)` є гостро нелінійною функцією напруженості або індукції магнітного поля. При зростанні зовнішнього поля `B_ext` індукція всередині тонкої стінки досягає значення насичення `B_sat` (для мю-металу `B_sat ≈ 0.75 Тл`), і проникність падає від 200 000 до одиниці (`μ_r → 1`).
2. **Багатошарова структура:** Екран складається з кількох концентричних шарів із матеріалів з різною індукцією насичення та проникністю (наприклад, зовнішній шар із електротехнічної кремнієвої сталі `B_sat = 2.0 Тл`, внутрішній шар із мю-металу `B_sat = 0.75 Тл`), розділених повітряними або алюмінієвими проміжками.
3. **Крайові витоки через відкриті торці:** Циліндричні екрани скінченної довжини `L` відчувають затікання магнітного поля через відкриті отвори, що описується згасанням хвилеводного типу.

Нижче наведено математичне формулювання, ітераційний алгоритм та програмну реалізацію моделювання нелінійного багатошарового циліндричного екрана.

### 1. Фізична модель чисельних методів у магнітостатиці

У сучасній інженерній практиці розрахунок складних трьохвимірних екранувальних конструкцій з отворами, дверними прорізами та швами проводиться за допомогою чисельних методів сіткового розв'язання рівнянь Максвелла:

1. **Метод скінченних елементів (FEM — Finite Element Method):** Область простору розбивається на тетраедричну або гексаедричну сітку. Розв'язується варіаційна задача мінімізації функціонала магнітної енергії `W_m = (1/2) ∫ (B · H) dV`. Завдяки формулюванню через векторний магнітний потенціал `B = ∇ × A` дискретизоване рівняння набирає вигляду `∇ × ((1/μ) ∇ × A) = J`. Метод скінченних елементів забезпечує найвищу точність у пакетних середовищах (COMSOL Multiphysics, ANSYS Maxwell, Elmer FEM), але вимагає велетенських обчислювальних ресурсів і пам'яті при моделюванні тонкостінних оболонок (`d = 0.5 мм`) великого радіуса (`R = 1.5 м`), де сітка вимагає мільйонів вузлів у товщі стінки.
2. **Метод граничних елементів (BEM — Boundary Element Method):** Диференціальне рівняння Лапласа перетворюється на поверхневе інтегральне рівняння методом фундаментальних розв'язків Гріна `G(r, r') = 1 / (4π |r - r'|)`. Дискретизуються лише 2D-поверхні екранів, що радикально зменшує розмірність системи рівнянь.
3. **Матричний метод передавальних матриць (TMM — Transfer Matrix Method):** Спеціалізований швидкий чисельний метод для концентричних циліндричних та сферичних оболонок. Саме цей метод покладено в основу наведеного нижче обчислювального алгоритму.

### 2. Математичне формулювання та нелінійне співвідношення

Розглянемо систему із `N` концентричних циліндричних шарів. Кожен шар `i` (від внутрішнього `i = 0` до зовнішнього `i = N-1`) описується геометричними радіусами `r_in[i]`, `r_out[i]`, товщиною `d[i] = r_out[i] - r_in[i]` та параметрами нелінійної кривої намагнічування `B(H)`.

Магнітний опір ділянки стінки циліндра одиничної довжини для поперечного магнітного потоку становить:

```
R_m[i] = ln(r_out[i] / r_in[i]) / (2π · μ₀ · μ_r[i])
```

Для тонкостінних оболонок (`d[i] ≪ r_in[i]`) формула спрощується:

```
R_m[i] ≈ d[i] / (2π · r_mean[i] · μ₀ · μ_r[i])
```

#### Модель нелінійної проникності Фреліха — Кеннеллі

Для врахування магнітного насичення матеріалу використовується феноменологічна апроксимація кривої намагнічування Фреліха — Кеннеллі, модифікована для робочого діапазону індукції:

```
μ_r(B) = 1 + (μ_max - 1) · [ 1 - (B / B_sat)ⁿ ]
```
де `μ_max` — максимальна початкова відносна проникність у слабких полях, `B_sat` — індукція насичення матеріалу, `n ≈ 2...4` — показник крутості переходу до стану насичення.

Якщо розраховане полем у товщі стінки `B_wall` перевищує порог `B_sat`, значення `μ_r` прямує до практичного мінімуму `μ_r ≈ 1.05`, що моделює втрату екранувальних властивостей.

#### Алгоритм ітераційного розрахунку

Оскільки індукція у стінці кожного шару `B_wall[i]` залежить від локального значення проникності `μ_r[i]`, яке само залежить від `B_wall[i]`, розрахунок здійснюється методом послідовних ітерацій (метод простої ітерації або метод Ньютона — Рафсона):

1. **Ініціалізація:** Припускаємо, що у слабкому полі всі шари мають максимальну початкову проникність `μ_r[i] = μ_max[i]`.
2. **Прямий хід (Обчислення екранування):** Для поточних значень `μ_r[i]` обчислюємо коефіцієнти екранування окремих шарів `S_i` та сумарний коефіцієнт `S_tot` за формулою Кюпфмюллера.
3. **Оцінка індукції у стінках:** Обчислюємо локальну індукцію у матеріалі кожного шару `B_wall[i] = B_local[i] · (r_out[i] / d[i])`.
4. **Оновлення проникності:** Обчислюємо нові значення `μ_r_new[i] = μ_r(B_wall[i])`.
5. **Перевірка збіжності:** Якщо максимальна зміна `|μ_r_new[i] - μ_r[i]| < ε` (де `ε = 10⁻⁵`), ітераційний процес завершується. Інакше здійснюємо релаксаційний крок `μ_r[i] = (1 - α) · μ_r[i] + α · μ_r_new[i]` (де `α = 0.3` — коефіцієнт релаксації) і повертаємося до кроку 2.

### 4. Фізичний аналіз результатів чисельного моделювання

Результати обчислень показують важливі фізичні закономірності, які необхідно враховувати при розробці практичних екранувальних систем:

1. **Режим слабкого поля (`B_ext = 50 мкТл`, фонове поле Землі):**
   - Двошарова система працює в ідеальному лінійному режимі, оскільки індукція у стінці мю-металу становить близько `2.5 мТл`, що набагато менше за поріг насичення `0.75 Тл`.
   - Сумарний коефіцієнт екранування сягає `S ≈ 4.5 × 10⁵` (понад `113 дБ`). Залишкове поле всередині становить менше ніж `0.11 нТл`, що є цілком достатнім для біомагнітних та квантових вимірювань.

2. **Режим сильного зовнішнього поля (`B_ext = 10 мТл`):**
   - Якби ми застосували лише один шар із мю-металу, потік в його стінці перевищив би `0.75 Тл`, викликавши глибоке магнітне насичення (`μ_r → 1`), і екранування впало б практично до нуля.
   - У градієнтній двошаровій схемі зовнішній шар з електротехнічної кремнієвої сталі (`B_sat = 2.0 Тл`) приймає на себе основне навантаження і гасить поле до `0.4 мТл`. Внутрішній шар з мю-металу бере це послаблене поле без ризику насичення і забезпечує остаточну прецизійну фільтрацію.

### 5. Практичні приклади розрахунку інженерних систем (Case Studies)

#### Приклад 1: Екранування колони електронного мікроскопа (TEM/SEM)

В електронній мікроскопії поле завад амплітудою більше ніж `0.1 мкТл` спричиняє розмиття пучка електронів, що розфокусовує зображення. Для захисту колони мікроскопа довжиною 1.2 м та радіусом 0.1 м розраховується 3-шаровий циліндричний екран з мю-металу товщиною стінок `d = 1.0 мм` із радіальними проміжками 20 мм.

Чисельне моделювання за наведеним алгоритмом дає `S₁ ≈ 350`, `S₂ ≈ 300`, `S₃ ≈ 250`. З урахуванням міжкаскадних повітряних зазорів підсумкове екранування становить `S_tot ≈ 1.8 × 10⁶` (понад `125 дБ`), що зменшує фонове геомагнітне поле до рівню `0.028 нТл` та забезпечує атомарну роздільну здатність мікроскопа.

#### Приклад 2: Екранування атомного годинника на холодних атомах рубідію

У прецизійних атомних годинниках (оптичних ґратках та квантових стандартах частоти) зовнішні магнітні поля зміщують енергетичні рівні за рахунок ефекту Зеємана. Захисна камера повинна підтримувати залишкове поле менше ніж `0.5 нТл` при сталості поля у часі кращій за `10⁻¹³`.

Моделювання 4-шарового сферичного екрана з Супермаллою `μ_max = 500 000` показує, що для сфери внутрішнім радіусом `R = 0.15 м` та товщиною стінок `d = 0.8 мм` коефіцієнт екранування становить `S_tot ≈ 8.2 × 10⁷` (понад `158 дБ`), що повністю пригнічує зовнішні зеєманівські зсуви частоти.

### 6. Чисельне розв'язання методом Ньютона — Рафсона

Для складних тривимірних конфігурацій із градієнтним магнітним полем проста ітерація за відносною проникністю `μ_r` може збігатися занадто повільно або розбігатися у районі вигину кривої намагнічування (`B ≈ 0.8 B_sat`).

У цих випадках застосовують лінеаризований метод Ньютона — Рафсона для розв'язання нелінійного рівняння сіткового потенціалу `F(A) = 0`. Необхідно враховувати тензор тангенціальної диференціальної проникності `μ_t`:

```
μ_t = dB / dH = μ_r + H · (dμ_r / dH)
```

Матриця Якобі `J_ij = ∂F_i / ∂A_j` стає анізотропною навіть для первинно ізотропного матеріалу, оскільки диференціальний опір уздовж напрямку намагніченості є меншим, ніж у перпендикулярному напрямку. Обчислення нелінійного приросту потенціалу `ΔA = -J⁻¹ · F(A)` забезпечує квадратичну швидкість збіжності за 4–6 ітерацій.

### 7. Сіткові адаптивні методи у тонкостінних структурах

При застосуванні сіткових FEM-методів для оболонок товщиною 0.5–1.0 мм при розмірі камери у кілька метрів виникає геометрична асиметрія елементів сітки (високе співвідношення сторін *aspect ratio* `> 100`). Це призводить до поганого обумовлення матриць жорсткості.

Для усунення цієї проблеми чисельні пакети використовують **адаптивне сіткове розбиття (h-refinement)** та пригнічення розмірності через створення призматичних приповерхневих шарів (*boundary layer prisms*). У товщі листа мю-металу генерують щонайменше 3–4 шари призм із постійною товщиною, що забезпечує коректне врахування перерозподілу нормальної та тангенціальної індукції без залучення мільйонів об'ємних тетраедрів.

### 8. Чисельне оцінювання магнітних шумів Джонсона — Найквіста

Металеві екранувальні оболонки виготовляють із матеріалів з високою провідністю (мю-метал має провідність `σ ≈ 1.8 × 10⁶ См/м`). Відповідно до флуктуаційно-дисипативної теореми (ФДТ), хаотичний тепловий рух носіїв заряду у стінках екрана створює вихрові мікроструми Джонсона — Найквіста.

Ці теплові струми генерують у захищеному об'ємі паразитичне спонтанне магнітне поле шумів. Спектральна густина шумової індукції у центрі сферичного або циліндричного екрана обчислюється за формулою:

```
S_B(f) = (4 · k_B · T · μ₀² · σ · d) / (3 · R_in²)  [Тл²/Гц]
```

Для кімнатної температури `T = 300 K` та радіуса екрана `R_in = 0.5 м` товщиною `d = 1 мм` спектральна густина магнітного шуму становить близько `15 fT / √Hz`. Це встановлює фундаментальну межу чутливості пасивного екрана: вимірювання полів нижче цього порогу вимагають застосування диелектричних феритових екранів або кріогенного охолодження стінок.

### 9. Моделювання активних компенсаційних систем

Для захисту від інфранизькочастотних завад (0.01 – 1 Гц, наприклад, від руху міського транспорту) пасивне екранування вимагає велетенської товщини мю-металу. Ефективним рішенням є комбінація пасивного екрана з чисельно керованою **системою активної компенсації**.

Система складається з триосьового магнітометра, 3D-кілець Гемгольца та цифрового PID-контролера. Моделювання зворотного зв'язку проводиться шляхом розв'язання різницевого рівняння керування:

```
I_coil(k) = K_p · e(k) + K_i · ∑ e(j) · Δt + K_d · [ (e(k) - e(k-1)) / Δt ]
```
де `e(k) = B_set - B_sensor(k)` — помилка неузгодженості полів.

Пасивний мю-металевий екран гасить високочастотні завади (>10 Гц) на 60–80 дБ, а активна система кілець Гемгольца подавляє дрейф низькочастотного поля (0.01–5 Гц) ще на 40 дБ, забезпечуючи ідеально стабільне середовище для прецизійних експериментів.

### 10. Крайові ефекти та чисельне урахування отворів

У практичних конструкціях розрахований для нескінченного циліндра коефіцієнт екранування знижується через наявність відкритих торців та технологічних отворів.

#### Торцеве затікання поля (End-fringing effect)

Для циліндричного екрана довжиною `L` та діаметром `D = 2R` проникнення поля з відкритих торців у центр циліндра описується геометричним поправочним коефіцієнтом:

```
S_real(z=0) = S_cyl / [ 1 + (S_cyl / S_long) · exp(-α · L / D) ]
```
де `z = 0` відповідає центру циліндра, `α ≈ 7.6` — дипольний коефіцієнт згасання для першої TE₁₁ моди.

Якщо відношення довжини циліндра до його діаметра є малим (`L / D < 3`), реальний коефіцієнт екранування визначається не товщиною стінки мю-металу, а затіканням поля через відкриті торці. У цьому випадку чисельне моделювання вимагає додавання торцевих кришок із виступаючими патрубками.

#### Загасання у технологічних отворах (Aperture cutoff)

Якщо в стінці екрана висвердлено круглий отвір діаметром `d_hole`, магнітне поле проникає крізь нього за законом зрізного хвилеводу. Для пригнічення витоку до отвору приварюють трубчастий патрубок з мю-металу довжиною `h_tube`. 

Згасання поля всередині такого патрубка на відстані `z` від поверхні екрана становить:

```
A_db(z) ≈ 32.0 · (z / d_hole)  [дБ]
```

Якщо довжина патрубка дорівнює трьом його діаметрам (`z / d_hole = 3`), додаткове згасання становить понад `96 дБ`, що повністю нівелює вплив отвору на внутрішнє захищене поле.

#### Механіка перекриття швів (Lap joints)

При виготовленні великогабаритних кімнат листи мю-металу з'єднують механічним нахлестом. Щоб уникнути магнітного витоку через стик, ширина нахлесту `w_overlap` повинна задовольняти умові:

```
w_overlap ≥ 20 · d_wall · (μ_r / 1000)
```

При товщині листа `d_wall = 1 мм` ширина нахлесту становить 50–100 мм. Стики скріплюють гвинтами з немагнітної латуні або бронзи із кроком 30–50 мм, щоб усунути повітряні зазори у шві.

### 11. Чисельний розрахунок розмагнічування та струшування доменних меж (AC Deperming & Shaking)

Навіть після високотемпературного водневого відпалу мю-метал під дією сильних випадкових полів або механічних струсів може набути залишкової намагніченості, що створює внутрішнє паразитичне поле завад. Для відновлення початкового стану з високою проникністю застосовують процедуру **магнітного струшування (Magnetic Shaking)** або розмагнічування затухаючим змінним полем (*Deperming*).

До стінок екрана підводять змінний струм частотою 100–400 Гц з амплітудою, яка спочатку виводить матеріал у глибоке насичення, а потім плавно експоненційно згасає до нуля за законом:

```
I_shake(t) = I₀ · exp(-t / τ) · sin(2π · f · t)
```

У чисельних моделях це явище моделюється як вимушена динамічна релаксація доменних меж: змінне поле змушує 180-градусні доменні стінки зриватися з потенціальних ям і дислокаційних стопорів. Завдяки цьому ефективна магнітна проникність `μ_eff` під час струшування зростає у 2–4 рази порівняно зі статичним станом, що дозволяє гасити надслабкі поля рівня фемтотесла.

### 12. Підсумкова інженерна методологія чисельного розрахунку

Узагальнюючи наведені чисельні методи, алгоритм проектування прецизійної екранувальної оболонки складається з шести послідовних кроків:

1. **Аналіз спектра завад:** Визначення постійної складової (DC, геомагнітне поле) та частотних піків (50 Гц мережа, високочастотні імпульсні джерела).
2. **Оцінка амплітуди:** Якщо зовнішнє поле перевищує `1 мТл`, проектують градієнтний 2-шаровий екран (зовнішня сталь `B_sat = 2.0 Тл`, внутрішній мю-метал `B_sat = 0.75 Тл`).
3. **Геометричний розрахунок за формулами Кюпфмюллера:** Розрахунок мінімальної кількості шарів та повітряних зазорів для досягнення цільового значення `S_dB`.
4. **Чисельне нелінійне моделювання (FEM/BEM):** Врахування технологічних отворів, отворів для кабелів та патрубків згасання (`L / D ≥ 3`).
5. **Теплова та механічна специфікація:** Врахування температурного відпалу у водню та оцінка Джонсонівського магнітного шуму стінок.
6. **Додавання активних компенсаційних кілець:** Для інфранизьких частот (до 1 Гц) пасивний екран доповнюють триосьовою системою кілець Гемгольца з цифровим PID-керуванням.

Під час проведення тривимірних FEM-розрахунків важливе значення має вибір зовнішніх граничних умов на віддалених межах розрахункової області (*far-field boundaries*). Межу обчислювального домену розташовують на відстані не менше ніж 3–5 радіусів зовні екрана, накладаючи умову нульового векторного потенціалу `A = 0` або умови магнітної ізоляції `n × A = 0`. Для прискорення обчислень використовують нескінченні елементи (*infinite elements*) або приповерхневі шари згасання PML (Perfectly Matched Layers), які запобігають відбиттю електромагнітних хвиль від меж сітки та забезпечують швидке знаходження стійкого числового розв'язку.

Завдяки поєднанню чисельного моделювання передавальних матриць TMM, сіткового FEM-розрахунку та практичних випробувань з розмагнічуванням затухаючим змінним полем досягається максимально можливий на сьогодні рівень захисту чутливого наукового, військового та медичного обладнання від шкідливих електромагнітних завад будь-якої частоти.
