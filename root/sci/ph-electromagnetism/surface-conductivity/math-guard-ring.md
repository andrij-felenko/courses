# 🧮 Математика розділення об'ємного та поверхневого струмів у кільцевій геометрії

Ця математична вставка містить точний розрахунок розподілу електричного потенціалу, виведення геометричних коефіцієнтів конверсії для триелектродної системи із захисним кільцем за стандартом IEC 60093, аналіз часової кінетики накопичення поверхневого заряду та повний чисельний розрахунок похибок вимірювання.

## 1. Геометрія плоского дискового зразка та розрахунок поверхневого опору

Розглянемо круглий плоский зразок діелектрика товщиною `h`, на верхній поверхні якого розташовано центральний круглий електрод діаметром `d₁` та концентричне захисне кільце з внутрішнім діаметром `d₂` та зовнішнім діаметром `d₃`. Ширина зазору між центральним електродом та кільцем становить `g = (d₂ - d₁) / 2`. На нижній поверхні зразка розміщено суцільний електрод діаметром `D > d₂`.

```
        Центральний (1)            Захисне кільце (2)
        [=== d₁ ===]  <- g ->  [====== d₂ ======]
───────┬────────────┬─────────┬──────────────────┬─────── Поверхня діелектрика
       │            │         │                  │
       │  Об'єм     │  Зазор  │   Поверхневий    │  Товщина матеріалу h
       │ діелектрика│   g     │   струм I_s      │
───────┴────────────┴─────────┴──────────────────┴─────── Основа діелектрика
       [================== D ===================]
                     Нижній електрод (3)
```

Математичний аналіз розрахунку поверхневого опору базується на інтегруванні тангенціального струму у кільцевій зоні зазору. Оскільки лінійний опір елементарного кільця радіусом `r` та шириною `dr` зворотно пропорційний довжині його кола `2π·r`, повний поверхневий опір `R_s` зазору описується інтегральним виразом:

```
dR_s = ρ_s · (dr / (2π · r))     [опір елементарного кільця шириною dr]
```

Інтегруємо цей вираз від внутрішнього радіуса зазору `r₁ = d₁ / 2` до зовнішнього радіуса зазору `r₂ = d₂ / 2`:

```
R_s = ∫ (ρ_s / (2π · r)) dr      [інтегрування елементарних кілець від r₁ до r₂]
= (ρ_s / (2π)) · [ln(r)]         [підстановка меж інтегрування від r₁ до r₂]
= (ρ_s / (2π)) · (ln(r₂) - ln(r₁)) [різниця логарифмів радіусів]
= (ρ_s / (2π)) · ln(r₂ / r₁)    [властивість логарифма частки]
= (ρ_s / (2π)) · ln(d₂ / d₁)    [заміна радіусів на діаметри: r₂/r₁ = d₂/d₁]
```

Звідси отримуємо точну логарифмічну формулу для обчислення питомого поверхневого опору `ρ_s` (у «Омах на квадрат»):

```
ρ_s = R_s · (2π / ln(d₂ / d₁))   [вираження ρ_s через повний опір R_s та діаметри]
```

Для вузьких вимірювальних зазорів (`g << d₁`) вираз `ln(d₂ / d₁)` розкладається у степеневий ряд Тейлора:

```
ln(d₂ / d₁) = ln((d₁ + 2g) / d₁) [підстановка d₂ = d₁ + 2g]
= ln(1 + (2g / d₁))              [виділення одиничного доданка]
≈ (2g / d₁) - (1/2)·(2g/d₁)²     [розклад Тейлора першого та другого порядку]
≈ 2g / d₁                        [лінійне наближення при 2g/d₁ << 1]
```

Підставляючи лінійне наближення у формулу опору, отримуємо спрощений вираз:

```
R_s ≈ (ρ_s / (2π)) · (2g / d₁)   [підстановка лінійного наближення]
= ρ_s · g / (π · d₁)             [скорочення двійки у чисельнику та знаменнику]
```

Нормативний стандарт IEC 60093 для підвищення точності обчислень використовує середній периметр зазору `P = π · (d₁ + g)` та напівширину зазору `g_eff = (d₂ - d₁) / 2`:

```
P = π · (d₁ + g)                 [середній периметр кільцевого зазору]
g_eff = (d₂ - d₁) / 2            [ефективна ширина зазору g]
k_s = P / g_eff = π · (d₁ + g) / g [геометричний коефіціент комірки k_s]
ρ_s = R_s · k_s                  [формула розрахунку питомого поверхневого опору]
```

## 2. Математична теорія еквіпотенціального захисного кільця

Розглянемо двовимірне крайове завдання електростатики для розподілу потенціалу `Φ(r, z)` у круговому циліндричному зразку діелектрика, який описується диференціальним рівнянням Лапласа у циліндричних координатах:

```
∇² Φ = (1/r) · ∂/∂r (r · ∂Φ/∂r) + ∂²Φ/∂z² = 0 [рівняння Лапласа в циліндричних координатах]
```

Граничні умови при вимірюванні об'ємного опору `ρ_v`:
1. На нижній поверхні діелектрика (`z = 0`): `Φ(r, 0) = U_test` для всього нижнього електрода `0 ≤ r ≤ D/2`.
2. На верхній поверхні центрального вимірювального електрода (`z = h`, `0 ≤ r ≤ d₁/2`): `Φ(r, h) = U₁ = 0 В` (підключення до віртуальної землі підсилювача).
3. На верхній поверхні захисного кільця (`z = h`, `d₂/2 ≤ r ≤ d₃/2`): `Φ(r, h) = U₂ = 0 В` (підключення до заземленого екранованого корпусу).

Оскільки потенціали центрального електрода та захисного кільця тотожно рівні між собою (`U₁ = U₂ = 0 В`), тангенціальна складова електричного поля у зазорі між ними на поверхні дорівнює нулю:

```
E_r(r, h) = - ∂Φ/∂r = 0          [тангенціальне поле у зазорі між рівнопотенціальними електродами]
```

Густина поверхневого струму у зазорі на верхній грані тотожно дорівнює нулю:

```
j_s(r) = σ_s · E_r(r, h) = 0 А/м [відсутність поверхневого струму за відсутності поля]
```

Завдяки виконанню умови `E_r = 0` силові лінії електричного поля у товщі діелектрика безпосередньо під центральним електродом спрямовані суворо вертикально (перпендикулярно площині електрода). Крайовий ефект викривлення силових ліній поля повністю зміщується під захисне кільце. Фізично це означає, що захисне кільце бере на себе увесь викривлений край поля, роблячи поле під центральним електродом строго одновимірним та однорідним. За допомогою конформного відображення зваженої плоскої області розраховують, що крайове посилення поля спадає за експоненційним законом на відстані порядку товщини матеріалу `h`.

Ефективна площа `A_eff` центрального електрода враховує напівширину зазору `g`:

```
d_eff = d₁ + g                   [ефективний діаметр вимірювальної зони]
A_eff = (π / 4) · (d₁ + g)²     [ефективна площа вимірювального електрода]
```

Об'ємний питомий опір `ρ_v` (в Ом·м) обчислюється за формулою:

```
ρ_v = R_v · (A_eff / h)          [вираження ρ_v через опір R_v, площу A_eff та товщину h]
= (U_test / I_v) · (π · (d₁ + g)² / (4 · h)) [підстановка закону Ома для I_v та площі A_eff]
```

## 3. Релаксаційна кінетика накопичення поверхневого заряду

При подачі випробувальної напруги `U_test` процес формування поверхневого струму та перерозподілу вільних зарядів не є миттєвим. Внаслідок наявності поверхневої ємності `C_s` та питомого опору `ρ_s` у приповерхневому шарі виникає релаксація вільних зарядів, описувана рівнянням безперервності струму:

```
∇ · j_s + ∂q_s/∂t = 0            [рівняння безперервності поверхневого заряду]
j_s = - σ_s · ∇ Φ_s              [закон Ома для поверхневого струму]
q_s = C_s · Φ_s                  [зв'язок поверхневого заряду з потенціалом]
```

Підставляючи ці вирази, отримуємо диференціальне рівняння дифузії поверхневого заряду:

```
∂q_s/∂t = (σ_s / C_s) · ∇² q_s  [рівняння дифузії поверхневого заряду]
```

Характерний час поверхневої RC-релаксації `τ_s` визначається співвідношенням питомого опору та діелектричної проникності середовища:

```
τ_s = ρ_s · C_s = ε_0 · ε_r · ρ_s [стала часу поверхневої релаксації]
```

Для високоомного діелектрика з `ρ_s = 10¹⁴ Ом/□` та `ε_r = 4` стала часу релаксації становить:

```
τ_s = (8.854 · 10⁻¹²) · 4 · 10¹⁴ [підстановка сталого коефіцієнта ε_0, проникності ε_r та опору ρ_s]
= 3541 секунда ≈ 59 хвилин       [стала часу поверхневої релаксації]
```

Саме через цю тривалу релаксацію поверхневих зарядів нормативні стандарти IEC 60093 та ASTM D257 вимагають витримувати зразок під напругою строго **60 секунд** перед зчитуванням струму. Це дозволяє завершити швидкі ємкісні струми заряджання й перейти до вимірювання квазістаціонарного струму витоку.

## 4. Повний чисельний розрахунок похибки розділення струмів

Проведемо повний математичний розрахунок реального дискового зразка епоксидного компаунда при двох значеннях відносної вологості повітря (30% та 85%).

Вихідні параметри випробувальної комірки та зразка:
- Товщина зразка: `h = 3.0 мм = 0.003 м`.
- Діаметр вимірювального електрода: `d₁ = 50.0 мм = 0.050 м`.
- Внутрішній діаметр захисного кільця: `d₂ = 54.0 мм = 0.054 м` (ширина зазору `g = 2.0 мм = 0.002 м`).
- Прикладена випробувальна напруга: `U_test = 500 В`.
- Питомий об'ємний опір матеріалу: `ρ_v = 2.0 · 10¹⁴ Ом·м`.

### Сценарій А: Сухі умови (RH = 30%, ρ_s = 1.0 · 10¹⁴ Ом/□)

Обчислимо ефективну площу `A_eff` та чистий об'ємний опір `R_v`:

```
A_eff = (π / 4) · (0.050 + 0.002)² [формула ефективної площі із напівшириною зазору]
= (π / 4) · (0.052)²            [додавання діаметра d₁ та зазору g]
= 0.002124 м²                   [обчислення ефективної площі у квадратних метрах]

R_v = ρ_v · (h / A_eff)         [вираження об'ємного опору через ρ_v, h та A_eff]
= (2.0 · 10¹⁴) · (0.003 / 0.002124) [підстановка питомого опору, товщини та площі]
= 2.825 · 10¹⁴ Ом               [розрахований об'ємний опір зразка]
```

Розрахуємо чистий об'ємний струм `I_v`:

```
I_v = U_test / R_v               [закон Ома для об'ємного струму]
= 500 / (2.825 · 10¹⁴)           [підстановка напруги U_test = 500 В та опору R_v]
= 1.770 · 10⁻¹² А = 1.77 пА     [обчислення об'ємного струму: 1.77 пікоампера]
```

Розрахуємо опір поверхневого витоку `R_s` за відсутності захисного кільця (двоелектродне підключення):

```
k_s = π · (0.050 + 0.002) / 0.002 [формула геометричного коефіцієнта комірки k_s]
= π · 0.052 / 0.002              [сумування діаметра d₁ та зазору g]
= 81.68                          [обчислення коефіцієнта k_s]

R_s = ρ_s / k_s                  [розрахунок поверхневого опору R_s]
= (1.0 · 10¹⁴) / 81.68           [підстановка ρ_s = 1.0·10¹⁴ Ом/□ та k_s]
= 1.224 · 10¹² Ом                [поверхневий опір зазору]
```

Розрахуємо поверхневий струм `I_s`:

```
I_s = U_test / R_s               [закон Ома для поверхневого струму]
= 500 / (1.224 · 10¹²)           [підстановка напруги U_test = 500 В та опору R_s]
= 4.085 · 10⁻¹₀ А = 408.5 пА    [обчислення поверхневого струму: 408.5 пікоампера]
```

Порівняємо струми в сухих умовах:

```
I_s / I_v = (4.085 · 10⁻¹₀) / (1.770 · 10⁻¹²) [співвідношення поверхневого та об'ємного струмів]
= 230.8                          [поверхневий струм у 230.8 раза більший за об'ємний]
```

### Сценарій Б: Вологі умови (RH = 85%, ρ_s = 5.0 · 10⁹ Ом/□)

При підвищенні вологості повітря об'ємний струм `I_v` залишається незмінним (`I_v = 1.77 пА`), оскільки вода не встигає здифундувати у товщу діелектрика.

Розрахуємо новий поверхневий опір `R_s` та поверхневий струм `I_s`:

```
R_s = ρ_s / k_s                  [формула поверхневого опору для вологого стану]
= (5.0 · 10⁹) / 81.68            [підстановка ρ_s = 5.0·10⁹ Ом/□ та k_s = 81.68]
= 6.121 · 10⁷ Ом = 61.21 МОм    [поверхневий опір вологого зазору]

I_s = U_test / R_s               [закон Ома для поверхневого струму у вологому стані]
= 500 / (6.121 · 10⁷)            [підстановка напруги U_test = 500 В та опору R_s]
= 8.168 · 10⁻⁶ А = 8.168 мкА    [обчислення поверхневого струму: 8.168 мікроампера]
```

Порівняємо струми у вологих умовах:

```
I_s / I_v = (8.168 · 10⁻⁶) / (1.770 · 10⁻¹²) [співвідношення струмів при вологості 85%]
= 4.615 · 10⁶                    [поверхневий струм у 4.61 мільйона разів більший за об'ємний!]
```

Обчислимо систематичну похибку вимірювання об'ємного опору без захисного кільця:

```
R_measured = U_test / (I_v + I_s) [виміряний опір без захисного кільця]
= 500 / (1.770 · 10⁻¹² + 8.168 · 10⁻⁶) [підстановка сумарного струму]
≈ 500 / (8.168 · 10⁻⁶)           [нехтування малим об'ємним струмом I_v]
= 6.121 · 10⁷ Ом = 61.21 МОм     [виміряне значення замість істинного 282.5 ТГОм]

Error = ((R_v - R_measured) / R_v) · 100% [відносна похибка вимірювання]
= ((2.825 · 10¹⁴ - 6.121 · 10⁷) / (2.825 · 10¹⁴)) · 100% [підстановка істинного та хибного опору]
= 99.999978 %                    [похибка перевищує 99.9999%]
```

Математичний висновок: використання захисного кільця із нульовим різницевим потенціалом `ΔU_gap = 0` є абсолютного необхідною умовою вимірювання об'ємного опору діелектриків. Воно повністю ліквідує поверхневий струм `I_s`, знижуючи систематичну похибку вимірювання з 99.9999% до менше ніж 0.1%.
