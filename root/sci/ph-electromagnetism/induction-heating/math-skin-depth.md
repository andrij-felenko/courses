# 🧮 Математична теорія скін-ефекту та розрахунок поглинутої потужності

Ця математична вставка містить строго послідовний вивід фундаментальних диференціальних рівнянь скін-ефекту у провідному середовищі, аналітичний розрахунок тензора поверхневого імпедансу, виведення розподілу вихрових струмів та розрахунок питомої теплової потужності, поглинутої металевою заготовкою при індукційному нагріві.

### 1. Виведення хвильового рівняння для провідника з рівнянь Максвелла

Розглянемо суцільне однорідне й ізотропне провідне середовище, яке характеризується питомою електричною провідністю `σ`, відносною магнітною проникністю `μ_r` та абсолютною магнітною проникністю `μ = μ_0 · μ_r`, де `μ_0 = 4π · 10⁻⁷` Гн/м — магнітна стала. Припустимо, що всередині провідника відсутній вільний об'ємний електричний заряд (`ρ_v = 0`), а матеріал є електродинамічно лінійним.

Виходимо з диференціальної форми фундаментальних рівнянь Максвелла для квазістаціонарного електромагнітного поля. У квазістаціонарному наближенні струмом зміщення `∂D/∂t` нехтують, оскільки густина струму провідності `j = σ E` у металах перевищує густину струму зміщення на багато порядків аж до частот оптичного діапазону.

Перша пара рівнянь Максвелла має вигляд:

```
∇ × E = −∂B / ∂t
∇ × H = j
∇ · B = 0
∇ · E = 0
```

Матеріальні співвідношення для лінійного провідного середовища описуються рівняннями:

```
j = σ · E
B = μ · H
```

Для виведення диференціального рівняння для електричного поля застосуємо математичний оператор ротора `∇ ×` до обох частин закону електромагнітної індукції Фарадея `∇ × E = −∂B / ∂t`:

```
∇ × (∇ × E) 
= ∇ × (−∂B / ∂t)
= −∂ / ∂t (∇ × B)      [перестановка диференціювання за часом і простором]
= −μ · ∂ / ∂t (∇ × H)   [матеріальне співвідношення B = μ H]
= −μ · σ · (∂E / ∂t)    [закон Ома j = σ E та рівняння ∇ × H = j]
```

Скористаємося відомою векторною тотожністю векторного аналізу для подвійного ротора довільного векторного поля:

```
∇ × (∇ × E) = ∇(∇ · E) − ∇²E
```

Оскільки за умовою відсутності вільних об'ємних зарядів у провіднику градієнт дивергенції електричного поля дорівнює нулю (`∇(∇ · E) = 0`), ліва частина виразу спрощується до мінус-лапласіана `-∇²E`. Підставляючи це у вихідний вираз, отримуємо класичне тривимірне дифузійне хвильове рівняння для вектора напруженості електричного поля у провідному середовищі:

```
∇²E = μ · σ · (∂E / ∂t)
```

Аналогічним чином, застосовуючи оператор ротора до рівняння `∇ × H = j`, отримуємо дифузійне рівняння для вектора напруженості магнітного поля `H`:

```
∇²H = μ · σ · (∂H / ∂t)
```

Фізичний зміст отриманих рівнянь полягає у тому, що електромагнітне поле у провідному середовищі не поширюється у вигляді незгасного хвильового процесу (як у вакуумі чи діелектрику), а дифундує вглиб металу, зазнаючи інтенсивного експоненціального згасання через перетворення енергії поля на тепло Джоуля.

### 2. Одномірна модель плоского напівпростору та виведення глибини скін-шару

Для детального аналізу розподілу поля по глибині заготовки розглянемо одномірну модель: провідне тіло займає напівпростір `z ≥ 0`, а його плоска поверхня збігається з координатною площиною `z = 0`. Зовнішнє змінне магнітне поле індуктора є паралельним поверхні й спрямоване вздовж осі `x`: `H_x(z, t)`. Згідно з правилом правої руки, індуковане вихрове електричне поле та густина вихрових струмів спрямовані вздовж осі `y`: `E_y(z, t)` та `j_y(z, t)`.

Нехай зовнішнє магнітне поле змінюється за гармонічним (синусоїдальним) законом із кутовою частотою `ω = 2π f`:

```
H_x(z, t) = Re[ H_z(z) · e^(i ω t) ]
```

Підставляємо гармонічну залежність за часом у одномірне дифузійне рівняння:

```
d²H_z / dz² = i · ω · μ · σ · H_z
```

Позначимо комплексний коефіцієнт поширення електромагнітної хвилі у провіднику як `k`:

```
k² = i · ω · μ · σ
```

Для знаходження квадратного кореня з уявної одиниці скористаємося тригонометричною формою комплексного числа `i = e^(i π/2)`:

```
√i = e^(i π/4) = cos(π/4) + i · sin(π/4) = (1 + i) / √2
```

Тоді комплексний коефіцієнт поширення `k` набуває вигляду:

```
k = √(ω · μ · σ) · (1 + i) / √2 = √(ω · μ · σ / 2) · (1 + i)
```

Введемо фундаментальну фізичну величину — **глибину скін-шару** `δ` (*skin depth*), яка має розмірність довжини (метри або міліметри):

```
δ = √( 2 / (ω · μ · σ) ) = √( ρ / (π · f · μ_0 · μ_r) )
```

де `ρ = 1 / σ` — питомий електричний опір матеріалу (Ом·м).

За допомогою параметра `δ` комплексний коефіцієнт поширення записується у надзвичайно компактній формі:

```
k = (1 + i) / δ
```

Загальний розв'язок другого порядку диференціального рівняння є сумою двох експоненціальних доданків:

```
H_z(z) = C_1 · e^(−k z) + C_2 · e^(+k z)
```

З фізичної умови обмеженості поля при віддаленні від поверхні вглиб провідника (`z → ∞`) випливає, що амплітуда поля не може зростати до нескінченності. Отже, коефіцієнт `C_2` мусить дорівнювати нулю (`C_2 = 0`). Гранична умова на поверхні `z = 0` вимагає, щоб магнітне поле дорівнювало поверхневому значенню `H_0`, створеному струмом індуктора. Звідси `C_1 = H_0`.

Отримуємо підсумковий математичний закон розподілу комплексної амплітуди магнітного поля по глибині провідника:

```
H_z(z) = H_0 · e^(−(1 + i) z / δ) = H_0 · e^(−z / δ) · e^(−i z / δ)
```

Переходячи від комплексного подання до дійсних фізичних величин у часовій області, отримуємо:

```
H_x(z, t) = H_0 · e^(−z / δ) · cos(ω t − z / δ)
```

Аналіз отриманого рівняння показує двохкомпонентну структуру хвилі:
1. Множник `e^(−z / δ)` описує строге експоненціальне згасання амплітуди магнітного поля по мірі занурення вглиб металу. На глибині `z = δ` амплітуда спадає в `e ≈ 2.718` раза, а на глибині `z = 3δ` — у `e³ ≈ 20.1` раза.
2. Множник `cos(ω t − z / δ)` описує просторовий фазовий зсув: по мірі просунення вглиб металу фаза магнітного поля відстає від поверхневої фази на кут `Δφ = z / δ` радіан.

Для обчислення розподілу вихрових струмів скористаємося диференціальним зв'язком `j = ∇ × H`, що в одномірному випадку дає:

```
j_y(z) = −dH_z / dz = H_0 · (1 + i) / δ · e^(−(1 + i) z / δ)
```

Амплітудне значення густини вихрового струму `|j(z)|` спадає за аналогічним експоненціальним законом:

```
|j(z)| = j_0 · e^(−z / δ)
```

де `j_0 = √2 · H_0 / δ` — амплітуда густини струму безпосередньо на зовнішній поверхні `z = 0`.

### 3. Поверхневий імпеданс та питома поглинута потужність

Зв'язок між поверхневою напруженістю електричного поля `E_0` та поверхневим магнітним полем `H_0` визначається через **поверхневий імпеданс** `Z_s` (виражається у Ом/квадрат):

```
Z_s = E_0 / H_0 = (1 + i) / (σ · δ) = R_s + i · X_s
```

де активний поверхневий опір `R_s` та поверхневий індуктивний опір `X_s` дорівнюють один одному:

```
R_s = X_s = 1 / (σ · δ) = √( (ω · μ) / (2 · σ) ) = √( π · f · μ · ρ )
```

З рівності `R_s = X_s` випливає фундаментальний висновок: **будь-який провідник при індукційному нагріві вносить у коло індуктора не лише активний опір нагріву, але й еквівалентну індуктивність такого самого значення**.

Усереднений за періодом потік енергії електромагнітного поля, що входить у поверхню провідника одиничної площі (вектор Пойнтінга `S`), обчислюється як дійсне значення комплексного вектора Пойнтінга:

```
P_surf = Re[ 1/2 · E_0 · H_0* ] = 1/2 · R_s · |H_0|²
```

Оскільки повний поверхневий струм на одиницю ширини заготовки `J_surf = ∫₀^∞ j(z) dz = H_0`, поглинута питома потужність Джоулева нагріву (Вт/м²) виражається через квадрат поверхневого струму:

```
P_surf = 1/2 · R_s · |J_surf|² = 1/2 · √( (ω · μ) / (2 · σ) ) · |J_surf|²
```

З отриманої вираження випливають три фундаментальні інженерні залежності:
1. Поглинута потужність зростає пропорційно квадратному кореню з частоти `√f`.
2. Потужність нагріву пропорційна квадрату амплітуди струму індуктора `I²`.
3. Для феромагнітних матеріалів (де `μ_r ≫ 1`) поглинання потужності в десятки разів вище, ніж для кольорових металів.

### 4. Точний розрахунок циліндричної заготовки через функції Бесселя

Для суцільного циліндра радіуса `a` одномірна плоска модель є справедливою лише при `a ≫ δ`. У загальному випадку циліндричної геометрії диференціальне рівняння для магнітного поля у циліндричних координатах `(r, θ, z)` набуває вигляду:

```
d²H_z / dr² + (1 / r) · dH_z / dr − k² · H_z = 0
```

Це модифіковане диференціальне рівняння Бесселя нульового порядку. Його розв'язок, що є обмеженим і скінченним на осі циліндра `r = 0`, виражається через модифіковану функцію Бесселя першого роду `I_0`:

```
H_z(r) = H_surf · ( I_0(k r) / I_0(k a) )
```

де `k = (1 + i) / δ`. Повна активна потужність `P_total`, поглинута циліндричною заготовкою довжиною `L`, обчислюється шляхом інтегрування вектора Пойнтінга по бічній поверхні циліндра:

```
P_total = π · a · L · R_s · |H_surf|² · F(a / δ)
```

де `F(x)` — безрозмірна функція ефективності нагріву циліндра від відношення радіуса до глибини скін-шару `x = a / δ`:

```
F(x) = [ ber(x) · ber'(x) + bei(x) · bei'(x) ] / [ ber²(x) + bei²(x) ]
```

де `ber(x)` та `bei(x)` — дійсна та уявна частини функції Кельвіна `J_0(x · e^(i 3π/4))`.

Асимптотичний аналіз безрозмірної функції `F(a / δ)` демонструє два граничні режими:
- При `a / δ < 1` (дуже низька частота або тонка деталь): `F(a / δ) ≈ (1 / 8) · (a / δ)³`. Потужність нагріву прямує до нуля, оскільки магнітне поле пронизує деталь наскрізь без утворення вихрових струмів.
- При `a / δ > 4` (оптимальний високочастотний режим): `F(a / δ) ≈ 1 / √2`. Функція виходить на насичення, а ефективність нагріву сягає максимуму.

Звідси випливає практичний критерій вибору частоти генератора: **для забезпечення максимального ККД індукційного нагріву діаметр заготовки `d = 2a` повинен перевищувати глибину скін-шару `δ` щонайменше у 3.5–4 рази**:

```
d / δ ≥ 3.5 ... 4.0
```
