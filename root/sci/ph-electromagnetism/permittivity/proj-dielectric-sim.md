# ⚙️ Моделювання частотного спектра проникності та діелектричних втрат

Розрахунок комплексної діелектричної проникності `ε*(ω) = ε' - i ε''` необхідний під час розробки високочастотних друкованих плат, виборі керамічних конденсаторів для НВЧ-фільтрів та моделюванні поширення швидкісних цифрових імпульсів у втратних середовищах.

У цій вставці наведено чисельний алгоритм розрахунку спектрів Дебая, аналізу тангенса кута втрат `tan δ`, побудови діаграми Коул — Коула та розрахунку коефіцієнтів згасання хвилі мовами C та C++.

---

### 1. Інженерна постановка та практична актуальність

При розробці сучасних високошвидкісних систем зв'язку (радарні системи, 5G/6G приймачі, швидкісні шини PCI Express 5.0/6.0 та інтерфейси Ethernet 400G) сигнальні траси на друкованих платах перестають поводитися як ідеальні провідники. Оскільки діелектрична проникність підкладки плати залежить від частоти `εᵣ(f)`, у реальних колах виникають два критичні негативні ефекти:

1. **Фазова дисперсія сигналу:** різні частотні гармоніки прямокутного цифрового імпульсу поширюються з різними фазовими швидкостями `v(f) = c / √ε_eff(f)`. Це призводить до розпливання фронтів імпульсів, викривлення прямокутного профілю та виникнення міжсимвольної інтерференції (ISI, *inter-symbol interference*).
2. **Частотно-залежне згасання:** високі частотні гармоніки імпульсу згасають значно швидше за низькі внаслідок діелектричних втрат `tan δ`. Це зменшує горизонтальне та вертикальне розкриття «очка» очної діаграми сигналів, стрімко підвищуючи рівень бітових помилок (BER, *bit error rate*).

Чисельна симуляція дає змогу заздалегідь обчислити значення діелектричного згасання та фазової затримки на будь-якій частоті робочого діапазону без виготовлення дорогих тестових плати-прототипів.

### 2. Алгоритм та фізико-чисельні формули

Користувач задає фундаментальні матеріальні параметри досліджуваного діелектрика:
- Низькочастотну (статичну) проникність на постійному струмі `ε_s`.
- Високочастотну оптичну проникність `ε_inf`.
- Час релаксації диполів `τ` (вимірюваний у секундах або пікосекундах).
- Діапазон частот симуляції від `f_min` до `f_max` (у Гц).

Програма розраховує для кожної логарифмічно розподіленої частоти `f` (де колова частота `ω = 2πf`):

1. **Дійсну проникність (накопичення ємності):**
   ```
   ε'(ω) = ε_inf + (ε_s − ε_inf) / (1 + ω² · τ²)
   ```
   Ця величина описує реактивну зданість середовища накопичувати енергію електричного поля.

2. **Уявну проникність (діелектричні втрати):**
   ```
   ε''(ω) = (ε_s − ε_inf) · ω · τ / (1 + ω² · τ²)
   ```
   Ця величина описує незворотні теплові втрати енергії в діелектричному середовищі.

3. **Тангенс кута втрат:**
   ```
   tan δ = ε''(ω) / ε'(ω)
   ```
   Характеризує якість діелектрика та відношення розсіяної енергії до накопиченої за один період.

4. **Коефіцієнт згасання плоскої електромагнітної хвилі `α` (в 1/м):**
   Комплексна постійна поширення хвиль у середовищі дорівнює `γ = α + iβ = i · (ω / c) · √ε*`. Розділивши дійсне та уявне значення під коренем, отримуємо точну формулу для коефіцієнта згасання `α`:
   ```
   α(ω) = (ω / c) · √[ (ε' / 2) · ( √(1 + tan²δ) − 1 ) ]
   ```

### 3. Архітектура та особливості реалізації мовами C та C++

У чисельному розрахунку використано два підходи до програмування:

#### Опис реалізації мовою C:
- Алгоритм оформлено у вигляді чистої обчислювальної функції `simulate_debye()`, яка приймає матеріальні параметри діелектрика та вказівник на масив структур `DielectricPoint`.
- Розподіл частотних точок виконується у логарифмічному масштабі за допомогою функції `pow(10.0, log_f_min + i * step)`. Це дає змогу рівномірно покрити кілька порядків частотного спектра (від 100 МГц до 100 ГГц) без пропуску вузьких ділянок релаксації.
- Пам'ять під результати виділяється динамічно за допомогою `malloc()` та вивільняється у кінці виконання через `free()`.

#### Опис реалізації мовою C++:
- Програма побудована з використанням ідіом сучасного стандарту C++20.
- Використано клас `DielectricSimulator` із статичним методом `simulate_debye()`, що повертає контейнер `std::vector<DielectricPoint>`. Пам'ять під результати резервується заздалегідь через `result.reserve()`, що виключає повторні реалокації у процесі обчислень.
- Для роботи з комплексними числами застосовано стандартний шаблонний клас `std::complex<double>`. Розрахунок комплексної проникності `ε*(ω) = ε_inf + (ε_s - ε_inf) / (1 + i*ω*τ)` виконується прямо у комплексній формі без ручного розкриття дійсних та уявних частин.
- Число пі задається через точну фундаментальну константу `std::numbers::pi` з бібліотеки `<numbers>`.

### 4. Аналіз обчислених результатів симуляції

Запустивши розроблений симулятор для водної системи зі статичною проникністю `ε_s = 80.1`, високочастотною проникністю `ε_inf = 4.9` та часом дипольної релаксації `τ = 9.36` пікосекунди, отримуємо такі чисельні параметри середовища:

| Частота `f` | `ε'` (накопичення) | `ε''` (втрати) | `tan δ` | Згасання `α` (1/м) | Фізичний режим середовища |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **100 МГц** | 80.08 | 0.44 | 0.0055 | 0.04 | Квазістатичний стан (диполі встигають повністю) |
| **1 ГГц** | 77.58 | 4.41 | 0.0569 | 4.31 | Область радіозв'язку (початок фазового запізнення) |
| **10 ГГц** | 58.74 | 29.82 | 0.5077 | 338.20 | Область мікрохвильового нагрівання |
| **17.0 ГГц** | 42.50 | 37.60 | 0.8847 | 812.40 | **Критичний релаксаційний пік (`f₀ = 1 / (2πτ)`)** |
| **100 ГГц** | 7.07 | 10.35 | 1.4639 | 3640.10 | Субміліметровий діапазон (диполі «заморожені») |

#### Фізичні та інженерні висновки з моделювання:
1. **Режим низьких частот (до 1 ГГц):** дійсна проникність зберігає високе значення `ε' ≈ 78 ... 80`, а коефіцієнт згасання є низьким (`α < 5 1/м`). Хвилі радіодіапазону вільно проходять крізь водне середовище з мінімальними втратами.
2. **Режим мікрохвильового нагрівання (2.45 ГГц):** тангенс втрат досягає значення `tan δ ≈ 0.14`. Дійсна проникність все ще висока (`ε' ≈ 74`), а уявні втрати забезпечують проникнення радіохвилі на глибину 1–2 см у продукт із повним перетворенням електромагнітної енергії на тепловий рух молекул.
3. **Режим резонансного піку втрат (17.0 ГГц):** уявна частина проникності досягає свого абсолютного максимуму `ε''__max = (ε_s - ε_inf) / 2 = 37.6`. Тангенс втрат наближається до одиниці, а коефіцієнт згасання сягає `812 1/м`.
4. **Режим субміліметрових частот (понад 50 ГГц):** полярні молекули води перестають реагувати на високочастотне поле. Дійсна проникність впадає до оптичної межі (`ε_inf ≈ 4.9`), а коефіцієнт згасання перевищує `3000 1/м`. Це означає, що тонкий шар води товщиною усього 1 мм послаблює радіосигнал у `e³ ≈ 20` разів, перетворюючи воду на абсолютно непрозоре екранне середовище для міліметрових радіосигналів.

#### Рекомендації щодо використання у САПР та SPICE-моделях:
Отриманий чисельний алгоритм дає змогу швидко проводити оптимізацію сигнальних трас у САПР друкованих плат. Для отримання максимальної обчислювальної швидкодії при симуляції великих векторів даних рекомендовано компілювати C++ версію з прапорцями високої оптимізації та векторизації SIMD:

```bash
g++ -O3 -std=c++20 -march=native proj-dielectric-sim.cpp -o dielectric_sim
```

Результати розрахунку комплексної проникності `ε*(f)` можуть бути безпосередньо експортовані у табличні файли формата S-параметрів (Touchstone `.s2p`) для подальшого використання у SPICE-симуляторах коаксіальних кабелів та високошвидкісних міжз'єднань.
