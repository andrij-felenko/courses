# ⚙️ Вимірювання діелектричної проникності: від LC-резонансу до комплексного імпедансу

Цей проект описує розробку, розрахунок та практичну реалізацію лабораторного приладу для вимірювання відносної діелектричної проникності `εᵣ` та тангенса кута втрат `tan δ` рідких та твердих речовин. У ньому розглядаються два алгоритмічні підходи: метод зсуву резонансної частоти LC-генератора для швидкого експрес-аналізу та метод цифрового синхронного детектування (квадратурного вимірювання комплексного імпедансу) на мікроконтролері для зняття повноцінних діелектричних спектрів у діапазоні частот від 1 кГц до 10 МГц.

---

### 1. Фізичні принципи та вимірювальна геометрія датчика

Для вимірювання проникності речовини використовують спеціально сконструйовану вимірювальну комірку. Вона являє собою двох- або триелектродну конденсаторну систему з фіксованим міжобкладочним зазором. Найпоширенішими конструкціями є плоскі паралельні дискові електроди для твердих зразків та циліндричні концентричні трубки з нержавіючої сталі або латуні для рідких діелектриків (наприклад, трансформаторної олива, спиртів чи палива).

Початкова порожня (повітряна) ємність вимірювальної комірки `C₀` визначається чисто геометричними параметрами:

```
C₀ = ε₀ · A / d                          [для плоских дискових електродів]
C₀ = 2 · π · ε₀ · L / ln(R₂ / R₁)        [для циліндричної комірки]
```

Для реальних вимірювальних систем `C₀` зазвичай обирають у діапазоні від 5 до 50 пФ. Коли між електродами вносять досліджуваний діелектрик, підсумкова ємність комірки зростає і описується співвідношенням:

```
C_measured = εᵣ · C₀ + C_p
```

де `C_p` — паразитна ємність монтажних провідників, сполучних роз'ємів BNC та крайових полів на межах електродів. Значення `C_p` зазвичай лежить у межах від 1.5 до 8.0 пФ і має бути точно виміряне на етапі первинного калібрування приладу.

#### Метод 1: Зсув частоти LC-автогенератора
У першому варіанті приладу вимірювальна комірка підключається паралельно до високостабільного еталонного індуктивного елемента `L` (наприклад, дроселя 100 мкГн із сердечником із карбонільного заліза, що має мінімальний температурний коефіцієнт). За допомогою аналогового компаратора LM311 або високочастотних транзисторів будується автогенератор за схемою Коепітса або Франкліна.

Аналоговий компаратор LM311 перетворює синусоїдальні коливання LC-контуру на прямокутні імпульси з логічними рівнями 0–3.3 В, які надходять на вхід зовнішнього зачеплення апаратного таймера мікроконтролера (наприклад, TIM2_ETR у STM32 або вход PCNT в ESP32).

Генерована частота прямо визначається повною ємністю контуру:

```
f₀ = 1 / (2 · π · √(L · (C₀ + C_p)))         [порожня комірка з повітрям]
f_m = 1 / (2 · π · √(L · (εᵣ·C₀ + C_p)))      [комірка з досліджуваним діелектриком]
```

Виразивши квадрат відношення виміряних частот `(f₀ / f_m)²`:

```
(f₀ / f_m)² = (εᵣ · C₀ + C_p) / (C₀ + C_p)
```

отримуємо підсумкову розрахункову формулу відносної проникності `εᵣ`:

```
εᵣ = 1 + ((f₀ / f_m)² - 1) · (1 + C_p / C₀)
```

Цей метод вимагає лише підрахунку кількості імпульсів за допомогою апаратного таймера мікроконтролера за фіксований проміжок часу (наприклад, за 100 мілісекунд). Це забезпечує високу роздільну здатність (до 0.001 за значенням `εᵣ`), але дозволяє вимірювати лише дійсну частину проникності `ε'`.

#### Метод 2: Квадратурна спектроскопія комплексного імпедансу
Для вимірювання уявної частини проникності `ε''` та тангенса втрат `tan δ` використовують метод гармонічного зондування. Від цифрового генератора прямого синтезу частоти (DDS на базі AD9833) на комірку подається синусоїдальна напруга `V(t) = V₀ · cos(ω·t)`.

Протікаючий через комірку комплексний струм `I(t) = I₀ · cos(ω·t + φ)` перетворюється на напругу за допомогою трансімпедансного підсилювача (TIA) на високошвидкісному операційному підсилювачі AD8065 із малою вхідною ємністю. Двоканальний аналогово-цифровий перетворювач (АЦП) мікроконтролера синхронно оцифровує вибірки напруги та струму через канал DMA без залучення процесорного часу.

Цифровий процесор мікроконтролера здійснює квадратурну демодуляцію (помножує масив вибірок струму на вбудовані табличні послідовності `cos(2·π·k/N)` та `sin(2·π·k/N)`):

```
I_inphase = (2 / N) · ∑ I[k] · cos(2·π·k / N)
I_quad    = (2 / N) · ∑ I[k] · sin(2·π·k / N)
```

Комплексна провідність (адмітанс) комірки `Y = G + i · ω · C` описується формулами:

```
C = I_quad / (ω · V₀)                  [ємність -> ε' = (C - C_p) / C₀]
G = I_inphase / V₀                     [активна провідність -> ε'' = G / (ω · C₀)]
tan δ = G / (ω · C) = ε'' / ε'          [тангенс кута втрат]
```

Завдяки квадратурній обробці вдається вимірювати мікроскопічні кути втрат `tan δ` аж до значення `0.0005`, що необхідно для діагностики стану трансформаторної оливи та високочастотних полімерів.

### 4. Інженерні пастки, екранування та методи калібрування

Під час розробки вимірювальних систем діелектричної проникності інженер зіштовхується з низкою критичних факторів, порушення яких призводить до похибок вимірювання на сотні відсотків.

#### 1. Екранування крайових полів за допомогою охоронного кільця (Guard Ring)
У звичайному двополюсному конденсаторі силові лінії на краях обкладок вигинаються назовні в навколишнє повітря. Це призводить до того, що ефективна площа електродів здається більшою за реальну геометричну площу. Для розв'язання цієї проблеми в професійній вимірювальній техніці застосовують триелектродну схему за стандартом ASTM D150. Навколо центрального потенційного електрода розміщують кільцевий ізольований заземлений електрод (Guard Ring). Охоронне кільце перебуває під тим самим напругою, що й потенційний електрод, завдяки чому всі крайові викривлені силові лінії замкаються на заземлене кільце, а усередині вимірювальної зони зберігається ідеально однорідне вертикальне поле.

#### 2. Борьба з ефектом електродної поляризації на низьких частотах
При вимірюванні проникності рідких діелектриків (водних розчинів, рідких електролітів, біологічних рідин) на частотах нижче 10 кГц у середовищі присутні вільні іони. Під дією постійного або низькочастотного поля іони дрейфують до поверхонь металевих електродів і формують подвійний електричний шар (шар Ґої — Чапмана). Товщина цього шару становить лише кілька нанометрів, що створює гігантську поверхневу ємність. У результаті прилад показує хибні аномальні значення проникності (`εᵣ > 10 000`). Для усунення електродної поляризації застосовують електроди, покриті платиновою чернню, або проводять вимірювання виключно на частотах понад 50 кГц, де іони не встигають дрейфувати до електродів.

#### 3. Компенсація паразитної індуктивності дротів (Open/Short Calibration)
При проведенні вимірювань на частотах понад 1 МГц довжина підключувальних кабелів створює послідовну паразитна індуктивність `L_lead`. Вона утворює з ємністю комірки послідовний резонансний контур, через що виміряне значення ємності стає більшим за дійсне:

```
C_apparent = C_real / (1 - ω² · L_lead · C_real)
```

Для виключення впливу кабелів мікроконтролер виконує процедуру двоточкової компенсації: вимірювання імпедансу при розімкненій комірці (*Open Calibration*) та при короткозамкнених електродах (*Short Calibration*).

#### 4. Процедура двоточкового калібрування за еталонними рідинами
Для точного обчислення геометрії комірки `C₀` та паразитної ємності `C_p` прилад калібрують за двома вимірювальними рідинами із заздалегідь відомими табличними значеннями проникності при кімнатній температурі (20 °C):
* **Точка 1**: Очищене сухе повітря (`εᵣ = 1.0006`).
* **Точка 2**: Хімічно чистий циклогексан (`εᵣ = 2.02`) або толуол (`εᵣ = 2.38`).

Шляхом розв'язання системи з двох лінійних рівнянь обчислюються точні значення `C₀` та `C_p`, що зберігаються в енергонезалежній пам'яті EEPROM/Flash мікроконтролера.
