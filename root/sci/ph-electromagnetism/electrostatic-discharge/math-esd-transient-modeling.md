# 🧮 Математична модель перехідного процесу ESD: RLC-диференціальні рівняння та імпульсна енергетика

Математичний аналіз електростатичного розряду (ESD) дозволяє розрахувати ключові кількісні параметри перехідного процесу: амплітуду пікового струму `I_max`, час наростання `t_r`, розсіяну енергію `E_dis` та умови переходу між аперіодичним і коливальним режимами розряду. Без цієї математичної бази неможливо розрахувати геометричні параметри захисних TVS-діодів, визначити теплову стійкість напівпровідникових переходів та спроектувати ефективні екранувальні системи.

### 1. Виведення диференціального рівняння розрядного RLC-кола

Розглянемо класичну еквівалентну електричну схему розряду. Джерело накопиченого заряду моделюється конденсатором ємністю `C`, початково зарядженим до потенціалу `V₀`. Розрядне коло містить активний опір `R` (який враховує опір тіла людини, опір металізації та динамічний опір іскрового плазмового каналу) та паразитну індуктивність `L` з'єднувальних провідників.

Згідно з другим законом Кірхгофа, у будь-який момент часу `t` сума спадів напруг на всіх елементах замкненого контуру дорівнює нулю:

```
V_C(t) + V_R(t) + V_L(t) = 0
```

Виразимо напруги через електричний заряд ємності `Q(t)` та розрядний струм `I(t)`. Зв'язок між струмом та зміною заряду має вигляд `I(t) = -dQ/dt` (знак мінус вказує на зменшення заряду на конденсаторі). Напруга на ємності дорівнює `V_C = Q / C`, спад напруги на опорі дорівнює `V_R = I · R`, а спад напруги на індуктивності визначається самоіндукцією `V_L = L · (dI/dt)`.

Підставляючи ці співвідношення у вихідне рівняння Кірхгофа та виконуючи диференціювання по часу `t`, отримуємо лінійне однорідне диференціальне рівняння другого порядку з постійними коефіцієнтами:

```
L · (d²I / dt²) + R · (dI / dt) + (1 / C) · I = 0
```

Щоб знайти розв'язок цього рівняння, складемо відповідне алгебраїчне характеристичне рівняння відносно невідомого параметра `λ`:

```
L · λ² + R · λ + (1 / C) = 0
```

Розділивши всі члени на індуктивність `L`, перепишемо характеристичне рівняння у канонічній формі:

```
λ² + 2 · α · λ + ω₀² = 0
```

де引入ведено фундаментальні фізичні параметри контуру:
- `α = R / (2 · L)` — коефіцієнт згасання (характеризує швидкість втрати енергії на активному опорі);
- `ω₀ = 1 / √(L · C)` — власна резонансна коловий частота контуру за відсутності згасання.

Корені характеристичного рівняння `λ₁` та `λ₂` знаходяться за стандартною формулою квадратного рівняння:

```
λ₁,₂ = -α ± √(α² - ω₀²)
```

Фізичний характер розв'язку визначається знаком підкореневого виразу (дискримінанта) `D = α² - ω₀²`.

### 2. Детальний аналіз фізичних режимів розряду

#### Аперіодичний режим розряду (характерний для Human Body Model)

Аперіодичний режим виникає тоді, коли коефіцієнт згасання переважає власну частоту контуру (`α > ω₀`). Це відповідає високому активному опору кола, який перевищує критичне значення:

```
R > 2 · √(L / C)     [умова аперіодичного згасання]
```

У цьому випадку корені характеристичного рівняння є дійсними та від'ємними числоми. Позначимо параметр `β = √(α² - ω₀²)`. Тоді корені дорівнюють `λ₁ = -α + β` та `λ₂ = -α - β`. Загальний розв'язок для струму має вигляд суми двох експонент:

```
I(t) = A₁ · exp(( -α + β ) · t) + A₂ · exp(( -α - β ) · t)
```

Константи `A₁` та `A₂` визначаються з початкових фізичних умов у момент часу `t = 0`:
1. Струм у початковий момент дорівнює нулю через індуктивну інерцію: `I(0) = 0`, що дає `A₁ + A₂ = 0`, тобто `A₂ = -A₁`.
2. Напруга на конденсаторі в момент `t = 0` дорівнює `V₀`, тому швидкість наростання струму визначається індуктивністю: `dI/dt(0) = V₀ / L`.

Підставляючи початкові умови, отримуємо остаточний вираз для струму в аперіодичному режимі:

```
I(t) = (V₀ / (2 · β · L)) · ( exp(-(α - β) · t) - exp(-(α + β) · t) )
     = (V₀ / (β · L)) · exp(-α · t) · sinh(β · t)
```

Графік цієї функції являє собою імпульс із швидким наростанням та подальшим повільним експоненціальним згасанням. Час досягнення максимального пікового струму `t_peak` розраховується з умови рівності нулю першої похідної `dI/dt = 0`:

```
dI / dt = (V₀ / L) · exp(-α · t) · ( cosh(β · t) - (α / β) · sinh(β · t) ) = 0
```

Звідси отримуємо точну формулу для часу досягнення піку:

```
t_peak = (1 / (2 · β)) · ln((α + β) / (α - β))
```

Для більшості практичних випадків HBM (`R = 1500` Ом, `C = 100` пФ, `L = 1` мкГн) опір значно перевищує хвильовий опір контуру (`R >> 2·√(L/C)`), тому параметр `β ≈ α - ω₀² / (2·α)`. В цьому наближенні піковий струм досягається практично миттєво, а його амплітуда визначається простим співвідношенням Ома:

```
I_max ≈ V₀ / R
```

#### Затухаючий коливальний режим розряду (характерний для Machine Model)

Якщо активний опір кола є малим (`R < 2·√(L/C)`), підкореневий вираз стає від'ємним (`α < ω₀`). Корені характеристичного рівняння стають комплексно-спряженими:

```
λ₁,₂ = -α ± j · ω_d
```

де `ω_d = √(ω₀² - α²)` — квазічастота власних згасаючих коливань кола, а `j = √(-1)` — уявна одиниця.

За допомогою формули Ейлера комплексні експоненти перетворюються на гармонічні функції. Остаточний розв'язок для струму в коливальному режимі набуває вигляду:

```
I(t) = (V₀ / (ω_d · L)) · exp(-α · t) · sin(ω_d · t)
```

У цьому режимі струм багаторазово змінює свій напрямок (полярність), створюючи високочастотні згасаючі коливання. Для напівпровідникових структур цей режим є найбільш небезпечним, оскільки зворотно-зміщені p-n переходи почергово переходять із режиму пробою у режим прямого проходження струму, викликаючи вимушені перехідні процеси розсмоктування носіїв та високі динамічні перенапруги.

### 3. Енергетика розряду та інтеграл дії струму

Загальна потенціальна енергія `E_cap`, початково збережена в електростатичному полі конденсатора, обчислюється як інтеграл від густини енергії поля:

```
E_cap = (1 / 2) · C · V₀²
```

Ця енергія повністю розсіюється протягом перехідного процесу на всіх активних опорах контуру. Законом збереження енергії гарантується, що інтеграл від миттєвої потужності дорівнює початковій енергії:

```
E_cap = ∫ P(t) dt
      = ∫ I²(t) · R_total(t) dt      [дисипація тепла Джоуля]
```

Для оцінки теплового нагріву провідників та напівпровідникових переходів використовують **інтеграл дії струму** (так званий `i²t` інтеграл або термоінтеграл):

```
J_action = ∫ I²(t) dt
```

Ця величина показує здатність імпульсу струму нагрівати провідник в адіабатичному режимі (коли тепло не встигає відводитися в довкілля). Збільшення температури провідника масою `m` та питомою теплоємністю `c` розраховується за формулою:

```
ΔT = (R_element / (m · c)) · ∫ I²(t) dt
```

Якщо струм розряджається через захисний TVS-діод із фіксованою напругою обмеження `V_clamp`, енергія `E_tvs`, яка виділяється безпосередньо у захисному елементі, розраховується через сумарний перенесений заряд `Q_tot`:

```
E_tvs = ∫ V_clamp · I(t) dt
      = V_clamp · ∫ I(t) dt           [винесення константи V_clamp за інтеграл]
      = V_clamp · Q_tot
      = V_clamp · C · V₀              [заміна Q_tot = C · V₀]
```

Цей результат ілюструє фундаментальний інженерний принцип: **що меншою є напруга обмеження `V_clamp` захисного елемента, то менша частка енергії розряду виділяється у кристалі супресора**, а основний енергетичний удар приймає на себе послідовний обмежувальний опір лінії.

### 4. Виведення закону Пашена з умов Таунсенда

Напруга іскрового пробою повітряного зазору `V_b` у плоскій геометрії описується законом Пашена. Математичне виведення цього закону спирається на критерій самопідтримання електронної лавини Таунсенда.

Умова самопідтримання розряду у газі між двома плоскими електродами на відстані `d` має вигляд:

```
γ · ( exp( α · d ) - 1 ) = 1
```

де `α` — перший коефіцієнт Таунсенда (кількість іонізацій на 1 м шляху електрона), а `γ` — другий коефіцієнт Таунсенда (ефективний коефіцієнт вторинної емісії електронів із катода при бомбардуванні іонами).

Перший коефіцієнт Таунсенда `α` залежить від напруженості електричного поля `E` та тиску газу `p` за емпіричною формулою:

```
α = A · p · exp( -B · p / E )
```

де `A` та `B` — константи даного газу.

В однорідному полі електрична напруженість дорівнює `E = V / d`. Підставляючи `E` у формулу для `α` та логарифмуючи умову самопідтримання розряду, отримуємо:

```
α · d = ln( 1 + 1 / γ )
```

```
A · p · d · exp( -B · p · d / V_b ) = ln( 1 + 1 / γ )
```

Розв'язуючи це рівняння відносно напруги пробою `V_b`, отримуємо класичну формулу закону Пашена:

```
V_b = (B · p · d) / (ln(A · p · d) - ln(ln(1 + 1 / γ)))
```

Проаналізуємо отриману функцію `V_b(p·d)`. При дуже малих значеннях `p·d` чисельник зменшується, але знаменник прагне до нуля ще швидше (оскільки `ln(A·p·d)` зменшується), тому напруга пробою `V_b` стрімко зростає. Фізично це пояснюється тим, що при вкрай малих зазорах електрон не встигає зіштовхнутися з молекулами газу на своєму шляху (довжина вільного пробігу більша за зазор `d`).

При великих значеннях `p·d` напруга зростає лінійно, оскільки електрони втрачають енергію у частих пружних зіткненнях.

Мінімальне значення напруги пробою `V_b_min` знаходять шляхом взяття похідної `dV_b / d(pd) = 0`:

```
(p · d)_min = (e / A) · ln(1 + 1 / γ)
```

```
V_b_min = e · (B / A) · ln(1 + 1 / γ)
```

де `e ≈ 2.71828` — основа натурального логарифма.

Для атмосферного повітря (`p = 101.3` кПа) константи дорівнюють `A ≈ 11.25` 1/(Па·м), `B ≈ 274` В/(Па·м), а для металевих електродів `γ ≈ 0.01`. Підстановка цих чисел дає мінімальну напругу пробою повітря **`V_b_min ≈ 327` Вольт** при критичному зазорі **`d_min ≈ 7.5` мікрометрів**. Цей результат доводить, що при потенціалах нижче 300 В іскровий розряд у сухому повітрі неможливий — руйнування мікросхем при низьких напругах відбувається виключно через прямий механічний контакт та тунелювання носіїв.
