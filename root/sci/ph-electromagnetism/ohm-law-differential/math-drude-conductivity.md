# 🧮 Виведення питомої провідності в кінетичній моделі Друде

Математичне обґрунтування диференціального закону Ома базується на аналізі динаміки ансамблю носіїв заряду в провідному середовищі під сумісною дією прискорювального електричного поля та статистичного розсіювання на теплових коливаннях або дефектах ґратки.

## 1. Рівняння руху електрона з релаксаційним тертям

Розглянемо електрон із масою `m` та зарядом `q = -e` (де `e = 1.602 · 10⁻¹⁹` Кл), що рухається в однорідному електричному полі з напруженістю `E`.

У класичній моделі Друде вплив численних хаотичних зіткнень електрона з кристалічною ґраткою усереднюється по ансамблю частинок та описується ефективною силою гальмування (релаксаційним членом), пропорційною середній дрейфовій швидкості `v`:

```
F_drag = - (m / τ) · v
```

де `τ` — характерний час релаксації імпульсу (середній час вільного пробігу між двома послідовними актами розсіювання).

Диференціальне рівняння руху для середньої дрейфової швидкості електрона має вигляд:

```
m · (dv / dt) = - e · E - (m / τ) · v
```

Поділивши обидві частини рівняння на масу `m`, отримуємо лінійне неоднорідне диференціальне рівняння першого порядку:

```
dv / dt + (1 / τ) · v = - (e / m) · E
```

## 2. Стаціонарний розв'язок і дрейфова швидкість

У стаціонарному режимі (за постійного електричного поля `E = const`), коли процес прискорення полем точно врівноважується гальмуванням об ґратку, похідна швидкості за часом прямує до нуля:

```
dv / dt = 0
```

Підставляючи нульову похідну в рівняння руху, знаходимо стаціонарну дрейфову швидкість електронів `v_d`:

```
(1 / τ) · v_d = - (e / m) · E
v_d = - (e · τ / m) · E
```

Знак «мінус» відображає фундаментальний факт: негативно заряджені електрони дрейфують у напрямку, протилежному до вектора напруженості електричного поля `E`.

Коефіцієнт пропорційності між модулем дрейфової швидкості та напруженістю поля називається **рухливістю електронів** `μ_e`:

```
|v_d| = μ_e · |E|
μ_e = (e · τ) / m    [м² / (В · с)]
```

## 3. Нестаціонарний процес встановлення струму

Якщо в момент часу `t = 0` увімкнути постійне поле `E` у провіднику, де електрони спочатку не мали дрейфової швидкості (`v(0) = 0`), розв'язок диференціального рівняння методом розділення змінних або інтегрувального множника має вигляд:

```
v(t) + (e · τ / m) · E = C · exp(-t / τ)
```

Враховуючи початкову умову `v(0) = 0`, константа інтегрування дорівнює `C = (e · τ / m) · E`. Остаточний часовий профіль дрейфової швидкості:

```
v(t) = - (e · τ / m) · E · (1 - exp(-t / τ))
```

Оскільки час релаксації `τ` для чистих металів за кімнатної температури має надзвичайно малий порядок величини (`10⁻¹⁴`–`10⁻¹³` с), стаціонарний стан дрейфової швидкості встановлюється практично миттєво (за кілька десятків фемтосекунд).

## 4. Виведення вектора густини струму та формули Друде

Вектор густини струму `j` визначається сумарним перенесенням заряду всіма електронами в одиниці об'єму. Якщо концентрація електронів провідності дорівнює `n` [м⁻³], то:

```
j = n · q · v_d = n · (-e) · v_d
```

Підставляючи вираз для стаціонарної дрейфової швидкості `v_d = - (e · τ / m) · E`, отримуємо:

```
j = n · (-e) · ( - (e · τ / m) · E )    [підстановка стаціонарної дрейфової швидкості v_d]
  = (n · e² · τ / m) · E                [спрощення знаків: (-e) · (-e) = e²]
```

Порівнюючи отриманий результат із диференціальним законом Ома `j = σ · E`, знаходимо аналітичну формулу Друде для **питомої провідності** `σ`:

```
σ = (n · e² · τ) / m    [См / м  або  Ом⁻¹ · м⁻¹]
```

Відповідно, **питомий електричний опір** `ρ` як обернена величина дорівнює:

```
ρ = 1 / σ = m / (n · e² · τ)    [Ом · м]
```

## 5. Статистичне обґрунтування через функцію розподілу Больцмана

Для суворішого мікроскопічного виведення розглянемо функцію розподілу електронів у фазовому просторі `f(r, v, t)`. У стаціонарному та просторово однорідному стані кінетичне рівняння Больцмана в наближенні часу релаксації (BGK-наближення) має вигляд:

```
- (e / m) · E · (∂f / ∂v) = - (f - f₀) / τ
```

де `f₀(v)` — рівноважна функція розподілу (у класичному випадку — максвеллівський розподіл, у квантовому — фермієвський).

Шукаємо збурену функцію розподілу у вигляді `f(v) = f₀(v) + f₁(v)`, де `f₁ ≪ f₀` — мале відхилення від рівноваги під дією слабкого поля `E`.

Враховуючи, що в лінійному наближенні `∂f / ∂v ≈ ∂f₀ / ∂v`:

```
f₁(v) = (e · τ / m) · E · (∂f₀ / ∂v)
```

Густина електричного струму обчислюється як інтеграл за всім простором швидкостей:

```
j = - e · ∫ v · f(v) d³v = - e · ∫ v · f₁(v) d³v
```

Оскільки рівноважна функція `f₀(v)` сферично симетрична, інтеграл від `v · f₀` тотожно дорівнює нулю. Підставляючи `f₁`:

```
j = - (e² · τ / m) · ∫ v · (E · ∇_v f₀) d³v
```

Інтегруючи частинами по тривимірному простору швидкостей:

```
∫ v_x · (∂f₀ / ∂v_x) d³v
= - ∫ f₀(v) d³v        [інтегрування частинами: u = v_x, dv = (∂f₀/∂v_x) d³v]
= - n                  [умова нормування: повна концентрація електронів]
```

Звідси негайно випливає той самий вираз для густини струму вздовж поля:

```
j = (n · e² · τ / m) · E
```

Цей результат є надзвичайно важливим: він показує, що лінійна формула Друде `σ = n · e² · τ / m` зберігає свій аналітичний вигляд як для класичної максвеллівської статистики, так і для квантової статистики Фермі-Дірака (де маса замінюється ефективною масою квазічастинки на поверхні Фермі `m*`, а час релаксації береться при енергії Фермі `τ(E_F)`).

## 6. Зв'язок електропровідності та теплопровідності (закон Відемана-Франца)

Одним із найважливіших тріумфів моделі Друде стало теоретичне обґрунтування емпіричного закону Відемана-Франца, згідно з яким відношення коефіцієнта теплопровідності `κ` до питомої електропровідності `σ` для всіх чистих металів є універсальною функцією, прямо пропорційною абсолютній температурі `T`.

У кінетичній теорії газів коефіцієнт теплопровідності електронного газу виражається стандартною формулою:

```
κ = (1 / 3) · c_v · v_th · λ
```

де `c_v` — об'ємна теплоємність електронного газу, `v_th` — середня швидкість хаотичного руху, а `λ = v_th · τ` — середня довжина вільного пробігу.

У класичній моделі Друде теплоємність класичного одноатомного ідеального газу електронів дорівнює `c_v = (3 / 2) · n · k_B`, а середня кінетична енергія теплового руху пов'язана з температурою як `(1 / 2) · m · v_th² = (3 / 2) · k_B · T`.

Підставляючи ці величини у формулу теплопровідності:

```
κ = (1 / 3) · ( (3 / 2) · n · k_B ) · v_th · (v_th · τ)    [підстановка c_v та довжини вільного пробігу λ]
  = (1 / 2) · n · k_B · v_th² · τ                           [спрощення коефіцієнтів: (1/3) · (3/2) = 1/2]
  = (1 / 2) · n · k_B · (3 · k_B · T / m) · τ               [підстановка швидкості v_th² = 3·k_B·T/m]
  = (3 / 2) · (n · k_B² · T · τ) / m                        [перегрупування констант та множників]
```

Обчислимо тепер відношення коефіцієнта теплопровідності `κ` до питомої електропровідності `σ = (n · e² · τ) / m`:

```
κ / σ
= [ (3 / 2) · (n · k_B² · T · τ) / m ] / [ (n · e² · τ) / m ]    [підстановка формул теплопровідності та електропровідності]
= (3 / 2) · (k_B / e)² · T                                         [скорочення концентрації n, маси m та часу релаксації τ]
```

Таким чином, відношення `κ / (σ · T)` залежить виключно від фундаментальних фізичних констант і називається **числом Лоренца** `L`:

```
L = κ / (σ · T) = (3 / 2) · (k_B / e)² ≈ 1.11 · 10⁻⁸ Вт · Ом / К²
```

Квантове уточнення Зоммерфельда, яке строго враховує виродження електронного газу та статистику Фермі-Дірака, замінює числовий множник `3/2` на `π²/3`, що дає теоретичне значення `L = (π² / 3) · (k_B / e)² ≈ 2.44 · 10⁻⁸ Вт · Ом / К²`, що з високою точністю збігається з експериментальними вимірюваннями для міді, срібла, золота та алюмінію.

## 7. Частотна дисперсія та комплексна динамічна провідність

Якщо провідник перебуває у високочастотному змінному електричному полі `E(t) = E₀ · exp(-i · ω · t)`, шукаємо розв'язок для дрейфової швидкості у вигляді `v(t) = v₀ · exp(-i · ω · t)`.

Підстановка в динамічне рівняння руху дає:

```
- i · ω · m · v₀ = - e · E₀ - (m / τ) · v₀
```

Перегруповуючи доданки з `v₀`:

```
v₀ · (m / τ - i · ω · m) = - e · E₀
v₀ · (1 - i · ω · τ) = - (e · τ / m) · E₀
v₀ = - (e · τ / m) · E₀ / (1 - i · ω · τ)
```

Густина струму на частоті `ω`:

```
j(ω) = n · (-e) · v₀ = σ(ω) · E₀
```

де комплексна динамічна провідність середовища дорівнює:

```
σ(ω) = σ₀ / (1 - i · ω · τ)
```

де `σ₀ = (n · e² · τ) / m` — статична провідність на постійному струмі.

Розділяючи дійсну та уявну частини:

```
σ(ω) = σ₀ · (1 + i · ω · τ) / (1 + ω² · τ²)
Re(σ(ω)) = σ₀ / (1 + ω² · τ²)              [активна дисипативна провідність]
Im(σ(ω)) = σ₀ · ω · τ / (1 + ω² · τ²)        [реактивна індуктивна провідність через інерцію електронів]
```

Зв'язуючи провідність із комплексною діелектричною проникністю металу `ε(ω) = 1 + i · σ(ω) / (ε₀ · ω)`:

```
ε(ω) = 1 - ω_p² / (ω² + i · ω / τ)
```

де `ω_p = √(n · e² / (ε₀ · m))` — **плазмова частота** електронного газу. За частот `ω < ω_p` діелектрична проникність від'ємна, метал сильно відбиває електромагнітні хвилі (металевий блиск), а за `ω > ω_p` метал стає прозорим для ультрафіолетового випромінювання.

## 8. Тензорна провідність у магнітному полі (ефект Холла)

При накладанні постійного зовнішнього магнітного поля `B = (0, 0, B_z)` на електрони діє сила Лоренца `F_L = -e · (v × B)`. Повне стаціонарне рівняння руху в площині `xy`:

```
0 = - e · (E + v × B) - (m / τ) · v
```

У проекціях на осі координат:

```
(m / τ) · v_x + e · B_z · v_y = - e · E_x
- e · B_z · v_x + (m / τ) · v_y = - e · E_y
```

Вводячи циклотронну частоту `ω_c = (e · B_z) / m`, переписуємо систему для компонент швидкості:

```
v_x + ω_c · τ · v_y = - (e · τ / m) · E_x
- ω_c · τ · v_x + v_y = - (e · τ / m) · E_y
```

Розв'язуючи систему лінійних алгебраїчних рівнянь відносно `v_x` та `v_y`:

```
v_x = - (e · τ / m) · (E_x - ω_c · τ · E_y) / (1 + (ω_c · τ)²)
v_y = - (e · τ / m) · (E_y + ω_c · τ · E_x) / (1 + (ω_c · τ)²)
```

Обчислюємо компоненти густини струму `j_x = -n · e · v_x` та `j_y = -n · e · v_y`:

```
j_x = σ_xx · E_x + σ_xy · E_y
j_y = - σ_xy · E_x + σ_xx · E_y
```

де компоненти тензора провідності мають вигляд:

```
σ_xx = σ₀ / (1 + (ω_c · τ)²)
σ_xy = σ₀ · (ω_c · τ) / (1 + (ω_c · τ)²)
```

Недіагональна компонента `σ_xy` описує виникнення поперечного струму та поперечної різниці потенціалів — класичний ефект Холла, підтверджуючи фундаментальний тензорний характер диференціального закону Ома у магнітоактивних середовищах.
