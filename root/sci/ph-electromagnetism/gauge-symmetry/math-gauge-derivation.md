# 🧮 Математичний апарат калібрувальних перетворень і 4-потенціалу

Математична формалізація калібрувальної симетрії в класичній та квантовій електродинаміці спирається на введення потенціальних полів, які спрощують рівняння Максвелла й забезпечують лоренц-коваріантність викладу. Напруженості електричного поля `E` та магнітного поля `B` задовольняють однорідну пару рівнянь Максвелла (відсутність магнітних зарядів і закон індукції Фарадея):

```
∇ · B = 0                 [відсутність магнітних монополів]
∇ × E + ∂B/∂t = 0         [закон електромагнітної індукції Фарадея]
```

Оскільки дивергенція ротора дорівнює нулю для будь-якого векторного поля `∇ · (∇ × A) = 0`, умову `∇ · B = 0` можна тотожно задовольнити, виразивши вектор індукції `B` через векторний потенціал `A`:

```
B = ∇ × A                 [означення векторного потенціалу]
```

Підставляючи це співвідношення в закон Фарадея, отримуємо операторну рівність:

```
∇ × E + ∂(∇ × A)/∂t = 0
= ∇ × (E + ∂A/∂t) = 0     [винесення ротора за знак похідної]
```

Оскільки ротор безвихрового поля дорівнює нулю `∇ × (∇φ) = 0`, вираз під ротором можна подати як градієнт скалярної функції `φ` (скалярного потенціалу):

```
E + ∂A/∂t = -∇φ           [потенціальний характер безвихрового поля]
E = -∇φ - ∂A/∂t           [вираження електричного поля через потенціали]
```

## Теорема Гельмгольца та розклад векторного поля

Фундаментальна теорема Гельмгольца стверджує, що будь-яке гладке векторне поле `V(r)`, яке швидко загасає на безмежності, може бути однозначно розкладене на суму соленоїдальної (бездивергентної) та потенціальної (безроторної) компонент:

```
V = V_long + V_trans      [розклад Гельмгольца]
```

де `∇ × V_long = 0` (поздовжня або безвихрова компонента) та `∇ · V_trans = 0` (поперечна або соленоїдальна компонента).

У термінах електромагнітного поля векторний потенціал `A` містить як поперечну компоненту `A_trans` (`∇ · A_trans = 0`), так і поздовжню компоненту `A_long` (`∇ × A_long = 0`). Оскільки `∇ × A_long = 0`, поздовжня компонента може бути записана як градієнт скалярної функції `A_long = ∇λ`. Звідси стає зрозуміло, чому магнітне поле `B = ∇ × A = ∇ × A_trans` визначається виключно поперечною компонентою векторного потенціалу, тоді як поздовжня компонента `∇λ` залишається повністю довільною і може змінюватись за допомогою калібрувального перетворення.

## Калібрувальна свобода у тривимірному формалізмі

Потенціали `φ` та `A` визначені недосконало: вони містять надлишкові ступені вільності. Припустимо, що ми здійснюємо перетворення векторного потенціалу додаванням градієнта довільної тричі диференційовної скалярної функції `λ(r, t)`:

```
A' = A + ∇λ               [перетворення векторного потенціалу]
```

Ротор нового векторного потенціалу збігається з початковим магнітним полем, оскільки ротор градієнта тотожно дорівнює нулю:

```
B' = ∇ × A'
= ∇ × (A + ∇λ)            [підстановка перетворення]
= ∇ × A + ∇ × ∇λ          [лінійність оператора ротора]
= B + 0 = B               [властивість: ∇ × ∇λ = 0]
```

Щоб електричне поле `E` також залишалося інваріантним, скалярний потенціал `φ` повинен компенсувати часову похідну функції `λ(r, t)`:

```
E' = -∇φ' - ∂A'/∂t
= -∇φ' - ∂(A + ∇λ)/∂t
= -∇φ' - ∂A/∂t - ∇(∂λ/∂t)
= -∇(φ' + ∂λ/∂t) - ∂A/∂t  [згрупування градієнтів]
```

Порівнюючи вираз для `E'` із початковим полем `E = -∇φ - ∂A/∂t`, отримуємо умову інваріантності `E' = E`:

```
φ' + ∂λ/∂t = φ
φ' = φ - ∂λ/∂t            [перетворення скалярного потенціалу]
```

Таким чином, одночасна заміна наборів потенціалів `(φ, A) → (φ', A')` за правилом:

```
A' = A + ∇λ               [калібрувальне перетворення A]
φ' = φ - ∂λ/∂t            [калібрувальне перетворення φ]
```

залишає фізично спостережувані поля `E` та `B` абсолютно незмінними.

## Чотиривимірний коваріантний формалізм і тензор полів

У 4-вимірній просторово-часовій формалізації Спеціальної теорії відносності з метрикою `g_{μν} = diag(1, -1, -1, -1)` скалярний та векторний потенціали об'єднуються у єдиний 4-потенціал `A^μ`:

```
A^μ = (φ/c, A)            [контраваріантний 4-потенціал]
A_μ = (φ/c, -A)           [коваріантний 4-потенціал]
```

4-градієнт визначається як `∂_μ = (∂/(c ∂t), ∇)` та `∂^μ = (∂/(c ∂t), -∇)`. Калібрувальне перетворення набуває винятково компактного вигляду:

```
A'_μ = A_μ + ∂_μ λ        [коваріантне калібрувальне перетворення]
```

Тензор електромагнітного поля `F_{μν}` визначається як 4-ротор потенціалу:

```
F_{μν} = ∂_μ A_ν - ∂_ν A_μ  [тензор напруженостей електромагнітного поля]
```

Доведемо калібрувальну інваріантність тензора `F_{μν}` для довільної функції `λ(x^μ)`:

```
F'_{μν} = ∂_μ A'_ν - ∂_ν A'_μ
= ∂_μ (A_ν + ∂_ν λ) - ∂_ν (A_μ + ∂_μ λ)  [підстановка перетворення]
= ∂_μ A_ν - ∂_ν A_μ + ∂_μ ∂_ν λ - ∂_ν ∂_μ λ  [розкриття дужок]
= F_{μν} + (∂_μ ∂_ν λ - ∂_ν ∂_μ λ)       [виділення початкового тензора]
= F_{μν} + 0 = F_{μν}                     [симетрія других похідних: ∂_μ ∂_ν λ = ∂_ν ∂_μ λ]
```

Оскільки всі елементи тензора `F_{μν}` є компонентами векторів `E` та `B`, калібрувальна інваріантність тензора доводить незмінність усіх класичних спостережуваних величин.

Неоднорідні рівняння Максвелла у 4-коваріантній формі виражаються через 4-струм `J^ν = (c ρ, J)`:

```
∂_μ F^{μν} = μ₀ J^ν       [коваріантне рівняння Максвелла]
```

Підставляючи вираз для тензора `F^{μν} = ∂^μ A^ν - ∂^ν A^μ`, отримуємо рівняння для 4-потенціалу:

```
∂_μ (∂^μ A^ν - ∂^ν A^μ) = μ₀ J^ν
∂_μ ∂^μ A^ν - ∂^ν (∂_μ A^μ) = μ₀ J^ν  [перестановка похідних]
```

Тут `□ = ∂_μ ∂^μ = (1/c²) ∂²/∂t² - ∇²` — оператор Даламбера (даламберіан). Рівняння потенціалів містить зв'язаний член `∂^ν (∂_μ A^μ)`, який ускладнює розв'язання.

## Виведення хвильових рівнянь у калібруванні Лоренца

Для того щоб розчепити чотири коваріантні рівняння, застосовують калібрувальну умову Лоренца:

```
∂_μ A^μ = 0               [умова Лоренца]
```

За цієї умови зв'язаний додаток `∂^ν (∂_μ A^μ) = ∂^ν (0) = 0` зникає. В результаті рівняння Максвелла набувають вигляду чотирьох незалежних неоднорідних хвильових рівнянь для кожної компоненти 4-потенціалу:

```
□ A^ν = μ₀ J^ν            [розчеплені хвильові рівняння 4-потенціалу]
```

Розписавши це рівняння по компонентах `ν = 0, 1, 2, 3`, отримуємо відповідні хвильові рівняння для скалярного потенціалу `φ` та векторного потенціалу `A`:

```
(1/c²) ∂²φ/∂t² - ∇²φ = ρ / ε₀     [для скалярного потенціалу φ]
(1/c²) ∂²A/∂t² - ∇²A = μ₀ J      [для векторного потенціалу A]
```

Розв'язками цих хвильових рівнянь у необмеженому просторі є запізнювальні потенціали (retarded potentials):

```
φ(r, t) = (1 / 4π ε₀) ∫ [ρ(r', t - |r - r'|/c) / |r - r'|] d³r'
A(r, t) = (μ₀ / 4π) ∫ [J(r', t - |r - r'|/c) / |r - r'|] d³r'
```

Ці розв'язки явно показують, що будь-яка зміна густини заряду `ρ` або струму `J` у точці `r'` поширюється до точки спостереження `r` зі скінченною швидкістю `c`.

## Лагранжева формулювання та інваріантність дії

У лагранжевій формулюванні електродинаміки густина функції Лагранжа для вільного електромагнітного поля додається до густини Лагранжіана взаємодії з 4-струмом `J_μ`:

```
L_EM = -(1 / 4 μ₀) F_{μν} F^{μν} - J_μ A^μ   [густина Лагранжіана електродинаміки]
```

Перевіримо зміну дії `S = ∫ L_EM d⁴x` при калібрувальному перетворенні `A^μ → A^μ + ∂^μ λ`:

Перший член `F_{μν} F^{μν}` є суворо калібрувально-інваріантним, оскільки `F'_{μν} = F_{μν}`.

Зміна другого члена `L_int = -J_μ A^μ` при перетворенні дорівнює:

```
δ L_int = -J_μ ∂^μ λ      [зміна густини взаємодії]
```

Інтегруючи цю зміну по всьому 4-об'єму простору-часу частинами, отримуємо:

```
δ S_int = -∫ J_μ (∂^μ λ) d⁴x
= -∫ ∂^μ (J_μ λ) d⁴x + ∫ (∂^μ J_μ) λ d⁴x   [інтегрування частинами]
```

Перший додаток за теоремою Ґаусса перетворюється на поверхневий інтеграл на нескінченно віддаленій гіперповерхні і дорівнює нулю за умови загасання полів. Другий додаток дорівнює нулю тотожно завдяки коваріантному закону збереження електричного заряду (рівняння неперервності):

```
∂_μ J^μ = 0               [коваріантне рівняння неперервності струму]
```

Таким чином, **калібрувальна інваріантність електромагнітної дії є прямо еквівалентною закону збереження електричного заряду**.

## Коваріантна похідна та квантова фазова симетрія U(1)

У квантовій механіці стану частинки відповідає комплексна хвильова функція `ψ(r, t)`. Глобальне перетворення фази на постійний кут `α`:

```
ψ → ψ' = e^{i α} ψ        [глобальне перетворення фази]
```

залишає густину ймовірності `|ψ'|² = |ψ|²` інваріантною. Якщо зробити кут фази залежним від координати й часу `α = (q / ℏ) λ(r, t)` (локальне калібрувальне перетворення U(1)):

```
ψ(r, t) → ψ'(r, t) = e^{i (q / ℏ) λ(r, t)} ψ(r, t)  [локальне перетворення U(1)]
```

то звичайна похідна `∂_μ ψ` втрачає коваріантність, оскільки з'являється градієнт фазової функції `λ`:

```
∂_μ ψ' = ∂_μ (e^{i (q / ℏ) λ} ψ)
= e^{i (q / ℏ) λ} ∂_μ ψ + i (q / ℏ) (∂_μ λ) e^{i (q / ℏ) λ} ψ  [диференціювання добутку]
= e^{i (q / ℏ) λ} [ ∂_μ + i (q / ℏ) (∂_μ λ) ] ψ              [винесення експоненти]
```

Член `i (q / ℏ) (∂_μ λ) ψ` порушує симетрію рівняння. Для відновлення коваріантності визначають коваріантну похідну `D_μ`:

```
D_μ = ∂_μ - i (q / ℏ) A_μ  [коваріантна похідна калібрувального поля]
```

При одночасному калібрувальному перетворенні хвильової функції та калібрувального поля `A_μ → A_μ + ∂_μ λ`:

```
(D_μ ψ)' = (∂_μ - i (q / ℏ) A'_μ) ψ'
= [ ∂_μ - i (q / ℏ) (A_μ + ∂_μ λ) ] (e^{i (q / ℏ) λ} ψ)
= e^{i (q / ℏ) λ} (∂_μ ψ) + i (q / ℏ) (∂_μ λ) e^{i (q / ℏ) λ} ψ - i (q / ℏ) A_μ e^{i (q / ℏ) λ} ψ - i (q / ℏ) (∂_μ λ) e^{i (q / ℏ) λ} ψ
= e^{i (q / ℏ) λ} [ ∂_μ - i (q / ℏ) A_μ ] ψ  [скорочення градієнтних членів]
= e^{i (q / ℏ) λ} (D_μ ψ)                     [чисте калібрувальне перетворення]
```

Таким чином, коваріантна похідна `D_μ ψ` трансформується так само чисто, як і сама хвильова функція. Крім того, комутатор двох коваріантних похідних прямо дає тензор електромагнітного поля:

```
[D_μ, D_ν] ψ = D_μ (D_ν ψ) - D_ν (D_μ ψ)
= -i (q / ℏ) F_{μν} ψ     [зв'язок комутатора з тензором поля]
```

Це доводить, що напруженість електромагнітного поля є геометрією викривлення (кривиною) у фазовому розшаруванні квантового стану.

## Диференціальні форми та геометрія розшарувань

У сучасній диференціальній геометрії електромагнітне поле описується мовою зовнішніх диференціальних форм на 4-вимірному многовиді простору-часу:

1. **4-потенціал** подається як 1-форма зв'язаності (connection 1-form): `A = A_μ dx^μ`.
2. **Тензор поля** подається як 2-форма кривини (curvature 2-form): `F = dA = (1/2) F_{μν} dx^μ ∧ dx^ν`, де `d` — оператор зовнішнього диференціювання.
3. **Калібрувальне перетворення** задається як `A' = A + dλ`.

Тоді інваріантність тензора поля випливає з фундаментальної нільпотентності оператора зовнішнього диференціювання `d² = 0`:

```
F' = dA' = d(A + dλ) = dA + d²λ = dA + 0 = F   [нільпотентність d² = 0]
```

Однорідні рівняння Максвелла (`∇ · B = 0` та `∇ × E + ∂B/∂t = 0`) зводяться до тотожності Тотожності Біанкі: `dF = d(dA) = d²A = 0`. Неоднорідні рівняння Максвелла записуються через сопряжений оператор Кодаїри — Годжа `*`: `d * F = μ₀ J`. Мова диференціальних форм робить калібрувальну інваріантність природною властивістю топологічної структури простору-часу.
