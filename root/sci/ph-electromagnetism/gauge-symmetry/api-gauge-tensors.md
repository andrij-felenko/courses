# 📋 Інтерфейс та контракт полів, потенціалів і калібрувальних умов

Цей довідник визначає математичні, тензорні та алгоритмічні контракти електромагнітних потенціалів `(φ, A)`, тензора напруженостей поля `F^{μν}`, операторів калібрувальних перетворень та специфікацій канонічної фіксації калібрування. Він слугує точним специфікатором специфікацій полів для обчислювальних систем електродинаміки, квантової механіки та чисельного моделювання електромагнітних явищ.

## 1. Контракт фундаментальних об'єктів полів

Електромагнітний стан системи описується двома рівнями абстракції: потенціальним (що містить калібрувальну свободу) та спостережувальним (що складається з канонічних фізичних величин).

| Символ | Фізична величина | Одиниця СІ | Математична структура | Вимога до інваріантності |
| :--- | :--- | :--- | :--- | :--- |
| `φ` | Скалярний потенціал | В (Вольт) | Скалярне поле `φ(r, t)` | Калібрувально-варіантний (`φ → φ - ∂λ/∂t`) |
| `A` | Векторний потенціал | В·с/м (або Тл·м) | Векторне поле `A(r, t)` | Калібрувально-варіантний (`A → A + ∇λ`) |
| `A^μ` | 4-векторний потенціал | В/c | 4-вектор `(φ/c, A)` | Коваріантно-варіантний (`A_μ → A_μ + ∂_μ λ`) |
| `E` | Напруженість електричного поля | В/м | Векторне поле `-∇φ - ∂A/∂t` | **Фізично інваріантний** |
| `B` | Магнітна індукція | Тл (Тесла) | Псевдовекторне поле `∇ × A` | **Фізично інваріантний** |
| `F^{μν}` | Тензор електромагнітного поля | В/(м·с) | Антисиметричний 4-тензор `2-го` рангу | **Лоренц- та калібрувально інваріантний** |

### 1.1. Тензор напруженостей `F^{μν}` у матричній формі

Тензор електромагнітного поля `F^{μν} = ∂^μ A^ν - ∂^ν A^μ` задається у часоподібній сигнатурі метрики `g_{μν} = diag(1, -1, -1, -1)` наступною антисиметричною матрицею `4 × 4`:

```
          ┌                                       ┐
          │    0      -Ex/c    -Ey/c    -Ez/c     │
          │   Ex/c      0       -Bz       By      │
F^{μν} =  │   Ey/c     Bz        0       -Bx      │
          │   Ez/c    -By       Bx        0       │
          └                                       ┘
```

Коваріантна форма тензора `F_{μν} = g_{μα} g_{νβ} F^{αβ}` отримується зміною знаків часово-просторових компонент `(E → -E)`:

```
          ┌                                       ┐
          │    0       Ex/c     Ey/c     Ez/c     │
          │  -Ex/c      0       -Bz       By      │
F_{μν} =  │  -Ey/c     Bz        0       -Bx      │
          │  -Ez/c    -By       Bx        0       │
          └                                       ┘
```

Дуальний тензор полів `*F^{μν} = (1/2) ε^{μναβ} F_{αβ}` описує однорідні рівняння Максвелла:

```
           ┌                                       ┐
           │    0       Bx       By       Bz       │
           │   -Bx      0       Ex/c     Ey/c      │
*F^{μν} =  │   -By    -Ex/c      0       Ez/c      │
           │   -Bz    -Ey/c    -Ez/c      0        │
           └                                       ┘
```

### 1.2. Скалярні інваріанти тензора поля

Електромагнітне поле задовольняє дві скалярні інваріантні величини, які не змінюються при будь-яких перетвореннях Лоренца та калібрувальних зсувах:

1. **Перший інваріант поля:** `I₁ = F_{μν} F^{μν} = 2 (B² - E²/c²)`. Якщо у деякій системі відліку магнітне поле переважає електричне `B² > E²/c²`, воно залишатиметься магнітоподібним у всіх інерціальних системах.
2. **Другий інваріант поля:** `I₂ = *F_{μν} F^{μν} = -4 (E · B)/c`. Якщо вектори `E` та `B` взаємно перпендикулярні (`E · B = 0`, як у плоскій електромагнітній хвилі), вони залишатимуться ортогональними в усіх системах відліку.

## 2. Специфікація режимів фіксації калібрування (Gauge Fixing Conditions)

Вибір умови калібрувальної фіксації визначається обчислювальною або фізичною задачею. Кожен режим має чіткий математичний контракт, переваги та граничні обмеження.

### 2.1. Режим Лоренца (Lorentz / Lorenz Gauge)

* **Математичний контракт:** `∂_μ A^μ = 0`  або  `∇ · A + (1/c²) ∂φ/∂t = 0`.
* **Тип симетрії:** Явно лоренц-інваріантний режим.
* **Рівняння для потенціалів:**
  ```
  □ φ = ρ / ε₀              [(1/c²) ∂²φ/∂t² - ∇²φ = ρ / ε₀]
  □ A = μ₀ J                [(1/c²) ∂²A/∂t² - ∇²A = μ₀ J]
  ```
* **Основна область застосування:** Релятивістська електродинаміка, теорія випромінювання хвилеводів, електромагнітна зліченність у просторі-часі Минковського.
* **Залишкова калібрувальна свобода:** Дозволяє калібрувальні трансформації з функцією `λ(x, t)`, яка задовольняє однорідне хвильове рівняння `□ λ = 0`.

### 2.2. Кулонівський (поперечний) режим (Coulomb / Transverse Gauge)

* **Математичний контракт:** `∇ · A = 0`.
* **Тип симетрії:** Розділяє просторові й часові компоненти; порушує явну лоренц-коваріантність.
* **Рівняння для потенціалів:**
  ```
  ∇² φ = -ρ / ε₀            [статичне рівняння Пуассона]
  □ A = μ₀ J_trans          [хвильове рівняння для поперечного струму]
  ```
* **Формула поперечного струму:** `J_trans = J - ε₀ ∇(∂φ/∂t)`.
* **Основна область застосування:** Квантова оптика, канонічне квантування фотонного поля, нерелятивістська квантова механіка (атоми у зовнішньому полі).
* **Залишкова калібрувальна свобода:** Дозволяє будь-яку функцію `λ(r)`, яка є гармонічною у просторі (`∇² λ = 0`).

### 2.3. Часовий / Вайлівський режим (Temporal / Weyl Gauge)

* **Математичний контракт:** `φ = 0`  (або `A₀ = 0`).
* **Рівняння для потенціалів:**
  ```
  E = -∂A/∂t                [електричне поле виражається лише через часову похідну A]
  (1/c²) ∂²A/∂t² + ∇ × (∇ × A) = μ₀ J
  ```
* **Основна область застосування:** Гамільтонів формалізми електродинаміки, ґратчаста калібрувальна теорія (Lattice Gauge Theory), чисельна гамільтонова динаміка.
* **Залишкова калібрувальна свобода:** Дозволяє будь-які часово-незалежні перетворення `λ(r)` (`∂λ/∂t = 0`).

### 2.4. Аксіальний / Просторовий режим (Axial / Spatial Gauge)

* **Математичний контракт:** `A_z = 0`  (або напрямний вектор `n · A = 0`).
* **Рівняння для потенціалів:** Знімає поздовжню компонентну вільностей уздовж обраної осі `z`.
* **Основна область застосування:** Квантова теорія калібрувальних полів високих енергій, аналіз поширення плоских хвиль у хвилеводах, струнні моделі.
* **Залишкова калібрувальна свобода:** Дозволяє функції `λ(x, y, t)`, які не залежать від координати `z` (`∂λ/∂z = 0`).

### 2.5. Режим Фока — Швінґера (Fock-Schwinger / Coordinate Gauge)

* **Математичний контракт:** `x^μ A_μ = 0`  або  `r · A = 0`.
* **Основна область застосування:** Пертурбативні розрахунки у квантовій хромодинаміці, розклад потенціалу за локальними напруженостями поля `A_μ(x) = ∫₀¹ α F_{νμ}(α x) x^ν dα`.

### 2.6. Режим випромінювання (Radiation Gauge)

* **Математичний контракт:** `φ = 0`  ТА  `∇ · A = 0`  (за відсутності вільних зарядів `ρ = 0`).
* **Основна область застосування:** Опис вільних електромагнітних хвиль у вакуумі без джерел. Векторний потенціал має точно 2 фізичні поля поляризації.

## 3. Контракт інтерфейсу оператора калібрувального перетворення

Алгоритмічна реалізація модулів калібрувальної трансформації повинна дотримуватися наступної специфікації входів, виходів та перевірок інваріантності.

```
+-------------------------------------------------------------------------+
|                  Специфікація Калібрувального Модуля                    |
+-------------------------------------------------------------------------+
|  Вхідні дані:                                                           |
|    - φ_in(r, t)    : Початковий скалярний потенціал                     |
|    - A_in(r, t)    : Початковий векторний потенціал                     |
|    - λ(r, t)       : Калібрувальна скалярна функція                      |
|                                                                         |
|  Перетворення:                                                          |
|    - φ_out(r, t) = φ_in(r, t) - ∂λ/∂t                                   |
|    - A_out(r, t) = A_in(r, t) + ∇λ                                      |
|                                                                         |
|  Пост-умови (Гарантії інваріантності):                                  |
|    - E_out = -∇φ_out - ∂A_out/∂t  ==  E_in   (з точністю до ε_mach)      |
|    - B_out = ∇ × A_out            ==  B_in   (з точністю до ε_mach)      |
+-------------------------------------------------------------------------+
```

### 3.1. Алгоритмічний контракт чисельного допуску інваріантності

Для будь-якої числової обчислювальної системи з плаваючою крапкою подвійної точності (`double`), норма різниці полів до і після перетворення повинна задовольняти критерій:

```
|| E_out - E_in ||_∞  <  C₁ · (Δx)⁻¹ · ε_mach · || λ ||
|| B_out - B_in ||_∞  <  C₂ · (Δx)⁻¹ · ε_mach · || λ ||
```

де `Δx` — крок просторової сітки, `ε_mach ≈ 10⁻¹⁶` — машинний нуль, `C₁, C₂` — безрозмірні коефіцієнти розростання сеансової похибки скінченних різниць (типово `C < 4.0`).

### 3.2. C/C++ Інтерфейс обчислювального контуру потенціалів

Нижче подано специфікацію структур даних та функціонального контракту бібліотечного модуля моделювання полів:

```cpp
#pragma once
#include <vector>
#include <cstddef>

enum class GaugeChoice {
    Lorentz,
    Coulomb,
    Temporal,
    Axial
};

struct FieldGridConfig {
    std::size_t nx, ny, nz;
    double dx, dy, dz;
    double dt;
    GaugeChoice gauge;
};

struct FieldValues {
    std::vector<double> phi;
    std::vector<double> Ax, Ay, Az;
    std::vector<double> Ex, Ey, Ez;
    std::vector<double> Bx, By, Bz;
};

class IGaugeSolver {
public:
    virtual ~IGaugeSolver() = default;
    virtual void set_sources(const std::vector<double>& rho,
                            const std::vector<double>& Jx,
                            const std::vector<double>& Jy,
                            const std::vector<double>& Jz) = 0;
    virtual void step_time() = 0;
    virtual void apply_gauge_fixing() = 0;
    virtual FieldValues get_fields() const = 0;
};
```

## 4. Порівняльна матриця специфікацій калібрувальних умов

Наведена таблиця резюмує ключові властивості кожного калібрувального режиму для інженерного вибору алгоритму симуляції.

| Режим калібрування | Математична умова | Лоренц-коваріантність | Тип рівняння для `φ` | Тип рівняння для `A` | Фізична інтерпретація |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Лоренца** | `∂_μ A^μ = 0` | **Так (явно)** | Хвильове (`□ φ = ρ/ε₀`) | Хвильове (`□ A = μ₀ J`) | Запізнювальні потенціали |
| **Кулонівське** | `∇ · A = 0` | Ні (прихована) | Пуассона (`∇² φ = -ρ/ε₀`) | Хвильове для `A_trans` | Миттєвий кулонівський потенціал |
| **Вайлівське** | `φ = 0` | Ні | Відсутнє (`φ = 0`) | Еволюційне 2-го порядку | Гамільтонові динамічні системи |
| **Аксіальне** | `A_z = 0` | Ні | Диференційне | Монотонне вздовж `z` | Теорія струн і хвилеводи |
| **Фока — Швінґера**| `x^μ A_μ = 0` | Ні | Інтегральне від `F` | Інтегральне від `F` | Квантова хромодинаміка |
| **Випромінювання**| `φ=0, ∇·A=0` | Ні | Відсутнє | Хвильове без джерел | Вільні фотони у вакуумі |

## 5. Граничні умови та топологічні обмеження

1. **Граничні умови для потенціалів.** При застосуванні умов калібрування на обмежених областях необхідно задавати граничні значення не лише для спостережуваних полів `E` та `B`, але й для функцій `λ`. Неузгоджена межа призводить до виникнення штучних поверхневих джерел на краях обчислювальної сітки.
2. **Топологічна неоднозв'язність (Ефект Ааронова — Бома).** У неоднозв'язаних просторових областях (наприклад, у просторі з вирізаним соленоїдом) калібрувальна функція `λ(r, t)` може бути багатозначною. Циркуляція векторного потенціалу по замкненому контуру `∮ A · dl = Φ` є топологічним інваріантом і не може бути обнулена жодним однозначним калібрувальним перетворенням.
3. **Магнітні монополі Дірака та струна Дірака.** За наявності гіпотетичного магнітного монополя `q_m` векторний потенціал `A` не може бути заданий гладко в усьому просторі без сингулярності (струни Дірака). Для опису поля монополя простір покривають двома картами, на яких потенціали `A_N` та `A_S` пов'язані калібрувальним перетворенням у зоні перекриття `A_N - A_S = ∇λ`. Квантування заряду `q e / (2π ℏ) ∈ Z` виникає з вимоги однозначності фазового фактора `exp(i q λ / ℏ)`.
4. **Неабелеве узагальнення (Неоднозначність Ґрибова).** При розширенні симетрії U(1) до неабелевих груп SU(N) (у хромодинаміці) умови калібрувальної фіксації (наприклад, кулонівська або Лоренцева) втрачають однозначність у області сильного поля — виникають копії Ґрибова (Gribov copies), які потребують додаткових обмежень на простір потенціалів (обмеження горизонтом Ґрибова).
