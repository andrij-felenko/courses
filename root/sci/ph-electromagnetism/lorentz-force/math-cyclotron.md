# 🧮 Математичний вивід циклотронного руху та траєкторії в полі

Розглянемо точний математичний опис руху зарядженої частинки з масою `m` та зарядом `q` у постійному однорідному магнітному полі з індукцією `B`. Головне диференціальне рівняння руху задається другим законом Ньютона під дією векторної сили Лоренца:

```
m · (dv / dt) = q · (v × B)
```

Для побудови розв'язку та знаходження точної просторової траєкторії частинки оберемо прямокутну декартову систему координат так, щоб магнітне поле було спрямоване строго вздовж осі `Z`:

```
B = (0, 0, B_z),   де B_z = B > 0
```

Швидкість частинки у будь-який момент часу описується трьома компонентами `v = (v_x, v_y, v_z)`. Обчислимо векторний добуток `v × B` за допомогою визначника матриці третього порядку:

```
v × B = |  i    j    k  |
        | v_x  v_y  v_z |
        |  0    0    B  |

v × B = i · (v_y · B) - j · (v_x · B) + k · 0 = (v_y · B,  -v_x · B,  0)
```

Підставивши виражений векторний добуток у вихідне рівняння руху `m · (dv/dt) = q · (v × B)`, отримуємо систему трьох зв'язаних звичайних диференціальних рівнянь першого порядку у проекціях на координатні осі:

```
m · (dv_x / dt) =  q · B · v_y       [1: прискорення вздовж осі X]
m · (dv_y / dt) = -q · B · v_x       [2: прискорення вздовж осі Y]
m · (dv_z / dt) =  0                 [3: прискорення вздовж осі Z]
```

### Аналіз поздовжнього та поперечного руху

З диференціального рівняння [3] негайно випливає, що прискорення вздовж магнітного поля відсутнє:

```
dv_z / dt = 0  ⇒  v_z(t) = v_z(0) = const
z(t) = z_0 + v_z · t
```

Це фундаментальний результат: магнітне поле не спричиняє жодної сили уздовж напрямку своїх силових ліній. Рух уздовж осі `Z` є рівномірним та прямолінійним з постійною швидкістю `v_z = v_∥`.

Для аналізу поперечного руху в площині `XY` розділимо рівняння [1] на масу `m` та продиференціюємо його по часу `t`:

```
d²v_x / dt² = (q · B / m) · (dv_y / dt)
```

Підставимо у вираз похідну `dv_y / dt` з рівняння [2]:

```
d²v_x / dt² = (q · B / m) · (-q · B / m · v_x) = -(q · B / m)² · v_x
```

Введемо позначення **циклотронної (або ларморівської) кутової частоти** `ω_c`:

```
ω_c = |q| · B / m
```

Отримане рівняння є класичним канонічним рівнянням незагасаючих гармонічних коливань:

```
d²v_x / dt² + ω_c² · v_x = 0
```

Загальний математичний розв'язок цього диференціального рівняння для компонентів швидкості при початкових умовах `v_x(0) = v_⊥`, `v_y(0) = 0` (де `v_⊥` — модуль поперечної швидкості) має вигляд:

```
v_x(t) =  v_⊥ · cos(ω_c · t)
v_y(t) = -v_⊥ · sin(ω_c · t)   (для позитивного заряду q > 0)
```

Проінтегрувавши компоненти швидкості `v_x = dx/dt` та `v_y = dy/dt` по часу `t`, отримуємо закони зміни координат частинки у площині `XY`:

```
x(t) = x_0 + (v_⊥ / ω_c) · sin(ω_c · t)
y(t) = y_0 + (v_⊥ / ω_c) · cos(ω_c · t)
```

Піднісши різниці координат до квадрата та додавши їх `(x - x_0)² + (y - y_0)²`, отримуємо рівняння кола з радіусом `r_c` (циклотронним або ларморівським радіусом):

```
(x - x_0)² + (y - y_0)² = (v_⊥ / ω_c)² = r_c²

r_c = m · v_⊥ / (|q| · B)
```

### Гамільтонова формалізована механіка зарядженої частинки

У вищій теоретичній механіці рух частинки у потенціальному електромагнітному полі описується функцією Лагранжа `L(r, v)` та функцією Гамільтона `H(r, p)` через скалярний потенціал `Φ` та векторний потенціал магнітного поля `A` (де `B = ∇ × A`, `E = -∇Φ - ∂A/∂t`):

```
L(r, v) = 1/2 · m · v² - q · Φ + q · (v · A)
```

Канонічно спряжений імпульс частинки `p` визначається як частинна похідна від функції Лагранжа по швидкості:

```
p_i = ∂L / ∂v_i = m · v_i + q · A_i
p = m · v + q · A
```

Зверніть увагу: канонічний імпульс `p` складається з механічного імпульсу частинки `m · v` та полевого потенціального імпульсу `q · A`.

Застосувавши перетворення Лежандра, виведемо функцію Гамільтона (повну енергію системи):

```
H(r, p) = p · v - L = 1 / (2 · m) · (p - q · A)² + q · Φ
```

Гамільтонові рівняння руху `dp/dt = -∂H/∂r`, `dr/dt = ∂H/∂p` після розгортання операторів ротора та градієнта приводять строго до рівняння сили Лоренца `m · a = q · (E + v × B)`. Це доводить, що сила Лоренца повністю узгоджується з варіаційними принципами найменшої дії Гамільтона-Остроградського.

### Адіабатичний інваріант та ведучий центр

У слабконооднорідних магнітних полях (коли характерний розмір зміни індукції значно більший за циклотронний радіус `|∇B / B| << 1 / r_c`) рух частинки зручно розділити на дві складові:
1. Швидке циклотронне обертання навколо умовної точки — **ведучого центра**.
2. Повільний дрейф самого ведучого центра у просторі.

Введемо координату ведучого центра `R`:

```
R = r - (m / (q · B²)) · (v × B)
```

Інтеграл дії за один повний період циклотронного обертання називається **першим адіабатичним інваріантом `I`**:

```
I = ∮ p_⊥ · dq_⊥ = 2π · m · (m · v_⊥² / (2 · q · B)) = (2π · m² / q) · μ
```

оскільки маса `m` та заряд `q` є константами, незмінним залишається магнітний момент циклотронного витка `μ`:

```
μ = m · v_⊥² / (2 · B) = const
```

Теорема про збереження магнітного моменту `μ` пояснює утримання плазми в магнітних пастках: при русі у бік сильного поля `B` поперечна кінетична енергія `m v_⊥² / 2` зростає пропорційно `B`, що призводить до зменшення поздовжньої енергії та відбиття частинки від магнітного дзеркала.

### Строге доведення збереження кінетичної енергії

Доведемо за допомогою векторного аналізу, що магнітна сила Лоренца зберігає значення модуля швидкості `|v|` та кінетичної енергії частинки `E_k = m · v² / 2`.

Обчислимо часову похідну кінетичної енергії, скориставшись правилом диференціювання скалярного добутку векторів:

```
dE_k / dt = d/dt (1/2 · m · (v · v))
          = m · v · (dv / dt)
          = v · F_магн
          = v · (q · (v × B))
          = q · (v · (v × B))
```

Згідно з властивостями змішаного (скалярно-векторного) добутку трьох векторів, вектор `v × B` за означенням є строго перпендикулярним до вектора `v`. Скалярний добуток двох взаємно перпендикулярних векторів тотожно дорівнює нулю:

```
v · (v × B) = 0   ⇒   dE_k / dt = 0   ⇒   E_k = const
```

Таким чином, математично доведено: магнітна частина сили Лоренца виконує нульову роботу (`dW = 0`), змінюючи виключно напрямок вектора швидкості `v`, але залишаючи її модуль `|v|` повністю незмінним.

### Геометричні параметри спірального руху

Якщо частинка має як поперечну компоненту швидкості `v_⊥ = v · sinθ`, так і поздовжню `v_∥ = v · cosθ` (де `θ` — кут між вектором швидкості `v` та вектором магнітного поля `B`), то траєкторією руху у просторі є **гвинтова лінія (спіраль)**.

Основними математичними параметрами цієї спіралі є:

1. **Період циклотронного обертання `T`:**
   ```
   T = 2π / ω_c = 2π · m / (|q| · B)
   ```
   Важливий математичний висновок: період `T` взагалі не залежить від швидкості частинки `v` та радіуса орбіти `r_c`. Частинки з різними швидкостями проходять кола різного діаметра за один і той самий час.

2. **Крок спіралі (крок гвинта `h`):**
   Відстань, яку частинка долає вздовж силової лінії магнітного поля за один повний оборот:
   ```
   h = v_∥ · T = (v · cosθ) · (2π · m / (|q| · B)) = 2π · m · v · cosθ / (|q| · B)
   ```

### Релятивістські корекції та розсинхронізація у прискорювачах

При високих кінетичних енергіях, коли швидкість частинки `v` стає порівнянною зі швидкістю світла `c`, необхідно враховувати релятивістське зростання маси частинки через лоренц-фактор `γ`:

```
γ = 1 / √(1 - v² / c²)
m_релят = γ · m_0
```

Рівняння руху частинки у релятивістській формі `dp/dt = q · (v × B)` (де `p = γ · m_0 · v` — релятивістський імпульс) приводять до наступних модифікованих виразів для радіуса та частоти:

```
r_релят = γ · m_0 · v_⊥ / (|q| · B)
ω_релят = |q| · B / (γ · m_0) = ω_c / γ
```

У міру розгону частинки її лоренц-фактор `γ` зростає, через що релятивістська циклотронна частота `ω_релят` монотонно зменшується. Це призводить до розсинхронізації частинки з прискорювальною частотою у класичному циклотроні при енергіях понад ~20 МеВ. Для компенсації релятивістського ефекту розробляють **фазотрони** (де знижують частоту прискорювача `f(t)` в процесі розгону) та **синхрофазотрони** (де одночасно нарощують магнітне поле `B(t)` у часі).
