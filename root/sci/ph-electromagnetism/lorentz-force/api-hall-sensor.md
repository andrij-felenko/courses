# 📋 Специфікація та інтерфейс давача Холла

Давач Холла — це напівпровідниковий мікроелектронний прилад, який перетворює поперечну силу Лоренца, що діє на рухомі носії заряду у напівпровідниковій пластині, у пропорційну електричну напругу. У сучасній електронній інженерії, робототехніці, автомобільній промисловості та промисловій автоматиці застосовують два основні класи давачів Холла:

1. **Аналогові лінійні давачі (наприклад, SS49E / AH3503 / A1302 / DRV5055):** вихідна напруга лінійно пропорційна магнітній індукції `B` та змінюється відносно опорного рівня спокою (зазвичай `VCC / 2`).
2. **Цифрові ключі (наприклад, A3144 / US1881 / AH180 / DRV5013):** містять внутрішній тригер Шмітта та вихід з відкритим колектором, що переключає цифровий логічний рівень (HIGH/LOW) при досягненні порогового значення індукції.

### Внутрішня мікроелектронна структура сенсора

Напівпровідниковий кристал сенсора Холла виготовляють із матеріалів з високою рухливістю носіїв заряду (арсенід галію GaAs, антимонід індію InSb або високочистий кремній Si). Інтегральна мікросхема аналогового сенсора містить декілька послідовних функціональних блоків:

```
 ┌──────────┐    ┌─────────────┐    ┌─────────────────┐    ┌─────────────┐    ┌─────────┐
 │ Напівпров.│───►│ Диференційний│───►│ Температурна    │───►│ Чоппер-     │───►│ Вихідний│───► OUT
 │ елемент  │    │ підсилювач  │    │ компенсація     │    │ стабілізація│    │ буфер   │
 └──────────┘    └─────────────┘    └─────────────────┘    └─────────────┘    └─────────┘
```

1. **Первинний перетворювач Холла:** тонкий прямокутний шар напівпровідника з чотирма контактами (два для подачі струму живлення `I_bias`, два для знімання сигналу `V_H`).
2. **Низькошумний диференційний підсилювач:** підсилює мікровольтний первинний сигнал Холла до рівня одиниць вольта.
3. **Схема чоппер-стабілізації (Chopper Stabilization):** динамічно перемикає конфігурацію виводів елемента Холла із частотою сотні кілогерц, що дозволяє повністю усунути власний зміщення нуля (Offset) та низькочастотний флікер-шум (1/f шум).
4. **Блок температурної компенсації:** корегує чутливість підсилювача відповідно до температурного коефіцієнта напівпровідника.

### Електричні параметри та розпіновка (SS49E)

Аналоговий давач SS49E виготовляється у компактному термостійкому пластиковому корпусі TO-92S і має 3 стандартні металеві виводи для монтажу на друковану плату.

```
       ┌──────────┐
       │  SS49E   │  (Лицьова сторона з маркуванням)
       └──────────┘
        │    │    │
        1    2    3
        │    │    │
       VCC  GND  OUT
```

| Вивід | Назва | Тип | Опис та електричні характеристики |
|---|---|---|---|
| **1** | **VCC** | Живлення | Напруга живлення: **3.0 В – 6.5 В** (типово 5.0 В або 3.3 В) |
| **2** | **GND** | Земля | Спільний мінусовий дріт схеми (0 В) |
| **3** | **OUT** | Аналоговий вихід | Вихідна напруга пропорційна магнітному полю **B** |

### Таблиця специфічних характеристик (при VCC = 5.0 В, T = 25 °C)

| Параметр | Символ | Типове значення | Одиниці | Примітка / Умова |
|---|---|---|---|---|
| **Струм споживання** | `I_cc` | 4.2 – 6.0 | мА | Без навантаження на виході |
| **Напруга спокою** | `V_q` | 2.50 ± 0.10 | В | При B = 0 Тл (без зовнішнього поля) |
| **Чутливість** | `K_sens` | 1.40 ± 0.08 | мВ / Гаус | **14.0 мВ / мТл** (1 мТл = 10 Гаусів) |
| **Діапазон вимірювання** | `B_range` | -100 … +100 | мТл | -1000 … +1000 Гаусів |
| **Час відгуку** | `t_res` | 3.0 | мкс | Смуга пропускання ~20 кГц |
| **Вихідний опір** | `R_out` | 50 | Ом | Максимальний струм навантаження 1.5 мА |

### Математична модель вихідного сигналу та стала Холла

Вихідна напруга аналогового давача Холла `V_out` описується пропорційною лінійною формулою:

```
V_out = V_q + K_sens · B

B = (V_out - V_q) / K_sens
```

де:
- `V_out` — виміряна напруга на виході (В);
- `V_q` — напруга спокою при відсутності магнітного поля (В);
- `K_sens` — коефіцієнт чутливості давача (В / Тл);
- `B` — індукція магнітного поля (Тл). Північний полюс магніту (N), наближений до лицьового боку, збільшує напругу `V_out > V_q`, а південний (S) — зменшує `V_out < V_q`.

Мікроскопічний зв'язок напруги Холла з параметрами напівпровідника виражається через **сталу Холла `R_H`**:

```
V_H = R_H · (I · B / d)

R_H = 1 / (n · q)
```

де `n` — концентрація носіїв заряду (електронів або дірок), `q` — заряд носія, `d` — товщина активного напівпровідникового шару. Чим менша концентрація носіїв `n` та менша товщина `d`, тим вища чутливість давача Холла. Саме тому давачі Холла виготовляють із напівпровідників, а не з металів (де концентрація електронів `n` колосальна, а вихідна напруга `V_H` становить лиш частки мікровольта).

### Цифрові 3D-магнітометри на ефекті Холла (I2C/SPI)

У сучасній електроніці (смартфонах, польотних контролерах дронів, систем орієнтації) використовують тривісні цифрові магнітометри (наприклад, MLX90393 або TMAG5170), які об'єднують на одному кристалі три взаємно перпендикулярні елементи Холла та 16-бітний АЦП.

Огляд основних інтерфейсних регістрів цифрового магнітометра MLX90393 (I2C адреса `0x0C`):

| Адреса / Команда | Назва регістра | Тип | Опис та призначення |
|---|---|---|---|
| `0x60` | `SB` (Start Burst) | Команда | Запуск безперервного вимірювання по осях X, Y, Z |
| `0x4E` | `RM` (Read Measurement) | Команда | Зчитування 16-бітних даних вимірювання X, Y, Z |
| `REG_0` | `GAIN_SEL` | R/W | Налаштування коефіцієнта підсилення (Gain 0.2x … 5x) |
| `REG_1` | `HALLCONF` | R/W | Конфігурація чоппера та смуги фільтрації (0 … 7) |
| `REG_2` | `OFF_X / OFF_Y` | R/W | Регістри цифрового зміщення нуля для осей X та Y |

### Схема підключення та схемотехнічні вимоги

Для стабільної роботи давача SS49E між виводами VCC та GND у безпосередній близькості до корпусу (не далі 1 см) необхідно встановити керамічний блокирувальний конденсатор ємністю 0.1 мкФ (100 нФ). Це усуває високочастотні наводки з лінії живлення. Вихід OUT підключається безпосередньо до аналогового входу (АЦП) мікроконтролера. Якщо довжина з'єднувального кабелю перевищує 30 см, рекомендується додати послідовний резистор 100 Ом та фільтруючий конденсатор 1 нФ біля входу АЦП.

```
  VCC (+5V) ───────┬─────────────────────────── (1) VCC  [SS49E]
                   │
                 ═══ 100nF
                   │
  GND (0V)  ───────┴─────────────────────────── (2) GND  [SS49E]

  MCU ADC   ───────[ 100 Ohm ]─────┬─────────── (3) OUT  [SS49E]
                                   │
                                 ═══ 1nF
                                   │
                                  GND
```

### Покрокова діагностика несправностей при розробці

При налагодженні схем із давачами Холла рекомендується дотримуватися наступного діагностичного чек-листа:
1. **Перевірка напруги живлення VCC:** Виміряйте мультиметром напругу безпосередньо між виводами 1 та 2. Якщо `VCC` падає нижче 2.9 В, внутрішній підсилювач входить у нелінійний режим і вихід `OUT` спотворюється.
2. **Перевірка нуля `V_q`:** У відсутності поблизу постійних магнітів та феромагнетиків напруга на `OUT` має складати строго `2.50 ± 0.10 В` (для 5В живлення). Відхилення понад 0.2 В свідчить про наявність сильних зовнішніх магнітних наводок від силових трансформаторів або про пошкодження кристала статичною електрикою.
3. **Реакція на полюси:** При наближенні північного полюса магніту напруга на `OUT` повинна плавно зростати до `4.5–4.8 В`, а при наближенні південного полюса — плавно знижуватися до `0.2–0.5 В`. Якщо вихід залишається нерухомим, перевірте цілісність пайкі та відсутність короткого замикання на друкованій платі.

### Практичні інженерні застереження та типові пастки

1. **Температурний дрейф напруги спокою:** Напівпровідниковий елемент Холла дуже чутливий до температури навколишнього середовища. При нагріванні корпуса на 30 °C напруга спокою `V_q` може зміщуватися на 10–20 мВ, що створює хибну похибку вимірювання індукції до 1.5 мТл. У прецизійних приладах застосовують автоматичну температурну компенсацію за допомогою додаткового давача температури NTC або TMP36.
2. **Фонове магнітне поле Землі:** Геомагнітне поле Землі має індукцію порядку 0.03–0.06 мТл (0.3–0.6 Гауса). Хоч це нижче за поріг чутливості SS49E, при роботі з високочутливими цифровими магнітометрами (наприклад, QMC5883L / LSM303) поле Землі необхідно віднімати векторно під час програмного підрахунку.
3. **Насичення та нелінійність при сильних полях:** При полях понад 100 мТл вихідна характеристика SS49E входить у нелінійне насичення (вихідна напруга впирається у вихідні каскади біля 0.2 В та `VCC - 0.2 В`). Для вимірювання сильних полів неодимових магнітів слід збільшувати повітряний зазор або використовувати розширювальні магнітні дільники.
4. **Електростатичний захист (ESD):** Внутрішній напівпровідниковий кристал сенсора чутливий до статичної електрики. При монтажі на друковану плату слід використовувати захисні TVS-діоди на лінії OUT та VCC.
