# ⚙️ Обчислення поля магнітного диполя та траєкторії в неоднорідному полі

Обчислення магнітного поля диполя та моделювання руху магнітного моменту в неоднорідному полі — фундаментальна задача для чисельного розрахунку електронно-оптичних систем, магнітометрів, траєкторій атомарних пучків у досліді Штерна — Герлаха, магнітних пасток та систем магнітної левітації.

Моделювання такої взаємодії вимагає розв'язання двох пов'язаних задач: обчислення точного векторного поля `B(r)` від вихідного диполя та обчислення сили Ампера чи градієнтної сили, що діє на інший магнітний диполь, який рухається у просторі.

---

### Алгоритмічна модель та фізичні принципи

Обчислювальний алгоритм базується на послідовному виконанні трьох математичних блоків:

1. **Обчислення вектора індукції диполя у довільній точці:**
   За відомими координатами точки спостереження `r = (x, y, z)` відносно магнітного диполя `μ` обчислюється відстань `|r|` та одиничний вектор `r̂ = r / |r|`. Вектор індукції магнітного поля визначається за формулою:
   ```
   B(r) = (μ₀ / 4π r³) · [ 3 · (μ · r̂) · r̂ − μ ]
   ```
   Ця формула є точною для будь-якої точки простору поза самим диполем (`r > 0`).

2. **Обчислення сили у неоднорідному магнітному полі:**
   На диполь `μ` у зовнішньому полі `B[ext]` діє сила `F = ∇ (μ · B[ext])`. Для випадку, коли магнітний момент орієнтований вздовж осі `Z` (`μ = (0, 0, μ_z)`), а поле має градієнт `dB_z / dz = G`, вертикальна компонента сили дорівнює:
   ```
   F_z = μ_z · G
   ```
   Якщо сила додатна (`μ_z` та `G` одного знака), частинка прискорюється в напрямку зростання поля; якщо від'ємна — виштовхується в область слабкого поля.

3. **Чисельне інтегрування рівнянь руху:**
   Рівняння руху Ньютона `m · (d²z / dt²) = F_z` інтегрується за часом з кроком `dt`. Для забезпечення надійної математичної стійкості чисельної схеми без накопичення штучної енергії використовується метод Ейлера — Кромера (симплектичний інтегратор першого порядку):
   ```
   v_z(t + dt) = v_z(t) + (F_z / m) · dt
   z(t + dt)   = z(t) + v_z(t + dt) · dt
   ```
   У цій схемі нове значення координати `z` обчислюється вже за оновленою швидкістю `v_z(t + dt)`, що гарантує збереження фазового об'єму системи.

### Сфери застосування та практичне значення

Розрахунок траєкторій частинок у градієнтних полях є основою для проектування високоточних експериментальних установок:
- **Магнітна сепарація атомів та ізотопів:** розщеплення пучків нейтральних атомів за проекцією спіну у приладах Штерна — Герлаха та магнітних спектрометрах.
- **Магнето-оптичні пастки (MOT):** утримання нейтральних охолоджених атомів за допомогою комбінації лазерного випромінювання та градієнтного магнітного поля квадрупольних котушок.
- **Моделювання взаємодії неодимових магнітів:** розрахунок сил притягання та відштовхування у постійних магнітних підшипниках і сенсорах положення.

Точність обчислень у таких системах критично залежить від відсутності накопичення чисельної похибки на великій кількості кроків інтегрування. Для моделювання реальних вимірювальних систем програмісту необхідно контролювати діапазон плаваючої коми, оскільки значення фундаментальних моментів на кшталт магнетона Бора мають порядок `10⁻²⁴`, а маси атомів — порядок `10⁻²⁵` кг. Втрата точності розрядів або неправильний вибір типу даних легко призводить до повного спотворення результатів симуляції.

При моделюванні траєкторій у 3D-просторі з урахуванням довільних напрямків вектора магнітного моменту та градієнта поля формула результуючої сили узагальнюється до масивного градієнтного тензора. Обчислювальна складність такого розрахунку для системи з `N` взаємодіючих дипольних частинок зростає як `O(N²)`.

### Особливості вибору чисельних методів та контролю точності

При моделюванні фізичних систем із магнітними моментами виникає низка специфічних чисельних проблем, які необхідно враховувати під час розробки програмного забезпечення:

1. **Сингулярність у близькій зоні:**
   При підходженні точки спостереження до центу диполя (`r → 0`) індукція поля зростає пропорційно `1 / r³`. У чисельних розрахунках це призводить до виникнення ділення на нуль або швидкого переповнення розрядної сітки (`overflow`). Для запобігання цього в алгоритмі застосовується радіус сгладжування (*softening radius*) `ε`, при якому відстань замінюється на `√(r² + ε²)`.

2. **Порівняння схем інтегрування (Ейлер проти Рунґе — Кутти):**
   Явний метод Ейлера першого порядку є нестійким для крутильних коливань диполя і призводить до несправжнього експоненціального зростання амплітуди. Метод Ейлера — Кромера розв'язує цю проблему завдяки симплектичності, а для високоточного обчислення криволінійних траєкторій рекомендується застосовувати метод Рунґе — Кутти 4-го порядку (RK4).

3. **Обчислення потенціальної енергії диполь-дипольної системи:**
   Енергія взаємодії двох диполів `μ₁` та `μ₂` на відстані `R` обчислюється через скалярні добутки:
   `U₁₂ = (μ₀ / 4π R³) · [ (μ₁ · μ₂) − 3 (μ₁ · R̂)(μ₂ · R̂) ]`. Контроль сумарної енергії системи на кожному кроці інтегрування є головним критерієм коректності роботи симулятора.

4. **Оптимізація обчислення векторних добутків у C та C++:**
   Використання інлайн-функцій та векторних SIMD-інструкцій (AVX-512) дає змогу розпаралелити розрахунок сил для великих масивів частинок. Застосування `std::span` та вирівняних за пам'яттю структур даних у мові C++ гарантує відсутність накладних витрат при викликах математичних функцій у обчислювальних циклах високої інтенсивності.

### Особливості чисельної реалізації
- **Захист від сингулярності:** При `r → 0` поле диполя прямує до нескінченності (`1/r³`). У коді реалізовано перевірку на `r_len < 1e-12` м для запобігання діленню на нуль або отриманню `NaN` у розрахунках.
- **Вибір інтегратора:** Метод Ейлера — Кромера обрано за його фазову стійкість під час тривалого обчислення колових та просторових траєкторій у центральних та градієнтних полях.
- **Одиниці вимірювання:** Усі обчислення виконуються строго в міжнародній системі одиниць СІ (метри, кілограми, секунди, тесли, ампер-квадратні метри).
