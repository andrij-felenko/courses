### 1. Модель геомагнітного поля WMM (World Magnetic Model)

Світова магнітна модель (**WMM**) розробляється й оновлюється спільними зусиллями Національного управління океанічних і атмосферних досліджень США (NOAA) та Британської геологічної служби (BGS) кожні 5 років (поточна актуальна версія — WMM2025 на епоху 2025.0–2030.0). Вона розраховує повний тривимірний вектор індукції поля Землі у будь-якій точці планети за допомогою розкладу сферичних гармонік Гаусса до ступеня `N = 12`.

Модель спирається на розклад скалярного магнітного потенціалу `V`:

```
V(r, θ, φ) = a · ∑ (a/r)ⁿ⁺¹ · ∑ [gₙᵐ · cos(mφ) + hₙᵐ · sin(mφ)] · Pₙᵐ(cos θ)
```

де `gₙᵐ` та `hₙᵐ` — коефіцієнти Гаусса, `Pₙᵐ` — асоційовані поліноми Лежандра, `r, θ, φ` — сферичні геоцентричні координати.

Математично перетворення з геодезичної системи WGS-84 у сферичні геоцентричні координати виконується за допомогою еліпсоїда обертання з урахуванням стиснення Землі `f = 1/298.257223563` та екваторіального радіуса `a = 6378.137 км`. Для кожної точки простору обчислюють геоцентричний радіус `r` та геоцентричну кошироту `θ'`.

Обрізання розкладу сферичних гармонік саме на ступені `N = 12` (що відповідає 168 коефіцієнтам Гаусса) має строге фізичне обґрунтування. Гармоніки нижчих ступенів (`N = 1..12`) описують великомасштабне геомагнітне поле, породжене конвективним геодинамо в рідкому залізному ядрі Землі. Вищі гармоніки (`N > 12`) описують дрібномасштабні локальні аномалії намагніченості земної кори, які не піддаються глобальному часовому моделюванню і вимагають локальної аеромагнітної зйомки.

Кожен коефіцієнт Гаусса екстраполюється на поточну дату `t` через коефіцієнти секулярної варіації `ġₙᵐ` та `ḣₙᵐ`:

```
gₙᵐ(t) = gₙᵐ(t₀) + (t - t₀) · ġₙᵐ
hₙᵐ(t) = hₙᵐ(t₀) + (t - t₀) · ḣₙᵐ
```

Точність моделі WMM виміряна на рівні **±0.38°** для кута магнітного нахилу `I`, **±0.33°** для кута магнітного схилення `D` та **±135 нТл** для модуля повної індукції `B`. Похибка моделі повільно зростає наприкінці 5-річного циклу епохи через нелінійність секулярного дрейфу геодинамо, що вимагає перевидання моделі кожні 5 років.

Аналіз крайових випадків моделі показує, що поблизу магнітних полюсів (де горизонтальна складова `H < 2000 нТл`) похибка визначення схилення `D` стрімко зростає через ділення на малу горизонтальну компоненту у формулі `D = arctan2(Y, X)`. Втім, кут магнітного нахилу `I` у полярних регіонах обчислюється з високою стабільністю, оскільки вертикальна складова `Z` сягає максимальних значень (~55 000–60 000 нТл).

Структура підсистеми WMM складається з трьох ключових компонентів: завантажувача коефіцієнтів моделей з файлу `WMM.COF`, блоку геодезичних перетворень координат WGS-84 у геоцентричну систему та обчислювального ядра сферичних гармонік. Для забезпечення високої швидкодії на вбудованих системах (MCU) обчислення поліномів Лежандра виконують за допомогою рекурентних співвідношень, що дозволяє розраховувати тривимірний вектор індукції менш ніж за 1 мілісекунду на мікроконтролері з частотою 100 МГц.

У сучасних автопілотах (наприклад, PX4 або ArduPilot) підсистема WMM викликається автоматично після отримання першої надійної 3D-фіксації координат від GPS/GNSS модуля. Отримані значення магнітного схилення `D` та очікуваного модуля `F` передаються в розширений фільтр Калмана (EKF) як еталонні граничні умови для перевірки цілісності вимірювань 3-осьового магнітометра.

У полярних широтах (де широта `|φ| > 84°`) стандартне магнітне схилення `D` втрачає практичний сенс через швидку збіжність меридіанів у точку. Тому модель WMM розраховує додаткову величину — **грідовий азимут** (`GV`, *Grid Variation* або *Gnav*), який визначає кут між вектором горизонтальної складової поля та сіткою полярної стереографічної карти.

### 2. Структура параметрів калібрування магнітометра

Перед використанням сирих вимірювань `[B_raw.x, B_raw.y, B_raw.z]` для обчислення кута нахилу та азимута застосовують повну матричну компенсацію завад твердого заліза (*Hard-Iron*) та м'якого заліза (*Soft-Iron*). 

Математичний алгоритм калібрування описується перетворенням:

```
B_calibrated = S_soft_iron · (B_raw - V_hard_iron)
```

де `V_hard_iron` — вектор зсуву 3x1, який прибирає постійне магнітне поле плати, а `S_soft_iron` — симетрична матриця масштабування й повороту 3x3, яка перетворює деформований тривісний еліпсоїд вимірювань у сферу з радіусом `expected_total_field_uT`.

Обчислення коефіцієнтів калібрування здійснюють методом найменших квадратів (*Least Squares Ellipsoid Fitting*) на основі збору масиву вимірювань при обертанні пристрою в усіх трьох площинах (відома процедура «помахати вісімкою»). Прошивка порівнює виміряний кут нахилу `I_meas` із даними WMM `expected_inclination_deg` для оцінки якості калібрування. 

Якщо обчислений модуль індукції відхиляється від очікуваного `expected_total_field_uT` більш ніж на 10%, або кут нахилу `I_meas` відхиляється від `expected_inclination_deg` більш ніж на 5°, прошивка генерує попередження про наявність сильних зовнішніх металевих мас чи електромагнітних завад поблизу давача.
