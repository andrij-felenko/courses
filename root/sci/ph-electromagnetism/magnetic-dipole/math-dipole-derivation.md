# 🧮 Математичний вивод поля магнітного диполя та контактного дельта-члена

Цей математичний екскурс містить строгий векторний і тензорний вивод векторного потенціалу, індукції магнітного поля диполя у довільній точці простору, а також детальний інтегральний вивід сингулярного дельта-функціонального члена Фермі, який виникає у точці розташування точкового струмового диполя.

Строгий математичний опис поля магнітного диполя є фундаментальним для всієї класичної та квантової електродинаміки. Оскільки магнітні монополі в природі відсутні, магнітний дипольний доданок є найнижчим ненульовим членом у мультипольному розкладі векторного потенціалу для довільної локалізованої системи стаціонарних струмів.

---

### 1. Фізична постановка та мультипольний розклад векторного потенціалу

Розглянемо локалізований розподіл стаціонарних електричних струмів із векторною густиною `j(r')`, зосереджений усередині скінченного об'єму `V'` поблизу початку координат. Точка спостереження поля задається радіус-вектором `r`, причому відстань від початку координат `r = |r|` значно перевищує характерні розміри області джерел `r' = |r'|` (тобто розглядається далека зона `r >> r'`).

У точці спостереження `r` магнітний векторний потенціал `A(r)` визначається як об'ємний інтеграл від густини струму:

```
A(r) = (μ₀ / 4π) · ∫ [ j(r') / |r - r'| ] d³r'
```

де `μ₀` — магнітна стала, а інтегрування виконується за штрихованими координатами `r'` по всьому об'єму `V'`.

Щоб обчислити цей інтеграл у дальній зоні, розкладемо скалярний дріб `1 / |r - r'|` у тривимірний ряд Тейлора за малим параметром `(r' / r)`. Використовуючи формулу для відстані між двома точками у сферичній системі координат:

```
1 / |r - r'| 
= 1 / √(r² - 2 r · r' + r'²)
= (1 / r) · [ 1 - (2 r · r' / r²) + (r'² / r²) ]^(-1/2)
```

Застосовуючи біноміальний розклад Ньютона `(1 + x)^(-1/2) = 1 - 1/2 x + 3/8 x² - ...` для параметра `x = - (2 r · r' / r²) + (r'² / r²)`, збираємо члени за степенями `1/r`:

```
1 / |r - r'|
= (1 / r) + (r · r') / r³ + [ 3 (r · r')² - r² r'² ] / (2 r⁵) + O(r'³ / r⁴)
```

У виразі для відстані перший доданок `1/r` відповідає монопольному наближенню, другий `(r · r') / r³` — дипольному наближенню, а третій доданок порядку `1/r³` — квадрупольному наближенню.

Підставляючи отриманий розклад у вихідний об'ємний інтеграл для векторного потенціалу `A(r)`, розбиваємо його на суму окремих доданків різного порядку малості:

```
A(r) 
= (μ₀ / 4π r) · ∫ j(r') d³r' 
+ (μ₀ / 4π r³) · ∫ j(r') (r · r') d³r' 
+ (μ₀ / 8π r⁵) · ∫ j(r') [ 3 (r · r')² - r² r'² ] d³r' + ...
```

Проаналізуємо фізичний зміст та математичні властивості кожного з отриманих доданків.

### 2. Строгий доказовий розбір монопольного та дипольного членів

#### Доказ обнулення монопольного члена (`l = 0`)

Перший інтеграл `∫ j(r') d³r'` описує потенціал магнітного монополя. Доведем, що для будь-якої стаціонарної системи струмів цей інтеграл тотожно дорівнює нулю.

Розглянемо дивергенцію від добутку скалярної координати `x_i'` на вектор густини струму `j(r')`:

```
∇' · (x_i' j) 
= x_i' (∇' · j) + j · (∇' x_i')
= x_i' (∇' · j) + j_i                  [оскільки ∇' x_i' = e_i]
```

Для будь-якої локалізованої стаціонарної системи струмів виконується рівняння неперервності та відсутнє накопичення заряду: `∇' · j(r') = 0`. Отже, `j_i = ∇' · (x_i' j)`.

Інтегруючи цей вираз по всьому об'єму джерел `V'` та застосовуючи теорему Ґаусса про дивергенцію:

```
∫_V' j_i(r') d³r' 
= ∫_V' ∇' · (x_i' j) d³r'                   [підстановка тотожності j_i = ∇' · (x_i' j)]
= ∮_S' (x_i' j) · dS'                      [за теоремою Ґаусса про дивергенцію]
= 0                                         [струм не перетинає межу поверхні S']
```

Оскільки електричний струм локалізований усередині об'єму `V'` і не перетинає замкнену зовнішню поверхню `S'`, вектор `j` на поверхні `S'` дорівнює нулю (`j|S' = 0`). Отже, поверхневий інтеграл строго дорівнює нулю:

```
A_mono(r) = 0
```

Це є суворим математичним доказом того, що для будь-якого локалізованого розподілу стаціонарних струмів монопольний векторний потенціал тотожно дорівнює нулю, що відображає відсутність точкових магнітних зарядів у природі (`∇ · B = 0`).

---

#### Перетворення дипольного члена та введення магнітного моменту (`l = 1`)

Другий інтеграл розкладу є найнижчим ненульовим членом:

```
A_dip(r) = (μ₀ / 4π r³) · ∫ j(r') (r · r') d³r'
```

Розглянемо `i`-ту декартову компоненту цього інтегрального вектора. Скориставшись тензорним позначенням Ейнштейна з повторюваними індексами:

```
[ A_dip(r) ]_i = (μ₀ / 4π r³) · ∑_k r_k ∫ j_i(r') x_k' d³r'
```

Для розкладу інтеграла `∫ j_i x_k' d³r'` розіб'ємо підінтегральний добуток `j_i x_k'` на симетричну та антисиметричну частини відносно перестановки індексів `i` та `k`:

```
j_i x_k' = 1/2 (j_i x_k' + j_k x_i') + 1/2 (j_i x_k' - j_k x_i')
```

Доведемо, що інтеграл від симетричної частини `∫ (j_i x_k' + j_k x_i') d³r'` строго дорівнює нулю. Для цього розглянемо дивергенцію тензорного добутку:

```
∇' · (x_i' x_k' j)
= x_i' x_k' (∇' · j) + x_k' j · (∇' x_i') + x_i' j · (∇' x_k')   [диференціювання добутку трьох множників]
= 0 + x_k' j_i + x_i' j_k                                       [умови стаціонарності ∇' · j = 0 та ∇' x_i' = e_i]
```

Інтегруючи вираз по об'єму `V'` та знову застосовуючи теорему Ґаусса про дивергенцію:

```
∫_V' (j_i x_k' + j_k x_i') d³r' 
= ∫_V' ∇' · (x_i' x_k' j) d³r'              [підстановка розгортання дивергенції]
= ∮_S' (x_i' x_k' j) · dS'                 [за теоремою Ґаусса про дивергенцію]
= 0                                         [відсутність поверхневого струму на межі S']
```

Оскільки поверхневий інтеграл дорівнює нулю, симетрична частина повністю випадає з розкладу! Залишається лише антисиметрична частина:

```
∫ j_i x_k' d³r' = 1/2 ∫ (j_i x_k' - j_k x_i') d³r'
```

Підставляємо антисиметричну частину назад у вираз для `i`-ї компоненти дипольного векторного потенціалу:

```
[ A_dip(r) ]_i 
= (μ₀ / 4π r³) · 1/2 ∑_k r_k ∫ (j_i x_k' - j_k x_i') d³r'
```

Згортаючи антисиметричний тензор за допомогою подвійного векторного добутку та критерію Леві-Чивіта, переписуємо суму у компактній векторній формі:

```
A_dip(r) = (μ₀ / 4π r³) · [ - 1/2 r × ∫ (r' × j(r')) d³r' ]
```

Ввівши фундаментальне означення **вектора магнітного дипольного моменту** `m` системи струмів:

```
m = 1/2 · ∫_V' (r' × j(r')) d³r'
```

отримуємо остаточний вираз для дипольного векторного потенціалу у дальній зоні:

```
A(r) = (μ₀ / 4π) · (m × r) / r³ = (μ₀ / 4π r²) · (m × r̂)
```

де `r̂ = r / r` — одиничний радіус-вектор, спрямований від диполя до точки спостереження.

### 3. Диференціювання та векторний вивід індукції B = ∇ × A

Індукція магнітного поля `B(r)` обчислюється як ротор векторного потенціалу: `B = ∇ × A`. Виконаємо диференціювання для точок поза джерелом (`r ≠ 0`).

Використовуючи формулу ротора від добутку скаляра `f(r) = 1/r³` на векторне поле `V(r) = m × r`:

```
∇ × [ f(r) V(r) ] = f(r) (∇ × V) + [ ∇ f(r) ] × V
```

Обчислимо кожен із двох доданків послідовно:

1. **Перший доданок `∇ × (m × r)`:**
   Застосовуємо векторне правило розкриття ротора векторного добутку для сталого вектора `m`:
   ```
   ∇ × (m × r) 
   = m (∇ · r) - (m · ∇) r              [векторна тотожність BAC-CAB]
   = 3 m - m                            [оскільки ∇ · r = 3 та (m · ∇) r = m]
   = 2 m
   ```

2. **Другий доданок `[ ∇ (1 / r³) ] × (m × r)`:**
   Обчислимо градієнт скалярного поля `f(r) = r^(-3)`:
   ```
   ∇ (1 / r³) = - 3 r / r⁵ = - 3 r̂ / r⁴
   ```
   Підставляємо цей градієнт у векторний добуток і застосовуємо тотожність подвійного векторного добутку `a × (b × c) = b (a · c) - c (a · b)`:
   ```
   (-3 / r⁵) · [ r × (m × r) ]
   = (-3 / r⁵) · [ m (r · r) - r (m · r) ]    [розкриття векторного добутку]
   = (-3 / r³) m + (3 (m · r) r) / r⁵
   ```

3. **Сумування та згортання доданків:**
   Підставляємо обидва отримані вирази в формулу для `B(r)`:
   ```
   B(r)
   = (μ₀ / 4π) · [ (2 m / r³) - (3 m / r³) + (3 (m · r) r) / r⁵ ]
   = (μ₀ / 4π r³) · [ 3 (m · r̂) r̂ - m ]      [остаточне поле для r ≠ 0]
   ```

Отриманий вираз є фундаментальним законом розподілу індукції магнітного поля точкового диполя у довільній точці простору `r ≠ 0`.

### 4. Рівняння силових ліній та дифгеометрія поля диполя

Силові лінії магнітного поля задаються диференціальним рівнянням `dr × B = 0`, що означає паралельність дотичної до силової лінії вектору індукції `B` у кожній точці.

У сферичній системі координат `(r, θ, φ)` це рівняння розпадається на диференціальне співвідношення між радіусом `r` та кутом `θ`:

```
dr / B_r = r dθ / B_θ
```

Підставляючи вирази для сферичних компонент `B_r = (μ₀ m / 2π r³) cos θ` та `B_θ = (μ₀ m / 4π r³) sin θ`:

```
dr / [ (μ₀ m / 2π r³) cos θ ] = r dθ / [ (μ₀ m / 4π r³) sin θ ]
```

Спрощуємо спільні множники та розділяємо змінні:

```
dr / r = 2 (cos θ / sin θ) dθ = 2 (d(sin θ) / sin θ)
```

Інтегруючи обидві частини диференціального рівняння:

```
ln(r) = 2 ln(sin θ) + C = ln(R₀ · sin² θ)
```

Потенціюючи отриману рівність, маємо явне параметричне рівняння силових ліній магнітного диполя:

```
r(θ) = R₀ · sin² θ
```

де `R₀` — константа інтегрування, яка має зміст максимальної відстані від диполя до даної силової лінії на екваторі (`θ = 90°`). Зміна константи `R₀` дає все сімейство замкнених симетричних ліній дипольного поля.

Диференціальний елемент дуги силової лінії `ds` обчислюється як:

```
ds = √(dr² + r² dθ²)                        [диференціальний елемент довжини у сферичних координатах]
= √( (2 R₀ sin θ cos θ dθ)² + (R₀ sin² θ dθ)² ) [підстановка похідної dr = 2 R₀ sin θ cos θ dθ]
= R₀ sin θ √(1 + 3 cos² θ) dθ               [винесення спільного множника R₀ sin θ dθ за корінь]
```

Радіус кривизни силової лінії диполя `R_c(θ)` у довільній точці виражається формулою:

```
R_c(θ) = (R₀ / 3) · (sin θ (1 + 3 cos² θ)^(3/2)) / (1 + cos² θ)
```

На екваторі (`θ = 90°`) радіус кривизни силової лінії становить `R_c = R₀ / 3`.

### 5. Строгий вивід точкового контактного члена Фермі (r = 0)

Класичний вираз `B(r) = (μ₀ / 4π r³) [3(m · r̂)r̂ - m]` має математичну особливість у точці `r = 0`: при наближенні до нуля він прямує до нескінченності. Щоб правильно коректно визначити поле точкового струмового диполя у всьому просторі, обчислимо середнє магнітне поле `⟨B⟩` по кулі радіуса `R`, яка містить усередині себе джерело струму `j(r')`:

```
⟨B⟩ = (1 / V_кулі) · ∫_куля B(r) d³r = (3 / 4π R³) · ∫_куля B(r) d³r
```

Виразимо магнітну індукцію через ротор векторного потенціалу `B = ∇ × A` і застосуємо векторний аналог теореми Ґаусса:

```
∫_куля B d³r = ∫_куля (∇ × A) d³r = ∮_поверхня (dS × A)
```

де `dS = R² dΩ r̂` — елемент поверхні сфери радіуса `R`.

Підставляємо мультипольний вираз для векторного потенціалу `A(r') = (μ₀ / 4π) ∫ [j(r') / |r - r'|] d³r'` та міняємо порядок інтегрування за об'ємом `V'` та сферичною поверхнею `S`:

```
∮_поверхня (dS × A) 
= (μ₀ / 4π) · ∫_V' d³r' j(r') × [ ∮_S (r̂ × dS) / |r - r'| ]
```

Використовуючи значення поверхневого інтеграла для сфери `∮_S dS / |R r̂ - r'| = (4π / 3) r'`:

```
∫_куля B(r) d³r = (2 μ₀ / 3) · [ 1/2 ∫_V' (r' × j(r')) d³r' ] = (2 μ₀ / 3) · m
```

Отриманий результат є точним: об'ємний інтеграл від магнітної індукції будь-якої струмової системи по кулі радіуса `R`, яка повністю містить цю систему, дорівнює `(2μ₀ / 3) m` незалежно від радіуса кулі `R`.

Оскільки інтегрування звичайної дипольної формули `B_дип` по сфері дає нуль через кутову симетрію `∫_0^π (3 cos² θ - 1) sin θ dθ = 0`, повний вираз для магнітної індукції точкового диполя, справедливий для абсолютно всіх точок простору, стає рівним:

```
B_повне(r) = (μ₀ / 4π r³) · [ 3 (m · r̂) r̂ - m ] + (2μ₀ / 3) · m · δ³(r)
```

Другий доданок — **контактний член Фермі** — строго описує поле всередині точкового струмового диполя і є основою квантовомеханічного розрахунку надтонкої структури атомних спектрів.

### 6. Вивід сил та моментів взаємодії двох диполів

Для двох магнітних диполів `m₁` та `m₂`, розташованих у точках `r₁` та `r₂` з вектором відносного зсуву `r = r₂ - r₁`, потенціальна енергія другого диполя в полі першого дорівнює:

```
U₁₂ = - m₂ · B₁(r)
```

Підставляючи поле `B₁(r) = (μ₀ / 4π r³) [ 3 (m₁ · r̂) r̂ - m₁ ]`:

```
U₁₂ = (μ₀ / 4π r³) · [ m₁ · m₂ - 3 (m₁ · r̂) (m₂ · r̂) ]
```

Сила `F₂`, яка діє на другий диполь, є градієнтом потенціальної енергії `F₂ = - ∇₂ U₁₂`:

```
F₂ = - ∇ [ (μ₀ / 4π r³) (m₁ · m₂ - 3 (m₁ · r̂) (m₂ · r̂)) ]
```

Диференціюючи вираз за радіус-вектором `r`, обчислюємо градієнт кожного доданку:
1. `∇ (1 / r³) = - 3 r̂ / r⁴`.
2. `∇ ( (m₁ · r) (m₂ · r) / r⁵ ) = ( (m₁ · r) m₂ + (m₂ · r) m₁ ) / r⁵ - 5 (m₁ · r) (m₂ · r) r̂ / r⁷`.

Збираючи обидва вирази, отримуємо остаточну тензорну формулу сили диполь-дипольної взаємодії:

```
F₂ = (3 μ₀ / 4π r⁴) · [ (m₁ · r̂) m₂ + (m₂ · r̂) m₁ + (m₁ · m₂ - 5 (m₁ · r̂) (m₂ · r̂)) r̂ ]
```

Ця формула строго показує, що сила взаємодії двох магнітних диполів спадає з відстанню як `1 / r⁴` і є складною функцією трьох взаємних орієнтацій векторів `m₁`, `m₂` та `r̂`.

### 7. Поправки вищих мультиполів: квадрупольний доданок (`l = 2`)

Для скінченного струмового контуру радіуса `R` (наприклад, колового витка зі струмом `I`) точне магнітне поле на відстанях `r`, порівнянних із `R`, відхиляється від ідеального дипольного закону `1/r³`. Для врахування скінченного розміру джерела розкладемо векторний потенціал до квадрупольного члени `l = 2`:

```
A_quad(r) = (μ₀ / 8π r⁵) · ∫ j(r') [ 3 (r · r')² - r² r'² ] d³r'
```

Для колового витка зі струмом радіуса `R` та моментом `m = I π R²`, розташованого у площині `xy`, осьова компонента магнітної індукції `B_z` на осі `z` розкладається в ряд Тейлора:

```
B_z(z) 
= (μ₀ I R²) / (2 (R² + z²)^(3/2))
= (μ₀ m / 2π z³) · (1 + R²/z²)^(-3/2)
= (μ₀ m / 2π z³) · [ 1 - 3/4 (R / z)² + 15/8 (R / z)⁴ - ... ]
```

Цей результат показує:
1. Найперша квадрупольна поправка до дипольного поля спадає як `1 / z⁵` (порядок `(R/z)²` відносно головного члена).
2. Похибка точкової дипольної формули `B_дип = μ₀ m / (2π z³)` становить менше 1% при відстанях `z > 8.7 R`.

### 8. Скалярний магнітний потенціал та сферичні гармоніки

У точках простору, де відсутні електричні струми (`j = 0`), магнітне поле є безвихровим (`∇ × B = 0`). Це дає змогу виразити індукцію магнітного поля через скалярний магнітний потенціал `ψ_m`:

```
B(r) = - μ₀ ∇ ψ_m(r)
```

Оскільки `∇ · B = 0`, скалярний магнітний потенціал задовольняє рівняння Лапласа `∇² ψ_m = 0`. У сферичних координатах розклад скалярного потенціалу за поліномами Лежандра `P_l(cos θ)` має вигляд:

```
ψ_m(r, θ) = ∑_{l=0}^∞ [ A_l r^l + B_l / r^(l+1) ] P_l(cos θ)
```

Для точкового диполя з моментом `m`, спрямованим вздовж осі `z`, скалярний потенціал у зовнішньому просторі дорівнює першій гармоніці (`l = 1`):

```
ψ_dip(r, θ) = (m / 4π r²) cos θ = (m · r̂) / (4π r²)
```

Обчислення градієнта `- μ₀ ∇ ψ_dip` у сферичних координатах дає:

```
B_r = - μ₀ (∂ψ_dip / ∂r) = (μ₀ m / 2π r³) cos θ
B_θ = - (μ₀ / r) (∂ψ_dip / ∂θ) = (μ₀ m / 4π r³) sin θ
```

це строго збігається з результатами, отриманими через ротор векторного потенціалу `B = ∇ × A`.

### 9. Математичний вивід прецесії Лармора та частоти

Розглянемо магнітний диполь із моментом `m`, пов'язаний із квантовим чи класичним моментом імпульсу `L` через гіромагнітне відношення:

```
m = γ L
```

Зміна моменту імпульсу за часом під дією повертаючого моменту `τ = m × B` описується рівнянням механіки обертального руху:

```
dL / dt = τ = m × B = γ (L × B)
```

Враховуючи, що `L × B = - B × L`, перепишемо це рівняння у вигляді:

```
dL / dt = ( - γ B ) × L
```

Визначаючи вектор кутової частоти Лармора як `ω_L = - γ B`, рівняння набуває стандартної форми векторного обертання:

```
dL / dt = ω_L × L
```

Обчислимо скалярні добутки `L · (dL/dt)` та `B · (dL/dt)`:
1. `L · (dL/dt) = L · (ω_L × L) = 0 => d(|L|²) / dt = 0 => |L| = const`.
2. `B · (dL/dt) = B · (ω_L × L) = 0 => d(L · B) / dt = 0 => θ = const`.

Це строго доводить, що під дією магнітного поля вектор моменту імпульсу `L` (і відповідно магнітний дипольний момент `m`) обертається з незмінним модулем та під незмінним кутом `θ` навколо напрямку поля `B` із кутовою частотою Лармора `ω_L = |γ| |B|`.

### 10. Математичний вивід дипольного випромінювання у хвильовій зоні

Для гармонічно змінного дипольного моменту `m(t) = m₀ cos(ω t)` запізнювальний векторний потенціал `A(r, t)` обчислюється з урахуванням часу запізнення сигналів `t' = t - r/c`. У хвильовій зоні (`r >> λ = c/ω`) головним членом стає похідна від дипольного моменту:

```
A_rad(r, t) = (μ₀ / 4π c r) · [ ṁ(t - r/c) × r̂ ]
```

Диференціювання за координатами для обчислення індукції `B_rad = ∇ × A_rad` дає:

```
B_rad(r, t) = - (μ₀ / 4π c² r) · [ m̈(t - r/c) × r̂ ] × r̂
```

Електричне поле випромінювання дорівнює `E_rad = c (B_rad × r̂)`. Модуль вектора Пойнтінга `S_p = (1/μ₀) |E_rad × B_rad|` у напрямку радіус-вектора становить:

```
S_p(r, θ, t) = (μ₀ m̈²) / (16 π² c³ r²) · sin² θ
```

Інтегруючи потік енергії по сферичній поверхні радіуса `r` (інтеграл `∫_0^π sin³ θ dθ = 4/3`), отримуємо формулу Лармора для повної миттєвої потужності випромінювання магнітного диполя:

```
P(t) = ∮_S S_p · dS = (μ₀ m̈²) / (6 π c³)
```

Усереднення за періодом коливань `<m̈²> = 1/2 m₀² ω⁴` дає середню потужність випромінювання `P_rad = (μ₀ m₀² ω⁴) / (6 π c³)`.

### 11. Тензорний вивід розмагнічувальних факторів еліпсоїдів

Усередині однорідно намагніченого еліпсоїда з вектора намагніченості `M` внутрішнє розмагнічувальне поле `H_d` виражається через симетричний тензор розмагнічувальних факторів `N_ik`:

```
H_d,i = - ∑_k N_ik M_k
```

Головні осі тензора `N_ik` збігаються з осями симетрії еліпсоїда (`N_x, N_y, N_z`). Для довільного тривісного еліпсоїда скалярний магнітний потенціал задовольняє рівняння Лапласа, звідки випливає теорема про слід тензора:

```
Tr(N) = N_x + N_y + N_z = 1
```

Проаналізуємо три геометричні граничні випадки:

1. **Ідеальна сфера (`a = b = c`):**
   Внаслідок сферичної симетрії `N_x = N_y = N_z`. З теореми про слід отримуємо `3 N_x = 1 => N_x = N_y = N_z = 1/3`. Розмагнічувальне поле кулі дорівнює `H_d = - 1/3 M`.

2. **Тонкий плоский диск (`a = b >> c`, намагнічування вздовж осі `z`):**
   Поверхневі зв'язані заряди скаплюються на плоских гранях. Розмагнічування уздовж площини відсутнє (`N_x = N_y = 0`), тому `N_z = 1`. Розмагнічувальне поле диска перпендикулярно до площини дорівнює `H_d = - M`.

3. **Нескінченно довгий циліндр (`a = b << c`, намагнічування вздовж осі `z`):**
   Поверхневі заряди віднесені на нескінченність уздовж осі `z`, отже `N_z = 0`. Симетрія у поперечному перерізі дає `N_x = N_y = 1/2`.

### 12. Тензор градієнта дипольного поля `∇B` та просторові сили

Для детального обчислення механічної сили `F = (m₂ · ∇) B₁` розглядають тензор градієнта індукції магнітного поля `G_ik = ∂B_i / ∂x_k`.

Диференціюючи вираз `B_i(r) = (μ₀ / 4π r³) [ 3 r_i (m · r) / r² - m_i ]` за координатами `x_k`, отримуємо симетричний бездевіаторний тензор другого рангу:

```
G_ik 
= ∂B_i / ∂x_k 
= (3 μ₀ / 4π r⁴) · [ (m · r̂) (δ_ik - 5 r̂_i r̂_k) + m_i r̂_k + m_k r̂_i ]
```

Властивості тензора градієнта:
1. **Безвихровість у вакуумі:** `G_ik = G_ki`, що відповідає `∇ × B = 0`.
2. **Соленоїдальність (нульовий слід):** `Tr(G) = ∑_i G_ii = ∇ · B = 0`.

Сила, яка діє на диполь `m₂` у даному полі, згортається з тензором градієнта як `F_i = ∑_k G_ik m₂_k`, що підтверджує раніше виведену векторну формулу сили взаємодії.

### 13. Термодинамічна робота та потенціальна енергія орієнтації

Обчислимо елементарну роботу `dW`, яку виконує повертаючий момент `τ = m × B` при нескінченно малому повороті диполя на кут `dθ` у площині орієнтації:

```
dW = - |τ| dθ = - m B sin θ dθ
```

Зміна потенціальної енергії `dU` дорівнює виконанню роботи з протилежним знаком (`dU = - dW`):

```
dU = m B sin θ dθ = d( - m B cos θ ) = d( - m · B )
```

Інтегруючи від рівноважного стану `θ = 0` (де `U₀ = - m B`) до кута `θ`, отримуємо потенціальну енергію диполя в зовнішньому магнітному полі:

```
U(θ) = - m · B = - m B cos θ
```

Цей вивід показує, що потенціальна енергія є мінімальною при паралельній орієнтації `m ∥ B` (`U_min = - m B`), що забезпечує термодинамічно стійкий стан системи. У стан антипаралельної орієнтації `m ⇈ B` енергія досягає свого абсолютного максимуму (`U_max = + m B`), що відповідає нестійкій рівновазі.
