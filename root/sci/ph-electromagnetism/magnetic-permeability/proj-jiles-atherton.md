# ⚙️ Чисельне моделювання петлі гістерезису за моделлю Джайлса-Атертона

Моделювання нелінійної поведінки магнітопроводів у трансформаторах, дроселях та електродвигунах вимагає розрахунку миттєвої магнітної індукції `B(t)` з урахуванням магнітної передісторії матеріалу, насичення та втрат на перемагнічування. Нижче наведено практичну чисельну реалізацію феноменологічної диференціальної моделі Джайлса-Атертона (*Jiles-Atherton model*) мовами C та C++ з детальним аналізом фізичних параметрів та автоматичним обчисленням енергетичних втрат за повний цикл перемагнічування.

---

### 1. Фізичні основи моделі Джайлса-Атертона

Модель Джайлса-Атертона, розроблена Девідом Джайлсом та Девідом Атертоном у 1984–1986 роках, базується на термодинамічному балансі енергії в процесі руху міждоменних стінок у феромагнетику.

У реальному полікристалічному матеріалі рух стінок Блоха гальмується дефектами кристалічної ґратки: немагнітними включеннями, дислокаціями, границями зерен та локальними механічними напруженнями (явище піннінгу стінок). Коли зовнішнє магнітне поле зміщує стінку, вона спершу зворотно вигинається, як пружна мембрана, а потім зривається з центрів закріплення і незворотно перескакує в нове стійке положення з розсіюванням енергії у вигляді тепла.

Для математичного опису цього процесу повна намагніченість зразка `M` розбивається на дві складові:

```
M = M_rev + M_irr        [сума зворотної та незворотної намагніченостей]
```

1. **Незворотна складова** `M_irr` (*irreversible magnetization*): описує зміщення міждоменних стінок між центрами піннінгу і формує площу петлі гістерезису.
2. **Зворотна складова** `M_rev` (*reversible magnetization*): описує пружний прогин закріплених стінок та оборотне обертання векторів спонтанної намагніченості всередині доменів.

#### Ефективне магнітне поле та безгістерезисна крива
На кожен окремий домен діє не лише зовнішнє магнітне поле `H`, але й середнє молекулярне поле Вейсса, створене всіма сусідніми доменами. Підсумкове **ефективне магнітне поле** `H_e` всередині зразка становить:

```
H_e = H + α · M        [α — безрозмірний коефіцієнт міждоменного обмінного зв'язку]
```

Якби в кристалі були повністю відсутні дефекти та піннінг (ідеальний бездефектний феромагнетик), намагнічування відбувалося б абсолютно безперешкодно і без втрат енергії за термодинамічно рівноважною **безгістерезисною кривою** `M_an(H_e)` (*anhysteretic magnetization*). Для ізотропного матеріалу вона описується класичною функцією Ланжевена:

```
M_an(H_e) = M_s · [coth(H_e / a) - a / H_e]
```

де:
- `M_s` — намагніченість насичення матеріалу (А/м).
- `a` — параметр форми безгістерезисної кривої (А/м), що характеризує густину магнітних моментів доменів та їхню псевдотеплову дисперсію (`a = k_B · T_eff / μ₀ m_dom`).

#### Диференціальне рівняння незворотної намагніченості
Зміна незворотної намагніченості відбувається лише тоді, коли поточний стан `M_irr` відстає від термодинамічно рівноважного `M_an`. Енергія, що розсіюється на центрах закріплення, пропорційна коефіцієнту піннінгу `k` (А/м). Диференціальне рівняння балансу енергії має вигляд:

```
dM_irr / dH_e = (M_an - M_irr) / (δ · k)
```

де параметр `δ = sign(dH/dt)` фіксує напрямок зміни зовнішнього магнітного поля:
- `δ = +1` при зростанні поля (`dH/dt > 0`, рух по нижній гілці петлі вгору);
- `δ = -1` при спаданні поля (`dH/dt < 0`, рух по верхній гілці петлі вниз).

Коефіцієнт піннінгу `k` безпосередньо визначає ширину петлі гістерезису та коерцитивну силу матеріалу `H_c ≈ k`.

#### Зворотна складова та повна диференціальна сприйнятливість
Зворотна намагніченість вважається пропорційною відхиленню поточної незворотної намагніченості від безгістерезисної:

```
M_rev = c · (M_an - M_irr)        [c — коефіцієнт зворотності, 0 ≤ c ≤ 1]
```

Підставляючи цей вираз у повну намагніченість `M = M_irr + M_rev = (1 - c) · M_irr + c · M_an` та беручи повну похідну за зовнішнім полем `H`, отримуємо підсумкове диференціальне рівняння зв'язку:

```
dM/dH = ( (1 - c) · (dM_irr / dH_e) + c · (dM_an / dH_e) ) / ( 1 - α · (1 - c) · (dM_irr / dH_e) - α · c · (dM_an / dH_e) )
```

Це рівняння чисельно інтегрується на кожному кроці за часом `Δt` за відомим законом зміни зовнішнього поля `H(t)`.

### 2. Алгоритм чисельного розрахунку та обчислення втрат

Для моделювання гармонічного циклу перемагнічування напруженість поля задається синусоїдою `H(t) = H_peak · sin(2π f t)`.

На кожному кроці інтегрування виконується послідовність операцій:
1. Обчислюється приріст поля `dH = H_{next} - H_{prev}` та визначається знак `δ = (dH > 0) ? +1 : -1`.
2. Обчислюється ефективне поле `H_e = H + α · M`.
3. Розраховується значення безгістерезисної функції `M_an(H_e)` та її похідної `dM_an / dH_e`.
4. Обчислюється незворотна сприйнятливість `dM_irr / dH_e`. Якщо напрямок зміни поля намагається віддалити стан від `M_an` (`δ · (M_an - M_irr) ≤ 0`), незворотний приріст блокується (`dM_irr / dH_e = 0`).
5. Розраховується повна похідна `dM/dH` та оновлюються змінні стану: `M += (dM/dH) · dH`.
6. Знаходиться магнітна індукція `B = μ₀ · (H + M)`.
7. За методом трапецій накопичується інтеграл енергетичних втрат за повний замкнений цикл:

```
W_loss = ∮ H dB = μ₀ · ∮ H dM ≈ (1/2) · ∑ (H_i + H_{i-1}) · (B_i - B_{i-1})        [Дж/м³ за цикл]
```

### 4. Ідентифікація 5 параметрів моделі з експерименту

Для адаптації моделі Джайлса-Атертона під конкретну марку сталі чи фериту використовують виміряну квазістатичну петлю гістерезису:
1. **`M_s` (намагніченість насичення):** визначається з прямого вимірювання індукції в сильних полях `B_s = μ₀ · (H_s + M_s)`. Для кремнієвої сталі `M_s ≈ B_s / μ₀ ≈ 1.6 × 10⁶` А/м.
2. **`k` (коефіцієнт піннінгу):** у першому наближенні дорівнює коерцитивній силі `H_c` на головній петлі гістерезису (`k ≈ H_c`).
3. **`c` (коефіцієнт зворотності):** обчислюється як відношення початкової диференціальної сприйнятливості `χ_in` до сприйнятливості на безгістерезисній кривій `χ_an` біля нуля: `c = χ_in / χ_an`.
4. **`a` (параметр форми кривої):** зв'язаний із залишковою намагніченістю `M_r` через співвідношення `M_r = M_s · coth(α M_r / a) - a / (α M_r)`.
5. **`α` (коефіцієнт зв'язку):** підбирається разом із параметром `a` за допомогою нелінійної оптимізації методом найменших квадратів (алгоритм Левенберга-Марквардта) для мінімізації похибки між змодельованою та виміряною площею петлі.

### 5. Підводні камені та крайові випадки числового моделювання

1. **Нефізична від'ємна сприйнятливість (`dM/dH < 0`):**
   У класичній формулі Джайлса-Атертона при великих позитивних зворотних зв'язках `α` знаменник `1 - α · dM/dH_e` може змінити знак при різкому падінні поля. Це призводить до математичного артефакту — зменшення індукції при зростанні поля. У наведеному коді реалізовано обов'язкове обмеження `dM_dH = max(0.0, dM_dH)`, яке гарантує термодинамічну стійкість числової моделі.

2. **Сингулярність функції Ланжевена при `H_e → 0`:**
   Член `coth(z) - 1/z` містить невизначеність типу `∞ - ∞` в нулі. Пряме обчислення через `1/tanh(z)` призводить до ділення на нуль або втрати точності. При `|z| < 10⁻⁶` функцію розкладають у ряд Тейлора:
   
   ```
   coth(z) - 1/z = (1/3) · z - (1/45) · z³ + O(z⁵)
   ```

3. **Числова інтеграція при малих кроках по часу:**
   Простий метод Ейлера першого порядку забезпечує достатню точність лише при розбитті періоду на `N ≥ 2000` кроків. Для високочастотних перехідних процесів або моделювання в складі SPICE-симуляторів рекомендується використовувати адаптивні методи Рунге-Кутти 4-го порядку (RK4) з контролем похибки за кроком.

4. **Порівняння з моделлю Прейсаха:**
   На відміну від моделі Прейсаха, яка вимагає зберігання двовимірної густини розподілу гістеронів `μ(α, β)` і табличного інтегрування, модель Джайлса-Атертона потребує лише 5 скалярних параметрів і 2 змінних стану (`M`, `M_irr`). Це робить її набагато швидшою та придатнішою для тривимірного моделювання методом скінченних елементів (FEM).
