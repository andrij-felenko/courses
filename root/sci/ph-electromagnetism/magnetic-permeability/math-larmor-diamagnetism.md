# 🧮 Квантово-класичне виведення діамагнетизму та ларморової прецесії

Діамагнетизм є універсальною властивістю будь-якої атомної системи: при внесенні речовини у зовнішнє магнітне поле в кожній електронній оболонці індукується додатковий магнітний момент, спрямований строго протилежно до зовнішнього поля. Нижче наведено строге математичне виведення величини індукованого магнітного моменту та діамагнітної сприйнятливості на основі теореми Лармора.

---

### 1. Модель кругової орбіти електрона в атомі

Розглянемо електрон масою `m_e` з зарядом `-e` (де `e ≈ 1.602 × 10⁻¹⁹` Кл), який рухається по коловій орбіті радіуса `r` зі швидкістю `v` навколо атомного ядра.

У незбуреному стані (за відсутності зовнішнього магнітного поля) стабільність орбіти забезпечується кулонівською силою притягання до ядра `F_c`. Рівняння руху електрона за другим законом Ньютона має вигляд:

```
F_c = m_e · ω₀² · r        [ω₀ — початкова кутова швидкість обертання]
```

Обертання електрона по замкненій траєкторії еквівалентне круговому мікроструму силою `I_0`. Період обертання дорівнює `T_0 = 2π / ω₀`. Відповідно, сила орбітального струму становить:

```
I_0
= -e / T_0                 [визначення сили струму як заряду за період]
= -e · ω₀ / (2π)           [підстановка періоду T_0 = 2π / ω₀]
```

Магнітний дипольний момент `m⃗_0` цього струмового контуру дорівнює добутку сили струму на векторну площу орбіти `S⃗ = π · r² · n⃗`:

```
m⃗_0
= I_0 · S⃗                  [визначення магнітного моменту струмового контуру]
= - (1/2) · e · r² · ω⃗₀     [підстановка сили струму I_0 та площі π · r²]
```

Знак мінус показує, що через негативний знак заряду електрона його магнітний момент спрямований протилежно до вектора власного механічного орбітального моменту `L⃗_0 = m_e · r² · ω⃗₀`. Їхнє співвідношення визначається класичним гіромагнітним співвідношенням:

```
m⃗_0 = - (e / (2 · m_e)) · L⃗_0        [зв'язок магнітного та механічного моментів]
```

### 2. Дія зовнішнього магнітного поля та ларморова частота

Увімкнемо однорідне зовнішнє магнітне поле з індукцією `B⃗`, спрямоване перпендикулярно до площини орбіти електрона (уздовж осі `z`).

На рухомий електрон починає діяти додаткова сила Лоренца:

```
F⃗_L = -e · (v⃗ × B⃗)        [сила Лоренца на заряд -e]
```

Сила Лоренца напрямлена вздовж радіуса орбіти. Залежно від того, за годинниковою чи проти годинникової стрілки обертався електрон відносно вектора `B⃗`, сила Лоренца або додається до кулонівської сили притягання, або віднімається від неї.

Запишемо другий закон Ньютона для нового радіального руху електрона з новою кутовою швидкістю `ω`:

```
m_e · ω² · r
= F_c ± e · ω · r · B      [радіальний баланс сил з урахуванням сили Лоренца]
= m_e · ω₀² · r ± e · ω · r · B [підстановка незбуреної кулонівської сили F_c]
```

Поділимо обидві частини рівняння на `m_e · r`:

```
ω² - ω₀² = ± (e · B / m_e) · ω        [рівняння для нової кутової швидкості]
```

Розкладемо різницю квадратів `ω² - ω₀² = (ω - ω₀) · (ω + ω₀)`. Позначимо зміну кутової швидкості через `Δω = ω - ω₀`. Для практично досяжних магнітних полів (навіть у десятки тесла) зміна швидкості `Δω` є мізерною порівняно з гігантською атомною частотою обертання `ω₀ ≈ 10¹⁶` рад/с, тому можна покласти `ω + ω₀ ≈ 2 · ω`:

```
(ω - ω₀) · 2ω
= ± (e · B / m_e) · ω      [лінеаризація різниці квадратів при малій зміні швидкості]
Δω
= ± e · B / (2 · m_e)      [зсув кутової швидкості за рахунок сили Лоренца]
```

Величина `ω_L = e · B / (2 · m_e)` називається **ларморовою частотою** (*Larmor frequency*, на честь ірландського фізика Джозефа Лармора).

Згідно з **теоремою Лармора**, дія однорідного магнітного поля `B⃗` на довільну замкнену систему зарядів еквівалентна переходу в систему відліку, яка рівномірно прецесує навколо напрямку поля з векторною кутовою швидкістю:

```
ω⃗_L = e · B⃗ / (2 · m_e)        [вектор кутової швидкості ларморової прецесії]
```

Прецесія завжди відбувається в такий бік, що додатковий індукований струм створює магнітне поле, спрямоване строго назустріч зовнішньому полю (прямий прояв правила Ленца на атомному рівні).

### 3. Індукований магнітний момент атома

Додаткова кутова швидкість `Δω⃗ = - ω⃗_L` створює додатковий індукований струм `ΔI`:

```
ΔI
= -e · (Δω / 2π)           [визначення індукованого мікроструму через зсув частоти]
= -e · (- e · B / (2 · m_e)) / (2π) [підстановка ларморової кутової швидкості]
= - e² · B / (4π · m_e)    [алгебраїчне спрощення коефіцієнтів]
```

Цей струм тече по контуру радіуса `r_⊥`, де `r_⊥` — проекція радіус-вектора електрона на площину, перпендикулярну до вектора поля `B⃗`. Індукований магнітний момент одного електрона становить:

```
Δm
= ΔI · S_контуру           [визначення магнітного моменту контуру індукції]
= (- e² · B / (4π · m_e)) · (π · ⟨r_⊥²⟩) [підстановка сили струму та площі проекції]
= - (e² / (4 · m_e)) · ⟨r_⊥²⟩ · B [скорочення числа пі у чисельнику й знаменнику]
```

Для сферично симетричного атома середній квадрат відстані електрона від ядра `⟨r²⟩` пов'язаний з декартовими координатами співвідношенням:

```
⟨r²⟩ = ⟨x²⟩ + ⟨y²⟩ + ⟨z²⟩        [квадрат відстані в декартових координатах]
```

З огляду на повну просторову ізотропію електронної хмари в атомі:

```
⟨x²⟩ = ⟨y²⟩ = ⟨z²⟩ = (1/3) · ⟨r²⟩        [ізотропний розподіл за трьома осями]
```

Оскільки поле `B⃗` спрямоване вздовж осі `z`, перпендикулярний радіус дорівнює `r_⊥² = x² + y²`. Його квантовомеханічне середнє значення становить:

```
⟨r_⊥²⟩
= ⟨x²⟩ + ⟨y²⟩              [квадрат радіуса проекції на площину xy]
= (1/3) · ⟨r²⟩ + (1/3) · ⟨r²⟩ [підстановка ізотропних середніх для двох осей]
= (2/3) · ⟨r²⟩             [середній квадрат проекції для сферичної симетрії]
```

Підставимо `⟨r_⊥²⟩` у вираз для індукованого магнітного моменту:

```
Δm
= - (e² / (4 · m_e)) · ((2/3) · ⟨r²⟩) · B [підстановка середнього квадрата проекції]
= - (e² · ⟨r²⟩ / (6 · m_e)) · B [спрощення дробу 2 / (4 · 3)]
```

Якщо атом містить `Z` електронів (атомний номер елемента), то кожен електрон робить незалежний внесок у ларморову прецесію. Сумарний індукований магнітний момент одного атома дорівнює:

```
Δm_атома = - (Z · e² · ⟨r²⟩ / (6 · m_e)) · B        [сумарний індукований момент атома]
```

Зверніть увагу: цей результат отримано без будь-яких припущень про наявність власного постійного магнітного моменту. Він діє у **всіх без винятку** атомах і молекулах. Якщо атом має повністю заповнені електронні оболонки (інертні гази, іони галогенів, молекули води, метал мідь чи вісмут), його власний незбурений момент дорівнює нулю (`m⃗_0 = 0`), і відгук речовини визначається виключно цим діамагнітним індукованим моментом.

### 4. Діамагнітна сприйнятливість та проникність Ланжевена

Нехай в одиниці об'єму речовини міститься `N` атомів (`N = ρ · N_A / M_mol`, де `ρ` — густина, `N_A` — число Авогадро, `M_mol` — молярна маса).

Макроскопічна намагніченість одиниці об'єму `M` визначається сумою індукованих моментів:

```
M
= N · Δm_атома             [макроскопічна намагніченість як густина диполів]
= - (N · Z · e² · ⟨r²⟩ / (6 · m_e)) · B [підстановка індукованого моменту атома]
```

Оскільки зв'язок між індукцією у вакуумі та напруженістю поля має вигляд `B ≈ μ₀ · H` (через малість діамагнітного ефекту `M << H`), запишемо вектор намагніченості через напруженість поля `H`:

```
M = χ_dia · H        [визначення магнітної сприйнятливості середовища]
```

Звідси отримуємо класичну **формулу Ланжевена для діамагнітної сприйнятливості** (*Langevin diamagnetism formula*):

```
χ_dia = - (μ₀ · N · Z · e² / (6 · m_e)) · ⟨r²⟩        [діамагнітна сприйнятливість Ланжевена]
```

Відповідна відносна магнітна проникність діамагнетика становить:

```
μᵣ
= 1 + χ_dia                [зв'язок відносної проникності зі сприйнятливістю]
= 1 - (μ₀ · N · Z · e² / (6 · m_e)) · ⟨r²⟩ [підстановка сприйнятності Ланжевена]
```

### 5. Чисельний розрахунок для міді та вісмуту

Оцінимо порядок величини діамагнітної сприйнятливості для металевої міді (`Cu`, `Z = 29`):
- Густина міді: `ρ = 8960` кг/м³
- Молярна маса: `M_mol = 0.06355` кг/моль
- Концентрація атомів: `N = 8960 × 6.022 × 10²³ / 0.06355 ≈ 8.49 × 10²⁸` атомів/м³
- Середній радіус зовнішніх електронних оболонок: `⟨r²⟩ ≈ (0.7 × 10⁻¹⁰ м)² ≈ 5 × 10⁻²¹` м²
- Магнітна стала: `μ₀ = 4π × 10⁻⁷ ≈ 1.2566 × 10⁻⁶` Гн/м
- Електронний коефіцієнт: `e² / (6 · m_e) = (1.602 × 10⁻¹⁹)² / (6 × 9.109 × 10⁻³¹) ≈ 4.70 × 10⁻⁹` Кл²/(кг)

Підставимо ці значення у формулу Ланжевена:

```
χ_dia
= - (1.2566 × 10⁻⁶) · (8.49 × 10²⁸) · 29 · (4.70 × 10⁻⁹) · (5 × 10⁻²¹) [підстановка числових параметрів міді]
≈ -7.2 × 10⁻⁶              [теоретичне значення сприйнятності для Cu]
```

Експериментально виміряне значення магнітної сприйнятливості міді становить `χ_exp ≈ -9.6 × 10⁻⁶`, що демонструє чудову відповідність теоретичного виведення реальному фізичному експерименту.

### 6. Фундаментальні висновки теорії

З отриманої формули Ланжевена безпосередньо випливають чотири фундаментальні властивості діамагнетизму:

1. **Знакова визначеність (`χ < 0`):** сприйнятливість строго від'ємна для будь-якого матеріалу, тому відносна магнітна проникність діамагнетиків завжди строго менша за одиницю (`μᵣ < 1`).
2. **Температурна незалежність:** у формулу входять лише фундаментальні константи (`e`, `m_e`, `μ₀`), атомний номер `Z` та квантовомеханічний радіус електронної хмари `⟨r²⟩`. Тут немає температури `T`, тому діамагнетизм залишається незмінним від абсолютного нуля до точки плавлення кристала.
3. **Універсальність:** діамагнітний внесок існує абсолютно в усіх атомах (навіть у парамагнетиках та феромагнетиках), але у речовинах із власними неспареними спінами він повністю маскується значно сильнішим позитивним парамагнітним або обмінним відгуком.
4. **Квантова природа:** хоча виведення використовує класичну мову орбіт і ларморової прецесії, сам факт стабільності незмінних атомних орбіт із середнім радіусом `⟨r²⟩` є прямим наслідком хвильової квантової механіки Шредінгера.
