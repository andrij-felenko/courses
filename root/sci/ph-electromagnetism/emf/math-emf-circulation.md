# 🧮 Математична теорія ЕРС: циркуляція векторних полів та індукція

Математичне визначення електрорушійної сили (ЕРС) ґрунтується на циркуляції векторного поля сторонніх сил та теоремі Гельмгольца про розклад електричного поля. Повне ефективне поле ділиться на потенціальну кулонівську складову з нульовою циркуляцією та соленоїдальну вихрову складову, яка виконує роботу над зарядами вздовж замкненого контуру. З рівнянь Максвелла та сили Лоренца випливають два фундаментальні механізми генерації ЕРС: трансформаторний за рахунок зміни магнітного потоку в часі та індукційний ЕРС руху при переміщенні провідника в магнітному полі.

Тут наведено повні кроки виведення з обґрунтуванням кожного математичного переходу та додатковими геометричними прикладами.

---

### Теорема Гельмгольца та розклад електричного поля

За теоремою Гельмгольца (фундаментальною теоремою векторного числення), довільне достатньо гладке векторне поле `E_eff`, що прямує до нуля на нескінченності, можна однозначно розкласти на суму двох ортогональних складових: безвихрової (потенціальної) та соленоїдальної (вихрової):

```
E_eff = E_es + E_ext = − ∇V + ∇ × A
```

де `V` — скалярний електричний потенціал, а `A` — векторний потенціал стороннього поля.

Розглянемо властивості обох складових:

1. **Безвихрова складова (`E_es = − ∇V`):**
   Зазначене поле задовольняє умову тотожної рівності нулю ротора:
   ```
   ∇ × E_es = ∇ × (− ∇V) = 0             [ротор градієнта скаляра завжди дорівнює нулю]
   ```
   За теоремою Стокса циркуляція потенціального поля по будь-якому замкненому контуру `C` тотожно дорівнює нулю:
   ```
   ∮ C E_es · dl = ∬ S (∇ × E_es) · dS = 0
   ```

2. **Соленоїдальна (вихрова) складова (`E_ext`):**
   Має відмінний від нуля ротор (`∇ × E_ext ≠ 0`). Саме ця складова відповідає за виникнення неелектростатичних сторонніх сил.

Електрорушійна сила `E` в замкненому контурі `C` визначається як лінійний інтеграл напряженості стороннього поля:

```
E = ∮ C E_ext · dl
```

Оскільки циркуляція потенціального кулонівського поля дорівнює нулю, додавання або віднімання `E_es` не змінює значення циркуляції:

```
E = ∮ C E_ext · dl + 0
= ∮ C E_ext · dl + ∮ C E_es · dl     [додавання тотожно нульового інтеграла]
= ∮ C (E_ext + E_es) · dl             [об'єднання за лінійністю інтегрування]
= ∮ C E_eff · dl                      [підстановка повного поля E_eff]
```

Цей фундаментальний висновок доводить: **значення ЕРС у замкненому колі вимірює нехтувально малу консервативну частину, а виключно роботу соленоїдального вихрового поля**.

### Диференціальна форма та рівняння Максвелла — Фарадея

Для з'ясування математичної природи індукційної ЕРС застосуємо теорему Стокса до циркуляції повного поля `E` по контуру `C`, який охоплює поверхню `S`:

```
∮ C E · dl = ∬ S (∇ × E) · dS        [теорема Стокса: циркуляція дорівнює потоку ротора]
```

Згідно з другим рівнянням Максвелла (законом електромагнітної індукції у диференціальній формі):

```
∇ × E = − ∂B / ∂t                     [диференціальна форма закону Максвелла — Фарадея]
```

Підставляючи ротор поля `E` в інтегральну форму за теоремою Стокса, маємо:

```
E = ∬ S (∇ × E) · dS
= ∬ S (− ∂B / ∂t) · dS                [підстановка рівняння Максвелла — Фарадея]
= − ∂ / ∂t ∬ S B · dS                 [винесення частинної похідної за час поза інтеграл по нерухомій поверхні]
= − dΦ_B / dt                         [визначення магнітного потоку Φ_B = ∬ B · dS]
```

Цей ланцюг тотожностей дає математичне виведення **закону Фарадея**: ЕРС в нерухомому замкненому контурі дорівнює швидкості зміни магнітного потоку, що пронизує цей контур, узятому зі знаком мінус (правило Ленца).

### Розділення індукційної ЕРС: ЕРС руху та трансформаторна ЕРС

Якщо провідний контур рухається або деформується в просторі зі швидкістю `v(r, t)`, а магнітне поле `B(r, t)` одночасно змінюється в часі, то повна зміна магнітного потоку обумовлена двома доданочками.

Загальна сила Лоренца, що діє на заряд `q`, який рухається зі швидкістю `v`:

```
F_Lorentz = q · (E + v × B)
```

У цьому випадку напряженість стороннього поля, обумовлена рухом у магнітному полі, виражається вектором `E_ext = v × B`.

Повна ЕРС у рухомому контурі складається з двох частин:

```
E_total = ∮ C E_ind · dl + ∮ C (v × B) · dl
```

Зробимо аналіз кожної з двох компонент:

1. **Трансформаторна ЕРС (`E_trans`):** виникає внаслідок часової зміни магнітного поля `∂B / ∂t` при нерухомому контурі.
   ```
   E_trans = ∬ S (− ∂B / ∂t) · dS
   ```
2. **ЕРС руху (`E_motion`):** виникає при русі контуру зі швидкістю `v` у неоднорідному або сталому магнітному полі `B`.
   ```
   E_motion = ∮ C (v × B) · dl
   ```

Застосуємо векторну тотожність для мішаного добутку під інтегралом ЕРС руху:

```
(v × B) · dl = B · (dl × v) = − B · (v × dl)
```

Величини `v × dl` задають елемент площі `dS_sweep`, яку замітає елемент контуру `dl` за одиницю часу `dt`. 

Повний диференціал магнітного потоку за часом для рухомого контуру за теоремою про транспорт Банчелора / Лейбніца дає:

```
dΦ_B / dt = ∬ S (∂B / ∂t) · dS − ∮ C (v × B) · dl
```

Звідси негайно випливає, що загальна ЕРС задовольняє єдине узагальнене рівняння Фарадея:

```
E_total = − dΦ_B / dt
```

Незалежно від того, чи змінюється магнітне поле у часі, чи рухається сам контур (або відбуваються обидва процеси одночасно), математична формула зв'язку ЕРС зі повного похідною магнітного потоку залишається незмінною.

### Розбір математичної задачі 1: ЕРС руху в стержні, що обертається

Розглянемо класичний приклад обчислення ЕРС руху. Металевий стержень довжиною `L` обертається з постійною кутовою швидкістю `ω` в однорідному магнітному полі `B`, перпендикулярному до площини обертання. Один кінець стержня закріплений на осі обертання.

```
Вісь O *------------------------> [R]  (Довжина L)
         |<-- r -->| dr |
```

Обчислимо ЕРС, що виникає між кінцями стержня.

На кожен елемент стержня довжиною `dr`, розташований на відстані `r` від осі, що рухається з лінійною швидкістю `v(r) = ω · r`, діє магнітна частина сили Лоренца, спрямована вздовж стержня.

Напряженість стороннього поля руху:

```
E_ext(r) = v(r) · B = ω · r · B
```

ЕРС `E` є інтегралом напряженості стороннього поля від осі обертання (`r = 0`) до вільного кінця стержня (`r = L`):

```
E = ∫ 0^L E_ext(r) · dr
= ∫ 0^L (ω · r · B) · dr      [підстановка напряженості стороннього поля E_ext = ω·r·B]
= ω · B · ∫ 0^L r · dr        [винесення констант ω та B поза знак інтеграла]
= ω · B · [ r² / 2 ] 0^L       [обчислення первісної для r]
= (1 / 2) · B · ω · L²         [підстановка меж інтегрування 0 та L]
```

Отриманий результат `E = (1/2) · B · ω · L²` має чіткий геометричний зміст. За один оборот стержень замітає круг площею `S = π · L²`. Період одного обороту дорівнює `T = 2π / ω`.

Перевіримо результат через швидкість зміни замітаного магнітного потоку:

```
dΦ_B / dt = B · (dS / dt)
= B · (π · L² / T)             [швидкість замітання площі за період T]
= B · (π · L² / (2π / ω))      [підстановка T = 2π / ω]
= (1 / 2) · B · ω · L²         [скорочення π]
```

Обидва методи — безпосереднє інтегрування сили Лоренца та обчислення похідної потоку — дають тотожний результат.

### Розбір математичної задачі 2: Індукційна ЕРС у прямокутній рамці у змінному полі

Нехай у площині `XY` розташована нерухома прямокутна рамка зі сторонами `a` та `b`. Магнітне поле перпендикулярне до площини рамки і змінюється за гармонічним законом:

```
B(t) = B_0 · cos(ω · t)
```

Обчислимо амплітуду індукційного струму в рамці, якщо її повний електричний опір дорівнює `R`.

1. Площа рамки: `S = a · b`.
2. Магнітний потік крізь рамку в момент часу `t`:
   ```
   Φ_B(t) = B(t) · S = B_0 · a · b · cos(ω · t)
   ```
3. Знаходимо індукційну ЕРС за законом Фарадея:
   ```
   E(t) = − dΦ_B / dt
   = − d/dt [ B_0 · a · b · cos(ω · t) ]      [підстановка виразу для потоку]
   = − B_0 · a · b · [ − ω · sin(ω · t) ]    [обчислення похідної від cos(ωt)]
   = B_0 · a · b · ω · sin(ω · t)            [спрощення знаків]
   ```
4. Знаходимо струм у рамці за законом Ома для замкненого кола:
   ```
   I(t) = E(t) / R
   = (B_0 · a · b · ω / R) · sin(ω · t)
   ```

Амплітуда індукційного струму дорівнює `I_max = (B_0 · a · b · ω) / R`. Вона зростає з підвищенням частоти `ω`, збільшенням площі рамки `S = a · b` та зменшенням опору `R`.

### Розбір математичної задачі 3: Униполярний диск Фарадея

Розглянемо виведення ЕРС для униполярного генератора Фарадея. Суцільний провідний диск радіусом `R` обертається з кутовою швидкістю `ω` в однорідному магнітному полі `B`, спрямованому паралельно осі обертання. Ковзні контакти зняття напруги приєднані до осі та до зовнішнього краю диска.

Знайдемо ЕРС, що виникає між віссю та краєм диска:

1. Довільна точка диска на радіусі `r` рухається зі швидкістю `v(r) = ω · r`.
2. Напряженість радіального стороннього поля за рахунок сили Лоренца:
   ```
   E_ext(r) = v(r) · B = ω · r · B
   ```
3. ЕРС між центром та ковзним контактом на краю диска дорівнює радіальному інтегралу:
   ```
   E_disk = ∫ 0^R E_ext(r) · dr
   = ∫ 0^R (ω · r · B) · dr      [підстановка напряженості стороннього поля E_ext = ω·r·B]
   = ω · B · ∫ 0^R r · dr        [винесення сталих величин ω та B поза знак інтеграла]
   = (1 / 2) · B · ω · R²         [обчислення первісної r²/2 на межах від 0 до R]
   ```

Цей розрахунок підтверджує, що суцільні провідні тіла при обертанні у магнітному полі створюють сталу ЕРС без потреби у розщеплених обмотках чи колекторних пластинах.

### Розбір математичної задачі 4: Напруженість вихрового електричного поля в соленоїді

Нехай у довгому соленоїді радіусом `R_0` з кількістю витків на одиницю довжини `n` струм змінюється за законом `I(t) = I_0 · t`.

Знайдемо напряженість вихрового електричного поля `E_ind(r)` як функцію від відстані `r` від осі соленоїда.

1. Магнітне поле всередині соленоїда (`r < R_0`):
   ```
   B(t) = μ_0 · n · I(t) = μ_0 · n · I_0 · t
   ```
2. Похідна магнітного поля за часом:
   ```
   dB / dt = μ_0 · n · I_0
   ```
3. Для колового контуру радіусом `r < R_0` симетрія вимагає, щоб вихрове поле `E_ind` було направлене по дотичній до кола. Циркуляція дорівнює `2π · r · E_ind`.
4. За законом Фарадея:
   ```
   2π · r · E_ind = − (dB / dt) · (π · r²)
   = − (μ_0 · n · I_0) · (π · r²)              [підстановка похідної магнітного поля dB/dt]
   ```
5. Скорочуючи `π · r`, знаходимо напряженість поля всередині соленоїда (`r < R_0`):
   ```
   E_ind(r) = − (1 / 2) · μ_0 · n · I_0 · r
   ```
6. Для точок поза соленоїдом (`r > R_0`) магнітне поле дорівнює нулю, а потік обмежений радіусом `R_0`:
   ```
   2π · r · E_ind = − (dB / dt) · (π · R_0²)
   = − (μ_0 · n · I_0) · (π · R_0²)            [підстановка значення dB/dt для охопленої площі]
   ```
7. Звідси напряженість поля зовні соленоїда (`r > R_0`):
   ```
   E_ind(r) = − (μ_0 · n · I_0 · R_0²) / (2 · r)
   ```

Вихрове електричне поле існує навіть поза соленоїдом (де саме магнітне поле дорівнює нулю!), що є прямим наслідком того, що причиною вихрового поля є зміна повного магнітного потоку.

Ці математичні виведення показують, що концепція ЕРС має чітку та несуперечливу векторно-аналітичну основу, об'єднуючи механічний рух носіїв заряду та фундаментальні рівняння полів Максвелла.
