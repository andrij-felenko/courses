# ⚙️ Чисельне моделювання руху заряду в схрещених полях (E × B дрейф)

Для розрахунку траєкторій заряджених частинок у плазмі класичні методи чисельного інтегрування диференціальних рівнянь (такі як явний метод Ейлера або стандартний метод Рунге — Кутти 4-го порядку) виявляються незадовільними. Причина полягає у їхній несимлектичності: у магнітному полі вони порушують закон збереження фазового об'єму та збереження кінетичної енергії. На кожному часовому кроці вони додають штучну чисельну енергію, змушуючи заряджену частинку розкручуватися по спіралі зі зростаючим ларморівським радіусом там, де її траєкторія у фізичній дійсності має бути строго замкненим колом або циклоїдою.

У фізиці плазми та чисельному моделюванні методом частинок у комірках (PIC, *Particle-in-Cell*) стандартом де-факто є **алгоритм Бориса** (*Boris algorithm*), розроблений американським фізиком Джейєм Борисом у 1970 році. Цей алгоритм являє собою часово-реверсивну симплектичну схему типу «стрибок жаби» (*leapfrog integration*), яка відокремлює прискорення від електричного поля від чистого обертання у магнітному полі. Головна перевага алгоритму Бориса полягає у тому, що він **строго зберігає energy частинки у чисто магнітному полі** протягом довільно тривалого часу моделювання.

У цій вставці наведено детальний математичний розбір алгоритму Бориса, критерії вибору кроку інтегрування `dt`, а також повні робочі програмі на C та C++ для чисельного моделювання `E × B` дрейфу іона та електрона.

### 1. Математична формалізація сили Лоренца та алгоритму Бориса

Рівняння руху частинки з масою `m` та зарядом `q` під дією сили Лоренца в електричному полі `E` та магнітному полі `B` описується другим законом Ньютона:

```
m · (d v / dt) = q · ( E + v × B )
```

Застосовуючи симетричну різницеву схему для похідної за часом на інтервалі `[tⁿ⁻¹/², tⁿ⁺¹/²]` навколо моменту часу `tⁿ`, маємо:

```
(vⁿ⁺¹/² - vⁿ⁻¹/²) / dt = (q / m) · [ Eⁿ + ((vⁿ⁺¹/² + vⁿ⁻¹/²) / 2) × Bⁿ ]
```

Пряме розв'язання цього векторного рівняння відносно невідомої швидкості `vⁿ⁺¹/²` вимагало б обернення матриці 3×3 на кожному часовому кроці для кожної з мільйонів частинок, що надзвичайно сповільнює обчислення.

Ідея Джей П. Бориса полягає у тому, щоб виключити електричне поле `E` за допомогою простої заміни змінних, звівши векторний розрахунок до трьох послідовних кроків:

1. **Перший електричний півкрок:** Додаємо до швидкості половину прискорення від електричного поля `E`:

```
v_minus = vⁿ⁻¹/² + (q · E / m) · (dt / 2)
```

2. **Чисте обертання у магнітному полі:** Вектор `v_minus` повертається на циклотронний кут без зміни своєї довжини (абсолютної величини швидкості) за допомогою векторної алгебри:

```
t = (q · B / m) · (dt / 2)
```

Вектор `t` спрямований уздовж магнітного поля `B`, а його модуль дорівнює `tan(Δθ / 2)`. Спочатку обчислюється допоміжний вектор `v'`:

```
v' = v_minus + v_minus × t
```

Потім обчислюється нормований вектор `s`:

```
s = (2 · t) / (1 + |t|²)
```

Після чого повернений вектор швидкості `v_plus` отримується простим векторним добутком:

```
v_plus = v_minus + v' × s
```

Математично доведено, що абсолютні довжини векторів збігаються: `|v_plus| = |v_minus|`. Це означає, що магнітна частина алгоритму Бориса **не змінює кінетичну енергію частинки**, що строго відповідає фізичній природі сили Лоренца (магнітна сила не виконує роботи).

3. **Другий електричний півкрок:** Додаємо другу половину електричного прискорення:

```
vⁿ⁺¹/² = v_plus + (q · E / m) · (dt / 2)
```

4. **Оновлення координат:** Після обчислення нової швидкості координата частинки оновлюється на повному кроці за стандартною схемою:

```
xⁿ⁺¹ = xⁿ + vⁿ⁺¹/² · dt
```

### 2. Вибір кроку інтегрування за часом

Для забезпечення стійкості й високої точності чисельного інтегрування крок за часом `dt` мусить бути достатньо малим, щоб розв'язувати найшвидші часові масштаби руху частинки.

Головним обмеженням є циклотронна частота обертання `ω_c = |q| · B / m`. Щоб алгоритм Бориса точно відтворював круговий ларморівський рух без фазових спотворень, часовий крок повинен задовольняти умові:

```
ω_c · dt << 1    (практично: dt ≤ 0.1 / ω_c)
```

Якщо обрати `dt > 2 / ω_c`, чисельна схема втрачає стійкість, і траєкторія частинки починає неконтрольовано розлітатися.

### 4. Фізичний аналіз результатів моделювання

Виконання обох варіантів програми підтверджує ключові фізичні висновки щодо дрейфового руху у схрещених полях:

1. **Точність збігу зі швидкістю `v_E = E / B`:** Чисельно обчислена швидкість зсуву центрів обертання (провідних центрів) уздовж осі X з високою точністю дорівнює `10 000 м/с`. Дрібна відносна похибка (менше 0.01%) обумовлена фазовим положенням частинки на її ларморівській орбіті в момент завершення симуляції.
2. **Збереження амплітуди коливань:** Оскільки магнітна частина алгоритму Бориса виключає чисельну дисипацію чи штучний розгін, ларморівський радіус частинки залишається константним протягом усього часу моделювання.
3. **Застосування у масштабних PIC-кодах:** Саме завдяки своїй простоті (відсутність обернення матриць, використання лише базових векторних операцій) та строгому збереженню збережуваних величин алгоритм Бориса використовується у найпотужніших сучасних кодах для тривимірного моделювання плазми (таких як VPIC, OSIRIS, Smilei, WarpX), що моделюють мільярди частинок на суперкомп'ютерах.
