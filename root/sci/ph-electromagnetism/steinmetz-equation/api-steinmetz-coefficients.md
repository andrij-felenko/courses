# 📋 Довідник коефіцієнтів Штейнмеця та параметрів матеріалів

Цей довідник містить зведені таблиці емпіричних коефіцієнтів Штейнмеця `(k, α, β)` для промислових силових магнітних матеріалів (магнітом'яких феритів, порошкового заліза, аморфних та нанокристалічних сплавів), а також детальний розбір коефіцієнтів температурної та DC-bias корекції.

---

## 1. Класифікація магнітом'яких матеріалів та коефіцієнти OSE

У силовій електроніці вибір магнітного матеріалу для сердечника визначається робочою частотою перетворення, допустимою питомою потужністю втрат та індукцією насичення. Емпірична формула класичного рівняння Штейнмеця (OSE) визначає питому об'ємну потужність втрат:

```
P_v = k · f^α · B_m^β   [Вт/м³]
```

де значення коефіцієнта `k` наведено для частоти `f` у герцах [Гц] та індукції `B_m` у теслах [Тл], а питомі втрати виражено в одиницях SI [Вт/м³]. Для переведення в стандартні інженерні одиниці [мВт/см³] значення слід поділити на `1000`.

### Фізичні класи матеріалів:
1. **Силові марганець-цинкові ферити (MnZn):** Застосовуються в діапазоні від 20 кГц до 1 МГц. Мають високий питомий опір (`1 ... 10 Ом·м`), що практично усуває вихрові втрати на помірних частотах. Індукція насичення становить `B_sat ≈ 0.35 ... 0.50 Тл` при `100 °C`.
2. **Порошкове залізо (Iron Powder):** Виготовляється методом пресування мікроскопічних гранул ізольованого заліза. Має низький коефіцієнт `β ≈ 2.1`, високу індукцію насичення (`B_sat ≈ 1.2 ... 1.5 Тл`) та розподілений немагнітний зазор, що робить його ідеальним для згладжуючих дроселів DC-DC перетворювачів, але втрати на гістерезис вищі, ніж у феритів.
3. **Сплави Sendust (Kool Mμ):** Порошковий сплав заліза, кремнію та алюмінію (`Fe-Si-Al`). Поєднує високу індукцію насичення (`1.0 Тл`) із суттєво нижчими втратами, ніж у чистого порошкового заліза.
4. **Аморфні та нанокристалічні сплави (Metglas, Finemet):** Отримуються шляхом надшвидкого загартування розплаву металу зі швидкістю `10⁶ °C/с`. Не мають кристалічної ґратки та анізотропії, завдяки чому коерцитивна сила є мінімальною (`H_c < 1 А/м`), а втрати на гістерезис у 5–10 разів нижчі, ніж у найкращих феритів.

## 2. Коефіцієнти розрахунку k_i для покращеного рівняння iSE

Для розрахунку втрат при прямокутній напрузі або PWM трикутному струмі за допомогою покращеного рівняння Штейнмеця (iSE) базовий коефіцієнт `k` перераховується у модифікований коефіцієнт `k_i`:

```
k_i = k / K_factor(α, β)
```

Математичний множник `K_factor(α, β)` обчислюється через Бета-функцію Ейлера:

```
K_factor(α, β) = (2π)^(α - 1) · 2^(β - α + 1) · B( (α + 1) / 2,  0.5 )
```

У наступній таблиці наведено готові розраховані значення `K_factor` та коефіцієнти перетворення `k_i / k` для швидкого інженерного розрахунку:

| Матеріал | `α` | `β` | Значення `K_factor` | Множник перетворення `k_i / k` |
| :--- | :--- | :--- | :--- | :--- |
| **N87** | `1.25` | `2.55` | `43.12` | `0.02319` |
| **N97** | `1.38` | `2.62` | `68.45` | `0.01461` |
| **3C90** | `1.28` | `2.50` | `41.80` | `0.02392` |
| **3F3** | `1.75` | `2.70` | `215.30` | `0.00464` |

## 3. Температурна залежність втрат P_v(T) та її фізична природа

Для більшості силових марганець-цинкових феритів (MnZn) залежність питомих втрат від температури має характерний V- або U-подібний вигляд із мінімумом втрат у діапазоні робочих температур `80 ... 100 °C`.

### Фізичний механізм температурного мінімуму
Температурний мінімум втрат пояснюється поведінкою першої константи магнітокристалічної анізотропії `K_1` кристалічної ґратки фериту.
- При кімнатній температурі (`25 °C`) константа анізотропії `K_1` є від'ємною, що вимагає додаткової енергії для розвертання диполів і збільшує коерцитивну силу `H_c` та площу петлі гістерезису.
- При нагріванні до `80...100 °C` константа анізотропії `K_1` проходить через точний нуль (`K_1 = 0`). У цій точці магнітна анізотропія кристала зникає, доменні стінки пересуваються з мінімальним опором, а площа петлі гістерезису та втрати `P_v` стають мінімальними.
- При подальшому нагріванні понад `120 °C` матеріали наближаються до точки Кюрі (`T_c ≈ 210...230 °C`), індукція насичення `B_sat` стрімко падає, і втрати знову катастрофічно зростають через магнітне насичення.

Залежність втрат від температури `T` (у °C) описується тричленним поліномом другої ступені:

```
P_v(T) = P_v(100 °C) · [ c_0 - c_1 · T + c_2 · T² ]
```

| Матеріал | `c_0` | `c_1` (°C⁻¹) | `c_2` (°C⁻²) | Температура мінімуму втрат |
| :--- | :--- | :--- | :--- | :--- |
| **N87** | `2.45` | `0.031` | `0.000165` | `94 °C` |
| **N97** | `1.85` | `0.017` | `0.000085` | `100 °C` |
| **3C90** | `2.60` | `0.034` | `0.000180` | `94 °C` |

## 4. Вплив постійного підмагнічування (DC Bias Correction)

Наявність постійної складової магнітного поля `H_dc` (або `B_dc`), викликаного постійним струмом у силових дроселях, зміщує робочу точку часткової петлі гістерезису (minor loop) уздовж головної кривої намагнічування.

### Фізичний ефект DC-зміщення:
- Постійне поле `H_dc` частково запікає та іммобілізує частину доменних стінок.
- Перемагнічування змінною компонентою `ΔB` відбувається на фоні асиметричного потенційного рельєфу ґратки, що призводить до розширення часткової петлі гістерезису.
- Ефективний коефіцієнт Штейнмеця `k` зростає.

Вплив постійної індукції `B_dc` враховується мультиплікативним поправковим коефіцієнтом `F_DC`:

```
P_v(B_dc) = P_v(0) · F_DC(B_dc)
F_DC(B_dc) = 1 + k_dc · B_dc²
```

де `k_dc` — експериментальний коефіцієнт чутливості матеріалу до підмагнічування:
- **Силові ферити (N87, 3C90):** `k_dc ≈ 1.2 ... 2.5 Тл⁻²`. При постійному підмагнічуванні `B_dc = 0.2 Тл` втрати в сердечнику зростають на 5–10%, а при `B_dc = 0.3 Тл` — на 20–25%.
- **Порошкове залізо (#26, #52):** `k_dc ≈ 0.3 ... 0.8 Тл⁻²`. Має значно вищу стійкість до DC-підмагнічування завдяки розподіленому мікроскопічному немагнітному зазору між зернами заліза.

## 5. Методи експериментального визначення параметрів k, α, β

Оскільки коефіцієнти Штейнмеця залежать від технології виготовлення сердечника, хімічного складу сировини та температури спікання магнітокераміки, виробники матеріалів визначають їх експериментально на спеціалізованих лабораторних стендах.

### Вимірювальні методики:
1. **Калориметричний метод:** Випробувальний сердечник вміщують у ретельно теплоізольовану калориметричну камеру і подають на обмотку синусоїдальний струм заданої частоти `f` та амплітуди `B_m`. Швидкість підйому температури калориметричної рідини (масла або дистильованої води) дає прямий і найточніший вимір абсолютної теплової потужності втрат `P_v`. Цей метод усуває помилки вимірювання фазового зсуву, але вимагає тривалого часу (до кількох годин на одну точку) для досягнення повної теплової рівноваги.
2. **Електричний метод B-H аналізатора:** За допомогою високошвидкісного цифрового осцилографа або аналізатора силових втрат вимірюються миттєві осцилограми напруги `u(t)` на вимірювальній вторичній обмотці та струму `i(t)` у первинній обмотці. Потім числово розраховується добуток та інтегрування миттєвої потужності за період `P = (1/T) ∫ u(t) · i(t) dt`. Головною проблемою цього методу є те, що при високих частотах кут зсуву між струмом та напругою на індуктивності наближається до 90°, і найменша похибка калібрування фазового зсуву датчиків спричиняє величезну похибку розрахунку активної потужності втрат.
3. **Апроксимація методом найменших квадратів:** За отриманим масивом експериментальних точок `(P_v, f, B_m)` проводиться логарифмування `ln(P_v) = ln(k) + α · ln(f) + β · ln(B_m)` та виконується двовимірна лінійна регресія для обчислення троєчки матеріальних коефіцієнтів `(k, α, β)`.

## 6. Одиниці вимірювання та перерахунок співвідношень

При роботі з технічною документацією різних виробників (TDK, Ferroxcube, Micrometals, Magnetics) використовуються різні системи одиниць вимірювання.

Таблиця перерахунку коефіцієнтів та величин:

| Вихідні одиниці | Цільові одиниці | Множник перерахунку | Формула та коментар |
| :--- | :--- | :--- | :--- |
| **Вт/м³** (SI) | **мВт/см³** | `10⁻³` | `P [мВт/см³] = P [Вт/м³] / 1000` |
| **мВт/см³** | **Вт/м³** | `10³` | `P [Вт/м³] = P [мВт/см³] · 1000` |
| **Вт/м³** | **Вт/кг** | `1 / d_density` | `P [Вт/кг] = P [Вт/м³] / d_density` (для феритів густина `d_density ≈ 4800 кг/м³`) |
| **кГц** | **Гц** | `10³` | `f [Гц] = f [кГц] · 1000` |
| **мТл** | **Тесла (Тл)** | `10⁻³` | `B [Тл] = B [мТл] / 1000` |
| **Гаус (G)** | **Тесла (Тл)** | `10⁻⁴` | `B [Тл] = B [G] / 10000` (1 Тл = 10000 Гаус) |
