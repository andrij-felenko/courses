# ⚙️ Чисельний розв'язувач рівняння Пуассона на сітці

Аналітичні розв'язки рівнянь Пуассона та Лапласа існують лише для обмеженого набору симетричних геометрій (куля, циліндр, нескінченна площина). У реальних інженерних задачах — від розрахунку паразитних ємностей між провідниками друкованих плат до моделювання електронно-оптичних систем і високовольтних ізоляторів — область має довільну геометрію з довільним розташуванням електродів. У таких випадках застосовують чисельні методи, найпоширенішим і найпростішим у реалізації з яких є **метод кінцевих різниць** (англ. *Finite Difference Method*, FDM).

У цьому матеріалі детально розглянуто математичну дискретизацію 2D та 3D рівняння Пуассона для нерівномірних кроків сітки, 9-точковий шаблон підвищеної точності, методи дискретизації умов Неймана та Робена за допомогою фіктивних вузлів, алгоритми моделювання плаваючих провідників, аналіз спектрального радіуса ітераційних матрицій, порівняно ітераційні алгоритми релаксації (Якобі, Гаусса-Зейделя, Червоно-Чорний розклад, SOR, OpenMP розпаралелювання, метод сопряжених градієнтів PCG та концепцію мультисіток), критерії зупинки за нормами residual, розібрано оптимізацію пам'яті під кеш-лінії процесора, вирівнювання за 64-байтними межами, розширення типу вузлів `NodeFlags`, наведено повні виробничі реалізації мовами C та C++ з покроковим аналізом коду, а також розібрано практичний приклад розрахунку погонної ємності мікросмужкової лінії.

## Дискретизація 2D рівняння Пуассона на сітці

Розглянемо двовимірну область `Ω` на площині `(x, y)`, заповнену середовищем з абсолютною діелектричною проникністю `ε = ε_r · ε₀`. Диференціальне рівняння Пуассона має вигляд:

```
∂²φ / ∂x² + ∂²φ / ∂y² = −ρ(x, y) / ε
```

Покриємо область прямокутною сіткою. У загальному випадку кроки сітки вздовж осі `x` (`h_x`) та вздовж осі `y` (`h_y`) можуть не збігатися. Координати вузла сітки з індексами `(i, j)` визначаються як `x_i = i · h_x` та `y_j = j · h_y`, де `i ∈ [0, N_x − 1]`, а `j ∈ [0, N_y − 1]`. Позначимо шукане значення потенціалу у вузлі як `φ[i][j]`, а густину об'ємного заряду як `ρ[i][j]`.

Запишемо розклад функції потенціалу `φ` у ряд Тейлора поблизу вузла `(i, j)` за змінною `x`:

```
φ(x + h_x, y) = φ(x, y) + h_x · (∂φ / ∂x) + (h_x² / 2) · (∂²φ / ∂x²) + (h_x³ / 6) · (∂³φ / ∂x³) + O(h_x⁴)
φ(x − h_x, y) = φ(x, y) − h_x · (∂φ / ∂x) + (h_x² / 2) · (∂²φ / ∂x²) − (h_x³ / 6) · (∂³φ / ∂x³) + O(h_x⁴)
```

Додаючи ці два вирази, непарні степені `h_x` взаємно знищуються, що дає центрально-різницеве наближення другої похідної з другим порядком точності `O(h_x²)`:

```
∂²φ / ∂x² ≈ (φ[i+1][j] − 2φ[i][j] + φ[i-1][j]) / h_x²
```

Аналогічно для осі `y` з кроком `h_y`:

```
∂²φ / ∂y² ≈ (φ[i][j+1] − 2φ[i][j] + φ[i][j-1]) / h_y²
```

Підставляємо отримані скінченно-різницеві співвідношення в диференціальне рівняння Пуассона:

```
(φ[i+1][j] − 2φ[i][j] + φ[i-1][j]) / h_x² + (φ[i][j+1] − 2φ[i][j] + φ[i][j-1]) / h_y² = −ρ[i][j] / ε
```

У випадку квадратної сітки (`h_x = h_y = h`) рівняння спрощується до класичного **5-точкового хрестоподібного шаблону** (англ. *5-point stencil*):

```
(φ[i+1][j] + φ[i-1][j] + φ[i][j+1] + φ[i][j-1] − 4φ[i][j]) / h² = −ρ[i][j] / ε
```

Виражаємо потенціал у центральному вузлі `φ[i][j]`:

```
φ[i][j] = ¼ (φ[i+1][j] + φ[i-1][j] + φ[i][j+1] + φ[i][j-1]) + ¼ h² (ρ[i][j] / ε)
```

Це рівняння дає чітку фізичну інтерпретацію: потенціал у будь-якому внутрішньому вузлі дорівнює середньому арифметичному значень у чотирьох сусідніх вузлах плюс поправка на локальну густину заряду. Для порожнього простору без зарядів (`ρ = 0`, рівняння Лапласа) потенціал вузла є точним середнім арифметичним своїх чотирьох сусідів.

## Узагальнення на тривимірний простір 3D

У тривимірному просторі 3D рівняння Пуассона включає третю похідну за координатою `z`:

```
∂²φ / ∂x² + ∂²φ / ∂y² + ∂²φ / ∂z² = −ρ(x, y, z) / ε
```

Апроксимація других похідних центральними різницями на рівномірній кубічній сітці з кроком `h` дає **7-точковий 3D шаблон** (англ. *7-point 3D stencil*):

```
(φ[i+1][j][k] + φ[i-1][j][k] + φ[i][j+1][k] + φ[i][j-1][k] + φ[i][j][k+1] + φ[i][j][k-1] − 6φ[i][j][k]) / h² = −ρ[i][j][k] / ε
```

Звідси ітераційне формульне оновлення для вузла `(i, j, k)` в 3D набуває вигляду:

```
φ[i][j][k] = (1 / 6) · (φ[i+1][j][k] + φ[i-1][j][k] + φ[i][j+1][k] + φ[i][j-1][k] + φ[i][j][k+1] + φ[i][j][k-1]) + (1 / 6) h² (ρ[i][j][k] / ε)
```

Для 3D границь Неймана (наприклад, на нижній площині `k = 0`, де `∂φ/∂z = 0`) також застосовують дзеркальні фіктивні вузли `φ[i][j][-1] = φ[i][j][1]`. У тривимірній сітці індексація неперервного буфера пам'яті розраховується за формулою `idx = (i * ny + j) * nz + k`.

У 3D обсяг необхідної оперативної пам'яті масштабується як `O(N³)`. Наприклад, для кубічної сітки `500 × 500 × 500` масив потенціалу подвійної точності `double` займає `125 · 10⁶ × 8` байт = 1 ГБ RAM. Це робить оптимізацію кеш-локальності та використання багатопотокового розпаралелювання критично важливим для 3D моделей.

## 9-точковий шаблон підвищеного порядку точності

Для підвищення точності чисельного розв'язку без надмірного згущення сітки застосовують **9-точковий компактний шаблон Коллатца** (англ. *9-point compact stencil*), який ураховує діагональні вузли `(i+1, j+1)`, `(i-1, j+1)`, `(i+1, j-1)` та `(i-1, j-1)`.

Розклад у ряд Тейлора у 2D дає наступне компактне наближення оператора Лапласа четвертого порядку точності `O(h⁴)` для рівняння Лапласа (`∇²φ = 0`):

```
φ[i][j] = (1 / 20) · [ 4 · (φ[i+1][j] + φ[i-1][j] + φ[i][j+1] + φ[i][j-1]) +
                      + 1 · (φ[i+1][j+1] + φ[i-1][j+1] + φ[i+1][j-1] + φ[i-1][j-1]) ]
```

Використання 9-точкового шаблону забезпечує анізотропну симетрію поля і зменшує сіткову анізотропію (викривлення еквіпотенціалей уздовж діагоналей сітки), що є критичним при моделюванні круглих або похилих електродів.

## Дискретизація крайових умов Неймана, Робена та плаваючих провідників

Завдання умов Діріхле (`φ = V₀`) не викликає труднощів: відповідні вузли сітки фіксуються, і їхні значення не змінюються під час ітерацій. Однак при моделюванні ізольованих меж або симетричних границь необхідно задавати крайові умови Неймана (`∂φ / ∂n = 0`), Робена або умови на незаземлених провідниках.

### 1. Умова Неймана на симетричній або ізольованій межі

Розглянемо ліву межу області (`i = 0`), на якій задано відсутність нормальної складової електричного поля (`E_x = −∂φ/∂x = 0`).

Для збереження другого порядку точності `O(h²)` введемо шар **фіктивних (привидних) вузлів** (англ. *ghost nodes*) з індексом `i = −1`, розташованих за межею області на відстані `h`.

Апроксимуємо першу похідну на межі центральною різницею:

```
∂φ / ∂x |_{(0, j)} ≈ (φ[1][j] − φ[-1][j]) / (2 h) = 0   =>   φ[-1][j] = φ[1][j]
```

Підставляємо значення фіктивного вузла `φ[-1][j] = φ[1][j]` у загальну 5-точкову формулу для вузла `(0, j)`:

```
φ[0][j] = ¼ (2 · φ[1][j] + φ[0][j+1] + φ[0][j-1]) + ¼ h² (ρ[0][j] / ε)
```

Таким чином, умова Неймана реалізується заміною потенціалу відсутнього зовнішнього сусіда на значення внутрішнього дзеркального сусіда. Фізично це відповідає відзеркаленню силових ліній поля від ізольованої межі.

### 2. Дискретизація умови Робена (змішаної)

На межі розділу діелектрика з навколишнім середовищем задається умова Робена: `a · φ + b · (∂φ / ∂n) = c`. Виражаючи нормальну похідну через фіктивний вузол `(φ[1][j] − φ[-1][j]) / (2h)`, виключаємо значення `φ[-1][j]` з різницевого рівняння. Це дає алгебраїчне формульне оновлення для граничного вузла, яке зберігає загальну матричну структуру розв'язувача.

### 3. Плаваючі провідники (Floating Conductors)

У багатьох електронних приладах наявні незаземлені металеві об'єкти (наприклад, перехідні отвори PCB, екранні кільця або незаряджені острівці маски). Потенціал плаваючого провідника `V_float` не є фіксованим заздалегідь, але є однаковим у всіх його точках, а сумарний заряд провідника є заданим: `∮_S ε (∂φ / ∂n) dS = Q_total`.

На кожній ітерації чисельного розв'язку значення потенціалу `V_float` корегують підсумовуванням нормальних похідних електричного поля на замкненому контурі навколо провідника:

```
V_float^{(k+1)} = V_float^{(k)} + α · [ Q_total − ε ∮_{S_cond} (∂φ / ∂n)^{(k)} dS ]
```

де `α` — коефіцієнт релаксації струму корекції.

## Порівняння ітераційних алгоритмів релаксації

Дискретизація дає систему `N_x · N_y` лінійних алгебраїчних рівнянь з розрідженою п'ятидіагональною матрицею `A · Φ = B`. Збіжність будь-якого ітераційного методу `Φ^{(k+1)} = M · Φ^{(k)} + C` визначається **спектральним радіусом ітераційної матриці** `ρ(M)`. Якщо `ρ(M) < 1`, ітерації збігаються, причому швидкість збіжності пропорційна `−ln(ρ(M))`.

### 1. Метод Якобі (проста ітерація)

У методі Якобі значення на кроці `k+1` обчислюються виключно за даними з попереднього кроку `k`:

```
φ^{(k+1)}[i][j] = ¼ (φ^{(k)}[i+1][j] + φ^{(k)}[i-1][j] + φ^{(k)}[i][j+1] + φ^{(k)}[i][j-1]) + ¼ h² (ρ[i][j] / ε)
```

- **Переваги:** Повний паралелізм (вузли обробляються незалежно), ідеально підходить для GPU-прискорювачів.
- **Спектральний радіус:** `ρ(M_J) = cos(π / N) ≈ 1 − ½ (π/N)²`.
- **Недоліки:** Потребує подвійного обсягу пам'яті (дві матриці `φ_old` та `φ_new`). Дуже повільна збіжність: кількість ітерацій масштабується як `O(N²)`, де `N` — кількість вузлів уздовж однієї сторони.

### 2. Метод Гаусса-Зейделя та Червоно-Чорний розклад (Red-Black Ordering)

У методі Гаусса-Зейделя оновлені значення вузлів використовуються негайно в поточному ж обході сітки:

```
φ^{(k+1)}[i][j] = ¼ (φ^{(k)}[i+1][j] + φ^{(k+1)}[i-1][j] + φ^{(k)}[i][j+1] + φ^{(k+1)}[i][j-1]) + ¼ h² (ρ[i][j] / ε)
```

- **Спектральний радіус:** `ρ(M_GS) = (ρ(M_J))² ≈ 1 − (π/N)²`.
- **Переваги:** Використовує лише одну матрицю (оновлення «in-place») і збігається вдвічі швидше за метод Якобі.
- **Червоно-чорне розпаралелювання (Red-Black Ordering):** Для подолання послідовної залежності даних вузли сітки розфарбовують у шаховому порядку на «червоні» `(i + j) % 2 == 0` та «чорні» `(i + j) % 2 == 1`. На першому півобході оновлюють усі червоні вузли (вони залежать лише від чорних сусідів), а на другому півобході — усі чорні вузли. Це дозволяє розпаралелити Гаусс-Зейдель на багатоядерних CPU за допомогою OpenMP чи SIMD векторних інструкцій без втрати швидкості збіжності.

### 3. Метод послідовної верхньої релаксації (SOR)

Метод SOR прискорює збіжність Гаусса-Зейделя шляхом внесення лінійної екстраполяції з параметром релаксації `ω ∈ (1, 2)`:

```
φ_GS = ¼ (φ[i+1][j] + φ[i-1][j] + φ[i][j+1] + φ[i][j-1]) + ¼ h² (ρ[i][j] / ε)
φ^{(k+1)}[i][j] = (1 − ω) · φ^{(k)}[i][j] + ω · φ_GS
```

Оптимальне значення параметра `ω_opt` для прямокутної сітки розміром `N × N` обчислюється за формулою:

```
ω_opt = 2 / (1 + sin(π / N))
```

Спектральний радіус при оптимальному `ω_opt` дорівнює `ρ(M_SOR) = ω_opt − 1 ≈ 1 − (2π/N)`. Використання `ω_opt` кардинально змінює масштабованість алгоритму: кількість ітерацій зменшується з `O(N²)` до `O(N)`. Для сітки `100 × 100` це означає зменшення кількості ітерацій з 10 000 до ~150.

### 4. Метод сопряжених градієнтів з предобумовленням (PCG)

Для симетричних додатньо визначених матриць `A`, отриманих після дискретизації рівняння Пуассона, найшвидшим криловським алгоритмом є **метод сопряжених градієнтів** (англ. *Preconditioned Conjugate Gradient*, PCG). 

Використання неповного розкладу Холецького (ICCG) або симетричної релаксації в якості предобумовлювача `M ≈ A` зменшує число обумовленості матриці `κ(M⁻¹A) ≪ κ(A)`. Це дає збіжність за `O(√N)` ітерацій, що робить PCG найпопулярнішим прямим ітератором у професійних САПР (Ansys, COMSOL).

### 5. Критерії зупинки ітерацій за нормами залишку (Residual Norms)

Ітераційний процес припиняється, коли норма вектора неузгодженості (залишку) `r = B − A Φ` стає меншою за заданий поріг `tolerance`. На практиці застосовують дві метрики:
- **Лім-норму (L-infinity norm):** `max_{i,j} |φ^{(k+1)}[i][j] − φ^{(k)}[i][j]| < tolerance`. Вона гарантує точність у найгіршій точці сітки, але вразлива до поодиноких сплесків біля гострих кутів.
- **Відносну евклідову норму (L2 norm):** `||r^{(k)}||_2 / ||r^{(0)}||_2 < tolerance`. Вона оцінює глобальну енергетичну збіжність системи.

### 6. Багатопотокове розпаралелювання OpenMP для Red-Black SOR

Завдяки розділенню сітки на червоні та чорні вузли, кожен з двох півобходів методом SOR стає цілком незалежним у межах свого кольору. Це дозволяє ефективно масштабувати чисельний розв'язувач на сучасних багатоядерних процесорах за допомогою прагми OpenMP:

:::tabs
```c
/* Обхід лише червоних вузлів сітки (C + OpenMP) */
#pragma omp parallel for private(j) reduction(max:max_diff)
for (size_t i = 1; i < nx - 1; ++i) {
    size_t j_start = 1 + (i % 2); /* Червоний колір */
    for (size_t j = j_start; j < ny - 1; j += 2) {
        /* Формула оновлення SOR */
    }
}
```
```cpp
// Обхід лише червоних вузлів сітки (C++17 + OpenMP)
#pragma omp parallel for reduction(max:max_diff)
for (std::size_t i = 1; i < nx - 1; ++i) {
    std::size_t j_start = 1 + (i % 2); // Червоний колір
    for (std::size_t j = j_start; j < ny - 1; j += 2) {
        // Формула оновлення SOR
    }
}
```
:::

Такий підхід забезпечує прискорення обчислень у 4–8 разів на сучасних 8-ядерних процесорах без порушення чисельної стійкості.

### 7. Ідея мультисіткових методів (Multigrid)

Хоча SOR значно швидший за Гаусса-Зейделя, він ефективно пригнічує лише високочастотні (короткохвильові) компоненти похибки, розмір яких сумірний із кроком сітки `h`. Низькочастотні (довгохвильові) гладкі похибки гасяться надзвичайно повільно.

**Мультисітковий метод (Multigrid)** розв'язує цю проблему переносом залишку (неузгодженості) з дрібної сітки `h` на грубшу сітку `2h`, `4h` тощо. На грубій сітці гладка похибка стає високочастотною і швидко знищується кількома ітераціями релаксації, після чого корекція повертається назад на дрібну сітку шляхом інтерполяції (оператор пролонгації). Мультисіткові методи досягають оптимальної складності `O(N_total)` — часу, пропорційного загальній кількості вузлів сітки.

## Оптимізація пам'яті, вирівнювання та кеш-локальності

Ефективність чисельного розв'язувача на сучасних процесорах визначається не стільки кількістю арифметичних операцій, скільки пропускною здатністю підсистеми пам'яті та рівнем використання кеш-пам'яті L1/L2/L3.

1. **Неперервна вибірка (Row-major Layout):** Двовимірну сітку `nx × ny` розгортають у суцільний одновимірний масив розміром `nx * ny`. Індекс вузла обчислюється як `idx = i * ny + j`. Внутрішній цикл ітератора мусить здійснюватися за індексом `j` (другий індекс), щоб процесор зчитував послідовні байти пам'яті у межах однієї кеш-лінії (64 байти). Обхід за `i` у внутрішньому циклі призводить до постійних промахів кешу (англ. *cache misses*) та сповільнення обчислень у 5–10 разів.
2. **Вирівнювання пам'яті (Memory Alignment):** Виділення пам'яті під буфери сітки повинно бути вирівняне за 64-байтною межею (наприклад, через `posix_memalign` в C або `std::aligned_alloc` у C++). Це дозволяє процесору використовувати непозиційні SIMD інструкції завантаження пам'яті (`_mm256_load_pd` замість `_mm256_loadu_pd`), усуваючи затримки міжсторінкового зсуву.
3. **Модель типу вузлів (`NodeFlags`):** Замість зберігання окремого масиву булевих прапорців `bool *is_boundary` для кожного вузла, у професійних реалізаціях використовують однобайтний перелічуваний тип `enum class NodeKind : uint8_t { Interior, Dirichlet, Neumann, Robin, Floating }`. Це економить 87.5% пам'яті маски та покращує щільність упакування кешу L1.
4. **Векторизація SIMD:** При використанні послідовного розташування компілятор здатний автовекторизувати цикл за допомогою 256-бітних AVX2 або 512-бітних AVX-512 інструкцій, обробляючи 4 або 8 чисел з плаваючою крапкою подвійної точності (`double`) за один такт процесора.

#include <stdio.h>
#include <stdlib.h>
#include <math.h>
#include <stdbool.h>

/* Структурне представлення сітки Poisson 2D */
typedef struct {
    size_t nx;
    size_t ny;
    double h;
    double *phi;        /* Буфер потенціалу: index = i * ny + j */
    double *rho;        /* Густина об'ємного заряду */
    bool *is_boundary;  /* Маска фіксованих вузлів Діріхле */
} PoissonGrid2D;

/* Ініціалізація сітки та виділення динамічної пам'яті */
PoissonGrid2D* poisson_create(size_t nx, size_t ny, double h) {
    if (nx < 3 || ny < 3 || h <= 0.0) return NULL;

    PoissonGrid2D *grid = (PoissonGrid2D*)malloc(sizeof(PoissonGrid2D));
    if (!grid) return NULL;

    grid->nx = nx;
    grid->ny = ny;
    grid->h = h;
    size_t total = nx * ny;

    grid->phi = (double*)calloc(total, sizeof(double));
    grid->rho = (double*)calloc(total, sizeof(double));
    grid->is_boundary = (bool*)calloc(total, sizeof(bool));

    if (!grid->phi || !grid->rho || !grid->is_boundary) {
        free(grid->phi);
        free(grid->rho);
        free(grid->is_boundary);
        free(grid);
        return NULL;
    }
    return grid;
}

/* Звільнення ресурсів */
void poisson_free(PoissonGrid2D *grid) {
    if (!grid) return;
    free(grid->phi);
    free(grid->rho);
    free(grid->is_boundary);
    free(grid);
}

/* Встановлення потенціалу на зовнішніх межах Діріхле */
void poisson_set_boundary_dirichlet(PoissonGrid2D *grid, double v_top, double v_bot, double v_left, double v_right) {
    size_t nx = grid->nx;
    size_t ny = grid->ny;

    for (size_t i = 0; i < nx; ++i) {
        size_t idx_bot = i * ny + 0;
        grid->phi[idx_bot] = v_bot;
        grid->is_boundary[idx_bot] = true;

        size_t idx_top = i * ny + (ny - 1);
        grid->phi[idx_top] = v_top;
        grid->is_boundary[idx_top] = true;
    }

    for (size_t j = 0; j < ny; ++j) {
        size_t idx_left = 0 * ny + j;
        grid->phi[idx_left] = v_left;
        grid->is_boundary[idx_left] = true;

        size_t idx_right = (nx - 1) * ny + j;
        grid->phi[idx_right] = v_right;
        grid->is_boundary[idx_right] = true;
    }
}

/* Одна ітерація метода SOR. Повертає максимальну зміну (L-infinity норму) */
double poisson_step_sor(PoissonGrid2D *grid, double omega, double eps) {
    size_t nx = grid->nx;
    size_t ny = grid->ny;
    double h2 = grid->h * grid->h;
    double max_diff = 0.0;

    for (size_t i = 1; i < nx - 1; ++i) {
        for (size_t j = 1; j < ny - 1; ++j) {
            size_t idx = i * ny + j;
            if (grid->is_boundary[idx]) continue;

            size_t idx_ip1 = (i + 1) * ny + j;
            size_t idx_im1 = (i - 1) * ny + j;
            size_t idx_jp1 = i * ny + (j + 1);
            size_t idx_jm1 = i * ny + (j - 1);

            double phi_gs = 0.25 * (grid->phi[idx_ip1] + grid->phi[idx_im1] +
                                    grid->phi[idx_jp1] + grid->phi[idx_jm1]) +
                            0.25 * h2 * (grid->rho[idx] / eps);

            double old_val = grid->phi[idx];
            double new_val = (1.0 - omega) * old_val + omega * phi_gs;
            grid->phi[idx] = new_val;

            double diff = fabs(new_val - old_val);
            if (diff > max_diff) {
                max_diff = diff;
            }
        }
    }
    return max_diff;
}

/* Ітераційний цикл розв'язання до досягнення точності tolerance */
size_t poisson_solve(PoissonGrid2D *grid, double omega, double eps, double tolerance, size_t max_iters) {
    for (size_t iter = 0; iter < max_iters; ++iter) {
        double diff = poisson_step_sor(grid, omega, eps);
        if (diff < tolerance) {
            return iter + 1;
        }
    }
    return max_iters;
}

#include <vector>
#include <cmath>
#include <cstddef>
#include <stdexcept>
#include <numbers>
#include <algorithm>

namespace physics {

/* Виробничий RAII клас для 2D чисельного розв'язувача рівняння Пуассона */
class PoissonSolver2D {
public:
    struct ExecutionStats {
        std::size_t iterations_completed{0};
        double final_residual{0.0};
        bool is_converged{false};
    };

    PoissonSolver2D(std::size_t nx, std::size_t ny, double grid_spacing)
        : nx_(nx), ny_(ny), h_(grid_spacing),
          phi_(nx * ny, 0.0),
          rho_(nx * ny, 0.0),
          is_fixed_(nx * ny, false) {
        if (nx < 3 || ny < 3 || grid_spacing <= 0.0) {
            throw std::invalid_argument("Некоректні розміри сітки: потрібні nx, ny >= 3 та h > 0");
        }
    }

    /* Модифікатори та селектори вузлів сітки */
    [[nodiscard]] double& phi(std::size_t i, std::size_t j) { return phi_[i * ny_ + j]; }
    [[nodiscard]] double phi(std::size_t i, std::size_t j) const { return phi_[i * ny_ + j]; }

    [[nodiscard]] double& rho(std::size_t i, std::size_t j) { return rho_[i * ny_ + j]; }
    [[nodiscard]] double rho(std::size_t i, std::size_t j) const { return rho_[i * ny_ + j]; }

    /* Фіксація граничного вузла з умовою Діріхле */
    void set_dirichlet_node(std::size_t i, std::size_t j, double potential_volts) {
        std::size_t idx = i * ny_ + j;
        phi_[idx] = potential_volts;
        is_fixed_[idx] = true;
    }

    /* Фіксація зовнішнього периметра */
    void set_outer_boundaries(double v_top, double v_bot, double v_left, double v_right) {
        for (std::size_t i = 0; i < nx_; ++i) {
            set_dirichlet_node(i, 0, v_bot);
            set_dirichlet_node(i, ny_ - 1, v_top);
        }
        for (std::size_t j = 0; j < ny_; ++j) {
            set_dirichlet_node(0, j, v_left);
            set_dirichlet_node(nx_ - 1, j, v_right);
        }
    }

    /* Обчислення теоретично оптимального параметра релаксації SOR */
    [[nodiscard]] double get_optimal_omega() const noexcept {
        double min_dim = static_cast<double>(std::min(nx_, ny_));
        return 2.0 / (1.0 + std::sin(std::numbers::pi / min_dim));
    }

    /* Виконання чисельного розв'язку методом SOR */
    ExecutionStats solve(double tolerance = 1e-6, std::size_t max_iterations = 10000,
                         double permittivity = 8.8541878128e-12, double omega = 0.0) {
        if (omega <= 0.0 || omega >= 2.0) {
            omega = get_optimal_omega();
        }

        double h2 = h_ * h_;
        double current_residual = 0.0;

        for (std::size_t iter = 1; iter <= max_iterations; ++iter) {
            current_residual = 0.0;

            for (std::size_t i = 1; i < nx_ - 1; ++i) {
                for (std::size_t j = 1; j < ny_ - 1; ++j) {
                    std::size_t idx = i * ny_ + j;
                    if (is_fixed_[idx]) continue;

                    double phi_gs = 0.25 * (phi_[(i + 1) * ny_ + j] + phi_[(i - 1) * ny_ + j] +
                                            phi_[i * ny_ + (j + 1)] + phi_[i * ny_ + (j - 1)]) +
                                    0.25 * h2 * (rho_[idx] / permittivity);

                    double old_val = phi_[idx];
                    double new_val = (1.0 - omega) * old_val + omega * phi_gs;
                    phi_[idx] = new_val;

                    current_residual = std::max(current_residual, std::abs(new_val - old_val));
                }
            }

            if (current_residual < tolerance) {
                return ExecutionStats{iter, current_residual, true};
            }
        }
        return ExecutionStats{max_iterations, current_residual, false};
    }

private:
    std::size_t nx_;
    std::size_t ny_;
    double h_;
    std::vector<double> phi_;
    std::vector<double> rho_;
    std::vector<bool> is_fixed_;
};

} // namespace physics

## Аналіз архітектурних відмінностей реалізацій C та C++

Наведені приклади демонструють принципові відмінності між парадигмами двох мов у задачах чисельного моделювання:

1. **Управління пам'яттю та безпека ресурсів:**
   - У версії **C** використовується ручне виділення пам'яті через `malloc`/`calloc` та обов'язкова перевірка вказівників на `NULL`. Для уникнення витоків пам'яті при помилках необхідні каскадні виклики `free()`.
   - У версії **C++** застосовано концепцію RAII: вектор `std::vector<double>` автоматично виділяє неперервний блок пам'яті у купі при конструюванні та гарантовано звільняє її у деструкторі при виході з області видимості, у тому числі при виникненні винятків (`std::invalid_argument`).
2. **Інкапсуляція та інтерфейси:**
   - Версія C оперує відкритими структури з вказівниками на сирі масиви. Доступ до вузлів вимагає ручного обчислення зміщення `i * ny + j`.
   - Версія C++ приховує внутрішній захищений буфер і надає зручний та безпечний індексований доступ через гетери й сетери `phi(i, j)`, а також повертає структуровану статистику виконання `ExecutionStats`.
3. **Оптимізація та константність:**
   - Використання атрибутів `[[nodiscard]]` та кваліфікатора `noexcept` у C++ підказує компілятору можливість глибшої оптимізації викликів та захищає розробника від ігнорування результатів обчислень.

## Інженерний приклад: Розрахунок погонної ємності мікросмужкової лінії

Розглянемо практичне застосування написаного розв'язувача для розрахунку погонної ємності `C'` мікросмужкової лінії (англ. *microstrip line*) на друкованій платі.

Мікросмужка являє собою тонку мідну доріжку шириною `w`, розміщену на діелектричній підкладці товщиною `d` з відносною проникністю `ε_r`. Під підкладкою знаходиться суцільний заземлений шар міді (`V = 0`).

Для обчислення ємності виконують два чисельних розрахунки на 2D сітці:
1. Знаходять розподіл потенціалу `φ(x, y)` з урахуванням діелектрика підкладки `ε_r` та потенціалом на доріжці `V_stripe = 1` В.
2. Обчисляють повну електростатичну енергію поля `W_e`:

```
W_e = ½ ∫_Ω ε(x, y) · |∇φ|² dx dy
```

3. Обчисляють погонну ємність лінії за формулою:

```
C' = 2 · W_e / (V_stripe)²
```

Дискретний аналог інтеграла енергії обчислюється підсумовуванням по квадратних комірках сітки:

```
W_e ≈ ½ ∑_{i,j} ε[i][j] · [ ((φ[i+1][j] − φ[i][j]) / h)² + ((φ[i][j+1] − φ[i][j]) / h)² ] · h²
```

Отримане значення `C'` дозволяє миттєво обчислити хвильовий опір лінії `Z₀ = 1 / (v · C')`, де `v` — швидкість поширення електромагнітної хвилі в структурі.

## Типові пастки чисельного моделювання

1. **Недостатня роздільна здатність біля гострих країв:** Біля гострих кутів провідників градієнт потенціалу `∇φ` прямує до нескінченності. Використання грубої сітки призводить до заниження максимальної напруженості поля та похибок у ємності до 15–20%. Для усунення цього застосовують сітки з локальним згущенням (адаптивні сітки).
2. **Вплив штучних зовнішніх меж:** Якщо зовнішні межі області розміщені надто близько до провідника, умови Діріхле (`φ = 0`) викривляють силові лінії. Зовнішні межі повинні відступати від досліджуваного об'єкта щонайменше на 5–10 його характерних розмірів.
3. **Передчасна зупинка ітерацій:** Якщо критерій зупинки `tolerance` вибрано надто великим (наприклад, `1e-3`), розв'язок не встигає повністю релаксувати в центрі великої області, що призводить до системних похибок інтегральних величин.
