# 🧮 Фізика дисперсії, скін-шару та розсіювання електромагнітних хвиль

Математичний опис поширення електромагнітної хвилі в речовині вимагає з'єднання рівнянь електродинаміки Максвелла з мікроскопічними моделями відгуку середовища. Коли хвиля частотою `ω = 2πf` проникає у провідник або діелектрик, змінне електричне поле `E` зміщує зв'язані та вільні заряди, викликаючи макроскопічну поляризацію `P` та струми провідності `J`. 

У цій вставці наведено детальні математичні виведення чотирьох фундаментальних моделей класичної та квантової електродинаміки, які пояснюють фізичні механізми ЕМ-спектра: класичну дисперсію Лоренца — Друде й плазмову частоту, векторне виведення скін-ефекту в металах, дипольний розрахунок перерізу Рейлеєвського розсіювання та варіаційне виведення закону зсуву Віна для випромінювання абсолютно чорного тіла.

### 1. Дисперсія Лоренца — Друде та плазмова частота середовища

Розглянемо оптично активний електрон маси `m` із зарядом `-e`, який зв'язаний з атомним ядром квазіпружною силою з власною частотою `ω₀`. При проходженні гармонічної електромагнітної хвилі з електричним полем `E(t) = E₀ · e⁻ⁱʷᵗ` на електрон діють три сили: сила поля `-e·E`, квазіпружна сила повернення `-m·ω₀²·x` та сила дисипативного демпфування (тертя про ґратку) `-m·γ·(dx/dt)`.

Рівняння руху електрона має вигляд класичного збудженого осцилятора:

```
m·(d²x / dt²) + m·γ·(dx / dt) + m·ω₀²·x = -e·E₀·e⁻ⁱʷᵗ
```

Шукаємо стаціонарний розв'язок у формі гармонічних коливань `x(t) = x₀ · e⁻ⁱʷᵗ`. Обчисливши часові похідні `dx/dt = -i·ω·x` та `d²x/dt² = -ω²·x`, підставимо їх у вихідне рівняння:

```
-m·ω²·x₀ - i·m·γ·ω·x₀ + m·ω₀²·x₀ = -e·E₀
m · (ω₀² - ω² - i·γ·ω) · x₀ = -e·E₀
x₀ = -e·E₀ / (m · (ω₀² - ω² - i·γ·ω))     [амплітуда комплексного зміщення]
```

При концентрації електронів `n` у одиниці об'єму макроскопічний вектор поляризації середовища `P` дорівнює:

```
P = -n · e · x₀ = (n · e² · E₀) / (m · (ω₀² - ω² - i·γ·ω))
```

Зв'язок між вектором електричного зсуву `D`, поляризацією `P` та комплексною діелектричною проникністю `ε(ω)` визначається як `D = ε₀·E + P = ε(ω)·E`. Звідси отримуємо вираз для `ε(ω)`:

```
ε(ω) = ε₀ + P/E
ε(ω) = ε₀ · [ 1 + (n·e² / (m·ε₀)) / (ω₀² - ω² - i·γ·ω) ]
```

Введемо фундаментальний параметр — **плазмову частоту середовища ω_p**:

```
ω_p = √( (n · e²) / (m · ε₀) )                       [плазмова частота середовища]
```

Остаточне диференціальне рівняння дисперсії Лоренца набуває вигляду:

```
ε(ω) = ε₀ · [ 1 + ω_p² / (ω₀² - ω² - i·γ·ω) ]      [Формула дисперсії Лоренца]
```

Комплексна проникність розкладається на дійсну частину `ε'(ω)` (відповідає за заломлення та фазову швидкість) та уявну частину `ε''(ω)` (відповідає за згасання та джоулеве дисипативне поглинання хвилі).

#### Плазмова модель Друде для вільних електронів (Метали й іоносфера, ω₀ = 0):
У плазмі або незарядженому газі вільних електронів металу квазіпружна сила повернення відсутня (`ω₀ = 0`). Рівняння Лоренца спрощується до моделі Друде:

```
ε(ω) = ε₀ · [ 1 - ω_p² / (ω² + i·γ·ω) ]
```

У високочастотному наближенні, коли частота хвилі значно перевищує частоту зіткнень електронів (`γ << ω`):

```
ε(ω) ≈ ε₀ · [ 1 - (ω_p / ω)² ]                      [Діелектрична проникність плазми]
```

#### Аналіз двох фізичних режимів поширення хвилі:
Показник заломлення середовища `n(ω) = √(ε(ω) / ε₀)` та комплексне хвильове число `k = (ω/c) · n(ω)` визначають характер хвилі:

1. **Режим відбивання та непрозорості (`ω < ω_p`):**
   Значення `ε(ω) < 0`, тому показник заломлення стає чисто уявним:
   ```
   n(ω) = i · √( (ω_p / ω)² - 1 )
   k = i · (ω/c) · √( (ω_p / ω)² - 1 ) = i · α
   ```
   Хвиля `E(z, t) = E₀ · e⁻ᵃᶻ · e⁻ⁱʷᵗ` перетворюється на швидко згасаючу (evanescent wave) i не поширюється углиб середовища. Вся енергія падаючої хвилі повністю відбивається від межі розділу.
   - *Іоносфера Землі:* Концентрація вільних електронів у шарі F2 становить `n ≈ 10¹² м⁻³`. Плазмова частота `f_p = ω_p / (2π) ≈ 8.98 МГц`. Усі радіохвилі частотою нижче 9 МГц відбиваються іоносферою назад до поверхні Землі, що уможливлює дальній радіозв'язок.
   - *Оптичний блиск металів:* Для міді та срібла концентрація вільних електронів `n ≈ 8.5×10²⁸ м⁻³`, що дає плазмову частоту `f_p ≈ 2.6×10¹⁵ Гц` (далекий ультрафіолет). Оскільки для видимого світла `f_vis < f_p`, метали виявляють високий дзеркальний блиск і є повністю непрозорими.

2. **Режим прозорості (`ω > ω_p`):**
   Значення `ε(ω) > 0`, показник заломлення дійсний `n(ω) = √(1 - (ω_p/ω)²) < 1`. Хвиля вільно поширюється крізь середовище зі фазовою швидкістю `v_p = c / n(ω) > c` та груповою швидкістю переносу енергії `v_g = c · n(ω) < c`.

### 2. Диференціальне виведення векторного скін-ефекту в металах

У провідному середовищі з провідністю `σ`, діелектричною проникністю `ε` та магнітною проникністю `μ` перша пара диференціальних рівнянь Максвелла має вигляд:

```
∇ × E = -μ · (∂H / ∂t)                               [Закон індукції Фарадея]
∇ × H = J_cond + ∂D/∂t = σ·E + ε·(∂E / ∂t)           [Закон Ампера — Максвелла]
```

Для більшості металів на частотах нижче оптичного діапазону (`f < 10¹² Гц`) густина струму провідності `J_cond` значно перевищує густину струму зміщення `J_disp`:

```
|J_cond| / |J_disp| = σ / (ω·ε) >> 1
```

Тому струмом зміщення `∂D/∂t` можна нехтувати (`∇ × H ≈ σ·E`). Застосуємо векторний оператор ротора `∇ ×` до закону Фарадея:

```
∇ × (∇ × E) = -μ · ∂(∇ × H) / ∂t
∇(∇·E) - ∇²E = -μ · σ · (∂E / ∂t)
```

За відсутності вільних об'ємних зарядів усередині провідника (`ρ = 0 ⟹ ∇·E = 0`) векторне рівняння згортається до дифузійного рівняння Телеграфного типу:

```
∇²E = μ · σ · (∂E / ∂t)                              [Рівняння дифузії поля в провіднику]
```

Шукаємо розв'язок у вигляді плоскої монохроматичної хвилі, що поширюється вздовж осі `z` углиб провідника: `E(z, t) = E_x(z) · e⁻ⁱʷᵗ · x̂`.

```
d²E_x / dz² = -i · ω · μ · σ · E_x
```

Введемо комплексний хвильовий вектор `k = α + i·β`, для якого `k² = i · ω · μ · σ`. Скориставшись тотожністю `√i = (1 + i) / √2`:

```
k = (1 + i) · √( (ω · μ · σ) / 2 )
```

Визначивши **глибину скін-шару δ** як відстань, на якій амплітуда поля спадає у `e` разів:

```
δ = √( 2 / (ω · μ · σ) ) = √( 1 / (π · f · μ · σ) )   [Глибина проникнення скін-шару]
```

Отримуємо закон розповсюдження поля та струму вглиб провідника:

```
E_x(z, t) = E₀ · e⁻^(z / δ) · e^(i · (z/δ - ω·t))    [Розподіл поля в провіднику]
J_x(z, t) = σ · E₀ · e⁻^(z / δ) · e^(i · (z/δ - ω·t))  [Густина струму в провіднику]
```

#### Фізичні наслідки скін-ефекту:
1. **Згасання потужності (Вектор Пойнтінга):** Усереднений за часом вектор Пойнтінга `S(z) = (1/2) · Re(E × H*)`:
   ```
   S(z) = S₀ · e⁻^(2z / δ)                           [Загасання енергетичного потоку]
   ```
   Вся енергія випромінювання повністю перетворюється на джоулеве тепло у поверхневому шарі товщиною кількох `δ`.
2. **Зростання опору змінного струму (AC Resistance):** Для круглого провідника радіуса `R` при сильному скін-ефекті (`δ << R`) ефективна площа перерізу для протікання струму становить `A_eff ≈ 2π·R·δ`. Відношення опору змінного струму `R_ac` до опору постійного струму `R_dc = 1 / (σ·π·R²)` становить:
   ```
   R_ac / R_dc ≈ R / (2·δ) = (R / 2) · √( π · f · μ · σ )
   ```
   На частоті 1 ГГц опір мідного провідника зростає у сотні разів порівняно з постійним струмом.

### 3. Двохвильовий розрахунок Рейлеєвського розсіювання (I ∝ f⁴)

Розглянемо малу діелектричну частинку або молекулу з дипольною поляризовністю `α`, розмір якої значно менший за довжину хвилі (`a << λ`). Для сферичної частинки радіуса `a` з відносною проникністю `ε_r` поляризовність становить `α = 4π·ε₀·a³·(ε_r - 1)/(ε_r + 2)`.

Під дією падаючого гармонічного поля `E(t) = E₀ · e⁻ⁱʷᵗ` у частинці наводиться змінний дипольний момент:

```
p(t) = α · E₀ · e⁻ⁱʷᵗ
```

Друга похідна дипольного моменту по часу задає прискорення коливання зарядів:

```
p̈(t) = -ω² · α · E₀ · e⁻ⁱʷᵗ
```

Згідно з класичною електродинамікою (формула Лармора), прискорено коливний диполь випромінює в навколишній простір електромагнітні хвилі. Повня середня потужність випромінювання диполя дорівнює:

```
P_rad = (μ₀ · ⟨p̈²⟩) / (6π · c)
```

Підставляючи квадрат амплітуди прискорення `⟨p̈²⟩ = (1/2) · ω⁴ · α² · E₀²`:

```
P_rad = (μ₀ · ω⁴ · α² · E₀²) / (12π · c)
```

Інтенсивність падаючої плоскої хвилі `I₀ = (1/2) · c · ε₀ · E₀²` дозволяє виразити `E₀² = (2 · I₀) / (c · ε₀)`. Підставляючи `E₀²` та скориставшись співвідношенням `c² = 1 / (ε₀·μ₀)`:

```
P_rad = (ω⁴ · α² · I₀) / (6π · ε₀² · c⁴)
```

Перейшовши від кругової частоти `ω = 2π·c / λ` до довжини хвилі, піднесемо частоту до четвертого степеня: `ω⁴ = (16 · π⁴ · c⁴) / λ⁴`. Підставляючи `ω⁴`:

```
P_rad = [ ((16·π⁴·c⁴) / λ⁴) · α² · I₀ ] / (6π · ε₀² · c⁴)
P_rad = (8 · π³ · α² · I₀) / (3 · ε₀² · λ⁴)         [Потужність розсіювання Рейлея]
```

Ефективний переріз розсіювання `σ_R = P_rad / I₀` демонструє фундаментальну залежність від частоти й довжини хвилі:

```
σ_R = (8π³ · α²) / (3 · ε₀² · λ⁴) ∝ f⁴              [Закон 1/λ⁴]
```

#### Кількісне порівняння трьох режимів розсіювання:
- **Рейлеєвське розсіювання (`a << λ`):** `σ_R ∝ 1/λ⁴`. Фіолетове й синє світло розсіюються молекулами повітря майже у 10 разів інтенсивніше за червоне, що формує блакитний колір денного неба.
- **Розсіювання Мі (`a ≈ λ`):** Відбувається на краплях води у тумані та хмарах (`a ≈ 1–10 мкм`). Інтенсивність слабо залежить від довжини хвилі (`σ_Mie ∝ 1/λ⁰...¹`), тому хмари здаються білими.
- **Геометричне відбивання (`a >> λ`):** `σ = 2·π·a²` (оптична непрозорість великомасштабних тіл).

### 4. Точне варіаційне виведення закону зсуву Віна

Закон випромінювання Планка дає спектральну густину об'ємної енергії випромінювання абсолютно чорного тіла для довжини хвилі `λ` при температурі `T`:

```
u(λ, T) = (8π · h · c) / (λ⁵ · ( e^( (h·c) / (λ·k_B·T) ) - 1 ))
```

Щоб знайти довжину хвилі `λ_max`, на яку припадає максимум випромінювання, продиференціюємо `u(λ, T)` по `λ` і прирівняємо похідну до нуля: `du / dλ = 0`.

Введемо безрозмірну змінну `x = (h · c) / (λ · k_B · T)`. Перепишемо функцію `u(λ)` через `x`:

```
u(x) = C · x⁵ / (eˣ - 1)
```

де `C = (8π · (k_B · T)⁵) / (h⁴ · c⁴)`. Беремо похідну по `x`:

```
du/dx = C · [ (5·x⁴·(eˣ - 1) - x⁵·eˣ) / (eˣ - 1)² ] = 0
```

Прирівнюємо чисельник до нуля при `x ≠ 0`:

```
5 · x⁴ · (eˣ - 1) - x⁵ · eˣ = 0
5 · (eˣ - 1) - x · eˣ = 0
5 - 5·e⁻ˣ - x = 0
x = 5 · (1 - e⁻ˣ)                                   [Трансцендентне рівняння Віна]
```

#### Чисельний розв'язок методом ітерацій Ньютона — Рафсона:
Визначимо функцію `f(x) = x + 5·e⁻ˣ - 5` з похідною `f'(x) = 1 - 5·e⁻ˣ`. Застосуємо ітераційну формулу `x_{n+1} = x_n - f(x_n)/f'(x_n)`:

```
Початкове наближення : x₀ = 5.0
Крок 1: x₁ = 5.0 - (5.0 + 5·e⁻⁵ - 5) / (1 - 5·e⁻⁵) = 5.0 - 0.0348643 = 4.9651357
Крок 2: x₂ = 4.965114137
```

Точне значення кореня дорівнює **`x ≈ 4.96511423174`**.

Підставляючи початкове визначення `x`:

```
(h · c) / (λ_max · k_B · T) = 4.96511423174
λ_max · T = (h · c) / (4.96511423174 · k_B) = b
```

Обчислимо числове значення константи зсуву Віна `b`:

```
b = (6.62607015×10⁻³⁴ · 299792458) / (4.96511423174 · 1.380649×10⁻²³)
b = 1.98644586×10⁻²⁵ / 6.8550788×10⁻²³ ≈ 2.89777195 × 10⁻³ м·К
```

Отримуємо **перший закон зсуву Віна**:

```
λ_max · T = 2.897772 × 10⁻³ м·К                    [Закон зсуву Віна]
```

Ця формула дозволяє за виміряним спектром теплового випромінювання точно визначати температуру далеких астрономічних об'єктів (зірок, галактик, газових хмар) та плазми у термоядерних реакторах.
