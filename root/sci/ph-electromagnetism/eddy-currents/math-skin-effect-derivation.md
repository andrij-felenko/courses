# 🧮 Математичний вивід рівняння дифузії, скін-шару та втрат на вихрові струми

Цей математичний розділ містить послідовний вивід рівняння дифузії електромагнітного поля у провідному середовищі з рівнянь Максвелла, розрахунок комплексного хвильового вектора, поверхневого імпедансу, сили екранування, а також точне інтегрування питомої потужності джоулевих втрат `P_e` для пластини скінченної товщини за допомогою вектора Пойнтінга.

---

### 1. Вивід рівняння дифузії магнітного поля у провіднику

Розглянемо суцільне однорідне ізотропне провідне середовище з питомою електричною провідністю `σ`, магнітною проникністю `μ = μ₀ · μ_r` та діелектричною проникністю `ε`. Припустимо, що у провіднику відсутні сторонні вільні заряди (`ρ_v = 0`).

Виходимо з фундаментальної системи рівнянь Максвелла у диференціальній формі:

```
∇ × E = - ∂B / ∂t                  [закон індукції Фарадея]
∇ × H = j + ∂D / ∂t                [закон Ампера — Максвелла]
∇ · B = 0                          [закон Ґаусса для магнітного поля]
∇ · D = 0                          [закон Ґаусса для електричного поля]
```

Для квазістаціонарних процесів у металах (де частота `f < 10¹⁰ Гц`) густина струму провідності `j = σ · E` перевищує густину струму зсуву `∂D / ∂t = ε · (∂E / ∂t)` на багато порядків:

```
|j| / |∂D / ∂t| = σ / (ω · ε) >> 1
```

Для міді (`σ ≈ 5.8·10⁷ См/м`, `ε ≈ ε₀ ≈ 8.85·10⁻¹² Ф/м`) при частоті `f = 1 МГц` це відношення становить `5.8·10⁷ / (2π·10⁶ · 8.85·10⁻¹²) ≈ 10¹²,` що дозволяє знехтувати струмом зсуву у другому рівнянні Максвелла.

Застосуємо оператор ротора `∇ ×` до обох частин закону Фарадея:

```
∇ × (∇ × E) = ∇ × (- ∂B / ∂t)
∇ × (∇ × E) = - ∂ / ∂t (∇ × B)     [перестановка диференціювання]
```

Використовуємо векторну тотожність для подвійного ротора `∇ × (∇ × A) = ∇(∇ · A) - ∇²A` та підставляємо матеріальні співвідношення `B = μ · H` і `j = σ · E`:

```
∇(∇ · E) - ∇²E = - ∂ / ∂t (∇ × (μ · H))
- ∇²E = - μ · ∂ / ∂t (∇ × H)       [бо ∇ · E = 0 у нейтральному провіднику]
∇²E = μ · ∂ / ∂t (j)               [підстановка ∇ × H = j]
∇²E = μ · σ · (∂E / ∂t)            [підстановка j = σ · E]
```

Аналогічно, взявши ротор від рівняння `∇ × H = σ · E`, отримуємо векторне **рівняння дифузії магнітного поля**:

```
∇²B = μ · σ · (∂B / ∂t)            [рівняння дифузії магнітної індукції]
```

Отримане рівняння має структуру класичного рівняння теплопровідності. Воно показує, що зміна магнітного поля не поширюється у провіднику як незагасаюча хвиля зі швидкістю світла, а дифундує у глибину провідника із постійною часу дифузії `τ_diff ≈ μ · σ · L²`.

### 2. Одновимірне рішення та розрахунок глибини скін-шару (δ)

Розглянемо напівнескінченний провідник, що займає півпростір `x ≥ 0`. Нехай на його зовнішній межі (`x = 0`) прикладено синусоїдальне магнітне поле, спрямоване вздовж осі `z`:

```
B_z(0, t) = B_0 · cos(ωt) = Re [ B_0 · e^(i · ω · t) ]
```

Оскільки поле є однорідним у площині `(y, z)`, одновимірне рівняння дифузії набуває вигляду:

```
∂²B_z / ∂x² = μ · σ · (∂B_z / ∂t)
```

Шукаємо рішення у вигляді комплексної гармонічної хвилі `B_z(x, t) = Re [ B̂(x) · e^(i · ω · t) ]`:

```
d²B̂(x) / dx² = i · ω · μ · σ · B̂(x)
d²B̂(x) / dx² - k² · B̂(x) = 0
```

де комплексне хвильове число `k` дорівнює:

```
k = √( i · ω · μ · σ )
```

Використовуючи тотожність `√i = e^(i · π / 4) = (1 + i) / √2`, отримуємо:

```
k = (1 + i) · √( ω · μ · σ / 2 ) = (1 + i) / δ
```

де величина `δ` називається **глибиною скін-шару** (*skin depth*):

```
δ = √( 2 / (ω · μ · σ) ) = √( 1 / (π · f · μ · σ) )
```

Загальне рішення диференціального рівняння для півпростору `x ≥ 0` з умовою згасання поля при `x → ∞` має вигляд:

```
B̂(x) = B_0 · e^(- k · x) = B_0 · e^(- x / δ) · e^(- i · x / δ)
```

Переходячи до дійсної частини, отримуємо підсумковий розподіл магнітного поля по глибині:

```
B_z(x, t) = B_0 · e^(- x / δ) · cos( ωt - x / δ )
```

Густина вихрового струму `j_y(x, t)` визначається через ротор поля `j = (1 / μ) · (∇ × B)`:

```
j_y(x, t) = - (1 / μ) · (∂B_z / ∂x)
j_y(x, t) = (√2 · B_0 / (μ · δ)) · e^(- x / δ) · cos( ωt - x / δ + π/4 )
```

З отриманих формул випливають три фундаментальні властивості скін-ефекту:
1. **Експоненційне згасання:** Амплітуда магнітного поля та густини струму спадає в `e ≈ 2.718` разів на глибині `x = δ`, та у `e³ ≈ 20` разів на глибині `x = 3δ`.
2. **Фазовий зсув:** Завдяки зсуву фази `x / δ` на глибині `x = π · δ` напрямок вихрового струму змінюється на строго протилежний відносно поверхневого струму.
3. **Екранування:** Вихрові струми у поверхневому шарі створюють протидіюче магнітне поле, яке повністю компенсує зовнішнє змінне поле в глибині провідника.

### 3. Поверхневий імпеданс провідника (Z_s) та вектор Пойнтінга

Для аналізу поглинання електромагнітної енергії поверхнею провідника вводиться концепція **поверхневого імпедансу** `Z_s` (*surface impedance*). Він визначається як відношення комплексної амплітуди поверхневого електричного поля `E_y(0)` до поверхневого магнітного поля `H_z(0)`:

```
Z_s = E_y(0) / H_z(0)
```

З рівняння Ома `j_y(0) = σ · E_y(0)` та виразу для `j_y(0)` отримуємо:

```
E_y(0) = ( (1 + i) / (σ · δ) ) · H_z(0)
Z_s = (1 + i) / (σ · δ) = R_s + i · X_s
```

де:
- **Поверхневий активний опір:** `R_s = 1 / (σ · δ)` (Ом/кв).
- **Поверхневий індуктивний опір:** `X_s = 1 / (σ · δ)` (Ом/кв).

Цей висновок є надзвичайно важливим: для масивного провідника у режимі сильного скін-ефекту активний опір провідника `R_s` строго дорівнює його внутрішньому індуктивному опору `X_s`. Це означає, що поверхневий шар не лише дисипує енергію у тепло, але й запасає еквівалентну реактивну магнітну енергію.

Усереднений за період вектор Пойнтінга `<S_x>`, що входить углиб провідника через одиницю площі поверхні `x = 0`:

```
<S_x> = (1 / 2) · Re [ E_y(0) · H_z*(0) ]
<S_x> = (1 / 2) · R_s · |H_z(0)|² = (1 / 2) · ( 1 / (σ · δ) ) · H_0²  [Вт/м²]
```

Цей вираз доводить **теорему про еквівалентний шар**: сумарні джоулеві втрати у напівнескінченному провіднику з експоненційним згасанням поля є строго тотожними втратам від рівномірного постійного струму амплітудою `H_0`, що протікає через шар товщиною строго `δ`.

### 4. Точний вивід втрат на вихрові струми у тонкій пластині (P_e)

Розглянемо тонку електротехнічну пластину товщиною `d`, висотою `h` та довжиною `L` (`d << h, L`), розташовану симетрично відносно осі `x` (`-d/2 ≤ x ≤ d/2`). Зовнішнє змінне магнітне поле `B(t) = B_0 · sin(ωt)` спрямоване паралельно площині пластини уздовж осі `z`.

Припустимо, що товщина пластини значно менша за глибину скін-шару (`d << δ`). Це означає, що магнітне поле проникне в об'єм пластини майже однорідно (`B(x, t) ≈ B_0 · sin(ωt)`).

Розглянемо замкнений контур індукційного струму симетрично відносно центральної площини `x = 0`, що охоплює прямокутну ділянку шириною `2x` та висотою `h`.

```
        -d/2        -x       0       +x        +d/2
|---------|----------|-------|-------|----------|---------|
|<------------------------ d ---------------------------->|
                     <----- 2x ----->
```

Розрахуємо електрорушійну силу (ЕРС) індукції `e(x, t)`, збуджену у цьому контурі за законом Фарадея:

```
e(x, t) = - dΦ / dt
e(x, t) = - d / dt [ (2x · h) · B_0 · sin(ωt) ]
e(x, t) = - 2x · h · ω · B_0 · cos(ωt)
```

Опір `dR` елементарного шару товщиною `dx` уздовж довжини `h` (нехтуючи опором коротких торцевих перемичок завдовжки `2x << h`):

```
dR = 2 · h / (σ · L · dx)
```

Миттєва джоулева потужність `dP`, що дисипується у двох симетричних шарах товщиною `dx` при координатах `-x` та `+x`:

```
dP(x, t) = e(x, t)² / dR
dP(x, t) = [ 2x · h · ω · B_0 · cos(ωt) ]² / [ 2h / (σ · L · dx) ]
dP(x, t) = 2 · h · L · σ · ω² · B_0² · cos²(ωt) · x² dx
```

Проінтегруємо потужність по усій товщині пластини від `x = 0` до `x = d/2`:

```
P_inst(t) = 2 · h · L · σ · ω² · B_0² · cos²(ωt) · ∫₀^(d/2) x² dx
P_inst(t) = 2 · h · L · σ · ω² · B_0² · cos²(ωt) · [ (d/2)³ / 3 ]
P_inst(t) = (1 / 12) · (h · L · d) · σ · d² · ω² · B_0² · cos²(ωt)
```

Позначивши повний об'єм пластини як `V = h · L · d` та усереднивши миттєву потужність за період гармонічного коливання (`<cos²(ωt)> = 1/2`):

```
P_avg = (1 / 24) · V · σ · d² · ω² · B_0²
```

Підставивши кругову частоту `ω = 2πf` (`ω² = 4π²f²`):

```
P_avg = (1 / 24) · V · σ · d² · (4π²f²) · B_0²
P_avg = (π² / 6) · V · σ · d² · f² · B_0²
```

Поділивши на об'єм `V`, отримуємо точну формулу **питомих об'ємних втрат на вихрові струми** `P_e` (у Вт/м³):

```
P_e = (π² / 6) · σ · d² · f² · B_0² ≈ 1.645 · σ · d² · f² · B_0²
```

Якщо товщину `d` виразити через питомий електричний опір `ρ = 1 / σ`:

```
P_e = (π² / (6 · ρ)) · d² · f² · B_0²
```

Отриманий квадратний зв'язок `P_e ∝ d² · f² · B_0² / ρ` є фундаментальним інженерним співвідношенням:
- Зменшення товщини пластини `d` у 10 разів зменшує втрати на вихрові струми у **100 разів**.
- Збільшення питомого опору матеріалу `ρ` у 4 рази (наприклад, додаванням кремнію до сталі) зменшує вихрові втрати у **4 рази**.
