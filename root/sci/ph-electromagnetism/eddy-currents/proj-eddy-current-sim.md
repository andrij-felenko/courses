# ⚙️ Чисельне моделювання вихрових струмів та втрат у провідниках

Цей проект присвячено розробці розрахункового чисельного модуля для розв'язання нелінійного рівняння дифузії електромагнітного поля у металевій пластині методом скінченних різниць (FDTD), розрахунку просторового розподілу густини вихрових струмів та усередненої за період джоулевої потужності втрат мовами Python, C++ та C.

---

### 1. Фізична постановка задачі та потреба в чисельному розрахунку

У багатьох практичних пристроях силової електроніки, високочастотних трансформаторах, імпульсних перетворювачах напруги та пристроях індукційного нагріву товщина металевих елементів `d` нерідко перевищує глибину скін-шару `δ` (`d > 2δ`). У цьому режимі спрощені аналітичні формули втрат виявляються незастосовними, оскільки вихрові струми у поверхневому шарі сильно екранують внутрішній об'єм металу. В результаті магнітне поле фактично не проникає у центральні області провідника, а густина струму згасає за експоненційним законом від поверхні до центральної площини.

Для точного оцінювання тепловиділення, запобігання термічному руйнуванню ізоляції обмоток та розрахунку коефіцієнта корисної дії (ККД) необхідне чисельне моделювання часової динаміки дифузії магнітного поля та просторового розподілу струмів.

Розглянемо провідну металеву пластину товщиною `d`, розташовану у проміжку `[-d/2, +d/2]` вздовж осі `x`. На зовнішніх поверхнях пластини (`x = ±d/2`) прикладено зовнішнє гармонічне магнітне поле `B_ext(t) = B_0 · sin(ωt)`, спрямоване вздовж осі `z`.

Магнітне поле усередині пластини описується одновимірним рівнянням дифузії:

```
∂B / ∂t = D_m · (∂²B / ∂x²)
```

де `D_m = 1 / (μ · σ)` — коефіцієнт магнітної дифузійності (м²/с).

Густина вихрових струмів `j(x, t)` обчислюється через просторову похідну магнітної індукції за законом Ампера:

```
j_y(x, t) = - (1 / μ) · (∂B_z / ∂x)
```

Миттєва питома потужність джоулевих втрат на одиницю об'єму (Вт/м³):

```
p_e(x, t) = (j_y(x, t))² / σ
```

Для чисельного розв'язку розбиваємо товщину пластини `d` на `N` рівновіддалених вузлів із кроком `dx = d / (N - 1)`. Час дискретизуємо кроком `dt`.

Використовуємо явну різницеву схему (Euler explicit scheme). Значення індукції у вузлі `i` на часовому кроці `n+1` обчислюється через значення сусідніх вузлів на попередньому кроці `n`:

```
B[i]^(n+1) = B[i]^n + α · ( B[i+1]^n - 2·B[i]^n + B[i-1]^n )
```

де параметр числової стійкості `α = D_m · dt / (dx)²` мусить строго задовольняти умову Куранта — Фрідріхса — Леві (CFL condition):

```
α ≤ 0.5   ==>   dt ≤ 0.5 · (dx)² / D_m
```

Якщо крок за часом `dt` перевищить цю межу, чисельний розв'язок розбалансується і викличе нестійке зростання амплітуди (чисельну осциляцію).

Граничні умови на поверхнях `x = -d/2` (вузол `i = 0`) та `x = +d/2` (вузол `i = N-1`):

```
B[0]^(n+1) = B_0 · sin(ω · t^(n+1))
B[N-1]^(n+1) = B_0 · sin(ω · t^(n+1))
```

### 2. Покроковий алгоритм та математичний розбір чисельного модуля

Обчислювальний процес симулятора побудований за п'ятьма послідовними етапами:

#### Етап 1: Ініціалізація сітки та перевірка стійкості
На першому етапі задаються матеріальні константи: питома провідність `σ`, відносна магнітна проникність `μ_r`, товщина пластини `d`, частота поля `f` та амплітуда `B_0`. Обчислюється площа сітки з `N` вузлів та просторовий крок `dx = d / (N - 1)`.

Оскільки явна різницева схема вимагає суворого дотримання критерію стійкості, крок по часу автоматично розраховується як `dt = 0.45 · (dx)² / D_m`. Це гарантує, що безрозмірний коефіцієнт `α = 0.45 < 0.5`, і числова схема залишатиметься повністю стійкою протягом довільної кількості кроків.

#### Етап 2: Часове інтегрування та вихід на стаціонарний режим
Оскільки у початковий момент часу (`t = 0`) магнітне поле усередині пластини дорівнює нулю, для усунення перехідних процесів симуляція проводиться протягом 5 повних періодів `5 · T` (де `T = 1 / f`). Протягом перших двох періодів у пластині збуджуються перехідні вихрові струми, після чого система виходить на строгий гармонічний стаціонарний режим.

#### Етап 3: Обчислення ротора та густини струмів
Після завершення останнього періоду коливань для кожного вузла обчислюється просторова похідна `∂B / ∂x`. Для внутрішніх вузлів `i ∈ [1, N-2]` застосовується схема центральних різниць другого порядку точності:

```
j_y[i] = - (1 / μ) · ( B[i+1] - B[i-1] ) / (2 · dx)
```

Для крайніх поверхневих вузлів `i = 0` та `i = N-1` використовуються односторонні різниці першого порядку:

```
j_y[0] = - (1 / μ) · ( B[1] - B[0] ) / dx
j_y[N-1] = - (1 / μ) · ( B[N-1] - B[N-2] ) / dx
```

#### Етап 4: Розрахунок локального джоулевого нагріву
На кожному вузлі за законом Джоуля — Ленца обчислюється миттєва питома потужність втрат `p_e[i] = (j_y[i])² / σ` (Вт/м³).

#### Етап 5: Чисельне інтегрування за об'ємом (метод Трапецій)
Для обчислення середньої питомої потужності втрат по всьому об'єму пластини застосовується квадратурна формула Трапецій:

```
P_vol = (1 / d) · [ 0.5·p_e[0] + ∑_{i=1}^{N-2} p_e[i] + 0.5·p_e[N-1] ] · dx
```

Отримане значення чисельно зіставляється з аналітичною формулою тонкої пластини `P_analytical = (π² / 6) · σ · d² · f² · B_0²`.

### 4. Фізичний аналіз результатів, крайові випадки та розбір помилок

При проведенні чисельного випробування для мідної пластини товщиною `d = 2 мм` на частоті `f = 1 кГц` (`δ ≈ 2.09 мм`) розраховані чисельним модулем питомі втрати становлять `P_e ≈ 47.7 кВт/м³`.

Характерні інженерні та розрахункові нюанси чисельного моделювання вихрових струмів:

1. **Густота просторової сітки:** Для точної передачі скін-ефекту просторовий крок `dx` повинен бути у 4–5 разів меншим за глибину проникнення (`dx ≤ δ / 5`). Якщо взяти недостатньо вузлів (`N = 11`), чисельний метод зріже поверхневий пік вихрового струму, знизивши обчислені втрати на 30–40%.
2. **Вплив шихтування у чисельному експерименті:** Якщо зменшити товщину пластини у 6 разів до значення `d = 0.35 мм` (типова пластина шихтованого трансформатора), то чисельно обчислені втрати зменшуються з 47.7 кВт/м³ до **1.46 кВт/м³** (зменшення майже у 33 рази), що ідеально узгоджується з квадратичним законом придушення вихрових втрат `P_e ∝ d²`.
3. **Моделювання несинусоїдального живлення:** Наведений чисельний код легко адаптується під будь-яку форму зовнішньої напруги (трикутник, меандр, PWM). Для цього достатньо замінити формулу граничної умови `B_0 · sin(ωt)` на відповідну функцію імпульсного сигналу.
4. **Нелінійна магнітна проникність `μ(B)`:** У реальних сильних полях магнітна проникність феромагнетика залежить від миттєвого значення поля через криву намагнічування `B(H)`. Для моделювання насичення коефіцієнт дифузійності обчислюється динамічно на кожному кроці як `D_m(B) = 1 / (μ_diff(B) · σ)`, де `μ_diff = dB / dH` — диференціальна магнітна проникність.
