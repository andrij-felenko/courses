# 📋 Довідник параметрів, коефіцієнтів та розрахунку втрат у сердечниках

Цей довідник містить фундаментальні рівняння, розширені таблиці електрофізичних констант, методи вимірювання втрат на вихрові струми у ферромагнетиках (апарат Епштейна та апарат однолистового випробувача SST), емпіричні розрахункові моделі Штейнмеца для несинусоїдальних сигналів (MSE, iSE, NSE), а також повний алгоритм розрахунку теплового балансу та температури перегріву трансформаторних сердечників.

### 1. Зведені формули та параметри теорії вихрових струмів

Вихрові струми виникають у будь-якому суцільному або шихтованому провіднику, який знаходиться у змінному магнітному полі. Нижче наведено базову систему параметрів, що описують електромагнітну дифузію, скін-ефект та енергетичну дисипацію.

| Величина / Параметр | Позначення, одиниці | Фізична формула | Фізичний зміст та умови застосування |
| :--- | :--- | :--- | :--- |
| **Глибина скін-шару** | `δ` (м, мм) | `δ = √( 2 / (ω · μ · σ) )` | Товщина приповерхневого шару, у якому густина струму спадає в `e ≈ 2.718` разів. Плоска хвиля, `σ = const`. |
| **Магнітна дифузійність** | `D_m` (м²/с) | `D_m = 1 / (μ · σ)` | Швидкість розповсюдження магнітного фронту вглиб металу. Аналог коефіцієнта температурній дифузії. |
| **Питомі втрати на вихрові струми (об'єм)** | `P_e` (Вт/м³) | `P_e = (π² / 6) · σ · d² · f² · B_0²` | Розраховано для пластини товщиною `d << δ` у паралельному синусоїдальному полі `B_0`. |
| **Питомі втрати на вихрові струми (маса)** | `p_e` (Вт/кг) | `p_e = (π² / (6 · ρ_m · ρ_e)) · d² · f² · B_0²` | `ρ_m` — масова густина (кг/м³), `ρ_e` — питомий електричний опір (Ом·м). |
| **Постійна часу дифузії поля** | `τ_diff` (с) | `τ_diff = μ · σ · d²` | Характерний час затухання вихрових струмів після скачкоподібного вимкнення зовнішнього поля. |
| **Питомі втрати на гістерезис** | `P_h` (Вт/м³) | `P_h = K_h · f · B_0^n` | Дисипація на переорієнтацію магнітних доменів. Показник `n ≈ 1.6 – 2.2` (константа Штейнмеца). |
| **Аномальні (надлишкові) втрати** | `P_exc` (Вт/м³) | `P_exc = K_exc · f^1.5 · B_0^1.5` | Втрати, викликані мікроскопічним вихровим рухом навколо рухомих 180-градусних доменних стінок. |
| **Повні об'ємні втрати сердечника** | `P_total` (Вт/м³) | `P_total = P_h + P_e + P_exc` | Трикомпонентний поділ Бертотті (Bertotti loss separation model). |

### 2. Електрофізичні властивості матеріалів та глибина скін-шару (δ)

### 3. Методи вимірювання втрат: апарат Епштейна та SST

Для отримання паспортизованих характеристик втрат у листових електротехнічних сталях згідно зі міжнародним стандартом **IEC 60404-2** застосовуються два стандартизовані лабораторні прилади:

#### Апарат Епштейна (Epstein Frame)
Апарат складається з чотирьох однакових катушечних секцій, з'єднаних у квадратний рамковий контур. Усередину катушок закладаються смуги досліджуваної сталі завдовжки 280–300 мм і шириною 30 мм, розбіг яких на кутах збирається вперекришку. 

Прилад містить дві первинні обмотки (намагнічувальні) та дві вторинні (вимірювальні). Втрати обчислюються ватметровим методом через миттєвий добуток первинного струму `i_1(t)` та вторинної напруги `e_2(t)`:

```
P_loss = ( N_1 / N_2 ) · ( 1 / T ) · ∫₀^T i_1(t) · e_2(t) dt
```

Після віднімання втрат на опір первинних обмоток та зважування зразка отримують питомі втрати у Вт/кг (наприклад, параметр `P_1.5/50` означає питомі втрати при індукції 1.5 Тл та частоті 50 Гц).

#### Апарат однолистового випробувача (Single Sheet Tester, SST)
Згідно з IEC 60404-3, прилад SST дозволяє вимірювати втрати на одному великому цілісному листі сталі (розміром 500 × 500 мм) без його розрізання на дрібні смуги. Лист замикається подвійним масивним П-подібним ярмом із товстих пластин пермалою. Напруженість магнітного поля `H(t)` вимірюється за допомогою плоских поверхневих котушок Роговського або датчиків Голла, розміщених безпосередньо на поверхні листа, що усуває кутові похибки стиків.

### 4. Розрахункові емпіричні моделі втрат Штейнмеца (SE, MSE, iSE, NSE)

При синусоїдальному намагнічуванні для розрахунку повних об'ємних втрат використовується **класичне рівняння Штейнмеца (Steinmetz Equation, SE)**:

```
P_v = K · f^α · B_max^β  [кВт/м³]
```

де `f` — частота у кілогерцах (кГц), `B_max` — пікова індукція у теслах (Тл), а `K, α, β` — матеріальні параметри.

Проте у сучасній імпульсній силовій електроніці (DC-DC перетворювачах, мостових інверторах) напруга на трансформаторі має форму прямокутних меандрів із регульованою паузою (PWM), де швидкість зміни поля `dB / dt` є константою на інтервалі імпульсу і різко зростає при перемиканні ключових транзисторів.

Для розрахунку втрат при несинусоїдальних сигналах розроблені три послідовні модифікації:

#### 1. Модифіковане рівняння Штейнмеца (Modified Steinmetz Equation, MSE)
Вводить концепцію еквівалентної частоти `f_eq`, яка обчислюється через інтеграл квадрата швидкості зміни індукції:

```
f_eq = ( 2 / (π² · B_max²) ) · ∫₀^T ( dB / dt )² dt
P_v = ( K · f_eq^(α - 1) · B_max^β ) · f_sw
```
де `f_sw` — частота перемикання імпульсного перетворювача.

#### 2. Покращена узагальнена формула Штейнмеца (improved Generalized Steinmetz Equation, iSE)
Усуває недоліки MSE при роботі з паузами (постійною індукцією `dB/dt = 0`), інтегруючи миттєві втрати вздовж траєкторії петлі намагнічування:

```
P_v = ( 1 / T ) · ∫₀^T k_i · | dB / dt |^α · ( ΔB )^(β - α) dt
```
де `ΔB = 2 · B_max` — розмах індукції від піку до піку, а коефіцієнт `k_i` виражається через стандартизовані параметри Штейнмеца:

```
k_i = K / [ (2π)^(α - 1) · ∫₀^(2π) |cos θ|^α · 2^(β - α) dθ ]
```

#### 3. Природне розширення Штейнмеца (Natural Steinmetz Extension, NSE)
Особливо ефективне для прямокутних напруг із довільною тривалістю імпульсу (duty cycle `D`):

```
P_v = K · f_sw^α · B_max^β · [ (2 / π)^α · ( D^(1 - α) + (1 - D)^(1 - α) ) ]
```

### 6. Алгоритм розрахунку втрат та теплового балансу сердечника

Розрахунок силового трансформатора або дроселя вимагає спільної оцінки електромагнітних втрат та теплового розсіювання для запобігання перегріву вище класу нагрівостійкості ізоляції (Class B — 130 °C, Class F — 155 °C, Class H — 180 °C).

```
[Вихідні дані: U_rms, f, форма] ──> [Розрахунок B_max за законом Фарадея]
                                             │
                                             ▼
[Оцінка скін-шару δ = √(2/(ωμσ))] ──> [Перевірка умови d ≤ 2δ]
                                             │
                                             ▼
[Розрахунок P_total = P_h + P_e] ──> [Обчислення теплового опору R_th]
                                             │
                                             ▼
[Визначення перегріву ΔT = P · R_th] ──> [Перевірка умови ΔT ≤ ΔT_max]
```

#### Крок 1: Обчислення робочої індукції B_max
За законом Фарадея для синусоїдальної напруги:

```
B_max = U_rms / ( 4.44 · f · N_turns · A_fe )  [Тл]
```
де `A_fe` — ефективна площа перерізу магнітопроводу (м²), `N_turns` — кількість витків обмотки.

#### Крок 2: Оцінка скін-шару
Перевіряється товщина пластини `d` відносно скін-шару `δ`. Якщо `d > 2δ`, питомі вихрові втрати обчислюються з урахуванням екранування поля у центрі пластини за формулою Давелла (Dowell's equation):

```
F_R = ξ · [ ( sinh(2ξ) + sin(2ξ) ) / ( cosh(2ξ) - cos(2ξ) ) ]
```
де `ξ = d / δ`.

#### Крок 3: Розрахунок втрат у сердечнику та обмотках
Повні втрати у трансформаторі `P_loss` складаються з втрат у магнітопроводі `P_core = P_v · V_fe` та втрат у міді обмоток `P_cu = I_rms² · R_ac` (де `R_ac` враховує скін-ефект та ефект близькості у провідниках обмотки).

#### Крок 4: Розрахунок теплового опору та температури перегріву
Тепловий опір сердечника відносно довкілля `R_th` (°C/Вт) оцінюється за емпіричною формулою поверхневої конвекції та випромінювання:

```
R_th = 1 / ( h_total · A_surface )
```
де `A_surface` — відкрита площа поверхні випромінювання сердечника (м²), а сумарний коефіцієнт тепловіддачі `h_total = h_conv + h_rad`:
- Для природної повітряної конвекції `h_conv ≈ 8–12 Вт/(м²·°C)`.
- Для променистого випромінювання за законом Стефана — Больцмана `h_rad = 4 · ε_em · σ_SB · T_avg³ ≈ 5–7 Вт/(м²·°C)` (де `ε_em ≈ 0.9` — ступінь чорноти оксидованого сердечника).

Усереднений перегрів поверхні сердечника над температурою довкілля `T_amb`:

```
ΔT_surface = P_loss · R_th = P_loss / ( h_total · A_surface )  [°C]
```

Температура «гарячої точки» (Hot Spot) у центрі об'єму сердечника `T_center` перевищує поверхневу температуру за рахунок внутрішнього теплового опору матеріалу:

```
T_center = T_surface + ( P_v · R_eff² ) / ( 4 · k_th )
```
де `k_th` — коефіцієнт теплопровідності сердечника (`k_th ≈ 20–40 Вт/(м·°C)` вздовж пластин сталі, `k_th ≈ 3–5 Вт/(м·°C)` для ферітів), а `R_eff` — ефективний еквівалентний радіус сердечника.
