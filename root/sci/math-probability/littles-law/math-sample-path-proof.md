# 🧮 Строге доведення закону Літтла за вибірковими траєкторіями

Найпрозоріший та водночас математично строгий спосіб доведення закону Літтла базується на **методі вибіркових траєкторій** (англ. *sample path analysis*), запропонованому Шейлером Стідгемом у 1974 році. На відміну від класичних імовірнісних методів середини XX століття, які вимагали складної теорії випадкових процесів і марковських ланцюгів, аналіз вибіркових траєкторій розглядає конкретну детерміністичну реалізацію процесу в часі, не накладаючи жодних обмежень на ймовірнісні розподіли інтервалів надходження чи часу обслуговування.

## Формалізація вхідних величин та індикаторні функції

Розгляньмо довільну систему обслуговування як відкритий або закритий контур на інтервалі спостереження від `t = 0` до `t = T`. Припустимо для простоти викладу, що в початковий момент часу система була порожньою: `N(0) = 0`.

Уведемо базові лічильні функції та характеристики процесу:
- `A(t)` — кількість заявок, що надійшли в систему на проміжку часу `[0, t]`;
- `D(t)` — кількість заявок, що повністю завершили обслуговування та залишили систему на проміжку `[0, t]`;
- `N(t) = A(t) − D(t)` — миттєва кількість заявок усередині системи в момент часу `t`.

Для кожної окремої заявки з порядковим номером `i` (де `i = 1, 2, 3, …`):
- `t_in(i)` — точний момент надходження заявки в систему (`0 ≤ t_in(1) ≤ t_in(2) ≤ …`);
- `t_out(i)` — точний момент остаточного виходу заявки із системи (`t_out(i) ≥ t_in(i)`);
- `W_i = t_out(i) − t_in(i)` — повний час перебування (англ. *residence time / response time*) заявки `i` в системі.

Стан присутності заявки `i` в системі в момент часу `t` можна строго описати за допомогою індикаторної функції:

```
I_i(t) = 1,  якщо  t_in(i) ≤ t < t_out(i)
I_i(t) = 0,  в іншому разі
```

Тоді миттєва кількість заявок у системі `N(t)` у будь-який момент часу `t` є прямою сумою індикаторів усіх заявок, що надійшли до цього моменту:

```
N(t) = ∑_{i=1}^{A(t)} I_i(t)
```

## Подвійний підрахунок площі та зміна порядку інтегрування

Сумарний людино-час (або процесоро-секунди), накопичений усіма заявками всередині системи на проміжку `[0, T]`, задається визначеним інтегралом від ступінчастої функції кількості заявок `N(t)`:

```
S(T) = ∫₀ᵀ N(t) dt
```

Підставимо в цей інтеграл вираз для `N(t)` через індикаторні функції:

```
S(T) = ∫₀ᵀ ( ∑_{i=1}^{A(T)} I_i(t) ) dt
```

Оскільки сума є скінченною на будь-якому обмеженому проміжку часу `[0, T]`, ми маємо повне математичне право змінити порядок інтегрування та сумування (теорема Фубіні для скінченних сум):

```
S(T) = ∑_{i=1}^{A(T)} ( ∫₀ᵀ I_i(t) dt )
```

Обчислімо внутрішній інтеграл `∫₀ᵀ I_i(t) dt` для кожної окремої заявки `i`. Цей інтеграл вимірює тривалість перебування заявки `i` всередині часового вікна `[0, T]`.

Розгляньмо дві групи заявок:

1. **Заявки, що повністю завершили обслуговування до моменту `T` (тобто `t_out(i) ≤ T`):**
   Кількість таких заявок дорівнює `D(T)`. Для кожної з них весь інтервал `[t_in(i), t_out(i)]` повністю лежить усередині `[0, T]`, тому:
```
∫₀ᵀ I_i(t) dt = t_out(i) − t_in(i) = W_i
```

2. **Заявки, що надійшли до моменту `T`, але ще не завершилися (`t_in(i) ≤ T < t_out(i)`):**
   Ці заявки перебувають у системі в момент закінчення спостереження `T`. Їхній внесок у часовий інтеграл дорівнює лише частковому інтервалу `T − t_in(i)`, що строго не перевищує повний час `W_i`:
```
∫₀ᵀ I_i(t) dt = T − t_in(i) ≤ W_i
```

## Двостороння геометрична нерівність

Зіставляючи дві групи заявок, отримуємо точну двосторонню нерівність для площі під графіком зайнятості:

1. Нижня оцінка: площа `S(T)` містить щонайменше повні тривалості всіх заявок, які вже вийшли із системи до моменту `T`:
```
S(T) ≥ ∑_{i=1}^{D(T)} W_i
```

2. Верхня оцінка: площа `S(T)` не може перевищувати суму повних тривалостей усіх заявок, які хоча б розпочали обслуговування до моменту `T`:
```
S(T) ≤ ∑_{i=1}^{A(T)} W_i
```

Об'єднуючи обидві оцінки, формулюємо строгу границю площі:

```
∑_{i=1}^{D(T)} W_i  ≤  ∫₀ᵀ N(t) dt  ≤  ∑_{i=1}^{A(T)} W_i
```

## Нормування за часом спостереження

Поділимо всі три частини фундаментальної нерівності на довжину інтервалу спостереження `T`:

```
(1 / T) · ∑_{i=1}^{D(T)} W_i  ≤  (1 / T) · ∫₀ᵀ N(t) dt  ≤  (1 / T) · ∑_{i=1}^{A(T)} W_i
```

Центральний член цієї нерівності за визначенням є середньою за часом кількістю заявок у системі на інтервалі `[0, T]`:

```
L_T = (1 / T) · ∫₀ᵀ N(t) dt
```

Перетворимо ліву та праву частини нерівності, помноживши та поділивши їх на відповідну кількість подій `D(T)` та `A(T)`:

```
[ D(T) / T ] · [ (1 / D(T)) · ∑_{i=1}^{D(T)} W_i ]  ≤  L_T  ≤  [ A(T) / T ] · [ (1 / A(T)) · ∑_{i=1}^{A(T)} W_i ]
```

У цих виразах чітко відокремлено два фізичні фактори:
- Частотні характеристики потоку: `D(T) / T` (інтенсивність виходу) та `A(T) / T` (інтенсивність входу);
- Вибіркові середні часу перебування: `(1 / D(T)) ∑ W_i` та `(1 / A(T)) ∑ W_i`.

## Граничні переходи та умови регулярності

Тепер спрямуємо час спостереження до нескінченності (`T → ∞`) за виконання стандартних умов стаціонарності та ергодичності системи:

1. **Існування середньої швидкості надходження:**
   Середня кількість вхідних заявок за одиницю часу збігається до стаціонарної інтенсивності `λ`:
```
lim_{T → ∞} [ A(T) / T ] = λ  > 0
```

2. **Закон збереження потоку (стабільність черги):**
   Кількість незавершених заявок усередині системи `N(T) = A(T) − D(T)` зростає повільніше за лінійну швидкість часу `T`, тобто частка застряглих запитів на нескінченності прямує до нуля:
```
lim_{T → ∞} [ (A(T) − D(T)) / T ] = 0
```
Звідси швидкість виходу асимптотично збігається зі швидкістю входу:
```
lim_{T → ∞} [ D(T) / T ] = lim_{T → ∞} [ A(T) / T ] = λ
```

3. **Існування середнього часу перебування:**
   Послідовність індивідуальних часів перебування `W_i` має скінченне вибіркове середнє `W`:
```
lim_{K → ∞} (1 / K) · ∑_{i=1}^{K} W_i = W  < ∞
```

## Доведення за теоремою про затиснуту границю

Застосуємо теорему про границю добутку до лівої та правої меж нашої нерівності при `T → ∞`:

```
Ліва межа:
lim_{T → ∞} ( [ D(T) / T ] · [ (1 / D(T)) · ∑_{i=1}^{D(T)} W_i ] )
= [ lim_{T → ∞} (D(T) / T) ] · [ lim_{T → ∞} ((1 / D(T)) · ∑_{i=1}^{D(T)} W_i) ]    [теорема про границю добутку]
= λ · W                                                                             [підстановка граничних значень]

Права межа:
lim_{T → ∞} ( [ A(T) / T ] · [ (1 / A(T)) · ∑_{i=1}^{A(T)} W_i ] )
= [ lim_{T → ∞} (A(T) / T) ] · [ lim_{T → ∞} ((1 / A(T)) · ∑_{i=1}^{A(T)} W_i) ]    [теорема про границю добутку]
= λ · W                                                                             [підстановка граничних значень]
```

Оскільки вибіркова середня заповненість системи `L_T` обмежена знизу і зверху функціями, які мають однакову скінченну границю `λ · W`:

```
λ · W  ≤  lim_{T → ∞} L_T  ≤  λ · W
```

За математичною теоремою про затиснуту границю (теоремою про двох міліціонерів) границя `L = lim_{T → ∞} L_T` обов'язково існує і строго дорівнює:

```
L = λ · W
```

Це завершує формальне доведення.

## Аналіз залишкового члена та крайових умов

Щоб глибше зрозуміти, чому закон Літтла може не виконуватися на коротких інтервалах спостереження, проаналізуємо різницю між площею інтеграла `S(T)` та добутком `D(T) · W`:

```
Δ(T) = ∫₀ᵀ N(t) dt − ∑_{i=1}^{D(T)} W_i
```

Ця величина `Δ(T)` являє собою сумарний час, який заявки, що все ще залишаються в системі в момент `T`, уже встигли провести всередині контуру. Кількість таких заявок дорівнює `N(T) = A(T) − D(T)`.

Оскільки час перебування кожної незавершеної заявки до моменту `T` не перевищує повного часу її обслуговування `W_i`:

```
0 ≤ Δ(T) ≤ ∑_{i=D(T)+1}^{A(T)} W_i ≤ N(T) · max_{D(T) < i ≤ A(T)} W_i
```

Поділивши на `T`, маємо:

```
0 ≤ Δ(T) / T ≤ [ N(T) / T ] · max W_i
```

Якщо система є стаціонарною і стабільною, черга `N(T)` залишається обмеженою випадковою величиною, тому дріб `N(T) / T` прямує до 0 зі швидкістю `O(1/T)`. Відповідно, похибка оцінки `Δ(T) / T` зникає.

Проте якщо система потрапляє в режим катастрофічного перевантаження (`λ > μ`), кількість заявок у черзі зростає лінійно з часом: `N(T) ≈ (λ − μ) · T`. У такому разі відношення `N(T) / T` прямує до додатної константи `(λ − μ) > 0`, залишковий член не зникає, а середній час очікування `W` прямує до нескінченності. Це чітко окреслює точну математичну межу застосовності закону Літтла: збереження стаціонарного потоку є необхідною і достатньою умовою існування формули.
