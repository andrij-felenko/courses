# 🧮 Математичні методи оцінки квантилів на вибірках

Для неперервної теоретичної випадкової величини квантиль порядку `p ∈ (0, 1)` визначається однозначно як розв'язок рівняння `F(x) = p`, де `F(x)` — кумулятивна функція розподілу. Проте коли ми маємо скінченну вибірку з `N` дискретних спостережень `x[1], x[2], ..., x[N]`, обчислення квантиля перетворюється на задачу оцінювання невідомого параметра генеральної сукупності. Якщо впорядкувати вибірку за зростанням так, що `x[1] ≤ x[2] ≤ ... ≤ x[N]`, номер шуканого спостереження `h = p · (N - 1) + 1` майже ніколи не є цілим числом.

У статистичній практиці існує щонайменше дев'ять різних математичних методів інтерполяції для обчислення вибіркового квантиля. У фундаментальній праці 1996 року Роберт Гайндман (Rob J. Hyndman) та Яньань Фен (Yanan Fan) класифікували ці підходи на дві групи: три розривні методи на основі порядкових номерів (типи R-1, R-2, R-3) та шість неперервних методів лінійної інтерполяції (типи R-4 ... R-9).

## Теоретичний зв'язок порядкових статистик із бета-розподілом

Щоб зрозуміти, звідки беруться різні формули інтерполяції, розглянемо вибірку з `N` незалежних випадкових величин, рівномірно розподілених на відрізку `[0, 1]`. Нехай `U_(1) ≤ U_(2) ≤ ... ≤ U_(N)` — відповідні порядкові статистики.

Ймовірність того, що `k`-та порядкова статистика `U_(k)` не перевищує значення `u ∈ [0, 1]`, дорівнює ймовірності того, що щонайменше `k` із `N` спостережень потраплять у відрізок `[0, u]`. Це підпорядковується біноміальному закону:

```
F_{U_(k)}(u) = ∑_{j=k}^{N} C(N, j) · u^j · (1 - u)^(N - j)
```

Диференціюючи цю суму за змінною `u`, отримуємо щільність імовірності `k`-ї порядкової статистики, яка точно збігається з бета-розподілом із параметрами `k` та `N - k + 1`:

```
f_{U_(k)}(u) = (N! / ((k - 1)! · (N - k)!)) · u^(k - 1) · (1 - u)^(N - k)
```

Звідси математичне сподівання та медіана `k`-ї порядкової статистики для стандартного рівномірного розподілу дорівнюють:

```
E[U_(k)] = k / (N + 1)
Med[U_(k)] ≈ (k - 1/3) / (N + 1/3)
```

Саме ці дві теоретичні величини лежать в основі вибору точок прив'язки для методів інтерполяції R-6 (метод Вейбулла на основі математичного сподівання) та R-8 (метод на основі медіани порядку).

## Загальна формула лінійної інтерполяції

Усі шість неперервних методів використовують єдиний математичний каркас. Для заданої частки `p` обчислюється дійсний індекс `h`. Нехай `j = ⌊h⌋` — ціла частина індексу (ціле число, за якого `1 ≤ j < N`), а `γ = h - j` — дробовий залишок (`0 ≤ γ < 1`). Оцінка квантиля `Q(p)` обчислюється як зважена комбінація двох сусідніх порядкових статистик `x[j]` та `x[j+1]`:

```
Q(p) = (1 - γ)·x[j] + γ·x[j+1]
```

Різниця між шістьма неперервними методами полягає виключно у формулі розрахунку дійсного індексу `h` залежно від розміру вибірки `N` та параметрів зсуву `m` і `A`:

```
h = p·(N + A) + m
```

де значення констант `A` та `m` визначають граничну поведінку та властивості незміщеності оцінки.

## Класифікація дев'яти методів Гайндмана-Фена

### Розривні методи (Nearest Rank)

1. **Тип R-1 (Інверсія емпіричної функції розподілу):**
   Дійсний індекс обчислюється як `h = p·N`. Якщо дробова частина дорівнює нулю, береться значення `x[h]`, інакше береться `x[⌊h⌋ + 1]`. Цей метод є точним відображенням східчастої функції розподілу без будь-якого згладжування.

2. **Тип R-2 (Інверсія з усередненням на розривах):**
   Аналогічно до R-1, але якщо `p·N` є цілим числом, береться середнє арифметичне двох сусідніх точок: `(x[h] + x[h+1]) / 2`.

3. **Тип R-3 (Найближче ціле парне число):**
   Індекс округлюється до найближчого цілого `⌊p·N + 0.5⌋`. Якщо значення лежить посередині, округлення ведеться до найближчого парного індексу.

### Неперервні інтерполяційні методи

4. **Тип R-4 (Лінійна інтерполяція за точками `p[k] = k / N`):**
   Параметр індексу: `h = p·N`. Дробова частина `γ = h - ⌊h⌋`. Припускає, що спостереження ділять імовірнісну масу на рівні відрізки без урахування кінцевих інтервалів.

5. **Тип R-5 (Лінійна інтерполяція за точками `p[k] = (k - 0.5) / N`):**
   Параметр індексу: `h = p·N + 0.5`. Припускає, що кожне спостереження репрезентує середину свого ймовірнісного відрізка довжиною `1 / N`. Медіана `p = 0.5` на цьому методі точно збігається зі стандартним вибірковим значенням `(x[N/2] + x[N/2 + 1]) / 2`.

6. **Тип R-6 (Формула Вейбулла `p[k] = k / (N + 1)`):**
   Параметр індексу:
   ```
   h = p·(N + 1)
   ```
   Цей метод використовує математичне сподівання порядкових статистик `E[U_(k)] = k / (N + 1)`. Він є стандартом за замовчуванням у Microsoft Excel під назвою `PERCENTILE.EXC`, а також у пакетах Minitab та SPSS.

7. **Тип R-7 (Стандарт NumPy, Python `statistics.quantiles`, Excel `PERCENTILE.INC`, R):**
   Параметр індексу:
   ```
   h = p·(N - 1) + 1
   ```
   Цей метод прив'язує мінімум `x[1]` точно до `p = 0`, а максимум `x[N]` точно до `p = 1`. Завдяки цьому квантиль завжди потрапляє всередину діапазону вибірки без виходу за межі даних для будь-якого `p ∈ [0, 1]`.

8. **Тип R-8 (Незміщена оцінка медіани порядку):**
   Параметр індексу:
   ```
   h = p·(N + 1/3) + 1/3
   ```
   Метод використовує апроксимацію медіани бета-розподілу `Med[U_(k)] ≈ (k - 1/3) / (N + 1/3)`. Він забезпечує мінімальне зміщення оцінки `Q(p)` для довільних неперервних розподілів незалежно від їхньої форми.

9. **Тип R-9 (Незміщена оцінка для нормального розподілу):**
   Параметр індексу:
   ```
   h = p·(N + 1/4) + 3/8
   ```
   Метод базується на формулі Блома для нормального розподілу, даючи найточніше наближення до теоретичних квантилів генеральної сукупності за умови нормальності вихідних даних.

## Числовий приклад розрахунку квантиля на малій вибірці

Розглянемо вибірку з десяти вимірювань затримки запитів у мілісекундах:

```
N = 10
x = [12, 15, 18, 22, 29, 35, 44, 58, 85, 190]
```

Знайдемо 90-й перцентиль (`p = 0.90`) трьома поширеними методами:

**1. Обчислення за методом R-7 (NumPy / Excel INC):**

```
h = p·(N - 1) + 1
= 0.90·(10 - 1) + 1      [підставили p = 0.90, N = 10]
= 0.90·9 + 1             [обчислили добуток у дужках]
= 8.1 + 1                [виконали множення]
= 9.1                    [знайшли дійсний індекс h]

j = ⌊9.1⌋ = 9
γ = 9.1 - 9 = 0.1

Q_7(0.90) = (1 - 0.1)·x[9] + 0.1·x[10]
= 0.9·85 + 0.1·190       [підставили x[9] = 85, x[10] = 190]
= 76.5 + 19.0            [виконали множення доданків]
= 95.5 мс                [підсумковий результат R-7]
```

**2. Обчислення за методом R-6 (Excel EXC / Вейбулл):**

```
h = p·(N + 1)
= 0.90·(10 + 1)          [підставили параметри]
= 0.90·11                [додали одиницю в дужках]
= 9.9                    [знайшли дійсний індекс h]

j = ⌊9.9⌋ = 9
γ = 9.9 - 9 = 0.9

Q_6(0.90) = (1 - 0.9)·x[9] + 0.9·x[10]
= 0.1·85 + 0.9·190       [підставили значення вибірки]
= 8.5 + 171.0            [обчислили доданки]
= 179.5 мс               [підсумковий результат R-6]
```

**3. Обчислення за методом R-8 (незміщений):**

```
h = p·(N + 1/3) + 1/3
= 0.90·(10 + 0.3333) + 0.3333   [підставили формулу R-8]
= 0.90·10.3333 + 0.3333         [додали дріб у дужках]
= 9.300 + 0.3333                [обчислили добуток]
= 9.6333                        [знайшли дійсний індекс h]

j = 9
γ = 0.6333

Q_8(0.90) = (1 - 0.6333)·85 + 0.6333·190
= 0.3667·85 + 0.6333·190        [підставили значення]
= 31.17 + 120.33                [обчислили доданки]
= 151.5 мс                      [підсумковий результат R-8]
```

Різниця між оцінкою R-7 (95.5 мс) та R-6 (179.5 мс) для однієї вибірки сягає майже 88%. Це наочно демонструє, що на малих вибірках вибір математичного методу інтерполяції має вирішальне значення.

## Непараметричні довірчі інтервали для квантилів

Оскільки вибірковий квантиль є точковою оцінкою, він має випадкову похибку. Для неперервного розподілу можна побудувати точний довірчий інтервал без знання теоретичного закону розподілу, використовуючи біноміальний розподіл порядкових статистик.

Кількість спостережень у вибірці, які менші або дорівнюють істинному квантилю `Q(p)`, є випадковою величиною `K`, яка підпорядковується біноміальному розподілу з параметрами `N` та `p`:

```
K ~ Binomial(N, p)
```

Ймовірність того, що істинний квантиль `Q(p)` лежить між двома порядковими статистиками `x[r]` та `x[s]` (де `1 ≤ r < s ≤ N`), дорівнює ймовірності того, що кількість спостережень менших за `Q(p)` лежить у діапазоні від `r` до `s - 1`:

```
P(x[r] ≤ Q(p) ≤ x[s]) = ∑_{k=r}^{s-1} C(N, k) · p^k · (1 - p)^(N - k)
```

де `C(N, k) = N! / (k! · (N - k)!)` — біноміальний коефіцієнт.

Для вибірки розміром `N = 100` та медіани `p = 0.50`:
Якщо обрати порядкові статистики `r = 40` та `s = 61`, сумарна біноміальна ймовірність становить:

```
P(x[40] ≤ Q(0.50) ≤ x[61]) ≈ 0.965  (96.5% довірчий інтервал)
```

Це означає, що з імовірністю 96.5% справжня генеральна медіана гарантовано перебуває між 40-м та 61-м упорядкованими елементами зафіксованої вибірки без будь-яких припущень про форму розподілу.
