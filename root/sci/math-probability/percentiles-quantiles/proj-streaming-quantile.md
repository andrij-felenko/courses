# ⚙️ Однопрохідна оцінка квантилів у потоці даних

Обчислення точного вибіркового квантиля вимагає збереження всіх `N` спостережень у пам'яті та їх повного сортування за час `O(N log N)`. Для високонавантажених мережевих шлюзів, брокерів повідомлень та систем моніторингу, які обробляють мільйони запитів на секунду, такий підхід непридатний: пам'ять сервера швидко вичерпується, а накладні витрати на синхронізацію уповільнюють виконання цільових задач.

Для розв'язання цієї проблеми в 1985 році Радж Джайн (Raj Jain) та Імріх Хламтак (Imrich Chlamtac) розробили алгоритм **P²** (*Piecewise-Parabolic Quantile Estimation*). Алгоритм відстежує заданий квантиль `p ∈ (0, 1)` за один прохід по даних, використовуючи лише `O(1)` пам'яті (рівно п'ять числових маркерів) і виконуючи кожне оновлення за сталий час `O(1)`.

## Математична основа параболічної інтерполяції трьох точок

Алгоритм P² спирається на апроксимацію емпіричної функції квантилів за допомогою кусочно-параболічної інтерполяції. Замість зберігання мільйонів чисел алгоритм відстежує рух п'яти маркерів `q[0], q[1], q[2], q[3], q[4]`, які відповідають характерним квантилям:
- `q[0]` — мінімальне спостереження вибірки (квантиль `0`);
- `q[1]` — проміжний маркер порядку `p / 2`;
- `q[2]` — цільовий маркер порядку `p`;
- `q[3]` — проміжний маркер порядку `(1 + p) / 2`;
- `q[4]` — максимальне спостереження вибірки (квантиль `1`).

Кожен маркер `i` має три характеристики:
1. `q[i]` — поточна висота маркера (оцінка значення затримки чи вимірюваної величини).
2. `n[i]` — фактична цілочисельна позиція маркера у віртуально відсортованому масиві з `N` елементів (`1 ≤ n[i] ≤ N`).
3. `n_prime[i]` — ідеальна дійсна позиція маркера при поточному розмірі вибірки `N`.

Ідеальні позиції для п'яти маркерів обчислюються за формулою:

```
n_prime[0] = 1
n_prime[1] = 1 + 2·p·(N - 1)
n_prime[2] = 1 + p·(N - 1)
n_prime[3] = 1 + (1 + p)·(N - 1) / 2
n_prime[4] = N
```

При надходженні кожного нового спостереження `x` фактичні позиції деяких маркерів зміщуються. Коли накопичене відхилення між ідеальною та фактичною позицією `d = n_prime[i] - n[i]` сягає одиниці (`|d| ≥ 1`), маркер `i` необхідно зсунути на одну позицію ліворуч (`d = -1`) або праворуч (`d = +1`).

Щоб оцінити нову висоту `q[i]` при зсуві позиції на `d = ±1`, алгоритм будує параболу Лагранжа через три сусідні точки `(n[i-1], q[i-1])`, `(n[i], q[i])` та `(n[i+1], q[i+1])`:

```
q_new = q[i] + (d / (n[i+1] - n[i-1])) · [
    (n[i] - n[i-1] + d) · (q[i+1] - q[i]) / (n[i+1] - n[i]) +
    (n[i+1] - n[i] - d) · (q[i] - q[i-1]) / (n[i] - n[i-1])
]
```

Якщо обчислена параболічна висота порушує природну монотонність впорядкованого ряду (`q[i-1] < q_new < q[i+1]`), алгоритм відкидає параболу і застосовує лінійну інтерполяцію між маркером `i` та його сусідом `i + d`:

```
q_linear = q[i] + d · (q[i+d] - q[i]) / (n[i+d] - n[i])
```

Такий комбінований механізм забезпечує високу гладкість оцінки при дотриманні строгих інваріантів монотонності.

## Покроковий числовий приклад роботи алгоритму

Щоб побачити механізм у дії, простежимо поведінку структури для обчислення 90-го перцентиля (`p = 0.90`) на перших спостереженнях:

1. **Фаза ініціалізації:** надходять перші 5 значень: `10, 15, 20, 25, 30`. Вони сортуються у масив `q = [10, 15, 20, 25, 30]`.
   Фактичні позиції: `n = [1, 2, 3, 4, 5]`.
   Прирости бажаних позицій `dn`:
   - `dn[0] = 0.0`
   - `dn[1] = 0.90 / 2 = 0.45`
   - `dn[2] = 0.90`
   - `dn[3] = (1.0 + 0.90) / 2 = 0.95`
   - `dn[4] = 1.0`
   Початкові бажані позиції `n_prime = [1.0, 1.0 + 4·0.45, 1.0 + 4·0.90, 1.0 + 4·0.95, 5.0] = [1.0, 2.8, 4.6, 4.8, 5.0]`.

2. **Надходження 6-го спостереження (`x = 35`):**
   Оскільки `x ≥ q[4]`, новий максимум стає `q[4] = 35`, інтервал `k = 3`.
   Фактична позиція `n[4]` збільшується на одиницю (`n[4] = 6`).
   Бажані позиції збільшуються на `dn`: `n_prime = [1.0, 3.25, 5.5, 5.75, 6.0]`.
   Перевіряємо маркер 2 (цільовий `p = 0.90`):
   Відхилення `d = n_prime[2] - n[2] = 5.5 - 3 = 2.5 ≥ 1.0`.
   Оскільки сусідня позиція `n[3] = 4`, умова `n[3] - n[2] > 1` на цьому кроці не виконується (маркери стоять впритул), тому маркер 2 залишається на позиції до розсування інтервалу наступними точками.

3. **Надходження наступних спостережень:**
   Маркери поступово розсуваються, параболічна інтерполяція плавно перераховує висоту `q[2]`, наближаючи її до істинного значення 90-го перцентиля без виділення додаткової динамічної пам'яті.

## Порівняння алгоритму P² з альтернативними потоковими методами

1. **Алгоритм Грінвальда-Кханни (Greenwald-Khanna, GK):**
   Алгоритм GK гарантує точну верхню межу похибки `ε` для будь-якого квантиля, зберігаючи кортежі з мінімальними та максимальними рангами. Проте його просторова складність становить `O((1/ε) · log(ε·N))`, тобто розмір структури повільно зростає разом із кількістю спостережень `N`. На відміну від GK, алгоритм P² використовує строго `O(1)` пам'яті.
2. **Алгоритм t-digest (Тед Даннінга):**
   t-digest кластеризує точки у зважені центроїди, розмір яких зменшується на краях розподілу (біля `0` та `1`). Це забезпечує виняткову точність на хвостах (p99.9), але вимагає динамічної буферизації та періодичного сортування центроїдів. P² працює без буферизації та сортування після ініціалізації.
3. **Логарифмічні гістограми (DDSketch / HdrHistogram):**
   DDSketch розбиває числовий простір на логарифмічні кошики, забезпечуючи сталу відносну похибку та можливість паралельного об'єднання гістограм із різних серверів (mergeable sketches). P² відстежує лише один цільовий квантиль на структуру, але не потребує попереднього визначення діапазону значень.

## Обробка крайових випадків та інваріанти

- **Повторювані однакові значення:** коли потік містить велику кількість однакових значень (наприклад, тисячі успішних запитів із фіксованим часом 1 мс), висоти сусідніх маркерів можуть збігтися `q[i] = q[i+1]`. Параболічна інтерполяція в такому разі може дати нульовий або від'ємний приріст. Алгоритм P² автоматично виявляє порушення монотонності `q[i-1] < q_new < q[i+1]` і перемикається на лінійну інтерполяцію, запобігаючи числовим розривам.
- **Дрейф екстремумів:** якщо в потік надходять строго монотонно зростаючі значення, мінімум `q[0]` залишається зафіксованим на першому спостереженні, а `q[4]` постійно оновлюється новим максимумом. Маркери `1, 2, 3` рівномірно слідують за квантилями, підтримуючи точність оцінки.
- **Багатопотокова паралелізація:** оскільки структура P² змінює внутрішні поля `q` та `n` на кожен виклик `update`, прямий виклик з кількох паралельних потоків без блокування призведе до гонки даних. Рекомендований архітектурний патерн — створення локального екземпляра `P2Quantile` для кожного робочого потоку (per-thread instance) або захист єдиного екземпляра атомарним spin-lock, накладні витрати на який мінімальні через малий час операції `O(1)`.
