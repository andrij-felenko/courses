# 📋 Довідник форм нерівності Чернова та інженерних розрахунків меж

Цей довідковий модуль містить систематизовану табличну інформацію щодо варіантів нерівності Чернова, умов їхньої застосовності, форм верхнього та нижнього хвостів, порівняння з суміжними нерівностями концентрації (Маркова, Чебишова, Геффдінга, Бернштейна), а також алгоритмічний інтерфейс мовами C та C++ для автоматичного розрахунку мінімального розміру вибірки `n` при заданій допустимій ймовірності помилки.

## 1. Систематизоване порівняння нерівностей концентрації

При виборі нерівності концентрації для теоретичного аналізу чи розрахунку інженерних параметрів обчислювальної системи розробник повинен виходити з наявних припущень про випадкові величини (наявність обмеженості, незалежності, відомих моментів). У таблиці нижче наведено структуроване зіставлення основних ймовірнісних нерівностей, які використовуються в алгоритмах та теорії складності для аналізу відхилень суми `S♁ = ∑ᵢ₌₁ⁿ Xᵢ` від її очікуваного значення `μ = E[S♁]`.

Застосування кожної нерівності визначається обсягом доступної інформації про випадковий процес. Нерівність Маркова є найменш вимогливою, оскільки потребує лише невід'ємності величини та знання її першого моменту. Вона є незамінним першим кроком при побудові складніших математичних виводів, але у практичній інженерії дає занадто широкі, неоперабельні межі. Нерівність Чебишова вимагає знання другого моменту — дисперсії. Вона чудово працює у ситуаціях, коли додатки мають слабку залежність (наприклад, попарну незалежність), однак її степеневе спадання за законом `O(1/t²)` є недостатньо швидким для підсилення надійності обчислень. Якщо ж величини є сукупно незалежними та обмеженими, нерівності Чернова та Геффдінга забезпечують експоненціально точне згасання хвостів ймовірності, що дозволяє зменшувати ймовірність помилки до величин порядку `10⁻¹⁵`.

| Нерівність | Необхідні умови та припущення | Формула верхньої межі `Pr[S♁ - μ ≥ t]` | Швидкість згасання хвоста | Область оптимального застосування |
| :--- | :--- | :--- | :--- | :--- |
| **Маркова** | `S♁ ≥ 0` (невід'ємна випадкова величина) | `Pr[S♁ ≥ a] ≤ μ / a` | Лінійна: `O(1/a)` | Первинні оцінки, відсутня інформація про вищі моменти |
| **Чебишова** | Скінченна дисперсія `Var[S♁] = σ²` | `Pr[│S♁ - μ│ ≥ t] ≤ σ² / t²` | Степенева: `O(1/t²)` | Відома лише дисперсія, додатки можуть бути залежними |
| **Чернова (Верхній хвіст, точна)** | `Xᵢ ∈ {0,1}` independent Бернуліївські | `Pr[S♁ ≥ (1+δ)μ] ≤ (e^δ / (1+δ)^(1+δ))^μ` | Експоненціальна: `exp(-c · μ)` | Максимально точний аналіз Бернуліївських сум |
| **Чернова (Верхній хвіст, `δ ≤ 1`)** | `Xᵢ ∈ {0,1}` independent Бернуліївські | `Pr[S♁ ≥ (1+δ)μ] ≤ exp(-μ δ² / 3)` | Квадратично-експоненціальна | Зручні теоретичні оцінки відносних відхилень |
| **Чернова (Нижній хвіст, `δ < 1`)** | `Xᵢ ∈ {0,1}` independent Бернуліївські | `Pr[S♁ ≤ (1-δ)μ] ≤ exp(-μ δ² / 2)` | Квадратично-експоненціальна | Гарантії мінімального навантаження або прогресу |
| **Геффдінга (Адитивна)** | independent `aᵢ ≤ Xᵢ ≤ bᵢ` (обмежені) | `Pr[S♁ - μ ≥ t] ≤ exp(-2 t² / ∑ (bᵢ - aᵢ)²)` | Експоненціальна по `t²` | Довільні обмежені неперервні випадкові величини |
| **Бернштейна** | independent `│Xᵢ - E[Xᵢ]│ ≤ M`, відома `Var[S♁] = σ²` | `Pr[S♁ - μ ≥ t] ≤ exp(-t² / (2σ² + 2 M t / 3))` | Експоненціальна (перехідна) | Малі дисперсії `σ² << M t` (покращує Геффдінга) |

## 2. Повний зведення мультиплікативних форм Чернова

Для суми independent Бернуліївських випадкових величин `X = ∑ᵢ₌₁ⁿ Xᵢ` зі зведеним математичним сподіванням `μ = E[X] = ∑ pᵢ` застосовуються наступні математичні вирази залежно від напрямку відхилення та вимог до точності.

### 2.1. Формули верхнього хвоста (`X ≥ (1 + δ)μ`)

1. **Точна MGF-форма (для довільного `δ > 0`):**
   Опис: Найточніша межа, що випливає безпосередньо з мінімізації моментогенеруючої функції за параметром `t* = ln(1 + δ)`. Ця форма є абсолютно суворою і не припускає жодних спрощень. Вона гарантує максимальну щільність оцінки при будь-яких значеннях `δ`.
   ```
   Pr[X ≥ (1 + δ)μ] ≤ ( exp(δ) / (1 + δ)^(1 + δ) )^μ
   ```
2. **Стандартна квадратична форма (для `0 < δ ≤ 1`):**
   Опис: Використовується у більшості алгоритмічних доведень завдяки своїй простоті та симетрії. Вона виведена шляхом розкладу логарифмічного члена у ряд Тейлора та оцінки квадратичного залишкового члена.
   ```
   Pr[X ≥ (1 + δ)μ] ≤ exp( -μ δ² / 3 )
   ```
3. **Універсальна квадратична форма (для всіх `δ > 0`):**
   Опис: Працює для довільно великих відхилень `δ > 1`, поєднуючи квадратичне спадання при малих `δ` та лінійно-експоненціальне при великих.
   ```
   Pr[X ≥ (1 + δ)μ] ≤ exp( -μ δ² / (2 + δ) )
   ```
4. **Форма для великих абсолютних значень (`k ≥ 2e μ`):**
   Опис: Зручна для аналізу пікового навантаження в задачах рівномірного хешування та балансування, коли абсолютна кількість подій `k` значно перевищує очікуване середнє.
   ```
   Pr[X ≥ k] ≤ 2^(-k)
   ```

### 2.2. Формули нижнього хвоста (`X ≤ (1 - δ)μ`)

1. **Точна MGF-форма (для `0 < δ < 1`):**
   Опис: Точний результат мінімізації MGF при від'ємному параметрі `t* = ln(1 - δ) < 0`. Описує ймовірність того, що кількість успіхів буде суттєво меншою за очікувану.
   ```
   Pr[X ≤ (1 - δ)μ] ≤ ( exp(-δ) / (1 - δ)^(1 - δ) )^μ
   ```
2. **Стандартна квадратична форма (для `0 < δ < 1`):**
   Опис: Найвживаніша межа для оцінки ймовірності недосягнення середнього показника в алгоритмах мажоритарного голосування та аналізу глибини дерев.
   ```
   Pr[X ≤ (1 - δ)μ] ≤ exp( -μ δ² / 2 )
   ```

### 2.3. Формули двостороннього хвоста (`│X - μ│ ≥ δ μ`)

Для симетричної оцінки відхилень в обох напрямках одночасно (коли `0 < δ < 1`) поєднання меж верхнього та нижнього хвостів за нерівністю зауваження (Union Bound) дає двосторонній вираз:

```
Pr[│X - μ│ ≥ δ μ] ≤ 2 · exp( -μ δ² / 3 )
```

## 3. Практичні інженерні розрахунки та оцінки вибірки

У розробці рандомізованих алгоритмів, розподілених систем та високонавантажених сервісів нерівність Чернова використовується для вирішення чотирьох фундаментальних інженерних задач.

### 3.1. Підсилення більшості голосів (Probability Amplification / BPP Boosting)

Припустимо, ми маємо ймовірнісний алгоритм, який повертає правильну відповідь із ймовірністю `p = 1/2 + γ`, де `γ > 0` — перевага алгоритму над випадковим вгадуванням.

Щоб зменшити підсумкову ймовірність помилки більшості голосів при `k` незалежних запусках до величини `ε_error`, необхідна кількість повторів `k` обчислюється за формулою:

```
k ≥ ( 3 / (2 γ²) ) · ln( 1 / ε_error )
```

Цей розрахунок лежить у основі проектування підсилювачів надійності для криптографічних протоколів та квантових обчислень, де кожен окремий вимір має високий рівень шуму, але серія з кількох сотень повторів гарантує практично абсолютну точність.

**Таблиця необхідної кількості запусків `k` для різних переваг `γ` та вимог до точності `ε_error`:**

| Перевага `γ` | Ймовірність успіху `p` | Цільова помилка `ε_error` | Необхідна кількість запусків `k` | Інженерний контекст застосування |
| :--- | :--- | :--- | :--- | :--- |
| `0.10` (`10%`) | `0.60` | `10⁻³` (`0.1%`) | `104` запусків | Перевірка цілісності блоків даних у мережевих протоколах |
| `0.10` (`10%`) | `0.60` | `10⁻⁶` (`0.0001%`) | `208` запусків | Криптографічна аутентифікація сесій у розподілених системах |
| `0.05` (`5%`) | `0.55` | `10⁻⁶` (`0.0001%`) | `829` запусків | Тестування простоти великих чисел (тест Міллера — Рабіна) |
| `0.01` (`1%`) | `0.51` | `10⁻⁹` (`10⁻⁷%`) | `310 830` запусків | Визначення кворуму в консенсусних протоколах (Raft/Paxos) |

### 3.2. Концентрація максимального навантаження (Balls & Bins Load Balancing)

Якщо `n` обчислювальних завдань (кульок) незалежно та рівномірно розподіляються між `m` серверами (кошиками), середнє навантаження на один сервер дорівнює `μ = n / m`.

- **Випадок рівного навантаження (`n = m`, `μ = 1`):** За нерівністю Чернова з ймовірністю щонайменше `1 - 1/n` максимальне навантаження на будь-який сервер не перевищує:
  ```
  Max_Load ≤ ( 3 · ln n ) / ln(ln n)
  ```
- **Випадок надлишкового навантаження (`n ≥ m ln m`):** З високою ймовірністю навантаження будь-якого сервера не перевищить `μ + O(√(μ ln m))`.
- **Вибір із двох кандидатів (Power of Two Choices):** Якщо кожне завдання обирає менш завантажений сервер із двох випадково обраних, максимальне навантаження падає до:
  ```
  Max_Load ≤ ( ln(ln n) / ln 2 ) + O(1)
  ```

### 3.3. Вимоги до ємності фільтра Блума (Bloom Filter Parameter Choice)

Для забезпечення гарантії того, що частота хибнопозитивних спрацювань фільтра Блума не перевищить `p_fp` при зберіганні `n` елементів, оптимальна кількість хеш-функцій `k` та загальний розмір бітового масиву `m` обчислюються як:

```
m = - ( n · ln(p_fp) ) / (ln 2)²
k = ( m / n ) · ln 2
```

Нерівність Чернова гарантує, що фактична кількість встановлених бітів у фільтрі Блума буде строго концентруватися навколо очікуваного значення `m (1 - e^(-kn/m))`, що унеможливлює раптовий сплеск хибнопозитивних відповідей.

### 3.4. Оцінка глибини рандомізованих структур даних (Skip Lists & Treaps)

У рандомізованих списках із пропусками (Skip Lists) та випадкових деревах пошуку (Treaps) кожен елемент отримує випадковий рівень (вежу) з ймовірністю `p = 1/2`. Нерівність Чернова дозволяє довести, що максимальна висота структури даних для `n` елементів з ймовірністю `1 - 1/n` не перевищує `O(log n)`. Це гарантує, що найгірший час виконання операцій пошуку, вставки та видалення залишається логарифмічним, а ймовірність виродження структури у лінійний список є мікроскопічно малою.

## 4. Программний інтерфейс обчислення меж (API Reference)

Нижче наведено повний специфікований алгоритмічний інтерфейс мовами C та C++ для аналітичного обчислення меж Чернова та знаходження мінімального розміру вибірки `n`. Інтерфейс розроблено з урахуванням вимог до обчислювальної стійкості, захисту від чисельного underflow та повної відсутності витоків пам'яті.

```c
#ifndef CHERNOFF_BOUNDS_H
#define CHERNOFF_BOUNDS_H

#include <stdbool.h>
#include <math.h>

// Структура конфігурації параметрів випадкової суми
typedef struct {
    int n;             // загальна кількість незалежних випробувань (n > 0)
    double p;          // ймовірність успіху в кожному випробуванні (0 < p < 1)
    double delta;      // відносне відхилення delta > 0
    double target_err; // цільова гранична ймовірність помилки (0 < err < 1)
} ChernoffParams;

// Обчислення точної верхньої межі MGF: Pr[X >= (1 + delta) * mu]
static inline double chernoff_upper_bound_exact(double mu, double delta) {
    if (mu <= 0.0 || delta <= 0.0) return 1.0;
    // Обчислення через логарифмічний простір для захисту від чисельного underflow
    double log_b = mu * (delta - (1.0 + delta) * log(1.0 + delta));
    double bound = exp(log_b);
    return (bound > 1.0) ? 1.0 : bound;
}

// Обчислення квадратичної аппроксимації верхнього хвоста: exp(-mu * delta^2 / 3)
static inline double chernoff_upper_bound_approx(double mu, double delta) {
    if (mu <= 0.0 || delta <= 0.0) return 1.0;
    double bound = exp(-mu * delta * delta / 3.0);
    return (bound > 1.0) ? 1.0 : bound;
}

// Обчислення квадратичної аппроксимації нижнього хвоста: exp(-mu * delta^2 / 2)
static inline double chernoff_lower_bound_approx(double mu, double delta) {
    if (mu <= 0.0 || delta <= 0.0 || delta >= 1.0) return 1.0;
    double bound = exp(-mu * delta * delta / 2.0);
    return (bound > 1.0) ? 1.0 : bound;
}

// Обчислення двосторонньої межі: 2 * exp(-mu * delta^2 / 3)
static inline double chernoff_twosided_bound(double mu, double delta) {
    if (mu <= 0.0 || delta <= 0.0 || delta >= 1.0) return 1.0;
    double bound = 2.0 * exp(-mu * delta * delta / 3.0);
    return (bound > 1.0) ? 1.0 : bound;
}

// Обчислення необхідної кількості випробувань k для більшості голосів (Majority Voting)
static inline int chernoff_required_trials(double gamma, double target_error) {
    if (gamma <= 0.0 || target_error <= 0.0 || target_error >= 1.0) return -1;
    double k = (3.0 / (2.0 * gamma * gamma)) * log(1.0 / target_error);
    return (int)ceil(k);
}

#endif // CHERNOFF_BOUNDS_H
```
```cpp
#ifndef CHERNOFF_BOUNDS_HPP
#define CHERNOFF_BOUNDS_HPP

#include <cmath>
#include <algorithm>
#include <optional>
#include <cstddef>

namespace algo::chernoff {

struct ConcentrationConfig {
    double mu{0.0};
    double delta{0.0};
};

class BoundCalculator {
public:
    // Точна межа верхнього хвоста у логарифмічно захищеному форматі
    static constexpr double upper_exact(double mu, double delta) noexcept {
        if (mu <= 0.0 || delta <= 0.0) return 1.0;
        const double log_b = mu * (delta - (1.0 + delta) * std::log(1.0 + delta));
        return std::min(1.0, std::exp(log_b));
    }

    // Аппроксимація верхнього хвоста: exp(-mu * delta^2 / 3)
    static constexpr double upper_approx(double mu, double delta) noexcept {
        if (mu <= 0.0 || delta <= 0.0) return 1.0;
        return std::min(1.0, std::exp(-mu * delta * delta / 3.0));
    }

    // Аппроксимація нижнього хвоста: exp(-mu * delta^2 / 2)
    static constexpr double lower_approx(double mu, double delta) noexcept {
        if (mu <= 0.0 || delta <= 0.0 || delta >= 1.0) return 1.0;
        return std::min(1.0, std::exp(-mu * delta * delta / 2.0));
    }

    // Двостороння межа: 2 * exp(-mu * delta^2 / 3)
    static constexpr double two_sided(double mu, double delta) noexcept {
        if (mu <= 0.0 || delta <= 0.0 || delta >= 1.0) return 1.0;
        return std::min(1.0, 2.0 * std::exp(-mu * delta * delta / 3.0));
    }

    // Обчислення необхідної кількості випробувань k для підсилення більшості голосів
    static std::optional<std::size_t> required_trials(double gamma, double target_error) noexcept {
        if (gamma <= 0.0 || target_error <= 0.0 || target_error >= 1.0) {
            return std::nullopt;
        }
        const double k = (3.0 / (2.0 * gamma * gamma)) * std::log(1.0 / target_error);
        return static_cast<std::size_t>(std::ceil(k));
    }
};

} // namespace algo::chernoff

#endif // CHERNOFF_BOUNDS_HPP
```

## 5. Граничні умови, коректність параметрів та обробка виняткових ситуацій

При використанні даного інженерного API у продуктивних системах розробник повинен контролювати наступні крайові випадки та виняткові ситуації:

1. **Некоректний інтервал відхилення (`δ ≤ 0`):** Нерівність Чернова оцінює строго додатне відхилення від середнього значення. Якщо `δ ≤ 0`, функція повертає верхню межу `1.0`, оскільки подія `X ≥ μ` або `X ≥ (1 + δ)μ` для `δ ≤ 0` має ймовірність близку до `0.5` чи вище, і нерівність концентрації хвоста не застосовується.
2. **Нижній хвіст за межами допустимого інтервалу (`δ ≥ 1`):** Для нижнього хвоста `Pr[X ≤ (1 - δ)μ]` параметр відносного відхилення `δ` повинен строго лежати у відкритому інтервалі `(0, 1)`. При `δ ≥ 1` поріг стає від'ємним або нульовим `(1 - δ)μ ≤ 0`. Оскільки сума невід'ємних Бернуліївських величин не може бути меншою за нуль, така подія відповідає виключно випадку `X = 0`, ймовірність якого дорівнює точній величині `∏ᵢ₌₁ⁿ (1 - pᵢ)`.
3. **Захист від чисельного underflow у логарифмічному просторі:** При великих значеннях `μ` (наприклад, `μ = 10000`) пряме розрахування `pow(1 + δ, 1 + δ)` з наступним піднесенням до степеня `μ` спричиняє чисельний underflow типу `double` (повернення `0.0` або `NaN`). Наш API гарантує чисельну стабільність шляхом переведення всього показника в логарифмічну форму `log_bound = μ * (δ - (1 + δ) * log(1 + δ))` з подальшим викликом `exp()`.
4. **Контроль нульового математичного сподівання (`μ = 0`):** Якщо `μ = 0` (всі `pᵢ = 0`), сума `X` ототожнюється з константою `0`. Усі функції API повертають `1.0` для запобігання діленню на нуль або не невизначеностей вигляду `0 · log(0)`.
