# 🧮 Математичний вивід нерівностей Чернова та зв'язок із відносною ентропією

Цей математичний додаток містить повний, строго обґрунтований кроковий вивід мультиплікативних та адитивних форм нерівності Чернова для сум independent випадкових бернуліївських величин через метод моментогенеруючих функцій (MGF), а також розкриває глибоку інформаційно-теоретичну інтерпретацію цих меж через дивергенцію Кульбака — Лейблера та теорему Санова.

## 1. Вхідна постановка та аналітичні властивості моментогенеруючої функції

Розглянемо ймовірнісний простір `(Ω, F, P)`, на якому задано сукупність independent випадкових величин `X₁, X₂, ..., X♁`. Припустимо, що кожна величина `Xᵢ` є бернуліївською і приймає значення з множини `{0, 1}` із відповідними ймовірностями успіху та невдачі:

```
Pr[Xᵢ = 1] = pᵢ,    Pr[Xᵢ = 0] = 1 - pᵢ
```

Позначимо через `X = ∑ᵢ₌₁ⁿ Xᵢ` суму цих випадкових величин. Оскільки математичне сподівання володіє властивістю лінійності для довільних випадкових величин (незалежно від їхньої залежності), очікуване значення суми дорівнює сумі математичних сподівань додатків:

```
μ = E[X] = E[∑ᵢ₌₁ⁿ Xᵢ] = ∑ᵢ₌₁ⁿ E[Xᵢ] = ∑ᵢ₌₁ⁿ pᵢ
```

Для аналізу відхилень суми `X` від її середнього значення `μ` застосовується метод моментогенеруючих функцій. Моментогенеруючою функцією (MGF) випадкової величини `Z` називається функція дійсного параметра `t`, що визначається як матемаматичне сподівання експоненти `M_Z(t) = E[e^(tZ)]`. Перевага MGF полягає в тому, що вона розкладається в ряд за моментами `E[Zᵏ]`, а отже, одночасно містить інформацію про всі вищі моменти розподілу:

```
E[e^(tZ)] = ∑ₖ₌₀⁺∞ (tᵏ / k!) · E[Zᵏ]
```

Розрахуємо моментогенеруючу функцію для одного Бернуліївського доданка `Xᵢ`:

```
E[e^(tXᵢ)]
= pᵢ · e^(t·1) + (1 - pᵢ) · e^(t·0)    [означення математичного сподівання]
= pᵢ eᵗ + 1 - pᵢ                      [спрощення e⁰ = 1]
= 1 + pᵢ (eᵗ - 1)                     [групування доданків]
```

Для подальшого аналітичного спрощення скористаємося фундаментальною нерівністю для експоненціальної функції:

```
1 + y ≤ eʸ,    для всіх дійсних y ∈ ℝ
```

Ця нерівність є наслідком строгої опуклості функції `f(y) = eʸ`. Графік прямої `1 + y` є дотичною до кривої `eʸ` у точці `y = 0`, тому графік експоненти лежить суворо не нижче цієї дотичної. Підставивши `y = pᵢ (eᵗ - 1)`, отримуємо точну верхню межу для MGF одного доданка:

```
E[e^(tXᵢ)] ≤ exp( pᵢ (eᵗ - 1) )       [застосування нерівності 1 + y ≤ eʸ]
```

Головна алгебраїчна перевага перетворення `Z → e^(tZ)` полягає в тому, що воно перетворює операцію додавання у показникові степеня на операцію множення. Завдяки припущенню про сукупну незалежність випадкових величин `X₁, ..., X♁`, математичне сподівання добутку дорівнює добутку математичних сподівань:

```
E[e^(tX)]
= E[exp(t ∑ᵢ₌₁ⁿ Xᵢ)]                   [заміна суми]
= E[∏ᵢ₌₁ⁿ e^(tXᵢ)]                     [властивість показників степеня]
= ∏ᵢ₌₁ⁿ E[e^(tXᵢ)]                     [незалежність випадкових величин]
≤ ∏ᵢ₌₁ⁿ exp( pᵢ (eᵗ - 1) )             [підстановка верхньої межі для кожного Xᵢ]
= exp( ∑ᵢ₌₁ⁿ pᵢ (eᵗ - 1) )              [добуток експонент дорівнює експоненті суми]
= exp( μ (eᵗ - 1) )                    [заміна ∑ pᵢ = μ]
```

Отже, ми довели фундаментальну лему: для суми будь-якої кількості independent Бернуліївських величин зі збірним математичним сподіванням `μ`, моментогенеруюча функція строго обмежена зверху виразом `exp( μ (eᵗ - 1) )`.

## 2. Кроковий вивід нерівності для верхнього хвоста та оптимізація параметра t

Дослідимо ймовірність того, що сума `X` перевищить очікуване значення `μ` у `(1 + δ)` разів для додатного коефіцієнта відхилення `δ > 0`.

Зафіксуємо довільне додатне значення параметра `t > 0`. Оскільки монотонно зростаюча функція `f(z) = e^(tz)` зберігає знак нерівності при `t > 0`, подія `X ≥ (1 + δ)μ` настає тоді й лише тоді, коли `e^(tX) ≥ e^(t(1 + δ)μ)`.

Оскільки випадкова величина `Y = e^(tX)` є строго додатною (`Y > 0`), ми можемо застосувати до неї нерівність Маркова `Pr[Y ≥ a] ≤ E[Y] / a`:

```
Pr[X ≥ (1 + δ)μ]
= Pr[e^(tX) ≥ e^(t(1 + δ)μ)]           [монотонне перетворення eᵗˣ для t > 0]
≤ E[e^(tX)] / exp( t (1 + δ) μ )       [нерівність Маркова для перетвореної величини]
≤ exp( μ (eᵗ - 1) ) / exp( t (1 + δ) μ ) [підстановка оцінки MGF суми]
= exp( μ (eᵗ - 1) - t (1 + δ) μ )      [властивість ділення експонент]
```

Отримана верхня межа є справедливою для **будь-якого** значення `t > 0`. Щоб мінімізувати ймовірність і отримати найточнішу межу, ми повинні знайти таке `t* > 0`, яке мінімізує функцію показника експоненти:

```
g(t) = μ (eᵗ - 1) - t (1 + δ) μ
```

Знайдемо першу та другу похідні функції `g(t)` за змінною `t`:

```
g'(t) = μ eᵗ - (1 + δ) μ
g''(t) = μ eᵗ
```

Прирівняємо першу похідну до нуля для пошуку критичної точки:

```
μ eᵗ - (1 + δ) μ = 0                   [рівняння першої похідної]
eᵗ = 1 + δ                            [скорочення на μ > 0]
t* = ln(1 + δ)                        [логарифмування]
```

Оскільки `δ > 0`, маємо `1 + δ > 1`, отже `t* = ln(1 + δ) > 0`, що повністю задовольняє умову додатності параметра `t`. Друга похідна `g''(t*) = μ (1 + δ) > 0` є строго додатною, що підтверджує, що в точці `t*` досягається єдиний глобальний мінімум функції `g(t)`.

Підставимо значення `t* = ln(1 + δ)` та `e^(t*) = 1 + δ` назад у вираз для показника експоненти `g(t)`:

```
g(t*)
= μ ((1 + δ) - 1) - ln(1 + δ) (1 + δ) μ
= μ δ - (1 + δ) μ ln(1 + δ)           [спрощення доданків]
= μ [ δ - (1 + δ) ln(1 + δ) ]         [винесення μ за дужки]
```

Підставивши показник `g(t*)` в експоненту, отримуємо точну точкову мультиплікативну межу Чернова для верхнього хвоста:

```
Pr[X ≥ (1 + δ)μ]
≤ exp( μ [ δ - (1 + δ) ln(1 + δ) ] )
= ( e^δ / (1 + δ)^(1 + δ) )^μ          [алгебраїчне перетворення показника]
```

### Аналітичні аппроксимації для практичного використання

Точна межа `( e^δ / (1 + δ)^(1 + δ) )^μ` містить складний вираз `(1 + δ)^(1 + δ)`. Для зручності обчислень виведем квадратичні оцінки.

Розглянемо функцію `f(δ) = (1 + δ) ln(1 + δ) - δ`. Знайдемо її розклад у ряд Тейлора в околі нуля `δ = 0`:

```
f(δ) = δ²/2 - δ³/6 + δ⁴/12 - ...
```

Для проміжку `0 < δ ≤ 1` можна довести сувору нерівність `f(δ) ≥ δ² / 3`. Проведемо аналітичну перевірку: розіб'ємо різницю `h(δ) = (1 + δ) ln(1 + δ) - δ - δ² / 3`. Її похідна `h'(δ) = ln(1 + δ) - 2δ / 3`. Друга похідна `h''(δ) = 1/(1 + δ) - 2/3`. При `δ = 1/2` друга похідна дорівнює нулю, а функція `h(δ)` є строго додатною на всьому інтервалі `(0, 1]`.

Підставивши `-f(δ) ≤ -δ² / 3` у точну межу, отримуємо найвідомішу квадратичну форму Чернова:

```
Pr[X ≥ (1 + δ)μ] ≤ exp( -μ δ² / 3 ),    для 0 < δ ≤ 1
```

Для більших відхилень `δ > 1` використовується альтернативна квадратична оцінка:

```
Pr[X ≥ (1 + δ)μ] ≤ exp( -μ δ² / (2 + δ) ),    для всіх δ > 0
```

## 3. Кроковий вивід нерівності для нижнього хвоста

Тепер виведемо межу для ймовірності того, що сума `X` відхилиться нижче свого очікуваного значення: `Pr[X ≤ (1 - δ)μ]`, де `0 < δ < 1`.

У цьому випадку вибираємо від'ємний параметр `t < 0`. Множення обидвох частин нерівності на від'ємне число `t` змінює напрямок знаку нерівності: подія `X ≤ (1 - δ)μ` еквівалентна `tX ≥ t(1 - δ)μ`, що відповідає `e^(tX) ≥ e^(t(1 - δ)μ)`.

Застосувавши нерівність Маркова для перетвореної величини при `t < 0`:

```
Pr[X ≤ (1 - δ)μ]
≤ E[e^(tX)] / exp( t (1 - δ) μ )
≤ exp( μ (eᵗ - 1) - t (1 - δ) μ )
```

Знайдемо мінімум функції `h(t) = μ (eᵗ - 1) - t (1 - δ) μ` на півпрямій `t < 0`:

```
h'(t) = μ eᵗ - (1 - δ) μ = 0  ⇒  eᵗ = 1 - δ  ⇒  t* = ln(1 - δ)
```

Оскільки `0 < 1 - δ < 1`, значення `t* = ln(1 - δ) < 0` є строго від'ємним, що задовольняє умову `t < 0`.

Підставимо `t* = ln(1 - δ)` у функцію `h(t)`:

```
h(t*)
= μ ((1 - δ) - 1) - ln(1 - δ) (1 - δ) μ
= -μ δ - (1 - δ) μ ln(1 - δ)
= μ [ -δ - (1 - δ) ln(1 - δ) ]
```

Це дає точну межу нижнього хвоста:

```
Pr[X ≤ (1 - δ)μ]
≤ exp( μ [ -δ - (1 - δ) ln(1 - δ) ] )
= ( e^(-δ) / (1 - δ)^(1 - δ) )^μ
```

Скориставшись нерівністю Тейлора `(1 - δ) ln(1 - δ) ≥ -δ + δ² / 2`, яка виконується для всіх `0 < δ < 1`, отримуємо зручну квадратичну межу нижнього хвоста:

```
Pr[X ≤ (1 - δ)μ] ≤ exp( -μ δ² / 2 ),    для 0 < δ < 1
```

## 4. Загальна адитивна нерівність Геффдінга

У випадку, коли випадкові величини `X₁, ..., X♁` є independent, але не є дискретними Бернуліївськими, а довільними неперервними чи дискретними величинами, обмеженими інтервалами `aᵢ ≤ Xᵢ ≤ bᵢ`, використовують лему Геффдінга.

**Лема Геффдінга:** Нехай `Y` — випадкова величина з `E[Y] = 0` та `a ≤ Y ≤ b`. Тоді для будь-якого `t ∈ ℝ`:

```
E[e^(tY)] ≤ exp( t² (b - a)² / 8 )
```

Доведення ґрунтується на опуклості експоненти: будь-яку точку `y ∈ [a, b]` можна представити як опуклу комбінацію крайніх точок `y = α a + (1 - α) b`, де `α = (b - y) / (b - a)`. Оскільки `e^(ty)` є опуклою функцією, маємо `e^(ty) ≤ α e^(ta) + (1 - α) e^(tb)`. Взявши математичне сподівання та оптимізувавши показник, отримуємо квадратний член `t² (b - a)² / 8`.

Застосувавши цей результат до суми `S♁ = ∑ Xᵢ`, отримуємо адитивну нерівність Геффдінга:

```
Pr[S♁ - E[S♁] ≥ t] ≤ exp( -2 t² / ∑ᵢ⌠ⁿ (bᵢ - aᵢ)² )
```

## 5. Зв'язок із відносною ентропією (дивергенцією Кульбака — Лейблера) та теоремою Санова

Розглянемо випадок `n` independent ідентично розподілених Бернуліївських випробувань із ймовірністю успіху `p`. Маємо `μ = n p`.

Припустимо, ми спостерігаємо відхилення середньої частоти успіхів `q = X / n`, де `q > p`.

Запишемо точний показник згасання у межі Чернова:

```
( e^δ / (1 + δ)^(1 + δ) )^μ
```

Підставимо `μ = n p` та `1 + δ = q / p` (звідси `δ = (q - p) / p`):

```
Показник експоненти
= n p [ (q - p)/p - (q/p) ln(q/p) ]
= n [ (q - p) - q ln(q/p) ]
= -n [ q ln(q / p) + (1 - q) ln( (1 - q) / (1 - p) ) ]
```

Згадаємо вираз для дивергенції Кульбака — Лейблера (відносної ентропії) між двома Бернуліївськими розподілами `Bernoulli(q)` та `Bernoulli(p)`:

```
D(q || p) = q ln(q / p) + (1 - q) ln( (1 - q) / (1 - p) )
```

Отже, точна межа Чернова набуває геометричного змісту теорії інформації:

```
Pr[X ≥ n q] ≤ exp( -n · D(q || p) )
```

Цей результат є фундаментальним окремим випадком **теореми Санова** з теорії великих відхилень: ймовірність того, що емпіричний розподіл independent вибірки відхилиться від істинного розподілу `p` до спостережуваного розподілу `q`, спадає експоненціально зі швидкістю, пропорційною відносній ентропії `D(q || p)`.

| Форма нерівності | Аналітичний вираз | Область застосування |
| :--- | :--- | :--- |
| **Чернов (Верхній хвіст, точна)** | `Pr[X ≥ (1+δ)μ] ≤ (e^δ / (1+δ)^(1+δ))^μ` | Будь-які `δ > 0`, Бернуліївські |
| **Чернов (Верхній хвіст, квадратична)** | `Pr[X ≥ (1+δ)μ] ≤ exp(-μ δ² / 3)` | `0 < δ ≤ 1`, Бернуліївські |
| **Чернов (Нижній хвіст, квадратична)** | `Pr[X ≤ (1-δ)μ] ≤ exp(-μ δ² / 2)` | `0 < δ < 1`, Бернуліївські |
| **Геффдінг (Адитивна)** | `Pr[S♁ - μ ≥ t] ≤ exp(-2t² / ∑(bᵢ - aᵢ)²)` | Загальні обмежені `aᵢ ≤ Xᵢ ≤ bᵢ` |
| **Форма Санова (Ентропійна)** | `Pr[X/n ≥ q] ≤ exp(-n · D(q \|\| p))` | Теорія інформації, великі відхилення |
