# 🧮 Алгебраїчні властивості коваріації та матричних перетворень

Одиночна дисперсія підпорядковується простим числовим законам, але коли випадкові величини об'єднуються у вектори, взаємозв'язки між ними набувають структури лінійної алгебри. Тут наведено строгі математичні виведення ключових властивостей коваріації: нерівності Коші–Буняковського–Шварца для обмеження коефіцієнта кореляції, поведінки коваріаційної матриці при лінійних перетвореннях простору, а також інваріантів розкиду — сліду, визначника та відстані Махаланобіса.

## Нерівність Коші–Буняковського–Шварца та межі кореляції

Коефіцієнт кореляції Пірсона `ρ_{XY}` нормує коваріацію на добуток стандартних відхилень:

```
          Cov(X, Y)
ρ_{XY} = ───────────
           σ_X · σ_Y
```

Щоб довести, що для будь-яких випадкових величин із скінченною ненульовою дисперсією значення `ρ_{XY}` гарантовано належить відрізку `[-1, 1]`, скористаємося невід'ємністю математичного сподівання квадрата дійсної випадкової величини.

Введемо центровані величини `X̃ = X - μ_X` та `Ỹ = Y - μ_Y`. Для будь-якого дійсного параметра `t ∈ ℝ` складемо лінійну комбінацію `t X̃ + Ỹ`. Її квадрат є невід'ємною величиною `(t X̃ + Ỹ)² ≥ 0`, а отже, невід'ємним є і її математичне сподівання:

```
E[(t X̃ + Ỹ)²] ≥ 0
```

Розкриємо квадрат під знаком математичного сподівання, скориставшись лінійністю оператора `E`:

```
E[(t X̃ + Ỹ)²]
= E[t² X̃² + 2 t X̃ Ỹ + Ỹ²]              [розкрили квадрат суми]
= t² E[X̃²] + 2 t E[X̃ Ỹ] + E[Ỹ²]        [лінійність математичного сподівання]
= t² Var(X) + 2 t Cov(X, Y) + Var(Y)     [за означенням дисперсії та коваріації]
```

Отриманий вираз є квадратним тричленом `P(t) = A t² + B t + C` відносно змінної `t`, де коефіцієнти дорівнюють:

```
A = Var(X) = σ_X² > 0
B = 2 · Cov(X, Y)
C = Var(Y) = σ_Y² > 0
```

Оскільки парабола `P(t)` напрямлена вітками вгору (`A > 0`) і набуває невід'ємних значень для всіх дійсних `t` (`P(t) ≥ 0`), цей квадратний тричлен може мати не більше одного дійсного кореня. Це означає, що його дискримінант `D` мусить бути меншим або рівним нулю:

```
D = B² − 4 A C ≤ 0
```

Підставимо значення коефіцієнтів у нерівність для дискримінанта:

```
(2 · Cov(X, Y))² − 4 · Var(X) · Var(Y) ≤ 0
4 · (Cov(X, Y))² − 4 · σ_X² · σ_Y² ≤ 0
(Cov(X, Y))² ≤ σ_X² · σ_Y²
```

Добудемо квадратний корінь з обох частин нерівності (обидві частини невід'ємні):

```
|Cov(X, Y)| ≤ σ_X · σ_Y
```

Поділимо обидві частини на додатний добуток `σ_X · σ_Y`:

```
 |Cov(X, Y)|
───────────── ≤ 1
  σ_X · σ_Y
```

Оскільки за означенням `ρ_{XY} = Cov(X, Y) / (σ_X · σ_Y)`, отримуємо фундаментальну нерівність:

```
|ρ_{XY}| ≤ 1  ⟺  −1 ≤ ρ_{XY} ≤ 1
```

### Умова досягнення крайніх значень (|ρ| = 1)

Рівність `|ρ_{XY}| = 1` досягається тоді й лише тоді, коли дискримінант `D = 0`. Це означає наявність єдиного дійсного кореня `t₀ = −B / (2A) = −Cov(X, Y) / Var(X)`, за якого квадратний тричлен перетворюється на точний нуль:

```
E[(t₀ X̃ + Ỹ)²] = 0
```

Якщо математичне сподівання невід'ємної випадкової величини дорівнює нулю, сама величина дорівнює нулю майже напевно (з імовірністю 1):

```
t₀ (X - μ_X) + (Y - μ_Y) = 0
Y - μ_Y = −t₀ (X - μ_X)
Y = −t₀ X + (μ_Y + t₀ μ_X)
```

Позначивши `a = −t₀` та `b = μ_Y + t₀ μ_X`, отримуємо точний детермінований лінійний зв'язок:

```
Y = a X + b
```

При цьому:
- Якщо `a > 0`, коваріація `Cov(X, Y) = a Var(X) > 0`, а `ρ_{XY} = +1` (ідеальний прямий лінійний зв'язок).
- Якщо `a < 0`, коваріація `Cov(X, Y) = a Var(X) < 0`, а `ρ_{XY} = −1` (ідеальний протилежний лінійний зв'язок).

## Афінні перетворення випадкових векторів

Нехай `X = [X₁, X₂, ..., X_n]^T` — випадковий вектор розмірності `n` з вектором математичних сподівань `μ_X = E[X]` та коваріаційною матрицею `Σ_X = E[(X - μ_X)(X - μ_X)^T]`.

Розглянемо загальне афінне перетворення простору, яке відображає вектор `X` у новий випадковий вектор `Y` розмірності `m`:

```
Y = A X + b
```

де `A` — дійсна стала матриця розміру `m × n`, а `b` — сталий вектор зсуву розмірності `m`.

### Математичне сподівання трансформованого вектора

Скористаємося властивістю лінійності математичного сподівання для векторних величин:

```
E[Y]
= E[A X + b]           [підставили формулу перетворення]
= A E[X] + b           [матриця A та вектор b є сталими]
= A μ_X + b            [за означенням μ_X = E[X]]
```

Отже, вектор центрів зсувається згідно з тим самим афінним законом: `μ_Y = A μ_X + b`.

### Коваріаційна матриця трансформованого вектора

Знайдемо вектор відхилень для `Y`:

```
Y - μ_Y
= (A X + b) − (A μ_X + b)     [підставили Y та μ_Y]
= A X − A μ_X                 [сталі вектори b взаємно знищилися]
= A (X − μ_X)                 [винесли матрицю A за дужки]
```

За означенням коваріаційної матриці для вектора `Y`:

```
Σ_Y = E[(Y - μ_Y)(Y - μ_Y)^T]
```

Підставимо отриманий вираз для відхилення та застосуємо правило транспонування добутку матриць `(M N)^T = N^T M^T`:

```
Σ_Y
= E[ (A (X - μ_X)) (A (X - μ_X))^T ]             [підставили Y - μ_Y]
= E[ A (X - μ_X) (X - μ_X)^T A^T ]               [транспонували: (A u)^T = u^T A^T]
= A · E[(X - μ_X)(X - μ_X)^T] · A^T              [винесли сталі матриці A та A^T з-під сподівання]
= A · Σ_X · A^T                                  [за означенням Σ_X]
```

Отримано фундаментальний закон перетворення коваріації:

```
Σ_Y = A Σ_X A^T
```

Зсув `b` повністю зникає, оскільки коваріація вимірює розкид відносно центру і не залежить від абсолютного положення розподілу в просторі.

### Дисперсія довільної одновимірної проєкції

Якщо взяти довільний фіксований вектор `v ∈ ℝ^n`, скалярна величина `Z = v^T X = ∑ v_i X_i` є одновимірною лінійною проєкцією вектора `X`. Застосовуючи формулу перетворення при `A = v^T` (розмір `1 × n`):

```
Var(v^T X) = Σ_Z = v^T Σ_X (v^T)^T = v^T Σ_X v
```

Оскільки дисперсія будь-якої дійсної скалярної величини фізично не може бути від'ємною (`Var(Z) ≥ 0`), для будь-якого вектора `v` виконується:

```
v^T Σ_X v ≥ 0
```

Це доводить, що будь-яка коваріаційна матриця `Σ_X` є додатно напіввизначеною матрицею (`Σ_X ⪰ 0`).

## Слід і визначник коваріаційної матриці

У багатовимірному аналізі коваріаційна матриця містить `n(n+1)/2` незалежних параметрів. Для узагальненої числової оцінки сумарного обсягу невизначеності використовують дві скалярні характеристики: слід (trace) та визначник (determinant).

### Слід матриці: сумарна дисперсія

Слід квадратної матриці `tr(Σ)` дорівнює сумі її діагональних елементів:

```
tr(Σ) = Σ₁₁ + Σ₂₂ + ... + Σ_nn = Var(X₁) + Var(X₂) + ... + Var(X_n)
```

Згідно зі спектральною теоремою, будь-яку симетричну матрицю можна розкласти як `Σ = V Λ V^T`, де `V` — ортогональна матриця власних векторів (`V^T V = I`), а `Λ = diag(λ₁, λ₂, ..., λ_n)` — діагональна матриця власних значень. Завдяки циклічній властивості сліду `tr(A B C) = tr(C A B)`:

```
tr(Σ) = tr(V Λ V^T) = tr(V^T V Λ) = tr(I · Λ) = tr(Λ) = λ₁ + λ₂ + ... + λ_n
```

Слід коваріаційної матриці є **сумарною дисперсією** системи. Він показує загальну потужність розкиду і є інваріантним до будь-яких поворотів системи координат: як би ми не обертали базис, сума дисперсій уздовж осей залишається незмінною і дорівнює сумі власних чисел `∑ λ_i`.

### Визначник матриці: узагальнена дисперсія Вілкса

Визначник коваріаційної матриці `det(Σ)` через власні значення виражається як їхній добуток:

```
det(Σ) = det(V Λ V^T) = det(V) · det(Λ) · det(V^T) = det(Λ) = λ₁ · λ₂ · ... · λ_n
```

Величину `det(Σ)` називають **узагальненою дисперсією** (англ. *generalized variance*, запропонована Самуелем Вілксом у 1932 році). 

Геометричний зміст `det(Σ)`:
- Довірчий еліпсоїд розсіювання на рівні `1-сигма` має півосі довжиною `√λ₁, √λ₂, ..., √λ_n`.
- Об'єм `n`-вимірного гіпереліпсоїда пропорційний добутку його півосей:
  `V_ellipsoid ∝ ∏_{i=1}^n √λ_i = √(∏_{i=1}^n λ_i) = √(det(Σ))`.
- Таким чином, `det(Σ)` пропорційний **квадрату об'єму хмари невизначеності**.

Якщо `det(Σ) = 0`, принаймні одне власне значення `λ_k = 0`. Це свідчить про виродженість: випадковий вектор сконцентрований у підпросторі розмірності `n - 1` або менше, тобто між компонентами існує точна лінійна залежність.

## Інваріантність квадратичної форми Махаланобіса

Відстань Махаланобіса від точки `x` до центру `μ` задається квадратичною формою:

```
d_M²(x, μ) = (x − μ)^T Σ⁻¹ (x − μ)
```

Перевіримо, як змінюється ця відстань при невиродженому афінному перетворенні координат `y = A x + b`, де матриця `A` квадратна і має обернену `A⁻¹`.

Вектор середніх перетворюється як `μ_Y = A μ + b`, а коваріаційна матриця — як `Σ_Y = A Σ A^T`. Знайдемо обернену матрицю `Σ_Y⁻¹`:

```
Σ_Y⁻¹ = (A Σ A^T)⁻¹ = (A^T)⁻¹ · Σ⁻¹ · A⁻¹
```

Обчислимо відстань Махаланобіса в нових координатах:

```
d_M²(y, μ_Y)
= (y − μ_Y)^T · Σ_Y⁻¹ · (y − μ_Y)
= (A(x − μ))^T · [ (A^T)⁻¹ Σ⁻¹ A⁻¹ ] · (A(x − μ))       [підставили y - μ_Y та Σ_Y⁻¹]
= (x − μ)^T · A^T · (A^T)⁻¹ · Σ⁻¹ · A⁻¹ · A · (x − μ)   [розкрили транспонування]
= (x − μ)^T · I · Σ⁻¹ · I · (x − μ)                     [скоротили A^T (A^T)⁻¹ = I та A⁻¹ A = I]
= (x − μ)^T · Σ⁻¹ · (x − μ)
= d_M²(x, μ)
```

Квадратична форма Махаланобіса є строго інваріантною відносно будь-яких лінійних замін базису (масштабування, зсувів, поворотів). Вона вимірює дійсну статистичну відстань у термінах сигм розсіювання, абстрагуючись від довільного вибору одиниць вимірювання та орієнтації координатних осей.
