# 🧮 Математичне виведення та індикаторні змінні

Нерівності Бонферроні дають формальний апарат для знаходження верхніх та нижніх меж ймовірностей об'єднання скінченної сукупності довільних подій. Вони усувають необхідність обчислення всіх `2ⁿ - 1` комбінацій перетинів у принципі включень-виключень, забезпечуючи контрольовану точність при використанні лише часткових сукупностей перетинів низького порядку.

## Строге формулювання теореми

Нехай `(Ω, F, P)` — імовірнісний простір, а `A₁, A₂, ..., A♮ ∈ F` — довільні випадкові події. Позначимо через `Sᵣ` суму ймовірностей усіх можливих перетинів `r` різних подій з цієї сукупності:

```
S_r = ∑_{1 ≤ i₁ < i₂ < ... < i_r ≤ n} P(A_{i₁} ∩ A_{i₂} ∩ ... ∩ A_{i_r})
```

Зокрема, для `r = 1` сума `S₁ = ∑_{i=1}ⁿ P(Aᵢ)` є просто сумою індивідуальних ймовірностей подій. Для `r = 2` сума `S₂ = ∑_{1 ≤ i < j ≤ n} P(Aᵢ ∩ Aⱼ)` є сумою ймовірностей парних перетинів.

Класичний теоремний вираз Пуанкаре для ймовірності того, що станеться бодай одна з подій `Aᵢ` (тобто ймовірності їхнього об'єднання `⋃_{i=1}ⁿ Aᵢ`), задається формулою:

```
P(⋃_{i=1}ⁿ Aᵢ) = S₁ - S₂ + S₃ - S₄ + ... + (-1)ⁿ⁻¹ Sₙ = ∑_{r=1}ⁿ (-1)ʳ⁻¹ Sᵣ
```

**Теорема (Нерівності Бонферроні):** Для будь-якого урізання `k` (`1 ≤ k ≤ n`) сума `k` перших доданків утворює строгу межу для ймовірності об'єднання подій:

1. Якщо `k` **непарне** (`k = 1, 3, 5, ...`), то часткова сума надає **верхню оцінку**:
```
P(⋃_{i=1}ⁿ Aᵢ) ≤ ∑_{r=1}ᵏ (-1)ʳ⁻¹ Sᵣ
```

2. Якщо `k` **парне** (`k = 2, 4, 6, ...`), то часткова сума надає **нижню оцінку**:
```
P(⋃_{i=1}ⁿ Aᵢ) ≥ ∑_{r=1}ᵏ (-1)ʳ⁻¹ Sᵣ
```

Крім того, зі зростанням `k` послідовність верхніх оцінок монотонно спадає, а послідовність нижніх оцінок монотонно зростає, сходячись до точного значення `P(⋃_{i=1}ⁿ Aᵢ)` при `k = n`.

## Формальне виведення через індикаторні випадкові величини

Найбільш елегантний та строгий спосіб доведення нерівностей Бонферроні базується на алгебрі індикаторних випадкових величин та операторі математичного сподівання.

Визначимо індикаторну випадкову величину `Iᵢ` для кожної події `Aᵢ`:
```
I_i(ω) = 1,  якщо ω ∈ A_i
I_i(ω) = 0,  якщо ω ∉ A_i
```

Нехай `m(ω) = ∑_{i=1}ⁿ Iᵢ(ω)` — це випадкова величина, яка дорівнює точній кількості подій із сім'ї `{A₁, ..., A♮}`, які справдилися для елементарного наслідку `ω`.

Подія об'єднання `⋃_{i=1}ⁿ Aᵢ` означає, що справдилася щонайменше одна подія `Aᵢ`, тобто `m(ω) ≥ 1`. Її індикаторна величина дорівнює:
```
I(⋃_{i=1}ⁿ Aᵢ) = 1,  якщо m(ω) ≥ 1
I(⋃_{i=1}ⁿ Aᵢ) = 0,  якщо m(ω) = 0
```

### Крок 1. Зв'язок суми `Sᵣ` з біноміальними коефіцієнтами

Розглянемо вираз для добутку індикаторів кількох подій. Для довільного набору `r` індексів `i₁ < i₂ < ... < iᵣ` добуток `I_{i₁} · I_{i₂} · ... · I_{iᵣ}` дорівнює `1` тоді й лише тоді, коли всі `r` подій відбулися одночасно. Математичне сподівання цього добутку дорівнює ймовірності їхнього перетину:

```
E[ I_{i₁} · I_{i₂} · ... · I_{i_r} ] = P(A_{i₁} ∩ A_{i₂} ∩ ... ∩ A_{i_r})
```

Підсумуємо ці добутки за всіма комбінаціями `r` елементів з `n`. З одного боку, за лінійністю математичного сподівання отримаємо суму `Sᵣ`:

```
E[ ∑_{1 ≤ i₁ < ... < i_r ≤ n} I_{i₁} · I_{i₂} · ... · I_{i_r} ] = S_r
```

З іншого боку, якщо для конкретного наслідку `ω` справдилося рівно `m` подій з `n`, то серед цих `m` подій можна вибрати `r` подій рівно `C(m, r)` способами (де `C(m, r)` — біноміальний коефіцієнт, причому `C(m, r) = 0`, якщо `m < r`).

Отже, випадкова величина під сумою математичного сподівання тотожно дорівнює біноміальному коефіцієнту `C(m, r)`:

```
∑_{1 ≤ i₁ < ... < i_r ≤ n} I_{i₁} · I_{i₂} · ... · I_{i_r} = C(m, r)
```

Таким чином, сума `Sᵣ` є математичним сподіванням біноміального коефіцієнта від кількості подій `m`:

```
S_r = E[ C(m, r) ]
```

### Крок 2. Зведення урізаної суми до комбінаторної функції `fₖ(m)`

Завдяки лінійності математичного сподівання, урізана сума принципу включень-виключень виражається як математичне сподівання від многочлена `fₖ(m)`:

```
∑_{r=1}ᵏ (-1)ʳ⁻¹ Sᵣ = ∑_{r=1}ᵏ (-1)ʳ⁻¹ E[ C(m, r) ]
                  = E[ ∑_{r=1}ᵏ (-1)ʳ⁻¹ C(m, r) ]
                  = E[ f_k(m) ]
```

де комбінаторна функція `fₖ(m)` визначена як:

```
f_k(m) = ∑_{r=1}ᵏ (-1)ʳ⁻¹ C(m, r)
```

Тепер доведення теореми зводиться до аналізу значень скалярної функції `fₖ(m)` для цілих чисел `m ≥ 0`.

## Альтернативне доведення через твірні функції

Для глибшого розуміння комбінаторної тотожності `fₖ(m) = 1 - (-1)ᵏ C(m-1, k)` розглянемо доведення через метод твірних функцій.

Для заданого цілого `m ≥ 1` розглянемо двочленний вираз `P(x) = (1 - x)ᵐ`. За біномом Ньютона:

```
(1 - x)ᵐ = ∑_{r=0}ᵐ (-1)ʳ C(m, r) xʳ = 1 - ∑_{r=1}ᵐ (-1)ʳ⁻¹ C(m, r) xʳ
```

При підставці `x = 1` ліва частина перетворюється на `(1 - 1)ᵐ = 0`, що надає класичну біноміальну тотожність:

```
∑_{r=1}ᵐ (-1)ʳ⁻¹ C(m, r) = 1
```

Тепер розглянемо різницю між повною сумою (яка дорівнює 1) та урізаною сумою `fₖ(m)`:

```
1 - f_k(m) = ∑_{r=1}ᵐ (-1)ʳ⁻¹ C(m, r) - ∑_{r=1}ᵏ (-1)ʳ⁻¹ C(m, r)
           = ∑_{r=k+1}ᵐ (-1)ʳ⁻¹ C(m, r)
```

Застосовуючи біноміальну тотожність Паскаля `C(m, r) = C(m-1, r) + C(m-1, r-1)` та послідовне віднімання сусідніх доданків, залишок суми згортається у єдиний біноміальний коефіцієнт:

```
∑_{r=k+1}ᵐ (-1)ʳ⁻¹ C(m, r) = (-1)ᵏ C(m-1, k)
```

Звідси негайно отримуємо точну формулу:

```
f_k(m) = 1 - (-1)ᵏ C(m-1, k)
```

Цей метод твірних функцій демонструє, що похибка урізання нерівності Бонферроні порядку `k` дорівнює математичному сподіванню біноміального коефіцієнта `E[C(m-1, k)]`.

## Випадковий аналіз значень `fₖ(m)`

Розглянемо всі можливі значення `m` (кількості подій, що відбулися) та парність `k`:

### Випадок 1: `m = 0` (Жодна подія не відбулася)
Якщо `m = 0`, то `C(0, r) = 0` для всіх `r ≥ 1`.
Отже, `fₖ(0) = 0` для будь-якого `k ≥ 1`.
Індикатор об'єднання `I(⋃ Aᵢ)` при `m = 0` також дорівнює `0`.
Тому `fₖ(0) = I(⋃ Aᵢ) = 0` — рівність виконується тотожно.

### Випадок 2: `m ≥ 1` (Відбулася принаймні одна подія)
Індикатор об'єднання `I(⋃ Aᵢ)` при `m ≥ 1` дорівнює `1`.

- **Якщо `k` непарне (`k = 1, 3, 5, ...`):**
  Оскільки `k` непарне, то `(-1)ᵏ = -1`.
  Формула дає:
  ```
  f_k(m) = 1 - (-1)ᵏ C(m-1, k) = 1 + C(m-1, k)
  ```
  Оскільки біноміальний коефіцієнт `C(m-1, k) ≥ 0` для будь-яких цілих `m ≥ 1` та `k ≥ 1`, то:
  ```
  f_k(m) ≥ 1 = I(⋃_{i=1}ⁿ Aᵢ)
  ```

- **Якщо `k` парне (`k = 2, 4, 6, ...`):**
  Оскільки `k` парне, то `(-1)ᵏ = 1`.
  Формула дає:
  ```
  f_k(m) = 1 - (-1)ᵏ C(m-1, k) = 1 - C(m-1, k)
  ```
  Оскільки `C(m-1, k) ≥ 0`, маємо:
  ```
  f_k(m) ≤ 1 = I(⋃_{i=1}ⁿ Aᵢ)
  ```

### Крок 4. Перехід до математичного сподівання

Оскільки для кожного елементарного наслідку `ω ∈ Ω` виконуються нерівності між випадковими величинами:

```
f_{парне}(m) ≤ I(⋃_{i=1}ⁿ Aᵢ) ≤ f_{непарне}(m)
```

взявши математичне сподівання від усіх частин нерівності та використовуючи лінійність `E[...]`, отримуємо строгі нерівності для ймовірностей:

```
E[ f_{парне}(m) ] ≤ E[ I(⋃_{i=1}ⁿ Aᵢ) ] ≤ E[ f_{непарне}(m) ]
```

оскільки `E[I(⋃ Aᵢ)] = P(⋃ Aᵢ)`, це повністю доводить теорему Бонферроні:

```
∑_{r=1}^{2j} (-1)ʳ⁻¹ Sᵣ  ≤  P(⋃_{i=1}ⁿ Aᵢ)  ≤  ∑_{r=1}^{2j-1} (-1)ʳ⁻¹ Sᵣ
```

## Особливі випадки та геометрична інтерпретація

### Перший порядок (`k = 1`): Нерівність Буля (Union Bound)
При `k = 1` вираз дає нерівність Буля:

```
P(⋃_{i=1}ⁿ Aᵢ) ≤ S₁ = ∑_{i=1}ⁿ P(Aᵢ)
```
Це найпростіша верхня оцінка, яка припускає, що події взаємно не перетинаються. Якщо події мають спільні елементи, `S₁` перераховує їх кілька разів.

### Другий порядок (`k = 2`): Нижня межа другого порядку
При `k = 2` вираз віднімає ймовірності всіх парних перетинів:

```
P(⋃_{i=1}ⁿ Aᵢ) ≥ S₁ - S₂ = ∑_{i=1}ⁿ P(Aᵢ) - ∑_{1 ≤ i < j ≤ n} P(Aᵢ ∩ Aⱼ)
```
Ця оцінка враховує подвійне врахування перетинів. Якщо елемент належить двом подіям, у `S₁` він врахований 2 рази, а в `S₂` — 1 раз (`2 - 1 = 1`). Проте якщо елемент належить трьом подіям, у `S₁` він врахований 3 рази, а в `S₂` — `C(3, 2) = 3` рази (`3 - 3 = 0`), що призводить до недооцінки ймовірності (нижня межа).

### Монотонна збіжність меж

З фундаментальної формули `fₖ(m) - f_{k-1}(m) = (-1)ᵏ⁻¹ C(m-1, k-1)` безпосередньо випливає монотонність:

```
S₁  ≥  S₁ - S₂ + S₃  ≥  S₁ - S₂ + S₃ - S₄ + S₅  ≥  ...  ≥  P(⋃ Aᵢ)
S₁ - S₂  ≤  S₁ - S₂ + S₃ - S₄  ≤  S₁ - S₂ + S₃ - S₄ + S₅ - S₆  ≤  ...  ≤  P(⋃ Aᵢ)
```

Кожна наступна непарна сума покращує (зменшує) верхню оцінку, а кожна наступна парна сума покращує (збільшує) нижню оцінку, створюючи звужувальний вилка-інтервал (squeeze interval) навколо точного значення ймовірності.

## Узагальнення на ймовірності розподілу кількості подій `P(m = j)`

Нерівності Бонферроні можна розширити не лише для ймовірності об'єднання `P(m ≥ 1)`, але й для ймовірності того, що справдиться рівно `j` подій з `n` (`P(m = j)`) або щонайменше `j` подій (`P(m ≥ j)`).

Для довільного цілого `j ≥ 1` узагальнені нерівності Бонферроні (відомі також як тотожності Галамбоша-Сімонеллі) виражаються формулою:

```
P(m = j) ≤ ∑_{r=j}ᵏ (-1)ʳ⁻ʲ C(r, j) Sᵣ  (для непарних k - j)
P(m = j) ≥ ∑_{r=j}ᵏ (-1)ʳ⁻ʲ C(r, j) Sᵣ  (для парних k - j)
```

Це розширення дозволяє обчислювати вилкові межі для повного спектра розподілу частот випадкових подій у складних комбінаторних системах.
