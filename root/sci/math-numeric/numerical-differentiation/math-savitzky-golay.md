# 🧮 Математичне виведення ваг фільтра Савицького–Голея

Фільтр Савицького–Голея замінює чисельне ділення зашумлених різниць локальною апроксимацією даних методом найменших квадратів (МНК). Головна математична перевага підходу полягає в тому, що на рівномірній дискретній сітці розв'язок нормальних рівнянь Гаусса не залежить від значень вимірів і зводиться до постійної цифрової згортки (FIR-фільтра) із цілочисельними коефіцієнтами.

У цій вставці наведено повне матричне виведення аналітичних ваг фільтра Савицького–Голея для першої та другої похідних, продемонстровано розпад матриці Грама на незалежні парний та непарний блоки завдяки симетрії сітки, виведено зв'язок із дискретними ортогональними поліномами Грама, розібрано випадок поліномів 4-го степеня та оцінено коефіцієнт придушення дисперсії шуму.

---

### 1. Постановка задачі локального найменших квадратів

Нехай експериментальний сигнал дискретизовано з постійним часовим кроком `h`. Розглянемо симетричне ковзне вікно шириною `2m + 1` точок, центроване в поточному відліку `k`. Введемо локальну дискретну координату `t`, яка набуває цілих значень:

```
t ∈ {-m, -(m - 1), …, -1, 0, 1, …, m - 1, m}
```

Усередині цього локального вікна виміряні значення `y[k + t]` наближаються алгебраїчним многочленом степеня `p` (де степінь `p < 2m + 1`):

```
P(t) = c₀ + c₁·t + c₂·t² + … + c_p·t^p = ∑_{j=0}^p c_j · t^j
```

Критерієм оптимальності вектора невідомих коефіцієнтів `c = [c₀, c₁, …, c_p]ᵀ` є мінімізація зваженої суми квадратів відхилень моделі від спостережень:

```
S(c) = ∑_{t=-m}^m [ P(t) - y[k + t] ]²  →  min
```

Після знаходження оптимального вектора `c` аналітичні похідні в центрі вікна `t = 0` визначаються безпосередньо через значення відповідних коефіцієнтів розкладу за формулою Тейлора:

```
P(0)   = c₀                 [згладжене значення сигналу в точці k]
P′(0)  = (1 / h) · c₁       [оцінка першої похідної (швидкість)]
P″(0)  = (2 / h²) · c₂      [оцінка другої похідної (прискорення)]
P‴(0)  = (6 / h³) · c₃      [оцінка третьої похідної (ривок)]
```

### 2. Матрична структура та псевдообернення нормальних рівнянь

Запишемо значення шуканого полінома в усіх `2m + 1` вузлах вікна у векторно-матричній формі:

```
y_model = A · c
```

де `A` — матриця форми (матриця Вандермонда на дискретній сітці) розміру `(2m + 1) × (p + 1)`:

```
    [ 1   (-m)    (-m)²    …   (-m)^p    ]
    [ 1  -(m-1)  -(m-1)²   …  -(m-1)^p   ]
A = [ ⋮     ⋮        ⋮     ⋱      ⋮      ]
    [ 1     0        0     …      0      ]
    [ ⋮     ⋮        ⋮     ⋱      ⋮      ]
    [ 1     m       m²     …     m^p     ]
```

Задача найменших квадратів `||A·c - y||² → min` розв'язується через систему нормальних рівнянь Гаусса:

```
(Aᵀ · A) · c = Aᵀ · y                     [нормальні рівняння МНК]

c = (Aᵀ · A)⁻¹ · Aᵀ · y = H · y           [розв'язок через псевдообернену матрицю Мура–Пенроуза]
```

де `H = (Aᵀ · A)⁻¹ · Aᵀ` — проекційна матриця розміру `(p + 1) × (2m + 1)`.

Оскільки координати вузлів `t = -m, …, m` є фіксованими цілими числами, матриця `A` і матриця `H` є абсолютно сталими. Кожен `r`-й рядок матриці `H` містить фіксовані коефіцієнти імпульсної характеристики цифрового нерекурсивного FIR-фільтра для оцінки коефіцієнта `c_r`.

### 3. Симетрія сітки та блокова діагоналізація матриці Грама

Обчислимо елементи квадратної матриці Грама `G = Aᵀ · A` розміру `(p + 1) × (p + 1)`:

```
G_{r, s} = (Aᵀ · A)_{r, s} = ∑_{t=-m}^m t^r · t^s = ∑_{t=-m}^m t^{r + s},    де r, s ∈ [0, p]
```

Оскільки відрізок індексування `[-m, m]` є симетричним відносно нуля, сума будь-якого непарного степеня координати `t` тотожно дорівнює нулю:

```
∑_{t=-m}^m t^{2k + 1} = 0,    для будь-якого невід'ємного цілого k
```

Це фундаментальна алгебраїчна властивість: якщо сума індексів `r + s` є непарною, елемент матриці `G_{r, s} = 0`. В результаті матриця `Aᵀ · A` розпадається на шахову структуру з двох незалежних ортогональних блоків:
1. **Парний блок:** зв'язує парні коефіцієнти `[c₀, c₂, c₄, …]ᵀ`, що відповідають за згладжений сигнал і парні похідні (2-гу, 4-ту);
2. **Непарний блок:** зв'язує непарні коефіцієнти `[c₁, c₃, c₅, …]ᵀ`, що відповідають за непарні похідні (1-шу, 3-тю).

Парні та непарні коефіцієнти повністю розв'язуються незалежно один від одного. Важливо зазначити: оцінка першої похідної для кубічного полінома `p = 3` повністю збігається з оцінкою для квадратичного полінома `p = 2`, оскільки непарний блок матриці для `c₁` залишається незмінним. Додавання кубічного члена усуває похибку асиметрії, не змінюючи ваг лінійного нахилу.

### 4. Виведення коефіцієнтів першої похідної для полінома 2-го та 3-го степенів

Для квадратичного (`p = 2`) та кубічного (`p = 3`) поліномів непарний блок матриці Грама містить лише один ненульовий діагональний елемент `G₁₁`:

```
G₁₁ = ∑_{t=-m}^m t²

(Aᵀ · y)₁ = ∑_{t=-m}^m t · y_t
```

Тоді рівняння для першого коефіцієнта набуває вигляду:

```
G₁₁ · c₁ = (Aᵀ · y)₁

c₁ = (∑_{t=-m}^m t · y_t) / (∑_{t=-m}^m t²)     [аналітичний розв'язок для c₁]
```

Знайдемо аналітичний вираз для знаменника суми квадратів:

```
∑_{t=-m}^m t²
= 2 · ∑_{i=1}^m i²                          [симетрія парної функції]
= 2 · [ m·(m + 1)·(2m + 1) / 6 ]            [класична сума квадратів натурального ряду]
= [ m·(m + 1)·(2m + 1) ] / 3                [нормувальний дільник ваг 1-ї похідної]
```

Звідси випливає фундаментальний результат: **для квадратичного і кубічного фільтрів Савицького–Голея вага кожного відліку у вікні прямо пропорційна його зміщенню `t` від центру вікна**:

```
w_t = t,    де t ∈ [-m, m]
Norm = ∑_{t=-m}^m t² = [ m·(m + 1)·(2m + 1) ] / 3
```

Оцінка першої похідної визначається дискретною згорткою:

```
f′[k] = (1 / h) · c₁ = (1 / (h · Norm)) · ∑_{t=-m}^m t · y[k + t]
```

#### Розрахунок конкретних вікон:

- **5-точкове вікно (`m = 2`):**
  - Діапазон: `t ∈ [-2, -1, 0, 1, 2]`
  - Норма: `Norm = (2 · 3 · 5) / 3 = 10`
  - Ваги: `w = [-2, -1, 0, 1, 2]`
  - Формула: `f′[k] = (-2·y[k-2] - y[k-1] + 0·y[k] + y[k+1] + 2·y[k+2]) / (10·h)`

- **7-точкове вікно (`m = 3`):**
  - Діапазон: `t ∈ [-3, -2, -1, 0, 1, 2, 3]`
  - Норма: `Norm = (3 · 4 · 7) / 3 = 28`
  - Ваги: `w = [-3, -2, -1, 0, 1, 2, 3]`
  - Формула: `f′[k] = (-3·y[k-3] - 2·y[k-2] - y[k-1] + y[k+1] + 2·y[k+2] + 3·y[k+3]) / (28·h)`

- **9-точкове вікно (`m = 4`):**
  - Діапазон: `t ∈ [-4, -3, -2, -1, 0, 1, 2, 3, 4]`
  - Норма: `Norm = (4 · 5 · 9) / 3 = 60`
  - Ваги: `w = [-4, -3, -2, -1, 0, 1, 2, 3, 4]`
  - Формула: `f′[k] = (∑_{t=-4}^4 t · y[k+t]) / (60·h)`

### 5. Виведення коефіцієнтів другої похідної для квадратичного полінома (`p = 2`)

Для другої похідної розглядаємо парний блок розміру `2 × 2` для вектора `[c₀, c₂]ᵀ`:

```
[ S₀   S₂ ]   [ c₀ ]   [ ∑ y_t    ]
[ S₂   S₄ ] · [ c₂ ] = [ ∑ t²·y_t ]
```

де суми степенів дорівнюють:
```
S₀ = ∑_{t=-m}^m 1 = 2m + 1
S₂ = ∑_{t=-m}^m t² = [ m·(m + 1)·(2m + 1) ] / 3
S₄ = ∑_{t=-m}^m t⁴ = [ m·(m + 1)·(2m + 1)·(3m² + 3m - 1) ] / 15
```

Визначник парної матриці `Δ = S₀·S₄ - S₂²`:

```
Δ = (2m + 1)² · m · (m + 1) · (m - 1) · (m + 2) / 45
```

За правилом Крамера розв'язок для коефіцієнта `c₂`:

```
c₂ = (S₀ · ∑ t²·y_t - S₂ · ∑ y_t) / Δ = ∑_{t=-m}^m [ (S₀·t² - S₂) / Δ ] · y_t
```

Оскільки друга похідна полінома в центрі дорівнює `P″(0) = 2·c₂ / h²`, ваги для згортки другої похідної мають вигляд:

```
w_t = 2 · (S₀·t² - S₂) / Δ
```

#### Розрахунок для 5-точкового вікна (`m = 2`):
- `S₀ = 5`, `S₂ = 10`, `S₄ = 34`
- `Δ = 5 · 34 - 10² = 170 - 100 = 70`
- Для `t = 0`:  `w₀ = 2·(5·0 - 10)/70 = -20/70 = -2/7`
- Для `t = ±1`: `w_{±1} = 2·(5·1 - 10)/70 = -10/70 = -1/7`
- Для `t = ±2`: `w_{±2} = 2·(5·4 - 10)/70 = 20/70 = 2/7`
- Звідси отримуємо канонічний цілочисельний шаблон другої похідної:
  `f″[k] = (2·y[k-2] - y[k-1] - 2·y[k] - y[k+1] + 2·y[k+2]) / (7 · h²)`

### 6. Поліноми вищих степенів (`p = 4` для 7-точкового вікна)

Коли сигнал містить круті піки, квадратичний поліном може згладжувати вершини екстремумів. Для збереження гострих піків використовують поліном 4-го степеня `p = 4`.

У цьому разі парний блок матриці Грама має розмір `3 × 3` для `[c₀, c₂, c₄]ᵀ`, а непарний блок — розмір `2 × 2` для `[c₁, c₃]ᵀ`.

Для 7-точкового вікна (`m = 3`) з поліномом 4-го степеня розв'язання непарної системи `2 × 2` дає такі ваги для першої похідної:

```
w = [22, -67, -58, 0, 58, 67, -22] / (252 · h)
```

Поліном 4-го степеня значно краще зберігає динамічну форму сигналу та спектральну ширину ліній, проте має дещо менший коефіцієнт придушення високочастотного шуму порівняно з параболічним фільтром.

### 7. Теоретичний аналіз придушення шуму (VRF)

Нехай кожен вимір сигналу містить незалежний адитивний білий шум `e_t` із дисперсією `σ²` та нульовим математичним сподіванням: `E[e_i · e_j] = σ² · δ_{ij}`.

Оцінка похідної обчислюється як лінійна комбінація вимірів:

```
f̂′ = ∑_{t=-m}^m a_t · y_t,    де a_t = w_t / (h · Norm)
```

Дисперсія шуму оцінки похідної дорівнює:

```
Var(f̂′)
= Var( ∑ a_t · y_t )
= ∑ a_t² · Var(y_t)                         [незалежність шумових компонентів]
= [ (∑ w_t²) / (Norm² · h²) ] · σ²          [винесення константних множників]
```

Визначимо безрозмірний фактор зменшення дисперсії (Variance Reduction Factor):

```
VRF = (∑ w_t²) / Norm²
```

Для першої похідної підставимо знайдені значення `w_t = t` та `Norm = ∑ t²`:

```
VRF₁
= (∑ t²) / (∑ t²)²
= 1 / (∑_{t=-m}^m t²)
= 3 / [ m·(m + 1)·(2m + 1) ]
```

**Порівняння ефективності придушення шуму зі збільшенням вікна:**
- Звичайна скінченна центральна різниця на 2 точках (`m = 1`): `VRF = 1/2 = 0.500`.
- Савицький–Голей на 5 точок (`m = 2`): `VRF = 3/(2·3·5) = 1/10 = 0.100` (придушення шуму в 5 разів).
- Савицький–Голей на 7 точок (`m = 3`): `VRF = 3/(3·4·7) = 1/28 ≈ 0.0357` (придушення шуму в 14 разів).
- Савицький–Голей на 9 точок (`m = 4`): `VRF = 3/(4·5·9) = 1/60 ≈ 0.0167` (придушення шуму в 30 разів).
- Савицький–Голей на 11 точок (`m = 5`): `VRF = 3/(5·6·11) = 1/110 ≈ 0.00909` (придушення шуму в 55 разів).

Дисперсія шуму оціненої похідної спадає як `O(1 / m³)`. Таким чином, фільтр Савицького–Голея забезпечує потужне аналітичне придушення шуму за мінімальних апаратних витрат (лише кілька операцій множення з накопиченням MAC на відлік).
