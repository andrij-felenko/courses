Коли цифровий регулятор сервопривода чи польотний контролер безпілотника зчитує покази датчика положення із частотою 1 кГц, йому щотакту потрібні значення кутової швидкості та кутового прискорення для обчислення демпфувального моменту в [диференціальній ланці керування](root:embedded/derivative-control). Якщо обчислити швидкість за простою формулою різниці сусідніх відліків `(x[k] - x[k-1]) / dt`, навіть одиничний бітовий шум квантування АЦП або похибка в один імпульс оптичного енкодера з амплітудою `10⁻³` за крок `dt = 10⁻³ с` породжує стрибок швидкості величиною в `1.0` одиницю (100% від номіналу сигналу), а повторне взяття різниці для прискорення дає катастрофічний сплеск у `1000` одиниць на секунду в квадраті. Силові транзистори інвертора входять у насичення, обмотки двигуна перегріваються від високочастотного струму, а механічні редуктори зазнають ударних навантажень і вібраційного брязкоту.

Операція математичного [диференціювання](root:math-analysis/derivative) є оператором, що підсилює амплітуду кожної гармонійної складової сигналу прямо пропорційно її частоті `ω`. На відміну від інтегрування, яке згладжує випадкові відхилення завдяки накопичувальному усередненню, обчислення похідної діє як ідеальний фільтр високих частот із нескінченним коефіцієнтом підсилення на нескінченності. Зменшення кроку дискретизації `h`, яке в теоретичному математичному аналізі спрямовує похибку апроксимації до нуля, на практиці призводить до необмеженого зростання похибки вимірювань і розрядного заокруглення через ділення на зникаюче малий знаменник.

Щоб обчислювати похідні від експериментальних і цифрових сигналів без втрати стійкості системи, чисельний аналіз поєднує скінченно-різницеві шаблони високого порядку, апаратно-програмну оптимізацію кроку, регуляризацію та локальне поліноміальне згладжування.

### 1. Скінченно-різницеві схеми та їхнє виведення

Чисельне диференціювання базується на заміні неперервної похідної функції `f(x)` алгебраїчною комбінацією її значень у дискретній множині вузлів сітки, розташованих із кроком `h`.

Розвинемо значення функції у сусідніх вузлах `x + h` та `x - h` у ряд Тейлора в околі базової точки `x`, припускаючи, що функція `f(x)` є достатньо гладкою:

```
f(x + h) = f(x) + f′(x)·h + (1/2)·f″(x)·h² + (1/6)·f‴(x)·h³ + (1/24)·f⁽⁴⁾(x)·h⁴ + O(h⁵)
f(x - h) = f(x) - f′(x)·h + (1/2)·f″(x)·h² - (1/6)·f‴(x)·h³ + (1/24)·f⁽⁴⁾(x)·h⁴ + O(h⁵)
```

#### Схема прямої різниці (Forward Difference)

Виразимо першу похідну `f′(x)` із розкладу вперед:

```
f′(x)
= [f(x + h) - f(x)] / h - (1/2)·f″(ξ)·h      [перенесення членів вищих порядків]
= [f(x + h) - f(x)] / h + O(h)               [головний член похибки усікання O(h)]
```

де `ξ ∈ [x, x + h]`. Це одностороння схема першого порядку точності. Вона використовує інформацію з майбутнього або поточного стану, що робить її природною для покрокової екстраполяції в чисельному інтегруванні диференціальних рівнянь, проте її похибка спадає повільно — лінійно зі зменшенням кроку `h`.

#### Схема зворотної різниці (Backward Difference)

Аналогічно, виражаючи похідну з розкладу назад, отримуємо:

```
f′(x)
= [f(x) - f(x - h)] / h + (1/2)·f″(η)·h      [перенесення членів розкладу назад]
= [f(x) - f(x - h)] / h + O(h)               [головний член похибки усікання O(h)]
```

де `η ∈ [x - h, x]`. Зворотна різниця є базовим оператором для систем керування реального часу, оскільки вона спирається лише на вже збережені минулі виміри `x[k]` та `x[k-1]`, не вносячи часової затримки на очікування майбутніх відліків.

#### Схема центральної різниці (Central Difference)

Якщо відняти розклад для `f(x - h)` від розкладу для `f(x + h)`, усі парні степені кроку `h²`, `h⁴`, … взаємно знищуються завдяки симетрії відносно центральної точки:

```
f(x + h) - f(x - h)
= 2·f′(x)·h + (1/3)·f‴(x)·h³ + (1/60)·f⁽⁵⁾(x)·h⁵ + O(h⁷)  [віднімання двох розкладів Тейлора]

f′(x)
= [f(x + h) - f(x - h)] / (2·h) - (1/6)·f‴(ξ)·h²         [ділення на 2h]
= [f(x + h) - f(x - h)] / (2·h) + O(h²)                   [похибка другого порядку точності]
```

Центральна різниця забезпечує другий порядок точності `O(h²)`. Зменшення кроку `h` у 10 разів зменшує теоретичну похибка усікання формули у 100 разів. Геометрично центральна різниця відповідає нахилу січної, яка проходить через вузли `x - h` та `x + h`. Для гладкої кривої ця січна є строго паралельною дотичній у центральній точці `x` із точністю до параболічного члена кривини.

![Геометрія скінченно-різницевих схем](/root/sci/math-numeric/numerical-differentiation/img/finite-difference-stencils.svg)
*Геометричне зіставлення прямої, зворотної та центральної різниць. Завдяки взаємному скороченню парних членів Тейлора нахил центральної січної збігається з дотичною з точністю другого порядку O(h²).*

#### Багатоточкові шаблони вищого порядку (5-точковий шаблон)

Для досягнення четвертого порядку точності `O(h⁴)` розглядають симетричний п'ятиточковий шаблон, комбінуючи вузли `x ± 2h` та `x ± h`:

```
f(x + 2h) - f(x - 2h) = 4·f′(x)·h + (8/3)·f‴(x)·h³ + (32/120)·f⁽⁵⁾(x)·h⁵ + O(h⁷)
f(x + h) - f(x - h)   = 2·f′(x)·h + (1/3)·f‴(x)·h³ + (1/60)·f⁽⁵⁾(x)·h⁵ + O(h⁷)
```

Домноживши друге рівняння на 8 і віднявши від нього перше рівняння, ми повністю знищуємо член із третьою похідною `h³`:

```
8·[f(x + h) - f(x - h)] - [f(x + 2h) - f(x - 2h)]
= 12·f′(x)·h - (4/30)·f⁽⁵⁾(x)·h⁵ + O(h⁷)    [компенсація кубічного члена]

f′(x)
= [-f(x + 2h) + 8·f(x + h) - 8·f(x - h) + f(x - 2h)] / (12·h) + O(h⁴)  [ділення на 12h]
```

Цей шаблон вимагає збереження чотирьох сусідніх відліків, проте забезпечує надзвичайно швидке спадання похибки апроксимації зі швидкістю `h⁴`.

#### Апроксимація другої похідної

Друга похідна функції відповідає за кривину просторової траєкторії та фізичне прискорення матеріальної точки. Додамо розклади Тейлора вперед і назад:

```
f(x + h) + f(x - h)
= 2·f(x) + f″(x)·h² + (1/12)·f⁽⁴⁾(x)·h⁴ + O(h⁶)   [додавання розкладів Тейлора]

f″(x)
= [f(x + h) - 2·f(x) + f(x - h)] / h² - (1/12)·f⁽⁴⁾(ξ)·h²  [вираження другої похідної]
= [f(x + h) - 2·f(x) + f(x - h)] / h² + O(h²)      [центральна різниця другої похідної]
```

Схема другої похідної ділить різницю на квадрат кроку `h²`. Це робить другу похідну критично вразливою до високочастотного шуму: будь-яке збурення амплітудою `ε` у центральній точці породжує похибку величиною `2·ε / h²`.

#### Чисельні формули на нерівномірній сітці

У реальних вбудованих системах інтервал між вимірами не завжди сталий: таймери зазнають джиттера, а дані від бездротових сенсорів надходять із затримками. Нехай крок ліворуч дорівнює `h_L = x - x_{prev}`, а крок праворуч — `h_R = x_{next} - x`. 

Застосувавши метод невизначених коефіцієнтів до лінійної комбінації `f′(x) ≈ a·f(x - h_L) + b·f(x) + c·f(x + h_R)`, отримуємо узагальнену формулу центральної різниці на нерівномірній сітці:

```
f′(x) = [ f(x + h_R)·h_L² - f(x - h_L)·h_R² - f(x)·(h_L² - h_R²) ] / [ h_L · h_R · (h_L + h_R) ]
```

Якщо `h_L ≠ h_R`, порядок апроксимації падає з `O(h²)` до `O(h_R - h_L) + O(h²)`. Симетрія руйнується, і нерівномірний крок вносить додаткову похибку першого порядку.

### 2. Фундаментальна дилема: похибка апроксимації проти шуму

У класичному математичному аналізі похідна визначається як нескінченно мале відношення приростів при `h → 0`. Проте в обчислювальній практиці функція `f(x)` ніколи не задана абсолютно точно. Кожне значення містить похибку `e(x)`:

```
f̃(x) = f(x) + e(x),    де |e(x)| ≤ ε
```

Причиною невизначеності `ε` є або машинне заокруглення чисел із плаваючою комою стандарту [IEEE 754](root:math-numeric/ieee754) (де машинна точність становить `ε ≈ ε_mach ≈ 1.11·10⁻¹⁶` для подвійної точності `float64` та `ε ≈ 5.96·10⁻⁸` для одинарної точності `float32`), або крок квантування аналого-цифрового перетворювача (де `ε = V_ref / 2ⁿ`).

Розглянемо сумарну похибку центральної різниці при використанні зашумлених вимірів `f̃`:

```
f̃′_num(x) = [f̃(x + h) - f̃(x - h)] / (2·h)
```

Підставимо розклад функції та похибки вимірів:

```
f̃′_num(x) - f′(x)
= [f(x + h) - f(x - h)] / (2·h) - f′(x) + [e(x + h) - e(x - h)] / (2·h)
= (1/6)·f‴(ξ)·h² + [e(x + h) - e(x - h)] / (2·h)    [відокремлення усікання та шуму]
```

Оцінимо абсолютне значення повної похибки за нерівністю трикутника:

```
|E_total(h)|
≤ (M₃ / 6)·h² + (2·ε) / (2·h)     [де M₃ = max |f‴(ξ)| на відрізку]
= (M₃ / 6)·h² + ε / h             [сума похибки усікання та похибки шуму]
```

Повна похибка складається з двох антагоністичних компонентів:
1. **Похибка усікання (Truncation Error):** `E_trunc(h) = (M₃ / 6)·h²`. Зменшується монотонно зі зменшенням кроку `h`.
2. **Похибка шуму / заокруглення (Noise / Round-off Error):** `E_noise(h) = ε / h`. Необмежено зростає при `h → 0`, оскільки чисельник обмежений константою шуму `ε`, а знаменник прямує до нуля.

![Фундаментальна дилема чисельного диференціювання](/root/sci/math-numeric/numerical-differentiation/img/differentiation-dilemma-step.svg)
*Фундаментальна дилема чисельного диференціювання у логарифмічних координатах. Оптимальний крок h_opt лежить у точці перетину спадної лінії усікання Тейлора та зростаючої прямої підсилення шуму.*

#### Обчислення оптимального кроку `h_opt`

Знайдемо мінімум функції повної похибки `E(h) = (M₃ / 6)·h² + ε / h`, прирівнявши її похідну за кроком `h` до нуля:

```
dE/dh
= (M₃ / 3)·h - ε / h² = 0            [умова екстремуму сумарної похибки]
(M₃ / 3)·h = ε / h²
h³ = (3·ε) / M₃                      [домноження на h² та ізоляція h]
h_opt = [ (3·ε) / M₃ ]^(1/3)         [оптимальний крок центральної різниці]
```

Підставивши знайдений `h_opt` у формулу повної похибки, знайдемо теоретичну мінімальну похибку чисельного диференціювання:

```
E_min
= (M₃ / 6)·[(3·ε) / M₃]^(2/3) + ε·[M₃ / (3·ε)]^(1/3)
= C · (ε² · M₃)^(1/3) = O(ε^(2/3))   [теоретична межа точності центральної різниці]
```

Для схеми прямої різниці першого порядку оптимум має вигляд:

```
E_forward(h) ≤ (M₂ / 2)·h + (2·ε) / h
dE/dh = M₂ / 2 - (2·ε) / h² = 0  ⇒  h_opt = 2·√(ε / M₂)
E_min_forward = O(√ε)
```

Для другої похідної:

```
E_second(h) ≤ (M₄ / 12)·h² + (4·ε) / h²
dE/dh = (M₄ / 6)·h - (8·ε) / h³ = 0  ⇒  h_opt = [ (48·ε) / M₄ ]^(1/4)
E_min_second = O(√ε)
```

**Порівняльний числовий аналіз типів даних:**

| Тип даних | Рівень похибки `ε` | Оптимальний крок `h_opt` (1-ша похідна) | Досяжна точність `E_min` | Втрата значущих цифр |
|---|---|---|---|---|
| `float32` (одинарна точність) | `1.19·10⁻⁷` | `h_opt ≈ 7.1·10⁻³` | `E_min ≈ 2.5·10⁻⁵` | Втрачено 2.5 розряди з 7 |
| `float64` (подвійна точність) | `2.22·10⁻¹⁶` | `h_opt ≈ 8.7·10⁻⁶` | `E_min ≈ 3.8·10⁻¹¹` | Втрачено 5.4 розряди з 16 |
| 12-бітний сенсор АЦП | `2.44·10⁻⁴` | `h_opt ≈ 9.0·10⁻²` | `E_min ≈ 4.1·10⁻³` | Втрачено 1.5 розряди з 3.6 |

#### Частотний аналіз підсилення шуму

Перейдемо в частотну область, розглянувши комплексний коефіцієнт передачі дискретного оператора центральної різниці `H_diff(jω)`:

```
H_diff(jω) = [ e^(j·ω·h) - e^(-j·ω·h) ] / (2·h) = j · [ sin(ω·h) / h ]
```

Для низьких частот `ω·h ≪ 1` розклад синуса дає `sin(ω·h)/h ≈ ω · (1 - (ω·h)²/6)`, що збігається з ідеальним диференціатором `j·ω`. Проте якщо сигнал містить широкосмуговий білий шум із постійною спектральною густиною потужності `S_n(ω) = σ²`, потужність шуму на виході диференціатора в смузі Найквіста `[0, π/h]` дорівнює:

```
P_noise_out = (1 / π) · ∫₀^(π/h) [ sin²(ω·h) / h² ] · σ² dω = σ² / (2 · h³)
```

Дисперсія вихідного шуму зростає обернено пропорційно кубу кроку `h³`.

#### Некоректність задачі за Адамаром

Французький математик Жак Адамар сформулював критерій коректності математичної задачі: розв'язок має існувати, бути єдиним і неперервно залежати від вхідних даних. Задача чисельного диференціювання є **некоректно поставленою за Адамаром** на просторі неперервних функцій `C[a, b]`: як завгодно мале збурення амплітуди `ε·sin(ω·t)` при високій частоті `ω > 1/ε²` породжує нескінченно велике збурення похідної `ε·ω → ∞`. 

Детальніше про історичну еволюцію поглядів на некоректні задачі від таблиць Ньютона до методів Тихонова читайте у вставці [📜 Від таблиць Тейлора до спектроскопії: історія чисельного диференціювання](root:math-numeric/numerical-differentiation/hist-numerical-differentiation.md).

#### Екстраполяція Річардсона

Якщо шум відсутній (наприклад, диференціюється точна аналітична функція в математичній бібліотеці), похибку усікання можна усунути за допомогою екстраполяції Річардсона. Обчислимо центральну різницю з двома різними кроками `h` та `h/2`:

```
D(h)   = f′(x) + C·h² + O(h⁴)
D(h/2) = f′(x) + C·(h/2)² + O(h⁴) = f′(x) + (C/4)·h² + O(h⁴)
```

Домножимо друге рівняння на 4 і віднімемо перше:

```
4·D(h/2) - D(h) = 3·f′(x) + O(h⁴)

D_richardson = [ 4·D(h/2) - D(h) ] / 3 = f′(x) + O(h⁴)
```

Екстраполяція Річардсона підвищує порядок точності з другого до четвертого без необхідності виведення складних аналітичних формул. Проте у присутності шуму вимірювань множник `4/3` додатково підсилює випадкову похибку, тому екстраполяцію застосовують виключно до гладких модельних функцій.

### 3. Диференціювання зашумлених сигналів

Оскільки пряме скінченно-різницеве диференціювання зашумлених даних руйнує сигнал, на практиці використовують двоетапний підхід: спершу сигнал згладжують або проектують на простір гладких функцій за допомогою [цифрових FIR-фільтрів](root:com-signal/fir-filter), а потім беруть аналітичну похідну від згладженої моделі.

#### Фільтр Савицького–Голея (Savitzky-Golay Filter)

У 1964 році Абрахам Савицький та Марсель Голей запропонували метод локальної поліноміальної фільтрації: у ковзному симетричному вікні довжиною `2m + 1` точок `[-m, -(m-1), …, 0, …, m-1, m]` набір даних апроксимується поліномом низького степеня `p` (зазвичай `p = 2` або `p = 3`) методом найменших квадратів:

```
P(t) = c₀ + c₁·t + c₂·t² + … + c_p·t^p
```

Центр вікна розташовано в точці `t = 0`. Знайшовши аналітичні коефіцієнти полінома `c_k`, значення похідних у центральній точці визначаються миттєво безпосередньо з коефіцієнтів розкладу:

```
P(0)   = c₀          [згладжене значення сигналу]
P′(0)  = c₁          [оцінка першої похідної]
P″(0)  = 2·c₂        [оцінка другої похідної]
```

![Фільтр Савицького–Голея](/root/sci/math-numeric/numerical-differentiation/img/savitzky-golay-smoothing.svg)
*Принцип диференціювання Савицького–Голея. Локальний параболічний поліном підганяється під 2m+1 точок методом найменших квадратів. Перша похідна в центральній точці дорівнює коефіцієнту c₁ і обчислюється через цифрову згортку.*

Оскільки позиції вузлів у вікні є фіксованими цілими числами `t = -m, …, m`, нормальні рівняння методу найменших квадратів розв'язуються аналітично один раз, а обчислення коефіцієнтів зводиться до дискретної лінійної згортки (FIR-фільтрації) із постійними цілочисельними ваговими коефіцієнтами `w_i`:

```
f′[k] = (1 / (h · Norm)) · ∑_{i=-m}^m w_i · y[k + i]
```

**Таблиця коефіцієнтів Савицького–Голея для 1-ї похідної (квадратичний/кубічний поліном `p=2, 3`):**

| Розмір вікна `2m+1` | Вагові коефіцієнти `[w_{-m}, …, w_m]` | Нормувальний дільник `Norm` | Фактор зменшення дисперсії шуму (VRF) |
|---|---|---|---|
| 5 точок (`m=2`) | `[-2, -1, 0, 1, 2]` | 10 | `10 / 100 = 0.100` |
| 7 точок (`m=3`) | `[-3, -2, -1, 0, 1, 2, 3]` | 28 | `28 / 784 ≈ 0.0357` |
| 9 точок (`m=4`) | `[-4, -3, -2, -1, 0, 1, 2, 3, 4]` | 60 | `60 / 3600 ≈ 0.0167` |

**Таблиця коефіцієнтів для 2-ї похідної (квадратичний поліном `p=2`):**

| Розмір вікна `2m+1` | Вагові коефіцієнти `[w_{-m}, …, w_m]` | Нормувальний дільник `Norm · h²` |
|---|---|---|
| 5 точок (`m=2`) | `[2, -1, -2, -1, 2]` | `7 · h²` |
| 7 точок (`m=3`) | `[5, 0, -3, -4, -3, 0, 5]` | `42 · h²` |

Строге матричне виведення псевдообернених матриць для поліноміальних ваг довільного степеня наведено у вставці [🧮 Математичне виведення ваг фільтра Савицького–Голея](root:math-numeric/numerical-differentiation/math-savitzky-golay.md).

#### Згладжувальні сплайни та регуляризація Тихонова

Альтернативою локальним вікнам є глобальна регуляризація на основі [кубічних сплайнів](root:math-numeric/cubic-splines). Нехай шукається гладка крива `s(x)`, яка мінімізує функціонал Тихонова:

```
J(s) = ∑_{i=1}^N [ s(x_i) - y_i ]² + λ · ∫_{x₁}^{x_N} [ s″(x) ]² dx  →  min
```

Параметр регуляризації `λ > 0` задає компроміс: при `λ → 0` функціонал вироджується в точний інтерполяційний сплайн (що чутливий до шуму), а при `λ → ∞` розв'язок прямує до прямої лінії МНК. Аналітичне диференціювання сплайна `s′(x)` дає неперервну та стійку оцінку швидкості по всьому інтервалу спостереження.

#### Фільтрація низьких частот (LPF) перед диференціюванням

У замкнених контурах автоматичного керування фільтр Савицького-Голея вносить затримку на `m` тактів, оскільки для центральної оцінки потрібні майбутні виміри. Якщо затримка неприпустима, застосовують каскад: спершу причинний аналоговий чи цифровий [фільтр Баттерворта](root:com-signal/butterworth-filter) першого або другого порядку, а потім — зворотну різницю.

Передатна функція ідеального диференціатора `D(s) = s` у каскаді з фільтром низьких частот першого порядку із постійною часу `T_f`:

```
H(s) = s / (1 + T_f · s)
```

Застосуємо білінійне Z-перетворення (метод Тастіна) `s ≈ (2/T_s) · (1 - z⁻¹) / (1 + z⁻¹)` для переходу в дискретний час:

```
H(z)
= [ (2/T_s)·(1 - z⁻¹)/(1 + z⁻¹) ] / [ 1 + T_f·(2/T_s)·(1 - z⁻¹)/(1 + z⁻¹) ]
= [ 2·(1 - z⁻¹) ] / [ (2·T_f + T_s) + (T_s - 2·T_f)·z⁻¹ ]
```

Це дає рекурентне різницеве рівняння реального часу:

```
y[k] = α · y[k-1] + β · (x[k] - x[k-1])
де  α = (2·T_f - T_s) / (2·T_f + T_s),    β = 2 / (2·T_f + T_s)
```

При високих частотах коефіцієнт передачі перестає зростати й обмежується величиною `1 / T_f`, що надійно блокує високочастотний шум квантування.

### 4. Обчислення швидкості та прискорення з дискретних енкодерів

Типовою задачею вбудованої робототехніки є оцінка швидкості обертання вала двигуна за сигналами [оптичного інкрементного енкодера](root:hw-sensing/optical-incremental-encoder). Енкодер генерує ціле число імпульсів (наприклад, `N_c = 4096` відліків на один повний оберт).

![Оцінка швидкості з енкодера](/root/sci/math-numeric/numerical-differentiation/img/encoder-velocity-quantization.svg)
*Обчислення швидкості з квантованого сигналу енкодера. Наївне ділення дискретних приростів на фіксований час створює розривні сплески амплітудою в одиницю квантування, тоді як фільтрований диференціатор забезпечує гладку траєкторію.*

Існують два класичні методи обчислення похідної переміщення:

#### 1. Метод фіксованого часу (M-метод або частотний метод)

Контролер підраховує кількість імпульсів `ΔN`, що надійшли за фіксований квант часу таймера `ΔT` (наприклад, 1 мс):

```
v_M = (2·π · ΔN) / (N_c · ΔT)    [рад/с]
```

- **Перевага:** Сталий такт виконання алгоритму, простота реалізації в перериванні таймера.
- **Фатальний недолік на низьких швидкостях:** Якщо за такт надходить лише 0 або 1 імпульс, оцінка швидкості хаотично стрибає між `0` та `v_min = 2·π / (N_c · ΔT)`. Для `N_c = 1000`, `ΔT = 1 мс` квант швидкості становить `6.28 рад/с ≈ 60 об/хв`. Оцінити рух на швидкості 10 об/хв за M-методом неможливо.

#### 2. Метод вимірювання періоду (T-метод)

Контролер фіксує апаратним таймером час `Δt` між двома сусідніми фронтами імпульсів енкодера:

```
v_T = (2·π) / (N_c · Δt)    [рад/с]
```

- **Перевага:** Надзвичайно висока точність на наднизьких швидкостях (при `v → 0`, `Δt` зростає, таймер відраховує мільйони тактів із точністю до мікросекунд).
- **Недолік на високих швидкостях:** При швидкості 6000 об/хв частота імпульсів сягає сотень кілогерців, що перевантажує процесор обробкою переривань. Крім того, неточність кроку насічок диска енкодера створює просторовий періодичний шум.

#### 3. Гібридний M/T-метод і спостерігач стану (Alpha-Beta-Gamma Filter)

Сучасні приводи використовують відслідковувальний фільтр стану другого/третього порядку (спостерігач Луенбергера або `α-β-γ` фільтр). Він відновлює неперервні оцінки положення `x̂`, швидкості `v̂` та прискорення `â`, інтегруючи динамічну модель руху між моментами надходження квантів енкодера:

```
x̂_pred[k] = x̂[k-1] + v̂[k-1]·dt + (1/2)·â[k-1]·dt²    [прогноз положення]
v̂_pred[k] = v̂[k-1] + â[k-1]·dt                         [прогноз швидкості]
â_pred[k] = â[k-1]                                      [прогноз прискорення]

e[k] = x_meas[k] - x̂_pred[k]                            [похибка інновації виміру]

x̂[k] = x̂_pred[k] + α · e[k]                             [корекція положення]
v̂[k] = v̂_pred[k] + (β / dt) · e[k]                      [корекція швидкості]
â[k] = â_pred[k] + (2·γ / dt²) · e[k]                   [корекція прискорення]
```

Коефіцієнти `α, β, γ ∈ (0, 1)` налаштовуються за співвідношенням шуму вимірювань і максимального динамічного прискорення системи.

### 5. Інженерна реалізація стійкого диференціатора на C та C++

У вбудованих системах критично важливими є такі вимоги:
1. **Детермінізм пам'яті:** Повна відсутність динамічного виділення пам'яті (`malloc`/`new`).
2. **Часова складність `O(1)`:** Фіксований час обчислення на кожному кроці переривання.
3. **Чисельна стійкість:** Захист від ділення на нульовий або від'ємний крок `dt <= 0`, захист від переповнення та насичення виходу.

Нижче наведено два взаємодоповнюючі алгоритми:
1. **Фільтрований диференціатор 1-го порядку (LPF + Backward Diff)** для систем реального часу з мінімальною фазовою затримкою.
2. **Ковзний диференціатор Савицького–Голея на 5 точок** для одночасного обчислення швидкості та прискорення.

Повну бібліотеку алгоритмів відслідковувального нелінійного диференціювання дивіться у вставці [⚙️ Стійкий диференціатор сигналів реального часу для вбудованих систем](root:math-numeric/numerical-differentiation/proj-robust-differentiator.md).

```c
#include <stdbool.h>
#include <math.h>

/* --- 1. Фільтрований диференціатор першого порядку (LPF Differentiator) --- */
typedef struct {
    float prev_input;    /* попереднє значення x[k-1] */
    float output;        /* поточна оцінка похідної y[k] */
    float cutoff_hz;     /* частота зрізу фільтра низьких частот */
} LowPassDifferentiator;

void lpf_diff_init(LowPassDifferentiator* self, float cutoff_hz) {
    self->prev_input = 0.0f;
    self->output = 0.0f;
    self->cutoff_hz = (cutoff_hz > 0.1f) ? cutoff_hz : 0.1f;
}

float lpf_diff_update(LowPassDifferentiator* self, float input, float dt) {
    if (dt <= 0.000001f) {
        return self->output; /* захист від некоректного кроку часу */
    }
    
    /* Розрахунок коефіцієнта згладжування фільтра низьких частот: alpha = dt / (RC + dt) */
    const float tau = 1.0f / (2.0f * 3.1415926535f * self->cutoff_hz);
    const float alpha = dt / (tau + dt);
    
    /* Чисельна зворотна різниця */
    const float raw_diff = (input - self->prev_input) / dt;
    self->prev_input = input;
    
    /* Експоненційне згладжування похідної */
    self->output += alpha * (raw_diff - self->output);
    return self->output;
}

/* --- 2. Диференціатор Савицького–Голея (вікно 5 точок, поліном 2-го степеня) --- */
typedef struct {
    float buf[5];        /* кільцевий буфер вимірів положення */
    int head;            /* індекс останнього доданого елемента */
    int count;           /* кількість накопичених відліків */
} SavitzkyGolay5;

void sg5_init(SavitzkyGolay5* self) {
    for (int i = 0; i < 5; ++i) self->buf[i] = 0.0f;
    self->head = 0;
    self->count = 0;
}

void sg5_push(SavitzkyGolay5* self, float val) {
    self->head = (self->head + 1) % 5;
    self->buf[self->head] = val;
    if (self->count < 5) self->count++;
}

bool sg5_compute(const SavitzkyGolay5* self, float dt, float* out_velocity, float* out_accel) {
    if (self->count < 5 || dt <= 0.000001f) {
        return false; /* буфер ще не заповнено для повноцінної згортки */
    }
    
    /* Витягуємо відліки від найстарішого до найновішого: y_0, y_1, y_2, y_3, y_4 */
    float y[5];
    for (int i = 0; i < 5; ++i) {
        int idx = (self->head - 4 + i + 5) % 5;
        y[i] = self->buf[idx];
    }
    
    /* Ваги Савицького–Голея для 1-ї похідної: [-2, -1, 0, 1, 2] / (10 * dt) */
    if (out_velocity) {
        *out_velocity = (-2.0f * y[0] - 1.0f * y[1] + 0.0f * y[2] + 1.0f * y[3] + 2.0f * y[4]) / (10.0f * dt);
    }
    
    /* Ваги Савицького–Голея для 2-ї похідної: [2, -1, -2, -1, 2] / (7 * dt^2) */
    if (out_accel) {
        *out_accel = (2.0f * y[0] - 1.0f * y[1] - 2.0f * y[2] - 1.0f * y[3] + 2.0f * y[4]) / (7.0f * dt * dt);
    }
    
    return true;
}
```

```cpp
#include <array>
#include <numbers>
#include <optional>
#include <span>

/* --- 1. Фільтрований диференціатор першого порядку (C++20) --- */
class LowPassDifferentiator {
public:
    constexpr explicit LowPassDifferentiator(float cutoff_hz = 10.0f) noexcept
        : cutoff_hz_{cutoff_hz > 0.1f ? cutoff_hz : 0.1f} {}

    [[nodiscard]] float update(float input, float dt) noexcept {
        if (dt <= 1e-6f) {
            return output_;
        }

        const float tau = 1.0f / (2.0f * std::numbers::pi_v<float> * cutoff_hz_);
        const float alpha = dt / (tau + dt);

        const float raw_diff = (input - prev_input_) / dt;
        prev_input_ = input;

        output_ += alpha * (raw_diff - output_);
        return output_;
    }

    [[nodiscard]] constexpr float value() const noexcept { return output_; }
    constexpr void reset() noexcept {
        prev_input_ = 0.0f;
        output_ = 0.0f;
    }

private:
    float prev_input_{0.0f};
    float output_{0.0f};
    float cutoff_hz_{10.0f};
};

/* --- 2. Шаблонний фільтр Савицького–Голея для 1-ї та 2-ї похідних --- */
template <std::size_t N = 5>
requires (N == 5)
class SavitzkyGolayDifferentiator {
public:
    struct Derivatives {
        float velocity{0.0f};
        float acceleration{0.0f};
    };

    constexpr SavitzkyGolayDifferentiator() noexcept = default;

    void push(float value) noexcept {
        head_ = (head_ + 1) % N;
        buf_[head_] = value;
        if (count_ < N) {
            ++count_;
        }
    }

    [[nodiscard]] std::optional<Derivatives> compute(float dt) const noexcept {
        if (count_ < N || dt <= 1e-6f) {
            return std::nullopt;
        }

        std::array<float, N> y{};
        for (std::size_t i = 0; i < N; ++i) {
            const std::size_t idx = (head_ + 1 + i) % N;
            y[i] = buf_[idx];
        }

        /* Згортка для 1-ї похідної (ваги -2, -1, 0, 1, 2, норма 10) */
        const float vel = (-2.0f * y[0] - 1.0f * y[1] + 1.0f * y[3] + 2.0f * y[4]) / (10.0f * dt);
        
        /* Згортка для 2-ї похідної (ваги 2, -1, -2, -1, 2, норма 7*dt^2) */
        const float acc = (2.0f * y[0] - 1.0f * y[1] - 2.0f * y[2] - 1.0f * y[3] + 2.0f * y[4]) / (7.0f * dt * dt);

        return Derivatives{.velocity = vel, .acceleration = acc};
    }

    constexpr void clear() noexcept {
        buf_.fill(0.0f);
        head_ = 0;
        count_ = 0;
    }

private:
    std::array<float, N> buf_{};
    std::size_t head_{0};
    std::size_t count_{0};
};
```

### 6. Порівняльний синтез методів чисельного диференціювання

Вибір схеми диференціювання визначається компромісом між латентністю, рівнем придушення шуму вимірювань і наявними обчислювальними ресурсами:

| Метод | Порядок апроксимації | Чутливість до шуму | Фазова затримка (Latency) | Рекомендована сфера застосування |
|---|---|---|---|---|
| **Зворотна різниця 1-го порядку** | `O(h)` | Катастрофічна (`O(ε/h)`) | 0 тактів (миттєва) | Тільки надгладкі математичні моделі без шуму |
| **Центральна різниця 2-го порядку** | `O(h²)` | Дуже висока | 1 такт (`h`) | Офлайн-обробка табличних аналітичних функцій |
| **Фільтр низьких частот + зворотна різниця** | `O(h)` | Низька (регулюється `T_f`) | `T_f` секунд | Контури швидкості сервоприводів та PID-регулятори |
| **Фільтр Савицького–Голея (`2m+1` точок)** | `O(h²)` / `O(h⁴)` | Мінімальна (VRF `~ 1/m`) | `m` тактів | Спектроскопія, обробка траєкторій, фільтрація сигналів |
| **Спостерігач стану (Alpha-Beta-Gamma)** | Неперервна модель | Мінімальна (оптимальна) | `0` тактів (прогнозує стан) | Одометрія роботів, трекінг енкодерів на малих швидкостях |

Чисельне диференціювання вимагає постійного балансування між динамічною чуйністю системи та придушенням високочастотного шуму. Розуміння фундаментальної межі точності `h_opt` захищає розробника від фатальної помилки бездумного зменшення кроку дискретизації, а використання локальної поліноміальної апроксимації та фільтрів стану дозволяє будувати надійні системи керування навіть в умовах сильного квантування датчиків.
