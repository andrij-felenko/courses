# 🧮 Алгебраїчні та аналітичні виведення формули Вандермонда

Визначник матриці зі степенями вузлів завжди згортається у компактний добуток усіх попарних різниць координат, і цей фундаментальний результат можна строго довести трьома принципово різними шляхами — через властивості коренів многочленів, через елементарні стовпчикові операції Гаусса та через комбінаторну теорію симетричних функцій. Крім того, формулу можна узагальнити на випадок кратних вузлів (конфлюентні матриці), що є наріжним каменем інтерполяції Ерміта та теорії диференціальних рівнянь.

---

### Постановка задачі та структура матриці

Нехай задано впорядкований набір із `n` елементів `x₀, x₁, x₂, ..., x_{n-1}`, які належать деякому комутативному полю (наприклад, полю дійсних чисел `ℝ`, комплексних чисел `ℂ` або скінченному полю Галуа `GF(q)`).

Матрицею Вандермонда порядку `n`, яку ми позначимо символом `V_n`, називається квадратна таблиця розміру `n × n`, елемент якої на перетині рядка з номером `i` (де індекс `i` змінюється від `0` до `n - 1`) та стовпчика з номером `j` (де індекс `j` змінюється від `0` до `n - 1`) дорівнює `j`-му степеню елемента `x_i`:

```
V_{i, j} = x_i^j
```

Розгорнутий вигляд матриці `V_n`:

```
|  1    x₀    x₀²   ...  x₀ⁿ⁻¹  |
|  1    x₁    x₁²   ...  x₁ⁿ⁻¹  |
|  1    x₂    x₂²   ...  x₂ⁿ⁻¹  |
|  ⋮     ⋮     ⋮     ⋱     ⋮    |
|  1   xₙ₋₁  xₙ₋₁²  ... xₙ₋₁ⁿ⁻¹ |
```

Наша мета — довести загальну теорему: визначник матриці `V_n` дорівнює добутку всіх можливих різниць `(x_j - x_i)` для всіх пар індексів `(i, j)`, де індекс `j` є строго більшим за індекс `i`:

```
det(V_n) = ∏_{0 ≤ i < j < n} (x_j - x_i)
```

У цій формулі символ `∏` (велика грецька літера «Пі») позначає операцію перемноження всіх співмножників, що задовольняють зазначену під символом умову. Оскільки ми обираємо дві невпорядковані позиції `i` та `j` із загальної кількості `n` елементів, кількість співмножників у добутку точно дорівнює числу комбінацій з `n` по 2:

```
N_{множників} = n · (n - 1) / 2
```

### Метод 1: Поліноміальне виведення через теорему Безу

Перший спосіб виведення спирається на базову властивість многочленів: якщо число `r` є коренем многочлена `P(x)`, то цей многочлен ділиться на лінійний двочлен `(x - r)` без остачі (теорема Безу).

Зафіксуємо перші `n - 1` вузлів `x₀, x₁, ..., x_{n-2}` як сталі параметри, а останній вузол `x_{n-1}` замінимо на формальну змінну `x`. Розглянемо функцію `P(x)`, визначену як детермінант матриці розміру `n × n`, у якій останній рядок складено зі степенів змінної `x`:

```
P(x) = det |  1    x₀    x₀²   ...  x₀ⁿ⁻¹  |
           |  1    x₁    x₁²   ...  x₁ⁿ⁻¹  |
           |  ⋮     ⋮     ⋮     ⋱     ⋮    |
           |  1   xₙ₋₂  xₙ₋₂²  ... xₙ₋₂ⁿ⁻¹ |
           |  1     x     x²   ...   xⁿ⁻¹  |
```

Знайдемо степінь та корені функції `P(x)` за допомогою послідовних кроків.

#### Крок 1.1: Ступінь многочлена та провідний коефіцієнт

Розкладемо визначник за останнім (змінним) рядком матриці за теоремою Лапласа. Елементами останнього рядка є `1, x, x², ..., x^{n-1}`. Позначимо алгебраїчне доповнення до елемента на позиції `(n - 1, j)` символом `A_j`. Отримуємо вираз:

```
P(x) = A₀ · 1 + A₁ · x + A₂ · x² + ... + A_{n-1} · x^{n-1}
```

Кожне алгебраїчне доповнення `A_j` обчислюється через викреслювання останнього рядка та відповідного стовпчика. Оскільки викреслюється саме змінний рядок, жодне з чисел `A_j` не залежить від змінної `x` — вони є сталими величинами, складеними виключно з вузлів `x₀, x₁, ..., x_{n-2}`.

Отже, `P(x)` є алгебраїчним многочленом від змінної `x` степеня не вище `n - 1`.

Звернемо особливу увагу на старший коефіцієнт `A_{n-1}` при найвищому степені `x^{n-1}`. Він утворюється викреслюванням останнього рядка з індексом `n - 1` та останнього стовпчика з індексом `n - 1`:

```
A_{n-1}
= (-1)^{(n-1) + (n-1)} · det(V_{n-1}(x₀, x₁, ..., x_{n-2}))   [викреслювання останнього рядка і стовпчика]
= (-1)^{2n - 2} · det(V_{n-1}(x₀, x₁, ..., x_{n-2}))          [спрощення суми показників степеня]
= det(V_{n-1}(x₀, x₁, ..., x_{n-2}))                           [парний степінь: (-1)^{2n-2} = 1]
```

Оскільки показник степеня `2n - 2` завжди парний, знак мінора дорівнює `+1`. Таким чином, провідний коефіцієнт многочлена `P(x)` точно дорівнює визначнику Вандермонда попереднього порядку `n - 1`.

#### Крок 1.2: Знаходження коренів многочлена

Підставимо у функцію `P(x)` замість змінної `x` значення одного з фіксованих вузлів `x_k`, де індекс `k` належить множині `{0, 1, ..., n - 2}`.

При такій підстановці останній рядок матриці набуває вигляду `[1, x_k, x_k², ..., x_k^{n-1}]`. Але цей вектор рядка повністю збігається з рядком із номером `k`, який уже присутній у матриці.

З фундаментальних властивостей детермінантів відомо: якщо квадратна матриця має два однакові рядки, її визначник тотожно дорівнює нулю. Звідси випливає рівність:

```
P(x_k) = 0   для кожного k ∈ {0, 1, ..., n - 2}
```

Якщо всі вузли `x₀, x₁, ..., x_{n-2}` є попарно різними числами, то ми знайшли рівно `n - 1` різних коренів многочлена `P(x)`.

#### Крок 1.3: Факторизація та індуктивний перехід

За основною теоремою алгебри та теоремою Безу будь-який многочлен степеня `n - 1`, що має `n - 1` коренів `x₀, x₁, ..., x_{n-2}` та старший коефіцієнт `A_{n-1}`, однозначно розкладається на добуток лінійних множників:

```
P(x) = A_{n-1} · (x - x₀) · (x - x₁) · ... · (x - x_{n-2})
```

Підставимо у цю тотожність значення старшого коефіцієнта `A_{n-1} = det(V_{n-1})` та обчислимо значення многочлена у вихідній точці `x = x_{n-1}`:

```
det(V_n(x₀, ..., x_{n-1}))
= P(x_{n-1})                                                   [підстановка останнього вузла]
= det(V_{n-1}(x₀, ..., x_{n-2})) · ∏_{k=0}^{n-2} (x_{n-1} - x_k) [рекурентне вираження через мінор]
```

Ми отримали точне рекурентне співвідношення, що виражає визначник порядку `n` через визначник порядку `n - 1`.

Розглянемо базу індукції для розмірності `n = 2`:

```
det(V₂)
= 1 · x₁ - 1 · x₀       [визначник 2×2: різниця добутків діагоналей]
= (x₁ - x₀)             [базовий вираз для двох вузлів]
```

Застосовуючи рекурентну формулу послідовно для `n = 3, 4, ...,` отримуємо повний добуток усіх різниць:

```
det(V₃)
= det(V₂) · (x₂ - x₀)(x₂ - x₁)                                 [рекурентна формула для трьох вузлів]
= (x₁ - x₀)(x₂ - x₀)(x₂ - x₁)                                  [підстановка бази індукції det(V₂)]

det(V₄)
= det(V₃) · (x₃ - x₀)(x₃ - x₁)(x₃ - x₂)                        [рекурентна формула для чотирьох вузлів]
= (x₁ - x₀)(x₂ - x₀)(x₂ - x₁)(x₃ - x₀)(x₃ - x₁)(x₃ - x₂)       [підстановка значення det(V₃)]
```

За індукцією теорему повністю доведено для довільного `n`.

### Метод 2: Конструктивне виведення через стовпчикові операції Гаусса

Другий підхід є чисто конструктивним і не потребує залучення теорем про многочлени. Він базується на елементарних лінійних перетвореннях стовпчиків, які не змінюють значення визначника матриці.

Нехай задано матрицю `V_n`. Застосуємо до її стовпчиків серію послідовних операцій віднімання, рухаючись строго **справа наліво** — від останнього стовпчика з номером `n - 1` до другого стовпчика з номером `1`.

Для кожного номера стовпчика `j` від `n - 1` вниз до `1` виконаємо заміну:
від стовпчика з номером `j` віднімемо попередній стовпчик із номером `j - 1`, помножений на скаляр `x₀`:

```
C_j := C_j - x₀ · C_{j-1}
```

Простежимо, як змінюється довільний елемент на позиції `(i, j)` при цьому перетворенні:

```
(нове значення V_{i, j})
= x_i^j - x₀ · x_i^{j-1}          [віднімання помноженого стовпчика]
= (x_i - x₀) · x_i^{j-1}          [винесення спільного множника x_i^{j-1}]
```

Поглянемо, що станеться з елементами першого рядка (де індекс `i = 0`):
- Для першого стовпчика `j = 0` перетворення не виконувалося, тому елемент лишається рівним `1`.
- Для кожного наступного стовпчика `j ≥ 1` новий елемент набуває значення:
  ```
  V_{0, j} = (x₀ - x₀) · x₀^{j-1} = 0
  ```

Таким чином, перший рядок матриці набув канонічного вигляду `[1, 0, 0, ..., 0]`.

Запишемо отриману перетворену матрицю:

```
|    1               0                       0            ...            0              |
|    1     (x₁ - x₀) · 1           (x₁ - x₀) · x₁         ...  (x₁ - x₀) · x₁ⁿ⁻²        |
|    1     (x₂ - x₀) · 1           (x₂ - x₀) · x₂         ...  (x₂ - x₀) · x₂ⁿ⁻²        |
|    ⋮           ⋮                       ⋮                ⋱            ⋮                |
|    1   (xₙ₋₁ - x₀) · 1         (xₙ₋₁ - x₀) · xₙ₋₁       ...  (xₙ₋₁ - x₀) · xₙ₋₁ⁿ⁻²    |
```

Розкладемо цей визначник за першим рядком. Оскільки єдиним ненульовим елементом у першому рядку є одиниця на позиції `(0, 0)`, визначник вихідної матриці точно дорівнює визначнику мінора розміру `(n - 1) × (n - 1)`:

```
det(V_n) = det |  (x₁ - x₀) · 1         (x₁ - x₀) · x₁       ...  (x₁ - x₀) · x₁ⁿ⁻²      |
               |  (x₂ - x₀) · 1         (x₂ - x₀) · x₂       ...  (x₂ - x₀) · x₂ⁿ⁻²      |
               |        ⋮                     ⋮              ⋱            ⋮              |
               | (xₙ₋₁ - x₀) · 1       (xₙ₋₁ - x₀) · xₙ₋₁     ... (xₙ₋₁ - x₀) · xₙ₋₁ⁿ⁻²  |
```

Тепер застосуємо властивість лінійності визначника за рядками: спільний множник будь-якого рядка можна винести за знак визначника.
- З першого рядка мінора виносимо множник `(x₁ - x₀)`.
- З другого рядка мінора виносимо множник `(x₂ - x₀)`.
- І так далі, з останнього рядка виносимо множник `(x_{n-1} - x₀)`.

Добуток усіх винесених множників дорівнює:

```
∏_{i=1}^{n-1} (x_i - x₀)
```

А матриця, що залишилася під знаком визначника після винесення множників, має вигляд:

```
|  1    x₁    x₁²   ...  x₁ⁿ⁻²  |
|  1    x₂    x₂²   ...  x₂ⁿ⁻²  |
|  ⋮     ⋮     ⋮     ⋱     ⋮    |
|  1   xₙ₋₁  xₙ₋₁²  ... xₙ₋₁ⁿ⁻² |
```

Це в точності матриця Вандермонда `V_{n-1}` порядку `n - 1`, побудована на скороченому наборі вузлів `x₁, x₂, ..., x_{n-1}`.

Отримуємо співвідношення:

```
det(V_n(x₀, x₁, ..., x_{n-1})) = [ ∏_{i=1}^{n-1} (x_i - x₀) ] · det(V_{n-1}(x₁, ..., x_{n-1}))
```

Повторюючи цю процедуру рекурсивно для матриць розмірів `n - 1, n - 2, ..., 2`, ми послідовно винесемо добутки різниць для всіх пар `(x_j - x_i)` при `i < j`.

#### Покроковий приклад перетворення для матриці 3×3

Щоб наочно простежити дію цього алгоритму, розглянемо матрицю розміру `3 × 3`:

```
V₃ = | 1   x₀   x₀² |
     | 1   x₁   x₁² |
     | 1   x₂   x₂² |
```

1. **Крок 1:** Від третього стовпчика віднімаємо другий стовпчик, помножений на `x₀` (`C₂ := C₂ - x₀ · C₁`):
   ```
   | 1   x₀   x₀² - x₀ · x₀ |     | 1   x₀        0         |
   | 1   x₁   x₁² - x₀ · x₁ |  =  | 1   x₁   (x₁ - x₀) · x₁ |
   | 1   x₂   x₂² - x₀ · x₂ |     | 1   x₂   (x₂ - x₀) · x₂ |
   ```

2. **Крок 2:** Від другого стовпчика віднімаємо перший стовпчик, помножений на `x₀` (`C₁ := C₁ - x₀ · C₀`):
   ```
   | 1   x₀ - x₀ · 1   0         |     | 1        0               0         |
   | 1   x₁ - x₀ · 1   (x₁-x₀)·x₁|  =  | 1   (x₁ - x₀) · 1   (x₁ - x₀) · x₁ |
   | 1   x₂ - x₀ · 1   (x₂-x₀)·x₂|     | 1   (x₂ - x₀) · 1   (x₂ - x₀) · x₂ |
   ```

3. **Крок 3:** Розкладаємо за першим рядком та виносимо спільні множники `(x₁ - x₀)` з першого рядка мінора та `(x₂ - x₀)` з другого рядка мінора:
   ```
   det(V₃)
   = 1 · det | (x₁ - x₀) · 1   (x₁ - x₀) · x₁ |                 [розклад за першим рядком]
             | (x₂ - x₀) · 1   (x₂ - x₀) · x₂ |
   = (x₁ - x₀) · (x₂ - x₀) · det | 1  x₁ |                      [винесення спільних множників з рядків]
                                 | 1  x₂ |
   = (x₁ - x₀) · (x₂ - x₀) · (x₂ - x₁)                          [обчислення визначника 2×2]
   ```

Отримуємо точно канонічну формулу добутку різниць без жодного зайвого обчислення.

### Метод 3: Комбінаторне виведення через формулу Лейбніца

Третій спосіб ґрунтується на комбінаторному означенні визначника через перестановки та властивості кососиметричних многочленів від багатьох змінних.

За формулою Лейбніца визначник матриці `A` розміру `n × n` визначається як сума за всіма `n!` перестановками `σ` множини індексів `{0, 1, ..., n - 1}`:

```
det(A) = ∑_{σ ∈ S_n} sgn(σ) · a_{0, σ(0)} · a_{1, σ(1)} · ... · a_{n-1, σ(n-1)}
```

де `sgn(σ)` дорівнює `+1` для парних перестановок і `-1` для непарних перестановок.

Підставивши елементи матриці Вандермонда `a_{i, j} = x_i^j`, отримуємо:

```
det(V_n) = ∑_{σ ∈ S_n} sgn(σ) · x₀^{σ(0)} · x₁^{σ(1)} · ... · x_{n-1}^{σ(n-1)}
```

Дослідимо структуру цього полінома від `n` змінних `x₀, x₁, ..., x_{n-1}`:

1. **Однорідність:** Кожен доданок у сумі є добутком змінних, сума степенів яких дорівнює:
   ```
   Степінь = σ(0) + σ(1) + ... + σ(n-1) = 0 + 1 + 2 + ... + (n - 1) = n · (n - 1) / 2
   ```
   Отже, `det(V_n)` є однорідним многочленом сумарного степеня `n(n - 1) / 2`.

2. **Кососиметрія (знакозмінність):** Якщо ми поміняємо місцями дві змінні `x_p` та `x_q` (де `p ≠ q`), це еквівалентно обміну двох рядків матриці `V_n`. За властивістю визначника обмін двох рядків змінює знак визначника на протилежний. Отже, при підстановці `x_p = x_q` многочлен тотожно перетворюється на нуль.

3. **Подільність на двочлени:** Оскільки при `x_p = x_q` многочлен дорівнює нулю, за теоремою Безу для поліномів багатьох змінних `det(V_n)` ділиться на різницю `(x_q - x_p)` без остачі в кільці многочленів `K[x₀, x₁, ..., x_{n-1}]`.

Оскільки всі двочлени `(x_j - x_i)` для пар `0 ≤ i < j < n` є незвідними та взаємно простими многочленами, їхній добуток також ділить `det(V_n)`:

```
det(V_n) = K · ∏_{0 ≤ i < j < n} (x_j - x_i)
```

де `K` — деякий числовий коефіцієнт пропорційності.

Порівняємо степені обох частин рівності:
- Степінь лівої частини дорівнює `n(n - 1) / 2`.
- Степінь добутку в правій частині дорівнює кількості співмножників, тобто `n(n - 1) / 2`.

Оскільки степені збігаються, коефіцієнт `K` є числовою константою, що не залежить від змінних `x_i`.

Щоб знайти значення `K`, зіставимо коефіцієнти при однаковому мономі в обох частинах. Розглянемо моном, що утворюється добутком елементів на головній діагоналі:

```
x₀⁰ · x₁¹ · x₂² · ... · x_{n-1}^{n-1}
```

У формулі Лейбніца цей моном відповідає тотожній перестановці `id`, яка має знак `sgn(id) = +1`. У добутку `∏_{i < j} (x_j - x_i)` цей самий моном утворюється, якщо з кожної дужки `(x_j - x_i)` обрати перший член зі знаком плюс `x_j`. Оскільки перед усіма `x_j` стоїть знак плюс, коефіцієнт монома в правій частині також дорівнює `+1`.

Звідси негайно отримуємо:

```
K = 1
```

Що завершує комбінаторне доведення.

### Аналітична формула оберненої матриці Вандермонда

Знання визначника Вандермонда дозволяє виписати явну аналітичну формулу для елементів оберненої матриці `V_n^{-1}`. Ця формула спирається на базисні многочлени Лагранжа та елементарні симетричні многочлени.

Нехай `P(x)` — довільний многочлен степеня менше `n` із коефіцієнтами `c = [c₀, c₁, ..., c_{n-1}]^T`. Тоді вектор значень у вузлах `y = [P(x₀), P(x₁), ..., P(x_{n-1})]^T` задовольняє рівняння `V_n · c = y`. Отже, вектор коефіцієнтів шукається як `c = V_n^{-1} · y`.

З іншого боку, за формулою поліноміальної інтерполяції Лагранжа той самий многочлен `P(x)` записується через базисні поліноми:

```
P(x) = ∑_{j=0}^{n-1} y_j · l_j(x)
```

де базисний поліном Лагранжа `l_j(x)` має вигляд:

```
l_j(x) = ∏_{k ≠ j} (x - x_k) / ∏_{k ≠ j} (x_j - x_k)
```

Розкриємо дужки у чисельнику базисного полінома. За теоремою Вієта коефіцієнти многочлена `∏_{k ≠ j} (x - x_k)` виражаються через елементарні симетричні многочлени `e_m` від набору вузлів без елемента `x_j`, який ми позначимо як `X_{\setminus j} = \{x₀, x₁, ..., x_{n-1}\} \setminus \{x_j\}`:

```
∏_{k ≠ j} (x - x_k) = ∑_{m=0}^{n-1} (-1)^{n - 1 - m} · e_{n - 1 - m}(X_{\setminus j}) · xᵐ
```

Зіставляючи коефіцієнти при степені `xᵐ` у формулі `c_m = ∑_{j=0}^{n-1} (V_n^{-1})_{m, j} · y_j`, ми отримуємо точний аналітичний вираз для кожного елемента оберненої матриці:

```
(V_n^{-1})_{m, j} = (-1)^{n - 1 - m} · e_{n - 1 - m}(X_{\setminus j}) / ∏_{k ≠ j} (x_j - x_k)
```

З цієї формули чітко видно:
- У знаменнику стоїть добуток відстаней від вузла `x_j` до всіх інших вузлів.
- Якщо будь-які два вузли наближаються один до одного (`x_j \to x_k`), знаменник прямує до нуля, а елементи оберненої матриці зростають до нескінченності, що спричиняє чисельну нестабільність при роботі з дійсними числами.

### Конфлюентний визначник Вандермонда (випадок кратних вузлів)

У практичних задачах інтерполяції Ерміта та теорії крайових задач виникає ситуація, коли деякі вузли збігаються. Якщо покласти `x₁ = x₀`, класичний визначник Вандермонда обнуляється, оскільки два рядки стають однаковими.

Проте, якщо замість дублювання однакових рядків підставити значення послідовних похідних відповідного порядку, ми отримаємо так звану **конфлюентну матрицю Вандермонда** (від латинського *confluere* — зливатися).

Нехай задано `k` різних вузлів `x₁, x₂, ..., x_k` з кратностями `m₁, m₂, ..., m_k` відповідно, так що сума всіх кратностей дорівнює загальній розмірності матриці:

```
m₁ + m₂ + ... + m_k = n
```

Для кожного вузла `x_r` (де `r = 1, ..., k`) ми формуємо блок із `m_r` рядків, де рядок із локальним індексом `s` (від `0` до `m_r - 1`) утворюється взяттям `s`-ї похідної від базисного вектора степенів `[1, x, x², ..., x^{n-1}]` у точці `x = x_r`:

```
Рядок_{(r, s)} = (dˢ / dxˢ) [ 1, x, x², ..., x^{n-1} ] |_{x = x_r}
```

Наприклад, для вузла `x₁` кратності `m₁ = 3` перші три рядки матриці мають вигляд:
- `s = 0`: `[ 1,  x₁,   x₁²,    x₁³,    ...,   x₁^{n-1} ]`
- `s = 1`: `[ 0,  1,   2 x₁,   3 x₁²,   ...,   (n-1) x₁^{n-2} ]`
- `s = 2`: `[ 0,  0,     2,    6 x₁,    ...,   (n-1)(n-2) x₁^{n-3} ]`

#### Теорема про конфлюентний визначник

Визначник конфлюентної матриці Вандермонда `W` задається формулою:

```
det(W) = [ ∏_{r=1}^k ∏_{s=0}^{m_r - 1} s! ] · ∏_{1 ≤ r < p ≤ k} (x_p - x_r)^{m_r · m_p}
```

де `s!` позначає факторіал числа `s` (`0! = 1, 1! = 1, 2! = 2, 3! = 6, ...`).

#### Розбір конкретного прикладу для матриці 4×4

Розглянемо випадок двох вузлів `x₀` та `x₁`, кожен із яких має кратність 2 (`m₀ = 2, m₁ = 2`, сумарний розмір `n = 4`).

Конфлюентна матриця `W₄` має вигляд:

```
| 1   x₀   x₀²    x₀³   |   [вузол x₀, s = 0: значення функції]
| 0   1    2x₀   3x₀²   |   [вузол x₀, s = 1: перша похідна]
| 1   x₁   x₁²    x₁³   |   [вузол x₁, s = 0: значення функції]
| 0   1    2x₁   3x₁²   |   [вузол x₁, s = 1: перша похідна]
```

Застосуємо загальну формулу:
1. Факторіальна частина для `x₀` (`s = 0, 1`): `0! · 1! = 1 · 1 = 1`.
2. Факторіальна частина для `x₁` (`s = 0, 1`): `0! · 1! = 1 · 1 = 1`.
3. Степенева різниця між вузлами `x₁` та `x₀`: показник степеня дорівнює `m₀ · m₁ = 2 · 2 = 4`.

Підсумковий визначник:

```
det(W₄) = 1 · 1 · (x₁ - x₀)⁴ = (x₁ - x₀)⁴
```

Якщо обчислити цей визначник прямим розкладом або за методом Гаусса, ми отримаємо абсолютно тотожний вираз `(x₁ - x₀)⁴`.

Цей результат гарантує, що інтерполяційна задача Ерміта (відновлення функції за її значеннями та значеннями її похідних) завжди має єдиний розв'язок за умови, що всі базові вузли `x_r` є різними.

### Зв'язок із дискримінантом многочлена та результантом

Формула Вандермонда має глибокий зв'язок із двома класичними поняттями вищої алгебри — дискримінантом многочлена та результантом Сильвестра.

Нехай `f(x)` — нормований многочлен степеня `n` із коренями `x₀, x₁, ..., x_{n-1}`:

```
f(x) = (x - x₀) · (x - x₁) · ... · (x - x_{n-1})
```

**Дискримінант** многочлена `f(x)`, що позначається `disc(f)`, за означенням дорівнює добутку квадратів усіх попарних різниць його коренів:

```
disc(f) = ∏_{0 ≤ i < j < n} (x_j - x_i)²
```

Зіставляючи це означення з формулою Вандермонда, ми отримуємо фундаментальну тотожність:

```
disc(f) = ( det(V_n(x₀, x₁, ..., x_{n-1})) )²
```

Це означає, що дискримінант будь-якого многочлена дорівнює квадрату визначника Вандермонда, складеного з його коренів.

Зв'язок із результантом `Res(f, f')` многочлена та його похідної виражається класичним алгебраїчним співвідношенням:

```
Res(f, f')
= (-1)^{n(n-1)/2} · disc(f)             [алгебраїчний зв'язок результанту та дискримінанта]
= (-1)^{n(n-1)/2} · (det(V_n))²         [підстановка виразу визначника Вандермонда]
```

Коли многочлен має хоча б один кратний корінь (`x_i = x_j`), визначник Вандермонда обнуляється, дискримінант дорівнює нулю, а результант `Res(f, f') = 0`, що свідчить про наявність спільного дільника у многочлена та його похідної.
