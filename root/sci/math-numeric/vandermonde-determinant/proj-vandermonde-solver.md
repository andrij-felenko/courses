# ⚙️ Алгоритм Бйорка — Перейри та схема розділення секрету Шаміра

Розв'язання систем лінійних алгебраїчних рівнянь із матрицею Вандермонда є критичним кроком у задачах цифрової обробки сигналів, спектрального аналізу та порогової криптографії, проте застосування стандартного методу Гаусса вимагає `O(n³)` арифметичних операцій та `O(n²)` оперативної пам'яті, повністю ігноруючи внутрішню степеневу структуру матриці. У 1970 році шведський математик Оке Бйорк (Åke Björck) та венесуельський дослідник Віктор Перейра (Victor Pereyra) розробили революційний алгоритм, який знаходить точний розв'язок системи Вандермонда за час `O(n²)` та потребує лише `O(n)` пам'яті, виконуючи всі обчислення безпосередньо у вихідному масиві.

---

### Постановка задачі: пряма та дуальна системи

Нехай задано набір із `n` попарно різних вузлів `x₀, x₁, ..., x_{n-1}` та вектор значень правої частини `y = [y₀, y₁, ..., y_{n-1}]^T`.

У практичних застосуваннях виникають дві взаємопов'язані системи лінійних рівнянь:

1. **Пряма система Вандермонда (інтерполяція):**
   ```
   V_n · c = y
   ```
   У розгорнутому вигляді це відповідає знаходженню коефіцієнтів інтерполяційного полінома `P(x) = c₀ + c₁ x + c₂ x² + ... + c_{n-1} x^{n-1}`, що задовольняє умови `P(x_i) = y_i` для всіх `i = 0, 1, ..., n - 1`:
   ```
   |  1    x₀    x₀²   ...  x₀ⁿ⁻¹  |   |   c₀   |   |   y₀   |
   |  1    x₁    x₁²   ...  x₁ⁿ⁻¹  |   |   c₁   |   |   y₁   |
   |  ⋮     ⋮     ⋮     ⋱     ⋮    | · |   ⋮    | = |   ⋮    |
   |  1   xₙ₋₁  xₙ₋₁²  ... xₙ₋₁ⁿ⁻¹ |   | cₙ₋₁  |   |  yₙ₋₁  |
   ```

2. **Транспонована (дуальна) система Вандермонда:**
   ```
   V_n^T · a = f
   ```
   Така система виникає при знаходженні ваг чисельного інтегрування (квадратурних формул Ньютона — Котеса та Гаусса), де потрібно знайти такі вагові коефіцієнти `a_i`, щоб зважена сума значень функції `∑ a_i · P(x_i)` точно дорівнювала інтегралу для всіх базисних мономів `xʲ`.

Якщо формувати таблицю розміру `n × n` у пам'яті та розв'язувати систему за допомогою класичного методу Гаусса з вибором головного елемента, ми зіткнемося з двома серйозними проблемами:
- **Часова складність:** для розмірності `n = 1000` Гаусс вимагає близько `(2/3) · 10⁹` операцій із руйнуванням структури розрідженості, тоді як алгоритм Бйорка — Перейри виконує лише `2 · 10⁶` операцій, тобто працює у сотні разів швидше.
- **Пам'ять:** метод Гаусса вимагає виділення квадратичного масиву `n × n` елементів, що для великих розмірностей швидко вичерпує кеш-пам'ять процесора, тоді як Бйорк — Перейра потребує лише одного одновимірного робочого буфера довжини `n`.

### Математична ідея алгоритму Бйорка — Перейри

Алгоритм Бйорка — Перейри базується на точному алгебраїчному розкладі оберненої матриці `V_n^{-1}` у добуток елементарних біодіагональних матриць. Замість того, щоб шукати коефіцієнти мономіального базису напряму, алгоритм розбиває задачу на два послідовні каскадні етапи:

```
Значення y  ──[Етап 1: Розділені різниці]──>  Коефіцієнти Ньютона d  ──[Етап 2: Синтез мономів]──>  Коефіцієнти c
```

#### Етап 1: Перехід від значень до форми Ньютона (розділені різниці)

Інтерполяційний многочлен `P(x)` можна записати не лише у стандартному степеневому базисі `x^k`, а й у базисі Ньютона:

```
P(x) = d₀ + d₁·(x - x₀) + d₂·(x - x₀)(x - x₁) + ... + d_{n-1}·∏_{k=0}^{n-2}(x - x_k)
```

Коефіцієнти `d_k` називаються розділеними різницями порядку `k` і позначаються `d_k = f[x₀, x₁, ..., x_k]`.

Бйорк і Перейра показали, що знаходження всіх розділених різниць еквівалентне послідовному множенню вектора `y` на нижньотрикутні біодіагональні матриці `L_k(x)`. У числовому алгоритмі це реалізується компактним подвійним циклом, що виконується «на місці» над робочим масивом `d`:

1. Ініціалізуємо вектор `d` значеннями `y`: `d_i := y_i` для `i = 0, 1, ..., n - 1`.
2. Для кожного кроку `k` від `0` до `n - 2`:
   Для кожного індексу `i` від `n - 1` вниз до `k + 1`:
   ```
   d_i := (d_i - d_{i-1}) / (x_i - x_{i - k - 1})
   ```

Зверніть увагу: внутрішній цикл рухається строго **ззаду наперед** (від `n - 1` до `k + 1`). Це дозволяє перезаписувати елементи в тому самому масиві без виділення додаткової пам'яті.

Кількість операцій на першому етапі:
- Віднімань: `(n - 1) + (n - 2) + ... + 1 = n(n - 1) / 2`.
- Ділень: `n(n - 1) / 2`.

#### Етап 2: Перехід від форми Ньютона до стандартного мономіального базису

Маючи вектор коефіцієнтів Ньютона `d = [d₀, d₁, ..., d_{n-1}]`, нам залишається розкрити дужки у поліномі Ньютона та згрупувати коефіцієнти при однакових степенях `xʲ`, щоб отримати шуканий вектор `c = [c₀, c₁, ..., c_{n-1}]`.

Цей процес еквівалентний застосуванню узагальненої схеми Горнера у зворотному напрямку і виконується множенням на верхньотрикутні біодіагональні матриці `U_k(x)`:

1. Для кожного кроку `k` від `n - 2` вниз до `0`:
   Для кожного індексу `i` від `k` до `n - 2`:
   ```
   d_i := d_i - d_{i+1} · x_k
   ```

Після завершення другого етапу масив `d` містить точні коефіцієнти мономів `c₀, c₁, ..., c_{n-1}` вихідного полінома `P(x) = c₀ + c₁ x + ... + c_{n-1} x^{n-1}`.

Сумарна складність обох етапів:
- Множень та ділень: `n(n - 1)`.
- Віднімань: `n(n - 1)`.
- Загальна кількість арифметичних дій: рівно `2n² - 2n`, що становить строго `O(n²)`.

### Наочний числовий розрахунок крок за кроком

Щоб до найменших деталей зрозуміти, як масив чисел трансформується всередині пам'яті під час роботи алгоритму Бйорка — Перейри, простежимо обчислення для конкретного набору точок.

Нехай задано `4` вузли та відповідні значення:
- Вузли: `x = [1, 2, 4, 5]` (усі вузли різні, розмірність `n = 4`).
- Значення правої частини: `y = [2, 5, 17, 26]`.

Ми шукаємо коефіцієнти полінома `P(x) = c₀ + c₁ x + c₂ x² + c₃ x³`.

#### Покрокове виконання Етапу 1 (Розділені різниці):

Початковий стан масиву: `d = [2, 5, 17, 26]`.

1. **Ітерація `k = 0` (різниці першого порядку):**
   - Для `i = 3`: знаменник `x₃ - x₂ = 5 - 4 = 1`. Значення `d₃ := (26 - 17) / 1 = 9`.
   - Для `i = 2`: знаменник `x₂ - x₁ = 4 - 2 = 2`. Значення `d₂ := (17 - 5) / 2 = 6`.
   - Для `i = 1`: знаменник `x₁ - x₀ = 2 - 1 = 1`. Значення `d₁ := (5 - 2) / 1 = 3`.
   - Стан масиву: `d = [2, 3, 6, 9]`.

2. **Ітерація `k = 1` (різниці другого порядку):**
   - Для `i = 3`: знаменник `x₃ - x₁ = 5 - 2 = 3`. Значення `d₃ := (9 - 6) / 3 = 1`.
   - Для `i = 2`: знаменник `x₂ - x₀ = 4 - 1 = 3`. Значення `d₂ := (6 - 3) / 3 = 1`.
   - Стан масиву: `d = [2, 3, 1, 1]`.

3. **Ітерація `k = 2` (різниці третього порядку):**
   - Для `i = 3`: знаменник `x₃ - x₀ = 5 - 1 = 4`. Значення `d₃ := (1 - 1) / 4 = 0`.
   - Стан масиву: `d = [2, 3, 1, 0]`.

Етап 1 завершено. Вектор `d = [2, 3, 1, 0]` містить точні коефіцієнти полінома у базисі Ньютона:
`N(x) = 2 + 3·(x - 1) + 1·(x - 1)(x - 2) + 0·(x - 1)(x - 2)(x - 4)`.

#### Покрокове виконання Етапу 2 (Синтез мономіальних коефіцієнтів):

Перетворюємо поліном Ньютона у стандартний вигляд `c₀ + c₁ x + c₂ x² + c₃ x³`:

1. **Ітерація `k = 2` (вузол `x₂ = 4`):**
   - Для `i = 2`: `d₂ := d₂ - d₃ · x₂ = 1 - 0 · 4 = 1`.
   - Стан масиву: `d = [2, 3, 1, 0]`.

2. **Ітерація `k = 1` (вузол `x₁ = 2`):**
   - Для `i = 1`: `d₁ := d₁ - d₂ · x₁ = 3 - 1 · 2 = 1`.
   - Для `i = 2`: `d₂ := d₂ - d₃ · x₁ = 1 - 0 · 2 = 1`.
   - Стан масиву: `d = [2, 1, 1, 0]`.

3. **Ітерація `k = 0` (вузол `x₀ = 1`):**
   - Для `i = 0`: `d₀ := d₀ - d₁ · x₀ = 2 - 1 · 1 = 1`.
   - Для `i = 1`: `d₁ := d₁ - d₂ · x₀ = 1 - 1 · 1 = 0`.
   - Для `i = 2`: `d₂ := d₂ - d₃ · x₀ = 1 - 0 · 1 = 1`.
   - Стан масиву: `d = [1, 0, 1, 0]`.

Результат: ми отримали коефіцієнти `c₀ = 1, c₁ = 0, c₂ = 1, c₃ = 0`, тобто шуканий многочлен має вигляд `P(x) = 1 + x²`.

Перевіримо значення у вихідних вузлах:
- `P(1) = 1 + 1² = 2 = y₀`
- `P(2) = 1 + 2² = 5 = y₁`
- `P(4) = 1 + 4² = 17 = y₂`
- `P(5) = 1 + 5² = 26 = y₃`

Всі значення збіглися абсолютно точно. Обчислення виконані за `12` арифметичних дій без створення матриці в пам'яті.

### Алгоритм Бйорка — Перейри для транспонованої системи

У багатьох задачах чисельного аналізу (зокрема при побудові формул чисельного інтегрування та диференціювання) потрібно розв'язати транспоновану систему рівнянь:

```
V_n^T · a = f
```

У розгорнутому вигляді:

```
|   1     1    ...    1    |   |   a₀   |   |   f₀   |
|  x₀    x₁    ...   xₙ₋₁  |   |   a₁   |   |   f₁   |
|  x₀²   x₁²   ...  xₙ₋₁²  | · |   ⋮    | = |   ⋮    |
|   ⋮     ⋮    ⋱      ⋮    |   |   ⋮    |   |   ⋮    |
| x₀ⁿ⁻¹ x₁ⁿ⁻¹  ... xₙ₋₁ⁿ⁻¹ |   |  aₙ₋₁  |   |  fₙ₋₁  |
```

Транспонована матриця розв'язується за тією ж самою факторизацією, але матричні множники застосовуються у зворотному порядку та в транспонованому вигляді:

1. **Етап 1 (Застосування верхньотрикутних факторів `U_k^T`):**
   Для кожного `k` від `0` до `n - 2`:
   Для кожного `i` від `n - 1` вниз до `k + 1`:
   ```
   a_i := a_i - a_{i-1} · x_k
   ```

2. **Етап 2 (Застосування нижньотрикутних факторів `L_k^T`):**
   Для кожного `k` від `n - 2` вниз до `0`:
   Для кожного `i` від `k + 1` до `n - 1`:
   ```
   a_i := a_i / (x_i - x_{i - k - 1})
   a_{i-1} := a_{i-1} - a_i
   ```

Складність транспонованого розв'язувача також становить строго `2n² + O(n)` операцій при пам'яті `O(n)`.

### Застосування до порогової криптографії: схема розділення секрету Шаміра

Одним із найважливіших практичних застосувань матриць Вандермонда в комп'ютерній безпеці є **схема розділення секрету Шаміра** (Shamir's Secret Sharing Scheme), винайдена ізраїльським криптографом Аді Шаміром у 1979 році.

#### Принцип роботи схеми `(k, n)`

Задача полягає в тому, щоб розділити конфіденційний цифровий ключ (майстер-пароль від сховища, приватний ключ підпису або код доступу) між `n` довіреними учасниками так, щоб:
1. Будь-які `k` учасників (де `k ≤ n` — заданий поріг відновлення), об'єднавши свої частки, могли швидко і безпомилково відновити секрет.
2. Будь-яка група з `k - 1` або меншої кількості учасників не отримала жодного біта інформації про секрет (ідеальна криптографічна стійкість за Шенноном).

#### Математична реалізація через матрицю Вандермонда:

1. **Генерація часток:** Дилер обирає скінченне поле `GF(q)` (найчастіше поле байтів `GF(256)` або поле за великим простим модулем `GF(p)`).
   Секретне число `S` призначається вільним членом полінома: `a₀ = S`.
   Дилер випадковим чином обирає `k - 1` коефіцієнтів `a₁, a₂, ..., a_{k-1}` з поля `GF(q)` і формує секретний поліном степеня `k - 1`:
   ```
   P(x) = S + a₁ · x + a₂ · x² + ... + a_{k-1} · x^{k-1}
   ```
   Кожному з `n` учасників дилер видає унікальну пару `(x_i, y_i)`, де `x_i ≠ 0` — відкритий ідентифікатор учасника, а `y_i = P(x_i)` — його секретна частка.

2. **Відновлення секрету:** Коли будь-які `k` учасників збираються разом із парами `(x_i, y_i)` для `i = 0, ..., k - 1`, вони мають розв'язати лінійну систему рівнянь розміру `k × k`:
   ```
   |  1    x₀    x₀²   ...  x₀^{k-1}  |   |   a₀   |   |   y₀   |
   |  1    x₁    x₁²   ...  x₁^{k-1}  |   |   a₁   |   |   y₁   |
   |  ⋮     ⋮     ⋮     ⋱      ⋮      | · |   ⋮    | = |   ⋮    |
   |  1   x_{k-1} x_{k-1}² ... x_{k-1}^{k-1} |   | a_{k-1}|   |  y_{k-1}|
   ```
   Оскільки всі вузли `x_i` є різними ненульовими елементами поля, визначник матриці Вандермонда `det(V_k) ≠ 0`, що гарантує існування та єдиність розв'язку.

Оскільки для розшифрування потрібен лише вільний член `S = a₀ = P(0)`, його можна обчислити двома шляхами:
- Якщо нам потрібні **всі коефіцієнти** полінома (наприклад, у схемах порогового підпису чи верифікації), ми запускаємо повний алгоритм Бйорка — Перейри за `O(k²)` операцій.
- Якщо ж потрібен **виключно вільний член `S = P(0)`**, ми застосовуємо пряму оптимізовану формулу Лагранжа у точці `x = 0`, що вимагає всього `3k` операцій у полі `GF(256)`:

```
S = ∑_{i=0}^{k-1} y_i · ∏_{j ≠ i} (0 - x_j) / (x_i - x_j)
  = ∑_{i=0}^{k-1} y_i · ∏_{j ≠ i} x_j / (x_j - x_i)
```

Такий підхід дозволяє відновити майстер-ключ на вбудованих мікроконтролерах із тактовою частотою 16 МГц за лічені мікросекунди, забезпечуючи миттєвий доступ до криптографічного сховища при пред'явленні валідного набору часток.

#### Доведення абсолютної криптографічної стійкості (Perfect Secrecy)

Чому зловмисник, перехопивши `k - 1` часток, не може дізнатися про секрет абсолютно нічого?

Розглянемо систему лінійних рівнянь для `k - 1` відомих точок `(x₁, y₁), ..., (x_{k-1}, y_{k-1})`. Ця система містить `k - 1` рівнянь із `k` невідомими коефіцієнтами `[S, a₁, a₂, ..., a_{k-1}]`.
Для будь-якого гіпотетичного значення секрету `S' ∈ GF(q)` ми можемо зафіксувати `a₀ = S'`. Тоді отримана система відносно невідомих `a₁, ..., a_{k-1}` стає квадратною розміру `(k - 1) × (k - 1)` із матрицею Вандермонда, де вузлами є `x₁, ..., x_{k-1}`:

```
|  x₁    x₁²   ...  x₁^{k-1}  |   |   a₁   |   |   y₁ - S'   |
|  x₂    x₂²   ...  x₂^{k-1}  | · |   a₂   | = |   y₂ - S'   |
|  ⋮      ⋮     ⋱      ⋮      |   |   ⋮    |   |      ⋮      |
| x_{k-1} x_{k-1}² ... x_{k-1}^{k-1} | | a_{k-1}| | y_{k-1} - S' |
```

Оскільки всі вузли `x_i` різні та ненульові, визначник цієї матриці дорівнює:

```
x₁ · x₂ · ... · x_{k-1} · ∏_{1 ≤ i < j ≤ k-1} (x_j - x_i) ≠ 0
```

Оскільки визначник ненульовий, для **кожного** можливого значення `S' ∈ GF(q)` існує рівно один унікальний набір коефіцієнтів `(a₁, ..., a_{k-1})`, що ідеально узгоджується з усіма `k - 1` перехопленими частками. Оскільки всі випадкові коефіцієнти обиралися незалежно і рівномірно, апостеріорна ймовірність будь-якого кандидата `S'` залишається строго рівною апріорній:

```
P(S = S' | k - 1 часток) = 1 / |GF(q)|
```

Це доводить, що схема володіє ідеальною стійкістю за Шенноном: навіть володіючи необмеженими обчислювальними ресурсами квантового суперкомп'ютера, атакувальник не отримає жодної статистичної переваги.

### Верифіковане розділення секрету (схема Фельдмана)

У реальних розподілених мережах (наприклад, у блокчейн-протоколах та порогах валідації MPC) постає додаткова загроза: недобросовісний дилер може роздати учасникам некоректні частки, які не лежать на одному поліномі степеня `k - 1`. У такому разі різні підгрупи з `k` учасників відновлюватимуть різні секрети, що призведе до розколу системи.

Для захисту від фальсифікацій застосовують **схему верифікованого розділення секрету Фельдмана** (Feldman's Verifiable Secret Sharing):
1. Дилер обирає циклічну групу `G` простого порядку `p` із генератором `g`, у якій задача дискретного логарифмування є складною.
2. Разом із приватними частками `y_i = P(x_i)` дилер публікує відкриті криптографічні зобов'язання (commitments) до кожного коефіцієнта полінома:
   ```
   C_j = g^{a_j} mod p   для j = 0, 1, ..., k - 1
   ```
3. Кожен учасник `i`, отримавши свою пару `(x_i, y_i)`, може самостійно перевірити її автентичність, не розкриваючи значення іншим:
   ```
   g^{y_i} = ∏_{j=0}^{k-1} (C_j)^{x_i^j} mod p
   ```
4. Рівність гарантується гомоморфною властивістю піднесення до степеня. Якщо хоча б один учасник виявляє невідповідність, дилера дискваліфікують до початку роботи протоколу.

### Арифметика скінченного поля `GF(256)`

Для безпечної та швидкої роботи криптографічних протоколів на 8-бітних мікроконтролерах та серверах обчислення виконуються над полем Галуа `GF(256)`:
- Елементи поля — це байти від `0x00` до `0xFF`.
- Операція додавання та віднімання в полі збігається з порозрядним виключальним АБО (`XOR`, оператор `^`). Вона не дає переповнення і не вимагає переносів.
- Множення та ділення виконуються за модулем незвідного полінома `x⁸ + x⁴ + x³ + x + 1` (шістнадцяткове число `0x11B`, стандарт AES). Щоб операції виконувалися за одну процесорну інструкцію `O(1)`, застосовують попередньо обчислені таблиці дискретного логарифма `log_table` та дискретної експоненти `exp_table` від генератора поля `g = 3`.

#### Захист від атак за сторонніми каналами (Side-Channel Security)

При реалізації порогової криптографії у виробничих системах особливу увагу слід звертати на атаки за часом виконання (timing attacks) та кеш-лініями (cache-timing attacks):
- **Табличні звернення:** Якщо доступ до таблиць логарифмів здійснюється за секретними індексами `log_table[secret_byte]`, час зчитування з кешу L1/L2 процесора може виказувати значення секретного байта спостерігачеві на тому ж апаратному ядрі.
- **Постійний час (Constant-Time):** Для захисту високорівневих криптографічних ключів у HSM-модулях та банківських чипах застосовують алгоритми множення без розгалужень (наприклад, побітове множення без таблиць методом «Russian Peasant Multiplication» над `GF(256)` із фіксованою кількістю ітерацій) або бітслайсинг (bitslicing), де обчислення виконуються паралельно за допомогою логічних векторних інструкцій SIMD/AVX.

У наведених нижче прикладах ми демонструємо як високоефективну табличну реалізацію для швидкого обчислення, так і структурний поділ обов'язків із контролем помилок.

### Аналіз чисельної точності та практичні пастки

При програмній реалізації алгоритмів для матриць Вандермонда необхідно чітко розрізняти два абсолютно різні обчислювальні режими:

1. **Арифметика скінченних полів (криптографія та завадостійке кодування):**
   У полях Галуа `GF(256)` або `GF(p)` операції є абсолютно точними. Тут немає похибок округлення, втрати значущих цифр чи машинної точності. Якщо вузли є різними, розв'язок завжди існує, єдиний і обчислюється зі 100% математичною точністю.

2. **Дійсна арифметика з плаваючою комою (double, float):**
   У полі дійсних чисел матриця Вандермонда є сумнозвісним класичним прикладом **погано обумовленої матриці** (ill-conditioned matrix).
   Число обумовленості `κ(V_n) = ||V_n|| · ||V_n^{-1}||` для рівновіддалених вузлів на відрізку `[-1, 1]` зростає експоненційно зі збільшенням розмірності `n`:
   ```
   κ(V_n) ≈ O(e^{c · n})
   ```
   Вже при `n = 25` число обумовленості перевищує `10¹⁶`. Це означає, що машинна точність стандарту IEEE 754 (53 біти мантиси, близько 15–17 десяткових знаків) повністю вичерпується похибками округлення, і знайдений чисельний розв'язок стає повністю недостовірним.

#### Як уникнути чисельної катастрофи на дійсних числах:

- **Оптимальне розташування вузлів:** Ніколи не використовуйте рівновіддалені вузли для поліноміальної інтерполяції високих степенів через феномен Рунге. Використовуйте **вузли Чебишова**:
  ```
  x_k = cos( (2k + 1) · π / (2n) ),   де k = 0, 1, ..., n - 1
  ```
  Вузли Чебишова згущуються до країв інтервалу, суттєво зменшуючи норму оберненої матриці `||V_n^{-1}||` та мінімізуючи константу Лебега `Λ_n = O(ln n)`, що гарантує рівномірну збіжність інтерполяційного полінома.
- **Перехід від мономів до ортогональних поліномів Чебишова:** Якщо потрібно інтерполювати функцію на великій кількості точок (`n > 30`), відмовтеся від мономіального базису `x^k` на користь поліномів Чебишова `T_k(x) = cos(k · arccos(x))`. Матриця Чебишова `C_{i, j} = T_j(x_i)` на чебишовській сітці є практично ортогональною з числом обумовленості `κ(C_n) = √2`, що повністю усуває будь-яку втрату точності навіть при `n = 10000`.
- **Алгоритм Бйорка — Перейри як найточніший прямий метод:** Завдяки уникненню проміжного ділення рядків один на одного алгоритм Бйорка — Перейри дає значно меншу накопичену похибку, ніж метод Гаусса, забезпечуючи високу точність для помірних розмірностей `n ≤ 20`. Для дійсних обчислень рекомендується завжди попередньо відсортувати вузли `x_i` за зростанням або за відстанню від центру маси, що мінімізує похибки віднімання близьких чисел (catastrophic cancellation).
- **Діагностика через число обумовленості:** Перед запуском обчислень у середовищі з плаваючою комою рекомендується оцінити величину `det(V_n)` або мінімальну відстань між вузлами `min |x_i - x_j|`. Якщо `min |x_i - x_j| < 10⁻⁴`, похибка обчислення коефіцієнтів мономів вищих степенів перевищить 100%, що вимагає переходу на бібліотеки довільної точності (GMP/MPFR) або зміни математичної моделі.
