# 🧮 Вивід барицентричної форми Лагранжа, теорема єдиності та похибка

Ця вставка містить строгі математичні доведення фундаментальних властивостей інтерполяційного многочлена Лагранжа: теорему про існування та єдиність у кільці многочленів `K[x]`, векторно-просторову дуальність базисів, точний алгебраїчний вивід залишкового члена похибки через теорему Ролля, аналіз константи Лебега, перетворення канонічної формули Лагранжа у першу та другу барицентричні форми, а також особливості виконання інтерполяції над скінченними полями `GF(p)`.

---

### 1. Теорема про існування та єдиність інтерполяційного многочлена

Нехай `K` — довільне алгебраїчне поле (наприклад, дійсні числа `ℝ`, комплексні числа `ℂ` або скінченне поле Галуа `GF(p)`). Розглянемо векторний простір `Pₙ[x]` многочленів степеня не вище `n` над полем `K`. Розмірність цього векторного простору дорівнює `dim(Pₙ[x]) = n + 1`, оскільки канонічний базис складається з `n + 1` степенів `{1, x, x², …, xⁿ}`.

**Теорема (існування та єдиність):**
Для будь-якого набору з `n + 1` парувато різних вузлів `x₀, x₁, …, x╙ ∈ K` та довільних відповідних значень `y₀, y₁, …, y╙ ∈ K` існує єдиний многочлен `P(x) ∈ Pₙ[x]` степеня `deg(P) ≤ n` такий, що `P(x╖) = y╖` для всіх `k = 0, 1, …, n`.

#### Доведення існування:
Побудуємо явну конструкцію за допомогою базисних многочленів Лагранжа. Для кожного `k ∈ {0, 1, …, n}` визначимо многочлен `L╖(x) ∈ Pₙ[x]`:

```
L╖(x) = ∏ (x - xⱼ) / (x╖ - xⱼ)    (для всіх j від 0 до n, де j ≠ k)
```

Розглянемо значення `L╖(x)` у вузлах `x╟`:
1. При `i = k`: чисельник дорівнює `∏ (x╖ - xⱼ)`, що повністю збігається зі знаменником, тому `L╖(x╖) = 1`.
2. При `i ≠ k`: у чисельнику присутній множник `(x╟ - x╟) = 0`, тому `L╖(x╟) = 0`.

Отже, базисні многочлени задовольняють умову дельта-символу Кронекера: `L╖(x╟) = δ╖╟`.
Оскільки кожен `L╖(x)` є добутком `n` лінійних множників, його степінь дорівнює `deg(L╖) = n`.

Складемо лінійну комбінацію:

```
P(x) = ∑ y╖ · L╖(x)    (сума по k від 0 до n)
```

Степінь суми многочленів степеня `n` не перевищує `n`, тобто `deg(P) ≤ n`. Обчислимо значення `P(x)` у довільному вузлі `x╟`:

```
P(x╟)
= ∑ y╖ · L╖(x╟)          [розгортаємо суму]
= y╟ · L╟(x╟) + ∑ y╖ · 0  [оскільки L╖(x╟) = 0 при k ≠ i]
= y╟ · 1                [оскільки L╖(x╟) = 1]
= y╟
```

Існування доведено.

#### Алгебраїчний вимір дуальності:
Розглянемо `n + 1` лінійних функціоналів обчислення значення `ϕ╟: Pₙ[x] → K`, визначених як `ϕ╟(P) = P(x╟)`. Множина `{L₀, L₁, …, L╙}` є базисом векторного простору `Pₙ[x]`, який є дуальним до базису функціоналів `{ϕ₀, ϕ₁, …, ϕ╙}` у дуальному просторі `Pₙ[x]*`. Рівність `ϕ╟(L╖) = δ╖╟` підтверджує взаємну дуальність цих базисів.

#### Доведення єдиності:
Припустимо, що існують два многочлени `P(x), Q(x) ∈ Pₙ[x]` такі, що `deg(P) ≤ n`, `deg(Q) ≤ n`, і для всіх `k = 0, …, n` виконується `P(x╖) = Q(x╖) = y╖`.

Розглянемо різницевий многочлен `H(x) = P(x) - Q(x)`.
- Степінь `H(x)` за властивостями степенів многочленів не перевищує `n`: `deg(H) ≤ n`.
- Обчислимо значення `H(x)` у кожному з `n + 1` вузлів:

```
H(x╖) = P(x╖) - Q(x╖) = y╖ - y╖ = 0    (для всіх k = 0, 1, …, n)
```

Многочлен `H(x)` степеня `≤ n` має принаймні `n + 1` різних коренів `x₀, x₁, …, x╙`.
За основною теоремою алгебри (або властивістю кільця многочленів над полем), многочлен степеня не вище `n`, який має більше ніж `n` коренів, є тотожним нулю: `H(x) ≡ 0`.

Отже, `P(x) - Q(x) ≡ 0 ⇒ P(x) ≡ Q(x)`. Єдиність доведено.

### 2. Строгий вивід залишкового члена похибки

Нехай функція `f(x)` є `(n + 1)` разів неперервно диференційовною на відрізку `[a, b]`, який містить вузли `x₀, x₁, …, x╙`. Нехай `Pₙ(x)` — інтерполяційний многочлен Лагранжа степеня `≤ n`.

**Теорема про похибку:**
Для будь-якої точки `x ∈ [a, b]` існує точка `ξ ∈ (min(x╖, x), max(x╖, x))` така, що похибка `Rₙ(x) = f(x) - Pₙ(x)` дорівнює:

```
Rₙ(x) = ( fⁿ⁺¹⁾(ξ) / (n + 1)! ) · ωₙ₊₁(x)
```

де `ωₙ₊₁(x) = ∏ (x - x╖)` (для `k = 0, 1, …, n`) — вузловий многочлен.

#### Доведення:
Якщо `x` збігається з одним із вузлів `x╖`, то `Rₙ(x╖) = 0` і `ωₙ₊₁(x╖) = 0`, отже рівність виконується тривіально для довільного `ξ`.

Розглянемо випадок, коли `x` не збігається з жодним із вузлів. Зафіксуємо цю точку `x` і зафіксуємо число `K(x)`, визначене співвідношенням:

```
f(x) - Pₙ(x) - K(x) · ωₙ₊₁(x) = 0
```

Оскільки `x` не є вузлом, `ωₙ₊₁(x) ≠ 0`, тому `K(x) = (f(x) - Pₙ(x)) / ωₙ₊₁(x)`.

Введемо допоміжну функцію від змінної `t ∈ [a, b]`:

```
g(t) = f(t) - Pₙ(t) - K(x) · ωₙ₊₁(t)
```

Проаналізуємо нулі функції `g(t)` на відрізку `[a, b]`:
1. У вузлах `t = x╖` (для `k = 0, …, n`): `f(x╖) = Pₙ(x╖)` та `ωₙ₊₁(x╖) = 0`, тому `g(x╖) = 0` (всього `n + 1` нулів).
2. У точці `t = x`: за побудовою `K(x)` маємо `g(x) = 0` (ще 1 нуль).

Отже, функція `g(t)` має принаймні `n + 2` різних нулів на відрізку `[a, b]`.

Застосуємо теорему Ролля послідовно до похідних функції `g(t)`:
- Між кожною парою сусідніх нулів функції `g(t)` лежить принаймні один нуль її першої похідної `g′(t)`. Отже, `g′(t)` має принаймні `n + 1` нулів.
- Між нулями `g′(t)` лежать принаймні `n` нулів другої похідної `g″(t)`.
- Продовжуючи цей процес за індукцією, на `(n + 1)`-му кроці отримуємо, що похідна `gⁿ⁺¹⁾(t)` має принаймні один нуль на відрізку. Позначимо цей нуль через `ξ`.

Обчислимо `(n + 1)`-шу похідну функції `g(t)` у точці `ξ`:

```
gⁿ⁺¹⁾(t) = fⁿ⁺¹⁾(t) - Pₙⁿ⁺¹⁾(t) - K(x) · ωₙ₊₁ⁿ⁺¹⁾(t)
```

Знайдемо похідні окремих доданків:
1. `Pₙ(t)` є многочленом степеня `≤ n`, тому його `(n + 1)`-ша похідна тотожно дорівнює нулю: `Pₙⁿ⁺¹⁾(t) ≡ 0`.
2. `ωₙ₊₁(t) = tⁿ⁺¹ + cₙ tⁿ + …` є многочленом зі старшим коефіцієнтом 1 і степенем `n + 1`. Його `(n + 1)`-ша похідна дорівнює константі: `ωₙ₊₁ⁿ⁺¹⁾(t) = (n + 1)!`.

Підставимо ці значення у вираз для `gⁿ⁺¹⁾(ξ) = 0`:

```
0 = fⁿ⁺¹⁾(ξ) - 0 - K(x) · (n + 1)!
⇒ K(x) = fⁿ⁺¹⁾(ξ) / (n + 1)!
```

Підставляючи `K(x)` у початкове визначення похибки, отримуємо остаточну формулу:

```
f(x) - Pₙ(x) = ( fⁿ⁺¹⁾(ξ) / (n + 1)! ) · ωₙ₊₁(x)
```

Доведення завершено.

### 3. Функція Лебега та оцінка константи Лебега

Для аналізу стійкості інтерполяційного оператора `Lₙ: C[a, b] → Pₙ[x]` вводиться **функція Лебега**:

```
λₙ(x) = ∑ |L╖(x)|    (сума по k від 0 до n)
```

Точна верхня межа функції Лебега на відрізку `[a, b]` називається **константою Лебега**:

```
Λₙ = max |λₙ(x)|    (для x ∈ [a, b])
```

#### Нерівність Лебега:
Нехай `Eₙ(f) = inf_{P ∈ Pₙ} ║f - P║_∞` — найкраще можливе рівномірне наближення функції `f` многочленами степеня `≤ n`. Тоді похибка інтерполяції Лагранжа задовольняє нерівність Лебега:

```
║f - Lₙ(f)║_∞ ≤ (1 + Λₙ) · Eₙ(f)
```

Це свідчить про те, що константа Лебега `Λₙ` є коефіцієнтом підсилення похибки інтерполятора порівняно з теоретично ідеальним наближенням.

- **Для рівномірної сітки:** `Λₙ ~ 2ⁿ⁺¹ / (e · n · ln n)` зростає експоненціально, що веде до феномену Рунге.
- **Для вузлів Чебишова:** `Λₙ ~ (2 / π) · ln(n) + C` зростає логарифмічно, що гарантує мінімальне підсилення похибки та високу чисельну стабільність.

### 4. Алгебраїчний вивід барицентричних форм

Канонічна формула Лагранжа `P(x) = ∑ y╖ L╖(x)` потребує `O(n²)` операцій для обчислення значення у точці `x`. Перетворимо її у чисельно стійку та швидку барицентричну форму.

Введемо **барицентричні ваги** (англ. *barycentric weights*) `w╖` для кожного вузла `x╖`:

```
w╖ = 1 / ∏ (x╖ - xⱼ)    (по j від 0 до n, де j ≠ k)
```

Позначимо повний вузловий многочлен через `ω(x) = ∏ (x - xⱼ)` (для `j = 0, …, n`).

Тоді базисний многочлен Лагранжа `L╖(x)` можна виразити через `ω(x)` та `w╖`:

```
L╖(x)
= ∏ (x - xⱼ) / ∏ (x╖ - xⱼ)                   [канонічне визначення базису Лагранжа]
= ( ω(x) / (x - x╖) ) · ( 1 / ∏ (x╖ - xⱼ) )  [виділення вузлового многочлена ω(x)]
= ω(x) · ( w╖ / (x - x╖) )                    [підстановка барицентричних ваг w╖]
```

#### Перша барицентрична формула:
Підставимо виражений `L╖(x)` у формулу інтерполяції Лагранжа:

```
P(x)
= ∑ y╖ · L╖(x)                      [канонічна суперпозиція Лагранжа]
= ∑ y╖ · ω(x) · ( w╖ / (x - x╖) )   [підстановка виразу L╖(x) через w╖]
= ω(x) · ∑ ( w╖ · y╖ / (x - x╖) )   [винесення спільного множника ω(x)]
```

Це **перша барицентрична форма** (англ. *first barycentric form*). Якщо ваги `w╖` обчислені заздалегідь (за `O(n²)` операцій), то обчислення `P(x)` для будь-якого нового `x` вимагає лише `O(n)` операцій для обчислення суми та множення на `ω(x)`.

#### Друга (справжня) барицентрична формула:
Розглянемо тотожну інтерполяцію константної функції `f(x) ≡ 1`.
Оскільки `y╖ = 1` для всіх `k`, інтерполяційний многочлен для константи `1` дорівнює тотожно `1`:

```
1 = ω(x) · ∑ ( w╖ / (x - x╖) )
```

Поділимо першу барицентричну форму на це тотожне представлення одиниці:

```
P(x)
= [ ω(x) · ∑ ( w╖ · y╖ / (x - x╖) ) ] / [ ω(x) · ∑ ( w╖ / (x - x╖) ) ]  [ділення на тотожну 1]
= [ ∑ ( w╖ · y╖ / (x - x╖) ) ] / [ ∑ ( w╖ / (x - x╖) ) ]                 [скорочення спільного ω(x)]
```

Це **друга барицентрична форма** (англ. *second / true barycentric form*).

**Переваги другої барицентричної форми:**
1. Повний вузловий многочлен `ω(x)` повністю скоротився з чисельника та знаменника! Нам більше не потрібно обчислювати добуток `(x - xⱼ)`.
2. Множники `w╖` визначені з точністю до довільного спільного масштабувального коефіцієнта `C`. Якщо замінити `w╖` на `C · w╖`, то `C` скоротиться у чисельнику та знаменнику.
3. Формула є чисельно високостійкою за класичним аналізом Ніколаса Гайема (англ. *Nicholas Higham*): похибки заокруглення у плаваючій комі чесно компенсуються між чисельником і знаменником.

### 5. Інтерполяція над скінченними полями `GF(p)`

У криптографії (зокрема у схемі розділення секрету Шаміра) інтерполяція виконується у кільці многочленів `GF(p)[x]`, де `p` — просте число.

Всі арифметичні операції (додавання, віднімання, множення та ділення) виконуються за модулем `p`.
Ділення на знаменник `(x╖ - xⱼ)` замінюється множенням на **мультиплікативний обернений елемент** у полі `GF(p)`:

```
(x╖ - xⱼ)⁻¹ ≡ (x╖ - xⱼ)ᵖ⁻² (mod p)    [за малою теоремою Ферма]
```

#### Формула відновлення секрету у точці `x = 0`:
Якщо у криптографічній системі секрет `S` зашифровано як значення многочлена у точці `x = 0` (`S = P(0)`), то за наданими `k` частками `(x₁, y₁), (x₂, y₂), …, (x╟, y╟)` секрет відновлюється за спрощеною формулою:

```
S = P(0) = ∑ y╖ · ∏ ( -xⱼ / (x╖ - xⱼ) ) (mod p)    (для j ≠ k)
```

Оскільки операції виконуються в точній арифметиці скінченного поля без округлень, інтерполяція Лагранжа дає **абсолютно точний алгебраїчний результат**.
