# 🧮 Матриця Якобі та диференціальна кінематика карданового підвісу

Коли контролер підвісу стабілізує корисне навантаження (оптичну камеру, лідар або головку самонаведення), йому недостатньо знати лише статичні кути орієнтації моторів. Корпус літального апарата безперервно зазнає кутових збурень від поривів вітру та маневрів, обертаючись із миттєвими кутовими швидкостями `ω_body`. Щоб лінія візування залишалася абсолютно нерухомою у просторі, мотори підвісу повинні обертатися зі строго розрахованими швидкостями `[ψ̇, θ̇, φ̇]ᵀ`, які в кожен момент часу компенсують динамічний рух носія.

Зв'язок між вектором кутової швидкості корисного навантаження у тривимірному просторі та швидкостями зміни кутів шарнірів є лінійним у швидкостях, але нелінійним за кутами положення. Цей диференціальний зв'язок задається **матрицею Якобі** (*Jacobian matrix*) кінематики підвісу.

## 1. Векторне додавання кутових швидкостей у кінематичному ланцюзі

Розглянемо класичний триосьовий підвіс із послідовністю вкладених кілець Z-Y-X:
- Корпус апарата утворює базову систему координат (рамка `F_b`).
- Зовнішнє кільце рискання обертається навколо осі `z_b` корпусу на кут `ψ` із кутовою швидкістю `ψ̇`. Одиничний вектор осі обертання: `z_b = [0, 0, 1]ᵀ` у базисі `F_b`.
- Проміжне кільце тангажу обертається навколо повернутої осі `y₁` на кут `θ` із кутовою швидкістю `θ̇`. Одиничний вектор осі: `y₁ = [0, 1, 0]ᵀ` у системі координат проміжного кільця `F₁`.
- Внутрішня платформа корисного навантаження (камера) обертається навколо двічі поверненої осі `x₂` на кут `φ` із кутовою швидкістю `φ̇`. Одиничний вектор осі: `x₂ = [1, 0, 0]ᵀ` у системі координат внутрішнього кільця `F₂`.

Кутова швидкість платформи камери `ω_c` відносно корпусу апарата утворюється як векторна сума внесків усіх трьох шарнірів, спроєктованих у єдину систему координат:

```
ω_c = ψ̇ · z_b + θ̇ · y₁ + φ̇ · x₂
```

Оскільки датчики кутової швидкості (тривісний МЕМС-гіроскоп або волоконно-оптичний гіроскоп) жорстко встановлені на самій платформі камери, найзручніше спроєктувати кожен із трьох векторів осей обертання у кінцеву систему координат камери `F_c`.

Перехід між системами координат здійснюється матрицями обертання `SO(3)`:
- Перехід із `F_b` у `F₁` описується матрицею `R_z(ψ)`.
- Перехід із `F₁` у `F₂` описується матрицею `R_y(θ)`.
- Перехід із `F₂` у `F_c` описується матрицею `R_x(φ)`.

Спроєктуємо кожен одиничний вектор осі в систему координат `F_c`:

1. **Вісь крену `x₂`**: цей шарнір безпосередньо з'єднує рамку `F₂` із платформою `F_c`, тому його вісь уже збігається з віссю `x_c` камери:
```
(x₂) в F_c = [1, 0, 0]ᵀ
```

2. **Вісь тангажу `y₁`**: лежить у рамці `F₁` і піддається лише одному обертанню навколо осі крену `x` на кут `φ`:
```
(y₁) в F_c
= R_x(φ)ᵀ · [0, 1, 0]ᵀ               [проєкція з F₁ у F_c через транспоновану матрицю R_x]
= | 1     0       0    | | 0 |
  | 0   cos φ   sin φ  | | 1 |       [матриця R_x(φ)ᵀ = R_x(-φ)]
  | 0  −sin φ   cos φ  | | 0 |
= [0, cos φ, −sin φ]ᵀ                [вектор осі тангажу в базисі камери]
```

3. **Вісь рискання `z_b`**: закріплена на корпусі апарата `F_b` і зазнає двох послідовних поворотів: навколо осі тангажу на кут `θ`, а потім навколо осі крену на кут `φ`:
```
(z_b) в F_c
= R_x(φ)ᵀ · R_y(θ)ᵀ · [0, 0, 1]ᵀ     [проєкція з F_b у F_c через дві послідовні рамки]
= R_x(φ)ᵀ · |  cos θ   0  −sin θ | | 0 |
            |    0     1     0   | | 0 |  [проміжний поворот навколо Y]
            |  sin θ   0   cos θ | | 1 |
= R_x(φ)ᵀ · [−sin θ, 0, cos θ]ᵀ      [вектор осі рискання в системі проміжного кільця F₁]
= | 1     0       0    | | −sin θ |
  | 0   cos φ   sin φ  | |    0   |  [фінальний поворот навколо X]
  | 0  −sin φ   cos φ  | |  cos θ |
= [−sin θ,  sin φ · cos θ,  cos φ · cos θ]ᵀ
```

## 2. Будова прямої матриці Якобі

Підставимо отримані координатні стовпчики у рівняння векторної суми кутових швидкостей:

```
ω_c = ψ̇ · (z_b в F_c) + θ̇ · (y₁ в F_c) + φ̇ · (x₂ в F_c)
```

Запишемо цей лінійний зв'язок у матричному вигляді `ω_c = J · q̇`, де `q̇ = [φ̇, θ̇, ψ̇]ᵀ` — вектор кутових швидкостей моторів підвісу:

```
| ω_x |   | 1     0             −sin θ           | | φ̇ |
| ω_y | = | 0   cos φ      sin φ · cos θ         | | θ̇ |
| ω_z |   | 0  −sin φ      cos φ · cos θ         | | ψ̇ |
```

Матриця Якобі `J(θ, φ)` розміром 3×3 повністю описує пряму диференціальну кінематику підвісу:

```
          | 1     0             −sin θ       |
J(θ, φ) = | 0   cos φ      sin φ · cos θ     |
          | 0  −sin φ      cos φ · cos θ     |
```

Кожен стовпчик матриці Якобі має прозорий геометричний зміст:
- Перший стовпчик `[1, 0, 0]ᵀ` показує, в яку кутову швидкість камери перетворюється одинична швидкість мотора крену `φ̇`.
- Другий стовпчик `[0, cos φ, −sin φ]ᵀ` показує просторовий напрямок кутової швидкості, яку створює мотор тангажу `θ̇`.
- Третій стовпчик `[−sin θ, sin φ · cos θ, cos φ · cos θ]ᵀ` задає напрямок дії мотора рискання `ψ̇`.

## 3. Детермінант Якобіана та геометрична сингулярність

Обчислимо визначник матриці `J(θ, φ)` розкладанням за елементами першого стовпчика:

```
det(J)
= 1 · det |  cos φ    sin φ · cos θ |
          | −sin φ    cos φ · cos θ |   [розклад за першим стовпчиком: ненульовий лише елемент [0,0]=1]
= (cos φ · cos φ · cos θ) − (−sin φ · sin φ · cos θ) [різниця добутків діагоналей підматриці 2×2]
= cos² φ · cos θ + sin² φ · cos θ       [розкриття дужок]
= cos θ · (cos² φ + sin² φ)             [винесення спільного множника cos θ]
= cos θ · 1                             [основна тригонометрична тотожність: cos² φ + sin² φ = 1]
= cos θ                                 [аналітичний детермінант Якобіана підвісу]
```

Звідси випливає фундаментальна властивість:
- Визначник Якобіана залежить **виключно від кута тангажу `θ`** і абсолютно не залежить від кутів крену `φ` чи рискання `ψ`.
- При `θ = 0°` (горизонтальне положення камери) `det(J) = cos(0°) = 1`: осі шарнірів взаємно ортогональні, підвіс має максимальну керованість.
- При `θ → ±90°` (`±π/2` радіана) `det(J) = cos(±π/2) = 0`: матриця втрачає повний ранг (ранг падає з 3 до 2). Перший і третій стовпчики матриці стають лінійно залежними, що відповідає фізичному складанню осей крену та рискання на одну пряму.

## 4. Зворотна кінематика швидкостей (Інверсія Якобіана)

Для стабілізації камери мікроконтролер підвісу розв'язує задачу: за виміряною гіроскопом кутовою швидкістю `ω_c` розрахувати необхідні швидкості обертання приводів `q̇ = J⁻¹ · ω_c`.

Знайдемо обернену матрицю `J⁻¹` за формулою приєднаної матриці `J⁻¹ = (1 / det(J)) · Cᵀ`:

```
        | 1    sin φ · tan θ     cos φ · tan θ |
J⁻¹   = | 0        cos φ            −sin φ     |
        | 0    sin φ / cos θ     cos φ / cos θ |
```

Перевіримо правильність інверсії, обчисливши добуток `J⁻¹ · J`:

```
Рядок 0:
[1, 0, −sin θ + sin φ · tan θ · sin φ · cos θ + cos φ · tan θ · cos φ · cos θ]
= −sin θ + tan θ · cos θ · (sin² φ + cos² φ)   [групування за tan θ · cos θ]
= −sin θ + sin θ · 1                           [спрощення: tan θ · cos θ = sin θ]
= 0                                            [елемент [0,2] = 0, діагональ = 1]
```

Розгорнута система диференціальних рівнянь для швидкості кожного мотора:

```
φ̇ = ω_x + (ω_y · sin φ + ω_z · cos φ) · tan θ
θ̇ = ω_y · cos φ − ω_z · sin φ
ψ̇ = (ω_y · sin φ + ω_z · cos φ) / cos θ
```

Коли кут тангажу наближається до 90°, вирази `tan θ` та `1 / cos θ` необмежено зростають до нескінченності. Будь-який шум гіроскопа навколо поперечних осей породжує катастрофічні вимоги до швидкості моторів рискання `ψ̇` та крену `φ̇`.

## 5. Еліпсоїд маніпулятивності та сингулярні числа

Кінематичну спроможність підвісу генерувати кутові швидкості камери описує **еліпсоїд маніпулятивності Йошікави** (*Yoshikawa manipulability ellipsoid*).

Якщо обмежити вектор швидкостей моторів одиничною сферою `‖q̇‖² = φ̇² + θ̇² + ψ̇² ≤ 1`, то множина досяжних кутових швидкостей камери `ω_c` утворює тривимірний еліпсоїд:

```
ω_cᵀ · (J · Jᵀ)⁻¹ · ω_c ≤ 1
```

Півосі цього еліпсоїда дорівнюють сингулярним числам `σ₁, σ₂, σ₃` матриці Якобі `J`:
- Показник маніпулятивності: `w = √(det(J · Jᵀ)) = |det(J)| = |cos θ|`.
- При `θ = 0°`: еліпсоїд є сферою одиничного радіуса `σ₁ = σ₂ = σ₃ = 1`. Підвіс однаково легко парирує збурення за всіма трьома осями.
- При `θ → 90°`: найменше сингулярне число `σ₃ = |cos θ| → 0`. Еліпсоїд сплющується у плоский двовимірний диск. Здатність створювати кутову швидкість уздовж осі, перпендикулярної до площини кілець, повністю зникає.

### Число обумовленості Якобіана

Число обумовленості `κ(J) = ‖J‖ · ‖J⁻¹‖` показує, у скільки разів відносна похибка датчиків підсилюється при обчисленні швидкостей моторів:
- При `θ = 0°`: `κ(J) = 1.0` (ідеально обумовлена система).
- При `|θ| = 60°`: `cos(60°) = 0.5` → `κ(J) ≈ 2.6`.
- При `|θ| = 80°`: `cos(80°) ≈ 0.1736` → `κ(J) ≈ 6.8`.
- При `|θ| = 89°`: `cos(89°) ≈ 0.01745` → `κ(J) ≈ 58.2`.
- При `|θ| = 90°`: `κ(J) → ∞` (повна втрата керованості).

## 6. Демпфована інверсія (Damped Least Squares)

Щоб запобігти вибуху швидкостей приводів у реальних системах керування, застосовують метод демпфованих найменших квадратів (регуляризація Тихонова / псевдоінверсія Левенберга–Марквардта):

```
J* = Jᵀ · (J · Jᵀ + λ² · I)⁻¹
```

де `λ` — адаптивний параметр демпфування. У безпечній зоні `|θ| < 75°` демпфування відсутнє (`λ = 0`), а при наближенні до критичного кута `λ` плавно зростає:

```
λ² = λ_max² · (1 − (cos θ / cos θ_thresh)²)      [для |θ| > θ_thresh]
```

Застосування `J*` обмежує максимальні швидкості моторів фізично допустимими межами ціною незначного тимчасового відхилення лінії візування від ідеалу під час проходження зенітної зони.

## 7. Числовий розрахунок стабілізації (Worked Example)

Розглянемо практичний приклад. Нехай безпілотник виконує маневр, при якому підвіс перебуває в положенні:
- Крен: `φ = 30°` (`cos φ = 0.866`, `sin φ = 0.500`)
- Тангаж: `θ = 45°` (`cos θ = 0.707`, `sin θ = 0.707`, `tan θ = 1.000`)
- Рискання: `ψ = 15°`

Гіроскоп на камері фіксує кутову швидкість збурення: `ω_c = [0.10,  −0.20,  0.50]ᵀ` рад/с.

1. **Обчислимо матрицю Якобі `J`**:
```
J = | 1.000    0.000   −0.707 |
    | 0.000    0.866    0.354 |
    | 0.000   −0.500    0.612 |

det(J) = cos(45°) ≈ 0.7071
```

2. **Обчислимо обернену матрицю `J⁻¹`**:
```
J⁻¹ = | 1.000    0.500    0.866 |
      | 0.000    0.866   −0.500 |
      | 0.000    0.707    1.225 |
```

3. **Знаходимо кутові швидкості моторів `q̇ = J⁻¹ · ω_c`**:
```
φ̇ = 1.000 · (0.10) + 0.500 · (−0.20) + 0.866 · (0.50) = 0.10 − 0.10 + 0.433 = +0.433 рад/с
θ̇ = 0.000 · (0.10) + 0.866 · (−0.20) − 0.500 · (0.50) = −0.173 − 0.250 = −0.423 рад/с
ψ̇ = 0.000 · (0.10) + 0.707 · (−0.20) + 1.225 · (0.50) = −0.141 + 0.613 = +0.472 рад/с
```

Контролер підвісу видає завдання швидкості на регулятори моторів: мотор крену `+24.8°/с`, мотор тангажу `−24.2°/с`, мотор рискання `+27.0°/с`. Збурення успішно скомпенсоване.
