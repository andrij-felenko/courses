Коли дрон летить крізь поривчастий вітер, його фюзеляж безперервно тремтить, завалюється на крило та рискає курсом на десятки градусів щосекунди. Якби оптична камера або чутливий елемент гіроскопа були жорстко прикручені до рами, зняте відео перетворилося б на хаотичне тремтіння, а система інерціальної навігації накопичила б критичні похибки за лічені секунди. Щоб лінія візування залишалася абсолютно нерухомою у просторі незалежно від кульбітів носія, корисне навантаження встановлюють у шарнірний вузол — **кардановий підвіс** (*gimbal*; від старофранцузького *gemel* — «близнюк, парний шарнір», за іменем італійського математика й механіка Джероламо Кардано).

Кардановий підвіс — це не просто механічна конструкція з моторів, кілець і підшипників. Це фізичне втілення фундаментальної математичної структури: послідовної параметризації тривимірної групи обертань `SO(3)` через кінематичний ланцюг вкладених систем координат. Розберемо, як влаштована геометрія підвісу, чому центр мас зобов'язаний збігатися з перетином осей, де в ній ховається математична сингулярність карданового замка, як перейти від кутів до кватерніонів і матриць напрямних косинусів та як будуються алгоритми прямої й зворотної кінематики для прецизійної стабілізації та цілевказівки.

## 1. Механічна будова та кінематичний ланцюг підвісу

Щоб повністю ізолювати корисне навантаження (оптичну камеру, тепловізор, лазерний далекомір або інерціальну платформу) від кутових коливань корпусу, підвіс має забезпечити обертання платформи навколо трьох незалежних просторових осей. Для цього використовують конструкцію з трьох концентричних металевих рамок (кілець), вкладених одна в одну.

Кожне кільце з'єднується з сусіднім через обертальний шарнір (*revolute joint*), оснащений безколекторним електродвигуном прямого приводу (*direct-drive BLDC*) та високоточним магнітним енкодером кутового положення:

```
Корпус апарата (Базова рамка F_b)
   ↓ [Мотор 1: вісь Z_b, кут рискання ψ]
Зовнішнє кільце (Рамка F_1)
   ↓ [Мотор 2: вісь Y_1, кут тангажу θ]
Проміжне кільце (Рамка F_2)
   ↓ [Мотор 3: вісь X_2, кут крену φ]
Внутрішня платформа з корисним навантаженням (Рамка F_3 / Камера)
```

![Кінематичний ланцюг триосьового підвісу](/root/sci/math-geometry/gimbal/img/gimbal-kinematic-chain.svg)
*Кінематичний ланцюг триосьового підвісу за схемою Z-Y-X. Корпус апарата утворює базову систему координат. Зовнішнє кільце рискання обертається навколо осі Z_b, проміжне кільце тангажу — навколо поверненої осі Y_1, а внутрішня платформа камери — навколо двічі поверненої осі X_2. Повна орієнтація камери відносно корпусу є добутком трьох локальних матриць.*

### Геометрія перетину осей та балансування центра мас

У правильно спроєктованому кардановому підвісі всі три осі обертання перетинаються в **одній геометричній точці** `O`. У цій самій точці повинен строго розташовуватися центр мас (*Center of Gravity, CG*) корисного навантаження:

```
CG_payload ≡ O_intersection
```

Якщо центр мас зміщений від точки перетину осей на вектор `r_offset`, будь-яке лінійне прискорення літака `a` або гравітація `g` створюють збурювальний гравітаційно-інерційний момент:

```
τ_disturb = r_offset × m · (a − g)
```

Цей момент намагається провернути камеру в шарнірах при кожному розгоні або гальмуванні дрона, змушуючи мотори споживати колосальний струм для його утримання. Ідеальне статичне та динамічне балансування зводить `r_offset → 0`, завдяки чому приводи підвісу долають лише сили сухого та в'язкого тертя в підшипниках та аеродинамічний опір набігаючого потоку повітря.

### Розподіл моментів інерції за рамками

Ієрархія вкладених кілець породжує суттєву асиметрію моментів інерції:
- **Мотор крену (внутрішній)** обертає лише легку центральну платформу з камерою. Його момент інерції мінімальний: `I_roll = I_cam`.
- **Мотор тангажу (середній)** обертає камеру разом із внутрішньою рамкою крену та її мотором: `I_pitch = I_cam + I_roll_ring + m_roll_motor · r²`.
- **Мотор рискання (зовнішній)** обертає всю конструкцію: камеру, рамку крену, рамку тангажу та обидва внутрішні двигуни: `I_yaw ≫ I_pitch > I_roll`.

Через це смуга пропускання контурів стабілізації відрізняється: контур крену найшвидший (до 150–200 Гц), тоді як контур рискання через велику інерцію має нижчу резонансну частоту (30–60 Гц).

### Послідовність внутрішніх поворотів (Intrinsic Rotations)

Оскільки шарніри закріплені один на одному, кожен наступний поворот здійснюється навколо осі, положення якої вже змінене попередніми поворотами. Такі обертання в теоретичній механіці називають **внутрішніми** (*intrinsic*).

Розглянемо стандартну авіаційну послідовність Тейта–Браяна **3-2-1 (Z-Y-X)**:

1. **Рискання** (*yaw*, кут `ψ`): зовнішнє кільце повертається навколо базової осі `z_b` корпусу апарата. Система координат переходить із початкової `F_b` у рамку `F_1`. Матриця переходу:
```
           |  cos ψ  −sin ψ   0 |
R_z(ψ) =   |  sin ψ   cos ψ   0 |
           |    0       0     1 |
```

2. **Тангаж** (*pitch*, кут `θ`): проміжне кільце повертається навколо нової поперечної осі `y_1`. Система координат переходить із `F_1` у `F_2`. Матриця переходу:
```
           |  cos θ   0   sin θ |
R_y(θ) =   |    0     1     0   |
           | −sin θ   0   cos θ |
```

3. **Крен** (*roll*, кут `φ`): внутрішня платформа повертається навколо двічі поверненої поздовжньої осі `x_2`. Система координат переходить із `F_2` у кінцеву рамку камери `F_3`. Матриця переходу:
```
           | 1     0       0    |
R_x(φ) =   | 0   cos φ  −sin φ  |
           | 0   sin φ   cos φ  |
```

Чому саме послідовність Z-Y-X є канонічною для оптичних підвісів? Тому що зовнішня вісь Z відповідає за азимутальне панорамування по горизонту (панорама 360°), середня вісь Y — за підйом та опускання об'єктива по куту місця (нахил вгору-вниз), а внутрішня вісь X — виключно за усунення завалювання лінії горизонту на знімку. Така кінематика природно відображає роботу оператора та оптимізує поля зору.

### Композиція орієнтації в групі SO(3)

Спеціальна ортогональна група `SO(3)` (*Special Orthogonal Group* розмірності 3) — це математичний простір усіх можливих поворотів у тривимірному евклідовому просторі. Будь-який елемент `R ∈ SO(3)` є дійсною матрицею 3×3, яка зберігає довжини векторів, кути між ними та орієнтацію базису (`Rᵀ · R = I`, `det(R) = +1`).

Оскільки послідовні внутрішні повороти математично записуються як добуток елементарних матриць зліва направо в порядку їх застосування, результуюча матриця відносної орієнтації підвісу `R_g` дорівнює:

```
R_g(ψ, θ, φ) = R_z(ψ) · R_y(θ) · R_x(φ)
```

Перемножимо ці три матриці крок за кроком. Спершу знайдемо добуток `R_y(θ) · R_x(φ)`:

```
R_yx = R_y(θ) · R_x(φ)
= |  cos θ   0   sin θ | | 1     0       0    |    [підстановка матриць R_y(θ) та R_x(φ)]
  |    0     1     0   | | 0   cos φ  −sin φ  |
  | −sin θ   0   cos θ | | 0   sin φ   cos φ  |
= |  cos θ    sin θ · sin φ    sin θ · cos φ |         [результат добутку матриць 3×3]
  |    0          cos φ           −sin φ     |
  | −sin θ    cos θ · sin φ    cos θ · cos φ |
```

Тепер домножимо результат зліва на матрицю рискання `R_z(ψ)`:

```
R_g = R_z(ψ) · R_yx
= | cos ψ  −sin ψ   0 | |  cos θ    sin θ · sin φ    sin θ · cos φ |  [множення матриць R_z(ψ) та R_yx]
  | sin ψ   cos ψ   0 | |    0          cos φ           −sin φ     |
  |   0       0     1 | | −sin θ    cos θ · sin φ    cos θ · cos φ |

  [Рядок 0]:
  R_g[0,0] = cos ψ · cos θ
  R_g[0,1] = cos ψ · sin θ · sin φ − sin ψ · cos φ
  R_g[0,2] = cos ψ · sin θ · cos φ + sin ψ · sin φ

  [Рядок 1]:
  R_g[1,0] = sin ψ · cos θ
  R_g[1,1] = sin ψ · sin θ · sin φ + cos ψ · cos φ
  R_g[1,2] = sin ψ · sin θ · cos φ − cos ψ · sin φ

  [Рядок 2]:
  R_g[2,0] = −sin θ
  R_g[2,1] = cos θ · sin φ
  R_g[2,2] = cos θ · cos φ
```

Повна матриця обертання підвісу `R_g` компактно зв'язує систему координат камери з системою координат корпусу носія. Якщо орієнтація самого літака у світовій системі координат (наприклад, [ECEF або NED](root:math-geometry/ecef-ned-enu)) задана матрицею `R_body`, то абсолютна орієнтація камери у світі знаходиться простим асоціативним множенням:

```
R_cam = R_body · R_g
```

> 🔧 **Навіщо це.** Плутанина між внутрішніми (*intrinsic*, рухомі осі) та зовнішніми (*extrinsic*, нерухомі світові осі) поворотами — класична помилка розробників. Якщо обчислювати поворот відносно нерухомих осей світу, порядок матриць у добутку інвертується: `R_ext = R_x · R_y · R_z`. Для фізичного підвісу осі кілець жорстко вкладені одна в одну, тому адекватний кінематичний розрахунок будується виключно за внутрішньою послідовністю.

## 2. Карданів замок (Gimbal Lock) та кінематична сингулярність

Попри інтуїтивну наочність трійки кутів `(ψ, θ, φ)`, механічний триосьовий підвіс містить геометричну вразливість, яка за певних положень повністю паралізує його роботу. Це явище відоме як **карданів замок** (*gimbal lock*, або складання рамок).

### Геометричний механізм виродження

Уявімо, що безпілотник або камера підвісу нахиляється так, що кут тангажу досягає значення `θ = +90°` (`+π/2` радіана, ніс піднятий вертикально вгору в зеніт) або `θ = −90°` (надир, погляд вертикально вниз).

Поворот середнього кільця на 90° піднімає внутрішнє кільце дибки. При цьому вісь внутрішнього шарніра (вісь крену `X`), яка в горизонтальному положенні лежала в горизонтальній площині, розвертається строго вертикально. Але вертикально вже спрямована вісь зовнішнього шарніра (вісь рискання `Z`).

```
θ = +90°  ⇒  вісь X_2 (крен) стає строго колінеарною осі Z_b (рискання)
```

![Геометрія карданового замка](/root/sci/math-geometry/gimbal/img/gimbal-lock-singularity.svg)
*Складання осей підвісу при θ = +90°. Зліва: за нульового тангажу всі три осі ортогональні, забезпечуючи повноцінні 3 ступені вільності. Справа: при підйомі на 90° вісь крену збігається з віссю рискання. Обертання двох різних моторів виконує поворот навколо однієї прямої, а поворот навколо поперечної осі стає фізично неможливим.*

Коли дві осі обертання збігаються:
1. Обертання зовнішнього мотора рискання на кут `Δα` повертає камеру навколо вертикалі.
2. Обертання внутрішнього мотора крену на кут `Δβ` повертає ту саму камеру навколо тієї ж самої вертикалі.
3. Обидва мотори керують однією і тією самою просторовою координатою — сумою або різницею кутів `(ψ ± φ)`.

Система втрачає один ступінь вільності (`3 DOF → 2 DOF`). Якщо тепер корпус апарата зазнає кутового збурення навколо поперечної осі, перпендикулярної до площини кілець, підвіс фізично не має шарніра, здатного це збурення скомпенсувати. Мотори не можуть створити протидіючий момент, шарнір передає механічний ривок безпосередньо на камеру, і стабілізація зривається.

### Історичний прецедент: місія «Аполлон-11»

Явище складання рамок стало критичною проблемою під час пілотованих польотів програми Apollo на Місяць. Інерціальний вимірювальний блок корабля (*IMU*) являв собою платформу на триосьовому кардановому підвісі. Коли кут тангажу наближався до 85°, бортовий комп'ютер AGC (*Apollo Guidance Computer*) виводив тривожне повідомлення `GIMBAL LOCK`, а індикатор на панелі пілота спалахував червоним світлом.

Астронавт Майкл Коллінз під час маневрів командного модуля на навколомісячній орбіті мусив вручну контролювати орієнтацію корабля двигунами орієнтації RCS, щоб не допустити складання рамок підвісу. Якби корабель перетнув кут 90°, гіроплатформа механічно заклинила б, повністю втративши навігаційну прив'язку до зірок, що вимагало б тривалого та небезпечного повторного калібрування за допомогою оптичного секстанта.

### Аналітичне виродження матриці повороту

Погляньмо, що відбувається з аналітичною матрицею `R_g`, коли `θ = +90°` (`cos θ = 0`, `sin θ = 1`):

```
R_g(ψ, +π/2, φ)
= | cos ψ · 0    cos ψ · 1 · sin φ − sin ψ · cos φ    cos ψ · 1 · cos φ + sin ψ · sin φ |  [підстановка cos(π/2)=0, sin(π/2)=1]
  | sin ψ · 0    sin ψ · 1 · sin φ + cos ψ · cos φ    sin ψ · 1 · cos φ − cos ψ · sin φ |
  |    −1                     0 · sin φ                            0 · cos φ            |

= |  0    sin(φ − ψ)    cos(φ − ψ) |     [за тригонометричними формулами віднімання кутів]
  |  0    cos(φ − ψ)   −sin(φ − ψ) |
  | −1        0             0      |
```

Усі елементи матриці залежать **виключно від різниці кутів `(φ − ψ)`**. Не існує унікальної пари кутів `ψ` та `φ`: нескінченна множина комбінацій (наприклад, `ψ = 30°, φ = 50°` та `ψ = 0°, φ = 20°`) породжують абсолютно ідентичну орієнтацію в просторі. Зворотне перетворення стає невизначеним: неможливо відновити початкові кути моторів за відомим положенням камери.

Аналогічно, при `θ = −90°` (`cos θ = 0`, `sin θ = −1`):

```
R_g(ψ, −π/2, φ)
= | cos ψ · 0    cos ψ · (−1) · sin φ − sin ψ · cos φ    cos ψ · (−1) · cos φ + sin ψ · sin φ |  [підстановка cos(-π/2)=0, sin(-π/2)=-1]
  | sin ψ · 0    sin ψ · (−1) · sin φ + cos ψ · cos φ    sin ψ · (−1) · cos φ − cos ψ · sin φ |
  |     1                      0 · sin φ                             0 · cos φ            |

= |  0   −sin(φ + ψ)   −cos(φ + ψ) |     [за формулами суми кутів: елементи залежать лише від (φ + ψ)]
  |  0    cos(φ + ψ)   −sin(φ + ψ) |
  |  1        0             0      |
```

### Диференціальна сингулярність та вибух кутових швидкостей

У динаміці проблема карданового замка виявляється ще жорсткіше. Диференціальний зв'язок між кутовими швидкостями моторів `[φ̇, θ̇, ψ̇]ᵀ` та вектором кутової швидкості камери `ω` задається [матрицею Якобі](root:math-geometry/gimbal/math-gimbal-jacobian.md).

Для обчислення необхідних керуючих швидкостей моторів контролер повинен інвертувати матрицю Якобі:

```
| φ̇ |   | 1    sin φ · tan θ     cos φ · tan θ | | ω_x |
| θ̇ | = | 0        cos φ            −sin φ     | | ω_y |
| ψ̇ |   | 0    sin φ / cos θ     cos φ / cos θ | | ω_z |
```

Детермінант Якобіана дорівнює `det(J) = cos θ`. Коли тангаж наближається до 90°:
- `cos θ → 0`
- `tan θ → ±∞`
- `1 / cos θ → ∞`

Щоб компенсувати навіть мікроскопічну кутову швидкість корпусу літака `ω_y` чи `ω_z`, мотори підвісу повинні обертатися з нескінченною швидкістю `ψ̇ → ∞`, `φ̇ → ∞`. Реальний привід миттєво входить у насичення за струмом і напругою, відстає від збурення, і гіростабілізована платформа втрачає орієнтацію.

### Подолання сингулярності: чотириосьовий підвіс (4-Axis Gimbal)

У професійній кінематографії та військовій оптико-електронній розвідці, де кут огляду повинен безперервно супроводжувати цілі в зеніті та надирі (наприклад, супровід літака прямо над головою), трьох осей недостатньо. Застосовують **чотириосьовий надлишковий підвіс** (*4-axis redundant gimbal*).

![Чотириосьовий підвіс для усунення карданового замка](/root/sci/math-geometry/gimbal/img/four-axis-gimbal.svg)
*Чотириосьовий надлишковий підвіс. Зовнішня рамка грубого стеження (Outer Yaw) розвертає систему так, щоб робоче середнє кільце (Inner Pitch) завжди залишалося в безпечній зоні |θ| < 60°, гарантуючи безперервну тривісну стабілізацію 360°×360°.*

Конструкція додає додаткову зовнішню вісь:
1. **Зовнішній Yaw (Outer Yaw / Coarse)**: грубий поворот навколо вертикалі.
2. **Внутрішній Yaw (Inner Yaw / Fine)**: точна високочастотна стабілізація курсу.
3. **Тангаж (Pitch)**: нахил вгору-вниз.
4. **Крен (Roll)**: утримання лінії горизонту.

Алгоритм керування безперервно відстежує кут внутрішнього тангажу `θ`. Щойно `|θ|` перевищує поріг 60°, зовнішній мотор рискання починає плавно розвертати всю платформу, переорієнтовуючи підвіс так, щоб кут внутрішнього тангажу ніколи не досягав критичних 90°. Тим самим кінематична сингулярність виводиться за межі робочого діапазону приводів.

## 3. Альтернативні представлення орієнтації

Фундаментальна теорема топології стверджує: **неможливо параметризувати групу обертань `SO(3)` трьома дійсними числами глобально без сингулярностей**. Будь-яка система трьох параметрів (кути Ейлера, кути Тейта–Браяна, модифіковані параметри Родрігеса) обов'язково містить точки складання рамок або розриви.

Тому в математичному ядрі систем навігації та керування від кутів Ейлера відмовляються на користь чотири- або дев'ятипараметричних представлень.

### Матриця напрямних косинусів (DCM)

[Матриця напрямних косинусів](root:math-geometry/direction-cosine-matrix) (*Direction Cosine Matrix*, DCM) описує поворот безпосередньо через матрицю 3×3:

```
R = | r11  r12  r13 |
    | r21  r22  r23 |
    | r31  r32  r33 |
```

Кожен елемент `r_ij` дорівнює косинусу кута між `i`-ю віссю нової системи координат та `j`-ю віссю вихідної.
- **Переваги**: повна відсутність сингулярностей; поворот вектора обчислюється тривіальним матричним множенням `v' = R · v` без жодної тригонометричної функції.
- **Недоліки**: надлишкове представлення (9 чисел замість 3 ступенів вільності); для збереження належності до `SO(3)` необхідно постійно підтримувати 6 нелінійних обмежень ортогональності `Rᵀ · R = I`. При чисельному інтегруванні матриця швидко накопичує помилки округлення, вимагаючи періодичної ортогоналізації методом Грама–Шмідта.

### Кватерніони Гамільтона на одиничній 3-сфері

Найелегантнішим та обчислювально найефективнішим інструментом опису орієнтацій є [кватерніони Гамільтона](root:math-geometry/quaternions).

Кватерніон `q` — це гіперкомплексне число з однією дійсною та трьома уявними частинами:

```
q = q0 + q1 · i + q2 · j + q3 · k = [q0,  q_vecᵀ]ᵀ
де  i² = j² = k² = i·j·k = −1
```

Для опису поворотів використовують **одиничні кватерніони** (*unit quaternions*, версори), норми яких строго дорівнюють одиниці: `q0² + q1² + q2² + q3² = 1`. Геометрично простір одиничних кватерніонів утворює одиничну тривимірну гіперсферу `S³` у чотиривимірному просторі `ℝ⁴`.

Зв'язок із фізичним поворотом на кут `α` навколо одиничної просторової осі `u = [u_x, u_y, u_z]ᵀ` задається формулою Ейлера–Гамільтона:

```
q = [cos(α / 2),  u · sin(α / 2)]ᵀ
```

```
q0 = cos(α / 2)
q1 = u_x · sin(α / 2)
q2 = u_y · sin(α / 2)
q3 = u_z · sin(α / 2)
```

Поворот тривимірного вектора `v` через кватерніон обчислюється сендвіч-добутком Гамільтона:

```
v_rot_quat = q ⊗ [0, vᵀ]ᵀ ⊗ q*
```

де `q* = [q0, −q_vecᵀ]ᵀ` — спряжений кватерніон.

Кватерніонне представлення має такі властивості:
1. **Подвійне накриття групи `SO(3)`**: кватерніони `q` та `−q` описують абсолютно один і той самий фізичний поворот (поворот на кут `α` навколо осі `u` тотожний повороту на кут `2π − α` навколо осі `−u`).
2. **Композиція без тригонометрії**: послідовні повороти обчислюються як кватерніонний добуток Гамільтона `q_res = q_b ⊗ q_a`, що потребує всього 16 операцій множення та 12 операцій додавання (проти 27 множень для матриць 3×3).
3. **Плавна сферична інтерполяція (SLERP)**: для плавного переміщення камери між двома орієнтаціями `q_start` та `q_end` кватерніони дозволяють будувати дугу великого кола на сфері `S³` з постійною кутовою швидкістю:
```
slerp(q_a, q_b, t) = (sin((1 − t)·Ω) / sin Ω) · q_a + (sin(t·Ω) / sin Ω) · q_b
де cos Ω = q_a · q_b
```
4. **Неперервне кінематичне інтегрування**: динаміка зміни кватерніона за виміряною гіроскопом кутовою швидкістю `ω` описується лінійним диференціальним рівнянням без жодної сингулярності:
```
q̇ = 0.5 · q ⊗ [0, ωᵀ]ᵀ
```
5. **Проста нормалізація**: накопичення похибок виправляється діленням 4 компонентів на евклідову норму `q / ‖q‖` без складних матричних розкладів.

### Вектор поворотного зміщення та формула Родриґа

Поворот можна також задати вектором осі `u` та скалярним кутом `α`. [Формула повороту Родриґа](root:math-geometry/rodrigues-rotation) трансформує довільний вектор `v` без побудови повної матриці:

```
v_rot = v · cos α + (u × v) · sin α + u · (u · v) · (1 − cos α)
```

### Порівняльна характеристика представлень орієнтації

| Характеристика | Кути Ейлера (Z-Y-X) | Матриця DCM (3×3) | Кватерніон Гамільтона | Вісь-кут (Axis-Angle) |
|---|---|---|---|---|
| **Кількість параметрів** | 3 | 9 | 4 | 4 (або вектор 3) |
| **Кількість обмежень** | 0 | 6 (`Rᵀ·R=I, det=+1`) | 1 (`‖q‖=1`) | 1 (`‖u‖=1`) |
| **Сингулярності (Gimbal Lock)** | **Є** (при `θ = ±90°`) | **Немає** | **Немає** | Є (при `α = 0, 2π`) |
| **Операцій на композицію** | Багато (тригонометрія) | 27 mult, 18 add | 16 mult, 12 add | Перехід через кватерніон |
| **Поворот вектора** | Потрібна матриця | 9 mult, 6 add | 15 mult, 12 add | Формула Родриґа |
| **Нормалізація похибок** | Не потрібна | Складна (Грам–Шмідт) | Тривіальна (`1 / √∑q_i²`) | Нормалізація осі `u` |
| **Інтерполяція орієнтації** | Нелінійна (ривки) | Складна | Ідеальна (SLERP) | Лінійна за кутом |

## 4. Пряма та зворотна кінематика камери

У типовому завданні спостереження безпілотник повинен утримувати камеру спрямованою на наземний об'єкт із відомими координатами, навіть коли сам виконує розвороти, зліт або маневри ухилення.

![Пряма та зворотна кінематика підвісу камери](/root/sci/math-geometry/gimbal/img/gimbal-camera-targeting.svg)
*Пряма та зворотна кінематика цілевказівки. Пряма кінематика визначає глобальний промінь зору камери за кутами моторів та положенням фюзеляжу. Зворотна кінематика проєктує світовий вектор на ціль у рамку корпусу та обчислює точні уставки для моторів підвісу.*

### Пряма кінематика (Forward Kinematics)

**Вхідні дані:**
- Орієнтація носія у світовій системі координат `R_body` (отримана від [бортової інерціальної системи IMU](root:hw-sensing/gyroscope)).
- Поточні кути моторів підвісу `ψ_g` (рискання), `θ_g` (тангаж), `φ_g` (крен).

**Задача:** знайти напрямок оптичної осі камери `v_cam_world` у світових координатах.

1. Будуємо матрицю повороту підвісу відносно корпусу:
```
R_g = R_z(ψ_g) · R_y(θ_g) · R_x(φ_g)
```
2. Знаходимо повну орієнтацію камери у світі:
```
R_cam = R_body · R_g
```
3. Оптична вісь камери у власній рамці спрямована вперед уздовж осі X: `v_cam_local = [1, 0, 0]ᵀ`.
4. Вектор візування у світових координатах є першим стовпчиком матриці `R_cam`:
```
v_cam_world = R_cam · | 1 | = | R_cam[0,0] |
                      | 0 |   | R_cam[1,0] |
                      | 0 |   | R_cam[2,0] |
```

### Зворотна кінематика цілевказівки (Inverse Kinematics / Targeting)

**Вхідні дані:**
- Положення апарата у світі: `P_body = [x_b, y_b, z_b]ᵀ`.
- Положення цілі на землі: `P_target = [x_t, y_t, z_t]ᵀ`.
- Вектор зміщення шарніра підвісу відносно центру мас носія: `r_mount` (плече винесення підвісу).
- Поточна матриця орієнтації літака: `R_body`.

**Задача:** знайти кути моторів `(ψ_g, θ_g, φ_g)`, які повинен відпрацювати контролер підвісу, щоб об'єктив дивився точно на ціль, а лінія горизонту на знімку залишалася паралельною землі.

1. Враховуємо фізичне розташування підвісу на апараті (компенсація паралаксу плеча винесення):
```
P_gimbal_world = P_body + R_body · r_mount
```

2. Обчислюємо одиничний вектор напрямку лінії візування у світовій системі координат:
```
v_target_world = (P_target − P_gimbal_world) / ‖P_target − P_gimbal_world‖
```

3. Проєктуємо цей вектор у систему координат корпусу апарата через транспонування `R_bodyᵀ`:
```
v_body = R_bodyᵀ · v_target_world = [v_bx,  v_by,  v_bz]ᵀ
```

4. Знаходимо необхідний кут **рискання підвісу `ψ_g`** у площині XY корпусу за допомогою функції [atan2](root:math-geometry/atan2):
```
ψ_g = atan2(v_by, v_bx)
```

5. Знаходимо необхідний кут **тангажу підвісу `θ_g`**. Вектор нахилу розраховується через висоту `v_bz` та проєкцію на горизонтальну площину:
```
r_xy = √(v_bx² + v_by²)
θ_g = atan2(−v_bz, r_xy)
```
*(Знак мінус перед `v_bz` обумовлений авіаційним стандартом NED, де вісь Z спрямована вниз: ціль під літаком має `z_t > z_b`, отже `v_bz > 0`, а кут тангажу нахилу вниз є від'ємним).*

6. Кут **крену `φ_g`** для наведення оптичної осі встановлюється в `0`, що забезпечує вертикальне положення кадру.

## 5. Алгоритми стабілізації та керування підвісом

Під час польоту апарат зазнає вібрацій і маневрених кутових швидкостей. Контролер підвісу розв'язує задачу **інерціальної стабілізації** (*Attitude Stabilization*).

### Пряма компенсація збурень (Feedforward Control)

Якщо оператор задає фіксовану орієнтацію камери у світовому просторі `R_cam_desired` (наприклад, тримати погляд строго на північ із нахилом 30° вниз), контролер на кожному такті керування (зазвичай із частотою 500–1000 Гц) обчислює уставку для підвісу:

```
R_gimbal_cmd = R_bodyᵀ · R_cam_desired
```

З отриманої матриці `R_gimbal_cmd` витягуються цільові кути моторів за формулами зворотної тригонометрії:

```
θ_cmd = asin(−R_gimbal_cmd[2,0])
φ_cmd = atan2(R_gimbal_cmd[2,1], R_gimbal_cmd[2,2])
ψ_cmd = atan2(R_gimbal_cmd[1,0], R_gimbal_cmd[0,0])
```

Повна програмна реалізація прямої та зворотної кінематики, алгоритмів компенсації та стабілізації наведена у [бібліотеці прямої та зворотної кінематики](root:math-geometry/gimbal/proj-gimbal-kinematics.md).

### Двоконтурна архітектура зворотного зв'язку

На практиці прямої компенсації за даними IMU літака недостатньо через пружність конструкції, затримки зв'язку та люфти шарнірів. Тому безпосередньо на внутрішній платформі камери встановлюють власний високочастотний гіроскоп.

```
[Бажана орієнтація у світі R_desired]
             ↓
[Зовнішній контур: Кутовий розрахунок R_g = R_bodyᵀ · R_desired] (100–200 Гц)
             ↓ Кутова помилка e_angle
[Внутрішній контур: ПІД-регулятор швидкості за гіроскопом камери] (1000–2000 Гц)
             ↓ Керуючий струм (FOC / PWM)
[Безколекторні мотори підвісу BLDC]
```

Внутрішній контур регулює струми фаз двигунів через алгоритм векторного керування (*Field-Oriented Control*, FOC), створюючи момент, строго протилежний виміряній гіроскопом кутовій швидкості платформи. Тим самим досягається субпіксельна точність стабілізації оптичного сенсора (похибка менше 0.01°).

## 6. Порівняльний аналіз кінематичних перетворень

Підсумуємо кінематичні зв'язки в системі підвісу:

```
                        [Кути моторів (ψ, θ, φ)]
                                ⇅ (atan2 / тригонометрія)
    [Вектор на ціль v_world] ⇄ [Матриця підвісу R_g] ⇄ [Кватерніон підвісу q_g]
                                ⇅
                       [Матриця носія R_body]
                                ⇅
                       [Орієнтація камери R_cam]
```

1. **Кінематичний ланцюг** триосьового підвісу реалізує три послідовні внутрішні повороти `SO(3)` за схемою Z-Y-X: рискання `R_z(ψ)`, тангаж `R_y(θ)`, крен `R_x(φ)`.
2. **Карданів замок** виникає при тангажі `θ = ±90°`, коли осі зовнішнього та внутрішнього кілець збігаються, перетворюючи 3 незалежні ступені вільності на 2 і викликаючи ділення на нуль у зворотному перетворенні та диференціальному Якобіані.
3. Для **уникнення замка** в алгоритмах використовують одиничні кватерніони на сфері `S³` або матриці DCM, а в апаратних конструкціях — додають 4-ту надлишкову вісь стеження.
4. **Стабілізація та цілевказівка** базуються на проєкції векторів між світовою системою та рамкою корпусу через матрицю повороту апарата `R_bodyᵀ` із подальшим аналітичним розв'язанням зворотної кінематики через `atan2`.
