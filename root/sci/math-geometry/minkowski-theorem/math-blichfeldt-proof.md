# 🧮 Теорема Бліхфельдта, нерівність Мінковського та послідовні мінімуми

Геометрія чисел будується на взаємодії двох фундаментальних математичних структур: неперервної евклідової міри Лебега в просторі `ℝⁿ` та дискретної абелевої групи — просторової ґратки `L`. Центральним результатом цієї теорії є зведення дискретної комбінаторики вузлів ґратки до інтегральних об'ємів опуклих симетричних множин.

## Простір ґратки та фундаментальна комірка

Нехай `B = [b₁, b₂, …, bₙ]` — лінійно незалежний базис векторів дійсного простору `ℝⁿ`. Дискретна ґратка `L = L(B)` визначається як множина всіх цілочисельних лінійних комбінацій базисних векторів:

```
L = { x ∈ ℝⁿ : x = ∑_{i=1}ⁿ zᵢ·bᵢ,  zᵢ ∈ ℤ }
```

Фундаментальною паралелепіпедною коміркою (або фундаментальним доменом) ґратки `L` називається напіввідкритий многогранник `F₀`, натягнутий на вектори базису:

```
F₀ = { x ∈ ℝⁿ : x = ∑_{i=1}ⁿ tᵢ·bᵢ,  0 ≤ tᵢ < 1 }
```

Будь-який вектор простору `x ∈ ℝⁿ` однозначно розкладається на суму вектора ґратки `v ∈ L` та залишкової точки всередині фундаментальної комірки `y ∈ F₀`. Тобто простір `ℝⁿ` розбивається на зліченне диз'юнктне об'єднання зсувів комірки `F₀`:

```
ℝⁿ = ⋃_{v ∈ L} (F₀ + v),    де (F₀ + u) ∩ (F₀ + v) = ∅ при u ≠ v
```

Об'єм фундаментальної комірки `vol(F₀)` (у сенсі стандартної міри Лебега) є інваріантом ґратки, не залежить від вибору конкретного базису і дорівнює визначнику ґратки `det(L)`:

```
vol(F₀)
= |det(B)|            [об'єм паралелепіпеда, натягнутого на вектори базису]
= √(det(Bᵀ · B))      [інваріантний вираз через матрицю Грама]
= det(L)              [фундаментальний визначник ґратки]
```

## Теорема Бліхфельдта про згортання простору

Фундаментом сучасного доведення теорем Мінковського є теорема Ганса Бліхфельдта (1914). Вона встановлює неперервний геометричний аналог комбінаторного принципу Діріхле: якщо об'єм множини перевищує місткість однієї комірки, то при проєктуванні на фактор-простір `ℝⁿ / L` обов'язково виникне перекриття.

**Формулювання теореми Бліхфельдта.** Нехай `L ⊂ ℝⁿ` — повна ґратка, а `S ⊂ ℝⁿ` — вимірна за Лебегом множина з об'ємом `vol(S) > det(L)`. Тоді існують дві різні точки `x, y ∈ S` такі, що їхня різниця є ненульовим вектором ґратки:

```
x − y ∈ L,    x ≠ y
```

**Строге доведення.**
Розглянемо розбиття простору `ℝⁿ` на комірки `F₀ + v` для всіх `v ∈ L`. Перетнемо множину `S` із кожною коміркою, утворивши сімейство попарно неперетинних множин `S_v`:

```
S_v = S ∩ (F₀ + v),    де S = ⋃_{v ∈ L} S_v
```

Зсунемо кожну частину `S_v` на вектор `−v` назад у початкову фундаментальну комірку `F₀`:

```
S_v' = S_v − v = { s − v : s ∈ S_v } ⊆ F₀
```

Через інваріантність міри Лебега відносно паралельного переносу об'єм кожного фрагмента зберігається:

```
vol(S_v') = vol(S_v)    [інваріантність міри відносно зсуву на вектор −v]
```

Сума об'ємів усіх зсунутих фрагментів `S_v'` дорівнює повному об'єму вихідної множини `S`:

```
∑_{v ∈ L} vol(S_v')
= ∑_{v ∈ L} vol(S_v)   [підстановка рівності об'ємів зсунутих частин]
= vol(⋃_{v ∈ L} S_v)   [адитивність міри Лебега для неперетинних множин]
= vol(S)               [означення розбиття множини S на фрагменти S_v]
```

Введемо характеристичну функцію `χ_S(w)`, яка дорівнює `1`, якщо `w ∈ S`, і `0` в іншому разі. Для кожної точки `t ∈ F₀` визначимо функцію кратності покриття `N(t)`:

```
N(t) = ∑_{v ∈ L} χ_S(t + v)
```

Інтегруючи функцію `N(t)` по фундаментальній комірці `F₀`, отримуємо:

```
∫_{F₀} N(t) dt
= ∫_{F₀} (∑_{v ∈ L} χ_S(t + v)) dt   [підстановка означення функції N(t)]
= ∑_{v ∈ L} ∫_{F₀} χ_S(t + v) dt     [теорема Леві про почленне інтегрування]
= ∑_{v ∈ L} vol(S_v)                 [інтеграл від характеристичної функції]
= vol(S)                             [повний об'єм вихідної множини]
```

За умовою теореми `vol(S) > det(L) = vol(F₀)`. Припустимо від супротивного, що для майже всіх точок `t ∈ F₀` виконується `N(t) ≤ 1`. Тоді:

```
∫_{F₀} N(t) dt ≤ ∫_{F₀} 1 dt = vol(F₀) = det(L)
```

Це суперечить рівності `∫_{F₀} N(t) dt = vol(S) > det(L)`. Отже, множина точок `t ∈ F₀`, для яких `N(t) ≥ 2`, має додатну міру Лебега.

Зокрема, існує точка `t₀ ∈ F₀`, для якої `N(t₀) ≥ 2`. Це означає існування щонайменше двох різних векторів ґратки `v₁, v₂ ∈ L` (`v₁ ≠ v₂`) таких, що:

```
x = t₀ + v₁ ∈ S
y = t₀ + v₂ ∈ S
```

Обчислимо різницю векторів `x` та `y`:

```
x − y
= (t₀ + v₁) − (t₀ + v₂)   [підстановка координат через базову точку t₀]
= v₁ − v₂                 [скорочення спільної точки t₀]
```

Оскільки `v₁, v₂ ∈ L` і `v₁ ≠ v₂`, а ґратка замкнена відносно віднімання, отримуємо ненульовий вектор ґратки `u = v₁ − v₂ ∈ L \ {0}`. Теорему Бліхфельдта доведено.

## Виведення першої теореми Мінковського

**Формулювання.** Нехай `L ⊂ ℝⁿ` — повна ґратка з визначником `det(L)`. Нехай `K ⊂ ℝⁿ` — опукла центрально-симетрична множина (`x ∈ K ⇒ −x ∈ K`), об'єм якої задовольняє нерівність:

```
vol(K) > 2ⁿ · det(L)
```

Тоді `K` містить щонайменше один ненульовий вектор ґратки `v ∈ K ∩ (L \ {0})`.

**Доведення через згортання Бліхфельдта.**
Стиснемо множину `K` гомотетією з коефіцієнтом `½` відносно початку координат, утворивши нову множину `S`:

```
S = ½K = { ½z : z ∈ K }
```

Обчислимо об'єм масштабованої множини `S` у просторі розмірності `n`:

```
vol(S)
= vol(½K)              [означення стиснутої множини]
= (½)ⁿ · vol(K)        [властивість міри Лебега при масштабуванні в ℝⁿ]
= 2⁻ⁿ · vol(K)         [перетворення степеня числа 2]
> 2⁻ⁿ · (2ⁿ · det(L))  [підстановка умови vol(K) > 2ⁿ·det(L)]
= det(L)               [скорочення взаємно обернених множників]
```

Оскільки `vol(S) > det(L)`, за теоремою Бліхфельдта існують дві різні точки `x, y ∈ S = ½K` такі, що:

```
x − y = v ∈ L \ {0}
```

Згадаємо означення множини `S = ½K`:
1. `x ∈ ½K ⇒ 2x ∈ K`.
2. `y ∈ ½K ⇒ 2y ∈ K`.

Оскільки множина `K` є центрально-симетричною відносно початку координат (`z ∈ K ⇒ −z ∈ K`):

```
2y ∈ K ⇒ −2y ∈ K
```

Оскільки множина `K` є опуклою, відрізок між будь-якими двома її точками повністю належить `K`. Зокрема, середина відрізка між точками `2x` та `−2y` належить `K`:

```
v
= x − y                        [різниця точок зі стиснутої множини S]
= ½(2x) + ½(−2y)               [подання у вигляді опуклої комбінації з вагами ½ та ½]
∈ K                            [належність опуклій множині K]
```

Отже, вектор `v = x − y` одночасно задовольняє дві умови: `v ∈ L \ {0}` та `v ∈ K`. Теорему Мінковського доведено.

## Граничний перехід для компактних тіл

Якщо множина `K` є компактною (замкненою та обмеженою), строгу нерівність можна послабити до нестрогої: `vol(K) ≥ 2ⁿ · det(L)`.

Для доведення розглянемо послідовність роздутих тіл `K_m` для кожного `m ≥ 1`:

```
K_m = (1 + 1/m) · K
```

Для кожного `m` об'єм збільшеного тіла строго перевищує поріг:

```
vol(K_m) = (1 + 1/m)ⁿ · vol(K) > 2ⁿ · det(L)
```

За вже доведеною теоремою Мінковського для відкритих/строгих тіл, кожне тіло `K_m` містить ненульову точку ґратки:

```
v_m ∈ K_m ∩ (L \ {0})
```

Оскільки `K_m ⊆ K₁ = 2K` для всіх `m ≥ 1`, усі точки `v_m` лежать усередині компактної множини `K₁`. Перетин дискретної ґратки `L` із компактною множиною `K₁` є скінченною множиною точок:

```
|K₁ ∩ L| < ∞
```

Нескінченна послідовність векторів `{v_m}_{m=1}^∞` набуває значень зі скінченної множини. За принципом Діріхле існує фіксований ненульовий вектор `v* ∈ L \ {0}`, який повторюється нескінченну кількість разів. Оскільки `K` є замкненою множиною, а `K = ⋂_{m=1}^∞ K_m`, граничний вектор належить самому тілу:

```
v* ∈ K ∩ (L \ {0})
```

## Верхня оцінка довжини найкоротшого вектора

Застосуємо теорему Мінковського до евклідової кулі `Bₙ(r) = { x ∈ ℝⁿ : ‖x‖₂ ≤ r }`. Куля є опуклою, замкненою та центрально-симетричною множиною. Її `n`-вимірний об'єм виражається через гамма-функцію Ейлера:

```
vol(Bₙ(r)) = rⁿ · Vₙ,    де Vₙ = π^(n/2) / Γ(n/2 + 1)
```

Згідно з теоремою Мінковського, куля `Bₙ(r)` гарантовано містить ненульовий вектор ґратки `v ∈ L \ {0}`, якщо її об'єм не менший за `2ⁿ · det(L)`:

```
rⁿ · Vₙ ≥ 2ⁿ · det(L)
```

Виразимо критичний радіус `r`:

```
r ≥ 2 · (det(L) / Vₙ)^(1/n)
```

Звідси довжина найкоротшого ненульового вектора ґратки `λ₁(L) = min_{v ∈ L \ {0}} ‖v‖₂` задовольняє фундаментальну оцінку:

```
λ₁(L) ≤ 2 · (det(L) / Vₙ)^(1/n)
```

Застосуємо формулу Стірлінга для гамма-функції `Γ(k + 1) ≈ √(2πk) · (k/e)ᵏ` при `k = n/2`:

```
Vₙ^(1/n)
= (π^(n/2) / (√(πn) · (n / (2e))^(n/2)))^(1/n)   [асимптотика за формулою Стірлінга]
≈ √(2πe / n)                                      [спрощення показників степеня]
```

Підставляючи це значення в оцінку для `λ₁(L)`:

```
λ₁(L)
≤ 2 · (det(L) / √(2πe / nⁿ))^(1/n)   [підстановка асимптотики об'єму одиничної кулі]
≤ √(2n / (πe)) · (det(L))^(1/n)      [винесення констант з-під кореня]
≤ √n · (det(L))^(1/n)                [верхня практична межа Мінковського]
```

Ця величина `R_M = √n · (det(L))^(1/n)` називається **радіусом Мінковського** і служить головним орієнтиром якості редукції базисів у сучасних алгоритмах LLL та BKZ.

## Друга теорема Мінковського: послідовні мінімуми

Перша теорема Мінковського дає оцінку лише для одного, першого найкоротшого вектора. Проте ґратка має повний ранг `n` і визначається набором із `n` лінійно незалежних напрямків.

**Означення послідовних мінімумів.** Нехай `K ⊂ ℝⁿ` — центрально-симетричне опукле тіло ненульового об'єму. `i`-тим послідовним мінімумом `λᵢ = λᵢ(L, K)` (для `1 ≤ i ≤ n`) називається точна нижня межа коефіцієнтів розтягування `λ > 0`, за яких множина `λK` містить щонайменше `i` лінійно незалежних векторів ґратки:

```
λᵢ(L, K) = inf { λ > 0 : dim(span(λK ∩ L)) ≥ i }
```

За побудовою послідовні мінімуми утворюють монотонний ланцюжок:

```
0 < λ₁ ≤ λ₂ ≤ … ≤ λₙ < ∞
```

**Формулювання другої теореми Мінковського.** Для довільного центрально-симетричного опуклого тіла `K` та повної ґратки `L` виконується двостороння нерівність:

```
(2ⁿ / n!) · det(L) ≤ (∏_{i=1}ⁿ λᵢ) · vol(K) ≤ 2ⁿ · det(L)
```

**Виведення верхньої межі.**
Нехай `v₁, v₂, …, vₙ ∈ L` — лінійно незалежні вектори ґратки, що досягають послідовних мінімумів: `vᵢ ∈ λᵢK`. Побудуємо ортогональний базис Грама–Шмідта `v₁*, v₂*, …, vₙ*` для простору, натягнутого на ці вектори.

Введемо лінійне стиснення простору `T : ℝⁿ → ℝⁿ`, яке масштабує кожну координату в напрямку `vᵢ*` на коефіцієнт `λᵢ/2`:

```
T(x) = ∑_{i=1}ⁿ (λᵢ/2) · (⟨x, vᵢ*⟩ / ‖vᵢ*‖²) · vᵢ*
```

Визначник лінійного оператора `T` дорівнює добутку діагональних коефіцієнтів:

```
det(T) = 2⁻ⁿ · ∏_{i=1}ⁿ λᵢ
```

Розглянемо образ тіла `K` під дією оператора `T`: `K' = T(K)`. Об'єм деформованого тіла дорівнює:

```
vol(K') = det(T) · vol(K) = 2⁻ⁿ · (∏_{i=1}ⁿ λᵢ) · vol(K)
```

Аналіз взаємного розташування точок ґратки всередині деформованого тіла `K'` показує, що різниця будь-яких двох різних точок `x, y ∈ K'` не може породжувати новий вектор ґратки меншої довжини без порушення мінімальності коефіцієнтів `λᵢ`. За принципом Бліхфельдта тіло `K'` не може накривати більше ніж одну точку в кожній фундаментальній комірці, що вимагає:

```
vol(K') ≤ det(L)
```

Підставляючи вираз для `vol(K')`:

```
2⁻ⁿ · (∏_{i=1}ⁿ λᵢ) · vol(K) ≤ det(L)
```

Множачи обидві частини на `2ⁿ`, отримуємо фундаментальну верхню оцінку другої теореми Мінковського:

```
(λ₁ · λ₂ · … · λₙ) · vol(K) ≤ 2ⁿ · det(L)
```

**Виведення нижньої межі через крос-політоп.**
Для доведення лівої частини нерівності розглянемо опуклу оболонку нормованих векторів `± vᵢ / λᵢ`:

```
P = conv({ ± v₁/λ₁, ± v₂/λ₂, …, ± vₙ/λₙ })
```

Оскільки `vᵢ ∈ λᵢK`, вектор `vᵢ/λᵢ` належить вихідному тілу `K`. Через опуклість та центральну симетрію `K` увесь багатогранник `P` (який є `n`-вимірним крос-політопом) лежить усередині `K`:

```
P ⊆ K ⇒ vol(P) ≤ vol(K)
```

Об'єм `n`-вимірного крос-політопа `P` обчислюється через визначник векторів `vᵢ/λᵢ`:

```
vol(P)
= (2ⁿ / n!) · |det(v₁/λ₁, v₂/λ₂, …, vₙ/λₙ)|   [формула об'єму крос-політопа в ℝⁿ]
= (2ⁿ / n!) · (1 / ∏_{i=1}ⁿ λᵢ) · |det(v₁, …, vₙ)| [винесення скалярних множників]
≥ (2ⁿ / n!) · (1 / ∏_{i=1}ⁿ λᵢ) · det(L)          [бо матриця [v₁…vₙ] породжує підґратку в L]
```

Оскільки `vol(P) ≤ vol(K)`:

```
(2ⁿ / n!) · (det(L) / ∏_{i=1}ⁿ λᵢ) ≤ vol(K)
```

Множачи на добуток `∏_{i=1}ⁿ λᵢ`, отримуємо строгу нижню межу:

```
(∏_{i=1}ⁿ λᵢ) · vol(K) ≥ (2ⁿ / n!) · det(L)
```

## Теорема Мінковського про систему лінійних форм

Узагальненням геометричної теореми на довільні лінійні функціонали є теорема про систему лінійних форм.

**Формулювання.** Нехай задано `n` дійсних лінійних форм від `n` змінних:

```
lᵢ(x) = ∑_{j=1}ⁿ c_{ij} · xⱼ,    де C = (c_{ij}) ∈ ℝⁿˣⁿ,  det(C) = Δ ≠ 0
```

Нехай `c₁, c₂, …, cₙ` — додатні дійсні константи, добуток яких задовольняє умову:

```
c₁ · c₂ · … · cₙ ≥ |Δ|
```

Тоді існує ненульовий цілочисельний вектор `z ∈ ℤⁿ \ {0}` такий, що:

```
|l₁(z)| ≤ c₁
|l₂(z)| < c₂
…
|lₙ(z)| < cₙ
```

**Доведення.** Задамо множину `K ⊂ ℝⁿ` як паралелепіпед у просторі змінних `x`:

```
K = { x ∈ ℝⁿ : |l₁(x)| ≤ c₁,  |lᵢ(x)| < cᵢ (2 ≤ i ≤ n) }
```

Зробимо лінійну заміну змінних `y = C · x`. При цьому відображенні множина `K` переходить у прямокутний брус `Y ⊂ ℝⁿ`:

```
Y = { y ∈ ℝⁿ : |y₁| ≤ c₁,  |yᵢ| < cᵢ (2 ≤ i ≤ n) }
```

Об'єм бруса `Y` дорівнює `vol(Y) = 2ⁿ · c₁ · c₂ · … · cₙ`. Зв'язок об'ємів при лінійному перетворенні виражається через модуль якобіана (визначника матриці `C`):

```
vol(K)
= vol(Y) / |det(C)|             [зміна міри при неперервному лінійному відображенні]
= (2ⁿ · c₁ · c₂ · … · cₙ) / |Δ| [підстановка об'єму бруса Y та визначника Δ]
≥ (2ⁿ · |Δ|) / |Δ| = 2ⁿ         [підстановка умови c₁…cₙ ≥ |Δ|]
= 2ⁿ · det(ℤⁿ)                  [оскільки визначник стандартної ґратки ℤⁿ дорівнює 1]
```

Оскільки тіло `K` опукле й центрально-симетричне, за теоремою Мінковського воно містить ненульову цілу точку `z ∈ ℤⁿ \ {0}`.

## Двоїсті ґратки та теореми переносу

Нехай `L ⊂ ℝⁿ` — повна ґратка. **Двоїстою (або реципрокною) ґраткою** `L*` називається множина векторів простору, скалярний добуток яких з усіма векторами вихідної ґратки є цілим числом:

```
L* = { y ∈ ℝⁿ : ∀ x ∈ L,  ⟨x, y⟩ ∈ ℤ }
```

Якщо `B` — матриця базису ґратки `L`, то базисом двоїстої ґратки є `B* = (B⁻¹)ᵀ = (Bᵀ)⁻¹`. Визначник двоїстої ґратки дорівнює оберненому визначнику:

```
det(L*) = 1 / det(L)
```

**Теорема переносу (Transference Theorem).** Послідовні мінімуми ґратки `L` та її двоїстої ґратки `L*` пов'язані фундаментальною нерівністю:

```
1 ≤ λ₁(L) · λₙ(L*) ≤ n
```

**Доведення нижньої межі `1 ≤ λ₁(L) · λₙ(L*)`.**
Нехай `v ∈ L \ {0}` — вектор першого мінімуму вихідної ґратки (`‖v‖ = λ₁(L)`). Нехай `w ∈ L* \ {0}` — ненульовий вектор двоїстої ґратки такий, що `⟨v, w⟩ ≠ 0`. За означенням двоїстої ґратки `⟨v, w⟩ ∈ ℤ`, а оскільки добуток ненульовий:

```
|⟨v, w⟩| ≥ 1    [найменший модуль ненульового цілого числа]
```

За нерівністю Коші–Буняковського–Шварца:

```
‖v‖ · ‖w‖ ≥ |⟨v, w⟩| ≥ 1
```

Оскільки довжина будь-якого вектора `w` з набору базисних векторів двоїстої ґратки не перевищує `λₙ(L*)`, отримуємо:

```
λ₁(L) · λₙ(L*) ≥ 1
```

Верхня межа випливає з другої теореми Мінковського, застосованої одночасно до ґратки `L` та двоїстої ґратки `L*`.

## Стала Ерміта та точні геометричні межі

Оцінка довжини найкоротшого вектора через визначник ґратки формулюється у вигляді нормованого коефіцієнта — **сталої Ерміта** `γₙ`:

```
γₙ = sup_{L ⊂ ℝⁿ} (λ₁(L)² / (det(L))^(2/n))
```

Теорема Мінковського гарантує загальну верхню оцінку для будь-якої розмірності:

```
γₙ
≤ 4 / Vₙ^(2/n)                 [оцінка Мінковського для евклідової кулі]
≈ (2n / (πe)) · (1 + o(1))     [асимптотична поведінка при n → ∞]
```

Для малих розмірностей `n` точні значення сталої Ерміта відомі завдяки відкриттю найщільніших ґраткових упакувань:

```
n = 1: γ₁ = 1                  [одновимірна цілочисельна ґратка ℤ]
n = 2: γ₂ = 2 / √3 ≈ 1.1547    [гексагональна ґратка A₂]
n = 3: γ₃ = 2^(1/3) ≈ 1.2599   [гранецентрована кубічна ґратка A₃ (FCC)]
n = 4: γ₄ = √2 ≈ 1.4142        [ґратка D₄]
n = 8: γ₈ = 2.0000             [виняткова коренева ґратка E₈]
n = 24: γ₂₄ = 4.0000           [ґратка Ліча Λ₂₄]
```

Ці результати демонструють, що межа Мінковського `R_M` не є штучною теоретичною конструкцією, а відображає фундаментальну геометрію щільного пакування куль у просторах довільної розмірності.

## Зв'язок оцінок Мінковського з алгоритмами редукції LLL та BKZ

Алгоритм LLL (1982) є першим поліноміальним методом наближеного пошуку вектора Мінковського. Якщо `b₁, b₂, …, bₙ` — LLL-редукований базис ґратки `L` з параметром `δ = 3/4`, то для першого базисного вектора `b₁` гарантуються строгі оцінки:

```
‖b₁‖ ≤ 2^((n-1)/4) · (det(L))^(1/n)
‖b₁‖ ≤ 2^((n-1)/2) · λ₁(L)
```

Порівняємо це з теоретичною межею Мінковського:
1. Теорема Мінковського гарантує екзистенційне існування вектора з нормою `λ₁(L) ≤ √n · (det(L))^(1/n)`.
2. Алгоритм LLL знаходить ненульовий вектор за час `O(n⁶ · log³(B))`, але платить за поліноміальну швидкість експоненційним фактором наближення `2^((n-1)/4)`.
3. Блокова редукція BKZ інтерполює між цими двома полюсами: при розмірі блоку `k` фактор наближення зменшується до `k^(n/(2k))`, проте час обчислення зростає як `2^(O(k))`.

## Застосування 1: Теорема Діріхле про одночасні діофантові наближення

Класична теорема Діріхле стверджує, що для будь-якого набору з `n` дійсних чисел `α₁, α₂, …, αₙ` та цілого числа `Q > 1` існує цілий знаменник `1 ≤ q ≤ Q` та цілі чисельники `p₁, …, pₙ ∈ ℤ`, для яких:

```
|q·αᵢ − pᵢ| ≤ Q^(−1/n),    для всіх 1 ≤ i ≤ n
```

**Доведення через теорему Мінковського.**
Розглянемо простір `ℝⁿ⁺¹` зі змінними `(x₁, …, xₙ, y)`. Задамо дискретну ґратку `L ⊂ ℝⁿ⁺¹` матрицею базису:

```
B =
[ 1  0 … 0  −α₁ ]
[ 0  1 … 0  −α₂ ]
[ ⋮  ⋮ ⋱ ⋮   ⋮  ]
[ 0  0 … 1  −αₙ ]
[ 0  0 … 0   1  ]
```

Оскільки матриця `B` є верхньотрикутною з одиницями на головній діагоналі:

```
det(L) = |det(B)| = 1
```

Будь-яка точка ґратки `v = B · (p₁, …, pₙ, q)ᵀ` має координати:

```
v = (p₁ − q·α₁, p₂ − q·α₂, …, pₙ − q·αₙ, q)ᵀ,    де pᵢ, q ∈ ℤ
```

Задамо опукле центрально-симетричне компактне тіло `K ⊂ ℝⁿ⁺¹` як паралелепіпед, визначений системою нерівностей:

```
K = { (z₁, …, zₙ, y) ∈ ℝⁿ⁺¹ : |zᵢ| ≤ Q^(−1/n),  |y| ≤ Q + 1/2 }
```

Обчислимо об'єм цього прямокутного паралелепіпеда:

```
vol(K)
= (∏_{i=1}ⁿ (2 · Q^(−1/n))) · (2 · (Q + 1/2))   [добуток довжин ребер паралелепіпеда]
= (2ⁿ · Q⁻¹) · (2Q + 1)                         [спрощення добутку степенів]
= 2ⁿ⁺¹ · (1 + 1/(2Q))                           [винесення спільного множника]
> 2ⁿ⁺¹ · 1 = 2ⁿ⁺¹ · det(L)                      [оскільки Q ≥ 1 та det(L) = 1]
```

За теоремою Мінковського існує ненульовий вектор ґратки `v ∈ K ∩ (L \ {0})`. Це означає існування цілих чисел `p₁, …, pₙ, q ∈ ℤ` (не всі нулі) таких, що:

```
|pᵢ − q·αᵢ| ≤ Q^(−1/n)    для всіх 1 ≤ i ≤ n
|q| ≤ Q
```

Якби `q = 0`, то `|pᵢ| ≤ Q^(−1/n) < 1` (бо `Q > 1`), що змусило б усі `pᵢ = 0`, а це суперечить ненульовитості точки `v ≠ 0`. Отже, `q ≠ 0`. Якщо `q < 0`, змінимо знак усього вектора на протилежний `(pᵢ, q) ↦ (−pᵢ, −q)` (тіло `K` центрально-симетричне). Отримуємо шуканий розв'язок із `1 ≤ q ≤ Q`.

## Застосування 2: Теорема Ферма про суму двох квадратів

Теорема Ферма стверджує: кожне просте число `p ≡ 1 (mod 4)` подається у вигляді суми двох цілих квадратів: `p = a² + b²`.

**Доведення через геометрію ґратки в ℝ².**
Оскільки `p ≡ 1 (mod 4)`, число `−1` є квадратичним лишком за модулем `p`. Існує ціле число `u ∈ ℤ` таке, що:

```
u² ≡ −1 (mod p)
```

Задамо ґратку `L ⊂ ℝ²`, що складається з пар `(x, y) ∈ ℤ²`, які задовольняють модулярне рівняння:

```
L = { (x, y) ∈ ℤ² : x ≡ u·y (mod p) }
```

Базис цієї ґратки утворюють вектори `b₁ = (u, 1)` та `b₂ = (p, 0)`. Визначник ґратки дорівнює:

```
det(L) = |det([[u, p], [1, 0]])| = |0 − p| = p
```

Розглянемо відкритий евклідів круг `K ⊂ ℝ²` радіуса `r = √(2p)`:

```
K = { (x, y) ∈ ℝ² : x² + y² < 2p }
```

Круг `K` є опуклим і центрально-симетричним. Його площа дорівнює:

```
vol(K) = π · r² = π · 2p = 2π · p > 4p = 2² · det(L)    [оскільки π ≈ 3.14159 > 2]
```

За першою теоремою Мінковського існує ненульовий вектор ґратки `(a, b) ∈ L \ {(0,0)}`, що належить кругу `K`.

Для точки `(a, b) ∈ L` виконується `a ≡ u·b (mod p)`. Обчислимо величину `a² + b²`:

```
a² + b²
≡ (u·b)² + b² (mod p)   [підстановка порівняння a ≡ u·b]
≡ b² · (u² + 1) (mod p) [винесення спільного множника b²]
≡ b² · 0 ≡ 0 (mod p)    [оскільки u² ≡ −1 (mod p)]
```

Отже, ціле число `a² + b²` ділиться націло на `p`. З іншого боку, оскільки `(a, b) ∈ K` і `(a, b) ≠ (0, 0)`:

```
0 < a² + b² < 2p
```

Єдиним цілим кратним числа `p` у відкритому інтервалі `(0, 2p)` є саме число `p`. Звідси:

```
a² + b² = p
```

## Застосування 3: Теорема Лагранжа про чотири квадрати

Теорема Лагранжа стверджує, що кожне натуральне число подається у вигляді суми чотирьох цілих квадратів: `m = x₁² + x₂² + x₃² + x₄²`. Завдяки тотожності Ейлера для добутку сум чотирьох квадратів достатньо довести це твердження для довільного непарного простого числа `p`.

**Побудова ґратки в ℝ⁴.**
Для будь-якого непарного простого `p` існують цілі числа `u, v ∈ ℤ` такі, що:

```
u² + v² + 1 ≡ 0 (mod p)
```

Задамо дискретну чотиривимірну ґратку `L ⊂ ℝ⁴`, складену з цілих векторів `(x₁, x₂, x₃, x₄) ∈ ℤ⁴`, які задовольняють пару лінійних конгруенцій:

```
x₁ ≡ u·x₃ + v·x₄ (mod p)
x₂ ≡ v·x₃ − u·x₄ (mod p)
```

Визначник цієї ґратки обчислюється через об'єм фактор-простору `ℤ⁴ / L` і дорівнює:

```
det(L) = p²
```

Розглянемо чотиривимірну евклідову кулю `B₄(r) ⊂ ℝ⁴` радіуса `r = √(2p)`:

```
B₄(r) = { (x₁, x₂, x₃, x₄) ∈ ℝ⁴ : x₁² + x₂² + x₃² + x₄² < 2p }
```

Об'єм 4-вимірної кулі радіуса `r` виражається формулою:

```
vol(B₄(r))
= (π² / 2) · r⁴                 [формула об'єму чотиривимірної кулі]
= (π² / 2) · (2p)²              [підстановка радіуса r = √(2p)]
= 2π² · p²                      [спрощення коефіцієнтів]
≈ 19.7392 · p²                  [чисельне значення з π ≈ 3.14159]
> 16 · p² = 2⁴ · det(L)         [оскільки 19.74 > 16 та det(L) = p²]
```

Оскільки `vol(B₄(r)) > 2⁴ · det(L)`, за теоремою Мінковського існує ненульовий вектор ґратки `(a₁, a₂, a₃, a₄) ∈ L \ {0}`, що належить кулі `B₄(r)`.

Обчислимо суму квадратів координат цього вектора за модулем `p`:

```
a₁² + a₂² + a₃² + a₄²
≡ (u·a₃ + v·a₄)² + (v·a₃ − u·a₄)² + a₃² + a₄² (mod p)   [підстановка конгруенцій]
≡ (u²a₃² + 2uva₃a₄ + v²a₄²) + (v²a₃² − 2uva₃a₄ + u²a₄²) + a₃² + a₄² (mod p) [розкриття дужок]
≡ (u² + v² + 1)·a₃² + (u² + v² + 1)·a₄² (mod p)         [групування доданків]
≡ 0·a₃² + 0·a₄² ≡ 0 (mod p)                             [оскільки u² + v² + 1 ≡ 0 (mod p)]
```

Отже, ціла сума квадратів `a₁² + a₂² + a₃² + a₄²` ділиться на `p`. Оскільки вектор належить відкритій кулі `B₄(r)` і є ненульовим:

```
0 < a₁² + a₂² + a₃² + a₄² < 2p
```

Єдиним цілим кратним `p` у цьому проміжку є число `p`. Отримуємо точний розклад:

```
a₁² + a₂² + a₃² + a₄² = p
```

Ці класичні застосування наочно демонструють математичну міць підходу Мінковського: геометрія об'ємів дозволяє уніфіковано розв'язувати найскладніші діофантові задачі без жодних спеціальних алгебраїчних трюків.
