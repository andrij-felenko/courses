# 🧮 Математичний апарат оператора монодромії та показників Флоке

Математичне обґрунтування теорії Флоке спирається на лінійну алгебру матричних диференціальних рівнянь, теорію операторних експонент та спектральний аналіз неавтономних динамічних систем із періодичними коефіцієнтами. Нижче наведено строге виведення фундаментальних теорем, що визначають структуру розв'язків, властивості оператора монодромії та критерії стійкості періодичного руху.

## 1. Постановка задачі та матричне диференціальне рівняння

Розглянемо векторне лінійне неавтономне диференціальне рівняння в `n`-вимірному фазовому просторі `ℝⁿ`:

```
dx/dt = A(t) · x
```

де `x(t) ∈ ℝⁿ` — вектор стану системи, а `A(t)` — неперервна матрична функція розміру `n × n`, яка є строго періодичною з мінімальним періодом `T > 0`:

```
A(t + T) = A(t)  [для всіх t ∈ ℝ]
```

Нехай `Φ(t)` — **фундаментальна матриця розв'язків** цієї системи. За означенням, стовпчики матриці `Φ(t) = [x₁(t), x₂(t), ..., xₙ(t)]` утворюють базис із `n` лінійно незалежних розв'язків. Матрична функція `Φ(t)` задовольняє матричне диференціальне рівняння:

```
dΦ/dt = A(t) · Φ(t)
```

з початковою умовою `Φ(0) = I`, де `I` — одинична матриця розміру `n × n`.

Оскільки розв'язок задачі Коші для лінійної системи з неперервними коефіцієнтами існує й є єдиним узагалі на всій осі часу, фундаментальна матриця `Φ(t)` є невиродженою (`det Φ(t) ≠ 0`) для кожного `t ∈ ℝ`.

## 2. Оператор монодромії та теорема існування

Дослідимо поведінку фундаментальної матриці `Φ(t)` при зсуві аргументу на один період `T`. Розглянемо нову матричну функцію `Ψ(t) = Φ(t + T)`.

Знайдемо похідну `Ψ(t)` по часу `t`:

```
dΨ(t)/dt = dΦ(t + T)/dt
= A(t + T) · Φ(t + T)     [за правилом диференціювання dΦ/dt = A(t) · Φ(t)]
= A(t) · Ψ(t)             [унаслідок періодичності A(t + T) = A(t)]
```

Отже, матрична функція `Ψ(t) = Φ(t + T)` задовольняє те саме матричне диференціальне рівняння `dΨ/dt = A(t) · Ψ(t)`.

Оскільки `Φ(t)` є фундаментальною матрицею, будь-який інший розв'язок того самого матричного рівняння можна подати у формі добутку `Φ(t)` на деяку постійну невироджену матрицю `M`:

```
Φ(t + T) = Φ(t) · M
```

Покладемо у цьому співвідношенні `t = 0`:

```
Φ(T) = Φ(0) · M
= I · M                   [унаслідок початкової умови Φ(0) = I]
= M
```

Таким чином, матриця `M = Φ(T)` є оцінкою фундаментальної матриці наприкінці першого періоду. Ця матриця носить назву **матриці монодромії** (англ. *monodromy matrix*).

Оскільки `det Φ(t) ≠ 0` для всіх `t`, матриця монодромії є строго невиродженою:

```
det M = det Φ(T) ≠ 0
```

## 3. Матричний логарифм та декомпозиція Флоке

Оскільки матриця монодромії `M` є невиродженою (`det M ≠ 0`), у комплексному матричному просторі `ℂⁿ×ⁿ` завжди існує принаймні одна невироджена матриця `R` (взагалі кажучи, комплексна), така що:

```
e^(R·T) = M
```

Матриця `R` називається **показниковою матрицею Флоке** або матричним логарифмом: `R = (1/T) · ln M`. Існування комплексного матричного логарифма для будь-якої невиродженої матриці гарантується спектральною теоремою та функціональним калькулюсом Жордана.

Сформулюємо та доведемо головну теорему Флоке про структуру фундаментальної матриці.

### Теорема Флоке
Будь-яку фундаментальну матрицю розв'язків `Φ(t)` періодичної системи `dx/dt = A(t)·x` можна подати у вигляді добутку:

```
Φ(t) = P(t) · e^(R·t)
```

де `P(t)` — невироджена періодична матрична функція з періодом `T` (`P(t + T) = P(t)` для всіх `t`), а `R` — постійна матриця.

### Доведення теореми
Визначимо матричну функцію `P(t)` через співвідношення:

```
P(t) = Φ(t) · e^(-R·t)
```

Перевіримо періодичність функції `P(t)`, обчисливши значення `P(t + T)`:

```
P(t + T) = Φ(t + T) · e^(-R·(t + T))
= Φ(t) · M · e^(-R·T - R·t)        [бо Φ(t + T) = Φ(t) · M]
= Φ(t) · e^(R·T) · e^(-R·T) · e^(-R·t)  [заступили M = e^(R·T)]
= Φ(t) · I · e^(-R·t)             [бо e^(R·T) · e^(-R·T) = I]
= Φ(t) · e^(-R·t)
= P(t)                            [за початковим означенням P(t)]
```

Отже, `P(t + T) = P(t)` для всіх `t ∈ ℝ`. Крім того, при `t = 0`:

```
P(0) = Φ(0) · e^(0) = I · I = I
```

Теорему доведено повністю.

## 4. Перетворення Шура та конструктивне побудування показникової матриці

Для конструктивного обчислення матричного логарифма `R = (1/T) · ln M` скористаємося унітарним перетворенням Шура над комплексною матрицею монодромії `M`:

```
M = Q · U · Qᴴ
```

де `Q` — унітарна матриця (`Qᴴ · Q = I`), а `U` — верхня трикутна матриця, на головній діагоналі якої стоять власні значення (мультиплікатори Флоке) `λ₁, λ₂, ..., λₙ`:

```
U = [ λ₁  u₁₂  u₁₃ ... u₁ₙ ]
    [  0  λ₂   u₂₃ ... u₂ₙ ]
    [  0   0   λ₃  ... u₃ₙ ]
    [  0   0    0  ... λₙ  ]
```

Логарифм трикутної матриці `ln U` обчислюється через діагональні логарифми `ln λ_i` та послідовне розв'язання трикутних матричних рівнянь для недіагональних елементів. Тоді показникова матриця Флоке `R` визначається тотожністю:

```
R = (1 / T) · Q · (ln U) · Qᴴ
```

Цей розклад гарантує, що власні значення матриці `R` дорівнюють показникам Флоке `μ_i = (1/T) · ln λ_i`.

## 5. Формула Ліувілля — Остроградського для визначника монодромії

Щоб виразити визначник матриці монодромії через коефіцієнти початкової системи, використаємо класичну формулу Ліувілля — Остроградського для скалярного визначника фундаментальної матриці `W(t) = det Φ(t)` (вроньскіана):

```
dW/dt = tr(A(t)) · W(t)
```

Проінтегруємо це диференціальне рівняння з відокремлюваними змінними від `t = 0` до `t = T`:

```
dW / W = tr(A(t)) · dt
ln(W(T)) - ln(W(0)) = ∫₀ᵀ tr(A(s)) · ds
ln(det Φ(T)) - ln(det I) = ∫₀ᵀ tr(A(s)) · ds
ln(det M) - 0 = ∫₀ᵀ tr(A(s)) · ds
det M = exp( ∫₀ᵀ tr(A(s)) · ds )
```

Ця формула має вирішальне значення: **визначник матриці монодромії дорівнює експоненті від інтеграла слідів коефіцієнтної матриці за один період**.

Оскільки визначник матриці дорівнює добутку її власних значень, а визначник матричної експоненти дорівнює експоненті від сліду покажчика `det e^(R·T) = exp(tr R · T)`, маємо алгебраїчний зв'язок між мультиплікаторами `λ_i` та показниками `μ_i`:

```
∏ λ_i = det M = exp( ∑ μ_i · T ) = exp( ∫₀ᵀ tr(A(s)) ds )
```

Звідси випливає фундаментальний наслідок для консервативних та гамільтонових систем: якщо слід матриці `A(t)` дорівнює нулю для всіх `t` (`tr A(t) = 0`), то:

```
det M = exp(0) = 1
```

тобто матриця монодромії збереже фазовий об'єм (є спеціальною матрицею з одиничним визначником).

## 6. Жорданова нормальна форма та випадки кратності

Якщо матриця монодромії `M` має `n` різних власних значень `λ₁ ≠ λ₂ ≠ ... ≠ λₙ`, вона діагоналізується, й усі розв'язки системи суворо розкладаються на незалежні модулі `x_i(t) = exp(μ_i · t) · p_i(t)`.

Проте коли матриця `M` має кратні власні значення з виродженою геометричною кратністю, у її жордановій нормальній формі `J_M = S⁻¹ · M · S` виникають нетривіальні жорданові блоки розміру `k × k`:

```
J_k = [ λ  1  0 ... 0 ]
      [ 0  λ  1 ... 0 ]
      [ 0  0  λ ... 1 ]
      [ 0  0  0 ... λ ]
```

У цьому випадку для показникової матриці `R = (1/T) ln M` виникають приєднані власні вектори, а розв'язки системи містять поліноміально-експоненціальні члени вигляду:

```
x(t) = e^(μ·t) · ( p₀(t) + t · p₁(t) + t² · p₂(t) + ... + tᵏ⁻¹ · pₖ₋₁(t) )
```

де `p_j(t)` — періодичні векторні функції з періодом `T`.

Наявність секулярних поліноміальних множників `tᵐ` викличує так звану **секулярну нестійкість**: навіть якщо модуль мультиплікатора дорівнює одиниці `|λ| = 1`, наявність нетривіального жорданового блоку призводить до лінійного або поліноміального зростання амплітуди коливань з часом. Це спостерігається на точних межах зон параметричного резонансу.

## 7. Алгебраїчний зв'язок між мультиплікаторами та показниками Флоке

Нехай `λ₁` — власне значення матриці монодромії `M`, а `v₁` — відповідний власний вектор:

```
M · v₁ = λ₁ · v₁
```

Числа `λ₁, λ₂, ..., λₙ` називаються **мультиплікаторами Флоке** (англ. *Floquet multipliers*). Вони є коренями характеристичного многочлена матриці монодромії:

```
det(M - λ·I) = 0
```

Оскільки `det M ≠ 0`, жоден мультиплікатор не дорівнює нулю: `λ_i ≠ 0` для всіх `i = 1, ..., n`.

Числа `μ₁, μ₂, ..., μₙ`, пов'язані з мультиплікаторами співвідношенням:

```
λ_i = e^(μ_i · T)
```

називаються **показниками Флоке** (англ. *Floquet exponents*). Показники Флоке виражаються через мультиплікатори як:

```
μ_i = (1 / T) · ( ln|λ_i| + i · (arg(λ_i) + 2·π·k) )   [k ∈ ℤ]
```

Дійсна частина показника Флоке `Re(μ_i)` визначає довготривалу швидкість експоненціального зростання або згасання розв'язку:

```
Re(μ_i) = (1 / T) · ln|λ_i|
```

Уільній траєкторії, що відповідає власному вектору `v_i`, притаманна структура:

```
x_i(t) = e^(μ_i · t) · p_i(t)
```

де `p_i(t) = P(t) · v_i` є строго періодичним вектором з періодом `T`.

## 8. Двовимірні періодичні системи та критерій трасу

Розглянемо детально важливий для практичних застосувань випадок двовимірної періодичної системи (`n = 2`):

```
dx/dt = A(t) · x,   x ∈ ℝ²
```

Характеристичне рівняння для `2 × 2` матриці монодромії `M` має вигляд:

```
det(M - λ·I) = λ² - (tr M)·λ + det M = 0
```

Для систем зі збереженням фазового об'єму (`tr A(t) = 0`, як у рівняннях Гілла та Матьє `y'' + f(t)·y = 0`), маємо `det M = 1`. Характеристичне рівняння спрощується до:

```
λ² - D·λ + 1 = 0
```

де `D = tr M = λ₁ + λ₂` — слід матриці монодромії.

Корені цього квадратного рівняння виражаються формулою:

```
λ₁,₂ = (D ± √(D² - 4)) / 2
```

Залежно від значення сліду `D = tr M`, можливі три фундаментально різні фізичні режими:

### Режим 1: Стійкі коливання (|D| < 2)
Дискримінант від'ємний `D² - 4 < 0`. Корені є комплексно-спряженими числами, що лежать строго на одиничному колі:

```
λ₁,₂ = (D ± i · √(4 - D²)) / 2
|λ₁|² = (D/2)² + (4 - D²)/4 = 4/4 = 1
```

Мультиплікатори мають вигляд `λ₁,₂ = e^(± i · θ)`, де `cos(θ) = D / 2`.
Показники Флоке є чисто уявними: `μ₁,₂ = ± i · (θ / T)`.
Дійсна частина покажчиків дорівнює нулю `Re(μ₁,₂) = 0`.
Усі розв'язки залишаються обмеженими при `t → +∞`. Система знаходиться у **зоні стійкості**.

### Режим 2: Параметричний резонанс та нестійкість (|D| > 2)
Дискримінант додатний `D² - 4 > 0`. Корені є дійсними числами, причому `λ₁ · λ₂ = 1`.
Одне з власних значень строго перевищує одиницю за модулем `|λ₁| > 1`, а друге менше за одиницю `|λ₂| < 1`.

Дійсна частина покажчика Флоке є додатною:

```
Re(μ₁) = (1 / T) · ln|λ₁| > 0
```

Амплітуда коливань зростає експоненціально `|x(t)| ~ e^(Re(μ₁) · t)`. Система перебуває в **області параметричного резонансу (нестійкості)**.

### Режим 3: Межовий стан (|D| = 2)
Дискримінант дорівнює нулю `D² - 4 = 0`. Мультиплікатори кратні:
* Якщо `D = +2`: `λ₁ = λ₂ = +1`. У системі існує принаймні один строго періодичний розв'язок із періодом `T`.
* Якщо `D = -2`: `λ₁ = λ₂ = -1`. У системі існує принаймні один антиперіодичний розв'язок `x(t + T) = -x(t)` (період `2·T`).

Ці межові значення `tr M = ±2` задають точні межі між зонами стійкості та нестійкості на діаграмах параметрів (таких як діаграма Інса — Стретта для рівняння Матьє).

## 9. Аналітичний розклад за малим параметром для рівняння Матьє

Для малих амплітуд параметричного збудження `q << 1` межові значення параметрів `a`, при яких `tr M = ±2`, шукають у вигляді асимптотичних рядів теорії збурень.

Подамо розв'язок `y(t)` та параметр `a` у формі степеневих розкладів за малим параметром `q`:

```
a = a₀ + q · a₁ + q² · a₂ + q³ · a₃ + ...
y(t) = y₀(t) + q · y₁(t) + q² · y₂(t) + ...
```

Підставивши ці розклади у рівняння Матьє `y'' + (a - 2·q·cos(2·t))·y = 0` та згрупувавши члени при однакових степенях `q`, отримуємо послідовність лінійних автономних рівнянь для `y₀, y₁, y₂`.

Для першої зони параметричного резонансу у напрямку `a₀ = 1` пертурбативний розрахунок дає дві межові криві:
* Нижній край нестійкості (`λ = -1`): `a_low(q) = 1 - q - (1/8)·q² + (1/64)·q³ + O(q⁴)`.
* Верхній край нестійкості (`λ = -1`): `a_high(q) = 1 + q - (1/8)·q² - (1/64)·q³ + O(q⁴)`.

Ширина першої нестійкої зони становить `Δa = a_high - a_low = 2·q + O(q³)`. Для другої зони нестійкості у околі `a₀ = 4` межеві криві задаються формулами `a = 4 - (1/12)·q²` та `a = 4 + (5/12)·q²`, з шириною зони `Δa = (1/2)·q²`. Ці асимптотичні формули повністю узгоджуються з точними чисельними розрахунками матриці монодромії.
