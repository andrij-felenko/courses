# 🧮 Математичний аналіз відображення Ено: Якобіан, оберненість та розмірність Каплана–Йорка

Відображення Ено являє собою двовимірну дискретну динамічну систему, задану векторним перетворенням `T: ℝ² → ℝ²`, яке задає зв'язок між теперішнім станом фазової площини `(x[n], y[n])` та наступним станом `(x[n+1], y[n+1])`:

```
x[n+1] = 1 - a·x[n]² + y[n]
y[n+1] = b·x[n]
```

де `a > 0` — параметр нелінійності (керує параболічним згином фазової площини), а `b` — параметр дисипативності (керує стисканням площі й фазового об'єму).

## 1. Матриця Якобі та аналіз стискання фазового об'єму

Локальну деформацію малого елемента площини `d x ∧ d y` при кожній ітерації відображення визначає матриця Якобі, яка утворюється з частинних похідних першого порядку від функції відображення. Ця матриця описує лінійну частину Тейлорівського розкладу у околі кожної точки `(x, y)` фазового простору:

```
J(x, y) = [ [ ∂x[n+1]/∂x[n],  ∂x[n+1]/∂y[n] ],
            [ ∂y[n+1]/∂x[n],  ∂y[n+1]/∂y[n] ] ]
        = [ [ -2·a·x[n],      1 ],
            [  b,             0 ] ]             [частинні похідні рівнянь Ено]
```

Визначник матриці Якобі (Якобіан відображення) обчислюється розкладом за другим рядком матриці:

```
det J = (-2·a·x[n])·0 - 1·b
      = -b                                      [стале значення для будь-якої точки]
```

Звідси випливають три фундаментальні математичні та фізичні наслідки для динамічної системи:

По-перше, **сталість дисипації фазового об'єму:** Визначник `det J = -b` не залежить від координат `(x, y)`. Будь-яка область `S` у фазовій площині з початковою площею `Area(S)` після одного кроку змінює свою площу строго у `|b|` разів, тобто `Area(T(S)) = |b| · Area(S)`.

По-друге, **строго дисипативний характер:** При `|b| < 1` площа будь-якої фігури експоненційно тане зі швидкістю `|b|^n → 0` при `n → ∞`. Це означає, що система є дисипативною (грец. *dissipare* — розсіювати), і всі градієнти станів осідають на множину нульової двовимірної міри — дивний атрактор.

По-третє, **дзеркальна зміна орієнтації:** Оскільки при `b > 0` визначник `det J = -b < 0` є від'ємним, відображення міняє орієнтацію елемента площини на протилежну (дзеркальне відображення) на кожному кроці ітерації.

З математичного погляду, сталість Якобіана `det J = -b` робить відображення Ено найпростішим двовимірним розширенням одновимірних відображень. У загальному випадку двовимірного диференційовного відображення визначник Якобіана залежить від координат точки, через що швидкість стискання фазового об'єму змінюється від точки до точки. У відображенні Ено дисипація є абсолютно однорідною по всьому фазовому простору.

Така сталість Якобіана виявляється надзвичайно зручною при теоретичному аналізі. Збереження об'єму у гамільтонових системах описується теоремою Ліувілля, де Якобіан дорівнює одиниці `det J = 1`. У відображенні Ено ми маємо узагальнений випадок однорідно дисипативної системи, де площа кожного элемента фазового простору на кожній ітерації стискається з тим самим коефіцієнтом `|b|`.

## 2. Доведення дифеоморфізму та обернене перетворення

Динамічна система називається строго обратною, якщо за відомим майбутнім станом `(x[n+1], y[n+1])` можна однозначно та бездвозначно відновити єдиний минулий стан `(x[n], y[n])`. Для відображення Ено при `b ≠ 0` обернене перетворення `T⁻¹` виводиться аналітично у вигляд прямої алгебраїчної підстановки:

```
y[n+1] = b·x[n]
⇒ x[n] = y[n+1] / b                             [виражаємо x[n] через y[n+1]]

x[n+1] = 1 - a·x[n]² + y[n]
⇒ y[n] = x[n+1] - 1 + a·x[n]²
⇒ y[n] = x[n+1] - 1 + a·(y[n+1] / b)²          [підставляємо виражений x[n]]
```

Отже, обернене відображення `T⁻¹` має явний алгебраїчний вигляд:

```
x[n] = y[n+1] / b
y[n] = x[n+1] - 1 + (a / b²) · y[n+1]²
```

Оскільки як пряме відображення `T`, так і обернене `T⁻¹` є гладкими (нескінченно диференційовними, класу `C^∞`), відображення Ено є **дифеоморфізмом** площини `ℝ²`. Це алгебраїчно гарантує, що дискретні фазові траєкторії не можуть самоперетинатися або розриватися у фазовій площині.

Властивість дифеоморфізму має вирішальне значення для збереження топологічної структури. В одновимірному логістичному відображенні `x[n+1] = r*x[n]*(1-x[n])` пряма функція є квадратичною параболою з максимумом при `x = 0.5`. Через це кожне значення `x[n+1]` має два різні початкові значення `x[n]`, що робить систему незворотною у часі. Додавання другої координати `y[n] = b*x[n-1]` у відображенні Ено відновлює взаємно однозначну відповідність між станами системи, перетворюючи її на справжній дифеоморфізм фазової площини.

Геометричний зміст оберненого перетворення полягає у тому, що ми можемо запустити модель як уперед у часі `n → +∞`, розгортаючи атрактор, так і назад `n → -∞`. При зворотному русі напрямки стискання та розтягування міняються місцями: нестійкі сідлові маніфолди стають стійкими, що дозволяє чисельно будувати межі басейнів притягання атрактора.

## 3. Алгебраїчне геометричне розкладення операторів

Відображення Ено можна подати як композицію трьох простих геометричних операторів `T = T₃ ∘ T₂ ∘ T₁`:

```
T₁: (x, y) ↦ (x, 1 - a·x² + y)                  [параболічний зсув, det J₁ = 1]
T₂: (x, y) ↦ (b·x, y)                           [стискання вздовж осі x, det J₂ = b]
T₃: (x, y) ↦ (y, x)                             [симетрія відносно y = x, det J₃ = -1]
```

Перевіримо послідовну дію композиції операторів на точку `(x, y)`:

```
(x, y)  ──T₁──>  (x, 1 - a·x² + y)
        ──T₂──>  (b·x, 1 - a·x² + y)
        ──T₃──>  (1 - a·x² + y, b·x) = (x[n+1], y[n+1])
```

Добуток визначників матриць Якобі елементарних кроків дає загальний Якобіан відображення:

```
det J = det J₃ · det J₂ · det J₁
      = (-1) · b · 1
      = -b                                      [теорема про визначник матричного добутку]
```

Аналіз елементарних операторів показує, що єдиним джерелом нелінійності у системі є крок `T₁`, який виконує параболічний зсув по вертикалі. Оператор `T₂` відповідає за лінійну дисипацію, а оператор `T₃` забезпечує перехресну координаційну взаємодію осей. Це дозволяє розбігатися орбітам у двох вимірах, не залишаючи обмежену область фазової площини.

## 4. Нерухомі точки та аналіз лінійної стійкості

Нерухома точка відображення `(x*, y*)` задовольняє умову самоузгодженості `T(x*, y*) = (x*, y*)`:

```
x* = 1 - a·x*² + y*
y* = b·x*
```

Підставивши `y* = b·x*` у перше рівняння, отримуємо квадратне рівняння відносно `x*`:

```
x* = 1 - a·x*² + b·x*
⇒ a·x*² + (1 - b)·x* - 1 = 0
```

Дискримінант рівняння `D = (1 - b)² + 4·a`. Оскільки `a > 0`, дискримінант завжди додатний `D > 0`, тож відображення завжди має два дійсні корені:

```
x*₁ = ( -(1 - b) + √((1 - b)² + 4·a) ) / (2·a)   [первинна нерухома точка]
x*₂ = ( -(1 - b) - √((1 - b)² + 4·a) ) / (2·a)   [вторинна нерухома точка]
```

Для класичних параметрів `a = 1.4` та `b = 0.3`:

```
x*₁ ≈ 0.631354,    y*₁ ≈ 0.189406
x*₂ ≈ -1.131354,   y*₂ ≈ -0.339406
```

Стійкість нерухомої точки визначають власні значення `λ` лінеаризованої матриці Якобі `J(x*, y*)`:

```
det (J - λ·I) = det [ [ -2·a·x* - λ,  1 ],
                      [  b,          -λ ] ]
              = (-2·a·x* - λ)·(-λ) - b
              = λ² + 2·a·x*·λ + b = 0            [характеристики розкладу]
```

Корені характеристичного рівняння обчислюються за формулою:

```
λ₁,₂ = -a·x* ± √((a·x*)² - b)
```

Для первинної точки `(x*₁, y*₁)` при `a = 1.4, b = 0.3`:

```
a·x*₁ ≈ 1.4 · 0.631354 ≈ 0.883895
λ₁ = -0.883895 - √(0.883895² - 0.3) ≈ -1.5776    [нестійкий напрямок: |λ₁| > 1]
λ₂ = -0.883895 + √(0.883895² - 0.3) ≈ -0.1901    [стійкий напрямок: |λ₂| < 1]
```

Оскільки `|λ₁| > 1`, а `|λ₂| < 1`, первинна точка є **сідловою (сідлом)**. Власні вектори матриці Якобі задають локальні дотичні напрямки стійкого маніфолду `W^s` та нестійкого маніфолду `W^u`. Траєкторії, що стартують у фазовому просторі, експоненційно притягуються до нестійкого маніфолду вздовж напрямку `λ₂` і одночасно витягуються вздовж напрямку `λ₁`, що створює сітку атрактора.

Аналіз другої нерухомої точки `(x*₂, y*₂)` показує, що вона також є сідлом, але розташована на самій межі басейну притягання атрактора. Саме її нестійкий маніфолд відповідає за явище кризи межі при `a ≈ 1.42`.

## 5. Спектр Ляпунова та фрактальна розмірність Каплана–Йорка

Показники Ляпунова `λ₁ > λ₂` вимірюють середню експоненційну швидкість розходження сусідніх орбіт вздовж головних осей фазового простору:

```
λ₁ = lim (1/N) · ∑ ln |v₁(n)|  ≈ +0.419          [додатний — відповідає за хаос]
λ₂ = lim (1/N) · ∑ ln |v₂(n)|  ≈ -1.624          [від'ємний — відповідає за стискання]
```

Сума показників Ляпунова строго дорівнює логарифму модуля Якобіана:

```
λ₁ + λ₂ = ln |det J| = ln(0.3) ≈ -1.20397
```

За гіпотезою Каплана–Йорка (Kaplan-Yorke conjecture), фрактальна розмірність атрактора (розмірність за інформацією) обчислюється через показники Ляпунова:

```
D_KY = k + ( λ₁ + λ₂ + ... + λ_k ) / |λ_(k+1)|
```

Для двовимірного відображення Ено `k = 1` (оскільки `λ₁ > 0`, а `λ₁ + λ₂ < 0`):

```
D_KY = 1 + λ₁ / |λ₂|
     ≈ 1 + 0.4191 / 1.6240
     ≈ 1.258
```

Значення `D_KY ≈ 1.26` показує, що атрактор Ено не є ані лінією (розмірність 1), ані суцільною площиною (розмірність 2): це дробовий **фрактальний об'єкт**, створений з нескінченної кількості вкладених шарів.
