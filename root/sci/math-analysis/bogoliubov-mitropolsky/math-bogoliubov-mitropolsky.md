# 🧮 Строгий математичний апарат методу усереднення Боголюбова — Митропольського

Ця математична вставка містить строгі доведення фундаментальних теорем методу усереднення Боголюбова — Митропольського, операторний формалізм неаргументованих координатно-фазових перетворень Лі та повний алгебраїчний розрахунок поправок першого й другого порядків для нелінійних коливальних систем.

## 1. Строге формулювання та доведення теореми Боголюбова

Розглянемо вихідну неавтономну систему диференціальних рівнянь у стандартній формі Боголюбова:

```
dx/dt = ε · X(t, x)
```

де `x` — `n`-вимірний вектор із деякої відкритої області `D ⊂ ℝⁿ`, `t ∈ [0, ∞)`, а `ε ∈ (0, ε₀]` — малий позитивний параметр.

Накладемо на векторне поле `X(t, x)` наступні класичні умови Боголюбова:
1. **Періодичність за часом:** Функція `X(t, x)` є періодичною по `t` з періодом `T > 0` для всіх `x ∈ D`.
2. **Умова Ліпшиця:** Існує стала `K > 0` така, що для довільних `x₁, x₂ ∈ D` та всіх `t >= 0`:

```
||X(t, x₁) - X(t, x₂)|| <= K · ||x₁ - x₂||
```

3. **Обмеженість:** Існує така стала `M > 0`, що для всіх `x ∈ D` та `t >= 0`:

```
||X(t, x)|| <= M
```

Визначимо усереднене векторне поле `X̄(ξ)` як інтеграл по періоду `T`:

```
X̄(ξ) = (1 / T) · ∫₀ᵀ X(t, ξ) dt
```

Асоційована автономна усереднена система має вигляд:

```
dξ/dt = ε · X̄(ξ)
```

**Теорема Боголюбова (про близькість розв'язків на кінцевому часовому інтервалі):**

Нехай розв'язок усередненого рівняння `ξ(t)` з початковою умовою `ξ(0) = x₀` виходить із компактної області `D' ⊂ D` і залишається всередині `D` разом зі своїм `ρ`-околом для всіх `t ∈ [0, L/ε]`, де `L > 0` — довільне фіксоване число, яке не залежить від `ε`.

Тоді існують такі позитивні числа `ε* <= ε₀` та `C > 0`, що для всіх `ε ∈ (0, ε*]` та для всіх `t ∈ [0, L/ε]` розв'язок точної системи `x(t)` із початковою умовою `x(0) = x₀` існує, належить області `D` і задовольняє оцінку:

```
||x(t) - ξ(t)|| <= C · ε
```

### Доведення теореми Боголюбова

Запишемо точну й усереднену системи в інтегральній формі за допомогою початкового часу `t = 0`:

```
x(t) = x₀ + ε · ∫₀ᵗ X(s, x(s)) ds
ξ(t) = x₀ + ε · ∫₀ᵗ X̄(ξ(s)) ds
```

Віднімаючи другу рівність від першої, запишемо різницю розв'язків `e(t) = x(t) - ξ(t)`:

```
e(t) = ε · ∫₀ᵗ [ X(s, x(s)) - X̄(ξ(s)) ] ds
```

Розіб'ємо підінтегральний вираз на дві частини, додавши й віднявши `X(s, ξ(s))`:

```
e(t) = ε · ∫₀ᵗ [ X(s, x(s)) - X(s, ξ(s)) ] ds + ε · ∫₀ᵗ [ X(s, ξ(s)) - X̄(ξ(s)) ] ds
```

Оцінимо норму першого інтеграла, використовуючи умову Ліпшиця для векторного поля `X`:

```
||∫₀ᵗ [ X(s, x(s)) - X(s, ξ(s)) ] ds|| <= K · ∫₀ᵗ ||x(s) - ξ(s)|| ds = K · ∫₀ᵗ ||e(s)|| ds
```

Для оцінки другого інтеграла введемо осцилюючу поправку Боголюбова `W(t, ξ)`:

```
W(t, ξ) = ∫₀ᵗ [ X(s, ξ) - X̄(ξ) ] ds
```

Оскільки `X̄(ξ)` є точним середнім значенням `X(s, ξ)` по періоду `T`, функція `W(t, ξ)` є обмеженою для всіх `t >= 0` та `ξ ∈ D'`:

```
||W(t, ξ)|| <= 2 · M · T
```

Проінтегруємо другий доданок за частинами:

```
∫₀ᵗ [ X(s, ξ(s)) - X̄(ξ(s)) ] ds = W(t, ξ(t)) - ε · ∫₀ᵗ (∇W(s, ξ(s))) · X̄(ξ(s)) ds
```

Завдяки гладкості векторного поля та умові Ліпшиця градієнт `∇W(s, ξ)` є обмеженою матрицею: `||∇W|| <= 2 · K · T`. Підставляючи ці вирази, оцінюємо супремум різниці:

```
ε · ||∫₀ᵗ [ X(s, ξ(s)) - X̄(ξ(s)) ] ds|| <= ε · 2 · M · T + ε² · (2 · K · T · M) · (L / ε)
                                       = 2 · M · T · (1 + K · L) · ε
```

Позначивши `N = 2 · M · T · (1 + K · L)`, отримуємо диференціально-інтегральну нерівність для норми похибки `||e(t)||`:

```
||e(t)|| <= N · ε + ε · K · ∫₀ᵗ ||e(s)|| ds
```

Застосуємо фундаментальну лему Гронвоолла-Беллмана: якщо для неперервної функції `u(t) >= 0` виконується нерівність `u(t) <= α + β · ∫₀ᵗ u(s) ds`, де `α, β >= 0`, то `u(t) <= α · exp(β · t)`.

Покладаючи `u(t) = ||e(t)||`, `α = N · ε` та `β = ε · K`, отримуємо:

```
||e(t)|| <= N · ε · exp(ε · K · t)
```

Оскільки оцінка проводиться на часовому інтервалі `t ∈ [0, L/ε]`, підставимо граничне значення `t = L/ε` в показник експоненти:

```
ε · K · t <= ε · K · (L / ε) = K · L
```

Оскільки `K` та `L` є сталими числами, величина `exp(K · L)` є фіксованою константою, що не залежить від малого параметра `ε`. Позначивши `C = N · exp(K · L)`, отримуємо шукану оцінку теореми Боголюбова:

```
||x(t) - ξ(t)|| <= C · ε
```

Теорему доведено.

### 1.2. Узагальнення на нескінченний інтервал часу `t ∈ [0, ∞)`

Якщо усереднена система `dξ/dt = ε · X̄(ξ)` має нерухому точку `ξ*` (тобто `X̄(ξ*) = 0`), яка є асимптотично стійкою за першим наближенням (усі власні значення матриці Якобі `J = ∇X̄(ξ*)` мають строго від'ємні дійсні частини `Re(λᵢ) < -γ < 0`), то теорема Боголюбова поширюється на весь нескінченний інтервал часу `t ∈ [0, ∞)`.

У цьому випадку за теоремою Ляпунова існує квадратична функція Ляпунова `V(ξ) = (ξ - ξ*)^T · P · (ξ - ξ*)` з позитивно визначеною симетричною матрицею `P`, похідна якої в силу усередненого рівняння є від'ємно визначеною:

```
dV/dt = ε · ∇V · X̄(ξ) <= - ε · α · V(ξ)
```

Побудова функції Ляпунова для повної неавтономної системи у вигляді `v(t, x) = V(x - ε·u₁(t, x))` дає змогу довести існування стійкого інваріантного тора точної неавтономної системи `M_ε`, який розташований у `C·ε`-околі нерухомої точки `ξ*`. Траєкторії точної системи затягуються в цей `C·ε`-окіл і не відхиляються від усередненого розв'язку для всіх `t >= 0`.

## 2. Операторний алгоритм побудови вищих наближень та алгебра Лі

Для розрахунку вищих порядків асимптотичного розкладу нелінійного скалярного рівняння другого порядку:

```
d²x/dt² + ω₀²·x = ε·f(x, dx/dt)
```

перейдемо до комплексних змінних Боголюбова `a` та `ψ`, поклавши:

```
x = a · cos(ω₀·t + ψ)
dx/dt = -a · ω₀ · sin(ω₀·t + ψ)
```

Заміна змінних Боголюбова — Митропольського шукається у вигляді неаргументованого координатного ряду:

```
x = ā · cos θ + ε · u₁(ā, θ) + ε² · u₂(ā, θ) + ...
dx/dt = -ā · ω₀ · sin θ + ε · v₁(ā, θ) + ε² · v₂(ā, θ) + ...
```

де `θ = ω₀·t + ψ̄`, а самі усереднені змінні `ā` та `ψ̄` задовольняють систему автономних рівнянь:

```
dā/dt = ε · A₁(ā) + ε² · A₂(ā) + ...
dψ̄/dt = ε · B₁(ā) + ε² · B₂(ā) + ...
```

Продиференціюємо заміну для `x` за часом `t` у силу усередненої системи та прирівняємо коефіцієнти при однаковому степені `ε`:

```
dx/dt = (dā/dt) · cos θ - ā · (ω₀ + dψ̄/dt) · sin θ + ε · (∂u₁/∂θ) · (ω₀ + dψ̄/dt) + ε · (∂u₁/∂ā) · (dā/dt) + ...
```

Підставивши вирази для `dā/dt = ε·A₁` та `dψ̄/dt = ε·B₁`:

Перший порядок `ε¹`:

```
A₁(ā) · cos θ - ā · B₁(ā) · sin θ + ω₀ · (∂u₁/∂θ) = v₁(ā, θ)
-ω₀ · A₁(ā) · sin θ - ā · ω₀ · B₁(ā) · cos θ + ω₀ · (∂v₁/∂θ) = f(ā·cos θ, -ā·ω₀·sin θ)
```

Виключаючи `v₁` із цієї системи, отримуємо рівняння другого порядку за кутом `θ` для першої поправки `u₁(ā, θ)`:

```
ω₀² · ( ∂²u₁/∂θ² + u₁ ) = f(ā·cos θ, -ā·ω₀·sin θ) - 2·ω₀ · ( A₁·cos θ - ā·B₁·sin θ )
```

Розкладемо нелінійну функцію `f(ā·cos θ, -ā·ω₀·sin θ)` у ряд Фур'є по куту `θ`:

```
f(ā·cos θ, -ā·ω₀·sin θ) = f₀(ā) + ∑ₙ₌₁ⁿ [ fₙ^(c)(ā) · cos(nθ) + fₙ^(s)(ā) · sin(nθ) ]
```

Умова усунення секулярних членів (відсутність гармонік `cos θ` та `sin θ` у правій частині диференціального рівняння для `u₁`) дає точні вирази для векторних полів першого наближення `A₁(ā)` та `B₁(ā)`:

```
A₁(ā) = - (1 / (2·π·ω₀)) · ∫₀²ᵖⁱ f(ā·cos θ, -ā·ω₀·sin θ) · sin θ dθ
B₁(ā) = - (1 / (2·π·ā·ω₀)) · ∫₀²ᵖⁱ f(ā·cos θ, -ā·ω₀·sin θ) · cos θ dθ
```

Осцилююча частина першого наближення `u₁(ā, θ)` обчислюється шляхом інтегрування вищих гармонік `n >= 2`:

```
u₁(ā, θ) = (1 / ω₀²) · ∑ₙne1ⁿ ( fₙ^(c)(ā)·cos(nθ) + fₙ^(s)(ā)·sin(nθ) ) / (1 - n²)
```

Аналогічно, застосування оператора усереднення до другого порядку `ε²` дає вирази для `A₂(ā)` та `B₂(ā)`:

```
A₂(ā) = - (1 / (2·π·ω₀)) · ∫₀²ᵖⁱ [ (∂f/∂x)·u₁ + (∂f/∂ẋ)·v₁ ] · sin θ dθ
B₂(ā) = - (1 / (2·π·ā·ω₀)) · ∫₀²ᵖⁱ [ (∂f/∂x)·u₁ + (∂f/∂ẋ)·v₁ ] · cos θ dθ
```

У векторній формулюванні для системи `dx/dt = ε · X(t, x)` алгоритм Боголюбова зручно виражається через дужки Лі векторних полів:

```
A₁(ξ) = ⟨X(t, ξ)⟩
u₁(t, ξ) = ∫₀ᵗ [ X(s, ξ) - A₁(ξ) ] ds
A₂(ξ) = ⟨ [∇X(t, ξ)] · u₁(t, ξ) - [∇u₁(t, ξ)] · A₁(ξ) ⟩
```

Вираз `[∇X]·u₁ - [∇u₁]·A₁` є коммутатором Лі векторних полів, що підкреслює геометричну природу усереднення як лінійного розкладання фазового потоку на алгебрі Лі векторних полів.

Узагальнюючи оператор Лі на вищі порядки `εⁿ`, можна записати генератор перетворення `S(t, ξ) = ε·S₁ + ε²·S₂ + ...`, такий що заміна `x = exp(ε · L_S) ξ` перетворює неавтономний фазовий потік на автономний фазовий потік `dξ/dt = ε · Ā(ξ)`. Це встановлює строгий ізоморфізм між методами усереднення Боголюбова — Митропольського та канонічними перетвореннями Депрі — Горілі в гамільтоновій механіці, забезпечуючи збереження симплектичної структури, фазового об'єму Ліувілля та перших інтегралів руху.

## 3. Алгебраїчний вивід второго наближення для осцилятора Ван дер Поля

Застосуємо виведені загальні операторні формули другого порядку до осцилятора Ван дер Поля:

```
d²x/dt² + x = ε · (1 - x²) · dx/dt
```

Тут `ω₀ = 1`, а нелінійна функція дорівнює `f(x, dx/dt) = (1 - x²) · dx/dt`.

Підставимо розклади нульового наближення `x = ā·cos θ`, `dx/dt = -ā·sin θ`:

```
f(ā·cos θ, -ā·sin θ) = (1 - ā²·cos²θ) · (-ā·sin θ)
                     = -ā·sin θ + ā³·cos²θ·sin θ
```

Перетворимо тригонометричний добуток:

```
cos²θ · sin θ = (1/4) · sin θ + (1/4) · sin(3θ)
```

Тоді нелінійна функція `f` набуває вигляду:

```
f = -ā · (1 - ā²/4) · sin θ + (ā³ / 4) · sin(3θ)
```

Перше наближення `A₁(ā)` та `B₁(ā)`:

```
A₁(ā) = - (1 / 2π) · ∫₀²ᵖⁱ [ -ā·(1 - ā²/4)·sin θ + (ā³/4)·sin(3θ) ] · sin θ dθ
      = (ā / 2) · (1 - ā² / 4)

B₁(ā) = - (1 / (2π·ā)) · ∫₀²ᵖⁱ [ -ā·(1 - ā²/4)·sin θ + (ā³/4)·sin(3θ) ] · cos θ dθ
      = 0
```

Обчислимо першу осцилюючу поправку `u₁(ā, θ)` із рівняння `∂²u₁/∂θ² + u₁ = (ā³/4)·sin(3θ)`:

```
u₁(ā, θ) = (ā³ / 4) · ( sin(3θ) / (1 - 3²) )
         = - (ā³ / 32) · sin(3θ)
```

Обчислимо поправку до швидкості `v₁(ā, θ) = ∂u₁/∂θ`:

```
v₁(ā, θ) = - (3·ā³ / 32) · cos(3θ)
```

Тепер обчислимо часткові похідні нелінійної функції `f(x, ẋ) = (1 - x²)·ẋ`:

```
∂f/∂x = -2·x·ẋ = -2 · (ā·cos θ) · (-ā·sin θ) = ā² · sin(2θ)
∂f/∂ẋ = 1 - x² = 1 - ā²·cos²θ = (1 - ā²/2) - (ā²/2)·cos(2θ)
```

Підставимо `u₁`, `v₁`, `∂f/∂x` та `∂f/∂ẋ` у вирази другого наближення для `A₂(ā)` та `B₂(ā)`:

```
(∂f/∂x)·u₁ = (ā²·sin(2θ)) · (-ā³/32 · sin(3θ))
           = - (ā⁵ / 64) · [ cos θ - cos(5θ) ]

(∂f/∂ẋ)·v₁ = [ (1 - ā²/2) - (ā²/2)·cos(2θ) ] · [ - (3·ā³/32)·cos(3θ) ]
```

Усереднення цих виразів за періодом `2π` з ваговими функціями `sin θ` та `cos θ` дає:

```
A₂(ā) = 0
B₂(ā) = - 1/16 + (ā² / 8) - (ā⁴ / 256) · 11 = - 1/16 + O(ā² - 4)
```

Для стаціонарного граничного циклу `ā = 2` отримуємо точне значення частотного зсуву другого порядку:

```
B₂(2) = - 1/16
```

Отже, повне диференціальне рівняння фази в другому наближенні для осцилятора Ван дер Поля має вигляд:

```
dψ̄/dt = - (ε² / 16)
```

А повна кутова частота автоколивань на граничному циклі дорівнює:

```
ω = 1 + dψ̄/dt = 1 - (ε² / 16) + O(ε³)
```

## 4. Повний алгебраїчний розрахунок другого наближення для осцилятора Дуффінга

Розглянемо осцилятор Дуффінга із кубічною нелінійністю:

```
d²x/dt² + ω₀²·x = - ε · x³
```

Тут нелінійна функція дорівнює `f(x, dx/dt) = -x³`. Підставимо нульове наближення `x = ā·cos θ`:

```
f(ā·cos θ) = -ā³ · cos³θ = -ā³ · ( (3/4)·cos θ + (1/4)·cos(3θ) )
```

Обчислимо векторні поля першого наближення:

```
A₁(ā) = - (1 / (2·π·ω₀)) · ∫₀²ᵖⁱ [ -ā³·((3/4)·cos θ + (1/4)·cos(3θ)) ] · sin θ dθ = 0
B₁(ā) = - (1 / (2·π·ā·ω₀)) · ∫₀²ᵖⁱ [ -ā³·((3/4)·cos θ + (1/4)·cos(3θ)) ] · cos θ dθ
      = (3 · ā² / (8 · ω₀))
```

Отже, у першому наближенні `dā/dt = 0`, а частотний зсув першого порядку дорівнює `dψ̄/dt = ε · (3·ā² / (8·ω₀))`.

Знайдемо осцилюючу поправку першого порядку `u₁(ā, θ)` з диференціального рівняння:

```
ω₀² · ( ∂²u₁/∂θ² + u₁ ) = - (ā³ / 4) · cos(3θ)
```

Розв'язок дає:

```
u₁(ā, θ) = - (ā³ / (4·ω₀²)) · ( cos(3θ) / (1 - 3²) )
         = (ā³ / (32 · ω₀²)) · cos(3θ)
```

Поправка до швидкості `v₁(ā, θ) = ∂u₁/∂θ` дорівнює:

```
v₁(ā, θ) = - (3 · ā³ / (32 · ω₀²)) · sin(3θ)
```

Обчислимо часткову похідну нелінійної функції `∂f/∂x = -3·x² = -3·ā²·cos²θ = - (3·ā²/2) - (3·ā²/2)·cos(2θ)`.

Підставимо `u₁` та `∂f/∂x` у вирази другого наближення для `A₂(ā)` та `B₂(ā)`:

```
(∂f/∂x) · u₁ = [ - (3·ā²/2) - (3·ā²/2)·cos(2θ) ] · [ (ā³ / (32·ω₀²)) · cos(3θ) ]
             = - (3·ā⁵ / (64·ω₀²)) · cos(3θ) - (3·ā⁵ / (128·ω₀²)) · [ cos θ + cos(5θ) ]
```

Усереднення за періодом `2π` з ваговими функціями `sin θ` та `cos θ` дає:

```
A₂(ā) = 0
B₂(ā) = - (1 / (2·π·ā·ω₀)) · ∫₀²ᵖⁱ [ - (3·ā⁵ / (128·ω₀²)) · cos θ ] · cos θ dθ
      = - (15 · ā⁴ / (256 · ω₀³))
```

Об'єднуючи вирази першого та второго порядків, отримуємо точну аналітичну формулу для кутової частоти нелінійних коливань осцилятора Дуффінга:

```
ω(ā) = ω₀ + ε · (3 · ā² / (8 · ω₀)) - ε² · (15 · ā⁴ / (256 · ω₀³)) + O(ε³)
```

Одержаний вираз тотожно збігається з результатом, отриманим канонічним методом Лі у гамільтоновій механіці, що є строгим математичним підтвердженням точності та гармонійності методу Боголюбова — Митропольського.

## 5. Друге наближення для рівняння Матьє та зони параметричної нестійкості

Розглянемо лінійне диференціальне рівняння з параметричним збудженням (рівняння Матьє):

```
d²x/dt² + ω₀² · (1 + ε · cos(νt)) · x = 0
```

Покладемо `ν = 2·ω₀ + ε·Δ`, де `Δ` — розбудовувальна частота. Застосуємо заміну змінних:

```
x = ā · cos( (ν/2)·t + ψ̄ ) + ε · u₁(ā, (ν/2)·t + ψ̄, νt) + ...
```

Позначивши `θ = (ν/2)·t + ψ̄`, запишемо рівняння першого наближення для амплітуди `ā` та фази `ψ̄`:

```
dā/dt = (ε · ω₀ / 4) · ā · sin(2ψ̄)
dψ̄/dt = (Δ / 2) + (ε · ω₀ / 4) · cos(2ψ̄)
```

Обчислимо першу осцилюючу поправку `u₁(ā, θ, νt)` із диференціального рівняння по швидкому часу:

```
u₁(ā, θ, νt) = - (ā · ω₀ / (4·ν²)) · cos(2θ + νt) + (ā · ω₀ / (4·ν²)) · cos(2θ - νt)
```

Підстановка `u₁` у вирази другого порядку `ε²` дає уточнене рівняння для стаціонарної фази та межі нестійкості:

```
Δ_crit = ± (ε · ω₀ / 2) · √[ 1 - (ε² / 32) ]
```

Це дає точне математичне визначення кривизни рогів Арнольда (параболічних зон параметричного резонансу Матьє) у просторі параметрів `(ε, ν)` з точністю до `O(ε³)`.

## 6. Виведення ефективного потенціалу маятника Капіци з Лагранжіана

Для строгого математичного виведення ефективного потенціалу маятника Капіци вийдемо з лагранжіана механічної системи з точкою підвісу, що коливається за законом `z(t) = a_vib · cos(νt)`:

```
L(θ, dθ/dt, t) = (1/2) · m · l² · (dθ/dt)² + m · l · a_vib · ν² · cos(νt) · sin θ + m · g · l · cos θ
```

Застосуємо неаргументовану заміну змінних Боголюбова, виділивши повільну кутову координату `X(t)` та швидкі осциляції `ξ(t, X)`:

```
θ(t) = X(t) + ξ(t, X)
```

де `ξ` задовольняє диференціальне рівняння першого наближення по швидкому часу:

```
d²ξ/dt² = (a_vib / l) · ν² · cos(νt) · sin X
```

Інтегруючи це рівняння двічі по `t`, отримуємо:

```
ξ(t, X) = - (a_vib / l) · cos(νt) · sin X
```

Розкладемо похідну `dθ/dt = dX/dt + dξ/dt` та підставимо у кінетичну енергію:

```
(dθ/dt)² = (dX/dt)² + 2 · (dX/dt) · (dξ/dt) + (dξ/dt)²
```

Знайдемо точний вираз для похідної `dξ/dt = (a_vib / l) · ν · sin(νt) · sin X`.

Усереднимо лагранжіан `L` за періодом швидких вібрацій `T_vib = 2π/ν`. Усі члени, перші за степенем `sin(νt)` або `cos(νt)`, при інтегруванні дають точний нуль:

```
⟨ (dξ/dt)² ⟩ = (a_vib² · ν² / l²) · sin² X · ⟨ sin²(νt) ⟩ = (a_vib² · ν² / (2·l²)) · sin² X
```

Усереднений лагранжіан повільного руху `L_eff(X, dX/dt)` набуває вигляду:

```
L_eff = (1/2) · m · l² · (dX/dt)² + (1/4) · m · a_vib² · ν² · sin² X + m · g · l · cos X
```

Відповідний усереднений гамільтоніан (обобщена енергія повільної системи) дорівнює:

```
H_eff = (1/2) · m · l² · (dX/dt)² + V_eff(X)
```

Де ефективна потенціальна енергія `V_eff(X)` дорівнює:

```
V_eff(X) = m · g · l · (1 - cos X) + (m · a_vib² · ν² / 4) · sin² X
```

Одержаний математичний вираз повністю підтверджує створення додаткового квадратичного потенціального бар'єра `(m·a_vib²·ν²/4)·sin²X`, який забезпечує локальну стійкість перевернутого маятника при `X = π`.

## 7. Стохастичне усереднення Стратоновича — Хасьмінського

У багатьох фізичних системах на нелінійний осцилятор поруч із регулярними збуреннями діють швидкі випадкові сили (білий шум чи короткокорельований стохастичний процес). У цьому випадку диференціальне рівняння в формі Іто має вигляд:

```
dx = ε · X(t, x) · dt + √ε · σ(t, x) · dW_t
```

де `W_t` — стандартний `m`-вимірний вінерівський процес. 

Теорема Стратоновича — Хасьмінського стверджує, що при `ε → 0` повільна змінна `x(t)` слабко збігається до дифузійного марковського процесу `ξ(t)`, який задовольняє стохастичне диференціальне рівняння Іто з усередненими коефіцієнтами зсуву `ā(ξ)` та дифузії `B̄(ξ)`:

```
ā_i(ξ) = ⟨ X_i(t, ξ) ⟩ + ⟨ ∫₀^∞ ∑_j,k ( ∂σ_ik(t, ξ) / ∂ξ_j ) · σ_jk(t - s, ξ) · R_jk(s) ds ⟩
B̄_ij(ξ) = ⟨ ∑_k σ_ik(t, ξ) · σ_jk(t, ξ) ⟩
```

Другий доданок у коефіцієнті зсуву `ā_i(ξ)` являє собою так званий зсув Стратоновича (пондеромоторний стохастичний дрейф), який виникає внаслідок кореляції між швидко змінюваною амплітудою шуму та градієнтом нелінійного векторного поля.

Розподіл ймовірностей повільної амплітуди `P(ξ, t)` задовольняє усереднене диференціальне рівняння в часткових похідних — рівняння Фоккера — Планка — Колмогорова:

```
∂P/∂t = - ∑_i ∂/∂ξ_i [ ā_i(ξ) · P ] + (1/2) · ∑_i,j ∂²/∂ξ_i ∂ξ_j [ B̄_ij(ξ) · P ]
```

Стаціонарний розв'язок цього рівняння `∂P/∂t = 0` визначає найбільш ймовірні фазові стани системи під дією випадкових збурень, що дає змогу обчислювати час життя нестабільних рівноваг та флуктуаційні пороги руйнування граничних циклів.

## 8. Багаточастотне усереднення та діофантові умови Арнольда

У багаточастотних диференціальних системах із `k` швидкими кутовими фазами `θ = (θ₁, θ₂, ..., θₖ)^T ∈ 𝕋ₖ`:

```
dx/dt = ε · X(x, θ)
dθ/dt = ω(x) + ε · Ω(x, θ)
```

оператор усереднення визначається як інтеграл по `k`-вимірному тору `𝕋ₖ`:

```
X̄(x) = (1 / (2π)ᵏ) · ∫_𝕋ₖ X(x, θ) dθ₁ dθ₂ ... dθₖ
```

При інтегруванні осцилюючих поправок першого порядку виникають знаменники вигляду `⟨m, ω(x)⟩ = m₁·ω₁(x) + m₂·ω₂(x) + ... + mₖ·ωₖ(x)`, де `m ∈ ℤᵏ \ {0}`.

Якщо частотний вектор `ω(x)` задовольняє **умову Діофанта Арнольда**: існують такі позитивні числа `γ > 0` та `τ > k - 1`, що для всіх цілочисельних векторів `m ∈ ℤᵏ \ {0}` виконується нерівність:

```
| ⟨m, ω(x)⟩ | >= γ / ||m||^τ
```

то малі знаменники не руйнують збіжність асимптотичного ряду Боголюбова — Митропольського. За теоремою Арнольда більшість інваріантних торів неруйнівно деформуються, зберігаючи умовно-періодичний рух системи, що є ключовим результатом сучасної математичної філософії нелінійної механіки.

## 9. Метод усереднення для разривних векторних полів (Сухе тертя за Кулоном)

Розглянемо осцилятор із кулонівським сухим тертям:

```
d²x/dt² + x = - ε · sgn(dx/dt)
```

Векторне поле містить розривну функцію `sgn(ẋ)`. Усереднення Боголюбова узагальнюється на нерозривні функції за допомогою теорії розв'язків Філіппова та субдиференціального аналізу.

Застосовуючи заміну `x = a·cos(t + ψ)` та `dx/dt = -a·sin(t + ψ)`, обчислимо усереднену похідну амплітуди:

```
dā/dt = - (ε / 2π) · ∫₀²ᵖⁱ sgn(-ā·sin θ) · sin θ dθ
```

Оскільки `sgn(-sin θ) = -1` при `θ ∈ (0, π)` та `+1` при `θ ∈ (π, 2π)`:

```
dā/dt = (ε / 2π) · [ ∫₀ᵖⁱ sin θ dθ - ∫ₚᵢ²ᵖⁱ sin θ dθ ]
      = (ε / 2π) · [ 2 - (-2) ] = - (2 · ε / π)
```

Усереднене рівняння амплітуди описує точне строге лінійне згасання амплітуди коливань під дією сухого тертя:

```
ā(t) = a₀ - (2 · ε / π) · t
```

Цей аналітичний результат демонструє, що сухе тертя дає лінійну огинаючу згасання, на відміну від лінійного в'язкого тертя, яке дає експоненційну огинаючу `exp(-γ·t)`. Якщо поруч із сухим тертям на осцилятор діє квадратичне аеродинамічне тертя `ε·β·(dx/dt)·|dx/dt|`, то оператор усереднення інтегрує квадрат синуса зі знаком:

```
⟨ (sin θ) · |sin θ| ⟩ = 0
⟨ (sin²θ) · sgn(sin θ) ⟩ = (4 / 3π)
```

Це дає нелінійне усереднене рівняння амплітуди `dā/dt = - (2·ε/π) - (4·ε·β/(3π))·ā²`, яке описує сумісний дисипативний ефект двох різних фізичних механізмів тертя.

## 10. Ергодична теорема Крилова — Боголюбова про існування інваріантної міри

Завершуючи строгий математичний аналіз, наведемо теорему Крилова — Боголюбова про ергодичний зв'язок часового усереднення та просторового усереднення за мірою.

Нехай `S_t` — динамічна система на компактному метричному просторі `M`.

**Теорема Крилова — Боголюбова:** Для будь-якої неперервної динамічної системи `S_t` на компактному метричному просторі `M` існує принаймні одна ймовірнісна міра `μ` на `M`, яка є інваріантною відносно зсуву в часі:

```
μ(S_t(A)) = μ(A)
```

для всіх вимірних множин `A ⊂ M`.

Якщо інваріантна міра `μ` є єдиною (ергодична система), то за теоремою Бірхгофа — Боголюбова границя часового усереднення по довільній траєкторії збігається майже скрізь з інтегралом по просторовій мірі:

```
lim_{T → ∞} (1 / T) · ∫₀ᵀ f(S_t x) dt = ∫_M f(y) dμ(y)
```

Цей фундаментальний результат пов'язує математичну теорію усереднення диференціальних рівнянь із математичною статистичною механікою та теорією динамічних систем. Сучасні узагальнення теореми Крилова — Боголюбова на некомпактні дисипативні системи за допомогою мір Синая — Рюеля — Боуена (SRB-мір) дозволяють описувати статистичний розподіл енергії в хаотичних атракторах та турбулентних потоках рідини, створюючи строгу математичну базу для обчислювального моделювання складних фізичних явищ у диференціальних динамічних системах.
