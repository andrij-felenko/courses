# 🧮 Математика ренормалізації: рівняння Фейгенбаума-Цвітановича та спектр оператора

Теорія ренормалізаційної групи у поясненні універсальності каскаду подвоєння періоду спирається на функціональне рівняння Фейгенбаума-Цвітановича та спектральний аналіз лінеаризованого оператора перенормування. Нижче подано математичний вивід універсальних функцій, розрахунок масштабних коефіцієнтів `δ` та `α` і пояснення того, чому універсальність притаманна цілим класам нелінійних відображень.

## 1. Надстійкі орбіти та поняття масштабування

Розглянемо сім'ю одногорбих дискретних відображень `x[n+1] = f(x[n], r)` на відрізку `[-1, 1]`, де `r` — параметр керування. Припустимо, що функція `f(x, r)` має парний квадратичний максимум у точці `x = 0`, тобто її локальний розклад Тейлора біля нуля має вигляд:

```
f(x, r) = 1 - c(r) · x² + O(x⁴),   де c(r) > 0
```

При зміні параметра `r` стійкі циклічні орбіти періоду `2ⁿ` зазнають біфуркацій подвоєння. Серед усіх значень параметра `r` для кожного періоду `2ⁿ` існує особливе значення `R[n]`, за якого цикл стає **надстійким** (superstable).

Надстійкий цикл характеризується тим, що одна з його точок збігається з точкою екстремуму `x = 0`. Оскільки похідна функції у вершині дорівнює нулю `f'(0, R[n]) = 0`, похідна складеної функції `(f^(2ⁿ))'(0, R[n])` за правилом ланцюжка також стає тотожно рівною нулю:

```
(f^(2ⁿ))'(0, R[n])
= f'(x[0]) · f'(x[1]) · ... · f'(x[2ⁿ-1])      [правило ланцюжка для похідної складеної функції]
= 0 · f'(x[1]) · ...                            [оскільки f'(x[0]) = f'(0) = 0]
= 0                                             [множення на нуль]
```

Ці надстійкі значення параметра `R[n]` слугують строго визначеними реперними точками для аналізу геометрії каскаду:

1. **Параметричний масштаб `δ`:**
   Відношення відстаней між послідовними надстійкими параметрами визначає коефіціент стиснення параметра `r`:

   ```
   δ = lim (R[n] - R[n-1]) / (R[n+1] - R[n])   при n → ∞
   ```

2. **Просторовий масштаб `α`:**
   Нехай `d[n]` — відстань від вершини `x = 0` до найближчої елементарної точки циклу періоду `2ⁿ` при надстійкому параметрі `R[n]`. Значення цієї точки дорівнює півперіодному ітерованому числу `d[n] = f^(2ⁿ⁻¹)(0, R[n])`. Відношення цих відстаней дає просторовий масштабний коефіцієнт `α`:

   ```
   α = lim (d[n] / d[n+1])   при n → ∞
   ```

Зауважте, що знак `α` є від'ємним, оскільки найближча точка наступного подвоєного циклу опиняється по інший бік від нуля (відбувається дзеркальне перевертання вилки).

## 2. Функціональний оператор перенормування

Щоб зрозуміти, чому граничні коефіцієнти `δ` та `α` однакові для різних функцій, розглянемо дію оператора подвійного ітерування.

Якщо розглянути відображення `f(x)` на відрізку навколо нуля й застосувати його двічі, отримаємо нову функцію `f²(x) = f(f(x))`. Біля вершини `x = 0` ця подвійна ітерація виглядає як стиснута й перевернута копія вихідної функції `f(x)`.

Введемо **оператор перенормування Фейгенбаума-Цвітановича** `T`, який діє у функціональному просторі парних одногорбих функцій за правилом:

```
T f(x) = -α · f( f( -x / α ) )
```

Оператор `T` робить дві речі:
1. Застосовує відображення двічі поспіль (що відповідає переходу від періоду `2ⁿ` до періоду `2ⁿ⁺¹`).
2. Масштабує аргумент `x` у `-α` разів по осі абсцис та по осі ординат, щоб відновити вихідний масштаб і орієнтацію максимуму.

### Рівняння нерухомої точки

Границя нескінченного застосування оператора перенормування прямує до **універсальної граничної функції** `g(x)`, яка є нерухомою точкою оператора `T`:

```
T g(x) = g(x)
```

Розкривши означення оператора `T`, дістаємо знамените **функціональне рівняння Фейгенбаума-Цвітановича**:

```
g(x) = -α · g( g( -x / α ) )
```

із нормувальними умовами на граничну функцію:
- `g(0) = 1` (максимум у нулі дорівнює одиниці);
- `g'(0) = 0` (гладкий стаціонарний максимум);
- `g(x)` є парною функцією: `g(-x) = g(x)`.

### Поліноміальний розклад та знаходження констант

Розкладемо універсальну функцію `g(x)` у степеневий ряд за парними степенями `x²`:

```
g(x) = 1 + c₂ · x² + c₄ · x⁴ + c₆ · x⁶ + c₈ · x⁸ + ...
```

Підставимо цей розклад у рівняння `g(x) = -α · g(g(-x / α))` і прирівняємо коефіцієнти при одинакових степенях `x`.

Спочатку обчислимо значення `g(1)` у точці `x = 1`. З умови `g(0) = 1` при `x = 0` маємо:

```
g(0) = -α · g(g(0))       [означення рівняння нерухомої точки при x = 0]
= -α · g(1)               [умова нормування g(0) = 1]
```

Звідси отримуємо точне співвідношення між значенням `g(1)` і коефіцієнтом `α`:

```
g(1) = -1 / α
```

Тепер розкладемо вкладені вирази для малих `x`. Знаючи, що `g(0) = 1`, для вкладеного аргументу отримуємо:

```
g(-x / α)
= 1 + c₂ · (-x / α)² + c₄ · (-x / α)⁴ + c₆ · (-x / α)⁶ + ...       [розклад g(u) при u = -x / α]
= 1 + (c₂ / α²) · x² + (c₄ / α⁴) · x⁴ + (c₆ / α⁶) · x⁶ + ...        [піднесення до квадратів та вищих степенів]
```

Застосуємо зовнішню функцію `g(u) = 1 + c₂ u² + c₄ u⁴ + ...` до аргументу `u(x) = 1 + w(x)`, де `w(x) = (c₂ / α²) x² + (c₄ / α⁴) x⁴ + ...`:

```
g(1 + w(x))
= g(1) + g'(1) · w(x) + (1/2) · g''(1) · w(x)² + ...              [розклад Тейлора біля u = 1]
```

Прирівнюючи коефіцієнти при однаковісіньких степенях `x²`, `x⁴`, `x⁶`, виводимо алгебраїчну систему рекурентних співвідношень:

```
c₂ = -α · [ g'(1) · (c₂ / α²) ]                                   [прирівнювання коефіцієнтів при x²]
c₄ = -α · [ g'(1) · (c₄ / α⁴) + (1/2) · g''(1) · (c₂ / α²)² ]       [прирівнювання коефіцієнтів при x⁴]
```

Виконуючи чисельне розв'язання цієї нелінійної системи методів Ньютона-Рафсона високого порядку (з урахуванням членів до `x²⁰`), отримуємо точні значення універсальних констант:

```
α = 2.502907875095892822283902873218...
c₂ = -1.52763299703371994247545934509...
c₄ = 0.10481429454655184085449733055...
c₆ = -0.02670577170133283256037083040...
c₈ = 0.00257326296317208034504543789...
```

Універсальна функція `g(x)` є цілою аналітичною функцією на всій комплексній площині, а коефіцієнт `α ≈ 2.5029` визначає універсальний масштаб геометрії хаосу.

## 3. Лінеаризація оператора та походження сталої δ

Щоб зрозуміти, звідки береться друга стала `δ ≈ 4.6692`, необхідно дослідити стійкість нерухомої точки `g(x)` у функціональному Банаховому просторі аналітичних функцій.

Нехай `f(x)` є невеликим збуренням нерухомої функції `g(x)`:

```
f(x) = g(x) + ε · h(x)
```

Застосуємо оператор перенормування `T` до близької функції `f(x)` і розкладемо результат за малим параметром `ε`:

```
T (g + ε · h)(x)
= -α · (g + ε · h)( (g + ε · h)(-x / α) )                           [підстановка f = g + ε h у формулу оператора T]
= -α · g( g(-x / α) + ε · h(-x / α) ) - α · ε · h( g(-x / α) )      [лінійний розклад за ε у першому порядку]
```

Використовуючи розклад Тейлора для першого доданка біля точки `g(-x / α)`, маємо:

```
g( g(-x / α) + ε · h(-x / α) )
= g(g(-x / α)) + ε · g'(g(-x / α)) · h(-x / α) + O(ε²)             [формула Тейлора першого порядку]
```

Підставивши це назад і згрупувавши члени першого порядку за `ε`, отримуємо **лінеаризований оператор перенормування** `L`, що діє на вектор збурення `h(x)`:

```
L h(x) = -α · g'( g(-x / α) ) · h(-x / α) - α · h( g(-x / α) )
```

### Спектральний аналіз та спектральний зазор

Знайдемо власні значення `λ` та власні функції `h(x)` лінеаризованого оператора `L`:

```
L h(x) = λ · h(x)
```

Чисельний та аналітичний спектральний аналіз оператора `L` у просторі симетричних аналітичних функцій показує фундаментальний результат:

1. **Єдине нестійке власне значення `λ₁ > 1`:**
   Існує **рівно одне** власне значення, модуль якого більший за одиницю:

   ```
   λ₁ = δ = 4.669201609102990671853203820466...
   ```

2. **Несуттєве власне значення `λ₂ = -α`:**
   Це власне значення відповідає просторовій зміні масштабу (координатній трансформації) і не впливає на параметричний каскад.

3. **Стійкі власні значення `|λ_k| < 1` (при k ≥ 3):**
   Усі інші нескінченно вимірні власні значення лежать усередині одиничного кола на комплексній площині: `|λ_k| < 1`.

### Матрична дискретизація лінеаризованого оператора

Для практичного обчислення спектра оператора `L` власний вектор збурення `h(x)` розкладається у базис парних поліномів Чебишова або степеней `x²k`:

```
h(x) = ∑ b_k · x²k
```

Підстановка цього базису в дію лінеаризованого оператора `L h(x)` перетворює нескінченно вимірне функціональне рівняння `L h = λ h` на скінченновимірну матричну проблему на власні значення `M · b = λ · b`, де елементи матриці `M[i, j]` обчислюються через коефіцієнти Тейлора функції `g(x)`.

Діагоналізація матриці `M` розмірністю `50 × 50` дає значення провідного власного значення `λ₁ = 4.6692016...` із точністю до 12 значущих цифр.

### Геометричний зміст ковимірності 1 та магістрального стиснення

Наявність **спектрального зазору** (spectral gap) між єдиним нестійким власним значенням `δ > 1` та всією рештою спектра `|λ_k| < 1` дає суворе пояснення феномену універсальності:

- Поверхня нерухомих точок `T g = g` у функціональному Банаховому просторі володіє стійким багатовидом `W^s` ковимірності 1.
- Будь-яка однопараметрична сім'я функцій `f(x, r)` утворює криву у функціональному просторі, яка трансверсально перетинає `W^s`.
- При дії оператора `Tⁿ` усі компоненти збурення вздовж стійких напрямків `W^s` придушуються зі швидкістю `|λ_k|ⁿ → 0`.
- Єдина невидалена компонента збурення вздовж нестійкого напрямку `W^u` зростає зі швидкістю `δⁿ`.

Отже, після багатьох кроків перенормування будь-яка початкова гладка функція втрачає свої індивідуальні риси й виходить на єдину універсальну нестійку траєкторію зі швидкістю розбіжності `δ = 4.6692016...`.

## 4. Теорема Ньютона-Канторовича та строге існування розв'язку

Для строгого математичного доведення існування нерухомої точки `g(x)` функціонального оператора `T` використовується **теорема Ньютона-Канторовича** у Банахових просторах.

Розглянемо нелінійне операторне рівняння `F(g) = T g - g = 0`. Нехай `g₀(x)` — наближений поліноміальний розклад ступеня 10. Якщо задовольнити три умови Ньютона-Канторовича:
1. Обернений оператор Фреше `[F'(g₀)]⁻¹` є обмеженим у нормах Банахового простору: `||[F'(g₀)]⁻¹|| ≤ B`;
2. Невозначений залишок у початковій точці є малим: `||F(g₀)|| ≤ η`;
3. Друга похідна Фреше задовольняє умову Ліпшиця: `||F''(g)|| ≤ K`;
і виконується нерівність Канторовича `h_K = B · K · η < 1/2`, то послідовність ітерацій Ньютона `g_{k+1} = g_k - [F'(g_k)]⁻¹ F(g_k)` суворо збігається до єдиного точного розв'язку `g*(x)` у кулі радіуса `r* = (1 - √(1 - 2 h_K)) / (B K)`.

Суворе виконання умов Ньютона-Канторовича доведено Ланфордом за допомогою точних інтервальних комп'ютерних оцінок, що повністю закрило питання про математичне існування універсальної функції Фейгенбаума.

## 5. Комплексний ренормалізм та жорсткість за Любичем

У сучасній математичній фізиці теорія ренормалізації розширена на комплексні динамічні системи. Якщо розглядати логістичне відображення `z[n+1] = z[n]² + c` на комплексній площині `ℂ`, каскад подвоєння періоду описує послідовність злиття зародків на дійсній осі знаменитої **множини Мандельброта**.

Математик Михайло Любич довів теорему про **комплексну жорсткість (complex rigidity)**:
1. Гранична функція Фейгенбаума `g(z)` допускає аналітичне продовження на комплексну область `Ω ⊂ ℂ`, яка є квадратично-подібним диском.
2. Оператор перенормування `T` є суворим стискаючим відображенням на гіперповерхні ковимірності 1 у метриці Коші-Рімана.
3. Фрактальна межа множини Мандельброта у точці накопичення біфуркацій `c_∞ ≈ -1.401155...` має точну геометричну самоподібність, яка визначається комплексною сталою `α ≈ -2.5029`.

### Банахові простори аналітичних функцій та операторна норма
Для суворого аналізу оператора `T` розглядається Банахів простір `B` функцій, аналітичних у замкненій кулі `D_R = { z ∈ ℂ : |z| ≤ R }` із нормою Супремуму:

```
||f|| = sup |f(z)|   при   z ∈ D_R
```

Оператор `T` є локально гіперболічним відображенням на `B`. Існування єдиного нестійкого напрямку доведено за допомогою оцінок конформних інваріантів та модулів ріманових поверхонь у гіперболічній геометрії.

## 6. Колле-Екманівська умова та ергодичні властивості

Математичний аналіз нелінійної динаміки в критичній точці `r_∞` вимагає вивчення похідної вздовж ітерацій точок екстремуму `x₀ = 0`.

Кажуть, що відображення задовольняє **умову Колле-Екмана (Collet-Eckmann condition)**, якщо похідна складеної функції вздовж орбіти екстремуму зростає експоненційно:

```
|(fⁿ)'(f(0))| ≥ C · e^(ξ · n)   для деяких C > 0, ξ > 0
```

Для універсальної нерухомої функції Фейгенбаума `g(x)` умова Колле-Екмана виконується з показником експоненційного зростання `ξ = ln(δ) / 2 ≈ 0.7707`. Це гарантує існування єдиної абсолютно неперервної інваріантної міри (ACIM) для хаотичного відображення на смугах атрактора.

## 7. Розрахунок фрактальної розмірності та спектра мультифрактальності

Фрактальний атрактор Фейгенбаума в точці `r_∞` описується не лише єдиною розмірністю `D₀ ≈ 0.538`, але й повною неперервною функцією **мультифрактального спектра** `f(α_m)`.

Функція пакування або обобщена розмірність Рені `D_q` обчислюється через термодинамічний формалізм:

```
τ(q) = (q - 1) · D_q
```

де `τ(q)` — вільна енергія решітки, яка визначається як провідне власне значення відповідного оператора переносу Перрона-Фробеніуса. Зміна `q` від `-∞` до `+∞` дає інтервал розмірностей від `D_{-∞} = 1` до `D_{+∞} = ln(2) / ln(α²) ≈ 0.378`, виказуючи глибоку невиразну сутність геометричного розподілу ймовірностей фазових траєкторій на атракторові.

## 8. Асимптотичні оцінки та числова збіжність

Математична обчислюваність нерухомої точки `g(x)` опирається на оцінку залишку Тейлорівського ряду `R_N(x)` при великих `N`:

```
|R_N(x)| ≤ K · (x / R)^N   де R ≈ 2.58
```

Ця оцінка демонструє надшвидку експоненційну збіжність поліноміальних наближень `g_N(x)` до точної функції `g*(x)`. Розрахунок 50 членів Тейлора дає змогу обчислити першу сталу Фейгенбаума `δ` з точністю до 30 значущих десяткових розрядів:

```
δ = 4.66920160910299067185320382046620161725818557743999...
```

## 9. Універсальність у Банахових функціональних просторах

Математичне значення методу ренормалізації полягає у тому, що він зводить аналіз складної часової динаміки окремого відображення до геометрії фазового простору самих математичних функцій. 

Нескінченновимірний функціональний простір `C²([-1, 1])` ділиться стійким багатовидом `W^s` на дві частини: область періодичних орбіт та область хаосу. Траєкторія ренормалізації `Tⁿ f` під дією ітерацій оператора перенормування приваблюється до одновимірного нестійкого багатовиду `W^u`, виказуючи повну втрату пам'яті системи про її початкові аналітичні деталі.

## 10. Топологічна спряженість і структура орбіт

Дві динамічні системи `f` та `h` називаються топологічно спряженими, якщо існує гомеоморфізм `h : I → I` такий, що `h(f(x)) = g(h(x))`. 

Теорія ренормалізації доводить, що всі одногорбі відображення з однаковим комбінаторним типом подвоєння періоду є топологічно спряженими на своїх атракторах. Гомеоморфізм спряження `h(x)` є гладким скрізь, окрім Канторової множини атрактора Фейгенбаума, де він проявляє сингулярну фрактальну структуру з гелдеровським покажчиком гладкості `γ = ln(2) / ln(α) ≈ 0.538`.

## 11. Спектральний аналіз нестійких багатовидів

Структура фазового простору біля нерухомої точки `g(x)` розшаровується на нестійкий багатовид `W^u(g)` вимірності 1 та стійкий багатовид `W^s(g)` нескінченної вимірності.

Вздовж нестійкого багатовиду `W^u(g)` однопараметрична сім'я `g_r(x)` рухається під дією оператора `T` за експоненційним законом `Tⁿ g_r ≈ g + (r - r_∞) · δⁿ · h₁(x)`, де `h₁(x)` — провідна власна функція з власним значенням `δ`. Це дає суворе математичне доведення геометричного звуження параметричних інтервалів `Δr_n ~ δ⁻ⁿ`.

## 12. Похідні Шварца та теорема про глобальне атрактування

Важливим інструментом аналізу стійкості періодичних орбіт одновимірних відображень є **похідна Шварца (Schwarzian derivative)** `S f(x)`:

```
S f(x) = f'''(x) / f'(x) - (3/2) · ( f''(x) / f'(x) )²
```

Якщо похідна Шварца є від'ємною `S f(x) < 0` на всьому інтервалі `[-1, 1]` (що виконується для логістичного відображення `S f(x) = -6 / (1 - 2x)² < 0` та синусоїдального відображення), то за теоремою Зінгера відображення `f(x)` може мати **не більше одного стійкого періодичного циклу**, і басейн притягання цього циклу містить точку критичного екстремуму `x = 0`. Від'ємність похідної Шварца зберігається при дії оператора перенормування `T`, гарантуючи єдиність стійкого каскаду біфуркацій.

## 13. Термодинамічний формалізм Рюеля

Зв'язок між теорією ренормалізації та статистичною механікою формалізується через **термодинамічний формалізм Дезьє Рюеля**.

Нехай `ϕ(x) = -ln |f'(x)|` — потенційна функція на Канторовій множині атрактора. Давлення Рюеля `P(t)` визначається як провідне власне значення оператора Перрона-Фробеніуса `L_t u(x) = ∑ u(y) / |f'(y)|^t`, де сума береться за всіма прообразами `f(y) = x`. Точка `t₀`, у якій давлення дорівнює нулю `P(t₀) = 0`, дає суворе точне значення Хаусдорфової розмірності `D₀ = t₀ ≈ 0.538`.

## 14. Класи універсальності за степенем максимуму

Універсальні сталі Фейгенбаума `δ ≈ 4.6692` та `α ≈ 2.5029` розраховані для одногорбих відображень із **квадратичним максимумом** (локальний екстремум ступеня `z = 2`).

Якщо розглянути відображення з іншим ступенем гладкості максимуму `z > 0`, де розклад у вершині має вигляд `f(x) = 1 - c · |x|^z`, функціональне рівняння Фейгенбаума набирає вигляду:

```
g(x) = -α · g( g( -x / α ) )   із умовою   g(x) = 1 - c · |x|^z + O(|x|^(z+1))
```

Для кожного ступеня `z` виникає свій власний **клас універсальності** з власними значеннями `δ(z)` та `α(z)`:

```
Ступінь z = 2 (квадратичний):   δ ≈ 4.6692016,   α ≈ 2.5029078
Ступінь z = 4 (квадратично-квадратичний):   δ ≈ 7.2846862,   α ≈ 1.6903020
Ступінь z = 6 (шостого степеня):   δ ≈ 9.2961825,   α ≈ 1.4677424
```

Більшість реальних фізичних систем (механічні маятники, конвекція, електронні контури, розсіяння світла) мають аналітичні потенціали й гладкі екстремуми з `z = 2`. Саме тому сталі `δ ≈ 4.6692` та `α ≈ 2.5029` зустрічаються у переважній більшості фізичних експериментів.
