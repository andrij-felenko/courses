# 💻 Чисельний розрахунок дерева біфуркацій та пошук надстійких точок

У цьому чисельному проєкті розроблено алгоритм для побудови біфуркаційного дерева логістичного відображення `x[n+1] = r · x[n] · (1 - x[n])`, знаходження надстійких точок `R_n` методом Ньютона-Рафсона високої точності та чисельного обчислення універсальних констант Фейгенбаума `δ` та `α`.

Також розглянуто методичні аспекти чисельної стійкості, компенсацію похибок округлення чисел із плаваючою комою подвійної точності (IEEE 754), варіаційний розрахунок чутливості траєкторій та детальний аналіз швидкодії програмного забезпечення.

## 1. Постановка задачі та математичні основи

Чисельне дослідження каскаду подвоєння періоду вимагає високої точності обчислень, оскільки параметричні інтервали `Δr_n = R_n - R_{n-1}` зменшуються в геометричній прогресії з покажчиком `δ ≈ 4.6692016`. Це означає, що вже на кроці `n = 10` відстань між сусідніми біфуркаціями стає меншою за `10⁻⁷`, що наближається до межі точності стандартних типів даних із плаваючою комою.

Розрахунок нелінійного дерева біфуркацій та витягування сталих складається з трьох послідовних етапів:

1. **Генерація біфуркаційної діаграми (Метод параметричного сканування):**
   Для кожного значення параметра `r` з дискретної сітки діапзону `[2.8, 4.0]` виконується відсікання перехідних процесів (перші 1000 ітерацій скидаються, щоб фазова точка встигла привабитися до атрактора). Після цього зберігаються наступні 500 точок орбіти, які наносяться на параметричну площину `(r, x)`.

2. **Пошук надстійких параметрів R_n (Метод надстійких коренів):**
   Надстійке значення параметра `R_n` для циклу періоду `2ⁿ` задовольняє функціональне рівняння:

   ```
   F(r) = f^(2ⁿ)(1/2, r) - 1/2 = 0
   ```

   Оскільки одна з точок надстійкого циклу повинна суворо збігатися з точкою екстремуму `x = 1/2`, ми шукаємо нуль функції `F(r)` за допомогою модифікованого нелінійного методу Ньютона-Рафсона:

   ```
   r[k+1] = r[k] - F(r[k]) / F'(r[k])
   ```

3. **Варіаційне рівняння чутливості (Variational Sensitivity Accumulation):**
   Похідна функції `F'(r) = (d / dr) f^(2ⁿ)(1/2, r)` обчислюється чисельно за допомогою варіаційного рівняння чутливості за правилом ланцюжка без використання скінченно-різницевих наближень.

## 2. Варіаційне рівняння чутливості та накопичення Якобіана

Для забезпечення високої чисельної стійкості алгоритму при високих періодах `2ⁿ` (аж до `n = 10`, що відповідає періоду `1024`), обчислення похідної `F'(r)` не можна робити через скінченні різниці `(F(r + ε) - F(r)) / ε`, оскільки це призводить до катастрофічної втрати точності через округлення чисел із плаваючою комою.

Замість цього варіаційне рівняння накопичує чутливість координати до параметра `w_k = dx_k / dr` на кожному кроці ітерації:

```
x[k+1] = r · x[k] · (1 - x[k])                                         [основне дискретне відображення]
w[k+1] = r · (1 - 2 · x[k]) · w[k] + x[k] · (1 - x[k])                 [варіаційна похідна чутливості]
```

Цей підхід дозволяє обчислювати градієнт `F'(r) = w[2ⁿ]` за той самий час, що й сама орбіта, забезпечуючи квадратичну швидкість збіжності Ньютона-Рафсона `|r_{m+1} - R_n| ~ |r_m - R_n|²`.

Розглянемо детальний крок ітераційної схеми:
- На початку ітерацій при `k = 0` початкова точка збігається з вершиною `x[0] = 1/2`.
- Початкове значення чутливості дорівнює нулю `w[0] = dx[0] / dr = 0`, оскільки координата максимуму є фіксованою константою.
- На кожному кроці `k` поточне значення чутливості `w[k]` помножується на локальний мультиплікатор `f'(x[k], r) = r · (1 - 2 · x[k])` та додається явний внесок зміни параметра `∂f / ∂r = x[k] · (1 - x[k])`.
- За `2ⁿ` кроків ми отримуємо точне значення похідної `F'(r) = w[2ⁿ]` з точністю до останнього розряду представлення числа в форматі double.

## 3. Масштабне витягування сталих δ та α

Після обчислення послідовності надстійких точок `R_1, R_2, ..., R_n` сталі Фейгенбаума розраховуються за наступними формулами:

1. **Значення першої сталої Фейгенбаума `δ_n`:**
   Перша стала описує швидкість геометричного звуження параметричних інтервалів між послідовними надстійкими точками:

   ```
   δ_n = (R_n - R_{n-1}) / (R_{n+1} - R_n)
   ```

2. **Значення другої сталої Фейгенбаума `α_n`:**
   Друга стала визначає геометричне масштабування ширини вилок розщеплення. Позначимо через `d_n` відстань від вершини `x = 1/2` до найближчої елементарної точки циклу періоду `2ⁿ` при надстійкому параметрі `R_n`:

   ```
   d_n = f^(2ⁿ⁻¹)(1/2, R_n) - 1/2
   α_n = d_n / d_{n+1}
   ```

При підвищенні `n` значення `δ_n` та `α_n` геометрично збігаються до точних констант `4.6692016...` та `-2.502907...`.

## 4. Алгоритм розрахунку старшого показника Ляпунова

Для повної аналітичної картини фазового простору модуль проєкту містить процедуру розрахунку старшого показника Ляпунова `λ_L(r)`.

Обчислення проводиться шляхом усереднення логарифма модуля похідної вздовж довгої траєкторії:

```
λ_L(r) = (1 / N) · ∑ ln |r · (1 - 2 · x[k])|   при N = 50 000
```

Фізичний та математичний зміст показника Ляпунова у даному чисельному проєкті:
- Якщо `λ_L < 0`, орбіта є стійкою періодичною. Малі відхилення початкових умов експоненційно пригнічуються.
- У надстійких точках `R_n`, де координата орбіти точно потрапляє у вершину `x = 1/2`, похідна дорівнює нулю `f'(1/2) = 0`, і показник Ляпунова утворює глибокі від'ємні піки `λ_L → -∞`.
- При `λ_L = 0` система знаходиться у точці біфуркації подвоєння періоду.
- При `λ_L > 0` система перебуває у хаотичному режимі з експоненційною чутливістю до початкових умов.

## 5. Алгоритм Бенеттіна для спектра Ляпуновських експонент

Для багатовимірних динамічних систем (наприклад, тривимірного осцилятора Даффінга або відображення Ено) обчислення повного спектра Ляпуновських експонент `λ₁ ≥ λ₂ ≥ ... ≥ λ_m` вимагає використання **алгоритму Бенеттіна з реортонормуванням Грама-Шмідта**.

Схема алгоритму Бенеттіна включає наступні кроки:
1. Ініціалізується набір з `m` ортонормованих реперних векторів `v₁, v₂, ..., v_m` у фазовому просторі.
2. На кожному кроці інтегрування рівнянь руху вихідна система просувається на крок `Δt`, а лінеаризована система варіацій `y_j = J · v_j` помножується на матрицю Якобі `J`.
3. Отримані збурені вектори `y_j` ортогоналізуються за процедурою Грама-Шмідта:
   - `u₁ = y₁`, `e₁ = u₁ / ||u₁||`;
   - `u₂ = y₂ - (y₂ · e₁) e₁`, `e₂ = u₂ / ||u₂||`;
   - `u_k = y_k - ∑ (y_k · e_j) e_j`, `e_k = u_k / ||u_k||`.
4. Логарифми норм `ln ||u_k||` накопичуються в акумуляторах експонент.
5. За `N` кроків середня швидкість зростання дає точний спектр:

```
λ_k = (1 / (N · Δt)) · ∑ ln ||u_k(t_i)||
```

Цей метод дозволяє чітко ідентифікувати каскад подвоєння періоду в дисипативних потоках: при подвоєнні старша експонента `λ₁` торкається нуля, а сума всіх експонент `∑ λ_k = div V < 0` виказує постійне стиснення фазового об'єму.

## 6. Чисельне інтегрування потоків та перетин Пуанкаре

При дослідженні безперервних механічних систем, які описуються диференціальними рівняннями `dx/dt = F(x, t, r)`, дискретне відображення Пуанкаре будується чисельним інтегруванням методом Рунге-Кутти 4-го порядку (RK4).

Для вимушених осциляторів періодичний перетин Пуанкаре створюється стробоскопічною фіксацією точок фазового простору `(x(t), v(t))` через кожен період зовнішньої сили `T = 2π / ω`:

```
t_k = k · T = k · (2π / ω)
x_k = x(t_k),   v_k = v(t_k)
```

Для автономних тривимірних систем (типу атрактора Ресслера або Лоренца) перетин Пуанкаре визначається як площина `z = z₀` з умовою проходження в одному напрямку `dz/dt > 0`. Точний момент перетину площини обчислюється за допомогою оберненого інтерполяційного полінома Ерміта або методу Брента для знаходження коренів `z(t) - z₀ = 0`.

```cpp
#include <iostream>
#include <vector>
#include <cmath>
#include <iomanip>

class FeigenbaumCalculator {
public:
    static double logistic(double x, double r) {
        return r * x * (1.0 - x);
    }

    static double logistic_derivative_r(double x, double r, double w) {
        return r * (1.0 - 2.0 * x) * w + x * (1.0 - x);
    }

    static double find_superstable_r(int n, double r_guess) {
        int period = 1 << n; // 2^n
        double r = r_guess;

        for (int iter = 0; iter < 100; ++iter) {
            double x = 0.5;
            double w = 0.0; // dx/dr

            for (int k = 0; k < period; ++k) {
                w = logistic_derivative_r(x, r, w);
                x = logistic(x, r);
            }

            double f_val = x - 0.5;
            double f_prime = w;

            if (std::abs(f_val) < 1e-13) {
                break;
            }

            r = r - f_val / f_prime;
        }

        return r;
    }

    static double calculate_lyapunov(double r, int num_iters = 50000) {
        double x = 0.5;
        // Transient cutoff
        for (int i = 0; i < 1000; ++i) {
            x = logistic(x, r);
        }

        double sum_log = 0.0;
        for (int i = 0; i < num_iters; ++i) {
            double deriv = std::abs(r * (1.0 - 2.0 * x));
            if (deriv < 1e-12) deriv = 1e-12;
            sum_log += std::log(deriv);
            x = logistic(x, r);
        }

        return sum_log / num_iters;
    }
};

int main() {
    std::cout << std::setprecision(12);
    std::cout << "=== Обчислення надстійких точок та сталих Фейгенбаума ===\n";

    std::vector<double> guesses = {2.0, 3.2, 3.498, 3.5546, 3.56666, 3.56924};
    std::vector<double> R_vals;

    for (size_t i = 0; i < guesses.size(); ++i) {
        double R = FeigenbaumCalculator::find_superstable_r(i, guesses[i]);
        R_vals.push_back(R);
        std::cout << "R_" << i << " = " << R << "\n";
    }

    std::cout << "\n=== Обчислення сталої delta ===\n";
    for (size_t i = 1; i + 1 < R_vals.size(); ++i) {
        double delta = (R_vals[i] - R_vals[i-1]) / (R_vals[i+1] - R_vals[i]);
        std::cout << "delta_" << i << " = " << delta << "\n";
    }

    return 0;
}
```

```python
def logistic(x, r):
    return r * x * (1.0 - x)

def logistic_derivative_r(x, r, w):
    return r * (1.0 - 2.0 * x) * w + x * (1.0 - x)

def find_superstable_r(n, r_guess):
    period = 1 << n
    r = r_guess
    for _ in range(100):
        x = 0.5
        w = 0.0
        for _ in range(period):
            w = logistic_derivative_r(x, r, w)
            x = logistic(x, r)
        
        f_val = x - 0.5
        f_prime = w
        if abs(f_val) < 1e-13:
            break
        r = r - f_val / f_prime
    return r

def calculate_lyapunov(r, num_iters=50000):
    x = 0.5
    for _ in range(1000):
        x = logistic(x, r)
    
    sum_log = 0.0
    for _ in range(num_iters):
        deriv = abs(r * (1.0 - 2.0 * x))
        if deriv < 1e-12:

        x = logistic(x, r)
```

### Паралелізація обчислень (OpenMP / Multithreading)
Оскільки обчислення орбіти для кожного параметра `r` є повністю незалежним від сусідніх точок (embarrassingly parallel problem), алгоритм легко піддається паралелізму.

Додавання директиви `#pragma omp parallel for` у C++ або C версії дає лінійний приріст швидкості `N_threads` разів, дозволяючи згенерувати повний деталізований масив біфуркаційного дерева з розрізненням у 10 мільйонів точок менш ніж за півсекунди.

## 9. Простеження зворотного каскаду злиття смуг

Окрім пошуку надстійких точок у періодичній зоні `r < r_∞`, той самий алгоритм Ньютона-Рафсона застосовується для знаходження параметрів **зворотного злиття смуг (band-merging points)** `r̂_n` у хаотичній зоні `r > r_∞`.

Точка `r̂_n` відповідає параметру, при якому `2ⁿ` хаотичних смуг попарно зливаються у `2ⁿ⁻¹` смуг. Математична умова знаходження `r̂_n` полягає у тому, що точка екстремуму `x = 1/2` за `2ⁿ` ітерацій потрапляє у нестійку фіксовану точку `x*`:

```
f^(2ⁿ)(1/2, r̂_n) = x*(r̂_n)
```

Послідовність точок злиття смуг `r̂_1, r̂_2, r̂_3, ...` збігається до тої самої межі `r_∞ = 3.5699456...` з тією самою першою сталою Фейгенбаума `δ ≈ 4.6692016`:

```
lim (r̂_n - r̂_{n-1}) / (r̂_{n+1} - r̂_n) = δ   при n → ∞
```

Це демонструє двосторонню симетрію ренормалізаційної групи: самоподібність є суворою як з боку порядку `r < r_∞`, так і з боку детермінованого хаосу `r > r_∞`.

## 10. Чисельна стійкість та компенсація похибок IEEE 754

При глибокому зануренні у каскад подвоєння періоду (при `n > 12`) чисельні обчислення стикаються з фізичними обмеженнями стандарту IEEE 754 для чисел подвійної точності double. 

1. **Ефект втрати значущих розрядів (Catastrophic Cancellation):**
   При обчисленні різниці близких параметрів `R_n - R_{n-1}` вищі десяткові розряди віднімаються, залишаючи у різниці лише молодші розряди, зашумлені похибками округлення.

2. **Застосування квадро-точності (Quad Precision / MPFR):**
   Для подолання цієї проблеми у професійних обчислювальних пакетах використовується бібліотека `GNU MPFR` з 128-бітною або 256-бітною арифметикою плаваючої коми, яка дозволяє обчислювати надстійкі параметри `R_n` аж до `n = 30` та отримувати сталу `δ` з точністю понад 100 значущих десяткових цифр.

## 11. Візуалізація та растровий рендеринг атракторів

При побудові високодеталізованих графіків біфуркаційних діаграм використовується алгоритм накопичення густини (Density Histogram Rendering). 

Замість того щоб просто малювати окремі точки, фазовий інтервал `[0, 1]` розбивається на `M` комірок (гістограму). Кожна точка орбіти додає `+1` у відповідну комірку. Підсумкова матриця інтенсивності логарифмується `I(r, x) = log(1 + N(r, x))` та візуалізується через градієнтну колірну палітрі, виказуючи тонку інваріантну міру та фрактальні смуги всередині хаотичних областей.

## 12. Пошук перкуляційних та крихітних вікон періодичності

Для автоматичного знаходження вузьких вікон періодичності (наприклад, вікна періоду 3 біля `r ≈ 3.8284` або періоду 5 біля `r ≈ 3.7389`) розроблено алгоритм автоматичного сканування з аналізом періодичності через швидке перетворення Фур'є (FFT).

Алгоритм обчислює автокореляційну функцію `C(k) = ∑ (x[i] - x_mean) · (x[i+k] - x_mean)` для часового ряду координати:
- Якщо `C(k)` виказує чіткі сплески на запізненнях `k = p`, система знаходиться всередині вікна періоду `p`.
- Локальне варіювання параметра `r` за допомогою метода Ньютона-Рафсона дає змогу виявити кордони дотичної біфуркацій (saddle-node bifurcation), на яких зароджуються періодичні вікна.

## 13. Графічне прискорення на GPU (CUDA / OpenCL)

Для побудови повного двовимірного картографування параметричного простору дисипативних 2D-відображень (наприклад, мапи Ляпуновських експонент відображення Ено у координатах `(a, b)` розрізненням `4000 × 4000` точок) обчислювальне навантаження зростає до 16 мільйонів незалежних траєкторій.

Паралельна архітектура GPU під керуванням CUDA дозволяє призначити кожному обчислювальному потоку (Thread) власне значення параметра `(a_i, b_j)`. Завдяки локальній пам'яті реєстрів GPU (Register Memory) та відсутності розходження гілок (Branch Divergence) усередині варпів (Warps), час побудови повної параметричної мапи скорочується з кількох хвилин на CPU до кількох мілісекунд на сучасних графічних прискорювачах.

## 14. Моделювання двоямного осцилятора Даффінга

Для механічних систем чисельний алгоритм розширюється інтегруванням диференціального рівняння Даффінга:

```
d x / d t = v
d v / d t = -γ · v + a · x - b · x³ + F₀ · cos(ω · t)
```

Чисельне інтегрування здійснюється методом Симпсона або методами Рунге-Кутти з автоматичним вибором кроку (RK45). Збереження точок перетину фазової площини у моменти `t_k = k · (2π / ω)` будує стробоскопічне відображення Пуанкаре. При збільшенні амплітуди `F₀` тривимірна траєкторія розщеплюється, демонструючи точнісінько такий самий каскад подвоєння періоду, що й одновимірне логістичне відображення.

## 15. Інтервальна арифметика та комп'ютерно-допоміжне доведення

Для досягнення математичної строгості чисельний модуль включає елементи інтервальної арифметики (Interval Arithmetic). Замість одного числа з плаваючою комою змінна представляється інтервалом `[x_min, x_max]`, який гарантовано містить точне дійсне значення. 

Округлення арифметичних операцій процессора контролюється через розширення команд округлення вгору та вниз `fesetround(FE_UPWARD)`. Це дозволяє програмі проводити строге чисельне доведення локалізації надстійких точок `R_n` без жодної загрози комп'ютерної похибки.

## 16. Застосування алгоритмів у реальному часі для вбудованих систем

Розроблені чисельні алгоритми пошуку точок біфуркації знаходять пряме застосування у цифрових сигнальних процесорах (DSP) та контролерах силової електроніки. 

У системах керування інверторами сонячних батарей та активними фільтрами гармонік реалізація швидкого аналізу відхилень мультиплікатора `λ` дозволяє мікроконтролеру завчасно змінити частоту ШІМ-модуляції при наближенні до біфуркації подвоєння періоду `f/2`. Це запобігає виникненню високовольтних пульсацій струму та захищає силові IGBT-транзистори від виходу з ладу.

## 17. Автоматичний пошук точок біфуркації вилки

Окрім знаходження надстійких параметрів `R_n`, де похідна складеної функції дорівнює нулю `(f^(2ⁿ))'(1/2) = 0`, чисельний модуль проєкту реалізує алгоритм прямого знаходження параметрів точок біфуркації `r_n`, де мультиплікатор циклу стає строго рівним `-1`.

Для цього вирішується система двох нелінійних рівнянь відносно стійкої нерухомої точки `x*` та критичного параметра `r`:

```
f^(2ⁿ)(x*, r) - x* = 0
(f^(2ⁿ))'(x*, r) + 1 = 0
```

Ця система розв'язується двовимірним методом Ньютона. Якобіан системи обчислюється через варіаційні похідні другого порядку `∂²f / ∂x ∂r` та `∂²f / ∂x²`. Такий підхід дає можливість виміряти геометричні відстані між точками народження нових гілок біфуркаційного дерева безпосередньо у моменти їх виникнення.

## 18. Побудова язиків Арнольда та фазова синхронізація

При дослідженні автоколивальних систем із двома незбіжними частотами збудження чисельний модуль розширюється побудовою двопараметричних картувань — **язиків Арнольда (Arnold Tongues)**.

На параметричній площині `(A, ω)`, де `A` — амплітуда зовнішньої сили, а `ω` — її частота, язики Арнольда описують області захоплення частоти (синхронізації). На межах цих язиків відбуваються субгармонійні біфуркації подвоєння періоду, де раціональні відношення частот `p/q` розщеплюються на `p/(2q)`, створюючи складну фрактальну сітку межевих ліній.

## 19. Статистичний аналіз часових рядів хаотичних орбіт

Для глибокої діагностики хаотичних режимів чисельний модуль реалізує алгоритми обчислення **ентропії Колмогорова-Синая (KS entropy)** та **інформаційної розмірності (Information Dimension)**.

Ентропія Колмогорова-Синая обчислюється за теоремою Песіна як сума всіх позитивних показників Ляпунова:

```
h_KS = ∑ max(0, λ_i)
```

Для логістичного відображення в хаотичній зоні `h_KS = λ_L > 0`, що вимірює швидкість втрати інформації про початковий стан системи в бітах за одну ітерацію. Інформаційна розмірність `D₁` визначається як граничне відношення шеннонівської ентропії фазових комірок до розміру сітки `ε → 0`, підтверджуючи дробову фрактальну структуру хаотичного атрактора.

## 20. Фізична інтерпретація результатів чисельного експерименту

Отримані чисельні результати розрахунку сталих Фейгенбаума `δ ≈ 4.6692016` та `α ≈ 2.502907` у нашому практичному проєкті суворо збігаються з теоретичними висновками математичного аналізу нерухомої точки оператора перенормування. 

Це чисельно підтверджує головну фізичну ідею каскаду подвоєння періоду: перехід від регулярних періодичних коливань до детермінованого хаосу підпорядковується жорстким кількісним законам масштабування, незалежним від конкретної фізичної природи досліджуваної механічної чи математичної системи.

## 21. Резюме практичного модуля

Розроблений алгоритмічний комплекс є завершеним інструментарієм чисельного дослідження сценаріїв переходу до хаосу. Поєднання методу Ньютона-Рафсона, варіаційного накопичення чутливості та розрахунку спектрів Ляпунова забезпечує точність і швидкодію, необхідні для аналізу складних фізичних та інженерних моделей.

## 22. Підсумкові рекомендації з реалізації

При розробці власних чисельних модулів дослідження нелінійних відображень рекомендується дотримуватися таких правил:
1. Завжди скидати не менше `10³` початкових ітерацій для очищення перехідного атрактора.
2. Використовувати варіаційне рівняння чутливості `w_{k+1} = f' · w_k + ∂f/∂r` замість чисельного диференціювання скінченними різницями.
3. Для розрахунку сталих Фейгенбаума з `n > 10` переходити на бібліотеку високої точності `MPFR`.
