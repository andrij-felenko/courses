# 🧮 Математичний апарат фазових портретів: лінеаризація, Якобіан та інваріанти

Фазовий портрет двовимірної автономної динамічної системи описується системою двох зв'язаних звичайних диференціальних рівнянь першого порядку. Узагальнений математичний запис такої системи в просторі станів має вигляд:

```
dq/dt = f(q, p)
dp/dt = g(q, p)
```

тут `q` — узагальнена координата, `p` — узагальнений імпульс (або швидкість `v = dq/dt`), а гладкі функції `f(q, p)` та `g(q, p)` задають компоненти фазового векторного поля `V(q, p) = (f, g)`.

---

### 1. Теорема Ліувілля та дівергенція фазового потоку

Розглянемо довільну область `D(0)` у фазовому просторі з початковою площею `A(0)`. Під дією фазового потоку кожен стан всередині цієї області зміщується вздовж своєї траєкторії, утворюючи з часом нову область `D(t)` з площею `A(t)`.

Швидкість зміни площі `A(t)` описується формулою Ейлера для деформації суцільного середовища через дівергенцію векторного поля `V`:

```
dA/dt = ∬_D div(V) dq dp
```

Обчислимо дівергенцію векторного поля `div(V)` для трьох фундаментальних фізичних випадків.

#### Випадок А: Гамільтонова (консервативна) система

Для ідеальної механічної системи без тертя з гамільтоніаном `H(q, p) = T(p) + U(q)` (де `T` — кінетична, `U` — потенціальна енергія), канонічні рівняння Гамільтона мають вигляд:

```
dq/dt =  ∂H / ∂p
dp/dt = -∂H / ∂q
```

Підставимо ці вирази у формулу дівергенції фазової швидкості:

```
div(V) = ∂(dq/dt)/∂q + ∂(dp/dt)/∂p
       = ∂( ∂H/∂p )/∂q + ∂( -∂H/∂q )/∂p
       = ∂²H / (∂q ∂p) - ∂²H / (∂p ∂q)      [за теоремою Шварца про рівність мішаних похідних]
       = 0
```

Оскільки `div(V) = 0`, інтеграл зміни площі дорівнює нулю:

```
dA/dt = ∬_D 0 dq dp = 0  ⇒  A(t) = A(0) = const
```

Це і є **теорема Ліувілля**: фазовий потік консервативної гамільтонової системи зберігає фазовий об'єм (у 2D — площу). Фазова рідина є строго нестискуваною.

#### Випадок Б: Дисипативна система з гармонічним тертям

Розглянемо осцилятор маси `m` з жорсткістю пружини `k` та коефіцієнтом лінійного тертя `γ > 0`:

```
dq/dt = p / m
dp/dt = -k·q - (γ/m)·p
```

Обчислимо дівергенцію векторного поля для такої дисипативної системи:

```
div(V) = ∂(p/m)/∂q + ∂(-k·q - γ·p/m)/∂p
       = 0 - γ/m                            [часткове диференціювання доданків по q та p]
       = -γ/m < 0                           [підсумовування похідних]
```

Оскільки дівергенція є від'ємною константою, підставимо її в диференціальне рівняння для площі:

```
dA/dt = ∬_D (-γ/m) dq dp
      = (-γ/m) · A(t)
```

Розв'язуючи це просте диференціальне рівняння методом розділення змінних:

```
dA / A = (-γ/m) dt
ln(A(t)/A(0)) = (-γ/m) · t
A(t) = A(0) · exp( -(γ/m) · t )
```

Отже, у дисипативній системі фазовий об'єм стискається експоненційно до нуля з часом. Це математично пояснює, чому фазові траєкторії дисипативних систем невідворотно стікаються до атракторів (точок рівноваги чи граничних циклів).

### 2. Лінеаризація біля точок рівноваги та матриця Якобі

Точка `M₀(q₀, p₀)` називається **точкою рівноваги** (або особливою точкою), якщо фазова швидкість у ній дорівнює нулю:

```
f(q₀, p₀) = 0
g(q₀, p₀) = 0
```

Щоб дослідити поведінку траєкторій у близькому околі особливої точки, введемо малі відхилення: `ξ = q - q₀` та `η = p - p₀`.

Розкладемо функції `f` та `g` у ряд Тейлора в околі точки `(q₀, p₀)` і обмежимося першими лінійними членами:

```
f(q, p) = f(q₀, p₀) + (∂f/∂q)|₀ · ξ + (∂f/∂p)|₀ · η + O(ξ² + η²)
g(q, p) = g(q₀, p₀) + (∂g/∂q)|₀ · ξ + (∂g/∂p)|₀ · η + O(ξ² + η²)
```

Оскільки `f(q₀, p₀) = 0` та `g(q₀, p₀) = 0`, лінеаризована система набуває матричного вигляду:

```
d/dt [ ξ ] = J · [ ξ ]
     [ η ]       [ η ]
```

де `J` — матриця Якобі (Якобіан) лінеаризованого векторного поля, обчислена в точці рівноваги:

```
J = [ a  b ] = [ (∂f/∂q)|₀   (∂f/∂p)|₀ ]
    [ c  d ]   [ (∂g/∂q)|₀   (∂g/∂p)|₀ ]
```

### 3. Характеристичне рівняння та власні значення

Шукаємо розв'язки лінеаризованої системи у формі експоненціальних анзаців: `ξ(t) = u · exp(λ·t)` та `η(t) = v · exp(λ·t)`.

Підстановка дає систему алгебраїчних рівнянь для власного вектора `(u, v)ᵀ` та власного значення `λ`:

```
(J - λ·I) · [ u ] = [ 0 ]
            [ v ]   [ 0 ]
```

Ненульовий розв'язок існує тоді й лише тоді, коли детермінант матриці `(J - λ·I)` дорівнює нулю:

```
det(J - λ·I) = det [ a - λ     b   ]
                   [   c     d - λ ]
             = (a - λ)(d - λ) - b·c
             = λ² - (a + d)·λ + (a·d - b·c)
             = 0
```

Уведемо два фундаментальних інваріанти матриці Якобі:
1. **Слід матриці (Trace):** `Tr(J) = a + d = ∂f/∂q + ∂g/∂p = div(V)`
2. **Детермінант (Determinant):** `Det(J) = a·d - b·c`

Тоді квадратне характеристичне рівняння записується у стислій формі:

```
λ² - Tr(J)·λ + Det(J) = 0
```

Корені характеристичного рівняння (власні значення `λ₁` та `λ₂`) виражаються дискримінантом `Δ = (Tr J)² - 4·Det(J)`:

```
λ₁,₂ = ( Tr(J) ± √( (Tr J)² - 4·Det(J) ) ) / 2
```

### 4. Повна математична класифікація особливих точок у 2D

Тип та стійкість особливої точки повністю визначаються знаками `Det(J)`, `Tr(J)` та дискримінанта `Δ`.

```
                  Det(J)
                    │
       Центр /      │       Вузол
       Фокуси       │    (нестійкий)
        Δ < 0       │       Δ > 0
                    │
───────────┼────────┼─────────── Tr(J)
 (стійкі)  │   O    │ (нестійкі)
           │        │
           │ СІДЛО  │
           │ Det < 0│
```

#### Клас 1: `Det(J) < 0` — Сідло (Saddle)

Якщо `Det(J) < 0`, то дискримінант `Δ = (Tr J)² - 4·Det(J) > 0` завжди додатний. Власні значення `λ₁` та `λ₂` є дійсними числами протилежних знаків:

```
λ₁ > 0 > λ₂
```

- **Фазова топологія:** Уздовж власного вектора, що відповідає `λ₂ < 0` (стійкий власно-векторний напрям), траєкторії експоненційно входять у точку рівноваги. Уздовж власного вектора для `λ₁ > 0` (нестійкий напрям) траєкторії експоненційно виходять з неї.
- **Сепаратриси:** Лінії власних векторів є сепаратрисами. Решта фазових траєкторій утворюють родину гіпербол.
- **Стійкість:** Сідло є завжди **нестійкою** особливою точкою.

#### Клас 2: `Det(J) > 0` та `Δ < 0` — Фокуси та Центр (Комплексно-спряжені корені)

Якщо `Δ = (Tr J)² - 4·Det(J) < 0`, власні значення є комплексно-спряженими парами: `λ₁,₂ = α ± i·ω`, де:

```
α = Re(λ) = Tr(J) / 2
ω = Im(λ) = √( 4·Det(J) - (Tr J)² ) / 2
```

Залежно від знака дійсної частини `α = Tr(J)/2`, маємо три підвипадки:

1. **`Tr(J) < 0` (α < 0) — Стійкий фокус (Stable Focus):**
   Розв'язок має вигляд: `ξ(t) = C · exp(α·t) · cos(ω·t + φ)`.
   Амплітуда експоненційно згасає `exp(α·t) → 0`, а кут закручується з частотою `ω`. Фазові траєкторії мають вигляд спіралей, що нескінченно закручуються всередину до особливої точки.

2. **`Tr(J) > 0` (α > 0) — Нестійкий фокус (Unstable Focus):**
   Амплітуда експоненційно зростає `exp(α·t) → ∞`. Фазові траєкторії є спіралями, що розкручуються назовні від особливої точки.

3. **`Tr(J) = 0` (α = 0) — Центр (Center):**
   Власні значення є суто уявними: `λ₁,₂ = ± i·ω`, де `ω = √(Det J)`.
   Загальний розв'язок є чисто періодичним: `ξ(t) = A · cos(ω·t + φ)`.
   Фазові траєкторії утворюють замкнені концентричні еліпси навколо особливої точки. Це характерно для консервативних гамільтонових систем.

#### Клас 3: `Det(J) > 0` та `Δ ≥ 0` — Вузли (Nodes)

Якщо `Δ ≥ 0`, власні значення `λ₁` та `λ₂` є дійсними числами одного знака:

1. **`Tr(J) < 0` (λ₂ ≤ λ₁ < 0) — Стійкий вузол (Stable Node):**
   Обидва значення від'ємні. Усі траєкторії експоненційно впадають у точку рівноваги. При `t → ∞` траєкторії торкаються власного вектора, що відповідає «повільнішому» власному значенню `λ₁` (меншому за модулем).

2. **`Tr(J) > 0` (λ₂ ≥ λ₁ > 0) — Нестійкий вузол (Unstable Node):**
   Обидва значення додатні. Усі траєкторії випромінюються з особливої точки назовні.

### 5. Теорема Хартмана-Гробмана та грубість систем

Теорема Хартмана-Гробмана (1959–1962) дає строге математичне виправдання використанню лінеаризації у нелінійних фізичних задачах.

> **Теорема Хартмана-Гробмана:** Якщо точка рівноваги `M₀` автономної системи є **гіперболічною** (тобто жодне з власних значений Якобіана `J` не має нульової дійсної частини: `Re(λᵢ) ≠ 0`), то існує гомеоморфізм (безперервне взаємно-однозначне відображення), який переводить траєкторії повної нелінійної системи в околі `M₀` у траєкторії лінеаризованої системи `dξ/dt = J·ξ`.

Це означає, що для сідла, стійких та нестійких фокусів і вузлів топологічна структура нелінійного фазового портрета в околі особливої точки є точним дзеркальним відображенням лінеаризованого портрета.

**Винятковий випадок (Центр):** Для центру `Re(λ) = Tr(J) = 0`, тобто дійсна частина дорівнює нулю (точка не є гіперболічною). У цьому випадку нелінійні члени вищого порядку `O(ξ²)` можуть перетворити ідеальний центр лінійного наближення на слабостійкий або слабонестійкий фокус у повній нелінійній системі. Тому центр є **негрубою** (структурно нестійкою) особливою точкою: як завгодно мале нелінійне збурення або тертя ламає топологію концентричних кіл.

### 6. Перші інтеграли руху та інваріантні поверхні

Скалярна функція `I(q, p)` називається **першим інтегралом руху** динамічної системи, якщо її значення зберігається незмінним уздовж будь-якої фазової траєкторії:

```
dI/dt = (∂I/∂q) · (dq/dt) + (∂I/∂p) · (dp/dt)       [диференціювання складеної функції двох змінних за часом]
      = (∂I/∂q) · f(q, p) + (∂I/∂p) · g(q, p)      [підстановка dq/dt = f та dp/dt = g]
      = 0                                           [умова збереження величини I вздовж траєкторії]
```

Вираз `(∂I/∂q)·f + (∂I/∂p)·g` являє собою **похідну Лі** функції `I` вздовж векторного поля `V = (f, g)`.

Усі фазові траєкторії консервативної системи лежать на лініях рівня першого інтеграла: `I(q, p) = C`, де `C` — довільна дійсна константа, що визначається початковими умовами. У фізичних системах першим інтегралом найчастіше виступає повна механічна енергія `H(q, p) = E`.

Якщо градієнт першого інтеграла `∇I = (∂I/∂q, ∂I/∂p)` не дорівнює нулю у даній точці, вектор фазової швидкості `V = (f, g)` є суворо ортогональним до градієнта `∇I`:

```
∇I · V = ∂I/∂q · f + ∂I/∂p · g = 0
```

Це геометрично пояснює, чому фазові траєкторії рухаються суворо вздовж ізоліній потенціального чи енергетичного рельєфу й ніколи не перетинають їх.

### 7. Гомоклінічні та гетероклінічні орбіти

У фазовому просторі особливу роль відіграють траєкторії, які з'єднують нестійкі сідлові точки між собою:

1. **Гомоклінічна орбіта (Homoclinic Loop):** Це траєкторія `γ(t)`, яка виходить із сідлової точки `M₀` при `t → -∞` і повертається у ту саму сідлову точку `M₀` при `t → +∞`. 
   - *Приклад:* Сепаратрисна петля нелінійного маятника при E = 2·m·g·L узята для одного окремого сідла.
2. **Гетероклінічна орбіта (Heteroclinic Trajectory):** Це траєкторія `γ(t)`, яка виходить з однієї сідлової точки `M₁` при `t → -∞` і прямує до іншої, відмінної сідлової точки `M₂` при `t → +∞`.
   - *Приклад:* Сепаратрисні лінії нелінійного маятника, що з'єднують сідла в точках `θ = -π` та `θ = +π`.

При наявності зовнішнього періодичного збурення `F(t) = γ · cos(ωt)` стійкі та нестійкі сепаратриси (монодроми) сідлових точок розщеплюються й утворюють нескінченну кількість трансуральних перетинів — так звану **гомоклінічну структуру Пуанкаре**. За теоремою Смейла про підкову, наявність трансверсальних гомоклінічних перетинів гарантує наявність у системі підсистеми з хаотичною динамікою (динамічним хаосом).

### 8. Асимптотична стійкість за Ляпуновим та функції Ляпунова

Прямий метод Ляпунова дозволяє дослідити стійкість особливої точки `M₀(0, 0)` без необхідності шукати розв'язки або обчислювати Якобіан.

Для цього будують знаковизначену скалярну **функцію Ляпунова** `V(q, p)`, яка задовольняє дві умови у деякому околі `D` особливої точки:
1. `V(q, p) > 0` для всіх `(q, p) ≠ (0, 0)`, та `V(0, 0) = 0` (функція є суворо додатньо визначеною).
2. Повна похідна за часом `dV/dt` вздовж фазових траєкторій є від'ємно визначеною:

```
dV/dt = (∂V/∂q) · f(q, p) + (∂V/∂p) · g(q, p) ≤ 0
```

> **Теорема Ляпунова про стійкість:** Якщо для точки рівноваги `M₀` існує суворо додатньо визначена функція Ляпунова `V(q, p)`, похідна якої за часом вздовж траєкторій системи є від'ємно напіввизначеною `dV/dt ≤ 0`, то точка рівноваги `M₀` є **стійкою за Ляпуновим**.

> **Теорема про асимптотичну стійкість:** Якщо похідна `dV/dt < 0` є суворо від'ємно визначеною для всіх `(q, p) ≠ (0, 0)`, то точка рівноваги `M₀` є **асимптотично стійкою** (усі фазові траєкторії в околі `D` експоненційно збігаються до `M₀`).

Геометрично функція Ляпунова `V(q, p) = C` задає родину вкладених замкнених поверхонь навколо точки рівноваги. Умова `dV/dt < 0` означає, що фазова траєкторія в кожній точці перетинає ці поверхні ззовні всередину, пробиваючи ізолінії й невідворотно спускаючись на дно «потенціальної воронки» `V = 0`.

### 9. Критерій Бендіксона та теорема Пуанкаре-Бендіксона

Для аналізу наявності замкнених траєкторій (граничних циклів чи концентрів) у двовимірному фазовому просторі застосовують два потужних теореми.

#### Критерій Бендіксона (заперечення існування циклів)

> **Критерій Бендіксона:** Якщо в простозв'язаній області `D` фазової площини дівергенція векторного поля `div(V) = ∂f/∂q + ∂g/∂p` зберігає сталий знак (не звертається в нуль і не змінює знак), то область `D` не містить жодної замкненої фазової траєкторії.

**Доведення (від супротивного):**
Припустимо, що в області `D` існує замкнена траєкторія `C`, яка обмежує область `S ⊂ D`. За теоремою Ґріна для циркуляції векторного поля уздовж закриту контуру `C`:

```
∮_C (f dp - g dq) = ∬_S ( ∂f/∂q + ∂g/∂p ) dq dp
                  = ∬_S div(V) dq dp
```

Але вздовж фазової траєкторії за означенням `dq = f dt` та `dp = g dt`, тому лівий підінтегральний вираз дорівнює нулю:

```
f dp - g dq = f(g dt) - g(f dt) = 0
```

Отже, ліва частина контурного інтеграла дорівнює `0`. Проте права частина є подвійним інтегралом від функції `div(V)`, яка за умовою зберігає сталий знак у всій області `S`. Інтеграл від функції сталого знака по додатній площі `S` не може дорівнювати нулю! Отримане суперечність доводить, що замкнена траєкторія `C` існувати не може.

#### Теорема Пуанкаре-Бендіксона (існування граничного циклу)

> **Теорема Пуанкаре-Бендіксона:** Нехай `K` — замкнена обмежена область на фазовій площині, яка не містить жодної особливої точки. Якщо якась фазова траєкторія `C⁺` входить у область `K` при `t → ∞` і ніколи з неї не виходить, то ця траєкторія або сама є замкненим граничним циклом, або спірально наближається до замкненого граничного циклу всередині `K`.

Ця теорема є фундаментальним фундаментом існування стійких самостійних автоколивань у двовимірних нелінійних фізичних та інженерних системах. Вона доводить, що двовимірний фазовий простір є надзвичайно впорядкованим: у ньому можливі лише точки рівноваги, замкнені цикли та сепаратриси, які їх з'єднують. Динамічний хаос у 2D просторі неможливий.
