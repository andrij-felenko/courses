# ⚙️ Обчислення та візуалізація фазового портрета: інтегрування методом Рунґе-Кутти

Побудова фазового портрета складних нелінійних фізичних систем практично ніколи не може бути виконана шляхом отримання простих точних аналітичних формул для залежності координати від часу `q(t)` та імпульсу від часу `p(t)`. Єдиним надійним та універсальним способом побудови цілісної картографії станів є чисельне інтегрування диференціальних рівнянь руху за допомогою обчислювальних алгоритмів та побудова векторного поля на дискретній сітці фазового простору.

У цій практичній вставці детально розібрано математичні основи, практичний устрій та повні програмні реалізації обчислювального двигуна для симуляції нелінійних динамічних систем. На прикладі нелінійного математичного маятника та автоколивального генератора Ван дер Поля показано, як обчислювати фазові траєкторії, генерувати векторну сітку та експортувати дані для створення якісних візуальних графіків.

### 1. Метод Рунґе-Кутти 4-го порядку (RK4) для двовимірного простору станів

Загальна задача чисельного моделювання двовимірної автономної динамічної системи зводиться до розв'язання векторного диференціального рівняння першого порядку:

```
d/dt [ q ] = [ f(q, p) ]
     [ p ]   [ g(q, p) ]
```

Позначимо вектор фазового стану як `X = (q, p)ᵀ`, а векторне поле фазової швидкості як `F(X) = (f(q, p), g(q, p))ᵀ`.

Якщо нам відомо стан системи `X_n = (q_n, p_n)ᵀ` у момент часу `t_n`, то алгоритм Рунґе-Кутти 4-го порядку (RK4) дає можливість знайти стан `X_{n+1}` у наступний момент часу `t_{n+1} = t_n + h` (де `h` — крок інтегрування за часом).

Обчислення здійснюється шляхом знаходження чотирьох проміжних векторів нахилу (фазових швидкостей):

1. **Перша оцінка `k₁`** — фазова швидкість на початку інтервалу:
   ```
   k₁ = F( X_n )
   ```
2. **Друга оцінка `k₂`** — фазова швидкість у середині інтервалу, обчислена за зміщенням на основі `k₁`:
   ```
   k₂ = F( X_n + (h/2) · k₁ )
   ```
3. **Третя оцінка `k₃`** — уточнена фазова швидкість у середині інтервалу, обчислена за зміщенням на основі `k₂`:
   ```
   k₃ = F( X_n + (h/2) · k₂ )
   ```
4. **Четверта оцінка `k₄`** — фазова швидкість наприкінці інтервалу, обчислена за зміщенням на основі `k₃`:
   ```
   k₄ = F( X_n + h · k₃ )
   ```

Підсумковий стан `X_{n+1}` обчислюється як зважена середня сума початкового стану та чотирьох проміжних векторів:

```
X_{n+1} = X_n + (h / 6) · ( k₁ + 2·k₂ + 2·k₃ + k₄ )
```

Математично метод RK4 має четвертий порядок локальної точності `O(h⁵)` та четвертий порядок глобальної точності `O(h⁴)`. Це означає, що при зменшенні кроку `h` удвічі похибка обчислення траєкторії зменшується в 16 разів! Саме така комбінація високої точності та помірних обчислювальних витрат робить метод RK4 золотим стандартом у фізичному та інженерному моделюванні.

### 3. Детальний аналіз реалізацій та архітектурних рішень

Кожна з трьох наведених реалізацій вирішує завдання побудови фазового портрета у відповідному програмному контексті.

#### Аналіз C-реалізації (`phase_portrait.c`)

У сишній реалізації ключовим елементом є універсальний прототип вказівника на функцію `VectorFieldFunc`:

```
typedef void (*VectorFieldFunc)(const PhaseState* state, const void* params, PhaseState* deriv);
```

Такий підхід дозволяє передавати в інтегратор `rk4_step` будь-яку фізичну модель без зміни самого коду інтегрування. Параметри моделі упаковано в структуру `PendulumParams` і передано через безнаковий вказівник `const void* params`.

Основні особливості:
- Виділення пам'яті для траєкторій відсутнє — дані одразу потоково записуються у файл формату CSV за допомогою `fprintf`. Це дозволяє симулювати мільйони кроків без ризику переповнення оперативної пам'яті.
- Для побудови сітки векторного поля функція `generate_vector_grid` ітерується по двох вкладених циклах по `q` та `p`, обчислюючи фазову швидкість `(dq/dt, dp/dt)` та модуль швидкості `magnitude = sqrt(dq² + dp²)`.

#### Аналіз C++-реалізації (`phase_portrait.cpp`)

У реалізації мовою C++20 застосовано сучасні патерни безпечного та чистого кодування:

- Перевантаження операторів `+` та `*` для структури `State` дозволило записати формулу кроку RK4 у майже математичному вигляді:
  ```cpp
  return current + (k1 + k2 * 2.0 + k3 * 2.0 + k4) * (h / 6.0);
  ```
- Патерн **RAII (Resource Acquisition Is Initialization)** втілено у класі `PhaseDataExporter`. Деструктор `std::ofstream` автоматично закриває файл навіть у разі виникнення виняткових ситуацій під час обчислень.
- Функція-фабрика `make_van_der_pol(double mu)` повертає лямбду з захопленням параметра нелінійності `mu`, що виключає необхідність використання небезпечних void-вказівників.

#### Аналіз Python-реалізації (`phase_plotter.py`)

Python-скрипт орієнтовано на швидкий аналіз та візуалізацію. Функція `scipy.integrate.solve_ivp` використовує адаптивний алгоритм RK45 (Рунґе-Кутти-Фільберга), який автоматично змінює крок `h` залежно від швидкості зміни поля.

Функція `plt.streamplot` виконує трасування векторних ліній поля з автоматичним розрахунком густини стрілок, що дозволяє отримати наочний фазовий портрет високої якості лише в кілька рядків коду.

### 4. Симплектичні інтегратори для консервативних систем

У тривалих фізичних симуляціях гамільтонових систем (наприклад, руху планет або маятника без тертя) стандартний метод RK4 проявляє несимплектичність: він не зберігає фазовий об'єм (теорему Ліувілля). Через чисельну дисипацію замкнені фазові кола консервативного маятника за тисячі періодів поступово розкручуються або згортаються.

Для суворого збереження фазової площі `dq dp = const` застосовують **симплектичний інтегратор Ейлера-Кромера (Euler-Cromer)**:

```
p_{n+1} = p_n + h · g(q_n, p_n)
q_{n+1} = q_n + h · f(q_n, p_{n+1})
```

Зверніть увагу: нове значення координати `q_{n+1}` обчислюється з використанням вже оновленого значення імпульсу `p_{n+1}`! Ця крихітна зміна забезпечує точне збереження фазового об'єму на кожному кроці й робить симплектичний інтегратор ідеальним для довгострокових астрономічних та механічних моделей.

### 5. Чисельне побудова сепаратрис зворотним інтегруванням

Сепаратриси сідлових точок є критичними межами фазового портрета. Пряме чисельне інтегрування від довільної початкової точки часто не дозволяє точно потрапити на сепаратрису, оскільки найменша чисельна похибка відштовхує траєкторію від нестійкої сепаратриси.

Для точної побудови сепаратрис застосовують **метод зворотного інтегрування у часі**:

1. **Точне обчислення сідлової точки `M₀(q₀, p₀)`:** Здійснюють розрахунок матриці Якобі `J` та знаходять її власні вектори `e₁` (для `λ₁ > 0`) та `e₂` (для `λ₂ < 0`).
2. **Побудова нестійкої сепаратриси `W^u`:** Вибирають початкову точку `X₀ = M₀ + ε · e₁` на відстані `ε = 1e-4` уздовж нестійкого власного вектора `e₁`. Інтегрують систему **вперед у часі** (`h > 0`).
3. **Побудова стійкої сепаратриси `W^s`:** Вибирають початкову точку `X₀ = M₀ + ε · e₂` на відстані `ε = 1e-4` уздовж стійкого власного вектора `e₂`. Інтегрують систему **назад у часі** (`h < 0`).

Зворотне інтегрування перетворює стійкий власновекторний напрямок на нестійкий, що дозволяє чисельному інтегратору «вилітати» з сідлової точки точно вздовж сепаратриси без накопичення чисельних нестійкостей.

### 6. Багатопотоковий розрахунок векторних сіток та SIMD векторна оптимізація

При побудові тривимірних або високої роздільної здатності `(1000 × 1000)` фазових полів у реальному часі масове обчислення векторів `(dq/dt, dp/dt)` стає серйозним обчислювальним вузьким місцем.

Для прискорення розрахунків у сучасних чисельних двигунах застосовують два рівні паралелізму:

1. **Багатопотоковий розрахунок через OpenMP / C++ `std::execution::par`:**
   Оскільки обчислення вектора фазової швидкості у кожній точці сітки `(q_i, p_j)` є повністю незалежним від інших точок, обчислювальний цикл ідеально масштабується по всіх ядрах процесора:
   ```cpp
   #pragma omp parallel for collapse(2)
   for (std::size_t i = 0; i < q_steps; ++i) {
       for (std::size_t j = 0; j < p_steps; ++j) {
           grid[i * p_steps + j] = compute_vector(q_min + i * dq, p_min + j * dp);
       }
   }
   ```
2. **Векторизація SIMD (AVX2 / AVX-512):**
   Сучасні процесори з підтримкою команд AVX2 здатні одночасно обчислювати чотири числа подвійної точності (`double`). Упаковка чотирьох сусідніх фазових станів у SIMD-файли дозволяє виконати один крок інтегрування RK4 одразу для чотирьох фазових траєкторій за одну інструкцію процесора, що дає 3.5-кратне чисте прискорення розрахунку.

### 7. Практичні пастки чисельного побудови фазових портретів

При чисельному обчисленні та побудові фазових портретів інженери та дослідники стикаються з трьома основними пастками.

#### Пастка 1: Витік енергії в консервативних системах (Несимплектичність)

У консервативних гамільтонових системах (таких як незагасаючий маятник або планетна орбіта) точна траєкторія має зберігати повну енергію `H(q, p) = E = const`.

Проте стандартний метод RK4 не є **симплектичним** інтегратором. Це означає, що при тривалому обчисленні (`t >> 1000` періодів) чисельна похибка накопичується так, що збереження фазового об'єму (теорема Ліувілля) порушується. У результаті замкнені фазові колата еліпси консервативного маятника під дією чисельної дисипації штучно розкручуються або згортаються у спіралі.

> 💡 **Рішення:** Для тривалих симуляцій консервативних фазових портретів використовують **симплектичні інтегратори** (наприклад, метод Ейлера-Кромера або метод Штьормера-Верле), які строго зберігають фазову площу `dq dp` на кожному кроці.

#### Пастка 2: Поведінка поблизу сепаратрис та сідлових точок (Жорсткість)

В околі сідлових точок фазова швидкість `V(q, p)` стрімко прямує до нуля, але власні значення `λ₁ > 0` та `λ₂ < 0` спричиняють сильне розходження сусідніх траєкторій.

При сталеному кроці інтегрування `h` траєкторія, яка має наближатися до сепаратриси, через чисельну похибку може перестрибнути через сепаратрису й потрапити в зовсім інший якісний режим руху (наприклад, з області коливань перестрибнути в область обертання).

> 💡 **Рішення:** Застосування адаптивного вибору кроку інтегрування (алгоритм Рунґе-Кутти-Фільберга RK45), який автоматично зменшує крок `h` в десятки разів при наближенні до сідлових точок.

#### Пастка 3: Густина сітки векторного поля

При візуалізації векторного поля (стрілок швидкостей) занадто густа сітка перетворює графік на суцільну чорну пляму, де неможливо розрізнити особливі точки. Занадто рідка сітка не дозволяє помітити дрібні особливості (наприклад, вузькі сепаратрисні петлі або локальні центри). Досвідченою нормою для якісних фазових графіків є роздільна здатність `25 × 25` або `30 × 30` векторів на квадратний екран.
