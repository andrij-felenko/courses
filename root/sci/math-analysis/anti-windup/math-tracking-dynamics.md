# 🧮 Динаміка інтегратора в режимі насичення та вибір сталої стеження Tt

Коли виконавчий механізм досягає фізичної межі (максимальної напруги, повного відкриття клапана чи 100% шпаруватості ШІМ), розривається головна передумова лінійної теорії керування: вихід системи більше не пропорційний сигналу з регулятора. У цьому стані лінійний інтегратор перетворюється на розімкнений накопичувач похибки, що неминуче призводить до інтегрального насичення (*windup*). Метод зворотного перерахунку (*back-calculation*) відновлює замкнену динаміку шляхом введення додаткового контуру стеження. Нижче наведено строгий математичний аналіз поведінки інтегратора в режимі насичення, виведення стаціонарного стану та критерії аналітичного вибору сталої часу стеження `T_t`.

### Математична модель ПІД-регулятора та оператора насичення

Розглянемо неперервний ПІД-регулятор із паралельною структурою. Вихідний керівний сигнал `u(t)` формується як сума пропорційної, інтегральної та диференціальної складових:

```
u(t) = u_p(t) + x_i(t) + u_d(t)
```

де `u_p(t) = K_p · e(t)` — пропорційна дія з коефіцієнтом підсилення `K_p`, `e(t) = r(t) - y(t)` — похибка керування між уставкою `r(t)` та виходом об'єкта `y(t)`, `u_d(t) = K_d · de(t)/dt` — диференціальна дія з коефіцієнтом `K_d`, а `x_i(t)` — стан інтегратора, динаміка якого за відсутності обмежень визначається диференціальним рівнянням:

```
dx_i/dt = (K_p / T_i) · e(t)
```

де `T_i` — стала часу інтегрування (у секундах).

Реальний виконавчий орган описується статичною нелінійністю типу «насичення» з симетричними або несиметричними межами `[u_min, u_max]`:

```
sat(u) = u_max, якщо u > u_max
       = u,     якщо u_min ≤ u ≤ u_max
       = u_min, якщо u < u_min
```

Сигнал неузгодженості виконавчого органу (похибка насичення) визначається як різниця між фактично реалізованим фізичним керуванням та розрахунковим ненасиченим виходом регулятора:

```
e_s(t) = sat(u(t)) - u(t)
```

У лінійній зоні `u_min ≤ u(t) ≤ u_max` значення `sat(u(t)) = u(t)`, тому `e_s(t) = 0`. Під час насичення на верхній межі (`u(t) > u_max`) похибка насичення набуває строго від'ємного значення: `e_s(t) = u_max - u(t) < 0`.

### Диференціальне рівняння інтегратора зі зворотним перерахунком

У схемі зворотного перерахунку сигнал неузгодженості `e_s(t)` заводиться на вхід інтегратора через коефіцієнт зворотного зв'язку `1 / T_t`, де `T_t > 0` — стала часу стеження (*tracking time constant*):

```
dx_i/dt = (K_p / T_i) · e(t) + (1 / T_t) · e_s(t)
```

Підставимо явний вираз для `e_s(t) = sat(u(t)) - u(t)` та вираз для розрахункового керування `u(t) = K_p · e(t) + x_i(t) + u_d(t)` у диференціальне рівняння інтегратора для випадку насичення на верхній межі (`sat(u(t)) = u_max`):

```
dx_i/dt = (K_p / T_i) · e(t) + (1 / T_t) · (u_max - (K_p · e(t) + x_i(t) + u_d(t)))
```

Розкриємо дужки та згрупуємо члени відносно стану `x_i(t)`:

```
dx_i/dt
= (K_p / T_i)·e(t) + (1/T_t)·u_max - (K_p/T_t)·e(t) - (1/T_t)·x_i(t) - (1/T_t)·u_d(t)  [розкриття дужок]
= -(1/T_t)·x_i(t) + (1/T_t)·u_max + K_p·(1/T_i - 1/T_t)·e(t) - (1/T_t)·u_d(t)         [групування за x_i]
```

Перенесемо лінійний член `(1 / T_t) · x_i(t)` у ліву частину:

```
dx_i/dt + (1 / T_t) · x_i(t) = (1 / T_t) · u_max + K_p · (1 / T_i - 1 / T_t) · e(t) - (1 / T_t) · u_d(t)
```

Це лінійне неоднорідне диференціальне рівняння першого порядку відносно змінної стану `x_i(t)`.

### Аналіз полюсів та власної динаміки в режимі насичення

Однорідне рівняння, що описує вільний рух інтегратора під час насичення, має вигляд:

```
dx_i/dt + (1 / T_t) · x_i(t) = 0
```

Характеристичне рівняння та його єдиний корінь (полюс замкненого контуру стеження):

```
s + 1 / T_t = 0  =>  s = -1 / T_t
```

Оскільки `T_t > 0`, полюс завжди лежить у лівій відкритій комплексній півплощині (`s < 0`). Це означає, що при виході в режим насичення вільний рух інтегратора є асимптотично стійким із власною сталою часу `τ = T_t`.

Без зворотного перерахунку (`T_t -> ∞`) диференціальне рівняння мало б вигляд `dx_i/dt = (K_p / T_i) · e(t)`, що відповідає полюсу в нулі `s = 0` (нейтральна межа стійкості, чистий інтегратор, який накопичує постійну похибку до нескінченності). Контур зворотного перерахунку переносить полюс із точки `s = 0` у точку `s = -1 / T_t`, перетворюючи чистий аперіодичний накопичувач на стійку аперіодичну фільтрувальну ланку першого порядку.

### Стаціонарний стан інтегратора під час тривалого насичення

Припустимо, що система увійшла в тривале насичення зі сталою або повільно змінюваною похибкою `e(t) = e_0 > 0`, коли перехідні процеси у диференціальній складовій уже згасли (`u_d(t) ≈ 0`). Знайдемо стаціонарне значення стану інтегратора `x_i,ss`, прирівнявши похідну `dx_i/dt` до нуля:

```
0 + (1 / T_t) · x_i,ss = (1 / T_t) · u_max + K_p · (1 / T_i - 1 / T_t) · e_0
```

Помножимо обидві частини рівняння на `T_t`:

```
x_i,ss
= u_max + K_p · T_t · (1 / T_i - 1 / T_t) · e_0   [множення на T_t]
= u_max + K_p · (T_t / T_i - 1) · e_0             [спрощення дужки]
```

Тепер обчислимо загальний розрахунковий вихід регулятора `u_ss` у цьому квазістаціонарному стані:

```
u_ss
= u_p + x_i,ss + u_d                                     [означення u]
= K_p · e_0 + u_max + K_p · (T_t / T_i - 1) · e_0 + 0    [підстановка x_i,ss]
= u_max + K_p · e_0 · (1 + T_t / T_i - 1)                [винесення K_p·e_0]
= u_max + (T_t / T_i) · K_p · e_0                        [остаточний вираз]
```

Цей фундаментальний результат розкриває точний фізичний зміст вибору співвідношення `T_t / T_i`:

1. **Класичний вибір `T_t = T_i`:**
   У цьому випадку `T_t / T_i - 1 = 0`, другий доданок обнуляється, звідки:
   ```
   x_i,ss = u_max
   u_ss = u_p + x_i,ss = K_p · e_0 + u_max
   ```
   Стан інтегратора фіксується точно на верхній межі насичення `u_max` (запобігаючи неконтрольованому зростанню інтегрального заряду), а повний ненасичений вихід регулятора перевищує `u_max` лише на величину пропорційної дії `K_p · e_0`. Коли похибка `e(t)` починає зменшуватися і спадає до нуля (`e -> 0`), пропорційний внесок зникає, і регулятор швидко повертається до лінійної зони без тривалого очікування розряду інтегратора.

2. **Миттєве стеження при `T_t -> 0`:**
   За формулою `u_ss = u_max + (T_t / T_i) · K_p · e_0`, для досягнення точної рівності повного виходу межі насичення (`u_ss = u_max`, тобто `x_i,ss = u_max - K_p · e_0`) потрібне гранично швидке стеження при `T_t -> 0`:
   ```
   x_i,ss = u_max - K_p · e_0
   u_ss = u_p + x_i,ss = K_p · e_0 + (u_max - K_p · e_0) = u_max
   ```
   У цьому ідеалізованому випадку розрахунковий вихід утримується строго на межі `u_max`. Якщо похибка починає спадати, вихід миттєво стає меншим за `u_max`, що забезпечує нульову затримку десатурації (*desaturation delay = 0*). Проте на практиці надмірне зменшення `T_t` (`T_t << T_i`) обмежене періодом квантування (`T_t > T_s / 2`) і може призвести до недонасичення інтегратора та передчасного спадання зусилля керування до того, як об'єкт досягне заданої траєкторії.

3. **Повільне стеження `T_t > T_i`:**
   У цьому випадку `(T_t / T_i - 1) > 0`, тому `x_i,ss > u_max`. Розряд інтегратора відбувається повільніше, і після тривалого насичення залишається розрахунковий надлишок `u_ss - u_max = (T_t / T_i) · K_p · e_0 > K_p · e_0`, що збільшує час виходу з насичення.

### Оптимальний вибір сталої часу Tt для ПІ- та ПІД-контурів

Для ПІ-регулятора (`K_d = 0`) оптимальним за критерієм мінімізації часу десатурації без створення паразитних коливань є точна рівність:

```
T_t = T_i
```

Для повного ПІД-регулятора з вираженою диференціальною дією вибір ускладнюється тим, що диференціальний член `u_d(t)` під час швидких змін похибки створює імпульсні сплески в сигналі `u(t)`. Згідно з рекомендаціями Карла Юхана Острема (*Karl Johan Åström*) та Торі Хеґґлунда (*Tore Hägglund*), для ПІД-регуляторів рекомендовано обирати:

```
T_t = √(T_i · T_d)
```

де `T_d = K_d / K_p` — стала часу диференціювання. Середнє геометричне між сталою інтегрування та сталою диференціювання забезпечує узгодження смуги пропускання контуру анти-windup із частотною характеристикою диференціатора. Якщо ж регулятор налаштовано з помірним диференціюванням (`T_d < 0.25 · T_i`), часто обирають діапазон:

```
0.5 · T_i ≤ T_t ≤ T_i
```

### Стійкість за Ляпуновим контуру розвантаження інтегратора

Доведемо асимптотичну стійкість точки спокою контуру стеження за Ляпуновим. Визначимо відхилення стану інтегратора від його цільового стаціонарного значення:

```
ε_i(t) = x_i(t) - x_i,ss
```

Диференціал похибки стану:

```
dε_i/dt = dx_i/dt - 0 = -(1 / T_t) · ε_i(t)
```

Виберемо додатньо визначену функцію Ляпунова:

```
V(ε_i) = 1/2 · ε_i²
```

Обчислимо повну похідну функції Ляпунова за часом уздовж траєкторій системи:

```
dV/dt = ε_i · (dε_i/dt) = ε_i · (-(1 / T_t) · ε_i) = -(1 / T_t) · ε_i²
```

Оскільки `T_t > 0`, похідна `dV/dt < 0` для всіх `ε_i ≠ 0` і `dV/dt = 0` тільки при `ε_i = 0`. Відповідно до теореми Ляпунова про асимптотичну стійкість, динаміка інтегратора в режимі насичення є глобально асимптотично стійкою, а стан `x_i(t)` експоненційно прямує до `x_i,ss` зі швидкістю не менше ніж `exp(-t / T_t)`.

### Дискретизація рівнянь для чисельної реалізації

Для реалізації в мікроконтролерах із періодом квантування `T_s` неперервне диференціальне рівняння інтегратора дискретизується методом Ейлера назад (*Backward Euler*):

```
(x_i[k] - x_i[k-1]) / T_s = (K_p / T_i) · e[k] + (1 / T_t) · (u_sat[k-1] - u[k-1])
```

Звідки розрахункова різницева формула для кроку `k`:

```
x_i[k] = x_i[k-1] + (K_p · T_s / T_i) · e[k] + (T_s / T_t) · (u_sat[k-1] - u[k-1])
```

Для забезпечення чисельної стійкості різницевого рівняння полюс дискретної системи `z = 1 - T_s / T_t` повинен лежати всередині одиничного кола на z-площині (`|z| < 1`), що накладає фундаментальне обмеження на вибір сталої стеження відносно кроку дискретизації:

```
|1 - T_s / T_t| < 1  =>  0 < T_s / T_t < 2  =>  T_t > T_s / 2
```

На практиці для якісної гладкої фільтрації завжди обирають `T_t ≥ 2 · T_s` (а зазвичай `T_t >> T_s`), що гарантує абсолютну стійкість і відсутність високочастотного числового брязкоту на межах насичення.
