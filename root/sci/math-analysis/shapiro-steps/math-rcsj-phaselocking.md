# 🧮 Математичне виведення рівняння RCSJ, фазового захоплення та ширин сходинок Шапіро

Математичний опис динаміки джозефсонівського переходу під дією постійного та змінного струмів зсуву спирається на еквівалентну схему RCSJ (англ. *Resistively and Capacitively Shunted Junction*). Розглянемо послідовне строге виведення дифрівняння фази, його безрозмірної форми, пертурбативного розв'язку, аналізу стійкості через подібність систем та формули для ширини сходинок Шапіро через функції Бесселя.

### 1. Виведення диференціального рівняння RCSJ моделі

Згідно з першим законом Кірхгофа, повний струм `I(t)`, що подається на перехід від зовнішніх джерел, розгалужується на три паралельні гілки: ємнісний струм `I_C(t)`, квазічастинковий резистивний струм `I_R(t)` та надпровідний куперівський струм `I_J(t)`:

```
I(t) = I_C(t) + I_R(t) + I_J(t)
```

Застосуємо фізичні співвідношення для кожного з елементів схеми:

```
I_C(t) = C · dV/dt               [ємнісний струм через напругу на конденсаторі C]
I_R(t) = V(t) / R                [закон Ома для квазічастинкового опору R]
I_J(t) = I_c · sin(φ)            [перше співвідношення Джозефсона через критичний струм I_c]
```

Напруга `V(t)` пов'язана зі швидкістю зміни фазової різниці `φ(t)` другим співвідношенням Джозефсона:

```
V(t) = (ħ / 2e) · dφ/dt
```

Підставимо напругу `V(t)` та її першу похідну за часом `dV/dt = (ħ / 2e) · d²φ/dt²` у вираз для повного струму:

```
I(t) = C · d/dt [ (ħ / 2e) · dφ/dt ] + (1/R) · [ (ħ / 2e) · dφ/dt ] + I_c · sin(φ)
     = (ħ · C / 2e) · d²φ/dt² + (ħ / 2e · R) · dφ/dt + I_c · sin(φ)
```

Зовнішній струм складається з постійної складової `I_dc` та гармонічної НВЧ складової `I_ac · sin(ω_rf · t)`:

```
(ħ · C / 2e) · d²φ/dt² + (ħ / 2e · R) · dφ/dt + I_c · sin(φ) = I_dc + I_ac · sin(ω_rf · t)
```

Це і є базове нелінійне диференціальне рівняння второго порядку для фази Джозефсона.

### 2. Безрозмірна форма та параметр Маккамбера–Стьюарта

Введемо безрозмірний час `τ` та безрозмірну частоту `Ω`:

```
ω_p = √( 2e · I_c / (ħ · C) )     [плазмова частота джозефсонівського переходу]
τ = ω_p · t                      [безрозмірний час]
Ω = ω_rf / ω_p                   [безрозмірна частота НВЧ поля]
i_dc = I_dc / I_c                [безрозмірний постійний струм]
i_ac = I_ac / I_c                [безрозмірна амплітуда змінного струму]
```

Похідні за часом перераховуються за правилом диференціювання складеної функції:

```
dφ/dt = dφ/dτ · (dτ/dt) = ω_p · dφ/dτ
d²φ/dt² = ω_p² · d²φ/dτ²
```

Підставимо ці вирази в рівняння RCSJ та поділимо обидві частини на `I_c`:

```
[ (ħ · C / 2e · I_c) · ω_p² ] · d²φ/dτ² + [ (ħ / 2e · R · I_c) · ω_p ] · dφ/dτ + sin(φ)
= i_dc + i_ac · sin(Ω · τ)
```

Оскільки `(ħ · C / 2e · I_c) · ω_p² = (ħ · C / 2e · I_c) · (2e · I_c / ħ · C) = 1`, коефіцієнт при другій похідній дорівнює одиниці. Коефіцієнт при першій похідній визначає згасання:

```
β_c = (2e · I_c · R² · C / ħ) = (ω_p · R · C)²    [параметр Маккамбера–Стьюарта]
1 / √β_c = ħ / (2e · R · I_c · √(ħ · C / 2e · I_c)) = ħ · ω_p / (2e · R · I_c)
```

Отже, безрозмірне рівняння RCSJ набуває вигляду:

```
d²φ/dτ² + (1 / √β_c) · dφ/dτ + sin(φ) = i_dc + i_ac · sin(Ω · τ)
```

У граничному випадку сильно дисипативного (передемпфованого) переходу, коли ємність мала (`β_c << 1`), інерційним членом `d²φ/dτ²` можна знехтувати. Перейшовши до відліку часу `t' = t / (R · C · β_c) = (2e · R · I_c / ħ) · t`, дістаємо стандартне рівняння першого порядку:

```
dφ/dt' + sin(φ) = i_dc + i_ac · sin(ω_rf' · t')
```

Аналітичний розв'язок цього рівняння за відсутності НВЧ поля (`i_ac = 0`) для `i_dc > 1` дає неперервну вольт-амперну характеристику:

```
⟨v⟩ = √(i_dc² - 1)
```

При наявності НВЧ поля цей вираз трансформується у пласки сходинки Шапіро, математичний розрахунок яких наведено нижче.

### 3. Пертурбативний аналіз та ширини сходинок Шапіро через функції Бесселя

Для аналітичного розрахунку ширин сходинок Шапіро припустимо, що напруга на переході задається зовнішнім джерелом з напругою (режим фіксованої напруги, англ. *voltage-bias regime*):

```
V(t) = V_0 + V_ac · cos(ω_rf · t)
```

Інтегруємо друге співвідношення Джозефсона `dφ/dt = (2e/ħ) · V(t)` за часом:

```
φ(t) = φ_0 + ∫ (2e/ħ) · [ V_0 + V_ac · cos(ω_rf · t) ] dt
     = φ_0 + (2e · V_0 / ħ) · t + (2e · V_ac / (ħ · ω_rf)) · sin(ω_rf · t)
```

Позначимо середню джозефсонівську частоту `ω_J = 2e · V_0 / ħ` та безрозмірний параметр амплітуди НВЧ напруги `x = 2e · V_ac / (ħ · ω_rf)`. Тоді кут дорівнює:

```
φ(t) = φ_0 + ω_J · t + x · sin(ω_rf · t)
```

Підставимо цю фазу у вираз для надпровідного струму `I_J(t) = I_c · sin(φ(t))`:

```
I_J(t) = I_c · sin( φ_0 + ω_J · t + x · sin(ω_rf · t) )
```

Використаємо відомий аналітичний розклад Якобі–Ангера для тригонометричних функцій від синусоїдального аргументу через функції Бесселя першого роду `J_n(x)`:

```
exp(i · x · sin(θ)) = Σ [n = -∞..+∞] J_n(x) · exp(i · n · θ)
```

Беручи уявну частину від комплексного розкладу, дістаємо вираз для струму:

```
I_J(t) = I_c · Σ [n = -∞..+∞] (-1)^n · J_n(x) · sin( φ_0 + (ω_J - n · ω_rf) · t )
```

Обчислимо середнє значення струму за часом `⟨I_J(t)⟩`. Усі осцилюючі члени з частотами `ω_J - n · ω_rf ≠ 0` усереднюються до нуля. Постійний струмовий внесок виникає тоді й лише тоді, коли джозефсонівська частота точно дорівнює гармоніці НВЧ поля:

```
ω_J = n · ω_rf
```

Що відповідає квантованій напрузі сходинки Шапіро `V_n = n · (ħ · ω_rf / 2e)`. При цьому резонансі часова залежність під синусом зникає, і постійний надструм на сходинці стає функцією початкової фази `φ_0`:

```
I_dc(n) = I_c · (-1)^n · J_n(x) · sin(φ_0)
```

Оскільки початкова фаза `φ_0` під дією зовнішнього струму зсуву може довільно змінюватися в межах від `-π/2` до `+π/2` (де `|sin(φ_0)| ≤ 1`), струм на сходинці номер `n` може набувати будь-яких значень у діапазоні від `-ΔI_n / 2` до `+ΔI_n / 2`.

Повна ширина струмового плато `n`-ї сходинки Шапіро `ΔI_n` становить:

```
ΔI_n = 2 · I_c · | J_n( 2e · V_ac / (ħ · ω_rf) ) |
```

Ця формула доводить, що ширини сходинок Шапіро осцилюють як абсолютні значення функцій Бесселя відповідного порядку від амплітуди НВЧ напруги. При значеннях `x`, які відповідають нулям функцій Бесселя (`J_n(x) = 0`), ширина відповідної сходинки прямує до нуля.

### 4. Розрахунок ширин сходинок у режимі заданого струму (Теорія збуджень)

У більшості експериментів джозефсонівський контакт живиться від джерела постійного струму (англ. *current-bias regime*), а не напруги. Для розрахунку ширин сходинок при `β_c = 0` застосуємо теорію збуджень за малою амплітудою НВЧ струму `i_ac << 1`.

Розкладемо фазу `φ(t)` у ряд за степенями малого параметра `i_ac`:

```
φ(t) = φ_0(t) + i_ac · φ_1(t) + O(i_ac²)
```

Незбуджений розв'язок `φ_0(t)` задовольняє рівнянню `dφ_0/dt' + sin(φ_0) = i_dc`. Рівняння для першої поправки `φ_1(t)` набуває вигляду:

```
dφ_1/dt' + cos(φ_0(t')) · φ_1 = sin(ω_rf' · t')
```

Інтегрування цього лінійного неоднорідного дифрівняння методом варіації довільної сталої дозволяє знайти зміщення границь сходинок за струмом:

```
Δi_n = 2 · | J_n( i_ac / ( Ω · √(i_dc² - 1) ) ) |
```

У граничному випадку високих частот НВЧ поля (`Ω >> 1`) цей розв'язок суворо збігається з виразом режима заданої напруги.

### 5. Стійкість граничних циклів та мультиплікатори Флоке

Для аналізу лінійної стійкості періодичного розв'язку фазового захоплення `φ_s(t) = φ_s(t + T_rf)` додамо мале збудження `δφ(t)` до стійкого граничного циклу:

```
φ(t) = φ_s(t) + δφ(t)
```

Підставивши цей вираз у безрозмірне рівняння RCSJ та виконавши лінеаризацію по малій величині `δφ`, дістаємо рівняння Хілла з періодичними коефіцієнтами:

```
d²(δφ)/dτ² + (1 / √β_c) · d(δφ)/dτ + cos(φ_s(τ)) · δφ = 0
```

Згідно з теорією Флоке, стійкість цього розв'язку визначається власне значеннями (мультиплікаторами Флоке `ρ₁, ρ₂`) оператора монодромії за один період НВЧ випромінювання `T = 2π / Ω`.

Оскільки визначник матриці монодромії дорівнює:

```
det(M) = ρ₁ · ρ₂ = exp( - T / √β_c ) < 1
```

система RCSJ є дисипативною. Розв'язок є лінійно стійким тоді й лише тоді, коли обидва мультиплікатори Флоке лежать усередині одиничного кола на комплексній площині (`|ρ_k| < 1`). Всередині язиків Арнольда ця умова виконується суворо, що гарантує абсолютну фізичну стійкість квантованих сходинок Шапіро.

### 6. Фрактальна розмірність та Число обертання (Winding Number)

Для повного опису динаміки фазового захоплення розглянемо відображення Пуанкаре (англ. *Poincaré map*) фази за один період НВЧ випромінювання `T = 2π / Ω`. Отримуємо одновимірне кругове відображення (англ. *circle map*):

```
θ_{k+1} = θ_k + Ω_0 - (K / 2π) · sin(2π · θ_k)   (mod 1)
```

Число обертання `W` (середня кутова швидкість) описується границею:

```
W = lim [k -> ∞] ( (θ_k - θ_0) / k )
```

Коли параметр нелінійності `K = 1`, інтервали фазового захоплення утворюють повну «драбину диявола». Сума довжин усіх плато сходинок Шапіро на інтервалі змінних струмів точно дорівнює 1, а фрактальна розмірність множини точок розриву між сходинками становить:

```
D_f ≈ 0.87
```

Це доводить, що сходинки Шапіро займають майже весь простір параметрів динамічної системи, забезпечуючи надійність квантового захоплення напруги в експериментах.
