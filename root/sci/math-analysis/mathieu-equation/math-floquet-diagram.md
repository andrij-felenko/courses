# 🧮 Математичний аналіз рівняння Матьє та теорія Флоке

Ця вставка містить строге математичне виведення властивостей рівняння Матьє, спектральну теорію Флоке для диференціальних рівнянь із періодичними коефіцієнтами, доведення існування матриці монодромії, а також тридіагональний метод нескінченних ланцюгових дробів для розрахунку меж областей стійкості (кривих Інса — Стратта).

Канонічна форма диференціального рівняння Матьє має вигляд:

```
d²y/dz² + (a - 2·q·cos(2·z)) · y = 0
```

де `z ∈ ℝ` — незалежна змінна, `a ∈ ℝ` — параметр відношення частот (спектральний параметр), `q ∈ ℝ` — параметр амплітуди модуляції.

Оскільки коефіцієнт `p(z) = a - 2·q·cos(2·z)` є парною неперервною функцією з періодом `T = π` (`p(z + π) = p(z)`), рівняння належить до класу диференціальних рівнянь Гілла второго порядку.

## Перехід до систем першого порядку та монодромія

Перетворимо рівняння второго порядку на систему двох диференціальних рівнянь першого порядку. Ввівши вектор стану `Y(z) = [y(z), dy/dz]ᵀ`, отримуємо матричне рівняння:

```
dY/dz = A(z) · Y(z)
```

де матриця коефіцієнтів дорівнює:

```
A(z) = [       0                 1      ]
       [ -(a - 2·q·cos(2·z))    0      ]
```

Зауважимо, що слід матриці дорівнює нулю для всіх `z`: `Tr(A(z)) = 0 + 0 = 0`.

Нехай `Φ(z)` — фундаментальна матриця розв'язків, яка задовольняє початкову умову `Φ(0) = I` (одинична матриця `2×2`). Тобто першим стовпчиком `Φ(z)` є розв'язок `y_1(z)` з початковими умовами `y_1(0) = 1, y_1'(0) = 0`, а другим стовпчиком — розв'язок `y_2(z)` з умовами `y_2(0) = 0, y_2'(0) = 1`.

За формулою Остроградського — Ліувілля — Якобі визначник фундаментальної матриці (Вронськіан розв'язків `W(z) = det(Φ(z))`) дорівнює:

```
W(z) = W(0) · exp(∫₀ⁿ Tr(A(s)) ds)   [формула Остроградського — Ліувілля]
     = 1 · exp(0)                     [початкова умова W(0)=1 та Tr(A(s))=0]
     = 1                              [тотожність exp(0)=1]
```

Отже, Вронськіан систем зліченно зберігається й дорівнює `1` для будь-якого `z`.

Матриця `M = Φ(π)`, отримана інтегруванням фундаментальної системи на одному повному періоді коефіцієнтів `T = π`, називається **матрицею монодромії** (або оператором переходу за період).

## Доведення теореми Флоке

Сформулюємо та доведемо теорему Флоке для двовимірної системи з `π`-періодичною матрицею `A(z + π) = A(z)`.

Оскільки фундаментальна матриця `Φ(z)` задовольняє рівняння `dΦ/dz = A(z) · Φ(z)`, то через періодичність матриці `A(z + π) = A(z)` функція `Ψ(z) = Φ(z + π)` також є фундаментальною матрицею розв'язків тієї самої системи.

Оскільки стовпчики `Φ(z)` утворюють базис простору розв'язків, існує неособлива постійна матриця `M` така, що:

```
Φ(z + π) = Φ(z) · M                   [властивість фундаментальної матриці]
```

Підставивши `z = 0` та врахувавши початкову умову `Φ(0) = I`, маємо:

```
Φ(π) = Φ(0) · M = I · M = M           [визначення матриці монодромії]
```

Враховуючи, що `det(M) = det(Φ(π)) = 1 ≠ 0`, матриця `M` є неособливою. За теоремою про матричний логарифм існує постійна матриця `R` така, що `M = e^(R·π)`.

Введемо нову матричну функцію `P(z) = Φ(z) · e^(-R·z)`. Перевіримо її періодичність:

```
P(z + π) = Φ(z + π) · e^(-R·(z + π))  [заміна аргументу]
         = Φ(z) · M · e^(-R·π) · e^(-R·z) [властивість Φ(z+π)=Φ(z)·M]
         = Φ(z) · e^(R·π) · e^(-R·π) · e^(-R·z) [підстановка M=e^(R·π)]
         = Φ(z) · e^(-R·z) = P(z)     [скорочення матричних експонент]
```

Отже, матрична функція `P(z)` є строго `π`-періодичною `P(z + π) = P(z)`. Це завершує доведення теореми Флоке: фундаментальна матриця розв'язків будь-якої лінійної періодичної системи подається у формі `Φ(z) = P(z) · e^(R·z)`.

## Множники та показники Флоке: умова стійкості

Власні значення матриці монодромії `λ` називаються **множниками Флоке** (англ. *Floquet multipliers*), а власні значення матриці `R` позначимо як `μ` (**показники Флоке**, де `λ = e^(μ·π)`).

Характеристичне рівняння для власних значень матриці монодромії `λ` має вигляд:

```
det(M - λ·I) = 0                       [визначник лінійного оператора]
⇒ λ² - Tr(M)·λ + det(M) = 0            [теорема Гамільтона — Келі для 2×2]
```

Оскільки `det(M) = det(Φ(π)) = 1`, характеристичний член спрощується до:

```
λ² - 2·D·λ + 1 = 0                     [позначення D = Tr(M)/2]
```

де `D = Tr(M) / 2 = (y_1(π) + y_2'(π)) / 2` — півслід матриці монодромії.

Корені цього квадратного рівняння є множниками Флоке `λ_1, λ_2`:

```
λ_{1,2} = D ± √(D² - 1)                [розв'язок квадратного рівняння]
```

Оскільки добуток коренів `λ_1 · λ_2 = 1`, можливі три принципово різні математичні режими залежно від значення півсліду `D`:

1. **Область стійкості (`|D| < 1`):** Дискримінант `D² - 1 < 0`. Власні значення є комплексно-спряженими числами, що лежать строго на одиничному колі комплексної площини: `λ_{1,2} = e^(± i·ν·π)`, де `ν ∈ ℝ` — дійсне число (характеристичний показник). Усі розв'язки є обмеженими квазіперіодичними функціями:
   ```
   y(z) = c_1 · e^(i·ν·z) · P_1(z) + c_2 · e^(-i·ν·z) · P_2(z)
   ```
   де `P_1, P_2` мають період `π`.

2. **Область нестійкості / Параметричний резонанс (`|D| > 1`):** Дискримінант `D² - 1 > 0`. Власні значення є дійсними, причому одне за модулем більше одиниці: `|λ_1| > 1`, а друге менше: `|λ_2| < 1`. Представляючи `λ_1 = ± e^(μ·π)` з дійсним `μ > 0` (**дійсний показник Флоке**), отримуємо розв'язок з експоненційним зростанням амплітуди:
   ```
   y(z) = c_1 · e^(μ·z) · P_1(z) + c_2 · e^(-μ·z) · P_2(z)
   ```
   При `z -> ∞` член `e^(μ·z)` прямує до нескінченності, створюючи параметричний вибух коливань.

3. **Межа стійкості (`|D| = 1`):** Множники Флоке дорівнюють `λ = +1` або `λ = -1`. При `λ = +1` розв'язок має період `π`; при `λ = -1` розв'язок має період `2·π` (антиперіодичний розв'язок з періодом `π`). Саме ці межі визначають криві `a_n(q)` та `b_n(q)` на діаграмі Інса — Стратта.

## Побудова функцій Матьє та спектральна задача

На межах областей стійкості розв'язками рівняння Матьє є періодичні функцій — **функції Матьє**:
* Парні розв'язки косинусоїдального типу: `ce_n(z, q)` (лат. *cosine-elliptic*).
* Непарні розв'язки синусоїдального типу: `se_n(z, q)` (лат. *sine-elliptic*).

Розкладемо періодичний розв'язок `y(z)` у ряд Фур'є.

### Парні розв'язки періоду π (криві a₂ₙ)

Для парного розв'язку з періодом `π` розклад Фур'є містить лише парні гармоніки:

```
y(z) = ∑_{k=0}^∞ A_{2k} · cos(2k·z)
```

Підставивши цей ряд у рівняння Матьє та звівши добутки косинусів `2·cos(2z)·cos(2kz) = cos((2k+2)z) + cos((2k-2)z)`, після прирівняння коефіцієнтів при однакових гармоніках `cos(2kz)` отримуємо тридіагональну систему алгебраїчних рівнянь:

```
a · A_0 - q · A_2 = 0                               [гармоніка k = 0]
(a - 4) · A_2 - q · (2·A_0 + A_4) = 0                [гармоніка k = 1]
(a - 4k²) · A_{2k} - q · (A_{2k-2} + A_{2k+2}) = 0   [гармоніки k ≥ 2]
```

Для існування ненульового розв'язку вектор коефіцієнтів `[A_0, A_2, A_4, ...]` повинен мати нульовий визначник матриці коефіцієнтів.

### Метод ланцюгових дробів (метод Інса)

Поділивши `k`-те рівняння системи на `q · A_{2k}`, введемо відношення сусідніх коефіцієнтів `R_{2k} = A_{2k+2} / A_{2k}`. Рекурентна система набуває вигляду:

```
(a - 4k²) / q - R_{2k-2}⁻¹ - R_{2k} = 0             [нормування на q·A_{2k}]
```

Звідси відношення `R_{2k}` виражається у вигляді нескінченного ланцюгового дробу:

```
R_{2k} = q / (a - 4(k+1)² - q · R_{2k+2})            [рекурентна формула]
       = q / (a - 4(k+1)² - q² / (a - 4(k+2)² - ...)) [послідовна підстановка R_{2k+2}]
```

Для перших коефіцієнтів `k = 0` маємо з першого рівняння `A_2 / A_0 = a / q`. З іншого боку, з рекурентного ланцюгового дробу `A_2 / A_0 = R_0`. Прирівнюючи обидва вирази, отримуємо точне трансцендентне рівняння для власних значень `a_2n(q)`:

```
a = q² / (a - 4 - q² / (a - 16 - q² / (a - 36 - ...)))  [умова збіжності ланцюгового дробу]
```

Цей чисельний метод ланцюгових дробів збігається надзвичайно швидко й дозволяє обчислювати власні значення `a_2n(q)` та `b_n(q)` із машинною точністю `10⁻¹⁶` всього за 10–15 ітерацій.

## Асимптотичні розклади за малим параметром q

При малих значеннях амплітуди модуляції `q ≪ 1` власні значення `a` можна розкласти в степеневий ряд за теорією збурень:

```
a(q) = a⁰ + q · a¹ + q² · a² + q³ · a³ + ...
```

Застосовуючи метод збурень до тридіагональних рекурентних співвідношень, отримуємо наступні асимптотичні формули для межевих кривих:

```
a₀(q) = -q²/2 + q⁴/128 - q⁶/9216 + O(q⁸)

b₁(q) = 1 - q - q²/8 + q³/64 - q⁴/1536 - 11·q⁵/36864 + O(q⁶)

a₁(q) = 1 + q - q²/8 - q³/64 - q⁴/1536 + 11·q⁵/36864 + O(q⁶)

b₂(q) = 4 - q²/12 + 5·q⁴/13824 - 7·q⁶/1244160 + O(q⁸)

a₂(q) = 4 + 5·q²/12 - 11·q⁴/13824 + 987·q⁶/161243136 + O(q⁸)

b₃(q) = 9 - q²/16 + q⁴/640 + O(q⁶)

a₃(q) = 9 + q²/16 - q⁴/640 + O(q⁶)
```

Аналіз цих формул показує важливий фізичний результат:
* Ширина головного язика параметричного резонансу (`n = 1`) при малих `q` дорівнює `Δa = a₁(q) - b₁(q) = 2·q - q³/32 + O(q⁵)`. Тобто ширина першої зони нестійкості є **лінійною** за амплітудою модуляції `q`.
* Ширина другого язика (`n = 2`) дорівнює `Δa = a₂(q) - b₂(q) = (5/6)·q² - (7/1152)·q⁴ + O(q⁶)`, тобто є **квадратичною** за `q`.
* Ширина третього язика (`n = 3`) дорівнює `Δa = a₃(q) - b₃(q) = (1/8)·q³ + O(q⁵)`, тобто є **кубічною** за `q`.

Саме тому в реальних фізичних та механічних системах найлегше розлущити та найнебезпечніше прогледіти саме першу (головну) зону параметричного резонансу на частоті збудження `Ω ≈ 2·ω_0`.
