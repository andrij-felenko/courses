# 🧮 Математична структура та властивості оператора Шварца

Оператор Шварца (похідна Шварца) — це нелінійне диференціальне співвідношення третього порядку, яке вимірює відхилення гладкої функції від дробово-лінійного перетворення Мьобіуса. У той час як перша похідна `f'(x)` задає локальний масштаб розтягування інтервалу, а друга похідна `f''(x)` оцінює кривизну та локальну нелінійність, третя похідна `f'''(x)` у комбінації із квадратом другої похідної створює комбінацію, що володіє унікальною геометричною симетрією.

Класичне означення похідної Шварца для тричі диференційованої функції `f(x)` має вигляд:

```
S(f)(x) = f'''(x) / f'(x) - (3/2) · (f''(x) / f'(x))²
```

Цей оператор має також просте й природне вираження через логарифмічну похідну локального масштабу `v(x) = ln|f'(x)|`. Величезна перевага логарифмічної форми полягає у фізичній наочності: вона показує, що оператор Шварца є різницею між другою похідною логарифма швидкості розтягу та половиною квадрата його першої похідної. Обчислимо похідні від `v(x)`:

```
v'(x) = f''(x) / f'(x)
v''(x) = (f'''(x)·f'(x) - (f''(x))²) / (f'(x))² = f'''(x)/f'(x) - (f''(x)/f'(x))²
```

Підставляючи ці вирази в означення похідної Шварца, отримуємо еквівалентну форму через логарифмічне прискорення та швидкість зміщення масштабу:

```
S(f)(x)
= v''(x) - (1/2) · (v'(x))²    [зведення логарифмічних похідних]
```

## 1. Доведення інваріантності відносно перетворень Мьобіуса

Головною алгебраїчною та геометричною властивістю оператора Шварца є його повна інваріантність відносно дробово-лінійних перетворень групи `SL(2,ℝ)` або `SL(2,ℂ)`. Розглянемо загальне перетворення Мьобіуса:

```
M(x) = (a·x + b) / (c·x + d),    де a·d - b·c ≠ 0
```

Обчислимо послідовні похідні функції `M(x)` за допомогою стандартного диференціювання частки двох лінійних функцій:

```
M'(x)
= (a·(c·x + d) - c·(a·x + b)) / (c·x + d)²    [диференціювання частки]
= (a·d - b·c) / (c·x + d)²                    [розкриття дужок у чисельнику]

M''(x)
= -2·c·(a·d - b·c) / (c·x + d)³               [диференціювання знаменника у квадраті]

M'''(x)
= 6·c²·(a·d - b·c) / (c·x + d)⁴               [повторне диференціювання за x]
```

Тепер знайдемо співвідношення похідних, необхідні для формування оператора Шварца:

```
M'''(x) / M'(x)
= (6·c²·(a·d - b·c) / (c·x + d)⁴) / ((a·d - b·c) / (c·x + d)²)
= 6·c² / (c·x + d)²    [скорочення спільного множника (ad - bc)]

M''(x) / M'(x)
= (-2·c·(a·d - b·c) / (c·x + d)³) / ((a·d - b·c) / (c·x + d)²)
= -2·c / (c·x + d)     [скорочення степенів знаменника]
```

Підставляємо знахідки в оператор Шварца:

```
S(M)(x)
= M'''(x) / M'(x) - (3/2) · (M''(x) / M'(x))²
= 6·c² / (c·x + d)² - (3/2) · (-2·c / (c·x + d))²    [підстановка виразів]
= 6·c² / (c·x + d)² - (3/2) · (4·c² / (c·x + d)²)    [піднесення до квадрата]
= 6·c² / (c·x + d)² - 6·c² / (c·x + d)²              [множення 3/2 · 4 = 6]
= 0                                                   [тотожне обнулення]
```

Отже, похідна Шварца будь-якого дробово-лінійного перетворення тотожно дорівнює нулю. Більше того, якщо `S(f)(x) = 0` на деякому інтервалі, то функція `f(x)` обов'язково є дробово-лінійною.

## 2. Ланцюгове правило (Chain Rule) та неевклідова геометрія

Для суперпозиції двох гладких функцій `(f ∘ g)(x) = f(g(x))` оператор Шварца задовольняє специфічне нелінійне ланцюгове правило:

```
S(f ∘ g)(x) = S(f)(g(x)) · (g'(x))² + S(g)(x)
```

Це співвідношення демонструє, що `S(f)` поводиться як квадратичний диференціал. Якщо інтерпретувати `(g'(x))²` як метричний коефіцієнт деформації довжини, то похідна Шварца виступає як геодезична кривизна або тензорне співвідношення при проєктивних перетвореннях координат.

Якщо `M(z)` — дробово-лінійне перетворення Мьобіуса, то з огляду на `S(M)(z) = 0` композиція `(M ∘ g)(x)` дає:

```
S(M ∘ g)(x)
= S(M)(g(x)) · (g'(x))² + S(g)(x)             [ланцюгове правило для Шварціана]
= 0 · (g'(x))² + S(g)(x)                      [підстановка S(M) = 0]
= S(g)(x)                                     [скорочення нульового доданка]
```

Це означає, що ліва дія групи Мьобіуса повністю зберігає похідну Шварца! У геометрії Лобачевського на верхній півплощині Пуанкаре перетворення Мьобіуса відповідають ізометріям (рухам) гіперболічного простору. Таким чином, похідна Шварца прямо вимірює деформацію функції відносно неевклідових ізометрій.

## 3. Зв'язок із лінійними диференціальними рівняннями 2-го порядку

Розглянемо лінійне диференціальне рівняння другого порядку у канонічній формі Шредінгера чи Штурма-Ліувілля без першої похідної:

```
y''(x) + q(x)·y(x) = 0
```

Нехай `y₁(x)` та `y₂(x)` — два лінійно незалежні розв'язки цього рівняння, а їхній вронськіан `W = y₁'·y₂ - y₁·y₂'` є сталою величиною, відмінною від нуля. Розглянемо відношення цих двох розв'язків:

```
f(x) = y₁(x) / y₂(x)
```

Обчислимо похідні від відношення `f(x)` за правилами диференціювання частки:

```
f'(x)
= (y₁'·y₂ - y₁·y₂') / y₂²
= W / y₂²    [де W — вронськіан]

f''(x)
= -2·W·y₂' / y₂³

f'''(x)
= -2·W·(y₂''·y₂³ - 3·y₂²·(y₂')²) / y₂⁶
= -2·W·(y₂''·y₂ - 3·(y₂')²) / y₂⁴
```

Оскільки `y₂''(x) = -q(x)·y₂(x)` безпосередньо з вихідного диференціального рівняння, підставимо це у вираз для `f'''(x)`:

```
f'''(x)
= -2·W·(-q(x)·y₂² - 3·(y₂')²) / y₂⁴           [підстановка y₂'' = -q·y₂ з рівняння Шредінгера]
= 2·W·q(x) / y₂² + 6·W·(y₂')² / y₂⁴           [розкриття дужок та ділення]
```

Формуємо співвідношення для оператора Шварца:

```
f'''(x) / f'(x)
= (2·W·q(x) / y₂² + 6·W·(y₂')² / y₂⁴) / (W / y₂²)    [ділення на f' = W/y₂²]
= 2·q(x) + 6·(y₂'/y₂)²                               [скорочення W/y₂²]

f''(x) / f'(x)
= (-2·W·y₂' / y₂³) / (W / y₂²)                       [ділення f'' на f']
= -2·(y₂'/y₂)                                         [скорочення W/y₂²]
```

Обчислюємо похідну Шварца `S(f)(x)`:

```
S(f)(x)
= f'''(x) / f'(x) - (3/2) · (f''(x) / f'(x))²
= (2·q(x) + 6·(y₂'/y₂)²) - (3/2) · (-2·(y₂'/y₂))²    [підстановка відношень f'''/f' та f''/f']
= 2·q(x) + 6·(y₂'/y₂)² - 6·(y₂'/y₂)²                 [піднесення до квадрата (-2)² · 3/2 = 6]
= 2·q(x)                                              [скорочення однакових доданків]
```

Отже, похідна Шварца відношення розв'язків диференціального рівняння `y'' + q(x)y = 0` точно дорівнює подвоєному коефіцієнту потенціалу `2·q(x)`. Це дає фундаментальний спосіб побудови та аналізу потенціалів у квантовій механіці та нелінійній хвильовій динаміці.

## 4. Опуклість та аналіз теореми Сінґера

Вирішальна роль умови `S(f)(x) < 0` в одновимірній динаміці базується на властивостях опуклості. Розглянемо допоміжну функцію `u(x) = (f'(x))⁻¹/²` на інтервалі, де `f'(x) > 0`.

Обчислимо першу та другу похідні від `u(x)`:

```
u'(x)
= (-1/2) · (f'(x))⁻³/² · f''(x)                       [диференціювання степеня (f')⁻¹/²]

u''(x)
= (3/4) · (f'(x))⁻⁵/² · (f''(x))² - (1/2) · (f'(x))⁻³/² · f'''(x)    [диференціювання добутку]
= (-1/2) · (f'(x))⁻³/² · (f'''(x) - (3/2) · (f''(x))² / f'(x))       [винесення спільного множника]
= (-1/2) · (f'(x))⁻¹/² · S(f)(x)                                      [виділення оператора Шварца S(f)]
```

Звідси отримуємо елегантне лінійне рівняння для допоміжної функції `u(x)`:

```
u''(x) = (-1/2) · u(x) · S(f)(x)
```

Оскільки `u(x) = (f'(x))⁻¹/² > 0`, умова `S(f)(x) < 0` повністю еквівалентна тому, що `u''(x) > 0` на всьому інтервалі. Додатність другої похідної означає, що функція `u(x)` є строго опуклою (convex).

Опукла функція `u(x)` не може мати локальних максимумів усередині інтервалу. Відповідно, величина `|f'(x)| = 1/u²(x)` не може мати локальних мінімумів зі значеннями більшими за 1 усередині інтервалу без проходження через критичні точки (де `f'(x) = 0`) або межі. Саме цей геометричний факт заважає ітераціям відображення створювати ізольовані «кишені» стискання фазового простору і гарантує, що кожен стійкий періодичний атрактор захоплює орбіту принаймні однієї критичної точки.

## 5. Обчислення Шварціана для базових класів функцій

Для поглиблення розуміння оператора розглянемо результат дії Шварціана на основні елементарні функції:

### Параболічна функція (Логістична карта) `f(x) = a·x² + b·x + c`

Перша, друга та третя похідні дорівнюють:

```
f'(x) = 2·a·x + b
f''(x) = 2·a
f'''(x) = 0
```

Підставляючи у формулу Шварціана:

```
S(f)(x)
= 0 - (3/2) · (2·a / (2·a·x + b))²
= -6·a² / (2·a·x + b)² < 0                            [сувора від'ємність для всіх x ≠ -b/(2a)]
```

### Дійсна експоненціальна функція `f(x) = exp(k·x)`

Похідні експоненти пропорційні самій функції:

```
f'(x) = k·exp(k·x)
f''(x) = k²·exp(k·x)
f'''(x) = k³·exp(k·x)
```

Обчислюємо відношення похідних:

```
f'''(x) / f'(x) = k²
f''(x) / f'(x) = k

S(f)(x)
= k² - (3/2) · k² = (-1/2) · k² < 0                    [стале від'ємне значення]
```

Шварціан будь-якої експоненціальної функції є від'ємною сталою величина `-k²/2`.

### Степенева функція `f(x) = xⁿ` (де `n ≠ 0, 1`)

Обчислимо послідовні похідні:

```
f'(x) = n·xⁿ⁻¹
f''(x) = n·(n - 1)·xⁿ⁻²
f'''(x) = n·(n - 1)·(n - 2)·xⁿ⁻³
```

Підставляємо знаходження у формулу Шварціана:

```
f'''(x) / f'(x) = (n - 1)·(n - 2) / x²                [ділення f''' на f']
f''(x) / f'(x) = (n - 1) / x                          [ділення f'' на f']

S(f)(x)
= (n - 1)·(n - 2) / x² - (3/2) · (n - 1)² / x²        [підстановка відношень у формулу Шварціана]
= (n - 1) / x² · ((n - 2) - (3/2)·(n - 1))            [винесення спільного множника (n-1)/x²]
= (1 - n²) / (2·x²)                                    [спрощення многочлена у дужках]
```

Отже, для будь-якого степеня `|n| > 1` значення Шварціана `S(xⁿ)(x) = (1 - n²)/(2·x²)` є **суворо від'ємним** для всіх `x ≠ 0`. Це пояснює, чому степеневі карти вищого порядку підпорядковуються теоремі Сінґера.

## 6. Багатовимірні узагальнення та нелінійні многовиди

У багатовімірному фазовому просторі `ℝⁿ` оператор Шварца узагальнюється через матричний тензор Якобі `J(x)` та тензор Крістоффеля проєктивної зв'язності. Для дифеоморфізму багатовимірного многовиду `f: M → M` похідна Шварца визначається як симетричний тензор третього рангу `S(f)_{ijk}`, який описує відхилення відображення від конформних автоморфізмів багатовимірної сфери `Sⁿ`.

Цей тензорний апарат активно застосовується у геодезичному аналізі гідродинамічних течій Нав'є-Стокса та в розрахунках стійкості ламінарного примежового шару.
