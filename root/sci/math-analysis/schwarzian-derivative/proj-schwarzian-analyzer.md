# ⚙️ Чисельний аналіз похідної Шварца та стійкості нелінійних відображень

Під час чисельного дослідження стійкості нелінійних осциляторів, турбулентних змішувачів та дискретних моделей фізичних систем аналітичне диференціювання рівнянь руху не завжди можливе. Наприклад, якщо аналізується перетин Пуанкаре для системи трьох зв'язаних осциляторів або експериментальний часовий ряд капілярних хвиль, функція відображення `f(x)` задається числовою сіткою або алгоритмічним модулем інтегрування. Обчислення оператора Шварца у таких випадках вимагає застосування високоточних чисельних схем диференціювання, оскільки оцінка третьої похідної вкрай чутлива до шуму та похибок округлення.

Оператор Шварца визначається співвідношенням:

```
S(f)(x) = f'''(x) / f'(x) - (3/2) · (f''(x) / f'(x))²
```

Для чисельного обчислення першої, другої та третьої похідних доцільно використовувати 5-точкову симетричну скінченно-різницеву схему четвертого порядку точності. Вибір кроку диференціювання `h` є результатом компромісу: надто малий крок призводить до катастрофічної втрати значущих розрядів при відніманні близьких чисел у `f'''(x) ∝ 1/h³`, тоді як надто великий крок викликає високу методичну похибку апроксимації.

## 1. Математичне виведення 5-точкових скінченно-різницевих схем

Щоб побудувати високоточний аналізатор оператора Шварца без втрати значущих розрядів, розкладемо значення функції `f(x)` у ряд Тейлора в околі точки `x` для кроків `+h`, `-h`, `+2h` та `-2h`:

```
f(x + h) = f(x) + h·f' + (h²/2)·f'' + (h³/6)·f''' + (h⁴/24)·f⁴ + (h⁵/120)·f⁵ + O(h⁶)
f(x - h) = f(x) - h·f' + (h²/2)·f'' - (h³/6)·f''' + (h⁴/24)·f⁴ - (h⁵/120)·f⁵ + O(h⁶)
f(x + 2h) = f(x) + 2h·f' + 2h²·f'' + (4h³/3)·f''' + (2h⁴/3)·f⁴ + (4h⁵/15)·f⁵ + O(h⁶)
f(x - 2h) = f(x) - 2h·f' + 2h²·f'' - (4h³/3)·f''' + (2h⁴/3)·f⁴ - (4h⁵/15)·f⁵ + O(h⁶)
```

Комбінуючи ці розклади із ваговими коефіцієнтами методів невизначених коефіцієнтів, отримуємо симетричні схеми 4-го порядку точності:

```
df1(x) = (f(x - 2h) - 8·f(x - h) + 8·f(x + h) - f(x + 2h)) / (12·h) + O(h⁴)
df2(x) = (-f(x - 2h) + 16·f(x - h) - 30·f(x) + 16·f(x + h) - f(x + 2h)) / (12·h²) + O(h⁴)
df3(x) = (-f(x + 2h) + 2·f(x + h) - 2·f(x - h) + f(x - 2h)) / (2·h³) + O(h²)
```

Застосування цих вагових коефіцієнтів дозволяє компенсувати члени парних степенів `h²` та `h⁴`, забезпечуючи мінімальну систематичну похибку чисельного оцінювання оператора Шварца.

## 2. Фізичний сенс чисельного аналізу стійкості

У нелінійній механіці стійкість періодичного руху розраховується через спектральний радіус або похідні ітерацій відображення `fⁿ(x)`. За теоремою Сінґера, якщо одновимірне відображення задовольняє умову `S(f)(x) < 0` на всій області визначення, то при зміні керуючого параметра (наприклад, сили амплітуди збудження або коефіцієнта тертя) кожен новонароджений стійкий цикл захоплює траєкторію хоча б однієї критичної точки.

Це принципово спрощує чисельний пошук атракторів: замість сканування тисяч випадкових початкових умов фазового простору достатньо запустити ітераційний процес безпосередньо з критичної точки `x_c` (де `f'(x_c) = 0`). Якщо орбіта критичної точки збігається до періодичного циклу довжини `K`, то цей `K`-цикл є єдиним стійким рухом у системі. Якщо ж орбіта критичної точки поводиться хаотично й заповнює плями атрактора, системі притаманний детермінований хаос без ізольованих періодичних вікон.

Нижче наведено практичну реалізацію мовами C та C++ для аналізу логістичного відображення `f(x) = r·x·(1-x)` та синусоїдального відображення `f(x) = r·sin(π·x)`. Програма оцінює похідну Шварца, визначає критичні точки `x_c` та виконує числову перевірку теореми Сінґера шляхом трасування орбіти критичної точки.

```c
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

/* Обчислення похідної Шварца за точними аналітичними похідними */
double schwarzian_exact(double df1, double df2, double df3) {
    if (fabs(df1) < 1e-12) {
        return -1e15; /* Прямує до мінус нескінченності в критичній точці */
    }
    double term1 = df3 / df1;
    double ratio = df2 / df1;
    double term2 = 1.5 * ratio * ratio;
    return term1 - term2;
}

/* Чисельне обчислення похідної Шварца через центральні різниці 4-го порядку */
double schwarzian_numeric(double (*f)(double), double x, double h) {
    double f_p2 = f(x + 2.0 * h);
    double f_p1 = f(x + h);
    double f_m1 = f(x - h);
    double f_m2 = f(x - 2.0 * h);

    /* Скінченно-різницеві оцінки похідних 4-го порядку */
    double df1 = (f_m2 - 8.0 * f_m1 + 8.0 * f_p1 - f_p2) / (12.0 * h);
    double df2 = (-f_m2 + 16.0 * f_m1 - 30.0 * f(x) + 16.0 * f_p1 - f_p2) / (12.0 * h * h);
    double df3 = (-f_p2 + 2.0 * f_p1 - 2.0 * f_m1 + f_m2) / (2.0 * h * h * h);

    return schwarzian_exact(df1, df2, df3);
}

/* Тестове логістичне відображення f(x) = r * x * (1 - x) */
static double g_r = 3.83;

static double logistic_map(double x) {
    return g_r * x * (1.0 - x);
}

int main(void) {
    g_r = 3.83; /* Параметр у зоні 3-циклу */
    double x_step = 0.05;

    printf("=== Аналіз похідної Шварца для логістичного відображення (r = %.2f) ===\n", g_r);
    printf("  x     df1       df2       S(f) exact    S(f) numeric\n");
    printf("----------------------------------------------------------\n");

    for (double x = 0.1; x <= 0.9; x += x_step) {
        if (fabs(x - 0.5) < 1e-4) continue; /* Пропускаємо критичну точку */

        double df1 = g_r * (1.0 - 2.0 * x);
        double df2 = -2.0 * g_r;
        double df3 = 0.0;

        double S_exact = schwarzian_exact(df1, df2, df3);
        double S_num = schwarzian_numeric(logistic_map, x, 1e-4);

        printf("%4.2f  %8.4f  %8.4f  %12.4f  %12.4f\n", x, df1, df2, S_exact, S_num);
    }

    return 0;
}
```

```cpp
#include <iostream>
#include <vector>
#include <cmath>
#include <functional>
#include <optional>
#include <iomanip>
#include <limits>

class SchwarzianAnalyzer {
public:
    struct AnalysisPoint {
        double x;
        double df1;
        double df2;
        double df3;
        double schwarzian;
    };

    // Точне оцінювання похідної Шварца
    static constexpr double compute(double df1, double df2, double df3) noexcept {
        if (std::abs(df1) < 1e-12) {
            return -std::numeric_limits<double>::infinity();
        }
        const double ratio = df2 / df1;
        return (df3 / df1) - 1.5 * ratio * ratio;
    }

    // Чисельна апроксимація оператора Шварца для довільного callable-об'єкта
    static double computeNumeric(const std::function<double(double)>& func, double x, double h = 1e-4) {
        const double f_p2 = func(x + 2.0 * h);
        const double f_p1 = func(x + h);
        const double f_m1 = func(x - h);
        const double f_m2 = func(x - 2.0 * h);

        const double df1 = (f_m2 - 8.0 * f_m1 + 8.0 * f_p1 - f_p2) / (12.0 * h);
        const double df2 = (-f_m2 + 16.0 * f_m1 - 30.0 * func(x) + 16.0 * f_p1 - f_p2) / (12.0 * h * h);
        const double df3 = (-f_p2 + 2.0 * f_p1 - 2.0 * f_m1 + f_m2) / (2.0 * h * h * h);

        return compute(df1, df2, df3);
    }

    // Симуляція орбіти критичної точки для перевірки захоплення атрактором (Теорема Сінґера)
    static std::vector<double> traceCriticalOrbit(const std::function<double(double)>& func,
                                                  double x_critical,
                                                  size_t iterations) {
        std::vector<double> orbit;
        orbit.reserve(iterations);

        double curr = x_critical;
        for (size_t i = 0; i < iterations; ++i) {
            curr = func(curr);
            orbit.push_back(curr);
        }
        return orbit;
    }
};

int main() {
    constexpr double r = 3.83; // Вікно 3-циклу в логістичній карті
    auto logisticMap = [r](double x) noexcept { return r * x * (1.0 - x); };

    std::cout << std::fixed << std::setprecision(4);
    std::cout << "=== Спектральний аналіз Шварціана у C++ ===\n";
    std::cout << "  x       S(f) точне    S(f) чисельне\n";
    std::cout << "-------------------------------------\n";

    for (double x = 0.1; x <= 0.9; x += 0.1) {
        if (std::abs(x - 0.5) < 1e-4) continue;

        const double df1 = r * (1.0 - 2.0 * x);
        const double df2 = -2.0 * r;
        const double df3 = 0.0;

        const double S_exact = SchwarzianAnalyzer::compute(df1, df2, df3);
        const double S_num = SchwarzianAnalyzer::computeNumeric(logisticMap, x);

        std::cout << x << "    " << std::setw(10) << S_exact 
                  << "    " << std::setw(10) << S_num << "\n";
    }

    // Трасування критичної точки x_c = 0.5 за теоремою Сінґера
    constexpr double x_c = 0.5;
    const auto orbit = SchwarzianAnalyzer::traceCriticalOrbit(logisticMap, x_c, 10);

    std::cout << "\nПерші 10 ітерацій критичної точки x_c = 0.5:\n";
    for (size_t i = 0; i < orbit.size(); ++i) {
        std::cout << "  f^(" << (i + 1) << ")(x_c) = " << orbit[i] << "\n";
    }

    return 0;
}
```

## 3. Аналіз алгоритмічних пасток та обчислювальних нюансів

1. **Пастка критичних точок (`f'(x) = 0`):** При наближенні `x` до критичної точки перша похідна `f'(x)` прямує до нуля. Оскільки `f'(x)` стоїть у знаменнику оператора Шварца у квадраті, значення `S(f)(x)` стрімко прямує до `-∞`. Спроба обчислити значення безпосередньо в точці `x_c` призводить до ділення на нуль або генерування значення `NaN / -Inf`. Причиною цього є те, що критична точка є полюсом другого порядку для оператора Шварца.

2. **Оптимальний вибір кроку диференціювання `h`:** Для чисельного обчислення третьої похідної використовується схема з діленням на `h³`. У форматі плаваючої коми подвійної точності (IEEE 754 double, 53 біти мантиси) мінімальна похибка обчислень досягається при кроці порядку `h ≈ 1e-4` до `1e-3`. Занадто малий крок `h < 1e-5` викликає скасовувальну похибку (cancellation error), де різниця двох дуже близьких чисел втрачає молодші розряди.

3. **Стійкість при аналізі експериментальних даних:** Якщо функція `f(x)` отримана з фізичного вимірювання (наприклад, з давача кутової швидкості або оптичного ансамблю), перед використанням оператора Шварца необхідно провести згладжування за допомогою сплайнів (B-splines або кубічних сплайнів з регуляризацією Тихонова). Без згладжування чисельний шум високочастотних коливань буде піднесений до куба при обчисленні третьої похідної, що повністю викривить знак Шварціана.

4. **Розширення для багатовимірних систем:** Для систем високої розмірності (наприклад, тривимірний атрактор Лоренца) оператор Шварца узагальнюється через матричний вронськіан та тензор Якобі для відображення Пуанкаре. Скалярний Шварціан при цьому обчислюється уздовж одновимірного нестійкого многовиду (unstable manifold).

5. **Фільтр Савицького-Ґолея для дискретних вимірювань:** При обробці експериментальних даних рекомендується застосовувати цифровий фільтр Савицького-Ґолея (Savitzky-Golay filter). Цей фільтр виконує локальну поліноміальну регресію низького ступеня у ковзному вікні, дозволяючи аналітично продиференціювати отриманий поліном 3-го чи 4-го ступеня без акумуляції високочастотного вимірювального шуму.

## 4. Оптимізація продуктивності для масового сканування параметрів

При розрахунку біфуркаційних діаграм та аналізі стійкості на великих сітках керуючого параметра `r ∈ [2.0, 4.0]` з кількістю точок `N > 10⁶` чисельний виклик `computeNumeric` у циклі може створювати оверхед через виклики функціонального об'єкта `std::function`.

Щоб оптимізувати обчислення:
- Використовуйте шаблони C++ для інлайнінгу тіла функції відображення безпосередньо у скінченно-різницеву формулу.
- Вмикайте векторацію SIMD (AVX2/AVX-512) для одночасного розрахунку п'яти точок `f(x ± h)`, `f(x ± 2h)` на пакувальних регістрах.
- Застосовуйте OpenMP паралелізацію зовнішнього циклу сканування параметрів `r`.
