# 🧮 Математичний апарат та строге виведення рівняння центрального многовиду

Математична формалізація теорії центрального многовиду спирається на апарат спектральної теорії лінійних операторів, якісної теорії диференціальних рівнянь та теорем про неявну функцію у функціональних просторах. Головною метою цього апарату є суворий математичний перехід від високовимірного векторного поля до автономного диференціального рівняння меншої вимірності без втрати динамічних якостей системи.

---

### 1. Спектральний розклад та нормальна форма системи

Розглянемо автономну нелінійну систему диференціальних рівнянь у просторі `R^(n+m)`:

```
dz/dt = F(z)
```

Нехай `z = 0` є точкою рівноваги, тобто `F(0) = 0`. Припустимо, що векторне поле `F` належить класу гладкості `C^r` (`r ≥ 1`) у деякому околі початку координат.

Розкладемо `F(z)` у ряд Тейлора в околі точки `z = 0`:

```
dz/dt = J·z + R(z)
```

де `J = DF(0)` — матриця Якобі розміром `(n+m) × (n+m)`, а `R(z)` містить нелінійні члени порядку `O(|z|²)`, для яких `R(0) = 0` та `DR(0) = 0`.

Спектр `σ(J)` матриці Якобі розбивається на дві ізольовані частини:
1. **Критичний (центральний) спектр `σ_c`**: складається з `n` власних значень, дійсна частина яких дорівнює нулю (`Re(λ) = 0`).
2. **Стійкий спектр `σ_s`**: складається з `m` власних значень, дійсна частина яких строго від'ємна (`Re(λ) ≤ -γ < 0` для деякої константи `γ > 0`).

*Примітка:* Якщо у системі присутні також нестійкі власні значення (`Re(λ) > 0`), вони аналогічно виділяються у нестійкий підпростір `E^u`. Для простоти викладу припустимо `E^u = {0}`, оскільки при наявності нестійкого підпростору точка рівноваги є завідомо нестійкою, а редукція проводиться на комбінований центрально-нестійкий многовид `W^(cu)`.

За допомогою лінійного неразового перетворення координат `z = T·(x, y)^T` матриця `J` зводиться до блочно-діагонального вигляду:

```
dx/dt = A·x + f(x, y)
dy/dt = B·y + g(x, y)
```

де:
- `x ∈ Rⁿ` — вектор центральних (критичних) змінних;
- `y ∈ Rᵐ` — вектор стійких (швидко згасаючих) змінних;
- `A` — квадратна матриця `n × n`, усі власні значення якої задовольняють `Re(λ(A)) = 0`;
- `B` — квадратна матриця `m × m`, усі власні значення якої задовольняють `Re(λ(B)) ≤ -γ < 0`;
- `f(x, y)` та `g(x, y)` — нелінійні функції гладкості `C^r`, що задовольняють умову розкладу:

```
f(0, 0) = 0,    Df(0, 0) = 0
g(0, 0) = 0,    Dg(0, 0) = 0
```

---

### 2. Строге формулювання теореми про центральний многовид

**Теорема (Існування та гладкість локального центрального многовиду):**

Для канонічної системи з розділеним спектром існують відкритий окіл початку координат `U ⊂ Rⁿ` та локальна функція `h: U → Rᵐ` класу `C^r`, такі що:

1. **Дотичність у точці рівноваги**:
```
h(0) = 0,    Dh(0) = 0
```
це означає, що поверхня `W^c = {(x, y) ∈ Rⁿ × Rᵐ | y = h(x), x ∈ U}` дотикається до центрального підпростору `E^s = {(x, 0)}` у точці `(0, 0)`.

2. **Локальна інваріантність**:
Поверхня `W^c` є інваріантною відносно фазового потоку системи. Тобто, якщо початковий стан `(x(0), y(0))` належить `W^c`, то розв'язок `(x(t), y(t))` залишається на `W^c` для всіх `t`, поки `x(t) ∈ U`.

3. **Принцип притягання (Принцип редукції / Редукційна теорема Плісса)**:
Якщо точка `z = 0` є асимптотично стійкою (або нестійкою) для редукованої скалярної/векторної системи на `W^c`:
```
dx/dt = A·x + f(x, h(x))
```
то точка `z = 0` є асимптотично стійкою (або відповідно нестійкою) для всієї повної `(n+m)`-вимірної системи. 

Більше того, якщо `(x(t), y(t))` є розв'язком повної системи з початковими умовами у достатньо малому околі нульового стану, то існує розв'язок `x̄(t)` редукованої системи такий, що при `t → +∞`:
```
x(t) = x̄(t) + O(exp(-γ·t))
y(t) = h(x̄(t)) + O(exp(-γ·t))
```
Тобто фазова точка з експоненційною швидкістю западає на центральний многовид.

### 3. Виведення диференціального оператора N(h(x)) = 0

Скористаємося умовою інваріантності. Оскільки на багатовимірній поверхні `W^c` виконується співвідношення `y(t) = h(x(t))`, продиференціюємо цю рівність за часом `t` за допомогою багатовимірного ланцюгового правила (Chain Rule):

```
dy/dt = Dh(x) · dx/dt
```

де `Dh(x)` — матриця Якобі функції `h(x)` розміром `m × n`.

Підставимо у цю рівність праві частини канонічної системи `dx/dt` та `dy/dt`:

```
B·h(x) + g(x, h(x)) = Dh(x) · [ A·x + f(x, h(x)) ]
```

Перенесемо всі члени в один бік і сформулюємо квазілінійне диференціальне рівняння в частинних похідних відносно невідомого відображення `h(x)`:

```
N(h(x)) ≡ Dh(x)·[ A·x + f(x, h(x)) ] - B·h(x) - g(x, h(x)) = 0
```

Це рівняння називається **квазілінійним операторним рівнянням центрального многовиду**. Зауважимо, що `N(h)` є нелінійним оператором, який діє на векторну функцію `h(x)`. Граничні умови для `h(x)` мають вигляд:

```
h(0) = 0
Dh(0) = 0
```

Оскільки `Dh(0) = 0`, розклад Тейлора для `h(x)` починається з членів другого або вищого порядку:

```
h_k(x) = ∑_{|α| = 2}^{k} a_α · x^α
```

де `α = (α₁, α₂, ..., αₙ)` — мультиіндекс ступенів.

### 4. Теорема про наближення (Approximation Theorem)

Точний закритий аналітичний розв'язок операторного рівняння `N(h) = 0` у більшості фізичних і механічних задач знайти неможливо. Однак вирішальну практичну роль відіграє теорема Карра про наближене обчислення.

**Теорема (Карра про порядок наближення):**

Нехай `ϕ: Rⁿ → Rᵐ` є тричі диференційовною функцією у околі нуля, що задовольняє умови `ϕ(0) = 0` та `Dϕ(0) = 0`.

Якщо при підставці `ϕ(x)` у оператор `N` залишковий член задовольняє оцінку:
```
N(ϕ(x)) = O(|x|^q)    при  x → 0  (для деякого q > 1)
```
то точний центральний многовид `h(x)` відхиляється від наближеного відображення `ϕ(x)` на величину того самого порядку:
```
|h(x) - ϕ(x)| = O(|x|^q)    при  x → 0
```

Більше того, заміна точної функції `h(x)` на її тейлорівське наближення `ϕ(x)` у редукованому векторному полі дає точний опис динаміки з точністю до членів порядку `O(|x|^(q+1))`:
```
dx/dt = A·x + f(x, ϕ(x)) + O(|x|^(q+1))
```

Це доведення означає, що для визначення стійкості або типу біфуркації (наприклад, визначення знака першого ляпуновського величини для біфуркації Андронова-Гопфа) достатньо обчислити лише перші кілька коефіцієнтів Тейлора для `h(x)`.

### 5. Покроковий алгебраїчний розрахунок для 3D нелінійної механічної системи

Для ілюстрації розглянемо тривимірну нелінійну систему механічних коливань з одним нейтральним режимом `x` та двома стійкими швидко згасаючими модами `y₁` та `y₂`:

```
dx/dt = x·y₁ - x³
dy₁/dt = -2·y₁ + x² + y₂²
dy₂/dt = -3·y₂ - 2·x² + x·y₁
```

Тут матриці лінеаризації є діагональними:
- `A = [0]` (одне нульове власне значення, `n = 1`);
- `B = [-2, 0; 0, -3]` (два від'ємних власних значення `λ₁ = -2`, `λ₂ = -3`, `m = 2`).

Шукаємо центральний многовид `y = h(x) = (h₁(x), h₂(x))^T` у вигляді квадратичного розкладу Тейлора:

```
h₁(x) = a₂·x² + a₃·x³ + O(x⁴)
h₂(x) = b₂·x² + b₃·x³ + O(x⁴)
```

Звідси похідні за змінною `x` дорівнюють:

```
Dh₁(x) = 2·a₂·x + 3·a₃·x² + O(x³)
Dh₂(x) = 2·b₂·x + 3·b₃·x² + O(x³)
```

Обчислимо компоненти квазілінійного оператора `N(h(x))`:

#### Перша компонента N₁(h(x)):
```
N₁(h) = Dh₁(x)·[ dx/dt ] - [ dy₁/dt ]                                   [визначення оператора N₁]
      = (2·a₂·x + 3·a₃·x²) · [ x·(a₂·x² + ...) - x³ ] - [ -2·(a₂·x² + a₃·x³ + ...) + x² + (b₂·x² + ...)^2 ] [підставка правій частин та h₁(x)]
      = [ 2·a₂·x² ] + 2·a₂·x² - x² + O(x³)                             [розкриття дужок та згрупування степенів x²]
      = (2·a₂ - 1)·x² + (2·a₃)·x³ + O(x⁴)                               [приведення подібних доданків]
```

Для того щоб `N₁(h) = O(x⁴)`, прирівняємо коефіцієнти при одинакових степенях `x` до нуля:

```
При x²:   2·a₂ - 1 = 0    ⇒   a₂ = 0.5                         [розв'язання лінійного рівняння для a₂]
При x³:   2·a₃ = 0        ⇒   a₃ = 0                           [розв'язання лінійного рівняння для a₃]
```

#### Друга компонента N₂(h(x)):
```
N₂(h) = Dh₂(x)·[ dx/dt ] - [ dy₂/dt ]                                   [визначення оператора N₂]
      = (2·b₂·x + 3·b₃·x²) · [ O(x³) ] - [ -3·(b₂·x² + b₃·x³ + ...) - 2·x² + x·(a₂·x² + ...) ] [підставка правій частин та h₂(x)]
      = 3·b₂·x² + 3·b₃·x³ + 2·x² - a₂·x³ + O(x⁴)                         [розкриття дужок та впорядкування за степенями x]
      = (3·b₂ + 2)·x² + (3·b₃ - a₂)·x³ + O(x⁴)                         [приведення подібних доданків]
```

Прирівнюємо коефіцієнти при `x²` та `x³` до нуля:

```
При x²:   3·b₂ + 2 = 0         ⇒   b₂ = -2/3 ≈ -0.6667             [розв'язання рівняння для b₂]
При x³:   3·b₃ - 0.5 = 0       ⇒   b₃ = 1/6 ≈ 0.1667               [підставка a₂=0.5 та розв'язання для b₃]
```

#### Підсумкове явне відображення многовиду:

```
h₁(x) = 0.5 · x² + O(x⁴)
h₂(x) = -2/3 · x² + 1/6 · x³ + O(x⁴)
```

#### Побудова редукованого векторного поля на W^c:

Підставляємо знайдений розклад `h₁(x)` у скалярне рівняння для критичної змінної `x`:

```
dx/dt = x·h₁(x) - x³                                                   [вихідне рівняння для критичної змінної x]
      = x·(0.5·x² + O(x⁴)) - x³                                        [підставка Тейлорівського відображення h₁(x) = 0.5·x²]
      = 0.5·x³ - x³ + O(x⁵)                                            [розкриття дужки x · 0.5·x² = 0.5·x³]
      = -0.5 · x³ + O(x⁵)                                              [зведення подібних доданків 0.5·x³ - x³ = -0.5·x³]
```

#### Висновок про стійкість:
Оскільки у редукованому рівнянні `dx/dt = -0.5 · x³` коефіцієнт при кубічному члені є суворо від'ємним (`-0.5 < 0`), то точка рівноваги `x = 0` є **асимптотично стійкою** (субкритична атрактивність). За теоремою про редукцію, вихідна тривимірна нелінійна система є повністю асимптотично стійкою у околі нуля!

Якби ми обмежилися лише лінійним наближенням (`y₁ = 0`, `y₂ = 0`), ми отримали б `dx/dt = -x³`, що дало б помилкову швидкість згасання. Апарат центрального многовиду дозволив точно врахувати нелінійний внесок швидко згасаючих мод на тривалих часових інтервалах.
