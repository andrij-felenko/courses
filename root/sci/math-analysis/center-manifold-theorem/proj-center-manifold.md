# ⚙️ Чисельне обчислення центрального многовиду та редукція системи

Практичне застосування теореми про центральний многовид у чисельному моделюванні та обчислювальній механіці полягає у створенні алгоритмів автоматичного обчислення Тейлорівських коефіцієнтів многовиду `y = h(x)` та інтегруванні редукованої системи. Головна перевага цього підходу — подолання так званої **жорсткості диференціальних рівнянь** (Stiffness). У вихідній багатовимірній системі присутні швидко згасаючі компоненти з великим коефіцієнтом дисипації `γ >> 1`. При прямому чисельному інтегруванні повної системи це вимагає застосування надзвичайно малого кроку інтегрування `dt < 2/γ` для забезпечення чисельної стійкості класичних методів (наприклад, методів Рунге-Кутти).

Після аналітичної або чисельної редукції на центральний многовид швидкі змінні `y` вилучаються (вони підпорядковуються алгебраїчній залежності `y = h(x)`), а редукована система описує лише повільну асимптотичну еволюцію. Це дозволяє збільшити крок чисельного інтегрування у десятки та сотні разів без втрати точності та без ризику чисельного вибуху розрахунку.

---

### Постановка задачі та математичний алгоритм

Розглянемо двовимірну нелінійну систему диференціальних рівнянь, яка моделює механічні коливання з одного нейтрального (критичного) режиму `x` та одного стійкого швидко згасаючого режиму `y`:

```
dx/dt = a_lin·x + f_20·x² + f_11·x·y + f_02·y² + f_30·x³
dy/dt = -γ·y + g_20·x² + g_11·x·y + g_02·y²
```

де `γ > 0` є коефіцієнтом дисипації стійкої моди (наприклад, `γ = 10.0`), `a_lin = 0` задає нейтральний спектр лінійної частини (`Re(λ) = 0`), а коефіцієнти `f_ij` та `g_ij` описують нелінійний перехресний зв'язок між модами фазового простору.

Алгоритм чисельної редукції та побудови спрощеної моделі складається з трьох послідовних кроків:

1. **Алгебраїчний розрахунок Тейлорівських коефіцієнтів `h(x) = h₂·x² + h₃·x³`**:
   Підставляючи шукане розкладання у квазілінійне операторне рівняння `N(h(x)) = Dh(x)·(dx/dt) - dy/dt = 0` та прирівнюючи коефіцієнти при однаковим степенях `x` до нуля, отримуємо формули:
   ```
   h₂ = g_20 / γ
   h₃ = (g_11 · h₂ + 2.0 * h₂ · f_20) / γ
   ```
2. **Побудова редукованого векторного поля на многовиді**:
   Замінюючи змінну `y` на її обчислене відображення `y = h(x)`, отримуємо скалярне диференціальне рівняння для повільної змінної `x`:
   ```
   dx/dt = f_red(x) = f_20·x² + f_11·x·h(x) + f_02·(h(x))² + f_30·x³
   ```
3. **Чисельне інтегрування та верифікація похибки**:
   Виконується паралельне розв'язання повної двовимірної системи `(x_full, y_full)` та редукованої одновимірної системи `x_red` методом Рунге-Кутти 4-го порядку (RK4). Це дозволяє наочно оцінити швидкість виходу фазової точки на багатовид та обчислити неусувну похибку редукції.

### Характеристики чисельної жорсткості та вибір кроку інтегрування

Основним показником жорсткості системи диференціальних рівнянь є співвідношення між найбільшим за модулем стійким власним значенням та найменшим модулем критичного власного значення:

```
S = max |Re(λ_s)| / min |Re(λ_c)|
```

При високих значеннях `S >> 10²` явні методи чисельного інтегрування повної системи потребують виконання умов стійкості Куранта-Фрідріхса-Леві (CFL):

```
dt < 2.8 / max |Re(λ_s)|
```

Якщо ж інтегрувати редуковану систему `dx/dt = f_red(x)`, обмеження жорсткості знімається, оскільки власне значення `λ_s` вилучене з динамічних рівнянь. Крок `dt` обирається виключно з міркувань точності апроксимації повільних коливань `dt ~ 0.1 / ω₀`, що суттєво заощаджує процесорний час.

Для забезпечення максимальної обчислювальної точності у прикладних симуляторах рекомендується застосовувати явний метод Рунге-Кутти-Фельберга 4–5 порядків (RKF45) з автоматичним вибором кроку `dt` за оцінкою логарифмічної похибки локального залишкового члена Тейлора.

```c
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

/* Структура коефіцієнтів 2D системи */
typedef struct {
    double gamma;   /* Коефіцієнт згасання стійкої моди (gamma > 0) */
    double f20, f11, f02, f30; /* Нелінійності dx/dt */
    double g20, g11, g02;      /* Нелінійності dy/dt */
} cm_system_2d_t;

/* Структура обчисленого центрального многовиду y = h(x) = h2*x^2 + h3*x^3 */
typedef struct {
    double h2;
    double h3;
} cm_manifold_2d_t;

/* Обчислення коефіцієнтів центрального многовиду */
cm_manifold_2d_t cm_compute_manifold(const cm_system_2d_t *sys) {
    cm_manifold_2d_t res;
    if (sys->gamma <= 0.0) {
        fprintf(stderr, "Помилка: gamma повинна бути строго додатною!\n");
        res.h2 = 0.0;
        res.h3 = 0.0;
        return res;
    }
    
    /* Обчислення коефіцієнта при x^2: h2 = g20 / gamma */
    res.h2 = sys->g20 / sys->gamma;
    
    /* Обчислення коефіцієнта при x^3: враховуємо перехресні нелінійності */
    res.h3 = (sys->g11 * res.h2 + 2.0 * res.h2 * sys->f20) / sys->gamma;
    
    return res;
}

/* Обчислення значення h(x) */
double cm_eval_h(const cm_manifold_2d_t *mf, double x) {
    return mf->h2 * x * x + mf->h3 * x * x * x;
}

/* Права частина повної 2D системи */
void cm_full_rhs(const cm_system_2d_t *sys, double x, double y, double *dxdt, double *dydt) {
    *dxdt = sys->f20 * x * x + sys->f11 * x * y + sys->f02 * y * y + sys->f30 * x * x * x;
    *dydt = -sys->gamma * y + sys->g20 * x * x + sys->g11 * x * y + sys->g02 * y * y;
}

/* Права частина редукованої 1D системи на W^c */
double cm_reduced_rhs(const cm_system_2d_t *sys, const cm_manifold_2d_t *mf, double x) {
    double y_h = cm_eval_h(mf, x);
    return sys->f20 * x * x + sys->f11 * x * y_h + sys->f02 * y_h * y_h + sys->f30 * x * x * x;
}

/* Крок інтегрування RK4 для повної системи */
void cm_step_full_rk4(const cm_system_2d_t *sys, double *x, double *y, double dt) {
    double k1x, k1y, k2x, k2y, k3x, k3y, k4x, k4y;
    
    cm_full_rhs(sys, *x, *y, &k1x, &k1y);
    cm_full_rhs(sys, *x + 0.5 * dt * k1x, *y + 0.5 * dt * k1y, &k2x, &k2y);
    cm_full_rhs(sys, *x + 0.5 * dt * k2x, *y + 0.5 * dt * k2y, &k3x, &k3y);
    cm_full_rhs(sys, *x + dt * k3x, *y + dt * k3y, &k4x, &k4y);
    
    *x += (dt / 6.0) * (k1x + 2.0 * k2x + 2.0 * k3x + k4x);
    *y += (dt / 6.0) * (k1y + 2.0 * k2y + 2.0 * k3y + k4y);
}

/* Крок інтегрування RK4 для редукованої системи */
void cm_step_reduced_rk4(const cm_system_2d_t *sys, const cm_manifold_2d_t *mf, double *x, double dt) {
    double k1 = cm_reduced_rhs(sys, mf, *x);
    double k2 = cm_reduced_rhs(sys, mf, *x + 0.5 * dt * k1);
    double k3 = cm_reduced_rhs(sys, mf, *x + 0.5 * dt * k2);
    double k4 = cm_reduced_rhs(sys, mf, *x + dt * k3);
    
    *x += (dt / 6.0) * (k1 + 2.0 * k2 + 2.0 * k3 + k4);
}

int main(void) {
    cm_system_2d_t sys = {
        .gamma = 10.0, /* Сильне згасання */
        .f20 = 0.5, .f11 = 1.0, .f02 = -0.2, .f30 = -1.2,
        .g20 = 2.0, .g11 = -0.5, .g02 = 0.1
    };
    
    cm_manifold_2d_t mf = cm_compute_manifold(&sys);
    printf("=== Обчислення центрального многовиду ===\n");
    printf("h2 (коефіцієнт при x^2): %f\n", mf.h2);
    printf("h3 (коефіцієнт при x^3): %f\n\n", mf.h3);
    
    /* Початкові умови */
    double x_full = 0.4, y_full = 0.8; /* y далі від багатовиду */
    double x_red = 0.4;
    double t = 0.0;
    double dt = 0.01;
    int steps = 100;
    
    printf("t\t\tx_full\t\ty_full\t\tx_red\t\ty_h(x_red)\tабс. похибка\n");
    printf("----------------------------------------------------------------------------------\n");
    
    for (int i = 0; i <= steps; i++) {
        double y_h = cm_eval_h(&mf, x_red);
        double err = fabs(x_full - x_red);
        
        if (i % 10 == 0) {
            printf("%.2f\t\t%.6f\t%.6f\t%.6f\t%.6f\t%.6e\n", t, x_full, y_full, x_red, y_h, err);
        }
        
        cm_step_full_rk4(&sys, &x_full, &y_full, dt);
        cm_step_reduced_rk4(&sys, &mf, &x_red, dt);
        t += dt;
    }
    
    return 0;
}
```

```cpp
#include <iostream>
#include <vector>
#include <cmath>
#include <expected>
#include <format>
#include <span>

namespace CM {

struct System2D {
    double gamma{10.0};
    double f20{0.5}, f11{1.0}, f02{-0.2}, f30{-1.2};
    double g20{2.0}, g11{-0.5}, g02{0.1};
};

struct Manifold2D {
    double h2{0.0};
    double h3{0.0};

    [[nodiscard]] constexpr double evaluate(double x) const noexcept {
        return h2 * x * x + h3 * x * x * x;
    }
};

enum class ReductionError {
    InvalidDampingFactor,
    DivergentTrajectory
};

// Обчислення многовиду з обробкою помилок через std::expected (C++23)
[[nodiscard]] std::expected<Manifold2D, ReductionError> compute_manifold(const System2D& sys) noexcept {
    if (sys.gamma <= 0.0) {
        return std::unexpected(ReductionError::InvalidDampingFactor);
    }

    Manifold2D mf;
    mf.h2 = sys.g20 / sys.gamma;
    mf.h3 = (sys.g11 * mf.h2 + 2.0 * mf.h2 * sys.f20) / sys.gamma;
    return mf;
}

class SystemSolver {
public:
    explicit SystemSolver(System2D sys) : sys_{sys} {
        auto res = compute_manifold(sys_);
        if (res) {
            manifold_ = *res;
        } else {
            throw std::invalid_argument("Некоректний коефіцієнт згасання gamma");
        }
    }

    [[nodiscard]] std::pair<double, double> full_rhs(double x, double y) const noexcept {
        double dxdt = sys_.f20 * x * x + sys_.f11 * x * y + sys_.f02 * y * y + sys_.f30 * x * x * x;
        double dydt = -sys_.gamma * y + sys_.g20 * x * x + sys_.g11 * x * y + sys_.g02 * y * y;
        return {dxdt, dydt};
    }

    [[nodiscard]] double reduced_rhs(double x) const noexcept {
        double yh = manifold_.evaluate(x);
        return sys_.f20 * x * x + sys_.f11 * x * yh + sys_.f02 * yh * yh + sys_.f30 * x * x * x;
    }

    void step_full_rk4(double& x, double& y, double dt) const noexcept {
        auto [k1x, k1y] = full_rhs(x, y);
        auto [k2x, k2y] = full_rhs(x + 0.5 * dt * k1x, y + 0.5 * dt * k1y);
        auto [k3x, k3y] = full_rhs(x + 0.5 * dt * k2x, y + 0.5 * dt * k2y);
        auto [k4x, k4y] = full_rhs(x + dt * k3x, y + dt * k3y);

        x += (dt / 6.0) * (k1x + 2.0 * k2x + 2.0 * k3x + k4x);
        y += (dt / 6.0) * (k1y + 2.0 * k2y + 2.0 * k3y + k4y);
    }

    void step_reduced_rk4(double& x, double dt) const noexcept {
        double k1 = reduced_rhs(x);
        double k2 = reduced_rhs(x + 0.5 * dt * k1);
        double k3 = reduced_rhs(x + 0.5 * dt * k2);
        double k4 = reduced_rhs(x + dt * k3);

        x += (dt / 6.0) * (k1 + 2.0 * k2 + 2.0 * k3 + k4);
    }

    [[nodiscard]] const Manifold2D& manifold() const noexcept { return manifold_; }

private:
    System2D sys_;
    Manifold2D manifold_;
};

} // namespace CM

int main() {
    CM::System2D sys{.gamma = 10.0};
    CM::SystemSolver solver(sys);

    std::cout << "=== C++20/23 Обчислення центрального многовиду ===\n";
    std::cout << std::format("h2 = {:.6f}, h3 = {:.6f}\n\n", 
                             solver.manifold().h2, solver.manifold().h3);

    double x_full = 0.4, y_full = 0.8;
    double x_red = 0.4;
    double t = 0.0;
    constexpr double dt = 0.01;
    constexpr int steps = 100;

    std::cout << std::format("{:<6} {:<12} {:<12} {:<12} {:<12}\n", 
                             "t", "x_full", "y_full", "x_red", "Error");
    std::cout << "---------------------------------------------------------\n";

    for (int i = 0; i <= steps; ++i) {
        if (i % 10 == 0) {
            double err = std::abs(x_full - x_red);
            std::cout << std::format("{:<6.2f} {:<12.6f} {:<12.6f} {:<12.6f} {:<12.6e}\n", 
                                     t, x_full, y_full, x_red, err);
        }
        solver.step_full_rk4(x_full, y_full, dt);
        solver.step_reduced_rk4(x_red, dt);
        t += dt;
    }

    return 0;
}
```

### Результати обчислювального експерименту та аналіз пасток

Результати виконання програми демонструють ключовий фізичний ефект: на початкових кроках (`t ∈ [0, 0.2]`) існує невелике відхилення `|x_full - x_red|` порядку `10⁻²`, оскільки початкова точка `y(0) = 0.8` знаходилася поза центральним многовидом `h(0.4) ≈ 0.32`. Однак за короткий час транзитного згасання `τ ~ 1/γ = 0.1` секунди фазова точка повної системи притягується до многовиду, після чого похибка падає до `10⁻⁵` і лишається на цьому рівні протягом усього подальшого розрахунку.

Основними пастками при практичній реалізації чисельної редукції є:

1. **Нехтування радіусом локальної збіжності Тейлорівського ряду**:
   Розклад `h(x)` є асимптотичним рядком Тейлора у околі нульового стану (`|x| < δ`). Якщо внаслідок зовнішнього обурення змінна `x` перевищує критичний радіус `δ`, наближена парабола `h₂(x)` дає суттєве викривлення векторного поля, що може призвести до хибної чисельної нестійкості.
2. **Застосування методів редукції при слабкій дисипації (`γ → 0`)**:
   У разі якщо коефіцієнт `γ` є малим (слабке згасання), характерний час релаксації стійкої моди порівнянний із часом еволюції нейтральної змінної `x`. У цій ситуації розділення часових масштабів (Time-scale separation) ламається, і спроба вилучити змінну `y` призводить до втрати динамічної точності.
3. **Обчислювальна жорсткість вихідної системи при чисельному інтегруванні**:
   При розв'язанні повної 2D системи крок `dt` обмежений умовою чисельної стійкості `dt < 2/γ`. Якщо задати `dt = 0.3` при `γ = 10`, явний метод Рунге-Кутти для 2D системи швидко вибухає, тоді як редукована 1D система на многовиді залишається абсолютно стійкою і дає правильний розв'язок.
4. **Похибка накопичення при обчисленні вищих Тейлорівських коефіцієнтів**:
   При обчисленні коефіцієнтів вищих ступенів `h₄, h₅` розв'язок системи лінійних алгебраїчних рівнянь за допомогою числових методів Gauss-Elimination може призводити до накопичення похибок заокруглення чисел із плаваючою комою (Floating Point Round-off Error). Для запобігання цьому рекомендується застосовувати математичні символьні обчислення (Computer Algebra Systems) або чисельну обробку з подвійною точністю `double`/`long double`.
