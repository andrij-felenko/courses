# 🧮 Математика атак на малі підгрупи, алгоритм Поліга — Геллмана та кофакторний захист

Класичний протокол узгодження ключів Діффі — Геллмана розгортається в мультиплікативній групі скінченного поля лишків `ℤₚ* = (ℤ / pℤ)*`, де `p` — велике просте число. Порядок цієї групи дорівнює `|ℤₚ*| = p - 1`. Згідно з фундаментальною теоремою Лагранжа (від франц. *Joseph-Louis Lagrange*), порядок будь-якої підгрупи `H` мусить бути дільником порядку всієї групи `|G| = p - 1`. Якщо число `p - 1` містить невеликі прості множники, у групі неминуче існують власні циклічні підгрупи малого порядку, що відкриває шлях до атаки обмеження малою підгрупою (англ. *Small Subgroup Confinement Attack*).

### Теорема Лагранжа та існування циклічних підгруп

Нехай `G` — скінченна абелева група порядку `N`, а `g` — її елемент. Порядком елемента `g` називається найменше додатне ціле число `d`, для якого виконується рівність:

```
g^d ≡ 1
```

З теореми Лагранжа випливає, що порядок будь-якого елемента `d = ord(g)` є дільником порядку групи `N` (`d | N`). Навпаки, для будь-якого дільника `d` числа `p - 1` у циклічній групі `ℤₚ*` існує рівно одна підгрупа порядку `d`. Якщо `g` — генератор усієї групи `ℤₚ*`, то елемент:

```
g_d = g^((p - 1) / d) mod p
```

є генератором підгрупи порядку `d`, оскільки:

```
(g_d)^d = (g^((p - 1) / d))^d mod p
        = g^(p - 1) mod p          [скорочення степенів]
        = 1                        [мала теорема Ферма]
```

### Редукція Поліга — Геллмана для факторизованого порядку

Нехай порядок групи факторизується на добуток простих степенів:

```
p - 1 = q₁^(e₁) · q₂^(e₂) · ... · qₖ^(eₖ)
```

Якщо всі прості дільники `qᵢ` є невеликими числами (так зване гладке число, англ. *smooth number*), дискретний логарифм `x` у рівнянні `Y = g^x mod p` ефективно обчислюється алгоритмом Роланда Поліга та Мартіна Геллмана (1978 рік).

Замість надважкого розв'язання задачі у великій групі порядку `p - 1`, обчислення редукуються до кожної окремої підгрупи простого порядку `qᵢ`:

```
g_i = g^((p - 1) / q_i) mod p      [генератор підгрупи порядку q_i]
Y_i = Y^((p - 1) / q_i) mod p      [проєкція публічного ключа в підгрупу]
```

Оскільки `(g_i)^(q_i) ≡ g^(p - 1) ≡ 1 mod p`, елемент `g_i` породжує підгрупу розміром лише `q_i`. У ній розв'язання дискретного логарифма вимагає не більше ніж `O(√q_i)` операцій за методом «великий крок — малий крок» Шенкса:

```
Y_i ≡ (g_i)^(x_i) mod p,  де x_i = x mod q_i
```

Отримавши систему порівнянь для всіх простих дільників:

```
x ≡ x₁ (mod q₁^(e₁))
x ≡ x₂ (mod q₂^(e₂))
...
x ≡ xₖ (mod qₖ^(eₖ))
```

Повний закритий показник `x` однозначно реконструюється за допомогою Китайської теореми про залишки (англ. *Chinese Remainder Theorem*, CRT) за поліноміальний час:

```
x = ∑ (x_i · M_i · N_i) mod (p - 1)
де M_i = (p - 1) / q_i^(e_i)
та  N_i = (M_i)⁻¹ mod q_i^(e_i)
```

Складність розв'язання дискретного логарифма за методом Поліга — Геллмана визначається не розміром модуля `p`, а розміром **найбільшого простого дільника** числа `p - 1`:

```
T_PohligHellman = O( ∑ e_i · (log_2(p) + √q_i) )
```

Якщо всі `q_i` не перевищують, наприклад, `2⁴⁰`, злам 2048-бітного ключа виконується за лічені секунди.

### Анатомія атаки обмеження підгрупою (Lim — Lee)

У протоколі Діффі — Геллмана активний супротивник Меллорі може зловживати складеною структурою групи навіть тоді, коли генератор `g` породжує велику підгрупу. Для цього Меллорі надсилає жертві (серверу Бобу) сфабрикований відкритий ключ `A'`, який навмисно обрано як генератор малої підгрупи порядку `q` (де `q | (p - 1)` і `q` — невелике число):

```
h = (p - 1) / q
A' = g^h mod p    [порядок елемента A' у групі дорівнює в точності q]
```

Коли добросовісний сервер Боб приймає `A'` і обчислює спільний секрет `K`, модульне піднесення до степеня автоматично проектує результат у малу підгрупу:

```
K = (A')^b mod p
  = (g^h)^b mod p          [підстановка підробленого ключа A' = g^h mod p]
  = g^(h · b) mod p        [модульне піднесення до степеня]
```

Оскільки `(A')^q ≡ 1 mod p`, множина можливих значень секрету `K` звужується від повного діапазону поля до всього `q` дискретних точок:

```
K ∈ { (A')⁰, (A')¹, (A')², ..., (A')^(q-1) } mod p
```

Коли Боб зашифрує перше повідомлення або відправить тестовий пакет (наприклад, повідомлення `Finished` у рукостисканні TLS), Меллорі перебирає лише `q` можливих симетричних ключів `K_test = KDF((A')^i mod p)`. Той ключ, який успішно розшифровує пакет або дає коректний MAC-тег, однозначно визначає залишок закритого ключа сервера:

```
b ≡ i (mod q)
```

Повторюючи цей запит із різними малими підгрупами `q₁, q₂, ..., qₘ`, Меллорі накопичує достатню кількість залишків, щоб за CRT повністю відновити статичний або довгостроковий закритий ключ сервера `b`.

### Інженерний захист: безпечні прості числа Софі Жермен

Математично строгий спосіб унеможливити існування небезпечних малих підгруп у групі `ℤₚ*` — вибір так званого безпечного простого числа (англ. *Safe Prime*).

Просте число `p` називається безпечним, якщо воно має вигляд:

```
p = 2 · q + 1
```

де `q` — також велике просте число (яке називають простим числом Софі Жермен, франц. *Marie-Sophie Germain*).

Порядок мультиплікативної групи для такого модуля дорівнює:

```
|ℤₚ*| = p - 1 = 2 · q
```

Згідно з теоремою Лагранжа, дільниками числа `2q` можуть бути виключно чотири числа:

```
Div(2q) = { 1, 2, q, 2q }
```

Це означає, що в групі існують підгрупи лише трьох порядків:
1. Порядок `1`: тривіальний елемент `1`.
2. Порядок `2`: елемент `-1 ≡ p - 1 mod p` (оскільки `(p - 1)² ≡ 1 mod p`).
3. Порядок `q`: велика підгрупа квадратичних лишків (підгрупа Шнора), де дискретний логарифм є криптографічно стійким.

Захист від атак на малі підгрупи для safe primes зводиться до елементарної верифікації відкритого ключа `A`:

```
1 < A < p - 1
A^q mod p ≡ 1
```

Якщо `A = 1` або `A = p - 1`, ключ негайно відхиляється. Перевірка `A^q ≡ 1 mod p` гарантує, що відкритий ключ належить єдиній правильній підгрупі великого простого порядку `q`.

### Кофакторний захист на еліптичних кривих та Clamping

На відміну від скінченних полів, де прості модулі підбираються вручну під умову `p = 2q + 1`, порядок групи точок еліптичної кривої `E(𝔽ₚ)` за теоремою Гассе (англ. *Hasse's Theorem*) лежить у діапазоні:

```
p + 1 - 2√p ≤ #E(𝔽ₚ) ≤ p + 1 + 2√p
```

Загальний порядок кривої часто не є простим числом і факторизується як `N = #E(𝔽ₚ) = h · q`, де `q` — великий простий порядок базової криптографічної підгрупи, а ціле число `h` називається кофактором (англ. *cofactor*, від лат. *cum* — разом і *factor* — чинник).

Наприклад, стандартна крива Монтгомері Curve25519 (RFC 7748) має порядок:

```
#E(𝔽₂₅₅₁₉) = 8 · (2²⁵² + 27742317777372353535851937790883648493)
h = 8
```

Наявність кофактора `h = 8` означає, що на кривій існують точки малого порядку `1, 2, 4, 8`. Якщо зловмисник передасть точку малого порядку `P_low`, то скалярний добуток `k · P_low` викаже молодші біти приватного скаляра `k mod 8`.

Для повного усунення цієї вразливості в протоколі X25519 застосовується техніка бітового маскування скаляра (англ. *Scalar Clamping*). Перед обчисленням скалярного множення 32-байтний випадковий масив `k` модифікується на рівні бітів:

```
k[0]  &= 248;    [скидання бітів 0, 1, 2: скаляр стає кратним 8 (k = 8 · m)]
k[31] &= 127;    [скидання біта 255: гарантія k < 2²⁵⁵]
k[31] |= 64;     [встановлення біта 254: гарантія фіксованої довжини ітерацій]
```

Завдяки скиданню молодших трьох бітів (`k[0] &= 248`, що еквівалентно `k ≡ 0 mod 8`), множення на скаляр `k` будь-якої точки з малої підгрупи `P_low` дає:

```
k · P_low = (8 · m) · P_low      [підстановка розкладу скаляра k = 8 · m]
          = m · (8 · P_low)      [асоціативність скалярного множення]
          = m · O                [порядок точки P_low ділить 8: 8 · P_low = O]
          = O                    [добуток будь-якого скаляра на нейтральний елемент O]
```

Будь-яка спроба атаки малою підгрупою в Curve25519 нейтралізується на алгебраїчному рівні без потреби у важких операціях валідації точок.
