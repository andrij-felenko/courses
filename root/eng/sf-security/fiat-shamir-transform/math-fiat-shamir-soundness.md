# 🧮 Обґрунтованість евристики Фіата — Шаміра: модель випадкового оракула та лема про розгалуження

Математичний аналіз перетворення Фіата — Шаміра визначає умови, за яких інтерактивний протокол доведення знання перетворюється на безпечний неінтерактивний аргумент або цифровий підпис. Головною загрозою при видаленні інтерактивного верифікатора є втрата обґрунтованості (soundness): якщо інтерактивний верифікатор гарантує, що необознаний доводжувач може обдурити його лише з малою ймовірністю, то в неінтерактивній версії атакуючий може обчислювати хеш-значення від багатьох різних зобов'язань, шукаючи таке `α`, для якого випадковий виклик `β = H(x || α)` виявиться зручним для підробки.

Математичний апарат обґрунтованості Фіата — Шаміра спирається на три стовпи: властивість спеціальної обґрунтованості базового Σ-протоколу, формалізацію оракула у Моделі випадкового оракула (ROM) та редукцію за допомогою Леми про розгалуження (Forking Lemma).

## 1. Базові властивості інтерактивного Σ-протоколу

Нехай `L` — мова у `NP` з відношенням верифікації `R(x, w) = 1`, де `x` — вхідне твердження (публічний ключ чи умова), а `w` — свідок (секретний ключ). Трираундовий інтерактивний протокол з публічними монетами між Доводжувачем `P` та Верифікатором `V` називається Σ-протоколом, якщо він задовольняє три математичні вимоги:

1. **Повнота (Completeness):** Якщо `(x, w) ∈ R`, то для чесно згенерованого транскрипту `(α, β, γ)` верифікатор завжди приймає доказ:
```
Pr[ V(x, α, β, γ) = 1 ] = 1
```

2. **Спеціальна обґрунтованість (Special Soundness):** Існує поліноміальний детермінований алгоритм (Екстрактор `E`), який за двома приймаючими транскриптами з однаковим зобов'язанням `α`, але різними викликами `β₁ ≠ β₂`:
```
(α, β₁, γ₁)  та  (α, β₂, γ₂)   де  V(x, α, β₁, γ₁) = 1  і  V(x, α, β₂, γ₂) = 1
```
обчислює точний свідок `w = E(x, α, β₁, γ₁, β₂, γ₂)` за поліномний час. Ймовірність успіху підробки для одного виклику обмежена величиною `1 / |K|`, де `K` — простір викликів.

3. **Зорове нульове розголошення щодо чесного верифікатора (HVZK):** Існує поліноміальний Імітатор (Симулятор `S`), який за вхідним `x` та випадковим викликом `β` генерує транскрипт `(α, β, γ)` з розподілом, неотличимим від розподілу справжніх протокольних транскриптів, не знаючи свідка `w`.

## 2. Формалізація перетворення Фіата — Шаміра у ROM

У перетворенні Фіата — Шаміра виклик `β` обчислюється як:
```
β = H(x || α)      [для неінтерактивного доказу NIZK]
β = H(m || α)      [для цифрового підпису повідомлення m]
```
де `H: {0,1}* → K` — хеш-функція з простором виходів `K` розміру `2^k`.

У Моделі випадкового оракула (ROM) хеш-функція `H` моделюється як функція, обрана випадково з множини всіх можливих функцій. Противник `A` не має доступ до внутрішньої структури `H`, а може лише робити аналітичні запити до оракула `H(u)`.

Якщо противник `A` здійснює не більше `q[H]` запитів до хеш-оракула `H` та генерує підроблений підпис `(α, γ)` для твердження `x` (або повідомлення `m`), то ймовірність його успіху `ε[A]` зв'язана з ймовірністю вилучення свідка `ε[ext]` наступною розрахунковою формулою.

## 3. Лема про розгалуження (Pointcheval — Stern Forking Lemma)

Для доведення безпеки схеми використовують метод перемотування (rewinding). Оскільки оракул `H` знаходиться під контролем симулятора редукції `B`, симулятор може перехоплювати запити противника `A` та фіксувати відповіді.

Нехай противник `A` запускається з випадковою стрічкою `r` та оракулом `H`. Припустимо, `A` робить запити `u₁, u₂, ..., u[q]` до `H`. Якщо `A` видає valid підпис `(α, γ)` для `x`, то з високою ймовірністю зобов'язання `α` відповідає одному із запитів `u[i] = (x || α)`.

Симулятор `B` виконує алгоритм розгалуження:

1. **Перший прогон:** `B` запускає `A(x; r)` та відповідає на запити до оракула випадковими значеннями `h₁, h₂, ..., h[q]`. Якщо `A` видає коректну трійку `(α, β₁, γ₁)` на кроці `i`, де `β₁ = h[i]`, симулятор фіксує цей результат.

2. **Другий прогон (Розгалуження):** `B` перезапускає `A` з ТІЄЮ Ж випадковою стрічкою `r` та тими ж відповідями оракула `h₁, ..., h[i-1]` до кроку `i-1`. На кроці `i` симулятор дає СВІЖЕ випадкове значення `h'i ≠ h[i]`. Для подальших запитів `j > i` симулятор дає нові випадкові значення `h'j`.

3. **Результат:** Завдяки однаковій випадковій стрічці `r` та ідентичним відповідям оракула до кроку `i-1`, противник `A` робить абсолютно однакові обчислення та видає ТЕ САМЕ зобов'язання `α`. На кроці `i` він отримує новий виклик `β₂ = h'i`. Якщо `A` знову успішно завершує підробку, він видає другу відповідь `γ₂`.

У результаті симулятор `B` отримує дві трійки `(α, β₁, γ₁)` та `(α, β₂, γ₂)` з `β₁ ≠ β₂`. Оскільки базовий протокол володіє спеціальною обґрунтованістю, симулятор застосовує Екстрактор `E` та обчислює секретний свідок `w`.

### 3.1 Математична оцінка ймовірності

Згідно з лемою про розгалуження Пуаншваля — Стерна, якщо противник `A` перемагає з ймовірністю `ε` за час `T`, роблячи `q[H]` запитів до хеш-оракула, то ймовірність вилучення свідка `ε[ext]` алгоритмом `B` за час `T' ≈ 2T` оцінюється нижньою межею:

```
ε[ext] ≥ (ε / q[H]) - (1 / |K|)
```

При послідовному або паралельному повторенні розгалуження ймовірність успіху редукції виражається точніше:

```
ε[ext] ≥ (ε² / q[H]) - (ε / |K|)
```

Це доводить, що якщо розмір виклику `|K| = 2^k` є достатньо великим (наприклад, `k ≥ 128` біт або `k ≥ 256` біт), а середня ймовірність підробки `ε` є ненехтовною, то симулятор `B` гарантовано зламає базову математичну проблему за поліноміальний час.

## 4. Оцінка стійкості до квантових атак (QROM)

У Квантовій моделі випадкового оракула (QROM), запровадженій Деніелом Унру (Daniel Unruh) у 2015 році, квантовий противник може запитувати хеш-оракул у стані квантової суперпозиції:

```
|ψ⟩ = ∑_x c[x] |x, 0⟩  ↦  ∑_x c[x] |x, H(x)⟩
```

У цій моделі класична лема про розгалуження втрачає силу, оскільки квантовий стан неможливо скопіювати (теорема про заборону клонування) або виміряти без руйнування суперпозиції (перемотування стає руйнівним).

Для збереження обґрунтованості у QROM застосовують додаткові техніки:
- **Перетворення Унру (Unruh Transform):** доповнення доказу відповідями на всі можливі виклики або зашифрованими варіантами.
- **Підхід Дона — Фейрзінгєра — Маджафо — Опрепрехт (QROM Forking):** використання вимірювань у стилі стирання (measure-and-rewind) для отримання квантової редукції з поліноміальною втратою щільності (lossiness).
