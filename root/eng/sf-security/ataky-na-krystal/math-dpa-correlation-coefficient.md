# 🧮 Математичні моделі витоку та кореляційний аналіз енергоспоживання

Фізичний процес виконання обчислень у цифрових напівпровідникових схемах нерозривно пов'язаний зі споживанням енергії. Математичний апарат аналізу побічних каналів перетворює статистичну сукупність виміряних сигналів енергоспоживання або електромагнітної емісії на оцінку секретних параметрів криптосистеми.

## Фізико-математична модель енергоспоживання КМОН-вентиля

У цифровій КМОН-логіці основне споживання енергії відбувається в моменти зміни логічних станів (динамічне енергоспоживання). Повна миттєва потужність процесора в момент часу `t` виражається сумою трьох складових:

```text
P_total(t) = P_dynamic(t) + P_static(t) + ε(t)
P_dynamic(t) = Σ [ 0.5 · C_j · V_dd² · N_j(t) ]
```

де:
- `C_j` — паразитна ємність j-го вузла схеми (провідників, затворів польових транзисторів);
- `V_dd` — напруга шини живлення ядра;
- `N_j(t) ∈ {0, 1}` — індикатор перемикання стану j-го вузла в момент часу `t` (значення 1 при переході `0 → 1` або `1 → 0`, значення 0 за відсутності зміни стану);
- `P_static(t) = I_leak · V_dd` — потужність статичного витоку струму через зворотні струми p-n переходів та підпорогові витоки польових транзисторів;
- `ε(t)` — некорельований адитивний електронний шум вимірювального тракту з нульовим математичним сподіванням `E[ε(t)] = 0` та дисперсією `σ_ε²`.

Оскільки значення `N_j(t)` безпосередньо залежить від оброблюваних даних, сумарне енергоспоживання чіпа лінійно відображає кількість бітів, що змінюють свій стан у процесорних регістрах та шинах.

## Моделі витоку інформації: вага та дистанція Геммінґа

Для практичного моделювання енергоспоживання використовуються дві основні детерміновані метрики.

### 1. Модель ваги Геммінґа (Hamming Weight Model)
Застосовується у випадках, коли шина даних або внутрішній регістр перед кожною операцією скидається в попередній нульовий стан (так звана домінуюча динамічна логіка з фазою попереднього заряду, *Precharge Logic*).

Вага Геммінґа `HW(x)` для k-бітного двійкового слова `x = (x₀, x₁, ..., x_{k-1})` визначається як кількість одиничних бітів у слові:

```text
HW(x) = Σ x_j  [сума для j від 0 до k-1, де x_j ∈ {0, 1}]
```

Модельоване споживання енергії `W` для проміжного значення `V` описується лінійною функцією:

```text
W = a · HW(V) + b + ε
```

де `a` — масштабний коефіцієнт (енергія перезаряджання одиничного біта), `b` — базове статичне споживання схеми, а `ε` — гаусівський шум.

### 2. Модель дистанції Геммінґа (Hamming Distance Model)
Застосовується у синхронних мікропроцесорних архітектурах із класичними тригерами, де шина або регістр зберігає попереднє значення `V_{t-1}` до моменту запису нового значення `V_t`.

Дистанція Геммінґа `HD(V_{t-1}, V_t)` вимірює кількість бітів, які змінили свій стан між двома послідовними тактами:

```text
HD(V_{t-1}, V_t) = HW(V_{t-1} ⊕ V_t) = Σ (x_{j, t-1} ⊕ x_{j, t})
```

Модельоване споживання енергії для переходу стану має вигляд:

```text
W = a · HD(V_{t-1}, V_t) + b + ε = a · HW(V_{t-1} ⊕ V_t) + b + ε
```

## Математичний апарат класичного DPA (Різниця середніх)

Класичний метод диференційного аналізу енергоспоживання Кохера спирається на розділення набору виміряних осцилограм на дві підмножини за допомогою селекторної функції (предиката витоку).

Нехай записано `N` осцилограм споживання `T_i(t)` (`i = 1, ..., N`), кожна з яких відповідає шифруванню відомого відкритого тексту `P_i`. Припустимо, що атакується перший раунд алгоритму AES, де обчислюється вихід таблиці підстановок `S-Box`:

```text
V(P_i, k) = Sbox(P_i ⊕ k)
```

де `k` — гіпотеза щодо одного байта секретного ключа (`k ∈ {0, 1, ..., 255}`).

Обирається предикатна функція `D(P_i, k) ∈ {0, 1}` (наприклад, значення наймолодшого біта проміжного байта: `D(P_i, k) = LSB(V(P_i, k))`).

Усі `N` осцилограм розбиваються на дві групи:
- Група `S₁ = { T_i(t) : D(P_i, k) = 1 }` потужністю `N₁`;
- Група `S₀ = { T_i(t) : D(P_i, k) = 0 }` потужністю `N₀`.

Обчислюється диференційний слід `Δ_k(t)` як різниця вибіркових середніх значень:

```text
Δ_k(t) = [ (1 / N₁) · Σ T_i(t) для T_i ∈ S₁ ] - [ (1 / N₀) · Σ T_i(t) для T_i ∈ S₀ ]
```

### Статистична поведінка диференційного сліду

1. **Неправильна гіпотеза ключа (`k ≠ k*`):** значення предиката `D(P_i, k)` некорельоване з реальним фізичним станом процесора. Обидві підмножини `S₁` та `S₀` містять випадкову рівномірну суміш фізичних перемикань. За законом великих чисел при зростанні `N → ∞`:

```text
lim (Δ_k(t)) = E[T(t) | D=1] - E[T(t) | D=0] = E[T(t)] - E[T(t)] = 0
```

2. **Правильна гіпотеза ключа (`k = k*`):** поділ на групи точно відображає моменти, коли цільовий біт апаратного регістра дорівнював 1 або 0. У точці часу `t*`, коли процесор завантажує значення `V(P_i, k*)` на шину, виникає виражений диференційний сплеск амплітуди:

```text
Δ_{k*}(t*) = a · (1 - 0) = a > 0
```

## Кореляційний аналіз енергоспоживання (CPA)

Кореляційний аналіз енергоспоживання (Correlation Power Analysis, CPA) є потужним узагальненням DPA, яке використовує всю інформацію про вагу або дистанцію Геммінґа цілого байта (а не одного виділеного біта).

Для кожної з `N` операцій та для кожної з 256 гіпотез ключа `k` обчислюється матриця передбачуваного споживання:

```text
H_{i, k} = HW( Sbox(P_i ⊕ k) )
```

Кореляція між вектором реальних вимірювань `T(t) = (T₁(t), T₂(t), ..., T_N(t))` та вектором модельованого споживання `H_k = (H_{1, k}, H_{2, k}, ..., H_{N, k})` розраховується за формулою лінійного коефіцієнта кореляції Пірсона:

```text
ρ_k(t) = [ Σ (T_i(t) - μ_T(t)) · (H_{i, k} - μ_{H_k}) ] / [ sqrt( Σ (T_i(t) - μ_T(t))² ) · sqrt( Σ (H_{i, k} - μ_{H_k})² ) ]
```

де:
- `μ_T(t) = (1 / N) · Σ T_i(t)` — вибіркове середнє виміряних сигналів у момент часу `t`;
- `μ_{H_k} = (1 / N) · Σ H_{i, k}` — теоретичне середнє модельованої ваги Геммінґа (для 8-бітного рівномірного випадкового розподілу `μ_{H_k} = 8 / 2 = 4.0`).

Правильний ключ `k*` ідентифікується за максимальним абсолютним значенням коефіцієнта кореляції:

```text
k* = arg max_k ( max_t |ρ_k(t)| )
```

## Співвідношення сигнал/шум та гранична кількість осцилограм

Успішність виділення піка кореляції залежить від співвідношення сигнал/шум (Signal-to-Noise Ratio, SNR) вимірювального середовища. 

Нехай фізичний сигнал витоку має дисперсію `σ_signal² = Var(a · HW(V))`, а електронний та процесорний шум має дисперсію `σ_noise² = Var(ε)`. SNR визначається як:

```text
SNR = σ_signal² / σ_noise²
```

Для 8-бітної випадкової величини дисперсія ваги Геммінґа дорівнює:

```text
Var(HW(X)) = 8 · p · (1 - p) = 8 · 0.5 · 0.5 = 2.0
```

Коефіцієнт кореляції для правильного ключа `ρ_{max}` пов'язаний з SNR співвідношенням:

```text
ρ_{max} = sqrt( σ_signal² / (σ_signal² + σ_noise²) ) = sqrt( SNR / (SNR + 1) )
```

Мінімальна кількість осцилограм `N_{min}`, необхідна для достовірного виявлення кореляційного піка з довірчою ймовірністю `1 - α` (де значення `z_{1-α}` є квантилем стандартного нормального розподілу, наприклад `z ≈ 4.5` для надійного відокремлення від 255 хибних гіпотез), обмежується оцінкою Манджарда (Mangard):

```text
N_{min} ≈ 3 + 8 · [ (z_{1-α/2} + z_{1-β}) / ln((1 + ρ_{max}) / (1 - ρ_{max})) ]² ≈ c / ρ_{max}²
```

Якщо за наявності апаратного шуму `ρ_{max} ≈ 0.05`, то мінімальна кількість осцилограм для зламу становить:

```text
N_{min} ≈ 10 / (0.05)² = 10 / 0.0025 = 4 000 осцилограм
```

## Математичний доказ стійкості булевого маскування 1-го порядку

Булеве маскування першого порядку полягає в розщепленні кожного проміжного закритого значення `x` на дві незалежні частки (акції): випадкову маску `m ∈_R {0, 1}^n` та масковане значення `x'`:

```text
x' = x ⊕ m
```

Обчислимо умовний розподіл і математичне сподівання ваги Геммінґа для замаскованого значення `x'` за умови фіксованого значення секрету `x`.

Оскільки маска `m` генерується істинним генератором випадкових чисел (TRNG) незалежно для кожної операції, розподіл ймовірностей бітів маски є суворо рівномірним:

```text
P(m = v) = 1 / 2^n,  для будь-якого v ∈ {0, 1}^n
```

Для будь-якого фіксованого значення секрету `x`, значення `x' = x ⊕ m` набуває кожного з `2^n` можливих станів із абсолютно однаковою ймовірністю:

```text
P(x' = u | x) = P(x ⊕ m = u) = P(m = x ⊕ u) = 1 / 2^n
```

Звідси випливає, що умовне математичне сподівання ваги Геммінґа маскованого значення є строго константним і не залежить від секрету `x`:

```text
E[ HW(x') | x ] = Σ [ HW(u) · P(x' = u | x) ]
                = (1 / 2^n) · Σ HW(u)  [сума по всіх u від 0 до 2^n - 1]
                = (1 / 2^n) · (n · 2^{n-1})
                = n / 2
```

Для 8-бітної змінної (`n = 8`):

```text
E[ HW(x') | x ] = 8 / 2 = 4.0  [для будь-якого вхідного значення x]
```

Оскільки коваріація між модельованим значенням секрету та виміряним енергоспоживанням дорівнює нулю:

```text
Cov(HW(x'), f(x)) = E[HW(x') · f(x)] - E[HW(x')] · E[f(x)] = 0
```

коефіцієнт лінійної кореляції Пірсона тотожно обнуляється:

```text
ρ(x', f(x)) = 0
```

Цей математичний факт доводить, що диференційний та кореляційний аналіз енергоспоживання 1-го порядку принципово не здатні витягти секрет із коректно замаскованої криптографічної схеми. Для її зламу супротивник змушений переходити до аналізу 2-го порядку (комбінованої кореляції часток `x'` та `m`), складність якого квадратично зростає за шумом: `N_{2nd} ∝ (1 / SNR)²`.
