# 🧮 Алгоритм Берлекампа-Мессі та лінійна складність LFSR

Стійкість будь-якого генератора псевдовипадкових послідовностей на регістрах зсуву визначається його **лінійною складністю** — мінімальною довжиною регістру з лінійним зворотним зв'язком (LFSR), здатного згенерувати цю послідовність. Якщо лінійна складність послідовності дорівнює `L`, то алгоритм Берлекампа-Мессі гарантовано знаходить мінімальний характеристичний поліном зворотного зв'язку та весь початковий стан регістру всього за `2L` послідовних бітів за час `O(L²)`.

## Математична модель LFSR над полем GF(2)

Розглянемо бінарний регістр зсуву довжиною `L` бітів. Стан регістру в дискретний момент часу `t` задається вектором `S_t = (s_t, s_{t+1}, ..., s_{t+L-1}) ∈ GF(2)ᴸ`.

На кожному такті молодший біт `s_t` виводиться як черговий біт гами, біти регістру зсуваються праворуч на одну позицію, а новий біт зворотного зв'язку `s_{t+L}` обчислюється як лінійна комбінація попередніх комірок у скінченному полі Галуа `GF(2)`:

```
s_{t+L} = c₁ · s_{t+L-1} ⊕ c₂ · s_{t+L-2} ⊕ ... ⊕ c_L · s_t = ∑_{i=1}^L c_i · s_{t+L-i}  (mod 2)
```

де `c_i ∈ {0, 1}` — фіксовані коефіцієнти зворотного зв'язку, причому `c_L = 1` (інакше фактична розмірність стану регістру строго менша за `L`).

### Матричне подання та супутня матриця

Перехід між станами LFSR є лінійним оператором у векторному просторі `GF(2)ᴸ` і описується **супутньою матрицею Фробеніуса** (Companion Matrix) `M`:

```
[ s_{t+1}   ]   [ 0   1   0   ...  0   ] [ s_t     ]
[ s_{t+2}   ]   [ 0   0   1   ...  0   ] [ s_{t+1} ]
[ ...       ] = [ ... ... ... ...  ... ] [ ...     ]
[ s_{t+L-1} ]   [ 0   0   0   ...  1   ] [ s_{t+L-2} ]
[ s_{t+L}   ]   [ c_L c_{L-1} ... c₂ c₁ ] [ s_{t+L-1} ]
```

Стан регістру на довільному кроці `t` виражається через початковий вектор заповнення `S₀` за допомогою піднесення матриці до степеня: `S_t = Mᵗ · S₀`. Відповідно до теореми Гамільтона-Келі, будь-яка матриця занулює свій характеристичний многочлен: `P(M) = 0`.

### Многочлени зв'язку та генератриса послідовності

Лінійне рекурентне співвідношення зручно подати через **поліном зворотного зв'язку** (поліном підключень) `C(D)` або **характеристичний поліном** `P(x)` над кільцем многочленів `GF(2)[D]`:

```
C(D) = 1 ⊕ c₁·D ⊕ c₂·D² ⊕ ... ⊕ c_L·Dᴸ
```

Формальний степеневий ряд (твірна функція або генератриса) вихідної послідовності `S(D) = ∑_{t=0}^∞ s_t · Dᵗ` пов'язаний із поліномом зворотного зв'язку фундаментальною тотожністю:

```
S(D) · C(D) = P(D)  (mod D^N)
```

де `P(D)` — многочлен початкового стану степеня `deg(P) < L`, який однозначно залежить від початкових `L` бітів `(s₀, s₁, ..., s_{L-1})`. Отже, генератриса вихідного потоку є раціональною функцією:

```
S(D) = P(D) / C(D)
```

Якщо многочлен `C(D)` є **примітивним** над `GF(2)` (тобто незвідним і його корінь `α` породжує мультиплікативну групу розширення поля `GF(2ᴸ)*`), то період згенерованої вихідної послідовності досягає теоретичного максимуму:

```
T_max = 2ᴸ - 1
```

Такі послідовності називаються **послідовностями максимальної довжини** (m-послідовностями або m-sequences). Вони мають бездоганні статистичні характеристики:
- *Властивість збалансованості:* кількість одиниць у періоді рівно на одиницю більша за кількість нулів (`2^{L-1}` одиниць проти `2^{L-1} - 1` нулів).
- *Властивість серій (Run property):* половина всіх серій однакових бітів має довжину 1, чверть — довжину 2, одна восьма — довжину 3 тощо.
- *Двозначна автокореляція:* автокореляційна функція `R(k)` дорівнює `1` при `k = 0` та строго `-1/(2ᴸ - 1)` при всіх `k ≠ 0`.

Проте їхня криптографічна надійність є нульовою через цілковиту лінійність алгебраїчних зв'язків між бітами.

## Формальна постановка задачі синтезу

Нехай супротивник перехопив скінченний фрагмент послідовності довжиною `N` бітів:

```
s^N = (s₀, s₁, s₂, ..., s_{N-1})
```

**Задача лінійного криптоаналізу:** знайти найкоротший LFSR (поліном `C(D)` мінімального степеня `L`), який генерує заданий префікс `s^N`.

Супротивник міг би скласти систему з `N - L` лінійних алгебраїчних рівнянь над `GF(2)` відносно `L` невідомих коефіцієнтів `(c₁, c₂, ..., c_L)`:

```
[ s_{L-1}   s_{L-2}   ...  s₀     ] [ c₁  ]   [ s_L     ]
[ s_L       s_{L-1}   ...  s₁     ] [ c₂  ] = [ s_{L+1} ]
[ ...       ...       ...  ...    ] [ ... ]   [ ...     ]
[ s_{N-2}   s_{N-3}   ...  s_{N-L-1}] [ c_L ]   [ s_{N-1} ]
```

Це матриця Тепліца (або Ганкеля). Звичайний метод Гаусса розв'язує таку систему за `O(L³)`. Елвін Берлекамп (1968) при розкодуванні кодів Боуза-Чоудхурі-Хоквінгема (БЧХ) та Джеймс Мессі (1969) розробили ітеративний алгоритм, еквівалентний розкладу формального степеневого ряду в ланцюговий дріб Паде зі складністю всього `O(L²)`.

## Алгоритм Берлекампа-Мессі: покроковий механізм

Алгоритм обробляє біти послідовності `s₀, s₁, s₂, ...` по одному на кожному кроці `n` від `0` до `N-1`. На кожній ітерації підтримується поточний мінімальний поліном `C(D)` поточної лінійної складності `L`.

### Змінні та структури стану

1. `n` — номер поточного кроку (індекс аналізованого біта `s_n`).
2. `C(D)` — поточний поліном підключень мінімального LFSR (ініціалізується `C(D) = 1`).
3. `L` — поточна лінійна складність (степінь LFSR, ініціалізується `L = 0`).
4. `B(D)` — поліном підключень старого LFSR до моменту останньої зміни довжини `L` (ініціалізується `B(D) = 1`).
5. `m` — номер ітерації, на якій востаннє збільшувалася довжина `L` (ініціалізується `m = -1`).
6. `b` — значення розбіжності на кроці `m` (над `GF(2)` завжди `b = 1`).

### Крок ітерації та розрахунок розбіжності

Для поточного біта `s_n` обчислюється **невідповідність (розбіжність, discrepancy)** `d_n` між фактичним значенням біта `s_n` та значенням, передбаченим поточним поліномом `C(D)`:

```
d_n = s_n ⊕ ∑_{i=1}^L c_i · s_{n-i}  (mod 2)
```

Аналізується значення `d_n`:

**Випадок 1: `d_n = 0`**
Поточний LFSR правильно передбачив біт `s_n`. Поліном `C(D)` та складність `L` залишаються без змін. Система переходить до наступного біта.

**Випадок 2: `d_n = 1`**
Поточний LFSR дав збій і потребує корекції. Формується коригувальний поліном на основі старого збереженого полінома `B(D)`, зсунутого на `n - m` позицій у часі:

```
T(D) = C(D) ⊕ D^(n - m) · B(D)
```

Оскільки `B(D)` на кроці `m` мав розбіжність `1`, додавання `D^{n-m} · B(D)` інвертує передбачення на кроці `n`, компенсуючи помилку `d_n = 1` та зберігаючи правильні передбачення на всіх попередніх кроках `0, 1, ..., n-1`.

Далі перевіряється умова зміни довжини регістра:
- Якщо `2L ≤ n`: поточна довжина `L` була замалою, щоб згенерувати `n + 1` бітів. Лінійна складність стрибкоподібно збільшується за фундаментальною формулою Мессі:
  ```
  L_new = n + 1 - L
  B(D)  = C(D)
  m     = n
  b     = d_n
  ```
- Якщо `2L > n`: поточної довжини `L` математично достатньо для представлення послідовності. Складність `L` не змінюється (`L_new = L`), а старі значення `B(D)` та `m` зберігаються для можливих наступних корекцій.

Оновлюється робочий поліном: `C(D) = T(D)`.

## Числовий приклад розрахунку на 8 бітах

Простежимо виконання алгоритму для бінарної послідовності довжиною 8 бітів: `s = (1, 0, 1, 1, 0, 0, 1, 0)`.

| Крок `n` | Біт `s_n` | Розбіжність `d_n` | Новий поліном `C(D)` | Лінійна складність `L` | Попередній крок `m` | Старий `B(D)` |
|---|---|---|---|---|---|---|
| Старт | — | — | `1` | `0` | `-1` | `1` |
| `0` | `1` | `d₀ = 1` | `1 ⊕ D^(0 - (-1))·1 = 1 ⊕ D` | `0 + 1 - 0 = 1` | `0` | `1` |
| `1` | `0` | `d₁ = 0 ⊕ 1·1 = 1` | `(1 ⊕ D) ⊕ D^(1 - 0)·1 = 1` | `1 + 1 - 1 = 1` | `1` | `1 ⊕ D` |
| `2` | `1` | `d₂ = 1 ⊕ 0 = 1` | `1 ⊕ D^(2 - 1)·(1 ⊕ D) = 1 ⊕ D ⊕ D²` | `2 + 1 - 1 = 2` | `2` | `1` |
| `3` | `1` | `d₃ = 1 ⊕ 1·1 ⊕ 1·0 = 0` | `1 ⊕ D ⊕ D²` (без змін) | `2` | `2` | `1` |
| `4` | `0` | `d₄ = 0 ⊕ 1·1 ⊕ 1·1 = 0` | `1 ⊕ D ⊕ D²` (без змін) | `2` | `2` | `1` |
| `5` | `0` | `d₅ = 0 ⊕ 1·0 ⊕ 1·1 = 1` | `(1 ⊕ D ⊕ D²) ⊕ D^(5-2)·1 = 1 ⊕ D ⊕ D² ⊕ D³` | `5 + 1 - 2 = 4` | `5` | `1 ⊕ D ⊕ D²` |
| `6` | `1` | `d₆ = 1 ⊕ 0 ⊕ 0 ⊕ 1 = 0` | `1 ⊕ D ⊕ D² ⊕ D³` (без змін) | `4` | `5` | `1 ⊕ D ⊕ D²` |
| `7` | `0` | `d₇ = 0 ⊕ 1 ⊕ 0 ⊕ 1 = 0` | `1 ⊕ D ⊕ D² ⊕ D³` (без змін) | `4` | `5` | `1 ⊕ D ⊕ D²` |

На виході після обробки 8 бітів отримано мінімальний поліном зворотного зв'язку `C(D) = 1 ⊕ D ⊕ D² ⊕ D³` зі складністю `L = 4` (регістр із 4 комірок). Усі наступні біти тепер обчислюються детерміністично.

## Крайові випадки та поведінка складності

Аналіз лінійної складності `L(n)` як функції від довжини послідовності `n` демонструє характерні математичні патерни (профіль лінійної складності):

1. **Суцільні нулі `(0, 0, 0, ...)`:** Лінійна складність тотожно дорівнює `L = 0`. Регістр відсутній, поліном `C(D) = 1`.
2. **Одиничний імпульс на позиції `k` `(0, 0, ..., 0, 1, 0, ...)`:** На перших `k` кроках складність `L = 0`. На кроці `k` виникає `d_k = 1`, і складність стрибає до `L = k + 1`. Це демонструє, що поодинокий біт може штучно завищити лінійну складність на початку послідовності.
3. **Періодична послідовність періоду `T`:** Лінійна складність строго обмежена зверху довжиною періоду: `L ≤ T`. Якщо період `T = 2^k`, складність може бути суттєво меншою (наприклад, для чергування `1, 0, 1, 0, ...` період `T = 2`, а `L = 2` з поліномом `C(D) = 1 ⊕ D²`).
4. **Ідеально випадкова послідовність:** Для справжнього випадкового шуму профіль лінійної складності коливається довкола теоретичної прямої `L(n) ≈ n / 2`, здійснюючи нерегулярні сходинкові стрибки.

## Доведення достатності межі 2L бітів

Теорема Мессі встановлює фундаментальне правило однозначності розв'язку:

1. Якщо довжина спостережуваного фрагмента `N < 2L`, у просторі многочленів існує декілька різних лінійних рекурентностей степеня `≤ L`, що узгоджуються з префіксом `s^N`. Значень наступних бітів передбачити неможливо.
2. Щойно `N ≥ 2L`, отриманий за алгоритмом Берлекампа-Мессі мінімальний многочлен `C(D)` стає **строго єдиним**. Будь-який наступний біт `s_{2L}, s_{2L+1}, ...` передбачається зі стовідсотковою точністю.

Зв'язок із теорією апроксимацій Паде та розширеним алгоритмом Евкліда над полем `GF(2)[D]` дозволяє за допомогою техніки швидкого множення поліномів (Fast Fourier Transform / Schönhage-Strassen) реалізувати **швидкий алгоритм Берлекампа-Мессі** (Half-GCD approach), який знижує асимптотичну складність відновлення LFSR до:

```
O(L · log² L)
```

Це остаточно ставить крапку на використанні лінійних рекурентностей у криптографії: жодне збільшення довжини LFSR не здатне захистити систему від відновлення початкового стану за мізерну частку секунди.
