Автономний розвідувальний датчик, контролер дрона чи захищений термінал може перебувати в режимі повного радіомовчання з вимкненим вихідним каскадом передавача, проте станція радіотехнічного моніторингу на базі SDR (Software-Defined Radio) упевнено фіксує його присутність на відстані 50–100 метрів за вузькосмуговими сплесками на частотах 48 МГц, 144 МГц та 400 МГц. Джерелом цього випромінювання є комутація силових польових транзисторів у внутрішньому DC-DC перетворювачі з похідною струму `di/dt > 1.5 А/нс` та струми дерева тактування мікроконтролера, які збуджують друковані доріжки плати як несиметричні чвертьхвильові антени. Коли ж пристрій нарешті активує передавач і надсилає короткий зашифрований пакет тривалістю 2 мілісекунди, мікроскопічні варіації кремнієвого кристала — дисбаланс амплітуд у квадратурних гілках на 3.8%, перекіс фази на 1.6° та індивідуальний зсув опорного кварцу на +14.2 кГц — формують неповторний апаратний відбиток (RF-DNA), який дає змогу однозначно ідентифікувати саме цей екземпляр плати серед тисяч серійних пристроїв тієї ж моделі.

Радіочастотний слід пристрою (англ. *RF Footprint* або *Spectrum Signature*) складається з двох фундаментальних компонентів: **ненавмисного електромагнітного випромінювання** (Unintended Electromagnetic Emissions), що виникає внаслідок функціонування цифрових та силових кіл, і **радіочастотної сигнатури передавача** (Specific Emitter Identification / RF Fingerprinting), яка визначається фізичними неідеальностями виготовлення аналогового радіотракту. Комплексний аналіз цих сигналів дозволяє не лише виявляти та пеленгувати приховані електронні модулі, а й відстежувати їхні переміщення без розшифрування переданого трафіку.

## 1. Джерела ненавмисного радіовипромінювання на друкованій платі

Будь-який провідник зі змінним струмом, згідно з рівняннями Максвелла, створює в навколишньому просторі електромагнітне поле. На друкованій платі сучасного приладу діють сотні джерел швидкозмінних напруг `dv/dt` та струмів `di/dt`. За відсутності спеціальних заходів електромагнітного екранування ці кола перетворюються на паразитичні випромінювачі двох типів: **магнітні рамкові антени** (Differential-Mode Loop) та **електричні несиметричні диполі** (Common-Mode Dipole).

![Джерела ненавмисного електромагнітного випромінювання на друкованій платі](/root/eng/sf-security/radioslid-prystroiu/img/unintended-emissions-sources.svg)
*Чотири основні джерела ненавмисного радіовипромінювання в електронних модулях: тактові генератори, імпульсні перетворювачі живлення, швидкісні шини та комутація виводів введення-виведення*

### 1.1. Фізика ближньої та дальньої зон випромінювання (Near-Field vs Far-Field)

Простір навколо друкованої плати поділяється на три характерні електродинамічні області залежно від відстані `r` до джерела та робочої довжини хвилі `λ = c / f`:

1. **Реактивна ближня зона (Reactive Near-Field):** відстань `r < λ / (2·π)` (для частоти 100 МГц це область ближче 48 см). Тут переважає реактивна накопичена енергія. Електричне `E` та магнітне `H` поля ще не утворюють зв'язану поперечну електромагнітну хвилю TEM. Хвильовий опір простору `Z_w = |E| / |H|` визначається природою джерела: для струмових петель `Z_w ≪ 377 Ом` (переважає магнітне поле), для високоомних вузлів `Z_w ≫ 377 Ом` (переважає електричне поле). Зняття інформації в цій зоні виконується локальними H- та E-зондами безпосередньо над кристалом чіпа.
2. **Проміжна зона Френеля (Radiative Near-Field):** `λ / (2·π) ≤ r < 2·D² / λ`, де `D` — максимальний геометричний розмір плати чи підключеного кабелю. Формується діаграма спрямованості.
3. **Дальня зона Фраунгофера (Far-Field):** `r ≥ 2·D² / λ`. Електромагнітна хвиля стає плоскою поперечною, хвильовий опір дорівнює характеристичному імпедансу вільного простору `Z_0 = √(μ_0 / ε_0) ≈ 377 Ом`, а щільність потоку потужності спадає обернено пропорційно квадрату відстані `1 / r²`. Саме в дальній зоні працюють спрямовані антени станцій радіоелектронної розвідки.

### 1.2. Тактові генератори та дерево тактування PLL

Опорний кварцовий генератор формує прямокутний тактовий сигнал для процесорного ядра та периферії. Ідеальний прямокутний імпульс із періодом `T_0 = 1 / f_0` у частотній області розкладається в нескінченний ряд Фур'є з непарних гармонік:

```
v_clock(t) = (4 · V_dd / π) · ∑_{k=1,3,5...}^{∞} (1 / k) · sin(2 · π · k · f_0 · t)
```

Реальний тактовий сигнал має кінцеву тривалість фронту наростання `t_r` (зазвичай `0.3 .. 1.2 нс`). Спектральна густина потужності такого сигналу залишається практично пласкою аж до першої граничної частоти `f_1 = 1 / (π · t_pulse)`, а після другої граничної частоти `f_2 = 1 / (π · t_r)` починає спадати зі швидкістю 40 дБ на декаду:

```
Спектральний спад амплітуди тактового сигналу:
         ▲
  A(f)   │══════════════════════╗ (0 дБ/дек)
         │                      ╚══════════════╗ (-20 дБ/дек)
         │                                     ╚════════════════ (-40 дБ/дек)
         └──────────────────────┴──────────────┴────────────────► Частота f
                               f_1            f_2 = 1/(π·t_r)
```

Якщо тактова частота мікроконтролера становить 48 МГц, а тривалість фронту дорівнює `t_r = 0.8 нс`, гранична частота сягає `f_2 ≈ 400 МГц`. Це означає, що тактові доріжки довжиною всього 5–10 см на платі ефективно випромінюють десятки гармонік у діапазонах VHF та UHF (від 48 МГц до 1 ГГц), створюючи характерний «гребінець» частот, видимий на спектрограмі SDR-приймача.

### 1.3. Імпульсні перетворювачі живлення DC-DC

Сучасні високоефективні стабілізатори напруги (Buck / Boost / SEPIC) працюють на частотах комутації від 200 кГц до 3 МГц. Для мінімізації теплових втрат силові MOSFET-транзистори відкриваються та закриваються за лічені наносекунди.

У момент перемикання транзистора у вузлі комутації (SW-node) виникає різкий стрибок напруги `dv/dt > 5 В/нс` та сплеск струму `di/dt > 2 А/нс`. Паразитна індуктивність виводів котушки `L_par`, еквівалентна послідовна індуктивність керамічних конденсаторів (ESL) та міжелектродні ємності транзистора `C_oss` утворюють високодобротний контур, який породжує високочастотний паразитний «дзвін» (Switching Ringing) на частотах 50–300 МГц.

Напруженість електричного поля `E`, випромінюваного струмовою петлею площею `A` з гармонійним струмом `I` на частоті `f` на відстані `r`, визначається виразом:

```
E_loop = 1.316 · 10⁻¹⁴ · (f² · A · I) / r   [В/м]
```

Оскільки напруженість поля пропорційна квадрату частоти `f²` та площі петлі `A`, навіть мініатюрний контур площею `1 см²` на частоті дзвону 200 МГц створює потужне магнітне випромінювання, яке легко пеленгується рамочною антеною комплексу РЕР.

### 1.4. Швидкісні цифрові шини та синфазні струми (Common-Mode Currents)

Шини передачі даних (SPI, QSPI, SDIO, паралельні інтерфейси дисплеїв та зовнішньої пам'яті DDR) передають псевдовипадкові цифрові послідовності. Якщо доріжка на друкованій платі проходить над розривом у земляній площині (Ground Split), зворотний струм сигналу змушений огинати перешкоду, формуючи велику паразитну петлю.

Крім того, асиметрія імпедансів викликає виникнення синфазного струму `I_cm`, який витікає через земляні провідники на підключені кабелі (живлення, датчики, антени). Кабель довжиною `L` починає працювати як чвертьхвильовий штир:

```
E_dipole = 1.257 · 10⁻⁶ · (f · L · I_cm) / r   [В/м]
```

> ⚠️ **Критичний зв'язок:** Для створення гранично допустимого за стандартом FCC/TEMPEST випромінювання (30 мкВ/м на відстані 10 м на частоті 100 МГц) достатньо синфазного струму `I_cm` величиною всього **5–8 мікроамперів**.

Більше про історію відкриття ненавмисних випромінювань, секретну програму розвідки США та дослідження ван Ека можна дізнатися у вставці [Від Bell Labs і TEMPEST до кремнієвого RF-DNA](root:sf-security/radioslid-prystroiu/hist-tempest-and-van-eck.md).

## 2. Радіочастотна сигнатура передавача (RF Fingerprinting)

Коли пристрій виходить в ефір, його передавач формує радіосигнал. З погляду протоколу (Wi-Fi, Bluetooth, LoRa чи пропрієтарний FSK-канал) два ідентичні передавачі надсилають однакові байти даних. Проте на фізичному рівні (PHY layer) радіохвиля несе на собі відбиток кремнієвої топології конкретного чіпа.

```
       │                                                             │

       │          │                                                  │
       │          ▼                                                  │

       │          │                                                  │
       │          ▼                                                  │

       │          │              витік опорного гетеродина (DC)      │
       │          ▼                                                  │
       │  [Синтезатор PLL] ────> Зсув частоти CFO, фазовий шум L(Δf) │

       └─────────────────────────────────────────────────────────────┘
```

*Вплив апаратних неідеальностей аналогового тракту на сигнальне сузір'я квадратурної модуляції QPSK: розмиття точок, фазовий шум та зміщення центральної точки*

### 2.1. Фізика технологічного розкиду кремнію (Silicon Process Variations)

Виготовлення інтегральних мікросхем на кремнієвій пластині (Wafer) підпорядковується статистичним законам. Навіть у межах одного технологічного процесу (наприклад, TSMC 28nm або 40nm) спостерігаються мікроскопічні градієнти:
- варіація товщини підзатворного оксиду `t_ox` на кілька ангстремів змінює порогову напругу відкриття транзисторів `V_th`;
- випадковий розкид атомів легуючої домішки (Random Dopant Fluctuation) у каналі польового транзистора викликає асиметрію струмів насичення;
- нерівномірність травлення літографічних масок змінює ширину та міжелектродну ємність провідників змішувача.

Ці мікроскопічні дефекти залишаються незмінними протягом усього терміну служби чіпа і формують стабільну індивідуальну сигнатуру.

### 2.2. Квадратурний дисбаланс (IQ Imbalance)

Прямий квадратурний модулятор розкладає комплексний сигнал на синфазну `I(t)` та квадратурну `Q(t)` гілки, які перемножуються з сигналами гетеродина `cos(ω_c t)` та `-sin(ω_c t)`.

Через розкид геометричних розмірів резисторів, ємностей та транзисторів у змішувачах на кристалі виникають два спотворення:
1. **Амплітудний дисбаланс (Gain Imbalance) `α`:** підсилення гілок відрізняється на частки відсотка (`α ≠ 1.0`).
2. **Фазовий перекіс (Phase Skew) `ϕ`:** фазовий зсув між гілками гетеродина становить `90° + ϕ` замість строго `90.0°`.

Спотворений комплексний сигнал набуває вигляду:

```
r_bb(t) = K_1 · s(t) + K_2 · s*(t) + (d_I + j·d_Q)
```

де `s*(t)` — комплексно-спряжений сигнал (дзеркальний канал), а коефіцієнти `K_1` та `K_2` однозначно задаються парою `(α, ϕ)`. На сузір'ї модуляції амплітудний дисбаланс перетворює кругові кластери на еліпси, а фазовий перекіс нахиляє осі сузір'я.

### 2.3. Зсув несучої частоти (Carrier Frequency Offset — CFO)

Опорний кварцовий генератор має номінальну похибку резонансної частоти. Вона зумовлена кутом механічного зрізу монокристала кварцу та точністю лазерного підганяння маси електродів. Похибка вимірюється в частках на мільйон (PPM, `1 PPM = 10⁻⁶`):

```
Δf_cfo = f_carrier · (PPM_crystal / 10⁶)   [Гц]
```

Для передавача на частоті `f_c = 868 МГц` із кварцом точності `±20 PPM` індивідуальне зміщення несучої частоти становить від `-17.36 кГц` до `+17.36 кГц`. Оскільки сучасний цифровий SDR-приймач здатен вимірювати центральну частоту сигналу з роздільною здатністю до одиниць герц, значення `Δf_cfo` стає надійним первинним класифікатором.

### 2.4. Фазовий шум синтезатора частот (PLL Phase Noise)

Синтезатор частоти на базі дробової петлі ФАПЧ (Fractional-N PLL) містить генератор, керований напругою (VCO), підсилювач заряду (Charge Pump) та фільтр петлі. Фазові флуктуації напівпровідникових переходів зумовлюють наявність фазового шуму `θ_noise(t)`, який викликає випадкове кутове тремтіння точок сузір'я навколо центрального положення:

```
s_noisy(t) = s(t) · e^(j · θ_noise(t))
```

Форма спаду спектральної густини фазового шуму `L(Δf)` (вимірюється в дБн/Гц на різних відстроченнях від несучої: 1 кГц, 10 кГц, 100 кГц) залежить від фізичної добротності інтегрованого варикапа та параметрів пасивного RC-фільтра на кристалі.

### 2.5. Перехідний процес ввімкнення підсилювача потужності (RF Transient)

Найбільш інформативною частиною сигнатури є перші **1–10 мікросекунд** випромінювання — інтервал переходу підсилювача потужності з режиму глибокого сну (Standby / Deep Sleep) у режим насичення. У цей момент відбуваються:
- наростання струму зміщення бази/затвора силових транзисторів;
- перехідні коливання напруги живлення через паразитну індуктивність розв'язувальних конденсаторів;
- замикання петлі ФАПЧ під час різкої зміни імпедансу навантаження (VCO Pulling).

Огинаюча амплітуди `A(t)` та динаміка миттєвої фази `ψ(t)` на етапі наростання мають унікальний часовий профіль (час наростання, відносний викид, частота релаксаційних коливань), який практично неможливо підробити програмними методами.

Детальний аналітичний вивід формул квадратурного дисбалансу, алгоритму Муза та розрахунку гіперболічних ізохрон наведено у вставці [Математичні моделі IQ-дисбалансу, CFO та гіперболічної пеленгації](root:sf-security/radioslid-prystroiu/math-iq-cfo-and-tdoa.md).

## 3. Методи радіопеленгації та просторової локалізації

Виявлення сигналу в ефірі є першим кроком; наступне завдання комплексу РЕР — визначення фізичних географічних координат джерела.

```
       ┌─────────────────────────────────────────────────────────────┐
       │                МЕТОДИ ПРОСТОРОВОЇ ЛОКАЛІЗАЦІЇ               │
       │                                                             │
       │  1. Амплітудний (RSSI):                                     │
       │     • 1 приймач: напрямок за максимумом діаграми антени     │
       │     • 3+ приймачі: радіальні кола r = 10^((P0 - RSSI)/(10n))│
       │     • Точність: 20–100 м (висока чутливість до згасання)    │
       │                                                             │
       │  2. Кутомірний (AoA / Interferometry):                      │
       │     • Фазові антенні решітки (Uniform Linear/Circular Array)│
       │     • Алгоритми оцінки просторового спектра: MUSIC, ESPRIT  │
       │     • Точність: 1–5° по куту азимута                        │
       │                                                             │
       │  3. Різницево-далекомірний (TDoA):                          │
       │     • 3+ станції з синхронізацією часу GPS/PTP (Δt < 1 нс)  │
       │     • Взаємна кореляція необроблених IQ-потоків (GCC-PHAT)  │
       │     • Перетин гіперболічних ліній d_i - d_j = c · Δt_ij     │
       │     • Точність: 1–10 м (не залежить від потужності цілі)    │
       └─────────────────────────────────────────────────────────────┘
```

*Принцип TDoA-пеленгації: базові станції вимірюють різницю часу прийому фронту радіосигналу, будуючи гіперболи положення, на перетині яких знаходиться ціль*

### 3.1. Амплітудний метод (Signal Hunting та RSSI)

Найпростіший спосіб пошуку — спрямована антена з вузьким променем (антена Ягі-Уда або логоперіодична антена), підключена до вимірювача потужності. Оператор сканує простір за азимутом, фіксуючи напрямок максимального рівня прийнятого сигналу (RSSI).

Для автоматизованої багатопозиційної системи розрахунок відстані `d` до передавача ведеться за логарифмічною моделлю втрат на трасі (Log-Distance Path Loss Model):

```
RSSI(d) = P_tx + G_tx + G_rx - PL(d_0) - 10 · n · log10(d / d_0) + X_σ
```

де `n` — показник згасання середовища (від 2.0 у вільному просторі до 3.5–5.0 у міській або лісистій місцевості), а `X_σ` — гаусова випадкова величина затінення (Shadowing) із середньоквадратичним відхиленням `σ = 4 .. 10 дБ`.

> ⚠️ **Обмеження методу:** Багатопроменева інтерференція (Multipath Fading) створює глибокі локальні провали сигналу до 20–30 дБ на відстанях у чверть довжини хвилі. Через це локалізація виключно за RSSI дає похибку визначення координат від 30 до 150 метрів.

### 3.2. Кутомірна пеленгація AoA (Angle of Arrival) та фазові решітки

Кутомірний метод визначає кут приходу хвилі `θ` на антенну решітку з `K` елементів. Для лінійної решітки (Uniform Linear Array, ULA) з кроком між антенами `d = λ / 2` різниця фаз між сусідніми елементами дорівнює `Δψ = 2·π·(d / λ)·sin(θ) = π·sin(θ)`.

Для одночасного пеленгування кількох джерел у присутності завад застосовують метод оцінки просторового спектра **MUSIC** (Multiple Signal Classification). Алгоритм обчислює вибіркову просторову коваріаційну матрицю `R_xx = E[x(t) · x^H(t)]`, виконує її спектральний розклад на сигнальний та шумовий підпростори за власними векторами `E_n` і знаходить піки псевдоспектра:

```
P_music(θ) = 1 / ( a^H(θ) · E_n · E_n^H · a(θ) )
```

де `a(θ) = [1, e^(j·π·sin(θ)), ..., e^(j·(K-1)·π·sin(θ))]^T` — вектор просторового відгуку решітки (Steering Vector).

### 3.3. Різницево-далекомірний метод TDoA (Time Difference of Arrival)

Метод TDoA є найбільш високоточним і сучасним стандартом радіопеленгації. Він використовує мережу з трьох або більше географічно рознесених стаціонарних чи мобільних приймачів.

Приймачі не вимагають знання моменту початку випромінювання пакета `t_0` і точної вихідної потужності передавача. Станції записують синхронні часові зрізи комплексних відліків `r_i(t)` та передають їх на центральний сервер обробки.

1. **Обчислення взаємної кореляції:** Часова затримка `Δt_ij` між парою станцій `S_i` та `S_j` знаходиться через узагальнену взаємну кореляційну функцію з фазовою трансформацією (Generalized Cross-Correlation with Phase Transform — GCC-PHAT):

```
R_ij(τ) = ∫_{-∞}^{+∞} ( (S_i(f) · S_j*(f)) / |S_i(f) · S_j*(f)| ) · e^(j · 2·π·f·τ) df

Δt_ij = argmax_τ ( R_ij(τ) )
```

Нормалізація на амплітуду `|S_i(f) · S_j*(f)|` усуває вплив частотної характеристики каналу і залишає виключно фазову інформацію, що забезпечує гострий дельта-подібний кореляційний пік навіть в умовах сильного шуму.

2. **Геометричний розв'язок:** Для швидкості світла `c = 299 792 458 м/с` кожна пара станцій формує різницю відстаней `Δd_ij = c · Δt_ij`. Рівняння:

```
√((x - x_i)² + (y - y_i)²) - √((x - x_j)² + (y - y_j)²) = c · Δt_ij
```

задає двовимірну гіперболу. Перетин трьох гіпербол від чотирьох станцій дає однозначну точку `(x, y)` на карті.

3. **Вимоги до синхронізації:** Похибка синхронізації часу між станціями в **1 наносекунду** перетворюється на похибку визначення положення цілі приблизно в **30 сантиметрів** (`Δd = c · Δt ≈ 3·10⁸ м/с · 10⁻⁹ с = 0.3 м`). Для забезпечення такої точності базові станції комплектуються термостатованими рубідієвими стандартами частоти та приймачами сигналів супутникової навігації з міткою часу 1PPS (Pulse Per Second).

## 4. Методи маскування радіосліду (LPI / LPD)

Для захисту від виявлення та пеленгації розробники радіоліній спеціального призначення застосовують комплекс технологій **LPI** (Low Probability of Intercept — низька ймовірність перехоплення) та **LPD** (Low Probability of Detection — низька ймовірність виявлення).

![Методи зниження ймовірності виявлення та перехоплення сигналу (LPI/LPD)](/root/eng/sf-security/radioslid-prystroiu/img/lpi-lpd-techniques.svg)
*Комплекс технічних заходів маскування радіосліду: пакетний режим передачі, розширення спектра DSSS, стрибки частоти FHSS та адаптивне керування потужністю*

### 4.1. Пакетний режим (Ultra-Short Burst Transmission)

Пеленгатору TDoA для накопичення енергії та розрахунку кореляційного піку потрібен певний мінімальний часовий інтервал спостереження. Якщо стиснути передачу інформації в ультракороткий пакет тривалістю **200–800 мікросекунд** на високій швидкості передачі даних (наприклад, 2–10 Мбіт/с), автоматичні комплекси РЕР не встигають зафіксувати сплеск енергії або переналаштувати вхідні тракти сканування.

Додатково впроваджується **псевдовипадкова рандомізація інтервалу виходу в ефір (Jittering)**: якщо пристрій передає дані не строго кожні 10.0 секунд, а через випадковий інтервал `10.0 ± Δt` секунд, накопичувальні алгоритми періодичного виявлення втрачають когерентність.

### 4.2. Пряме розширення спектра (DSSS)

При прямому розширенні спектра (Direct Sequence Spread Spectrum) кожен інформаційний біт перемножується з високошвидкісною псевдовипадковою послідовністю чіпів (Pseudo-Noise Code, PN-послідовність) довжиною `L_pn`:

```
s_dsss(t) = d(t) · c_pn(t) · cos(ω_c t)
```

Ширина спектра сигналу зростає в `L_pn` разів: `B_ss = L_pn · B_info`. Відповідно до закону збереження енергії, спектральна густина потужності `PSD` падає пропорційно коефіцієнту розширення (Processing Gain `G_p = 10 · log10(L_pn)`):

```
PSD_dsss = P_total / B_ss
```

```
Спектральна картина DSSS-сигналу нижче рівня шуму:
  Потужність ▲
             │   Звичайний вузькосмуговий сигнал
             │        ┌─┐ (SNR > +20 дБ — легко пеленгується)
             │        │ │
  Рівень     │        │ │
  шуму  ─────┼────────┴─┴─────────────────────────────── (0 дБ)
             │  ═══════════════════════════════════════  DSSS сигнал
             │  (SNR < -10 дБ — прихований під шумом)
             └──────────────────────────────────────────► Частота f
```

Якщо енергія сигналу розподіляється по смузі 20 МГц, його спектральна густина опускається на 10–15 дБ **нижче рівня природного теплового шуму приймача** (`SNR < 0 dB`). Класичний спектроаналізатор бачить на екрані лише рівний тепловий шум. Відновити інформацію та обчислити кореляційний пік здатен лише легітимний приймач, якому відомий точний математичний закон генерації та початковий стан псевдовипадкової послідовності `c_pn(t)`.

### 4.3. Псевдовипадкова перебудова робочої частоти (FHSS)

У режимі FHSS (Frequency Hopping Spread Spectrum) передавач змінює несучу частоту сотні чи тисячі разів на секунду (наприклад, 1000 стрибків/с у тактичних радіостанціях) за псевдовипадковим криптографічним алгоритмом у широкій смузі частот (наприклад, 100–500 каналів).

Вузькосмуговий пеленгатор встигає зафіксувати лише окремі розрізнені сплески на випадкових частотах, але не може зібрати достатньо енергії на одній фіксованій частоті для побудови безперервного пеленга.

### 4.4. Адаптивне регулювання потужності (Closed-Loop TPC)

Випромінювання надлишкової потужності — головна помилка інженерів радіоліній. Якщо для забезпечення стійкого зв'язку за заданого рівня завад достатньо потужності 2 мВт (+3 дБм), робота на стандартних 100 мВт (+20 дБм) збільшує радіус виявлення пристрою в 5–10 разів.

Адаптивне керування потужністю (Transmit Power Control, TPC) використовує зворотний зв'язок від приймача: якщо пакет прийнято із запасом по відношенню сигнал/шум (`SNR > Margin`), передавач автоматично знижує вихідну потужність до мінімально можливого порогу.

### 4.5. Апаратне придушення паразитних витоків на платі

Для боротьби з ненавмисними випромінюваннями застосовують схемотехнічні та конструктивні заходи:
1. **Екрануючі металеві кришки (RF Can Shields):** безпосередньо над процесором, мікросхемами пам'яті, генераторами та котушками DC-DC монтуються заземлені металеві екрани. Ефективність екранування (Shielding Effectiveness) складається з втрат на відбиття `R`, втрат на поглинання `A` та поправки на багаторазові відбиття `B`: `SE = R + A + B` [дБ], що забезпечує ослаблення випромінювання на 40–60 дБ.
2. **Контроль швидкості наростання фронтів (Slew Rate Control):** для ліній GPIO у мікроконтролері програмно вмикається режим `Slow Slew Rate` (наприклад, швидкість перемикання 2–5 нс замість 0.5 нс), що зрізає гармоніки вище 50 МГц на 20–30 дБ без порушення функціонування логіки.
3. **Феритові фільтри (Ferrite Beads) та синфазні дроселі (Common-Mode Chokes):** встановлюються на всіх виходах кабелів живлення та зовнішніх інтерфейсів для блокування синфазних струмів `I_cm`.
4. **Суцільні земляні площини з перехідними отворами (Ground Stitching Vias):** розміщення металізованих отворів уздовж країв друкованої плати з кроком `d < λ_min / 10` утворює еквівалентну клітку Фарадея всередині шарів текстоліту.

Повний опис програмних структур конфігурації та числових значень параметрів наведено у вставці [Довідник структур даних та метрик радіочастотної сигнатури](root:sf-security/radioslid-prystroiu/api-rf-metrics.md).

Нижче наведено програмний модуль на мовах C та ідіоматичній C++ для вилучення ключових скалярних параметрів сигнатури та формування дескриптора передавача.

:::tabs
```c
#include <stdio.h>
#include <stdlib.h>
#include <math.h>
#include <stdbool.h>

typedef struct {
    float i;
    float q;
} iq_sample_t;

typedef struct {
    double cfo_hz;
    double gain_imbalance;
    double phase_skew_deg;
    double dc_offset_i;
    double dc_offset_q;
    double snr_db;
} rf_emitter_metrics_t;

/* Обчислення вектора радіочастотних ознак передавача */
bool compute_rf_metrics(const iq_sample_t *samples, size_t count, 
                        double sample_rate, rf_emitter_metrics_t *out) {
    if (!samples || count < 64 || !out) return false;

    /* 1. Постійне зміщення (DC Offset) */
    double sum_i = 0.0, sum_q = 0.0;
    for (size_t k = 0; k < count; ++k) {
        sum_i += samples[k].i;
        sum_q += samples[k].q;
    }
    out->dc_offset_i = sum_i / (double)count;
    out->dc_offset_q = sum_q / (double)count;

    /* 2. Квадратурний дисбаланс (IQ Imbalance) */
    double p_i = 0.0, p_q = 0.0, cross_iq = 0.0;
    for (size_t k = 0; k < count; ++k) {
        double ci = samples[k].i - out->dc_offset_i;
        double cq = samples[k].q - out->dc_offset_q;
        p_i += ci * ci;
        p_q += cq * cq;
        cross_iq += ci * cq;
    }
    p_i /= (double)count;
    p_q /= (double)count;
    cross_iq /= (double)count;

    out->gain_imbalance = (p_q > 1e-12) ? sqrt(p_i / p_q) : 1.0;
    double denom = sqrt(p_i * p_q);
    if (denom > 1e-12) {
        double s = cross_iq / denom;
        if (s > 1.0) s = 1.0;
        if (s < -1.0) s = -1.0;
        out->phase_skew_deg = asin(s) * (180.0 / M_PI);
    } else {
        out->phase_skew_deg = 0.0;
    }

    /* 3. Зсув частоти несучої (CFO) через диференційну автокореляцію */
    double re_acc = 0.0, im_acc = 0.0;
    for (size_t k = 0; k < count - 1; ++k) {
        double r1_re = samples[k + 1].i, r1_im = samples[k + 1].q;
        double r0_re = samples[k].i,     r0_im = -samples[k].q; /* conj */
        re_acc += (r1_re * r0_re - r1_im * r0_im);
        im_acc += (r1_re * r0_im + r1_im * r0_re);
    }
    double phase_step = atan2(im_acc, re_acc);
    out->cfo_hz = (phase_step * sample_rate) / (2.0 * M_PI);

    /* 4. Оцінка відношення сигнал/шум */
    out->snr_db = 10.0 * log10((p_i + p_q) + 1e-12);

    return true;
}
```

```cpp
#include <vector>
#include <complex>
#include <cmath>
#include <numbers>
#include <span>
#include <expected>
#include <numeric>

namespace rf_security {

struct EmitterMetrics {
    double cfo_hz{0.0};
    double gain_imbalance{1.0};
    double phase_skew_deg{0.0};
    std::complex<double> dc_offset{0.0, 0.0};
    double snr_db{0.0};
};

enum class AnalysisStatus {
    InvalidData,
    BufferTooShort
};

class SignatureAnalyzer {
public:
    [[nodiscard]] static std::expected<EmitterMetrics, AnalysisStatus>
    analyze(std::span<const std::complex<float>> samples, double sample_rate_hz) noexcept {
        if (samples.size() < 64) {
            return std::unexpected(AnalysisStatus::BufferTooShort);
        }

        const auto count = static_cast<double>(samples.size());

        // 1. Обчислення постійного зміщення
        const auto sum = std::accumulate(samples.begin(), samples.end(), std::complex<double>{0.0, 0.0});
        const auto dc = sum / count;

        // 2. Оцінка квадратурного дисбалансу
        double p_i = 0.0;
        double p_q = 0.0;
        double cross_iq = 0.0;

        for (const auto& s : samples) {
            const double ci = static_cast<double>(s.real()) - dc.real();
            const double cq = static_cast<double>(s.imag()) - dc.imag();
            p_i += ci * ci;
            p_q += cq * cq;
            cross_iq += ci * cq;
        }

        p_i /= count;
        p_q /= count;
        cross_iq /= count;

        const double gain_imb = (p_q > 1e-12) ? std::sqrt(p_i / p_q) : 1.0;
        const double denom = std::sqrt(p_i * p_q);
        double phase_skew_deg = 0.0;

        if (denom > 1e-12) {
            const double sin_phi = std::clamp(cross_iq / denom, -1.0, 1.0);
            phase_skew_deg = std::asin(sin_phi) * (180.0 / std::numbers::pi);
        }

        // 3. Зсув несучої частоти (CFO)
        std::complex<double> corr{0.0, 0.0};
        for (std::size_t k = 0; k < samples.size() - 1; ++k) {
            const std::complex<double> s1{samples[k + 1].real(), samples[k + 1].imag()};
            const std::complex<double> s0{samples[k].real(), samples[k].imag()};
            corr += s1 * std::conj(s0);
        }

        const double phase_diff = std::arg(corr);
        const double cfo = (phase_diff * sample_rate_hz) / (2.0 * std::numbers::pi);
        const double snr = 10.0 * std::log10((p_i + p_q) + 1e-12);

        return EmitterMetrics{
            .cfo_hz = cfo,
            .gain_imbalance = gain_imb,
            .phase_skew_deg = phase_skew_deg,
            .dc_offset = dc,
            .snr_db = snr
        };
    }
};

} // namespace rf_security
```

## 6. Інженерний контрольний список радіобезпеки пристрою

Під час розробки апаратно-програмних комплексів із підвищеними вимогами до скритності рекомендується виконувати такий покроковий аудит:

> 🔧 **Інженерний чеклист захисту від радіовиявлення:**
> 1. **Аудит тактового дерева:** Перевірити довжину ліній тактування кварців та PLL. Розміщувати резонатори впритул до виводів мікроконтролера, огороджувати земляними полігонами з перехідними отворами (Ground Guard Ring).
> 2. **Обмеження швидкості GPIO:** Програмно встановити мінімально достатній `Slew Rate` для всіх виводів введення-виведення та інтерфейсів SPI/I2C/UART.
> 3. **Мінімізація петлі комутації DC-DC:** Вхідні керамічні блокувальні конденсатори `C_in` та зворотний діод/нижній транзистор повинні утворювати фізичну петлю площею менше `15 мм²`.
> 4. **Фільтрація вихідних ліній:** Усі кабельні з'єднання, що виходять за межі корпусу пристрою, повинні мати синфазні дроселі та прохідні RC/LC фільтри.
> 5. **Режим випромінювання:** Відмовитися від передачі періодичних беззмістовних маяків (Heartbeat/Keep-Alive). Передавати дані виключно короткими пакетами (Burst) із псевдовипадковим часовим джитером.
> 6. **Калібрування потужності:** Завжди реалізовувати адаптивний контроль вихідної потужності (TPC), обмежуючи рівень сигналу мінімумом, необхідним для надійного прийому легітимною базою.
