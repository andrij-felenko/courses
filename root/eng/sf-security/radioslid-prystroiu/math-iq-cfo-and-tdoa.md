# 🧮 Математичні моделі IQ-дисбалансу, CFO та гіперболічної пеленгації

Ідентифікація передавача за його радіочастотною сигнатурою та високоточна просторова локалізація базуються на строгому математичному апараті моделювання неідеальностей аналогового радіотракту та геометрії поширення електромагнітних хвиль. Нижче наведено формалізовані аналітичні моделі квадратурного дисбалансу, зміщення несучої частоти, фазового шуму генераторів та розв'язання нелінійних систем гіперболічних рівнянь різницево-далекомірної пеленгації (TDoA) разом із теоретичними межами точності Крамера-Рао (CRLB).

---

## 1. Аналітична модель квадратурного IQ-дисбалансу

У прямому квадратурному модуляторі комплексний модулюючий сигнал низької частоти `s(t) = I(t) + j·Q(t)` переноситься на опорну радіочастоту `ω_c = 2·π·f_c` за допомогою двох ортогональних гілок гетеродина:

```
s_tx(t) = I(t)·cos(ω_c·t) - Q(t)·sin(ω_c·t)
```

Через технологічні похибки літографії та розкид номіналів компонентів реальний модулятор має три фундаментальні типи викривлень:
1. **Амплітудний дисбаланс (Gain Imbalance) `α`:** коефіцієнти підсилення синфазної `I` та квадратурної `Q` гілок різняться на величину `α = (1 + ε) / (1 - ε)`, де `ε` — відносна асиметрія амплітуд.
2. **Фазовий перекіс (Phase Skew) `ϕ`:** кут між опорними коливаннями відхиляється від ідеальних `90°` на помилку `ϕ` радіан.
3. **Витік опорного коливання гетеродина (LO Leakage / DC Offset):** постійні зміщення `d_I` та `d_Q`, які створюють незмодульований пік на центральній частоті несучої.

Реальний сигнал на виході модулятора записується у вигляді:

```
s_real(t) = (I(t) + d_I)·(1 + ε)·cos(ω_c·t + ϕ/2) - (Q(t) + d_Q)·(1 - ε)·sin(ω_c·t - ϕ/2)
```

Розкладемо тригонометричні функції за формулами додавання кутів та згрупуємо члени для представлення сигналу в еквівалентній комплексній низькочастотній формі:

```
r_bb(t) = K_1·s(t) + K_2·s*(t) + (d_I + j·d_Q)

де коефіцієнти спотворення K_1 та K_2 дорівнюють:
K_1 = 0.5·((1 + ε)·e^(j·ϕ/2) + (1 - ε)·e^(-j·ϕ/2)) = cos(ϕ/2) + j·ε·sin(ϕ/2)
K_2 = 0.5·((1 + ε)·e^(j·ϕ/2) - (1 - ε)·e^(-j·ϕ/2)) = ε·cos(ϕ/2) + j·sin(ϕ/2)
```

Тут `s*(t)` — комплексно спряжений сигнал. Наявність другого доданка `K_2·s*(t)` означає виникнення дзеркального частотного каналу (Image Frequency), що дзеркально відбивається відносно несучої частоти.

### Коефіцієнт придушення дзеркального каналу (IRR)

Показник придушення дзеркальної складової (Image Rejection Ratio, `IRR`) кількісно описує якість модулятора і слугує першим скалярним дескриптором RF-сигнатури:

```
IRR = 10 · log10( |K_1|² / |K_2|² )

IRR_approx ≈ 10 · log10( 4 / (4·ε² + ϕ²) ) [дБ]
```

Для типових недорогих кремнієвих трансиверів величина `IRR` лежить у діапазоні від 25 до 42 дБ. Розподіл значень `(ε, ϕ)` для партії мікросхем формує стабільний у часі кластер кремнієвої сигнатури, стійкий до змін корисного навантаження.

## 2. Зсув несучої частоти (Carrier Frequency Offset — CFO)

Опорні кварцові резонатори передавача та приймача мають фізичні похибки нарізки кристала (кути AT/BT-зрізу) та температурний коефіцієнт частоти (TKЧ), що створює різницю номінальних частот `Δf = f_tx - f_rx`.

Дискретна модель прийнятого комплексного сигналу на інтервалі спостереження:

```
r[n] = s[n] · e^(j · (2·π·Δf·n·T_s + θ_0)) + w[n]
```

де `T_s = 1 / F_s` — період дискретизації, `θ_0` — початкова випадкова фаза, `w[n]` — комплексний адитивний білий гаусів шум `AWGN ~ CN(0, σ²_w)`.

### Алгоритм Муза (Moose Algorithm) для оцінки CFO

Якщо передавач випромінює два ідентичні навчальні блоки `s_1[n]` та `s_2[n] = s_1[n]` довжиною `N` відліків, розділені інтервалом `D = N` тактів (наприклад, у преамбулі кадрів OFDM або DSSS), фазовий зсув між відповідними відліками становить:

```
Δθ = 2 · π · Δf · N · T_s
```

Оцінка максимальної правдоподібності (ML) для частотного зсуву знаходиться через взаємну автокореляцію двох сусідніх блоків:

```
R_12 = ∑_{n=0}^{N-1} r[n + N] · r*[n]

R_12 = ∑_{n=0}^{N-1} |s[n]|² · e^(j · 2·π·Δf·N·T_s) + шум

Δf_est = (1 / (2 · π · N · T_s)) · arg(R_12)
       = (F_s / (2 · π · N)) · arctan2( Im(R_12), Re(R_12) )
```

Діапазон однозначної оцінки частоти обмежений умовою відсутності переповнення фази `|Δθ| < π`:

```
|Δf_max| ≤ F_s / (2 · N)
```

Нижня межа Крамера-Рао (CRLB) для дисперсії оцінки зсуву частоти за `N` відліками при заданому відношенні сигнал/шум `SNR = P_s / σ²_w` визначається як:

```
var(Δf_est) ≥ (6 · F_s²) / ( (2·π)² · SNR · N · (N² - 1) )   [Гц²]
```

При вибірці `N = 1024` відліки на частоті дискретизації `F_s = 10 МГц` та `SNR = 10 дБ` теоретична точність вимірювання частотного зсуву становить менше 5 Гц, що забезпечує надійне розрізнення передавачів із різницею частот кварцу всього в 0.05 PPM.

## 3. Фазовий шум синтезатора частот (PLL Phase Noise)

Опорний генератор петлі фазового автопідлаштування частоти (PLL) має випадкові фазові флуктуації `φ(t)`. Спектральна густина потужності фазового шуму `L(Δf)` описується емпіричною моделлю Лісона (Leeson's equation):

```
L(Δf) = 10 · log10( (2·F·k·T / P_sig) · (1 + (f_0 / (2·Q_L·Δf))²) · (1 + f_c_flicker / |Δf|) )
```

де:
- `F` — коефіцієнт шуму активного транзистора генератора;
- `k` — стала Больцмана (`1.38·10⁻²³ Дж/К`);
- `T` — абсолютна температура в Кельвінах;
- `P_sig` — потужність коливань на виході резонатора;
- `f_0` — номінальна частота коливань;
- `Q_L` — навантажена добротність коливального контуру;
- `Δf` — частотне відстрочення від несучої;
- `f_c_flicker` — кутова частота переходу флікер-шуму `1/f`.

Форма схилу `L(Δf)` у діапазоні відстрочень 1 кГц – 100 кГц визначається параметрами інтегрованого фільтра петлі (Loop Filter) та добротністю варикапа на кристалі. Вона утворює стійку сигнатуру сімейства та конкретної ревізії чіпа.

## 4. Математичний апарат TDoA-пеленгації (Time Difference of Arrival)

Нехай у двовимірній площині `(x, y)` розташовано `M ≥ 3` синхронізованих базових станцій із відомими координатами `S_i = (x_i, y_i)`, де `i = 1, 2, ..., M`.

Невідомі координати передавача цілі позначимо як `P = (x, y)`. Відстань від передавача до `i`-ї базової станції дорівнює:

```
d_i = || P - S_i || = √((x - x_i)² + (y - y_i)²)
```

Час приходу сигналу на станцію `S_i` становить `t_i = t_0 + d_i / c`, де `t_0` — невідомий момент випромінювання пакета, `c` — швидкість світла у вакуумі (`299 792 458 м/с`).

Оскільки момент `t_0` невідомий, вимірюється різниця часів приходу між `i`-ю та базовою (першою) станціями `Δt_i1 = t_i - t_1`. Різниця відстаней:

```
d_i1 = d_i - d_1 = c · Δt_i1

√((x - x_i)² + (y - y_i)²) - √((x - x_1)² + (y - y_1)²) = c · Δt_i1
```

Це рівняння описує гілку гіперболи з фокусами в точках `S_i` та `S_1`. Перетин кількох гіпербол визначає точку знаходження передавача.

### 4.1. Алгоритм Чана (Chan's Closed-Form Method)

Для швидкого аналітичного розв'язання без початкового наближення застосовується метод Чана. Піднесемо рівняння відстані до квадрата:

```
d_i² = (x - x_i)² + (y - y_i)²
d_i² = x² + y² - 2·x·x_i - 2·y·y_i + x_i² + y_i²

Позначимо K_i = x_i² + y_i² та R = d_1 = √(x² + y²) (за умови розміщення S_1 на початку координат x_1=0, y_1=0):
d_i² = (d_i1 + R)² = d_i1² + 2·d_i1·R + R²
d_i² = R² - 2·x·x_i - 2·y·y_i + K_i

Прирівнюючи обидва вирази для d_i²:
d_i1² + 2·d_i1·R + R² = R² - 2·x·x_i - 2·y·y_i + K_i
2·x_i·x + 2·y_i·y + 2·d_i1·R = K_i - d_i1²
```

Для `M - 1` різницевих вимірювань отримуємо лінійну матричну систему відносно вектора невідомих `θ = [x, y, R]^T`:

```
G · θ = h

де:
G = [ 2·x_2,   2·y_2,   2·d_21 ]
    [ 2·x_3,   2·y_3,   2·d_31 ]
    [ ...  ,   ...  ,   ...    ]
    [ 2·x_M,   2·y_M,   2·d_M1 ]

h = [ K_2 - d_21² ]
    [ K_3 - d_31² ]
    [ ...         ]
    [ K_M - d_M1² ]
```

Розв'язок за зваженим методом найменших квадратів (WLS):

```
θ_est = (G^T · W^(-1) · G)^(-1) · G^T · W^(-1) · h
```

де `W` — коваріаційна матриця похибок вимірювання різниць відстаней:

```
W = c² · B · Q_t · B

B = diag(d_2, d_3, ..., d_M)
Q_t — коваріаційна матриця похибок вимірювання затримок часу cross-correlation (GCC-PHAT).
```

### 4.2. Геометричний фактор зниження точності (GDOP)

Точність пеленгації критично залежить від взаємного розташування базових станцій і цілі. Матриця Якобі `H` системи лінеаризованих рівнянь має вигляд:

```
H_i = [ (x - x_i)/d_i - (x - x_1)/d_1,   (y - y_i)/d_i - (y - y_1)/d_1 ]
```

Інформаційна матриця Фішера (Fisher Information Matrix — FIM) для системи позиціонування:

```
J_FIM = H^T · (c² · Q_t)^(-1) · H
```

Матриця коваріації координат цілі:

```
cov(P) = J_FIM^(-1) = (H^T · (c² · Q_t)^(-1) · H)^(-1)

GDOP = √( trace( (H^T · H)^(-1) ) )
```

Якщо всі базові станції розташовані на одній лінії (колінеарні), визначник `det(H^T · H) -> 0`, значення `GDOP -> ∞`, і визначення координат цілі перпендикулярно до лінії бази стає фізично неможливим незалежно від точності вимірювання часу.
