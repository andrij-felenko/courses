# 📋 Довідник структур даних та метрик радіочастотної сигнатури

Цей довідник визначає публічний програмний інтерфейс (API), контракт структур даних, скалярні числові дескриптори та математичні правила валідації радіочастотних сигнатур (RF Fingerprinting / Specific Emitter Identification). Описані типи застосовуються в системах радіотехнічного моніторингу, когерентних пеленгаційних мережах TDoA та програмно-апаратних модулях оцінки власної радіопомітності (LPI/LPD Assessment).

---

## 1. Базові типи відліків та дескриптор сигнатури передавача

Сигнатура аналогового радіотракту формується набором взаємопов'язаних параметрів, кожен з яких відображає конкретний фізичний ефект у напівпровідниковій структурі мікросхеми. Для забезпечення сумісності між різними апаратними платформами SDR (USRP, HackRF, BladeRF, ADALM-PLUTO) комплексні відліки квадратур `I` (In-phase) та `Q` (Quadrature) нормалізуються до діапазону значень з рухомою комою, де амплітуда одиничного гармонійного сигналу дорівнює `1.0`.

Дескриптор сигнатури передавача містить три функціональні групи параметрів:
1. **Модуляційні неідеальності аналогового тракту:** амплітудний дисбаланс квадратурних гілок `α`, фазовий перекіс змішувача `ϕ`, постійне зміщення через витік гетеродина (DC Offset / LO Leakage), відносний зсув несучої частоти (CFO) та коефіцієнт придушення дзеркального каналу (IRR).
2. **Параметри динамічного перехідного процесу (Turn-On Transient):** тривалість наростання імпульсу вихідного підсилювача потужності (PA) від 10% до 90% потужності, коефіцієнт перерегулювання огинаючої та час встановлення стабільної фази синтезатора PLL.
3. **Статистичні метрики якості сигналу:** середньоквадратичне значення модуля вектора помилки (EVM RMS), розраховане за сузір'ям модуляції, та інтегральне відношення сигнал/шум (SNR) у смузі вимірювання.

:::tabs
```c
#include <stdint.h>
#include <stdbool.h>

/**
 * @brief Комплексний квадратурний відлік I/Q у форматі чисел із рухомою комою.
 */
typedef struct {
    float i;  /**< Синфазна складова (In-phase), нормована в діапазон [-1.0, 1.0] */
    float q;  /**< Квадратурна складова (Quadrature), нормована в діапазон [-1.0, 1.0] */
} rf_iq_sample_f32_t;

/**
 * @brief Вектор апаратних ознак кремнієвої сигнатури передавача (RF-DNA).
 */
typedef struct {
    /* 1. Модуляційні неідеальності аналогового тракту */
    double cfo_hz;              /**< Зсув несучої частоти від номіналу (Carrier Frequency Offset), Гц */
    double cfo_ppm;             /**< Нормоване відхилення частоти в частках на мільйон (PPM) */
    double iq_gain_imbalance;   /**< Амплітудний дисбаланс alpha = RMS(I) / RMS(Q), [0.8 .. 1.2] */
    double iq_phase_skew_deg;   /**< Фазова неортогональність змішувача, градуси [-10.0 .. +10.0] */
    double dc_offset_i;         /**< Постійне зміщення синфазного каналу (LO leakage) [-0.2 .. +0.2] */
    double dc_offset_q;         /**< Постійне зміщення квадратурного каналу [-0.2 .. +0.2] */
    double image_rejection_db;  /**< Рівень придушення дзеркального каналу (IRR), дБ */

    /* 2. Часові характеристики перехідного процесу ввімкнення підсилювача (Turn-On Transient) */
    double transient_rise_ns;   /**< Тривалість наростання імпульсу від 10% до 90% потужності, нс */
    double transient_overshoot; /**< Відносний коефіцієнт перерегулювання амплітуди (Overshoot) */
    double transient_settle_ns; /**< Час заспокоєння фази генератора PLL до стабільного стану, нс */

    /* 3. Статистичні показники якості сигналу */
    double evm_rms_percent;     /**< Модуль вектора помилки (Error Vector Magnitude), % */
    double snr_db;              /**< Оцінене відношення сигнал/шум у смузі вимірювання, дБ */
    uint32_t sample_count;      /**< Кількість відліків, використаних для усереднення */
} rf_emitter_fingerprint_t;
```

### Математичні правила валідації полів дескриптора

Перед збереженням дескриптора або передачею його в класифікатор перевіряються такі граничні умови:
- **Діапазон коефіцієнта придушення дзеркального каналу:** `IRR = 10 · log10( (1 + α² + 2α·cos(ϕ)) / (1 + α² - 2α·cos(ϕ)) )`. Якщо розраховане значення `IRR < 15 дБ`, вибірка вважається зашумленою або пошкодженою колізією в ефірі.
- **Діапазон відхилення частоти:** для стандартних промислових модулів значення `cfo_ppm` має лежати в межах `[-50.0 .. +50.0] PPM`. Перевищення цього порогу вказує на наявність доплерівського зсуву від швидкісної цілі або несправність опорного резонатора.
- **Стабільність амплітудного дисбалансу:** фізично реалізований квадратурний модулятор не може мати дисбаланс `α < 0.5` або `α > 2.0` без повної втрати працездатності демодулятора.

## 2. Структури різницево-далекомірної пеленгації (TDoA)

Обчислення просторового положення випромінювача вимагає узгодженого формату опису просторового розташування сенсорних вузлів, високоточних міток часу прибуття (Time of Arrival) та розрахунку метрик невизначеності.

Кожен сенсорний вузол пеленгаційної мережі прив'язується до спільної шкали часу за допомогою апаратного захвату міток 1PPS від GNSS-приймача. Систематичні апаратні затримки у фідерних лініях та трактах оцифрування SDR калібруються індивідуально для кожної станції та віднімаються від виміряного часу `timestamp_raw_ns`.

:::tabs
```c
/**
 * @brief Просторові координати географічної точки у системі WGS-84 або локальній площині.

    double x_meters;  /**< Координата X (Схід / Easting), метри */
    double y_meters;  /**< Координата Y (Північ / Northing), метри */
    double z_meters;  /**< Висота над рівнем моря (Altitude), метри */

    uint64_t timestamp_raw_ns; /**< Відмітка часу прийому фронту імпульсу (GPS/PTP), наносекунди */
    double snr_db;             /**< Рівень сигналу на приймачі, дБ */
```

### Інтерпретація геометричного фактора GDOP

Показник `gdop` кількісно відображає масштабування похибки вимірювання часу в просторову похибку координат. Зв'язок між радіусом круга ймовірного положення (Circular Error Probable, `CEP_95`) та похибкою синхронізації часу `σ_t` виражається формулою:

```
CEP_95 ≈ 2.45 · c · σ_t · GDOP
```

- `GDOP < 2.0` — ідеальна геометрія розташування сенсорів (ціль знаходиться всередині багатокутника станцій);
- `2.0 ≤ GDOP ≤ 5.0` — добра геометрія, похибка координат не перевищує 5–15 метрів за точності синхронізації 10 нс;
- `GDOP > 10.0` — погана геометрія (станції розташовані близько до однієї прямої лінії), координати розраховуються з високою дисперсією;
- `GDOP > 50.0` — вироджена конфігурація, розв'язок не придатний для практичного застосування.

## 3. Параметри конфігурації маскування радіосліду (LPI/LPD)

Керування радіопомітністю пристрою здійснюється через спеціалізований дескриптор налаштувань. Він визначає режим розширення спектра, швидкість переналаштування синтезатора частот, діапазон адаптивного регулювання вихідної потужності (TPC) та статистичні параметри псевдовипадкового джитеру передачі.

:::tabs
```c
/**
 * @brief Режими формування радіовипромінювання низької помітності.
 */
typedef enum {
    RF_LPI_MODE_BURST = 0,   /**< Ультракороткі пакетні спалахи зі стисненням у часі */
    RF_LPI_MODE_DSSS  = 1,   /**< Пряме розширення спектра послідовністю прямого множення */
    RF_LPI_MODE_FHSS  = 2,   /**< Псевдовипадкові стрибки частоти */
    RF_LPI_MODE_HYBRID = 3   /**< Гібридний режим DSSS + FHSS */
} rf_lpi_mode_t;

/**
 * @brief Конфігурація передавача в режимі скритності (LPI/LPD).
 */
typedef struct {
    rf_lpi_mode_t mode;        /**< Обраний режим маскування */
    double tx_power_dbm;       /**< Поточна вихідна потужність передавача, дБм [-30.0 .. +20.0] */
    uint32_t burst_duration_us;/**< Тривалість випромінювання одного пакета, мікросекунди [50 .. 2000] */
    uint32_t min_interval_ms;  /**< Мінімальний інтервал між пакетами (радіомовчання), мс */
    uint32_t max_interval_ms;  /**< Максимальний інтервал (рандомізація інтервалу / jitter) */
    
    /* Параметри DSSS */
    uint16_t dsss_spreading_factor; /**< Коефіцієнт розширення спектра (чіпів на інформаційний біт) */
    uint64_t dsss_pn_poly;          /**< Генераторний поліном псевдовипадкової послідовності */

    /* Параметри FHSS */
    uint32_t fhss_hop_rate_hz;      /**< Швидкість стрибків по частоті (hops/sec) */
    uint16_t fhss_channel_count;    /**< Кількість робочих частотних каналів у сітці */
} rf_stealth_config_t;
```

## 4. Детектор енергії та поріг радіопомітності (Energy Detector Metrics)

Для кількісної оцінки ймовірності виявлення сигналу стороннім радіометром (Energy Detector) використовується статистична модель перевірки гіпотез Неймана-Пірсона. Радіометр обчислює сумарну енергію `Y = ∑ |r[n]|²` у смузі `W` за час спостереження `T`.

Критерій виявлення задається порогом `γ_th`, який визначається за заданою допустимою ймовірністю хибної тривоги `P_fa` (Probability of False Alarm):

```
γ_th = σ_w² · ( N + √(2 · N) · Q⁻¹(P_fa) )
```

де `N = 2 · W · T` — число ступенів вільності хі-квадрат розподілу, `σ_w²` — потужність шуму приймача, `Q⁻¹(·)` — обернена функція стандартного гаусового хвоста (Q-function).

Ймовірність виявлення сигналу `P_d` за наявності відношення сигнал/шум `SNR`:

```
P_d = Q( ( (γ_th / σ_w²) - N · (1 + SNR) ) / √(2 · N · (1 + 2 · SNR)) )
```

:::tabs
```c
/**
 * @brief Оцінка ймовірності виявлення радіометром.
 */
typedef struct {
    double bandwidth_hz;     /**< Смуга аналізу радіометра, Гц */
    double integration_time_s; /**< Час інтегрування енергії, с */
    double target_snr_db;    /**< Рівень сигналу цілі відносно шуму, дБ */
    double prob_false_alarm; /**< Задана ймовірність хибної тривоги (наприклад, 1e-4) */
    double prob_detection;   /**< Розрахована ймовірність виявлення [0.0 .. 1.0] */
    double detection_margin_db; /**< Запас скритності (від'ємне значення = сигнал приховано) */
} rf_detection_margin_t;
```

## 5. Фізичні діапазони та допуски апаратних параметрів кремнію

Кожен клас напівпровідникових виробів має власні статистичні межі розкиду геометричних та електричних характеристик. Знання цих меж дозволяє системі радіорозвідки відокремлювати нормальні виробничі допуски від навмисних спроб маскування або викривлення сигналу:

1. **Похибка частоти (CFO):** визначається класом термостабілізації кварцового резонатора. Некомпенсовані кристали (XO) комерційного класу мають похибку до `±40 PPM`, термокомпенсовані генератори (TCXO) промислового класу забезпечують стабільність `±0.5 .. ±2.0 PPM`, а термостатовані генератори (OCXO) військового призначення досягають точності `±0.01 .. ±0.1 PPM`.
2. **Дисбаланс квадратурних гілок IQ:** у дешевих мікросхемах прямого перетворення (Direct Conversion Transceivers) амплітудна асиметрія `α` становить 3–8%, а фазовий перекіс `ϕ` досягає 2–6 градусів. У висококласних трансиверах із цифровим формуванням діаграми та калібрувальними таблицями DSP дисбаланс знижується до величин менше 0.5% та 0.2° відповідно.
3. **Витік опорного гетеродина (LO Leakage / DC Offset):** характеризує наявність паразитного зміщення постійного струму на виході змішувача. Для побутової електроніки типовим є рівень від `-25` до `-35 dBc` (відносно потужності несучої), тоді як у захищених системах спеціального зв'язку цей рівень придушується нижче `-55 dBc`.

| Параметр сигнатури | Комерційні чіпи (Commercial IoT) | Промислові модулі (Industrial) | Військові трансивери (SDR / Defense) |
|---|---|---|---|
| **CFO (похибка кварцу)** | `±20 .. ±40 PPM` | `±5 .. ±15 PPM` | `±0.1 .. ±1.0 PPM` (TCXO / OCXO) |
| **IQ Gain Imbalance `α`** | `0.92 .. 1.08` (`±8%`) | `0.96 .. 1.04` (`±4%`) | `0.995 .. 1.005` (калібрований DSP) |
| **IQ Phase Skew `ϕ`** | `±2.0° .. ±6.0°` | `±0.8° .. ±2.0°` | `< ±0.2°` (апаратна компенсація) |
| **DC Offset (LO leakage)** | `-25 .. -35 dBc` | `-35 .. -45 dBc` | `< -55 dBc` |
| **Phase Noise @ 10 kHz** | `-85 .. -95 dBc/Hz` | `-95 .. -108 dBc/Hz` | `-115 .. -130 dBc/Hz` |
| **Час наростання фронту** | `100 .. 500 нс` (неконтрольований) | `50 .. 200 нс` | Програмоване плавне вікно Гаусса |

Контроль та вимірювання зазначених параметрів у лабораторії здійснюється за допомогою вимірювальних приймачів, векторних аналізаторів сигналів (VSA) та когерентних багатоканальних платформ SDR.
