# 🧮 Математичне доведення коректності та аналіз атак на RSA

Стійкість та абсолютна математична строгість криптосистеми RSA ґрунтуються на алгебраїчних структурах скінченних кілець залишків та властивостях теорії чисел. У цій вставці наведено строге виведення коректності алгоритму для будь-яких відкритих текстів (включаючи випадки, коли повідомлення не є взаємно простим із модулем `N`), а також детальний математичний розбір п'яти класичних атак, які виникають при неправильному виборі параметрів ключа або збоях реалізації.

---

## Доведення коректності RSA для довільного повідомлення

Нехай `p` та `q` — два різні прості числа, `N = p · q` — модуль шифрування, а `ϕ(N) = (p − 1)·(q − 1)` — значення функції Ейлера.

Відкритий показник `e` та приватний показник `d` пов'язані співвідношенням мультиплікативної оберненості за модулем `ϕ(N)`:

```
e · d ≡ 1 (mod ϕ(N))
```

Це означає, що існує таке ціле неотримане число `k`, що:

```
e · d = 1 + k · ϕ(N) = 1 + k · (p − 1) · (q − 1)
```

Операція зашифрування перетворює повідомлення `m ∈ ℤ_N` у шифротекст `c ≡ mᵉ mod N`. Операція розшифрування обчислює `cᵈ mod N`. Наша мета — довести, що для **будь-якого** `m ∈ {0, 1, ..., N − 1}` виконується тотожність:

```
(mᵉ)ᵈ ≡ m^(e·d) ≡ m (mod N)
```

Шкільні підручники часто наводять коротке доведення за допомогою теореми Ейлера, припускаючи, що `НСД(m, N) = 1`. Проте якщо `m` ділиться на `p` або `q` (тобто `НСД(m, N) > 1`), теорема Ейлера непридатна. Нижче наведено універсальне доведення через Китайську теорему про лишки (CRT), яке покриває абсолютно всі випадки.

### Крок 1: Аналіз за модулем p

Розглянемо вираз `m^(e·d) mod p`. Існують дві можливі ситуації для числового значення `m`:

**Випадок 1A: `m` не ділиться на `p` (`m not≡ 0 mod p`).**
Оскільки `p` — просте число, `НСД(m, p) = 1`. За Малою теоремою Ферма виконується:

```
m^(p − 1) ≡ 1 (mod p)
```

Підставимо розклад `e · d` у показник степеня:

```
m^(e·d)
= m^(1 + k·(p − 1)·(q − 1))
= m · (m^(p − 1))^(k·(q − 1))        [розклад степеня]
≡ m · (1)^(k·(q − 1))                 [за Малою теоремою Ферма: m^(p-1) ≡ 1 mod p]
≡ m · 1                               [піднесення 1 до будь-якого степеня дорівнює 1]
≡ m (mod p)                           [спрощення]
```

**Випадок 1B: `m` ділиться на `p` (`m ≡ 0 mod p`).**
Тоді будь-який додатний степінь `m` також дорівнює нулю за модулем `p`:

```
m^(e·d) ≡ 0^(e·d) ≡ 0 ≡ m (mod p)
```

Отже, для **будь-якого** цілого `m` незалежно від дільності виконується:

```
m^(e·d) ≡ m (mod p)
```

### Крок 2: Аналіз за модулем q

Провівши аналогічні міркування для простого модуля `q`, отримуємо:

- Якщо `m not≡ 0 mod q`, за Малою теоремою Ферма `m^(q − 1) ≡ 1 (mod q)`, звідки `m^(e·d) ≡ m (mod q)`.
- Якщо `m ≡ 0 mod q`, то `0^(e·d) ≡ 0 ≡ m (mod q)`.

Таким чином, безумовно виконується:

```
m^(e·d) ≡ m (mod q)
```

### Крок 3: Об'єднання за Китайською теоремою про лишки

Ми отримали систему двох порівнянь:

```
m^(e·d) − m ≡ 0 (mod p)   ⇒   p ∣ (m^(e·d) − m)
m^(e·d) − m ≡ 0 (mod q)   ⇒   q ∣ (m^(e·d) − m)
```

Оскільки `p` та `q` — різні прості числа, вони взаємно прості (`НСД(p, q) = 1`). Звідси випливає, що добуток `p · q` також ділить різницю `m^(e·d) − m`:

```
(p · q) ∣ (m^(e·d) − m)   ⇒   m^(e·d) ≡ m (mod N)
```

Доведення повністю завершено. Тотожність розшифрування RSA є абсолютною і діє для всього діапазону `ℤ_N`. ■

## Математичний аналіз криптографічних атак

Стійкість RSA базується не лише на складності факторизації `N`. Небачливий вибір параметрів `e` чи `d` перетворює криптосистему на вразливу ціль для комбінаторних та алгебраїчних атак.

### 1. Атака Вінера на малий приватний показник d

Бажаючи прискорити процес розшифрування або створення цифрового підпису, розробник може спокуситися вибором малого значення `d`. Майкл Вінер у 1990 році довів: якщо приватний показник `d` занадто малий, його можна обчислити за поліноміальний час із відкритого ключа `(N, e)`.

**Теорема Вінера:** Якщо `d < (1 / 3) · N^(1/4)`, то `d` є знаменником одного з підхідних дробів у розкладі `e / N` у ланцюговий дріб.

**Виведення:**
З рівності `e · d − k · ϕ(N) = 1` маємо:

```
e · d − k · (N − p − q + 1) = 1
```

Поділимо обидві частини на `d · N`:

```
e/N − k/d = (k · (p + q − 1) − 1) / (d · N)
```

Оскільки `p` та `q` мають однаковий порядок розміру `√N`, сума `p + q` порядку `2√N`. Зважаючи на те, що `k < d < (1/3) N^(1/4)`, чисельник правої частини суттєво менший за `N^(3/4)`, а знаменник `d · N` перевищує `d · N^(3/4)`. Це дає оцінку:

```
| e/N − k/d | < 1 / (2 · d²)
```

За класичною теоремою Лежандра про ланцюгові дроби, якщо дріб `k/d` наближає `e/N` із похибкою, меншою за `1 / (2d²)`, то `k/d` є одним із підхідних дробів (convergents) ланцюгового дробу для `e/N`.

Алгоритм атаки Вінера:
1. Розкласти дріб `e / N` у ланцюговий дріб: `[a₀; a₁, a₂, ...]`.
2. Обчислити послідовність підхідних дробів `k_i / d_i`.
3. Для кожного кандидатського знаменника `d_i` перевірити, чи є квадратне рівняння `x² − (N − ϕ_i + 1)x + N = 0` розв'язним у цілих числах, де `ϕ_i = (e · d_i − 1) / k_i`. Якщо корені цілі — це і є прості дільники `p` та `q`.

### 2. Трансляційна атака Гостада (Hastad's Broadcast Attack)

Типовим вибором для відкритого показника є мале число `e = 3` (для максимальної швидкості зашифрування). Якщо один і той самий відкритий текст `m` надсилається `e` різним отримувачам із однаковим `e = 3`, але різними модулями `N₁, N₂, N₃`, виникає катастрофічна вразливість.

Перехоплювач бачить три шифротексти:

```
c₁ ≡ m³ (mod N₁)
c₂ ≡ m³ (mod N₂)
c₃ ≡ m³ (mod N₃)
```

Припустимо, що модулі взаємно прості між собою (`НСД(N_i, N_j) = 1`). За Китайською теоремою про лишки спостерігач обчислює єдине значення `C mod (N₁ · N₂ · N₃)` таке, що:

```
C ≡ c₁ (mod N₁)
C ≡ c₂ (mod N₂)
C ≡ c₃ (mod N₃)
```

Оскільки `m < N₁`, `m < N₂` та `m < N₃`, то добуток `m³ < N₁ · N₂ · N₃`. Це означає, що за модулем `N₁ · N₂ · N₃` піднесення до степеня **не викликало жодного переповнення (збивання модуля)**!

Звідси порівняння перетворюється на звичайну числову тотожність над цілими числами:

```
C = m³  (в звичайних цілих числах)
```

Зловмиснику достатньо обчислити звичайний арифмето-геометричний кубічний корінь `m = ∛C` над цілими числами, повністю відновлюючи повідомлення `m` без знання жодного з приватних ключів `d_i` і без факторизації модулів!

### 3. Атака спільного модуля (Common Modulus Attack)

Якщо криптографічна система використовує один і той самий модуль `N` для кількох користувачів, видаючи їм різні пари ключів `(e₁, d₁)` та `(e₂, d₂)`, то при надсиланні одного повідомлення `m` цим двом користувачам виникає виток даних.

Перехоплювач має:

```
c₁ ≡ m^(e₁) (mod N)
c₂ ≡ m^(e₂) (mod N)
```

Якщо показники `e₁` та `e₂` взаємно прості (`НСД(e₁, e₂) = 1`), за Розширеним алгоритмом Евкліда можна знайти цілі числа `r` та `s` (одне з яких буде від'ємним) такі, що:

```
r · e₁ + s · e₂ = 1
```

Припустимо без втрати загальності, що `r > 0` та `s < 0`. Тоді спостерігач обчислює обернений елемент `c₂⁻¹ mod N` і комбінує шифротексти:

```
(c₁)^r · (c₂⁻¹)^(−s) ≡ (m^(e₁))^r · (m^(e₂))^s
                     ≡ m^(r·e₁ + s·e₂)
                     ≡ m¹ ≡ m (mod N)
```

Повідомлення `m` повністю відновлено за лінійну кількість кроків без факторизації модуля.

### 4. Атака Копперсміта через теорему про малі корені

Дон Копперсміт у 1996 році запропонував потужний метод аналізу модульних поліномів за допомогою зменшення решіток за алгоритмом LLL (Lenstra-Lenstra-Lovász).

**Теорема Копперсміта:** Нехай `P(x)` — монічний поліном степеня `d` відносно однієї змінної за модулем `N`. Усі цілі корені `x₀`, що задовольняють порівняння `P(x₀) ≡ 0 (mod N)` і обмежені умовою `|x₀| < N^(1/d)`, можна обчислити за поліноміальний час.

Ця атака застосовується, якщо відкритий текст `m` частково відомий (наприклад, заголовок стандартизовано, а невідомими є лише кілька молодших байтів). Якщо відносний розмір невідомої частини менший за `1/e` від довжини ключа, Копперсміт відновлює весь текст `m` за лічені секунди.

### 5. Атака Беллкора на CRT-розшифрування (Fault Injection Attack)

При використанні Китайської теореми про лишки для прискорення розшифрування або підпису виникає апаратна вразливість, відкрита дослідниками з Bellcore (Boneh, DeMillo, Lipton) у 1997 році.

Під час розшифрування обчислюються дві компоненти: `m_p = c^(d_p) mod p` та `m_q = c^(d_q) mod q`. Припустимо, що внаслідок штучно викликанного збою (наприклад, імпульсу лазера чи стрибка напруги у смарткарті) обчислення `m_p` відбулося з помилкою і дало зіпсоване значення `m_p'`, у той час як `m_q` обчислилося правильно.

Рекомбінація Гарнера видає зіпсоване підписане значення `s'`. Розглянемо різницю між правильним підписом `s` та зіпсованим `s'`:

```
s'not≡ s (mod p)   ⇒   p not∣ (s'^e − m)
s' ≡ s (mod q)     ⇒   q ∣ (s'^e − m)
```

Атакуючому достатньо обчислити Найбільший Спільний Дільник за допомогою звичайного алгоритму Евкліда:

```
q = НСД(s'^e − m, N)
```

За один-єдиний виклик алгоритму Евкліда атакуючий знаходить просте число `q` і миттєво факторизує весь модуль `N`! Для відвернення атаки Беллкора сучасні криптографічні чипи виконують перевірку підпису перед видачею результату зовні.
