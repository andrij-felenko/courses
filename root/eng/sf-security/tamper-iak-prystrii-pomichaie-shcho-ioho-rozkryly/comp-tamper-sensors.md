# 🔌 Класифікація та схемотехніка тампер-давачів

Фізичний периметр безпеки пристрою вимагає комбінації різнотипних сенсорних технологій із ретельно розрахованими електричними колами підключення. Інженерне проєктування тамперних інтерфейсів вирішує дві протилежні задачі: гарантувати миттєве спрацьовування тривоги при спробі несанкціонованого доступу (розмикання контактів, оптичне засвічення, механічне свердління чи зміна міжелектродної ємності) та унеможливити катастрофічні хибні занулення ключів шифрування через електромагнітні завади чи статичний струм витоку.

### 1. Механічні мікроперемикачі (Microswitches)

Механічний контакт — найпростіший і найбільш перевірений засіб контролю положення кришки корпусу або притискання плати до шасі.

```
       VDD / VBAT (Резервне живлення)
          │
         ┌┴┐
         │ │ R_pull (1 МОм .. 10 МОм)
         └┬┘
          ├─────────────── До входу TAMP_INx (MCU)
          │
        ┌─o──┐
        │ SW │ (Нормально-замкнений контакт NC при закритій кришці)
        └─o──┘
          │
         ─┴─ GND
```

#### Особливості схемотехніки:
- **Конфігурація NC (Normally Closed):** у робочому стані кришка притискає кнопку, замикаючи вхід мікроконтролера на `GND`. Логічний рівень на вході — стабільний «0». При відкритті кришки пружина розмикає контакт, і підтягувальний резистор `R_pull` піднімає потенціал до `VBAT`, що фіксується як наростаючий фронт тривоги.
- **Вибір номіналу резистора:** у батарейних системах струм спокою є критичним. При `R_pull = 10 МОм` і напрузі `3 В` струм витоку під час відкритого стану становить лише `0.3 мкА`. Застосування внутрішніх підтяжок MCU (зазвичай 40 кОм) у постійному режимі неприпустиме, оскільки це створило б струм витоку `75 мкА`, що розрядило б літієву батарейку за кілька місяців.
- **Вразливість та захист:** механічний перемикач можна зафіксувати тонкою голкою, введеною крізь щілину корпусу, або закоротити провідним лаком. Тому в банківських терміналах використовують матрицю з 4–8 паралельно-послідовних мікрокнопок або силіконові купольні контакти на внутрішньому боці плати.

### 2. Оптичні давачі темряви (Photodiode Darkness Monitors)

Оптичний тампер фіксує потрапляння фотонів світла всередину герметичного непрозорого корпусу при знятті кришки, появі тріщини або просвердлюванні отвору.

```
       VDD / VBAT
          │
         ┌┴┐
         │ │ R_gain (10 МОм .. 100 МОм)
         └┬┘
          ├─────────────── До компаратора / TAMP_INx
          │
          ▲  Зворотне включення
       ───┴─── Фотодіод (PIN-діод)
          │
         ─┴─ GND
```

#### Принцип дії:
1. **Зворотне зміщення:** кремнієвий фотодіод увімкнений у зворотному напрямку. У повній темряві крізь p-n перехід протікає лише мікроскопічний темновий струм (Dark Current, зазвичай `I_dark < 1 нА` при кімнатній температурі). Падіння напруги на резисторі `R_gain` близьке до нуля.
2. **Світловий спалах:** при відкритті корпусу або свердлінні зовнішній світловий потік генерує електронно-діркові пари в збідненій зоні. Зворотний фотострум зростає в тисячі разів (до `10–100 мкА`). Напруга на виході стрибкоподібно зростає майже до рівня `VBAT`, переводячи вхідний тригер Шмітта або ультранизькоспоживаючий компаратор у стан тривоги.
3. **Оптичні лабіринти:** вентиляційні канали корпусу виготовляють у вигляді звивистих чорних лабіринтів з матовим покриттям, що поглинає відбиті промені, але пропускає повітря.

### 3. Активна захисна сітка (Active Shield Mesh)

Активна сітка утворює фізичний бар'єр над захищеною зоною плати або чипа. На відміну від пасивного заземленого екрана, активна сітка перебуває під постійним динамічним опитуванням.

```
 Контролер тампера                   Захисна зона (Flex PCB)
 ┌───────────────┐                  ┌───────────────────────────────────────┐
 │               │  TAMP_OUT1 (LFSR)│  ───┐ ┌───┐ ┌───┐ ┌───┐ ┌───┐ ┌───    │
 │ Генератор     ├─────────────────►│     │ │   │ │   │ │   │ │   │ │       │
 │ псевдовипад-  │                  │  ───┘ └───┘ └───┘ └───┘ └───┘ └───► ──┤ До TAMP_IN1
 │ кових кодів   │  TAMP_OUT2 (!LFSR│  ───┐ ┌───┐ ┌───┐ ┌───┐ ┌───┐ ┌───    │
 │ (LFSR)        ├─────────────────►│     │ │   │ │   │ │   │ │   │ │       │
 │               │                  │  ───┘ └───┘ └───┘ └───┘ └───┘ └───► ──┤ До TAMP_IN2
 └───────────────┘                  └───────────────────────────────────────┘
```

#### Параметри проєктування друкованої плати (PCB Layout):
- **Геометрія провідників:** ширина доріжки `50–100 мкм`, відстань між сусідніми доріжками `50–100 мкм`. Такий крок унеможливлює свердління навіть найтоншим стоматологічним бором без пошкодження щонайменше одного провідника.
- **Багатошарове розташування:** доріжки сітки розводять на зовнішніх шарах (Top Layer і Bottom Layer), а також у проміжних сигнальних шарах навколо криптографічних мікросхем. Перехідні отвори роблять глухими (Blind Vias) або прихованими (Buried Vias), щоб унеможливити доступ до внутрішніх шарів без руйнування зовнішньої сітки.
- **Динамічний стимул:** по одній лінії передається псевдовипадкова послідовність бітів від лінійного регістру зсуву зі зворотним зв'язком (LFSR), по сусідній — її побітова інверсія або сигнал із часовим зсувом. Будь-який місток між сусідніми лініями миттєво взаємно спотворює сигнали й активує аварійний сигнал неспівпадіння.

### 4. Ємнісні давачі наближення та зміщення

Ємнісний тампер вимірює зміну паразитної ємності між електродами на платі та металевим шасі пристрою.

```
       Зовнішня металева кришка (Електрод 1)
       ─────────────────────────────────────
                         ↕ Зміна відстані d → зміна ємності C = ε·S / d
       ┌───────────────────────────────────┐
       │   Електрод 2 на друкованій платі  │
       └─────────────────┬─────────────────┘
                         │
                         ▼
        До модуля ємнісного вимірювання (Capacitive Sensing / CDC)
```

При спробі підняти кришку навіть на 0.5 мм або наблизити металевий інструмент/зонд ємність контуру змінюється на кілька пікофарад. Контролер фіксує зміну резонансної частоти LC-генератора чи часу заряду RC-ланцюжка і генерує сигнал попередження.

### Порівняльна таблиця сенсорних технологій

| Тип сенсора | Чутливість до впливу | Струм споживання | Головна вразливість | Засіб протидії |
|---|---|---|---|---|
| **Мікроперемикач NC** | Відкриття кришки (> 1 мм) | < 0.5 мкА | Механічна фіксація голкою | Заливка компаундом, матричне розташування |
| **Фотодіод темряви** | Світловий спалах (> 0.1 люкс) | < 0.1 мкА | Робота в повній темряві (червоне світло) | Інфрачервона чутливість, лабіринти |
| **Активна сітка (Mesh)** | Свердління, розріз, шунт | 1.0–3.0 мкА | Паразитна ємність довгих трас | Динамічний LFSR, контроль фази |
| **Ємнісний сенсор** | Наближення інструменту, зміщення | 2.0–5.0 мкА | Температурний дрейф діелектрика | Диференціальні пари електродів |
