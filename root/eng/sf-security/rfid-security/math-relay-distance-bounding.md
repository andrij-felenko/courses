# 🧮 Математична модель атаки ретрансляції та протоколу Distance Bounding

Атака ретрансляції (*Relay Attack*) на фізичному рівні не зламує криптографічні ключі, а створює тунель затримки між зчитувачем і тегом. Протоколи обмеження відстані (*Distance Bounding*) виявляють цей тунель за допомогою вимірювання часу подвійного прольоту сигналів (*Round-Trip Time*, RTT) на швидкості світла.

---

### 1. Бюджет часу подвійного прольоту (RTT) та фізичні межі

Час подвійного прольоту `t_RTT` складається з фізичного часу поширення електромагнітної хвилі туди й назад на відстань `d`, швидкості поширення сигналу у фідерних лініях та апаратного часу обробки кадру в мікросхемі тега `t_proc`:

```
t_RTT = (2 · d / v) + t_proc + t_jitter
```

де:
* `v` — швидкість поширення електромагнітного сигналу у середовищі (`v = c ≈ 3·10⁸ м/с` у повітрі; у діелектриках друкованої плати `v = c / √ε_r ≈ 2·10⁸ м/с`).
* `t_proc` — зафіксований апаратний час затримки логічних вентилів тега (для бітових раундів `t_proc` є константою в кілька наносекунд).
* `t_jitter` — випадкове відхилення тактування (джитер), викликане шумом квантування й фазовим шумом гетеродина.

Якщо максимальний дозволений радіус фізичної присутності тега встановлено як `d_max` (наприклад, 1 метр для безконтактного платежу або відкриття дверного замка авто), гранично допустимий час відповіді `t_max` обчислюється так:

```
t_max = (2 · d_max / c) + t_proc + 3·σ_jitter
```

#### Розрахунок затримок для різних дистанцій

Порівняємо фізичний час поширення хвилі для двох сценаріїв:

```
Сценарій А (Легітимний тег на відстані d = 1 м):
t_prop = 2 · 1 / (3·10⁸) = 6.67·10⁻⁹ с = 6.67 нс

Сценарій Б (Атака ретрансляції через радіоміст 5G/Wi-Fi на d = 100 м):
t_prop_wave = 2 · 100 / (3·10⁸) = 666.67 нс = 0.667 мкс
```

До часу поширення хвилі додається затримка цифрової обробки кадру у мережі ретрансляції: пакетизація на рівні L2/L3, буферизація в стеку Wi-Fi/5G та час комутації прийомопередавача `t_relay`. Практична затримка найшвидшого цифрового радіомосту становить від `10 мс` до `50 мс` (`10 000 000 нс`).

Обчислимо співвідношення затримки ретрансляції та фізичного порогу:

```
Затримка ретранслятора Δt = 20 мс = 20 000 000 нс
Фізичний поріг часу t_prop (1 м) = 6.67 нс

Співвідношення:
Δt / t_prop = 20 000 000 / 6.67 ≈ 3 000 000 разів перевищення порогу!
```

Таким чином, вимірювання затримки з точністю до десятків наносекунд дозволяє безумовно виявити й заблокувати будь-які цифрові мережі ретрансляції.

### 2. Математичний аналіз атак у бітовому протоколі Брандса-Шома

Класичний протокол Брандса-Шома (*Brands-Chaum Distance Bounding*) складається з трьох послідовних фаз:
1. **Фаза зобов'язань (Slow Phase):** Тег і зчитувач обмінюються зашифрованими одноразовими числами `N_V` та `N_P`. Тег генерує дві секретні послідовності бітів `R⁰ = (r₁⁰, ..., r_k⁰)` та `R¹ = (r₁¹, ..., r_k¹)`.
2. **Швидка фаза (Fast Challenge-Response Phase):** Передається `k` послідовних 1-бітових раундів.
3. **Фаза підтвердження (Verification Phase):** Тег передає криптографічний підпис `HMAC(K, N_V || N_P || C || R)` по всьому транскрипту сесії.

У кожному швидкому раунді `i ∈ [1, k]`:
- Зчитувач надсилає випадковий біт запиту `c_i ∈ {0, 1}`.
- Тег негайно відповідає бітом `r_i = r_i⁰` (якщо `c_i = 0`) або `r_i = r_i¹` (якщо `c_i = 1`).

#### Аналіз модальностей атак та ймовірностей успіху

У теорії протоколів обмеження відстані виділяють три класи шахрайства:

```
1. Distance Fraud:   Чесний зчитувач ────── Скривджений тег бреше про свою відстань
2. Mafia Fraud:      Зчитувач ─── Атакуючий (Relay) ─── Невідаючий тег
3. Terrorist Fraud:  Зчитувач ─── Атакуючий + Тег-змовник (передає часткові секрети)
```

Обчислимо ймовірність успіху атакуючого у випадку **Mafia Fraud** (атака ретрансляції без допомоги тега).

Для кожного бітового раунду `i` атакуючий може спробувати передати біт запиту `c'_i` тегу заздалегідь (*Early Challenge Attack*), або вгадати відповідь `r'_i` для зчитувача до отримання запиту (*Early Response Attack*).

Зводна матриця можливих варіантів відповідей атакуючого у 1-бітовому раунді:

```
Варіант A (Атакуючий вгадав c_i до випромінювання):
Імовірність вгадати біт запиту: P(c'_i = c_i) = 1/2. 
Якщо вгадав — відповідь r_i буде 100% вірною.

Варіант B (Атакуючий не вгадав c_i):
Імовірність помсти: P(c'_i ≠ c_i) = 1/2.
Атакуючий надсилає довільний біт r'_i. Імовірність вгадати біт відповіді: P(r'_i = r_i) = 1/2.
```

Сумарна ймовірність `P_i` успішного проходження одного раунду обчислюється за формулою повної ймовірності:

```
P_i = P(Успіх | Вгадав c_i)·P(c'_i = c_i) + P(Успіх | Не вгадав c_i)·P(c'_i ≠ c_i)
P_i = 1 · (1/2) + (1/2) · (1/2)
P_i = 1/2 + 1/4 = 3/4 = 0.75
```

Для всієї серії з `k` незалежних бітових раундів ймовірність `P_success` того, що атакуючий зможе обдурити систему по всьому кадру без виявлення затримки, становить:

```
P_success = (3/4)^k
```

Обчислимо необхідну кількість раундів `k` для досягнення криптографічної стійкості:

```
Для k = 8 бітів:
P_success = (3/4)⁸ = 6561 / 65536 ≈ 0.1001 (10.01%)

Для k = 16 бітів:
P_success = (3/4)¹⁶ ≈ 0.0100 (1.00%)

Для k = 32 бітів:
P_success = (3/4)³² ≈ 1.004·10⁻⁴ (0.01%)

Для k = 64 бітів:
P_success = (3/4)⁶⁴ ≈ 1.008·10⁻⁸ (0.000001%)
```

### 3. Вплив завад у каналі (BER) та вибір числового порогу

У реальному радіоканалі передача 1-бітових імпульсів піддається впливу шуму, через що легітимний тег може припуститися помилки з ймовірністю `p_e` (*Bit Error Rate*, BER).

Якщо зчитувач вимагатиме 100% ідеальних відповідей у всіх `k` раундах, ймовірність помилкового відхилення легітимного тега (*False Reject Rate*, FRR) становитиме:

```
FRR = 1 - (1 - p_e)^k
```

При `p_e = 0.01` (1% помилок у каналі) та `k = 64` бітів:

```
FRR = 1 - (0.99)⁶⁴ ≈ 1 - 0.5248 = 0.4752 (47.5% хибних відмов!)
```

Щоб запобігти масовим відмовам легітимним користувачам, протокол дозволяє тегу припуститися не більше `m` помилкових бітів із `k` раундів. У цьому випадку ймовірність успіху атакуючого `P_attack` розраховується за біноміальним розподілом:

```
P_attack = ∑_{j=0}^{m} (k choose j) · (3/4)^{k-j} · (1/4)^j
```

Вибір параметрів `k` та `m` є класичним компромісом у радіоінженерії між ймовірністю пропуску атаки (*False Accept Rate*, FAR) та ймовірністю хибного блокування легітимного користувача (FRR).

### 4. Геометричне обмеження у багатоантенних системах (TDoA)

У складних об'єктах контролю доступу (наприклад, ворота паркінгу або склади) використовується кілька синхронізованих привальних антено-зчитувачів `V₁, V₂, ..., V_N`.

Відстань від тега до кожного зчитувача `i` розраховується за часом приходу сигналу (Time of Arrival, ToA):

```
d_i = c · (t_i - t_0)
```

де `t_0` — невідомий час початку випромінювання тега.

Для усунення невідомої величини `t_0` застосовують метод різниці часу приходу сигналів (*Time Difference of Arrival*, TDoA) між парами антено-зчитувачів `i` та `j`:

```
Δd_{i,j} = d_i - d_j = c · (t_i - t_j)
```

Геометричним місцем точок можливого розташування тега на площині є гіпербола, фокусами якої є антени `V_i` та `V_j`. Перетин трьох і більше гіпербол від різних пар антен дозволяє визначити фізичні координати `(x, y, z)` тега в просторі з точністю до кількох сантиметрів. Якщо розраховані координати виходять за межі геометричного периметра дверей, система фіксує спробу ретрансляції сигналу.
