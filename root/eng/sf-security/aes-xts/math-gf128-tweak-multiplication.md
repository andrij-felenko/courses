# 🧮 Алгебра поля GF(2^128) та множення твіка на альфа

У режимі шифрування XTS-AES маска кожного 16-байтового блока всередині сектора формується шляхом послідовного множення базового твіка на ступені примітивного елемента `α` у скінченному полі Галуа `GF(2¹²⁸)`. Ця математична операція генерує послідовність псевдовипадкових масок із мінімальними обчислювальними витратами без повторного виклику криптографічного перетворення AES.

### Поліноміальне представлення елементів поля

Скінченне поле `GF(2¹²⁸)` (поле Галуа з `2¹²⁸` елементами) будується як фактор-кільце многочленів із бінарними коефіцієнтами `GF(2)[x]` за модулем незвідного полінома `P(x)` степеня 128:

```
GF(2¹²⁸) ≅ GF(2)[x] / ⟨P(x)⟩
```

Стандарт IEEE 1619-2007 фіксує конкретний первісний (незвідний) поліном:

```
P(x) = x¹²⁸ + x⁷ + x² + x + 1
```

Будь-який 128-бітний блок даних (зокрема значення твіка `T`) розглядається як поліном степеня не вище 127:

```
A(x) = a₁₂₇·x¹²⁷ + a₁₂₆·x¹²⁶ + ... + a₁·x + a₀,   де aᵢ ∈ {0, 1}
```

Додавання двох елементів у полі `GF(2¹²⁸)` еквівалентне порозрядному додаванню за модулем 2 відповідних коефіцієнтів многочленів, що в апаратній та програмній реалізації відповідає операції побітового виключного «АБО» (`XOR`):

```
A(x) + B(x) = ∑ (aᵢ ⊕ bᵢ)·xⁱ
```

### Порівняння полів Галуа: XTS проти AES S-Box та GCM

У сучасній криптографії застосовуються різні поля Галуа, правила представлення яких суттєво різняться:

1. **AES Rijndael S-Box (`GF(2⁸)`):** використовує 8-бітне поле за модулем `x⁸ + x⁴ + x³ + x + 1` (шістнадцяткова константа `0x11B`). Кожен байт розглядається як многочлен степеня не вище 7.
2. **Автентифікований режим GCM (`GF(2¹²⁸)` за NIST SP 800-38D):** використовує той самий поліном `x¹²⁸ + x⁷ + x² + x + 1`, проте застосовує **віддзеркалений порядок бітів Big-Endian** (англ. *reflected representation*). У режимі GCM молодший коефіцієнт многочлена `x⁰` розташований у найстаршому біті нульового байта, а операція множення на `x` виконується шляхом бітового зсуву вправо з маскою редукції `0xE1` у старшому байті.
3. **Режим дискового шифрування XTS (`GF(2¹²⁸)` за IEEE 1619):** застосовує **прямий стандартний порядок байтів Little-Endian**. Коефіцієнт `x⁰` розташований у нульовому біті байта `t[0]`, старший коефіцієнт `x¹²⁷` — у сьомому біті байта `t[15]`, а множення на `x` виконується зсувом вліво з константою редукції `0x87` у молодшому байті.

Плутанина між форматами GCM та XTS є однією з найпоширеніших помилок при реалізації низькорівневих криптографічних бібліотек.

### Порядок байтів у стандарті IEEE 1619

128-бітний вектор `T` зберігається як масив із 16 байтів `t[0] .. t[15]`. Молодший коефіцієнт `a₀` розташований у нульовому (наймолодшому) біті нульового байта `t[0]`, а старший коефіцієнт `a₁₂₇` — у сьомому (найстаршому) біті п'ятнадцятого байта `t[15]`:

```
t[0]  = a₇·x⁷   + a₆·x⁶   + ... + a₁·x   + a₀
t[1]  = a₁₅·x⁷  + a₁₄·x⁶  + ... + a₉·x   + a₈
...
t[15] = a₁₂₇·x⁷ + a₁₂₆·x⁶ + ... + a₁₂₁·x + a₁₂₀
```

Примітивним генератором `α` обирається поліном першого степеня:

```
α = x
```

У 16-байтовому представленні елемент `α` має шістнадцятковий вигляд:

```
t_alpha = [0x02, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00,
           0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00]
```

### Множення на α за модулем P(x)

Множення довільного елемента `A(x)` на примітивний елемент `α = x` за модулем `P(x)` здійснюється за алгебраїчним правилом:

```
A(x) · x mod P(x)
= (a₁₂₇·x¹²⁷ + a₁₂₆·x¹²⁶ + ... + a₀) · x mod P(x)          [підстановка многочлена A(x)]
= a₁₂₇·x¹²⁸ + a₁₂₆·x¹²⁷ + ... + a₁·x² + a₀·x mod P(x)      [дистрибутивність множення на x]
```

Розглянемо два випадки залежно від старшого біта `a₁₂₇`:

#### Випадок 1: Старший біт a₁₂₇ = 0

Якщо найстарший степінь `x¹²⁸` має коефіцієнт 0, результат добутку має степінь не більше 127 і не потребує приведення за модулем:

```
A(x) · x = a₁₂₆·x¹²⁷ + a₁₂₅·x¹²⁶ + ... + a₀·x
```

У двійковому представленні це звичайний бітовий зсув усього 128-бітного числа вліво на 1 біт (перенесення бітів від `t[k]` до `t[k+1]`).

#### Випадок 2: Старший біт a₁₂₇ = 1

Якщо найстарший коефіцієнт `a₁₂₇ = 1`, після зсуву виникає член `x¹²⁸`, який необхідно замінити за модулем редукційного полінома:

```
x¹²⁸ mod (x¹²⁸ + x⁷ + x² + x + 1)
= x⁷ + x² + x + 1                                          [редукція за незвідним поліномом P(x)]
```

Бінарний поліном `x⁷ + x² + x + 1` записується у шістнадцятковому вигляді як `0x87` (двійкове `10000111₂`). Оскільки він має степінь 7, він потрапляє винятково в нульовий байт `t[0]` масиву Little-Endian.

Таким чином, покроковий алгоритм обчислення `T_next = T ⊗ α`:
1. Зсунути 16-байтовий масив `T` вліво на 1 біт із переносом між байтами від молодших індексів до старших.
2. Якщо до зсуву старший біт байта `t[15]` (біт 7) дорівнював 1, виконати операцію:
   `t[0] ^= 0x87`

### Покроковий приклад обчислення

Нехай 128-бітний твік `T` має значення, у якому старший біт встановлено в одиницю:

```
T = 0x80 00 00 00 00 00 00 00 00 00 00 00 00 00 00 80
```

1. Аналіз старшого біта: `t[15] = 0x80`, старший біт `a₁₂₇ = 1`.
2. Зсув масиву вліво на 1 біт:
   - `t[0] = 0x80 << 1 = 0x00` (перенос 1 у наступний байт)
   - `t[1] = (0x00 << 1) | 1 = 0x01`
   - `t[15] = 0x80 << 1 = 0x00`
   - Отримуємо проміжне значення: `0x00 01 00 ... 00`
3. Редукція полінома за модулем:
   - Оскільки `a₁₂₇ = 1`, модифікуємо `t[0]`:
   - `t[0] = 0x00 ^ 0x87 = 0x87`
4. Результат `T ⊗ α`:
   ```
   T_next = 0x87 01 00 00 00 00 00 00 00 00 00 00 00 00 00 00
   ```

### Алгебраїчні властивості та довжина циклу

Оскільки поліном `P(x) = x¹²⁸ + x⁷ + x² + x + 1` є первісним многочленом над полем `GF(2)`, мультиплікативна група поля `GF(2¹²⁸)*` є циклічною групою порядку:

```
|GF(2¹²⁸)*| = 2¹²⁸ - 1
```

Елемент `α = x` є генератором цієї групи, тому послідовність степенів `α⁰, α¹, α², ..., αʲ` має максимальний можливий період `2¹²⁸ - 1`. Це гарантує, що для будь-якого дискового сектора (навіть граничного розміру `2²⁰` блоків за стандартом IEEE 1619) усі згенеровані маски `T[j]` є строго унікальними та лінійно незалежними.

### Апаратне прискорення через безпереносне множення (CLMUL)

На сучасних мікропроцесорах x86-64 та ARM64 операції множення в полі Галуа прискорюються за допомогою спеціальних векторних інструкцій безпереносного множення (Carry-less Multiplication):

* **x86-64 (PCLMULQDQ / VPCLMULQDQ):** Інструкція `_mm_clmulepi64_si128` обчислює добуток двох 64-бітних бінарних поліномів за 1–3 такти процесора. Для обчислення ступенів `αʲ` процесор може розпаралелювати генерацію одразу 4 або 8 твіків через інструкції AVX-512.
* **ARMv8-A (PMULL / PMULL2):** Векторні інструкції криптографічного розширення Neon виконують безпереносне множення над 64-бітними регістрами `d0-d31`.

Завдяки цьому апаратні драйвери ядра Linux генерують твік-маски для всього 4096-байтного дискового сектора менш ніж за 50 наносекунд, забезпечуючи нульову втрату пропускної здатності дискових операцій на накопичувачах зі швидкістю понад 7 ГБ/с.
