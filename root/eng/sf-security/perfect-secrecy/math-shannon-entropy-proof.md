# 🧮 Математичні доведення теорем Шеннона: ймовірності, ентропія та розмір ключів

У криптографії інтуїтивні твердження про «неможливість зламати шифр» не мають сили без строгого математичного фундаменту. Якщо алгоритм виглядає заплутаним або містить мільйони перемішувань, це гарантує лише те, що поточні дослідники не бачать простої атаки, але не доводить відсутність такої атаки в принципі. Клод Шеннон у 1949 році вперше побудував дедуктивну теорію секретності, де безпека спирається на аксіоми теорії ймовірностей та алгебраїчні структури. Тут зібрано повні покрокові доведення фундаментальних теорем Шеннона: еквівалентності ймовірнісних критеріїв досконалої таємниці, теореми про мінімальний розмір ключового простору `|K| ≥ |M|`, критерію латинських квадратів для рівних просторів, ентропійних меж `H(K) ≥ H(M)`, наслідків нерівномірного розподілу ключів, теорії квазігруп та оцінок мін-ентропії.

### 1. Позначення та ймовірнісна модель криптосистеми

Введемо точні математичні об'єкти, якими оперує теорія Шеннона. Позначимо всі символи та простори українськими назвами при їх першій появі:

1. **Простір повідомлень** позначимо великою літерою `M`. Це скінченна множина всіх можливих відкритих текстів. Конкретне повідомлення позначимо малою літерою `m ∈ M`.
2. **Простір ключів** позначимо великою літерою `K`. Це скінченна множина всіх можливих секретних ключів. Конкретний ключ позначимо малою літерою `k ∈ K`.
3. **Простір шифротекстів** позначимо великою літерою `C`. Це скінченна множина всіх можливих криптограм. Конкретний шифротекст позначимо малою літерою `c ∈ C`.
4. **Алгоритм шифрування** позначимо `Enc(k, m)`, де функція `Enc : K × M → C` зіставляє парі «ключ, повідомлення» шифротекст `c`.
5. **Алгоритм дешифрування** позначимо `Dec(k, c)`, де функція `Dec : K × C → M` повертає відкритий текст за умови, що використано правильний ключ: для будь-яких `k ∈ K` та `m ∈ M` виконується `Dec(k, Enc(k, m)) = m`.

Випадковий вибір повідомлення описується дискретною випадковою величиною `M` із розподілом ймовірностей `P(M = m)`, де велика літера `P` позначає ймовірність (*probability*). Припускаємо, що для всіх повідомлень `m ∈ M` апріорна ймовірність є строго додатною: `P(M = m) > 0`.

Випадковий вибір ключа описується випадковою величиною `K` із розподілом `P(K = k)`. Ключ обирається відправником до початку передачі даних незалежно від відкритого тексту, тобто випадкові величини `M` та `K` є **статистично незалежними**:

```
P(M = m, K = k) = P(M = m) · P(K = k)
```

Шифротекст `C` є випадковою величиною, породженою детермінованою функцією `Enc(K, M)`. Ймовірність появи конкретного шифротексту `c ∈ C` визначається сумою по всіх парах `(m, k)`, які приводять до `c`:

```
P(C = c) = ∑ P(M = m) · P(K = k)    [сума по всіх m ∈ M та k ∈ K, для яких Enc(k, m) = c]
```

### 2. Теорема про еквівалентність критеріїв досконалої таємниці

Означення Шеннона вимагає, щоб спостереження шифротексту не змінювало ймовірностей відкритого тексту. Сформулюємо це твердження як теорему з трьома еквівалентними умовами.

**Теорема 1 (Еквівалентність форм досконалої таємниці).** Для будь-якої криптосистеми `(Enc, Dec)` такі три твердження є строго еквівалентними:

1. **Апостеріорна форма:** для всіх `m ∈ M` та всіх `c ∈ C`, для яких `P(C = c) > 0`, виконується:
   ```
   P(M = m | C = c) = P(M = m)
   ```
2. **Форма незалежності шифротексту:** для всіх `m ∈ M` та всіх `c ∈ C` умовна ймовірність шифротексту не залежить від повідомлення:
   ```
   P(C = c | M = m) = P(C = c)
   ```
3. **Форма однакової правдоподібності:** для будь-яких двох повідомлень `m₁, m₂ ∈ M` та будь-якого шифротексту `c ∈ C`:
   ```
   P(C = c | M = m₁) = P(C = c | M = m₂)
   ```

**Доведення еквівалентності (1) ⟺ (2):**

Запишемо формулу умовної ймовірності та формулу Байєса для події `M = m` за умови `C = c`:

```
P(M = m | C = c)
= P(M = m ∩ C = c) / P(C = c)            [означення умовної ймовірності]
= (P(C = c | M = m) · P(M = m)) / P(C = c) [формула множення ймовірностей]
```

Якщо виконується умова (1), тобто `P(M = m | C = c) = P(M = m)`, підставимо це значення у ліву частину:

```
P(M = m)
= (P(C = c | M = m) · P(M = m)) / P(C = c)   [підстановка умови P(M = m | C = c) = P(M = m)]
```

Оскільки за нашою умовою `P(M = m) > 0`, ми можемо поділити обидві частини рівності на `P(M = m)`:

```
1 = P(C = c | M = m) / P(C = c)   [скорочення на P(M = m) > 0]
```

Помноживши обидві частини на `P(C = c)`, отримуємо:

```
P(C = c | M = m) = P(C = c)       [множення обох частин на P(C = c)]
```

Це доводить, що з (1) випливає (2). Обернений перехід від (2) до (1) виконується тими самими кроками у зворотному порядку, оскільки `P(C = c) > 0`.

**Доведення еквівалентності (2) ⟺ (3):**

Якщо виконується (2), то для будь-якого `m₁` маємо `P(C = c | M = m₁) = P(C = c)`, і для будь-якого `m₂` маємо `P(C = c | M = m₂) = P(C = c)`. Праві частини однакові, тому ліві частини рівні між собою: `P(C = c | M = m₁) = P(C = c | M = m₂)`. Отже, з (2) випливає (3).

Доведемо, що з (3) випливає (2). Нехай `P(C = c | M = m)` має одне й те саме постійне значення для всіх `m ∈ M`. Позначимо цю константу літерою `q`. За формулою повної ймовірності обчислимо безумовну ймовірність `P(C = c)`:

```
P(C = c)
= ∑ P(M = m) · P(C = c | M = m)   [формула повної ймовірності по всіх m ∈ M]
= ∑ P(M = m) · q                 [підстановка сталого значення q]
= q · ∑ P(M = m)                 [винесення спільного множника q за знак суми]
= q · 1                          [сума ймовірностей повної групи подій дорівнює 1]
= q                              [отримали P(C = c) = q]
```

Оскільки `P(C = c | M = m) = q` і `P(C = c) = q`, то `P(C = c | M = m) = P(C = c)`. Твердження повністю доведено.

### 3. Теорема Шеннона про розмір простору ключів

Найглибшим результатом теорії є доведення того, що досконала таємність вимагає колосального ресурсу невизначеності: ключів має бути щонайменше стільки ж, скільки повідомлень.

**Теорема 2 (Нижня межа простору ключів за Шенноном).** Якщо криптосистема `(Enc, Dec)` забезпечує досконалу таємність для довільного простору повідомлень `M`, де `P(M = m) > 0` для всіх `m ∈ M`, то кількість можливих ключів не може бути меншою за кількість можливих повідомлень:

```
|K| ≥ |M|
```

**Доведення (від супротивного):**

Припустимо протилежне: нехай існує криптосистема з досконалою таємністю, у якій кількість ключів строго менша за кількість повідомлень, тобто `|K| < |M|`.

Оберемо будь-який можливий шифротекст `c ∈ C`, для якого `P(C = c) > 0` (такий шифротекст обов'язково існує, оскільки сума ймовірностей дорівнює одиниці).

Розглянемо множину `S_c` усіх можливих повідомлень, які можна отримати дешифруванням цього фіксованого шифротексту `c` за допомогою всіх наявних ключів із простору `K`:

```
S_c = { m ∈ M | ∃ k ∈ K : Dec(k, c) = m }
```

Оскільки алгоритм дешифрування `Dec` є детермінованою функцією, кожен ключ `k ∈ K` породжує не більше одного повідомлення `m = Dec(k, c)`. Звідси потужність множини `S_c` обмежена зверху кількістю ключів:

```
|S_c| ≤ |K|
```

За нашим припущенням `|K| < |M|`. Звідси отримуємо строгу нерівність:

```
|S_c| < |M|
```

Це означає, що множина `S_c` є строгою підмножиною `M`, і у просторі повідомлень обов'язково знайдеться принаймні одне повідомлення `m* ∈ M`, яке **не належить** множині `S_c` (`m* ∉ S_c`).

З'ясуємо ймовірнісні наслідки для цього елемента `m*`:
1. За означенням `m* ∉ S_c` не існує жодного ключа `k ∈ K`, для якого `Dec(k, c) = m*`.
2. За властивістю коректності дешифрування це означає, що не існує жодного ключа `k ∈ K`, для якого `Enc(k, m*) = c`.
3. Отже, умовна ймовірність згенерувати шифротекст `c` при відправленні повідомлення `m*` дорівнює точно нулю:
   ```
   P(C = c | M = m*) = 0
   ```

Обчислимо тепер апостеріорну ймовірність `P(M = m* | C = c)` за формулою Байєса:

```
P(M = m* | C = c)
= (P(C = c | M = m*) · P(M = m*)) / P(C = c)   [формула Байєса]
= (0 · P(M = m*)) / P(C = c)                   [підстановка P(C = c | M = m*) = 0]
= 0                                            [множення на нуль]
```

Проте за початковою умовою теореми апріорна ймовірність цього повідомлення є строго додатною: `P(M = m*) > 0`.

Ми отримали:

```
P(M = m* | C = c) = 0 ≠ P(M = m*)
```

Це прямо суперечить умові досконалої таємниці `P(M = m | C = c) = P(M = m)`.

Отримане протиріччя доводить хибність припущення `|K| < |M|`. Отже, для будь-якої досконало таємної криптосистеми обов'язково виконується:

```
|K| ≥ |M|
```

### 4. Критерій Шеннона для мінімального випадку |K| = |M|

Розглянемо випадок, коли криптосистема досягає абсолютної теоретичної межі економічності, тобто `|K| = |M| = |C|`. Шеннон дав вичерпну характеристику таких систем.

**Теорема 3 (Критерій досконалої таємниці за Шенноном).** Нехай маємо криптосистему `(Enc, Dec)`, у якій `|K| = |M| = |C|` та `P(M = m) > 0` для всіх `m ∈ M`. Ця система є досконало таємною тоді й тільки тоді, коли одночасно виконані дві умови:

1. **Рівноймовірність ключів:** кожен ключ `k ∈ K` обирається з однаковою ймовірністю:
   ```
   P(K = k) = 1 / |K|
   ```
2. **Алгебраїчна регулярність (латинський квадрат):** для будь-якої пари повідомлення `m ∈ M` та шифротексту `c ∈ C` існує **рівно один** унікальний ключ `k ∈ K`, такий що `Enc(k, m) = c`.

**Доведення достатності (з 1 та 2 випливає досконала таємність):**

Нехай виконані умови 1 та 2. Зафіксуємо довільне повідомлення `m ∈ M` та довільний шифротекст `c ∈ C`.

За умовою 2 існує рівно один ключ `k* ∈ K`, для якого `Enc(k*, m) = c`. Отже, подія `C = c` за умови `M = m` настає тоді й тільки тоді, коли було обрано саме ключ `k*`:

```
P(C = c | M = m) = P(K = k*)   [єдиність ключа, що переводить m у c]
```

За умовою 1 всі ключі мають ймовірність `1 / |K|`:

```
P(C = c | M = m) = 1 / |K|     [рівномірний розподіл простору ключів]
```

Оскільки права частина `1 / |K|` є сталою величиною і абсолютно не залежить від вибору `m`, умова (3) Теореми 1 виконана: `P(C = c | M = m)` є однаковою для всіх `m ∈ M`. Згідно з Теоремою 1, це доводить досконалу таємність криптосистеми.

**Доведення необхідності (з досконалої таємниці випливають 1 та 2):**

Нехай система є досконало таємною і `|K| = |M| = |C|`.

Зафіксуємо шифротекст `c ∈ C` з `P(C = c) > 0`. Як показано в доведенні Теореми 2, множина `S_c = { Dec(k, c) | k ∈ K }` повинна містити **всі** елементи `M`, інакше для відсутнього елемента апостеріорна ймовірність впаде до нуля. Тобто `S_c = M`, а отже `|S_c| = |M|`.

Оскільки `|S_c| = |M|` та `|M| = |K|`, відображення `k ↦ Dec(k, c)` є бієкцією між `K` та `M`. Це означає, що для кожного `m ∈ M` існує **рівно один** ключ `k ∈ K`, такий що `Enc(k, m) = c`. Це доводить умову 2.

Позначимо цей єдиний ключ як `k_{m,c}`. Оскільки шифрування досконало таємне, за Теоремою 1 маємо `P(C = c | M = m) = P(C = c)`. Але `P(C = c | M = m) = P(K = k_{m,c})`. Отже:

```
P(K = k_{m,c}) = P(C = c)    [для всіх m ∈ M за досконалою таємністю]
```

Оскільки при пробіганні `m` по всій множині `M` ключ `k_{m,c}` пробігає всю множину `K`, це означає, що кожен ключ `k ∈ K` має одну й ту саму ймовірність, рівну `P(C = c)`.

Оскільки сума ймовірностей усіх ключів дорівнює 1:

```
∑ P(K = k)
= |K| · P(C = c)   [сума |K| однакових доданків]
= 1                [нормалізація розподілу ймовірностей]
```

Звідси маємо `P(K = k) = 1 / |K|`. Це доводить умову 1. Теорему повністю доведено.

Таблиця шифрування для такої системи утворює в комбінаториці **латинський квадрат**: якщо розмістити повідомлення по рядках, а ключі по стовпцях, то в кожному рядку і в кожному стовпці кожен шифротекст зустрічається рівно один раз. З алгебраїчної точки зору це еквівалентно тому, що операція шифрування задає таблицю Келі для скінченної **квазігрупи** (*quasigroup*) або лупи з однозначним правилом ділення зліва та справа.

### 5. Чому нерівномірний ключ руйнує таємність

Покажемо строго, що умова рівноймовірності ключів `P(K = k) = 1 / |K|` є не просто математичною формальністю, а абсолютно необхідною умовою.

Припустимо, що криптосистема має `|K| = |M| = 2`, де `M = {m₀, m₁}` та `K = {k₀, k₁}` з операцією додавання за модулем 2 (`XOR`):
- `Enc(k₀, m₀) = c₀`, `Enc(k₁, m₀) = c₁`
- `Enc(k₀, m₁) = c₁`, `Enc(k₁, m₁) = c₀`

Нехай повідомлення мають рівні апріорні ймовірності: `P(M = m₀) = 0.5`, `P(M = m₁) = 0.5`.

Але припустимо, що генератор ключів має апаратний зсув (неідеальне джерело шуму) і генерує ключ `k₀` з імовірністю `0.80`, а ключ `k₁` — з імовірністю `0.20`.

Обчислимо умовні ймовірності появи шифротексту `c₀`:
1. При відправленні `m₀` шифротекст `c₀` виникає при виборі ключа `k₀`:
   ```
   P(C = c₀ | M = m₀) = P(K = k₀) = 0.80
   ```
2. При відправленні `m₁` шифротекст `c₀` виникає при виборі ключа `k₁`:
   ```
   P(C = c₀ | M = m₁) = P(K = k₁) = 0.20
   ```

Оскільки `P(C = c₀ | M = m₀) ≠ P(C = c₀ | M = m₁)`, умова (3) Теореми 1 грубо порушена.

Обчислимо повну ймовірність `P(C = c₀)`:

```
P(C = c₀)
= P(M = m₀) · P(C = c₀ | M = m₀) + P(M = m₁) · P(C = c₀ | M = m₁)   [формула повної ймовірності]
= 0.50 · 0.80 + 0.50 · 0.20                                        [підстановка значень]
= 0.40 + 0.10                                                       [обчислення добутків]
= 0.50                                                              [підсумок]
```

Тепер обчислимо апостеріорну ймовірність за формулою Байєса:

```
P(M = m₀ | C = c₀)
= (P(C = c₀ | M = m₀) · P(M = m₀)) / P(C = c₀)   [формула Байєса]
= (0.80 · 0.50) / 0.50                           [підстановка ймовірностей]
= 0.40 / 0.50                                    [обчислення чисельника]
= 0.80                                           [кінцевий результат]
```

Апріорна ймовірність `P(M = m₀)` дорівнювала `0.50`. Після спостереження шифротексту `c₀` апостеріорна ймовірність стрибнула до `0.80`! Супротивник тепер із 80% впевненістю знає, що передавалося саме повідомлення `m₀`.

Найменший зсув у генераторі випадкових бітів миттєво відкриває канал витоку інформації.

### 6. Ентропійне формулювання та нерівність H(K) ≥ H(M)

Шеннон виразив властивість досконалої таємниці також на мові своєї новоствореної теорії інформації.

Нагадаємо означення: **ентропія Шеннона** дискретної випадкової величини `X` (позначається `H(X)`) вимірює середню кількість невизначеності (у бітах) і обчислюється як:

```
H(X) = - ∑ P(x) · log₂ P(x)    [сума по всіх можливих значеннях x]
```

**Умовна ентропія** `H(X | Y)` вимірює невизначеність величини `X`, яка залишається після того, як стало відомо значення величини `Y`:

```
H(X | Y) = ∑ P(y) · H(X | Y = y) = - ∑∑ P(x, y) · log₂ P(x | y)
```

**Взаємна інформація** `I(X; Y)` показує, скільки інформації одна випадкова величина несе про іншу:

```
I(X; Y) = H(X) - H(X | Y)
```

**Теорема 4 (Ентропійний критерій досконалої таємниці).** Криптосистема має досконалу таємність тоді й тільки тоді, коли взаємна інформація між відкритим текстом і шифротекстом дорівнює нулю:

```
I(M; C) = 0  ⟺  H(M | C) = H(M)
```

**Доведення:**

Розпишемо умовну ентропію `H(M | C)` за означенням:

```
H(M | C)
= - ∑∑ P(m, c) · log₂ P(m | c)          [за означенням умовної ентропії]
= - ∑∑ P(c) · P(m | c) · log₂ P(m | c)   [розклад спільної ймовірності P(m, c)]
= - ∑ P(c) · (∑ P(m | c) · log₂ P(m | c)) [групування суми за значеннями c]
```

Якщо система має досконалу таємність, то за Теоремою 1 виконується `P(m | c) = P(m)`. Підставимо це в суму:

```
H(M | C)
= - ∑ P(c) · (∑ P(m) · log₂ P(m))     [заміна P(m | c) на P(m)]
= - (∑ P(c)) · (∑ P(m) · log₂ P(m))   [винесення суми по m за межі суми по c]
= - 1 · (∑ P(m) · log₂ P(m))          [оскільки сума P(c) по всіх c дорівнює 1]
= H(M)                                [отримали точне означення ентропії H(M)]
```

Отже, `H(M | C) = H(M)`, що еквівалентно `I(M; C) = H(M) - H(M | C) = 0`. Обернене доведення спирається на те, що `I(M; C) = 0` настає тоді й тільки тоді, коли `M` та `C` статистично незалежні, що еквівалентно `P(m | c) = P(m)`.

**Теорема 5 (Ентропійна нерівність для ключа).** Для будь-якої криптосистеми з досконалою таємністю ентропія ключа не може бути меншою за ентропію повідомлення:

```
H(K) ≥ H(M)
```

**Доведення:**

Розглянемо спільну ентропію трьох випадкових величин `H(M, K, C)`. Оскільки шифротекст `C = Enc(K, M)` повністю детермінований парою `(M, K)`, він не додає нової невизначеності:

```
H(M, K, C) = H(M, K)   [детермінованість функції Enc]
```

Оскільки повідомлення `M` і ключ `K` обираються незалежно, їхня спільна ентропія дорівнює сумі окремих ентропій:

```
H(M, K) = H(M) + H(K)   [статистична незалежність M та K]
```

З іншого боку, розпишемо `H(M, K, C)` через ланцюгове правило ентропії в іншому порядку:

```
H(M, K, C) = H(C) + H(K | C) + H(M | K, C)   [ланцюгове правило ентропії]
```

Оскільки відкритий текст `M` однозначно відновлюється за шифротекстом і ключем `M = Dec(K, C)`, залишкової невизначеності немає: `H(M | K, C) = 0`. Отже:

```
H(M, K, C) = H(C) + H(K | C)   [оскільки H(M | K, C) = 0]
```

Прирівняємо обидва вирази для `H(M, K, C)`:

```
H(M) + H(K) = H(C) + H(K | C)   [прирівняння двох розкладів H(M, K, C)]
```

Розглянемо умовну ентропію `H(K | C)`:

```
H(K | C)
= H(M, K | C) - H(M | K, C)    [ланцюгове правило для умовної ентропії]
= H(M | C) + H(K | M, C) - 0    [розклад через M | C та підстановка H(M | K, C) = 0]
≥ H(M | C)                      [оскільки умовна ентропія H(K | M, C) ≥ 0]
= H(M)                          [через досконалу таємність H(M | C) = H(M)]
```

Ми отримали фундаментальний результат:

```
H(K | C) ≥ H(M)
```

Це означає: навіть коли супротивник перехопив шифротекст `c`, невизначеність ключа `H(K | C)` залишається не меншою за повну інформативність повідомлення `H(M)`.

Оскільки безумовна ентропія завжди не менша за умовну (`H(K) ≥ H(K | C)`):

```
H(K) ≥ H(K | C) ≥ H(M)   [властивість зменшення ентропії при кондиціюванні]
```

Звідси остаточно випливає нерівність Шеннона:

```
H(K) ≥ H(M)
```

### 7. Мін-ентропія та екстрактори випадковості

У реальних фізичних генераторах випадкових чисел (TRNG) джерело шуму рідко дає ідеально рівномірний розподіл. Для криптографічної оцінки слабких джерел випадковості замість Шеннонової ентропії використовують **мін-ентропію Реньї** (*min-entropy*):

```
H_∞(K) = - log₂ (max_{k} P(K = k))
```

Мін-ентропія вимірює найгірший випадок: наскільки передбачуваним є найбільш ймовірний ключ. Якщо `H_∞(K) = k_min`, то ймовірність вгадати ключ із першої спроби становить `2^{-k_min}`. Для ідеально рівномірного розподілу на множині потужністю `|K| = 2^N` мін-ентропія досягає свого абсолютного максимуму: `H_∞(K) = H(K) = N` бітів.

Згідно з **лемою про залишкове хешування** (*Leftover Hash Lemma*), щоб отримати `N` майже ідеально рівномірних бітів для одноразового блокнота з неідеального фізичного джерела з мін-ентропією `k_min`, необхідно пропустити сирі байти через універсальне сімейство хеш-функцій (екстрактор випадковості), де довжина виходу задовольняє:

```
N ≤ k_min - 2 · log₂(1 / ε)
```

де `ε` — допустиме статистичне відхилення отриманого ключа від ідеально рівномірного розподілу. Це математично пов'язує фізичну мін-ентропію апаратних датчиків із строгою рівномірністю Шеннонового ключового простору.
