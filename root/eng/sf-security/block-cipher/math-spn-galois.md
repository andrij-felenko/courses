# 🧮 Алгебраїчна побудова S-Box та MDS-дифузії в AES

Цей математичний аналіз розкриває алгебраїчні засади проектування шифру AES (Rijndael): побудову нелінійного S-Box над скінченним полем Галуа `GF(2⁸)`, криптографічні метрики стійкості та властивості матриць максимального розділення відстані (MDS) у шарі дифузії.

## Арифметика скінченного поля `GF(2⁸)`

Блоковий шифр AES оперує байтами як елементами поля Галуа `GF(2⁸) = GF(2)[x] / ⟨m(x)⟩`. Кожен 8-бітний байт `b₇b₆b₅b₄b₃b₂b₁b₀` розглядається як многочлен степеня не вище 7 над полем `GF(2) = {0, 1}`:

```
b(x) = b₇·x⁷ + b₆·x⁶ + b₅·x⁵ + b₄·x⁴ + b₃·x³ + b₂·x² + b₁·x + b₀
```

Многочленом редукції обрано незвідний двійковий многочлен степеня 8 (поліном поля):

```
m(x) = x⁸ + x⁴ + x³ + x + 1    [у шістнадцятковому записі: 0x11B]
```

### Додавання в `GF(2⁸)`
Додавання двох многочленів є побітовим додаванням їхніх коефіцієнтів за модулем 2, що на рівні процесора відповідає одній операції XOR (`⊕`):

```
a(x) + b(x) = ∑ (aᵢ ⊕ bᵢ)·xⁱ
```

### Множення в `GF(2⁸)`
Множення елементів `a(x)` та `b(x)` виконується як класичне множення многочленів із наступним взяттям залишку від ділення на незвідний многочлен `m(x)`:

```
d(x) = (a(x) · b(x)) mod m(x)
```

Базовою операцією множення є множення на `x` (елемент `{02}`), яке в алгоритмічному вигляді називається `xtrapolate` або `xtime`. Якщо старший біт `b₇ = 0`, результат дорівнює простому зсуву ліворуч `(a << 1)`. Якщо `b₇ = 1`, після зсуву віднімається (через XOR) поліном `m(x)` без старшого біта `x⁸` (тобто маска `0x1B`):

```
xtime(a) = (a << 1) ⊕ ((a & 0x80) ? 0x1B : 0x00)
```

## Будова AES S-Box: Мультиплікативна інверсія та афінне перетворення

Шар `SubBytes` виконує нелінійну заміну кожного байта за правилом:

```
S(a) = Affine(a⁻¹)
```

де перетворення складається з двох послідовних кроків.

### Крок 1: Мультиплікативна інверсія в `GF(2⁸)`
Для ненульового елемента `a ∈ GF(2⁸)` обчислюється його мультиплікативний обернений елемент `a⁻¹`, такий що:

```
a · a⁻¹ ≡ 1 mod m(x)
```

За теоремою Лагранжа та малою теоремою Ферма для мультиплікативної групи поля порядку `2⁸ - 1 = 255`, обернений елемент можна обчислити піднесенням до степеня:

```
a⁻¹ = a²⁵⁴ = a² · a⁴ · a⁸ · a¹⁶ · a³² · a⁶⁴ · a¹²⁸
```

Для нульового елемента інверсія за домовленістю дорівнює нулю: `0⁻¹ = 0`.

Мультиплікативна інверсія над полем `GF(2ⁿ)` має теоретично мінімальну різницеву однорідність і захищає шифр від диференціального криптоаналізу. Проте сама по собі функція `f(a) = a⁻¹` є надто простою алгебраїчно, що відкриває шлях для інтерполяційних атак (відновлення функції у вигляді полінома малого степеня над полем).

### Крок 2: Афінне перетворення над `GF(2)`
Щоб зруйнувати просту алгебраїчну структуру інверсії над полем, вектор бітів оберненого байта `b = a⁻¹ = (b₀, b₁, b₂, b₃, b₄, b₅, b₆, b₇)ᵀ` множиться на фіксовану матрицю над `GF(2)` та додається константний вектор:

```
s = M · b ⊕ c
```

де константа `c = 0x63 = (1, 1, 0, 0, 0, 1, 1, 0)ᵀ`, а матриця `M` розміру 8×8 є циркулянтною:

```
[ s₀ ]   [ 1 0 0 0 1 1 1 1 ] [ b₀ ]   [ 1 ]
[ s₁ ]   [ 1 1 0 0 0 1 1 1 ] [ b₁ ]   [ 1 ]
[ s₂ ]   [ 1 1 1 0 0 0 1 1 ] [ b₂ ]   [ 0 ]
[ s₃ ] = [ 1 1 1 1 0 0 0 1 ] [ b₃ ] ⊕ [ 0 ]
[ s₄ ]   [ 1 1 1 1 1 0 0 0 ] [ b₄ ]   [ 0 ]
[ s₅ ]   [ 0 1 1 1 1 1 0 0 ] [ b₅ ]   [ 1 ]
[ s₆ ]   [ 0 0 1 1 1 1 1 0 ] [ b₆ ]   [ 1 ]
[ s₇ ]   [ 0 0 0 1 1 1 1 1 ] [ b₇ ]   [ 0 ]
```

Кожен вихідний біт `sᵢ` обчислюється як:

```
sᵢ = bᵢ ⊕ b_((i+4) mod 8) ⊕ b_((i+5) mod 8) ⊕ b_((i+6) mod 8) ⊕ b_((i+7) mod 8) ⊕ cᵢ
```

## Криптографічні критерії стійкості S-Box

Конструкція S-Box Rijndael задовольняє найжорсткіші критерії сучасної криптографії:

1. **Максимальна нелінійність (Nonlinearity):**
   Відстань Уолша-Адамара від будь-якої булевої лінійної комбінації вихідних бітів до множини всіх афінних функцій становить `NL = 112`, що є максимально можливим значенням для оборотних відображень розміру 8×8 (за винятком теоретичного класу функцій, які не мають ефективної оберненості).
2. **Мінімальна різницева ймовірність (Differential Uniformity):**
   Для будь-якої ненульової вхідної різниці `Δx ∈ GF(2⁸)` та довільної вихідної різниці `Δy ∈ GF(2⁸)` рівняння `S(x ⊕ Δx) ⊕ S(x) = Δy` має не більше 4 коренів:
   
   ```
   DP_max = max_(Δx ≠ 0, Δy) |{x : S(x ⊕ Δx) ⊕ S(x) = Δy}| / 256 = 4 / 256 = 2⁻⁶
   ```
3. **Мінімальна лінійна ймовірність (Linear Uniformity):**
   Кореляція між будь-якою лінійною комбінацією вхідних бітів `α · x` та вихідних бітів `β · S(x)` обмежена:
   
   ```
   LP_max = max_(α, β ≠ 0) ( (2 · |{x : α·x = β·S(x)}| - 256) / 256 )² = (32 / 256)² = 2⁻⁶
   ```
4. **Відсутність нерухомих точок (Fixed Points):**
   Для всіх `x ∈ GF(2⁸)` виконується `S(x) ≠ x` (жоден байт не переходить сам у себе).
5. **Відсутність інверсних нерухомих точок (Opposite Fixed Points):**
   Для всіх `x ∈ GF(2⁸)` виконується `S(x) ≠ x ⊕ 0xFF` (жоден байт не переходить у своє порозрядне доповнення).

## Лінійний шар `MixColumns` та MDS-матриці

Шар `MixColumns` забезпечує перемішування всередині кожного 4-байтового стовпчика матриці стану `(s₀, s₁, s₂, s₃)ᵀ`. Стовпчик розглядається як многочлен степеня не вище 3 над полем `GF(2⁸)`:

```
s(y) = s₃·y³ + s₂·y² + s₁·y + s₀
```

Операція полягає у множенні многочлена `s(y)` на фіксований многочлен `c(y)` за модулем `y⁴ + 1`:

```
r(y) = c(y) · s(y) mod (y⁴ + 1)
```

де многочлен `c(y)` має вигляд:

```
c(y) = {03}·y³ + {01}·y² + {01}·y + {02}
```

У матричному вигляді для стовпчика це записується як:

```
[ r₀ ]   [ 02  03  01  01 ] [ s₀ ]
[ r₁ ] = [ 01  02  03  01 ] [ s₁ ]
[ r₂ ]   [ 01  01  02  03 ] [ s₂ ]
[ r₃ ]   [ 03  01  01  02 ] [ s₃ ]
```

де всі коефіцієнти `{01}, {02}, {03}` є константами поля `GF(2⁸)`.

### Властивість MDS (Maximum Distance Separable)
Матриця `M` розміру `4×4` над полем `GF(2⁸)` називається MDS-матрицею, якщо код, породжений матрицею `[I₄ | M]`, є кодом з максимально можливою мінімальною відстанню за межею Сінглтона:

```
d_min = (n + k) - k + 1 = 4 + 4 - 4 + 1 = 5
```

Для довільного ненульового вхідного вектора `v` та відповідного вихідного вектора `u = M·v` сума ваг Геммінга на рівні байтів (кількість ненульових байтів `wt(v)`) задовольняє властивість показника розгалуження (Branch Number `B`):

```
B = min_(v ≠ 0) (wt(v) + wt(M·v)) = 5
```

**Доведення наслідку дифузії:**
Якщо на вході `MixColumns` змінено рівно один байт (`wt(v) = 1`), то на виході кількість змінених байтів `wt(M·v)` зобов'язана бути:

```
wt(M·v) ≥ 5 - wt(v) = 5 - 1 = 4
```

Тобто зміна навіть одного біта в одному байті стовпчика гарантовано призводить до зміни всіх 4 байтів цього стовпчика після `MixColumns`.

## Стратегія широкого сліду (Wide Trail Strategy)

Опір AES лінійному та диференціальному криптоаналізу ґрунтується на комбінації `SubBytes`, `ShiftRows` та `MixColumns`.

- Один раунд AES: зміна 1 байта розсіюється на 4 байти стовпчика за рахунок `MixColumns`.
- Два раунди AES: операція `ShiftRows` розносить ці 4 байти в чотири різні стовпчики. У другому раунді `MixColumns` розсіює кожен із 4 байтів на всі 4 байти відповідного стовпчика, активуючи всі 16 байтів матриці стану.

Криптографічна теорема Wide Trail стверджує:
**Будь-який 4-раундовий диференціальний або лінійний слід у AES містить щонайменше 25 активних S-боксів.**

Звідси розраховується верхня межа ймовірності найкращої 4-раундової диференціальної характеристики:

```
P_diff ≤ (DP_max)²⁵ = (2⁻⁶)²⁵ = 2⁻¹⁵⁰
```

Оскільки `2⁻¹⁵⁰ < 2⁻¹²⁸`, навіть для 10-раундового AES-128 не існує жодної теоретично придатної диференціальної або лінійної характеристики для розрізнення шифру від випадкової перестановки, що гарантує математичну стійкість алгоритму проти статистичного криптоаналізу.
