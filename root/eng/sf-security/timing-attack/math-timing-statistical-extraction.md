# 🧮 Статистичні критерії виявлення часових витоків

Математичний аналіз часових побічних каналів дозволяє кількісно оцінити витік секретної інформації та розрахувати мінімальну кількість спостережень, необхідну для відновлення криптографічного ключа в умовах зашумленого фізичного чи мережевого середовища. Цей математичний розділ формалізує модель часових вимірювань, критерії перевірки статистичних гіпотез (t-тест Велча, тест Колмогорова-Смірнова), ентропійну оцінку витоку та алгоритми нелінійної фільтрації мережевого джитеру.

## Математична модель вимірювань та джерела шуму

Нехай цільова криптографічна система виконує операцію обробки або верифікації, тривалість якої залежить від секретного вектора `k` (ключа, токена чи пароля) та відкритого повідомлення `m`. Фізичний час виконання `T` є неперервною випадковою величиною, яку можна розкласти на детерміновану та стохастичну компоненти:

```
T(m, k) = T_det(m, k) + ε_cpu + ε_net
```

У цій моделі складові мають чіткий фізичний зміст:
- `T_det(m, k)` — істинний детермінований час виконання алгоритму на процесорі за відсутності збурень, що визначається сумою тактів виконаних інструкцій та станом підсистеми пам'яті;
- `ε_cpu` — стохастичний шум центрального процесора, викликаний перериваннями операційної системи (IRQ), перемиканням контексту потоків, роботою диспетчера задач (scheduler) та колізіями за ресурси спільного кешу в архітектурах одночасної багатопоточності (SMT / Hyper-Threading);
- `ε_net` — стохастичний мережевий шум, зумовлений варіаціями черг комутаторів, джитером буферів маршрутизаторів та затримками середовища передачі.

За центральною граничною теоремою, сумарний шум `ε = ε_cpu + ε_net` для великої кількості проміжних вузлів наближається до нормального розподілу з нульовим математичним сподіванням та сумарною дисперсією:

```
ε ~ N(0, σ²)
```

Де `σ² = σ_cpu² + σ_net²` — сумарна дисперсія вимірювального каналу.

Якщо криптографічний алгоритм містить часовий витік (наприклад, перевірка чергового байта додає фіксовану апаратну затримку `Δμ`), то для правильного значення кандидата `k_true` та довільного хибного значення `k_false` функції розподілу ймовірностей часу відрізняються зсувом математичного сподівання:

```
T_true  ~ N(μ₀ + Δμ, σ²)
T_false ~ N(μ₀,      σ²)
```

Величина `Δμ` є корисним сигналом витоку, а `σ` — середньоквадратичним відхиленням навколишнього шуму.

## Співвідношення сигнал/шум та вибіркова складність атаки

Співвідношення сигнал/шум (англ. *Signal-to-Noise Ratio*, SNR) для часового каналу визначається як відношення квадрата амплітуди корисного сигналу до дисперсії шуму:

```
SNR = (Δμ)² / σ²
```

Щоб атакуючий міг однозначно відрізнити правильний кандидат ключа від хибних з імовірністю помилки першого роду, меншою за заданий рівень значущості `α` (наприклад, `α = 0.001`), необхідно провести серію з `N` незалежних вимірювань для кожного значення-кандидата.

Вибіркове середнє `T̄` для вибірки розміром `N` має власний нормальний розподіл зі зменшеною в `N` разів дисперсією:

```
T̄_true  ~ N(μ₀ + Δμ, σ² / N)
T̄_false ~ N(μ₀,      σ² / N)
```

Для розділення двох нормальних розподілів необхідно, щоб відстань між їхніми центрами `Δμ` перевищувала ширину довірчих інтервалів на рівні надійності `Z_(1 - α/2)` (відповідний квантиль стандартного нормального розподілу):

```
Δμ ≥ 2 · Z_(1 - α/2) · √( (σ² / N) + (σ² / N) )
Δμ ≥ 2 · Z_(1 - α/2) · σ · √(2 / N)
```

Виведення формули мінімального обсягу вибірки `N`:

```
Δμ ≥ 2 · Z_(1 - α/2) · σ · √(2 / N)      [початкова умова розділення розподілів]
(Δμ)² ≥ 4 · (Z_(1 - α/2))² · σ² · (2 / N) [піднесення обох частин до квадрата]
(Δμ)² ≥ 8 · (Z_(1 - α/2))² · (σ² / N)     [арифметичне спрощення: 4 · 2 = 8]
N · (Δμ)² ≥ 8 · (Z_(1 - α/2))² · σ²       [множення обох частин на N]
N ≥ 8 · (Z_(1 - α/2))² · (σ / Δμ)²        [ділення на квадрат корисного сигналу (Δμ)²]
```

Для рівня довіри 99.9% стандартний квантиль дорівнює `Z = 3.29`, звідки константа становить:

```
8 · (3.29)² ≈ 8 · 10.8241 ≈ 86.6
```

Таким чином, фундаментальна вибіркова складність вимагає:

```
N ≥ 86.6 · (σ / Δμ)²
```

Ця формула математично доводить ключовий висновок: шум ніколи не усуває часовий витік, а лише лінійно збільшує кількість вимірювань, необхідних для його подолання. Збільшення амплітуди шуму в 10 разів вимагає в 100 разів більше вимірювань, але не робить систему абсолютно безпечною.

## Критерій Велча для перевірки статистичних гіпотез (TVLA)

У сучасній сертифікації криптографічних модулів (за стандартом ISO/IEC 17825 та методологією NIST TVLA — Test Vector Leakage Assessment) наявність побічного каналу перевіряється за допомогою t-тесту Велча (Welch's t-test) для двох незалежних вибірок із нерівними дисперсіями.

Нехай зібрано дві вибірки часових вимірювань:
- Вибірка `A` (розмір `N_A`, вибіркове середнє `x̄_A`, вибіркова незсунена дисперсія `s²_A`) для тестової множини запитів (фіксований перший байт);
- Вибірка `B` (розмір `N_B`, вибіркове середнє `x̄_B`, вибіркова незсунена дисперсія `s²_B`) для контрольної множини запитів (випадковий перший байт).

Статистичний критерій `t` обчислюється як:

```
t = (x̄_A - x̄_B) / √( (s²_A / N_A) + (s²_B / N_B) )
```

Ефективне число ступенів вільності `ν` розраховується за формулою Велча-Саттервейта:

```
ν = [ (s²_A / N_A) + (s²_B / N_B) ]² / [ (s²_A / N_A)² / (N_A - 1) + (s²_B / N_B)² / (N_B - 1) ]
```

Критерій прийняття рішення у методології TVLA:
- Якщо обчислене значення `|t| > 4.5`, нульова гіпотеза `H₀` про ідентичність розподілів часу відхиляється з імовірністю помилки менше `p < 10⁻⁵` (надійність виявлення витоку становить 99.999%).
- Перевищення порогу `4.5` є суворим математичним доказом наявності експлуатованого побічного каналу у реалізації алгоритму.

## Нелінійна фільтрація мережевого шуму: метод мінімальних квантилів

Мережевий джитер `ε_net` має виражену асиметрію. Закони фізики накладають жорстке нижнє обмеження: пакет не може пройти мережевий шлях швидше за швидкість світла у провіднику та мінімальну апаратну затримку комутації. Водночас верхньої межі затримки практично не існує через можливі повторні передачі (TCP Retransmission), колізії та буферизацію.

Розподіл часу мережевої доставки описується розподілом з довгим правим хвостом (логарифмічно нормальним або розподілом Вейбулла). За таких умов вибіркове середнє `x̄` зміщується під впливом рідкісних, але великих затримок, що штучно завищує дисперсію `σ²`.

Для ефективного придушення асиметричного шуму застосовується оцінка за мінімальними квантилями (наприклад, 5-й або 10-й процентиль):

```
Q_p(T) = inf { t : F_T(t) ≥ p }
```

Де `F_T(t)` — емпірична функція розподілу часу відповідей, а `p = 0.05` (5% найшвидших пакетів).

Оскільки 5% найшвидших запитів проходять мережевий маршрут за майже ідеальних умов (порожні черги комутаторів, відсутність повторних передач), їхня часова дисперсія наближається до чистого апаратного шуму процесора `σ_cpu²`. Застосування квантильної фільтрації замість арифметичного середнього дозволяє зменшити ефективний шум у 20–50 разів, що скорочує необхідну кількість мережевих запитів для зламу з мільйонів до кількох тисяч.

## Оцінка витоку через взаємну інформацію Шеннона

Кількість інформації про секретний ключ `K`, що витікає через спостереження часової змінної `T`, строго визначається взаємною інформацією Шеннона `I(K; T)`:

```
I(K; T) = H(K) - H(K | T)
```

Де `H(K)` — апріорна ентропія секретного ключа, а `H(K | T)` — умовна ентропія ключа після отримання часового розподілу:

```
H(K | T) = - ∑_k P(k) ∫ p(t | k) · log₂ P(k | t) dt
```

Для системи з ідеальним постійним часом виконання розподіл часу не залежить від ключа: `p(t | k) = p(t)` для всіх значень `k`. Тоді:

```
I(K; T) = H(K) - H(K) = 0 бітів
```

Рівність взаємної інформації нулю `I(K; T) = 0` є вичерпним математичним критерієм абсолютної безпеки системи відкритого коду проти атак за часом.
