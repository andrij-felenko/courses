# 🧮 Доведення досконалої таємності та лінійність інтерполяції Лагранжа

Строге математичне обґрунтування порогової схеми Шаміра спирається на дві фундаментальні теореми абстрактної алгебри та теорії інформації: існування та єдиність інтерполяційного полінома над скінченним полем `GF(p)` та інформаційно-теоретичну досконалу таємність Клода Шеннона (нульову взаємну інформацію між частками та секретом).

Це дослідження розгортає повні алгебраїчні доведення того, чому володіння `k - 1` частками залишає секрет абсолютно невідомим, виводить формули відновлення секрету, аналізує детермінант матриці Вандермонда та вивчає гомоморфні властивості схеми.

---

### 1. Алгебраїчні структури та властивості поля GF(p)

Побудова порогової схеми Шаміра вимагає, щоб усі арифметичні операції проводилися над скінченним полем лишків `GF(p)` (де `p` — просте число). Поле `GF(p)` — це множина цілих чисел `{0, 1, 2, ..., p - 1}` разом із двома бінарними операціями: додаванням `+` та множенням `·` за модулем `p`.

Для того щоб поліноміальна інтерполяція працювала однозначно, алгебраїчна структура повинна задовольняти дев'ять аксіом поля:

1. **Замкненість:** Для будь-яких `a, b ∈ GF(p)` значення `(a + b) mod p ∈ GF(p)` та `(a · b) mod p ∈ GF(p)`.
2. **Асоціативність:** `(a + b) + c = a + (b + c)` та `(a · b) · c = a · (b · c)`.
3. **Комутативність:** `a + b = b + a` та `a · b = b · a`.
4. **Нейтральні елементи:** Існує `0` для додавання (`a + 0 = a`) та `1` для множення (`a · 1 = a`).
5. **Обернений елемент за додаванням:** Для кожного `a ∈ GF(p)` існує `-a = (p - a) mod p` таке, що `a + (-a) = 0 mod p`.
6. **Мультиплікативний обернений елемент:** Для кожного ненульового елемента `a ≠ 0 mod p` існує єдиний елемент `a⁻¹ ∈ GF(p)` такий, що:
   ```
   a · a⁻¹ ≡ 1 mod p
   ```
7. **Дистрибутивність:** `a · (b + c) = (a · b + a · c) mod p`.

Наявність мультиплікативного оберненого елемента `a⁻¹` гарантує, що у полі `GF(p)` завжди визначена операція ділення `b / a = b · a⁻¹ mod p` для всіх `a ≠ 0`. За малою теоремою Ферма, оскільки `p` — просте число, для кожного ненульового `a` виконується рівність `aᵖ⁻¹ ≡ 1 mod p`. Звідси обернений елемент обчислюється як:

```
a⁻¹ ≡ aᵖ⁻² mod p
```

### 2. Теорема про існування та єдиність полінома

Нехай `GF(p)` — скінченне поле лишків за модулем простого числа `p`. Припустимо, що нам задано `k` точок `(x₁, y₁), (x₂, y₂), ..., (xₖ, yₖ)`, де всі значення `xᵢ ∈ GF(p)` є попарно різними (`xᵢ ≠ xⱼ` при `i ≠ j`), а `yᵢ ∈ GF(p)`.

**Теорема 1.** Існує один і тільки один поліном `f(x)` степеня не вище `k - 1` із коефіцієнтами з поля `GF(p)`, який задовольняє умови `f(xᵢ) = yᵢ` для всіх `i = 1, 2, ..., k`.

#### Доведення існування через інтерполяційний поліном Лагранжа

Для кожного `i` від `1` до `k` побудуємо базисний поліном Лагранжа `ℓᵢ(x)`. Це поліном степеня `k - 1`, який дорівнює `1` у точці `x = xᵢ` та дорівнює `0` у всіх інших заданих точках `xⱼ` (при `j ≠ i`):

```
ℓᵢ(x) = ∏ (x - xⱼ) / (xᵢ - xⱼ)   [добуток за всіма j від 1 до k, де j ≠ i]
```

Оскільки всі `xᵢ` є попарно різними, різниця `(xᵢ - xⱼ) ≠ 0 mod p`. Оскільки поле `GF(p)` є полем, для кожного ненульового елемента `(xᵢ - xⱼ)` існує єдиний мультиплікативний обернений елемент `(xᵢ - xⱼ)⁻¹ mod p`. Отже, обчислення ділення у базисному поліномі завжди є коректно визначеним.

Перевіримо значення `ℓᵢ(x)` у заданих точках:

- При `x = xᵢ`: у чисельнику кожного множника стоїть `(xᵢ - xⱼ)`, що збігається зі знаменником. Добуток одиниць дорівнює `1 mod p`.
- При `x = xₘ` (де `m ≠ i`): серед множників у чисельнику обов'язково трапиться дужка `(xₘ - xₘ) = 0`, тому весь добуток дорівнює `0 mod p`.

Шуканий поліном `f(x)` будується як лінійна комбінація базисних поліномів:

```
f(x) = ∑ yᵢ · ℓᵢ(x) mod p   [сума за всіма i від 1 до k]
```

Підставивши значення `x = xₘ`, вилучаємо всі доданки з `j ≠ m`, лишаючи єдиний доданок `y☤ · 1 = y☤`. Отже, існування доведено.

#### Доведення єдиності

Припустимо, що існують два різні поліноми `f(x)` та `g(x)` степеня не вище `k - 1`, які проходять через ті самі `k` точок.

Розглянемо їхню різницю `h(x) = f(x) - g(x)`.

1. Степінь полінома `h(x)` не перевищує `k - 1`, бо це різниця двох поліномів степеня `≤ k - 1`.
2. Для кожної точки `xᵢ` маємо `h(xᵢ) = f(xᵢ) - g(xᵢ) = yᵢ - yᵢ = 0 mod p`.
3. Отже, поліном `h(x)` має щонайменше `k` різних коренів `x₁, x₂, ..., xₖ`.

За основною теоремою алгебри для поліномів над полем, ненульовий поліном степеня `d` може мати не більше ніж `d` коренів. Оскільки поліном `h(x)` степеня `≤ k - 1` має `k` коренів, він тотожно дорівнює нулю: `h(x) ≡ 0`.

Звідси `f(x) ≡ g(x)`, що доводить єдиність.

### 3. Строге доведення досконалої таємності (Шеннонівська безпека)

Схема володіє **досконалою таємністю** (інформаційно-теоретичною безпекою), якщо апостеріорний розподіл ймовірностей секрету `S` після отримання `k - 1` часток дорівнює апріорному розподілу ймовірностей. Формально через умовну ймовірність та ентропію за Шенноном:

```
P(S = S' | y₁, y₂, ..., yₖ₋₁) = P(S = S')
H(S | Y₁, ..., Yₖ₋₁) = H(S)
I(S; Y₁, ..., Yₖ₋₁) = H(S) - H(S | Y₁, ..., Yₖ₋₁) = 0
```

Це означає, що взаємна інформація `I(S; Y)` між секретом та неповним набором часток тотожно дорівнює нулю. Спостерігач, який перехопив `k - 1` часток, не отримує жодного біта інформації про секрет `S`.

#### Алгебраїчне доведення через детермінант Вандермонда

Нехай зловмисники зібрали `k - 1` часток `(x₁, y₁), (x₂, y₂), ..., (xₖ₋₁, yₖ₋₁)`.

Поліном `f(x) = a₀ + a₁ x + a₂ x² + ... + aₖ₋₁ xᵏ⁻¹ mod p` має `k` невідомих коефіцієнтів `(a₀, a₁, ..., aₖ₋₁)`. З них `a₀ = S` є секретом, а коефіцієнти `a₁, ..., aₖ₋₁` були обрані дилером незалежно та рівномірно випадково з поля `GF(p)`.

Припустимо, зловмисники висувають гіпотезу, що секрет дорівнює певному конкретному значенню `S' ∈ GF(p)`. Зафіксуємо `a₀ = S'`. Тоді наявні `k - 1` часток утворюють систему з `k - 1` лінійних рівнянь відносно `k - 1` невідомих коефіцієнтів `(a₁, a₂, ..., aₖ₋₁)`:

```
a₁·x₁   + a₂·x₁²   + ... + aₖ₋₁·x₁ᵏ⁻¹   = y₁ - S'    mod p
a₁·x₂   + a₂·x₂²   + ... + aₖ₋₁·x₂ᵏ⁻¹   = y₂ - S'    mod p
...
a₁·xₖ₋₁ + a₂·xₖ₋₁² + ... + aₖ₋₁·xₖ₋₁ᵏ⁻¹ = yₖ₋₁ - S' mod p
```

У матричному вигляді ця система має форму `V · a = y_diff`, де `V` — матриця розміру `(k-1) × (k-1)`:

```
| x₁    x₁²    ...  x₁ᵏ⁻¹   |
| x₂    x₂²    ...  x₂ᵏ⁻¹   |
| ...   ...    ...  ...     |
| xₖ₋₁  xₖ₋₁²  ...  xₖ₋₁ᵏ⁻¹ |
```

Матрицю `V` можна винести як добуток діагональної матриці індексів `diag(x₁, ..., xₖ₋₁)` на класичну матрицю Вандермонда `W`:

```
W = | 1  x₁    x₁²    ...  x₁ᵏ⁻²   |
    | 1  x₂    x₂²    ...  x₂ᵏ⁻²   |
    | ... ...  ...    ...  ...     |
    | 1  xₖ₋₁  xₖ₋₁²  ...  xₖ₋₁ᵏ⁻² |
```

Детермінант класичної матриці Вандермонда `W` обчислюється за формулою добутку всіх різниць:

```
det(W) = ∏ (xⱼ - xᵢ)   [для всіх 1 ≤ i < j ≤ k - 1]
```

Отже, детермінант видозміненої матриці `V` дорівнює:

```
det(V) = (∏ xᵢ) · ∏ (xⱼ - xᵢ)   [для всіх 1 ≤ i < j ≤ k - 1]
```

Оскільки всі `xᵢ` є ненульовими (`xᵢ ≠ 0`) та попарно різними (`xᵢ ≠ xⱼ`), детермінант `det(V) ≠ 0 mod p`.

Оскільки детермінант не дорівнює нулю в полі `GF(p)`, матриця `V` є неособливою (оборотною). Це означає, що для **будь-якого** обраного гіпотетичного значення секрету `S' ∈ GF(p)` система має **рівно один єдиний розв'язок** щодо коефіцієнтів `(a₁, ..., aₖ₋₁)`.

#### Рівноймовірність варіантів

Оскільки коефіцієнти `a₁, ..., aₖ₋₁` генератором випадкових чисел дилера вибиралися рівномірно з `GF(p)` серед усіх `pᵏ⁻¹` можливих комбінацій:

- Кожній гіпотезі `S' ∈ GF(p)` відповідає рівно 1 підхожий поліном серед `pᵏ⁻¹` можливих.
- Отже, ймовірність того, що секретом є `S'`, за умови знання `k - 1` часток, становить:

```
P(S = S' | y₁, ..., yₖ₋₁) = 1 / p
```

Оскільки ймовірність дорівнює `1 / p` для всіх без винятку `p` можливих значень `S'`, апостеріорна ймовірність збігається з рівномірним апріорним розподілом. Кількість витекшої інформації про секрет тотожно дорівнює нулю біт.

### 4. Гомоморфна адитивність схеми Шаміра

Схема Шаміра володіє важливою алгебраїчною властивістю — **адитивним гомоморфізмом**.

Нехай є два секрети `S₁` та `S₂`, розбиті за допомогою двох поліномів `f(x)` та `g(x)` одинакового степеня `k - 1` над тим самим полем `GF(p)`:

```
f(0) = S₁
g(0) = S₂
```

Нехай учасникові `i` видано частки `uᵢ = f(xᵢ)` та `vᵢ = g(xᵢ)`.

Якщо кожен учасник обчислить у себе локальну суму своїх часток `wᵢ = (uᵢ + vᵢ) mod p`, то нові значення `wᵢ` будуть коректними частками для відновлення сумарного секрету `S_sum = (S₁ + S₂) mod p`.

#### Доведення

Розглянемо сумарний поліном `h(x) = (f(x) + g(x)) mod p`.

1. Степінь полінома `h(x)` не перевищує `k - 1`, оскільки `deg(f + g) ≤ max(deg(f), deg(g)) = k - 1`.
2. Значення полінома `h(x)` у точці `x = 0` дорівнює:

```
h(0) = f(0) + g(0) = S₁ + S₂ mod p
```

3. Значення полінома `h(x)` у точках `xᵢ` дорівнюють:

```
h(xᵢ) = f(xᵢ) + g(xᵢ) = uᵢ + vᵢ = wᵢ mod p
```

Отже, будь-які `k` учасників можуть додати свої частки локально й відновити суму секретів `S₁ + S₂`, не розкриваючи при цьому ні власні початкові частки, ні самі початкові секрети `S₁` та `S₂`. Ця властивість робить схему Шаміра наріжним каменем протоколів консенсусу та безпечних багатосторонніх обчислень (MPC).

### 5. Верифіковане розділення секрету (Feldman VSS)

Для захисту від активного зловмисника або нечесного дилера Пауль Фельдман розширив схему Шаміра за допомогою гомоморфних зобов'язань у циклічній групі `G` порядку `q` з генератором `g`, де обчислення дискретного логарифма є важким.

Під час генерації полінома `f(x) = a₀ + a₁ x + ... + aₖ₋₁ xᵏ⁻¹ mod q` дилер публікує у відкритому доступі публічні зобов'язання `Cⱼ`:

```
C₀ = g^{a₀} = g^S mod p
C₁ = g^{a₁} mod p
...
Cₖ₋₁ = g^{aₖ₋₁} mod p
```

Отримавши свою приватну частку `yᵢ = f(i) mod q`, учасник `i` може перевірити її коректність без розкриття самого значення `yᵢ`, обчисливши:

```
g^{yᵢ} ≡ ∏ (Cⱼ)^{i^j} mod p   [для всіх j від 0 до k - 1]
```

Якщо рівність виконується, учасник гарантовано знає, що його частка `yᵢ` лежить на того самого поліномі степеня `k - 1`, що й зобов'язання інших учасників. Якщо ж дилер видав фальшиву частку, учасник подає публічну скаргу із математичним доказом зради.
