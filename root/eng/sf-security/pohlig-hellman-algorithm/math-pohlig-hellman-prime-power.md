# 🧮 Алгебраїчний вивід ліфтингу в підгрупах порядку pᵉ

Цей математичний аналіз містить повне строге виведення алгоритму порозрядного визначення дискретного логарифма (ліфтингу) для циклічних груп, порядок яких є степенем простого числа `pᵉ`, включаючи доведення коректності, аналіз інваріантів та розрахунок асимптотичної складності.

---

### Постановка задачі для примарної циклічної підгрупи

Нехай маємо скінченну мультиплікативну циклічну групу `H` з операцією множення. Загальна кількість елементів у цій групі (її порядок) дорівнює степеню фіксованого простого числа:

```
|H| = pᵉ
```

де `p` — просте число (наприклад, `2, 3, 5, 7, …`), а `e ≥ 1` — ціле додатне число, показник степеня.

Нехай елемент `g₀ ∈ H` є твірним елементом (генератором) групи `H`. Це означає, що мультиплікативний порядок елемента `g₀` дорівнює точно порядку всієї групи:

```
ord(g₀) = pᵉ
```

Послідовні степені елемента `g₀`, а саме `g₀⁰, g₀¹, g₀², …, g₀^{pᵉ - 1}`, є попарно різними й вичерпують усі `pᵉ` елементів підгрупи `H`. За канонічним ізоморфізмом циклічних груп, мультиплікативна група `H` ізоморфна адитивній групі кільця залишків `(Z / pᵉ Z, +)`:

```
H ≅ (Z / pᵉ Z, +)
```

Нехай у групі `H` задано деякий цільовий елемент `h₀ ∈ H`. Необхідно знайти ціле число `x` у діапазоні від `0` до `pᵉ - 1`, яке задовольняє основне рівняння дискретного логарифма:

```
g₀ˣ = h₀    у групі H
```

Якщо розв'язувати це рівняння безпосередньо загальними алгоритмами (наприклад, методом «крок немовляти — крок велетня» чи ро-методом Поларда), часова складність становитиме:

```
T_{naive} = O(√(pᵉ)) = O(p^{e/2})
```

Для великих значень показника `e` величина `p^{e/2}` швидко стає непідйомною. Наприклад, якщо `p = 2` та `e = 64`, наївний пошук вимагає `2³² ≈ 4.29 · 10⁹` операцій. А для `p = 2` та `e = 128` наївний пошук вимагає `2⁶⁴ ≈ 1.84 · 10¹⁹` операцій, що фізично неможливо виконати на одному комп'ютері за розумний час.

Алгоритм ліфтингу дозволяє знайти невідомий показник `x` за час `O(e · √p)` групових операцій, послідовно визначаючи розряди числа `x` у позиційній системі числення за основою `p`.

---

### Алгебраїчна фільтрація підгруп та фактор-групи

Щоб глибше зрозуміти внутрішню структуру ліфтингу, розглянемо ланцюг вкладених підгруп (фільтрацію) циклічної групи `H`:

```
H = G₀ ⊃ G₁ ⊃ G₂ ⊃ … ⊃ G_{e-1} ⊃ Gₑ = {1}
```

де кожна підгрупа `Gⱼ` визначається як образ множення на степінь `pʲ`:

```
Gⱼ = { y^{pʲ}  |  y ∈ H } = ⟨ g₀^{pʲ} ⟩
```

Порядок підгрупи `Gⱼ` дорівнює точно:

```
|Gⱼ| = p^{e - j}
```

Зокрема:
- `G₀ = H` має порядок `pᵉ`;
- `G_{e-1} = ⟨ g₀^{p^{e-1}} ⟩` має порядок `p¹ = p`;
- `Gₑ = {1}` — тривіальна підгрупа порядку 1.

Кожен суміжний фактор у цьому ланцюзі є циклічною групою простого порядку `p`:

```
Gⱼ / G_{j+1} ≅ (Z / p Z, +)
```

Це означає, що перехід від рівня `j` до рівня `j+1` завжди полягає у визначенні рівно одного елемента простої групи `Z_p`. Задача знаходження логарифма у групі `H` розкладається на послідовне проходження `e` простих фактор-груп розміру `p`.

### Зв'язок із лемою Гензеля та p-адичним логарифмом

Механізм порозрядного ліфтингу в алгоритмі Поліга — Геллмана є прямим дискретним аналогом **леми Гензеля** в алгебрі та теорії p-адичних чисел.

У класичній комутативній алгебрі лема Гензеля дозволяє піднімати простий корінь поліноміального рівняння `f(x) ≡ 0 (mod p)` до єдиного кореня за модулем довільного степеня `pᵉ` за допомогою лінеаризованої ітерації, подібної до методу дотичних Ньютона:

```
x_{k+1} = x_k - f(x_k) · (f'(x_k))⁻¹ mod p^{k+1}
```

У задачі дискретного логарифма ми розглядаємо експоненційне рівняння `f(x) = g₀ˣ - h₀ = 0`. Оскільки експоненційна функція володіє груповим гомоморфізмом `g₀^{a+b} = g₀ᵃ · g₀ᵇ`, диференціювання в p-адичній топології трансформується у вилучення залишків у фактор-кільцях:

```
Z / pᵉ Z  ⟶  Z / p^{e-1} Z  ⟶  …  ⟶  Z / p Z
```

На кожному кроці ліфтингу значення розряду `zⱼ` компенсує нев'язку `h_{(j)} = g₀^(x - x_{(j)})` точно так само, як поправка Ньютона компенсує залишкове значення полінома `f(x_k)` на наступному p-адичному рівні.

У p-адичному аналізі для мультиплікативної групи 1-одиниць `U₁ = 1 + p Z_p` дискретний логарифм перетворюється на звичайний аналітичний p-адичний логарифм Івасави, що задається збіжним степеневим рядом:

```
log_p(1 + p · u) = ∑_{k=1}^∞ (-1)^{k-1} · (p · u)^k / k
```

Цей глибокий зв'язок пояснює, чому алгебраїчна природа степенів простих чисел завжди допускає розв'язання за поліноміальний час від показника `e`.

### Оптимізація обчислень: модульне представлення Монтгомері

Під час послідовного ліфтингу через велику кількість розрядів `e` (наприклад, `e = 128` або `e = 256`) на кожному кроці виконуються серійні операції модульного множення на `g₀⁻¹` та піднесення до степеня `p`.

У високопродуктивних обчислювальних бібліотеках для прискорення цього циклу застосовують перетворення у форму Монтгомері (Montgomery Representation):
- Кожен елемент `a` замінюється образом `a~ = (a · R) mod p_{mod}`, де `R = 2⁶⁴` або `2²⁵⁶`.
- Модульне множення двох образів `(a~ · b~) · R⁻¹ mod p_{mod}` виконується без операцій ділення з остачею (замінюючись зсувами та додаваннями).
- Усі `e` ітерацій ліфтингу проходять у просторі Монтгомері, а зворотне перетворення `a = (a~ · R⁻¹) mod p_{mod}` виконується лише один раз наприкінці. Це скорочує константний час виконання ліфтингу у 2.5–3 рази.

### Порівняння класичного ліфтингу з квантовими алгоритмами

Цікаво зіставити класичну складність ліфтингу Поліга — Геллмана для степенів простих чисел із квантовим алгоритмом Пітера Шора.
- Алгоритм Шора знаходить період функції у будь-якій абелевій групі за квантовий час `O(e³ · log³ p)` кубічної складності за допомогою квантового перетворення Фур'є (QFT).
- Проте класичний ліфтинг Поліга — Геллмана для малих простих чисел (наприклад, `p = 2` або `p = 3`) має часову складність лише `O(e² · log p)` на звичайному класичному процесорі, взагалі не вимагаючи квантових обчислювачів чи складних кубітів!

Це показує, що для примарних підгруп малих характеристик класична алгебра забезпечує навіть вищу практичну продуктивність, ніж універсальні квантові алгоритми.

### Узагальнення на розв'язні та поліциклічні групи

Принцип розщеплення задачі вздовж ланцюга підгруп не обмежується абелевими групами. У загальній теорії груп будь-яка скінченна розв'язна група `G` володіє композиційним рядом Жордана — Гельдера:

```
1 = N₀ ⊲ N₁ ⊲ N₂ ⊲ … ⊲ N_k = G
```

де кожен композиційний фактор `N_{i+1} / N_i` є простою циклічною групою порядку `p_i`.

У поліциклічних групах довільний елемент однозначно записується у канонічному базисі Мальцева через вектор показників. Задача відшукання відносного дискретного логарифма розв'язується послідовним спуском по ряду підгруп від вершини до одиниці, де на кожному шарі застосовується проекція у відповідний простий фактор. Таким чином, техніка Поліга — Геллмана становить фундаментальну алгебраїчну парадигму для розв'язання систем рівнянь у довільних скінченних розв'язних алгебраїчних структурах.

### Позиційне представлення за основою p: p-адичний розклад

Оскільки шуканий показник `x` задовольняє нерівність `0 ≤ x < pᵉ`, його можна єдиним чином розкласти в позиційній системі числення за основою `p` з `e` розрядів:

```
x = z₀ + z₁·p + z₂·p² + … + z_{e-1}·pᵉ⁻¹ = ∑_{j=0}^{e-1} zⱼ · pʲ
```

У цьому розкладі кожна невідома величина `zⱼ` (де індекс `j` набуває значень від `0` до `e - 1`) є цілим числом у множині цифр за основою `p`:

```
zⱼ ∈ {0, 1, 2, …, p - 1}
```

**Теорема 1 (Про єдиність p-адичного розкладу).** *Для будь-якого цілого числа `x`, такого що `0 ≤ x < pᵉ`, існує єдиний набір коефіцієнтів `(z₀, z₁, …, z_{e-1})`, де кожне `zⱼ ∈ {0, 1, …, p - 1}`, такий що `x = ∑_{j=0}^{e-1} zⱼ · pʲ`.*

*Доведення.*
Існування випливає з послідовного ділення числа `x` на `p` з остачею:
- `z₀ = x mod p`, `x₁ = ⌊x / p⌋`;
- `z₁ = x₁ mod p`, `x₂ = ⌊x₁ / p⌋`;
- узагальнюючи, `zⱼ = ⌊x / pʲ⌋ mod p`.

Єдиність випливає з того, що кількість різних наборів коефіцієнтів дорівнює `p · p · … · p = pᵉ`, і кожному такому набору відповідає чітке ціле число в інтервалі `[0, pᵉ - 1]`. Оскільки розмір множини наборів дорівнює кількості чисел в інтервалі, це відображення є бієкцією.

Отже, задача знаходження одного великого невідомого числа `x` еквівалентна послідовному знаходженню `e` маленьких цифр `z₀, z₁, …, z_{e-1}`.

### Базова лема: побудова інваріантного генератора підгрупи простого порядку

Визначимо спеціальний елемент `γ` (грецька літера гамма) як результат піднесення твірного елемента `g₀` до фіксованого степеня `pᵉ⁻¹`:

```
γ = g₀^(pᵉ⁻¹)
```

**Лема 1 (Про порядок генератора γ).** *Елемент `γ` має мультиплікативний порядок рівно `p` у групі `H`, породжує єдину підгрупу порядку `p` у циклічній групі `H`, і є нейтральним елементом тоді й лише тоді, коли показник степеня ділиться націло на `p`.*

*Доведення.*
Обчислимо результат піднесення елемента `γ` до степеня `p`:

```
γᵖ
= (g₀^(pᵉ⁻¹))ᵖ      [підстановка визначення γ]
= g₀^(pᵉ⁻¹ · p)     [властивість степенів]
= g₀^(pᵉ)           [арифметика показників]
= 1                 [оскільки ord(g₀) = pᵉ за умовою]
```

Таким чином, порядок елемента `γ` ділить просте число `p`. Оскільки `p` — просте число, єдиними дільниками числа `p` є `1` та `p`.

Припустимо, що `ord(γ) = 1`. Це означало б, що `γ¹ = g₀^(pᵉ⁻¹) = 1`. Проте твірний елемент `g₀` має порядок `pᵉ`, тому його найменшим додатним степенем, рівним одиниці, є `pᵉ`. Оскільки `e ≥ 1`, маємо `pᵉ⁻¹ < pᵉ`, що суперечить рівності `g₀^(pᵉ⁻¹) = 1`.

Отже, `ord(γ) ≠ 1`, звідки однозначно випливає:

```
ord(γ) = p
```

Елемент `γ` породжує циклічну підгрупу `⟨γ⟩ = {γ⁰, γ¹, γ², …, γᵖ⁻¹}` розміру рівно `p`.

### Знаходження нульового розряду z₀

Піднесемо обидві частини вихідного рівняння `g₀ˣ = h₀` до степеня `pᵉ⁻¹`:

```
(g₀ˣ)^(pᵉ⁻¹) = h₀^(pᵉ⁻¹)
```

Розкриємо ліву частину, підставивши повний розклад `x = z₀ + z₁·p + z₂·p² + … + z_{e-1}·pᵉ⁻¹`:

```
(g₀ˣ)^(pᵉ⁻¹)
= g₀^(x · pᵉ⁻¹)                                                       [властивість степеня]
= g₀^((z₀ + z₁·p + z₂·p² + … + z_{e-1}·pᵉ⁻¹) · pᵉ⁻¹)                  [підстановка розкладу x]
= g₀^(z₀·pᵉ⁻¹ + z₁·pᵉ + z₂·pᵉ⁺¹ + … + z_{e-1}·p²ᵉ⁻²)                  [розкриття дужок]
= g₀^(z₀·pᵉ⁻¹) · g₀^(pᵉ · (z₁ + z₂·p + … + z_{e-1}·pᵉ⁻²))            [групування доданків]
= g₀^(z₀·pᵉ⁻¹) · (g₀^(pᵉ))^(z₁ + z₂·p + … + z_{e-1}·pᵉ⁻²)            [винесення степеня]
= g₀^(z₀·pᵉ⁻¹) · (1)^(z₁ + z₂·p + … + z_{e-1}·pᵉ⁻²)                 [оскільки g₀^(pᵉ) = 1]
= g₀^(z₀·pᵉ⁻¹)                                                        [множення на одиницю]
= (g₀^(pᵉ⁻¹))^z₀                                                      [перестановка степенів]
= γ^z₀                                                                [за визначенням γ]
```

Отримано ключове спрощення: усі вищі члени розкладу `z₁, z₂, …, z_{e-1}` містять множник `p` у степені, не меншому за одиницю. При множенні на `pᵉ⁻¹` їхній сумарний степінь стає не меншим за `pᵉ`, тому у групі порядку `pᵉ` вони гарантовано перетворюються на нейтральний елемент `1`.

Таким чином, для першого розряду ми отримали точне рівняння:

```
γ^z₀ = h₀^(pᵉ⁻¹)
```

У цьому рівнянні:
- основа `γ` — відомий фіксований елемент простого порядку `p`;
- права частина `h₀^(pᵉ⁻¹)` — відомий елемент підгрупи `⟨γ⟩`;
- невідома величина `z₀` — ціле число з множини `{0, 1, …, p - 1}`.

Це класична задача дискретного логарифма у групі простого порядку `p`. Значення `z₀` знаходиться за допомогою алгоритму Baby-Step Giant-Step за `O(√p)` групових операцій.

### Загальний індукційний крок: вилучення довільного розряду zⱼ

Припустимо за індукцією, що перші `j` цифр шуканого показника, а саме `z₀, z₁, …, zⱼ₋₁`, уже обчислені на попередніх кроках.

Визначимо накопичене часткове значення показника:

```
x_{(j)} = ∑_{k=0}^{j-1} z_k · p^k = z₀ + z₁·p + z₂·p² + … + zⱼ₋₁·pʲ⁻¹
```

Тоді повний невідомий показник `x` можна подати як суму відомого префікса та залишку:

```
x = x_{(j)} + pʲ · ( zⱼ + zⱼ₊₁·p + … + z_{e-1}·p^{e-1-j} )
```

Сформуємо модифікований цільовий елемент `h_{(j)}`, помноживши `h₀` на елемент, обернений до відомої частини:

```
h_{(j)} = h₀ · (g₀)^{-x_{(j)}}
```

Підставимо вираз для `h₀ = g₀ˣ`:

```
h_{(j)}
= g₀ˣ · g₀^(-x_{(j)})                                                 [підстановка h₀]
= g₀^(x - x_{(j)})                                                    [властивість степенів]
= g₀^(pʲ · (zⱼ + zⱼ₊₁·p + … + z_{e-1}·p^{e-1-j}))                    [підстановка x - x_{(j)}]
```

Тепер піднесемо модифікований елемент `h_{(j)}` до ізолюючого степеня `p^{e - 1 - j}`:

```
(h_{(j)})^(p^{e - 1 - j})
= ( g₀^(pʲ · (zⱼ + zⱼ₊₁·p + … + z_{e-1}·p^{e-1-j})) )^(p^{e - 1 - j})  [підстановка виразу h_{(j)}]
= g₀^( pʲ · p^{e - 1 - j} · (zⱼ + zⱼ₊₁·p + … + z_{e-1}·p^{e-1-j}) )   [множення показників степеня]
= g₀^( p^{e - 1} · (zⱼ + zⱼ₊₁·p + … + z_{e-1}·p^{e-1-j}) )            [спрощення pʲ · p^{e-1-j} = p^{e-1}]
= g₀^( zⱼ·p^{e - 1} + zⱼ₊₁·pᵉ + … + z_{e-1}·p^{2e - 2 - j} )          [розкриття дужок]
= g₀^( zⱼ·p^{e - 1} ) · (g₀^(pᵉ))^(zⱼ₊₁ + … + z_{e-1}·p^{e - 2 - j})  [виділення множників, кратних pᵉ]
= g₀^( zⱼ·p^{e - 1} ) · (1)^(zⱼ₊₁ + …)                                [оскільки g₀^(pᵉ) = 1]
= (g₀^(p^{e - 1}))^zⱼ                                                 [властивість степенів]
= γ^zⱼ                                                                [за визначенням γ]
```

Отримано фундаментальну рекурентну формулу для обчислення цифри `zⱼ`:

```
γ^zⱼ = ( h₀ · g₀^(-(z₀ + z₁·p + … + zⱼ₋₁·pʲ⁻¹)) )^(p^{e - 1 - j})
```

**Теорема 2 (Про коректність індуктивного ліфтингу).** *Для будь-якого кроку `j ∈ {0, 1, …, e - 1}` елемент `(h_{(j)})^(p^{e-1-j})` належить до циклічної підгрупи `⟨γ⟩`, і значення цифри `zⱼ ∈ {0, 1, …, p - 1}` визначається єдиним чином.*

*Доведення.*
Оскільки `(h_{(j)})^(p^{e-1-j}) = γ^zⱼ`, а `γ` породжує підгрупу простого порядку `p`, образ елемента гарантовано належить `⟨γ⟩`. Оскільки `zⱼ ∈ {0, 1, …, p - 1}`, а порядок `ord(γ) = p`, усі степені `γ⁰, γ¹, …, γᵖ⁻¹` попарно різні. Отже, існує єдине значення `zⱼ`, що задовольняє рівність.

### Інваріант бази: чому таблиця Baby-Step Giant-Step будується лише один раз

Головна перевага цього алгебраїчного виведення полягає в тому, що на кожному кроці `j` (від `0` до `e - 1`) **основа дискретного логарифма `γ` залишається абсолютно однаковою**:

```
γ = g₀^(p^{e - 1})    для всіх j ∈ {0, 1, …, e - 1}
```

Змінюється лише цільовий елемент у правій частині рівняння:

```
target_j = (h₀ · g₀^(-x_{(j)}))^(p^{e - 1 - j})
```

Це дозволяє оптимізувати алгоритм:
1. На початку обчислень один раз генеруємо хеш-таблицю розміру `m = ⌈√p⌉` для кроків немовляти:
   `Table = { γ^k : k  |  0 ≤ k < m }`.
2. Для кожного кроку `j` обчислюємо `target_j` і виконуємо швидкий пошук кроками велетня, використовуючи вже побудовану таблицю.
3. Додаткова пам'ять для збереження таблиці становить лише `O(√p)` елементів групи, і вона повторно використовується на всіх `e` ітераціях.

### Числовий розрахунок для двійкової групи: pᵉ = 2⁴ = 16

Продемонструємо роботу алгоритму на конкретній числовій групі.

Нехай розглядається мультиплікативна група за простим модулем `p_{mod} = 17`.
Порядок групи `|Z₁₇^*| = 17 - 1 = 16 = 2⁴`. Тут `p = 2`, `e = 4`.

Візьмемо твірний елемент `g₀ = 3`. Перевіримо його порядок:
- `3¹ = 3`
- `3² = 9`
- `3⁴ = 9² = 81 = 4 · 17 + 13 ≡ 13 ≡ -4 (mod 17)`
- `3⁸ = (-4)² = 16 ≡ -1 (mod 17)`
- `3¹⁶ = (-1)² = 1 (mod 17)`

Отже, `ord(3) = 16 = 2⁴`.

Нехай цільовий елемент `h₀ = 11`. Шукаємо показник `x ∈ {0, 1, …, 15}` такий, що:

```
3ˣ ≡ 11 (mod 17)
```

Запишемо `x` у двійковій системі числення (`p = 2`, `e = 4` розряди):

```
x = z₀ + z₁·2 + z₂·4 + z₃·8,    де кожне zⱼ ∈ {0, 1}
```

Обчислимо базовий генератор `γ`:

```
γ = g₀^(2⁴⁻¹) = 3⁸ ≡ 16 ≡ -1 (mod 17)
```

Оскільки `γ = -1`, степені `γ` мають простий вигляд: `γ⁰ = 1`, `γ¹ = -1 ≡ 16`.

Знайдемо обернений елемент до генератора: `g₀⁻¹ = 3⁻¹ mod 17 = 6` (оскільки `3 · 6 = 18 ≡ 1 mod 17`).

#### Крок 0 (знаходження z₀):
Обчислюємо ізолюючий степінь `p^{e - 1 - 0} = 2³ = 8`:

```
target₀
= 11⁸ mod 17                  [піднесення цільового елемента 11 до степеня 8]
= (11²)⁴ mod 17               [подання степеня 8 = 2 · 4]
= (121)⁴ mod 17               [обчислення 11² = 121]
= (2)⁴ mod 17                 [оскільки 121 = 7 · 17 + 2 ≡ 2 mod 17]
= 16                          [обчислення 2⁴ = 16 mod 17]
= -1                          [канонічний залишок 16 ≡ -1 mod 17]
```

Рівняння для `z₀`:

```
γ^{z₀} ≡ 16 (mod 17)  ⟹  (-1)^{z₀} ≡ -1 (mod 17)  ⟹  z₀ = 1
```

Накопичений показник: `x_{(1)} = 1`.

#### Крок 1 (знаходження z₁):
Модифікуємо цільовий елемент:

```
h_{(1)}
= (11 · 6¹) mod 17            [множення цілі на обернений елемент g₀⁻¹ = 6]
= 66 mod 17                   [множення 11 · 6 = 66]
= 15                          [оскільки 66 = 3 · 17 + 15 ≡ 15 mod 17]
= -2                          [оскільки 15 ≡ -2 mod 17]
```

Обчислюємо ізолюючий степінь `p^{e - 1 - 1} = 2² = 4`:

```
target₁
= (-2)⁴ mod 17                [піднесення h_{(1)} = -2 до степеня 4]
= 16 mod 17                   [обчислення (-2)⁴ = 16]
= -1                          [оскільки 16 ≡ -1 mod 17]
```

Рівняння для `z₁`:

```
(-1)^{z₁} ≡ -1 (mod 17)  ⟹  z₁ = 1
```

Накопичений показник: `x_{(2)} = z₀ + z₁·2 = 1 + 2 = 3`.

#### Крок 2 (знаходження z₂):
Модифікуємо цільовий елемент:

```
h_{(2)}
= (11 · 6³) mod 17            [множення цілі на (g₀⁻¹)³]
= (11 · 216) mod 17           [обчислення 6³ = 216]
= (11 · 12) mod 17            [оскільки 216 = 12 · 17 + 12 ≡ 12 mod 17]
= 132 mod 17                  [множення 11 · 12 = 132]
= 13                          [оскільки 132 = 7 · 17 + 13 ≡ 13 mod 17]
= -4                          [оскільки 13 ≡ -4 mod 17]
```

Обчислюємо ізолюючий степінь `p^{e - 1 - 2} = 2¹ = 2`:

```
target₂
= (-4)² mod 17                [піднесення h_{(2)} = -4 до степеня 2]
= 16 mod 17                   [обчислення (-4)² = 16]
= -1                          [оскільки 16 ≡ -1 mod 17]
```

Рівняння для `z₂`:

```
(-1)^{z₂} ≡ -1 (mod 17)  ⟹  z₂ = 1
```

Накопичений показник: `x_{(3)} = 1 + 2 + 1·4 = 7`.

#### Крок 3 (знаходження z₃):
Модифікуємо цільовий елемент:

```
h_{(3)}
= (11 · 6⁷) mod 17            [множення цілі на (g₀⁻¹)⁷]
= (11 · 6⁴ · 6³) mod 17       [розклад показника 7 = 4 + 3]
= (11 · 4 · 12) mod 17        [підстановка 6⁴≡4 та 6³≡12 mod 17]
= (44 · 12) mod 17            [множення 11 · 4 = 44]
= (10 · 12) mod 17            [оскільки 44 = 2 · 17 + 10 ≡ 10 mod 17]
= 120 mod 17                  [множення 10 · 12 = 120]
= 1                           [оскільки 120 = 7 · 17 + 1 ≡ 1 mod 17]
```

Обчислюємо ізолюючий степінь `p^{e - 1 - 3} = 2⁰ = 1`:

```
target₃ = (1)¹ = 1 (mod 17)
```

Рівняння для `z₃`:

```
(-1)^{z₃} ≡ 1 (mod 17)  ⟹  z₃ = 0
```

Повний показник:

```
x = z₀ + z₁·2 + z₂·4 + z₃·8 = 1 + 2 + 4 + 0 = 7
```

#### Перевірка результату:
Піднесемо основу `3` до знайденого степеня `7`:

```
3⁷ mod 17
= (3⁴ · 3³) mod 17            [розклад показника 7 = 4 + 3]
= (13 · 10) mod 17            [підстановка 3⁴≡13 та 3³≡10 mod 17]
= 130 mod 17                  [множення 13 · 10 = 130]
= 11                          [оскільки 130 = 7 · 17 + 11 ≡ 11 mod 17]
```

Результат `11` точно збігається з вихідним елементом `h₀`.

### Числовий розрахунок для непарного простого: pᵉ = 3³ = 27

Розгляньмо другий числовий випадок для непарного простого числа, де на кожному кроці розв'язується нетривіальна тризначна підзадача.

Нехай розглядається поле за простим модулем `p_{mod} = 109`.
Порядок групи `Z₁₀₉^*` дорівнює `109 - 1 = 108 = 4 · 27 = 2² · 3³`.
Виділимо підгрупу `H` порядку `pᵉ = 3³ = 27` (тут `p = 3`, `e = 3`).

Візьмемо твірний елемент вихідної групи `g = 6`. Спроектуємо його на підгрупу порядку 27:
- Кофактор проекції `d = 108 / 27 = 4`.
- Генератор підгрупи: `g₀ = 6⁴ mod 109 = 1296 mod 109 = 97 ≡ -12 (mod 109)`.
- Порядок `g₀` у групі дорівнює точно 27.

Нехай цільовий елемент підгрупи `h₀ = 21` (оскільки `21²⁷ mod 109 = 1`, елемент належить підгрупі `H`). Необхідно знайти `x ∈ {0, 1, …, 26}`, такий що:

```
g₀ˣ ≡ 21 (mod 109)
```

Запишемо `x` у трійковій системі числення (`p = 3`, `e = 3` розряди):

```
x = z₀ + z₁·3 + z₂·9,    де z₀, z₁, z₂ ∈ {0, 1, 2}
```

Обчислимо базовий генератор підгрупи порядку 3:

```
γ = g₀^(3³⁻¹) = g₀⁹ mod 109
g₀³ = (-12)³ = -1728 = -16 · 109 + 16 ≡ 16 (mod 109)
γ = (g₀³)³ = 16³ = 4096 = 37 · 109 + 63 ≡ 63 ≡ -46 (mod 109)
```

Перевіримо степені генератора `γ = 63`:
- `γ⁰ = 1`
- `γ¹ = 63`
- `γ² = 63² = 3969 = 36 · 109 + 45 ≡ 45 (mod 109)`
- `γ³ = 45 · 63 = 2835 = 26 · 109 + 1 ≡ 1 (mod 109)`

Знайдемо обернений елемент до `g₀ = 97 ≡ -12`: `g₀⁻¹ = (-12)⁻¹ mod 109 = 9` (оскільки `-12 · 9 = -108 = -1 · 109 + 1 ≡ 1 mod 109`).

#### Крок 0 (знаходження z₀):
Обчислюємо ізолюючий степінь `p^{e - 1 - 0} = 3² = 9`:

```
target₀
= 21⁹ mod 109                 [піднесення цільового елемента 21 до степеня 9]
= (21³)³ mod 109              [подання показника 9 = 3 · 3]
= (105)³ mod 109              [оскільки 21² = 441 = 4 · 109 + 5 ≡ 5, 21 · 5 = 105]
= (-4)³ mod 109               [оскільки 105 = 109 - 4 ≡ -4 mod 109]
= -64 mod 109                 [обчислення (-4)³ = -64]
= 45                          [оскільки -64 + 109 = 45 ≡ 45 mod 109]
```

Рівняння для `z₀`:

```
γ^{z₀} ≡ 45 (mod 109)  ⟹  63^{z₀} ≡ 45 (mod 109)  ⟹  z₀ = 2
```

Знаходимо розряд `z₀ = 2` за таблицею степенів `γ` (`γ² = 45`). Накопичений показник: `x_{(1)} = 2`.

#### Крок 1 (знаходження z₁):
Модифікуємо цільовий елемент:

```
h_{(1)}
= (21 · 9²) mod 109           [множення цілі на (g₀⁻¹)² = 9² = 81]
= (21 · 81) mod 109           [обчислення 21 · 81 = 1701]
= 66                          [оскільки 1701 = 15 · 109 + 66 ≡ 66 mod 109]
```

Обчислюємо ізолюючий степінь `p^{e - 1 - 1} = 3¹ = 3`:

```
target₁
= 66³ mod 109                 [піднесення h_{(1)} = 66 до степеня 3]
= (66² · 66) mod 109          [подання показника 3 = 2 + 1]
= (105 · 66) mod 109          [оскільки 66² = 4356 = 39 · 109 + 105 ≡ 105 mod 109]
= (-4 · 66) mod 109           [оскільки 105 ≡ -4 mod 109]
= -264 mod 109                [обчислення -4 · 66 = -264]
= 63                          [оскільки -264 = -3 · 109 + 63 ≡ 63 mod 109]
```

Рівняння для `z₁`:

```
γ^{z₁} ≡ 63 (mod 109)  ⟹  63^{z₁} ≡ 63 (mod 109)  ⟹  z₁ = 1
```

Знаходимо розряд `z₁ = 1` за таблицею степенів `γ` (`γ¹ = 63`). Накопичений показник: `x_{(2)} = 2 + 1·3 = 5`.

#### Крок 2 (знаходження z₂):
Модифікуємо цільовий елемент:

```
h_{(2)}
= (66 · 9³) mod 109           [множення h_{(1)} на (g₀⁻¹)³ = 9³ = 729 ≡ 75 mod 109]
= (66 · 75) mod 109           [обчислення 66 · 75 = 4950]
= 45                          [оскільки 4950 = 45 · 109 + 45 ≡ 45 mod 109]
```

Обчислюємо ізолюючий степінь `p^{e - 1 - 2} = 3⁰ = 1`:

```
target₂
= 45¹ mod 109                 [піднесення h_{(2)} = 45 до степеня 1]
= 45                          [обчислення 45¹ = 45]
```

Рівняння для `z₂`:

```
γ^{z₂} ≡ 45 (mod 109)  ⟹  63^{z₂} ≡ 45 (mod 109)  ⟹  z₂ = 2
```

Шукаємо `z₂` у таблиці степенів `γ`: оскільки `γ² = 45`, отримуємо `z₂ = 2`.

Повний показник:

```
x = z₀ + z₁·3 + z₂·9 = 2 + 1·3 + 2·9 = 2 + 3 + 18 = 23
```

#### Перевірка результату:
Піднесемо генератор підгрупи `g₀ = 97` до знайденого степеня `23`:

```
97²³ mod 109
= ((97⁹)² · 97⁵) mod 109      [подання показника 23 = 9 · 2 + 5]
= (63² · 97⁵) mod 109         [підстановка γ = 97⁹ ≡ 63 mod 109]
= (45 · 97⁵) mod 109          [оскільки 63² = 3969 = 36 · 109 + 45 ≡ 45 mod 109]
= (45 · 15) mod 109           [оскільки 97⁵ ≡ (-12)⁵ = -248832 = -2283 · 109 + 15 ≡ 15 mod 109]
= 675 mod 109                 [обчислення 45 · 15 = 675]
= 21                          [оскільки 675 = 6 · 109 + 21 ≡ 21 mod 109]
```

Результат `21` точно збігається з вихідним елементом `h₀`.

### Підсумкова асимптотична оцінка складності

Зведемо воєдино всі витрати ресурсів для циклічної підгрупи порядку `pᵉ`:

1. **Одноразова ініціалізація:**
   - Обчислення генератора `γ = g₀^(p^{e-1})`: `O(e · log p)` множень у групі за допомогою алгоритму швидкого піднесення до степеня.
   - Побудова таблиці Baby-Step Giant-Step для `γ`: `O(√p)` групових множень та `O(√p)` слів оперативної пам'яті.

2. **Ітераційний процес (e кроків):**
   - На кожному кроці `j`:
     - Обчислення `g₀^(-x_{(j)})`: `O(e · log p)` операцій;
     - Піднесення до степеня `p^{e-1-j}`: `O((e - j) · log p)` операцій;
     - Пошук за готовою таблицею BSGS: `O(√p)` операцій (або `O(1)` при використанні геш-таблиці з прямим доступом).
   - Сума витрат на піднесення до степеня за всі `e` кроків становить `∑_{j=0}^{e-1} O((e - j) · log p) = O(e² · log p)`.

Загальна часова складність для примарної підгрупи порядку `pᵉ`:

```
T(p, e) = O(√p + e² · log p)
```

Просторова складність:

```
S(p, e) = O(√p)
```

Це доводить, що збільшення показника `e` впливає на складність лише поліноміально (квадратично від `e`), тоді як зростання простого множника `p` визначає складність за законом квадратного кореня `O(√p)`.
