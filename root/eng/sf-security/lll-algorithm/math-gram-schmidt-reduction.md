# 🧮 Математична теорія LLL: ортогоналізація, умова Ловаса та поліноміальна збіжність

Математична строгість LLL-алгоритму тримається на трьох взаємопов'язаних алгебраїчних механізмах: ортогоналізації Грама — Шмідта, локальній геометричній умові Ласло Ловаса та монотонно спадній потенційній функції Девіса — Ленстри. Разом вони гарантують одночасно високу якість знайденого базису ґратки та завершення роботи алгоритму за строго детермінований поліноміальний час.

---

### Евклідові ґратки та їхній детермінант

Нехай `ℝᵐ` — `m`-вимірний евклідовий векторний простір зі стандартним скалярним добутком `⟨u, v⟩ = ∑_{j=1}^m u_j v_j` та евклідовою нормою вектора `‖v‖ = √⟨v, v⟩`.

Нехай дано впорядковану систему з `n` лінійно незалежних векторів `b_1, b_2, ..., b_n ∈ ℝᵐ` (`n ≤ m`). 

**Ґраткою** (lattice) `Λ`, породженою базисом `B = (b_1, ..., b_n)`, називається множина всіх можливих цілочисельних лінійних комбінацій цих векторів:

```
Λ = ℒ(b_1, ..., b_n) = { ∑_{i=1}^n z_i b_i : z_i ∈ ℤ }
```

Число `n` називається **рангом** або розмірністю ґратки (`rank(Λ) = n`), а число `m` — розмірністю навколишнього простору. Якщо розмірності збігаються (`n = m`), ґратка називається повноранговою.

Фундаментальною областю (напіввідкритим паралелепіпедом) базису `B` є множина точок простору:

```
𝒫(B) = { ∑_{i=1}^n t_i b_i : 0 ≤ t_i < 1, t_i ∈ ℝ }
```

`n`-вимірний евклідовий об'єм цієї фундаментальної області є фундаментальним геометричним інваріантом ґратки і не залежить від вибору конкретного базису. Він називається **детермінантом** або визначником ґратки `det(Λ)`:

```
det(Λ) = √det(Bᵀ · B)
```

де `B` — матриця розміру `m × n`, стовпцями якої є координати векторів базису `b_1, ..., b_n`. Якщо `m = n`, то `det(Λ) = |det(B)|`. Якщо ми замінимо базис `B` на інший базис `B' = B · U`, де `U ∈ GL_n(ℤ)` — унімодулярна цілочисельна матриця з визначником `det(U) = ±1`, то об'єм фундаментальної області збережеться:

```
det(B'ᵀ · B') = det(Uᵀ Bᵀ B U) = det(U)² · det(Bᵀ B) = det(Bᵀ B)
```

### Зв'язок із двовимірною редукцією Гаусса — Лагранжа

Щоб зрозуміти, чому тривимірні та багатовимірні ґратки вимагають складного підходу, корисно розглянути двовимірний випадок (`n = 2`), розв'язаний Жозефом-Луї Лагранжем (1773) та Карлом Фрідріхом Гауссом (1801).

У двовимірному просторі редукція базису `(b_1, b_2)` є прямим геометричним аналогом алгоритму Евкліда для знаходження найбільшого спільного дільника:
1. Замінюють вектор `b_2` на його зсув `b_2 ← b_2 - ⌊μ_{2,1}⌉ · b_1`, де `μ_{2,1} = ⟨b_2, b_1⟩ / ‖b_1‖²`. Після цього довжина проєкції задовольняє умову `|μ_{2,1}| ≤ 1/2`.
2. Порівнюють довжини: якщо `‖b_2‖ < ‖b_1‖`, то міняють вектори місцями `(b_1, b_2) ← (b_2, b_1)` і повторюють крок 1.
3. Якщо ж `‖b_2‖ ≥ ‖b_1‖`, алгоритм зупиняється.

Гаусс довів, що для `n = 2` цей процес завжди знаходить абсолютно найкоротший ненульовий вектор ґратки `b_1 = λ_1(Λ)`, а кут між векторами `b_1` та `b_2` гарантовано лежить у межах від `60°` до `120°`.

Проте для розмірностей `n ≥ 3` наївне попарне сортування за довжиною перестає працювати: вектори можуть бути короткими, але майже паралельними один одному, утворюючи дуже гострі кути. Саме тому для багатовимірних ґраток необхідна ортогоналізація простору підґраток.

### Процес ортогоналізації Грама — Шмідта над ґратками

Для аналізу геометрії довільного базису `(b_1, ..., b_n)` застосовують класичний процес ортогоналізації Грама — Шмідта (Gram-Schmidt Orthogonalization, GSO).

Вектори ортогоналізованого базису `b_1*, b_2*, ..., b_n*` та коефіцієнти ортогональної проєкції `μ_{i,j}` обчислюються за рекурентними формулами:

```
b_1* = b_1
b_i* = b_i - ∑_{j=1}^{i-1} μ_{i,j} b_j*   для i = 2, 3, ..., n
```

де проєкційний коефіцієнт `μ_{i,j}` є скалярною величиною, що задає довжину проєкції вектора `b_i` на напрямок `b_j*`:

```
μ_{i,j} = ⟨b_i, b_j*⟩ / ‖b_j*‖²           для 1 ≤ j < i ≤ n
```

За побудовою, для будь-яких різних індексів `i ≠ j` вектори `b_i*` та `b_j*` є взаємно перпендикулярними у просторі `ℝᵐ`:

```
⟨b_i*, b_j*⟩ = 0   при i ≠ j
```

Крім того, для кожного індексу `i ∈ {1, ..., n}` підпростори, натягнуті на перші `i` векторів, збігаються:

```
span_{ℝ}(b_1, ..., b_i) = span_{ℝ}(b_1*, ..., b_i*)
```

Геометричний зміст вектора `b_i*` полягає в тому, що він є ортогональною проєкцією вектора `b_i` на ортогональне доповнення лінійного підпростору `span_{ℝ}(b_1, ..., b_{i-1})`.

Матричний зв'язок між вихідним базисом `B` та ортогоналізованим базисом `B*` має вигляд:

```
B = B* · Mᵀ
```

де `M = (μ_{i,j})` — нижньотрикутна унітрикутна матриця розміру `n × n` з одиницями на головній діагоналі (`μ_{i,i} = 1` та `μ_{i,j} = 0` при `j > i`).

Оскільки визначник унітрикутної матриці завжди дорівнює одиниці (`det(M) = 1`), визначник ґратки виражається як прямий добуток довжин ортогональних векторів:

```
det(Λ) = ∏_{i=1}^n ‖b_i*‖
```

> ⚠️ **Цілочисельний бар'єр ортогоналізації.**
> Вектори `b_i*` утворюють ідеальний ортогональний базис векторного простору `span_{ℝ}(Λ)`, але вони **не належать самій ґратці `Λ`** (за винятком першого вектора `b_1* = b_1`), оскільки коефіцієнти `μ_{i,j}` є раціональними або дійсними дробами, а не цілими числами. Мета редукції ґратки полягає у знаходженні такого цілочисельного базису `(b_1, ..., b_n)`, вектори якого є максимально близькими до взаємно ортогональних осей `b_i*`.

### Означення LLL-редукованого базису

Нехай задано параметр фактора якості `δ ∈ (1/4, 1]`. Найчастіше на практиці обирають `δ = 3/4` (значення, запропоноване авторами у 1982 році) або `δ = 0.99` для отримання щільніших оцінок ортогональності ціною незначного збільшення кількості ітерацій.

Базис `(b_1, b_2, ..., b_n)` ґратки `Λ` називається **`δ`-LLL-редукованим**, якщо він одночасно задовольняє дві фундаментальні умови:

#### 1. Умова розмірного редукування (Size Reduction)
Для всіх пар індексів `1 ≤ j < i ≤ n` коефіцієнти Грама — Шмідта за абсолютною величиною не перевищують половини:

```
|μ_{i,j}| ≤ 1/2
```

Ця умова означає, що вектор `b_i` є максимально наближеним до проєкції на підпростір, ортогональний до всіх попередніх векторів `b_1, ..., b_{i-1}`.

#### 2. Умова Ловаса (Lovász Condition)
Для всіх індексів `k ∈ {2, 3, ..., n}` виконується нерівність:

```
δ · ‖b_{k-1}*‖² ≤ ‖b_k* + μ_{k,k-1} b_{k-1}*‖²
```

Розпишемо праву частину нерівності Ловаса, скориставшись взаємною перпендикулярністю векторів `b_k*` та `b_{k-1}*`:

```
‖b_k* + μ_{k,k-1} b_{k-1}*‖²
= ⟨b_k* + μ_{k,k-1} b_{k-1}*, b_k* + μ_{k,k-1} b_{k-1}*⟩     [означення норми через скалярний добуток]
= ‖b_k*‖² + 2 · μ_{k,k-1} · ⟨b_k*, b_{k-1}*⟩ + μ_{k,k-1}² ‖b_{k-1}*‖²   [білінійність скалярного добутку]
= ‖b_k*‖² + μ_{k,k-1}² ‖b_{k-1}*‖²                           [ортогональність: ⟨b_k*, b_{k-1}*⟩ = 0]
```

Підставивши цей результат у нерівність Ловаса, отримуємо її стандартну обчислювальну форму:

```
‖b_k*‖² ≥ (δ - μ_{k,k-1}²) · ‖b_{k-1}*‖²
```

Геометричний зміст умови Ловаса полягає в наступному: якщо ми спроєктуємо вектори базису `b_{k-1}` та `b_k` на ортогональне доповнення підпростору `span(b_1, ..., b_{k-2})`, ми отримаємо двовимірну ґратку. Умова Ловаса вимагає, щоб на цій двовимірній площині вектори задовольняли модифіковану умову редукції Гаусса з коефіцієнтом послаблення `δ`.

Якщо виконано умову розмірного редукування (`|μ_{k,k-1}| ≤ 1/2`), то `μ_{k,k-1}² ≤ 1/4`. Для класичного параметра `δ = 3/4` коефіцієнт становить:

```
δ - μ_{k,k-1}² ≥ 3/4 - 1/4 = 1/2
```

Звідси випливає головний наслідок умови Ловаса: довжина ортогональної складової наступного вектора не може зменшуватися більше ніж удвічі порівняно з попередньою:

```
‖b_k*‖² ≥ (1/2) · ‖b_{k-1}*‖²
```

### Формули оновлення Грама — Шмідта під час обміну векторів (Swap)

Коли умова Ловаса порушується для деякого індексу `k`, тобто `‖b_k*‖² < (δ - μ_{k,k-1}²) · ‖b_{k-1}*‖²`, алгоритм міняє місцями вектори `b_{k-1}` та `b_k`.

Позначимо новий базис через `(c_1, ..., c_n)`, де `c_{k-1} = b_k`, `c_k = b_{k-1}`, а для всіх інших індексів `c_i = b_i` (`i ∉ {k-1, k}`).

Виведемо явні аналітичні формули для перерахунку векторів Грама — Шмідта та коефіцієнтів проєктування без повторного повного виконання процесу ортогоналізації:

#### Крок 1. Новий ортогональний вектор `c_{k-1}*`
Вектор `c_{k-1} = b_k` проєктується на ортогональне доповнення підпростору `span(b_1, ..., b_{k-2})`:

```
c_{k-1}*
= b_k - ∑_{j=1}^{k-2} μ_{k,j} b_j*       [проєкція на доповнення перших k-2 векторів]
= b_k* + μ_{k,k-1} b_{k-1}*             [виділення компоненти вздовж b_{k-1}*]
```

Квадрат евклідової норми нового вектора дорівнює:

```
‖c_{k-1}*‖² = ‖b_k*‖² + μ_{k,k-1}² ‖b_{k-1}*‖²
```

#### Крок 2. Новий коефіцієнт взаємної проєкції `ν_{k, k-1}`
Обчислимо новий коефіцієнт `ν_{k, k-1}`:

```
ν_{k, k-1}
= ⟨c_k, c_{k-1}*⟩ / ‖c_{k-1}*‖²           [означення коефіцієнта Грама — Шмідта]
= ⟨b_{k-1}, b_k* + μ_{k,k-1} b_{k-1}*⟩ / ‖c_{k-1}*‖²   [підстановка c_k = b_{k-1} та c_{k-1}*]
= μ_{k,k-1} · ‖b_{k-1}*‖² / ‖c_{k-1}*‖²   [ортогональність ⟨b_{k-1}*, b_k*⟩ = 0 та ⟨b_{k-1}, b_{k-1}*⟩ = ‖b_{k-1}*‖²]
```

#### Крок 3. Новий ортогональний вектор `c_k*`
Вектор `c_k = b_{k-1}` ортогоналізується відносно щойно знайденого `c_{k-1}*`:

```
c_k*
= b_{k-1}* - ν_{k, k-1} · c_{k-1}*        [віднімання проєкції на c_{k-1}*]
= b_{k-1}* - (μ_{k,k-1} ‖b_{k-1}*‖² / ‖c_{k-1}*‖²) · (b_k* + μ_{k,k-1} b_{k-1}*)  [підстановка c_{k-1}* та ν]
= (1 - μ_{k,k-1}² ‖b_{k-1}*‖² / ‖c_{k-1}*‖²) · b_{k-1}* - (μ_{k,k-1} ‖b_{k-1}*‖² / ‖c_{k-1}*‖²) · b_k*  [групування коефіцієнтів]
= (‖b_k*‖² / ‖c_{k-1}*‖²) · b_{k-1}* - (μ_{k,k-1} ‖b_{k-1}*‖² / ‖c_{k-1}*‖²) · b_k*  [зведення до спільного знаменника ‖c_{k-1}*‖²]
```

Квадрат норми вектора `c_k*` задовольняє точну рівність збереження двовимірного об'єму підґратки:

```
‖c_{k-1}*‖² · ‖c_k*‖² = ‖b_{k-1}*‖² · ‖b_k*‖²
```

Звідси отримуємо просту формулу для довжини:

```
‖c_k*‖² = (‖b_{k-1}*‖² · ‖b_k*‖²) / ‖c_{k-1}*‖²
```

#### Крок 4. Оновлення решти коефіцієнтів матриці `M`
Для коефіцієнтів у стовпцях `k-1` та `k`:
- Для `j < k-1`:
  коефіцієнти просто міняються місцями: `ν_{k-1, j} = μ_{k, j}` та `ν_{k, j} = μ_{k-1, j}`.
- Для `i > k`:
  ```
  ν_{i, k-1} = μ_{i, k-1} · ν_{k, k-1} + μ_{i, k} · (‖b_k*‖² / ‖c_{k-1}*‖²)
  ν_{i, k}   = μ_{i, k-1} - μ_{i, k} · μ_{k, k-1}
  ```
Всі інші ортогональні вектори `c_i*` для `i ∉ {k-1, k}` та коефіцієнти `μ_{i,j}` залишаються повністю незмінними. Це дозволяє виконувати операцію обміну всього за `O(n)` дій замість `O(n²)` дій повного перерахунку.

### Теоретичні гарантії на довжину знайдених векторів

Умови розмірної редукції та Ловаса забезпечують точні геометричні межі для довжин векторів отриманого базису.

Введемо константу фактора росту:

```
α = 1 / (δ - 1/4)
```

Для стандартного вибору `δ = 3/4` маємо `α = 1 / (3/4 - 1/4) = 2`.

#### Лема про співвідношення ортогональних векторів
Для будь-яких індексів `1 ≤ j ≤ i ≤ n` виконується нерівність:

```
‖b_j*‖² ≤ α^{i - j} · ‖b_i*‖²
```

*Доведення.* За умовою Ловаса, для кожного кроку `‖b_{k-1}*‖² ≤ α · ‖b_k*‖²`. Послідовно застосовуючи цю нерівність `(i - j)` разів від індексу `k = j+1` до `k = i`, отримуємо ланцюг:

```
‖b_j*‖² ≤ α · ‖b_{j+1}*‖² ≤ α² · ‖b_{j+2}*‖² ≤ ... ≤ α^{i - j} · ‖b_i*‖²
```

#### Теорема про довжину першого вектора базису
Перший вектор `b_1` LLL-редукованого базису задовольняє нерівність:

```
‖b_1‖ ≤ 2^{(n - 1) / 4} · (det Λ)^{1 / n}
```

*Доведення.* Оскільки `b_1* = b_1`, за попередньою лемою для кожного індексу `i ∈ {1, ..., n}` маємо:

```
‖b_1‖² ≤ 2^{i - 1} · ‖b_i*‖²
```

Перемножимо ці нерівності для всіх `i` від `1` до `n`:

```
∏_{i=1}^n ‖b_1‖² ≤ ∏_{i=1}^n (2^{i - 1} · ‖b_i*‖²)
```

Ліва частина дорівнює `(‖b_1‖²)^n = ‖b_1‖^{2n}`. Праву частину розіб'ємо на два добутки:

```
‖b_1‖^{2n}
≤ (∏_{i=1}^n 2^{i - 1}) · (∏_{i=1}^n ‖b_i*‖²)   [відокремлення степенів двійки]
= 2^{∑_{i=1}^n (i - 1)} · (det Λ)²              [сума арифметичної прогресії та det(Λ) = ∏ ‖b_i*‖]
= 2^{n(n - 1) / 2} · (det Λ)²                   [формула суми 0 + 1 + ... + n-1 = n(n-1)/2]
```

Добудемо корінь степеня `2n` з обох частин нерівності:

```
‖b_1‖
≤ (2^{n(n - 1) / 2} · (det Λ)²)^{1 / (2n)}      [добування кореня степеня 2n]
= 2^{n(n - 1) / (4n)} · (det Λ)^{2 / (2n)}      [ділення показників степенів на 2n]
= 2^{(n - 1) / 4} · (det Λ)^{1 / n}             [скорочення на n у показнику степеня двійки]
```

#### Теорема про наближення найкоротшого вектора (SVP)
Нехай `λ_1(Λ)` позначає довжину найкоротшого ненульового вектора ґратки:

```
λ_1(Λ) = min_{v ∈ Λ \ {0}} ‖v‖
```

Тоді перший вектор LLL-редукованого базису задовольняє нерівність:

```
‖b_1‖ ≤ 2^{(n - 1) / 2} · λ_1(Λ)
```

*Доведення.* Нехай `v` — довільний ненульовий вектор ґратки `Λ`. Його можна подати як цілочисельну лінійну комбінацію векторів базису: `v = ∑_{i=1}^k z_i b_i`, де `z_k ≠ 0` — останній ненульовий цілий коефіцієнт (`1 ≤ k ≤ n`).

Підставимо розклад векторів `b_i` через ортогоналізовані вектори Грама — Шмідта `b_j*`:

```
v = ∑_{i=1}^k z_i (b_i* + ∑_{j=1}^{i-1} μ_{i,j} b_j*) = z_k b_k* + ∑_{j=1}^{k-1} c_j b_j*
```

де `c_j` — деякі дійсні коефіцієнти. Завдяки попарній ортогональності векторів `b_j*`, за теоремою Піфагора маємо:

```
‖v‖² = z_k² ‖b_k*‖² + ∑_{j=1}^{k-1} c_j² ‖b_j*‖² ≥ z_k² ‖b_k*‖²
```

Оскільки `z_k` є ненульовим цілим числом (`z_k ∈ ℤ \ {0}`), то `z_k² ≥ 1`. Отже, довжина довільного ненульового вектора обмежена знизу:

```
‖v‖ ≥ ‖b_k*‖
```

Оскільки вектор `v` обирався довільно, найкоротший ненульовий вектор ґратки задовольняє оцінку:

```
λ_1(Λ) ≥ min_{1 ≤ i ≤ n} ‖b_i*‖
```

Нехай мінімум досягається на індексі `k`, тобто `‖b_k*‖ = min_i ‖b_i*‖`. Застосуємо лему про співвідношення векторів Грама — Шмідта для індексів `j = 1` та `i = k`:

```
‖b_1‖ = ‖b_1*‖ ≤ 2^{(k - 1) / 2} ‖b_k*‖ ≤ 2^{(n - 1) / 2} ‖b_k*‖ ≤ 2^{(n - 1) / 2} · λ_1(Λ)
```

Це математично доводить, що LLL-алгоритм знаходить розв'язок задачі найкоротшого вектора (SVP) з апроксимаційним коефіцієнтом `2^{(n-1)/2}` за поліноміальний час.

#### Дефект ортогональності та нерівність Адамара
Класична нерівність Адамара стверджує, що об'єм паралелепіпеда не перевищує добутку довжин його сторін:

```
det(Λ) ≤ ∏_{i=1}^n ‖b_i‖
```

Рівність досягається тоді й лише тоді, коли всі вектори `b_i` є взаємно ортогональними. Для LLL-редукованого базису виконується зворотна нерівність, що обмежує **дефект ортогональності**:

```
∏_{i=1}^n ‖b_i‖ ≤ 2^{n(n - 1) / 4} · det(Λ)
```

Це означає, що вектори LLL-базису не можуть бути надмірно скошеними чи майже паралельними.

### Потенційна функція Девіса — Ленстри та поліноміальна збіжність

Найважливішим теоретичним результатом статті Ленстри, Ленстри та Ловаса є строге доведення того, що алгоритм LLL ніколи не зациклюється і гарантовано зупиняється за поліноміальну кількість дій.

Для кожного індексу `i ∈ {1, 2, ..., n}` визначимо підґратку `Λ_i = ℒ(b_1, ..., b_i)`, натягнуту на перші `i` векторів поточного базису. Її визначник дорівнює:

```
det(Λ_i) = ∏_{j=1}^i ‖b_j*‖
```

Введемо квадрат детермінанта підґратки `d_i`:

```
d_i = (det Λ_i)² = ∏_{j=1}^i ‖b_j*‖²   для i = 1, 2, ..., n
```

Визначимо **потенційну функцію** (потенціал Ленстри — Ловаса) `D` як добуток квадратів визначників усіх проміжних підґраток:

```
D = ∏_{i=1}^{n-1} d_i = ∏_{i=1}^{n-1} ‖b_i*‖^{2(n - i)}
```

Простежимо поведінку потенціалу `D` під час виконання двох основних кроків алгоритму:

#### 1. Операція розмірного редукування (`b_k ← b_k - q · b_j`)
Зсув вектора на цілочисельну комбінацію попередніх векторів тієї ж підґратки не змінює ортогональних складових `b_i*`. Отже, всі величини `‖b_i*‖²`, усі детермінанти `d_i` та загальний потенціал `D` **залишаються абсолютно незмінними**.

#### 2. Операція обміну векторів (`b_{k-1} ↔ b_k`)
Розглянемо підґратки `Λ_i` під час обміну пари векторів `(k-1, k)`:
- Для всіх індексів `i < k-1`: підґратки `Λ_i = span(b_1, ..., b_i)` не зачіпаються, тому `d_i` не змінюється.
- Для всіх індексів `i ≥ k`: множина векторів `{b_1, ..., b_i}` як множина містить ті самі вектори (лише в іншому порядку), тому простір `span(b_1, ..., b_i)` та його визначник `d_i` залишаються повністю незмінними.
- **Єдиний визначник, що змінюється — це `d_{k-1}`!**

Новий визначник `d_{k-1}^{new}` дорівнює:

```
d_{k-1}^{new}
= d_{k-2} · ‖c_{k-1}*‖²                  [означення визначника підґратки рангу k-1]
= d_{k-2} · (‖b_k*‖² + μ_{k,k-1}² ‖b_{k-1}*‖²)   [підстановка норми нового вектора c_{k-1}*]
```

Оскільки обмін виконується **виключно тоді, коли порушено умову Ловаса**:

```
‖b_k*‖² + μ_{k,k-1}² ‖b_{k-1}*‖² < δ · ‖b_{k-1}*‖²
```

Підставивши цю нерівність у вираз для `d_{k-1}^{new}`, маємо:

```
d_{k-1}^{new}
< d_{k-2} · (δ · ‖b_{k-1}*‖²)           [застосування порушеної умови Ловаса]
= δ · (d_{k-2} · ‖b_{k-1}*‖²)           [винесення скаляра δ]
= δ · d_{k-1}^{old}                     [означення попереднього визначника d_{k-1}]
```

Для стандартного параметра `δ = 3/4` отримуємо:

```
d_{k-1}^{new} < (3/4) · d_{k-1}^{old}
```

Оскільки всі інші співмножники `d_i` (`i ≠ k-1`) залишилися незмінними, загальний потенціал `D` спадає у строго спадній геометричній прогресії:

```
D_{new} < (3/4) · D_{old}
```

#### Оцінка максимальної кількості обмінів
Якщо вихідний базис складається з цілочисельних векторів `b_i ∈ ℤᵐ` з максимальною початковою довжиною `B = max_i ‖b_i‖`, то початковий потенціал обмежений зверху величиною:

```
D_0 ≤ ∏_{i=1}^{n-1} B^{2(n - i)} ≤ B^{n(n - 1)}
```

З іншого боку, для цілочисельної ґратки кожна матриця Грама `B_iᵀ B_i` складається з цілих чисел, тому її визначник `d_i` є додатним цілим числом (`d_i ≥ 1` для всіх `i`). Отже, потенціал `D` завжди обмежений знизу одиницею:

```
D ≥ 1
```

Оскільки при кожному обміні потенціал `D` зменшується щонайменше у `4/3` раза, загальна кількість операцій обміну `N_{swaps}` строго обмежена:

```
N_{swaps} ≤ log_{4/3}(D_0) ≤ n(n - 1) · log_{4/3}(B) = O(n² · log B)
```

Між двома послідовними обмінами індекс `k` може лише зростати від `2` до `n+1`, виконуючи не більше ніж `n` розмірних редукцій. Кожна розмірна редукція потребує `O(n · m)` арифметичних дій над координатами векторів.

Отже, загальна кількість арифметичних операцій LLL-алгоритму обмежена поліномом від розмірності та довжини вхідних даних:

```
T_{ops} = O(n³ · m · log B)
```

Якщо врахувати контроль за розміром знаменників раціональних чисел за допомогою леми про цілі числа `d_i · μ_{j,i} ∈ ℤ`, бітова довжина проміжних чисел не перевищує `O(n · log B)` бітів. Тому загальна бітова складність алгоритму становить:

```
T_{bits} = O(n⁵ · m · log³ B)
```

### Обчислення з рухомою комою та алгоритм Нгуєна — Стеле (L²)

Класичний LLL-алгоритм 1982 року використовує точну раціональну арифметику. Хоча бітова довжина чисел обмежена поліноміально, операції з дробами великої розрядності (`O(n · log B)` бітів) є обчислювально важкими через постійне обчислення найбільшого спільного дільника для скорочення дробів.

У 1988 році Клаус Шнорр запропонував замінити точні дроби на числа з рухомою комою стандартної розрядності (double precision IEEE 754). Проте евристичні варіанти зіткнулися з проблемою накопичення чисельних похибок: через втрату точності в процесі Грама — Шмідта алгоритм міг потрапляти у нескінченні цикли обмінів.

У 2005 році французькі дослідники Фонг Нгуєн (Phong Nguyen) та Дам'єн Стеле (Damien Stehlé) розробили строгий алгоритм **L² (Floating-Point LLL)**. Вони довели, що контролюючи точність наближень та використовуючи швидкі ортогональні повороти Ґівенса замість повного перерахунку Грама — Шмідта, можна гарантувати збіжність з бітовою точністю мантиси всього `p = O(n)` бітів.

Це знизило практичну часову складність LLL-редукції до:

```
T_{L²} = O(n⁴ · m · log B)
```

що зробило редукцію ґраток розмірності `n = 500` практично здійсненною за лічені секунди.

### Узагальнення: ієрархія алгоритмів BKZ (Block Korkine — Zolotarev)

LLL-алгоритм розглядає блоки розмірності `2` (перевіряючи умову Ловаса для сусідніх пар векторів `b_{k-1}, b_k`). Його природним узагальненням є блочний алгоритм редукції Коркіна — Золотарьова (BKZ), запропонований Клаусом Шнорром у 1987 році.

Алгоритм BKZ з параметром розміру блока `β ∈ [2, n]`:
1. Застосовує LLL-редукцію до всієї ґратки.
2. Для кожного ковзного вікна індексів `{j, j+1, ..., min(j+β-1, n)}` проєктує відповідну підґратку розмірності `β` і знаходить у ній **точний найкоротший вектор** за допомогою експоненційного перебору (алгоритм Канди — Шнорра — Ейхнера).
3. Вставляє знайдений найкоротший вектор на позицію `j` та редукує залишок вікна за допомогою LLL.
4. Повторює переходи, доки всі блоки не стануть редукованими.

При `β = 2` алгоритм BKZ збігається зі звичайним LLL-алгоритмом і дає апроксимаційний фактор `2^{(n-1)/2}` за час `O(poly(n))`. При `β = n` алгоритм BKZ перетворюється на повну редукцію Коркіна — Золотарьова (HKZ), знаходячи абсолютно найкоротший вектор `b_1 = λ_1(Λ)`, але вимагає експоненційного часу `2^{O(n)}`.

У сучасній постквантовій криптографії параметр блоку `β` обирають як баланс між часом виконання та якістю редукції, а алгоритм LLL виступає найшвидшим базовим рушієм (підпрограмою) всередині кожного кроку BKZ.

Повернутися до загального викладу алгоритму та прикладів застосування можна у статті: [LLL-алгоритм редукції ґраток](topic:sf-security/lll-algorithm).
