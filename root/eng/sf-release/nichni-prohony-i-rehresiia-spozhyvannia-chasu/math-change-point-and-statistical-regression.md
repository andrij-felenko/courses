# 🧮 Математика виявлення точок зміни та статистичної регресії метрик

Автоматичний аналіз нічних прогонів спирається на розв'язання фундаментальної математичної дилеми: як надійно виявити справжню інженерну деградацію системи серед природного статистичного шуму вимірювань, мінімізуючи ймовірність хибних тривог (англ. *False Positives*) та пропущених регресій (англ. *False Negatives*).

Простий підхід із фіксованими граничними порогами виду `if metric > threshold` зазнає повної поразки у складних системах. Якщо поріг занадто жорсткий, інженери щоранку отримують хибні сповіщення через коливання температури в серверній або мерехтіння навантаження сусідніх процесів. Якщо поріг занадто вільний, деградація на 1–2% накопичується щотижня, і за пів року система втрачає половину продуктивності без жодного спрацювання алерту.

## 1. Чисельне інтегрування енергетичного профілю

Миттєва електрична потужність `P(t)` та повна спожита енергія `E` за час тестового прогону `T` визначаються через неперервний інтеграл добутку напруги `V(t)` та сили струму `I(t)`:

```text
E = ∫₀ᵀ V(t) · I(t) dt
```

На апаратному стенді цифровий аналізатор живлення здійснює дискретизацію з фіксованим кроком часу `Δt = 1 / f_s`, де `f_s` — частота дискретизації (зазвичай від 10 кГц до 100 кГц). Для обчислення повної енергії за `N` вимірів застосовується чисельне інтегрування методом трапецій, яке мінімізує похибку апроксимації порівняно з простими прямокутними сумами:

```text
E[k] = ((V[k] · I[k] + V[k+1] · I[k+1]) / 2) · Δt

E_total
= ∑_{k=0}^{N-1} E[k]                 [підсумовування енергії елементарних трапецій]
= (Δt / 2) · ∑_{k=0}^{N-1} (P[k] + P[k+1])  [підстановка миттєвої потужності P[k] = V[k] · I[k]]
= Δt · ( (P[0] + P[N]) / 2 + ∑_{k=1}^{N-1} P[k] )  [групування внутрішніх вузлів сітки]
```

Середня споживана потужність `P_avg` за весь час тесту `T = N · Δt` становить:

```text
P_avg
= E_total / T                       [означення середньої потужності через інтеграл]
= E_total / (N · Δt)                [підстановка повної тривалості вимірювання]
```

Якщо напруга живлення стабілізована прецизійним лабораторним джерелом (`V(t) = V_const`), розрахунок спрощується до інтеграла накопиченого заряду `Q` (в ампер-годинах або кулонах):

```text
Q = ∫₀ᵀ I(t) dt ≈ Δt · ∑_{k=0}^{N-1} I[k]
E_total = V_const · Q
```

## 2. Експоненційне зважене ковзне середнє (EWMA) та динамічні довірчі межі

Для згладжування випадкових шумів у щоденних прогонах та відстеження тренду використовується експоненційно зважене ковзне середнє (англ. *Exponentially Weighted Moving Average*, EWMA).

Нехай `x[t]` — значення метрики (наприклад, тривалість активної фази обробки пакету) на нічному прогоні `t`. Згладжене значення `S[t]` обчислюється рекурентно:

```text
S[t]
= α · x[t] + (1 - α) · S[t-1]        [рекурентна формула EWMA з коефіцієнтом згладжування α]
= α · ∑_{i=0}^{t-1} (1 - α)ⁱ · x[t-i] + (1 - α)ᵗ · S[0]  [розгортання рекуренсії у степеневий ряд]
```

Параметр згладжування `α ∈ (0, 1]` визначає «пам'ять» моделі: типове значення `α = 0.2` відповідає ефективному вікну згладжування близько `(2 - α) / α = 9` останніх нічних прогонів.

Оцінка дисперсії похибки прогнозу `σ²[t]` оновлюється аналогічно:

```text
e[t] = x[t] - S[t-1]                 [похибка прогнозу нового виміру відносно попереднього стану]
σ²[t]
= β · (e[t])² + (1 - β) · σ²[t-1]   [експоненційне оновлення оцінки дисперсії, типово β = 0.1]
```

Динамічні межі контролю Шухарта–EWMA формуються як довірчий інтервал шириною `L · σ`:

```text
UCL[t] = S[t] + L · σ[t] · √((α / (2 - α)) · (1 - (1 - α)²ᵗ))   [верхня контрольна межа, Upper Control Limit]
LCL[t] = S[t] - L · σ[t] · √((α / (2 - α)) · (1 - (1 - α)²ᵗ))   [нижня контрольна межа, Lower Control Limit]
```

Для виявлення регресій зазвичай обирається множник `L = 3` (правило «трьох сигм»), що для нормального розподілу забезпечує теоретичну ймовірність хибного спрацювання `P(хибна тривога) ≈ 0.0027` (один хибний алерт на 370 прогонів).

## 3. Кумулятивна сума відхилень (CUSUM) для виявлення малих персистентних зсувів

EWMA ефективно фільтрує поодинокі викиди, але може повільно реагувати на невеликі, проте постійні зсуви середнього (наприклад, зростання базового струму сну на 8% через неоптимальний дільник напруги). Для детектування таких змін найефективнішим є алгоритм кумулятивних сум (англ. *Cumulative Sum Control Chart*, CUSUM), розроблений Ісоном Пейджем (E. S. Page).

Нехай `μ₀` — еталонне історичне середнє значення метрики, а `σ` — стандартне відхилення на стабільному періоді. Ми шукаємо зміщення на величину `δ · σ` (де `δ` — розмір детектуючого зсуву, зазвичай `δ = 1.0`).

Параметр запасу (англ. *slack parameter*) `k` обчислюється як половина цільового зсуву:

```text
k = (δ · σ) / 2
```

Двосторонній алгоритм CUSUM веде дві паралельні накопичувальні статистики — `C⁺` для виявлення регресії вгору (зростання споживання або затримок) та `C⁻` для виявлення зсуву вниз:

```text
C⁺[t] = max(0, C⁺[t-1] + (x[t] - μ₀) - k)   [накопичення позитивних відхилень понад поріг k]
C⁻[t] = max(0, C⁻[t-1] - (x[t] - μ₀) - k)   [накопичення негативних відхилень нижче порогу -k]
```

Інваріант алгоритму: початкові значення `C⁺[0] = 0` та `C⁻[0] = 0`. Якщо процес перебуває у штатному стані (`x[t] ≈ μ₀`), доданки `(x[t] - μ₀) - k` є від'ємними, і функція `max(0, ...)` скидає кумулятивну суму до нуля.

Сигнал тривоги генерується в момент, коли статистика перетинає поріг прийняття рішення `H = h · σ` (типово `h = 4.5` або `h = 5.0`):

```text
АЛЕРТ_РЕГРЕСІЯ ⇔ C⁺[t] > H
```

Час виникнення зміни (найбільш імовірний коміт, що спричинив регресію) локалізується точкою останнього обнулення статистики:

```text
t_change = max { i ≤ t | C⁺[i] = 0 } + 1
```

Це дозволяє автоматизованій системі відкинути проміжні збірки та запустити бінарний пошук (`git bisect`) саме в діапазоні комітів між `t_change - 1` та `t_change`.

## 4. Непараметричний критерій Манна — Вітні (Mann — Whitney U-test) для квантилів затримок

Час відгуку сервісів та мікроконтролерних переривань практично ніколи не підпорядковується нормальному розподілу Гауса: він має виражену асиметрію та «важкий хвіст» через блокування, конкуренцію за шину пам'яті та кеш-промахи.

Для строгого порівняння двох вибірок затримок — еталонної `A = {a₁, a₂, ..., aₙ}` та вибірки з нічного прогону `B = {b₁, b₂, ..., bₘ}` без припущення про форму розподілу застосовується непараметричний критерій Манна — Вітні.

Нульова гіпотеза `H₀`: ймовірність того, що випадково обране значення з нового прогону перевищує значення з еталону, дорівнює `1/2`:

```text
H₀: P(B > A) = P(A > B) = 1/2
```

Обчислення статистики критерію:
1. Усі `n + m` спостережень обох вибірок об'єднуються у спільний масив і сортуються за зростанням.
2. Кожному елементу присвоюється ранг від `1` до `n + m` (для однакових значень береться середній ранг).
3. Обчислюється сума рангів для вибірки `A` (`R_A`) та вибірки `B` (`R_B`).

Статистика `U` для нової вибірки `B`:

```text
U_B
= n · m + (m · (m + 1)) / 2 - R_B    [рангова статистика Манна — Вітні для вибірки B]
```

Для великих вибірок (`n, m > 20`) розподіл статистики `U` апроксимується нормальним розподілом із параметрами:

```text
μ_U = (n · m) / 2                    [математичне сподівання рангової статистики]
σ_U = √((n · m · (n + m + 1)) / 12)  [стандартне відхилення рангової статистики]

Z
= (U_B - μ_U) / σ_U                  [стандартизована z-оцінка зсуву розподілів]
```

Якщо обчислена `p-value = 2 · (1 - Φ(|Z|)) < 0.01` (де `Φ` — функція стандартного нормального розподілу), гіпотеза про однаковість розподілів відкидається. Зсув визнається статистично достовірним, що виключає хибні тривоги через випадкові викиди в окремих запитах.

## 5. Математичний індекс фрагментації динамічної купи

Витік пам'яті вимірюється простою монотонною зміною сумарного обсягу зайнятої пам'яті: `d(Heap_used) / dt > 0`. Однак фрагментація купи може призвести до відмови виділення пам'яті (паніки ядра або повернення `NULL` функцією `malloc`) навіть за умови, що 80% пам'яті залишається вільною.

Нехай `M_total` — сумарний розмір вільної пам'яті в купі на момент вимірювання, а `M_max` — розмір найбільшого неперервного вільного блоку (англ. *maximum contiguous free block*).

Індекс фрагментації купи `F(t) ∈ [0, 1)` визначається співвідношенням:

```text
F(t)
= 1 - (M_max(t) / M_total(t))        [означення безрозмірного індексу фрагментації]
```

Аналіз граничних станів:
- `F(t) = 0`: пам'ять абсолютно монолітна (`M_max = M_total`), фрагментація відсутня. Будь-який запит розміром до `M_total` успішно задовольниться.
- `F(t) → 1`: катастрофічна фрагментація. Вільна пам'ять розбита на тисячі дрібних незв'язних ділянок. Хоча сумарно `M_total` може дорівнювати 100 КБ, спроба виділити один буфер на 4 КБ призведе до системного краху `Out Of Memory`.

У нічних тестах стабільність динамічної пам'яті вважається доведеною, якщо протягом 8-годинного стрес-прогону похідна індексу фрагментації асимптотично прямує до нуля:

```text
lim_{t → ∞} (dF(t) / dt) = 0   [критерій стабілізації структури купи під постійним циклічним навантаженням]
```
