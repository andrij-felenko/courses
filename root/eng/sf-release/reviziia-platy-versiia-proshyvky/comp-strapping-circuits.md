# 🔌 Схеми апаратного детектування ревізій: дільники ADC та цифрові Strapping-піни

Автоматичне визначення апаратної ревізії вимагає фізичного носія інформації на самій друкованій платі (PCB). Цей носій повинен мати нульову або мінімальну вартість у серійному виробництві, читатися в перші мікросекунди після скидання мікроконтролера та зберігати надійність за екстремальних температур від −40 °C до +85 °C.

У серійній електроніці застосовують два базові апаратні підходи: аналоговий резистивний дільник на вході аналого-цифрового перетворювача (ADC) та цифрові конфігураційні піни (англ. *strapping pins*).

```text
АНАЛОГОВИЙ ДІЛЬНИК (1 пін ADC):             ЦИФРОВИЙ STRAPPING (3 піни GPIO):
 VDD (3.3V)                                   VDD          GND          VDD
    │                                          │            │            │
  [R1]                                       [10k]        [10k]        [10k]
    │                                          │            │            │
    ├──●──[100nF]── GND ──> ADC_IN             ●── GPIO0    ●── GPIO1    ●── GPIO2
    │                                        (Bit0 = 1)   (Bit1 = 0)   (Bit2 = 1)
  [R2]                                       
    │                                       Код ревізії: 101_2 = 0x05 (Rev F)
   GND
```

## 1. Резистивний дільник на вході ADC

Головна перевага резистивного дільника — економія виводів мікроконтролера: один аналоговий пін здатен розрізнити від 4 до 8 ревізій плати. Вихідна напруга дільника визначається базовим співвідношенням:

```
V_out = V_dd · R_bot / (R_top + R_bot)
```

### Розрахунок допусків і захисних інтервалів

У реальних умовах напруга на вході ADC зазнає відхилень через три незалежні фактори:
1. **Точність резисторів:** використання прецизійних резисторів із допуском `±1%` (стандартний ряд E96) або `±0.5%`.
2. **Температурний коефіцієнт опору (TCR):** для стандартних SMD-компонентів типовий TCR становить `±100 ppm/°C`, що за перепаду температури у 100 °C дає додатковий дрейф опору до `±1%`.
3. **Нестабільність опорної напруги Vref та шум перетворення ADC:** коливання лінії живлення 3.3V та внутрішні шуми перетворювача створюють похибку квантування до `±2–3%`.

Для надійної роботи діапазон напруги живлення від 0 В до VDD розбивають на симетричні зони з широкими захисними смугами (англ. *guard bands*).

**Таблиця номіналів для 4 ревізій при живленні VDD = 3.3 В (12-бітний ADC: 0...4095 відліків):**

| Ревізія | R_top | R_bot | Ідеальна напруга | Очікуваний код ADC | Робоче вікно ADC (±12%) |
|---|---|---|---|---|---|
| **Rev A** | Не встановлено (NC) | 0 Ом (GND) | 0.00 В | 0 | 0 – 350 |
| **Rev B** | 30.0 кОм | 10.0 кОм | 0.825 В | 1024 | 750 – 1300 |
| **Rev C** | 10.0 кОм | 10.0 кОм | 1.65 В | 2048 | 1750 – 2350 |
| **Rev D** | 10.0 кОм | 30.0 кОм | 2.475 В | 3072 | 2750 – 3350 |
| **Rev E** | 0 Ом (VDD) | Не встановлено (NC) | 3.30 В | 4095 | 3750 – 4095 |

### Фільтрація шумів та час встановлення (RC Settling Time)

Для придушення високочастотних наведень паралельно до нижнього резистора `R_bot` встановлюють керамічний конденсатор ємністю `C = 100 нФ`. 

Еквівалентний вихідний опір дільника за теоремою Тевеніна дорівнює паралельному з'єднанню резисторів:

```
R_eq = (R_top · R_bot) / (R_top + R_bot)
```

Для гіршого випадку (`R_top = R_bot = 10 кОм`): `R_eq = 5 кОм`. Постійна часу фільтра становить:

```
τ = R_eq · C = 5000 Ом · 100·10⁻⁹ Ф = 0.5 мс
```

Щоб напруга на конденсаторі досягла 99.3% від стаціонарного значення, необхідно витримати час, рівний 5 постійним часу:

```
t_settle = 5 · τ = 2.5 мс
```

> ⚠️ **Критична пастка:** якщо опитувати ADC одразу в першому рядку функції `main()` без очікування стабілізації перехідного процесу заряду фільтруючого конденсатора, зчитування поверне занижене значення напруги, і прошивка помилково ідентифікує плату Rev C як Rev A.

## 2. Цифрові Strapping-піни (GPIO Pull-Up / Pull-Down)

Цифровий метод використовує групу з 2–4 пінів вводу-виводу загального призначення (GPIO). На платі під час монтажу кожен пін фізично підтягується резистором 10 кОм або до лінії живлення VDD (логічна 1), або до землі GND (логічний 0).

### Переваги цифрового методу
- **Абсолютна несприйнятливість до аналогового шуму:** цифрові входи тригера Шмітта мікроконтролера мають чіткі пороги спрацьовування (V_IL < 0.3 · VDD, V_IH > 0.7 · VDD).
- **Миттєве зчитування:** не потрібно чекати прогріву та вибірки аналогового блоку ADC; код ревізії зчитується за 1 такт процесора з регістра `IDR` (Input Data Register).

### Боротьба з паразитним струмом витоку

Якщо пін підтягнутий зовнішнім резистором 10 кОм до GND, а внутрішній контролер залишить пін у режимі цифрового виходу з високим рівнем (Output High), через резистор постійно протікатиме струм:

```
I_leak = 3.3 В / 10 000 Ом = 330 мкА
```

Для батарейних IoT-пристроїв зі споживанням у режимі сну 5–10 мкА постійний витік 330 мкА на одному піні зменшує час автономної роботи в 30 разів.

**Правильний алгоритм роботи зі strapping-пінами:**
1. Після скидання налаштувати піни як входи високого імпедансу (Input Floating / High-Z) із вимкненими внутрішніми підтяжками.
2. Зчитати бітовий стан з регістра введення та зберегти числове значення в оперативній пам'яті.
3. Повністю відключити цифрові вхідні буфери пінів або перевести їх у режим аналогового входу без підключення до ADC (Analog Mode), що фізично розмикає вхідний польовий транзистор і гарантує струм витоку менше 1 нА.
