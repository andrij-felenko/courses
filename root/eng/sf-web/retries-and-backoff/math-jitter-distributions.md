# 🧮 Математика джитера: густина розподілу, дисперсія та ймовірність колізій

Коли група з `N` незалежних клієнтів одночасно стикається з відмовою сервера в момент часу `t = 0`, їхня подальша поведінка визначається ймовірнісним розподілом часу очікування `T`. Якщо сервер має максимальну пропускну здатність `C` запитів за секунду, а загальна інтенсивність вхідного потоку повторів `λ(t)` у певний момент перевищує `C`, сервер знову зазнає перевантаження, відкидаючи запити.

Математична мета випадкового тремтіння (Jitter) — розсіяти дельта-піки навантаження в часі, максимізуючи дисперсію `Var(T)` та утримуючи миттєву інтенсивність трафіку `λ(t) ≤ C`.

## 1. Чистий експоненційний відступ: вироджений дельта-розподіл

У чистому детермінованому алгоритмі тривалість очікування на `i`-й спробі (`i ≥ 0`) задається константою:

```
t[i] = min(M, b · 2ⁱ)
```

де `b` — базовий інтервал, `M` — максимальна межа відступу (`max_backoff`).

Густина ймовірності `f(t)` для кожного клієнта є дельта-функцією Дірака `δ(t - t[i])`:
- Математичне сподівання: `E[T] = t[i]`
- Дисперсія: `Var(T) = 0`

Сумарна інтенсивність запитів від `N` клієнтів у момент `t = t[i]` дорівнює:

```
λ(t) = N · δ(t - t[i])
```

Оскільки вся маса ймовірності зосереджена в одній точці, у момент `t = t[i]` виникає імпульс нескінченної щільності. Ймовірність колізії (одночасного надходження запитів на сервер) дорівнює `P = 1.0`, що гарантовано провокує повторний шторм при `N > C · Δt`.

## 2. Повний джитер (Full Jitter): рівномірний розподіл від нуля

У схемі Full Jitter випадкова величина часу затримки `T` розподілена рівномірно на неперервному інтервалі від `0` до верхньої експоненційної межі `B[i] = min(M, b · 2ⁱ)`:

```
T ~ Uniform(0, B[i])
```

Густина ймовірності:

```
f(t) = 1 / B[i]    при 0 ≤ t ≤ B[i]
f(t) = 0           при t < 0 або t > B[i]
```

### Обчислення математичного сподівання

```
E[T]
= ∫₀^{B[i]} t · f(t) dt         [означення математичного сподівання]
= ∫₀^{B[i]} (t / B[i]) dt       [підстановка густини f(t) = 1 / B[i]]
= [t² / (2 · B[i])]₀^{B[i]}     [первісна від t]
= B[i] / 2                      [результат інтегрування]
```

### Обчислення дисперсії

```
E[T²]
= ∫₀^{B[i]} t² · (1 / B[i]) dt  [другий початковий момент]
= [t³ / (3 · B[i])]₀^{B[i]}     [первісна від t²]
= B[i]² / 3                     [результат інтегрування]

Var(T)
= E[T²] - (E[T])²               [формула дисперсії через моменти]
= B[i]² / 3 - (B[i] / 2)²       [підстановка значень E[T²] та E[T]]
= B[i]² / 3 - B[i]² / 4         [зведення до спільного знаменника]
= B[i]² / 12                    [підсумкова дисперсія Full Jitter]
```

Середня інтенсивність потоку на інтервалі `[0, B[i]]` становить:

```
λ_avg = N / B[i]
```

З кожною наступною спробою межа `B[i]` подвоюється, а пікова густина запитів спадає експоненційно як `O(2⁻ⁱ)`. Це забезпечує мінімальне навантаження на сервер серед усіх варіантів джитера.

## 3. Рівний джитер (Equal Jitter): фіксована база з випадковою надбудовою

Схема Equal Jitter ділить експоненційний інтервал `B[i]` навпіл: перша половина `B[i] / 2` є обов'язковою фіксованою затримкою, а друга половина вибирається випадково:

```
T = (B[i] / 2) + Uniform(0, B[i] / 2)
```

Густина ймовірності зосереджена на інтервалі `[B[i]/2, B[i]]`:

```
f(t) = 2 / B[i]    при B[i]/2 ≤ t ≤ B[i]
f(t) = 0           поза інтервалом
```

### Обчислення математичного сподівання

```
E[T]
= B[i] / 2 + E[Uniform(0, B[i] / 2)]    [лінійність математичного сподівання]
= B[i] / 2 + (B[i] / 4)                 [сподівання рівномірного розподілу]
= 3 · B[i] / 4                          [підсумкове сподівання Equal Jitter]
```

### Обчислення дисперсії

```
Var(T)
= Var((B[i] / 2) + Uniform(0, B[i] / 2)) [константа не впливає на дисперсію]
= Var(Uniform(0, B[i] / 2))              [дисперсія рівномірного залишку довжиною L = B[i]/2]
= (B[i] / 2)² / 12                       [формула Var = L² / 12]
= B[i]² / 48                             [підсумкова дисперсія Equal Jitter]
```

Дисперсія Equal Jitter рівно в **4 рази менша**, ніж у Full Jitter:

```
Var_Equal / Var_Full
= (B[i]² / 48) / (B[i]² / 12)   [відношення дисперсій]
= 12 / 48                       [скорочення на B[i]²]
= 1 / 4                         [Equal Jitter розсіює у 4 рази вужче]
```

Оскільки інтервал `[0, B[i]/2]` залишається абсолютно порожнім, Equal Jitter гарантує, що клієнт не почне повтор занадто рано, але концентрація запитів на другій половині інтервалу вдвічі вища (`2N / B[i]`), ніж у Full Jitter.

## 4. Декорельований джитер (Decorrelated Jitter): стохастичне блукання

Декорельований джитер позбавляється жорсткої прив'язки до експоненти `2ⁱ` та формує марковський ланцюг випадкових блукань. Затримка для кроку `i` залежить від фактично отриманої затримки на попередньому кроці `t[i-1]`:

```
t[0] = b
t[i] = min(M, Uniform(b, 3 · t[i-1]))    для i ≥ 1
```

Якщо знехтувати обмеженням `M`, умовне математичне сподівання за умови відомого попереднього значення `t[i-1]` обчислюється як середина інтервалу `[b, 3 · t[i-1]]`:

```
E[T[i] | T[i-1] = t]
= (b + 3t) / 2                  [середина відрізка [b, 3t]]
= b/2 + 1.5 · t                 [лінійна рекурентна залежність]
```

### Безумовне математичне сподівання на кроці `i`

Застосовуючи формулу повного математичного сподівання:

```
E[T[i]]
= b/2 + 1.5 · E[T[i-1]]         [рекурентне рівняння першого порядку]
```

Розгортаючи рекурентність від початкового значення `E[T[0]] = b`:

```
E[T[1]] = b/2 + 1.5 · b = 2 · b
E[T[2]] = b/2 + 1.5 · (2b) = 3.5 · b
E[T[3]] = b/2 + 1.5 · (3.5b) = 5.75 · b
E[T[i]] = b · (1.5ⁱ + 0.5 · ∑_{k=0}^{i-1} 1.5ᵏ) = b · (2 · 1.5ⁱ - 1)
```

Коефіцієнт зростання середнього часу становить `1.5` за крок (проти `2.0` у класичного подвоєння). Головна статистична властивість Decorrelated Jitter — збереження високої індивідуальної варіативності між клієнтами: навіть якщо клієнти мають однаковий номер спроби `i`, їхні поточні значення `t[i]` виявляються розсіяними по всьому простору значень від `b` до `M`, що повністю усуває групову кореляцію.

## 5. Дискретна модель колізій у квантованому часі

Для глибшого розуміння поведінки системи розглянемо дискретну модель, де сервер здатний обробити один запит за квант часу тривалістю `Δt` (наприклад, `Δt = 1 мс`). Якщо інтервал відступу `B` містить `K = B / Δt` незалежних часових слотів, розміщення `N` незалежних клієнтських запитів описується класичною задачею про розміщення частинок по комірках (парадокс днів народження).

Ймовірність того, що всі `N` клієнтів оберуть різні часові слоти (тобто жодної колізії не виникне):

```
P(без колізій)
= ∏_{j=0}^{N-1} (1 - j / K)
≈ exp(-N² / (2K))               [при N << K за наближенням Тейлора]
```

Відповідно, ймовірність виникнення хоча б одного конфліктного слота з накладанням запитів:

```
P(колізія) ≈ 1 - exp(-N² / (2K))
```

Звідси випливає критичний інженерний висновок:
- При чистому експоненційному відступі `K = 1`, тому `P(колізія) = 1.0` при будь-якому `N ≥ 2`.
- При Full Jitter кількість слотів `K = B[i] / Δt` подвоюється на кожному кроці, завдяки чому аргумент експоненти `N² / (2K)` експоненційно зменшується, прямуючи до нуля при `K >> N²`.
- При Equal Jitter ефективна кількість доступних слотів скорочується до `K / 2`, що подвоює ймовірність колізії порівняно з Full Jitter при тому самому значенні `B[i]`.

## 6. Вплив дисперсії на черги масового обслуговування за формулою Поллачека–Хінчина

Поведінка сервера під час відновлення після збою моделюється системою масового обслуговування типу `M/G/1` (пуассонівський вхідний потік із довільним розподілом часу обслуговування або випадковими інтервалами надходження).

Згідно з класичною формулою Поллачека–Хінчина, середня довжина черги `L_q` та середній час очікування запиту в черзі `W_q` прямо пропорційні коефіцієнту варіації часу надходження запитів:

```
W_q = (λ · (σ² + 1/μ²)) / (2 · (1 - ρ))
```

де:
- `λ` — інтенсивність вхідного потоку запитів;
- `μ` — продуктивність сервера (середній час обробки одного запиту дорівнює `1/μ`);
- `ρ = λ / μ` — коефіцієнт завантаження системи (`ρ < 1`);
- `σ²` — дисперсія інтервалів між подіями.

Коли клієнти застосовують чистий експоненційний відступ, дельта-хвиля запитів створює локальне миттєве завантаження `ρ >> 1`, що призводить до миттєвого переповнення буфера черги (`L_q → ∞`) та масового скидання пакетів за правилом Tail Drop.

Навпаки, використання Full Jitter та Decorrelated Jitter перетворює імпульсний сплеск на стаціонарний пуассонівський потік низької інтенсивності `λ(t) = N / B[i]`, для якого `ρ = (N / B[i]) / μ < 1`. Черга запитів залишається стабільною, а час очікування `W_q` утримується в межах кількох мілісекунд, забезпечуючи плавне розсмоктування пікового навантаження.

## 7. Порівняльний аналіз розподілів

| Параметр | Pure Backoff | Full Jitter | Equal Jitter | Decorrelated Jitter |
|---|---|---|---|---|
| **Формула `T`** | `B` | `U(0, B)` | `B/2 + U(0, B/2)` | `U(b, 3 · T_prev)` |
| **Сподівання `E[T]`** | `B` | `0.5 · B` | `0.75 · B` | `≈ b · (2 · 1.5ⁱ - 1)` |
| **Дисперсія `Var(T)`** | `0` | `B² / 12` | `B² / 48` | Висока, нелінійна |
| **Пікова густина трафіку** | `∞` (імпульс `N · δ`) | `N / B` | `2N / B` | Рівномірно розмазана |
| **Ймовірність колізії** | `1.0` (неминуча) | Мінімальна `≈ 1 - e^{-N²/(2K)}` | Помірна `≈ 1 - e^{-N²/K}` | Мінімальна |
| **Ризик повторного шторму** | Критичний (100%) | Мінімальний | Помірний | Мінімальний |
| **Середня затримка до успіху** | Максимальна | Оптимальна | Помірна | Швидка на перших кроках |

Математичний аналіз доводить: **Full Jitter є оптимальним вибором для захисту серверної інфраструктури**, оскільки забезпечує найнижчу пікову густину запитів `N / B`, найбільшу дисперсію від нуля та мінімальну ймовірність переповнення черг. **Decorrelated Jitter є найкращим компромісом для клієнтського SLA**, оскільки забезпечує швидке зростання затримок без жорсткої кластеризації за номерами спроб.
