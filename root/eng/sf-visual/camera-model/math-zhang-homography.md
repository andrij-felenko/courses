# 🧮 Виведення калібрувальних обмежень Чжана

У калібруванні камери за плоским шаблоном (методом Чжана) головний математичний крок полягає в тому, щоб зв'язати відомі двовимірні координати точок на шаховій дошці з пікселями на знімку через матрицю гомографії, а потім використати ортонормованість стовпців повороту для знаходження внутрішніх параметрів камери в замкненому аналітичному вигляді.

Тут наведено повне алгебраїчне виведення системи лінійних обмежень на матрицю коніки B = K⁻ᵀ · K⁻¹ та формули відновлення п'яти внутрішніх параметрів камери: фокусних відстаней f_x, f_y, головної точки (c_x, c_y) та коефіцієнта скосу s.

## 1. Гомографія між площиною шаблону та зображенням

Нехай система координат калібрувального об'єкта жорстко прив'язана до площини шахової дошки. Без обмеження загальності покладемо, що всі точки шаблону лежать у площині Z_w = 0.

Тривимірна точка шаблону в однорідних координатах має вигляд:

```
M̃ = [X_w,  Y_w,  0,  1]ᵀ
```

Підставимо цю точку в загальне рівняння перспективної проекції камери-обскури s · m̃ = K · [R | t] · M̃, де R = [r_1, r_2, r_3] — матриця повороту 3×3, а t — вектор зсуву 3×1:

```
s · m̃ = K · [r_1,  r_2,  r_3,  t] · [X_w,  Y_w,  0,  1]ᵀ
      = K · (r_1 · X_w + r_2 · Y_w + r_3 · 0 + t · 1)     [третій стовпець r_3 множиться на 0]
      = K · [r_1,  r_2,  t] · [X_w,  Y_w,  1]ᵀ            [зведення до розмірності 3×3]
      = H · m̃_plane                                       [H — матриця гомографії 3×3]
```

де m̃_plane = [X_w, Y_w, 1]ᵀ — однорідні координати точки на площині дошки.

Матриця гомографії H = [h_1, h_2, h_3] розміром 3×3 пов'язує точки площини шаблону з їхніми проекціями на матриці сенсора з точністю до невідомого масштабу λ:

```
[h_1,  h_2,  h_3] = λ · K · [r_1,  r_2,  t]
```

Звідси отримуємо вирази для окремих стовпців:

```
h_1 = λ · K · r_1                                         [перший стовпець гомографії]
h_2 = λ · K · r_2                                         [другий стовпець гомографії]
h_3 = λ · K · t                                           [третій стовпець гомографії]
```

## 2. Обмеження ортонормованості стовпців повороту

Матриця R є елементом спеціальної ортогональної групи SO(3). Її стовпці r_1 та r_2 — це одиничні вектори, взаємно перпендикулярні у тривимірному просторі. Це дає дві фундаментальні геометричні властивості:

```
r_1ᵀ · r_2 = 0                                            [вектори взаємно перпендикулярні]
r_1ᵀ · r_1 = r_2ᵀ · r_2 = 1                               [вектори мають однакову одиничну довжину]
```

Виразимо r_1 та r_2 через стовпці гомографії h_1, h_2 та обернену матрицю внутрішніх параметрів K⁻¹:

```
r_1 = (1 / λ) · K⁻¹ · h_1
r_2 = (1 / λ) · K⁻¹ · h_2
```

Підставимо ці вирази в геометричні умови ортонормованості:

```
(1 / λ²) · h_1ᵀ · (K⁻¹)ᵀ · K⁻¹ · h_2 = 0                  [умова ортогональності]
(1 / λ²) · h_1ᵀ · (K⁻¹)ᵀ · K⁻¹ · h_1 = (1 / λ²) · h_2ᵀ · (K⁻¹)ᵀ · K⁻¹ · h_2   [умова рівності норм]
```

Оскільки масштабний множник λ ≠ 0, скорочуємо його й вводимо симетричну матрицю B розміром 3×3 (образ абсолютної коніки):

```
B = (K⁻¹)ᵀ · K⁻¹ = K⁻ᵀ · K⁻¹
```

Отримуємо два фундаментальні рівняння Чжана для кожної спостереженої гомографії H:

```
h_1ᵀ · B · h_2 = 0                                        [ортогональність стовпців]
h_1ᵀ · B · h_1 − h_2ᵀ · B · h_2 = 0                       [однаковий масштаб стовпців]
```

## 3. Лінеаризація та побудова системи рівнянь

Матриця B симетрична (B = Bᵀ), тому має лише 6 незалежних елементів:

```
    ⎡ B₁₁  B₁₂  B₁₃ ⎤
B = ⎢ B₁₂  B₂₂  B₂₃ ⎥
    ⎣ B₁₃  B₂₃  B₃₃ ⎦
```

Згорнемо незалежні елементи B у 6-вимірний вектор b:

```
b = [B₁₁,  B₁₂,  B₂₂,  B₁₃,  B₂₃,  B₃₃]ᵀ
```

Нехай h_i = [h_i1, h_i2, h_i3]ᵀ — i-й стовпець матриці гомографії H. Запишемо скалярний добуток h_iᵀ · B · h_j як лінійну комбінацію елементів вектора b:

```
h_iᵀ · B · h_j = v_ijᵀ · b
```

де 6-вимірний рядок v_ij обчислюється безпосередньо з компонент стовпців h_i та h_j:

```
v_ij = [ h_i1·h_j1,
         h_i1·h_j2 + h_i2·h_j1,
         h_i2·h_j2,
         h_i3·h_j1 + h_i1·h_j3,
         h_i3·h_j2 + h_i2·h_j3,
         h_i3·h_j3 ]ᵀ
```

Тоді два рівняння для кожної гомографії записуються у компактному матричному вигляді:

```
⎡        v_12ᵀ        ⎤ · b = 0
⎣ (v_11 − v_22)ᵀ      ⎦
```

Якщо ми маємо N знімків калібрувальної дошки під різними кутами, ми оцінюємо N гомографій H_1, H_2, ..., H_N. Кожна гомографія дає два рядки, утворюючи однорідну систему лінійних рівнянь розміром 2N × 6:

```
V · b = 0
```

де V — матриця розміром 2N × 6.

## 4. Розв'язання системи через SVD

Оскільки вектор b визначений з точністю до масштабу, ненульовий розв'язок задачі найменших квадратів min ‖V · b‖ при умові ‖b‖ = 1 знаходиться за допомогою сингулярного розкладу (SVD) матриці V:

```
V = U · Σ · Wᵀ
```

Вектор b є останнім стовпцем матриці W (що відповідає найменшому сингулярному числу в діагональній матриці Σ).

## 5. Аналітичне вилучення внутрішніх параметрів з матриці B

Матриця внутрішніх параметрів K у загальному випадку має 5 параметрів:

```
    ⎡ f_x   s   c_x ⎤
K = ⎢  0   f_y  c_y ⎥
    ⎣  0    0    1  ⎦
```

Обернена матриця K⁻¹ дорівнює:

```
        ⎡ 1/f_x   −s/(f_x·f_y)   (s·c_y − c_x·f_y)/(f_x·f_y) ⎤
K⁻¹ = ⎢   0         1/f_y                −c_y/f_y          ⎥
        ⎣   0           0                        1             ⎦
```

Обчислюючи добуток B = (K⁻¹)ᵀ · K⁻¹ і прирівнюючи його до компонент вектора b = [B₁₁, B₁₂, B₂₂, B₁₃, B₂₃, B₃₃]ᵀ з урахуванням спільного масштабного множника γ_B, отримуємо замкнені аналітичні формули відновлення параметрів:

```
c_y = (B₁₂ · B₁₃ − B₁₁ · B₂₃) / (B₁₁ · B₂₂ − B₁₂²)

λ_scale = B₃₃ − (B₁₃² + c_y · (B₁₂ · B₁₃ − B₁₁ · B₂₃)) / B₁₁

f_x = sqrt( λ_scale / B₁₁ )

f_y = sqrt( λ_scale · B₁₁ / (B₁₁ · B₂₂ − B₁₂²) )

s = −B₁₂ · f_x² · f_y / λ_scale

c_x = (s · c_y / f_y) − (B₁₃ · f_x² / λ_scale)
```

Якщо відомо, що сенсор має ідеально прямокутні пікселі без скосу (що вірно для переважної більшості сучасних цифрових матриць), параметр s = 0 фіксують, що спрощує оцінку та вилучає зайвий ступінь вільності.

## 6. Відновлення зовнішніх параметрів (пози) для кожного ракурсу

Після знаходження матриці K зовнішні параметри R_i = [r_1, r_2, r_3] та t_i для кожного i-го кадру відновлюються безпосередньо зі знайденої гомографії H_i = [h_1, h_2, h_3]:

```
λ_i = 1 / ‖ K⁻¹ · h_1 ‖                                  [нормалізаційний коефіцієнт]

r_1 = λ_i · K⁻¹ · h_1                                     [перший стовпець повороту]
r_2 = λ_i · K⁻¹ · h_2                                     [другий стовпець повороту]
r_3 = r_1 × r_2                                           [третій стовпець — векторний добуток]
t_i = λ_i · K⁻¹ · h_3                                     [вектор зсуву]
```

Оскільки через шум вимірювань матриця R_raw = [r_1, r_2, r_3] може не бути строго ортогональною, її проектують на простір SO(3) за допомогою SVD:

```
R_raw = U_R · Σ_R · V_Rᵀ  ⇒  R_corrected = U_R · V_Rᵀ
```

Ці аналітично знайдені значення K та (R_i, t_i) слугують початковим наближенням для нелінійного методу Левенберґа–Марквардта, який одночасно підганяє K, коефіцієнти оптичної дисторсії k_1, k_2, p_1, p_2 та пози (R_i, t_i) до мінімуму похибки перепроекції.
