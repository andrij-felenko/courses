# 🧮 Математика дискретної апроксимації та рівнянь Брезенгема

Растеризація відрізка або кривої на двовимірній цілочисельній ґратці `ℤ²` являє собою фундаментальну задачу дискретної оптимізації: для кожного дискретного значення аргументу необхідно знайти таке ціле число, яке мінімізує відхилення від ідеальної неперервної кривої. З погляду теорії чисел та діофантового аналізу, алгоритм Брезенгема є ефективним методом обчислення найкращого цілочисельного наближення до розв'язків лінійного діофантового рівняння без використання дробових чисел.

## 1. Строге формулювання задачі растеризації відрізка

Нехай задано дві точки ґратки `(x₁, y₁)` та `(x₂, y₂)` із цілочисельними координатами. На евклідовій площині вони визначають неперервний відрізок. Завдяки 8-бічній симетрії декартової площини будь-який відрізок можна звести до канонічного випадку першого октанта шляхом дзеркального відображення осі або перестановки координат `x` і `y`:

```
0 ≤ dy ≤ dx,   де dx = x₂ - x₁, dy = y₂ - y₁
```

У першому октанті зміна координати `x` є монотонною з одиничним кроком `Δx = 1`. Це означає, що для кожного цілого значення `x` на проміжку від `x₁` до `x₂` відповідає точно один піксель у растрові сітці. Неперервна пряма, що проходить через вихідні точки, описується функціональною залежністю:

```
y(x) = y₁ + (dy / dx) · (x - x₁)
```

Для кожного цілого `x ∈ [x₁, x₂]` ми шукаємо цілочисельну координату `y_k ∈ ℤ`, яка мінімізує абсолютну вертикальну похибку відхилення від прямої:

```
|y_k - y(x_k)| → min
```

Позначимо поточну розраховану точку як `(x_k, y_k)`. На наступному кроці `x_{k+1} = x_k + 1` алгоритм має зробити дискретний вибір між двома можливими пікселями-кандидатами на ґратці:
1. Піксель **E** (East / Схід): `(x_k + 1, y_k)`
2. Піксель **NE** (North-East / Північний Схід): `(x_k + 1, y_k + 1)`

Геометрично цей вибір залежить від того, з якого боку від неперервної прямої проходить середня точка (midpoint) між двома кандидатами:

```
M = (x_k + 1, y_k + 1/2)
```

Якщо неперервна пряма проходить вище середньої точки `M`, відстань до верхнього пікселя **NE** є меншою, отже обирається `y_k + 1`. Якщо пряма проходить нижче `M`, ближчим є нижній піксель **E**, отже `y_k` залишається без змін.

## 2. Математичне виведення параметра рішення Брезенгема

Обчислимо вертикальні відстані від кандидатів до ідеальної прямої при `x = x_k + 1`. Позначимо через `y_exact` точне значення координати неперервної прямої:

```
y_exact = (dy / dx) · (x_k + 1 - x₁) + y₁
```

Відстань від нижнього пікселя `y_k` до прямої дорівнює `d₁`, а відстань від прямої до верхнього пікселя `y_k + 1` дорівнює `d₂`:

```
d₁ = y_exact - y_k
= (dy / dx) · (x_k + 1 - x₁) + y₁ - y_k     [вертикальне відхилення від нижнього пікселя]

d₂ = (y_k + 1) - y_exact
= y_k + 1 - (dy / dx) · (x_k + 1 - x₁) - y₁  [вертикальне відхилення від верхнього пікселя]
```

Різниця цих відстаней `d₁ - d₂` показує, який із двох пікселів лежить ближче до прямої:

```
d₁ - d₂
= 2 · y_exact - 2 · y_k - 1
= 2 · (dy / dx) · (x_k + 1 - x₁) + 2 · y₁ - 2 · y_k - 1     [підставили y_exact]
```

Якщо `d₁ - d₂ < 0`, то ідеальна пряма проходить нижче середини `M`, отже ближчим є нижній піксель `E` (`y_{k+1} = y_k`).
Якщо `d₁ - d₂ ≥ 0`, то пряма проходить вище або через середину `M`, отже ближчим є верхній піксель `NE` (`y_{k+1} = y_k + 1`).

Щоб повністю виключити дробові числа та ділення, помножимо вираз `d₁ - d₂` на константу `dx > 0`. Отримане ціле число позначимо як параметр рішення Брезенгема `D_k`:

```
D_k = dx · (d₁ - d₂)
= 2 · dy · (x_k + 1 - x₁) - 2 · dx · (y_k - y₁) + dx · (2 · dy - dx)
```

Оскільки `dx > 0`, знак `D_k` строго відповідає знаку `d₁ - d₂`. Отже, порівняння `D_k` із нулем є точним еквівалентом геометричного оцінювання відстаней.

Знайдемо рекурентне співвідношення для `D_{k+1} - D_k`:

```
D_{k+1} - D_k
= 2 · dy · (x_{k+1} - x_k) - 2 · dx · (y_{k+1} - y_k)
= 2 · dy - 2 · dx · (y_{k+1} - y_k)                     [бо x_{k+1} = x_k + 1]
```

Звідси отримуємо два випадки оновлення параметра рішення на кожному кроці растеризації:

1. **Якщо `D_k < 0` (обрано крок E, тобто `y_{k+1} = y_k`):**
```
y_{k+1} - y_k = 0
D_{k+1} = D_k + ΔD_E
де ΔD_E = 2 · dy
```

2. **Якщо `D_k ≥ 0` (обрано крок NE, тобто `y_{k+1} = y_k + 1`):**
```
y_{k+1} - y_k = 1
D_{k+1} = D_k + ΔD_{NE}
де ΔD_{NE} = 2 · dy - 2 · dx
```

Початкове значення параметра `D₀` обчислюється в початковій точці `(x₁, y₁)` при `k = 0`:

```
D₀ = 2 · dy · (x₁ + 1 - x₁) - 2 · dx · (y₁ - y₁) + dx · (2 · dy - dx)
   = 2 · dy - dx
```

Повний алгоритм растеризації відрізка потребує лише обчислення початкового значення `D₀ = 2 · dy - dx` та подальшого додавання констант `2 · dy` або `2 · dy - 2 · dx` залежно від знака `D_k`. Жодної операції ділення чи множення в основному циклі не виконується.

## 3. Зв'язок із діофантовими рівняннями, послідовностями Бітті та словами Штурма

Канонічне рівняння прямої лінії у цілих числах можна записати у формі лінійного діофантового рівняння:

```
dx · y - dy · x = C
```

Для відрізка, що починається в початку координат `(0, 0)`, маємо `C = 0`. Точки ґратки `(x, y) ∈ ℤ²`, які належать прямій тотожно, відповідають цілочисельним розв'язкам рівняння `dx · y - dy · x = 0`. Згідно з арифметикою діофантових рівнянь, якщо `d = gcd(dx, dy)`, то пряма перетинає точні вузли сітки `d + 1` разів на відрізку від `(0, 0)` до `(dx, dy)`. Точні вузли мають вигляд:

```
x_t = t · (dx / d),   y_t = t · (dy / d),   де t ∈ {0, 1, ..., d}
```

Усі проміжні точки відрізка апроксимуються послідовністю кроків Брезенгема. Послідовність вибору напрямків `s_k ∈ {E, NE}` утворює так зване слово Штурма (Sturmian word) або послідовність Бітті (Beatty sequence) для кутового коефіцієнта `θ = dy / dx`.

Послідовність Бітті задається формулою:

```
B_n = ⌊(n + 1) · θ⌋ - ⌊n · θ⌋
```

Значення `B_n = 0` відповідає кроку **E**, а `B_n = 1` відповідає кроку **NE**. Ланцюгові дроби (continued fractions) для кутового коефіцієнта `θ = [a₀; a₁, a₂, ...]` дають найкращі раціональні наближення `p_m / q_m` до нахилу прямої. Кожна підхідна дріб `p_m / q_m` визначає період макро-шаблону кроків Брезенгема: послідовність із `q_m` кроків містить точно `p_m` діагональних підйомів.

Важливою математичною властивістю послідовностей Брезенгема є властивість збалансованості (balance property): для будь-яких двох підслів однакової довжини в послідовності кроків, кількість діагональних зсувів `NE` у них відрізняється щонайбільше на 1. Це гарантує максимальну візуальну рівномірність растеризованого відрізка та відсутність штучних локальних скупчень кроків.

## 4. Доведення оптимальності та похибка апроксимації

Доведемо, що дискретний відрізок, згенерований алгоритмом Брезенгема, є строго оптимальним у сенсі рівномірної метрики `L_∞` (Чебишова) та метрики `L_1` (Манхеттена).

Нехай `y(x)` — ідеальна координата неперервної прямої, а `y_k` — вибрана ціла координата пікселя. Завдяки критерію середньої точки на кожному кроці вибирається ціле число `y_k`, яке задовольняє нерівність:

```
|y_k - y(x_k)| ≤ 1/2
```

Максимальна вертикальна похибка растеризації не перевищує 0.5 кроку сітки. Оскільки відстань між сусідніми цілими вузлами сітки дорівнює 1, досягнення меншої похибки на цілочисельній ґратці є математично неможливим. Отже, алгоритм Брезенгема будує єдину дискретну ломану, яка лежить у мінімальному `L_∞`-околі неперервного відрізка.

Крім того, накопичена інтегральна похибка уздовж усього відрізка рівна нулю, оскільки параметр похибки тотожно відстежує точний залишок від ділення. При досягненні кінцевої точки `(x₂, y₂)` похибка дорівнює 0, що гарантує точне попадання в кінцевий піксель без накоплення похибок заокруглення.

## 5. Математика дискретного кола Брезенгема

Растеризація кола з радіусом `R ∈ ℕ` та центром у початку координат `(0, 0)` спирається на неявну алгебраїчну функцію кола другому порядку:

```
F(x, y) = x² + y² - R²
```

Точки на колі задовольняють умову `F(x, y) = 0`. Всередині кола `F(x, y) < 0`, а зовні — `F(x, y) > 0`.

Завдяки 8-бічній симетрії достатньо обчислити дугу в першому октанті від `x = 0` до `x = y` (від кута 90° до 45°). На цій дузі `x` зростає від `0` до `R / √2`, а `y` зменшується від `R`. Решту 7 октантів можна побудувати дзеркальним відображенням знаків та перестановкою координат `(±x, ±y)` та `(±y, ±x)`.

Для поточної точки `(x_k, y_k)` на наступному кроці `x_{k+1} = x_k + 1` кандидатами є:
1. Піксель **E** (East): `(x_k + 1, y_k)`
2. Піксель **SE** (South-East / Південний Схід): `(x_k + 1, y_k - 1)`

Середня точка між ними дорівнює:

```
M = (x_k + 1, y_k - 1/2)
```

Оцінимо значення неявної функції у середній точці `M`:

```
D_k = F(x_k + 1, y_k - 1/2)
    = (x_k + 1)² + (y_k - 1/2)² - R²                   [підставили координати M у функцію F]
    = x_k² + 2·x_k + 1 + y_k² - y_k + 1/4 - R²         [розкрили квадрати двочленів]
```

Правило прийняття рішення:
- **Якщо `D_k < 0`:** середня точка `M` лежить усередині кола, тобто дуга кола проходить вище `M`. Ближчим є піксель **E** (`y_{k+1} = y_k`).
- **Якщо `D_k ≥ 0`:** середня точка `M` лежить зовні кола, тобто дуга проходить нижче `M`. Ближчим є піксель **SE** (`y_{k+1} = y_k - 1`).

Обчислимо прирости параметра рішення:

1. **Для кроку E (`y_{k+1} = y_k`):**
```
D_{k+1} = F(x_k + 2, y_k - 1/2)
        = (x_k + 2)² + (y_k - 1/2)² - R²               [підставили x_{k+1} = x_k + 1]
D_{k+1} - D_k = (x_k + 2)² - (x_k + 1)²                [скоротили однакові члени з y та R]
              = 2 · x_k + 3                            [розкрили різницю квадратів]
```

2. **Для кроку SE (`y_{k+1} = y_k - 1`):**
```
D_{k+1} = F(x_k + 2, y_k - 3/2)
        = (x_k + 2)² + (y_k - 3/2)² - R²               [підставили x_{k+1} = x_k + 1 та y_{k+1} = y_k - 1]
D_{k+1} - D_k = (x_k + 2)² - (x_k + 1)² + (y_k - 3/2)² - (y_k - 1/2)²     [відняли значення D_k]
              = 2 · x_k + 3 - 2 · y_k + 2              [розкрили різниці квадратів]
              = 2 · (x_k - y_k) + 5                    [звели подібні доданки]
```

Щоб позбутися дробу `1/4` у початковому значенні `D₀ = F(1, R - 1/2) = 1 + R² - R + 1/4 - R² = 5/4 - R`, помножимо дискримінант на 4 або використаємо цілочисельне округлення `D₀ = 1 - R` (або `3 - 2·R` у подвоєному форматі).

Початкове значення у форматі Брезенгема при `D₀ = 3 - 2 · R`:

```
D₀ = 3 - 2 · R
ΔD_E = 4 · x_k + 6
ΔD_{SE} = 4 · (x_k - y_k) + 10
```

Усі обчислення виконуються виключно в цілих числах з операціями додавання та побітового зсуву.

## 6. Покроковий обчислювальний приклад

Продемонструємо роботу алгоритму Брезенгема для побудови відрізка від `(0, 0)` до `(7, 3)`.

Параметри відрізка:
```
x₁ = 0, y₁ = 0
x₂ = 7, y₂ = 3
dx = 7 - 0 = 7
dy = 3 - 0 = 3
D₀ = 2 · dy - dx = 2 · 3 - 7 = -1
ΔD_E = 2 · dy = 6
ΔD_{NE} = 2 · dy - 2 · dx = 6 - 14 = -8
```

Таблиця покрокового перерахунку:

| Крок `k` | Поточний піксель `(x_k, y_k)` | Параметр рішення `D_k` | Знак `D_k` | Обраний крок | Зміна `D` | Наступний `D_{k+1}` |
|---|---|---|---|---|---|---|
| 0 | (0, 0) | -1 | < 0 | E | +6 | +5 |
| 1 | (1, 0) | +5 | ≥ 0 | NE | -8 | -3 |
| 2 | (2, 1) | -3 | < 0 | E | +6 | +3 |
| 3 | (3, 1) | +3 | ≥ 0 | NE | -8 | -5 |
| 4 | (4, 2) | -5 | < 0 | E | +6 | +1 |
| 5 | (5, 2) | +1 | ≥ 0 | NE | -8 | -7 |
| 6 | (6, 3) | -7 | < 0 | E | +6 | -1 |
| 7 | (7, 3) | — | — | Завершено | — | — |

Результат растеризації: множина точок `{(0,0), (1,0), (2,1), (3,1), (4,2), (5,2), (6,3), (7,3)}`. Кожна точка лежить на мінімальній відстані від неперервної прямої `y = (3/7) · x`, а всі обчислення виконані виключно через цілочисельне додавання.
