# 🧮 Математика суміші Ґаусіанів: онлайн-модель тла

Динамічні сцени комп'ютерного бачення — коливання гілок дерев, сонячні відблиски на воді чи мерехтіння моніторів — неможливо описати одним середнім значенням яскравості. Ця математична вставка розбирає повний апарат суміші Ґаусіанів (англ. *Gaussian Mixture Models*, GMM) для фонового віднімання за моделлю Стауффера—Ґрімсона (1999): імовірнісну густину розподілу, онлайн-апроксимацію алгоритму очікування-максимізації (EM), формули оновлення ваг, центрів і дисперсій, а також аналітичний критерій відбору фонових компонент.

## Ймовірнісна модель спостереження пікселя

Розглядаємо відеопотік у відтінках сірого (або один колірний канал), де `I_t` — яскравість окремо взятого пікселя в момент часу `t` (`0 ≤ I_t ≤ 255`). Попередні спостереження цього пікселя моделюються сумішшю `K` одновимірних нормальних (ґаусових) розподілів (типово `K = 3...5`):

```
P(I_t) = Σ ω_{k,t} · η(I_t; μ_{k,t}, σ²_{k,t})    [сума по k = 1 … K]
```

де:
- `ω_{k,t}` — апріорна вага (частка часу) `k`-ї компоненти суміші, причому `0 ≤ ω_{k,t} ≤ 1` та `Σ ω_{k,t} = 1`;
- `μ_{k,t}` — математичне сподівання (середній тон) `k`-ї компоненти;
- `σ²_{k,t}` — дисперсія (розкид шуму) `k`-ї компоненти;
- `η(I_t; μ, σ²)` — одновимірна функція густини нормального розподілу Ґауса:

```
η(I_t; μ, σ²) = ( 1 / (√(2π) · σ) ) · exp( − (I_t − μ)² / (2σ²) )
```

Кожна ґаусіана описує один фізичний стан пікселя: наприклад, `k=1` — зелене листя дуба (`μ₁ = 68`), `k=2` — блакитне небо за листям (`μ₂ = 210`).

## Критерій збігу (Matching Criterion)

Коли приходить новий відлік `I_t`, система перевіряє, до якого з `K` наявних розподілів належить це значення. Оскільки для нормального розподілу ймовірність потрапляння відліку в межі трьох стандартних відхилень становить 99.7% (правило трьох сигм), збігом вважається умова, коли відстань Махаланобіса не перевищує порогового значення `D` (типово `D = 2.5`):

```
|I_t − μ_{k,t−1}| ≤ D · σ_{k,t−1}
```

Визначаємо бінарний індикатор збігу `M_{k,t}` для кожної компоненти `k`:
- `M_{k,t} = 1`, якщо `k` — перша (найкраща) компонента, для якої виконано умову збігу;
- `M_{k,t} = 0` для всіх інших компонент.

## Онлайн-апроксимація оновлення параметрів

Класичний алгоритм очікування-максимізації (англ. *Expectation-Maximization*, EM) вимагає зберігання великої історії спостережень та багаторазових ітерацій по всьому масиву даних, що фізично неможливо в реальному часі на кадрових частотах 30–60 FPS. 

Стауффер і Ґрімсон запропонували рекурентну онлайн-апроксимацію стохастичного градієнтного спуску (англ. *Online K-Means approximation*), де параметри перераховуються за один прохід для кожного нового пікселя.

### 1. Оновлення ваг компонент

Вага кожної компоненти оновлюється через біжуче згладжування з постійним коефіцієнтом навчання `α` (`0 < α ≤ 1`, типово `α = 0.005...0.02`):

```
ω_{k,t} = (1 − α)·ω_{k,t−1} + α·M_{k,t}
```

- Якщо компонента збіглася (`M_{k,t} = 1`):
  ```
  ω_{k,t} = (1 − α)·ω_{k,t−1} + α = ω_{k,t−1} + α·(1 − ω_{k,t−1})
  ```
  Її вага зростає на частку від невикористаного залишку.

- Якщо компонента не збіглася (`M_{k,t} = 0`):
  ```
  ω_{k,t} = (1 − α)·ω_{k,t−1}
  ```
  Її вага експоненційно згасає зі швидкістю `(1 − α)`.

Після кроку оновлення ваги перенормовуються для збереження одиничної суми:
```
ω_{k,t} = ω_{k,t} / ( Σ ω_{j,t}, j = 1 … K )
```

### 2. Оновлення середнього та дисперсії для збіглої компоненти

Для компоненти зі збігом (`M_{k,t} = 1`) параметри притягуються до нового значення `I_t` з ефективною швидкістю `ρ`:

```
μ_{k,t} = (1 − ρ)·μ_{k,t−1} + ρ·I_t
```

```
σ²_{k,t} = (1 − ρ)·σ²_{k,t−1} + ρ·(I_t − μ_{k,t})²
```

Параметр адаптації `ρ` визначається через правдоподібність спостереження:

```
ρ = α · η(I_t; μ_{k,t−1}, σ²_{k,t−1})
```

На практиці для прискорення обчислень на вбудованих процесорах часто застосовують лінійну апроксимацію `ρ = α / ω_{k,t}` або фіксовану константу `ρ = α`.

Для всіх інших компонент (`M_{k,t} = 0`), які не отримали збігу на поточному кадрі, їхні середні `μ` та дисперсії `σ²` залишаються без змін:
```
μ_{k,t} = μ_{k,t−1}
σ²_{k,t} = σ²_{k,t−1}
```

### 3. Обробка промаху (No Match)

Якщо значення пікселя `I_t` не потрапило в межі `D·σ` жодної з `K` наявних компонент, це означає появу принципово нового кольору (наприклад, у зону пікселя зайшов пішохід у червоній куртці).

У такому разі компонента з найменшою поточною вагою `ω_{K,t}` замінюється новим розподілом:
- Середнє ініціалізується поточним значенням: `μ_{K,t} = I_t`;
- Дисперсія встановлюється великою стартовою величиною: `σ²_{K,t} = σ²_0` (типово `σ_0 = 15...30`);
- Вага отримує мінімальне початкове значення: `ω_{K,t} = ω_0` (типово `ω_0 = 0.01...0.05`).

Після заміни всі ваги знову нормуються до 1.

## Ранжування компонент і критерій фону

Після оновлення параметрів постає фундаментальне питання: які саме з `K` ґаусіанів описують справжнє статичне тло, а які належать рухомим об'єктам або тимчасовим перешкодам?

Стауффер і Ґрімсон ввели метрику якості (фітнесу) розподілу:

```
r_k = ω_{k,t} / σ_{k,t}
```

Фізичний зміст відношення `ω / σ`:
- **Велика вага `ω`** свідчить, що піксель перебуває в цьому стані більшість часу (висока часова стабільність).
- **Мала дисперсія `σ`** свідчить про низький рівень шуму навколо центру (висока просторова визначеність).
- Отже, чим вище значення `r_k`, тим більше розподіл схожий на постійний фоновий стан сцени. Навпаки, рухомі об'єкти, які щойно з'явилися, мають малу вагу `ω` та велику дисперсію `σ`, тому мають мінімальний рейтинг `r_k`.

Всі `K` компонент сортуються за спаданням рейтингу:

```
ω₁ / σ₁  ≥  ω₂ / σ₂  ≥  …  ≥  ω_K / σ_K
```

Фоновими визнаються перші `B` розподілів у відсортованому списку, сумарна вага яких перевищує встановлений поріг фону `T_B` (типово `T_B = 0.6...0.8`):

```
B = argmin_b ( Σ ω_k > T_B )    [сума по k = 1 … b]
```

### Формування вихідної бінарної маски

Остаточна класифікація пікселя `I_t` виконується за правилом:
- Якщо `I_t` збігається хоча б з однією з перших `B` фонових компонент (`k ≤ B`), піксель позначається як **ТЛО** (`Mask(x, y) = 0`).
- Якщо `I_t` збігається лише з компонентами нижче порогу (`k > B`) або не збігся з жодною, піксель позначається як **РУХОМИЙ ОБ'ЄКТ** (`Mask(x, y) = 255`).

## Покроковий обчислювальний приклад

**Вхідні умови:**
- Поточне значення пікселя: `I_t = 75`;
- Кількість розподілів: `K = 3`;
- Поріг збігу: `D = 2.5`;
- Швидкість навчання: `α = 0.05`, `ρ = 0.05`;
- Поріг сумарної ваги фону: `T_B = 0.70`.

Початковий стан трьох компонент:
```
Компонента 1:  ω₁ = 0.50,  μ₁ = 70,   σ₁ = 5    (σ₁² = 25)
Компонента 2:  ω₂ = 0.35,  μ₂ = 190,  σ₂ = 10   (σ₂² = 100)
Компонента 3:  ω₃ = 0.15,  μ₃ = 120,  σ₃ = 20   (σ₃² = 400)
```

**Крок 1: Перевірка збігу для I_t = 75**
- Для `k = 1`: `|75 − 70| = 5 ≤ 2.5 · 5 = 12.5`  ⇒  **ЗБІГ!** (`M₁ = 1`).
- Для `k = 2`: `M₂ = 0`.
- Для `k = 3`: `M₃ = 0`.

**Крок 2: Оновлення ваг**
```
ω₁ = (1 − 0.05)·0.50 + 0.05·1 = 0.475 + 0.050 = 0.525    [оновлення ваги зі збігом: M₁ = 1]
ω₂ = (1 − 0.05)·0.35 + 0.05·0 = 0.3325                  [згасання ваги без збігу: M₂ = 0]
ω₃ = (1 − 0.05)·0.15 + 0.05·0 = 0.1425                  [згасання ваги без збігу: M₃ = 0]
Сума ваг: 0.525 + 0.3325 + 0.1425 = 1.000               [перевірка умови нормування]
```

**Крок 3: Оновлення параметрів збіглої компоненти k = 1**
```
μ₁ = (1 − 0.05)·70 + 0.05·75 = 66.5 + 3.75 = 70.25      [зсув центру до нового спостереження]
σ₁² = (1 − 0.05)·25 + 0.05·(75 − 70.25)²                [формула оновлення дисперсії]
    = 23.75 + 0.05·(4.75)²                              [відхилення від оновленого центру]
    = 23.75 + 0.05·22.5625 = 23.75 + 1.128 = 24.878     [підстановка значень та додавання]
σ₁ = √24.878 ≈ 4.988                                    [стандартне відхилення]
```

**Крок 4: Розрахунок критерію фітнесу r = ω / σ**
```
r₁ = 0.525 / 4.988 = 0.10525    [рейтинг компоненти 1: висока вага, малий розкид]
r₂ = 0.3325 / 10.0 = 0.03325    [рейтинг компоненти 2: середня вага]
r₃ = 0.1425 / 20.0 = 0.007125   [рейтинг компоненти 3: низька вага, великий розкид]
Порядок спадання: r₁ > r₂ > r₃
```

**Крок 5: Визначення порогу фону B**
- Для `b = 1`: `ω₁ = 0.525 ≤ T_B (0.70)`;
- Для `b = 2`: `ω₁ + ω₂ = 0.525 + 0.3325 = 0.8575 > 0.70`  ⇒  `B = 2`.

Компоненти 1 та 2 належать до моделі фону. Оскільки спостереження `I_t = 75` збіглося з компонентою 1 (`1 ≤ B`), піксель класифікується як **ТЛО** (`Mask = 0`).
