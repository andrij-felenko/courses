# 🧮 Інваріантність NCC та геометричний зв'язок з евклідовою відстанню

Коли камера спостерігає за фізичним об'єктом, яскравість пікселів у кадрі постійно змінюється: джерело світла зміщується, хмара перекриває сонце, об'єктив закриває діафрагму або автоматика камери змінює експозицію. Якщо зіставляти фрагменти зображення наївним порівнянням сирих чисел, будь-яке загальне потемніння чи підсилення контрасту руйнує пошук. Нормалізована крос-кореляція (англ. *Zero-mean Normalized Cross-Correlation*, ZNCC) залишається незмінною, якщо яскравість трансформується лінійно: додається фонова константа або масштабується динамічний діапазон. Нижче наведено строге алгебраїчне виведення цієї інваріантності, доведення меж коефіцієнта кореляції через нерівність Коші–Буняковського–Шварца, матричний оператор центрування, обробку сингулярностей та числовий наскрізний розбір.

## Афінна модель зміни освітлення

Нехай `T(u, v)` — еталонний шаблон розміром `M × N` пікселів, де `u ∈ [0, M−1]`, `v ∈ [0, N−1]`. Загальна кількість пікселів у шаблоні дорівнює `K = M · N`. Розглянемо фрагмент зображення `I(u, v)` такого самого розміру `M × N`.

Припустимо, що внаслідок зміни освітлення або коефіцієнта підсилення сенсора яскравість кожного пікселя фрагмента зазнала афінного (лінійного) перетворення:

```
I'(u, v) = α · I(u, v) + β
```

де `α > 0` — коефіцієнт контрасту (масштабування інтенсивності світла або чутливості матриці), а `β ∈ ℝ` — адитивне зміщення яскравості (фонове розсіяне світло чи рівень чорного сенсора).

Середнє значення яскравості вихідного фрагмента `I` та зміненого фрагмента `I'` позначатимемо рискою зверху:

```
Ī  = (1 / K) · ∑ I(u, v)
Ī' = (1 / K) · ∑ I'(u, v)
```

де знак суми `∑` тут і далі означає підсумовування по всіх пікселях вікна: `∑ = ∑_{u=0}^{M-1} ∑_{v=0}^{N-1}`.

Обчислимо середнє значення трансформованого фрагмента `Ī'`:

```
Ī' = (1 / K) · ∑ [ α · I(u, v) + β ]
   = (α / K) · ∑ I(u, v) + (β / K) · ∑ 1          [лінійність оператора суми]
   = α · Ī + (β / K) · K                          [сума одиниць по вікну дорівнює K]
   = α · Ī + β                                    [скорочення K]
```

## Центрування та компенсація адитивного зсуву

Коли ми віднімаємо середнє значення від кожного пікселя (операція центрування), адитивна складова `β` повністю зникає. Розглянемо центровані відхилення `Ĩ'(u, v) = I'(u, v) − Ī'`:

```
Ĩ'(u, v) = I'(u, v) − Ī'
         = (α · I(u, v) + β) − (α · Ī + β)       [підстановка виразів для I' та Ī']
         = α · I(u, v) + β − α · Ī − β            [розкриття дужок]
         = α · (I(u, v) − Ī)                      [скорочення константи β і винесення α]
         = α · Ĩ(u, v)                            [позначення центрованого вихідного сигналу Ĩ]
```

Таким чином, віднімання локального середнього `Ī'` зводить будь-який адитивний зсув `β` до нуля. Центрований фрагмент `Ĩ'` відрізняється від початкового центрованого фрагмента `Ĩ` виключно скалярним множником `α`.

## Матричний погляд: проекція на гіперплощину нульового середнього

У векторній формі фрагмент `I` можна розглядати як вектор-стовпчик `x ∈ ℝᴷ`. Вектор із суцільних одиниць позначимо як `1_K = (1, 1, ..., 1)ᵀ`. Тоді скалярне середнє значення записується через векторний добуток:

```
Ī = (1 / K) · 1_Kᵀ · x
```

Вектор середніх значень однакової розмірності `K` формується як:

```
Ī_vec = 1_K · Ī = (1 / K) · (1_K · 1_Kᵀ) · x
```

Матриця `J_K = 1_K · 1_Kᵀ` є квадратною матрицею `K × K`, кожен елемент якої дорівнює `1`. Операція центрування зводиться до лінійного множення на матрицю центрування `H`:

```
x̃ = x − Ī_vec = (E_K − (1 / K) · J_K) · x = H · x
```

де `E_K` — одинична матриця розміру `K × K`. Матриця `H` володіє двома ключовими властивостями ортогонального проектора:
1. Симетричність: `Hᵀ = H`.
2. Ідемпотентність: `H² = H · H = H`.

Геометрично множення на матрицю `H` проектує довільний вектор `x` ортогонально на `(K−1)`-вимірну лінійну гіперплощину `P₀ = { v ∈ ℝᴷ | 1_Kᵀ · v = 0 }`. Будь-який адитивний зсув яскравості задається вектором `b = β · 1_K`, колінеарним нормалі до гіперплощини `P₀`. Дія проектора `H` на такий зсув дає нуль:

```
H · b = (E_K − (1 / K) · 1_K · 1_Kᵀ) · (β · 1_K)
      = β · 1_K − (β / K) · 1_K · (1_Kᵀ · 1_K)    [винесення скаляра β]
      = β · 1_K − (β / K) · 1_K · K                [оскільки 1_Kᵀ · 1_K = K]
      = β · 1_K − β · 1_K                          [скорочення коефіцієнта K]
      = 0                                          [повне знищення адитивного зсуву]
```

## Нормування енергії та компенсація масштабу

Формула коефіцієнта нормалізованої крос-кореляції ZNCC між шаблоном `T` та фрагментом `I` має вигляд:

```
R(I, T) = ∑ [ (I(u, v) − Ī) · (T(u, v) − T̄) ] / √[ ∑ (I(u, v) − Ī)² · ∑ (T(u, v) − T̄)² ]
```

Для спрощення запису позначимо енергії центрованих сигналів через квадрати норм:

```
‖Ĩ‖² = ∑ (I(u, v) − Ī)² = ∑ Ĩ(u, v)²
‖T̃‖² = ∑ (T(u, v) − T̄)² = ∑ T̃(u, v)²
```

Тоді формула коефіцієнта набуває вигляду:

```
R(I, T) = ( ∑ [ Ĩ(u, v) · T̃(u, v) ] ) / ( ‖Ĩ‖ · ‖T̃‖ )
```

Обчислимо тепер норму трансформованого центрованого вектора `‖Ĩ'‖`:

```
‖Ĩ'‖² = ∑ Ĩ'(u, v)²
       = ∑ [ α · Ĩ(u, v) ]²                      [оскільки Ĩ' = α · Ĩ]
       = α² · ∑ Ĩ(u, v)²                         [винесення константи α² за знак суми]
       = α² · ‖Ĩ‖²                               [підстановка норми вихідного вектора]
```

Оскільки за фізичною умовою коефіцієнт підсилення контрасту строго додатний (`α > 0`), добування квадратного кореня дає:

```
‖Ĩ'‖ = √(α² · ‖Ĩ‖²) = α · ‖Ĩ‖                    [бо |α| = α при α > 0]
```

Тепер підставимо трансформований сигнал `I'` у формулу ZNCC:

```
R(I', T) = ( ∑ [ Ĩ'(u, v) · T̃(u, v) ] ) / ( ‖Ĩ'‖ · ‖T̃‖ )
         = ( ∑ [ (α · Ĩ(u, v)) · T̃(u, v) ] ) / ( (α · ‖Ĩ‖) · ‖T̃‖ )   [підстановка Ĩ' та ‖Ĩ'‖]
         = ( α · ∑ [ Ĩ(u, v) · T̃(u, v) ] ) / ( α · ‖Ĩ‖ · ‖T̃‖ )       [винесення константи α з суми]
         = ( ∑ [ Ĩ(u, v) · T̃(u, v) ] ) / ( ‖Ĩ‖ · ‖T̃‖ )               [скорочення однакового множника α]
         = R(I, T)                                                     [вихідний коефіцієнт ZNCC]
```

Рівність `R(I', T) = R(I, T)` доведено. Коефіцієнт ZNCC є абсолютно інваріантним до будь-яких довільних афінних перетворень яскравості виду `I' = α·I + β` за умови `α > 0`.

## Межі коефіцієнта та нерівність Коші–Буняковського–Шварца

Розглянемо множину значень, яких може набувати коефіцієнт `R(I, T)`. Представимо центровані фрагменти `Ĩ` та `T̃` як вектори в `K`-вимірному евклідовому просторі `ℝᴷ`, де кожна координата відповідає одному пікселю:

```
x = (Ĩ(0,0), Ĩ(1,0), ..., Ĩ(M−1, N−1)) ∈ ℝᴷ
y = (T̃(0,0), T̃(1,0), ..., T̃(M−1, N−1)) ∈ ℝᴷ
```

За побудовою обидва вектори мають нульову суму координат: `∑ xᵢ = 0` та `∑ yᵢ = 0`. Скалярний добуток векторів `⟨x, y⟩` та їхні евклідові норми `‖x‖`, `‖y‖` визначаються як:

```
⟨x, y⟩ = ∑ xᵢ · yᵢ
‖x‖    = √( ∑ xᵢ² )
‖y‖    = √( ∑ yᵢ² )
```

У цих позначеннях коефіцієнт ZNCC являє собою косинус кута `θ` між векторами `x` та `y`:

```
R = ⟨x, y⟩ / ( ‖x‖ · ‖y‖ ) = cos(θ)
```

Згідно з класичною нерівністю Коші–Буняковського–Шварца для довільних векторів у гільбертовому просторі:

```
|⟨x, y⟩| ≤ ‖x‖ · ‖y‖
```

Поділивши обидві частини нерівності на додатний добуток норм `‖x‖ · ‖y‖` (припускаючи, що шаблон і фрагмент не є однорідними константними полями, тобто `‖x‖ > 0` та `‖y‖ > 0`), отримуємо:

```
|R| ≤ 1  ⇔  −1 ≤ R ≤ 1
```

Рівність `|⟨x, y⟩| = ‖x‖ · ‖y‖` (тобто `|R| = 1`) досягається тоді й лише тоді, коли вектори `x` та `y` є лінійно залежними (колінеарними), тобто існує таке ненульове число `c ∈ ℝ`, що:

```
x = c · y  ⇔  Ĩ(u, v) = c · T̃(u, v)  для всіх (u, v)
```

Розглянемо випадки знака константи `c`:
- `c > 0`: вектори співнапрямлені (`θ = 0`), звідки `R = +1`. Повертаючись до початкових пікселів, маємо:
  `I(u, v) − Ī = c · (T(u, v) − T̄)  ⇒  I(u, v) = c · T(u, v) + (Ī − c · T̄) = α · T(u, v) + β`, де `α = c > 0`. Це відповідає ідеальному афінному збігу зображення з шаблоном.
- `c < 0`: вектори протилежно напрямлені (`θ = π`), звідки `R = −1`. Це відповідає ідеальному інверсному збігу (негативу шаблону).
- `⟨x, y⟩ = 0`: вектори ортогональні (`θ = π/2`), звідки `R = 0`. Патерни повністю некорельовані.

## Еквівалентність ZNCC та нормалізованої квадратичної різниці (NSSD)

Розглянемо метрику нормалізованої суми квадратичних різниць (англ. *Normalized Sum of Squared Differences*, NSSD). Попередньо нормалізуємо вектори `x` та `y` до одиничної довжини:

```
u = x / ‖x‖ = Ĩ / ‖Ĩ‖
v = y / ‖y‖ = T̃ / ‖T̃‖
```

За побудовою `‖u‖² = 1` та `‖v‖² = 1`. Обчислимо квадратичну евклідову відстань між одиничними векторами `u` та `v`:

```
NSSD = ‖u − v‖²
     = ∑ (uᵢ − vᵢ)²
     = ∑ [ uᵢ² − 2·uᵢ·vᵢ + vᵢ² ]                  [розкриття квадрата різниці]
     = ∑ uᵢ² − 2 · ∑ (uᵢ · vᵢ) + ∑ vᵢ²            [лінійність суми]
     = ‖u‖² − 2 · ⟨u, v⟩ + ‖v‖²                   [визначення норм і скалярного добутку]
     = 1 − 2 · R + 1                              [бо ‖u‖² = 1, ‖v‖² = 1 та ⟨u, v⟩ = R]
     = 2 · (1 − R)                                [спрощення виразу]
```

З отриманої тотожності безпосередньо випливає фундаментальний висновок:

```
NSSD = 2 · (1 − R)
R    = 1 − (1/2) · NSSD
```

Мінімізація нормалізованої квадратичної похибки `NSSD` суворо еквівалентна максимізації коефіцієнта нормалізованої крос-кореляції `R`. Коли кореляція сягає максимуму `R = 1`, відстань `NSSD = 0`. Коли сигнали некорельовані `R = 0`, відстань `NSSD = 2`. У випадку точного негативу `R = −1`, відстань сягає максимального значення `NSSD = 4`.

## Крайовий випадок: однорідне поле та регуляризація знаменника

Якщо фрагмент зображення `I` є абсолютно однорідною ділянкою (наприклад, чисте небо або рівна біла стіна), усі його пікселі мають однакове значення: `I(u, v) = C`. Тоді:

```
Ī = C
Ĩ(u, v) = C − C = 0
‖Ĩ‖ = 0
```

У знаменнику формули ZNCC виникає ділення на нуль `0 / 0`. Це не є збоєм алгоритму — це математичне відображення невизначеності: однорідна область не містить жодної просторової структури (інформаційна ентропія нульова), тому зіставити з нею шаблон неможливо.

На практиці для запобігання переповненню та діленню на нуль у знаменник вводять малу регуляризаційну константу `ε > 0` (типово `ε = 10⁻⁷` або перевірка дисперсії на поріг):

```
R_reg(I, T) = ⟨Ĩ, T̃⟩ / [ √( ‖Ĩ‖² + ε ) · ‖T̃‖ ]
```

Якщо енергія патча `‖Ĩ‖² < ε_thr`, алгоритм відразу повертає значення `R = 0`, не виконуючи ділення.

## Числовий наскрізний приклад

Розглянемо простий фрагмент `3 × 3` пікселі для наочного числового простеження. Нехай шаблон `T` має такі значення яскравості:

```
    ⎡ 10   20   10 ⎤
T = ⎢ 20  100   20 ⎥
    ⎣ 10   20   10 ⎦
```

Сума елементів `T` дорівнює `10+20+10 + 20+100+20 + 10+20+10 = 220`. Середнє значення `T̄ = 220 / 9 ≈ 24.444`.

Центрований шаблон `T̃ = T − T̄`:

```
     ⎡ −14.44   −4.44  −14.44 ⎤
T̃ = ⎢  −4.44   75.56   −4.44 ⎥
     ⎣ −14.44   −4.44  −14.44 ⎦
```

Енергія центрованого шаблону:
`‖T̃‖² = 4·(−14.444)² + 4·(−4.444)² + (75.556)² = 4·208.64 + 4·19.75 + 5708.64 = 834.56 + 79.01 + 5708.64 = 6622.22`.
Звідси `‖T̃‖ = √6622.22 ≈ 81.377`.

Нехай у кадрі знайдено фрагмент `I`, який зазнав афінного перетворення з параметрами `α = 2.0` та `β = 30.0` (`I(u,v) = 2·T(u,v) + 30`):

```
    ⎡ 50    70   50 ⎤
I = ⎢ 70   230   70 ⎥
    ⎣ 50    70   50 ⎦
```

Сума елементів `I` дорівнює `50+70+50 + 70+230+70 + 50+70+50 = 710`. Середнє `Ī = 710 / 9 ≈ 78.889` (що точно дорівнює `2 · 24.444 + 30 = 78.889`).

Центрований фрагмент `Ĩ = I − Ī`:

```
     ⎡ −28.89   −8.89  −28.89 ⎤
Ĩ = ⎢  −8.89  151.11   −8.89 ⎥
     ⎣ −28.89   −8.89  −28.89 ⎦
```

Помітимо, що кожен елемент `Ĩ` рівно вдвічі більший за відповідний елемент `T̃` (`Ĩ = 2 · T̃`).
Енергія `‖Ĩ‖² = 2² · ‖T̃‖² = 4 · 6622.22 = 26488.89`, тому `‖Ĩ‖ = 2 · 81.377 = 162.754`.

Обчислимо скалярний добуток:
`⟨Ĩ, T̃⟩ = 4·(−28.889·−14.444) + 4·(−8.889·−4.444) + (151.111·75.556) = 2 · ‖T̃‖² = 2 · 6622.22 = 13244.44`.

Обчислюємо коефіцієнт кореляції:

```
R = ⟨Ĩ, T̃⟩ / ( ‖Ĩ‖ · ‖T̃‖ )
  = 13244.44 / ( 162.754 · 81.377 )             [підстановка обчисленого скалярного добутку та норм]
  = 13244.44 / 13244.44                         [перемноження норм у знаменнику]
  = 1.0000                                      [ідеальний збіг]
```

Незважаючи на те, що яскравість пікселів зросла у понад два рази через контраст та адитивне зміщення `+30`, коефіцієнт ZNCC дав точну одиницю `R = 1.0`.
