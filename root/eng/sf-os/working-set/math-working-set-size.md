# 🧮 Математична модель робочої множини та динаміка сторінкових збоїв

Робота процесу з пам'яттю розглядається як дискретна послідовність звернень до сторінок віртуального адресного простору:

```
R = r(1), r(2), r(3), ..., r(t), ...
```

де `r(t) ∈ {1, 2, ..., N}` позначає номер сторінки, до якої процесор звертається на дискретному часовому кроці `t` (номер інструкції читання або запису в пам'ять), а `N` — загальна кількість віртуальних сторінок процесу.

## Визначення вікна спостереження та робочої множини

Для фіксованого цілочисельного параметра вікна `Δ ≥ 1` **робоча множина сторінок** у момент часу `t` визначається як множина всіх унікальних сторінок, до яких процес звертався протягом останніх `Δ` інструкцій:

```
W(t, Δ) = { r(τ) : t - Δ + 1 ≤ τ ≤ t }
```

Розмір робочої множини `w(t, Δ)` є потужністю цієї множини (кількістю унікальних сторінок у ній):

```
w(t, Δ) = |W(t, Δ)|
```

Оскільки у вікні довжиною `Δ` не може бути більше ніж `Δ` різних сторінок і не більше ніж загальна кількість сторінок програми `N`, для будь-якого моменту часу `t` діє фундаментальна нерівність:

```
1 ≤ w(t, Δ) ≤ min(Δ, N)
```

## Середній розмір робочої множини

Якщо послідовність звернень `R` описується стаціонарним стохастичним процесом (властивості програми не змінюються миттєво під час стабільної фази циклу), ми розглядаємо математичне сподівання розміру робочої множини `w(Δ)`:

```
w(Δ) = E[w(t, Δ)]
```

Для аналізу введемо індикаторну функцію `I(i, t, Δ)`, яка дорівнює `1`, якщо сторінка `i` входить до вікна `[t - Δ + 1, t]`, і `0` в іншому випадку:

```
w(t, Δ) = ∑ [i=1..N] I(i, t, Δ)
```

Взявши математичне сподівання від обох частин:

```
w(Δ)
= E[ ∑ [i=1..N] I(i, t, Δ) ]      [лінійність математичного сподівання]
= ∑ [i=1..N] E[ I(i, t, Δ) ]      [перестановка суми й сподівання]
= ∑ [i=1..N] P(сторінка i ∈ W(t, Δ)) [сподівання індикатора дорівнює ймовірності]
```

Позначимо через `F_i(k)` функцію розподілу довжини інтервалу повторного звернення до сторінки `i` (ймовірність того, що наступне звернення до сторінки `i` відбудеться не пізніше ніж через `k` кроків після попереднього). Тоді ймовірність присутності сторінки у вікні довжиною `Δ` виражається через середню частоту звернень до неї `p_i` та функцію повторних звернень:

```
P(i ∈ W(t, Δ)) = p_i · ∑ [k=0..Δ-1] (1 - F_i(k))
```

## Зв'язок між розміром робочої множини та частотою сторінкових збоїв

Нехай операційна система динамічно утримує в оперативній пам'яті саме ті сторінки, які входять до робочої множини `W(t, Δ)`. Тоді сторінковий збій на наступному кроці `t + 1` виникає тоді і тільки тоді, коли чергове звернення `r(t + 1)` потрапляє на сторінку, якої немає в поточній множині `W(t, Δ)`.

Позначимо ймовірність сторінкового збою (missing page rate) як `m(Δ)`:

```
m(Δ) = P( r(t + 1) ∉ W(t, Δ) )
```

Знайдемо математичний зв'язок між `m(Δ)` та приростом розміру робочої множини при розширенні вікна на 1 крок:

```
W(t + 1, Δ + 1) = W(t, Δ) ∪ { r(t + 1) }
```

Потужність нової множини залежить від того, чи була сторінка `r(t + 1)` уже у `W(t, Δ)`:

```
w(t + 1, Δ + 1) - w(t, Δ)
= 1,  якщо r(t + 1) ∉ W(t, Δ)    [новий збій додає нову унікальну сторінку]
= 0,  якщо r(t + 1) ∈ W(t, Δ)    [сторінка вже була у вікні]
```

Беручи математичне сподівання від обох частин рівності:

```
E[ w(t + 1, Δ + 1) - w(t, Δ) ]
= 1 · P(r(t + 1) ∉ W(t, Δ)) + 0 · P(r(t + 1) ∈ W(t, Δ))
= m(Δ)
```

Оскільки для стаціонарного режиму `E[w(t + 1, Δ + 1)] = w(Δ + 1)` та `E[w(t, Δ)] = w(Δ)`, отримуємо тотожність Деннінга:

```
m(Δ) = w(Δ + 1) - w(Δ)
```

У неперервному наближенні для великих значень `Δ`:

```
m(Δ) = dw(Δ) / dΔ
```

Ця формула доводить фундаментальну властивість: **частота сторінкових збоїв системи є похідною (швидкістю зростання) розміру робочої множини за розміром вікна спостереження**.

## Модель незалежних звернень (Independent Reference Model)

Для аналітичного дослідження класично застосовують модель незалежних звернень (IRM), де кожне звернення `r(t)` обирає сторінку `i` з постійною ймовірністю `p_i` незалежно від минулої історії (`∑ [i=1..N] p_i = 1`).

Ймовірність того, що сторінка `i` жодного разу не зустрінеться у вікні довжиною `Δ`:

```
P(i ∉ W(t, Δ)) = (1 - p_i)^Δ
```

Відповідно, ймовірність потрапляння сторінки `i` до робочої множини становить `1 - (1 - p_i)^Δ`. Тоді формули для середнього розміру робочої множини та частоти збоїв набувають вигляду:

```
w(Δ) = N - ∑ [i=1..N] (1 - p_i)^Δ
m(Δ) = ∑ [i=1..N] p_i · (1 - p_i)^Δ
```

Якщо розподіл ймовірностей доступу підпорядковується закону Ціпфа (деякі сторінки використовуються експоненційно частіше за інші: `p_i ∝ 1/i`), крива `w(Δ)` демонструє крутий початковий підйом і вихід на тривале плато, що відповідає активному ядру циклів програми.

## Модель глибини стека LRU (Stack Distance Model)

Більш точною для реальних програм є модель стекової відстані (SDM). Нехай усі сторінки впорядковані у стеку за часом останнього звернення: на вершині стека (позиція 1) стоїть щойно використана сторінка, а на дні (позиція N) — сторінка, до якої не зверталися найдовше.

Кожне звернення генерує відстань у стеку `d(t) ∈ {1, 2, ..., N}`:
- Якщо `d(t) = k`, це означає, що звернення відбулося до сторінки на глибині `k`.
- Після звернення ця сторінка переміщується на вершину стека (позицію 1), а сторінки з позицій `1 .. k-1` опускаються на 1 позицію вниз.

Нехай `q(k) = P(d(t) = k)` — стаціонарний розподіл імовірностей глибини звернень. Тоді сторінковий збій для кешу ємністю `C` кадрів виникає з імовірністю:

```
P_fault(C) = ∑ [k=C+1..N] q(k) = 1 - ∑ [k=1..C] q(k)
```

Завдяки властивості включення стекових алгоритмів (Mattson's Stack Algorithm), робоча множина `W(t, Δ)` у будь-який момент часу точно збігається з першими `w(t, Δ)` елементами стека LRU.

## Оптимізація просторово-часової вартості (Space-Time Product)

Виділення пам'яті під робочу множину створює компроміс:
- Мале вікно `Δ` зменшує обсяг зайнятої пам'яті `w(Δ)`, але спричиняє часті сторінкові збої `m(Δ)`, що блокують процесор на час дискового читання `T_fault`.
- Велике вікно `Δ` зводить частоту збоїв до нуля, але монополізує велику кількість фізичних кадрів, витісняючи інші процеси.

Сумарна вартість роботи програми за час виконання `T` описується критерієм просторово-часового добутку:

```
C(Δ) = w(Δ) · (T + m(Δ) · T · T_fault)
```

де `w(Δ)` — середній обсяг зайнятої пам'яті (просторова складова), а другий множник — повний астрономічний час роботи з урахуванням простоїв на дисковому I/O (часова складова).

Мінімум цільової функції `dC(Δ)/dΔ = 0` визначає оптимальний розмір вікна `Δ*`, при якому ядро досягає найвищої сумарної продуктивності на одиницю використаної оперативної пам'яті.

## Практичний розрахунок на прикладі циклу

**Умова:** Програма виконує інтенсивний обчислювальний цикл над матрицею. У тілі циклу звернення циклічно повторюють послідовність із 4 сторінок коду та даних: `P1, P2, P3, P1, P2, P4`. Загальний адресний простір програми `N = 100` сторінок.

Розрахуємо розмір робочої множини `w(Δ)` та частоту збоїв `m(Δ)` для різних значень вікна `Δ`:

1. **При `Δ = 1`:**
   Кожне вікно містить лише 1 сторінку. `w(1) = 1`.
   Ймовірність того, що наступна сторінка відрізняється від поточної:
   Послідовність: `P1→P2 (збій), P2→P3 (збій), P3→P1 (збій), P1→P2 (збій), P2→P4 (збій), P4→P1 (збій)`.
   Усі 6 переходів між різними сторінками, тому `m(1) = 1.0` (100% збоїв).

2. **При `Δ = 3`:**
   Вікна звернень довжиною 3:
   - `[P1, P2, P3]` -> унікальних 3 сторінки. Наступна `P1` (є у вікні -> влучання).
   - `[P2, P3, P1]` -> унікальних 3 сторінки. Наступна `P2` (є у вікні -> влучання).
   - `[P3, P1, P2]` -> унікальних 3 сторінки. Наступна `P4` (немає у вікні -> збій).
   - `[P1, P2, P4]` -> унікальних 3 сторінки. Наступна `P1` (є у вікні -> влучання).
   - `[P2, P4, P1]` -> унікальних 3 сторінки. Наступна `P2` (є у вікні -> влучання).
   - `[P4, P1, P2]` -> унікальних 3 сторінки. Наступна `P3` (немає у вікні -> збій).
   
   Середній розмір: `w(3) = 3.0`.
   Кількість збоїв: 2 з 6 переходів -> `m(3) = 2/6 = 0.333` (33.3%).

3. **При `Δ = 6`:**
   Вікно довжиною 6 повністю покриває весь період циклу:
   Будь-яке вікно довжиною 6 містить множину `{P1, P2, P3, P4}`.
   `w(6) = 4.0`.
   Будь-яке наступне звернення обов'язково належить до множини `{P1, P2, P3, P4}` -> `m(6) = 0.0` (0% збоїв під час усталеного циклу).

4. **При `Δ = 50`:**
   `w(50) = 4.0` (розмір не збільшується, бо процес не виходить за межі 4 сторінок циклу).
   `m(50) = 0.0`.

**Висновок:** Точка `Δ* = 6` є точкою насичення локальності. Виділення системі пам'яті під `w(6) = 4` сторінки повністю ліквідує сторінкові збої під час роботи циклу. Виділення пам'яті понад 4 сторінки не дає жодного виграшу у швидкодії, марнуючи фізичні кадри.
