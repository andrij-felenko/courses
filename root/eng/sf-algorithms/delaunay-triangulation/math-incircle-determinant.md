# 🧮 Алгебра та геометрія предикату InCircle: визначник, 3D-параболоїд та точна арифметика

Предикат перевірки належності точки описаному колу трикутника (англ. *InCircle predicate*) є центральним обчислювальним ядром усіх алгоритмів тріангуляції Делоне. Він дає сувору математичну відповідь на запитання: чи лежить тестова точка `D = (dx, dy)` всередині, на межі чи зовні кола, утвореного трьома вершинами `A = (ax, ay)`, `B = (bx, by)` та `C = (cx, cy)`.

## Канонічне рівняння кола та визначник 4×4

Загальне неявне рівняння довільного кола на евклідовій площині `ℝ²` описується квадратичною формою від координат `(x, y)`:

```
a·(x² + y²) + b·x + c·y + d = 0
```

де коефіцієнт `a ≠ 0` відповідає невиродженому колу (при `a = 0` рівняння описує пряму лінію).

Якщо три точки `A, B, C` лежать на колі, їхні координати задовольняють це рівняння. Якщо ми підставимо координати четвертої точки `D`, то умова її належності тому самому колу формує систему чотирьох однорідних лінійних рівнянь відносно невідомого вектора коефіцієнтів `[a, b, c, d]ᵀ`:

```
a·(ax² + ay²) + b·ax + c·ay + d = 0
a·(bx² + by²) + b·bx + c·by + d = 0
a·(cx² + cy²) + b·cx + c·cy + d = 0
a·(dx² + dy²) + b·dx + c·dy + d = 0
```

Ця однорідна лінійна система має ненульовий вектор розв'язків тоді й лише тоді, коли визначник її матриці коефіцієнтів `4×4` тотожно дорівнює нулю. Запишемо відповідну матрицю:

```
det4(A, B, C, D)
= | ax  ay  (ax² + ay²)  1 |
  | bx  by  (bx² + by²)  1 |
  | cx  cy  (cx² + cy²)  1 |
  | dx  dy  (dx² + dy²)  1 |
```

Якщо трикутник `ΔABC` орієнтований суворо проти годинникової стрілки (що еквівалентно додатній площі трикутника `Orientation(A, B, C) > 0`), знак цього визначника визначає просторове положення точки `D`:

- `det4(A, B, C, D) > 0` : точка `D` лежить строго **всередині** відкритого круга `ΔABC`.
- `det4(A, B, C, D) = 0` : точка `D` лежить **точно на межі** описаного кола (всі чотири точки коциклічні).
- `det4(A, B, C, D) < 0` : точка `D` лежить строго **зовні** описаного кола.

## Зведення до визначника 3×3 паралельним переносом

Пряме обчислення визначника `4×4` вимагає 24 добутків по чотири множники кожен, що створює значне навантаження на обчислювальний конвеєр процесора.

Оскільки властивість належності точок колу є інваріантною відносно довільного паралельного переносу системи координат, ми перенесемо початок координат у тестову точку `D`, виконавши заміну координат:

```
ax' = ax − dx,  ay' = ay − dy
bx' = bx − dx,  by' = by − dy
cx' = cx − dx,  cy' = cy − dy
dx' = 0,        dy' = 0
```

В матричній формі це відповідає відніманню четвертого рядка матриці від перших трьох. Покажемо покроковий ланцюг перетворень:

```
det4(A, B, C, D)
= | ax    ay    (ax² + ay²)    1 |
  | bx    by    (bx² + by²)    1 |
  | cx    cy    (cx² + cy²)    1 |
  | dx    dy    (dx² + dy²)    1 |
= | ax-dx ay-dy (ax²-dx²+ay²-dy²) 0 |  [віднімання 4-го рядка від 1-го]
  | bx-dx by-dy (bx²-dx²+by²-dy²) 0 |  [віднімання 4-го рядка від 2-го]
  | cx-dx cy-dy (cx²-dx²+cy²-dy²) 0 |  [віднімання 4-го рядка від 3-го]
  | dx    dy    (dx² + dy²)       1 |
```

Використовуючи алгебраїчну тотожність `x² − dx² = (x − dx)² + 2·dx·(x − dx)` та віднімаючи від третього стовпчика перший стовпчик, помножений на `2·dx`, і другий стовпчик, помножений на `2·dy`, розкладаємо матрицю за останнім стовпчиком:

```
InCircle(A, B, C, D)
= | ax − dx    ay − dy    (ax − dx)² + (ay − dy)² |
  | bx − dx    by − dy    (bx − dx)² + (by − dy)² |   [розклад за 4-м стовпчиком]
  | cx − dx    cy − dy    (cx − dx)² + (cy − dy)² |
```

Введемо короткі позначення для зміщених координат та квадратів їхніх евклідових відстаней до точки `D`:

```
adx = ax − dx
ady = ay − dy
bdx = bx − dx
bdy = by − dy
cdx = cx − dx
cdy = cy − dy

distA_sq = adx² + ady²
distB_sq = bdx² + bdy²
distC_sq = cdx² + cdy²
```

Розкладаючи визначник `3×3` за третім стовпчиком, отримуємо компактну формулу:

```
InCircle(A, B, C, D)
= distA_sq · (bdx·cdy − bdy·cdx)
  − distB_sq · (adx·cdy − ady·cdx)
  + distC_sq · (adx·bdy − ady·bdx)
```

Кожен із трьох виразів у дужках є орієнтованою площею (подвійним орієнтованим трикутником) відповідної пари точок відносно початку координат `D`:

```
Area(D, B, C) = bdx·cdy − bdy·cdx
Area(D, A, C) = adx·cdy − ady·cdx
Area(D, A, B) = adx·bdy − ady·bdx
```

## Геометричне виведення через підняття на 3D-параболоїд

Глибокий взаємозв'язок між планарними колами та лінійною алгеброю розкривається через канонічне відображення підняття (*lifting map*) площини `ℝ²` на тривимірний параболоїд:

```
L: ℝ² → ℝ³
L(x, y) = (x, y, x² + y²)
```

Розглянемо коло радіуса `R` із центром у точці `(xc, yc)`. Його рівняння має вигляд `(x − xc)² + (y − yc)² = R²`. Розкриємо дужки:

```
x² − 2·xc·x + xc² + y² − 2·yc·y + yc² = R²
= (x² + y²) − 2·xc·x − 2·yc·y + (xc² + yc² − R²) = 0    [згрупували доданки]
= z − 2·xc·x − 2·yc·y + (xc² + yc² − R²) = 0            [підставили z = x² + y²]
```

Отримане співвідношення є рівнянням не параболоїда, а звичайної похилої **площини `H`** у просторі `ℝ³`:

```
H: z = 2·xc·x + 2·yc·y + (R² − xc² − yc²)
```

Це доводить такі геометричні факти:

1. **Коло як плоский перетин:** Лінія перетину тривимірного параболоїда `z = x² + y²` із будь-якою січною площиною `H` при ортогональному проектуванні на площину `XY` утворює ідеальне коло.
2. **Три точки визначають площину:** Три підняті точки `A' = (ax, ay, ax²+ay²)`, `B' = (bx, by, bx²+by²)`, `C' = (cx, cy, cx²+cy²)` однозначно задають єдину площину `H(A', B', C')` у просторі `ℝ³`.
3. **Положення тестової точки:** Для будь-якої точки `D = (dx, dy)` відстань до центру кола менша за `R` тоді й лише тоді, коли:

```
(dx − xc)² + (dy − yc)² < R²
= dx² + dy² < 2·xc·dx + 2·yc·dy + (R² − xc² − yc²)      [розкрили квадрати]
= z(D') < z_plane(H, dx, dy)                           [точка D' лежить НИЖЧЕ площини H]
```

Отже, точка `D` лежить усередині описаного кола `ΔABC` тоді й лише тоді, коли її тривимірний образ `D'` лежить строго **під площиною**, натягнутою на підняті точки `A', B', C'`.

Орієнтація чотирьох точок `A', B', C', D'` у просторі `ℝ³` визначається знаком визначника `4×4`, що алгебраїчно доводить тотожність 2D-предиката Делоне та просторової орієнтації.

## Числовий розрахунок на конкретному прикладі

Проілюструємо роботу предиката на конкретних числових координатах.

Нехай задано три вершини трикутника:
- `A = (0.0, 0.0)`
- `B = (4.0, 0.0)`
- `C = (0.0, 4.0)`

Описане коло прямокутного трикутника `ΔABC` має центр у середині гіпотенузи `(2.0, 2.0)` та радіус `R = √8 ≈ 2.8284`. Рівняння кола: `(x − 2)² + (y − 2)² = 8`, тобто `x² + y² − 4x − 4y = 0`.

Перевіримо тестову точку `D = (1.0, 1.0)` (яка очевидно лежить усередині кола, оскільки `(1−2)² + (1−2)² = 2 < 8`):

1. Обчислюємо зміщені координати відносно `D = (1.0, 1.0)`:
   - `adx = 0 − 1 = −1.0`, `ady = 0 − 1 = −1.0`, `distA_sq = (−1)² + (−1)² = 2.0`
   - `bdx = 4 − 1 = 3.0`, `bdy = 0 − 1 = −1.0`, `distB_sq = 3² + (−1)² = 10.0`
   - `cdx = 0 − 1 = −1.0`, `cdy = 4 − 1 = 3.0`, `distC_sq = (−1)² + 3² = 10.0`

2. Обчислюємо парні орієнтації:
   - `Area(D, B, C) = bdx·cdy − bdy·cdx = 3.0·3.0 − (−1.0)·(−1.0) = 9.0 − 1.0 = 8.0`
   - `Area(D, A, C) = adx·cdy − ady·cdx = (−1.0)·3.0 − (−1.0)·(−1.0) = −3.0 − 1.0 = −4.0`
   - `Area(D, A, B) = adx·bdy − ady·bdx = (−1.0)·(−1.0) − (−1.0)·3.0 = 1.0 + 3.0 = 4.0`

3. Обчислюємо фінальний визначник:

```
InCircle(A, B, C, D)
= 2.0 · 8.0 − 10.0 · (−4.0) + 10.0 · 4.0  [підстановка обчислених орієнтацій та dist_sq]
= 16.0 + 40.0 + 40.0                      [арифметичне множення доданків]
= 96.0                                    [сума доданків: значення визначника > 0]
```

Оскільки результат строго додатний (`96.0 > 0`), точка `D` гарантовано лежить усередині описаного кола.

## Числова стійкість та адаптивна арифметика Шевчука

При програмній реалізації предиката на апаратних числах із рухомою комою подвійної точності `double` (стандарт IEEE 754) виникає загроза втрати точності через віднімання близьких чисел (явище катастрофічного скасування розрядів / *catastrophic cancellation*).

Якщо чотири точки майже коциклічні (наприклад, лежать на колі радіуса `10⁴` з відхиленням у `10⁻¹²`), різниця добутків у визначнику вимагає більшої кількості значущих бітів, ніж 53 біти мантиси типу `double`. Помилка у знаку визначника призводить до створення сіток із перевернутими трикутниками або нескінченних циклів перекидання ребер.

Джонатан Шевчук розробив трирівневу систему фільтрації обчислень:

1. **Швидкий статичний фільтр з плаваючою комою:**
   Обчислюється наближене значення `det` за стандартними формулами `double` та розраховується теоретична верхня межа накопиченої похибки округлення:

```
ε_bound
= (10 · 2⁻⁵³ + 96 · (2⁻⁵³)²) · max_coord⁴
```

   Якщо `|det| > ε_bound`, знак наближеного результату гарантовано збігається зі знаком точного математичного значення. У 99.9% практичних випадків обчислення завершуються на цьому етапі без додаткових витрат часу.

2. **Точна арифметика розширень (Floating-Point Expansions):**
   Якщо `|det| ≤ ε_bound` (невизначеність знаку), алгоритм перемикається на представлення чисел у вигляді суми кількох неперекривних значень типу `double` (розширення без втрати розрядів за алгоритмами Кнута та Деккера `TwoSum` та `TwoProduct`). Це забезпечує абсолютну топологічну надійність генерації сіток Делоне при швидкості звичайних апаратних обчислень.
