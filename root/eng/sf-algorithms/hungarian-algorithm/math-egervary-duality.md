# 🧮 Математичні основи: лінійне програмування, двоїстість та теорема Еґерварі

Математична строгість Угорського методу ґрунтується на теорії двоїстості лінійного програмування та теоремі Біркгофа-фон Неймана, які разом доводять, що розв'язання неперервної релаксації задачі про призначення завжди дає цілочисловий глобальний оптимум за поліноміальний час.

---

### Пряма задача лінійного програмування

Задачу про призначення можна сформулювати як задачу лінійного цілочислового програмування. Нехай задано дійсну або цілочислову матрицю витрат `C` розміром `N × N`. Введемо матрицю змінних рішень `X = (x[i][j])`, де кожна змінна позначає факт вибору конкретної пари:

```text
x[i][j] = 1, якщо виконавець i призначений на завдання j
x[i][j] = 0, у протилежному випадку
```

Цільова функція вимагає мінімізації сумарних витрат на все призначення:

```text
min  ∑[i=1..N] ∑[j=1..N] C[i][j] · x[i][j]
```

за виконання таких базових лінійних обмежень:

1. Кожен виконавець отримує рівно одне завдання:
   ```text
   ∑[j=1..N] x[i][j] = 1   (для кожного i = 1..N)
   ```
2. Кожне завдання закріплюється рівно за одним виконавцем:
   ```text
   ∑[i=1..N] x[i][j] = 1   (для кожного j = 1..N)
   ```
3. Умова цілочисловості:
   ```text
   x[i][j] ∈ {0, 1}        (для всіх i, j = 1..N)
   ```

Якщо замінити жорстку дискретну умову `x[i][j] ∈ {0, 1}` на неперервну релаксацію `x[i][j] ≥ 0`, ми отримаємо стандартну задачу неперервного лінійного програмування.

---

### Теорема Біркгофа-фон Неймана та цілочисловість релаксації

Множина допустимих розв'язків релаксованої задачі утворює опуклий багатогранник у просторі розмірності `N²`, відомий у лінійній алгебрі як багатогранник **двічі стохастичних матриць** (невід'ємних дійсних матриць, сума елементів у кожному рядку та кожному стовпці яких дорівнює 1).

За фундаментальною **теоремою Біркгофа-фон Неймана** (доведеною Гарретом Біркгофом у 1946 році та Джоном фон Нейманом у 1953 році):
- Багатогранник двічі стохастичних матриць розміром `N × N` є опуклою оболонкою скінченної множини всіх `N!` матриць перестановок.
- Усі крайні точки (вершини цього багатогранника) є чистими матрицями перестановок, тобто матрицями, усі елементи яких строго належать множині `{0, 1}`.

Оскільки лінійна цільова функція на замкненому обмеженому опуклому багатограннику завжди досягає свого екстремуму в одній із крайніх точок, оптимальний розв'язок неперервної релаксованої задачі **завжди є строго цілочисловим**. Матриця обмежень задачі про призначення є унімодулярною, що унеможливлює появу дробових вершин і повністю позбавляє потреби у застосуванні експоненційних методів комбінаторного перебору типу «гілок і меж».

### Двоїста задача та слабка двоїстість

Побудуємо двоїсту задачу лінійного програмування за класичними правилами подвійності Лагранжа.

Введемо множники Лагранжа для системи лінійних обмежень:
- `u[i]` — двоїсті змінні (потенціали), що відповідають обмеженням за рядками `i = 1..N`.
- `v[j]` — двоїсті змінні (потенціали), що відповідають обмеженням за стовпцями `j = 1..N`.

Двоїста задача формулюється як максимізація суми потенціалів:

```text
max  ∑[i=1..N] u[i] + ∑[j=1..N] v[j]
```

за виконання умови допустимості двоїстих оцінок:

```text
u[i] + v[j] ≤ C[i][j]   (для всіх i, j = 1..N)
```

Доведемо теорему про **слабку двоїстість** (англ. *weak duality*). Нехай `x` — будь-яке допустиме призначення, а `(u, v)` — будь-який допустимий вектор потенціалів. Тоді:

```text
∑[i=1..N] ∑[j=1..N] C[i][j] · x[i][j]
≥ ∑[i=1..N] ∑[j=1..N] (u[i] + v[j]) · x[i][j]    [бо C[i][j] ≥ u[i] + v[j] та x[i][j] ≥ 0]
= ∑[i=1..N] u[i] · (∑[j=1..N] x[i][j]) + ∑[j=1..N] v[j] · (∑[i=1..N] x[i][j])  [перегрупування доданків]
= ∑[i=1..N] u[i] · 1 + ∑[j=1..N] v[j] · 1        [бо суми за рядками та стовпцями дорівнюють 1]
= ∑[i=1..N] u[i] + ∑[j=1..N] v[j]                [тотожність суми потенціалів]
```

Слабка двоїстість математично гарантує, що значення цільової функції прямої задачі для будь-якого допустимого призначення завжди є верхньою оцінкою для будь-якої допустимої суми двоїстих потенціалів:

```text
W(x) ≥ D(u, v)
```

### Умови доповняльної нежорсткості та граф рівності

За теоремою про сильну двоїстість лінійного програмування допустимий вектор `x*` прямої задачі та допустимий вектор `(u*, v*)` двоїстої задачі є одночасно оптимальними тоді й лише тоді, коли їхні значення цільових функцій строго збігаються:

```text
∑[i=1..N] ∑[j=1..N] C[i][j] · x*[i][j] = ∑[i=1..N] u*[i] + ∑[j=1..N] v*[j]
```

Розглянемо різницю між лівою та правою частинами цієї рівності:

```text
∑[i=1..N] ∑[j=1..N] (C[i][j] - u*[i] - v*[j]) · x*[i][j] = 0
```

Оскільки для будь-якої допустимої пари виконується `x*[i][j] ≥ 0` та `C[i][j] - u*[i] - v*[j] ≥ 0`, кожен окремий доданок цієї подвійної суми є невід'ємним числом. Сума невід'ємних доданків дорівнює нулю тоді й лише тоді, коли **кожен доданок дорівнює нулю окремо**.

Звідси отримуємо класичні **умови доповняльної нежорсткості** (англ. *complementary slackness*):

```text
x*[i][j] > 0  ⇒  u*[i] + v*[j] = C[i][j]
```

Це означає, що у будь-якому оптимальному призначенні ребра `(i, j)` можуть бути обрані (`x*[i][j] = 1`) **виключно** з графа рівності, де редукована вартість дорівнює строго нулю:

```text
C'[i][j] = C[i][j] - u*[i] - v*[j] = 0
```

### Доведення теореми Еґерварі (1931)

Теорема Єньо Еґерварі встановлює конструктивний міст між комбінаторним паросполученням та двоїстими потенціалами:

> **Теорема Еґерварі.** Максимальна вага досконалого паросполучення в повному зваженому дводольному графі дорівнює мінімальній сумі потенціалів `∑ u[i] + ∑ v[j]`, які задовольняють умову двоїстої допустимості `u[i] + v[j] ≤ C[i][j]`.

#### Доведення:
1. За слабкою двоїстістю будь-яке досконале паросполучення має вагу, не меншу за будь-яку допустиму суму потенціалів.
2. Нехай поточне паросполучення `M` у графі рівності `G_eq` містить менше ніж `N` ребер (`|M| < N`).
3. Запустимо пошук доповнюючого шляху від деякого вільного рядка `i_0`. Нехай `S ⊂ U` — множина досяжних рядків у змінному дереві, а `T ⊂ V` — множина досяжних стовпців.
4. Оскільки в `G_eq` немає доповнюючого шляху, усі стовпці з `T` насичені паросполученням з вершинами з `S \ {i_0}`. Отже, потужність множин задовольняє рівність `|S| = |T| + 1 > |T|`.
5. Обчислимо мінімальну дельту між відвіданими рядками та невідвіданими стовпцями:
   ```text
   Δ = min[i ∈ S, j ∉ T] (C[i][j] - u[i] - v[j])
   ```
   Оскільки між `S` та `V \ T` у графі `G_eq` ребер за визначенням немає, різниця `C[i][j] - u[i] - v[j] > 0` для всіх таких пар. Оскільки множина пар скінченна, звідси строго випливає `Δ > 0`.
6. Виконаємо коригування потенціалів:
   - `u[i] := u[i] + Δ` для всіх `i ∈ S`
   - `v[j] := v[j] - Δ` для всіх `j ∈ T`
7. Обчислимо зміну сумарного значення двоїстої функції:
   ```text
   ∑ u_new[i] + ∑ v_new[j]
   = (∑ u_old[i] + Δ · |S|) + (∑ v_old[j] - Δ · |T|)   [групування змін]
   = (∑ u_old[i] + ∑ v_old[j]) + Δ · (|S| - |T|)      [винесення спільного множника]
   = (∑ u_old[i] + ∑ v_old[j]) + Δ · 1 > ∑ u_old[i] + ∑ v_old[j]  [бо |S| - |T| = 1 та Δ > 0]
   ```
8. Сума потенціалів строго монотонно зростає на кожній ітерації перерахунку. Оскільки кількість можливих підмножин вершин у графі скінченна, а на кожному кроці до графа додається щонайменше одне нове ребро, алгоритм не може зациклитися і за скінченне число кроків знайде досконале паросполучення, де досягається точна рівність прямої та двоїстої цільових функцій.
