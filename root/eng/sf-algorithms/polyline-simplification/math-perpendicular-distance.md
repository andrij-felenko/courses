# 🧮 Геометрія відстані від точки до відрізка на площині

Обчислення точної мінімальної відстані від довільної точки `P` до обмеженого відрізка `AB` є критичним обчислювальним ядром алгоритмів спрощення ламаних: заміна проекції на нескінченну пряму обмеженим відрізком запобігає грубим топологічним спотворенням на гострих кутах і замкнених контурах. Наївна підстановка формули відстані до нескінченної прямої дає хибний нульовий результат для точок, що лежать на продовженні прямої далеко за межами відрізка, що призводить до неконтрольованого видалення важливих вершин.

## Векторна параметризація відрізка та розбиття площини на зони Вороного

Нехай на евклідовій площині задано відрізок із початком у точці `A = (x_A, y_A)` та кінцем у точці `B = (x_B, y_B)`. Будь-яка точка `S(t)` на прямій, що проходить крізь `A` та `B`, описується векторним рівнянням через дійсний скалярний параметр `t`:

```
S(t) = A + t · (B − A)
```

Для відрізка параметр `t` обмежений замкненим інтервалом `t ∈ [0, 1]`:
* `t = 0` відповідає початковій вершині `A`;
* `t = 1` відповідає кінцевій вершині `B`;
* `0 < t < 1` відповідає строго внутрішнім точкам відрізка `AB`.

Введемо два вектори на площині:
1. Вектор напрямку відрізка `v = B − A = (x_B − x_A, y_B − y_A)`.
2. Вектор зміщення від початку відрізка до тестової точки `w = P − A = (x_P − x_A, y_P − y_A)`.

Квадрат довжини відрізка `|v|²` дорівнює:

```
|v|² = v_x² + v_y² = (x_B − x_A)² + (y_B − y_A)²
```

Геометрично відрізок `AB` розбиває всю навколишню площину на три неперетинні області тяжіння (зони діаграми Вороного для відрізка):
* **Півплощина вершини A:** область точок, для яких найближчою частиною відрізка є сам вузол `A`. Вона відокремлена прямою, перпендикулярною до `AB`, що проходить крізь `A`.
* **Півплощина вершини B:** область точок, для яких найближчою є вершина `B`. Відокремлена перпендикуляром до `AB`, що проходить крізь `B`.
* **Центральна смуга (ортогональний шар):** простір між двома опорними перпендикулярами, де найближча точка лежить строго на тілі відрізка і є основою опущеного перпендикуляра.

Якщо `|v|² = 0`, відрізок вироджується в одну точку (`A = B`). У цьому окремому випадку центральна смуга зникає, а відстань від точки `P` до відрізка дорівнює звичайній евклідовій відстані від `P` до `A`:

```
dist(P, AB) = |w| = √((x_P − x_A)² + (y_P − y_A)²)
```

## Виведення параметра проекції через мінімізацію квадрата відстані

Знайдемо значення параметра `t`, при якому відстань від точки `P` до точки `S(t)` на прямій є мінімальною. Квадрат відстані між точкою `P` та точкою прямої `S(t)` задається функцією `f(t)`:

```
f(t)
= |P − S(t)|²              [означення квадрата евклідової норми]
= |P − (A + t·v)|²         [підстановка параметричного рівняння прямої S(t)]
= |(P − A) − t·v|²         [групування векторів]
= |w − t·v|²               [позначення вектора w = P − A]
= (w − t·v) · (w − t·v)    [квадрат норми через скалярний добуток]
= |w|² − 2·t·(w · v) + t²·|v|²  [розкриття дужок за лінійністю скалярного добутку]
```

Функція `f(t)` є квадратичною параболою відносно `t` із додатною другою похідною `2·|v|² > 0`. Її мінімум досягається в точці, де перша похідна дорівнює нулю:

```
f'(t)
= d/dt (|w|² − 2·t·(w · v) + t²·|v|²)   [диференціювання за параметром t]
= −2·(w · v) + 2·t·|v|²                 [похідна лінійного та квадратичного членів]
= 0                                     [умова екстремуму]
```

Звідси отримуємо аналітичний вираз для оптимального параметра проекції `t`:

```
t = (w · v) / |v|²
= (w_x · v_x + w_y · v_y) / (v_x² + v_y²)
```

Чисельник `w · v` є скалярним добутком векторів, що відображає величину проекції вектора `w` на напрямок вектора `v`. Знаменник `|v|²` нормує значення на квадрат довжини відрізка.

## Три геометричні режими та затискання параметра (Clamping)

Оскільки шукається найближча точка саме на обмеженому відрізку, а не на нескінченній прямій, параметр `t` має бути затиснутий у межі відрізка `[0, 1]`. Виникає три взаємовиключні випадки:

### 1. Проекція ліворуч від відрізка (`t ≤ 0`)
Скалярний добуток `w · v ≤ 0`. Це означає, що кут між вектором відрізка `v` та вектором `w` є тупим або прямим (`θ ≥ 90°`). Ортогональна проекція точки `P` падає на промінь поза вершиною `A`.

Найближчою точкою відрізка є вершина `A`. Квадрат відстані обчислюється безпосередньо як довжина вектора `w`:

```
dist²(P, AB) = |P − A|² = w_x² + w_y² = (x_P − x_A)² + (y_P − y_A)²
```

### 2. Проекція праворуч від відрізка (`t ≥ 1`)
Значення `w · v ≥ |v|²`. Проекція точки `P` виходить за межі вершини `B` вздовж напрямку відрізка.

Найближчою точкою відрізка є вершина `B`. Квадрат відстані обчислюється як відстань між точками `P` та `B`:

```
dist²(P, AB) = |P − B|² = (x_P − x_B)² + (y_P − y_B)²
```

### 3. Ортогональна проекція всередині відрізка (`0 < t < 1`)
Основа перпендикуляра `H = S(t) = A + t·v` лежить строго на відрізку `AB`. Мінімальна відстань дорівнює довжині опущеного перпендикуляра `|P − H|`.

## Обчислення ортогональної відстані через псевдовекторний добуток

Для внутрішнього випадку (`0 < t < 1`) довжину перпендикуляра можна обчислити безпосередньо через площу паралелограма, натягнутого на вектори `w` та `v`.

У двовимірному просторі кососимметричний псевдовекторний добуток (z-компонента тривимірного векторного добутку) векторів `w` та `v` дорівнює орієнтованій площі паралелограма:

```
w × v = det [w_x  w_y] = w_x · v_y − w_y · v_x
            [v_x  v_y]
```

З геометричного змісту векторного добутку:

```
|w × v| = |w| · |v| · |sin θ|
```

Оскільки висота трикутника `h`, опущена з точки `P` на пряму `AB`, дорівнює `h = |w| · |sin θ|`, маємо:

```
h
= |w| · |sin θ|               [висота прямокутного трикутника]
= (|w| · |v| · |sin θ|) / |v| [множення та поділ на норму |v|]
= |w × v| / |v|               [підстановка геометричного означення |w × v|]
= |w_x · v_y − w_y · v_x| / √(v_x² + v_y²) [алгебраїчний вираз у координатах]
```

Квадрат ортогональної відстані набуває вигляду раціонального дробу:

```
dist²(P, AB) = (w_x · v_y − w_y · v_x)² / (v_x² + v_y²)
```

## Нормальна форма прямої Гессе

Альтернативний погляд на обчислення відстані дає нормальне рівняння прямої у формі Людвіга Гессе. Якщо вектор напрямку відрізка `v = (v_x, v_y)` повернути на 90 градусів проти годинникової стрілки, отримаємо вектор нормалі `n = (−v_y, v_x)`. Нормований одиничний вектор нормалі дорівнює:

```
n_unit = (−v_y / |v|,  v_x / |v|)
```

Тоді пряма, що проходить крізь точки `A` та `B`, задається рівнянням:

```
(X − A) · n_unit = 0
```

Для довільної точки `P` скалярний добуток `(P − A) · n_unit = w · n_unit` безпосередньо дорівнює знаковій ортогональній відстані від точки `P` до прямої:

```
dist_signed = w · n_unit = (w_x · (−v_y) + w_y · v_x) / |v| = −(w_x · v_y − w_y · v_x) / |v|
```

Абсолютне значення цього виразу повністю збігається з висотою, отриманою через векторний добуток.

## Чисельна стійкість та усунення катастрофічного скорочення

При реалізації формули на комп'ютері виникають дві проблеми чисельної точності:

1. **Ділення на нуль або субнормальні числа:** Якщо довжина відрізка `|v|` надзвичайно мала (менше `1e-6` для координат у метрах або `1e-11` для географічних градусів), пряме обчислення `(w · v) / |v|²` може призвести до втрати порядку або переповнення розрядної сітки. У коді перед діленням ставиться порогова перевірка `|v|² < EPSILON_SQ`, при спрацьовуванні якої відрізок вважається виродженим у точку `A`.
2. **Катастрофічне скорочення розрядів (Catastrophic cancellation):** Якщо координати точок виражені у великих абсолютних числах (наприклад, координати проєкції UTM порядка `x ≈ 500 000` м, `y ≈ 5 400 000` м), різниця `w_x · v_y − w_y · v_x` містить добутки величин порядка `10¹²`. При звичайній 32-бітній арифметиці `float` (24 біти мантиси ≈ 7 десяткових знаків) відбувається повна втрата молодших розрядів. Тому всі геометричні зміщення `w = P − A` та `v = B − A` обов'язково обчислюються в 64-бітній точності `double` (53 біти мантиси ≈ 15–17 знаків), причому відносні координати беруться від початку відрізка `A`, а не від глобального початку координат.

## Квадратичне порівняння без обчислення квадратного кореня

В алгоритмах спрощення ламаних (зокрема в алгоритмі Дугласа–Пекера) внутрішній цикл мільйони разів порівнює відстань `dist` кожної проміжної точки з порогом допуску `ε` (точність `epsilon`):

```
dist > ε ⟺ dist² > ε²
```

Оскільки операція вилучення квадратного кореня `sqrt()` у 5–15 разів повільніша за множення й додавання на сучасних мікропроцесорах, у коді використовується виключно порівняння квадратів відстаней:

```
(w_x · v_y − w_y · v_x)² > ε² · (v_x² + v_y²)
```

Такий підхід позбавляє внутрішній цикл як від інструкції `sqrt()`, так і від ділення з плаваючою комою, перетворюючи обчислення на кілька базових операцій `FMA` (Fused Multiply-Add), що виконуються процесором за 1–2 такти.
