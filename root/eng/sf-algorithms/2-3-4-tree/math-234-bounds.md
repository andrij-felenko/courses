# 🧮 Математичний аналіз висоти та ємності 2-3-4 дерев

Геометрична досконалість 2-3-4 дерева ґрунтується на інваріанті абсолютної рівності глибини всіх листкових вузлів. На відміну від звичайних бінарних дерев пошуку, де дисбаланс висот гілок може призводити до деградації топології до лінійного списку `O(N)`, 2-3-4 дерево регулює свою просторову конфігурацію синхронно по всій ширині структури. Дерево збільшує свою висоту виключно тоді, коли розщеплюється кореневий вузол, і зменшує висоту лише тоді, коли корінь зливається зі своїми безпосередніми нащадками.

Нижче наведено строгий математичний аналіз геометричних характеристик, меж висоти, амортизаційної складності операцій за методом потенціалів, моделі введення-виведення Aggarwal-Vitter та ймовірнісного розподілу типів вузлів.

---

## Границі кількості ключів залежно від висоти

Нехай висота дерева `h` визначається як кількість ребер на шляху від кореня до довільного листка. Дерево, що складається з одного-єдиного кореневого вузла, має висоту `h = 0`. Якщо корінь має дітей-листків, висота дорівнює `h = 1`. Загальна кількість рівнів вузлів у дереві висоти `h` дорівнює `h + 1` (від рівня `0` для кореня до рівня `h` для листків).

### 1. Максимальна ємність дерева (найнижча висота)

Дерево фіксованої висоти `h` вміщує максимально можливу кількість ключів тоді і тільки тоді, коли кожен внутрішній та листовий вузол є максимально заповненим — тобто 4-вузлом (містить рівно 3 ключі та має 4 дочірні вказівники).

На рівні `0` (корінь) знаходиться `1` вузол, що містить `3` ключі.  
На рівні `1` знаходиться `4¹ = 4` вузли, кожен з яких містить `3` ключі (загалом `3 · 4` ключів).  
На довільному проміжному рівні `i` (де `0 ≤ i ≤ h`) знаходиться `4ⁱ` вузлів, кожен з яких містить `3` ключі.

Загальна кількість ключів `N_max(h)` є сумою скінченної геометричної прогресії:

```
N_max(h)
= ∑[i=0..h] (3 · 4ⁱ)                 [сума ключів на всіх рівнях від 0 до h]
= 3 · ∑[i=0..h] 4ⁱ                   [винесення константи 3 за знак суми]
= 3 · ((4^(h+1) - 1) / (4 - 1))      [формула суми геометричної прогресії: (q^(n+1)-1)/(q-1)]
= 3 · ((4^(h+1) - 1) / 3)            [обчислення знаменника 4 - 1 = 3]
= 4^(h+1) - 1                        [скорочення на множник 3]
```

Знайдемо мінімально можливу висоту `h_min` для дерева, що містить задану кількість ключів `N`:

```
N ≤ 4^(h_min + 1) - 1                [нерівність максимальної ємності]
N + 1 ≤ 4^(h_min + 1)                [додавання 1 до обох частин]
log₄(N + 1) ≤ h_min + 1              [логарифмування за основою 4]
h_min ≥ log₄(N + 1) - 1              [віднімання 1 від обох частин]
```

Оскільки висота є дискретним цілим числом, мінімальна висота дерева при заданій кількості ключів `N` визначається формулою:

```
h_min = ⌈log₄(N + 1)⌉ - 1            [округлення вгору для дискретної висоти]
```

У термінах кількості рівнів вузлів `L = h + 1`:

```
L_min = ⌈log₄(N + 1)⌉                [мінімальна кількість рівнів дерева]
```

### 2. Мінімальна ємність дерева (найвища висота)

Дерево фіксованої висоти `h` вміщує мінімально можливу кількість ключів тоді і тільки тоді, коли кожен внутрішній та листовий вузол містить мінімально допустиму кількість елементів — тобто є 2-вузлом (містить рівно 1 ключ та має 2 дочірні вказівники).

На рівні `0` (корінь) знаходиться `1` вузол, що містить `1` ключ.  
На рівні `1` знаходиться `2¹ = 2` вузли, кожен з яких містить `1` ключ.  
На довільному рівні `i` (де `0 ≤ i ≤ h`) знаходиться `2ⁱ` вузлів, кожен з яких містить `1` ключ.

Загальна кількість ключів `N_min(h)` обчислюється як сума степенів двійки:

```
N_min(h)
= ∑[i=0..h] (1 · 2ⁱ)                 [сума по одному ключу на кожен вузол]
= ∑[i=0..h] 2ⁱ                       [спрощення константного множника 1]
= (2^(h+1) - 1) / (2 - 1)            [формула суми геометричної прогресії для q = 2]
= 2^(h+1) - 1                        [знаменник 2 - 1 = 1]
```

Знайдемо максимально можливу висоту `h_max` для дерева, що містить `N` ключів:

```
N ≥ 2^(h_max + 1) - 1                [нерівність мінімальної ємності]
N + 1 ≥ 2^(h_max + 1)                [додавання 1 до обох частин]
log₂(N + 1) ≥ h_max + 1              [логарифмування за основою 2]
h_max ≤ log₂(N + 1) - 1              [віднімання 1 від обох частин]
```

Таким чином, максимальна висота 2-3-4 дерева строго обмежена логарифмом двійки:

```
h_max = ⌊log₂(N + 1)⌋ - 1            [округлення вниз для дискретної висоти]
```

Кількість рівнів вузлів `L = h + 1` не перевищує:

```
L_max = ⌊log₂(N + 1)⌋                [максимальна кількість рівнів дерева]
```

## Зв'язок між основами логарифмів та висотою

Скористаємося формулою переходу до іншої основи логарифма:

```
log₄(x)
= log₂(x) / log₂(4)                  [формула переходу до основи 2]
= log₂(x) / 2                        [обчислення log₂(4) = 2]
= 0.5 · log₂(x)                      [множення на коефіцієнт 0.5]
```

Підставивши цей вираз у межі висоти, отримуємо строгу двосторонню нерівність для висоти 2-3-4 дерева з `N` елементами:

```
0.5 · log₂(N + 1) - 1 ≤ h ≤ log₂(N + 1) - 1   [двостороннє логарифмічне обмеження висоти]
```

Це співвідношення доводить, що за будь-якого порядку вставки або вилучення елементів висота найглибшого листка не може перевищувати висоту найкоротшого більш ніж удвічі. 2-3-4 дерево володіє строго логарифмічною глибиною `Θ(log N)`.

## Амортизаційний аналіз операції розщеплення (метод потенціалів)

Під час вставки нового ключа алгоритм превентивно розщеплює кожен 4-вузол на шляху спуску. У найгіршому випадку, коли всі вузли від кореня до листка виявляються 4-вузлами, алгоритм виконає `h + 1` операцій розщеплення за одну вставку:

```
C_worst_insert = h + 1 ≤ log₂(N + 1)
```

Хоча найгірша одинична вставка виконує `O(log N)` розщеплень, їхня **амортизована кількість** (середня вартість на одну операцію у довгій послідовності) становить строго `O(1)`. Доведемо це за допомогою методу потенціалів Роберта Тарджана.

### Визначення потенціалу структури

Введемо функцію потенціалу `Φ(T)`, яка відображає конфігурацію дерева `T` у невід'ємне дійсне число:

```
Φ(T) = ∑[v ∈ T] φ(v)                 [сумарний потенціал усіх вузлів дерева]
```

Потенціал окремого вузла `v` задається залежно від його типу:
- `φ(v) = 2`, якщо `v` є 4-вузлом (накопичена енергія на майбутній спліт).
- `φ(v) = 0`, якщо `v` є 2-вузлом або 3-вузлом (стабільний стан).

Оскільки `φ(v) ≥ 0` для всіх вузлів, початковий потенціал порожнього дерева дорівнює `Φ(T₀) = 0`, а для будь-якого наступного стану `Φ(T_i) ≥ 0`.

### Амортизована вартість розщеплення одного вузла

Розглянемо, як змінюється потенціал при розщепленні одного 4-вузла:
1. 4-вузол `v` з потенціалом `φ(v) = 2` знищується.
2. Створюються два нові 2-вузли, кожен з яких має потенціал `φ = 0`. Зміна потенціалу на рівні дітей становить `0 + 0 - 2 = -2`.
3. Середній ключ виштовхується вгору у батьківський вузол `p`:
   - Якщо батько `p` був 2-вузлом (`φ(p) = 0`), він стає 3-вузлом (`φ(p') = 0`). Зміна потенціалу батька дорівнює `0 - 0 = 0`.
   - Якщо батько `p` був 3-вузлом (`φ(p) = 0`), він стає 4-вузлом (`φ(p') = 2`). Зміна потенціалу батька дорівнює `2 - 0 = +2`.

Таким чином, максимальна зміна потенціалу внаслідок одного розщеплення складає:

```
ΔΦ_split ≤ -2 + 2 = 0                [компенсація потенціалу при переході 3-вузла в 4-вузол]
```

Якщо ж батьківський вузол був 2-вузлом, зміна потенціалу є строго від'ємною:

```
ΔΦ_split = -2 + 0 = -2               [чисте вивільнення потенціалу]
```

### Підсумкова амортизована вартість вставки

Нехай операція вставки зустрічає ланцюжок із `k` послідовних 4-вузлів (де `k ≥ 0`), які всі розщеплюються, після чого новий ключ додається у листок (який перетворюється з 2-вузла на 3-вузол або з 3-вузла на 4-вузол).

Фактична вартість операції (кількість структурних модифікацій):

```
c_actual = k + 1                     [k сплітів + 1 фінальна вставка ключа]
```

Зміна потенціалу структури під час цієї послідовності:
- Кожен із перших `k - 1` сплітів виштовхує ключ у вищий 4-вузол, який перед тим уже був розщеплений (тобто став 2-вузлом чи 3-вузлом), тому сумарна зміна потенціалу від `k` сплітів становить щонайбільше `-2k + 2(k - 1) = -2`.
- Фінальна вставка ключа в листок може перетворити 3-вузол на 4-вузол, додавши не більше ніж `+2` до потенціалу.

Загальна зміна потенціалу:

```
ΔΦ = Φ(T_новий) - Φ(T_старий)
≤ -2k + 2(k - 1) + 2
= -2k + 2k - 2 + 2
= 0                                  [сумарна зміна потенціалу компенсує спліти]
```

Амортизована вартість вставки `a_insert` визначається за формулою:

```
a_insert
= c_actual + ΔΦ                      [визначення амортизованої вартості за Тарджаном]
≤ (k + 1) + (2 - 2k)                 [підстановка фактичної вартості та оцінки ΔΦ]
= 3 - k                              [спрощення виразу]
≤ 3 = O(1)                           [константна амортизована верхня межа]
```

Це доводить, що незалежно від довжини шляху спуску середня кількість розщеплень на одну вставку становить не більше `O(1)`.

## Амортизаційний аналіз вилучення (потенціал дефіциту)

Аналогічний математичний апарат застосовується для доведення константної амортизованої вартості операцій вилучення.

Введемо функцію дефіцитного потенціалу `Ψ(T)`:

```
Ψ(T) = ∑[v ∈ T] ψ(v)                 [сума потенціалів дефіциту всіх вузлів]
```

де значення `ψ(v)` відображає вразливість вузла до виникнення дефіциту ключів:
- `ψ(v) = 1`, якщо `v` є 2-вузлом (знаходиться за один крок від underflow).
- `ψ(v) = 0`, якщо `v` є 3-вузлом або 4-вузлом (безпечний стан).

Розглянемо дві базові операції відновлення ємності при спуску:

1. **Запозичення (Rotate / Borrow):** 2-вузол перетворюється на 3-вузол (`1 -> 0`), а сусідній 3-вузол стає 2-вузлом (`0 -> 1`) або 4-вузол стає 3-вузлом (`0 -> 0`). Загальна зміна потенціалу `ΔΨ ≤ 0`.
2. **Злиття (Merge):** Два 2-вузли (`ψ = 1 + 1 = 2`) та роздільник батька зливаються в один 4-вузол (`ψ = 0`). Якщо батько був 3-вузлом, він стає 2-вузлом (`ψ = +1`). Зміна потенціалу: `ΔΨ = 0 + 1 - 2 = -1`.

Звідси випливає, що кожне каскадне злиття зменшує потенціал системи на одиницю, покриваючи витрати на виконання злиття:

```
a_delete = c_delete + ΔΨ = O(1)
```

Середня кількість модифікацій вузлів при вилученні елемента є строго константною `O(1)`.

## Ймовірнісний розподіл типів вузлів при випадкових вставках

У практичних застосуваннях ключі надходять у випадковому порядку. Дослідження Ендрю Яо (Andrew Yao, 1978) та Роберта Седжвіка щодо поведінки B-дерев малого порядку доводять, що структура прямує до стаціонарного розподілу вузлів.

Нехай `p₂`, `p₃` та `p₄` позначають асимптотичні частки 2-вузлів, 3-вузлів та 4-вузлів у дереві великого розміру `N → ∞`.

При випадковій вставці ключ потрапляє у кожен із `N + 1` міжключових інтервалів із рівною ймовірністю `1 / (N + 1)`. Ймовірність попадання в листок пропорційна кількості його вихідних інтервалів:
- 2-вузол має `2` інтервали (вага 2).
- 3-вузол має `3` інтервали (вага 3).
- 4-вузол має `4` інтервали (вага 4).

Розв'язуючи систему диференціальних рівнянь марковського процесу переходів між станами вузлів:

```
dp₂/dt = 2 · p₄ - 2 · p₂             [поява 2-вузлів від спліту 4-вузлів мінус переходи 2->3]
dp₃/dt = 2 · p₂ - 3 · p₃             [поява 3-вузлів від 2-вузлів мінус переходи 3->4]
dp₄/dt = 3 · p₃ - 4 · p₄             [поява 4-вузлів від 3-вузлів мінус спліти 4->2]
```

У стаціонарному стані `dp/dt = 0`, разом із умовою нормування ймовірностей `p₂ + p₃ + p₄ = 1`, отримуємо стаціонарні частки:

```
p₂ = 2 / (2 + 3 + 4 - k_norm) ≈ 0.444   (44.4% 2-вузлів)
p₃ = 3 / (2 + 3 + 4 - k_norm) ≈ 0.333   (33.3% 3-вузлів)
p₄ = 4 / (2 + 3 + 4 - k_norm) ≈ 0.222   (22.2% 4-вузлів)
```

### Середня ємність вузла та щільність пам'яті

Очікувана середня кількість ключів у вузлі при стаціонарному випадковому заповненні становить:

```
E[keys]
= 1 · p₂ + 2 · p₃ + 3 · p₄
= 1 · 0.444 + 2 · 0.333 + 3 · 0.222
= 0.444 + 0.666 + 0.666
= 1.776 ключів на вузол
```

Оскільки максимальна ємність вузла становить 3 ключі, коефіцієнт корисного використання пам'яті (англ. *storage utilization*) у 2-3-4 дереві зі статичними масивами становить:

```
U = E[keys] / 3 = 1.776 / 3 ≈ 0.592  (59.2%)
```

Це пояснює, чому червоно-чорні дерева, які зберігають рівно 1 ключ на бінарний вузол і усувають 40% простою виділеної пам'яті, стали домінуючим варіантом представлення 2-3-4 дерев в оперативній пам'яті комп'ютерів.

## Зовнішня модель пам'яті (I/O Complexity за Aggarwal-Vitter)

У моделі ієрархічної пам'яті Аґґарвала-Віттера (англ. *Aggarwal-Vitter External Memory Model*) обчислювальна складність вимірюється кількістю операцій передачі блоків розміром `B` між швидкою оперативною пам'яттю `M` та повільним зовнішнім носієм (або кешем L3).

Кількість операцій введення-виведення `I/O(N)` для пошуку у B-дереві порядку `B` становить:

```
I/O_BTree(N) = O(log_B(N))           [логарифм за основою розміру дискового блоку]
```

Для 2-3-4 дерева основа логарифма є константною (`m = 4`), тому кількість операцій введення-виведення при зберіганні на диску становить:

```
I/O_234(N) = O(log₄(N)) = O(log₂(N)) [логарифм за основою 4]
```

Коефіцієнт прискорення B-дерева дискового масштабу над 2-3-4 деревом на зовнішніх носіях складає:

```
Speedup = log₂(N) / log_B(N) = log₂(B)
```

При типовому розмірі дискового сектора `B = 4096` байтів (вміщує `≈ 512` ключів) B-дерево виконує у `log₂(512) = 9` разів менше дискових звернень, ніж 2-3-4 дерево. Це строго обґрунтовує доменний поділ: 2-3-4 дерева орієнтовані на оперативну пам'ять та кеш-лінії ЦП, тоді як B-дерева високого порядку — на блоки накопичувачів.
