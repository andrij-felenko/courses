# 🧮 Математичне обґрунтування та доведення інваріантів редукції Монтгомері

Редукція Монтгомері спирається на точні властивості модулярної конгруентності та обмеження на діапазони проміжних сум у позиційних системах числення. У класичній модулярній арифметиці для обчислення остачі від ділення застосовують редукцію старших розрядів, що вимагає складного ділення на довільне число `N`. Метод Монтгомері натомість змінює алгебраїчний ізоморфізм кільця лишків, замінюючи незручний дільник `N` на двійкову основу `R = 2⁶⁴ᵏ`, ділення на яку зводиться до тривіального бітового зсуву.

Нижче наведено строге математичне виведення коректності базового оператора `REDC`, доведення квадратичної збіжності інверсії Гензеля, аналіз границі `U < 2N`, індуктивне обґрунтування інваріантів покрокового багаторозрядного алгоритму CIOS (Coarsely Integrated Operand Scanning) та аналіз релаксованих меж Вальтера.

## Початкові параметри та алгебраїчний базис

Нехай задано непарний модуль `N > 1`.
Обираємо допоміжну основу `R > N` таку, щоб взаємна простота виконувалася автоматично:

```
НСД(R, N) = 1
```

У комп'ютерній арифметиці основа `R` обирається як степінь основи машинного слова `b = 2⁶⁴`:

```
R = bᵏ = 2⁶⁴ᵏ
```

де `k` — кількість 64-бітних лімбів, необхідних для представлення числа `N` (тобто `bᵏ⁻¹ ≤ N < bᵏ`).

Оскільки `НСД(R, N) = 1`, за тотожністю Безу існують єдині цілі числа `R⁻¹` та `N'`, що задовольняють співвідношення в діапазоні `0 < R⁻¹ < N` та `0 < N' < R`:

```
R · R⁻¹ - N · N' = 1
```

Переходячи до конгруенцій за модулем `R`:

```
R · R⁻¹ - N · N' ≡ 1 (mod R)
-N · N' ≡ 1 (mod R)           [оскільки R · R⁻¹ ділиться на R]
N' ≡ -N⁻¹ (mod R)             [означення константи Монтгомері N']
```

Для багаторозрядної арифметики за базою `b = 2⁶⁴` повне число `N'` не обчислюють для всього `R = 2⁶⁴ᵏ`. Замість цього алгоритм редукції обробляє число по одному лімбу за крок, тому достатньо знати константу лише для молодшого машинного слова:

```
n0' = (-N[0]⁻¹) mod b
```

## Квадратична збіжність інверсії за лемою Гензеля

Обчислення `n0'` здійснюється без ділення за допомогою ітерацій Ньютона — Рафсона у 2-адичному кільці цілих чисел. 

Нехай ми шукаємо корінь функції `f(x) = 1/x - N[0] = 0`. Класична ітерація Ньютона має вигляд:

```
x_{k+1} = x_k - f(x_k) / f'(x_k) = x_k - (1/x_k - N[0]) / (-1/x_k²) = x_k · (2 - N[0] · x_k)
```

Доведемо за індукцією, що кожна ітерація подвоює кількість точних двійкових розрядів оберненого елемента.

**Лема про подвоєння точності:**
Якщо `N[0] · x_k ≡ 1 (mod 2^p)`, то `N[0] · x_{k+1} ≡ 1 (mod 2^{2p})`.

**Доведення:**
За умовою `N[0] · x_k = 1 + q · 2^p` для деякого цілого `q`. Розглянемо добуток для наступного наближення `x_{k+1} = x_k · (2 - N[0] · x_k)`:

```
N[0] · x_{k+1}
= N[0] · x_k · (2 - N[0] · x_k)        [означення ітерації Ньютона]
= (1 + q · 2^p) · (2 - (1 + q · 2^p))  [підстановка 1 + q · 2^p]
= (1 + q · 2^p) · (1 - q · 2^p)        [спрощення другого множника]
= 1 - q² · 2^{2p}                      [формула різниці квадратів]
≡ 1 (mod 2^{2p})                       [оскільки q² · 2^{2p} ділиться на 2^{2p}]
```

Оскільки модуль `N` непарний, `N[0] ≡ 1 (mod 2)`, тому початкове наближення `x₀ = 1` задовольняє умову для `p = 1`. Застосовуючи формулу послідовно, отримуємо точність:
1. Крок 1: `p = 2` біти
2. Крок 2: `p = 4` біти
3. Крок 3: `p = 8` бітів
4. Крок 4: `p = 16` бітів
5. Крок 5: `p = 32` біти
6. Крок 6: `p = 64` біти

Таким чином, рівно за 6 ітерацій множення та віднімання 64-бітне значення `n0' = -x₆ mod 2⁶⁴` обчислюється абсолютно точно.

## Теорема 1: Коректність оператора REDC

Нехай задано ціле число `T` у діапазоні `0 ≤ T < R · N`.
Оператор редукції Монтгомері `REDC(T)` обчислює коефіцієнт:

```
m = (T · N') mod R
```

та формує значення:

```
U = (T + m · N) / R
```

### Доведення подільності націло

Покажемо, що вираз `T + m · N` ділиться на `R` без остачі:

```
(T + m · N) mod R
= (T + ((T · N') mod R) · N) mod R   [підстановка m]
= (T + T · N' · N) mod R             [властивість модулярного множення]
= (T · (1 + N' · N)) mod R           [винесення T за дужки]
= (T · (1 + (-N⁻¹) · N)) mod R       [підстановка N' ≡ -N⁻¹ mod R]
= (T · (1 - 1)) mod R                [N⁻¹ · N ≡ 1 mod R]
= 0 mod R                            [T · 0 = 0]
```

Отже, остача від ділення `T + m · N` на `R` дорівнює нулю. Це означає, що ділення `(T + m · N) / R` є точною цілочисельною операцією, яка виконується простим бітовим зсувом праворуч на `64k` бітів без втрати дробової частини.

### Доведення модулярної еквівалентності

Покажемо, що `U ≡ T · R⁻¹ (mod N)`:

```
U · R = T + m · N
U · R ≡ T + m · 0 (mod N)     [оскільки m · N ділиться на N]
U · R ≡ T (mod N)             [спрощення правої частини]
U ≡ T · R⁻¹ (mod N)           [множення обох частин на R⁻¹ mod N]
```

## Теорема 2: Верхня межа U та достатність одного віднімання

Покажемо, що якщо вхідне число `T` задовольняє умову `0 ≤ T < R · N`, то результат `U` суворо обмежений зверху: `U < 2N`.

Оскільки `m = (T · N') mod R`, за означенням залишку маємо:

```
0 ≤ m ≤ R - 1
```

Використаємо верхні оцінки для `T` та `m`:

```
T + m · N
< R · N + (R - 1) · N         [оскільки T < R · N та m ≤ R - 1]
= R · N + R · N - N           [розкриття дужок]
= 2 · R · N - N               [групування доданків]
< 2 · R · N                   [оскільки N > 0]
```

Ділимо всю нерівність на додатне число `R`:

```
U = (T + m · N) / R < (2 · R · N) / R = 2N
```

Оскільки `T ≥ 0`, `m ≥ 0` та `N > 0`, значення `U` є невід'ємним:

```
0 ≤ U < 2N
```

Звідси випливає фундаментальний наслідок:
- Якщо `0 ≤ U < N`, то `U` вже є канонічною остачею `(T · R⁻¹) mod N`.
- Якщо `N ≤ U < 2N`, то для отримання канонічної остачі достатньо виконати рівно **одне** віднімання: `U - N < 2N - N = N`.

Жодного ділення чи циклічного віднімання не потрібно.

## Теорема 3: Інваріант покрокового алгоритму CIOS

В алгоритмі CIOS редукція інтегрована в зовнішній цикл множення за операндом `A`. Операнди `A` та `B` мають довжину `k` лімбів за основою `b = 2⁶⁴`, причому `A < N` та `B < N`.

Алгоритм підтримує акумулятор `T`, що ініціалізується нулем (`T₀ = 0`). На кожному кроці `i` (від `0` до `k - 1`):
1. Додається добуток чергового лімба: `T' = Tᵢ + A[i] · B`.
2. Обчислюється коефіцієнт редукції для молодшого слова: `mᵢ = (T'[0] · n0') mod b`.
3. Додається кратне модуля і виконується зсув на один лімб: `Tᵢ₊₁ = (T' + mᵢ · N) / b`.

### Індуктивне доведення обмеженості акумулятора

Доведемо за математичною індукцією, що на кожній ітерації `i` значення акумулятора задовольняє інваріант:

```
Tᵢ < 2N
```

**База індукції (`i = 0`):**
На початку `T₀ = 0 < 2N` — умова виконується.

**Індукційний перехід (`i → i + 1`):**
Припустимо, що `Tᵢ < 2N`. Оцінимо проміжне значення `T'`:

```
T' = Tᵢ + A[i] · B
```

Оскільки `A[i] ≤ b - 1` (одне машинне слово) та `B < N`:

```
T' < 2N + (b - 1) · N = (b + 1) · N
```

Тепер оцінимо значення `Tᵢ₊₁` після додавання `mᵢ · N` (де `mᵢ ≤ b - 1`):

```
Tᵢ₊₁ = (T' + mᵢ · N) / b
< ((b + 1) · N + (b - 1) · N) / b   [підстановка верхніх меж для T' та mᵢ]
= ((b + 1 + b - 1) · N) / b         [винесення N за дужки]
= (2b · N) / b                      [спрощення чисельника]
= 2N                                [скорочення на b]
```

Отже, `Tᵢ₊₁ < 2N`. Індукційний перехід доведено.

Після виконання всіх `k` ітерацій акумулятор містить:

```
Tₖ = (A · B · R⁻¹) mod N  або  (A · B · R⁻¹) mod N + N
```

Оскільки `Tₖ < 2N`, остаточний результат отримується за одне умовне віднімання:

```
якщо Tₖ ≥ N, то повернути Tₖ - N; інакше повернути Tₖ
```

Розмір акумулятора під час усіх обчислень не перевищує `2N < 2 · bᵏ`, тому для зберігання `T` достатньо рівно `k + 2` машинних слів (включно зі словами для прапорців перенесення), що дозволяє повністю утримувати робочий стан у регістрах процесора.

## Релаксовані межі Вальтера та виключення проміжних віднімань

У роботах Коліна Вальтера (Colin Walter, 1999) було доведено, що якщо допоміжну основу обрати дещо більшою за модуль, а саме:

```
R > 4N
```

то умовне фінальне віднімання `U = U - N` можна повністю виключити з усіх проміжних множень у циклі модулярного піднесення до степеня.

Якщо операнди задовольняють послаблену нерівність `A < 2N` та `B < 2N`, то їхній добуток становить:

```
T = A · B < 4N² < R · N       [оскільки 4N < R]
```

Тоді редукція `U = REDC(T)` дає:

```
U = (T + m · N) / R < (4N² + R · N) / R = 4N²/R + N < N + N = 2N
```

Це означає, що вихідне значення `U` автоматично задовольняє ту саму нерівність `U < 2N`, що й вхідні операнди. Завдяки цьому проміжні віднімання стають непотрібними: обчислення тривають у надлишковому діапазоні `[0, 2N)`, а єдине фінальне зведення `U mod N` виконується лише один раз після завершення всього експоненціювання. Це усуває будь-які варіації часу виконання та захищає алгоритм від атак за сторонніми каналами.
