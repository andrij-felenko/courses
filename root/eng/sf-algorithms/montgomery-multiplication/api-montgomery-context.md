# 📋 Програмний інтерфейс обчислювального контексту Монтгомері

Контекст Монтгомері інкапсулює попередньо обчислені параметри модуля — непарний модуль `N`, константу редукції `n0'`, константу переводу `R² mod N` та попередньо виділені буфери робочої пам'яті. Такий підхід усуває повторні динамічні виділення пам'яті в критичних циклах модулярного піднесення до степеня та гарантує сталий час виконання операцій.

## Архітектура та призначення обчислювального контексту

У криптографічних протоколах (RSA, Diffie-Hellman, ECDSA) операція модулярного множення виконується не ізольовано, а всередині довгих ланцюжків обчислень — передусім у циклах модулярного піднесення до степеня або скалярного множення точок еліптичної кривої. Для 2048-бітного ключа RSA одне піднесення до степеня вимагає понад 3000 модулярних множень за одним і тим самим модулем `N`.

Якщо виконувати попередні обчислення (пошук оберненого елемента `n0'`, розрахунок коефіцієнта переводу `R² mod N` та виділення тимчасових масивів під лімби) перед кожним окремим множенням, накладні витрати повністю знищать перевагу алгоритму Монтгомері над класичним діленням.

Обчислювальний контекст `montgomery_ctx_t` (у мові C) або клас `MontgomeryContext` (у мові C++) вирішує цю задачу шляхом розділення життєвого циклу на дві фази:
1. **Фаза ініціалізації (Setup phase)**: виконується один раз під час завантаження ключа або створення криптографічної сесії. Обчислюються константи `n0'`, `R² mod N` та алокуються робочі буфери фіксованого розміру.
2. **Фаза обчислень (Execution phase)**: виконує швидкі операції переведення операндів у форму Монтгомері, множення, піднесення до квадрата та зворотного переведення без жодного виділення пам'яті на купі (heap allocation) та без жодного класичного ділення.

## Життєвий цикл та діаграма станів

```
                  ┌─────────────────────────────────────┐
                  │   montgomery_ctx_init(N, limbs)     │
                  │   - Обчислення n0' = (-N[0]⁻¹) mod b│
                  │   - Обчислення R² mod N             │
                  │   - Виділення робочих буферів       │
                  └──────────────────┬──────────────────┘
                                     │
                                     ▼
                  ┌─────────────────────────────────────┐
                  │   montgomery_to_domain(X, X_bar)    │
                  │   X_bar = REDC(X · (R² mod N))      │
                  └──────────────────┬──────────────────┘
                                     │
                  ┌──────────────────┴──────────────────┐
                  │                                     │
                  ▼                                     ▼
  ┌───────────────────────────────┐     ┌───────────────────────────────┐
  │ montgomery_mul(A_bar, B_bar)  │     │ montgomery_sqr(A_bar, Res_bar)│
  │ Res = REDC(A_bar · B_bar)     │     │ Res = REDC(A_bar · A_bar)     │
  └───────────────┬───────────────┘     └───────────────┬───────────────┘
                  │                                     │
                  └──────────────────┬──────────────────┘
                                     │
                                     ▼
                  ┌─────────────────────────────────────┐
                  │  montgomery_from_domain(X_bar, X)   │
                  │  X = REDC(X_bar)                    │
                  └──────────────────┬──────────────────┘
                                     │
                                     ▼
                  ┌─────────────────────────────────────┐
                  │   montgomery_ctx_free(ctx)          │
                  │   Безпечне очищення буферів пам'яті │
                  └─────────────────────────────────────┘
```

## Алгоритм підготовки константи R² mod N

Для входу в простір Монтгомері число `A` множиться на `R mod N`. Проте пряме обчислення `(A · R) mod N` вимагало б ділення. Замість цього застосовують сам оператор редукції `REDC`:

```
REDC(A · (R² mod N)) = (A · R² · R⁻¹) mod N = (A · R) mod N = Ā
```

Таким чином, для швидкого переведення довільного числа в простір Монтгомері достатньо один раз під час ініціалізації обчислити константу `R² mod N`. Вона розраховується без загального дільника за допомогою `2k` кроків зсуву та умовного віднімання:
1. Початкове значення встановлюється в `X₀ = (2 · R) mod N = (2 · 2⁶⁴ᵏ) mod N` або формується з одиниці `X = 1`.
2. Виконується `128k` ітерацій подвоєння: `X = X + X`.
3. Якщо `X ≥ N`, виконується віднімання: `X = X - N`.

Ця процедура виконується виключно на етапі конструювання контексту і гарантує, що в подальших гарячих циклах жодна операція ділення не викликається.

## Специфікація інтерфейсу мовами C та C++

:::tabs
```c
#ifndef MONTGOMERY_API_H
#define MONTGOMERY_API_H

#include <stdint.h>
#include <stddef.h>
#include <stdbool.h>

/**
 * @brief Статуси виконання операцій контексту Монтгомері
 */
typedef enum {
    MONTGOMERY_OK               = 0,  /**< Успішне виконання */
    MONTGOMERY_ERR_INVALID_ARG  = -1, /**< Нульовий вказівник або некоректні розміри */
    MONTGOMERY_ERR_EVEN_MODULUS = -2, /**< Модуль N є парним (НСД(N, 2) != 1) */
    MONTGOMERY_ERR_ALLOC        = -3  /**< Помилка виділення динамічної пам'яті */
} montgomery_status_t;

/**
 * @brief Структура контексту Монтгомері
 */
typedef struct {
    size_t   k;        /**< Кількість 64-бітних лімбів модуля */
    uint64_t *n;       /**< Масив лімбів модуля N (розмір k) */
    uint64_t *r2;      /**< Константа R^2 mod N для входу в простір (розмір k) */
    uint64_t n0_prime; /**< Константа n0' = (-N[0]^(-1)) mod 2^64 */
    uint64_t *workspace; /**< Попередньо виділений робочий буфер (розмір k + 2) */
} montgomery_ctx_t;

/**
 * @brief Ініціалізація контексту Монтгомері
 * @param ctx Вказівник на структуру контексту
 * @param modulus Масив 64-бітних слів модуля (little-endian)
 * @param k Кількість слів у модулі
 * @return MONTGOMERY_OK у разі успіху, інакше код помилки
 */
montgomery_status_t montgomery_ctx_init(montgomery_ctx_t *ctx,
                                        const uint64_t *modulus,
                                        size_t k);

/**
 * @brief Звільнення ресурсів контексту
 * @param ctx Вказівник на контекст (пам'ять обнуляється)
 */
void montgomery_ctx_free(montgomery_ctx_t *ctx);

/**
 * @brief Переведення числа у форму Монтгомері: a_bar = (a * R) mod N
 * @param ctx Ініціалізований контекст
 * @param a Вхідне число в стандартному представленні (розмір k)
 * @param a_bar Вихідний буфер для образу Монтгомері (розмір k)
 */
montgomery_status_t montgomery_to_domain(const montgomery_ctx_t *ctx,
                                         const uint64_t *a,
                                         uint64_t *a_bar);

/**
 * @brief Зворотне переведення з форми Монтгомері: a = (a_bar * R^(-1)) mod N
 * @param ctx Ініціалізований контекст
 * @param a_bar Вхідне число у формі Монтгомері (розмір k)
 * @param a Вихідний буфер для стандартного числа (розмір k)
 */
montgomery_status_t montgomery_from_domain(const montgomery_ctx_t *ctx,
                                           const uint64_t *a_bar,
                                           uint64_t *a);

/**
 * @brief Множення у просторі Монтгомері: res_bar = (a_bar * b_bar * R^(-1)) mod N
 * @param ctx Ініціалізований контекст
 * @param a_bar Перший множник у формі Монтгомері (розмір k)
 * @param b_bar Другий множник у формі Монтгомері (розмір k)
 * @param res_bar Результат у формі Монтгомері (розмір k)
 */
montgomery_status_t montgomery_mul(const montgomery_ctx_t *ctx,
                                   const uint64_t *a_bar,
                                   const uint64_t *b_bar,
                                   uint64_t *res_bar);

/**
 * @brief Піднесення до квадрата у просторі Монтгомері: res_bar = (a_bar^2 * R^(-1)) mod N
 */
montgomery_status_t montgomery_sqr(const montgomery_ctx_t *ctx,
                                   const uint64_t *a_bar,
                                   uint64_t *res_bar);

/**
 * @brief Модулярне експоненціювання: res = (base^exp) mod N
 * @param ctx Ініціалізований контекст
 * @param base Основа в стандартному вигляді (розмір k)
 * @param exp Показник степеня (масив слів exp_limbs)
 * @param exp_limbs Кількість слів у показнику степеня
 * @param res Результат у стандартному вигляді (розмір k)
 */
montgomery_status_t montgomery_exp(const montgomery_ctx_t *ctx,
                                   const uint64_t *base,
                                   const uint64_t *exp,
                                   size_t exp_limbs,
                                   uint64_t *res);

#endif /* MONTGOMERY_API_H */
```

```cpp
#ifndef MONTGOMERY_CONTEXT_HPP
#define MONTGOMERY_CONTEXT_HPP

#include <cstdint>
#include <cstddef>
#include <vector>
#include <span>
#include <stdexcept>
#include <memory>

namespace bignum {

class MontgomeryContext {
public:
    /**
     * @brief Конструктор контексту Монтгомері
     * @param modulus Лімби модуля N (little-endian, модуль має бути непарним)
     * @throws std::invalid_argument якщо модуль парний або порожній
     */
    explicit MontgomeryContext(std::span<const uint64_t> modulus);

    ~MontgomeryContext() noexcept;

    // Заборона копіювання для запобігання дублювання робочих буферів
    MontgomeryContext(const MontgomeryContext&) = delete;
    MontgomeryContext& operator=(const MontgomeryContext&) = delete;

    // Дозвіл переміщення
    MontgomeryContext(MontgomeryContext&&) noexcept = default;
    MontgomeryContext& operator=(MontgomeryContext&&) noexcept = default;

    [[nodiscard]] size_t limb_count() const noexcept { return k_; }
    [[nodiscard]] uint64_t n0_prime() const noexcept { return n0_prime_; }
    [[nodiscard]] std::span<const uint64_t> modulus() const noexcept { return n_; }

    /**
     * @brief Переведення у простір Монтгомері
     */
    void to_domain(std::span<const uint64_t> a, std::span<uint64_t> a_bar) const;

    /**
     * @brief Зворотне переведення зі простору Монтгомері
     */
    void from_domain(std::span<const uint64_t> a_bar, std::span<uint64_t> a) const;

    /**
     * @brief Множення образів Монтгомері: res_bar = REDC(a_bar * b_bar)
     */
    void multiply(std::span<const uint64_t> a_bar,
                  std::span<const uint64_t> b_bar,
                  std::span<uint64_t> res_bar) const;

    /**
     * @brief Піднесення до квадрата у просторі Монтгомері
     */
    void square(std::span<const uint64_t> a_bar,
                std::span<uint64_t> res_bar) const;

    /**
     * @brief Сталочасове модулярне експоненціювання: res = base^exp mod N
     */
    void exponentiate(std::span<const uint64_t> base,
                      std::span<const uint64_t> exp,
                      std::span<uint64_t> res) const;

private:
    size_t k_;
    uint64_t n0_prime_;
    std::vector<uint64_t> n_;
    std::vector<uint64_t> r2_;
    mutable std::vector<uint64_t> workspace_;

    void compute_r2();
};

} // namespace bignum

#endif // MONTGOMERY_CONTEXT_HPP
```

## Детальний опис функцій та параметрів

### 1. `montgomery_ctx_init` / Конструктор
- **Призначення**: Перевіряє коректність модуля, виділяє пам'ять під копію модуля `n`, масив `r2` та внутрішній буфер `workspace` розміром `k + 2` лімби.
- **Вхідні вимоги**:
  - Вказівник `modulus` не повинен бути `NULL`, а довжина `k` має бути строго більшою за нуль.
  - Молодший біт модуля `modulus[0] & 1` обов'язково повинен дорівнювати `1` (непарне число). Якщо модуль парний, функція негайно повертає код `MONTGOMERY_ERR_EVEN_MODULUS` (або генерує виняток `std::invalid_argument` у C++).
- **Поведінка**: Обчислює `n0_prime` за 6 ітерацій Ньютона — Рафсона та формує масив `r2` довжиною `k` слів. Буфер `workspace` виділяється заздалегідь для уникнення алокацій у критичних секціях.

### 2. `montgomery_to_domain` / `to_domain`
- **Призначення**: Здійснює перетворення вхідного числа `A` зі стандартного представлення в образ Монтгомері `Ā = (A · R) mod N`.
- **Механізм**: Викликає оператор `REDC` для добутку `A` та попередньо обчисленої константи `R² mod N`:
  ```
  montgomery_mul_cios(a, ctx->r2, ctx->n, ctx->k, ctx->n0_prime, a_bar);
  ```
- **Складність**: `O(k²)` операцій множення машинних слів без жодного ділення. Вхідний масив `a` повинен містити значення, строго менше за `N`.

### 3. `montgomery_from_domain` / `from_domain`
- **Призначення**: Виконує зворотне перетворення образу Монтгомері `Ā` у звичайне модулярне число `A = (Ā · R⁻¹) mod N`.
- **Механізм**: Застосовує редукцію Монтгомері безпосередньо до числа `Ā`, розглядаючи його як число, помножене на 1:
  ```
  montgomery_mul_cios(a_bar, one_array, ctx->n, ctx->k, ctx->n0_prime, a);
  ```
- **Складність**: `O(k²)` операцій.

### 4. `montgomery_mul` / `multiply`
- **Призначення**: Обчислює образ добутку двох чисел `C̄ = (Ā · B̄ · R⁻¹) mod N = ((A · B) · R) mod N`.
- **Особливості**: Використовує алгоритм CIOS із попередньо виділеним буфером `workspace`. Усі операції виконуються в сталому часі, не створюючи витоків за часом виконання. Перекриття пам'яті (aliasing) між вихідним масивом `res_bar` та вхідними операндами дозволяється, оскільки результат спочатку збирається у внутрішньому буфері `workspace`.

### 5. `montgomery_sqr` / `square`
- **Призначення**: Спеціалізоване модулярне піднесення до квадрата `C̄ = (Ā² · R⁻¹) mod N`.
- **Оптимізація**: Оскільки операнди збігаються (`A = B`), половина недіагональних добутків `A[i] · A[j]` є симетричною, що дозволяє скоротити кількість 64-бітних множень майже вдвічі порівняно зі звичайним множенням.

### 6. `montgomery_exp` / `exponentiate`
- **Призначення**: Підносить число до степеня `(base^exp) mod N`.
- **Алгоритм**:
  1. Переводить `base` у простір Монтгомері: `base_bar = to_domain(base)`.
  2. Ініціалізує результат одиничним образом Монтгомері: `acc_bar = to_domain(1) = (R mod N)`.
  3. Проходить по бітах показника степеня `exp` від старшого до молодшого:
     - На кожному біті виконує піднесення до квадрата: `acc_bar = montgomery_sqr(acc_bar)`.
     - Якщо поточний біт дорівнює `1`, виконує множення: `acc_bar = montgomery_mul(acc_bar, base_bar)`.
  4. Наприкінці повертає результат зі простору Монтгомері: `res = from_domain(acc_bar)`.

## Інваріанти та вимоги до безпеки

1. **Непарність модуля**: Модуль `N` обов'язково повинен бути непарним (`N[0] & 1 == 1`). Якщо модуль парний, `НСД(N, 2⁶⁴) ≠ 1`, оберненого елемента за основою степеня двійки не існує, і `montgomery_ctx_init` повертає статус помилки `MONTGOMERY_ERR_EVEN_MODULUS`.
2. **Діапазон операндів**: Усі вхідні операнди `A` та `B` мають бути строго меншими за модуль `N` (`A < N`, `B < N`). Перевищення модуля призводить до порушення інваріанта `U < 2N` у проміжних редукціях.
3. **Сталий час виконання (Constant-Time)**: Реалізації методів `montgomery_mul`, `montgomery_sqr` та `montgomery_exp` не повинні містити розгалужень, які залежать від бітів приватного ключа чи проміжних даних операндів. Для цього умовне віднімання виконується бітовими масками.
4. **Очищення секретів**: Деструктор або функція `montgomery_ctx_free` виконують безпечне перезаписування нулями (secure zeroing) робочого буфера та збережених лімбів модуля для захисту від витоку секретних ключів у залишкових ділянках оперативної пам'яті.
5. **Вирівнювання пам'яті (Memory Alignment)**: Масиви лімбів `modulus`, `r2` та `workspace` вирівнюються за межею 64 байтів (розмір рядка кешу L1), що запобігає виникненню міжрядкових конфліктів доступу (cache-line splits) під час виконання векторних інструкцій SIMD та інструкцій `adcx`/`adox`.
