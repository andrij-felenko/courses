# 🧮 Похибка табличної апроксимації та вибір кроку

Коли безперервну математичну функцію замінюють скінченною таблицею замін, неминуче виникає похибка дискретизації. Збільшення кількості точок у таблиці зменшує похибку, але збільшує обсяг зайнятої пам'яті. Мета математичного аналізу — встановити точний зв'язок між кроком дискретизації сітки `h`, порядком інтерполяції, розрядністю квантування даних та максимальною гарантованою похибкою `E_max`.

### Ступінчаста апроксимація (нульовий порядок)

Найпростіший спосіб табличного пошуку — відкидання дробової частини або вибір найближчого вузла (метод нульового порядку). Проміжок визначення функції `[a, b]` розбивають рівномірною сіткою з кроком `h` на `N` вузлів:

```
x_i = a + i · h,   де i ∈ {0, 1, ..., N-1},   h = (b - a) / (N - 1)
```

Для довільного значення аргументу `x ∈ [x_i, x_{i+1}]` функція апроксимується константою лівого вузла: `f(x) ≈ f(x_i) = y_i`.

За теоремою Лагранжа про скінченні прирости (теорема про середнє значення), різниця значень функції на відрізку виражається через першу похідну в деякій проміжній точці `ξ ∈ (x_i, x)`:

```
|f(x) - f(x_i)|
= |f'(ξ) · (x - x_i)|        [за теоремою Лагранжа про скінченні прирости]
≤ max |f'(t)| · |x - x_i|    [оцінка максимумом похідної на відрізку]
≤ M₁ · h                     [оскільки |x - x_i| ≤ h, де M₁ = max |f'(t)|]
```

Якщо брати не лівий вузол, а найближчий до `x` вузол сітки (округлення до найближчого цілого), максимальна відстань до вузла становить `h / 2`, і гранична похибка зменшується вдвічі:

```
E₀(x) ≤ (M₁ / 2) · h
```

Похибка нульового порядку спадає лінійно зі зменшенням кроку: `O(h)`. Щоб подвоїти точність (зменшити похибку вдвічі), потрібно вдвічі збільшити розмір таблиці в пам'яті. У цифрових системах це означає, що кожен додатковий біт точності вимагає подвоєння обсягу таблиці, що експоненціально вичерпує кеш-пам'ять.

### Лінійна інтерполяція (перший порядок)

Лінійна інтерполяція з'єднує сусідні вузлові точки `(x_i, y_i)` та `(x_{i+1}, y_{i+1})` прямолінійним відрізком (хордою). Для точки `x ∈ [x_i, x_{i+1}]` апроксимуючий поліном першого степеня `L(x)` записується у вигляді:

```
L(x) = y_i + ((x - x_i) / h) · (y_{i+1} - y_i)
```

Введемо локальну нормалізовану координату `t = (x - x_i) / h`, де `t ∈ [0, 1]`. Тоді:

```
L(t) = (1 - t) · y_i + t · y_{i+1}
```

Виведемо формулу залишкового члена (похибки) `R(x) = f(x) - L(x)` через теорему Ролля. Для фіксованої точки `x` розглянемо допоміжну функцію `g(t)` на відрізку `[x_i, x_{i+1}]`:

```
g(t) = f(t) - L(t) - C · (t - x_i) · (t - x_{i+1})
```

Константу `C` обирають так, щоб `g(x) = 0`. Оскільки у вузлах `x_i` та `x_{i+1}` значення `f(t)` та `L(t)` збігаються, функція `g(t)` має щонайменше три нулі на відрізку: `x_i`, `x` та `x_{i+1}`.

За теоремою Ролля, перша похідна `g'(t)` має щонайменше два нулі між цими точками, а друга похідна `g''(t)` має щонайменше один нуль у деякій точці `ξ ∈ (x_i, x_{i+1})`.

Обчислимо другу похідну від `g(t)`:
1. `f''(t)` — друга похідна вихідної функції;
2. `L''(t) = 0` — друга похідна лінійної функції тотожно дорівнює нулю;
3. Друга похідна від `(t - x_i)(t - x_{i+1}) = t² - (x_i + x_{i+1})t + x_i x_{i+1}` дорівнює `2`.

Прирівнюючи `g''(ξ)` до нуля в точці `ξ`:

```
g''(ξ)
= f''(ξ) - 0 - 2 · C         [диференціювання компонентів g(t)]
= 0                          [за теоремою Ролля для другої похідної]
⇒ C = f''(ξ) / 2             [вираження константи C]
```

Підставляючи отримане значення `C` у рівняння `g(x) = 0`:

```
f(x) - L(x) = (f''(ξ) / 2) · (x - x_i) · (x_{i+1} - x)
```

Знайдемо максимум добутку `(x - x_i)(x_{i+1} - x)` на відрізку `[x_i, x_{i+1}]`. Виразимо через `t = (x - x_i)`:

```
P(t) = t · (h - t) = h · t - t²
P'(t) = h - 2 · t = 0  ⇒  t = h / 2
P_max = (h / 2) · (h - h / 2) = h² / 4
```

Підставляючи максимум добутку у вираз для похибки, отримуємо верхню теоретичну межу похибки лінійної інтерполяції:

```
E₁(x) ≤ (M₂ / 8) · h²,   де M₂ = max |f''(t)| на [a, b]
```

Похибка лінійної інтерполяції має порядок `O(h²)`. Це означає, що подвоєння розміру таблиці зменшує похибку **в 4 рази**, а збільшення таблиці в 10 разів зменшує похибку **в 100 разів**. Кожен додатковий біт точності вимагає збільшення таблиці лише в `√2 ≈ 1.41` раза замість двократного росту.

### Кубічна інтерполяція Ерміта (третій порядок)

Коли потрібна висока гладкість першої похідної (наприклад, у цифровому синтезі звуку або розрахунку траєкторій роботів), застосовують кубічні ермітові сплайни або інтерполяцію за чотирма сусідніми точками `y_{i-1}, y_i, y_{i+1}, y_{i+2}`.

Поліном третього степеня `H(t)` забезпечує неперервність як самих значень функції, так і її перших похідних у вузлах сітки. Залишковий член кубічної інтерполяції виводиться через четверту похідну `M₄ = max |f⁴(t)|`:

```
E₃(x) ≤ (M₄ / 384) · h⁴
```

Четвертий степінь `O(h⁴)` забезпечує надзвичайно стрімке спадання похибки: зменшення кроку сітки `h` вдвічі знижує похибку в **16 разів**. Завдяки цьому розмір таблиці можна скоротити до декількох десятків значень ціною виконання трьох інструкцій FMA (Fused Multiply-Add) для обчислення полінома за схемою Горнера.

### Похибка квантування дискретних значень

У реальних системах табличні значення зберігаються не як нескінченно точні математичні дійсні числа, а як цілі числа фіксованої розрядності (`int8_t`, `int16_t`, `int32_t`) або числа з плаваючою комою обмеженої мантиси (`float32`). Це вносить додаткову похибку квантування `E_q`.

Якщо крок квантування становить `q` (вага молодшого значущого розряду LSB), похибка округлення до найближчого рівня квантування обмежена величиною:

```
E_q ≤ q / 2 = 2^(-B - 1) · (Y_max - Y_min)
```

Повна похибка табличної апроксимації є сумою похибки інтерполяції методу та похибки квантування:

```
E_total(x) = E_interp(x) + E_q ≤ (M₂ / 8) · h² + q / 2
```

Інженерне правило збалансованого проектування вимагає, щоб похибка інтерполяції та похибка квантування були одного порядку величини: `(M₂ / 8) · h² ≈ q / 2`. Робити крок сітки `h` надмірно дрібним немає сенсу, якщо похибка тоне в шумі молодших розрядів квантування даних.

### Інженерний розрахунок: таблиця для функції `sin(x)`

Розглянемо практичну задачу: обчислення `f(x) = sin(x)` на інтервалі першого квадранта `[0, π/2]`. Оцінимо необхідний розмір таблиці для 16-бітної точності аудіосигналу (`ε = 2⁻¹⁶ ≈ 1.526 × 10⁻⁵`) та стандартної 32-бітної плаваючої коми IEEE-754 (`ε = 2⁻²³ ≈ 1.192 × 10⁻⁷`).

Знайдемо похідні функції:
- `f'(x) = cos(x) ⇒ M₁ = max |cos(x)| = 1` при `x = 0`;
- `f''(x) = -sin(x) ⇒ M₂ = max |-sin(x)| = 1` при `x = π/2`;
- `f⁴(x) = sin(x) ⇒ M₄ = max |sin(x)| = 1` при `x = π/2`.

#### Варіант 1: Ступінчаста апроксимація (без інтерполяції)

Використовуємо оцінку `E₀ ≤ (M₁ / 2) · h ≤ ε`:

```
h ≤ (2 · ε) / M₁ = 2 · ε
N = (π / 2) / h + 1 = π / (4 · ε) + 1
```

Розрахунок для 16-бітної точності (`ε = 1.526 × 10⁻⁵`):

```
N
= 3.14159 / (4 · 1.526 × 10⁻⁵) + 1   [підстановка π та ε]
= 3.14159 / 0.00006104 + 1           [обчислення знаменника]
≈ 51 471 елемент                     [округлення до найближчого цілого]
```

Для зберігання 16-бітних відліків знадобиться масив: `51 471 × 2 байти ≈ 100.5 КБ`. Така таблиця гарантовано витіснить дані з кешу першого рівня L1 багатьох мікроконтролерів і сигнальних процесорів.

#### Варіант 2: Таблиця з лінійною інтерполяцією

Використовуємо квадратичну оцінку `E₁ ≤ (M₂ / 8) · h² ≤ ε`:

```
h² ≤ (8 · ε) / M₂
h ≤ √(8 · ε / M₂)
```

Розрахунок кроку `h` та кількості вузлів `N` для 16-бітної точності:

```
h
≤ √(8 · 1.526 × 10⁻⁵ / 1.0)          [підстановка ε та M₂ = 1]
= √0.00012208                        [обчислення підкореневого виразу]
≈ 0.011049 рад                       [добування квадратного кореня]

N
= (π / 2) / h + 1                    [формула кількості вузлів сітки]
= 1.570796 / 0.011049 + 1            [підстановка значень π/2 та h]
≈ 144 вузли                          [округлення вгору]
```

Для таблиці з лінійною інтерполяцією достатньо всього **144 вузлів** (288 байтів пам'яті). Обсяг пам'яті скоротився в **357 разів** ціною виконання одного множення та двох віднімань.

Розрахунок для одинарної точності `float32` (`ε = 1.192 × 10⁻⁷`):

```
h
≤ √(8 · 1.192 × 10⁻⁷ / 1.0)          [підстановка ε для float32 та M₂]
= √0.0000009536                      [перемноження констант]
≈ 0.0009765 рад                      [добування квадратного кореня]

N
= (π / 2) / 0.0009765 + 1            [підстановка кроку h]
≈ 1610 вузлів                        [округлення вгору]
```

Для `float32` таблиця займає `1610 × 4 байти ≈ 6.28 КБ`, що повністю поміщається в швидкісний L1-кеш будь-якого сучасного процесора.

#### Варіант 3: Таблиця з кубічною інтерполяцією

Використовуємо оцінку четвертого порядку `E₃ ≤ (M₄ / 384) · h⁴ ≤ ε`:

```
h⁴ ≤ (384 · ε) / M₄
h ≤ (384 · ε)^(1/4)
```

Для `float32` (`ε = 1.192 × 10⁻⁷`):

```
h
≤ (384 · 1.192 × 10⁻⁷)^(1/4)         [підстановка констант у формулу]
= (0.00004577)^(1/4)                 [обчислення добутку]
≈ 0.08225 рад                        [добування кореня 4-го степеня]

N
= (π / 2) / 0.08225 + 1              [підстановка кроку h]
≈ 21 вузол                           [округлення вгору]
```

Усього **21 вузол** (84 байти пам'яті) забезпечує точність 7 значущих десяткових цифр на всьому діапазоні квадранта.

### Нерівномірні сітки: логарифмічний та експоненціальний крок

Якщо друга похідна функції `f''(x)` сильно змінюється на проміжку (наприклад, функція має крутий вигин біля нуля та майже лінійна на нескінченності, як `log(x)` або характеристика діода `exp(x)`), використання рівномірної сітки стає неекономічним.

Щоб мінімізувати сумарну похибку при фіксованій кількості точок `N`, локальний крок сітки `h(x)` повинен задовольняти умові рівномірного розподілу похибки:

```
h(x) ∝ 1 / √( |f''(x)| )
```

У зонах із високою кривизною (`|f''(x)|` велике) вузли розташовують густо, а в зонах низької кривизни — розріджено. Для апаратного обчислення індексу в нерівномірних сітках використовують або логарифмічне шкалювання входу через виділення порядку числа з плаваючою комою (`frexp` / бітове поле експоненти), або каскад із двох таблиць (ієрархічний індекс).

| **0** | Найближчий вузол | `O(h)` | `(M₁ / 2) · h` | ~13.1 МБ (не влізе в L3) | 0 АЛП (1 читання) |
