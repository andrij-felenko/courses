# 🧮 Метрична геометрія MBR: відстані MINDIST, MINMAXDIST та обмежувальні об'єми

Математичний апарат просторової індексації на основі R-дерев спирається на опуклу геометрію багатовимірних паралелепіпедів у евклідовому просторі `ℝⁿ` та метричні оцінки для відсікання гілок під час пошуку найближчих сусідів.

## Алгебраїчна структура мінімального обмежувального гіперпрямокутника (MBR)

Нехай `ℝⁿ` — `n`-вимірний евклідовий простір із декартовими координатами `x = (x₁, x₂, ..., xₙ)`. 

Мінімальний обмежувальний гіперпрямокутник (MBR, від англ. *Minimum Bounding Rectangle / Box*) `R` визначається як декартовий добуток `n` одновимірних замкнених числових відрізків `Iᵢ = [sᵢ, eᵢ]`, де `sᵢ ≤ eᵢ`:

```
R = I₁ × I₂ × ... × Iₙ = ∏_{i=1}^n [sᵢ, eᵢ]
```

Точка `P = (p₁, p₂, ..., pₙ)` належить паралелепіпеду `R` тоді й тільки тоді, коли для кожного координатного виміру `i ∈ {1, 2, ..., n}` виконується подвійна нерівність:

```
P ∈ R  ⇔  ∀ i ∈ {1, ..., n}:  sᵢ ≤ pᵢ ≤ eᵢ
```

### Базові геометричні операції над парою MBR

Для двох паралелепіпедів `A = ∏ [sᵢᴬ, eᵢᴬ]` та `B = ∏ [sᵢᴮ, eᵢᴮ]` визначаються дві фундаментальні операції:

1. **Мінімальний покривальний прямокутник об'єднання (`MBR(A ∪ B)`):**
   Об'єднання двох прямокутників у загальному випадку не є прямокутником. Тому індекс оперує найменшим паралелепіпедом `U = A ⊕ B`, що містить обидва об'єкти:
   ```
   A ⊕ B = ∏_{i=1}^n [ min(sᵢᴬ, sᵢᴮ), max(eᵢᴬ, eᵢᴮ) ]
   ```

2. **Геометричний перетин (`A ∩ B`):**
   Перетин двох паралелепіпедів є або іншим паралелепіпедом, або порожньою множиною `∅`:
   ```
   A ∩ B = ∏_{i=1}^n [ max(sᵢᴬ, sᵢᴮ), min(eᵢᴬ, eᵢᴮ) ]
   ```
   Перетин є непорожнім (`A ∩ B ≠ ∅`) тоді й тільки тоді, коли для всіх `i ∈ {1, ..., n}` виконується умова:
   ```
   max(sᵢᴬ, sᵢᴮ) ≤ min(eᵢᴬ, eᵢᴮ)
   ```

## Геометричні функціонали: об'єм, периметр та приріст

Для оцінки якості просторового групування використовуються три числові функціонали.

### 1. n-вимірний гіпероб'єм (Міра Лебега)

Об'єм паралелепіпеда `V(R)` дорівнює добутку довжин його ребер уздовж усіх координатних осей:

```
V(R) = ∏_{i=1}^n (eᵢ - sᵢ)
```

Для 2D-випадку цей функціонал відповідає площі прямокутника `Area(R) = (e₁ - s₁) · (e₂ - s₂)`.

### 2. Півпериметр та поверхнева міра (Margin)

Півпериметр (Margin) `M(R)` обчислюється як сума довжин усіх ребер:

```
M(R) = ∑_{i=1}^n (eᵢ - sᵢ)
```

Повна площа поверхні `S(R)` `n`-вимірного паралелепіпеда пропорційна сумі добутків ребер за всіма вимірами крім одного. У 2D-просторі повний периметр дорівнює `Perimeter(R) = 2 · M(R) = 2 · ((e₁ - s₁) + (e₂ - s₂))`.

Миргінальний функціонал має критичну властивість: серед усіх прямокутників заданої площі `V` мінімальний периметр `M` має `n`-вимірний куб. Оптимізація за периметром у R*-деревах запобігає виродженню вузлів у довгі витягнуті смуги, які перетинають велику кількість випадкових просторових запитів.

### 3. Функція приросту об'єму (Enlargement)

При вставці нового елемента `E` у вузол із рамкою `R` обчислюється абсолютне розширення простору:

```
ΔV(R, E) = V(R ⊕ E) - V(R)
```

Властивість монотонності: оскільки `R ⊆ (R ⊕ E)`, міра Лебега завжди не зменшується:

```
V(R ⊕ E) ≥ V(R)  ⇒  ΔV(R, E) ≥ 0
```

## Метрика найкоротшої відстані MINDIST

При пошуку найближчих сусідів (k-NN) до заданої точки запиту `P = (p₁, ..., pₙ)` необхідно оцінювати мінімальну можливу евклідову відстань від точки `P` до будь-якої точки всередині гіперпрямокутника `R`.

### Означення та покомпонентна проєкція

Для кожної координатної осі `i` визначається найближча координата `rᵢ` прямокутника `R` до точки `pᵢ`:

```
rᵢ = sᵢ,   якщо pᵢ < sᵢ
rᵢ = eᵢ,   якщо pᵢ > eᵢ
rᵢ = pᵢ,   якщо sᵢ ≤ pᵢ ≤ eᵢ
```

Квадрат метрики найкоротшої відстані `MINDIST²(P, R)` дорівнює:

```
MINDIST²(P, R) = ∑_{i=1}^n (pᵢ - rᵢ)²
```

Покомпонентно це розгортається у суму:

```
MINDIST²(P, R) = ∑_{i=1}^n dist_i²(pᵢ, Iᵢ)

де dist_i(pᵢ, [sᵢ, eᵢ]) =
  sᵢ - pᵢ,   якщо pᵢ < sᵢ
  0,         якщо sᵢ ≤ pᵢ ≤ eᵢ
  pᵢ - eᵢ,   якщо pᵢ > eᵢ
```

### Теорема про точну нижню граню (Lower Bound)

**Теорема 1.** *Для будь-якої точки `X ∈ R` виконується нерівність `dist(P, X) ≥ MINDIST(P, R)`, причому існує принаймні одна точка `R_closest ∈ R`, для якої досягається точна рівність `dist(P, R_closest) = MINDIST(P, R)`.*

**Доведення:**
Розглянемо квадрат евклідової відстані між точкою `P` та довільною точкою `X = (x₁, ..., xₙ) ∈ R`:

```
dist²(P, X) = ∑_{i=1}^n (pᵢ - xᵢ)²
```

Оскільки `xᵢ ∈ [sᵢ, eᵢ]`, мінімум кожного окремого доданка `(pᵢ - xᵢ)²` досягається незалежно:
- Якщо `pᵢ < sᵢ`, то для будь-якого `xᵢ ≥ sᵢ` маємо `(pᵢ - xᵢ)² ≥ (pᵢ - sᵢ)² = (pᵢ - rᵢ)²`.
- Якщо `pᵢ > eᵢ`, то для будь-якого `xᵢ ≤ eᵢ` маємо `(pᵢ - xᵢ)² ≥ (pᵢ - eᵢ)² = (pᵢ - rᵢ)²`.
- Якщо `sᵢ ≤ pᵢ ≤ eᵢ`, мінімум дорівнює 0 при виборі `xᵢ = pᵢ = rᵢ`.

Підсумовуючи нерівності по всіх координатах від `1` до `n`:

```
∑ (pᵢ - xᵢ)² ≥ ∑ (pᵢ - rᵢ)² = MINDIST²(P, R)
```

Точка `R_closest = (r₁, r₂, ..., rₙ)` належить `R` за побудовою (`sᵢ ≤ rᵢ ≤ eᵢ`), отже:

```
dist(P, R_closest) = MINDIST(P, R)
```

Що й треба було довести.

Наслідок для алгоритмів пошуку: якщо знайдено об'єкт на відстані `d_current`, і для деякого вузла дерева `MINDIST(P, R) > d_current`, то жодна точка всередині цього піддерева не може бути ближчою за `d_current`. Це піддерево відкидається цілком без зчитування з диска.

## Метрика гарантованої верхньої межі MINMAXDIST

Метрика `MINDIST` дає оптимістичну нижню оцінку: вона каже, наскільки близько *може* бути об'єкт. Проте вона не гарантує, що всередині `R` справді є об'єкт на цій відстані (прямокутник може бути порожнім біля найближчої грані).

Для песимістичного відсікання Руссопулос (1995) ввів метрику `MINMAXDIST(P, R)` — мінімальну з максимальних відстаней від точки `P` до граней гіперпрямокутника.

### Формула MINMAXDIST

Для точки `P` та прямокутника `R` по кожній осі визначаються координати найближчої `rmᵢ` та найвіддаленішої `rMᵢ` граней:

```
rmᵢ = sᵢ,   якщо pᵢ ≤ (sᵢ + eᵢ) / 2
rmᵢ = eᵢ,   якщо pᵢ > (sᵢ + eᵢ) / 2

rMᵢ = eᵢ,   якщо pᵢ ≤ (sᵢ + eᵢ) / 2
rMᵢ = sᵢ,   якщо pᵢ > (sᵢ + eᵢ) / 2
```

Квадрат відстані `MINMAXDIST²(P, R)` визначається як мінімум за всіма вимірами `k ∈ {1, ..., n}` від суми, де по осі `k` береться дальня грань, а по решті осей — найближчі грані:

```
MINMAXDIST²(P, R) = min_{1 ≤ k ≤ n} [ (pₖ - rMₖ)² + ∑_{i ≠ k} (pᵢ - rmᵢ)² ]
```

### Теорема про гарантовану наявність об'єкта

**Теорема 2.** *Усередині будь-якого непорожнього паралелепіпеда `R` існує принаймні одна гіпергрань розмірності `n - 1`, кожна точка якої віддалена від точки `P` на відстань, що не перевищує `MINMAXDIST(P, R)`. Отже, якщо в `R` міститься хоча б одне просторове тіло, відстань від `P` до найближчого об'єкта в `R` гарантовано не перевищує `MINMAXDIST(P, R)`.*

**Доведення:**
Розглянемо `2n` граней гіперпрямокутника `R`. Кожна грань `Fₖ` перпендикулярна до координатної осі `k` і задається фіксацією однієї координати `xₖ = eₖ` або `xₖ = sₖ`.

Візьмемо дальню грань по осі `k`: `xₖ = rMₖ`. Для будь-якої точки `X = (x₁, ..., xₙ)` на цій грані:
- Координата `xₖ` фіксована і дорівнює `rMₖ`. Внесок цієї осі у квадрат відстані точно дорівнює `(pₖ - rMₖ)²`.
- Для кожної іншої осі `i ≠ k` координата `xᵢ` вільно пробігає весь відрізок `[sᵢ, eᵢ]`. Найближча до `pᵢ` точка цього відрізка — це `rmᵢ`. Максимальна відстань до точок відрізка не перевищує `|pᵢ - rMᵢ|`, але найближча точка на цій грані має відстань:

```
dist²(P, Fₖ_closest) = (pₖ - rMₖ)² + ∑_{i ≠ k} (pᵢ - rmᵢ)²
```

Оскільки грань `Fₖ` є непорожньою компактною множиною, на ній обов'язково лежить точка з такою відстанню. Обираючи вимір `k`, що мінімізує цей вираз по всіх `k ∈ {1, ..., n}`, отримуємо значення `MINMAXDIST²(P, R)`. 

Отже, на цій оптимальній грані гарантовано існує точка на відстані `≤ MINMAXDIST(P, R)`.

Що й треба було довести.

### Правило подвійного відсікання в алгоритмі k-NN

Комбінація `MINDIST` та `MINMAXDIST` дозволяє формувати два взаємодоповнюючі критерії відсікання:

1. **Критерій оновлення радіуса пошуку:**
   Якщо для довільного вузла `R_j` обчислено `MINMAXDIST(P, R_j)`, то глобальний радіус пошуку найближчого сусіда `d_max` можна миттєво зменшити:
   ```
   d_max = min(d_max, MINMAXDIST(P, R_j))
   ```

2. **Критерій відкидання піддерев:**
   Будь-який інший вузол `R_k`, для якого `MINDIST(P, R_k) > d_max`, негайно відкидається з черги пріоритетів, оскільки він гарантовано не може містити об'єкт, ближчий за вже гарантований в `R_j`.

## Відображення багатовимірного простору на одновимірні криві

Для статичного завантаження (Bulk Loading) R-дерев застосовуються неперервні відображення `f: ℝⁿ → ℝ`, що зберігають просторову локальність (Space-Filling Curves).

### Крива Гільберта (Hilbert Curve)

Крива Гільберта порядку `k` відображає дискретну `n`-вимірну сітку `[0, 2^k - 1]ⁿ` на одновимірний числовий відрізок `[0, 2^{n·k} - 1]`.

Головна метрична властивість кривої Гільберта полягає в обмеженні просторового розриву: для двох точок `A, B ∈ ℝⁿ` із гільбертовими індексами `h(A)` та `h(B)` виконується нерівність:

```
dist(A, B) ≤ C · |h(A) - h(B)|^{1/n}
```

де `C` — константа, що залежить лише від розмірності простору `n`. 

Це означає, що сортування об'єктів за гільбертовим значенням їхніх центрів `h(center(MBR))` гарантує, що просторово близькі об'єкти опиняться поруч у лінійній послідовності. Заповнення листків R-дерева послідовними пачками таких об'єктів мінімізує як сумарний периметр `∑ Margin(Lᵢ)`, так і площу перекриття `Overlap(Lᵢ, Lⱼ)` між сусідніми листками.
