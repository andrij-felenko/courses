# 🧮 Математичні межі метричного відсікання та похибка квантування

Метричний пошук найближчих сусідів спирається на суворі геометричні інваріанти. Без математично доведеної нижньої оцінки відстані алгоритм не має права відкинути жодну підмножину простору — відмова від повної перевірки без доказу перетворює точний алгоритм на ненадійну евристику.

Тут наведено строге математичне обґрунтування меж відсікання для сферичних оболонок (Ball tree), виведення похибки асиметричного продуктового квантування (IVF-PQ), математичний апарат анізотропного квантування (ScaNN), лему Джонсона — Лінденштрауса про випадкові проекції, аналітичну оптимізацію гіперпараметрів інвертованих індексів, геометричні співвідношення об'ємів гіперсфери й гіперкуба та доведення явища концентрації відстаней у просторах довільної вимірності.

### 1. Аксіоматика метричного простору та інваріанти куль

Нехай `X` — довільна множина об'єктів, а `d: X × X → ℝ` — функція дійсної відстані. Пара `(X, d)` утворює метричний простір тоді й лише тоді, коли для будь-яких точок `x, y, z ∈ X` виконуються чотири аксіоми:

```
1. d(x, y) ≥ 0               [невід'ємність відстані]
2. d(x, y) = 0  ⇔  x = y     [тотожність нерозрізненних]
3. d(x, y) = d(y, x)         [симетрія]
4. d(x, z) ≤ d(x, y) + d(y, z) [нерівність трикутника]
```

Замкнена метрична куля (сферична оболонка) з центром у точці `c ∈ X` та радіусом `R ≥ 0` визначається як множина:

```
B(c, R) = { x ∈ X | d(c, x) ≤ R }
```

Під час пошуку `k` найближчих сусідів алгоритм підтримує обмежену чергу з пріоритетом (Max-Heap) розміром `k`. Поточний радіус пошуку `r_max` дорівнює відстані від точки запиту `q` до найвіддаленішого з поточних `k` найкращих кандидатів (кореня купи). Якщо купа ще містить менше за `k` елементів, `r_max = +∞`.

#### Нижня межа відстані від запиту до кулі

**Теорема (Нижня оцінка відстані).** Для будь-якої точки `x ∈ B(c, R)` дійсна відстань від точки запиту `q` до `x` обмежена знизу величиною:

```
d(q, x) ≥ max(0, d(q, c) − R)
```

**Доведення.**
Застосуємо нерівність трикутника для трійки точок `q, c, x`:

```
d(q, c) ≤ d(q, x) + d(x, c)     [аксіома 4: нерівність трикутника]
d(q, c) ≤ d(q, x) + d(c, x)     [аксіома 3: симетрія d(x, c) = d(c, x)]
d(q, x) ≥ d(q, c) − d(c, x)     [перенесення d(c, x) ліворуч]
```

Оскільки за визначенням кулі `x ∈ B(c, R)` виконується `d(c, x) ≤ R`, замінюємо `d(c, x)` на його верхню межу `R`:

```
d(q, x) ≥ d(q, c) − R           [враховано d(c, x) ≤ R]
```

Оскільки за аксіомою 1 відстань `d(q, x) ≥ 0`, отримуємо остаточну невід'ємну нижню оцінку:

```
d_min(q, B) = max(0, d(q, c) − R)
```

**Критерій відсікання піддерева:**
Якщо `d_min(q, B) ≥ r_max` і черга з пріоритетом уже заповнена (`size(Heap) = k`), то жодна точка `x ∈ B(c, R)` не може мати відстань `d(q, x) < r_max`. Піддерево гарантовано не містить кандидатів у топ-k і відкидається без перевірки жодної точки всередині.

#### Верхня межа відстані від запиту до кулі

**Теорема (Верхня оцінка відстані).** Для будь-якої точки `x ∈ B(c, R)` дійсна відстань від точки запиту `q` до `x` обмежена зверху величиною:

```
d(q, x) ≤ d(q, c) + R
```

**Доведення.**
Застосуємо нерівність трикутника для трійки `q, x, c`:

```
d(q, x) ≤ d(q, c) + d(c, x)     [аксіома 4: нерівність трикутника]
d(q, x) ≤ d(q, c) + R           [враховано d(c, x) ≤ R]
```

**Критерій безумовного включення піддерева:**
Якщо `d_max(q, B) = d(q, c) + R < r_max`, то **кожна** точка `x ∈ B(c, R)` гарантовано лежить ближче за поточного найгіршого кандидата. Якщо кількість точок у піддереві `|B| ≤ k − size(Heap)`, усі точки піддерева можна включити в купу гуртом, не обчислюючи міжточкових відстаней.

#### Нижня оцінка відстані між двома кулями (Dual-Tree Pruning)

Коли запити надходять пакетами, їх групують у дерево запитів `Q`. Відсікання виконується між вузлом дерева запитів `B_q(c_q, R_q)` та вузлом дерева даних `B_x(c_x, R_x)`.

**Теорема.** Мінімальна відстань між будь-якою точкою `q ∈ B_q` та будь-якою точкою `x ∈ B_x` обмежена знизу:

```
d_min(B_q, B_x) = max(0, d(c_q, c_x) − R_q − R_x)
```

**Доведення.**
Для довільних `q ∈ B_q(c_q, R_q)` та `x ∈ B_x(c_x, R_x)`:

```
d(c_q, c_x)
≤ d(c_q, q) + d(q, x) + d(x, c_x)    [подвійна нерівність трикутника]
≤ R_q + d(q, x) + R_x                [за визначенням куль d(c_q, q) ≤ R_q та d(x, c_x) ≤ R_x]
```

Переносячи радіуси у ліву частину нерівності:

```
d(q, x) ≥ d(c_q, c_x) − R_q − R_x
```

Якщо для всього вузла запитів `B_q` підтримується спільна верхня оцінка `r_max(B_q)`, то за умови `d_min(B_q, B_x) ≥ r_max(B_q)` вся пара піддерев відсікається за один крок `O(1)`.

### 2. Числовий розрахунок відсікання на площині

Розглянемо числовий приклад роботи алгоритму відсікання гілок для задачі 2-NN (`k = 2`) на двовимірній площині з евклідовою метрикою.

**Вхідні параметри:**
- Точка запиту: `q = (1.0, 1.0)`.
- Поточний стан Max-Heap (розмір `k = 2` заповнено):
  1. Кандидат 1: `p_a = (1.2, 1.3)`, відстань `d(q, p_a) = √((0.2)² + (0.3)²) = √(0.04 + 0.09) = √0.13 ≈ 0.3606`.
  2. Кандидат 2 (корінь купи, найгірший): `p_b = (1.4, 1.5)`, відстань `d(q, p_b) = √((0.4)² + (0.5)²) = √(0.16 + 0.25) = √0.41 ≈ 0.6403`.
- Поточний радіус відсікання: `r_max = 0.6403`.

**Аналіз вузла дерева Ball Tree:**
Вузол містить піддерево з 5000 точок.
- Центр сфери: `c = (4.0, 5.0)`.
- Радіус сферичної оболонки: `R = 2.1`.

**Кроки розрахунку:**

```
1. Відстань від запиту до центру кулі:
   d(q, c) = √((4.0 − 1.0)² + (5.0 − 1.0)²)
           = √(3.0² + 4.0²) = √(9.0 + 16.0) = √25.0 = 5.0000

2. Нижня оцінка відстані до будь-якої точки кулі:
   d_min(q, B) = d(q, c) − R
               = 5.0000 − 2.1000 = 2.9000

3. Перевірка умови відсікання:
   d_min(q, B) = 2.9000
   r_max       = 0.6403
   2.9000 ≥ 0.6403   →   Умова виконується!
```

**Висновок:** Піддерево з 5000 точок відсікається за 5 елементарних операцій (два віднімання, два множення, один квадратний корінь). Жодна з 5000 точок не читається з пам'яті.

### 3. Похибка асиметричного продуктового квантування (ADC)

У продуктовому квантуванні (Product Quantization, PQ) `d`-вимірний векторний простір `ℝ^d` розбивається на прямий добуток `M` незалежних ортогональних підпросторів низької розмірності `d' = d / M`:

```
ℝ^d = ℝ^(d') × ℝ^(d') × ... × ℝ^(d')
```

Кожен вектор `x ∈ ℝ^d` розглядається як конкатенація `M` підвекторів: `x = [x^(1), x^(2), ..., x^(M)]`.

Для кожного підпростору `m ∈ {1, ..., M}` методом k-середніх будується словник із `K*` центроїдів `C^(m) = { c_1^(m), c_2^(m), ..., c_{K*}^(m) }` (зазвичай `K* = 256`, що дозволяє адресувати кожен центроїд 1 байтом). Квантувач `q_m: ℝ^(d') → C^(m)` проектує підвектор на його найближчий центроїд:

```
q_m(x^(m)) = argmin_{c ∈ C^(m)} ||x^(m) − c||²
```

Повний квантований вектор `x̃ = q(x) = [q_1(x^(1)), q_2(x^(2)), ..., q_M(x^(M))]`.

#### Квадратичне спотворення квантування (Mean Squared Distortion)

Оскільки координатні підпростори попарно ортогональні, сумарна квадратична помилка реконструкції розкладається в точну суму помилок за окремими підпросторами:

```
||x − q(x)||² = ∑_{m=1}^M ||x^(m) − q_m(x^(m))||²
```

Математичне сподівання загального квадратичного спотворення:

```
E[||x − q(x)||²] = ∑_{m=1}^M E[||x^(m) − q_m(x^(m))||²]
```

За асимптотичною теорією векторного квантування Гершо (Gersho's Conjecture), для оптимального векторного квантувача при `K* >> 1` у підпросторі розмірності `d'`:

```
E[||x^(m) − q_m(x^(m))||²] ≈ C(d') · (K*)^(−2 / d') · [ ∫ p_m(u)^(d' / (d' + 2)) du ]^((d' + 2) / d')
```

де `C(d')` — геометрична константа щільності пакування решітки у `d'` вимірах, а `p_m(u)` — густина ймовірності розподілу векторів у `m`-му підпросторі.

З цієї формули видно ключовий ефект розбиття: квантування цілого 768-вимірного вектора (`d' = 768`) дає швидкість спадання похибки `(K*)^(−2 / 768) ≈ (K*)^(−0.0026)` — похибка майже не зменшується при збільшенні словника. Натомість при розбитті на `M = 96` підпросторів по `d' = 8` вимірів швидкість спадання становить `(K*)^(−2 / 8) = (K*)^(−0.25)` — збільшення словника центроїдів дає швидке згасання помилки реконструкції.

#### Межа похибки асиметричної відстані (ADC Error Bound)

В алгоритмі ADC (Asymmetric Distance Computation) вектор запиту `y` залишається у точній формі float32, а вектор бази даних `x` замінюється його квантованим представленням `q(x)`:

```
d̃_ADC²(y, x) = ||y − q(x)||² = ∑_{m=1}^M ||y^(m) − q_m(x^(m))||²
```

Оцінимо різницю між дійсною квадратичною відстанню `||y − x||²` та її асиметричною оцінкою `||y − q(x)||²`.

Запишемо вектор `y − q(x)` через суму `(y − x) + (x − q(x))`:

```
||y − q(x)||²
= ||(y − x) + (x − q(x))||²                           [тотожне розкладання вектора]
= ||y − x||² + ||x − q(x)||² + 2·⟨y − x, x − q(x)⟩    [розкриття квадрата норми суми]
```

Звідси різниця оцінки та дійсної відстані дорівнює:

```
||y − q(x)||² − ||y − x||² = ||x − q(x)||² + 2·⟨y − x, x − q(x)⟩
```

Застосуємо нерівність Коші — Буняковського до скалярного добутку `|⟨y − x, x − q(x)⟩| ≤ ||y − x|| · ||x − q(x)||`:

```
| ||y − q(x)||² − ||y − x||² | ≤ ||x − q(x)||² + 2 · ||y − x|| · ||x − q(x)||
```

Позначимо помилку реконструкції квантованого вектора `ε_x = ||x − q(x)||` та дійсну евклідову відстань `D = ||y − x||`:

```
| d̃_ADC² − D² | ≤ ε_x² + 2 · D · ε_x
```

Перейдемо до лінійної відстані. За нерівністю трикутника для норм:

```
||y − q(x)|| ≤ ||y − x|| + ||x − q(x)||   →   d̃_ADC ≤ D + ε_x
||y − x|| ≤ ||y − q(x)|| + ||q(x) − x||   →   D ≤ d̃_ADC + ε_x
```

Об'єднуючи обидві нерівності, отримуємо строгу двосторонню межу:

```
| d̃_ADC − D | ≤ ε_x = ||x − q(x)||
```

Це доводить, що асиметрична відстань `d̃_ADC` є незміщеною оцінкою, абсолютна похибка якої строго обмежена радіусом комірки квантування і не залежить від відстані `D` між запитом і точкою.

### 4. Анізотропне квантування векторів (ScaNN)

У задачі пошуку за максимальним скалярним добутком (MIPS, англ. *Maximum Inner Product Search*) класична мінімізація середньоквадратичного відхилення (MSE) виявляється субоптимальною.

Нехай `x` — вектор бази даних, а `x̃ = q(x)` — його квантоване наближення. Похибку квантування `h = x − x̃` можна розкласти на дві ортогональні компоненти відносно напрямку самого вектора `x`:
1. **Поздовжня похибка `h_parallel`** — проекція помилки на одиничний напрямок `x / ||x||`:

```
h_parallel = ⟨h, x⟩ / ||x||² · x
```

2. **Поперечна похибка `h_perp`** — складова, ортогональна до вектора `x`:

```
h_perp = h − h_parallel
```

Під час обчислення скалярного добутку з вектором запиту `q`:

```
⟨q, x̃⟩ = ⟨q, x − h⟩ = ⟨q, x⟩ − ⟨q, h_parallel⟩ − ⟨q, h_perp⟩
```

Оскільки для релевантних (найближчих) документів кут між `q` та `x` є малим, вектор запиту `q` майже співнапрямлений із `x`. У результаті скалярний добуток `⟨q, h_parallel⟩ ≈ ||q|| · ||h_parallel||` має максимальний негативний вплив на ранжування, тоді як поперечна помилка `⟨q, h_perp⟩ ≈ 0` майже не змінює порядок сортування кандидатів.

Анізотропний квантувач ScaNN (Guo et al., Google Research, 2020) оптимізує зважену функцію втрат:

```
L_aniso(x, x̃) = ||h_perp||² + λ · ||h_parallel||²
```

де вага штрафу `λ > 1` (зазвичай `λ = 4..10`). Завдяки штрафуванню поздовжньої помилки квантовані центроїди зміщуються так, щоб зберігати точну довжину та кутову проекцію вектора, що збільшує Recall@10 на 15–20% при тій самій швидкості обчислень.

### 5. Лема Джонсона — Лінденштрауса про випадкові проекції

Фундаментальна теорема розмірної редукції пояснює, чому стиснення простору зберігає геометричні відстані між точками.

**Лема (Johnson, Lindenstrauss, 1984).**
Для будь-якої множини з `N` точок `P ⊂ ℝ^D` та довільного допустимого коефіцієнта спотворення `0 < ε < 1`, існує лінійне відображення `f: ℝ^D → ℝ^d` у простір значно меншої розмірності:

```
d ≥ ( 8 · ln(N) ) / ( ε² )
```

таке, що для **всіх** пар точок `u, v ∈ P` квадрати міжточкових відстаней зберігаються з точністю `(1 ± ε)`:

```
(1 − ε) · ||u − v||² ≤ ||f(u) − f(v)||² ≤ (1 + ε) · ||u − v||²
```

#### Доведення на основі випадкової матриці Гаусса

Побудуємо випадкову матрицю проекції `A ∈ ℝ^(d × D)`, елементи якої є незалежними випадковими величинами зі стандартного нормального розподілу `A_{i,j} ~ N(0, 1)`.

Лінійне відображення визначається нормованим множенням:

```
f(x) = (1 / √d) · A · x
```

Нехай `v = u − w` — вектор різниці між двома довільними точками одиничної довжини `||v|| = 1`. Довжина спроектованого вектора `z = f(v) = (1 / √d) · A · v`.

Кожна координата `z_i = (1 / √d) · ∑_{j=1}^D A_{i,j} · v_j` є лінійною комбінацією незалежних гауссових величин. Оскільки `||v|| = 1`, дисперсія суми дорівнює `∑ v_j² = 1`, тому координати `z_i ~ N(0, 1/d)` є незалежними.

Квадрат норми спроектованого вектора дорівнює:

```
||f(v)||² = ∑_{i=1}^d z_i² = (1 / d) · ∑_{i=1}^d X_i²
```

де `X_i ~ N(0, 1)`, а величина `Q = ∑ X_i²` має хі-квадрат розподіл `χ²(d)` із `d` ступенями вільності.

Математичне сподівання та дисперсія хі-квадрат величини:

```
E[ ||f(v)||² ] = (1 / d) · E[ Q ] = (1 / d) · d = 1 = ||v||²
Var( ||f(v)||² ) = (1 / d²) · Var( Q ) = (1 / d²) · 2d = 2 / d
```

За нерівністю Чернова для розподілу `χ²(d)` імовірність того, що довжина спроектованого вектора відхилиться більше ніж на `ε`:

```
P( ||f(v)||² ≥ 1 + ε ) ≤ exp( − (d / 4) · (ε² − ε³) )
P( ||f(v)||² ≤ 1 − ε ) ≤ exp( − (d / 4) · (ε² + ε³) )
```

Об'єднуючи обидва хвости, отримуємо ймовірність спотворення для однієї пари:

```
P( | ||f(v)||² − 1 | ≥ ε ) ≤ 2 · exp( − (d · ε²) / 8 )
```

У множині з `N` точок існує всього `(N · (N − 1)) / 2 < N² / 2` пар точок. За правилом об'єднання ймовірностей (Union Bound), імовірність того, що **хоча б одна** пара точок зазнає спотворення більше за `ε`:

```
P_fail ≤ (N² / 2) · 2 · exp( − (d · ε²) / 8 ) = exp( 2·ln(N) − (d · ε²) / 8 )
```

Щоб гарантувати існування проекції (`P_fail < 1`), достатньо обрати розмірність:

```
d > ( 8 · ln(N) + 8 · ln(2) ) / ε² = O( ln(N) / ε² )
```

**Критичний наслідок:** Розмірність стисненого простору `d` залежить виключно від **кількості точок `N`** і не залежить від вихідної розмірності `D`. Корпус із `10⁶` ембедингів будь-якої початкової розмірності можна спроектувати у простір `d ≈ 1000` вимірів зі збереженням усіх відстаней із точністю до `ε = 0.1`.

### 6. Математична оптимізація вибору гіперпараметрів IVF-PQ

Під час налаштування інвертованого індексу IVF-PQ виникає задача вибору оптимальної кількості центроїдів Вороного `K` для мінімізації загального часу запиту при фіксованому бюджеті точності (параметрі `nprobe`).

Обчислювальна вартість одного запиту складається з двох послідовних фаз:
1. **Фаза 1: Пошук `nprobe` найближчих центроїдів.**
   Запит порівнюється з усіма `K` центроїдами розмірністю `d`:

```
T_coarse = K · d
```

2. **Фаза 2: Табличне сканування інвертованих списків.**
   При рівномірному розподілі кожен список містить `N / K` векторів. Для `nprobe` списків сканується `nprobe · (N / K)` векторів, кожен із яких вимагає `M` вибірок із таблиці ADC:

```
T_fine = nprobe · (N / K) · M · c_adc
```

де `c_adc` — апаратна вартість одного табличного додавання відносно одного векторного множення float32 (зазвичай `c_adc ≈ 0.2..0.5` завдяки інструкціям SIMD).

Загальна функція вартості запиту:

```
T_total(K) = K · d + ( nprobe · M · N · c_adc ) / K
```

Знайдемо екстремум функції `T_total(K)`, взявши похідну за `K` і прирівнявши її до нуля:

```
d/dK [ T_total(K) ]
= d/dK [ K · d + (nprobe · M · N · c_adc) · K^(−1) ]   [диференціювання за K]
= d − (nprobe · M · N · c_adc) / K² = 0               [прирівнювання до нуля]
```

Звідси оптимальна кількість центроїдів `K*`:

```
K* = √( (nprobe · M · N · c_adc) / d )
```

**Аналітичний висновок:** Оптимальна кількість кластерів `K*` строго пропорційна квадратному кореню з обсягу вибірки: `K* = Θ(√N)`. Для вибірки `N = 10⁷` точок із параметрами `d = 768`, `M = 96`, `nprobe = 16`, `c_adc = 0.33`:

```
K* = √( (16 · 96 · 10⁷ · 0.33) / 768 ) = √( 6.6 · 10⁶ ) ≈ 2569 ≈ 4096 (найближчий степінь 2)
```

Це доводить математичну обґрунтованість загальноприйнятого інженерного правила обирати `K = 4 · √N` або `K = 16 · √N` у бібліотеках FAISS та Milvus.

### 7. Геометрія гіперпростору: зникнення об'єму кулі

Чому розбиття простору кулями або гіперплощинами перестає діяти у просторах високої вимірності? Відповідь дає геометрія `d`-вимірних тіл.

Об'єм `d`-вимірного гіперкуба зі стороною `2R`:

```
V_cube(d, R) = (2R)^d = 2^d · R^d
```

Об'єм `d`-вимірної гіперсфери радіуса `R`, вписаної у цей гіперкуб:

```
V_sphere(d, R) = ( π^(d/2) / Γ(d/2 + 1) ) · R^d
```

де `Γ(z)` — гамма-функція Ейлера (`Γ(n + 1) = n!` для цілих `n`).

#### Співвідношення об'ємів при парній розмірності `d = 2k`

Підставимо `d = 2k` та `Γ(k + 1) = k!`:

```
V_sphere(2k, R) / V_cube(2k, R)
= [ (π^k / k!) · R^(2k) ] / [ 2^(2k) · R^(2k) ]      [підстановка формул об'єму]
= (π / 4)^k / k!                                     [скорочення R^(2k) та спрощення]
```

За формулою Стірлінга для факторіала `k! ≈ √(2πk) · (k / e)^k`:

```
(π / 4)^k / k!
≈ (π / 4)^k / ( √(2πk) · (k / e)^k )                 [підстановка формули Стірлінга]
= (1 / √(2πk)) · ( (e · π) / (4 · k) )^k             [об'єднання степенів]
```

При прямуванні розмірності до нескінченності `k = d/2 → ∞`:

```
lim_{d → ∞} V_sphere(d, R) / V_cube(d, R) = 0
```

**Числові значення частки об'єму вписаної сфери від об'єму куба:**
- `d = 2`: `V_sphere / V_cube = π / 4 ≈ 0.7854` (78.5% об'єму всередині кола)
- `d = 3`: `V_sphere / V_cube = π / 6 ≈ 0.5236` (52.4%)
- `d = 10`: `V_sphere / V_cube = π⁵ / (120 · 2¹⁰) ≈ 0.00249` (0.25%)
- `d = 50`: `V_sphere / V_cube ≈ 1.53 · 10⁻²⁸`
- `d = 768` (типовий вектор BERT/RAG): `V_sphere / V_cube < 10⁻⁵⁰⁰`

**Геометричний зміст:** У високій розмірності практично 100% об'єму гіперкуба зосереджено в його тонких кутах. Вписана сфера має нульовий відносний об'єм. Будь-яке розбиття на осі орієнтованими коробками перетинає кути простору і втрачає здатність ізолювати точки.

### 8. Теорема Байєра про концентрацію відстаней

Колапс просторових дерев при `d > 20` строго описується теоремою концентрації відстаней.

Нехай `d` — розмірність простору. Розглянемо вибірку з `N` точок `X_d = { x_1, ..., x_N } ⊂ ℝ^d` та точку запиту `q_d`.

Позначимо:
- `D_min^(d) = min_{x ∈ X_d} ||q_d − x||` — відстань до 1-найближчого сусіда;
- `D_max^(d) = max_{x ∈ X_d} ||q_d − x||` — відстань до найвіддаленішої точки вибірки.

**Теорема (Beyer, Goldstein, Ramakrishnan, Shaft, 1999).**
Якщо для послідовності випадкових відстаней `||q_d − X_d||` виконується умова зникнення відносної дисперсії:

```
lim_{d → ∞} Var( ||q_d − X_d|| ) / ( E[ ||q_d − X_d|| ] )² = 0
```

тоді для будь-якого фіксованого `ε > 0` ймовірність того, що всі точки стануть майже однаково віддаленими від запиту, прямує до одиниці:

```
lim_{d → ∞} P( D_max^(d) ≤ (1 + ε) · D_min^(d) ) = 1
```

#### Доведення для незалежних координат

Нехай координати точки `x = (x_1, ..., x_d)` та запиту `q = (q_1, ..., q_d)` є незалежними однаково розподіленими випадковими величинами з скінченними моментами.

Квадрат евклідової відстані є сумою `d` незалежних випадкових величин `Y_i = (q_i − x_i)²`:

```
D_d² = ∑_{i=1}^d Y_i
```

Нехай `μ = E[Y_i] > 0` та `σ² = Var(Y_i) < ∞`.

За адитивністю математичного сподівання та дисперсії для суми незалежних величин:

```
E[D_d²] = d · μ
Var(D_d²) = d · σ²
```

Відношення стандартного відхилення квадрата відстані до його математичного сподівання:

```
√Var(D_d²) / E[D_d²]
= √(d · σ²) / (d · μ)           [підстановка формул суми]
= (σ / μ) · (1 / √d)            [спрощення кореня]
```

При `d → ∞`:

```
lim_{d → ∞} (σ / μ) · (1 / √d) = 0
```

За дельта-методом переходу до кореневої випадкової величини `D_d = √(D_d²)`:

```
E[D_d] ≈ √(d · μ)
Var(D_d) ≈ σ² / (4 · μ) = O(1)
```

Обчислимо граничне відношення дисперсії відстані до квадрата її середнього:

```
Var(D_d) / (E[D_d])² ≈ (σ² / (4 · μ)) / (d · μ) = O(1 / d) → 0
```

#### Наслідок для швидкості просторових дерев

Оскільки `(D_max^(d) − D_min^(d)) / D_min^(d) → 0`:
1. Відстань до найближчого сусіда `r_max = D_min^(d)` прямує до тієї самої величини `√(d · μ)`, що й відстань до випадкової точки бази даних.
2. Куля пошуку з радіусом `r_max` накриває майже весь допустимий об'єм простору.
3. Будь-яка куля `B(c, R)` дерева перетинає область пошуку: `d_min(q, B) < r_max`.
4. Частка відсічених піддерев прямує до 0, а час виконання запиту деградує від `O(k · log N)` до повного лінійного перебору `O(N · d)`.
