# 🧮 Геометрія різниці Мінковського та опорних функцій

Алгоритм GJK зводить складну просторову перевірку взаємного перетину або вимірювання відстані між двома довільними тривимірними опуклими фігурами до значно простішої задачі: визначення відстані від єдиної фіксованої точки — початку координат `O = (0, 0, 0)` — до однієї похідної опуклої фігури.

Математичним фундаментом цього зведення виступають три теорії: алгебра операцій Мінковського над множинами, теорія двоїстості опуклих тіл через опорні функції та теорема Каратеодорі про розмірність симплексів.

### 1. Сума й різниця Мінковського

Нехай у евклідовому просторі `Rⁿ` задано дві непорожні підмножини `A ⊂ Rⁿ` та `B ⊂ Rⁿ`.

Сумою Мінковського (позначається `A ⊕ B`) називають множину всіх попарних сум векторів із `A` та `B`:

```
A ⊕ B = { a + b | a ∈ A, b ∈ B }
```

Різницею Мінковського (позначається `A ⊖ B`) називають результат додавання множини `A` та відбитої відносно початку координат множини `−B = { −b | b ∈ B }`:

```
A ⊖ B = A ⊕ (−B) = { a − b | a ∈ A, b ∈ B }
```

#### Збереження опуклості

Важлива геометрична властивість полягає в тому, що операція різниці зберігає опуклість.

**Твердження:** якщо множини `A` та `B` опуклі, то їхня різниця Мінковського `C = A ⊖ B` також є опуклою множиною.

**Доведення:**
За означенням опуклості, множина `C` є опуклою, якщо для будь-яких двох точок `c₁, c₂ ∈ C` та будь-якого дійсного параметра `λ ∈ [0, 1]` їхня опукла лінійна комбінація `c_λ = λ · c₁ + (1 − λ) · c₂` також належить `C`.

Оскільки `c₁ ∈ C` та `c₂ ∈ C`, існують такі `a₁, a₂ ∈ A` та `b₁, b₂ ∈ B`, що:
`c₁ = a₁ − b₁`
`c₂ = a₂ − b₂`

Підставимо ці вирази у формулу опуклої комбінації:

```
c_λ = λ · c₁ + (1 − λ) · c₂
    = λ · (a₁ − b₁) + (1 − λ) · (a₂ − b₂)                       [підстановка c₁ та c₂]
    = (λ · a₁ + (1 − λ) · a₂) − (λ · b₁ + (1 − λ) · b₂)         [перегрупування доданків]
```

Позначимо:
`a_λ = λ · a₁ + (1 − λ) · a₂`
`b_λ = λ · b₁ + (1 − λ) · b₂`

Оскільки множина `A` опукла за умовою, `a_λ ∈ A`.
Оскільки множина `B` опукла за умовою, `b_λ ∈ B`.

Звідси різниця `c_λ = a_λ − b_λ` за означенням належить множині `A ⊖ B`. Отже, множина `C` опукла, що й треба було довести.

### 2. Еквівалентність задачі перетину та включення початку координат

**Теорема перетину:** Два тіла `A` та `B` мають непорожній перетин (`A ∩ B ≠ ∅`) тоді й лише тоді, коли початок координат `O = (0, 0, ..., 0)` належить їхній різниці Мінковського `A ⊖ B`:

```
A ∩ B ≠ ∅  ⇔  O ∈ A ⊖ B
```

**Пряме доведення (зліва направо):**
1. Припустимо, `A ∩ B ≠ ∅`.
2. Це означає, що існує хоча б одна спільна точка `p`, для якої одночасно `p ∈ A` та `p ∈ B`.
3. Візьмемо `a = p` та `b = p`.
4. Різниця векторів: `a − b = p − p = 0 = O`.
5. Оскільки `a ∈ A` та `b ∈ B`, точка `0` за означенням належить `A ⊖ B`.

**Зворотне доведення (справа наліво):**
1. Припустимо, `O ∈ A ⊖ B`.
2. За означенням різниці Мінковського це означає, що існують такі елементи `a* ∈ A` та `b* ∈ B`, для яких: `a* − b* = O`.
3. Додавши вектор `b*` до обох частин рівності, отримуємо: `a* = b*`.
4. Позначимо цю спільну точку як `p* = a* = b*`.
5. Оскільки `p* = a* ∈ A` та `p* = b* ∈ B`, маємо `p* ∈ A ∩ B`.
6. Отже, перетин `A ∩ B` не є порожнім.

### 3. Евклідова відстань між тілами

Евклідова відстань між двома множинами точок `A` та `B` у просторі `Rⁿ` визначається як інфімум (найменша точна грань) відстаней між парами точок:

```
dist(A, B) = inf { ||a − b|| | a ∈ A, b ∈ B }
```

Оскільки кожна пара `a ∈ A` та `b ∈ B` утворює вектор `c = a − b ∈ A ⊖ B`, цей вираз тотожно збігається з відстанню від початку координат `O` до множини `C = A ⊖ B`:

```
dist(A, B) = inf { ||c|| | c ∈ A ⊖ B } = dist(O, A ⊖ B)
```

Якщо множини `A` та `B` є замкненими й обмеженими (компактними), інфімум досягається на конкретній парі найближчих точок `a* ∈ A` та `b* ∈ B`. При цьому вектор `v* = a* − b*` є вектором мінімальної довжини, що з'єднує початок координат із межею тіла `C = A ⊖ B`.

### 4. Опорне відображення та лінійність

Для компактної опуклої множини `K ⊂ Rⁿ` та ненульового вектора напрямку `d ∈ Rⁿ` визначають дві взаємопов'язані функції:

1. **Опорна функція (support function)** `h_K(d)` — повертає максимальне скалярне значення проєкції точок множини на напрямок `d`:

```
h_K(d) = max { x · d | x ∈ K }
```

2. **Опорне відображення (support mapping)** `s_K(d)` — повертає саму точку множини `K`, на якій цей максимум досягається:

```
s_K(d) = argmax { x · d | x ∈ K }
```

#### Головна лема про опорну точку різниці Мінковського

**Лема:** Опорна точка різниці Мінковського `A ⊖ B` у напрямку `d` дорівнює різниці між опорною точкою множини `A` у напрямку `d` та опорною точкою множини `B` у протилежному напрямку `−d`:

```
s_{A ⊖ B}(d) = s_A(d) − s_B(−d)
```

**Доведення:**
Розглянемо опорну функцію для довільної точки `c ∈ A ⊖ B`. За означенням `c = a − b`, де `a ∈ A`, `b ∈ B`.

Обчислимо скалярний добуток вектора `c` на напрямок `d`:

```
c · d = (a − b) · d
      = a · d − b · d               [дистрибутивність скалярного добутку]
      = a · d + b · (−d)            [властивість знака: −(b · d) = b · (−d)]
```

Для максимізації суми `a · d + b · (−d)` над усіма парами `a ∈ A` та `b ∈ B`, оскільки вибір `a` та вибір `b` є абсолютно незалежними один від одного, максимум суми дорівнює сумі окремих максимумів:

```
max_{c ∈ A ⊖ B} (c · d) = max_{a ∈ A, b ∈ B} (a · d + b · (−d))
                        = max_{a ∈ A} (a · d) + max_{b ∈ B} (b · (−d))      [незалежність вибору a та b]
                        = h_A(d) + h_B(−d)
```

Точка `a*`, що максимізує `a · d`, за означенням є `s_A(d)`.
Точка `b*`, що максимізує `b · (−d)`, за означенням є `s_B(−d)`.

Отже, точка `c* = a* − b* = s_A(d) − s_B(−d)` досягає максимуму скалярного добутку з вектором `d` серед усіх точок множини `A ⊖ B`. Тобто:

```
s_{A ⊖ B}(d) = s_A(d) − s_B(−d)
```

Ця теорема є обчислювальним ядром GJK: знаходження екстремальної точки тривимірної різниці `A ⊖ B` ніколи не потребує перебору `n · m` комбінацій — воно виконується за два незалежні швидкі запити до вихідних тіл `A` та `B`.

### 5. Теорема Каратеодорі та розмірність симплекса

Чому для пошуку найближчої точки або перевірки наявності нуля всередині складної фігури з тисячами граней алгоритму GJK достатньо пам'ятати не більше 4 точок у 3D (або 3 точок у 2D)?

Відповідь дає класична теорема опуклої геометрії.

**Теорема Каратеодорі (1911):**
Якщо множина `X ⊂ Rⁿ` лежить у `n`-вимірному евклідовому просторі, то будь-яка точка `x` з опуклої оболонки `conv(X)` може бути представлена як опукла комбінація не більше ніж `n + 1` точок множини `X`.

**Геометричний наслідок для GJK:**
`k`-вимірний симплекс утворюється `k + 1` афінно незалежними точками:
- У 2D (`n = 2`): максимум 3 точки (трикутник). Будь-яка точка всередині 2D опуклої фігури гарантовано лежить усередині деякого трикутника з її вершин.
- У 3D (`n = 3`): максимум 4 точки (тетраедр). Будь-яка точка (зокрема початок координат `O`) гарантовано покривається деяким тетраедром, побудованим на вершинах фігури.

Таким чином, алгоритм GJK на кожній ітерації оперує виключно `k`-симплексом (`k ≤ 3` у 3D), не витрачаючи пам'ять на зберігання решти політопа.

### 6. Барицентричні координати та проєкція на симплекс

Нехай симплекс `S` задано набором вершин `V = {v₁, v₂, ..., v_m}`, де `m ≤ n + 1`. Будь-яка точка `p` у площині (афінній оболонці) симплекса однозначно записується через барицентричні ваги `λ₁, λ₂, ..., λ_m`:

```
p = ∑_{i=1}^m (λ_i · v_i)   при умові   ∑_{i=1}^m λ_i = 1
```

Точка `p` належить безпосередньо внутрішній частині симплекса (замкненій опуклій оболонці `conv(V)`), якщо всі барицентричні ваги є невід'ємними:

```
∀ i ∈ {1, ..., m}:  λ_i ≥ 0
```

Пошук найближчої точки симплекса до початку координат зводиться до задачі мінімізації норми:

```
min ||p||² = min || ∑_{i=1}^m (λ_i · v_i) ||²
за умов: ∑ λ_i = 1  та  λ_i ≥ 0 (∀ i)
```

Якщо для деякого індексу `j` барицентрична вага розв'язку виходить від'ємною (`λ_j < 0`), це геометрично означає, що початок координат лежить поза межами відповідної грані. У такому разі вершина `v_j` видаляється з симплекса, а розмірність симплекса зменшується, що алгоритм GJK реалізує через швидку топологічну перевірку областей Вороного.
