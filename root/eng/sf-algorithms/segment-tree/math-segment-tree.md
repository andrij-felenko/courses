# 🧮 Алгебраїчна теорія відрізкового дерева: моноїди, комбінаторика та інваріанти

Формальний аналіз обчислювальної ефективності відрізкового дерева спирається на апарат абстрактної алгебри (грец. *algebra* — відновлення) та комбінаторики. На відміну від специфічних структур даних, розроблених суто для арифметичного додавання, відрізкове дерево є універсальним алгебраїчним обчислювачем. Воно здатно працювати з довільною множиною елементів, на якій задано бінарну операцію, що задовольняє аксіомам алгебраїчного моноїда (грец. *monas* — одиниця).

Розуміння алгебраїчних інваріантів відрізкового дерева дозволяє не лише обчислювати суму чи мінімум на відрізку, а й будувати складні комбінаторні структури: шукати максимальний підмасив за алгоритмом Кадане, знаходити кількість нулів чи першу позицію елемента, що задовольняє умові, та підтримувати матричні множення в динамічних графах.

## 1. Формальне означення моноїда та вимоги до операцій

Нехай `S` — непорожня множина елементів, а `⊕` — бінарна операція, визначена на цій множині `⊕: S × S → S`. Пара `(S, ⊕)` з нейтральним елементом `e ∈ S` утворює алгебраїчний моноїд, якщо виконуються наступні три фундаментальні аксіоми:

1. **Замкненість (Closure):**
```
∀ a, b ∈ S ⇒ (a ⊕ b) ∈ S
```
Результат застосування операції до будь-яких двох елементів множини обов'язково належить цій же множині. Жодне обчислення всередині вузла дерева не може вийти за межі визначеної числової чи об'єктної області.

2. **Асоціативність (Associativity, лат. *associare* — з'єднувати):**
```
∀ a, b, c ∈ S ⇒ (a ⊕ b) ⊕ c = a ⊕ (b ⊕ c)
```
Порядок виконання операцій при їх послідовному застосуванні не впливає на кінцевий результат. Властивість асоціативності є математично необхідною та достатньою умовою для того, щоб вираз `a₁ ⊕ a₂ ⊕ ... ⊕ aₙ` можна було обчислювати у формі довільного бінарного дерева обчислень. Без асоціативності канонічна декомпозиція інтервалу втрачає математичну коректність.

3. **Існування нейтрального елемента (Identity element):**
```
∃ e ∈ S : ∀ a ∈ S ⇒ a ⊕ e = e ⊕ a = a
```
У множині `S` існує нейтральний елемент `e`, який залишає будь-який елемент `a` незмінним при застосуванні операції `⊕`. Нейтральний елемент повертається алгоритмом обходу дерева у випадках, коли піддерево поточного вузла взагалі не перетинається з інтервалом запиту.

### Приклади моноїдів у структурі відрізкового дерева

| Множина `S` | Операція `⊕` | Нейтральний елемент `e` | Приклад застосування |
| :--- | :--- | :--- | :--- |
| `ℤ` (цілі числа) | `+` (додавання) | `0` | Запит суми на відрізку |
| `ℝ ∪ {+∞}` | `min` (мінімум) | `+∞` | Пошук найменшого елемента |
| `ℝ ∪ {-∞}` | `max` (максимум) | `-∞` | Пошук найбільшого елемента |
| `ℕ` (натуральні) | `gcd` (НСД) | `0` | Найбільший спільний дільник |
| `Bool` | `AND` / `OR` / `XOR` | `true` / `false` / `false` | Побітові логічні операції |
| `Mat(K×K)` | `×` (множення матриць) | `I` (одинична матриця) | Динамічні шляхи в графах |

Зверніть увагу: комутативність (`a ⊕ b = b ⊕ a`) **не є обов'язковою** для відрізкового дерева. Оскільки дерево зберігає строго впорядковану ліво-праву ієрархію вузлів, некомутативні моноїди (такі як множення матриць або об'єднання текстових рядків) успішно агрегуються, за умови дотримання порядку об'єднання: `Node_val = Left_child ⊕ Right_child`.

## 2. Теорема про канонічну декомпозицію інтервалу

Головне математичне досягнення відрізкового дерева полягає в доведенні того, що будь-який безперервний інтервал елементів `[L, R]` масиву розмірності `N` можна подати як диз'юнктне об'єднання не більше ніж `2 ⌈log₂ N⌉` канонічних підінтервалів, що зберігаються у вузлах дерева.

### Доведення теореми про межу покриття

Розглянемо повне двійкове дерево висоти `H = ⌈log₂ N⌉`. На кожному рівні дерева `h` (де `h = 0` відповідає листкам, а `h = H` — кореню) знаходяться вузли, що покривають інтервали довжиною `2ʰ`.

Під час виконання рекурсивного обходу інтервального запиту `query(L, R)` на кожному рівні дерева `h` алгоритм може відвідати максимум 4 вузли:
1. Найлівіший вузол, який частково перетинає інтервал `[L, R]`.
2. Вузол, що повністю лежить всередині `[L, R]` і прилягає до лівої межі (канонічний вузол).
3. Вузол, що повністю лежить всередині `[L, R]` і прилягає до правої межі (канонічний вузол).
4. Найправіший вузол, який частково перетинає інтервал `[L, R]`.

Вузли, які повністю потрапляють всередину запиту (типу 2 та 3), негайно припиняють рекурсію й повертають своє збережене значення. Далі рекурсія продовжується лише у двох частково перекритих вузлах (типу 1 та 4).

Оскільки на кожному з `H` рівнів дерева додається не більше 2 канонічних вузлів, загальна кількість канонічних підінтервалів `K`, необхідних для покриття будь-якого `[L, R]`, строго обмежена:

```
K ≤ 2 · H = 2 · ⌈log₂ N⌉
```

Для масиву розміром `N = 10⁶` елементів висота дерева `H = 20`. Отже, довільний інтервальний запит до мільйона елементів обчислюється шляхом об'єднання не більше ніж `2 · 20 = 40` канонічних значень у вузлах дерева.

## 3. Математична формалізація відкладеної пропогації (Endomorphism Action)

При виконанні масових інтервальних оновлень відрізкове дерево оперує двома алгебраїчними системами: моноїдом значень `(S, ⊕, e)` та множиною операторів модифікації `F`.

Математично дія модифікатора `f ∈ F` на елемент `x ∈ S` визначається як ендоморфізм `f: S → S`. Щоб відкладена пропогація коректно обчислювала агреговані значення, мусять виконуватися дві умови узгодженості:

### Умова 1. Дистрибутивність оператора відносно моноїда

Оператор модифікації `f` повинен бути дистрибутивним відносно бінарної операції `⊕`:

```
f(a ⊕ b) = f(a) ⊕ f(b)
```

Якщо модифікація залежить від довжини інтервалу `len` (наприклад, додавання константи `v` до суми на відрізку довжиною `len`), формула набуває вигляду:

```
f(a ⊕ b, len_a + len_b) = f(a, len_a) ⊕ f(b, len_b)
```

Наприклад, для суми елементів при додаванні константи `v`: `f(sum, len) = sum + v · len`. Тоді:
```
(sum_a + v · len_a) + (sum_b + v · len_b) = (sum_a + sum_b) + v · (len_a + len_b)
```
Дистрибутивність виконується строго.

### Умова 2. Замкненість композиції операторів (Lazy Tag Composition)

Якщо до одного й того ж вузла послідовно застосовуються дві відкладені модифікації `f₁ ∈ F` та `f₂ ∈ F`, їх комбінація повинна зводитися до єдиного еквівалентного оператора `f₃ = f₂ ∘ f₁ ∈ F`:

```
f₃(x) = f₂(f₁(x))
```

Множина операторів `(F, ∘)` сама повинна утворювати моноїд відносно композиції функцій.

Приклад: якщо операція `f₁(x) = x + v₁` (додавання), а `f₂(x) = x + v₂`, то композиція `f₃(x) = x + (v₁ + v₂)`. Якщо ж операції відносяться до різних класів (наприклад, присвоєння значення та додавання), то `lazy`-структура вузла повинна зберігати кортеж операторів із чіткою алгебраїчною пріоритетністю.

## 4. Оцінка просторової складності та верхньої межі `4N`

Поширеним питанням при практиційреалізації відрізкового дерева є розрахунок обсягу необхідної пам'яті під плоский масив. Розглянемо найгірший випадок, коли розмір вхідного масиву `N` не є точним ступенем двійки.

Нехай `N` — кількість елементів. Найближчий більший або рівний ступінь двійки дорівнює `2^(⌈log₂ N⌉)`. Повне двійкове дерево для такої кількості листків містить загальну кількість вузлів `T(N)`:

```
T(N) = 2 · 2^(⌈log₂ N⌉) - 1
```

Оскільки `2^(⌈log₂ N⌉) < 2N`, підставимо цю нерівність у формулу загальної кількості вузлів:

```
T(N) < 2 · (2N) - 1 = 4N - 1
```

Таким чином, масив розміром `4N` математично гарантує, що жоден індекс вузла відрізкового дерева не вийде за межі allocated пам'яті незалежно від значення `N`.

## 5. Матричні моноїди та лінійні рекурентні співвідношення

Потужною теоретичною властивістю відрізкового дерева є можливість обчислення лінійних рекурентних співвідношень на відрізку за допомогою матричного моноїда.

Розглянемо послідовність Фібоначчі або довільний лінійний динамічний процес, де перехід від стану `V[i]` до стану `V[i+1]` задається лінійним перетворенням у формі матриці `M`. Завдяки асоціативності матричного множення `(M₁ × M₂) × M₃ = M₁ × (M₂ × M₃)`, відрізкове дерево здатне зберігати матриці переходу розмірності `K × K` у своїх вузлах.

При виконанні точкової модифікації коефіцієнтів переходу або запиту добутку матриць на відрізку `[L, R]` дерево обчислює підсумкову матрицю перетворення за час `O(K³ log N)`. Це дозволяє розв'язувати задачі динамічного програмування з лінійними переходами на інтервалах із масовими модифікаціями коефіцієнтів.

## 6. Двовимірне відрізкове дерево (2D Segment Tree)

У двовимірному просторі для матриці розміром `N × M` відрізкове дерево будується як «дерево дерев» (англ. *tree of segment trees*). Зовнішнє відрізкове дерево відповідає за декомпозицію рядків `[R1, R2]`, а кожен його вузол сам є повноцінним відрізковим деревом, побудованим над стовпчиками `[C1, C2]`.

Математичні властивості двовимірної структури:
1. **Просторова складність:** `4N · 4M = 16 N M` вузлів для статичного виділення пам'яті.
2. **Часова складність запиту:** обчислення прямокутного регіону `[R1..R2] × [C1..C2]` складається з декомпозиції зовнішнього дерева за `O(log N)` та декомпозиції внутрішніх дерев за `O(log M)`. Загальний час запиту становить `O(log N · log M)`.
3. **Точкове оновлення:** вимагає модифікації `O(log N)` внутрішніх дерев, у кожному з яких оновлюється `O(log M)` вузлів, що дає підсумкову складність `O(log N · log M)`.

## 7. Теоретичний аналіз персистентності та динамічної вибірки координат

Математичні гарантії персистентного відрізкового дерева базуються на інваріанті копіювання шляху (path copying):
- При виконанні точкового оновлення версії `t-1` для створення версії `t` алгоритм виділяє `H = ⌈log₂ N⌉` нових вузлів.
- Усі інші `2 · 2^(⌈log₂ N⌉) - 1 - H` вузлів залишаються спільно використовуваними між версіями `t-1` та `t` без дублювання в пам'яті.
- Витрати пам'яті для `K` оновлень становлять `O(N + K log N)`.

Для неявного (динамічного) дерева при діапазоні координат `[0, U]` кожен точковий запис виділяє не більше `⌈log₂ U⌉` вузлів, що дає точну просторову межу `O(Q log U)` для `Q` запитів.

## 8. Амортизаційний аналіз алгоритму Segment Tree Beats

Техніка Segment Tree Beats (алгоритм Чжи Жуї) застосовується для виконання некомутативних та ненаправлених інтервальних модифікацій виду `A[i] = min(A[i], X)` або `A[i] = A[i] % X`.

Математичне доведення амортизованої логарифмічної складності спирається на функцію потенціалу `Φ`:
- Нехай `Φ` — кількість унікальних значень у піддеревах.
- На кожному кроці рекурсивного спуску, коли `X < max1` та `X > max2`, значення потенціалу `Φ` зменшується щонайменше на 1.
- Оскільки початковий потенціал `Φ₀ <= N log N`, середня амортизована складність виконання одного запиту оновлення становить `O(log N)`.

## 9. Комбінаторна складність Heavy-Light Decomposition (HLD) на деревах

При агрегації шляхів на довільному графі декомпозиція дерева (Heavy-Light Decomposition) ділить довільний шлях між двома вершинами `u` та `v` на послідовність суцільних вертикальних відрізків.

Математичне доведення логарифмічної межі ланцюгів:
- Кожен перехід між різними «важкими» ланцюгами (по «легкому» ребру) зменшує розмір піддерева щонайменше вдвічі: `Size(Parent) >= 2 · Size(Child)`.
- Тому на будь-якому шляху від кореня до довільного листка може бути не більше ніж `⌈log₂ N⌉` легких ребер.
- Це гарантує, що шлях між `u` та `v` розкладається на не більше ніж `2 ⌈log₂ N⌉` суцільних підінтервалів у плоскому масиві відрізкового дерева, що дає підсумкову складність `O(log² N)`.

## 10. Розширення на комбінаторні інваріанти: Алгоритм Кадане на відрізках

Алгебраїчна гнучкість відрізкового дерева дозволяє підтримувати складні комбінаторні величини. Розглянемо задачу пошуку максимальної суми на підвідрізку (Maximum Subarray Sum / Алгоритм Кадане) у динамічному масиві.

Звичайне число `sum` у вузлі недостатнє для комбінування відповідей двох дочірніх піддерев. Тому елементом моноїдної множини `S` роблять структуру з 4 величин `Node`:

```
Node = {
    sum:  загальна сума елементів на відрізку,
    pref: максимальна сума на префіксі відрізка,
    suff: максимальна сума на суфіксі відрізка,
    ans:  максимальна сума на довільному підвідрізку
}
```

Операція об'єднання двох вузлів `Left` та `Right` визначається алгебраїчно:

```
Parent.sum  = Left.sum + Right.sum
Parent.pref = max(Left.pref, Left.sum + Right.pref)
Parent.suff = max(Right.suff, Right.sum + Left.suff)
Parent.ans  = max(Left.ans, Right.ans, Left.suff + Right.pref)
```

Ця операція повністю задовольняє аксіомі асоціативності. Завдяки цьому відрізкове дерево здатне знаходити максимальний підмасив на довільному відрізку `[L, R]` та виконувати точкові й інтервальні оновлення елементів за час `O(log N)`.
