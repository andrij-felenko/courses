# 🧮 Математичні властивості біноміальних дерев та куп

Ця вставка містить строгі математичні доведення п'яти ключових властивостей біноміального дерева `B_k`, глибинний аналіз двійкового ізоморфізму та детальний розрахунок амортизованої складності операцій над біноміальною купою методом потенціалів.

Матеріали розраховані на читачів, які прагнуть зрозуміти теоретичний фундамент структури даних, її комбінаторну природу та причини, з яких амортизована вартість вставки елемента залишається сталою.

---

## 1. Рекурсивне означення біноміального дерева B_k

Біноміальне дерево `B_k` порядку `k ≥ 0` — це впорядковане дерево, яке визначається індуктивно за його порядком `k`:

1. **Базовий випадок (k = 0):** Біноміальне дерево `B_0` складається з єдиного вузла. Його висота дорівнює 0, степінь кореня дорівнює 0, а загальна кількість вузлів дорівнює 1.
2. **Індуктивний крок (k > 0):** Біноміальне дерево `B_k` утворюється з двох однаковісіньких біноміальних дерев `B_{k-1}` порядку `k-1`. Корінь одного з цих дерев під'єднується як найлівіша дитина до кореня іншого дерева.

Наочна схема послідовної рекурсивної побудови дерев від `B_0` до `B_3` виглядає так:

```
  B_0:    ◯

  B_1:    ◯
          |
          ◯

  B_2:    ◯
         / \
        ◯   ◯
        |
        ◯

  B_3:        ◯
          /   |   \
         ◯    ◯    ◯
        / \   |
       ◯   ◯  ◯
       |
       ◯
```

## 2. Фундаментальні теореми про структурні інваріанти B_k

Нижче наведено п'ять теорем, які описують розмір, висоту, степені та комбінаторний розподіл вузлів у біноміальному дереві.

### Теорема 1 (Загальна кількість вузлів). Загальна кількість вузлів у біноміальному дереві B_k порядку k дорівнює точно 2^k.

**Контекст та інтуїція:** Кожне наступне дерево `B_k` будується подвоєнням попереднього дерева `B_{k-1}`. Звідси випливає геометрична прогресія зі значенням `2^k`.

**Строге доведення методом математичної індукції за k:**
- *База індукції (k = 0):* За означенням, `B_0` містить 1 вузол. Оскільки `2⁰ = 1`, база індукції виконується.
- *Індуктивне припущення:* Нехай твердження правильне для дерева порядку `k - 1`, тобто `|B_{k-1}| = 2^{k-1}`.
- *Індуктивний крок:* За рекурсивним означенням, дерево `B_k` утворюється об'єднанням двох екземплярів `B_{k-1}`. Обчислимо сумарну кількість вузлів:

```
|B_k| 
= |B_{k-1}| + |B_{k-1}|      [означення об'єднання двох B_{k-1}]
= 2^{k-1} + 2^{k-1}          [за індуктивним припущенням]
= 2 · 2^{k-1}                 [алгебраїчне групування]
= 2^k                         [властивість степенів]
```

Отже, за принципом математичної індукції, кількість вузлів у біноміальному дереві `B_k` дорівнює `2^k` для всіх `k ≥ 0`. ■

---

### Теорема 2 (Висота дерева). Висота дерева B_k (довжина найдовшого шляху від кореня до листка) дорівнює k.

**Контекст та інтуїція:** При під'єднанні одного дерева `B_{k-1}` під корінь іншого `B_{k-1}` під'єднане дерево опускається на один рівень глибше. Це збільшує довжину найдовшого шляху від кореня до листків приєднаного дерева рівно на 1.

**Строге доведення методом математичної індукції за k:**
- *База індукції (k = 0):* Дерево `B_0` має лише один корінь і нуль ребер. Довжина найдовшого шляху дорівнює 0. База виконується.
- *Індуктивне припущення:* Нехай висота дерева `B_{k-1}` дорівнює `k - 1`.
- *Індуктивний крок:* При створенні `B_k` корінь дочірнього `B_{k-1}` з'єднується з коренем основного `B_{k-1}` новим ребром. Найдовший шлях тепер проходить через це нове ребро у дочірнє дерево `B_{k-1}`:

```
height(B_k) 
= 1 + height(child_B_{k-1})  [нове ребро від кореня додає 1 до глибини]
= 1 + (k - 1)                [за індуктивним припущенням]
= k                          [спрощення виразу]
```

Отже, висота біноміального дерева `B_k` дорівнює його порядку `k`. ■

---

### Теорема 3 (Степінь кореня та будова його піддерев). Корінь дерева B_k має степінь k (тобто має k безпосередніх дітей). Дітьми кореня B_k є корені біноміальних дерев B_{k-1}, B_{k-2}, ..., B_0, розташовані у порядку спадання їхніх степенів.

**Доведення:**
Розглянемо процес послідовної побудови дерева `B_k`. Починаючи з єдиного вузла `B_0`, ми послідовно приєднуємо до його кореня нові дерева на кроках 1, 2, ..., `k`.
- На кроці 1 до кореня приєднується корінь дерева `B_0`.
- На кроці 2 до кореня приєднується корінь дерева `B_1`.
- ...
- На кроці `k` до кореня приєднується корінь дерева `B_{k-1}`.

Оскільки кожна дитина приєднується як найлівіша дитина, діти кореня у списку ідуть у порядку `B_{k-1}, B_{k-2}, ..., B_0`. Загальна кількість дітей дорівнює кількості кроків, тобто `k`. ■

### Теорема 4 (Розподіл вузлів по рівнях — Біноміальний коефіцієнт). Кількість вузлів у біноміальному дереві B_k на глибині i (де 0 ≤ i ≤ k) дорівнює біноміальному коефіцієнту C(k, i) = k! / (i! · (k - i)!).

**Контекст та інтуїція:** Ця теорема пояснює назву усієї структури даних. Кількість вузлів на кожному рівні дерева описується коефіцієнтами розкладу бінома Ньютона `(x + y)^k`.

**Строге доведення (метод математичної індукції за k та тотожність Паскаля):**
- *База індукції (k = 0):* На глибині `i = 0` сидить `C(0, 0) = 1` вузол (корінь). База виконується.
- *Індуктивний крок:* Нехай для `B_{k-1}` кількість вузлів на глибині `i` дорівнює `C(k-1, i)`.
Дерево `B_k` складається з основного `B_{k-1}` та дочірнього `B_{k-1}`. Будь-який вузол на глибині `i` в `B_k` належить до однієї з двох категорій:
1. Вузол перебуває в основному `B_{k-1}` на глибині `i`. За індуктивним припущенням таких вузлів є `C(k-1, i)`.
2. Вузол перебуває у дочірньому `B_{k-1}`. Оскільки це дерево опустилося на один рівень нижче під корінь `B_k`, у своєму власному дереві цей вузол перебував на глибині `i - 1`. За індуктивним припущенням таких вузлів є `C(k-1, i-1)`.

Складаємо кількість вузлів з обох частин:

```
nodes(B_k, i)
= nodes(main_B_{k-1}, i) + nodes(child_B_{k-1}, i - 1)    [сума вузлів основної та дочірньої гілок]
= C(k-1, i) + C(k-1, i - 1)                              [за індуктивним припущенням]
= C(k, i)                                                 [за тотожністю Паскаля C(n-1, k) + C(n-1, k-1) = C(n, k)]
```

Саме ця тотожність Паскаля доводить, що розподіл вузлів по рівнях у біноміальному дереві строго збігається з біноміальними коефіцієнтами! ■

## 3. Двійковий ізоморфізм біноміальної купи

Розглянемо біноміальну купу `H`, яка містить загалом `N` елементів. 

Представимо число `N` у позиційній двійковій системі числення:

```
N = b_r · 2^r + b_{r-1} · 2^{r-1} + ... + b_1 · 2¹ + b_0 · 2⁰
```

де кожен розряд `b_i ∈ {0, 1}`, а старший розряд `r = ⌊log₂ N⌋`.

З теореми 1 випливає, що розклад купи на окремі дерева `B_k` є **ізоморфним двійковому запису її розміру N**:
1. Дерево `B_i` присутнє в кореневому списку купи `H` тоді й лише тоді, коли біт `b_i = 1`.
2. Загальна кількість дерев у купі дорівнює вазі Геммінга `w(N)` — кількості одиничних бітів у двійковому записі `N`.
3. Оскільки двійковий запис числа `N` містить не більше ніж `⌊log₂ N⌋ + 1` бітів, купа з `N` елементів містить **не більше ніж O(log N) дерев**.

### Ізоморфізм злиття та двійкового додавання

Операція об'єднання (злиття) двох куп `H_1` (з `N_1` елементами) та `H_2` (з `N_2` елементами) математично тотожна додаванню двох чисел `N_1 + N_2` у стовпчик:

```
  1 0 1   (N_1 = 5: купа містить дерева B_2 та B_0)
+ 0 1 1   (N_2 = 3: купа містить дерева B_1 та B_0)
-------
1 0 0 0   (N_1 + N_2 = 8: результатом є єдине дерево B_3)
```

Коли у певному розряді `i` додаються дві одиниці (два дерева `B_i`), виникає перенос (carry): два дерева `B_i` за сталий час `O(1)` зливаються в одне дерево `B_{i+1}` шляхом порівняння ключів їхніх коренів.

## 4. Амортизований аналіз операції вставки (метод потенціалів)

Хоча у найгіршому випадку вставка одного елемента може вимагати `O(log N)` кроків (якщо відбуваються каскадні переноси при додаванні `1` до `111...1₂`), її **амортизована вартість є сталою — O(1)**.

Доведемо це за допомогою **методу потенціалів**.

### Визначення потенціалу

Визначимо потенційну функцію купи `Φ(H)` як кількість дерев у її кореневому списку:

```
Φ(H) = t(H)
```

де `t(H)` — кількість дерев у купі `H`.

Потенціал `Φ(H) ≥ 0` для будь-якої купи, і `Φ(H_0) = 0` для порожньої купи.

### Розрахунок амортизованої вартості вставки

Нехай операція `insert` додає один новий вузол `B_0` у купу `H`. Припустимо, що у двійковому записі `N` молодші `k` бітів є одиницями: `...011...1₂`.

- При додаванні новий вузол `B_0` викликає ланцюжок з `k` злиттів дерев однакових степенів (каскад переносу бітів).
- **Фактична вартість операції:** `c_i = k + 1` (виконується `k` об'єднань пар дерев plus виділення нового вузла).
- **Початковий потенціал:** `Φ(H) = t(H)`.
- **Кінцевий потенціал:** `Φ(H') = t(H) - k + 1` (замість `k` старих дерев утворилося 1 нове дерево степеня `B_k`).

Обчислимо амортизовану вартість `a_i` за формулою `a_i = c_i + Φ(H') - Φ(H)`:

```
a_i
= c_i + Φ(H') - Φ(H)                                    [означення амортизованої вартості за методом потенціалів]
= (k + 1) + (t(H) - k + 1) - t(H)                       [підстановка c_i = k + 1 та Φ(H') = t(H) - k + 1]
= k + 1 - k + 1                                         [взаємне скорочення потенціалів t(H)]
= 2                                                     [алгебраїчне спрощення: k - k = 0]
= O(1)                                                  [стала вартість, незалежна від розміру купи]
```

**Висновок:** Амортизована вартість кожної вставки становить **O(1)**. Це означає, що послідовне виконання `N` операцій вставки у порожню купу гарантовано вимагатиме не більше ніж `O(N)` дій загалом, а середня вартість однієї вставки дорівнюватиме сталій величині.
