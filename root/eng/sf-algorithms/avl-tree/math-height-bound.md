# 🧮 Доведення логарифмічної межі висоти AVL-дерева

Головна алгебраїчна та обчислювальна перевага AVL-дерева полягає у наданні суворої гарантії логарифмічної висоти навіть у найгіршому випадку вхідних даних. Оскільки максимальний час виконання операцій пошуку, вставки та видалення прямо пропорційний висоті дерева `h`, знаходження строгої верхньої межі `h` залежно від кількості вузлів `n` є ключовим теоретичним результатом у теорії балансованих дерев.

У цьому математичному додатку розібрано повне, крок за кроком виведення верхньої межі висоти AVL-дерева через числа Фібоначчі та детально проаналізовано асимптотичні властивості отриманої оцінки.

## 1. Постановка оптимізаційної задачі

Перед тим як шукати максимальну висоту для заданої кількості вузлів `n`, зручніше сформулювати обернену задачу: **якою є найменша кількість вузлів `N(h)`, необхідна для побудови дійсного AVL-дерева висоти `h`?**

Якщо ми знайдемо функцію `N(h)`, яка визначає мінімальну кількість вузлів у найгіршому разі (найбільш перекошеному дійсній структурі), то нерівність `n ≥ N(h)` дозволить прямо виразити `h` через `n` шляхом логарифмування.

Приймемо такі позначення та базові інваріанти:
- Висота порожнього дерева дорівнює 0: `h(NULL) = 0`.
- Висота одного вузла-листка дорівнює 1: `h(leaf) = 1`.
- Для будь-якого вузла `v` фактор балансу дорівнює `BF(v) = height(Right(v)) - height(Left(v))`.
- Основний інваріант AVL-дерева вимагає, щоб `|BF(v)| ≤ 1` для кожного вузла.

## 2. Дерева Фібоначчі та рекурентне співвідношення

Розглянемо AVL-дерево висоти `h`, яке містить мінімально можливу кількість вузлів `N(h)`.

Щоб дерево мало висоту `h` при мінімальній кількості елементів, його корінь повинен об'єднувати:
1. **Один вузол у самому корені** (корінь піддерева).
2. **Одне піддерево висоти `h - 1`**, яке також є мінімальним AVL-деревом цієї висоти і містить `N(h - 1)` вузлів.
3. **Друге піддерево висоти `h - 2`**, яке має мінімальну допустиму за інваріантом висоту і містить `N(h - 2)` вузлів.

Якщо зробити одне з піддерев ще коротшим (наприклад, висоти `h - 3`), різниця висот між піддеревами кореня становила б `(h - 1) - (h - 3) = 2`, що є грубим порушенням інваріанта `|BF| ≤ 1`. Якщо ж зробити друге піддерево довшим (висоти `h - 1`), загальна кількість вузлів не буде мінімальною.

Звідси випливає фундаментальне рекурентне співвідношення для мінімальної кількості вузлів:

```
N(h) = N(h - 1) + N(h - 2) + 1
```

Обчислимо початкові базові значення для малих висот:
- Для `h = 1` мінімальним є єдиний вузол-корінь: `N(1) = 1`.
- Для `h = 2` корінь повинен мати один син висоти 1 і порожнє друге піддерево: `N(2) = 1 + N(1) + N(0) = 1 + 1 + 0 = 2`.

Застосуємо рекурентну формулу послідовно для обчислення кількох наступних значень:

```
N(1) = 1
N(2) = 2
N(3) = N(2) + N(1) + 1 = 2 + 1 + 1 = 4
N(4) = N(3) + N(2) + 1 = 4 + 2 + 1 = 7
N(5) = N(4) + N(3) + 1 = 7 + 4 + 1 = 12
N(6) = N(5) + N(4) + 1 = 12 + 7 + 1 = 20
N(7) = N(6) + N(5) + 1 = 20 + 12 + 1 = 33
```

Такі гранично перекошені AVL-дерева в науковій літературі називають **деревами Фібоначчі** (англ. *Fibonacci trees*). Вони демонструють граничну формальну конструкцію, у якій кожен вузол має фактор балансу рівно `-1` або `+1`.

## 3. Зв'язок із послідовністю чисел Фібоначчі

Пригадаймо стандартне визначення класичних чисел Фібоначчі `Fₖ`:
- `F₀ = 0`
- `F₁ = 1`
- `F₂ = 1`
- `F₃ = 2`
- `F₄ = 3`
- `F₅ = 5`
- `F₆ = 8`
- `F₇ = 13`
- `F₈ = 21`
- `F₉ = 34`

Зіставимо значення `N(h)` із елементами послідовності `Fₕ₊₂`:

```
h = 1:  N(1) = 1,   F₃ = 2   →  N(1) = F₃ - 1
h = 2:  N(2) = 2,   F₄ = 3   →  N(2) = F₄ - 1
h = 3:  N(3) = 4,   F₅ = 5   →  N(3) = F₅ - 1
h = 4:  N(4) = 7,   F₆ = 8   →  N(4) = F₆ - 1
h = 5:  N(5) = 12,  F₇ = 13  →  N(5) = F₇ - 1
h = 6:  N(6) = 20,  F₈ = 21  →  N(6) = F₈ - 1
h = 7:  N(7) = 33,  F₉ = 34  →  N(7) = F₉ - 1
```

Сформулюємо математичну теорему: для будь-якого цілого `h ≥ 1` мінімальна кількість вузлів AVL-дерева висоти `h` задається тотожністю **`N(h) = Fₕ₊₂ - 1`**.

Доведемо цю теорему методом повної математичної індукції.

**База індукції:**
- Для `h = 1`: `N(1) = 1` та `F₃ - 1 = 2 - 1 = 1` (збігається).
- Для `h = 2`: `N(2) = 2` та `F₄ - 1 = 3 - 1 = 2` (збігається).

**Індукційний крок:**
Припустимо, що тотожність `N(k) = Fₖ₊₂ - 1` виконана для всіх `k < h`. Перевіримо її для значення `h`:

```
N(h) = N(h - 1) + N(h - 2) + 1                  [за визначенням рекурентності]
     = (Fₕ₊₁ - 1) + (Fₕ - 1) + 1                [за припущенням індукції для h-1 та h-2]
     = Fₕ₊₁ + Fₕ - 1                             [групування числових доданків]
     = Fₕ₊₂ - 1                                  [за фундаментальною тотожністю Фібоначчі: Fₖ = Fₖ₋₁ + Fₖ₋₂]
```

Індукційний крок доведено. Тотожність `N(h) = Fₕ₊₂ - 1` є строгою і справедливою для всіх вимірних висот.

## 4. Виведення нерівності верхньої межі висоти

Для чисел Фібоначчі відома формула Біне:

```
Fₖ = (φₖ - (1 - φ)ₖ) / √5
```

де `φ` — число золотого перетину (лат. *sectio aurea*), яке дорівнює алгебраїчному кореню рівняння `x² - x - 1 = 0`:

```
φ = (1 + √5) / 2 ≈ 1.6180339887...
```

Оскільки другорядне значення `|(1 - φ)ₖ / √5| < 0.5` для всіх `k ≥ 1`, число Фібоначчі строго обмежене знизу експоненційним виразом:

```
Fₖ > (φₖ / √5) - 1
```

Поєднаємо це із доведеною тотожністю для довільного AVL-дерева з `n` вузлами:

```
n ≥ N(h) = Fₕ₊₂ - 1
n + 1 ≥ Fₕ₊₂
n + 1 > (φ⁽ʰ⁺²⁾ / √5) - 1
n + 2 > φ⁽ʰ⁺²⁾ / √5                            [додано 1 до обох частин]
```

Помножимо обидві частини нерівності на `√5`:

```
√5 · (n + 2) > φ⁽ʰ⁺²⁾
```

Прологарифмуємо обидві частини нерівності за основою `φ`:

```
log_φ (√5 · (n + 2)) > h + 2
h + 2 < log_φ (√5) + log_φ (n + 2)             [за властивістю логарифма добутку]
h < log_φ (n + 2) + log_φ (√5) - 2             [віднято 2 від обох частин]
```

Тепер перейдемо від логарифма за основою `φ` до логарифма за основою 2 за допомогою формули зміни основи: `log_φ (x) = log₂ (x) / log₂ (φ)`.

Обчислимо константу коефіцієнта пропорційності:

```
1 / log₂ (φ) = 1 / log₂ (1.6180339887)          [підстановка значення золотого перетину]
            ≈ 1 / 0.6942419136                 [обчислення логарифма за основою 2]
            ≈ 1.440420088                      [значення коефіцієнта пропорційності]
```

Також обчислимо значення сталого зсуву:

```
log_φ (√5) - 2 = (log₂ (√5) / log₂ (φ)) - 2    [формула зміни основи логарифма]
               = (1.1609640474 / 0.6942419136) - 2 [ділення логарифмів]
               = 1.6722754 - 2                 [числовий результат частки]
               = -0.3277246                    [підсумкове значення зсуву]
```

Підставимо ці значення у нерівність висоти:

```
h < 1.44042 · log₂ (n + 2) - 0.3277
```

Таким чином, доведено нерівність:

```
h < 1.4404 · log₂ (n + 2)
```

## 5. Геометричний зміст та аналіз щільності

Отримана верхня межа показує, що навіть за умов найбільшого можливого перекосу, коли на кожному рівні дерева одна з гілок є коротшою за іншу на 1 рівень, висота AVL-дерева зростає строго як логарифмічна функція.

Геометрично це можна уявити так: якщо звичайне повне двійкове дерево має абсолютно плоску нижню межу (всі листки знаходяться на одному рівні `h`), то дерево Фібоначчі має ступенчату межу листків. Проте завдяки тому, що на кожному рівні кількість вузлів зростає у пропорції золотого перетину `φ ≈ 1.618`, площа розгалуження залишається експоненційною.

Порівняємо коефіцієнти для різних типів дерев пошуку:

1. **Ідеально повне двійкове дерево:**
   - Висота: `h_ideal = ⌈log₂ (n + 1)⌉ ≈ 1.000 · log₂ n`.

2. **AVL-дерево у найгіршому випадку (дерево Фібоначчі):**
   - Висота: `h_max = 1.4404 · log₂ n`.
   - Максимальний перекіс перевищує теоретичний ідеал не більше ніж на 44%.

3. **Червоно-чорне дерево у найгіршому випадку:**
   - Висота: `h_max = 2.0000 · log₂ n`.
   - Допускає подвійний перекіс довжини чорно-червоних шляхів, тобто перевищує ідеал на 100%.

4. **Незбалансоване двійкове дерево пошуку у найгіршому випадку:**
   - Висота: `h_worst = n`.

### Практичний приклад обчислення для великих обсягів даних

Обчислимо граничну висоту AVL-дерева для таблиці з **1 000 000 000** (один мільярд) елементів:

```
h_ideal = log₂ (10⁹) ≈ 29.89  →  30 рівнів
h_avl_max = 1.4404 · log₂ (10⁹) ≈ 1.4404 · 29.897 ≈ 43 рівні
h_rb_max = 2.0000 · log₂ (10⁹) ≈ 60 рівнів
```

Отже, для обходу мільярда записів у AVL-дереві знадобиться використати максимум 43 порівняння ключів у найгіршому разі. Це гарантує стабільну продуктивність системи без несподіваних падінь швидкості та забезпечує суворі асимптотичні межі для алгоритмів реального часу.
