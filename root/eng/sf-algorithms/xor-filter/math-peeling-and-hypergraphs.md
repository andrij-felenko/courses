Математична основа Xor-фільтра спирається на комбінаторні властивості випадкових 3-однорідних гіперграфів (3-uniform hypergraphs), теорію фазових переходів у випадкових структурах та розв'язання трикутних систем лінійних алгебраїчних рівнянь над скінченними полями `GF(2)`.

Розглянемо послідовне строге математичне обґрунтування того, чому коефіцієнт розширення пам'яті дорівнює саме `c ≈ 1.23`, як алгоритм лущення зводить матричне рівняння до верхньотрикутного вигляду та чому ймовірність помилки строго дорівнює `2^(-r)`.

## Формалізація задачі через 3-часткові гіперграфи

Нехай задано фіксовану множину з `N` унікальних ключів:

```
S = {x₀, x₁, x₂, ..., x_{N-1}}
```

Фільтр створює масив слотів `B` загального розміру `M = 3 · L`, де `L = ⌈c · N / 3⌉`, а `c > 1` — коефіцієнт просторового надлишку. Масив `B` розбивається на три рівні неперетинні сегменти:

```
B₀ = B[0 .. L-1]
B₁ = B[L .. 2L-1]
B₂ = B[2L .. 3L-1]
```

Для кожного ключа `x ∈ S` три незалежні псевдовипадкові хеш-функції `h₀, h₁, h₂` генерують індекси комірок у відповідних сегментах:

```
h₀(x) ∈ {0, 1, ..., L-1}
h₁(x) ∈ {L, L+1, ..., 2L-1}
h₂(x) ∈ {2L, 2L+1, ..., 3L-1}
```

Крім того, незалежна хеш-функція `f(x)` генерує `r`-бітний відбиток (фінгерпринт):

```
f: S → {0, 1}^r
```

Цю конструкцію можна розглядати як випадковий 3-частковий гіперграф `H = (V, E)`:
* Множина вершин `V = V₀ ∪ V₁ ∪ V₂` відповідає слотам масиву `B`, де `|V| = M = 3L`.
* Множина гіперребер `E` складається з `N` трійок `e(x) = {h₀(x), h₁(x), h₂(x)}` для кожного `x ∈ S`.

Задача побудови фільтра зводиться до пошуку значень комірок `B[0 .. M-1] ∈ {0, 1}^r`, які задовольняють систему з `N` лінійних рівнянь над простором `({0, 1}^r, ⊕)`:

```
B[h₀(x)] ⊕ B[h₁(x)] ⊕ B[h₂(x)]
= f(x),    ∀ x ∈ S        [система рівнянь для кожного ключа]
```

## Матрична форма над полем GF(2)

Кожне `r`-бітне рівняння можна розбити на `r` незалежних рівнянь над двійковим полем `GF(2) = ({0, 1}, ⊕, ·)`. 

Нехай `A` — матриця інцидентності гіперграфа `H` розміру `N × M`, де елемент `A[i, j] = 1`, якщо вершина `j ∈ e(x_i)`, і `A[i, j] = 0` у протилежному випадку:

```
A · B = F        [матричне рівняння над полем GF(2)]
```

Тут:
* `A ∈ {0, 1}^{N × M}` — матриця інцидентності, у кожному рядку якої міститься строго три одиниці.
* `B ∈ ({0, 1}^r)^{M × 1}` — шуканий стовпець слотів фільтра.
* `F ∈ ({0, 1}^r)^{N × 1}` — стовпець цільових відбитків ключів.

Оскільки кількість невідомих `M = 1.23 · N` перевищує кількість рівнянь `N`, система є недовизначеною. Якщо рядки матриці `A` є лінійно незалежними над `GF(2)` (або система є сумісною), розв'язок гарантовано існує.

Однак пряме розв'язання методом Гаусса над `GF(2)` вимагає часу `O(N · M²) = O(N³)`, що є неприйнятним для великих обсягів даних. Xor-фільтр досягає часу `O(N)` завдяки алгоритму лущення гіперграфа (Peeling Algorithm).

## Теорема про 2-ядро випадкового 3-гіперграфа та поріг c ≈ 1.23

**Означення 2-ядра (2-core):** 2-ядром гіперграфа називається його максимальний підгіперграф, у якому кожна вершина має степінь (кількість інцидентних гіперребер) не менше 2.

**Алгоритм лущення (Peeling):**
1. Знайти вершину `v ∈ V` степеня `d(v) = 1`.
2. Якщо такої вершини немає, алгоритм зупиняється.
3. Нехай `e = {v, u, w}` — єдине гіперребро, що містить `v`.
4. Додати пару `(e, v)` на вершину стека `Stack`.
5. Видалити гіперребро `e` з гіперграфа `H` та зменшити степені вершин `v, u, w` на 1.
6. Повторювати з кроку 1, доки всі `N` гіперребер не будуть видалені або черга вершин степеня 1 не спорожніє.

Якщо в результаті лущення всі `N` ребер опиняються в стеку, 2-ядро гіперграфа є **порожнім** (`2-core(H) = ∅`).

**Фазовий перехід (Phase Transition):**
Поведінка 2-ядра у випадкових `k`-однорідних гіперграфах підпорядковується закону фазового переходу. Нехай `c = M / N` — відношення кількості вершин до кількості ребер.

Математичний аналіз динамічної системи лущення методом диференціальних рівнянь (теорема Моллоя, 2005 та Діцфельбінгера — Пага, 2008) визначає частку вершин степеня `k` через систему пуассонівських розподілів.

Для 3-часткового гіперграфа критичний поріг фазового переходу `c*` визначається як точка, де ймовірність виникнення непорожнього 2-ядра стрибкоподібно спадає до нуля при `N → ∞`:

```
c* ≈ 1.2217...     [теоретичний поріг зникнення 2-ядра]
```

При виборі коефіцієнта `c = 1.23 > c*`:
* Ймовірність того, що гіперграф повністю злущиться (2-ядро порожнє), прямує до строго додатної константи `p_success ≈ 0.82` (для `c = 1.23`) уже з першої спроби побудови.
* Середня кількість спроб до першого успішного лущення є геометрично розподіленою величиною:

```
E[T]
= 1 / p_success
≈ 1 / 0.82
≈ 1.22 спроби     [математичне сподівання кількості спроб]
```

Оскільки кожна спроба лущення виконується за лінійний час `O(N)` через підтримку масиву степенів та черги вершин степеня 1, загальний очікуваний час побудови становить строго `O(N)`.

## Зведення матриці до верхньотрикутного вигляду

Порядок видалення ребер у стеку `Stack = [(e₁, v₁), (e₂, v₂), ..., (e_N, v_N)]` визначає перестановку рядків і стовпців матриці інцидентності `A`.

Нехай рядки матриці впорядковано відповідно до витягування зі стеку (від `e_N` до `e₁`), а перші `N` стовпців відповідають виділеним вершинам `v_N, v_{N-1}, ..., v₁`. Тоді підматриця розміру `N × N` набуває строго верхньотрикутного вигляду з одиницями на головній діагоналі:

```
A_perm = 
[ 1  *  *  ...  * ]
[ 0  1  *  ...  * ]
[ 0  0  1  ...  * ]
[ ⋮  ⋮  ⋮  ⋱   ⋮ ]
[ 0  0  0  ...  1 ]
```

Для кожного рівняння `i` невідома змінна `B[v_i]` з'являється на діагоналі й не залежить від змінних `B[v_j]` для `j < i` (оскільки на момент лущення ребра `e_i` вершина `v_i` не була інцидентна жодному іншому неполущеному ребру).

### Зворотна підстановка (Back-substitution)

Розв'язання системи виконується проходженням стека від вершини до дна (LIFO):

```
B[v_i]
= f(x_i) ⊕ B[u_i] ⊕ B[w_i]        [де u_i, w_i — інші дві вершини ребра e_i]
```

На момент обчислення `B[v_i]` значення слотів `B[u_i]` та `B[w_i]` уже повністю визначені попередніми кроками (або залишаються нулями, якщо вони не були опорними вершинами). Таким чином, кожен крок зворотної підстановки є детермінованим і виконує рівно дві операції `XOR`.

## Строгий розрахунок ймовірності хибнопозитивного спрацьовування (FPR)

Розглянемо властивості Xor-фільтра при перевірці довільного ключа `y`.

### Випадок 1: Ключ належить множині (`y ∈ S`)
За алгоритмом побудови значення слотів `B` обрано так, що для всіх `x_i ∈ S` рівність виконується тотожно:

```
B[h₀(y)] ⊕ B[h₁(y)] ⊕ B[h₂(y)]
= f(y)        [за побудовою зворотної підстановки]
```

Отже, ймовірність хибнонегативної відповіді строго дорівнює нулю:

```
P(Відповідь = «НІ» | y ∈ S)
= 0        [гарантія відсутності False Negatives]
```

### Випадок 2: Ключ не належить множині (`y ∉ S`)
Якщо `y ∉ S`, то трійка індексів `(h₀(y), h₁(y), h₂(y))` та цільовий відбиток `f(y)` генеруються незалежними псевдовипадковими хеш-функціями.

Величина `V(y) = B[h₀(y)] ⊕ B[h₁(y)] ⊕ B[h₂(y)]` є детермінованою сумою трьох комірок масиву `B`. Оскільки хеш-функція `f(y)` є незалежною від масиву `B` для ключів, які не брали участі у побудові фільтра, значення `f(y)` розподілене рівномірно на просторі всіх `2^r` бінарних векторів довжини `r`:

```
P(f(y) = v)
= 1 / (2^r),    ∀ v ∈ {0, 1}^r        [рівномірний розподіл відбитка]
```

Ймовірність того, що випадкова комбінація слотів `V(y)` випадково збіжиться зі значенням `f(y)`, становить:

```
ε
= P(V(y) = f(y) | y ∉ S)
= ∑_{v ∈ {0, 1}^r} P(V(y) = v) · P(f(y) = v)
= (1 / 2^r) · ∑_{v} P(V(y) = v)
= (1 / 2^r) · 1
= 2^(-r)        [точна ймовірність хибнопозитивного спрацьовування]
```

## Ефективність використання пам'яті та межа Шеннона

Порівняємо витрати пам'яті Xor-фільтра з теоретичною межею Шеннона та класичним фільтром Блума:

1. **Теоретичний мінімум Шеннона**:
```
S_min
= N · log₂(1/ε)
= N · log₂(2^r)
= r · N бітів        [ентропійний мінімум: r бітів на ключ]
```

2. **Витрати Xor-фільтра**:
Фільтр виділяє `M = 1.23 · N` слотів, кожен з яких містить `r` бітів:
```
S_xor
= M · r
= 1.23 · r · N бітів
= 1.23 · S_min        [лише +23% надлишку понад межу Шеннона]
```

3. **Витрати фільтра Блума**:
Оптимальний фільтр Блума вимагає `m / N = (1 / ln 2) · log₂(1/ε) ≈ 1.4427 · r` бітів на ключ:
```
S_bloom
= 1.4427 · r · N бітів
= 1.4427 · S_min        [+44.3% надлишку понад межу Шеннона]
```

```
Відбиток r   Цільовий FPR (ε)   Xor-фільтр (біт/ключ)   Фільтр Блума (біт/ключ)   Економія Xor
```

Для досягнення стандартного 1% FPR (`ε = 0.01`, що відповідає `r = 6.64` біта):
* Фільтр Блума потребує `1.4427 · 6.64 ≈ 9.58` біта на ключ.
* Дробовий Xor-фільтр (або 8-бітний Xor-фільтр з набагато вищою точністю 0.39%) споживає `9.84` біта, даючи у 2.5 раза меншу кількість помилок при майже однаковому обсязі пам'яті.
