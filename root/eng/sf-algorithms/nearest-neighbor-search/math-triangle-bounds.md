# 🧮 Математичні межі та відсікання за нерівністю трикутника

Усі структури точного та наближеного просторового індексування, від метричних дерев до графових навігаторів, спираються на властивості метричного простору. Якщо множина об'єктів `M` забезпечена дійсною функцією відстані `d: M × M → ℝ`, ця функція мусить задовольняти чотири фундаментальні аксіоми:

1. Невід'ємність: `d(x, y) ≥ 0` для всіх `x, y ∈ M`.
2. Тотожність нерозрізнюваних: `d(x, y) = 0` тоді й лише тоді, коли `x = y`.
3. Симетрія: `d(x, y) = d(y, x)` для всіх `x, y ∈ M`.
4. Нерівність трикутника: `d(x, z) ≤ d(x, y) + d(y, z)` для будь-яких трьох точок `x, y, z ∈ M`.

Саме четверта аксіома робить можливим геометричне індексування: вона дозволяє оцінити відстань між невідомими точками через їхню відстань до відомої опорної вершини (англ. *pivot* або *vantage point*), не обчислюючи саму відстань.

### Виведення нижньої та верхньої меж відстані

Нехай `q` — точка запиту, `P` — заздалегідь обрана опорна точка (центр розбиття простору), а `x` — довільна точка бази даних. Відстань `d(P, x)` обчислюється один раз під час побудови індексу й зберігається в пам'яті. Під час виконання запиту алгоритм обчислює лише одне число — `d(q, P)`.

Застосуємо нерівність трикутника для трійки точок `(q, P, x)`:

```
d(q, P) ≤ d(q, x) + d(x, P)
d(q, P) − d(P, x) ≤ d(q, x)    [віднімання d(P, x) від обох частин, симетрія d(x,P) = d(P,x)]
```

Аналогічно, розглянемо нерівність трикутника для трійки `(P, x, q)`:

```
d(P, x) ≤ d(P, q) + d(q, x)
d(P, x) − d(q, P) ≤ d(q, x)    [віднімання d(q, P), симетрія d(P,q) = d(q,P)]
−(d(q, P) − d(P, x)) ≤ d(q, x) [винесення знака мінус]
```

Поєднуючи обидві нерівності, отримуємо строгу нижню оцінку відстані (так звану зворотну нерівність трикутника):

```
|d(q, P) − d(P, x)| ≤ d(q, x)
```

З іншого боку, пряма нерівність трикутника для трійки `(q, x, P)` дає верхню межу:

```
d(q, x) ≤ d(q, P) + d(P, x)
```

Повний діапазон можливих значень невідомої відстані `d(q, x)` затиснутий у строгих границях:

```
|d(q, P) − d(P, x)| ≤ d(q, x) ≤ d(q, P) + d(P, x)
```

### Критерії відсікання піддерев у метричних деревах

Нехай поточний знайдений кандидат на найближчого сусіда розташований на відстані `r_best = d(q, p_curr)`. Ми прагнемо знайти точку з меншою відстанню, тобто область нашого пошуку обмежена сферою радіуса `r_best` із центром у `q`.

Припустимо, опорна точка `P` ділить множину точок на два піддерева відносно радіуса розбиття `R_split`:
- Внутрішнє піддерево `S_in`: усі точки `x`, для яких `d(P, x) ≤ R_split`.
- Зовнішнє піддерево `S_out`: усі точки `x`, для яких `d(P, x) > R_split`.

#### Критерій 1: Відсікання внутрішнього піддерева

Якщо запит `q` лежить далеко ззовні сфери `P`, і нижня межа відстані до будь-якої точки всередині перевищує радіус пошуку `r_best`:

```
d(q, P) − R_split > r_best
```

Перевіримо, чому жодна точка `x ∈ S_in` не може бути ближчою за `r_best`:

```
d(q, x) ≥ d(q, P) − d(P, x)    [нижня межа за нерівністю трикутника]
d(q, x) ≥ d(q, P) − R_split    [оскільки d(P, x) ≤ R_split для всіх x ∈ S_in]
d(q, x) > r_best               [за припущенням критерію відсікання]
```

Отже, жодна точка внутрішнього піддерева не може покращити поточний результат. Піддерево `S_in` (яке може містити мільйони точок) відкидається цілком без жодного додаткового обчислення відстаней.

#### Критерій 2: Відсікання зовнішнього піддерева

Якщо запит `q` лежить глибоко всередині сфери `P`, і відстань до межі сфери більша за радіус пошуку:

```
R_split − d(q, P) > r_best
```

Доведення аналогічне:

```
d(q, x) ≥ d(P, x) − d(q, P)    [нижня межа за нерівністю трикутника]
d(q, x) > R_split − d(q, P)    [оскільки d(P, x) > R_split для всіх x ∈ S_out]
d(q, x) > r_best               [за припущенням критерію відсікання]
```

Зовнішнє піддерево `S_out` повністю відкидається.

### Відсікання у задачі пошуку k найближчих сусідів (k-NN)

Під час пошуку не одного, а `k` найближчих сусідів алгоритм підтримує макс-купу (англ. *max-heap*) місткістю `k` елементів. Нехай `r_k` — найбільша відстань серед поточних `k` найкращих знайдених кандидатів (корінь макс-купи).

Поки купа містить менше ніж `k` точок, `r_k = ∞`, і жодне піддерево не може бути відтяте. Щойно знайдено перші `k` точок, величина `r_k` стає динамічним радіусом пошуку.

Правила відсікання для макс-купи мають вигляд:

```
d(q, P) − R_split ≥ r_k   ⇒   пропустити внутрішнє піддерево S_in
R_split − d(q, P) ≥ r_k   ⇒   пропустити зовнішнє піддерево S_out
```

Кожного разу, коли алгоритм знаходить нову точку `x` із відстанню `d(q, x) < r_k`, він видаляє найгіршого кандидата з купи, вставляє `x` і оновлює `r_k`. Зі звуженням `r_k` ефективність відсікання монотонно зростає під час обходу.

### Багатоопорне фільтрування (Multi-Pivot Filtering)

Якщо в системі обрано `m` фіксованих опорних точок `P₁, P₂, ..., P_m`, для кожної точки бази `x` заздалегідь обчислено вектор відстаней `[d(P₁, x), d(P₂, x), ..., d(P_m, x)]`.

Під час запиту обчислюються `m` відстаней `d(q, P_i)`. Нижня межа відстані до точки `x` визначається найсильнішою з усіх опор:

```
d_lower(q, x) = max_{i=1..m} |d(q, P_i) − d(P_i, x)|
```

Якщо для певної точки `x` значення `d_lower(q, x) ≥ r_best`, точка `x` негайно відкидається. Оскільки порівняння скалярних чисел `|d(q, P_i) − d(P_i, x)|` у пам'яті виконується за лічені процесорні такти, а повне обчислення відстані між `D`-вимірними векторами вимагає сотень операцій із плавальною комою, така фільтрація суттєво розвантажує обчислювальний конвеєр.

### Геометрія `(1 + ε)`-наближеного пошуку (ANN)

У задачі точного пошуку алгоритм шукає точку `p* ∈ S`, для якої відстань `r* = d(q, p*) = min_{p ∈ S} d(q, p)`.

У задачі `(1 + ε)`-наближеного пошуку користувач задає параметр допустимої похибки `ε > 0`. Алгоритм має право повернути будь-яку точку `p_ann ∈ S`, яка задовольняє умову:

```
d(q, p_ann) ≤ (1 + ε) · r*
```

Це послаблення кардинально розширює зону допустимого відсікання під час обходу дерев. Умова відсікання піддерева модифікується з урахуванням множника наближення:

```
d_lower(q, S_sub) > r_best / (1 + ε)
```

Замість вимоги безумовного виключення точок, кращих за `r_best`, алгоритм відкидає гілки, які не здатні дати покращення щонайменше в `(1 + ε)` разів. При помірному `ε = 0.1..0.2` (похибка у відстані 10–20%) частка відтятих гілок у просторових деревах зростає у десятки разів, повертаючи швидкість пошуку до логарифмічного масштабу.

### Математичний механізм руйнування метричного відтинання у високих вимірах

Чому відсікання за нерівністю трикутника перестає працювати, коли розмірність `D` перевищує 50–100? Причиною є теорема концентрації міри (явище концентрації відстаней).

Розглянемо випадок, коли координати векторів є незалежними однаково розподіленими випадковими величинами зі скінченною дисперсією `σ²` та математичним сподіванням `μ`. Для двох випадкових векторів `u, v ∈ ℝ^D` квадрат евклідової відстані дорівнює сумі `D` випадкових величин:

```
d²(u, v) = ∑_{i=1}^D (u[i] − v[i])²
```

За законом великих чисел математичне сподівання відстані зростає пропорційно `√D`, тоді як середньоквадратичне відхилення лишається обмеженим величиною порядку `O(1)`:

```
E[d(u, v)] ≈ c₁ · √D
Var[d(u, v)] ≈ c₂ · 1
```

Обчислимо відносний розкид відстаней при зростанні `D`:

```
lim_{D → ∞} Var[d(u, v)] / (E[d(u, v)])²
= lim_{D → ∞} c₂ / (c₁² · D)    [підстановка сподівання та дисперсії]
= 0                             [знаменник прямує до нескінченності]
```

Це означає, що відносна різниця між максимальною та мінімальною відстанню до будь-яких точок прямує до нуля:

```
lim_{D → ∞} (d_max − d_min) / d_min = 0
```

У високих вимірах усі точки лежать приблизно на однаковій відстані одна від одної та від запиту `q`. Як наслідок, радіус пошуку `r_best` стає майже рівним відстані `d(q, P)` до опорної точки. Різниця `|d(q, P) − R_split|` майже завжди виявляється меншою за `r_best`, через що умови відсікання перестають виконуватися для 95–100% вузлів дерева.
