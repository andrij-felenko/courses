# 🧮 Топологічна структура діаграми Вороного та дуальність Делоне

Математичний опис діаграми Вороного поєднує опуклу геометрію, планарну топологію графів та алгебраїчний аналізу конічних перерізів. Нижче наведено строгі виведення фундаментальних комбінаторних оцінок складності, аналітичне рівняння пляжної лінії алгоритму Форчуна, детермінантний предикат належності до описаного кола та доведення топологічної дуальності з тріангуляцією Делоне.

## Комбінаторна складність: формула Ейлера для планарних графів

Нехай на площині задано множину з `N` точок (сайтів) `P = {p₁, p₂, ..., p_N}`, причому `N ≥ 3` і точки не лежать на одній прямій. 

Діаграма Вороного `Vor(P)` є планарним розбиттям площини на `N` опуклих граней (по одній комірці для кожного сайта). Кожна внутрішня вершина діаграми утворюється перетином щонайменше трьох серединних перпендикулярів і має степінь (кількість інцидентних ребер) `deg(v) ≥ 3`.

Щоб застосувати топологічну формулу Ейлера, додамо одну фіктивну «нескінченно віддалену вершину» `v_∞`, в яку сходяться всі нескінченні промені діаграми Вороного. Отриманий граф на сфері є повністю зв'язним і задовольняє характеристику Ейлера:

```
V_total − E + F = 2
```

де:
- `V_total = V + 1` — загальна кількість вершин (`V` скінченних вершин Вороного плюс одна вершина `v_∞`);
- `E` — загальна кількість ребер Вороного (як скінченних відрізків, так і нескінченних променів);
- `F = N` — кількість граней (комірок Вороного, яка точно дорівнює кількості сайтів).

Підставимо ці величини у формулу Ейлера:

```
(V + 1) − E + N
= 2                                  [характеристика Ейлера для замкненої сфери]
V − E + N
= 1                                  [віднімання 1 від обох частин]
```

Оскільки кожне ребро з'єднує дві вершини, а степінь кожної скінченної вершини `v` задовольняє `deg(v) ≥ 3`, сума степенів усіх скінченних вершин дає оцінку:

```
∑ deg(v) = 2·E − (кількість нескінченних ребер, що йдуть у v_∞)
∑ deg(v) ≥ 3·V                       [кожна вершина інцидентна щонайменше 3 ребрам]
3·V ≤ 2·E                            [нижня межа для кількості ребер]
```

Виразимо `E` через `V` та `N` з формули Ейлера `E = V + N − 1`:

```
3·V
≤ 2·(V + N − 1)                      [підстановка виразу для E]
= 2·V + 2·N − 2                      [розкриття дужок]
3·V − 2·V
≤ 2·N − 2                            [перенесення членів з V ліворуч]
V
≤ 2·N − 2                            [верхня межа для загальної кількості вершин]
```

Якщо точки перебувають у загальному положенні (жодні 4 сайти не лежать на одному колі), то кожна вершина має степінь рівно `deg(v) = 3`. Оскільки на опуклій оболонці множини `P` лежить щонайменше `h ≥ 3` сайтів, які породжують `h` нескінченних променів у `v_∞` зі степенем `deg(v_∞) = h ≥ 3`, точний підрахунок степенів дає:

```
3·V + h
= 2·E                                [сума степенів усіх вершин графу]
3·V + h
= 2·(V + N − 1)                      [підстановка E = V + N - 1]
= 2·V + 2·N − 2                      [розкриття дужок]
V
= 2·N − 2 − h                        [точна кількість вершин через розмір оболонки h]
```

Оскільки опукла оболонка містить щонайменше `h ≥ 3` точок:

```
V = 2·N − 2 − h
≤ 2·N − 2 − 3                        [оскільки h ≥ 3 для неполінеарних точок]
= 2·N − 5                            [максимальна кількість вершин Вороного]
```

Аналогічно знайдемо верхню межу для кількості ребер `E`:

```
E
= V + N − 1                          [з формули Ейлера]
≤ (2·N − 5) + N − 1                  [підстановка максимального значення V]
= 3·N − 6                            [максимальна кількість ребер Вороного]
```

Ці два виведення строго доводять, що діаграма Вороного для `N` точок завжди має не більше ніж `2N − 5` вершин та не більше ніж `3N − 6` ребер. Її комбінаторний обсяг строго лінійний: `O(N)`.

## Кількість подій в алгоритмі замітання Форчуна

На основі комбінаторної оцінки планарного графу можна строго оцінити кількість кроків алгоритму Форчуна:

1. **Кількість сайт-подій:** рівно `N`, оскільки кожен сайт додається в чергу подій рівно один раз.
2. **Кількість створених дуг:** кожна сайт-подія додає щонайбільше дві нові дуги в пляжну лінію (розщеплюючи одну наявну дугу на дві та вставляючи нову між ними). Отже, загальна кількість дуг, що коли-небудь з'являлися на пляжній лінії, не перевищує `2N − 1`.
3. **Кількість успішних коло-подій:** кожна коло-подія безповоротно видаляє рівно одну дугу з пляжної лінії та фіксує рівно одну вершину Вороного. Оскільки кількість вершин `V ≤ 2N − 5`, алгоритм обробляє не більше ніж `2N − 5` реальних коло-подій.
4. **Кількість хибних коло-подій:** коло-подія може бути згенерована, а пізніше інвалідована новою сайт-подією. Оскільки кожна сайт-подія створює не більше двох нових суміжних трійок дуг, кількість скасованих подій також пропорційна `O(N)`.

Загальна кількість подій у черзі `Q` не перевищує `O(N)`. Оскільки кожна операція з деревом пляжної лінії та чергою подій виконується за `O(log N)`, повний час роботи алгоритму Форчуна строго дорівнює `O(N log N)`.

## Аналітична геометрія пляжної лінії Форчуна

В алгоритмі Форчуна замітальна пряма `L: y = y_L` рухається згори донизу вздовж осі `Y`. Кожен оброблений сайт `p_i = (x_i, y_i)` з `y_i ≥ y_L` породжує параболу `f_i(x)`, яка є геометричним місцем точок `(x, y)`, рівновіддалених від фокуса `p_i` та директриси `L`.

### 1. Виведення рівняння параболи

Відстань від довільної точки `(x, y)` до фокуса `p_i(x_i, y_i)`:

```
dist(P, p_i) = √((x − x_i)² + (y − y_i)²)
```

Відстань від точки `(x, y)` до горизонтальної директриси `y = y_L` (за умови `y ≥ y_L`):

```
dist(P, L) = y − y_L
```

Прирівняємо обидві відстані та піднесемо до квадрата:

```
(x − x_i)² + (y − y_i)²
= (y − y_L)²                         [умова рівновіддаленості dist(P, p_i) = dist(P, L)]
(x − x_i)² + y² − 2·y·y_i + y_i²
= y² − 2·y·y_L + y_L²                [розкриття квадратів різниць]
(x − x_i)² + y_i² − y_L²
= 2·y·y_i − 2·y·y_L                  [перенесення членів з y праворуч]
(x − x_i)² + (y_i − y_L)·(y_i + y_L)
= 2·y·(y_i − y_L)                    [групування за різницею y_i - y_L]
y
= (y_i + y_L) / 2 + (x − x_i)² / (2·(y_i − y_L))   [явне рівняння параболічної дуги]
```

Коли пряма `L` торкається самого сайта (`y_L = y_i`), знаменник прямує до нуля, і парабола вироджується у вертикальний промінь із вершиною в точці `(x_i, y_i)`. При віддаленні прямої `y_L` парабола поступово розширюється та згладжується.

### 2. Обчислення точки зламу двох парабол

Точка зламу (*breakpoint*) між двома суміжними дугами `p_i` та `p_j` визначається перетином їхніх парабол `f_i(x) = f_j(x)`:

```
(y_i + y_L)/2 + (x − x_i)² / (2·(y_i − y_L))
= (y_j + y_L)/2 + (x − x_j)² / (2·(y_j − y_L))     [рівність значень двох парабол]
```

Позначимо `d_i = y_i − y_L` та `d_j = y_j − y_L`. Перенесемо всі члени в одну частину:

```
(1/d_i − 1/d_j)·x² − 2·(x_i/d_i − x_j/d_j)·x + (x_i²/d_i − x_j²/d_j + y_i − y_j) = 0
```

Це звичайне квадратне рівняння відносно `x`:

```
A·x² + B·x + C = 0
```

де коефіцієнти обчислюються безпосередньо через координати сайтів та положення замітальної прямої:

```
A = d_j − d_i = y_j − y_i
B = 2·(d_i·x_j − d_j·x_i)
C = d_j·x_i² − d_i·x_j² + d_i·d_j·(y_i − y_j)
```

Корені цього рівняння:

```
x = (−B ± √(B² − 4·A·C)) / (2·A)
```

З двох коренів вибирається той, який відповідає правильному просторовому сусідству дуг у дереві статусу (лівий або правий перетин залежно від взаємного порядку `p_i` та `p_j`).

## Теорема про порожнє описане коло

Властивість порожнього описаного кола встановлює фундаментальний міст між геометрією Вороного та тріангуляцією Делоне.

> **Теорема:** Точка `v` на площині є вершиною діаграми Вороного `Vor(P)` для множини сайтів `P` тоді й лише тоді, коли коло з центром у `v`, яке проходить через сайти `p_i, p_j, p_k`, не містить у своїй відкритій внутрішній області жодної іншої точки з множини `P`.

### Доведення

1. **Необхідність (якщо `v` — вершина, то коло порожнє):**
   Нехай `v` — вершина діаграми Вороного. За означенням розбиття Вороного, точка `v` належить замиканню щонайменше трьох комірок: `v ∈ V(p_i) ∩ V(p_j) ∩ V(p_k)`.
   З рівновіддаленості до генераторів цих трьох комірок маємо:
   `dist(v, p_i) = dist(v, p_j) = dist(v, p_k) = R`.
   Отже, коло `C(v, R)` радіуса `R` із центром у `v` проходить крізь `p_i, p_j, p_k`.
   Припустимо від супротивного, що всередині кола `C(v, R)` лежить інший сайт `p_m ∈ P` (`m ∉ {i, j, k}`).
   Тоді `dist(v, p_m) < R`. Але це суперечить тому, що `v ∈ V(p_i)`, оскільки за означенням комірки Вороного:
   `dist(v, p_i) ≤ dist(v, p_m)` для всіх `p_m ∈ P`.
   Отримана суперечність `R ≤ dist(v, p_m) < R` доводить, що всередині кола `C(v, R)` не може існувати жодного сайта.

2. **Достатність (якщо коло порожнє, то `v` — вершина):**
   Нехай коло `C(v, R)` проходить через три сайти `p_i, p_j, p_k` і не містить інших сайтів усередині.
   Тоді для будь-якого сайта `p_m` маємо `dist(v, p_m) ≥ R`.
   Для трьох опорних сайтів маємо точну рівність: `dist(v, p_i) = dist(v, p_j) = dist(v, p_k) = R`.
   Отже, точка `v` одночасно мінімізує відстань до `p_i`, `p_j` та `p_k` серед усіх точок множини `P`, а отже, лежить на перетині меж їхніх комірок і є вершиною Вороного.

## Предикат належності точки описаному колу (In-Circle Test)

В обчислювальній геометрії перевірка, чи потрапляє точка `d(x_d, y_d)` всередину описаного кола трьох орієнтованих проти годинникової стрілки точок `a, b, c`, формулюється через знаковий детермінант розміру 4×4 або зведений детермінант 3×3.

Перенесемо початок координат у точку `d`. Позначимо відносні координати:

```
a' = (a_x − d_x, a_y − d_y)
b' = (b_x − d_x, b_y − d_y)
c' = (c_x − d_x, c_y − d_y)
```

Предикат `in_circle(a, b, c, d)` обчислюється через визначник:

```
det_incircle
= det | a'_x   a'_y   (a'_x)² + (a'_y)² |
      | b'_x   b'_y   (b'_x)² + (b'_y)² |
      | c'_x   c'_y   (c'_x)² + (c'_y)² |
```

Геометричний зміст знака детермінанта:
- `det_incircle > 0` — точка `d` лежить **строго всередині** описаного кола трикутника `abc`;
- `det_incircle = 0` — чотири точки `a, b, c, d` лежать на одному колі (коциклічні);
- `det_incircle < 0` — точка `d` лежить **поза межами** описаного кола.

Цей предикат є алгебраїчним еквівалентом проекції точок на тривимірний параболоїд `z = x² + y²`: точка `d` лежить усередині кола на площині тоді й лише тоді, коли її піднята точка на параболоїді лежить під площиною, що проходить через підняті точки `a, b, c`. Це фундаментальне відображення пов'язує 2D-тріангуляцію Делоне з 3D-опуклою оболонкою.
