# 📜 Історія виникнення алгоритму квіток та поліедральної комбінаторики

## Проблема максимізації паросполучень у середині XX століття

У 1950-х роках теорія графів та дослідження операцій переживали бурхливий розвиток, зумовлений появою перших електронно-обчислювальних машин і потребами військової та цивільної логістики. Задачі про транспортні потоки, призначення робіт та розподіл ресурсів сформували фундамент математичного програмування.

Задачу пошуку найбільшого паросполучення у двочасткових графах вдалося успішно розв'язати завдяки угорському алгоритму (англ. *Hungarian algorithm*), розробленому Гарольдом Куном (англ. *Harold Kuhn*) у 1955 році на основі робіт Денеша Кеніга (угор. *Dénes Kőnig*) та Йоньо Егерварі (угор. *Jenő Egerváry*). Угорський алгоритм показав, що у двочасткових графах чергувальні шляхи (англ. *alternating paths*) дозволяють послідовно збільшувати розмір паросполучення за поліноміальний час.

Проте при спробі узагальнити цей підхід на довільні (недвочасткові) графи дослідники зіштовхнулися з важкопрохідною перешкодою. У графах із непарними циклами звичайний пошук в ширину або глибину потрапляв у зациклення, а класичне поняття відстані в чергувальному дереві втрачало однозначність. Протягом кількох років задача знаходження найбільшого паросполучення в загальному графі вважалася багатьма математиками відкритим питанням без впевненості у існуванні ефективного розв'язку.

## Теорема Татта 1947 року: алгебраїчний фундамент

Перший глибокий теоретичний прорив у розумінні структури паросполучень довільних графів здійснив британський математик Вільям Татт (англ. *William Thomas Tutte*) у 1947 році. Теорема Татта про досконале паросполучення дала точний критерій існування паросполучення, яке покриває всі вершины графа.

Татт довів, що граф `G = (V, E)` має досконале паросполучення тоді й лише тоді, коли для будь-якої підмножини вершин `S ⊆ V` кількість зв'язаних компонентів у підграфі `G \ S`, що мають непарну кількість вершин (позначувана як `odd(G \ S)`), не перевищує розмірності `|S|`:

```
odd(G \ S) ≤ |S|    [умова Татта для досконалого паросполучення]
```

Пізніше Норман Берж (фр. *Claude Berge*) у 1958 році узагальнив цей результат у формулі Татта — Бержа (англ. *Tutte-Berge formula*), яка визначає точний розмір найбільшого паросполучення `|M*|` в довільному графі:

```
|M*| = (1/2) · min_{S ⊆ V} (|V| + |S| - odd(G \ S))
```

Попри фундаментальну математичну красу, формула Татта — Бержа не давала очевидного алгоритму обчислення `M*`. Кількість можливих підмножин `S ⊆ V` становить `2^|V|`, тому перебір усіх підмножин вимагав експоненційного часу. Склалася ситуація, коли математичний критерій існував, але ефективного обчислювального механізму для його знаходження не було.

## Едмондс і статті 1965 року: народження класу P

У 1965 році американсько-канадський математик Джек Едмондс (англ. *Jack Edmonds*), працюючи в Національному бюро стандартів США (NBS, нині NIST), опублікував доленосну статтю «Paths, Trees, and Flowers» (Шляхи, дерева та квітки) у *Canadian Journal of Mathematics*.

У цій роботі Едмондс запропонував концептуально новий алгоритм згортання непарних циклів, який він назвав алгоритмом квіток (англ. *blossom algorithm*). Головне новаторство полягало в тому, що при виявленні непарного циклу спеціальної структури — «квітки» (англ. *blossom*) — алгоритм стискає весь цикл в одну псевдовершину, продовжує пошук у меншому графі, а після знаходження доповняльного шляху розгортає квітку назад без втрати точності.

Окрім створення самого алгоритму складності `O(V^4)`, стаття Едмондса мала колосальний вплив на усю комп'ютерну науку. Саме у ній Едмондс уперше чітко сформулював поняття **ефективного алгоритму** як алгоритму, час виконання якого обмежений поліномом від розміру вхідних даних `O(n^k)`. Він протиставив поліноміальний час `O(n^k)` перебиральному експоненційному часу `O(2^n)` і висловив гіпотезу про фундаментальну відмінність між цими двома складностями. Це стало передвісником формалізації класичного класу складності **P** (англ. *Polynomial Time*) та подальших праць Стівена Кука і Річарда Карпа з NP-повноти.

## Поліедральна комбінаторика та двоїстість

У другій статті 1965 року під назвою «Maximum Matching and a Polytope with 0-1 Vertices» Едмондс відкрив новий напрям сучасної математики — поліедральну комбінаторику (англ. *polyhedral combinatorics*).

Едмондс поставив питання: чи можна записати задачу про найбільше паросполучення у вигляді задачі лінійного програмування (ЛП)? Для двочасткових графів матриця суміжності є цілком унімодулярною (англ. *totally unimodular*), тому вершини дробового політопа завжди є цілочисельними vector-векторами з `0` та `1`.

У загальних графах непарні трикутники створюють дробові розв'язки із значеннями `1/2`. Наприклад, для повного графа `K3` з трьома вершинами дробове паросполучення `x[e] = 1/2` для всіх трьох ребер дає сумарну вагу `1.5`, хоча будь-яке ціле паросполучення містить лише `1` ребро.

Едмондс довів, що для повного опису цілочисельного політопа паросполучень довільного графа необхідно додати дробовим нерівностям вершин додатковий клас нерівностей — нерівності непарних розрізів (англ. *blossom inequalities*):

```
∑_{e ∈ E(S)} x[e] ≤ (|S| - 1) / 2    [для всіх непарних підмножин S ⊆ V, |S| ≥ 3]
```

Теорема Едмондса про політоп паросполучень довів, що опукла оболонка всіх цілочисельних паросполучень загального графа повністю задається системами нерівностей вершин та нерівностей квіток. Це відкриття дозволило застосувати теорію двоїстості лінійного програмування (англ. *LP duality*) для побудови алгоритмів пошуку паросполучень максимальної ваги у зважених графах складності `O(V^3)`.

## Розвиток та сучасний статус

У наступні десятиліття алгоритм Едмондса надихнув низку досліджень з оптимізації структур даних у теорії графів:

1. **Гарольд Ґабов (Harold Gabow, 1976):** удосконалив структуру зберігання квіток за допомогою неперетинних множин (DSU), знизивши складність алгоритму до `O(V^3)` та `O(V · E)`.
2. **Сільвіо Мікалі та Віджай Вазірані (Silvio Micali, Vijay Vazirani, 1980):** розробили алгоритм знаходження паросполучення у загальних графах із часовою складністю `O(E · √V)`, що зрівняло складність алгоритмів для недвочасткових графів із алгоритмом Хопкрофта — Карпа для двочасткових графів.
3. **Зважені паросполучення (Weighted Matching):** алгоритм Едмондса для зважених графів став базовим інструментом для розв'язання задачі китайського листоноші (англ. *Chinese Postman Problem*) та алгоритму Крістофідеса (англ. *Christofides algorithm*) для задачі коммівояжера.

Історична цінність алгоритму Едмондса полягає не лише у розв'язанні однієї конкретної задачі теорії графів, а й у тому, що він довів реалістичність подолання комбінаторного вибуху за допомогою глибокого аналізу математичної структури об'єктів.
