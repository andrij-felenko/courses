# 🧮 Математичне виведення рекурентних співвідношень та числовий аналіз стійкості

<preknowlist>
- [Вибіркова дисперсія](root:math-probability/sample-variance) — математичне означення вибіркових моментів та суми квадратів відхилень.
- [Похибка машинної арифметики](root:math-numeric/float-arithmetic-error) — машинний епсилон, обумовленість задач і похибки заокруглення.
</preknowlist>

Чисельне обчислення вибіркових моментів у потоці спирається на рекурентне вираження статистик `k`-го кроку через відомі статистики `(k-1)`-го кроку та нове спостереження `x_k`. У цьому розділі наведено строге виведення формул Велфорда для середнього значення, вибіркової дисперсії, коваріації, моментів вищих порядків, зважених та ковзних вибірок, а також проведено аналіз обумовленості задач відносно накопичення похибок заокруглення в арифметиці з рухомою комою.

### 1. Рекурентне оновлення вибіркового середнього

Нехай задано послідовність спостережень `x_1, x_2, ..., x_k`. За означенням, вибіркове середнє `μ_k` для перших `k` елементів дорівнює:

```
μ_k = (1 / k) · ∑_{i=1}^k x_i
```

Виділимо останній доданок `x_k` зі складу загальної суми:

```
μ_k
= (1 / k) · ( ∑_{i=1}^{k-1} x_i + x_k )             [відокремлення останнього елемента]
= (1 / k) · ( (k − 1)·μ_{k−1} + x_k )               [використання означення: ∑_{i=1}^{k-1} x_i = (k-1)·μ_{k-1}]
= (1 / k) · ( k·μ_{k−1} − μ_{k−1} + x_k )           [розкриття дужок (k-1)·μ_{k-1}]
= μ_{k−1} + (1 / k) · (x_k − μ_{k−1})               [зведення подібних доданків і винесення 1/k]
```

Позначимо через `δ_k` різницю між новим спостереженням `x_k` та попереднім середнім `μ_{k-1}`:

```
δ_k = x_k − μ_{k−1}
```

Тоді крок оновлення середнього набуває компактного вигляду:

```
μ_k = μ_{k−1} + δ_k / k
```

Ця формула не потребує збереження суми `∑ x_i`, а її похибка на кожному кроці масштабується величиною різниці `δ_k`, а не абсолютною сумою спостережень.

### 2. Рекурентне оновлення суми квадратів відхилень (M2)

Сума квадратів відхилень спостережень від вибіркового середнього для `k` елементів позначається як `M2_k`:

```
M2_k = ∑_{i=1}^k (x_i − μ_k)²
```

Вибіркове незміщене оцінювання дисперсії `s_k²` через `M2_k` визначається як `s_k² = M2_k / (k − 1)` для `k ≥ 2`.

Розгорнемо вираз для `M2_k`, відокремивши `k`-й елемент:

```
M2_k = ∑_{i=1}^{k-1} (x_i − μ_k)² + (x_k − μ_k)²
```

Виразимо центровану різницю `(x_i - μ_k)` через відхилення від попереднього середнього `(x_i - μ_{k-1})` та зсув самого середнього `(μ_k - μ_{k-1})`:

```
x_i − μ_k = (x_i − μ_{k−1}) − (μ_k − μ_{k−1})
```

Підставимо цей вираз у суму перших `(k - 1)` доданків і піднесемо до квадрата:

```
∑_{i=1}^{k-1} (x_i − μ_k)²
= ∑_{i=1}^{k-1} [ (x_i − μ_{k−1}) − (μ_k − μ_{k−1}) ]²
= ∑_{i=1}^{k-1} (x_i − μ_{k−1})² − 2·(μ_k − μ_{k−1}) · ∑_{i=1}^{k-1} (x_i − μ_{k−1}) + (k − 1)·(μ_k − μ_{k−1})²
```

Звернемо увагу на центральний член суми: за фундаментальною властивістю вибіркового середнього сума відхилень елементів від власного середнього тотожно дорівнює нулю:

```
∑_{i=1}^{k-1} (x_i − μ_{k−1}) = ∑_{i=1}^{k-1} x_i − (k − 1)·μ_{k−1} = 0
```

Тому середній доданок зникає, і ми отримуємо:

```
∑_{i=1}^{k-1} (x_i − μ_k)² = M2_{k−1} + (k − 1)·(μ_k − μ_{k−1})²
```

Тепер підставимо цей результат назад у формулу `M2_k`:

```
M2_k
= M2_{k−1} + (k − 1)·(μ_k − μ_{k−1})² + (x_k − μ_k)²
```

Врахуємо, що `μ_k - μ_{k-1} = δ_k / k`. Звідси `(k - 1)·(μ_k - μ_{k-1}) = (k - 1)·δ_k / k = δ_k - δ_k / k = δ_k - (μ_k - μ_{k-1}) = (x_k - μ_{k-1}) - (μ_k - μ_{k-1}) = x_k - μ_k`.

Перегрупуємо останні два доданки:

```
(k − 1)·(μ_k − μ_{k−1})² + (x_k − μ_k)²
= (μ_k − μ_{k−1}) · [ (k − 1)·(μ_k − μ_{k−1}) ] + (x_k − μ_k)²
= (μ_k − μ_{k−1}) · (x_k − μ_k) + (x_k − μ_k)²             [заміна (k-1)·(μ_k - μ_{k-1}) на (x_k - μ_k)]
= (x_k − μ_k) · [ (μ_k − μ_{k−1}) + (x_k − μ_k) ]          [винесення спільного множника (x_k - μ_k)]
= (x_k − μ_k) · (x_k − μ_{k−1})                            [спрощення μ_k - μ_{k-1} + x_k - μ_k = x_k - μ_{k-1}]
= δ_k · (x_k − μ_k)
```

Таким чином, ми отримали точну рекурентну формулу Велфорда:

```
M2_k = M2_{k−1} + δ_k · (x_k − μ_k)
```

Або, в еквівалентному виразі через єдине відхилення `δ_k`:

```
M2_k
= M2_{k−1} + δ_k · (x_k − (μ_{k−1} + δ_k / k))          [підстановка формули середнього μ_k = μ_{k-1} + δ_k / k]
= M2_{k−1} + δ_k · (δ_k − δ_k / k)                       [використання означення відхилення δ_k = x_k - μ_{k-1}]
= M2_{k−1} + δ_k² · (k − 1) / k                          [винесення спільного множника δ_k · (1 - 1/k)]
```

### 3. Паралельне об'єднання статистик двох вибірок (формула Чена)

Нехай є дві незалежні вибірки: вибірка `A` розміром `n_A`, із середнім `μ_A` та сумою квадратів відхилень `M2_A`, та вибірка `B` розміром `n_B`, із середнім `μ_B` та сумою `M2_B`.

Об'єднана вибірка має розмір `n = n_A + n_B`. Знайдемо її середнє `μ_{AB}`:

```
μ_{AB}
= (1 / n) · ( n_A·μ_A + n_B·μ_B )                      [за означенням зваженого середнього двох груп]
= (1 / n) · [ n_A·μ_A + n_B·μ_A + n_B·(μ_B − μ_A) ]     [додавання й віднімання доданка n_B·μ_A]
= (1 / n) · [ (n_A + n_B)·μ_A + n_B·(μ_B − μ_A) ]       [групування перших двох доданків]
= μ_A + (n_B / n) · (μ_B − μ_A)                         [поділ на n = n_A + n_B]
```

Позначимо різницю середніх як `Δ = μ_B - μ_A`. Тоді:

```
μ_{AB} − μ_A = (n_B / n) · Δ
μ_{AB} − μ_B = −(n_A / n) · Δ
```

Тепер виведемо суму квадратів `M2_{AB}` для об'єднаної вибірки:

```
M2_{AB} = ∑_{i∈A} (x_i − μ_{AB})² + ∑_{j∈B} (x_j − μ_{AB})²
```

Розкриємо суму для елементів вибірки `A`:

```
∑_{i∈A} (x_i − μ_{AB})²
= ∑_{i∈A} [ (x_i − μ_A) − (μ_{AB} − μ_A) ]²                                [виділення відхилення від групового середнього μ_A]
= ∑_{i∈A} (x_i − μ_A)² − 2·(μ_{AB} − μ_A)·∑_{i∈A} (x_i − μ_A) + n_A·(μ_{AB} − μ_A)² [піднесення до квадрата і розподіл суми]
= M2_A + 0 + n_A · [ (n_B / n) · Δ ]²                                      [використання ∑(x_i - μ_A) = 0 та значення зсуву]
= M2_A + n_A · (n_B² / n²) · Δ²                                            [піднесення дробу до квадрата]
```

Аналогічно для вибірки `B`:

```
∑_{j∈B} (x_j − μ_{AB})²
= ∑_{j∈B} [ (x_j − μ_B) − (μ_{AB} − μ_B) ]²                                [виділення відхилення від групового середнього μ_B]
= ∑_{j∈B} (x_j − μ_B)² − 2·(μ_{AB} − μ_B)·∑_{j∈B} (x_j − μ_B) + n_B·(μ_{AB} − μ_B)² [піднесення до квадрата і розподіл суми]
= M2_B + n_B · [ −(n_A / n) · Δ ]²                                         [використання ∑(x_j - μ_B) = 0 та значення зсуву]
= M2_B + n_B · (n_A² / n²) · Δ²                                            [піднесення від'ємного дробу до квадрата]
```

Додамо обидві частини для отримання `M2_{AB}`:

```
M2_{AB}
= M2_A + M2_B + [ n_A·n_B² + n_B·n_A² ] / n² · Δ²      [додавання двох частин суми]
= M2_A + M2_B + [ n_A·n_B · (n_B + n_A) ] / n² · Δ²    [винесення спільного множника n_A·n_B]
= M2_A + M2_B + [ n_A·n_B · n ] / n² · Δ²              [заміна n_A + n_B на загальний розмір n]
= M2_A + M2_B + Δ² · (n_A · n_B / n)                   [скорочення n у чисельнику та знаменнику]
```

Це рівняння є строго чисельно стійким, оскільки містить виключно операції додавання невід'ємних величин, що повністю усуває загрозу катастрофічного скасування під час паралельної редукції.

### 4. Рекурентні співвідношення для вищих моментів (M3 та M4)

Центральні моменти третього та четвертого порядків визначаються сумами:

```
M3_k = ∑_{i=1}^k (x_i − μ_k)³
M4_k = ∑_{i=1}^k (x_i − μ_k)⁴
```

Ці величини слугують основою для розрахунку коефіцієнтів асиметрії `g1 = √k · M3 / M2^(3/2)` та ексцесу `g2 = k · M4 / M2² − 3`.

Введемо позначення:

```
δ = x_k − μ_{k−1}
δ_new = x_k − μ_k = δ · (k − 1) / k
```

Рекурентні формули Пебея-Терріберрі для оновлення `M3_k` та `M4_k` мають вигляд:

```
M3_k
= M3_{k−1} + δ · δ_new · (x_k − μ_k) − 3 · (δ / k) · M2_{k−1}       [розкладання кубічного відхилення через менші моменти]
= M3_{k−1} + δ · δ_new · δ_new · (k − 2) − 3 · (δ / k) · M2_{k−1}   [підстановка δ_new = x_k - μ_k та зведення подібних]
```

```
M4_k
= M4_{k−1} + δ · δ_new · (δ_new² · (k² − 3k + 3)) + 6 · (δ / k)² · M2_{k−1} − 4 · (δ / k) · M3_{k−1} [біноміальне розкладання четвертого центрального моменту]
```

Кожен наступний момент оновлюється на основі поточного вхідного значення `x_k` та значень попередніх моментів нижчого порядку, зберігаючи просторову складність `O(1)`.

### 5. Зважений алгоритм Велфорда (Weighted Welford)

Якщо кожне спостереження `x_k` надходить із невід'ємною вагою `w_k > 0`, формули Велфорда узагальнюються через накопичення поточної сумарної ваги `W_k`:

```
W_k = W_{k−1} + w_k
```

Крок оновлення зваженого середнього набуває вигляду:

```
μ_k = μ_{k−1} + (w_k / W_k) · (x_k − μ_{k−1})
```

Позначивши зважене відхилення `δ = x_k - μ_{k-1}`, зважена сума квадратів відхилень `M2_k = ∑_{i=1}^k w_i (x_i - μ_k)²` оновлюється за правилом:

```
M2_k = M2_{k−1} + w_k · δ · (x_k − μ_k) = M2_{k−1} + w_k · δ · (δ − (w_k / W_k) · δ) = M2_{k−1} + w_k · δ² · (W_{k−1} / W_k)
```

Незміщена оцінка зваженої вибіркової дисперсії з корекцією Бесселя-Вейса (Bessel-Weis correction) розраховується з урахуванням суми квадратів ваг `W2_k = ∑_{i=1}^k w_i²`:

```
s_w² = M2_k / ( W_k − W2_k / W_k )
```

У разі одиничних ваг (`w_i = 1`) маємо `W_k = k`, `W2_k = k`, і знаменник перетворюється на `k - k/k = k - 1`, повертаючи стандартну формулу.

### 6. Зворотний крок Велфорда для ковзного вікна (Sliding Window)

Під час аналізу потоків у ковзному вікні розміром `W` при надходженні нового елемента `x_{new}` найстаріший елемент `x_{old}` видаляється з вікна. Це можна зробити за `O(1)` операцій без перерахунку всього вікна через прямий та зворотний крок Велфорда.

Нехай до видалення вікно містило `k = W` елементів із середнім `μ_W` та сумою `M2_W`. При видаленні `x_{old}` параметри оновлюються у зворотному порядку:

```
μ_{W−1} = μ_W − (x_{old} − μ_W) / (W − 1)
```

Позначивши `δ_{old} = x_{old} - μ_{W-1}`, сума квадратів зменшується на величину вилученого відхилення:

```
M2_{W−1} = M2_W − δ_{old} · (x_{old} − μ_W) = M2_W − δ_{old}² · (W − 1) / W
```

Після видалення старого елемента застосовується стандартний прямий крок Велфорда для нового елемента `x_{new}` із розміром вибірки `(W - 1) → W`. З міркувань числової стійкості у довгих вікнах рекомендується періодично (наприклад, кожні 10 000 кроків) скидати накопичувач та перераховувати статистику з кільцевого буфера, щоб уникнути повільного дрейфу похибок віднімання.

### 7. Експоненційне згладжування (EWMA Variance)

Для нестаціонарних процесів часто застосовують експоненційно зважене ковзне середнє із коефіцієнтом згладжування `α ∈ (0, 1)`. Рекурентні співвідношення для оцінки поточного середнього та дисперсії набувають вигляду:

```
μ_k = (1 − α) · μ_{k−1} + α · x_k = μ_{k−1} + α · (x_k − μ_{k−1})
```

Позначивши `δ = x_k - μ_{k-1}` та `δ_new = x_k - μ_k = (1 - α) · δ`, експоненційно зважена сума квадратів `S_k` оновлюється як:

```
S_k = (1 − α) · S_{k−1} + α · δ · (x_k − μ_k) = (1 − α) · S_{k−1} + α · (1 − α) · δ²
```

Поточна оцінка дисперсії прямо дорівнює `Var_k = S_k`, оскільки фактор масштабування ваг компенсується нормуванням геометричного ряду ваг `∑_{i=0}^∞ α (1 - α)^i = 1`.

### 8. Рекурентна коваріація двох потоків

Для пари одночасно спостережуваних величин `(x_k, y_k)` сума добутків центрованих відхилень (немасштабована коваріація) визначається як:

```
C_k = ∑_{i=1}^k (x_i − μ_{x,k}) · (y_i − μ_{y,k})
```

Розкладання суми за аналогією з одновимірним випадком дає:

```
C_k
= C_{k−1} + (x_k − μ_{x,k−1}) · (y_k − μ_{y,k})          [розкриття суми добутків та обнулення крос-членів]
= C_{k−1} + δ_x · (y_k − μ_{y,k})                         [використання позначення δ_x = x_k - μ_{x,k-1}]
```

Незміщена вибіркова коваріація на кроці `k ≥ 2` обчислюється діленням на число ступенів свободи: `Cov(X, Y) = C_k / (k − 1)`.

### 9. Аналіз обумовленості та оцінка похибок заокруглення

Розглянемо чутливість задачі обчислення вибіркової дисперсії до збурень у вхідних даних.

Число обумовленості `κ` (condition number) для оцінювання дисперсії вибірки `X = {x_1, ..., x_n}` визначається співвідношенням масштабу середнього до стандартного відхилення:

```
κ(Var) = √( 1 + (μ / σ)² )
```

Коли середнє значення `μ` набагато перевищує стандартне відхилення `σ` (наприклад, `μ = 10⁹`, а `σ = 1`), число обумовленості стає пропорційним `μ / σ = 10⁹`.

#### Похибка наївної однопрохідної формули

Наївна формула обчислює дисперсію як різницю `S2 / n - (S1 / n)²`.

У машинній арифметиці з відносною точністю `ε_mach` (для IEEE 754 double `ε_mach ≈ 1.11 × 10⁻¹⁶`) абсолютна похибка представлення доданка `(S1 / n)² ≈ μ²` становить порядка `μ² · ε_mach`.

Відносна похибка обчисленої дисперсії `fl(s²)` для наївного методу дорівнює:

```
| fl(s²) − s² | / s² ≈ ε_mach · ( 1 + μ² / σ² ) = ε_mach · κ²
```

Якщо `μ / σ > 1 / √ε_mach ≈ 10⁸`, квадрат числа обумовленості `κ² ≈ 10¹⁶` повністю поглинає 53 біти точності мантиси, і результат перетворюється на чистий числовий шум або набуває від'ємного значення.

#### Похибка алгоритму Велфорда

В алгоритмі Велфорда на кожному кроці накопичується величина `M2_k = ∑ (x_i - μ_k)²`. Проміжні доданки `δ_k · (x_k - μ_k)` мають порядок величини `σ²`.

Відносна похибка накопичення суми `M2` в алгоритмі Велфорда обмежена лінійною залежністю від числа кроків `k`:

```
| fl(M2_k) − M2_k | / M2_k ≤ k · ε_mach · ( 1 + O(σ / μ) )
```

Оскільки похибка алгоритму Велфорда залежить від числа обумовленості лінійно (а не квадратично, як у наївній формулі) і не масштабується величиною `μ² / σ²`, алгоритм Велфорда є строго назад-стійким (backward stable) для довільних зсувів вибірки вздовж числової осі.
