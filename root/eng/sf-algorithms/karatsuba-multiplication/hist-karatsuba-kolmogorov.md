# 📜 Семінар Колмогорова та спростування гіпотези О(n²)

Восени 1960 року на механіко-математичному факультеті Московського державного університету розпочав роботу спеціальний семінар із математичних питань кібернетики. Керував семінаром академік Андрій Миколайович Колмогоров — один із найвизначніших математиків двадцятого століття, фундатор сучасної теорії ймовірностей та дослідник теорії інформації. Колмогоров сформулював перед молодими вченими фундаментальну проблему, яка здавалася настільки очевидною, що століттями не викликала сумнівів: визначити точну нижню обчислювальну складність операції множення двох цілих чисел довжиною `n` десяткових або двійкових знаків.

Шкільний метод множення в стовпчик, відомий ще з праць стародавніх шумерів, єгиптян та арабських математиків раннього середньовіччя (зокрема Аль-Хорезмі), вимагає порозрядного множення кожної цифри першого операнда на кожну цифру другого. Якщо обидва числа мають довжину `n`, цей процес вимагає виконання рівно `n²` елементарних однорозрядних добутків та відповідної кількості операцій додавання переносів. З початком цифрової ери та появою перших електронних обчислювальних машин виникло питання: чи є показник `2` в оцінці складності `O(n²)` непереборною фізичною та алгоритмічною межею?

Колмогоров був переконаний, що множення принципово неможливо виконати швидше, ніж за квадратичний час. Його інтуїція ґрунтувалася на тому, що кожен із `n` розрядів першого числа мусить провзаємодіяти з кожним із `n` розрядів другого числа, утворюючи матрицю з `n²` перехресних взаємодій. Математик висунув гіпотезу про квадратичну нижню межу: для будь-якого алгоритму множення двох `n`-значних чисел часова складність у гіршому випадку оцінюється як `Ω(n²)`. Цю гіпотезу Колмогоров виніс як головну тему для досліджень на щотижневих засіданнях семінару, пропонуючи слухачам знайти суворе математичне доведення неможливості субквадратичного множення.

Серед учасників семінару був 23-річний аспірант Анатолій Олексійович Карацуба (фахівець з аналітичної теорії чисел, учень професора Миколи Коробова). Замість того, щоб шукати доведення нездоланності квадратичного бар'єра, Карацуба подивився на задачу з протилежного боку: чи можна обійти необхідність обчислення всіх чотирьох перехресних добутків при розділенні чисел навпіл?

Математична ідея спала Карацубі на думку під час роздумів над структурою білінійних форм. Якщо розбити кожне `n`-значне число на старшу й молодшу частини довжиною `m = n/2`, стандартний вираз добутку містить три коефіцієнти: старший `X_h · Y_h`, молодший `X_l · Y_l` та середній перехресний член `X_h·Y_l + X_l·Y_h`. Стандартний підхід вимагає чотирьох множень половинного розміру. Карацуба помітив алгебраїчну тотожність: якщо помножити суму половин першого числа на суму половин другого `(X_h + X_l) · (Y_h + Y_l)`, отриманий добуток уже містить усі потрібні перехресні складові разом зі старшим та молодшим членами. Віднявши від цього допоміжного добутку вже обчислені величини `X_h · Y_h` та `X_l · Y_l`, можна знайти середній коефіцієнт ціною лише одного рекурсивного множення та кількох лінійних додавань і віднімань.

Усього через тиждень після початку роботи семінару Карацуба розробив повну рекурсивну схему, побудував рекурентне рівняння `T(n) = 3·T(n/2) + c·n` та обчислив його асимптотику через показник степеня:

```
степінь складності = log₂ 3 ≈ 1.5849625...
```

Складність алгоритму виявилася строго субквадратичною — `O(n^(log₂ 3))`, що для великих чисел є кардинально меншим за `O(n²)`. Наприклад, для чисел довжиною мільйон розрядів різниця між `n² = 10¹²` та `n^1.585 ≈ 3.98 · 10⁹` становить понад 250 разів.

На наступному засіданні семінару Карацуба виклав свій результат перед аудиторією. Колмогоров був глибоко вражений елегантністю та простотою спростування власної гіпотези. На відміну від випадків наукових ревнощів, академік повівся як справжній науковець: він публічно визнав помилковість свого припущення про квадратичний бар'єр і закрив роботу семінару, заявивши, що головна інтрига теми розв'язана найнесподіванішим чином.

1962 року Колмогоров особисто підготував статтю про відкриття та подав її до наукового журналу «Доповіді Академії наук СРСР». Він вказав авторами публікації Анатолія Карацуби та Юрія Офмана (який розробив паралельну схемну реалізацію множення), причому сам Карацуба дізнався про вихід статті у світ лише після її публікації, отримавши відтиск журналу від колег. Публікація мала назву «Умножение многозначных чисел на автоматах» (Доклады АН СССР, 1962, том 145, № 2, с. 293–294).

Відкриття алгоритму Карацуби мало колосальні наслідки для всієї комп'ютерної науки та теорії алгоритмів:

1. **Руйнування догми:** Було знищено багатовікове переконання, що арифметичні дії мають незмінну «природну» складність, задану ручними шкільними правилами.
2. **Зародження розділяй-і-володарюй для алгебри:** Метод Карацуби став першим в історії строго доведеним субквадратичним алгоритмом типу «розділяй і володарюй» (лат. *divide et impera*). До цього подібні техніки застосовувалися лише в сортуванні (швидке сортування Гоара) або двійковому пошуку.
3. **Хвиля нових відкриттів:** Метод надихнув Андрія Тума (1963) та Стівена Кука (1966) узагальнити розбиття операндів на 3, 4 та більше частин (алгоритм Тума-Кука). Згодом Арнольд Шьонгаґе та Фолькер Штрассен (1971) поєднали поліноміальне представлення чисел зі швидким перетворенням Фур'є, отримавши складність `O(n log n log log n)`, а Фолькер Штрассен у 1969 році застосував аналогічний трюк зменшення кількості множень із 8 до 7 для матриць розміру `2 × 2`, відкривши перше субкубічне множення матриць `O(n^2.807)`.

Сьогодні алгоритм Карацуби є невіддільною частиною будь-якої бібліотеки довгої арифметики, від GNU MP (GMP) і OpenSSL до рушіїв мов програмування Python, Java та JavaScript (V8), забезпечуючи прискорення операцій у діапазоні від кількох сотень до десятків тисяч двійкових розрядів.
