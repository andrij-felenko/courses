# 🧮 Математичний апарат алгоритму Бойєра — Мура: інваріанти, потенціали та бар'єри пам'яті

Коректність алгоритму голосування більшості Бойєра — Мура та його узагальнень спирається на дискретну комбінаторику розбиттів, інваріанти парного скорочення, алгебраїчні властивості оператора злиття станів та формальний аналіз нижніх оцінок пам'яті в однопрохідній потоковій моделі.

## Формальна постановка задачі та означення більшості

Нехай задано скінченну послідовність (мультимножину) з `N` елементів над універсумом `U`:

```text
S = (x₁, x₂, ..., x_N),  де x_i ∈ U
```

Універсум `U` є довільною множиною, на якій визначено операцію перевірки на рівність (відношення еквівалентності). Для будь-якого фіксованого значення `v ∈ U` визначимо його абсолютну частоту `f(v, S)` як кількість індексів, для яких значення збігається з `v`:

```text
f(v, S) = |{i ∈ [1, N] : x_i = v}|
```

Елемент `M ∈ U` називається **елементом абсолютної більшості** (Majority Element), якщо його абсолютна частота строго перевищує половину довжини всієї послідовності:

```text
f(M, S) > N / 2
```

Якщо `N` — парне число (`N = 2k`), для абсолютної більшості необхідно щонайменше `k + 1` входжень. Якщо `N` — непарне число (`N = 2k + 1`), поріг становить `k + 1` входжень (тобто `(N + 1) / 2`).

### Властивість єдиності

У будь-якій послідовності `S` може існувати не більше одного елемента абсолютної більшості.

Доведення здійснюється від супротивного. Припустимо, що існують два різні елементи `M₁ ≠ M₂`, для кожного з яких виконується умова абсолютної більшості: `f(M₁, S) > N / 2` та `f(M₂, S) > N / 2`. Оскільки множини позицій цих елементів не перетинаються, сумарна частота становить:

```text
f(M₁, S) + f(M₂, S)
> N / 2 + N / 2          [додавання двох строгих нерівностей]
= N                      [результат додавання]
```

Отримано нерівність `f(M₁, S) + f(M₂, S) > N`, що суперечить тому, що загальна кількість усіх елементів у послідовності дорівнює `N`. Отже, елемент абсолютної більшості завжди єдиний.

## Доведення коректності через інваріант парного скорочення

Основна комбінаторна ідея алгоритму полягає в операції редукції: одночасному вилученні з мультимножини пари довільних взаємно нерівних елементів.

### Лема про збереження абсолютної більшості при парному скороченні

Нехай у мультимножині `S` довжиною `N` існує елемент абсолютної більшості `M` із частотою `f(M, S) > N / 2`. Нехай `a, b ∈ S` — два довільні елементи такі, що `a ≠ b`. Утворимо редуковану мультимножину шляхом вилучення цих двох елементів:

```text
S' = S \ {a, b}
```

Тоді елемент `M` залишається елементом абсолютної більшості в редукованій мультимножині `S'`.

### Доведення леми

Розглянемо довжину нової мультимножини:

```text
N' = |S'| = N - 2
```

Оскільки елементи `a` та `b` взаємно відмінні (`a ≠ b`), вони не можуть одночасно дорівнювати `M`. Звідси випливають два взаємовиключні випадки для частоти `M` у множині `S'`:

**Випадок 1: Один із вилучених елементів дорівнює `M` (наприклад, `a = M`, а `b ≠ M`).**

У цьому випадку частота `M` у множині `S'` зменшується рівно на 1:

```text
f(M, S')
= f(M, S) - 1            [вилучено один екземпляр M]
> N / 2 - 1              [оскільки f(M, S) > N / 2]
= (N - 2) / 2            [зведення до спільного знаменника]
= N' / 2                 [підстановка довжини N' = N - 2]
```

Отже, `f(M, S') > N' / 2`, і `M` зберігає статус абсолютної більшості.

**Випадок 2: Жоден із вилучених елементів не дорівнює `M` (`a ≠ M` і `b ≠ M`).**

У цьому випадку частота `M` у множині `S'` залишається незмінною:

```text
f(M, S')
= f(M, S)                [жодного екземпляра M не вилучено]
> N / 2                  [оскільки f(M, S) > N / 2]
> (N - 2) / 2            [оскільки N > N - 2]
= N' / 2                 [підстановка довжини N' = N - 2]
```

У цьому випадку частка `M` у редукованій множині `S'` строго зростає: `f(M, S') / N' > f(M, S) / N`.

Оскільки в обох випадках `f(M, S') > N' / 2`, лему повністю доведено.

## Потенціальна функція стану та індукція за довжиною префікса

Розглянемо виконання алгоритму як послідовність переходів автомата. Стан алгоритму після обробки префікса довжиною `t` (де `0 ≤ t ≤ N`) задається парою `(C_t, c_t)`, де `C_t ∈ U` — поточний кандидат, а `c_t ∈ ℕ₀` — невід'ємний лічильник переваги.

Початковий стан при `t = 0`: `c_0 = 0`, значення `C_0` довільне.

Введемо векторний потенціал стану `Φ_t : U → ℤ`, визначений для кожного значення `v ∈ U`:

```text
Φ_t(v) = c_t · [C_t == v]
```

де `[C_t == v]` — символ Айверсона, що дорівнює 1, якщо поточний кандидат збігається з `v`, і 0 в іншому разі.

### Інваріант парного розбиття префікса

**Теорема (Основний інваріант префікса):**
Для будь-якого кроку `t ∈ [0, N]` префікс послідовності `S_t = (x₁, ..., x_t)` можна розбити на дві неперетинні частини:

```text
S_t = P_t ∪ R_t
```

де:
1. `P_t` — мультимножина спарених елементів, яку можна повністю розбити на `k_t` невпорядкованих пар `{u_i, w_i}` таких, що `u_i ≠ w_i` для всіх `i ∈ [1, k_t]`. Загальна кількість спарених елементів дорівнює `2 · k_t = t - c_t`.
2. `R_t` — залишок (незменшуваний запас), який складається рівно з `c_t` однакових екземплярів елемента `C_t` (якщо `c_t > 0`) або є порожнім (якщо `c_t = 0`).

### Доведення теореми індукцією за кроком t

**База індукції (`t = 0`):**
Префікс порожній `S_0 = ∅`. Маємо `c_0 = 0`, `k_0 = 0`, `P_0 = ∅`, `R_0 = ∅`. Твердження виконується тривіально.

**Індукційний перехід (`t → t + 1`):**
Припустимо, що твердження виконується для кроку `t`, тобто `S_t = P_t ∪ R_t`. Розглянемо надходження нового елемента `x_{t+1}`:

* **Підвипадок 1 (`c_t = 0`):**
  За індукційним припущенням `R_t = ∅`, а вся множина `S_t = P_t` складається зі спарених пар. За алгоритмом новий стан: `C_{t+1} = x_{t+1}`, `c_{t+1} = 1`.
  Новий залишок: `R_{t+1} = {x_{t+1}}`, множина пар залишається незмінною: `P_{t+1} = P_t`.
  Розмір залишку `|R_{t+1}| = 1 = c_{t+1}`, розмір парної частини `|P_{t+1}| = t = (t + 1) - 1`. Інваріант збережено.

* **Підвипадок 2 (`c_t > 0` та `x_{t+1} == C_t`):**
  За алгоритмом `C_{t+1} = C_t`, `c_{t+1} = c_t + 1`.
  Новий елемент додається до залишку: `R_{t+1} = R_t ∪ {x_{t+1}}`.
  Усі елементи `R_{t+1}` однакові й дорівнюють `C_{t+1}`. Множина пар `P_{t+1} = P_t`.
  Розмір `|R_{t+1}| = c_t + 1 = c_{t+1}`. Інваріант збережено.

* **Підвипадок 3 (`c_t > 0` та `x_{t+1} ≠ C_t`):**
  За алгоритмом `c_{t+1} = c_t - 1`, кандидат залишається `C_{t+1} = C_t` (якщо `c_t > 1`) або стає неважливим (якщо `c_t = 1`, тоді `c_{t+1} = 0`).
  Ми вилучаємо один екземпляр `C_t` із залишку `R_t` та об'єднуємо його з новим елементом `x_{t+1}` у нову пару `{C_t, x_{t+1}}`.
  Оскільки `x_{t+1} ≠ C_t`, ця пара містить два різні елементи.
  Нова множина пар: `P_{t+1} = P_t ∪ {C_t, x_{t+1}}`.
  Новий залишок `R_{t+1}` містить `c_t - 1 = c_{t+1}` екземплярів `C_t`. Інваріант збережено.

Індукцію завершено.

### Висновок про фінальний стан лічильника

Нехай у вхідній послідовності довжиною `N` існує елемент більшості `M` із частотою `f(M, S) = m > N / 2`.

Оцінимо кількість входжень елемента `M` у спареній частині `P_N`. Оскільки кожна з `k_N` пар складається з двох *відмінних* елементів, кожна пара може містити не більше одного екземпляра `M`. Отже:

```text
f(M, P_N) ≤ k_N = (N - c_N) / 2
```

З іншого боку, загальна частота `m` складається із входжень у `P_N` та входжень у залишок `R_N`:

```text
m = f(M, P_N) + f(M, R_N)
```

Підставимо оцінку для `f(M, P_N)`:

```text
f(M, R_N)
= m - f(M, P_N)          [вираження частоти в залишку]
≥ m - (N - c_N) / 2      [підстановка верхньої оцінки для f(M, P_N)]
```

Оскільки залишок `R_N` містить елементи кандидата `C_N` лише тоді, коли `C_N == M`, максимальний розмір залишку обмежений числом `c_N`:

```text
c_N ≥ f(M, R_N) ≥ m - (N - c_N) / 2
```

Помножимо обидві частини нерівності на 2:

```text
2 · c_N ≥ 2 · m - N + c_N
```

Віднімемо `c_N` від обох частин:

```text
c_N
≥ 2 · m - N              [віднімання c_N]
> 2 · (N / 2) - N        [оскільки m > N / 2]
= N - N                  [множення]
= 0                      [результат]
```

Оскільки `c_N > 0`, залишок не може бути порожнім. Єдиний елемент, який може утворювати цей додатний залишок — це `M`. Отже, обов'язково `C_N = M`, а фінальне значення лічильника строго обмежене знизу величиною `2m - N ≥ 1`.

## Алгебраїчні властивості паралельного злиття станів (Map-Reduce)

Нехай `(C_A, c_A)` та `(C_B, c_B)` — стани лічильників, отримані після незалежної обробки двох неперетинних підпотоків `S_A` та `S_B`.

Визначимо бінарну операцію злиття `⊕` на просторі станів `Ω = (U × ℕ₀) ∪ {⊥}`:

```text
(C_A, c_A) ⊕ (C_B, c_B) =
  (C_A, c_A + c_B),         якщо C_A = C_B
  (C_A, c_A - c_B),         якщо C_A ≠ C_B і c_A ≥ c_B
  (C_B, c_B - c_A),         якщо C_A ≠ C_B і c_B > c_A
```

Якщо один із лічильників дорівнює нулю (`c = 0`), відповідний кандидат вважається нейтральним елементом.

### Теорема про асоціативність оператора злиття

Оператор `⊕` є асоціативним: для будь-яких трьох станів `X, Y, Z` виконується рівність:

```text
(X ⊕ Y) ⊕ Z = X ⊕ (Y ⊕ Z)
```

### Доведення асоціативності

Розглянемо представлення кожного стану `(C, c)` як формальної мультимножини `R`, що складається з `c` однакових елементів `C`.

Операція `(C_A, c_A) ⊕ (C_B, c_B)` еквівалентна об'єднанню двох мультимножин залишків `R_A ∪ R_B` із наступним виконанням усіх можливих попарних скорочень нерівних елементів.

Оскільки операція мультимножинного об'єднання є асоціативною, а кількість парних скорочень не залежить від порядку вибору пар (результат скорочення нерівних елементів завжди залишає надлишок єдиного домінуючого значення), результуючий залишок для `(R_A ∪ R_B) ∪ R_C` тотожно дорівнює залишку для `R_A ∪ (R_B ∪ R_C)`.

Отже, оператор `⊕` коректно зливає стани в розподілених системах без втрати абсолютної більшості.

## Доведення узагальнення Місри — Гріса для k-групового скорочення

Узагальнений алгоритм Місри — Гріса відстежує `k - 1` пар `(C_i, c_i)`. Коли надходить елемент `x`, відмінний від усіх поточних кандидатів, і всі слоти зайняті (`c_i > 0` для всіх `i`), виконується операція декременту всіх `k - 1` лічильників:

```text
c_i ← c_i - 1,  ∀ i ∈ [1, k - 1]
```

Це відповідає вилученню з потоку мультимножини `G` потужністю `k`:

```text
G = {C₁, C₂, ..., C_{k-1}, x}
```

Усі `k` елементів у множині `G` є попарно різними.

### Оцінка максимальної кількості групових декрементів

Позначимо через `D` загальну кількість операцій групового декременту за весь час обробки потоку довжиною `N`.

Оскільки кожна така операція безповоротно знищує рівно `k` різних елементів, загальна кількість вилучених елементів становить `k · D`. Кількість вилучених елементів не може перевищувати загальної довжини потоку `N`:

```text
k · D ≤ N  ⇒  D ≤ ⌊N / k⌋
```

### Гарантія збереження частих елементів

Нехай `v ∈ U` — довільний елемент, чия справжня частота строго перевищує поріг: `f(v, S) > N / k`.

Під час кожного групового декременту частота елемента `v` у лічильнику може зменшитися щонайбільше на 1 (якщо `v` перебував серед кандидатів у момент декременту) або залишитися незмінною (якщо `v` був новим елементом `x`, який спричинив скорочення).

За весь потік лічильник елемента `v` може зазнати не більше ніж `D` зменшень. Оцінимо підсумковий лічильник `c(v)`:

```text
c(v)
≥ f(v, S) - D            [зменшення не більше ніж на кількість скорочень D]
≥ f(v, S) - N / k        [оскільки D ≤ N / k]
> N / k - N / k          [оскільки f(v, S) > N / k]
= 0                      [результат]
```

Оскільки `c(v) > 0`, елемент `v` не може бути витіснений до нуля і гарантовано буде присутній у вихідному списку кандидатів.

## Нижній інформаційний бар'єр однопрохідної верифікації

Доведемо, що вимога другого проходу для підтвердження існування більшості є фундаментальним інформаційним бар'єром.

### Формальна теорема про комунікаційну складність

Будь-який детермінований однопрохідний алгоритм, який для довільної послідовності `S` довжиною `N` над універсумом `U` (де `|U| ≥ N`) коректно відповідає на запитання «Чи існує в `S` елемент із частотою `> N / 2`?», вимагає щонайменше `Ω(N)` біт оперативної пам'яті.

### Доведення через задачу індексації (Index Problem)

У класичній моделі комунікаційної складності розглядається протокол між двома учасниками:
* Аліса отримує двійковий рядок `x = (x₁, x₂, ..., x_m) ∈ {0, 1}^m`, де `m = ⌊N / 2⌋`.
* Боб отримує індекс `j ∈ {1, ..., m}`.
* Мета Боба — визначити значення біта `x_j`, отримавши єдине повідомлення від Аліси.

Відомо, що одностороння комунікаційна складність задачі індексації становить строго `m` біт: Аліса зобов'язана передати щонайменше `m` біт інформації, інакше Боб припуститься помилки для деякого `j`.

Зведемо цю задачу до однопрохідного розпізнавання більшості:

1. Аліса будує першу половину потоку `S_A` довжиною `m`, використовуючи унікальні пари `(i, b)`:
   ```text
   S_A = ((1, x₁), (2, x₂), ..., (m, x_m))
   ```
   Усі елементи в `S_A` є попарно різними, оскільки перший компонент пари є унікальним індексом `i ∈ [1, m]`.
2. Аліса обробляє потік `S_A` через стан потокового алгоритму і передає отриманий зліпок пам'яті Бобу.
3. Боб отримує стан і подає на вхід алгоритму другу частину потоку `S_B`, яка складається рівно з `m` однакових елементів `(j, 1)`:
   ```text
   S_B = ((j, 1), (j, 1), ..., (j, 1))  [m повторень]
   ```
4. Загальна довжина об'єднаного потоку `S = S_A ∘ S_B` становить `2m = N`.

Проаналізуємо частоту елемента `(j, 1)` у сумарному потоці:

* Якщо `x_j = 1`, елемент `(j, 1)` з'явився 1 раз у `S_A` і `m` разів у `S_B`. Його сумарна частота: `m + 1 > N / 2`. Елемент є абсолютною більшістю.
* Якщо `x_j = 0`, елемент `(j, 1)` з'явився 0 разів у `S_A` (там був елемент `(j, 0)`) і `m` разів у `S_B`. Його сумарна частота: `m = N / 2`. Оскільки для більшості потрібна строга нерівність `> N / 2`, елемент не є більшістю. Жоден інший елемент також не має більшості.

Якби потоковий алгоритм міг за один прохід визначити наявність більшості, використовуючи менше ніж `m` біт пам'яті, Аліса могла б передати Бобу цей стан, а Боб розв'язав би задачу індексації з повідомленням довжиною менше ніж `m` біт, що неможливо.

Отже, пам'ять алгоритму для довільного потоку без апріорної обіцянки обмежена знизу:

```text
Space ≥ ⌊N / 2⌋ біт = Ω(N)
```

Це завершує доведення необхідності другого проходу або адитивного наближення.
