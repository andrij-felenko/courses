# 🧮 Формальні інваріанти та амортизований аналіз 2WL

Ця вставка містить строгі математичні доведення коректності інваріанту двох спостережуваних літералів, формалізацію процедур передачі станів диз'юнктів та амортизований аналіз складності алгоритму за допомогою методу потенціалів.

## Формалізація простору часткових присвоєнь

Нехай `V = {x₁, x₂, ..., x♁}` — скінченна множина булевих змінних. Множина літералів визначається як `L = V ∪ {¬x : x ∈ V}`. Заперечення літерала `l ∈ L` позначається як `¬l`, де `¬(¬x) = x`.

Диз'юнкт `C` — це множина літералів `C = {l₁, l₂, ..., lₖ}`, яка представляє їхню диз'юнкцію `l₁ ∨ l₂ ∨ ... ∨ lₖ`. Довжина диз'юнктів позначається через `|C| = k`. Формула `F` у кон'юнктивній нормальній формі (КНФ) є множиною диз'юнктів `F = {C₁, C₂, ..., C⡯}`.

Частковим присвоєнням називається функція `α: V → {0, 1, *}`, де:
- `α(x) = 1` означає, що змінна `x` оцінена як істинна (True);
- `α(x) = 0` означає, що змінна `x` оцінена як хибна (False);
- `α(x) = *` означає, що змінна `x` є неприсвоєною (Unassigned).

Розширимо функцію `α` на множину літералів `L`:
- `val_α(x) = α(x)`
- `val_α(¬x) = 1` при `α(x) = 0`
- `val_α(¬x) = 0` при `α(x) = 1`
- `val_α(¬x) = *` при `α(x) = *`

У кожній точці пошуку часткове присвоєння `α` розбиває будь-який диз'юнкт `C` на три підмножини літералів:
- `C_true(α) = {l ∈ C : val_α(l) = 1}` — множина істинних літералів;
- `C_false(α) = {l ∈ C : val_α(l) = 0}` — множина хибних літералів;
- `C_free(α) = {l ∈ C : val_α(l) = *}` — множина вільних (неприсвоєних) літералів.

Множина **не-хибних** літералів виражається як `C_nonfalse(α) = C_true(α) ∪ C_free(α)`.

Залежно від потужностей цих підмножин диз'юнкт `C` перебуває в одному з чотирьох взаємовиключних станів під дією `α`:
1. **Задоволений (Satisfied):** `|C_true(α)| ≥ 1`.
2. **Активний / Невизначений (Unresolved):** `|C_true(α)| = 0` та `|C_free(α)| ≥ 2`.
3. **Одиничний (Unit):** `|C_true(α)| = 0` та `|C_free(α)| = 1`.
4. **Конфліктний (Conflict):** `|C_true(α)| = 0` та `|C_free(α)| = 0` (тобто `|C_false(α)| = k`).

## Формальна теорема інваріанту 2WL

У алгоритмі 2WL для кожного диз'юнкт `C` з `k ≥ 2` виділяються два покажчики на індекси літералів `w₁, w₂ ∈ {0, 1, ..., k-1}` такі, що `w₁ ≠ w₂`. Для стислості позначимо спостережувані літерали як `L_w1 = C[w₁]` та `L_w2 = C[w₂]`.

**Теорема 1 (Коректність інваріанту 2WL).**
*Нехай для незадоволеного диз'юнкта C у стані часткового присвоєння α виконується інваріант:*
`val_α(L_w1) ∈ {1, *}  та  val_α(L_w2) ∈ {1, *}`
*Тоді диз'юнкт C гарантовано НЕ перебуває ані в одиничному, ані в конфліктному стані.*

**Доведення:**
За умовою теореми `val_α(L_w1) ∈ {1, *}` та `val_α(L_w2) ∈ {1, *}`. Звідси випливає, що обидва літерали `L_w1` та `L_w2` належать до множини не-хибних літералів `C_nonfalse(α)`:
```
L_w1 ∈ C_nonfalse(α)      [за умовою теореми]
L_w2 ∈ C_nonfalse(α)      [за умовою теореми]
```
Оскільки `w₁ ≠ w₂`, літерали `L_w1` та `L_w2` є різними елементами диз'юнкта `C`. Звідси випливає нижня оцінка потужності множини не-хибних літералів:
```
|C_nonfalse(α)| ≥ 2      [підрахунок двох не-хибних літералів L_w1 та L_w2]
```
За визначенням `C_nonfalse(α) = C_true(α) ∪ C_free(α)`. Оскільки `C_true(α)` та `C_free(α)` є диз'юнктними множинами, маємо:
```
|C_true(α)| + |C_free(α)| ≥ 2    [розклад потужності об'єднання]
```
Розглянемо можливі випадки:
- **Випадок 1: `|C_true(α)| ≥ 1`.** Диз'юнкт `C` задоволений. Оскільки одиничний та конфліктний стани вимагають `|C_true(α)| = 0`, диз'юнкт не є одиничним або конфліктним.
- **Випадок 2: `|C_true(α)| = 0`.** Тоді з нерівності випливає `|C_free(α)| ≥ 2`. За визначенням це відповідає активному (невизначеному) стану диз'юнкта.
  Для одиничного стану потрібно `|C_free(α)| = 1`, для конфліктного `|C_free(α)| = 0`. Оскільки `|C_free(α)| ≥ 2`, обидві умови порушено.

Таким чином, усім станам із `|C_nonfalse(α)| ≥ 2` відповідає повна відсутність вимушених обмежень. Диз'юнкт `C` не потребує жодної обробки. **Теорему доведено.**

## Теорема про асинхронне скасування (Lazy Backtracking)

Розглянемо дію операції повернення (backtracking) у CDCL-солвері. Скасування присвоєння переводить частину змінних зі стану `1` або `0` у стан `*`.

Формально перехід від присвоєння `α` до присвоєння `α'` при бектрекінгу задовольняє умову послаблення обмежень:
`∀ x ∈ V : (α'(x) = α(x))  ∨  (α'(x) = *)`

**Теорема 2 (Збереження інваріанту 2WL при бектрекінгу).**
*Якщо покажчики w₁, w₂ задовольняли інваріант 2WL під дією присвоєння α (тобто val_α(L_w1) ∈ {1, *} та val_α(L_w2) ∈ {1, *}), то ті самі покажчики w₁, w₂ гарантовано задовольняють інваріант 2WL під дією будь-якого послабленого присвоєння α'.*

**Доведення:**
Розглянемо спостережуваний літерал `L_w1`. За умовою `val_α(L_w1) ∈ {1, *}`.
З покомпонентного визначення оцінки літералів маємо два випадки для присвоєння `α'`:
- Якщо `val_α(L_w1) = *`, це означає `α(var(L_w1)) = *`. За умовою послаблення значення `α'(var(L_w1))` може бути лише `*`. Отже, `val_α'(L_w1) = * ∈ {1, *}`.
- Якщо `val_α(L_w1) = 1`, це означає, що відповідна змінна була оцінена істинно. За умовою послаблення значення `α'(var(L_w1))` може або залишитися тим самим (`1`), або перетворитися на `*`. В обох випадках `val_α'(L_w1) ∈ {1, *}`.

Аналогічна логіка застосовується до другого спостережуваного літерала `L_w2`.
Звідси маємо:
```
val_α'(L_w1) ∈ {1, *}     [збереження стану зауваження для L_w1]
val_α'(L_w2) ∈ {1, *}     [збереження стану зауваження для L_w2]
```
Це означає, що покажчики `w₁, w₂` повністю задовольняють вимогам інваріанту 2WL під дією присвоєння `α'` без жодних змін у списку спостереження або масиві диз'юнкта. **Теорему доведено.**

## Амортизований аналіз методом потенціалів

Оцінимо обчислювальну складність переміщення покажчиків 2WL під час пошуку розв'язку.

Нехай дана КНФ-формула `F` складається з `m` диз'юнктів `C₁, C₂, ..., C⡯` довжинами `k₁, k₂, ..., k⡯`. Загальна кількість літералів у формулі дорівнює `L = ∑ k_i`.

Застосуємо **метод потенціалів (Potential Method)** амортизованого аналізу.

Для кожного диз'юнкта `C_j` визначимо позиції спостережуваних літералів у масиві як `pos(w₁) = 0` та `pos(w₂) = 1`. Решта неспостережуваних літералів зберігаються в індексах від `2` до `k_j - 1`.

При зміні покажчика спостереження з `w₁` на новий літерал `L_new` відбуваються такі кроки:
- Сканування масиву від поточного індексу сканування `scan_idx` управо до знаходження не-хибного літерала `L_new`.
- Обмін елементів `swap(literals[0], literals[new_idx])`.

Визначимо потенціал диз'юнкта `Ф(C_j)` під дією часткового присвоєння `α`:
```
Ф(C_j) = 2 · k_j - (pos(w₁) + pos(w₂))
```
Оскільки `0 ≤ pos(w₁) < k_j` та `0 ≤ pos(w₂) < k_j`, потенціал кожного диз'юнкта завжди є строго додатним:
`Ф(C_j) ≥ 0` для всіх `j`.

Повний потенціал системи `Ф` дорівнює сумі потенціалів усіх диз'юнктів:
```
Ф = ∑_{j=1}^{m} Ф(C_j)
```
Початковий потенціал порожньої системи дорівнює `Ф₀ = ∑ (2 · k_j - 1) = 2L - m`.

Проаналізуємо амортизовану вартість трьох типів операцій у CDCL-солвері:

### 1. Операція сканування та заміни покажчика (Watch Shift)
Нехай при зміні значення літерала `w₁` на False солвер переглядає `s` літералів у диз'юнкті `C_j` і знаходить новий не-хибний літерал на позиції `new_idx > pos(w₁)`.
- Реальна вартість операції: `c_real = s` (сканування `s` осередків пам'яті).
- Зміна потенціалу: покажчик переноситься на більший індекс `new_idx`, тому новий потенціал `Ф'` зменшується:
  `ΔФ = Ф' - Ф = - (new_idx - pos(w₁)) ≤ -s`
- Амортизована вартість операції:
```
c_amortized
= c_real + ΔФ       [визначення амортизованої вартості]
= s + (Ф' - Ф)     [підстановка c_real = s та ΔФ = Ф' - Ф]
≤ s - s            [оцінка зменшення потенціалу ΔФ ≤ -s]
= 0                [скасування протилежних доданків]
```
Амортизована вартість заміни покажчика дорівнює **`0`**! Конкретна робота зі сканування масиву повністю покривається вивільненням накопиченого потенціалу.

### 2. Операція бектрекінгу (Backtracking)
При скасуванні `N_unassign` змінних покажчики 2WL залишаються на своїх місцях.
- Реальна вартість операції над диз'юнктами: `c_real = 0`.
- Зміна потенціалу: `ΔФ = 0`.
- Амортизована вартість операції:
```
c_amortized
= c_real + ΔФ       [визначення амортизованої вартості]
= 0 + 0            [підстановка c_real = 0 та ΔФ = 0]
= 0                [підсумок нульових витрат]
```

### 3. Операція додавання нового вивченого диз'юнкта (Learned Clause Insertion)
При створенні нового вивченого диз'юнкта `C_new` довжиною `k_new`:
- Покажчики `w₁, w₂` ставляться на індекси 0 та 1.
- Потенціал системи збільшується на `ΔФ = 2 · k_new - 1`.
- Цей потенціал сплачується за рахунок аналізу конфлікту (Conflict Analysis), який згенерував цей диз'юнкт.

**Висновок амортизованого аналізу:**
Сукупна кількість операцій перегляду осередків пам'яті в масивах диз'юнктів за весь час роботи SAT-солвера обмежена початковим потенціалом `2L` плюс сумою потенціалів усіх вивчених диз'юнктів. Це математично доводить, що 2WL забезпечує амортизовану константну вартість обслуговування на один крок пошуку.
