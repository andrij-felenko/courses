# 🧮 Математичне виведення та строге доведення леми Джонсона — Лінденштрауса

Доведення леми Джонсона — Лінденштрауса розкриває фундаментальну геометричну причину того, чому випадкове матричне множення зберігає попарні відстані між точками у високовимірному просторі. Доведення будується на переході від геометрії складної конфігурації точок до аналізу довжини одного різницевого вектора, використанні сферичної симетрії багатовимірного гаусового розподілу та застосуванні нерівності Чернова для оцінки ймовірностей великих відхилень суми квадратів випадкових величин.

### 1. Зведення геометричної конфігурації до одного вектора

Нехай у вихідному гільбертовому просторі `Rᵈ` задано скінченну множину `V`, що складається з `N` довільних точок. Кількість усіх можливих невпорядкованих пар точок у цій множині визначається біноміальним коефіцієнтом:

```
Кількість пар = N · (N - 1) / 2 < N² / 2
```

Ми розглядаємо лінійне випадкове відображення `f: Rᵈ → Rᵏ`, яке задається множенням на випадкову дійсну матрицю `R` розміром `k × d`:

```
f(u) = (1 / √k) · R · u
```

де множник `1 / √k` є нормувальним коефіцієнтом масштабу.

Завдяки лінійності оператора множення матриці на вектор, образ різниці двох точок `u, v ∈ V` тотожно збігається з різницею їхніх спроєктованих образів:

```
f(u) - f(v)
= (1 / √k) · R · u - (1 / √k) · R · v    [означення лінійного оператора f]
= (1 / √k) · R · (u - v)                 [дистрибутивність матричного множення]
= f(u - v)                               [згортання виразу за означенням f]
```

Позначимо вектор різниці між точками як `x = u - v`. Вимога збереження евклідової відстані між точками `u` та `v` з відносною точністю `(1 ± ε)`:

```
(1 - ε) · ||u - v||² ≤ ||f(u) - f(v)||² ≤ (1 + ε) · ||u - v||²
```

набуває еквівалентного вигляду для довжини вектора `x`:

```
(1 - ε) · ||x||² ≤ ||f(x)||² ≤ (1 + ε) · ||x||²
```

Оскільки обидві частини нерівності є однорідними відносно норми вектора `x`, ми можемо без обмеження загальності розділити всі члени нерівності на `||x||²` і розглядати нормований одиничний вектор `x`, для якого `||x|| = 1`.

Таким чином, уся геометрична задача про збереження взаємного розташування `N` точок звелася до суто імовірнісної оцінки поведінки довжини одного фіксованого одиничного вектора: необхідно оцінити ймовірність того, що випадкова величина `||f(x)||²` відхилиться від свого математичного сподівання `1` більше ніж на задане мале число `ε`:

```
P[ | ||f(x)||² - 1 | ≥ ε ] ≤ 2 · e^( - c · k · ε² )
```

### 2. Ізотропність гаусового розподілу та одновимірні проєкції

Нехай елементи матриці `R[i, j]` є незалежними однаково розподіленими випадковими величинами зі стандартного нормального розподілу `N(0, 1)`.

Розглянемо `i`-й рядок матриці `R`, який позначимо як `r_i = [R[i, 1], R[i, 2], ..., R[i, d]]`. Результатом множення цього рядка на одиничний вектор `x` є скалярна випадкова величина:

```
Y_i = ∑_{j=1}^d R[i, j] · x[j]
```

Оскільки випадкова величина `Y_i` утворена як лінійна комбінація незалежних гаусових величин `R[i, j]`, сама величина `Y_i` має строго нормальний розподіл. Знайдемо її числові характеристики: математичне сподівання та дисперсію.

Обчислення математичного сподівання:

```
E[ Y_i ]
= E[ ∑_{j=1}^d R[i, j] · x[j] ]
= ∑_{j=1}^d x[j] · E[ R[i, j] ]          [лінійність математичного сподівання]
= ∑_{j=1}^d x[j] · 0                     [оскільки для стандартного нормального розподілу E[R] = 0]
= 0
```

Обчислення дисперсії:

```
Var( Y_i )
= Var( ∑_{j=1}^d R[i, j] · x[j] )
= ∑_{j=1}^d x[j]² · Var( R[i, j] )       [попарна незалежність елементів одного рядка матриці]
= ∑_{j=1}^d x[j]² · 1                    [оскільки дисперсія стандартного гаусового числа дорівнює 1]
= ||x||²                                 [означення квадрата евклідової норми вектора]
= 1                                      [оскільки розглядається одиничний вектор ||x|| = 1]
```

Звідси випливає фундаментальний результат: незалежно від розмірності початкового простору `d` та просторової орієнтації вектора `x`, кожна спроєктована координата `Y_i` є стандартною нормальною випадковою величиною:

```
Y_i ~ N(0, 1)
```

Оскільки рядки матриці `R` вибираються взаємно незалежно, величини `Y_1, Y_2, ..., Y_k` утворюють набір із `k` незалежних однаково розподілених нормальних випадкових величин `N(0, 1)`.

### 3. Розподіл хі-квадрат для квадрата спроєктованої норми

Квадрат евклідової довжини спроєктованого вектора `||f(x)||²` обчислюється через координати `Y_i`:

```
||f(x)||²
= || (1 / √k) · Y ||²
= (1 / k) · ∑_{i=1}^k Y_i²               [розкриття евклідової норми у просторі R^k]
```

Введемо позначення для суми квадратів незалежних стандартних нормальних величин:

```
Q = ∑_{i=1}^k Y_i²
```

За математичним означенням, випадкова величина `Q` має розподіл хі-квадрат із `k` ступенями вільності (`Q ~ χ²(k)`). Відомі точні аналітичні вирази для її математичного сподівання та дисперсії:

```
E[ Q ] = k
Var( Q ) = 2 · k
```

Застосовуючи властивості лінійності математичного сподівання та квадратичного масштабування дисперсії до нормованої величини `(1/k) · Q`, маємо:

```
E[ ||f(x)||² ] = (1 / k) · E[ Q ] = (1 / k) · k = 1
Var( ||f(x)||² ) = (1 / k²) · Var( Q ) = (1 / k²) · 2k = 2 / k
```

Таким чином, випадкова проєкція є незміщеною оцінкою початкової довжини вектора: середнє значення квадрата довжини після стискання в точності дорівнює одиниці, а дисперсія оцінки прямує до нуля пропорційно `1/k`.

### 4. Оцінка ймовірності великих відхилень через метод Чернова

Для доведення леми недостатньо знати середнє значення та дисперсію — необхідно строго обмежити хвости розподілу, тобто ймовірність того, що випадкова величина `Q` відхилиться від свого математичного сподівання `k` більше ніж на величину `ε · k`.

#### 4.1. Аналіз верхнього хвоста: P[Q ≥ (1 + ε) · k]

Застосуємо експоненційну нерівність Маркова. Для будь-якого додатного дійсного параметра `λ > 0`:

```
P[ Q ≥ (1 + ε) · k ]
= P[ e^(λ · Q) ≥ e^(λ · (1 + ε) · k) ]         [монотонне експоненційне перетворення з параметром λ > 0]
≤ E[ e^(λ · Q) ] / e^(λ · (1 + ε) · k)         [нерівність Маркова для невід'ємної випадкової величини]
```

Твірна функція моментів для одного доданка `Y_i²` (де `Y_i ~ N(0, 1)`) обчислюється через інтеграл Гауса за умови, що `1 - 2λ > 0` (тобто `λ < 1/2`):

```
E[ e^(λ · Y_i²) ]
= ∫_{-∞}^∞ (1 / √(2π)) · e^(λ · y²) · e^(- y² / 2) dy   [інтеграл за густиною стандартного гаусового розподілу]
= ∫_{-∞}^∞ (1 / √(2π)) · e^(- y² · (1 - 2λ) / 2) dy     [групування показників експоненти]
= ( 1 - 2λ )^(-1 / 2)                                  [використання інтеграла Пуассона — Гауса при 1 - 2λ > 0]
```

Оскільки всі `k` величин `Y_i` є взаємно незалежними, математичне сподівання експоненти від їхньої суми дорівнює добутку відповідних математичних сподівань:

```
E[ e^(λ · Q) ]
= ∏_{i=1}^k E[ e^(λ · Y_i²) ]                          [незалежність випадкових величин Y_i]
= ( 1 - 2λ )^(-k / 2)                                  [добуток k однакових множників]
```

Підставивши твірну функцію моментів у нерівність Маркова, отримуємо оцінку ймовірності як функцію від параметра `λ`:

```
P[ Q ≥ (1 + ε) · k ] ≤ ( 1 - 2λ )^(-k / 2) · e^( - λ · (1 + ε) · k )
```

Знайдемо оптимальне значення параметра `λ ∈ (0, 1/2)`, яке мінімізує отриману верхню межу. Для цього розглянемо логарифм правої частини:

```
g(λ) = - (k / 2) · ln(1 - 2λ) - λ · (1 + ε) · k
```

Обчислимо першу похідну функції `g(λ)` за змінною `λ` та прирівняємо її до нуля:

```
g'(λ) = k / (1 - 2λ) - (1 + ε) · k = 0
1 / (1 - 2λ) = 1 + ε
1 - 2λ = 1 / (1 + ε)
2λ = 1 - 1 / (1 + ε) = ε / (1 + ε)
λ = ε / ( 2 · (1 + ε) )
```

Оскільки `ε > 0`, знайдений екстремум `λ` строго лежить в інтервалі `(0, 1/2)`. Підставимо це оптимальне значення `λ` назад у нерівність:

```
P[ Q ≥ (1 + ε) · k ]
≤ ( 1 / (1 + ε) )^(-k / 2) · e^( - (ε / (2 · (1 + ε))) · (1 + ε) · k )   [підстановка оптимального значення λ]
= ( 1 + ε )^(k / 2) · e^( - ε · k / 2 )                                  [скорочення множника (1 + ε) у показнику]
= [ (1 + ε) · e^(-ε) ]^(k / 2)                                           [об'єднання основ під спільний степінь k/2]
```

Проаналізуємо поведінку виразу під знаком степеня через розклад у ряд Тейлора:

```
ln( (1 + ε) · e^(-ε) )
= ln(1 + ε) + ln(e^(-ε))                                                 [властивість логарифма добутку]
= ln(1 + ε) - ε                                                          [тотожність ln(e^(-ε)) = -ε]
= ( ε - ε² / 2 + ε³ / 3 - ε⁴ / 4 + ... ) - ε                             [розклад ln(1+ε) у ряд Тейлора при |ε| < 1]
= - ε² / 2 + ε³ / 3 - ε⁴ / 4 + ...                                       [скорочення лінійних членів ε та -ε]
≤ - ε² / 2 + ε³ / 3                                                      [відкидання вищих знакопочесних членів ряду]
```

Підставивши логарифмічну оцінку в основу степеня, отримуємо строгу верхню межу для правого хвоста:

```
P[ Q ≥ (1 + ε) · k ] ≤ e^( - (k / 2) · (ε² / 2 - ε³ / 3) )
```

#### 4.2. Аналіз нижнього хвоста: P[Q ≤ (1 - ε) · k]

Оцінка ймовірності того, що норма вектора виявиться занадто малою, проводиться повністю симетрично через нерівність Чернова з від'ємним параметром `-λ` (де `λ > 0`):

```
P[ Q ≤ (1 - ε) · k ]
= P[ e^(-λ · Q) ≥ e^(-λ · (1 - ε) · k) ]                                 [експоненційне перетворення з -λ < 0]
≤ E[ e^(-λ · Q) ] / e^(-λ · (1 - ε) · k)                                 [нерівність Маркова]
= ( 1 + 2λ )^(-k / 2) · e^( λ · (1 - ε) · k )                            [підстановка твірної функції моментів E[e^(-λ Q)]]
```

Диференціювання логарифма цього виразу за `λ` дає оптимальну точку мінімуму `λ = ε / ( 2 · (1 - ε) )`. Підстановка дає:

```
P[ Q ≤ (1 - ε) · k ] ≤ [ (1 - ε) · e^ε ]^(k / 2)
```

Оцінка логарифма через розклад Тейлора для від'ємного аргументу:

```
ln( (1 - ε) · e^ε )
= ln(1 - ε) + ln(e^ε)                                                    [логарифм добутку: ln(a · b) = ln a + ln b]
= ln(1 - ε) + ε                                                          [тотожність ln(e^ε) = ε]
= ( - ε - ε² / 2 - ε³ / 3 - ... ) + ε                                    [розклад ln(1 - ε) у ряд Тейлора]
= - ε² / 2 - ε³ / 3 - ...                                                [скорочення лінійних доданків -ε та +ε]
≤ - ε² / 2                                                               [відкидання від'ємних членів вищих порядків]
```

Оскільки `- ε² / 2 ≤ - (ε² / 2 - ε³ / 3)` для будь-якого `0 < ε < 1`, межа для нижнього хвоста оцінюється тією самою величиною:

```
P[ Q ≤ (1 - ε) · k ] ≤ e^( - (k / 2) · (ε² / 2 - ε³ / 3) )
```

#### 4.3. Сумарна ймовірність спотворення довжини одного вектора

Об'єднуючи оцінки для обох хвостів розподілу, отримуємо повну ймовірність того, що довжина спроєктованого вектора вийде за межі коридору `(1 ± ε)`:

```
P[ | ||f(x)||² - 1 | ≥ ε ]
≤ P[ Q ≥ (1 + ε) · k ] + P[ Q ≤ (1 - ε) · k ]
≤ 2 · e^( - (k / 2) · (ε² / 2 - ε³ / 3) )
```

### 5. Об'єднання по парах (Union Bound) та виведення розмірності k

У множині `V`, яка налічує `N` об'єктів, загальна кількість попарних відстаней дорівнює `P = N · (N - 1) / 2 < N² / 2`.

Застосуємо нерівність Буля (Union Bound): ймовірність того, що **хоча б одна** пара точок у всій множині зазнає відносного спотворення відстані більше ніж на `ε`, не перевищує суми ймовірностей спотворення для кожної окремої пари:

```
P[ існує пара (u, v) : | ||f(u) - f(v)||² / ||u - v||² - 1 | ≥ ε ]
≤ ∑_{(u, v)} P[ | ||f(u - v)||² - 1 | ≥ ε ]
≤ (N² / 2) · 2 · e^( - (k / 2) · (ε² / 2 - ε³ / 3) )
= N² · e^( - (k / 2) · (ε² / 2 - ε³ / 3) )
```

Ми вимагаємо, щоб повна ймовірність порушення геометрії вибірки не перевищувала наперед заданої малої величини `δ` (наприклад, `δ = 0.01`):

```
N² · e^( - (k / 2) · (ε² / 2 - ε³ / 3) ) ≤ δ
```

Логарифмуємо нерівність за основою `e`:

```
2 · ln N - (k / 2) · (ε² / 2 - ε³ / 3) ≤ ln δ = - ln(1 / δ)
(k / 2) · (ε² / 2 - ε³ / 3) ≥ 2 · ln N + ln(1 / δ)
```

Множимо обидві частини на 2 та ділимо на поліноміальний вираз похибки:

```
k ≥ ( 4 · ln N + 2 · ln(1 / δ) ) / ( ε² / 2 - ε³ / 3 )
```

Ця формула є точним аналітичним виразом леми Джонсона — Лінденштрауса. Вона строго доводить, що для збереження попарних відстаней між будь-якими `N` точками достатньо вибрати розмірність підпростору `k = O( ε⁻² · log N )`, яка абсолютно не залежить від вихідної розмірності простору `d`.

### 6. Узагальнення на дискретні субгаусові матриці

Чи є гаусовий розподіл єдиним можливим для випадкової проєкції? Доведення Ахіоптаса (2003) показало, що ключовою властивістю є не неперервність нормального розподілу, а його **субгаусовість** (експоненційне спадання хвостів).

Якщо елементи матриці `R[i, j]` задовольняють умови:
1. `E[ R[i, j] ] = 0`;
2. `Var( R[i, j] ) = 1`;
3. Величина `R[i, j]` є субгаусовою, тобто існує константа `C > 0` така, що `E[ e^(λ · R[i, j]) ] ≤ e^(C · λ²)` для всіх `λ ∈ R`,

то сума `∑ R[i, j] · x[j]` веде себе подібно до гаусової величини за теоремою про концентрацію субгаусових сум. Зокрема, для випадкових знаків Радемахера `R[i, j] ∈ {+1, -1}` та для розріджених величин Ахіоптаса `R[i, j] ∈ {+√3, 0, -√3}` зі збереженням одиничної дисперсії аналогічні межі Чернова гарантують асимптотично ту саму розмірність `k = O(ε⁻² · log N)`.
