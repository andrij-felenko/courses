# 🧮 Математична теорія універсальних сімейств хеш-функцій

Ця вставка містить строгі математичні доведення колізійних меж для 2-універсальних сімейств хеш-функцій, виведення очікуваної довжини ланцюжка колізій у хеш-таблицях з розділеними списком комірками, а також формальне обґрунтування універсальності модульного лінійного хешування Картера-Вегмана та множильно-зсувного хешування Дітцфельбінгера.

## 1. Імовірнісний простір та формальні означення

Нехай `U` — скінченний або зліченний простір (універсум) усіх можливих ключів, а `M = {0, 1, ..., m-1}` — простір вихідних індексів (бакетів) хеш-таблиці розміру `m`.

Розглянемо скінченну множину хеш-функцій `H = {h : U → M}`. Імовірнісний простір будується вибором хеш-функції `h` з множини `H` за допомогою дискретного рівномірного розподілу, тобто для будь-якої конкретної функції `f ∈ H`:

```
P_{h ∈ H}[h = f] = 1 / |H|
```

Математична ідея випадкового вибору виключає можливість завчасного підбору найгіршого вектору ключів. Оскільки супротивник не має доступу до генератора випадкових чисел процесу, для нього вихідний індекс хеш-функції стає випадковою величиною.

### 1.1. Класифікація сімейств за ступенем незалежності

Для математичного опису властивостей сімейств вводиться наступна строга ієрархія:

- **2-універсальне сімейство (2-Universal Hash Family)**:
  Множина `H` є 2-універсальною, якщо для будь-яких двох різних ключів `x, y ∈ U` при `x ≠ y`:

  ```
  |{h ∈ H : h(x) = h(y)}| ≤ |H| / m
  ```

  або еквівалентно у термінах ймовірності:

  ```
  P_{h ∈ H}[h(x) = h(y)] ≤ 1 / m
  ```

  Зауважимо важливу деталь: це означення розглядає виключно події колізій для пар елементів, не накладаючи жодних обмежень на рівномірність відображення поодиноких ключів.

- **Строго 2-універсальне (Pairwise Independent) сімейство**:
  Множина `H` є строго 2-універсальною, якщо для будь-яких двох різних ключів `x ≠ y ∈ U` та будь-яких двох індексів `i, j ∈ M`:

  ```
  P_{h ∈ H}[h(x) = i ∧ h(y) = j] = 1 / m²
  ```

  З цього означення шляхом підсумовування по всіх `j ∈ M` безпосередньо випливає рівномірність відображення кожного окремого ключа у простір бакетів:

  ```
  P_{h ∈ H}[h(x) = i] = 1 / m
  ```

- **`k`-універсальне / `k`-незалежне сімейство (`k`-wise Independent Family)**:
  Множина `H` є `k`-незалежною, якщо для довільного впорядкованого набору з `k` різних ключів `(x₁, x₂, ..., xₖ)` та довільного набору `k` індексів `(i₁, i₂, ..., iₖ)` виконується рівність:

  ```
  P_{h ∈ H}[ ∧_{t=1}^k (h(x_t) = i_t) ] = 1 / m^k
  ```

  Параметр `k` характеризує силу концентрації ймовірностей. Якщо при `k = 2` алгоритм надає гарантії лише для математичного сподівання кількості колізій, то при `k = O(log n)` вищі моменти дозволяють довести, що максимальна довжина ланцюжка колізій з високою ймовірністю `1 - 1/n` не перевищує `O(log n / log log n)`.

## 2. Теорема про очікувану кількість колізій

Сформулюємо та доведемо фундаментальну теорему, яка обґрунтовує високу швидкість обробки даних у хеш-таблиці під дією 2-універсального сімейства.

> **Теорема 1.** Нехай `S ⊂ U` — довільна фіксована підмножина з `n` ключів, збережена у хеш-таблиці розміру `m` з розділеними ланцюжками. Якщо функція `h` обрана випадково та рівномірно з 2-універсального сімейства `H`, то для довільного ключа `x ∈ U` (який може належати або не належати до `S`), очікувана кількість ключів `E[C_x]` у бакеті `h(x)` задовольняє межу:
>
> `E[C_x] ≤ 1 + n / m`

### Крок 1: Введення індикаторних випадкових величин
Для кожного елемента `y ∈ S` введемо бінарну випадкову величину-індикатор `I_y(h)`:

```
I_y(h) = 1,  якщо h(x) = h(y)
I_y(h) = 0,  якщо h(x) ≠ h(y)
```

Математичний сенс цієї величини полягає у фіксації факту колізії між ключем `x` та ключем `y`. Загальна кількість ключів `C_x` у ланцюжку колізій бакета `h(x)` виражається як пряма сума цих індикаторів по всіх елементах `S`:

```
C_x = ∑_{y ∈ S} I_y(h)
```

### Крок 2: Застосування лінійності математичного сподівання
Обчислимо математичне сподівання `E[C_x]` над імовірнісним простором вибору хеш-функції:

```
E[C_x]
  = E[ ∑_{y ∈ S} I_y(h) ]                                   [лінійність математичного сподівання]
  = ∑_{y ∈ S} E[ I_y(h) ]                                   [перестановка знаків суми та сподівання]
  = ∑_{y ∈ S} P_{h ∈ H}[h(x) = h(y)]                         [сподівання індикатора дорівнює ймовірності події]
```

Зауважимо, що лінійність математичного сподівання виконується завжди, незалежно від того, чи є випадкові величини `I_y(h)` залежними між собою.

### Крок 3: Відокремлення випадку `y = x` та оцінка колізій
Розділимо суму на два окремих доданки — випадок `y = x` (якщо ключ `x` вже міститься у множині `S`) та випадок `y ≠ x`:

```
E[C_x]
  = P[h(x) = h(x)] + ∑_{y ∈ S, y ≠ x} P[h(x) = h(y)]        [розбиття множини підсумовування]
  ≤ 1 + ∑_{y ∈ S, y ≠ x} (1 / m)                            [застосування означення 2-універсальності]
  = 1 + (n - 1) / m                                         [підсумовування n-1 однакових констант]
  < 1 + n / m                                               [строге підсилення нерівності]
```

Отже, теорему повністю доведено. Якщо коефіцієнт завантаження таблиці обмежено як `α = n / m ≤ 1`, очікувана кількість елементів у ланцюжку `E[C_x] < 2`, а очікуваний час пошуку елемента становить константне `O(1)`.

## 3. Математичний доказ універсальності модульного лінійного сімейства

Розглянемо класичну конструкцію Картера-Вегмана над скінченним простим полем `ℤₚ`.

Нехай `p` — просте число, `p > |U|`. Позначимо через `ℤₚ = {0, 1, ..., p-1}` скінченне поле за модулем `p`, а через `ℤₚ* = {1, 2, ..., p-1}` — його мультиплікативну групу.

Модульне лінійне сімейство хеш-функцій визначається як:

```
H_{p,m} = { h_{a,b}(x) = ((a · x + b) mod p) mod m  |  a ∈ ℤₚ*,  b ∈ ℤₚ }
```

Загальна кількість функцій у сімействі дорівнює `|H_{p,m}| = p · (p - 1)`.

> **Теорема 2.** Сімейство `H_{p,m}` є 2-універсальним, тобто для будь-яких двох різних ключів `x ≠ y ∈ ℤₚ`:
>
> `P_{a, b}[ h_{a,b}(x) = h_{a,b}(y) ] ≤ 1 / m`

### Доведення Теореми 2

#### Крок 1: Бієктивність афінного перетворення у полі `ℤₚ`
Розглянемо пару відображень:

```
r = (a · x + b) mod p
s = (a · y + b) mod p
```

Покажемо, що вибір параметрів `(a, b)` взаємно-однозначно (бієктивно) визначає пару `(r, s)` при `r ≠ s`.

Запишемо систему лінійних рівнянь у полі `ℤₚ`:

```
r - s ≡ a · (x - y) (mod p)
```

Оскільки `p` — просте число, а `x ≠ y (mod p)`, різниця `(x - y)` має обернений елемент `(x - y)⁻¹ mod p`. Отже, для будь-якої фіксованої пари значень `(r, s)` з `r ≠ s` існує **єдиний** розв'язок щодо `a` та `b`:

```
a = (r - s) · (x - y)⁻¹ mod p
b = (r - a · x) mod p
```

Оскільки `a ∈ ℤₚ*`, параметр `a` не може дорівнювати нулю, а отже `r` не може дорівнювати `s`. Загальна кількість допустимих впорядкованих пар `(r, s)` при `r ≠ s` дорівнює `p · (p - 1)`.

#### Крок 2: Оцінка колізій за модулем `m`
Колізія `h_{a,b}(x) = h_{a,b}(y)` виникає тоді і тільки тоді, коли:

```
r ≡ s (mod m)
```

Підрахуємо кількість пар `(r, s)` у просторі `ℤₚ × ℤₚ` при `r ≠ s`, які задовольняють умову `r ≡ s (mod m)`.

Для фіксованого значення `r ∈ ℤₚ` кількість можливих значень `s ∈ ℤₚ` таких, що `s ≡ r (mod m)` та `s ≠ r`, не перевищує `⌈p / m⌉ - 1 ≤ (p - 1) / m`.

Оскільки `r` може набувати будь-якого з `p` значень, загальна кількість колізійних пар `(r, s)` задовольняє межу:

```
N_{col} ≤ p · (p - 1) / m
```

#### Крок 3: Обчислення підсумкової ймовірності
Імовірність колізії обчислюється як відношення кількості колізійних пар `N_{col}` до загальної кількості функцій у сімействі `|H| = p · (p - 1)`:

```
P[h_{a,b}(x) = h_{a,b}(y)]
  = N_{col} / |H|                                            [класичне означення ймовірності]
  ≤ (p · (p - 1) / m) / (p · (p - 1))                       [підстановка отриманої верхньої межі N_col]
  = 1 / m                                                   [скорочення p(p-1) у чисельнику та знаменнику]
```

Теорему 2 повністю доведено.

## 4. Аналіз множильно-зсувного хешування Дітцфельбінгера

Для множильно-зсувного сімейства `H_{mult}` на `w`-бітних цілих числах з параметром `m = 2ᴹ`:

```
h_a(x) = ((a · x) mod 2ʷ) >> (w - M)
```

де `a` — випадкове непарне `w`-бітне ціле число, Мартін Дітцфельбінгер довів, що для будь-яких двох різних ключів `x ≠ y`:

```
P_a[h_a(x) = h_a(y)] ≤ 2 / 2ᴹ = 2 / m
```

Коефіцієнт `2` у чисельнику є платою за усунення операції ділення за модулем `p`. У практичних хеш-таблицях це збільшує очікувану довжину ланцюжка колізій усього на `1/m`, зберігаючи асимптотичну складність `O(1)`.

## 5. Лемма про залишковий хеш (Leftover Hash Lemma, LHL)

У криптографії та теорії складності універсальне хешування використовується для екстракції випадковості.

> **Лемма про залишковий хеш.** Нехай `X` — випадкова величина над `U` з мін-ентропією `H_min(X) = -log₂ (max_x P[X = x]) ≥ k`. Нехай `H` — 2-універсальне сімейство хеш-функцій, що відображає `U` у `{0, 1}^b`. Якщо довжина вихідного ключа задовольняє умову:
>
> `b ≤ k - 2 log₂(1 / ε)`
>
> то пара `(h, h(X))`, де `h` обрано рівномірно з `H`, є `ε`-близькою за статистичною відстанню до ідеально рівномірного розподілу над `H × {0, 1}^b`.

Лемма LHL гарантує, що універсальні хеш-функції здатні перетворювати напіввипадкові фізичні джерела даних у криптографічно стійкі секретні ключі без втрати ентропії.

Таким чином, математичний апарат 2-універсальності надає строгі гарантії безпеки та ефективності, які лягли в основу сучасної прикладної комп'ютерної науки.
