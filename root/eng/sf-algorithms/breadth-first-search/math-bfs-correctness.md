# 🧮 Математичне доведення коректності та інваріанти BFS

Математична строгість алгоритму пошуку у ширину (BFS) базується на тому, що локальний порядок обробки вершин у черзі FIFO гарантує глобальну мінімальність знайдених шляхів у незваженому графі. На відміну від алгоритму Дейкстри, який вимагає доведення через жадібний вибір на вагах `w >= 0`, обґрунтування BFS спирається на дискретну монотонність черги та трикутникову нерівність для кількості ребер.

Нижче наведено формальні визначення, математичні леми, доведення властивостей ребер дерева BFS, теореми про діаметр дерев, аналіз гібридного обходу Беймера, доведення 0-1 BFS, просторовий аналіз ширини графів та повне доведення коректності алгоритму за допомогою методу математичної індукції.

### Початкові визначення та нерівність трикутника

Нехай задано орієнтований або неорієнтований незважений граф `G = (V, E)` та початкову вершину `s ∈ V`.

**Визначення 1 (Точна найкоротша відстань):**
Значення `δ(s, v)` позначує найменшу кількість ребер у будь-якому шляху від вершини `s` до вершини `v`. Якщо шлях від `s` до `v` відсутній, приймаємо `δ(s, v) = ∞`. За визначенням, `δ(s, s) = 0`.

**Лема 1 (Нерівність трикутника для незважених графів):**
Для будь-якого ребра `(u, v) ∈ E` справджується нерівність:
```
δ(s, v) <= δ(s, u) + 1
```

*Доведення:* Якщо вершина `u` недосяжна від `s` (`δ(s, u) = ∞`), права частина дорівнює нескінченності, і нерівність виконується тривіально. Якщо `u` досяжна, існує шлях від `s` до `u` довжиною `δ(s, u)` ребер. Додавши до цього шляху ребро `(u, v)`, отримуємо допустимий шлях від `s` до `v` довжиною `δ(s, u) + 1` ребер. Оскільки точна найкоротша відстань `δ(s, v)` є мінімумом серед усіх можливих шляхів, вона не може перевищувати довжину побудованого шляху. Лему 1 доведено.

### Лема про монотонність черги FIFO

У процесі виконання BFS черга `Q` підтримує строгий монотонний порядок обчислених відстаней.

**Лема 2 (Монотонність відстаней у черзі):**
Нехай у довільний момент часу елементи черги `Q` від голови до хвоста мають вигляд `[v_1, v_2, ..., v_r]`. Тоді виконуються дві умови:
1. `dist[v_1] <= dist[v_2] <= ... <= dist[v_r]`
2. `dist[v_r] <= dist[v_1] + 1`

*Доведення (індукція за кількістю операцій з чергою):*

**База індукції:** На початку роботи алгоритму черга містить лише стартову вершину `Q = [s]` з відстанню `dist[s] = 0`.
Оскільки `r = 1`, нерівності `dist[s] <= dist[s]` та `dist[s] <= dist[s] + 1` виконуються тривіально.

**Індукційний крок:** Припустимо, що лема виконується для черги `Q = [v_1, v_2, ..., v_r]`. Розглянемо два типи операцій, що змінюють стан черги:

1. **Операція `pop` (вилучення з голови):**
   Вилучаємо `v_1`. Новою головою черги стає `v_2`.
   З індукційного припущення `dist[v_2] <= dist[v_3] <= ... <= dist[v_r]`.
   Також із припущення `dist[v_r] <= dist[v_1] + 1 <= dist[v_2] + 1` (оскільки `dist[v_1] <= dist[v_2]`).
   Отже, обидві умови леми зберігаються.

2. **Операція `push` (додавання нового сусіда у хвіст):**
   Під час обробки голови `v_1` її невідвіданий сусід `x` відкривається і додається в хвіст черги з відстанню `dist[x] = dist[v_1] + 1`.
   Новий стан черги: `[v_2, v_3, ..., v_r, x]`.

   Перевіримо першу умову для нового хвоста `x`:
   З індукційного припущення `dist[v_r] <= dist[v_1] + 1 = dist[x]`. Отже, `dist[v_r] <= dist[x]`, і монотонне зростання збережено.

   Перевіримо другу умову для нової голови `v_2` та нового хвоста `x`:
   Оскільки `dist[v_1] <= dist[v_2]`, то `dist[x] = dist[v_1] + 1 <= dist[v_2] + 1`.
   Отже, різниця між новим хвостом `x` та новою головою `v_2` не перевищує 1.

Лему 2 повністю доведено.

### Лема про нижню оцінку відстаней

**Лема 3 (Верхня межа для точної відстані):**
У будь-який момент роботи алгоритму для кожної вершини `v ∈ V` виконується нерівність:
```
dist[v] >= δ(s, v)
```

*Доведення:* Алгоритм присвоює значення `dist[v]` лише у двох випадках:
1. При ініціалізації: `dist[s] = 0 = δ(s, s)` та `dist[v] = ∞ >= δ(s, v)`.
2. При відкритті вершини `v` через ребро `(u, v)`: `dist[v] = dist[u] + 1`.

За індукцією, якщо `dist[u] >= δ(s, u)`, то з урахуванням Леми 1 (нерівність трикутника):
```
dist[v] = dist[u] + 1
        >= δ(s, u) + 1
        >= δ(s, v)
```
Отже, значення `dist[v]` ніколи не може стати строго меншим за істинну найкоротшу відстань `δ(s, v)`. Лему 3 доведено.

### Головна теорема про коректність BFS

**Теорема (Коректність обчислення найкоротших шляхів):**
Після завершення алгоритму BFS для всіх вершин `v ∈ V`, досяжних із початкової вершини `s`, розраховане значення `dist[v]` дорівнює точній найкоротшій відстані:
```
dist[v] = δ(s, v)
```

*Доведення (від супротивогу):*
Припустимо, що існують вершини, для яких `dist[v] ≠ δ(s, v)`.
З Леми 3 випливає, що `dist[v] >= δ(s, v)`. Отже, для помилкових вершин має виконуватися строга нерівність `dist[v] > δ(s, v)`.

Нехай `v` — досяжна вершина з **найменшою точною відстанню `δ(s, v)`**, для якої алгоритм допустив помилку `dist[v] > δ(s, v)`.
Оскільки для старту `dist[s] = 0 = δ(s, s)`, вершина `v ≠ s`, отже `δ(s, v) >= 1`.

Розглянемо точний найкоротший шлях від `s` до `v`. Нехай `u` — безпосередній предок вершини `v` у цьому найкоротшому шляху.
Тоді:
```
δ(s, v) = δ(s, u) + 1
```

Оскільки `δ(s, u) < δ(s, v)`, вершина `u` має меншу точну відстань за `v`. Оскільки `v` була обрана як *найперша* вершина з помилкою, для `u` алгоритм спрацював абсолютно правильно:
```
dist[u] = δ(s, u)
```

Розглянемо момент, коли вершина `u` була вилучена з голови черги:
- **Випадок 1:** На момент обробки `u` вершина `v` ще не була помічена (`visited[v] == false`).
  Тоді алгоритм перегляне ребро `(u, v)`, встановлюючи:
  ```
  dist[v] = dist[u] + 1 = δ(s, u) + 1 = δ(s, v)
  ```
  Це прямо суперечить припущенню, що `dist[v] > δ(s, v)`.

- **Випадок 2:** На момент обробки `u` вершина `v` вже була помічена раніше через інше ребро.
  Це означає, що `v` була додана до черги раніше, ніж `u` була з неї вилучена.
  За Лемою 2 (монотонність черги), відстань доданої раніше вершини `v` не може перевищувати відстань вершини, що додається зараз:
  ```
  dist[v] <= dist[u] + 1 = δ(s, u) + 1 = δ(s, v)
  ```
  Знову отримуємо `dist[v] <= δ(s, v)`, що разом із Лемою 3 (`dist[v] >= δ(s, v)`) дає строгу рівність `dist[v] = δ(s, v)`.

В обох випадках припущення про існування вершини з `dist[v] > δ(s, v)` приводить до математичного супереччя.

Отже, для всіх досяжних вершин `dist[v] = δ(s, v)`. Теорему про коректність BFS повністю доведено.

### Властивості ребер дерева BFS та класифікація

**Теорема (Обмеження на рівні ребер у неорієнтованому графі):**
Нехай `G = (V, E)` — неорієнтований граф. Для будь-якого ребра `(u, v) ∈ E` різниця відстаней від стартової вершини `s` задовільняє умову:
```
|dist[u] - dist[v]| <= 1
```

*Доведення:* Без втрати загальності припустимо, що вершина `u` була вилучена з черги раніше за `v` (`dist[u] <= dist[v]`).
Коли `u` обробляється в алгоритмі, переглядається ребро `(u, v)`:
- Якщо `v` не була відвідана, вона отримує `dist[v] = dist[u] + 1`, звідки `dist[v] - dist[u] = 1`.
- Якщо `v` уже була відвідана раніше або одночасно, вона була додана в чергу не пізніше за `u` або під час обробки `u`, отже `dist[v] <= dist[u] + 1`.

Оскільки `dist[u] <= dist[v]`, маємо два можливі значення різниці: `dist[v] - dist[u] = 0` (вершини в одному шарі) або `dist[v] - dist[u] = 1` (вершини в сусідніх шарах).
Отже, у неорієнтованому графі неможливе існування ребер, які пропускають один або більше шарів (наприклад, з `L_i` в `L_{i+2}`).

### Доведення збереження монотонності в алгоритмі 0-1 BFS

У графах з вагами ребер `w ∈ {0, 1}` замість пріоритетної купи застосовується двостороння черга `deque`.

**Теорема (Інваріант монотонності 0-1 BFS):**
Якщо при розпуску ребра `(u, v)` вагою `w = 0` вершина `v` додається у голову черги (`push_front`), а при `w = 1` — у хвіст черги (`push_back`), то елементи в `deque` залишаються монотонно впорядкованими за значенням `dist`.

*Доведення:*
Розглянемо момент вилучення вершини `u` з голови `deque`. Всі вершини в `deque` мають вигляд:
```
dist[head] = d  ...  dist[tail] ∈ {d, d + 1}
```
1. **Якщо `w = 0`:** Сусід `v` отримує відстань `dist[v] = dist[u] + 0 = d`. Оскільки нова голова `v` має відстань `d`, яка дорівнює поточній голові `dist[head] = d`, додавання `v` через `push_front` зберігає монотонне зростання від голови до хвоста.
2. **Якщо `w = 1`:** Сусід `v` отримує відстань `dist[v] = dist[u] + 1 = d + 1`. Оскільки поточний хвіст `deque` містить значення не більше за `d + 1`, додавання `v` через `push_back` зберігає верхню межу хвоста `dist[tail] <= dist[head] + 1`.

Отже, інваріант монотонності `deque` повністю зберігається без використання операцій перешикування купи, що дає лінійну складність `O(V + E)`.

### Теорема про дві BFS для знаходження діаметра дерева

У теорії графів **діаметром дерева** `Diam(T)` називається найбільша найкоротша відстань між довільною парою вершин `u, v ∈ V`:
```
Diam(T) = max_{u, v} δ(u, v)
```

Для обчислення діаметра довільного незваженого дерева `T = (V, E)` використовується класичний алгоритм **двох BFS** (Double BFS):
1. Обираємо довільну стартову вершину `x ∈ V` і запускаємо `BFS(x)`. Знаходимо вершину `u`, яка має найбіднішу відстань від `x`: `u = argmax_v dist_x[v]`.
2. Запускаємо другий `BFS(u)` від знайденої вершини `u`. Знаходимо найвіддаленішу від неї вершину `w`: `w = argmax_v dist_u[v]`.
3. Довжина шляху між `u` та `w` дорівнює точній величині діаметра дерева `Diam(T) = dist_u[w]`.

**Доведення коректності алгоритму двох BFS:**
Нехай `a` та `b` — вершини, що утворюють справжній діаметральний шлях `P(a, b)` у дереві `T`.
Розглянемо довільну вершину `x`. У дереві існує єдиний простий шлях між будь-якими двома вершинами.
Нехай `u` — найвіддаленіша вершина від `x`, знайдена першим `BFS(x)`.

- **Випадок 1:** Шлях від `x` до `u` перетинається з діаметральним шляхом `P(a, b)` у деякому вузлі `y`.
  Тоді `dist(x, u) = dist(x, y) + dist(y, u)`.
  Оскільки `u` є найвіддаленішою від `x`, то `dist(x, u) >= dist(x, a)` та `dist(x, u) >= dist(x, b)`.
  Це означає, що `dist(y, u) >= max(dist(y, a), dist(y, b))`.
  Додавши шлях від `u` через `y` до одного з кінців діаметра (`a` або `b`), отримуємо шлях довжиною `dist(u, y) + max(dist(y, a), dist(y, b)) >= dist(a, b)`.
  Оскільки `dist(a, b)` є максимальним можливим шляхом у дереві, цей новий шлях також є діаметральним, отже `u` є одним із кінців діаметра.

- **Випадок 2:** Шлях від `x` до `u` не перетинається прямо з `P(a, b)`.
  З зв'язності дерева існує єдиний місток, який з'єднує `x` з деякою точкою `y` на діаметрі `P(a, b)`.
  Аналогічне розбиття шляхів показує, що якщо `dist(x, u) >= dist(x, a)`, то вершина `u` гарантовано є кінцевою точкою іншого діаметрального шляху такої самої довжини.

Отже, друга вершина `u` завжди належить принаймні одному діаметральному шляху дерева, і другий `BFS(u)` знаходить точний діаметр за лінійний час `O(V + E)`.

### Математичний аналіз ширини графів та споживання пам'яті

Розглянемо аналітичну залежність максимального розміру черги `max |Q|` від топологічних характеристик графа.

#### 1. Двовимірні квадратні сітки (2D Lattice Grids)
Розглянемо сітку розміром `N × N`. Шар `L_k` на такій сітці утворює ромбоподібний фронт (манхеттенське коло).
Кількість вершин у шарі `L_k` дорівнює:
```
|L_k| = 4k  (для k > 0)
```
Максимальний розмір черги досягається на діагоналі сітки при `k = N`, де `max |Q| = O(N) = O(√V)`. Таким чином, для двовимірної сітки з `V` клітинами BFS потребує лише `O(√V)` додаткової пам'яті під чергу.

#### 2. n-мірний гіперкуб (Hypercube Graphs)
Розглянемо граф гіперкуба `Q_n`, що має `V = 2^n` вершин, де кожна вершина кодується двоічним рядком довжиною `n`, а ребра з'єднують вершини з відстаню Геммінга 1.
Кількість вершин у шарі `L_k` від вершини `00...0` дорівнює біноміальному коефіцієнту:
```
|L_k| = C(n, k) = n! / (k! (n - k)!)
```
За теоремою Муавра-Лапласа, максимальний розмір черги досягається на медіанному рівні `k = n / 2`:
```
max |Q| = C(n, n/2) ≈ √(2 / (π n)) · 2^n = O(V / √log V)
```
Для графа гіперкуба обсяг черги становить переважну більшість усіх вершин графа.

#### 3. Випадкові графи Ердеша-Реньї (Erdős–Rényi Random Graphs)
У випадковому графі `G(N, p)` із середнім ступенем `d = p · N > 1` розмір шару `L_k` зростає як геометрична прогресія `|L_k| ≈ d^k` до досягнення екватора обходу `k ≈ log_d N`. На медіанному шарі ширина черги охоплює значну частку всіх вершин `max |Q| = Θ(V)`.

### Математичний аналіз гібридного обходу Беймера (Direction-Optimized BFS)

У масивних графах типу «світ малий» (Small-World Networks — соціальні мережі, веб-графи), де середня довжина шляху мала, а коефіціент розгалуження великий, стандартний Top-Down BFS зазнає суттєвих втрат продуктивності через обробку величезного фронту `L_k`.

У 2012 році Скотт Беймер запропонував гібридний метод **Direction-Optimized BFS**, який чергує дві математичні фази обходу:

#### 1. Фаза Top-Down (Зверху вниз)
Для кожної вершини `u` у поточному фронті `L_k` обходиться її список вихідних ребер `(u, v)`. Якщо `v` ще не відвідана, її додають до наступного шару `L_{k+1}`.
Кількість перевірених ребер у фазі Top-Down дорівнює:
```
E_{top_down} = ∑_{u ∈ L_k} deg^+(u)
```

#### 2. Фаза Bottom-Up (Знизу вгору)
Замість обходу вихідних ребер активного фронту, алгоритм сканує всі **ще не відвідані вершини `v`** у графі і перевіряє їхні **вхідні ребра `(w, v)`**:
- Якщо серед вхідних ребер знайдено хоча б одну вершину `w ∈ L_k`, вершина `v` негайно позначається як відвідана (`dist[v] = k + 1`), додається до `L_{k+1}`, і перевірка решти її вхідних ребер зупиняється (Early Break).

Імовірність раннього зупину для вершини `v` із вхідним ступенем `deg^-(v)` при розмірі фронту `|L_k|`:
```
P(v ∈ L_{k+1}) = 1 - (1 - |L_k| / |V|)^(deg^-(v))
```

Для щільних графів, коли фронт `|L_k|` охоплює значну частку вершин (наприклад, понад 10–20% від `|V|`), імовірність знайти батька вже на першому-другому вхідному ребрі прямує до 1. В результаті кількість сканованих ребер у фазі Bottom-Up падає в десятки разів за формулою:
```
E_{bottom_up} ≪ ∑_{v ∉ Visited} deg^-(v)
```

#### Математична умова перемикання фаз:
Перехід із фази Top-Down у фазу Bottom-Up відбувається тоді, коли кількість ребер, які виходять із поточного фронту `L_k`, перевищує порогове значення:
```
∑_{u ∈ L_k} deg^+(u) > E_{unvisited} / α
```
де `E_{unvisited}` — кількість ребер, що залишаються у невідвіданій частині графа, а `α` — коефіцієнт налаштування (типово `α ≈ 14`).

Зворотне перемикання з Bottom-Up на Top-Down відбувається тоді, коли розмір фронту `|L_k|` знову падає нижче порога:
```
|L_k| < |V| / β
```
де `β` — коефіцієнт зворотного перемикання (типово `β ≈ 24`).

Оптимізація Беймера знижує число перевірених ребер у суперкомп'ютерному бенчмарку Graph500 у 4–8 разів, зберігаючи строгу математичну гарантію точності відстаней `dist[v] = δ(s, v)`.

### Теорема про єдиність остовного дерева найкоротших шляхів

**Теорема (Умови єдиності дерева BFS):**
Остовне дерево найкоротших шляхів `T_BFS`, згенероване алгоритмом BFS для граф `G = (V, E)` від вершини `s`, є єдиним тоді й лише тоді, коли для кожної вершини `v ∈ V \ {s}` існує **рівно одна** вершина `u ∈ V`, така що `(u, v) ∈ E` та `δ(s, v) = δ(s, u) + 1`.

*Доведення:*
Якщо існує хоча б одна вершина `v`, яка має двох різних батьків `u_1` та `u_2` на попередній відстані (`δ(s, u_1) = δ(s, u_2) = δ(s, v) - 1`), порядок обходу сусідів залежить від порядку вершин у списках сусідості `adj[]`.
Якщо `u_1` обробляється раніше за `u_2`, алгоритм встановить `parent[v] = u_1`. Якщо змінити порядок викликів або переставити елементи у списках сусідості так, щоб `u_2` оброблялася раніше, алгоритм встановить `parent[v] = u_2`.
Обидва отримані остовні дерева `T_1` та `T_2` задовільняють умову найкоротших відстаней `dist[v] = δ(s, v)`, але відрізняються ребрами.
Отже, єдиність остовного дерева BFS гарантується тоді й лише тоді, коли вибір батьківської вершини є однозначним для всіх вузлів графа.

### Покроковий приклад індукційного обчислення

Продемонструємо виведення інваріанту монотонності на конкретному графі з 4 вершин:
`E = {(S, A), (S, B), (A, C), (B, C)}`.

```
 Крок 0 (Старт):
   Q = [S], dist[S] = 0
   Черга монотонна: [0]

 Крок 1 (Вилучаємо S):
   Додаємо A та B (dist = 0 + 1 = 1)
   Q = [A, B], dist = [1, 1]
   Нерівність: 1 <= 1 та 1 <= 1 + 1 (Виконується!)

 Крок 2 (Вилучаємо A):
   Додаємо C (dist = 1 + 1 = 2)
   Q = [B, C], dist = [1, 2]
   Нерівність: 1 <= 2 та 2 <= 1 + 1 (Виконується!)

 Крок 3 (Вилучаємо B):
   C вже відвідано (dist[C] = 2)
   Q = [C], dist = [2]
   Нерівність: 2 <= 2 (Виконується!)

 Крок 4 (Вилучаємо C):
   Q = []
   Завершено. Всі dist рівні exact δ(S, v).
```

Цей числовий розрахунок підтверджує, що теоретичні леми строго відповідають кожній ітерації алгоритму в реальному коді.
