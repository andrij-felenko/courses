# 🧮 Математичні основи: граф редагування та інваріанти Маєрса

Формальний аналіз задачі порівняння послідовностей спирається на дискретну геометрію графа редагування, теорію двоїстості між спільною підпослідовністю та сценарієм правок, а також інваріанти збереження парності на сіткових діагоналях.

## Формальні означення та дуальність LCS і SES

Нехай задано скінченний алфавіт `Σ`. Послідовності `A = (a₁, a₂, ..., a_N)` та `B = (b₁, b₂, ..., b_M)` є векторами елементів з `Σ`, де `|A| = N` та `|B| = M`.

Підпослідовністю послідовності `A` називається будь-яка послідовність `A'`, отримана вилученням нуля або більше елементів зі збереженням відносного порядку тих, що залишилися. Формально, існує строго монотонний набір індексів `1 ≤ i₁ < i₂ < ... < i_k ≤ N`, такий що:

```
A' = (a_{i₁}, a_{i₂}, ..., a_{i_k})
```

Послідовність `C` є **спільною підпослідовністю** (Common Subsequence) для `A` та `B`, якщо вона є підпослідовністю і для `A`, і для `B`. Довжина найдовшої такої послідовності позначається через `LCS(A, B)`.

**Сценарієм редагування** (Edit Script) називається послідовність операцій вилучення (Delete) елемента з `A` та вставки (Insert) елемента з `B`, яка послідовно трансформує рядок `A` в рядок `B`. Вартістю сценарію є сумарна кількість виконаних операцій. Найкоротший сценарій редагування позначається як `SES(A, B)`, а його довжина (кількість правок) — як `D`.

### Теорема про двоїстість LCS та SES

Для будь-яких двох послідовностей `A` та `B` довжин `N` та `M` довжина найкоротшого сценарію редагування `D` та довжина найдовшої спільної підпослідовності `L = |LCS(A, B)|` пов'язані строгим співвідношенням:

```
D
= (N - L) + (M - L)        [видаляємо всі елементи A поза LCS і додаємо всі елементи B поза LCS]
= N + M - 2·L              [згруповано доданки]
```

**Доведення.** 
1. Нехай знайдено спільну підпослідовність довжини `L`. Щоб перетворити `A` на `B`, необхідно:
   - Видалити з `A` всі елементи, які не увійшли до спільної підпослідовності. Кількість таких видалень дорівнює `N - L`.
   - Вставити в отриману спільну послідовність усі елементи з `B`, які не увійшли до спільної підпослідовності. Кількість таких вставок дорівнює `M - L`.
   - Загальна кількість операцій дорівнює `(N - L) + (M - L) = N + M - 2·L`. Звідси випливає верхня оцінка: `D ≤ N + M - 2·L`.

2. Припустимо, існує сценарій редагування довжини `D'`, що складається з `d_del` видалень та `d_ins` вставок, причому `D' = d_del + d_ins`. Кожна операція видалення зменшує довжину послідовності на 1, а вставка збільшує на 1:
   ```
   M - N = d_ins - d_del
   ```
   Звідси кількість елементів `A`, які не зазнали видалення і були збережені у `B`, дорівнює `K = N - d_del = M - d_ins`. Ці збережені елементи утворюють спільну підпослідовність для `A` та `B` довжини `K`. 

   Оскільки `L` — довжина НАЙДОВШОЇ спільної підпослідовності, маємо `K ≤ L`.
   Підставляючи вираз для `D'`:
   ```
   D'
   = d_del + d_ins
   = (N - K) + (M - K)     [за означенням K = N - d_del та K = M - d_ins]
   = N + M - 2·K           [арифметичне перегрупування]
   ≥ N + M - 2·L           [оскільки K ≤ L, віднімання більшого числа зменшує різницю]
   ```
   Отже, мінімальне можливе значення `D` досягається тоді й лише тоді, коли `K = L`, що дає `D = N + M - 2·L`. Теорему доведено.

## Геометрія графа редагування (Edit Graph)

Граф редагування `G = (V, E)` для послідовностей `A` та `B` будується як орієнтована прямокутна сітка розміром `(N + 1) × (M + 1)`:
- Множина вершин: `V = {(x, y) | 0 ≤ x ≤ N, 0 ≤ y ≤ M}`.
- Множина ребер складається з трьох типів переходів:
  1. Горизонтальні ребра: `(x-1, y) → (x, y)` з вагою 1 для всіх `1 ≤ x ≤ N, 0 ≤ y ≤ M` (видалення елемента `a_x`).
  2. Вертикальні ребра: `(x, y-1) → (x, y)` з вагою 1 для всіх `0 ≤ x ≤ N, 1 ≤ y ≤ M` (вставка елемента `b_y`).
  3. Діагональні ребра: `(x-1, y-1) → (x, y)` з вагою 0 для пар, де `a_x = b_y` (безкоштовний перехід / збіг).

Будь-який шлях від вершини `(0, 0)` до вершини `(N, M)` відповідає коректному сценарію редагування. Вага шляху дорівнює сумі ваг його ребер (тобто кількості горизонтальних та вертикальних кроків). Пошук найкоротшого сценарію редагування еквівалентний пошуку шляху мінімальної ваги на графі `G`.

## Діагоналі та інваріант парності Маєрса

Кожній вершині `(x, y)` графа редагування зіставляється номер діагоналі `k`, визначений як:

```
k = x - y
```

Діагональ `k = 0` проходить через точку початку `(0, 0)`. Діагоналі з `k > 0` лежать нижче і правіше головної діагоналі, а з `k < 0` — вище і лівіше. Оскільки `0 ≤ x ≤ N` та `0 ≤ y ≤ M`, значення `k` належить діапазону `-M ≤ k ≤ N`.

### Теорема про збереження парності діагоналей

Нехай шлях у графі редагування починається в `(0, 0)` і містить рівно `D` недіагональних ребер (сумарно горизонтальних і вертикальних). Тоді кінцева вершина шляху `(x, y)` лежить на такій діагоналі `k = x - y`, що:

```
k ≡ D (mod 2)
```

та `-D ≤ k ≤ D`.

**Доведення за індукцією по D.**
- **База індукції (`D = 0`):** Початкова точка `(0, 0)` має `x = 0, y = 0`, отже `k = 0 - 0 = 0`. Діагональні ребра мають вигляд `(x-1, y-1) → (x, y)`, де `x' - y' = (x - 1) - (y - 1) = x - y = k`. Діагональні кроки не змінюють номер діагоналі `k`. Отже, при `D = 0` кінцева точка лежить на діагоналі `k = 0`, і `0 ≡ 0 (mod 2)`.
- **Індукційний перехід (`D - 1 → D`):** Припустимо, твердження справедливе для `D - 1`, тобто всі досяжні точки лежать на діагоналях `k' ∈ {-(D-1), -(D-1)+2, ..., D-1}` і `k' ≡ (D - 1) (mod 2)`.
  Розглянемо `D`-й недіагональний крок:
  1. Якщо виконується горизонтальний крок `(x, y) → (x + 1, y)` з діагоналі `k'`:
     ```
     k_new = (x + 1) - y = (x - y) + 1 = k' + 1
     ```
  2. Якщо виконується вертикальний крок `(x, y) → (x, y + 1)` з діагоналі `k'`:
     ```
     k_new = x - (y + 1) = (x - y) - 1 = k' - 1
     ```
  В обох випадках `k_new = k' ± 1`. Оскільки `k' ≡ (D - 1) (mod 2)`, маємо:
  ```
  k_new ≡ (D - 1) ± 1 ≡ D (mod 2)
  ```
  Мінімальне можливе значення нової діагоналі: `-(D - 1) - 1 = -D`. Максимальне: `(D - 1) + 1 = D`. Подальший рух уздовж діагональних нульових ребер (змій) не змінює різниці `x - y = k`. Теорему доведено.

### Жадібна формула максимального поступу

Нехай `V[k]` зберігає максимальну координату `x`, досяжну на діагоналі `k` за `D` недіагональних кроків. На кроці `D` значення `V[k]` для кожного `k ∈ {-D, -D+2, ..., D}` обчислюється жадібно з двох сусідніх діагоналей попереднього кроку `D - 1`:

```
x = V[k + 1]        [якщо k == -D або (k != D і V[k - 1] < V[k + 1]) — крок вниз від k+1]
x = V[k - 1] + 1    [інакше — крок вправо від k-1]

y = x - k           [відновлення координати y на діагоналі k]

поки x < N і y < M і A[x + 1] == B[y + 1]:
    x = x + 1       [жадібне ковзання по діагональному збігу (змія)]
    y = y + 1
```

Оскільки на кожному кроці `D` розглядається `D + 1` діагональ, а максимальна довжина діагоналі обмежена `O(N + M)`, сумарна часова складність до моменту знаходження точки `(N, M)` дорівнює:

```
T(N, M, D)
= ∑_{d=0}^{D} (d + 1) + O(D · (N + M))
= O(D² + D · (N + M))
= O((N + M) · D)            [оскільки D ≤ N + M]
```

## Математичне обґрунтування рекурсії Гіршберґа

Алгоритм Гіршберґа оптимізує споживання простору динамічного програмування, зводячи матричну пам'ять `O(N · M)` до лінійного вектора `O(M)`.

Нехай `Score(A, B)` повертає останній рядок матриці DP для LCS довжини `M + 1`.
Алгоритм фіксує середину першої послідовності `mid = ⌊N / 2⌋`.

Введемо дві векторні функції:
1. `L_fwd[j] = Score(A[1 .. mid], B[1 .. j])` — довжина LCS префікса `A` довжиною `mid` з префіксом `B` довжиною `j`.
2. `L_bwd[j] = Score(rev(A[mid + 1 .. N]), rev(B[j + 1 .. M]))` — довжина LCS суфіксів.

Оптимальна точка розрізу `j*` у послідовності `B` максимізує сумарний збіг:

```
j* = argmax_{0 ≤ j ≤ M} (L_fwd[j] + L_bwd[M - j])
```

### Доведення часової складності O(N · M)

Нехай час роботи алгоритму Гіршберґа для послідовностей довжин `N` та `M` обмежений рекурентним співвідношенням:

```
T(N, M) ≤ c · N · M + T(N/2, j*) + T(N/2, M - j*)
```

де `c · N · M` — час обчислення двох векторів `L_fwd` та `L_bwd`.

Доведемо за індукцією, що `T(N, M) ≤ 2 · c · N · M`:
- **База:** Для малих `N, M ≤ 1` умова виконується безпосередньо.
- **Крок індукції:**
  ```
  T(N, M)
  ≤ c · N · M + T(N/2, j*) + T(N/2, M - j*)
  ≤ c · N · M + 2·c · (N/2) · j* + 2·c · (N/2) · (M - j*)   [за індукційним припущенням]
  = c · N · M + c · N · j* + c · N · (M - j*)               [скорочення двійки]
  = c · N · M + c · N · (j* + M - j*)                       [винесення спільного множника c·N]
  = c · N · M + c · N · M                                   [спрощення суми індексів]
  = 2 · c · N · M                                           [підсумкова константа 2c]
  ```

Таким чином, незважаючи на повторне обчислення DP-векторів на кожному рівні рекурсії, загальний час виконання алгоритму Гіршберґа не перевищує подвоєного часу одного повного матричного проходу `2 · c · N · M = O(N · M)`, при цьому необхідна пам'ять обмежена `2 · (M + 1) = O(M)`.
