# 🧮 Математичне виведення формули шнурівки, теорема Гріна та центроїд

Обчислення площі довільного многокутника через координати вершин спирається на дискретну форму формули Гріна для контурного інтеграла, мову зовнішніх диференціальних форм Картана, адитивність других моментів площі та теорему Штейнера для тензора інерції. Нижче наведено суворе математичне виведення формули шнурівки з неперервного аналізу, алгебраїчний доказ інваріантності результату щодо зсуву системи координат, перетворення під дією афінних операторів, виведення формул геометричного центроїда, а також повний розрахунок головних моментів інерції однорідної багатокутної пластини.

## Теорема Гріна та диференціальні форми площі

Нехай `D` — обмежена однозв'язна область на площині `ℝ²` з кусково-лінійною орієнтованою межею `∂D`, що обходиться у додатному напрямку (проти годинникової стрілки, так що внутрішня область залишається ліворуч від вектора дотичної).

Згідно з класичною теоремою Гріна, для будь-яких неперервно диференційовних скалярних полів `L(x, y)` та `M(x, y)` подвійний інтеграл за областю `D` тотожно дорівнює циркуляції векторного поля вздовж замкненого контуру `∂D`:

```
∬_D (∂M/∂x − ∂L/∂y) dx dy = ∮_∂D (L dx + M dy)
```

Геометрична площа області `D` визначається подвійним інтегралом від одиничної густини:

```
S = ∬_D 1 dx dy
```

Мовою зовнішніх диференціальних форм площа виражається інтегралом від форми об'єму (площі) `dω = dx ∧ dy`. Якщо знайти таку диференціальну 1-форму `ω = L dx + M dy`, зовнішній диференціал якої дорівнює формі площі `dω = dx ∧ dy`, то за загальною теоремою Стокса для ланцюгів `∬_D dω = ∮_∂D ω`.

Підбираючи функції `L` та `M` так, щоб вираз `∂M/∂x − ∂L/∂y` дорівнював `1`, ми отримуємо три рівносильні контурні форми для площі:

1. **Форма проєкцій на вісь Y:** Покладемо `L = 0, M = x`. Тоді `∂M/∂x − ∂L/∂y = 1 − 0 = 1`, звідки:

```
S = ∮_∂D x dy
```

2. **Форма проєкцій на вісь X:** Покладемо `L = −y, M = 0`. Тоді `∂M/∂x − ∂L/∂y = 0 − (−1) = 1`, звідки:

```
S = −∮_∂D y dx
```

3. **Симетрична антисиметризована форма:** Взявши напівсуму попередніх двох виразів (що відповідає диференціальній 1-формі `ω = (1/2)·(x dy − y dx)`):

```
S = (1/2) · ∮_∂D (x dy − y dx)
```

Симетрична форма має найвищу числову стабільність при машинних обчисленнях, оскільки обидві просторові координати входять у неї з однаковою вагою та однаково реагують на похибки округлення.

## Інтегрування диференціальної форми вздовж прямолінійного відрізка

Межа багатокутника `∂D` розбивається на скінченну кількість `n` прямолінійних орієнтованих відрізків `e_i = [V_i, V_{i+1}]`, де `i ∈ {0, 1, ..., n − 1}`, а кінцева вершина замикається на початкову: `V_n = V_0`.

Кожна вершина задана парою дійсних координат: `V_i = (x_i, y_i)`.

Параметризуємо довільний відрізок `e_i` за допомогою скалярного параметра `t ∈ [0, 1]`:

```
x(t) = x_i + t · (x_{i+1} − x_i)
y(t) = y_i + t · (y_{i+1} − y_i)
```

Обчислимо диференціали вздовж параметризованого ребра:

```
dx = (x_{i+1} − x_i) dt
dy = (y_{i+1} − y_i) dt
```

Підставимо ці вирази у підінтегральну форму `x dy − y dx`:

```
x(t) dy − y(t) dx
= [ x_i + t·(x_{i+1} − x_i) ] · (y_{i+1} − y_i) dt − [ y_i + t·(y_{i+1} − y_i) ] · (x_{i+1} − x_i) dt    [підстановка параметричних рівнянь]
= x_i · (y_{i+1} − y_i) dt + t·(x_{i+1} − x_i)(y_{i+1} − y_i) dt
  − y_i · (x_{i+1} − x_i) dt − t·(y_{i+1} − y_i)(x_{i+1} − x_i) dt                                      [розкриття добутків]
= (x_i y_{i+1} − x_i y_i − y_i x_{i+1} + y_i x_i) dt                                                     [взаємне скорочення доданків із параметром t]
= (x_i · y_{i+1} − x_{i+1} · y_i) dt                                                                     [скорочення x_i y_i]
```

Член, залежний від параметра `t`, тотожно перетворюється на нуль. Це показує, що диференціальна густина площі вздовж прямолінійного відрізка є абсолютно константною та не залежить від положення точки на відрізку.

Обчислимо визначений інтеграл уздовж відрізка `e_i`:

```
∫_{e_i} (x dy − y dx)
= ∫₀¹ (x_i · y_{i+1} − x_{i+1} · y_i) dt    [підстановка спрощеного виразу]
= (x_i · y_{i+1} − x_{i+1} · y_i) · ∫₀¹ dt    [винесення константи за знак інтеграла]
= x_i · y_{i+1} − x_{i+1} · y_i              [оскільки інтеграл від 1 на проміжку [0, 1] дорівнює 1]
```

Підсумовуючи інтеграли вздовж усіх `n` відрізків межі, отримуємо замкнений вираз формули шнурівки:

```
S = (1/2) · ∑_{i=0}^{n-1} (x_i · y_{i+1} − x_{i+1} · y_i)
```

## Доказ інваріантності щодо паралельного перенесення

Геометрична площа фігури є евклідовим інваріантом і не може змінюватися при зміні початку координат. Доведемо алгебраїчно, що формулі шнурівки притаманна ця властивість.

Нехай усі вершини багатокутника зміщено на сталий вектор `(x₀, y₀)`:

```
x'_i = x_i + x₀
y'_i = y_i + y₀
```

Обчислимо подвоєну площу `2 · S'` у зміщеній системі координат:

```
2 · S'
= ∑_{i=0}^{n-1} (x'_i · y'_{i+1} − x'_{i+1} · y'_i)                                                           [означення у новій системі]
= ∑_{i=0}^{n-1} [ (x_i + x₀)(y_{i+1} + y₀) − (x_{i+1} + x₀)(y_i + y₀) ]                                      [підстановка зміщених координат]
= ∑_{i=0}^{n-1} [ (x_i y_{i+1} + x_i y₀ + x₀ y_{i+1} + x₀ y₀) − (x_{i+1} y_i + x_{i+1} y₀ + x₀ y_i + x₀ y₀) ] [розкриття дужок]
= ∑_{i=0}^{n-1} (x_i y_{i+1} − x_{i+1} y_i) + y₀ · ∑_{i=0}^{n-1} (x_i − x_{i+1}) + x₀ · ∑_{i=0}^{n-1} (y_{i+1} − y_i)  [групування за коефіцієнтами x₀ та y₀]
```

Розглянемо суми різниць сусідніх координат:

```
∑_{i=0}^{n-1} (x_i − x_{i+1}) = (x₀ − x₁) + (x₁ − x₂) + ... + (x_{n-1} − x₀) = 0    [телескопічна сума замкненого контуру]
∑_{i=0}^{n-1} (y_{i+1} − y_i) = (y₁ − y₀) + (y₂ − y₁) + ... + (y₀ − y_{n-1}) = 0    [телескопічна сума замкненого контуру]
```

Оскільки обидві суми тотожно обнуляються для будь-якого замкненого циклу, коефіцієнти при `x₀` та `y₀` зникають:

```
2 · S'
= ∑_{i=0}^{n-1} (x_i y_{i+1} − x_{i+1} y_i) + y₀ · 0 + x₀ · 0    [підстановка нульових сум]
= 2 · S                                                            [зсув системи координат не змінює результат]
```

Ця інваріантність дозволяє віднімати координати першої вершини `(x₀, y₀)` перед виконанням обчислень, що усуває втрату точності чисел із плаваючою комою у великих світових координатах.

## Поведінка під дією афінних перетворень

Нехай на площині задано довільне афінне перетворення `T(v) = A · v + b`, де `A` — матриця 2×2, а `b` — вектор паралельного перенесення:

```
| x' | = | a₁₁  a₁₂ | · | x | + | b_x |
| y' |   | a₂₁  a₂₂ |   | y |   | b_y |
```

З математичного аналізу відомо, що при заміні змінних у подвійному інтегралі елемент площі перетворюється через модуль детермінанта матриці Якобі (якобіана):

```
dx' dy' = |det(A)| dx dy
```

Для орієнтованої площі знак зберігається відповідно до знака детермінанта `det(A)`:

```
S_орієнт(T(P)) = det(A) · S_орієнт(P)
```

Якщо `det(A) > 0` (перенесення, масштабування з додатними коефіцієнтами, повороти), орієнтація контуру зберігається (CCW залишається CCW). Якщо `det(A) < 0` (дзеркальне відбиття від прямої), орієнтація змінюється на протилежну (CCW стає CW), а площа змінює знак на протилежний.

## Виведення координат центроїда через моменти першого порядку

Геометричний центроїд `(C_x, C_y)` плоскої однорідної пластини `D` одиничної густини визначається відношенням статичних моментів площі до повної площі `S`:

```
C_x = (1 / S) · ∬_D x dx dy
C_y = (1 / S) · ∬_D y dx dy
```

Застосуємо теорему Гріна до інтеграла `∬_D x dx dy`. Підберемо векторне поле `L = 0, M = (1/2) · x²`, де `∂M/∂x − ∂L/∂y = x`:

```
∬_D x dx dy = (1/2) · ∮_∂D x² dy
```

Проінтегруємо `(1/2) · x² dy` вздовж параметризованого відрізка `[V_i, V_{i+1}]`:

```
∫₀¹ [ x_i + t·(x_{i+1} − x_i) ]² · (y_{i+1} − y_i) dt
= (y_{i+1} − y_i) · ∫₀¹ [ x_i² + 2 t x_i(x_{i+1} − x_i) + t²(x_{i+1} − x_i)² ] dt               [розкриття квадрата бінома]
= (y_{i+1} − y_i) · [ x_i² + x_i(x_{i+1} − x_i) + (1/3)·(x_{i+1} − x_i)² ]                      [інтегрування t та t²]
= (y_{i+1} − y_i) · [ (1/3)·(x_i² + x_i x_{i+1} + x_{i+1}²) ]                                   [алгебраїчне зведення подібних]
```

З іншого боку, розглядаючи елементарний трикутник `Δ(O, V_i, V_{i+1})` з початком у нулі, його орієнтована площа та координата центроїда дорівнюють:

```
S_i = (1/2) · (x_i y_{i+1} − x_{i+1} y_i)
c_{i, x} = (x_i + x_{i+1}) / 3
```

За теоремою про центр мас складеної системи:

```
C_x · S
= ∑_{i=0}^{n-1} c_{i, x} · S_i                                                                [зважена сума центроїдів трикутників]
= ∑_{i=0}^{n-1} [ ((x_i + x_{i+1}) / 3) · (1/2) · (x_i y_{i+1} − x_{i+1} y_i) ]               [підстановка центроїда та площі]
= (1/6) · ∑_{i=0}^{n-1} (x_i + x_{i+1}) · (x_i y_{i+1} − x_{i+1} y_i)                         [винесення множника 1/6]
```

Аналогічно для координати `C_y`:

```
C_y · S = (1/6) · ∑_{i=0}^{n-1} (y_i + y_{i+1}) · (x_i y_{i+1} − x_{i+1} y_i)
```

Ділячи на площу `S`, отримуємо шукані координати:

```
C_x = (1 / (6 · S)) · ∑_{i=0}^{n-1} (x_i + x_{i+1}) · (x_i y_{i+1} − x_{i+1} y_i)
C_y = (1 / (6 · S)) · ∑_{i=0}^{n-1} (y_i + y_{i+1}) · (x_i y_{i+1} − x_{i+1} y_i)
```

## Виведення других моментів інерції та теорема Штейнера

У фізичних рушіях та системах динаміки твердого тіла (2D Rigid Body Physics) важливими характеристиками є моменти інерції плоскої пластини відносно початку координат:

```
I_xx = ∬_D y² dx dy
I_yy = ∬_D x² dx dy
I_xy = ∬_D x y dx dy
```

Застосовуючи теорему Гріна до поля `(L, M) = (0, (1/3)·x³)` для моменту `I_yy`:

```
I_yy = ∬_D x² dx dy = (1/3) · ∮_∂D x³ dy
```

Інтегруючи кубічний вираз `x(t)³` вздовж відрізка `[V_i, V_{i+1}]` і спрощуючи отримані алгебраїчні коефіцієнти, одержуємо замкнені вирази:

```
I_yy = (1/12) · ∑_{i=0}^{n-1} (x_i² + x_i x_{i+1} + x_{i+1}²) · (x_i y_{i+1} − x_{i+1} y_i)
I_xx = (1/12) · ∑_{i=0}^{n-1} (y_i² + y_i y_{i+1} + y_{i+1}²) · (x_i y_{i+1} − x_{i+1} y_i)
I_xy = (1/24) · ∑_{i=0}^{n-1} (x_i y_{i+1} + 2 x_i y_i + 2 x_{i+1} y_{i+1} + x_{i+1} y_i) · (x_i y_{i+1} − x_{i+1} y_i)
```

Щоб отримати центральний момент інерції відносно власного центру мас пластини `(C_x, C_y)`, застосовують теорему Гюйгенса–Штейнера про паралельні осі:

```
I_{C, xx} = I_xx − S · C_y²
I_{C, yy} = I_yy − S · C_x²
I_{C, xy} = I_xy − S · C_x C_y
```

Полярний момент інерції відносно центру мас пластини дорівнює сумі осьових моментів:

```
J_C = I_{C, xx} + I_{C, yy}
```

Ці результати підтверджують, що абсолютно всі інтегральні геометричні та механічні характеристики плоскої фігури (орієнтована площа, положення центру мас, тензор інерції будь-якого порядку) повністю виражаються через суми поліноміальних комбінацій координат сусідніх вершин, зважених на елементарні косі добутки `(x_i y_{i+1} − x_{i+1} y_i)`.
