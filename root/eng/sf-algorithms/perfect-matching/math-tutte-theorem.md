# 🧮 Теорема Тутте та алгебраїчні методи паросполучень

Математичний апарат теорії досконалих паросполучень спирається на дві фундаментальні опори: структурно-комбінаторну (критерій Тутте та формула Тутте-Бержа) та алгебраїчно-спектральну (кососиметрична матриця Тутте, фафіан та детермінантні тотожності over finite fields). Ця вставка містить суворе математичне формулювання, математичне виведення ключових співвідношень та докладний розбір алгебраїчного методу Ловаса для інваріантної перевірки існування паросполучення.

## 1. Комбінаторний аналіз: Теорема Тутте та її виведення

Нехай `G = (V, E)` — скінченний неорієнтований граф без петель та кратних ребер із кількістю вершин `|V| = n`. Досконале паросполучення (perfect matching) — це підмножина ребер `M ⊆ E`, така що кожна вершина `v ∈ V` є інцидентною рівно одному ребру з `M`. Очевидною необхідною умовою існування досконалого паросполучення є парність кількості вершин: `n` має бути парним числом.

Для довільної підмножини вершин `S ⊆ V` позначимо через `G \ S` підграф, отриманий вилученням із `G` усіх вершин множини `S` та інцидентних їм ребер. Позначимо через `q(G \ S)` кількість зв'язних компонент підграфа `G \ S`, які мають **непарну** кількість вершин.

> 🧮 **Теорема Тутте (1947).** Граф `G = (V, E)` має досконале паросполучення тоді й лише тоді, коли для будь-якої підмножини вершин `S ⊆ V` виконується нерівність:
> ```
> q(G \ S) ≤ |S|
> ```

### Доведення необхідності (⇒)

Нехай у графі `G` існує досконале паросполучення `M`. Зафіксуємо довільну підмножину вершин `S ⊆ V`. Розглянемо будь-яку непарну зв'язну компоненту `C` у підграфі `G \ S`.

Оскільки компонента `C` містить непарну кількість вершин `|V(C)| = 2k + 1`, ребра паросполучення `M`, які з'єднують вершини всередині `C`, можуть покрити максимум `2k` вершин. Отже, принаймні одна вершина `u ∈ V(C)` повинна бути з'єднана ребром з `M` із вершиною, що лежить за межами компонети `C`.

Оскільки в `G \ S` немає ребер між різними компонентами, єдиним можливим місцем розташування суміжної вершини є множина `S`. Отже, кожна з `q(G \ S)` непарних компонент має принаймні одне ребро з `M`, що веде до множини `S`.

Оскільки кожна вершина з `S` може бути покрита лише одним ребром з `M`, множина `S` не може прийняти ребра від більше ніж `|S|` різних компонент. Звідси безпосередньо випливає необхідна нерівність:

```
q(G \ S) ≤ |S|
```

### Доведення достатності (⇐) та конструктивні властивості

Доведення достатності побудовано від супротивного. Припустимо, що нерівність `q(G \ S) ≤ |S|` виконується для всіх `S ⊆ V`, але граф `G` не має досконалого паросполучення. 

Додамо до графа `G` максимальну кількість ребер так, щоб граф залишався без досконалого паросполучення. Позначимо отриманий насичений граф через `G*`. Для графа `G*` властивість `q(G* \ S) ≤ |S|` продовжує виконуватися, оскільки додавання ребер може лише об'єднувати компоненти (зменшуючи їхню кількість) або перетворювати непарні компоненти на парні.

Аналіз структури графа `G*` показує, що існує спеціальна множина вершин `S*`, така що:
1. Кожна компонента підграфа `G* \ S*` є повним графом (`Kₘ`).
2. Множина `S*` утворює повний граф чи зв'язана з усіма вершинами кожної компоненти.

Оскільки кожна компонента є повним графом, у кожній парній компоненті можна легко утворити внутрішнє досконале паросполучення. У кожній непарній компоненті `Cᵢ` можна утворити паросполучення, яке покриває всі вершини, крім однієї. Оскільки кількість непарних компонент `q(G* \ S*) ≤ |S*|`, кожну з залишкових непокритих вершин непарних компонент можна з'єднати унікальним ребром із власною вершиною з `S*`. Решту вершин множини `S*` (які залишаться після покриття непарних компонент) можна об'єднати між собою в пари, оскільки загальна кількість вершин графа є парною.

Це дає суперечність із припущенням про відсутність досконалого паросполучення у `G*`, що й доводить достатність умови Тутте.

### Формула Тутте-Бержа для максимального паросполучення

Якщо граф не має досконалого паросполучення, дефіцит покриття оцінюється через максимально можливе перевищення кількості непарних компонент над розміром вилученої множини.

```
|M_max| = (1/2) · min_{S ⊆ V} (|V| - (q(G \ S) - |S|))
        = (1/2) · (|V| - max_{S ⊆ V} (q(G \ S) - |S|))
```

Ця формула показує, що кожна непарна компонента `C`, яка перевищує розмір `|S|`, залишає принаймні одну вершину непокритою, пропорційно зменшуючи розмір максимального паросполучення.

## 2. Алгебраїчні структури: Матриця Тутте та фафіан

Альгебраїчний підхід переводить комбінаторне питання існування паросполучення у площину лінійної алгебри та теорії багаточленів.

### Символьна матриця Тутте T(G)

Для графа `G = (V, E)` із вершинами `V = {1, 2, ..., n}` визначимо кососиметричну символьну матрицю `T(G)` розміром `n × n`, елементи якої є формальними змінними `x[i, j]`:

```
T[i, j] =  x[i, j],   якщо (i, j) ∈ E та i < j
T[i, j] = -x[j, i],   якщо (i, j) ∈ E та i > j
T[i, j] =  0,         якщо (i, j) ∉ E або i = j
```

Матриця `T(G)` є кососиметричною за побудовою: `Tᵀ = -T`.

### Властивості фафіана (Pfaffian)

Для будь-якої кососиметричної матриці `A` парного порядку `n = 2m` детермінант є точним квадратом многочлена від елементів матриці, який називається **фафіаном** (Pfaffian), позначуваним `Pf(A)`:

```
det(A) = (Pf(A))²
```

Явний вираз для фафіана через розбиття множини вершин `{1, 2, ..., 2m}` на впорядковані пари `P = {(i₁, j₁), (i₂, j₂), ..., (iₘ, jₘ)}` де `i▖ < j▖` має вигляд:

```
Pf(T(G)) = ∑_{P} sgn(π_P) · ∏_{k=1}^{m} T[iₖ, jₖ]
```

де `sgn(π_P)` — знак перестановки `π_P = (1, 2, ..., 2m ↦ i₁, j₁, i₂, j₂, ..., iₘ, jₘ)`.

Кожен доданок у цій сумі відповідає розбиттю вершин графа на `m` пар `(iₖ, jₖ)`. Якщо всі пари `(iₖ, jₖ)` є ребрами графа `E`, відповідний добуток `∏ T[iₖ, jₖ]` не дорівнює нулю і являє собою одночлен `± x[i₁, j₁] · x[i₂, j₂] · ... · x[iₘ, jₘ]`.

З огляду на те, що кожне досконале паросполучення відповідає унікальній множині змінних `x[iₖ, jₖ]`, різні досконалі паросполучення породжують різні одночлени. Отже, взаємного скорочення подібних доданків у сумі не відбувається!

> 🧮 **Теорема Тутте-Ловаса.** Многочлен `det(T(G))` тотожно не дорівнює нулю (`det(T(G)) ≢ 0`) тоді й лише тоді, коли граф `G` має принаймні одне досконале паросполучення.

## 3. Рандомізований алгоритм Ловаса та Лема Шварца-Ціппеля

Перевірка символьного детермінанта `det(T(G))` на тотожну нульову рівність шляхом прямого розкриття многочлена вимагає обчислення експоненціальної кількості доданків (`O(2ⁿ)`), що є неефективним. Алгебраїчний метод Ловаса долає цю перешкоду за допомогою рандомізації over a finite field.

### Лема Шварца-Ціппеля (Schwartz-Zippel Lemma)

Нехай `P(x₁, x₂, ..., xₘ)` — ненульовий многочлен степеня `d` над скінченним полем `F_q`. Якщо значення змінних `r₁, r₂, ..., rₘ` вибираються незалежно та рівномірно-випадково зі скінченного підмножини `S ⊆ F_q`, то ймовірність того, що многочлен звернеться в нуль на цьому випадковому наборі, обмежена зверху:

```
P(P(r₁, r₂, ..., rₘ) = 0 | P ≢ 0) ≤ d / |S|
```

### Алгоритм перевірки існування досконалого паросполучення

Для перевірки існування досконалого паросполучення у графі `G = (V, E)` з `n` вершинами та `m` ребрами виконуються такі кроки:

1. Вибираємо велике скінченне поле `F_q` (або просто просте число `p > 2n` і проводимо обчислення за модулем `p`).
2. Для кожного ребра `e = (i, j) ∈ E` вибираємо незалежне випадкове число `r[i, j]` з поля `F_q` (де `r[j, i] = -r[i, j]`).
3. Формуємо числову кососиметричну матрицю `T_rand` розміром `n × n`.
4. Обчислюємо детермінант `det(T_rand)` за допомогою класичного методу Гаусса за час `O(n³)` (або `O(nʷ)` через швидке множення матриць).
5. Якщо `det(T_rand) ≠ 0`, граф **гарантовано** має досконале паросполучення.
6. Якщо `det(T_rand) = 0`, вважаємо, що граф не має досконалого паросполучення.

### Виведення ймовірності помилки

Оскільки степінь многочлена `det(T(G))` по відношенню до змінних дорівнює `d = n` (бо кожне паросполучення містить `n/2` ребер, а детермінант є квадратом фафіана), за лемою Шварца-Ціппеля ймовірність односторонньої помилки (фальшиво-негативного результату, коли паросполучення існує, але детермінант випадково обнулився) становить:

```
P(помилки) = P(det(T_rand) = 0 | det(T(G)) ≢ 0) ≤ n / q
```

Зауважимо, що фальшиво-позитивна помилка неможлива: якщо граф не має досконалого паросполучення, многочлен `det(T(G))` є тотожним нулем, і підстановка будь-яких чисел завжди дасть `det(T_rand) = 0`.

Якщо вибрати розмір поля `q ≥ 2¹²8 · n`, ймовірність помилки стає меншою за `2⁻¹²⁸`, що робить алгоритм практично абсолютно надійним інструментом у реальних обчислювальних системах.

## 4. Перманент проти Детермінанта: Дихотомія складності

Різниця між розпізнаванням існування досконалого паросполучення та обчисленням їхньої кількості математично зводиться до порівняння двох алгебраїчних операторів — **детермінанта** та **перманента**.

Для двочасткового графа з матрицею суміжності `A` розміром `n × n` кількість досконалих паросполучений рівна перманенту:

```
Perm(A) = ∑_{σ ∈ Sₙ} ∏_{i=1}^{n} A[i, σ(i)]
```

Тоді як детермінант містить знаки перестановок:

```
det(A) = ∑_{σ ∈ Sₙ} sgn(σ) · ∏_{i=1}^{n} A[i, σ(i)]
```

Наявність знаків `sgn(σ)` дозволяє обчислювати детермінант за поліноміальний час `O(n³)` через елементарні перетворення рядків (метод Гаусса). Перманент позбавлений знаків, тому подібні скорочення неможливі. Теорема Валіанта (1979) доводить, що обчислення перманента є **#P-повною задачею**, тоді як обчислення детермінанта належить до класу **P**.

### Орієнтація Кастелейна для планарних графів

Для планарних графів Пітер Кастелейн у 1961 році довів, що можна підібрати знаки для елементів матриці суміжності (шляхом надання ребрам орієнтації), так що всі доданки у детермінанті отримують однаковий знак!

> 🧮 **Теорема Кастелейна.** Для будь-якого планарного графа існує така орієнтація ребер (орієнтація Кастелейна), що кожна грань графа містить непарне число ребер, орієнтованих за годинниковою стрілкою. Для такої кососиметричної матриці `K(G)` виконується:
> ```
> (Pf(K(G)))² = det(K(G)) = (Кількість досконалих паросполучень)²
> ```

Це дає поліноміальний алгоритм складності `O(n³)` для точного підрахунку кількості досконалих паросполучень у будь-яких планарних графах.

## 5. Порівняльний алгебраїчний підсумок

```
[Граф G = (V, E)]
       │
       ├─► Комбінаторні критерії:
       │     q(G \ S) ≤ |S| (Теорема Тутте)
       │     |M_max| = (1/2) · (|V| - max(q(G \ S) - |S|)) (Формула Тутте-Бержа)
       │
       ├─► Алгебраїчні критерії:
       │     Матриця Тутте T(G) кососиметрична (Tᵀ = -T)
       │     det(T(G)) = (Pf(T(G)))²
       │     Тест Ловаса: підстановка в F_q + Гаусс O(n³)
       │     Шварц-Ціппель: P(err) ≤ n / q
       │
       └─► Підрахунок паросполучень:
             Двочасткові графи ──► Perm(A) ──► #P-повна задача
             Планарни графи ──► Орієнтація Кастелейна ──► det(K) ──► O(n³) [P]
```

Алгебраїчна теорія паросполучень демонструє унікальний зв'язок між комбінаторним перебором та лінійною алгеброю, перетворюючи складну комбінаторну структуру на обчислення детермінанта числової матриці.
