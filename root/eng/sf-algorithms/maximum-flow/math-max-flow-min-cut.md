# 🧮 Математичне доведення теореми про максимальний потік і мінімальний розріз

Теорема Форда — Фалкерсона про максимальний потік і мінімальний розріз (Max-Flow Min-Cut Theorem) є одним із фундаментальних результатів комбінаторної оптимізації. Вона стверджує, що найбільша кількість речовини, інформації або енергії, яку можна передати через мережу з пропускними обмеженнями від джерела до стоку, строго дорівнює мінімальній сумарній місткості бар'єра ребер, руйнування яких робить передачу неможливою.

Нижче наведено строге математичне виведення алгебраїчних властивостей розрізів, доведення слабкої та сильної дуальності, еквівалентності критеріїв оптимальності та обґрунтування поліноміальної збіжності алгоритму Едмондса — Карпа.

## Формальні аксіоми мережі та потоку

Нехай `G = (V, E)` — скінченний орієнтований граф без петель, у якому кожній дузі `(u, v) ∈ E` зіставлено невід'ємне дійсне число — пропускну спроможність `c(u, v) ≥ 0`. Якщо дуга `(u, v) ∉ E`, покладаємо `c(u, v) = 0`. У графі виділено дві особливі вершини: джерело `s ∈ V` (витік) та стік `t ∈ V` (`s ≠ t`).

Функція `f: V × V → ℝ` називається **допустимим потоком** (Feasible Flow), якщо вона задовольняє дві фундаментальні умови:

1. **Обмеження місткості (Capacity Constraint):** Для будь-якої пари вершин `(u, v) ∈ V × V`:
```
0 ≤ f(u, v) ≤ c(u, v)
```

2. **Збереження потоку (Flow Conservation / Закон Кірхгофа):** Для будь-якої внутрішньої вершини `u ∈ V \ {s, t}` сумарний вхідний потік дорівнює сумарному вихідному потоку:
```
∑_{v ∈ V} f(v, u) = ∑_{w ∈ V} f(u, w)
```

**Величина потоку** (Value of Flow), що позначається як `|f|`, визначається як чистий вихідний потік із джерела `s`:
```
|f| = ∑_{v ∈ V} f(s, v) - ∑_{v ∈ V} f(v, s)
```

## Алгебраїчні властивості розрізів та лема про збереження

**Розрізом мережі** `(S, T)` (s-t Cut) називається розбиття множини вершин `V` на дві неперетинні підмножини `S` та `T = V \ S` такі, що `s ∈ S` та `t ∈ T`.

**Пропускною спроможністю розрізу** `c(S, T)` називається сума місткостей усіх дуг, що спрямовані строго з множини `S` у множину `T`:
```
c(S, T) = ∑_{u ∈ S} ∑_{v ∈ T} c(u, v)
```
Зверніть увагу: місткості зворотних дуг із `T` в `S` не входять до `c(S, T)`.

**Чистим потоком через розріз** `f(S, T)` називається різниця між прямим потоком із `S` у `T` та зворотним потоком із `T` у `S`:
```
f(S, T) = ∑_{u ∈ S} ∑_{v ∈ T} f(u, v) - ∑_{u ∈ S} ∑_{v ∈ T} f(v, u)
```

### Лема 1 (Еквівалентність потоку через будь-який розріз)
Для будь-якого допустимого потоку `f` та будь-якого розрізу `(S, T)` чистий потік через розріз дорівнює повній величині потоку `|f|`:
```
f(S, T) = |f|
```

**Доведення:**
Розглянемо суму чистих вихідних потоків для всіх вершин підмножини `S`:
```
∑_{u ∈ S} ( ∑_{v ∈ V} f(u, v) - ∑_{v ∈ V} f(v, u) )
= ( ∑_{v ∈ V} f(s, v) - ∑_{v ∈ V} f(v, s) ) + ∑_{u ∈ S \ {s}} ( ∑_{v ∈ V} f(u, v) - ∑_{v ∈ V} f(v, u) )  [відокремили джерело s]
= |f| + ∑_{u ∈ S \ {s}} 0                                                                                 [за законом збереження для u ≠ s, t]
= |f|                                                                                                     [адитивність суми]
```

З іншого боку, розіб'ємо множину всіх сусідніх вершин `v ∈ V` у внутрішніх сумах на дві частини: `v ∈ S` та `v ∈ T`:
```
∑_{u ∈ S} ( ∑_{v ∈ V} f(u, v) - ∑_{v ∈ V} f(v, u) )
= ∑_{u ∈ S} ∑_{v ∈ S} f(u, v) + ∑_{u ∈ S} ∑_{v ∈ T} f(u, v) - ∑_{u ∈ S} ∑_{v ∈ S} f(v, u) - ∑_{u ∈ S} ∑_{v ∈ T} f(v, u)  [розбиття V = S ∪ T]
= ( ∑_{u ∈ S} ∑_{v ∈ S} f(u, v) - ∑_{u ∈ S} ∑_{v ∈ S} f(v, u) ) + ( ∑_{u ∈ S} ∑_{v ∈ T} f(u, v) - ∑_{u ∈ S} ∑_{v ∈ T} f(v, u) )  [групування за підмножинами]
= 0 + f(S, T)                                                                                             [внутрішні пари (u,v) ∈ S×S взаємно скорочуються]
= f(S, T)                                                                                                 [визначення чистого потоку через розріз]
```
Прирівнюючи обидва вирази, отримуємо `f(S, T) = |f|`. Лему доведено.

### Лема 2 (Слабка дуальність / Обмеження зверху)
Величина будь-якого допустимого потоку `|f|` не перевищує пропускної спроможності довільного розрізу `c(S, T)`:
```
|f| ≤ c(S, T)
```

**Доведення:**
За Лемою 1 та обмеженнями місткості:
```
|f|
= f(S, T)                                                 [за Лемою 1]
= ∑_{u ∈ S} ∑_{v ∈ T} f(u, v) - ∑_{u ∈ S} ∑_{v ∈ T} f(v, u)  [за визначенням f(S, T)]
≤ ∑_{u ∈ S} ∑_{v ∈ T} f(u, v)                             [оскільки f(v, u) ≥ 0 для всіх пар]
≤ ∑_{u ∈ S} ∑_{v ∈ T} c(u, v)                             [оскільки f(u, v) ≤ c(u, v)]
= c(S, T)                                                 [за визначенням c(S, T)]
```
Звідси безпосередньо випливає наслідок: якщо для деякого потоку `f*` та деякого розрізу `(S*, T*)` досягається рівність `|f*| = c(S*, T*)`, то `f*` є строго максимальним потоком у мережі, а `(S*, T*)` — мінімальним розрізом.

## Залишкова мережа та розширювальні шляхи

Нехай `f` — допустимий потік у мережі `G = (V, E)`. **Залишковою місткістю** `c_f(u, v)` для пари вершин `(u, v)` називається величина:
```
c_f(u, v) = c(u, v) - f(u, v) + f(v, u)
```
Якщо початковий граф не містить антипаралельних дуг (тобто якщо `(u, v) ∈ E`, то `(v, u) ∉ E`), залишкове правило спрощується до двох випадків:
1. **Для прямої дуги `(u, v) ∈ E`:** `c_f(u, v) = c(u, v) - f(u, v)` (невикористаний залишок місткості).
2. **Для зворотної дуги `(v, u)` (де `(u, v) ∈ E`):** `c_f(v, u) = f(u, v)` (можливість зменшити вже спрямований прямий потік).

**Залишковою мережею** називається граф `G_f = (V, E_f)`, де множина дуг складається з усіх пар з ненульовою залишковою спроможністю:
```
E_f = { (u, v) ∈ V × V | c_f(u, v) > 0 }
```

**Розширювальним шляхом** (Augmenting Path) `P` називається простий орієнтований шлях від джерела `s` до стоку `t` у залишковій мережі `G_f`.

**Залишковою місткістю шляху** (пляшковим горлом) називається:
```
c_f(P) = min_{(u, v) ∈ P} c_f(u, v) > 0
```

Якщо до потоку `f` додати аугментацію вздовж `P` на величину `Δ = c_f(P)`:
```
f'(u, v) = f(u, v) + Δ,  якщо (u, v) ∈ P (пряме ребро)
f'(u, v) = f(u, v) - Δ,  якщо (v, u) ∈ P (зворотне ребро)
f'(u, v) = f(u, v),      якщо ребро не належить P
```
То новий потік `f'` залишається допустимим, а його величина зростає: `|f'| = |f| + Δ > |f|`.

## Теорема Форда — Фалкерсона (Сильна дуальність)

### Теорема (Max-Flow Min-Cut)
Для будь-якої мережі `G = (V, E)` з пропускними спроможностями `c` та допустимим потоком `f` такі три твердження є строго еквівалентними:
1. Потік `f` є максимальним потоком у мережі `G`.
2. У залишковій мережі `G_f` не існує жодного розширювального шляху від `s` до `t`.
3. Існує розріз `(S, T)` такий, що `|f| = c(S, T)`.

**Доведення еквівалентності за колом (1 ⇒ 2 ⇒ 3 ⇒ 1):**

- **Крок (1 ⇒ 2):** Доводимо від супротивного. Припустимо, що `f` є максимальним потоком, проте в `G_f` існує розширювальний шлях `P` від `s` до `t` із місткістю `c_f(P) = Δ > 0`. Тоді операція аугментації вздовж `P` будує новий допустимий потік `f'` величиною `|f'| = |f| + Δ > |f|`. Це суперечить тому, що `f` був максимальним. Отже, розширювальних шляхів у `G_f` не існує.

- **Крок (2 ⇒ 3):** Припустимо, що в `G_f` немає шляху від `s` до `t`. Визначимо множину вершин `S` як множину всіх вершин `v ∈ V`, які є досяжними з джерела `s` у залишковій мережі `G_f`:
```
S = { v ∈ V | існує орієнтований шлях від s до v у G_f }
```
Покладемо `T = V \ S`.
Очевидно, що `s ∈ S` (шлях нульової довжини). Оскільки в `G_f` немає шляху від `s` до `t`, стік `t ∉ S`, отже `t ∈ T`. Таким чином, пара `(S, T)` утворює коректний розріз мережі.

Розглянемо довільну пару вершин `u ∈ S` та `v ∈ T`:
1. Ребро `(u, v)` не може мати позитивної залишкової місткості в `G_f`: якби `c_f(u, v) > 0`, дуга `(u, v)` належала б `E_f`, і вершина `v` була б досяжною з `s` через `u`, що суперечить умові `v ∈ T`. Отже, `c_f(u, v) = 0`.
   Звідси `c(u, v) - f(u, v) = 0`, тобто `f(u, v) = c(u, v)` (усі прямі дуги з `S` у `T` повністю насичені).
2. Зворотне ребро `(v, u)` також не може нести прямого потоку: якби `f(v, u) > 0`, у залишковій мережі існувала б зворотна дуга `(u, v)` із залишковою місткістю `c_f(u, v) = f(v, u) > 0`, і вершина `v` знову була б досяжною з `u ∈ S`. Отже, `f(v, u) = 0` (усі зворотні дуги з `T` у `S` мають нульовий потік).

Обчислимо чистий потік через розріз `(S, T)`:
```
|f|
= f(S, T)                                                 [за Лемою 1]
= ∑_{u ∈ S} ∑_{v ∈ T} f(u, v) - ∑_{u ∈ S} ∑_{v ∈ T} f(v, u)  [визначення чистого потоку]
= ∑_{u ∈ S} ∑_{v ∈ T} c(u, v) - ∑_{u ∈ S} ∑_{v ∈ T} 0     [оскільки f(u,v) = c(u,v) та f(v,u) = 0]
= c(S, T)                                                 [визначення c(S, T)]
```
Рівність `|f| = c(S, T)` доведено конструктивно.

- **Крок (3 ⇒ 1):** Нехай для деякого розрізу `(S, T)` виконується `|f| = c(S, T)`. За Лемою 2 (слабка дуальність), для будь-якого іншого допустимого потоку `f'` виконується нерівність `|f'| ≤ c(S, T) = |f|`. Отже, жоден потік не може мати величину, строго більшу за `|f|`, що доводить максимальність `f`.

Теорему повністю доведено.

## Доведення поліноміальної складності алгоритму Едмондса — Карпа

Алгоритм Едмондса — Карпа конкретизує пошук розширювального шляху: на кожному кроці за допомогою пошуку в ширину (BFS) обирається найкоротший шлях за кількістю ребер у `G_f`.

Позначимо через `δ_f(s, v)` найкоротшу відстань (кількість ребер) від джерела `s` до вершини `v` у залишковій мережі `G_f`.

### Лема 3 (Монотонність найкоротших відстаней)
У процесі послідовних аугментацій за алгоритмом Едмондса — Карпа для кожної вершини `v ∈ V` найкоротша відстань від джерела `δ_f(s, v)` не зменшується:
```
δ_{f'}(s, v) ≥ δ_f(s, v)  для всіх v ∈ V
```
де `f'` — потік після аугментації вздовж найкоротшого шляху `P`.

**Доведення:**
Доводимо від супротивного. Припустимо, що існує множина вершин, для яких відстань зменшилася. Нехай `v` — вершина з цієї множини з найменшим значенням нової відстані `δ_{f'}(s, v)`:
```
δ_{f'}(s, v) < δ_f(s, v)
```
Нехай `u → v` — останнє ребро на найкоротшому шляху від `s` до `v` у новій залишковій мережі `G_{f'}`. Тоді:
```
δ_{f'}(s, v) = δ_{f'}(s, u) + 1
```
Оскільки `δ_{f'}(s, u) < δ_{f'}(s, v)`, для вершини `u` зменшення відстані не відбулося:
```
δ_{f'}(s, u) ≥ δ_f(s, u)
```

Розглянемо стан ребра `(u, v)` до аугментації:
1. Якщо `(u, v) ∈ E_f` (ребро вже існувало в `G_f`), то:
```
δ_f(s, v) ≤ δ_f(s, u) + 1 ≤ δ_{f'}(s, u) + 1 = δ_{f'}(s, v)
```
Це прямо суперечить припущенню `δ_{f'}(s, v) < δ_f(s, v)`.

2. Якщо `(u, v) ∉ E_f` (ребро з'явилося в `G_{f'}` лише внаслідок аугментації), це означає, що потік був проштовхнутий по зворотному ребру `(v, u)` під час останньої аугментації.
   Але тоді ребро `(v, u)` лежало на найкоротшому шляху в `G_f`, отже:
```
δ_f(s, u) = δ_f(s, v) + 1
```
Обчислюємо нову відстань до `v`:
```
δ_{f'}(s, v)
= δ_{f'}(s, u) + 1        [за вибором ребра u→v у G_{f'}]
≥ δ_f(s, u) + 1          [оскільки δ_{f'}(s, u) ≥ δ_f(s, u)]
= (δ_f(s, v) + 1) + 1    [підстановка δ_f(s, u)]
= δ_f(s, v) + 2          [арифметика]
> δ_f(s, v)
```
Це знову суперечить припущенню `δ_{f'}(s, v) < δ_f(s, v)`.

Отже, припущення хибне, і відстань `δ(s, v)` монотонно не зменшується для всіх вершин `v`.

### Теорема про кількість аугментацій
Загальна кількість розширювальних шляхів, знайдених алгоритмом Едмондса — Карпа, не перевищує `O(V · E)`.

**Доведення:**
На кожному розширювальному шляху `P` хоча б одне ребро є критичним (пляшковим горлом), тобто `c_f(u, v) = c_f(P)`. Після аугментації це ребро насичується і зникає з залишкової мережі `G_f`.

Щоб ребро `(u, v)` знову з'явилося в залишковій мережі в деякій наступній ітерації, потік мусить бути проштовхнутий у зворотному напрямку вздовж `(v, u)`.
- У момент, коли `(u, v)` стало критичним уперше:
```
δ(s, v) = δ(s, u) + 1
```
- У момент, коли зворотне ребро `(v, u)` використовується для проштовхування:
```
δ'(s, u) = δ'(s, v) + 1
```
За Лемою 3 (монотонність відстаней), `δ'(s, v) ≥ δ(s, v)`. Звідси:
```
δ'(s, u)
= δ'(s, v) + 1            [оскільки ребро v→u лежить на найкоротшому шляху в G_{f'}]
≥ δ(s, v) + 1             [за Лемою 3 про монотонність відстаней: δ'(s, v) ≥ δ(s, v)]
= (δ(s, u) + 1) + 1       [оскільки в момент першого насичення δ(s, v) = δ(s, u) + 1]
= δ(s, u) + 2             [арифметичне спрощення]
```
Отже, між двома послідовними моментами, коли ребро `(u, v)` стає критичним, відстань від джерела до вершини `u` зростає щонайменше на 2 одиниці.

Оскільки довжина найпростішого шляху в графі з `|V|` вершинами не перевищує `|V| - 1`, максимальна відстань `δ(s, u) ≤ |V| - 2`. 

Звідси кожне з `|E|` спрямованих ребер може ставати критичним не більше ніж:
```
Критичних_разів ≤ (|V| - 2) / 2 + 1 = O(V)
```
Оскільки кожна аугментація насичує щонайменше одне критичне ребро, а всього в мережі є `2 |E|` можливих спрямованих дуг, загальна кількість розширювальних шляхів за весь час роботи алгоритму обмежена:
```
Загальна_кількість_шляхів ≤ 2 |E| · (|V| / 2) = O(V · E)
```

Оскільки пошук одного найкоротшого шляху за допомогою BFS виконується за час `O(E)`, сумарна часова складність алгоритму Едмондса — Карпа становить:
```
T_total = O(V · E) · O(E) = O(V · E²)
```
Це строгий поліноміальний результат, незалежний від числових значень місткостей.
