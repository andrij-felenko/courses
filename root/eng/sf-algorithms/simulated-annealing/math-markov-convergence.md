# 🧮 Математичні основи: ланцюги Маркова, детальний баланс та асимптотична збіжність

Математична строгість методу імітації відпалу ґрунтується на теорії однорідних та неоднорідних ланцюгів Маркова у скінченному дискретному просторі станів. Алгоритм розглядає оптимізаційну задачу як процес випадкового блукання по графу конфігурацій, у якому ймовірності переходів динамічно змінюються разом із параметром температури `T`.

Нехай задано скінченну множину можливих конфігурацій `S` (простір станів) потужністю `|S| < ∞` та функцію вартості `E: S → ℝ` (енергію), для якої необхідно знайти глобальний мінімум:

```
s* ∈ argmin_{s ∈ S} E(s)
E_min = min_{s ∈ S} E(s)
S* = {s ∈ S : E(s) = E_min}
```

де `S*` — підмножина глобально оптимальних конфігурацій, а `S \ S*` — множина субоптимальних станів.

## 1. Оператор переходу та стохастична матриця Метрополіса

Для кожного стану `s ∈ S` визначено його окіл `N(s) ⊆ S`. Граф станів `G = (S, E_G)` утворюється вершинами `S` та ребрами `(s, s')`, де `s' ∈ N(s)`.

Перехід від поточного стану `s` до наступного стану `s'` на фіксованому кроці складається з двох послідовних фаз:
1. **Генерація кандидата**: з околу `N(s)` обирається стан `s'` з імовірністю пропозиції `G(s, s')`. Зазвичай генератор обирається симетричним та рівномірним: `G(s, s') = 1 / |N(s)|`, причому `G(s, s') = G(s', s)` для будь-якої пари суміжних станів. Якщо `s' ∉ N(s)`, то `G(s, s') = 0`.
2. **Фільтрація за критерієм Метрополіса**: кандидат `s'` приймається з імовірністю `A_T(s, s')`, яка залежить від різниці енергій `ΔE = E(s') - E(s)` та поточної температури `T > 0`:

```
A_T(s, s') = min(1, exp(−(E(s') − E(s)) / T))
```

Повна ймовірність переходу `P_T(s, s')` для пари різних станів `s' ≠ s` є добутком імовірності генерації та ймовірності прийняття:

```
P_T(s, s') = G(s, s') · min(1, exp(−(E(s') − E(s)) / T))
```

Якщо згенерованого кандидата відхилено, система залишається в поточному стані `s`. Ймовірність самопетлі дорівнює залишковому балансу стохастичного рядка:

```
P_T(s, s) = 1 − ∑_{u ≠ s} P_T(s, u)
```

Матриця переходів `P_T = (P_T(s, s'))_{s, s' ∈ S}` є стохастичною: усі її елементи невід'ємні (`P_T(s, s') ≥ 0`), а сума елементів у кожному рядку строго дорівнює одиниці (`∑_{s' ∈ S} P_T(s, s') = 1`).

## 2. Умова детального балансу та стаціонарний розподіл Гіббса

Якщо зафіксувати температуру `T = const` і дозволити системі еволюціонувати нескінченно довго, ланцюг Маркова стає однорідним. Для існування та єдиності стаціонарного розподілу необхідне виконання двох фундаментальних властивостей графа конфігурацій:
1. **Незвідність (ергодичність)**: граф станів `G` є зв'язним, тобто з будь-якого стану `s` можна дістатися до будь-якого `s'` за скінченну кількість окільних переходів (`∃ k > 0: P_T^k(s, s') > 0`).
2. **Аперіодичність**: оскільки існує ненульова ймовірність відхилення мутації (`P_T(s, s) > 0`), найбільший спільний дільник довжин усіх можливих циклів повернення дорівнює 1.

За теоремою Перрона — Фробеніуса незвідний аперіодичний скінченний ланцюг Маркова володіє єдиним стаціонарним розподілом ймовірностей `π_T = (π_T(s))_{s ∈ S}`, який є лівим власним вектором матриці `P_T` для власного значення `λ_1 = 1`:

```
π_T · P_T = π_T
```

Достатньою умовою стаціонарності є виконання **умови детального балансу** (detailed balance) для кожної пари станів `s, s' ∈ S`:

```
π_T(s) · P_T(s, s') = π_T(s') · P_T(s', s)
```

Фізичний зміст детального балансу полягає в тому, що сумарний ймовірнісний потік зі стану `s` у стан `s'` точно дорівнює зворотному потоку зі стану `s'` у стан `s`, що виключає виникнення нерівноважних кругових циркуляцій імовірності.

Доведемо, що розподіл Гіббса — Больцмана задовольняє умову детального балансу при симетричному генераторі `G(s, s') = G(s', s)`. Розподіл Больцмана задається формулою:

```
π_T(s) = (1 / Z(T)) · exp(−E(s) / T)
Z(T) = ∑_{u ∈ S} exp(−E(u) / T)
```

де `Z(T)` — статистична сума (partition function), яка нормує суму ймовірностей усіх станів простору до одиниці.

Розглянемо два довільні суміжні стани `s` та `s'`. Нехай без обмеження загальності `E(s') ≥ E(s)` (перехід `s → s'` є погіршенням розв'язку, а зворотний перехід `s' → s` — покращенням):
- Для прямого переходу `s → s'`: різниця `E(s') − E(s) ≥ 0`, тому `A_T(s, s') = exp(-(E(s') - E(s)) / T)`.
- Для зворотного переходу `s' → s`: різниця `E(s) − E(s') ≤ 0`, тому `A_T(s', s) = min(1, exp(-(E(s) - E(s')) / T)) = 1`.

Обчислимо покроково обидві частини рівняння детального балансу:

```
Ліва частина:
π_T(s) · P_T(s, s')
= (1 / Z(T)) · exp(−E(s) / T) · G(s, s') · exp(−(E(s') − E(s)) / T)   [підстановка формул Больцмана та Метрополіса]
= (G(s, s') / Z(T)) · exp(−E(s) / T − (E(s') − E(s)) / T)            [додавання показників експоненти]
= (G(s, s') / Z(T)) · exp(−E(s') / T)                                [спрощення: −E(s) + E(s) = 0]

Права частина:
π_T(s') · P_T(s', s)
= (1 / Z(T)) · exp(−E(s') / T) · G(s', s) · 1                       [оскільки A_T(s', s) = 1 для ΔE ≤ 0]
= (G(s', s) / Z(T)) · exp(−E(s') / T)                                [множення на одиницю]
= (G(s, s') / Z(T)) · exp(−E(s') / T)                                [використання симетрії генератора G(s, s') = G(s', s)]
```

Обидва вирази тотожно рівні. Отже, розподіл Гіббса `π_T` є точним інваріантним розподілом для ланцюга Маркова при фіксованій температурі `T`.

## 3. Спектральний зазор та час релаксації (Mixing Time)

Швидкість збіжності ланцюга Маркова до стаціонарного розподілу `π_T` при фіксованій температурі визначається спектром власних значень стохастичної матриці `P_T`.

Оскільки матриця `P_T` задовольняє умову детального балансу, вона є самоспряженою у зваженому гільбертовому просторі `l²(π_T)`. Усі її власні значення є дійсними числами і можуть бути впорядковані за спаданням:

```
1 = λ_1(T) > λ_2(T) ≥ λ_3(T) ≥ ... ≥ λ_{|S|}(T) ≥ −1
```

Різниця між першим та другим власними значеннями називається **спектральним зазором** (spectral gap):

```
γ(T) = 1 − λ_2(T)
```

Спектральний зазор безпосередньо визначає геометричну швидкість збіжності ймовірнісного розподілу `p_k` на кроці `k` до стаціонарного розподілу `π_T` за повною варіаційною відстанню (total variation distance):

```
||p_k − π_T||_{TV} ≤ (1 / (2 · √(min_{s} π_T(s)))) · (1 − γ(T))^k
```

Характерний час, необхідний для вирівнювання розподілу (час релаксації або час змішування), оцінюється як:

```
τ_rel(T) = 1 / γ(T)
```

При високій температурі `T → ∞` спектральний зазор `γ(T)` є відносно великим, а час релаксації `τ_rel` малим: система швидко перемішується і досягає квазірівноваги. Проте при зниженні температури `T → 0` ймовірності подолання енергетичних бар'єрів експоненційно падають, друге власне значення `λ_2(T) → 1`, спектральний зазор `γ(T) → 0`, а час релаксації прямує до нескінченності (`τ_rel(T) → ∞`). Це явище у фізиці відоме як **критичне сповільнення** (critical slowing down).

## 4. Граничний перехід при T → 0⁺

Розглянемо, як трансформується стаціонарний розподіл `π_T(s)`, коли температура нескінченно повільно прямує до абсолютного нуля (`T → 0⁺`).

Розділимо чисельник та знаменник нормалізованої формули Больцмана на величину `exp(-E_min / T)`:

```
π_T(s)
= exp(−E(s) / T) / ∑_{u ∈ S} exp(−E(u) / T)                                            [означення π_T]
= exp(−(E(s) − E_min) / T) / ∑_{u ∈ S} exp(−(E(u) − E_min) / T)                        [ділення на exp(−E_min / T)]
= exp(−(E(s) − E_min) / T) / (|S*| + ∑_{u ∉ S*} exp(−(E(u) − E_min) / T))              [виділення множини оптимумів S*]
```

Для будь-якого неоптимального стану `u ∉ S*` за означенням різниця енергій строго додатна: `E(u) - E_min > 0`. Тому при `T → 0⁺` показник степеня прямує до мінус нескінченності:

```
lim_{T → 0⁺} exp(−(E(u) − E_min) / T) = exp(−∞) = 0
```

Звідси отримуємо точну границю ймовірності для двох класів станів:

```
Для оптимального стану s ∈ S* (де E(s) = E_min):
lim_{T → 0⁺} π_T(s)
= exp(0) / (|S*| + 0)                                                                  [граничний перехід у знаменнику]
= 1 / |S*|                                                                            [оскільки exp(0) = 1]

Для неоптимального стану s ∉ S* (де E(s) > E_min):
lim_{T → 0⁺} π_T(s)
= 0 / (|S*| + 0)                                                                      [чисельник прямує до нуля]
= 0                                                                                   [ділення нуля на скінченне число |S*|]
```

Таким чином, при прямуванні температури до абсолютного нуля вся сумарна ймовірнісна маса системи зосереджується строго на множині глобальних мінімумів `S*` з рівномірним розподілом `1 / |S*|`, а ймовірність перебування в будь-якому субоптимальному стані стає рівною нулю.

## 5. Неоднорідний ланцюг Маркова та теорема збіжності Гаєка

У реальному алгоритмі температура не є постійною величиною, а монотонно зменшується на кожному кроці: `T_k = f(k)`. Процес перетворюється на **неоднорідний у часі ланцюг Маркова** (time-inhomogeneous Markov chain) з матрицею переходів `P_{T_k}` на кроці `k`.

Якщо знижувати температуру занадто швидко (наприклад, геометрично `T_k = T_0 · α^k`), система замерзне в одному з локальних оптимумів, оскільки час перебування на кожному температурному рівні буде набагато меншим за час релаксації `τ_rel(T_k)`.

Фундаментальна теорема про необхідні та достатні умови асимптотичної збіжності була сформульована Брюсом Гаєком (Bruce Hajek, 1988) та незалежно доведена Стюартом і Дональдом Джеманами (1984):

> **Теорема (Гаєк, 1988).** Нехай простір станів `S` є скінченним і незвідним. Послідовність станів `s_k` неоднорідного ланцюга Маркова збігається за ймовірністю до множини глобальних мінімумів `S*`:
> ```
> lim_{k → ∞} P(s_k ∈ S*) = 1
> ```
> тоді і тільки тоді, коли послідовність температур `T_k` задовольняє умову:
> ```
> ∑_{k=1}^{∞} exp(−d / T_k) = ∞
> ```
> де `d` — глибина найглибшої локальної ями (cup depth) у графі простору станів `S`.

Глибина ями `d` визначається як максимальна висота енергетичного бар'єра, який необхідно подолати, щоб вийти з будь-якого локального мінімуму `s ∉ S*` і перейти в стан із суворо меншою енергією:

```
d = max_{s ∈ S \ S*} min_{path p: s → s_{lower}} (max_{u ∈ p} E(u) − E(s))
```

де `path p` — ланцюжок суміжних станів у графі переходів, що веде від `s` до деякого стану `s_{lower}`, для якого `E(s_{lower}) < E(s)`.

Умова розбіжності ряду `∑ exp(-d / T_k) = ∞` задовольняється тоді і тільки тоді, коли температура знижується не швидше логарифмічного закону:

```
T_k ≥ d / ln(1 + k)
```

Логарифмічний розклад гарантує, що система здійснює нескінченну кількість спроб виходу з кожної потенційної ями глибиною `d`, що робить застрягання в субоптимальних точках математично неможливим при `k → ∞`.
