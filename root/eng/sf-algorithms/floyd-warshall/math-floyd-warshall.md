# 🧮 Математичні інваріанти, коректність та алгебра напівкілець Флойда–Уоршелла

Строге математичне обґрунтування алгоритму Флойда–Уоршелла спирається на індуктивне доведення принципу оптимальності Беллмана над простором обмежених підмножин вершин, інваріант незмінності координат при двовимірній редукції пам'яті, теорему про ациклічність відновлення маршрутів та алгебраїчний ізоморфізм замкнених тропічних напівкілець.

---

### Формальна постановка та простір підзадач

Нехай задано зважений орієнтований граф `G = (V, E)`, де множина вершин упорядкована натуральними індексами `V = {1, 2, ..., n}`, а функція ваг ребер `w: V × V → ℝ ∪ {+∞}` визначає початкову вагову структуру:

```
w(i, j) = 0,             якщо i = j
w(i, j) = вага ребра,    якщо (i, j) ∈ E
w(i, j) = +∞,            якщо (i, j) ∉ E та i ≠ j
```

Шляхом `p` від вершини `v_1` до вершини `v_m` називається скінченна послідовність вершин `(v_1, v_2, ..., v_m)`, де кожна пара суміжних вузлів `(v_r, v_{r+1}) ∈ E`. Вагою шляху `w(p)` є сума ваг усіх ребер, що входять до нього:

```
w(p) = w(v_1, v_2) + w(v_2, v_3) + ... + w(v_{m-1}, v_m)
```

Для будь-якого шляху `p = (v_1, v_2, ..., v_m)` визначимо множину його **внутрішніх (проміжних) вершин** як:

```
int(p) = {v_2, v_3, ..., v_{m-1}}
```

Якщо шлях складається з одного прямого ребра `(v_1, v_2)`, множина його внутрішніх вершин є порожньою: `int(p) = ∅`. Для шляху нульової довжини `(v_1)` також `int(p) = ∅`.

Сформулюємо сімейство підзадач динамічного програмування:

**Означення.** Нехай `d^(k)[i, j]` — найменша вага серед усіх можливих шляхів від вершини `i` до вершини `j`, усі проміжні вершини яких належать початковому префіксу множини вершин `{1, 2, ..., k}`:

```
d^(k)[i, j] = min { w(p) | p: i ↝ j, int(p) ⊆ {1, 2, ..., k} }
```

Якщо між вершинами `i` та `j` не існує жодного шляху з проміжними вузлами з `{1, 2, ..., k}`, значення `d^(k)[i, j]` приймається рівним `+∞`.

### Індуктивне доведення коректності (Теорема Флойда)

**Теорема.** Якщо граф `G` не містить замкнених контурів із від'ємною сумарною вагою, то для всіх `k ∈ {1, 2, ..., n}` та будь-якої пари вершин `(i, j) ∈ V × V` виконується рекурентне співвідношення:

```
d^(k)[i, j] = min( d^(k-1)[i, j],  d^(k-1)[i, k] + d^(k-1)[k, j] )
```

**Доведення (за методом математичної індукції по параметру k):**

1. **База індукції (`k = 0`):**
   Множина дозволених проміжних вершин є порожньою: `{1, ..., 0} = ∅`. Шлях від `i` до `j` без жодної внутрішньої вершини може складатись щонайбільше з одного ребра `(i, j)` (або бути тривіальним шляхом із нульовою вагою при `i = j`).
   
   За означенням вагової матриці:
   ```
   d^(0)[i, j] = w(i, j)
   ```
   База індукції виконується строго.

2. **Індукційне припущення:**
   Припустимо, що для деякого значення `k - 1` (де `k ≥ 1`) матриця `d^(k-1)[u, v]` містить точні ваги найкоротших шляхів для всіх пар `(u, v) ∈ V × V` з внутрішніми вершинами з множини `{1, 2, ..., k-1}`.

3. **Індукційний перехід (`k - 1 → k`):**
   Розглянемо довільну пару вершин `(i, j)` та найкоротший простий шлях `p` між ними, проміжні вершини якого належать множині `{1, 2, ..., k}`. Стосовно вершини `k` можливі рівно два взаємовиключні випадки:
   
   - **Випадок 1: Вершина `k` не належить множині проміжних вершин шляху `p` (`k ∉ int(p)`).**
     Тоді всі внутрішні вузли шляху `p` насправді належать звуженій підмножині `{1, 2, ..., k-1}`. За індукційним припущенням вага найкоротшого такого шляху строго дорівнює `d^(k-1)[i, j]`.
     
   - **Випадок 2: Вершина `k` є проміжною вершиною шляху `p` (`k ∈ int(p)`).**
     Оскільки граф не містить від'ємних циклів, найкоротший шлях `p` є простим (не містить вершин, що повторюються). Отже, шлях `p` проходить крізь вершину `k` рівно один раз.
     
     Розщепимо шлях `p` у точці `k` на дві складові частини:
     ```
     p₁: i ↝ k   та   p₂: k ↝ j
     ```
     
     Оскільки вершина `k` є кінцем шляху `p₁` та початком шляху `p₂`, вона не належить до внутрішніх вершин жодного з цих підшляхів:
     ```
     int(p₁) ⊆ {1, 2, ..., k-1}   та   int(p₂) ⊆ {1, 2, ..., k-1}
     ```
     
     За принципом оптимальності Беллмана будь-яка частина найкоротшого шляху сама є найкоротшим шляхом між відповідними кінцевими вершинами. Отже, `p₁` є найкоротшим шляхом від `i` до `k` з проміжними вузлами в `{1, ..., k-1}`, а `p₂` — найкоротшим шляхом від `k` до `j` з тими самими обмеженнями.
     
     Їхні ваги відповідно дорівнюють `d^(k-1)[i, k]` та `d^(k-1)[k, j]`. Вага всього шляху `p` дорівнює сумі:
     ```
     w(p) = w(p₁) + w(p₂) = d^(k-1)[i, k] + d^(k-1)[k, j]
     ```

4. **Об'єднання та висновок індукції:**
   Оскільки оптимальний шлях обов'язково належить або до першого, або до другого випадку, найменша можлива вага обирається операцією мінімуму:
   
   ```
   d^(k)[i, j]
   = min( d^(k-1)[i, j],  d^(k-1)[i, k] + d^(k-1)[k, j] )    [вибір між обходом без k та транзитом через k]
   ```
   
   Пройшовши `n` послідовних кроків індукції, множина дозволених проміжних вершин розширюється до повної множини вершин графа `{1, 2, ..., n}`. Відповідно, величина `d^(n)[i, j]` дорівнює істинній найкоротшій відстані `δ(i, j)` між будь-якими вершинами `i` та `j`. Теорему доведено.

### Доведення коректності обчислення «на місці» (In-place Invariance)

При зменшенні розмірності пам'яті до однієї двовимірної таблиці `D[i][j]` необхідно гарантувати, що зміна значень матриці на `k`-му кроці не призведе до читання частково оновлених значень, які б спотворили подальші обчислення в цьому ж раунді.

**Лема про стабільність активного рядка і стовпця.**
Для будь-якого `k ∈ {1, ..., n}` та довільних `i, j ∈ V` виконуються тотожності:

```
d^(k)[i, k] = d^(k-1)[i, k]
d^(k)[k, j] = d^(k-1)[k, j]
```

**Доведення:**
Застосуємо рекурентну формулу для фінішної вершини `j = k`:

```
d^(k)[i, k]
= min( d^(k-1)[i, k],  d^(k-1)[i, k] + d^(k-1)[k, k] )    [підстановка j = k у формулу переходу]
```

Оскільки граф за припущенням не містить від'ємних циклів, найкоротший шлях від вершини `k` до самої себе має вагу `d^(k-1)[k, k] = 0` (тривіальний шлях без ребер).

Виконуючи арифметичні спрощення:

```
d^(k-1)[i, k] + d^(k-1)[k, k]
= d^(k-1)[i, k] + 0                                        [підстановка нульової петлі d[k, k] = 0]
= d^(k-1)[i, k]                                            [властивість нейтрального елемента додавання]
```

Підставляючи це значення назад у мінімум:

```
d^(k)[i, k]
= min( d^(k-1)[i, k],  d^(k-1)[i, k] )                     [мінімум рівних величин]
= d^(k-1)[i, k]
```

Аналогічно перевіримо для початкової вершини `i = k`:

```
d^(k)[k, j]
= min( d^(k-1)[k, j],  d^(k-1)[k, k] + d^(k-1)[k, j] )    [підстановка i = k]
= min( d^(k-1)[k, j],  0 + d^(k-1)[k, j] )                 [підстановка d[k, k] = 0]
= d^(k-1)[k, j]
```

**Наслідок:** Значення у рядку `k` та стовпці `k` не змінюються протягом усього `k`-го кроку. Отже, у формулі `D[i][j] := min(D[i][j], D[i][k] + D[k][j])` операнди `D[i][k]` та `D[k][j]` завжди зберігають значення попереднього раунду `k-1` незалежно від того, в якому порядку виконуються цикли по `i` та `j`.

### Теорема про коректність відновлення маршрутів

Нехай матриця переходів `next[i][j]` ініціалізується як `next[i][j] = j` при `(i, j) ∈ E` та `next[i][j] = NIL` за відсутності ребра. При оновленні `d[i][j] := d[i][k] + d[k][j]` виконується присвоєння:

```
next[i][j] := next[i][k]
```

**Теорема.** Якщо граф не містить від'ємних циклів, то для будь-якої пари досяжних вершин `(u, v)` послідовність переходів `v_0 = u, v_1 = next[v_0][v], v_2 = next[v_1][v], ...` є скінченною, не містить повторень вершин і утворює найкоротший шлях від `u` до `v`.

**Доведення:**
Доведемо ациклічність від зворотного. Припустимо, що під час трасування виник цикл: `v_a = v_b` для деяких `a < b`. Це означає, що частина шляху від `v_a` до `v_a` має сумарну вагу `W_cycle`. 

Оскільки всі присвоєння `next` відповідають найкоротшим підшляхам, ділянка від `v_a` до `v_b` є сумою найкоротших кроків. Якби `W_cycle > 0`, алгоритм ніколи не обрав би цей цикл як покращення шляху, бо вилучення циклу зменшило б вагу. Якби `W_cycle = 0`, правило строгої нерівності (`new_dist < old_dist`) запобігає заміні прямого шляху на довший шлях із нульовим циклом при коректній ініціалізації. Оскільки від'ємних циклів у графі немає за умовою, `W_cycle < 0` неможливе. Отже, припущення хибне, послідовність вершин є строго простою та досягає `v` за не більше ніж `n - 1` кроків.

### Алгебраїчна теорія замкнених напівкілець

Алгоритм Флойда–Уоршелла є конкретною інстанціацією методу Жордана–Гаусса над алгебраїчною структурою, відомою як **замкнене напівкільце** (Closed Semiring або Kleene Algebra).

Формально напівкільце `(S, ⊕, ⊗, 0̄, 1̄)` задовольняє такі аксіоми:
1. `(S, ⊕, 0̄)` — комутативний моноїд з нейтральним елементом `0̄` та ідемпотентністю: `a ⊕ a = a`.
2. `(S, ⊗, 1̄)` — моноїд з нейтральним елементом `1̄`.
3. Множення дистрибутивне відносно додавання:
   ```
   a ⊗ (b ⊕ c) = (a ⊗ b) ⊕ (a ⊗ c)
   (a ⊕ b) ⊗ c = (a ⊗ c) ⊕ (b ⊗ c)
   ```
4. Елемент `0̄` є поглинаючим для множення: `a ⊗ 0̄ = 0̄ ⊗ a = 0̄`.
5. Визначено операцію замикання (зірочку Кліні) `a* = 1̄ ⊕ a ⊕ a² ⊕ ...`. Для ідемпотентних напівкілець без від'ємних контурів `a* = 1̄ ⊕ a`.

Різні фундаментальні задачі на графах виникають простою зміною сигнатури напівкільця:

| Задача на графах | Носій `S` | Операція `⊕` (вибір) | Операція `⊗` (композиція) | `0̄` | `1̄` |
|---|---|---|---|---|---|
| **Найкоротші шляхи (Флойд)** | `ℝ ∪ {+∞}` | `min(a, b)` | `a + b` | `+∞` | `0` |
| **Транзитивне замикання (Уоршелл)** | `{0, 1}` | `a ∨ b` (OR) | `a ∧ b` (AND) | `0` | `1` |
| **Найширший шлях (Bottleneck Capacity)** | `ℝ⁺ ∪ {+∞}` | `max(a, b)` | `min(a, b)` | `0` | `+∞` |
| **Найбільш надійний шлях (Reliability)** | `[0, 1]` | `max(a, b)` | `a · b` | `0` | `1` |
| **Кількість шляхів фіксованої довжини** | `ℕ₀` | `a + b` | `a · b` | `0` | `1` |

Універсальний матричний крок алгоритму над довільним напівкільцем записується єдиною матричною формулою:

```
D^(k)[i, j] = D^(k-1)[i, j] ⊕ ( D^(k-1)[i, k] ⊗ (D^(k-1)[k, k])* ⊗ D^(k-1)[k, j] )
```

Оскільки для тропічного напівкільця `(D^(k-1)[k, k])* = min(0, d[k][k]) = 0`, ця абстрактна алгебраїчна формула перетворюється на знайомий вираз Флойда: `d[i][j] = min(d[i][j], d[i][k] + d[k][j])`.
