# 🧮 Математичні основи DPLL та CDCL: резолюція, граф імплікацій та некоректність хронологічного вертання

Формальний аналіз алгоритмів DPLL (Davis-Putnam-Logemann-Loveland) та CDCL (Conflict-Driven Clause Learning) базується на теорії доведень булевої логіки, алгебрі резолюцій, складності резолюційних виводів та властивостях спрямованих ациклічних графів імплікацій.

## 1. Математичне правило резолюції та збереження здійсненності

Фундаментальною логічною операцією, яка лежить в основі як спрощення формул у DPLL, так і виведення нових дизюнктів у CDCL, є **правило бінарної резолюції** (Propositional Resolution Rule).

Нехай `C₁` та `C₂` — два диз'юнкти в кон'юнктивній нормальній формі (КНФ), які містять протилежні літерали для змінної `x`:

```
C₁ = A ∨ x
C₂ = B ∨ ¬x
```

Тут `A` та `B` є довільними диз'юнкціями літералів. Правило резолюції виводить новий диз'юнкт `R`, який називається **резольвентою** диз'юнктів `C₁` та `C₂` за змінною `x`:

```
Res_x(C₁, C₂) = A ∨ B
```

### Теорема про коректність резолюції (Soundness of Resolution)
Якщо інтерпретація `I` задовольняє обидва диз'юнкти `C₁` та `C₂` (`I ⊨ C₁` та `I ⊨ C₂`), то вона обов'язково задовольняє їхню резольвенту `Res_x(C₁, C₂)` (`I ⊨ A ∨ B`).

**Доведення:**
Розглянемо значення змінної `x` у довільній модельній інтерпретації `I`:
1. Якщо `I(x) = 0` (змінна хибна), то літерал `x = 0`. Оскільки `I ⊨ (A ∨ x)`, умова `A` мусить бути істинною (`I ⊨ A = 1`). Звідси `I ⊨ A ∨ B = 1`.
2. Якщо `I(x) = 1` (змінна істинна), то заперечення `¬x = 0`. Оскільки `I ⊨ (B ∨ ¬x)`, умова `B` мусить бути істинною (`I ⊨ B = 1`). Звідси `I ⊨ A ∨ B = 1`.

В обох випадках `I ⊨ A ∨ B`. Отже, долучення резольвенти до КНФ-формули не змінює множину її розв'язків:

```
F ∧ (A ∨ B) ≡ F        [для будь-якої інтерпретації I, що задовольняє F]
```

### Древовидні та граф-резолюційні доведення

Множина диз'юнктів, що отримуються виведенням резолюції, може бути подана у вигляді спрямованого ациклічного графа виводу (Resolution DAG).
- Якщо кожен виведений диз'юнкт використовується як посилка для резолюції **не більше одного разу**, граф виводу перетворюється на дерево (Tree Resolution Proof).
- Якщо виведений диз'юнкт може повторно використовуватися як посилка у багатьох інших резолюціях, вивід утворює загальний граф (General DAG Resolution Proof).

Ця відмінність визначає фундаментальний розрив у обчислювальній складності між DPLL та CDCL.

## 2. Алгебраїчна модель графа імплікацій та 1UIP

Під час виконання BCP (Boolean Constraint Propagation) CDCL-солвер будує спрямований ациклічний граф `G = (V, E)`, який називається **Графом імплікацій** (Implication Graph).

### Означення графа імплікацій
- **Вершини `V`:** кожна вершина `v ∈ V` відповідає призначенню літерала `l` на рівні прийняття рішення `d`, що позначається як `l = 1 @ d`. Додатково існує спеціальна конфліктна вершина `⊥` (порожній диз'юнкт).
- **Спрямовані ребра `E`:** ребро `(u, v) ∈ E` існує тоді і тільки тоді, коли призначення літерала `u` було безпосередньою причиною вхідного поширення літерала `v` згідно з деяким диз'юнктом `C = (¬u₁ ∨ ¬u₂ ∨ ... ∨ ¬u_k ∨ v)`.

```
 u₁ @ d₁ ──┐
 u₂ @ d₂ ──┼──> v @ d_curr    [за диз'юнктом C = ¬u₁ ∨ ¬u₂ ∨ ... ∨ ¬u_k ∨ v]
 u_k @ d_k ┘
```

### Домінантно-зрізова теорія 1UIP (First Unique Implication Point)

Нехай `d_curr` — поточний рівень прийняття рішення, на якому виник конфлікт `⊥`, а `x_dec` — літерал рішення, обраний на рівні `d_curr`.

**Означення (UIP — Unique Implication Point):**
Вершина `u ∈ V` називається єдиною точкою імплікації (UIP), якщо вона належить поточному рівню прийняття рішення (`level(u) = d_curr`), і будь-який спрямований шлях у графі `G` від вершини рішення `x_dec` до конфліктної вершини `⊥` проходить через вершину `u`.

Оскільки сама вершина рішення `x_dec` лежить на всіх шляхах до `⊥`, вона завжди є тривіальним UIP.

**Означення (1UIP — First Unique Implication Point):**
Першою єдиною точкою імплікації (1UIP) називається UIP, яка знаходиться найближче до конфліктної вершини `⊥` за топологічною відстані у графі імплікацій.

```
x_dec @ d_curr ──> ... ──> 2UIP ──> ... ──> 1UIP ──> [Зріз конфлікту] ──> ⊥
```

### Формування вивченого диз'юнкта через резолюційний ланцюжок

Конфліктний диз'юнкт обчислюється шляхом послідовної резолюції заперечень літералів, що виникли в результаті BCP на поточному рівні, починаючи від диз'юнкта конфлікту `C_conf`:

```
Крок 0:  R₀ = C_conf
Крок i:  R_i = Res_y(R_{i-1}, C_y)      [де y — літерал BCP, вибраний у зворотному порядку поширення]
```

Ітерація зупиняється на кроці `k`, коли диз'юнкт `R_k` містить **рівно один літерал**, який призначений на поточному рівні `d_curr`. Цей літерал відповідає 1UIP:

```
C_learn = R_k = (¬1UIP ∨ ¬l₁ ∨ ¬l₂ ∨ ... ∨ ¬l_m)
```

де `l₁, l₂, ..., l_m` — літерали з попередніх рівнів прийняття рішень (`level(l_j) < d_curr`).

## 3. Властивість ствердження та рівень нехронологічного вертання

Диз'юнкт `C_learn` називається **одиничним на рівні ствердження (Asserting Clause)**.

**Означення (Рівень ствердження - Assertion Level):**
```
d_assert = max(level(l₁), level(l₂), ..., level(l_m))
```

Якщо диз'юнкт не містить жодного літерала з попередніх рівнів (`m = 0`), то `d_assert = 0`.

### Теорема про вимушену одиничність (Asserting Property Theorem)
Після нехронологічного вертання солвера на рівень `d_assert` вивчений диз'юнкт `C_learn` стає одиничним диз'юнктом на рівні `d_assert`.

**Доведення:**
1. На рівні `d_assert` усі літерали `l₁, l₂, ..., l_m` вже прийняли свої значення під час попередніх кроків пошуку, оскільки їхні рівні прийняття рішень не перевищують `d_assert` (`level(l_j) ≤ d_assert`).
2. Оскільки диз'юнкт `C_learn` виведено з конфлікту, заперечення цих літералів `¬l_j` всі оцінені як хибні (`¬l_j = 0`).
3. Єдиним невизначеним літералом у `C_learn` залишається літерал `¬1UIP`.
4. Отже, за правилом BCP на рівні `d_assert` диз'юнкт `C_learn` вимушує призначення `¬1UIP = 1` (тобто `1UIP = 0`) без здійснення нового вибору рішення.

## 4. Математичне доведення повноти та завершуваності CDCL

Завершуваність алгоритму CDCL доводиться методом строгої індукції за розміром простору пошуку та монотонним зменшенням кількості доступних часткових призначень.

### Теорема про завершуваність (Termination Theorem)
Алгоритм CDCL зупиняється за скінченне число кроків для будь-якої початкової КНФ-формули з `N` змінними.

**Доведення:**
1. Кількість можливих вивчених диз'юнктів над `N` змінними є скінченною і не перевищує `3ⁿ` (кожна змінна може входити як стверджувальний літерал, заперечення або бути відсутньою).
2. Кожен вивчений диз'юнкт `C_learn` є підтвердженим логічним наслідком початкової формули `F`.
3. Завдяки наявності 1UIP, диз'юнкт `C_learn` стає одиничним одразу після нехронологічного вертання на рівень `d_assert`.
4. Це гарантує, що поточна комбінація призначень літералів більше ніколи не повториться у дереві пошуку, оскільки BCP негайно виключить цю гілку.
5. Отже, CDCL не може потрапити в нескінченний цикл. Оскільки кількість унікальних вивчених диз'юнктів обмежена `3ⁿ`, алгоритм зупиниться або знайшовши розв'язок (SAT), або згенерувавши порожній диз'юнкт `⊥` на рівні 0 (UNSAT).

## 5. Експоненційна нижня межа DPLL: Принцип дірок (Pigeonhole Principle)

Фундаментальною відмінністю між DPLL та CDCL є складність резолюційних доведень, які вони здатні генерувати для нездійсненних (UNSAT) формул.

### Формулювання принципу дірок `PHP_n`
Формула `PHP_n` стверджує можливість розміщення `n + 1` голуба у `n` лунках так, щоб у кожній лунці знаходилося не більше одного голуба. За принципом Діріхле ця формула є нездійсненною при будь-якому `n ≥ 1`.

КНФ-формулювання `PHP_n` використовує змінні `x[i, j]`, де `i ∈ {1, ..., n+1}` (голуби), а `j ∈ {1, ..., n}` (лунки):

```
1. Кожен голуб i повинен перебувати принаймні в одній лунці:
   (x[i, 1] ∨ x[i, 2] ∨ ... ∨ x[i, n])                      для кожного i ∈ {1, ..., n+1}

2. Жодна лунка j не може містити двох різних голубів i₁ ≠ i₂:
   (¬x[i₁, j] ∨ ¬x[i₂, j])                                 для всіх i₁ < i₂ та j ∈ {1, ..., n}
```

### Теорема Хакена (Haken's Exponential Lower Bound, 1985)
Будь-яке древовидне резолюційне доведення (Tree Resolution Proof) нездійсненності формули `PHP_n` має розмір не менше ніж `2^(Ω(n))`.

Оскільки алгоритм DPLL без вивчення диз'юнктів строго еквівалентний побудові древовидного резолюційного доведення, час виконання DPLL на формулах `PHP_n` обов'язково зростає як експонента:

```
Time_DPLL(PHP_n) = Ω(2^(n/20))          [експоненційний вибух часу виконання DPLL]
```

Натомість CDCL здатний будувати загальні граф-резолюційні доведення (General DAG Resolution Proofs). Шляхом запам'ятовування та повторного використання вивчених дизюнктів CDCL виводить поліноміальне за розміром доведення для `PHP_n`, розв'язуючи задачу за час `O(n³)`.
