# 🧮 Математичне обґрунтування меж похибки Count-Min Sketch

Математична надійність структури Count-Min Sketch спирається на строгий імовірнісний апарат теорії потокових обчислень. Цей розділ містить повне аналітичне виведення меж похибки для точкових запитів частот, обґрунтування вибору розмірностей матриці лічильників, доведення властивостей 2-універсального хешування, математичний аналіз консервативного оновлення та оцінку скалярного добутку векторів.

## Потокова модель даних та визначення простору

У теорії потокових алгоритмів розглядають послідовність подій, що надходять у реальному часі. Нехай `U = {1, 2, ..., n}` — універсум можливих ідентифікаторів елементів (наприклад, простір усіх можливих IPv4-адрес, де `n = 2³²`).

Потік даних є послідовністю транзакцій:

```
Stream = ( (i₁, c₁), (i₂, c₂), ..., (i_T, c_T) )
```

де кожен `i_t ∈ U` позначає ідентифікатор ключа, а `c_t` — величину зміни частоти на кроці часу `t`.

У класичній моделі лічильників (модель Cash Register) усі величини оновлення є строго додатними цілими числами: `c_t > 0`. Це відповідає типовим задачам мережевого обліку, де пакети лише надходять, або підрахунку пошукових запитів, які накопичуються в системі.

Після надходження `T` подій стан потоку повністю описується невідомим вектором частот `a = (a₁, a₂, ..., aₙ)`, де координата `aᵢ` визначає точну сумарну частоту появи елемента `i`:

```
aᵢ = ∑_{t: i_t = i} c_t
```

Загальний обсяг потоку даних визначається як норма `L₁` вектора `a`, тобто сума всіх накопичених частот:

```
||a||₁ = ∑_{i=1}^{n} |aᵢ| = a₁ + a₂ + ... + aₙ = N
```

Структура даних Count-Min Sketch моделює цей гігантський `n`-вимірний вектор `a` за допомогою компактної двовимірної таблиці лічильників `C` розмірністю `d × w`, де `d` — кількість рядків (глибина ескізу), а `w` — кількість стовпців (ширина ескізу).

```
C[j, k], де 0 ≤ j < d,  0 ≤ k < w
```

## Властивості 2-універсального сімейства хеш-функцій

Для кожного рядка `j` (`0 ≤ j < d`) обирається випадкова хеш-функція `hⱼ` із сімейства 2-універсальних (попарно незалежних) функцій `H`:

```
hⱼ: {1, 2, ..., n} → {0, 1, ..., w - 1}
```

Сімейство хеш-функцій `H` називається 2-універсальним за визначенням Картера і Вегмана, якщо для будь-якої пари різних ключів `x ≠ y` ймовірність того, що вони відобразяться в один і той самий стовпець, не перевищує рівномірної ймовірності `1 / w`:

```
Pr_{h ∈ H}[h(x) = h(y)] ≤ 1 / w
```

Це критично важлива властивість. Вона гарантує, що для довільно обраного фіксованого елемента `x` будь-який інший елемент потоку `y` потрапляє в ту саму комірку з імовірністю не більше ніж `1 / w`, навіть якщо сам вхідний потік даних сформовано зловмисником або він має складний нерівномірний розподіл.

## Аналіз одного рядка: математичне сподівання шуму колізій

Зафіксуємо довільний елемент `x ∈ U`, для якого ми хочемо оцінити частоту `aₓ`.

Розглянемо значення лічильника в рядку `j` у стовпці `hⱼ(x)`. Кожен елемент потоку `i`, який має спільне значення хешу з `x` (тобто `hⱼ(i) = hⱼ(x)`), додає свою повну частоту `aᵢ` до цієї комірки:

```
C[j, hⱼ(x)] = aₓ + ∑_{i ≠ x} aᵢ · I_{i, j, x}
```

де `I_{i, j, x}` — індикаторна випадкова величина колізії елемента `i` з елементом `x` у рядку `j`:

```
I_{i, j, x} = 1, якщо hⱼ(i) = hⱼ(x)
I_{i, j, x} = 0, якщо hⱼ(i) ≠ hⱼ(x)
```

Позначимо сумарну похибку (адитивний шум колізій) у рядку `j` як невід'ємну випадкову величину `Xⱼ`:

```
Xⱼ = ∑_{i ≠ x} aᵢ · I_{i, j, x}
```

Оскільки всі частоти `aᵢ` є невід'ємними (`aᵢ ≥ 0`), а індикатори `I_{i, j, x} ≥ 0`, величина шуму завжди більша або дорівнює нулю: `Xⱼ ≥ 0`.

Звідси випливає фундаментальний детермінований інваріант: **значення кожного окремого лічильника ніколи не буває меншим за істинну частоту елемента**:

```
C[j, hⱼ(x)] = aₓ + Xⱼ ≥ aₓ  для будь-якого рядка j ∈ {0, ..., d - 1}
```

Обчислимо математичне сподівання шуму колізій `E[Xⱼ]`. Завдяки фундаментальній властивості лінійності математичного сподівання, сподівання суми дорівнює сумі сподівань доданків незалежно від наявності статистичної залежності між ними:

```
E[Xⱼ]
= E[∑_{i ≠ x} aᵢ · I_{i, j, x}]               [за визначенням випадкової величини Xⱼ]
= ∑_{i ≠ x} aᵢ · E[I_{i, j, x}]               [лінійність математичного сподівання]
= ∑_{i ≠ x} aᵢ · Pr[hⱼ(i) = hⱼ(x)]            [сподівання індикатора дорівнює ймовірності події]
≤ ∑_{i ≠ x} aᵢ · (1 / w)                      [застосування властивості 2-універсального хешування]
= (1 / w) · ∑_{i ≠ x} aᵢ                      [винесення константи (1/w) за знак суми]
≤ (1 / w) · ||a||₁                            [бо сума без одного елемента не перевищує повної норми ||a||₁]
```

Отже, середній шум колізій у будь-якому рядку матриці суворо обмежений величиною `||a||₁ / w`.

## Застосування нерівності Маркова для окремого рядка

Нерівність Маркова є базовим інструментом теорії ймовірностей для оцінки «хвостів» розподілів. Вона стверджує, що для будь-якої невід'ємної випадкової величини `Y ≥ 0` та будь-якого додатного порогу `λ > 0` ймовірність того, що величина перевищить `λ`, обмежується відношенням її середнього значення до `λ`:

```
Pr[Y ≥ λ] ≤ E[Y] / λ
```

Застосуємо нерівність Маркова до випадкової величини шуму `Y = Xⱼ`, обравши як поріг допустиму величину абсолютної похибки `λ = ε · ||a||₁`, де `ε > 0` — заданий користувачем коефіцієнт відносної точності:

```
Pr[Xⱼ ≥ ε · ||a||₁]
≤ E[Xⱼ] / (ε · ||a||₁)                        [застосування нерівності Маркова]
≤ (||a||₁ / w) / (ε · ||a||₁)                 [підстановка верхньої межі E[Xⱼ] ≤ ||a||₁ / w]
= 1 / (ε · w)                                 [скорочення норми ||a||₁]
```

Щоб обмежити ймовірність великої похибки в одному рядку константою `1 / e` (де `e ≈ 2.71828` — основа натуральних логарифмів), достатньо встановити ширину таблиці `w` рівною:

```
w = ⌈e / ε⌉
```

Підставивши обране значення `w` у формулу ймовірності, отримуємо:

```
Pr[Xⱼ ≥ ε · ||a||₁] ≤ 1 / (ε · (e / ε)) = 1 / e ≈ 0.3679
```

Це означає, що в кожному окремому рядку ймовірність перевищення допустимого шуму `ε · ||a||₁` не перевищує приблизно 36.8%.

## Об'єднання рядків та експоненційне придушення похибки

Оцінка частоти елемента `x` у Count-Min Sketch обчислюється як мінімум значень по всіх `d` рядках таблиці:

```
âₓ = min_{0 ≤ j < d} C[j, hⱼ(x)] = aₓ + min_{0 ≤ j < d} Xⱼ
```

Помилка підсумкової оцінки `âₓ - aₓ` перевищить поріг `ε · ||a||₁` тоді й лише тоді, коли похибка перевищить цей поріг **у кожному без винятку рядку матриці**:

```
Pr[âₓ - aₓ ≥ ε · ||a||₁] = Pr[∀ j ∈ {0, ..., d - 1}: Xⱼ ≥ ε · ||a||₁]
```

Оскільки всі `d` хеш-функцій `h₀, h₁, ..., h_{d-1}` обираються взаємно незалежно, події перевищення похибки в різних рядках є статистично незалежними. За теоремою множення ймовірностей незалежних подій:

```
Pr[∀ j ∈ {0, ..., d - 1}: Xⱼ ≥ ε · ||a||₁]
= ∏_{j=0}^{d-1} Pr[Xⱼ ≥ ε · ||a||₁]           [незалежність хеш-функцій між рядками]
≤ ∏_{j=0}^{d-1} (1 / e)                       [оцінка похибки для одного рядка ≤ 1/e]
= (1 / e)ᵈ                                    [добуток d однакових ймовірностей]
= e⁻ᵈ                                         [експоненційне спадання похибки від глибини d]
```

Ми вимагаємо, щоб підсумкова ймовірність невдачі не перевищувала заданого користувачем порогу ризику `δ` (наприклад, `δ = 0.01` для 99% надійності):

```
e⁻ᵈ ≤ δ
```

Логарифмуючи обидві частини нерівності за натуральною основою:

```
-d ≤ ln(δ)
d ≥ ln(1 / δ)
```

Округлюючи до найближчого більшого цілого числа, отримуємо необхідну глибину матриці:

```
d = ⌈ln(1 / δ)⌉
```

## Підсумкова теорема точності

Для довільних наперед обраних параметрів точності `ε > 0` та надійності `δ ∈ (0, 1)`, якщо розміри таблиці лічильників задані як `w = ⌈e / ε⌉` та `d = ⌈ln(1 / δ)⌉`, тоді для будь-якого елемента `x` оцінка `âₓ` задовольняє нерівність:

```
aₓ ≤ âₓ ≤ aₓ + ε · ||a||₁
```

причому ліва нерівність виконується абсолютно детерміновано (з імовірністю 1), а права — з імовірністю щонайменше `1 - δ`.

## Гарантія виявлення важких елементів (Heavy Hitters)

Елемент `x` називається важким елементом з порогом `φ ∈ (0, 1)` (Heavy Hitter), якщо його істинна частота становить не менше ніж частку `φ` від загального обсягу потоку: `aₓ ≥ φ · ||a||₁`.

Якщо обрати параметр точності ескізу `ε ≤ φ`, тоді за гарантією Count-Min Sketch:

```
âₓ ≥ aₓ ≥ φ · ||a||₁
```

Це означає, що жоден справді важкий елемент ніколи не буде пропущений (False Negative = 0). Усі елементи з частотою `aₓ ≥ φ · ||a||₁` гарантовано матимуть оцінку `âₓ ≥ φ · ||a||₁` і будуть зафіксовані системою.

Можливі лише хибнопозитивні спрацьовування (False Positive), коли через колізійний шум дрібний елемент отримає завищену оцінку `â > φ · ||a||₁`. Проте ймовірність такого завищення для будь-якого неважливого елемента з істинною частотою `a < (φ - ε) · ||a||₁` суворо обмежена величиною `δ`.

## Математична коректність консервативного оновлення

При консервативному оновленні лічильників нове значення комірки визначається правилом:

```
C[j, hⱼ(x)] = max(C[j, hⱼ(x)], min_{0 ≤ r < d} C[r, hᵣ(x)] + c)
```

Доведемо за математичною індукцією за кількістю транзакцій потоку, що інваріант `min_{j} C[j, hⱼ(x)] ≥ aₓ` зберігається на кожному кроці.

* **База індукції**: до початку роботи потоку всі лічильники `C[j, k] = 0` та всі істинні частоти `aₓ = 0`. Нерівність `0 ≥ 0` виконується.
* **Індукційний перехід**: нехай нерівність виконувалася до поточної події `(x, c)`.
  1. Якщо оновлюється елемент `x`, поточний мінімум дорівнював `M = min_{r} C[r, hᵣ(x)] ≥ aₓ`.
  2. Після виконання правила оновлення кожен лічильник `C[j, hⱼ(x)]` стає щонайменше рівним `M + c`.
  3. Новий мінімум дорівнює:
     ```
     M_new = min_{j} (нове значення C[j, hⱼ(x)]) ≥ M + c ≥ aₓ + c = a_new
     ```
  4. Якщо ж оновлюється інший елемент `y ≠ x`, значення лічильників для `x` можуть тільки збільшитися або залишитися незмінними, тобто умова `min_{j} C[j, hⱼ(x)] ≥ aₓ` не порушується.

Таким чином, консервативне оновлення є математично строгим і зберігає повну гарантію відсутності занижень частот.
