# 🧮 Математичні оцінки покриття: гармонійна межа, найгірший випадок та двоїстість LP

Цей аналітичний розділ містить строге математичне обґрунтування характеристик задачі про покриття множини (*Set Cover*). Нижче наведено покрокове виведення коефіцієнта апроксимації жадібного алгоритму методом розподілу вартості (*cost-sharing*), точну геометричну конструкцію найгіршого випадку (*tightness analysis*), а також доведення через апарат двоїстості лінійного програмування (*dual fitting*).

---

## 1. Покрокове доведення коефіцієнта апроксимації H(k)

Нехай задано універсум `U` з `|U| = n` елементів та сімейство підмножин `S = {S₁, S₂, ..., Sₘ}` з додатними вагами `w(Sᵢ) > 0`. Нехай `k = max_{S ∈ S} |S|` — максимальний розмір підмножини в сімействі (`k ≤ n`).

Позначимо через `OPT` підсімейство підмножин, що утворює оптимальне покриття, а через `Cost(OPT) = ∑_{S ∈ OPT} w(S)` — його сумарну вартість. Жадібний алгоритм обирає підмножини покроково: на кроці `t` обирається множина `S_t`, яка мінімізує питому вартість за один новий покритий елемент:

```
min_{S} ( w(S) / |S \ Covered_{t-1}| )
```

### Метод розподілу вартості (Price-per-Element)

Для кожного елемента `e ∈ U` визначимо його ціну `price(e)`. Якщо елемент `e` був вперше покритий на кроці `t` вибором множини `S_t`, то вартість `w(S_t)` порівну розподіляється між усіма щойно покритими елементами:

```
price(e) = w(S_t) / |S_t \ Covered_{t-1}|
```

За побудовою, сумарна вартість розв'язку, знайденого жадібним алгоритмом `Cost(Greedy)`, точно дорівнює сумі цін усіх елементів універсуму:

```
Cost(Greedy) = ∑_{e ∈ U} price(e)
```

### Лема про покриття довільної підмножини

Розглянемо довільну фіксовану підмножину `S ∈ S`. Впорядкуємо її елементи у порядку їх покриття жадібним алгоритмом: `e₁, e₂, ..., e_{|S|}`.

Розглянемо момент часу безпосередньо перед тим, як було покрито елемент `e_j` (де `1 ≤ j ≤ |S|`). У цей момент у множині `S` залишалося щонайменше `|S| - j + 1` непокритих елементів. Оскільки множина `S` була доступна для вибору жадібному алгоритму, середня вартість покриття одного її елемента становила:

```
w(S) / (|S| - j + 1)
```

Жадібний алгоритм обрав множину `S_t`, яка мінімізувала питому вартість, отже ціна елемента `e_j` задовольняє нерівність:

```
price(e_j) ≤ w(S) / (|S| - j + 1)
```

Підсумуємо ціни всіх елементів множини `S`:

```
∑_{e ∈ S} price(e)
= ∑_{j=1}^{|S|} price(e_j)
≤ ∑_{j=1}^{|S|} ( w(S) / (|S| - j + 1) )    [підстановка нерівності для кожного price(e_j)]
= w(S) · ∑_{j=1}^{|S|} ( 1 / (|S| - j + 1) ) [винесення константи w(S) за знак суми]
= w(S) · ( 1/|S| + 1/(|S|-1) + ... + 1/2 + 1/1 ) [розкриття суми при j від 1 до |S|]
= w(S) · H(|S|)                            [визначення гармонійного числа H(m)]
```

де `H(m) = ∑_{i=1}^m (1/i)` — `m`-те гармонійне число.

### Фінальне зв'язування з оптимумом

Оскільки множини з оптимального розв'язку `OPT` разом покривають увесь універсум `U`, тобто `U = ⋃_{S^* ∈ OPT} S^*`, сума цін по всіх елементах не перевищує суми цін по елементах множин з `OPT`:

```
Cost(Greedy)
= ∑_{e ∈ U} price(e)
≤ ∑_{S^* ∈ OPT} ( ∑_{e ∈ S^*} price(e) )     [елементи можуть перекриватися в OPT]
≤ ∑_{S^* ∈ OPT} ( w(S^*) · H(|S^*|) )       [застосування леми для кожної множини S^*]
≤ H(k) · ∑_{S^* ∈ OPT} w(S^*)               [оскільки |S^*| ≤ k для всіх множин]
= H(k) · Cost(OPT)                         [підстановка Cost(OPT)]
```

Оскільки для довільного цілого `k` виконується аналітична оцінка гармонійного ряду `H(k) ≤ ln(k) + 1`, маємо остаточну гарантію:

```
Cost(Greedy) ≤ (ln k + 1) · Cost(OPT) ≤ (ln n + 1) · Cost(OPT)
```

## 2. Конструкція найгіршого випадку (Доведення досяжності межі)

Доведемо, що логарифмічний коефіцієнт не є артефактом методу доведення, а відображає реальну поведінку жадібного алгоритму на спеціально побудованих вхідних даних.

Побудуємо екстремальний приклад незваженої задачі про покриття множини (`w(S) = 1` для всіх `S`), де жадібний алгоритм дає фактор `Ω(ln n)` відносно оптимуму.

### Побудова універсуму та сімейства підмножин

Нехай `n = 2^k` — кількість елементів в універсумі `U = {1, 2, ..., n}`. Розділимо універсум на дві рівні половини:
- `U_L = {1, 2, ..., n/2}`
- `U_R = {n/2 + 1, ..., n}`

Визначимо сімейство підмножин `S`, яке складається з двох груп:

1. **Оптимальна група (2 множини):**
   - `O₁ = U_L` (покриває ліву половину, `|O₁| = n/2`, вартість `w(O₁) = 1`)
   - `O₂ = U_R` (покриває праву половину, `|O₂| = n/2`, вартість `w(O₂) = 1`)
   Очевидно, що `O₁ ∪ O₂ = U`, тому розмір і вартість оптимального покриття дорівнюють:
   ```
   Cost(OPT) = 1 + 1 = 2
   ```

2. **Пастка для жадібного алгоритму (k множин `G₁, G₂, ..., G_k`):**
   - Множина `G₁` містить `n/4` елементів з `U_L` та `n/4` елементів з `U_R`. Її розмір `|G₁| = n/2`.
   - Множина `G₂` містить `n/8` непокритих елементів з `U_L` та `n/8` непокритих елементів з `U_R`. Її розмір `|G₂| = n/4`.
   - У загальному вигляді: множина `G_i` (для `1 ≤ i ≤ k - 1`) містить `n / 2^{i+1}` раніше не задіяних елементів з кожної половини, покриваючи сумарно `n / 2^i` нових елементів.
   - Остання множина `G_k` покриває останні 2 непокриті елементи (по 1 з кожного боку).

Усі множини `G_i` мають однакову одиничну вартість `w(G_i) = 1`. Додамо до кожної множини `G_i` нескінченно малий пріоритет (або на 1 елемент більше), щоб розірвати нічию на користь жадібного вибору.

### Траєкторія жадібного вибору

- **Крок 1:** Алгоритм обирає `G₁` (покриває `n/2` елементів). Непокритими залишаються `n/2` елементів. У множинах `O₁` та `O₂` залишилося лише по `n/4` непокритих елементів.
- **Крок 2:** Множина `G₂` покриває `n/4` елементів, тоді як `O₁` та `O₂` покривають лише по `n/4`. Жадібний алгоритм обирає `G₂`.
- **Крок i:** На кожному наступному кроці множина `G_i` покриває більше нових елементів, ніж залишок будь-якої з множин `O₁` або `O₂`.

Жадібний алгоритм послідовно обере всі `k` множин `G₁, G₂, ..., G_k`:

```
Cost(Greedy) = k = log₂(n)
```

Обчислимо співвідношення між вартістю жадібного розв'язку та оптимуму:

```
Cost(Greedy) / Cost(OPT)
= log₂(n) / 2
= (ln(n) / ln(2)) / 2           [перехід до натурального логарифма]
= (1 / (2 · ln 2)) · ln(n)
≈ 0.7213 · ln(n)
```

Таким чином, коефіцієнт `Ω(ln n)` є фундаментально непереборним для жадібної стратегії.

## 3. Обґрунтування через двоїстість LP (Dual Fitting)

Метод підгонки двоїстих змінних (*Dual Fitting*) дає глибоке пояснення гармонійного фактора через призму опуклого аналізу та лінійного програмування.

### Пряма та двоїста задачі

Запишемо пряму релаксовану задачу лінійного програмування (Primal LP) та відповідну їй двоїсту задачу (Dual LP):

```
Пряма задача (Primal LP):
min  ∑_{S ∈ S} w(S) · x_S
при обмеженнях:
  ∑_{S : e ∈ S} x_S ≥ 1   (для кожного e ∈ U)
  x_S ≥ 0                 (для кожного S ∈ S)

Двоїста задача (Dual LP):
max  ∑_{e ∈ U} y_e
при обмеженнях:
  ∑_{e ∈ S} y_e ≤ w(S)    (для кожної S ∈ S)
  y_e ≥ 0                 (для кожного e ∈ U)
```

За теоремою слабкої двоїстості (*Weak Duality Theorem*), для будь-якого допустимого двоїстого вектора `y` та будь-якого допустимого прямого розв'язку `x` (зокрема цілочисельного оптимуму `OPT`) виконується фундаментальна нерівність:

```
∑_{e ∈ U} y_e ≤ Cost(OPT_LP) ≤ Cost(OPT)
```

### Конструювання двоїстого розв'язку

Покладемо двоїсті змінні рівними цінам елементів, призначеним жадібним алгоритмом:

```
y_e' = price(e)
```

Сума двоїстих змінних дорівнює вартості жадібного розв'язку:

```
∑_{e ∈ U} y_e' = Cost(Greedy)
```

Як було доведено в пункті 1, для будь-якої підмножини `S ∈ S` сума цін її елементів задовольняє нерівність:

```
∑_{e ∈ S} y_e' ≤ w(S) · H(|S|) ≤ w(S) · H_n
```

Вектор `y'` порушує двоїсті обмеження в щонайбільше `H_n` разів. Масштабуємо двоїсті змінні, поділивши їх на `H_n`:

```
y_e = y_e' / H_n = price(e) / H_n
```

Перевіримо допустимість вектора `y` для двоїстої задачі:

```
∑_{e ∈ S} y_e
= (1 / H_n) · ∑_{e ∈ S} price(e)
≤ (1 / H_n) · (w(S) · H_n)         [підстановка верхньої оцінки суми цін]
= w(S)                             [скорочення H_n]
```

Вектор `y` є строго **допустимим розв'язком двоїстої задачі** Dual LP. Застосуємо слабку двоїстість:

```
∑_{e ∈ U} y_e ≤ Cost(OPT_LP) ≤ Cost(OPT)
```

Підставимо визначення `y_e = price(e) / H_n`:

```
(1 / H_n) · ∑_{e ∈ U} price(e) ≤ Cost(OPT)
(1 / H_n) · Cost(Greedy) ≤ Cost(OPT)
Cost(Greedy) ≤ H_n · Cost(OPT)
```

Цей результат є надзвичайно потужним: жадібний алгоритм гарантує наближення не просто відносно невідомого цілочисельного оптимуму `OPT`, але й відносно значно меншого дробового оптимуму лінійної релаксації `OPT_LP` (*Integrality Gap*).
