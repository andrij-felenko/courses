# 🧮 Геометрія зсуву контуру, бісектриси та сума Мінковського

Ця математична вставка містить строге аналітичне виведення вектора зміщення вершин при побудові еквідистанти многокутника, розрахунок довжини кутового стику (*miter distance*), оцінку похибки дискретизації скруглень дугами та формулювання зовнішнього розширення через операцію суми Мінковського.

## 1. Векторні рівняння зміщених прямих

Розглянемо дві послідовні орієнтовані сторони багатокутника на евклідовій площині: вхідне ребро `E₁ = (V_{prev}, V)` та вихідне ребро `E₂ = (V, V_{next})`, які перетинаються у спільній вершині `V`.

Позначимо вектори напрямків ребер як `v₁ = V − V_{prev}` та `v₂ = V_{next} − V`. Їхні евклідові довжини дорівнюють відповідно:

```
L₁ = √(v₁.x² + v₁.y²)
L₂ = √(v₂.x² + v₂.y²)
```

Одиничні вектори напрямків ребер визначаються як:

```
e₁ = v₁ / L₁ = (v₁.x / L₁, v₁.y / L₁)
e₂ = v₂ / L₂ = (v₂.x / L₂, v₂.y / L₂)
```

Для контуру, орієнтованого проти годинникової стрілки (CCW), одиничні вектори лівобічних зовнішніх нормалей отримуються поворотом одиничних векторів напрямку на кут `+90°` (тобто перетворенням `(x, y) ↦ (−y, x)`):

```
n₁ = (−e₁.y, e₁.x) = (−v₁.y / L₁, v₁.x / L₁)
n₂ = (−e₂.y, e₂.x) = (−v₂.y / L₂, v₂.x / L₂)
```

Пряма, паралельна ребору `E₁` і віддалена від нього на відстань `d` уздовж нормалі `n₁`, описується геометричним місцем точок `X`, для яких скалярний добуток вектора `X − V` на нормаль `n₁` дорівнює величині зсуву `d`. Аналогічно задається пряма для ребра `E₂`:

```
Пряма L₁: (X − V) · n₁ = d
Пряма L₂: (X − V) · n₂ = d
```

## 2. Аналітичний розрахунок вектора зсуву вершини

Шукана зміщена вершина `P` лежить на перетині прямих `L₁` та `L₂`. Позначимо вектор відхилення зміщеної точки від початкової вершини як `m = P − V`.

Підставивши точку `P` у рівняння обох прямих, отримуємо систему двох лінійних скалярних рівнянь відносно вектора `m`:

```
m · n₁ = d        [проєкція вектора m на нормаль n₁ дорівнює d]
m · n₂ = d        [проєкція вектора m на нормаль n₂ дорівнює d]
```

Оскільки проєкції вектора `m` на одиничні нормалі `n₁` та `n₂` однакові, вектор `m` симетрично розташований відносно обох нормалей і лежить строго на їхній кутовій бісектрисі. Напрямок бісектриси задається вектором суми `n₁ + n₂`.

Запишемо шуканий вектор у вигляді `m = k · (n₁ + n₂)`, де `k` — скалярний коефіцієнт масштабу, який підлягає визначенню. Підставимо цей вираз у перше рівняння системи:

```
m · n₁
= (k · (n₁ + n₂)) · n₁      [підставили вираз для вектора m]
= k · (n₁ · n₁ + n₂ · n₁)   [розкрили дужки скалярного добутку]
= k · (1 + n₁ · n₂)         [оскільки нормаль одинична: n₁ · n₁ = 1]
= d                         [вимога рівновіддаленості від першої грані]
```

Звідси однозначно знаходимо скалярний множник `k`:

```
k = d / (1 + n₁ · n₂)       [поділили обидві частини на (1 + n₁ · n₂)]
```

Підставляючи отримане значення коефіцієнта `k` у формулу для `m`, маємо точний аналітичний вираз для вектора зміщення вершини:

```
m = d · (n₁ + n₂) / (1 + n₁ · n₂) [підставили k у формулу бісектриси]
```

Координати нової вершини `P` обчислюються безпосереднім додаванням вектора `m` до вихідних координат точки `V`:

```
P = V + m
P.x = V.x + d · (n₁.x + n₂.x) / (1 + n₁.x · n₂.x + n₁.y · n₂.y)
P.y = V.y + d · (n₁.y + n₂.y) / (1 + n₁.x · n₂.x + n₁.y · n₂.y)
```

Ця формула не вимагає обчислення визначників матриці системи чи тригонометричних функцій `sin` і `cos`, що забезпечує максимальну швидкодію в обчислювальних циклах.

## 3. Довжина стику та тригонометрична сингулярність

Знайдемо евклідову довжину вектора зсуву `|m|` залежно від величини внутрішнього кута многокутника `θ` при вершині `V`.

Кут між векторами суміжних ребер дорівнює `θ`. Оскільки нормалі повернуті відносно ребер на 90°, кут між зовнішніми нормалями `n₁` та `n₂` дорівнює `α = π − θ`.

Обчислимо скалярний добуток двох одиничних нормалей:

```
n₁ · n₂ = |n₁| · |n₂| · cos(α) = 1 · 1 · cos(π − θ) = −cos(θ)
```

Обчислимо квадрат норми вектора бісектриси `n₁ + n₂`:

```
|n₁ + n₂|²
= (n₁ + n₂) · (n₁ + n₂)                     [квадрат норми вектора]
= n₁ · n₁ + 2 · (n₁ · n₂) + n₂ · n₂         [розкрили дужки]
= 1 + 2 · (n₁ · n₂) + 1                     [норми одиничних векторів дорівнюють 1]
= 2 + 2 · (n₁ · n₂)                         [згрупували доданки]
= 2 · (1 + n₁ · n₂)                         [винесли спільний множник]
```

Тепер знайдемо довжину вектора зміщення `|m|`:

```
|m|
= |d · (n₁ + n₂) / (1 + n₁ · n₂)|           [взяли довжину від виразу для m]
= d · |n₁ + n₂| / (1 + n₁ · n₂)             [винесли додатний скаляр d]
= d · √(2 · (1 + n₁ · n₂)) / (1 + n₁ · n₂)  [підставили довжину бісектриси]
= d · √(2 / (1 + n₁ · n₂))                  [скоротили дріб на √(1 + n₁ · n₂)]
```

Підставимо тригонометричне співвідношення `n₁ · n₂ = −cos(θ)` та застосуємо формулу половинного кута `1 − cos(θ) = 2 · sin²(θ / 2)`:

```
1 + n₁ · n₂
= 1 − cos(θ)                                [підставили скалярний добуток нормалей]
= 2 · sin²(θ / 2)                           [тригонометрична тотожність половинного кута]

|m|
= d · √(2 / (2 · sin²(θ / 2)))              [підставили тотожність під корінь]
= d · √(1 / sin²(θ / 2))                    [скоротили двійки в чисельнику й знаменнику]
= d / sin(θ / 2)                            [добули квадратний корінь для 0 < θ < π]
```

Отриманий результат демонструє фундаментальну геометричну властивість: гіпотенуза прямокутного трикутника, утвореного вершиною, зміщеною точкою та проєкцією на ребро, дорівнює `d / sin(θ / 2)`.

При наближенні внутрішнього кута до нуля (`θ → 0`):
- Значення `sin(θ / 2) → 0`;
- Довжина стику прямує до нескінченності: `lim_{θ → 0} |m| = +∞`.

Коефіцієнт подовження стику (*miter ratio*) визначається як відношення довжини вектора зміщення до величини зсуву:

```
miter_ratio = |m| / d = 1 / sin(θ / 2) = √(2 / (1 + n₁ · n₂))
```

Якщо це значення перевищує встановлений ліміт `M` (*miter limit*), вершину відсікають прямою фаскою на відстані `d` від кожної грані.

## 4. Оцінка похибки апроксимації кругової дуги

При побудові скругленого з'єднання кутів (*round join*) кругова дуга радіусом `d`, яка стягує кут повороту `α = π − θ`, замінюється полігональною ламаною з `k` прямолінійних відрізків.

Кут повороту одного хордового відрізка становить:

```
Δφ = α / k = (π − θ) / k
```

Максимальна радіальна похибка `ε` між ідеальною круговою дугою та прямолінійною хордою виникає посередині хорди. Відстань від вихідної вершини до середини хорди дорівнює `h = d · cos(Δφ / 2)`.

Геометрична похибка (стріла сегмента) обчислюється як:

```
ε
= d − h                                     [різниця радіуса кола та апофеми хорди]
= d − d · cos(Δφ / 2)                       [підставили вираз для h]
= d · (1 − cos(Δφ / 2))                     [винесли радіус d за дужки]
= d · (1 − cos(α / (2 · k)))                [підставили крок кута Δφ = α / k]
```

Для заданого допустимого інженерного допуску `ε_max` мінімально необхідна кількість кроків дискретизації `k` визначається послідовним розв'язанням нерівності:

```
d · (1 − cos(α / (2 · k))) ≤ ε_max
1 − cos(α / (2 · k)) ≤ ε_max / d            [поділили на величину зсуву d]
cos(α / (2 · k)) ≥ 1 − (ε_max / d)          [перенесли знаки]
α / (2 · k) ≤ arccos(1 − ε_max / d)         [застосували функцію arccos]
k ≥ α / (2 · arccos(1 − ε_max / d))         [виразили кількість відрізків k]
```

При малих значеннях `ε_max / d ≪ 1` можна використати розклад косинуса в [ряд Тейлора](root:math-analysis/taylor-series):

```
cos(x) ≈ 1 − x² / 2
1 − cos(α / (2 · k)) ≈ (α / (2 · k))² / 2 = α² / (8 · k²)

α² / (8 · k²) ≤ ε_max / d
k² ≥ (α² · d) / (8 · ε_max)                 [помножили на k² та перегрупували]
k ≥ (α / 2) · √(d / (2 · ε_max))            [добули квадратний корінь]
```

Ця формула дозволяє алгоритму адаптивно обирати кількість сегментів: для тупих кутів (мале `α`) генерується лише 1–2 відрізки, а для прямих кутів на великих радіусах кількість точок масштабується як `√d`, утримуючи баланс між точністю та обсягом вихідної полігональної сітки.

## 5. Алгебраїчна сума Мінковського та морфологічне розширення

Зовнішній зсув довільної плоскої замкненої множини точок `P ⊂ ℝ²` на відстань `r = d` математично строго формулюється через теоретико-множинну операцію **[суми Мінковського](root:math-geometry/minkowski-sum)** багатокутника `P` та круглого диска `D_r = { q ∈ ℝ² : |q| ≤ r }`:

```
P ⊕ D_r = { p + q : p ∈ P, q ∈ D_r }
```

З геометричної точки зору сума Мінковського являє собою область площини, утворену об'єднанням усіх можливих положень круга радіусом `r`, центр якого розташований у довільній точці вихідного багатокутника `P`.

Оскільки границя багатокутника `∂P` складається зі скінченної множини прямолінійних відрізків `{E_i}` та множини вершин `{V_i}`, границю розширеної фігури можна представити у вигляді дистрибутивного об'єднання:

```
∂(P ⊕ D_r)
= ∂ ( ( ⋃ E_i ⊕ D_r ) ∪ ( ⋃ V_i ⊕ D_r ) )  [дистрибутивність суми Мінковського]
```

Кожен доданок у цьому виразі має просту геометричну форму:
1. `E_i ⊕ D_r` — прямокутник зі скругленими краями (капсула або *stadium*), утворений паралельним розширенням відрізка `E_i` на відстань `r` в обидва боки;
2. `V_i ⊕ D_r` — круглий диск радіусом `r` з центром у точці `V_i`.

Зовнішня огинаюча лінія сукупності всіх таких прямокутників і дисків точно збігається з еквідистантою, побудованою за правилом скруглення кутів (*Round Join*). Внутрішні самоперетини увігнутих вершин повністю поглинаються об'єднанням множин, що математично доводить відсутність зовнішніх паразитних петель у строгому розширенні контуру.
