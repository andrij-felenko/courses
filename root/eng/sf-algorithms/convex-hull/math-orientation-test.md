# 🧮 Предикат повороту: алгебра й геометрія орієнтованої площі

Кожен алгоритм побудови опуклої оболонки спирається на одну атомарну операцію: визначення орієнтації трійки точок на площині. Якщо задано три точки `A`, `B` і `C`, необхідно однозначно відповісти, чи здійснює шлях `A → B → C` поворот ліворуч (проти годинникової стрілки), праворуч (за годинниковою стрілкою) або ж усі три точки лежать на одній прямій. 

Ця операція називається геометричним предикатом повороту (англ. *orientation predicate*, від лат. *praedicatum* — «висловлене, стверджуване», *orientari* — «знаходити схід, зорієнтуватися»). Від швидкості та чисельної надійності цього обчислення залежить коректність і топологічна цілісність усього алгоритму.

## Векторне виведення через косий добуток

Нехай точки площини задані декартовими координатами `A = (x[1], y[1])`, `B = (x[2], y[2])` та `C = (x[3], y[3])`. Розглянемо два напрямлені вектори, що виходять із точки `A`: вектор `u = B - A` та вектор `v = C - A`. Їхні координати мають вигляд:

```
u = (x[2] - x[1], y[2] - y[1])  [вектор від A до B]
v = (x[3] - x[1], y[3] - y[1])  [вектор від A до C]
```

У тривимірному просторі векторний добуток `u × v` є вектором, перпендикулярним до площини `xy`. Його довжина дорівнює площі паралелограма, натягнутого на вектори `u` та `v`, а знак `z`-компоненти визначається правилом правої руки. На двовимірній площині ця `z`-компонента називається псевдоскалярним або косим добутком (англ. *2D cross product*):

```
cross(u, v) = u[x]·v[y] - u[y]·v[x]
            = (x[2] - x[1])·(y[3] - y[1]) - (y[2] - y[1])·(x[3] - x[1])  [підстановка координат векторів]
            = x[2]·y[3] - x[2]·y[1] - x[1]·y[3] + x[1]·y[1] - (y[2]·x[3] - y[2]·x[1] - y[1]·x[3] + y[1]·x[1]) [розкриття дужок]
            = x[1]·(y[2] - y[3]) + x[2]·(y[3] - y[1]) + x[3]·(y[1] - y[2])  [перегрупування доданків за вершинами]
```

Отриманий вираз є точно визначником матриці розміру 2×2, стовпцями якої є вектори `u` та `v`:

```
det([u[x], v[x]], [u[y], v[y]]) = u[x]·v[y] - u[y]·v[x]  [визначник 2×2]
```

## Інваріантність відносно паралельного перенесення та обертання

Важливою властивістю предиката орієнтації є його строга інваріантність щодо жорстких рухів площини (паралельного перенесення та повороту системи координат).

Якщо перенести всю систему точок на довільний вектор `t = (t[x], t[y])`, нові координати точок стануть `A' = A + t`, `B' = B + t`, `C' = C + t`. Тоді вектори різниці залишаються абсолютно незмінними:

```
u' = B' - A'
   = (B + t) - (A + t)
   = B - A
   = u                  [інваріантність вектора різниці при перенесенні]
```

Аналогічно, якщо повернути площину на кут `θ` навколо початку координат за допомогою ортогональної матриці повороту `R(θ)` (для якої `det(R) = 1`), вектори трансформуються як `u' = R·u` та `v' = R·v`. Тоді за мультиплікативною властивістю детермінанта маємо:

```
det([u', v']) = det(R · [u, v])
              = det(R) · det([u, v])
              = 1 · det([u, v])
              = det([u, v])            [інваріантність при обертанні координат]
```

Це математично гарантує, що знак предиката повороту залежить виключно від взаємного просторового розташування точок і не змінюється при будь-якому виборі базису чи зміщенні початку відліку.

## Зв'язок з однорідними координатами та визначником 3×3

Той самий результат отримується через афінний визначник трьох точок в однорідних координатах, де третя координата кожної точки дорівнює одиниці:

```
Δ = det([x[1], y[1], 1], [x[2], y[2], 1], [x[3], y[3], 1])
  = 1·(x[2]·y[3] - x[3]·y[2]) - 1·(x[1]·y[3] - x[3]·y[1]) + 1·(x[1]·y[2] - x[2]·y[1])  [розклад за третім стовпцем]
  = x[1]·(y[2] - y[3]) + x[2]·(y[3] - y[1]) + x[3]·(y[1] - y[2])                        [алгебраїчне групування]
  = (x[2] - x[1])·(y[3] - y[1]) - (y[2] - y[1])·(x[3] - x[1])                           [зведення до різниці добутків]
```

Геометричний зміст визначника `Δ`: його абсолютна величина дорівнює подвоєній площі трикутника `ABC`, а знак вказує на орієнтацію вершин:

```
S_ABC = (1/2) · Δ  [орієнтована площа трикутника за формулою шнурівки]
```

Звідси випливає фундаментальне правило знаків для предиката `ccw(A, B, C)` (counter-clockwise):

1. `Δ > 0`: Вектор `v = C - A` відхилений ліворуч від вектора `u = B - A`. Точки `A → B → C` утворюють лівий поворот (рух проти годинникової стрілки). Точка `C` лежить у лівій відкритій півплощині відносно орієнтованої прямої `AB`.
2. `Δ < 0`: Вектор `v` відхилений праворуч від вектора `u`. Точки `A → B → C` утворюють правий поворот (рух за годинниковою стрілкою). Точка `C` лежить у правій півплощині.
3. `Δ = 0`: Вектори `u` та `v` є лінійно залежними (паралельними). Точки `A`, `B` і `C` є строго колінеарними (лежать на одній прямій), а площа трикутника `S_ABC` дорівнює нулю.

## Пастка чисел із плаваючою комою

У комп'ютерній реалізації пряме обчислення `(x[2] - x[1])·(y[3] - y[1]) - (y[2] - y[1])·(x[3] - x[1])` з використанням 64-бітних чисел із плаваючою комою (`double` за стандартом IEEE 754) приховує критичну небезпеку: катастрофічне скасування розрядів (англ. *catastrophic cancellation*).

Коли точка `C` знаходиться майже на прямій `AB`, обидва добутки `(x[2] - x[1])·(y[3] - y[1])` та `(y[2] - y[1])·(x[3] - x[1])` є близькими за величиною числами. Віднімання таких чисел призводить до втрати значущих двійкових розрядів мантиси. У результаті:

1. Предикат може повернути `Δ > 0` замість `Δ < 0`, змінюючи знак повороту на протилежний.
2. Порушується властивість антисиметричності: обчислення `ccw(A, B, C)` та `ccw(B, A, C)` можуть одночасно повернути додатне значення, що геометрично неможливо.
3. Порушується транзитивність орієнтації: для трьох точок `A, B, C` алгоритм може отримати `ccw(A, B, C) > 0`, `ccw(B, C, D) > 0`, `ccw(C, D, A) > 0` і водночас `ccw(D, A, B) < 0` на майже виродженому чотирикутнику. Через це алгоритми Грехема або Ендрю можуть потрапити в нескінченний цикл, почергово виштовхуючи та повертаючи одну й ту саму вершину, або побудувати самоперетинний многокутник замість опуклої оболонки.

## Точна арифметика та практичні гарантії

Існує два надійні способи усунення похибок округлення:

### 1. Цілочисельна арифметика достатньої розрядності
Якщо вхідні координати є цілими числами (наприклад, екранні пікселі, координати сітки або нормалізовані фіксовані числа), то для діапазону координат `|x|, |y| ≤ M` різниці координат не перевищують `2M`, а їхні добутки — `4M²`. Для запобігання переповненню максимальне значення визначника оцінюється як:

```
|Δ| ≤ 2 · (2M) · (2M)
    = 8M²  [максимальне значення детермінанта]
```

Якщо `M = 10⁶` (один мільйон), то `8M² = 8·10¹²`, що гарантовано вміщується в стандартне 64-бітне ціле число зі знаком `int64_t` (діапазон до `≈ 9·10¹⁸`). Якщо ж координати досягають `10⁹`, різниці добутків вимагають проміжного 128-бітного множення (`__int128_t` у GCC/Clang), яке виконується за кілька процесорних тактів без жодної втрати точності.

Якщо апаратного типу `__int128` немає (наприклад, у 32-бітних мікроконтролерах без розширеного компілятора), 64-бітне множення розбивають на 32-бітні половини:

```
A = A_hi·2³² + A_lo
B = B_hi·2³² + B_lo
A · B = A_hi·B_hi·2⁶⁴ + (A_hi·B_lo + A_lo·B_hi)·2³² + A_lo·B_lo  [емуляція 128-бітного добутку]
```

Така програмна емуляція гарантує 100% захист від переповнення при мінімальних накладних витратах.

### 2. Адаптивні предикати Шевчука
Для дійсних чисел із плаваючою комою золотим стандартом обчислювальної геометрії є адаптивні предикати точної арифметики Джонатана Шевчука (Jonathan Shewchuk, 1997). Алгоритм Шевчука спершу швидко обчислює детермінант у звичайному типі `double` разом із верхньою оцінкою похибки округлення `ε`:

```
ε = (3·2⁻⁵³ + 32·2⁻¹⁰⁶) · (|u[x]·v[y]| + |u[y]·v[x]|)  [межа похибки обчислення 2×2]
```

Якщо `|Δ_approx| > ε`, знак наближеного результату гарантовано збігається зі справжнім знаком детермінанта, і функція миттєво повертає відповідь. Лише у випадку, коли `|Δ_approx| ≤ ε` (точка надзвичайно близька до прямої), алгоритм динамічно перемикається на точне покрокове додавання розширень мантиси без округлення (*expansion arithmetic*). Це забезпечує абсолютну математичну строгість при збереженні максимальної швидкодії на реальних наборах даних.
