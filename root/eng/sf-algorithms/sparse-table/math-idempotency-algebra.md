# 🧮 Алгебраїчні засади ідемпотентності та властивості двійкових покриттів

Коли обчислювальна система виконує запит на відрізку масиву `A[L .. R]`, вона обчислює згортку послідовності елементів за допомогою деякої бінарної операції `⊕`:

```
Q(L, R) = A[L] ⊕ A[L + 1] ⊕ ... ⊕ A[R]
```

Швидкість, з якою можна знайти значення `Q(L, R)`, фундаментально залежить не від розміру масиву, а від **алгебраїчної структури**, яку утворює множина значень разом із цією операцією. 

Головна відмінність між структурами зі складністю запиту `O(1)` (як у таблиці розрідження для мінімуму) та структурами зі складністю `O(log N)` (як у відрізковому дереві чи префіксних сумах для додавання) полягає в одній математичній властивості — **ідемпотентності**.

## Алгебраїчна класифікація операцій над відрізками

Розглянемо множину `S` та бінарну операцію `⊕: S × S → S`.

### 1. Напівгрупа (Semigroup)
Пара `(S, ⊕)` називається **напівгрупою**, якщо для будь-яких елементів `a, b, c ∈ S` виконується аксіома **асоціативності**:

```
(a ⊕ b) ⊕ c = a ⊕ (b ⊕ c)
```

Асоціативність гарантує, що порядок розстановки дужок у виразі `A[L] ⊕ A[L + 1] ⊕ ... ⊕ A[R]` не впливає на кінцевий результат. Це дозволяє розбивати довільний відрізок на підвідрізки меншої довжини та комбінувати їхні проміжні результати.

Якщо операція не є асоціативною (наприклад, операція віднімання `(a - b) - c ≠ a - (b - c)` або ділення), ні таблиця розрідження, ні дерево відрізків не можуть бути застосовані.

### 2. Ідемпотентна напівгрупа (Band / Напівґратка)
Напівгрупа `(S, ⊕)` називається **ідемпотентною** (в абстрактній алгебрі — *бендом* або *напівґраткою*, якщо операція також комутативна), якщо для кожного елемента `x ∈ S` виконується закон **ідемпотентності** (лат. *idem* — той самий, *potens* — здатний):

```
x ⊕ x = x
```

Саме ідемпотентність відкриває можливість **перекриття підвідрізків**: якщо деякий елемент масиву потрапляє у проміжні обчислення двічі (або довільну скінченну кількість разів), він не спотворює фінального результату.

### 3. Зв'язок із теорією порядків: напівґратки (Meet-Semilattices)
У теорії частково впорядкованих множин (Poset) ідемпотентні комутативні напівгрупи знаходяться у взаємно однозначній відповідності з **нижніми напівґратками** (англ. *meet-semilattices*). 

Якщо на множині `S` задано частковий порядок `≤`, у якому для будь-якої пари елементів `a, b` існує точна нижня межа (інфімум) `inf(a, b) = a ∧ b`, то операція `∧` автоматично задовольняє:
- Асоціативність: `(a ∧ b) ∧ c = a ∧ (b ∧ c) = inf(a, b, c)`.
- Комутативність: `a ∧ b = b ∧ a`.
- Ідемпотентність: `a ∧ a = inf(a, a) = a`.

Для будь-якої лінійно впорядкованої множини (наприклад, дійсних чи цілих чисел із природним порядком `≤`) операція взяття мінімуму `min(a, b)` є саме таким інфімумом напівґратки. Аналогічно операція максимуму `max(a, b)` є супремумом (операцією `join` верхньої напівґратки). Це доводить, що будь-яка екстремальна задача на впорядкованих множинах природно допускає обчислення за константний час через таблицю розрідження.

## Теорема про перекриття інтервалів степеня двійки

Сформулюємо та строго доведемо головне математичне твердження, на якому базується константний запит розрідженої таблиці.

### Формулювання теореми
Нехай задано цілочисельний відрізок індексів `I = [L, R]`, де `L, R ∈ ℤ` та `L ≤ R`. 
Позначимо довжину відрізка як:

```
len = R - L + 1,   len ≥ 1
```

Нехай степінь двійки `k` визначено як цілу частину двійкового логарифма довжини:

```
k = ⌊log₂ len⌋
```

Тоді два відрізки `I₁` та `I₂` довжини `2^k`:

```
I₁ = [L,  L + 2^k - 1]
I₂ = [R - 2^k + 1,  R]
```

задовольняють дві фундаментальні умови:
1. Обидва відрізки є підмножинами вихідного інтервалу: `I₁ ⊆ I` та `I₂ ⊆ I`.
2. Їхнє об'єднання повністю покриває вихідний інтервал: `I₁ ∪ I₂ = I`.

### Доведення

#### Крок 1. Перевірка включення підмножин
За означенням операції взяття нижньої цілої частини `k = ⌊log₂ len⌋`, маємо строгу подвійну нерівність:

```
k ≤ log₂ len < k + 1
```

Підносячи двійку до відповідних степенів (оскільки показникова функція `2^x` строго зростає на `ℝ`), отримуємо:

```
2^k ≤ len < 2^(k + 1)
```

Оскільки `2^k ≤ len = R - L + 1`:
- Права межа відрізка `I₁` дорівнює `L + 2^k - 1 ≤ L + (R - L + 1) - 1 = R`. Звідси `I₁ ⊆ [L, R]`.
- Ліва межа відрізка `I₂` дорівнює `R - 2^k + 1 ≥ R - (R - L + 1) + 1 = L`. Звідси `I₂ ⊆ [L, R]`.

#### Крок 2. Перевірка повного покриття та непорожнього перетину
Щоб довести, що `I₁ ∪ I₂ = [L, R]`, достатньо показати, що правий край `I₁` перетинає або принаймні стикається з лівим краєм `I₂`. Тобто:

```
Права межа I₁ ≥ Ліва межа I₂ - 1
(L + 2^k - 1) ≥ (R - 2^k + 1) - 1
```

Перетворимо цю нерівність за допомогою тотожних алгебраїчних перетворень:

```
L + 2^k - 1 ≥ R - 2^k
2^k + 2^k ≥ R - L + 1    [перенесли -2^k ліворуч та L праворуч]
2 · 2^k ≥ len            [за означенням len = R - L + 1]
2^(k + 1) ≥ len          [застосували властивість степенів]
```

З нерівності `k = ⌊log₂ len⌋` ми вже знаємо, що `2^(k + 1) > len`. 
Отже, нерівність `2 · 2^k > len` виконується суворо для будь-якого `len ≥ 1`.

Це означає, що відрізки `I₁` та `I₂` не просто дотикаються, а **завжди мають непорожній перетин**:

```
I₁ ∩ I₂ = [R - 2^k + 1,  L + 2^k - 1] ≠ ∅
```

Кількість спільних елементів у зоні перекриття становить:

```
|I₁ ∩ I₂| = (L + 2^k - 1) - (R - 2^k + 1) + 1
          = 2^(k + 1) - (R - L + 1)                 [групуємо доданки з 2^k]
          = 2^(k + 1) - len > 0                     [підставляємо довжину len = R - L + 1]
```


Оскільки ліва межа `I₁` збігається з `L`, права межа `I₂` збігається з `R`, а перетин між ними непорожній, об'єднання дискретних цілочисельних інтервалів не має прогалин:

```
I₁ ∪ I₂ = [L, R]
```

Теорему доведено.

## Доведення коректності обчислення для ідемпотентних напівгруп

Нехай `(S, ⊕)` — ідемпотентна напівгрупа, де операція `⊕` є асоціативною, комутативною та ідемпотентною.

Нехай елементи масиву впорядковані за індексами `A[L], A[L+1], ..., A[R]`.
Розглянемо результат виразу:

```
Result = ( ⨁_{i ∈ I₁} A[i] ) ⊕ ( ⨁_{j ∈ I₂} A[j] )
```

Розіб'ємо множину індексів `[L, R]` на три взаємно неперетинні частини:
1. `J₁ = I₁ \ I₂ = [L,  R - 2^k]` — елементи, що належать тільки першому блоку.
2. `J_overlap = I₁ ∩ I₂ = [R - 2^k + 1,  L + 2^k - 1]` — елементи перекриття.
3. `J₂ = I₂ \ I₁ = [L + 2^k,  R]` — елементи, що належать тільки другому блоку.

Тоді:

```
⨁_{i ∈ I₁} A[i] = ( ⨁_{i ∈ J₁} A[i] ) ⊕ ( ⨁_{m ∈ J_overlap} A[m] )
⨁_{j ∈ I₂} A[j] = ( ⨁_{m ∈ J_overlap} A[m] ) ⊕ ( ⨁_{j ∈ J₂} A[j] )
```

Підставимо ці вирази у формулу `Result`:

```
Result = ( ( ⨁_{i ∈ J₁} A[i] ) ⊕ ( ⨁_{m ∈ J_overlap} A[m] ) ) ⊕ ( ( ⨁_{m ∈ J_overlap} A[m] ) ⊕ ( ⨁_{j ∈ J₂} A[j] ) )
```

Застосовуючи властивість асоціативності та комутативності, згрупуємо однакові члени:

```
Result = ( ⨁_{i ∈ J₁} A[i] ) ⊕ ( ( ⨁_{m ∈ J_overlap} A[m] ) ⊕ ( ⨁_{m ∈ J_overlap} A[m] ) ) ⊕ ( ⨁_{j ∈ J₂} A[j] )
```

Позначимо спільну згортку перекриття як `V_overlap = ⨁_{m ∈ J_overlap} A[m]`. 
Застосовуючи закон ідемпотентності `x ⊕ x = x` до `V_overlap ⊕ V_overlap`:

```
V_overlap ⊕ V_overlap = V_overlap
```

Отримуємо:

```
Result = ( ⨁_{i ∈ J₁} A[i] ) ⊕ ( ⨁_{m ∈ J_overlap} A[m] ) ⊕ ( ⨁_{j ∈ J₂} A[j] )
       = ⨁_{i=L}^R A[i]
```

Це доводить, що обчислення `min(ST[k][L], ST[k][R - 2^k + 1])` дає математично точний мінімум вихідного відрізка без будь-яких похибок.

## Чому перекриття руйнує неідемпотентні операції: випадок групи `(ℤ, +)`

Розглянемо звичайне додавання цілих чисел на множині `ℤ`. Операція `+` є асоціативною та комутативною, але не є ідемпотентною:

```
x + x = 2x ≠ x   (для всіх x ≠ 0)
```

Якщо застосувати формулу двох блоків до обчислення суми на відрізку `[L, R]`, отримаємо:

```
Sum_approx = ST_sum[k][L] + ST_sum[k][R - 2^k + 1]
           = ∑_{i ∈ I₁} A[i] + ∑_{j ∈ I₂} A[j]
           = ∑_{i=L}^R A[i] + ∑_{m ∈ I₁ ∩ I₂} A[m]
           = Real_Sum + Overlap_Sum
```

У результаті сума елементів у зоні перекриття `I₁ ∩ I₂` додається двічі, що призводить до хибного результату, якщо хоча б один елемент перекриття відмінний від нуля.

## Диз'юнктне двійкове розбиття для загальних напівгруп

Якщо напівгрупа `(S, ⊕)` є асоціативною, але не ідемпотентною (наприклад, множення матриць, знаходження суми, добутку чи композиції перетворень), перекриття блоків використовувати не можна. 

У цьому випадку відрізок `[L, R]` розбивають на **диз'юнктні (взаємно неперетинні)** підвідрізки, довжини яких відповідають одиничним бітам у двійковому поданні числа `len`.

### Двійковий розклад довжини
Будь-яке натуральне число `len` можна однозначно подати у вигляді двійкового розкладу:

```
len = ∑_{b=0}^{m} c_b · 2^b,   де c_b ∈ {0, 1},   m = ⌊log₂ len⌋
```

Кількість ненульових коефіцієнтів `c_b = 1` дорівнює вазі Геммінга (кількості встановлених бітів) `popcount(len) ≤ ⌊log₂ len⌋ + 1`.

### Алгоритм диз'юнктного накриття
1. Ініціалізуємо поточний покажчик початку `curr = L`.
2. Для кожного біта `b` від `0` до `m`:
   - Якщо `c_b == 1` (тобто `(len & (1 << b)) != 0`):
     - Беремо блок довжини `2^b`, що починається в точці `curr`: `Block = [curr,  curr + 2^b - 1]`.
     - Його результат збережено в комірці `ST[b][curr]`.
     - Акумулюємо: `Total = Total ⊕ ST[b][curr]`.
     - Зсуваємо покажчик: `curr = curr + 2^b`.
3. Оскільки всі взяті блоки мають довжини `2^b` і розташовані впритул один за одним без прогалин і перекриттів:

```
⋃ Block_b = [L, R]   та   Block_a ∩ Block_b = ∅ (для a ≠ b)
```

Часова складність такого запиту становить `O(popcount(len)) = O(log len) ≤ O(log N)`, що робить розріджену таблицю універсальною для довільних асоціативних операцій.

## Алгебраїчний аналіз фундаментальних ідемпотентних операторів

Розглянемо докладніше, як закон ідемпотентності проявляється на конкретних алгебраїчних структурах, що найчастіше зустрічаються в алгоритмічній практиці.

### 1. Операція Range GCD (Найбільший спільний дільник)
Розглянемо множину додатних цілих чисел `ℤ⁺` з операцією знаходження найбільшого спільного дільника `gcd(a, b)`.

За основною теоремою арифметики кожне натуральне число `n` однозначно розкладається на прості множники:

```
n = p₁^(a₁) · p₂^(a₂) · ... · p_m^(a_m)
```

Операція `gcd(x, y)` відповідає покомпонентному взяттю мінімуму показників степенів для кожного простого числа `p_i`:

```
gcd(x, y) = ∏ p_i^( min(a_i, b_i) )
```

Оскільки операція взяття мінімуму для показників степенів є ідемпотентною `min(a_i, a_i) = a_i`, для будь-якого натурального числа `x` маємо:

```
gcd(x, x) = ∏ p_i^( min(a_i, a_i) ) = ∏ p_i^(a_i) = x
```

Крім того, операція `gcd` є строго асоціативною та комутативною:

```
gcd(gcd(a, b), c) = gcd(a, gcd(b, c))
gcd(a, b) = gcd(b, a)
```

Отже, трійка `(ℤ⁺, gcd)` утворює комутативну ідемпотентну напівгрупу (напівґратку ділимості). Обчислення НСД на довільному числовому відрізку масиву `[L, R]` зводиться до двох запитів до таблиці розрідження `ST_gcd`:

```
Range_GCD(L, R) = gcd( ST_gcd[k][L],  ST_gcd[k][R - 2^k + 1] )
```

Час відповіді становить `O(log(min(A, B)))` (через виконання алгоритму Евкліда над двома числами), що не залежить від довжини відрізка `len = R - L + 1` і є строго константним `O(1)` за кількістю звернень до пам'яті.

### 2. Побітові операції AND та OR на булевих ґратках
Розглянемо множину `w`-бітних машинних слів `W = {0, 1}^w` (наприклад, 32- або 64-бітні цілі числа).
Кожне слово `X ∈ W` можна розглядати як характеристичний вектор підмножини деякої `w`-елементної множини `U`.

Операція побітового `AND` відповідає перетину множин `A ∩ B`, а побітового `OR` — їхньому об'єднанню `A ∪ B`.
Для кожного окремого біта `b ∈ {0, 1}` аксіоми булевої алгебри стверджують:

```
b AND b = b
b OR  b = b
```

Оскільки побітові операції виконуються незалежно для кожного з `w` розрядів паралельно на рівні АЛП процесора, властивість ідемпотентності поширюється на все машинне слово:

```
X & X = X
X | X = X
```

Це дозволяє будувати таблицю розрідження для миттєвої перевірки спільних прапорців або масок дозволів на будь-якому часовому проміжку за одну процесорну інструкцію.

## Узагальнення на двовимірний простір: 2D Sparse Table

Принцип двійкового перекриття легко узагальнюється на багатовимірні простори. Розглянемо прямокутну матрицю `M` розміру `N × M` та задачу знаходження мінімуму на довільному прямокутному підрегіоні `[x1 .. x2] × [y1 .. y2]`.

### Структура 4D-масиву
Двовимірна таблиця розрідження будується як чотиривимірний масив:

```
ST2D[jx][jy][x][y]
```

який зберігає мінімум на прямокутнику розміру `2^jx × 2^jy`, верхній лівий кут якого розташований у точці `(x, y)`:

```
[x .. x + 2^jx - 1] × [y .. y + 2^jy - 1]
```

### Двовимірне рівняння динамічного програмування
Базовий рівень `jx = 0, jy = 0` відповідає окремим клітинкам матриці:

```
ST2D[0][0][x][y] = M[x][y]
```

Перехід за першим виміром (`jy = 0`, нарощування по `x`):

```
ST2D[jx][0][x][y] = min( ST2D[jx - 1][0][x][y],  ST2D[jx - 1][0][x + 2^(jx - 1)][y] )
```

Загальний перехід за обома вимірами (нарощування по `y` з уже збудованих блоків по `x`):

```
ST2D[jx][jy][x][y] = min( ST2D[jx][jy - 1][x][y],  ST2D[jx][jy - 1][x][y + 2^(jy - 1)] )
```

Кожен блок розміру `2^jx × 2^jy` обчислюється як мінімум двох прямокутників розміру `2^jx × 2^(jy - 1)`.

### Теорема про 4-блокове покриття прямокутника
Для довільного прямокутного запиту `[x1 .. x2] × [y1 .. y2]` визначимо довжини сторін та відповідні степені двійки:

```
len_x = x2 - x1 + 1,   kx = ⌊log₂ len_x⌋
len_y = y2 - y1 + 1,   ky = ⌊log₂ len_y⌋
```

Тоді вихідний прямокутник повністю покривається **чотирма прямокутниками** розміру `2^kx × 2^ky`, прикріпленими до чотирьох кутів області запиту:

```
Кут 1 (Top-Left):     ST2D[kx][ky][x1][y1]
Кут 2 (Bottom-Left):  ST2D[kx][ky][x2 - 2^kx + 1][y1]
Кут 3 (Top-Right):    ST2D[kx][ky][x1][y2 - 2^ky + 1]
Кут 4 (Bottom-Right): ST2D[kx][ky][x2 - 2^kx + 1][y2 - 2^ky + 1]
```

Мінімум на підматриці знаходиться взяттям мінімуму від цих чотирьох значень:

```
2D_RMQ = min(
    min( ST2D[kx][ky][x1][y1],  ST2D[kx][ky][x2 - 2^kx + 1][y1] ),
    min( ST2D[kx][ky][x1][y2 - 2^ky + 1],  ST2D[kx][ky][x2 - 2^kx + 1][y2 - 2^ky + 1] )
)
```

Завдяки ідемпотентності операції мінімуму взаємне 4-кратне перекриття цих прямокутників у центральній зоні запиту не спотворює результат. Час відповіді на 2D-запит становить строго `O(1)` (рівно 4 читання з пам'яті та 3 порівняння), а просторова складність 2D-таблиці — `O(N · M · log N · log M)`.

## Точний підрахунок кількості операцій побудови та пам'яті

Обчислимо точну кількість клітинок у класичній одновимірній розрідженій таблиці для масиву довжини `N`.

Нехай `K = ⌊log₂ N⌋`. Кількість рівнів таблиці дорівнює `K + 1` (від `j = 0` до `j = K`).
На кожному рівні `j` блок довжини `2^j` може починатися в будь-якому індексі `i`, для якого `i + 2^j - 1 < N`. Отже, кількість дійсних блоків на рівні `j` становить:

```
Count(j) = N - 2^j + 1
```

Загальна кількість обчислюваних комірок `Total_Cells` дорівнює сумі по всіх рівнях:

```
Total_Cells = ∑_{j=0}^{K} (N - 2^j + 1)
            = ∑_{j=0}^{K} (N + 1) - ∑_{j=0}^{K} 2^j           [розбиваємо суму на дві частини]
            = (N + 1) · (K + 1) - (2^(K + 1) - 1)             [за формулою суми геометричної прогресії]
```

Оскільки `2^K ≤ N < 2^(K + 1)`:

```
(N + 1) · (K + 1) - (2 · 2^K - 1) ≤ (N + 1) · (log₂ N + 1) - N = N · log₂ N + O(N)
```

Під час заповнення таблиці:
- Рівень `j = 0` ініціалізується копіюванням масиву: `N` операцій.
- Кожен наступний рівень `j ∈ [1, K]` вимагає рівно одного порівняння `min` на кожну клітинку:

```
Total_Min_Ops = ∑_{j=1}^{K} (N - 2^j + 1)
              = N · K - (2^(K + 1) - 2) + K                   [сумуємо окремо константи та степені двійки]
              ≤ N · log₂ N                                    [оскільки 2^(K + 1) > N]
```


## Некомутативні напівгрупи та порядок аргументів

Важливим тонким моментом алгебраїчного аналізу є питання **комутативності** (лат. *commutare* — змінювати місцями). Операція `⊕` називається комутативною, якщо `a ⊕ b = b ⊕ a`.

Операції `min`, `max`, `gcd`, `AND`, `OR` є як асоціативними, так і комутативними. Проте в загальній алгебрі існують ідемпотентні напівгрупи, які **не є комутативними** (так звані *некомутативні бенди*).

### Приклад лівого та правого нуля
Розглянемо операцію лівого вибору `a ⊕_L b = a`:
- Вона асоціативна: `(a ⊕_L b) ⊕_L c = a ⊕_L c = a`, та `a ⊕_L (b ⊕_L c) = a ⊕_L b = a`.
- Вона ідемпотентна: `a ⊕_L a = a`.
- Але вона не комутативна: `a ⊕_L b = a ≠ b = b ⊕_L a` (при `a ≠ b`).

Якщо операція `⊕` не є комутативною, обчислення через два перекривні блоки `ST[k][L] ⊕ ST[k][R - 2^k + 1]` вимагає особливої обережності: елементи в зоні перекриття `I₁ ∩ I₂` потрапляють у вираз двічі у певному порядку. 

Якщо напівгрупа є **прямокутним бендом** (де `a ⊕ b ⊕ a = a`), порядок дублювання елементів не руйнує тотожність лише за умови строгого збереження послідовності індексів. Проте для довільних некомутативних операцій (як-от множення невироджених матриць або композиція функцій) дублювання елементів перекриття у виразі `(A[L]...A[M]) · (A[M-d]...A[R])` не скорочується, оскільки множення матриць не є ідемпотентним.

## Алгебраїчний міст до константного часу без ідемпотентності: Disjoint Sparse Table

Щоб подолати обмеження ідемпотентності й отримати запити за час `O(1)` для **будь-яких асоціативних напівгруп** (наприклад, множення матриць або Range Sum без ділення/віднімання), у 2010-х роках було розроблено структуру **Disjoint Sparse Table** (розріджена таблиця неперетинних блоків).

### Конструкція префіксно-суфіксного розбиття
1. Масив розглядається як двійкове дерево відрізків висоти `log₂ N`.
2. На кожному рівні `j ∈ [1, log₂ N]` масив розбивається на блоки фіксованого розміру `2^j`.
3. Кожен такий блок ділиться навпіл на дві половини розміру `2^(j-1)`: ліву та праву, з центральною межею `M`.
4. Усередині кожної половини обчислюються:
   - **Суфіксні згортки** від точки `M - 1` ліворуч до початку блоку: `Suff[i] = A[i] ⊕ A[i+1] ⊕ ... ⊕ A[M-1]`.
   - **Префіксні згортки** від точки `M` праворуч до кінця блоку: `Pref[j] = A[M] ⊕ A[M+1] ⊕ ... ⊕ A[j]`.

### Константна теорема Disjoint-запиту
Для будь-якого відрізка `[L, R]`, якщо `L < R`, існує **найглибший рівень дерева `level`**, на якому індекси `L` та `R` потрапляють в один спільний блок розміру `2^level`, але опиняються по різні боки від його центральної межі `M`:

```
L < M ≤ R
```

Номер цього рівня визначається виключно операцією побітового XOR над індексами:

```
level = 31 - __builtin_clz(L ^ R)
```

Оскільки `[L, R]` розпадається на суфікс лівої половини `[L, M - 1]` та префікс правої половини `[M, R]`, точний результат запиту знаходиться рівно за **одну операцію `⊕` над двома передрахованими значеннями**:

```
Q(L, R) = Suff_level[L] ⊕ Pref_level[R]
```

Оскільки суфікс `[L, M-1]` та префікс `[M, R]` не мають жодного спільного елемента (`[L, M-1] ∩ [M, R] = ∅`), операція `⊕` **не вимагає ідемпотентності**. 

Це дає час запиту `O(1)` для будь-якої асоціативної напівгрупи при збереженні часу побудови `O(N log N)` та пам'яті `O(N log N)`.

## Підсумкова класифікація алгебраїчних вимог до структур даних

| Структура даних | Необхідні алгебраїчні аксіоми | Складність запиту | Складність побудови | Підтримка оновлення (динаміка) |
| :--- | :--- | :--- | :--- | :--- |
| **Таблиця розрідження (Sparse Table)** | Асоціативність + **Ідемпотентність** `(x ⊕ x = x)` | `O(1)` | `O(N log N)` | `O(N)` (лише статика) |
| **Таблиця розрідження (диз'юнктний запит)** | Тільки асоціативність | `O(log N)` | `O(N log N)` | `O(N)` (лише статика) |
| **Disjoint Sparse Table** | Тільки асоціативність (напівгрупа) | `O(1)` | `O(N log N)` | `O(N)` (лише статика) |
| **Префіксні суми (Prefix Sums)** | Асоціативність + **Обернений елемент (Абелева група)** | `O(1)` | `O(N)` | `O(N)` (лише статика) |
| **Відрізкове дерево (Segment Tree)** | Тільки асоціативність (напівгрупа) | `O(log N)` | `O(N)` | `O(log N)` (динамічна) |
| **Дерево Фенвіка (Fenwick Tree)** | Асоціативність + Комутативність + Обернений елемент | `O(log N)` | `O(N)` | `O(log N)` (динамічна) |

Ця строга математична категоризація показує, що вибір оптимальної структури даних для роботи з масивами визначається не вподобаннями програміста, а фундаментальними алгебраїчними властивостями обчислюваної операції.
