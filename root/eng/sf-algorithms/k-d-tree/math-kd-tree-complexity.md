# 🧮 Математичний аналіз складності та геометрія просторів високої вимірності

Математична теорія багатовимірних дерев пошуку спирається на три фундаментальні складові: дискретні рекурентні співвідношення розділення множин, комбінаторну геометрію ортогональних перетинів опуклих багатогранників та багатовимірний інтегральний аналіз гіперповерхонь у евклідовому просторі `R^k`. Нижче наведено строгі математичні виведення часових та просторових характеристик `k-d` дерева, а також геометричне доведення деградації алгоритмів у просторах високої вимірності.

## Топологічні інваріанти розбиття простору

Розглянемо евклідовий векторний простір `R^k` із канонічним базисом `e₀, e₁, ..., e_{k-1}` та ортогональною декартовою системою координат.

Кожен вузол `u` збалансованого `k-d` дерева асоціюється з відкритою або замкненою опуклою просторовою областю — `k`-вимірним вирівняним за осями паралелепіпедом (ортогональним брусом) `Cell(u) = ∏ᵢ₌₀ᵏ⁻¹ [Lᵢ(u), Rᵢ(u)]`, де `Lᵢ(u) ∈ R ∪ {-∞}`, `Rᵢ(u) ∈ R ∪ {+∞}`.

**Інваріант розбиття простору.** Нехай вузол `u` знаходиться на глибині `depth` в дереві та зберігає точку `P_u = (x₀, x₁, ..., x_{k-1})`. Віссю розбиття є координата `d = depth mod k`. Тоді:
1. Гіперплощина розбиття задається рівнянням `H_u = { x ∈ R^k | x_d = P_{u, d} }`.
2. Ліве дочірнє піддерево `left(u)` асоціюється з областю:
   `Cell(left(u)) = Cell(u) ∩ { x ∈ R^k | x_d ≤ P_{u, d} }`.
3. Праве дочірнє піддерево `right(u)` асоціюється з областю:
   `Cell(right(u)) = Cell(u) ∩ { x ∈ R^k | x_d > P_{u, d} }`.
4. Області дітей не перетинаються за внутрішніми точками (`int(Cell(left(u))) ∩ int(Cell(right(u))) = ∅`), а їхнє об'єднання повністю покриває батьківську область:
   `Cell(left(u)) ∪ Cell(right(u)) = Cell(u)`.

Завдяки цим чотирьом інваріантам система комірок на будь-якому фіксованому рівні глибини `h` утворює строго повне розбиття вихідного обмежувального паралелепіпеда всієї вибірки.

## Асимптотика побудови через лінійну селекцію медіани

Нехай задано скінченну множину `S ⊂ R^k` із `N` точок. Метою є побудова дерева мінімальної висоти, де кожен внутрішній вузол ділить підмножину точок на дві рівні за розміром частини.

**Лема про висоту збалансованого дерева.** Якщо на кожному кроці рекурсії як розділовий елемент обирається точна медіана підмножини за поточною координатою `d`, то максимальна глибина дерева `h(N)` для `N` точок задовольняє нерівність:

```
h(N) = ⌊log₂ N⌋
```

*Доведення.* При виборі медіани підмножина розміру `n` ділиться на ліву частину розміром `n_left = ⌊(n - 1) / 2⌋` та праву частину розміром `n_right = ⌈(n - 1) / 2⌉`. У найгіршому випадку розмір дочірньої підзадачі становить `n' ≤ ⌊n / 2⌋`. За індукцією, після `⌊log₂ N⌋` кроків розмір підмножини скорочується до 1 точки (листок дерева). Отже, шлях від кореня до будь-якого вузла містить не більше `⌊log₂ N⌋` ребер. Лему доведено.

### Рекурентне рівняння та метод підстановки

Для знаходження медіани невідсортованого масиву розміру `n` застосовується алгоритм Quickselect (розбиття Хоара) або алгоритм Блюма — Флойда — Пратта — Рівеста — Тарджана (медіана медіан), який гарантує лінійний час виконання `O(n)`.

Після знаходження медіани масив за час `O(n)` розпадається на дві частини однакового розміру `n / 2`. Рекурентне співвідношення для сумарного часу побудови `T(N)`:

```
T(N) = 2 · T(N / 2) + c · k · N
```

де константа `c > 0` враховує перестановку координат та лінійний прохід.

Розгорнемо рекуренсію по рівнях дерева глибини `h = log₂ N`:

```
T(N)
= 2 · T(N / 2) + c · k · N                       [рівень 0: 1 вузол розміру N]
= 2 · (2 · T(N / 4) + c · k · (N / 2)) + c · k · N  [підстановка виразу T(N/2)]
= 4 · T(N / 4) + 2 · c · k · N                   [рівень 1: 2 вузли розміру N/2]
= 8 · T(N / 8) + 3 · c · k · N                   [рівень 2: 4 вузли розміру N/4]
= 2ⁱ · T(N / 2ⁱ) + i · c · k · N                 [загальний стан для рівня i]
= N · T(1) + (log₂ N) · c · k · N                [підстановка i = log₂ N]
= O(k · N log N)                                 [фінальна асимптотична оцінка]
```

Таким чином, використання алгоритму швидкого вибору медіани забезпечує строгу верхню межу часу побудови `O(k · N log N)`. Просторова складність складає строго `O(k · N)` для зберігання масиву точок та зв'язків між вузлами.

## Складність ортогонального діапазонного пошуку

Задача ортогонального діапазонного пошуку полягає у вибірці всіх точок множини `S`, що потрапляють усередину `k`-вимірного паралелепіпеда `W = [a₀, b₀] × [a₁, b₁] × ... × [a_{k-1}, b_{k-1}]`.

Складність цього алгоритму визначається кількістю вузлів дерева, чиї просторові комірки `Cell(u)` мають непорожній перетин із геометричною межею вікна запиту `∂W`, але не містяться в ньому повністю.

### Двовимірний випадок (k = 2)

Розглянемо кількість комірок дерева, які може перетнути одна нескінченна ортогональна пряма `L: x = x_const`, паралельна осі `Y`.

1. **Рівень 0 (розбиття по X):** Пряма `L` лежить або ліворуч від точки розбиття `X_root`, або праворуч. Вона перетинає рівно одну з двох дочірніх областей рівня 1. Друга область лишається непорушною.
2. **Рівень 1 (розбиття по Y):** У вибраній області розбиття здійснюється горизонтальною прямою `Y = Y_split`. Вертикальна пряма `L` гарантовано перетинає обидві утворені підобласті (верхню і нижню).
3. **Рівень 2 (розбиття по X):** У кожній із двох перетнутих областей розбиття знову йде по осі `X`. Як і на рівні 0, пряма `L` перетинає лише одну з двох дочірніх підобластей у кожній гілці. Отже, із 4 підобластей рівня 2 пряма `L` перетинає рівно 2.

Таким чином, за кожні 2 рівні спуску по дереву (один повний цикл зміни осей `X → Y`) кількість перетнутих прямою областей зростає вдвічі, тоді як кількість точок у кожній такій області скорочується в 4 рази.

Складемо рекурентне рівняння для кількості перетнутих вузлів `Q(N)`:

```
Q(N) = 2 · Q(N / 4) + O(1)
```

Застосуємо основну теорему про рекурентні співвідношення (Master Theorem) для рівняння `Q(N) = a · Q(N / b) + f(N)`:
Параметри: `a = 2`, `b = 4`, вільний член `f(N) = O(1)`.

```
log_b a
= log₄ 2                                        [підстановка параметрів a=2, b=4]
= log₂(2) / log₂(4)                             [перехід до двійкової основи]
= 1 / 2                                         [оскільки log₂ 4 = 2]
```

Оскільки `f(N) = O(N^c)` з `c = 0 < 1/2`, спрацьовує перший випадок теореми:

```
Q(N)
= O(N^(log_b a))                                [перший випадок Master Theorem]
= O(N^(1/2))                                    [підстановка критичного показника]
= O(√N)                                         [фінальна асимптотика]
```

Оскільки прямокутне вікно `W` на площині обмежене чотирма відрізками, а всі точки всередині повністю покритих областей вивантажуються за час `O(M)`, де `M` — розмір вибірки відповідей, загальна часова складність діапазонного пошуку в `R²` становить строго:

```
T_range(N) = O(√N + M)
```

### Доведення для загального простору R^k

У `k`-вимірному просторі повний цикл зміни всіх координат займає `k` рівнів дерева. Розглянемо гіперплощину розмірності `k - 1`, ортогональну до однієї з осей (наприклад, `x₀ = c`).

- На кроці розбиття вздовж осі `x₀` гіперплощина потрапляє лише в одну з двох дочірніх півпросторів (множник перетинів 1).
- На кожному з решти `k - 1` кроків (розбиття по осях `x₁, x₂, ..., x_{k-1}`) гіперплощина перетинає обидві дочірні півпростори (множник перетинів 2 на кожен вимір).

Після спуску на `k` рівнів глибини кількість точок у піддереві зменшується в `2^k` разів, а сумарна кількість перетнутих гіперплощиною областей становить:

```
1 · 2 · 2 · ... · 2 = 2^(k-1)
```

Рекурентне співвідношення для `k` вимірів набуває вигляду:

```
Q(N) = 2^(k-1) · Q(N / 2^k) + O(1)
```

Обчислимо характеристичний показник степеня:

```
log_{2^k} (2^(k-1))
= (k - 1) · log₂(2) / ( k · log₂(2) )           [властивість логарифма частки]
= (k - 1) / k                                   [скорочення log₂ 2 = 1]
= 1 - 1 / k                                     [виділення цілої частини]
```

Застосовуючи основну теорему, отримуємо фундаментальну теорему складності ортогонального діапазонного пошуку в `k-d` деревах:

```
Q(N) = O(N^(1 - 1/k))
```

Враховуючи вивантаження `M` точок відповіді та `2k` гіперграней вікна запиту `W`, повний час виконання становить:

```
T_range(N) = O(k · N^(1 - 1/k) + M)
```

Аналіз граничної поведінки при зростанні вимірності `k`:
- `k = 2`: `1 - 1/2 = 1/2 ⇒ O(N^(0.5) + M) = O(√N + M)`.
- `k = 3`: `1 - 1/3 = 2/3 ⇒ O(N^(0.667) + M)`.
- `k = 4`: `1 - 1/4 = 3/4 ⇒ O(N^(0.75) + M)`.
- `k = 10`: `1 - 1/10 = 9/10 ⇒ O(N^(0.9) + M)`.
- `k → ∞`: `lim_{k→∞} (1 - 1/k) = 1 ⇒ O(N + M)`.

При високих вимірностях асимптотика діапазонного пошуку плавно вироджується у лінійний перебір `O(N)`.

## Геометрія гіперсфер та математичне доведення прокляття вимірності

Ефективність пошуку найближчого сусіда спирається на те, що радіус поточної знайденої кулі кандидатів `R_best` швидко зменшується і відсікає більшість розділових площин. Покажемо строго, чому у просторах високої вимірності ця геометрична властивість повністю руйнується.

### Аналітичний вираз об'єму k-вимірної кулі

Об'єм `k`-вимірної кулі радіуса `R` у просторі `R^k` обчислюється через кратний інтеграл:

```
V_k(R) = ∫_{||x|| ≤ R} dx₁ dx₂ ... dx_k
```

Переходячи до багатовимірних сферичних координат, отримуємо точну аналітичну формулу через гамма-функцію Ейлера `Γ(z)`:

```
V_k(R) = ( π^(k/2) / Γ(k/2 + 1) ) · R^k
```

де для цілих значень аргументу `Γ(n + 1) = n!`, а для напівцілих значень:

```
Γ(n + 1/2) = ( (2n - 1)!! / 2^n ) · √π
```

Об'єм описаного навколо цієї кулі `k`-вимірного гіперкуба з довжиною ребра `2R`:

```
V_cube(R) = (2 · R)^k = 2^k · R^k
```

### Доведення прямування частки об'єму до нуля

Знайдемо частку об'єму гіперкуба, яку займає вписана гіперсфера:

```
η_k
= V_k(R) / V_cube(R)                            [означення відношення об'ємів]
= ( (π^(k/2) / Γ(k/2 + 1)) · R^k ) / ( 2^k · R^k ) [підстановка аналітичних формул]
= π^(k/2) / ( 2^k · Γ(k/2 + 1) )                [скорочення радіуса R^k]
```

Для оцінки поведінки знаменника при `k → ∞` застосуємо формулу Стірлінга для гамма-функції:

```
Γ(z + 1) ≈ √(2π · z) · (z / e)^z
```

Підставимо `z = k / 2`:

```
Γ(k/2 + 1) ≈ √(π · k) · ( k / (2 · e) )^(k/2)
```

Підставимо це наближення у формулу для `η_k`:

```
η_k
≈ π^(k/2) / ( 2^k · √(π · k) · ( k / (2 · e) )^(k/2) )  [підстановка формули Стірлінга]
= ( 1 / √(π · k) ) · ( π / ( 4 · (k / (2 · e)) ) )^(k/2) [групування степенів k/2]
= ( 1 / √(π · k) ) · ( (2 · π · e) / (4 · k) )^(k/2)     [перетворення знаменника]
= ( 1 / √(π · k) ) · ( (π · e) / (2 · k) )^(k/2)         [скорочення коефіцієнтів]
```

Оскільки чисельник підстепеневого виразу є фіксованою константою `π · e ≈ 3.14159 · 2.71828 ≈ 8.5397`, а знаменник `2 · k` лінійно зростає, для будь-якого `k > 5`:

```
(π · e) / (2 · k) < 1
```

Звідси випливає фундаментальна гранична теорема:

```
lim_{k → ∞} η_k = lim_{k → ∞} ( V_k(R) / V_cube(R) ) = 0
```

Швидкість прямування до нуля є факторіальною (швидшою за будь-яку експоненту). Уже при `k = 20` частка об'єму вписаної кулі становить `η₂₀ ≈ 2.46 · 10⁻⁸`, а понад `99.999997%` об'єму гіперкуба зосереджено у його віддалених вершинах.

### Теорема про концентрацію відстаней

Нехай `X = (X₁, ..., X_k)` та `Y = (Y₁, ..., Y_k)` — дві незалежні випадкові точки, рівномірно розподілені в одиничному гіперкубі `[0, 1]^k`.

Квадрат евклідової відстані між ними є сумою `k` незалежних однаково розподілених випадкових величин:

```
D²(X, Y) = ∑ᵢ₌₁ᵏ (Xᵢ - Yᵢ)²
```

Обчислимо математичне сподівання різниці координат двох незалежних рівномірних величин `U, V ~ Uniform(0, 1)`:
Густина різниці `Z = U - V` має трикутний розподіл на відрізку `[-1, 1]`: `f_Z(z) = 1 - |z|`.

```
E[(U - V)²] = ∫_{-1}^{1} z² · (1 - |z|) dz = 2 · ∫₀¹ (z² - z³) dz = 2 · (1/3 - 1/4) = 1/6
```

Обчислимо дисперсію квадрата різниці:

```
E[(U - V)⁴] = 2 · ∫₀¹ (z⁴ - z⁵) dz = 2 · (1/5 - 1/6) = 1/15
Var((U - V)²) = E[(U - V)⁴] - (E[(U - V)²])² = 1/15 - (1/6)² = 1/15 - 1/36 = 7/180
```

За центральною граничною теоремою:

```
E[D²] = k / 6
Var(D²) = k · (7 / 180)
```

Розглянемо стандартне відхилення відстані `D = √(D²)`:

```
σ(D) / E[D] ≈ ( √(Var(D²)) / (2 · E[D²]) ) = ( √(k · 7/180) / (2 · k/6) ) = √(7/5) / √(k) ≈ 1.183 / √k
```

При `k → ∞` відносна варіація відстаней спадає як `O(1 / √k)`:

```
lim_{k → ∞} ( σ(D) / E[D] ) = 0
```

**Наслідок для відсікання гілок.** У високих вимірностях евклідова відстань між будь-якими двома випадковими точками асимптотично прямує до фіксованого значення `√(k / 6)`. 

Відстань від точки запиту `Q` до її найближчого сусіда `P_nearest` практично не відрізняється від відстані до найвіддаленішої точки:

```
lim_{k → ∞} ( (dist_max(Q) - dist_min(Q)) / dist_min(Q) ) = 0
```

Через це радіус сфери кандидатів `R_best` стає рівним `≈ √(k / 6)`. Проте проекція цієї сфери на будь-яку координату `d` має довжину `R_best`, що перевищує відстань між сусідніми точками вибірки. Умова геометричного відсікання `|Q_d - P_{u, d}| ≥ R_best` не виконується майже для жодного вузла дерева, що змушує алгоритм пошуку найближчого сусіда обходити `O(N)` вузлів, повністю знищуючи логарифмічну ефективність `k-d` дерева.
