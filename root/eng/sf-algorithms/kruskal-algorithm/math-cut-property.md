# 🧮 Математичне обґрунтування: лема про безпечне ребро та теорія розрізів

Коректність жадібних алгоритмів побудови мінімального кістякового дерева (MST) не є очевидною: локально оптимальний вибір найдешевшого ребра взагалі кажучи не гарантує глобальної оптимальності для довільних оптимізаційних задач. У випадку пошуку мінімального кістяка збіжність до точного глобального мінімуму забезпечується двома фундаментальними дуальними твердженнями теорії графів: **властивістю розрізу (Cut Property)** та **властивістю циклу (Cycle Property)**, а також алгебраїчною структурою графових матроїдів.

## 1. Формальні означення та постановка задачі

Нехай `G = (V, E)` — скінченний неорієнтований зв'язаний граф без петель, де `V` — множина вершин (`|V| = n`), а `E` — множина ребер (`|E| = m`).
Кожному ребру `e = (u, v) ∈ E` зіставлено дійсну вагу `w(e) ∈ ℝ`.

Кістяковим деревом (Spanning Tree) графа `G` називається ациклічний зв'язаний підграф `T = (V, E_T)`, який містить усі вершини графа `V` і рівно `n - 1` ребро (`|E_T| = n - 1`).
Сумарна вага кістякового дерева `w(T)` визначається як сума ваг усіх ребер, що входять до нього:

```
w(T) = ∑ w(e)          [підсумовування за всіма ребрами e ∈ E_T]
```

Задача полягає в знаходженні такого кістякового дерева `T*`, для якого значення `w(T*)` є мінімальним серед усіх можливих кістякових дерев множини `𝒯(G)`:

```
w(T*) = min { w(T) : T ∈ 𝒯(G) }
```

## 2. Властивість розрізу (Cut Property)

**Означення розрізу.** Розрізом `(S, V \ S)` графа `G = (V, E)` називається розбиття множини вершин `V` на дві непорожні підмножини, що не перетинаються: `S ⊂ V` та `V \ S`.

Ребро `e = (u, v) ∈ E` **перетинає розріз** `(S, V \ S)`, якщо один його кінець належить `S`, а інший — `V \ S` (тобто `u ∈ S` та `v ∈ V \ S`). Множина всіх ребер, що перетинають розріз, позначається як `δ(S)`.

Множина ребер `A ⊆ E` **поважає розріз** `(S, V \ S)`, якщо жодне ребро з `A` не перетинає цей розріз (тобто `A ∩ δ(S) = ∅`).

Ребро `e*` називається **безпечним (safe edge)** для підмножини ребер `A` майбутнього кістяка, якщо множина `A ∪ {e*}` також є підмножиною деякого мінімального кістякового дерева.

### Теорема 1 (Лема про безпечне ребро розрізу)
Нехай `G = (V, E)` — зважений зв'язаний граф, `A` — підмножина деякого мінімального кістякового дерева `T*`, а `(S, V \ S)` — довільний розріз графа `G`, який поважає множину `A`.
Якщо `e* = (u, v)` є ребром найменшої ваги серед усіх ребер, що перетинають розріз `(S, V \ S)`:

```
w(e*) = min { w(e) : e ∈ δ(S) }
```

тоді ребро `e*` є безпечним для `A`, тобто існує мінімальне кістякове дерево `T'`, яке містить `A ∪ {e*}`.

### Доведення теореми методом обміну (Exchange Argument)
Розглянемо вихідне мінімальне кістякове дерево `T*`, яке за припущенням містить множину ребер `A` (`A ⊆ T*`).

1. **Випадок 1:** Якщо `e* ∈ T*`, твердження доведено автоматично, оскільки `A ∪ {e*} ⊆ T*`.

2. **Випадок 2:** Припустимо, що `e* ∉ T*`.
Оскільки `T*` є кістяковим деревом, воно зв'язує всі вершини графа. Отже, додавання ребра `e* = (u, v)` до `T*` створює рівно один простий замкнений цикл `C` у графі `T* ∪ {e*}`.

Оскільки вершина `u ∈ S`, а вершина `v ∈ V \ S`, цикл `C` починається в `S`, переходить у `V \ S` через ребро `e*` і мусить повернутися назад із `V \ S` у підмножину `S`, щоб замкнутися.
Отже, у циклі `C` обов'язково існує принаймні ще одне ребро `e' = (x, y) ≠ e*`, яке також перетинає розріз `(S, V \ S)`, тобто `e' ∈ C ∩ δ(S)`.

Оскільки за умовою теореми розріз поважає множину `A` (`A ∩ δ(S) = ∅`), а ребро `e' ∈ δ(S)`, то ребро `e'` не може належати `A` (`e' ∉ A`).

Сконструюємо новий граф `T' = (T* \ {e'}) ∪ {e*}` шляхом видалення ребра `e'` та додавання ребра `e*`.
Перевіримо властивості отриманого графа `T'`:
- Видалення ребра `e'` розриває цикл `C`, тому граф `T'` залишається ациклічним.
- Граф `T'` містить рівно `(n - 1) - 1 + 1 = n - 1` ребро і є зв'язним, отже `T'` є коректним кістяковим деревом.
- Оскільки `A ⊆ T*` і `e' ∉ A`, а ми додали `e*`, маємо `A ∪ {e*} ⊆ T'`.

Порівняємо сумарну вагу дерев `w(T')` та `w(T*)`:

```
w(T') - w(T*)
= w(T* \ {e'} ∪ {e*}) - w(T*)     [за конструкцією дерева T']
= w(T*) - w(e') + w(e*) - w(T*)    [адитивність сумарної ваги]
= w(e*) - w(e')                    [скорочення доданків w(T*)]
```

Оскільки `e*` є ребром мінімальної ваги в перетині розрізу `δ(S)`, а `e' ∈ δ(S)`, виконується нерівність:

```
w(e*) ≤ w(e')
```

Звідси отримуємо:

```
w(T') - w(T*) = w(e*) - w(e') ≤ 0
w(T') ≤ w(T*)
```

Оскільки `T*` було мінімальним кістяковим деревом (`w(T*)` мінімальна серед усіх дерев), нерівність `w(T') < w(T*)` неможлива. Отже:

```
w(T') = w(T*)
```

Це доводить, що `T'` є мінімальним кістяковим деревом, яке містить `A ∪ {e*}`. Таким чином, жадібний вибір ребра `e*` є безпечним. ■

## 3. Властивість циклу (Cycle Property)

Властивість циклу є дуальною до властивості розрізу та визначає умову, за якої ребро гарантовано можна відкинути.

### Теорема 2 (Властивість циклу)
Нехай `C` — довільний простий замкнений цикл у зваженому графі `G = (V, E)`.
Якщо ребро `e_max ∈ C` має строго більшу вагу, ніж будь-яке інше ребро цього циклу:

```
∀ e ∈ C \ {e_max} : w(e_max) > w(e)
```

тоді ребро `e_max` не належить жодному мінімальному кістяковому дереву графа `G`.

### Доведення
Припустимо від супротивного, що існує мінімальне кістякове дерево `T*`, яке містить ребро `e_max` (`e_max ∈ T*`).

Видалення ребра `e_max` розбиває дерево `T*` на дві незв'язні компоненти, породжуючи розріз `(S, V \ S)`.
Кінці ребра `e_max = (u, v)` лежать у різних компонентах розбиття: `u ∈ S`, `v ∈ V \ S`.

Оскільки ребра циклу `C \ {e_max}` утворюють альтернативний простий шлях між `u` та `v`, серед них обов'язково існує принаймні одне ребро `e' = (x, y) ≠ e_max`, яке також перетинає розріз `(S, V \ S)`.

Сконструюємо нове кістякове дерево `T' = (T* \ {e_max}) ∪ {e'}`. Обчислимо його вагу:

```
w(T')
= w(T*) - w(e_max) + w(e')         [заміна важкого ребра на легше]
```

Оскільки за умовою теореми `w(e_max) > w(e')`, маємо:

```
w(T') < w(T*)
```

Отримано суперечність із тим, що дерево `T*` має мінімальну вагу. Отже, ребро `e_max` не може належати жодному мінімальному кістяковому дереву. ■

## 4. Зв'язок із теорією матроїдів (Графові матроїди)

Жадібний вибір алгоритму Краскала є прямим проявом теореми Радо–Едмондса для матроїдів.

**Графовий матроїд (Graphic Matroid)** `M(G) = (E, ℐ)` над множиною ребер `E` визначається системою незалежних множин `ℐ`:
- Множина ребер `A ⊆ E` є незалежною (`A ∈ ℐ`) тоді й лише тоді, коли підграф `(V, A)` є ациклічним (тобто є лісом).
- Базами матроїда `M(G)` є максимальні за включенням незалежні множини — це саме кістякові ліси (або кістякові дерева для зв'язаного графа), які містять рівно `|V| - 1` ребро.

Згідно з теоремою Едмондса (1971), жадібний алгоритм, який на кожному кроці додає елемент мінімальної ваги зі збереженням властивості незалежності (`A ∪ {e} ∈ ℐ`), знаходить базу мінімальної сумарної ваги для будь-якого матроїда. Оскільки перевірка ациклічності в алгоритмі Краскала еквівалентна перевірці належності до `ℐ`, глобальна оптимальність алгоритму Краскала безпосередньо випливає з матроїдної структури ациклічних підмножин ребер.

## 5. Теорема про єдиність мінімального кістяка

### Теорема 3
Якщо у зваженому зв'язаному графі `G = (V, E)` усі ваги ребер є попарно різними:

```
∀ e₁, e₂ ∈ E, e₁ ≠ e₂ ⇒ w(e₁) ≠ w(e₂)
```

тоді мінімальне кістякове дерево графа `G` є єдиним.

### Доведення
Нехай існують два різних мінімальних кістякових дерева `T₁` та `T₂` (`T₁ ≠ T₂`) з однаковою мінімальною вагою `w(T₁) = w(T*) = w(T₂)`.
Розглянемо симетричну різницю множин ребер `(T₁ \ T₂) ∪ (T₂ \ T₁) ≠ ∅`.
Оскільки всі ваги ребер у графі попарно різні, у цій множині існує єдине ребро найменшої ваги `e* = min { w(e) : e ∈ (T₁ \ T₂) ∪ (T₂ \ T₁) }`.

Без обмеження загальності припустимо, що `e* ∈ T₁ \ T₂`.
Додамо ребро `e*` до дерева `T₂`. Це створить цикл `C ⊆ T₂ ∪ {e*}`.
У цьому циклі `C` обов'язково є ребро `e' ∈ T₂ \ T₁`, яке перетинає той самий розріз, що й `e*`.

За вибором ребра `e*` як мінімального в симетричній різниці, маємо `w(e*) < w(e')`.
Замінюючи `e'` на `e*` у дереві `T₂`, отримуємо нове дерево `T₂' = (T₂ \ {e'}) ∪ {e*}` з вагою:

```
w(T₂') = w(T₂) - w(e') + w(e*) < w(T₂)
```

Це суперечить мінімальності дерева `T₂`. Отже, при попарно різних вагах ребер мінімальне кістякове дерево завжди єдине. ■
