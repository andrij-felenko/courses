# Програмний інтерфейс черги робіт у RTOS

Програмний інтерфейс черги робіт (@@en|work queue API@@) надає надійний механізм передачі обчислювального завдання з контексту апаратного переривання або витісняльного потоку у спільний фоновий потік ядра. Замість виділення окремого стека пам'яті для кожної периферійної задачі система використовує одну постійну задачу-виконавець (англ. *worker task*), яка вичитує завдання з черги повідомлень і послідовно викликає зареєстровані користувацькі функції. Інтерфейс гарантує захист від пошкодження списку при одночасному доступі та запобігає переповненню пам'яті.

## Структури даних та дескриптор роботи

Базовим елементом диспетчеризації є структура елемента роботи `work_item_t`. Вона містить покажчик на функцію обробки, користувацький контекст та атомарні системні прапорці стану:

```c
typedef void (*work_handler_t)(void *arg);

typedef struct work_item {
    work_handler_t handler;       // Покажчик на функцію відкладеної обробки
    void *arg;                    // Користувацький контекст або покажчик на дані
    volatile uint32_t flags;      // Прапорці стану: біт зайнятості (BUSY), очікування (PENDING)
    struct work_item *next;       // Вказівник зв'язку в черзі
} work_item_t;

typedef struct {
    void *queue_handle;           // Внутрішній дескриптор системної черги RTOS
    void *worker_task_handle;     // Дескриптор потоку-виконавця
    uint16_t capacity;            // Максимальна місткість черги
    volatile uint16_t count;      // Поточна кількість робіт у черзі
} work_queue_t;
```

## Сценарії використання інтерфейсу

### 1. Постановка роботи з контексту переривання (ISR)
Обробник переривання лінії готовності датчика виставляє роботу в системну чергу для виконання важкого зчитування по шині I2C:

```c
static work_item_t sensor_work;

void EXTI_IRQHandler(void) {
    BaseType_t xHigherPriorityTaskWoken = pdFALSE;
    
    // Скидання апаратного прапорця переривання
    EXTI->PR = EXTI_PR_PR0;
    
    // Постановка роботи у чергу з перевіркою потреби у витісненні
    work_submit_from_isr(&sys_work_queue, &sensor_work, &xHigherPriorityTaskWoken);
    
    // Негайне перемикання контексту, якщо потік черги пріоритетніший
    portYIELD_FROM_ISR(xHigherPriorityTaskWoken);
}
```

### 2. Ініціалізація та скасування роботи
Підготовка елемента роботи перед першим використанням та безпечне вилучення при зупинці модуля:

```c
void sensor_init(void) {
    work_init(&sensor_work, process_sensor_data, (void *)&sensor_config);
}

void sensor_deinit(void) {
    work_cancel(&sensor_work);
}
```

## Довідка функцій та статусів

### Статусні прапорці елемента роботи

| Прапорець | Бітова маска | Опис стану елемента роботи |
| :--- | :--- | :--- |
| `WORK_FLAG_PENDING` | `0x0001` | Робота поставлена в чергу і очікує виклику диспетчером |
| `WORK_FLAG_RUNNING` | `0x0002` | Функція-обробник виконується в потоці робітника в цей момент |
| `WORK_FLAG_CANCELLED` | `0x0004` | Роботу позначено як скасовану; диспетчер пропустить її виконання |

### Системні виклики

#### `void work_init(work_item_t *work, work_handler_t handler, void *arg)`
- **Призначення**: ініціалізує дескриптор роботи, прив'язуючи функцію зворотного виклику та контекст.
- **Параметри**:
  - `work` — покажчик на користувацьку структуру роботи (виділену статично або в пулі).
  - `handler` — покажчик на функцію з сигнатурою `void (*)(void *)`.
  - `arg` — довільний покажчик на дані, що передається у функцію.
- **Інваріанти**: прапорці `flags` скидаються в 0; виклик дозволено лише з потокового контексту.

#### `bool work_submit(work_queue_t *wq, work_item_t *work)`
- **Призначення**: додає елемент роботи в кінець черги для виконання потоком робітника.
- **Повертає**:
  - `true` — роботу успішно поставлено в чергу.
  - `false` — черга заповнена або робота вже перебуває в черзі (`WORK_FLAG_PENDING`).
- **Поведінка при коалесценції**: якщо робота вже чекає виконання, повторний виклик не додає дублікат у список, запобігаючи пошкодженню вказівників.

#### `bool work_submit_from_isr(work_queue_t *wq, work_item_t *work, BaseType_t *pxHigherPriorityTaskWoken)`
- **Призначення**: безпечне додавання роботи в чергу з контексту обробника апаратного переривання.
- **Параметри**:
  - `pxHigherPriorityTaskWoken` — покажчик на прапорець витіснення; встановлюється в `pdTRUE`, якщо пріоритет потоку черги вищий за перерваний потік.
- **Обмеження**: функція є повністю неблокувальною і гарантовано завершується за детермінований час `O(1)`.

#### `bool work_cancel(work_item_t *work)`
- **Призначення**: спроба вилучити роботу з черги або запобігти її виклику.
- **Повертає**: `true`, якщо роботу скасовано до початку її виконання; `false`, якщо робота вже виконується або не була в черзі.

#### `bool work_is_busy(const work_item_t *work)`
- **Призначення**: перевірка, чи робота очікує в черзі або виконується в даний момент.
- **Повертає**: `true`, якщо встановлено будь-який із бітів `PENDING` чи `RUNNING`.
