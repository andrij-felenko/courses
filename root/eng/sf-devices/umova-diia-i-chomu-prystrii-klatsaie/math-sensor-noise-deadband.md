# 🧮 Математика шуму АЦП та мінімальна ширина мертвої зони

Коли неперервний аналоговий сигнал перетворюється на послідовність цифрових кодів [АЦП](root:hw-analog/adc), кожне окреме вимірювання містить випадкову стохастичну похибку. Навіть коли вимірювана фізична величина — температура стабілізованого термостата, гідростатичний тиск у закритій ємності чи напруга на виводах акумуляторної батареї — залишається абсолютно незмінною в часі, послідовні зчитані коди мікроконтролера неперервно флуктують.

Якщо ширина мертвої зони гістерезису (англ. *deadband*) вибрана меншою за амплітудний розмах цих випадкових флуктуацій або порівнянна з ним, пороговий компаратор неминуче перемикатиметься від випадкових сплесків шуму. Щоб гарантувати надійність порогового предикату, ширину мертвої зони розраховують на основі строгої теорії ймовірностей та математичної статистики випадкових процесів.

## Складові шуму вимірювального тракту

Сумарна похибка окремого вибіркового значення формується як композиція двох фізично незалежних стохастичних процесів: цифрового шуму квантування аналого-цифрового перетворювача та сумарного аналогового шуму первинного сенсора, резистивних кіл і вхідних підсилювачів.

### 1. Шум квантування АЦП

При перетворенні неперервної напруги в `N`-розрядне ціле число виникає невизначеність округлення в межах одного молодшого значущого розряду (англ. *Least Significant Bit*, LSB). Для повної шкали опорної напруги `V_ref` величина кванта визначається співвідношенням:

```
LSB = V_ref / (2^N - 1)
```

Помилка квантування `e_q` є випадковою величиною, розподіленою рівномірно на симетричному інтервалі `[-0.5·LSB, +0.5·LSB]`. Її густина ймовірності становить `p(e_q) = 1 / LSB`.

Середньоквадратичне відхилення (RMS, `σ_q`) шуму квантування визначається через інтеграл дисперсії:

```
σ_q² = ∫[від -LSB/2 до +LSB/2] e_q² · (1 / LSB) de_q   [інтеграл дисперсії рівномірного розподілу]
     = (1 / LSB) · [e_q³ / 3] (від -LSB/2 до +LSB/2)   [первісна степеневої функції]
     = (1 / LSB) · (LSB³ / 24 - (-LSB³ / 24))          [підстановка меж інтегрування]
     = (1 / LSB) · (2 · LSB³ / 24)                     [спрощення різниці дробів]
     = LSB² / 12                                       [теоретична дисперсія квантування]

σ_q  = √(LSB² / 12)                                    [добування квадратного кореня]
     = LSB / √12                                       [винесення LSB з-під кореня]
     ≈ 0.288675 · LSB                                  [числовий коефіцієнт квантового шуму]
```

### 2. Аналоговий шум сенсора та операційного тракту

Тепловий шум Джонсона-Найквіста на резистивних елементах, низькочастотний флікер-шум `1/f` напівпровідникових підсилювачів та електромагнітні наведення від силових кіл формують випадковий процес із нормальним (гаусовим) розподілом з нульовим математичним сподіванням та дисперсією `σ_analog²`.

### 3. Результуючий середньоквадратичний шум тракту

Оскільки шум квантування та тепловий аналоговий шум породжуються різними фізичними явищами, вони є взаємно некорельованими та статистично незалежними. Відповідно до теореми про дисперсію суми незалежних випадкових величин, їхні дисперсії додаються:

```
σ_total² = σ_analog² + σ_q²                           [додавання дисперсій незалежних шумів]
σ_total  = √(σ_analog² + σ_q²)                        [результуючий RMS шум тракту]
```

Завдяки центральній граничній теоремі сума багатьох незалежних мікрошумів формує результуючий розподіл, що з високою точністю описується класичною функцією густини ймовірності Гауса `p(x)`:

```
p(x) = (1 / (σ_total · √(2π))) · e^(-(x - μ)² / (2·σ_total²))
```

де `μ` — істинне середнє значення фізичної величини.

## Ймовірність помилкового перемикання та виведення правила 6σ

Припустимо найнесприятливіший режим експлуатації: фізична величина зупинилася точно на нижньому порозі перемикання `T_low`. Автомат перебуває у вимкненому стані `OFF`.

Щоб випадкова флуктуація шуму призвела до хибного перемикання компаратора в активний стан `ON`, миттєвий сплеск шуму `n[k]` повинен подолати всю відстань між двома порогами — тобто ширину мертвої зони:

```
Δ = T_high - T_low
```

Ймовірність `P(помилки)` того, що окрема гаусова випадкова величина з нульовим середнім та стандартним відхиленням `σ_total` перевищить додатне зміщення `Δ`, описується інтегралом хвоста розподілу (Q-функцією):

```
P(помилки) = Q(Δ / σ_total)
           = ∫[від Δ/σ_total до ∞] (1 / √(2π)) · e^(-u² / 2) du
```

Оцінимо залежність частоти виникнення хибних спрацьовувань від кратності відношення `k_σ = Δ / σ_total`:

| Кратність мертвої зони k_σ = Δ / σ | Ймовірність одного хибного викиду P | Середня кількість відліків між викидами (1 / P) |
|---|---|---|
| `1.0·σ` | 1.587 · 10⁻¹ (15.87 %) | ~6 відліків |
| `2.0·σ` | 2.275 · 10⁻² (2.28 %) | ~44 відліки |
| `3.0·σ` | 1.350 · 10⁻³ (0.135 %) | ~740 відліків |
| `4.0·σ` | 3.167 · 10⁻⁵ (0.00317 %) | ~31 570 відліків |
| `5.0·σ` | 2.867 · 10⁻⁷ | ~3 488 000 відліків |
| `6.0·σ` | 9.866 · 10⁻¹⁰ | ~1 013 594 000 відліків |
| `7.0·σ` | 1.280 · 10⁻¹² | ~7.81 · 10¹¹ відліків |
| `8.0·σ` | 6.221 · 10⁻¹⁶ | ~1.60 · 10¹⁵ відліків |

Якщо система виконує опитування сенсора в головному циклі або таймерному перериванні із типовою промисловою частотою `f_s = 1000 Гц` (1000 вимірювань на секунду), середній час безвідмовної роботи до першого хибного спрацьовування (англ. *Mean Time To False trigger*, MTTF) обчислюється як:

```
MTTF = (1 / P) / f_s
```

- При `Δ = 3·σ`: `MTTF = 740 / 1000 = 0.74 секунди`. Пристрій зазнає безперервного брязкоту, попри наявність номінальної мертвої зони.
- При `Δ = 4·σ`: `MTTF = 31570 / 1000 ≈ 31.6 секунди`. Реле клацає кожні пів хвилини, руйнуючи контакти.
- При `Δ = 6·σ`: `MTTF = 1.013·10⁹ / 1000 ≈ 1 013 594 секунди ≈ 11.73 доби`. Одиничні рідкісні збої за тривалої роботи.
- При `Δ = 8·σ`: `MTTF = 1.60·10¹⁵ / 1000 = 1.60·10¹² секунд ≈ 50 990 років`. Повна гарантована стійкість до випадкових шумів протягом усього життєвого циклу виробу.

Звідси випливає фундаментальна інженерна вимога: **мінімальна ширина мертвої зони гістерезису для автономних пристроїв повинна задовольняти нерівність `Δ ≥ 6·σ_total`, а для відповідального промислового та медичного обладнання — `Δ ≥ 8·σ_total`**.

## Зниження шуму через осереднення (Oversampling)

Якщо технологічний регламент вимагає підтримувати параметр у надзвичайно вузькому коридорі `Δ_req`, і виявляється, що `Δ_req < 6·σ_total`, безпосередньо звужувати мертву зону гістерезису категорично заборонено — це миттєво поверне брязкіт контактів.

Єдиний інженерний вихід у такій ситуації — попереднє зменшення дисперсії шуму `σ_total` за допомогою математичного осереднення послідовних вибірок (англ. *oversampling and averaging*).

Якщо обчислити середнє арифметичне з `M` незалежних послідовних вимірювань:

```
x_avg = (1 / M) · ∑[i=1..M] x[i]
```

то математичне сподівання шуму залишається нульовим, а результуюче стандартне відхилення знижується пропорційно кореню з кількості накопичених відліків:

```
σ_filtered = σ_total / √M
```

Кожне чотирикратне збільшення вибірки осереднення (`M = 4`) зменшує середньоквадратичний шум удвічі та еквівалентне додаванню одного додаткового ефективного біта розрядності (ENOB) до шкали [АЦП](root:hw-analog/adc).

## Покроковий розрахунок параметрів гістерезису: реальний приклад

Проведемо повний інженерний розрахунок конфігурації гістерезисного регулятора температури для промислової сушильної камери.

### Вихідні фізичні та апаратні параметри:
1. Опорна напруга перетворювача: `V_ref = 3.300 В`.
2. Розрядність АЦП мікроконтролера: `N = 12 біт` (діапазон кодів `0 .. 4095`).
3. Коефіцієнт передачі лінійного термоперетворювача: `S = 10.0 мВ / °C` (напруга зростає на 10 мВ на кожен градус Цельсія).
4. Результат осцилографічного вимірювання шуму спокою на вході: розмах пік-пік `V_noise_pp = 18.0 мВ` для вибірки обсягом 10 000 точок.
5. Частота запуску контрольного циклу: `f_s = 100 Гц`.

### Крок 1. Розрахунок роздільної здатності АЦП та шуму квантування

```
LSB = V_ref / (2^N - 1)                               [формула ціни молодшого розряду]
    = 3300.0 мВ / 4095                                [підстановка напруги та розрядності]
    ≈ 0.80586 мВ                                      [величина кванта напруги]

σ_q = LSB / √12                                       [теоретичний RMS шуму квантування]
    = 0.80586 мВ / 3.46410                            [підстановка значення кванта LSB]
    ≈ 0.23263 мВ                                      [середньоквадратичний шум квантування]
```

### Крок 2. Оцінка середньоквадратичного аналогового шуму

Для вибірки обсягом `10 000` відліків емпіричний розмах шуму від піка до піка `V_noise_pp` охоплює приблизно `6·σ_analog` (довірчий інтервал 99.73 %):

```
σ_analog = V_noise_pp / 6                             [правило 6σ: оцінка RMS за розмахом пік-пік]
         = 18.0 мВ / 6                                [підстановка виміряного розмаху напруги]
         = 3.000 мВ                                   [середньоквадратичний аналоговий шум]
```

### Крок 3. Розрахунок повного RMS шуму вимірювального каналу

```
σ_total = √(σ_analog² + σ_q²)                         [додавання дисперсій незалежних компонент]
        = √(3.000² + 0.23263²)                        [підстановка аналогового та квантового RMS]
        = √(9.0000 + 0.0541)                          [обчислення суми квадратів]
        = √9.0541                                     [проміжне значення під коренем]
        ≈ 3.0090 мВ                                   [повний середньоквадратичний шум каналу]
```

Переведемо отриманий рівень шуму у фізичні одиниці вимірюваної температури за допомогою коефіцієнта чутливості сенсора `S`:

```
σ_temp = σ_total / S                                  [перевід напруги шуму в градуси]
       = 3.0090 мВ / (10.0 мВ / °C)                   [ділення на чутливість термодавача]
       ≈ 0.3009 °C                                    [еквівалентний температурний шум]
```

### Крок 4. Розрахунок мінімально допустимої ширини мертвої зони (критерій 6σ)

```
Δ_min_volts = 6 · σ_total                             [застосування критерію надійності 6σ]
            = 6 · 3.0090 мВ                           [множення повного RMS шуму]
            ≈ 18.054 мВ                               [мінімальна мертва зона в мілівольтах]

Δ_min_temp  = Δ_min_volts / S                         [перерахунок мертвої зони в градуси]
            = 18.054 мВ / (10.0 мВ / °C)              [ділення на крутизну характеристики]
            ≈ 1.805 °C                                [мінімальна мертва зона температури]

Δ_min_adc   = Δ_min_volts / LSB                       [перерахунок у кванти АЦП]
            = 18.054 мВ / 0.80586 мВ                  [ділення на ціну одного кванта]
            ≈ 22.40 → 23 кванти                       [округлення вгору до цілого LSB]
```

### Крок 5. Конфігурація порогових уставок

Якщо цільова робоча температура сушильної камери становить `SP = 60.0 °C` (що відповідає коду АЦП `Code_SP = 60.0°C · 10 мВ/°C / 0.80586 мВ ≈ 745 квантів`), то безпечні порогові значення для цілочисельного предикату нагрівача дорівнюють:

```
T_high = SP + (Δ_min_temp / 2)                        [формула верхньої межі вимкнення]
       = 60.0 °C + 0.903 °C                           [додавання половини мертвої зони]
       ≈ 60.9 °C  (756 квантів АЦП)                   [поріг вимкнення ТЕНів]

T_low  = SP - (Δ_min_temp / 2)                        [формула нижньої межі ввімкнення]
       = 60.0 °C - 0.903 °C                           [віднімання половини мертвої зони]
       ≈ 59.1 °C  (733 кванти АЦП)                    [поріг увімкнення ТЕНів]
```

Вибір ширини гістерезису менше `1.81 °C` (або менше 23 квантів АЦП) для даного вимірювального тракту призведе до гарантованого брязкоту силових реле через випадкові сплески теплового шуму.
