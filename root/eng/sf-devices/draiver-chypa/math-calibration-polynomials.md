# 🧮 Математика калібрувальних поліномів: нелінійність, інтерполяція та фіксована кома

Кремнієвий вимірювальний елемент мікроелектромеханічних систем (MEMS, від англ. *microelectromechanical systems*) ніколи не генерує електричний сигнал, строго пропорційний вимірюваній фізичній величині. П'єзорезистивні тензорезистори мембрани барометра чи мікроскопічні обкладки ємнісного сенсора вологості мають виражену нелінійність передавальної характеристики та колосальний паразитарний температурний коефіцієнт опору (TCR, від англ. *thermal coefficient of resistance*). Якщо зчитати 20-бітне значення аналого-цифрового перетворювача (АЦП) безпосередньо й помножити на постійний коефіцієнт чутливості, похибка вимірювання тиску при зміні температури від -20 °C до +65 °C може перевищити 50 гектопаскалів (гПа), що еквівалентно помилці оцінки висоти польоту безпілотного апарата у понад 400 метрів.

Щоб перетворити зашумлений і температурно залежний сирий код АЦП на достовірну фізичну величину в Міжнародній системі одиниць (SI, фр. *Système international d'unités*), драйвер чипа виконує апаратну або програмну математичну компенсацію. Математична основа цього процесу спирається на комплекс взаємопов'язаних дисциплін: аналітичну апроксимацію нелінійних функцій багатьох змінних, матричне калібрування методом найменших квадратів, ортогональне розкладання за поліномами Чебишова, кусочну сплайн-інтерполяцію, оптимальне квантування коефіцієнтів у фабричній одноразово програмованій пам'яті (OTP / NVM) та безвтратну арифметику фіксованої коми (Q-формат) на 32-бітних і 64-бітних цілочисельних регістрах мікроконтролера.

## 1. Фізична природа нелінійності та перехресної температурної чутливості

У класичному напівпровідниковому п'єзорезистивному барометричному сенсорі вимірювальним ядром виступає тонка монокристалічна кремнієва діафрагма з вакуумною порожниною під нею. Чотири тензорезистори, сформовані методом іонної імплантації, з'єднані за схемою повного вимірювального моста Вітстона. При прикладанні зовнішнього тиску `P` діафрагма зазнає пружного механічного прогину, викликаючи механічне напруження `σ` у кристалічній решітці кремнію. Механічне напруження змінює ширину забороненої зони та деформує еліпсоїди енергетичних долин зони провідності, внаслідок чого ефективна маса носіїв заряду та їхня рухливість стають анізотропними:

```
ΔR / R₀ = π_l · σ_l + π_t · σ_t
```
де:
* `R₀` — номінальний опір тензорезистора за нульового тиску та калібрувальної температури `T₀`,
* `π_l` та `π_t` — поздовжній та поперечний п'єзорезистивні коефіцієнти кремнію (Па⁻¹),
* `σ_l` та `σ_t` — поздовжнє і поперечне механічні напруження на поверхні діафрагми (Па).

Головна складність вимірювального перетворення полягає в тому, що самі п'єзорезистивні коефіцієнти `π(T)` не є константами, а експоненційно спадають зі зростанням абсолютної температури `T` внаслідок інтенсифікації розсіювання електронів на акустичних та оптичних фононах кристалічної решітки:

```
π(T) = π(T₀) · (T / T₀)^(-γ)
```
де `γ ≈ 1.2 ... 1.8` — емпіричний показник легування напівпровідника (залежить від концентрації домішок бору чи фосфору).

Крім того, різниця коефіцієнтів лінійного теплового розширення кремнієвого кристала (`α_Si ≈ 2.6 · 10⁻⁶ К⁻¹`), скляної підкладки (`α_Glass ≈ 3.2 · 10⁻⁶ К⁻¹`) та полімерного герметика корпусу мікросхеми (`α_Molding ≈ 12 · 10⁻⁶ К⁻¹`) генерує паразитарне термомеханічне напруження `σ_терм(T)`, яке згинає вимірювальну мембрану навіть за умов ідеального абсолютного вакууму:

```
σ_терм(T) = E_Si · (α_Molding - α_Si) · (T - T_cure)
```
де `E_Si` — модуль Юнга монокристалічного кремнію (близько 169 ГПа у напрямку [110]), а `T_cure` — температура полімеризації компаунда при корпусуванні чипа.

У результаті диференціальна вихідна напруга моста Вітстона `V_bridge(P, T)` є складною нелінійною функцією двох взаємозалежних аргументів:

```
V_bridge(P, T) = S₀(T) · P + Off(T) + NL_P(P, T) + NL_T(T)
```
де:
* `S₀(T) = S_base · (1 + α_S · ΔT + β_S · ΔT²)` — температурна характеристика чутливості (Slope),
* `Off(T) = Off_base + α_off · ΔT + β_off · ΔT² + γ_off · ΔT³` — температурний дрейф зміщення нуля (Offset),
* `NL_P(P, T) = k_p2 · P² + k_p3 · P³` — власна геометрична та фізична нелінійність прогину мембрани,
* `NL_T(T)` — високотемпературні залишковий шум та нелінійності напівпровідника.

Після перетворення аналогової напруги `V_bridge` внутрішнім сигма-дельта АЦП отримуємо безрозмірний цілий 20-бітний код `ADC_P`. Одночасно інтегрований термодіодний сенсор або температурний перетворювач з забороненою зоною (Bandgap) оцифровує температуру підкладки, повертаючи сирий код `ADC_T`.

Задача математичного калібрувального ядра драйвера полягає у розв'язанні задачі обернення оператора перетворення:

```
P_si = f⁻¹(ADC_P, ADC_T, C)
```
де `C = {c₁, c₂, ..., c_k}` — вектор індивідуальних фабричних калібрувальних коефіцієнтів, обчислених на заводі під час тестування пластини на зондових станціях при різних температурах та записаних у незалежну пам'ять NVM.

## 2. Багатовимірний ряд Тейлора та матрична факторизація компенсації

Оскільки аналітичне фізичне рівняння термопружності мембрани вимагає розв'язання нелінійних диференціальних рівнянь у частинних похідних методом скінченних елементів, що фізично неможливо виконати на мікроконтролері з обмеженим енергоспоживанням, функцію відгуку апроксимують відрізком багатовимірного ряду Тейлора в околі номінальної точки калібрування `(P₀, T₀)`:

```
P(u_p, u_t) = ∑ [i=0..N] ∑ [j=0..M] a_ij · (u_p)^i · (u_t)^j
```
де `u_p = ADC_P - P_ref`, `u_t = ADC_T - T_ref`.

Для забезпечення компромісу між точністю вимірювання (похибка менше 0.01% повної шкали) та обчислювальною складністю, ряд Тейлора обмежують поліномом 2-го порядку за тиском та 3-го порядку за температурою з урахуванням перехресних членів (крос-термів `u_p · u_t` та `u_p · u_t²`):

```
P_comp = b₀ + b₁·u_p + b₂·u_p² + b₃·u_t + b₄·u_t² + b₅·u_t³ + b₆·u_p·u_t + b₇·u_p·u_t²
```

Пряме обчислення такого восьмичленного виразу на кожній ітерації вимагало б 14 операцій множення та 7 операцій додавання на кожну вибірку. Проте інженерна математика пропонує каскадну декомпозицію: функцію розбивають на два послідовні етапи:
1. Розрахунок лінеаризованого температурного фактора високої роздільної здатності `t_fine`.
2. Розрахунок температурно-залежних функцій зміщення `Offset(t_fine)` та масштабу `Sensitivity(t_fine)` з подальшою корекцією залишкової нелінійності.

### Етап 1: Формування температурного ядра `t_fine`

Температурний канал калібрується за трьома параметрами: зміщення `dig_T1`, лінійний нахил `dig_T2` та квадратична кривина `dig_T3`.

Позначимо нормоване відхилення вихідного коду АЦП температури:

```
ΔT = ADC_T - 2 · dig_T1
```

Обчислення проміжних доданків розкладається на кроки:

```
var1 = (ΔT / 2) · dig_T2
var2 = (ΔT / 4)² · dig_T3
t_fine = var1 + var2
```

Покажемо повний аналітичний ланцюг обчислення `t_fine`:

```
t_fine
= var1 + var2                                            [означення кумулятивного фактора]
= (ΔT / 2) · dig_T2 + ((ΔT / 4) · (ΔT / 4) · dig_T3)     [підстановка формул компонент]
= (ΔT / 2) · dig_T2 + (ΔT² / 16) · dig_T3                [спрощення дробу в квадратичному члені]
= ((ADC_T - 2·dig_T1) / 2) · dig_T2 + ((ADC_T - 2·dig_T1)² / 16) · dig_T3 [підстановка вхідного коду АЦП]
```

Змінна `t_fine` має розмірність фіксованої коми Q24.8 і слугує універсальним температурним аргументом для всіх інших вимірювальних каналів кристала (тиску, вологості, летких органічних сполук). Значення фізичної температури в градусах Цельсія обчислюється як пряме лінійне масштабування:

```
T_celsius
= (t_fine · 5 + 128) / 256                               [масштабування у соті частки градуса]
= (t_fine · 5) / 256 + 0.5                               [виділення адитивного округлення]
```

### Етап 2: Двовимірне відновлення тиску з крос-компенсацією

Температурні функції зміщення нуля `Offset_T` та чутливості `Sensitivity_T` виражаються через квадратичні поліноми від `t_fine`:

```
Offset_T = dig_P1 · 2¹⁶ + (dig_P2 · t_fine) / 2¹¹ + (dig_P3 · t_fine²) / 2²⁴
```

```
Sensitivity_T = dig_P4 · 2¹⁵ + (dig_P5 · t_fine) / 2¹⁰ + (dig_P6 · t_fine²) / 2²³
```

Після розрахунку `Offset_T` та `Sensitivity_T` сирий 20-бітний код тиску `ADC_P` перетворюється на первинне наближення тиску `p`:

```
p = (((1048576 - ADC_P) · 2³¹ - Offset_T) · 3125) / Sensitivity_T
```

До отриманого значення `p` застосовується завершальний поліном другого порядку, який компенсує залишкову механічну пружну нелінійність кремнієвої діафрагми:

```
var1 = (dig_P9 · (p / 2¹³) · (p / 2¹³)) / 2²⁵
var2 = (dig_P8 · p) / 2¹⁹
p_final = ((p + var1 + var2) / 2⁸) + dig_P7 · 2⁴
```

Усі ділення на степені двійки `2^k` виконуються арифметичними зсувами вправо `>> k`, що зводить складний нелінійний розрахунок до кількох швидких машинних інструкцій процесора.

## 3. Математика фіксованої коми: Q-формати та алгебра переповнення

Вбудовані процесори систем реального часу (наприклад, ядра ARM Cortex-M0+, Cortex-M3 або RISC-V RV32EC) не мають апаратного блоку FPU з плаваючою комою. Використання 64-бітних дійсних чисел `double` призводить до підключення важких бібліотечних процедур `soft-float`, кожна з яких виконується за 100–300 тактів із розгортанням небезпеки затримки критичних переривань.

Для забезпечення детермінованого часу виконання та збереження повної 24-бітної точності АЦП використовується арифметика з фіксованою комою у форматі `Q_m.n` (де `m` — кількість бітів для цілої частини зі знаком, а `n` — кількість дробових бітів).

### Карта форматів фіксованої коми у вимірювальному конвеєрі

| Позначення формату | Біти цілої частини `m` | Біти дробу `n` | Квант роздільної здатності (LSB) | Діапазон значень | Призначення у компенсації |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Q24.8** | 24 біти (зі знаком) | 8 бітів | `2⁻⁸ = 0.00390625` | `[-8388608.0, +8388607.996]` | Температурна база `t_fine`, фінальний тиск |
| **Q16.16** | 16 бітів (зі знаком) | 16 бітів | `2⁻¹⁶ ≈ 1.52588 · 10⁻⁵` | `[-32768.0, +32767.99998]` | Коефіцієнти першого порядку `dig_P2, dig_P5` |
| **Q11.21** | 11 бітів (зі знаком) | 21 біт | `2⁻²¹ ≈ 4.76837 · 10⁻⁷` | `[-1024.0, +1023.9999995]` | Квадратичні коефіцієнти `dig_P3, dig_P6` |
| **Q32.32** | 32 біти (зі знаком) | 32 біти | `2⁻³² ≈ 2.32831 · 10⁻¹⁰` | `[-2.14·10⁹, +2.14·10⁹]` | 64-бітний внутрішній акумулятор `Offset_T` |

### Закони двійкового масштабування в операціях Q-форматів

Нехай задано два операнди `A` у форматі `Q_m1.n1` та `B` у форматі `Q_m2.n2`.

1. **Додавання та віднімання:** вимагає приведення до спільного двійкового експоненційного базису. Якщо `n1 > n2`, молодше за розрядністю число `B` зсувається ліворуч:
```
(A ± B)_q = A_q ± (B_q << (n1 - n2))
```

2. **Множення:** дробові розрядності додаються: `n_prod = n1 + n2`. Для приведення результату до цільового формату `Q_m3.n3` добуток зсувається праворуч на різницю розрядностей:
```
(A · B)_q3 = (int64_t(A_q) · int64_t(B_q)) >> (n1 + n2 - n3)
```

3. **Ділення:** для збереження точності ділене попередньо масштабується вліво:
```
(A / B)_q3 = (int64_t(A_q) << (n3 + n2 - n1)) / int64_t(B_q)
```

Розглянемо детальний алгебраїчний розбір збереження розрядності на прикладі обчислення доданку чутливості `Sensitivity_T`:

```
Sensitivity_T
= ((int64_t)dig_P4 << 15) + (((int64_t)dig_P5 · t_fine) >> 10) + (((int64_t)dig_P6 · (t_fine >> 2) · (t_fine >> 2)) >> 19)
```

Простежимо граничні межі значень кожного члена:
1. `dig_P4` — 16-бітне беззнакове ціле `uint16_t` з діапазоном `[0 ... 65535]`. Операція `dig_P4 << 15` дає 31-бітне додатне число в діапазоні `[0 ... 2147450880]`, що гарантовано вкладається в додатну напіввісь `int32_t`.
2. `dig_P5` — 16-бітне знакове ціле `int16_t` `[-32768 ... +32767]`. `t_fine` у діапазоні температур від -40 °C до +85 °C приймає значення від `-10240` до `+21760`. Добуток `dig_P5 · t_fine` досягає максимального абсолютного значення `32768 · 21760 = 713031680` (30 бітів). Після зсуву `>> 10` отримуємо діапазон `[-696320 ... +696319]` (вміщується в 20 бітів).
3. `dig_P6` — 16-бітне знакове ціле `int16_t`. Член `(t_fine >> 2)²` має значення до `(21760 / 4)² = 29593600` (25 бітів). Потрійний добуток `dig_P6 · (t_fine >> 2)²` генерує 41-бітне проміжне число: `32768 · 29593600 = 9.697 · 10¹¹`.
4. Якщо виконати цей добуток на 32-бітному типі, відбудеться катастрофічне циклічне переповнення розрядної сітки зі зміною знака. Використання проміжного приведення до `int64_t` усуває невизначену поведінку стандарту ISO C99, а фінальний зсув `>> 19` повертає доданок у 22-бітний діапазон.

## 4. Оцінка похибок квантування, зміщення середнього та шум округлення

При роботі з фіксованою комою відкидання молодших розрядів двійковим зсувом вправо `>> k` еквівалентне взяттю цілої частини `floor(x / 2^k)`.

Розглянемо статистичні властивості похибки обтинання (Truncation Error) проти похибки симетричного округлення до найближчого (Round-to-Nearest):

### Теорема про систематичне зміщення при асиметричному усіченні

Для випадкового сигналу `X`, рівномірно розподіленого на квантах дискретизації, похибка оператора `x >> k` визначається як:

```
ε_trunc(x) = x / 2^k - floor(x / 2^k)
```

Математичне сподівання цієї похибки строго додатне:

```
E[ε_trunc] = (1 / 2^k) · ∑ [i=0..(2^k - 1)] (i / 2^k)
= (1 / 2^(2k)) · ((2^k - 1) · 2^k / 2)
= (2^k - 1) / (2^(k + 1)) ≈ 0.5 - 2^(-(k+1)) LSB
```

Якщо в каскадному алгоритмі компенсації міститься 6 послідовних зсувів праворуч, сумарне накопичене систематичне зміщення:

```
Bias_total = ∑ [i=1..6] E[ε_trunc_i] · Scale_i
```
викликає постійний температурний дрейф нуля сенсора до 3.8 Па (що в прецизійній навігації еквівалентно 32 см висотного зсуву).

### Метод незміщеного симетричного округлення з адитивним зміщенням

Для усунення систематичного зсуву застосовується аддитивне округлення з додаванням половини кванта `1 << (k - 1)` перед виконанням зсуву:

```
round_pow2(x, k) = (x + (1 << (k - 1))) >> k
```

Доведемо нульове математичне сподівання похибки симетричного округлення:

```
E[ε_round]
= E[x / 2^k - floor((x + 2^(k-1)) / 2^k)]               [означення похибки round_pow2]
= E[x / 2^k] - E[floor((x + 2^(k-1)) / 2^k)]            [лінійність математичного сподівання]
= (2^k - 1) / (2 · 2^k) - ((2^k - 1) / (2 · 2^k) + 0)   [симетрія центрованого розподілу]
= 0 LSB                                                 [нульове систематичне зміщення]
```

Дисперсія шуму округлення при цьому становить фундаментальну величину:

```
σ²_round = (2^(2k) - 1) / (12 · 2^(2k)) ≈ 1 / 12 LSB²
```

Спектральна густина потужності цього шуму рівномірно розподілена в смузі Найквіста від `0` до `F_odr / 2`, перетворюючи похибку квантування на адитивний білий гаусівський шум (AWGN, англ. *Additive White Gaussian Noise*), який легко фільтрується наступним каскадом низькочастотного IIR-фільтра драйвера.

## 5. Мінімаксна апроксимація поліномами Чебишова проти звичайного ряду Тейлора

Чому коефіцієнти NVM у сучасних сенсорах розраховуються на заводі через мінімаксне наближення Чебишова, а не шляхом прямого диференціювання в ряди Тейлора?

Ряд Тейлора оптимізує точність строго в одній точці `x₀`, де всі похідні збігаються. Проте при віддаленні від точки калібрування похибка апроксимації різко зростає на краях інтервалу вимірювання за степеневим законом `O((x - x₀)^(N+1))`.

Поліноми Чебишова першого роду `T_n(x)` мають унікальну властивість рівнохвильовості (Equiripple Property): на відрізку `[-1, 1]` вони приймають екстремальні значення `±1` рівно `n + 1` разів.

Рекурентна формула поліномів Чебишова:

```
T₀(x) = 1
T₁(x) = x
T_(n+1)(x) = 2x · T_n(x) - T_(n-1)(x)
```

Перші шість ортогональних базисних функцій:
* `T₀(x) = 1`
* `T₁(x) = x`
* `T₂(x) = 2x² - 1`
* `T₃(x) = 4x³ - 3x`
* `T₄(x) = 8x⁴ - 8x² + 1`
* `T₅(x) = 16x⁵ - 20x³ + 5x`

Якщо розкласти функцію калібрування сенсора `f(x)` за базисом Чебишова:

```
f(x) ≈ (c₀ / 2) + ∑ [k=1..N] c_k · T_k(x)
```
де коефіцієнти Фур'є-Чебишова обчислюються як зважені інтеграли:

```
c_k = (2 / π) · ∫ [-1..1] (f(x) · T_k(x)) / √(1 - x²) dx
```

За теоремою Чебишова про альтернанс, отримана поліноміальна апроксимація мінімізує максимальну абсолютну похибку на всьому інтервалі температур від -40 °C до +85 °C (мінімаксне наближення у нормі `L_∞`):

```
min [P_N] max [x ∈ [-1, 1]] |f(x) - P_N(x)| = |c_(N+1)|
```

Це означає, що при калібруванні за Чебишовим похибка сенсора на морозі (-40 °C) та на спеці (+85 °C) є точно такою ж мізерною, як і за кімнатної температури (+25 °C), позбавляючись крайового розбігання поліномів (феномену Рунге).

## 6. Кусочно-лінійна та сплайн-інтерполяція (LUT) для високонелінійних датчиків

У деяких категоріях сенсорів (наприклад, оптичних люксметрах, термопарах високого температурного діапазону типу K/S, або електрохімічних газових сенсорах) фізична залежність сигналу від вимірюваної величини містить круті експоненційні або логарифмічні ділянки, які неможливо апроксимувати поліномом низького степеня без виникнення паразитних коливань.

У таких архітектурах застосовується табличне калібрування (Look-Up Table, LUT) з інтерполяцією між вузлами сітки.

### Кусочно-лінійна інтерполяція з масштабуванням

Нехай задано `M` калібрувальних вузлів `{X_i, Y_i}` для `i = 0 ... M - 1`. Якщо вхідне значення потрапляє в інтервал `[X_k, X_(k+1)]`, вихідне значення розраховується за формулою:

```
Y_out = Y_k + ((X_in - X_k) · (Y_(k+1) - Y_k)) / (X_(k+1) - X_k)
```

Для оптимізації виконання на мікроконтролері крок сітки `ΔX = X_(k+1) - X_k` обирають рівним ступеню двійки `2^p`. Тоді індекс вузла `k` та внутрішній зсув знаходяться без операцій ділення:

```
k = (X_in - X_0) >> p
offset = (X_in - X_0) & ((1 << p) - 1)
Y_out = Y[k] + ((offset · (Y[k+1] - Y[k])) >> p)
```

Залишковий член похибки кусочно-лінійної інтерполяції за теоремою Лагранжа обмежений другою похідною функції:

```
|R_1(x)| ≤ (1 / 8) · max |f''(ξ)| · (ΔX)²
```

Зменшення кроку сітки `ΔX` удвічі знижує похибку апроксимації в 4 рази, що дозволяє досягти довільної точності ціною лінійного збільшення обсягу постійної пам'яті Flash/NVM.

### Кубічні ермітові сплайни Catmull-Rom для неперервності похідних

Якщо в контурі керування вимагається неперервність не лише самої фізичної величини, але й її швидкості зміни (першої похідної `dP/dt`), звичайна лінійна інтерполяція створює розриви похідної у вузлах, викликаючи ривки та високочастотні гармоніки в контурах ПІД-регуляторів.

У таких задачах драйвер використовує локальні кубічні сплайни Катмулла-Рома (Catmull-Rom), де дотична у кожному вузлі визначається автоматично за сусідніми точками:

```
m_k = (Y_(k+1) - Y_(k-1)) / 2
```

Інтерполяційний поліном на відрізку `t ∈ [0, 1]` задається виразом:

```
Y(t) = (2t³ - 3t² + 1)·Y_k + (t³ - 2t² + t)·m_k + (-2t³ + 3t²)·Y_(k+1) + (t³ - t²)·m_(k+1)
```

Цей поліном гарантує гладкість класу `C¹` без необхідності розв'язання глобальних тридіагональних матриць у реальному часі.

## 7. Аналіз обумовленості калібрувальної матриці (Condition Number)

На заводі коефіцієнти знаходять розв'язанням перевизначеної системи лінійних алгебраїчних рівнянь (СЛАР) для `M` вимірювальних точок у термобарокамері (`M >> K`, де `K` — кількість шуканих коефіцієнтів).

Нехай матриця плану калібрувального експерименту має вигляд:

```
X = [
  1,  u_p1,  u_p1²,  u_t1,  u_t1²,  u_p1·u_t1
  1,  u_p2,  u_p2²,  u_t2,  u_t2²,  u_p2·u_t2
  ...
  1,  u_pM,  u_pM²,  u_tM,  u_tM²,  u_pM·u_tM
]
```

Вектор коефіцієнтів `C` знаходиться за методом найменших квадратів (МНК):

```
C = (Xᵀ · X)⁻¹ · Xᵀ · Y_ref
```

Якість та надійність калібрування визначається числом обумовленості матриці Грама `A = Xᵀ · X`:

```
cond(A) = ||A|| · ||A⁻¹|| = σ_max(A) / σ_min(A)
```
де `σ_max` та `σ_min` — максимальне та мінімальне сингулярні числа матриці `A`.

Якщо змінні `u_p` та `u_t` не нормалізовані й вимірюються в сирих кодах АЦП (порядку `10⁶`), число обумовленості `cond(A)` перевищує `10¹⁶`. Це призводить до катастрофічної втрати точності: матриця стає чисельно виродженою (Ill-conditioned), а розраховані коефіцієнти набувають гігантських знакозмінних значень, чутливих до найменшого аналогового шуму вимірювань.

Для запобігання цьому виробники виконують попереднє центроване масштабування змінних до діапазону `[-1, 1]`:

```
x_p = (ADC_P - P_mid) / P_span
x_t = (ADC_T - T_mid) / T_span
```

Нормалізація зменшує число обумовленості до ідеального значення `cond(A) < 10.0`, гарантуючи математичну стійкість калібрувальних коефіцієнтів NVM протягом усього 10-річного життєвого циклу експлуатації датчика.

## 8. Моделі часової деградації, релаксації механічних напружень та закону Арреніуса

Калібрувальні коефіцієнти NVM фіксують стан кристала на момент випуску з фабрики. Проте в процесі реальної експлуатації точність сенсора зазнає повільного дрейфу внаслідок дії трьох фізичних механізмів:
1. **Релаксація внутрішніх напружень компаунда:** полімерний корпус мікросхеми зазнає поступової усадки та старіння, що змінює постійне механічне зміщення кремнієвої мембрани `σ_0(t)`.
2. **Дифузія іонів та дрейф зарядів у діелектриках:** накопичення паразитарного заряду на пасивуючому шарі діоксиду кремнію (SiO₂) змінює потенціал поверхні та струми витоку тензорезисторів.
3. **Гігроскопічне розбухання корпусу:** поглинання вологи з повітря змінює геометрію корпусу та створює додаткове механічне напруження (вологісний гістерезис барометрів).

Швидкість деградації калібрування описується законом Арреніуса:

```
k_drift(T) = A_drift · exp(-E_a / (k_B · T))
```
де `E_a` — енергія активації процесу деградації (типово 0.6–0.9 еВ для кремнієвих MEMS), `k_B` — стала Больцмана (`8.617 · 10⁻⁵ еВ/К`), `T` — абсолютна температура в Кельвінах, а `A_drift` — частотний фактор.

Математична модель довготривалого дрейфу зміщення нуля в часі `t` має сублогарифмічний характер:

```
ΔOff_aging(t) = D₀ · log(1 + t / τ_aging)
```
де `τ_aging` — характерний час первинної релаксації кристала (зазвичай від 48 до 168 годин після монтажу на друковану плату методом оплавлення припою). Саме тому промислові стандарти вимагають обов'язкового періоду температурного тренування (Burn-in) плати перед фінальним калібруванням готового приладу.

## 9. Багатоканальна крос-компенсація вологості та нелінійність тиску насиченої пари

У комбінованих сенсорах середовища (температура, тиск, відносна вологість, якість повітря) виникає перехресна багатопараметрична взаємодія. Вимірювання відносної вологості `RH` ємнісним сенсором базується на зміні діелектричної проникності полімерної плівки `ε_r(RH)`. Проте адсорбція водяної пари полімером має суттєву температурну залежність, яка описується рівнянням тиску насиченої пари Арго — Магнуса — Тетена:

```
P_sat(T) = 6.112 · exp((17.62 · T) / (243.12 + T))
```
де `T` — температура в градусах Цельсія, а `P_sat` — тиск насиченої пари в гектопаскалях (гПа).

Калібрувальний поліном вологості вимагає попереднього точного обчислення `t_fine` з температурного каналу:

```
var_H1 = t_fine - 76800;
var_H2 = (ADC_H - (dig_H4 · 64 + (dig_H5 / 16384) · var_H1)) · (dig_H2 / 65536 · (1 + (dig_H6 / 67108864) · var_H1 · (1 + (dig_H3 / 67108864) · var_H1)));
var_H3 = var_H2 · (1 - (dig_H1 · var_H2) / 524288);
RH_comp = var_H3 > 100.0 ? 100.0 : (var_H3 < 0.0 ? 0.0 : var_H3);
```

Цей каскадний розрахунок усуває температурну похибку вологості з ±8% RH до менше ніж ±1.5% RH у повному діапазоні температур від -20 °C до +70 °C.

## 10. Матричний аналіз поширення похибок через матрицю Якобі

Будь-який цифровий вимір супроводжується випадковим шумом квантування та аналоговим шумом вхідного каскаду. Якщо вектор вхідних сирих вимірів `U = [ADC_P, ADC_T]ᵀ` має коваріаційну матрицю шумів `Σ_in`:

```
Σ_in = [
  σ²_P,   σ_PT
  σ_PT,   σ²_T
]
```

то дисперсія вихідної фізичної величини `P_si = f(ADC_P, ADC_T)` за законом поширення похибок Гауса визначається через вектор градієнта (матрицю Якобі `J`):

```
J = [ ∂f/∂(ADC_P),  ∂f/∂(ADC_T) ]
```

```
σ²_P_out = J · Σ_in · Jᵀ = (∂f/∂(ADC_P))² · σ²_P + 2 · (∂f/∂(ADC_P)) · (∂f/∂(ADC_T)) · σ_PT + (∂f/∂(ADC_T))² · σ²_T
```

Частинна похідна `∂f/∂(ADC_T)` характеризує температурну чутливість каналу тиску:

```
∂f/∂(ADC_T) = (∂Offset_T / ∂(t_fine) · Sensitivity_T - (1048576 - ADC_P) · (∂Sensitivity_T / ∂(t_fine))) / Sensitivity_T² · (∂(t_fine) / ∂(ADC_T))
```

Якщо температурний канал має підвищений рівень шуму (наприклад, через занижений коефіцієнт передискретизації OSR температури), високий коефіцієнт передачі `∂f/∂(ADC_T)` призведе до деградації відношення сигнал/шум у каналі тиску. Математичний аналіз доводить, що для мінімізації дисперсії тиску `σ²_P_out` коефіцієнт передискретизації температури `OSR_T` повинен бути не меншим за `OSR_P / 4`, навіть якщо саму температуру не потрібно вимірювати з високою частотою.
