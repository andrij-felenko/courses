# Апаратні регістри таймера в режимі одного імпульсу

Режим одного імпульсу (@@en|One-Pulse Mode, OPM@@) реалізується через комбінацію бітових полів регістрів керування лічильником, контролера веденого режиму та вихідних каналів порівняння. Після активації режиму апаратура таймера автоматично вимикає лічильник після досягнення кінцевого значення періоду. Дана довідка описує карту регістрів та призначення критичних бітових полів для налаштування OPM.

## Карта регістрів режиму OPM

| Регістр | Зміщення | Повна назва | Призначення в режимі OPM |
| :--- | :--- | :--- | :--- |
| `TIMx_CR1` | `0x00` | Control Register 1 | Увімкнення біта `OPM`, буферизації `ARPE` та біта запуску `CEN` |
| `TIMx_SMCR`| `0x08` | Slave Mode Control Register | Вибір джерела зовнішнього тригера `TS` та режиму тригерування `SMS` |
| `TIMx_CCMR1`| `0x18`| Capture/Compare Mode Register 1 | Вибір режиму ШІМ для вихідного каналу та вхідного фільтра тригера |
| `TIMx_CCER` | `0x20` | Capture/Compare Enable Register | Дозвіл виходу каналу `CCxE` та налаштування полярності `CCxP` |
| `TIMx_PSC`  | `0x28` | Prescaler | Коефіцієнт вхідного дільника тактової частоти шини |
| `TIMx_ARR`  | `0x2C` | Auto-Reload Register | Повна тривалість циклу (момент завершення імпульсу та вимкнення `CEN`) |
| `TIMx_CCR1` | `0x34` | Capture/Compare Register 1 | Затримка переднього фронту імпульсу від моменту тригера |
| `TIMx_SR`   | `0x10` | Status Register | Прапорці подій оновлення `UIF` та спрацьовування тригера `TIF` |

## Детальний опис бітових полів

### 1. Регістр керування `TIMx_CR1`
- **Біт 3 `OPM` (One-pulse mode)**:
  - `0` — Лічильник працює циклічно у звичайному режимі;
  - `1` — Лічильник зупиняється (апаратура скидає біт `CEN = 0`) під час першої ж події оновлення `UEV` (при досягненні `CNT == ARR`).
- **Біт 7 `ARPE` (Auto-reload preload enable)**:
  - `1` — Вмикає тіньовий регістр для `ARR`, гарантуючи оновлення межі лічби лише після завершення поточного імпульсу.
- **Біт 0 `CEN` (Counter enable)**:
  - `1` — Лічильник активний і рахує; встановлюється програмно або автоматично апаратним тригером `TRGI`.

### 2. Регістр веденого режиму `TIMx_SMCR`
- **Біти `[2:0] SMS` (Slave mode selection)**:
  - `110` (Trigger Mode) — Лічильник запускається за активним фронтом на лінії `TRGI` (автоматично виставляється `CEN = 1`), але лічильник не скидається в 0.
  - `100` (Reset Mode) — Активний фронт на `TRGI` скидає лічильник `CNT = 0` і реініціалізує таймінги.
- **Біти `[6:4] TS` (Trigger selection)**:
  - `101` — Вхід `TI1FP1` (фільтрований сигнал із вхідного виводу каналу 1);
  - `110` — Вхід `TI2FP2` (фільтрований сигнал із вхідного виводу каналу 2);
  - `111` — Зовнішній тригерний вхід `ETRF`.

### 3. Регістр конфігурації каналу `TIMx_CCMR1`
- **Біти `[6:4] OC1M` (Output compare 1 mode)**:
  - `110` (PWM mode 1) — Канал активний при `CNT < CCR1`, неактивний при `CNT >= CCR1`;
  - `111` (PWM mode 2) — Канал неактивний при `CNT < CCR1` (пауза затримки), і стає активним при `CNT >= CCR1` (формування імпульсу до моменту `ARR`).
- **Біт 3 `OC1PE` (Output compare 1 preload enable)**:
  - `1` — Запис у `CCR1` буферизується і не змінює активний імпульс до наступної події `UEV`.

## Апаратні інваріанти
1. Для генерації імпульсу із затримкою вихідний канал обов'язково налаштовують у режим `PWM mode 2` (`OCxM = 111`), щоб вихід залишався в пасивному рівні від `0` до `CCR`, а потім переходив в активний стан від `CCR` до `ARR`.
2. Якщо `CCR >= ARR`, вихід ніколи не перейде в активний стан, і таймер зупиниться після затримки без формування вихідного імпульсу.
