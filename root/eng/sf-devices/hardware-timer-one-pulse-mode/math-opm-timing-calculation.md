# Математичний розрахунок часових параметрів у режимі одного імпульсу

Режим одного імпульсу (@@en|one-pulse mode, OPM@@) апаратного таймера дозволяє генерувати поодинокий прямокутний імпульс каліброваної тривалості з точно заданою затримкою відносно вхідного тригера. Формування сигналу виконується виключно цифровою логікою таймера без втручання процесора. Математичний апарат конфігурування OPM спирається на розрахунок дільника тактової частоти, регістрів порівняння та автоперезавантаження з урахуванням апаратних квантів дискретизації.

## Базові формули часових інтервалів

Таймер тактується від внутрішньої шини з частотою `f_CLK`. Вхідний дільник частоти (@@en|prescaler, PSC@@) зменшує частоту тактування лічильника `CNT` у `(PSC + 1)` разів. Період одного елементарного такту лічби `t_tick` обчислюється як:

```
t_tick = (PSC + 1) / f_CLK
```

Початок формування імпульсу визначається значенням регістра захоплення/порівняння `CCR` (Capture/Compare Register). Затримка від моменту тригерного старту до появи активного фронту на вихідному виводі `t_delay` дорівнює:

```
t_delay = CCR × t_tick = CCR × (PSC + 1) / f_CLK
```

Завершення імпульсу та автоматична зупинка лічильника відбуваються при досягненні значення регістра автоперезавантаження `ARR` (Auto-Reload Register). Тривалість активного імпульсу `t_pulse` визначається різницею між `ARR` та `CCR`:

```
t_pulse = (ARR - CCR) × t_tick = (ARR - CCR) × (PSC + 1) / f_CLK
```

Повний час виконання циклу від приходу тригера до апаратного скидання біта увімкнення `CEN` складає:

```
t_total = ARR × t_tick = ARR × (PSC + 1) / f_CLK
```

Для коректного формування сигналу значення регістрів повинні суворо задовольняти граничну нерівність:

```
0 < CCR < ARR ≤ MAX_VAL
```

де `MAX_VAL = 65535` для 16-бітних таймерів або `4294967295` для 32-бітних таймерів.

## Покроковий розрахунок конфігурації для заданих таймінгів

**Умова розрахунку:** Необхідно налаштувати 16-бітний апаратний таймер мікроконтролера з базовою частотою тактування шини `f_CLK = 84` МГц (`84 000 000` Гц). Параметри вихідного імпульсу:
- Затримка переднього фронту: `t_delay = 50` мкс (`0.000050` с);
- Тривалість активного стану: `t_pulse = 20` мкс (`0.000020` с).

**Крок 1. Вибір зручного кванта часу та розрахунок дільника PSC.**

Для забезпечення цілочисельних значень регістрів обираємо дискрет лічби `t_tick = 1` мкс (`1.0 × 10⁻⁶` с):

```
PSC
= (f_CLK × t_tick) - 1   [визначення коефіцієнта переддільника]
= (84000000 × 0.000001) - 1 [підстановка частоти 84 МГц та кванта 1 мкс]
= 84 - 1
= 83                     [значення регістра PSC]
```

Значення `83` вкладається в 16-бітний діапазон (`83 < 65535`).

**Крок 2. Обчислення значення регістра порівняння CCR.**

Значення `CCR` визначає затримку появи імпульсу:

```
CCR
= t_delay / t_tick       [ділення необхідної затримки на період такту]
= 50 × 10⁻⁶ / (1.0 × 10⁻⁶) [підстановка затримки 50 мкс]
= 50                     [значення регістра CCR]
```

**Крок 3. Обчислення значення регістра автоперезавантаження ARR.**

Значення `ARR` відповідає моменту скидання виходу та завершення відліку:

```
ARR
= CCR + (t_pulse / t_tick) [сума затримки та тривалості імпульсу]
= 50 + (20 × 10⁻⁶ / (1.0 × 10⁻⁶)) [підстановка тривалості 20 мкс]
= 50 + 20
= 70                     [значення регістра ARR]
```

Обидва значення `CCR = 50` та `ARR = 70` задовольняють інваріант `0 < 50 < 70 ≤ 65535`.

## Граничні кванти та похибка дискретизації

Мінімальний квант затримки, який здатна забезпечити апаратура без переддільника (`PSC = 0`), становить:

```
t_tick_min
= 1 / f_CLK              [мінімальний період такту при PSC=0]
= 1 / 84000000           [для тактової частоти 84 МГц]
≈ 11.905 × 10⁻⁹ с        [гранична дискретність 11.9 нс]
```

Максимальна тривалість одного неперервного імпульсу для 16-бітного таймера за умови збереження мікросекундного кванта (`PSC = 83`) обмежена максимальною місткістю `ARR`:

```
t_pulse_max
= 65535 × 1.0 × 10⁻⁶ с   [множення 2¹⁶-1 на квант часу]
≈ 0.0655 с = 65.535 мс   [максимальна тривалість імпульсу]
```

Якщо приладу потрібні довші імпульси (наприклад, сотні мілісекунд або секунди), коефіцієнт `PSC` пропорційно збільшують або переходять на 32-бітний таймерний канал.
