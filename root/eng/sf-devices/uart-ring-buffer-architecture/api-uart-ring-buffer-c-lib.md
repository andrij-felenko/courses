# Програмний інтерфейс бібліотеки кільцевого буфера UART

Програмна бібліотека кільцевого буфера надає набір функцій для організації асинхронного обміну даними між апаратними обробниками переривань мікроконтролера та прикладними задачами. Інтерфейс бібліотеки спроєктований за принципом мінімальних накладних витрат: усі виклики є повністю неблокувальними, оперують фіксованими масивами пам'яті без викликів динамічної купи (@@en|heap@@) та забезпечують атомарне оновлення індексів.

## Призначення та архітектура викликів

Кільцевий буфер інкапсулює стан черги байтів у структурі `ring_buffer_t`. Інтерфейс розділено на дві групи операцій:
1. **Операції запису (постачальник)**: виклики розміщення даних (`ring_buf_put`), які зазвичай виконуються всередині обробника переривання UART RX або зворотного виклику контролера прямого доступу до пам'яті (DMA).
2. **Операції зчитування (споживач)**: виклики вилучення байтів (`ring_buf_get`), перегляду чергового символу без вилучення (`ring_buf_peek`) та діагностики заповненості (`ring_buf_available`), що викликаються з фонового суперциклу чи задач операційної системи.

## Сценарії використання інтерфейсу

### 1. Запис вхідного байта з обробника переривання UART
Обробник перевіряє прапорець готовності приймача та переносить байт у буфер:

```c
void USART1_IRQHandler(void) {
    if (USART1->SR & USART_SR_RXNE) {
        uint8_t rx_byte = (uint8_t)(USART1->DR & 0xFF);
        // Неблокувальний запис у кільцевий буфер
        if (!ring_buf_put(&uart_rx_rb, rx_byte)) {
            // Буфер переповнено, лічильник помилок збільшено всередині функції
        }
    }
}
```

### 2. Вичитування та пакетна обробка в головному циклі
Споживач перевіряє наявність даних і послідовно обробляє прийняті байти:

```c
void process_incoming_stream(void) {
    uint8_t byte;
    while (ring_buf_get(&uart_rx_rb, &byte)) {
        parse_protocol_byte(byte);
    }
}
```

## Довідка функцій інтерфейсу

### `void ring_buf_init(ring_buffer_t *rb)`
- **Призначення**: ініціалізація або повне скидання структури буфера.
- **Параметри**: `rb` — покажчик на структуру кільцевого буфера.
- **Поведінка**: скидає індекси `head` і `tail` у 0, очищує лічильник переповнень `overrun_count`.

### `bool ring_buf_put(ring_buffer_t *rb, uint8_t byte)`
- **Призначення**: додавання одного байта в кінець черги.
- **Параметри**:
  - `rb` — покажчик на структуру буфера.
  - `byte` — значення байта для збереження.
- **Повертає**:
  - `true` — байт успішно збережено в масиві.
  - `false` — буфер повністю заповнений; байт відкинуто, а `overrun_count` інкрементовано.
- **Потокобезпека**: викликається лише з контексту постачальника.

### `bool ring_buf_get(ring_buffer_t *rb, uint8_t *byte)`
- **Призначення**: вилучення одного найстарішого байта з початку черги.
- **Параметри**:
  - `rb` — покажчик на структуру буфера.
  - `byte` — адреса змінної, куди записується зчитане значення.
- **Повертає**:
  - `true` — байт успішно зчитано, індекс `tail` зсунуто вперед.
  - `false` — буфер порожній (`head == tail`), значення змінної не змінюється.

### `uint32_t ring_buf_available(const ring_buffer_t *rb)`
- **Призначення**: повертає поточну кількість байтів, готових до зчитування.
- **Повертає**: ціле число від `0` до `RING_BUF_SIZE - 1`.

### `uint32_t ring_buf_free_space(const ring_buffer_t *rb)`
- **Призначення**: повертає кількість вільних слотів, доступних для запису нових байтів.
- **Повертає**: ціле число від `0` до `RING_BUF_SIZE - 1`.

### `bool ring_buf_peek(const ring_buffer_t *rb, uint8_t *byte)`
- **Призначення**: зчитування чергового байта без його вилучення з буфера (без зміни індексу `tail`).
- **Повертає**: `true`, якщо буфер не порожній; інакше `false`.

### `void ring_buf_flush(ring_buffer_t *rb)`
- **Призначення**: миттєве скидання вмісту буфера.
- **Поведінка**: прирівнює індекс `tail` до значення `head`, миттєво звільняючи весь обсяг черги.
