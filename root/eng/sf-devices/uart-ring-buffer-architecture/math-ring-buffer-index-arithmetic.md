# Математична арифметика індексації кільцевого буфера

Кільцевий буфер (англ. *circular buffer* або *ring buffer*) моделює нескінченну послідовність слотів на обмеженому лінійному масиві пам'яті за допомогою циклічної індексації. Оскільки мікроконтролерні ядра часто позбавлені апаратного блока ділення або витрачають на операцію остачі від ділення десятки машинних тактів, оптимізація індексної арифметики є критичною для швидкодії переривань. Використання розмірів буфера, кратних степеням двійки, дозволяє замінити операцію взяття остачі блискавичним порозрядним логічним множенням.

## Математичне обґрунтування заміни остачі на бітову маску

Нехай розмір масиву пам'яті становить `N`, причому `N` є точним степенем двійки з показником `k`:

```
N = 2ᵏ                                   [визначення степеня двійки]
```

За теоремою про ділення з остачею будь-яке невід'ємне ціле число `x` можна подати в єдиній формі через неповну частку `q` та остачу `r`:

```
x = q × 2ᵏ + r,  де  0 ≤ r < 2ᵏ          [канонічний розклад числа]
```

У двійковій позиційній системі числення множення цілого числа на `2ᵏ` еквівалентне зсуву його двійкових розрядів вліво на `k` позицій. Отже, добуток `q × 2ᵏ` містить нульові значення у всіх молодших `k` розрядах (від біта `0` до біта `k - 1`).

Визначимо бітову маску `MASK` як число, на одиницю менше за розмір буфера:

```
MASK = N - 1
     = 2ᵏ - 1                            [значення двійкової маски]
```

Число `2ᵏ - 1` у двійковому записі містить рівно `k` молодших одиниць, тоді як усі старші біти дорівнюють нулю.

Знайдемо результат порозрядного логічного множення `x` на маску `MASK`:

```
x AND MASK = (q × 2ᵏ + r) AND (2ᵏ - 1)
           = ((q × 2ᵏ) AND (2ᵏ - 1)) OR (r AND (2ᵏ - 1)) [дистрибутивність кон'юнкції]
           = 0 OR r                      [оскільки молодші розряди (q × 2ᵏ) рівні нулю]
           = r                           [тотожність]
           = x mod 2ᵏ                    [еквівалентність остачі від ділення]
```

Цей висновок доводить строгу математичну еквівалентність: для будь-якого `N = 2ᵏ` взяття остачі `x mod N` повністю замінюється порозрядною операцією `x & (N - 1)`. На архітектурі процесора це скорочує час виконання з 12–35 тактів інструкції ділення до одного машинного такту операції `AND`.

## Обчислення кількості елементів без розгалужень умов

Позначимо поточний індекс запису через `head`, а індекс зчитування — через `tail`. Якщо `head ≥ tail`, кількість збережених байтів у буфері визначається простою різницею `head - tail`. Проте коли індекс запису доходить до кінця масиву і переходить через нуль (`head < tail`), виникає ситуація обгортання (@@en|wrap-around@@).

Класичний арифметичний розрахунок заповненості буфера `count` вимагає додавання розміру `N` при виникненні переходу:

```
count = (head - tail + N) mod N          [арифметичне визначення зайнятих слотів]
```

Застосовуючи властивості беззнакової арифметики за модулем `2ᵏ` у додатковому коді, різниця беззнакових цілих чисел `(head - tail)` автоматично перетворюється на коректне додатне зміщення при накладанні маски:

```
count = (head - tail) AND MASK           [безрозгалужене визначення довжини черги]
```

Ця формула не містить умовних переходів `if-else`, що виключає хибні передбачення розгалужень конвеєра (@@en|branch misprediction@@) у процесорі.

## Розрахунок на числовому прикладі

**Умова розрахунку**: Кільцевий буфер має обсяг `N = 64` байти (`k = 6`, `2⁶ = 64`). Бітова маска становить `MASK = 64 - 1 = 63` (`0x3F` або в двійковій системі `00111111₂`). Нехай індекс запису перейшов через нуль і набув значення `head = 5`, а індекс зчитування перебуває на позиції `tail = 58`.

Обчислимо наступний індекс для запису нового байта `head_next`:

```
head_next = (head + 1) AND MASK
          = (5 + 1) AND 63
          = 6 AND 63
          = 6                            [новий індекс у межах буфера]
```

Обчислимо поточну кількість збережених байтів у буфері `count`:

```
diff = 5 - 58
     = -53                               [проміжна різниця індексів]

count = (-53) mod 64
      = 64 - 53
      = 11 байтів                        [фактична кількість накопичених даних]
```

Перевіримо роботу порозрядної формули на 8-бітових числах без знаку: число `-53` у додатковому коді представляється як `256 - 53 = 203` (у двійковій формі `11001011₂`):

```
count = 203 AND 63
      = 11001011₂ AND 00111111₂
      = 00001011₂
      = 11                               [результат повністю збігся]
```

**Інженерний висновок**: Порозрядна маска `x & MASK` та беззнакова арифметика дозволяють вираховувати зміщення та розмір заповненості буфера рівно за одну інструкцію процесора, гарантуючи детермінований час виконання переривань незалежно від положення вказівників.
