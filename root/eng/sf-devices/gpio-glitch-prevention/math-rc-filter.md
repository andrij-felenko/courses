# Розрахунок параметрів RC-фільтра для придушення глітчів

Аналоговий низькочастотний фільтр першого порядку на базі резистора та конденсатора (@@en|RC low-pass filter@@) є класичним бар'єром проти високочастотних імпульсних наведень на вхідних лініях мікроконтролера. Математичний опис динаміки заряду ємності дозволяє розрахувати граничну тривалість імпульсу завади, яка гарантовано не викличе хибного спрацьовування вхідного цифрового каскаду.

## Диференціальне рівняння та перехідна характеристика

Проходження сигналу через послідовний резистор `R` та паралельний конденсатор `C` описується лінійним неоднорідним диференціальним рівнянням першого порядку, що випливає із законів Кірхгофа:

```
R × C × (dv_out / dt) + v_out = v_in
```

Добуток опору та ємності визначає сталу часу ланцюга (@@en|time constant@@) `τ = R × C` (грец. @@el|tau@@). Якщо на вхід подається прямокутний стрибок напруги амплітудою `V_in` у момент часу `t = 0`, розв'язок диференціального рівняння для перехідної характеристики має експоненціальний вигляд:

```
v_out(t) = V_in × (1 - e^(-t / τ))
```

Частота зрізу (@@en|cutoff frequency@@) `f_c`, на якій потужність сигналу спадає вдвічі (затухання -3 дБ), обчислюється зі співвідношення:

```
f_c = 1 / (2 × π × R × C)
```

## Розрахунок придушення амплітуди імпульсної завади

Нехай на лінію надходить короткочасний сплеск напруги тривалістю `t_glitch` та амплітудою, що дорівнює напрузі живлення `V_DD = 3.3` В. Щоб цифровий вхідний каскад мікроконтролера з пороговою напругою логічної одиниці `V_IH = 2.0` В не зафіксував перемикання, пікова напруга на конденсаторі `v_peak` повинна строго задовольняти нерівність:

```
v_peak = V_DD × (1 - e^(-t_glitch / τ)) < V_IH
```

Перетворимо цю нерівність для визначення мінімально необхідної сталої часу `τ`:

```
1 - e^(-t_glitch / τ) < V_IH / V_DD
e^(-t_glitch / τ) > 1 - (V_IH / V_DD)
-t_glitch / τ > ln(1 - V_IH / V_DD)
τ > -t_glitch / ln(1 - V_IH / V_DD)
```

Розрахуємо мінімальне значення сталої часу `τ` для надійного придушення індуктивного глітчу тривалістю `t_glitch = 10` мкс при `V_DD = 3.3` В та `V_IH = 2.0` В:

```
V_IH / V_DD
= 2.0 / 3.3              [відношення порогової напруги до напруги живлення]
≈ 0.606                  [частка порогу від живлення]
```

```
1 - (V_IH / V_DD)
= 1 - 0.606              [залишок динамічного діапазону]
= 0.394                  [аргумент натурального логарифма]
```

```
ln(0.394)
≈ -0.9314                [обчислення логарифма]
```

```
τ_min
= -10 × 10⁻⁶ / (-0.9314) [ділення тривалості завади на логарифм]
≈ 1.074 × 10⁻⁵ с         [мінімальна стала часу 10.74 мкс]
```

## Вибір номіналів пасивних компонентів

Визначивши мінімальну сталу часу `τ = 10.74` мкс, розробник обирає номінал резистора `R` виходячи з обмеження струму витоку вхідного каскаду GPIO. Типовий вхідний струм витоку CMOS становить `I_leak ≈ 50` нА. Щоб падіння напруги на резисторі не перевищувало `0.5` мВ, опір обмежують значенням `R = 10` кОм (`10 000` Ом).

Розрахуємо необхідну ємність конденсатора `C`:

```
C
= τ / R                  [визначення ємності через сталу часу та опір]
= 1.074 × 10⁻⁵ / 10000   [підстановка розрахованих параметрів]
= 1.074 × 10⁻⁹ Ф         [розрахункове значення 1.074 нФ]
```

Обираємо найближчий стандартний номінал керамічного конденсатора ряду E24: `C = 1.0` нФ або `1.2` нФ.

Перевіримо частоту зрізу для обраних номіналів `R = 10` кОм та `C = 1.0` нФ:

```
f_c
= 1 / (2 × 3.14159 × 10000 × 1.0 × 10⁻⁹) [підстановка номіналів]
= 1 / (6.28318 × 10⁻⁵)   [добуток у знаменнику]
≈ 15915 Гц ≈ 15.9 кГц   [частота зрізу фільтра]
```

Фільтр повністю пропускає низькочастотні сигнали перемикання кнопок та сенсорів (до 1 кГц), одночасно ефективно ослаблюючи високочастотні завади комутації на частотах понад 16 кГц.
