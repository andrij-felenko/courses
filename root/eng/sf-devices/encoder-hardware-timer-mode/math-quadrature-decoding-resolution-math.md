# Математика квадратурного декодування та розрахунок роздільної здатності

Квадратурні енкодери генерують два прямокутні сигнали (фази A та B), зсунуті за фазою на 90 електричних градусів. Апаратний таймер мікроконтролера здатен детектувати фронти цих сигналів у трьох різних режимах множення роздільної здатності (1X, 2X та 4X). Для точного позиціонування та безаварійного розрахунку швидкості інженер повинен володіти математичним апаратом перетворення дискретних відліків у кутові координати та обґрунтувати частотні межі вхідних цифрових фільтрів.

## Режими множення роздільної здатності

Позначимо кількість базових фізичних імпульсів на один повний оберт вала енкодера через `PPR` (англ. *Pulses Per Revolution*). Повний електричний цикл складається з чотирьох послідовних станів пари сигналів `(A, B)`: `00 → 10 → 11 → 01` (при обертанні вперед).

Загальна кількість відліків лічильника на повний оберт `CPR` (англ. *Counts Per Revolution*) залежить від обраного апаратного режиму декодування:

1. **Режим 1X (підрахунок по наростаючому фронту фази A)**:
   Таймер інкрементує лічильник лише на одному фронті одного каналу:
```
CPR_1X = PPR                             [режим декодування 1X]
```

2. **Режим 2X (підрахунок по обох фронтах фази A)**:
   Таймер детектує як наростаючий, так і спадний перепади фази A:
```
CPR_2X = 2 × PPR                         [режим декодування 2X]
```

3. **Режим 4X (підрахунок по обох фронтах обох фаз A та B)**:
   Таймер фіксує кожен із чотирьох фазових переходів електричного циклу:
```
CPR_4X = 4 × PPR                         [режим декодування 4X]
```

Режим 4X забезпечує максимальну роздільну здатність без зміни механічної конструкції датчика.

Кутова роздільна здатність `Delta_theta` (мінімальний кут повороту, який реєструє система) виражається у градусах або радіанах через відношення повного кола до числа відліків:

```
Delta_theta = 360° ÷ CPR_4X
            = 360° ÷ (4 × PPR)           [мінімальна дискрета кута у градусах]
```

Ця величина визначає теоретичну границю точності апаратного позиціонування привода.

## Частота квадратурних перепадів та обмеження фільтра

Нехай швидкість обертання вала становить `RPM` (обертів на хвилину).

Частота обертання вала в секунду `f_rot` визначається діленням на 60:

```
f_rot = RPM ÷ 60                         [частота обертання у герцах]
```

Частота проходження базових імпульсів на одному каналі енкодера `f_ch` дорівнює добутку частоти обертання на роздільну здатність:

```
f_ch = PPR × f_rot
     = (PPR × RPM) ÷ 60                  [частота сигналів на каналі A або B]
```

Сумарна частота надходження квадратурних фронтів `f_quad`, яку повинна детектувати вхідна логіка таймера в режимі 4X, у чотири рази вища:

```
f_quad = 4 × f_ch
       = (4 × PPR × RPM) ÷ 60            [сумарна швидкість підрахунку дискрет]
```

Мінімальний часовий інтервал між сусідніми квадратурними фронтами `t_edge_min` визначається зворотною величиною:

```
t_edge_min = 1 ÷ f_quad                  [мінімальна тривалість фазового стану]
```

Щоб вхідний цифровий фільтр таймера не пропустив корисний квадратурний перепад, тривалість фільтрації завад `t_filter` зобов'язана бути меншою за мінімальний інтервал: `t_filter < t_edge_min`.

## Розрахунок кутової швидкості за різницею дискрет

Миттєва кутова швидкість вала `omega` (у радіанах за секунду) обчислюється за різницею показів лічильника `Delta_N` за фіксований дискретний проміжок часу `Delta_t`:

```
omega = (2 × pi × Delta_N) ÷ (CPR_4X × Delta_t)  [кутова швидкість у радіанах за секунду]
```

Швидкість в обертах на хвилину `N_rpm` знаходять через перевідний коефіцієнт:

```
N_rpm = (60 × Delta_N) ÷ (CPR_4X × Delta_t)     [швидкість в обертах на хвилину]
```

## Розрахунок на числовому прикладі

**Умова розрахунку**: Промисловий сервопривід обертається з максимальною швидкістю `RPM = 6000` об/хв. На валу змонтовано енкодер з роздільною здатністю `PPR = 2048` імп/об. Таймер мікроконтролера налаштовано в повному квадратурному режимі 4X. Період опитування швидкості складає `Delta_t = 0.001` с (1 мс).

Розрахуємо сумарну кількість відліків лічильника на повний оберт `CPR_4X` та кутову роздільну здатність:

```
CPR_4X = 4 × 2048
       = 8192                            [кількість дискрет на повний оберт]

Delta_theta = 360° ÷ 8192
            ≈ 0.043945°                  [дискретність кута становить приблизно 2.64 кутові мінути]
```

Обчислимо максимальну частоту сигналів на одному каналі `f_ch` та сумарну швидкість рахунку таймера `f_quad`:

```
f_rot = 6000 ÷ 60
      = 100 Гц                           [100 обертів вала на секунду]

f_ch = 2048 × 100
     = 204800 Гц
     = 204.8 кГц                         [частота імпульсів на виводі A]

f_quad = 4 × 204800
       = 819200 Гц
       = 819.2 кГц                       [частота квадратурних перемикань]
```

Знайдемо мінімальний часовий інтервал між квадратурними перепадами `t_edge_min`:

```
t_edge_min = 1 ÷ 819200
           ≈ 1.2207 × 10⁻⁶ с
           ≈ 1.22 мкс                    [тривалість найкоротшого фазового стану]
```

Обчислимо зміну показів лічильника `Delta_N` за період `Delta_t = 1` мс на максимальній швидкості:

```
Delta_N = (CPR_4X × RPM × Delta_t) ÷ 60
        = (8192 × 6000 × 0.001) ÷ 60
        = 819.2                          [приблизно 819 дискрет за кожну мілісекунду]
```

**Інженерний висновок**: Апаратний таймер повинен гарантовано обробляти частоту до 820 кГц. Вхідний цифровий фільтр придушення завад повинен мати вікно менше 1.22 мікросекунди (наприклад, 200–400 нс), інакше на швидкості 6000 об/хв лічильник втрачатиме координату вала.
