## 1. Алгебраїчне доведення перетину кворумів

Розглянемо розподілену систему, що складається з універсальної скінченної множини вузлів `U`, де загальна кількість вузлів дорівнює `|U| = N`.

Кожна операція мутації (запису) фіксується на деякій підмножині вузлів `W ⊆ U` потужністю `|W| = W` (кворум запису). Кожен вузол із множини `W` зберігає нове значення даних разом із монотонно зростаючим номером версії `v_new`.

Операція зчитування стану опитує довільну підмножину вузлів `R ⊆ U` потужністю `|R| = R` (кворум читання) і збирає відповіді з версіями.

### Теорема про непустий перетин (Pigeonhole Quorum Theorem)
Якщо параметри системи задовольняють строгу нерівність:

```
W + R > N
```

тоді множина вузлів перетину `W ∩ R` є гарантовано непорожньою, а її потужність строго більша або дорівнює одиниці:

```
|W ∩ R| ≥ 1
```

### Строге виведення

За фундаментальною теоремою теорії множин про потужність об'єднання двох скінченних множин (принцип включень-виключень):

```
|W ∪ R| = |W| + |R| - |W ∩ R|
```

Звідси виражаємо потужність множини перетину:

```
|W ∩ R| = |W| + |R| - |W ∪ R|
```

Оскільки обидві підмножини `W` та `R` є частинами універсальної множини `U`, їхнє об'єднання також є підмножиною `U`:

```
(W ∪ R) ⊆ U  ⇒  |W ∪ R| ≤ |U| = N
```

Підставляючи оцінку зверху `|W ∪ R| ≤ N` у формулу для потужності перетину, отримуємо нижню межу:

```
|W ∩ R| ≥ |W| + |R| - N
```

Оскільки всі змінні є цілими додатними числами, умова `W + R > N` еквівалентна нерівності `W + R ≥ N + 1`. Підставляючи це значення:

```
|W ∩ R| ≥ (N + 1) - N = 1
```

**Фізичний зміст інваріанта:** У будь-якій вибірці з `R` довільних вузлів системи обов'язково присутній щонайменше `k = W + R - N` вузлів, які брали участь у фіксації останнього запису `W`. Оскільки опитані вузли повертають свої локальні копії разом із номерами версій, клієнт або координатор обирає максимальну версію, гарантовано спостерігаючи `v_new`.

## 2. Ймовірність застарілого читання при послаблених кворумах (PBS)

У високонавантажених системах інженери часто обирають швидкісні конфігурації (наприклад, `N = 5, W = 2, R = 2`), для яких умова суворого перетину свідомо порушується:

```
W + R = 2 + 2 = 4 ≤ 5   [умова W + R > N не виконується]
```

Такий компроміс дозволяє знизити латентність запису та читання, проте вводить ймовірність прочитати старе значення (**Stale Read**).

### Гіпергеометрична модель випадкового вибору

Нехай у кластері з `N` вузлів рівно `W` вузлів успішно отримали та зберегли нову версію `v_new`, а решта `N - W` вузлів залишаються застарілими зі значенням `v_old`.

Клієнт випадковим і незалежним чином обирає `R` вузлів для виконання запиту читання.

1. Загальна кількість усіх можливих способів обрати `R` вузлів із загальної кількості `N` дорівнює числу комбінацій (біноміальному коефіцієнту):

```
Кількість усіх вибірок = C(N, R) = N! / (R! · (N - R)!)
```

2. Подія застарілого читання `E_stale` настає тоді й лише тоді, коли **всі `R` опитаних вузлів потрапили виключно в підмножину з `N - W` застарілих машин** (тобто перетин `W ∩ R` виявився порожнім).

3. Кількість таких несприятливих вибірок дорівнює числу способів обрати `R` вузлів із `N - W` застарілих:

```
Кількість застарілих вибірок = C(N - W, R) = (N - W)! / (R! · (N - W - R)!)
```

4. Точна ймовірність отримати застаріле значення `P(Stale)` виражається класичним гіпергеометричним розподілом:

```
P(Stale) = C(N - W, R) / C(N, R)   [за умови W + R ≤ N та R ≤ N - W]
```

Якщо `W + R > N`, то `N - W < R`, число комбінацій `C(N - W, R) = 0`, і ймовірність аномалії строго дорівнює нулю: `P(Stale) = 0`.

### Покроковий розрахунковий приклад: кластер із 5 вузлів

Порівняємо три конфігурації для `N = 5`:

#### Сценарій 1: Мажоритарний строгий кворум (N = 5, W = 3, R = 3)
```
W + R = 3 + 3 = 6 > 5
P(Stale) = 0.0 (0%)   [перетин гарантований]
```

#### Сценарій 2: Асиметричний кворум (N = 5, W = 4, R = 2)
```
W + R = 4 + 2 = 6 > 5
P(Stale) = 0.0 (0%)   [перетин гарантований, оптимізовано під читання]
```

#### Сценарій 3: Послаблений швидкісний кворум (N = 5, W = 2, R = 2)
Обчислимо ймовірність застарілого читання покроково:

```
C(N, R) = C(5, 2)
= 5! / (2! · (5 - 2)!)
= (5 · 4 · 3!) / (2 · 1 · 3!)
= 20 / 2
= 10              [всього 10 рівноймовірних пар вузлів для читання]

N - W = 5 - 2 = 3 [кількість застарілих вузлів у системі]

C(N - W, R) = C(3, 2)
= 3! / (2! · 1!)
= 3               [кількість пар, складених лише із застарілих машин]

P(Stale)
= C(3, 2) / C(5, 2)
= 3 / 10
= 0.30 (30.0%)    [30% клієнтських запитів читання повернуть застарілий стан!]
```

## 3. Часово-залежна ймовірнісна консистентність (t-Visibility PBS)

У реальному кластері стан не залишається статичним: фонові процеси реплікації безперервно передають дельти на решту `N - W` вузлів.

Нехай час поширення повідомлення від координатора до вузла `i` є випадковою величиною `L_i` з функцією розподілу `F_L(t) = P(L_i ≤ t)`.

Якщо операція запису завершилася в момент `t_0`, то через інтервал `Δt` кожен із залишкових `N - W` вузлів отримує оновлення з імовірністю `p(Δt) = F_L(Δt)`.

Кількість оновлених вузлів до моменту `t_0 + Δt` є випадковою величиною `K(Δt) = W + B`, де `B` має біноміальний розподіл:

```
B ~ Binomial(N - W, p(Δt))
```

Тоді ймовірність спостереження застарілого стану під час читання через час `Δt` після запису падає експоненційно:

```
P(Stale | Δt) = ∑_{b = 0}^{N - W} [ C(N - (W + b), R) / C(N, R) ] · C(N - W, b) · [p(Δt)]^b · [1 - p(Δt)]^(N - W - b)
```

Для експоненційного закону затримки мережі `F_L(t) = 1 - e^(-λ · t)` із середньою затримкою реплікації `1/λ = 20` мс, ймовірність застарілого читання при `N=5, W=2, R=2` стрімко згасає в часі:
- При `Δt = 0` мс: `P(Stale) = 30.0%`
- При `Δt = 20` мс: `P(Stale) ≈ 8.4%`
- При `Δt = 60` мс: `P(Stale) ≈ 0.6%`
- При `Δt = 100` мс: `P(Stale) < 0.05%`

## 4. Марковська модель збіжності реплік під дією Gossip-антиентропії

Якщо система спирається на фоновий протокол пліток (Gossip Protocol), де кожен вузол у кожному раунді обирає один випадковий інший вузол для синхронізації, динаміка оновлення кластера моделюється дискретним ланцюгом Маркова.

Нехай стан ланцюга `S_i` позначає кількість вузлів у кластері, які володіють свіжою версією даних (`i ∈ {W, W+1, ..., N}`).

Позначимо через `p_{i, j}` ймовірність того, що за один раунд протоколу кількість оновлених вузлів зросте з `i` до `j`.

У кожному раунді кожен із `i` оновлених вузлів відправляє дельту випадковому вузлу з імовірністю `1 / (N - 1)`. Імовірність того, що конкретний застарілий вузол **не** буде обраний жодним із `i` активних вузлів, дорівнює:

```
q_miss(i) = [ 1 - 1 / (N - 1) ]^i
```

Відповідно, ймовірність того, що застарілий вузол отримає оновлення за цей раунд:

```
p_hit(i) = 1 - q_miss(i) = 1 - [ 1 - 1 / (N - 1) ]^i
```

Оскільки в кластері є `N - i` застарілих вузлів, кількість новооновлених вузлів `k = j - i` підпорядковується біноміальному розподілу:

```
p_{i, j} = C(N - i, j - i) · [p_hit(i)]^(j - i) · [1 - p_hit(i)]^(N - j)
```

Матриця перехідних ймовірностей є верхньотрикутною, а стан `S_N` (усі `N` вузлів оновлені) є **поглинаючим станом (Absorbing State)**.

Середня кількість раундів `E[T_converge]` до досягнення 100% консистентності кластера асимптотично оцінюється логарифмічною залежністю:

```
E[T_converge] = O(log N)
```

## 5. Аналіз хвостової латентності: теорія порядкових статистик

Час відгуку розподіленої операції кворуму визначається не середньою швидкістю вузлів, а поведінкою хвостових перцентилів (Tail Latency).

Нехай час обробки запиту окремим вузлом є незалежною неперервною випадковою величиною `X_i` із щільністю ймовірності `f(t)` та функцією розподілу `F(t) = P(X_i ≤ t)`.

Координатор надсилає запити одночасно на всі `N` вузлів і повертає відповідь клієнту, щойно отримає `k` найшвидших підтверджень (де `k = W` для запису або `k = R` для читання).

Час завершення операції `T_k` є **`k`-ою порядковою статистикою (k-th Order Statistic)** вибірки розміру `N`:

```
T_k = X_(k:N)
```

Функція розподілу часу завершення операції `F_{k:N}(t) = P(X_(k:N) ≤ t)` визначається ймовірністю того, що щонайменше `k` із `N` вузлів дадуть відповідь за час `≤ t`:

```
F_{k:N}(t) = ∑_{j = k}^{N} C(N, j) · [F(t)]^j · [1 - F(t)]^(N - j)
```

### Порівняння повного узгодження (W = N) проти мажоритарного кворуму (W = ⌈(N+1)/2⌉)

Розглянемо випадок експоненційного розподілу затримки вузла `F(t) = 1 - e^(-λ · t)` із середнім часом відповіді `μ = 1/λ = 10` мс для кластера `N = 5`:

1. **Режим повної синхронізації (`W = 5`, `k = 5`):**
   Час операції визначається максимумом: `T_5 = max(X_1, ..., X_5)`.
   Математичне сподівання часу завершення дорівнює сумі гармонічного ряду:

```
E[T_5] = μ · ∑_{m = 1}^{5} (1 / m)
= 10 · (1 + 1/2 + 1/3 + 1/4 + 1/5)
= 10 · (2.283)
= 22.83 мс
```

2. **Режим мажоритарного кворуму (`W = 3`, `k = 3`):**
   Час операції визначається медіаною: `T_3 = X_(3:5)`.
   Математичне сподівання дорівнює:

```
E[T_3] = μ · ∑_{m = 3}^{5} (1 / m)
= 10 · (1/3 + 1/4 + 1/5)
= 10 · (0.783)
= 7.83 мс
```

```
Повний запис (W = 5):      Середній час = 22.83 мс   |  p99 латентність ~ 46.0 мс
Мажоритарний кворум (W = 3): Середній час = 7.83 мс    |  p99 латентність ~ 18.2 мс
```

**Математичний висновок:** Перехід від повної синхронізації (`W = N`) до кворуму більшості (`W = ⌈(N+1)/2⌉`) прискорює середню операцію в **2.9 раза**, а хвостову p99 латентність — у **2.5 раза**, повністю усуваючи вплив поодиноких «завислих» вузлів на загальну продуктивність кластера.
