# 🧮 Математичне моделювання надійності комірок і комбінаторика перемішаного шардування

У багатоорендарних розподілених системах надійність вимірюється не лише ймовірністю безвідмовної роботи окремого сервера, але й математичним сподіванням частки користувачів, які втрачають доступ під час збоїв. Коміркова архітектура та перемішане шардування трансформують лінійні ризики відмов у комбінаторно малі величини.

## 1. Радіус ураження та доступність системи

Нехай система обслуговує загальну кількість активних орендарів `M`. Кожен орендар створює потік запитів, а сервери додатків та бази даних мають певну статистичну ймовірність зазнати відмови внаслідок апаратних збоїв, програмних помилок або шкідливого навантаження.

### Модель єдиного спільного кластера
У монолітній архітектурі або єдиному розподіленому кластері всі `M` орендарів використовують спільний пул серверів і єдиний кластер бази даних. Нехай інтенсивність виникнення фатального збою (пошкодження схеми даних, збій консенсусу або деградація пулу з'єднань) дорівнює `p`.

Коли стається збій, радіус ураження `B_mono` охоплює всю систему:

```
B_mono = 1.0 = 100%
```

Математичне сподівання кількості постраждалих клієнтів `E[U_mono]` дорівнює:

```
E[U_mono]
= M · B_mono          [визначення математичного сподівання кількості відмов]
= M · 1.0             [підстановка радіуса ураження моноліту]
= M                   [усі клієнти системи одночасно зазнають відмови]
```

### Коміркова модель з N автономними одиницями
Розділимо систему на `N` повністю ізольованих комірок, кожна з яких обслуговує рівну кількість орендарів:

```
m_cell = M / N
```

Припустимо, що аварії в комірках є взаємно незалежними випадковими подіями з однаковою ймовірністю відмови `p_cell`. Оскільки комірки не мають спільних дисків, мереж або пулів потоків, збій у комірці `i` не змінює умов функціонування комірки `j`.

Радіус ураження від виходу з ладу однієї комірки `B_cell` становить:

```
B_cell = 1 / N
```

Кількість постраждалих орендарів при збої однієї комірки дорівнює:

```
U_cell
= m_cell              [ємність однієї комірки]
= M / N               [частка від загальної кількості орендарів]
```

Якщо стається збій у `k` комірках одночасно (де `k ∈ {0, 1, ..., N}`), кількість відмовних одиниць є дискретною випадковою величиною `X`, що підпорядковується біноміальному розподілу ймовірностей:

```
P(X = k) = C(N, k) · (p_cell)ᵏ · (1 - p_cell)ᴺ⁻ᵏ
```

Математичне сподівання частки доступних орендарів у системі `A_sys` обчислюється як сума всіх можливих станів, зважених за їхньою ймовірністю:

```
A_sys
= ∑_{k=0}^{N} (1 - k / N) · P(X = k)      [сума зважених станів доступності системи]
= 1 - (1 / N) · ∑_{k=0}^{N} k · P(X = k)   [винесення константи за знак математичної суми]
= 1 - (1 / N) · (N · p_cell)               [математичне сподівання біноміального розподілу E[X] = N·p]
= 1 - p_cell                               [середня доступність системи збігається з доступністю комірки]
```

Головна перевага коміркового підходу полягає не стільки у зміні середньої доступності, скільки у радикальному зменшенні дисперсії збитків і «важких хвостів» розподілу втрат.

Обчислимо дисперсію частки постраждалих клієнтів `Var(B)` для обох архітектурних підходів:

```
Var(B_mono)
= 1² · p · (1 - p)                        [дисперсія для бінарного вибору «все або нічого»]
= p · (1 - p)

Var(B_cell)
= Var(X / N)                              [випадкова величина кількості аварій, поділена на константу N]
= (1 / N²) · Var(X)                       [квадратична властивість дисперсії Var(a·X) = a²·Var(X)]
= (1 / N²) · (N · p_cell · (1 - p_cell))  [підстановка аналітичної дисперсії біноміального розподілу]
= (p_cell · (1 - p_cell)) / N             [скорочення чисельника і знаменника на параметр N]
```

Дисперсія збитків зменшується рівно в `N` разів. Замість рідкісних, але катастрофічних зупинок усього бізнесу компанія отримує частіші, проте дрібні й локалізовані інциденти, кожен із яких зачіпає лише малу частку користувачів і легко виправляється без загальної паніки.

## 2. Комбінаторика перемішаного шардування (Shuffle Sharding)

При простому детермінованому шардуванні кожен орендар закріплюється за однією конкретною коміркою. Якщо клієнт генерує шкідливий запит (англ. *poison pill*), комірка аварійно зупиняється, позбавляючи зв'язку всіх `M / N` сусідніх клієнтів.

**Перемішане шардування (англ. *Shuffle Sharding*)** призначає кожному орендарю унікальну комбінацію з `K` різних комірок із загального пулу з `N` комірок (де `1 < K < N`). Запити орендаря розподіляються між його `K` виділеними комірками.

### Кількість унікальних віртуальних штампів
Загальна кількість можливих ізольованих призначень орендарів визначається біноміальним коефіцієнтом:

```
S = C(N, K) = N! / (K! · (N - K)!)
```

**Приклад розрахунку:**
Нехай загальний пул налічує `N = 16` фізичних комірок, а кожен орендар отримує комбінацію з `K = 4` комірок:

```
C(16, 4)
= 16! / (4! · (16 - 4)!)                  [визначення числа комбінацій з 16 по 4]
= (16 · 15 · 14 · 13) / (4 · 3 · 2 · 1)   [скорочення факторіала 12! у чисельнику і знаменнику]
= 43680 / 24                              [обчислення проміжних добутків]
= 1820                                    [підсумкова кількість унікальних віртуальних штампів]
```

Система з 16 фізичних одиниць утворює 1820 взаємно ізольованих віртуальних кластерів без необхідності закупівлі додаткового обладнання.

### Ймовірність взаємного впливу орендарів
Припустимо, один шкідливий орендар надсилає запит, який призводить до зависання всіх його `K` виділених комірок. Тобто з ладу виходять рівно `K` комірок з `N`.

Знайдемо ймовірність того, що інший довільний орендар зазнає повної відмови (тобто всі його `K` комірок повністю збігаються зі зламаними `K` комірками):

```
P(повна відмова)
= C(K, K) · C(N - K, 0) / C(N, K)         [гіпергеометрична ймовірність повного збігу K елементів]
= (1 · 1) / C(N, K)                       [значення C(K, K) = 1 та C(N-K, 0) = 1]
= 1 / C(N, K)                             [підсумкова ймовірність перетину множин]
```

Для конфігурації `N = 16, K = 4`:

```
P(повна відмова)
= 1 / 1820                                [підстановка розрахованого числа комбінацій]
≈ 0.000549 = 0.0549%                      [менше ніж одна десята відсотка]
```

Ймовірність того, що інший орендар зазнає часткової деградації (рівно `j` з його `K` комірок вийдуть з ладу, де `0 ≤ j ≤ K`):

```
P(втрата j комірок) = (C(K, j) · C(N - K, K - j)) / C(N, K)
```

Обчислимо розподіл для `N = 16, K = 4` при виході з ладу `F = 4` комірок шкідливого клієнта:

1. **Жодної втрати (`j = 0` — орендар повністю здоровий):**
```
P(j = 0)
= (C(4, 0) · C(12, 4)) / C(16, 4)         [підстановка нульового збігу j = 0]
= (1 · 495) / 1820                        [значення комбінацій C(12, 4) = 495]
= 495 / 1820                              [спрощення арифметичного виразу]
≈ 0.2720 = 27.20%                         [частка клієнтів без жодного впливу збою]
```

2. **Втрата 1 комірки (`j = 1` — працездатні 3 із 4, тобто 75% ємності збережено):**
```
P(j = 1)
= (C(4, 1) · C(12, 3)) / C(16, 4)         [підстановка одиничного збігу j = 1]
= (4 · 220) / 1820                        [значення C(4, 1) = 4 та C(12, 3) = 220]
= 880 / 1820                              [обчислення чисельника]
≈ 0.4835 = 48.35%                         [майже половина клієнтів втрачає лише чверть ємності]
```

3. **Втрата 2 комірок (`j = 2` — працездатні 2 із 4, тобто 50% ємності збережено):**
```
P(j = 2)
= (C(4, 2) · C(12, 2)) / C(16, 4)         [підстановка збігу двох елементів j = 2]
= (6 · 66) / 1820                         [значення C(4, 2) = 6 та C(12, 2) = 66]
= 396 / 1820                              [обчислення чисельника]
≈ 0.2176 = 21.76%                         [збережено половину пропускної здатності]
```

4. **Втрата 3 комірок (`j = 3` — працездатна 1 із 4, тобто 25% ємності збережено):**
```
P(j = 3)
= (C(4, 3) · C(12, 1)) / C(16, 4)         [підстановка збігу трьох елементів j = 3]
= (4 · 12) / 1820                         [значення C(4, 3) = 4 та C(12, 1) = 12]
= 48 / 1820                               [обчислення чисельника]
≈ 0.0264 = 2.64%                          [сильна деградація ємності]
```

5. **Повна втрата зв'язку (`j = 4` — втрачено всі 4 комірки):**
```
P(j = 4)
= (C(4, 4) · C(12, 0)) / C(16, 4)         [підстановка повного збігу j = 4]
= (1 · 1) / 1820                          [одиничні множники]
= 1 / 1820                                [підсумковий дріб]
≈ 0.000549 = 0.0549%                      [повний збій виникає лише в 1 із 1820 випадків]
```

Підсумок: понад 97.3% клієнтів зберігають від 50% до 100% своєї пропускної здатності навіть у момент масштабної аварії, спричиненої виходом з ладу 4 фізичних комірок одночасно.

## 3. Розрахунок ємності та черг у межах комірки (M/M/c/K)

Кожна комірка є самостійною замкненою системою масового обслуговування. Щоб комірка не переходила в режим деградації через шторм запитів, її параметри розраховуються за формулами ерлангівського аналізу черг.

Нехай:
- `λ_cell` — сумарний вхідний потік запитів на комірку (запитів за секунду);
- `μ` — інтенсивність обслуговування одного робочого потоку/процесу (`μ = 1 / T_srv`, де `T_srv` — середній час виконання запиту);
- `c` — кількість паралельних серверних обробників у комірці;
- `k_buf` — максимальна місткість черги очікування перед відхиленням запиту.

Коефіцієнт завантаження комірки `ρ`:

```
ρ = λ_cell / (c · μ)
```

Для забезпечення стабільності та відсутності нескінченного росту затримок необхідно виконання умови:

```
ρ < 0.70                                  [запас ємності 30% на пікові сплески]
```

При стабільному режимі середня кількість запитів у системі комірки `L_sys` за законом Літтла (англ. *Little's Law*):

```
L_sys = λ_cell · W_sys
```

де `W_sys = W_queue + T_srv` — повний час перебування запиту в системі (затримка в черзі плюс час обробки). Оскільки розмір комірки жорстко обмежений, величина `λ_cell` має детерміновану верхню межу, що запобігає колапсу пулів з'єднань і дозволяє точно калібрувати апаратні ресурси.
