# 🧮 Математична модель узгоджених перерізів і ґратки глобальних станів

Математичний апарат розподіленого знімка базується на теорії частково впорядкованих множин (англ. *poset*, від *partially ordered set*) та дистрибутивних ґраток (англ. *distributive lattices*). Щоб строго довести коректність знімка, необхідно формалізувати поняття розподіленого виконання, причинного перерізу, нижніх ідеалів та досяжності глобальних станів.

## Формальна модель розподіленого виконання

Нехай розподілена система складається зі скінченної множини процесів `P = {P₁, P₂, ..., Pₙ}`. Процеси не мають спільної пам'яті та взаємодіють виключно шляхом передачі повідомлень через орієнтовані канали зв'язку `C_ij` (канал передачі від процесу `P_i` до `P_j`).

Локальне виконання кожного процесу `P_i` моделюється як лінійно впорядкована послідовність локальних подій:

```
H_i = e_i¹, e_i², e_i³, ...
```

Кожна окрема подія `e` належить до одного з трьох базових типів:
1. **Внутрішня подія процесу** (англ. *internal event*) — локальна модифікація стану пам'яті або виконання обчислення без мережевої взаємодії.
2. **Подія відправлення повідомлення** `send(m)` у вихідний канал зв'язку `C_ij`.
3. **Подія отримання повідомлення** `receive(m)` із вхідного каналу зв'язку `C_ji`.

Сукупність усіх подій, що відбулися в розподіленій системі протягом виконання, позначається множиною:

```
E = ⋃ { e_i^k | i ∈ {1..n}, k ≥ 1 }
```

Відношення причинності Лампорта `→` (англ. *happened-before relation*) задає строгий частковий порядок на множині `E` відповідно до трьох аксіом:
1. **Локальний порядок:** Якщо події `a` та `b` відбулися на одному процесі `P_i`, і `a` передує `b` у послідовності `H_i`, то `a → b`.
2. **Причинність передачі повідомлення:** Якщо подія `a` є відправленням повідомлення `send(m)`, а подія `b` — його отриманням `receive(m)`, то `a → b`.
3. **Транзитивність:** Якщо `a → b` та `b → c`, то `a → c`.

Якщо для двох подій `a` та `b` не виконується ні `a → b`, ні `b → a`, події називаються конкурентними (паралельними), що позначається як `a || b`.

## Поняття перерізу та причинна замкненість

**Переріз** (англ. *cut*) розподіленої системи — це довільна підмножина подій `C ⊆ E`, яка для кожного процесу `P_i` містить початковий префікс його локальної історії `H_i`:

```
C = ⋃ C_i,  де C_i ⊆ H_i та (∀ e_i^k ∈ C_i, ∀ m < k ⇒ e_i^m ∈ C_i)
```

Переріз однозначно визначає **локальний стан** кожного процесу `s_i` як стан `P_i` безпосередньо після виконання останньої події з префікса `C_i`. Вектор таких станів формує просторовий зріз розподіленої системи.

### Означення узгодженого перерізу
Переріз `C` називається **узгодженим** (англ. *consistent cut*), якщо він є **причинно замкненим** (нижнім ідеалом або *downward-closed set* у частково впорядкованій множині `(E, →)`):

```
∀ e, e' ∈ E : (e ∈ C ∧ e' → e) ⇒ e' ∈ C
```

Змістовна інтерпретація причинної замкненості полягає в тому, що якщо до перерізу потрапив деякий наслідок, то всі події, які спричинили цей наслідок у минулому, також гарантовано містяться всередині перерізу.

### Теорема про відсутність повідомлень-привидів

Нехай `send(m)` — подія відправлення повідомлення `m`, а `receive(m)` — подія його отримання.

```
Теорема:
Переріз C є узгодженим тоді і тільки тоді, коли:
∀ m : (receive(m) ∈ C ⇒ send(m) ∈ C)
```

**Доведення:**
1. **Необхідність (⇒):** Нехай `C` — узгоджений переріз, і подія отримання повідомлення належить перерізу: `receive(m) ∈ C`. За означенням відношення причинності Лампорта подія відправлення завжди передує події отримання: `send(m) → receive(m)`. Оскільки переріз `C` причинно замкнений, з умов `receive(m) ∈ C` та `send(m) → receive(m)` безпосередньо випливає `send(m) ∈ C`.
2. **Достатність (⇐):** Припустимо, що умова `receive(m) ∈ C ⇒ send(m) ∈ C` виконується для всіх повідомлень у системі. Розглянемо довільні події `b ∈ C` та `a → b`. За означенням часткового порядку `→` існує скінченний причинний ланцюг подій `a = e₀ → e₁ → ... → e_k = b`. Кожен крок `e_{j-1} → e_j` у цьому ланцюзі представляє собою або два послідовні кроки одного процесу, або пару `send(m) → receive(m)`. Якщо `e_j ∈ C` є локальною подією процесу `P_i`, її локальний попередник `e_{j-1}` також належить `C` за означенням префікса `C_i`. Якщо `e_j = receive(m) ∈ C`, то за нашим припущенням `e_{j-1} = send(m) ∈ C`. Застосовуючи математичну індукцію за довжиною ланцюга `k`, отримуємо `a = e₀ ∈ C`. Отже, переріз `C` є причинно замкненим та узгодженим.

## Стан комунікаційних каналів у знімку

Глобальний стан розподіленої системи `S(C)` для довільного узгодженого перерізу `C` складається з локальних станів усіх процесів та станів усіх спрямованих каналів:

```
S(C) = ( { s_i(C_i) | i = 1..n }, { channel_state(C_ij) | i, j = 1..n, i ≠ j } )
```

Стан каналу зв'язку `channel_state(C_ij)` визначається як множина повідомлень, які були надіслані процесом `P_i` до лінії перерізу, але ще не були отримані процесом `P_j` на момент його локального знімка:

```
channel_state(C_ij) = { m | send(m) ∈ C_i ∧ receive(m) ∉ C_j }
```

Оскільки переріз `C` узгоджений, ситуація `send(m) ∉ C_i ∧ receive(m) ∈ C_j` (отримання без відправки) математично неможлива, і відповідна множина є порожньою. Повідомлення можуть перетинати межу перерізу виключно з минулого в майбутнє, що відповідає транзитному стану в польоті.

## Ґратка узгоджених глобальних станів

Нехай `Σ` — множина всіх можливих узгоджених перерізів заданого розподіленого виконання `(E, →)`.

```
Теорема (Дистрибутивність ґратки станів):
Алгебраїчна структура (Σ, ⊆) є обмеженою дистрибутивною ґраткою
відносно операцій об'єднання (∪) та перетину (∩) множин.
```

**Доведення:**
1. **Замкненість щодо перетину:** Нехай `C₁, C₂ ∈ Σ`. Візьмемо довільну подію `e ∈ C₁ ∩ C₂` та подію `e' → e`. Оскільки `e ∈ C₁`, а `C₁` узгоджений, маємо `e' ∈ C₁`. Аналогічно, оскільки `e ∈ C₂`, маємо `e' ∈ C₂`. Звідси `e' ∈ C₁ ∩ C₂`, отже перетин `C₁ ∩ C₂` є узгодженим перерізом (найбільшим спільним причинним минулим).
2. **Замкненість щодо об'єднання:** Нехай `C₁, C₂ ∈ Σ`. Візьмемо довільну подію `e ∈ C₁ ∪ C₂` та подію `e' → e`. Тоді `e ∈ C₁` або `e ∈ C₂`. Якщо `e ∈ C₁`, то `e' ∈ C₁ ⊆ C₁ ∪ C₂`. Якщо `e ∈ C₂`, то `e' ∈ C₂ ⊆ C₁ ∪ C₂`. В обох випадках `e' ∈ C₁ ∪ C₂`, отже об'єднання `C₁ ∪ C₂` є узгодженим перерізом (найменшим спільним майбутнім).
3. **Дистрибутивність:** Оскільки теоретико-множинні операції об'єднання та перетину задовольняють законам дистрибутивності `(A ∪ B) ∩ C = (A ∩ C) ∪ (B ∩ C)`, ґратка `(Σ, ⊆)` є дистрибутивною.

За фундаментальною теоремою Біркгофа про представлення скінченних дистрибутивних ґраток, будь-яка скінченна дистрибутивна ґратка ізоморфна ґратці нижніх ідеалів часткового порядку подій.

## Теорема про досяжність та лінеаризовність знімка Чанді-Лампорта

Нехай `S_init` — фізичний глобальний стан системи безпосередньо перед початком виконання алгоритму знімка (коли жоден вузол ще не зафіксував локальний стан). Нехай `S_final` — фізичний глобальний стан після того, як останній процес отримав усі маркери.

Нехай `S*` — глобальний стан, зібраний алгоритмом Чанді-Лампорта.

```
Теорема (Досяжність):
1. Стан S* є узгодженим глобальним станом (S* ∈ Σ).
2. Стан S* є досяжним із початкового стану: S_init ⇝ S*.
3. Кінцевий стан S_final є досяжним зі стану знімка: S* ⇝ S_final.
```

**Схема доведення:**
Розподілене виконання задає частковий порядок подій `(E, →)`. Будь-яке реальне спостереження системи відповідає деякому **топологічному сортуванню** (лінеаризації) часткового порядку `E`, де події виконуються по одній.

Алгоритм Чанді-Лампорта розділяє всі події множини `E` на дві підмножини:
- `E_before` — події, що відбулися до відправлення або отримання маркерів (події, зафіксовані у стані вузлів або стані каналів).
- `E_after` — події, що відбулися після обробки маркерів.

За правилами алгоритму та завдяки властивості FIFO жодна подія з `E_after` не може причинно передувати події з `E_before` (не існує таких `a ∈ E_after` та `b ∈ E_before`, для яких `a → b`).

Отже, існує лінійний порядок подій, у якому спочатку виконуються всі події з `E_before`, приводячи систему зі стану `S_init` у стан `S*`, а потім виконуються всі події з `E_after`, переводячи систему зі стану `S*` у стан `S_final`. Тим самим доведено, що алгоритм фіксує абсолютно валідну точку на траєкторії простору станів розподіленої системи.
