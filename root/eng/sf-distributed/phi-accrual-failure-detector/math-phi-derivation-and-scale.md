# 🧮 Математичне виведення метрики підозри та логарифмічна шкала Phi

Ймовірнісний детектор відмов розраховує ступінь доступності віддаленого вузла на основі статистичного аналізу інтервалів між контрольними сигналами. Замість евристичних порогів алгоритм спирається на інтеграл правого хвоста функції густини ймовірності та логарифмічне перетворення правдоподібності події. Нижче наведено повне математичне виведення формули підозри `Φ` (грецька літера «фі»), оцінку чисельної стійкості та взаємозв'язок між обраним порогом і частотою помилкових спрацьовувань.

## 1. Статистичні оцінки у ковзному вікні вибірок

Нехай вузол-спостерігач `A` отримує послідовність контрольних сигналів пульсу (heartbeat) від віддаленого вузла `B` у локальні моменти часу `t₁, t₂, ..., tₙ`. Інтервал між двома послідовними надходженнями визначається як різниця:

```
Δt[i] = t[i] - t[i-1]
```

Для врахування динамічної зміни умов мережі детектор зберігає лише останні `W` вибірок у ковзному вікні (зазвичай `W = 1000`). Вибіркове середнє `μ` та незсунена вибіркова дисперсія `σ²` розраховуються за формулами:

```
μ = (1 / W) · ∑_{i=1}^{W} Δt[i]
```

```
σ² = (1 / (W - 1)) · ∑_{i=1}^{W} (Δt[i] - μ)²
```

Вибіркове стандартне відхилення `σ = √(σ²)` кількісно виражає рівень поточного тремтіння затримок (джиттеру).

Розмір вікна `W` є ключовим параметром точності:
* При малих розмірах вікна (`W = 50..100`) детектор миттєво адаптується до різких змін мережевих маршрутів, проте вибіркова дисперсія стає нестабільною через чутливість до випадкових поодиноких сплесків.
* При великих розмірах вікна (`W = 1000..2000`) оцінки `μ` та `σ` мають високу статистичну надійність, але час реакції на стійку деградацію мережі зростає пропорційно `W`.

## 2. Густина ймовірності та вибір моделі розподілу

В оригінальній моделі Наото Хаясібари припускається, що інтервали між прибуттями підпорядковуються нормальному (гаусовому) закону з параметрами `(μ, σ)`. Густина ймовірності `f(t)` має вигляд:

```
f(t) = (1 / (σ · √(2π))) · e^(-(t - μ)² / (2σ²))
```

Хоча затримки в реальних пакетах IP-мереж мають асиметричний розподіл із «важкими хвостами» (heavy-tailed distribution, подібний до логнормального або розподілу Парето), гаусова апроксимація у ковзному вікні має дві фундаментальні математичні переваги:
1. **Центральна гранична теорема:** затримка доставки пакета через ланцюг із кількох маршрутизаторів та комутаторів формується як сума незалежних черг, що наближає сумарний час до нормального закону.
2. **Алгоритмічна складність `O(1)`:** обчислення параметрів нормального розподілу вимагає збереження лише двох акумуляторів — суми `∑ Δt[i]` та суми квадратів `∑ (Δt[i])²`, що дозволяє оновлювати статистику за константний час при отриманні кожного повідомлення.

Нехай `t_last` — мітка часу останнього успішно отриманого повідомлення від вузла `B`, а `t_now` — поточний локальний час на вузлі `A`. Час очікування чергового сигналу дорівнює:

```
t_diff = t_now - t_last
```

Ймовірність `P_later(t_diff)` того, що черговий сигнал затримається на час, більший або рівний `t_diff` (за умови, що віддалений вузол залишається справним і працює у звичному статистичному режимі), відповідає інтегралу від правого хвоста розподілу:

```
P_later(t_diff) = ∫_{t_diff}^{∞} f(t) dt = 1 - F(t_diff)
```

де `F(t)` — інтегральна функція розподілу (CDF) нормального закону:

```
F(t_diff) = (1 / 2) · (1 + erf((t_diff - μ) / (σ · √2)))
```

Тут `erf(z)` — стандартна функція помилок Гауса, визначена як:

```
erf(z) = (2 / √π) · ∫_{0}^{z} e^(-u²) du
```

## 3. Покрокове аналітичне виведення метрики Phi

Знайдемо аналітичний вираз для ймовірності запізнення `P_later(t_diff)`:

```
P_later(t_diff)
= 1 - F(t_diff)                                     [означення ймовірності правого хвоста]
= 1 - (1/2) · (1 + erf((t_diff - μ) / (σ · √2)))     [підстановка формули CDF нормального закону]
= 1 - 1/2 - (1/2) · erf((t_diff - μ) / (σ · √2))     [розкриття дужок]
= (1/2) · (1 - erf((t_diff - μ) / (σ · √2)))         [зведення подібних та винесення 1/2]
= (1/2) · erfc((t_diff - μ) / (σ · √2))              [застосування тотожності: erfc(z) = 1 - erf(z)]
```

де `erfc(z)` — додаткова функція помилок Гауса (Complementary Error Function).

Рівень підозри `Φ` за означенням Хаясібари визначається як від'ємний десятковий логарифм ймовірності запізнення:

```
Φ = -log₁₀(P_later(t_diff))
```

Розгорнемо вираз для `Φ` через властивості логарифма:

```
Φ
= -log₁₀(P_later(t_diff))                            [означення метрики підозри]
= -log₁₀((1/2) · erfc((t_diff - μ) / (σ · √2)))      [підстановка виведеної ймовірності P_later]
= -(log₁₀(1/2) + log₁₀(erfc((t_diff - μ) / (σ · √2)))) [логарифм добутку: log(a·b) = log(a) + log(b)]
= log₁₀(2) - log₁₀(erfc((t_diff - μ) / (σ · √2)))    [спрощення: -log₁₀(1/2) = -(-log₁₀(2)) = log₁₀(2)]
```

Оскільки `log₁₀(2) ≈ 0.30103`, остаточна формула для обчислення має вигляд:

```
Φ = 0.30103 - (ln(erfc((t_diff - μ) / (σ · √2))) / ln(10))
```

де `ln(10) ≈ 2.302585`.

## 4. Чисельна стійкість та асимптотичний розклад Лапласа

Під час обчислень на комп'ютері зі стандартною арифметикою подвійної точності (IEEE 754 `double`) пряме обчислення `erfc(z)` стикається з проблемою зникнення порядку (underflow): при `z > 6` значення `erfc(z) < 10⁻¹⁷`, що апаратно округлюється до нуля (`0.0`). Обчислення `-log₁₀(0.0)` повертає `+Infinity`, що призводить до втрати плавності метрики.

Для аргументів `z = (t_diff - μ) / (σ · √2) > 3` застосовують асимптотичний розклад Лапласа для додаткової функції помилок:

```
erfc(z) ≈ (e^(-z²) / (z · √π)) · (1 - 1/(2z²) + 3/(4z⁴) - ...)
```

Логарифмуючи обидві частини, отримуємо формулу, яка зберігає точність навіть при гігантських затримках:

```
ln(erfc(z)) ≈ -z² - ln(z) - ln(√π) + ln(1 - 1/(2z²))
```

Підставляючи цей розклад у вираз для `Φ`, маємо чисельно стійке наближення для великих значень затримки (`z > 3`):

```
Φ ≈ (z² + ln(z) + 0.57236) / 2.302585 - 0.30103
```

Це дозволяє монотонно і неперервно накопичувати рівень підозри від малих значень (`Φ = 1`) до екстремальних (`Φ = 50`), не ризикуючи отримати ділення на нуль або нескінченність.

## 5. Фізичний зміст та масштабування помилок

Метрика `Φ` має чітку ймовірнісну інтерпретацію: значення `Φ = k` означає, що ймовірність зафіксувати таку затримку від здорового вузла становить `10⁻ᵏ`.

Нехай вузол надсилає пульс кожні `T = 1.0` секунду (`μ = 1.0`). Очікуваний середній час між двома помилковими підозрами (Mean Time Between False Positives, MTBF) визначається як:

```
MTBF = T / P_later = T · 10^Φ
```

| Значення `Φ` | `P_later(t_diff)` | Очікуваний інтервал між хибними тривогами (при `T = 1 c`) |
| :--- | :--- | :--- |
| **`Φ = 1`** | `10⁻¹ = 0.1` (10%) | 10 секунд (надзвичайно агресивно) |
| **`Φ = 2`** | `10⁻² = 0.01` (1%) | 100 секунд ≈ 1.66 хвилини |
| **`Φ = 3`** | `10⁻³ = 0.001` (0.1%) | 1000 секунд ≈ 16.6 хвилин |
| **`Φ = 4`** | `10⁻⁴` (0.01%) | 10 000 секунд ≈ 2.77 години |
| **`Φ = 6`** | `10⁻⁶` | 1 000 000 секунд ≈ 11.57 днів |
| **`Φ = 8`** | `10⁻⁸` | 100 000 000 секунд ≈ 3.17 року (стандарт Cassandra) |
| **`Φ = 10`** | `10⁻¹⁰` | 10¹⁰ секунд ≈ 317 років |
| **`Φ = 12`** | `10⁻¹²` | 10¹² секунд ≈ 31 700 років (стандарт Akka Cluster) |

Кожне збільшення порогу `Φ` на одиницю експоненційно зменшує частоту помилкових спрацьовувань рівно в 10 разів, додаючи лише невелику сублінійну частку часу до виявлення реальної аварії:

```
T_D ≈ μ + σ · √2 · erfc_inv(2 · 10^(-Φ_th))
```

де `erfc_inv` — обернена додаткова функція помилок Гауса. Завдяки цій властивості система отримує математично гарантований захист від хибних спрацьовувань за мінімальної ціни затримки виявлення аварії.

## 6. Порівняння з експоненційною моделлю розподілу

У деяких спрощених моделях мережевої затримки замість нормального розподілу використовують експоненційний розподіл із параметром інтенсивності `λ = 1 / μ`:

```
f_exp(t) = λ · e^(-λ · t)
```

Для експоненційного закону інтеграл правого хвоста обчислюється тривіально без додаткових спеціальних функцій:

```
P_later_exp(t_diff) = ∫_{t_diff}^{∞} λ · e^(-λ · t) dt = e^(-λ · t_diff)
```

Тоді рівень підозри набуває лінійного вигляду:

```
Φ_exp = -log₁₀(e^(-λ · t_diff)) = λ · t_diff · log₁₀(e) ≈ 0.43429 · (t_diff / μ)
```

Незважаючи на простоту обчислення, експоненційна модель має суттєвий недолік: вона має властивість «відсутності пам'яті» (memoryless property) і припускає, що дисперсія завжди дорівнює квадрату середнього (`σ² = μ²`). Вона повністю не здатна врахувати низький джиттер у локальних мережах дата-центрів, де `σ ≪ μ`. Саме тому використання нормального розподілу з роздільним оцінюванням `μ` та `σ` залишається золотим стандартом у реальних хмарних системах.
