# 🧮 Алгебра причинності: частковий порядок, конуси та лінійне розширення годинників Лампорта

Цей розділ містить строго формалізоване математичне обґрунтування причинного порядку у розподілених системах, алгебраїчне доведення умови коректності годинника Лампорта (Clock Condition), теорію причинних конусів і узгоджених зрізів (Consistent Cuts), а також теорему про лінійне розширення часткового порядку до тотального.

## 1. Простір подій та алгебра часткового порядку

Нехай розподілена система складається зі скінченної множини процесів `P = {P₁, P₂, ..., P_n}`. Кожен процес `P_i` генерує дискретну лінійно впорядковану послідовність локальних дій:

```
E_i = {e_i¹, e_i², e_i³, ...}
```

Повним простором подій системи є диз'юнктне об'єднання множин усіх процесів:

```
E = ⋃ E_i    де i ∈ {1, ..., n}
```

Кожна подія `e ∈ E` належить до одного з трьох типів:
1. Внутрішня дія процесу (локальна зміна стану пам'яті).
2. Відправлення повідомлення `m` (позначається `send(m)`).
3. Отримання повідомлення `m` (позначається `recv(m)`).

### Означення відношення «сталося раніше» (Happened-Before)

Відношення «сталося раніше» (позначається `→` або `≺`) є бінарним відношенням на множині `E`, визначеним як найменше транзитивне замикання трьох базових аксіом:

```
1. Локальний порядок виконання:
   Якщо e_i^a, e_i^b ∈ E_i та a < b, то e_i^a → e_i^b

2. Мережева причинність:
   Для будь-якого повідомлення m: send(m) → recv(m)

3. Транзитивність:
   Якщо a → b та b → c, то a → c
```

### Алгебраїчні властивості частково впорядкованої множини (Poset)

Математична структура `(E, →)` утворює **строгий частковий порядок** (англ. *strict partially ordered set, poset*), що задовольняє такі аксіоми:

1. **Іррефлексивність**: для будь-якої події `a ∈ E` неможливо, щоб `a → a`. Подія не може передувати самій собі, оскільки передача інформації фізично обмежена скінченною швидкістю світла, а граф залежностей не містить циклів.
2. **Асиметричність**: якщо `a → b`, то вираз `b → a` є хибним. Наслідок не може впливати на власну причину.
3. **Транзитивність**: якщо `a → b` та `b → c`, то `a → c`.

Будь-яке скінченне виконання розподіленої системи можна представити у вигляді **орієнтованого ациклічного графа** (англ. *Directed Acyclic Graph, DAG*), де вершинами є події `E`, а ребрами — транзитивне скорочення відношення `→` (діаграма Гассе).

## 2. Причинні конуси, паралельність та узгоджені зрізи

Для кожної події `e ∈ E` простір подій ділиться на три взаємовиключні підмножини за допомогою геометричної аналогії з релятивістськими світловими конусами Ейнштейна:

1. **Конус минулого (Causal Past)** події `e`:
   Множина всіх подій, які причинно вплинули на `e`:
   ```
   ↓e = { x ∈ E | x → e }
   ```
   Стан процесу в момент події `e` може залежати виключно від підмножини `↓e`.

2. **Конус майбутнього (Causal Future)** події `e`:
   Множина всіх подій, на які подія `e` потенційно здатна вплинути:
   ```
   ↑e = { y ∈ E | e → y }
   ```

3. **Простір паралельності (Concurrent Events)**:
   Множина подій, які причинно незалежні від `e`:
   ```
   Conc(e) = E \ ( ↓e ∪ ↑e ∪ {e} )
   ```

Дві події `a, b ∈ E` називаються **паралельними** (позначається `a ∥ b`), якщо `a ∈ Conc(b)` (і відповідно `b ∈ Conc(a)`):

```
a ∥ b  ⇔  ¬(a → b) ∧ ¬(b → a)
```

Відношення паралельності `∥` є рефлексивним (`a ∥ a`) і симетричним (`a ∥ b ⇔ b ∥ a`), але **не є транзитивним**: із `a ∥ b` та `b ∥ c` не випливає `a ∥ c`. Підмножина подій, де будь-яка пара є паралельною, у теорії порядку називається **антиланцюгом** (англ. *antichain*). Максимальний антиланцюг відповідає миттєвому розподіленому зрізу системи.

## 3. Доведення умови коректності годинника Лампорта

Функція логічного годинника Лампорта є відображенням простору подій у множину натуральних чисел:

```
L: E → ℕ
```

Алгоритм обчислення функції `L` задається правилами:
- Для початкової події `e_i¹` процесу `P_i`: `L(e_i¹) = 1` (якщо це не подія отримання).
- Для локальної події `e_i^{k+1}` після `e_i^k`:
  `L(e_i^{k+1}) = L(e_i^k) + 1`.
- Для події відправлення `send(m)`: повідомлення маркується міткою `ts(m) = L(send(m))`.
- Для події отримання `recv(m)` на процесі `P_j` після локальної події `e_j^k`:
  `L(recv(m)) = max(L(e_j^k), ts(m)) + 1`.

### Теорема (Clock Condition)

```
Для будь-яких двох подій a, b ∈ E:
якщо a → b, то L(a) < L(b)
```

### Доведення (методом математичної індукції за довжиною причинного ланцюга)

**Базовий випадок (ланцюг довжини 1):**
Подія `b` безпосередньо слідує за подією `a`. Існує рівно два варіанти:
1. Події `a` і `b` відбулися на одному процесі `P_i`, причому `b = e_i^{k+1}`, `a = e_i^k`.
   За правилом оновлення локального лічильника:
   `L(b) = L(a) + 1 > L(a)  ⇒  L(a) < L(b)`.

2. Подія `a` є відправленням `send(m)` на процесі `P_i`, а `b` є отриманням `recv(m)` на процесі `P_j`.
   За правилом отримання повідомлення:
   `L(b) = max(L(prev), L(a)) + 1`.
   Оскільки за визначенням функції максимуму `max(x, y) ≥ y`, отримуємо:
   `L(b) ≥ L(a) + 1 > L(a)  ⇒  L(a) < L(b)`.

**Індукційний перехід:**
Припустимо, що твердження теореми виконується для будь-якого причинного ланцюга довжини `k ≥ 1`.
Розглянемо довільний ланцюг довжини `k + 1`:

```
a = e₀ → e₁ → e₂ → ... → e_k → e_{k+1} = b
```

За припущенням індукції для підланцюга довжини `k` маємо:
`L(a) < L(e_k)`.

Для останнього кроку `e_k → b` за базою індукції маємо:
`L(e_k) < L(b)`.

Застосовуючи властивість транзитивності відношення строгої числової нерівності на множині натуральних чисел:

```
L(a) < L(e_k) ∧ L(e_k) < L(b)
= L(a) < L(b)    [транзитивність строгого порядку < на ℕ]
```

Теорему повністю доведено для будь-якого скінченного ланцюга подій.

## 4. Необоротність імплікації та розмірність часткового порядку

Чому зворотне твердження `L(a) < L(b) ⇒ a → b` є хибним?

У теорії частково впорядкованих множин фундаментальну роль відіграє **розмірність за Дашніком — Міллером** (англ. *poset dimension*, `dim(Poset)`). Розмірністю часткового порядку називається мінімальна кількість лінійних порядків (ланцюгів), перетин яких повністю відновлює вихідний частковий порядок.

Для системи з `n` незалежних процесів розмірність причинного порядку `(E, →)` у загальному випадку дорівнює кількості процесів:

```
dim(E, →) = n
```

Скалярний годинник Лампорта `L(e)` відображає `n`-вимірний частковий порядок у **одновимірний** лінійний простір натуральних чисел `(ℕ, <)`:

```
L: (E, →) → (ℕ, <)    де dim(ℕ) = 1 < n = dim(E, →)
```

Відображення з простору вищої розмірності у простір нижчої розмірності неминуче втрачає інформацію про взаємну ортогональність (незалежність). Скалярний годинник проектує паралельні події на одну пряму, внаслідок чого неможливо відрізнити справжній причинний зв'язок `a → b` від паралельності `a ∥ b`, де подія `b` випадково отримала більше числове значення.

Щоб зберегти необхідну й достатню умову (`a → b ⇔ V(a) < V(b)`), розмірність вектора часу повинна точно дорівнювати розмірності системи `n`, що становить основу векторних годинників.

## 5. Побудова тотального порядку (Linear Extension)

Частковий порядок `(E, →)` залишає паралельні події `a ∥ b` непорівнянними. Для багатьох практичних алгоритмів (реплікація автоматів SMR, розподілені блокування) необхідний **строгий тотальний порядок** `<_L`, у якому будь-які дві різні події є однозначно порівнянними.

Визначимо бінарне відношення `<_L` на множині `E` через лексикографічне впорядкування пари `(L(e), PID(e))`, де `PID(e) ∈ {1, ..., n}` — унікальний числовий ідентифікатор процесу:

```
a <_L b  ⇔  ( L(a) < L(b) )  ∨  ( L(a) = L(b) ∧ PID(a) < PID(b) )
```

### Теорема про лінійне розширення

Відношення `<_L` є **коректним лінійним розширенням** (англ. *linear extension*, топологічним сортуванням) часткового порядку `(E, →)`:

1. **Тотальність**: для будь-яких двох різних подій `a ≠ b` виконується або `a <_L b`, або `b <_L a`.
   - Якщо `L(a) ≠ L(b)`, їх порівнюють значення лічильників.
   - Якщо `L(a) = L(b)` і події виникли на одному процесі, вони мають різні локальні порядкові номери, що унеможливлює рівність `L(a) = L(b)`.
   - Якщо `L(a) = L(b)` і події виникли на різних процесах, то `PID(a) ≠ PID(b)`, і порядок однозначно визначається нерівністю ідентифікаторів.

2. **Збереження причинності (Causal Consistency)**:
   ```
   a → b  ⇒  a <_L b
   ```
   *Доведення*: Якщо `a → b`, то за теоремою про Clock Condition маємо `L(a) < L(b)`. Перша умова диз'юнкції `L(a) < L(b)` є істинною незалежно від значень `PID(a)` і `PID(b)`. Отже, `a <_L b`.

Таким чином, розв'язання нічиїх за ідентифікатором процесу детерміновано лінеаризує граф подій, ніколи не порушуючи реальні причинно-наслідкові ланцюги системи.
