# 🧮 Девіація Аллана та спектральні складові шуму

Ця математична вставка розгортає строгий зв'язок між спектральною густиною фазового і частотного шуму генератора та двовибірковою дисперсією Аллана `σ_y²(τ)`. Вона виводить передавальну функцію часового вікна усереднення, інтегральне перетворення спектра у девіацію для п'яти канонічних моделей шуму, перекривну оцінку дисперсії (Overlapping AVAR), модифіковану дисперсію Аллана (MVAR) та часову девіацію (TDEV).

## Часові ряди відхилення частоти

Нехай реальний сигнал генератора описується коливанням із миттєвою фазою `Φ(t)` навколо номінальної кругової частоти `ω₀ = 2π·f₀`:

```
V(t) = V₀ · sin(2π·f₀·t + φ(t))
```

де `φ(t)` — випадкова нестабільність фази (у радіанах). Фазове відхилення зручно виразити в одиницях часу через функцію часової похибки `x(t)` (вимірюється в секундах):

```
x(t) = φ(t) / (2π·f₀)
```

Миттєве безрозмірне відносне відхилення частоти `y(t)` (англ. *fractional frequency offset*) є похідною від часової похибки `x(t)` за часом:

```
y(t) = (f(t) − f₀) / f₀ = dx(t) / dt = (1 / (2π·f₀)) · (dφ(t) / dt)
```

У реальних вимірюваннях частотомір не фіксує миттєву похідну, а підраховує кількість коливань за скінченний інтервал усереднення `τ`. Середнє відносне відхилення частоти `ȳₖ(τ)` на k-му інтервалі `[tₖ, tₖ + τ]` дорівнює:

```
ȳₖ(τ) = (1 / τ) · ∫ y(t) dt               [межі інтегрування від tₖ до tₖ+τ]
       = (1 / τ) · [x(tₖ + τ) − x(tₖ)]      [інтегрування похідної dx/dt]
```

Таким чином, усереднена частота є простою першою різницею фазових міток часу, поділеною на тривалість вікна `τ`.

## Чому розходиться вибіркова дисперсія

Класична вибіркова дисперсія для послідовності `N` послідовних відліків `ȳₖ` обчислюється як:

```
s²(N, τ) = (1 / (N − 1)) · ∑ (ȳₖ − ȳ)²
```

де `ȳ = (1 / N) · ∑ ȳₖ` — загальне вибіркове середнє.

Якщо процес `y(t)` містить флікер-шум частоти (зі спектральною густиною потужності `S_y(f) = h₋₁ · f⁻¹`) або випадкове блукання частоти (`S_y(f) = h₋₂ · f⁻²`), автокореляційна функція повільно спадає або взагалі не інтегровна біля нульової частоти `f → 0` (інфрачервона розбіжність).

Математичне сподівання класичної вибіркової дисперсії для шуму `f⁻¹` прямо залежить від кількості відліків `N`:

```
E[s²(N, τ)] ∝ h₋₁ · ln(N)
```

При `N → ∞` оцінка дисперсії прямує до нескінченності. Зі збільшенням тривалості експерименту вибіркове середнє `ȳ` не стабілізується, а дрейфує, «ковтаючи» дедалі повільніші гармоніки шуму. Вибіркова дисперсія стає функцією тривалості спостереження, втрачаючи властивість фізичної характеристики приладу.

## Двовибіркова дисперсія Аллана: оператор другої різниці

У 1966 році Девід Аллан запропонував зафіксувати розмір вибірки рівним `N = 2` для пари сусідніх інтервалів без проміжку між ними (`tₖ₊₁ = tₖ + τ`).

Дисперсія Аллана `σ_y²(τ)` (англ. *Allan variance*, або двовибіркова дисперсія без проміжків) визначається як математичне сподівання квадрата різниці двох сусідніх усереднених значень частоти:

```
σ_y²(τ) = ½ · E[(ȳₖ₊₁ − ȳₖ)²]
```

Підставивши вираз через часові похибки `x(t)`:

```
ȳₖ₊₁ − ȳₖ
= (1 / τ) · [x(tₖ + 2τ) − x(tₖ + τ)] − (1 / τ) · [x(tₖ + τ) − x(tₖ)]
= (1 / τ) · [x(tₖ + 2τ) − 2·x(tₖ + τ) + x(tₖ)]
```

Різниця частот `ȳₖ₊₁ − ȳₖ` є дискретною **другою різницею** фазової часової похибки `x(t)`. Звідси випливає формулювання дисперсії Аллана через мітки часу:

```
σ_y²(τ) = (1 / (2·τ²)) · E[(x(t + 2τ) − 2·x(t + τ) + x(t))²]
```

Оператор другої різниці діє в часовій області як фільтр високих частот: він повністю знищує постійний зсув фази `x₀` і сталий лінійний нахил частоти `α·t`, забезпечуючи скінченність дисперсії для шумів зі спектром аж до `f⁻²`.

Девіація Аллана `σ_y(τ)` є квадратним коренем з дисперсії:

```
σ_y(τ) = √[ σ_y²(τ) ]
```

Вона має ту саму безрозмірну розмірність, що й відносне відхилення частоти `y(t)`.

## Частотна характеристика та інтеграл зв'язку

Перейдемо у частотну область за допомогою перетворення Фур'є. Різницю сусідніх усереднених значень можна записати як згортку миттєвого процесу `y(t)` з імпульсною характеристикою `h_A(t)`:

```
ȳₖ₊₁ − ȳₖ = ∫ y(t') · h_A(t − t') dt'
```

де вагова функція `h_A(t)` задається двома сусідніми прямокутними імпульсами протилежного знака:

```
h_A(t) = { −1/τ,  коли 0 ≤ t < τ
         { +1/τ,  коли τ ≤ t < 2τ
         {  0,    для решти t
```

Обчислимо перетворення Фур'є функції `h_A(t)`:

```
H_A(f) = ∫ h_A(t) · e^(−j·2π·f·t) dt
       = (1/τ) · [ −∫₀^τ e^(−j·2π·f·t) dt + ∫_τ^(2τ) e^(−j·2π·f·t) dt ]
       = (1/τ) · (1 / (j·2π·f)) · [ −(1 − e^(−j·2π·f·τ)) + e^(−j·2π·f·τ)·(1 − e^(−j·2π·f·τ)) ]
       = −(1/τ) · (1 / (j·2π·f)) · (1 − e^(−j·2π·f·τ))²
```

Використовуючи тотожність `1 − e^(−j·θ) = 2j · e^(−j·θ/2) · sin(θ/2)`:

```
|1 − e^(−j·2π·f·τ)|² = 4 · sin²(π·f·τ)
|H_A(f)|² = (1 / τ²) · (1 / (4π²·f²)) · [4 · sin²(π·f·τ)]²
          = 2 · [sin⁴(π·f·τ) / (π·f·τ)²]
```

За теоремою Вінера — Хінчина дисперсія виходу лінійної системи дорівнює інтегралу від добутку спектральної густини потужності входу `S_y(f)` на квадрат модуля передавальної функції `|H_A(f)|²`. Враховуючи множник `½` у визначенні Аллана:

```
σ_y²(τ) = 2 · ∫₀^∞ S_y(f) · [sin⁴(π·f·τ) / (π·f·τ)²] df
```

Аналіз функції фільтрації `|H_A(f)|²`:
1. При `f → 0`: розклад `sin(π·f·τ) ≈ π·f·τ` дає `sin⁴(π·f·τ) / (π·f·τ)² ≈ (π·f·τ)⁴ / (π·f·τ)² = (π·f·τ)² ∝ f²`.
   Множник `f²` ефективно компенсує низькочастотні полюси спектра аж до `S_y(f) ∝ f⁻²`, усуваючи розбіжність інтеграла на нулі.
2. При `f → ∞`: функція спадає як `f⁻²`, що гарантує збіжність інтеграла на верхній межі для більшості типів шуму (за винятком білого шуму фази, де вводиться гранична частота зрізу вимірювального тракту `f_h`).

## Розрахунок девіації для п'яти типів шуму

Спектральна густина потужності відносного відхилення частоти `S_y(f)` описується степеневою моделлю Барнса:

```
S_y(f) = ∑ h_α · f^α    [сума за α від −2 до +2]
```

Обчислимо інтеграл дисперсії Аллана для кожної складової окремо.

### 1. Білий шум фази (White Phase Noise, WPM, α = +2)

Спектр частотного шуму зростає квадратично: `S_y(f) = h₂ · f²`. Це відповідає білому спектру фазових помилок `S_φ(f) = const`.
Оскільки інтеграл розходиться при `f → ∞`, вводиться верхня частота зрізу фільтра низьких частот вимірювача `f_h` (за умови `2π·f_h·τ ≫ 1`):

```
σ_y²(τ) = 2·h₂ · ∫₀^(f_h) f² · [sin⁴(π·f·τ) / (π·f·τ)²] df
        = (2·h₂ / (π²·τ²)) · ∫₀^(f_h) sin⁴(π·f·τ) df
```

Середнє значення `sin⁴(u)` за багатьма періодами дорівнює `⅜`. Тоді:

```
∫₀^(f_h) sin⁴(π·f·τ) df ≈ ⅜ · f_h
σ_y²(τ) = (3 · f_h · h₂) / (4π² · τ²)
```

Девіація Аллана:

```
σ_y(τ) = [ √(3 · f_h · h₂) / (2π) ] · τ⁻¹
```

На логарифмічній шкалі нахил залежності `log(σ_y)` від `log(τ)` дорівнює **−1**. Величина залежить від апаратної смуги пропускання `f_h`.

### 2. Флікер-шум фази (Flicker Phase Noise, FPM, α = +1)

Спектр: `S_y(f) = h₁ · f`. Інтеграл із верхнім зрізом `f_h` дає:

```
σ_y²(τ) = [h₁ / (4π² · τ²)] · [1.038 + 3 · ln(2π · f_h · τ)]
```

При домінуванні члена `τ⁻²` логарифмічна поправка створює пологий нахил:

```
σ_y(τ) ∝ τ⁻¹ · √[ln(τ)] ≈ τ⁻¹
```

Нахил на графіку близький до **−1**, але відрізняється слабкою залежністю від вибору `f_h`.

### 3. Білий шум частоти (White Frequency Noise, WFM, α = 0)

Спектр: `S_y(f) = h₀` (постійна густина на всіх частотах). Це фундаментальний тепловий шум у контурі резонатора.

```
σ_y²(τ) = 2·h₀ · ∫₀^∞ [sin⁴(π·f·τ) / (π·f·τ)²] df
```

Зробимо заміну змінної `u = π·f·τ`, `df = du / (π·τ)`:

```
σ_y²(τ) = [2·h₀ / (π·τ)] · ∫₀^∞ [sin⁴(u) / u²] du
```

Табличний інтеграл `∫₀^∞ (sin⁴(u) / u²) du = π / 4`. Отримуємо:

```
σ_y²(τ) = [2·h₀ / (π·τ)] · (π / 4) = h₀ / (2·τ)
```

Девіація Аллана:

```
σ_y(τ) = √(h₀ / 2) · τ⁻¹/²
```

Нахил на логарифмічній шкалі дорівнює **−½**. Дисперсія не залежить від верхньої смуги зрізу `f_h`.

### 4. Флікер-шум частоти (Flicker Frequency Noise, FFM, α = −1)

Спектр: `S_y(f) = h₋₁ · f⁻¹` (шум `1/f`).

```
σ_y²(τ) = 2·h₋₁ · ∫₀^∞ f⁻¹ · [sin⁴(π·f·τ) / (π·f·τ)²] df
        = 2·h₋₁ · ∫₀^∞ [sin⁴(u) / u³] du    [де u = π·f·τ]
```

Табличний інтеграл `∫₀^∞ (sin⁴(u) / u³) du = ln(2)`. Звідси:

```
σ_y²(τ) = 2 · h₋₁ · ln(2)
```

Девіація Аллана:

```
σ_y(τ) = √[2 · ln(2) · h₋₁] ≈ 1.177 · √(h₋₁) = const
```

На логарифмічній шкалі нахил дорівнює **0**. Девіація Аллана виходить на горизонтальне плато (англ. *flicker floor*), що визначає фундаментальну межу короткочасної стабільності генератора незалежно від часу накопичення `τ`.

### 5. Випадкове блукання частоти (Random Walk Frequency, RWFM, α = −2)

Спектр: `S_y(f) = h₋₂ · f⁻²`. Процес відповідає інтегруванню білого шуму (нестаціонарні температурні та механічні градієнти).

```
σ_y²(τ) = 2·h₋₂ · ∫₀^∞ f⁻² · [sin⁴(π·f·τ) / (π·f·τ)²] df
        = 2·h₋₂ · (π·τ) · ∫₀^∞ [sin⁴(u) / u⁴] du
```

Табличний інтеграл `∫₀^∞ (sin⁴(u) / u⁴) du = π / 3`. Тоді:

```
σ_y²(τ) = 2·h₋₂ · π·τ · (π / 3) = (2π² / 3) · h₋₂ · τ
```

Девіація Аллана:

```
σ_y(τ) = π · √(2·h₋₂ / 3) · τ⁺¹/²
```

На логарифмічній шкалі нахил дорівнює **+½**. Зі зростанням `τ` похибка починає прогресивно збільшуватися.

### Лінійний детермінований дрейф частоти

Якщо частота має детерміновану лінійну швидкість зміни `y(t) = d · t` (де `d = dα/dt` — коефіцієнт старіння або нагріву):

```
ȳₖ = (1/τ) · ∫_(tₖ)^(tₖ+τ) d·t dt = d · (tₖ + τ/2)
ȳₖ₊₁ − ȳₖ = d · (tₖ + τ + τ/2) − d · (tₖ + τ/2) = d · τ
```

Підставивши у формулу дисперсії Аллана:

```
σ_y²(τ) = ½ · (d · τ)² = (d² / 2) · τ²
σ_y(τ) = (d / √2) · τ⁺¹
```

На логарифмічній шкалі нахил дорівнює **+1**.

## Перекривна оцінка дисперсії Аллана (Overlapping AVAR)

У класичній неперекривній дисперсії Аллана масив із `N` фазових відліків `x_k` (з кроком дискретизації `τ₀`) розбивається на послідовні блоки довжиною `m` (`τ = m · τ₀`). Кількість незалежних пар різниць для заданого `m` становить лише `M = ⌊(N - 1) / (2m)⌋`. При великих `τ` кількість пар стає надто малою, що призводить до великої дисперсії самої статистичної оцінки.

Для максимального використання статистичної інформації застосовують **перекривну дисперсію Аллана** (англ. *Overlapping Allan Variance*). Замість того, щоб зміщувати вікно на `2m` кроків, розрахункове вікно зсувають на один крок вимірювання `τ₀`:

```
σ_y²(m·τ₀) = (1 / (2 · m² · τ₀² · (N − 2m))) · ∑ [x(k + 2m) − 2·x(k + m) + x(k)]²
```

де сумування проводиться за всіма `k` від `1` до `N - 2m`.

Перекривна оцінка збільшує число ступенів вільності оцінки `edf` майже вдвічі при `m ≫ 1`, істотно звужуючи довірчі інтервали оцінки `σ_y(τ)` без зміни її математичного сподівання.

## Модифікована дисперсія Аллана (MVAR) та часова девіація (TDEV)

Класична дисперсія Аллана має одну фундаментальну ваду: вона має однаковий нахил `τ⁻¹` як для білого шуму фази (WPM), так і для флікер-шуму фази (FPM). Щоб розрізнити ці процеси, використовують **модифіковану дисперсію Аллана** (*Modified Allan Variance*, `Mod σ_y²(τ)`), яка додає додаткове ковзне фазове усереднення:

```
Mod σ_y²(m·τ₀) = (1 / (2 · m⁴ · τ₀² · (N − 3m + 1))) · ∑ [ ∑ (x(i + 2m) − 2·x(i + m) + x(i)) ]²
```

де зовнішня сума йде за `j` від `1` до `N - 3m + 1`, а внутрішня сума усереднює фазові помилки за `i` від `j` до `j + m - 1`.

У модифікованій дисперсії нахили розділяються:
- Білий шум фази (WPM): `Mod σ_y(τ) ∝ τ⁻³/²` (нахил **−1.5**).
- Флікер-шум фази (FPM): `Mod σ_y(τ) ∝ τ⁻¹` (нахил **−1.0**).
- Білий шум частоти (WFM): `Mod σ_y(τ) ∝ τ⁻¹/²` (нахил **−0.5**).

На базі `Mod σ_y(τ)` у телекомунікаційних стандартах ITU-T (G.810, G.813, G.8262) визначається **часова девіація** (*Time Deviation*, `TDEV`, `σ_x(τ)`), яка вимірює розкид фазової часової похибки в секундах:

```
σ_x(τ) = (τ / √3) · Mod σ_y(τ)
```

Для білого шуму фази `σ_x(τ) ∝ τ⁻¹/²`, що наочно показує здатність цифрових фільтрів покращувати точність міток часу при збільшенні вікна спостереження.

## Зведена таблиця відповідності спектрів і нахилів

Співвідношення між показником спектра `α` у `S_y(f) ∝ f^α`, показником фазового спектра `β` у `S_φ(f) ∝ f^β` (де `β = α − 2`), показником степеня дисперсії Аллана `μ` у `σ_y²(τ) ∝ τ^μ`, нахилом девіації Аллана `μ/2` та нахилом модифікованої девіації `Mod σ_y(τ)`:

| Процес шуму | `S_y(f) ∝ f^α` | `S_φ(f) ∝ f^β` | `σ_y(τ)` нахил | `Mod σ_y(τ)` нахил | `TDEV σ_x(τ)` нахил | Залежність від смуги `f_h` |
|:---|:---:|:---:|:---:|:---:|:---:|:---|
| Білий шум фази (WPM) | `f⁺²` | `f⁰` | **−1** | **−1.5** | **−0.5** | Залежить лінійно (`√f_h`) |
| Флікер-шум фази (FPM) | `f⁺¹` | `f⁻¹` | **−1** | **−1.0** | **0** (плато) | Слабко залежить (`√ln(f_h)`) |
| Білий шум частоти (WFM) | `f⁰` | `f⁻²` | **−½** | **−0.5** | **+0.5** | Не залежить |
| Флікер-шум частоти (FFM) | `f⁻¹` | `f⁻³` | **0** (плато) | **0** (плато) | **+1.0** | Не залежить |
| Блукання частоти (RWFM) | `f⁻²` | `f⁻⁴` | **+½** | **+0.5** | **+1.5** | Не залежить |
| Лінійний дрейф частоти | — | — | **+1** | **+1.0** | **+2.0** | Не залежить |

## Довірчі інтервали та статистична похибка

Оскільки оцінка `σ̂_y²(τ)` обчислюється за скінченною вибіркою, вона є випадковою величиною, розподіленою за законом `χ²` (хі-квадрат) із `edf` еквівалентними ступенями вільності:

```
edf · σ̂_y²(τ) / σ_y²(τ) ~ χ²(edf)
```

Для вибірки з `N` точок відліку частоти формули еквівалентних ступенів вільності залежать від домінуючого типу шуму:
- Для білого шуму частоти (WFM): `edf ≈ (N − 1) · (2m + 1) / (3m)`
- Для флікер-шуму частоти (FFM): `edf ≈ (N − 1) / (1 + 0.5 · ln(m))`
- Для випадкового блукання (RWFM): `edf ≈ (N − 2) / m`

Відносне середньоквадратичне відхилення оцінки девіації Аллана становить приблизно:

```
Δσ_y(τ) / σ_y(τ) ≈ 1 / √(2 · edf)
```

Це означає, що для отримання 10% статистичної точності оцінки стабільності на певному інтервалі `τ` необхідно зареєструвати щонайменше `edf ≈ 50`, тобто вибірка спостережень повинна тривати щонайменше `50…100 · τ`.

## Приклад перерахунку: фазовий шум у девіацію Аллана

Нехай високочастотний генератор `f₀ = 10 МГц` має виміряну односмугову спектральну густину фазового шуму `L(f)` у режимі білого шуму частоти (на відстрочці `f = 10 кГц`):

```
L(10 кГц) = −140 дБк/Гц
```

Зв'язок між `L(f)` та двосторонньою спектральною густиною фази `S_φ(f)`:

```
S_φ(f) = 2 · 10^(L(f) / 10) = 2 · 10^(−14) рад²/Гц
```

Переведемо спектр фази `S_φ(f)` у спектр відносної частоти `S_y(f)`:

```
S_y(f) = (f² / f₀²) · S_φ(f)
```

Оскільки на цій ділянці `S_φ(f) ∝ f⁻²`, значення `S_y(f)` є сталою величиною `h₀`:

```
h₀ = S_y(f)
   = ((10⁴)² / (10⁷)²) · (2 · 10⁻¹⁴)    [підстановка f = 10 кГц, f₀ = 10 МГц, S_φ]
   = (10⁸ / 10¹⁴) · (2 · 10⁻¹⁴)         [піднесення до квадрата]
   = 10⁻⁶ · 2 · 10⁻¹⁴                  [ділення степенів 10⁸ / 10¹⁴ = 10⁻⁶]
   = 2 × 10⁻²⁰ Гц⁻¹                    [фінальне значення сталої h₀]
```

Обчислимо очікувану девіацію Аллана для інтервалу `τ = 1 с`:

```
σ_y(1 с)
= √(h₀ / (2 · τ))                       [формула девіації для білого шуму частоти]
= √( (2 × 10⁻²⁰) / (2 · 1) )             [підстановка h₀ = 2×10⁻²⁰ та τ = 1 с]
= √(10⁻²⁰)                              [спрощення дробу 2 / 2 = 1]
= 1.0 × 10⁻¹⁰                            [добування квадратного кореня]
```

Це означає, що за інтервал спостереження в 1 секунду розкид відносної частоти генератора становитиме 0.1 ppb (одна десятимільярдна частка номіналу), що для 10 МГц відповідає середньоквадратичному відхиленню частоти `10⁷ · 10⁻¹⁰ = 0.001 Гц` (1 мГц).
