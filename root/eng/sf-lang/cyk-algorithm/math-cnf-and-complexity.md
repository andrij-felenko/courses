# 🧮 Математичні основи CYK: нормальна форма Хомського, індуктивне доведення та теорема Вальянта

Алгоритм Кока–Янгера–Касамі базується на двох фундаментальних математичних результатах: канонічній теоремі про існування еквівалентної нормальної форми Хомського для будь-якої контекстно-вільної граматики та індуктивному принципі оптимальності розбиття підрядків на піраміді динамічного програмування.

## 1. Нормальна форма Хомського (CNF) та еквівалентність

Контекстно-вільна граматика `G = (V_N, V_T, R, S)` перебуває в **нормальній формі Хомського** (Chomsky Normal Form, CNF), якщо всі її правила з множини `R` мають виключно один із таких виглядів:
1. `A → BC`, де `A, B, C ∈ V_N` та `B, C ≠ S` (строго бінарне нетермінальне розгалуження);
2. `A → a`, де `A ∈ V_N`, `a ∈ V_T` (породження одного термінального символу);
3. `S → ε`, якщо і тільки якщо порожнє слово належить мові `ε ∈ L(G)`. У цьому разі початковий символ `S` не має права з'являтися в правих частинах жодних інших правил.

### Теорема про зведення до CNF
Для будь-якої контекстно-вільної граматики `G` існує алгоритмічно побудована граматика `G'` у нормальній формі Хомського така, що мови обох граматик збігаються `L(G') = L(G)`, причому розмір нової граматики обмежений поліномом `|G'| = O(|G|²)`.

### Конструктивний 5-кроковий алгоритм конвертації

Перетворення довільної граматики виконується послідовним застосуванням п'яти нормалізаційних кроків:

#### Крок 1 (START): Введення нового початкового символу
Створюється новий нетермінал `S₀ ∉ V_N`, який стає новою аксіомою граматики, та додається правило `S₀ → S`. Це ізолює початковий символ від появи в правих частинах продукцій, що гарантує коректну обробку порожнього слова `ε` без порушення структури внутрішніх розгалужень.

#### Крок 2 (TERM): Відокремлення термінальних символів
У правилах довжини два і більше термінали не можуть бути сусідами інших символів. Для кожного термінала `a ∈ V_T` вводиться допоміжний нетермінал `T_a` та одиничне термінальне правило `T_a → a`. У всіх змішаних та довгих правилах кожне входження термінала `a` замінюється на відповідний нетермінал `T_a`.

#### Крок 3 (BIN): Бінаризація довгих правил
Кожне правило, права частина якого містить `k ≥ 3` нетерміналів `A → B₁ B₂ B₃ ... B_k`, каскадно замінюється на ланцюжок із `k - 1` бінарних правил шляхом введення нових проміжних змінних `X₁, X₂, ..., X_{k-2}`:
```
A       → B₁ X₁
X₁      → B₂ X₂
...
X_{k-2} → B_{k-1} B_k
```
Цей крок зберігає порядок символів і гарантує, що кожне виведення розгалужується строго на два нащадки.

#### Крок 4 (DEL): Усунення ε-правил
1. Множина анульовних (nullable) нетерміналів обчислюється як найменша нерухома точка:
```
NULLABLE = { A ∈ V_N | A ⇒* ε }
```
Алгоритм використовує чергу завдань (worklist): спочатку до множини додаються всі `A`, де є пряме правило `A → ε`. Потім ітеративно додаються нетермінали `B`, якщо для правила `B → C₁ C₂ ... C_m` усі праві символи `C_i` вже належать до множини `NULLABLE`. Процес завершується за скінченну кількість кроків `O(|R|)`, оскільки множина нетерміналів скінченна і монотонно зростає.
2. Для кожного наявного правила `A → Y₁ ... Y_m` генеруються всі комбінаторні варіанти заміни, де підмножина символів `Y_i ∈ NULLABLE` опускається.
3. Усі вихідні правила вигляду `A → ε` видаляються. Якщо стара аксіома була анульовною (`S ∈ NULLABLE`), до граматики додається єдине правило `S₀ → ε`.

#### Крок 5 (UNIT): Усунення ланцюгових правил (Unit Productions)
Ланцюговим називається правило вигляду `A → B`, де обидва символи є нетерміналами.
1. Будується орієнтований граф одиничних переходів з вершинами `V_N` та дугами `(A, B)` для кожного правила `A → B`.
2. Знаходиться транзитивне замикання графа — множина пар досяжності `UNIT = { (A, B) | A ⇒* B }` за допомогою пошуку в глибину (DFS) або алгоритму Флойда–Воршелла за час `O(|V_N|³)`.
3. Для кожної пари `(A, B) ∈ UNIT` та кожного неланцюгового правила `B → α` (де `|α| ≥ 2` або `α ∈ V_T`) до граматики додається правило `A → α`.
4. Усі вихідні правила `A → B` видаляються.

### Доведення кількості кроків виведення в CNF
**Лема:** Нехай `G` — граматика в нормальній формі Хомського без `ε`-правил. Якщо слово `w ∈ L(G)` має довжину `|w| = n ≥ 1`, то будь-яке виведення `S ⇒* w` складається рівно з `2n - 1` кроків застосування правил.

**Доведення:**
1. Кожне бінарне правило `A → BC` збільшує кількість нетерміналів у поточному ланцюжку рівно на `+1` (замінює 1 нетермінал на 2).
2. Початковий ланцюжок містить `1` нетермінал (`S`). Щоб отримати рядок із `n` нетерміналів, необхідно застосувати бінарні правила рівно:
```
n - 1   [кроків бінарного розгалуження A → BC]
```
3. Кожне термінальне правило `A → a` замінює один нетермінал на один термінальний символ, не змінюючи загальної довжини рядка.
4. Оскільки підсумкове слово `w` складається з `n` терміналів, термінальні правила мають бути застосовані рівно `n` разів:
```
n       [кроків термінальної заміни A → a]
```
5. Загальна кількість кроків виведення:
```
(n - 1) + n = 2n - 1
```
Цей інваріант унеможливлює нескінченні ланцюжки виведення та гарантує скінченність простору синтаксичного дерева.

## 2. Строге індуктивне доведення коректності CYK

Нехай задано слово `w = a₁ a₂ ... aₙ` довжини `n` та граматику `G` у CNF.
Тривимірна таблиця динамічного програмування `P[l, i]` визначається для всіх довжин `1 ≤ l ≤ n` та початкових індексів `1 ≤ i ≤ n - l + 1` як множина нетерміналів:
```
P[l, i] ⊆ V_N
```

**Теорема коректності:** Для довільного нетермінала `A ∈ V_N`, довжини `1 ≤ l ≤ n` та позиції `1 ≤ i ≤ n - l + 1`:
```
A ∈ P[l, i]  ⟺  A ⇒* a_i a_{i+1} ... a_{i+l-1}
```

**Доведення (математична індукція за довжиною підрядка `l`):**

### Базовий крок (`l = 1`):
Підрядок складається з одного символу `w[i .. i] = a_i`.
- За алгоритмом: `A ∈ P[1, i] ⟺ (A → a_i) ∈ R`.
- За структурою CNF єдиний спосіб вивести один термінал `a_i` з нетермінала `A` за `2(1) - 1 = 1` крок — це безпосереднє застосування правила `A → a_i`.
- Отже, `A ∈ P[1, i] ⟺ A ⇒ a_i`, твердження істинне для `l = 1`.

### Індукційне припущення:
Припустимо, що для всіх довжин `m` таких, що `1 ≤ m < l`, і для всіх позицій `j` твердження виконується:
```
X ∈ P[m, j]  ⟺  X ⇒* a_j ... a_{j+m-1}
```

### Індукційний перехід (для довжини `l > 1`):
Розглянемо підрядок `w[i .. i+l-1]`.

1. **Необхідність (`⇒`):**
   Нехай `A ⇒* a_i ... a_{i+l-1}`. Оскільки `l > 1`, перший крок виведення не може бути термінальним `A → a`. Отже, першим застосовано бінарне правило:
   ```
   A ⇒ BC ⇒* a_i ... a_{i+l-1}
   ```
   У контекстно-вільній граматиці виведення з `B` та `C` є незалежними. Нетермінал `B` породжує деякий непорожній префікс підрядка довжини `k` (`1 ≤ k < l`), а нетермінал `C` породжує суміжний суфікс довжини `l - k`:
   ```
   B ⇒* a_i ... a_{i+k-1}           [довжина k < l]
   C ⇒* a_{i+k} ... a_{i+l-1}       [довжина l - k < l]
   ```
   Оскільки `k < l` та `l - k < l`, за індукційним припущенням:
   ```
   B ∈ P[k, i]
   C ∈ P[l - k, i + k]
   ```
   Алгоритм CYK перебирає всі можливі точки розбиття `k ∈ {1, 2, ..., l - 1}`. При поточному `k` алгоритм знаходить правило `A → BC`, де `B ∈ P[k, i]` та `C ∈ P[l - k, i + k]`, і записує `A` у множину `P[l, i]`.

2. **Достатність (`⇐`):**
   Нехай `A ∈ P[l, i]`. За визначенням алгоритму це означає, що існує точка розбиття `1 ≤ k < l` та правило `A → BC ∈ R` таке, що:
   ```
   B ∈ P[k, i]  та  C ∈ P[l - k, i + k]
   ```
   Оскільки `k < l` та `l - k < l`, за індукційним припущенням маємо:
   ```
   B ⇒* a_i ... a_{i+k-1}
   C ⇒* a_{i+k} ... a_{i+l-1}
   ```
   Застосовуючи правило `A → BC`, отримуємо:
   ```
   A ⇒ BC ⇒* (a_i ... a_{i+k-1}) (a_{i+k} ... a_{i+l-1}) = a_i ... a_{i+l-1}
   ```
   Отже, `A ⇒* a_i ... a_{i+l-1}`.

Індукційний перехід доведено.

**Наслідок:** Вхідне слово `w` довжини `n` належить мові `L(G)` тоді й тільки тоді, коли початковий символ `S ∈ P[n, 1]`.

## 3. Точний підрахунок кількості операцій та складність

Порахуємо точну кількість елементарних перевірок пар підрядків. Для фіксованої довжини `l` існує `n - l + 1` початкових позицій `i`. Для кожної позиції перевіряється `l - 1` точок розбиття `k`.

Загальна кількість ітерацій внутрішнього циклу становить:
```
∑_{l=2}^n (n - l + 1) · (l - 1)
= ∑_{m=1}^{n-1} (n - m) · m                             [заміна змінної підсумовування m = l - 1]
= n · ∑_{m=1}^{n-1} m - ∑_{m=1}^{n-1} m²                 [розкриття дужок та лінійність суми]
= n · (n(n - 1) / 2) - ((n - 1)n(2n - 1) / 6)           [формули суми чисел і суми квадратів]
= (n(n - 1) / 6) · [3n - (2n - 1)]                      [винесення спільного множника n(n - 1)/6]
= (n(n - 1)(n + 1)) / 6                                 [спрощення виразу в дужках 3n - 2n + 1 = n + 1]
= (n³ - n) / 6                                          [добуток різниці квадратів (n² - 1)n]
```

На кожній ітерації алгоритм зіставляє множини нетерміналів з бінарними правилами граматики `|R_{bin}|`.
Отже, точна кількість операцій дорівнює:
```
T(n, |G|) = ((n³ - n) / 6) · |R_{bin}| + n · |R_{term}| = O(n³ · |G|)
```

Просторова складність: таблиця розміру `n × n`, кожна клітинка містить підмножину нетерміналів `V_N`.
```
S(n, |G|) = (n(n + 1) / 2) · |V_N| = O(n² · |V_N|)
```

## 4. Теорема Вальянта: зв'язок із множенням матриць (1975)

У 1975 році Леслі Вальянт (Leslie G. Valiant) опублікував фундаментальну теорему, яка встановила прямий обчислювальний зв'язок між синтаксичним аналізом контекстно-вільних граматик та швидким множенням булевих матриць (Boolean Matrix Multiplication, BMM).

### Операція множення матриць над граматичним напівкільцем
Нехай `A` та `B` — дві верхньотрикутні матриці розміру `n × n`, елементами яких є підмножини нетерміналів `V_N`. Визначимо спеціальну операцію множення `C = A ⊙ B`:
```
C_{i, j} = ⋃_{k=i+1}^{j-1} { X ∈ V_N | ∃ (X → Y Z) ∈ R, де Y ∈ A_{i, k} ∧ Z ∈ B_{k, j} }
```

Ця операція точно ізоморфна стандартному множенню матриць, де операція додавання замінена на об'єднання множин `∪`, а множення елементів — на згортку за правилами граматики `R`.

### Рекурсивне блочне розбиття (Divide and Conquer)
Замість покрокового обчислення шарів довжини `l = 1, 2, ..., n` алгоритм Вальянта розбиває матрицю розбору на 4 рівні блоки розміру `(n/2) × (n/2)`:
```
     | A₁₁  A₁₂ |
 A = |          |
     |  0   A₂₂ |
```

1. Рекурсивно обчислюються діагональні блоки `A₁₁` та `A₂₂` (вони відповідають незалежному синтаксичному розбору лівої та правої половин вхідного слова довжини `n/2`).
2. Недіагональний блок `A₁₂`, що містить зв'язки між лівою та правою половинами, обчислюється множенням уже готових блоків:
```
A₁₂ = A₁₁ ⊙ A₁₂ ∪ A₁₂ ⊙ A₂₂
```
Це матричне рівняння розв'язується через зведення до `|V_N|` незалежних множень стандартних булевих матриць.

### Асимптотична оцінка
Якщо позначити через `M(n)` час множення двох булевих матриць розміру `n × n`, то рекурентне співвідношення для часу розбору має вигляд:
```
T(n) = 2 · T(n / 2) + O(M(n) · |G|)
```
За основною теоремою про рекурентності (Master Theorem), оскільки степінь `M(n) = O(n^ω)` задовольняє умову `ω ≥ 2 > log₂ 2 = 1`, розв'язок становить:
```
T_{Valiant}(n) = O(M(n) · log n · |G|)
```

При використанні класичного алгоритму Штрассена (`ω ≈ 2.807`) або сучасних матричних методів (Копперсміт–Віноград, Дюан–Ву–Чжоу з `ω ≈ 2.371552`), верхня межа складності парсингу строго опускається нижче кубічної:
```
O(n^{2.372} · |G|)
```

### Умовна нижня межа Лілліан Лі (2002)
У 2002 році Лілліан Лі (Lillian Lee) довела зворотне твердження: довільний алгоритм швидкого множення булевих матриць за час `O(n^{3 - ε})` може бути перетворений на алгоритм синтаксичного аналізу довільних КВ-граматик за час `O(n^{3 - ε})`. Це свідчить про те, що суттєвий комбінаторний прорив у швидкодії універсального синтаксичного розбору неможливий без одночасного прориву в загальній алгебрі матричних обчислень.
