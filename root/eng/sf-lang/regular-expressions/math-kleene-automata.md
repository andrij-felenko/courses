# 🧮 Математичні основи регулярних виразів: теорема Кліні, конструкція Томпсона та лема про розростання

Регулярні мови є базовим класом у класифікації формальних граматик Ноама Чомскі (тип 3). Щоб формально довести, які операції пошуку можна виконати за лінійний час без повернень, а які принципово вимагають експоненційного перебору, необхідно визначити алгебраїчну структуру регулярних множин, правила індуктивної побудови автоматів та межі їхньої виразності.

## Алгебра регулярних множин та індуктивне визначення

Нехай `Σ` — скінченний набір символів (алфавіт). Рядок над алфавітом `Σ` — це скінченна послідовність символів, а довжина порожнього рядка позначається грецькою літерою `ε` (`|ε| = 0`). Мова `L` над алфавітом `Σ` — це довільна підмножина множини всіх можливих рядків `Σ*`.

Регулярний вираз `R` індуктивно визначає регулярну мову `L(R)` за такими аксіомами:

**Базові випадки (базис індукції):**
1. `∅` — регулярний вираз, що позначає порожню множину: `L(∅) = ∅`.
2. `ε` — регулярний вираз, що позначає мову з єдиного порожнього рядка: `L(ε) = { ε }`.
3. Для кожного символу `a ∈ Σ`, вираз `a` позначає мову з одного символу: `L(a) = { a }`.

**Індуктивні кроки (замкненість відносно трьох операцій):**
Якщо `R₁` та `R₂` — регулярні вирази, що задають мови `L(R₁)` та `L(R₂)`, то:

1. **Чергування (об'єднання, `|` або `+`):**
```
L(R₁ | R₂) = L(R₁) ∪ L(R₂)
```
Рядок належить мові, якщо він розпізнається хоча б одним із підвиразів.

2. **Конкатенація (`·`):**
```
L(R₁ · R₂) = { u · v | u ∈ L(R₁), v ∈ L(R₂) }
```
Рядок утворюється зчепленням довільного рядка з першої мови та довільного рядка з другої мови.

3. **Замикання Кліні (зірочка `*`):**
```
L(R*) = ⋃_{i=0}^∞ (L(R))ⁱ
```
де `(L(R))⁰ = { ε }`, а `(L(R))ⁱ = L(R) · (L(R))^{i-1}`. Замикання позначає нуль або довільну скінченну кількість повторень рядків мови `L(R)`.

Будь-яка мова, отримана застосуванням скінченної кількості цих трьох операцій до базових випадків, називається **регулярною мовою** (*regular language*).

## Теорема Кліні та еквівалентність автоматам

Математичний зміст теореми Кліні полягає у встановленні повної еквівалентності між декларативним описом мови через вирази та операційним описом через обчислювальні машини зі скінченною пам'яттю.

**Визначення детермінованого скінченного автомата (DFA):**
DFA визначається як кортеж із п'яти елементів:
```
M = (Q, Σ, δ, q₀, F)
```
де:
- `Q` — скінченна множина станів;
- `Σ` — скінченний вхідний алфавіт;
- `δ : Q × Σ → Q` — функція переходів, яка кожній парі (стан, символ) ставить у відповідність рівно один наступний стан;
- `q₀ ∈ Q` — початковий стан;
- `F ⊆ Q` — множина допускальних (фінальних) станів.

**Визначення недетермінованого скінченного автомата з `ε`-переходами (`ε`-NFA):**
`ε`-NFA має ту саму структуру, проте функція переходів допускає переходи без зчитування символу (`ε`) і повертає множину можливих станів:
```
δ : Q × (Σ ∪ {ε}) → 2ᵠ
```

**Теорема Кліні (1956):**
Мова `L ⊆ Σ*` є регулярною тоді й тільки тоді, коли існує скінченний автомат (DFA або `ε`-NFA), який розпізнає `L`.

## Конструкція Томпсона: генерація `ε`-NFA за лінійний час

Алгоритм Кена Томпсона перетворює довільний регулярний вираз `R` довжини `M` на еквівалентний автомат `ε`-NFA за строго лінійний час `O(M)`. Кожен фрагмент автомата має рівно один початковий стан і рівно один допускальний стан.

Побудова здійснюється рекурсивно за синтаксичною структурою виразу:

1. **Символ `a ∈ Σ`:**
   Створюються два стани `s_in` та `s_out` з єдиним переходом `δ(s_in, a) = { s_out }`.
2. **Конкатенація `A · B`:**
   Допускальний стан автомата для `A` з'єднується `ε`-переходом із початковим станом автомата для `B`:
   `δ(s_out(A), ε) = { s_in(B) }`.
   Початковим станом стає `s_in(A)`, допускальним — `s_out(B)`.
3. **Чергування `A | B`:**
   Створюються нові стани `s_in` та `s_out`. Додаються переходи:
   `δ(s_in, ε) = { s_in(A), s_in(B) }`,
   `δ(s_out(A), ε) = { s_out }`,
   `δ(s_out(B), ε) = { s_out }`.
4. **Замикання Кліні `A*`:**
   Створюються нові стани `s_in` та `s_out`. Додаються чотири `ε`-переходи:
   `δ(s_in, ε) = { s_in(A), s_out }` (вхід у підінтенсив або прямий пропуск при нулі повторень),
   `δ(s_out(A), ε) = { s_in(A), s_out }` (повернення на повтор або вихід у допускальний стан).

**Властивість розмірності:**
Отриманий автомат `ε`-NFA містить не більше `2M` станів і не більше `4M` переходів, де `M` — кількість символів та операторів у виразі. Робота такого автомата на рядку довжини `N` шляхом паралельного відстеження множини активних станів виконується за час `O(M · N)` і потребує `O(M)` пам'яті.

## Алгоритм побудови підмножин (детермінізація Рабіна–Скотта)

Щоб прискорити виконання з `O(M · N)` до `O(N)`, `ε`-NFA трансформують у детермінований автомат DFA за алгоритмом підмножин (*powerset construction*).

Нехай `S ⊆ Q` — множина станів NFA. `ε`-замиканням `ε-closure(S)` називається множина всіх станів NFA, досяжних зі станів множини `S` ланцюжком із нуля або більше `ε`-переходів.

Кожен стан детермінованого автомата `T ∈ Q_DFA` відповідає підмножині станів вихідного NFA: `T ⊆ Q_NFA`.

1. Початковий стан DFA:
```
q₀_DFA = ε-closure({ q₀_NFA })
```
2. Для кожного стану `T ∈ Q_DFA` та кожного символу `a ∈ Σ` обчислюється перехід:
```
δ_DFA(T, a) = ε-closure( ⋃_{s ∈ T} δ_NFA(s, a) )
```
3. Стан `T` стає допускальним у DFA, якщо він містить хоча б один допускальний стан NFA:
```
F_DFA = { T ∈ Q_DFA | T ∩ F_NFA ≠ ∅ }
```

**Експоненційний вибух станів:**
Оскільки множина станів DFA є підмножиною булеана `2ᵠ`, кількість станів у найгіршому випадку досягає `2ᴹ`.
Класичний приклад виразу, що демонструє цей вибух:
```
(a|b)* a (a|b)ⁿ⁻¹
```
NFA для цього виразу потребує лише `n + 1` станів (відстеження передостаннього символу). Проте мінімальний еквівалентний DFA вимагає рівно `2ⁿ` станів, оскільки автомат мусить «пам'ятати» історію останніх `n` прочитаних бітів.

## Межі регулярності: Лема про розростання (Pumping Lemma)

Лема про розростання формулює необхідну властивість будь-якої регулярної мови. Вона базується на принципі Діріхле: якщо автомат із `p` станами зчитує рядок довжиною `≥ p`, він неминуче відвідає щонайменше один стан двічі, утворюючи цикл.

**Формулювання леми:**
Якщо мова `L` є регулярною, то існує число `p ≥ 1` (довжина розростання, *pumping length*), таке, що будь-який рядок `s ∈ L` довжиною `|s| ≥ p` можна розбити на три частини:
```
s = x · y · z
```
які задовольняють три умови:
1. `|y| ≥ 1` (циклічна частина не порожня);
2. `|x · y| ≤ p` (перший цикл замикається в межах перших `p` символів);
3. Для будь-якого цілого числа `k ≥ 0` рядок `x · yᵏ · z ∈ L`.

## Доведення нерегулярності мов зі зворотними посиланнями (`\1`)

Сучасні рушії регулярних виразів підтримують зворотні посилання, наприклад `([a-z]+)\1`. Ця конструкція задає мову точних повторів слів:
```
L_copy = { w · w | w ∈ {a, b}* }
```

Доведемо від супротивного, що `L_copy` не є регулярною мовою.

1. Припустимо, що `L_copy` регулярна. Тоді за лемою про розростання існує стала `p`.
2. Оберемо слово `s ∈ L_copy` довжини `≥ p`:
```
w = aᵖ · bᵖ
s = w · w = aᵖ · bᵖ · aᵖ · bᵖ
```
Довжина рядка `|s| = 4p ≥ p`.

3. За умовою (2) леми, `|x · y| ≤ p`. Оскільки перші `p` символів рядка `s` складаються виключно з символів `a`, підрядок `y` мусить мати вигляд:
```
y = aᵐ,   де 1 ≤ m ≤ p
```
Отже, розбиття має вигляд:
```
x = aᵖ⁻ᵐ
y = aᵐ
z = bᵖ · aᵖ · bᵖ
```

4. Застосуємо розростання з параметром `k = 2` (дублюємо підрядок `y`):
```
s' = x · y² · z
   = aᵖ⁻ᵐ · a²ᵐ · bᵖ · aᵖ · bᵖ     [підстановка x = aᵖ⁻ᵐ, y = aᵐ, z = bᵖ · aᵖ · bᵖ]
   = aᵖ⁺ᵐ · bᵖ · aᵖ · bᵖ           [додавання степенів однакових основ (p - m + 2m = p + m)]
```

5. Щоб рядок `s'` належав мові `L_copy`, він повинен мати форму `u · u` для деякого рядка `u`.
Загальна довжина рядка `|s'| = 4p + m`.
Довжина половини `|u| = (4p + m) / 2 = 2p + m/2`.

Перша половина рядка `s'` починається з `aᵖ⁺ᵐ` і закінчується всередині першого блоку `b`. Вона містить `p + m` символів `a` та `p - m/2` символів `b`.
Друга половина рядка `s'` починається з залишку символів `b` першого блоку або одразу з символів `a` другого блоку.
Кількість символів `a` в першій половині (`p + m`) не дорівнює кількості символів `a` у другій половині (`p`), оскільки `m ≥ 1`.

Отже, рядок `s'` не може бути представлений у вигляді `u · u`, тобто:
```
s' ∉ L_copy
```
Отримано суперечність з умовою (3) леми про розростання.

**Висновок про обчислювальну складність:**
Мова `L_copy` не є регулярною і належить до контекстно-залежних мов (тип 1 за Чомскі). Зіставлення регулярних виразів зі зворотними посиланнями неможливо реалізувати на класичних автоматах DFA чи NFA. Доведено, що задача перевірки збігу для виразів зі зворотними посиланнями є **NP-повною** (до неї поліноміально зводиться задача 3-SAT). Саме тому рушії з бектрекінгом стикаються з катастрофічною експоненційною складністю.
