# 📋 Довідник директив, макросів та операторів препроцесора

У цьому довіднику наведено повний перелік директив, вбудованих макросів та спеціальних операторів препроцесора для стандартів C (від ANSI C89 до C23) та C++ (від C++98 до C++23).

Усі інструкції препроцесора опрацьовуються на фазах трансляції 1–4, тобто до початку синтаксичного розбору, перевірки типів та генерації коду компілятором.

---

### 1. Директиви препроцесора

Директива починається з символу `#` як першого непробільного символу рядка і завершується переведенням рядка (якщо рядок не продовжено зворотним слешем `\`).

#### Включення вихідних файлів: `#include`

Директива механічно вставляє повний вміст цільового файлу в поточну позицію одиниці трансляції.

- **Синтаксис:**
  - `#include <заголовок>` — пошук ведеться у стандартних системних каталогах та шляхах, переданих компілятору прапорцем `-I`.
  - `#include "файл"` — пошук починається з каталогу поточного файлу; якщо файл не знайдено, пошук переходить до системних шляхів.
- **Особливості поведінки:** Включений файл рекурсивно проходить усі фази препроцесингу. Якщо в ньому містяться інші директиви `#include`, вони обробляються глибинно за принципом дерева.

#### Оголошення та скасування макросів: `#define` та `#undef`

- **Синтаксис:**
  - `#define ІМ'Я значення` — створення об'єктного макросу.
  - `#define ІМ'Я(параметри) тіло` — створення функціонального макросу. Між ім'ям і відкриваючою дужкою заборонено пробіл.
  - `#undef ІМ'Я` — видалення ідентифікатора з таблиці макросів препроцесора.
- **Особливості поведінки:** Повторне визначення макросу через `#define` без попереднього `#undef` дозволяється стандартами лише у випадку, якщо послідовність токенів заміни та пробілів повністю ідентична початковій. Якщо послідовності різняться, компілятор зобов'язаний згенерувати попередження або помилку. Директива `#undef` для невідомого або вже скасованого макросу безпечно ігнорується.

#### Умовна компіляція: `#if`, `#ifdef`, `#ifndef`, `#elif`, `#elifdef`, `#elifndef`, `#else`, `#endif`

Дозволяє адаптувати вихідний код під різні операційні системи, архітектури процесорів та рівні налагодження.

- **Синтаксис:**
  - `#if константний-вираз` — обчислює цілочисельний вираз. Якщо результат не дорівнює `0`, гілка компілюється.
  - `#ifdef ІМ'Я` — еквівалентно `#if defined(ІМ'Я)`.
  - `#ifndef ІМ'Я` — еквівалентно `#if !defined(ІМ'Я)`.
  - `#elif константний-вираз` — перевіряє альтернативну умову, якщо попередня гілка була хибною.
  - `#elifdef ІМ'Я` — альтернативна гілка перевірки наявності макросу (введено в C23 та C++23).
  - `#elifndef ІМ'Я` — альтернативна гілка перевірки відсутності макросу (введено в C23 та C++23).
  - `#else` — гілка за замовчуванням, якщо всі попередні умови виявилися хибними.
  - `#endif` — маркер завершення блоку умовної компіляції.
- **Правила константних виразів:** Обчислення виконуються в найбільшому цілому типі платформи (`intmax_t` або `uintmax_t`). Дробові числа (`3.14`) та рядкові літерали у виразах `#if` заборонені. Усі невідомі препроцесору ідентифікатори, що не є макросами, автоматично замінюються на `0`.

#### Керування діагностикою та рядками: `#line`, `#error`, `#warning`

- **Синтаксис:**
  - `#line номер ["ім'я_файлу"]` — перевизначає значення вбудованих макросів `__LINE__` та `__FILE__`. Використовується генераторами коду (Bison, Flex, ANTLR) для прив'язки діагностики компілятора до рядків оригінального DSL-файлу.
  - `#error "Повідомлення"` — примусово зупиняє трансляцію з фатальною помилкою компілятора, виводячи вказаний текст.
  - `#warning "Повідомлення"` — генерує попередження компілятора під час збирання без зупинки процесу трансляції (стандартизовано в C23 та C++23).

#### Прагми компілятора: `#pragma` та оператор `_Pragma`

Директива `#pragma` передає специфічні інструкції компілятору. Оператор `_Pragma("рядок")` (введений у C99) є еквівалентом директиви, але може використовуватися всередині макропідстановок.

Вбудовані прагми дозволяють тонко налаштовувати генерацію коду, вирівнювання структур та обробку діагностичних повідомлень:

1. `#pragma once` — оптимізована компілятором директива запобігання повторному включенню файлу, що відстежує унікальні ідентифікатори файлів у файловій системі.
2. `#pragma pack(push, n)` та `#pragma pack(pop)` — керує вирівнюванням полів структур у пам'яті. Значення `n=1` усуває паддінг, що є обов'язковим для бінарних заголовків мережевих пакетів, але може призводити до апаратних збоїв (Bus Fault) при непідтримуваному повирівнювальному читанні на процесорах ARM Cortex-M0.
3. `#pragma message("текст")` — виводить інформаційне повідомлення в консоль компіляції.

:::tabs
```c
#include <stdio.h>

/* Вказівка компілятору запакувати поля без вирівнювання (1 байт) */
#pragma pack(push, 1)
typedef struct {
    unsigned char flag;
    unsigned int  data;
} CompactHeader;
#pragma pack(pop)

/* Застосування _Pragma всередині функціонального макросу */
#define SUPPRESS_DEPRECATED_WARNING \
    _Pragma("GCC diagnostic push") \
    _Pragma("GCC diagnostic ignored \"-Wdeprecated-declarations\"")

int main(void) {
    printf("Розмір CompactHeader: %zu байтів\n", sizeof(CompactHeader));
    return 0;
}
```
```cpp
#include <iostream>
#include <cstdint>

// Вказівка компілятору запакувати поля без вирівнювання (1 байт)
#pragma pack(push, 1)
struct CompactHeader {
    uint8_t  flag;
    uint32_t data;
};
#pragma pack(pop)

// Застосування _Pragma всередині макросу для ізоляції попереджень
#define SUPPRESS_DEPRECATED_WARNING \
    _Pragma("GCC diagnostic push") \
    _Pragma("GCC diagnostic ignored \"-Wdeprecated-declarations\"")

int main() {
    std::cout << "Розмір CompactHeader: " << sizeof(CompactHeader) << " байтів\n";
    return 0;
}
```

### 2. Оператори макросів

Оператори препроцесора виконуються виключно під час розгортання тіла макросу.

#### Оператор стрінгіфікації: `#`

Перетворює аргумент функціонального макросу на валідний рядковий літерал мови C. Будь-які внутрішні подвійні лапки та зворотні слеші автоматично екрануються, а послідовності пробілів стискаються в один пробіл. Важливою особливістю є блокування попереднього розгортання (Argument Prescan) для відповідного параметра.

:::tabs
```c
#include <stdio.h>

#define STRINGIFY_VAL(x) #x

int main(void) {
    printf("Результат: %s\n", STRINGIFY_VAL(a + b * (c - d)));
    return 0;
}
```
```cpp
#include <iostream>
#include <string_view>

#define STRINGIFY_VAL(x) #x

int main() {
    constexpr std::string_view expr = STRINGIFY_VAL(a + b * (c - d));
    std::cout << "Результат: " << expr << "\n";
    return 0;
}
```
:::

#### Оператор склеювання токенів: `##`

З'єднує два сусідні токени в один новий токен. Застосовується для генерації унікальних імен функцій, змінних або констант. Результат зобов'язаний бути коректним лексичним токеном (наприклад, валідним ідентифікатором або числом). Так само як і оператор `#`, оператор `##` блокує розгортання макросів у своїх безпосередніх операндах.

:::tabs
```c
#include <stdio.h>

#define MAKE_FN_NAME(prefix, name) prefix##_##name

void api_v1_init(void) {
    printf("Ініціалізація API v1\n");
}

int main(void) {
    void (*init_ptr)(void) = MAKE_FN_NAME(api_v1, init);
    init_ptr();
    return 0;
}
```
```cpp
#include <iostream>

#define MAKE_FN_NAME(prefix, name) prefix##_##name

void api_v1_init() {
    std::cout << "Ініціалізація API v1 C++\n";
}

int main() {
    auto* init_ptr = &MAKE_FN_NAME(api_v1, init);
    init_ptr();
    return 0;
}
```
:::

#### Варіативні оператори: `__VA_ARGS__` та `__VA_OPT__`

- `__VA_ARGS__` — замінюється на список аргументів, переданих замість трикрапки `...` у сигнатурі макросу.
- `__VA_OPT__(вміст)` — стандартний механізм (C++20, C23), що розгортається у свій вміст, якщо `__VA_ARGS__` не порожній, і повністю зникає, якщо аргументи не передано.

У старіших компіляторах GCC та Clang замість `__VA_OPT__` використовувалося нестандартне розширення `, ##__VA_ARGS__`, де оператор конкатенації перед комою ковтав попередню кому, якщо список аргументів був порожнім. У сучасному коді слід надавати перевагу стандартизованому `__VA_OPT__`.

:::tabs
```c
#include <stdio.h>

#define DBG_PRINT(tag, fmt, ...) \
    printf("[" tag "] " fmt "\n" __VA_OPT__(,) __VA_ARGS__)

int main(void) {
    DBG_PRINT("NET", "З'єднання встановлено");
    DBG_PRINT("CPU", "Завантаження: %d%%, Температура: %d C", 45, 62);
    return 0;
}
```
```cpp
#include <iostream>
#include <cstdio>

#define DBG_PRINT(tag, fmt, ...) \
    std::printf("[" tag "] " fmt "\n" __VA_OPT__(,) __VA_ARGS__)

int main() {
    DBG_PRINT("NET", "З'єднання встановлено");
    DBG_PRINT("CPU", "Завантаження: %d%%, Температура: %d C", 45, 62);
    return 0;
}
```
:::

#### Оператори перевірки середовища: `defined`, `__has_include`, `__has_cpp_attribute`

- `defined(NAME)` — повертає `1`, якщо макрос визначений, і `0` в іншому разі. Дозволяє формувати комплексні булеві вирази в директивах `#if` та `#elif`.
- `__has_include(<header>)` — перевіряє наявність файлу заголовка в системних шляхах пошуку без генерації помилки включення.
- `__has_cpp_attribute(attr)` та `__has_c_attribute(attr)` — повертають ціле ненульове число (версію або дату прийняття стандартом), якщо компілятор підтримує відповідний синтаксичний атрибут.

:::tabs
```c
#include <stdio.h>

#if defined(__has_include)
    #if __has_include(<stdfix.h>)
        #define HAS_FIXED_POINT 1
    #else
        #define HAS_FIXED_POINT 0
    #endif
#else
    #define HAS_FIXED_POINT 0
#endif

int main(void) {
    printf("Підтримка фіксованої коми: %d\n", HAS_FIXED_POINT);
    return 0;
}
```
```cpp
#include <iostream>

#if defined(__has_cpp_attribute)
    #if __has_cpp_attribute(nodiscard) >= 201907L
        #define SAFE_CHECK [[nodiscard("Ігнорування результату неприпустиме")]]
    #elif __has_cpp_attribute(nodiscard)
        #define SAFE_CHECK [[nodiscard]]
    #else
        #define SAFE_CHECK
    #endif
#else
    #define SAFE_CHECK
#endif

SAFE_CHECK int compute_status() {
    return 1;
}

int main() {
    std::cout << "Статус обчислення: " << compute_status() << "\n";
    return 0;
}
```

### 3. Стандартні зумовлені макроси

Стандарти C та C++ гарантують наявність низки службових макросів у кожній одиниці трансляції. Розробнику суворо заборонено скасовувати (`#undef`) або перевизначати (`#define`) ці макроси.

Крім загальноприйнятих макросів, більшість компіляторів надають службові розширення, такі як `__COUNTER__`, що збільшує своє цілочисельне значення на 1 при кожному зверненні. Це дозволяє генерувати унікальні імена змінних у межах однієї одиниці трансляції.

| Макрос | Тип повернення | Опис значення |
| :--- | :--- | :--- |
| `__FILE__` | `const char*` | Рядковий літерал із назвою та шляхом до поточного файлу вихідного коду. |
| `__LINE__` | `int` | Десяткове ціле число: номер поточного рядка у файлі (від 1). |
| `__DATE__` | `const char*` | Рядковий літерал із датою запуску компіляції у форматі `"Mmm dd yyyy"`. |
| `__TIME__` | `const char*` | Рядковий літерал із часом початку компіляції у форматі `"hh:mm:ss"`. |
| `__STDC__` | `int` | Значення `1`, якщо компілятор сумісний зі стандартом ISO C. |
| `__STDC_VERSION__` | `long` | Версія стандарту C: `199901L` (C99), `201112L` (C11), `201710L` (C17), `202311L` (C23). |
| `__cplusplus` | `long` | Версія стандарту C++: `201103L` (C++11), `201402L` (C++14), `201703L` (C++17), `202002L` (C++20), `202302L` (C++23). |
| `__STDC_HOSTED__` | `int` | `1` для повноцінних операційних систем; `0` для bare-metal систем без підтримки стандартної бібліотеки. |
| `__func__` | `const char[]` | Локальна службова змінна (не макрос), що містить ім'я поточної функції. |

Застосування зумовлених макросів забезпечує точне документування стану збирання та формування вичерпних журналів помилок у системних програмах.
