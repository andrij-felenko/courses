# 🧮 Математичні основи деревоподібних порядків: інтервальне кодування та транзитивне замикання

Ієрархічні структури даних мають строгий теоретико-графовий та топологічний опис. Щоб зберігати дерева у пласких реляційних відношеннях без втрати продуктивності під час обчислення нащадків та предків, застосовують два математичних апарати: геометричне вкладення числових інтервалів (модель Джо Селко) та матричне представлення транзитивного замикання відношень.

## Дерево як частковий порядок та орієнтований граф

Кореневе дерево визначається як зв'язний орієнтований ациклічний граф:

```
T = (V, E, r)
```

де:
- `V` — скінченна множина вершин (вузлів) кардинальності `|V| = n`;
- `E ⊆ V × V` — множина напрямлених ребер (дуг) від батьківського вузла до дочірнього;
- `r ∈ V` — унікальна вершина-корінь, для якої півстепінь заходу `in-degree(r) = 0`;
- для будь-якої іншої вершини `v ∈ V \ {r}` півстепінь заходу строго дорівнює одиниці: `in-degree(v) = 1`.

Граф `T` породжує строгий частковий порядок `≺` (відношення предка) на множині `V`:
- `u ≺ v` тоді й лише тоді, коли існує непустий спрямований шлях `(v₀, v₁, ..., vₖ)` у графі `T`, де `v₀ = u`, `vₖ = v` та `(vᵢ, vᵢ₊₁) ∈ E` для всіх `0 ≤ i < k`.

## Теорема про вкладення інтервалів Ейлерового обходу

Інтервальне кодування базується на формуванні ейлерового обходу графа в глибину (Depth-First Search, DFS). Нехай дискретний лічильник `t` ініціалізується одиницею: `t = 1`.

Під час обходу кожній вершині `v ∈ V` присвоюються дві цілочисельні мітки:
1. **Ліва межа `lft(v)`:** фіксується у момент першого входу у вершину `v` (`lft(v) = t++`).
2. **Права межа `rgt(v)`:** фіксується у момент повернення з вершини `v` після повного рекурсивного обходу всіх її нащадків (`rgt(v) = t++`).

Кожній вершині `v` зіставляється числовий інтервал на множині натуральних чисел:

```
I(v) = [lft(v), rgt(v)]
```

### Теорема (про диз'юнктність та строге вкладення)

Для будь-яких двох довільних вершин `u, v ∈ V` інтервали `I(u)` та `I(v)` задовольняють рівно одну з трьох взаємовиключних умов:

1. Інтервал `I(v)` строго міститься всередині `I(u)`:
```
lft(u) < lft(v)  та  rgt(v) < rgt(u)   [v є нащадком u, тобто u ≺ v]
```

2. Інтервал `I(u)` строго міститься всередині `I(v)`:
```
lft(v) < lft(u)  та  rgt(u) < rgt(v)   [u є нащадком v, тобто v ≺ u]
```

3. Інтервали `I(u)` та `I(v)` не перетинаються (диз'юнктні):
```
rgt(u) < lft(v)   або   rgt(v) < lft(u)   [вершини перебувають у різних гілках]
```

Жодні два інтервали в інтервальному кодуванні не можуть частково перекриватися, тобто ситуація `lft(u) < lft(v) < rgt(u) < rgt(v)` неможлива за побудовою DFS.

### Доведення

Розглянемо часові мітки входу та виходу рекурсивного алгоритму DFS.

Нехай алгоритм увійшов у вершину `u` у момент `lft(u)`. До моменту виходу з `u` (тобто до настання `rgt(u)`) алгоритм відвідує підмножину вершин `Subtree(u)`.

Якщо `v ∈ Subtree(u)`, то вхід у `v` відбувається після входу в `u`, а вихід із `v` відбувається до повернення з `u`:

```
lft(u) < lft(v) < rgt(v) < rgt(u)
```

Якщо `v ∉ Subtree(u)` та `u ∉ Subtree(v)`, то або весь стек викликів для `u` повністю завершується до початку входу у `v` (`rgt(u) < lft(v)`), або навпаки (`rgt(v) < lft(u)`).

Таким чином, перетин інтервалів без повного вкладення суперечив би дисципліні роботи стека викликів (LIFO). Теорему доведено.

### Властивості інтервалів та топологічні порядки

З теореми безпосередньо випливають базові кількісні характеристики піддерев:

**1. Розмір піддерева:** Кількість нащадків вершини `v` (включно із самою вершиною) точно визначається за формулою:

```
|Subtree(v)| = (rgt(v) - lft(v) + 1) / 2
```

Для визначення лише власних нащадків (без самого вузла):

```
|Descendants(v)| = (rgt(v) - lft(v) - 1) / 2
```

Доведення цього факту спирається на те, що кожен вузол у піддереві займає рівно два цілих числа в просторі ключів (одне для входу `lft`, одне для виходу `rgt`). Оскільки інтервали нащадків щільно заповнюють числовий діапазон між `lft(v)` та `rgt(v)`, загальна довжина інтервалу `rgt(v) - lft(v) + 1` містить рівно `2 · |Subtree(v)|` дискретних відліків.

**2. Критерій листка:** Вершина `v` є листком дерева тоді й лише тоді, коли між її лівим і правим ключем немає інших чисел:

```
rgt(v) = lft(v) + 1
```

**3. Глибина вершини (відстань від кореня):** Глибина `depth(v)` дорівнює кількості зовнішніх інтервалів, що охоплюють `I(v)`:

```
depth(v) = |{ u ∈ V : lft(u) < lft(v)  та  rgt(u) > rgt(v) }|
```

**4. Топологічне сортування:**
- Сортування вузлів за зростанням лівого ключа `ORDER BY lft ASC` дає точний прямий префіксний порядок обходу дерева (Pre-order Traversal).
- Сортування вузлів за зростанням правого ключа `ORDER BY rgt ASC` дає точний зворотний постфіксний порядок обходу дерева (Post-order Traversal).

## Дробові інтервали та дерево Штерна-Броко (Fractional Intervals)

Головний недолік класичних вкладених множин — цілочисельний зсув ключів при вставці нових вузлів. Щоб уникнути масового оновлення рядків, застосовують дробові інтервали (Fractional / Nested Intervals), де межі інтервалів є раціональними числами `p/q`.

Для генерації нових інтервалів між існуючими вузлами використовують властивість медіанти дробів Фарея та дерево Штерна-Броко:
- Для двох додатних нескоротних дробів `a/b` та `c/d` їхньою медіантою називається дріб:
  ```
  m = (a + c) / (b + d)
  ```
- Якщо `a/b < c/d` та `b·c - a·d = 1`, то медіанта строго лежить між ними: `a/b < (a + c)/(b + d) < c/d`.

Це дозволяє вставляти довільну кількість нових дочірніх інтервалів між будь-якими двома суміжними границями без зміни числових значень уже збережених вузлів.

## Алгебраїчне транзитивне замикання та матриці суміжності

Нехай зв'язки між вузлами графа задаються квадратною матрицею суміжності `A` розмірності `n × n`, де:

```
A[i, j] = 1, якщо (i, j) ∈ E (вузол i є прямим батьком вузла j)
A[i, j] = 0, якщо (i, j) ∉ E
```

Добуток матриць `A² = A · A` обчислює кількість шляхів довжини 2 між усіма парами вершин:

```
A²[i, j] = ∑_{k=1}^n A[i, k] · A[k, j]
```

Значення `A²[i, j] = 1` означає, що вузол `i` є «дідом» вузла `j`. Аналогічно степінь матриці `A^m` відображає наявність спрямованих шляхів довжини `m`.

Оскільки граф `T` є скінченним деревом із максимальною глибиною `h < n`, матриця `A` є нільпотентною (тобто існує такий степінь, при якому матриця перетворюється на нульову):

```
A^m = 0 для всіх m > h
```

### Транзитивне замикання

Матриця строгого транзитивного замикання `A⁺` визначає наявність шляху довільної додатної довжини між будь-якою парою вузлів:

```
A⁺
= A + A² + A³ + ... + A^h   [сума матриць шляхів усіх довжин від 1 до h]
= ∑_{k=1}^h A^k             [згортка в позначення скінченного ряду]
```

Рефлексивне транзитивне замикання `A*` включає одиничну матрицю `I` (шляхи нульової довжини від вузла до самого себе):

```
A*
= I + A⁺                    [додавання рефлексивних шляхів нульової довжини]
= I + A + A² + ... + A^h    [підстановка розкладу строгого замикання]
= (I - A)⁻¹                 [сума матричного ряду для нільпотентної матриці A]
```

Оскільки матриця `A` є нільпотентною, ряд Неймана `∑_{k=0}^∞ A^k` обривається на кроці `h` і є строго еквівалентним оберненій матриці `(I - A)⁻¹`.

### Зв'язок із таблицею замикання (Closure Table)

У реляційній моделі таблиця замикання `closure_table(ancestor_id, descendant_id, depth)` є точною матеріалізацією всіх ненульових елементів матриць `A^k`:

```
(u, v, k) ∈ closure_table  ⟺  A^k[u, v] > 0
```

Завдяки цьому запит на отримання всіх нащадків вершини `u` на довільну глибину зводиться до селекції за одним стовпчиком:

```
Descendants(u) = { v ∈ V : (u, v) ∈ A* }
```

Ця операція виконується за сталий час `O(1)` відносно структури графа за наявності B-Tree індексу на стовпчик `ancestor_id`.
