# 🧮 Математичний апарат k-анонімності, l-різноманітності та метрик втрати інформації

Математичне моделювання приватності в реляційних структурах даних базується на теорії розбиття багатовимірних просторів кортежів на класи еквівалентності, аналізі ентропії чутливих атрибутів та мінімізації цільових функцій інформаційних втрат.

## 1. Формалізація реляційного відношення та класів еквівалентності

Нехай задано реляційну таблицю `T = {t₁, t₂, ..., tₙ}`, що складається з `n` рядків над схемою атрибутів `A = {A₁, A₂, ..., Aₘ}`.

Множина атрибутів розбивається на три підмножини, що не перетинаються між собою:
- `ID ⊂ A` — прямі ідентифікатори особи (вилучаються або токенізуються перед публікацією);
- `QI = {Q₁, Q₂, ..., Qₚ} ⊆ A` — множина квазі-ідентифікаторів розмірності `p` (відкриті ознаки, присутні у зовнішніх реєстрах);
- `S = {S₁, S₂, ..., Sᵣ} ⊆ A` — множина конфіденційних (чутливих) атрибутів суб'єкта.

Для кожного кортежу `t ∈ T` його проєкція на квазі-ідентифікатори позначається як вектор `t[QI] = (t[Q₁], t[Q₂], ..., t[Qₚ])`.

**Означення класу еквівалентності.** Класом еквівалентності кортежу `t` щодо `QI`, який позначається `[t]_{QI}` (або `E`), є множина всіх кортежів таблиці `T`, що мають абсолютно тотожні значення на всіх квазі-ідентифікаторах:

```
[t]_{QI} = { s ∈ T : s[QI] = t[QI] }
```

Множина всіх класів еквівалентності `EC = {E₁, E₂, ..., Eᵤ}` утворює строге розбиття множини рядків таблиці `T`:

```
⋃_{i=1}^{u} E_i = T   і   E_i ∩ E_j = ∅ для всіх i ≠ j
```

## 2. Модель k-анонімності та верхня межа деанонімізації

Таблиця `T` задовольняє властивість `k`-анонімності щодо множини квазі-ідентифікаторів `QI` тоді й лише тоді, коли потужність кожного сформованого класу еквівалентності не менша за ціле число `k ≥ 2`:

```
∀ t ∈ T: |[t]_{QI}| ≥ k
```

**Оцінка ймовірності деанонімізації.** Припустимо, що зловмисник знає про гарантовану наявність цільової особи `x` у таблиці `T` і володіє точним вектором її квазі-ідентифікаторів `QI(x)`. Апостеріорна ймовірність `P` правильного зіставлення особи `x` із конкретним рядком `t ∈ [x]_{QI}` строго обмежується зверху:

```
P(t = record(x) | QI(x)) 
= 1 / |[x]_{QI}|        [вибір серед невідрізних рядків у межах класу]
≤ 1 / k                 [оскільки потужність класу щонайменше k]
```

Якщо `k = 1`, таблиця містить унікальні кортежі, де ймовірність розкриття становить `P = 1` (100%). Зі зростанням `k` ризик прямого вгадування спадає гіперболічно: при `k = 20` ймовірність не перевищує `0.05` (5%).

## 3. Складність задачі та евристика багатовимірного розбиття Mondrian

Пошук оптимального набору узагальнень та супресій, що мінімізує інформаційні втрати при забезпеченні `k`-анонімності, є `NP`-складною задачею (доведено Мейєрсоном та Вільямсом 2004 року через зведення до задачі про вершинне покриття графа).

На практиці для реляційних масивів застосовують жадібний алгоритм багатовимірного розбиття Mondrian:

1. Вся таблиця розглядається як єдиний гіпероб'єм у `p`-вимірному просторі квазі-ідентифікаторів.
2. Алгоритм обирає вимір `Qⱼ` із найбільшим нормалізованим розмахом значень.
3. Обчислюється медіана значень атрибута `Qⱼ`.
4. Простір розсікається гіперплощиною на дві частини: ліву `T_left = { t : t[Qⱼ] ≤ median }` та праву `T_right = { t : t[Qⱼ] > median }`.
5. Якщо обидві підмножини містять щонайменше `k` рядків (`|T_left| ≥ k` і `|T_right| ≥ k`), процедура рекурсивно повторюється для кожної половини.
6. Якщо поділ призводить до утворення області з кількістю рядків `< k`, розбиття цієї гілки зупиняється, а всі кортежі в блоці узагальнюються до спільних граничних меж `[min, max]`.

## 4. l-Різноманітність та ентропійний захист від гомогенності

Якщо всі рядки в класі `E` містять ідентичне значення чутливого атрибута `s ∈ S`, то попри дотримання `|E| ≥ k` розкриття стану особи відбувається з імовірністю `P = 1`.

### Дискретна l-різноманітність (Distinct l-Diversity)
Клас `E` вважається дискретно `l`-різноманітним, якщо в ньому наявні щонайменше `l` різних станів чутливого поля:

```
∀ E ∈ EC: |{ t[S] : t ∈ E }| ≥ l
```

### Ентропійна l-різноманітність (Entropy l-Diversity)
Дискретна модель не враховує перекосу частот (наприклад, 98 пацієнтів із застудою і 2 пацієнти з рідкісним захворюванням). Ентропійний критерій оцінює рівномірність.

Нехай `p(E, s)` — емпірична ймовірність зустріти чутливе значення `s ∈ S` у межах класу `E`:

```
p(E, s) = |{ t ∈ E : t[S] = s }| / |E|
```

Інформаційна ентропія розподілу чутливого атрибута в класі `E` за формулою Шеннона дорівнює:

```
H(E) = - ∑_{s ∈ S} p(E, s) · log₂(p(E, s))
```

Клас `E` задовольняє ентропійну `l`-різноманітність, якщо його ентропія не менша за ентропію ідеального рівномірного розподілу між `l` альтернативами:

```
H(E) ≥ log₂(l)
```

## 5. t-Близькість через метрику переміщення мас (Earth Mover's Distance)

Якщо чутливий атрибут має сильний популяційний перекіс у межах конкретної підгрупи, застосовують модель `t`-близькості.

Нехай `Q = (q₁, q₂, ..., qᵥ)` — глобальний вектор розподілу ймовірностей значень чутливого поля `S` у всій таблиці `T`, а `P = (p₁, p₂, ..., pᵥ)` — локальний вектор розподілу того самого поля в класі `E`.

Клас `E` задовольняє вимогу `t`-близькості, якщо відстань між розподілами `D[P, Q]` не перевищує порогового значення `t ∈ [0, 1]`:

```
D[P, Q] ≤ t
```

Для впорядкованих категоріальних або числових шкал відстань обчислюється як нормалізована метрика переміщення мас (1-Wasserstein / Earth Mover's Distance):

```
D[P, Q] = (1 / (v - 1)) · ∑_{i=1}^{v-1} | ∑_{j=1}^{i} (p_j - q_j) |
```

Ця величина вимірює мінімальну роботу, необхідну для перетворення локального розподілу `P` на глобальний розподіл `Q`, нормалізовану довжиною шкали станів.

## 6. Метрики оцінки інформаційних втрат (Information Loss)

Оскільки генералізація розмиває значення, а супресія повністю видаляє рядки, алгоритми анонімізації мінімізують математичні функції штрафу за втрату аналітичної точності.

### Нормований штраф визначеності (Normalized Certainty Penalty, NCP)
Для числового або ієрархічного квазі-ідентифікатора `Qⱼ`, узагальненого для кортежу `t` до інтервалу `[v_low, v_high]` при загальному діапазоні домену `[min_j, max_j]`, штраф невизначеності обчислюється як:

```
NCP(t[Qⱼ]) = (v_high - v_low) / (max_j - min_j)
```

Якщо атрибут збережено в первинному точному вигляді (`v_low = v_high`), значення `NCP = 0`. При повному придушенні на весь діапазон домену `NCP = 1`.

Сумарний штраф таблиці `T` за всіма `n` рядками та `p` квазі-ідентифікаторами:

```
NCP(T) = (1 / (n · p)) · ∑_{t ∈ T} ∑_{j=1}^{p} NCP(t[Qⱼ])
```

### Метрика помітності (Discernibility Metric, DM)
Метрика `DM` штрафує розмір груп еквівалентності: кожен рядок у класі `E` отримує штраф, пропорційний розміру свого класу, а повністю придушені (вилучені) рядки штрафуються розміром усієї таблиці `n`:

```
DM(T) = ∑_{E ∈ EC} |E|² + |Suppressed| · n
```

### Числовий приклад розрахунку компромісу між DM та NCP

Розглянемо вибірку з `n = 6` записів із віком у діапазоні `[20, 80]` (довжина домену `60` років):

1. **Без анонімізації (k = 1):** 6 класів розміром по 1.
   Штраф `NCP = 0` (повна точність), штраф `DM = 1² + 1² + 1² + 1² + 1² + 1² = 6`. Рівень приватності нульовий.
2. **Розбиття на 2 класи по 3 записи (k = 3):**
   - Клас `E₁` узагальнено до інтервалу `[20, 39]` (розмах 19): `NCP(E₁) = 19 / 60 ≈ 0.316`.
   - Клас `E₂` узагальнено до інтервалу `[40, 79]` (розмах 39): `NCP(E₂) = 39 / 60 = 0.650`.
   - Середній штраф `NCP(T) = (3 · 0.316 + 3 · 0.650) / 6 = 0.483` (втрата близько 48% визначеності).
   - Штраф помітності `DM(T) = 3² + 3² = 18`. Забезпечено гарантовану 3-анонімність.

Оптимальна конфігурація анонімізації досягається при мінімізації `DM(T)` та `NCP(T)` за умови жорсткого дотримання обмежень `|E| ≥ k`, `H(E) ≥ log₂(l)` та `D[P, Q] ≤ t`.
