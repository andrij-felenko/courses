# 🧮 Диференційне числення реляційних представлень (IVM Calculus)

Математичною основою інкрементного оновлення матеріалізованих представлень (Incremental View Maintenance, IVM) є диференційне реляційне числення над мультимножинами (кортежами з урахуванням кратності / Bags). У реляційній моделі відношення розглядається не як класична множина унікальних елементів, а як функція кратності:

```
R : T → ℕ₀
```

де кожному можливому кортежу `t ∈ T` зіставляється невід'ємне ціле число `R(t)`, яке позначає кількість його входжень у таблицю.

---

### Алгебра мутацій та формальне представлення дельт

Будь-яка транзакційна зміна стану реляційної таблиці `R` описується парою диз'юнктних мультимножин:
* `ΔR⁺` — мультимножина доданих кортежів (породжених оператором `INSERT`);
* `ΔR⁻` — мультимножина видалених кортежів (породжених оператором `DELETE`).

Операція модифікації `UPDATE` формально розкладається на атомарне видалення старої версії кортежу та вставку нової версії:

```
ΔR = (ΔR⁺, ΔR⁻)
```

Новий стан відношення `R_new` після застосування мутації обчислюється через адитивну суперпозицію:

```
R_new = (R_old \ ΔR⁻) ∪ ΔR⁺
```

Для довільного реляційного виразу `V = f(R₁, R₂, …, Rₖ)` мета диференційного числення полягає в знаходженні оператора `Δf`, такого що новий стан матеріалізованого результату обчислюється безпосередньо з поточного стану та дельт:

```
V_new = V_old + ΔV
```

де обчислення `ΔV` спирається виключно на `ΔRᵢ` та поточний стан базових таблиць, без повторного виконання вихідного виразу `f(R₁, …, Rₖ)` над повними обсягами даних.

---

### Диференційні правила базових реляційних операторів

#### 1. Селекція (Фільтрація, σ)

Нехай оператор селекції `σ_p(R)` вибирає кортежі, що задовольняють логічний предикат `p`. Оскільки предикат застосовується до кожного кортежу ізольовано, оператор селекції є строго дистрибутивним щодо операцій додавання та видалення мультимножин.

Покрокове виведення диференційного правила для селекції:

```
Δ(σ_p(R))
= σ_p(R_new) - σ_p(R_old)                   [означення зміни результату]
= σ_p(R_old - ΔR⁻ + ΔR⁺) - σ_p(R_old)       [підстановка нового стану базової таблиці]
= (σ_p(R_old) - σ_p(ΔR⁻) + σ_p(ΔR⁺)) - σ_p(R_old) [дистрибутивність селекції щодо мультимножин]
= σ_p(ΔR⁺) - σ_p(ΔR⁻)                       [скорочення однакових членів σ_p(R_old)]
= σ_p(ΔR)                                   [згортання в дельта-оператор]
```

Таким чином, для оновлення фільтрованого представлення достатньо застосувати предикат `p` виключно до вставлених і видалених рядків:

```
ΔV⁺ = σ_p(ΔR⁺)
ΔV⁻ = σ_p(ΔR⁻)
```

---

#### 2. Проєкція (Вибір атрибутів, π) та лічильники кратності

Оператор проєкції `π_A(R)` залишає лише підмножину атрибутів `A`. Якщо у вихідному відношенні два різних кортежі `t₁ ≠ t₂` мали однакові значення проєктованих атрибутів `A` (`t₁.A = t₂.A`), у результаті проєкції виникає дублювання кортежів.

Щоб коректно обробляти операції видалення `DELETE`, матеріалізоване представлення зобов'язане зберігати кратність кожного результуючого кортежу у вигляді додаткового службового стовпця `__count`:

```
V(a) = ∑_{t ∈ R, t.A = a} R(t)
```

Диференційне правило зміни кратності для значення `a`:

```
ΔV(a)
= V_new(a) - V_old(a)                       [різниця кратностей]
= ∑_{t ∈ ΔR⁺, t.A = a} 1 - ∑_{t ∈ ΔR⁻, t.A = a} 1 [баланс доданих та видалених входжень]
```

Якщо після застосування дельти для кортежу `a` значення кратності досягає нуля:

```
V_new(a) = V_old(a) + ΔV(a) = 0
```

кортеж `a` повністю видаляється з фізичного сховища матеріалізованого представлення.

---

#### 3. Реляційне з'єднання (Inner Join, ⋈)

Розглянемо матеріалізоване з'єднання двох таблиць `V = R ⋈ S`. Нехай одночасно мутували обидві таблиці: `R_new = R_old + ΔR` та `S_new = S_old + ΔS`.

Виведення диференційного правила з'єднання за білінійною схемою:

```
Δ(R ⋈ S)
= (R_new ⋈ S_new) - (R_old ⋈ S_old)         [означення зміни з'єднання]
= ((R_old + ΔR) ⋈ (S_old + ΔS)) - (R_old ⋈ S_old) [підстановка нових станів таблиць]
= (R_old ⋈ S_old) + (ΔR ⋈ S_old) + (R_old ⋈ ΔS) + (ΔR ⋈ ΔS) - (R_old ⋈ S_old) [дистрибутивність з'єднання]
= (ΔR ⋈ S_old) + (R_old ⋈ ΔS) + (ΔR ⋈ ΔS)   [скорочення базового члена R_old ⋈ S_old]
= (ΔR ⋈ (S_old + ΔS)) + (R_old ⋈ ΔS)        [групування доданків]
= (ΔR ⋈ S_new) + (R_old ⋈ ΔS)               [підстановка S_new]
```

Отримана симетрична формула:

```
ΔV = (ΔR ⋈ S_new) ∪ (R_old ⋈ ΔS)
```

дозволяє обчислити зміну з'єднання двома незалежними точковими операціями:
1. З'єднати дельту першої таблиці `ΔR` з актуальним станом другої таблиці `S_new`.
2. З'єднати старий стан першої таблиці `R_old` з дельтою другої таблиці `ΔS`.

Для багатотабличних з'єднань трьох і більше відношень `V = R₁ ⋈ R₂ ⋈ … ⋈ Rₙ` диференційне правило узагальнюється у вигляді полілінійної телескопічної суми:

```
Δ(R₁ ⋈ R₂ ⋈ … ⋈ Rₙ) = ∑_{i=1}^n (R₁_old ⋈ … ⋈ R_{i-1}_old ⋈ ΔRᵢ ⋈ R_{i+1}_new ⋈ … ⋈ Rₙ_new)
```

де кожен доданок вимагає лише одного дельта-сканування та `(n - 1)` точкових індексних з'єднань.

---

#### 4. Ліве зовнішнє з'єднання (Left Outer Join, ⟕)

У лівому зовнішньому з'єднанні `V = R ⟕ S` кортеж `r ∈ R`, для якого немає відповідників у таблиці `S`, доповнюється значеннями `NULL`.

Диференційне правило для `R ⟕ S` розкладається на три взаємовиключні випадки:
1. Якщо в таблицю `R` додано рядок `r`, а в `S` знайдено збіги `s₁, s₂`, генерується `r ⋈ {s₁, s₂}`. Якщо збігів немає, генерується `(r, NULL)`.
2. Якщо в таблицю `S` додано перший рядок `s`, який збігається з раніше непарним рядком `r`, рушій зобов'язаний видалити `(r, NULL)` зі знаком мінус і додати `(r, s)` зі знаком плюс:
   ```
   ΔV = - (r, NULL) + (r, s)
   ```
3. Якщо з таблиці `S` видалено останній рядок, що відповідав кортежу `r`, рушій видаляє пару `(r, s)` і повертає `(r, NULL)`.

### Диференційне числення агрегатних функцій

Агрегатні функції класифікуються за їхньою математичною структурою на три категорії:

#### 1. Дистрибутивні агрегати (`COUNT`, `SUM`)
Формують комутативну абелеву групу щодо операції додавання. Значення оновлюються прямим арифметичним додаванням або відніманням дельти:

```
COUNT_new = COUNT_old + COUNT(ΔR⁺) - COUNT(ΔR⁻)
SUM_new   = SUM_old   + SUM(ΔR⁺)   - SUM(ΔR⁻)
```

#### 2. Алгебраїчні агрегати (`AVG`, вибіркова дисперсія `VAR`, середньоквадратичне відхилення `STDDEV`)
Алгебраїчні агрегати не є дистрибутивними безпосередньо, але детерміновано виражаються через вектор дистрибутивних підсумків.

Для середнього арифметичного значення:

```
AVG(R) = SUM(R) / COUNT(R)
```

Диференційне виведення середнього значення:

```
AVG_new
= (SUM_old + ΔSUM) / (COUNT_old + ΔCOUNT)    [вираження через диференційні суми]
```

Для вибіркової дисперсії використовується збереження суми квадратів значень `SS = ∑ xᵢ²`:

```
VAR(R) = (SS(R) / COUNT(R)) - (AVG(R))²
```

Дельта суми квадратів обчислюється ідентично до простої суми:

```
SS_new = SS_old + ∑_{x ∈ ΔR⁺} x² - ∑_{x ∈ ΔR⁻} x²
```

#### 3. Холістичні агрегати (`MIN`, `MAX`, `MEDIAN`, `PERCENTILE`)
Агрегати `MIN` та `MAX` є напівдистрибутивними щодо операції `INSERT`:
* Якщо в групу додається новий елемент `x`, нове мінімальне значення дорівнює `MIN_new = min(MIN_old, x)`.
* Проте операція `DELETE` порушує зворотність: якщо видаляється поточний мінімальний елемент `x = MIN_old`, знайти наступний мінімум без повного пересканування неможливо. Щоб уникнути повного перерахунку групи, рушій зобов'язаний зберігати впорядковану гістограму або дерево підрахунку кількості кожного унікального значення в групі.

### Інкрементне обчислення рекурсивних представлень (Datalog / Fixed-Point)

Для рекурсивних запитів (наприклад, обчислення транзитивного замикання графів зв'язків або ієрархічних структур організацій) використовується диференційний метод фіксованої точки (Semi-naive Evaluation).

Нехай рекурсивне правило задане рівнянням:

```
R = R₀ ∪ (R ⋈ E)
```

де `E` — таблиця ребер графа. При додаванні нових ребер `ΔE` алгоритм не перераховує всі шляхи заново, а ітерує лише нові виведені шляхи `ΔR^(k)`:

```
ΔR^(k+1) = (ΔR^(k) ⋈ E_old) ∪ (R_old ⋈ ΔE)
```

Ітерації зупиняються, коли `ΔR^(k+1) = ∅` (досягнення найменшої фіксованої точки).

---

### Аналіз часової складності: Повне обчислення проти IVM

Нехай розміри базових таблиць становлять `|R| = N` та `|S| = M`, а обсяги транзакційних змін дорівнюють `|ΔR| = n ≪ N` та `|ΔS| = m ≪ M`. За наявності B-Tree індексів на атрибутах з'єднання:

* **Повне обчислення з'єднання на льоту (Hash Join / Sort-Merge Join)**:
```
T_full = O(N + M + N · log N)
```
* **Інкрементне обчислення дельти (IVM через індексний пошук)**:
```
T_ivm = O(n · log M + m · log N)
```

При `N = 10 000 000`, `M = 50 000 000` та транзакційній дельті `n = 100`, `m = 0`:
* Повне обчислення потребує порядку `60 000 000` дискових операцій та порівнянь.
* Інкрементне оновлення дельти вимагає: `100 · log₂(50 000 000) ≈ 100 · 26 = 2 600` операцій.

Зниження обчислювальних витрат становить понад чотири порядки величини (`×23 000`), що дозволяє підтримувати матеріалізовані представлення в актуальному стані безпосередньо в транзакційному циклі.
