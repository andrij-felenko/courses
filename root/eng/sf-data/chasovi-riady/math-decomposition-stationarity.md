# 🧮 Математична декомпозиція та стаціонарність часових рядів

Аналіз часових рядів у системах збереження та обробки телеметрії спирається на суворий математичний апарат теорії ймовірностей та математичної статистики. Коли інженерний моніторинг фіксує сплеск затримки мережевих запитів або поступове зростання споживання оперативної пам'яті, алгоритми автоматичного виявлення аномалій (англ. *anomaly detection*) та прогнозування навантаження (англ. *capacity forecasting*) повинні відокремити передбачувані добові коливання від системного збою чи довгострокового тренду. Ця вставка розгортає математичний фундамент часових рядів: умови слабкої та суворої стаціонарності, виведення автоковаріаційної та автокореляційної функцій, формальні моделі адитивної й мультиплікативної декомпозиції, метод експоненційного згладжування Хольта-Вінтерса та критерій наявності одиничного кореня Дікі-Фуллера.

## Формальне означення часового ряду та ймовірнісні моменти

Математично **часовий ряд** (лат. *series* — ряд, ланцюг) є дискретною реалізацією неперервного або дискретного стохастичного процесу `{X(t), t ∈ T}`, де множина індексів `T` зазвичай упорядкована за часом: `T = {t₁, t₂, ..., t_N}`.

Кожен елемент `X_t` є випадковою величиною, яка підпорядковується певному закону розподілу ймовірностей. Поведінка такого процесу в часі повністю описується системою його ймовірнісних моментів першого та другого порядків.

### 1. Математичне сподівання (перший момент)

Математичне сподівання (англ. *expected value*, позначається `μ_t`) визначає середній рівень значень процесу в момент часу `t`:

```
μ_t = E[X_t]
```

Якщо `X_t` є неперервною випадковою величиною зі щільністю ймовірності `f_t(x)`, то сподівання обчислюється через інтеграл:

```
E[X_t] = ∫ x · f_t(x) dx   (межі інтегрування від -∞ до +∞)
```

### 2. Дисперсія та автоковаріація (другі моменти)

Дисперсія (англ. *variance*, лат. *dispersio* — розсіювання) вимірює масштаб випадкових відхилень значень ряду від середнього рівня:

```
σ²_t = Var(X_t) = E[(X_t - μ_t)²]
```

Зв'язок між двома спостереженнями `X_s` та `X_t`, здійсненими в різні моменти часу `s` і `t`, описується **автоковаріаційною функцією** (лат. *con-* — разом + *variare* — змінювати, позначається `γ(s, t)`):

```
γ(s, t) = Cov(X_s, X_t)
= E[(X_s - μ_s) · (X_t - μ_t)]   [за означенням коваріації]
= E[X_s · X_t] - μ_s · μ_t       [розкриття добутку та лінійність сподівання]
```

Дисперсія є окремим випадком автоковаріації при збігу часових точок: `Var(X_t) = γ(t, t)`.

### 3. Автокореляційна функція (ACF)

Оскільки значення коваріації залежать від одиниць вимірювання (наприклад, мілісекунди або гігабайти), для порівняння ступеня зв'язку використовують безрозмірну **автокореляційну функцію** (грец. *autos* — сам + лат. *relatio* — відношення, позначається `ρ(s, t)`):

```
ρ(s, t) = γ(s, t) / √(Var(X_s) · Var(X_t))   [за означенням коефіцієнта кореляції]
= γ(s, t) / (σ_s · σ_t)                      [підстановка стандартних відхилень σ_s, σ_t]
```

За нерівністю Коші-Буняковського значення автокореляції завжди обмежені одиничним діапазоном:

```
-1 ≤ ρ(s, t) ≤ 1
```

## Математична стаціонарність: сувора та слабка

Більшість класичних статистичних методів і моделей прогнозування (ARIMA, експоненційне згладжування, фільтри Калмана) вимагають, щоб статистичні властивості процесу залишалися стабільними в часі. Ця властивість називається **стаціонарністю** (лат. *stationarius* — нерухомий, від *stare* — стояти).

### Сувора стаціонарність (Strong Stationarity)

Випадковий процес `{X_t}` називається **суворо стаціонарним** (або стаціонарним у вузькому розумінні), якщо спільний розподіл ймовірностей довільного набору значень `(X_{t₁}, X_{t₂}, ..., X_{t_k})` є інваріантним відносно будь-якого часового зсуву `h`:

```
P(X_{t₁} ≤ x₁, ..., X_{t_k} ≤ x_k) = P(X_{t₁+h} ≤ x₁, ..., X_{t_k+h} ≤ x_k)   [для всіх k, t_i та h]
```

Це означає, що вся функція розподілу ймовірностей (усі нескінченні моменти) не змінюється при перенесенні початку відліку часу. На практиці перевірити сувору стаціонарність для реальних метрик телеметрії неможливо через обмежений обсяг вибірки.

### Слабка стаціонарність (Weak / Covariance Stationarity)

Для практичного застосування використовують **слабку стаціонарність** (стаціонарність другого порядку або коваріаційну стаціонарність). Процес `{X_t}` є слабко стаціонарним, якщо він задовольняє три математичні умови:

1. **Постійне математичне сподівання**:
   ```
   E[X_t] = μ = const   [для всіх t]
   ```
2. **Скінченна постійна дисперсія**:
   ```
   Var(X_t) = σ² = const < ∞   [для всіх t]
   ```
3. **Автоковаріація залежить виключно від лагу `k`**, а не від абсолютного часу `t`:
   ```
   γ(t, t+k) = γ(k) = E[(X_t - μ)(X_{t+k} - μ)]   [для всіх t і будь-якого лагу k]
   ```

Для слабко стаціонарного процесу автокореляційна функція `ρ(k)` спрощується до одновимірної функції часового лагу `k`:

```
ρ(k) = γ(k) / γ(0)
```

Властивості автокореляційної функції стаціонарного процесу:
- `ρ(0) = γ(0) / γ(0) = 1` (кореляція точки самої з собою ідеальна).
- `ρ(k) = ρ(-k)` (парність функції відносно зміни знака лагу).
- `|ρ(k)| ≤ 1` для будь-якого `k`.

### Оцінка вибіркової автокореляції (Sample ACF)

Для дискретного часового ряду довжиною `N` спостережень `{x₁, x₂, ..., x_N}` із вибірковим середнім `x̄` вибіркова автоковаріація `c_k` та вибіркова автокореляція `r_k` обчислюються за формулами:

```
x̄ = (1 / N) · ∑_{t=1}^{N} x_t

c_k = (1 / N) · ∑_{t=1}^{N-k} (x_t - x̄) · (x_{t+k} - x̄)

r_k = c_k / c_0
```

Якщо значення `r_k` повільно спадають до нуля зі зростанням `k`, ряд містить чіткий тренд (нестаціонарність за середнім). Якщо на графіку `r_k` з'являються періодичні піки (наприклад, на `k = 24` або `k = 168` для годинних даних), це вказує на наявність добової або тижневої сезонності.

## Структурна декомпозиція часового ряду

Реальні телеметричні метрики серверів та сервісів майже завжди є нестаціонарними. Вони містять довгострокові зміни (зростання бази клієнтів), періодичні бізнес-цикли (пікове навантаження в робочі години) та стохастичний шум.

**Декомпозиція** — це математичне розкладання спостережуваного ряду `Y_t` на три фундаментальні складові:
1. `T_t` — **тренд** (англ. *trend* / *drift*): плавна довгострокова зміна середнього рівня процесу.
2. `S_t` — **сезонність** (англ. *seasonality*): регулярні коливання з постійним періодом `p` (наприклад, `p = 24` години або `p = 7` днів), де `S_{t+p} = S_t`.
3. `I_t` (або `ε_t`) — **шум** / випадковий залишок (англ. *irregular / residual / noise*): непередбачувана випадкова компонента з нульовим математичним сподіванням `E[I_t] = 0`.

### Адитивна модель декомпозиції

Адитивна модель передбачає, що амплітуда сезонних коливань та розмах шуму не залежать від абсолютного рівня тренду:

```
Y_t = T_t + S_t + I_t
```

Покрокове виділення компонент за методом ковзного середнього (Classical Additive Decomposition):

**Крок 1. Оцінка тренду `T_t` через центрування ковзного середнього (CMA).**
Для періоду сезонності `p` (якщо `p` парне, наприклад `p = 24`):

```
T_t = (1 / (2p)) · [ x_{t - p/2} + 2 · ∑_{j = -(p/2)+1}^{(p/2)-1} x_{t+j} + x_{t + p/2} ]
```

**Крок 2. Розрахунок детрендованого ряду (Detrending).**
Віднімаємо обчислений тренд від вихідних спостережень:

```
D_t = Y_t - T_t = S_t + I_t   [за адитивною моделлю]
```

**Крок 3. Оцінка сезонної компоненти `S_t`.**
Для кожного сезонного індексу `i ∈ {1, 2, ..., p}` обчислюємо середнє значення детрендованого ряду `D_t` по всіх доступних циклах `m = 1, 2, ..., M`:

```
S̃_i = (1 / M) · ∑_{m=0}^{M-1} D_{i + m·p}
```

Щоб сума сезонних відхилень за повний період строго дорівнювала нулю, застосовуємо центрування:

```
S_mean = (1 / p) · ∑_{i=1}^{p} S̃_i
S_i = S̃_i - S_mean            [гарантує: ∑_{i=1}^{p} S_i = 0]
```

**Крок 4. Розрахунок випадкового залишку (Residual Noise).**
Залишок обчислюється як різниця між вихідним рядом і сумою виділених компонент:

```
I_t = Y_t - T_t - S_t
```

### Мультиплікативна модель декомпозиції

Якщо амплітуда сезонних коливань та розмах випадкових стрибків пропорційні поточному рівню тренду (наприклад, при зростанні трафіку в 10 разів добові піки також збільшуються в 10 разів), використовують мультиплікативну модель:

```
Y_t = T_t · S_t · I_t
```

При цьому нормалізована сезонна компонента коливається навколо одиниці:

```
(1 / p) · ∑_{i=1}^{p} S_i = 1
```

Мультиплікативну модель можна строго звести до адитивної за допомогою логарифмічного перетворення (якщо `Y_t > 0`):

```
ln(Y_t)
= ln(T_t · S_t · I_t)
= ln(T_t) + ln(S_t) + ln(I_t)   [за властивістю логарифма добутку]
```

Логарифмування стабілізує зростаючу дисперсію ряду (гомоскедастичність), дозволяючи застосовувати лінійні алгоритми фільтрації та виявлення викидів.

## Експоненційне згладжування та модель Хольта-Вінтерса

Для обробки нескінченних потоків телеметрії в реальному часі алгоритми не можуть зберігати всю історію для розрахунку ковзного середнього. Замість цього використовують рекурентні фільтри з експоненційно спадними вагами минулих спостережень.

### Просте експоненційне згладжування (SES)

Для стаціонарного ряду без вираженого тренду та сезонності нове згладжене значення `S_t` розраховується як зважена комбінація поточного вимірювання `X_t` та попереднього стану `S_{t-1}` з коефіцієнтом згладжування `α ∈ (0, 1)`:

```
S_t = α · X_t + (1 - α) · S_{t-1}
```

Розгорнемо рекурентну формулу для глибини `k` кроків назад:

```
S_t
= α · X_t + (1 - α) · [α · X_{t-1} + (1 - α) · S_{t-2}]
= α · X_t + α(1 - α) · X_{t-1} + (1 - α)² · S_{t-2}
= α · ∑_{j=0}^{k} (1 - α)^j · X_{t-j} + (1 - α)^{k+1} · S_{t-k-1}   [розгортання рекурентної залежності]
```

Оскільки `(1 - α) < 1`, ваговий коефіцієнт `w_j = α · (1 - α)^j` експоненційно прямує до нуля при віддаленні в минуле (`j → ∞`). Сума всіх нескінченних ваг строго дорівнює одиниці:

```
∑_{j=0}^{∞} α · (1 - α)^j
= α · (1 / (1 - (1 - α)))   [сума нескінченної геометричної прогресії]
= α · (1 / α)
= 1
```

### Потрійне експоненційне згладжування Хольта-Вінтерса

Модель Хольта-Вінтерса (англ. *Holt-Winters Triple Exponential Smoothing*) динамічно відстежує три параметри: поточний базовий рівень `L_t`, нахил тренду `b_t` та вектор сезонних коефіцієнтів `S_t` із періодом `p`.

Для **адитивної моделі** з коефіцієнтами згладжування `α, β, γ ∈ [0, 1]` система рекурентних рівнянь має вигляд:

```
L_t = α · (Y_t - S_{t-p}) + (1 - α) · (L_{t-1} + b_{t-1})      [оновлення базового рівня]
b_t = β · (L_t - L_{t-1}) + (1 - β) · b_{t-1}                  [оновлення нахилу тренду]
S_t = γ · (Y_t - L_{t-1} - b_{t-1}) + (1 - γ) · S_{t-p}        [оновлення сезонного коефіцієнта]
```

Прогноз на `h` кроків уперед `Ŷ_{t+h}` будується екстраполяцією вирівняного рівня, лінійного тренду та відповідного сезонного зсуву:

```
Ŷ_{t+h} = L_t + h · b_t + S_{t + h - p · ⌈h/p⌉}
```

Ця формула виконується за константний час `O(1)` і потребує пам'яті лише для збереження одного скаляра рівня, скаляра тренду та масиву з `p` сезонних коефіцієнтів, що робить її ідеальним кандидатом для вбудовування в рушії потокової аналітики часових рядів.

## Тест Дікі-Фуллера на наявність одиничного кореня

Щоб автоматизована система могла перевірити, чи є часовий ряд стаціонарним, використовують статистичний тест Дікі-Фуллера (англ. *Dickey-Fuller Test*, ADF).

Розглянемо авторегресійну модель першого порядку AR(1):

```
Y_t = φ · Y_{t-1} + ε_t   [де ε_t — білий шум із E[ε_t] = 0 та дисперсією σ²]
```

Умови поведінки системи залежно від значення параметра `φ`:
1. `|φ| < 1` — процес є стаціонарним. Будь-який випадковий сплеск `ε_t` з часом згасає: `E[Y_{t+k} | Y_t] = φ^k · Y_t → 0` при `k → ∞`.
2. `|φ| > 1` — процес є вибуховим (дисперсія експоненційно прямує до нескінченності).
3. `φ = 1` — процес містить **одиничний корінь** (випадкове блукання, англ. *random walk*). Попередні збурення ніколи не згасають: `Y_t = ∑_{j=1}^{t} ε_j`, а дисперсія лінійно зростає з часом: `Var(Y_t) = t · σ²`.

Для проведення тесту віднімемо `Y_{t-1}` від обох частин рівняння:

```
Y_t - Y_{t-1}
= φ · Y_{t-1} - Y_{t-1} + ε_t   [віднімання Y_{t-1} від обох частин рівняння]
= (φ - 1) · Y_{t-1} + ε_t       [винесення спільного множника Y_{t-1} за дужки]
```

Введемо оператор першої різниці `ΔY_t = Y_t - Y_{t-1}` та коефіцієнт `δ = φ - 1`:

```
ΔY_t = δ · Y_{t-1} + ε_t
```

Статистична гіпотеза формулюється так:
- **Нульова гіпотеза `H₀`**: `δ = 0` (тобто `φ = 1`, процес містить одиничний корінь і є нестаціонарним).
- **Альтернативна гіпотеза `H₁`**: `δ < 0` (тобто `φ < 1`, процес є стаціонарним).

Тестова статистика розраховується як t-відношення оцінки найменших квадратів `δ̂` до її стандартної похибки `SE(δ̂)`:

```
t_stat = δ̂ / SE(δ̂)
```

Оскільки при виконанні нульової гіпотези статистика `t_stat` не підпорядковується стандартному розподілу Стьюдента, її порівнюють зі спеціальними таблицями критичних значень Дікі-Фуллера (розподіл Тау). Якщо `t_stat` є меншою за критичне значення (наприклад, `-2.86` на рівні значущості 5%), нульова гіпотеза відхиляється, і ряд визнається **стаціонарним**. Якщо ж ряд нестаціонарний, його приводять до стаціонарного вигляду взяттям послідовних різниць `ΔY_t = Y_t - Y_{t-1}` перед передачею в аналітичні моделі.
