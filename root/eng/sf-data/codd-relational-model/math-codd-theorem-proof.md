# 🧮 Доведення теореми Кодда та реляційна повнота

Ця вставка містить точне математичне доведення теореми Едгара Кодда про синтаксичну та семантичну еквівалентність процедурної реляційної алгебри (Relational Algebra, RA) та декларативного реляційного числення кортежів (Tuple Relational Calculus, TRC), обмеженого умовою безпечності (Safe TRC).

## Математичні означення та феномен «небезпечних» запитів

Нехай `DB = {R₁, R₂, ..., Rₘ}` є реляційною базою даних над скінченною множиною атрибутів `U`. Кожне відношення `Rᵢ` визначене на схемі `Schema(Rᵢ) ⊆ U` і являє собою скінченну множину кортежів `Rᵢ ⊆ D₁ × D₂ × ... × Dₖ`.

**Активний домен бази даних** `Dom(DB)` визначається як скінченна множина всіх скалярних значень, які фізично присутні у кортежах відношень бази даних `DB` або явним чином вказані в константах запиту `Q`.

Реляційне числення кортежів (TRC) оперує виразами вигляду:

```
Q = { t(A₁, ..., Aₖ) | φ(t) }
```

де `t` — змінна кортежу зі схемою `A₁, ..., Aₖ`, а `φ(t)` — формула логіки першого порядку, побудована з атомарних предикатів `Rᵢ(t)`, `t.A = s.B`, `t.A = c` (де `c` — константа) за допомогою логічних зв'язок `∧, ∨, ¬` та кванторів `∀, ∃`.

### Проблема небезпечних (Unsafe) виразів

Якщо домени атрибутів є нескінченними (наприклад, множина всіх дійсних чисел або довільних рядків `String`), деякі синтаксично коректні формули TRC дають нескінченний результат:

```
Q₁ = { t | ¬(Users(t)) }
```

Вираз `Q₁` вимагає повернути всі кортежі світу, які *не* належать відношенню `Users`. Оскільки домен `String × String` є нескінченним, оцінка `Q₁` є нездійсненною на комп'ютері з скінченною пам'яттю.

Аналогічно, вираз з альтернативою:

```
Q₂ = { t | Users(t) ∨ t.Age = 25 }
```

повертає нескінченну множину кортежів, у яких атрибут `Age` дорівнює `25`, навіть якщо значення інших атрибутів є довільними елементами з нескінченного домену.

### Означення безпечності (Domain Independence) та Теорема Трахтенброта

Запит `Q = { t | φ(t) }` називається **незалежним від домену** (domain-independent), якщо для будь-якої бази даних `DB` та будь-яких двох розширень домену `D ⊆ D'` значення результату запиту `Q(DB)` залишається тотожним: `Q_D(DB) = Q_{D'}(DB)`.

У 1950 році радянський математик Борис Трахтенброт довів фундаментальну теорему теоретичної комп'ютерної науки:

> **Теорема Трахтенброта.** Задача перевірки того, чи є довільна формула логіки першого порядку загальнозначущою на скінченних моделях, є алгоритмічно нерозв'язною (нерозв'язність перевірки незалежності від домену).

Через нерозв'язність загальної перевірки незалежності від домену Кодд увів синтаксично обмежений клас **безпечних формул** (Safe TRC), для яких незалежність від домену ґарантується синтаксичною структурою:

1. Для кожного кортежу `t`, що задовольняє `φ(t)`, усі його компоненти `t.Aᵢ` належать активному домену `Dom(φ, DB)`.
2. Для кожної підформули вигляду `∃ u (ψ(u))`, якщо `u` задовольняє `ψ`, то значення атрибутів `u` мусять належати `Dom(ψ, DB)`.
3. Для кожної підформули вигляду `∀ u (ψ(u))`, заперечення `¬ψ(u)` вимагає належності елементів `u` до `Dom(ψ, DB)`.

Додатково вимагається, щоб у диз'юнкціях `ψ₁ ∨ ψ₂` вільні змінні формули були обмежені активним доменом ув обох альтернативах, а в запереченнях `¬ψ` змінна заперечення попередньо обмежувалася додатним предикатом належності до відношення.

## Формулювання теореми Кодда

> **Теорема (Кодд, 1972).** Мова виразів реляційної алгебри (RA) та мова безпечного реляційного числення кортежів (Safe TRC) є еквівалентними за виразною силою:
>
> 1. Для кожного виразу реляційної алгебри `E` існує еквівалентна безпечна формула реляційного числення `φ_E` така, що `Result(E) = { t | φ_E(t) }`.
> 2. Для кожної безпечної формули реляційного числення `φ(t)` існує еквівалентний вираз реляційної алгебри `E_φ` такий, що `Result(E_φ) = { t | φ(t) }`.

## Частина 1: Індуктивний переклад RA → Safe TRC

Доведення першого напрямку здійснюється індукцією за структурою алгебраїчного виразу `E`.

### Базовий крок: Відношення-атоми
Якщо `E = R`, де `R` — відношення зі схемою `(A₁, ..., Aₖ)`, то відповідна формула TRC має вигляд:

```
φ_E(t) = R(t)
```

### Індукційний крок
Припустимо, для виразів `E₁` та `E₂` побудовано формули `φ₁(t)` та `φ₂(s)`.

1. **Селекція (`E = σ_φ(E₁)`):**
   ```
   φ_E(t) = φ₁(t) ∧ φ_pred(t)
   ```
   де `φ_pred(t)` — синтаксична конверсія предикату селекції. Оскільки `φ₁(t)` гарантує належність `t` до `Dom(E₁)`, підсумкова формула залишається безпечною.

2. **Проекція (`E = π_{A₁, ..., A☵}(E₁)`):**
   Нехай схема `E₁` дорівнює `{A₁, ..., A☵, B₁, ..., B☙}`. Формула створює екзистенційний квантор для відкинутих атрибутів:
   ```
   φ_E(t) = ∃ u (φ₁(u) ∧ t.A₁ = u.A₁ ∧ ... ∧ t.A☵ = u.A☵)
   ```

3. **Декартів добуток (`E = E₁ × E₂`):**
   ```
   φ_E(t) = ∃ u ∃ v (φ₁(u) ∧ φ₂(v) ∧ t[Schema(E₁)] = u ∧ t[Schema(E₂)] = v)
   ```

4. **Об'єднання (`E = E₁ ∪ E₂`):**
   ```
   φ_E(t) = φ₁(t) ∨ φ₂(t)
   ```

5. **Різниця (`E = E₁ \ E₂`):**
   ```
   φ_E(t) = φ₁(t) ∧ ¬φ₂(t)
   ```

Оскільки `E₁` та `E₂` є скінченними відношеннями, а оператори алгебри замкнені, усі згенеровані формули `φ_E` автоматично задовольняють вимоги безпечності.

## Частина 2: Алгоритм зниження Кодда (Safe TRC → RA)

Доведення зворотного напрямку (переклад Safe TRC у вираз алгебри) потребує побудови спеціального виразу алгебри для **Активного домену** `Dom_RA`, який формується як об'єднання проекцій усіх атрибутів усіх відношень бази даних та констант запиту:

```
Dom_RA = π_{A₁}(R₁) ∪ π_{A₂}(R₁) ∪ ... ∪ π_{Aₖ}(R☘) ∪ {c₁, ..., cₚ}
```

Активний домен гарантує, що будь-який універсум значень для оцінки формули логіки є скінченним і виражається засобами реляційної алгебри.

Алгоритм трансляції формули `φ` у вираз реляційної алгебри `E(φ)` працює знизу вгору за деревом формули:

1. **Атомарний предикат `R(t)`:**
   Транслюється безпосередньо у відношення `R`.

2. **Атомарне порівняння `t.A = c`:**
   Транслюється у селекцію над повним декартовим добутком активного домену:
   ```
   σ_{A = c}(Dom_RA × Dom_RA × ... × Dom_RA)
   ```

3. **Кон'юнкція `φ₁ ∧ φ₂`:**
   - Якщо `φ₁` та `φ₂` мають однакові вільні змінні, це перетинається оператором `E(φ₁) ∩ E(φ₂)`.
   - Якщо змінні різняться, застосовується природне з'єднання або декартів добуток `E(φ₁) ⋈ E(φ₂)`.

4. **Диз'юнкція `φ₁ ∨ φ₂`:**
   Оскільки формула є безпечною, обидва операнди зведені до або сумісних за схемою відношень, або підмножин активного домену. Трансляція виконає об'єднання:
   ```
   E(φ₁) ∪ E(φ₂)
   ```

5. **Заперечення `¬φ₁`:**
   Пряме заперечення зазвичай дає нескінченність, але для безпечної формули заперечення оцінюється виключно відносно активного домену `Dom_RA`:
   ```
   (Dom_RA × ... × Dom_RA) \ E(φ₁)
   ```

6. **Екзистенційний квантор `∃ u (φ₁(t, u))`:**
   Транслюється у проекцію, яка відкидає атрибути, відповідні змінній `u`:
   ```
   π_{Schema(t)}(E(φ₁))
   ```

7. **Квантор загальності `∀ u (φ₁(t, u))`:**
   За законами логіки першого порядку квантор загальності попередньо еквівалентно замінюється на квантор існування з подвійним запереченням:
   ```
   ∀ u (φ₁(t, u)) ≡ ¬ ∃ u (¬ φ₁(t, u))
   ```
   Після цієї заміни трансляція виконується через комбінацію проекцій та різниць відносно активного домену `Dom_RA` або через оператор ділення `E(φ₁) ÷ Dom_RA`.

### Конкретний приклад зниження Кодда

Розглянемо приклад трансляції формули з квантором загальності: «Знайти студентів, які склали всі іспити».
Формула TRC:
```
Q = { s | Student(s) ∧ ∀ e (Exam(e) ⇒ Passed(s, e)) }
```
Крок 1. Заміна імплікації `A ⇒ B ≡ ¬A ∨ B` та законів Де Моргана:
```
Q = { s | Student(s) ∧ ¬ ∃ e (Exam(e) ∧ ¬Passed(s, e)) }
```
Крок 2. Зниження підформул до реляційної алгебри:
- `E(Exam(e) ∧ ¬Passed(s, e)) = (Exam × π_{ID}(Student)) \ Passed`
- `E(∃ e (...)) = π_{StudentID}((Exam × π_{ID}(Student)) \ Passed)`
- `E(Q) = Student \ (π_{StudentID}((Exam × π_{ID}(Student)) \ Passed))`

Отриманий вираз реляційної алгебри є точним еквівалентом оператора ділення `Passed ÷ Exam`.

### Ігри Еренфойхта — Фрессе та неможливість вираження рекурсії

Для доведення того, що логіка першого порядку (і реляційна алгебра) **не може** виразити транзитивне замикання графа, використовуються **ігри Еренфойхта — Фрессе** (Ehrenfeucht-Fraïssé Games, EF-games).

EF-гра розгортається між двома гравцями (Новатором та Дублером) над двома реляційними структурами `A` та `B` за `m` раундів:
- Новатор обирає елемент в одній зі структур.
- Дублер мусить обрати елемент у другій структурі, намагаючись зберегти частковий ізоморфізм між обраними підструктурами.

Якщо Дублер має виграшну стратегію у `m`-раундовій грі на структурах `A` та `B`, то жодна формула логіки першого порядку з рангом кванторів, не більшим за `m`, не може відрізнити структуру `A` від `B`.

Для задачі зв'язності графа будуються два графи:
- Граф `A`: один простий цикл довжини `2^m`.
- Граф `B`: два незв'язані цикли довжини `2^{m-1}` кожен.

Дублер має виграшну стратегію у `m`-раундовій грі на цих графах. Звідси випливає, що жодна формула логіки першого порядку з рангом кванторів `m` не здатна відрізнити зв'язаний граф `A` від незв'язаного графа `B`. Оскільки ранг кванторів у формулі є фіксованим, логіка першого порядку і реляційна алгебра не можуть перевірити зв'язність графа довільного розміру.

## Математичне доведення еквівалентності TRC та DRC (Domain Relational Calculus)

Паралельно з численним кортежів (TRC), Кодд розробив **Числення доменів** (Domain Relational Calculus, DRC), де змінні позначають скалярні елементи доменів, а не цілі кортежі.

Запит у DRC має синтаксичну форму:

```
Q = { <x₁, x₂, ..., x☵> | φ(x₁, x₂, ..., x☵) }
```

де `xᵢ` — доменні змінні, а `φ` — формула першого порядку з предикатами належності `R(x₁, ..., x☵)`.

### Алгоритм двостороннього мапування TRC ⟺ DRC

1. **Напрямок TRC → DRC:**
   Кожна кортежна змінна `t` зі схемою `(A₁, ..., A☵)` замінюється векторною послідовністю доменних змінних `<x_t1, ..., x_tk>`. Предикат належності `R(t)` перетворюється на атомарний предикат `R(x_t1, ..., x_tk)`. Усі порівняння `t.Aᵢ = s.Aⱼ` транслюються у прямості рівності змінних `x_ti = y_sj`.

2. **Напрямок DRC → TRC:**
   Для кожної вибірки доменних змінних `<x₁, ..., x☵>` будується кортежна змінна `t` належності декартовому добутку активних доменів. Умови належності доменних змінних предикатам `R(x₁, ..., x☵)` замінюються на екзистенційні квантори кортежів: `∃ r (R(r) ∧ r.A₁ = x₁ ∧ ... ∧ r.A☵ = x☵)`.

Оскільки обидва перетворення є синтаксично замкненими і зберігають семантичну тотожність результату над скінченними базами даних, виразна сила TRC та DRC є строго однаковою:

```
Safe TRC ≡ Safe DRC ≡ Relational Algebra
```

## Семантика Тарського та моделювання скінченних структур

Семантичний фундамент реляційного числення Кодда будується на канонічному означенні істинності Альфреда Тарського (Tarski's Truth Definitions).

Для скінченної реляційної моделі `M = (Dom(DB), R₁^M, ..., R☵^M)` оцінка формули `φ` під наданням змінним значень `v` визначається рекурсивно:
- `M, v ⊨ R(t)` тоді і тільки тоді, коли кортеж `v(t)` належить множині `R^M`.
- `M, v ⊨ φ₁ ∧ φ₂` тоді і тільки тоді, коли `M, v ⊨ φ₁` та `M, v ⊨ φ₂`.
- `M, v ⊨ ¬φ₁` тоді і тільки тоді, коли не справджується `M, v ⊨ φ₁`.
- `M, v ⊨ ∃ u (φ₁(u))` тоді і тільки тоді, коли існує значення `c ∈ Dom(DB)` таке, що `M, v[u ↦ c] ⊨ φ₁(u)`.

Завдяки скінченності `Dom(DB)` перевірка здійсненності будь-якого квантора `∃` зводиться до скінченної перевірки елементів, що гарантує завершуваність обчислень та належність запиту до класу `LOGSPACE`.

## Теорема Фагіна та зв'язок із класом складності NP

У 1974 році Рональд Фагін (Ronald Fagin) розширив дескриптивну складність, показавши межі виразності логіки другого порядку (Second-Order Logic, SO).

> **Теорема Фагіна (1974).** Клас мов, які виражаються екзистенційною логікою другого порядку (Existential Second-Order Logic, ESO або Σ¹₁), напередодні збігається з класом складності **NP** (недетермінований поліноміальний час).

У реляційній моделі це означає, що якщо розширити реляційне числення Кодда кванторами існування за самими відношеннями (таблицями), виразна сила мови запитів тотожно піднімається від `AC⁰` / `LOGSPACE` до класу **NP-повних задач** (таких як пошук Гамільтонового циклу або розфарбування графа).

### Узагальнена теорема про логічні розширення

Розглянемо підсумок ієрархії виразності логічних мов запитів від реляційної алгебри Кодда до повної логіки другого порядку:
- **Логіка першого порядку (FO / RA / Safe TRC):** Клас складності `AC⁰` / `LOGSPACE`. Не може обчислити парність кількості елементів та транзитивне замикання.
- **Логіка першого порядку з оператором найменшої нерухомої точки (FO + LFP / Datalog):** Клас складності **P** (поліноміальний час над впорядкованими структурами). Обчислює транзитивне замикання та досяжність у графах.
- **Екзистенційна логіка другого порядку (ESO / Σ¹₁):** Клас складності **NP** (за теоремою Фагіна). Обчислює NP-повні задачі комбінаторної оптимізації.
- **Повна логіка другого порядку (Full SO):** Поліноміальна ієрархія складності **PH**.

Ця математична ієрархія показує строго розрахований баланс Кодда: реляційна алгебра свідомо обмежена першим рівнем (`AC⁰` / `LOGSPACE`), щоб гарантувати миттєве обчислення запитів на паралельних комп'ютерних архітектурах.

Важливо зауважити, що межа між `LOGSPACE` та `P` у теорії реляційних баз даних є критичною. Додавання оператора розв'язання нерухомої точки дозволяє будувати процедурні цикли типу `WHILE`, що робить мову запитів виразнішою, але піднімає обчислювальні витрати з чисто паралельного класу `AC⁰` до послідовного за своєю природою класу `P`.

Окрім цього, в рамках дескриптивної складності розглядається параметрична складність запитів: **Data Complexity** (складність при фіксованому запиті `Q` і зростанні бази даних `N`) та **Expression Complexity** (складність при фіксованій базі даних і зростанні розміру виразу запиту `|Q|`). Для реляційної алгебри Data Complexity становить `AC⁰` / `LOGSPACE`, тоді як Expression Complexity є `PSPACE`-повною через можливість побудови глибоко вкладених декартових добутків та кванторів.

Нарешті, теорема Кодда забезпечила теоретичний фундамент для всього напрямку оптимізації запитів: можливість синтаксично еквівалентного переведення з декларативного рівня (TRC) на процедурний рівень (RA) і далі на рівень фізичного плану виконання є основою архітектури будь-якої сучасної реляційної СУБД.

## Наслідок: Обчислювальна складність та Реляційна повнота

З теореми Кодда випливають три фундаментальні теоретико-складносні наслідки:

1. **Реляційна повнота (Relational Completeness):** Будь-яка мова запитів до баз даних (зокрема SQL чи QUEL) називається реляційно повною, якщо вона має виразну силу, не меншу за реляційну алгебру або безпечне реляційне числення.
2. **Складність оцінки запиту (Data Complexity):** Оцінка виразу реляційної алгебри над фіксованим запитом `Q` при зростанні розміру бази даних `N = |DB|` належить до класу складності `LOGSPACE` за пам'яттю та паралельного класу `AC⁰` за схемною складністю.
3. **Обмеження логіки першого порядку:** Теорема Кодда встановлює жорстку верхню межу виразності: реляційна алгебра **не здатна** виразити операцію транзитивного замикання (наприклад, перевірити зв'язність графа або знайти всі ієрархічні підпорядкування довільної глибини). Для вираження транзитивного замикання необхідне розширення алгебри оператором найменшої нерухомої точки (Least Fixed Point, LFP), що приводить до логіки Datalog та конструкцій `WITH RECURSIVE` у сучасному SQL.
