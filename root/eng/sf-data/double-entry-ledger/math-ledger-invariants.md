# 🧮 Математичні інваріанти бухгалтерського обліку

Бухгалтерський облік подвійного запису є строго замкненою дискретною алгебраїчною системою над кільцем цілих чисел `ℤ`. Вона підпорядковується фундаментальним законам збереження, подібним до законів збереження електричного заряду або першого закону Кірхгофа в теорії електричних кіл. Кожна фінансова транзакція є лінійним оператором перерозподілу вартості, який не створює нових грошових одиниць і не знищує наявні, а лише переносить їх між визначеними вузлами графа облікових рахунків.

## Алгебраїчний простір станів рахунків

Розглянемо систему обліку, яка складається з `n` окремих ідентифікованих рахунків. Стан фінансової системи в дискретний момент часу `t` повністю описується вектором залишків `b(t) ∈ ℤⁿ`:

```
b(t) = [b₁(t), b₂(t), ..., bₙ(t)]ᵀ
```

Кожна компонента вектора `bᵢ(t)` задає поточний баланс рахунку `i` в неподільних дискретних одиницях валюти (наприклад, у копійках або центах).

Усі `n` рахунків класифікуються на п'ять неперетинних підмножин відповідно до їхньої базової економічної та правової природи:
1. `A` — Активи (*Assets*): реальні ресурси, якими володіє суб'єкт (готівка, банківські залишки, дебіторська заборгованість).
2. `E` — Витрати (*Expenses*): зменшення економічних ресурсів у процесі поточної діяльності.
3. `L` — Зобов'язання (*Liabilities*): фінансові борги перед зовнішніми контрагентами або користувачами системи.
4. `Q` — Власний капітал (*Equity*): чисті активи, що належать власникам або засновникам бізнесу.
5. `R` — Доходи (*Revenue*): валові економічні надходження від реалізації товарів або послуг.

Фундаментальне динамічне рівняння бухгалтерського балансу формулюється як рівність між сумою активних елементів та сумою пасивних елементів:

```
∑_{i ∈ A} bᵢ(t) + ∑_{j ∈ E} bⱼ(t) = ∑_{k ∈ L} bₖ(t) + ∑_{m ∈ Q} bₘ(t) + ∑_{p ∈ R} bₚ(t)
```

## Векторне представлення транзакції та інваріант нульової суми

Транзакція `Tⱼ` — це атомарна операція зміни фінансового стану, яка переводить систему зі стану `b(t)` у новий стан `b(t+1)`. Транзакція математично задається вектором змін `Δbⱼ ∈ ℤⁿ`:

```
Δbⱼ = [δ₁, δ₂, ..., δₙ]ᵀ
```

де `δᵢ` позначає величину дебетової (якщо `δᵢ > 0`) або кредитової (якщо `δᵢ < 0`) проводки по рахунку `i`. Якщо певний рахунок `k` не бере участі в поточній транзакції, відповідний елемент вектора строго дорівнює нулю: `δₖ = 0`.

Головний інваріант подвійного запису стверджує, що будь-яка допустима транзакція повинна мати строго нульову суму всіх своїх складових компонентів:

```
1ᵀ · Δbⱼ = 0
```

де `1 = [1, 1, ..., 1]ᵀ` — одиничний вектор розмірності `n`.

Розгорнемо це скалярне рівняння у вигляді покомпонентної суми:

```
δ₁ + δ₂ + ... + δₙ = 0      [інваріант консервативності транзакції]
```

Для простої бінарної транзакції (*simple posting*), яка переказує суму `M` з рахунку `u` на рахунок `v`, вектор змін має рівно два ненульові елементи:

```
δ_u = -M
δ_v = +M
δ_k = 0 для всіх k ∉ {u, v}

-M + (+M) = 0
```

Для складнішої розгалуженої транзакції (*split transaction*), наприклад, оплати замовлення клієнтом на суму 1000 грн з утриманням еквайрингової комісії 25 грн і зарахуванням чистої виручки торговцю 975 грн, покомпонентний баланс виглядає так:

```
δ_customer    = -1000
δ_merchant    = +975
δ_fee_revenue = +25

-1000 + 975 + 25
= -1000 + 1000              [асоціативність додавання в кільці ℤ]
= 0                         [інваріант нульової суми виконано]
```

## Теорема про збереження глобального інваріанта системи

Сформулюємо та доведемо теорему про збереження сумарного балансу замкненої облікової системи при довільній скінченній кількості послідовних транзакцій.

**Теорема.** Якщо в початковий момент часу `t = 0` система перебуває в збалансованому стані `1ᵀ · b(0) = 0`, то після виконання будь-якої скінченної послідовності з `m` валідних транзакцій `Δb₁, Δb₂, ..., Δbₘ` сумарний баланс системи залишається строго рівним нулю: `1ᵀ · b(m) = 0`.

**Доведення.**
Стан системи після `m` транзакцій визначається лінійною суперпозицією початкового вектора та всіх векторів змін:

```
b(m) = b(0) + ∑_{j=1}^m Δbⱼ
```

Помножимо обидві частини рівняння зліва на транспонований одиничний вектор `1ᵀ`:

```
1ᵀ · b(m)
= 1ᵀ · (b(0) + ∑_{j=1}^m Δbⱼ)
= 1ᵀ · b(0) + 1ᵀ · (∑_{j=1}^m Δbⱼ)       [дистрибутивність множення матриць]
= 0 + ∑_{j=1}^m (1ᵀ · Δbⱼ)               [лінійність оператора підсумовування]
= ∑_{j=1}^m 0                             [оскільки 1ᵀ · Δbⱼ = 0 за означенням інваріанта]
= 0
```

Теорему доведено. Цей математичний результат гарантує, що в коректній системі подвійного запису ніякі внутрішні перекази, перерозподіли комісій чи розщеплення платежів не здатні призвести до несанкціонованої емісії вартості або безповоротного зникнення грошових одиниць.

## Мультивалютні інваріанти та рахунки курсового клірингу

Коли фінансова система обслуговує операції в кількох різних валютах (наприклад, UAH, USD та EUR), пряме додавання сум у різних валютах втрачає математичний зміст, оскільки валюти не утворюють єдиного лінійного простору без урахування обмінного курсу.

Для збереження математичної строгості простір рахунків розшаровується на незалежні моновалютні підпростори:

```
b(t) = [b_UAH(t), b_USD(t), b_EUR(t)]
```

Для кожної окремої валюти `c` інваріант нульової суми повинен виконуватися автономно:

```
1ᵀ · Δb_c = 0 для кожної валюти c ∈ {UAH, USD, EUR}
```

Обмін валют (наприклад, купівля 100 USD за 4100 UAH) моделюється не прямим перехресним записом, а через введення спеціального системного рахунку курсового клірингу (*FX Clearing / Currency Exchange Account*). Транзакція розбивається на дві строго ізольовані моновалютні частини:

```
Частина 1 (простір UAH):
  Дебет:  Рахунок клієнта (UAH)          -4100
  Кредит: Рахунок клірингу валюти (UAH)  +4100
  Сума UAH: -4100 + 4100 = 0

Частина 2 (простір USD):
  Дебет:  Рахунок клірингу валюти (USD)  -100
  Кредит: Рахунок клієнта (USD)          +100
  Сума USD: -100 + 100 = 0
```

У результаті інваріант нульової суми зберігається в кожній окремій валюті без порушення загальної консервативності системи.

## Графова інтерпретація та мережеві потоки

Систему обліку можна формалізувати як орієнтований мультиграф `G = (V, E)`, де:
- Множина вершин `V = {v₁, v₂, ..., vₙ}` представляє облікові рахунки.
- Множина орієнтованих ребер `E` представляє окремі проводки перенесення вартості. Кожне ребро `e = (u, v)` має додатну вагу `w(e) > 0`, що позначає переказ суми `w(e)` від рахунку `u` до рахунку `v`.

У термінах теорії мережевих потоків кожна транзакція є консервативною циркуляцією потоку. Для кожної вершини `v` транзакції виконується перший закон Кірхгофа: сума вхідних грошових потоків точно дорівнює сумі вихідних потоків:

```
∑_{e ∈ In(v)} w(e) = ∑_{e ∈ Out(v)} w(e)
```

Матриця інцидентності транзакцій `M ∈ ℤⁿˣᵐ` (де `n` — кількість рахунків, `m` — кількість проводок) має властивість повної унімодулярності: кожен її стовпчик містить рівно одне значення `+1` (дебет), рівно одне значення `-1` (кредит), а всі інші елементи дорівнюють нулю. Це забезпечує стійкість до накопичення чисельних аномалій і однозначність розв'язків балансових рівнянь.
