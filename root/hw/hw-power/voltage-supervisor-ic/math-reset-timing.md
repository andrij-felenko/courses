# 🧮 Розрахунок порогів, часових затримок та вікон сторожового таймера

Проєктування вузла супервізора напруги спирається на суворий розрахунок найгіршого випадку (worst-case analysis). Неточний розрахунок порогової напруги призводить або до раптових хибних перезавантажень під час пікових навантажень на шину, або до пропуску аварійного зниження живлення нижче межі працездатності мікросхем пам'яті.

### 1. Бюджет похибок та вибір порогової напруги

Шина живлення ніколи не має строго постійної напруги: вона коливається через похибку стабілізатора, температурний дрейф та динамічні пульсації струму навантаження. З іншого боку, сам поріг супервізора має власний технологічний розкид.

```
V_nom (3.30 В) ───────────────┬─ Номінальна напруга шини
                              │
V_sup_max (3.12 В) ───────────┼─ Максимальний поріг супервізора (з урахуванням +2.5% похибки)
                              │  [ Зона гарантованої відсутності хибних скидань ]
V_sup_nom (3.04 В) ───────────┼─ Номінальний поріг супервізора
                              │
V_sup_min (2.96 В) ───────────┼─ Мінімальний поріг супервізора (з урахуванням -2.5% похибки)
                              │  [ Зона гарантованого скидання до відмови мікроконтролера ]
V_mcu_min (2.70 В) ───────────┴─ Мінімальна робоча напруга процесора за документацією
```

Щоб система працювала бездоганно, повинні одночасно виконуватися дві незалежні умови:

1. **Умова відсутності хибних перезавантажень:**
   Мінімальна напруга живлення за найгірших умов (найбільше просідання та пульсація) мусить залишатися строго вищою за максимально можливий поріг супервізора `V_sup_max`:

```
V_sup_max < V_nom · (1 − tol_reg) − V_ripple
```

2. **Умова надійного захисту процесора:**
   Мінімально можливий поріг спрацьовування супервізора `V_sup_min` мусить бути строго вищим за критичну напругу відмови логіки мікроконтролера `V_mcu_min`:

```
V_sup_min > V_mcu_min
```

#### Чутливість порогової напруги до розкиду дільника

Якщо супервізор має регульований вхід моніторингу `SENSE` із зовнішнім дільником на резисторах `R1` і `R2`, поріг спрацьовування визначається рівністю напруги на середній точці дільника внутрішній опорній напрузі `Vref`:

```
V_IT- = Vref · (1 + R1 / R2)
```

Повна похибка встановлення порогу залежить від похибки опори `Vref` та похибок опорів резисторів `R1` і `R2`. Знайдемо частинні похідні функції `V_IT-`:

```
∂V_IT- / ∂Vref = 1 + R1 / R2
∂V_IT- / ∂R1 = Vref / R2
∂V_IT- / ∂R2 = −Vref · R1 / (R2²)
```

Відносна похибка в лінійному наближенні через коефіцієнти чутливості набуває вигляду:

```
(ΔV_IT- / V_IT-)
= (ΔVref / Vref) + (R1 / (R1 + R2)) · (ΔR1 / R1) − (R1 / (R1 + R2)) · (ΔR2 / R2)
```

Коефіцієнт при похибці опорів `k_sens = R1 / (R1 + R2)`. Якщо `R1 = 150 кОм`, а `R2 = 100 кОм` (для перетворення 3.0 В у 1.2 В), коефіцієнт чутливості становить `150 / 250 = 0.60`.

За методом найгіршого випадку (Extreme Value Analysis, EVA), коли всі похибки складаються в найбільш несприятливий бік:

```
tol_total_EVA = tol_Vref + k_sens · (tol_R1 + tol_R2) + tol_temp
```

За статистичним методом середньоквадратичного підсумовування (Root-Sum-Square, RSS) для незалежних випадкових величин:

```
tol_total_RSS = √( (tol_Vref)² + (k_sens · tol_R1)² + (k_sens · tol_R2)² + (tol_temp)² )
```

Якщо `tol_Vref = 1.0%`, а резистори мають точність `tol_R = 0.5%` (прецизійні тонкоплівкові резистори) з температурним коефіцієнтом `TCR = 25 ppm/°C` (дає `0.25%` дрейфу на інтервалі 100 °C):

```
tol_total_RSS
= √( 1.0² + (0.6·0.5)² + (0.6·0.5)² + 0.25² ) [підстановка значень]
= √( 1.0 + 0.09 + 0.09 + 0.0625 )             [піднесення до квадрата]
= √( 1.2425 )                                 [сумування дисперсій]
= 1.115%                                      [статистична похибка порогу]
```

#### Числовий розрахунок порогу для 3.3 В системи

Вихідні дані проєкту:
- Номінальна напруга шини: `V_nom = 3.30 В`.
- Похибка вихідної напруги LDO стабілізатора: `tol_reg = ±2.0%` (`±0.066 В`).
- Амплітуда високочастотних пульсацій та комутаційного шуму: `V_ripple = 0.050 В`.
- Мінімальна робоча напруга мікроконтролера за паспортом: `V_mcu_min = 2.70 В`.
- Повний розкид супервізора: `tol_sup = ±2.5%`.

Обчислимо граничні межі коридору допустимих порогів:

```
V_rail_min
= V_nom · (1 − tol_reg) − V_ripple    [найгірше просідання шини]
= 3.30 · (1 − 0.02) − 0.050           [підстановка параметрів]
= 3.30 · 0.98 − 0.050                 [обчислення відсотка]
= 3.234 − 0.050                       [віднімання пульсацій]
= 3.184 В                             [гарантоване дно робочої шини]
```

Звідси знаходимо верхню межу для номінального порогу супервізора `V_sup_nom`:

```
V_sup_nom_max
= V_rail_min / (1 + tol_sup)          [поділ на максимальний відхил]
= 3.184 / (1 + 0.025)                 [підстановка похибки 2.5%]
= 3.184 / 1.025                       [спрощення знаменника]
= 3.106 В                             [верхня допустима межа]
```

Нижня межа для номінального порогу визначається мінімумом процесора:

```
V_sup_nom_min
= V_mcu_min / (1 − tol_sup)           [поділ на мінімальний відхил]
= 2.70 / (1 − 0.025)                  [підстановка похибки 2.5%]
= 2.70 / 0.975                        [спрощення знаменника]
= 2.769 В                             [нижня допустима межа]
```

**Висновки вибору:** Номінальний поріг супервізора мусить лежати у строгому діапазоні `2.77 В < V_sup_nom < 3.10 В`. Стандартний заводський поріг **2.93 В** або **3.08 В** ідеально вписується в цей коридор, гарантуючи запас 104 мВ зверху (від хибних спрацьовувань) та 157 мВ знизу (до відмови процесора).

### 2. Розрахунок ємності конденсатора затримки скидання (CT)

У супервізорах із регульованим часом затримки пуску `t_rst` (Power-On Reset Delay) внутрішній генератор струму `I_CT` заряджає зовнішній конденсатор `C_T` від 0 В до внутрішнього опорного порогу перемикання компаратора затримки `V_TH_CT`.

Базове диференціальне рівняння заряду конденсатора постійним струмом:

```
I_CT = C_T · (dV / dt)
```

Інтегруючи на проміжку часу від `t = 0` (початок відліку після стабілізації напруги вище порогу) до `t = t_rst` (момент досягнення напруги `V_TH_CT`):

```
t_rst
= ∫ (C_T / I_CT) dV                   [інтеграл за напругою від 0 до V_TH_CT]
= (C_T / I_CT) · ∫ dV                 [винесення констант C_T та I_CT]
= (C_T · V_TH_CT) / I_CT              [результат інтегрування]
```

Більшість виробників наводять лінеаризовану формулу з коефіцієнтом пропорційності `K` та внутрішньою апаратною затримкою лічильника `t_internal`:

```
t_rst = C_T · K + t_internal
```

#### Вплив струму витоку конденсатора при високій температурі

Реальний керамічний конденсатор має власний опір ізоляції `R_ins`, через який протікає струм витоку `I_leak`. При високих температурах (+125 °C) опір ізоляції падає на кілька порядків. Рівняння заряду набуває вигляду:

```
C_T · (dV / dt) = I_CT − (V(t) / R_ins)
```

Розв'язок цього лінійного диференціального рівняння:

```
V(t) = I_CT · R_ins · (1 − e^(−t / (R_ins · C_T)))
```

Щоб конденсатор гарантовано зарядився до порогової напруги `V_TH_CT`, асимптотична напруга `I_CT · R_ins` повинна суттєво перевищувати `V_TH_CT` (щонайменше у 5–10 разів). Це накладає фундаментальну інженерну вимогу: **струм заряду `I_CT` мусить бути щонайменше на два порядки вищим за максимальний струм витоку конденсатора**. Для таймерних кіл слід застосовувати виключно керамічні конденсатори діелектричної групи **C0G (NP0)** або високоякісні **X7R**; застосування дешевих сегнетоелектричних конденсаторів групи Y5V або Z5U категорично заборонено, оскільки їхня ємність при зміні температури падає на 70–80%, скорочуючи затримку скидання до неприпустимо малих значень.

#### Приклад числового розрахунку

Для типового супервізора з параметрами:
- Струм заряду: `I_CT = 2.0 мкА` (`2.0·10⁻⁶ А`).
- Поріг компаратора затримки: `V_TH_CT = 1.20 В`.
- Потрібна системна затримка стабілізації кварцового резонатора: `t_rst = 150 мс` (`0.150 с`).

Знаходимо необхідну ємність конденсатора `C_T`:

```
C_T
= (t_rst · I_CT) / V_TH_CT            [вираження ємності з базової формули]
= (0.150 · 2.0·10⁻⁶) / 1.20           [підстановка числових значень]
= (3.0·10⁻⁷) / 1.20                   [множення в чисельнику]
= 2.5·10⁻⁷ Ф                          [ділення]
= 250 нФ = 0.25 мкФ                   [переведення в стандартні одиниці]
```

Обираємо найближчий стандартний номінал із ряду E24: **270 нФ** (або паралельно 220 нФ + 33 нФ), що дає фактичну затримку:

```
t_rst_fact
= (270·10⁻⁹ · 1.20) / (2.0·10⁻⁶)      [підстановка номіналу 270 нФ]
= (3.24·10⁻⁷) / (2.0·10⁻⁶)            [обчислення чисельника]
= 0.162 с = 162 мс                    [фактична затримка пуску]
```

### 3. Часовий бюджет віконного сторожового таймера (WWDT)

Віконний сторожовий таймер вимагає скидання (імпульсу WDI) строго всередині інтервалу `t_WD_min ≤ t_service ≤ t_WD_max`.

```
t = 0 ───────────────────────────── Початок циклу (останній імпульс WDI)
  │
  │  [ Зачинене вікно: скидання веде до RESET ]
  │
t_WD_min (30 мс) ────────────────── Нижня межа дозволеного вікна
  │
  │  [ ВІДЧИНЕНЕ ВІКНО: безпечне скидання ] ◄── Точка скидання t_service (55 мс)
  │
t_WD_max (80 мс) ────────────────── Верхня межа (таймаут: веде до RESET)
```

При розрахунку періоду виклику сервісної функції прошивки `t_service` необхідно врахувати три незалежні джерела похибок часу:
1. **Розкид внутрішнього RC-генератора супервізора:** технологічна похибка виробництва та температурний коефіцієнт вбудованого генератора становлять `tol_wdt = ±15%`.
2. **Неточність тактового генератора процесора:** нестабільність внутрішнього RC-генератора мікроконтролера (HSI) або дрейф кварцу (HSE) разом із температурним дрейфом дає `tol_mcu = ±2%`.
3. **Джиттер планувальника задач реального часу (RTOS Scheduling Jitter):** затримка диспетчеризації через виконання переривань та блокування критичних секцій становить `t_jitter = ±5 мс`.

Граничні параметри вікна супервізора з документації:
- Номінальне зачинене вікно: `t_win_nom = 40 мс` (мінімум `t_WD_min_worst = 40 · 0.85 = 34 мс`, максимум `t_WD_min_max = 40 · 1.15 = 46 мс`).
- Номінальний таймаут: `t_to_nom = 100 мс` (мінімум `t_WD_max_min = 100 · 0.85 = 85 мс`, максимум `t_WD_max_max = 100 · 1.15 = 115 мс`).

Безпечний період виклику сервісної функції розраховується як геометрична або арифметична середина відкритого інтервалу з урахуванням найгірших умов розкиду:

```
t_service_nom
= (t_WD_min_max + t_WD_max_min) / 2   [центрування всередині гірших меж]
= (40 · 1.15 + 100 · 0.85) / 2        [підстановка найгірших умов відхилення]
= (46.0 + 85.0) / 2                   [обчислення сум]
= 131.0 / 2                           [ділення навпіл]
= 65.5 мс                             [оптимальний період обслуговування]
```

Перевіримо крайні точки з урахуванням джиттера `±5 мс` та дрейфу процесора `±2%`:

```
t_service_earliest
= 65.5 · (1 − 0.02) − 5.0             [найраніший можливий виклик]
= 65.5 · 0.98 − 5.0                   [множення]
= 64.19 − 5.0                         [віднімання джиттера]
= 59.19 мс > 46.0 мс                  [строго вище верхньої межі зачиненого вікна: OK]

t_service_latest
= 65.5 · (1 + 0.02) + 5.0             [найпізніший можливий виклик]
= 65.5 · 1.02 + 5.0                   [множення]
= 66.81 + 5.0                         [додавання джиттера]
= 71.81 мс < 85.0 мс                  [строго нижче нижньої межі таймауту: OK]
```

Коефіцієнт запасу надійності часового вікна:

```
k_margin_early = (59.19 − 46.0) / 46.0 = 13.19 / 46.0 ≈ +28.7%
k_margin_late = (85.0 − 71.81) / 85.0 = 13.19 / 85.0 ≈ +15.5%
```

Обидва запаси перевищують інженерну норму 10%, що гарантує повну відсутність хибних спрацьовувань сторожа при будь-яких режимах роботи операційної системи.

### 4. Час наростання лінії Open-Drain та енергоспоживання

При відпусканні сигналу скидання лінія `/RESET` заряджається через резистор підтяжки `R_PU` до напруги логічної одиниці входу процесора `V_IH = 0.7 · VDD`.

Диференціальне рівняння RC-кола заряду ємності шини:

```
V(t) = VDD · (1 − e^(−t / (R_PU · C_bus)))
```

Знаходимо час наростання `t_rise` до рівня `0.7 · VDD`:

```
0.7 · VDD = VDD · (1 − e^(−t_rise / (R_PU · C_bus)))
1 − 0.7 = e^(−t_rise / (R_PU · C_bus)) [скорочення VDD та перенесення]
0.3 = e^(−t_rise / (R_PU · C_bus))      [обчислення різниці]
ln(0.3) = −t_rise / (R_PU · C_bus)      [логарифмування обох частин]
−1.204 = −t_rise / (R_PU · C_bus)       [наближене значення натурального логарифма]
t_rise ≈ 1.204 · R_PU · C_bus           [вираження часу наростання]
```

#### Приклад розрахунку швидкодії та споживання

- Резистор підтяжки: `R_PU = 10 кОм` (`10⁴ Ом`).
- Сумарна паразитна ємність лінії (доріжки плати + вхідна ємність виводів MCU та зневаджувача): `C_bus = 30 пФ` (`30·10⁻¹² Ф`).

```
t_rise
= 1.204 · 10⁴ · 30·10⁻¹²              [підстановка опору та ємності]
= 1.204 · 3.0·10⁻⁷                    [перемноження степенів]
= 3.61·10⁻⁷ с = 361 нс                [час наростання логічної одиниці]
```

Час 361 нс є абсолютно безпечним, оскільки вхідний тригер Шмітта мікроконтролера гарантовано перемикається без брязкоту при швидкостях наростання до сотень мікросекунд.

Струм споживання при утриманні лінії `/RESET` у низькому стані (під час пуску або аварії):

```
I_reset = VDD / R_PU = 3.3 В / 10 кОм = 0.33 мА = 330 мкА
```

У нормальному режимі роботи (коли `/RESET = 1`), струм через відкритий стік не тече, і споживання визначається виключно власним струмом спокою супервізора (quiescent current) `I_Q ≈ 150–500 нА`, що критично важливо для збереження заряду батареї в автономних пристроях.

### 5. Динамічна характеристика придушення викидів (Glitch Immunity)

Вхідний аналоговий фільтр компаратора супервізора реалізує частотно-залежну характеристику чутливості до імпульсних просідань напруги. Якщо напруга живлення короткочасно просідає нижче порогу `V_IT-` на величину перевищення порогу `ΔV_overdrive = V_IT- − V_min`, час реакції компаратора визначається інтегралом площі імпульсу просідання (добутком вольт-секунд):

```
∫ (V_IT- − V(t)) dt ≥ K_glitch
```

де `K_glitch` — конструктивна константа фільтра (типово 15–50 В·мкс).

Для прямокутного імпульсу просідання глибиною `ΔV_overdrive` та тривалістю `t_pulse`:

```
ΔV_overdrive · t_pulse ≥ K_glitch
⟹ t_crit = K_glitch / ΔV_overdrive
```

Якщо `K_glitch = 25 В·мкс`:
- При дрібному просіданні `ΔV_overdrive = 100 мВ` (`0.10 В`) критична тривалість становить:

```
t_crit_100mV
= 25 / 0.10                           [ділення константи на глибину]
= 250 мкс                             [час фільтрації дрібного просідання]
```

- При глибокому аварійному просіданні `ΔV_overdrive = 1.5 В`:

```
t_crit_1500mV
= 25 / 1.50                           [ділення константи на глибину]
= 16.7 мкс                            [швидка реакція на тяжку аварію]
```

Ця гіперболічна залежність є оптимальною з точки зору фізики: вона забезпечує абсолютну нечутливість до високочастотних комутаційних шумів без втрати швидкодії при реальній втраті живлення.

### 6. Тепловий шум Джонсона-Найквіста у високоомних дільниках

Для досягнення ультранизького споживання струму `I_Q < 1 мкА` резистори дільника `R1` і `R2` обирають великих номіналів (наприклад, `R1 = 1.8 МОм`, `R2 = 1.2 МОм`). Еквівалентний опір дільника для змінного струму:

```
R_eq = (R1 · R2) / (R1 + R2) = (1.8 · 1.2) / (1.8 + 1.2) = 2.16 / 3.0 = 0.72 МОм = 720 кОм
```

Середньоквадратична напруга теплового шуму Джонсона-Найквіста в смузі частот компаратора `Δf = 100 кГц` при температурі `T = 300 К` (`k_B = 1.38·10⁻²³ Дж/К`):

```
v_noise_RMS
= √( 4 · k_B · T · R_eq · Δf )        [формула Джонсона-Найквіста]
= √( 4 · 1.38·10⁻²³ · 300 · 720·10³ · 100·10³ ) [підстановка констант]
= √( 1.656·10⁻²⁰ · 7.2·10¹⁰ )         [перемноження множників]
= √( 1.192·10⁻⁹ )                     [обчислення підкореневого виразу]
= 3.45·10⁻⁵ В = 34.5 мкВ              [середньоквадратичний шум]
```

Пікова амплітуда шуму з коефіцієнтом пік-фактора 6 (гарантія 99.7% за розподілом Гаусса) становить `v_peak ≈ 6 · 34.5 мкВ ≈ 207 мкВ`. Оскільки вбудований гістерезис супервізора становить `V_hys = 20–100 мВ`, відношення сигнал/шум перевищує:

```
SNR = 20 мВ / 0.207 мВ ≈ 96.6 (або 39.7 дБ)
```

Це доводить, що навіть при використанні мегаомних резисторів тепловий шум не здатен спричинити хибне спрацьовування компаратора, підтверджуючи високу надійність низькоспоживаючих мікросхем.

### 7. Температурна модель джерела Bandgap та метод коробки

Опорна напруга забороненої зони кремнію `V_bg(T)` описується фундаментальним нелінійним рівнянням Відлара-Курека:

```
V_bg(T) = V_g0 − (V_g0 − V_be(T0)) · (T / T0) + (k_B · T / q) · ln(N) − (γ − α) · (k_B · T / q) · ln(T / T0)
```

де:
- `V_g0 ≈ 1.205 В` — напруга ширини забороненої зони кремнію при абсолютному нулі температур;
- `V_be(T0)` — напруга база-емітер при калібрувальній кімнатній температурі `T0 = 300 К`;
- `N` — співвідношення площ емітерів біполярних транзисторів;
- `γ` — температурний показник рухливості носіїв заряду (типово 3.2);
- `α` — порядок залежності струму від температури.

Перший доданок лінійної термокомпенсації скасовує основний нахил, проте логарифмічний нелінійний член `(γ − α) · T · ln(T / T0)` створює характерний параболічний прогин характеристики (Curvature).

Для кількісної оцінки стабільності в документації застосовують стандартний **метод коробки (Box Method)**:

```
TC_box = ( (V_bg_max − V_bg_min) / (V_bg_nom · (T_max − T_min)) ) · 10⁶ ppm/°C
```

Якщо в діапазоні від -40 °C до +125 °C (`ΔT = 165 °C`) максимальна напруга становить `1.203 В`, а мінімальна — `1.198 В`:

```
TC_box
= ( (1.203 − 1.198) / (1.200 · 165) ) · 10⁶ [підстановка значень]
= ( 0.005 / 198.0 ) · 10⁶                    [обчислення чисельника і знаменника]
= 2.525·10⁻⁵ · 10⁶                           [ділення]
= 25.25 ppm/°C                               [температурний коефіцієнт дрейфу]
```

Це свідчить про високу термічну стабільність, оскільки за перепаду температури на 50 °C опорна напруга зміститься лише на `1.200 · 25.25·10⁻⁶ · 50 ≈ 1.5 мВ` (0.125%), що значно менше вбудованого гістерезису компаратора.

### 8. Розрахунок фільтра входу ручного скидання (/MR)

Вхід `/MR` має внутрішнє джерело струму підтяжки `I_MR_PU` (типово 5–20 мкА) до `VDD`. Під час натискання кнопки лінія розряджається на землю. Щоб захистити вхід від брязкоту контактів (Bounce) та високочастотних завад, паралельно кнопці встановлюють зовнішній конденсатор `C_MR` (1–10 нФ).

Час розряду лінії від `VDD` до нижнього порогу перемикання внутрішнього тригера Шмітта `V_IL_MR ≈ 0.3 · VDD`:

```
t_discharge = C_MR · R_button_wire · ln( VDD / (0.3 · VDD) ) = C_MR · R_button_wire · ln(3.33) ≈ 1.20 · C_MR · R_button_wire
```

Час відновлення (заряду) лінії після відпускання кнопки до верхнього порогу `V_IH_MR ≈ 0.7 · VDD` під дією внутрішнього струму `I_MR_PU`:

```
t_recovery = (C_MR · (0.7 · VDD)) / I_MR_PU
```

Якщо `C_MR = 10 нФ` (`10·10⁻⁹ Ф`), `VDD = 3.3 В`, а `I_MR_PU = 10 мкА` (`10·10⁻⁶ А`):

```
t_recovery
= (10·10⁻⁹ · 0.7 · 3.3) / (10·10⁻⁶)   [підстановка параметрів]
= (2.31·10⁻⁸) / (10·10⁻⁶)             [множення чисельника]
= 2.31·10⁻³ с = 2.31 мс               [час фільтрації брязкоту при відпусканні]
```

Цей час (2.31 мс) значно перевищує типову тривалість механічного брязкоту тактових кнопок (0.5–1.5 мс), гарантуючи одноразове та чітке формування системного імпульсу скидання без мікросекундного тремтіння сигнальних ліній.

### 9. Динамічний енергетичний баланс та розрахунок буферної ємності

Під час передавання даних бездротовими модулями (GSM, LTE, Wi-Fi або Bluetooth) струм споживання зростає імпульсно від 15 мА до 2.0 А на час `t_burst = 577 мкс` (типовий таймслот 2G/GSM) або 1–2 мс (пакет Wi-Fi). Якщо внутрішній опір джерела живлення чи батареї становить `R_source = 0.30 Ом`, спад напруги на внутрішньому опорі сягає:

```
ΔV_drop_internal = I_pulse · R_source = 2.0 · 0.30 = 0.60 В
```

Якщо номінал шини становить 3.30 В, напруга на виводах мікроконтролера миттєво просяде до:

```
V_min_pulse = 3.30 − 0.60 = 2.70 В
```

Якщо супервізор налаштований на поріг 2.93 В, такий імпульс викличе аварійне перезавантаження пристрою під час кожної спроби виходу в ефір.

Щоб компенсувати дефіцит енергії, паралельно шині живлення встановлюють локальний буферний конденсатор `C_bulk`. За час імпульсу `t_burst` конденсатор віддає заряд:

```
Q_supplied = (I_pulse − I_source_max) · t_burst
```

Зміна напруги на конденсаторі:

```
ΔV_allowed = V_nom − V_sup_max − V_noise_margin
```

Звідси розраховується мінімальна необхідна ємність буферного накопичувача:

```
C_bulk ≥ (I_pulse · t_burst) / (V_nom − V_sup_max − V_margin)
```

**Числовий приклад розрахунку ємності:**
- Імпульсний струм передавача: `I_pulse = 1.5 А`.
- Тривалість пакета передачі: `t_burst = 1.0 мс` (`1.0·10⁻³ с`).
- Номінальна напруга: `V_nom = 3.30 В`.
- Максимальний поріг супервізора: `V_sup_max = 3.00 В`.
- Запас на перешкоди та шум: `V_margin = 0.10 В`.

```
ΔV_allowed = 3.30 − 3.00 − 0.10 = 0.20 В
```

Знаходимо ємність:

```
C_bulk
= (1.5 · 1.0·10⁻³) / 0.20              [підстановка струму і часу]
= (1.5·10⁻³) / 0.20                   [множення в чисельнику]
= 7.5·10⁻³ Ф = 7500 мкФ                [розрахункова буферна ємність]
```

Якщо паралельно конденсатору джерело здатне видавати струм `I_source = 0.5 А`, необхідна ємність зменшується пропорційно:

```
C_bulk_eff
= ((1.5 − 0.5) · 1.0·10⁻³) / 0.20     [віднімання струму джерела]
= (1.0·10⁻³) / 0.20                   [обчислення заряду]
= 5.0·10⁻³ Ф = 5000 мкФ                [ефективна буферна ємність]
```

### 10. Розрахунок енергетичного бюджету та тривалості роботи від літієвої батареї

В автономних вимірювальних пристроях із живленням від дискового літієвого елемента CR2032 номінальною ємністю `C_batt = 225 мА·год` супервізор напруги функціонує безперервно протягом усього життєвого циклу приладу (до 10 років).

Сумарний середній струм розряду батареї у режимі очікування складається з трьох компонентів:

```
I_total_sleep = I_Q_sup + I_RTC_SRAM + I_self_discharge
```

де:
- `I_Q_sup` — струм спокою супервізора (для ультранизькоспоживаючих мікросхем `I_Q_sup = 250 нА`);
- `I_RTC_SRAM` — струм годинника реального часу та збереження статичної пам'яті (`I_RTC = 350 нА`);
- `I_self_discharge` — природний саморозряд літієвого елемента (близько 1% на рік від номінальної ємності):

```
I_self_discharge
= (0.01 · 225 мА·год) / (365 · 24 год) [переведення річного відсотка у постійний струм]
= 2.25 мА·год / 8760 год               [ділення на кількість годин у році]
= 2.568·10⁻⁴ мА = 257 нА               [середній струм саморозряду]
```

Повний струм споживання вузла безпеки:

```
I_total_sleep
= 250 нА + 350 нА + 257 нА            [підстановка струмів]
= 857 нА = 0.857 мкА                  [сумарний струм у сні]
```

Теоретичний термін служби батареї CR2032 виключно на підтримку супервізора та пам'яті:

```
T_life_years
= C_batt / (I_total_sleep · 8760 год) [розрахунок тривалості в роках]
= 225 мА·год / (0.857·10⁻³ мА · 8760 год) [підстановка значень у мА]
= 225 / 7.507                          [обчислення річного споживання]
= 29.97 років                          [теоретичний ресурс батареї]
```

Якби для цієї задачі помилково обрали застарілий супервізор загального призначення зі струмом спокою `I_Q = 15 мкА`, річне споживання склало б `15·10⁻³ · 8760 = 131.4 мА·год`, і батарея CR2032 повністю розрядилася б лише за `225 / 131.4 ≈ 1.7 року`. Цей розрахунок демонструє вирішальне значення вибору наноамперних супервізорів для польових датчиків та інтернету речей (IoT).

#### Вплив пасивації літієвих елементів при тривалому зберіганні
При зберіганні літієвих первинних джерел (Li-SOCl2 або Li-MnO2) на поверхні літієвого анода утворюється захисна плівка хлориду літію (пасиваційний шар). Якщо пристрій споживає ультранизький струм протягом місяців, опір пасивації `R_pass` може зростати до десятків ом. Під час першого активного пробудження струм навантаження викликає миттєве динамічне просідання напруги (Voltage Delay Effect) тривалістю 1–10 мс.

Якщо супервізор не має достатньої часової фільтрації (Glitch Immunity), це падіння напруги нижче порогу викличе паразитичний цикл безперервного перезавантаження. Для запобігання цьому розраховують паралельний конденсатор підтримки за формулою ємності буфера, або обирають мікросхеми супервізорів із розширеним часом аналогової фільтрації вхідних імпульсів.
