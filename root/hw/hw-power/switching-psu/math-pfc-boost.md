# 🧮 Розрахунок накопичувача й PFC-дроселя

Спроєктувати надійне мережеве джерело живлення неможливо без точного інженерного розрахунку двох критичних магнітних та ємнісних компонентів первинного боку: накопичувального конденсатора високовольтної шини (*Bulk capacitor*) та дроселя коректора коефіцієнта потужності (*PFC boost inductor*). Якщо ємність накопичувача обрана замалою, блок живлення вимикатиметься під час найменшого короткочасного просідання мережевої напруги (тривалістю в один напівперіод 10–20 мс), а пульсації 100 Гц модулюватимуть вихідні напруги. Якщо ж індуктивність дроселя PFC розрахована неправильно, струм через силовий ключ вийде з граничного або неперервного режиму, осердя ввійде в магнітне насичення, а високочастотні гармоніки перевищать ліміти стандарту IEC 61000-3-2.

Нижче наведено повний математичний вивід, теплові рівняння та числовий розрахунок обох вузлів для джерела номінальною вихідною потужністю 300 Вт, що живиться від універсальної електромережі 85–265 В змінного струму частотою 50 Гц.

### Розрахунок ємності накопичувального конденсатора та часу утримання

Накопичувальний конденсатор високовольтної шини постійного струму виконує дві взаємопов'язані фізичні задачі:
1. Згладжує низькочастотні пульсації струму 100 Гц, зумовлені пульсацією миттєвої потужності однофазної мережі.
2. Забезпечує резерв енергії під час аварійного знеструмлення мережі на нормований час утримання (*Hold-up time*, `t_hold`).

Стандарт IEC 62368-1 та специфікація Intel ATX вимагають, щоб блок живлення комп'ютерного або телекомунікаційного класу продовжував видавати номінальну потужність щонайменше протягом одного повного періоду мережі (`t_hold = 20 мс` за частоти 50 Гц) після раптового зникнення вхідної напруги.

У схемі з активним коректором коефіцієнта потужності номінальна напруга на накопичувачі жорстко стабілізується на рівні `V_bulk_nom = 400 В`. Під час відключення мережі накопичувальний конденсатор розряджається, живлячи вторинний DC-DC перетворювач, доки напруга на ньому не впаде до мінімального порогу працездатності перетворювальної секції `V_bulk_min = 320 В`.

Енергія, яку віддає конденсатор під час розряду від `V_bulk_nom` до `V_bulk_min`:

```
ΔE = (1/2) · C_bulk · (V_bulk_nom² - V_bulk_min²)
```

Ця енергія має повністю покрити споживання вихідного навантаження `P_out` протягом часу `t_hold` з урахуванням коефіцієнта корисної дії вторинного перетворювача `η`:

```
E_req = (P_out · t_hold) / η
```

Прирівнюємо енергію розряду конденсатора до необхідної енергії споживання:

```
(1/2) · C_bulk · (V_bulk_nom² - V_bulk_min²) = (P_out · t_hold) / η   [рівняння енергетичного балансу]
```

Виражаємо необхідну ємність накопичувача `C_bulk`:

```
C_bulk = (2 · P_out · t_hold) / (η · (V_bulk_nom² - V_bulk_min²))
```

**Числовий розрахунок для `P_out = 300 Вт`, `t_hold = 20 мс` (0.02 с), `η = 0.92`, `V_bulk_nom = 400 В`, `V_bulk_min = 320 В`:**

```
C_bulk = (2 · P_out · t_hold) / (η · (V_bulk_nom² - V_bulk_min²))
       = (2 · 300 · 0.02) / (0.92 · (400² - 320²))   [підстановка вихідних параметрів]
       = 12.0 / (0.92 · (160000 - 102400))           [піднесення напруг до квадрата]
       = 12.0 / (0.92 · 57600)                       [різниця квадратів напруг]
       = 12.0 / 52992                                [множення в знаменнику]
       ≈ 0.0002264 Ф = 226.4 мкФ                     [остаточне значення ємності]
```

З урахуванням виробничого допуску електролітичних конденсаторів (±20%), втрати ємності під час нагріву та деградації електроліту внаслідок висихання протягом 5–7 років експлуатації (старіння зменшує ємність на 15–20%), номінал обирають із запасом 1.3–1.4:

```
C_selected ≥ 226.4 мкФ · 1.35 ≈ 305 мкФ
```

Обираємо промисловий оксидно-електролітичний конденсатор номіналом **330 мкФ на робочу напругу 450 В DC** температурної серії 105 °C.

### Пульсації напруги 100 Гц та струмове навантаження конденсатора

У стаціонарному режимі з увімкненим PFC вхідна потужність, що надходить у шину 400 В, пульсує з подвійною частотою мережі (`2 · f_line = 100 Гц`), оскільки миттєва потужність однофазної синусоїди змінюється від нуля до подвійного середнього значення:

```
p_in(t) = 2 · P_in · sin²(ω · t) = P_in · (1 - cos(2 · ω · t))
```

Постійна складова `P_in` безперервно забирається вторинним перетворювачем, а змінна гармонічна складова з частотою 100 Гц протікає крізь накопичувальний конденсатор, породжуючи низькочастотні пульсації напруги з подвійним розмахом `ΔV_pk_pk`:

```
ΔV_pk_pk = P_out / (2 · π · f_line · C_bulk · V_bulk_nom · η)
```

**Перевірка подвійного розмаху пульсацій 100 Гц для обраного конденсатора `C_bulk = 330 мкФ` (0.00033 Ф):**

```
ΔV_pk_pk = 300 / (2 · 3.1416 · 50 · 0.00033 · 400 · 0.92)   [підстановка параметрів системи]
         = 300 / (314.16 · 0.00033 · 368)                   [обчислення кругової частоти 2·π·f]
         = 300 / 38.15                                      [добуток знаменника]
         ≈ 7.86 В                                           [розмах пульсацій від піку до піку]
```

Відносний розмах пульсацій напруги на високовольтній шині:

```
ΔV_rel = (7.86 В / 400 В) · 100% ≈ 1.96%
```

Рівень пульсацій менше 2% є чудовим результатом, що забезпечує запас регулювання для вторинного перетворювача.

#### Діючий струм пульсацій через накопичувач (RMS Ripple Current)

Діючий (середньоквадратичний) струм, що протікає крізь накопичувальний конденсатор, складається з двох складових: низькочастотної (100 Гц) від випрямленої синусоїди та високочастотної (65 кГц) від комутації ключів PFC та DC-DC інвертора.

Низькочастотний струм пульсацій 100 Гц через конденсатор:

```
I_cap_100hz_rms = P_out / (√2 · V_bulk_nom · η)
                = 300 / (1.4142 · 400 · 0.92)   [підстановка параметрів виходу]
                = 300 / 520.4                   [множення в знаменнику]
                ≈ 0.576 А                       [струм пульсацій 100 Гц]
```

Високочастотний струм комутації PFC-діода розраховується з інтеграла струму діода за період мережі:

```
I_diode_pfc_rms = (P_in_max / V_in_min_rms) · √(8 · √2 · V_in_pk_min / (3 · π · V_bulk_nom))
```

Для мінімальної напруги мережі 85 В (`V_in_pk_min = 120.2 В`, `P_in_max = 343.2 Вт`):

```
8 · 1.4142 · 120.2 / (3 · 3.1416 · 400) = 1360.0 / 3769.9 ≈ 0.3607   [інтегральний коефіцієнт форми]
√0.3607 ≈ 0.6006                                                     [вилучення квадратного кореня]
I_diode_pfc_rms = (343.2 / 85) · 0.6006 = 4.037 · 0.6006 ≈ 2.425 А    [діючий струм діода]
```

Сумарний високочастотний діючий струм крізь накопичувач:

```
I_cap_hf_rms = √(I_diode_pfc_rms² - I_dc_out²)
             = √(2.425² - 0.815²)   [підстановка діючого та постійного струмів]
             = √(5.880 - 0.664)     [піднесення до квадрата]
             = √5.216               [різниця квадратів струмів]
             ≈ 2.284 А              [високочастотний діючий струм]
```

Повний тепловий діючий струм конденсатора:

```
I_cap_total_rms = √(I_cap_100hz_rms² + I_cap_hf_rms²)
                = √(0.576² + 2.284²)   [додавання ортогональних гармонік]
                = √(0.332 + 5.217)     [обчислення квадратів складових]
                = √5.549               [сума квадратів струмів]
                ≈ 2.356 А              [сумарний тепловий діючий струм]
```

Обраний конденсатор повинен мати паспортний допустимий струм пульсацій (*Rated Ripple Current*) щонайменше `I_ripple_rated ≥ 2.5 А` за 105 °C і 100 кГц, інакше внутрішнє джоулеве нагрівання на опір `ESR` призведе до закипання електроліту та виходу приладу з ладу.

### Розрахунок терміну служби накопичувального конденсатора (Рівняння Арреніуса)

Оксидно-електролітичні конденсатори є найбільш термочутливими компонентами імпульсного джерела. Їхній термін служби визначається швидкістю випаровування рідкого органічного електроліту крізь гумове ущільнення денця корпусу, яка строго підпорядковується правилу Арреніуса: підвищення робочої температури на кожні 10 °C прискорює хімічні реакції деградації вдвічі, скорочуючи час життя конденсатора рівно в 2 рази.

Розрахунковий термін служби конденсатора `L_expected` вираховується за формулою:

```
L_expected = L_base · 2^((T_max - T_core) / 10)
```

де:
* `L_base` — базовий гарантований ресурс конденсатора за максимальної температури (для якісних серій, наприклад Nichicon або Nippon Chemi-Con, `L_base = 5000 годин` при `T_max = 105 °C`);
* `T_core` — температура внутрішнього ядра конденсатора в робочому режимі.

Температура ядра конденсатора складається з температури повітря всередині закритого корпусу блоку живлення `T_ambient` та внутрішнього самонагріву від протікання діючого струму пульсацій на еквівалентному послідовному опорі `ESR`:

```
ΔT_core = I_cap_total_rms² · ESR · R_th_cap
```

**Приклад розрахунку ресурсу для конденсатора 330 мкФ з `ESR = 0.12 Ом`, тепловим опором корпус-повітря `R_th_cap = 28 °C/Вт` за температури всередині блоку `T_ambient = 55 °C`:**

```
P_loss_cap = I_cap_total_rms² · ESR = (2.356)² · 0.12 = 5.551 · 0.12 ≈ 0.666 Вт   [теплова потужність втрат]
ΔT_core = P_loss_cap · R_th_cap = 0.666 Вт · 28 °C/Вт ≈ 18.6 °C                  [перегрів ядра над повітрям]
T_core = T_ambient + ΔT_core = 55 °C + 18.6 °C = 73.6 °C                         [абсолютна температура ядра]
```

Обчислюємо температурний множник ресурсу:

```
(T_max - T_core) / 10 = (105 - 73.6) / 10 = 31.4 / 10 = 3.14   [різниця температур у декадах]
2^3.14 ≈ 8.815                                                [коефіцієнт подовження життя Арреніуса]
```

Очікуваний термін безперервної служби конденсатора:

```
L_expected = 5000 годин · 8.815 ≈ 44 075 годин   [розрахунковий ресурс роботи]
```

У режимі безперервної цілодобової роботи (24/7, що становить 8760 годин на рік) розрахований конденсатор надійно пропрацює:

```
Час_років = 44075 / 8760 ≈ 5.03 роки   [переведення годин у календарні роки]
```

Якщо ж температура повітря всередині блоку зросте до 75 °C (внаслідок зупинки вентилятора чи забивання пилом), температура ядра сягне `93.6 °C`, а ресурс впаде до `5000 · 2^((105 - 93.6)/10) = 5000 · 2^1.14 ≈ 11 000 годин` (менше 1.2 року).

### Розрахунок індуктивності дроселя Boost PFC (режим CCM)

Активний Boost PFC перетворює вхідну пульсуючу синусоїдну напругу `v_in(t) = V_in_pk · |sin(ω·t)|` на стабільні 400 В DC. Найважчий тепловий і магнітний режим настає за мінімальної напруги мережі `V_in_min_rms = 85 В`, коли вхідний струм максимальний.

Амплітудне значення мінімальної напруги:

```
V_in_pk_min = 85 В · √2 ≈ 120.2 В
```

Максимальна вхідна потужність за ККД коректора `η_pfc = 0.95`:

```
P_in_max = P_out / (η · η_pfc) = 300 / (0.92 · 0.95) ≈ 343.2 Вт
```

Піковий струм мережі на вершині вхідної синусоїди:

```
I_in_pk_max = (2 · P_in_max) / V_in_pk_min
            = (2 · 343.2) / 120.2   [підстановка потужності та напруги]
            ≈ 5.71 А                [амплітудний струм мережі]
```

У режимі неперервних струмів (*Continuous Conduction Mode*, CCM) розмах високочастотних пульсацій струму дроселя `ΔI_L` обирають як частку від пікового струму мережі через коефіцієнт пульсацій `K_rf = ΔI_L / I_in_pk_max = 0.30` (30% розмаху):

```
ΔI_L = 0.30 · 5.71 А ≈ 1.713 А
```

Шпаруватість відкритого стану силового MOSFET (*duty cycle*) на вершині синусоїди:

```
D = (V_bulk_nom - V_in_pk_min) / V_bulk_nom   [формула коефіцієнта заповнення Boost]
  = (400 - 120.2) / 400                      [підстановка напруг шини й мережі]
  = 279.8 / 400                              [різниця напруг на дроселі]
  = 0.6995 ≈ 0.70                            [обчислене значення шпаруватості]
```

Час увімкненого стану ключа за комутаційної частоти `f_sw = 65 кГц` (період `T_sw = 15.38 мкс`):

```
t_on = D / f_sw = 0.6995 / 65000 ≈ 10.76 мкс
```

З основного закону електромагнітної індукції для індуктивності `V_L = L · (ΔI_L / t_on)` знаходимо необхідну індуктивність дроселя PFC:

```
L_pfc = (V_in_pk_min · D) / (f_sw · ΔI_L)
```

**Числовий розрахунок для `f_sw = 65 кГц` (65000 Гц):**

```
L_pfc = (120.2 · 0.6995) / (65000 · 1.713)   [підстановка напруги, шпаруватості й струму]
      = 84.08 / 111345                      [обчислення чисельника й знаменника]
      ≈ 0.000755 Гн = 755 мкГн              [шукана індуктивність дроселя]
```

Обираємо стандартний номінал **`L_pfc = 750–800 мкГн`**.

### Граничний режим провідності (Critical Conduction Mode, CrM / BCM)

Для менших потужностей (до 150–200 Вт) часто обирають **граничний режим провідності** (англ. *Critical Conduction Mode*, CrM, або *Boundary Conduction Mode*, BCM). У цьому режимі силовий транзистор вмикається в той самий момент, коли струм у дроселі спадає строго до нуля (`I_min = 0`).

У режимі CrM розмах пульсацій струму дорівнює подвійному середньому струму (`ΔI_L = 2 · i_in(t)`), а комутаційна частота є змінною і залежить від миттєвої фази напруги мережі `θ = ω·t`:

```
f_sw(θ) = (V_in_pk² · sin²(θ) · (1 - (V_in_pk / V_bulk) · sin(θ))) / (2 · L_crm · P_in)
```

Мінімальна частота комутації в CrM спостерігається на вершині синусоїди (`θ = 90°`):

```
f_sw_min = (V_in_pk² · (1 - (V_in_pk / V_bulk))) / (2 · L_crm · P_in)
```

Розрахуємо необхідну індуктивність для CrM-коректора на 150 Вт за мінімальної частоти `f_sw_min = 45 кГц` на напрузі 85 В AC (`V_in_pk = 120.2 В`, `P_in = 165 Вт`):

```
L_crm = (V_in_pk² · (1 - (V_in_pk / V_bulk))) / (2 · f_sw_min · P_in)
      = (120.2² · (1 - (120.2 / 400))) / (2 · 45000 · 165)   [підстановка напруги, частоти й потужності]
      = (14448 · (1 - 0.3005)) / 14850000                     [обчислення коефіцієнта заповнення]
      = (14448 · 0.6995) / 14850000                           [множення в чисельнику]
      = 10106 / 14850000                                      [ділення чисельника на знаменник]
      ≈ 0.000680 Гн = 680 мкГн                                [індуктивність для граничного режиму]
```

Головна перевага CrM — увімкнення транзистора при нульовому струмі (*Zero-Current Switching*, ZCS), що усуває втрати зворотного відновлення діода. Недолік — піковий струм через транзистор у 2 рази вищий, ніж у CCM (`I_pk_CrM = 2 · I_pk_CCM`), що обмежує застосування CrM потужностями до 200 Вт.

### Розрахунок магнітного осердя та втрат у дроселі

Осердя дроселя Boost PFC працює з однополярним підмагнічуванням постійним струмом. Для запобігання насиченню застосовують пресовані порошкові магнітодіелектрики (*Sendust / Kool Mμ*, *High Flux*) або феритові осердя з каліброваним немагнітним повітряним зазором.

Абсолютний піковий струм через дросель у режимі CCM:

```
I_L_peak = I_in_pk_max + (ΔI_L / 2)   [додавання напіврозмаху пульсацій до піку]
         = 5.71 + (1.713 / 2)         [підстановка середнього піку та розмаху]
         = 5.71 + 0.856               [обчислення напівпульсації]
         = 6.57 А                     [піковий струм через осердя]
```

Осердя дроселя повинно мати струм насичення із запасом не менше 30%:

```
I_sat ≥ 1.30 · I_L_peak = 1.30 · 6.57 А ≈ 8.54 А
```

Необхідна величина магнітної енергії, яку має накопичувати дросель:

```
W_mag = (1/2) · L_pfc · I_L_peak²
      = (1/2) · 0.000755 · (6.57)²   [підстановка індуктивності та пікового струму]
      = 0.0003775 · 43.16            [піднесення струму до квадрата]
      ≈ 0.0163 Дж = 16.3 мДж         [накопичена енергія магнітного поля]
```

Для феритового осердя типу E-core (наприклад, E42/21/15 з матеріалу MnZn N87) з площею перерізу `A_e = 178 мм²` (0.000178 м²) та максимальною робочою індукцією `B_max = 0.30 Тл` необхідне число витків первинної обмотки `N`:

```
N = (L_pfc · I_L_peak) / (B_max · A_e)
  = (0.000755 · 6.57) / (0.30 · 0.000178)   [підстановка параметрів магнітопроводу]
  = 0.00496 / 0.0000534                     [добутки чисельника й знаменника]
  ≈ 92.9 витків → обираємо N = 93 витки     [округлення до цілого числа витків]
```

Необхідна сумарна довжина повітряного зазору в центральному керні `l_gap` (де `μ_0 = 4·π·10⁻⁷ Гн/м`):

```
l_gap = (μ_0 · N² · A_e) / L_pfc
      = (4 · 3.1416 · 10⁻⁷ · 93² · 0.000178) / 0.000755   [підстановка магнітної сталої та витків]
      = (1.2566 · 10⁻⁶ · 8649 · 0.000178) / 0.000755      [піднесення витків до квадрата]
      = (0.001934) / 0.000755                             [обчислення магнітної провідності]
      ≈ 0.00256 м = 2.56 мм                               [величина повітряного зазору]
```

Шліфування центрального керна осердя на зазор 2.56 мм забезпечує стабільну індуктивність 755 мкГн без насичення аж до струму 9 А.

#### Розрахунок перерізу мідного дроту та скін-ефекту обмотки дроселя

Для комутаційної частоти 65 кГц товщина скін-шару в міді за робочої температури 100 °C (`ρ_cu = 2.3 · 10⁻⁸ Ом·м`):

```
δ = √(ρ_cu / (π · f_sw · μ_0))
  = √( (2.3 · 10⁻⁸) / (3.1416 · 65000 · 4 · 3.1416 · 10⁻⁷) )   [підстановка питомого опору та частоти]
  = √( (2.3 · 10⁻⁸) / (0.2566) )                               [обчислення знаменника під коренем]
  = √(8.96 · 10⁻⁸)                                             [ділення під коренем]
  ≈ 0.000299 м = 0.30 мм                                       [глибина скін-шару в міді]
```

Щоб струм протікав рівномірно по всьому перерізу міді без зростання опору на змінному струмі, діаметр кожної окремої жили обмотки не повинен перевищувати подвійну товщину скін-шару: `d_wire ≤ 2 · δ = 0.60 мм`. Обираємо емальпровід діаметром `d = 0.35 мм` (номінальний переріз однієї жили `S_1 = π · d² / 4 = 0.0962 мм²`).

За допустимої щільності струму `J = 4.5 А/мм²` та діючого струму дроселя `I_L_rms = 4.04 А` необхідний сумарний переріз міді:

```
S_cu_total = I_L_rms / J = 4.04 А / 4.5 А/мм² ≈ 0.898 мм²
```

Кількість паралельних жил у джгуті:

```
n_strands = S_cu_total / S_1 = 0.898 / 0.0962 ≈ 9.33 → обираємо джгут із 10 жил діаметром 0.35 мм
```

Такий багатожильний джгут мінімізує омічні втрати в міді до рівня менше `P_cu = I_L_rms² · R_dc_winding = (4.04)² · 0.08 Ом ≈ 1.30 Вт`.

#### Втрати в магнітному осерді дроселя (Рівняння Штайнмеца)

Високочастотна змінна складова індукції `ΔB` викликає втрати на гістерезис та вихрові струми в осерді, які описуються узагальненим емпіричним рівнянням Штайнмеца:

```
P_core = C_m · f_sw^α · (ΔB / 2)^β · V_e
```

де для фериту MnZn N87 на частотах 50–100 кГц параметри становлять: `C_m = 1.25 Вт/(м³·Гц^α·Тл^β)`, `α = 1.35`, `β = 2.45`, а ефективний об'єм осердя E42/21/15 дорівнює `V_e = 17.3 см³ = 1.73 · 10⁻⁵ м³`.

Амплітуда високочастотної змінної індукції:

```
ΔB = (L_pfc · ΔI_L) / (N · A_e)
   = (0.000755 · 1.713) / (93 · 0.000178)   [підстановка пульсацій струму й площі керна]
   = 0.001293 / 0.016554                    [обчислення чисельника й знаменника]
   ≈ 0.0781 Тл                              [розмах змінної магнітної індукції]
```

Напіврозмах змінної індукції: `B_ac = ΔB / 2 = 0.03905 Тл`.

Обчислюємо втрати в осерді:

```
P_core = 1.25 · (65000)^1.35 · (0.03905)^2.45 · (1.73 · 10⁻⁵)   [підстановка параметрів Штайнмеца]
       = 1.25 · (3.12 · 10⁶) · 0.000354 · (1.73 · 10⁻⁵)        [обчислення степеневих множників]
       = 1380.6 · (1.73 · 10⁻⁵)                                 [добуток коефіцієнтів втрат]
       ≈ 0.414 Вт                                               [сумарні втрати в осерді дроселя]
```

Втрати в осерді 0.41 Вт є цілком прийнятними й не спричинять перегріву магнітопроводу.

### Розрахунок теплових втрат силових ключів PFC

#### 1. Втрати в силовому транзисторі MOSFET

Середньоквадратичний струм через транзистор за період мережі:

```
I_sw_rms = (P_in_max / V_in_min_rms) · √(2 - (16 · V_in_pk_min / (3 · π · V_bulk_nom)))
```

Обчислюємо підкореневий коефіцієнт форми:

```
16 · 120.2 / (3 · 3.1416 · 400) = 1923.2 / 3769.9 ≈ 0.510   [гармонійний коефіцієнт інтеграла]
√(2 - 0.510) = √1.490 ≈ 1.2207                              [обчислення коефіцієнта форми]
```

Розрахунок діючого струму транзистора:

```
I_sw_rms = (343.2 / 85) · 1.2207   [підстановка діючого вхідного струму]
         = 4.037 · 1.2207          [ділення потужності на напругу]
         ≈ 4.93 А                 [діючий RMS-струм через ключ]
```

Статичні втрати провідності на ключі з опором каналу `R_ds_on = 0.15 Ом` за 100 °C:

```
P_cond_sw = I_sw_rms² · R_ds_on = (4.93)² · 0.15 = 24.3 · 0.15 ≈ 3.65 Вт
```

Динамічні комутаційні втрати вмикання та вимикання за тривалості фронтів `t_r = 20 нс`, `t_f = 15 нс`:

```
P_sw_loss = (1/2) · V_bulk_nom · I_in_pk_max · (t_r + t_f) · f_sw · (2 / π)
          = 0.5 · 400 · 5.71 · (35 · 10⁻⁹) · 65000 · 0.6366   [підстановка напруги, струму й фронтів]
          = 1142 · (35 · 10⁻⁹) · 65000 · 0.6366              [добуток напруги на струм]
          = 0.00003997 · 65000 · 0.6366                      [множення на тривалість фронту]
          ≈ 1.65 Вт                                          [динамічні втрати комутації ключа]
```

Сумарні втрати на MOSFET-транзисторі:

```
P_total_sw = P_cond_sw + P_sw_loss = 3.65 + 1.65 = 5.30 Вт
```

#### 2. Втрати у випрямному діоді Boost PFC

Середній струм через вихідний високовольтний діод:

```
I_diode_avg = P_out / (V_bulk_nom · η) = 300 / (400 · 0.92) = 300 / 368 ≈ 0.815 А
```

Статичні втрати на діоді Шотткі на основі карбіду кремнію (SiC) з падінням `V_f = 1.4 В`:

```
P_cond_diode = I_diode_avg · V_f = 0.815 · 1.4 ≈ 1.14 Вт
```

Оскільки діоди SiC практично не мають заряду зворотного відновлення (`Q_rr ≈ 0 нКл`), динамічні втрати відновлення діода дорівнюють нулю, що усуває додаткові 2–3 Вт тепла, які виділялися б на кремнієвому ультрашвидкому діоді типу FRD.

### Розрахунок вхідного EMI-конденсатора X-типу та резистора розряду

Високочастотні пульсації струму комутації PFC на частоті 65 кГц не повинні проникати назад у живильну електромережу. Для їхнього шунтування на вході діодного моста встановлюють плівковий поліпропіленовий X-конденсатор `C_x`.

Необхідна ємність `C_x` визначається допустимим рівнем високочастотних пульсацій напруги на вході (зазвичай `ΔV_in_hf ≤ 2 В` за струму комутації `ΔI_L = 1.713 А`):

```
C_x ≥ ΔI_L / (8 · f_sw · ΔV_in_hf)
    = 1.713 / (8 · 65000 · 2)   [підстановка струму комутації та пульсацій]
    = 1.713 / 1040000           [множення в знаменнику]
    ≈ 1.65 · 10⁻⁶ Ф = 1.65 мкФ  [мінімальна фільтруюча ємність]
```

Обираємо стандартний конденсатор класу X2 номіналом **0.47 мкФ або 2 × 0.47 мкФ = 0.94 мкФ** у парі з індуктивністю розсіювання вхідного фільтра.

#### Розрахунок безпечного резистора розряду (Bleeder Resistor)

Коли користувач висмикує вилку блоку живлення з розетки, на виводах конденсатора `C_x` може залишитися повна пікова напруга мережі (до 375 В). Якщо людина випадково торкнеться металевих штирів вилки, вона отримає удар електричним струмом.

Стандарт безпеки IEC 62368-1 вимагає, щоб протягом часу `t_discharge = 1.0 с` після відключення напруга на вилці гарантовано впала до безпечного рівня нижче `V_safe = 60 В DC` (що становить менше `37%` від початкового рівня):

```
V(t) = V_pk · e^(-t / (R_bleed · C_x)) ≤ V_safe
```

Постійна часу розряду кола `τ = R_bleed · C_x` має задовольняти умову `τ ≤ 1.0 с`:

```
R_bleed ≤ 1.0 с / C_x
```

Для сумарної ємності двох X-конденсаторів `C_x_total = 0.94 мкФ` (0.00000094 Ф):

```
R_bleed ≤ 1.0 / 0.00000094 ≈ 1 063 800 Ом = 1.06 МОм
```

Обираємо розрядний резистор номіналом **680–820 кОм**. Оскільки напруга 230 В AC прикладена до нього постійно, робоча потужність розсіювання резистора становить:

```
P_bleed = V_rms² / R_bleed = 230² / 680000 = 52900 / 680000 ≈ 0.078 Вт (78 мВт)
```

Для забезпечення високовольтної надійності резистор складають із двох послідовних SMD-резисторів типорозміру 1206 номіналом по 360 кОм.

### Розрахунок захисту від пускового струму (NTC та запобіжник)

У момент холодного старту конденсатор `C_bulk = 330 мкФ` заряджається від мережі 265 В AC (`V_pk_max = 375 В`). Для обмеження пікового струму значенням `I_inrush_max ≤ 35 А` опір холодного NTC-термістора має становити:

```
R_ntc_25c ≥ V_pk_max / I_inrush_max = 375 В / 35 А ≈ 10.7 Ом → обираємо NTC 10 Ом
```

Інтеграл енергії розплавлення плавкого запобіжника `I²t` під час заряду конденсатора:

```
I²t_pulse = (1/2) · C_bulk · (V_pk_max)² / R_ntc
          = 0.5 · 0.00033 · (375)² / 10   [підстановка ємності, напруги та NTC]
          = 0.5 · 0.00033 · 140625 / 10   [піднесення пікової напруги до квадрата]
          = 23.2 / 10                     [енергія заряду конденсатора]
          ≈ 2.32 А²·с                     [інтеграл Джоуля пускового імпульсу]
```

Щоб запобіжник не спрацьовував хибно від пускового струму під час кожного увімкнення в розетку, його номінальний параметр `I²t_fuse` повинен перевищувати розраховане значення імпульсу щонайменше в 3–5 разів:

```
I²t_fuse ≥ 4 · 2.32 ≈ 9.28 А²·с
```

Обираємо сповільнений керамічний запобіжник типу *Time-Lag* (маркування **T3.15A / 250V** з номіналом `I²t = 15–20 А²·с`), що забезпечує надійну багаторічну роботу без помилкових спрацьовувань.
