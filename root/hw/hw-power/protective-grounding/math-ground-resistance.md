# 🧮 Математична теорія розтікання струму та опору заземлення

Коли струм аварійного замикання стікає з металевого заземлювача в ґрунт, він розходиться в об'ємі землі по нескінченній кількості паралельних траєкторій. Оскільки питомий опір ґрунту `ρ` в середньому становить від 10 до 500 Ом·м, розподіл електричного потенціалу в провідному середовищі підпорядковується диференціальним рівнянням поля. Математичний розрахунок опору заземлення, потенціального поля та небезпечних напруг (дотику й кроку) спирається на розв'язання рівняння Лапласа для електростатичних та стаціонарних струмових полів у однорідному півпросторі.

---

### Диференціальні рівняння стаціонарного струмового поля в ґрунті

У провідному середовищі без внутрішніх джерел сторонніх епірс (поза межами самих заземлювальних електродів) вектор густини струму `j` задовольняє диференціальне рівняння неперервності струму:

```
∇ · j = 0     [умова стаціонарності струмового поля]
```

За диференціальною формою закону Ома для ізотропного середовища з питомою провідністю `σ = 1 / ρ`:

```
j = σ · E = (1 / ρ) · E     [закон Ома в диференціальній формі]
```

Оскільки стаціонарне електричне поле є потенціальним, вектор напруженості поля `E` виражається через градієнт електричного потенціалу `V`:

```
E = -∇V     [зв'язок напруженості та потенціалу]
```

Підставляючи вирази для `j` та `E` у рівняння неперервності, отримуємо фундаментальне диференціальне рівняння Лапласа для електричного потенціалу у середовищі з постійним питомим опором `ρ`:

```
∇ · ((1 / ρ) · (-∇V)) = 0
∇²V = 0     [рівняння Лапласа для скалярного потенціалу V]
```

У сферичній системі координат `(r, θ, φ)` за наявності сферичної симетрії розтікання (коли потенціал залежить лише від радіуса `r`) рівняння Лапласа спрощується до звичайного диференціального рівняння другого порядку:

```
(1 / r²) · d/dr (r² · dV/dr) = 0
```

Інтегруючи це рівняння двічі по `r`, отримуємо загальний вигляд функціональної залежності потенціалу:

```
1. r² · dV/dr = C_1          [перше інтегрування]
2. dV/dr = C_1 / r²
3. V(r) = -C_1 / r + C_2     [друге інтегрування]
```

Константи інтегрування `C_1` та `C_2` визначаються з двох граничних умов:
- Гранична умова на нескінченності: `V(r → ∞) = 0`, звідки `C_2 = 0`.
- Гранична умова на межі заземлювача: струм `I`, що протікає крізь будь-яку закриту поверхню `S`, дорівнює `I = ∮ j · dS`.

Фізичний зміст рівняння Лапласа полягає у тому, що у середовищі без джерел та стоків стаціонарний струм не накопичує електричного заряду в об'ємі. Будь-який електричний заряд у провіднику згладжується за час релаксації `τ = ε · ρ`, який для ґрунту становить частки наносекунди. Завдяки цьому розподіл стаціонарного потенціалу повністю утримується миттєвими граничними умовами на поверхнях електродів та межах шарів.

### Півсферичний заземлювач у провідному півпросторі

Розглянемо заземлювач у формі металевої півсфери радіуса `r_0`, занурений урівень із поверхнею землі в однорідний ґрунт із питомим опором `ρ`. Поверхня землі при `z = 0` є межею розділу між провідним ґрунтом та диелектричним повітрям, тому нормальна складова густини струму на цій поверхні дорівнює нулю (`j_z = 0`).

Для врахування межі розділу застосовують **метод дзеркальних відображень**: півпростір ґрунту `z ≥ 0` подумки доповнюють верхнім півпростором `z < 0` із таким самим питомим опором `ρ`, а півсферичний заземлювач доповнюють до повної сфери, крізь яку стікає подвійний струм `2·I`.

Густина струму `j(r)` на радіусі `r ≥ r_0` дорівнює струму `I`, поділеному на площу півсфери `S(r) = 2·π·r²`:

```
j(r) = I / (2·π·r²)     [густина струму на радіусі r]
```

Напруженість електричного поля `E(r)` за законом Ома:

```
E(r) = ρ · j(r)
     = (I · ρ) / (2·π·r²)     [напруженість електричного поля]
```

Потенціал `V(r)` визначається як інтеграл від напруженості від точки `r` до нескінченності:

```
V(r) = ∫[r до ∞] E(r') dr'
     = ∫[r до ∞] ((I · ρ) / (2·π·r'²)) dr'
     = (I · ρ) / (2·π) · [-1 / r'][від r до ∞]
     = (I · ρ) / (2·π·r)     [потенціал ґрунту на відстані r]
```

Потенціал металевого заземлювача `V_0` дорівнює значенню потенціалу на його поверхні `r = r_0`:

```
V_0 = V(r_0)
    = (I · ρ) / (2·π·r_0)     [потенціал заземлювача]
```

Повний опір заземлювача розтіканню струму `R_g` визначається за законом Ома для всієї зони розтікання:

```
R_g = V_0 / I
    = ((I · ρ) / (2·π·r_0)) / I
    = ρ / (2·π·r_0)     [опір півсферичного заземлювача]
```

Завдяки принципу еквівалентності електричних полів будь-який заземлювач складної форми можна математично зіставити з еквівалентним півсферичним заземлювачем певного радіуса `r_екв`. Наприклад, для дискового заземлювача радіуса `R_диск` еквівалентний радіус півсфери становить `r_екв = (2 / π) · R_диск`, а опір диска дорівнює `R_диск_електрод = ρ / (4 · R_диск)`.

Математично цей аналог розгортається через теорію ємності: опір заземлювача розтіканню `R_g` строго пов'язаний із самоємністю `C_0` металевого тіла тієї самої форми у безмежному диелектричному середовищі співвідношенням `R_g = (ε_0 · ρ) / C_0`.

### Розрахунок вертикального стрижневого заземлювача

На практиці найбільш поширеним заземлювачем є вертикальний сталевий або мідний стрижень довжиною `L` та діаметром `d` (радіус `a = d / 2`), забитий у ґрунт.

Для обчислення поля стрижня використовують **метод еквівалентного лінійного заряду** (наближення Оллендорфа — Двайта). Припускаємо, що струм `I` рівномірно витікає з тонкої вертикальної нитки довжиною `L` з лінійною густиною струму `I_1 = I / L`.

Потенціал точки з координатами `(r, z)` від відрізка струму довжиною `L` та його дзеркального відображення відносно поверхні землі обчислюється логарифмічним інтегруванням:

```
V(r, z) = (I · ρ / (4·π·L)) · [ln((z + L + √((z + L)² + r²)) / (z + √(z² + r²))) +
                                ln((z - L + √((z - L)² + r²)) / (z + √(z² + r²)))]
```

Для поверхні самого стрижня (`r = a = d / 2`, `0 ≤ z ≤ L`) при умові `L >> d` після спрощення логарифмічних виразів середня величина потенціалу стрижня дорівнює:

```
V_середній = (I · ρ / (2·π·L)) · [ln(4·L / d) - 1]
```

Звідси опір вертикального стрижня `R_rod`, забитого урівень із поверхнею землі, дорівнює:

```
R_rod = V_середній / I
      = (ρ / (2·π·L)) · [ln(4·L / d) - 1]     [при L >> d]
```

Якщо верхній кінець стрижня заглиблений нижче поверхні землі на глибину `t`, використовується уточнена формула Двайта (H. B. Dwight):

```
R_rod = (ρ / (2·π·L)) · [ln(4·L / d) + (1/2)·ln((4·t + 3·L) / (4·t + L))]
```

**Приклад обчислення:** Обчислити опір вертикального сталевого стрижня довжиною `L = 3.0 м`, діаметром `d = 0.016 м` (16 мм), забитого в суглинок із питомим опором `ρ = 60 Ом·м` (верхній кінець урівень із землею).

```
1. Обчислюємо відношення 4·L / d:
   4 · L / d = 4 · 3.0 / 0.016 = 750

2. Обчислюємо натуральний логарифм:
   ln(750) ≈ 6.620

3. Віднімаємо одиницю:
   6.620 - 1 = 5.620

4. Підставляємо значення у формулу:
   R_rod = (60 / (2 · π · 3.0)) · 5.620
         = (60 / 18.8495) · 5.620
         = 3.183 · 5.620
         ≈ 17.89 Ом
```

### Розрахунок горизонтального смугового та кільцевого заземлювачів

Для з'єднання вертикальних стрижнів у спільний контур або як самостійний заземлювач застосовують горизонтальну сталеву смугу шириною `b` та товщиною `t_s` (або круглий дріт діаметром `d`), укладену в траншею на глибину `h` (зазвичай `h = 0.5...0.8 м`).

Опір горизонтальної смуги довжиною `L_s` визначається за формулою:

```
R_strip = (ρ / (2·π·L_s)) · [ln(2·L_s² / (b · h)) + A]
```

де `A` — геометрічний коефіцієнт (для прямої смуги `A ≈ 0.5...1.0`).

Для горизонтального замкненого контуру у формі кільця радіуса `R_контур`, укладеного на глибині `h`:

```
R_ring = (ρ / (2·π²·R_контур)) · ln(8·R_контур / d_екв)
```

де `d_екв` — еквівалентний діаметр провідника смуги (`d_екв ≈ 0.5 · b`).

### Взаємне екранування та груповий заземлювач

При паралельному з'єднанні `n` однаково забитих вертикальних стрижнів, розташованих поруч один від одного на відстані `a`, їхні потенціальні поля розтікання перекриваються. Через взаємне екранування потенціал ґрунту довкола кожного стрижня підвищується за рахунок сусідніх електродів, що зменшує струм із кожного стрижня при тій самій напрузі.

Загальний опір групового заземлювача `R_group` виявляється більшим, ніж розрахований за простою формулою паралельних опорів `R_rod / n`:

```
R_group = R_rod / (n · η_g)     [опір n паралельних заземлювачів]
```

де `η_g` — **коефіціент використання** (значення `η_g ≤ 1.0`).

Коефіцієнт використання обчислюється через систему потенціальних коефіцієнтів Максвелла `α_ij`. Для двох однакових стрижнів на відстані `a` взаємний опір `R_12` дорівнює:

```
R_12 = (ρ / (2·π·a)) · [1 - (L² / (12 · a²))]     [при a ≥ L]
```

Звідси коефіцієнт використання `η_g` для двох стрижнів:

```
η_g = R_rod / (R_rod + R_12)
```

При відношенні відстані до довжини `a / L = 1` для трьох стрижнів у ряд `η_g ≈ 0.75...0.80`; при `a / L = 2` екранування зменшується і `η_g ≈ 0.88...0.92`.

При розміщенні заземлювачів у формі замкненого контуру (прямокутника або квадрата по периметру будівлі) екранування кутових та внутрішніх стрижнів є значно сильнішим, ніж середніх бічних. Для кутових стрижнів коефіцієнт використання становить `η_кути ≈ 0.65...0.70`, а для внутрішніх — `η_внутр ≈ 0.40...0.50`. Саме тому в практичному проектуванні стрижні розміщують переважно по зовнішньому периметру, уникаючи густого заповнення внутрішньої площі контуру.

### Математичний розрахунок комбінованих контурів заземлення

У реальному інженерному проектуванні заземлювальний пристрій складається з прямокутного горизонтального контуру смуги довжиною `L_смуги` та сітки `n` вертикальних стрижнів довжиною `L_стриж`.

Загальний опір комбінованого заземлювального пристрою `R_комб` обчислюється за формулою еквівалентного паралельного з'єднання елементів з урахуванням їхнього взаємного екранування:

```
R_комб = (R_смуги · R_стриж_групи) / (R_смуги · η_смуги + R_стриж_групи · η_стриж)
```

де `R_смуги` — опір горизонтальної смуги контуру, `R_стриж_групи = R_rod / (n · η_g)` — опір куща вертикальних стрижнів, `η_смуги` та `η_стриж` — коефіцієнти використання смуги та стрижнів при їхній спільній роботі у контурі (зазвичай `η_смуги ≈ 0.7...0.85`, `η_стриж ≈ 0.5...0.7`).

**Приклад розрахунку комбінованого контуру:**
Нехай контур складається з горизонтального квадрата 10х10 метрів (довжина смуги `L_смуги = 40 м`, укладена на глибині `h = 0.7 м`) та 4 вертикальних стрижнів по кутах довжиною `L = 3.0 м`, діаметром `d = 16 мм`. Питомий опір ґрунту `ρ = 100 Ом·м`.

```
1. Опір одного вертикального стрижня R_rod:
   R_rod = (100 / (2 · π · 3.0)) · [ln(4 · 3.0 / 0.016) - 1] ≈ 29.82 Ом

2. Опір групи з 4 кутових стрижнів (при η_g ≈ 0.70):
   R_стриж_групи = 29.82 / (4 · 0.70) = 29.82 / 2.80 ≈ 10.65 Ом

3. Опір горизонтальної смуги контуру R_смуги (при b = 0.04 м):
   R_смуги = (100 / (2 · π · 40)) · [ln(2 · 40² / (0.04 · 0.7)) + 0.5]
           = 0.398 · [ln(3200 / 0.028) + 0.5]
           = 0.398 · [11.648 + 0.5] ≈ 4.83 Ом

4. Спільний опір комбінованого контуру (при η_смуги = 0.75, η_стриж = 0.65):
   R_комб = (4.83 · 10.65) / (4.83 · 0.75 + 10.65 · 0.65)
          = 51.44 / (3.62 + 6.92) = 51.44 / 10.54
          ≈ 4.88 Ом
```

Отже, комбінований контур забезпечує підсумковий опір близько 4.9 Ом, що задовольняє більшості вимог для повторного заземлення.

### Математичний розрахунок двошарового ґрунту

Реальний ґрунт практично завжди є неоднорідним. Найчастіше його моделюють двома горизонтальними шарами: верхній шар товщиною `h_1` з питомим опором `ρ_1` та нижній шар із питомим опором `ρ_2`.

Потенціал від точкового джерела струму `I` на поверхні двошарового ґрунту виражається у формі нескінченного ряду за методом дзеркальних відображень:

```
V(r) = (I · ρ_1 / (2·π)) · [1/r + 2 · ∑[n=1 до ∞] (Kⁿ / √(r² + (2·n·h_1)²))]
```

де `K` — **коефіціент відображення**:

```
K = (ρ_2 - ρ_1) / (ρ_2 + ρ_1)
```

Якщо нижній шар є більш провідним (`ρ_2 < ρ_1`), коефіціент `K < 0`, і ряд є знакозмінним, що прискорює його збіжність. Еквівалентний питомий опір `ρ_екв` для вертикального стрижня довжиною `L` у двошаровому ґрунті обчислюється як виважене середнє:

```
ρ_екв = (ρ_1 · ρ_2 · L) / (ρ_1 · (L - h_1) + ρ_2 · h_1)     [при L > h_1]
```

Для складних багатноелектродних контурів заземлення у багаторазово неоднорідних ґрунтах аналітичні інтеграли замінюють чисельними методами — **методом граничних елементів (BEM)** або **методом скінченних елементів (FEM)**. Поверхні заземлювачів розбиваються на `N` елементарних ділянок, для яких складається система лінійних алгебраїчних рівнянь відносно невідомих густин струму `j_i`.

Метод граничних елементів спирається на дискретизацію функції Ґріна для півпростору. Кожен прямокутний або циліндричний сегмент електрода позначається невідомим лінійним струмом `I_k`. Потенціал будь-якої вимірювальної точки обчислюється як інтегральна сума внесків усіх `N` елементів, після чого складається квадратна матриця опорів розміром `N x N`. Розв'язання цієї системи методом Гаусса або LU-розкладу дає точний розподіл струму уздовж усіх провідників складної сітки.

### Математичний аналіз потенціального поля сітчастого заземлювача (IEEE 80)

Для підстанцій високої напруги стандарт IEEE 80 вимагає обчислення потенціалу всередині комірок прямокутної заземлювальної сітки. Максимальна напруга дотику всередині комірки `U_mesh` розраховується за аналітичною формулою Коча (J. G. Koch):

```
U_mesh = (I_g · ρ · K_m · K_i) / L_M
```

де `I_g` — струм замикання на землю, `K_m` — геометричний коефіцієнт комірки сітки, `K_i` — коефіцієнт нерівномірності струму по елементах сітки, `L_M` — ефективна сумарна довжина провідників сітки та забивних стрижнів.

Геометричний коефіцієнт `K_m` враховує крок сітки `D`, діаметр провідника `d` та глибину укладання `h`:

```
K_m = (1 / (2·π)) · [ln(D² / (16 · h · d) + (D + 2·h)² / (8 · D · d) - h / (4 · d)) + (K_ii / K_h) · ln(8 / (π · (2·n - 1)))]
```

Аналітичний розрахунок напруги кроку `U_step` по периметру сітки згідно зі стандартом IEEE 80 виражається схожою залежністю з використанням крокового коефіцієнта `K_s`:

```
U_step = (I_g · ρ · K_s · K_i) / L_S
```

де `K_s = (1 / π) · [1 / (2 · h) + 1 / (D + h) + 1 / D · (1 - 0.5ⁿ⁻²)]`.

Ці математичні формули дають змогу гарантувати, що в жодній точці всередині території підстанції напруга дотику не перевищить безпечного значення, захищаючи персонал від травмування під час аварійних вимкнень ліній високої напруги.

### Математика комплексного імпедансу при високочастотних імпульсах

При зміні струму з високою частотою `ω = 2·π·f` (або при грозових імпульсах із фронтом `1...10 мкс`) опір заземлювача стає комплексним імпедансом `Z_g(jω)`:

```
Z_g(jω) = R_g(ω) + j·ω·L_g + 1 / (j·ω·C_g)
```

де `L_g` — власна індуктивність металевих провідників контуру, `C_g` — ємність заземлювача відносно землі.

Індуктивність довгої сталевої смуги обчислюється як:

```
L_g = (μ_0 · L_s / (2·π)) · [ln(2·L_s / d_екв) - 1]
```

При грозовому розряді струм `I(t)` створює спад напруги `U(t) = R_g · I(t) + L_g · (dI/dt)`. Оскільки швидкість наростання струму блискавки сягає `dI/dt = 10¹⁰ А/с`, індуктивна складова `L_g · (dI/dt)` стає домінуючою, досягаючи сотень кіловольт.

Для врахування імпульсних явищ вводять **імпульсний коефіцієнт заземлювача** `α_імп`:

```
α_імп = Z_імп / R_g
```

Значення `α_імп` залежить від довжини заземлювача та амплітуди струму: для довгих провідників через індуктивність `α_імп > 1.0`, але при надвисоких струмах (понад 20 кА) у ґрунті виникає іскровий мікропробій порового простору, що збільшує ефективний радіус електрода і знижує `α_імп` до 0.5...0.8.

Аналітичний розрахунок хвильового процесу розповсюдження струму уздовж заземлювальної смуги описується телеграфними рівняннями у часткових похідних. Хвильовий опір заземлювача `Z_w` визначається як `√(L_g / C_g)`. Для сталевої смуги в ґрунті хвильовий опір становить від 40 до 120 Ом. Це пояснює, чому для ефективного відведення імпульсів блискавки тривалістю одиниці мікросекунд довжина окремих променів заземлювача не повинна перевищувати 10–15 метрів: імпульсна хвиля струму просто не встигає досягти віддаленого кінця смуги за час існування грозового піку.

Фізична природа хвильового розповсюдження струму в землеводоносних шарах додатково аналізується через комплексний коефіцієнт розповсюдження `γ = √(j·ω·μ_0 · (σ + j·ω·ε))`. Для частот грозового спектра (100 кГц — 1 МГц) глибина проникнення електромагнітної хвилі в ґрунт (скіновий шар) становить від 5 до 15 метрів, що обмежує розтікання струму верхнім поверхневим шаром землі.

Амплітудне значення струму іскроутворення `I_c` у ґрунті розраховується через критичну напруженість пробою ґрунту `E_c ≈ 300...500 кВ/м`:

```
I_c = (E_c · ρ) / (2 · π · R_g²)
```

Якщо струм замикання перевищує `I_c`, навколо електрода спалахує підземний коронарний розряд, який каналізує струм углиб і придушує первинну індуктивну пікову перенапругу. Диференціальні рівняння перехідного розряду розв'язують методом скінченних різниць у часовій області (FDTD).

### Загальний підсумок розрахунку небезпечних напруг

На основі потенціальної функції `V(r)` строго виводяться математичні формули для напруги дотику та кроку.

#### Напруга дотику:
```
U_t(x) = V_0 - V(x)
       = (I · ρ / (2·π·r_0)) · [1 - r_0 / x]
       = V_0 · [1 - r_0 / x]     [напруга дотику на відстані x]
```

Коефіцієнт напруги дотику `α_t = [1 - r_0 / x]` зростає від 0 при `x = r_0` до 1.0 при `x → ∞`.

#### Напруга кроку:
```
U_s(x) = V(x) - V(x + a)
       = (I · ρ / (2·π)) · [1 / x - 1 / (x + a)]
       = (I · ρ / (2·π)) · [a / (x · (x + a))]     [напруга кроку]
```

Для людини з довжиною кроку `a = 0.8 м`, яка стоїть на відстані `x = 1.0 м` від півсферичного електрода `r_0 = 0.2 м` у ґрунті `ρ = 100 Ом·м` при аварійному струмі `I = 50 А`:

```
1. V(1.0) = (50 · 100) / (2 · π · 1.0) ≈ 795.77 В
2. V(1.8) = (50 · 100) / (2 · π · 1.8) ≈ 442.10 В
3. U_s = 795.77 - 442.10 = 353.67 В
```

Розраховане значення `U_s ≈ 354 В` є смертельно небезпечним. Строгий математичний розрахунок доводить необхідність застосування вирівнювальних сіток та автоматичного вимкнення аварійного струму за розрахований час.

> 🔧 **Навіщо це знати.** Наведені математичні формули лежать у основі алгоритмів вимірювальних приладів та систем САПР для обчислення контурів заземлення електростанцій, підстанцій і житлових масивів.
