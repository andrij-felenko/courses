# 🧮 Виведення межі Бетца: дискова модель та коефіцієнт уповільнення потоку

Коли вітер набігає на вітроколесо, потік не може віддати всю свою кінетичну енергію: якби швидкість повітря за ротором впала до нуля, за ним утворилася б непрохідна повітряна пробка, яка зупинила б рух нових порцій повітря. Якщо ж ротор взагалі не гальмує повітря, то й енергії з нього не видобувається. Межа Бетца встановлює фундаментальний теоретичний бар'єр: яку максимальну частку кінетичної енергії відкритого нестисливого потоку можна перетворити на механічну роботу за допомогою ідеального тонкого диска без урахування тертя та закручування сліду.

### Постановка задачі та контрольний об'єм

Розглянемо одновимірну модель ідеального проникного диска (модель диска-актуатора Ренкіна — Фруда — Бетца), розташованого перпендикулярно до напрямку руху нестисливого повітряного потоку з постійною густиною `ρ`.

Потік рухається крізь нерухому струминну трубку змінного перерізу. Позначимо три ключові перерізи вздовж осі потоку:
1. **Переріз 1 (далеко перед ротором)**: площа перерізу струминної трубки `A₁`, швидкість незбуреного набігаючого вітру `v₁`, статичний тиск дорівнює атмосферному `p₀`.
2. **Переріз ротора (активна площина)**: площа, що описується лопатями, `A`, швидкість повітря безпосередньо в площині ротора `v_rotor`, статичний тиск перед самим диском `p⁺`, а за диском `p⁻` (виникає стрибок тиску `Δp = p⁺ − p⁻ > 0`).
3. **Переріз 2 (далеко за ротором у збуреному сліді / wake)**: площа струминної трубки `A₂`, залишкова швидкість уповільненого потоку `v₂`, статичний тиск знову вирівнюється до атмосферного `p₀`.

Повітря вважається нестисливим плином, тому масова витрата повітря `dm/dt` крізь будь-який поперечний переріз струминної трубки є строго однаковою за законом нерозривності:

```
dm/dt
= ρ · A₁ · v₁       [масова витрата у перерізі 1 перед ротором]
= ρ · A · v_rotor   [масова витрата крізь площину самого ротора]
= ρ · A₂ · v₂       [масова витрата у сліді далеко за ротором]
```

Оскільки повітря сповільнюється (`v₂ < v_rotor < v₁`), площа струминної трубки за законом нерозривності неминуче розширюється: `A₁ < A < A₂`.

### Зв'язок швидкості в площині ротора зі швидкостями потоку

Знайдемо силу осьового тиску (аеродинамічну тягу `T`), яку потік чинить на диск ротора, двома незалежними шляхами: через зміну кількості руху та через перепад статичного тиску за рівнянням Бернуллі.

Згідно з теоремою про зміну імпульсу (другий закон Ньютона для стаціонарного потоку контрольного об'єму), сила, що діє на ротор, дорівнює різниці потоків імпульсу на вході та виході:

```
T
= (dm/dt) · (v₁ − v₂)            [різниця імпульсів на вході й виході за одиницю часу]
= ρ · A · v_rotor · (v₁ − v₂)   [підставили масову витрату крізь диск ротора]
```

З іншого боку, та сама тяга створюється інтегралом стрибка статичного тиску `Δp` по площі диска `A`:

```
T = (p⁺ − p⁻) · A
```

Застосуємо закон збереження енергії нестисливого струменя через [динамічний тиск](root:ph-mechanics/dynamic-pressure) (рівняння Бернуллі) окремо для двох незбурених ділянок течії — до диска (від перерізу 1 до точки перед ротором) і після диска (від точки відразу за ротором до перерізу 2 у сліді):

```
p₀ + ½·ρ·v₁²
= p⁺ + ½·ρ·v_rotor²              [рівняння Бернуллі на ділянці до ротора]

p⁺ − p₀
= ½·ρ·(v₁² − v_rotor²)           [виразили надлишковий тиск перед диском]
```

Аналогічно для ділянки за ротором:

```
p⁻ + ½·ρ·v_rotor²
= p₀ + ½·ρ·v₂²                  [рівняння Бернуллі на ділянці за ротором]

p₀ − p⁻
= ½·ρ·(v_rotor² − v₂²)           [виразили розрідження за диском]
```

Додамо ці два рівняння й знайдемо повний стрибок статичного тиску на диску `Δp`:

```
Δp
= p⁺ − p⁻                        [означення повного стрибка тиску]
= (p⁺ − p₀) + (p₀ − p⁻)          [додали та відняли атмосферний тиск p₀]
= ½·ρ·(v₁² − v_rotor²) + ½·ρ·(v_rotor² − v₂²) [підставили різниці тисків]
= ½·ρ·(v₁² − v₂²)                [скоротили внутрішню швидкість v_rotor²]
```

Підставимо отриманий перепад тиску у вираз для аеродинамічної тяги:

```
T
= Δp · A                         [означення сили через тиск і площу]
= ½·ρ·A·(v₁² − v₂²)             [підставили знайдений перепад тиску Δp]
```

Тепер прирівняємо два вирази для сили тяги `T` (через імпульс і через Бернуллі):

```
ρ · A · v_rotor · (v₁ − v₂)
= ½ · ρ · A · (v₁² − v₂²)        [рівність сили тяги за імпульсом і за тиском]
= ½ · ρ · A · (v₁ − v₂) · (v₁ + v₂) [розклали різницю квадратів як добуток]
```

Скоротимо обидві частини рівняння на `ρ · A · (v₁ − v₂)` (оскільки `v₁ ≠ v₂` за наявності гальмування):

```
v_rotor
= ½ · (v₁ + v₂)                  [швидкість у площині диска є середнім арифметичним]
```

Це ключовий результат: швидкість повітря безпосередньо в площині ротора дорівнює півсумі швидкості набігаючого вітру далеко попереду та швидкості уповільненого сліду далеко позаду.

### Коефіцієнт осьового гальмування

Введемо безрозмірний коефіцієнт осьового гальмування (або коефіцієнт індукції швидкості) `a`, який показує, на яку частку сповільнюється потік при підході до диска:

```
a = (v₁ − v_rotor) / v₁
```

Звідси швидкість у площині ротора виражається через `a`:

```
v_rotor = v₁ · (1 − a)
```

Оскільки ми довели, що `v_rotor = ½·(v₁ + v₂)`, знайдемо швидкість у сліді `v₂`:

```
½ · (v₁ + v₂) = v₁ · (1 − a)
v₁ + v₂ = 2·v₁ · (1 − a)
v₂
= 2·v₁·(1 − a) − v₁              [перенесли v₁ у праву частину]
= v₁ · (2 − 2a − 1)              [розкрили дужки й згрупували доданки]
= v₁ · (1 − 2a)                  [кінцевий вираз швидкості у віддаленому сліді]
```

Уповільнення швидкості у віддаленому сліді вдвічі більше за уповільнення в площині ротора (`2a` проти `a`). Це накладає фізичне обмеження: при `a = 0.5` швидкість за ротором падає до нуля (`v₂ = 0`), а при `a > 0.5` виникає реверс течії (потік у сліді розвертається назад), що порушує припущення ламінарної струминної трубки й переводить ротор у режим вітряного гальма з розвиненим вихровим кільцем.

### Потужність та коефіцієнт використання енергії вітру

Механічна потужність `P`, яку ротор вилучає з повітряного потоку, дорівнює добутку сили тяги `T` на швидкість повітря в площині диска `v_rotor`:

```
P
= T · v_rotor                    [робота сили тяги за одиницю часу]
= [ρ · A · v_rotor · (v₁ − v₂)] · v_rotor [підставили вираз для тяги T]
= ρ · A · v_rotor² · (v₁ − v₂)   [об'єднали множники v_rotor]
```

Підставимо у формулу швидкості через коефіцієнт гальмування `a` (`v_rotor = v₁·(1 − a)` та `v₁ − v₂ = 2a·v₁`):

```
P
= ρ · A · [v₁·(1 − a)]² · [2a·v₁] [підставили швидкості через фактор гальмування a]
= ρ · A · v₁² · (1 − a)² · 2a · v₁ [розкрили квадрат добутку]
= 2 · ρ · A · v₁³ · a · (1 − a)² [згрупували кубічну швидкість вітру]
```

Повна кінетична потужність непорушеного вітрового потоку `P_wind`, який проходить крізь площу `A` з початковою швидкістю `v₁`, дорівнює:

```
P_wind
= ½ · (dm₁/dt) · v₁²             [кінетична енергія маси повітря за одиницю часу]
= ½ · (ρ · A · v₁) · v₁²         [підставили витрату набігаючого потоку dm₁ = ρ·A·v₁]
= ½ · ρ · A · v₁³                [теоретичний потік енергії вітру крізь площу A]
```

Безрозмірний коефіцієнт потужності вітроротора `Cp` (*power coefficient*) визначається як відношення корисної потужності `P` до повної потужності вітру `P_wind`:

```
Cp(a)
= P / P_wind                     [означення коефіцієнта потужності]
= [2 · ρ · A · v₁³ · a · (1 − a)²] / [½ · ρ · A · v₁³] [підставили вирази P і P_wind]
= 4 · a · (1 − a)²               [скоротили однакові множники ρ, A та v₁³]
= 4 · a · (1 − 2a + a²)          [розкрили квадрат різниці]
= 4a − 8a² + 4a³                 [поліном залежності ККД від фактора гальмування]
```

### Знаходження максимуму: оптимум Бетца

Щоб знайти значення коефіцієнта гальмування `a`, при якому видобуток потужності досягає максимуму, візьмемо першу похідну функції `Cp(a)` за аргументом `a` і прирівняємо її до нуля:

```
dCp/da
= d/da (4a − 8a² + 4a³)          [похідна від полінома Cp]
= 4 − 16a + 12a²                 [диференціювання за степенями a]
= 12a² − 16a + 4                 [стандартний вигляд квадратного тричлена]
```

Прирівнюємо похідну до нуля для пошуку екстремумів:

```
12a² − 16a + 4 = 0               [умова екстремуму dCp/da = 0]
3a² − 4a + 1 = 0                 [поділили рівняння на 4]
(3a − 1) · (a − 1) = 0           [розкладання на лінійні множники]
```

Рівняння має два дійсні корені:
1. `a = 1` — потік повністю зупиняється в площині ротора (`v_rotor = 0`), витрата маси спадає до нуля, `Cp(1) = 4·1·0² = 0` (точка абсолютного мінімуму / блокування).
2. `a = 1/3` — потік уповільнюється на третину в площині ротора та на дві третини в дальньому сліді.

Перевіримо знак другої похідної в точці `a = 1/3`:

```
d²Cp/da²
= d/da (12a² − 16a + 4)
= 24a − 16
= 24·(1/3) − 16                  [підставили a = 1/3]
= 8 − 16
= −8 < 0                         [від'ємна друга похідна підтверджує строгий максимум]
```

### Граничне значення коефіцієнта Бетца

Підставимо оптимальне значення `a = 1/3` у формулу коефіцієнта потужності `Cp(a)`:

```
Cp_max
= 4 · (1/3) · (1 − 1/3)²         [підставили a = 1/3 у функцію 4·a·(1-a)²]
= 4/3 · (2/3)²                   [обчислили різницю в дужках]
= 4/3 · 4/9                      [піднесли до квадрата]
= 16/27                          [точне аналітичне значення межі Бетца]
≈ 0.592592...                    [десятковий дріб]
≈ 59.26%                         [теоретичний максимум у відсотках]
```

Оптимальні швидкості потоку для досягнення межі Бетца складають:
- Швидкість на роторі: `v_rotor = v₁ · (1 − 1/3) = (2/3) · v₁`
- Швидкість у сліді: `v₂ = v₁ · (1 − 2/3) = (1/3) · v₁`

Це означає, що ідеальний ротор уповільнює набігаючий вітер рівно на одну третину в своїй площині й на дві третини у віддаленому сліді. Жоден вітрогенератор у відкритому потоці не може перетворити в механічну роботу понад `16/27` (≈ 59.26%) кінетичної енергії набігаючого повітря.
