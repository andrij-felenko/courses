# 📋 Ніжки й увімкнення power-модуля

Готовий аналоговий power-модуль (PoL) оживляють лише кількома ніжками й одним резисторним дільником. Ось повна розпіновка типового модуля, формула, що задає вихідну напругу, і код, який вмикає шину та чекає на підтвердження «вихід у нормі» — контракт, за яким модуль підводять до живлення й керують ним із прошивки.

## Розпіновка

Зовні модуль навмисне простий — у звичайного аналогового PoL лише жменя ніжок, і вони майже завжди ті самі:

```
VIN  — вхід живлення (сюди вхідний конденсатор, упритул до ніжки)
GND  — спільна земля (силова й сигнальна сходяться під корпусом)
EN   — enable: подав «1» — модуль увімкнувся; до нього вішають
       старт за порогом входу й послідовність увімкнення шин
FB   — feedback: вхід зворотного зв'язку; дільник Rверх/Rниз
       від VOUT задає вихідну напругу
VOUT — вихід; сюди вихідний конденсатор
PG   — power-good: модуль сам каже «вихід у нормі»; цим сигналом
       дозволяють старт наступного чипа в системі
```

**EN** — це не просто «вкл/викл». У ніжки є свій поріг (типово близько 1 В), тож дільником від VIN на EN задають **напругу ввімкнення входу** (undervoltage lockout, UVLO): нижче порога модуль не стартує, і шина не «моргає» на просілому вході. Найпростіше — підтягнути EN на VIN через резистор, і модуль вмикається разом зі входом; лишати ніжку висіти в повітрі не можна — стан буде невизначений.

**FB** тримає точність виходу: струм крізь дільник Rверх/Rниз беруть набагато більшим за струм витоку ніжки, але не марнотратним — типово десятки мікроампер, тобто Rниз у одиниці-десятки кОм.

## «Перший байт»: мінімум, щоб ожив

«Перший байт» — мінімум, щоб модуль ожив, — виглядає так: вхідний конденсатор на VIN, вихідний на VOUT, дільник на FB, EN підтягнутий на дозвіл (часто його лишають на VIN через резистор). Усе. Напругу задає один дільник:

```
Vвих = Vfb·(1 + Rверх/Rниз)
```

де Vfb — опорна напруга зворотного зв'язку з даташита (типово 0.6 чи 0.8 В).

**Приклад (вихід 3.3 В).** Хай Vfb = 0.6 В, нижній резистор Rниз = 10 кОм. Тоді верхній:

```
Rверх = Rниз·(Vвих/Vfb − 1)
Rверх = 10·(3.3/0.6 − 1) = 10·4.5 = 45 кОм   → беремо найближчий 45.3 кОм (ряд E96)
```

## Увімкнення й power-good

Після дозволу на EN модуль не видає напругу миттєво: усередині працює **м'який старт** (soft-start), що плавно піднімає вихід за сотні мікросекунд — одиниці мілісекунд, аби не смикати вхід кидком струму на заряд вихідних конденсаторів. Ніжка **PG** підіймається в «норму» лише тоді, коли вихід дійшов до вікна допуску (типово 90–95 % номіналу), ще й із невеликою затримкою внутрішнього таймера. Саме тому PG — природний дозвіл **старту наступної шини**: у системі з кількома живленнями PG однієї шини заводять на EN наступної, і вони встають **по черзі**, у заданому порядку.

Одна тонкість монтажу: PG майже завжди — вихід із **відкритим стоком** (open-drain), тож на нього потрібен підтягувальний резистор до логічної шини мікроконтролера; без нього замість чіткого «норма/не норма» на вході читатиметься сміття.

У прошивці модуль найчастіше нічим не «програмують» — він аналоговий і працює сам. Код торкається його лише через дискретні лінії EN і PG:

```c
// Увімкнути шину живлення й дочекатися, поки модуль підтвердить норму.
gpio_set(PWR_EN, 1);                 // подали дозвіл на ніжку EN модуля

uint32_t t0 = millis();
while (!gpio_read(PWR_PG)) {         // чекаємо сигнал power-good від модуля
    if (millis() - t0 > 10) {        // 10 мс не піднявся — щось не так
        fault(FAULT_RAIL_3V3);       // у захист: шина не вийшла на норму
        break;
    }
}
// PG = 1 → вихід у межах; тепер можна запускати наступний чип
```

Поріг у 10 мс беруть із запасом над сумою м'якого старту й затримки PG із даташита: не піднялася шина за цей час — то коротке замикання, перевантаження чи брак входу, і замість роботи «наосліп» код одразу йде в захист.

Цифрові PoL-модулі (із шиною PMBus) — окрема, складніша порода: там напругу, м'який старт і захисти справді задають **командами по шині**, і код уже пише регістри. Але для звичайної плати бери аналоговий: він простий рівно так, як описано вище.
