# 🧮 Розрахунок термоелектричного узгодження: тепловий подільник, ККД і точка MPP

Термоелектричний генератор (ТЕГ) є замкненою зв'язаною системою: електричний струм, що протікає через напівпровідникові ніжки, безпосередньо впливає на тепловий баланс через ефект Пельтьє та джоулів нагрів, а температурний перепад на ніжках визначає генеровану напругу. Спроба розрахувати електричне коло окремо від теплового призводить до похибки у 200–500% при оцінці реальної вихідної потужності.

## Тепловий баланс напівпровідникового стовпчика

Розглянемо термопару з двох ніжок (p-тип та n-тип) висотою `L` та площею поперечного перерізу `A`, затиснуту між гарячим спаєм із температурою `T_h` та холодним спаєм із температурою `T_c`.

Повний тепловий потік `Q_h`, що поглинається гарячим спаєм, складається з трьох фізичних складових:
1. Теплопровідність кристалічної ґратки та електронного газу за законом Фур'є: `Q_cond = K_teg · (T_h − T_c)`.
2. Тепловий потік Пельтьє, який переноситься носіями заряду при протіканні струму `I`: `Q_Peltier = N · S_pn · T_h · I`.
3. Повернення частини джоулевого тепла, яке виділяється всередині ніжок і дифундує порівну до гарячого та холодного кінців: `Q_Joule = 0.5 · I² · R_int`.

```
Q_h = K_teg · (T_h − T_c) + N · S_pn · T_h · I − 0.5 · I² · R_int
Q_c = K_teg · (T_h − T_c) + N · S_pn · T_c · I + 0.5 · I² · R_int
```

де:
- `N` — кількість послідовних термопар у модулі;
- `S_pn = S_p − S_n` — сумарний диференціальний коефіцієнт Зеєбека пари (`S_p > 0`, `S_n < 0`);
- `K_teg` — теплова провідність термомодуля, `K_teg = N · (kappa_p + kappa_n) · A / L`, де `kappa` — питома теплопровідність матеріалу, Вт/(м·К);
- `R_int` — електричний опір ніжок, `R_int = N · (rho_p + rho_n) · L / A + R_contact`, де `rho` — питомий електричний опір, Ом·м.

## Тепловий подільник: визначення реального перепаду ΔT

Джерело тепла має фіксовану температуру `T_src`, а навколишнє повітря — `T_amb`. Повна різниця температур у системі:

```
ΔT_system = T_src − T_amb
```

Між джерелом тепла та гарячою стороною напівпровідника існує паразитний тепловий опір контакту й пасти `Theta_hot`. Між холодною стороною та повітрям стоїть опір холодної пасти й радіатора `Theta_sink`. Власний тепловий опір модуля ТЕГ дорівнює `Theta_teg = 1 / K_teg`.

Сумарний тепловий опір системи:

```
Theta_total = Theta_hot + Theta_teg + Theta_sink
```

Тепловий потік `Q`, що проходить крізь ланцюг за умов холостого ходу (`I = 0`), становить:

```
Q = ΔT_system / Theta_total
  = (T_src − T_amb) / (Theta_hot + Theta_teg + Theta_sink)    [закон Ома для теплового кола]
```

Фактичний перепад температур `ΔT_teg` безпосередньо на напівпровідникових стовпчиках визначається формулою теплового подільника:

```
ΔT_teg = Q · Theta_teg
       = (T_src − T_amb) · [ Theta_teg / (Theta_hot + Theta_teg + Theta_sink) ]   [підстановка потоку Q]
```

Якщо модуль має високу теплопровідність (малий опір `Theta_teg = 1.5 К/Вт`), а радіатор замалий (`Theta_sink = 4.0 К/Вт`), то при загальному перепаді `ΔT_system = 60 К`:

```
ΔT_teg = 60 · [ 1.5 / (0.5 + 1.5 + 4.0) ]
       = 60 · [ 1.5 / 6.0 ]                                                        [сума теплових опорів]
       = 60 · 0.25                                                                 [коефіцієнт передачі подільника]
       = 15 К                                                                      [фактичний перепад на кристалі]
```

Три чверті доступного температурного напору губляться на радіаторі та термопасті ще до того, як тепло досягне робочого напівпровідника.

## Електричне узгодження та максимум корисної потужності

Холоста напруга ТЕГ лінійно залежить від фактичного перепаду `ΔT_teg`:

```
Voc = N · S_pn · ΔT_teg
```

При підключенні зовнішнього навантаження з опором `R_load` електричний струм у колі дорівнює:

```
I = Voc / (R_int + R_load)
```

Корисна електрична потужність `P_load`, що виділяється на навантаженні:

```
P_load = I² · R_load
       = Voc² · R_load / (R_int + R_load)²
```

Знайдемо умову максимуму потужності, взявши похідну `dP_load / dR_load` та прирівнявши її до нуля:

```
dP_load / dR_load
= Voc² · [ (R_int + R_load)² − 2 · R_load · (R_int + R_load) ] / (R_int + R_load)⁴   [правило диференціювання дробу]
= Voc² · [ (R_int + R_load) · (R_int + R_load − 2 · R_load) ] / (R_int + R_load)⁴    [винесення спільного множника]
= Voc² · (R_int − R_load) / (R_int + R_load)³                                        [скорочення на (R_int + R_load)]
= 0                                                                                  [умова екстремуму функції]
```

Звідси випливає фундаментальна умова узгодження за імпедансом:

```
R_load = R_int
```

Підставивши `R_load = R_int` у вираз для потужності, отримуємо максимальну вихідну потужність (MPP):

```
P_max = Voc² · R_int / (R_int + R_int)²    [підстановка умови R_load = R_int]
      = Voc² · R_int / (4 · R_int²)        [розкриття квадрата знаменника]
      = Voc² / (4 · R_int)                 [скорочення на R_int]
```

Напруга на навантаженні в точці MPP становить рівно половину напруги холостого ходу:

```
V_mpp = Voc / 2
```

## Оптимальна геометрія термопари та зв'язок параметрів

Висота стовпчика `L` та площа його перерізу `A` входять у тепловий та електричний опір із протилежними наслідками:
- Збільшення висоти `L` збільшує тепловий опір `Theta_teg`, що збільшує `ΔT_teg` на модулі (корисно для напруги `Voc`).
- Проте збільшення `L` водночас пропорційно збільшує електричний внутрішній опір `R_int`, що зменшує струм.

Виразимо вихідну потужність через питомі властивості матеріалу та геометрію:

```
Voc = N · S_pn · ΔT_system · [ (L / (N · 2 · A · kappa)) / (Theta_sink + L / (N · 2 · A · kappa)) ]
R_int = N · 2 · rho · (L / A)
```

де прийнято `kappa_p ≈ kappa_n = kappa` та `rho_p ≈ rho_n = rho`.

Підставивши вирази у `P_max = Voc² / (4 · R_int)`, отримаємо функцію, яка має чіткий максимум за відношенням `L / A`. Максимальна потужність генератора досягається за умови теплового узгодження модуля з радіатором:

```
Theta_teg = Theta_sink
```

Тобто тепловий опір генератора повинен дорівнювати тепловому опору системи охолодження. Якщо тепловий опір радіатора фіксований, оптимальна висота ніжок:

```
L_opt = 2 · N · A · kappa · Theta_sink
```

## Термоелектричний коефіцієнт корисної дії та добротність zT

Коефіцієнт корисної дії термогенератора `eta` визначається як відношення електричної потужності `P_load` до теплового потоку на гарячій стороні `Q_h`:

```
eta = P_load / Q_h
```

Максимальний термодинамічний ККД обмежується циклом Карно `eta_Carnot = (T_h − T_c) / T_h`. Реальний ККД ТЕГ виражається через термодинамічну межу Карно та безрозмірну термоелектричну добротність `zT_avg`:

```
zT_avg = (S_pn² · T_avg) / (rho · kappa)
```

де `T_avg = (T_h + T_c) / 2`.

За умови оптимального електричного узгодження (`R_load = R_int · sqrt(1 + zT_avg)` з урахуванням зворотного ефекту Пельтьє):

```
eta_max = eta_Carnot · [ (sqrt(1 + zT_avg) − 1) / (sqrt(1 + zT_avg) + T_c / T_h) ]
```

## Динаміка перехідних процесів та теплова ємність

При стрибкоподібній зміні температури джерела тепла `T_src` (наприклад, увімкнення технологічного обладнання чи пуск двигуна) напруга на виході ТЕГ установлюється не миттєво. Швидкість реакції визначається тепловою ємністю `C_th` керамічних пластин і напівпровідникових стовпчиків:

```
C_th = m_ceramic · c_ceramic + m_pellets · c_pellets
```

де `m` — маса компонентів у кілограмах, `c` — питома теплоємність матеріалу (для `Bi₂Te₃` питома теплоємність `c ≈ 154 Дж/(кг·К)`, густина `7700 кг/м³`).

Часова стала встановлення теплового градієнта `tau_th`:

```
tau_th = Theta_total · C_th
```

Для стандартного модуля розміром 40×40 мм з алюмінієвою керамікою `Al₂O₃` теплова ємність становить приблизно `C_th ≈ 4–8 Дж/К`. При загальному тепловому опорі системи `Theta_total = 5 К/Вт` часова стала перехідного процесу становить `tau_th = 20–40 с`. Це означає, що імпульсні сплески тепла тривалістю менше 1–2 секунд практично не створюють вихідної напруги на виході генератора, оскільки тепло поглинається теплоємністю конструкції без формування градієнта на ніжках.

## Числовий приклад розрахунку системи збирання тепла

Розрахуємо параметри реального модуля збирання енергії (127 пар `Bi₂Te₃`, розмір 40×40 мм) на трубі гарячого водопостачання:
- Температура труби: `T_src = 75 °C = 348.15 К`;
- Температура повітря: `T_amb = 25 °C = 298.15 К`;
- Загальний перепад: `ΔT_system = 50 К`;
- Тепловий опір модуля: `Theta_teg = 1.8 К/Вт`;
- Тепловий опір пасти (дві сторони): `Theta_hot + Theta_cold = 0.4 К/Вт`;
- Тепловий опір ребристого радіатора природної конвекції: `Theta_sink = 2.8 К/Вт`;
- Коефіцієнт Зеєбека модуля: `S_module = N · S_pn = 127 · 400 мкВ/К = 0.0508 В/К`;
- Внутрішній електричний опір: `R_int = 2.4 Ом`.

1. Розрахунок теплового подільника:

```
Theta_total = 0.4 + 1.8 + 2.8
            = 5.0 К/Вт                                                        [сумарний тепловий опір]

Q = 50 / 5.0
  = 10.0 Вт                                                                   [наскрізний тепловий потік]

ΔT_teg = 10.0 · 1.8
       = 18.0 К                                                               [корисний перепад на кристалі]
```

2. Розрахунок електричних параметрів:

```
Voc = 0.0508 · 18.0
    ≈ 0.9144 В                                                                [напруга холостого ходу]

V_mpp = 0.9144 / 2
      = 0.4572 В                                                              [робоча напруга на MPP]

P_max = 0.9144² / (4 · 2.4)
      = 0.8361 / 9.6                                                          [квадрат напруги ділений на 4·R]
      ≈ 0.0871 Вт  (87.1 мВт)                                                 [максимальна вихідна потужність]
```

3. Розрахунок реального ККД установки:

```
eta_real = P_max / Q
         = 0.0871 / 10.0                                                      [відношення електрики до тепла]
         = 0.00871  (0.871%)                                                  [системний ККД установки]
```

Незважаючи на ККД менше 1%, вихідної потужності `87.1 мВт` більш ніж достатньо для живлення сучасного мікроконтролера з бездротовим передавачем (наприклад, модуль LoRaWAN або BLE, який у середньому споживає лише 0.05–0.5 мВт).
