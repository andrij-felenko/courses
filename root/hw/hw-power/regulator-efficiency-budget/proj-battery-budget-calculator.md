# ⚙️ Калькулятор енергетичного бюджету та оцінки часу автономності

Розрахунок тривалості автономної роботи акумуляторного пристрою на основі простого середнього струму або паспортного ККД перетворювача призводить до помилок в оцінці часу життя в рази. Практичний калькулятор енергетичного бюджету моделює поведінку системи як послідовність дискретних станів навантаження, застосовує нелінійну криву втрат стабілізатора для кожного стану окремо та враховує реальні неідеальності акумуляторної батареї.

## Чому табличні інженерні розрахунки дають хибні результати

Більшість розробників автономних пристроїв починають розрахунок енергетичного бюджету зі складання електронної таблиці, де для кожного вузла схеми (мікроконтролера, радіомодуля, сенсорів, Flash-пам'яті) вказується струм споживання та тривалість активності. Після цього обчислюється середньозважений струм навантаження `I_load_avg = ∑ (I_i · t_i) / T_cycle`, який потім ділиться на паспортний ККД регулятора (наприклад, `η = 90%`), взятий з титульної сторінки даташита.

Цей спрощений підхід містить три критичні системні помилки:

1. **Ігнорування нелінійності кривої ККД:** імпульсний перетворювач має паспортний ККД `90...95%` лише в обмеженому діапазоні струмів (зазвичай від `10 мА` до `500 мА`). У фазі глибокого сну при струмі навантаження `10...50 мкА` ККД стандартного перетворювача обвалюється до `10...30%` через переважання власного струму спокою кіл керування (`I_q`) та втрат на перезаряджання затворів силових ключів. Оскільки пристрій перебуває в режимі сну `99%` або `99.9%` часу, усереднення за високим ККД активного стану дає завищену в 3–5 разів оцінку автономності.
2. **Неврахування динаміки розрядної кривої акумулятора:** робоча напруга літій-іонного або літій-тіонілхлоридного елемента не є константою. Протягом життєвого циклу напруга Li-ion акумулятора змінюється від `4.2 В` (повний заряд) до `3.0 В` (повний розряд). Для LDO-регулятора це означає, що миттєвий ККД `η ≈ V_out / V_in` безперервно зростає від `78.5%` на початку розряду до `94.3%` наприкінці (при вихідній напрузі `3.3 В`), тоді як для Buck-перетворювача ККД, навпаки, дещо падає або стабілізується.
3. **Ігнорування внутрішнього опору та імпульсного просідання напруги:** під час потужного сплеску струму (наприклад, вихід у радіоефір зі струмом `100...300 мА`) внутрішній опір батареї `R_bat` та опір захисних ключів BMS викликають миттєвий спад напруги `ΔV = I_peak · R_bat`. Якщо батарея частково розряджена, це просідання може перетнути поріг відключення регулятора (Dropout) або викликати скидання мікроконтролера за сигналом Brownout Reset задовго до вичерпання хімічної ємності елемента.

## Архітектура моделі та математичний алгоритм

Програмний калькулятор усуває ці обмеження шляхом почергового моделювання кожної фази робочого циклу з використанням фізичних рівнянь втрат.

```
+-------------------------------------------------------------------------+
|                  ПРОФІЛЬ РОБОЧОГО ЦИКЛУ НАВАНТАЖЕННЯ                    |
|  [Фаза 1: Сон] -> [Фаза 2: Сенсор] -> [Фаза 3: Обчислення] -> [Фаза 4: TX]  |
+-------------------------------------------------------------------------+
                                    |
                                    v
+-------------------------------------------------------------------------+
|                 МОДЕЛЬ ВТРАТ РЕГУЛЯТОРА НАПРУГИ                         |
|   Обчислення миттєвих P_loss, P_in та η_i окремо для кожної фази       |
+-------------------------------------------------------------------------+
                                    |
                                    v
+-------------------------------------------------------------------------+
|                  ІНТЕГРАТОР ЕНЕРГІЇ ТА БЮДЖЕТУ БАТАРЕЇ                  |
|   Розрахунок E_total_in, η_avg, просідання напруги, часу автономності   |
+-------------------------------------------------------------------------+
```

### 1. Модель профілю навантаження (State Profile)

Профіль пристрою описується послідовністю дискретних фаз. Кожна `i`-та фаза містить:
- Текстову назву стану для звітності;
- Тривалість фази `t_i` у мілісекундах;
- Струм навантаження `I_out_i` у міліамперах;
- Вихідну напругу шини живлення `V_out` у вольтах.

Сумарний період повторення циклу:

```
T_cycle = ∑ [i=1..N] t_i
```

### 2. Математичні моделі регуляторів напруги

Калькулятор підтримує чотири класи стабілізаторів:

- **Лінійний стабілізатор (LDO):**
  Втрати складаються з теплового розсіювання на спаді напруги регулювального транзистора та живлення внутрішніх опорних джерел:
  ```
  P_loss_ldo = (V_in - V_out) · I_out + V_in · I_q
  P_in_ldo   = V_out · I_out + P_loss_ldo = V_in · (I_out + I_q)
  ```

- **Понижувальний перетворювач з підтримкою PFM (Buck PFM):**
  У режимі частотно-імпульсної модуляції перетворювач пропускає такти комутації при малих струмах, завдяки чому комутаційні втрати масштабуються майже лінійно зі струмом навантаження:
  ```
  P_loss_buck_pfm = V_in · I_q + k_sw · I_out + R_eq · I_out²
  ```
  де `k_sw` — коефіцієнт динамічних комутаційних втрат (Вт/А), `R_eq` — сумарний опір транзисторів і котушки індуктивності (Ом).

- **Понижувальний перетворювач з постійною частотою ШІМ (Buck PWM):**
  Перетворювач продовжує перемикати ключі на повній робочій частоті `f_sw` незалежно від струму навантаження, що створює сталі фонові комутаційні втрати `P_fix_pwm`:
  ```
  P_loss_buck_pwm = P_fix_pwm + k_sw · I_out + R_eq · I_out²
  ```

- **Синхронний 4-ключовий Buck-Boost:**
  Враховує подвоєння комутаційних та провідних втрат у зоні рівності вхідної та вихідної напруг `V_in ≈ V_out`:
  ```
  P_loss_buck_boost = V_in · I_q + 1.8 · k_sw · I_out + 1.8 · R_eq · I_out²
  ```

### 3. Модель акумулятора та інтеграція енергії

Корисна енергія акумулятора `E_bat_usable` (в Джоулях) розраховується з урахуванням доступної глибини розряду (DoD, зазвичай `0.85...0.95` для літієвих систем, щоб уникнути деградації структури катода):

```
E_bat_usable = C_nominal_Ah · V_bat_nominal · 3600 · DoD_factor
```

Фоновий річний саморозряд батареї перераховується в еквівалентну потужність постійного витоку:

```
P_self_discharge = (E_bat_usable · (SelfDischarge_pct_year / 100)) / (365.25 · 86400)
```

Повна середня потужність, яка відбирається від хімічного джерела:

```
P_in_avg = (∑ [i=1..N] P_in_i · t_i) / T_cycle
P_total_draw = P_in_avg + P_self_discharge
```

Розрахунковий час автономної роботи в секундах, днях та роках:

```
T_life_seconds = E_bat_usable / P_total_draw
T_life_days    = T_life_seconds / 86400
T_life_years   = T_life_days / 365.25
```

## Розбір чотирьох практичних інженерних кейсів

### Кейс 1: Лічильник води з вимогою 10 років автономності

Пристрій живиться від неперезаряджуваного літій-тіонілхлоридного елемента Li-SOCl2 (тип ER14505, ємність `2700 мА·год`, номінальна напруга `3.6 В`). Профіль роботи: сон зі струмом `2.5 мкА` протягом `59.8 с` та імпульс зчитування ультразвукового витратоміра зі струмом `18 мА` тривалістю `200 мс`. Робоча напруга сенсорного тракту — `3.0 В`.

- **Варіант зі звичайним LDO (`I_q = 15 мкА`):** сумарний струм сну з батареї складає `2.5 + 15 = 17.5 мкА`. Середній струм за цикл — `77.4 мкА`. З урахуванням річного саморозряду `1%` елемент `2700 мА·год` розряджається за **3.98 року**, що повністю провалює технічне завдання.
- **Варіант з ультрананопотужним LDO (`I_q = 0.025 мкА`):** струм сну становить `2.525 мкА`. Середній струм за цикл знижується до `62.5 мкА`. Час автономності досягає **11.4 року**.
- **Висновок кейсу:** заміна одного компонента вартістю $0.15 збільшує термін експлуатації виробу майже втричі без збільшення габаритів батареї.

### Кейс 2: Носимий фітнес-трекер на акумуляторі 70 мА·год

Компактний пристрій містить Li-Po акумулятор `70 мА·год` (`3.7 В`), оптичний пульсометр PPG (`15 мА`, робота `50 мс` щосекунди), акселерометр (`20 мкА` постійно), Bluetooth LE мікроконтролер (`10 мкА` в сні, `8 мА` під час передачі реклами `20 мс` кожні `500 мс`). Напруга внутрішньої шини — `1.8 В`.

Оскільки перепад напруг великий (`3.7 В → 1.8 В`), граничний ККД лінійного стабілізатора становить лише `1.8 / 3.7 = 48.6%`. Застосування LDO навіть із нульовим `I_q` знищує понад половину енергії крихітного акумулятора, забезпечуючи автономність лише **3.8 дня**.

Застосування високочастотного мініатюрного Buck-перетворювача з PFM-режимом (наприклад, з робочим ККД `88%` при струмі `15 мА` та струмом спокою `1.2 мкА` у сні) підвищує середньозважений ККД системи до `84.2%`. Це подовжує час роботи трекера до **6.5 днів**, дозволяючи користувачеві заряджати пристрій раз на тиждень замість двох разів.

### Кейс 3: Промисловий датчик вібрації з радіоканалом LoRaWAN

Датчик живиться від двох лужних батарейок AA (`V_in = 2.0...3.0 В`). Напруга живлення радіотрансивера Semtech SX1262 становить `3.3 В`. Оскільки вхідна напруга завжди нижча за вихідну, необхідний підвищувальний Boost-перетворювач.

Під час передачі пакета на максимальній потужності `+22 dBm` струм навантаження досягає `I_out = 120 мА`. При розрядженій батареї `V_in = 2.0 В` коефіцієнт заповнення становить:

```
D = 1 - (V_in · η) / V_out = 1 - (2.0 · 0.90) / 3.3 = 1 - 0.545 = 0.455
```

Струм, який відбирається від батареї: `I_in = (3.3 · 0.120) / (2.0 · 0.90) = 0.220 А = 220 мА`.
На внутрішньому опорі двох старих батарейок AA (`R_int = 2 · 0.4 = 0.8 Ом`) виникає миттєва просадка напруги:

```
ΔV_drop = 0.220 А · 0.8 Ом = 0.176 В
```

Напруга на клемах перетворювача падає до `2.0 - 0.176 = 1.824 В`. Щоб запобігти передчасному вимкненню за сигналом UVLO (англ. *Under-Voltage Lockout*), схема вимагає паралельного встановлення танталового або полімерного конденсатора великої ємності (`220...470 мкФ`) безпосередньо біля входу перетворювача, який бере на себе імпульсний струм тривалістю `50 мс`.

### Кейс 4: Стільниковий трекер активів (LTE-M / NB-IoT)

Стільниковий модем під час реєстрації в мережі споживає короткі пікові струми до `500 мА...1.5 А` тривалістю `2...5 мс`. Живлення здійснюється від акумулятора LiFePO4 (`V_nom = 3.2 В`, діапазон `3.6 В → 2.5 В`). Напруга модему — `3.3 В`.

Діапазон вхідної напруги перетинає вихідну, що вимагає вибору між 4-ключовим Buck-Boost або прямим живленням від акумулятора, якщо компоненти підтримують діапазон `2.5...3.6 В`. Калькулятор показує, що 4-ключовий Buck-Boost у зоні `3.2 В` має провал ККД до `82%` і струм спокою `30 мкА`. Пряме підключення компонентів із розширеним діапазоном живлення без регулятора усуває втрати взагалі, підвищуючи ефективність використання енергії до `99%` (лише втрати на проводах).

## Низькотемпературна деградація та моделювання роботи на морозі

Вуличні пристрої, датчики моніторингу сільськогосподарських угідь та трекери вантажів повинні функціонувати в діапазоні температур від `-20 °C` до `-40 °C`. Низька температура докорінно змінює фізичні параметри силового тракту:

1. **Сповільнення електрохімічної кінетики:** згідно з рівнянням Арреніуса, швидкість хімічних реакцій та рухливість іонів в електроліті батареї експоненційно падають. При `-20 °C` доступна ємність Li-ion акумулятора скорочується на `40...50%`, а внутрішній опір `R_int` зростає у `3...5` разів (від `0.15 Ом` до `0.75 Ом`).
2. **Катастрофічне просідання напруги під імпульсом:** якщо при кімнатній температурі імпульс `200 мА` викликає спад `ΔV = 0.2 · 0.15 = 30 мВ`, то на морозі `-20 °C` спад становить `ΔV = 0.2 · 0.75 = 150 мВ`. Якщо напруга частково розрядженого елемента дорівнює `3.4 В`, під імпульсом вона падає до `3.25 В`, що провокує раптовий перезапуск мікроконтролера.
3. **Зростання опору відкритих каналів польових транзисторів та діелектричних втрат:** хоча рухливість електронів у чистому кремнії на холоді зростає, еквівалентний послідовний опір електролітичних конденсаторів `ESR` зростає у `10...50` разів, що призводить до значного збільшення амплітуди пульсацій напруги на виході стабілізатора.
4. **Корекція в калькуляторі:** у модель батареї вводиться температурний коефіцієнт дератингу ємності `k_T_cap` та множник внутрішнього опору `k_T_esr`:
   ```
   C_usable_cold = C_nominal · usable_dod · k_T_cap(T_ambient)
   R_bat_cold = R_bat_nom · k_T_esr(T_ambient)
   ```

## Архітектурне секціонування доменів живлення

Найефективніший спосіб знизити споживання системи у фазі сну — це повне знеструмлення периферійних вузлів за допомогою керованих силових ключів (англ. *load switches*):

1. **Комутація шин живлення через P-MOSFET або інтегровані Load Switches:** замість того, щоб переводити датчики, зовнішню Flash-пам'ять та інтерфейсні мікросхеми (RS-485, CAN) у режим програмного Standby (де кожен із них продовжує споживати `1...10 мкА`), живлення всієї периферійної підсистеми розривається за допомогою інтегрованого ключа з наднизьким струмом витоку (`I_leak < 10 нА`).
2. **Контроль пускового струму (Inrush Current):** при увімкненні силового ключа розряджені блокувальні конденсатори периферійної шини (`C_load = 10...100 мкФ`) викликають стрибок струму `I_inrush = C_load · (dV / dt)`. Якщо ключ відкривається миттєво, пусковий струм може досягати кількох ампер, що створює різке просідання напруги на виході основного регулятора і викликає скидання мікроконтролера. Застосування ключів із керованою швидкістю наростання напруги (англ. *slew-rate controlled soft-start*) обмежує струм заряду на безпечному рівні:
   ```
   I_inrush = C_load · (V_out / t_rise)
   ```
   де `t_rise` — апаратно заданий час наростання напруги (зазвичай `0.5...2.0 мс`).
3. **Енергетична ціна вмикання домену:** кожне підключення знеструмленого домену неминуче витрачає енергію на заряджання його розподіленої ємності:
   ```
   E_charge = 0.5 · C_load · V_out²
   ```
   Якщо шина `3.3 В` із ємністю `47 мкФ` комутується занадто часто (наприклад, кожні `10 мс`), потужність втрат на перезаряджання становить `P_cap = 0.5 · (47 · 10⁻⁶) · (3.3)² · 100 = 25.6 мВт`, що повністю нівелює вигоду від вимикання домену. Повне вимикання живлення виправдане лише тоді, коли інтервал сну перевищує критичний час окупності `t_breakeven = E_charge / (V_out · I_standby)`.

## Програмні патерни оптимізації енергетичного бюджету

Програмне забезпечення мікроконтролера має такий самий вирішальний вплив на енергетичний бюджет, як і вибір топології заліза:

1. **Парадигма «Race to Sleep» (Швидше виконай — швидше засни):** розповсюдженою помилкою є зниження тактової частоти процесорного ядра (наприклад, робота на `2 МГц` замість `64 МГц`) з метою «зменшення струму». Хоча миттєвий струм споживання процесора при цьому падає, час виконання математичного алгоритму або шифрування зростає пропорційно. Оскільки енергія є добутком потужності на час (`E = P · t`), робота на максимальній частоті ядра з наступним негайним переходом у глибокий режим Stop/Standby споживає у 3–4 рази менше енергії батареї, ніж повільне виконання коду на зниженій частоті.
2. **Автономне апаратне збирання даних без пробудження ядра:** сучасні мікроконтролери містять автономні контролери прямого доступу до пам'яті (DMA) та периферійні інтерфейси з підтримкою низькоспоживаючих таймерів (Low-Power Timer). АЦП може самостійно виконувати серію вимірювань за таймером, записувати результати в оперативну пам'ять через DMA і генерувати переривання для пробудження основного процесора лише тоді, коли виміряне значення перевищить заданий поріг тривоги. Це скорочує коефіцієнт заповнення активного стану `Duty Cycle` з `1%` до `0.01%`.
3. **Динамічне масштабування напруги живлення ядра (DVS):** споживана потужність КМОН-цифрових схем прямо пропорційна квадрату напруги живлення:
   ```
   P_dynamic = C_sw · V_core² · f_clk
   ```
   Зниження напруги живлення ядра з `1.2 В` до `0.9 В` у періоди низької обчислювальної активності зменшує динамічні втрати на `1 - (0.9 / 1.2)² = 43.75%`.

## Діагностичний чекліст апаратних витоків струму

Під час фінального аудиту принципової схеми та трасування плати необхідно перевірити типові апаратні пастки витоку мікрострумів:

- **Підвішені цифрові входи (Floating Inputs):** вхідний каскад КМОН-логіки при невизначеному потенціалі (близькому до `V_dd / 2`) відкриває одночасно N-канальний та P-канальний транзистори інвертора, викликаючи наскрізний струм витоку від `10 мкА` до `100 мкА` на кожен невикористаний вивід мікроконтролера. Усі невикористані піни мають бути програмно налаштовані як аналогові входи або підтягнуті до шини живлення/землі.
- **Паразитне підживлення через захисні діоди (Phantom Powering):** якщо зовнішній сенсор знеструмлюється за допомогою силового ключа, але лінії інтерфейсу I2C/SPI залишаються підключеними до мікроконтролера з активними підтягуючими резисторами, струм тече через резистор підтяжки у захисний діод ESD знеструмленої мікросхеми. Це не тільки призводить до неконтрольованого витоку `0.5...2.0 мА`, але й викликає зависання шини або пошкодження кристала сенсора. Лінії інтерфейсу перед вимкненням домену повинні програмно переводитися у високоімпедансний стан (High-Z) або відключатися двонаправленими ізоляторами.
- **Спад ємності керамічних конденсаторів під постійною напругою (DC-Bias Effect):** керамічні багатошарові конденсатори (MLCC) класу діелектрика X5R/X7R у дрібних корпусах (0402, 0603) втрачають до `60...80%` своєї номінальної ємності при роботі під напругою, близькою до номінальної. Конденсатор `10 мкФ 6.3 В` на шині `3.3 В` реально має ємність лише `3.5 мкФ`. Це збільшує амплітуду пульсацій вихідної напруги імпульсного перетворювача, змушуючи його частіше виходити з режиму PFM і збільшуючи інтегральні комутаційні втрати.
- **Пасивація літій-тіонілхлоридних елементів (LiSOCl2 Voltage Delay):** під час тривалого зберігання або роботи на мікрострумах на поверхні літієвого анода утворюється захисна плівка хлориду літію, яка знижує струм саморозряду до `<1%/рік`. Проте під час раптового потужного імпульсу радіопередачі внутрішній опір елемента тимчасово зростає, викликаючи глибоке просідання напруги протягом перших `5...50 мс`. Для нейтралізації цього ефекту паралельно батареї встановлюють гібридний імпульсний конденсатор (HPC) або суперконденсатор з низьким струмом витоку.

## Інтеграція систем енергетичного збору (Energy Harvesting)

Для досягнення практично необмеженої автономності сенсорних вузлів первинну батарею доповнюють перетворювачами відновлюваної енергії навколишнього середовища: сонячними фотоелементами, термоелектричними генераторами (TEG) або п'єзоелектричними вібраційними перетворювачами.

Енергетичний калькулятор розширюється рівнянням балансу збирання енергії:

1. **Модель надходження потужності:** середньодобова зібрана енергія `E_harvest` розраховується з урахуванням площі фотоелемента `S_cm2`, освітленості (люкси або `Вт/м²`) та ККД спеціалізованого перетворювача збирання енергії (англ. *Harvesting PMIC*, наприклад, BQ25570 або AEM10941):
   ```
   P_harvest_avg = P_solar_peak · (Sun_Hours_Day / 24) · η_mppt
   ```
2. **Буферизація в суперконденсаторі:** для накопичення енергії та згладжування піків радіопередачі паралельно підключають іоністор (суперконденсатор) ємністю `0.1...1.0 Ф`. На відміну від хімічних акумуляторів, іоністори мають необмежений ресурс циклів перезаряджання (>500 000) та зберігають працездатність при екстремальних температурах від `-40 °C` до `+85 °C`.
3. **Критерій енергетичної автономності (Energy Neutrality):** система досягає повної незалежності від первинної батареї, якщо зібрана енергія строго перевищує сумарні системні втрати:
   ```
   E_harvest_day > E_total_in_day + E_leakage_cap_day
   ```
   де `E_leakage_cap_day` — енергія власного струму витоку суперконденсатора (`1...5 мкА`). Якщо ця умова виконується, розрахунковий термін служби пристрою обмежується не вичерпанням хімічного заряду, а виключно фізичним старінням компонентів друкованої плати (15–20 років).
