# 🧮 Математична модель втрат регулятора та інтегральний ККД

Аналітичний розрахунок балансу потужності, математичний розклад кривої ефективності на складові втрат, виведення еквівалентного середньозваженого ККД, розрахунок граничного коефіцієнта підсилення Boost-перетворювача та динамічної теплової моделі кристала дають змогу розрахувати автономність і надійність пристрою без тривалих натурних випробувань.

## Баланс потужності та аналітична модель LDO

Лінійний стабілізатор з малим спадом напруги (англ. *Low-Dropout Regulator*, LDO) регулює вихідну напругу за рахунок керованого динамічного опору прохідного транзистора, що працює в активній (лінійній) області.

Вхідний струм стабілізатора `I_in` складається зі струму, переданого в навантаження `I_out`, та власного струму спокою внутрішніх кіл керування (компаратора, джерела опорної напруги, дільника зворотного зв'язку, підсилювача похибки) `I_q` (англ. *quiescent current*, від лат. *quiescere* — спочивати):

```
I_in = I_out + I_q
```

Повна електрична потужність `P_in`, яку регулятор відбирає від первинного джерела живлення:

```
P_in = V_in · I_in
     = V_in · (I_out + I_q)                  [підстановка I_in = I_out + I_q]
     = V_in · I_out + V_in · I_q            [розкриття дужок]
```

Корисна вихідна потужність `P_out`, що надходить безпосередньо у навантаження:

```
P_out = V_out · I_out
```

Потужність втрат `P_loss`, яка повністю розсіюється на кристалі мікросхеми у вигляді тепла:

```
P_loss = P_in - P_out                        [закон збереження енергії]
       = V_in · I_out + V_in · I_q - V_out · I_out  [підстановка P_in та P_out]
       = (V_in - V_out) · I_out + V_in · I_q [групування за спільним множником I_out]
```

Перший доданок `(V_in - V_out) · I_out` описує провідні втрати регулювального ключа на спаді напруги (англ. *pass element drop*), а другий доданок `V_in · I_q` — фонові втрати живлення внутрішньої схеми керування.

Коефіцієнт корисної дії лінійного регулятора `η_LDO` (від лат. *efficere* — здійснювати) визначається як відношення корисної потужності до повної спожитої:

```
η_LDO = P_out / P_in
      = (V_out · I_out) / (V_in · (I_out + I_q))
```

Поділивши чисельник і знаменник на `I_out` (за умови `I_out > 0`), отримуємо залежність ККД від відношення напруг та співвідношення струмів:

```
η_LDO = (V_out / V_in) · (1 / (1 + I_q / I_out))
```

При помірних та великих струмах навантаження, коли `I_out >> I_q` (наприклад, `I_out = 100 мА`, а `I_q = 1 мкА`, тобто `I_q / I_out = 10⁻⁵`):

```
1 / (1 + I_q / I_out) ≈ 1
η_LDO ≈ V_out / V_in
```

Теоретична максимальна ефективність будь-якого лінійного регулятора жорстко обмежена відношенням вихідної напруги до вхідної. Якщо лінійний регулятор живить мікроконтролер з напругою `3.3 В` від джерела `5.0 В`, його граничний ККД навіть при нульовому струмі спокою не може перевищити `3.3 / 5.0 = 66.0%`. Решта `34.0%` енергії незворотно перетворюється на тепло.

При мікрострумах, коли струм навантаження стає сумірним зі струмом спокою (`I_out ~ I_q` або `I_out < I_q`), знаменник починає визначатися величиною `I_q`, і ККД лінійно спадає до нуля:

```
lim (I_out → 0) η_LDO = lim (I_out → 0) [ (V_out · I_out) / (V_in · I_q) ] = 0
```

## Поліноміальна модель втрат імпульсного перетворювача

Імпульсний перетворювач (наприклад, понижувальний Buck-перетворювач) передає енергію порціями за рахунок періодичного перемикання силових транзисторів і накопичення енергії в магнітному полі індуктивності `L`.

Повні втрати потужності імпульсного перетворювача `P_loss` розкладаються на три фундаментальні складові, що мають різну функціональну залежність від струму навантаження `I_out`:

```
P_loss(I_out) = P_fix + k_sw · I_out + R_eq · I_out²
```

### 1. Статичні та фіксовані втрати `P_fix`

Фіксовані втрати не залежать від струму навантаження. Вони складаються з трьох основних процесів:

1. Втрати струму спокою внутрішніх аналогових блоків (джерело опорної напруги, компаратор зворотного зв'язку, підсилювач похибки):
   ```
   P_q = V_in · I_q
   ```
2. Втрати на перезаряджання ємностей затворів силових польових транзисторів (англ. *gate drive losses*):
   ```
   P_gate = Q_g_tot · V_drv · f_sw
   ```
   де `Q_g_tot` — сумарний заряд затворів верхнього та нижнього MOSFET (кулони), `V_drv` — амплітуда напруги керування затвором (вольти), `f_sw` — частота комутації (герци).
3. Втрати в осерді індуктивності на перемагнічування та вихрові струми (рівняння Штейнмеца):
   ```
   P_core = V_core · k_core · f_sw^α · (ΔB)^β
   ```
   де `V_core` — об'єм осердя, `ΔB` — розмах магнітної індукції в осерді, `α` та `β` — емпіричні коефіцієнти матеріалу фериту або композиту.

Сумарні фіксовані втрати перетворювача:

```
P_fix = V_in · I_q + Q_g_tot · V_drv · f_sw + P_core
```

### 2. Динамічні комутаційні втрати `k_sw · I_out`

Під час кожного перемикання силового транзистора напруга стік-витік `V_ds` та струм стоку `I_d` змінюються не миттєво. Протягом часу наростання `t_r` (англ. *rise time*) та часу спаду `t_f` (англ. *fall time*) транзистор одночасно перебуває під високою напругою і пропускає повний струм навантаження:

```
E_sw_turn_on  = 0.5 · V_in · I_out · t_r      [енергія втрат при вмиканні]
E_sw_turn_off = 0.5 · V_in · I_out · t_f      [енергія втрат при вимиканні]
```

Середня комутаційна потужність перекриття за період перемикання:

```
P_sw_overlap = (E_sw_turn_on + E_sw_turn_off) · f_sw
             = 0.5 · V_in · I_out · (t_r + t_f) · f_sw
```

Додатково виникають втрати на зворотне відновлення паразитного діода (англ. *reverse recovery losses*) нижнього ключа або синхронного випрямляча:

```
P_rr = Q_rr · V_in · f_sw
```

Звідси лінійний коефіцієнт комутаційних втрат `k_sw`:

```
k_sw = 0.5 · V_in · (t_r + t_f) · f_sw + (Q_rr · V_in · f_sw) / I_out
```

### 3. Провідні (омічні) втрати `R_eq · I_out²`

Провідні втрати виникають через протікання середньоквадратичного струму (RMS) через активні опори всіх компонентів силового тракту:

1. Опір відкритого каналу верхнього транзистора `R_ds_on_high`, через який струм тече протягом частки періоду `D = V_out / V_in` (коефіцієнт заповнення):
   ```
   P_cond_high = I_out² · D · R_ds_on_high
   ```
2. Опір відкритого каналу нижнього транзистора `R_ds_on_low`, через який струм тече протягом інтервалу `(1 - D)`:
   ```
   P_cond_low = I_out² · (1 - D) · R_ds_on_low
   ```
3. Опір обмотки котушки індуктивності постійному струму `DCR` (англ. *DC Resistance*):
   ```
   P_cond_L = I_out² · DCR
   ```
4. Втрати на еквівалентному послідовному опорі вихідного конденсатора `ESR` від пульсацій струму котушки `ΔI_L`:
   ```
   P_cond_C = (ΔI_L² / 12) · ESR
   ```

Зводячи омічні складові до єдиного еквівалентного опору втрат `R_eq`:

```
R_eq = D · R_ds_on_high + (1 - D) · R_ds_on_low + DCR + (ΔI_L / I_out)² · (ESR / 12)
```

При малих пульсаціях індуктивності (`ΔI_L << I_out`) останнім доданком можна знехтувати, і `R_eq` стає чистою константою омічного шляху.

## Виведення аналітичного максимуму кривої ККД

Підставивши поліном втрат у загальне рівняння ККД імпульсного перетворювача, маємо:

```
η(I_out) = P_out / (P_out + P_loss)
         = (V_out · I_out) / (V_out · I_out + P_fix + k_sw · I_out + R_eq · I_out²)
```

Поділимо чисельник і знаменник на вихідну потужність `V_out · I_out`:

```
η(I_out) = 1 / [ 1 + (k_sw / V_out) + (P_fix / (V_out · I_out)) + (R_eq · I_out / V_out) ]
```

Щоб знайти значення струму навантаження `I_out_opt`, при якому ККД досягає абсолютного максимуму, необхідно мінімізувати знаменник виразу. Позначимо функцію знаменника як `f(I_out)`:

```
f(I_out) = 1 + (k_sw / V_out) + (P_fix / V_out) · I_out⁻¹ + (R_eq / V_out) · I_out
```

Візьмемо першу похідну функції `f(I_out)` за змінною `I_out` і прирівняємо її до нуля:

```
df / dI_out = - (P_fix / V_out) · I_out⁻² + (R_eq / V_out) = 0
```

Домножимо обидві частини рівняння на `V_out` та перенесемо від'ємний доданок праворуч:

```
R_eq = P_fix / I_out²                        [перенесення членів]
I_out² · R_eq = P_fix                        [множення на I_out²]
I_out_opt = √(P_fix / R_eq)                  [добування квадратного кореня]
```

Отриманий результат формулює фундаментальний закон узгодження втрат імпульсного регулятора:

> **Максимум ККД імпульсного перетворювача досягається точно при такому струмі навантаження, коли квадратичні провідні втрати `R_eq · I_out²` зрівнюються з постійними фіксованими втратами `P_fix`.**

Підставимо знайдений оптимальний струм `I_out_opt = √(P_fix / R_eq)` назад у вираз для максимального ККД `η_max`:

```
P_loss_opt = P_fix + k_sw · √(P_fix / R_eq) + R_eq · (P_fix / R_eq)
           = 2 · P_fix + k_sw · √(P_fix / R_eq)

η_max = (V_out · √(P_fix / R_eq)) / [ V_out · √(P_fix / R_eq) + 2 · P_fix + k_sw · √(P_fix / R_eq) ]
      = V_out / [ V_out + k_sw + 2 · √(P_fix · R_eq) ]
```

### Приклад чисельного розрахунку піку ККД

Нехай понижувальний перетворювач має параметри:
- `V_in = 5.0 В`, `V_out = 3.3 В`;
- Фіксовані втрати: `P_fix = 12 мВт = 0.012 Вт`;
- Комутаційний коефіцієнт: `k_sw = 0.04 Вт/А`;
- Еквівалентний опір силового кола: `R_eq = 0.15 Ом`.

Розрахуємо оптимальний струм навантаження та піковий ККД:

```
I_out_opt = √(0.012 / 0.15)                  [підстановка P_fix та R_eq]
          = √(0.08)                          [ділення 0.012 на 0.15]
          ≈ 0.283 А = 283 мА                 [обчислення кореня квадратного]

P_out_opt = 3.3 · 0.283                      [підстановка V_out та I_out_opt]
          ≈ 0.9339 Вт                        [обчислення вихідної потужності]

P_loss_opt = 0.012 + 0.04 · 0.283 + 0.15 · (0.283)² [підстановка компонентів втрат]
           = 0.012 + 0.0113 + 0.0120         [обчислення доданків]
           = 0.0353 Вт                       [підсумовування втрат]

η_max = 0.9339 / (0.9339 + 0.0353)           [відношення корисної до повної потужності]
      = 0.9339 / 0.9692                      [додавання в знаменнику]
      ≈ 0.9636 = 96.4%                       [обчислення ККД у відсотках]
```

Якщо навантаження зменшиться до `I_out = 1 мА = 0.001 А`:

```
P_out = 3.3 · 0.001 = 0.0033 Вт (3.3 мВт)    [корисна потужність]
P_loss = 0.012 + 0.04 · 0.001 + 0.15 · (0.001)² ≈ 0.01204 Вт (12.04 мВт) [втрати]
η(1 мА) = 0.0033 / (0.0033 + 0.01204) = 0.0033 / 0.01534 ≈ 21.5% [ККД]
```

Втрати `12 мВт` у режимі безперервної ШІМ повністю поглинають корисну потужність `3.3 мВт`, обвалюючи ККД до `21.5%`.

## Граничний ККД та передатна характеристика Boost-перетворювача

Підвищувальний перетворювач (англ. *Boost Converter*) передає енергію на рівень напруги `V_out > V_in`. В ідеальному перетворювачі без втрат відношення напруг визначається виключно коефіцієнтом заповнення `D`:

```
V_out_ideal = V_in / (1 - D)
```

У реальній схемі струм індуктивності `I_L` у режимі неперервних струмів пов'язаний із вихідним струмом навантаження `I_out` співвідношенням:

```
I_L = I_out / (1 - D)
```

При зростанні коефіцієнта заповнення `D` (наприклад, коли треба підняти напругу з `1.2 В` до `5.0 В`, де `D = 1 - 1.2 / 5.0 = 0.76`) струм через індуктивність у `1 / (1 - 0.76) = 4.17` раза перевищує струм навантаження.

Провідні втрати на активному опорі котушки `R_L` та ключа `R_on`:

```
P_loss_boost = I_L² · R_loss
             = (I_out / (1 - D))² · R_loss
             = I_out² · [ R_loss / (1 - D)² ]
```

Потужність навантаження: `P_out = I_out² · R_load`. Реальна вихідна напруга перетворювача з урахуванням падіння на внутрішньому опорі:

```
V_out_real = [ V_in / (1 - D) ] · [ 1 / (1 + R_loss / ((1 - D)² · R_load)) ]
```

ККД підвищувального перетворювача з урахуванням провідних втрат:

```
η_boost = P_out / (P_out + P_loss_boost)
        = (I_out² · R_load) / [ I_out² · R_load + I_out² · R_loss / (1 - D)² ]
        = 1 / [ 1 + (R_loss / R_load) / (1 - D)² ]
```

Знайдемо максимум реальної вихідної напруги за коефіцієнтом заповнення `D`. Продиференціювавши вираз для `V_out_real` за `(1 - D)` та прирівнявши до нуля:

```
(1 - D)_opt = √(R_loss / R_load)
D_max_gain = 1 - √(R_loss / R_load)
```

Якщо намагатися збільшувати `D` вище `D_max_gain`, вихідна напруга не зростає, а починає падати через експоненційне зростання втрат `I_L² · R_loss`. При `D → 1` ККД Boost-перетворювача прямує до нуля:

```
lim (D → 1) η_boost = 0
```

Це доводить, що для високократного підвищення напруги (наприклад, з `1.0 В` до `12 В`) однокаскадний Boost-перетворювач є непридатним, і вимагає застосування багатофазних або трансформаторних топологій (Flyback, SEPIC).

## Модель втрат 4-ключового Buck-Boost у зоні переходу

Синхронний чотириключовий Buck-Boost перетворювач (англ. *Four-Switch Synchronous Buck-Boost*) здатен стабілізувати фіксовану вихідну напругу (наприклад, `3.3 В`) як при вищій напрузі батареї (`4.2 В`), так і при нижчій (`2.8 В`).

Втрати перетворювача кардинально залежать від режиму комутації:

1. **Режим Buck (`V_in > 1.15 · V_out`):** ключі вихідного каскаду зафіксовані (верхній увімкнений, нижній вимкнений). Працюють тільки вхідні ключі. Втрати відповідають стандартній моделі Buck.
2. **Режим Boost (`V_in < 0.85 · V_out`):** вхідний верхній ключ зафіксований увімкненим. Працюють тільки вихідні ключі Boost-каскаду.
3. **Зона переходу (`0.85 · V_out ≤ V_in ≤ 1.15 · V_out`):** перетворювач змушений періодично комутувати всі чотири силові транзистори протягом одного такту (або чергувати цикли Buck і Boost), щоб зберегти керування струмом індуктивності.

У зоні переходу комутаційні та драйверні втрати подвоюються:

```
P_gate_4sw = 2 · (Q_g_buck + Q_g_boost) · V_drv · f_sw
P_sw_4sw   = 0.5 · (V_in + V_out) · I_out · (t_r + t_f) · f_sw
```

Провідні втрати зростають через послідовне протікання струму через два відкритих канали транзисторів одночасно:

```
R_eq_4sw = R_ds_on_in + R_ds_on_out + DCR_L
```

Сумарні втрати в зоні `V_in ≈ V_out`:

```
P_loss_4sw = P_fix_4sw + k_sw_4sw · I_out + R_eq_4sw · I_out²
```

ККД 4-ключового перетворювача в зоні переходу зазнає характерного локального провалу (на `4...8%` нижче від чистих режимів Buck або Boost), що необхідно враховувати в інтегральному розрахунку розряду Li-ion акумулятора при проходженні плато напруги `3.6...3.8 В`.

---

Для автономних мікроконтролерних систем характерний періодичний профіль навантаження, що складається з `N` дискретних фаз функціонування (наприклад, глибокий сон, опитування сенсора, обчислення, радіопередача).

Нехай повний період робочого циклу становить `T_cycle`:

```
T_cycle = ∑ [i=1..N] t_i
```

Кожна `i`-та фаза характеризується тривалістю `t_i`, вихідним струмом споживання `I_i` та миттєвим ККД регулятора `η_i(I_i)`.

Сумарна корисна електрична енергія `E_out`, спожита навантаженням за один повний період циклу:

```
E_out = ∑ [i=1..N] P_out_i · t_i
      = ∑ [i=1..N] V_out · I_i · t_i
      = V_out · ∑ [i=1..N] (I_i · t_i)
```

Сумарна електрична енергія `E_in`, відібрана стабілізатором від джерела живлення (акумулятора) за той самий період:

```
E_in = ∑ [i=1..N] P_in_i · t_i
     = ∑ [i=1..N] (P_out_i / η_i) · t_i
     = ∑ [i=1..N] ( (V_out · I_i · t_i) / η_i )
```

Еквівалентний середньозважений системний ККД `η_avg` (англ. *energy-weighted average efficiency*) визначається строго як відношення повної корисної енергії до повної спожитої енергії за період:

```
η_avg = E_out / E_in
      = [ ∑ [i=1..N] V_out · I_i · t_i ] / [ ∑ [i=1..N] (V_out · I_i · t_i / η_i) ]
```

Скоротивши вихідну напругу `V_out` у чисельнику та знаменнику, отримуємо узагальнену формулу середньозваженого ККД через зарядові інтервали `Q_i = I_i · t_i` (кулони або ампер-секунди):

```
η_avg = [ ∑ [i=1..N] Q_i ] / [ ∑ [i=1..N] (Q_i / η_i) ]
```

> **Важливий математичний висновок:** середньозважений ККД `η_avg` є не середнім арифметичним ККД фаз `(η_1 + η_2) / 2`, а **гармонійним зваженим середнім** за розподілом переданого електричного заряду `Q_i`.

## Чисельне порівняння трьох топологій: двофазний IoT-цикл

Розглянемо типовий бездротовий сенсорний вузол, який працює за двофазним циклом з періодом `T_cycle = 10 с`:
1. **Фаза сну (Sleep):** тривалість `t_sleep = 9.9 с` (99% часу), вихідний струм `I_sleep = 20 мкА = 2 · 10⁻⁵ А`, вихідна напруга `V_out = 3.3 В`.
2. **Фаза передачі (Burst):** тривалість `t_active = 0.1 с` (1% часу), вихідний струм `I_active = 100 мА = 0.1 А`, вихідна напруга `V_out = 3.3 В`.
Первинне джерело — однокомірковий Li-ion акумулятор із середньою робочою напругою `V_in = 3.7 В`.

Порівняємо три варіанти схеми живлення:
- **Варіант А: Нанопотужний LDO.** Струм спокою `I_q = 1 мкА = 10⁻⁶ А`.
- **Варіант Б: Стандартний Buck без PFM.** Струм спокою `I_q = 80 мкА`, ККД у сні `η_sleep = 18%`, ККД в активності `η_active = 92%`.
- **Варіант В: Buck з ультранизьким PFM.** Струм спокою `I_q = 1.5 мкА`, ККД у сні `η_sleep = 82%`, ККД в активності `η_active = 93%`.

### 1. Розрахунок корисної енергії навантаження `E_out`

```
Q_sleep = I_sleep · t_sleep                  [заряд фази сну]
        = (20 · 10⁻⁶ А) · 9.9 с              [підстановка значень]
        = 1.98 · 10⁻⁴ Кл (0.198 мА·с)        [обчислення добутку]

Q_active = I_active · t_active               [заряд активної фази]
         = 0.1 А · 0.1 с                     [підстановка значень]
         = 0.01 Кл = 1.00 · 10⁻² Кл (10 мА·с) [обчислення добутку]

Q_total = Q_sleep + Q_active                 [сумарний заряд за період]
        = 0.000198 + 0.01                    [додавання зарядів]
        = 0.010198 Кл                        [обчислення суми]

E_out = V_out · Q_total                      [корисна енергія за період]
      = 3.3 В · 0.010198 Кл                  [підстановка напруги і заряду]
      ≈ 0.0336534 Дж (33.65 мДж)             [обчислення енергії]
```

### 2. Варіант А: Нанопотужний LDO (`I_q = 1 мкА`)

```
I_in_sleep = I_sleep + I_q                   [вхідний струм у сні]
           = 20 мкА + 1 мкА                  [підстановка значень]
           = 21 мкА = 2.1 · 10⁻⁵ А           [додавання струмів]

E_in_sleep = V_in · I_in_sleep · t_sleep     [вхідна енергія фази сну]
           = 3.7 В · (2.1 · 10⁻⁵ А) · 9.9 с  [підстановка параметрів]
           = 3.7 · 2.079 · 10⁻⁴              [проміжне множення]
           ≈ 0.0007692 Дж (0.769 мДж)        [обчислення енергії сну]

I_in_active = I_active + I_q                 [вхідний струм в активності]
            = 100 мА + 0.001 мА              [підстановка значень]
            ≈ 100 мА = 0.1 А                 [округлення до 0.1 А]

E_in_active = V_in · I_in_active · t_active  [вхідна енергія активної фази]
            = 3.7 В · 0.1 А · 0.1 с          [підстановка параметрів]
            = 0.037000 Дж (37.00 мДж)        [обчислення енергії активності]

E_in_total_LDO = E_in_sleep + E_in_active    [сумарна спожита енергія]
               = 0.0007692 + 0.037000        [додавання енергій]
               = 0.0377692 Дж (37.77 мДж)    [обчислення повної енергії]

η_avg_LDO = E_out / E_in_total_LDO           [середньозважений ККД LDO]
          = 0.0336534 / 0.0377692            [відношення енергій]
          ≈ 0.8910 = 89.1%                   [обчислення ККД у відсотках]
```

### 3. Варіант Б: Стандартний Buck (`I_q = 80 мкА`, `η_sleep = 18%`, `η_active = 92%`)

```
E_out_sleep = 3.3 В · (20 · 10⁻⁶ А) · 9.9 с  [корисна енергія сну]
            ≈ 0.0006534 Дж (0.6534 мДж)      [обчислення добутку]

E_in_sleep_buck = E_out_sleep / η_sleep      [вхідна енергія сну Buck]
                = 0.0006534 / 0.18           [ділення на ККД сну]
                ≈ 0.0036300 Дж (3.630 мДж)   [обчислення вхідної енергії]

E_out_active = 3.3 В · 0.1 А · 0.1 с         [корисна енергія активності]
             = 0.0330000 Дж (33.00 мДж)      [обчислення добутку]

E_in_active_buck = E_out_active / η_active   [вхідна енергія активності Buck]
                 = 0.0330000 / 0.92          [ділення на ККД активності]
                 ≈ 0.0358696 Дж (35.87 мДж)  [обчислення енергії]

E_in_total_Buck_PWM = E_in_sleep_buck + E_in_active_buck [повна енергія Buck]
                    = 0.0036300 + 0.0358696  [додавання енергій]
                    = 0.0394996 Дж (39.50 мДж) [обчислення суми]

η_avg_Buck_PWM = E_out / E_in_total_Buck_PWM [середньозважений ККД PWM]
               = 0.0336534 / 0.0394996       [відношення енергій]
               ≈ 0.8520 = 85.2%              [обчислення ККД у відсотках]
```

### 4. Варіант В: Buck з ультранизьким PFM (`η_sleep = 82%`, `η_active = 93%`)

```
E_in_sleep_PFM = 0.0006534 / 0.82            [вхідна енергія сну PFM]
               ≈ 0.0007968 Дж (0.797 мДж)    [ділення на ККД 0.82]

E_in_active_PFM = 0.0330000 / 0.93           [вхідна енергія активності PFM]
                ≈ 0.0354839 Дж (35.48 мДж)   [ділення на ККД 0.93]

E_in_total_PFM = E_in_sleep_PFM + E_in_active_PFM [повна енергія за період]
               = 0.0007968 + 0.0354839       [додавання фаз]
               = 0.0362807 Дж (36.28 мДж)    [обчислення повної енергії]

η_avg_Buck_PFM = E_out / E_in_total_PFM      [середньозважений ККД PFM]
               = 0.0336534 / 0.0362807       [відношення енергій]
               ≈ 0.9276 = 92.8%              [обчислення ККД у відсотках]
```

### Зведена таблиця результатів моделювання

| Топологія регулятора | Споживання в сні `E_in_sleep` | Споживання в активності `E_in_act` | Повна енергія за цикл `E_in` | Середньозважений ККД `η_avg` |
|---|---|---|---|---|
| Нанопотужний LDO (`I_q = 1 мкА`) | 0.769 мДж | 37.00 мДж | **37.77 мДж** | **89.1%** |
| Класичний PWM Buck (`I_q = 80 мкА`) | 3.630 мДж | 35.87 мДж | **39.50 мДж** | **85.2%** |
| Нанопотужний PFM Buck (`I_q = 1.5 мкА`)| 0.797 мДж | 35.48 мДж | **36.28 мДж** | **92.8%** |

Математичний розрахунок виявляє неочевидний інженерний ефект: простий і дешевий нанопотужний LDO перевершує класичний імпульсний Buck-перетворювач за сумарною енергоефективністю (`89.1%` проти `85.2%`), оскільки високі втрати неоптимізованого перетворювача в 99% періоду сну нівелюють усю його перевагу в 1% активного стану.

---

У реальному пристрої напруга батареї не є сталою: Li-ion елемент розряджається за нелінійною кривою `V_bat(Q)`, де `Q` — відданий електричний заряд:

```
V_bat(Q) = V_0 - k_pol · (Q_nom / (Q_nom - Q)) - R_int · I_bat - k_exp · e^(-3 · Q / Q_exp)
```
де `V_0` — ЕРС повністю зарядженого елемента (`4.2 В`), `Q_nom` — номінальна ємність, `R_int` — внутрішній омічний опір акумулятора, `k_pol` — коефіцієнт поляризації, `k_exp` — експоненційна амплітуда початкового спаду.

Сумарна віддана акумулятором енергія `E_battery` до досягнення порогової напруги вимкнення `V_cutoff` (`3.0 В`):

```
E_battery = ∫ [0..T_life] V_bat(t) · I_bat(t) dt
          = ∫ [0..Q_cutoff] V_bat(Q) dQ
```

Застосовуючи середню інтегральну напругу акумулятора `V_bat_avg = E_battery / Q_cutoff` (для типового Li-ion `V_bat_avg ≈ 3.7 В`), повний час життя батареї `T_life` у секундах обчислюється як:

```
T_life = E_battery / P_in_avg
       = (E_battery · η_avg) / P_out_avg
       = [ E_battery · η_avg · T_cycle ] / [ ∑ [i=1..N] V_out · I_i · t_i ]
```

## Чутливість середньозваженого ККД до параметрів навантаження

Щоб визначити, зміна якого саме інженерного параметра дає максимальний приріст тривалості автономної роботи, знайдемо частинні похідні середньозваженого ККД двофазної системи (сон з параметрами `Q_s = I_s · t_s`, `η_s` та активність з `Q_a = I_a · t_a`, `η_a`).

Загальний вираз середньозваженого ККД для двох станів:

```
η_avg = (Q_s + Q_a) / (Q_s / η_s + Q_a / η_a)
```

Позначимо знаменник як `D = Q_s / η_s + Q_a / η_a`.

1. **Чутливість до струму спокою в режимі сну `I_q`:**
   У фазі сну струм малий, тому `η_s ≈ (V_out · I_s) / (V_in · (I_s + I_q))`.
   Знаменник енергії сну становить:
   ```
   Q_s / η_s = (I_s · t_s) / [ (V_out · I_s) / (V_in · (I_s + I_q)) ]
             = (V_in / V_out) · (I_s + I_q) · t_s
   ```
   Диференціюючи `η_avg` за струмом спокою `I_q`:
   ```
   ∂η_avg / ∂I_q = - (Q_s + Q_a) / D² · (∂D / ∂I_q)
                 = - (Q_s + Q_a) / D² · [ (V_in / V_out) · t_s ]
   ```
   Оскільки час сну `t_s` займає `99%` або `99.9%` усього життєвого циклу, множник `t_s` у чисельнику похідної є величезним. Це аналітично доводить, що будь-яке збільшення `I_q` катастрофічно зменшує системний ККД.

2. **Чутливість до тривалості активної фази `t_a`:**
   ```
   ∂η_avg / ∂t_a = [ I_a · D - (Q_s + Q_a) · (I_a / η_a) ] / D²
                 = [ I_a · (Q_s / η_s + Q_a / η_a) - I_a · (Q_s / η_a + Q_a / η_a) ] / D²
                 = [ I_a · Q_s · (1 / η_s - 1 / η_a) ] / D²
   ```
   Оскільки `η_a > η_s` (в активній фазі перетворювач працює ближче до піка ККД, ніж у фазі мікрострумів сну без PFM), вираз `(1 / η_s - 1 / η_a)` є строго додатним. Це означає, що зі зростанням частки активного часу `t_a` середньозважений ККД формально зростає, але сумарне споживання енергії `E_in` різко збільшується, скорочуючи абсолютний час життя батареї.

## Теплова модель перехідного процесу кристала

Втрачена потужність `P_loss` викликає нагрівання кристала мікросхеми стабілізатора. Стаціонарна температура кристала `T_j` (англ. *junction temperature*) визначається рівнянням теплового балансу, аналогічним закону Ома:

```
T_j = T_a + P_loss · R_thJA
```
де `T_a` — температура навколишнього середовища (°C), `R_thJA` — сумарний тепловий опір кристал-середовище (°C/Вт).

Однак у циклічному імпульсному режимі (наприклад, передача радіопакета тривалістю `t_pulse = 10 мс` з потужністю втрат `P_peak = 1.5 Вт` і паузою `990 мс`) температура кристала не встигає досягти стаціонарного значення завдяки власній теплоємності кремнію та мідної підкладки `C_th` (Дж/°C).

Динамічний тепловий опір (імпеданс) `Z_th(t)` описується експоненційним перехідним процесом:

```
Z_th(t) = R_thJA · (1 - e^(-t / τ_th))
```
де `τ_th = R_thJA · C_th` — теплова стала часу кристала (зазвичай від `10 мс` для дрібних корпусів SOT-23 до `1...2 с` для корпусів з Exposed Pad на великих мідних полігонах).

Максимальне динамічне перегрівання кристала `ΔT_j_max` наприкінці одиночного імпульсу втрат:

```
ΔT_j_max = P_avg · R_thJA + (P_peak - P_avg) · Z_th(t_pulse)
```
де `P_avg = P_peak · (t_pulse / T_cycle) + P_sleep · (1 - t_pulse / T_cycle)` — середня потужність втрат за повний період.

### Розрахунок теплового запасу для імпульсного навантаження

Нехай лінійний стабілізатор у корпусі SOT-23 (`R_thJA = 220 °C/Вт`, `τ_th = 25 мс`) живить передавач:
- Напруги: `V_in = 5.0 В`, `V_out = 3.3 В`;
- Імпульсний струм: `I_peak = 400 мА = 0.4 А`, тривалість `t_pulse = 5 мс`;
- Струм сну: `I_sleep = 50 мкА`, тривалість `t_sleep = 995 мс` (період `T_cycle = 1.0 с`);
- Температура повітря всередині корпусу: `T_a = 50 °C`.

1. Розрахунок миттєвих втрат потужності:
```
P_peak = (5.0 - 3.3) · 0.4 = 1.7 · 0.4 = 0.68 Вт [пікові втрати активної фази]
P_sleep = (5.0 - 3.3) · (50 · 10⁻⁶) = 1.7 · 5 · 10⁻⁵ = 0.000085 Вт ≈ 0 Вт [втрати сну]
```

2. Середня потужність втрат:
```
P_avg = 0.68 · (0.005 / 1.0) + 0 · 0.995     [усереднення за період]
      = 0.68 · 0.005                         [множення на шпаруватість]
      = 0.0034 Вт (3.4 мВт)                  [середні втрати]
```

3. Стаціонарний нагрів від середньої потужності:
```
ΔT_avg = P_avg · R_thJA                      [середній перегрів]
       = 0.0034 · 220                        [підстановка параметрів]
       ≈ 0.75 °C                             [обчислення стаціонарного ΔT]
```

4. Динамічний тепловий імпеданс за час `5 мс`:
```
Z_th(5 мс) = 220 · (1 - e^(-5 / 25))         [експоненційний перехідний процес]
           = 220 · (1 - e^(-0.2))            [ділення часу на тау]
           = 220 · (1 - 0.8187)              [обчислення експоненти]
           = 220 · 0.1813                    [віднімання від одиниці]
           ≈ 39.88 °C/Вт                     [динамічний тепловий опір]
```

5. Максимальна температура кристала наприкінці імпульсу:
```
ΔT_pulse = (P_peak - P_avg) · Z_th(5 мс)     [імпульсний сплеск температури]
         = (0.68 - 0.0034) · 39.88           [підстановка значень]
         = 0.6766 · 39.88                    [обчислення добутку]
         ≈ 26.98 °C                          [динамічний перегрів]

T_j_max = T_a + ΔT_avg + ΔT_pulse            [максимальна температура кристала]
        = 50 + 0.75 + 26.98                  [підсумовування складових]
        ≈ 77.7 °C                            [підсумкова температура кристала]
```

Якби потужність `0.68 Вт` діяла неперервно, температура кристала досягла б аварійного значення:

```
T_j_cont = 50 + 0.68 · 220 = 50 + 149.6 = 199.6 °C  [перегрів та руйнування кристала]
```

Завдяки теплоємності кристала короткий імпульс нагріває кристал лише на `27.0 °C`, що забезпечує надійну роботу стабілізатора із запасом `47.3 °C` до граничного ліміту `125 °C`.
