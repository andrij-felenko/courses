# 🔌 Схемотехніка автогенераторів холодного старту на збіднених JFET

Автономні мікроелектронні системи без хімічних батарей часто змушені починати роботу в умовах, коли вхідний перетворювач отримує від термоелектричного генератора чи фотодіода крихітну напругу 20–50 мілівольтів, а всі внутрішні конденсатори розряджені до абсолютного нуля. Звичайні кремнієві польові транзистори (MOSFET) збагаченого типу за такої напруги заблоковані, оскільки для відкриття їхнього каналу потрібна порогова напруга затвора `V_th ≥ 0.4–0.7 В`. Щоб запустити систему без зовнішнього живлення, застосовують спеціальний клас схем — автотрансформаторні релаксаційні генератори на нормально замкнутих польових транзисторах із керувальним p-n-переходом (JFET, від англ. *Junction Field-Effect Transistor*). Цей розбір пояснює фізичні засади роботи таких генераторів, умови виникнення автоколивань від десятків мілівольтів та схемотехніку перемикання на основний синхронний перетворювач.

---

### Фізична основа: чому саме збіднений N-JFET

Звичайний кремнієвий MOSFET збагаченого типу (англ. *enhancement mode*) за нульової напруги на затворі `V_GS = 0` перебуває в закритому стані: під затвором немає шару інверсії, опір між стоком і витоком становить сотні мегаомів. Для створення провідного каналу на затвор треба подати позитивний потенціал, що перевищує поріг `V_th`. Але якщо система щойно ввімкнулася, джерел позитивної напруги на платі ще не існує.

Польовий транзистор із керувальним p-n-переходом збідненого типу (англ. *depletion-mode N-JFET*) працює за принципово іншим механізмом:

1. **Природний провідний канал при V_GS = 0.**
   Канал n-типу сформований технологічно під час легування кремнієвої пластини. Коли затвор і витік з'єднані накоротко або підтягнуті до одного потенціалу через пасивні елементи (`V_GS = 0`), канал повністю відкритий. Крізь транзистор вільно протікає початковий струм стоку `I_DSS` (англ. *Drain Current at Zero Gate Source Voltage*), а статичний опір відкритого каналу `R_DS(on)` становить лише одиниці чи десятки омів.

2. **Керування звуженням каналу (запирання від'ємною напругою).**
   Щоб перекрити струм у N-JFET, на затвор p-типу відносно витоку n-типу необхідно подати **від'ємну** напругу `V_GS < 0`. Зворотне зміщення p-n-переходу розширює збіднену область носіїв заряду (англ. *depletion region*) всередину провідного каналу, стискаючи його з боків. Коли напруга досягає порогу відсічки `V_p` (англ. *pinch-off voltage*, зазвичай від −0.5 В до −2.0 В), збіднені зони змикаються, і струм стоку повністю блокується.

Здатність пропускати помітний струм за наднизької напруги стоку `V_DS = 20–50 мВ` без попереднього зміщення на затворі робить збіднений N-JFET ідеальним пусковим елементом для систем холодного старту.

### Топологія автогенератора Мейснера / Армстронга

Схема запуску будується як релаксаційний трансформаторний автогенератор із трансформаторним додатним зворотним зв'язком (класична схема Мейснера / Армстронга з магнітним зв'язком):

```
       V_in (20–50 мВ)
          o───────+
                  │
             ┌────┴────┐
             │ Первинна│ L_p (1 виток)
             │ обмотка │
             └────┬────┘
                  ├───────────────────o Стік (D)
                  │                  ┌┴┐
             ┌────┴────┐      C_gate │ │ JFET (N-channel)
             │Вторинна │    ┌───┤├───┤ ├─┐
             │ обмотка │    │        └┬┘ │
             │   L_s   ├────┘         │  │
             │(50–100в)│              │  │
             └────┬────┘              │  │
                  │                   │  │
             ┌────┴────┐              │  │
             │  Діод   │ Schottky     │  │
             │ Шотткі  │              │  │
             └────┬────┘              │  │
                  │                   │  │
                  o V_aux (1.8–2.2 В) │  │
                  │                   │  │
                ┌─┴─┐ C_aux           │  │
                │   │ (1–10 мкФ)      │  │
                └─┬─┘                 │  │
                  │                   │  │
                 ===                 === ===
                 GND                 GND GND
```

#### Ключові компоненти схеми

- **Підвищувальний автотрансформатор (Coupled Inductor).**
  Складається з первинної обмотки `L_p` з низьким активним опором (міліоми, щоб не втрачати вхідну напругу 20 мВ) та вторинної обмотки `L_s` з високим коефіцієнтом трансформації `N = 1:20 ... 1:100`. Обмотки підключені у протифазі для забезпечення інверсії знаку та створення сильного додатного зворотного зв'язку на затвор.

- **Розділовий конденсатор затвора `C_gate` (1–10 нФ).**
  Передає високочастотний імпульс напруги з вторинної обмотки на затвор транзистора, блокуючи проникнення постійної складової струму з p-n-переходу.

- **Випрямляч зворотного ходу (Flyback Diode) та допоміжний конденсатор `C_aux`.**
  Діод Шотткі (або синхронний діодний ключ із нульовим падінням) спрямовує високовольтні імпульси самоіндукції вторинної обмотки в резервний конденсатор `C_aux` ємністю 1–10 мкФ, що живить внутрішні схеми керування основного мікроконтролера чи DC-DC перетворювача.

### Чотири фази динамічного циклу релаксації

Робота генератора розгортається у чотири послідовні фази:

```
Фаза 1: Лінійне наростання струму стоку
    V_in подається на L_p → JFET відкритий (V_GS ≈ 0) → di_D/dt = V_in / L_p.

Фаза 2: Додатний зворотний зв'язок і лавинне відкриття
    На вторинній обмотці L_s наводиться позитивна напруга V_s = N · L_p · (di_D/dt) > 0.
    Позитивний імпульс через C_gate підтискає затвор угору, ще сильніше знижуючи R_DS.

Фаза 3: Зупинка наростання струму та глибока відсічка
    Струм стоку сягає межі насичення або магнітне осердя входить у насичення → di_D/dt падає до 0.
    Напруга на L_s різко змінює знак на протилежний.
    На затворі формується потужний від'ємний імпульс V_GS < V_p (глибше −2 В).
    Канал JFET миттєво і повністю перекривається.

Фаза 4: Екстракція енергії (Flyback) у допоміжну шину
    Струм у первинній обмотці обривається. Енергія магнітного поля трансформатора
    викидається у вторинну обмотку у вигляді високовольтного flyback-імпульсу амплітудою 3–5 В.
    Імпульс випрямляється діодом Шотткі та заряджає конденсатор C_aux.
```

Після передачі магнітної енергії від'ємний заряд на конденсаторі `C_gate` повільно стікає через паразитні витоки p-n-переходу або спеціальний високомомний резистор розряду. Напруга `V_GS` повертається до нуля, канал JFET знову відкривається, і цикл починається спочатку.

Частота автоколивань такого релаксаційного контуру зазвичай лежить у межах 10–100 кГц залежно від індуктивності обмоток і напруги джерела.

### Перемикання на основний перетворювач (Handover Mechanism)

Автогенератор Мейснера має низький коефіцієнт корисної дії (близько 20–40%) через активні втрати в обмотках тонкого дроту та діоді випрямляча. Його єдине завдання — викачати перші мікроджоулі енергії для підйому напруги на допоміжній шині `V_aux` до порогу `V_wake ≈ 1.8 В`.

Щойно напруга `V_aux` досягає 1.8 В, спрацьовує нанопотужний супервізор напруги (англ. *voltage supervisor*), вбудований у мікросхему збирача енергії (наприклад, архітектури Linear Technology / Analog Devices LTC3108 чи Texas Instruments bq25570):

1. Вмикається внутрішній тактовий генератор і CMOS-драйвери основного високочастотного синхронного Boost-перетворювача.
2. Основний перетворювач бере на себе викачування енергії з вхідного джерела з високим ККД (80–90%) за алгоритмом стеження за точкою максимальної потужності (MPPT).
3. **Примусове гасіння JFET-генератора:** щоб вимкнути паразитні втрати в пусковому контурі, затвор пускового JFET притягується до від'ємної шини живлення або замикається внутрішнім MOSFET-ключем на постійний потенціал `V_GS < V_p`. Провідний канал пускового транзистора надійно блокується, і автоколивання припиняються.

### Практичні компроміси та типові помилки реалізації

При проектуванні вузла холодного старту розробники найчастіше припускаються таких помилок:

- **Завищений опір первинної обмотки (DCR).**
  Якщо джерело видає 30 мВ, а опір первинної обмотки становить 0.5 Ом при пусковому струмі 30 мА, падіння напруги на мідному дроті складе `30 мА · 0.5 Ом = 15 мВ` — тобто половину всієї напруги генератора! Первинна обмотка повинна виконуватися товстим дротом або шиною з активним опором `DCR < 0.05 Ом`.

- **Неправильна фазировка обмоток трансформатора.**
  Якщо початок і кінець вторинної обмотки переплутані, зворотний зв'язок стає від'ємним замість додатного. Генератор не збудиться за жодних умов.

- **Струм витоку конденсатора `C_aux`.**
  Якщо резервний конденсатор `C_aux` має витік 5–10 мкА (що типово для старих танталових або електролітичних конденсаторів), а автогенератор здатний генерувати лише 3 мкА середнього струму, напруга на шині `V_aux` ніколи не дотягне до 1.8 В, і система застрягне у вічному незавершеному пуску. На позицію `C_aux` слід встановлювати виключно високоякісні багатошарові керамічні конденсатори (MLCC) класу діелектрика X7R або C0G.
