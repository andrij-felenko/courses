# 🧮 Математичний розрахунок накопичувача, витоків та автогенератора Мейснера

Проектування безбатарейних вузлів із живленням від збирачів мікроенергії вимагає точного математичного узгодження трьох взаємопов'язаних процесів: виникнення автоколивань у пусковому генераторі Мейснера за напруг у десятки мілівольтів, накопичення заряду в резервуарі з урахуванням паразитних струмів власного витоку та розрахунку мінімально необхідної ємності під імпульс споживання цифрового навантаження. Нижче наведено виведення ключових аналітичних співвідношень та розрахункових рівнянь.

---

### 1. Розрахунок корисної енергії накопичувача в гістерезисному вікні

Конденсатор ємністю `C` не може бути розряджений навантаженням до повного нуля, оскільки цифрові мікроконтролери та радіотрансивери перестають функціонувати при падінні напруги нижче мінімального робочого порогу `V_low` (зазвичай 1.8–2.0 В).

Повна енергія, накопичена в ємності при заряджанні до верхнього порогу `V_high`:

```
E_total = (1 / 2) · C · V_high²
```

Залишкова енергія, яка залишається заблокованою в конденсаторі в момент спрацьовування супервізора на відсічку навантаження при напрузі `V_low`:

```
E_rem = (1 / 2) · C · V_low²
```

Корисна енергія `E_usable`, яку навантаження може реально вилучити з накопичувача за один робочий імпульс активності:

```
E_usable
= E_total - E_rem
= (1 / 2) · C · V_high² - (1 / 2) · C · V_low²     [підстановка формул повної та залишкової енергії]
= (1 / 2) · C · (V_high² - V_low²)               [винесення спільного множника (1/2)·C]
```

#### Розрахунок мінімальної необхідної ємності `C_min`

Нехай бездротовий сенсорний вузол для виконання вимірювання та відправки радіопакета вимагає середньої потужності `P_burst` протягом часу `t_burst`. Загальна енергія активного імпульсу:

```
E_burst = P_burst · t_burst = V_nom · I_burst · t_burst
```

Якщо між накопичувачем і навантаженням встановлено понижувальний або LDO-стабілізатор із середнім коефіцієнтом корисної дії `η_reg`, то з накопичувача має бути вилучена енергія `E_req = E_burst / η_reg`.

Прирівнюючи необхідну енергію до корисної ємнісної енергії, отримуємо вираз для розрахунку мінімальної ємності накопичувача:

```
(1 / 2) · C_min · (V_high² - V_low²) = E_burst / η_reg

C_min
= (2 · E_burst) / (η_reg · (V_high² - V_low²))   [вираження C_min через параметри імпульсу]
```

**Числовий приклад:**
Нехай радіомодуль споживає струм `I_burst = 20 мА` при напрузі `V_nom = 3.0 В` протягом часу `t_burst = 15 мс`. Поріг увімкнення `V_high = 3.3 В`, поріг відсічки `V_low = 2.2 В`, ККД перетворювача `η_reg = 0.85`.

```
E_burst
= 3.0 В · 0.020 А · 0.015 с                      [підстановка заданих напруги, струму та тривалості]
= 0.0009 Дж                                      [обчислення добутку величин]
= 900 мкДж                                       [переведення у мікроджоулі]
```

```
V_high² - V_low²
= 3.3² - 2.2²                                    [підстановка порогових напруг]
= 10.89 - 4.84                                   [піднесення до квадрата]
= 6.05 В²                                        [обчислення різниці квадратів]
```

```
C_min
= (2 · 900 · 10⁻⁶ Дж) / (0.85 · 6.05 В²)         [підстановка E_burst, η_reg та різниці квадратів]
= (1800 · 10⁻⁶) / 5.1425                         [перемноження чисельника та знаменника]
≈ 350 · 10⁻⁶ Ф                                   [обчислення ділення]
= 350 мкФ                                        [переведення у мікрофаради]
```

З урахуванням 30% технологічного запасу на старіння діелектрика та температурну деградацію ємності вибирають конденсатор номіналом `C = 470 мкФ`.

### 2. Динаміка заряду та баланс струмів власного витоку

Джерело збирання енергії (наприклад, термоелектрогенератор або малогабаритна сонячна панель) для конденсатора можна представити еквівалентним джерелом струму `I_h` з внутрішнім шунтуючим опором або напругою холостого ходу `V_oc` та еквівалентним послідовним опором `R_eq`.

Рівняння струмів у вузлі накопичувача за першим законом Кірхгофа:

```
I_charge(t) = I_harvest(V) - I_leak(V) - I_q
```

де:
- `I_harvest(V)` — корисний вихідний струм перетворювача збирача;
- `I_leak(V)` — власний струм витоку діелектрика накопичувача (для суперконденсатора або кераміки);
- `I_q` — власний струм споживання мікросхеми супервізора напруги та схеми стеження.

#### Експоненційний час заряду

Якщо збирач енергії працює в режимі квазіпостійної потужності `P_in` з ефективністю передачі `η_boost`, середня швидкість надходження енергії дорівнює `P_ch = η_boost · P_in`.

Диференціальне рівняння балансу енергії:

```
P_ch - P_leak = d/dt [(1 / 2) · C · V(t)²] = C · V(t) · (dV/dt)
```

Якщо знехтувати нелінійністю витоку на початковому етапі (`P_leak << P_ch`), час первинного заряду конденсатора від 0 до `V_high`:

```
t_cold
= ∫₀^(V_high) (C · V / P_ch) dV
= (C / P_ch) · [V² / 2]₀^(V_high)                [інтегрування за напругою]
= (C · V_high²) / (2 · P_ch)                     [підстановка меж інтегрування]
```

Час міжподієвого перезаряджання між робочими циклами (від `V_low` до `V_high`):

```
t_recharge
= (C · (V_high² - V_low²)) / (2 · P_ch)          [інтегрування в межах від V_low до V_high]
```

**Числовий приклад:**
При ємності `C = 470 мкФ`, корисній потужності збирача `P_ch = 50 мкВт`, напругах `V_high = 3.3 В` та `V_low = 2.2 В`:

```
t_recharge
= (470 · 10⁻⁶ Ф · 6.05 В²) / (2 · 50 · 10⁻⁶ Вт)  [підстановка C, різниці квадратів та P_ch]
= (2.8435 · 10⁻³) / (100 · 10⁻⁶)                 [обчислення чисельника і знаменника]
≈ 28.4 с                                         [результат ділення: час перезаряджання]
```

#### Скважність та середня частота активації вузла

Скважність роботи системи `D` (англ. *duty cycle*):

```
D
= t_burst / (t_recharge + t_burst)
≈ t_burst / t_recharge                           [при t_burst << t_recharge]
= (0.015 с) / (28.4 с)                           [підстановка тривалостей імпульсу та заряду]
≈ 0.000528                                       [обчислення частки активного часу]
= 0.053%                                         [вираження у відсотках]
```

Вузол проводить 99.95% свого життєвого циклу в стані повного знеструмлення або глибокого сну, накопичуючи енергію на наступний короткий спалах активності.

### 3. Гранична умова заряду: пастка екстремальних витоків

Струм власного витоку суперконденсаторів (EDLC) зростає експоненційно з підвищенням напруги та температури:

```
I_leak(V) = I_0 · exp(α · V)
```

Якщо струм витоку при досягненні напруги `V_lim` зрівнюється з доступним струмом мікрозбирача `I_harvest`, результуючий струм заряду спадає до нуля:

```
I_charge = I_harvest(V_lim) - I_leak(V_lim) - I_q = 0
```

У цій точці накопичувач припиняє заряджатися. Якщо `V_lim < V_high`, система **ніколи не досягне порогу увімкнення** і залишиться навічно заблокованою в стані незавершеного накопичення.

Критична умова працездатності безбатарейної системи:

```
I_harvest(V_high) > I_leak(V_high) + I_q
```

Для джерела потужністю 10 мкВт при вихідній напрузі 3.3 В доступний струм становить лише `I_harvest ≈ 3 мкА`. Звідси випливає фундаментальна вимога: **сумарний струм власного витоку конденсатора та супервізора при напрузі 3.3 В не повинен перевищувати 300–500 нА**.

### 4. Умова самозбудження автогенератора Мейснера на збідненому JFET

Для виникнення незатухаючих автоколивань у релаксаційному генераторі на малій вхідній напрузі `V_in` петльовий коефіцієнт підсилення схеми за критерієм Баркгаузена повинен перевищувати одиницю:

```
T(jω) = A(jω) · β(jω) ≥ 1
```

де:
- `A` — коефіцієнт підсилення за напругою каскаду на JFET;
- `β` — коефіцієнт передачі ланки зворотного зв'язку трансформатора.

#### Малосигнальна модель у робочій точці V_GS = 0

Крутизна вольт-амперної характеристики транзистора (англ. *transconductance*) при нульовому зміщенні:

```
g_m = (2 · I_DSS) / |V_p|
```

Коефіцієнт взаємоіндукції між первинною обмоткою `L_p` та вторинною `L_s`:

```
M = k · √(L_p · L_s)
```

де `k` — коефіцієнт магнітного зв'язку (`k ≈ 0.8–0.95` для тороїдальних або броньових осердь).

При лінійному наростанні струму стоку в первинній обмотці `di_D/dt` на вторинній обмотці наводиться напруга зворотного зв'язку:

```
V_gate(t) = M · (di_D/dt) = M · (g_m / C_eff) · V_gate(t)
```

Диференціальне рівняння амплітуди коливань на резонансній частоті контуру `ω_0 = 1 / √(L_s · C_eff)`:

```
d²V_g/dt² + [ (R_p / L_p) + (1 / (R_load · C_eff)) - (g_m · M) / (L_p · C_eff) ] · (dV_g/dt) + ω_0² · V_g = 0
```

Щоб система втратила стійкість і перейшла в режим наростання амплітуди коливань (від'ємне демпфування), коефіцієнт при першій похідній повинен бути від'ємним:

```
(g_m · M) / (L_p · C_eff) > (R_p / L_p) + (1 / (R_load · C_eff))

g_m · M > R_p · C_eff + (L_p / R_load)          [множення на L_p · C_eff]
```

Оскільки коефіцієнт трансформації `N = √(L_s / L_p)`, то `M ≈ k · N · L_p`. Підставляючи `M` у нерівність:

```
g_m · k · N · L_p > R_p · C_eff + (L_p / R_load)

N_min
> [R_p · C_eff + (L_p / R_load)] / (k · g_m · L_p)   [виведення мінімального коефіцієнта трансформації]
```

#### Висновок для схемотехніки

1. **Транзистор повинен мати високу крутизну `g_m` при V_GS = 0.** Оптимальними є збіднені транзистори з високим `I_DSS` (від 10 до 50 мА) та помірним напруженням відсічки `V_p ≈ −1.0 В`, що забезпечує `g_m ≈ 20–50 мСм`.
2. **Коефіцієнт трансформації `N` повинен бути не менше 1:20–1:50.** Це гарантує, що навіть при вхідній амплітуді коливань 20 мВ на вторинній обмотці наводиться імпульс `V_s = N · V_in ≥ 50 · 20 мВ = 1.0 В`, достатній для надійного відкриття випрямного діода та глибокого перекриття каналу JFET у фазі відсічки.
