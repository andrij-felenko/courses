# 🧮 Тепловий баланс та математичний критерій теплового розгону (Thermal Runaway)

У цій математичній викладці виведено кількісні критерії теплової стійкості літій-іонної комірки на основі класичної теорії теплового вибуху Миколи Семенова та Давида Франк-Каменецького. Розрахунок зіставляє експоненційне зростання хімічного тепловиділення за законом Арреніуса з лінійною тепловіддачею в навколишнє середовище за законом Ньютона і доводить існування критичної температури `T_crit`, перевищення якої робить температурний розгін незворотним.

## 1. Фізична постановка та критерій зосереджених параметрів (число Біо)

Аналіз теплового стану акумулятора вимагає попередньої перевірки розподілу температури всередині циліндричної або призматичної гільзи. Для цього оцінюють безрозмірне число Біо (лат. *Biot*):

```
Bi = h · L_c / k_r
```

де:
* `h` — коефіцієнт зовнішньої тепловіддачі конвекцією та випромінюванням (типово `10–25 Вт/(м²·К)` для природної конвекції в повітрі);
* `L_c = R_cell / 2` — характерний лінійний розмір (для циліндра радіусом `R_cell = 9 мм` маємо `L_c = 0.0045 м`);
* `k_r` — ефективна радіальна теплопровідність рулону електродів (типово `0.5–1.2 Вт/(м·К)`).

Підставляючи граничні значення, отримуємо:

```
Bi ≈ 20 · 0.0045 / 0.8 ≈ 0.11
```

Оскільки число Біо близьке до межі `Bi ≤ 0.1`, температурний градієнт між центром комірки та її стінкою на початковій стадії саморозігріву є помірним. Це дає змогу застосувати термодинамічну модель із зосередженими параметрами (lumped thermal model), де вся комірка масою `m` і питомою теплоємністю `C_p` характеризується єдиною узагальненою внутрішньою температурою `T`.

## 2. Диференціальне рівняння балансу потужностей

Зміна внутрішньої енергії комірки в часі `t` визначається балансом трьох складових: екзотермічного хімічного тепловиділення `q_gen`, джоулевого нагріву від протікання струму `q_joule` та тепловідведення в навколишнє середовище `q_cool`:

```
C_p · m · (dT / dt) = q_gen(T) + q_joule - q_cool(T)
```

Розгорнемо кожну фізичну складову:

1. **Електричний нагрів (Джоулів закон):**

```
q_joule = I² · R_int(T, SOC)
```

де `I` — зовнішній струм (заряду або розряду), а `R_int` — активний омічний внутрішній опір комірки, що залежить від ступеня наповнення `SOC` та експоненційно спадає зі зростанням температури за рахунок підвищення рухливості іонів в електроліті.

2. **Тепловідведення Ньютона:**

```
q_cool(T) = h · S · (T - T_amb)
```

де `S` — площа зовнішньої поверхні корпусу комірки, а `T_amb` — абсолютна температура довкілля.

3. **Хімічне тепловиділення Арреніуса:**
Швидкість екзотермічного розкладу компонентів (депасивація SEI-шару, взаємодія літію в графіті з розчинником, окиснення електроліту оксидом катода) описується кінетичним рівнянням нульового або першого порядку:

```
q_gen(T) = Q_rx · m_act · A · exp(-E_a / (R · T))
```

де `Q_rx` — питомий тепловий ефект реакції (Дж/кг), `m_act` — маса реагуючої активної речовини (кг), `A` — частотний передекспоненційний множник (1/с), `E_a` — енергія активації (Дж/моль), `R = 8.314 Дж/(моль·К)` — універсальна газова стала.

## 3. Виведення критичної точки біфуркації Семенова

Для настання стаціонарного теплового балансу швидкість нагріву має дорівнювати швидкості охолодження (`dT/dt = 0`). Розглянемо випадок батареї в стані спокою або під малим струмом витоку (`q_joule ≈ 0`):

```
q_gen(T) = q_cool(T)
```

Графічно ліва частина рівняння є стрімкою експонентою, а права частина — прямою лінією з нахилом `h · S`. Залежно від умов тепловідведення можливі три режими:
1. Пряма перетинає експоненту у двох точках: нижня точка — стійка рівновага, верхня точка — поріг займання.
2. Пряма не перетинає експоненту: тепловідведення слабше за нагрів за будь-якої температури — розгін неминучий.
3. Пряма є дотичною до експоненти: граничний критичний режим (точка Семенова).

Умова дотику кривої тепловиділення та прямої тепловідведення вимагає рівності їхніх перших похідних за температурою:

```
d q_gen(T) / dT = d q_cool(T) / dT
```

Обчислимо похідні аналітично:

```
d q_cool / dT
= d [h · S · (T - T_amb)] / dT    [диференціювання за T]
= h · S                          [лінійний нахил тепловідведення]
```

```
d q_gen / dT
= d [Q_rx · m_act · A · exp(-E_a / (R · T))] / dT         [правило ланцюга]
= Q_rx · m_act · A · exp(-E_a / (R · T)) · (E_a / (R · T²))   [похідна аргументу -E_a/(R·T)]
= q_gen(T) · (E_a / (R · T²))                             [підстановка виразу q_gen]
```

Прирівнюючи похідні в критичній точці `T = T_crit`:

```
h · S = q_gen(T_crit) · (E_a / (R · T_crit²))
```

Оскільки в точці контакту також виконується рівність потужностей `q_gen(T_crit) = h · S · (T_crit - T_amb)`, підставляємо цей вираз замість `q_gen(T_crit)`:

```
h · S = h · S · (T_crit - T_amb) · (E_a / (R · T_crit²))
```

Скорочуючи ненульовий множник `h · S` з обох частин рівності:

```
1 = (T_crit - T_amb) · (E_a / (R · T_crit²))
```

Множимо обидві частини на `R · T_crit²` та перегруповуємо до канонічного квадратного рівняння:

```
R · T_crit² - E_a · T_crit + E_a · T_amb = 0
```

Розв'язуємо квадратне рівняння щодо `T_crit`:

```
Дискримінант:
D = E_a² - 4 · R · E_a · T_amb
D = E_a² · (1 - 4 · R · T_amb / E_a)

Корені:
T_crit = [E_a ± E_a · √(1 - 4 · R · T_amb / E_a)] / (2 · R)
```

Оскільки відношення теплової енергії молекул до енергії хімічної активації є малою величиною (`R · T_amb / E_a ≈ 0.02 << 1`), застосовуємо розклад кореня в ряд Тейлора: `√(1 - x) ≈ 1 - x/2 - x²/8`. Для нижнього фізичного кореня:

```
T_crit
≈ [E_a - E_a · (1 - 2 · R · T_amb / E_a)] / (2 · R)
= [E_a - E_a + 2 · R · T_amb] / (2 · R)   [перше наближення]
= T_amb
```

Беручи наступний порядок наближення Тейлора `1 - x/2 - x²/8`:

```
T_crit ≈ T_amb + (R · T_amb² / E_a)
```

Різниця між критичною температурою та температурою середовища — це граничний допустимий саморозігрів Семенова:

```
ΔT_crit = T_crit - T_amb = R · T_amb² / E_a
```

## 4. Безрозмірний критерій стійкості Семенова (параметр Ψ)

Введемо безрозмірний параметр Семенова `Ψ`, що характеризує співвідношення між максимальною швидкістю тепловиділення за температури середовища та швидкістю тепловідведення:

```
Ψ = [Q_rx · m_act · A · exp(-E_a / (R · T_amb)) · E_a] / [h · S · R · T_amb²]
```

Термодинамічний висновок теорії Семенова стверджує:
* Якщо `Ψ < 1/e ≈ 0.368` — система стабільна, існує стаціонарна робоча точка з малим перегрівом.
* Якщо `Ψ = 1/e ≈ 0.368` — система перебуває на критичній межі біфуркації.
* Якщо `Ψ > 0.368` — стаціонарний стан неможливий: будь-яке мале температурне збурення призводить до нескінченного зростання швидкості реакції та вибухового теплового розгону.

## 5. Числовий приклад розрахунку для циліндричної комірки 18650

Визначимо критичний допустимий перегрів і тепловий стан комірки при деструкції пасиваційного SEI-шару.

**Параметри елемента:**
* Радіус `r = 9 мм`, висота `L = 65 мм`; площа поверхні `S = 2·π·r·L + 2·π·r² ≈ 0.00418 м²`;
* Маса комірки: `m = 0.045 кг`; питома теплоємність: `C_p = 1000 Дж/(кг·К)`;
* Температура середовища: `T_amb = 300.15 К` (27 °C);
* Енергія активації реакції розпаду метастабільного SEI: `E_a = 1.25 × 10⁵ Дж/моль` (125 кДж/моль);
* Тепловий ефект реакції розпаду SEI: `Q_rx · m_act ≈ 12000 Дж` на комірку;
* Коефіцієнт охолодження в збірці: `h = 15 Вт/(м²·К)`.

**Розрахунок критичного перегріву:**

```
ΔT_crit
= R · T_amb² / E_a                                    [формула Семенова]
= 8.314 · (300.15)² / 125000                          [підстановка значень]
= 8.314 · 90090 / 125000                              [обчислення квадрата]
= 748997 / 125000                                     [добуток]
≈ 5.99 К                                              [критичний перепад]
```

```
Критична абсолютна температура:
T_crit = T_amb + ΔT_crit = 300.15 + 5.99 = 306.14 К ≈ 33.0 °C
```

**Оцінка часу розгону (інтеграл адіабатичного саморозігріву):**
Якщо тепловідведення погіршується (наприклад, комірка затиснута в щільному герметичному блоці без обдуву, де `h → 0`), динаміка температури описується адіабатичним рівнянням:

```
C_p · m · (dT / dt) = Q_rx · m_act · A · exp(-E_a / (R · T))
```

Інтегруючи від початкової температури активації `T_0 = 360 К` (87 °C) до температури займання `T_ign = 450 К` (177 °C), час переходу в термічний розгін становить:

```
t_runaway = (C_p · m) / (Q_rx · m_act · A) · ∫[T_0 → T_ign] exp(E_a / (R · T)) dT
```

Через експоненційну залежність підінтегральної функції понад 90% загального часу розгону витрачається на повільний розігрів у діапазоні від 80 °C до 120 °C. Щойно температура перетинає поріг 130–140 °C, час нагріву скорочується до десятих часток секунди, перетворюючи хімічний процес на детонаційне горіння.
