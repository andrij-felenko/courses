Літій-іонна комірка концентрує величезну питому густину енергії (до 250–300 Вт·год/кг та 700 Вт·год/л) у системі з рідким органічним електролітом на основі суміші алкілкарбонатів (етиленкарбонат, диметилкарбонат) із сіллю гексафторофосфату літію (`LiPF₆`). Цей розчинник має температуру спалаху нижче 30 °C і є легкозаймистою рідиною. На відміну від водних акумуляторів (свинцево-кислотних або нікель-кадмієвих), літієва комірка є термодинамічно метастабільною системою: вона залишається цілісною лише завдяки штучній нанометровій пасиваційній плівці на аноді та мікропористому полімерному сепаратору завтовшки 12–25 мкм між електродами. Вихід за вузькі межі напруги, температури чи струму призводить не просто до втрати ресурсу, а запускає незворотні хімічні ланцюгові реакції — від утворення внутрішніх металевих голок до самопідтримуваного екзотермічного горіння.

Слово «акумулятор» (лат. *accumulare* — накопичувати) означає електрохімічну комірку, здатну зворотно відновлювати свою хімічну енергію. Проте зворотність цієї реакції не є абсолютною. Безпечне поводження з літієм вимагає глибокого розуміння того, що саме руйнується всередині батареї під час холодного заряду, тривалого зберігання на екстремальних напругах чи механічного пошкодження корпусу.

## Вразлива хімічна рівновага: межі заряду й розряду

Перше, з чим стикається інженер при роботі з літій-іонними комірками (NMC, LCO, LFP), — це різка асиметрія допустимих умов роботи. Розряджати комірку дозволено в широкому температурному діапазоні від -20 °C до +60 °C, тоді як заряджати її дозволяється лише у вузькому вікні від 0 °C до +45 °C.

Ця асиметрія зумовлена різною енергетикою процесів:

1. **Розряд (деінтеркаляція з анода):** Іони літію `Li⁺` самочинно виходять із графітової матриці анода, рухаючись за градієнтом електрохімічного потенціалу в бік оксидного катода. Електричне поле допомагає іонам долати внутрішній опір навіть у в'язкому охолодженому електроліті.
2. **Заряд (інтеркаляція в анод):** Зовнішнє джерело живлення примусово вганяє іони `Li⁺` назад у міжшаровий простір графіту (явище інтеркаляції, від лат. *intercalare* — вставляти). Іон має десольватуватися (скинути оболонку з молекул розчинника), пройти крізь пасиваційний шар SEI та протиснутися всередину кристалічної ґратки вуглецю.

Якщо швидкість притоку іонів перевищує швидкість їх дифузії всередину графіту, хімічна система обирає енергетично простіший шлях — осадження літію у вигляді вільного металу прямо на поверхні електрода.

## Холод і дендрити: фізика літієвого плакування (Lithium Plating)

Рівноважний потенціал графітового анода, насиченого літієм (`LiC₆`), становить лише +0.05...+0.15 В відносно потенціалу чистого металевого літію (`Li/Li⁺`). За кімнатної температури (25 °C) цей мікроскопічний зазор надійно утримує літій в іонній формі всередині вуглецю.

Проте за низьких температур (нижче 0 °C) кінетика різко погіршується:
* В'язкість органічного електроліту зростає, а його питома іонна провідність падає у 5–10 разів.
* Коефіцієнт твердотільної дифузії літію всередині кристалітів графіту експоненційно спадає за законом Арреніуса.
* Опір пасиваційної плівки SEI (Solid Electrolyte Interphase; лат. *passivus* — недіяльний) зростає в рази.

Щоб проштовхнути зарядний струм крізь цей збільшений опір, виникає значна поляризаційна перенапруга `η`. Реальний потенціал поверхні анода `E_anode` описується рівнянням балансу:

```
E_anode = E_eq - η_act - η_conc - I · R_sei
```

де:
* `E_eq` — термодинамічний рівноважний потенціал інтеркаляції графіту (~0.1 В);
* `η_act` — активаційна перенапруга переносу заряду;
* `η_conc` — концентраційна перенапруга через повільну дифузію;
* `I · R_sei` — омічне падіння напруги на пасиваційному шарі.

Коли сумарне падіння напруги перевищує 0.1 В, потенціал анода пробиває нульовий рівень і стає від'ємним (`E_anode < 0.0 В` vs `Li/Li⁺`). У цю мить термодинамічно вигіднішою стає реакція прямого електролітичного відновлення металу:

```
Li⁺ + e⁻ → Li⁰ (металевий осад)
```

Це явище зветься **літієвим плакуванням** (англ. *lithium plating*). Металевий літій, що виділяється на поверхні графіту, росте не гладким шаром, а утворює голчасті розгалужені кристали — **дендрити** (грец. *déndron* — дерево). Силові лінії електричного поля концентруються на гострих мікровершинах, змушуючи голки рости вперед із величезною швидкістю.

Дендрити завдають двох незворотних ударів по комірці:

1. **Хімічна деградація («мертвий літій»):** Свіжий металевий літій має надзвичайно високу реакційну здатність. Він миттєво реагує з рідким електролітом, відновлюючи його молекули й утворюючи товстий шар вторинного SEI. Цей літій електрично ізолюється від електрода й назавжди вибуває з обороту — ємність акумулятора безповоротно падає після кожного холодного заряду.
2. **Механічний прокол сепаратора:** Гострі металеві голки проростають крізь пори полімерного сепаратора завтовшки 15–20 мкм і досягають катода. Утворюється пряме внутрішнє коротке замикання (ISC, Internal Short Circuit).

Історичний досвід катастроф перших металевих літієвих батарей 1980-х років детально розібрано в [історичній вставці](root:hw-power/povodzhennia-z-li-ion/hist-sony-1991-safety.md).

> 🔧 **Навіщо це.** Спроба зарядити холодний повербанк, електровелосипед чи дрон, занесений із зимового морозу (-10 °C), прямим швидким струмом призводить до миттєвого проростання літієвих дендритів. Батарея може не спалахнути негайно, але за 5–10 таких циклів вона перетворюється на внутрішньо закорочену бомбу сповільненої дії. Перед заряджанням акумулятор зобов'язаний прогрітися до температури щонайменше +10 °C по всьому внутрішньому об'єму.

## Температурні зони та профіль заряду JEITA

Для формалізації безпечних меж заряду Японська асоціація індустрії електроніки та інформаційних технологій у 2007 році ввела галузевий стандарт **JEITA** (Japan Electronics and Information Technology Industries Association; лат. *associatio* — об'єднання).

Стандарт поділяє температурний діапазон на 5 дискретних зон, у кожній із яких жорстко лімітуються струм та кінцева напруга заряду:

![Профіль заряду JEITA за температурними зонами](/root/hw/hw-power/povodzhennia-z-li-ion/img/jeita-profile.svg)
*П'ять температурних зон стандарту JEITA: заборона заряду на холоді (<0 °C) рятує від плакування літію, зниження напруги у теплій зоні (45–60 °C) зменшує окиснювальний розпад електроліту на катоді, а повне блокування на спеці (>60 °C) запобігає переходу до теплового розгону.*

### Логіка обмежень за зонами JEITA

1. **Зона холоду Cold (`T < 0 °C`):** Силовий струм повністю блокується (`I_chg = 0 мА`). Будь-який струм заряду за мінусової температури неминуче викликає осадження металевого літію.
2. **Зона прохолоди Cool (`0 °C ≤ T < 10 °C`):** Дифузія сповільнена, тому струм заряду примусово знижується до безпечного рівня `0.2C–0.5C`. Це знижує поляризаційну перенапругу й утримує потенціал графіту вище відмітки 0.0 В.
3. **Стандартна зона Standard (`10 °C ≤ T < 45 °C`):** Номінальний робочий режим. Дозволено повний паспортний струм `1.0C` і стандартну кінцеву напругу `4.20 В` (або `4.35–4.40 В` для високовольтних комірок LiHV).
4. **Тепла зона Warm (`45 °C ≤ T < 60 °C`):** Нагрів прискорює окиснення органічного розчинника на поверхні оксиду катода. Щоб запобігти окиснювальному стресу та газоутворенню, напругу заряду примусово знижують на 100 мВ (до `4.10 В`), а струм обмежують до `0.5C`. За рівнянням Нернста зниження напруги на 100 мВ суттєво зменшує окиснювальний потенціал катода й подовжує життя комірки.
5. **Зона спеки Hot (`T ≥ 60 °C`):** Заряд суворо заборонено (`I_chg = 0 мА`). За температури понад 60–70 °C розпочинається теплова деструкція компонентів електроліту. Додатковий джоулів нагрів від зарядного струму здатен зіштовхнути комірку в неконтрольований тепловий розгін.

Для реалізації цього профілю на рівні прошивки мікроконтролера розроблено алгоритм із гістерезисом та контролем швидкості наростання температури `dT/dt`, представлений у [проєктному модулі](root:hw-power/povodzhennia-z-li-ion/proj-jeita-guard.md).

## Правила зберігання та саморозряд: чому 100% і 0% однаково згубні

Хімічна деградація (лат. *degradatio* — зниження якості) акумулятора триває безперервно, навіть коли він лежить на полиці без підключеного навантаження. Проте швидкість цього старіння кардинально залежить від двох параметрів: **рівня заряду (SOC, State of Charge)** та **температури навколишнього середовища**.

![Деградація ємності Li-ion залежно від умов зберігання](/root/hw/hw-power/povodzhennia-z-li-ion/img/storage-degradation.svg)
*Вплив умов тривалого консервування на щорічну безповоротну втрату ємності: зберігання на 100% заряді прискорює старіння в 5–10 разів, тоді як 0% заряду загрожує повним розчиненням міді при перерозряді нижче 2.0 В.*

### Небезпека зберігання на повному заряді (100% SOC / 4.20 В)

Коли комірка заряджена до 4.20 В:
* Із катода вилучено понад 50% іонів літію. Кристалічна ґратка кобальтату або нікелату переходить у високоокиснений стан із нестабільною валентністю металів (наприклад, `Co⁴⁺` або `Ni⁴⁺`).
* Катод має сильний термодинамічний потенціал, що відбирає електрони у молекул органічного розчинника електроліту (етиленкарбонату). Відбувається постійне повільне окиснення електроліту з виділенням газів (`CO₂`, `CO`).
* На аноді графіт повністю насичений літієм, що створює максимальний градієнт хімічного потенціалу відносно електроліту, змушуючи пасиваційний шар SEI безперервно товщати, нарощуючи внутрішній опір комірки.

Якщо повністю заряджену комірку лишити на спеці (+45 °C) на кілька місяців, вона втратить до 30–35% своєї первинної ємності за рік без жодного циклу роботи.

### Небезпека зберігання на нульовому заряді (0% SOC / <2.50 В)

Будь-яка комірка має власний природний хімічний саморозряд (близько 0.5–2% ємності на місяць за кімнатної температури). Якщо до комірки підключено захисну плату BMS, її мікросхеми споживають додатковий струм спокою (від 5 до 50 мкА). Якщо залишити акумулятор розрядженим «в нуль» (напруга відсічки 3.0 В), через кілька місяців саморозряд неминуче опустить напругу нижче 2.5 В, а згодом — нижче критичного порога 2.0 В.

За напруги нижче 2.0 В починається катастрофічний процес — **розчинення мідного струмознімача**:

![Розчинення мідного струмознімача та утворення мідних містків](/root/hw/hw-power/povodzhennia-z-li-ion/img/copper-shunting.svg)
*Каскад руйнування комірки при перерозряді: при напрузі нижче 2.0 В потенціал анода піднімається вище +3.56 В vs Li/Li⁺, мідна фольга розчиняється в електроліті у вигляді іонів Cu²⁺, а наступна спроба заряду відновлює мідь у вигляді суцільних металевих шунтів крізь сепаратор.*

1. **Підйом потенціалу анода:** При глибокому перерозряді (лат. *dis-* — розділення + *carricare* — вантажити) з графіту вимиваються всі іони літію. Потенціал анода починає нестримно зростати вгору й перетинає відмітку **+3.56 В** відносно `Li/Li⁺`.
2. **Окиснення мідної фольги:** За потенціалу понад +3.56 В мідна фольга, на яку нанесено графіт, втрачає електрохімічну стійкість і починає окиснюватися, розчиняючись в електроліті:

```
Cu → Cu²⁺ + 2e⁻
```

3. **Дифузія іонів міді:** Іони `Cu²⁺` розчиняються в рідкому електроліті й вільно проникають крізь пори полімерного сепаратора, розподіляючись по всьому міжелектродному об'єму.
4. **Утворення мідних містків при заряді:** Коли користувач підключає зарядний пристрій до такої «виснаженої» комірки, потенціал анода знову падає. Іони `Cu²⁺` відновлюються назад у металеву мідь прямо всередині пор сепаратора:

```
Cu²⁺ + 2e⁻ → Cu⁰ (металевий мідний дендрит)
```

На відміну від літію, мідь не реагує з електролітом і не розчиняється. Утворюються монолітні металеві містки, що прошивають сепаратор наскрізь. Комірка отримує постійне внутрішнє коротке замикання. Спроба зарядити таку комірку стандартним струмом викликає колосальний локальний нагрів у місцях мідних шунтів і майже гарантовано призводить до пожежі.

### Оптимальний режим тривалого зберігання (Storage Voltage)

Для консервування літій-іонних батарей на термін від кількох місяців до років слід дотримуватися трьох правил:

1. **Напруга зберігання (Storage Voltage):** Комірки повинні мати напругу **3.80–3.85 В** (для хімії LiFePO4 — 3.25–3.30 В), що відповідає ступеню наповнення **40–50% SOC**. За цієї напруги катод і анод перебувають у хімічно збалансованому стані з мінімальним окиснювальним стресом, а залишкового заряду вистачає на 1.5–2 роки компенсації саморозряду до досягнення порога UVP.
2. **Температура:** Оптимально зберігати в сухому прохолодному приміщенні за температури **+10...+15 °C** (не вище +20 °C). Зберігання в холодильнику дозволене лише в герметичній упаковці з силікагелем для запобігання утворенню конденсату на контактах.
3. **Ревізія заряду:** Раз на 6–12 місяців необхідно вимірювати напругу мультиметром і підзаряджати блок до рівня 3.85 В у разі просідання нижче 3.65 В.

## Порівняння хімічних систем: LCO, NMC, LFP та LTO

Різні катодні та анодні матеріали мають кардинально різну термодинамічну стійкість та схильність до аварійних режимів:

| Хімія комірки | Номінальна напруга | Початок розпаду катода | Кисневиділення | Ризик плакування | Рівень безпеки |
|---|---|---|---|---|---|
| **LCO** (`LiCoO₂`) | 3.70 В | 150–180 °C | Дуже високе | Високий (анод — графіт) | Низький (вибухове горіння) |
| **NMC 811** (`LiNi₀.₈Mn₀.₁Co₀.₁O₂`) | 3.65 В | 170–200 °C | Високе | Високий (анод — графіт) | Помірний (потребує жорсткої BMS) |
| **LFP** (`LiFePO₄`) | 3.20 В | 270–300 °C | Відсутнє (зв'язок P–O) | Помірний | Дуже високий (без відкритого полум'я) |
| **LTO** (`Li₄Ti₅O₁₂`) | 2.40 В | > 300 °C | Відсутнє | Нульовий (потенціал 1.55 В) | Екстремально високий |

* **Олівінова структура LFP:** Завдяки надміцним ковалентним зв'язкам фосфор-кисень (`P–O`) фосфат заліза не виділяє вільний кисень навіть при нагріванні понад 250 °C. Горіння можливе лише при зовнішньому підпалі парів електроліту.
* **Титанатний анод LTO:** Робочий потенціал анода з оксиду титану становить +1.55 В vs `Li/Li⁺`. Це в 15 разів вище за поріг осадження металевого літію (0.0 В), що повністю унеможливлює ріст дендритів за будь-яких струмів і морозів до -30 °C.

## Діагностика ушкодженої комірки: як виявити внутрішню біду

Перед експлуатацією чи заряджанням батарейного блока інженер зобов'язаний виконати діагностику стану комірок за чотирма основними маркерами.

### 1. Механічні та візуальні дефекти
* **Здуття пакетних комірок (Pouch / Li-Po):** Утворення газових кишень свідчить про розклад електроліту через перезаряд, високу температуру або старіння. Газ розсуває шари електродів, різко збільшуючи внутрішній опір і погіршуючи тепловідвід. Будь-яке механічне здуття — пряме показання до списання та утилізації комірки.
* **Спрацювання аварійного клапана CID у циліндрах:** У якісних елементах 18650/21700 під плюсовим контактом встановлено біметалевий переривач струму (CID, Current Interrupt Device). При зростанні внутрішнього тиску газів понад 10–12 атм мембрана вигинається й фізично розмикає коло. Якщо на клемах комірки мультиметр показує рівно 0.00 В за цілісного корпусу, це означає спрацювання CID через внутрішній аварійний тиск. Відновлювати та продавлювати мембрану голкою суворо заборонено — це прямий шлях до вибуху.

### 2. Електричні симптоми внутрішніх дефектів
* **Аномальний саморозряд:** Якщо свіжозаряджена комірка, залишена у стані спокою за кімнатної температури, втрачає понад 50–100 мВ за добу (наприклад, просідає з 4.20 В до 4.05 В), це свідчить про наявність внутрішнього мікрокороткого замикання (мідні містки або дендрити літію).
* **Стрибок внутрішнього опору (`ΔR_int > 150–200%`):** Вимірювання імпедансу на частоті 1 кГц або за постійним струмом показує деградацію струмознімачів, висихання електроліту або відшарування активної маси.
* **Глибока просадка напруги під навантаженням:** При підключенні номінального струму напруга миттєво падає нижче 3.2 В.

### 3. Теплова асиметрія
Якщо під час спокійного заряду помірним струмом (0.5C) одна комірка в пакеті нагрівається на 10–15 °C сильніше за сусідні, це означає протікання струму через внутрішні паразитні шунти з перетворенням енергії в тепло.

> ⚠️ **Головне правило електробезпеки:** Комірку, напруга якої впала нижче 1.5 В, або яка має видимі вм'ятини, здуття чи запах солодкуватого органічного розчинника (ознака розгерметизації), **КАТЕГОРИЧНО ЗАБОРОНЕНО** підключати до зарядного пристрою стандартним струмом. Будь-яка спроба форсованого заряду ушкодженого літію є основною причиною лабораторних і побутових пожеж.

## Каскад теплового розгону (Thermal Runaway)

Найнебезпечнішим сценарієм для літій-іонного акумулятора є явище **теплового розгону** (англ. *Thermal Runaway*; лат. *thermalis* — тепловий + укр. *розгін*). Це лавиноподібна самопідтримувана екзотермічна хімічна реакція, під час якої швидкість внутрішнього виділення тепла значно перевищує швидкість тепловідведення в навколишнє середовище (`q_gen >> q_cool`).

![Каскад температурних стадій теплового розгону](/root/hw/hw-power/povodzhennia-z-li-ion/img/thermal-runaway-stages.svg)
*П'ять стадій каскадного термічного розкладу літій-іонної комірки: депасивація анода за 80–120 °C запускає саморозігрів, плавлення сепаратора створює внутрішнє коротке замикання, а розпад катода з виділенням кисню перетворює горіння на незворотний вибуховий процес.*

Процес розгону розгортається у п'ять послідовних температурних етапів:

1. **Стадія 1 (80 °C – 120 °C) — Розпад пасиваційного SEI-шару:** Метастабільні компоненти пасиваційної плівки анода (алкілкарбонати літію, `(CH₂OCO₂Li)₂`) зазнають екзотермічного розпаду з виділенням вуглекислого газу та тепла:

```
(CH₂OCO₂Li)₂ → Li₂CO₃ + C₂H₄ + CO₂ + 0.5 O₂  (ΔH ≈ -250 Дж/г)
```

Графіт втрачає захисну оболонку й контактує безпосередньо з чистим рідким електролітом. Швидкість саморозігріву становить від 0.2 до 1 °C/хв.

2. **Стадія 2 (120 °C – 140 °C) — Реакція літію в графіті з розчинником:** Інтеркальований літій у графіті бурхливо реагує з органічними карбонатами електроліту. Виділяються горючі вуглеводневі гази (метан, етан, пропен) та водень. Швидкість розігріву підскакує до 5–10 °C/хв.

3. **Стадія 3 (130 °C – 170 °C) — Плавлення полімерного сепаратора:** Поліетиленовий шар сепаратора плавиться за температури ~130–135 °C, поліпропіленовий — за ~165 °C. Сепаратор стягується й утворює розриви на великій площі. Анод і катод входять у прямий контакт: починається масивне внутрішнє коротке замикання (ISC). Струм короткого замикання миттєво розряджає весь накопичений електрохімічний заряд у тепло.

4. **Стадія 4 (180 °C – 240 °C) — Розпад катода з виділенням кисню:** Оксидна матриця катода (LCO, NMC, NCA) зазнає незворотного термічного піролізу (грец. *pŷr* — вогонь + *lýsis* — розчинення). Кристалічна ґратка руйнується, вивільняючи атомарний і молекулярний кисень (`O₂`):

```
LiCoO₂ → 1/3 Li₃CoO₄ + 1/3 Co₃O₄ + 1/6 O₂  (за T > 190 °C)
```

5. **Стадія 5 (>250 °C – 800 °C+) — Самопідтримуване вибухове горіння:** Вивільнений кисень катода зустрічається з перегрітими парами органічного розчинника електроліту всередині замкненого об'єму гільзи. Для горіння більше не потрібен кисень із повітря — батарея містить у собі і пальне, і окиснювач. Тиск газів підскакує до 30–50 атмосфер, розриваючи корпус із факельним викидом розжареного полум'я, токсичного фтороводню (`HF`) та фосфорилоксифториду (`POF₃`).

Паралельно сіль `LiPF₆` за високої температури розпадається на фторид літію та газоподібний пентафторид фосфору:

```
LiPF₆ ⇄ LiF + PF₅
PF₅ + H₂O → POF₃ + 2 HF
```

Утворений фтороводень (`HF`) є смертельно небезпечним газом, що вражає дихальні шляхи персоналу та роз'їдає будь-яке металеве обладнання в зоні аварії.

Математичний розрахунок точки теплової біфуркації та критичного перепаду температури Семенова виведено в [математичній вставці](root:hw-power/povodzhennia-z-li-ion/math-thermal-runaway-balance.md).

## Локалізація, гасіння та безпечна нейтралізація

Хімічна природа літій-іонної пожежі кардинально відрізняється від горіння звичайних матеріалів (клас A) або лужних металів (клас D).

### Головний парадокс пожежогасіння Li-ion

Літій-іонний акумулятор практично **не містить вільного металевого літію** (на відміну від первинних одноразових батарейок типу `Li-SOCl₂` чи `Li-MnO₂`). Тому:
* **Порошкові вогнегасники класу D (для металів) неефективні:** Вони розраховані на ізоляцію поверхні палаючого натрію чи літію від атмосферного повітря.
* **Вуглекислотні (CO₂) та пінні вогнегасники не зупиняють розгін:** Оскільки катод сам виділяє кисень (`O₂`) під час термолізу, перекриття доступу зовнішнього повітря не припиняє внутрішнє окиснення.

Єдиним фізично дієвим методом зупинки теплового розгону є **глибоке й масивне охолодження** тіла акумулятора нижче критичної температури реакції розпаду (нижче 80 °C).

Саме тому міжнародні протипожежні стандарти (NFPA, FAA) визначають **воду** як основний засіб боротьби з літій-іонними пожежами. Вода має рекордну питому теплоємність (`c = 4184 Дж/(кг·К)`) та приховану теплоту пароутворення (`L = 2.26 МДж/кг`). Заливання палаючого блоку великою кількістю води швидко відбирає тепло та зупиняє передачу теплового удару на сусідні комірки збірки.

### Лабораторне обладнання для локалізації
1. **Захисні вогнетривкі чохли (LiPo Safe Bags):** Склотканинні мішки з алюмінієвим термостійким покриттям затримують відкрите полум'я й осколки при розриві пакетних акумуляторів під час тестового заряджання.
2. **Металеві бокси з вермикулітом:** Спеціальні контейнери (наприклад, патронні ящики з видаленим гумовим ущільнювачем для стравлювання тиску), заповнені гранульованим вермикулітом або пірогенним кремнеземом, які поглинають рідкі викиди та гасять ударну хвилю.

### Методика нейтралізації та підготовки до утилізації

Якщо комірка зазнала механічного пошкодження або глибокого перерозряду, її необхідно повністю розрядити в нуль перед передачею в пункт переробки.

* **Еталонний інженерний метод (резистивний розряд):** Комірку підключають до потужного керамічного резистора опором 50–100 Ом (потужністю 10–25 Вт). Розряд триває 24–48 годин під контролем вольтметра, доки залишковий потенціал не складе рівно 0.00 В. Після цього клеми закорочують мідною перемичкою.
* **Небезпека солоної води (Brine Bath):** Популярний у побуті метод занурення батареї у відро з солоною водою (`NaCl`) має серйозні вади. Електроліз сольового розчину викликає швидке відгнивання тонких нікелевих або мідних контактних виводів ще до того, як комірка встигне розрядитися. Крім того, у процесі виділяється токсичний газоподібний хлор (`Cl₂`). Якщо застосовується водна ванна, слід використовувати розчин харчової соди (`NaHCO₃`) і проводити процедуру виключно на відкритому повітрі.

## Програмний модуль супервізора безпеки

Для гарантованого захисту комірок у вбудованих пристроях застосовують програмний контролер безпеки, який зчитує показники датчиків струму, напруги та температури NTC, контролює виконання профілю JEITA та блокує роботу силового перетворювача при небезпечних відхиленнях.

```c
/* battery_supervisor.h / battery_supervisor.c */
#include <stdint.h>
#include <stdbool.h>

typedef enum {
    BATT_STATE_SAFE_DISCHARGE = 0,
    BATT_STATE_JEITA_CHARGE,
    BATT_STATE_STORAGE_IDLE,
    BATT_STATE_FAULT_LOCKOUT
} batt_state_t;

typedef struct {
    uint16_t cell_voltage_mv;   /* Напруга комірки, мВ */
    int16_t  pack_temp_c;       /* Температура, градуси Цельсія */
    int16_t  charge_current_ma; /* Зарядний струм, мА */
} batt_telemetry_t;

typedef struct {
    bool charge_allowed;        /* Прапорець дозволу заряду */
    uint16_t max_voltage_mv;    /* Гранична напруга відсічки */
    uint16_t max_current_ma;    /* Дозволений струм */
    uint8_t fault_flags;        /* Маска помилок */
} batt_control_t;

#define FAULT_OVERVOLTAGE   (1 << 0)
#define FAULT_UNDERVOLTAGE  (1 << 1)
#define FAULT_COLD_CHARGE   (1 << 2)
#define FAULT_OVERTEMP      (1 << 3)
#define FAULT_DEEP_DISCHG   (1 << 4)

void batt_supervisor_step(const batt_telemetry_t *telem, batt_control_t *ctrl) {
    ctrl->fault_flags = 0;

    /* 1. Перевірка критичного перерозряду (< 2.0 В) — розчинення міді */
    if (telem->cell_voltage_mv < 2000) {
        ctrl->fault_flags |= FAULT_DEEP_DISCHG;
        ctrl->charge_allowed = false;
        ctrl->max_current_ma = 0;
        return; /* Повне блокування: заряд суворо заборонено! */
    }

    /* 2. Перевірка граничних напруг */
    if (telem->cell_voltage_mv > 4250) {
        ctrl->fault_flags |= FAULT_OVERVOLTAGE;
    }

    /* 3. Оцінка температурного вікна JEITA для заряду */
    if (telem->pack_temp_c < 0) {
        /* Холод: заборона заряду через плакування літію */
        ctrl->fault_flags |= FAULT_COLD_CHARGE;
        ctrl->charge_allowed = false;
        ctrl->max_current_ma = 0;
        ctrl->max_voltage_mv = 4200;
    } else if (telem->pack_temp_c < 10) {
        /* Прохолодно: знижений струм 0.2C */
        ctrl->charge_allowed = true;
        ctrl->max_current_ma = 500;
        ctrl->max_voltage_mv = 4200;
    } else if (telem->pack_temp_c <= 45) {
        /* Стандартний безпечний режим */
        ctrl->charge_allowed = true;
        ctrl->max_current_ma = 2000;
        ctrl->max_voltage_mv = 4200;
    } else if (telem->pack_temp_c < 60) {
        /* Тепло: зниження напруги до 4.10 В для захисту катода */
        ctrl->charge_allowed = true;
        ctrl->max_current_ma = 1000;
        ctrl->max_voltage_mv = 4100;
    } else {
        /* Спека: небезпека теплового розгону */
        ctrl->fault_flags |= FAULT_OVERTEMP;
        ctrl->charge_allowed = false;
        ctrl->max_current_ma = 0;
        ctrl->max_voltage_mv = 4100;
    }
}
```

```cpp
// BatterySupervisor.hpp — Ідіоматичний модуль контролю безпеки на C++20
#pragma once
#include <cstdint>
#include <expected>

namespace BatteryManagement {

enum class SafetyError : uint8_t {
    None = 0,
    OverVoltage,
    DeepOverDischarge,
    ColdPlatingHazard,
    OverTemperature
};

struct BatteryTelemetry {
    uint16_t cell_voltage_mv;
    int16_t  temperature_c;
    int16_t  current_ma;
};

struct TargetChargeProfile {
    bool allow_charge{false};
    uint16_t max_voltage_mv{4200};
    uint16_t max_current_ma{0};
};

class BatterySupervisor {
public:
    [[nodiscard]] static constexpr std::expected<TargetChargeProfile, SafetyError>
    evaluate_policy(const BatteryTelemetry& telem) noexcept {
        // 1. Захист від розчинення міді при перерозряді нижче 2.0 В
        if (telem.cell_voltage_mv < 2000) {
            return std::unexpected(SafetyError::DeepOverDischarge);
        }

        // 2. Захист від перезаряду
        if (telem.cell_voltage_mv > 4250) {
            return std::unexpected(SafetyError::OverVoltage);
        }

        // 3. JEITA температурне профілювання
        if (telem.temperature_c < 0) {
            return std::unexpected(SafetyError::ColdPlatingHazard);
        }

        if (telem.temperature_c >= 60) {
            return std::unexpected(SafetyError::OverTemperature);
        }

        TargetChargeProfile profile{};
        profile.allow_charge = true;

        if (telem.temperature_c < 10) {
            profile.max_current_ma = 500;  // 0.2C..0.5C на холоді
            profile.max_voltage_mv = 4200;
        } else if (telem.temperature_c <= 45) {
            profile.max_current_ma = 2000; // 1.0C номінал
            profile.max_voltage_mv = 4200;
        } else {
            // 45..60 °C — знижена напруга для захисту електроліту
            profile.max_current_ma = 1000;
            profile.max_voltage_mv = 4100;
        }

        return profile;
    }
};

} // namespace BatteryManagement
```

## Підсумок інженерної дисципліни

Безпека літій-іонної батареї спирається на жорстке дотримання трьох непорушних меж:

1. **Температурний бар'єр:** Заряд заборонено нижче 0 °C (небезпека росту літієвих дендритів) та вище 60 °C (небезпека теплового розгону).
2. **Дисципліна напруги:** Робоче вікно утримується в діапазоні 3.00–4.20 В. Падіння нижче 2.00 В викликає розчинення мідного струмознімача й перетворює комірку на аварійну; тривале зберігання вимагає напруги 3.80–3.85 В.
3. **Реакція на аварію:** Здуті чи глибоко розряджені комірки вибраковуються без спроб відновлення, а локалізація аварійного займання забезпечується масивним охолодженням водою.
