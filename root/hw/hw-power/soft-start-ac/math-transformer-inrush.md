# 🧮 Математика кидка струму в трансформаторі: інтеграл потоку та насичення осердя

Цей математичний розрахунок розкриває повний аналітичний апарат виникнення та розрахунку надструму намагнічування силового трансформатора під час комутації на змінну напругу: від інтегрування закону Фарадея за довільної початкової фази вмикання до кількісного розрахунку пікового струму насичення через індуктивність повітряного осердя, аналізу трифазних з'єднань (зірка/трикутник), топологій магнітопроводів (3-стрижневі проти 5-стрижневих), явища взаємного (симпатичного) намагнічування паралельних трансформаторів, розрахунку джоулевого інтеграла плавких вставок, порівняння електротехнічних сталей з аморфними сплавами, спектрального розкладу Фур'є з виділенням другої гармоніки та математики керованої синхронної комутації (Point-on-Wave).

## Закон індукції та потік у часовій області

Зв'язок між миттєвою напругою на первинній обмотці трансформатора `v(t)` та магнітним потоком в осерді `Φ(t)` визначається фундаментальним законом електромагнітної індукції Фарадея:

```
v(t) = N · dΦ/dt + R · i(t)
```

де `N` — кількість витків первинної обмотки, `R` — активний опір міді обмотки. В усталеному режимі роботи силових трансформаторів спад напруги на активному опорі первинної обмотки `R · i(t)` становить менше ніж 0.5–1 % від номінальної напруги мережі, тому на першому півперіоді після вмикання ним можна знехтувати для знаходження магнітного потоку.

Інтегруючи напругу від миті комутації `t = 0` до довільного моменту часу `t`, отримуємо залежність магнітного потоку від прикладеної напруги:

```
Φ(t) = Φ_rem + (1 / N) · ∫[0..t] v(τ) dτ
```

де `Φ_rem` — залишковий магнітний потік (англ. *remanent flux*), що зберігся у феромагнітному осерді від моменту попереднього вимикання трансформатора.

## Залежність магнітного потоку від кута вмикання

Нехай напруга живильної мережі змінюється за гармонічним законом із кутовою частотою `ω = 2·π·f` (для мережі 50 Гц кутова частота `ω = 314.159 рад/с`):

```
v(t) = V_pk · sin(ω·t + ψ)
```

де `V_pk = √2 · V_rms` — амплітуда напруги мережі, а `ψ` — фазовий кут напруги в мить замикання контактів вимикача (`t = 0`).

Підставимо закон зміни напруги в інтеграл потоку:

```
Φ(t)
= Φ_rem + (V_pk / N) · ∫[0..t] sin(ω·τ + ψ) dτ    [підстановка напруги]
= Φ_rem − (V_pk / (ω·N)) · [cos(ω·τ + ψ)][0..t]    [первісна від синуса: −cos/ω]
= Φ_rem + (V_pk / (ω·N)) · [cos(ψ) − cos(ω·t + ψ)]  [підстановка меж інтегрування]
```

Введемо позначення амплітуди усталеного номінального магнітного потоку `Φ_max`:

```
Φ_max = V_pk / (ω·N) = (√2 · V_rms) / (2·π·f · N)
```

Тоді рівняння магнітного потоку в осерді набуває вигляду:

```
Φ(t) = Φ_rem + Φ_max · cos(ψ) − Φ_max · cos(ω·t + ψ)
```

У цьому виразі чітко видно дві складові:
1. Змінна періодична складова: `−Φ_max · cos(ω·t + ψ)`, що коливається з частотою 50 Гц навколо зміщеного центру.
2. Аперіодична постійна складова: `Φ_dc = Φ_rem + Φ_max · cos(ψ)`, рівень якої повністю визначається кутом комутації `ψ` та залишковою намагніченістю `Φ_rem`.

## Найгірший випадок: увімкнення в нуль напруги

Якщо комутація трансформатора відбувається в момент проходження напруги мережі через нуль (`ψ = 0`):

```
Φ(t)
= Φ_rem + Φ_max · cos(0) − Φ_max · cos(ω·t + 0)   [підстановка ψ = 0]
= Φ_rem + Φ_max · (1 − cos(ω·t))                  [винесення Φ_max за дужки]
```

Через половину періоду мережі (`t = T/2 = 10 мс` для 50 Гц, кут `ω·t = π`):

```
cos(π) = −1
Φ_pk = Φ(T/2) = Φ_rem + Φ_max · (1 − (−1)) = 2·Φ_max + Φ_rem
```

Магнітний потік досягає пікового значення, що дорівнює **подвоєному номінальному потоку плюс залишковий потік**.

## Чутливість пікового потоку до кута комутації ψ

Проаналізуємо, як піковий потік першого періоду залежить від фази увімкнення `ψ` у діапазоні від `0°` до `90°` (`π/2 рад`).

Пік потоку настає у момент, коли періодична косинусоїда досягає свого від'ємного мінімуму `cos(ω·t + ψ) = −1`:

```
Φ_пік(ψ) = Φ_rem + Φ_max · (1 + cos(ψ))
```

Співвідношення між фазою вмикання `ψ` та піковим магнітним потоком при типовій залишковій намагніченості `Φ_rem = 0.4 · Φ_max`:

| Кут вмикання напруги ψ | `cos(ψ)` | Піковий потік `Φ_пік / Φ_max` | Режим насичення осердя |
| :--- | :--- | :--- | :--- |
| **ψ = 0° (Перехід через нуль)** | 1.000 | `0.4 + 1.0 · (1 + 1.0) = 2.40` | **Глибоке насичення (катастрофічний кидок струму)** |
| **ψ = 30° (π/6 рад)** | 0.866 | `0.4 + 1.0 · (1 + 0.866) = 2.27` | Глибоке насичення (дуже високий струм) |
| **ψ = 45° (π/4 рад)** | 0.707 | `0.4 + 1.0 · (1 + 0.707) = 2.11` | Сильне насичення |
| **ψ = 60° (π/3 рад)** | 0.500 | `0.4 + 1.0 · (1 + 0.500) = 1.90` | Початок насичення |
| **ψ = 90° (Пік напруги)** | 0.000 | `0.4 + 1.0 · (1 + 0.000) = 1.40` | **Повна відсутність насичення (номінальний струм)** |

Цей аналіз наочно демонструє, що найбезпечнішим моментом для комутації однофазного трансформатора є амплітудний максимум напруги (`ψ = 90°`), коли початковий потік коливається навколо залишкового значення без перетину порогу насичення сталі.

## Трифазні трансформатори: чому одночасна комутація трьох фаз неминуче викликає кидок

У трифазних трансформаторах три фазні напруги зсунуті між собою на кут `120°` (`2·π/3`):

```
v_A(t) = V_pk · sin(ω·t + ψ)
v_B(t) = V_pk · sin(ω·t + ψ − 120°)
v_C(t) = V_pk · sin(ω·t + ψ + 120°)
```

Якщо триполюсний автоматичний вимикач замикає всі три контакти одночасно, неможливо обрати кут `ψ`, за якого всі три напруги опинилися б у піку:
- Якщо `ψ = 90°` (фаза A вмикається в максимумі напруги `v_A = V_pk`), то фази B та C мають напруги `sin(90° − 120°) = sin(−30°) = −0.5 · V_pk`.
- Інтеграл напруги у фазах B і C починається поблизу нуля, що неминуче викликає накопичення потоку `Φ_B(t)` та `Φ_C(t)` понад `1.8 · Φ_max` і спричиняє насичення відповідних стрижнів трифазного магнітопроводу.

У трансформаторах зі з'єднанням первинної обмотки в «трикутник» (Δ) або з наявністю компенсаційної вторинної обмотки трикутника виникає додатковий циркуляційний струм нульової послідовності `I_0 = ⅓ · (i_A + i_B + i_C)`, який частково згладжує асиметрію намагнічування між стрижнями за рахунок взаємної магнітної індукції.

### Вплив конструкції магнітопроводу: 3-стрижневі проти 5-стрижневих осердь

Геометрія трифазного магнітопроводу суттєво впливає на розподіл потоків насичення:
1. **Тристрижневий магнітопровід (3-Leg Core):** Стрижні магнітно зв'язані між собою: сума потоків трьох стрижнів має дорівнювати нулю (`Φ_A + Φ_B + Φ_C = 0`). Коли один зі стрижнів насичується, надлишковий магнітний потік не може замкнутися через сусідні стрижні й вимушений виходити в повітря, трансформаторне масло та сталеві стінки бака трансформатора. Високий магнітний опір повітряного шляху обмежує піковий потік, але викликає локальний нагрів сталевого бака вихровими струмами.
2. **П'ятистрижневий магнітопровід (5-Leg Core) та броньові конструкції:** Мають два бічні розвантажувальні ярма без обмоток. Потік нульової послідовності вільно замикається через бічні ярма з низьким магнітним опором. Внаслідок цього стрижні зазнають глибшого насичення, а піковий пусковий струм виявляється на 20–30 % вищим, ніж у 3-стрижневих аналогів.

## Симпатичний кидок струму в паралельних трансформаторах (Sympathetic Inrush)

Складне перехідне явище виникає, коли новий трансформатор `T2` вмикається в шини підстанції паралельно з трансформатором `T1`, який уже тривалий час перебуває під навантаженням.

Під час комутації `T2` його колосальний надструм намагнічування `i_inrush_2(t)` протікає через внутрішній імпеданс живильної енергосистеми `Z_sys = R_sys + j·ω·L_sys`. Це спричиняє спотворення та асиметричний спад напруги на загальних шинах підстанції:

```
v_bus(t) = v_grid(t) − R_sys · i_total(t) − L_sys · (d(i_total)/dt)
```

Цей асиметричний провал напруги містить постійну складову (DC bias). Оскільки працюючий трансформатор `T1` підключений до цих самих шин, постійна складова напруги починає інтегруватися в його осерді:

```
Φ_1(t) = Φ_1_уст(t) + (1 / N_1) · ∫[0..t] v_dc_bus(τ) dτ
```

У результаті вже працюючий трансформатор `T1`, який щойно працював у нормальному режимі, сам заходить у глибоке магнітне насичення! Обидва трансформатори починають обмінюватися перехресними аперіодичними струмами намагнічування. Взаємний перехідний процес затухає значно повільніше, ніж одиночний пуск — симпатичний кидок струму може тривати від 10 до 60 секунд, спричиняючи аварійне відключення всієї секції шин релейним захистом.

## Розрахунок інтеграла Джоуля (I²·t) для захисних апаратів

Для запобігання помилковому перегорянню плавких вставок запобіжників або спрацьовуванню теплових розчіплювачів під час пуску трансформатора виконують інтегрування квадрата миттєвого струму за час перехідного процесу:

```
I²t_пуск = ∫[0..t_затухання] i(t)² dt
```

Оскільки струм спадає за експоненційним законом `i_pk · exp(−t / τ_dc)`, аналітичний розрахунок джоулевого інтеграла дає:

```
I²t_пуск ≈ ½ · i_pk² · τ_dc
```

Номінальний захисний інтеграл плавлення запобіжника `I²t_fuse` повинен перевищувати розрахункове значення `I²t_пуск` щонайменше у 2.5–3.0 рази, що часто змушує встановлювати запобіжники завищеного номіналу, погіршуючи захист від реальних тривалих перевантажень.

## Вплив матеріалу магнітопроводу: електротехнічна сталь проти аморфних сплавів

Сучасні енергозберігаючі трансформатори дедалі частіше виготовляють з аморфних металевих стрічок (англ. *Amorphous Metal Core*, наприклад Metglas 2605SA1) або нанокристалічних сплавів.

Порівняння параметрів насичення та залишкової індукції:

| Матеріал магнітопроводу | Робоча індукція B_max | Індукція насичення B_sat | Коерцитивна сила H_c | Залишкова індукція B_rem / B_sat | Кидок пускового струму |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Гарячекатана сталь (CRNGO)** | 1.2–1.4 Тл | 1.9–2.1 Тл | 40–60 А/м | 0.3–0.4 (30–40 %) | 8–15 × Іном |
| **Холоднокатана анізотропна сталь (CRGO)** | 1.5–1.7 Тл | 1.8–2.0 Тл | 15–25 А/м | 0.5–0.7 (50–70 %) | 15–30 × Іном |
| **Аморфний сплав (Metglas)** | 1.2–1.35 Тл | 1.56 Тл | 3–6 А/м | 0.80–0.90 (80–90 %) | **35–60 × Іном** |

Через виняткову прямокутність петлі гістерезису аморфних сплавів залишкова намагніченість `B_rem` досягає 90 % від індукції насичення. Навіть незначний інтеграл прикладеної напруги миттєво вганяє аморфний трансформатор у глибоке насичення, викликаючи екстремальні надструми.

## Перехід від потоку до індукції та нелінійна петля гістерезису

Магнітна індукція в осерді `B(t)` пов'язана з потоком через площу поперечного перерізу сталевого магнітопроводу `A_core`:

```
B(t) = Φ(t) / A_core
```

Зв'язок між напруженістю магнітного поля `H` (яка створюється струмом в обмотці) та магнітною індукцією `B` визначається нелінійною кривою намагнічування електротехнічної сталі:

```
B = μ_r(H) · μ0 · H
```

Номінальна індукція трансформаторної сталі `B_max = Φ_max / A_core` зазвичай обирається в діапазоні 1.5–1.7 Тл для мінімізації маси та вартості міді й заліза. Початок глибокого насичення електротехнічної кремнієвої сталі настає при `B_sat ≈ 1.8...2.0 Тл`.

Залишковий магнітний потік створює залишкову індукцію `B_rem = Φ_rem / A_core`, яка для холоднокатаних анізотропних сталей може досягати 0.4–0.8 Тл.

При комутації в нуль напруги пікова розрахункова індукція становить:

```
B_pk = 2·B_max + B_rem
```

Для типових значень `B_max = 1.6 Тл` та `B_rem = 0.6 Тл`:

```
B_pk = 2 · 1.6 + 0.6 = 3.8 Тл
```

Оскільки залізо фізично не може утримати індукцію понад 2.0 Тл (через повну орієнтацію всіх магнітних доменів у напрямку поля), надлишок магнітного потоку виштовхується в повітряний простір обмотки. Диференційна магнітна проникність заліза `μ_diff = dB/dH` обвалюється від робочих значень `2000...5000 · μ0` до магнітної проникності вакууму `μ0 = 4·π·10⁻⁷ Гн/м`.

## Розрахунок індуктивності повітряного осердя та пікового струму

Коли осердя повністю насичене, первинна обмотка втрачає підсилення феромагнетика і поводиться як котушка без осердя (повітряний соленоїд). Індуктивність обмотки в режимі повного насичення `L_sat` наближено дорівнює геометрії повітряного простору обмотки з урахуванням коефіцієнта Роговського `k_R ≈ 0.85...0.95`:

```
L_sat ≈ (k_R · μ0 · N² · A_w) / h_w
```

де `A_w` — середня площа перерізу каркаса обмотки, `h_w` — висота обмотки вздовж стрижня.

Струм, необхідний для створення індукції понад поріг насичення `B_sat`, визначається за законом повного струму (теоремою про циркуляцію магнітного поля):

```
H_sat = (B_pk − B_sat) / μ0
i_pk = (H_sat · l_core) / N = ((2·B_max + B_rem − B_sat) · l_core) / (μ0 · N)
```

де `l_core` — середня довжина магнітної силової лінії осердя.

## Повний числовий приклад розрахунку

**Параметри трансформатора:**
- Номінальна потужність: `S_nom = 40 кВА`
- Номінальна первинна напруга: `V_rms = 400 В` (однофазне підключення)
- Частота мережі: `f = 50 Гц` (`ω = 314.16 рад/с`)
- Кількість витків первинної обмотки: `N = 120`
- Площа перерізу сталі осердя: `A_core = 0.015 м²` (150 см²)
- Середня довжина магнітної лінії: `l_core = 0.8 м`
- Номінальна робоча індукція: `B_max = 1.50 Тл`
- Індукція насичення сталі: `B_sat = 1.80 Тл`
- Залишкова індукція: `B_rem = 0.60 Тл`
- Активний опір первинної обмотки: `R_pri = 0.12 Ом`
- Індуктивність насиченої обмотки: `L_sat = 1.8 мГн` (`0.0018 Гн`)

```
Номінальний струм первинної обмотки:
I_nom = S_nom / V_rms = 40000 / 400 = 100 А
Амплітуда номінального струму:
I_nom_pk = √2 · I_nom = 1.414 · 100 = 141.4 А

Пікова магнітна індукція при комутації в ψ = 0:
B_pk = 2 · B_max + B_rem = 2 · 1.50 + 0.60 = 3.60 Тл

Перевищення порогу насичення:
ΔB = B_pk − B_sat = 3.60 − 1.80 = 1.80 Тл

Напруженість поля в насиченому стані:
H_pk = ΔB / μ0 = 1.80 / (4 · π · 10⁻⁷) = 1.432 · 10⁶ А/м

Піковий струм намагнічування в обмотці:
i_pk = (H_pk · l_core) / N
     = (1.432 · 10⁶ · 0.8) / 120
     = 9549 А

Відношення пікового струму до номінального:
i_pk / I_nom_pk = 9549 / 141.4 ≈ 67.5×
i_pk / I_nom    = 9549 / 100   ≈ 95.5×
```

## Диференційне рівняння та затухання перехідного процесу

Форма струму в часі описується нелінійним диференційним рівнянням першого порядку:

```
L(i) · di/dt + R_loop · i(t) = V_pk · sin(ω·t + ψ)
```

де `R_loop = R_pri + R_source + R_cable` — повний активний опір кола живлення.

Нелінійна індуктивність `L(i)` має кусково-лінійний характер:
- У ненасиченій зоні (`|B| ≤ B_sat`): індуктивність намагнічування величезна (`L_mag ≈ 2...10 Гн`), струм намагнічування мізерний (менше ніж 1–2 % `I_ном`).
- У насиченій зоні (`|B| > B_sat`): індуктивність падає до рівня повітряної котушки `L_sat ≈ 1...5 мГн`.

Через це струм протікає у вигляді однополярних гострих сплесків, що повторюються один раз за період (кожні 20 мс) під час позитивного півперіоду.

Постійна аперіодична складова магнітного потоку спадає за експонентою зі сталою часу:

```
τ_dc = L_екв / R_loop
```

Для потужних трансформаторів опір `R_pri` є вкрай малим (десяті частки відсотка), тому стала часу затухання `τ_dc` досягає 0.5–3.0 секунд. Кількість періодів, протягом яких діє струмовий стрес:

```
N_періодів ≈ (3 ... 5) · τ_dc · f = 3 · 1.0 · 50 = 150 періодів (3 секунди)
```

## Спектральний аналіз струму: домінування другої гармоніки

Оскільки імпульси струму насичення є строго однополярними (протікають лише в одній половині кожного періоду синусоїди), розклад кривої струму `i(t)` у ряд Фур'є дає унікальний гармонійний спектр:

```
i(t) = I_dc + I_1 · sin(ω·t + θ_1) + I_2 · sin(2·ω·t + θ_2) + I_3 · sin(3·ω·t + θ_3) + ...
```

На відміну від звичайного симетричного короткого замикання в навантаженні (де струм містить лише непарні гармоніки 1-шу, 3-тю, 5-ту), у пусковому струмі насиченого трансформатора **друга гармоніка (100 Гц)** досягає 20–60 % від амплітуди основної гармоніки (50 Гц):

```
I_2 / I_1 = 0.20 ... 0.60 (20 ... 60 %)
```

Ця фізична властивість покладена в основу роботи мікропроцесорного **диференційного релейного захисту** силових трансформаторів. Реле захисту безперервно вимірює відношення `I_2 / I_1`. Якщо це відношення перевищує поріг у 15–20 %, реле розпізнає процес як безпечний пусковий кидок намагнічування (англ. *inrush restraint*) і блокує помилкове вимкнення силового вимикача підстанції.

## Електродинамічні сили в обмотках

Колосальні імпульси струму породжують усередині обмоток потужні механічні сили взаємодії між провідниками зі струмом (сили Лоренца):

```
F(t) = (μ0 / (2·π)) · (i_1(t) · i_2(t) / d) · l_w ∝ i(t)²
```

де `d` — відстань між витками, `l_w` — довжина провідника.

Оскільки сила пропорційна квадрату миттєвого струму (`F ∝ i²`), при перевищенні номінального струму у 50 разів механічні стискальні та радіальні розривні зусилля в обмотках зростають у `50² = 2500` разів. Тиск на ізоляцію між витками сягає десятків тонн на квадратний метр. Повторювані пуски без обмеження струму призводять до поступового перетирання лакової ізоляції міді та міжвиткового короткого замикання.

## Синхронна комутація (Point-on-Wave Switching)

Сучасним високовольтним методом запобігання насиченню без використання тиристорів є **синхронна комутація за фазою напруги** (англ. *Point-on-Wave*, POW). Спеціальний мікропроцесорний контролер вимірює залишкову індукцію `B_rem` у момент відключення та керує кожним полюсом високовольтного вакуумного або елегазового вимикача індивідуально з точністю до 0.1 мілісекунди:
- Фаза A замикається в мить `ω·t = 90°` (пік напруги);
- Фази B і C замикаються із затримкою у чверть періоду в точках, де їхня напруга компенсує залишкову намагніченість стрижнів.

У низьковольтних мережах 400 В тиристорний софтстартер реалізує ще надійніший плавний підйом напруги: подаючи на осердя серію зрізаних імпульсів малої площі вольт-секундного інтеграла `∫ v dt`, софтстартер плавно розхитує потік навколо нуля, не допускаючи сумарного інтеграла вище ніж `Φ_sat`.
