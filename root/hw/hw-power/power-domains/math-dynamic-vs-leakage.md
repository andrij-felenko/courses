# 🧮 Розрахунок динамічної та статичної потужності CMOS при масштабуванні напруги

Коли мікроконтролер перемикає логічні вентилі на частоті в сотні мегагерців, споживання енергії визначається двома фундаментальними фізичними процесами: перезаряджанням паразитної ємності вузлів і витоками носіїв заряду через закриті транзистори. Розділення кристала на окремі силові домени дає змогу оптимізувати обидва ці механізми, подаючи на кожен функціональний блок напругу, що точно відповідає його вимогам за швидкодією та рівнем шумів. Нижче наведено математичне виведення складових потужності, розрахунок точки мінімального енергоспоживання (MEP), аналіз втрат у розподіленій мережі металізації та кількісну оцінку виграшу від переходу з єдиної шини 3.3 В на багадоменну архітектуру.

## Динамічна потужність перезаряджання ємності

Кожен логічний вентиль CMOS (англ. *Complementary Metal-Oxide-Semiconductor*, комплементарна структура метал-оксид-напівпровідник) містить вихідний вузол із сумарною паразитною ємністю `C[L]`. Ця ємність складається з ємності затворів наступних логічних каскадів, ємності збіднених шарів стоків та ємності паразитних металевих провідників топології.

При переході виходу з логічного нуля (0 В) в логічну одиницю (`V[DD]`) транзистор верхнього плеча PMOS відкривається і заряджає ємність `C[L]` від джерела живлення. Повна енергія `E[source]`, віддана джерелом живлення за один перехід:

```
E[source] = ∫[0..∞] V[DD] · i(t) dt
          = V[DD] · ∫[0..∞] i(t) dt               [джерело підтримує сталу напругу V[DD]]
          = V[DD] · Q                            [інтеграл струму в часі дорівнює переданому заряду]
          = V[DD] · (C[L] · V[DD])               [заряд конденсатора Q = C · V]
          = C[L] · V[DD]²                         [повна енергія, передана джерелом]
```

Енергія, яка безпосередньо запасається в електричному полі конденсатора `C[L]`:

```
E[cap] = ∫[0..V[DD]] q/C[L] dq
       = (1/2) · C[L] · V[DD]²                   [рівно половина енергії джерела переходить у поле]
```

Решта енергії неминуче розсіюється у вигляді тепла на активному омічному опорі відкритого каналу PMOS транзистора незалежно від його опору `R[DS(on)]`:

```
E[diss,PMOS] = E[source] - E[cap]
             = C[L] · V[DD]² - (1/2) · C[L] · V[DD]²
             = (1/2) · C[L] · V[DD]²             [теплові втрати в каналі під час заряду]
```

При зворотному переході з логічної одиниці в нуль PMOS закривається, відкривається нижній NMOS транзистор, і накопичена в електричному полі ємності енергія `E[cap] = (1/2) · C[L] · V[DD]²` повністю виділяється у вигляді тепла на опорі каналу NMOS, коли струм розряду стікає в землю.

Таким чином, за один повний цикл перемикання вентиля (0 → 1 → 0) у тепло перетворюється енергія:

```
E[cycle] = C[L] · V[DD]²
```

Якщо вентиль перемикається з тактовою частотою `f`, а коефіцієнт активності `α` (імовірність зміни стану за один тактовий період) відображає статистику роботи логіки, середня динамічна потужність перезаряджання становить:

```
P[dyn] = α · C[total] · V[DD]² · f
```

Квадратична залежність від напруги доводить: зниження напруги живлення ядра навіть на 30% (наприклад, з 1.2 В до 0.84 В) зменшує динамічні теплові втрати більш ніж на 50%.

## Втрати в розподіленій мережі металізації (PDN) та паразитні RC-ланцюги

У сучасних багатошарових інтегральних схемах цифрова логіка живиться через розподілену мережу провідників живлення (Power Distribution Network — PDN), що складається з 6–12 шарів мідної та алюмінієвої металізації.

Кожен провідник має погонний опір `R[wire]` та паразитну ємність відносно сусідніх шарів і підкладки `C[wire]`. При протіканні імпульсного струму `i(t)` у шинах виникають динамічні омічні втрати `P[IR]`:

```
P[IR] = ∫[0..T] i(t)² · R[wire] dt = I[rms]² · R[wire]
```

Оскільки середньоквадратичний струм `I[rms]` у логічному ядрі пропорційний добутку заряду на частоту `I[rms] ∝ C[total] · V[DD] · f`, омічні втрати на металізації масштабуються квазіквадратично від напруги живлення:

```
P[IR] ∝ R[wire] · (C[total] · V[DD] · f)²
```

Зниження напруги живлення ядра з 3.3 В до 1.0 В зменшує струмові навантаження на металізацію більш ніж утричі, що не лише мінімізує паразитний нагрів провідників, але й усуває явище електроміграції (англ. *electromigration* — перенесення атомів металу під дією високої густини струму), гарантуючи тривалий ресурс надійності кристала.

## Наскрізний струм короткого замикання (Crowbar)

Під час фронту перемикання вхідний сигнал проходить через проміжну ділянку напруг, коли вхідний потенціал перевищує порогову напругу NMOS (`V[th,n]`), але ще не досяг значення `V[DD] - |V[th,p]|`. У цьому інтервалі обидва транзистори інвертора одночасно перебувають у відкритому стані, створюючи прямий низькоомний шлях струму від шини живлення до землі.

Потужність наскрізного струму перекриття описується виразом:

```
P[sc] = I[peak] · t[sc] · V[DD] · f
```

де `I[peak]` — піковий струм перекриття, пропорційний питомій крутизні транзисторів `β` та кубу різниці `(V[DD] - V[th,n] - |V[th,p]|)³`, а `t[sc]` — тривалість фронту перемикання вхідного сигналу.

Коли напруга живлення `V[DD]` наближається до суми порогових напруг `V[th,n] + |V[th,p]|`, наскрізний струм практично повністю зникає, оскільки діапазон одночасної провідності звужується до нуля. При напрузі 1.0 В частка наскрізного струму в загальному динамічному балансі становить менше 2–4%, тоді як при напрузі 3.3 В вона може досягати 15–20%.

## Статичний струм підпорогового витоку та вплив температури

Коли польовий транзистор перебуває у закритому стані (`V[GS] = 0`), кремнієвий канал не стає абсолютним ізолятором. У субмікронних технологіях домінує підпороговий витік (англ. *subthreshold leakage*), зумовлений тепловою дифузією носіїв заряду через знижений потенціальний бар'єр між витоком і стоком:

```
I[sub] = I[0] · exp((V[GS] - V[th]) / (η · V[T])) · (1 - exp(-V[DS] / V[T]))
```

де:
* `I[0] = μ · C[ox] · (W / L) · (η - 1) · V[T]²` — технологічний масштабний коефіцієнт струму;
* `V[T] = (k · T) / q` — температурний потенціал (при `T = 300 K` величина `V[T] ≈ 25.86 мВ`, а при `T = 358 K` (+85 °C) зростає до `30.85 мВ`);
* `η` — коефіцієнт підпорогової неідеальності (зазвичай 1.2–1.5);
* `V[th]` — порогова напруга відкривання транзистора;
* `W` та `L` — ширина та довжина затвора.

При `V[GS] = 0` та робочій напрузі стоку `V[DS] >> V[T]` вираз статичного струму витоку затвора набуває вигляду:

```
I[leak,gate_off] = I[0] · exp(-V[th] / (η · V[T]))
```

Підпороговий розмах (англ. *subthreshold slope factor*) `S` визначає, скільки мілівольтів зміни `V[GS]` потрібно для зміни струму витоку на один порядок (в 10 разів):

```
S = ln(10) · η · V[T] ≈ 2.303 · 1.3 · 25.86 мВ ≈ 77.4 мВ/декаду
```

Це означає, що зниження порогової напруги `V[th]` на кожні 77 мВ заради підвищення швидкодії призводить до зростання статичного витоку в 10 разів.

Крім того, підпороговий струм експоненційно зростає з температурою кристала через залежність `V[T]` та теплову генерацію носіїв через заборонену зону кремнію `E[g] ≈ 1.12 еВ`:

```
I[sub](T) ∝ T² · exp(-E[g] / (2 · k · T))
```

При нагріванні мікроконтролера від кімнатної температури (+25 °C) до робочої промислової межі (+85 °C) струм статичного витоку ядра зростає у 10–25 разів. Якщо домен ядра не відключати силовим ключем, струм споживання в режимі очікування при підвищеній температурі може досягати десятків міліамперів.

## Струм квантовомеханічного тунелювання крізь діелектрик затвора

При товщині підзатворного оксиду діоксиду кремнію менше 2 нм (близько 5–7 атомних шарів `SiO[2]`) виникає пряме квантове тунелювання електронів крізь потенціальний бар'єр діелектрика (англ. *gate oxide tunneling*):

```
J[gate] = A · E[ox]² · exp(-B / E[ox])
```

де `E[ox] = V[DD] / t[ox]` — напруженість електричного поля в оксиді, а `A` і `B` — фізичні константи бар'єра Фаулера-Нордгейма. Оскільки напруженість поля прямо пропорційна напрузі `V[DD]`, зменшення напруги ядра з 3.3 В до 1.0 В знижує тунельний струм затворів на кілька порядків.

У сучасних технологічних процесах High-K Metal Gate (HKMG) замість чистого `SiO[2]` застосовують діоксид гафнію `HfO[2]` із високою діелектричною проникністю (`k ≈ 20–25` проти `3.9` у `SiO[2]`). Це дозволяє збільшити фізичну товщину підзатворного шару `t[phys]` при збереженні малої еквівалентної ємнісної товщини оксиду (EOT), знижуючи квантовий тунельний витік у сотні разів. Проте підпороговий витік каналу `I[sub]` залишається незмінним, вимагаючи обов'язкового апаратного відсікання живлення силовим ключем.

## Точка мінімального енергоспоживання (Minimum Energy Point — MEP)

Повна енергія `E[task]`, необхідна мікроконтролеру для виконання фіксованого обсягу обчислень із загальною кількістю тактів `N[cyc]`, складається з динамічної та інтегрованої статичної складових:

```
E[task] = E[dyn] + E[stat]
        = (N[cyc] · α · C[total] · V[DD]²) + (V[DD] · I[leak,total] · (N[cyc] / f))
```

де час виконання завдання `t[exec] = N[cyc] / f`.

Оскільки максимальна робоча частота транзисторів залежить від напруги за формулою Альфа-потужності Сакаї (Alpha-power law):

```
f[max](V[DD]) ∝ (V[DD] - V[th])^α_v / V[DD]     (де α_v ≈ 1.3 для субмікрона)
```

при глибокому зниженні напруги `V[DD]` частота `f` різко падає. Час виконання `t[exec]` зростає швидше, ніж зменшується напруга, через що інтегральний статичний витік `E[stat]` починає домінувати над динамічною енергією.

```
Енергетичний баланс MEP:
  Енергія
     ▲
     │ \                                / E[task] (сумарна)
     │  \     Точка MEP (мінімум)      /
     │   \          ▼                 /
     │    \      ╭─────╮             /   E[dyn] ∝ V[DD]²
     │     \____/       \___________/  (домінує при високій V)
     │      \                      /
     │       \                    /
     │        \                  /
     │   E[stat] ∝ V / f(V)     /
     │  (домінує при низькій V)/
     └──────────────────────────────────────► Напруга V[DD]
```

Оптимальна напруга живлення `V[MEP]` (зазвичай 0.5–0.7 В для сучасних CMOS-процесів) відповідає точці, де динамічна енергія та статична енергія за цикл зрівнюються:

```
E[dyn](V[MEP]) ≈ E[stat](V[MEP])
```

Це математично обґрунтовує концепцію динамічного масштабування напруги та частоти (DVFS): коли обчислень немає, напругу знижують або повністю знімають живлення; коли з'являється завдання — ядро переводять на номінальну напругу 1.0–1.2 В, виконують завдання на максимальній швидкодії та миттєво повертають блок у глибокий сон (стратегія *Race-to-Sleep*).

## Динаміка перехідного процесу при зміні напруги (DVFS Transition Energy)

При динамічній зміні напруги ядра між двома рівнями `V[1]` та `V[2]` (наприклад, перехід між економічним режимом 0.9 В на 48 МГц та продуктивним 1.2 В на 200 МГц) вбудований стабілізатор або Buck-перетворювач повинен перезарядити блокувальну ємність шини живлення ядра `C[decoupling]` (зазвичай 0.1–1.0 мкФ на кристалі та платі).

Енергія, яка витрачається на зміну потенціалу шини живлення:

```
ΔE[transition] = (1/2) · C[decoupling] · |V[2]² - V[1]²|
```

Для ємності `C[decoupling] = 470 нФ` перехід від 0.9 В до 1.2 В потребує енергії:

```
ΔE[transition] = 0.5 · (470 · 10⁻⁹ Ф) · |1.44 - 0.81| В²
               = 0.5 · (470 · 10⁻⁹) · 0.63
               = 148.05 нДж
```

Якщо перемикання виконується за час `t[trans] = 20 мкс`, додаткова середня потужність перехідного процесу становить `P[trans] = 148.05 нДж / 20 мкс = 7.4 мВт`. Цей розрахунок доводить, що занадто часті перемикання напруги живлення (понад 10–50 тисяч разів на секунду) можуть нівелювати виграш від енергозбереження. Тому інтервали адаптивного регулювання напруги в операційних системах реального часу завжди узгоджуються з енергетичною вартістю переходу.

## Кількісний розрахунок: монолітна шина 3.3 В проти розділених доменів

Порівняємо енергетичні показники 32-бітного мікроконтролера з тактовою частотою 200 МГц для двох архітектур живлення.

Вихідні параметри кристала:
* Еквівалентна кількість логічних вентилів ядра: `N[core] = 2 000 000` (2 млн вентилів).
* Сумарна ємність комутації ядра: `C[core] = 1.2 нФ` (`1.2 · 10⁻⁹ Ф`).
* Коефіцієнт перемикання логіки: `α = 0.15` (15% вентилів перемикаються щотакту).
* Тактова частота ядра: `f = 200 МГц` (`200 · 10⁶ Гц`).
* Периферія та зовнішні виводи: 32 активні лінії I/O, середня зовнішня ємність `C[pin] = 15 пФ`, середня частота комутації виводів `f[io] = 10 МГц`.
* Струм підпорогового витоку одного вентиля при 3.3 В (товстий оксид): `I[leak,3.3V] = 0.5 нА`.
* Струм підпорогового витоку одного вентиля ядра при 1.0 В (тонкий оксид): `I[leak,1.0V] = 2.0 нА`.

### Варіант 1: Монолітна шина живлення 3.3 В для всього чіпа

Усі цифрові, периферійні та інтерфейсні блоки живляться від єдиної зовнішньої лінії `V[DD] = 3.3 В`.

1. Динамічна потужність обчислювального ядра:

```
P[dyn,core] = α · C[core] · V[DD]² · f
            = 0.15 · (1.2 · 10⁻⁹ Ф) · (3.3 В)² · (200 · 10⁶ Гц)
            = 0.15 · 1.2 · 10.89 · 200 · 10⁻³ Вт
            = 392.04 мВт
```

2. Динамічна потужність вихідних каскадів виводів I/O:

```
P[dyn,io] = 32 · C[pin] · V[DD]² · f[io]
          = 32 · (15 · 10⁻¹² Ф) · (3.3 В)² · (10 · 10⁶ Гц)
          = 32 · 15 · 10.89 · 10 · 10⁻⁶ Вт
          = 52.27 мВт
```

3. Статична потужність витоку ядра в активному режимі:

```
P[stat,core] = N[core] · V[DD] · I[leak,3.3V]
             = (2 · 10⁶) · 3.3 В · (0.5 · 10⁻⁹ А)
             = 3.30 мВт
```

Повна активна потужність монолітної системи:

```
P[total,mono] = P[dyn,core] + P[dyn,io] + P[stat,core]
              = 392.04 + 52.27 + 3.30
              = 447.61 мВт
```

Струм, споживаний від джерела 3.3 В у робочому стані:

```
I[dd,mono] = 447.61 мВт / 3.3 В = 135.64 мА
```

У режимі очікування (тактування ядра зупинено, `f = 0`, живлення не вимкнено):

```
P[sleep,mono] = P[stat,core] = 3.30 мВт   (I[sleep] = 1000 мкА = 1.0 мА)
```

При температурі кристала +85 °C статичний струм очікування монолітного чіпа зростає в 12 разів:

```
I[sleep,mono,85C] = 1.0 мА · 12 = 12.0 мА
```

### Варіант 2: Розділені силові домени з вбудованим Buck-перетворювачем

Кристал розділено на три функціональні домени:
* **Домен ядра `V[CORE] = 1.0 В`:** живиться від внутрішнього понижувального Buck-стабілізатора з коефіцієнтом корисної дії `η[buck] = 90%` (`0.90`).
* **Домен периферії та виводів `V[DDIO] = 3.3 В`:** живиться безпосередньо від зовнішнього джерела 3.3 В.
* **Керування живленням у сні (Power Gating):** у режимі сну домен ядра повністю знеструмлюється силовими Header PMOS-ключами. Залишається заживленим лише блок збереження стану Retention SRAM на 4 КБ із сумарним струмом витоку `I[ret] = 80 нА`.

1. Динамічна потужність ядра при напрузі 1.0 В:

```
P[dyn,core,1.0V] = α · C[core] · V[CORE]² · f
                 = 0.15 · (1.2 · 10⁻⁹ Ф) · (1.0 В)² · (200 · 10⁶ Гц)
                 = 0.15 · 1.2 · 1.0 · 200 · 10⁻³ Вт
                 = 36.00 мВт
```

Виграш за динамічною потужністю обчислювальної логіки:

```
Ratio[dyn] = P[dyn,core,3.3V] / P[dyn,core,1.0V]
           = 392.04 мВт / 36.00 мВт
           = 10.89 рази                      [динамічні втрати впали майже в 11 разів]
```

2. Потужність, споживана від первинної шини 3.3 В на живлення ядра з урахуванням втрат у Buck-перетворювачі:

```
P[in,buck] = P[dyn,core,1.0V] / η[buck]
           = 36.00 мВт / 0.90
           = 40.00 мВт
```

3. Динамічна потужність виводів I/O (залишається на рівні 3.3 В для повної сумісності з лініями на платі):

```
P[dyn,io] = 52.27 мВт
```

4. Статична потужність ядра під час роботи з урахуванням ККД стабілізатора:

```
P[stat,core,1.0V] = N[core] · V[CORE] · I[leak,1.0V]
                  = (2 · 10⁶) · 1.0 В · (2.0 · 10⁻⁹ А)
                  = 4.00 мВт
P[in,buck,stat] = 4.00 мВт / 0.90 = 4.44 мВт
```

Повна активна потужність системи з розділеними доменами:

```
P[total,split] = P[in,buck] + P[in,buck,stat] + P[dyn,io]
               = 40.00 + 4.44 + 52.27
               = 96.71 мВт
```

Струм, споживаний від зовнішнього джерела 3.3 В в активному режимі:

```
I[dd,split] = 96.71 мВт / 3.3 В = 29.31 мА
```

Загальне активне енергоспоживання мікроконтролера впало з 447.61 мВт до 96.71 мВт — у 4.63 рази.

### Споживання в режимі глибокого сну (Deep Sleep)

При переході в стан сну силовий ключ повністю відсікає шину `V[CORE]`. Статичний витік активної логіки ядра обнуляється. Заживленим залишається лише модуль Retention SRAM і генератор годинника реального часу RTC:

```
P[sleep,split] = V[DD] · I[ret]
               = 3.3 В · (80 · 10⁻⁹ А)
               = 0.264 мкВт   (I[sleep] = 0.08 мкА = 80 нА)
```

Порівняння статичного струму в режимі сну між монолітною та розділеною архітектурами:

```
Ratio[sleep] = I[sleep,mono] / I[sleep,split]
             = 1000 мкА / 0.08 мкА
             = 12 500 разів
```

При температурі +85 °C струм витоку Retention-блоку зростає лише до 0.6–0.9 мкА, тоді як монолітний чіп споживає 12.0 мА — виграш становить понад 15 000 разів.

## Підсумковий висновок

Математичний аналіз переконливо доводить:
1. Зниження напруги ядра `V[CORE]` до 1.0 В усуває понад 90% динамічних теплових втрат процесора завдяки квадратичній залежності `P ∝ V²`.
2. Повне апаратне відсікання домену ядра за допомогою силових ключів ліквідує експоненційний підпороговий витік, знижуючи струм у режимі очікування на чотири порядки.
3. Збереження високовольтного домену `V[DDIO]` на рівні 3.3 В забезпечує необхідні запаси завадостійкості та навантажувальну здатність зовнішніх ліній зв'язку без шкоди для енергоефективності обчислювального вузла.
