# 🧮 Розрахунок потенціального поля напівсферичного заземлювача, крокової та дотикової напруг

Для точного математичного аналізу розподілу електричного потенціалу в ґрунті та обчислення небезпечних напруг скористаємося теорією електромагнітного поля у провідних суцільних середовищах. Розглянемо послідовно математичні моделі однорідного напівпростору, тривимірний розподіл потенціалів для різних геометрій електродів, метод дзеркальних відображень у двошарових ґрунтах та точний розв'язок крайової задачі для ступні людини.

---

### 1. Напівсферичний заземлювач у суцільному однорідному середовищі

Розглянемо заземлювальний електрод у формі напівсфери радіуса `r₀`, занурений у плоску поверхню землі. Ґрунт вважається ізотропним та однорідним середовищем із питомим електричним опором `ρ` (вимірюється в Ом·м). 

через заземлювач у землю стікає постійний або низькочастотний змінний струм короткого замикання `I` (в амперах). Завдяки сферичній симетрії середовища струм розтікається радіально в усі боки рівномірно через півсферичні поверхні.

#### Виведення густини струму, напруженості поля та потенціалу

Площа поверхні півсфери радіуса `r` (де `r ≥ r₀`) на поверхні або в глибині ґрунту становить:

```
S(r) = 2·π·r²
```

Звідси густина струму `j(r)` на відстані `r` від центра електрода виражається як:

```
j(r) = I / S(r)            [визначення густини струму як відношення струму до площі]
= I / (2·π·r²)             [підстановка площі півсфери S(r) = 2·π·r²]
```

За диференціальною формою закону Ома для ізотропного провідного середовища `j = σ·E = E / ρ`, напруженість електричного поля `E(r)` дорівнює:

```
E(r) = ρ·j(r)              [диференціальна форма закону Ома для провідного середовища]
= ρ·I / (2·π·r²)           [підстановка виразу густини струму j(r)]
```

Потенціал `V(r)` у довільній точці ґрунту визначається як робота з перенесення одиничного позитивного заряду з цієї точки в нескінченність, де потенціал землі прийнято за нуль (`V(∞) = 0`):

```
V(r) = ∫ [від r до ∞] E(r') dr'           [визначення потенціалу як інтеграла від напруженості]
= ∫ [від r до ∞] (ρ·I / (2·π·r'²)) dr'    [підстановка напруженості поля E(r')]
= (ρ·I / (2·π)) · [-1/r'] [від r до ∞]    [інтегрування степеневої функції 1/r'²]
= (ρ·I / (2·π)) · (0 - (-1/r))            [застосування граничних умов Ньютона-Лейбніца]
= ρ·I / (2·π·r)                           [підсумкове спрощення виразу]
```

Потенціал самого заземлювального електрода `V₀ = V(r₀)` становить:

```
V₀ = ρ·I / (2·π·r₀)
```

Отже, власний опір розтіканню напівсферичного заземлювача `R_g` визначається співвідношенням:

```
R_g = V₀ / I              [визначення опору заземлювача за законом Ома]
= ρ / (2·π·r₀)            [підстановка потенціалу напівсфери V₀]
```

### 2. Вертикальний стержневий заземлювач (Метод лінійного джерела)

На практиці напівсферичні заземлювачі використовуються рідко; найпоширенішим типом є вертикальний циліндричний стержень довжини `L` та радіуса `r₀` (при чому `L >> r₀`), занурений у ґрунт врівень із поверхнею.

Для обчислення потенціального поля такого електрода застосовують метод еквівалентного лінійного джерела струму. Припустимо, що струм `I` рівномірно витікає з лінійного відрізка довжиною `L` з лінійною густиною `λ = I / L`.

Потенціал точки на поверхні землі `V(r)` на радіальній відстані `r` від осі стержня обчислюється шляхом інтегрування внесків від усіх елементів довжини `dz'` стержня та його дзеркального відображення відносно поверхні землі:

```
V(r) = (ρ·I / (4·π·L)) · ∫ [від 0 до L] (2 / √(r² + z'²)) dz'   [інтеграл потенціалу від лінійного джерела]
= (ρ·I / (2·π·L)) · [ln(z' + √(r² + z'²))] [від 0 до L]        [первісна від 1/√(r²+z'²)]
= (ρ·I / (2·π·L)) · ln((L + √(r² + L²)) / r)                    [підстановка верхньої та нижньої меж]
```

При малих значеннях радіуса `r << L` опір розтіканню вертикального стержня `R_rod` наближено виражається класичною формулою Лорана-Дуйта:

```
R_rod = (ρ / (2·π·L)) · (ln(2·L / r₀) - 1)
```

### 3. Точний розрахунок крокової напруги та градієнтна апроксимація

Крокова напруга `V_step` виникає як різниця потенціалів між точками контакту ступень ніг `r₁` та `r₂ = r₁ + s` (де `s = 0.8` м — відстань кроку):

```
V_step(r) = V(r) - V(r + s)                                    [означення крокової напруги]
= (ρ·I / (2·π·r)) - (ρ·I / (2·π·(r + s)))                      [підстановка потенціалів V(r) та V(r+s)]
= (ρ·I / (2·π)) · (1/r - 1/(r + s))                            [винесення спільного множника]
= (ρ·I / (2·π)) · ((r + s - r) / (r·(r + s)))                  [зведення дробі до спільного знаменника]
= ρ·I·s / (2·π·r·(r + s))                                      [спрощення чисельника r + s - r = s]
```

#### Диференціальний аналіз та градієнтна апроксимація
Якщо відстань до джерела `r` значно перевищує довжину кроку (`r >> s`), приращення потенціалу можна розкласти в ряд Тейлора:

```
V(r + s) ≈ V(r) + (dV/dr)·s + (1/2)·(d²V/dr²)·s² + ...
```

Звідси в першому наближенні крокова напруга пропорційна напруженості електричного поля `E(r)`:

```
V_step(r) ≈ - (dV/dr) · s                                      [апроксимація першим членом ряду Тейлора]
= E(r) · s                                                     [зв'язок напруженості та градієнта E = -dV/dr]
= ρ·I·s / (2·π·r²)                                             [підстановка напруженості поля E(r)]
```

Порівняння точної формули та градієнтної апроксимації показує:
- На великих відстанях (`r = 10` м, `s = 0.8` м): точний вираз дає `1 / (10 · 10.8) = 1/108`, а градієнтний `1 / 100`. Похибка апроксимації становить лише 7.4%.
- На малих відстанях (`r = 1` м, `s = 0.8` м): точний вираз дає `1 / (1 · 1.8) = 1/1.8 ≈ 0.555`, а градієнтний `1 / 1 = 1.0`. Градієнтне наближення перебільшує напругу майже вдвічі. Тому при поблизькому розрахунку слід вживати виключно точні формули.

Максимальне значення крокової напруги спостерігається безпосередньо біля заземлювача при `r = r₀`:

```
V_step_max = ρ·I·s / (2·π·r₀·(r₀ + s))
```

### 4. Точний розрахунок дотикової напруги

Дотикова напруга `V_touch(r)` вимірюється між потенціалом корпуса обладнання `V₀` та потенціалом поверхні землі `V(r)` у точці, де стоїть людина:

```
V_touch(r) = V₀ - V(r)                                         [означення дотикової напруги]
= (ρ·I / (2·π·r₀)) - (ρ·I / (2·π·r))                           [підстановка потенціалів V₀ та V(r)]
= (ρ·I / (2·π)) · (1/r₀ - 1/r)                                 [винесення спільного множника]
= ρ·I·(r - r₀) / (2·π·r₀·r)                                    [зведення дробі до спільного знаменника]
```

Аналітичні властивості дотикової напруги:
1. Біля самого електрода (`r → r₀`): `V_touch → 0`. Людина, яка стоїть безпосередньо на заземлювачі і торкається його, перебуває під нульовою різницею потенціалів.
2. На великому віддаленні (`r >> r₀`): `V_touch → V₀`. На відстані понад 8–10 метрів потенціал землі спадає до нуля, і дотикова напруга дорівнює повному потенціалу заземлювача.

### 5. Теоретичний розв'язок крайової задачі для ступні людини (Диск Блека)

Для обчислення реального струму крізь тіло необхідно визначити опір розтіканню ступні `R_f`. Ступня моделюється як плоский круглий диск радіуса `a ≈ 0.08` м, що лежить на поверхні провідного напівпростору `z ≥ 0` з опором `ρ`.

Крайова задача для потенціалу `V(r, z)` описується рівнянням Лапласа:

```
∇²V = (1/r)·(∂/∂r)(r · ∂V/∂r) + ∂²V/∂z² = 0
```

з граничними умовами:
1. `V(r, 0) = V_disk = const` при `0 ≤ r ≤ a` (поверхня диска еквіпотенціальна).
2. `∂V/∂z |_(z=0) = 0` при `r > a` (струм не витікає через суху поверхню землі поза диском).
3. `V → 0` при `√(r² + z²) → ∞`.

Розв'язок цієї задачі в парних парціальних інтегралах Бесселя дає такий розподіл густини струму під диском ступні:

```
j(r) = I / (2·π·a · √(a² - r²))
```

Зверніть увагу: густина струму прямує до безкінечності на гострому краю диска (`r → a`) — це так званий ефект крайової сінгулярності.

Інтегруванням потенціалу по поверхні диска отримуємо точну формулу опору розтіканню ступні:

```
R_f = ρ / (4·a)
```

При `a = 0.08` м:

```
R_f = ρ / (4 · 0.08)                                           [підстановка еквівалентного радіуса ступні a = 0.08 м]
= ρ / 0.32                                                     [перемноження у знаменнику 4 · 0.08 = 0.32]
≈ 3.125 · ρ                                                    [обчислення коефіцієнта 1 / 0.32 = 3.125]
```

### 6. Двошарова модель ґрунту та метод дзеркальних відображень

У реальних умовах ґрунт рідко є однорідним. Поширеною є двошарова структура: верхній шар завтовшки `h` з питомим опором `ρ₁` та нижній шар із опором `ρ₂`.

Для обчислення потенціалу `V(r)` на поверхні верхнього шару застосовують метод дзеркальних відображень. Коефіцієнт відображення електричного поля `K` на межі двох шарів дорівнює:

```
K = (ρ₂ - ρ₁) / (ρ₂ + ρ₁)
```

Потенціал на поверхні землі від точкового джерела струму `I` у двошаровому середовищі виражається безкінечним рядом відображень:

```
V(r) = (ρ₁·I / (2·π)) · (1/r + 2 · ∑ [n=1..∞] (Kⁿ / √(r² + (2·n·h)²)))
```

#### Вплив параметрів шарів на безпеку:
1. **Високоомний верхній шар (`ρ₁ >> ρ₂`, `K → -1`)**: Наприклад, шар гравію `ρ₁ = 3000` Ом·м над глиною `ρ₂ = 100` Ом·м. Ряд відображень є знаконоперемінним і зменшує загальний опір заземлювача, але **значно підвищує опір ступні `R_f`**, що зменшує струм крізь тіло людини.
2. **Низькоомний верхній шар (`ρ₁ << ρ₂`, `K → +1`)**: Наприклад, вологий чорнозем над гранітною скалою. Ряд є додатним і сумується, що призводить до різкого зростання градієнтів потенціалу на поверхні та підвищення крокової напруги.

### 7. Комплексний розрахунок струмів та аналіз безпеки

Обчислимо струм крізь тіло людини для кіл крокової та дотикової напруг.

#### Схема заміщення крокового кола:
Ступні ввімкнені **послідовно**:

```
R_total_step = R_b + 2·R_f                                     [опір кола при послідовному ввімкненні ступень]
= R_b + 2 · (3.125 · C_s · ρ₁)                                 [підстановка формули опору ступні R_f]

I_body_step = V_step / (R_b + 6.25 · C_s · ρ₁)                 [закон Ома для кола крокової напруги]
```

#### Схема заміщення дотикового кола:
Ступні ввімкнені **паралельно**:

```
R_total_touch = R_b + (R_f / 2)                                [опір кола при паралельному ввімкненні ступень]
= R_b + (3.125 · C_s · ρ₁) / 2                                 [підстановка формули опору ступні R_f]

I_body_touch = V_touch / (R_b + 1.5625 · C_s · ρ₁)             [закон Ома для кола дотикової напруги]
```

#### Числовий деталізований приклад розрахунку
**Вихідні дані**:
- Струм замикання на землю: `I = 800` А.
- Радіус заземлювальної напівсфери: `r₀ = 0.3` м.
- Верхній шар ґрунту: чорнозем завтовшки `h = 1.0` м з опором `ρ₁ = 100` Ом·м.
- Покриття гравієм відсутнє (`C_s = 1.0`).
- Опір тіла людини: `R_b = 1000` Ом.
- Людина стоїть на відстані `r = 1.5` м від заземлювача, крок `s = 0.8` м.

**Покрокове обчислення**:

1. Опір заземлювача:
```
R_g = 100 / (2 · 3.14159 · 0.3)
≈ 53.05 Ом
```

2. Повний потенціал заземлювача:
```
V₀ = I · R_g = 800 · 53.05
= 42440 В
```

3. Потенціали в точках розташування ніг:
```
V(1.5) = 100 · 800 / (2 · 3.14159 · 1.5)
≈ 8488 В

V(2.3) = 100 · 800 / (2 · 3.14159 · 2.3)
≈ 5536 В
```

4. Величина крокової та дотикової напруг:
```
V_step = V(1.5) - V(2.3)                                       [різниця потенціалів між точками r=1.5м та r=2.3м]
= 8488 - 5536                                                  [підстановка обчислених потенціалів V(1.5) та V(2.3)]
= 2952 В                                                       [арифметичне віднімання]

V_touch = V₀ - V(1.5)                                          [різниця потенціалів між корпусом V₀ та ґрунтом]
= 42440 - 8488                                                 [підстановка потенціалу заземлювача та точки r=1.5м]
= 33952 В                                                      [арифметичне віднімання]
```

5. Опір ступні та еквівалентні опори кіл:
```
R_f = 3.125 · 100 = 312.5 Ом

R_total_step = 1000 + 2 · 312.5 = 1625 Ом
R_total_touch = 1000 + (312.5 / 2) = 1156.25 Ом
```

6. Розрахунок струмів крізь тіло людини:
```
I_body_step = 2952 / 1625                                      [закон Ома: напруга кроку розділена на опір кола]
= 1.816 А  (1816 мА)                                           [обчислення струму крізь тіло при кроці]

I_body_touch = 33952 / 1156.25                                 [закон Ома: напруга дотику розділена на опір кола]
= 29.364 А  (29364 мА)                                         [обчислення струму крізь тіло при дотику]
```

**Висновки з розрахунку**:
За відсутності сітки вирівнювання потенціалів та гравійного покриття обидва струми у тисячі разів перевищують смертельний поріг фібриляції серця (100 мА). Це математично підтверджує недопустимість експлуатації високовольтних об'єктів без професійно розрахованих систем вирівнювання потенціалів.
