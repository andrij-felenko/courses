# 🧮 Розрахунок температурної компенсації та енергетичного балансу свинцю

Розрахунок температурної компенсації напруги заряду свинцево-кислотного акумулятора необхідний для запобігання двом протилежним руйнівним процесам: тепловому розгону за високих температур та глибокому недозаряду із замерзанням кислоти на морозі. Без точного термодинамічного коригування зарядної напруги на кожний градус відхилення від еталонних 25 °C термін служби батареї скорочується в три-чотири рази.

### Термодинамічна основа температурного коефіцієнта (рівняння Нернста)

Рівноважна електрорушійна сила (ЕРС) свинцевої комірки описується рівнянням Нернста для загальної подвійної сульфатної реакції `PbO2 + Pb + 2H2SO4 <=> 2PbSO4 + 2H2O`:

```
E_eq = E_0 + (R·T / (z·F)) · ln((a_H+)^2 · (a_HSO4-)^2 / (a_H2O)^2)
```

де:
- `E_0 = 2.048 В` — стандартний потенціал реакції за 25 °C (298.15 K);
- `R = 8.314 Дж/(моль·К)` — універсальна газова стала;
- `F = 96485 Кл/моль` — стала Фарадея;
- `z = 2` — число електронів, перенесених в одному елементарному акті реакції;
- `a` — термодинамічні активності іонів у водному розчині сірчаної кислоти.

Зміна термодинамічної ЕРС із температурою визначається ентропією хімічної реакції `ΔS`:

```
dE_eq / dT
= ΔS / (z·F)                     [зв'язок зміни вільної енергії Гіббса з ЕРС]
= −0.00022 В/°C                  [чисельний розрахунок для H2SO4 густиною 1.28 г/см³]
= −0.22 мВ/°C                    [термодинамічний зсув рівноважної ЕРС на одну комірку]
```

Проте в процесі заряду напруга на клемах визначається не лише рівноважною ЕРС `E_eq`, а й перенапругою виділення газів (кисню на позитивній пластині та водню на негативній) `η(T)`, а також внутрішнім омічним опором електроліту `R_int(T)`:

```
V_charge(T) = E_eq(T) + η_anode(T) + η_cathode(T) + I·R_int(T)
```

Перенапруга виділення кисню й водню стрімко падає зі зростанням температури за рівнянням Тафеля, оскільки активаційний бар'єр електрохімічних реакцій знижується, а кінетика масоперенесення іонів у рідині прискорюється. Емпіричний температурний коефіцієнт сумарної перенапруги становить близько `−3.78 мВ/°C`.

Сума термодинамічного зсуву ЕРС та кінетичного зсуву перенапруг дає сумарний практичний температурний коефіцієнт заряду свинцевої комірки:

```
k_cell
= (dE_eq / dT) + (dη / dT)       [сума термодинамічної та кінетичної складових]
= −0.22 мВ/°C − 3.78 мВ/°C       [підстановка експериментальних коефіцієнтів]
= −4.0 мВ/°C                     [температурний градієнт однієї комірки]
```

Для стандартного 12-вольтового акумуляторного моноблока, що містить `N = 6` послідовно з'єднаних комірок, загальний температурний коефіцієнт компенсації напруги становить:

```
k_12V
= N · k_cell                     [множення на кількість послідовних комірок]
= 6 · (−4.0 мВ/°C)               [підстановка N = 6]
= −24.0 мВ/°C                    [−0.024 В на кожен градус Цельсія відхилення]
```

Виробники стаціонарних та тягових батарей залежно від легування свинцевих ґраток кальцієм чи сурмою зазначають градієнт у межах від `−18 мВ/°C` (−3 мВ/°C на комірку) до `−30 мВ/°C` (−5 мВ/°C на комірку). Значення `−24 мВ/°C` є загальноприйнятим стандартом для більшості герметизованих свинцевих батарей VRLA (AGM та GEL).

### Зв'язок стану заряду, густини електроліту та температури замерзання

Під час розряду сірчана кислота витрачається на утворення сульфату свинцю, а в розчин виділяється вода. Густина електроліту падає прямо пропорційно відданій ємності. Зниження концентрації кислоти призводить до різкого підвищення температури кристалізації водного розчину:

```
Густина електроліту та температура замерзання за станом заряду (SoC):
100% SoC : густина 1.28 г/см³ (37% H2SO4)  → замерзання при −68 °C (безпечно)
 75% SoC : густина 1.24 г/см³ (32% H2SO4)  → замерзання при −40 °C (безпечно)
 50% SoC : густина 1.18 г/см³ (25% H2SO4)  → замерзання при −20 °C (небезпечна межа)
 25% SoC : густина 1.12 г/см³ (17% H2SO4)  → замерзання при −10 °C (критично)
  0% SoC : густина 1.06 г/см³ (9% H2SO4)   → замерзання при −4 °C (розрив корпусу льодом)
```

Якщо взимку за температури −20 °C зарядний пристрій не збільшує напругу до розрахункових 15.48 В, струм заряду падає майже до нуля через високий внутрішній опір і низьку кінетику. Батарея залишається на рівні 30–40% заряду з низькою густиною електроліту (близько 1.15 г/см³). Під час наступного нічного похолодання до −15 °C вода в порах активної маси кристалізується в лід, розпирає та руйнує свинцеві ґратки, викришуючи оксид свинцю на дно моноблока.

### Покроковий розрахунок цільової напруги на температурних екстремумах

Формула коригування напруги для будь-якої стадії заряду (Bulk, Absorption, Float) відносно базової температури `T_ref = 25 °C`:

```
V_target(T) = V_ref + k_12V · (T − 25 °C)
```

де:
- `V_ref` — номінальна напруга стадії за 25 °C (для стадії Absorption `V_ref = 14.40 В`, для Float `V_ref = 13.60 В`);
- `T` — поточна температура електроліту в градусах Цельсія.

#### Приклад 1. Заряд у зимових умовах при −20 °C

Обчислюємо температурну різницю та напругу насичення (Absorption):

```
ΔT
= T − T_ref                      [визначення температурного зсуву]
= −20 °C − 25 °C                 [підстановка значень]
= −45 °C                         [охолодження відносно нормальних умов]

V_abs(−20 °C)
= 14.40 В + (−0.024 В/°C) · (−45 °C)  [підстановка у формулу компенсації]
= 14.40 В + 1.08 В               [обчислення поправки: від'ємне на від'ємне дає плюс]
= 15.48 В                        [необхідна напруга стадії Absorption]

V_float(−20 °C)
= 13.60 В + (−0.024 В/°C) · (−45 °C)  [підстановка базової напруги Float]
= 13.60 В + 1.08 В               [додавання поправки]
= 14.68 В                        [необхідна напруга стадії Float]
```

Якщо при −20 °C залишити зарядник із фіксованою напругою 14.40 В, батарея отримає еквівалент лише `14.40 − 1.08 = 13.32 В` кімнатного потенціалу. Вона ніколи не досягне стану повного розчинення сульфатів, густина електроліту залишиться на рівні 1.15 г/см³ замість 1.28 г/см³, що призведе до сульфатації пластин і незворотної втрати ємності.

#### Приклад 2. Буферний режим у спекотній шафі при +45 °C

Обчислюємо цільову напругу буферного режиму (Float) для запобігання википанню герметизованої AGM/GEL батареї:

```
ΔT
= +45 °C − 25 °C                 [температурне перевищення]
= +20 °C                         [нагрів понад норму]

V_float(+45 °C)
= 13.60 В + (−0.024 В/°C) · (+20 °C)  [підстановка у формулу]
= 13.60 В − 0.48 В               [віднімання поправки через зростання температури]
= 13.12 В                        [безпечна напруга утримання в буфері]
```

### Енергетичний баланс та умова теплового розгону (Thermal Runaway)

У буферному режимі (Float) струм витоку `I_float` визначається кінетикою кисневого циклу рекомбінації та електрохімічної корозії ґраток. Залежність струму саморозряду та витоку від температури підпорядковується закону Арреніуса:

```
I_float(T) = I_0 · exp((E_act / R) · (1/T_ref − 1/T))
```

Енергія активації реакцій корозії та рекомбінації у свинцевому акумуляторі становить `E_act ≈ 65 кДж/моль`. Це означає, що струм витоку приблизно **подвоюється на кожні 10 °C підвищення температури**:

```
I_float(T) ≈ I_float(25 °C) · 2^((T − 25) / 10)
```

Потужність тепловиділення всередині герметичного блоку при заряді напругою `V`:

```
P_gen = V_float · I_float(T)
```

Потужність природного тепловідведення в навколишнє середовище за конвекцією й випромінюванням:

```
P_diss = h_c · A · (T_battery − T_ambient)
```

де:
- `h_c ≈ 10...15 Вт/(м²·К)` — коефіцієнт теплопередачі поверхні пластикового корпусу;
- `A` — площа поверхні корпусу акумулятора (для типового блоку 100 А·год `A ≈ 0.25 м²`).

Умова теплової стабільності вимагає, щоб швидкість зростання тепловідведення з температурою перевищувала швидкість зростання тепловиділення:

```
dP_diss / dT > dP_gen / dT
```

Якщо напруга `V_float` не знижується при зростанні `T` (залишається на рівні 13.60 В при 45 °C замість 13.12 В), струм `I_float` зростає в 4 рази (від 50 мА до 200 мА для батареї 100 А·год). Тепловиділення досягає `13.6 В · 0.2 А = 2.72 Вт`. У закритому батарейному відсіку зі слабкою вентиляцією температура корпусу піднімається до 55–60 °C, що спричиняє подальше лавиноподібне зростання струму до 1–2 А (тепловиділення 15–25 Вт). Виникає тепловий розгін: тиск газів вибиває запобіжні клапани, гель або скломати втрачають вологу, корпус роздувається і сплавляється в суцільний моноліт.
