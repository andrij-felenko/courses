# 🧮 Математична модель дисбалансу комірок: струмовий перекіс, втрата ємності та тепловий розгін

Коли окремі літій-іонні комірки об'єднують у паралельні та послідовні збірки, відхилення їхніх базових фізичних параметрів — внутрішнього опору `R_i`, дійсної ємності `Q_i` та напруги відкритого кола `OCV` — призводить до нелінійного перерозподілу навантаження. Макроефекти не усереднюються, а навпаки, концентрують струмове та теплове навантаження на крайніх елементах.

Нижче наведено строге математичне виведення законів розподілу струмів, динамічного перехідного процесу в часовій області, виділення джоулевого тепла, електротеплової нестійкості та статистичної втрати корисної ємності батарейного пакета за наявності виробничого розкиду.

---

### 1. Статичний розподіл струмів у паралельній групі комірок

Розглянемо паралельне з'єднання `P` комірок, підключених до спільних струмопровідних шин. Загальний струм навантаження, що протікає крізь паралель, дорівнює `I_tot`.

Оскільки всі комірки з'єднані паралельно, спад напруги `ΔV` на кожній гілці є однаковим:

```
ΔV = I_1 · R_1 = I_2 · R_2 = ... = I_P · R_P     [закон Ома для паралельних віток]
```

Виразимо струм `k`-ї комірки через спад напруги та її провідність `G_k = 1 / R_k`:

```
I_k = ΔV / R_k = ΔV · G_k                        [означення провідності G = 1 / R]
```

За першим законом Кірхгофа сума струмів усіх віток дорівнює повному струму:

```
I_tot = ∑ I_j                                    [перший закон Кірхгофа]
= ∑ (ΔV · G_j)                                   [підстановка I_j = ΔV · G_j]
= ΔV · ∑ G_j                                     [винесення спільного множника ΔV]
```

Звідси виражаємо спільний спад напруги на паралельній ланці:

```
ΔV = I_tot / (∑ G_j)                             [ділення обох частин на еквівалентну провідність]
```

Підставляючи вираз для `ΔV` у формулу струму `k`-ї комірки, отримуємо точний закон розподілу струму:

```
I_k = I_tot · (G_k / ∑ G_j)                      [підстановка ΔV у вираз для I_k]
= I_tot · ((1 / R_k) / ∑ (1 / R_j))              [заміна провідностей на опори]
```

#### Приклад для двох паралельних комірок (P = 2)
Нехай паралель живить навантаження струмом `I_tot = 30 А`. Опір першої комірки `R_1 = 15 мОм`, опір другої `R_2 = 30 мОм` (двократна різниця).

```
G_1 = 1 / 15 ≈ 0.0667 См                         [провідність першої комірки]
G_2 = 1 / 30 ≈ 0.0333 См                         [провідність другої комірки]
G_sum = G_1 + G_2 = 0.1000 См                    [сумарна провідність]
I_1 = 30 · (0.0667 / 0.1000) = 20.0 А            [струм низькоомної комірки]
I_2 = 30 · (0.0333 / 0.1000) = 10.0 А            [струм високоомної комірки]
```

Комірка з удвічі меншим внутрішнім опором бере на себе `2/3` повного струму (`20 А` замість номінальних `15 А`).

### 2. Динамічний перехідний процес під час імпульсного навантаження

У реальних умовах внутрішній опір комірки описується еквівалентною схемою Рендлса першого порядку: послідовно з'єднаний омічний опір `R_0` та паралельна ланка поляризації `R_ct || C_dl`, де `R_ct` — опір переносу заряду, а `C_dl` — ємність подвійного електричного шару (зазвичай сотні або тисячі фарад на комірку).

Спад напруги на `k`-й комірці в часовій області описується інтегро-диференціальним рівнянням:

```
V_k(t) = OCV_k - I_k(t) · R_0k - V_ct,k(t)
```

де напруга на ємності подвійного шару задовольняє рівняння:

```
d V_ct,k / dt = (I_k(t) - V_ct,k(t) / R_ct,k) / C_dl,k
```

Розглянемо дві паралельні комірки з однаковою напругою спокою `OCV_1 = OCV_2`, але різними параметрами `(R_01, R_ct1, C_dl1)` та `(R_02, R_ct2, C_dl2)`.

У момент стрибка струму `t = 0+` напруга на конденсаторах подвійного шару не може змінитися миттєво (`V_ct1(0+) = V_ct2(0+) = 0`). Тому розподіл струмів у перші мікросекунди визначається виключно **високочастотним омічним опором `R_0`** (тим самим, що вимірюється на частоті 1 кГц):

```
I_1(0+) / I_2(0+) = R_02 / R_01                  [початковий розподіл струмів за омічним опором]
```

У міру протікання струму конденсатори заряджаються з часовими константами `τ_1 = R_ct1 · C_dl1` та `τ_2 = R_ct2 · C_dl2`. У квазістаціонарному стані (`t ≫ τ`) струми переходять до розподілу за **повним постійнострумовим опором DC IR**:

```
I_1(∞) / I_2(∞) = (R_02 + R_ct2) / (R_01 + R_ct1) [усталений розподіл за повним DC-опором]
```

Якщо одна комірка має малий `R_0`, але великий `R_ct` (наприклад, деградація активної поверхні електрода), струм під час коротких імпульсів різко перекошується в її бік, перевантажуючи струмовідводи, після чого повільно перетікає у сусідку.

#### Вирівнювальні перетікання струму після вимкнення навантаження
Коли зовнішній струм зникає (`I_tot = 0`), комірки, які розрядилися на різну глибину через струмовий перекіс, мають різний рівень залишкового заряду `SoC_1 < SoC_2` і, відповідно, різну напругу спокою `OCV_1 < OCV_2`.

Між паралельними комірками виникає внутрішній вирівнювальний контурний струм:

```
I_circ(t) = (OCV_2(t) - OCV_1(t)) / (R_1 + R_2)
```

Сумарний заряд, який безкорисно перетікає між комірками у стані спокою:

```
Q_circ = ∫ I_circ(t) dt                          [втрачений на внутрішнє циркулювання заряд]
```

Цей струм викликає додатковий нецільовий нагрів комірок уже після вимкнення споживача.

### 3. Джоулеве тепловиділення та електротеплова нестійкість

Потужність тепла, що виділяється всередині `k`-ї комірки, описується законом Джоуля — Ленца:

```
P_k = I_k² · R_k                                 [закон Джоуля — Ленца]
```

Підставимо отриманий вираз для статичного струму `I_k`:

```
P_k = (I_tot · (G_k / ∑ G_j))² · R_k             [підстановка виведеного струму I_k]
= I_tot² · (G_k² / (∑ G_j)²) · (1 / G_k)         [використання R_k = 1 / G_k]
= I_tot² · G_k / (∑ G_j)²                        [скорочення на G_k]
= (I_tot² / (∑ G_j)²) · (1 / R_k)                [заміна G_k на 1 / R_k]
```

Оскільки множник `I_tot² / (∑ G_j)²` є спільним для всіх комірок паралельної ланки, потужність тепловиділення **обернено пропорційна внутрішньому опору**:

```
P_k ∝ 1 / R_k                                    [тепловиділення обернено пропорційне опору]
```

#### Розрахунок теплового перекосу для двох комірок:
Обчислимо теплову потужність для прикладу (`R_1 = 15 мОм`, `R_2 = 30 мОм`, `I_tot = 30 А`):

```
P_1 = (20.0 А)² · 0.015 Ом = 400 · 0.015 = 6.00 Вт   [теплова потужність низькоомної комірки]
P_2 = (10.0 А)² · 0.030 Ом = 100 · 0.030 = 3.00 Вт   [теплова потужність високоомної комірки]
P_ratio = P_1 / P_2 = 6.00 / 3.00 = 2.00              [співвідношення тепловиділення]
```

#### Електротепловий позитивний зворотний зв'язок (Thermal Runaway precursor)
Електропровідність рідкого органічного електроліту має активаційний арреніусівський характер: зі зростанням температури `T` в'язкість розчинника падає, а коефіцієнт дифузії іонів зростає, тому внутрішній опір комірки зменшується з від'ємним температурним коефіцієнтом:

```
R(T) = R_ref · exp((E_a / R_gas) · (1 / T - 1 / T_ref))
```

де `E_a` — енергія активації провідності електроліту (~15–25 кДж/моль), `R_gas` — універсальна газова стала.

Це створює небезпечну ланцюгову реакцію в паралельній збірці:
1. Низькоомна комірка бере більший струм `I_1 > I_2`.
2. Вона виділяє більше тепла `P_1 > P_2` і нагрівається сильніше: `T_1 > T_2`.
3. Зростання температури `T_1` призводить до додаткового зниження її внутрішнього опору `R_1(T_1) ↓`.
4. Зниження опору змушує її брати ще більшу частку загального струму `I_1 ↑`.

Якщо тепловідвід від акумуляторного блоку обмежений, цей позитивний зворотний зв'язок призводить до локального перегріву окремих циліндрів аж до температур початку розкладання сепаратора (> 130°C).

### 4. Статистична модель втрати корисної ємності в довгих послідовних збірках (S-strings)

У послідовному рядку з `S` ланок однаковий струм навантаження `I(t)` протікає крізь кожну ланку. Сумарна ємність кожної ланки `Q_s` є випадковою величиною.

Нехай ємності ланок розподілені за нормальним законом `N(μ_Q, σ_Q²)`.
Корисна ємність усього послідовного пакета визначається мінімальним значенням серед усіх `S` ланок:

```
Q_pack = min (Q_1, Q_2, ..., Q_S)
```

Згідно з теорією екстремальних значень (розподіл Гумбеля / Вейбулла), математичне сподівання мінімуму вибірки обсягу `S` з нормального розподілу асимптотично описується виразом:

```
E[Q_pack] ≈ μ_Q - σ_Q · √(2 · ln S) + (σ_Q · (ln(ln S) + ln(4π))) / (2 · √(2 · ln S))
```

Для першого наближення використовують оцінку:

```
E[Q_pack] ≈ μ_Q - σ_Q · √(2 · ln S)               [асимптотична оцінка мінімальної ланки]
```

Ця формула показує ключову закономірність: **чим довший послідовний ланцюг `S`, тим далі найслабша ланка відхиляється вниз від середнього значення партії `μ_Q`**.

#### Числове порівняння для батарей різної напруги:
Нехай партія комірок має середню ємність `μ_Q = 3000 мА·год` зі стандартним відхиленням `σ_Q = 60 мА·год` (розкид ±2%):

1. Для короткої збірки 4S (14.8 В, дрон або шурупокрут, `S = 4`):
```
√(2 · ln 4) = √(2 · 1.386) = √2.773 ≈ 1.665
E[Q_pack] ≈ 3000 - 60 · 1.665 = 3000 - 100 = 2900 мА·год   [втрата 3.3% ємності]
```

2. Для довгої тягової збірки 96S (355 В, електромобіль, `S = 96`):
```
√(2 · ln 96) = √(2 · 4.564) = √9.129 ≈ 3.021
E[Q_pack] ≈ 3000 - 60 · 3.021 = 3000 - 181 = 2819 мА·год   [втрата 6.0% ємності]
```

Без попереднього добору в довгій збірці ймовірність натрапити на глибокий статистичний «хвіст» розподілу зростає пропорційно `√(ln S)`, що призводить до втрати сотень ват-годин корисної енергії ще до початку експлуатації.

### 5. Підсумкова формула балансу енергії та висновок

Сумарна корисна енергія батарейного пакета з урахуванням втрат на внутрішніх опорах та обмеження найслабшою ланкою виражається інтегралом:

```
E_usable = ∫ [ (∑ OCV_s(SoC_s(t))) - I(t) · (∑ R_eq_s) ] · I(t) dt
```

де інтегрування ведеться від моменту старту `t = 0` до моменту `t_cutoff`, коли напруга будь-якої з ланок досягає критичного порогу:

```
min_s ( OCV_s(t_cutoff) - I(t_cutoff) · R_eq_s ) = V_UVLO
```

З формули безпосередньо випливають три обов'язкові інженерні вимоги добору комірок:
1. **Мінімізація дисперсії ємності `Var(Q_s) → 0`:** запобігає передчасному досягненню `V_UVLO` окремою ланкою за хімічним зарядом.
2. **Мінімізація дисперсії опору `Var(R_eq_s) → 0`:** усуває динамічний перекіс напруги `I · R_eq_s` під час пікових навантажень.
3. **Вирівнювання опорів всередині кожної паралелі `R_{s,1} ≈ R_{s,2} ≈ ... ≈ R_{s,P}`:** ліквідує локальні струмові та теплові концентрації, запобігаючи деградації та тепловому розгону окремих циліндрів.
