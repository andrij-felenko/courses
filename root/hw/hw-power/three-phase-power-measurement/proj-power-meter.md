# ⚙️ Практична реалізація трифазного аналізатора потужності на мікроконтролері

Проєктування цифрового аналізатора трифазної потужності є класичною фундаментальною задачею вимірювальної та силової мікропроцесорної техніки. Такий прилад має в реальному часі безперервно зчитувати аналогові сигнали трьох фазних напруг та трьох фазних струмів, виконувати їхнє цифрове фільтрування, обчислювати діючі значення (True RMS), миттєву та середню активну, реактивну й повну потужності, коефіцієнт потужності `cos(φ)`, а також визначати струм у нейтральному провіднику й спектральний склад гармонік.

У цьому практичному проєкті розбито повний цикл побудови приладу: від аналогового тракту узгодження сигналів до дискретних алгоритмів цифрової обробки сигналів (DSP) та робочої програмної реалізації мовами C та C++ з використанням ідіоматичних підходів обох мов.

### Апаратна архітектура вимірювального тракту та вибір датчиків

Типова схема підключення аналогового тракту трифазного аналізатора містить два триканальні вимірювальні порти: порт напруги (канали `VA, VB, VC`) та порт струму (канали `IA, IB, IC`).

#### 1. Канали вимірювання напруги

Для зниження високої мережевої напруги (230 В фазної або 400 В лінійної) до безпечного робочого діапазону аналогово-цифрового перетворювача (наприклад, `0...3.3 В` або `±1.2 В`) застосовують один із двох основних схемотехнічних підходів:

- **Прецизійні резистивні дільники напруги:** складаються з послідовності високостабільних SMD-резисторів (із допуском `0.1%` та низьким температурним коефіцієнтом опору ТКО `25 ppm/°C`). Для забезпечення вимог з безпеки електричної ізоляції (категорія `CAT III 600V` або `CAT IV 300V`) загальний опір верхнього плеча вибирають у межах `1...2 МОм`, розбиваючи його на 4-6 послідовно включених резисторів типрозміру 1206 для запобігання дуговому пробою поверхні плати. Сигнал із нижнього плеча надходить на операційний підсилювач у режимі повторювача напруги із додаванням постійного зміщення `Vref / 2 = 1.65 В`.
- **Вимірювальні трансформатори напруги (TV):** забезпечують повну гальванічну розв'язку вимірювальної схеми від силової мережі. Трансформатори мають коефіцієнт трансформації `230В / 2В` та низьку кутову похибку. Вони є більш громіздкими, проте гарантують максимальну безпеку приладу та стійкість до імпульсних перенапруг.

#### 2. Канали вимірювання струму

Для знімання сигналів струму застосовують три альтернативні технології:

- **Трансформатори струму (ТС / CT):** класичні пермаллоєві або феритові тороїдальні трансформатори з коефіцієнтом трансформації `1000:1` або `2000:1`. Вони вимагають підключення нагрузочного резистора (шунта `Rburden`) до вторинної обмотки. Трансформатори струму забезпечують високу точність у широкому діапазоні, проте піддаються магнітному насиченню при наявності постійної складової у струмі навантаження.
- **Котушки Роговського (Rogowski Coils):** гнучкі або жорсткі повітряні соленоїди без феромагнітного осердя. Вихідна напруга котушки Роговського є пропорційною похідній струму за часом: `v_rog(t) = M · (di/dt)`. Вони не насичуються навіть при струмах у десятки кілоампер, але вимагають застосування аналогового або цифрового інтегратора для відновлення форми струму `i(t)`.
- **Низькоомні струмові шунти:** застосовуються в прямому включенні у дводротових та трифазних лічильниках малого габариту. Вимагають застосування ізольованих сигма-дельта дельта-модуляторів (наприклад, `AMC1304` або `ADuM7701`) для кожного каналу струму через відсутність гальванічної розв'язки.

#### 3. Вимоги до аналогово-цифрового перетворювача (АЦП)

Основною вимогою до АЦП трифазного аналізатора є **строго синхронна вибірка сигналів** по всіх 6 каналах одночасно. Якщо застосувати класичний АЦП послідовного наближення (SAR) з єдиним аналоговим мультиплексором, між вибіркою напруги `VA` та вибіркою струму `IA` виникне міжканальна часова затримка `Δt`. На частоті 50 Гц затримка всього у `10 мкс` створює фазову похибку `Δφ = 360° · 50 · 10⁻⁵ = 0.18°`, що спричиняє неприпустиму похибку обчислення `cos(φ)` при реактивному навантаженні.

Тому для якісних аналізаторів використовують багатоканальні сигма-дельта АЦП із незалежними модуляторами на кожному каналі (наприклад, `ADS131M06`, `STPM33` або `ADE7880`), які фіксують відліки усіх каналів по єдиному фронту тактового сигналу.

### Архітектура збирання даних: DMA та Ping-Pong буферизація

Для забезпечення безперервного вимірювання без втрати жодного відліку на частоті дискретизації `fs = 6400 Гц` процесор мікроконтролера не повинен витрачати час на обробку кожного окремого переривання АЦП. Замість цього застосовують апаратний контролер прямого доступу до пам'яті (DMA) у режимі закольцованого пинг-понг буфера (Double-Buffering):

1. **Буфер А (Ping):** під час того, як модуль DMA автоматично заповнює відліками АЦП першу половину масиву в оперативній пам'яті SRAM, центральний процесор виконує інтенсивні DSP-розрахунки над другою половиною масиву.
2. **Буфер Б (Pong):** після завершення заповнення першої половини масиву генерується переривання DMA `Half-Transfer Complete`. Процесор та DMA міняються буферами без зупинки вибірки.

Така двобуферна схема гарантує 100% покриття часу вимірювання та виключає часові розриви при інтегруванні активної та реактивної енергії.

### Математична дисертація SOGI-PLL та генерація квадратурних сигналів

Для точного вимірювання реактивної потужності та синхронізації з мережею у цифрових аналізаторах застосовують генератор квадратурних сигналів на основі обобоченого інтегратора другого порядку (Second-Order Generalized Integrator, SOGI).

Передавальна функція прямий компоненти SOGI `Hd(s)` та квадратурної компоненти `Hq(s)` має вигляд:

```
Hd(s) = (k · ω0 · s) / (s² + k · ω0 · s + ω0²)
Hq(s) = (k · ω0²) / (s² + k · ω0 · s + ω0²)
```

де `ω0` — центральна резонансна частота мережі (2π · 50 рад/с), а `k` — коефіцієнт демпфування (зазвичай `k = 1.414`).

При дискретизації за допомогою білінійного перетворення Тастіна `s = (2/Ts) · (1 − z⁻¹) / (1 + z⁻¹)` виводиться різницеве рівняння IIR-фільтра другого порядку, яке обчислюється на кожному кроці переривання АЦП:

```
v_direct[n] = b0·v_in[n] + b2·v_in[n-2] − a1·v_direct[n-1] − a2·v_direct[n-2]
v_quadrature[n] = c0·v_in[n] + c1·v_in[n-1] + c2·v_in[n-2] − a1·v_quadrature[n-1] − a2·v_quadrature[n-2]
```

Вихідний сигнал `v_quadrature` строго відстає від `v_direct` на `90.0°` незалежно від гармонійного складу напруги, що забезпечує прецизійний розрахунок реактивної потужності `Q` без викривлення часовими затримками.

### Алгоритм Ґертцеля для цільового виділення гармонік

Коли обчислювальні ресурси мікроконтролера обмежені і виконання повного класичного Швидкого Перетворення Фур'є (FFT) для усіх 64 каналів вимагає занадто багато оперативної пам'яті та циклів ядра, застосовують алгоритм Ґертцеля (Goertzel Algorithm).

Алгоритм Ґертцеля обчислює амплітуду й фазу лише однієї конкретної обраної гармоніки (наприклад, 3-ї, 5-ї або 7-ї) з обчислювальною складністю `O(N)` на гармоніку замість `O(N log N)` для повного FFT.

Різницеве рівняння фільтра Ґертцеля для цільового гармонійного індексу `m = f_target / (fs / N)` обчислюється рекурентно для кожного нового відліку `x[n]`:

```
s[n] = x[n] + 2 · cos(2π · m / N) · s[n-1] − s[n-2]
```

Після накопичення `N` відліків масиву квадрат амплітуди гармоніки обчислюють за формулою:

```
|X[m]|² = s[N-1]² + s[N-2]² − 2 · cos(2π · m / N) · s[N-1] · s[N-2]
```

Завдяки цьому мікроконтролер може безперервно відстежувати величину небезпечної 3-ї гармоніки у нейтральному провіднику з мінімальними витратами ресурсів.

### Детекція нуль-переходів та адаптивна синхронізація (Zero-Crossing Detection)

Для запобігання похибкам спектрального витікання (spectral leakage), що виникають при відхиленні частоти мережі від номінальних 50.0 Гц (наприклад, при роботі від дизель-генератора у діапазоні 47...53 Гц), аналізатор оснащують детектором нуль-переходів напруги.

Цифровий компаратор із програмним гістерезисом `V_hyst = 5.0 В` аналізує сигнал напруги фази A:

```
if (v[n-1] < 0 && v[n] >= 0 && v[n] > V_hyst) {
    // Фіксація точного моменту початку нового періоду
}
```

Знайдений фактичний період `T_measured` використовують для динамічного перезапуску таймера квантування АЦП, забезпечуючи суворо кратно-синхронне вибірку сигналів напруги й струму.

### Інтеграція зі спеціалізованими IC (ADE7880 / ATM90E36)

Поряд із суто софтверним розрахунком на ядрах ARM Cortex-M4/M7, у промислових аналізаторах класу точності 0.2S широко застосовують спеціалізовані апаратні фронтенд-контролери вимірювання енергії (Energy Metering IC), такі як Analog Devices ADE7880 або Microchip ATM90E36.

Ці мікросхеми містять 6 незалежних 24-бітних сигма-дельта АЦП, апаратний DSP-процесор розрахунку True RMS, активної та реактивної потужностей, а також регістри внутрішньої конфігурації. Обмін даними з головним контролером здійснюється по високошвидкісній шині SPI (до 10 МГц).

Взаємодія з ADE7880 включає такі етапи:

1. **Ініціалізація та конфігурування по SPI:** запис констант у регістр `COMPMODE` (вибір 3-провідної схеми Арона або 4-провідної Зірки) та `GAIN` (вибір коефіцієнтів підсилення PGA для каналів струму).
2. **Налаштування калібрувальних регістрів:** запис розрахованих коефіцієнтів у регістри `AIGAIN`, `BIGAIN`, `CIGAIN` для компенсації розкиду параметрів трансформаторів струму та `APHCAL`, `BPHCAL`, `CPHCAL` для компенсації фазового кута.
3. **Обробка апаратних переривань `IRQ0` / `IRQ1`:** мікросхема виставляє низький рівень на виводі `IRQ0` при виявленні просідання напруги (`SAG`), перевантаження за струмом (`OVERCURRENCY`) або нуль-переходу напруги, дозволяючи головному процесору миттєво зреагувати на аварійну ситуацію.

### Дискретні алгоритми цифрової обробки сигналів (DSP)

Розглянемо покроково алгоритм цифрової обробки масиву відліків за один період мережевої частоти `T = 20 мс` (50 Гц). При частоті дискретизації `fs = 6400 Гц` масив містить `N = 128` відліків на період.

#### 1. Вилучення постійного зміщення (DC Offset Removal)

Через неідеальність джерел опорної напруги та зміщення операційних підсилювачів сирий код АЦП `code[k]` містить постійну складову. Для її усунення у кожному кадрі обчислюють середнє значення або застосовують цифровий фільтр високих частот (ФВЧ / High-Pass Filter):

```
v[k] = (code_v[k] − offset_v) · scale_v
i[k] = (code_i[k] − offset_i) · scale_i
```

#### 2. Обчислення діючих значень True RMS

Середньоквадратичне значення напруги `Vrms` та струму `Irms` обчислюється шляхом піднесення до квадрата усіх відліків кадру, накопичення суми та вилучення квадратного кореня:

```
Vrms = √[ (1/N) · ∑_{k=0}^{N-1} (v[k])² ]
Irms = √[ (1/N) · ∑_{k=0}^{N-1} (i[k])² ]
```

Цей метод є True RMS: він дає абсолютну точність вимірювання для сигналів будь-якої несинусоїдальної форми з урахуванням усіх вищих гармонік.

#### 3. Активна та реактивна потужність

Активна потужність `P` обчислюється як середнє значення миттєвих добутків `v[k] · i[k]`:

```
P = (1/N) · ∑_{k=0}^{N-1} (v[k] · i[k])
```

Для розрахунку реактивної потужності `Q` необхідно сформувати ортогональний сигнал напруги `v_90[k]`, зсунутий на `90°` відносно `v[k]`. Найпростішим дискретним методом при фіксованій частоті дискретизації є індексований зсув масиву на `N / 4` відліків (для `N = 128` це зсув на 32 відліки назад):

```
Q = (1/N) · ∑_{k=0}^{N-1} (v_90[k] · i[k])
```

#### 4. Повна потужність та коефіцієнт потужності

```
S = Vrms · Irms
PF = P / S = cos(φ)
```

При наявності нелінійних вищих гармонік коефіцієнт потужності `PF` є меншим за `cos(φ1)` основної гармоніки через наявність деформаційної потужності.

#### 5. Розрахунок енергії в кіловат-годинах (kWh Accumulation)

Накопичена активна енергія `E_active` (в Вт·с або кВт·год) обчислюється шляхом інтегрування активної потужності у часі. Для кожного кадру тривалістю `Δt = N / fs` (0.02 с для 50 Гц) додається прирощення енергії:

```
E_inc = Ptotal · Δt                                          [прирощення енергії за один період, Вт·с]
E_kwh += E_inc / 3600000.0f                                 [накопичення у кВт·год]
```

Для імпульсного виходу лічильника (наприклад, `1000 імпульсів / кВт·год`) генерується вихідний калібрувальний імпульс `CF` щоразу, коли накопичена енергія досягає порогу `1 Вт·год` (3600 Дж).

#### 6. Спектральний аналіз гармонік та розрахунок THD

Для визначення коефіцієнта нелінійних спотворень напруги `THDV` та струму `THDI` над масивом `N = 128` відліків виконують Швидке Перетворення Фур'є (FFT). Знайшовши амплітуди гармонік `V1, V2, V3... V50`, обчислюють коефіцієнт гармонійних спотворень:

```
THDV = ( √[ ∑_{h=2}^{50} (Vh)² ] / V1 ) · 100%              [сумарний коефіцієнт гармонік напруги]
```

Наявність великих значень 3-ї та 9-ї гармонік вказує на роботу однофазних імпульсних джерел живлення, а 5-ї та 7-ї гармонік — на роботу трифазних частотних перетворювачів.

### Захисні функції трифазного реле (Protective Relay Logic)

Окрім вимірювальних функцій, аналізатор потужності реалізує алгоритми релейного захисту обладнання за стандартами ANSI:

- **Захист від перевантаження за струмом (ANSI 51):** зворотна часострумова характеристика (Inverse Definite Minimum Time, IDMT), при якій час відключення реле зменшується пропорційно квадрату кратності струму перевантаження.
- **Захист від несиметрії фазних струмів (ANSI 46):** розрахунок співвідношення струму зворотної послідовності до прямої `I2 / I1`. Якщо несиметрія перевищує `10%` протягом `5` секунд, подається сигнал на відключення контактора для захисту електродвигуна від згоряння.
- **Захист від просідання та перевищення напруги (ANSI 27/59):** миттєве відключення при просіданні напруги нижче `160 В` або перевищенні понад `265 В`.

### Польна робоча реалізація мовами C та C++

Наведена нижче програмна реалізація містить повний модуль розрахунку параметрів трифазної мережі. У вкладці C дано продуктивний код для embedded-платформ без динамічного виділення пам'яті. У вкладці C++ надано об'єктно-орієнтований клас із безпечними контейнерами `std::span` та `std::array`, перевіркою меж і виняткобезпечним інтерфейсом на основі `std::expected`.

```c
/* c */
#include <stdio.h>
#include <stdlib.h>
#include <math.h>
#include <stdint.h>
#include <stdbool.h>

#define SAMPLES_PER_PERIOD 128
#define NUM_PHASES 3

/* Структура результатів вимірювання для однієї фази */
typedef struct {
    float v_rms;       /* Діюча напруга, В */
    float i_rms;       /* Діючий струм, А */
    float p_active;    /* Активна потужність, Вт */
    float q_reactive;  /* Реактивна потужність, вар */
    float s_apparent;  /* Повна потужність, ВА */
    float power_factor;/* Коефіцієнт потужності cos(phi) */
} PhaseResult;

/* Структура загального стану трифазного аналізатора */
typedef struct {
    PhaseResult phases[NUM_PHASES];
    float p_total;
    float q_total;
    float s_total;
    float pf_total;
    float i_neutral_rms;
    double energy_kwh_accumulated;
} ThreePhaseResult;

/* Конфігурація коефіцієнтів калібрування тракту */
typedef struct {
    float v_scale;     /* Коефіцієнт масштабування напруги, В/LSD */
    float i_scale;     /* Коефіцієнт масштабування струму, А/LSD */
    float v_offset;    /* Зміщення нуля АЦП напруги */
    float i_offset;    /* Зміщення нуля АЦП струму */
} MeterCalibration;

/* Обчислення параметрів потужності за один період 50 Гц */
bool process_three_phase_frame(const float raw_v[NUM_PHASES][SAMPLES_PER_PERIOD],
                               const float raw_i[NUM_PHASES][SAMPLES_PER_PERIOD],
                               const MeterCalibration* cal,
                               ThreePhaseResult* out_result)
{
    if (!cal || !out_result) return false;

    float sum_p_total = 0.0f;
    float sum_q_total = 0.0f;
    const int q_shift = SAMPLES_PER_PERIOD / 4; /* Зсув на 90 градусів = 32 відліки */

    /* Цикл розрахунку по кожній із 3 фаз */
    for (int ph = 0; ph < NUM_PHASES; ++ph) {
        float sum_v2 = 0.0f;
        float sum_i2 = 0.0f;
        float sum_p  = 0.0f;
        float sum_q  = 0.0f;

        for (int k = 0; k < SAMPLES_PER_PERIOD; ++k) {
            /* Вилучення зміщення та масштабування */
            float v = (raw_v[ph][k] - cal->v_offset) * cal->v_scale;
            float i = (raw_i[ph][k] - cal->i_offset) * cal->i_scale;

            sum_v2 += v * v;
            sum_i2 += i * i;
            sum_p  += v * i;

            /* Квадратурний відлік напруги для Q (із кільцевим зсувом) */
            int k_q = (k >= q_shift) ? (k - q_shift) : (k + SAMPLES_PER_PERIOD - q_shift);
            float v_90 = (raw_v[ph][k_q] - cal->v_offset) * cal->v_scale;
            sum_q += v_90 * i;
        }

        PhaseResult* res = &out_result->phases[ph];
        res->v_rms = sqrtf(sum_v2 / (float)SAMPLES_PER_PERIOD);
        res->i_rms = sqrtf(sum_i2 / (float)SAMPLES_PER_PERIOD);
        res->p_active = sum_p / (float)SAMPLES_PER_PERIOD;
        res->q_reactive = sum_q / (float)SAMPLES_PER_PERIOD;
        res->s_apparent = res->v_rms * res->i_rms;

        if (res->s_apparent > 1e-5f) {
            res->power_factor = res->p_active / res->s_apparent;
            if (res->power_factor > 1.0f) res->power_factor = 1.0f;
            if (res->power_factor < -1.0f) res->power_factor = -1.0f;
        } else {
            res->power_factor = 1.0f;
        }

        sum_p_total += res->p_active;
        sum_q_total += res->q_reactive;
    }

    /* Розрахунок струму нейтралі iN(t) = iA(t) + iB(t) + iC(t) */
    float sum_in2 = 0.0f;
    for (int k = 0; k < SAMPLES_PER_PERIOD; ++k) {
        float iA = (raw_i[0][k] - cal->i_offset) * cal->i_scale;
        float iB = (raw_i[1][k] - cal->i_offset) * cal->i_scale;
        float iC = (raw_i[2][k] - cal->i_offset) * cal->i_scale;
        float iN = iA + iB + iC;
        sum_in2 += iN * iN;
    }
    out_result->i_neutral_rms = sqrtf(sum_in2 / (float)SAMPLES_PER_PERIOD);

    /* Загальні трифазні підсумки */
    out_result->p_total = sum_p_total;
    out_result->q_total = sum_q_total;
    out_result->s_total = sqrtf(sum_p_total * sum_p_total + sum_q_total * sum_q_total);
    out_result->pf_total = (out_result->s_total > 1e-5f) ? (out_result->p_total / out_result->s_total) : 1.0f;

    /* Інтегрування активної енергії за кадр тривалістю 0.02 с (50 Гц) */
    double frame_duration_sec = 0.02;
    double energy_joules = (double)out_result->p_total * frame_duration_sec;
    out_result->energy_kwh_accumulated += energy_joules / 3600000.0;

    return true;
}
```

```cpp
// cpp
#include <iostream>
#include <vector>
#include <array>
#include <cmath>
#include <span>
#include <algorithm>
#include <numeric>
#include <expected>

namespace power_meter {

constexpr size_t SamplesPerPeriod = 128;
constexpr size_t NumPhases = 3;

struct PhaseMetrics {
    float v_rms{0.0f};
    float i_rms{0.0f};
    float p_active{0.0f};
    float q_reactive{0.0f};
    float s_apparent{0.0f};
    float power_factor{1.0f};
};

struct SystemMetrics {
    std::array<PhaseMetrics, NumPhases> phases{};
    float p_total{0.0f};
    float q_total{0.0f};
    float s_total{0.0f};
    float pf_total{1.0f};
    float i_neutral_rms{0.0f};
    double energy_kwh_accumulated{0.0};
};

struct Calibration {
    float v_scale{1.0f};
    float i_scale{1.0f};
    float v_offset{0.0f};
    float i_offset{0.0f};
};

enum class MeterError {
    InvalidBufferSize,
    NullCalibration,
    ComputationOverflow
};

class ThreePhaseAnalyzer {
public:
    explicit ThreePhaseAnalyzer(Calibration cal) : cal_(cal) {}

    [[nodiscard]] std::expected<SystemMetrics, MeterError> analyze_frame(
        std::span<const float> raw_v,
        std::span<const float> raw_i,
        double current_kwh_acc = 0.0) const noexcept
    {
        if (raw_v.size() != NumPhases * SamplesPerPeriod ||
            raw_i.size() != NumPhases * SamplesPerPeriod)
        {
            return std::unexpected(MeterError::InvalidBufferSize);
        }

        SystemMetrics sys{};
        sys.energy_kwh_accumulated = current_kwh_acc;
        float sum_p_total = 0.0f;
        float sum_q_total = 0.0f;
        constexpr int q_shift = SamplesPerPeriod / 4;

        for (size_t ph = 0; ph < NumPhases; ++ph) {
            auto v_phase = raw_v.subspan(ph * SamplesPerPeriod, SamplesPerPeriod);
            auto i_phase = raw_i.subspan(ph * SamplesPerPeriod, SamplesPerPeriod);

            float sum_v2 = 0.0f;
            float sum_i2 = 0.0f;
            float sum_p  = 0.0f;
            float sum_q  = 0.0f;

            for (size_t k = 0; k < SamplesPerPeriod; ++k) {
                const float v = (v_phase[k] - cal_.v_offset) * cal_.v_scale;
                const float i = (i_phase[k] - cal_.i_offset) * cal_.i_scale;

                sum_v2 += v * v;
                sum_i2 += i * i;
                sum_p  += v * i;

                const size_t k_q = (k >= q_shift) ? (k - q_shift) : (k + SamplesPerPeriod - q_shift);
                const float v_90 = (v_phase[k_q] - cal_.v_offset) * cal_.v_scale;
                sum_q += v_90 * i;
            }

            auto& res = sys.phases[ph];
            res.v_rms = std::sqrt(sum_v2 / static_cast<float>(SamplesPerPeriod));
            res.i_rms = std::sqrt(sum_i2 / static_cast<float>(SamplesPerPeriod));
            res.p_active = sum_p / static_cast<float>(SamplesPerPeriod);
            res.q_reactive = sum_q / static_cast<float>(SamplesPerPeriod);
            res.s_apparent = res.v_rms * res.i_rms;

            if (res.s_apparent > 1e-5f) {
                res.power_factor = std::clamp(res.p_active / res.s_apparent, -1.0f, 1.0f);
            }

            sum_p_total += res.p_active;
            sum_q_total += res.q_reactive;
        }

        // Струм нейтрального провідника
        float sum_in2 = 0.0f;
        for (size_t k = 0; k < SamplesPerPeriod; ++k) {
            const float iA = (raw_i[0 * SamplesPerPeriod + k] - cal_.i_offset) * cal_.i_scale;
            const float iB = (raw_i[1 * SamplesPerPeriod + k] - cal_.i_offset) * cal_.i_scale;
            const float iC = (raw_i[2 * SamplesPerPeriod + k] - cal_.i_offset) * cal_.i_scale;
            const float iN = iA + iB + iC;
            sum_in2 += iN * iN;
        }
        sys.i_neutral_rms = std::sqrt(sum_in2 / static_cast<float>(SamplesPerPeriod));

        sys.p_total = sum_p_total;
        sys.q_total = sum_q_total;
        sys.s_total = std::hypot(sys.p_total, sys.q_total);
        sys.pf_total = (sys.s_total > 1e-5f) ? (sys.p_total / sys.s_total) : 1.0f;

        constexpr double frame_duration_sec = 0.02;
        const double energy_joules = static_cast<double>(sys.p_total) * frame_duration_sec;
        sys.energy_kwh_accumulated += energy_joules / 3600000.0;

        return sys;
    }

private:
    Calibration cal_;
};

} // namespace power_meter
```

### Покроковий порядок метрологічного калібрування

Для забезпечення класу точності `0.2S` за IEC 62053-22 зібраний прилад піддають триетапному метрологічному калібруванню на автоматизованій стендовій установці з еталонним калібратором `Fluke 6100A`:

1. **Калібрування зміщення нуля (Zero-Offset Calibration):**
   При замиканні аналогових входів струму й напруги на загальну шину GND зчитують 1000 послідовних кадрів АЦП. Обчислене середнє арифметичне значення у кодах АЦП зберігається у константах `v_offset` та `i_offset` у конфігураційній флеш-пам'яті.
2. **Калібрування масштабних коефіцієнтів (Gain Scaling Calibration):**
   На входи приладу подають суворо синусоїдальні напруги `V_ref = 230.000 В` та струми `I_ref = 5.0000 А` від еталонного джерела при суто активному навантаженні (`cos(φ) = 1.0000`). Зчитують виміряні неодкалібровані діючі значення `V_raw` та `I_raw`. Обчислюють масштабні коефіцієнти:

```
v_scale = V_ref / V_raw
i_scale = I_ref / I_raw
```

3. **Калібрування фазового зсуву (Phase Angle Compensation):**
   На еталонному калібраторі встановлюють індуктивне навантаження з кутом зсуву `φ = 60.0°` (`cos(φ) = 0.5000`). Якщо аналізатор показує відхилення `PF` (наприклад, `0.4860`), обчислюють власну кутову похибку трансформаторів струму `Δφ = arccos(0.4860) − 60.0°` і вносять цифровий фазообертач або інтерполяційний зсув в масив відліків струму.

### Протоколи передачі даних та інтеграція у мережі Modbus RTU / RS-485

Отримані обчислені параметри `SystemMetrics` пакують у регістри зберігання (Holding Registers) промислового протоколу Modbus RTU для передачі у системи SCADA або контролери АСКУЕ через інтерфейс RS-485 з трансиверами серії `ADM2483` або `MAX1487`. Кожна 32-бітна величина з плаваючою комою `float` або `double` пакується у два послідовні 16-бітні регістри Modbus у форматі IEEE 754 Big-Endian (CDAB або ABCD). Для гарантії цілісності передачі даних кожен кадр Modbus супроводжується перевірочною контрольною сумою CRC-16 (поліном `0xA001`).

Обчислення CRC-16 виконується за лінійним алгоритмом:

```
uint16_t modbus_crc16(const uint8_t *buf, uint16_t len) {
    uint16_t crc = 0xFFFF;
    for (uint16_t pos = 0; pos < len; pos++) {
        crc ^= (uint16_t)buf[pos];
        for (int i = 8; i != 0; i--) {
            if ((crc & 0x0001) != 0) {
                crc >>= 1;
                crc ^= 0xA001;
            } else {
                crc >>= 1;
            }
        }
    }
    return crc;
}
```

Використання гальванічно ізольованих трансиверів RS-485 з захистом від статичної електрики (ESD 15 кВ) гарантує надійну передачу виміряних даних в умовах жорстких промислових електромагнітних завад від частотних перетворювачів.

Типову карту регістрів аналізатора наведено в описі специфікацій трифазних мереж.

### Практичні інженерні пастки та крайові випадки при експлуатації

- **Підмагнічування осердя трансформаторів струму постійним струмом (DC Saturation):** при живленні однонапівперіодних навантажень (наприклад, фенів із діодним регулятором) у мережевому струмі виникає постійна складова. Постійний струм заганяє магнітне осердя ТС у глибоке насичення, спотворюючи форму вторинного струму та викликаючи похибку вимірювання активної потужності до `25–30%`. Для побутових лічильників вибирають шунти або спеціальні ТС з антинасичуваним аморфним осердям.
- **Самопрогрів струмових шунтів:** проходження постійного або змінного струму `100 А` через шунт опором `100 мкОм` виділяє теплову потужність `P = I²·R = 1 Вт`. Нагрів шунта на `50 °C` при ТКО `100 ppm/°C` змінює його опір на `0.5%`. Для прецизійних приладів використовують марганінові або константанові шунти з ТКО `< 10 ppm/°C` та масивні радіаторні площадки.
- **Плутанина послідовності фаз (Phase Swapping):** підключення фаз у порядку `A-C-B` замість `A-B-C` призводить до того, що асинхронні двигуни починають обертатися у зворотний бік. Програму аналізатора доповнюють детектором послідовності фаз, який перевіряє знак напруги прямої та зворотної послідовностей `V1` та `V2`.
