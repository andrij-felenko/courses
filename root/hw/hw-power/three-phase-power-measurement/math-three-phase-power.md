# 🧮 Математичний вивід та аналіз потужності у трифазних кола

У колах змінного струму обчислення потужності базується на аналізі миттєвого добутку напруги та струму. У трифазній симетричній системі виникає унікальний алгебраїчний феномен: незважаючи на те, що напруга й струм кожної окремої фази гармонічно змінюються в часі, а миттєва потужність кожної фази містить пульсуючу складову з подвоєною частотою `2ω`, сума миттєвих потужностей усіх трьох фаз у будь-який момент часу є суворо постійною величиною.

Нижче наведено виведення цієї фундаментальної властивості, математичне обґрунтування співвідношень між лінійними та фазними величинами при з'єднаннях «Зірка» та «Трикутник», виведення еквівалентних перетворень імпедансів, математичний розрахунок зсуву нейтралі за теоремою Мільмана, виведення методу двох ватметрів (схеми Арона), теорію миттєвої потужності Акагі у координатах Кларк, а також метод симетричних складових Фортеск'ю та аналіз деформаційної потужності.

### Доведення постійності сумарної миттєвої потужності

Розглянемо симетричну трифазну систему. Напруги трьох фаз `vA(t)`, `vB(t)`, `vC(t)` утворюють гармонічну трійку сигналів, зсунутих один відносно одного у часі на третину періоду, тобто на кут `120°` (`2π/3` радіан). Фізично це відповідає просторовому розміщенню обмоток генератора на статорі через рівні кутові інтервали:

```
vA(t) = √2 · Vph · sin(ωt)
vB(t) = √2 · Vph · sin(ωt − 2π/3)
vC(t) = √2 · Vph · sin(ωt − 4π/3)
```

де `Vph` — середньоквадратичне (діюче) значення фазної напруги, а `ω` — кутова частота обертання ротора генератора.

При збалансованому трифазному навантаженні з однаковим комплексним імпедансом `Z = |Z| · e^(jφ)` у кожній фазі струми мають таку ж амплітуду та відстають від відповідних фазних напруг на кут зсуву фаз `φ`, який визначається співвідношенням реактивного та активного опорів навантаження:

```
iA(t) = √2 · Iph · sin(ωt − φ)
iB(t) = √2 · Iph · sin(ωt − 2π/3 − φ)
iC(t) = √2 · Iph · sin(ωt − 4π/3 − φ)
```

де `Iph` — діюче значення фазного струму.

Миттєва потужність фази A `pA(t)` дорівнює добутку миттєвого значення напруги цієї фази на миттєве значення струму, що протікає через неї:

```
pA(t) = vA(t) · iA(t)
= 2 · Vph · Iph · sin(ωt) · sin(ωt − φ)
```

Застосуємо фундаментальну тригонометричну тотожність розкладу добутку двох синусів у різницю косинусів `sin(α) · sin(β) = (1/2) · [cos(α − β) − cos(α + β)]`:

```
pA(t) = 2 · Vph · Iph · (1/2) · [cos(φ) − cos(2ωt − φ)]      [застосовано добуток синусів для α = ωt, β = ωt − φ]
= Vph · Iph · cos(φ) − Vph · Iph · cos(2ωt − φ)              [розкрито дужки]
```

З отриманого виразу виразно видно, що миттєва потужність однофазного кола складається з двох частин: постійної складової `Vph · Iph · cos(φ)` (активна потужність фази) та змінної складової `Vph · Iph · cos(2ωt − φ)`, яка гармонічно коливається з подвоєною частотою `2ω`. Саме ця змінна складова в однофазній мережі викликає пульсацію механічного моменту двигунів і створює вібрації.

Аналогічно знайдемо миттєві потужності фаз B і C, враховуючи відповідні кутові зсуви:

```
pB(t) = Vph · Iph · cos(φ) − Vph · Iph · cos(2ωt − 4π/3 − φ)  [миттєва потужність фази B]
pC(t) = Vph · Iph · cos(φ) − Vph · Iph · cos(2ωt − 8π/3 − φ)  [миттєва потужність фази C]
```

Сумарна миттєва потужність трифазного кола `ptotal(t)` в будь-який момент часу є алгебраїчною сумою миттєвих потужностей усіх трьох окремих фаз:

```
ptotal(t) = pA(t) + pB(t) + pC(t)
= 3 · Vph · Iph · cos(φ) − Vph · Iph · [cos(2ωt − φ) + cos(2ωt − 4π/3 − φ) + cos(2ωt − 8π/3 − φ)]  [групування сталих та змінних членів]
```

Розглянемо детально тригонометричну суму трьох гармонічних функцій під квадратними дужками. Здійснимо заміну змінної `θ = 2ωt − φ`. Тоді сума трьох косинусів набуває вигляду:

```
S(θ) = cos(θ) + cos(θ − 2π/3) + cos(θ − 4π/3)
```

Застосуємо формулу косинуса різниці двох кутів `cos(x − y) = cos(x)·cos(y) + sin(x)·sin(y)` для другого та третього доданків:

```
cos(θ − 2π/3) = cos(θ)·cos(2π/3) + sin(θ)·sin(2π/3)
= −(1/2)·cos(θ) + (√3/2)·sin(θ)                             [значення cos(120°) = -1/2, sin(120°) = √3/2]

cos(θ − 4π/3) = cos(θ)·cos(4π/3) + sin(θ)·sin(4π/3)
= −(1/2)·cos(θ) − (√3/2)·sin(θ)                             [значення cos(240°) = -1/2, sin(240°) = -√3/2]
```

Підставимо ці вирази в сумарний вираз `S(θ)` і виконаймо алгебраїчне спрощення:

```
S(θ) = cos(θ) + [−(1/2)·cos(θ) + (√3/2)·sin(θ)] + [−(1/2)·cos(θ) − (√3/2)·sin(θ)]
= cos(θ) − (1/2)·cos(θ) − (1/2)·cos(θ) + (√3/2)·sin(θ) − (√3/2)·sin(θ)  [групування подібних доданків]
= cos(θ) · (1 − 1/2 − 1/2) + sin(θ) · (√3/2 − √3/2)                    [зведення коефіцієнтів]
= cos(θ) · 0 + sin(θ) · 0                                              [коефіцієнти обнулилися]
= 0                                                                    [тотожний нуль при будь-якому t]
```

Оскільки сума змінних складових `S(θ)` тотожно дорівнює нулю у будь-який момент часу `t`, пульсуюча частина енергії повністю взаємознищується між фазами. У результаті отримуємо остаточне рівняння:

```
ptotal(t) = 3 · Vph · Iph · cos(φ) = Ptotal = const
```

Це доведення демонструє головний теоретичний феномен трифазної мережі: сумарна миттєва потужність є суворо постійною величиною в часі. Трифазна система діє як ідеальний безперервний потік енергії без жодних часових пульсацій.

### Математичний зв'язок між лінійними та фазними величинами

У практичних трифазних мережах оперують двома категоріями параметрів: фазними величинами (напруга між фазовим провідником і нейтраллю `Vph`, струм у фазній обмотці `Iph`) та лінійними величинами (напруга між двома суміжними фазовими провідниками `VL`, струм у лінійному провіднику `IL`).

#### 1. З'єднання «Зірка» (Y)

У з'єднанні «Зірка» фазні обмотки джерела або навантаження об'єднані в одній спільній нейтральній точці N. Звідси випливає, що лінійний струм, який тече по силовому провіднику від джерела до навантаження, безпосередньо затікає у відповідну фазову обмотку:

```
IL = Iph                                                    [тотожна рівність лінійного та фазного струмів у Зірці]
```

Лінійна напруга `vAB(t)` між лініями A та B визначається як різниця потенціалів фазних провідників відносно нейтралі:

```
vAB(t) = vA(t) − vB(t)
= √2 · Vph · [sin(ωt) − sin(ωt − 2π/3)]                     [різниця фазних синусоїд]
```

Застосуємо тригонометричну формулу різниці синусів `sin(α) − sin(β) = 2 · sin((α − β)/2) · cos((α + β)/2)`:

```
α − β = ωt − (ωt − 2π/3) = 2π/3  →  (α − β)/2 = π/3 (60°)
α + β = 2ωt − 2π/3              →  (α + β)/2 = ωt − π/3 (60°)
```

Отже:

```
vAB(t) = √2 · Vph · 2 · sin(π/3) · cos(ωt − π/3)
= √2 · Vph · 2 · (√3/2) · cos(ωt − π/3)                    [підстановка sin(60°) = √3/2]
= √2 · (√3 · Vph) · sin(ωt + π/6)                           [перехід від cos до sin через cos(x) = sin(x + π/2)]
```

Звідси випливає фундаментальне співвідношення для діючих значень у «Зірці»: лінійна напруга випереджає відповідну фазну напругу за фазою на `30°` (`π/6`), а її амплітудне й діюче значення у `√3 ≈ 1.732` раза перевищує фазну напругу:

```
VL = √3 · Vph                                               [лінійна напруга більша за фазну у √3 разів]
```

Для стандартної побутової та промислової мережі при фазній напрузі `Vph = 230 В` лінійна напруга між фазами становить `VL = 230 · √3 ≈ 400 В`.

Замінивши `Vph = VL / √3` у загальній формулі сумарної потужності `P = 3 · Vph · Iph · cos(φ)`, отримуємо розрахунковий вираз через лінійні параметри:

```
P = 3 · (VL / √3) · IL · cos(φ)
= √3 · VL · IL · cos(φ)                                     [активна потужність через лінійні величини]
```

#### 2. З'єднання «Трикутник» (Δ)

У з'єднанні «Трикутник» фазні обмотки навантаження підключені безпосередньо між двома лінійними провідниками. Оскільки нейтральний провідник відсутній, лінійна напруга прикладається безпосередньо до кожної фази:

```
VL = Vph                                                    [рівність лінійного та фазного значений напруги у Трикутнику]
```

Лінійний струм `iA(t)`, який втікає у вузол А, розгалужується на два фазні струми `iAB(t)` та `iCA(t)`. За першим законом Кірхгофа:

```
iA(t) = iAB(t) − iCA(t)
```

Аналогічно до математичного виведення напруг у «Зірці», різниця двох однакових гармонічних струмів зі зсувом `120°` дає пропорційне збільшення амплітуди лінійного струму:

```
IL = √3 · Iph                                               [лінійний струм більший за фазний у √3 разів]
```

Підставивши `Iph = IL / √3` у формулу потужності `P = 3 · Vph · Iph · cos(φ)`, виводимо вираз для active power:

```
P = 3 · VL · (IL / √3) · cos(φ)
= √3 · VL · IL · cos(φ)                                     [інваріантна формула потужності]
```

Цей висновок доводить фундаментальний інваріант електротехніки: незалежно від внутрішньої схеми з'єднання навантаження («Зірка» чи «Трикутник»), формула трифазної активної потужності через лінійні виміряні струми та напруги має єдиний уніфікований вигляд `P = √3 · VL · IL · cos(φ)`.

Аналогічним чином визначаються вирази для реактивної `Q` та повної `S` потужностей трифазної мережі:

```
Q = √3 · VL · IL · sin(φ)                                   [реактивна потужність, вар / var]
S = √3 · VL · IL                                            [повна потужність, В·А / VA]
S = √(P² + Q²)                                              [трикутник потужностей]
```

### Перетворення еквівалентних імпедансів Зірка-Трикутник

Для розрахунку складних трифазних кіл часто виникає потреба замінити навантаження, з'єднане «Зіркою» з імпедансами `ZA, ZB, ZC`, еквівалентним навантаженням, з'єднаним «Трикутником» з імпедансами `ZAB, ZBC, ZCA`, щоб споживана потужність та лінійні струми залишилися незмінними.

Формули перетворення «Зірка -> Трикутник» виводяться з умови рівності вхідних провідностей між відповідними парами затискачів:

```
ZAB = ZA + ZB + (ZA · ZB) / ZC                              [еквівалентний імпеданс плеча AB]
ZBC = ZB + ZC + (ZB · ZC) / ZA                              [еквівалентний імпеданс плеча BC]
ZCA = ZC + ZA + (ZC · ZA) / ZB                              [еквівалентний імпеданс плеча CA]
```

Обернене перетворення «Трикутник -> Зірка» здійснюється за формулами:

```
ZA = (ZAB · ZCA) / (ZAB + ZBC + ZCA)                        [еквівалентний імпеданс фази A]
ZB = (ZAB · ZBC) / (ZAB + ZBC + ZCA)                        [еквівалентний імпеданс фази B]
ZC = (ZBC · ZCA) / (ZAB + ZBC + ZCA)                        [еквівалентний імпеданс фази C]
```

У разі симетричного навантаження, коли `ZA = ZB = ZC = ZY` та `ZAB = ZBC = ZCA = ZΔ`, вирази спрощуються до фундаментального співвідношення:

```
ZΔ = 3 · ZY                                                 [опір фази у Трикутнику втричі більший за опір у Зірці]
```

Це означає, що при перемиканні обмоток трифазного двигуна з «Зірки» на «Трикутник» при тій же лінійній напрузі мережі споживана потужність та пусковий струм зростають у 3 рази. Цей математичний факт лежить в основі класичного пуску потужних асинхронних двигунів схемою «перемикання зірка-трикутник» для зменшення пускових кидків струму.

### Теорема Мільмана та розрахунок зміщення нейтралі при обриві N-провідника

У несиметричній 4-провідній мережі при порушенні цілісності нейтрального провідника (обрив нейтралі) виникає явище зміщення нейтральної точки. Математично потенціал зміщеної нейтралі навантаження `N'` відносно нейтралі джерела `N` обчислюється за **теоремою Мільмана** (методом вузлових потенціалів):

```
V_NN' = (VA · YA + VB · YB + VC · YC) / (YA + YB + YC + YN)  [теорема Мільмана для потенціалу нейтралі]
```

де `VA, VB, VC` — фазні комплексні напруги джерела, `YA = 1/ZA`, `YB = 1/ZB`, `YC = 1/ZC` — комплексні провідності фаз навантаження, а `YN = 1/ZN` — провідність нейтрального провідника.

Коли нейтральний провідник справний і має малий опір (`ZN ≈ 0`, відповідно `YN -> ∞`), знаменник прямує до нескінченності, і потенціал зміщення нейтралі дорівнює нулю (`V_NN' = 0`). Фазні напруги на споживачах залишаються суворо симетричними та дорівнюють `230 В`.

Проте при обриві нейтралі (`YN = 0`) формула Мільмана набуває вигляду:

```
V_NN' = (VA · YA + VB · YB + VC · YC) / (YA + YB + YC)       [потенціал зміщення нейтралі при обриві N]
```

Напруга на кожній фазі навантаження обчислюється як різниця потенціалів фази джерела та зміщеної нейтралі:

```
VA' = VA − V_NN'
VB' = VB − V_NN'
VC' = VC − V_NN'
```

Якщо навантаження фаз катастрофічно несиметричне (наприклад, у фазі A включений потужний прилад із малим опором `ZA`, тобто великою провідністю `YA`, а у фазі B включений лише малопотужний прилад із великим опором `ZB`, тобто `YB ≈ 0`), потенціал `V_NN'` зміщується в бік фази A. У результаті напруга `VA'` на фазі A падає майже до нуля, а напруга `VB'` на малонавантаженій фазі B зростає до значення лінійної напруги:

```
VB' -> VAB = √3 · Vph ≈ 400 В                                [перекіс фаз: напруга сягає лінійного значення]
```

Цей математичний розрахунок пояснює фізичну небезпеку обриву нейтралі у побутових електромережах: усі однофазні прилади на 230 В, підключені до малонавантаженої фази, опиняються під нищівною напругою 400 В і миттєво виходять з ладу.

### Математичний вивід методу двох ватметрів (Схема Арона)

Вимірювання трифазної потужності у трипровідній мережі (без нейтралі) можна виконати лише двома однофазними ватметрами. Виведемо математичну строгість цього методу.

За визначенням, миттєва потужність трифазного кола дорівнює:

```
p(t) = vA · iA + vB · iB + vC · iC
```

За першим законом Кірхгофа для ізольованого вузла без нейтралі сума лінійних струмів тотожно дорівнює нулю у будь-який момент часу:

```
iA + iB + iC = 0  →  iC = − iA − iB
```

Підставимо вираз для `iC` у формулу миттєвої потужності:

```
p(t) = vA · iA + vB · iB + vC · (− iA − iB)                  [виключення струму iC]
= vA · iA + vB · iB − vC · iA − vC · iB                      [розкрито дужки]
= (vA − vC) · iA + (vB − vC) · iB                            [групування за струмами iA та iB]
= vAC · iA + vBC · iB                                        [підстановка лінійних напруг vAC = vA − vC, vBC = vB − vC]
```

Отже, миттєва потужність трифазного кола повністю описується сумою двох добутків: струму лінії A на лінійну напругу `vAC` та струму лінії B на лінійну напругу `vBC`.

Усереднивши цей вираз за період коливань `T`, отримаємо значення активної потужності, які виміряють два однофазні ватметри `W1` та `W2`:

```
P1 = VAC · IA · cos(ψ1)                                      [покази першого ватметра W1]
P2 = VBC · IB · cos(ψ2)                                      [покази другого ватметра W2]
```

Знайдемо кути фазового зсуву `ψ1` та `ψ2` між векторами напруг і струмів:
- Вектор лінійної напруги `VAC` випереджає фазну напругу `VA` на `30°`. Оскільки струм `IA` відстає від `VA` на кут `φ`, кут між векторами `VAC` та `IA` становить `ψ1 = 30° − φ`.
- Вектор лінійної напруги `VBC` відстає від фазної напруги `VB` на `30°`. Оскільки струм `IB` відстає від `VB` на кут `φ`, кут між векторами `VBC` та `IB` становить `ψ2 = 30° + φ`.

Підставивши ці кути при симетричній напрузі `VAC = VBC = VL` та струмах `IA = IB = IL`, отримуємо покази ватметрів:

```
P1 = VL · IL · cos(30° − φ)
P2 = VL · IL · cos(30° + φ)
```

Обчислимо суму показів двох ватметрів `P1 + P2`:

```
P1 + P2 = VL · IL · [cos(30° − φ) + cos(30° + φ)]
= VL · IL · [2 · cos(30°) · cos(φ)]                          [тригонометрична сума косинусів: cos(α−β)+cos(α+β) = 2·cos(α)·cos(β)]
= VL · IL · [2 · (√3/2) · cos(φ)]                            [підстановка значення cos(30°) = √3/2]
= √3 · VL · IL · cos(φ) = Ptotal                             [доведено: сума показів дорівнює повній активній потужності]
```

Обчислимо різницю показів двох ватметрів `P1 − P2`:

```
P1 − P2 = VL · IL · [cos(30° − φ) − cos(30° + φ)]
= VL · IL · [2 · sin(30°) · sin(φ)]                          [різниця косинусів: cos(α−β)−cos(α+β) = 2·sin(α)·sin(β)]
= VL · IL · [2 · (1/2) · sin(φ)]                            [підстановка значення sin(30°) = 1/2]
= VL · IL · sin(φ)                                           [отримано вираз VL · IL · sin(φ)]
```

Помноживши отриману різницю `(P1 − P2)` на `√3`, виводимо вираз для сумарної реактивної потужності трифазного кола `Qtotal`:

```
Qtotal = √3 · (P1 − P2) = √3 · VL · IL · sin(φ)               [визначення реактивної потужності через покази ватметрів]
```

Поділивши різницю показів на їхню суму, отримуємо прямий метод розрахунку тангенса кута фазового зсуву без застосування фазометра:

```
tan(φ) = Qtotal / Ptotal = [√3 · (P1 − P2)] / (P1 + P2)      [розрахунок tan(φ) за показами двох ватметрів]
```

Цей результат пояснює важливу практичну особливість: якщо коефіцієнт потужності навантаження знижується нижче `cos(φ) = 0.5` (тобто кут `φ > 60°`), один із ватметрів (`W2`) починає показувати від'ємне значення. Стрілка аналогового приладу відхиляється ліворуч від нуля, і для зняття показань потрібно змінити полярність його струмової обмотки, а виміряне значення не додавати, а віднімати від показів першого ватметра.

### Теорія миттєвої потужності Акагі у координатах αβ0 (Clarke Transformation)

У сучасній силовій електроніці та цифрових аналізаторах якості електроенергії для миттєвого розрахунку активної та реактивної потужностей у нестаціонарних режимах застосовують теорію миттєвої потужності (Instantaneous p-q Theory), розроблену японським професором Хірофумі Акагі (*Hirofumi Akagi*) у 1983 році.

В основі методів Акагі лежить перетворення Кларк (*Clarke Transformation*), яке ортогонально проектує трифазну систему координат `A, B, C` на двовісну нерухому систему координат `α, β, 0`:

```
vα = √(2/3) · [vA − (1/2)·vB − (1/2)·vC]                     [компонента напруги α]
vβ = √(2/3) · [(√3/2)·vB − (√3/2)·vC]                         [компонента напруги β]
v0 = (1/√3) · [vA + vB + vC]                                 [компонента нульової послідовності]
```

Аналогічно обчислюються ортогональні компоненти струму `iα`, `iβ`, `i0`.

У координатах `α-β` миттєва активна потужність `p(t)` та миттєва реактивна потужність `q(t)` визначаються через векторний та скалярний добутки ортогональних векторів напруги та струму:

```
p(t) = vα · iα + vβ · iβ                                     [миттєва активна потужність Акагі]
q(t) = vβ · iα − vα · iβ                                     [миттєва реактивна потужність Акагі]
```

У матричній формі це перетворення записується у вигляді:

```
[ p ]   [  vα   vβ ] [ iα ]
[   ] = [          ] [    ]                                  [матричне рівняння Акагі]
[ q ]   [  vβ  -vα ] [ iβ ]
```

Перевага підходу Акагі полягає у тому, що миттєві потужності `p(t)` та `q(t)` розраховуються дискретно для кожного окремого відліку АЦП без потреби у накопиченні відліків за цілий період коливань `T`. Це дозволяє створювати надшвидкодіючі активні силові фільтри та компенсатори нелінійних вищих гармонік у реальному часі.

### Несиметричні режими та метод симетричних складових Фортеск'ю

При нерівномірному навантаженні фаз (`ZA ≠ ZB ≠ ZC`) симетрія струмів і напруг порушується. Для математичного розрахунку таких режимів американський інженер Чарльз Фортеск'ю у 1918 році розробив **метод симетричних складових**.

Будь-яку несиметричну трифазну систему векторів напруг `(VA, VB, VC)` або струмів `(IA, IB, IC)` можна однозначно розкласти на суму трьох симетричних систем:

1. **Пряма послідовність (індекс 1):** вектори однакової амплітуди `V1`, зсунуті на `120°` у порядку чередування `A -> B -> C`.
2. **Зворотна послідовність (індекс 2):** вектори однакової амплітуди `V2`, зсунуті на `120°` у зворотному порядку чередування `A -> C -> B`.
3. **Нульова послідовність (індекс 0):** три вектори однакової амплітуди `V0`, які збігаються за фазою (зсув `0°`).

Введемо комплексний фазний оператор повороту `a`:

```
a = e^(j 2π/3) = cos(120°) + j·sin(120°) = −0.5 + j 0.866
a² = e^(j 4π/3) = cos(240°) + j·sin(240°) = −0.5 − j 0.866
1 + a + a² = 0                                              [властивість оператора повороту]
```

Зв'язок фазних напруг із симетричними складовими описується системою рівнянь:

```
VA = V0 + V1 + V2
VB = V0 + a²·V1 + a·V2
VC = V0 + a·V1 + a²·V2
```

Обернене перетворення Фортеск'ю дозволяє обчислити симетричні складові за виміряними фазними векторами:

```
V0 = (1/3) · (VA + VB + VC)                                 [напруга нульової послідовності]
V1 = (1/3) · (VA + a·VB + a²·VC)                             [напруга прямої послідовності]
V2 = (1/3) · (VA + a²·VB + a·VC)                             [напруга зворотної послідовності]
```

При несиметричному навантаженні струм у нейтральному провіднику `IN` дорівнює потрійному струму нульової послідовності:

```
IN = IA + IB + IC = 3 · I0
```

#### Вплив кратно-триплетних гармонік (3-тя, 9-та, 15-та) та деформаційна потужність D

При наявності нелінійних навантажень (імпульсні джерела живлення, випрямлячі, частотні перетворювачі) у струмі виникають вищі гармоніки. Особливу небезпеку становлять гармоніки, кратні трьом (триплетні гармоніки `h = 3, 9, 15...`).

Оскільки зсув фаз 3-ї гармоніки між фазами становить `3 · 120° = 360° = 0°`, струми третинної гармоніки усіх трьох фаз збігаються за напрямком і фазою. Звідси випливає, що у нейтральному провіднику струми третинної гармоніки не взаємознищуються, а скалярно додаються:

```
IN_3rd = iA_3rd + iB_3rd + iC_3rd = 3 · I_3rd               [струм 3-ї гармоніки в нейтралі]
```

Це може призвести до того, що діюче значення струму у нейтральному провіднику `IN` перевищить діюче значення струму у фазних провідниках у `√3 ≈ 1.73` раза, що викликає катастрофічний перегрів і пожежну небезпеку нейтральних кабелів, якщо їхній переріз розраховували лише на несиметрію основної частоти 50 Гц.

У несинусоїдальних режимах за теорією Будяну (*Budeanu*) повна потужність `S` розкладається на три ортогональні складові: активну потужність `P`, реактивну потужність `Q` та потужність спотворення `D` (*distortion power*):

```
S = √(P² + Q² + D²)                                         [розклад повної потужності за Будяну]
```

де `D` описує взаємодію напруг і струмів різних гармонійних порядків. Наявність складової `D` знижує загальний коефіцієнт потужності `PF = P / S` навіть при повному збігу фаз основних гармонік напруги та струму (`cos(φ1) = 1`), що вимагає застосування активних фільтрів вищих гармонік для захисту мереж.
