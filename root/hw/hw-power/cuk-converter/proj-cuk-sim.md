# ⚙️ Проєктування та числова симуляція перетворювача Ćuk: від вибору компонентів до моделювання перехідних процесів

Теоретичні формули ідеального перетворювача Ćuk не враховують реальних нелінійностей напівпровідникових ключів, паразитних індуктивностей витоку у зв'язаних магнітних осердях та теплових обмежень керамічних конденсаторів перенесення енергії. Ця практична вставка містить повну інженерну методику розрахунку реального перетворювача для живлення прецизійного аналогового тракту, покроковий вибір компонентної бази, тепловий баланс втрат, схему зворотного зв'язку для від'ємної шини, трасування друкованої плати, розрахунок ЕМС-фільтрації, схеми захисту, а також верифіковану числову модель симулятора перехідних процесів на мовах C та C++, яка демонструє фізику явища занулення пульсацій струму (ripple steering).

## 1. Технічне завдання на розробку

Спроектуємо модуль вторинного живлення для прецизійної системи збору аналогових даних (АЦП високої розрядності та вимірювальні операційні підсилювачі):
- Вхідна напруга живлення: `Vвх = 24 В` (промислова шина живлення, робочий діапазон `18–30 В`).
- Вихідна напруга: `Vвих = −15 В` (стабілізована від'ємна шина аналогового живлення).
- Номінальний струм навантаження: `Iвих = 1.5 А` (вихідна потужність `Pвих = 22.5 Вт`).
- Частота комутації: `f_sw = 200 кГц` (період перемикання `T = 5 мкс`).
- Максимальний розмах пульсацій вихідної напруги: `ΔVвих ≤ 5 мВ` (пік-пік).
- Допустима відносна пульсація струму вхідної котушки: `Δi_L1 / Iвх ≤ 25%`.
- Робочий температурний діапазон середовища: `−40 ... +85 °C`.

## 2. Покроковий розрахунок силового каскаду

### Крок 1: Розрахунок діапазону коефіцієнта заповнення D

Номінальний коефіцієнт заповнення при номіналі `Vвх = 24 В` та `|Vвих| = 15 В`:

```
|Vвих| / Vвх = D / (1 − D)
15 / 24 = 0.625
D = 0.625 / (1 + 0.625) = 0.625 / 1.625 ≈ 0.3846  (38.5%)
```

Перевіримо крайні значення робочого діапазону:
- При мінімальній вхідній напрузі `Vвх,min = 18 В`: `D_max = 15 / (18 + 15) = 15 / 33 ≈ 0.4545` (45.5%).
- При максимальній вхідній напрузі `Vвх,max = 30 В`: `D_min = 15 / (30 + 15) = 15 / 45 ≈ 0.3333` (33.3%).

### Крок 2: Середні та пульсаційні струми схеми

Номінальний середній вхідний струм:
```
Iвх = Iвих · D / (1 − D) = 1.5 А · 0.625 = 0.9375 А
```

Задана амплітуда пульсації вхідного струму (`25%`):
```
Δi_L1 = 0.25 · 0.9375 А ≈ 0.234 А
```

Пульсація струму вихідної індуктивності `L2`:
```
Δi_L2 = 0.25 · 1.5 А = 0.375 А
```

### Крок 3: Розрахунок роздільних індуктивностей L1 та L2

Вхідна індуктивність `L1`:
```
L1 = (Vвх · D) / (Δi_L1 · f_sw)
   = (24 В · 0.3846) / (0.234 А · 200 000 Гц)
   = 9.23 В·мкс / 46.8 кА/с
   ≈ 197 мкГн
```
Обираємо стандартний номінал силового дроселя **220 мкГн** зі струмом насичення не менше `I_sat ≥ Iвх + Δi_L1 / 2 = 0.94 + 0.12 = 1.06 А`.

Вихідна індуктивність `L2`:
```
L2 = (Vвх · D) / (Δi_L2 · f_sw)
   = (24 В · 0.3846) / (0.375 А · 200 000 Гц)
   = 9.23 В·мкс / 75.0 кА/с
   ≈ 123 мкГн
```
Обираємо стандартний номінал **150 мкГн** із струмом насичення `I_sat ≥ 1.5 + 0.19 = 1.69 А`.

### Крок 4: Розрахунок та вибір проміжного конденсатора C1

Середня напруга на проміжному конденсаторі:
```
V_C1 = Vвх + |Vвих| = 24 + 15 = 39 В
При Vвх,max = 30 В: V_C1,max = 30 + 15 = 45 В
```

Задамо допустиму пульсацію напруги `ΔV_C1 ≤ 1.5 В` (близько `3.8%` від `V_C1`):
```
C1 = (Iвих · D) / (ΔV_C1 · f_sw)
   = (1.5 А · 0.3846) / (1.5 В · 200 000 Гц)
   = 0.5769 / 300 000
   ≈ 1.92 мкФ
```

Діючий середньоквадратичний струм через `C1`:
```
I_C1,rms = √(D · (1 − D)) · (Iвх + Iвих)
         = √(0.3846 · 0.6154) · (0.9375 + 1.5)
         = √0.2367 · 2.4375
         = 0.4865 · 2.4375
         ≈ 1.186 А
```

#### Критичний нюанс вибору кераміки (DC-Bias Effect)

Багатошарові керамічні конденсатори класу діелектрика X7R/X5R втрачають від 40% до 70% своєї номінальної ємності при роботі під постійною напругою, близькою до номінальної. Для робочої напруги 45 В конденсатор на 50 В втратить понад половину ємності.

Тому обираємо конденсатори з номінальною напругою **100 В**. 
Щоб гарантувати ефективну ємність не менше 4.7 мкФ та низький ESR, формуємо батарею з **двох паралельних керамічних конденсаторів 4.7 мкФ / 100 В (розмір 1210, X7R)**. Їхній сумарний допустимий струм пульсацій перевищує 3.5 А RMS, що забезпечує триразовий запас за надійністю.

### Крок 5: Розрахунок вихідного фільтруючого конденсатора Свих

Для досягнення пульсації `ΔVвих ≤ 5 мВ` при роздільних котушках:
```
Свих = Δi_L2 / (8 · ΔVвих · f_sw)
     = 0.375 А / (8 · 0.005 В · 200 000 Гц)
     = 0.375 / 8000
     ≈ 46.9 мкФ
```

Встановлюємо комбінований фільтр: паралельно **два керамічні конденсатори по 22 мкФ / 25 В (X7R, 1206)** та один полімерний танталовий конденсатор **47 мкФ / 25 В з низьким ESR = 25 мОм**.

## 3. Проектування зв'язаної магнітної структури на спільному осерді

Замість двох окремих дроселів реалізуємо зв'язану індуктивність на базі феритового осердя типу EFD20 (матеріал N87 або N97, початкова проникність `μ_i ≈ 2200`).

Розрахунок обмоток для режиму нульових пульсацій вихідного струму (`Δi_L2 = 0`):
1. **Необхідний коефіцієнт зв'язку**: для осердя EFD20 із роздільним секційним каркасом типовий коефіцієнт магнітного зв'язку становить `k ≈ 0.85–0.90`.
2. **Умова занулення вихідних пульсацій**: `n = N2 / N1 = k`.
3. **Первинна обмотка**: обираємо кількість витків `N1 = 28 витків` дротом ПЕВ-2 діаметром 0.45 мм.
4. **Вторинна обмотка**: кількість витків `N2 = round(k · N1) = round(0.88 · 28) = 25 витків` дротом 0.55 мм.
5. **Повітряний зазор**: у центральному керні шліфується зазор товщиною `g ≈ 0.35 мм` для забезпечення струму насичення без входу осердя в нелінійний режим при сумарному постійному струмі `Iвх + Iвих = 0.94 + 1.5 = 2.44 А`.

При такому співвідношенні витків змінна ЕРС, трансформована у вторинну обмотку, з точністю до долей відсотка компенсує прикладену комутаційну напругу, знижуючи пульсацію струму на виході практично до нуля (`Δi_L2 < 5 мА`).

## 4. Тепловий баланс та аналіз втрат потужності

Загальні втрати потужності перетворювача розбиваються на шість складових:

1. **Статичні втрати у польовому транзисторі Q1 (Conduction Loss)**:
   При струмі каналу `I_Q1,rms = √(D) · (Iвх + Iвих) = √0.3846 · 2.44 А ≈ 1.51 А` та опорі каналу `R_DS(on) = 20 мОм` (при нагріві до 100 °C опір зростає до 32 мОм):
   ```
   P_cond,Q1 = I_Q1,rms² · R_DS(on) = (1.51 А)² · 0.032 Ом ≈ 0.073 Вт
   ```

2. **Динамічні комутаційні втрати транзистора Q1 (Switching Loss)**:
   При часі наростання і спаду `t_r = t_f = 12 нс`, напрузі блокування `V_block = 39 В` та піковому струмі `I_pk = 2.7 А`:
   ```
   P_sw,Q1 = V_block · I_pk · f_sw · (t_r + t_f) / 2
           = 39 В · 2.7 А · 200 000 Гц · 24 · 10⁻⁹ с / 2
           ≈ 0.253 Вт
   ```

3. **Втрати на перезаряд затвора MOSFET (Gate Charge Loss)**:
   При повному заряді затвора `Q_g = 15 нКл` та напрузі драйвера `V_gs = 10 В`:
   ```
   P_gate = Q_g · V_gs · f_sw = 15 · 10⁻⁹ Кл · 10 В · 200 000 Гц = 0.030 Вт
   ```

4. **Втрати у випрямному діоді Шотткі D1**:
   Середній струм діода `I_D1,avg = (1 − D) · (Iвх + Iвих) = 0.6154 · 2.44 А ≈ 1.50 А`. При прямому падінні `V_F = 0.42 В`:
   ```
   P_diode = V_F · I_D1,avg = 0.42 В · 1.50 А = 0.630 Вт
   ```

5. **Втрати у проміжному конденсаторі C1**:
   При діючому струмі `I_C1,rms = 1.186 А` та сумарному ESR батареї кераміки `r_esr ≈ 8 мОм`:
   ```
   P_C1 = I_C1,rms² · r_esr = (1.186 А)² · 0.008 Ом ≈ 0.011 Вт
   ```

6. **Втрати в магнітному осерді та обмотках дроселя**:
   - Омічні втрати в міді обмоток: `P_cu = I_L1,rms² · R_w1 + I_L2,rms² · R_w2 = (0.94)² · 0.08 + (1.5)² · 0.06 ≈ 0.071 + 0.135 = 0.206 Вт`.
   - Втрати на гістерезис і вихрові струми у фериті N87 за формулою Штейнметца: `P_core ≈ 0.095 Вт`.
   Сумарні втрати в магнетиці: `P_mag ≈ 0.301 Вт`.

### Загальний баланс ККД
Сумарні втрати становлять:
```
P_loss,total = 0.073 + 0.253 + 0.030 + 0.630 + 0.011 + 0.301 = 1.298 Вт
```
Розрахунковий ККД перетворювача:
```
η = Pвих / (Pвих + P_loss,total) = 22.5 / (22.5 + 1.298) = 22.5 / 23.798 ≈ 94.5%
```

## 5. Схема зворотного зв'язку для від'ємної вихідної напруги

Регулювання від'ємної напруги відносно спільної землі вимагає узгодження рівнів сигналу помилки. Найбільш надійним рішенням є використання прецизійного операційного підсилювача, що живиться від вхідної напруги `Vвх` та вихідної напруги `Vвих`.

Схема використовує прецизійне джерело опорної напруги (ІОН) +2.5 В (наприклад, LM4040 або ADR5040). Дільник зворотного зв'язку підключається між опорною напругою `+V_ref` та від'ємним виходом `Vвих`:

```
V_fb = (V_ref · R_fb2 + Vвих · R_fb1) / (R_fb1 + R_fb2)
```

Резистори підбираються так, щоб при номінальній напрузі `Vвих = −15 В` потенціал точки зворотного зв'язку `V_fb` дорівнював нулю вольтів (віртуальна земля інвертуючого входу ОП):

```
R_fb1 / R_fb2 = |Vвих| / V_ref = 15 В / 2.5 В = 6.0
Обираємо R_fb1 = 60.0 кОм (точність 0.1%) та R_fb2 = 10.0 кОм (0.1%).
```

Операційний підсилювач помилки охоплений ланцюгом частотної корекції Type-III, сигнал з виходу якого подається на модулятор ШІМ контролера.

## 6. Драйвер затвора та узгодження рівнів для синхронного ключа

При реалізації синхронної версії перетворювача Ćuk діод `D1` замінюють польовим транзистором `Q2`. Це вимагає спеціалізованої схеми керування затвором:

### Проблема змінного потенціалу витоку
Витік транзистора `Q2` підімкнений до вузла `SW2`, потенціал якого змінюється стрибком від `0 В` (коли `Q1` вимкнено) до `−(Vвх + |Vвих|) = −39 В` (коли `Q1` увімкнено). Звичайні драйвери нижнього плеча не здатні працювати з потенціалом витоку, що опускається на десятки вольтів нижче системної землі GND.

### Варіанти побудови драйвера
1. **Імпульсний трансформатор затвора (Gate Drive Transformer, GDT)**:
   Трансформаторна розв'язка передає диференційний сигнал керування безпосередньо між затвором та витоком `Q2`. Конденсатор розв'язки послідовно з первинною обмоткою забезпечує відновлення нульового середнього рівня напруги на сердечнику. Це надійний, недорогий метод без потреби у плаваючому джерелі живлення.
2. **Оптоізольований драйвер затвора (наприклад, FOD3180 або Si8233)**:
   Драйвер живиться від локального плаваючого джерела напруги +12 В, сформованого відносно вузла `SW2` за допомогою додаткової обмотки на дроселі або мініатюрного DC-DC ізольованого конвертера.
3. **Синхронний резистивний розряд**:
   Для запобігання паразитному відкриванню транзистора `Q2` через ємність Міллера `C_gd` при швидкому падінні напруги на вузлі `SW2` опір вимикання затвора `R_g,off` обирають мінімальним (`≤ 2.2 Ом`), встановлюючи зустрічний діод Шотткі паралельно резистору затвора `R_g,on`.

## 7. Трасування друкованої плати та правила компонування високочастотних контурів

Проектування 4-шарової друкованої плати для перетворювача Ćuk вимагає суворого дотримання правил топології високочастотних імпульсних джерел живлення:

### Розподіл шарів плати (Stackup)
- **Шар 1 (Top Layer)**: Силові компоненти (`Q1`, `D1`, `C1`, зв'язане осердо), силові вузли `SW1` та `SW2`.
- **Шар 2 (Inner Layer 1)**: Суцільний полігон землі (GND Plane) без розрізів, який слугує екраном і шляхом поворотного струму.
- **Шар 3 (Inner Layer 2)**: Шини живлення `Vвх`, шина опорної напруги `+2.5 В` та аналогові лінії керування.
- **Шар 4 (Bottom Layer)**: Контролер ШІМ, ланцюги частотної корекції Type-III, дільник зворотного зв'язку.

### Мінімізація паразитних індуктивностей контурів
Внутрішній комутаційний контур `Q1 − C1 − D1` є основним джерелом випромінювання електромагнітних завад. Паразитна індуктивність друкованої доріжки приблизно становить `1 нГн/мм`. При швидкості зміни струму `di/dt = 100 А/мкс` паразитна індуктивність усього в 10 нГн генерує амплітудний викид напруги `V_spike = L_par · (di/dt) = 10 · 10⁻⁹ Гн · 100 · 10⁶ А/с = 1.0 В`.

Правила розміщення:
1. Конденсатор `C1` встановлюється впритул до стоку `Q1` та катода `D1`. Їхнє з'єднання виконується широким мідним полігоном (не менше 3–4 мм) без використання перехідних отворів у силовому шляху.
2. Виводи витоку `Q1` та анода `D1` підключаються до шару GND кількома паралельними перехідними отворами (via stitch) прямо під контактними площадками.
3. Аналогова земля сигнальних кіл (AGND) з'єднується з силовою землею (PGND) в єдиній точці під вихідним конденсатором `Свих` для запобігання протіканню силових імпульсних струмів через чутливий вимірювальний дільник.

## 8. Вхідний ЕМС-фільтр для відповідності нормам CISPR 25 Class 5

Для запобігання проникненню залишкових високочастотних шумів у спільну мережу 24 В на вході встановлюється дволанковий LC-фільтр:
- Синфазний дросель (Common-Mode Choke) з індуктивністю `L_cm = 2.2 мГн` на тороїдальному осерді.
- Диференційний дросель `L_diff = 10 мкГн` зі струмом насичення 2 А.
- Конденсатори фільтрації: X2-конденсатор `C_x = 0.47 мкФ` (поліпропілен) між лініями живлення та Y-конденсатори `C_y = 2.2 нФ` від кожної лінії на корпус приладу (CHASSIS GND).

Такий фільтр забезпечує затухання кондуктивних завад не менше ніж на 45 дБ у діапазоні частот 150 кГц – 108 МГц, гарантуючи виконання вимог стандарту CISPR 25 Class 5 для автомобільної та промислової апаратури.

## 9. Комплексна система захисту від аварійних ситуацій

Надійний промисловий модуль вторинного живлення оснащується трирівневою системою захисту:

1. **Захист від перевантаження за струмом (Over-Current Protection, OCP)**:
   Вимірювальний шунт `R_sense = 20 мОм` встановлюється послідовно у вхідній шині після індуктивності `L1`. Сигнал спаду напруги підсилюється струмовим підсилювачем із синфазним фільтром низьких частот `R_f = 100 Ом, C_f = 1 нФ`. При перевищенні струму `Iвх > 1.8 А` компаратор контролера скидає поточний ШІМ-імпульс (потактне обмеження струму Cycle-by-Cycle).
2. **Захист від перенапруги на виході (Over-Voltage Protection, OVP)**:
   Якщо петля зворотного зв'язку обривається, вихідна напруга може піти в неконтрольований розгін. Швидкодіючий компаратор відстежує стан шини і при досягненні `|Vвих| > 17.5 В` відкриває шунтуючий тиристор (Crowbar), перепалюючи вхідний полімерний запобіжник (PTC Resettable Fuse) та захищаючи дорогі мікросхеми АЦП.
3. **Захист від зниженої вхідної напруги (Under-Voltage Lockout, UVLO)**:
   Резистивний дільник на вході блокує запуск ШІМ-генератора, якщо напруга живлення опускається нижче 16.5 В, усуваючи роботу перетворювача з аномально високими струмами при просіданні батареї.

## 10. Числова симуляція перехідних процесів у часовій області

Для верифікації динаміки, перевірки стійкості, оцінки перенапруг та демонстрації режиму зв'язаних котушок створено числову модель симулятора на базі методу інтегрування Рунге-Кутти 4-го порядку (RK4).

Програма розраховує динаміку миттєвих значень `i_L1(t)`, `i_L2(t)`, `v_C1(t)`, `v_Cout(t)` з урахуванням прямого падіння на діоді `V_F`, опору каналу транзистора `R_on`, матриці взаємоіндукції та стрибка навантаження.

/* simulation_cuk.c — Числова симуляція перетворювача Cuk методом RK4 */
#include <stdio.h>
#include <math.h>

typedef struct {
    double Vin;      /* Вхідна напруга, В */
    double R_load;   /* Опір навантаження, Ом */
    double f_sw;     /* Частота комутації, Гц */
    double D;        /* Коефіцієнт заповнення [0..1] */
    double L1;       /* Вхідна індуктивність, Гн */
    double L2;       /* Вихідна індуктивність, Гн */
    double k_mag;    /* Коефіцієнт магнітного зв'язку [0..1) */
    double C1;       /* Передавальний конденсатор, Ф */
    double Cout;     /* Вихідний конденсатор, Ф */
    double Ron;      /* Опір ключа Q1, Ом */
    double V_diode;  /* Пряме падіння на діоді D1, В */
} CukParams;

typedef struct {
    double i1;       /* Струм L1, А */
    double i2;       /* Струм L2, А */
    double v1;       /* Напруга C1, В */
    double v2;       /* Напруга Cout (|Vвих|), В */
} CukState;

/* Обчислення похідних вектора стану */
static void get_derivatives(const CukParams *p, const CukState *s, double t, CukState *deriv) {
    double T = 1.0 / p->f_sw;
    double t_phase = fmod(t, T);
    int q1_on = (t_phase < p->D * T);

    double v_L1_applied, v_L2_applied;
    double i_C1;

    if (q1_on) {
        /* Фаза 1: Q1 замкнений на землю, D1 закритий */
        v_L1_applied = p->Vin - s->i1 * p->Ron;
        v_L2_applied = -s->v1 + s->v2;
        i_C1 = -s->i2;
    } else {
        /* Фаза 2: Q1 розімкнений, D1 відкритий */
        v_L1_applied = p->Vin - s->v1 + p->V_diode;
        v_L2_applied = s->v2 - p->V_diode;
        i_C1 = s->i1;
    }

    /* Матриця магнітного зв'язку */
    double M = p->k_mag * sqrt(p->L1 * p->L2);
    double detL = p->L1 * p->L2 - M * M;

    deriv->i1 = (p->L2 * v_L1_applied - M * v_L2_applied) / detL;
    deriv->i2 = (p->L1 * v_L2_applied - M * v_L1_applied) / detL;
    deriv->v1 = i_C1 / p->C1;
    deriv->v2 = (s->i2 - s->v2 / p->R_load) / p->Cout;
}

/* Крок інтегрування Рунге-Кутти 4-го порядку */
static void rk4_step(const CukParams *p, CukState *s, double t, double dt) {
    CukState k1, k2, k3, k4, temp;

    get_derivatives(p, s, t, &k1);

    temp.i1 = s->i1 + 0.5 * dt * k1.i1;
    temp.i2 = s->i2 + 0.5 * dt * k1.i2;
    temp.v1 = s->v1 + 0.5 * dt * k1.v1;
    temp.v2 = s->v2 + 0.5 * dt * k1.v2;
    get_derivatives(p, &temp, t + 0.5 * dt, &k2);

    temp.i1 = s->i1 + 0.5 * dt * k2.i1;
    temp.i2 = s->i2 + 0.5 * dt * k2.i2;
    temp.v1 = s->v1 + 0.5 * dt * k2.v1;
    temp.v2 = s->v2 + 0.5 * dt * k2.v2;
    get_derivatives(p, &temp, t + 0.5 * dt, &k3);

    temp.i1 = s->i1 + dt * k3.i1;
    temp.i2 = s->i2 + dt * k3.i2;
    temp.v1 = s->v1 + dt * k3.v1;
    temp.v2 = s->v2 + dt * k3.v2;
    get_derivatives(p, &temp, t + dt, &k4);

    s->i1 += (dt / 6.0) * (k1.i1 + 2.0 * k2.i1 + 2.0 * k3.i1 + k4.i1);
    s->i2 += (dt / 6.0) * (k1.i2 + 2.0 * k2.i2 + 2.0 * k3.i2 + k4.i2);
    s->v1 += (dt / 6.0) * (k1.v1 + 2.0 * k2.v1 + 2.0 * k3.v1 + k4.v1);
    s->v2 += (dt / 6.0) * (k1.v2 + 2.0 * k2.v2 + 2.0 * k3.v2 + k4.v2);
}

int main(void) {
    CukParams cfg = {
        .Vin = 24.0, .R_load = 10.0, .f_sw = 200000.0, .D = 0.3846,
        .L1 = 220e-6, .L2 = 150e-6, .k_mag = 0.88,
        .C1 = 9.4e-6, .Cout = 91e-6,
        .Ron = 0.020, .V_diode = 0.45
    };

    CukState state = { .i1 = 0.0, .i2 = 0.0, .v1 = 0.0, .v2 = 0.0 };

    double dt = 2.5e-8;  /* Крок інтегрування 25 нс */
    double t_end = 0.005; /* 5 мс симуляції */

    printf("# Симуляція перетворювача Cuk (Зв'язані індуктивності k=%.2f)\n", cfg.k_mag);
    printf("# Час(мс)   I_in(A)    I_out(A)   V_C1(V)    V_out(V)\n");

    int print_decimation = 2000;
    int step_count = 0;

    for (double t = 0.0; t < t_end; t += dt, step_count++) {
        rk4_step(&cfg, &state, t, dt);

        if (step_count % print_decimation == 0) {
            printf("%8.3f   %8.4f   %8.4f   %8.3f   %8.3f\n",
                   t * 1000.0, state.i1, state.i2, state.v1, -state.v2);
        }
    }

    printf("\n# Усталений стан на t = %.2f мс:\n", t_end * 1000.0);
    printf("V_out = %.3f В (Ціль: -15.0 В)\n", -state.v2);
    printf("I_in  = %.3f А, I_out = %.3f А\n", state.i1, state.i2);
    printf("V_C1  = %.3f В (Теорія: %.3f В)\n", state.v1, cfg.Vin + state.v2);

    return 0;
}

// simulation_cuk.cpp — Об'єктно-орієнтована числова симуляція перетворювача Cuk
#include <iostream>
#include <iomanip>
#include <cmath>
#include <array>
#include <vector>
#include <span>

namespace power_sim {

struct ConverterConfig {
    double vin{24.0};        // Вхідна напруга, В
    double r_load{10.0};     // Опір навантаження, Ом
    double f_sw{200000.0};   // Частота перемикання, Гц
    double duty{0.3846};     // Шпаруватість [0..1]
    double l1{220e-6};       // Вхідна індуктивність, Гн
    double l2{150e-6};       // Вихідна індуктивність, Гн
    double k_coupling{0.88}; // Магнітний зв'язок обмоток
    double c1{9.4e-6};       // Ємнісний міст, Ф
    double c_out{91e-6};     // Вихідна ємність, Ф
    double r_on{0.020};      // Опір відкритого ключа, Ом
    double v_diode{0.45};    // Пряме падіння діода Шотткі, В
};

struct SystemState {
    double i_l1{0.0};        // Струм дроселя L1, А
    double i_l2{0.0};        // Струм дроселя L2, А
    double v_c1{0.0};        // Напруга на ємності C1, В
    double v_cout{0.0};      // Напруга на вихідній ємності, В
};

class CukSimulator {
public:
    explicit CukSimulator(ConverterConfig cfg) : cfg_(cfg) {
        double m = cfg_.k_coupling * std::sqrt(cfg_.l1 * cfg_.l2);
        det_l_ = cfg_.l1 * cfg_.l2 - m * m;
        mutual_l_ = m;
    }

    [[nodiscard]] SystemState step(const SystemState& current, double time, double dt) const {
        auto k1 = compute_derivatives(current, time);
        auto k2 = compute_derivatives(advance_state(current, k1, 0.5 * dt), time + 0.5 * dt);
        auto k3 = compute_derivatives(advance_state(current, k2, 0.5 * dt), time + 0.5 * dt);
        auto k4 = compute_derivatives(advance_state(current, k3, dt), time + dt);

        SystemState next;
        next.i_l1 = current.i_l1 + (dt / 6.0) * (k1.i_l1 + 2.0 * k2.i_l1 + 2.0 * k3.i_l1 + k4.i_l1);
        next.i_l2 = current.i_l2 + (dt / 6.0) * (k1.i_l2 + 2.0 * k2.i_l2 + 2.0 * k3.i_l2 + k4.i_l2);
        next.v_c1 = current.v_c1 + (dt / 6.0) * (k1.v_c1 + 2.0 * k2.v_c1 + 2.0 * k3.v_c1 + k4.v_c1);
        next.v_cout = current.v_cout + (dt / 6.0) * (k1.v_cout + 2.0 * k2.v_cout + 2.0 * k3.v_cout + k4.v_cout);
        return next;
    }

private:
    [[nodiscard]] SystemState compute_derivatives(const SystemState& s, double t) const {
        double period = 1.0 / cfg_.f_sw;
        double phase = std::fmod(t, period);
        bool switch_on = (phase < cfg_.duty * period);

        double v_l1_app = switch_on ? (cfg_.vin - s.i_l1 * cfg_.r_on) 
                                    : (cfg_.vin - s.v_c1 + cfg_.v_diode);
        double v_l2_app = switch_on ? (-s.v_c1 + s.v_cout) 
                                    : (s.v_cout - cfg_.v_diode);
        double i_c1_flow = switch_on ? (-s.i_l2) : (s.i_l1);

        SystemState deriv;
        deriv.i_l1 = (cfg_.l2 * v_l1_app - mutual_l_ * v_l2_app) / det_l_;
        deriv.i_l2 = (cfg_.l1 * v_l2_app - mutual_l_ * v_l1_app) / det_l_;
        deriv.v_c1 = i_c1_flow / cfg_.c1;
        deriv.v_cout = (s.i_l2 - s.v_cout / cfg_.r_load) / cfg_.c_out;
        return deriv;
    }

    [[nodiscard]] static SystemState advance_state(const SystemState& s, const SystemState& d, double factor) {
        return {
            s.i_l1 + d.i_l1 * factor,
            s.i_l2 + d.i_l2 * factor,
            s.v_c1 + d.v_c1 * factor,
            s.v_cout + d.v_cout * factor
        };
    }

    ConverterConfig cfg_;
    double det_l_{0.0};
    double mutual_l_{0.0};
};

} // namespace power_sim

int main() {
    using namespace power_sim;

    ConverterConfig cfg;
    CukSimulator sim(cfg);
    SystemState current_state;

    constexpr double dt = 2.5e-8; // 25 нс крок
    constexpr double t_end = 0.005; // 5 мс

    std::cout << std::fixed << std::setprecision(4);
    std::cout << "# Час (мс)    I_L1 (A)    I_L2 (A)    V_C1 (V)    V_out (V)\n";

    int step = 0;
    for (double t = 0.0; t < t_end; t += dt, ++step) {
        current_state = sim.step(current_state, t, dt);

        if (step % 2000 == 0) {
            std::cout << std::setw(8) << (t * 1000.0) << "    "
                      << std::setw(8) << current_state.i_l1 << "    "
                      << std::setw(8) << current_state.i_l2 << "    "
                      << std::setw(8) << current_state.v_c1 << "    "
                      << std::setw(8) << -current_state.v_cout << "\n";
        }
    }

    std::cout << "\n# Результати усталеного стану:\n";
    std::cout << "Вихідна напруга V_out = " << -current_state.v_cout << " В\n";
    std::cout << "Середня напруга V_C1  = " << current_state.v_c1 << " В\n";
    std::cout << "Вхідний струм   I_in  = " << current_state.i_l1 << " А\n";

    return 0;
}

## 11. Лабораторна методика налагодження та тестування

При запуску прототипу перетворювача Ćuk у лабораторії рекомендується дотримуватися такої послідовності вимірювань:

1. **Перевірка форми напруги на комутаційних вузлах**:
   Підключіть осцилографічний щуп із короткою пружинкою заземлення безпосередньо до стоку транзистора `Q1`. Перевірте відсутність високочастотного дзвону при вимиканні транзистора. Амплітуда викиду не повинна перевищувати 80% від максимальної напруги `V_DS` обраного польового транзистора. При наявності дзвону скоригуйте номінали снібера або затворного резистора `R_gate`.

2. **Вимірювання пульсацій струму струмовим пробником**:
   Використовуючи високочастотні струмові кліщі (наприклад, Tektronix TCP0030A), виміряйте струми `i_L1` та `i_L2`. У схемі зі зв'язаними індуктивностями плавно підганяйте немагнітну прокладку зазору в осерді, спостерігаючи за зникненням змінної складової у вторинній обмотці до досягнення ідеальної горизонтальної прямої на екрані осцилографа.

3. **Зняття логарифмічних амплітудно-фазових характеристик (Bode Plot)**:
   За допомогою аналізатора частотного відгуку (FRA) та трансформатора інжекції сигналу розірвіть петлю зворотного зв'язку у верхньому плечі дільника. Переконайтеся, що частота одиничного зрізу `f_c` лежить щонайменше у 3–4 рази нижче частоти RHP-нуля, а запас за фазою становить не менше 50° при крайніх значеннях напруги живлення та струму навантаження.

4. **Тепловізійний контроль**:
   Після 30 хвилин роботи на максимальному навантаженні 1.5 А перевірте температуру поверхні керамічних конденсаторів `C1` та магнітного осердя. Їхній перегрів відносно навколишнього середовища не повинен перевищувати +35 °C.

5. **Тестування динамічного відгуку на накид навантаження (Load Transient Step)**:
   За допомогою електронного навантаження сформуйте стрибок вихідного струму `0.3 А → 1.5 А` зі швидкістю наростання `1 А/мкс`. Осцилографом зафіксуйте максимальне динамічне просідання вихідної напруги `ΔV_dip` та час відновлення стабілізації `t_settle`. Завдяки компенсатору Type-III перерегулювання не повинно перевищувати 3% від номіналу (450 мВ), а час перехідного процесу — не більше 150 мкс.
