# 🧮 Розрахунок інтегралу Джоуля та теплового вибуху провідників під струмом КЗ

Коли струм короткого замикання сягає сотень і тисяч амперів, процес нагрівання провідників переходить в адіабатичний режим (гр. *adiábatos* — неперехідний, без теплообміну з довкіллям). Тривалість імпульсу аварійного струму становить від кількох мікросекунд до кількох мілісекунд. За такий короткий проміжок часу теплова енергія, що виділяється всередині металу за законом Джоуля-Ленца, фізично не встигає віддатися в навколишнє повітря, текстоліт або ізоляцію шляхом теплопровідності чи конвекції. Уся виділена енергія йде виключно на нагрівання та фазовий перехід (плавлення й випаровування) самого провідника.

Мірою цього теплового удару є інтеграл Джоуля `I²t` (питома наскрізна енергія). Нижче наведено суворе математичне виведення зв'язку між величиною `I²t`, геометрією провідника, його питомим опором, теплоємністю та часом до розплавлення за рівнянням Ондердонка.

## Адіабатичне рівняння теплового балансу

Розгляньмо однорідний металевий провідник перерізом `S` (м²) і довжиною `l` (м). Нехай через нього протікає струм `i(t)`.

Опір ділянки провідника за температури `T`:

```
R(T) = ρ(T) · l / S
```

де `ρ(T)` — питомий електричний опір металу (Ом·м).

За нескінченно малий інтервал часу `dt` струм виділяє в об'ємі провідника елементарну кількість теплоти `dQ`:

```
dQ = i(t)² · R(T) · dt
= i(t)² · (ρ(T) · l / S) · dt       [підстановка опору R(T)]
```

В адіабатичному наближенні ця теплота викликає зростання температури провідника на `dT`:

```
dQ = m · c(T) · dT
= (D · S · l) · c(T) · dT           [маса m = густина D · об'єм (S · l)]
```

де `D` — густина металу (кг/м³), `c(T)` — питома масова теплоємність (Дж/(кг·К)).

Прирівняємо обидва вирази для `dQ`:

```
i(t)² · (ρ(T) · l / S) · dt = D · S · l · c(T) · dT
```

Скоротимо довжину `l` з обох боків рівняння та розділимо змінні часу `t` і температури `T`:

```
i(t)² · dt = S² · (D · c(T) / ρ(T)) · dT
```

Інтегруючи ліву частину від `t = 0` до моменту розплавлення `t_melt`, а праву частину — від початкової температури `T_0` до температури плавлення `T_melt`:

```
∫[0..t_melt] i(t)² dt = S² · ∫[T_0..T_melt] (D · c(T) / ρ(T)) dT
```

Величина в лівій частині називається **інтегралом Джоуля розплавлення** (англ. *melting Joule integral*):

```
I²t_melt = ∫[0..t_melt] i(t)² dt
```

Властивість правої частини: інтеграл від матеріальних констант `K_mat = ∫[T_0..T_melt] (D · c(T) / ρ(T)) dT` залежить виключно від фізико-хімічних властивостей металу (міді, нікелю, срібла чи алюмінію). Отже:

```
I²t_melt = S² · K_mat
```

Це фундаментальний висновок: **гранична теплова стійкість будь-якого провідника пропорційна квадрату його площі поперечного перерізу**. Збільшення товщини чи ширини шини вдвічі підвищує її стійкість до струму КЗ у 4 рази.

## Температурна залежність опору та формула Ондердонка

Питомий опір металів лінійно зростає з температурою в широкому діапазоні:

```
ρ(T) = ρ_0 · (1 + α_0 · (T - T_0))
```

де `ρ_0` — питомий опір за базової температури `T_0 = 20 °C` (293.15 K), `α_0` — температурний коефіцієнт електричного опору (1/°C або 1/K).

Припустивши густину `D` і питому теплоємність `c` усереднено постійними в діапазоні від кімнатної температури до точки плавлення, підставимо лінійну модель `ρ(T)` під інтеграл:

```
K_mat = D · c · ∫[T_0..T_melt] (1 / (ρ_0 · (1 + α_0 · (T - T_0)))) dT
```

Виконаємо аналітичне інтегрування:

```
K_mat
= (D · c / (ρ_0 · α_0)) · ∫[T_0..T_melt] (d(1 + α_0 · (T - T_0)) / (1 + α_0 · (T - T_0)))  [заміна змінної під диференціалом]
= (D · c / (ρ_0 · α_0)) · ln((1 + α_0 · (T_melt - T_0)) / (1 + α_0 · (T_0 - T_0)))          [інтеграл dU/U = ln(U)]
= (D · c / (ρ_0 · α_0)) · ln(1 + α_0 · (T_melt - T_0))                                      [знаменник ln(1) = 0]
```

Отриманий вираз є аналітичною основою рівняння Ондердонка (англ. *Onderdonk's equation*), що пов'язує граничний струм розплавлення, площу провідника та час дії:

```
I²t_melt = S² · (D · c / (ρ_0 · α_0)) · ln(1 + α_0 · (T_melt - T_0))
```

Для врахування прихованої теплоти плавлення `λ_melt` (фазового переходу тверде тіло → рідина), до інтегралу додається енергія перетворення:

```
ΔQ_phase = m · λ_melt = D · S · l · λ_melt
```

яка збільшує результуючий коефіцієнт `K_mat` на величину `(D · λ_melt) / ρ(T_melt)`.

## Розрахунок часу вибуху та розплавлення для типових збірок

### 1. Доріжка друкованої плати BMS (PCB Trace)

Нехай силова доріжка на платі BMS має стандартну товщину фольги 1 oz (35 мкм = 0.035 мм) і ширину `w = 4 мм`.

Площа поперечного перерізу:

```
S = 4 мм × 0.035 мм = 0.14 мм²
```

Граничний інтеграл плавлення мідної доріжки:

```
I²t_melt
= S² · K_Cu                         [базова формула адіабатичного нагріву]
= (0.14 мм²)² · 83 500 А²·с/мм⁴     [підстановка перерізу доріжки та константи міді]
= 0.0196 · 83 500                   [піднесення до квадрата]
≈ 1636 А²·с                         [підсумок інтегралу розплавлення]
```

Якщо струм короткого замикання пакета становить `I_sc = 1500 А`, час до розриву та випаровування доріжки складає:

```
t_melt
= I²t_melt / I_sc²                  [час за постійного струму t = I²t / I²]
= 1636 / (1500)²                    [підстановка струму КЗ]
= 1636 / 2 250 000                  [обчислення знаменника]
≈ 0.000727 с = 727 мкс              [результат у мікросекундах]
```

Менш ніж за 1 мілісекунду тонка мідна доріжка перетворюється на вибуховий спалах, відриваючи маску та обвуглюючи склотекстоліт FR-4.

### 2. Нікелева міжкоміркова шина (0.15 мм × 8 мм)

У збірках 18650/21700 комірки з'єднують стрічкою товщиною 0.15 мм та шириною 8 мм.

Площа перерізу:

```
S = 8 мм × 0.15 мм = 1.20 мм²
```

Для чистого нікелю (Ni 200):

```
I²t_melt(Ni) = (1.20)² · 22 400 = 1.44 · 22 400 ≈ 32 256 А²·с
```

Для нікельованої сталі:

```
I²t_melt(Steel) = (1.20)² · 8900 = 1.44 · 8900 ≈ 12 816 А²·с
```

За аварійного струму `I_sc = 1000 А`:

Час розплавлення сталевої стрічки:

```
t_melt(Steel) = 12 816 / 1 000 000 ≈ 12.8 мс
```

Час розплавлення чистого нікелю:

```
t_melt(Ni) = 32 256 / 1 000 000 ≈ 32.3 мс
```

Упродовж цих 12–30 мс стрічка нагрівається до білого розжарення, проплавляє нікелеві холдери та пластикову термоусадку акумуляторів, що прилягають до плюсового полюса комірки, викликаючи бічний пробій корпусу комірки.

## Селективність запобіжника: критерій повного розриву кола

Щоб плавкий запобіжник надійно захистив доріжки плати та ключі BMS від термічного вибуху, його **повний інтеграл відключення** `I²t_clear` (сума енергії розплавлення перешийка `I²t_melt` та енергії горіння дуги `I²t_arc`) повинен задовольняти строгу нерівність:

```
I²t_clear(Fuse) < I²t_damage(BMS / PCB / Cable)
```

де:
- `I²t_melt(Fuse)` — інтеграл Джоуля, необхідний для досягнення температури плавлення срібного перешийка запобіжника;
- `I²t_arc(Fuse)` — додаткова теплова енергія, що виділяється під час горіння дуги в кварцовому піску до повного згасання плазми:

```
I²t_arc = ∫[t_melt..t_extinguish] i(t)² dt
```

Для швидкодіючих DC-запобіжників класу aR типове співвідношення між енергією плавлення та енергією дуги:

```
I²t_clear ≈ (2.0 ... 3.5) · I²t_melt
```

Якщо для захисту плати з `I²t_damage = 1636 А²·с` обрати запобіжник із `I²t_melt = 300 А²·с` та `I²t_clear = 850 А²·с`, запобіжник гарантовано розірве коло за час `t_clear = 850 / 1500² ≈ 377 мкс`, залишивши запас стійкості доріжок плати у понад 48 %.

## Апроксимація інтегралу Джоуля для реальних форм хвилі струму

У практичних інженерних розрахунках форма імпульсу струму короткого замикання не є ідеально прямокутною. Вона визначається перехідним процесом в RLC-контурі. Для різних типових форм хвилі струму з амплітудним значенням `I_pk` та тривалістю `t_pulse` інтеграл Джоуля обчислюється через коефіцієнт форми `k_shape`:

```
I²t = k_shape · I_pk² · t_pulse
```

1. **Прямокутний імпульс (постійний струм на плато):**

```
I²t
= ∫[0..t_p] I_pk² dt                 [інтегрування константи]
= I_pk² · t_p                       [коефіцієнт форми k_shape = 1.0]
```

2. **Трикутний імпульс (наростання та швидке лінійне переривання):**

```
I²t
= ∫[0..t_p] (I_pk · t / t_p)² dt     [лінійне зростання i(t) = I_pk · t / t_p]
= (I_pk² / t_p²) · (t_p³ / 3)       [інтегрування t²]
= (1 / 3) · I_pk² · t_p             [коефіцієнт форми k_shape = 1/3 ≈ 0.333]
```

3. **Експоненціальний наростаючий імпульс (RL-контур):**
Для струму `i(t) = I_max · (1 - e^(-t / τ))` за тривалості імпульсу `t_p ≈ 3 · τ`:

```
I²t
= I_max² · ∫[0..t_p] (1 - 2·e^(-t/τ) + e^(-2t/τ)) dt  [розкриття квадрата різниці]
= I_max² · (t_p - 1.5 · τ)                            [інтегрування експонент]
```

Застосування відповідного коефіцієнта форми дозволяє точно розрахувати еквівалентний тепловий імпульс для реальних осцилограм струму, знятих під час тестування батарейних блоків.

## Багатошарові друковані плати та межа адіабатичності

У силових платах BMS часто використовують внутрішні шари фольги (шари L2, L3 у 4-шарових платах). Для внутрішніх шарів тепловідведення в епоксидний діелектрик відбувається з обох боків (зверху і знизу), проте через низьку теплопровідність FR-4 (`λ_FR4 ≈ 0.3 Вт/(м·К)`) адіабатичне наближення залишається строго справедливим для всіх часів `t < 5 мс`.

Глибина проникнення теплової хвилі в діелектрик за час `t` оцінюється як:

```
x_th = √(2 · a_FR4 · t)
```

де `a_FR4 = λ / (D · c) ≈ 1.5 · 10⁻⁷ м²/с` — коефіцієнт температуропровідності склотекстоліту.

Для імпульсу тривалістю `t = 1 мс` глибина прогріву становить лише `x_th ≈ √(2 · 1.5·10⁻⁷ · 10⁻³) ≈ 17 мкм`. Це підтверджує, що під час відсічки короткого замикання вся енергія залишається зосередженою безпосередньо в об'ємі металу, що й спричиняє вибухове випаровування доріжок за рівнянням Ондердонка.
