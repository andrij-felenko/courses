# 🧮 Розрахунок активного розряду вихідних ємностей шин живлення

Під час вимкнення багатоканальної системи живлення недостатньо просто зняти сигнал дозволу з силових перетворювачів. Накопичений у вихідних конденсаторах електричний заряд утримує напругу на шині. Якщо навантаження знеструмлене або перейшло у високоімпедансний стан спокою, спад напруги відбувається виключно за рахунок повільного струму саморозряду та витоків, що може тривати від сотень мілісекунд до десятків секунд. За цей час виникає небезпечна асиметрія потенціалів між доменами ядра та периферії, здатна спричинити зворотний струм або паразитний тиристорний защіп. Вузол активного розряду (*active output discharge*) примусово підключає паралельно до вихідної ємності низькоомний резистор або генератор стабільного струму, гарантуючи контрольований спад напруги до безпечного рівня за визначений часовий інтервал.

### Фізична модель резистивного розрядного контуру

Розглянемо вихідну лінію перетворювача після переведення силових ключів у закритий стан. Еквівалентна схема розряду складається з еквівалентної ємності вихідного фільтра `C_out` (сума керамічних, танталових та полімерних конденсаторів на платі та всередині корпусу навантаження), початкової напруги `V₀` та повного опору кола розряду `R_dis`, який складається з опору відкритого каналу розрядного транзистора `R_ds_on` та послідовного струмообмежувального резистора `R_ext`.

Струм розряду `i(t)` визначається швидкістю зміни заряду на обкладках конденсатора за законом:

```
i(t) = -C_out · (dV / dt)
```

За другим законом Кірхгофа для замкненого контуру з резистором `R_dis`:

```
V(t) - i(t) · R_dis = 0
```

Підставляючи вираз для струму, отримуємо класичне однорідне диференціальне рівняння першого порядку:

```
C_out · (dV(t) / dt) + V(t) / R_dis = 0                [рівняння балансу струмів контуру]
dV(t) / dt + V(t) / (R_dis · C_out) = 0                [ділення на C_out, зведення до стандартного вигляду]
```

Розв'язок цього рівняння за початкової умови `V(0) = V₀` має форму спадної експоненти:

```
V(t) = V₀ · exp(-t / τ)
```

де стала часу контуру розряду `τ` (грецька літера тау) визначається добутком еквівалентного опору та ємності:

```
τ = R_dis · C_out
```

### Розрахунок часу розряду до безпечного порогу

У цифрових інтегральних схемах безпечним порогом залишкової напруги `V_safe`, за якого гарантовано виключається відкриття внутрішніх кремнієвих p-n переходів і паразитних тиристорів, вважається напруга, що не перевищує 0.1–0.2 В (або 5–10% від номінального значення шини).

Для визначення часу `t_dis`, необхідного для зниження напруги від `V₀` до `V_safe`, прологарифмуємо рівняння експоненційного розряду:

```
V_safe / V₀ = exp(-t_dis / τ)                          [ділення обох частин на V₀]
ln(V_safe / V₀) = -t_dis / τ                           [натуральний логарифм обох частин]
-ln(V₀ / V_safe) = -t_dis / τ                          [властивість логарифма: ln(a/b) = -ln(b/a)]
t_dis = τ · ln(V₀ / V_safe)                           [множення обох частин на -τ]
t_dis = R_dis · C_out · ln(V₀ / V_safe)                [підстановка виразу сталої часу τ = R·C]
```

Якщо безпечний рівень становить `k = V_safe / V₀` (наприклад, `k = 0.05` для 5%), коефіцієнт логарифма є сталою величиною:

```
ln(1 / 0.10) = ln(10) ≈ 2.303                         [спад до 10% вимагає 2.3 сталих часу]
ln(1 / 0.05) = ln(20) ≈ 2.996                         [спад до 5% вимагає 3.0 сталих часу]
ln(1 / 0.01) = ln(100) ≈ 4.605                        [спад до 1% вимагає 4.6 сталих часу]
```

### Порівняння: лінійний резистивний розряд проти розряду стабільним струмом

У сучасних інтегральних схемах стабілізаторів застосовують два принципово різні типи вузлів розряду:
1. **Пасивний резистивний ключ (Resistive Discharge Switch):** польовий транзистор NMOS із фіксованим послідовним резистором.
2. **Активне джерело стабільного струму (Constant Current Sink):** транзистор у режимі насичення з контуром зворотного зв'язку, що підтримує постійний струм `I_dis`.

Розглянемо фізику та математику розряду стабільним струмом:

```
i(t) = I_dis = const
dV(t) / dt = -I_dis / C_out                            [швидкість зміни напруги є константою]
V(t) = V₀ - (I_dis / C_out) · t                        [інтегрування за часом від 0 до t]
```

Час досягнення безпечного порогу для розряду стабільним струмом визначається лінійним рівнянням:

```
t_dis_cc = C_out · (V₀ - V_safe) / I_dis
```

**Порівняльний аналіз динаміки:**
- При резистивному розряді струм експоненційно падає разом із напругою (`i(t) = V(t) / R_dis`). Коли напруга на шині 3.3 В падає до 0.4 В, струм розряду зменшується у 8 разів, через що «хвіст» розряду нижче 0.5 В затягується в часі.
- При розряді стабільним струмом швидкість спаду напруги залишається строго постійною аж до моменту, поки напруга не опуститься нижче напруги насичення розрядного транзистора (близько 50–100 мВ). Це дозволяє досягти безпечного порогу значно швидше за меншого початкового пікового струму.

```
V(t) [В]
3.3 ┬──────┐
    │      │\  (Резистивний: крутий старт, але повільний експоненційний хвіст)
    │      │ \
1.8 ┼──────┼──\───────┐
    │      │   \      │\
0.8 ┼──────┼────\─────┼─\──────┐  (Стабільний струм: строго лінійна рампа)
    │      │     \    │  \     │\
0.2 ┴──────┴──────┴───┴───┴────┴─\─────► t [мс]
   t=0   (Вимкнення I/O → Aux → Core)
```

### Піковий струм, енергія та імпульсний нагрів розрядного ключа

У момент замикання резистивного розрядного ключа `t = 0` напруга на конденсаторі максимальна, тому через розрядний резистор і канал MOSFET протікає піковий струм:

```
I_peak = V₀ / R_dis
```

Цей струм не повинен перевищувати гранично допустимий імпульсний струм розрядного ключа `I_max_pulse`, який наводиться в технічній документації на інтегрований стабілізатор або зовнішній польовий транзистор.

Енергія `E`, накопичена в електричному полі вихідного конденсатора, повністю перетворюється на тепло в опорі `R_dis`:

```
E = ∫[0→∞] (V(t)² / R_dis) dt
  = (V₀² / R_dis) · ∫[0→∞] exp(-2·t / (R_dis · C_out)) dt      [підстановка виразу V(t)]
  = (V₀² / R_dis) · [ - (R_dis · C_out / 2) · exp(-2·t / τ) ]  [первісна показникової функції]
  = (V₀² / R_dis) · (0 - ( - R_dis · C_out / 2 ))              [підстановка границь від 0 до ∞]
  = (1 / 2) · C_out · V₀²                                      [кінцевий вираз енергії конденсатора]
```

Зверніть увагу: загальна виділена енергія `E` **абсолютно не залежить** від величини опору `R_dis` — вона залежить лише від ємності та початкової напруги. Величина опору `R_dis` визначає лише **швидкість** виділення цієї енергії (тобто миттєву пікову потужність `P_peak = V₀² / R_dis`).

#### Імпульсний тепловий розрахунок перехідного імпедансу `Z_th`

При розряді великих ємностей (понад 1000–5000 мкФ) кристал розрядного транзистора відчуває короткочасний адіабатичний тепловий удар. Тепло не встигає передатися на друковану плату за час імпульсу (менш як 10–50 мс), тому температура кристала зростає пропорційно перехідному тепловому імпедансу `Z_th(t_pulse)`:

```
ΔT_j = P_avg · Z_th(t_pulse)
```

Середня потужність за час розряду `t_dis ≈ 3·τ`:

```
P_avg = E / t_dis = (0.5 · C_out · V₀²) / (3 · R_dis · C_out)
      = V₀² / (6 · R_dis)
```

Максимальна температура переходу `T_j_max` не повинна перевищувати граничного значення кристала (зазвичай +150 °C):

```
T_j_max = T_ambient + ΔT_j ≤ 150 °C
```

### Крайові випадки: паразитна індуктивність та RLC-дзвінок

У реальній схемі друковані провідники між вихідним конденсатором, розрядним транзистором та полігоном землі мають власну паразитну індуктивність `L_trace` (орієнтовно 1–2 нГн на кожен міліметр довжини доріжки).

Разом з вихідною ємністю `C_out` та опором розряду `R_dis` утворюється послідовний коливальний контур другого порядку. Характеристичний опір контуру `Z₀` становить:

```
Z₀ = √(L_trace / C_out)
```

Якщо для досягнення екстремально швидкого розряду опір `R_dis` обрати занадто малим, добротність контуру зросте, і процес розряду з аперіодичного перейде в коливальний. Умова аперіодичного розряду без коливань вимагає:

```
R_dis ≥ 2 · √(L_trace / C_out)                         [умова відсутності резонансного перерегулювання]
```

Якщо ця умова порушується, напруга на шині після перетину нульового рівня здійснить від'ємний викид (*undershoot*):

```
V_min < 0 В
```

Якщо від'ємний викид перевищить поріг -0.3...-0.5 В, відчиняться нижні захисні діоди ESD відносно землі, викликаючи чергову хвилю паразитного інжекційного струму в підкладку мікросхеми. Тому вибір опору `R_dis` завжди є інженерним компромісом між швидкістю розряду та демпфуванням паразитних індуктивностей.

### Числовий приклад комплексного проєктування для FPGA

Розглянемо практичний інженерний розрахунок системи розряду для обчислювального модуля з FPGA Xilinx UltraScale+, що містить три домени живлення:
1. **Шина ядра `V_CORE`:** 0.85 В, ємність `C_core = 2200 мкФ`, струм навантаження під час вимкнення падає до 10 мА.
2. **Шина допоміжної логіки `V_AUX`:** 1.8 В, ємність `C_aux = 470 мкФ`, струм після зупинки PLL — 5 мА.
3. **Шина вводу-виводу `V_IO`:** 3.3 В, ємність `C_io = 680 мкФ`, струм після відключення периферії — 0.5 мА.

**Системні часові вимоги за даташитом:**
- Шина 3.3 В повинна впасти нижче 0.2 В за час `t_io_target ≤ 20 мс`.
- Шина 1.8 В повинна впасти нижче 0.2 В за час `t_aux_target ≤ 20 мс`.
- Шина ядра 0.85 В повинна утримуватися вище 0.3 В протягом усього часу розряду шини 3.3 В, після чого розрядитися нижче 0.1 В за час `t_core_final ≤ 50 мс`.

**Крок 1. Розрахунок розрядного кола для шини 3.3 В (`V_IO`).**

Заданий поріг безпеки `V_safe = 0.2 В`. Знайдемо необхідну сталу часу `τ_io`:

```
ln(V₀ / V_safe) = ln(3.3 / 0.2) = ln(16.5) ≈ 2.803   [логарифм кратності зниження напруги]
τ_io = t_io_target / ln(V₀ / V_safe)                  [формула необхідної сталої часу]
     = 0.020 с / 2.803                                [підстановка цільового часу 20 мс]
     ≈ 7.135 · 10⁻³ с = 7.135 мс                      [розрахункова стала часу]
```

Звідси визначаємо максимальний допустимий опір кола розряду `R_dis_io`:

```
R_dis_io = τ_io / C_io                                [формула опору з виразу τ = R · C]
         = 7.135 · 10⁻³ с / (680 · 10⁻⁶ Ф)            [підстановка сталої часу та ємності 680 мкФ]
         = 7.135 / 0.68                               [спрощення чисельника та знаменника]
         ≈ 10.49 Ом                                   [максимальний опір кола розряду]
```

Обираємо номінал зовнішнього резистора `R_ext = 8.2 Ом` (ряд E24). При опорі відкритого каналу розрядного MOSFET `R_ds_on = 1.0 Ом` повний опір становить:

```
R_dis_total = 8.2 Ом + 1.0 Ом = 9.2 Ом
```

Перевіримо фактичний час розряду з обраним номіналом:

```
τ_actual_io = 9.2 Ом · 680 · 10⁻⁶ Ф = 6.256 мс        [фактична стала часу контуру IO]
t_dis_actual = 6.256 мс · 2.803                       [підстановка у формулу часу розряду]
             ≈ 17.54 мс                               [у межах системної вимоги ≤ 20 мс]
```

Перевірка пікових струмів та теплових режимів для шини 3.3 В:

```
I_peak_io = 3.3 В / 9.2 Ом ≈ 0.359 А (359 мА)         [піковий струм розряду]
P_peak_io = 3.3 В · 0.359 А ≈ 1.185 Вт                [пікова миттєва потужність на старті]
E_dis_io = 0.5 · 680 · 10⁻⁶ Ф · (3.3 В)²              [енергія електричного поля конденсатора]
         = 0.5 · 680 · 10⁻⁶ · 10.89                   [піднесення напруги до квадрата]
         ≈ 3.70 · 10⁻³ Дж = 3.70 мДж                  [сумарна виділена теплова енергія]
```

Резистор типорозміру 0805 з імпульсною стійкістю 10 Дж легко витримує імпульс 3.70 мДж без деградації резистивного шару.

**Крок 2. Розрахунок розрядного кола для шини 1.8 В (`V_AUX`).**

```
ln(V₀ / V_safe) = ln(1.8 / 0.2) = ln(9.0) ≈ 2.197     [логарифм кратності для Aux]
τ_aux = 0.020 с / 2.197 ≈ 9.103 мс                    [необхідна стала часу]
R_dis_aux = 9.103 · 10⁻³ с / (470 · 10⁻⁶ Ф)           [опір кола розряду Aux]
          = 9.103 / 0.47                              [обчислення відношення]
          ≈ 19.37 Ом                                  [максимально допустимий опір]
```

Обираємо стандартний номінал резистора `R_ext = 15 Ом`. З урахуванням опору ключа `R_ds_on = 1.0 Ом` повний опір `R_dis_total = 16.0 Ом`.

```
τ_actual_aux = 16.0 Ом · 470 · 10⁻⁶ Ф = 7.52 мс       [фактична стала часу Aux]
t_dis_aux = 7.52 мс · 2.197 ≈ 16.52 мс                [час спаду до 0.2 В]
```

**Крок 3. Розрахунок параметрів утримання та розряду ядра 0.85 В (`V_CORE`).**

Щоб шина ядра гарантовано не просіла нижче 0.3 В під час розряду шини 3.3 В (який триває 17.54 мс), перетворювач ядра утримується увімкненим протягом перших 18 мс процедури LIFO-вимкнення.

Після вимкнення перетворювача ядра в момент `t = 18 мс` активується розрядний резистор ядра `R_dis_core = 10 Ом`:

```
τ_core = 10 Ом · 2200 · 10⁻⁶ Ф = 22.0 мс              [стала часу розряду ядра]
ln(V₀ / V_safe) = ln(0.85 / 0.1) = ln(8.5) ≈ 2.140    [логарифм для спаду до 0.1 В]
t_dis_core = 22.0 мс · 2.140                          [час повного розряду ядра після відключення]
           ≈ 47.08 мс                                 [у межах вимоги ≤ 50 мс]
```

Повний час знеструмлення системи від моменту подачі команди вимкнення до повного нульового заряду на всіх лініях становить:

```
t_total_shutdown = 18 мс + 47.08 мс = 65.08 мс
```

Такий детальний інженерний розрахунок гарантує, що в жодний момент часу напруга периферійного домену не перевищить напругу ядра, струми розряду залишаться в межах безпечної робочої області ключів, а перехідні процеси будуть строго аперіодичними без паразитних коливань та викидів.
