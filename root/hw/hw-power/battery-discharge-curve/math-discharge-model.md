# 🧮 Математична модель розрядної кривої та поляризаційних перенапруг

Форма розрядної кривої хімічного джерела струму визначається складною взаємодією термодинамічних потенціалів реагентів та кінетичних втрат, що виникають під час проходження електричного струму. Напруга на клемах елемента `V(t)` у будь-який момент часу розряду є різницею між потенціалом розімкненого кола `V_ocv` та трьома основними складовими падіння напруги: омічним опором, активаційною поляризацією та концентраційною перенапругою.

Повний математичний аналіз формалізму розрядної кривої є основою для проектування акумуляторних осередків, оптимізації пористості електродів та розробки цифрових моделей джерел живлення.

---

### Загальне рівняння потенціалу під навантаженням

Аналітичний вираз для клемної напруги `V(t)` при струмі розряду `I(t)` описується фундаментальним балансом потенціалів:

```
V(t) = V_ocv(Q) - ΔV_Ohm - η_act - η_conc
```

де:
- `V_ocv(Q)` — рівноважна електрорушійна сила (потенціал розімкненого кола), яка є функцією екстрагованого заряду `Q`;
- `ΔV_Ohm` — падіння напруги на внутрішньому омічному опорі елемента;
- `η_act` — активаційна перенапруга, зумовлена енергетичним бар'єром переносу заряду крізь межу розділу «електрод — електроліт»;
- `η_conc` — концентраційна (масопереносна) перенапруга, зумовлена градієнтом концентрації іонів-носіїв у приповерхневому шарі електрода.

Розглянемо покрокове фізико-математичне виведення та структуру кожної з цих чотирьох складових.

---

### 1. Рівноважна ЕРС та термодинаміка Нернста

Потенціал розімкненого кола `V_ocv` безпосередньо зв'язаний зі зміною вільної енергії Гіббса `ΔG` валової електрохімічної реакції:

```
ΔG = -z · F · V_ocv
```

де:
- `z` — валентність носія заряду (число електронів, що беруть участь у молі елементарної реакції);
- `F = 96485.33 Кл/моль` — стала Фарадея;
- `ΔG` — зміна ізобарно-ізотермічного потенціалу реакції.

При зміні відносних молярних часток або активностей реагентів у процесі розряду потенціал `V_ocv` змінюється згідно з класичним рівнянням Нернста:

```
V_ocv = V⁰ + (R · T / (z · F)) · ln( a_ox / a_red )
```

де `V⁰` — стандартний електродний потенціал, `R = 8.314 Дж/(моль·К)` — універсальна газова стала, `T` — абсолютна температура у кельвінах, `a_ox` та `a_red` — хімічні активності окисненої та відновленої форм активної речовини на електродах.

Для інтеркаляційних матеріалів (наприклад, у літій-іонних акумуляторах, де іони літію вбудовуються у матрицю графиту або кобальтату), відношення активностей виражають через ступінь інтеркаляції `x` (частка заповнених вакансій у кристалічній ґратці, від `x = 0` до `x = 1`). Модель регулярного розчину дає розширене рівняння для потенціалу електрода:

```
V_ocv(x) = E⁰ - (R · T / F) · ln( x / (1 - x) ) - (Ω / F) · (1 - 2 · x)
```

де `Ω` — параметр взаємодії між сусідніми іонами у кристалічній ґратці. 

Другий доданок `(R · T / F) · ln(x / (1 - x))` описує конфігураційну ентропію змішування іонів та вакансій, а третій доданок `(Ω / F) · (1 - 2·x)` відповідає за міжатомне відштовхування чи притягання. Саме ця ентропійно-енергетична сума формує пласку або похилу конфігурацію термодинамічного розрядного плато.

### 2. Омічні втрати та структура внутрішнього опору

Омічне просідання напруги `ΔV_Ohm` виникає безинерційно в момент виклику струму `I` і описується класичним законом Ома:

```
ΔV_Ohm = I · R_i(Q, T)
```

Внутрішній опір елемента `R_i` являє собою послідовно-паралельну суму трьох окремих фізичних опорів:

```
R_i = R_electrolyte + R_active_material + R_contact
```

Покрокова деталізація структурних внесків:
1. **Іонний опір електроліту (`R_electrolyte`):** Описується питомим опором розчину `ρ_el`, товщиною сепаратора `L` та його звивистістю (tortuosity) `τ`:
   ```
   R_electrolyte = ρ_el · (L · τ / (A · ε))
   ```
   де `A` — площа електрода, `ε` — пористість сепаратора.

2. **Електронний опір активної маси (`R_active_material`):** Зумовлений провідністю графітового чи оксидного порошку та добавками сажі.

3. **Перехідний опір контактів (`R_contact`):** Опір межі між пористим електродом та металевим струмознімачем (мідною або алюмінієвою фольгою).

Під час розряду `R_i` зростає наприкінці циклу через виснаження вільного електроліту в порах та погіршення контактів між гранулами при зміні об'єму кристалічних ґраток.

### 3. Активаційна поляризація та кінетика Батлера — Фольмера

Електрохімічний перехід електрона через подвійний електричний шар вимагає подолання енергетичного бар'єра активації. Зв'язок між густиною струму `j = I / A` та активаційною перенапругою `η_act` описується рівнянням Батлера — Фольмера:

```
j = j₀ · [ exp( (α · z · F / (R · T)) · η_act ) - exp( -( (1 - α) · z · F / (R · T) ) · η_act ) ]
```

де:
- `j₀` — густина струму рівноважного обміну (Exchange Current Density);
- `α` — симетричний коефіцієнт переносу заряду (зазвичай `α ≈ 0.5`).

Для великих струмів розряду (`η_act > 0.05 В`) зворотною реакцією анодного окиснення можна знехтувати. Рівняння спрощується до емпіричного закону Тафеля:

```
η_act = (R · T / (α · z · F)) · ln( j / j₀ )
```

Аналітичне розв'язання рівняння Батлера — Фольмера відносно `η_act` для всього діапазону струмів через обернену гіперболічну синусну функцію виглядає наступним чином:

```
η_act = (2 · R · T / (z · F)) · arcsinh( I / (2 · A · j₀) )
```

Активаційна поляризація виявляється у швидкому початковому зниженні напруги в перші секунди після пуску струму, поки подвійний електричний шар досягає стаціонарного потенціалу.

### 4. Концентраційна поляризація та обмеження масопереносу

У міру розряджання іони-носії споживаються на реакційних центрах електрода. Нові іони мусять транспортуватися з об'єму електроліту за рахунок дифузії, яка описується другим законом Фіка:

```
∂C / ∂t = D · (∂²C / ∂x²)
```

де `D` — коефіцієнт дифузії іонів у розчиннику або твердій фазі.

Існує граничний дифузійний струм `I_lim`, при якому концентрація іонів на поверхні електрода падає до нуля (`C_surface → 0`):

```
I_lim = (z · F · A · D · C_bulk) / δ
```

де `C_bulk` — початкова об'ємна концентрація іонів, `δ` — товщина дифузійного примежового шару Нернста.

Вираз для концентраційної перенапруги `η_conc` виводиться з різниці Нернстівських потенціалів між об'ємом розчину та поверхнею електрода:

```
η_conc = - (R · T / (z · F)) · ln( C_surface / C_bulk )
       = - (R · T / (z · F)) · ln( 1 - I / I_lim )
```

Коли вилучений заряд `Q` наближається до повної ємності елемента `Q_max`, локальна концентрація `C_surface` прямує до нуля, відношення `I / I_lim` прямує до одиниці, а логарифм `ln(1 - I / I_lim)` прямує до мінус нескінченності.

Саме ця логарифмічна сингулярність математично формує круте кінцеве коліно розрядної кривої: напруга стрімко валиться вниз до критичного значення відсічки `V_cut`.

### 5. Повна динамічна модель Шеперда та ефект Пешара

Для інженерного моделювання в системах автоматизованого проектування (SPICE, MATLAB / Simulink) широкого вжитку набула модель Шеперда (Shepherd Battery Model), яка об'єднує омічні, дифузійні та термодинамічні втрати в єдине алгебраїчне рівняння:

```
V(t) = E₀ - K · (Q_max / (Q_max - Q(t))) · I - I · R_i + A_exp · exp( -B_exp · Q(t) )
```

Покрокова структура розшифровки параметрів Шеперда:

```
[Початковий експоненційний вигин]
V_exp(Q) = A_exp · exp(-B_exp · Q)           [згасання початкового зарядного поля]

[Дифузійна ампліфікація опору]
R_eff(Q) = K · (Q_max / (Q_max - Q))         [зростання опору при виснаженні реагентів]

[Підсумковий клемний потенціал]
V(t) = E₀ - I · R_eff(Q) - I · R_i + V_exp(Q)
```

Розрахунок фактичної ємності, екстрагованої з батареї при довільному профілі струму `I(t)`, з урахуванням ефекту Пешара виконується шляхом інтегрування еквівалентного виснаження:

```
Q_peukert = ∫₀ᵀ [ I(t) / I_nom ]ᵏ dt
```

де `k` — показник Пешара (`1.05–1.30`). Коли значення інтеграла `Q_peukert` досягає номінальної ємності `C_nom`, клемна напруга досягає відсічки `V_cut`, і розряд припиняється.
