# 📋 Регістрова карта bq2419x: адреса, поля й кодування уставок

Зарядний чип класу bq2419x (тут — конкретний bq24192) з боку програми — це **банк однобайтових регістрів за I2C-адресою `0x6B`**. У ньому немає команди «заряджай на 1.5 ампера»: ви не наказуєте, а записуєте в поля закодовані **межі**, у яких залізу дозволено працювати. Ця довідка — карта тих регістрів і формули, за якими число «1.5 А» чи «4.2 В» перетворюється на біти, готові до запису. Перевірено за даташитом TI SLUSAW5B (bq24190/bq24192).

## Адреса й доступ

- **Адреса на шині — `0x6B`, семибітна.** API, що хочуть восьмибітну (як STM32 HAL), потребують `0x6B << 1 = 0xD6`.
- **Одинадцять регістрів, REG00…REG0A.** REG00–REG07 доступні на **запис і читання**, REG08–REG0A — **лише на читання** (статус, фолти, паспорт чипа).
- **Доступ до однієї комірки — звичайна [реєстрова транзакція I2C](topic:com-devices/i2c-transaction):** щоб записати — шлеш адресу пристрою, тоді номер регістра, тоді байт; щоб прочитати — шлеш адресу й номер регістра, робиш повторний старт і забираєш байт.

## Карта регістрів

Драйверу для повного циклу заряду досить сімох регістрів на запис і трьох на читання:

```
REG  назва                        поля, що нас цікавлять
00   Input Source Control         EN_HIZ[7] · VINDPM[6:3] · IINLIM[2:0]  ← ліміт входу
01   Power-On Configuration       REG_RST[7] · WD_RST[6] · CHG_CONFIG[5:4] · SYS_MIN[3:1]
02   Charge Current Control       ICHG[7:2]  ← струм заряду
03   Pre-Charge/Term Current      IPRECHG[7:4] · ITERM[3:0]  ← поріг термінації
04   Charge Voltage Control       VREG[7:2] · BATLOWV[1] · VRECHG[0]  ← напруга заряду
05   Charge Term/Timer Control    EN_TERM[7] · WATCHDOG[5:4] · EN_TIMER[3] · CHG_TIMER[2:1]
08   System Status (RO)           VBUS_STAT[7:6] · CHRG_STAT[5:4] · DPM_STAT[3] · PG · THERM · VSYS
09   Fault (RO)                   WATCHDOG_FAULT[7] · BOOST · CHRG_FAULT[5:4] · BAT · NTC[2:0]
0A   Vendor/Part/Rev (RO)         PN[5:3]  ← паспорт чипа
```

## Кодування трьох уставок заряду

Три уставки кодуються по-різному, і саме тут роблять помилки на ампер. Скрізь округлення таке, щоб фактичне значення **не перевищило** заявленого.

**Вхідний ліміт (IINLIM, REG00[2:0]) — таблиця, не формула.** Три біти вибирають одне з восьми фіксованих значень:

```
код   000  001  010  011  100   101   110   111
мА    100  150  500  900  1200  1500  2000  3000
```

Проміжних немає. Правило вибору жорстке: беремо найбільший код, чий струм **не перевищує** того, що джерело дозволило. Джерело дає 900 мА — код 011 (900 мА). Дає 1000 мА — усе одно 011 (900), бо наступний щабель 1200 вже забагато, а перевищити вхідний ліміт означає посадити джерело.

**Струм заряду (ICHG, REG02[7:2]) — лінійний.** Шість бітів, крок 64 мА, зсув 512 мА:

```
Iзар = 512 + код·64  (мА),  код = 0…63,  діапазон 512…4544 мА
```

**Приклад — цільові 1500 мА.**

```
код   = (1500 − 512) / 64 = 15.4  →  округляємо ВНИЗ до 15
Iфакт = 512 + 15·64 = 1472 мА
```

Округлюємо саме вниз, не до найближчого: 1472 мА безпечніше за 1536 мА, бо не перевищує заявленого.

**Напруга заряду (VREG, REG04[7:2]) — теж лінійна, але тут округлення критичне.** Шість бітів, крок 16 мВ, зсув 3504 мВ:

```
Uзар = 3504 + код·16  (мВ),  діапазон 3504…4400 мВ
```

**Приклад — цільові 4200 мВ (стандартний потолок Li-ion).**

```
код   = (4200 − 3504) / 16 = 43.5  →  ВНИЗ до 43
Uфакт = 3504 + 43·16 = 4192 мВ
```

Чому вниз, а не 44 (що дало б 4208 мВ)? Бо 4208 мВ — це вже **вище** за 4.2 В, а для літію кожні зайві мілівольти в потолку — це прискорене старіння й ризик. 4192 мВ — безпечний недобір; 4208 — перебір. Округлення напруги заряду завжди донизу. (Прикро, але типове значення чипа після скидання — саме 4.208 В, код 44; тому VREG варто виставляти явно, а не покладатися на типове.)

**Поріг термінації (ITERM, REG03[3:0]) — лінійний.** Чотири біти, крок 128 мА, зсув 128 мА: `Iтерм = 128 + код·128` (мА), діапазон 128…2048 мА.

## Заголовок `bq2419x_regs.h`: адреси, маски й кодувальники

Зведімо адреси регістрів, маски полів і чотири кодувальники «мА/мВ → біти» в один заголовок, на який спиратиметься драйвер. Таблична функція — для вхідного ліміту, три формульні — для струму, напруги й порога; кожна округлює так, щоб не перевищити цілі.

```c
#ifndef BQ2419X_REGS_H
#define BQ2419X_REGS_H
#include <stdint.h>

#define BQ_ADDR   0x6B          /* 7-бітна адреса bq2419x на шині */

/* Іменовані регістри (bq2419x, за даташитом SLUSAW5B) */
#define BQ_REG00  0x00
#define BQ_REG01  0x01
#define BQ_REG02  0x02
#define BQ_REG03  0x03
#define BQ_REG04  0x04
#define BQ_REG05  0x05
#define BQ_REG08  0x08
#define BQ_REG09  0x09
#define BQ_REG0A  0x0A

/* Маски й іменовані значення полів */
#define REG00_IINLIM_MASK      0x07
#define REG01_REG_RST          (1u << 7)
#define REG01_WD_RST           (1u << 6)
#define REG01_CHG_CONFIG_MASK  0x30
#define REG01_CHG_ENABLE       0x10        /* CHG_CONFIG = 01 */
#define REG02_ICHG_MASK        0xFC        /* біти [7:2] */
#define REG03_ITERM_MASK       0x0F        /* біти [3:0] */
#define REG04_VREG_MASK        0xFC        /* біти [7:2] */
#define REG05_EN_TERM          (1u << 7)

/* IINLIM: найбільший табличний щабель, що НЕ перевищує ma */
static inline uint8_t iinlim_code(uint16_t ma)
{
    static const uint16_t tbl[8] = {100, 150, 500, 900, 1200, 1500, 2000, 3000};
    uint8_t code = 0;
    for (uint8_t i = 0; i < 8; i++)
        if (tbl[i] <= ma) code = i;
    return code;                            /* 000…111 */
}

/* ICHG: зсув 512 мА, крок 64 мА, поле [7:2]; округлення вниз */
static inline uint8_t ichg_reg(uint16_t ma)
{
    if (ma < 512)  ma = 512;
    if (ma > 4544) ma = 4544;
    return (uint8_t)(((ma - 512) / 64) << 2);
}

/* VREG: зсув 3504 мВ, крок 16 мВ, поле [7:2]; округлення вниз (не вище потолку) */
static inline uint8_t vreg_reg(uint16_t mv)
{
    if (mv < 3504) mv = 3504;
    if (mv > 4400) mv = 4400;
    return (uint8_t)(((mv - 3504) / 16) << 2);
}

/* ITERM: зсув 128 мА, крок 128 мА, поле [3:0] */
static inline uint8_t iterm_code(uint16_t ma)
{
    if (ma < 128)  ma = 128;
    if (ma > 2048) ma = 2048;
    return (uint8_t)((ma - 128) / 128);
}

#endif /* BQ2419X_REGS_H */
```

Зверніть увагу: `ichg_reg` і `vreg_reg` уже вертають значення, **зсунуте на місце поля** (`<< 2`), тож його накладають прямо під маскою `REG02_ICHG_MASK` / `REG04_VREG_MASK`. `iinlim_code` та `iterm_code` вертають «сирий» код у молодших бітах — поле IINLIM і так займає [2:0], а ITERM — [3:0], зсув не потрібен.

Як цю карту вживає живий драйвер — послідовність підняття, годування watchdog, читання статусу й фолтів — показано в [робочому прикладі драйвера](topic:hw-power/charger-ic-architecture/proj-bq2419x-driver.md).
