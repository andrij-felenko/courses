# ⚙️ Програмна реалізація цифрового регулятора напруги (Digital AVR) для синхронного генератора

У сучасних автономних генераторних установках, гібридних транспортних засобах і стаціонарних дизель-електростанціях класичні аналогові регулятори напруги повністю витіснені цифровими мікроконтролерними модулями dAVR (Digital Automatic Voltage Regulator). Цифрове керування усуває температурний дрейф аналогових компараторів, дозволяє реалізувати прецизійну адаптивну термокомпенсацію акумуляторної батареї, алгоритм обмеження динамічного відгуку навантаження (LRC) для запобігання перевантаженню первинного двигуна на холостому ходу, а також надшвидкий апаратний та програмний захист від руйнівного імпульсу скидання навантаження (Load Dump).

У цьому проєкті розглянуто архітектуру апаратно-програмного комплексу та наведено повну промислову реалізацію алгоритму цифрового регулятора для вбудованих 32-бітних мікроконтролерів (архітектури ARM Cortex-M0+/M4, STM32, NXP S32K або RISC-V) мовами C (C99/C11) та сучасним типізованим C++ (C++20).

```
  ┌────────────────────────────────────────────────────────────────────────┐
  │                         АЛГОРИТМІЧНИЙ ЦИКЛ dAVR                        │
  │                                                                        │
  │   [ АЦП ]  ──> [ Фільтр IIR ] ──> [ Термокомпенсація ] ──> [ ПІД ]     │
  │  (V_bat,T)      (фільтрація        (корекція V_target      (розрахунок │
  │                 пульсацій 6f)          за NTC)              ШІМ Duty)  │
  │                                                                │       │
  │   [ Аварійний ] <──────────────────────────────────────────────┘       │
  │   [ Load Dump ] ──> (якщо V > 16.5 В або dV/dt > 50 В/мс ──> Duty = 0) │
  │                                                                │       │
  │   [ Драйвер ]  <───────────────────────────────────────────────┘       │
  │   (ШІМ 300 Гц на затвор силового MOSFET обмотки ротора)                │
  └────────────────────────────────────────────────────────────────────────┘
```

### 1. Апаратна топологія та контур комутації збудження

Електронний блок dAVR інтегрується безпосередньо в задню кришку генератора поруч зі щіткотримачем і підключається до силової шини постійного струму `B+`, виводу фази статора для детектування частоти обертання та обмотки збудження ротора.

```
                  Шина живлення B+ (12..14.4 В)
                       │
                       ├─────────────────────┐
                       │                     │
                   ┌───┴───┐             ┌───┴───┐
                   │ Діод  │ Зворотний   │ Обмотка│
                   │ Шотткі│ демпфер     │ ротора │ L_f = 250 мГн
                   └───┬───┘ (Freewheel) │ L_field│ R_f = 3.0 Ом
                       │                 └───┬───┘
                       ├─────────────────────┘
                       │
                 ┌─────┴─────┐
                 │ N-MOSFET  │ Силовий Low-side ключ
                 │ (R_ds_on  │ (керується ШІМ 300 Гц)
                 │  = 5 мОм) │
                 └─────┬─────┘
                       │
                      GND (Корпус генератора)
```

Силовий каскад комутації індуктивного навантаження побудований за схемою нижнього ключа (Low-Side Switch) на N-канальному польовому транзисторі MOSFET з логічним рівнем керування затвором або за схемою верхнього ключа (High-Side Switch) зі спеціалізованим драйвером затвора, що містить внутрішню зарядову помпу. 

Для вибору силового MOSFET ключовими параметрами є опір відкритого каналу `R_ds_on ≤ 5..8 мОм` для мінімізації тепловиділення без зовнішнього радіатора та максимальна напруга «стік–витік» `V_ds_max ≥ 55..60 В` для забезпечення безпечного запасу при лавинному зрізі імпульсів перенапруги.

Паралельно обмотці ротора обов'язково встановлюється силовий діод швидкого відновлення (Fast Recovery) або потужний бар'єрний діод Шотткі у зворотному включенні (Freewheeling / Flyback Diode). Індуктивність обмотки збудження автомобільного генератора становить `L_f = 150..350 мГн` при активному опорі `R_f = 2.5..4.0 Ом`. 

Під час кожного такту вимкнення MOSFET-транзистора (при частоті ШІМ `f_pwm = 200..400 Гц`) струм індуктивності не може перерватися миттєво. Зворотний діод підхоплює струм розряду, забезпечуючи його плавне циркулювання по колу «котушка–діод», що гарантує безперервність магнітного потоку ротора та виключає виникнення пробійного високовольтного викиду на стоці комутуючого транзистора.

### 2. Математична модель алгоритмічних вузлів

Програмний цикл dAVR виконується періодично з фіксованим кроком дискретизації `dt = 1 мс` (частота виклику 1000 Гц) у прериванні апаратного таймера або за подією завершення перетворення багатоканального АЦП. Алгоритм містить послідовні математичні обчислювальні ланки:

#### 2.1. Цифрова фільтрація випрямленої напруги

Вихідна напруга шестидіодного випрямляча містить високочастотні пульсації амплітудою до 1.0–1.5 В із частотою `f_rip = 6 · (p · n / 60)`. При швидкості обертання ротора від 1200 до 12 000 об/хв частота пульсацій змінюється від 720 Гц до 7.2 кГц.

Якщо подати нефільтрований сигнал на вхід диференціальної та пропорційної ланок ПІД-регулятора, це призведе до хаотичної модуляції шпаруватості ШІМ на частоті пульсацій (джиттеру). Для очищення сигналу застосовують експоненційний фільтр низьких частот першого порядку (IIR):

```
v_filt[k] = v_filt[k−1] + α · (v_raw[k] − v_filt[k−1])
```

де коефіцієнт згладжування `α = 0.125` (`1/8`, що обчислюється швидким бітовим зсувом `>> 3`) формує частоту зрізу близько 150 Гц. Фільтр повністю пригнічує гармоніки моста Ларіонова, зберігаючи достатню швидкодію для відпрацювання динамічних просідань напруги за час менше 10–15 мс.

#### 2.2. Адаптивна термокомпенсація робочої точки

Олив'яно-кислотні (WET, AGM, GEL) та літій-залізо-фосфатні (LiFePO4) акумуляторні батареї змінюють внутрішній опір та електрохімічний потенціал залежно від температури. При низьких температурах електроліт гусне, швидкість дифузії іонів падає, і для повноцінного заряду потрібна підвищена напруга (до 14.8–15.0 В при −20 °C). У спеку (+50 °C під капотом), навпаки, висока напруга викликає інтенсивний електроліз води (википання акумулятора).

Контролер вимірює температуру вбудованого NTC-терморезистора `T_meas` і коригує цільову уставку напруги `V_target`:

```
V_target(T) = V_base + k_t · (T_meas − 25.0)
```

де базова уставка `V_base = 14.4 В`, а температурний коефіцієнт становить `k_t = −0.015 В/°C` (−15 мВ на кожен градус відхилення від стандартних +25 °C). Розраховане значення обмежується безпечним коридором `[13.2 В .. 15.2 В]`.

#### 2.3. ПІД-регулятор зі захистом від насичення інтегратора (Anti-Windup)

Похибка регулювання обчислюється як різниця між цільовою термокомпенсованою напругою та відфільтрованою напругою на шині:

```
e[k] = V_target − v_filt[k]
```

Вихідна величина ПІД-алгоритму формується сумою трьох складових:

1. **Пропорційна ланка:** `P[k] = K_p · e[k]` забезпечує негайну реакцію на зміну навантаження.
2. **Диференціальна ланка:** `D[k] = K_d · (e[k] − e[k−1]) / dt` демпфує швидкі коливання напруги.
3. **Інтегральна ланка:** `I[k] = I[k−1] + K_i · e[k] · dt` ліквідує статичну похибку до абсолютного нуля.

Коли генератор працює на низьких обертах під максимальним навантаженням, вихідна напруга фізично не може досягти 14.4 В навіть при повністю відкритому транзисторі (`Duty = 100%`). У цей момент класичний інтегратор продовжує накопичувати помилку, досягаючи величезних значень (явище Integrator Windup). Коли навантаження раптово вимикається, перенасичений інтегратор утримує транзистор відкритим ще сотні мілісекунд, викликаючи небезпечний стрибок напруги до 18–20 В.

Для запобігання цьому явищу реалізовано механізм умовного інтегрування (Clamping Anti-Windup): накопичення суми `I[k]` дозволяється лише тоді, коли сумарна вихідна шпаруватість лежить у допустимих фізичних межах `[0.0 .. 1.0]`.

#### 2.4. Контроль динамічного відгуку навантаження (LRC — Load Response Control)

При включенні потужних споживачів (наприклад, електричного догрівача салону потужністю 1.5 кВт) генератор починає споживати від колінчастого вала гальмівний механічний момент до 15–20 Н·м. Якщо цей момент прикласти миттєво під час роботи двигуна на холостому ходу (700 об/хв), двигун може заглохнути або різко втратити оберти.

Функція LRC обмежує максимальну швидкість наростання шпаруватості ШІМ `Slew_Rate_Max` (зазвичай не більше +25% шпаруватості за секунду):

```
Duty[k] = min(Duty_calculated, Duty[k−1] + Slew_Rate_Max · dt)
```

Це змушує генератор приймати навантаження плавно протягом 2–3 секунд, надаючи блоку керування двигуном (ECU) достатньо часу для відкриття дросельної заслінки або збільшення циклової подачі палива.

#### 2.5. Фазове детектування обертів та режим «сліпого старту» (Blind Start)

Перед запуском двигуна (при включенні замка запалювання) генератор не обертається. Якщо подати повний струм збудження 4–5 А на нерухомий ротор, це призведе до непотрібного розряду акумулятора та перегріву котушки ротора за відсутності примусового охолодження крильчаткою.

Цифровий регулятор вимірює напругу та частоту на виводі однієї з фаз статора (вивід `W` або фазний тахо-сигнал):

- **Стан спокою (`RPM = 0`):** контролер підтримує мінімальний черговий струм збудження (шпаруватість ШІМ `Duty = 4..6%`, струм близько 0.2 А), необхідний для створення початкового магнітного поля підхоплення.
- **Прокручування стартером (`0 < RPM < 400`):** режим «сліпого пуску» (Blind Time). Регулятор утримує мінімальне збудження, щоб генератор не створював додаткового механічного опору стартеру, який крутить холодний двигун.
- **Вихід на холостий хід (`RPM > 500`):** детектується стала генерація змінного сигналу на фазі. Регулятор плавно активує замкнений контур ПІД-стабілізації, переводячи генератор у повноцінний робочий режим.

#### 2.6. Надшвидкий захист від аварійного Load Dump

При випадковому від'єднанні силової клеми акумулятора напруга генератора різко зростає через затримку спаду магнітного потоку масивного ротора. Алгоритм dAVR безперервно відстежує два критерії аварії:

1. Абсолютне перевищення напруги: `v_raw ≥ 16.5 В`.
2. Градієнт наростання напруги: `(v_raw[k] − v_raw[k−1]) / dt ≥ 50 В/мс`.

При спрацьовуванні будь-якого з критеріїв контролер за один цикл скидає шпаруватість ШІМ строго в `0.0%`, скидає накопичений інтегратор у нуль і блокує роботу ключа до повного повернення напруги в безпечну зону.

```c
/* ============================================================================
 * digital_avr.h / digital_avr.c — Цифровий регулятор напруги генератора (C99)
 * ============================================================================ */
#ifndef DIGITAL_AVR_H
#define DIGITAL_AVR_H

#include <stdint.h>
#include <stdbool.h>

#ifdef __cplusplus
extern "C" {
#endif

typedef struct {
    float kp;               /* Пропорційний коефіцієнт регулятора */
    float ki;               /* Інтегральний коефіцієнт регулятора */
    float kd;               /* Диференціальний коефіцієнт регулятора */
    float i_term;           /* Накопичена інтегральна сума */
    float prev_error;       /* Попередня похибка для розрахунку D-складової */
    float duty_min;         /* Мінімальна шпаруватість ШІМ (0.0) */
    float duty_max;         /* Максимальна шпаруватість ШІМ (1.0) */
    float v_target_base;    /* Базова цільова напруга при 25°C (14.4 В) */
    float temp_coeff;       /* Температурний коефіцієнт (-0.015 В/°C) */
    float v_filt;           /* Відфільтрована вихідна напруга генератора */
    float prev_v_raw;       /* Попереднє сире значення напруги для dV/dt */
    float current_duty;     /* Поточна фактична шпаруватість ШІМ ротора */
    float lrc_slew_rate;    /* Максимальна швидкість наростання ШІМ (1/с) */
    bool  load_dump_active; /* Прапорець аварійного режиму Load Dump */
} avr_controller_t;

void avr_init(avr_controller_t *avr, float v_base, float kp, float ki, float kd);
float avr_update(avr_controller_t *avr, float v_raw, float temp_c, float dt);
void avr_reset_faults(avr_controller_t *avr);

#ifdef __cplusplus
}
#endif

#endif /* DIGITAL_AVR_H */

/* ── Реалізація digital_avr.c ──────────────────────────────────────────────── */
#include <math.h>

#define IIR_ALPHA           0.125f   /* Коефіцієнт згладжування IIR фільтра */
#define LOAD_DUMP_VOLTAGE   16.50f   /* Поріг відключення при Load Dump (В) */
#define LOAD_DUMP_SLOPE     50.0f    /* Поріг швидкості наростання (В/мс) */

void avr_init(avr_controller_t *avr, float v_base, float kp, float ki, float kd)
{
    if (!avr) return;
    avr->kp = kp;
    avr->ki = ki;
    avr->kd = kd;
    avr->i_term = 0.0f;
    avr->prev_error = 0.0f;
    avr->duty_min = 0.0f;
    avr->duty_max = 1.0f;
    avr->v_target_base = v_base;
    avr->temp_coeff = -0.015f;
    avr->v_filt = v_base;
    avr->prev_v_raw = v_base;
    avr->current_duty = 0.0f;
    avr->lrc_slew_rate = 0.25f;      /* 25% шпаруватості за 1 секунду */
    avr->load_dump_active = false;
}

float avr_update(avr_controller_t *avr, float v_raw, float temp_c, float dt)
{
    if (!avr || dt <= 0.0f) return 0.0f;

    /* 1. Фільтрація вихідної напруги від високочастотних пульсацій */
    avr->v_filt += IIR_ALPHA * (v_raw - avr->v_filt);

    /* 2. Детектування аварійного скидання навантаження (Load Dump) */
    float dv_dt = (v_raw - avr->prev_v_raw) / (dt * 1000.0f);
    avr->prev_v_raw = v_raw;

    if (v_raw >= LOAD_DUMP_VOLTAGE || dv_dt >= LOAD_DUMP_SLOPE) {
        avr->load_dump_active = true;
        avr->current_duty = 0.0f;
        avr->i_term = 0.0f;
        return 0.0f;
    }

    if (avr->load_dump_active) {
        /* Чекаємо повного повернення напруги в безпечний робочий діапазон */
        if (v_raw <= avr->v_target_base) {
            avr->load_dump_active = false;
        } else {
            return 0.0f;
        }
    }

    /* 3. Термокомпенсація цільової уставки напруги */
    float v_target = avr->v_target_base + avr->temp_coeff * (temp_c - 25.0f);
    if (v_target < 13.2f) v_target = 13.2f;
    if (v_target > 15.2f) v_target = 15.2f;

    /* 4. Обчислення похибки регулювання */
    float error = v_target - avr->v_filt;

    /* 5. Пропорційна та диференціальна складові */
    float p_term = avr->kp * error;
    float d_term = avr->kd * (error - avr->prev_error) / dt;
    avr->prev_error = error;

    /* 6. Інтегрування з захистом від насичення (Anti-Windup) */
    float tentative_duty = p_term + avr->i_term + (avr->ki * error * dt) + d_term;
    if (tentative_duty >= avr->duty_min && tentative_duty <= avr->duty_max) {
        avr->i_term += avr->ki * error * dt;
    }

    float calculated_duty = p_term + avr->i_term + d_term;
    if (calculated_duty > avr->duty_max) calculated_duty = avr->duty_max;
    if (calculated_duty < avr->duty_min) calculated_duty = avr->duty_min;

    /* 7. Контроль відгуку навантаження (LRC Slew-Rate Limiter) */
    float max_step = avr->lrc_slew_rate * dt;
    if (calculated_duty > avr->current_duty + max_step) {
        avr->current_duty += max_step;
    } else {
        avr->current_duty = calculated_duty;
    }

    return avr->current_duty;
}

void avr_reset_faults(avr_controller_t *avr)
{
    if (avr) {
        avr->load_dump_active = false;
        avr->i_term = 0.0f;
    }
}
```

```cpp
// ============================================================================
// digital_avr.hpp — Об'єктно-орієнтований цифровий регулятор напруги (C++20)
// ============================================================================
#pragma once

#include <algorithm>
#include <concepts>
#include <expected>
#include <numbers>
#include <span>

namespace electronics::power {

enum class AvrStatus : uint8_t {
    NormalOperation,
    LoadDumpTripped,
    SensorFault,
    ThermalWarning
};

struct AvrConfig {
    float target_voltage_base{14.4f};
    float temp_coefficient{-0.015f};
    float kp{0.35f};
    float ki{1.80f};
    float kd{0.008f};
    float duty_min{0.0f};
    float duty_max{1.0f};
    float lrc_slew_rate{0.25f};
    float load_dump_threshold{16.5f};
    float load_dump_slope{50.0f};     // Градієнт В/мс
};

class DigitalAvr {
public:
    explicit constexpr DigitalAvr(const AvrConfig& config = {}) noexcept
        : cfg_{config}, v_filtered_{config.target_voltage_base}, prev_v_raw_{config.target_voltage_base} {}

    [[nodiscard]] std::expected<float, AvrStatus> update(float v_raw, float temp_c, float dt_seconds) noexcept {
        if (dt_seconds <= 0.0f || std::isnan(v_raw) || std::isnan(temp_c)) {
            return std::unexpected(AvrStatus::SensorFault);
        }

        // 1. Цифрова фільтрація напруги від пульсацій моста Ларіонова
        constexpr float kAlpha = 0.125f;
        v_filtered_ += kAlpha * (v_raw - v_filtered_);

        // 2. Детектування швидкого скидання навантаження (Load Dump)
        const float dv_dt = (v_raw - prev_v_raw_) / (dt_seconds * 1000.0f);
        prev_v_raw_ = v_raw;

        if (v_raw >= cfg_.load_dump_threshold || dv_dt >= cfg_.load_dump_slope) {
            load_dump_active_ = true;
            current_duty_ = 0.0f;
            integral_sum_ = 0.0f;
            return std::unexpected(AvrStatus::LoadDumpTripped);
        }

        if (load_dump_active_) {
            if (v_raw <= cfg_.target_voltage_base) {
                load_dump_active_ = false;
            } else {
                return std::unexpected(AvrStatus::LoadDumpTripped);
            }
        }

        // 3. Адаптивна температурна корекція робочої точки
        float v_target = cfg_.target_voltage_base + cfg_.temp_coefficient * (temp_c - 25.0f);
        v_target = std::clamp(v_target, 13.2f, 15.2f);

        // 4. Розрахунок ланок ПІД-регулятора
        const float error = v_target - v_filtered_;
        const float p_term = cfg_.kp * error;
        const float d_term = cfg_.kd * (error - prev_error_) / dt_seconds;
        prev_error_ = error;

        // Anti-Windup: накопичення інтегратора лише всередині лінійного діапазону
        const float tentative_duty = p_term + integral_sum_ + (cfg_.ki * error * dt_seconds) + d_term;
        if (tentative_duty >= cfg_.duty_min && tentative_duty <= cfg_.duty_max) {
            integral_sum_ += cfg_.ki * error * dt_seconds;
        }

        const float calculated_duty = std::clamp(p_term + integral_sum_ + d_term, cfg_.duty_min, cfg_.duty_max);

        // 5. Обмеження швидкості зміни струму збудження (LRC)
        const float max_step = cfg_.lrc_slew_rate * dt_seconds;
        if (calculated_duty > current_duty_ + max_step) {
            current_duty_ += max_step;
        } else {
            current_duty_ = calculated_duty;
        }

        return current_duty_;
    }

    [[nodiscard]] constexpr float filtered_voltage() const noexcept { return v_filtered_; }
    [[nodiscard]] constexpr float duty_cycle() const noexcept { return current_duty_; }
    [[nodiscard]] constexpr bool is_load_dump_active() const noexcept { return load_dump_active_; }

    constexpr void reset_faults() noexcept {
        load_dump_active_ = false;
        integral_sum_ = 0.0f;
    }

private:
    AvrConfig cfg_;
    float v_filtered_{14.4f};
    float prev_v_raw_{14.4f};
    float prev_error_{0.0f};
    float integral_sum_{0.0f};
    float current_duty_{0.0f};
    bool load_dump_active_{false};
};

} // namespace electronics::power
```

### 4. Налаштування коефіцієнтів та експериментальні випробування

Для практичного калібрування dAVR на випробувальному стенді з приводним електродвигуном та керованим електронним навантаженням застосовують покрокову інженерну процедуру:

1. **Встановлення `K_p`:** коефіцієнти `K_i` та `K_d` попередньо обнуляють. Генератор розганяють до середніх робочих обертів (3000 об/хв ротора). Поступово збільшують коефіцієнт `K_p` до виникнення перших стійких незгасаючих автоколивань напруги амплітудою 0.2–0.3 В. Робоче значення встановлюють на рівні 50–60% від цього критичного порогу.
2. **Введення `K_i`:** поступово збільшують `K_i`, контролюючи час повної ліквідації статичної похибки при накиданні струму навантаження 100 А. Оптимально налаштоване значення забезпечує плавне повернення напруги до 14.4 В за 100–150 мс без виникнення коливальних перерегулювань.
3. **Налаштування `K_d`:** диференціальну ланку додають для демпфування динамічного просідання в перші 10 мс комутації, при цьому ретельно фільтрують вхід АЦП для уникнення помилкової реакції на високочастотні імпульсні шуми системи запалювання.
4. **Випробування на скидання навантаження (Load Dump Stress Test):** під час віддачі генератором номінального струму 150 А розмикають силовий контактор батареї. Осцилограф фіксує перехідний процес: завдяки миттєвому апаратному скиданню шпаруватості в нуль та енергетичному лавинному обмеженню силовими діодами пік напруги на клемах не перевищує 32.5 В з повною тривалістю імпульсу менше 200 мс.

### 5. Інтеграція з цифровими шинами автомобіля (LIN / BSS)

У сучасних інтелектуальних генераторах мікроконтролер dAVR безперервно бере участь у комунікації за протоколом LIN 2.1 / SAE J2602. Блок керування двигуном надсилає майстер-фрейм кожні 100 мс із полями:
- Байт 0: Цільова напруга `V_target_cmd` (крок 50 мВ, від 10.6 В до 16.0 В).
- Байт 1: Максимальний ліміт струму генератора / час наростання LRC.
- Байт 2: Командний байт (вимкнення генерації при старті / форсована рекуперація).

У відповідь регулятор транслює ведений слейв-фрейм телеметрії:
- Байт 0: Поточний коефіцієнт заповнення ШІМ ротора `DF` (Digital Field Monitor, 0..255).
- Байт 1: Оцінений струм віддачі генератора `I_out_est` (на основі `DF` та частоти фази `f_w`).
- Байт 2: Температура кристала регулятора `T_die` (−40 .. +160 °C).
- Байт 3: Байт статусів помилок (обрив ременя, коротке замикання ротора, несправність фази, перегрів).

Така інтеграція дозволяє автомобілю реалізувати режим рекуперативного гальмування (Smart Charging): під час гальмування двигуном напруга генератора піднімається до 15.0 В для інтенсивного заряду батареї без витрати палива, а під час інтенсивного розгону напруга знижується до 12.6 В, звільняючи до 2–3 кВт механічної потужності двигуна для прискорення автомобіля.

### 6. Діагностика іскріння щіток та тепловий захист кристала (Thermal Derating)

Окрім базового регулювання напруги мікроконтролер dAVR реалізує два критично важливих діагностичних алгоритми, що запобігають аварійним відмовам генератора:

#### 6.1. Детектування зносу щіток та іскріння кілець

При граничному зносі графітових щіток або забрудненні контактних кілець мастилом у колі ковзного контакту виникають мікророзриви тривалістю від 10 до 100 мкс. Це супроводжується високочастотними сплесками напруги на шунті струму збудження. 

Контролер виконує аналіз дисперсії струму збудження: якщо за вікно спостереження 50 мс кількість високочастотних мікророзривів перевищує поріг, регулятор виставляє прапорець попередження `BrushWearWarning` у слейв-фреймі шини LIN, інформуючи бортовий комп'ютер про необхідність регламентної заміни щіткового вузла задовго до повної відмови генератора.

#### 6.2. Теплове розвантаження (Thermal Derating)

Якщо температура силового кристала регулятора перевищує критичний поріг +135 °C (наприклад, через засмічення вентиляційних вікон корпусу або тривалу роботу на максимальному струмі в літню спеку), алгоритм активує плавне обмеження максимальної шпаруватості ШІМ ротора:

```
Duty_max(T) = 1.0 − (T_die − 135.0) · 0.04
```

На кожен градус нагріву понад +135 °C максимальний струм ротора примусово обмежується на 4%. Це знижує вихідну потужність генератора, проте повністю виключає незворотне термічне руйнування польового транзистора регулятора та ізоляції обмоток статора.

### 7. Трасування друкованої плати, ЕМС та апаратний захист

Робота в умовах підкапотного простору вимагає дотримання суворих правил проектування друкованої плати (PCB) та забезпечення електромагнітної сумісності (EMC):

1. **Розділення силової та сигнальної земель:** 
   Струм ротора до 5 А комутується з крутизною фронтів `dI/dt > 10 А/мкс`. Силовий витік транзистора підключається до корпусу генератора окремим полігоном. Сигнальна земля мікроконтролера та вимірювальних кіл АЦП з'єднується з силовою землею в єдиній точці (зіркоподібне заземлення біля шунта), що запобігає проникненню контурних струмів у вимірювальний тракт.
2. **Мінімізація контуру комутації затвора:**
   Провідники від виходу драйвера до затвора та витоку силового MOSFET прокладаються паралельними трасами з мінімальною площею петлі. Для демпфування паразитних коливань ємності затвора з індуктивністю доріжки послідовно із затвором встановлюється резистор `R_gate = 10..22 Ом`.
3. **Демпферний RC-снабер:**
   Паралельно зворотному діоду обмотки збудження встановлюється RC-ланцюг (`R_snub = 10 Ом`, `C_snub = 4.7 нФ`), який поглинає енергію високочастотного дзвону (30–80 МГц), що виникає в момент зворотного відновлення діода.
4. **Тепловий менеджмент:**
   Мікроконтролер та силовий транзистор монтуються на теплопровідній алюмінієвій підкладці (IMS — *Insulated Metal Substrate*) або багатошаровій FR4-платі з масивом металізованих теплових перехідних отворів (Thermal Vias) під термальним майданчиком транзистора, які передають тепло безпосередньо на масивний силуміновий корпус генератора.

### 8. Функціональна безпека (ISO 26262) та аварійний режим Limp-Home

У системах підвищеної надійності мікропрограмне забезпечення dAVR проектується відповідно до вимог автомобільного стандарту функціональної безпеки ISO 26262 (рівень ASIL-B):

1. **Апаратний сторожовий таймер (Independent Watchdog, IWDG):**
   Обслуговування сторожового таймера виконується виключно в кінці успішного виконання основного циклу регулювання. Якщо мікроконтролер зависає через екстремальну електромагнітну заваду, сторожовий таймер перезавантажує ядро за час менше 10 мс.
2. **Контроль цілісності пам'яті Flash та RAM:**
   При кожному старті обчислюється контрольна сума CRC-32 прошивки та проводиться маршовий тест оперативної пам'яті (March-C тест).
3. **Аварійний режим доїзду (Limp-Home Mode):**
   Якщо внутрішня діагностика фіксує відмову АЦП або помилку пам'яті мікроконтролера, керування силовим ключем апаратно перехоплює дублюючий аналоговий компаратор із фіксованим порогом 13.8 В. Це дозволяє транспортному засобу продовжити рух до станції технічного обслуговування без знеструмлення бортової мережі та без ризику перенапруги.
