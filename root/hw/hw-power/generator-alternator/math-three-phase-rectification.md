# 🧮 Математичний аналіз трифазної генерації, випрямлення та перехідних процесів

Цей розділ містить строгий аналітичний апарат електромеханіки трифазного синхронного генератора та напівпровідникової перетворювальної техніки. Послідовно виведено обмоткові коефіцієнти просторового розподілу магнітного поля, векторну геометрію фазних і лінійних напруг, інтегральне середнє значення та гармонійний спектр випрямленої напруги за схемою Ларіонова, фізику комутаційного перекриття фаз через індуктивність розсіювання, математику третіх гармонік нейтралі, двовісну модель Парка-Горєва (`d-q`), баланс теплових втрат та інтеграл енергії розряду ротора при скиданні навантаження (Load Dump).

### 1. Просторові поля, обмоткові коефіцієнти та наведена ЕРС

Магнітне поле в робочому повітряному зазорі між ротором і внутрішньою розточкою статора утворюється обтіканням постійним струмом котушки збудження. Через просторове профілювання полюсних наконечників (дзьобів або башмаків) радіальна складова магнітної індукції `B(θ)` розподілена по колу розточки статора з просторовим періодом `2τ_p` (де `τ_p` — полюсна поділка, тобто геометрична довжина дуги кола статора, яка відповідає одному магнітному полюсу). 

У реальній машині магнітна індукція зазору має сплощену трапецеподібну форму через насичення сталевих зубців. Розклад цього поля в ряд Фур'є дає непарні просторові гармоніки: основну `B_1`, третю `B_3`, п'яту `B_5` і сьому `B_7`. Основна гармоніка магнітної індукції описується синусоїдальним розподілом уздовж координати розточки статора `x`:

```
B(x) = B_max · cos(π · x / τ_p)
```

При механічному обертанні ротора зі швидкістю `n` об/хв (обертів за хвилину) машиною з числом пар полюсів `p` циклічна частота `f` та кутова швидкість обертання основного магнітного поля `ω` строго визначаються фундаментальними кінематичними співвідношеннями:

```
f = (p · n) / 60
ω = 2π · f = (2π · p · n) / 60 = (π · p · n) / 30
```

Кожна з трьох фаз статора містить `N_ph` послідовно з'єднаних витків провідника, вкладених у пази сердечника. Оскільки обмотка не зосереджена в одному пазу, а розподілена по групі з `q` сусідніх пазів на фазну зону, миттєві ЕРС окремих пазових провідників мають невеликий кутовий фазовий зсув `γ = π · p / Z_s` (де `Z_s` — загальна кількість пазів статора). 

Сумарна фазна ЕРС є векторною сумою ЕРС окремих витків. Оскільки вектори зсунуті на кут `γ`, довжина сумарного вектора хорди завжди менша за арифметичну суму довжин дуг векторів. Це геометричне ослаблення враховується коефіцієнтом розподілу обмотки `k_d`:

```
k_d = sin(q · γ / 2) / (q · sin(γ / 2))
```

Для ефективного придушення паразитних 5-ї та 7-ї просторових гармонік поля крок котушки `y` навмисно роблять коротшим за полюсну поділку `τ_p` на відносний коефіцієнт вкорочення кроку `β = y / τ_p` (зазвичай обирають оптимальне значення `β = 5/6 ≈ 0.833`). При такому хордуванні п'ята та сьома гармоніки майже повністю компенсуються, що суттєво зменшує вихрові втрати в залізі та усуває високочастотний акустичний писк генератора. Це вкорочення знижує ЕРС основної гармоніки відповідно до коефіцієнта вкорочення (хордування) `k_p`:

```
k_p = sin(β · π / 2)
```

Повний обмотковий коефіцієнт статора `k_w` є добутком коефіцієнтів розподілу та вкорочення:

```
k_w = k_d · k_p
```

Корисний магнітний потік одного полюса `Φ_p` через активну циліндричну площу довжиною `l_fe` обчислюється інтегруванням півхвилі синусоїдної індукції:

```
Φ_p
= ∫[0 .. τ_p] B_max · sin(π · x / τ_p) · l_fe dx                       [інтеграл магнітної індукції по площі]
= B_max · l_fe · [−(τ_p / π) · cos(π · x / τ_p)]_[0 .. τ_p]            [первісна від синуса]
= B_max · l_fe · (τ_p / π) · (1 − (−1))                                [підстановка меж 0 та τ_p]
= (2 / π) · B_max · τ_p · l_fe                                         [середнє значення індукції по полюсу]
```

Діюче значення основної гармоніки ЕРС холостого ходу фази статора `E_0` за законом Фарадея:

```
E_0
= (2π / √2) · f · N_ph · k_w · Φ_p                                     [діюче значення ЕРС за Фарадеєм]
= 4.44288 · f · N_ph · k_w · Φ_p                                       [коефіцієнт форми гармонічного сигналу]
```

### 2. Векторна геометрія схем «Зірка» та «Трикутник»

Три симетричні фази статора розміщені зі зміщенням на `120°` (`2π/3` рад) в електричному просторі. Система наведених миттєвих фазних ЕРС описується функціями:

```
e_A(t) = E_m · sin(ωt)
e_B(t) = E_m · sin(ωt − 2π/3)
e_C(t) = E_m · sin(ωt + 2π/3)
```

#### Топологія «Зірка» (Wye / Y)

У схемі «зірка» три фазні обмотки з'єднані одними кінцями в центральну точку нейтралі `N`. Лінійна напруга `u_AB(t)` між фазними клемами `A` і `B` дорівнює різниці фазних напруг:

```
u_AB(t)
= e_A(t) − e_B(t)                                                     [визначення лінійної напруги]
= E_m · sin(ωt) − E_m · sin(ωt − 2π/3)                                 [підстановка фазних функцій]
= 2 · E_m · sin((ωt − (ωt − 2π/3)) / 2) · cos((ωt + (ωt − 2π/3)) / 2)   [тригонометрична різниця sin α − sin β]
= 2 · E_m · sin(π/3) · cos(ωt − π/3)                                   [обчислення півсуми й піврізниці]
= 2 · E_m · (√3 / 2) · cos(ωt − π/3)                                   [підстановка sin(60°) = √3/2]
= √3 · E_m · cos(ωt − π/3)                                             [скорочення коефіцієнта 2]
= √3 · E_m · sin(ωt − π/3 + π/2)                                       [перехід від косинуса до синуса]
= √3 · E_m · sin(ωt + π/6)                                             [зведення кута до +30°]
```

Звідси діючі значення лінійних і фазних величин у зірці пов'язані коефіцієнтом `√3`:

```
V_line = √3 · V_phase ≈ 1.73205 · V_phase
I_line = I_phase
```

Повна активна трифазна потужність генератора за коефіцієнта потужності `cos φ`:

```
P_total
= 3 · V_phase · I_phase · cos(φ)                                       [сума трьох симетричних фаз]
= 3 · (V_line / √3) · I_line · cos(φ)                                  [заміна V_phase = V_line / √3]
= √3 · V_line · I_line · cos(φ)                                        [вираз через лінійні величини]
```

#### Топологія «Трикутник» (Delta / Δ)

У схемі «трикутник» обмотки утворюють замкнений контур `A→B→C→A`. Лінійна напруга збігається з фазною, а лінійний вихідний струм є різницею струмів суміжних фаз:

```
V_line = V_phase
I_line = √3 · I_phase ≈ 1.73205 · I_phase
```

Головна перевага схеми «зірка» над «трикутником» в автономних генераторах полягає у поведінці третьої гармоніки. У «зірці» треті гармоніки всіх трьох фаз є синфазними (`3 · 120° = 360° ≡ 0°`), тому в лінійній напрузі між будь-якими двома фазами вони взаємно віднімаються (`e_A3 − e_B3 = 0`). 

У схемі «трикутник» синфазні ЕРС третьої гармоніки сумуються вздовж замкненого контуру, утворюючи сумарну результуючу ЕРС `E_3_loop = 3 · E_3m`. Оскільки опір контуру визначається лише малим активним та індуктивним опором міді обмоток статора, всередині трикутника виникає безперервний паразитарний циркулюючий струм третьої гармоніки:

```
I_circ_3 = (3 · E_3m) / (3 · Z_phase_3) = E_3m / √(R_ph² + (3ω · L_s)²)
```

Цей струм не виходить у зовнішнє навантаження, але викликає постійний додатковий нагрів статора мідними втратами `3 · I_circ_3² · R_ph`, знижуючи ККД генератора на 3–5%. Саме тому в автомобільних і тракторних генераторах перевагу майже завжди віддають схемі «зірка».

### 3. Інтегральний вивід випрямленої напруги моста Ларіонова

У шестидіодному мостовому випрямлячі Ларіонова кожен вентиль проводить струм протягом третини періоду (`120°` або `2π/3` рад). Кожні `60°` (`π/3` рад) відбувається зміна провідної пари діодів: відкривається черговий діод у катодній або анодній групі, який підключає до навантаження фазу з найвищим миттєвим додатним або від'ємним потенціалом.

Середнє значення постійної випрямленої напруги `V_dc_avg` отримуємо інтегруванням купола лінійної напруги `u_line(θ) = V_line_max · cos(θ)` у межах кутів симетрії `[−π/6 .. +π/6]`:

```
V_dc_avg
= (1 / (π / 3)) · ∫[−π/6 .. +π/6] V_line_max · cos(θ) dθ               [інтеграл середнього значення за інтервал]
= (3 / π) · V_line_max · ∫[−π/6 .. +π/6] cos(θ) dθ                     [винесення множників за знак інтеграла]
= (3 / π) · V_line_max · [sin(θ)]_[−π/6 .. +π/6]                       [первісна функція sin(θ)]
= (3 / π) · V_line_max · (sin(π/6) − sin(−π/6))                        [різниця значень на границях]
= (3 / π) · V_line_max · (0.5 − (−0.5))                                [підстановка тригонометричних значень]
= (3 / π) · V_line_max · 1.0                                           [арифметичне додавання]
= (3 / π) · V_line_max                                                 [середнє через амплітуду лінійної напруги]
```

Зв'язок із діючими (RMS) значеннями напруг:

```
V_dc_avg
= (3 / π) · √2 · V_line_rms                                            [оскільки V_line_max = √2 · V_line_rms]
= ((3 · √2) / π) · V_line_rms                                          [зведення числових множників]
≈ 1.35047 · V_line_rms                                                 [коефіцієнт лінійної напруги]
= ((3 · √2) / π) · (√3 · V_phase_rms)                                  [підстановка V_line_rms = √3 · V_phase_rms]
= ((3 · √6) / π) · V_phase_rms                                         [зведення під спільний корінь]
≈ 2.33914 · V_phase_rms                                                [коефіцієнт фазної напруги]
```

При врахуванні прямого спаду напруги на двох відкритих послідовних діодах `2 · V_f` (для кремнієвих діодів `V_f ≈ 0.85 В`):

```
V_out_dc = 1.3505 · V_line_rms − 2 · V_f
```

### 4. Гармонійний спектр пульсацій і розклад Фур'є

Крива напруги на виході моста Ларіонова є періодичною парною функцією часу з базовою частотою пульсацій `f_rip = 6 · f`. Парний тригонометричний ряд Фур'є містить виключно гармоніки, кратні 6:

```
v_dc(t) = V_dc_avg + ∑[k=1..∞] A_6k · cos(6k · ωt)
```

Коефіцієнт амплітуди `A_6k` обчислюється інтегруванням:

```
A_6k
= (2 / (π / 3)) · ∫[−π/6 .. +π/6] V_line_max · cos(θ) · cos(6k · θ) dθ  [формула коефіцієнтів ряду Фур'є]
= (6 / π) · V_line_max · ∫[0 .. π/6] [cos((6k − 1)θ) + cos((6k + 1)θ)] dθ [розклад добутку косинусів]
= (6 / π) · V_line_max · [sin((6k − 1)π/6)/(6k − 1) + sin((6k + 1)π/6)/(6k + 1)] [інтегрування за кутом]
= (6 / π) · V_line_max · (−1)^(k+1) / ((6k)² − 1)                      [тригонометричне згортання]
= (−1)^(k+1) · (2 / (36k² − 1)) · V_dc_avg                             [вираз через середнє значення V_dc_avg]
```

Розрахунок амплітуд перших гармонік:

```
A_6  = (2 / 35)  · V_dc_avg ≈ 0.05714 · V_dc_avg  (5.71% від постійної складової)
A_12 = (2 / 143) · V_dc_avg ≈ 0.01399 · V_dc_avg  (1.40% від постійної складової)
A_18 = (2 / 323) · V_dc_avg ≈ 0.00619 · V_dc_avg  (0.62% від постійної складової)
```

Діюче значення пульсацій `V_ac_rms`:

```
V_ac_rms
= √((A_6 / √2)² + (A_12 / √2)² + (A_18 / √2)²)                         [корінь із суми квадратів діючих значень]
= (V_dc_avg / √2) · √((2/35)² + (2/143)² + (2/323)²)                   [винесення спільного множника]
≈ (V_dc_avg / 1.41421) · √(0.003265 + 0.000196 + 0.000038)             [обчислення значень дробів]
≈ (V_dc_avg / 1.41421) · √0.003499                                     [сума підкореневого виразу]
≈ (V_dc_avg / 1.41421) · 0.05915
≈ 0.04182 · V_dc_avg                                                   [діюче значення пульсацій 4.18%]
```

Коефіцієнт пульсацій від піку до піку (Peak-to-Peak):

```
K_p2p
= (V_line_max − V_line_max · cos(π/6)) / V_dc_avg                      [відношення розмаху коливань до середнього]
= (V_line_max · (1 − √3/2)) / ((3/π) · V_line_max)                     [підстановка аналітичного інтеграла]
= (π / 3) · (1 − √3/2)                                                 [скорочення амплітуди V_line_max]
≈ 1.04720 · (1 − 0.86603)                                              [числовий розрахунок]
≈ 1.04720 · 0.13397
≈ 0.14030                                                              [розмах пульсацій 14.03%]
```

### 5. Комутаційне перекриття фаз через індуктивність розсіювання

У реальному генераторі струм не може миттєво перейти з однієї фази в іншу через наявність власної індуктивності розсіювання статорних обмоток `L_s`. Процес перемикання діодів триває скінченний кут комутації `γ_comm` (або `μ`), під час якого одночасно відкриті три діоди моста, утворюючи коротке замикання комутуючих фаз.

Рівняння зміни комутаційного струму:

```
2 · L_s · (di_comm / dt) = u_line(t) = √2 · V_line_rms · sin(ωt)
```

Інтегруючи за інтервалом комутації від `0` до `γ_comm`, знаходимо кут перекриття:

```
cos(γ_comm) = 1 − (2 · ω · L_s · I_dc) / (√2 · V_line_rms)
```

Комутаційне коротке замикання призводить до «вирізання» площі під кривою напруги, що викликає додаткове внутрішнє падіння випрямленої напруги під навантаженням `ΔV_comm`:

```
ΔV_comm
= (3 / π) · ω · L_s · I_dc                                             [втрата середньої напруги від комутації]
= (6 · f · L_s) · I_dc                                                 [еквівалентний комутаційний опір R_comm]
```

Повна вихідна напруга випрямляча з урахуванням активного опору статора `R_s`, комутаційного реактансу `X_s` та спаду на діодах:

```
V_out(I_dc) = 1.3505 · V_line_rms − 2 · V_f − (2 · R_s + (3/π) · ω · L_s) · I_dc
```

### 6. Використання 3-ї гармоніки нейтралі (Neutral Diode Injection)

У схемі «зірка» третя просторова гармоніка магнітного поля наводить у всіх трьох фазах синфазні ЕРС:

```
e_A3(t) = E_3m · sin(3ωt)
e_B3(t) = E_3m · sin(3(ωt − 2π/3)) = E_3m · sin(3ωt − 2π) = E_3m · sin(3ωt)
e_C3(t) = E_3m · sin(3(ωt + 2π/3)) = E_3m · sin(3ωt + 2π) = E_3m · sin(3ωt)
```

Оскільки напруга нейтралі відносно фаз коливається з потрійною частотою `3f` та амплітудою `E_3m ≈ 0.15..0.25 · E_m`, підключення точки нейтралі `N` до вихідних шин через додаткову пару діодів (8-діодний випрямляч) дозволяє відбирати струм третьої гармоніки на високих обертах. 

Коли потенціал нейтралі перевищує потенціал шини `B+` або стає нижчим за потенціал `GND`, додаткові діоди відкриваються і спрямовують струм 3-ї гармоніки в загальне навантаження. Це збільшує максимальний вихідний струм генератора на `10..15%` без збільшення маси заліза та міді:

```
I_out_total = I_bridge + I_neutral_diodes ≈ 1.12 · I_bridge
```

### 7. Двовісна модель Парка-Горєва (d-q осі) для явнополюсного ротора

Для дзьобоподібного ротора (ротора Лунделла) або явнополюсної машини магнітний опір по поздовжній осі `d` (вісь симетрії магнітних полюсів) значно менший за магнітний опір по поперечній осі `q` (міжполюсний зазор із великим повітряним проміжком). Синхронні індуктивності відрізняються: `X_d > X_q`.

Рівняння напруг за перетворенням Парка-Горєва в системі координат ротора:

```
v_d = −R_a · i_d − ω · L_q · i_q
v_q = −R_a · i_q + ω · L_d · i_d + E_0
```

Активна `P` та реактивна `Q` електромагнітна потужність машини, підключеної до шини напруги `V_t` під кутом ротора `δ`:

```
P = (E_0 · V_t / X_d) · sin(δ) + (V_t² / 2) · (1/X_q − 1/X_d) · sin(2δ)
Q = (E_0 · V_t / X_d) · cos(δ) − V_t² · ((cos(δ))² / X_d + (sin(δ))² / X_q)
```

Другий доданок у формулі потужності `(V_t²/2) · (1/X_q − 1/X_d) · sin(2δ)` є реактивною потужністю випуклополюсності (реактивним моментом), який виникає завдяки прагненню сталевих дзьобів ротора зайняти положення з найменшим магнітним опором навіть за відсутності струму збудження (`E_0 = 0`).

### 8. Тепловий баланс та порівняння з активним MOSFET-випрямлячем

Повний ККД генераторної установки визначається тепловим балансом п'яти складових втрат:

```
P_loss = P_cu_stator + P_cu_rotor + P_rect + P_fe + P_mech
η = P_out / (P_out + P_loss)
```

1. **Втрати в міді статора:** `P_cu_stator = 3 · I_phase_rms² · R_stator`
2. **Втрати в обмотці збудження ротора:** `P_cu_rotor = I_field² · R_field`
3. **Втрати у випрямлячі:**
- Для класичного діодного моста:
```
P_rect_diode = 2 · V_f · I_dc + 2 · I_dc² · (r_d / 3)
```
- Для активного синхронного випрямляча на шести польових транзисторах MOSFET:
```
P_rect_mosfet = 2 · I_phase_rms² · R_ds_on + 2 · V_body · I_dc · (t_dead · 6 · f)
```
При струмі `I_dc = 150 А` діодний міст виділяє `P_rect ≈ 2 · 0.85 · 150 = 255 Вт` тепла, що вимагає потужного алюмінієвого радіатора та інтенсивного обдуву крильчаткою ротора. Синхронний міст на сучасних MOSFET з опором відкритого каналу `R_ds_on = 1.2 мОм` за того самого струму розсіює лише:

```
P_rect_mosfet ≈ 2 · (150 / √3)² · 0.0012 ≈ 18 Вт
```
Зниження тепловтрат у 14 разів кардинально покращує температурний режим генератора та підвищує загальний ККД із 72% до 88–90%.

4. **Магнітні втрати в залізі статора (гістерезис і вихрові струми):**
```
P_fe = k_h · f · B_max² · m_fe + k_e · f² · B_max² · d_lam² · m_fe
```
де `d_lam` — товщина ізольованих пластин сталі (0.35–0.5 мм), `m_fe` — маса осердя.

5. **Механічні та вентиляційні втрати:**
```
P_mech = k_bearing · n + k_fan · n³
```

### 9. Перехідний процес розряду ротора при скиданні навантаження (Load Dump)

При аварійному обриві кола акумулятора під час генерації повного струму (Load Dump за стандартом ISO 16750-2, Pulse 5a) струм збудження ротора `i_f(t)` спадає за експоненціальним законом через демпферний контур регулятора з електромагнітною сталою часу `τ_f = L_f / R_f`:

```
i_f(t) = I_f0 · exp(−t / τ_f)
E_gen(t) = E_peak · exp(−t / τ_f)
```

Інтегральна теплова енергія `W_dump`, яка поглинається захисними лавинними діодами випрямляча або супресором з фіксованою напругою зрізу `V_clamp`:

```
W_dump
= ∫[0 .. t_d] V_clamp · i_dump(t) dt                                   [інтеграл повної енергії розряду]
= V_clamp · ∫[0 .. t_d] ((E_gen(t) − V_clamp) / R_i) dt                [струм розряду через внутрішній опір R_i]
= (V_clamp / R_i) · ∫[0 .. t_d] (E_peak · exp(−t / τ_f) − V_clamp) dt  [підстановка закону спаду ЕРС]
= (V_clamp / R_i) · [−E_peak · τ_f · exp(−t / τ_f) − V_clamp · t]_[0 .. t_d] [інтегрування експоненти]
= (V_clamp / R_i) · [E_peak · τ_f · (1 − exp(−t_d / τ_f)) − V_clamp · t_d] [підстановка меж часу [0..t_d]]
```

Для реальних параметрів автомобільного генератора: `V_clamp = 34.0 В`, `E_peak = 110.0 В`, `R_i = 0.18 Ом`, `τ_f = 0.12 с`, тривалість активного імпульсу `t_d = 0.14 с`:

```
W_dump
= (34.0 / 0.18) · [110.0 · 0.12 · (1 − exp(−0.14 / 0.12)) − 34.0 · 0.14] [підстановка параметрів генератора]
= 188.89 · [13.2 · (1 − exp(−1.1667)) − 4.76]                          [проміжне обчислення коефіцієнтів]
= 188.89 · [13.2 · (1 − 0.3114) − 4.76]                                [значення експоненти e^(-1.1667)]
= 188.89 · [13.2 · 0.6886 − 4.76]                                      [обчислення спаду потоку в дужках]
= 188.89 · [9.0895 − 4.76]                                             [множення 13.2 * 0.6886]
= 188.89 · 4.3295                                                      [різниця генераторного й захисного інтегралів]
≈ 817.8 Дж                                                             [повна поглинена теплова енергія]
```

### 10. Передавальна функція генератора та синтез ПІ-регулятора напруги

Для проектування стійкого цифрового або аналогового контуру автоматичного регулювання напруги (AVR) складемо малу-сигнальну лінеаризовану передавальну функцію генераторної установки. Вхідним впливом є зміна коефіцієнта заповнення ШІМ-сигналу `Δd(t)`, а вихідною величиною — зміна випрямленої напруги на клемах навантаження `Δv_out(t)`.

Ланка збудження описується аперіодичною ланкою першого порядку з коефіцієнтом підсилення `K_f = V_bat / R_f` та сталою часу ротора `τ_f = L_f / R_f`:

```
W_f(s) = ΔI_f(s) / Δd(s) = (V_bat / R_f) / (1 + s · τ_f)
```

Внутрішня ЕРС генератора лінійно залежить від струму збудження `E_0 = k_e · ω · i_f` (коефіцієнт передачі `K_e = k_e · ω`), а випрямляч зі згладжуючим фільтром та навантаженням описується еквівалентним внутрішнім опором `R_i` та ємністю батареї `C_bat` з еквівалентним послідовним опором `ESR` (стала часу фільтра `τ_filt = (R_i || R_load) · C_bat`):

```
W_out(s) = ΔV_out(s) / ΔI_f(s) = K_e · (R_load / (R_i + R_load)) / (1 + s · τ_filt)
```

Повна передавальна функція об'єкта керування `G_p(s)` є послідовним з'єднанням ланок ротора та статора:

```
G_p(s) = W_f(s) · W_out(s) = K_gen / ((1 + s · τ_f) · (1 + s · τ_filt))
```

де сумарний коефіцієнт статичного підсилення `K_gen` визначається як:

```
K_gen = (V_bat / R_f) · K_e · (R_load / (R_i + R_load))
```

Оскільки стала часу ротора `τ_f ≈ 80..150 мс` значно перевищує сталу часу випрямляча з батареєю `τ_filt ≈ 2..10 мс`, передавальна функція має домінантний полюс `p_1 = −1 / τ_f`. Для забезпечення нульової статичної похибки стабілізації напруги при зміні обертів або навантаження застосовують пропорційно-інтегральний (ПІ) регулятор із передавальною функцією:

```
W_reg(s) = K_p + K_i / s = K_p · (1 + s · (K_p / K_i)) / s
```

За методом компенсації домінантного полюса нуль ПІ-регулятора налаштовують на компенсацію постійної часу ротора:

```
K_p / K_i = τ_f
```

При такому налаштуванні розімкнений контур регулювання набуває виду інтегруючої ланки з малою затримкою фільтра `L(s) = (K_p · K_gen / τ_f) / (s · (1 + s · τ_filt))`. Це гарантує запас стійкості за фазою понад `65°`, виключаючи низькочастотні автоколивання напруги («плавання» яскравості освітлення).

### 11. Динаміка раптового трифазного короткого замикання

При раптовому короткому замиканні на клемах статора в обмотках виникає надперехідний струм, амплітуда якого в перші мілісекунди обмежена лише надперехідним індуктивним реактансом розсіювання `X_d''`:

```
I_sc_subtrans = E_0 / X_d''
```

Проте в міру наростання струму статора магнітний потік розмагнічувальної реакції якоря повністю компенсує потік збудження ротора. Усталений струм короткого замикання `I_sc_steady` синхронного генератора падає до безпечного значення:

```
I_sc_steady = E_0 / X_d = E_0 / (X_l + X_a)
```

Оскільки повний синхронний опір `X_d` є відносно великим (у відносних одиницях `x_d = 1.2..2.0`), усталений струм короткого замикання перевищує номінальний лише у 1.2–1.5 раза. Відношення струму короткого замикання при номінальному струмі збудження до номінального струму якоря визначає коефіцієнт короткого замикання (SCR — *Short Circuit Ratio*):

```
SCR = 1 / x_d = I_sc_steady / I_nom
```

Машини з великим повітряним зазором мають малий реактанс реакції якоря `X_a`, вищий `SCR ≈ 0.8..1.2` та кращу жорсткість зовнішньої характеристики (менше просідання напруги під навантаженням), проте вимагають потужнішої обмотки ротора та вищих струмів збудження. Машини з малим зазором (зокрема автомобільні альтернатори) мають низький `SCR ≈ 0.4..0.6`, що знижує витрату міді на роторі, а високе просідання напруги повністю компенсується швидкодіючим електронним контуром регулятора AVR. Це фізичне явище самообмеження струму реакцією якоря забезпечує природну стійкість синхронного генератора до тривалих аварійних режимів.

Отриманий результат `817.8 Дж` у розрахунку Load Dump обґрунтовує вимогу застосування в силі випрямлячів кремнієвих вентилів виключно з керованим лавинним пробоєм (Avalanche Diodes), які поглинають високовольтний сплеск без точкового термічного шнурування струму та руйнування кристала.
