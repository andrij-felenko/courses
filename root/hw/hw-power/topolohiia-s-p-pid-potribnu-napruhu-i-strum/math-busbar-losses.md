# 🧮 Математика струмопровідних шин: опір, нерівномірність струмів та нагрів

У сильнострумових акумуляторних батареях опір металевих шин (англ. *busbars*) та зварних мікроперемичок становить від часток міліома до кількох міліом. Хоча ця величина здається незначною порівняно з внутрішнім опором комірок, за струмів у десятки й сотні ампер падіння напруги на шинах кардинально спотворює розподіл струмів між паралельними банками й генерує паразитичне тепло за законом Джоуля-Ленца. Розгляньмо аналітичні моделі розрахунку опору провідників, драбинкових резистивних матриць (англ. *ladder networks*) та термодинамічного розсіювання потужності.

### 1. Опір прямокутної шини та порівняння матеріалів

Електричний опір суцільної прямокутної шини довжиною `L`, шириною `w` і товщиною `t` визначається питомим опором матеріалу `ρ`:

```
R = ρ · L / A
  = ρ · L / (w · t)   [підстановка площі прямокутного перерізу A = w · t]
```

Де:
- `ρ` — питомий електричний опір матеріалу (Ом·м або мкОм·см);
- `A = w · t` — площа поперечного перерізу шини (м² або мм²);
- `L` — довжина ділянки протікання струму (м).

У практичних інженерних розрахунках зручно використовувати одиниці `мОм·мм²/м`:

| Матеріал шини | Питомий опір `ρ` (мОм·мм²/м) при 20 °C | Температурний коефіцієнт опору `α` (1/°C) | Відносний опір до міді (`ρ / ρ_Cu`) |
|---|---|---|---|
| Електротехнічна мідь (Cu ETP / CW004A) | 17.2 | 0.00393 | 1.00 |
| Алюміній (Al 1050 / 99.5%) | 28.2 | 0.00403 | 1.64 |
| Чистий нікель (Ni 200 / Ni 201) | 96.0 | 0.00540 | 5.58 |
| Нікельована низьковуглецева сталь (SPCC) | 130.0 | 0.00500 | 7.56 |

**Розрахунковий приклад: опір типової перемички 18650 між двома сусідніми комірками.**
Нехай міжосьова відстань між банками `L = 20 мм` (`0.02 м`), ширина стрічки `w = 8 мм`, товщина `t = 0.15 мм` (переріз `A = 8 · 0.15 = 1.2 мм²`).

Для чистої нікелевої стрічки:
```
R_Ni = 96.0 мОм·мм²/м · 0.02 м / 1.2 мм²
     = 1.92 / 1.2       [обчислення чисельника: 96.0 · 0.02 = 1.92]
     = 1.60 мОм         [ділення на площу перерізу 1.2 мм²]
```

Для мідної шини такого самого розміру:
```
R_Cu = 17.2 мОм·мм²/м · 0.02 м / 1.2 мм²
     = 0.344 / 1.2      [обчислення чисельника: 17.2 · 0.02 = 0.344]
     = 0.287 мОм        [ділення на площу перерізу 1.2 мм²]
```

Різниця становить понад 5.5 раза. При протіканні струму 20 А втрати потужності на одному такому відрізку становлять:
```
P_loss_Ni = I² · R_Ni
          = (20)² · 0.00160    [підстановка струму I = 20 А та опору 1.60 мОм]
          = 400 · 0.00160      [піднесення до квадрата: 20² = 400]
          = 0.64 Вт            [обчислення потужності втрат]

P_loss_Cu = I² · R_Cu
          = (20)² · 0.000287   [підстановка струму I = 20 А та опору 0.287 мОм]
          = 400 · 0.000287     [піднесення до квадрата: 20² = 400]
          = 0.115 Вт           [обчислення потужності втрат]
```

Нікелева перемичка на кожному сантиметрі розсіює понад пів вата чистого тепла, що безпосередньо підігріває плюсовий контакт комірки та сепаратор.

### 2. Розподіл струмів у паралельній групі: резистивна драбина

Розглянемо паралельну групу з `N` однакових комірок, кожна з яких має внутрішній опір `R_c` та ЕРС `E`. Комірки з'єднані верхньою (позитивною) і нижньою (негативною) шинами. Кожен відрізок шини між сусідніми банками має опір `r_s`.

```
Верхня шина:   Вузол 1 ──[ r_s ]── Вузол 2 ──[ r_s ]── ... ── Вузол N
                  │                   │                          │
              [ R_c, E ]          [ R_c, E ]                 [ R_c, E ]
                  │                   │                          │
Нижня шина:    Вузол 1' ──[ r_s ]── Вузол 2' ──[ r_s ]── ... ── Вузол N'
```

#### Випадок А: Однобічне підключення навантаження (U-flow)
Якщо обидві зовнішні клеми навантаження підключено з лівого боку (вузол 1 і вузол 1'):
- Контур першої комірки має нульову довжину шини: опір кола `R_loop_1 = R_c`.
- Контур `k`-ї комірки включає опір відрізків верхньої та нижньої шин: `R_loop_k = R_c + 2 · (k - 1) · r_s`.

При `r_s > 0` струми в гілках спадають зі зростанням індексу `k`. Для системи вузлових рівнянь за методом потенціалів вузлів:

```
I_k = (V_top[k] - V_bot[k] - E) / R_c
```

Відношення струму першої (найближчої до клем) банки до останньої (найвіддаленішої) при `N = 4`, `R_c = 20 мОм`, `r_s = 2 мОм`:
```
I_1 / I_4 ≈ 1 + 2 · (4 - 1) · r_s / R_c
          = 1 + 6 · 2 / 20     [підстановка параметрів: N = 4, r_s = 2 мОм, R_c = 20 мОм]
          = 1 + 0.60           [спрощення дробу: 12 / 20 = 0.60]
          = 1.60               [відношення струмів крайніх комірок]
```
Перша банка бере на 60% більший струм, ніж четверта, розігріваючись у `(1.6)² = 2.56` раза сильніше.

#### Випадок Б: Діагональне підключення навантаження (Z-flow / Reverse-Return)
Якщо позитивну клему підключено до вузла 1 (ліворуч), а негативну — до вузла `N'` (праворуч):
- Струм від вузла 1 до `k`-ї банки проходить `(k - 1)` відрізків верхньої шини.
- Від `k`-ї банки до негативної клеми `N'` струм проходить `(N - k)` відрізків нижньої шини.
- Сумарна довжина шини в контурі будь-якої `k`-ї комірки є строгою константою:

```
L_total_k = (k - 1) · r_s + (N - k) · r_s
          = (k - 1 + N - k) · r_s      [винесення спільного множника r_s за дужки]
          = (N - 1) · r_s              [скорочення доданків k та -k]
```

Оскільки опір шинної петлі для кожної з `N` комірок є однаковим (`R_loop_k = R_c + (N - 1) · r_s`), струми розподіляються симетрично:
```
I_1 = I_N
I_2 = I_(N-1)
```
Розкид струмів між крайніми й центральними банками в Z-схемі становить лічені відсотки (зазвичай < 3–5%), що гарантує рівномірне старіння й однаковий тепловий режим усіх паралельних комірок.

### 3. Нерівномірність струмів при розкиді внутрішнього опору комірок

Нехай у групі з `P` паралельних банок з ідеальною шиною (`r_s ≈ 0`) комірки мають індивідуальні внутрішні опори `R_1, R_2, ..., R_P`.

Оскільки всі банки підключені до спільних вузлів, напруга на затискачах групи `U_p` однакова для всіх гілок:
```
U_p = E - I_k · R_k    (для будь-якого k від 1 до P)
```

Звідси спад напруги на внутрішньому опорі кожної банки однаковий:
```
ΔU = E - U_p = I_k · R_k = const
```

Отже, струм `k`-ї гілки обернено пропорційний її внутрішньому опору:
```
I_k = ΔU / R_k
```

Сумарний струм групи:
```
I_total = ∑ I_k
        = ΔU · ∑ (1 / R_k)
```

Виразивши `ΔU = I_total / ∑ (1 / R_i)`, отримуємо частку струму, яку несе `k`-та банка:

```
I_k = I_total · (1 / R_k) / ∑ (1 / R_i)
```

Потужність, що виділяється всередині `k`-ї комірки у вигляді тепла:

```
P_k = I_k² · R_k
    = [ I_total · (1 / R_k) / ∑ (1 / R_i) ]² · R_k     [підстановка виразу для I_k]
    = I_total² · (1 / R_k²) / [ ∑ (1 / R_i) ]² · R_k   [розкриття квадрата дробу]
    = I_total² · (1 / R_k) / [ ∑ (1 / R_i) ]²          [скорочення R_k у чисельнику та знаменнику]
```

**Головний фізичний висновок:**
Оскільки `P_k ∝ 1 / R_k`, потужність тепловиділення **обернено пропорційна** внутрішньому опору комірки. Банка з найменшим опором бере на себе найбільший струм і виділяє **найбільше тепла**.

**Числовий приклад для 1S3P групи при сумарному струмі `I_total = 30 А`:**
- Банка 1: `R_1 = 15 мОм` (провідність `G_1 = 1/0.015 = 66.67 См`);
- Банка 2: `R_2 = 25 мОм` (провідність `G_2 = 1/0.025 = 40.00 См`);
- Банка 3: `R_3 = 40 мОм` (провідність `G_3 = 1/0.040 = 25.00 См`).

Сумарна провідність:
```
∑ G_i = 66.67 + 40.00 + 25.00
      = 131.67 См
```

Розподіл струмів:
```
I_1 = 30 · (66.67 / 131.67) = 15.19 А
I_2 = 30 · (40.00 / 131.67) = 9.11 А
I_3 = 30 · (25.00 / 131.67) = 5.70 А
```

Теплові втрати:
```
P_1 = (15.19)² · 0.015 = 230.7 · 0.015 = 3.46 Вт
P_2 = (9.11)² · 0.025  = 83.0 · 0.025  = 2.08 Вт
P_3 = (5.70)² · 0.040  = 32.5 · 0.040  = 1.30 Вт
```

Банка з опором 15 мОм генерує **у 2.66 раза більше тепла**, ніж банка з опором 40 мОм. Це спричиняє локальний градієнт температур і швидку деградацію найкращої комірки в невідсортованій групі.

### 4. Тепловий баланс і розрахунок перегріву шини

Втрати потужності на ділянці шини перетворюються на тепло за законом Джоуля-Ленца:
```
P_joule = I² · R
```

У стаціонарному тепловому режимі вся виділена потужність розсіюється в навколишнє повітря конвекцією та випромінюванням через відкриту площу поверхні шини `S_surf`:

```
P_dissipated = h_total · S_surf · (T_bus - T_amb)
```

Де:
- `h_total ≈ 10–15 Вт/(м²·°C)` — коефіцієнт природного конвективно-променевого тепловідведення в закритому батарейному корпусі;
- `S_surf = 2 · (w + t) · L` — площа поверхні прямокутної смуги довжиною `L`;
- `ΔT = T_bus - T_amb` — перевищення температури шини над навколишнім середовищем.

Прирівнюючи виділене тепло до розсіяного (`P_joule = P_dissipated`), отримуємо оцінку стаціонарного перегріву шини:

```
ΔT = (I² · ρ · L / (w · t)) / (h_total · 2 · (w + t) · L)
   = I² · ρ / [ 2 · h_total · w · t · (w + t) ]   [скорочення довжини шини L у чисельнику та знаменнику]
```

Зверніть увагу: довжина шини `L` скорочується. Перегрів прямокутної шини під постійним струмом залежить виключно від геометрії її перерізу `(w, t)`, властивостей металу `ρ` та струму `I`.

Для збереження перегріву шин у безпечних межах (`ΔT < 15–20 °C`):
- Для **міді** щільність струму `J = I / A` обирають у діапазоні **4–6 А/мм²** (тривалий режим) та до **10–12 А/мм²** (короткочасний пік);
- Для **чистого нікелю** через високий питомий опір щільність струму не повинна перевищувати **1.2–2.0 А/мм²**.
