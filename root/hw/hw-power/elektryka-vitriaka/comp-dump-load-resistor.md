# 🔌 Баластні гальмівні резистори малої вітроустановки: розрахунок, тепловідведення, комутація

У вітроенергетичній системі баластне навантаження (Dump Load) виконує роль головного запобіжного клапана. На відміну від сонячної панелі, яку контролер заряду може будь-якої миті просто відімкнути розімкненням силового ключа, вітрогенератор без електричного струму втрачає електромагнітний опір і йде в неконтрольований рознос. Коли акумуляторна батарея повністю заряджена або інвертор аварійно вимкнувся, баластні резистори приймають на себе повну потужність генератора, перетворюючи кіловати надлишкової механічної енергії вітру на тепло.

### Фізична конструкція силових баластних елементів

Для тривалого та імпульсного розсіювання потужності у вітроустановках від 500 Вт до 10 кВт застосовують два основні класи пасивних резистивних компонентів:

1. **Трубчасті керамічні дротяні резистори (керамічні реостати):**
   - Виготовляються намотуванням ніхромового або фехралевого дроту на порожнистий керамічний каркас із високоглиноземистої кераміки чи стеатиту.
   - Дріт покривається високотемпературною склоподібною емаллю або кремнійорганічним цементом, здатним витримувати нагрів до 350–400 °C без деградації діелектричних властивостей.
   - Мають високу теплоємність керамічного тіла, що дозволяє поглинати короткочасні теплові удари під час різких шквалів без перегорання провідника.

2. **Трубчасті електронагрівачі (ТЕНи) для повітряного або водяного охолодження:**
   - Ніхромова спіраль розташована всередині герметичної трубки з неіржавної сталі або міді, щільно заповненої діелектричним порошком оксиду магнію (периклазом, MgO).
   - Водяні ТЕНи встановлюють у буферні баки опалення або гарячого водопостачання: надлишок вітрової енергії не марнується на нагрів повітря навколо щогли, а корисним чином підігріває теплоносій будівлі.

### Розрахунок номінального опору та потужності баласту

Опір баласту `R_dump` підбирають так, щоб при максимально допустимій напрузі на виході випрямляча або акумулятора `U_max` резистор міг створити струм, достатній для генерації гальмівного електромагнітного моменту, що дорівнює або перевищує пікову потужність вітроколеса `P_peak`.

Якщо баласт увімкнено на шину постійного струму DC з напругою `U_dc`, необхідний опір резистора розраховують за виразом:

```
R_dump = (U_dc_min)² / P_rated
```

де:
- `U_dc_min` — напруга на шині, при якій баласт уже повинен бути здатний утилізувати номінальну потужність вітрогенератора `P_rated`. Для 48-вольтової батареї порогу стабілізації (наприклад, 56.0 В) опір для вітряка потужністю 2000 Вт складе:

```
R_dump = (56.0 В)² / 2000 Вт = 3136 / 2000 = 1.568 Ом
```

Якщо обрати опір занадто великим (наприклад, 4.0 Ом), максимальний струм баласту `I = 56 / 4 = 14 А` забезпечить відбір лише `P = 56 · 14 = 784 Вт`. Решта 1216 Вт піде на розгін ротора і неконтрольоване зростання напруги шини понад безпечну межу.

Якщо ж обрати опір занадто малим (наприклад, 0.4 Ом), під час першого ж відкриття транзисторного ключа виникне кидок струму `I = 56 / 0.4 = 140 А`, що може перевищити максимальний імпульсний струм MOSFET або вибити запобіжники. Тому оптимізацію опору супроводжують ШІМ-регулюванням шпаруватості (Duty Cycle).

### Силова топологія комутації баласту (Low-Side Chopper)

Для плавного дозування відбору потужності застосовують транзисторний переривач (чопер) на базі N-канального MOSFET або IGBT-транзистора в нижньому плечі (Low-Side Switch).

Баластний резистор `R_dump` під'єднується між позитивною шиною живлення `DC+` та стоком (Drain) силового транзистора. Витік (Source) транзистора сідає на спільну мінусову шину `GND`.

```
           DC+ ────┬───────────────────────┐
                   │                       │
               [R_dump]                  [ C ]  Фільтруючий
                   │                  електроліт
                   ├───[ Діод Шотткі ]─────┤
                   │   (Flyback / Спад)    │
                 Drain                     │
                ┌──┴──┐                    │
   ШІМ ─────────┤ Q1  ├────────────────────┘
  (MCU)         └──┬──┘
                 Source
                   │
           GND ────┴───────────────────────
```

Ключові вимоги до компонентів каскаду:

1. **Захисний зворотний діод (Flyback Diode):**
   Потужні дротяні керамічні резистори мають помітну паразитарну індуктивність намотки `L_par` (від 5 до 50 мкГн). Під час різкого вимкнення транзистора на частоті ШІМ (1–10 кГц) енергія, накопичена в індуктивності `0.5 · L_par · I²`, створює стрибок позитивної напруги `V_spike = L_par · (dI/dt) + U_dc`. Без паралельного діода цей викид пробиває стік-витік транзистора за механізмом лавинного пробою (Avalanche Breakdown). Паралельно баласту встановлюють швидкий діод Шотткі або ультрашвидкий діод (Ultrafast Recovery), розрахований на повний робочий струм баласту.

2. **Вибір силового MOSFET:**
   Транзистор обирають із запасом за напругою `V_DS_max ≥ 1.5 · U_dc_max` та мінімальним опором відкритого каналу `R_DS(on)`. Для 48-вольтової системи використовують польові транзистори на 100–150 В з опором каналу менше 3–5 мОм у паралельному з'єднанні (2–3 транзистори на спільному радіаторі).

3. **Спадковий тепловий розрахунок радіатора:**
   На самому комутаційному транзисторі виділяються два типи втрат:
   - Статичні омічні втрати провідності: `P_cond = I_rms² · R_DS(on)`.
   - Динамічні комутаційні втрати перемикання: `P_sw = 0.5 · U_dc · I_load · (t_rise + t_fall) · f_pwm`.
   Для частоти ШІМ 2–5 кГц динамічні втрати мінімальні, що дозволяє обмежитися компактним алюмінієвим радіатором із термоопором `R_th < 1.5 °C/Вт` та примусовим обдувом вентилятором.

### Інженерні пастки при експлуатації баластних резисторів

1. **Ефект температурного коефіцієнта опору (TCR):**
   При нагріванні ніхромового дроту від 20 °C до 350 °C його електричний опір зростає на 5–10% (для фехралю — до 12%). Якщо система розрахована «впритул», розігрітий до червоного світіння баласт знижує споживаний струм, і гальмівна здатність вітроустановки під час тривалого шквалу падає саме тоді, коли вона потрібна найбільше. Розрахунок опору слід виконувати з урахуванням гарячого стану спіралі.

2. **Відмова відкритого ключа (Short-Circuit Fail):**
   Найпоширеніший вид відмови MOSFET при перегріві — пробій стоку на витік у постійне коротке замикання. Якщо ключ пробивається, баластний резистор виявляється постійно під'єднаним до батареї. За кілька годин баласт повністю висмоктує заряд акумуляторів до нуля, попутно створюючи пожежну небезпеку від безперервного нагріву.
   *Вирішення:* встановлення захисного послідовного біметалевого терморозмикача безпосередньо на корпусі резистора або аварійного контактного реле, що знеструмлює баластну секцію при виявленні струму за відсутності сигналу ШІМ.

3. **Пожежна безпека та інфрачервоне випромінювання:**
   Повітряний баластний резистор потужністю 2–3 кВт за 10 хвилин роботи нагріває металевий кожух до температури понад 200 °C. Його монтаж дозволено виключно на негорючі основи (цегла, бетон, сталевий лист) на відстані не менше 50 см від будь-яких легкозаймистих матеріалів, кабельних трас та акумуляторних батарей, які при нагріванні можуть виділяти вибухонебезпечний водень.
