# 🧮 Електромеханічний момент, ЕРС та динаміка гальмування синхронного генератора (PMSG)

Робота вітроелектричної системи базується на постійній динамічній взаємодії між двома протилежними крутильними моментами: аеродинамічним моментом вітроколеса `T_aero`, що розганяє ротор, та електромагнітним гальмівним моментом генератора `T_em`, що чинить опір обертанню під час відбору електричної потужності.

### 1. Аеродинамічний баланс потужності та моменту

Потужність повітряного потоку, що проходить крізь площу, окреслену лопатями вітроколеса радіусом `R`, становить:

```
P_wind = 0.5 · ρ · A · v³
A      = π · R²
```

де:
- `ρ` — густина повітря (за нормальних атмосферних умов на рівні моря `ρ ≈ 1.225 кг/м³`);
- `A` — ометаєма площа ротора (м²);
- `v` — лінійна швидкість вітрового потоку (м/с).

Механічна потужність, яку вітроколесо здатне відібрати з повітряного потоку, визначається безрозмірним аеродинамічним коефіцієнтом використання енергії вітру `C_p(λ, β)`:

```
P_mech = P_wind · C_p(λ, β) = 0.5 · ρ · π · R² · v³ · C_p(λ, β)
```

де:
- `λ` — швидкохідність (Tip-Speed Ratio, TSR) — відношення колової швидкості кінця лопаті до швидкості набігаючого вітрового потоку:

```
λ = (ω · R) / v
```

- `β` — кут установки лопатей (для вітряків із фіксованим кроком `β = const`);
- `ω` — механічна кутова швидкість обертання ротора (рад/с).

За [теоремою Бетца](root:hw-power/mala-vitroustanovka) теоретичний фізичний максимум коефіцієнта `C_p` становить `16/27 ≈ 0.593`. Для реальних малопотужних трилопатевих вітроколес максимум досягає `C_p,max ≈ 0.40...0.46` при строго визначеному оптимальному значенні швидкохідності `λ_opt` (зазвичай `λ_opt ≈ 6.0...7.5` залежно від аеродинамічного профілю лопаті).

Аеродинамічний крутильний момент `T_aero`, що діє на вал генератора:

```
T_aero = P_mech / ω = 0.5 · ρ · π · R³ · v² · C_T(λ)
C_T(λ) = C_p(λ) / λ
```

### 2. Виведення кубічного закону оптимальної потужності (MPPT)

Щоб вітроустановка в кожну мить часу працювала з максимальним аеродинамічним ККД `C_p,max`, контролер повинен змінювати навантаження так, щоб підтримувати сталу оптимальну швидкохідність `λ_opt`:

```
λ = λ_opt = (ω · R) / v  =>  v = (ω · R) / λ_opt
```

Підставимо вираз для швидкості вітру `v` у формулу механічної потужності:

```
P_opt = 0.5 · ρ · π · R² · v³ · C_p,max                      [вихідна формула потужності]
      = 0.5 · ρ · π · R² · ((ω · R) / λ_opt)³ · C_p,max     [підстановка v через ω]
      = [ 0.5 · ρ · π · R⁵ · (C_p,max / λ_opt³) ] · ω³      [групування констант]
```

Звідси отримуємо фундаментальний кубічний закон MPPT для вітрогенераторів:

```
P_opt(ω) = k_opt · ω³
k_opt    = 0.5 · ρ · π · R⁵ · C_p,max / (λ_opt³)
```

Відповідно, оптимальний електромагнітний момент, який генератор має створювати на валу для утримання колеса в точці максимальної потужності (OTC, Optimal Torque Control), є строго квадратичною функцією кутової швидкості:

```
T_opt(ω) = P_opt(ω) / ω = k_opt · ω²
```

### 3. Електромеханічні співвідношення PMSG

Синхронний генератор із ротором на постійних магнітах описується системою рівнянь напруги статора у фазних координатах:

```
E_ph(rms) = k_e_ph · ω = (p · ψ_f / √2) · ω
E_LL(rms) = √3 · E_ph = k_e · ω
f_e       = (p · ω) / (2 · π)
```

де:
- `p` — кількість пар магнітних полюсів ротора;
- `ψ_f` — зчеплений магнітний потік постійних магнітів (Вб);
- `k_e` — коефіцієнт проти-ЕРС генератора між двома фазами (В/(рад/с));
- `f_e` — електрична частота напруги статора (Гц).

Випрямлена напруга холостого ходу на виході трифазного шестипульсного діодного моста B6:

```
U_dc_nl = (3 · √2 / π) · E_LL(rms) ≈ 1.3505 · k_e · ω
```

Під навантаженням струмом `I_dc` напруга на виході випрямляча просідає через активний опір обмотки однієї фази `R_s`, синхронну індуктивність `L_s` та спад напруги на діодах `V_f`:

```
U_dc(I_dc) = 1.3505 · k_e · ω − 2 · V_f − I_dc · (2 · R_s + (6 · f_e · L_s) / π)
```

Електромагнітний гальмівний момент, створюваний трифазним струмом статора `I_s`:

```
T_em = 1.5 · p · ψ_f · I_q = k_t · I_s · cos(φ)
```

де `k_t` — коефіцієнт моменту (Н·м/А), `φ` — кут зсуву фаз між напругою та струмом статора.

### 4. Динамічне рівняння руху ротора та інерційний зрив

Поведінка системи в часі описується рівнянням Ньютона для обертового руху твердого тіла:

```
J · (dω / dt) = T_aero(v, ω) − T_em(I_dc) − B · ω
```

де:
- `J` — сумарний момент інерції вітроколеса, маточини та ротора генератора (кг·м²);
- `B` — коефіцієнт в'язкого механічного тертя в підшипниках (Н·м·с/рад).

Кінетична енергія, запасена в маховику вітроколеса:

```
E_kin = 0.5 · J · ω²
```

Якщо електричне навантаження зростає занадто швидко (перетворювач намагається відібрати струм `I_dc`, для якого `T_em > T_aero`), виникає гальмування `dω/dt < 0`. Частина електричної потужності відбирається не з вітру, а за рахунок спустошення кінетичної енергії `dE_kin/dt = J · ω · (dω/dt)`. Це спричиняє стрімке падіння обертів, зниження швидкохідності `λ < λ_opt`, різке зменшення аеродинамічного коефіцієнта `C_p` та повне застрягання ротора (Rotor Stall).

### 5. Аналітичний розрахунок короткозамкненого електромагнітного гальмування

Під час штормової аварійної зупинки всі три виводи статора PMSG з'єднуються між собою накоротко (`U_s = 0`).

Комплексний струм короткого замикання фази статора:

```
I_sc = E_ph / Z_s = (k_e_ph · ω) / √(R_s² + (ω_e · L_s)²)
```

де `ω_e = p · ω` — електрична кутова частота (рад/с).

Потужність омічних втрат, що виділяється в трьох фазах статора і перетворюється на тепло:

```
P_brake = 3 · I_sc² · R_s                                           [сума втрат 3 фаз]
        = 3 · [ (k_e_ph · ω)² / (R_s² + (p · ω · L_s)²) ] · R_s    [підстановка струму I_sc]
```

Електромагнітний гальмівний момент короткого замикання:

```
T_brake(ω) = P_brake / ω                                           [визначення моменту]
           = (3 · k_e_ph² · R_s · ω) / (R_s² + (p · L_s)² · ω²)   [скорочення на ω]
```

Дослідимо функцію `T_brake(ω)` на екстремум шляхом взяття похідної за `ω`:

```
dT_brake / dω = 0  =>  R_s² − (p · L_s)² · ω² = 0
```

Звідси швидкість, за якої гальмівний момент досягає абсолютного максимуму:

```
ω_peak = R_s / (p · L_s)  =>  ω_e_peak = R_s / L_s
```

Підставивши `ω_peak` у формулу моменту, отримуємо максимальний піковий гальмівний момент:

```
T_max = 1.5 · (k_e_ph² / (p · L_s)) = (3 · k_e_ph²) / (2 · p · L_s)
```

#### Граничні режими гальмування:

1. **Низькі оберти (активна зона, `ω << ω_peak`):**
   Індуктивним опором можна знехтувати `(p · ω · L_s)² << R_s²`:

```
T_brake(ω) ≈ (3 · k_e_ph² / R_s) · ω
```

Момент строго лінійно пропорційний швидкості обертання і зворотно пропорційний активному опору статора `R_s`. Чим менший опір обмоток — тим сильніше гальмує генератор.

2. **Високі оберти (індуктивна пастка розносу, `ω >> ω_peak`):**
   Омічним опором можна знехтувати `R_s² << (p · ω · L_s)²`:

```
T_brake(ω) ≈ (3 · k_e_ph² · R_s) / (p² · L_s² · ω)
```

Гальмівний момент **спадає обернено пропорційно швидкості обертання** `1/ω`. Струм короткого замикання досягає межі насичення `I_sc_max = k_e_ph / (p · L_s) = const`, а кут зсуву між струмом та ЕРС наближається до 90° (струм стає чисто індуктивним/реактивним, не створюючи корисного гальмівного моменту). Увесь струм іде на розігрів міді статора, але зупинити розігнане бурею вітроколесо такий генератор уже фізично не здатен.

### 6. Числовий інженерний приклад розрахунку вітроустановки на 2 кВт

Для закріплення взаємозв'язку між формулами розглянемо реальний інженерний розрахунок параметрів прямоприводної вітроустановки:

#### Вихідні паспортні параметри установки:
- Радіус вітроколеса: `R = 1.6 м` (ометаєма площа `A = π · 1.6² ≈ 8.04 м²`);
- Аеродинамічні характеристики: `C_p,max = 0.42` при швидкохідності `λ_opt = 6.5`;
- Генератор PMSG: 24 полюси (`p = 12`), коефіцієнт проти-ЕРС `k_e = 0.95 В/(рад/с)`;
- Параметри статора: активний опір фази `R_s = 0.42 Ом`, індуктивність `L_s = 1.8 мГн` (0.0018 Гн);
- Густина повітря: `ρ = 1.225 кг/м³`.

#### Крок 1. Розрахунок коефіцієнта кубічного MPPT:

```
k_opt = 0.5 · 1.225 · π · (1.6)⁵ · [ 0.42 / (6.5)³ ]               [підстановка параметрів]
      = 0.5 · 1.225 · 3.1416 · 10.4858 · [ 0.42 / 274.625 ]         [обчислення множників]
      = 20.174 · 0.0015293 ≈ 0.03085 Вт/(рад/с)³                   [коефіцієнт оптимуму]
```

При швидкості вітру `v = 8 м/с` оптимальна механічна кутова швидкість ротора становить:

```
ω_opt = (λ_opt · v) / R = (6.5 · 8) / 1.6 = 32.5 рад/с
n_opt = (32.5 · 60) / (2 · π) ≈ 310.3 об/хв
```

Оптимальна корисна механічна потужність вітроколеса в цій точці:

```
P_opt = k_opt · ω_opt³ = 0.03085 · (32.5)³ = 0.03085 · 34328 ≈ 1059 Вт
```

Лінійна проти-ЕРС генератора та випрямлена напруга DC-шини на холостому ході:

```
E_LL_rms = k_e · ω = 0.95 · 32.5 ≈ 30.88 В
U_dc_nl  = 1.3505 · 30.88 ≈ 41.7 В
```

#### Крок 2. Розрахунок характеристик аварійного короткого замикання:

Критична електрична швидкість перегину гальмівного моменту:

```
ω_e_peak = R_s / L_s = 0.42 Ом / 0.0018 Гн ≈ 233.33 рад/с
ω_peak   = ω_e_peak / p = 233.33 / 12 ≈ 19.44 рад/с (близько 185.6 об/хв)
```

Коефіцієнт фазної ЕРС: `k_e_ph = k_e / √3 = 0.95 / 1.732 ≈ 0.548 В/(рад/с)`.

Максимальний можливий піковий гальмівний момент:

```
T_max = (3 · k_e_ph²) / (2 · p · L_s)                [формула піку моменту]
      = (3 · 0.548²) / (2 · 12 · 0.0018)             [підстановка чисел]
      = (3 · 0.3003) / 0.0432 ≈ 20.85 Н·м            [обчислення результату]
```

#### Крок 3. Перевірка небезпеки розносу при штормовому вітрі (v = 22 м/с):

Якщо вітроколесо потрапило у шторм `v = 22 м/с` без своєчасного ввімкнення баласту і розігналося до `n = 800 об/хв` (`ω = 83.77 рад/с`), електрична частота становить `ω_e = 12 · 83.77 = 1005 рад/с`.

Аеродинамічний момент вітру на цій швидкості досягає:

```
T_aero ≈ 88.4 Н·м
```

А гальмівний електромагнітний момент короткого замикання через індуктивне згасання падає до:

```
T_brake = (3 · 0.548² · 0.42 · 83.77) / (0.42² + (1005 · 0.0018)²)   [підстановка при 800 об/хв]
        = 31.70 / (0.1764 + 3.272)                                     [проміжний знаменник]
        = 31.70 / 3.448 ≈ 9.19 Н·м                                     [гальмівний момент]
```

Оскільки `T_brake (9.19 Н·м) << T_aero (88.4 Н·м)`, електричне закорочування обмоток не зможе зупинити ротор, а струм `I_sc ≈ 25.3 А` виділить у нерухомому статорі понад `3 · 25.3² · 0.42 ≈ 806 Вт` тепла, що безперервно розігріває котушки. Зупинити вітряк у такому стані здатний виключно механічний ферлінг або дискове фрикційне гальмо.
