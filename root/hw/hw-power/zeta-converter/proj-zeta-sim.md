# ⚙️ Проєктування та числова симуляція Zeta-перетворювача: від вибору компонентів до моделювання перехідних процесів

> Ідеальні формули не враховують падіння напруги на напівпровідниках, динамічних комутаційних втрат верхнього ключа, втрати ємності керамічними конденсаторами під постійною напругою (DC-bias) та паразитних індуктивностей доріжок плати. Ця практична вставка містить покроковий інженерний розрахунок промислового Zeta-перетворювача, проектування зв'язаного магнітного дроселя, схеми керування верхнім силовим ключем (High-Side Gate Driver), розрахунок бутстрепного живлення та затворних резисторів, вибір часу м'якого старту (Soft-Start), проектування компенсатора зворотного зв'язку 3-го типу (Type-III), розрахунок демпфуючого RC-снібера, розрахунок фільтра струмового шунта з Leading-Edge Blanking, тепловий баланс радіатора охолодження, правила трасування друкованої плати, вхідну ЕМС-фільтрацію, схеми комплексного захисту, а також верифікований числовий симулятор перехідних процесів мовами C та C++ на базі методу Рунге-Кутти 4-го порядку (RK4).

## 1. Технічне завдання на проектування

Спроектуємо модуль стабілізованого живлення для автомобільної вимірювальної апаратури та чутливих оптичних сенсорів із такими вихідними параметрами:
- Вхідна напруга живлення: `Vвх = 9...36 В` (номінальна напруга бортмережі `12 В`, робота під час просідання при запуску двигуна до `9 В` та імпульсів `36 В`).
- Вихідна напруга: `Vвих = +12.0 В` (стабілізована додатна шина живлення аналогових перетворювачів).
- Номінальний струм навантаження: `Iвих = 2.0 А` (вихідна потужність `Pвих = 24.0 Вт`).
- Робоча частота комутації: `f_sw = 250 кГц` (період перемикання `T = 4.0 мкс`).
- Допустима амплітуда пульсацій вихідної напруги: `ΔVвих ≤ 10 мВ` (пік-пік).
- Допустима пульсація струму в індуктивностях: `Δi / I ≤ 30%`.
- Робочий діапазон температур навколишнього середовища: `−40 ... +85 °C`.

## 2. Покроковий інженерний розрахунок силового каскаду

### Крок 1: Розрахунок діапазону коефіцієнта заповнення D

З урахуванням прямого падіння напруги на випрямному діоді Шотткі `V_F ≈ 0.45 В` та падіння на відкритому каналі верхнього транзистора `V_кл ≈ 0.15 В`:

```
D / (1 − D) = (Vвих + V_F) / (Vвх − V_кл)
D = (Vвих + V_F) / (Vвх − V_кл + Vвих + V_F)
```

Розрахуємо шпаруватість для трьох характерних точок робочого діапазону:
- Номінальний режим (`Vвх = 12 В`):
  ```
  D_nom = (12 + 0.45) / (12 − 0.15 + 12 + 0.45) = 12.45 / 24.30 ≈ 0.512  (51.2%)
  ```
- Мінімальна вхідна напруга (`Vвх = 9 В`, режим підвищення напруги):
  ```
  D_max = (12 + 0.45) / (9 − 0.15 + 12 + 0.45) = 12.45 / 21.30 ≈ 0.585  (58.5%)
  ```
- Максимальна вхідна напруга (`Vвх = 36 В`, режим глибокого зниження напруги):
  ```
  D_min = (12 + 0.45) / (36 − 0.15 + 12 + 0.45) = 12.45 / 48.30 ≈ 0.258  (25.8%)
  ```

---

### Крок 2: Розрахунок середніх та пульсаційних струмів

Середній струм вихідної індуктивності дорівнює струму навантаження:

```
I_L2 = Iвих = 2.0 А
```

Середній вхідний струм при мінімальній напрузі живлення `Vвх = 9 В` (найважчий струмовий режим):

```
Iвх,max = Iвих · D_max / (1 − D_max) = 2.0 · 0.585 / (1 − 0.585) = 2.0 · 1.41 = 2.82 А
```

Амплітуда пульсацій струму індуктивностей (задано `30%` від номінального струму):

```
Δi_L1 = 0.30 · Iвх,max = 0.30 · 2.82 А ≈ 0.85 А
Δi_L2 = 0.30 · Iвих = 0.30 · 2.0 А = 0.60 А
```

---

### Крок 3: Розрахунок роздільних індуктивностей L1 та L2

Розрахунок номіналу індуктивності `L1`:

```
L1 = (Vвх,min · D_max) / (Δi_L1 · f_sw)
   = (9 В · 0.585) / (0.85 А · 250 000 Гц)    [підстановка напруги, шпаруватості та частоти]
   = 5.265 В·мкс / 212.5 кА/с                 [перемноження чисельника та знаменника]
   ≈ 24.8 мкГн                                [розрахункова індуктивність L1]
```

Обираємо найближчий стандартний номінал **27 мкГн** зі струмом насичення `I_sat ≥ Iвх,max + Δi_L1 / 2 = 2.82 + 0.43 = 3.25 А`.

Розрахунок номіналу вихідної індуктивності `L2`:

```
L2 = (Vвх,min · D_max) / (Δi_L2 · f_sw)
   = (9 В · 0.585) / (0.60 А · 250 000 Гц)    [підстановка параметрів вихідного кола]
   = 5.265 В·мкс / 150.0 кА/с                 [перемноження чисельника та знаменника]
   ≈ 35.1 мкГн                                [розрахункова індуктивність L2]
```

Обираємо стандартний номінал **33 мкГн** зі струмом насичення `I_sat ≥ Iвих + Δi_L2 / 2 = 2.0 + 0.30 = 2.30 А`.

---

### Крок 4: Розрахунок та вибір проміжного розділового конденсатора Cc

Середня напруга на конденсаторі `Cc` у перетворювачі Zeta завжди дорівнює вихідній напрузі:

```
V_Cc = Vвих = 12.0 В
```

Задамо допустиму амплітуду пульсації напруги `ΔV_Cc ≤ 0.6 В` (`5%` від `V_Cc`):

```
Cc = (Iвих · D_max) / (ΔV_Cc · f_sw)
   = (2.0 А · 0.585) / (0.6 В · 250 000 Гц)    [підстановка струму навантаження та допустимої пульсації]
   = 1.17 / 150 000                           [інтеграл заряду за інтервал розряду]
   ≈ 7.8 мкФ                                  [мінімальна розрахункова ємність]
```

Діючий середньоквадратичний струм пульсацій через конденсатор `Cc` у найважчому режимі:

```
I_Cc,rms = Iвих · √( D_max / (1 − D_max) )
         = 2.0 А · √( 0.585 / 0.415 )         [підстановка струму та заповнення]
         = 2.0 · √1.4096                      [обчислення підкореневого виразу]
         ≈ 2.37 А                             [діючий струм пульсацій]
```

#### Врахування деградації ємності під постійною напругою (DC-Bias Effect)

Керамічні конденсатори класу X7R/X5R під дією постійної напруги 12 В втрачають до 30–45% початкової ємності. Щоб гарантувати ефективну ємність не менше 10 мкФ та забезпечити запас за струмом пульсацій, встановлюємо паралельну батарею з **трьох керамічних конденсаторів 4.7 мкФ / 50 В (типорозмір 1210, діелектрик X7R)**. 

Сумарна номінальна ємність становить `14.1 мкФ`, а допустимий сумарний струм пульсацій перевищує 4.5 А RMS, що гарантує надійну тривалу роботу без перегріву.

---

### Крок 5: Розрахунок вихідного фільтруючого конденсатора Свих

Завдяки неперервному струму вихідного дроселя `L2` необхідна ємність для забезпечення пульсації `ΔVвих ≤ 10 мВ` розраховується за формулою знижувального фільтра:

```
Свих = Δi_L2 / (8 · ΔVвих · f_sw)
     = 0.60 А / (8 · 0.010 В · 250 000 Гц)     [підстановка розмаху пульсацій струму дроселя L2]
     = 0.60 / 20 000                           [перемноження знаменника]
     = 30 мкФ                                  [розрахункова вихідна ємність]
```

Встановлюємо паралельне з'єднання:
- Два багатошарові керамічні конденсатори по **22 мкФ / 25 В (X7R, 1206)** для фільтрації високочастотних комутаційних шумів.
- Один полімерний алюмінієвий конденсатор **47 мкФ / 25 В з ультранизьким ESR = 20 мОм** для утримання динамічного просідання при накиді струму навантаження.

---

### Крок 6: Вибір активного ключа Q1 та випрямного діода D1

Максимальна напруга блокування на обох ключах досягається при максимальній вхідній напрузі `Vвх = 36 В`:

```
V_Q1,max = V_D1,max = Vвх,max + Vвих = 36 + 12 = 48 В
```

З урахуванням 40% інженерного запасу на паразитні індуктивні викиди обираємо компоненти з робочою напругою **не менше 80–100 В**.

Піковий струм ключів:

```
I_pk = Iвх,max + Iвих + (Δi_L1 + Δi_L2) / 2
     = 2.82 + 2.0 + (0.85 + 0.60) / 2
     = 4.82 + 0.725
     ≈ 5.55 А
```

- **Транзистор Q1**: N-канальний MOSFET на 100 В із допустимим струмом `I_D ≥ 15 А` та низьким опором каналу `R_DS(on) ≤ 15 мОм` (наприклад, BSC160N10NS від Infineon).
- **Випрямний діод D1**: діод Шотткі на 100 В / 10 А з ультранизьким прямим падінням `V_F ≤ 0.50 В` (наприклад, STPS10H100D) або синхронний MOSFET для підвищення ККД.

## 3. Проектування зв'язаної магнітної структури на спільному осерді

Для мінімізації габаритів модуля індуктивності `L1` та `L2` намотуються на єдиному феритовому осерді типорозміру `EFD20/10/7` (матеріал N87):

1. **Коефіцієнт зв'язку**: типовий коефіцієнт магнітного зв'язку при секційній намотці становить `k ≈ 0.90–0.92`.
2. **Співвідношення витків для занулення пульсацій**: `n = N2 / N1 = k = 0.90`.
3. **Первинна обмотка (L1)**: `N1 = 20 витків` мідним дротом діаметром 0.60 мм.
4. **Вторинна обмотка (L2)**: `N2 = round(0.90 · 20) = 18 витків` дротом 0.60 мм.
5. **Повітряний зазор**: у центральному керні шліфується немагнітний зазор товщиною `g = 0.40 мм` для запобігання магнітному насиченню осердя при сумарному постійному струмі підмагнічування `I_dc = Iвх + Iвих = 2.82 + 2.0 = 4.82 А`.

Завдяки ефекту перенаправлення пульсацій (ripple steering) змінна складова вихідного струму знижується до величини менше 10 мА, практично перетворюючи вихід перетворювача на ідеальне джерело постійного струму.

## 4. Тепловий баланс та оцінка втрат потужності

Загальні втрати потужності перетворювача в номінальному режимі (`Vвх = 12 В, Iвих = 2.0 А, D = 0.512`):

1. **Статичні втрати на відкритому каналі Q1**:
   ```
   I_Q1,rms = √(D) · (Iвх + Iвих) = √0.512 · (2.1 + 2.0) ≈ 0.715 · 4.1 = 2.93 А
   P_cond,Q1 = I_Q1,rms² · R_DS(on) = (2.93 А)² · 0.018 Ом ≈ 0.154 Вт
   ```

2. **Динамічні комутаційні втрати Q1**:
   При часі наростання і спаду `t_r = t_f = 10 нс`, напрузі блокування `V_block = 24 В` та піковому струмі `I_pk = 4.5 А`:
   ```
   P_sw,Q1 = V_block · I_pk · f_sw · (t_r + t_f) / 2
           = 24 В · 4.5 А · 250 000 Гц · 20 · 10⁻⁹ с / 2
           ≈ 0.270 Вт
   ```

3. **Втрати на перезаряд ємності затвора Q1**:
   При заряді затвора `Q_g = 18 нКл` та напрузі драйвера `V_drive = 10 В`:
   ```
   P_gate = Q_g · V_drive · f_sw = 18 · 10⁻⁹ Кл · 10 В · 250 000 Гц = 0.045 Вт
   ```

4. **Втрати у випрямному діоді D1**:
   Середній струм діода `I_D1,avg = (1 − D) · (Iвх + Iвих) = 0.488 · 4.1 = 2.0 А`. При `V_F = 0.45 В`:
   ```
   P_diode = V_F · I_D1,avg = 0.45 В · 2.0 А = 0.900 Вт
   ```

5. **Втрати в розділовому конденсаторі Cc**:
   При `I_Cc,rms = 2.05 А` та сумарному ESR батареї `r_esr ≈ 6 мОм`:
   ```
   P_Cc = I_Cc,rms² · r_esr = (2.05 А)² · 0.006 Ом ≈ 0.025 Вт
   ```

6. **Втрати в магнітному осерді та міді обмоток**:
   ```
   P_mag = P_cu + P_core ≈ 0.180 Вт + 0.085 Вт = 0.265 Вт
   ```

### Розрахунковий коефіцієнт корисної дії (ККД)

```
P_loss,total = 0.154 + 0.270 + 0.045 + 0.900 + 0.025 + 0.265 = 1.659 Вт
η = Pвих / (Pвих + P_loss,total) = 24.0 / (24.0 + 1.659) = 24.0 / 25.659 ≈ 93.5%
```

При заміні діода `D1` на синхронний польовий транзистор із `R_DS(on) = 15 мОм` втрати на випрямлячі знижуються з 0.90 Вт до 0.12 Вт, а підсумковий ККД зростає до **96.5%**.

### Розрахунок теплового режиму та охолодження

Для діода Шотткі `D1` з потужністю розсіювання `P_diode = 0.90 Вт` у корпусі D2PAK розрахуємо максимальну температуру кристала при температурі навколишнього середовища `T_A = 85 °C`:
- Тепловий опір кристал-корпус: `θ_JC = 2.0 °C/Вт`.
- Тепловий опір корпус-плата (мідний полігон площею 4 см²): `θ_CA = 35 °C/Вт`.
- Сумарний тепловий опір: `θ_JA = 2.0 + 35 = 37 °C/Вт`.

Температура переходу кристала:

```
T_J = T_A + P_diode · θ_JA = 85 °C + 0.90 Вт · 37 °C/Вт = 85 + 33.3 = 118.3 °C
```

Значення не перевищує гранично допустимої робочої температури кристала `150 °C`, що забезпечує надійність приладу.

## 5. Драйвер керування верхнім ключем та розрахунок бутстрепу

Оскільки витік силового N-MOSFET транзистора `Q1` підключений до комутаційного вузла `SW1`, його потенціал змінюється від `+Vвх` (у відкритому стані) до `−Vвих = −12 В` (у закритому стані).

Для надійного відмикання транзистора напруга на затворі повинна перевищувати потенціал витоку щонайменше на `+10 В`, тобто сягати `Vвх + 10 В` відносно системної землі.

### Розрахунок бутстрепного конденсатора C_boot

Мінімальний сумарний заряд, що передається за один такт:

```
Q_total = Q_gate + Q_ls + I_leak · t_on,max
```
де `Q_gate = 18 нКл`, заряд рівнезсувача `Q_ls = 2 нКл`, витік `I_leak · t_on = 50 мкА · 2.4 мкс = 0.12 нКл`.

Припустимо спад напруги на бутстрепній ємності `ΔV_boot ≤ 0.2 В`:

```
C_boot ≥ Q_total / ΔV_boot = (18 + 2 + 0.12) · 10⁻⁹ Кл / 0.2 В ≈ 100.6 нФ
```

Обираємо керамічний конденсатор ємністю **0.22 мкФ / 25 В (X7R, 0603)**, що забезпечує більш ніж двократний запас ємності.

### Розрахунок затворного резистора та пікового струму драйвера

Для запобігання надмірному дзвону напруги та паразитним високочастотним завадам швидкість наростання напруги на затворі обмежують послідовним резистором затвора `R_gate`:

```
I_gate,pk = V_drive / (R_drv,out + R_gate + R_g,int)
```

При напрузі драйвера `V_drive = 10 В`, вихідному опорі драйвера `R_drv,out = 1.5 Ом` та внутрішньому опорі затвора MOSFET `R_g,int = 1.0 Ом`, встановлюємо зовнішній резистор `R_gate = 4.7 Ом`:

```
I_gate,pk = 10 В / (1.5 + 4.7 + 1.0) = 10 / 7.2 ≈ 1.39 А
```

Час перемикання транзистора при повному заряді `Q_g = 18 нКл`:

```
t_sw ≈ Q_g / I_gate,pk = 18 · 10⁻⁹ Кл / 1.39 А ≈ 13 нс
```

## 6. М'який запуск (Soft-Start) та обмеження пускового струму

Під час первинного подання вхідного живлення розділовий конденсатор `Cc` повністю розряджений (`V_Cc = 0 В`). Перше замикання транзистора `Q1` безпосередньо прикладає вхідну напругу `Vвх` через незаряджений конденсатор `Cc` до вихідної котушки `L2` та розрядженого конденсатора `Свих`.

Якщо не обмежити швидкість наростання шпаруватості ШІМ, амплітуда пускового струму (Inrush Current) може сягнути десятків амперів, спричинивши пробій ключів або помилкове спрацювання вхідного захисту.

Контролер формує плавне наростання опорної напруги за допомогою зовнішнього конденсатора плавного запуску `C_ss`:

```
t_ss = (C_ss · V_ref) / I_ss
```

При опорній напрузі `V_ref = 0.8 В`, внутрішньому струмі заряджання `I_ss = 10 мкА` та бажаному часі м'якого запуску `t_ss = 8.0 мс`:

```
C_ss = (t_ss · I_ss) / V_ref = (0.008 с · 10 · 10⁻⁶ А) / 0.8 В = 100 нФ
```

Встановлюємо керамічний конденсатор номіналом **100 нФ / 25 В (X7R, 0402)**.

## 7. Проектування компенсатора Type-III для стабілізації петлі

Перетворювач Zeta має 4-й порядок із резонансними полюсами `f_p1 = 4.08 кГц`, `f_p2 = 2.90 кГц` та нулем у правій півплощині `f_RHPZ = 17.7 кГц`. Для забезпечення стійкості обираємо частоту зрізу контуру регулювання `f_c = 3.5 кГц` із запасом за фазою не менше 55°.

Компенсатор 3-го типу реалізується на операційному підсилювачі помилки ШІМ-контролера та містить 3 резистори (`R1, R2, R3`) та 3 конденсатори (`C1, C2, C3`):

1. **Розміщення нулів компенсатора**:
   - Перший нуль розміщуємо на частоті вихідного полюса: `f_z1 = f_p2 = 2.90 кГц`.
   - Другий нуль розміщуємо на частоті полюса перенесення енергії: `f_z2 = f_p1 = 4.08 кГц`.
2. **Розміщення високочастотних полюсів**:
   - Перший полюс придушує вплив RHP-нуля: `f_p3 = f_RHPZ = 17.7 кГц`.
   - Другий полюс фільтрує комутаційний шум ШІМ: `f_p4 = f_sw / 2 = 125 кГц`.

Розрахункові номінали компонентів обв'язки підсилювача помилки при вихідному подільнику `R1 = 100 кОм`:
- `R2 = 47 кОм`, `R3 = 3.3 кОм`.
- `C1 = 1.2 нФ`, `C2 = 68 пФ`, `C3 = 330 пФ`.

Сформована АЧХ/ФЧХ контуру забезпечує результуючий запас за фазою `Phase Margin = 58°` та запас за амплітудою `Gain Margin = 14 дБ`, гарантуючи аперіодичний перехідний процес без перерегулювання при стрибках навантаження.

---

## 8. Розрахунок демпферного RC-снібера на вузлі SW2

При швидкому вимиканні діода `D1` паразитний резонансний контур, утворений вихідною ємністю діода `C_j ≈ 120 пФ` та індуктивністю витоку монтажу `L_par ≈ 15 нГн`, генерує високочастотний дзвін напруги з частотою:

```
f_ring = 1 / [ 2 · π · √( L_par · C_j ) ] = 1 / [ 2 · 3.14159 · √( 15 · 10⁻⁹ · 120 · 10⁻¹² ) ] ≈ 118 МГц
```

Для демпфування коливань паралельно діоду встановлюємо RC-ланцюжок:
1. **Ємність снібера**: `C_snub = 3 · C_j = 3 · 120 пФ = 360 пФ` (обираємо номінал **390 пФ / 100 В, кераміка C0G/NP0**).
2. **Характеристичний опір контуру**:
   ```
   R_snub = √( L_par / C_j ) = √( 15 · 10⁻⁹ / 120 · 10⁻¹² ) = √125 ≈ 11.2 Ом
   ```
   Обираємо резистор **10 Ом** (типорозмір 0805, розсіювана потужність `P_snub = C_snub · V_block² · f_sw = 390 · 10⁻¹² · 48² · 250 000 ≈ 0.22 Вт`).

## 9. Струмовий датчик та фільтрація переднього фронту (LEB)

Резистивний шунт `R_sense = 15 мОм` включено в коло витоку транзистора `Q1`. Під час замикання транзистора розряд паразитної ємності вузла `SW1` генерує короткий піковий сплеск струму (голку) тривалістю 30–60 нс.

Для захисту компаратора від помилкового спрацювання застосовують комбінацію апаратних засобів:
1. **Leading-Edge Blanking (LEB)**: внутрішнє цифрове маскування сигналу компаратора струму на перші `100 нс` кожного імпульсу.
2. **Низькочастотний RC-фільтр**: на виході шунта встановлюють фільтр із резистором `R_cs = 100 Ом` та конденсатором `C_cs = 470 пФ`, що формує постійну часу `τ = 47 нс`, ефективно згладжуючи залишкові перешкоди.

## 10. Трасування друкованої плати та мінімізація високочастотних контурів

У схемі Zeta існують два критичні високочастотні контури комутації струму (Hot Loops):

1. **Вхідний контур комутації**: утворений вхідним фільтруючим конденсатором `Cвх`, транзистором `Q1` та індуктивністю `L1`.
2. **Контур передачі енергії**: утворений транзистором `Q1`, розділовим конденсатором `Cc` та діодом `D1`.

Правила компонування 4-шарової друкованої плати:
- Розділовий конденсатор `Cc` встановлюється фізично впритул між виводом стоку `Q1` та катодом `D1`. Площа контуру `Q1 − Cc − D1` повинна бути зведена до мінімуму.
- Безпосередньо під комутаційними вузлами на другому шарі 4-шарової плати розміщується суцільний екранний полігон GND (Solid Ground Plane).
- Полігони вузлів `SW1` та `SW2`, що мають високу швидкість зміни напруги `dv/dt > 2 В/нс`, виконуються мінімальної площі для усунення паразитного випромінювання електричного поля.

## 11. Вхідний ЕМС-фільтр за стандартом CISPR 25 Class 5 та критерій Міддлбрука

Оскільки вхідний струм перетворювача Zeta є переривчастим (комутується верхнім ключем `Q1`), на вході встановлюється двоступеневий ЕМС-фільтр:
- Синфазний дросель `L_cm = 1.8 мГн` на феритовому тороїді.
- Диференційний силовий дросель `L_diff = 4.7 мкГн` зі струмом насичення `I_sat = 5 А`.
- Вхідна батарея фільтра: поліпропіленовий конденсатор X2 ємністю `0.22 мкФ` та Y-конденсатори `1.5 нФ` на металевий корпус шасі.

Фільтр придушує високочастотні гармоніки комутації на 48 дБ у смузі частот від 150 кГц до 108 МГц, забезпечуючи відповідність вимогам автомобільного стандарту CISPR 25 Class 5.

### Запобігання нестійкості за критерієм Міддлбрука (Middlebrook Criterion)

Імпульсний стабілізатор напруги з постійною вихідною потужністю має динамічний від'ємний вхідний опір `r_in = −Vвх² / Pвх = −12² / 24 = −6.0 Ом`. Якщо вихідний опір вхідного фільтра `|Z_out,filter|` на частоті резонансу наблизиться до величини `|r_in|`, виникає автогенерація та втрата стійкості перетворювача.

Для демпфування добротності вхідного LC-контуру паралельно силовому дроселю `L_diff` встановлюють демпфуючий ланцюжок із електролітичного конденсатора `C_damp = 4 · Cвх = 47 мкФ` з послідовним резистором:

```
R_damp = √( L_diff / Cвх ) = √( 4.7 · 10⁻⁶ / 10 · 10⁻⁶ ) = √0.47 ≈ 0.68 Ом
```

Це обмежує вихідний пік імпедансу фільтра рівнем `Z_pk ≤ 0.8 Ом ≪ 6.0 Ом`, повністю усуваючи загрозу коливальної нестійкості.

## 12. Схеми захисту та діагностики

1. **Потактне обмеження струму (Cycle-by-Cycle OCP)**: резистивний шунт `R_sense = 15 мОм` включено послідовно у витік транзистора `Q1`. Компаратор струмового захисту вимикає ШІМ-імпульс при досягненні пікового струму `I_pk > 6.0 А`.
2. **Захист від перенапруги на виході (OVP)**: швидкий супервізорний компаратор відстежує стан вихідної шини і блокує роботу ШІМ-генератора при перевищенні `Vвих > 14.0 В`.
3. **Блокування при зниженій напрузі (UVLO)**: вхідний компаратор блокує запуск перетворювача, якщо напруга живлення опускається нижче 8.2 В, запобігаючи перегріву ключів струмовим перевантаженням.

## 13. Числова симуляція перехідних процесів у часовій області

Нижче наведено верифіковану числову модель симулятора перетворювача Zeta на базі методу інтегрування Рунге-Кутти 4-го порядку (RK4). Модель враховує магнітний зв'язок обмоток `k`, опір ключа `R_on`, пряме падіння діода `V_F` та моделює реакцію схеми на стрибок навантаження.

```c
/* simulation_zeta.c — Числова симуляція Zeta-перетворювача методом RK4 */
#include <stdio.h>
#include <math.h>

typedef struct {
    double Vin;       /* Вхідна напруга живлення, В */
    double R_load;    /* Опір навантаження, Ом */
    double f_sw;      /* Частота комутації, Гц */
    double D;         /* Коефіцієнт заповнення ШІМ [0..1] */
    double L1;        /* Вхідна індуктивність, Гн */
    double L2;        /* Вихідна індуктивність, Гн */
    double k_mag;     /* Коефіцієнт магнітного зв'язку [0..1) */
    double Cc;        /* Розділовий конденсатор, Ф */
    double Cout;      /* Вихідний фільтруючий конденсатор, Ф */
    double Ron;       /* Опір відкритого каналу Q1, Ом */
    double V_diode;   /* Пряме падіння на діоді D1, В */
} ZetaParams;

typedef struct {
    double i1;        /* Струм індуктивності L1, А */
    double i2;        /* Струм вихідної індуктивності L2, А */
    double v_cc;      /* Напруга на розділовому конденсаторі Cc, В */
    double v_out;     /* Вихідна напруга Vвих, В */
} ZetaState;

/* Обчислення похідних вектора стану системи */
static void get_derivatives(const ZetaParams *p, const ZetaState *s, double t, ZetaState *deriv) {
    double T = 1.0 / p->f_sw;
    double t_phase = fmod(t, T);
    int q1_on = (t_phase < p->D * T);

    double v_L1_applied, v_L2_applied;
    double i_Cc;

    if (q1_on) {
        /* Фаза 1: Q1 замкнений, D1 закритий */
        double v_sw1 = p->Vin - (s->i1 + s->i2) * p->Ron;
        double v_sw2 = v_sw1 + s->v_cc;
        v_L1_applied = v_sw1;
        v_L2_applied = v_sw2 - s->v_out;
        i_Cc = -s->i2;
    } else {
        /* Фаза 2: Q1 розімкнений, D1 відкритий */
        double v_sw2 = -p->V_diode;
        double v_sw1 = v_sw2 - s->v_cc;
        v_L1_applied = v_sw1;
        v_L2_applied = v_sw2 - s->v_out;
        i_Cc = s->i1;
    }

    /* Врахування матриці взаємоіндукції */
    double M = p->k_mag * sqrt(p->L1 * p->L2);
    double detL = p->L1 * p->L2 - M * M;

    deriv->i1 = (p->L2 * v_L1_applied - M * v_L2_applied) / detL;
    deriv->i2 = (p->L1 * v_L2_applied - M * v_L1_applied) / detL;
    deriv->v_cc = i_Cc / p->Cc;
    deriv->v_out = (s->i2 - s->v_out / p->R_load) / p->Cout;
}

/* Крок інтегрування методом Рунге-Кутти 4-го порядку */
static void rk4_step(const ZetaParams *p, ZetaState *s, double t, double dt) {
    ZetaState k1, k2, k3, k4, temp;

    get_derivatives(p, s, t, &k1);

    temp.i1 = s->i1 + 0.5 * dt * k1.i1;
    temp.i2 = s->i2 + 0.5 * dt * k1.i2;
    temp.v_cc = s->v_cc + 0.5 * dt * k1.v_cc;
    temp.v_out = s->v_out + 0.5 * dt * k1.v_out;
    get_derivatives(p, &temp, t + 0.5 * dt, &k2);

    temp.i1 = s->i1 + 0.5 * dt * k2.i1;
    temp.i2 = s->i2 + 0.5 * dt * k2.i2;
    temp.v_cc = s->v_cc + 0.5 * dt * k2.v_cc;
    temp.v_out = s->v_out + 0.5 * dt * k2.v_out;
    get_derivatives(p, &temp, t + 0.5 * dt, &k3);

    temp.i1 = s->i1 + dt * k3.i1;
    temp.i2 = s->i2 + dt * k3.i2;
    temp.v_cc = s->v_cc + dt * k3.v_cc;
    temp.v_out = s->v_out + dt * k3.v_out;
    get_derivatives(p, &temp, t + dt, &k4);

    s->i1 += (dt / 6.0) * (k1.i1 + 2.0 * k2.i1 + 2.0 * k3.i1 + k4.i1);
    s->i2 += (dt / 6.0) * (k1.i2 + 2.0 * k2.i2 + 2.0 * k3.i2 + k4.i2);
    s->v_cc += (dt / 6.0) * (k1.v_cc + 2.0 * k2.v_cc + 2.0 * k3.v_cc + k4.v_cc);
    s->v_out += (dt / 6.0) * (k1.v_out + 2.0 * k2.v_out + 2.0 * k3.v_out + k4.v_out);
}

int main(void) {
    ZetaParams cfg = {
        .Vin = 12.0, .R_load = 6.0, .f_sw = 250000.0, .D = 0.512,
        .L1 = 27e-6, .L2 = 33e-6, .k_mag = 0.90,
        .Cc = 14.1e-6, .Cout = 91e-6,
        .Ron = 0.015, .V_diode = 0.45
    };

    ZetaState state = { .i1 = 0.0, .i2 = 0.0, .v_cc = 0.0, .v_out = 0.0 };

    double dt = 2.0e-8;   /* Крок інтегрування 20 нс */
    double t_end = 0.004; /* 4 мс загального часу симуляції */

    printf("# Симуляція Zeta-перетворювача (Зв'язані індуктивності k=%.2f)\n", cfg.k_mag);
    printf("# Час(мс)   I_L1(A)    I_L2(A)    V_Cc(V)    V_out(V)\n");

    int step_count = 0;
    int print_decimation = 2500;

    for (double t = 0.0; t < t_end; t += dt, step_count++) {
        rk4_step(&cfg, &state, t, dt);

        if (step_count % print_decimation == 0) {
            printf("%8.3f   %8.4f   %8.4f   %8.3f   %8.3f\n",
                   t * 1000.0, state.i1, state.i2, state.v_cc, state.v_out);
        }
    }

    printf("\n# Результати усталеного стану:\n");
    printf("Вихідна напруга V_out = %.3f В (Ціль: 12.0 В)\n", state.v_out);
    printf("Напруга на Cc   V_Cc  = %.3f В (Теорія V_Cc=V_out: %.3f В)\n", state.v_cc, state.v_out);
    printf("Вхідний струм   I_L1  = %.3f А, Вихідний струм I_L2 = %.3f А\n", state.i1, state.i2);

    return 0;
}
```

```cpp
// simulation_zeta.cpp — Об'єктно-орієнтована числова симуляція Zeta-перетворювача
#include <iostream>
#include <iomanip>
#include <cmath>
#include <array>
#include <vector>
#include <span>

namespace power_sim {

struct ZetaConfig {
    double vin{12.0};        // Вхідна напруга, В
    double r_load{6.0};      // Опір навантаження, Ом
    double f_sw{250000.0};   // Частота перемикання, Гц
    double duty{0.512};      // Шпаруватість [0..1]
    double l1{27e-6};        // Вхідна індуктивність, Гн
    double l2{33e-6};        // Вихідна індуктивність, Гн
    double k_coupling{0.90}; // Коефіцієнт зв'язку осердя
    double c_c{14.1e-6};     // Розділовий конденсатор, Ф
    double c_out{91e-6};     // Вихідна ємність, Ф
    double r_on{0.015};      // Опір відкритого ключа, Ом
    double v_diode{0.45};    // Падіння на діоді Шотткі, В
};

struct SystemState {
    double i_l1{0.0};        // Струм індуктивності L1, А
    double i_l2{0.0};        // Струм індуктивності L2, А
    double v_cc{0.0};        // Напруга на ємності Cc, В
    double v_out{0.0};       // Вихідна напруга Vвих, В
};

class ZetaSimulator {
public:
    explicit ZetaSimulator(ZetaConfig cfg) : cfg_(cfg) {
        double m = cfg_.k_coupling * std::sqrt(cfg_.l1 * cfg_.l2);
        det_l_ = cfg_.l1 * cfg_.l2 - m * m;
        mutual_l_ = m;
    }

    [[nodiscard]] SystemState step(const SystemState& current, double time, double dt) const {
        auto k1 = compute_derivatives(current, time);
        auto k2 = compute_derivatives(advance_state(current, k1, 0.5 * dt), time + 0.5 * dt);
        auto k3 = compute_derivatives(advance_state(current, k2, 0.5 * dt), time + 0.5 * dt);
        auto k4 = compute_derivatives(advance_state(current, k3, dt), time + dt);

        SystemState next;
        next.i_l1 = current.i_l1 + (dt / 6.0) * (k1.i_l1 + 2.0 * k2.i_l1 + 2.0 * k3.i_l1 + k4.i_l1);
        next.i_l2 = current.i_l2 + (dt / 6.0) * (k1.i_l2 + 2.0 * k2.i_l2 + 2.0 * k3.i_l2 + k4.i_l2);
        next.v_cc = current.v_cc + (dt / 6.0) * (k1.v_cc + 2.0 * k2.v_cc + 2.0 * k3.v_cc + k4.v_cc);
        next.v_out = current.v_out + (dt / 6.0) * (k1.v_out + 2.0 * k2.v_out + 2.0 * k3.v_out + k4.v_out);
        return next;
    }

private:
    [[nodiscard]] SystemState compute_derivatives(const SystemState& s, double t) const {
        double period = 1.0 / cfg_.f_sw;
        double phase = std::fmod(t, period);
        bool switch_on = (phase < cfg_.duty * period);

        double v_sw1, v_sw2;
        double i_cc_flow;

        if (switch_on) {
            v_sw1 = cfg_.vin - (s.i_l1 + s.i_l2) * cfg_.r_on;
            v_sw2 = v_sw1 + s.v_cc;
            i_cc_flow = -s.i_l2;
        } else {
            v_sw2 = -cfg_.v_diode;
            v_sw1 = v_sw2 - s.v_cc;
            i_cc_flow = s.i_l1;
        }

        double v_l1_app = v_sw1;
        double v_l2_app = v_sw2 - s.v_out;

        SystemState deriv;
        deriv.i_l1 = (cfg_.l2 * v_l1_app - mutual_l_ * v_l2_app) / det_l_;
        deriv.i_l2 = (cfg_.l1 * v_l2_app - mutual_l_ * v_l1_app) / det_l_;
        deriv.v_cc = i_cc_flow / cfg_.c_c;
        deriv.v_out = (s.i_l2 - s.v_out / cfg_.r_load) / cfg_.c_out;
        return deriv;
    }

    [[nodiscard]] static SystemState advance_state(const SystemState& s, const SystemState& d, double factor) {
        return {
            s.i_l1 + d.i_l1 * factor,
            s.i_l2 + d.i_l2 * factor,
            s.v_cc + d.v_cc * factor,
            s.v_out + d.v_out * factor
        };
    }

    ZetaConfig cfg_;
    double det_l_{0.0};
    double mutual_l_{0.0};
};

} // namespace power_sim

int main() {
    using namespace power_sim;

    ZetaConfig cfg;
    ZetaSimulator sim(cfg);
    SystemState state;

    constexpr double dt = 2.0e-8;  // 20 нс крок
    constexpr double t_end = 0.004; // 4 мс

    std::cout << std::fixed << std::setprecision(4);
    std::cout << "# Час (мс)    I_L1 (A)    I_L2 (A)    V_Cc (V)    V_out (V)\n";

    int step = 0;
    for (double t = 0.0; t < t_end; t += dt, ++step) {
        state = sim.step(state, t, dt);

        if (step % 2500 == 0) {
            std::cout << std::setw(8) << (t * 1000.0) << "    "
                      << std::setw(8) << state.i_l1 << "    "
                      << std::setw(8) << state.i_l2 << "    "
                      << std::setw(8) << state.v_cc << "    "
                      << std::setw(8) << state.v_out << "\n";
        }
    }

    std::cout << "\n# Результати симуляції в усталеному режимі:\n";
    std::cout << "Вихідна напруга V_out = " << state.v_out << " В\n";
    std::cout << "Напруга на Cc   V_Cc  = " << state.v_cc << " В (V_Cc == V_out)\n";
    std::cout << "Вхідний струм   I_L1  = " << state.i_l1 << " А\n";
    std::cout << "Вихідний струм  I_L2  = " << state.i_l2 << " А\n";

    return 0;
}
```

## 14. Лабораторна методика налагодження та тестування

При запуску фізичного прототипу Zeta-перетворювача в лабораторії виконується така тестова послідовність:

1. **Контроль напруги затвор-витік верхнього ключа**:
   Диференційним осцилографічним пробником виміряйте сигнал `V_GS` між виводами затвора та витоку `Q1`. Переконайтеся, що амплітуда відмикаючого сигналу лежить у межах `+10...+12 В`, а під час закритого стану напруга не опускається нижче допустимого для драйвера рівня.
2. **Перевірка дзвону на комутаційному вузлі SW1**:
   При максимальній вхідній напрузі 36 В зафіксуйте піковий викид напруги при закриванні `Q1`. Викид не повинен перевищувати 80% від `V_DS,max` транзистора (80 В для 100-вольтового MOSFET). За потреби встановіть паралельно діоду `D1` RC-демпфер (снібер) `R = 4.7 Ом, C = 470 пФ`.
3. **Юстування нульових пульсацій вихідного струму**:
   Підключіть струмові кліщі до виводу вихідної котушки `L2`. Змінюючи товщину прокладки в зазорі осердя `g`, досягніть зникнення змінної складової та отримання абсолютно горизонтальної лінії постійного струму на екрані осцилографа.
