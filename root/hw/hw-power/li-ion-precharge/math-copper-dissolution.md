# 🧮 Електрохімічний поріг розчинення міді та тепловий розрахунок передзаряду

Коли напруга літієвої комірки падає нижче критичної межі 2.0–2.5 В, усередині змінюється термодинамічний баланс: матеріал струмоприймача, який роками вважався абсолютно пасивним, починає хімічно руйнуватися. Математичний і електрохімічний аналіз показує, як за значеннями потенціалів електродів розрахувати точну межу анодної корозії міді, чому швидкість зарядного струму визначає форму її повторного осадження — планарний шар чи гострі дендрити, — та як обчислити тепловий бюджет і безпечне часове вікно попереднього заряду.

### Термодинамічні потенціали електродів та опорна шкала літію

Усі електрохімічні реакції в літій-іонному джерелі струму кількісно описуються відносно стандартного водневого електрода (SHE) або зручнішої для акумуляторної галузі шкали відліку відносно металічного літію (`Li/Li⁺`).

Стандартний електродний потенціал літію є найнижчим серед усіх металів:

```
E°(Li⁺/Li) = −3.040 В відносно SHE
```

Під час нормальної роботи комірки графітовий анод (від грец. *ánodos* — рух угору) перебуває у стані високого насичення інтеркальованим літієм (`LiC6` або `LiC12`). Завдяки наявності металізованих зв'язків літію в графітовій матриці потенціал робочого графітового електрода залишається надзвичайно низьким:

```
φ_anode(робочий) ≈ +0.05...+0.20 В відносно Li/Li⁺
```

Струмоприймачем негативного електрода слугує тонка мідна фольга (завтовшки 6–10 мкм). Мідь обрано тому, що вона не утворює інтерметалідів із літієм за низьких потенціалів (на відміну від алюмінію, який при `φ < 0.3 В` легується літієм з руйнуванням кристалічної ґратки).

Окиснення міді в неводних апротонних органічних електролітах (на основі етиленкарбонату `EC` та диметилкарбонату `DMC` із сіллю `LiPF6`) описується двома послідовними реакціями переходу:

```
Cu ⇄ Cu⁺ + e⁻        [одноосновне окиснення, утворення розчинного комплексу]
Cu⁺ ⇄ Cu²⁺ + e⁻      [двоосновне окиснення]
Cu ⇄ Cu²⁺ + 2e⁻      [сумарна анодна реакція]
```

Термодинамічні стандартні потенціали цих напівреакцій у неводному органічному середовищі становлять:

```
E°(Cu⁺/Cu)  = +0.52 В відносно SHE = +3.56 В відносно Li/Li⁺
E°(Cu²⁺/Cu) = +0.34 В відносно SHE = +3.38 В відносно Li/Li⁺
E°(Cu²⁺/Cu⁺)= +0.16 В відносно SHE = +3.20 В відносно Li/Li⁺
```

Для довільних концентрацій іонів міді в електроліті рівноважний потенціал окиснення міді описується рівнянням Нернста (англ. *Nernst equation*):

```
E_eq(Cu²⁺/Cu)
= E°(Cu²⁺/Cu) + (R · T / (z · F)) · ln(a_Cu²⁺)    [рівняння Нернста для мідного електрода]
= 3.38 + (8.314 · 298.15 / (2 · 96485)) · ln(a_Cu²⁺) [підстановка R, T=298.15 K, z=2, F]
= 3.38 + 0.01284 · ln(a_Cu²⁺)                     [розрахунок теплового множника]
= 3.38 + 0.02956 · log₁₀(a_Cu²⁺)                  [перехід до десяткового логарифма]
```

Де:
- `R = 8.314 Дж/(моль·К)` — універсальна газова стала;
- `T = 298.15 К` — абсолютна температура (25 °C);
- `z = 2` — кількість електронів, що беруть участь у реакції окиснення міді;
- `F = 96485 Кл/моль` — стала Фарадея (від лат. *constans* — незмінний);
- `a_Cu²⁺` — активність іонів міді в розчині електроліту.

Навіть якщо початкова концентрація іонів міді в чистому електроліті мізерно мала (наприклад, активність дорівнює `10⁻⁶ моль/л` через фонові домішки):

```
E_eq(Cu²⁺/Cu, 10⁻⁶)
= 3.38 + 0.02956 · log₁₀(10⁻⁶) [підстановка активності 10⁻⁶]
= 3.38 + 0.02956 · (−6)         [обчислення логарифма]
= 3.38 − 0.177                 [множення на нахил Нернста]
= 3.203 В відносно Li/Li⁺      [поріг початку анодного розчинення]
```

Це означає: щойно локальний електрохімічний потенціал поверхні графітового електрода піднімається вище `+3.20...+3.38 В` відносно `Li/Li⁺`, металічна мідь струмоприймача перетворюється на термодинамічно нестабільну фазу й починає спонтанно окиснюватися з виходом іонів `Cu²⁺` у рідкий електроліт.

### Зсув потенціалів при надглибокому розряді

Повна напруга на клемах акумуляторної комірки `U_cell` є різницею потенціалів між позитивним електродом (катодом, від грец. *káthodos* — рух униз) та негативним електродом (анодом):

```
U_cell = φ_cathode − φ_anode
```

Під час нормального робочого розряду (від 4.2 В до 3.0 В) напруга падає головним чином за рахунок виснаження літію в шарах катодного оксиду (наприклад, `LiCoO2` чи `LiNi_xMn_yCo_zO2`), тоді як потенціал анода зростає дуже повільно:

```
φ_cathode(при 100% заряду) ≈ 4.25 В відносно Li/Li⁺
φ_anode(при 100% заряду)   ≈ 0.05 В відносно Li/Li⁺
U_cell = 4.25 − 0.05 = 4.20 В

φ_cathode(при розряді до 3.0 В) ≈ 3.75 В відносно Li/Li⁺
φ_anode(при розряді до 3.0 В)   ≈ 0.25 В відносно Li/Li⁺
U_cell = 3.75 − 0.25 = 3.50 В
```

Коли розряд триває нижче 3.0 В, графіт повністю віддає залишки інтеркальованого літію (ступінь деінтеркаляції досягає 100%). Графітова матриця стає порожньою вуглецевою структурою. Оскільки літію для підтримки низького електродного потенціалу більше немає, потенціал анода `φ_anode` стрімко злітає вгору, наближаючись до потенціалу катода:

```
φ_anode(деінтеркальований графіт) → +3.50...+3.65 В відносно Li/Li⁺
```

Розрахуймо критичну напругу комірки `U_crit`, за якої настає розчинення міді, якщо катодний потенціал частково деградованого оксиду кобальту становить `φ_cathode ≈ +3.80 В`:

```
U_crit
= φ_cathode − φ_anode(Cu_розчинення) [різниця потенціалів для початку корозії]
= 3.80 − 3.38                        [підстановка потенціалів]
= 0.42 В                             [гранична напруга на клемах]
```

Якщо ж катод виснажується сильніше (`φ_cathode ≈ +3.60 В`):

```
U_crit
= 3.60 − 3.38 [підстановка виснаженого катода]
= 0.22 В      [напруга спонтанного розчинення міді]
```

Проте в реальних комірках в умовах струмового перерозряду або тривалого саморозряду потенціал анода сягає порогу розчинення міді вже при падінні загальної напруги комірки нижче `1.50–2.00 В`. Причина полягає в локальних неоднорідностях: на краях електродів та поблизу зварних швів щільність деінтеркаляції вища, тому локальний потенціал `φ_local` перевищує 3.38 В значно раніше, ніж середня напруга досягне нульової позначки.

Швидкість анодного розчинення міді визначається струмом корозії за законом Фарадея:

```
dm_Cu / dt
= (M_Cu / (z · F)) · I_corr              [швидкість втрати маси мідної фольги]
= (63.546 / (2 · 96485)) · I_corr        [підстановка молярної маси Cu M=63.546 г/моль]
= 3.293 · 10⁻⁴ · I_corr г/с              [маса на кожен ампер корозійного струму]
= 1.185 · I_corr г/(А·год)               [втрата маси міді на 1 А·год перерозряду]
```

При товщині мідної фольги `d = 8 мкм` та площі електрода `S = 100 см²` загальна маса струмоприймача становить:

```
m_foil
= S · d · ρ_Cu                           [маса фольги через густину]
= 100 · (8 · 10⁻⁴) · 8.96                [густина міді ρ = 8.96 г/см³]
= 0.7168 г                               [загальна маса фольги в комірці]
```

Якщо через комірку протікає паразитно струм саморозряду чи струм підпорогового навантаження силою всього 5 мА протягом 30 днів (3.6 А·год):

```
Δm_Cu
= 1.185 · (0.005 · 720)                  [втрата маси за місяць]
= 1.185 · 3.6                            [перемноження величин]
= 4.266 г                                [теоретична потреба в міді]
```

Це значно перевищує загальну масу фольги, що означає повну локальну перфорацію колектора, утворення наскрізних каверн та повне відшарування активної графітової маси від металевої основи.

### Кінетика відновлення міді: виникнення дендритів проти планарного осадження

Головна небезпека полягає не лише у втраті контакту з фольгою, а в тому, що відбувається з іонами `Cu²⁺`, які перейшли в електроліт, коли на комірку подають зарядний струм.

Під час подачі зарядного струму потенціал анода різко падає нижче 3.0 В. Іони міді `Cu²⁺` стають термодинамічно схильними до зворотного відновлення в металічну фазу:

```
Cu²⁺ + 2e⁻ → Cu⁰ ↓
```

Морфологія відновленої міді підпорядковується електрохімічній теорії кристалізації та кінетичному рівнянню Батлера–Фольмера (англ. *Butler–Volmer equation*):

```
j = j₀ · [ exp((α_a · z · F / (R · T)) · η) − exp(−(α_c · z · F / (R · T)) · η) ]
```

Де:
- `j` — густина катодного струму відновлення міді (А/м²);
- `j₀` — густина струму обміну (залежить від природи поверхні та концентрації іонів);
- `α_a, α_c` — коефіцієнти переносу заряду (зазвичай `α_a ≈ α_c ≈ 0.5`);
- `η = φ − E_eq` — електродна перенапруга (відхилення потенціалу від рівноважного).

За високої перенапруги (`|η| > 150 мВ`), яка виникає при підключенні повного зарядного струму фази CC (0.5C–1.0C), процес відновлення переходить у режим, контрольований виключно дифузією іонів з об'єму електроліту. Граничний дифузійний струм описується співвідношенням:

```
j_lim = z · F · D_Cu · C_bulk / δ_N
```

Де `D_Cu ≈ 2 · 10⁻¹⁰ м²/с` — коефіцієнт дифузії іонів міді в карбонатному електроліті, `C_bulk` — об'ємна концентрація іонів, `δ_N` — товщина дифузійного шару Нернста.

Коли струм заряду перевищує `j_lim`, на мікронерівностях графітової поверхні виникає локальне загострення електричного поля. Швидкість осадження на вершинах мікропагорбів стає в десятки разів вищою, ніж у западинах:

```
v_tip / v_flat ∝ exp(2 · γ · V_m / (r_tip · R · T)) · exp((z · F / (R · T)) · η_local)
```

Де `r_tip` — радіус кривизни вістря зародка, `γ` — поверхнева енергія міді, `V_m` — молярний об'єм.

Це призводить до формування розгалужених голчастих структур — мідних дендритів (від грец. *déndron* — дерево). Час переходу до необмеженого росту дендритів визначається формулою Сенда (англ. *Sand's time*):

```
τ_Sand
= π · D_Cu · (z · F · C_bulk / (2 · j))²    [час початку вибухового росту дендритів]
```

З формули видно, що час до проколу сепаратора обернено пропорційний квадрату густини струму:

```
τ_Sand ∝ 1 / j²
```

Збільшення зарядного струму в 10 разів (перехід від передзаряду 0.1C до швидкого заряду 1.0C) скорочує безпечний час бездендритного відновлення у `10² = 100` разів.

Натомість при малому струмі передзаряду (`0.05C–0.10C`):
1. Густина струму залишається значно нижчою за критичну величину `j ≪ j_lim`.
2. Перенапруга процесу становить лише кілька мілівольтів (`η < 20 мВ`).
3. Процес осадження контролюється швидкістю перенесення заряду, а не дифузією.
4. Іони міді рівномірно відновлюються у вигляді плоских нанокристалічних острівців у порах графітової матриці, не утворюючи гострих голок.

### Вплив температури на кінетику корозії та енергія сольватації

Швидкість розчинення міді та її зворотного відновлення експоненційно залежить від температури за законом Арреніуса (англ. *Arrhenius law*):

```
k_corr(T) = A_corr · exp(−E_a / (R · T))
```

Енергія активації процесу анодного окиснення міді в етиленкарбонатному розчиннику становить `E_a ≈ 48.5 кДж/моль`. Якщо акумулятор зберігається в перерозрядженому стані за підвищеної температури (наприклад, у закритому автомобілі на сонці при `T = 45 °C = 318.15 K` замість стандартних `T = 20 °C = 293.15 K`), швидкість корозії міді зростає в кілька разів:

```
k_corr(318) / k_corr(293)
= exp((E_a / R) · (1/293.15 − 1/318.15))   [відношення швидкостей реакцій]
= exp((48500 / 8.314) · (0.003411 − 0.003143)) [підстановка температур і R]
= exp(5833.5 · 0.000268)                   [обчислення експоненти]
= exp(1.563)
= 4.77                                     [прискорення корозії майже в 5 разів]
```

Це означає, що за температури 45 °C критичне руйнування мідного струмоприймача настає не за місяць, а всього за 6 діб перебування під напругою нижче 1.5 В.

Крім того, вільні іони `Cu²⁺` у неводному середовищі не існують у вигляді ізольованих частинок — вони утворюють міцні сольватні комплекси з чотирма молекулами етиленкарбонату:

```
Cu²⁺ + 4EC ⇄ [Cu(EC)4]²⁺    [утворення сольватного комплексу в електроліті]
```

Енергія сольватації `ΔG_solv ≈ −185 кДж/моль` створює високий активаційний бар'єр для десольватації під час заряду. Якщо зарядний струм малий (передзаряд 0.05C), іон має достатньо часу для поступового скидання сольватної оболонки на границі розділу фаз без накопичення локального просторового заряду. При великому ж струмі 1C перенапруга змушує іони проникати вглиб пор сепаратора у частково сольватованому вигляді, де вони миттєво відновлюються на випадкових дефектах, каталізуючи формування наскрізних дендритних містків.

### Термодинаміка та енергетика деградації SEI-шару

На поверхні графітового анода в робочому стані завжди присутня захисна плівка твердого електролітного інтерфейсу — SEI (англ. *Solid Electrolyte Interphase*, від лат. *inter* — між + *facies* — обличчя). Вона складається з неорганічних сполук (`Li2CO3`, `LiF`, `Li2O`) та органічних солей літію (`(CH2OCO2Li)2` — дилітій етилендикарбонату).

За нормального потенціалу анода (`0.1–0.2 В`) плівка стабільна й перешкоджає подальшому відновленню молекул розчинника. Проте коли потенціал анода при перерозряді злітає вище `+3.0 В відносно Li/Li⁺`, компоненти SEI-шару піддаються окиснювальній деструкції:

```
Li2CO3 → 2Li⁺ + CO2 ↑ + 1/2 O2 ↑ + 2e⁻       [окиснення карбонату літію]
(CH2OCO2Li)2 → 2Li⁺ + 2CO2 ↑ + C2H4 ↑ + O2 ↑ + 2e⁻ [розпад алкілкарбонатів]
```

Ці реакції супроводжуються двома руйнівними ефектами:
1. **Газовиділення:** Утворення вуглекислого газу `CO2`, етилену `C2H4` та кисню `O2` викликає незворотне спучування м'яких пакетів (LiPo pouch cell) або підвищення тиску в циліндричних банках.
2. **Оголення графіту:** Окиснення захисного шару оголює чисту поверхню графіту.

Під час наступного підключення зарядного струму комірка змушена знову формувати шар SEI за рахунок необоротного витрачання іонів літію з катода та молекул розчинника.

Ентальпія утворення вторинного SEI-шару супроводжується паразитною витратою заряду `Q_SEI`:

```
Q_SEI = ∫ I_parasitic(t) dt = S_anode · C_film · ΔV
```

Якщо подати великий струм заряду 1C, швидке відновлення розчинника відбувається з бурхливим локальним виділенням газів, плівка виходить пухкою, нерівномірною та з високим внутрішнім опором. Натомість малий струм передзаряду `0.05C` забезпечує повільне електрохімічне осадження стабільної щільної плівки товщиною 10–25 нм із мінімальним утворенням газу.

### Тепловий розрахунок лінійного ключа зарядного контролера

Для апаратної реалізації вузла заряду часто обирають інтегровані лінійні регулятори завдяки їхній простоті та низькій вартості. Проте з погляду тепловиділення фаза передзаряду містить фундаментальний фізичний парадокс.

Потужність, що розсіюється на регулювальному MOSFET-транзисторі лінійного зарядного чипа, визначається різницею між вхідною напругою джерела живлення `U_in` (зазвичай стандартні 5.00 В від шини USB) та миттєвою напругою акумулятора `U_bat`:

```
P_loss(t) = (U_in − U_bat(t)) · I_charge
```

Розгляньмо, що сталося б, якби зарядний пристрій не мав фази передзаряду й одразу спрямовував у глибоко розряджену батарею повний струм `I_CC = 1.0 А` при `U_bat = 1.50 В`:

```
P_loss(гіпотетична)
= (U_in − U_bat) · I_CC   [потужність лінійного перетворювача без обмеження]
= (5.00 − 1.50) · 1.0     [підстановка параметрів найгіршого випадку]
= 3.50 · 1.0              [різниця потенціалів]
= 3.50 Вт                 [катастрофічне теплове розсіювання]
```

Типовий зарядний контролер виготовляється в мініатюрному безвивідному корпусі QFN-16 (3×3 мм) або SOT-23-5. Тепловий опір перехід-середовище `R_thJA` такого корпусу на стандартній двошаровій друкованій платі становить:

```
R_thJA ≈ 65...120 °C/Вт
```

Перегрів напівпровідникового кристала `ΔT_junction` відносно температури навколишнього середовища `T_amb = 25 °C` склав би:

```
ΔT_junction
= P_loss · R_thJA         [формула теплового перегріву]
= 3.50 · 85               [для типового R_thJA = 85 °C/Вт]
= 297.5 °C                [розрахункове перевищення температури]

T_junction = 25 + 297.5 = 322.5 °C
```

Оскільки максимальна допустима температура кремнієвого p-n переходу становить `T_j(max) = 125...150 °C`, кристал зазнав би миттєвого теплового пробою або пішов би в безперервний циклічний захист від перегріву (англ. *thermal shutdown oscillation*).

Тепер обчислімо реальну розсіювану потужність за наявності штатного режиму попереднього заряду з обмеженням струму на рівні `I_precharge = 0.1C = 0.10 А`:

```
P_loss(передзаряд)
= (U_in − U_bat) · I_precharge [розсіювання при струмі передзаряду]
= (5.00 − 1.50) · 0.10         [підстановка величин]
= 3.50 · 0.10                  [обчислення]
= 0.35 Вт                      [безпечна потужність розсіювання]
```

Розрахунок робочої температури переходу за тих самих умов:

```
ΔT_junction
= 0.35 · 85               [перегрів кристала при 0.35 Вт]
= 29.75 °C                [перевищення над оточенням]

T_junction = 25 + 29.75 = 54.75 °C
```

Температура кристала 55 °C є цілком безпечною та забезпечує багаторічну безвідмовну роботу мікросхеми без додаткових тепловідвідних радіаторів.

Для імпульсних (англ. *switching*) buck-зарядників потужність втрат ще менша й розраховується через динамічний коефіцієнт корисної дії:

```
P_loss(buck) = P_out · (1 − η) / η = (U_bat · I_precharge) · (1 − η) / η
```

При `U_bat = 1.5 В`, `I_precharge = 0.1 А` та ККД `η ≈ 80%` імпульсний каскад розсіює лише:

```
P_loss(buck)
= (1.5 · 0.1) · (1 − 0.80) / 0.80  [підстановка напруги, струму та ККД]
= 0.15 · 0.20 / 0.80               [перемноження вхідної потужності й втрат]
= 0.0375 Вт (37.5 мВт)             [підсумкова розсіювана потужність]
```

### Розрахунок бюджету таймера передзаряду та критерій аварії

Процес відновлення напруги під час подачі постійного струму передзаряду `I_pre` описується диференціальним рівнянням заряду еквівалентної ємності комірки `C_eff(U)` з урахуванням внутрішнього послідовного опору `R_int`:

```
dU_cell(t) / dt = I_pre / C_eff(U_cell)
```

Еквівалентна диференціальна ємність літій-іонного акумулятора `C_eff = dQ / dU` у зоні глибокого розряду (1.5–3.0 В) є вкрай нелінійною функцією. На відміну від робочого плато (3.6–3.8 В), де ємність вимірюється тисячами фарад, у зоні глибокого розряду ємність становить лише 1–3% від номінального значення акумулятора, оскільки електрохімічна фаза там нестабільна.

Для комірки номінальною ємністю `C_nom = 2000 мА·год = 2.0 А·год = 7200 Кл` кількість електрики `Q_pre`, необхідна для підняття напруги від `U_init = 1.50 В` до порогу швидкого заряду `U_LOWV = 3.00 В`, становить близько 2% від `C_nom`:

```
Q_pre
= 0.02 · C_nom           [заряд для виходу з глибокого розряду]
= 0.02 · 2.0 А·год       [підстановка ємності 2000 мА·год]
= 0.04 А·год = 144 Кл    [необхідний кулонівський заряд]
```

Час штатного проходження фази попереднього заряду струмом `I_pre = 0.1C = 0.20 А`:

```
t_pre_nominal
= Q_pre / I_pre          [час набору заряду]
= 0.04 А·год / 0.20 А    [ділення величин]
= 0.20 год = 12 хв       [номінальний час передзаряду]
```

Якщо ж акумулятор розряджений до нуля (`U_init ≈ 0.80 В`) і струм обмежено рівнем `0.05C = 0.10 А`:

```
Q_pre(глибокий) ≈ 0.035 · 2.0 = 0.07 А·год
t_pre_deep = 0.07 / 0.10 = 0.70 год = 42 хв
```

Щоб відокремити справну комірку, яка повільно відновлюється, від мертвої батареї з внутрішнім коротким замиканням (через пророслий дендрит або деградацію сепаратора), зарядні контролери встановлюють апаратний таймер безпеки (англ. *safety timer*) `t_PRECHG_MAX`.

Еквівалентна схема комірки з внутрішнім шунтувальним коротким замиканням моделюється резистором витоку `R_leak`, підключеним паралельно ємності:

```
I_net(t) = I_pre − (U_cell(t) / R_leak)
```

Якщо опір внутрішнього шунта `R_leak` є низьким (наприклад, `R_leak = 15 Ом` через локальний мікропрокол сепаратора), то при струмі `I_pre = 0.10 А` напруга комірки стабілізується на рівні:

```
U_max_leak
= I_pre · R_leak         [максимальна напруга при шунтуванні]
= 0.10 · 15              [підстановка струму й опору витоку]
= 1.50 В                 [напруга застрягання]
```

Оскільки `U_max_leak = 1.50 В < U_LOWV (3.00 В)`, диференціал `dU/dt` падає до нуля, і напруга ніколи не досягне порогу виходу в режим CC:

```
dU / dt
= (I_pre − U_max / R_leak) / C_eff  [диференціал напруги з урахуванням витоку]
= (0.10 − 1.50 / 15) / C_eff        [підстановка струму, напруги й опору шунта]
= (0.10 − 0.10) / C_eff             [компенсація струму заряду струмом витоку]
= 0 В/с                             [зупинка росту напруги]
```

Увесь струм `I_pre = 0.10 А` безперервно перетворюється на тепло безпосередньо в точці мікрошунта з виділенням локальної потужності:

```
P_leak
= U² / R_leak            [потужність нагріву точки замикання]
= (1.50)² / 15           [підстановка напруги й опору]
= 2.25 / 15              [піднесення до квадрата]
= 0.15 Вт                [локальне тепловиділення в мікрооб'ємі]
```

Хоча 0.15 Вт здається малою потужністю для всієї батареї, у мікроскопічній точці контакту розміром 50×50 мкм густина потужності сягає `60000 Вт/см²`, що викликає локальне нагрівання полімерного сепаратора вище температури його плавлення (130–165 °C для поліетилену/поліпропілену) та розростання повномасштабного внутрішнього КЗ.

Саме тому максимальний час роботи таймера попереднього заряду вибирають із запасом 1.5–2.0 рази від номінального часу найгіршого випадку:

```
t_PRECHG_MAX = 1.5 · t_pre_deep ≈ 1.5 · 42 хв ≈ 60 хв
```

Якщо після спливання інтервалу `t_PRECHG_MAX` (зазвичай від 30 до 60 хвилин за стандартом виробників зарядних чипів) напруга на акумуляторі залишається нижчою за `U_LOWV`, контролер фіксує фатальну помилку *Precharge Timeout Fault*, назавжди блокує силові транзистори і захищає пристрій від термічного самозаймання.
