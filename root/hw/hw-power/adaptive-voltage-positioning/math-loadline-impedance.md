# 🧮 Математика навантажувальної прямої та постійного імпедансу

Ця вставка розгортає математичний апарат адаптивного позиціонування напруги (AVP): точний вивід передатної функції вихідного імпедансу замкненого стабілізатора, умову монотонного перехідного процесу без перерегулювання, розрахунок необхідної ємності вихідного конденсаторного банку та енергетичний баланс розсіювання потужності в обчислювальному кристалі.

Без строгого частотного та часового розрахунку імпедансу спроба додати спад напруги (droop) призводить або до виникнення фазового дзвону на резонансній частоті LC-фільтра, або до передчасного виходу напруги за рамки допустимого коридору живлення мікропроцесора (voltage tolerance window).

```
+──────────────────────────────────────────────────────────────────────────────+
│                      УМОВИ ПОСТІЙНОГО ВИХІДНОГО ІМПЕДАНСУ                    │
│                                                                              │
│   1. Активний нахил регулятора:     R_LL = ΔV_tol / I_max                    │
│   2. Узгодження активних втрат:     ESR_bank = R_LL                          │
│   3. Баланс енергії фільтра:        C_out = L_eq / R_LL²                     │
│   4. Результуючий імпеданс:         Z_out(s) = R_LL  (у всій робочій смузі)  │
+──────────────────────────────────────────────────────────────────────────────+
```

### 1. Вихідний імпеданс імпульсного стабілізатора

Розглянемо еквівалентну малосигнальну схему багатофазного понижувального перетворювача (multiphase buck converter). Нехай `N` однакових фаз працюють паралельно, утворюючи еквівалентну індуктивність `L_eq = L / N` з еквівалентним послідовним опором обмоток `DCR_eq = DCR / N`. Вихід навантажений на батарею конденсаторів загальною ємністю `C_out` із сумарним еквівалентним послідовним опором `ESR` та еквівалентною послідовною індуктивністю `ESL`.

Імпеданс пасивного вихідного фільтра без урахування зворотного зв'язку (open-loop output impedance) описується виразом:

```
Z_ol(s) = (s·L_eq + DCR_eq) || (1 / (s·C_out) + ESR + s·ESL)
```

У низькочастотній та середньочастотній областях паразитна індуктивність `ESL` є незначною, а опір обмоток `DCR_eq` набагато менший за реактивний опір індуктивності. Тоді імпеданс спрощується:

```
Z_ol(s) ≈ (s·L_eq) · (1 + s·C_out·ESR) / (s²·L_eq·C_out + s·C_out·(ESR + DCR_eq) + 1)
```

При замиканні контуру керування з петлевим підсиленням `T(s)` вихідний імпеданс закритої системи (closed-loop output impedance) стає:

```
Z_cl(s) = Z_ol(s) / (1 + T(s))
```

В ідеальному класичному стабілізаторі напруги петлеве підсилення `T(s)` намагаються зробити нескінченно великим на постійному струмі (`T(0) → ∞`), що дає нульовий статичний вихідний опір `Z_cl(0) = R_out = 0`. Проте на високих частотах підсилення `T(s)` неминуче спадає відповідно до частоти одиничного перетину петлі `f_c` (gain crossover frequency). На частотах вище `f_c` контур стабілізації втрачає керування, і вихідний імпеданс визначається виключно пасивною конденсаторною батареєю:

```
Z_cl(s) ≈ Z_caps(s) = ESR + 1 / (s·C_out)      [при |s| >> 2·π·f_c]
```

### 2. Перехідний процес в ідеальному стабілізаторі з R_out = 0

Нехай процесор споживає струм, що миттєво змінюється на величину `ΔI` зі швидкістю наростання `di/dt`. Допустимий діапазон коливань напруги ядра обмежений значеннями `V_max` та `V_min`. Повний розмах допустимого коридору напруги:

```
ΔV_tol = V_max - V_min
```

В ідеальному регуляторі з `R_out = 0` номінальна напруга встановлюється посередині дозволеного коридору:

```
V_nom = (V_max + V_min) / 2
```

Тому допустимий запас напруги для динамічного просідання (undershoot) і динамічного викиду (overshoot) становить лише половину загального вікна толерантності:

```
ΔV_max_allowed = ΔV_tol / 2
```

При раптовому накиданні навантаження `0 → I_max` контур регулювання не встигає зреагувати протягом часу затримки `t_resp ≈ 1 / (2·π·f_c)`. Весь стрибок струму `ΔI` замикається через вихідні конденсатори. Загальне просідання напруги складається з трьох послідовних компонентів:

```
ΔV_under = ΔV_ESL + ΔV_ESR + ΔV_C
```

Розпишемо кожну складову:

```
ΔV_ESL = ESL · (di/dt)                          [індуктивний сплеск у перші наносекунди]
ΔV_ESR = ΔI · ESR                               [активне падіння на опорі виводів і обкладок]
ΔV_C   = (ΔI · t_resp) / (2 · C_out)            [ємнісний розряд до моменту наростання струму дроселів]
```

Швидкість наростання струму в еквівалентній індуктивності стабілізатора обмежена прикладеною напругою:

```
(di_L / dt) = (V_in · D_max - V_out) / L_eq
```

Час, необхідний дроселям для виходу на новий струм навантаження:

```
t_L_rise = (L_eq · ΔI) / (V_in · D_max - V_out)
```

Протягом цього часу заряд `Q_dis = (ΔI · t_L_rise) / 2` викачується виключно з конденсаторів. Отже, амплітуда просідання:

```
ΔV_under = ΔI · ESR + (L_eq · ΔI²) / (2 · C_out · (V_in · D_max - V_out))
```

Ще гірша ситуація виникає при раптовому скиданні струму `I_max → 0` (load release). Дроселі накопичили магнітну енергію:

```
E_L = (1 / 2) · L_eq · I_max²
```

Після закриття верхніх ключів перетворювача цей струм не може зникнути миттєво і вливається у вихідну ємність `C_out`, викликаючи викид напруги (overshoot):

```
(1 / 2) · C_out · (V_peak² - V_nom²) = (1 / 2) · L_eq · I_max²
```

Розкладаючи різницю квадратів для малого приросту `ΔV_over = V_peak - V_nom << V_nom`:

```
V_peak² - V_nom² = (V_peak - V_nom) · (V_peak + V_nom) ≈ 2 · V_nom · ΔV_over
```

Підставляючи у рівняння енергетичного балансу:

```
ΔV_over ≈ (L_eq · I_max²) / (2 · C_out · V_nom)
```

Оскільки стабілізатор без AVP має тримати `ΔV_under ≤ ΔV_tol / 2` та `ΔV_over ≤ ΔV_tol / 2`, необхідна вихідна ємність визначається найжорсткішою з умов:

```
C_out_no_avp ≥ (L_eq · I_max²) / (V_nom · ΔV_tol)
ESR_no_avp   ≤ ΔV_tol / (2 · I_max)
```

### 3. Синтез контуру AVP: постійний вихідний опір

В архітектурі AVP замість утримання `Z_cl(0) = 0` у контур зворотного зв'язку навмисно вводиться штучний опір навантажувальної прямої (load-line resistance) `R_LL`:

```
V_out(I_load) = V_NL - R_LL · I_load
```

де `V_NL` — напруга холостого ходу (No-Load voltage), встановлена на верхню межу робочого вікна:

```
V_NL = V_max - V_margin
```

При протіканні максимального струму `I_max` напруга ядра опускається рівно до нижньої допустимої межі:

```
V_FL = V_NL - R_LL · I_max = V_min + V_margin
```

Звідси розраховується точне значення коефіцієнта спаду (droop slope):

```
R_LL = (V_NL - V_FL) / I_max = (ΔV_tol - 2·V_margin) / I_max
```

Розглянемо передатну функцію замкненого контуру з підмішуванням струмового сигналу. Нехай напруга зворотного зв'язку формується як:

```
V_FB(s) = V_out(s) + G_droop(s) · I_load(s)
```

де `G_droop(s)` — передавальний опір струмового сенсингу. Підсилювач помилки підтримує `V_FB(s) = V_ref`. Тоді вихідна напруга:

```
V_out(s) = V_ref - G_droop(s) · I_load(s) - (1 / T(s)) · (V_out(s) - V_ol(s))
```

Якщо петльове підсилення `T(s)` велике в робочій смузі, вихідний імпеданс стабілізатора стає строго резистивним:

```
Z_out(s) = - (ΔV_out(s) / ΔI_load(s)) = G_droop(s) = R_LL = const
```

### 4. Умова монотонного перехідного процесу без перерегулювання

Повний динамічний імпеданс системи на високих частотах визначається паралельним з'єднанням активного контуру та вихідної ємності:

```
Z_out_total(s) = Z_cl(s) || Z_caps(s)
```

Підставимо малосигнальні вирази для контуру зі спадом `Z_cl(s) = R_LL · (1 + s / ω_c)` та конденсаторного банку `Z_caps(s) = ESR + 1 / (s·C_out)`:

```
Z_out_total(s) = (R_LL · (1 + s / ω_c)) || (ESR + 1 / (s·C_out))
```

Для того щоб сумарний вихідний імпеданс був абсолютно сталим і не залежав від частоти (`Z_out_total(s) = R_LL` для будь-якого `s`), необхідно одночасно виконати дві фундаментальні умови узгодження:

```
1. ESR = R_LL
2. C_out = L_eq / (R_LL · (R_LL + DCR_eq)) ≈ L_eq / R_LL²
```

Доведемо цю рівність. Розглянемо відгук напруги `V_out(t)` на одиничний стрибок струму `I_load(t) = ΔI · u(t)`.

У класичній системі напруга спочатку здійснює стрибок вниз на величину `ΔI · ESR`, потім просідає далі через розряд ємності, а потім відновлюється до вихідного рівня `V_nom` завдяки роботі інтегратора в підсилювачі помилки. Це створює коливальний або квазірезонансний процес із глибоким провалом.

У системі з ідеально узгодженим AVP (`ESR = R_LL`):

```
v_out(0+) = V_NL - ΔI · ESR = V_NL - ΔI · R_LL
```

У сталий момент часу (`t → ∞`), коли індуктивності вийшли на новий режим:

```
v_out(∞) = V_NL - ΔI · R_LL
```

Оскільки миттєве падіння напруги в момент комутації `v_out(0+)` в точності дорівнює новому усталеному значенню `v_out(∞)`, напруга змінюється строго монотонною сходинкою:

```
v_out(t) = V_NL - ΔI · R_LL · u(t)
```

Перехідний процес не містить жодного просідання нижче сталого рівня (zero undershoot beyond load-line) і жодного викиду вище рівня холостого ходу при скиданні навантаження.

### 5. Доказ скорочення конденсаторного банку у 2 рази

Порівняємо необхідний обсяг конденсаторів для стабілізатора без AVP та стабілізатора з AVP при однакових граничних умовах: струм `I_max`, напруга `V_nom`, допустимий розмах вікна `ΔV_tol`, індуктивність `L_eq`.

Вимоги до максимального сплеску напруги:

```
Без AVP:  ΔV_transient_max = ΔV_tol / 2   [система симетрична навколо V_nom]
З AVP:    ΔV_transient_max = ΔV_tol       [система використовує повний розмах від V_NL до V_FL]
```

Розрахуємо мінімальну ємність для поглинання енергії індуктивності при скиданні струму `I_max → 0`:

```
Без AVP:
C_min_no_avp = (L_eq · I_max²) / (2 · V_nom · (ΔV_tol / 2))
             = (L_eq · I_max²) / (V_nom · ΔV_tol)

З AVP:
C_min_avp    = (L_eq · I_max²) / (2 · V_nom · ΔV_tol)
             = (1 / 2) · C_min_no_avp
```

Аналогічно для максимально допустимого еквівалентного послідовного опору батареї:

```
Без AVP:  ESR_max_no_avp = (ΔV_tol / 2) / I_max = ΔV_tol / (2 · I_max)
З AVP:    ESR_max_avp    = ΔV_tol / I_max       = 2 · ESR_max_no_avp
```

```
+──────────────────────────────────────────────────────────────────────────────+
│                      ПОРІВНЯННЯ ПАРАМЕТРІВ ВИХІДНОГО ФІЛЬТРА                 │
│                                                                              │
│   Параметр                       Без AVP (R_out = 0)     З AVP (R_out = R_LL)│
│   ────────────────────────────────────────────────────────────────────────   │
│   Вихідна напруга при 0 А        V_nom                   V_max               │
│   Вихідна напруга при I_max      V_nom                   V_min               │
│   Допустимий динамічний стрибок  ΔV_tol / 2              ΔV_tol              │
│   Необхідна ємність C_out        C_базова                0.5 · C_базова      │
│   Допустимий опір ESR банку      ESR_базовий             2.0 · ESR_базовий   │
│   Кількість MLCC конденсаторів   N_керам                 ≈ 0.5 · N_керам     │
+──────────────────────────────────────────────────────────────────────────────+
```

Збільшення допустимого ESR у 2 рази та зниження мінімальної ємності у 2 рази означає, що фізична кількість паралельних керамічних (MLCC) і полімерних конденсаторів на материнській платі зменшується рівно на 50%.

### 6. Енергетичний баланс та розсіювання тепла в кристалі CPU

Споживана процесором потужність складається з динамічної комутаційної потужності КМОН-логіки `P_dyn` та статичної потужності витоку `P_leak`:

```
P_cpu(V) = P_dyn + P_leak
         = α · C_gate · f_clk · V² + V · I_leak(V, T)
```

де `α` — коефіцієнт активності перемикання затворів, `C_gate` — сумарна комутована ємність, `f_clk` — тактова частота, `I_leak` — струм підпорогового та тунельного витоку транзисторів.

При високому навантаженні струм наближається до `I_max`. Порівняємо потужність, що виділяється у кристалі, при живленні фіксованою напругою `V_nom` та напругою зі спадом `V_FL = V_nom - ΔV_droop / 2`:

```
Без AVP:
P_no_avp = V_nom · I_max

З AVP:
P_avp    = V_FL · I_max = (V_nom - R_LL · I_max / 2) · I_max
         = V_nom · I_max - (1 / 2) · R_LL · I_max²
```

Абсолютна економія потужності під повним навантаженням:

```
ΔP_saved = P_no_avp - P_avp = (1 / 2) · R_LL · I_max²
```

Відносна економія енергії:

```
η_save = ΔP_saved / P_no_avp = (R_LL · I_max) / (2 · V_nom) = ΔV_droop / (2 · V_nom)
```

Порахуємо числовий приклад для сучасного обчислювального вузла штучного інтелекту або сервера:
- `V_nom = 1.00 В`
- `I_max = 200 А`
- `ΔV_tol = 160 мВ` (від 1.08 В у простої до 0.92 В під навантаженням)
- `R_LL = 160 мВ / 200 А = 0.80 мОм`

Обчислюємо розсіювану потужність:

```
P_no_avp = 1.00 В · 200 А = 200.0 Вт
P_avp    = 0.92 В · 200 А = 184.0 Вт
ΔP_saved = 200.0 Вт - 184.0 Вт = 16.0 Вт
```

Зниження тепловиділення на 16 Вт (8.0% від повної потужності кристала) суттєво зменшує температуру кристала `T_junction`, що додатково експоненційно знижує струм витоку `I_leak`, запобігаючи переходу кристала в режим теплового тротлінгу (thermal throttling).

### 7. Бюджет похибок та статичний розкид Load-Line (Tolerance Budget)

У реальному пристрої навантажувальна пряма має розкид параметрів через технологічні допуски компонентів, шум вимірювання та дрейф напруги опорного джерела (DAC reference).

Загальна похибка регулювання вихідної напруги розбивається на похибку зміщення нуля (DC Offset error) та похибку нахилу навантажувальної прямої (Slope error):

```
V_out(I) = (V_NL ± δV_offset) - (R_LL ± δR_LL) · I_load ± V_ripple / 2
```

де:
1. `δV_offset` — адитивна похибка: включає точність внутрішнього ЦАП контролера (зазвичай `±0.5%` або `±5 мВ`), зміщення підсилювача помилки `V_os` та похибку віддаленого диференціального сенсингу `V_remote_sense`.
2. `δR_LL` — мультиплікативна похибка: зумовлена розкидом струмових сенсорних резисторів, похибкою DCR індуктивностей (`±5–10%`) та залишковою нелінійністю NTC-термокомпенсації.
3. `V_ripple` — амплітуда високочастотних пульсацій ШІМ (перемикання фаз).

Для гарантованого утримання напруги в межах `[V_min_spec, V_max_spec]` вводяться захисні інтервали (Guardbands):

```
V_NL_target = V_max_spec - δV_offset - V_ripple / 2
V_FL_target = V_min_spec + δV_offset + δR_LL · I_max + V_ripple / 2
```

Тоді доступний діапазон для активного спаду напруги визначається як:

```
ΔV_droop_effective = V_NL_target - V_FL_target
                   = ΔV_tol_spec - 2 · δV_offset - δR_LL · I_max - V_ripple
```

Цей баланс показує фундаментальний інженерний компроміс: чим вища точність струмового моніторингу (менший `δR_LL`) та джерела опорної напруги (менший `δV_offset`), тим більший нахил `R_LL` можна закласти в систему, і тим меншу кількість вихідних конденсаторів доведеться монтувати на друковану плату.

### 8. Алгебраїчний вивід скорочення полюсів та нулів у просторі Лапласа

Проведемо строгий аналітичний аналіз передатної функції сумарного імпедансу `Z_out(s)` у частотній області `s`. Нехай зворотний зв'язок реалізує пропорційний контур за струмом із коефіцієнтом передачі `R_LL` та частотою одиничного перетину підсилювача напруги `ω_v = 2·π·f_c`.

Малосигнальне рівняння вихідної напруги з урахуванням контуру AVP:

```
v_out(s) = - Z_ol(s) · i_load(s) - T_v(s) · (v_out(s) + R_LL · i_load(s))
```

де `T_v(s) = ω_v / s` — передатна функція інтегруючого підсилювача помилки. Перегрупуємо доданки:

```
v_out(s) · (1 + T_v(s)) = - [ Z_ol(s) + T_v(s) · R_LL ] · i_load(s)
```

Результуючий замкнений імпеданс:

```
Z_cl(s) = - (v_out(s) / i_load(s)) = (Z_ol(s) + T_v(s) · R_LL) / (1 + T_v(s))
        = (s · Z_ol(s) + ω_v · R_LL) / (s + ω_v)
```

Підставимо у вираз імпеданс відкритого LC-фільтра `Z_ol(s) = (s·L_eq) / (s²·L_eq·C_out + s·C_out·ESR + 1)` за умови, що конденсаторний банк узгоджений за активним опором `ESR = R_LL`:

```
Z_cl(s) = [ s²·L_eq / (s²·L_eq·C_out + s·C_out·R_LL + 1) + ω_v·R_LL ] / (s + ω_v)
```

Приведемо чисельник до спільного знаменника:

```
Z_cl(s) = [ s²·L_eq + ω_v·R_LL · (s²·L_eq·C_out + s·C_out·R_LL + 1) ] / [ (s + ω_v) · (s²·L_eq·C_out + s·C_out·R_LL + 1) ]
```

Згрупуємо доданки в чисельнику за степенями оператора `s`:

```
Чисельник = s² · [ L_eq + ω_v · R_LL · L_eq · C_out ] + s · [ ω_v · R_LL² · C_out ] + ω_v · R_LL
```

Тепер застосуємо другу умову оптимального узгодження AVP: `C_out = L_eq / R_LL²` (або `L_eq = C_out · R_LL²`). Підставимо `L_eq` у чисельник:

```
Чисельник = s² · [ C_out · R_LL² + ω_v · R_LL · (C_out · R_LL²) · C_out ] ...
```

Винесемо спільний множник `R_LL` за дужки:

```
Чисельник = R_LL · [ s² · (C_out · R_LL + ω_v · C_out² · R_LL²) + s · (ω_v · R_LL · C_out) + ω_v ]
          = R_LL · (s + ω_v) · (s² · L_eq · C_out + s · C_out · R_LL + 1)
```

Погляньмо на результуючий вираз для імпедансу:

```
Z_cl(s) = R_LL · [ (s + ω_v) · (s²·L_eq·C_out + s·C_out·R_LL + 1) ] / [ (s + ω_v) · (s²·L_eq·C_out + s·C_out·R_LL + 1) ]
        = R_LL
```

Усі поліноми третього порядку в чисельнику та знаменнику повністю ідентичні та скорочуються. У системі відсутні резонансні піки, перегини фазової характеристики та комплексні полюси: вихідний опір залишається абсолютно дійсним і константним на всіх частотах.

### 9. Вплив паразитної індуктивності сокета і корпусу процесора (Package Parasitics)

На частотах понад 10–20 МГц імпеданс шини живлення перестає визначатися стабілізатором на материнській платі, оскільки між платою та кристалом процесора увімкнені паразитна індуктивність виводів сокета `L_socket` та індуктивність BGA-підкладки процесора `L_pkg`:

```
Z_pkg(s) = s · (L_socket + L_pkg) + R_socket
```

Для сучасного сокета LGA4189 / LGA4677 або AM5 сумарна паразитна індуктивність становить `L_pkg_tot ≈ 20–80 пГн`. При швидкості наростання струму `di/dt = 200 А/нс` стрибок напруги на підкладці процесора сягає:

```
ΔV_pkg = L_pkg_tot · (di/dt) = (50 · 10⁻¹² Гн) · (200 · 10⁹ А/с) = 10.0 В
```

Такий колосальний сплеск миттєво зруйнував би кристалічну структуру транзисторів. Для його нейтралізації застосовують багаторівневу ієрархію розв'язувальних ємностей (Power Delivery Network — PDN):

```
+──────────────────────────────────────────────────────────────────────────────+
│                      ІЄРАРХІЯ ВИХІДНОГО ІМПЕДАНСУ PDN ЗА ЧАСТОТОЮ            │
│                                                                              │
│   Частотний діапазон   Хто забезпечує імпеданс R_LL    Тип компонентів       │
│   ────────────────────────────────────────────────────────────────────────   │
│   0 Гц ... 100 кГц     Контур AVP стабілізатора VRM    ШІМ та підсилювач     │
│   100 кГц ... 2 МГц    Полімерні конденсатори Bulk     SP-Cap / POSCAP       │
│   2 МГц ... 20 МГц     Кераміка на платі біля сокета   MLCC 1206 / 0805 X7R  │
│   20 МГц ... 200 МГц   Кераміка на підкладці (BGA)     MLCC 0402 / 0201 X5R  │
│   > 200 МГц            Внутрішньокристальна ємність    On-die trench caps    │
+──────────────────────────────────────────────────────────────────────────────+
```

На кожному рівні ієрархії резонансна частота конденсаторів підбирається так, щоб їхній активний опір `ESR` у зоні власного послідовного резонансу точно дорівнював цільовому значенню `R_LL`.

### 10. Повний числовий приклад розрахунку VRM для 8-фазного сервера

Розглянемо проектування системи живлення процесора з наступними параметрами:
- Номінальна напруга: `V_nom = 1.00 В`
- Струм холостого ходу: `I_NL = 0 А`, максимальний струм: `I_max = 240 А`
- Допустимий розмах напруги: `V_max_spec = 1.08 В`, `V_min_spec = 0.92 В` (`ΔV_tol = 160 мВ`)
- Кількість фаз: `N = 8`, індуктивність однієї фази: `L = 150 нГн`
- Вхідна напруга: `V_in = 12.0 В`

**Крок 1. Розрахунок нахилу навантажувальної прямої R_LL:**

```
R_LL = ΔV_tol / I_max = 160 мВ / 240 А = 0.667 мОм (6.67 · 10⁻⁴ Ом)
```

**Крок 2. Розрахунок еквівалентної індуктивності багатофазного вузла:**

```
L_eq = L / N = 150 нГн / 8 = 18.75 нГн
```

**Крок 3. Розрахунок мінімальної вихідної ємності C_out:**

```
C_out = L_eq / R_LL²
      = (18.75 · 10⁻⁹ Гн) / (6.667 · 10⁻⁴ Ом)²
      = (18.75 · 10⁻⁹) / (4.444 · 10⁻⁷)
      = 0.04219 Ф ≈ 42.2 мФ (42 200 мкФ)
```

**Крок 4. Порівняння з класичною схемою без AVP:**
Для традиційної схеми без AVP розрахункова ємність становила б:

```
C_no_avp = 2 · C_out = 84.4 мФ
```

Застосування AVP дозволяє відмовитися від 42 200 мкФ ємності (економія приблизно 90 полімерних конденсаторів типу POSCAP ємністю 470 мкФ), що звільняє понад 45 см² площі друкованої плати навколо процесорного сокета і знижує собівартість силового вузла на десятки доларів.

### 11. Добротність LC-контуру та демпфування перехідного процесу

У класичному стабілізаторі напруги без AVP вихідний фільтр `L_eq - C_out` має вкрай низький власний активний опір (`ESR + DCR << 1 мОм`), через що добротність коливального контуру є дуже високою:

```
Q_ol = (1 / (ESR + DCR_eq)) · √(L_eq / C_out) >> 10
```

При будь-якому різкому збуренні навантаження висока добротність `Q_ol` викликає затяжний резонансний дзвін (ringing) на частоті `f_res = 1 / (2·π·√(L_eq·C_out))`. Щоб запобігти збудженню, інженерам доводиться застосовувати складні пропорційно-інтегрально-диференціальні коректори (PID / Type III compensation) з низькою частотою зрізу, що штучно сповільнює реакцію стабілізатора.

Контур AVP докорінно змінює фізику демпфування системи: активний зворотний зв'язок за струмом синтезує віртуальний паралельний демпфуючий резистор опором `R_LL`. Еквівалентна добротність замкненої системи стає рівною:

```
Q_cl = (1 / R_LL) · √(L_eq / C_out)
```

Підставимо в цей вираз раніше виведену умову оптимального узгодження ємності `C_out = L_eq / R_LL²`:

```
Q_cl = (1 / R_LL) · √(L_eq / (L_eq / R_LL²))
     = (1 / R_LL) · √(R_LL²)
     = 1.00
```

Добротність `Q_cl = 1.00` (коефіцієнт затухання `ζ = 1 / (2·Q_cl) = 0.50` в послідовному представленні або `ζ = 1.00` у паралельному представленні) відповідає **критично задемпфованій аперіодичній системі** (Critically Damped System).

У такій системі перехідний процес припиняє бути коливальним: енергія індуктивності повністю поглинається активним контуром droop-регулювання, а напруга виходить на нову навантажувальну лінію за найкоротший фізично можливий час без вторинних фазових коливань.

Практична перевірка в лабораторії полягає у вимірюванні частотної характеристики імпедансу за допомогою векторного аналізатора кіл (VNA / Bode 100) з інжекційним трансформатором: крива `|Z_out(f)|` повинна мати вигляд строго горизонтальної лінії від частоти 10 Гц до частоти одиничного зрізу петлі `f_c`, без провалів і без резонансних викидів. Будь-який викид на графіку свідчить про занижений номінал вихідної ємності або завищений опір `R_LL`, тоді як провал свідчить про надмірний фазовий зсув у контурі сумування струму.
