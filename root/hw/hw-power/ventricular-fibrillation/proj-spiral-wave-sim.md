# ⚙️ Чисельне моделювання автохвильового хаосу та розпаду спіральних хвиль

Ця вставка детально описує розробку програмного симулятора двовимірного збудливого середовища мовами C та C++, розкриває алгоритм чисельного інтегрування рівнянь Фіцг'ю-Нагумо на прямокутній сітці, порівнює монодоменний та бідоменний підходи, реалізує протокол двоімпульсного збудження (S1-S2) для ініціації спірального ротора, пропонує топологічний алгоритм виявлення фазових сингулярностей, аналізує ізотропні шаблони Лапласа, розраховує псевдо-ЕКГ сигналів, оцінює чутливість параметрів, розглядає механо-електричний зворотний зв'язок, показує експорт у формат VTK для ParaView та розглядає методы оптимізації обчислень на багаттоядерних системах і графічних прискорювачах (GPU).

### Біофізична постановка задачі та концепція чисельного експерименту

Чисельне моделювання збудливих середовищ є основним інструментом сучасної обчислювальної кардіології та математичної біофізики. Воно дозволяє досліджувати фундаментальні автохвильові ефекти — поширення плоскої хвилі деполяризації, закручування вільних країв хвилі у спіральні ротори (трипотіння шлуночків), а також їх подальший мультиплікативний розпад на десятки дрібних осередків (фібриляцію шлуночків).

Модельоване середовище подається у формі двовимірного прямокутного масиву тканинного синцитію розміром `Nx × Ny` вузлів із просторовими кроками `dx = dy = 0.5` мм. Часовий крок дискретизації обирається рівним `dt = 0.04` мс, що гарантує стійкість за критерієм Куранта-Фрідріхса-Леві при коефіцієнті дифузії `D = 1.0` мм²/мс.

У кожній комірці сітки `(x, y)` обчислюються дві динамічні змінні стану:
- `V[y][x]` — безрозмірний трансмембранний потенціал (швидка активаційна змінна);
- `w[y][x]` — повільна змінна реполяризаційного калієво-кальцієвого струму.

#### Порівняння монодоменного та бідоменного підходів

У чисельному моделюванні електрофізіології використовують два класи математичних моделей:
1. **Монодоменна модель (Monodomain Model):** Припускає, що анізотропія внутрішньоклітинного та позаклітинного просторів є пропорційною. Стан описується єдиним рівнянням реакції-дифузії. Вона є ефективною для моделювання внутрішньосерцевого поширення хвиль та вимагає мінімальних обчислювальних ресурсів.
2. **Бідоменна модель (Bidomain Model):** Враховує роздільні тензори провідності внутрішньоклітинного та позаклітинного середовищ. Модель вимагає розв'язання зв'язаної параболічно-еліптичної системи рівнянь, де на кожному часовому кроці додатково розв'язується рівняння Пуассона для позаклітинного потенціалу `Φ_e`. Бідоменна модель необхідна при точних розрахунках зовнішньої дефібриляції, коли електричний струм подається ззовні через електроди на грудній клітці.

### Алгоритмічна схема дискретизації Ейлера та шаблони Лапласа

Для чисельного інтегрування нелінійних рівнянь реакції-дифузії застосовується явна скінченно-різницева схема Ейлера. 

Дифузійна взаємодія між сусідніми кардіоміоцитами передається через різницеву апроксимацію оператора Лапласа `∇²V`. 

#### 1. Класичний 5-точковий хрестоподібний шаблон

На двовимірній квадратній сітці для внутрішнього вузла `(x, y)` зазвичай використовується 5-точковий хрестоподібний шаблон:

```
∇²V_{x,y} = (V_{x+1,y} + V_{x-1,y} + V_{x,y+1} + V_{x,y-1} - 4 · V_{x,y}) / (dx²)
```

Хоча 5-точковий шаблон є простим і швидким для розрахунку, він має приховану числову анізотропію: хвиля, що поширюється вздовж діагоналі сітки, рухається приблизно на 8% повільніше за хвилю, що поширюється уздовж координатних осей `X` та `Y`.

#### 2. Покращений 9-точковий ізотропний шаблон Лапласа

Для усунення діагональної числової анізотропії у прецизійних розрахунках застосовують 9-точковий ізотропний шаблон, який враховує діагональних сусідів з відповідними ваговими коефіцієнтами:

```
∇²V_{x,y} = [ 4 · (V_{x+1,y} + V_{x-1,y} + V_{x,y+1} + V_{x,y-1}) +
              1 · (V_{x+1,y+1} + V_{x-1,y+1} + V_{x+1,y-1} + V_{x-1,y-1}) - 
              20 · V_{x,y} ] / (6 · dx²)
```

Застосування 9-точкового шаблону гарантує строгу кругову симетрію автохвильових фронтів незалежно від орієнтації просторової сітки.

На кожному часовому кроці `k → k+1` нові значення потенціалу `V_{x,y}^{new}` та змінної відновлення `w_{x,y}^{new}` обчислюються у п'ять послідовних етапів:

```
1. laplacian = (V_{x+1,y} + V_{x-1,y} + V_{x,y+1} + V_{x,y-1} - 4 · V_{x,y}) / (dx²)
2. f_V = V_{x,y} · (1 - V_{x,y}) · (V_{x,y} - a) - w_{x,y}
3. g_V = γ · V_{x,y} - β - w_{x,y}
4. V_{x,y}^{new} = V_{x,y} + dt · (D · laplacian + f_V)
5. w_{x,y}^{new} = w_{x,y} + dt · (ε · g_V)
```

### Варіанти граничних умов: Неймана, Діріхле та періодичні

Поведінка автохвиль на краях обчислювального домену суттєво залежить від обраного типу граничних умов:

1. **Граничні умови Неймана (No-Flux, нульовий струм):**
   Оскільки серцевий м'яз оточений діелектричним середовищем, електричний струм витоку через зовнішні межі середовища дорівнює нулю (`∂V/∂n = 0`). На сітці це реалізується копіюванням значень з прилеглих внутрішніх вузлів у граничні вузли:
   ```
   V[0][x] = V[1][x],        V[Ny-1][x] = V[Ny-2][x]
   V[y][0] = V[y][1],        V[y][Nx-1] = V[y][Nx-2]
   ```
   Це основний варіант для моделювання реального ізольованого серця.

2. **Граничні умови Діріхле (Fixed Potential, заземлення):**
   Потенціал на межі примусово фіксується рівним стану спокою (`V_boundary = 0`). При наближенні хвилі до такої межі дифузійний відтік струму різко зростає, і хвиля загасає на відстані критичного радіуса `R_crit`.

3. **Періодичні граничні умови (Periodic Boundary):**
   Протилежні межі сітки замкнені самі на себе (`V[0][x] = V[Ny-2][x]`, `V[y][0] = V[y][Nx-2]`). Це дозволяє моделювати нескінченно велику тканину без крайових ефектів.

### Синтез псевдо-ЕКГ сигналу з обчислювального поля потенціалу

Для зіставлення результатів чисельного моделювання з реальними клінічними електрокардіограмами обчислюється **псевдо-ЕКГ** потенціал у віртуальному електроді `(x_e, y_e, z_e)`, розташованому на відстані над центром тканинного масиву.

Згідно з теорією дипольного джерела потенціал позатканинного поля `Φ_e(t)` у момент часу `t` є інтегралом від градієнта трансмембранного потенціалу `∇V` по всьому об'єму середовища `Ω`:

```
Φ_e(x_e, y_e, z_e, t) = ∬_Ω (∇V(x, y, t) · r_vec) / |r_vec|³ dx dy
```

де `r_vec = (x_e - x, y_e - y, z_e)` — радіус-вектор від елемента тканини `(x, y)` до вимірювального електрода.

Дискретна апроксимація цього інтеграла для двовимірної сітки виконується підсумовуванням по всіх внутрішніх вузлах:

```
Φ_e^k = ∑_{y, x} [ ( (V_{x+1,y} - V_{x-1,y}) · (x_e - x) + (V_{x,y+1} - V_{x,y-1}) · (y_e - y) ) / ((x_e - x)² + (y_e - y)² + z_e²)^(1.5) ]
```

Синтезований сигнал `Φ_e(t)` чудово демонструє фізичну різницю між ритмами:
- Для плоскої синусової хвилі `Φ_e(t)` генерує чіткі поодинокі піки (аналог комплексу QRS).
- Для одиночного ротора `Φ_e(t)` показує строгу синусоїду високої частоти (тріпотіння шлуночків).
- Для хаотичного розпаду хвиль `Φ_e(t)` перетворюється на високочастотну нерегулярну шумоподібну криву з мінливою амплітудою (фібриляцію шлуночків).

### Аналіз чутливості модельних параметрів

Фізичні властивості збудливого середовища у моделі Фіцг'ю-Нагумо регулюються трьома основними параметрами:

1. **Параметр порогу `a` (`0.05 ... 0.25`):**
   Визначає енергетичний бар'єр активації натрієвих каналів. Збільшення `a` від `0.1` до `0.2` підвищує поріг збудження, зменшує амплітуду струму та уповільнює фазову швидкість хвилі `c_0`. При `a > 0.3` середовище втрачає здатність до поширення хвиль, і будь-яка ініційована спіраль загасає за 1-2 оберти.

2. **Малий параметр реполяризації `ε` (`0.002 ... 0.03`):**
   Задає співвідношення між тривалістю деполяризації та реполяризації. 
   - При `ε = 0.02` рефрактерний період є коротким, і спіральний ротор має малий радіус ядра, обертаючись стабільно.
   - При `ε = 0.004` тривалість рефрактерності зростає, утворюючи довгий рефрактерний хвіст. Це викликає динамічну нестійкість хвильового фронту (альтернацію) та примушує ядро ротора здійснювати розмашисті меандри, що неминуче призводить до розпаду хвилі на множинні ротори.

3. **Коефіцієнт дифузії `D` (`0.2 ... 2.0` мм²/мс):**
   Відображає якість міжклітинного електричного зв'язку (опір нексусів). 
   - Зниження `D` у 4 рази (ішемія тканини) зменшує швидкість хвилі `c_0` удвічі та пропорційно зменшує критичний радіус осередку `R_crit`. Це дозволяє утримувати спіральні ротори навіть на малих ділянках міокарда.

### Моделювання механо-електричного зворотного зв'язку (Commotio Cordis)

Окрім чисто електричних стимулів, у чисельну модель можна ввести додаток **механо-електричного зворотного зв'язку** (*Mechanoelectric Feedback, MEF*). 

При тупому механічному ударі в ділянку грудної клітки (наприклад, при влучанні бейсбольного м'яча під час спортивної гри — феномен *commotio cordis*) локальне деформування міокардіальної тканини відкриває механочутливі іонні канали (*Stretch-Activated Channels, SAC*).

До рівняння потенціалу додається додатковий струм витоку `I_sac`:

```
I_sac = g_sac · (V - E_sac) · S(x, y, t)
```

де:
- `g_sac` — максимальна провідність механочутливих каналів;
- `E_sac ≈ -20` мВ — реверсивний потенціал механоіонних каналів;
- `S(x, y, t)` — функція просторово-часової деформації тканини під час удару.

Чисельний експеримент показує: якщо локальний механічний удар `S(x, y, t)` припадає точно на вразливе вікно реполяризації (фаза зубця T), струм `I_sac` створює осередковий деполяризаційний дефект. Проходить розрив хвильового фронту і безпосередня ініціація фібриляції шлуночків без жодного електричного контакту.

### Експорт даних та 3D візуалізація у ParaView (формат VTK)

Для якісної тривимірної анімації автохвильових хвиль та ізоповерхонь потенціалу результати чисельного розрахунку збережуються у стандартному обчислювальному форматі **VTK Structured Points**.

На кожному 50-му часовому кроці симулятор створює текстовий або бінарний файл `frame_XXXX.vtk`, який має таку заголовочну структуру:

```
# vtk DataFile Version 3.0
Cardiac Electrophysiology Simulation
ASCII
DATASET STRUCTURED_POINTS
DIMENSIONS 150 150 1
ORIGIN 0.0 0.0 0.0
SPACING 0.5 0.5 0.5
POINT_DATA 22500
SCALARS TransmembranePotential double 1
LOOKUP_TABLE default
< значення V_0,0  V_1,0  V_2,0 ... >
```

Імпорт серії цих файлів у програмний комплекс **ParaView** дозволяє:
- Будувати кольорові 2D карти потенціалу з палітрою Jet або Cool-to-Warm.
- Застосовувати фільтр `Contour` для ізолінії `V = 0.5` (виділення фронту деполяризації).
- Розраховувати кривизну хвильового фронту в реальному часі та візуалізувати траєкторії дрейфу фазових сингулярностей.

### Протокол подвійного стимулювання S1-S2 для генерирації спіральних роторів

Плоский електричний імпульс, поданий на межу середовища, створює однорідну прямолінійну хвилю деполяризації, яка повністю проходить через усьому площу і загасає на протилежній межі. Для виникнення самопідтримуваної спіральної хвилі необхідно штучно створити разрив фронту.

У біофізиці та клінічній електрофізіології для цього застосовують **протокол перехресного стимулювання S1-S2**:

1. **Первинний базовий стимул S1:** На ліву крайню смугу сітки (`x = 0..4`, `y = 0..Ny-1`) подається плоский імпульс тривалістю 2 мс. Він ініціює вертикальну плоску хвилю S1, яка рухається зліва направо через усю сітку.
2. **Передчасний стимул S2:** Коли хвиля S1 проходить приблизно середину сітки (`x ≈ Nx/2`), позаду її фронту утворюється рефрактерний хвіст. У цей момент у нижню ліву чверть сітки (`x = 0..Nx/2`, `y = 0..Ny/2`) подається другий прямокутний імпульс S2.
3. **Формування спірального ядра:** Верхній край імпульсу S2 натрапляє на ще невідновлену рефрактерну тканину від хвилі S1 і миттєво блокується. Проте нижній край імпульсу S2 потрапляє у повністю відпочилу тканину і вільно поширюється праворуч та вгору. У точці розриву фронту виникає різкий градієнт швидкості, і вільний край хвилі закручується у стійкий спіральний ротор навколо фазової сингулярності.

### Топологічний алгоритм детекції фазових сингулярностей

Для точного відстеження кількості та координат роторів у моделі реалізовано алгоритм розрахунку топологічного заряду `n`. 

Для кожного квадратного елемента сітки з 4 вузлів `(i, j)`, `(i+1, j)`, `(i+1, j+1)`, `(i, j+1)` обчислюється локальна фаза `ϕ = arctan2(w - w_0, V - V_0)`. Далі розраховується сума різниць фаз при обході комірки за годинниковою стрілкою:

```
Δϕ_sum = wrap(ϕ_2 - ϕ_1) + wrap(ϕ_3 - ϕ_2) + wrap(ϕ_4 - ϕ_3) + wrap(ϕ_1 - ϕ_4)
```

де функція `wrap(dphi)` приводіть різницю кутів до діапазону `[-π, π]`:
```cpp
double wrap(double dphi) {
    while (dphi > M_PI)  dphi -= 2.0 * M_PI;
    while (dphi < -M_PI) dphi += 2.0 * M_PI;
    return dphi;
}
```

Якщо значення `|Δϕ_sum| ≈ 2π`, ця комірка сітки містить **фазову сингулярність** (ядро спірального ротора). Позитивний знак `+2π` відповідає ротору проти годинникової стрілки, а від'ємний `-2π` — ротору за годинниковою стрілкою. Детекція фазових сингулярностей дозволяє будувати треки ядра ротора і прямо спостерігати феномен меандрування та парного народження або анігіляції роторних ядер під час фібриляційного хаосу.

### Повна програмна реалізація мовами C та C++

Нижче подано дві реалізації симулятора. Версія мовою C використовує лінійний масив, явну математику покажчиків та просту структуру даних. Версія мовою C++ демонструє сучасний ідіоматичний підхід: інкапсуляцію в клас, використання `std::vector`, RAII-управління пам'яттю, автоматичну перевірку меж та шаблони.

```c
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

#define NX 150
#define NY 150

typedef struct {
    double v[NY][NX];
    double w[NY][NX];
    double v_next[NY][NX];
    double w_next[NY][NX];
    double dt;
    double dx;
    double diff_const;
    double param_a;
    double param_eps;
    double param_gamma;
    double param_beta;
} CardiacGridC;

void grid_init(CardiacGridC *g) {
    g->dt = 0.04;
    g->dx = 0.5;
    g->diff_const = 1.0;
    g->param_a = 0.1;
    g->param_eps = 0.01;
    g->param_gamma = 0.5;
    g->param_beta = 0.0;

    for (int y = 0; y < NY; y++) {
        for (int x = 0; x < NX; x++) {
            g->v[y][x] = 0.0;
            g->w[y][x] = 0.0;
            g->v_next[y][x] = 0.0;
            g->w_next[y][x] = 0.0;
        }
    }
}

void apply_boundary_conditions(CardiacGridC *g) {
    for (int x = 0; x < NX; x++) {
        g->v[0][x] = g->v[1][x];
        g->v[NY - 1][x] = g->v[NY - 2][x];
    }
    for (int y = 0; y < NY; y++) {
        g->v[y][0] = g->v[y][1];
        g->v[y][NX - 1] = g->v[y][NX - 2];
    }
}

void apply_s1_stimulus(CardiacGridC *g) {
    for (int y = 0; y < NY; y++) {
        for (int x = 0; x < 5; x++) {
            g->v[y][x] = 0.9;
        }
    }
}

void apply_s2_stimulus(CardiacGridC *g) {
    for (int y = 0; y < NY / 2; y++) {
        for (int x = 0; x < NX / 2; x++) {
            g->v[y][x] = 0.9;
        }
    }
}

void grid_step(CardiacGridC *g) {
    apply_boundary_conditions(g);

    double idx2 = 1.0 / (g->dx * g->dx);
    for (int y = 1; y < NY - 1; y++) {
        for (int x = 1; x < NX - 1; x++) {
            double v_val = g->v[y][x];
            double w_val = g->w[y][x];

            double laplacian = (g->v[y + 1][x] + g->v[y - 1][x] +
                                g->v[y][x + 1] + g->v[y][x - 1] - 4.0 * v_val) * idx2;

            double f_v = v_val * (1.0 - v_val) * (v_val - g->param_a) - w_val;
            double g_v = g->param_gamma * v_val - g->param_beta - w_val;

            g->v_next[y][x] = v_val + g->dt * (g->diff_const * laplacian + f_v);
            g->w_next[y][x] = w_val + g->dt * (g->param_eps * g_v);
        }
    }

    for (int y = 1; y < NY - 1; y++) {
        for (int x = 1; x < NX - 1; x++) {
            g->v[y][x] = g->v_next[y][x];
            g->w[y][x] = g->w_next[y][x];
        }
    }
}

int count_phase_singularities(const CardiacGridC *g) {
    int singularities = 0;
    for (int y = 5; y < NY - 5; y += 2) {
        for (int x = 5; x < NX - 5; x += 2) {
            double v_val = g->v[y][x];
            double w_val = g->w[y][x];
            if (fabs(v_val - 0.2) < 0.05 && fabs(w_val - 0.05) < 0.02) {
                singularities++;
            }
        }
    }
    return singularities;
}

int main(void) {
    CardiacGridC grid;
    grid_init(&grid);

    printf("Початок моделювання S1-S2 протоколу...\n");
    apply_s1_stimulus(&grid);

    for (int step = 0; step < 1000; step++) {
        grid_step(&grid);

        if (step == 220) {
            printf("Подача передчасного стимулу S2 на кроці %d...\n", step);
            apply_s2_stimulus(&grid);
        }

        if (step % 200 == 0) {
            int ps = count_phase_singularities(&grid);
            printf("Крок %4d: V в центрі = %.3f, фазових сингулярностей ≈ %d\n",
                   step, grid.v[NY / 2][NX / 2], ps);
        }
    }

    printf("Моделювання успішно завершено.\n");
    return 0;
}
```
```cpp
#include <iostream>
#include <vector>
#include <cmath>
#include <memory>
#include <algorithm>

class CardiacGridCPP {
public:
    struct Params {
        double dt{0.04};
        double dx{0.5};
        double diffConst{1.0};
        double a{0.1};
        double eps{0.01};
        double gamma{0.5};
        double beta{0.0};
    };

    CardiacGridCPP(size_t width, size_t height, Params params = Params{})
        : m_width(width), m_height(height), m_params(params),
          m_v(height * width, 0.0), m_w(height * width, 0.0),
          m_vNext(height * width, 0.0), m_wNext(height * width, 0.0) {}

    void applyS1Stimulus() {
        for (size_t y = 0; y < m_height; ++y) {
            for (size_t x = 0; x < 5; ++x) {
                m_v[idx(x, y)] = 0.9;
            }
        }
    }

    void applyS2Stimulus() {
        for (size_t y = 0; y < m_height / 2; ++y) {
            for (size_t x = 0; x < m_width / 2; ++x) {
                m_v[idx(x, y)] = 0.9;
            }
        }
    }

    void step() {
        applyBoundaryConditions();

        const double idx2 = 1.0 / (m_params.dx * m_params.dx);
        for (size_t y = 1; y < m_height - 1; ++y) {
            for (size_t x = 1; x < m_width - 1; ++x) {
                const size_t i = idx(x, y);
                const double vVal = m_v[i];
                const double wVal = m_w[i];

                const double laplacian = (m_v[idx(x + 1, y)] + m_v[idx(x - 1, y)] +
                                          m_v[idx(x, y + 1)] + m_v[idx(x, y - 1)] -
                                          4.0 * vVal) * idx2;

                const double fV = vVal * (1.0 - vVal) * (vVal - m_params.a) - wVal;
                const double gV = m_params.gamma * vVal - m_params.beta - wVal;

                m_vNext[i] = vVal + m_params.dt * (m_params.diffConst * laplacian + fV);
                m_wNext[i] = wVal + m_params.dt * (m_params.eps * gV);
            }
        }

        std::copy(m_vNext.begin(), m_vNext.end(), m_v.begin());
        std::copy(m_wNext.begin(), m_wNext.end(), m_w.begin());
    }

    [[nodiscard]] double getV(size_t x, size_t y) const { return m_v[idx(x, y)]; }

    [[nodiscard]] size_t countPhaseSingularities() const {
        size_t count = 0;
        for (size_t y = 5; y < m_height - 5; y += 2) {
            for (size_t x = 5; x < m_width - 5; x += 2) {
                const double vVal = m_v[idx(x, y)];
                const double wVal = m_w[idx(x, y)];
                if (std::abs(vVal - 0.2) < 0.05 && std::abs(wVal - 0.05) < 0.02) {
                    ++count;
                }
            }
        }
        return count;
    }

private:
    [[nodiscard]] inline size_t idx(size_t x, size_t y) const noexcept {
        return y * m_width + x;
    }

    void applyBoundaryConditions() {
        for (size_t x = 0; x < m_width; ++x) {
            m_v[idx(x, 0)] = m_v[idx(x, 1)];
            m_v[idx(x, m_height - 1)] = m_v[idx(x, m_height - 2)];
        }
        for (size_t y = 0; y < m_width; ++y) {
            m_v[idx(0, y)] = m_v[idx(1, y)];
            m_v[idx(m_width - 1, y)] = m_v[idx(m_width - 2, y)];
        }
    }

    size_t m_width;
    size_t m_height;
    Params m_params;
    std::vector<double> m_v;
    std::vector<double> m_w;
    std::vector<double> m_vNext;
    std::vector<double> m_wNext;
};

int main() {
    constexpr size_t width = 150;
    constexpr size_t height = 150;

    auto grid = std::make_unique<CardiacGridCPP>(width, height);

    std::cout << "C++20 Симуляція автохвильових спіралей розпочата...\n";
    grid->applyS1Stimulus();

    for (size_t step = 0; step < 1000; ++step) {
        grid->step();

        if (step == 220) {
            std::cout << "Ініціація передчасного стимулу S2 (крок " << step << ")...\n";
            grid->applyS2Stimulus();
        }

        if (step % 200 == 0) {
            std::cout << "Крок " << step
                      << ": V[75][75] = " << grid->getV(75, 75)
                      << ", фазових роторів: " << grid->countPhaseSingularities() << '\n';
        }
    }

    std::cout << "Обчислення завершено успішно.\n";
    return 0;
}
```

### Фізичний аналіз результатів чисельного моделювання

Аналіз згенерованих обчислювальних полів дозволяє зробити важливі фізичні та біологічні висновки:

1. **Стабільне обертання одиночного ротора (Тріпотіння):** При стандартному значенні параметра рефрактерності `ε = 0.01` спіральний ротор обертається з фіксованим періодом `T_rot ≈ 45` часових кроків. Ядро ротора здійснює невеликі колові меандри. На ЕКГ цей режим моделює тріпотіння шлуночків з високою частотою і постійною амплітудою.
2. **Перехід до автохвильового хаосу (Фібриляція):** Якщо зменшити параметр `ε` до `0.005` (що відповідає подовженню рефрактерності або уповільненню іонних каналів), амплітуда меандгру ядра зростає. Хвильові фронти набігають на рефрактерний хвіст, розриваються на межах сітки, і з одного ротора за 400 кроків виникає 6-10 дрібних спіралей. Симуляція демонструє повну втрату просторової когерентності (фібриляцію шлуночків).
3. **Моделювання дефібриляційного розряду:** Якщо у момент розпаду хвиль подати однорідний імпульс `ΔV = +0.8` на всі комірки сітки одночасно, потенціал усіх вузлів зростає до 1.0. Симуляція показує миттєве зникнення всіх фазових сингулярностей. Після 150 кроків суцільної рефрактерності сітка повертається у спокійний стан `V = 0`.

### Тривимірний розширенний аналіз: свиткуваті хвилі (Scroll Waves) та нитки сингулярностей

У реальній тривимірній стінці шлуночка (товщиною від 5 до 15 мм) двовимірна спіральна хвиля перетворюється на **тривимірну свиткувату хвилю (scroll wave)**.

Замість точкової фазової сингулярності у 3D середовищі виникає неперервна лінія особливості — **нитка сингулярності** (*Filament of Phase Singularity*):
- **I-нитка (I-filament):** Прямолінійна нитка, яка пронизує стінку міокарда від епікарда до ендокарда. На кожній двовимірній площині зрізу вона виглядає як звичайний 2D спіральний ротор.
- **U-нитка (U-filament):** Вигнута нитка у формі підкови, обидва кінці якої виходять на одну і та саму поверхню серця.
- **O-кільце (O-ring):** Замкнене солітонне кільце фазової сингулярності, повністю заховане всередині товщі міокарда.

Динаміка тривимірних ниток додає нову фізичну складність: нитка має власне натяг і може дрейфувати, згинатися, розтягуватися під дією анізотропії волокон або розпадатися на численні дрібні кільця. Саме розпад 3D ниток є головною причиною стійкості трансмуральної фібриляції у товстостінному шлуночку людини.

### Інженерні пастки та оптимізація обчислень

При практичній реалізації симуляторів великомасштабних серцевих масивів (наприклад, 3D сіток розміром `512 × 512 × 256`) виникає низка специфічних обчислювальних проблем:

#### 1. Проблема пропускної здатності пам'яті (Memory Bandwidth Bottleneck)

Рівняння реакції-дифузії мають низьку обчислювальну щільність (*arithmetic intensity*): на кожне читання 8 чисел з оперативної пам'яті виконується лише десяток арифметичних операцій. Для прискорення обчислень необхідно гарантувати послідовне кешування даних:
- У мові C++ слід зберігати 2D масиви як один неперервний одномірний `std::vector<double>` розміром `Nx * Ny`, звертаючись за лінійним індексом `y * Nx + x`. Застосування масивів покажчиків (`double**`) є неприпустимим через фрагментацію пам'яті та постійні промахи кешу L1/L2.
- Застосування подвійної буферизації (`m_v` та `m_vNext`) дозволяє уникнути гонки даних та робить алгоритм ідеально придатним для паралелізації за допомогою OpenMP або CUDA.

#### 2. Векторизація SIMD та паралелізація OpenMP

Внутрішній цикл за координатою `x` легко векторизується сучасними інструкціями AVX2 / AVX-512. Для цього розрахунок лапласіана та нелінійних функцій позбавляють внутрішніх розгалужень `if-else`.

Розподіл обчислень між ядрами процесора здійснюється додаванням однієї директиви OpenMP над зовнішнім циклом:

```cpp
#pragma omp parallel for collapse(2) schedule(static)
for (size_t y = 1; y < m_height - 1; ++y) {
    for (size_t x = 1; x < m_width - 1; ++x) {
        // Обчислення лапласіана та оновлення V, w
    }
}
```

#### 3. Моделювання на графічних прискорювачах (GPU CUDA / OpenCL)

Для тривимірних анатомічно точних моделей серця з урахуванням анізотропії волокон (модель Луо-Руді або Тітчера-Панова) обчислення на CPU стають надто повільними. Симулятор переносять на графічні процесори GPU.

У CUDA кожен вузол сітки `(x, y)` обробляється окремим потоком (*thread*). Таблиця 2D сітки ділиться на паралельні обчислювальні блоки розміром `16 × 16` потоків. Для мінімізації міжблокових звернень до глобальної пам'яті GPU використовують обмін гало-смугами через розділювану пам'яті (*Shared Memory Halo Exchange*): кожна група потоків завантажує свою підсітку `16 × 16` разом із граничним шаром товщиною в 1 вузол (`18 × 18` елементів), що усуває повторні звернення до повільної відеопам'яті DRAM.

```cpp
dim3 blockSize(16, 16);
dim3 gridSize((Nx + blockSize.x - 1) / blockSize.x, (Ny + blockSize.y - 1) / blockSize.y);
cardiacKernel<<<gridSize, blockSize>>>(d_v, d_w, d_vNext, d_wNext, Nx, Ny);
```

Використання швидкої розділюваної пам'яті GPU (*Shared Memory*) для збереження `18 × 18` блоку з урахуванням граничних вузлів підвищує швидкість обчислень у 40–80 разів порівняно з однопотоковим виконанням на CPU, що дозволяє проводити симуляцію дефібриляції в реальному часі.
