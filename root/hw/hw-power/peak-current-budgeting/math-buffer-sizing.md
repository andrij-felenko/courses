# 🧮 Математичний розрахунок буферної ємності та допустимого ESR

Коли автономний передавач вмикає вихідний каскад підсилювача потужності, струм у колі живлення стрибкоподібно зростає на кілька порядків за частки мікросекунди. Якщо джерело живлення має скінченний внутрішній опір (хімічний опір батареї, опір дроселя перетворювача чи падіння на регуляторі), напруга на живильній шині падає. Щоб напруга не опустилася нижче критичного порогу апаратного скидання мікроконтролера, паралельно шині встановлюють буферний накопичувач. Нижче виведено аналітичні формули для точного розрахунку мінімальної необхідної ємності та гранично допустимого еквівалентного послідовного опору (ESR) буферного конденсатора як для лінійного навантаження постійного струму, так і для нелінійного навантаження постійної потужності.

### 1. Динамічна модель перехідного процесу розряду

Розглянемо розподільчу мережу живлення під час імпульсу постійного струму навантаження `I_пік` тривалістю `t_імп`.

Джерело живлення характеризується напругою холостого ходу `V_0` та власним еквівалентним внутрішнім опором `R_джерела` (що об'єднує опір хімічної комірки, контактів та провідників друкованої плати). Паралельно навантаженню підключено буферний конденсатор із номінальною ємністю `C` та власним еквівалентним послідовним опором `R_esr`.

У початковий момент часу `t = 0` конденсатор повністю заряджений до напруги `V_0`. При миттєвому стрибку струму навантаження від `0` до `I_пік` струм розподіляється між двома паралельними гілками — джерелом живлення та буферним конденсатором.

За законами Кірхгофа миттєва напруга на шині `V_шина(t)` описується диференціальним рівнянням першого порядку:

```
V_шина(t) = V_0 − I_пік · R_екв − (I_пік − I_джерела_стац) · (R_джерела² / (R_джерела + R_esr)) · (1 − exp(−t / τ))
```

де еквівалентний паралельний опір у початковий момент комутації:

```
R_екв
= (R_джерела · R_esr) / (R_джерела + R_esr)    [паралельне з'єднання опорів джерела та буфера]
```

а стала часу зарядно-розрядного контуру:

```
τ
= (R_джерела + R_esr) · C                      [еквівалентна стала часу RC-ланцюга]
```

### 2. Декомпозиція просідання напруги на дві складові

Повне динамічне падіння напруги `ΔV_макс = V_0 − V_шина_мін` складається з двох фізично різних процесів: миттєвого омічного стрибка на послідовних опорах та подальшого монотонного розряду ємності під інтегральним струмом імпульсу.

```
ΔV_макс
= ΔV_esr + ΔV_c                                [сума омічного та ємнісного просідання]
```

1. **Миттєвий стрибок на опорі ESR (`ΔV_esr`):**
У перші наносекунди після комутації ємність поводиться як коротке замикання, і весь піковий струм протікає крізь еквівалентний опір. Оскільки внутрішній опір первинної батареї (`R_джерела`, наприклад 20–50 Ом для дискової батареї CR2032) значно перевищує опір керамічного чи танталового конденсатора (`R_esr` близько 0.01–0.1 Ом), струм майже повністю замикається через конденсатор:

```
ΔV_esr
= I_пік · R_esr                                [омічне падіння на паразитному опорі буфера]
```

2. **Ємнісний розряд (`ΔV_c`):**
Протягом тривалості імпульсу `t_імп` конденсатор віддає заряд `ΔQ`. Джерело живлення одночасно підживлює шину граничним струмом `I_джерела_макс ≈ (V_0 − V_шина_мін) / R_джерела`. У найгіршому випадку (коли джерело має високий опір або низьку температуру і не встигає віддати помітний струм за короткий час `t_імп`), весь імпульс живиться виключно з енергії електричного поля конденсатора:

```
ΔQ
= I_пік · t_імп                                [повний заряд імпульсу навантаження]
```

Зміна напруги на ідеальній ємності за час `t_імп`:

```
ΔV_c
= ΔQ / C
= (I_пік · t_імп) / C                          [ємнісний спад за законом кулонівського розряду]
```

### 3. Аналітичне виведення мінімальної ємності C_min

Нехай `V_мін_доп` — мінімальна допустима напруга на шині живлення, яка гарантує запас надійності відносно порогу скидання Brownout Reset (`V_bor`):

```
V_мін_доп
= V_bor + V_запас                              [робочий поріг із запасом надійності]
```

Максимально допустиме сумарне просідання напруги:

```
ΔV_доп
= V_0 − V_мін_доп                              [максимально дозволена глибина провалу]
```

Підставимо складові просідання у нерівність стійкості живлення:

```
ΔV_esr + ΔV_c ≤ ΔV_доп
I_пік · R_esr + (I_пік · t_імп) / C ≤ ΔV_доп
(I_пік · t_імп) / C ≤ ΔV_доп − I_пік · R_esr   [перенесення омічного члена праворуч]
```

Звідси отримуємо базову формулу для мінімальної необхідної ємності буфера:

```
C_мін
= (I_пік · t_імп) / (ΔV_доп − I_пік · R_esr)   [аналітичний розрахунок ємності буфера]
```

Зі знаменника безпосередньо випливає фундаментальне фізичне обмеження: якщо омічне просідання `I_пік · R_esr` перевищує допустимий бюджет `ΔV_доп`, знаменник стає нульовим або від'ємним. Це означає, що **жодна, навіть нескінченно велика ємність, не врятує шину від просідання**, якщо паразитно-послідовний опір конденсатора занадто великий.

Гранично допустиме значення ESR конденсатора:

```
R_esr_макс
= ΔV_доп / I_пік                               [верхня межа ESR для збереження працездатності]
```

### 4. Модель нелінійного навантаження постійної потужності (DC-DC перетворювач)

У багатьох сучасних архітектурах радіомодуль або ядро процесора живляться не безпосередньо від батареї, а через імпульсний понижувальний перетворювач (Buck DC-DC) з високим коефіцієнтом корисної дії `η`.

Імпульсний стабілізатор підтримує сталу напругу на виході `V_вих` при сталому струмі радіочастотного каскаду `I_вих`. Таким чином, вхідна потужність перетворювача є константою:

```
P_вх
= (V_вих · I_вих) / η = P_конст                [стала споживана потужність перетворювача]
```

Струм, що відбирається від вхідної шини живлення `V_шина(t)`, становить:

```
I_вх(t)
= P_конст / V_шина(t)                          [струм навантаження зі зворотною залежністю від напруги]
```

Це створює ефект **негативного динамічного опору**: при просіданні вхідної напруги `V_шина` перетворювач для збереження вихідної потужності змушений тягнути **ще більший вхідний струм**. Диференціальне рівняння розряду конденсатора набуває нелінійного вигляду:

```
C · (dV_c / dt)
= −P_конст / (V_c − I_вх · R_esr)              [нелінійне диференціальне рівняння розряду]
```

Нехтуючи на першому кроці `R_esr` для аналітичної оцінки та розділяючи змінні:

```
V_c · dV_c
= −(P_конст / C) · dt                          [розділення змінних]

∫ [від V_0 до V_мін] V_c dV_c
= −(P_конст / C) · ∫ [від 0 до t_імп] dt       [інтегрування за інтервалом імпульсу]

(V_0² − V_мін²) / 2
= (P_конст · t_імп) / C                        [інтеграл лівої та правої частин]
```

Звідси отримуємо точну формулу мінімальної ємності для імпульсних стабілізаторів постійної потужності:

```
C_мін_потужність
= (2 · P_конст · t_імп) / (V_0² − V_мін²)      [розрахунок ємності за енергетичним балансом]
```

Ця формула демонструє, що ємність визначається різницею квадратів напруг (тобто зміною запасеної електростатичної енергії `ΔE = 0.5 · C · (V_0² − V_мін²)`), а не лінійною різницею напруг.

### 5. Врахування струму підживлення від джерела (модель помірного опору)

Якщо джерело живлення має помірний внутрішній опір `R_джерела` (наприклад, літій-тіонілхлоридна батарея Li-SOCl₂ або лінійний стабілізатор LDO в режимі обмеження струму `I_src_max`), струм джерела частково компенсує розряд:

```
I_ефект
= I_пік − I_джерела_мін                        [чистий струм розряду буферної ємності]
```

де мінімальний струм, що постачається джерелом у найглибшій точці просідання:

```
I_джерела_мін
= (V_0 − (V_0 − ΔV_доп)) / R_джерела
= ΔV_доп / R_джерела                           [струм підживлення через внутрішній опір]
```

Підставляючи `I_ефект` у рівняння ємності:

```
C_мін_піджив
= ((I_пік − ΔV_доп / R_джерела) · t_імп) / (ΔV_доп − I_пік · R_esr)  [розрахунок із компенсацією струму джерела]
```

### 6. Коефіцієнти деградації (DC Bias, температура та старіння)

Реальний керамічний конденсатор (MLCC класу II: X5R, X7R) суттєво втрачає ємність під впливом постійної напруги зміщення (DC Bias Derating), температури та виробничого розкиду. Номінальна ємність для замовлення компонентів `C_ном` розраховується з урахуванням трьох коефіцієнтів запасу:

```
C_ном
= C_мін / (k_dcbias · k_temp · k_tol)          [номінал замовлення з урахуванням деградацій]
```

де:
- `k_dcbias` — коефіцієнт збереження ємності під робочою напругою `V_0` (для типорозміру 0402 при 3.3 В становить `0.30–0.45`, тобто втрата до 70%);
- `k_temp` — температурний коефіцієнт на межах робочого діапазону (`0.85–0.90` для X7R при −40 °C);
- `k_tol` — початковий виробничий допуск (`0.80` для номіналу ±20%).

### 7. Повний інженерний приклад розрахунку

**Умова задачі:**
Автономний датчик із модулем бездротового зв'язку NB-IoT живиться від літієвої дискової батареї CR2032 (`V_0 = 3.0 В`, `R_джерела = 25 Ом` при 20 °C, до `80 Ом` при −20 °C).
- Піковий струм радіопередачі: `I_пік = 320 мА` (`0.32 А`).
- Тривалість імпульсу передачі пакета: `t_імп = 15 мс` (`0.015 с`).
- Поріг Brownout Reset мікроконтролера: `V_bor = 2.20 В`.
- Бажаний запас надійності: `V_запас = 0.20 В` (мінімальна напруга шини `V_мін_доп = 2.40 В`).
- Параметри буферного тантало-полімерного конденсатора POSCAP: `R_esr = 35 мОм` (`0.035 Ом`).

**Покроковий розрахунок:**

```
ΔV_доп
= 3.00 В − 2.40 В
= 0.60 В                                       [допустимий бюджет просідання напруги]

ΔV_esr
= 0.32 А · 0.035 Ом
= 0.0112 В ≈ 11.2 мВ                           [омічне падіння на ESR буфера]

ΔV_c_доп
= ΔV_доп − ΔV_esr
= 0.60 В − 0.0112 В
= 0.5888 В                                     [залишок бюджету на ємнісний розряд]

C_мін_ідеал
= (I_пік · t_імп) / ΔV_c_доп
= (0.32 А · 0.015 с) / 0.5888 В
= 0.0048 Кл / 0.5888 В
≈ 0.00815 Ф = 8150 мкФ                         [мінімальна ємність без підживлення]
```

Врахуємо струм підживлення від батареї за найгіршої температури (−20 °C, `R_джерела = 80 Ом`):

```
I_джерела_мін
= 0.60 В / 80 Ом
= 0.0075 А = 7.5 мА                            [мінімальний струм батареї під навантаженням]

I_ефект
= 0.320 А − 0.0075 А
= 0.3125 А                                     [чистий розрядний струм конденсатора]

C_мін_реальне
= (0.3125 А · 0.015 с) / 0.5888 В
= 0.0046875 Кл / 0.5888 В
≈ 7961 мкФ                                     [уточнена мінімальна ємність буфера]
```

Оскільки ємність близько 8000 мкФ занадто велика для кераміки MLCC (вимагала б сотень корпусів), доцільно застосувати комбінований буфер: іоністор (EDLC) ємністю `0.1 Ф` (`100 000 мкФ`) із власним `R_esr = 0.5 Ом` у парі з танталовим конденсатором `100 мкФ` (`R_esr = 30 мОм`) для зрізання початкового омічного сплеску.
