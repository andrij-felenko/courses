# 🧮 Розрахунок демпфера та пульсацій

Коли на столі осцилограф показує на виході імпульсного стабілізатора нерівну напругу, перед інженером постають два окремі розрахункові завдання. Перше — обчислити амплітуду детермінованих низькочастотних пульсацій, що залежать від параметрів дроселя та вихідної ємності. Друге — розрахувати параметри демпферного RC-ланцюга (снубера) для комутаційного вузла, де високочастотний дзвін виникає на невідомих заздалегідь паразитних індуктивностях доріжок та ємностях напівпровідникових ключів. Обидва розрахунки вимагають послідовного математичного виведення від фізичних законів накопичення заряду та коливальних процесів у контурі другого порядку.

### 1. Математична декомпозиція низькочастотних пульсацій

У [знижувальному перетворювачі (buck)](root:hw-power/buck) струм дроселя `I_L(t)` складається з постійної складової струму навантаження `I_out` та змінної трикутної складової з розмахом `ΔI_L`. На виході цей змінний струм тече крізь [вихідний конденсатор](root:hw-power/converter-caps), який у реальній схемі моделюється послідовним з'єднанням ідеальної ємності `C_out`, еквівалентного послідовного опору `ESR` та еквівалентної послідовної індуктивності `ESL`.

Миттєве відхилення вихідної напруги `v_rip(t)` від середнього значення є сумою трьох фізично незалежних спадів напруги:

```text
v_rip(t) = v_C(t) + v_ESR(t) + v_ESL(t)
```

Розгляньмо внесок кожного компонента окремо протягом періоду комутації `T_sw = 1 / f_sw`.

#### Ємнісна складова (інтегрування заряду)

Змінний струм, що втікає в ємність, дорівнює `i_C(t) = i_L(t) − I_out`. Протягом першої половини інтервалу, коли `i_L(t) > I_out`, конденсатор накопичує надлишковий електричний заряд `ΔQ`. Оскільки форма хвилі струму є симетричним трикутником із базою `T_sw / 2` та висотою `ΔI_L / 2`, площа трикутника над нульовою лінією визначає накопичений заряд:

```text
ΔQ = (1/2) · (T_sw / 2) · (ΔI_L / 2)
   = (T_sw · ΔI_L) / 8                     [геометрична площа трикутника струму]
   = ΔI_L / (8 · f_sw)                     [підстановка T_sw = 1 / f_sw]
```

Зміна напруги на чистій ємності через зміну заряду становить:

```text
ΔV_C = ΔQ / C_out
     = ΔI_L / (8 · f_sw · C_out)           [ділення заряду на ємність]
```

Ця складова має форму квадратичної параболи, зміщеної за фазою на 90 градусів відносно струму дроселя.

#### Резистивна складова (падіння на ESR)

Струм трикутника з повним розмахом від піку до піку `ΔI_L`, протікаючи крізь активний опір `ESR`, створює синфазне падіння напруги за законом Ома:

```text
ΔV_ESR = ΔI_L · ESR                        [закон Ома для змінного струму]
```

Ця складова повторює форму трикутного струму без жодного зсуву фази.

#### Індуктивна складова (стрибок на ESL)

На кожному фронті перемикання ключа швидкість зміни струму дроселя `di_L / dt` миттєво змінює знак. Хоча струм дроселя безперервний, його похідна зазнає розриву першого роду. Стрибок напруги на внутрішній індуктивності конденсатора `ESL` становить:

```text
ΔV_ESL = ESL · (di_L / dt_on + |di_L / dt_off|)
       = ESL · ( (V_in − V_out)/L + V_out/L )  [похідні струму при заряді й розряді]
       = ESL · (V_in / L)                      [спрощення суми напруг]
```

У сучасній багатошаровій кераміці (MLCC) величина `ESL` становить від 0.2 до 0.8 нГн, тому для частот нижче 2 МГц внесок `ΔV_ESL` незначний порівняно з `ΔV_C` та `ΔV_ESR`, однак він створює короткі сходинки на піках трикутника.

#### Сумарний розмах низькочастотних пульсацій

Оскільки піки напруги на ємності `v_C(t)` та опорі `v_ESR(t)` зсунуті в часі на чверть періоду (максимум струму відповідає середині інтервалу інтегрування, коли похідна заряду дорівнює нулю), точний геометричний розмах пульсацій `ΔV_out(pp)` залежить від співвідношення між постійною часу конденсатора `τ = ESR · C_out` та періодом комутації `T_sw`.

Для електролітичних конденсаторів, де `ESR` домінує (`ESR · C_out >> T_sw / 8`), діє наближення:

```text
ΔV_out(pp) ≈ ΔI_L · ESR
```

Для керамічних конденсаторів MLCC, де `ESR` надзвичайно малий (одиниці міліомів), домінує ємнісний інтеграл:

```text
ΔV_out(pp) ≈ ΔI_L / (8 · f_sw · C_out)
```

У проміжних випадках розмах обчислюється коренем із суми квадратів або через точний розв'язок екстремуму:

```text
ΔV_out(pp) = √((ΔV_C)² + (ΔV_ESR)²)        [квадратичне наближення для некорельованих піків]
```

### 2. Спектральний аналіз комутаційних завад: трапецієподібний імпульс

Щоб зрозуміти, чому швидкі комутаційні фронти створюють завади в широкому радіодіапазоні, розгляньмо розклад у ряд Фур'є періодичної послідовності трапецієподібних імпульсів напруги на вузлі SW з амплітудою `V_in`, періодом `T_sw`, тривалістю відкритого стану `t_on` та часом наростання/спаду фронтів `t_r` (де `t_r = t_f`).

Амплітудний спектр гармонік `c_n` на частотах `f_n = n · f_sw` описується формулою подвійного кардинального синуса (sinc):

```text
|c_n| = 2 · V_in · (t_on / T_sw) · |sinc(n · π · t_on / T_sw)| · |sinc(n · π · t_r / T_sw)|
```

Асимптотична огинаюча амплітудного спектра на логарифмічному графіку Боде має дві характерні точки зламу:

1. **Перша точка зламу:** `f_1 = 1 / (π · t_on)`.
   - На частотах `f < f_1` спектральна густина плоска: амплітуди гармонік постійні й пропорційні середньому значенню напруги `V_in · (t_on / T_sw)`.
   - На частотах `f_1 < f < f_2` амплітуда кожної наступної гармоніки спадає обернено пропорційно частоті (`1 / f`), що відповідає нахилу **−20 дБ на декаду**.

2. **Друга точка зламу:** `f_2 = 1 / (π · t_r)`.
   - На частотах вище `f_2` (що визначається скінченною крутизною фронтів `t_r`) огинаюча починає спадати зі швидкістю `1 / f²`, що відповідає нахилу **−40 дБ на декаду**.

Якщо транзистор перемикається дуже швидко (`t_r = 2 нс`), друга точка зламу зміщується високо вправо:

```text
f_2 = 1 / (π · 2·10⁻⁹) ≈ 159.15 МГц
```

Це означає, що аж до 160 МГц спектральна потужність завад спадає повільно (−20 дБ/дек), забруднюючи FM-радіодіапазон та частоти промислового зв'язку. Якщо штучно сповільнити фронт до `t_r = 20 нс`, частота `f_2` знижується до 16 МГц, і на частоті 160 МГц спектральна густина шуму зменшується на 40 дБ (у 100 разів за напругою!). Проте ціною такого сповільнення є десятикратне зростання динамічних втрат перемикання в ключі.

### 3. Математична модель високочастотного дзвіну (Ringing)

Під час розмикання силового ключа струм індуктивності комутується на протилежний діод або синхронний MOSFET. На комутаційному вузлі SW утворюється еквівалентний паралельний коливальний контур другого порядку, утворений паразитною індуктивністю монтажних доріжок `L_par` та сумарною паразитною ємністю вузла `C_par` (вихідна ємність транзисторів `C_oss`, ємність діода `C_j` та ємність полігону друкованої плати).

Диференціальне рівняння контуру без навмисного демпфування:

```text
L_par · (d²q / dt²) + R_par · (dq / dt) + (1 / C_par) · q = 0
```

де `R_par` — паразитний активний опір мідних доріжок та виводів (зазвичай 0.05–0.2 Ом). Власна кутова частота незатухаючих коливань:

```text
ω_0 = 1 / √(L_par · C_par)
f_ring = ω_0 / (2 · π) = 1 / (2 · π · √(L_par · C_par))
```

Характеристичний (хвильовий) імпеданс контуру:

```text
Z_0 = √(L_par / C_par)
```

Добротність контуру без демпфера досягає високих значень:

```text
Q_0 = Z_0 / R_par = √(L_par / C_par) / R_par
```

При типових значеннях `L_par = 5 нГн`, `C_par = 200 пФ` та `R_par = 0.1 Ом`:

```text
Z_0 = √(5·10⁻⁹ / 200·10⁻¹²) = √25 = 5.0 Ом
Q_0 = 5.0 / 0.1 = 50
```

Добротність `Q = 50` означає майже незатухаючі радіочастотні коливання на частоті `f_ring = 1 / (2·π·√(10⁻¹⁸)) = 159.15 МГц`, які багаторазово перевідбиваються в силовому контурі й випромінюються в навколишній простір.

### 4. Дводіапазонний метод визначення невідомих L_par та C_par

Паразитні параметри `L_par` та `C_par` неможливо прочитати в документації на компоненти, оскільки вони визначаються конкретною геометрією мідних провідників на друкованій платі. Для їхнього точного обчислення застосовують метод пробної ємності.

#### Крок 1. Вимірювання початкової частоти

За допомогою високочастотного осцилографа з пружинним контактом щупа вимірюють період власного дзвіну на вузлі SW `T_ring1` та обчислюють початкову резонансну частоту:

```text
f_1 = 1 / T_ring1 = 1 / (2 · π · √(L_par · C_par))
```

#### Крок 2. Підключення калібрувальної ємності

Паралельно комутаційному вузлу (між SW та GND) запаюють високочастотний керамічний конденсатор класу C0G/NP0 відомої ємності `C_add` (рекомендовано обирати номінал, близький до очікуваної ємності вузла, наприклад 220–470 пФ). Нова резонансна частота стає меншою:

```text
f_2 = 1 / (2 · π · √(L_par · (C_par + C_add)))
```

#### Крок 3. Алгебраїчне виведення C_par та L_par

Складемо відношення частот `f_1` до `f_2`:

```text
f_1 / f_2 = √( (L_par · (C_par + C_add)) / (L_par · C_par) )
          = √( (C_par + C_add) / C_par )   [скорочення L_par]
          = √( 1 + C_add / C_par )         [почленне ділення під коренем]
```

Піднесемо обидві частини рівності до квадрата:

```text
(f_1 / f_2)² = 1 + C_add / C_par           [піднесення до квадрата]
(f_1 / f_2)² − 1 = C_add / C_par           [перенесення одиниці]
C_par = C_add / ( (f_1 / f_2)² − 1 )       [вираз для невідомої паразитної ємності]
```

Знаючи знайдену ємність `C_par`, обчислюємо паразитну індуктивність контуру з формули частоти `f_1`:

```text
f_1² = 1 / (4 · π² · L_par · C_par)        [квадрат формули Томсона]
L_par = 1 / (4 · π² · f_1² · C_par)        [вираз для паразитної індуктивності]
```

### 5. Розрахунок параметрів демпферного RC-снубера

Демпферний ланцюг складається з послідовно з'єднаних резистора `R_snub` та конденсатора `C_snub`, підключених паралельно нижньому ключу (SW до GND).

```text
                 SW
                  │
                  ├───┐
                  │   │
                 [Q2] [R_snub]
                  │   │
                  │  [C_snub]
                  │   │
                 GND GND
```

#### Вибір ємності снубера C_snub

Конденсатор `C_snub` має виконувати дві взаємовиключні функції:
1. На робочій частоті комутації `f_sw` (сотні кГц) його реактивний опір має бути високим, щоб блокувати постійний струм і не спричиняти надлишкових теплових втрат.
2. На частоті дзвіну `f_ring` (понад 100 МГц) його реактивний опір має бути значно меншим за опір `R_snub`, щоб резистор повністю увімкнувся в коливальний контур.

Практичний оптимум досягається при виборі ємності в діапазоні від двох до чотирьох значень паразитної ємності:

```text
C_snub = k_c · C_par,    де k_c ∈ [2, 4]
```

При `k_c = 3` еквівалентна ємність вузла зростає в 4 рази, що знижує резонансну частоту у 2 рази, водночас реактивний імпеданс `X_C(f_ring) = 1 / (2 · π · f_ring · C_snub)` становить менш ніж 15% від опору снубера.

#### Вибір опору снубера R_snub

Для повного придушення коливань без надмірного затягування фронтів добротність контуру `Q` має бути знижена до оптимального значення `Q_opt ≈ 0.5...1.0` (критичне або близьке до критичного демпфування).

Характеристичний імпеданс контуру зі встановленим снубером змінюється до:

```text
Z_new = √(L_par / (C_par + C_snub)) = √(L_par / ((1 + k_c) · C_par)) = Z_0 / √(1 + k_c)
```

Опір демпфера обирають рівним характеристичному імпедансу навантаженого контуру:

```text
R_snub = Z_new = √(L_par / (C_par + C_snub))
```

Часто на практиці беруть наближене значення `R_snub ≈ Z_0 = √(L_par / C_par)`, що забезпечує коефіцієнт затухання `ζ ≈ 0.707`.

#### Розрахунок теплових втрат на резисторі снубера

Кожен цикл комутації ємність `C_snub` заряджається від 0 до вхідної напруги `V_in`, а потім повністю розряджається до нуля. Енергія, що розсіюється на активному опорі `R_snub` за один повний цикл (заряд + розряд):

```text
E_cycle = (1/2) · C_snub · V_in² [заряд] + (1/2) · C_snub · V_in² [розряд]
        = C_snub · V_in²                   [сумарна енергія за один такт]
```

Повна теплова потужність, яка безперервно виділяється на резисторі снубера:

```text
P_snub = E_cycle · f_sw = C_snub · V_in² · f_sw
```

Зверніть увагу: розсіювана потужність **не залежить від номіналу резистора `R_snub`**, а визначається виключно ємністю `C_snub`, квадратом напруги живлення та частотою комутації. Номінал резистора визначає лише швидкість згасання коливань та пікову миттєву потужність.

### 6. Розрахунок RCD-демпфера для фіксації індуктивних викидів (Clamping)

У підвищувальних (Boost) та зворотноходових (Flyback) перетворювачах паразитний дзвін супроводжується великим однополярним викидом напруги самоіндукції індуктивності розсіювання `L_leak`. Для обмеження цього піку на рівні фіксованої напруги фіксації `V_clamp` застосовують RCD-демпфер:

```text
             SW ───►│───┬───────────┐
                   D_sn │           │
                       [C_sn]      [R_sn]
                        │           │
             V_in ──────┴───────────┘
```

#### Баланс енергії та розрахунок R_sn

Енергія, накопичена в індуктивності розсіювання на момент вимикання ключа при піковому струмі `I_pk`, становить:

```text
E_leak = (1/2) · L_leak · I_pk²
```

Ця енергія передається в конденсатор `C_sn`. Щоб напруга на конденсаторі в усталеному режимі залишалася сталою `V_sn = V_clamp − V_in`, потужність, яка втікає в демпфер, має повністю розсіюватися на паралельному резисторі `R_sn`:

```text
P_sn = E_leak · f_sw · ( V_clamp / (V_clamp − V_in) )
```

Звідси опір розрядного резистора `R_sn` обчислюється за формулою:

```text
R_sn = (V_clamp − V_in)² / P_sn                                                    [закон Джоуля для теплової потужності]
     = (2 · (V_clamp − V_in)²) / (L_leak · I_pk² · f_sw · (V_clamp / (V_clamp − V_in))) [підстановка виразу потужності втрат]
     = (2 · (V_clamp − V_in)³ ) / (L_leak · I_pk² · f_sw · V_clamp)                [спрощення триповерхового дробу]
```

#### Вибір ємності C_sn

Ємність `C_sn` обирають достатньо великою, щоб пульсація напруги на самому демпфері `ΔV_sn` за період комутації не перевищувала 5–10% від `V_sn`:

```text
ΔV_sn = V_sn / (R_sn · C_sn · f_sw) ≤ 0.05 · V_sn  [умова малості пульсацій на демпфері]
C_sn ≥ 20 / (R_sn · f_sw)                          [нижня межа ємності фіксатора]
```

#### Числовий розрахунок RCD-демпфера

Розглянемо зворотноходовий перетворювач із такими параметрами:
- Вхідна напруга: `V_in = 48.0 В`
- Індуктивність розсіювання первинної обмотки: `L_leak = 2.5 мкГн (2.5 · 10⁻⁶ Гн)`
- Піковий струм ключа на момент вимикання: `I_pk = 3.0 А`
- Частота комутації: `f_sw = 100 кГц (1.0 · 10⁵ Гц)`
- Максимально допустима напруга фіксації на стоку ключа: `V_clamp = 100.0 В`

1. Різниця напруг на демпфері:

```text
V_sn = V_clamp − V_in
     = 100.0 − 48.0 = 52.0 В                       [напруга заряду конденсатора снубера]
```

2. Енергія в індуктивності розсіювання:

```text
E_leak = (1/2) · L_leak · I_pk²
       = 0.5 · 2.5·10⁻⁶ · (3.0)²                   [підстановка L_leak та струму]
       = 0.5 · 2.5·10⁻⁶ · 9.0 = 11.25·10⁻⁶ Дж      [енергія одиничного комутаційного викиду]
```

3. Теплова потужність на резисторі:

```text
P_sn = E_leak · f_sw · (V_clamp / V_sn)
     = 11.25·10⁻⁶ · 100·10³ · (100.0 / 52.0)       [множення енергії на частоту та коефіцієнт напруг]
     = 1.125 · 1.923 ≈ 2.16 Вт                     [повна потужність розсіювання на R_sn]
```

4. Розрахунок опору резистора:

```text
R_sn = V_sn² / P_sn
     = (52.0)² / 2.16                              [квадрат напруги демпфера ділений на потужність]
     = 2704.0 / 2.16 ≈ 1251.8 Ом                   [розрахунковий номінал]
```
Обираємо стандартний резистор `R_sn = 1.2 кОм` потужністю не менше 3 Вт або два паралельні резистори по `2.4 кОм` потужністю 2 Вт кожен.

5. Розрахунок ємності конденсатора:

```text
C_sn ≥ 20 / (R_sn · f_sw)
     = 20 / (1200 · 100·10³)                       [підстановка опору та робочої частоти]
     = 20 / 1.2·10⁸ ≈ 1.67 · 10⁻⁷ Ф = 167 нФ       [мінімально допустима ємність фіксатора]
```
Обираємо плівковий або керамічний конденсатор `C_sn = 220 нФ` на номінальну напругу не менше 100 В.

### 7. Приклад повного числового розрахунку

Розглянемо синхронний Buck-перетворювач із параметрами:
- Вхідна напруга: `V_in = 24.0 В`
- Вихідна напруга: `V_out = 3.3 В`
- Частота комутації: `f_sw = 500 кГц (5.0 · 10⁵ Гц)`
- Струм навантаження: `I_out = 4.0 А`
- Індуктивність дроселя: `L = 3.3 мкГн (3.3 · 10⁻⁶ Гн)`
- Вихідна керамічна ємність: `C_out = 44 мкФ (два конденсатори по 22 мкФ з урахуванням DC-Bias)`, сумарний `ESR = 3 мОм (0.003 Ом)`

#### Розрахунок пульсацій

1. Розмах струму дроселя:

```text
ΔI_L = (V_in − V_out) · (V_out / V_in) / (f_sw · L)
     = (24.0 − 3.3) · (3.3 / 24.0) / (500·10³ · 3.3·10⁻⁶) [підстановка числових значень]
     = 20.7 · 0.1375 / 1.65                                 [обчислення коефіцієнта заповнення]
     = 2.846 / 1.65 ≈ 1.725 А                               [ділення чисельника на знаменник]
```

2. Ємнісна складова пульсацій:

```text
ΔV_C = ΔI_L / (8 · f_sw · C_out)
     = 1.725 / (8 · 500·10³ · 44·10⁻⁶)     [підстановка розмаху струму та сумарної ємності]
     = 1.725 / 176.0 ≈ 0.0098 В = 9.8 мВ   [кінцевий результат ємнісного розмаху]
```

3. Резистивна складова пульсацій:

```text
ΔV_ESR = ΔI_L · ESR
       = 1.725 · 0.003                     [множення струму на опір втрат]
       = 0.005175 В ≈ 5.2 мВ               [кінцевий спад напруги на ESR]
```

4. Повний розмах низькочастотних пульсацій:

```text
ΔV_out(pp) = √((9.8)² + (5.2)²)            [квадратична сума ортогональних складових]
           = √(96.04 + 27.04)              [піднесення до квадрата]
           = √123.08 ≈ 11.1 мВ             [обчислення кореня]
```

#### Розрахунок паразитів та снубера

Під час осцилографічного тестування вузла SW зафіксовано:
- Початкова частота дзвіну: `f_1 = 180.0 МГц`
- Після підключення тестового конденсатора `C_add = 470 пФ`: `f_2 = 95.0 МГц`

1. Обчислення паразитної ємності:

```text
C_par = C_add / ( (f_1 / f_2)² − 1 )
      = 470 / ( (180.0 / 95.0)² − 1 )      [підстановка виміряних частот f1 та f2]
      = 470 / ( 3.590 − 1 )                [відношення частот у квадраті]
      = 470 / 2.590 ≈ 181.5 пФ             [кінцеве значення паразитної ємності]
```

2. Обчислення паразитної індуктивності монтажу:

```text
L_par = 1 / (4 · π² · f_1² · C_par)
      = 1 / (4 · 9.8696 · (180·10⁶)² · 181.5·10⁻¹²) [підстановка π, частоти f1 та ємності C_par]
      = 1 / (39.478 · 3.24·10¹⁶ · 181.5·10⁻¹²)      [проміжне множення знаменника]
      = 1 / 232.15 ≈ 4.31 · 10⁻⁹ Гн = 4.31 нГн      [обчислення паразитної індуктивності]
```

3. Характеристичний опір контуру:

```text
Z_0 = √(L_par / C_par)
    = √(4.31·10⁻⁹ / 181.5·10⁻¹²)           [підстановка знайдених L_par і C_par]
    = √23.75 ≈ 4.87 Ом                     [хвильовий опір контуру]
```

4. Вибір компонентів снубера:
Обираємо кратність ємності `k_c = 3`:

```text
C_snub = 3 · C_par = 3 · 181.5 пФ = 544.5 пФ  → стандартний ряд: 560 пФ (C0G, 50 В)
```

Розрахунковий опір снубера:

```text
R_snub = √(L_par / (C_par + C_snub))
       = √(4.31·10⁻⁹ / (181.5·10⁻¹² + 560·10⁻¹²)) [підстановка C_snub у формулу опору]
       = √(4.31·10⁻⁹ / 741.5·10⁻¹²)               [сумарна ємність навантаженого контуру]
       = √5.81 ≈ 2.41 Ом                          [оптимальний опір демпфування]
```

5. Розрахунок потужності втрат на резисторі:

```text
P_snub = C_snub · V_in² · f_sw
       = 560·10⁻¹² · (24.0)² · 500·10³     [підстановка обраної ємності, напруги та частоти]
       = 560·10⁻¹² · 576 · 500·10³         [квадрат напруги живлення]
       = 0.1613 Вт ≈ 161 мВт               [кінцева теплова потужність розсіювання]
```

Рекомендований типорозмір резистора `R_snub`: SMD 0805 або 1206 із номінальною потужністю розсіювання не менше 0.25 Вт (250 мВт) для забезпечення температурного запасу.

### 8. Розрахунок вторинного LC-фільтра (Post-Filter)

Коли амплітуда комутаційних голок після встановлення снубера залишається неприпустимою для живлення прецизійного АЦП або радіотракту, застосовують вторинний LC-фільтр другого порядку:

```text
             L_post (або Bead)
   V_out ───═══╤═════════════════─── V_clean
               │               │
             [C_out1]        [C_out2]
               │               │
              GND             GND
```

Коефіцієнт придушення (передатна функція за напругою) ненавантаженого LC-фільтра на частотах вище частоти зрізу `f >> f_c`:

```text
f_c = 1 / (2 · π · √(L_post · C_out2))
K(f) = |V_clean(f) / V_out(f)| ≈ (f_c / f)²
```

Послаблення в децибелах (dB) падає зі швидкістю 40 дБ на декаду:

```text
Att(dB) = 40 · log₁₀(f / f_c)
```

#### Вплив опору навантаження та найгірший випадок добротності

У комплексній площині Лапласа передатна функція ненавантаженого фільтра з активним опором навантаження `R_L` має вигляд:

```text
H(s) = 1 / ( s² · L_post · C_out2 + s · (L_post / R_L) + 1 )
```

Добротність цього фільтра становить `Q = R_L · √(C_out2 / L_post)`. Звідси видно парадоксальний факт: **найгіршим випадком для стабільності та резонансного викиду є режим холостого ходу або малого навантаження** (`R_L → ∞`), коли добротність контуру нічим не обмежена й прямує до нескінченності.

#### Запобігання резонансному піку: умова демпфування

На частоті `f_c` добротність контуру без навантаження створює небезпечний пік імпедансу, що може призвести до автоколивань перетворювача. Для обмеження добротності до `Q ≤ 1` паралельно вихідній кераміці `C_out2` підключають демпферну RC-гілку `R_d − C_d`, параметри якої розраховують за критерієм Мідлбрука:

```text
C_d ≥ 4 · C_out2                           [ємність демпфера мінімум учетверо більша]
R_d ≈ √(L_post / C_out2)                   [опір дорівнює характеристичному імпедансу]
```

При використанні замість чистої індуктивності феритової намистини (Ferrite Bead), її внутрішній активний опір на частотах 50–300 МГц (що становить 50–200 Ом) сам виступає природним демпфером, розсіюючи енергію високочастотних сплесків у тепло.
