# Розрахунок ККД та відбитого імпедансу в резонансному WPT

Бездротова передача енергії крізь повітряний зазор опиняється перед парадоксом: магнітний зв'язок між пласкими котушками слабкий (`k ≈ 0.1–0.3`), більшість силових ліній магнітного поля розсіюється, а індуктивність розсіяння створює колосальний реактивний опір, який блокує струм. Для отримання високого ККД (`>75–85%`) необхідно компенсувати реактивні опори обох котушок конденсаторами в резонанс і точно узгодити імпеданс навантаження з параметрами магнітного контуру. Цей розрахунок виводить аналітичні формули відбитого імпедансу, вираз для ККД системи, знаходить умову оптимального навантаження, доводить фундаментальну роль добутку `k·Q` та аналізує явище біфуркації частоти.

## Фізична модель слабко зв'язаних котушок

У звичайному силовому трансформаторі первинна і вторинна обмотки намотані на спільному замкненому феритовому осерді. Магнітна проникність фериту `μ_r > 2000` спрямовує майже весь магнітний потік крізь обидві обмотки, завдяки чому коефіцієнт зв'язку наближається до одиниці (`k ≈ 0.98–0.99`), а індуктивність розсіяння становить лише частки відсотка від основної індуктивності.

У системі бездротової передачі енергії котушки розділені немагнітним повітряним зазором товщиною від 3 до 8 мм (а в автомобільних системах — до 150–200 мм). Оскільки магнітна проникність повітря `μ_r = 1`, магнітний опір шляху замикання потоку виявляється величезним. Більшість силових ліній замикається довкола витків власної котушки через навколишній простір, не досягаючи приймача.

Повний магнітний потік первинної котушки `Φ₁` розпадається на дві складові: потік взаємного зчеплення `Φ₁₂`, який пронизує витки вторинної котушки, та потік розсіяння `Φ_σ1`:

```
Φ₁ = Φ₁₂ + Φ_σ1
```

Коефіцієнт магнітного зв'язку `k` визначається як геометричне середнє часток зчепленого магнітного потоку:

```
k = √( (Φ₁₂ / Φ₁) · (Φ₂₁ / Φ₂) ) = M / √(L₁ · L₂)
```

де `M` — взаємна індуктивність котушок, `L₁` та `L₂` — їхні повні власні індуктивності.

Для типових пласких спіральних котушок стандарту Qi діаметром 40–50 мм при зазорі 5 мм коефіцієнт зв'язку лежить у діапазоні `k = 0.15–0.30`. Це означає, що від 70% до 85% магнітної енергії зосереджено в полі розсіяння. Індуктивність розсіяння первинного кола `L_σ1 = (1 − k) · L₁` на робочій частоті `f = 125 кГц` створює значний реактивний опір `X_σ = 2π·f·L_σ1 ≈ 6–10 Ом`. Без резонансної компенсації цей опір обмежує струм первинного кола і вимагає подачі кіловольтних напруг для передачі навіть кількох ват потужності.

## Модель двох зв'язаних контурів

Розглянемо систему передачі енергії з послідовною компенсацією первинного та вторинного контурів (топологія SS). Первинний контур містить джерело синусоїдної напруги `U₁` частоти `ω = 2π·f`, власний активний опір котушки `R₁`, індуктивність котушки передавача `L₁` та послідовний компенсаційний конденсатор `C₁`. Вторинний контур містить індуктивність приймача `L₂`, власний активний опір `R₂`, компенсаційний конденсатор `C₂` та активний опір навантаження `R_нав`.

Магнітний зв'язок між котушками описується взаємною індуктивністю `M`:

```
M = k · √(L₁ · L₂)
```

Запишемо рівняння другого закону Кірхгофа у комплексній формі для контурних струмів первинного кола `İ₁` та вторинного кола `İ₂`:

```
U̇₁ = (R₁ + j·(ωL₁ − 1/(ωC₁))) · İ₁ − jωM · İ₂
0  = −jωM · İ₁ + (R₂ + R_нав + j·(ωL₂ − 1/(ωC₂))) · İ₂
```

Знак мінус перед взаємною індуктивністю враховує зустрічний напрямок ЕРС самоіндукції згідно з правилом Ленца. Позначимо власні комплексні імпеданси первинного та вторинного контурів як `Z₁` та `Z₂`:

```
Z₁ = R₁ + j·(ωL₁ − 1/(ωC₁))
Z₂ = R₂ + R_нав + j·(ωL₂ − 1/(ωC₂))
```

Тоді система рівнянь набуває компактного вигляду:

```
U̇₁ = Z₁ · İ₁ − jωM · İ₂
0  = −jωM · İ₁ + Z₂ · İ₂
```

## Виведення відбитого імпедансу

З другого рівняння системи виразимо контурний струм вторинного кола `İ₂` через струм первинного кола `İ₁`:

```
İ₂ = (jωM / Z₂) · İ₁
```

Підставимо отриманий струм `İ₂` у перше рівняння для первинного контуру:

```
U̇₁ = Z₁ · İ₁ − jωM · ((jωM / Z₂) · İ₁)
= Z₁ · İ₁ − ((j·j·ω²M²) / Z₂) · İ₁    [перемноження уявних одиниць: j·j = −1]
= Z₁ · İ₁ + (ω²M² / Z₂) · İ₁          [розкриття подвійного мінуса: −(−1) = +1]
= (Z₁ + (ωM)² / Z₂) · İ₁              [винесення спільного струму İ₁ за дужки]
```

Член `(ωM)² / Z₂` являє собою додатковий комплексний опір, який вноситься вторинним контуром у первинне коло крізь спільне магнітне поле. Цей опір називається **відбитим імпедансом** (англ. *reflected impedance*) `Z_відб`:

```
Z_відб = (ωM)² / Z₂
```

Повний еквівалентний вхідний імпеданс, який бачить інвертор передавача, дорівнює:

```
Z_вх = Z₁ + Z_відб = Z₁ + (ωM)² / Z₂
```

Розглянемо випадок, коли робоча частота генератора `ω` збігається з власною резонансною частотою вторинного контуру `ω₀ = 1 / √(L₂C₂)`. На цій частоті реактивний опір вторинної котушки `ωL₂` та реактивний опір конденсатора `1/(ωC₂)` рівні за модулем і взаємно віднімаються:

```
ωL₂ − 1/(ωC₂) = 0
```

Тоді власний імпеданс вторинного контуру стає суто активним: `Z₂ = R₂ + R_нав`. Відповідно, відбитий імпеданс у первинне коло також стає суто **активним резистивним опором**:

```
Z_відб = (ωM)² / (R₂ + R_нав)
```

Це найважливіший висновок: на резонансі вторинне навантаження відбивається в первинне коло як еквівалентний паралельний активний резистор, без жодної паразитної індуктивності чи ємності. Якщо первинний контур також налаштований у резонанс `ω = 1 / √(L₁C₁)`, його власний опір спрощується до `Z₁ = R₁`, і загальний вхідний імпеданс системи є суто активним:

```
Z_вх = R₁ + (ωM)² / (R₂ + R_нав)
```

## Виведення формули ККД

Коефіцієнт корисної дії системи `η` визначається як відношення активної потужності, що виділяється на корисному навантаженні `P_нав`, до повної активної потужності, що надходить від джерела в первинний контур `P_вх`:

```
η = P_нав / P_вх
```

Активна потужність у навантаженні дорівнює:

```
P_нав = |İ₂|² · R_нав
```

Потужність, споживана від джерела на резонансі (де коефіцієнт потужності `cos(φ) = 1`):

```
P_вх = |İ₁|² · Re(Z_вх) = |İ₁|² · (R₁ + R_відб)
```

Підставимо вираз для струму `|İ₂| = (ωM / (R₂ + R_нав)) · |İ₁|`:

```
P_нав = |İ₁|² · (ωM / (R₂ + R_нав))² · R_нав
= |İ₁|² · ((ωM)² / (R₂ + R_нав)) · (R_нав / (R₂ + R_нав))    [розкриття квадрата дробу]
= |İ₁|² · R_відб · (R_нав / (R₂ + R_нав))                     [підстановка R_відб = (ωM)² / (R₂ + R_нав)]
```

Розділимо корисну потужність на повну вхідну:

```
η = P_нав / P_вх
= (|İ₁|² · R_відб · (R_нав / (R₂ + R_нав))) / (|İ₁|² · (R₁ + R_відб))   [підстановка формул P_нав та P_вх]
= (R_відб / (R₁ + R_відб)) · (R_нав / (R₂ + R_нав))                       [скорочення спільного струму |İ₁|²]
```

Формула ККД розпадається на добуток двох незалежних ефективностей:
1. Ефективність первинного контуру `η₁ = R_відб / (R₁ + R_відб)` — показує, яка частка енергії джерела передається у вторинний контур, а не розсіюється на активному опорі власного дроту передавача `R₁`.
2. Ефективність вторинного контуру `η₂ = R_нав / (R₂ + R_нав)` — показує, яка частка наведеної потужності потрапляє в навантаження, а не гріє опір дроту котушки приймача `R₂`.

Підставимо вираз `R_відб = (ωM)² / (R₂ + R_нав)` у формулу ККД:

```
η = (((ωM)² / (R₂ + R_нав)) / (R₁ + (ωM)² / (R₂ + R_нав))) · (R_нав / (R₂ + R_нав))   [підстановка R_відб]
= ((ωM)² / (R₁·(R₂ + R_нав) + (ωM)²)) · (R_нав / (R₂ + R_нав))                         [зведення дробів до спільного знаменника]
= ((ωM)² · R_нав) / ((R₂ + R_нав) · (R₁·(R₂ + R_нав) + (ωM)²))                         [перемноження чисельників і знаменників]
```

Введемо поняття добротностей первинної та вторинної котушок:

```
Q₁ = ωL₁ / R₁
Q₂ = ωL₂ / R₂
```

Виразимо `(ωM)²` через `Q₁`, `Q₂` та коефіцієнт зв'язку `k`:

```
(ωM)² = ω² · k² · L₁ · L₂          [підстановка формули взаємоіндукції M = k·√(L₁L₂)]
= k² · (ωL₁) · (ωL₂)               [перегрупування множників кругової частоти]
= k² · (Q₁ · R₁) · (Q₂ · R₂)       [вираження індуктивних опорів через добротності Q₁ та Q₂]
= k² · Q₁ · Q₂ · R₁ · R₂           [винесення добутку опорів втрат]
```

Також введемо безрозмірне відносне навантаження вторинного кола `x = R_нав / R₂`. Тоді `R₂ + R_нав = R₂ · (1 + x)`. Підставимо ці позначення у формулу ККД:

```
η = (k²·Q₁·Q₂·R₁·R₂ · x·R₂) / (R₂·(1 + x) · (R₁·R₂·(1 + x) + k²·Q₁·Q₂·R₁·R₂))   [підстановка (ωM)² та відносного навантаження x]
= (k²·Q₁·Q₂ · x) / ((1 + x) · ((1 + x) + k²·Q₁·Q₂))                             [скорочення спільних множників R₁ та R₂]
= (k²·Q₁·Q₂ · x) / ((1 + x)² + k²·Q₁·Q₂ · (1 + x))                               [розкриття дужок у знаменнику]
```

Позначимо фігуру якості бездротового магнітного каналу як `A = k² · Q₁ · Q₂`:

```
η(x) = (A · x) / ((1 + x)² + A · (1 + x))
= (A · x) / ((1 + x) · (1 + x + A))
```

## Пошук оптимального навантаження

Знайдемо екстремум функції ККД `η(x)` за змінною відносного навантаження `x`. Для цього візьмемо похідну `dη / dx` та прирівняємо її до нуля:

```
dη/dx = d/dx [ (A · x) / (x² + (2 + A)·x + (1 + A)) ]
= (A · (x² + (2 + A)·x + (1 + A)) − A·x · (2x + 2 + A)) / (x² + (2 + A)·x + (1 + A))²
= (A · (x² + 2x + A·x + 1 + A − 2x² − 2x − A·x)) / (знаменник)²
= (A · (1 + A − x²)) / (знаменник)²
```

Прирівнюючи чисельник до нуля `A · (1 + A − x²) = 0`, отримуємо оптимальне відносне навантаження:

```
x_opt² = 1 + A = 1 + k² · Q₁ · Q₂
x_opt = √(1 + k² · Q₁ · Q₂)
```

Повертаючись до фізичного опору навантаження `R_нав_opt = x_opt · R₂`:

```
R_нав_opt = R₂ · √(1 + k² · Q₁ · Q₂)
```

Це фундаментальна умова імпедансного узгодження резонансного WPT: щоб передавати енергію з максимальним ККД, опір навантаження має бути в `√(1 + k²Q₁Q₂)` разів більшим за власний опір дроту котушки приймача.

## Максимально досяжний ККД

Підставимо значення `x_opt = √(1 + A)` у вираз для ККД:

```
η_max = (A · √(1 + A)) / ((1 + √(1 + A)) · (1 + √(1 + A) + A))
= (A · √(1 + A)) / ((1 + √(1 + A)) · (1 + A + √(1 + A)))
= (A · √(1 + A)) / ((1 + √(1 + A)) · (√(1 + A)² + √(1 + A)))     [заміна: 1 + A = (√(1 + A))²]
= (A · √(1 + A)) / ((1 + √(1 + A)) · √(1 + A) · (√(1 + A) + 1))  [винесення √(1 + A) за дужки]
= A / (1 + √(1 + A))²                                             [скорочення √(1 + A) в чисельнику й знаменнику]
```

Підставляючи назад `A = k² · Q₁ · Q₂`, отримуємо класичну формулу максимального ККД бездротової передачі енергії:

```
η_max = (k² · Q₁ · Q₂) / (1 + √(1 + k² · Q₁ · Q₂))²
```

Якщо добуток `k²·Q₁·Q₂ ≫ 1`, чисельник і знаменник можна спростити:

```
η_max ≈ (k²·Q₁·Q₂) / (√(k²·Q₁·Q₂))² = 1 − 2 / √(k²·Q₁·Q₂)
```

Звідси очевидно: для досягнення ККД понад 80% добуток `k · √(Q₁Q₂)` повинен бути не меншим за 10:

```
k · √(Q₁Q₂) ≥ 10  ⇒  k²·Q₁·Q₂ ≥ 100  ⇒  η_max ≥ 100 / (1 + √101)² ≈ 100 / (1 + 10.05)² ≈ 81.8%
```

## Явище біфуркації частоти (розщеплення резонансу)

Коли дві котушки розміщені близько одна до одної, коефіцієнт зв'язку `k` зростає і може перевищити критичне значення:

```
k_крит = 1 / √(Q₁ · Q₂)
```

При `k > k_крит` система переходить у режим надкритичного зв'язку (англ. *overcoupled regime*). У цьому режимі графік вхідного імпедансу зазнає якісної зміни: замість одного мінімуму на частоті `f₀` крива розщеплюється на два локальні мінімуми на частотах `f_odd < f₀` та `f_even > f₀`, а на самій резонансній частоті `f₀` виникає локальний максимум імпедансу.

Це явище називають **біфуркацією частоти** або розщепленням резонансу. Якщо контролер інвертора використовує автопідлаштування частоти (ФАПЧ) для відстеження нульового фазового кута (ZPA / ZVS), він може «зірватися» в один із бічних екстремумів, що спричиняє стрибкоподібні коливання потужності. Для усунення нестабільності контролери Qi фіксують мінімальну робочу частоту інвертора вище зони біфуркації.

## Числовий приклад розрахунку котушок Qi

Розрахуємо параметри реального бездротового зарядного пристрою потужністю 15 Вт стандарту Qi EPP.

**Вихідні дані вимірювань:**
- Робоча частота інвертора: `f = 125 кГц` (`ω = 2π · 125 000 = 785 398 рад/с`).
- Первинна котушка TX: `L₁ = 10.0 мкГн` (`10.0 · 10⁻⁶ Гн`), опір мідного літцендрату `R₁ = 0.12 Ом`.
- Вторинна котушка RX: `L₂ = 15.0 мкГн` (`15.0 · 10⁻⁶ Гн`), опір пласкої спіралі `R₂ = 0.28 Ом`.
- Коефіцієнт магнітного зв'язку при зазорі 5 мм: `k = 0.25`.

**Крок 1. Розрахунок реактивних опорів та добротностей котушок на частоті 125 кГц:**

```
X_L1 = ω · L₁
= 785398 · 10.0·10⁻⁶       [множення кругової частоти на індуктивність L1]
= 7.854 Ом

Q₁ = X_L1 / R₁
= 7.854 / 0.12             [ділення реактивного опору на опір втрат дроту TX]
= 65.45

X_L2 = ω · L₂
= 785398 · 15.0·10⁻⁶       [множення кругової частоти на індуктивність L2]
= 11.781 Ом

Q₂ = X_L2 / R₂
= 11.781 / 0.28            [ділення реактивного опору на опір втрат дроту RX]
= 42.07
```

**Крок 2. Розрахунок взаємної індуктивності M:**

```
M = k · √(L₁ · L₂)
= 0.25 · √(10.0·10⁻⁶ · 15.0·10⁻⁶)  [обчислення геометричного середнього індуктивностей]
= 0.25 · √(150·10⁻¹²)
= 0.25 · 12.247·10⁻⁶
= 3.062 мкГн
```

**Крок 3. Розрахунок резонансних ємностей C1 та C2:**

```
C₁ = 1 / (ω² · L₁)
= 1 / (785398² · 10.0·10⁻⁶)        [формула Томсона для послідовного конденсатора TX]
= 1 / (6.1685·10¹¹ · 10.0·10⁻⁶)

= 1.081·10⁻⁷ Ф = 108.1 нФ
```

**Крок 4. Розрахунок фігури якості каналу A та оптимального навантаження:**

```
A = k² · Q₁ · Q₂
= 0.25² · 65.45 · 42.07    [підстановка квадрата зв'язку та добротностей]
= 0.0625 · 2753.48
= 172.09

R_нав_opt = R₂ · √(1 + A)

= 0.28 · √173.09

= 3.684 Ом
```

**Крок 5. Розрахунок відбитого опору та максимального ККД:**

```
R_відб = (ωM)² / (R₂ + R_нав_opt)
= (785398 · 3.062·10⁻⁶)² / (0.28 + 3.684)  [розрахунок внесеного опору в первинне коло]
= (2.405)² / 3.964

= 1.459 Ом

= 172.09 / (1 + √173.09)²                  [підстановка у формулу максимального ККД]
= 172.09 / (1 + 13.156)²

```
