# 🧮 Математична модель одностороннього підмагнічування та струмового балансування осердя

У двотактному перетворювачі з центральним відводом первинна обмотка трансформатора підключена безпосередньо до постійної напруги живлення `Vin`. За ідеальної симетрії напруга на напівобмотках змінює знак кожні пів періоду, завдяки чому середній магнітний потік за період залишається строго нульовим. Проте в реальній системі неминуче виникає асиметрія параметрів компонентів або часових інтервалів комутації, яка призводить до одностороннього накопичення магнітного потоку — явища звалювання потоку (англ. *flux walking* або *staircase saturation*).

Нижче наведено строгий математичний аналіз фізики цього процесу, розрахунок чутливості до похибок, динаміку перехідних процесів, порівняння малосигнальних моделей, розрахунок компенсації нахилу пилки, врахування високочастотних втрат в обмотках та доведення абсолютної стійкості системи при використанні керування за піковим струмом (Peak Current Mode Control, PCMC).

## 1. Рівняння вольт-секундного балансу та дрейф індукції

За фундаментальним законом електромагнітної індукції Фарадея зміна магнітного потоку `Φ(t)` в осерді з площею поперечного перерізу `Ae` та числом витків первинної напівобмотки `Np` визначається миттєвою напругою на індуктивності `vL(t)`:

```
dΦ/dt = vL(t) / Np                      [закон Фарадея для індуктивно зв'язаної котушки]
dB/dt = vL(t) / (Np · Ae)                [зв'язок магнітної індукції B та прикладеної напруги]
```

Для двох послідовних напівперіодів комутації періоду `T` напруги на напівобмотках `Np1` та `Np2` під час відкритих станів транзисторів `Q1` (тривалістю `ton1`) та `Q2` (тривалістю `ton2`) описуються виразами:

```
vL1(t) = Vin − i1(t) · Ron1 − Vdrop1     [напруга на Np1 під час прямого напівперіоду ton1]
vL2(t) = −(Vin − i2(t) · Ron2 − Vdrop2)  [напруга на Np2 під час зворотного напівперіоду ton2]
```

Тут `Ron1, Ron2` — активні опори відкритих каналів польових транзисторів; `Vdrop1, Vdrop2` — сумарні падіння напруги на випрямних діодах, виводах та доріжках друкованої плати; `i1(t), i2(t)` — миттєві первинні струми відповідних напівперіодів.

Інтегральна зміна магнітної індукції `ΔB_period` за повний період комутації `T` дорівнює алгебраїчній сумі інтегралів вольт-секунд двох робочих тактів:

```
ΔB_period = (1 / (Np · Ae)) · ( ∫₀^{ton1} vL1(t) dt + ∫_{T/2}^{T/2+ton2} vL2(t) dt )
```

Позначивши середньоінтегральні значення напруг на напівобмотках як `V1` та `V2`:

```
V1 = (1 / ton1) · ∫₀^{ton1} vL1(t) dt
V2 = (1 / ton2) · ∫_{T/2}^{T/2+ton2} |vL2(t)| dt
```

Отримуємо базове рівняння чистого циклічного зсуву магнітної індукції:

```
ΔB_drift = (V1 · ton1 − V2 · ton2) / (Np · Ae)   [циклічний приріст постійної складової індукції]
```

Якщо різниця `V1 · ton1 − V2 · ton2 ≠ 0`, робоча точка на петлі гістерезису не повертається у вихідний стан, а зміщується щоциклу на постійну величину `ΔB_drift`.

## 2. Аналіз чутливості до конструктивних асиметрій

Розглянемо аналітичний вплив чотирьох незалежних джерел інженерної похибки на швидкість дрейфу індукції `dB_drift/dt = ΔB_drift · fsw`.

### 1. Асиметрія тривалості імпульсів керування (`Δt = ton1 − ton2`)

Припустимо ідеальну симетрію електричних опорів (`V1 = V2 = Vin`), але наявність часового розбігу `Δt` через фазовий джиттер мікроконтролера чи різницю затримок увімкнення та вимкнення драйверів:

```
ΔB_t = Vin · (ton1 − ton2) / (Np · Ae)
     = Vin · Δt / (Np · Ae)              [зсув індукції через часову асиметрію ШІМ]
```

**Розрахунковий приклад:**
Для типового низьковольтного перетворювача бортової мережі:
`Vin = 12 В`, `Np = 4 витки`, `Ae = 120 мм² = 1.2 · 10⁻⁴ м²`, `fsw = 100 кГц` (`T = 10 мкс`), часова асиметрія `Δt = 25 нс` (0.25% від періоду).

Обчислимо покроковий циклічний зсув індукції:

```
ΔB_t = 12 · (25 · 10⁻⁹) / (4 · 1.2 · 10⁻⁴)
     = 300 · 10⁻⁹ / 4.8 · 10⁻⁴          [підстановка значень у формулу]
     = 0.000625 Тл = 0.625 мТл за цикл  [зсув індукції за 1 період]
```

Швидкість накопичення постійного магнітного потоку в часі:

```
dB_drift/dt = ΔB_t · fsw
            = 0.625 · 10⁻³ · 100 000    [множення на робочу частоту комутації]
            = 62.5 Тл / с               [швидкість дрейфу робочої точки]
```

Якщо робочий розмах індукції становить `B_op = 0.18 Тл`, а межа насичення силового фериту марки N87 за робочої температури 100 °C дорівнює `Bsat = 0.38 Тл`, запас індукції до насичення становить:

```
ΔB_margin = Bsat − B_op
          = 0.38 − 0.18                 [різниця між порогом насичення та робочою індукцією]
          = 0.20 Тл                     [залишковий динамічний запас]
```

Час до повного катастрофічного насичення трансформатора становить:

```
t_crash = ΔB_margin / (dB_drift/dt)
        = 0.20 / 62.5                   [час до повного входу осердя в насичення]
        = 0.0032 с = 3.2 мс             [рівно 320 періодів комутації!]
```

Без корекції перетворювач виходить із ладу менш ніж за 4 мілісекунди після запуску.

### 2. Асиметрія активних опорів ключів (`ΔRon = Ron1 − Ron2`)

Нехай імпульси ШІМ строго рівні (`ton1 = ton2 = ton`), але через технологічний розкид параметрів кремнієвих кристалів або різну температуру тепловідводів транзистори мають відмінні опори відкритого стану `Ron1 ≠ Ron2`:

```
V1 = Vin − Ipk · Ron1
V2 = Vin − Ipk · Ron2
ΔB_R = ((Vin − Ipk · Ron1) · ton − (Vin − Ipk · Ron2) · ton) / (Np · Ae)
     = −Ipk · (Ron1 − Ron2) · ton / (Np · Ae)
     = −Ipk · ΔRon · ton / (Np · Ae)    [зсув індукції від розкиду опорів транзисторів]
```

При первинному піковому струмі `Ipk = 40 А`, `ton = 4 мкс` та різниці опорів `ΔRon = 3 мОм`:

```
ΔB_R = −40 · (3 · 10⁻³) · (4 · 10⁻⁶) / (4 · 1.2 · 10⁻⁴)
     = −4.8 · 10⁻⁷ / 4.8 · 10⁻⁴         [підстановка струму та різниці опорів]
     = −0.001 Тл = −1.0 мТл за цикл     [дрейф індукції в негативний бік]
```

### 3. Різниця прямих спадів напруги випрямних діодів (`ΔVf = Vf1 − Vf2`)

Вторинна асиметрія трансформується в первинне коло через коефіцієнт трансформації `n = Ns / Np`:

```
ΔV_reflected = ΔVf / n
ΔB_diode = (ΔVf / n) · ton / (Np · Ae)  [дрейф індукції від несиметрії вихідного випрямляча]
```

## 3. Нелінійна динаміка лавинного зриву в режимі Voltage Mode

При керуванні за напругою (Voltage Mode Control) контур зворотного зв'язку контролює лише вихідну напругу `Vout` через повільний інтегральний підсилювач помилки, не маючи жодної інформації про миттєвий магнітний стан осердя.

Повний первинний струм кожного такту складається з трансформованого струму навантаження та власного струму намагнічування `im(t)`:

```
ip(t) = n · iL_sec(t) + im(t)
```

Струм намагнічування визначається нелінійною диференціальною індуктивністю осердя `Lm(B)`:

```
im(t) = (1 / Lm(B)) · ∫ vL(t) dt
Lm(B) = μ_diff(B) · μ₀ · Np² · Ae / le  [індуктивність намагнічування як функція індукції]
```

Тут `le` — довжина середньої магнітної лінії магнітопроводу; `μ₀ = 4π · 10⁻⁷ Гн/м`; `μ_diff(B) = (1 / μ₀) · (dB/dH)` — диференціальна магнітна проникність феритового матеріалу.

На квазілінійній робочій ділянці петлі гістерезису (`|B| ≤ 0.25 Тл`) диференціальна проникність фериту висока (`μ_diff ≈ 2500...3000`), а індуктивність намагнічування становить:

```
Lm_nom = 3000 · (4π · 10⁻⁷) · 4² · (1.2 · 10⁻⁴) / (0.06)
       = 3000 · (1.257 · 10⁻⁶) · 16 · (1.2 · 10⁻⁴) / 0.06
       = 7.24 · 10⁻³ / 0.06             [розрахунок номінальної індуктивності]
       = 0.120 мГн = 120 мкГн           [номінальна індуктивність Lm]
```

Амплітуда струму намагнічування за такт `ton = 4 мкс` складає лише:

```
Im_nom = Vin · ton / Lm_nom
       = 12 · (4 · 10⁻⁶) / (1.2 · 10⁻⁴) [розрахунок нормального струму намагнічування]
       = 0.40 А                         [безпечний струм намагнічування]
```

Коли через накопичення дрейфу `ΔB_drift` робоча точка заходить на кривизну коліна насичення (`B → Bsat`), домени фериту вишиковуються повністю. Диференціальна проникність падає до проникності вакууму: `μ_diff → 1`.

Індуктивність намагнічування лавиноподібно зменшується у 3000 разів:

```
Lm_sat = Lm_nom / 3000
       = 120 · 10⁻⁶ / 3000              [обвал індуктивності при насиченні]
       = 0.04 мкГн = 40 нГн             [залишкова паразитна індуктивність котушки]
```

Швидкість наростання первинного струму стрибає до екстремальних значень:

```
di/dt = Vin / Lm_sat
      = 12 / (40 · 10⁻⁹)                [швидкість наростання аварійного струму]
      = 300 А / мкс = 300 000 000 А / с [швидкість струмового удару]
```

За час відкритого стану, що залишився (наприклад, 2 мкс), струм ключа досяг би теоретичних 600 А. Оскільки контролер напруги не бачить цього струму і не перериває імпульс, кристал силового MOSFET переходить у режим струмового перевантаження, зазнає локального теплового шнурування струму та вибухає з фізичним руйнуванням корпусу.

## 4. Вплив немагнітного проміжку на стабільність осердя

Введення малого розподіленого або фіксованого повітряного зазору `lg` у магнітний контур кардинально трансформує еквівалентну петлю гістерезису. Ефективна магнітна проникність осердя із зазором становить:

```
μ_eff = μr / (1 + μr · (lg / le))       [ефективна проникність осердя із зазором]
```

При довжині середньої лінії `le = 60 мм`, початковій проникності `μr = 3000` та крихітному зазорі `lg = 40 мкм = 0.04 мм`:

```
μ_eff = 3000 / (1 + 3000 · (0.04 / 60))
      = 3000 / (1 + 3000 · 0.000667)    [підстановка параметрів зазору]
      = 3000 / (1 + 2.0)
      = 3000 / 3.0 = 1000               [зниження ефективної проникності]
```

Зазор нахиляє петлю гістерезису (збільшує поле насичення `Hsat = Bsat / (μ_eff · μ₀)` у 3 рази), зменшує залишкову індукцію `Br` практично до нуля та збільшує струмовий запас до насичення. Проте платою за це є пропорційне зростання амплітуди реактивного струму намагнічування `Im_pk`, що дещо збільшує омічні втрати в міді первинної обмотки.

## 5. Високочастотні втрати в міді та модель Довелла для двотактних обмоток

У високочастотному двотактному трансформаторі омічний опір первинних напівобмоток істотно перевищує їхній статичний опір постійному струму `Rdc` через прояв скін-ефекту та ефекту близькості (англ. *proximity effect*).

Товщина скін-шару `δ` у мідному провіднику на робочій частоті `fsw` визначається виразом:

```
δ = √( ρ_cu / (π · fsw · μ₀ · μ_cu) )   [глибина проникнення змінного струму в мідь]
```

Для міді за робочої температури 100 °C (`ρ_cu = 2.3 · 10⁻⁸ Ом · м`):

```
δ_100kHz = √( 2.3 · 10⁻⁸ / (π · 100 000 · 4π · 10⁻⁷ · 1) )
         = √( 2.3 · 10⁻⁸ / 0.3948 )
         = √( 5.826 · 10⁻⁸ )
         = 0.000241 м = 0.241 мм        [товщина скін-шару на 100 кГц]
```

Коефіцієнт зростання динамічного опору обмотки `Fr = Rac / Rdc` розраховується за класичною моделлю Довелла (англ. *Dowell's equation*) для багатошарової циліндричної або плоскої обмотки:

```
Fr = ξ · ( (sinh(2ξ) + sin(2ξ)) / (cosh(2ξ) − cos(2ξ)) + (2·(m² − 1)/3) · ((sinh(ξ) − sin(ξ)) / (cosh(ξ) + cos(ξ))) )
```

Тут `ξ = h_layer / δ` — нормована товщина шару провідника відносно скін-шару; `m` — кількість шарів в обмотці.

Для мінімізації коефіцієнта `Fr` у push-pull трансформаторах застосовують два ключові прийоми:
1. **Використання літцендрату (Litz wire):** Набір із десятків ізольованих тонких жил діаметром `d ≤ 2 · δ` (наприклад, жилки 0.1 мм для частоти 100 кГц).
2. **Мідна фольга або планарні доріжки:** Товщина стрічки обирається рівною `h ≤ 1.5 · δ` (0.1–0.3 мм), що мінімізує циркулюючі вихрові струми у поперечному магнітному полі вікна трансформатора.

## 6. Доведення стійкості при керуванні за піковим струмом (PCMC)

Керування за піковим струмом (Peak Current Mode Control) усуває саму причину звалювання магнітного потоку завдяки внутрішньому апаратному швидкісному контуру зворотного зв'язку.

У схемі PCMC тактовий генератор синхронно встановлює тригер і відкриває черговий ключ на початку кожного напівперіоду. Вимикання ключа відбувається **не за фіксованим таймером**, а в точний момент, коли миттєвий первинний струм ключа досягає порогового значення `Iref`, виставленого зовнішнім регулятором напруги:

```
ip(t) = n · Iload + im(t) = Iref        [умова розмикання силового ключа]
```

Побудуємо точну різницеву модель перетворення магнітного стану від такту до такту.

Нехай на початку `k`-го періоду комутації (на старті напівперіоду транзистора `Q1`) струм намагнічування має деяке випадкове початкове зміщення `Im₀[k]`.

Під час провідності `Q1` струм намагнічування лінійно наростає з нахилом `m1 = Vin / Lm`:

```
im1(t) = Im₀[k] + m1 · t
```

Ключ `Q1` вимикається в момент `ton1[k]`, коли повний струм досягає порогу `Iref`:

```
Iref = n · Iload + Im₀[k] + m1 · ton1[k]
ton1[k] = (Iref − n · Iload − Im₀[k]) / m1   [точна тривалість першого робочого такту]
```

Кінцеве значення струму намагнічування наприкінці першого напівперіоду `Im₁[k]` становить:

```
Im₁[k] = Im₀[k] + m1 · ton1[k]
       = Im₀[k] + m1 · ((Iref − n · Iload − Im₀[k]) / m1)
       = Im₀[k] + (Iref − n · Iload) − Im₀[k]
       = Iref − n · Iload               [струм намагнічування в момент вимикання Q1]
```

Початкове зміщення `Im₀[k]` **повністю зникло** з виразу кінцевого магнітного стану першого напівперіоду.

Під час другого напівперіоду (робота ключа `Q2`) струм намагнічування спадає з тим самим за модулем нахилом `m2 = −Vin / Lm`. На початку другого такту стартовий струм становить `Im₁[k]`.

Аналогічно, вимикання `Q2` відбувається при досягненні того ж порогу `Iref` (з урахуванням протилежного напрямку струму відносно відводу):

```
ton2[k] = (Iref − n · Iload + Im₁[k]) / m1
```

Різниця тривалостей імпульсів двох напівперіодів автоматично адаптується під початкове зміщення:

```
Δton = ton1[k] − ton2[k]
     = −2 · (Im₀[k] / m1)               [компенсаційна різниця тривалостей ШІМ]
```

Зміна індукції за період перетворюється на:

```
ΔB_period[k+1] = −(Lm / (Np · Ae)) · Im₀[k]
```

Потокове відхилення на наступному кроці зв'язане з попереднім через дискретне відображення:

```
B_offset[k+1] = λ · B_offset[k]         [дискретне характеристичне рівняння дрейфу]
```

Де власне число системи за наявності компенсувального пилкоподібного сигналу з нахилом `Se` описується класичним рівнянням стабільності струмового контуру:

```
λ = − (m2 − Se) / (m1 + Se)             [коефіцієнт згасання збурення потоку]
```

Для коефіцієнта заповнення `D < 0.5` на напівперіод (що завжди строго виконується у push-pull перетворювачах, де робочий `D` на ключ становить 0.35–0.45 для збереження мертвого часу), модуль власного числа строго менший за одиницю:

```
|λ| < 1                                 [критерій абсолютної асимптотичної стійкості]
```

## 7. Компенсація нахилу (Slope Compensation) та субгармонічні коливання

Хоча на стороні первинних ключів шпаруватість напівперіоду ніколи не перевищує `D = 0.5`, вторинний згладжувальний дросель `Lout` працює на подвоєній частоті `2 · fsw` з еквівалентною шпаруватістю:

```
D_eff = 2 · D                           [еквівалентна шпаруватість вихідного ступеня]
```

Коли еквівалентна шпаруватість вихідного каскаду перевищує критичну межу `D_eff > 0.5` (що відповідає `D > 0.25` на кожен первинний ключ), у внутрішньому контурі регулювання струму виникає небезпека **субгармонійних коливань** (англ. *subharmonic oscillation*) на частоті `fsw / 2`.

Фізична природа субгармонійних коливань полягає в тому, що будь-яке випадкове збурення струму на початку такту `Δi₀` не згасає, а посилюється з кожним наступним періодом комутації за геометричною прогресією:

```
Δi_end = − (m2_ind / m1_ind) · Δi₀     [перетворення струмового збурення в індуктивності]
```

Тут `m1_ind = (Vs − Vout) / Lout` — швидкість наростання струму вихідного дроселя; `m2_ind = Vout / Lout` — швидкість спадання струму дроселя під час паузи.

При `D_eff > 0.5` нахил спадання перевищує нахил наростання (`m2_ind > m1_ind`), внаслідок чого модуль коефіцієнта посилення збурення перевищує одиницю: `|m2_ind / m1_ind| > 1`. Струм починає хаотично чергувати один широкий та один вузький імпульс, викликаючи акустичний писк трансформатора та паразитні низькочастотні пульсації напруги.

Для гарантованого придушення субгармонійних коливань до виміряного струмового сигналу (або до порогової напруги підсилювача помилки) додають штучний компенсувальний пилкоподібний сигнал із постійним нахилом `Se`.

Мінімально необхідний нахил компенсації для забезпечення стійкості за будь-якої шпаруватості визначається критерієм:

```
Se ≥ 0.5 · m2_ind                       [критерій безперечної субгармонійної стійкості]
```

При виборі оптимального нахилу `Se = m2_ind` струмовий контур набуває властивостей регулятора з дед-біт динамікою (англ. *deadbeat response*), за якої будь-яке початкове збурення струму повністю ліквідується рівно за один такт комутації.

## 8. Порівняння передатних функцій VMC та PCMC

Застосування поциклового струмового керування кардинально змінює структуру малосигнальної моделі перетворювача в частотній області:

1. **Режим керування за напругою (Voltage Mode):**
   Об'єкт регулювання має другий порядок через наявність вихідного LC-фільтра:

   ```
   G_vd(s) = (Vout / D) · (1 + s · Resr · Cout) / (1 + s · (Lout / Rload) + s² · Lout · Cout)
   ```

   Комплексно-спряжена пара полюсів на частоті резонансу `f₀ = 1 / (2π · √(Lout · Cout))` створює різкий спад фази на 180°, що вимагає складного триполюсного компенсатора типу Type III (PID-регулятора) та уповільнює динаміку реакції на накидання навантаження.

2. **Режим керування за струмом (Current Mode):**
   Внутрішній струмовий контур перетворює індуктивність вихідного дроселя `Lout` на кероване джерело струму, знижуючи порядок передатної функції до першого:

   ```
   G_vc(s) ≈ (Rload / (n · Rsense)) · (1 + s · Resr · Cout) / (1 + s · Rload · Cout)
   ```

   Система має єдиний домінуючий низькочастотний полюс навантаження `fp = 1 / (2π · Rload · Cout)`. Це дозволяє використовувати простий двополюсний компенсатор Type II (PI-регулятор), забезпечуючи запас фази понад 60° та прискорення реакції на перехідні процеси у 3–5 разів.

## 9. Архітектура датчиків первинного струму

Для реалізації Peak Current Mode Control у схемах push-pull застосовують три основні методи зняття струмового сигналу:

1. **Резистивні шунти у витоках MOSFET (`Rsense`):**
   Два прецизійні низькоіндуктивні шунти, встановлені між витоками `Q1, Q2` та шиною первинної землі. Сигнали об'єднуються через діодне «АБО» або підсумовуються диференціальним підсилювачем.
   *Переваги:* простота, низька собівартість, пряма передача сигналу від постійного струму до мегагерців.
   *Недоліки:* активні втрати потужності `P = I_rms² · Rsense`, що для струмів 50–100 А є неприйнятним.

2. **Струмові трансформатори (Current Transformers, CT):**
   Два мініатюрні високочастотні трансформатори струму, увімкнені послідовно в стокові або витокові кола ключів із вторинним коефіцієнтом передачі 1:50 або 1:100.
   *Переваги:* повна гальванічна розв'язка, мізерні омічні втрати в первинному витку, високий рівень амплітуди вихідної напруги на навантажувальному резисторі без додаткового підсилення.
   *Недоліки:* необхідність діодного кола скидання магнітного потоку (reset) струмового трансформатора під час паузи мертвого часу.

3. **Спільний струмовий датчик у шині живлення `+Vin`:**
   Трансформатор струму з двома зустрічно намотаними первинними витками або високошвидкісний датчик Холла, інтегрований у провідник центрального відводу.
   *Переваги:* один спільний компонент для обох тактів комутації, що виключає асиметрію самого вимірювального тракту.

## 10. Підсумок

1. **Voltage Mode Control у двотактному перетворювачі є безумовно нестійким**: будь-яка похибка затримки драйвера на десятки наносекунд або розкид опору каналів MOSFET на міліоми створює постійний інтеграл напруги, що виводить магнітопровід у режим лавинного насичення за кілька сотень тактів комутації (одиниці мілісекунд).
2. **Peak Current Mode Control забезпечує поциклову від'ємну корекцію**: вищий початковий магнітний потік автоматично зменшує тривалість поточного імпульсу ШІМ `ton1` та подовжує протилежний `ton2`, зводячи циклічний зсув індукції до нуля вже за 1–2 періоди комутації.
3. **Компенсація нахилу `Se ≥ 0.5 · m2_ind`** усуває небезпеку виникнення субгармонійних коливань струму на подвоєній частоті вихідного фільтра при коефіцієнтах заповнення `D > 0.25` на ключ.
4. Додаткове введення малого технологічного немагнітного зазору `lg ≈ 20...50 мкм` забезпечує надійний захисний бар'єр проти динамічних перехідних процесів різкого накидання навантаження, гарантуючи безаварійну експлуатацію силового трансформатора.
