# 📜 Еволюція специфікацій VRM та паралельного коду VID

Історія процесорного живлення — це літопис постійної кризи, у якій технологічний прогрес мікроелектроніки кожні кілька років упирався в неможливість подати потрібну напругу на кремнієвий кристал. На початку 1990-х років персональний комп'ютер взагалі не мав спеціалізованих стабілізаторів біля процесора: блок живлення стандарту AT видавав фіксовані +5 В, і ця напруга живила системну логіку, оперативну пам'ять, дискові накопичувачі та сам процесор Intel 80486. Напруга не була змінним інженерним параметром — вона була непорушною константою індустрії.

Криза вибухнула в момент, коли щільність розміщення транзисторів на кристалі перетнула межу субмікронних технологічних норм. Зі зменшенням товщини підзатворного діелектрика діоксиду кремнію до лічених нанометрів напруга 5 В викликала електричний пробій транзисторів. Крім того, квадратична залежність динамічної потужності КМОН-логіки `P = C · V² · f` означала, що подвоєння тактової частоти на напрузі 5 В перетворювало процесор на електричний нагрівач, нездатний розсіяти тепло наявними радіаторами. Виникла невідкладна потреба знизити напругу живлення: спершу до 3.3 В (процесори 486DX4 та Pentium P54C), а згодом до 2.8 В (Pentium MMX).

### Епоха ручних перемикачів та небезпека спаленого кремнію

Першим інженерним рішенням стало розміщення на материнській платі дискретного лінійного, а згодом імпульсного регулятора напруги. Але тут виникла нова комерційна та технічна перешкода: кожен новий степінг або модель процесора вимагали власної специфічної напруги. Наприклад, один процесор для гнізда Socket 7 працював при 3.3 В, інший — при 2.9 В, третій — при 2.8 В або 2.2 В (AMD K6).

Щоб одна й та сама материнська плата могла підтримувати різні процесори, виробники встановлювали біля регулятора поле механічних контактних перемикачів — джамперів (англ. *jumpers*) або DIP-перемикачів. Комбінація джамперів комутувала опір аналогового дільника у зворотному зв'язку ШІМ-стабілізатора, змінюючи вихідну напругу.

Цей підхід виявився надзвичайно ризикованим:

1. **Людський фактор:** Якщо збирач комп'ютера або користувач помилявся хоча б в одному джампері, перетворювач замість 2.2 В подавав на процесор 3.5 В. Ультратонкі транзистори вигорали за кілька мілісекунд при першому натисканні кнопки живлення.
2. **Несумісність з автоматизацією:** Комп'ютер не мав змоги динамічно змінювати напругу програмно під час роботи, адаптуючись до навантаження чи температури.
3. **Обмежена точність:** Механічні контакти джамперів окислювалися з часом, їхній контактний опір плавав, що призводило до випадкових просідань напруги та системних збоїв.

Індустрія гостро потребувала рішення, у якому процесор самостійно, без втручання людини, повідомляв би материнській платі свій точний заводський вольтаж.

### Народження стандарту VID: специфікації Intel VRM 8.1 та 8.2

Восени 1995 року компанія Intel представила серверний процесор шостого покоління Pentium Pro для гнізда Socket 8. Разом із ним дебютувала офіційна специфікація модуля стабілізатора напруги **VRM 8.1** (Voltage Regulator Module, від лат. *regulare* — впорядковувати).

Уперше в історії процесор отримав чотири спеціалізовані сигнальні виводи: `VID0`, `VID1`, `VID2`, `VID3`. Сама концепція була максимально простою: усередині корпусу процесора кожен із цих виводів або жорстко закорочувався на землю (GND, логічний `0`), або залишався вільним (стан `Open` / `1`, що підтягувався резистором на платі).

Чотири біти забезпечували 16 можливих комбінацій. Вони дозволяли кодувати напруги від 2.1 В до 3.5 В з фіксованим дискретним кроком 100 мВ:

```
Таблиця кодування Intel VRM 8.1 (4-бітний паралельний VID):
┌──────┬──────┬──────┬──────┬─────────────────┐
│ VID3 │ VID2 │ VID1 │ VID0 │ Вихідна напруга │
├──────┼──────┼──────┼──────┼─────────────────┤
│  0   │  1   │  1   │  1   │ 2.10 В          │
│  0   │  1   │  1   │  0   │ 2.20 В          │
│  0   │  1   │  0   │  1   │ 2.30 В          │
│  ... │  ... │  ... │  ... │ ...             │
│  0   │  0   │  0   │  0   │ 2.80 В          │
│  ... │  ... │  ... │  ... │ ...             │
│  1   │  0   │  0   │  0   │ 3.50 В          │
│  1   │  1   │  1   │  1   │ Заборонено (Вимк)│
└──────┴──────┴──────┴──────┴─────────────────┘
```

Особливе значення мала комбінація `1111` (усі виводи відімкнені): вона кодувала стан вимкнення стабілізатора (`No CPU Present` або аварійний стан). Якщо процесор не було вставлено в сокет або сокет був пошкоджений, VRM блокував генерацію напруги, рятуючи компоненти плати від короткого замикання.

### Гонка мілівольтів: від 5 бітів до 8 бітів (VRM 8.4 – VRM 11.1)

З кожним новим поколінням кремнієвих техпроцесів робоча напруга ядер неухильно знижувалася, а вимоги до точності її утримання ставали дедалі жорсткішими. Кроку в 100 мВ уже було замало: відхилення навіть у 50 мВ для процесора з номіналом 1.5 В становило понад 3 % допустимого допуску.

Це викликало безперервну череду оновлень специфікацій паралельного коду VID:

#### 1. VRM 8.4 та 8.5 (Pentium III, Slot 1 / Socket 370)
Додано п'ятий біт `VID4`. Кількість кодових комбінацій зросла до 32, робочий діапазон опустився до 1.30–3.50 В, а дискретний крок напруги зменшився вдвічі — до **50 мВ**. Це дозволило гнучко живити ядра Coppermine та Tualatin, які перейшли на алюмінієву та мідну металізацію шарів із напругами 1.65 В та 1.475 В відповідно. Формула обчислення вихідної напруги для діапазону 1.30–2.05 В набула лінійного вигляду:

```
V_out = 2.05 В - (код_VID · 0.05 В)
```

#### 2. VRM 9.0 та 9.1 (Pentium 4 Willamette/Northwood, Socket 423 / 478)
Поява мікроархітектури NetBurst зажадала колосальних струмів до 70–80 А при робочих частотах понад 2 ГГц. Специфікація VRM 9.0 зберегла 5-бітне кодування, але змістила весь діапазон униз — від 1.100 В до 1.850 В, а крок напруги знову зменшили вдвічі — до **25 мВ**:

```
V_out = 1.850 В - (код_VID · 0.025 В)
```

Саме в еру VRM 9.0 живлення стабілізатора було остаточно переведено з 5-вольтової шини на 12 В через введення окремого 4-контактного силового роз'єму ATX12V, що дозволило зменшити струми у джгутах живлення блока майже у два з половиною рази.

#### 3. VRM 10.0 та 10.2 (Pentium 4 Prescott, LGA 775)
90-нанометрове ядро Prescott споживало понад 100 А при напрузі близько 1.25–1.40 В, розсіюючи понад 130 Вт тепла. Специфікація ввела шостий біт `VID5` (64 комбінації), розширивши діапазон від 0.8375 В до 1.6000 В із кроком **12.5 мВ**:

```
V_out = 1.6000 В - (код_VID · 0.0125 В)
```

У цій же специфікації вперше стандартизували обов'язкове використання динамічного нахилу навантаження — [адаптивного позиціонування напруги](root:hw-power/adaptive-voltage-positioning) (Load-Line / Droop Control), що дозволило вдвічі скоротити необхідну ємність вихідних конденсаторів материнської плати.

#### 4. VRM 11.0 та 11.1 (Core 2 Duo / Quad Conroe/Yorkfield, LGA 775)
Мікроархітектура Core повернула високу питому енергоефективність, але вимагала прецизійного регулювання напруг у широкому динамічному діапазоні від 0.50000 В до 1.60000 В. Інтерфейс було розширено до повних **8 бітів** (`VID0`–`VID7`, 256 дискретних станів), а крок напруги досяг ювелірних **6.25 мВ** (0.00625 В):

```
V_out = 1.60000 В - (код_VID · 0.00625 В)
```

Така висока розрядність дозволила системі керування живленням реалізувати багатоступеневу технологію Intel Enhanced SpeedStep (EIST), за якої процесор під час простою миттєво знижував напругу до 0.85–0.90 В, зменшуючи енергоспоживання офісних комп'ютерів у рази. Проте на цьому резерв паралельного підходу вичерпався остаточно.

### Архітектурний глухий кут паралельної шини

До кінця 2000-х років паралельна шина VID досягла межі своїх фізичних можливостей. З появою перших багатоядерних процесорів з інтегрованою графікою (Intel Clarkdale, Sandy Bridge та AMD Fusion) виявилися три фатальні недоліки:

1. **Розмноження силових доменів:** Процесор перестав бути монолітним споживачем з єдиною лінією `Vcore`. На одному кристалі розмістилися обчислювальні ядра, графічний прискорювач, контролер оперативної пам'яті (System Agent) та шини введення-виведення. Кожен блок вимагав власної незалежної напруги зі своїм динамічним графіком зміни. Чотири силові площини вимагали 32 паралельні лінії VID — це було неприпустимим марнотратством дорогоцінних виводів сокета та шарів друкованої плати.
2. **Проблема перехідних збоїв (Bus Skew):** Коли 8 бітів перемикалися одночасно на високій швидкості, мізерна різниця в затримках ліній призводила до того, що ЦАП контролера на кілька наносекунд бачив хибні коди напруги. Якщо в процесі переходу випадково з'являвся код вимкнення або перенапруги, система аварійно вимикалася.
3. **Відсутність зворотної телеметрії:** Процесор залишався абсолютно «сліпим». Він не знав, який реальний струм споживає плата, яка температура силових транзисторів і чи не перебуває стабілізатор на межі теплового пробою.

У 2010 році індустрія здійснила вирішальний крок: паралельні шини VID були назавжди списані в історію. На зміну їм прийшли швидкісні послідовні цифрові протоколи — Intel SVID, AMD SVI2/SVI3 та PMBus/AVSBus, які передають команди вольтажу, телеметрію струму та температури всього трьома сигнальними провідниками на частотах до 25–50 МГц.
