# 🧮 Математика перехідних процесів та slew rate у DVFS

Динамічне масштабування напруги та частоти (DVFS) вимагає переведення вихідного потенціалу багатофазного імпульсного стабілізатора з початкового рівня `V_1` на кінцевий рівень `V_2` за скінченний час `Δt`. Цей процес не є миттєвим: він жорстко обмежений законами електродинаміки конденсаторних батарей, швидкістю наростання струму в силових індуктивностях та стійкістю контуру зворотного зв'язку.

Цей математичний аналіз виводить фундаментальні співвідношення між швидкістю наростання напруги (`Slew Rate`), піковими ємнісними струмами, індуктивними обмеженнями багатофазного перетворювача та дисипацією енергії під час перемикання станів.

---

### 1. Ємнісний струм зміщення та рівняння перехідного процесу

Вихідний фільтр процесорного стабілізатора напруги містить паралельний масив багатошарових керамічних конденсаторів (MLCC) та полімерно-танталових ємностей із сумарною еквівалентною ємністю `C_out` та еквівалентним послідовним опором `R_ESR`.

Коли за командою VID напруга на виході змінюється в часі за законом `v(t)`, через ємність протікає струм зміщення `i_cap(t)`:

```
i_cap(t) = C_out · (dv(t) / dt)
```

При лінійному наростанні напруги з постійною швидкістю `SR = dV / dt = const` ємнісний струм є прямокутним імпульсом постійної амплітуди протягом усього часу наростання `Δt = |V_2 - V_1| / SR`:

```
I_cap = C_out · SR
```

Якщо напруга зростає (`V_2 > V_1`), струм `I_cap` додається до корисного струму навантаження ядер процесора `I_load(t)`. Сумарний струм `i_total(t)`, який мають забезпечити фази регулятора, становить:

```
i_total(t) = I_load(t) + C_out · SR
```

Якщо напруга знижується (`V_2 < V_1`), похідна `dv/dt < 0`, і струм `I_cap` стає від'ємним: конденсатори повертають накопичений заряд назад у силові кола:

```
i_total(t) = I_load(t) - C_out · |SR|
```

Якщо струм розряду ємностей `C_out · |SR|` перевищує струм споживання навантаження `I_load`, сумарний струм перетворювача стає від'ємним (`i_total < 0`). Це означає, що енергія починає текти у зворотному напрямку — від вихідних конденсаторів через нижні польові транзистори у вхідну шину +12 В.

### 2. Індуктивні обмеження швидкості наростання струму

Швидкість наростання напруги `SR` не може бути як завгодно великою. Вона обмежена максимальною швидкістю зміни струму в багатофазній групі дроселів.

Розглянемо перетворювач із `N` паралельними фазами. Кожна фаза містить дросель з індуктивністю `L`. Еквівалентна сумарна індуктивність усього паралельного масиву становить:

```
L_eq = L / N
```

Швидкість наростання струму в дроселі описується законом Фарадея:

```
di_L / dt = V_L / L_eq
```

де `V_L` — різниця потенціалів, прикладена до виводів дроселя.

#### Випадок А: Підйом напруги (Up-step Transition, V_1 → V_2)

Під час підйому напруги ШІМ-контролер відкриває верхні польові транзистори (High-Side MOSFETs) на максимальний коефіцієнт заповнення. До дроселів прикладається максимальна пряма напруга:

```
V_L_up = V_in - v(t)
```

Максимальна фізична швидкість наростання струму в дроселях становить:

```
(di_L / dt)_max_up = (V_in - V_2) / L_eq = N · (V_in - V_2) / L
```

Щоб вихідна напруга зростала із заданою швидкістю `SR`, індуктивності повинні встигати нарощувати струм швидше, ніж зростає сумарне навантаження. Звідси випливає умова відсутності просідання напруги під час переходу:

```
(di_L / dt)_max_up ≥ (dI_load / dt) + C_out · (d²v / dt²)
```

Якщо перехід здійснюється з лінійним `SR`, то друга похідна на фронтах формує імпульси, а на стаціонарній ділянці переходу дроселі повинні забезпечити струм `I_cap`. Час розгону струму в дроселях `t_rise_I` до величини `I_cap` становить:

```
t_rise_I = (C_out · SR · L_eq) / (V_in - V_2)
```

Цей час повинен бути значно меншим за повну тривалість переходу `Δt`:

```
(C_out · SR · L_eq) / (V_in - V_2) ≪ (V_2 - V_1) / SR
```

Звідси отримуємо фундаментальне інженерне обмеження на максимально допустиму швидкість наростання напруги:

```
SR_max_up < √[ (V_2 - V_1) · (V_in - V_2) / (L_eq · C_out) ]
```

#### Випадок Б: Зниження напруги (Down-step Transition, V_2 → V_1)

Під час примусового активного зниження напруги верхні ключі закриті, а нижні транзистори (Low-Side MOSFETs) відкриті, притискаючи комутовані виводи дроселів до землі (0 В). До індуктивностей прикладається спадна різниця потенціалів:

```
V_L_down = 0 - v(t) = -v(t)
```

Максимальна швидкість спадання струму обмежена виключно поточною вихідною напругою:

```
(di_L / dt)_max_down = -v(t) / L_eq = -N · V_1 / L
```

Оскільки кінцева напруга `V_1` (зазвичай 0.6–0.8 В) набагато менша за різницю напруг при заряді `(V_in - V_2) = (12.0 В - 1.3 В = 10.7 В)`, **швидкість спадання струму в індуктивностях у 10–15 разів нижча за швидкість його наростання**:

```
| (di_L / dt)_down | / (di_L / dt)_up = V_1 / (V_in - V_2) ≈ 0.7 В / 10.7 В ≈ 0.065
```

Це асиметричне фізичне обмеження пояснює, чому форсоване зниження напруги значно небезпечніше за її підйом. Якщо контур регулювання намагається знизити напругу занадто швидко (`SR_down` зависокий), індуктивності не встигають скидати накопичену магнітну енергію, струм дроселів стає глибоко від'ємним, і виникає високовольтний викид напруги (Overshoot), здатний вивести з ладу кристал.

### 3. Динамічна похибка стеження та смуга пропускання контуру зворотного зв'язку

ШІМ-контролер регулює напругу не миттєво: його передатна функція замкненого контуру має скінченну смугу пропускання частот `f_BW` (Unity Gain Bandwidth, зазвичай 50–150 кГц для багатофазних перетворювачів).

Коли на вхід підсилювача помилки надходить лінійно зростаючий сигнал опорної напруги `v_ref(t) = V_1 + SR · t`, система автоматичного регулювання реагує на пандус із характерним динамічним відставанням.

У класичній системі регулювання другого порядку з еквівалентною частотою зрізу контуру `ω_c = 2 · π · f_BW` передатна функція замкненого стабілізатора напруги поблизу смуги пропускання наближається виразом:

```
T(s) = V_out(s) / V_ref(s) ≈ 1 / (1 + s / ω_c + s² / ω_0²)
```

де `ω_0 = 1 / √(L_eq · C_out)` — власна резонансна частота вихідного LC-фільтра.

Похибка стеження в часовій області між замовленим значенням ЦАП та реальною вихідною напругою `e(t) = v_ref(t) - v_out(t)` у стаціонарному режимі лінійного наростання дорівнює:

```
e_ss = SR / ω_c = SR / (2 · π · f_BW)
```

Порахуймо значення динамічного відставання напруги для реальної системи з `SR = 30 мВ/мкс` та смугою пропускання `f_BW = 80 кГц`:

```
e_ss = (30 000 В/с) / (2 · π · 80 000 с⁻¹)
     = 30 000 / 502 654
     ≈ 0.0597 В = 59.7 мВ
```

Це означає, що протягом усього процесу швидкого наростання напруга на виході стабілізатора відстає від коду ЦАП майже на 60 мілівольтів. Якщо процесор увімкне підвищену тактову частоту одразу після відправки останнього біта команди `SetVID_Fast`, ядра спробують працювати на максимальній частоті за напруги, що ще на 60 мВ нижча за номінальну.

Саме тому стандарт SVID вводить обов'язковий апаратний інтервал очікування стабілізації (Settling Time) або формує прапорець `Slew_Busy` у регістрі `Status1`. Процесор затримує перемикання помножувача частоти PLL на час `t_settle`:

```
t_settle = Δt_ramp + 3 / ω_c = (ΔV / SR) + 3 / (2 · π · f_BW)
```

Для нашого числового прикладу: `Δt_ramp = 20.0 мкс`, додатковий час загасання похибки становить `3 / (2 · π · 80 кГц) ≈ 6.0 мкс`, отже повний час готовності становить `26.0 мкс`.

### 4. Аналітичний розв'язок диференціального рівняння RLC-контуру при лінійному наростанні

Щоб точно розрахувати миттєву напругу на процесорі під час перехідного процесу, розглянемо повне лінійне диференціальне рівняння другого порядку для вихідного вузла перетворювача.

Еквівалентна схема містить паралельне з'єднання еквівалентної індуктивності `L_eq`, вихідної ємності `C_out` з послідовним опором `R_ESR`, опору лінії навантаження `R_LL` та джерела струму навантаження `I_load`.

Рівняння балансу струмів у вузлі вихідної напруги `v(t)` записується у вигляді:

```
L_eq · C_out · (d²v / dt²) + (L_eq / R_load + R_eq · C_out) · (dv / dt) + v(t) = v_ref(t)
```

де `R_eq = R_ESR + R_dson / N + R_trace` — сумарний активний демпфуючий опір контуру.

Введемо характеристичні параметри коливальної ланки:
* Власна кутова частота незгасаючих коливань: `ω_0 = 1 / √(L_eq · C_out)`
* Коефіцієнт загасання (Damping Factor): `ζ = (R_eq / 2) · √(C_out / L_eq) + 1 / (2 · R_load · ω_0 · C_out)`
* Добротність контуру (Quality Factor): `Q = 1 / (2 · ζ)`

Коли опорна напруга зростає лінійно `v_ref(t) = V_1 + SR · t` для `0 ≤ t ≤ Δt`, загальний розв'язок для напруги `v(t)` в умовах критичного або надкритичного демпфування (`ζ ≥ 1`, що є обов'язковою вимогою стійкості процесорного живлення) набуває вигляду:

```
v(t) = V_1 + SR · [ t - (2 · ζ / ω_0) + (2 · ζ / ω_0) · e^(-ζ · ω_0 · t) · cos(ω_d · t) ]
```

де `ω_d = ω_0 · √(1 - ζ²)` — частота згасаючих коливань.

Аналіз цього виразу дає три фундаментальні інженерні висновки:

1. **Експоненційне відставання на початку:** У перші мікросекунди (`t < 1 / (ζ · ω_0)`) напруга зростає не лінійно, а за квадратично-експоненційним законом через інерційність накопичення магнітного поля в індуктивностях.
2. **Стаціонарний зсув фази:** На лінійній ділянці переходу напруга відстає від опорного пандуса на постійну величину часової затримки `τ_lag = 2 · ζ / ω_0`.
3. **Відсутність коливального перерегулювання:** При правильному підборі демпфуючого опору `R_eq` (за рахунок активного нахилу лінії навантаження [адаптивного позиціонування напруги](topic:hw-power/adaptive-voltage-positioning)) коефіцієнт `ζ ≈ 1`, тому напруга плавно входить у нову робочу точку `V_2` без паразитного дзвону (Ringing) та високовольтних викидів.

### 5. Одночасна дія зміни вольтажу VID та стрибка струму навантаження

Найбільш критичним для системи живлення є комбінований динамічний сценарій: процесор одночасно надсилає команду `SetVID_Fast` (наприклад, підйом напруги з 0.7 В до 1.3 В) і рівно в цей же момент активує обчислювальні конвеєри, створюючи накид струму `ΔI_load = 0 → 150 А`.

У системі з активним позиціонуванням напруги (Load-Line Droop Control) результуюча цільова напруга формується з урахуванням активного нахилу лінії навантаження `R_LL`:

```
v_target(t) = v_VID(t) - i_load(t) · R_LL
```

Для системи з `R_LL = 1.0 мОм` та стрибком струму 150 А спад напруги становить:

```
ΔV_droop = 150 А · 1.0·10⁻³ Ом = 0.150 В = 150 мВ
```

Тому кінцева стаціонарна напруга ядра після виходу на нову робочу точку складе не 1.300 В, а:

```
V_final = 1.300 В - 0.150 В = 1.150 В
```

Це активне просідання зменшує амплітуду потрібного перепаду напруги з `0.60 В` до `0.45 В`, що безпосередньо знижує ємнісний струм заряду `I_cap = C_out · (dV/dt)` на 25 % і суттєво полегшує тепловий режим перетворювача під час розгону.

### 6. Динамічний коефіцієнт заповнення ШІМ під час переходу

Під час стаціонарного режиму коефіцієнт заповнення імпульсів ШІМ (Duty Cycle) для понижувального buck-перетворювача визначається простим співвідношенням напруг:

```
D_stat = V_out / V_in
```

Проте під час швидкого перехідного процесу із заданою швидкістю `SR` дроселі повинні забезпечувати не лише миттєву напругу `v(t)`, але й додаткову напругу для нарощування струму `L_eq · (di_total / dt)`.

Тому миттєвий динамічний коефіцієнт заповнення `D_dyn(t)` описується диференційним виразом:

```
D_dyn(t) = [ v(t) + L_eq · (d i_total(t) / dt) ] / V_in
```

Підставляючи вираз для повного струму `i_total(t) = I_load + C_out · SR`:

```
D_dyn(t) = [ v(t) + L_eq · (d I_load / dt) + L_eq · C_out · (d²v / dt²) ] / V_in
```

На лінійній ділянці наростання (`d²v / dt² = 0`):

```
D_dyn(t) = [ V_1 + SR · t + L_eq · (d I_load / dt) ] / V_in
```

Якщо під час розгону `dI_load / dt` досягає 50 А/мкс, додатковий динамічний зсув коефіцієнта заповнення для нашої системи становить:

```
ΔD_dyn = (L_eq · dI_load / dt) / V_in
       = (18.75·10⁻⁹ Гн · 50·10⁶ А/с) / 12.0 В
       = 0.9375 В / 12.0 В
       ≈ 0.0781  (збільшення Duty Cycle на 7.81 %)
```

Це означає, що за номінального статичного `D_stat = 1.30 В / 12.0 В = 10.83 %` у момент переходу ШІМ-контролер повинен миттєво розширити імпульси до `D_dyn = 10.83 % + 7.81 % = 18.64 %`. Якщо контролер має жорстке обмеження максимального заповнення `D_max`, напруга почне просідати нижче розрахункового темпу.

### 7. Розрахунок мінімальної кількості фаз перетворювача

Кожна силова фаза сучасного регулятора (інтелектуальна збірка DrMOS) має граничний тривалий тепловий струм `I_phase_cont` (зазвичай 30–40 А) та короткочасний піковий струм насичення дроселя `I_sat` (зазвичай 45–60 А).

Щоб визначити мінімально необхідну кількість паралельних фаз `N_min`, яка гарантує відсутність насичення феритових осердь під час переходу `SetVID_Fast`, застосовують критерій пікового струму:

```
N_min ≥ (I_load_max + C_out · SR_fast) / I_sat
```

Для нашої розрахункової системи з `I_load_max = 120 А`, `C_out = 2200 мкФ`, `SR = 30 мВ/мкс` (`I_cap = 66 А`) та дроселями з `I_sat = 30 А`:

```
I_peak_total = 120 А + 66 А = 186.0 А
N_min ≥ 186.0 А / 30.0 А = 6.2 фази  ->  обираємо N = 8 фаз
```

Запас у 8 фаз забезпечує струм на одну фазу `186 / 8 = 23.25 А`, що гарантує 22 % запас до порогу насичення котушок `I_sat`, виключаючи небезпеку різкого падіння індуктивності та перегорання польових транзисторів.

Крім того, багатофазна топологія зі зсувом тактових імпульсів на кут `θ = 360° / N = 45°` забезпечує взаємне віднімання пульсацій струмів окремих котушок на вихідних конденсаторах. Результуюча амплітуда пульсацій вихідного струму `ΔI_out_ripple` зменшується в рази порівняно з пульсаціями однієї фази:

```
ΔI_out_ripple = [ (V_in - N · V_out) · V_out ] / (f_sw · L · V_in)
```

де `f_sw` — частота комутації однієї фази (зазвичай 400–800 кГц). Ефективна частота пульсацій на вихідних конденсаторах зростає до `f_eff = N · f_sw = 8 · 500 кГц = 4.0 МГц`, що дозволяє фільтрувати перехідні процеси компактними керамічними конденсаторами типорозмірів 0805 та 0603 безпосередньо всередині порожнини сокета процесора.

### 8. Енергетичний баланс та втрати потужності при комутації

Енергія, накопичена у вихідній конденсаторній батареї стабілізатора, визначається виразом:

```
E_cap = (1 / 2) · C_out · V²
```

При зміні напруги від `V_1` до `V_2` зміна накопиченої енергії становить:

```
ΔE_cap = (1 / 2) · C_out · (V_2² - V_1²)
```

Під час заряду конденсаторів від джерела напруги `V_in` через активний опір силових ключів, міді дроселів та `R_ESR` частина енергії неминуче розсіюється у вигляді тепла.

Миттєва потужність теплових втрат на сумарному еквівалентному послідовному опорі `R_eq` контуру становить:

```
P_loss(t) = i_cap²(t) · R_eq = (C_out · SR)² · R_eq
```

Сумарна енергія, що перетворюється на тепло за час одного перехідного процесу `Δt = ΔV / SR`:

```
E_loss = ∫[0..Δt] P_loss(t) dt
       = (C_out · SR)² · R_eq · (ΔV / SR)
       = C_out² · R_eq · ΔV · SR
```

З цього виразу видно критичну залежність: **теплові втрати під час перемикання напруги зростають прямо пропорційно до швидкості наростання `SR`**. Подвоєння швидкості наростання з 15 мВ/мкс до 30 мВ/мкс рівно вдвічі збільшує кількість розсіяного тепла на кожен цикл зміни стану процесора.

### 4. Комплексний числовий приклад розрахунку перехідного процесу

Розглянемо реальну систему живлення високопродуктивного процесора з наступними параметрами:

```
Вхідні інженерні параметри системи:
  Вхідна напруга шини живлення:    V_in   = 12.0 В
  Початкова напруга (стан спокою): V_1    = 0.70 В
  Кінцева напруга (Turbo Boost):   V_2    = 1.30 В
  Перепад напруги:                 ΔV     = 1.30 - 0.70 = 0.60 В
  Кількість активних фаз VRM:      N      = 8 фаз
  Індуктивність однієї фази:       L      = 150 нГн = 150·10⁻⁹ Гн
  Еквівалентна індуктивність:      L_eq   = 150 нГн / 8 = 18.75 нГн
  Сумарна вихідна ємність MLCC:    C_out  = 2200 мкФ = 2.2·10⁻³ Ф
  Еквівалентний опір контуру:      R_eq   = 0.50 мОм = 0.5·10⁻³ Ом
  Постійний струм навантаження:    I_load = 80 А
```

Порівняємо два режими роботи протоколу SVID:
* **Режим 1:** Швидкий перехід `SetVID_Fast` зі швидкістю `SR_fast = 30 мВ/мкс` (`30 000 В/с`).
* **Режим 2:** Повільний перехід `SetVID_Slow` зі швидкістю `SR_slow = 5 мВ/мкс` (`5 000 В/с`).

```
================================================================================
РОЗРАХУНОК 1: Швидкий перехід (SetVID_Fast, SR = 30 мВ/мкс)
================================================================================

1. Час наростання напруги:
   Δt_fast = ΔV / SR_fast
           = 0.60 В / 0.030 В/мкс
           = 20.0 мкс

2. Додатковий ємнісний струм заряду C_out:
   I_cap_fast = C_out · SR_fast
              = (2.2·10⁻³ Ф) · (30 000 В/с)
              = 66.0 А

3. Піковий сумарний струм крізь дроселі:
   I_peak_fast = I_load + I_cap_fast
               = 80 А + 66 А
               = 146.0 А  (струм на фазу: 146 / 8 = 18.25 А)

4. Максимальна швидкість наростання струму дроселів:
   (di_L/dt)_max = (V_in - V_2) / L_eq
                 = (12.0 В - 1.30 В) / (18.75·10⁻⁹ Гн)
                 = 10.7 В / (18.75·10⁻⁹ Гн)
                 = 570.67 А/мкс

5. Час виходу індуктивностей на струм I_cap:
   t_lag = I_cap_fast / (di_L/dt)_max
         = 66.0 А / (570.67 А/мкс)
         = 0.116 мкс = 116 нс
   Оскільки 116 нс ≪ 20.0 мкс, фази легко встигають за темпом наростання.

6. Теплова енергія, розсіяна на R_eq за час переходу:
   E_loss_fast = I_cap_fast² · R_eq · Δt_fast
               = (66.0 А)² · (0.5·10⁻³ Ом) · (20.0·10⁻⁶ с)
               = 4356 · 0.0005 · 0.00002
               = 43.56 мкДж

================================================================================
РОЗРАХУНОК 2: Повільний перехід (SetVID_Slow, SR = 5 мВ/мкс)
================================================================================

1. Час наростання напруги:
   Δt_slow = ΔV / SR_slow
           = 0.60 В / 0.005 В/мкс
           = 120.0 мкс  (у 6 разів довше)

2. Додатковий ємнісний струм заряду C_out:
   I_cap_slow = C_out · SR_slow
              = (2.2·10⁻³ Ф) · (5 000 В/с)
              = 11.0 А  (у 6 разів менше!)

3. Піковий сумарний струм крізь дроселі:
   I_peak_slow = I_load + I_cap_slow
               = 80 А + 11 А
               = 91.0 А  (струм на фазу: 91 / 8 = 11.38 А)

4. Теплова енергія, розсіяна на R_eq за час переходу:
   E_loss_slow = I_cap_slow² · R_eq · Δt_slow
               = (11.0 А)² · (0.5·10⁻³ Ом) · (120.0·10⁻⁶ с)
               = 121 · 0.0005 · 0.00012
               = 7.26 мкДж  (втрати зменшилися у 6 разів!)
```

### 5. Аналіз пасивного згасання (SetVID_Decay)

При переході процесора у стан глибокого сну C-State використовується команда `SetVID_Decay`. Контролер вимикає генерацію ШІМ і переводить силові ключі у високоомний стан.

Розряд вихідної ємності `C_out` відбувається виключно струмом витоку та фоновим споживанням сплячого кристала `I_leak`:

```
dv(t) / dt = - I_leak(v) / C_out
```

Якщо вважати струм витоку приблизно сталим на рівні `I_leak = 3.0 А`:

```
Час пасивного спаду напруги з 1.30 В до 0.70 В:
  Δt_decay = C_out · ΔV / I_leak
           = (2.2·10⁻³ Ф · 0.60 В) / 3.0 А
           = 1.32·10⁻³ Кл / 3.0 А = 0.44·10⁻³ с = 440 мкс
```

Пасивний спад триває 440 мікросекунд (проти 20 мікросекунд у режимі `Fast`), але він має дві принципові фізичні переваги:
1. **Нульові комутаційні втрати:** Силові ключі взагалі не перемикаються, динамічні втрати в затворах дорівнюють нулю.
2. **Відсутність зворотних струмів:** Струм у дроселях монотонно спадає до нуля без переходу у від'ємну область, що повністю виключає закидання реактивної енергії у вхідні ланцюги живлення комп'ютера.
