# Монтаж панелі в полі: кріплення, бруд, град, тварини

<preknowlist>
- [ВАХ панелі](root:hw-power/panel-iv-mpp) — як виглядає вольт-амперна характеристика кремнієвого фотоелемента та де лежить точка максимальної потужності.
- [Байпасний діод сонячної панелі](root:hw-power/panel-bypass-diode) — як зустрічно-паралельний діод захищає затінені комірки від локального перегріву.
- [Температурні коефіцієнти сонячної панелі](root:hw-power/panel-temperature-coeff) — чому нагрів кремнію знижує напругу холостого ходу та вихідну потужність.
- [Захисне заземлення](root:hw-power/protective-grounding) — зрівнювання потенціалів металоконструкцій для відведення струмів витоку та грозових перенапруг.
- [Ізоляція проводів і кабелів](root:hw-components/wire-insulation) — деградація діелектричних полімерів під впливом ультрафіолету, вологи та озону.
</preknowlist>

Сонячна панель на заводському тестовому стенді віддає номінальні 100 Вт при освітленості 1000 Вт/м² та строго перпендикулярному падінні світла за температури кристала 25 °C, але після монтажу на польовій щоглі автономний ретранслятор чи датчик стикається з реальною геометрією руху сонця: кут падіння променів змінюється щохвилини, а взимку полуденне сонце в помірних широтах підіймається лише на 15–18° над горизонтом проти 60–65° улітку. Якщо закріпити модуль горизонтально або під випадковим кутом, зимова генерація падає не у два, а у вісім-десять разів через косинусне зменшення проєкції площі, потовщення атмосферного оптичного шару та налипання снігу.

Для автономного вузла (англ. off-grid), що живиться від комбінації панелі та акумулятора, критичним періодом є зимове сонцестояння (грудень і січень). Улітку генерація завжди надлишкова — акумулятор повністю заряджається за перші дві ранкові години, після чого контролер заряду скидає зайву енергію. Узимку сонячний день триває лише 7–8 годин, а пряма радіація ослаблена хмарністю та довгим шляхом світла крізь повітряну масу. Якщо система спроєктована під річний максимум виробки (стандартний мережевий підхід із кутом нахилу близько 30–35°), у грудні акумулятор зазнає глибокого системного недозаряду, що закінчується замерзанням електроліту та повним вимиканням апаратури.

## Орієнтація за азимутом і кутом нахилу: подолання зимового дефіциту

Орієнтація панелі в просторі визначається двома параметрами: азимутом (араб. as-sumūt — «напрямки, шляхи») та кутом нахилу до горизонту (лат. inclinatio — «нахил, схилення»).

Азимут встановлює напрямок площини модуля відносно сторін світу. Для північної півкулі модуль спрямовують суворо на географічний (істинний) південь із відхиленням не більше ±5°. Слід розрізняти географічний та магнітний південь: покази туристичного магнітного компаса потребують корекції на магнітне схилення місцевості (кут між напрямком на магнітний полюс і географічний меридіан), яке в Україні коливається від +5° до +9° на схід. Спрямування за нескомпенсованим компасом зміщує пік генерації на передполуденні години та краде вечірню інсоляцію.

Кут нахилу `β` відлічується від горизонтальної площини. Висота сонця над горизонтом у сонячний полудень `h_noon` змінюється протягом року за формулою:

```
h_noon = 90° - φ + δ
```

де `φ` — географічна широта точки монтажу, а `δ` — сонячне схилення, яке плавно коливається від +23.44° у день літнього сонцестояння до -23.44° у день зимового сонцестояння.

На широті Києва чи Харкова (`φ ≈ 50°`):
- у червні полуденне сонце стоїть високо: `h_noon = 90° - 50° + 23.44° = 63.44°`;
- у грудні сонце ковзає над самим горизонтом: `h_noon = 90° - 50° - 23.44° = 16.56°`.

Ефективна оптична площа панелі, яка перехоплює прямі сонячні промені, підпорядковується закону Ламберта:

```
A_eff = A_panel · cos(θ_inc)
```

де `θ_inc` — кут між вектором падіння сонячного променя та нормаллю до площини фотоелементів. Для модуля, зорієнтованого на південь, у полудень кут падіння дорівнює:

```
θ_inc = |φ - β - δ|
```

*Геометрія сонячних кутів для автономного польового вузла. Улітку енергії з надлишком, а взимку крутий нахил ставить площину перпендикулярно до низького полуденного променя та скидає сніг під дією сили тяжіння.*

Для автономних систем фіксований кут нахилу обирають не за правилом річного максимуму (`β ≈ φ - 10°`), а за правилом зимової оптимізації:

```
β_offgrid = φ + 15° ... φ + 20°
```

Для широт 46–52° це означає встановлення панелі під крутим кутом **55°–65° до горизонту**. Повний висновок тригонометричних рівнянь наведено у вставці [геометричний розрахунок сонячної інсоляції](root:hw-power/montazh-paneli-v-poli/math-solar-geometry-tilt.md).

Такий крутий кут дає відразу три вирішальні інженерні переваги:
1. **Максимізація зимового струму:** у грудні кут падіння променів `θ_inc` становить усього `|50° - 65° - (-23.44°)| = 8.44°`, а `cos(8.44°) = 0.989`, тобто втрати від косого падіння практично відсутні (менше 1.1%).
2. **Зменшення літнього перегріву:** у червні високі промені падають під косим кутом `|50° - 65° - (+23.44°)| = 38.44°` (`cos = 0.783`), що природно знижує надлишкове теплове навантаження на кристал і сповільнює деградацію елементів.
3. **Гравітаційне скидання снігу:** сухий і мокрий сніг не утримується на скляній поверхні при нахилі понад 50–55° і самостійно сповзає вниз під власною вагою за першої ж появи розсіяного світла.

> 🔧 **Навіщо це.** Мережеві дахові станції завжди монтують під кутом 30–35°, щоб зібрати якомога більше кіловат-годин у липні й продати їх у мережу. Якщо скопіювати цей даховий кут для віддаленого метеопоста чи камери спостереження, у січні панель опиниться під шапкою мокрого снігу, промені низького сонця відіб'ються від скла під кутом 45°, акумулятор розрядиться до нуля, замерзне і лусне корпус.

## Забруднення поверхні (Soiling): пил, птахи та геометрія самоочищення

Після кількох місяців у полі дзеркально чиста поверхня загартованого скла вкривається сумішшю атмосферного пилу, пилку рослин, сажі, аерозолів добрив та пташиного посліду. Цей процес називають сойлінгом (англ. soiling — «забруднення, засолювання»).

Рівномірний шар сухого польового пилу послаблює світловий потік за рахунок двох фізичних механізмів: поглинання фотонів непрозорими частинками та зворотного дифузного відбиття на межі скло-пил-повітря. При поверхневій щільності пилу 2–5 г/м² генерація моно- та полікристалічних модулів падає на 8–15%, а в сухі періоди без дощів — до 25%.

Однак набагато більшу небезпеку становить нерівномірне забруднення, яке концентрується на нижньому краю модуля.

Стандартна сонячна панель має алюмінієву рамку з виступаючим захисним бортиком заввишки 2–4 мм над рівнем фронтального скла. Коли під час дрібного дощу або випадання ранкової роси вода стікає склом униз, вона впирається в цей нижній бортик. Через явище капілярності (лат. capillaris — «волосяний», від capillus — «волосся») та силу поверхневого натягу вода не може перевалити через металевий край і утворює застійну калюжу вздовж усієї нижньої кромки.

![Забруднення нижньої кромки рами та утворення мулового бар'єра («mud lip»), що затінює нижній ряд фотоелементів, і дренажна кліпса для вільного капілярного скидання води.](/root/hw/hw-power/montazh-paneli-v-poli/img/soiling-mud-lip.svg)
*Формування мулового валика на нижній кромці рами. Ліворуч: поверхневий натяг утримує брудну воду, створюючи смугу непрозорого осаду над фотоелементами. Праворуч: дренажна кліпса відводить вологу сифонним шляхом.*

Коли волога випаровується, увесь змитий із верхньої частини панелі пил осідає у вигляді вузької, але абсолютно непрозорої смуги мулу завширшки 15–30 мм («муловий валик» або англ. mud lip).

Ця брудна смуга перекриває нижній край першого ряду фотоелементів. Оскільки всі елементи в підрядку з'єднані послідовно, перекриття навіть 10% площі хоча б однієї комірки обмежує струм усього ланцюга до мінімального значення.

Для запобігання утворенню мулових валиків застосовують два заходи:
1. **Мінімальний кут самоочищення:** кут нахилу модуля має бути не меншим за 15° (для автономних систем кут 55–65° забезпечує швидкий та турбулентний стік дощової води, що змиває частинки пилу розміром понад 5 мкм).
2. **Дренажні кліпси (Water Drain Clips):** спеціальні пружні пластикові або гідрофільні кліпси, які надягають на нижній бортик рами в місцях скупчення води. Кліпса створює вузький капілярний канал, що перекидає меніск води через металевий виступ рами, запускаючи сифонний ефект (грец. síphōn — «трубка, насос»). Уся накопичена брудна вода повністю стікає за край рами, не залишаючи осаду на склі.

Пташиний послід (гуано) створює локальні ізольовані непрозорі плями високої щільності. На відміну від мінерального пилу, органічні кислоти в складі гуано при нагріванні на сонці понад 70 °C вступають у хімічну реакцію з антибліковим покриттям скла (пористий діоксид кремнію `SiO2`), спричиняючи його незворотне помутніння та локальне травлення.

## Затінення та гарячі точки (Hot Spots) у польових умовах

Коли один або кілька фотоелементів повністю або частково перекриваються непрозорою перешкодою (пташиний послід, сухе листя, сніговий замет, що застряг знизу, або стебло польового бур'яну), електричний режим роботи послідовного ланцюга зазнає катастрофічних змін.

Освітлений фотоелемент під дією сонячних квантів генерує фотострум `I_ph` близько 9–11 А при напрузі прямого зміщення `V_cell ≈ 0.55–0.60 В`. Затінений елемент не генерує вільних носіїв заряду і перетворюється на звичайний напівпровідниковий p-n перехід, зміщений у зворотному напрямку.

Решта 19 або 23 послідовно з'єднаних освітлених комірок підрядка продовжують генерувати струм 9 А. Цей струм не може зникнути — закони Кірхгофа вимагають неперервності струму в послідовній гілці. Освітлені сусіди починають підвищувати напругу на затіненому елементі, зміщуючи його у зворотний бік («проти шерсті») аж до напруги лавинного або тунельного пробою:

```
струм ланцюга I_string         ≈ 9 А
зворотна напруга на комірці V  ≈ 12–15 В
теплова потужність P_hotspot   = I · V = 9 · 14 ≈ 126 Вт
```

Понад 120 Вт тепла виділяються на площі кремнієвої пластинки розміром усього 156×156 мм (товщина кристала 160–180 мкм). Температура в точці перегріву стрімко підіймається до 140–180 °C. Це явище називають гарячою точкою (англ. hot spot).

Наслідки виникнення тривалої гарячої точки:
- **Термічна деградація інкапсулянту:** плавиться та обвуглюється оптична плівка з етиленвінілацетату (EVA), утворюючи коричневі газові бульбашки;
- **Деламінація** (лат. de- — «від-» + lamina — «пластина, шар»): відшарування захисної полімерної підкладки (backsheet на основі Tedlar/PET) з втратою герметичності модуля;
- **Термомеханічні мікротріщини:** через локальний температурний градієнт крихкий кремній розтріскується, назавжди ізолюючи частини кристала від струмознімних срібних шин (busbars);
- **Пожежна небезпека:** спалахування горючих полімерних шарів панелі або сухої трави та дерев'яних конструкцій під нею.

Для захисту від руйнування гарячими точками застосовують [байпасні діоди сонячної панелі](root:hw-power/panel-bypass-diode). Стандартний модуль ділять на 3 паралельні секції (підрядки), кожну з яких шунтують антипаралельним діодом Шотткі (зазвичай на 15 А, 45 В), розміщеним у задній розподільній коробці (англ. Junction Box, J-Box).

Коли напруга на затіненому підрядку падає нижче -0.4 В, байпасний діод відкривається і перехоплює струм 9 А на себе, обмежуючи зворотну напругу на хворій секції. На самому діоді розсіюється лише `P_diode = 9 А · 0.4 В = 3.6 Вт`, що безпечно розсіюється корпусом коробки.

Однак байпасні діоди не лікують причину затінення, а лише захищають модуль від загоряння ціною вимикання третини панелі. Якщо тінь від трави падає вздовж нижнього краю вертикально змонтованої панелі (портретна орієнтація), вона перетинає всі три вертикальні підрядки одночасно. Усі три байпасні діоди відкриваються, і генерація модуля падає до абсолютного нуля.

> 🔧 **Навіщо це.** Якщо польовий модуль монтується на невисокій стійці над землею (0.5–1 м), рослинність за літо виростає і затінює нижній край. При портретній орієнтації трава вимикає панель повністю. При ландшафтній (горизонтальній) орієнтації, де підрядки витягнуті горизонтально, трава накриває лише один нижній підрядок — діод шунтує його, а верхні два підрядки продовжують стабільно видавати 66% номінальної потужності.

## Механічна стійкість: вітровий тиск, сніг і стандарт IEC 61215

Польовий монтаж перетворює сонячну панель площею 1–2 м² на вітрило, закріплене на верхівці щогли чи каркаса. Вітровий потік створює на площині модуля значні знакозмінні сили.

Аеродинамічний тиск повітряного потоку `q` (Па) описується рівнянням Бернуллі:

```
q = 0.5 · ρ_air · v²
```

де `ρ_air` — густина повітря (при 0 °C на рівні моря `ρ_air ≈ 1.29 кг/м³`), а `v` — швидкість вітру в м/с.

При штормовому вітрі зі швидкістю 35 м/с (126 км/год) динамічний тиск на поверхню сягає:

```
q = 0.5 · 1.29 · 35² = 0.5 · 1.29 · 1225 ≈ 790 Па
```

З урахуванням коефіцієнта аеродинамічного опору похилої пластини `C_d ≈ 1.2–1.4` та локальних пульсацій тиск на фронтальну площу модуля становить понад 1000–1100 Па.

Міжнародний стандарт **IEC 61215** («Design qualification and type approval for terrestrial photovoltaic modules») встановлює суворі вимоги до механічної міцності панелей:
1. **Фронтальне статичне навантаження (Front static load):** модуль повинен витримувати тиск **5400 Па** (еквівалент шару мокрого снігу товщиною до 50–60 см або вітру швидкістю понад 200 км/год).
2. **Тильне вітрове розрідження (Rear wind load / Uplift suction):** модуль повинен витримувати зусилля на відрив **2400 Па** (виникає, коли вітер дме в спину панелі або створює зону низького тиску через завихрення за верхньою кромкою).

![Механічні навантаження за стандартом IEC 61215: притискний тиск снігу та вітру з деформацією кремнію вниз проти підйомного вітрового відриву та флатеру кріплень.](/root/hw/hw-power/montazh-paneli-v-poli/img/wind-load-mechanics.svg)
*Силове навантаження на модуль. Ліворуч: фронтальний тиск снігу й вітру прогинає скло вниз. Праворуч: вітрове розрідження намагається відірвати модуль від напрямних рейок.*

Головна небезпека вітру криється не в статичному зламі алюмінієвої рами, а в динамічних коливаннях — явищі аеропружного флатеру (англ. flutter — «тріпотіння, махання крилами»).

Під час поривів вітру скло панелі зазнає циклічних пружних прогинів із розмахом у кілька міліметрів. Товщина кремнієвої пластинки становить усього 160–180 мкм. Кремній є надзвичайно крихким монокристалічним матеріалом (модуль Юнга `E ≈ 130–170 ГПа`). Коли скло прогинається, у товщі кремнію виникають розтягуючі механічні напруження, які перевищують межу міцності.

Утворюються невидимі неозброєним оком **мікротріщини** (англ. microcracks). Під час оптичного огляду панель здається цілою, але під люмінесцентним або електролюмінесцентним контролем видно мережу розривів кристала.

З часом під дією циклічних перепадів денної та нічної температур мікротріщини розширюються. Окремі острівці фотоелемента повністю відриваються від струмознімних контактних доріжок. Струм модуля падає, виникають незворотні локальні гарячі точки, а деградація потужності панелі прискорюється з нормальних 0.5% на рік до 5–10% на рік.

Правила монтажу для запобігання мікротріщинам:
- Панель повинна спиратися на дві паралельні несучі рейки суворо в зонах, визначених паспортом виробника (зазвичай на відстані 1/4 та 3/4 довжини модуля від країв — точки нульового згинального моменту);
- Забороняється кріпити модуль лише за кути або свердлити додаткові отвори в алюмінієвій рамі — це концентратори механічних напружень;
- Кріпильні притискачі (клемпи) повинні затягуватися динамометричним ключем із моментом 12–15 Н·м. Недотягнутий притискач дозволяє рамі вібрувати, перетираючи метал, а перетягнутий — деформує раму і передає стискаюче зусилля безпосередньо на край гартованого скла.

## Стійкість до граду та мікротріщини в кремнії

Град становить пряму загрозу механічної руйнації фотомодуля. За стандартом **IEC 61215** сонячні модулі проходять обов'язковий тест на стійкість до граду (Hail Impact Test).

Умови випробування:
- Пневматична гармата стріляє сферичною крижаною кулею діаметром `d = 25 мм`;
- Маса льодового снаряда становить `m ≈ 7.53 г`;
- Швидкість зіткнення `v = 23.0 м/с` (82.8 км/год);
- Кінетична енергія удару:
```
E_k = 0.5 · m · v² = 0.5 · 0.00753 · 23² ≈ 1.99 Дж
```
- Стрільба ведеться по 11 різних критичних точках панелі: по центру, по кутах, біля краю рами та безпосередньо над електричними з'єднаннями шин.

Модуль вважається таким, що пройшов тест, якщо на склі немає тріщин, збережена герметичність, опір ізоляції у вологому стані перевищує 400 МОм·м², а втрата потужності після тесту не перевищує 5%.

Лицьова поверхня якісного модуля захищена спеціальним загартованим термозміцненим склом товщиною 3.2 мм або 4.0 мм з низьким вмістом заліза (Low-Iron Tempered Glass).

Загартування створює у поверхневих шарах скла постійні напруження стиску (понад 90–120 МПа), тоді як внутрішній шар перебуває під напруженням розтягу. Таке скло витримує удари граду в 4–6 разів міцніше за звичайне віконне скло аналогічної товщини.

Однак при ударі надвеликого граду (діаметром 40–50 мм із кінетичною енергією понад 15–20 Дж) гартоване скло миттєво розпадається на мільйони дрібних безпечних гранул без гострих лез («павутинка»). Хоча панель може зберігати механічну форму завдяки шарам EVA-плівки, волога та кисень повітря негайно проникають до кремнію. Протягом 2–4 тижнів срібні та алюмінієві контакти на фотоелементах окиснюються, а корозія знищує модуль.

Крутий кут нахилу автономного модуля (55–65°) захищає і від граду: град падає вертикально вниз або під невеликим кутом до вертикалі. Удар по похилому склу відбувається під косим кутом (ковзний удар), тому нормальна складова імпульсу зменшується за синусом кута нахилу:

```
E_normal = E_k · cos²(β)
```

При нахилі `β = 60°` коефіцієнт `cos²(60°) = 0.5² = 0.25`, тобто ударне навантаження на скло зменшується вчетверо порівняно з горизонтальним дахом.

## Гальванічна пара алюміній-сталь та електричне заземлення рами

Конструкція сонячного кріплення об'єднує різні метали: раму панелі виготовляють з алюмінієвого сплаву, монтажні рейки — з алюмінію або оцинкованої сталі, кріпильні болти — з нержавіючої або вуглецевої сталі, а щоглу — з чорної або гарячеоцинкованої сталевої труби.

Коли два метали з різними стандартними електродними потенціалами мають прямий електричний контакт і омиваються електролітом (дощова вода з розчиненими солями, вуглекислим газом або сажею), виникає **гальванічна корозія** (названа на честь італійського анатома і фізика Луїджі Гальвані, італ. Galvani).

| Метал / Сплав | Електродний потенціал відносно водневого електрода | Роль у гальванічній парі |
|---|---|---|
| Магній (Mg) | -2.37 В | Активний анод (руйнується) |
| Алюміній (Al 6063) | -1.66 В | Активний анод при контакті зі сталлю |
| Цинк (Zn) | -0.76 В | Жертовний анод для заліза |
| Вуглецева сталь (Fe) | -0.44 В | Катод відносно алюмінію та цинку |
| Нержавіюча сталь (AISI 304) | -0.08 В ... +0.10 В (пасивна) | Благородний катод |
| Мідь (Cu) | +0.34 В | Сильний катод (катастрофічний для Al) |

Різниця потенціалів між алюмінієм рами (-1.66 В) та вуглецевою сталлю щогли (-0.44 В) становить `ΔE = 1.22 В`.

При безпосередньому скручуванні алюмінієвої рами сталевим чорним болтом алюміній стає анодом і починає стрімко розчинятися:

```
Al → Al³⁺ + 3e⁻   [окиснення анода — руйнування рами]
```

За 1–2 польові сезони отвори в алюмінієвій рамі роз'їдаються до стану крихкого порошку гідроксиду алюмінію, болти послаблюються, і вітер зриває модуль з опори. Ще катастрофічнішим є прямий контакт алюмінієвої рами з мідним заземлювальним дротом (`ΔE = 2.0 В`).

Правила електрохімічної сумісності польового монтажу:
1. **Використання нержавіючої сталі A2-70 (AISI 304) або A4-70 (AISI 316):** болти, гайки та шайби кріплення мають бути суворо нержавіючими;
2. **Розв'язка різнорідних металів:** між оцинкованою сталлю щогли та алюмінієвим кронштейном обов'язково встановлюють діелектричні ізоляційні шайби або прокладки з EPDM-гуми (етилен-пропіленовий каучук) чи поліаміду;
3. **Заборона прямого контакту міді з алюмінієм:** заземлювальний мідний дріт приєднують до алюмінієвої рами виключно через біметалеві луджені наконечники або спеціальні затискачі з нержавіючої сталі.

Окремою проблемою є [захисне заземлення](root:hw-power/protective-grounding) алюмінієвого каркаса.

Поверхня рами панелі покрита шаром штучного анодування (оксидна плівка `Al2O3` товщиною 15–25 мкм). Оксид алюмінію — це корунд, діелектрик із питомим опором понад `10¹⁴ Ом·м`. Якщо просто затиснути болт на рамі, електричного контакту не буде — тестер покаже нескінченний опір.

Для створення надійного електричного зв'язку між рамою модуля та металоконструкцією застосовують спеціальні заземлювальні шайби з гострими зубами — шайби **WEEB** (Washer, Electrical Equipment Bonding).

Шайба WEEB виготовляється з пружинної нержавіючої сталі. Під час затягування клемпи її загартовані зуби протикають діелектричний шар `Al2O3` на рамі панелі та на монтажній рейці, врізаючись у чистий метал. Це забезпечує надійний газонепроникний перехідний контакт з опором менше 0.005 Ом, здатний безпечно відвести на контур заземлення струми грозових наведень величиною в десятки кілоампер. Детальний перелік монтажної фурнітури наведено у вставці [довідник польової монтажної фурнітури та кабельних вузлів](root:hw-power/montazh-paneli-v-poli/comp-solar-mounting-hardware.md).

## Кабельна проводка в полі: УФ-деградація, капельні петлі та зуби гризунів

Електрична проводка в полі зазнає одночасного впливу жорсткого сонячного ультрафіолету, циклів заморожування/розмерзання вологи, вібрації та атак диких тварин.

### Ультрафіолетова деградація ізоляції

Звичайні побутові та промислові кабелі з ізоляцією з полівінілхлориду (ПВХ, PVC) або звичайного поліетилену (PE) категорично непридатні для відкритого сонячного монтажу.

Кванти ультрафіолетового спектра UV-A та UV-B мають енергію 3.1–4.1 еВ, що перевищує енергію ковалентних зв'язків `C-C` (3.6 еВ) та `C-H` (4.3 еВ) у полімерних ланцюгах. Відбувається фотоокиснювальна деструкція: вимиваються рідкі пластифікатори, полімер стає крихким, і через 12–18 місяців ізоляція кабелю осипається шматками від найменшого подиху вітру, оголюючи мідні жили під робочою напругою.

Для з'єднання сонячних модулів застосовують виключно спеціалізований сонячний кабель за стандартом **EN 50618** (маркування **H1Z2Z2-K** або **PV1-F**):
- **Струмопровідна жила:** багатодротова гнучка луджена мідь (олово захищає мідь від корозії при потраплянні вологи);
- **Ізоляція та зовнішня оболонка:** двошаровий зшитий безгалогенний поліолефін (XLPO / XLPE — Cross-linked Polyethylene);
- **Стійкість:** розрахований на 25 років безперервного прямого сонячного опромінення, температуру від -40 °C до +90 °C (короткочасно до +120 °C) та стійкий до впливу озону й гідролізу.

### Капельні петлі (Drip Loops) та гермовводи

Вода завжди знаходить шлях уздовж кабелю. Якщо кабель від панелі заходить у корпус апаратної коробки (гермобокса) прямо або з нахилом донизу, дощові краплі та конденсат під дією сили тяжіння стікають по оболонці прямісінько в ущільнювач гермовводу (cable gland). Навіть гермоввід із рейтингом IP67 під постійним стовпом води та перепадами внутрішнього тиску (через денне нагрівання й нічне охолодження повітря в боксі) врешті-решт всмоктує вологу всередину.

![Кабельний ввід польової установки: організація капельної петлі, гермоввід IP68, нержавіючий захисний металорукав від гризунів і заземлення рами через WEEB-шайбу.](/root/hw/hw-power/montazh-paneli-v-poli/img/cable-protection-drip-loop.svg)
*Правильна організація кабельного введення. Капельна петля гарантує скидання води в найнижчій точці до того, як кабель підніметься до гермовводу, а металорукав блокує зуби тварин.*

Для захисту від затікання води обов'язково формують **капельну петлю** (англ. drip loop). Кабель виводять нижче рівня кабельного вводу на 100–150 мм, формують плавне U-подібне провисання, і лише після цього заводять у гермоввід знизу вгору. Вода, стікаючи кабелем, досягає нижньої точки дуги і безперешкодно капає на землю.

### Захист від тварин і гризунів

У польових умовах відкриті кабелі стають мішенню для мишей-полівок, щурів, зайців, куниць та птахів.

Гризуни мають різці, які безперервно ростуть протягом усього життя (до 10–12 см на рік). Щоб сточувати зуби, тварина інстинктивно гризе будь-які пружні полімерні предмети. М'яка ізоляція сонячного кабелю перекушується полівкою за лічені хвилини.

Птахи (сороки, ворони) використовують пластикові кабельні стяжки та дріт для будування гнізд, розкльовуючи ізоляцію в пошуках комах або блискучих мідних ниток.

Заходи захисту кабельних трас:
1. **Металорукав з нержавіючої сталі AISI 304 або оцинкованої сталі в ПВХ-покритті:** уся вільна кабельна траса від розподільної коробки панелі до вводу в гермобокс обов'язково затягується в гнучкий металорукав зі спеціальними латунними або нержавіючими різьбовими муфтами;
2. **Нержавіючі стяжки замість пластикових:** фіксацію рукавів і кабелів до металоконструкцій виконують стяжками з нержавіючої сталі з кульковим замком. Білі та навіть чорні пластикові нейлонові стяжки в полі розтріскуються від УФ-випромінювання або перетираються вітром за 1–2 роки;
3. **Захисні металеві сітки проти птахів:** простір під панеллю закривають сіткою з нержавіючої сталі з вічком 10–12 мм, що блокує доступ птахів до з'єднувальних коробок MC4.

## Програмний розрахунок робочої точки польового модуля

Для автономного контролера живлення на мікроконтролері важливо точно прогнозувати доступну сонячну потужність з урахуванням температури, бруду та кута падіння променів.

Повна вихідна електрична потужність модуля в польових умовах `P_out` розраховується за формулою:

```
P_out = P_stc · (G_tilt / 1000) · [1 + (γ_Pmp / 100) · (T_cell - 25)] · (1 - k_soiling)
```

де:
- `P_stc` — паспортна номінальна потужність панелі за стандартних умов (STC, 1000 Вт/м², 25 °C);
- `G_tilt` — розрахована інсоляція на похилу площину (Вт/м²);
- `γ_Pmp` — температурний коефіцієнт максимальної потужності (%/°C, для кремнію зазвичай від -0.35 до -0.42 %/°C, детально розглянутий у темі [температурні коефіцієнти сонячної панелі](root:hw-power/panel-temperature-coeff));
- `T_cell` — реальна робоча температура кристала, що залежить від температури навколишнього повітря `T_amb` та коефіцієнта NOCT (Normal Operating Cell Temperature, типово 45 °C):
```
T_cell = T_amb + G_tilt · ((NOCT - 20) / 800)
```
- `k_soiling` — емпіричний коефіцієнт втрат від забруднення скла (0.03–0.05 для чистого омитого дощем модуля, 0.15–0.25 для запиленого в посушливий сезон).

```c
#include <math.h>

typedef struct {
    double p_stc_w;         /* Номінальна потужність панелі за STC (Вт) */
    double gamma_pmp;       /* Температурний коефіцієнт потужності (%/°C, наприклад -0.38) */
    double noct_c;          /* Нормальна робоча температура комірки (°C, типово 45.0) */
    double soiling_factor;  /* Частка втрат від забруднення (наприклад 0.05 = 5%) */
} SolarFieldPanel;

/* Розрахунок реальної потужності сонячної панелі у польових умовах */
double calculate_field_power(const SolarFieldPanel *panel, double g_tilt_w_m2, double t_ambient_c) {
    if (g_tilt_w_m2 <= 0.0) {
        return 0.0;
    }

    /* 1. Розрахунок робочої температури кремнієвого фотоелемента */
    double t_cell = t_ambient_c + g_tilt_w_m2 * ((panel->noct_c - 20.0) / 800.0);

    /* 2. Температурна деградація потужності */
    double temp_correction = 1.0 + (panel->gamma_pmp / 100.0) * (t_cell - 25.0);
    if (temp_correction < 0.1) {
        temp_correction = 0.1; /* Захист від від'ємних значень при екстремальному нагріві */
    }

    /* 3. Корекція на оптичні втрати від пилу та бруду */
    double soiling_correction = 1.0 - panel->soiling_factor;
    if (soiling_correction < 0.0) {
        soiling_correction = 0.0;
    }

    /* 4. Фінальна електрична потужність */
    double p_out = panel->p_stc_w * (g_tilt_w_m2 / 1000.0) * temp_correction * soiling_correction;
    return p_out > 0.0 ? p_out : 0.0;
}
```

```cpp
#include <algorithm>

struct SolarFieldPanel {
    double p_stc_w{100.0};       // Номінальна потужність за STC (Вт)
    double gamma_pmp{-0.38};      // Температурний коефіцієнт потужності (%/°C)
    double noct_c{45.0};          // Робоча температура комірки NOCT (°C)
    double soiling_factor{0.05};  // Коефіцієнт втрат від бруду (5%)
};

// Розрахунок реальної польової потужності модуля
[[nodiscard]] constexpr double calculate_field_power(
    const SolarFieldPanel& panel,
    double g_tilt_w_m2,
    double t_ambient_c) noexcept 
{
    if (g_tilt_w_m2 <= 0.0) {
        return 0.0;
    }

    // 1. Оцінка робочої температури кристала
    const double t_cell = t_ambient_c + g_tilt_w_m2 * ((panel.noct_c - 20.0) / 800.0);

    // 2. Вплив температури кристала на вихідну потужність
    const double temp_correction = std::max(0.1, 1.0 + (panel.gamma_pmp / 100.0) * (t_cell - 25.0));

    // 3. Вплив забруднення скла
    const double soiling_correction = std::max(0.0, 1.0 - panel.soiling_factor);

    // 4. Реальна вихідна потужність
    const double p_out = panel.p_stc_w * (g_tilt_w_m2 / 1000.0) * temp_correction * soiling_correction;
    return std::max(0.0, p_out);
}
```

## Підсумок монтажних вимог для польової автономності

Надійна цілорічна робота автономної сонячної установки вимагає суворого дотримання інженерного чек-листа:
1. **Кут нахилу:** встановлювати на `широту + 15°..20°` (55°–65° для України) для ліквідації зимового провалу та сходу снігу;
2. **Орієнтація модулів:** монтувати панелі в ландшафтній (горизонтальній) орієнтації для мінімізації втрат від затінення травою та муловими валиками;
3. **Дренаж:** використовувати капілярні дренажні кліпси на нижній кромці рами для запобігання сойлінгу;
4. **Механіка:** фіксувати панель у 4 штатних точках на алюмінієвих рейках із моментом затяжки 12–15 Н·м за стандартом IEC 61215;
5. **Гальванічна розв'язка:** застосовувати виключно нержавіючі кріплення A2/A4 та ізолюючі прокладки між алюмінієм і сталлю;
6. **Заземлення:** використовувати зубчасті шайби WEEB для проколювання анодованого діелектричного шару рами;
7. **Проводка:** прокладати сонячний кабель H1Z2Z2-K у нержавіючому металорукаві з формуванням обов'язкової капельної петлі перед гермовводом IP68.
