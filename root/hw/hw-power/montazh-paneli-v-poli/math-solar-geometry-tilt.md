# 🧮 Геометрія сонячної інсоляції та кут нахилу панелі

Цей розрахунок дає повну математичну модель визначення оптимального кута нахилу сонячної панелі для автономної системи живлення через сферичну тригонометрію руху сонця небосхилом протягом року. Без точного розрахунку положення сонця автономний вузол у зимовий період стикається з критичним браком енергії, що призводить до глибокого розряду акумулятора та виходу системи з ладу.

## Сонячні кути та схилення

Положення Сонця на небесній сфері для точки земної поверхні з географічною широтою `φ` (позитивна для північної півкулі, негативна для південної) описується двома кутовими координатами: висотою Сонця над горизонтом `h` (або зенітним кутом `θ_z = 90° - h`) та сонячним азимутом `γ_s`.

Кут сонячного схилення `δ` (кут між вектором напрямку на Сонце та площиною земного екватора) неперервно змінюється через орбітальний рух Землі та фіксований нахил осі обертання Землі на 23.44° до нормалі площини екліптики. Для порядкового дня року `n` (від 1 для 1 січня до 365 для 31 грудня) схилення `δ` (у градусах) обчислюється за уточненою апроксимацією Спенсера або стандартною формулою Купера:

```
δ = 23.45° · sin(360° · (284 + n) / 365)
```

Характерні точки року для кута схилення:
- Літнє сонцестояння (`n = 172`, 21 червня): `δ = +23.45°` (максимальний нахил північного полюса до Сонця);
- Зимове сонцестояння (`n = 355`, 21 грудня): `δ = -23.45°` (максимальне відхилення від Сонця);
- Весняне та осіннє рівнодення (`n = 80` і `n = 264`): `δ = 0.00°` (Сонце стоїть у зеніті над екватором).

Висота Сонця над горизонтом `h` у будь-яку мить доби визначається через широту місцевості `φ`, схилення `δ` та годинний кут `ω`:

```
sin(h) = sin(φ) · sin(δ) + cos(φ) · cos(δ) · cos(ω)
```

Годинний кут `ω` відображає добове обертання Землі зі швидкістю 15° за одну годину часу (`360° / 24 год = 15°/год`). За точку відліку приймається істинний сонячний полудень (`ω = 0°` у момент кульмінації Сонця на географічному півдні), ранкові значення від'ємні, вечірні — додатні (`ω = (t_solar - 12) · 15°`).

У момент сонячного полудня (`ω = 0°`, отже `cos(ω) = 1`):

```
sin(h_noon)
= sin(φ) · sin(δ) + cos(φ) · cos(δ)       [основна тригонометрична тотожність: sin·sin + cos·cos]
= cos(φ - δ)                              [косинус різниці кутів]
= sin(90° - (φ - δ))                      [формула зведення тригонометричних функцій]
```

Звідси отримуємо лінійне рівняння для полуденної висоти Сонця:

```
h_noon = 90° - φ + δ
```

Для помірних широт (наприклад, широта Києва `φ = 50.45°`):

```
h_summer = 90° - 50.45° + 23.45° = 63.00°  [літнє сонцестояння: висока траєкторія]
h_equinox = 90° - 50.45° + 0.00° = 39.55°  [рівнодення: середня траєкторія]
h_winter = 90° - 50.45° - 23.45° = 16.10°  [зимове сонцестояння: низьке ковзання над горизонтом]
```

## Тривалість сонячного дня

Момент сходу та заходу Сонця відповідає умові `h = 0°` (`sin(h) = 0`). Підставляючи це у рівняння висоти, знаходимо кут заходу Сонця `ω_s`:

```
0 = sin(φ) · sin(δ) + cos(φ) · cos(δ) · cos(ω_s)
cos(ω_s) = -tan(φ) · tan(δ)
```

Тривалість світлового дня `T_day` (у годинах) визначається інтегруванням годинного кута від сходу до заходу:

```
T_day = (2 / 15°) · arccos(-tan(φ) · tan(δ))
```

Для широти `φ = 50.45°`:
- У червні: `tan(50.45°) · tan(23.45°) = 1.211 · 0.4338 = 0.5253`, звідки `ω_s = arccos(-0.5253) = 121.7°`, а `T_day = (2 · 121.7) / 15 = 16.23 години` (16 год 14 хв);
- У грудні: `tan(50.45°) · tan(-23.45°) = -0.5253`, звідки `ω_s = arccos(+0.5253) = 58.3°`, а `T_day = (2 · 58.3) / 15 = 7.77 години` (7 год 46 хв).

Зимовий день не лише удвічі коротший за літній, але й середня висота Сонця протягом дня утричі нижча.

## Кут падіння променів на похилу площину модуля

Нехай сонячна панель встановлена з кутом нахилу `β` до горизонту та розгорнута за азимутом `γ_m` (для модуля, орієнтованого суворо на південь, `γ_m = 0°`).

Кут падіння прямих сонячних променів `θ_inc` на площину модуля для довільного часу доби визначається співвідношенням сферичної геометрії:

```
cos(θ_inc)
= sin(δ) · sin(φ) · cos(β)
- sin(δ) · cos(φ) · sin(β) · cos(γ_m)
+ cos(δ) · cos(φ) · cos(β) · cos(ω)
+ cos(δ) · sin(φ) · sin(β) · cos(γ_m) · cos(ω)
+ cos(δ) · sin(β) · sin(γ_m) · sin(ω)
```

Для панелі, орієнтованої суворо на південь (`γ_m = 0°`, отже `cos(γ_m) = 1`, `sin(γ_m) = 0`), вираз спрощується:

```
cos(θ_inc)
= sin(δ) · (sin(φ) · cos(β) - cos(φ) · sin(β)) + cos(δ) · cos(ω) · (cos(φ) · cos(β) + sin(φ) · sin(β))
= sin(δ) · sin(φ - β) + cos(δ) · cos(φ - β) · cos(ω)                                                     [тригонометричні формули різниці]
```

У полудень (`ω = 0°`, `cos(ω) = 1`):

```
cos(θ_inc_noon)
= sin(δ) · sin(φ - β) + cos(δ) · cos(φ - β)
= cos((φ - β) - δ)                           [косинус різниці кутів]
= cos(|φ - β - δ|)
```

Звідси полуденний кут падіння променів дорівнює:

```
θ_inc = |φ - β - δ|
```

Коли промені падають перпендикулярно до скла (`θ_inc = 0°`), косинус кута дорівнює 1, і модуль перехоплює максимальну густину випромінювання. При відхиленні кута ефективна оптична апертура панелі зменшується за косинусним законом Ламберта:

```
A_eff = A_panel · cos(θ_inc)
```

## Модель сонячної радіації на похилу площину (Лю-Джордан)

Повна сонячна інсоляція на похилу поверхню `G_tilt` (Вт/м²) складається з трьох компонентів: прямої радіації `G_dir_tilt`, розсіяної (дифузної) атмосферою радіації `G_dif_tilt` та відбитої від землі радіації `G_alb_tilt` (ізотропна модель Лю-Джордана):

```
G_tilt
= G_dir_tilt + G_dif_tilt + G_alb_tilt                                             [сума компонентів: пряма + розсіяна + відбита]
= G_dir · cos(θ_inc) + G_dif · ((1 + cos β) / 2) + G_glo · ρ_alb · ((1 - cos β) / 2) [модель Лю-Джордана: проєкція та коефіцієнти огляду]
```

де:
- `G_dir` — пряма нормальна радіація (DNI, Direct Normal Irradiance, Вт/м²);
- `G_dif` — розсіяна радіація на горизонтальну поверхню (DHI, Diffuse Horizontal Irradiance, Вт/м²);
- `G_glo = G_dir · sin(h) + G_dif` — сумарна глобальна радіація на горизонталь (GHI);
- `ρ_alb` — коефіцієнт відбиття навколишньої поверхні (альбедо: ґрунт/трава ≈ 0.20, сухий свіжий сніг ≈ 0.70–0.85);
- `(1 + cos β) / 2` — геометричний коефіцієнт огляду неба (sky view factor): для вертикальної стіни `β = 90°` він дорівнює 0.5, для горизонталі `β = 0°` — 1.0;
- `(1 - cos β) / 2` — геометричний коефіцієнт огляду поверхні землі (ground view factor): визначає частку відбитого від землі світла, яку бачить нахилена площина.

## Покроковий розрахунок: мережевий оптимум проти автономного

Порівняємо два інженерні підходи до вибору кута нахилу `β` для автономного об'єкта на широті `φ = 50°` під час зимового сонцестояння (`δ = -23.45°`).

Умови зимового сонячного полудня:
- Висота Сонця: `h_winter = 90° - 50° - 23.45° = 16.55°`, `sin(16.55°) ≈ 0.2849`;
- Пряма сонячна радіація: `G_dir = 700 Вт/м²`;
- Дифузна радіація: `G_dif = 120 Вт/м²`;
- Альбедо засніженого поля: `ρ_alb = 0.70`;
- Глобальна горизонтальна радіація: `G_glo = 700 · 0.2849 + 120 = 199.4 + 120 = 319.4 Вт/м²`.

### Варіант А: Мережевий кут літнього максимуму (`β = φ - 10° = 40°`)

Обчислюємо кут падіння та три складові інсоляції:

```
θ_inc = |50° - 40° - (-23.45°)| = |10° + 23.45°| = 33.45°
cos(θ_inc) = cos(33.45°) ≈ 0.8344

G_dir_tilt = 700 · 0.8344 ≈ 584.1 Вт/м²
G_dif_tilt = 120 · ((1 + cos 40°) / 2) = 120 · ((1 + 0.7660) / 2) = 120 · 0.8830 ≈ 106.0 Вт/м²
G_alb_tilt = 319.4 · 0.70 · ((1 - cos 40°) / 2) = 223.58 · ((1 - 0.7660) / 2) = 223.58 · 0.1170 ≈ 26.2 Вт/м²

G_tilt_40 = 584.1 + 106.0 + 26.2 = 716.3 Вт/м²
```

### Варіант Б: Автономний кут зимової оптимізації (`β = φ + 15° = 65°`)

Обчислюємо кут падіння та три складові інсоляції:

```
θ_inc = |50° - 65° - (-23.45°)| = |-15° + 23.45°| = 8.45°
cos(θ_inc) = cos(8.45°) ≈ 0.9892

G_dir_tilt = 700 · 0.9892 ≈ 692.4 Вт/м²
G_dif_tilt = 120 · ((1 + cos 65°) / 2) = 120 · ((1 + 0.4226) / 2) = 120 · 0.7113 ≈ 85.4 Вт/м²
G_alb_tilt = 319.4 · 0.70 · ((1 - cos 65°) / 2) = 223.58 · ((1 - 0.4226) / 2) = 223.58 · 0.2887 ≈ 64.5 Вт/м²

G_tilt_65 = 692.4 + 85.4 + 64.5 = 842.3 Вт/м²
```

### Порівняльний аналіз результатів

При переході від кута 40° до кута 65°:
1. **Зростання прямої генерації:** пряма складова зростає з 584.1 Вт/м² до 692.4 Вт/м² (+18.5%) завдяки майже перпендикулярному падінню світла на скло (`θ_inc` лише 8.45°).
2. **Збільшення уловлювання альбедо:** частка відбитого від снігу світла зростає з 26.2 Вт/м² до 64.5 Вт/м² (+146%) через більший кут огляду засніженої землі (`(1 - cos β)/2` зростає в 2.47 раза).
3. **Сумарний приріст доступної потужності:** повна інсоляція на модуль зростає з 716.3 Вт/м² до 842.3 Вт/м² (чистий виграш +17.6%).
4. **Сніговий бар'єр:** при куті 40° сніг не сповзає і закриває модуль шаром у кілька сантиметрів, що призводить до падіння генерації практично до 0 Вт/м². При куті 65° сила тяжіння перевищує силу тертя між снігом і склом, модуль миттєво очищується, забезпечуючи розрахункові 842 Вт/м².
