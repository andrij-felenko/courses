# 🔌 Схемотехніка та розрахунок NTC-мереж температурної компенсації

Використання активного опору мідної обмотки силової котушки індуктивності (DCR-сенсинг) забезпечує повну відсутність додаткових втрат потужності в силовому тракті перетворювача. Проте головним фізичним бар'єром на шляху прецизійного вимірювання є висока температурна чутливість питомого опору міді. Без введення спеціального контуру корекції нагрівання дроселя під навантаженням призводить до фатальних спотворень сигналу струму, хибного обмеження потужності та порушення стабільності живлення навантаження. Схемотехнічним стандартом розв'язання цієї проблеми є застосування терморезисторів із негативним температурним коефіцієнтом опору (NTC) у складі спеціальних лінеаризуючих резистивних мереж.

### 1. Фізична несумісність характеристик міді та «голого» NTC-термістора

Температурна залежність електричного опору мідної обмотки в типовому діапазоні температур від 0 °C до 125 °C з високою точністю описується лінійною залежністю:

```
DCR(T) = DCR_25 · [ 1 + α_Cu · (T − 25 °C) ]
```

де:
- `DCR_25` — активний опір обмотки при базовій кімнатній температурі 25 °C;
- `α_Cu` — температурний коефіцієнт електричного опору міді (TCR), що становить `α_Cu ≈ +0.00393 / °C` (`+3930 ppm/K`).

При нагріванні силового дроселя до робочої температури 100 °C під тривалим навантаженням його опір зростає майже на третину:

```
ΔDCR / DCR_25 = 0.00393 · (100 − 25) = +0.29475   [тобто +29.5 %]
```

Якщо система керування не враховує цей нагрів, вимірювальна схема сприймає незмінний струм навантаження як такий, що зріс на 29.5 %. Це призводить до передчасного спрацьовування струмового захисту та спотворення навантажувальної прямої стабілізатора.

Напівпровідникові NTC-термістори виготовляють спіканням полікристалічних оксидів перехідних металів (марганцю, нікелю, кобальту та заліза). Електронна провідність у такій кераміці базується на активаційному механізмі стрибкової провідності електронів (hopping conduction) між іонами різної валентності. Внаслідок цього опір NTC зменшується з нагріванням за строго експоненційним законом Стейнхарта-Харта (або спрощеним рівнянням B-константи):

```
R_NTC(T) = R_NTC_25 · exp[ B · (1 / T − 1 / T_0) ]
```

де:
- `T` та `T_0` — абсолютні температури в Кельвінах (`T_0 = 298.15 К`, тобто 25 °C);
- `R_NTC_25` — номінальний опір термістора при 25 °C (найчастіше обирають номінали 10 кОм або 100 кОм);
- `B` — температурна стала чутливості керамічного напівпровідника (типово `B = 3400–4250 К`).

Температурний коефіцієнт «голого» NTC-термістора `α_NTC` визначається логарифмічною похідною:

```
α_NTC(T) = (1 / R_NTC) · (d R_NTC / dT)
         = −B / T²   [диференціювання експоненти за абсолютною температурою]
```

При температурі 25 °C (298.15 К) і типовому значенні `B = 3950 К`:

```
α_NTC(25 °C) = −3950 / (298.15)² ≈ −0.0444 / °C   [тобто −4.44 % / °C]
```

Порівняння двох коефіцієнтів демонструє фундаментальну фізичну невідповідність:
1. Опір міді зростає **лінійно** з помірною швидкістю `+0.393 % / °C`.
2. Опір «голого» NTC спадає **експоненційно** зі швидкістю `−4.44 % / °C` (більш ніж у 11 разів швидше за мідь).

Якщо підключити NTC-термістор безпосередньо у вимірювальне коло, схема зазнає катастрофічної перекомпенсації: при нагріванні вимірюваний сигнал впаде майже до нуля, повністю засліпивши контролер живлення.

### 2. Порівняння схемотехнічних топологій компенсації

Для формування спадного коефіцієнта передачі, який дзеркально повторює зростання опору міді, розроблено кілька схемотехнічних підходів:

| Топологія контуру | Склад компонентів | Діапазон лінійності | Залишкова похибка | Переваги та обмеження |
| :--- | :--- | :--- | :--- | :--- |
| **Одиночний NTC + паралельний резистор** | 1 NTC, 1 резистор | Вузький (40 °C — 80 °C) | ±3.5 % | Мінімальна кількість деталей, але помітна кривина на краях робочого інтервалу. |
| **Лінеаризований дільник (3-резисторна мережа)** | 1 NTC, 3 резистори | Широкий (25 °C — 115 °C) | ±0.8 % | Галузевий стандарт для ШІМ-контролерів VRM. Висока стабільність і низька собівартість. |
| **Містова вимірювальна схема** | 1 NTC, 5 резисторів | Дуже широкий (0 °C — 125 °C) | ±0.5 % | Прецизійна симетрія, але вимагає диференційного підсилювача з високим CMRR. |
| **Цифрова термокомпенсація (MCU / DSP)** | 1 NTC + АЦП каналу | Повний діапазон датчика | < ±0.3 % | Програмне обчислення полінома в реальному часі. Вимагає додаткових обчислювальних ресурсів. |

Найбільш поширеною в аналогових і цифро-аналогових контролерах імпульсних стабілізаторів є триелементна пасивна лінеаризована мережа.

```
+──────────────────────────────────────────────────────────────+
|              СХЕМА ЛІНЕАРИЗОВАНОЇ NTC-МЕРЕЖІ                 |
|                                                              |
|                     R_p                                      |
|             ┌───────[   ]───────┐                            |
|             │                   │                            |
|    Вхід ────┴───────[ NTC ]─────┴─────[ R_s2 ]─────► До ОУ   |
|                                                              |
|    R_net(T) = R_s2 + (R_p · R_NTC(T)) / (R_p + R_NTC(T))     |
+──────────────────────────────────────────────────────────────+
```

Паралельний резистор `R_p` виконує ключову роль: він шунтує терморезистор, обмежуючи максимальний еквівалентний опір при низьких температурах (коли `R_NTC → ∞`) та усуваючи круту нелінійність експоненти.

Послідовний резистор `R_s2` задає мінімальний базовий імпеданс ланцюга при високих температурах (коли `R_NTC → 0`).

Еквівалентний опір термомережі становить:

```
R_net(T) = R_s2 + [ R_p · R_NTC(T) ] / [ R_p + R_NTC(T) ]
```

Коефіцієнт передачі дільника напруги, включеного перед підсилювачем сигналу струму, дорівнює:

```
G_net(T) = R_bias / [ R_bias + R_net(T) ]
```

Головне математичне завдання інженерного синтезу — розрахувати номінали `R_p`, `R_s2` та `R_bias` так, щоб добуток фактичного опору міді на коефіцієнт передачі дільника залишався константою в усьому інтервалі температур експлуатації (від 25 °C до 105 °C):

```
DCR(T) · G_net(T) ≈ const = DCR_25 · G_net(25 °C)
```

### 3. Метод розрахунку номіналів за точкою перегину (Inflection Point Method)

Ефективне значення опору паралельної ланки `R_par(T) = (R_p · R_NTC(T)) / (R_p + R_NTC(T))` має класичну S-подібну сигмоїдну характеристику. Найвища лінійність досягається в околі точки перегину кривої, де друга похідна функції за температурою дорівнює нулю:

```
d² R_par(T) / dT² = 0
```

Диференціюючи вираз для `R_par(T)` з урахуванням швидкості зміни опору термістора `d R_NTC / dT = −(B / T²) · R_NTC`, отримуємо строгу аналітичну умову для центральної температури робочого діапазону `T_mid`:

```
R_p = R_NTC(T_mid) · [ (B − 2·T_mid) / (B + 2·T_mid) ]
```

Оскільки параметр чутливості `B` (близько 3900 К) набагато більший за подвоєну абсолютну температуру `2·T_mid` (близько 680 К), дріб у квадратних дужках знаходиться в межах `0.65–0.75`.

Для силових стабілізаторів живлення центральну температуру оптимізації зазвичай обирають у центрі найбільш імовірного робочого стану плати: `T_mid = 65 °C` (338.15 К).

Для знаходження номіналів `R_s2` та `R_bias` застосовують метод найменших квадратів, мінімізуючи цільову функцію відносної похибки:

```
E(R_p, R_s2, R_bias) = ∑ [ (DCR(T_k) · G_net(T_k)) / (DCR(25 °C) · G_net(25 °C)) − 1 ]² → min
```

де сумування проводиться за контрольними температурними вузлами діапазону.

### 4. Повний числовий приклад проектування контуру термокомпенсації

Проведемо покроковий інженерний розрахунок мережі компенсації для силового перетворювача з наступними вихідними параметрами:
- Дросель: `L = 150 нГн`, `DCR_25 = 0.32 мОм`
- Діапазон температур: від `T_min = 25 °C` (298.15 К) до `T_max = 105 °C` (378.15 К)
- NTC-термістор: `R_NTC_25 = 10.0 кОм`, `B = 3900 К`

**Крок 1. Розрахунок зміни опору DCR на межах температурного інтервалу:**
- При 25 °C: `DCR(25 °C) = 0.320 мОм`
- При 65 °C: `DCR(65 °C) = 0.320 · (1 + 0.00393 · 40) = 0.3703 мОм` (+15.7 %)
- При 105 °C: `DCR(105 °C) = 0.320 · (1 + 0.00393 · 80) = 0.4206 мОм` (+31.4 %)

**Крок 2. Розрахунок опору NTC при центральній температурі 65 °C (338.15 К):**

```
R_NTC(65 °C) = 10000 · exp[ 3900 · (1 / 338.15 − 1 / 298.15) ]
             = 10000 · exp[ 3900 · (−0.0003960) ]
             = 10000 · exp(−1.5444)
             = 10000 · 0.2134 = 2134 Ом
```

**Крок 3. Вибір паралельного резистора R_p:**
Використовуючи аналітичну формулу точки перегину:

```
R_p = 2134 · [ (3900 − 2·338.15) / (3900 + 2·338.15) ]
    = 2134 · [ 3223.7 / 4576.3 ]
    = 2134 · 0.7044 = 1503 Ом
```

Обираємо найближчий стандартний номінал із прецизійного ряду E96 (допуск 1 %): `R_p = 1.50 кОм`.

**Крок 4. Розрахунок послідовного резистора R_s2 та резистора зміщення:**
Для забезпечення ідеального балансу передачі в трьох ключових вузлах (25 °C, 65 °C, 105 °C) числова оптимізація дає стандартні номінали:
- `R_s2 = 4.75 кОм` (ряд E96, 1 %)
- `R_bias = 2.49 кОм` (ряд E96, 1 %)

**Крок 5. Верифікація залишкової похибки скомпенсованого вимірювання:**

| Температура | Опір DCR (мОм) | Опір NTC (Ом) | Еквівалентний R_net (Ом) | Відносний сигнал | Залишкова похибка |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **25 °C** | 0.3200 | 10000 | 6054 | 1.0000 | **0.00 %** (база) |
| **45 °C** | 0.3452 | 4367 | 5866 | 0.9942 | **−0.58 %** |
| **65 °C** | 0.3703 | 2134 | 5630 | 1.0021 | **+0.21 %** |
| **85 °C** | 0.3954 | 1130 | 5395 | 1.0084 | **+0.84 %** |
| **105 °C** | 0.4206 | 638 | 5197 | 0.9912 | **−0.88 %** |

**Результат:** вихідний тепловий розкид опору міді на `+31.4 %` після інтеграції пасивної триелементної NTC-мережі стиснуто до вузького коридору залишкової похибки менше `±0.9 %` в усьому діапазоні температур друкованої плати.

### 5. Аналіз чутливості до допусків компонентів

На підсумкову точність термокомпенсації впливає не лише форма характеристики, а й виробничий розкид параметрів дискретних компонентів:

1. **Допуск B-параметра NTC-термістора:** Недорогі термістори загального застосування мають розкид параметра `B` до ±3–5 %. Відхилення `B` на ±3 % зміщує крутизну температурної характеристики, додаючи до ±1.8 % похибки на краях робочого інтервалу. У прецизійних схемах слід застосовувати термістори з допуском `B` не гірше ±1.0 %.
2. **Точність лінеаризуючих резисторів:** Застосування резисторів ряду E24 з допуском 5 % може збільшити максимальну похибку до ±3.2 %. Використання тонкоплівкових SMD-резисторів ряду E96/E192 з допуском 0.5–1 % та температурним дрейфом TCR `< 50 ppm/K` повністю усуває цей фактор.
3. **Старіння та вологісна деградація:** Під тривалою дією високої температури (понад 1000 годин при 100 °C) опір дешевих керамічних термісторів дрейфує на 1–2 %. Для відповідальних обчислювальних плат застосовують термістори автомобільної або промислової градації (AEC-Q200) зі стабільністю краще ±0.5 %.

### 6. Теплова динаміка та правила топологічного розміщення NTC на платі

Навіть бездоганний математичний розрахунок втрачає сенс, якщо між датчиком NTC та мідною обмоткою дроселя виникає статичний або динамічний температурний градієнт.

Розглянемо еквівалентну теплову схему системи (Thermal RC Model):

```
+──────────────────────────────────────────────────────────────+
|              ТЕПЛОВА RC-МОДЕЛЬ ДРОСЕЛЯ ТА NTC                |
|                                                              |
|    Тепловиділення міді P_Cu ──┬──[ R_th_coil ]──┬── Навколишнє середовище
|                               │                 │            |
|                            [ C_th_coil ]     [ R_th_pcb ]    |
|                               │                 │            |
|                               └────────┬────────┘            |
|                                        │                     |
|                                     [ NTC ] (C_th_ntc ≪ C_th_coil)
+──────────────────────────────────────────────────────────────+
```

Головні інженерні правила фізичного проектування:

1. **Мінімальна просторова відстань:** NTC-термістор мініатюрного типорозміру (0402 або 0603) повинен встановлюватися впритул до корпусу силового дроселя (дистанція менше 1.0–1.5 мм).
2. **Прямий тепловий міст:** один із контактних майданчиків NTC або його земляний вивід підключають безпосередньо до вихідного мідного силового полігону котушки через широку доріжку без теплових розвантажень (thermal relief), забезпечуючи мінімальний тепловий опір контакт-перехід.
3. **Узгодження теплових постійних часу (Thermal Time Constant Matching):** масивна котушка індуктивності масою 3–6 грамів має значну теплоємність і нагрівається з постійною часу `τ_th ≈ 10–30 с`, тоді як мініатюрний SMD-термістор масою кілька міліграмів прогрівається за `τ_th < 1 с`. Щоб запобігти хибному перерегулюванню при коротких сплесках струму (CPU Turbo Boost), простір між NTC та дроселем заливають краплею теплопровідного компаунду.
4. **Вибір термокритичної фази в багатофазних перетворювачах:** центральні фази стабілізатора завжди нагріваються на 10–15 °C сильніше за периферійні через взаємне теплове випромінювання та конвекцію. Сенсорний термістор монтують біля центрального, найбільш навантаженого дроселя системи.

### 7. Активна цифрова термокомпенсація в сучасних контролерах

У новітніх багатофазних ШІМ-контролерах пасивну резистивну мережу доповнюють або повністю замінюють програмною цифровою обробкою:

Контролер містить окремий вхід АЦП для термодатчика (NTC або виносного термодіода), періодично опитує температуру з частотою 10–100 Гц та виконує швидкий розрахунок коефіцієнта масштабування в апаратному обчислювальному ядрі:

```
I_actual = I_raw / [ 1 + α_Cu · (T_measured − 25 °C) ]
```

Такий підхід дозволяє повністю виключити зовнішні прецизійні лінеаризуючі резистори `R_p` та `R_s2`, зменшити кількість компонентів на платі та забезпечити похибку менше ±0.3 % за рахунок точного індивідуального фабричного калібрування кожного екземпляра пристрою при випуску з виробничої лінії.

### 8. Компенсація за температурою кристала силових ключів (DrMOS Temperature Telemetry)

У високоефективних модульних силових каскадах (Smart Power Stages — SPS / DrMOS) виробники інтегрують кремнієвий термодатчик (PTAT — Proportional To Absolute Temperature) безпосередньо в кристал драйвера поруч із силовими MOSFET.

Оскільки силова котушка індуктивності припаяна безпосередньо до вихідного виводу SW модуля DrMOS через масивний мідний полігон, тепловий зв'язок між кристалом силового транзистора та обмоткою дроселя є надзвичайно тісним:

```
T_inductor ≈ T_junction_DrMOS − ΔT_thermal_drop
```

ШІМ-контролер зчитує аналогову або цифрову телеметрію температури `TMON` із кожного DrMOS-модуля по шині зв'язку (наприклад, по протоколу PMBus або спеціалізованій шині телеметрії). Це дозволяє контролеру в режимі реального часу індивідуально коригувати розрахований струм для кожної фази стабілізатора окремо, виключаючи похибки навіть при сильному локальному тепловому градієнті вздовж плати.
