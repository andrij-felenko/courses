# 🧮 Розрахунок магнітного балансу та самостабілізації напівмоста

Коли імпульсний трансформатор живиться двотактним каскадом, будь-яка асиметрія тривалості імпульсів у частки мікросекунди загрожує однобічним підмагнічуванням осердя постійним струмом (*flux walking*). У мостових чи двотактних схемах без ємнісної розв'язки це неминуче завершується залітанням у насичення та тепловим пробоєм ключів. Тут наведено точний математичний вивід симетричного перемагнічування за законом Фарадея, рівняння самовідновлення ємнісної середньої точки, розрахунок діючих струмів, втрат в осерді за Стейнмецем, аналіз ефекту близькості за рівнянням Доуелла (Dowell), параметрів індуктивності розсіювання, передавальної функції вихідного LC-фільтра, розрахунок частотної корекції контуру зворотного зв'язку Type III, розклад бюджету втрат ККД та повний наскрізний числовий розрахунок напівмостового перетворювача.

### Закон Фарадея для симетричного біполярного збудження

На відміну від однотактних схем, де напруга на первинній обмотці має лише одну полярність, напівміст прикладає до первинної котушки знакозмінні прямокутні імпульси напруги `+Vin / 2` та `−Vin / 2`.

Закон електромагнітної індукції Фарадея зв'язує миттєву напругу на обмотці `Vp(t)` зі швидкістю зміни магнітного потоку `Φ(t)` крізь площу поперечного перерізу осердя `Ae`:

```
Vp(t) = Np · (dΦ / dt)
      = Np · Ae · (dB / dt)
```

За час відкритого стану верхнього ключа `t(on)` до первинної обмотки прикладено сталу напругу `Vp = Vin / 2`. Інтегруючи рівняння за інтервал `t(on) = D · Ts`, де `D` — робоча шпаруватість кожного ключа (`D ≤ 0.5`), а `Ts = 1 / fsw` — повний період комутації:

```
ΔB = ∫ (Vp / (Np · Ae)) dt                [інтегрування за час t(on)]
   = (Vin / 2) · t(on) / (Np · Ae)        [Vp = Vin / 2 на інтервалі t(on)]
   = (Vin · D) / (2 · Np · Ae · fsw)      [підстановка t(on) = D / fsw]
```

Оскільки осердя перемагнічується симетрично від від'ємного піка `−Bpeak` до додатного піка `+Bpeak`, повний розмах магнітної індукції становить:

```
ΔB = 2 · Bpeak
```

Прирівнюючи два вирази для розмаху `ΔB`, отримуємо розрахункову формулу амплітуди магнітної індукції в осерді:

```
2 · Bpeak = (Vin · D) / (2 · Np · Ae · fsw)
Bpeak     = (Vin · D) / (4 · Np · Ae · fsw)      [поділили обидві частини на 2]
```

Звідси визначається мінімальна кількість витків первинної обмотки `Np`, яка гарантує, що індукція не перевищить гранично допустимого робочого значення `Bmax` (для силових марганець-цинкових феритів N87/PC40 типово обирають `Bmax = 0.15...0.20 Тл` на частоті 100 кГц для обмеження питомих втрат):

```
Np ≥ (Vin · Dmax) / (4 · fsw · Ae · Bmax)
```

> 🔧 **Навіщо це.** Якщо порівняти цю формулу з розрахунком однотактного прямоходового перетворювача (Forward), знаменник містить коефіцієнт `4` замість `2` або `1`. Це означає, що при однаковій напрузі, частоті й перерізі осердя напівміст потребує у 2 рази менше витків або вдвічі меншого розміру сердечника, оскільки використовує петлю гістерезису в обох напрямках.

### Рівняння вольт-секундного балансу та зміщення середньої точки

У реальній схемі комутаційні затримки затворів, час вимикання транзисторів `t(off)` та тривалості керуючих імпульсів контролера ніколи не бувають ідеально рівними. Нехай верхній ключ відкритий протягом часу `t1 = D1 · Ts`, а нижній — `t2 = D2 · Ts`, причому `t1 ≠ t2`.

Нехай потенціал середньої точки ємнісного дільника становить `Vmid`. Тоді напруга на первинній обмотці дорівнює:
- у першому напівперіоді (відкритий Q1): `Vp1 = Vin − Vmid`;
- у другому напівперіоді (відкритий Q2): `Vp2 = −Vmid`.

За один повний період магнітний потік повинен повернутися у вихідну точку, інакше магнітна індукція невпинно зростатиме з кожним тактом:

```
ΔB_період = (1 / (Np · Ae)) · [ (Vin − Vmid) · t1 − Vmid · t2 ] = 0
```

Розв'яжемо це рівняння відносно стаціонарного потенціалу середньої точки `Vmid`:

```
(Vin − Vmid) · t1 − Vmid · t2 = 0
Vin · t1 − Vmid · t1 − Vmid · t2 = 0         [розкрили дужки]
Vin · t1 = Vmid · (t1 + t2)                  [згрупували доданки з Vmid]
Vmid = Vin · [ t1 / (t1 + t2) ]              [поділили на сумарний час провідності]
```

Підставивши вирази через шпаруватості `t1 = D1 · Ts` та `t2 = D2 · Ts`:

```
Vmid = Vin · [ D1 / (D1 + D2) ]
```

Якщо тривалості імпульсів симетричні (`D1 = D2 = D`):

```
Vmid = Vin · [ D / (2 · D) ]
     = Vin / 2                               [ідеальна середина шини]
```

Якщо ж виникає асиметрія тривалостей `Δt = t1 − t2` або `ΔD = D1 − D2`:

```
Vmid = Vin · [ (D2 + ΔD) / (2 · D2 + ΔD) ]
```

Потенціал середньої точки автоматично зсувається рівно на таку величину `ΔVmid`, щоб площа вольт-секундних імпульсів різної тривалості виявилася строго однаковою:

```
(Vin − Vmid) · t1
= [ Vin − Vin · (t1 / (t1 + t2)) ] · t1      [підставили стаціонарний Vmid]
= Vin · [ (t1 + t2 − t1) / (t1 + t2) ] · t1  [звели до спільного знаменника]
= Vin · [ (t1 · t2) / (t1 + t2) ]

Vmid · t2
= [ Vin · (t1 / (t1 + t2)) ] · t2            [підставили стаціонарний Vmid]
= Vin · [ (t1 · t2) / (t1 + t2) ]
```

Обидві площі вольт-секундних прямокутників абсолютно рівні:

```
(Vin − Vmid) · t1 = Vmid · t2
```

Це доводить, що за наявності розділового ємнісного дільника постійна складова напруги на первинній обмотці **завжди тотожно дорівнює нулю**, незалежно від будь-якої статичної асиметрії ШІМ, розкиду параметрів ключів або падіння напруги на діодах.

### Динаміка перехідного процесу перезаряджання конденсаторів

Розгляньмо, як саме середня точка переходить у новий зрівноважений стан при раптовій появі асиметрії `Δt`.

Якщо в початковий момент середня точка була на рівні `Vin / 2`, незбалансована вольт-секундна площа за один період становить:

```
Δ(V·t) = (Vin / 2) · t1 − (Vin / 2) · t2
       = (Vin / 2) · (t1 − t2)            [винесення спільного множника Vin / 2]
       = (Vin / 2) · Δt                   [підстановка різниці тривалостей Δt]
```

Цей надлишок напруги створює постійну складову струму намагнічування `Idc`, яка протікає крізь еквівалентну ємність дільника `Cекв = C1 + C2`. За кожен період `Ts` на конденсатори переноситься заряд:

```
ΔQ = Idc · Ts
```

Зміна напруги на конденсаторах за один період:

```
d(Vmid) / dt ≈ ΔVmid / Ts
             = ΔQ / (Cекв · Ts)           [підстановка приросту заряду ΔQ]
             = Idc / (C1 + C2)            [скорочення періоду Ts]
```

Оскільки зсув середньої точки зменшує прикладену різницю напруг, процес описується лінійним диференціальним рівнянням першого порядку, а стала часу самобалансування визначається індуктивністю намагнічування `Lm` та ємністю дільника:

```
τ_баланс = √(Lm · (C1 + C2))
```

Для типових параметрів перетворювача (`Lm = 2 мГн`, `C1 = C2 = 470 нФ`):

```
Cекв = C1 + C2 = 470e-9 + 470e-9 = 940e-9 Ф
τ_баланс = √(2e-3 · 940e-9)
         = √(1.88e-9)                     [обчислення підкореневого виразу]
         = 43.4 мкс                       [розрахункова стала часу]
```

Перехідний процес встановлення нового балансу триває менше 5–10 періодів комутації (близько 50–100 мкс на частоті 100 кГц), що в сотні разів швидше за будь-які теплові або експлуатаційні дрейфи параметрів.

### Розрахунок діючих струмів та форми первинного сигналу

Струм первинної обмотки складається з двох складових: струму навантаження, трансформованого з вторинної сторони `I_refl(t) = n · I_sec(t)`, та трикутного струму намагнічування `I_mag(t)`.

Розмах струму намагнічування за час відкритого стану ключа:

```
ΔI_mag = (Vin / 2) · t(on) / Lm
       = (Vin · D) / (2 · Lm · fsw)
```

Форма струму під час провідності ключа є трапецією з початковим значенням `I_start = n · (Iout − ΔI_L / 2) − ΔI_mag / 2` та кінцевим `I_end = n · (Iout + ΔI_L / 2) + ΔI_mag / 2`.

Середньоквадратичний (RMS) струм первинної обмотки за повний період комутації розраховується інтегруванням квадрата струму на двох напівперіодах:

```
I_rms_pri = √( (2 / Ts) · ∫ [ i_p(t)² ] dt )
          = Ip_peak · √( (2 · D / 3) · [ 1 + (I_start / Ip_peak) + (I_start / Ip_peak)² ] )
```

Для попередніх інженерних розрахунків при відносно малому розмаху пульсацій застосовують спрощену формулу:

```
I_rms_pri ≈ Ip_peak · √(2 · D)
```

де `Ip_peak = Pout / (Vin · D · η)`.

### Втрати в осерді: рівняння Стейнмеца

Високочастотні втрати у феритовому магнітопроводі складаються з втрат на гістерезис і втрат на вихрові струми. Питома об'ємна потужність втрат `P_v` (у мВт/см³ або кВт/м³) з високою точністю описується емпіричним рівнянням Стейнмеца:

```
P_v = Cm · fsw^α · Bpeak^β
```

де `Cm`, `α` та `β` — коефіцієнти виробника матеріалу (для популярного силового фериту TDK/Epcos N87: `Cm = 10.9`, `α = 1.63`, `β = 2.62` при частоті в кГц та індукції в Теслах).

Повна потужність втрат у трансформаторі визначається множенням питомих втрат на ефективний магнітний об'єм сердечника `Ve`:

```
P_core = P_v · Ve
```

Для осердя ETD39 (`Ve = 11500 мм³ = 11.5 см³`) на частоті 100 кГц при піковій індукції `Bpeak = 0.18 Тл`:

```
P_v = 10.9 · (100)^1.63 · (0.18)^2.62
    = 10.9 · 1819.7 · 0.0112              [обчислення степенів]
    = 222.1 мВт/см³                       [питомі об'ємні втрати]

P_core = 222.1 · 11.5 = 2554 мВт = 2.55 Вт
```

Це дозволяє заздалегідь оцінити перегрів магнітопроводу за формулою теплового опору `ΔT = R_th · P_core`.

### Скін-ефект та глибина проникнення струму в міді

На високих частотах густина струму в провіднику витісняється до його поверхні. Глибина скін-шару `δ` (відстань від поверхні, на якій густина струму спадає в `e ≈ 2.718` разів) визначається виразом:

```
δ = √( ρ / (π · μ₀ · μ_r · fsw) )
```

де для міді при температурі 100 °C:
- питомий опір `ρ = 2.3·10⁻⁸ Ом·м`,
- абсолютна магнітна проникність вакууму `μ₀ = 4π·10⁻⁷ Гн/м`,
- відносна проникність `μ_r = 1`.

На частоті `fsw = 100 кГц`:

```
δ = √( 2.3e-8 / (π · 4πe-7 · 1 · 100000) )
  = √( 2.3e-8 / (3.9478e-1) )             [обчислення знаменника]
  = √( 5.826e-8 )                         [ділення під коренем]
  = 0.241 мм                              [добування квадратного кореня]
```

Щоб опір обмотки змінному струму `R_ac` не перевищував опір постійному струму `R_dc` більш ніж на 10–15 %, максимальний діаметр окремої мідної жили не повинен перевищувати подвійної глибини скін-шару:

```
d_wire_max ≤ 2 · δ = 2 · 0.241 = 0.48 мм
```

Тому первинну і вторинну обмотки намотують не суцільним товстим дротом, а джгутом із кількох паралельних тонких ізольованих жил діаметром 0.2–0.35 мм (ліцендратом) або тонкою мідною стрічкою (фольгою).

### Ефект близькості та фактор Доуелла (Dowell)

Окрім скін-ефекту, у багатошарових котушках трансформатора діє **ефект близькості** *(Proximity Effect)*: змінне магнітне поле струму сусідніх витків індукує вихрові струми в провіднику, ще сильніше стискаючи струм до країв і різко збільшуючи активний опір `R_ac`.

Відношення опору змінного струму до опору постійному струму `F_R = R_ac / R_dc` описується формулою Доуелла:

```
F_R = ξ · [ (sinh(2ξ) + sin(2ξ)) / (cosh(2ξ) − cos(2ξ)) + (2·(p² − 1) / 3) · (sinh(ξ) − sin(ξ)) / (cosh(ξ) + cos(ξ)) ]
```

де `p` — кількість шарів обмотки в одній секції, а `ξ = h_cond / δ` — нормована товщина провідника відносно скін-глибини.

З формули видно, що втрати на ефекті близькості зростають пропорційно квадрату кількості шарів `p²`. Для чотиришарової обмотки (`p = 4`) при суцільному намотуванні опір змінному струму зростає в 6–8 разів!

Для нейтралізації цього ефекту застосовують **секціонування обмоток (Interleaving)**: первинну обмотку ділять навпіл на дві напівобмотки `P1` і `P2`, а вторинну `S` розміщують між ними за схемою `P1 − S − P2` («сендвіч»). Це зменшує ефективну кількість шарів до `p = 1`, знижуючи `F_R` майже до одиниці (`1.15...1.25`) та зменшуючи індуктивність розсіювання `Llk` у 4 рази.

### Індуктивність розсіювання та демпфування комутаційних викидів

Індуктивність розсіювання `Llk` виникає через неповне зчеплення магнітного потоку між первинною та вторинною обмотками. Вона зосереджена в просторі ізоляційного проміжку між шарами обмоток каркаса трансформатора.

Аналітична оцінка індуктивності розсіювання для концентричної конструкції котушки:

```
Llk ≈ μ₀ · Np² · (l_w / (3 · h_w)) · (b_p + b_s + 3 · c_ins)
```

де:
- `l_w` — середня довжина одного витка обмотки,
- `h_w` — висота вікна намотування каркаса,
- `b_p, b_s` — товщини пакетів первинної та вторинної обмоток,
- `c_ins` — товщина міжобмоткової діелектричної ізоляції (майларової стрічки).

При типових значеннях для трансформатора ETD39 (`Np = 16`, `Llk ≈ 3.5 мкГн`) енергія, накопичена в індуктивності розсіювання в момент вимикання струму `Ip_peak = 4.31 А`:

```
E_lk = 0.5 · Llk · Ip_peak²
     = 0.5 · 3.5e-6 · (4.31)²             [підстановка Llk = 3.5 мкГн та Ip_peak = 4.31 А]
     = 0.5 · 3.5e-6 · 18.57               [піднесення струму до квадрата]
     = 32.5 мкДж                          [накопичена індуктивна енергія]
```

Потужність, що виділяється у вигляді тепла на демпферному RCD-клампі при частоті перемикання 100 кГц:

```
P_snubber = E_lk · fsw · [ Vclamp / (Vclamp − Vin / 2) ]
```

При напрузі фіксації `Vclamp = 250 В` (що на 87.5 В вище за робочу напругу `Vin / 2 = 162.5 В`):

```
P_snubber = 32.5e-6 · 100000 · [ 250 / (250 − 162.5) ]
          = 3.25 · [ 250 / 87.5 ]
          = 3.25 · 2.857
          = 9.28 Вт
```

Ці втрати розсіюються резистором RCD-ланцюжка, оберігаючи силові ключі від перенапруги.

### Передавальна функція та частотний відгук вихідного LC-фільтра

Вихідний каскад перетворювача являє собою згладжувальний LC-фільтр другого порядку. Передавальна функція малосигнального тракту від вхідної напруги дроселя `Vs` до виходу `Vout` у просторі Лапласа:

```
H(s) = Vout(s) / Vs(s)
     = [ 1 + s · Cout · ESR ] / [ 1 + s · (Lout / Rн + Cout · ESR) + s² · Lout · Cout ]
```

Ця функція містить:
1. Резонансний подвійний полюс на частоті власного резонансу фільтра:
   ```
   f_0 = 1 / (2π · √(Lout · Cout))
   ```
2. Диференціюючий нуль, утворений ємністю та власним послідовним опором ESR вихідного конденсатора:
   ```
   f_esr = 1 / (2π · Cout · ESR)
   ```

Добротність резонансного контуру фільтра залежить від опору навантаження `Rн`:

```
Q = Rн · √( Cout / Lout )
```

На резонансній частоті `f_0` фаза сигналу в контурі регулювання різко просідає на 180 градусів. Щоб замкнений контур зворотного зв'язку залишався абсолютно стійким за критерієм Найквіста і мав фазовий запас *(Phase Margin)* не менше 45–60 градусів, підсилювач помилки компенсують частотно-задаючим колом Type III, що вводить два випереджальних нулі для компенсації спаду фази подвійного полюса `f_0`.

### Розрахунок компенсатора Type III для стабілізації напруги

Для досягнення частоти зрізу контуру регулювання `fc = fsw / 10 = 10 кГц` підсилювач помилки на основі операційного підсилювача або TL431 охоплюють шестиелементним колом корекції:

1. Перший нуль `f_z1 = 0.75 · f_0` компенсує перший спад фази LC-фільтра.
2. Другий нуль `f_z2 = f_0` повністю повертає фазу назад до −90 градусів.
3. Перший полюс `f_p1 = f_esr` нейтралізує вплив нуля ESR конденсатора `Cout`.
4. Другий полюс `f_p2 = fsw / 2 = 50 кГц` пригнічує високочастотний шум комутації ШІМ.

Розрахунок номіналів пасивних компонентів зворотного зв'язку (`R1, R2, R3, C1, C2, C3`):

```
R1 = 10.0 кОм                                     [опорний резистор дільника]
C1 = 1 / (2π · R1 · f_z2) = 1 / (2π · 10000 · 2250) = 7.07 нФ (обираємо 6.8 нФ)
R3 = R1 · (f_0 / (f_p2 − f_0)) = 10000 · (2250 / 47750) = 471 Ом (обираємо 470 Ом)
C3 = 1 / (2π · R3 · f_p2) = 1 / (2π · 470 · 50000) = 6.77 нФ (обираємо 6.8 нФ)
R2 = (2π · fc · Lout · Cout · R1) / (Vin_nom · n) = 33.2 кОм (обираємо 33 кОм)
C2 = 1 / (2π · R2 · f_z1) = 1 / (2π · 33000 · 1680) = 2.87 нФ (обираємо 2.7 нФ)
```

Такий компенсатор забезпечує стабільний час відновлення вихідної напруги менше 100 мкс при 50 % стрибку струму навантаження без перерегулювання.

### Комплексний баланс втрат та розрахунок підсумкового ККД

Для верифікації теплового режиму перетворювача розраховують повний енергетичний баланс втрат:

1. **Втрати провідності первинних ключів MOSFET:**
   ```
   P_cond_sw = 2 · I_rms_pri² · Rds(on)
             = 2 · (2.36)² · 0.099        [підстановка I_rms_pri = 2.36 А та Rds(on) = 99 мОм]
             = 2 · 5.57 · 0.099           [піднесення струму до квадрата]
             = 1.10 Вт                    [статичні втрати двох ключів]
   ```
2. **Динамічні комутаційні втрати ключів:**
   ```
   P_sw_trans = 2 · [ 0.5 · (Vin / 2) · Ip_peak · (tr + tf) · fsw ]
              = 2 · [ 0.5 · 140 · 4.31 · (25e-9 + 15e-9) · 100000 ]
              = 2 · [ 301.7 · 40e-9 · 100000 ]
              = 2 · 1.21
              = 2.42 Вт
   ```
3. **Втрати в осерді трансформатора (Стейнмец):** `P_core = 2.55 Вт`.
4. **Втрати в міді обмоток трансформатора:**
   ```
   P_cu_tx = I_rms_pri² · R_ac_pri + I_rms_sec² · R_ac_sec
           = (2.36)² · 0.08 + (15.5)² · 0.003 [підстановка діючих струмів та опорів]
           = 0.45 + 0.72                      [добутки втрат первинної і вторинної обмоток]
           = 1.17 Вт                          [сумарні втрати в міді]
   ```
5. **Втрати на вторинних діодах Шотткі:**
   ```
   P_rect = 2 · Vf · (Iout / 2)
          = 0.55 · 20.83                  [підстановка Vf = 0.55 В та Iout = 20.83 А]
          = 11.46 Вт                      [втрати на діодах Шотткі]
   ```
6. **Втрати у вихідному дроселі (осердя + мідь):**
   ```
   P_ind = P_core_L + Iout² · DCR_L
         = 0.8 + (20.83)² · 0.004         [підстановка струму і DCR дроселя]
         = 0.8 + 1.74                     [обчислення омічних втрат]
         = 2.54 Вт                        [повні втрати у вихідному дроселі]
   ```

Сумарна потужність втрат:

```
P_loss_sum = 1.10 + 2.42 + 2.55 + 1.17 + 11.46 + 2.54 + 9.28 [з демпфером]
           = 30.52 Вт
```

Підсумковий ККД системи при номінальній потужності 500 Вт:

```
η_calc = Pout / (Pout + P_loss_sum)
       = 500 / (500 + 30.52)              [підстановка корисної потужності та втрат]
       = 500 / 530.52                     [сумарна споживана потужність]
       = 0.9425 (94.25 %)                 [розрахунковий ККД]
```

Розрахунковий ККД узгоджується з вихідним інженерним припущенням `η = 0.92` з запасом на втрати в колах керування та фільтрах ЕМС.

### Наскрізний числовий розрахунок напівмостового перетворювача

**Вихідні дані для проєктування:**
- Вихідна потужність: `Pout = 500 Вт`
- Вхідна напруга живлення (випрямлена мережа 230 В): `Vin = 325 В` (мінімальна під навантаженням `Vin_min = 280 В`)
- Вихідна стабілізована напруга: `Vout = 24 В`
- Частота комутації ключів: `fsw = 100 кГц` (період `Ts = 10 мкс`)
- Максимальна робоча шпаруватість: `Dmax = 0.45` (мертвий час `t_dead = 500 нс` на кожен напівперіод)
- Осердя: феритовий сердечник ETD39 (ефективна площа `Ae = 125 мм² = 1.25·10⁻⁴ м²`)
- Максимальна робоча індукція фериту: `Bmax = 0.16 Тл`
- Очікуваний ККД: `η = 0.92`
- Допустимі пульсації середньої точки: `ΔVmid_ripple = 10 В`

**Крок 1. Розрахунок мінімальної кількості витків первинної обмотки:**

```
Np ≥ (Vin_min · Dmax) / (4 · fsw · Ae · Bmax)
   = (280 · 0.45) / (4 · 100000 · 1.25e-4 · 0.16) [підстановка числових значень]
   = 126 / (400000 · 2e-5)                        [проміжний розрахунок]
   = 126 / 8                                      [обчислення знаменника]
   = 15.75 витків                                 [теоретичний мінімум]
```

Округляємо до найближчого більшого цілого числа: **`Np = 16 витків`**.

Перевіряємо реальну пікову індукцію при максимальній напрузі `Vin = 325 В`:

```
Bpeak = (325 · 0.45) / (4 · 16 · 1.25e-4 · 100000)
      = 146.25 / 800                              [обчислення чисельника і знаменника]
      = 0.183 Тл                                  [менше за Bsat = 0.38 Тл фериту при 100 °C]
```

**Крок 2. Розрахунок кількості витків вторинної обмотки:**

Враховуємо падіння напруги на діодах Шотткі вторинного випрямляча `Vd ≈ 0.6 В`:

```
Vs_min = (Vout + Vd) / (2 · Dmax)
       = (24 + 0.6) / (2 · 0.45)                  [підстановка Vout = 24 В та Dmax = 0.45]
       = 24.6 / 0.90                              [обчислення знаменника]
       = 27.33 В                                  [мінімальна вторинна амплітуда]
```

Коефіцієнт трансформації `n = Ns / Np`:

```
n = Vs_min / (Vin_min / 2)
  = 27.33 / 140                                   [підстановка Vin_min / 2 = 140 В]
  = 0.1952                                        [коефіцієнт трансформації]

Ns = Np · n
   = 16 · 0.1952                                  [множення на число первинних витків]
   = 3.12 витки                                   [теоретичне число вторинних витків]
```

Округляємо до **`Ns1 = Ns2 = 4 витки`** (дві напівобмотки зі спільною середньою точкою).

**Крок 3. Розрахунок первинного струму та ємності дільника:**

Піковий струм первинної обмотки:

```
Ip_peak = Pout / (Vin_min · Dmax · η)
        = 500 / (280 · 0.45 · 0.92)               [підстановка параметрів потужності]
        = 500 / 115.92                            [обчислення знаменника]
        = 4.31 А                                  [піковий первинний струм]
```

Мінімальна ємність кожного з двох конденсаторів дільника `C1` та `C2`:

```
C ≥ Pout / (2 · Vin_min · η · fsw · ΔVmid_ripple)
  = 500 / (2 · 280 · 0.92 · 100000 · 10)          [підстановка значень напруги і частоти]
  = 500 / 515200000                               [обчислення знаменника]
  = 0.97·10⁻⁶ Ф                                   [розрахункова ємність]
  = 0.97 мкФ                                      [переведення у мікрофаради]
```

Обираємо стандартний поліпропіленовий плівковий конденсатор (MKP/CBB21) номіналом **`C1 = C2 = 1.5 мкФ`** на робочу напругу `400 В`. Плівковий діелектрик забезпечує мізерний ESR і здатність довготривало витримувати середньоквадратичний струм імпульсів понад `3 А`.

**Крок 4. Розрахунок середньоквадратичного струму конденсаторів дільника:**

Форма струму крізь конденсатори є знакозмінною трапецією:

```
I_rms_C = Ip_peak · √(2 · Dmax / 3)
        = 4.31 · √(2 · 0.45 / 3)                  [підстановка пікового струму і шпаруватості]
        = 4.31 · √(0.30)                          [обчислення підкореневого дробу]
        = 4.31 · 0.5477                           [добування квадратного кореня]
        = 2.36 А                                  [діючий струм крізь конденсатор]
```

Обрані плівкові конденсатори на 1.5 мкФ розраховані на струми до `4.5 А`, що гарантує надійну роботу без перегріву діелектрика.

**Крок 5. Розрахунок вихідного дроселя:**

Номінальний вихідний струм: `Iout = Pout / Vout = 500 / 24 = 20.83 А`.

Задаємо розмах пульсацій струму дроселя `ΔI_L = 0.3 · Iout = 0.3 · 20.83 = 6.25 А`.

Мінімальна індуктивність дроселя при роботі на частоті пульсацій 200 кГц:

```
Lout = [ Vout · (0.5 − Dmin) ] / (ΔI_L · fsw)
     = [ 24 · (0.5 − 0.35) ] / (6.25 · 100000)   [підстановка Dmin = 0.35]
     = [ 24 · 0.15 ] / 625000                     [обчислення чисельника]
     = 3.6 / 625000                               [ділення]
     = 5.76·10⁻⁶ Гн                               [розрахункова індуктивність]
     = 5.76 мкГн                                  [переведення у мікрогенрі]
```

Обираємо стандартний силовий дросель індуктивністю **`10 мкГн`** на струм насичення понад 25 А.
