# 🧮 Математичний апарат трифазних симетричних та несиметричних кіл

Ця вставка пропонує вичерпне математичне обґрунтування фундаментальних властивостей трифазних кіл змінного струму. Вона містить строгі алгебраїчні та векторні виведення нульової суми фазних величин, доведення часової сталості миттєвої потужності, тригонометричний та комплексний розрахунок коефіцієнта `√3` для лінійних і фазних параметрів у топологіях «зірка» та «трикутник», математичний доказ вимірювання потужності методом двох ватметрів (схема Арона), а також теорію симетричних складових Фортеск'ю для розрахунку несиметричних та аварійних режимів.

## Комплексний фазорний опис та оператор повертання

Для математичного опису синусоїдальних величин у трифазних колах зручно використовувати комплексні амплітуди (фазори). Симетрична трифазна система напруг складається з трьох гармонічних сигналів одинакової амплітуди `U_m` та діючого значення `U_ph`, які зсунуті за фазою на кут `120°` (або `2π/3` радіан).

У комплексному вигляді фазні напруги виражаються як:

```
U_A = U_ph · e^(j·0) = U_ph
U_B = U_ph · e^(-j·2π/3)
U_C = U_ph · e^(-j·4π/3) = U_ph · e^(j·2π/3)
```

Для спрощення математичних записів в електротехніці вводиться безрозмірний комплексний оператор повертання (поворотний множник), який позначається буквою `a`. Цей оператор являє собою одиничний вектор, повернутий проти годинникової стрілки на кут `120°` (або `2π/3` радіан) відносно дійсної осі:

```
a = e^(j·2π/3)
= cos(2π/3) + j·sin(2π/3)   [формула Ейлера]
= -1/2 + j·√3/2             [тригонометричні значення]
```

Множення будь-якого комплексного вектора на оператор `a` повертає цей вектор проти годинникової стрілки на `120°` без зміни його модуля. Відповідно, квадрат оператора `a²` відповідає повороту на кут `240°` (або за годинниковою стрілкою на `-120°`):

```
a² = e^(j·4π/3)
= cos(4π/3) + j·sin(4π/3)   [формула Ейлера]
= -1/2 - j·√3/2             [тригонометричні значення]
```

Третій степінь оператора `a³` відповідає повному оберту на `360°` і дорівнює одиниці:

```
a³ = e^(j·2π) = cos(2π) + j·sin(2π) = 1
```

Сума оператора повертання, його квадрата та одиниці утворює одну з найважливіших тотожностей трифазної електротехніки:

```
1 + a + a²
= 1 + (-1/2 + j·√3/2) + (-1/2 - j·√3/2)  [підстановка дійсних і уявних частин]
= (1 - 1/2 - 1/2) + j·(√3/2 - √3/2)       [групування за дійсними та уявними компонентами]
= 0 + j·0
= 0                                       [нульова сума векторів зі зсувом 120°]
```

Використовуючи оператор `a`, комплексні напруги симетричної трифазної системи записують у компактній формі: `U_A = U_ph`, `U_B = a²·U_ph`, `U_C = a·U_ph`. З тотожності `1 + a + a² = 0` безпосередньо випливає, що сума комплексних фазних напруг симетричної системи строго дорівнює нулю: `U_A + U_B + U_C = U_ph · (1 + a² + a) = 0`.

Властивості поворотного множника `a` включають також корисні алгебраїчні тотожності, що регулярно використовуються при спрощенні комплексних рівнянь:
- `1 - a = √3 · e^(-j·π/6) = 3/2 - j·√3/2`
- `1 - a² = √3 · e^(j·π/6) = 3/2 + j·√3/2`
- `a - a² = j·√3`
- `a² - a = -j·√3`

## Математичне доведення сталості миттєвої потужності

Розглянемо симетричну трифазну систему, яка живить симетричне навантаження з однаковими фазними опорами. Нехай діюче значення фазної напруги дорівнює `U_ph`, діюче значення фазного струму — `I_ph`, а кут зсуву фаз між напругою та струмом кожної фази дорівнює `φ`.

Миттєві значення фазних напруг та струмів виражаються тригонометричними функціями часу `t`:

```
u_A(t) = √2·U_ph·sin(ωt)
u_B(t) = √2·U_ph·sin(ωt - 2π/3)
u_C(t) = √2·U_ph·sin(ωt - 4π/3)

i_A(t) = √2·I_ph·sin(ωt - φ)
i_B(t) = √2·I_ph·sin(ωt - 2π/3 - φ)
i_C(t) = √2·I_ph·sin(ωt - 4π/3 - φ)
```

Загальна миттєва потужність трифазного кола `p(t)` у кожен момент часу `t` визначається як алгебраїчна сума миттєвих потужностей окремих фаз: `p(t) = u_A(t)·i_A(t) + u_B(t)·i_B(t) + u_C(t)·i_C(t)`.

Застосуємо до кожної фази тригонометричну формулу добутку синусів `2·sin(x)·sin(y) = cos(x - y) - cos(x + y)`:

```
u_A(t)·i_A(t)
= 2·U_ph·I_ph·sin(ωt)·sin(ωt - φ)
= U_ph·I_ph·[cos(φ) - cos(2ωt - φ)]                  [застосування тотожності для фази A]

u_B(t)·i_B(t)
= 2·U_ph·I_ph·sin(ωt - 2π/3)·sin(ωt - 2π/3 - φ)
= U_ph·I_ph·[cos(φ) - cos(2ωt - 4π/3 - φ)]           [застосування тотожності для фази B]

u_C(t)·i_C(t)
= 2·U_ph·I_ph·sin(ωt - 4π/3)·sin(ωt - 4π/3 - φ)
= U_ph·I_ph·[cos(φ) - cos(2ωt - 8π/3 - φ)]           [застосування тотожності для фази C]
```

Тепер просумуємо всі три миттєві потужності фаз:

```
p(t)
= U_ph·I_ph·[3·cos(φ) - (cos(2ωt - φ) + cos(2ωt - φ - 4π/3) + cos(2ωt - φ - 8π/3))]  [групування доданків]
```

Розглянемо вираз у внутрішніх дужках: це сума трьох косинусоїдальних функцій подвоєної частоти `2ω`, які мають одинаковий модуль і зсунуті одна відносно одної на `120°` (`4π/3` радіан у подвоєній часовій шкалі є еквівалентним `2π/3`). Застосовуючи формулу суми гармонічних функцій зі зсувом `120°`, переконуємося, що ця сума в дужках тотожно дорівнює нулю для будь-якого моменту часу `t`.

Звідси отримуємо остаточний фундаментальний результат:

```
p(t) = 3 · U_ph · I_ph · cos(φ) = const
```

Отже, миттєва потужність трифазного навантаження не залежить від часу `t` і є строго постійною величиною, що повністю усуває механічну пульсацію крутного моменту в генераторах та двигунах.

## Розрахунок співвідношень фазних та лінійних величин

### З'єднання зіркою (Y): Зв'язок між фазною та лінійною напругою

При з'єднанні обмоток джерела або навантаження зіркою лінійні струми `I_L` безпосередньо протікають через відповідні фази, тому для струмів виконується тотожність: `I_L = I_ph`.

Лінійна напруга між двома лінійними провідниками (наприклад, між фазами A і B) дорівнює різниці комплексних фазних напруг цих фаз: `U_AB = U_A - U_B`.

Проведемо віднімання у комплексній формі:

```
U_A = U_ph
U_B = U_ph · (-1/2 - j·√3/2)

U_AB
= U_A - U_B                               [визначення лінійної напруги]
= U_ph - U_ph · (-1/2 - j·√3/2)           [підстановка комплексних фазних напруг]
= U_ph · (1 + 1/2 + j·√3/2)               [розкриття дужок]
= U_ph · (3/2 + j·√3/2)                   [зведення подібних доданків]
= √3 · U_ph · (√3/2 + j·1/2)              [винесення √3 за дужки]
= √3 · U_ph · e^(j·π/6)                   [подання в показниковій формі]
```

Отриманий вираз показує два важливі факти:
1. Модуль лінійної напруги перевищує модуль фазної напруги у **`√3 ≈ 1.732`** разів: `U_L = √3 · U_ph`.
2. Вектор лінійної напруги `U_AB` випереджає за фазою вектор фазної напруги `U_A` на кут **`30°` (`π/6` радіан)**.

Аналогічні співвідношення отримують для інших лінійних напруг: `U_BC = √3·U_ph·e^(-j·π/2)` та `U_CA = √3·U_ph·e^(j·5π/6)`. Геометрична сума трьох лінійних напруг завжди дорівнює нулю: `U_AB + U_BC + U_CA = 0`.

### З'єднання трикутником (Δ): Зв'язок між фазним та лінійним струмом

При з'єднанні трикутником кожна фаза навантаження підключена між двома лінійними провідниками, тому лінійна напруга строго дорівнює фазній напрузі: `U_L = U_ph`.

Лінійний струм, що тече від лінії L1 до вершини трикутника A, за першим законом Кірхгофа розгалужується у фази `AB` та `CA`: `I_A = I_AB - I_CA`.

Проведемо комплексне віднімання для симетричної системи струмів:

```
I_AB = I_ph
I_CA = I_ph · (-1/2 + j·√3/2)             [струм фази CA зі зсувом +120°]

I_A
= I_AB - I_CA                             [перший закон Кірхгофа для вузла]
= I_ph - I_ph · (-1/2 + j·√3/2)           [підстановка комплексних фазних струмів]
= I_ph · (3/2 - j·√3/2)                   [спрощення дійсних та уявних частин]
= √3 · I_ph · (√3/2 - j·1/2)              [винесення √3 за дужки]
= √3 · I_ph · e^(-j·π/6)                  [подання в показниковій формі]
```

Отже, при з'єднанні трикутником:
1. Модуль лінійного струму перевищує модуль фазного струму у **`√3 ≈ 1.732`** разів: `I_L = √3 · I_ph`.
2. Вектор лінійного струму `I_A` відстає за фазою від вектора фазного струму `I_AB` на кут **`30°` (`π/6` радіан)**.

## Математична теорія методу двох ватметрів (схема Арона)

Метод двох ватметрів дає змогу виміряти повну активну потужність будь-якої трипровідної системи (без нейтрального провідника) при несиметричному навантаженні.

У 3-провідній мережі за першим законом Кірхгофа сума миттєвих лінійних струмів дорівнює нулю у будь-який момент часу: `i_A(t) + i_B(t) + i_C(t) = 0`. Звідси струм фази B можна виразити через струми фаз A і C: `i_B(t) = -i_A(t) - i_C(t)`.

Миттєва потужність трифазної системи дорівнює сумі добутків потенціалів ліній `v_A, v_B, v_C` на відповідні струми:

```
p(t)
= v_A·i_A + v_B·i_B + v_C·i_C             [визначення через потенціали ліній]
= v_A·i_A + v_B·(-i_A - i_C) + v_C·i_C     [підстановка виразу i_B]
= (v_A - v_B)·i_A + (v_C - v_B)·i_C       [групування за струмами i_A та i_C]
= u_AB·i_A + u_CB·i_C                     [перехід до міжфазних напруг u_AB та u_CB]
```

Усереднюючи миттєву потужність за період `T`, отримуємо активну потужність `P`:

```
P = (1/T)·∫₀ᵀ u_AB·i_A dt + (1/T)·∫₀ᵀ u_CB·i_C dt = P_W1 + P_W2
```

Де `P_W1` — покази першого ватметра, струмова обмотка якого включена в лінію A, а обмотка напруги — між лініями A і B; `P_W2` — покази другого ватметра, струмова обмотка якого включена в лінію C, а обмотка напруги — між лініями C і B.

У симетричному режимі покази ватметрів виражаються через кут фазового зсуву `φ`:

```
P_W1 = U_L · I_L · cos(30° - φ)
P_W2 = U_L · I_L · cos(30° + φ)
```

За допомогою показів двох ватметрів можна також визначити реактивну потужність `Q` та коефіцієнт потужності `cos(φ)` симетричного кола:

```
P_W1 - P_W2
= U_L·I_L·[cos(30° - φ) - cos(30° + φ)]
= U_L·I_L·[2·sin(30°)·sin(φ)]             [різниця косинусів]
= U_L·I_L·sin(φ)                          [підстановка sin(30°) = 0.5]

Q = √3 · (P_W1 - P_W2)                    [реактивна потужність кола]

tg(φ) = √3 · (P_W1 - P_W2) / (P_W1 + P_W2)  [розрахунок тангенса кута фазового зсуву]
```

## Метод симетричних складових Фортеск'ю

Для аналізу складних несиметричних режимів (наприклад, однофазного або двофазного короткого замикання) застосовується метод симетричних складових, запропонований Чарльзом Фортеск'ю у 1918 році.

Довільна несиметрична система трьох векторів напруг `[U_A, U_B, U_C]ᵀ` розкладається на суму трьох симетричних систем:

1. **Пряма послідовність (`U_1`):** вектори `U_A1, U_B1 = a²·U_A1, U_C1 = a·U_A1` з прямим чередуванням фаз A-B-C.
2. **Зворотна послідовність (`U_2`):** вектори `U_A2, U_B2 = a·U_A2, U_C2 = a²·U_A2` зі зворотним чередуванням фаз A-C-B.
3. **Нульова послідовність (`U_0`):** три однакові синфазні вектори `U_A0 = U_B0 = U_C0 = U_0`.

Пряме перетворення Фортеск'ю виражається матричним рівнянням:

```
[U_0]   [1   1    1 ]   [U_A]
[U_1] = [1   a   a² ] · [U_B] · (1/3)     [матриця прямого перетворення Фортеск'ю]
[U_2]   [1  a²    a ]   [U_C]
```

Скалярні рівняння прямого перетворення:

```
U_0 = (1/3) · (U_A + U_B + U_C)           [складова нульової послідовності]
U_1 = (1/3) · (U_A + a·U_B + a²·U_C)       [складова прямої послідовності]
U_2 = (1/3) · (U_A + a²·U_B + a·U_C)       [складова зворотної послідовності]
```

Зворотне перетворення дає змогу відновити реальні фазні напруги за їхніми симетричними складовими:

```
U_A = U_0 + U_1 + U_2                     [фазна напруга A]
U_B = U_0 + a²·U_1 + a·U_2                 [фазна напруга B]
U_C = U_0 + a·U_1 + a²·U_2                 [фазна напруга C]
```

### Математичний розрахунок однофазного короткого замикання на землю (L1-G)

Розглянемо практичний випадок застосування методу симетричних складових для обчислення струму однофазного короткого замикання фази A на землю в 4-провідній мережі.

Граничні умови для точки замикання:
- Напруга пошкодженої фази: `U_A = 0`.
- Струми непошкоджених фаз: `I_B = 0`, `I_C = 0`.

Виразимо симетричні складові струмів за формулами Фортеск'ю:

```
I_0 = (1/3) · (I_A + I_B + I_C) = (1/3) · I_A
I_1 = (1/3) · (I_A + a·I_B + a²·I_C) = (1/3) · I_A
I_2 = (1/3) · (I_A + a²·I_B + a·I_C) = (1/3) · I_A
```

Отже, при однофазному короткому замиканні всі три симетричні складові струмів дорівнюють одна одній: `I_0 = I_1 = I_2 = (1/3)·I_A`.

Рівняння замикання фазних напруг через опори систем прямої `Z_1`, зворотної `Z_2` та нульової `Z_0` послідовностей мають вигляд:

```
U_A = E_A - I_1·Z_1 - I_2·Z_2 - I_0·Z_0 = 0
```

Оскільки `I_0 = I_1 = I_2`, підставляємо їх в рівняння напруги:

```
E_A - I_1 · (Z_1 + Z_2 + Z_0) = 0
```

Звідси струм прямої послідовності дорівнює:

```
I_1 = E_A / (Z_1 + Z_2 + Z_0)
```

Повний струм однофазного короткого замикання в точці пошкодження виражається як:

```
I_A = 3 · I_1 = (3 · E_A) / (Z_1 + Z_2 + Z_0)
```

Ця формула показує, що для розрахунку однофазного короткого замикання схеми заміщення прямої, зворотної та нульової послідовностей з'єднуються послідовно.

Метод симетричних складових є основою сучасних релейних захистів та мікропроцесорних блоків автоматики, оскільки виникнення струмів зворотної `I_2` та нульової `I_0` послідовностей однозначно сигналізує про виникнення короткого замикання або обриву фази в електричній мережі.
