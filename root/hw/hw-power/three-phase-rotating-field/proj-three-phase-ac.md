# ⚙️ Програмний розрахунок та симуляція трифазних кіл

Ця вставка містить повноцінну інженерну методику та програмну реалізацію чисельного розрахунку режимів трифазних кіл змінного струму при довільному несиметричному навантаженні. Поданий модуль моделює роботу топологій «зірка» (з нейтральним провідником N та без нього) і «трикутник», розраховує комплексні фазні та лінійні струми, струм нейтралі `I_N`, напругу зміщення нейтралі `U_N`, фазні та сумарні активні `P`, реактивні `Q` і повні `S` потужності, а також коефіцієнти потужності `cos(φ)`.

## Фізико-математична модель та інженерний алгоритм

Розкреслення розрахунку несиметричного трифазного кола за методом вузлових потенціалів ґрунтується на визначенні напруги між нейтральною точкою навантаження `N'` та нейтральною точкою джерела `N`. Ця напруга називається **напругою зміщення нейтралі** і позначається як `U_N`.

За формулою Мілмана (методом двох вузлів у комплексній формі), комплексне значення напруги зміщення нейтралі дорівнює:

```
U_N = (U_A·Y_A + U_B·Y_B + U_C·Y_C) / (Y_A + Y_B + Y_C + Y_N)
```

Де:
- `U_A, U_B, U_C` — комплексні ЕРС фаз джерела зі зсувом 120°: `U_A = U_ph`, `U_B = U_ph·e^(-j·2π/3)`, `U_C = U_ph·e^(j·2π/3)`;
- `Y_A = 1/Z_A`, `Y_B = 1/Z_B`, `Y_C = 1/Z_C` — комплексні провідності фаз навантаження, де `Z_A, Z_B, Z_C` — комплексні опори фаз (`Z = R + jX`);
- `Y_N = 1/Z_N` — комплексна провідність нейтрального провідника з опором `Z_N`.

Після обчислення `U_N` фактичні напруги на фазах навантаження виражаються як різниця потенціалів джерела та зміщення нейтралі:

```
U_A' = U_A - U_N
U_B' = U_B - U_N
U_C' = U_C - U_N
```

Комплексні фазні струми споживача розраховуються за законом Ома для кожної фази:

```
I_A = U_A' · Y_A = (U_A - U_N) / Z_A
I_B = U_B' · Y_B = (U_B - U_N) / Z_B
I_C = U_C' · Y_C = (U_C - U_N) / Z_C
```

Струм, що тече через нейтральний провідник від точки `N'` до точки `N`, визначається за першим законом Кірхгофа як векторна сума трьох фазних струмів, або за законом Ома для нейтралі:

```
I_N = I_A + I_B + I_C = U_N · Y_N = U_N / Z_N
```

### Покроковий чисельний розрахунок контрольного прикладу

Розглянемо детальний покроковий приклад чисельного розрахунку несиметричного навантаження, з'єднаного зіркою з нейтральним провідником. Нехай лінійна напруга джерела становить `U_L = 400 В`, що відповідає діючому значенню фазної напруги `U_ph = 400 / √3 ≈ 230.94 В`.

Параметри фазних опорів споживача та нейтрального проводу задано наступними комплексними величинами:
- Фаза A: чисто активне навантаження `Z_A = 10 + j0 Ом` (активний опір `R_A = 10 Ом`, реактивний опір `X_A = 0 Ом`).
- Фаза B: індуктивне навантаження `Z_B = 15 + j10 Ом` (активний опір `R_B = 15 Ом`, індуктивний опір `X_B = 10 Ом`).
- Фаза C: ємнісне навантаження `Z_C = 20 - j8 Ом` (активний опір `R_C = 20 Ом`, ємнісний опір `X_C = 8 Ом`).
- Нейтральний провідник: опір `Z_N = 1.2 + j0 Ом`.

Обчислимо комплексні ЕРС джерела з фазовим зсувом 120 градусів:
- `U_A = 230.94 + j0 В`.
- `U_B = 230.94 · (-0.5 - j·0.86603) = -115.47 - j200.00 В`.
- `U_C = 230.94 · (-0.5 + j·0.86603) = -115.47 + j200.00 В`.

Обчислимо комплексні провідності кожної фази `Y = 1 / Z`:
- `Y_A = 1 / (10 + j0) = 0.1000 + j0.0000 См`.
- `Y_B = (15 - j10) / (15² + 10²) = 15 / 325 - j10 / 325 = 0.04615 - j0.03077 См`.
- `Y_C = (20 + j8) / (20² + 8²) = 20 / 464 + j8 / 464 = 0.04310 + j0.01724 См`.
- `Y_N = 1 / (1.2 + j0) = 0.83333 + j0.0000 См`.

Обчислимо суму провідностей знаменника формули Мілмана:
`Y_{sum} = Y_A + Y_B + Y_C + Y_N = (0.1000 + 0.04615 + 0.04310 + 0.83333) + j(0.0000 - 0.03077 + 0.01724) = 1.02258 - j0.01353 См`.

Обчислимо добутки напруг на провідності в чисельнику формули Мілмана:
- `U_A · Y_A = 230.94 · 0.1000 = 23.094 + j0.000 В`.
- `U_B · Y_B = (-115.47 - j200.00) · (0.04615 - j0.03077) = (-5.329 - 6.154) + j(3.553 - 9.230) = -11.483 - j5.677 В`.
- `U_C · Y_C = (-115.47 + j200.00) · (0.04310 + j0.01724) = (-4.977 - 3.448) + j(-1.991 + 8.620) = -8.425 + j6.629 В`.

Сума чисельника: `Num = (23.094 - 11.483 - 8.425) + j(0.000 - 5.677 + 6.629) = 3.186 + j0.952 В`.

Діленням чисельника на знаменник отримуємо напругу зміщення нейтралі `U_N`:
`U_N = (3.186 + j0.952) / (1.02258 - j0.01353) ≈ 3.10 + j0.97 В`. Модуль зміщення нейтралі `|U_N| ≈ 3.25 В`.

Значне значення провідності нейтрального проводу `Y_N = 0.833 См` у даному випадку надійно утримує зміщення нейтралі на низькому рівні `3.25 В`, що забезпечує стабільність фазних напруг споживачів.

Обчислимо тепер фактичні напруги на фазах споживача `U_k' = U_k - U_N`:
- `U_A' = 230.94 - (3.10 + j0.97) = 227.84 - j0.97 В`, модуль `|U_A'| ≈ 227.84 В`.
- `U_B' = (-115.47 - j200.00) - (3.10 + j0.97) = -118.57 - j200.97 В`, модуль `|U_B'| ≈ 233.35 В`.
- `U_C' = (-115.47 + j200.00) - (3.10 + j0.97) = -118.57 + j199.03 В`, модуль `|U_C'| ≈ 231.69 В`.

Як видно з чисельного розрахунку, через невеликий опір нейтрального проводу (`1.2 Ом`) фазні напруги споживачів зазнали незначних відхилень від номінального значення `230.94 В` (фаза A просіла на 3.1 В, а фази B і C підскочили на 2.4 В та 0.7 В відповідно).

Обчислимо струми у фазах навантаження `I_k = U_k' · Y_k`:
- `I_A = (227.84 - j0.97) · 0.1000 = 22.784 - j0.097 А`, модуль `|I_A| ≈ 22.78 А`.
- `I_B = (-118.57 - j200.97) · (0.04615 - j0.03077) = -11.656 - j5.626 А`, модуль `|I_B| ≈ 12.94 А`.
- `I_C = (-118.57 + j199.03) · (0.04310 + j0.01724) = -8.542 + j6.534 А`, модуль `|I_C| ≈ 10.75 А`.

Струм у нейтральному провіднику дорівнює `I_N = U_N · Y_N = (3.10 + j0.97) · 0.83333 = 2.58 + j0.81 А`, модуль `|I_N| ≈ 2.71 А`. Цей струм протікає по нейтральному проводу, розвантажуючи фази та утримуючи нейтральну точку споживача від фазного перекосу.

### Розрахунок топології Трикутник (Δ)

Для з'єднання навантаження трикутником лінійні напруги джерела підводяться безпосередньо до вершин трикутника навантаження: `U_AB = U_A - U_B`, `U_BC = U_B - U_C`, `U_CA = U_C - U_A`.

При симетричній системі напруг джерела `U_L = 400 В` комплексні міжфазні напруги дорівнюють:
- `U_AB = 400 · e^(j·π/6) = 346.41 + j200.00 В`.
- `U_BC = 400 · e^(-j·π/2) = 0.00 - j400.00 В`.
- `U_CA = 400 · e^(j·5π/6) = -346.41 + j200.00 В`.

Фазні струми споживача обчислюються прямо за законом Ома:
```
I_AB = U_AB / Z_AB = U_AB · Y_AB
I_BC = U_BC / Z_BC = U_BC · Y_BC
I_CA = U_CA / Z_CA = U_CA · Y_CA
```

Лінійні струми у провідниках лінії живлення визначаються за першим законом Кірхгофа:
```
I_A = I_AB - I_CA
I_B = I_BC - I_AB
I_C = I_CA - I_BC
```

Загальна активна потужність трикутника дорівнює сумі дійсних частин комплексних потужностей окремих фаз: `P_{total} = Re(U_AB · conj(I_AB)) + Re(U_BC · conj(I_BC)) + Re(U_CA · conj(I_CA))`.

### Аналіз аварійних режимів та крайових випадків

1. **Ідеальний нейтральний провідник (`Z_N = 0`, `Y_N -> ∞`):**
   Знаменник у формулі Мілмана прямує до нескінченності, тому напруга зміщення нейтралі строго дорівнює нулю: `U_N = 0`. Фактичні напруги на фазах навантаження жорстко зафіксовані на рівні ЕРС джерела (`U_A' = U_A`, `U_B' = U_B`, `U_C' = U_C`), а струм у нейтралі `I_N` компенсує всю несиметрію струмів навантаження.
2. **Обрив нейтрального провідника (`Z_N -> ∞`, `Y_N = 0`):**
   Це аварійний режим. Струм у нейтралі `I_N = 0`, але зміщення нейтралі `U_N` досягає максимального значення:
   ```
   U_N = (U_A·Y_A + U_B·Y_B + U_C·Y_C) / (Y_A + Y_B + Y_C)
   ```
   На фазі з найбільшим опором (найменшим навантаженням) напруга `U'` зростає майже до лінійного значення `U_L ≈ √3·U_ph`, що призводить до пробою ізоляції та виходу з ладу обладнання. На фазі з найменшим опором напруга просідає до низьких значень.
3. **Симетричний режим (`Z_A = Z_B = Z_C = Z`):**
   У цьому випадку `Y_A = Y_B = Y_C = Y`. Чисельник формули Мілмана містить суму `Y·(U_A + U_B + U_C) = Y·0 = 0`. Отже, `U_N = 0` та `I_N = 0` навіть при відсутності нейтрального провідника.
4. **Однофазне коротке замикання фази на нейтраль (`Z_A -> 0`, `Y_A -> ∞`):**
   У цьому разі потенціал нейтралі `N'` наближається до потенціалу фази A (`U_N ≈ U_A`), що викликає суттєві перенапруги на двох інших фазах B і C у трьохпровідній мережі.
5. **Обрив однієї з фаз навантаження (`Z_A -> ∞`, `Y_A = 0`):**
   При обриві фази A провідність `Y_A = 0`. Схема перетворюється на несиметричну двофазну систему. Алгоритм автоматично обчислює зміщення нейтралі `U_N` та фазні струми без виникнення винятків ділення на нуль, оскільки обчислення виконуються через провідності `Y`.

### Розрахунок комплексних потужностей

Комплексна потужність кожної фази `S_k` обчислюється як добуток комплексної фазної напруги на комплексно-спряжений струм цієї фази:

```
S_A = U_A' · conj(I_A) = P_A + j·Q_A
S_B = U_B' · conj(I_B) = P_B + j·Q_B
S_C = U_C' · conj(I_C) = P_C + j·Q_C
```

Дійсна частина `Re(S_k)` дає активну потужність фази `P_k` (Вт), а уявна частина `Im(S_k)` — реактивну потужність `Q_k` (вар). Загальна активна потужність трифазного кола дорівнює алгебраїчній сумі активних потужностей трьох фаз: `P_{total} = P_A + P_B + P_C`.

Повна потужність трифазної системи розраховується як модуль комплексної суми або через прямокутний трикутник потужностей:

```
S_{total} = √(P_{total}² + Q_{total}²)
```

Коефіцієнт потужності всієї трифазної системи виражається співвідношенням активної та повної потужності:

```
cos(φ_{sys}) = P_{total} / S_{total}
```

## Інженерні висновки та порівняння мовних реалізацій

Наведена програмна симуляція ілюструє важливі особливості обчислення трифазних кіл:

1. **Ідіоматичність C++:** Використання стандартного типу `std::complex<double>` та стандартної константи `std::numbers::pi` з C++20 робить код лаконічним і виключає помилки виклику функцій над дійсними та уявними частинами, характерні для самописних структур мови C.
2. **Типобезпечність та константна чистота:** Реалізація на C++ використовує концепцію незмінності даних `const`, атрибут `[[nodiscard]]` та синтаксис `std::array`, що гарантує відсутність витоків пам'яті та виходів за межі масивів без використання динамічного виділення пам'яті `malloc`.
3. **Практична цінність:** Програма дозволяє легко проводити числові експерименти, моделювати вихід з ладу нейтрального провідника (встановивши `has_neutral = false`) та оцінювати перенапруги, що виникають при аваріях у реальних розподільчих мережах.
