# Критерій стійкості Міддлбрука для вхідного фільтра

Вхідний LC-фільтр електромагнітної сумісності (ЕМС) та імпульсний перетворювач напруги утворюють взаємозв'язану динамічну систему, в якій ідеально налаштований стабілізатор може раптово втратити стійкість і перейти в режим безперервних автоколивань. Причиною цього є властивість замкненої петлі зворотного зв'язку перетворювача підтримувати сталу потужність навантаження, що формує від'ємний динамічний опір на його вхідних клемах. Цей математичний опис виводить кількісні умови стійкості за критерієм Міддлбрука, розраховує вихідний імпеданс фільтра та визначає точні аналітичні параметри паралельного демпфувального кола для усунення резонансного піку.

### Від'ємний динамічний вхідний опір перетворювача

Імпульсний перетворювач із замкненою петлею регулювання підтримує незмінну вихідну напругу `V_out` на стаціонарному навантаженні з опором `R_load`, забезпечуючи сталу вихідну потужність `P_out`. За коефіцієнта корисної дії `η` споживана потужність на вході перетворювача `P_in` є незмінною відносно повільних коливань вхідної напруги:

```
P_in = P_out / η = const
```

Струм, що споживається перетворювачем від живильної лінії, пов'язаний із вхідною напругою `V_in` співвідношенням:

```
I_in(V_in) = P_in / V_in
```

Малосигнальний (динамічний) вхідний опір перетворювача `r_in` визначається як похідна напруги за струмом у робочій точці `(V_in0, I_in0)`:

```
1 / r_in = d(I_in) / d(V_in)
         = d(P_in · V_in⁻¹) / d(V_in)
         = -P_in / V_in0²                 [похідна степеневої функції]
         = -I_in0 / V_in0                 [підстановка робочої точки I_in0 = P_in / V_in0]
```

Обертаючи вираз для провідності, отримуємо малосигнальний динамічний опір:

```
r_in = -V_in0² / P_in                     [динамічний опір замкненого перетворювача]
```

Знак «мінус» означає, що при зростанні вхідної напруги `V_in` вхідний струм `I_in` зменшується для збереження сталої потужності, а при падінні напруги — струм зростає. У смузі пропускання петлі регулювання (від постійного струму до частоти зрізу петлі `f_c`) перетворювач поводиться для живильної мережі як чистий від'ємний резистор.

### Вплив фільтра на петлю зворотного зв'язку за теоремою EET

Розглянемо вхідний фільтр нижніх частот з еквівалентною індуктивністю `L_f`, еквівалентною ємністю `C_f` та паразитним послідовним опором втрат `R_s`.

Вихідний імпеданс недемпфованого фільтра `Z_out(s)` (імпеданс, який бачить перетворювач, дивлячись назад у бік фільтра при закороченому джерелі живлення) дорівнює паралельному з'єднанню гілки індуктивності та ємності:

```
Z_out(s) = (s·L_f + R_s) || (1 / (s·C_f))
         = (s·L_f + R_s) / (s²·L_f·C_f + s·R_s·C_f + 1)   [розкриття паралельного з'єднання]
```

Введемо характеристичний опір контуру `R_0`, резонансну кутову частоту `ω_0` та власну добротність `Q_0`:

```
ω_0 = 1 / √(L_f · C_f)
R_0 = √(L_f / C_f)
Q_0 = R_0 / R_s                           [добротність недемпфованого фільтра]
```

На резонансній частоті `ω = ω_0` реактивні опори індуктивності та ємності взаємно компенсуються, і вихідний імпеданс досягає максимального резонансного піку:

```
|Z_out(j·ω_0)| = L_f / (R_s · C_f)
               = Q_0 · R_0                [резонансний пік імпедансу фільтра]
```

За теоремою про додатковий елемент (Extra Element Theorem, EET) вхідний фільтр модифікує передатну функцію розімкненої петлі зворотного зв'язку перетворювача `T(s)` множником узгодження:

```
T_mod(s) = T(s) · (1 + Z_out(s) / Z_in,inf(s)) / (1 + Z_out(s) / Z_in,0(s))
```

де `Z_in,0(s)` — вхідний імпеданс перетворювача при замкненій петлі зворотного зв'язку (у смузі петлі `Z_in,0 ≈ r_in = -V_in0² / P_in`), а `Z_in,inf(s)` — вхідний імпеданс при розімкненій петлі керування.

Знаменник виразу `1 + Z_out(s) / Z_in,0(s)` являє собою характеристичне рівняння замкненої системи за наявності фільтра. Якщо на частоті резонансу `ω_0` комплексне відношення імпедансів наближається до небезпечної точки:

```
Z_out(j·ω_0) / Z_in,0(j·ω_0) = -1
```

знаменник обертається в нуль, що створює пару полюсів на уявній осі або в правій комплексній півплощині `s`. Система втрачає стійкість і перетворюється на LC-генератор.

Критерій стійкості Міддлбрука (Middlebrook Stability Criterion) встановлює строгу умову розділення амплітудно-частотних характеристик: для гарантованої стійкості та відсутності спотворень перехідної характеристики вихідний імпеданс фільтра `Z_out(s)` повинен бути значно меншим за вхідний імпеданс перетворювача `Z_in(s)` на всіх частотах:

```
|Z_out(s)| ≪ |Z_in(s)|                    [критерій Міддлбрука]
```

На практиці інженерний запас стійкості `ΔM` має становити не менше 6 дБ (фактор запасу 2):

```
|Z_out(j·ω)|_max ≤ 0.5 · |r_in| = V_in0² / (2 · P_in)
```

Крім того, перетин характеристик імпедансів спричиняє деградацію запасу фази петлі керування. Зниження запасу фази `ΔPM` оцінюється як:

```
ΔPM ≈ -arctan(|Z_out(j·ω_c)| / |Z_in(j·ω_c)|)
```

де `ω_c` — частота зрізу петлі зворотного зв'язку перетворювача. Якщо вихідний імпеданс фільтра становить навіть 50% від вхідного імпедансу на частоті зрізу, запас фази зменшується майже на 26 градусів, що веде до сильного перерегулювання та тривалого дзвону під час стрибків навантаження.

### Порівняння топологій демпфування: паралельне RC проти послідовного RL

Для обмеження резонансного піку добротності застосовують демпфувальні ланцюжки. Існують дві базові топології демпфування LC-фільтра:

1. **Послідовне RL-демпфування індуктивності.** Паралельно головному дроселю `L_f` підключають резистор `R_s_damp`. На високих частотах струм завади тече через резистор, знижуючи добротність. Недолік схеми: погіршення крутизни спаду АЧХ фільтра на високих частотах (фільтр перетворюється з фільтра другого порядку зі спадом -40 дБ/дек на фільтр першого порядку зі спадом -20 дБ/дек).

2. **Паралельне RC-демпфування ємності.** Паралельно основному фільтрувальному конденсатору `C_f` підключають послідовний ланцюжок з резистора `R_d` та блокувального конденсатора `C_d`. Конденсатор `C_d` не пропускає постійний струм живлення, що забезпечує нульові статичні втрати потужності на резисторі `R_d`. На частотах резонансу конденсатор `C_d` має малий реактивний опір, і резистор `R_d` ефективно шунтує контур, поглинаючи енергію резонансних коливань без погіршення високочастотного затухання фільтра.

Завдяки збереженню крутизни спаду АЧХ та відсутності втрат на постійному струмі паралельне RC-демпфування є промисловим стандартом для вхідних фільтрів живлення.

### Аналітичний розрахунок паралельного RC-демпфування

Позначимо відношення ємності демпфера до ємності основного конденсатора через параметр `n`:

```
n = C_d / C_f                             [коефіцієнт збільшення ємності демпфера]
```

Повний вихідний імпеданс демпфованого фільтра описується виразом:

```
Z_out,damped(s) = s·L_f || (1 / (s·C_f)) || (R_d + 1 / (s·C_d))
                = s·L_f · (s·R_d·C_d + 1) / (s³·L_f·C_f·C_d·R_d + s²·L_f·(C_f + C_d) + s·R_d·C_d + 1)
```

Мінімізація пікового значення модуля імпедансу `|Z_out,damped(j·ω)|` відносно опору `R_d` дає оптимальне аналітичне значення демпфувального резистора:

```
R_d,opt = R_0 · √((2 + n) · (4 + 3·n) / (2 · n² · (4 + n)))
```

При такому оптимальному виборі опору `R_d` пікове значення вихідного імпедансу фільтра стає строго обмеженим зверху величиною:

```
|Z_out,damped|_max = R_0 · √((2 + n) / n)
```

Аналіз залежності показує:
- При `n = 1` (`C_d = C_f`): `|Z_out|_max = 1.73 · R_0`
- При `n = 3` (`C_d = 3 · C_f`): `|Z_out|_max = 1.29 · R_0`
- При `n = 4` (`C_d = 4 · C_f`): `|Z_out|_max = 1.22 · R_0`
- При `n = 10` (`C_d = 10 · C_f`): `|Z_out|_max = 1.09 · R_0`

Оптимальним компромісом між габаритами конденсатора `C_d` та величиною пікового імпедансу є діапазон `n = 3..5`.

### Числовий приклад повного проєктування фільтра за Міддлбруком

Спроєктуємо вхідний ЕМС-фільтр для живлення DC/DC перетворювача з такими параметрами ТЗ:
- Вхідна напруга: номінальна `V_in = 48 В`, мінімальна `V_in,min = 36 В`
- Вихідна потужність: `P_out = 150 Вт`
- ККД перетворювача: `η = 0.90` (споживана потужність `P_in = 150 / 0.90 = 166.7 Вт`)
- Параметри індуктивності та ємності фільтра за вимогами фільтрації завад: `L_f = 15 мкГн`, `C_f = 22 мкФ`

**Крок 1. Розрахунок найгіршого динамічного опору перетворювача.**
Найменший за модулем динамічний опір спостерігається при мінімальній вхідній напрузі `V_in,min = 36 В`:

```
|r_in,min| = V_in,min² / P_in
           = 36² / 166.7
           = 1296 / 166.7
           ≈ 7.77 Ом                      [критичний динамічний опір навантаження]
```

**Крок 2. Розрахунок параметрів недемпфованого контуру.**

```
R_0 = √(L_f / C_f)
    = √(15×10⁻⁶ / 22×10⁻⁶)
    = √0.6818
    ≈ 0.826 Ом                            [характеристичний опір]

f_0 = 1 / (2π · √(L_f · C_f))
    = 1 / (2π · √(15×10⁻⁶ · 22×10⁻⁶))
    = 1 / (2π · 1.8166×10⁻⁵)
    ≈ 8760 Гц = 8.76 кГц                  [резонансна частота]
```

Якщо власний опір втрат дроселя становить `R_s = 20 мОм` (0.02 Ом), добротність контуру дорівнює:

```
Q_0 = R_0 / R_s = 0.826 / 0.02 = 41.3
|Z_out(j·ω_0)| = Q_0 · R_0 = 41.3 · 0.826 = 34.1 Ом
```

Оскільки `34.1 Ом > |r_in,min| = 7.77 Ом`, недемпфований фільтр порушує критерій стійкості у 4.4 раза і призведе до неминучих автоколивань.

**Крок 3. Розрахунок демпфувального ланцюжка.**
Обираємо коефіцієнт збільшення ємності `n = 4`:

```
C_d = n · C_f = 4 · 22 мкФ = 88 мкФ       [номінал: електролітичний або полімерний 100 мкФ]
```

Розраховуємо оптимальний резистор демпфування `R_d,opt`:

```
R_d,opt = R_0 · √((2 + n)·(4 + 3·n) / (2 · n² · (4 + n)))
        = 0.826 · √((2 + 4)·(4 + 3·4) / (2 · 16 · (4 + 4)))    [підстановка n = 4]
        = 0.826 · √((6 · 16) / (32 · 8))                      [арифметика в чисельнику й знаменнику]
        = 0.826 · √(96 / 256)                                 [спрощення дробу під коренем]
        = 0.826 · √0.375                                      [ділення чисел]
        = 0.826 · 0.6124                                      [обчислення квадратного кореня]
        ≈ 0.506 Ом                                            [номінал: 0.51 Ом]
```

**Крок 4. Перевірка максимального піку демпфованого імпедансу.**

```
|Z_out,damped|_max = R_0 · √((2 + n) / n)
                   = 0.826 · √((2 + 4) / 4)                   [підстановка n = 4]
                   = 0.826 · √1.5                             [спрощення дробу]
                   = 0.826 · 1.2247                           [обчислення кореня]
                   ≈ 1.01 Ом                                  [піковий вихідний імпеданс]
```

**Крок 5. Перевірка запасу стійкості.**

```
ΔM = |r_in,min| / |Z_out,damped|_max
   = 7.77 / 1.01
   ≈ 7.69                                 [коефіцієнт запасу стійкості]

ΔM_dB = 20 · log10(7.69) ≈ 17.7 дБ ≫ 6 дБ [відповідає вимогам надійності]
```

Введення паралельної демпфувальної гілки `R_d = 0.51 Ом` та `C_d = 100 мкФ` знизило резонансний пік імпедансу з 34.1 Ом до 1.01 Ом, забезпечивши гарантований запас стійкості 17.7 дБ за будь-яких режимів роботи перетворювача.
