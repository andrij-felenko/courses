Кожен імпульсний перетворювач напруги працює шляхом періодичного переривання струму силовими транзисторами з частотою від десятків кілогерців до кількох мегагерців. Перемикання силового ключа формує круті фронти напруги зі швидкістю наростання `dV/dt` від 10 до 100 В/нс та стрибки струму зі швидкістю `dI/dt` від 0.5 до 10 А/нс. За законами Фур'є неперервна послідовність таких імпульсів створює широкий спектр гармонік, амплітуда яких спадає зі швидкістю -20 дБ/дек до частоти зворотного часу наростання фронту `1 / (π · t_r)` і зі швидкістю -40 дБ/дек на вищих частотах, сягаючи десятків і сотень мегагерців. Без спеціальних бар'єрів цей високочастотний струм безперешкодно виходить у зовнішні проводи живлення, які перетворюються на ефективні випромінювальні антени. Стандарти електромагнітної сумісності (CISPR 32, CISPR 25, EN 55032) жорстко обмежують рівень наведених у мережу завад у смузі 150 кГц – 30 МГц стелею 46–66 дБмкВ (від 200 мкВ до 2 мВ). Оскільки власний рівень шуму неізольованого перетворювача досягає 100–120 дБмкВ (1–3 В), вхідний ЕМС-фільтр мережі живлення є обов'язковим вузлом, який має забезпечити від 40 до 70 дБ пригнічення високочастотної енергії в обох напрямках.

### Генезис завад у мережі живлення: dV/dt та dI/dt

Високочастотний шум, що циркулює між імпульсним джерелом живлення та живильною мережею, поділяється на два принципово різні типи за фізичною природою походження та геометрією контурів поширення: диференціальну (DM) та синфазну (CM) завади.

![Джерела та контури поширення завад](/root/hw/hw-power/emi-filter/img/cm-dm-noise-sources.svg)
*Контури поширення завад в імпульсному перетворювачі: ліворуч — диференціальний струм циркулює між фазним L і нейтральним N проводами через комутацію dI/dt; праворуч — синфазний струм зміщення dV/dt протікає через паразитну ємність радіатора на корпус PE і повертається синхронно по обох проводах живлення.*

**Диференціальна завада** (англ. *differential-mode noise, DM*; від лат. *differentia* — різниця) породжується розривним струмом комутації силового ключа `dI/dt`. У понижувальному перетворювачі струм, що споживається від вхідного джерела, має форму трапецієподібних імпульсів із нульовими паузами. Цей пульсуючий струм тече по фазному проводу (L або `+V_in`) у бік перетворювача й повертається назад через нейтральний або загальний провід (N або `-V_in`). Диференціальна завада є напругою між двома живильними шинами:

```
V_DM = V_L - V_N
I_DM = (I_L - I_N) / 2
```

Основним джерелом диференціальної завади є імпульсний струм, що протікає через еквівалентний послідовний опір (ESR) та еквівалентну послідовну індуктивність (ESL) вхідного конденсатора перетворювача. Спектр диференціальної завади переважає в низькочастотній частині діапазону вимірювань (від 150 кГц до 1–2 МГц).

**Синфазна завада** (англ. *common-mode noise, CM*; від грец. *σύν* — разом, та *φάσις* — фаза/поява) породжується швидкими перепадами напруги `dV/dt` на внутрішніх комутаційних вузлах схеми (Switch Node, стік/витік силових MOSFET чи колектор IGBT). Комутаційний вузол має значну площу мідних полігонів і з'єднаний через ізоляційні прокладки з металевим радіатором або заземленим корпусом пристрою. Це створює розподілену паразитну ємність монтажу `C_para` величиною від 10 до 200 пФ.

При кожному перемиканні ключа висока швидкість зміни напруги збуджує струм зміщення через цю паразитну ємність за законом Максвелла:

```
i_CM = C_para · (dV_SW / dt)
```

За швидкості наростання фронту `dV/dt = 50 В/нс` та паразитної ємності радіатора `C_para = 50 пФ` амплітуда імпульсу синфазного струму досягає:

```
i_CM = 50×10⁻¹² · (50 / 10⁻⁹) = 2.5 А
```

Цей струм стікає через корпус у захисне заземлення (PE, Protective Earth), розтікається по металевих конструкціях будівлі або шасі транспортного засобу і повертається до джерела живлення одночасно та синфазно по обох живильних проводах (L та N). Синфазна завада визначається як середній потенціал обох шин відносно землі:

```
V_CM = (V_L + V_N) / 2
I_CM = (I_L + I_N) / 2
```

Оскільки контур синфазного струму замикається через просторову геометрію корпусу та кабелів заземлення, площа його петлі в сотні разів перевищує площу диференціального контуру на платі. Саме синфазний струм відповідає за високочастотне випромінювання завад в ефір у діапазоні від 2 до 30 МГц і вище.

Оскільки струми DM та CM завад протікають абсолютно різними просторовими шляхами, жоден універсальний пасивний елемент не здатен одночасно придушити обидві складові. Фільтр мережі живлення будується як спеціалізована топологія, де кожен компонент виконує суворо розмежовану функцію.

> 🔧 **Навіщо це.** Спроба збільшити затухання фільтра простим нарощуванням ємності між шинами живлення давить лише диференціальну складову завади, залишаючи синфазний шум незмінним. Якщо на частоті 5 МГц прилад провалює сертифікацію через випромінювання кабелю живлення, це стовідсоткова ознака синфазної завади, яку неможливо усунути без синфазного дроселя та Y-конденсаторів.

### Анатомія вхідного ЕМС-фільтра

Повний промисловий вхідний фільтр мережі живлення являє собою багатоланкову структуру, що містить конденсатори класу X, конденсатори класу Y, синфазний дросель з індуктивністю розсіювання, розрядний резистор та демпфувальні ланцюжки.

![Схемотехнічна анатомія дволанкового вхідного ЕМС-фільтра](/root/hw/hw-power/emi-filter/img/filter-topology-breakdown.svg)
*Анатомія дволанкового вхідного ЕМС-фільтра: плівкові конденсатори C_X1, C_X2 разом з індуктивністю розсіювання L_leak формують диференціальний П-фільтр; синфазний дросель L_cm та Y-конденсатори C_Y1, C_Y2 відводять синфазний струм у захисне заземлення PE; ланцюжок R_d + C_d гасить резонансний пік імпедансу за критерієм Міддлбрука.*

#### X-конденсатори та розрядний резистор

**X-конденсатори** встановлюються безпосередньо між фазним (L) та нейтральним (N) проводами (або між `+` та `-` шинами DC). Їхнє завдання — створити низький імпеданс для диференціального високочастотного струму завади, замикаючи його локально біля перетворювача й не пускаючи в мережу.

Позначення «X» вказує на міжнародний клас безпеки (за стандартом IEC 60384-14). Конденсатори цього класу підключаються між лініями живлення, де їхній електричний пробій не створює прямої загрози ураження людини електричним струмом (оскільки корпус приладу не задіяний), але може спричинити коротке замикання мережі та пожежу. За рівнем стійкості до високовольтних імпульсів у мережі X-конденсатори поділяються на три підкласи:
- **X1**: витримують пікові імпульсні перенапруги понад 2.5 кВ і до 4.0 кВ (застосовуються в промисловому обладнанні з жорсткими перехідними процесами);
- **X2**: витримують імпульси до 2.5 кВ (найпоширеніший стандартний клас для побутової та комерційної апаратури, що живиться від мережі 230 В);
- **X3**: витримують імпульси до 1.2 кВ (для слабкострумових мереж).

Конструктивно X-конденсатори виготовляються з металізованої поліпропіленової плівки (MKP) або металопаперу (MP). Вони мають властивість **самовідновлення** (англ. *self-healing*): у разі локального пробою діелектрика високовольтним імпульсом тонкий шар металізації товщиною в частки мікрона навколо точки пробою миттєво випаровується електричною дугою, ізолюючи дефектне місце без утворення струмопровідного вугільного містка. Конденсатор втрачає мізерну частку ємності (менше 0.1%), але зберігає працездатність і не переходить у стан короткого замикання.

**Розрядний резистор (Bleeder Resistor)** підключається паралельно вхідному конденсатору `C_X1`. Якщо прилад вимикають з розетки в момент амплітудного піка мережевої синусоїди (325 В для мережі 230 В), конденсатор `C_X1` залишається зарядженим до повної напруги. Якщо людина торкнеться відкритих штирів вилки, накопичений заряд розрядиться через її тіло. Стандарти безпеки (IEC 62368-1, IEC 60950) вимагають, щоб напруга на вилці спадала до безпечного рівня (нижче 60 В) за час не більше 1 секунди після відключення (для обладнання з ємністю X понад 0.1 мкФ).

Постійна часу розряду `τ` визначається добутком:

```
τ = R_bleed · C_X
```

Для конденсатора `C_X = 0.47 мкФ` резистор `R_bleed = 1 МОм` забезпечує постійну часу `τ = 0.47 с`. За час `t = 2 · τ ≈ 0.94 с` напруга на вилці спадає з 325 В до `325 · e⁻² ≈ 44 В`, що повністю відповідає нормам безпеки. У сучасних енергоефективних блоках живлення замість постійного резистора застосовують спеціалізовані мікросхеми активного розряду (наприклад, Power Integrations CAPZero), які відключають розрядний резистор під час нормальної роботи, усуваючи постійні втрати потужності 50–100 мВт.

#### Синфазний дросель та індуктивність розсіювання

**Синфазний дросель** (англ. *common-mode choke, CMC*; від нім. *Drossel* — звуження/задушення, або англ. *choke* — душити) являє собою дві симетричні обмотки з однаковою кількістю витків, намотані на спільному магнітопроводі з високою магнітною проникністю.

Фізичний принцип роботи синфазного дроселя базується на векторному додаванні та відніманні магнітних потоків:
1. **Диференціальний робочий струм** тече через першу обмотку в перетворювач і повертається через другу обмотку в протилежному напрямку. Оскільки струми рівні за величиною і протилежні за знаком (`I_L = -I_N`), магнітні потоки, збуджені цими струмами в осерді, повністю компенсують один одного:
```
Φ_net,DM = Φ_L - Φ_N = 0
```
Магнітний потік у фериті дорівнює нулю. Дросель не створює індуктивного опору для корисного струму живлення і не насичується навіть за значних робочих струмів (десятки амперів).
2. **Синфазний струм завади** тече в одному напрямку по обох обмотках (`I_CM / 2`). Магнітні потоки двох обмоток мають однаковий знак і додаються в осерді:
```
Φ_net,CM = Φ_L + Φ_N = 2 · Φ_L
```
Магнітопровід створює для синфазного струму повну індуктивність `L_CM`, що формує високий реактивний опір `X_L = 2π · f · L_CM`, блокуючи поширення завади в мережу.

Як магнітопроводи для синфазних дроселів використовують тороїди з високопроникних марганець-цинкових феритів (MnZn з початковою проникністю `μ_i = 5000..15000`) або сучасні нанокристалічні сплави на основі заліза (Finemet, Vitroperm з проникністю `μ_i = 30000..100000`). Нанокристалічні осердя зберігають високу проникність на частотах до декількох мегагерців і мають високу індукцію насичення (`B_sat = 1.2 Тл` проти `0.4 Тл` у фериту), що дозволяє зменшити масу й габарити дроселя в 2–3 рази.

**Індуктивність розсіювання (Leakage Inductance).** У реальному дроселі коефіцієнт магнітного зв'язку між обмотками не є ідеальним (`k < 1`), оскільки частина магнітних ліній замикається через повітря між витками, не пронизуючи сусідню обмотку. Цей незчеплений магнітний потік створює **індуктивність розсіювання** `L_leak`:

```
L_leak = 2 · (1 - k) · L_CM
```

Типово величина `L_leak` становить від 0.5% до 2% від номінальної синфазної індуктивності `L_CM` для тороїдальної намотки з протилежним розташуванням секцій (і до 0.1% для біфілярної намотки). Якщо синфазний дросель має номінал `L_CM = 10 мГн`, його індуктивність розсіювання становить від 50 до 200 мкГн.

Ця паразитна індуктивність розсіювання є надзвичайно корисною: вона діє як чистий **диференціальний дросель**, включений послідовно в кожну живильну лінію. Працюючи разом із вхідними X-конденсаторами, `L_leak` утворює високоефективний П-подібний фільтр диференціальної завади другого порядку, що усуває потребу встановлювати на плату окремі громіздкі диференціальні котушки.

#### Y-конденсатори та обмеження струму витоку на захисне заземлення

**Y-конденсатори** підключаються між кожною лінією живлення (L та N) та шиною захисного заземлення PE (металевим корпусом пристрою). Разом із синфазним дроселем вони утворюють низькочастотний Г-подібний або П-подібний фільтр синфазної завади: дросель створює високий послідовний опір, а Y-конденсатори створюють паралельне плече з низьким імпедансом, відводячи залишки синфазного струму завади назад у корпус до того, як вони потраплять у кабель живлення.

Конденсатори класу Y підлягають найсуворішим вимогам електробезпеки, оскільки вони з'єднують фазний провід із металевим корпусом, до якого може доторкнутися людина. Електричний пробій Y-конденсатора призводить до появи небезпечного потенціалу 230 В на корпусі приладу. Якщо захисне заземлення виявиться обірваним, дотик до корпусу призведе до смертельного ураження струмом.

За стандартом IEC 60384-14 конденсатори класу Y поділяються на підкласи:
- **Y1**: подвійна або посилена ізоляція, витримують випробувальний імпульс напруги до 8.0 кВ при робочій змінній напрузі до 500 В;
- **Y2**: базова або додаткова ізоляція, витримують імпульс до 5.0 кВ при змінній напрузі до 300 В (стандарт для більшості мережевих приладів);
- **Y4**: витримують імпульси до 2.5 кВ при напрузі до 150 В.

Конденсатори Y виготовляються з високоякісної багатошарової кераміки спеціальних безпечних серій або металізованого паперу з гарантованою відмовою виключно в режим обриву кола (відкритий розрив), унеможливлюючи коротке замикання обкладок.

**Критичне обмеження: струм витоку на землю (Leakage Current).** Навіть абсолютно справний Y-конденсатор пропускає через себе реактивний змінний струм промислової частоти 50/60 Гц. Реактивний ємнісний опір конденсатора на частоті мережі `f_line`:

```
X_C = 1 / (2π · f_line · C_Y)
```

Струм витоку через один конденсатор від фазного проводу `V_line = 230 В` у землю становить:

```
I_leak = V_line / X_C = 2π · f_line · C_Y · V_line
```

Якщо захисний провід заземлення PE буде пошкоджено або обірвано в розетці, цей струм витоку потече через тіло людини, яка торкнеться металевого корпусу. Міжнародні стандарти електробезпеки встановлюють жорстку стелю максимального струму витоку:
- **Медичне обладнання (IEC 60601-1, тип CF):** `I_leak_max ≤ 0.01..0.05 мА` (10–50 мкА);
- **Медичне обладнання (тип B/BF):** `I_leak_max ≤ 0.1..0.5 мА` (100–500 мкА);
- **Портативна побутова та офісна техніка (IEC 62368-1, Class I):** `I_leak_max ≤ 0.75 мА`;
- **Стаціонарне промислове обладнання:** `I_leak_max ≤ 3.5 мА`.

**Приклад розрахунку ліміту ємності Y-конденсаторів.**
Розрахуємо граничну сумарну ємність Y-конденсаторів для приладу класу I з лімітом струму витоку `I_leak = 0.5 мА` у мережі 230 В, 50 Гц:

```
C_Y,total_max = I_leak / (2π · f_line · V_line)
              = 0.5×10⁻³ / (2π · 50 · 230)            [підстановка параметрів мережі та ліміту струму]
              = 0.5×10⁻³ / 72256.6                    [обчислення знаменника]
              ≈ 6.92×10⁻⁹ Ф = 6.92 нФ                 [ділення чисел]
```

Оскільки в схемі встановлено два Y-конденсатори (від L до PE та від N до PE), з урахуванням допуску на ємність (±20%) та підвищення напруги мережі до 250 В номінал кожного окремого конденсатора не повинен перевищувати **2.2–3.3 нФ**.

> 🔧 **Навіщо це.** Стеля струму витоку на землю — це фундаментальне обмеження безпеки, яке не можна порушувати. Через те, що ємність Y-конденсаторів затиснута на рівні кількох нанофарадів, отримати необхідні 40–50 дБ затухання синфазної завади за рахунок одних лише конденсаторів неможливо. Відсутню фільтрацію зобов'язаний компенсувати синфазний дросель, чию індуктивність доводиться нарощувати до 5–20 мГн.

### Еквівалент мережі LISN та вимірювання внесених втрат

Сертифікаційні випробування кондуктивних завад неможливо проводити шляхом прямого вмикання приладу у звичайну настінну розетку. Імпеданс реальної електромережі непередбачувано коливається від 1 до 100 Ом залежно від довжини проводів, типу проводки та кількості сусідніх увімкнених споживачів. Без нормованого навантаження виміри будуть неповторюваними між різними лабораторіями.

Для створення стандартизованого вимірювального середовища між мережею живлення та досліджуваним пристроєм (EUT, Equipment Under Test) включають **еквівалент мережі** — LISN (англ. *Line Impedance Stabilization Network*, або штучна мережа AMN за CISPR 16-1-2).

![Схема вимірювання кондуктивних завад з еквівалентом мережі](/root/hw/hw-power/emi-filter/img/lisn-measurement-setup.svg)
*Схема стенду сертифікаційного вимірювання завад з еквівалентом мережі LISN: дроселі 50 мкГн розв'язують пристрій від коливань імпедансу електромережі; вимірювальні порти 50 Ом передають нормований сигнал шуму на вхід аналізатора спектра.*

LISN виконує три фундаментальні завдання:
1. Задає стабільний нормований високочастотний імпеданс лінії живлення — рівно **50 Ом** у смузі від 150 кГц до 30 МГц відносно землі для кожної фази (схема 50 мкГн + 5 Ом || 50 Ом).
2. Фільтрує та блокує всі сторонні шуми, радіозавади й перешкоди, що надходять із зовнішньої живильної електромережі.
3. Містить внутрішній розділовий конденсатор 0.1 мкФ, який відсікає напругу живлення 50/60 Гц або постійну напругу, направляючи високочастотний сигнал шуму на калібрований 50-омний коаксіальний вхід вимірювального приймача або аналізатора спектра.

Ефективність вхідного фільтра кількісно характеризується величиною **внесених втрат** (англ. *Insertion Loss, IL*), що вимірюється в децибелах:

```
IL(f) = 20 · log10(|V_unfiltered(f) / V_filtered(f)|)
```

де `V_unfiltered(f)` — спектральна амплітуда напруги завади на вимірювальному терміналі 50 Ом LISN без фільтра, а `V_filtered(f)` — напруга після встановлення фільтра.

Детальний числовий алгоритм розрахунку частотної характеристики внесених втрат фільтра з урахуванням комплексної матриці LISN та паразитних параметрів компонентів наведено у вставці про [програмну симуляцію вхідного ЕМС-фільтра та розрахунок АЧХ затухання](root:hw-power/emi-filter/proj-filter-simulation.md).

### Взаємодія фільтра з перетворювачем: критерій стійкості Міддлбрука

Найнебезпечніша пастка під час додавання вхідного ЕМС-фільтра полягає в тому, що фільтр, який бездоганно виконує вимоги затухання завад, може раптово зруйнувати стабільність замкненого імпульсного стабілізатора, перетворивши схему на потужний низькочастотний автогенератор.

Фізична причина криється в поведінці імпульсного перетворювача із замкненою петлею регулювання. Стабілізатор напруги підтримує сталу напругу на навантаженні, споживаючи незмінну потужність `P_in = const`. Якщо вхідна напруга живлення зростає, петля зворотного зв'язку зменшує коефіцієнт заповнення ключів, щоб зменшити вхідний струм, і навпаки: при падінні вхідної напруги стабілізатор збільшує споживання струму для компенсації.

Диференціальний малосигнальний вхідний опір перетворювача `r_in` є строго **від'ємним**:

```
r_in = dV_in / dI_in = -V_in0² / P_in
```

На низьких частотах (у межах смуги пропускання петлі зворотного зв'язку `f < f_c`) перетворювач діє як ідеальний від'ємний резистор.

![Критерій стійкості Міддлбрука: імпеданс фільтра проти перетворювача](/root/hw/hw-power/emi-filter/img/middlebrook-impedance-overlap.svg)
*Критерій стійкості Міддлбрука на логарифмічній площині імпедансів: червоний недемпфований пік вихідного імпедансу фільтра Z_out перевищує вхідний динамічний опір перетворювача Z_in, спричиняючи автоколивання; зелена крива демпфованого фільтра (R_d + C_d) лежить значно нижче Z_in з гарантованим інженерним запасом ΔM ≥ 6 дБ.*

Вхідний LC-фільтр є коливальним контуром із власною резонансною частотою `f_0 = 1 / (2π · √(L_f · C_f))`. Якщо опір втрат дроселя малий, на частоті резонансу вихідний імпеданс фільтра `Z_out(s)` має гострий пік добротності:

```
|Z_out(j·ω_0)| = Q_0 · R_0 = √(L_f / C_f) / R_s
```

Якщо цей резонансний пік перевищує за модулем динамічний опір перетворювача:

```
|Z_out(j·ω_0)| ≥ |r_in|
```

пасивні втрати фільтра повністю компенсуються від'ємним опором перетворювача. Сумарний еквівалентний опір контуру стає меншим або рівним нулю, що формує пару полюсів у правій комплексній півплощині. Система втрачає стійкість і переходить у режим автоколивань великої амплітуди на частоті резонансу вхідного фільтра.

У 1976 році професор Каліфорнійського технологічного інституту Роберт Девід Міддлбрук сформулював фундаментальний закон стійкості вхідних кіл живлення: **модуль вихідного імпедансу вхідного фільтра повинен бути значно меншим за модуль вхідного імпедансу перетворювача на всіх частотах**:

```
|Z_out,filter(s)| ≪ |Z_in,converter(s)|
```

Історію відкриття цього ефекту під час розробки аерокосмічних систем живлення викладено в нарисі про [історію відкриття взаємодії фільтра з перетворювачем Девідом Міддлбруком](root:hw-power/emi-filter/hist-middlebrook-criterion.md).

**Паралельне RC-демпфування за Міддлбруком.** Для придушення резонансного піку `Z_out` паралельно основному фільтрувальному конденсатору `C_f` встановлюють демпфувальну гілку з послідовно з'єднаних резистора `R_d` та блокувального конденсатора `C_d`.

Конденсатор `C_d` обирають у 3–5 разів більшим за `C_f` (`n = C_d / C_f = 3..5`). Оптимальний демпфувальний резистор розраховується за формулою:

```
R_d,opt = √(L_f / C_f) · √((2 + n) · (4 + 3·n) / (2 · n² · (4 + n)))
```

Такий розрахунок зрізає добротність контуру до безпечного рівня `Q ≤ 1.2`, обмежуючи максимальний імпеданс фільтра величиною `|Z_out|_max ≤ 1.22 · √(L_f / C_f)` та забезпечуючи гарантований запас стійкості `ΔM ≥ 6 дБ`.

Повний математичний вивід передатних функцій демпфованого фільтра та аналітичну оптимізацію компонентів наведено у вставці про [виведення критерію Міддлбрука та розрахунок демпфування](root:hw-power/emi-filter/math-middlebrook-criterion.md).

### Паразитні ефекти та частотний колапс фільтра

На високих частотах (понад 5–10 МГц) реальна АЧХ фільтра різко відхиляється від теоретичного розрахунку через прояв паразитних параметрів компонентів та друкованого монтажу.

1. **Власна індуктивність виводів конденсаторів (ESL).**
Реальний конденсатор `C` має паразитну індуктивність виводів та обкладок `L_esl` (типово 5–15 нГн для плівкових X-конденсаторів та 1–3 нГн для керамічних Y-конденсаторів). На частоті власного послідовного резонансу:
```
f_srf = 1 / (2π · √(C · L_esl))
```
імпеданс конденсатора досягає мінімуму, а вище цієї частоти починає лінійно зростати як `ω · L_esl`. Плівковий конденсатор ємністю 0.47 мкФ із виводами довжиною 10 мм (`ESL = 10 нГн`) має частоту резонансу всього 2.3 МГц. На частоті 25 МГц його реактивний опір становить не розрахункові 0.013 Ом, а понад 1.5 Ом, що знижує ефективність диференціальної фільтрації майже на 40 дБ.

2. **Міжвиткова ємність дроселя (EPC).**
Синфазний дросель з індуктивністю 5–10 мГн містить десятки витків тонкого дроту. Ємність між сусідніми витками та протилежними шарами намотки утворює еквівалентну паралельну ємність `C_epc` величиною 10–30 пФ. Ця ємність утворює з індуктивністю паралельний коливальний контур (антирезонанс) на частотах 500 кГц – 1.5 МГц. Вище частоти антирезонансу струм завади тече не через витки дроселя, а напряму через паразитну ємність `C_epc`, минаючи магнітопровід. На частоті 20 МГц імпеданс дроселя падає з розрахункових 500 кОм до кількох сотень ом.

3. **Паразитний ємнісний та магнітний зв'язок (Crosstalk) на друкованій платі.**
Якщо вхідні фільтровані клеми розташовані поруч із нефільтрованими вихідними провідниками або комутаційним вузлом SW, паразитний зв'язок між доріжками передає високочастотний шум в обхід усіх компонентів фільтра:
- **Паразитна ємність зв'язку:** навіть мізерна ємність монтажу `C_mut = 0.5 пФ` між входом і виходом фільтра на частоті 30 МГц має опір `X_C = 1 / (2π · 30×10⁶ · 0.5×10⁻¹²) ≈ 10.6 кОм`. Для синфазного джерела завад напругою 100 В цей паразитний шлях пропускає струм 9.4 мА, що створює на 50-омному вимірювальному порту LISN напругу шуму понад 70 дБмкВ, повністю перекреслюючи роботу фільтра.
- **Взаємна індуктивність контурів:** струм швидкого перемикання силового контуру генерує змінне магнітне поле, яке наводить ЕРС у вхідних доріжках живлення.

**Правила просторового трасування вхідного фільтра на платі:**
- **Суворе лінійне зонування:** фільтр розводиться виключно по прямій лінії від вхідного рознімача до виходу, без зворотних петель і без наближення вихідних кіл до вхідних.
- **Бар'єр під дроселем:** під синфазним дроселем повністю видаляють полігони заземлення та сигнальні доріжки на всіх шарах плати, щоб виключити паразитну ємнісну ємність між обмотками та землею.
- **Зіркове підключення Y-конденсаторів:** виводи заземлення конденсаторів Y1/Y2 з'єднують безпосередньо з металевим шасі приладу в одній точці за допомогою короткого гвинта або масивного полігону з мінімальною довжиною доріжки (індуктивність траси заземлення має бути менше 2–3 нГн).

### Покроковий інженерний розрахунок і вибір компонентів

Спроєктуємо вхідний фільтр для мережевого джерела живлення потужністю 120 Вт (зворотноходовий перетворювач Flyback) із такими вихідними параметрами ТЗ:
- Напруга живлення: AC 230 В (діапазон 185–265 В, 50 Гц)
- Частота комутації: `f_sw = 100 кГц`, ККД `η = 0.88` (вхідна потужність `P_in = 136 Вт`)
- Максимальний дозволений струм витоку на заземлення: `I_leak_max = 0.5 мА` (Class I)
- Результати вимірювання власного шуму без фільтра:
  * Диференціальний шум на першій гармоніці (100 кГц): `V_DM,raw = 92 дБмкВ`
  * Синфазний шум на частоті 500 кГц: `V_CM,raw = 86 дБмкВ`
- Вимоги стандарту CISPR 32 Class B (квазіпік):
  * Ліміт на 150 кГц: 66 дБмкВ (необхідне затухання на 100–150 кГц: `Att_DM ≥ 92 - 66 + 6 дБ (запас) = 32 дБ`)
  * Ліміт на 500 кГц: 56 дБмкВ (необхідне затухання: `Att_CM ≥ 86 - 56 + 10 дБ (запас) = 40 дБ`)

**Крок 1. Розрахунок ємності Y-конденсаторів за струмом витоку.**

```
C_Y,max = I_leak_max / (2π · f_line · V_line,max · 2)
        = 0.5×10⁻³ / (2π · 50 · 265 · 2)              [підстановка параметрів для двох конденсаторів]
        = 0.5×10⁻³ / 166504                           [обчислення знаменника]
        ≈ 3.0×10⁻⁹ Ф = 3.0 нФ                         [розрахунок граничної ємності]
```

Обираємо найближчий стандартний номінал конденсаторів класу Y2: **`C_Y1 = C_Y2 = 2.2 нФ`**.
Сумарна ємність для синфазного струму: `C_Y,total = 2 · C_Y = 4.4 нФ`.

**Крок 2. Розрахунок синфазного дроселя (L_CM).**
Для фільтра другого порядку (дросель `L_CM` + конденсатори `C_Y,total`) затухання після частоти зрізу спадає зі швидкістю 40 дБ/дек.
Щоб отримати затухання `Att_CM = 40 дБ` на частоті `f = 500 кГц`, частота зрізу синфазного фільтра `f_cut,CM` повинна бути у 10 разів нижчою (`40 дБ = 2 декади` по 20 дБ/дек, тобто частота зрізу у `√100 = 10` разів нижча):

```
f_cut,CM = 500 кГц / 10 = 50 кГц                      [визначення частоти зрізу]
```

Знаходимо необхідну індуктивність дроселя:

```
L_CM = 1 / ( (2π · f_cut,CM)² · C_Y,total )
     = 1 / ( (2π · 50×10³)² · 4.4×10⁻⁹ )              [підстановка f_cut = 50 кГц та C_Y = 4.4 нФ]
     = 1 / ( 9.8696×10¹⁰ · 4.4×10⁻⁹ )                 [піднесення до квадрата 2π·f]
     = 1 / 434.26                                     [множення чисел у знаменнику]
     ≈ 2.3×10⁻³ Гн = 2.3 мГн                          [обчислення індуктивності]
```

Обираємо стандартний промисловий тороїдальний дросель з номіналом **`L_CM = 3.3 мГн`** (номінальний струм 1.5 А, опір обмотки `DCR = 0.08 Ом`).

**Крок 3. Розрахунок X-конденсаторів та використання індуктивності розсіювання.**
Синфазний дросель із роздільною намоткою має коефіцієнт розсіювання близько 1.5%:

```
L_leak = 0.015 · L_CM = 0.015 · 3.3 мГн ≈ 50 мкГн
```

Щоб забезпечити затухання диференціальної завади `Att_DM = 32 дБ` на частоті `f = 100 кГц`, частота зрізу диференціальної ланки повинна становити:

```
f_cut,DM = 100 кГц / 10^(32 / 40)
         = 100 кГц / 10^0.8                           [ділення 32/40 = 0.8]
         = 100 кГц / 6.31                             [степінь 10^0.8 ≈ 6.31]
         ≈ 15.8 кГц                                   [обчислення частоти зрізу DM]
```

Розраховуємо сумарну еквівалентну ємність X-ланки:

```
C_X,total = 1 / ( (2π · f_cut,DM)² · L_leak )
          = 1 / ( (2π · 15.8×10³)² · 50×10⁻⁶ )        [підстановка f_cut = 15.8 кГц та L_leak = 50 мкГн]
          = 1 / ( 9.85×10⁹ · 50×10⁻⁶ )                [обчислення (2π·f)²]
          = 1 / 492500                                [множення у знаменнику]
          ≈ 2.03×10⁻⁶ Ф = 2.03 мкФ                    [розрахунок сумарної ємності]
```

Розподіляємо ємність на два X2-конденсатори на вході та виході фільтра: **`C_X1 = 0.47 мкФ`** та **`C_X2 = 0.47 мкФ`** (разом із паралельною демпфувальною ємністю).

**Крок 4. Розрахунок демпфування за критерієм Міддлбрука.**
Визначаємо найменший за модулем вхідний динамічний опір перетворювача при мінімальній випрямленій напрузі шини DC (`V_in,min = 185 В · √2 ≈ 260 В`):

```
|r_in,min| = V_in,min² / P_in
           = 260² / 136                               [підстановка V_in = 260 В та P_in = 136 Вт]
           = 67600 / 136                              [піднесення до квадрата 260²]
           ≈ 497 Ом                                   [обчислення динамічного опору]
```

Розраховуємо характеристичний опір диференціального контуру (`L_leak = 50 мкГн`, `C_X = 0.47 мкФ`):

```
R_0 = √(L_leak / C_X)
    = √(50×10⁻⁶ / 0.47×10⁻⁶)                          [підстановка L_leak та C_X]
    = √106.38                                         [ділення під коренем]
    ≈ 10.3 Ом                                         [обчислення характеристичного опору]
```

Обираємо коефіцієнт ємності демпфера `n = 4`:

```
C_d = 4 · C_X = 4 · 0.47 мкФ = 1.88 мкФ    [номінал: 2.2 мкФ електролітичний або плівковий]
```

Розраховуємо оптимальний резистор демпфування:

```
R_d,opt = R_0 · √((2 + 4)·(4 + 3·4) / (2 · 16 · (4 + 4)))
        = 10.3 · √(96 / 256)                          [спрощення чисельника й знаменника під коренем]
        = 10.3 · 0.6124                               [добування квадратного кореня √0.375]
        ≈ 6.3 Ом                                      [номінал: 6.2 Ом або 6.8 Ом, 0.5 Вт]
```

Максимальний піковий вихідний імпеданс демпфованого фільтра:

```
|Z_out|_max = R_0 · √((2 + 4) / 4)
            = 10.3 · √1.5                             [підстановка n = 4]
            = 10.3 · 1.225                            [обчислення кореня √1.5]
            ≈ 12.6 Ом                                 [піковий імпеданс фільтра]
```

Перевірка запасу стійкості Міддлбрука:

```
|Z_out|_max = 12.6 Ом ≪ |r_in,min| = 497 Ом
Запас стійкості: 497 / 12.6 ≈ 39.4 (31.9 дБ ≫ 6 дБ)
```

Система має абсолютну динамічну стійкість та гарантує виконання нормативів CISPR 32 Class B у всьому діапазоні навантажень.
