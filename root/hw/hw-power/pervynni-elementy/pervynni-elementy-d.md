- [Саморозряд батареї](root:hw-power/self-discharge) — механізми витоку заряду при зберіганні та вплив температури.
- [Просадка під навантаженням](root:hw-power/battery-sag) — внутрішній опір (ESR), падіння напруги при імпульсному струмі.

Автономний ультразвуковий лічильник води, заглиблений у ґрунтовий колодязь, бездротовий датчик вібрації на магістральному газопроводі або мітка відстеження контейнерів у трансокеанському плаванні мають працювати без обслуговування від 10 до 20 років. Класичний літій-іонний акумулятор у таких умовах втрачає працездатність уже через два-три роки: його власний фоновий [саморозряд](root:hw-power/self-discharge) становить 2–5% на місяць, а хімічна деградація електроліту й сепаратора незворотно знижує ємність навіть за нульового навантаження. Коли пристрій фізично неможливо під'єднати до електромережі чи сонячної панелі для періодичного підзаряджання, єдиним технічно виправданим вибором стають первинні (неперезаряджувані) хімічні джерела струму.

### Електрохімія первинних систем: чому незворотність дає виграш

Первинний хімічний елемент (лат. *primarius* — первинний, головний, від *primus* — перший; на честь італійського фізика Луїджі Гальвані, італ. *Luigi Galvani*) перетворює енергію спонтанної окисно-відновної реакції на електричну роботу безпосередньо й одноразово. 

На відміну від вторинних джерел (акумуляторів), де матеріали електродів зобов'язані витримувати сотні й тисячі циклів розширення та стиснення кристалічної решітки при зворотному русі іонів (інтеркаляції), первинна комірка оптимізується лише під один прямий напрямок хімічного перетворення.

Ця фундаментальна відмінність забезпечує первинним системам три вирішальні інженерні переваги:

1. **Екстремальна питома енергетична густина**: відсутність важких струмопровідних каркасів подвійного призначення, полімерних зв'язуючих та масивних струмознімачів дозволяє заповнити майже весь внутрішній об'єм сталевого корпусу активною речовиною. Питома [густина енергії](root:hw-power/energy-density) літій-тіонілхлоридних елементів сягає `650–700 Вт·год/кг` та `1200 Вт·год/л`, що у 2.5–3 рази перевищує показники найкращих серійних Li-ion акумуляторів формату 18650.
2. **Мізерний річний саморозряд**: завдяки природній хімічній пасивації електродів швидкість паразитних бічних реакцій знижується до `< 0.5–1.0%` на рік при кімнатній температурі.
3. **Широкий температурний діапазон**: неорганічні рідкі та твердотільні катоди зберігають рухливість носіїв заряду від `-55 °C` до `+85 °C` (а спеціальні високотемпературні виконання для буріння свердловин — до `+125...+150 °C`), де звичайні акумулятори замерзають або руйнуються через незворотне наростання металевих дендритів.

У сучасній мікроелектроніці та вбудованих системах виділилися три головні класи первинних джерел, кожен із яких займає чітко окреслену інженерну нішу:
- **Лужні елементи (Alkaline `Zn-MnO₂`, `1.5 В`)** — масове побутове живлення низької вартості;
- **Монетні літієві елементи (`CR2032 Li-MnO₂`, `3.0 В`)** — мініатюрне резервне живлення годинників реального часу (RTC) та малопотужних датчиків Bluetooth Low Energy;
- **Літій-тіонілхлоридні елементи (`Li-SOCl₂`, `3.6 В`)** — рекордсмени енергоємності та довговічності для промислового Інтернету речей (IoT), телеметрії (грец. *τῆле*, *tele* — далеко + *μέтроν*, *metron* — вимірювання) та систем комерційного обліку ресурсів.

### Лужні елементи (Alkaline Zn-MnO₂, 1.5 В): масовість, похилий розряд та ризик витоку

Лужний гальванічний елемент (назва походить від араб. *al-qaly* — кальцинований попіл рослин, луг) базується на електрохімічній парі порошкового цинку `Zn` (анод) та діоксиду марганцю `MnO₂` (катод), занурених у концентрований водний розчин гідроксиду калію `KOH` (електроліт — грец. *ἤлектрон*, *elektron* — бурштин + *λυτός*, *lytos* — розчинний).

#### Електрохімічний механізм

На негативному електроді (аноді — грец. *ἄνοδος*, *anodos* — сходження, шлях угору) цинковий порошок у формі густого гелю окиснюється з утворенням цинкат-іонів і подальшим осадженням оксиду цинку:

```
Zn + 2OH⁻ → ZnO + H₂O + 2e⁻
```

На позитивному електроді (катоді — грец. *κάθοδος*, *kathodos* — спуск, шлях униз) діоксид марганцю відновлюється до оксигідроксиду марганцю:

```
2MnO₂ + H₂O + 2e⁻ → 2MnO(OH) + 2OH⁻
```

Сумарна термодинамічна реакція забезпечує початкову електрорушійну силу розімкненого кола (ЕРС) близько `1.55–1.60 В`:

```
Zn + 2MnO₂ → ZnO + 2MnO(OH)
```

#### Похила розрядна крива та вимоги до перетворювача живлення

На відміну від літієвих джерел із плоским плато, напруга лужного елемента знижується плавно й майже лінійно протягом усього розряду: від `1.55 В` у свіжому стані до `1.2 В` при віддачі 50% ємності та `0.9 В` у кінці розряду (напруга відсічки).

```
1.60 В ───┐
          └───-..
1.20 В           └───-.. (50% ємності)
                        └───-..
0.90 В ────────────────────────┴──── (Cutoff)
```

Ця поведінка вимагає від схемотехніки джерела живлення роботи в надзвичайно широкому діапазоні вхідних напруг:
- Для живлення мікроконтролера з фіксованою шиною `3.3 В` від двох послідовних лужних елементів `AA` (2S) сумарна напруга батареї змінюється від `3.1 В` (нова батарея) до `1.8 В` (висаджена). Звичайний лінійний стабілізатор ([LDO](root:hw-power/ldo)) тут принципово не підходить. Необхідно застосовувати підвищувальний імпульсний перетворювач ([Boost](root:hw-power/boost)) або універсальний [Buck-Boost](root:hw-power/buck-boost), здатний стабілізувати вихід при падінні входу нижче робочої напруги мікросхем.

#### Вплив струму розряду: ефект Пойкерта

Паспортна ємність лужного елемента типорозміру `AA` (близько `2500–2800 мА·год`) вимірюється за мізерного струму розряду `10–25 мА` (розряд протягом понад 100 годин). Якщо спробувати живити від такого елемента пристрій із постійним споживанням `500 мА` (наприклад, потужний ліхтар або сервопривід), реальна віддана ємність падає у 2.5–3 рази — до `1000–1200 мА·год`. 

Це прямий прояв [ефекту Пойкерта](root:hw-power/peukert-effect): при високій густині струму іони `OH⁻` у гелевому електроліті не встигають дифундувати до поверхні цинкових гранул, а пори катодного діоксиду марганцю блокуються продуктами неповного відновлення.

#### Механізм витоку електроліту (протікання батарейок)

Головна небезпека тривалої експлуатації лужних елементів у промислових приладах — витік їдкого електроліту. Цинк повільно взаємодіє з водою в лужному розчині навіть без зовнішнього струму, виділяючи газоподібний водень:

```
Zn + 2H₂O → Zn(OH)₂ + H₂↑
```

У міру розряду внутрішній тиск водню всередині сталевого корпусу зростає. Виробники оснащують дно комірки запобіжною мембраною з поліамідного пластику. Під дією надлишкового тиску та капілярного ефекту розчин `KOH` поступово просочується крізь кільцеві ущільнювачі. 

На повітрі гідроксид калію реагує з вуглекислим газом `CO₂`, утворюючи білі кристали карбонату калію `K₂CO₃`:

```
2KOH + CO₂ → K₂CO₃↓ + H₂O
```

Ці кристали мають високу гігроскопічність і електропровідність, що спричиняє швидку електрохімічну корозію пружинних контактів, роз'їдання мідних доріжок друкованої плати та руйнування корпусу приладу. Тому лужні батарейки категорично не застосовують у необслуговуваній апаратурі з розрахунковим терміном роботи понад 3–5 років.

### Монетні літієві елементи (CR2032 Li-MnO₂, 3.0 В): опір та імпульсний бар'єр

Дискові монетні елементи типорозміру `CR2032` (позначення за стандартом IEC: `C` — хімія `Li-MnO₂`, `R` — круглий циліндричний корпус, `20` — діаметр 20.0 мм, `32` — товщина 3.2 мм) стали де-факто стандартом живлення автономних годинників реального часу (RTC) на материнських платах, медичних глюкометрів, автомобільних брелоків та мініатюрних маяків Bluetooth Low Energy (BLE).

#### Електрохімія та конструкція

У комірці `CR2032` анодом слугує диск із високочистого металевого літію, а катодом — пресований твердотільний діоксид марганцю `MnO₂`. Електролітом є розчин солі літію (перхлорату літію `LiClO₄` або трифлату `LiCF₃SO₃`) в органічному апротонному розчиннику (суміші пропіленкарбонату та диметоксиетану).

Конструктивна особливість монетних комірок полягає у розподілі полярності корпусу: зовнішній нікельований сталевий стаканчик (дно та бокова циліндрична стінка) є **позитивним полюсом** (+, катод), тоді як верхня кругла кришка ізольована поліпропіленовим кільцем і є **негативним полюсом** (−, анод).

Реакція розряду базується на твердофазному впровадженні (інтеркаляції) іонів літію в кристалічну решітку діоксиду марганцю без руйнування вихідної структури оксиду:

```
Li + MnO₂ → LiMnO₂
```

Номінальна напруга комірки становить `3.0 В`. На розрядній кривій спостерігається тривале пологе плато на рівні `2.9–2.7 В`, після чого настає крутий спад до кінцевої напруги `2.0 В`.

![Профілі розрядних кривих первинних систем](/root/hw/hw-power/pervynni-elementy/img/discharge-curves.svg)
*Порівняння профілів розрядних кривих: Li-SOCl₂ демонструє горизонтальне плато 3.6 В до 95% розряду; CR2032 плавно знижується від 3.0 до 2.6 В; Alkaline монотонно спадає від 1.5 до 0.9 В.*

#### Внутрішній опір (ESR) та дилема імпульсного струму

Головне фізичне обмеження монетного елемента — його високий внутрішній опір ([ESR](root:hw-power/battery-sag) — *Equivalent Series Resistance*). Через малу площу дискових електродів та помірну іонну провідність органічного електроліту еквівалентний послідовний опір нового елемента `CR2032` становить:
- `10–20 Ом` при температурі `+25 °C`;
- `40–80 Ом` при `0 °C`;
- понад `100–150 Ом` при `-20 °C`;
- зростає до `60–120 Ом` наприкінці терміну служби навіть при кімнатній температурі.

Паспортний номінальний струм безперервного розряду `CR2032` становить лише `0.1–0.2 мА` (при типовій ємності `220–240 мА·год`).

Коли мікроконтролер із радіотрансивером BLE (наприклад, nRF52832 або CC2640) виходить зі стану глибокого сну (де споживає `1–2 мкА`) і вмикає передавач на потужність `+4 дБм`, струм споживання стрибкоподібно зростає до `15–25 мА` на час `5–10 мс`.

Відповідно до закону Ома, на внутрішньому опорі батареї виникає миттєве падіння напруги:

```
ΔU = I_tx · R_esr = 0.020 А · 30 Ом = 0.60 В
```

Якщо напруга розімкненого кола батареї становила `2.7 В`, то в момент передачі напруга на шині живлення мікроконтролера миттєво провалюється:

```
U_vcc = 2.70 В - 0.60 В = 2.10 В
```

Пороги виявлення зниження напруги живлення мікроконтролера ([UVLO](root:hw-power/uvlo) / *Brownout Reset*) зазвичай налаштовані на рівень `2.0–2.2 В`. Стрибок струму призводить до миттєвого перезавантаження процесора в момент виходу в ефір, переривання передачі та зависання пристрою у нескінченному циклі рестартів.

![Просідання напруги CR2032 при радіопередачі](/root/hw/hw-power/pervynni-elementy/img/coin-cell-sag.svg)
*Еквівалентна схема джерела живлення на базі CR2032 та осцилограма напруги під час радіоімпульсу. Без буферного конденсатора напруга падає нижче порогу UVLO.*

#### Схемотехнічне розв'язання: буферні конденсатори

Щоб запобігти збою, паралельно монетному елементу встановлюють резервний буферний конденсатор (танталовий або багатошаровий керамічний `MLCC` ємністю від `100` до `470 мкФ` з низьким струмом власного витоку):

```
+ ───┬──────────────┬─────────────── + Vcc (MCU + BLE)
     │              │
  ┌──┴──┐        ┌──┴──┐
  │     │        │     │
  │ CR  │       === C_buf (100–470 мкФ)
  │2032 │        │ Low Leakage
  │     │        └──┬──┘
  └──┬──┘           │
     │              │
− ───┴──────────────┴─────────────── GND
```

Конденсатор виконує роль гідроакумулятора: під час тривалого глибокого сну він повільно заряджається від батареї мікроамперним струмом. Під час мілісекундного радіоімпульсу основну частину пікового струму постачає накопичений заряд конденсатора, чий ESR становить частки ома, захищаючи слабкий монетний елемент від глибокого просідання.

> 🧮 Точний математичний вивід формули розрахунку ємності буферного конденсатора та аналіз імпульсного просідання наведено у вставці: [Математична модель просідання напруги, розрахунку HLC та ресурсу первинних елементів](root:hw-power/pervynni-elementy/math-pulse-sag.md).

### Літій-тіонілхлорид (Li-SOCl₂, 3.6 В): структура, енергія та екстремальний ресурс

Літій-тіонілхлоридна система (`Li-SOCl₂`) займає перше місце серед усіх промислових хімічних джерел струму за енергетичною щільністю та терміном зберігання.

#### Електрохімія та будова комірки

У елементі `Li-SOCl₂` металевий літій формує негативний електрод (анод). Проте катод не є твердим тілом: його функцію виконує сама рідка речовина електроліту — тіонілхлорид `SOCl₂` (грец. *θεῖον*, *theion* — сірка; ковалентна сполука сірки, кисню та хлору).

Як позитивний струмознімач використовується пористий циліндричний блок із високоочищеного вуглецю (сажі) з величезною питомою площею поверхні.

При розряді на аноді літій віддає електрони:

```
4Li → 4Li⁺ + 4e⁻
```

На поверхні вуглецевого катода молекули рідкого тіонілхлориду відновлюються, приєднуючи електрони:

```
2SOCl₂ + 4e⁻ → 4Cl⁻ + S + SO₂
```

Іони літію та хлору з'єднуються в твердий хлорид літію `LiCl`, який випадає у вигляді нерозчинного осаду в порах вуглецевого катода, а сірка `S` та діоксид сірки `SO₂` розчиняються в рідкому електроліті:

```
4Li + 2SOCl₂ → 4LiCl↓ + S + SO₂
```

Оскільки рідкий деполяризатор безпосередньо контактує з металевим літієм, стандартний електродний потенціал системи досягає рекордних `3.65 В` на одній комірці. 

Розрядна крива `Li-SOCl₂` є майже ідеально горизонтальною: напруга тримається на рівні `3.60–3.65 В` протягом 95% усього життєвого циклу, і лише в останні години перед повним вичерпанням активних речовин різко падає вниз.

### Пасивація літію: фізичний щит і тимчасова пастка

Чому ж металевий літій не реагує з рідким окисником `SOCl₂` миттєво з вибухом чи бурхливим саморозігрівом прямо на полиці складу?

Відповідь криється в явищі **пасивації** (лат. *passivus* — сприйнятливий до зовнішнього впливу, бездіяльний, від *pati* — терпіти, зазнавати). 

У перші мікросекунди після заливання рідкого тіонілхлориду на поверхню металевого літію відбувається пряма хімічна реакція, продуктом якої є мономолекулярний шар кристалів хлориду літію `LiCl`:

```
           ┌────────────────────────┐
           │   Рідкий SOCl₂         │
           ├────────────────────────┤
           │   Плівка кристалів LiCl│ ◄── Діелектрик для електронів,
           ├────────────────────────┤     високий опір для іонів Li⁺
           │   Металевий літій (Li) │
           └────────────────────────┘
```

Кристалічна плівка `LiCl` має унікальну фізичну структуру:
1. Вона є абсолютним електричним ізолятором для електронів, що повністю унеможливлює подальший прямий перенос заряду між металом і розчинником — хімічна реакція саморозряду блокується на 99.9%.
2. Вона має щільну кристалічну решітку, крізь дефекти якої іони `Li⁺` можуть дрейфувати лише під дією зовнішнього електричного поля.

Завдяки цьому природному захисному шару елементи `Li-SOCl₂` мають саморозряд менше ніж `1%` на рік при `+20 °C` і здатні зберігатися понад 20 років.

#### Динамічний провал напруги (TMV) та час затримки

Зворотний бік пасивації — **ефект затримки напруги** (*Voltage Delay*). 

Якщо батарея тривалий час зберігалася на складі або працювала в режимі глибокого мікроамперного сну при підвищеній температурі (`+40...+60 °C`), товщина шару кристалів `LiCl` збільшується. 

Коли прилад раптово вмикає потужне навантаження (струм `50–200 мА`), товстий шар `LiCl` діє як великий послідовний опір (до сотень ом). Напруга на клемах у перші мікросекунди стрімко падає до так званого мінімального перехідного значення (TMV — *Transient Minimum Voltage*), яке може опускатися нижче `2.0 В`. 

Лише в міру протікання струму електричне поле механічно розтріскує та розчиняє шар `LiCl`, внутрішній опір падає, і напруга повертається до номінальних `3.6 В`. Проте час відновлення (депасивації) може становити від десятків мілісекунд до кількох секунд — що гарантовано викличе скидання мікроконтролера по UVLO.

```
Напруга
3.6 В ───┐                             ┌────────── (Робоче плато після депасивації)
         │                             │
         └──┐                       ┌──┘
2.0 В ──────┴─────── TMV ───────────┘
            │◄─── t_delay (мс) ───►│
```

#### Бобінна (Bobbin) проти спіральної (Spiral) конструкції

Щоб оптимізувати елементи під різні сценарії, виробники випускають `Li-SOCl₂` у двох принципово різних конструктивних виконаннях:

| Параметр | Бобінна конструкція (Bobbin) | Спіральна конструкція (Spiral) |
|---|---|---|
| **Внутрішня геометрія** | Суцільний циліндричний катод у центрі, літій на стінках стакана | Щільно скручений рулон із тонкої літієвої фольги, сепаратора та вуглецевої сітки |
| **Площа контакту електродів** | Мала (одиниці `см²`) | Велика (десятки й сотні `см²`) |
| **Питома ємність** | Максимальна (наприклад, типорозмір `AA` = `2600–2700 мА·год`) | Знижена на 25–35% (`AA` = `1600–1900 мА·год`) |
| **Річний саморозряд** | `< 0.7–1.0%` на рік при +20 °C | `2.5–4.0%` на рік (через велику площу) |
| **Максимальний постійний струм** | `10–25 мА` | `500–1500 мА` |
| **Максимальний імпульсний струм**| `50–100 мА` (глибоке просідання TMV) | `1500–3000 мА` (просідання мінімальне) |
| **Розрахунковий термін служби**| 15–25 років | 5–8 років |
| **Типове застосування** | Лічильники води/газу/тепла, логери | Військові радіостанції, аварійні маяки |

### Депасивація та гібридні конденсатори (HLC)

Як поєднати 20-річний ресурс і максимальну ємність бобінної конструкції зі здатністю передавати потужні радіопакети LoRaWAN чи NB-IoT (імпульси до `300–500 мА`) без провалу напруги через пасивацію?

У сучасній інженерії застосовують два взаємодоповнюючі методи:

#### 1. Гібридні шаруваті конденсатори (HLC / PulsesPlus)

Найдосконаліше апаратне рішення — паралельне підключення до бобінного елемента `Li-SOCl₂` спеціалізованого імпульсного накопичувача: гібридного конденсатора HLC (*Hybrid Layer Capacitor*).

![Пасивація Li-SOCl₂ та розв'язання через гібридний конденсатор](/root/hw/hw-power/pervynni-elementy/img/passivation-hlc.svg)
*Зліва — утворення плівки LiCl на поверхні літію та провал напруги під імпульсом; справа — гібридна схема з паралельним HLC, що забезпечує стабільні 3.6 В.*

HLC — це хімічний суперконденсатор із літій-іонною структурою, який має номінальну напругу `3.6–3.9 В`, екстремально низький опір (`ESR = 0.1–0.4 Ом`) та саморозряд менше ніж `1 мкА`.

Розподіл функцій у гібридному тандемі:
- **У режимі глибокого сну**: бобінний елемент `Li-SOCl₂` плавно й повільно підзаряджає HLC мікроамперним струмом.
- **Під час радіопередачі**: конденсатор HLC бере на себе 99% імпульсного навантаження, забезпечуючи струм у сотні міліампер без падіння напруги шини нижче `3.4 В`. Бобінна батарея ніколи не відчуває важких імпульсів, що повністю усуває проблему провалу TMV і захищає структуру від передчасного руйнування.

> 🔌 Детальний розбір характеристик, порівняння з класичними іоністорами та схемотехнічні тонкощі підключення наведено у вставці: [Гібридні конденсатори HLC та імпульсні накопичувачі](root:hw-power/pervynni-elementy/comp-hlc-supercap.md).

#### 2. Програмна контрольована депасивація

Якщо з міркувань вартості чи габаритів конденсатор HLC не встановлено, застосовують програмну депасивацію. На платі встановлюють окремий польовий транзистор із баластним резистором (струм `15–30 мА`), підключений паралельно батареї.

Алгоритм мікроконтролера контролює час спокою: якщо пристрій перебував у глибокому сні понад 30 діб або якщо вбудований датчик температури фіксує переохолодження нижче `0 °C`, перед активацією основного радіомодему процесор відкриває транзистор на `50–100 мс`. Цей контрольований імпульс безпечно руйнує надлишковий шар `LiCl`, відновлюючи низький опір комірки до того, як модем почне передачу.

### Спеціалізовані первинні літієві системи: Li-FeS₂ та Li-CFₓ

Окрім тіонілхлориду та діоксиду марганцю, в інженерній практиці застосовують ще дві високоефективні первинні літієві системи:

1. **Літій-дисульфід заліза (`Li-FeS₂`, `1.5 В`)**: відомий споживачам як батарейки *Energizer Ultimate Lithium*. Має номінальну напругу `1.5 В`, що робить його прямою drop-in заміною звичайних лужних батарейок AA/AAA. Володіє величезними перевагами: у 3–5 разів більша ємність при високих струмах (відсутність ефекту Пойкерта), маса на 33% менша за лужну, термін зберігання 20 років і повна герметичність без ризику протікання електроліту.
2. **Літій-монофторид вуглецю (`Li-CFₓ`, `3.0 В`)**: найвища теоретична питома енергія серед твердотільних катодів (до `600–750 Вт·год/кг`). Не має ефекту рідкої пасивації, абсолютно безпечний і стабільний при температурах до `+85 °C`, тому активно застосовується у військовій авіації, медичних кардіостимуляторах та космічних апаратах.

### Герметичність, безпека та конструктивне виконання

Тривала надійність первинних джерел живлення критично залежить від механічної конструкції корпусу та технології герметизації:

1. **Склометалеві ізолятори (Glass-to-Metal Seal, GTM)**: На відміну від лужних та монетних батарей, які ущільнюються полімерними прокладками (схильними до поступової дифузії вологи та випаровування розчинника), промислові елементи `Li-SOCl₂` мають суцільнозварний корпус із нержавіючої сталі марки 304L або 316L. Центральний позитивний вивід ізолюється спеціальним безлужним склом, звареним зі сталлю при температурі понад `1000 °C`. Це забезпечує витік гелію менше ніж `10⁻⁸ см³/с`, що гарантує збереження рідкого тіонілхлориду понад 25 років.
2. **Запобіжні мембрани аварійного скидання тиску (Safety Vent)**: У разі аварійного перегріву або короткого замикання вбудована лазерно-перфорована мембрана на дні стакана розривається при тиску `15–20 атм`, спрямовано скидаючи гази та запобігаючи руйнуванню приладу.
3. **Вбудовані полімерні запобіжники (PTC)**: У спіральних елементах `Li-SOCl₂` послідовно з виводом встановлюють диск із провідного полімеру зі значним позитивним температурним коефіцієнтом опору. При перевищенні струму `2–3 А` диск миттєво розігрівається, його опір стрибкоподібно зростає в тисячі разів, обмежуючи струм аварійного замикання до безпечних міліамперів.

### Архітектура живлення та енергетичний бюджет на роки

Щоб гарантувати 10–15 років роботи автономного приладу на первинних елементах, класичного підрахунку «поділити ємність батареї на середній струм» недостатньо.

Реальний розрахунок сумарного бюджету ємності враховує чотири незалежні складові:

```
Q_total = Q_sleep + Q_active + Q_self(T) + Q_margin
```

1. **Енергія глибокого сну (`Q_sleep`)**: інтеграл струму мікроконтролера, годинника RTC, компараторів та витоку конденсаторів за 8760 годин на рік (типово `1.5–5.0 мкА` постійно).
2. **Енергія активних сеансів (`Q_active`)**: сума заряду на зняття показів сенсорів (наприклад, `5 мА` протягом `20 мс`) та радіопередачу (наприклад, `120 мА` протягом `50 мс` раз на добу).
3. **Температурно-прискорений саморозряд (`Q_self(T)`)**: розраховується за правилом Вант-Гоффа / Арреніуса — на кожні `10 °C` підвищення середньорічної температури понад `+25 °C` швидкість саморозряду подвоюється.
4. **Коефіцієнт безпечного запасу (`Q_margin`)**: первинний елемент ніколи не проектують під використання 100% паспорта. На практиці закладають коефіцієнт використання `k_use = 0.80–0.85`, оскільки залишок ємності на завершальному крутому коліні розрядної кривої має занадто високий внутрішній опір.

|---|---|---|---|---|---|

| **CR2032 (Li-MnO₂)** | `3.0 В` | `225 мА·год` | `15–30 Ом` | `1–2% / рік` | `0.2 мА` (імпульс 15 мА з C_buf) | RTC, BLE-маяки, ключі авто |

### Інженерний розрахунок кейсів автономного живлення

Розгляньмо три типові практичні сценарії проектування пристроїв з первинними джерелами струму:

#### Сценарій 1: Розумний лічильник води LoRaWAN на 15 років
- **Вимоги**: 15 років безперервної роботи в підземному колодязі (температура `+5...+20 °C`).
- **Профіль споживання**:
  - Режим сну: `2.5 мкА` постійно (годинник RTC та схема зняття імпульсів з геркона).
  - Сеанс зв'язку LoRaWAN: один вихід в ефір раз на добу, струм `120 мА` тривалістю `2.0 с` (передача з високим коефіцієнтом розширення спектра SF12).
- **Розрахунок споживання**:
  - Річний заряд сну: `Q_sleep = 2.5 мкА · 8760 год = 21.9 мА·год / рік`.
  - Річний заряд передач: `Q_tx = 365 · (120 мА · (2.0 / 3600) год) = 24.3 мА·год / рік`.
  - Сумарне корисне річне споживання: `Q_year = 21.9 + 24.3 = 46.2 мА·год / рік`.
  - За 15 років прилад споживе: `Q_15 = 46.2 · 15 = 693 мА·год`.
  - Втрати на саморозряд батареї за 15 років (при 0.7% на рік): близько `270 мА·год`.
  - Повна необхідна ємність із коефіцієнтом запасу 1.25: `Q_req = (693 + 270) · 1.25 = 1203 мА·год`.
- **Вибір джерела**: Одиночний бобінний елемент `Li-SOCl₂ ER14505` (формат AA, номінал `2700 мА·год`) у парі з паралельним гібридним конденсатором `HLC 1520` (`15 Ф`). Батарея забезпечує більш ніж двократний запас ємності, а конденсатор HLC гарантує відсутність просідання напруги під час 120-міліамперних імпульсів передавача LoRaWAN протягом усього 15-річного терміну.

#### Сценарій 2: Ношений BLE-маяк на CR2032
- **Вимоги**: 2 роки роботи від однієї «монетки» `CR2032` (номінал `225 мА·год`).
- **Профіль споживання**:
  - Режим сну: `1.2 мкА` постійно.
  - Рекламний пакет BLE: передача на 3 рекламних канали (37, 38, 39) кожні 1.0 с, середній струм пачки `15 мА` тривалістю `4 мс`.
- **Розрахунок споживання**:
  - Середній струм імпульсів: `I_avg_tx = 15 мА · (0.004 с / 1.0 с) = 60 мкА = 0.060 мА`.
  - Загальний середній струм: `I_total = 0.0012 + 0.060 = 0.0612 мА`.
  - Час життя: `T = (225 мА·год · 0.85) / 0.0612 мА = 3125 годин ≈ 130 днів` (лише 4.3 місяця!).
- **Оптимізація інженерного рішення**: Щоб досягти цільових 2 років (`17 520 годин`), інтервал передачі реклами збільшують до `5.0 секунд`, або зменшують потужність передавача з `+4 дБм` до `0 дБм`. При інтервалі `5.0 с` середній струм падає до `13.2 мкА`, що забезпечує розрахунковий термін служби `1.65 року` (а з урахуванням ємнішого елемента `CR2450` на `600 мА·год` — понад `4.5 роки`).

#### Сценарій 3: Автономний лісовий логер вібрації на лужних батареях
- **Вимоги**: 1 рік роботи від 2 елементів Alkaline AA без підзаряджання.
- **Профіль споживання**:
  - Режим сну: `15 мкА` (MCU в режимі Stop з увімкненим акселерометром).
  - Семплювання вібрації: щохвилини розрахунок швидкого перетворення Фур'є (FFT), струм `8 мА` протягом `100 мс`.
  - Радіопередача: щогодини відправка звіту через субгігагерцовий трансивер `868 МГц`, струм `35 мА` протягом `200 мс`.
- **Розрахунок споживання**:
  - Струм сну: `15 мкА = 0.015 мА`.
  - Середній струм FFT: `8 мА · (0.1 с / 60 с) = 13.3 мкА = 0.0133 мА`.
  - Середній струм передачі: `35 мА · (0.2 с / 3600 с) = 1.94 мкА = 0.00194 мА`.
  - Сумарний середній струм: `I_total = 0.015 + 0.0133 + 0.00194 = 0.0302 мА`.
  - Річне споживання: `Q_year = 0.0302 мА · 8760 год = 265 мА·год`.
- **Висновки щодо надійності**: Дві свіжі лужні батареї AA мають сумарну ємність понад `2400 мА·год` при струмі `30 мкА`, що з десятикратним запасом перекриває річну потребу `265 мА·год`. Проте для запобігання корозії плати від протікання батарейний відсік слід проектувати ізольованим від основної друкованої плати, а пристрій потребує планової заміни елементів кожні 2–3 роки.

### Програмна модель оцінки просідання напруги

Щоб вбудоване програмне забезпечення автономного пристрою могло безпечно керувати сеансами зв'язку, воно повинно містити предиктивну модель розрахунку клемної напруги. Наведений нижче модуль обчислює прогнозовану напругу шини під планованим струмом навантаження та перевіряє безпеку запуску передавача.

:::tabs
```c
#include <stdint.h>
#include <stdbool.h>

/* Прогнозування клемної напруги первинного елемента під імпульсним струмом */
bool battery_check_pulse_safe(uint16_t ocv_mv, 
                              uint32_t pulse_current_ua, 
                              uint32_t esr_milliohm, 
                              uint16_t uvlo_threshold_mv, 
                              uint16_t *predicted_vterm_mv) {
    /* Омічне просідання: ΔU (мВ) = I (мкА) * ESR (мОм) / 10^6 */
    uint32_t sag_mv = ((uint64_t)pulse_current_ua * esr_milliohm) / 1000000ULL;
    
    if (ocv_mv <= sag_mv) {
        if (predicted_vterm_mv) *predicted_vterm_mv = 0;
        return false;
    }
    
    uint16_t vterm_mv = ocv_mv - (uint16_t)sag_mv;
    if (predicted_vterm_mv) {
        *predicted_vterm_mv = vterm_mv;
    }
    
    /* Безпечно, якщо напруга під навантаженням перевищує поріг UVLO з запасом 100 мВ */
    return (vterm_mv >= (uvlo_threshold_mv + 100));
}
```
```cpp
#include <cstdint>
#include <optional>

namespace embedded::power {

struct BatteryPulsePredictor {
    uint32_t esrMilliohm;
    uint16_t uvloThresholdMilliVolts;

    [[nodiscard]] constexpr std::optional<uint16_t> predictVoltage(uint16_t ocvMilliVolts, uint32_t pulseCurrentMicroAmps) const noexcept {
        const uint32_t sagMilliVolts = (static_cast<uint64_t>(pulseCurrentMicroAmps) * esrMilliohm) / 1000000ULL;
        if (ocvMilliVolts <= sagMilliVolts) {
            return std::nullopt;
        }
        return static_cast<uint16_t>(ocvMilliVolts - sagMilliVolts);
    }

    [[nodiscard]] constexpr bool isSafe(uint16_t ocvMilliVolts, uint32_t pulseCurrentMicroAmps, uint16_t marginMilliVolts = 100) const noexcept {
        const auto vterm = predictVoltage(ocvMilliVolts, pulseCurrentMicroAmps);
        return vterm.has_value() && (*vterm >= (uvloThresholdMilliVolts + marginMilliVolts));
    }
};

} // namespace embedded::power
```

### Підсумок теми

Первинні неперезаряджувані елементи забезпечують енергетичну автономність там, де акумулятори безсилі через саморозряд і деградацію. Вибір хімічної системи визначається компромісом між вартістю, напругою, внутрішнім опором та розрахунковим терміном служби пристрою:

1. **Лужні елементи (Alkaline `Zn-MnO₂`, `1.5 В`)** — економічні та загальнодоступні, але страждають від похилої розрядної кривої (`1.5→0.9 В`), високого ефекту Пойкерта під навантаженням та ризику витоку їдкого `KOH` при тривалому зберіганні.
2. **Монетні елементи (`CR2032 Li-MnO₂`, `3.0 В`)** — ідеальні для ультракомпактних пристроїв та RTC із постійним споживанням у частки мікроампера, проте мають високий внутрішній опір (`15–40 Ом`) і вимагають паралельних буферних конденсаторів для згладжування радіоімпульсів BLE.
3. **Літій-тіонілхлоридні елементи (`Li-SOCl₂`, `3.6 В`)** — абсолютні лідери за енергетичною густиною (`650 Вт·год/кг`) та довговічністю (15–20 років із саморозрядом `< 1%/рік`). Їхній головний фізичний феномен — захисна пасивація літію кристалами `LiCl`, яка ефективно вирішується усуненням просідання TMV за допомогою гібридних конденсаторів HLC або програмних циклів депасивації.
