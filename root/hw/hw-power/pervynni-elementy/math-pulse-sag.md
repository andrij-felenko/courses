# 🧮 Математична модель просідання напруги, розрахунку HLC та ресурсу первинних елементів

Математичний розрахунок автономного вузла на первинних хімічних джерелах струму базується на комплексі взаємопов'язаних електрохімічних та термодинамічних моделей: миттєвому омічно-поляризаційному падінні напруги під час імпульсу струму, динамічній поведінці подвійного електричного шару (модель Рендлса), балансі заряду буферного накопичувача (HLC або танталового/керамічного конденсатора) та інтегральній витраті хімічної ємності з урахуванням температурного саморозряду за законом Арреніуса.

---

### 1. Еквівалентна схема Рендлса та компоненти динамічного просідання напруги

Поведінка первинного хімічного елемента під імпульсним навантаженням описується еквівалентною схемою Рендлса, яка враховує об'ємний опір електроліту та металевих струмознімачів `R_ohm`, опір переносу заряду крізь міжфазну межу розділу «електрод — електроліт» `R_ct`, ємність подвійного електричного шару `C_dl` та дифузійний імпеданс Варбурга `Z_w`.

Клемна напруга первинного елемента `U_term(t)` під час імпульсу струму навантаження `I_load` відхиляється від термодинамічної електрорушійної сили розімкненого кола `E_ocv` через три послідовні фізичні внески:

```
U_term(t)
= E_ocv - ΔU_ohm - η_act(t) - η_diff(t)          [загальний баланс потенціалів]
= E_ocv - I_load·R_ohm - η_act(t) - η_diff(t)    [омічний спад: закон Ома для R_ohm]
```

Розглянемо фізичну природу кожної з трьох динамічних складових перенапруги:

1. **Миттєвий омічний стрибок (`ΔU_ohm`)**: відбувається за час менше однієї мікросекунди і визначається питомим електронним опором металевих виводів, пористого вуглецевого матриксу та іонною провідністю рідкого або гелевого електроліту:
```
ΔU_ohm
= I_load · R_ohm                                 [миттєва омічна втрата напруги]
```

2. **Активаційна перенапруга заряду подвійного шару (`η_act(t)`)**: релаксує з характерною сталою часу `τ_ct = R_ct · C_dl` (яка для хімічних джерел становить від сотень мікросекунд до кількох мілісекунд). Вона відображає кінетику подолання енергетичного бар'єру перенесення електрона на межі фаз:
```
η_act(t)
= I_load · R_ct · (1 - e^(-t / (R_ct · C_dl)))   [перехідний процес заряджання C_dl]
```

3. **Дифузійна поляризація Варбурга (`η_diff(t)`)**: зумовлена утворенням градієнта концентрації іонів-реагентів у рідкій фазі біля поверхні електрода. Для коротких імпульсів зв'язку тривалістю до `10–20 мс` дифузійний внесок є незначним і починає суттєво обмежувати напругу лише при тривалому безперервному розряді понад `100–500 мс`.

Для коротких високочастотних імпульсів (пакети Bluetooth Low Energy або короткі опитування сенсорів тривалістю `5–15 мс`) перехідний процес не встигає дійти до дифузійного насичення, і просідання напруги з високою точністю описується спрощеною квазіомічною моделлю з ефективним послідовним опором `R_esr = R_ohm + R_ct`:

```
ΔU_sag
= I_pulse · R_esr                                [миттєвий провал напруги шини живлення]
```

Якщо це просідання перевищує допустимий запас між напругою розімкненого кола `E_ocv` та порогом аварійного вимкнення мікроконтролера `U_uvlo`, пристрій зазнає раптового апаратного скидання (Brownout reset):

```
U_margin
= E_ocv - ΔU_sag - U_uvlo                        [залишковий запас напруги до порогу UVLO]
```

Температурна залежність еквівалентного внутрішнього опору `R_esr(T)` підпорядковується експоненційному закону Арреніуса, оскільки в'язкість електроліту та рухливість сольватованих іонів літію різко падають на холоді:

```
R_esr(T)
= R_0 · e^(E_a / (k_B · T))                      [зростання внутрішнього опору при охолодженні]
```

Через це опір монетки `CR2032` або бобінного елемента `Li-SOCl₂` при похолоданні від `+25 °C` до `-20 °C` збільшується в 3–5 разів.

### 2. Розрахунок мінімальної ємності буферного конденсатора для CR2032

Монетні літієві елементи типу `CR2032` мають номінальну напругу `3.0 В`, проте їхній внутрішній опір становить `R_esr ≈ 25–40 Ом` при кімнатній температурі, а при похолоданні до `-10 °C` зростає до `80–120 Ом`. Максимальний тривалий струм, який можна відбирати безпосередньо з хімічної системи без катастрофічного падіння потенціалу, не перевищує `I_cell_max ≈ 0.5 мА`.

Під час радіопередачі трансивер потребує постійного струму `I_pulse = 20 мА` протягом інтервалу `t_pulse = 8 мс`. Необхідний дефіцит струму `I_cap = I_pulse - I_cell_max` має забезпечити паралельний буферний конденсатор `C_buf` за рахунок власного накопиченого заряду `Q_cap`.

Виведемо аналітичну формулу необхідної ємності:

```
Q_cap
= I_cap · t_pulse                                [заряд, спожитий за час імпульсу]
= (I_pulse - I_cell_max) · t_pulse               [дефіцит струму над можливістю комірки]

ΔU_allowed
= Q_cap / C_buf                                  [зв'язок напруги, заряду та ємності]

C_buf
= Q_cap / ΔU_allowed                             [вираження ємності через допустимий спад]
= (I_pulse - I_cell_max) · t_pulse / ΔU_allowed  [підстановка спожитого заряду імпульсу]
```

**Числовий приклад розрахунку для BLE-маяка:**
- Струм передавача під час пакету: `I_pulse = 20 мА = 0.020 А`
- Граничний струм віддачі батарейки: `I_cell_max = 0.5 мА = 0.0005 А`
- Тривалість імпульсу реклами: `t_pulse = 8 мс = 0.008 с`
- Допустиме просідання напруги шини: `ΔU_allowed = 0.25 В`

```
C_min
= (0.020 - 0.0005) · 0.008 / 0.25                [підстановка вихідних параметрів]
= 0.0195 · 0.008 / 0.25                          [різниця струмів дефіциту]
= 0.000156 / 0.25                                [сумарний заряд дефіциту в Кулонах]
= 0.000624 Ф                                     [результат у Фарадах]
= 624 мкФ                                        [переведення у мікрофаради]
```

З урахуванням температурного коефіцієнта ємності та зниження ємності керамічних конденсаторів під постійною напругою (DC bias effect) обирається номінал `C_buf = 680 мкФ` або пара танталових конденсаторів по `330 мкФ` із наднизьким струмом власного витоку (`< 0.5 мкА`).

### 3. Баланс заряду та час релаксації гібридної пари Li-SOCl₂ + HLC

У системі з бобінним елементом `Li-SOCl₂` та гібридним конденсатором `HLC` ємністю `C_hlc` (типово `15–50 Ф`) імпульс передачі модему LoRaWAN або NB-IoT споживає заряд `Q_burst`:

```
Q_burst
= I_burst · t_burst                              [заряд окремого пакету передачі]

ΔU_hlc
= Q_burst / C_hlc                                [падіння напруги на HLC після пакету]
```

Для пакету LoRaWAN тривалістю `t_burst = 200 мс` зі струмом `I_burst = 120 мА` при ємності `C_hlc = 20 Ф`:

```
Q_burst
= 0.120 А · 0.200 с                              [підстановка струму й тривалості]
= 0.024 Кл                                       [витрачений електричний заряд]

ΔU_hlc
= 0.024 Кл / 20 Ф                                [падіння потенціалу на конденсаторі]
= 0.0012 В                                       [просідання становить лише 1.2 мВ]
```

Після завершення передачі бобінний первинний елемент із власною ЕРС `E_ocv = 3.65 В` та внутрішнім опором `R_cell ≈ 50 Ом` відновлює заряд конденсатора HLC. Струм підзаряджання `i_ch(t)` та напруга на конденсаторі `u_hlc(t)` підпорядковуються класичному диференціальному рівнянню заряджання RC-кола:

```
u_hlc(t)
= E_ocv - (E_ocv - U_min) · e^(-t / (R_cell · C_hlc))   [експоненційне відновлення напруги HLC]
```

Час `t_rec`, необхідний для відновлення `95%` втраченої напруги до цільового рівня `U_target`:

```
(E_ocv - U_target) / (E_ocv - U_min)
= e^(-t_rec / (R_cell · C_hlc))                  [відношення залишкового дефіциту]

- t_rec / (R_cell · C_hlc)
= ln((E_ocv - U_target) / (E_ocv - U_min))       [логарифмування обох частин]

t_rec
= - R_cell · C_hlc · ln((E_ocv - U_target) / (E_ocv - U_min)) [час релаксації напруги]
```

Для екстремального розряду з падінням до `U_min = 3.45 В` при відновленні до `U_target = 3.63 В` (`R_cell = 50 Ом`, `C_hlc = 20 Ф`):

```
t_rec
= - 50 · 20 · ln((3.65 - 3.63) / (3.65 - 3.45))  [підстановка параметрів гібрида]
= - 1000 · ln(0.02 / 0.20)                       [обчислення відношення дефіцитів]
= - 1000 · ln(0.1)                               [спрощення аргументу логарифма]
= - 1000 · (-2.3026)                             [натуральний логарифм 0.1]
= 2302.6 с                                       [час повного відновлення ~38 хвилин]
```

Оскільки просідання напруги `0.02 В` становить менше `1%` робочого діапазону батареї, наступний імпульс зв'язку дозволяється виконувати значно раніше (вже через кілька секунд), оскільки ємність `20 Ф` накопичує величезний надлишковий запас заряду.

### 4. Температурно-скоригована модель сумарного терміну служби

Сумарна хімічна ємність `Q_total`, витрачена пристроєм за `N_years` років експлуатації, складається з трьох незалежних фізичних компонентів: корисної енергії сну `Q_sleep`, енергії активних сеансів зв'язку `Q_active` та втрат на саморозряд `Q_self`:

```
Q_total
= Q_sleep + Q_active + Q_self                    [структура річного споживання]
```

1. **Заряд у режимі сну за рік (`T_year = 8760 год`):**
```
Q_sleep_year
= I_sleep · 8760 год                             [інтеграл струму глибокого сну]
```

2. **Заряд активних сеансів зв'язку за рік (за частоти `n_tx` посилок на добу):**
```
Q_active_year
= (n_tx · 365) · (I_pulse · t_pulse / 3600)      [сумарний заряд передач у мА·год]
```

3. **Саморозряд із температурною корекцією за правилом Арреніуса:**
Швидкість хімічного саморозряду `r_self` зростає приблизно вдвічі на кожні `10 °C` підвищення середньої температури експлуатації понад базові `+25 °C` (температурний коефіцієнт `Q_10 ≈ 2.0`):

```
r_self(T)
= r_base · Q_10^((T_avg - 25) / 10)              [температурна інтенсивність саморозряду]

Q_self_year
= C_nominal · (r_self(T) / 100)                  [втрата номінальної ємності за рік]
```

Загальний розрахунковий термін автономної служби `T_life` (у роках) при номінальній ємності батареї `C_nominal` та коефіцієнті запасу надійності `k_safe = 0.85` (використання не більше 85% паспортної ємності):

```
T_life
= (C_nominal · k_safe) / (Q_sleep_year + Q_active_year + Q_self_year) [прогноз служби у роках]
```
