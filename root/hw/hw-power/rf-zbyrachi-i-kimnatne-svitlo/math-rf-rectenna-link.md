# 🧮 Розрахунок RF-тракту: від рівня випромінювання до випрямленої напруги

Збирання розсіяної радіочастотної енергії (англ. *RF Energy Harvesting*) вимагає наскрізного інженерного розрахунку на кожному етапі перетворення: від ослаблення електромагнітної хвилі в просторі за рівнянням Фрііса до амплітуди напруги на виході пасивного узгоджувального LC-контуру, фізики підпорогового детектування діодами Шотткі та постійної напруги на навантаженні багатокаскадного помножувача. Без точного розрахунку цих ланок розробник ризикує зіткнутися з тим, що вхідна напруга на діодах не подолає навіть порогового бар'єру відкривання, і вся схема виявиться заблокованою в «мертвій зоні».

## 1. Рівняння передачі Фрііса у вільному просторі

Потужність радіосигналу, яку приймає антена на відстані `R` від передавача, визначається формулою Гаральда Фрііса (1946 рік):

```
Pr = Pt · Gt · Gr · (λ / (4 · π · R))²
```

де:
- `Pt` — потужність передавача у ватах (Вт);
- `Gt`, `Gr` — безрозмірні коефіцієнти підсилення передавальної та приймальної антен (відносно ізотропного випромінювача);
- `λ` — довжина електромагнітної хвилі у метрах: `λ = c / f` (де `c ≈ 3·10⁸ м/с`);
- `R` — відстань між антенами у метрах.

У логарифмічній шкалі (децибел-мілівати, дБм) згасання у вільному просторі (FSPL, англ. *Free-Space Path Loss*) записується як:

```
FSPL[дБ] = 20 · lg(R) + 20 · lg(f) + 20 · lg(4 · π / c)
= 20 · lg(R[м]) + 20 · lg(f[Гц]) − 147.55
```

Для частоти Wi-Fi `f = 2.4 ГГц` (`2.4 · 10⁹ Гц`) згасання спрощується:

```
FSPL[дБ] = 20 · lg(R[м]) + 20 · lg(2.4 · 10⁹) − 147.55
= 20 · lg(R[м]) + 187.60 − 147.55
= 20 · lg(R[м]) + 40.05
```

**Приклад обчислення потужності на відстані 2 метри від роутера:**
Якщо Wi-Fi точка доступу випромінює `Pt = +20 дБм` (100 мВт) з антеною `Gt = 2 dBi`, а наш збирач має компактну друковану антену з підсиленням `Gr = 0 dBi` на відстані `R = 2 м`:

```
FSPL(2 м)
= 20 · lg(2) + 40.05       [логарифм відстані 2 м]
= 6.02 + 40.05             [обчислення 20 · 0.301]
= 46.07 дБ                 [сумарне згасання в ефірі]

Pr[дБм]
= Pt + Gt + Gr − FSPL
= 20 + 2 + 0 − 46.07       [підстановка параметрів тракту]
= −24.07 дБм               [прийнята антеною потужність]
```

Переведемо потужність `Pr = −24.07 дБм` у мікровати:

```
Pr[мВт] = 10^(−24.07 / 10)
= 10^(−2.407)
≈ 0.00392 мВт = 3.92 мкВт
```

## 2. Амплітуда високочастотної напруги на антені

Антена з хвильовим імпедансом `R_ant = 50 Ом` передає потужність `Pr` в узгоджене навантаження. Середньоквадратична (RMS) напруга `V_rms` та пікова амплітуда `V_peak` немодульованої синусоїди розраховуються через закон Джоуля — Ленца:

```
Pr = (V_rms)² / R_ant          [закон Джоуля — Ленца через діючу напругу]
= (V_peak / √2)² / R_ant       [зв'язок RMS та пікової напруги: V_rms = V_peak / √2]
= (V_peak)² / (2 · R_ant)      [піднесення до квадрата у знаменнику]
```

Звідси пікова амплітуда напруги на клемах 50-омної антени:

```
V_peak = √(2 · Pr · R_ant)
```

Для нашого значення `Pr = 3.92 мкВт` (`3.92 · 10⁻⁶ Вт`):

```
V_peak
= √(2 · 3.92 · 10⁻⁶ · 50)  [підстановка потужності та імпедансу 50 Ом]
= √(3.92 · 10⁻⁴)           [добуток 100 · 3.92 · 10⁻⁶]
= 0.0198 В = 19.8 мВ       [пікова амплітуда сигналу]
```

Амплітуда 19.8 мілівольта занадто мала: прямий поріг навіть найкращого арсенід-галієвого або кремнієвого детекторного діода Шотткі становить щонайменше `V_th ≈ 150–250 мВ`. Якщо подати 19.8 мВ на діод напряму, він залишиться закритим, а струм буде обмежений наноамперними струмами термоемісійного витоку.

## 3. Пасивний підйом напруги резонансним LC-контуром

Щоб підняти напругу до відкривання діодів, між антеною (50 Ом) та високим вхідним імпедансом випрямляча `R_in_rec` вмикають узгоджувальне коло (LC-трансформатор напруги).

Добротність контуру `Q` визначає коефіцієнт трансформації напруги при узгодженні імпедансів:

```
R_in_rec = R_ant · (1 + Q²)
```

Якщо еквівалентний паралельний опір діодного випрямляча на мікропотужностях становить, наприклад, `R_in_rec = 1800 Ом`:

```
1 + Q² = R_in_rec / R_ant
= 1800 / 50                [відношення імпедансів]
= 36                       [коефіцієнт масштабування опору]

Q = √(36 − 1)
= √35
≈ 5.92                     [навантажена добротність контуру]
```

Резонансний підйом амплітуди напруги на вході діода:

```
V_diode_in = Q · V_peak
= 5.92 · 19.8 мВ           [підйом амплітуди на добротності]
≈ 117.2 мВ                 [амплітуда напруги перед діодами]
```

Завдяки пасивній резонансній трансформації напруга зросла майже у 6 разів — зі сліпих 19.8 мВ до 117.2 мВ, що вже дає змогу випрямлячеві зміщуватися у слабку підпорогову зону провідності.

## 4. Фізика підпорогового детектування діодом Шотткі

При амплітудах вхідного сигналу `V_rf < 150 мВ` діод працює не як ідеальний ключ, а як нелінійний квадратичний детектор. Вольт-амперна характеристика бар'єра Шотткі описується рівнянням термоемісії:

```
I(V) = Is · (exp(q · V / (n · k · T)) − 1)
```

де:
- `Is` — зворотний струм насичення (струм витоку, зазвичай 1–10 мкА для низькобар'єрних детекторних діодів типу SMS7630);
- `q` — елементарний заряд електрона (`1.602 · 10⁻¹⁹ Кл`);
- `k` — стала Больцмана (`1.381 · 10⁻²³ Дж/К`);
- `T` — абсолютна температура в Кельвінах (при 300 К тепловий потенціал `Vt = k·T/q ≈ 25.86 мВ`);
- `n` — коефіцієнт неідеальності переходу (`n ≈ 1.02–1.08`).

Диференціальний відеоопір діода на нульовому зміщенні (англ. *video resistance* `Rv`):

```
Rv = 1 / (dI / dV)|_{V=0}      [означення диференціального опору]
= (n · k · T) / (q · Is)       [диференціювання рівняння термоемісії Шотткі]
= n · Vt / Is                  [позначення теплового потенціалу Vt = k·T/q]
```

Якщо для діода з нульовим зміщенням `Is = 5 мкА`, а `n = 1.05`:

```
Rv = (1.05 · 0.02586) / (5 · 10⁻⁶) [підстановка числових значень n, Vt, Is]
= 0.02715 / (5 · 10⁻⁶)             [множення у чисельнику]
= 5430 Ом                          [ділення: відеоопір на нульовому зміщенні]
```

Струмова чутливість детектора на нульовому зміщенні `β_i` визначається кривиною характеристики (другою похідною ВАХ):

```
β_i = (d²I / dV²) / (2 · (dI / dV)) [означення струмової чутливості за Тейлором]
= q / (2 · n · k · T)               [відношення другої та першої похідних ВАХ]
= 1 / (2 · n · Vt)                  [підстановка теплового потенціалу Vt]
```

При кімнатній температурі теоретична межа струмової чутливості становить:

```
β_i = 1 / (2 · 1.05 · 0.02586)
≈ 18.4 А/Вт
```

Випрямлений постійний струм короткого замикання `I_dc` квадратично залежить від амплітуди високочастотної напруги `V_rf`:

```
I_dc = 0.5 · β_i · (V_rf)² / Rv
```

При малих потужностях випрямлений струм пропорційний квадрату напруги (тобто лінійний щодо вхідної потужності), але коефіцієнт корисної дії випрямлення є надзвичайно низьким, оскільки більша частина потужності розсіюється на паразитному послідовному опорі бази діода `Rs` та шунтується ємністю бар'єра `Cj`.

## 5. Вихідна напруга багатокаскадного помножувача Діксона

Помножувач напруги Діксона з `N` каскадами складається з `2N` діодів та `2N` конденсаторів перенесення заряду.

В ідеальному режимі холостого ходу (без навантаження струмом) кожен каскад подвоює пікову амплітуду за вирахуванням прямого падіння напруги на діодах `V_d`:

```
V_out_ideal = 2 · N · (V_diode_in − V_d)
```

При підключенні навантаження `R_load` вихідна напруга просідає через опір комутації ємностей `R_sw` та струм розряду `I_load`:

```
V_out = 2 · N · (V_diode_in − V_d) − I_load · R_sw
```

де комутаційний опір помножувача при частоті `f` та ємності міжкаскадних конденсаторів `C`:

```
R_sw = N / (f · C)
```

На надвисоких частотах (2.4 ГГц) ємності беруть порядку `C = 1 пФ` (`10⁻¹² Ф`), щоб зменшити паразитна шунтування на підкладку.

**Розрахунок для 3-каскадного помножувача (N = 3):**
Нехай вхідна амплітуда `V_diode_in = 150 мВ`, пряме динамічне падіння на нульовому зміщенні детекторного діода `V_d ≈ 80 мВ`, а струм навантаження на накопичувальний конденсатор `I_load = 0.5 мкА`:

```
V_out_no_load
= 2 · 3 · (0.150 − 0.080)  [розрахунок холостого ходу]
= 6 · 0.070
= 0.420 В = 420 мВ         [теоретична напруга без навантаження]

R_sw
= 3 / (2.4 · 10⁹ · 1 · 10⁻¹²) [комутаційний опір на 2.4 ГГц]
= 3 / (2.4 · 10⁻³)
= 1250 Ом                  [внутрішній опір джерела]

ΔV_drop
= I_load · R_sw
= 0.5 · 10⁻⁶ · 1250        [просідання під струмом 0.5 мкА]
= 0.000625 В ≈ 0.63 мВ     [зневажливо мале просідання]

V_out_real
= 420 мВ − 0.63 мВ
≈ 419.4 мВ                 [постійна напруга на виході збирача]
```

## 6. Оптимальна кількість каскадів та енергетичний ККД (PCE)

Коефіцієнт перетворення потужності (PCE, англ. *Power Conversion Efficiency*) визначається відношенням вихідної постійної потужності до вхідної радіочастотної:

```
PCE = P_dc_out / P_rf_in
= (V_out² / R_load) / P_rf_in
```

Паразитна ємність монтажу на підкладку `C_sub` (зазвичай 0.05–0.1 пФ на кожен діодний вузол) створює мікроструми витоку на землю:

```
I_leak_sub = 2 · π · f · C_sub · V_node
```

Зі збільшенням кількості каскадів `N` напруга на старших вузлах `V_node` зростає, що призводить до лавиноподібного росту ємнісних втрат на землю та сумарного прямого падіння на діодах `2·N·V_d`.

**Оптимальне число каскадів `N_opt`** для слабких сигналів визначається емпіричним співвідношенням:

```
N_opt ≈ √(V_target / (2 · V_diode_in))
```

Для цільової напруги запуску PMIC `V_target = 0.35 В` та амплітуди `V_diode_in = 0.12 В`:

```
N_opt ≈ √(0.35 / (2 · 0.12))   [підстановка цільової та вхідної напруг]
= √(0.35 / 0.24)               [множення у знаменнику]
= √1.46                        [ділення під коренем]
≈ 1.2                          [обчислення кореня; обирають N = 2]
```

Нарощування помножувача до 5–10 каскадів при слабкому сигналі (-25 дБм) призводить до катастрофічного падіння ККД майже до нуля: напруга на виході не росте, а весь мікропотужний сигнал розсіюється на паразитному заряді внутрішніх ємностей. Оптимальний вибір для кімнатного радіоефіру — 2 або 3 каскади на діодах із мінімальною бар'єрною ємністю (`Cj < 0.15 пФ`).

Отримана постійна напруга `V_out ≈ 0.42 В` перевищує поріг холодного старту сучасних нанопотужних мікросхем керування живленням (PMIC, таких як AEM30940 або BQ25570, у яких мінімальний поріг старту становить 330–380 мВ). Це дозволяє мікросхемі запустити внутрішній підвищувальний імпульсний перетворювач і зарядити робочий накопичувач вузла до стандартних 3.3 В.
