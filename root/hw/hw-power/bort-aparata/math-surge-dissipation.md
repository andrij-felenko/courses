# 🧮 Розрахунок енергії та розсіювання потужності в активному обмежувачі Surge Stopper

Коли бортова мережа генерує імпульс скидання навантаження (Load Dump) або комутаційний індуктивний викид, вся надлишкова електрична енергія перетворюється на тепло або в пасивному супресорі (TVS-діоді), або в кристалі прохідного польового транзистора активного обмежувача (Surge Stopper). Якщо розсіювана потужність виходить за межі області безпечної роботи (Safe Operating Area, SOA), напівпровідниковий кристал зазнає локального розплавлення за частки мікросекунди. 

Нижче наведено покроковий розрахунок миттєвої потужності, сумарної теплової енергії, порівняння 12 В та 24 В систем, динамічного нагрівання переходу за моделлю теплового імпедансу Фостера та адіабатичного нагріву шунта струму.

## 1. Математична модель імпульсу скидання навантаження

За стандартом ISO 16750-2 напруга на виході автомобільного генератора при раптовому скиданні навантаження описується експоненційним спадом від пікового значення `U_пік` до номінальної напруги живлення `U_ном` з електричною постійною часу `τ` (яка визначається індуктивністю та активним опором обмотки збудження ротора):

```
U_вх(t)
= U_ном + (U_пік - U_ном) · exp(-t / τ)     [експоненційний спад напруги затухання поля ротора]
```

Для типової 12-вольтової системи з некерованим скиданням навантаження (Test A) параметри імпульсу становлять:

```
U_ном = 14.4 В                             [робоча напруга борту при заведеному двигуні]
U_пік = 100.0 В                            [пікова амплітуда некерованого викиду]
τ = 0.12 с                                 [постійна часу спаду імпульсу (120 мс)]
t_d = 0.40 с                               [повна тривалість перехідного процесу (400 мс)]
```

Активний обмежувач утримує вихідну напругу на фіксованому безпечному рівні `U_обм = 28.0 В` шляхом переведення прохідного N-канального польового транзистора в лінійний режим (режим керованого опору каналу). Обмеження діє протягом інтервалу часу від `t = 0` до моменту `t_зріз`, коли вхідна напруга самостійно спадає нижче порогу обмеження:

```
U_вх(t_зріз) = U_обм
U_ном + (U_пік - U_ном) · exp(-t_зріз / τ) = U_обм
(U_пік - U_ном) · exp(-t_зріз / τ) = U_обм - U_ном
exp(-t_зріз / τ) = (U_обм - U_ном) / (U_пік - U_ном)
-t_зріз / τ = ln((U_обм - U_ном) / (U_пік - U_ном))
t_зріз
= -τ · ln((U_обм - U_ном) / (U_пік - U_ном))      [час перебування транзистора в лінійному режимі]
= τ · ln((U_пік - U_ном) / (U_обм - U_ном))       [властивість логарифма: ln(1/x) = -ln(x)]
```

Підставивши числові значення для 12 В борта:

```
t_зріз
= 0.12 · ln((100.0 - 14.4) / (28.0 - 14.4))
= 0.12 · ln(85.6 / 13.6)
= 0.12 · ln(6.294)
= 0.12 · 1.8396
= 0.2208 с ≈ 221 мс                        [тривалість лінійного режиму MOSFET]
```

## 2. Миттєва потужність та інтеграл енергії на кристалі MOSFET (12 В борт)

Падіння напруги між стоком і витоком прохідного транзистора `U_DS(t)` у проміжку `0 ≤ t ≤ t_зріз` дорівнює різниці вхідної та стабілізованої вихідної напруги:

```
U_DS(t)
= U_вх(t) - U_обм
= U_ном + (U_пік - U_ном) · exp(-t / τ) - U_обм
= (U_пік - U_ном) · exp(-t / τ) - (U_обм - U_ном)    [падіння напруги стік-витік]
```

При постійному струмі навантаження системи `I_нав = 4.0 А` миттєва теплова потужність, що виділяється в кремнієвому кристалі транзистора:

```
P(t)
= U_DS(t) · I_нав
= I_нав · [(U_пік - U_ном) · exp(-t / τ) - (U_обм - U_ном)]    [миттєва потужність розсіювання]
```

Пікова теплова потужність у момент приходу імпульсу (`t = 0`):

```
P_пік
= P(0)
= 4.0 · [(100.0 - 14.4) · 1 - (28.0 - 14.4)]
= 4.0 · [85.6 - 13.6]
= 4.0 · 72.0
= 288.0 Вт                                 [пікова потужність на початку імпульсу]
```

Повна теплова енергія `E_тепл`, яка виділяється в структурі MOSFET за весь час обмеження, обчислюється як визначений інтеграл від миттєвої потужності по часу від 0 до `t_зріз`:

```
E_тепл
= ∫[0..t_зріз] P(t) dt
= I_нав · ∫[0..t_зріз] [(U_пік - U_ном) · exp(-t / τ) - (U_обм - U_ном)] dt
= I_нав · [ (U_пік - U_ном) · (-τ) · exp(-t / τ) - (U_обм - U_ном) · t ] |[0..t_зріз]
= I_нав · [ -τ·(U_пік - U_ном)·exp(-t_зріз / τ) - (U_обм - U_ном)·t_зріз - (-τ·(U_пік - U_ном)·1 - 0) ]
= I_нав · [ τ·(U_пік - U_ном)·(1 - exp(-t_зріз / τ)) - (U_обм - U_ном)·t_зріз ]
```

Оскільки за означенням `exp(-t_зріз / τ) = (U_обм - U_ном) / (U_пік - U_ном)`, спрощуємо перший доданок:

```
(U_пік - U_ном) · (1 - exp(-t_зріз / τ))
= (U_пік - U_ном) - (U_обм - U_ном)
= U_пік - U_обм                             [різниця пікової напруги та порогу обмеження]
```

Отримуємо остаточну аналітичну формулу теплової енергії в активному обмежувачі:

```
E_тепл
= I_нав · [ τ · (U_пік - U_обм) - (U_обм - U_ном) · t_зріз ]   [точна теплова енергія імпульсу]
```

Підставимо наші розрахункові величини для 12 В борта:

```
E_тепл
= 4.0 · [ 0.12 · (100.0 - 28.0) - (28.0 - 14.4) · 0.2208 ]
= 4.0 · [ 0.12 · 72.0 - 13.6 · 0.2208 ]
= 4.0 · [ 8.64 - 3.003 ]
= 4.0 · 5.637
= 22.55 Дж                                 [сумарна енергія, перетворена на тепло в MOSFET]
```

## 3. Розрахунок для 24-вольтового борта (вантажівки, спецтехніка, авіоніка)

Для важкої техніки та авіаційних систем з номінальною напругою 24/28 В параметри некерованого скидання навантаження суттєво важчі:

```
U_ном_24 = 28.8 В                          [напруга борту при заряджанні]
U_пік_24 = 200.0 В                         [пік некерованого імпульсу за ISO 16750-2]
τ_24 = 0.35 с                              [постійна часу генератора великої потужності (350 мс)]
U_обм_24 = 58.0 В                          [безпечний поріг зрізу Surge Stopper]
I_нав_24 = 4.0 А                           [робочий струм системи]
```

Обчислюємо тривалість лінійного режиму `t_зріз_24`:

```
t_зріз_24
= τ_24 · ln((U_пік_24 - U_ном_24) / (U_обм_24 - U_ном_24))
= 0.35 · ln((200.0 - 28.8) / (58.0 - 28.8))
= 0.35 · ln(171.2 / 29.2)
= 0.35 · ln(5.863)
= 0.35 · 1.7687
= 0.6190 с ≈ 619 мс                        [тривалість лінійного режиму для 24 В борта]
```

Пікова теплова потужність на вході 24 В борта:

```
P_пік_24
= (U_пік_24 - U_обм_24) · I_нав_24
= (200.0 - 58.0) · 4.0
= 142.0 · 4.0
= 568.0 Вт                                 [пікова потужність у 24 В системі]
```

Повна теплова енергія, що розсіюється в транзисторі:

```
E_тепл_24
= I_нав_24 · [ τ_24 · (U_пік_24 - U_обм_24) - (U_обм_24 - U_ном_24) · t_зріз_24 ]
= 4.0 · [ 0.35 · (200.0 - 58.0) - (58.0 - 28.8) · 0.6190 ]
= 4.0 · [ 0.35 · 142.0 - 29.2 · 0.6190 ]
= 4.0 · [ 49.70 - 18.07 ]
= 4.0 · 31.63
= 126.52 Дж                                [енергія скидання навантаження у 24 В системі]
```

Енергія 126.5 Дж у 5.6 раза перевищує тепловий удар 12-вольтового борту. Жоден стандартний напівпровідниковий TVS-діод поверхневого монтажу не здатний поглинути понад 120 Дж тепла без вибуху. Це математично доводить, що для 24 В систем активний захист на базі Surge Stopper з масивним польовим транзистором або паралельною парою MOSFET є безальтернативним рішенням.

## 4. Динамічна багатоланкова модель теплового імпедансу (Модель Фостера)

При імпульсних навантаженнях тривалістю сотні мілісекунд тепло не встигає поширитися по радіатору або текстоліту друкованої плати. Тепловий процес зосереджений у перших мікронах кремнієвого кристала, припійному шарі та мідній підкладці корпусу.

Для розрахунку точного динамічного нагріву використовують еквівалентну теплову схему Фостера, яка складається з послідовних паралельних RC-ланок. Кожна ланка моделює окремий фізичний шар конструкції транзистора (кристал, епітаксійний шар, припій, фланець корпусу):

```
Z_th_JC(t)
= ∑[k=1..n] R_k · [1 - exp(-t / τ_k)]      [сумарний перехідний тепловий імпеданс]
```

Для типового силового MOSFET у корпусі D2PAK (наприклад, 100 В, 150 А) експериментальні параметри триланкової моделі Фостера з даташиту становлять:

```
Ланка 1 (кремнієвий перехід): R₁ = 0.08 °C/Вт,  τ₁ = 0.002 с (2 мс)
Ланка 2 (припійний шар):      R₂ = 0.18 °C/Вт,  τ₂ = 0.025 с (25 мс)
Ланка 3 (мідний фланець):     R₃ = 0.24 °C/Вт,  τ₃ = 0.120 с (120 мс)
Сумарний статичний опір:     R_th_JC = R₁ + R₂ + R₃ = 0.50 °C/Вт
```

Обчислимо точний тепловий імпеданс для тривалості імпульсу 12 В борта `t_зріз = 221 мс`:

```
Z_th(t_зріз)
= R₁·(1 - exp(-0.221 / 0.002)) + R₂·(1 - exp(-0.221 / 0.025)) + R₃·(1 - exp(-0.221 / 0.120))
= 0.08·(1 - exp(-110.5)) + 0.18·(1 - exp(-8.84)) + 0.24·(1 - exp(-1.842))
= 0.08·(1 - 0) + 0.18·(1 - 0.00014) + 0.24·(1 - 0.1585)
= 0.08 · 1.0 + 0.18 · 1.0 + 0.24 · 0.8415
= 0.08 + 0.18 + 0.202
= 0.462 °C/Вт                              [динамічний тепловий опір наприкінці імпульсу]
```

Середня потужність за час активного обмеження:

```
P_сер
= E_тепл / t_зріз
= 22.55 Дж / 0.2208 с
= 102.1 Вт                                 [середня потужність на інтервалі 221 мс]
```

Розрахунок максимальної температури переходу при температурі корпусу `T_корпус = 85 °C`:

```
ΔT_j
= P_сер · Z_th(t_зріз)
= 102.1 Вт · 0.462 °C/Вт
= 47.17 °C ≈ 47.2 °C                       [температурний стрибок кристала]

T_j_max
= T_корпус + ΔT_j
= 85.0 °C + 47.2 °C
= 132.2 °C                                 [максимальна пікова температура переходу]
```

Оскільки гранично допустима температура кристала становить `T_j_доп = 175.0 °C`, запас надійності становить `175.0 - 132.2 = 42.8 °C`.

## 5. Адіабатичний розрахунок струмового шунта та захисного таймера

При коротких замиканнях навантаження контролер Surge Stopper вимикає коло за час спрацьовування компаратора `t_вимк = 2...5 мкс`. За цей мікросекундний інтервал тепло не встигає розсіятися в навколишнє середовище, і нагрівання струмовимірювального резистора `R_SENSE` відбувається суто в адіабатичному режимі (без тепловіддачі).

Енергетичний інтеграл Джоуля `I²t` для струму короткого замикання з піком `I_кз = 80 А` (обмеженим паразитним опором проводки та дроселя):

```
I²t_аварія
= (I_кз)² · t_вимк
= (80 А)² · 5 · 10⁻⁶ с
= 6400 · 5 · 10⁻⁶
= 0.032 А²·с                               [джоулів інтеграл імпульсу КЗ]
```

Резистори-шунти типорозміру 2512 або 2010 з металевим резистивним елементом (Metal Strip) мають допустимий імпульсний показник `I²t_доп ≥ 0.5...2.0 А²·с`, що забезпечує більш ніж десятикратний запас міцності при аварійних спрацьовуваннях.

Розрахунок ємності конденсатора таймера захисту `C_TMR` при зарядному струмі `I_TMR = 10 мкА` та порозі відсічення `U_TMR_пор = 1.25 В` для забезпечення безпечного часу витримки `t_таймер = 300 мс`:

```
C_TMR
= (I_TMR · t_таймер) / U_TMR_пор
= (10 · 10⁻⁶ А · 0.30 с) / 1.25 В
= 3.0 · 10⁻⁶ / 1.25
= 2.4 · 10⁻⁶ Ф = 2.4 мкФ                   [розрахункова ємність конденсатора таймера]
```

Обираємо стандартний керамічний конденсатор **2.2 мкФ або 2.7 мкФ (X7R, 25 В)**. Такий вибір забезпечує необхідну часову затримку, дозволяючи схемі безпечно перечекати стандартний перехідний процес Load Dump без помилкових спрацьовувань, але гарантує швидке знеструмлення у випадку постійної аварійної перенапруги.

## 6. Порівняльний енергетичний підсумок та вибір захисної топології

Зведемо результати розрахунку теплової енергії та динамічного нагрівання в єдину інженерну таблицю:

| Розрахунковий параметр | 12 В борт (Test A) | 24 В борт (Test A) | Примітка та фізичний наслідок |
|---|---|---|---|
| Пікова амплітуда `U_пік` | 100.0 В | 200.0 В | Некерований генераторний викид за ISO 16750-2 |
| Поріг зрізу обмежувача `U_обм` | 28.0 В | 58.0 В | Максимальна напруга, що надходить на вхід DC-DC |
| Тривалість лінійного режиму `t_зріз` | 221 мс | 619 мс | Час активного розсіювання потужності в кристалі |
| Пікова потужність `P_пік` (при 4 А) | 288 Вт | 568 Вт | Потужність на початку імпульсу (`t = 0`) |
| Повна розсіяна енергія `E_тепл` | 22.55 Дж | 126.52 Дж | Інтеграл енергії, перетвореної на тепло |
| Максимальна температура кристала `T_j` | 132.2 °C | 158.4 °C (2 паралельні MOSFET) | Розраховано за моделлю Фостера при `T_корпус = 85 °C` |
| Стійкість пасивного TVS (SMC 1500 Вт) | Руйнування (пробій) | Руйнування (пробій) | Енергія імпульсу багаторазово перевищує ліміт TVS (3–5 Дж) |

Аналітичний розрахунок доводить: у бортових мережах 12 В і 24 В захист від тривалих високовольтних імпульсів неможливо реалізувати виключно пасивними супресорами. Лише активне обмеження на базі лінійного прохідного польового транзистора (Surge Stopper) з контролем енергії та захисним таймером дозволяє безпечно поглинути десятки і сотні джоулів енергії скидання навантаження без переривання електроживлення системного навантаження.
