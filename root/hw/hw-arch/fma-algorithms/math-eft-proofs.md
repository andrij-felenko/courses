# 🧮 Математичні доведення перетворень без похибки (EFT) на базі FMA

В обчислювальній математиці високої точності апаратна операція FMA (*Fused Multiply-Add*, `fma(a, b, c) = round(a · b + c)`) виступає не просто оптимізацією продуктивності, а фундаментальним математичним інструментом для побудови алгоритмів перетворення без похибки (*Error-Free Transformations*, скорочено **EFT**).

EFT — це клас алгоритмів плаваючої коми, які для заданої пари машинних операндів обчислюють не лише стандартно округлений результат базової арифметичної дії, але й абсолютно точну похибку цього округлення у вигляді окремого машинного числа того самого формату.

---

### Арифметична модель IEEE 754 та одиниця молодшого розряду

Нехай `𝔽` — множина нормалізованих чисел із плаваючою комою стандарту IEEE 754 з точністю `p` бітів мантиси (для одинарної точності `float` `p = 24`, для подвійної точності `double` `p = 53`).

Кожне ненульове число `x ∈ 𝔽` подається у вигляді:

```
x = (-1)ˢ × m × 2ᵉ⁻ᵖ⁺¹
```

де `s ∈ {0, 1}` — біт знака, `e` — цілочисельний порядок, а ціле число `m` задовольняє нерівність `2ᵖ⁻¹ ≤ m < 2ᵖ` (мантиса з неявною провідною одиницею).

Одиницею молодшого розряду (*Unit in the Last Place*, скорочено **ULP**) для числа `x` називають вагу наймолодшого розряду його мантиси:

```
ulp(x) = 2ᵉ⁻ᵖ⁺¹
```

Одинична похибка округлення (машинний епсилон) позначається як `u = 2⁻ᵖ` (для `double` `u = 2⁻⁵³ ≈ 1.11022 × 10⁻¹⁶`). При використанні базового режиму округлення IEEE 754 до найближчого парного (*Round to nearest, ties to even*) для будь-якої дійсної величини `r` оператор машинного округлення `fl(r)` задовольняє фундаментальні межі:

```
|fl(r) − r| ≤ 0.5 × ulp(fl(r)) ≤ u × |r|
fl(r) = r × (1 + δ),  де |δ| ≤ u
```

### Лема Штербенца про точне віднімання

Перед аналізом FMA-алгоритмів розглянемо базову лему Пета Штербенца (*Pat H. Sterbenz*, 1974), яка описує умови, за яких різниця двох чисел із плаваючою комою обчислюється абсолютно точно без виникнення похибки округлення.

**Теорема (Лема Штербенца):**
Нехай `x, y ∈ 𝔽` — два позитивні числа з плаваючою комою однакового формату. Якщо виконується співвідношення:

```
y / 2 ≤ x ≤ 2y
```

то їхня різниця `x − y` належить множині `𝔽`, тобто `fl(x − y) = x − y` (віднімання виконується без втрати бітів і без округлення).

#### Кроки математичного доведення

Нехай порядки чисел дорівнюють відповідно `eₓ` та `e_y`.

1. Припустимо без обмеження загальності, що `x ≥ y`. З умови теореми маємо `y ≤ x ≤ 2y`.
2. Оскільки `x ≥ y`, порядки можуть або збігатися (`eₓ = e_y`), або різнитися максимум на одиницю (`eₓ = e_y + 1`).

**Випадок 1:** `eₓ = e_y`.
Мантиси чисел `x` та `y` мають однаковий масштаб:

```
x − y = mₓ × 2ᵉ⁻ᵖ⁺¹ − m_y × 2ᵉ⁻ᵖ⁺¹
      = (mₓ − m_y) × 2ᵉ⁻ᵖ⁺¹          [дистрибутивність: спільний множник 2ᵉ⁻ᵖ⁺¹]
```

Оскільки `mₓ` та `m_y` — цілі числа в діапазоні `[2ᵖ⁻¹, 2ᵖ − 1]`, їхня різниця `mₓ − m_y` є цілим невід'ємним числом, строго меншим за `2ᵖ`. Отже, значення `x − y` укладається у `p` бітів мантиси й не потребує відтинання розрядів.

**Випадок 2:** `eₓ = e_y + 1`.
Тоді число `x` записується з порядком `e_y + 1`:

```
x − y = mₓ × 2ᵉ_y⁺²⁻ᵖ − m_y × 2ᵉ_y⁺¹⁻ᵖ
      = (2mₓ − m_y) × 2ᵉ_y⁺¹⁻ᵖ       [вирівнювання порядку: винесення 2ᵉ_y⁺¹⁻ᵖ]
```

Оскільки `x ≤ 2y`, маємо `mₓ × 2ᵉ_y⁺²⁻ᵖ ≤ 2 × (m_y × 2ᵉ_y⁺¹⁻ᵖ)`, звідки `2mₓ ≤ 2m_y`, тобто `2mₓ − m_y ≤ m_y < 2ᵖ`.
З іншого боку, оскільки `x ≥ y` і `eₓ = e_y + 1`, маємо `2mₓ − m_y > 0`.
Різниця `(2mₓ − m_y)` знову є цілим числом у межах `[1, 2ᵖ − 1]`, тобто точно вміщується в розрядну сітку формату.

Лема Штербенца доведена. Вона гарантує, що коли операнди близькі за величиною, їхня математична різниця є точним машинним числом.

### Алгоритм Fast2Mult: доведення точності

Алгоритм `Fast2Mult` призначений для точного розкладання добутку двох чисел `a, b ∈ 𝔽` у суму двох машинних чисел:

```
a × b = x + y
```

де `x = fl(a × b)` — старша округлена частина, а `y ∈ 𝔽` — точний залишок округлення.

За наявності апаратної інструкції FMA алгоритм має вигляд:

```
x = a * b
y = fma(a, b, -x)
```

#### Формальне доведення безпомилковості

**Теорема (Точність Fast2Mult):**
Нехай `a, b ∈ 𝔽` — нормалізовані числа з точністю `p` бітів (IEEE 754), і нехай при обчисленні `a × b` не виникає переповнення (*overflow*) та антипереповнення (*underflow*). Тоді:

```
x = fl(a × b) ∈ 𝔽
y = fl((a × b) − x) ∈ 𝔽
a × b = x + y  (точна математична рівність у ℝ)
|y| ≤ 0.5 × ulp(x) ≤ u × |x|
```

#### Доведення:

1. **Довжина точного добутку:**
   Мантиси чисел `a` та `b` містять по `p` бітів:
   ```
   a = mₐ × 2ᵉᵃ⁻ᵖ⁺¹,  b = m_b × 2ᵉᵇ⁻ᵖ⁺¹
   ```
   Точний математичний добуток дорівнює:
   ```
   a × b = (mₐ × m_b) × 2ᵉᵃ⁺ᵉᵇ⁻²ᵖ⁺²
   ```
   Добуток двох `p`-бітних цілих чисел `mₐ × m_b` є цілим числом, яке містить не більше ніж `2p` бітів (для double: `53 + 53 = 106` бітів).

2. **Структура числа x:**
   Число `x = fl(a × b)` утворюється шляхом округлення `2p`-бітного числа `a × b` до найближчого `p`-бітного числа. За означенням операції округлення до найближчого:
   ```
   |(a × b) − x| ≤ 0.5 × ulp(x)
   ```

3. **Аналіз залишкового члена y:**
   Розглянемо точну математичну різницю `Δ = (a × b) − x`.
   - Оскільки `a × b` є кратним `2ᵉᵃ⁺ᵉᵇ⁻²ᵖ⁺²`, а число `x ∈ 𝔽` є кратним `ulp(x) = 2ᵉˣ⁻ᵖ⁺¹ ≥ 2ᵉᵃ⁺ᵉᵇ⁻²ᵖ⁺²`, їхня різниця `Δ` також є строго кратною `2ᵉᵃ⁺ᵉᵇ⁻²ᵖ⁺²`.
   - Величина `|Δ|` обмежена зверху: `|Δ| ≤ 0.5 × ulp(x) = 2ᵉˣ⁻ᵖ`.
   - Кількість значущих бітів у двійковому записі числа `Δ` визначається відношенням його верхньої межі до кроку дискретизації:
   ```
   N_bits = log₂ ( (0.5 × ulp(x)) / 2ᵉᵃ⁺ᵉᵇ⁻²ᵖ⁺² )  [означення кількості двійкових розрядів]
          ≤ log₂ ( 2ᵉˣ⁻ᵖ / 2ᵉᵃ⁺ᵉᵇ⁻²ᵖ⁺² )           [підстановка межі ulp(x) = 2ᵉˣ⁻ᵖ⁺¹]
          = eₓ − p − (eₐ + e_b − 2p + 2)           [логарифм частки степенів двійки]
          = (eₓ − eₐ − e_b) + p − 2                [групування доданків]
   ```
   Оскільки порядок добутку `eₓ` задовольняє нерівність `eₐ + e_b − 1 ≤ eₓ ≤ eₐ + e_b`, отримуємо:
   ```
   N_bits ≤ (0) + p − 2 = p − 2 < p
   ```
   Отже, точна різниця `Δ = (a × b) − x` містить не більше ніж `p − 1` значущих бітів (для double: не більше 52 бітів!).

4. **Дія апаратного блоку FMA:**
   Інструкція `fma(a, b, -x)` обчислює `fl((a × b) − x)`.
   Оскільки математична величина `(a × b) − x` складається максимум із `p − 1` бітів, вона **повністю і без залишку** вкладається у стандартну `p`-бітну розрядну сітку формату `𝔽`.
   Отже, фінальне округлення операції FMA не відкидає жодного біта:
   ```
   fl((a × b) − x) = (a × b) − x
   ```
   Звідси `y = (a × b) − x`, або еквівалентно: `a × b = x + y`.

Теорема доведена. Fast2Mult на базі FMA знаходить точну похибку множення всього за 2 машинних такти/інструкції без втрати жодного біта інформації.

### Алгоритми додавання без похибки: Fast2Sum та TwoSum

Для додавання двох чисел `a, b ∈ 𝔽` також існують алгоритми EFT, які розкладають суму на два доданки: `a + b = s + t`, де `s = fl(a + b)` та `t = (a + b) − s`.

#### 1. Алгоритм Fast2Sum (Теодорус Деккер, 1971)

Алгоритм вимагає виконання попередньої умови `|a| ≥ |b|` і складається з 3 операцій:

```
s = a + b
z = s - a
t = b - z
```

#### Доведення:
1. Оскільки `|a| ≥ |b|`, маємо `|s| = |fl(a + b)| ≤ 2|a|` та `|s| ≥ |a|/2`.
2. За лемою Штербенца, віднімання `z = fl(s − a)` виконується абсолютно точно: `z = s − a`.
3. Тоді `t = fl(b − z) = fl(b − (s − a)) = fl((a + b) − s)`.
4. Оскільки `s = fl(a + b)`, залишок `(a + b) − s` не перевищує `0.5 × ulp(s)`. Оскільки `|z| ≤ |b|`, віднімання `b − z` також не втрачає бітів: `t = (a + b) − s`.

#### 2. Алгоритм TwoSum (Дональд Кнут, 1969; Оле Меллер, 1965)

Алгоритм працює для довільних чисел `a, b ∈ 𝔽` без перевірки умови `|a| ≥ |b|` і без умовних переходів за 6 операцій:

```
s = a + b
v = s - a
z = s - v
a_err = a - z
b_err = b - v
t = a_err + b_err
```

#### Математична ідея TwoSum:
- `v = fl(s − a)` обчислює ту частину числа `b`, яка фактично увійшла до суми `s`.
- `z = fl(s − v)` відновлює фактично враховану частину числа `a`.
- `a_err = fl(a − z)` видобуває відкинуті молодші біти операнда `a`.
- `b_err = fl(b − v)` видобуває відкинуті молодші біти операнда `b`.
- Обидва віднімання `a − z` та `b − v` є точними за лемою Штербенца. Їхня сума `t = a_err + b_err` дає точний залишок `(a + b) − s`.

### Алгоритм Вільяма Кахана для детермінанта 2×2: аналіз похибок

Задача обчислення детермінанта матриці розміром 2×2:

```
det = a × d − b × c
```

є класичним джерелом катастрофічного скасування розрядів при `a × d ≈ b × c`.

#### Наївне обчислення та його похибка

При прямому обчисленні `fl(fl(a × d) − fl(b × c))`:
Нехай `p = fl(a × d) = a·d·(1 + δ₁)`, `q = fl(b × c) = b·c·(1 + δ₂)`, де `|δ₁|, |δ₂| ≤ u`.
Тоді машинний результат дорівнює:

```
res = (p − q) × (1 + δ₃)                           [округлення фінального віднімання]
    = (a·d·(1 + δ₁) − b·c·(1 + δ₂)) × (1 + δ₃)     [підстановка p = fl(ad) та q = fl(bc)]
    = (a·d − b·c) + a·d·δ₁ − b·c·δ₂ + (p − q)·δ₃   [розкриття дужок з точністю до першого порядку]
```

Відносна похибка обчислення становить:

```
|res − det| / |det| ≤ u × (1 + (|a·d| + |b·c|) / |a·d − b·c|)
```

Коли `a·d ≈ b·c`, знаменник `|a·d − b·c| → 0`, тому відносна похибка прямує до нескінченності: результат може мати навіть протилежний знак.

#### Алгоритм Вільяма Кахана на базі FMA

Кахан запропонував алгоритм із 4 операцій:

```
w = b * c
e = fma(-b, c, w)
d_val = fma(a, d, -w)
det = d_val + e
```

#### Доведення теореми про похибку алгоритму Кахана

**Теорема (Кахан, 1998; Жан-Мішель Мюллер, 2018):**
Якщо під час проміжних дій не виникає переповнення або антипереповнення, результат алгоритму Кахана задовольняє нерівність:

```
|det − (a·d − b·c)| ≤ 1.5 × u × |a·d − b·c| + O(u²)
```

тобто похибка не перевищує **1.5 ULP** незалежно від глибини взаємного скасування добутків!

#### Хід виведення:
1. `w = fl(b × c)` обчислює округлений добуток.
2. `e = fma(-b, c, w) = -b·c + w = w − b·c` — за теоремою про Fast2Mult, це **абсолютно точна** похибка першого множення, тобто `b × c = w − e` без жодного заокруглення!
3. Підставимо це точне співвідношення у шуканий вираз:
   ```
   a·d − b·c = a·d − (w − e)
             = (a·d − w) + e
   ```
4. Інструкція `d_val = fma(a, d, -w)` обчислює `fl(a·d − w)` з **одним-єдиним** округленням:
   ```
   d_val = (a·d − w) × (1 + δ₄),  де |δ₄| ≤ u
   ```
5. Фінальне додавання `det = fl(d_val + e)`:
   ```
   det = (d_val + e) × (1 + δ₅)                                [округлення фінального додавання]
       = ((a·d − w)·(1 + δ₄) + e) × (1 + δ₅)                   [підстановка значення d_val]
       = (a·d − w + e) + (a·d − w)·δ₄ + ((a·d − w) + e)·δ₅     [лінеаризація похибок першого порядку]
       = (a·d − b·c) + (a·d − w)·δ₄ + (a·d − b·c)·δ₅           [заміна a·d − w + e = a·d − b·c]
   ```
6. Оскільки `|(a·d − w) − (a·d − b·c)| = |e| ≤ u × |b·c|`, при `a·d ≈ b·c` маємо `|a·d − w| ≈ |a·d − b·c|`.
   Звідси максимальна похибка обмежується сумою `|δ₄| + |δ₅| ≤ u + 0.5u = 1.5u`.

Математичне виведення підтверджує: FMA утримує різницю `a·d − w` у широкому акумуляторі, а додавання `e` повертає втрачені молодші розряди `b·c`, ліквідуючи катастрофічне скасування.

### Межі похибок компенсованої схеми Горнера

При обчисленні значення полінома `P(x) = ∑ᵢ₌₀ⁿ aᵢ xⁱ` за класичною схемою Горнера:

```
s_n = a_n
sᵢ = sᵢ₊₁ × x + aᵢ  (для i = n-1 down to 0)
```

похибки округлення на кожному кроці множаться на `x` і накопичуються. Число обумовленості задачі обчислення полінома дорівнює:

```
cond(P, x) = ( ∑ᵢ₌₀ⁿ |aᵢ| |x|ⁱ ) / |P(x)| = P̃(|x|) / |P(x)|
```

де `P̃(x) = ∑ᵢ₌₀ⁿ |aᵢ| xⁱ`.

Для класичної схеми Горнера відома класична межа прямої похибки (Ніколас Хайем, *Accuracy and Stability of Numerical Algorithms*, 2002):

```
|fl(P(x)) − P(x)| ≤ γ₂ₙ × P̃(|x|)
```

де константа `γ_k = (k × u) / (1 − k × u) ≈ k × u`.
Отже, коли `cond(P, x) ≥ 1/u ≈ 10¹⁶`, класична схема Горнера повністю втрачає всі значущі цифри.

#### Компенсована схема Горнера Огіти-Румпа-Оїші (2005)

Компенсований алгоритм використовує EFT на кожному кроці схеми Горнера:

```
(pᵢ, πᵢ) = TwoProductFMA(sᵢ₊₁, x)
(sᵢ, σᵢ) = TwoSum(pᵢ, aᵢ)
```

де `πᵢ` — точна похибка множення, а `σᵢ` — точна похибка додавання.
Завдяки цьому формується точний залишковий поліном похибок:

```
P_err(x) = ∑ᵢ₌₀ⁿ⁻¹ (πᵢ + σᵢ) × xⁱ
```

Значення полінома похибок `P_err(x)` обчислюється класичною схемою Горнера та додається до основного результату: `res = fl(s₀ + fl(P_err(x)))`.

#### Теорема про збіжність (Ogita, Rump, Oishi, 2005):

Якщо `4n × u < 1`, то обчислене значення `CompHorner(P, x)` задовольняє строгу нерівність:

```
|CompHorner(P, x) − P(x)| ≤ u × |P(x)| + γ₂ₙ² × P̃(|x|)
```

#### Наслідок:
Член похибки `γ₂ₙ²` пропорційний величині `u² ≈ (1.11 × 10⁻¹⁶)² ≈ 1.23 × 10⁻³²`!
Це означає, що компенсована схема Горнера на базі FMA видає результат із гарантованою точністю до найближчого машинного числа для всіх поліномів із числом обумовленості аж до:

```
cond(P, x) ≤ 1 / u² ≈ 10³²
```

Алгоритм подвоює ефективну розрядність обчислень, досягаючи якості чотирикратної точності (*quadruple precision*) виключно за рахунок стандартних 64-бітних FMA-інструкцій процесора.
