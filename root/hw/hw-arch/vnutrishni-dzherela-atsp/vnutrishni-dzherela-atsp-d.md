# Внутрішні джерела АЦП: опора, датчик температури, VBAT

<preknowlist>
- [Аналого-цифровий перетворювач (АЦП)](root:hw-analog/adc) — базовий принцип квантування вхідної напруги відносно опорного рівня.
- [Дільник напруги](root:hw-analog/voltage-divider) — розрахунок коефіцієнта передачі резистивного дільника та вплив вхідного опору навантаження.
- [Джерела опорної напруги](root:hw-analog/voltage-reference-sources) — принцип побудови кремнієвої забороненої зони (bandgap reference) та її температурна стабільність.
- [Вибірка та зберігання в АЦП](root:hw-analog/adc-sample-hold) — модель заряду вибіркової ємності C_S через опір ключа та внутрішнього джерела.
- [Brown-out детектор](root:hw-arch/brownout) — як просідання живлення впливає на працездатність вузлів мікроконтролера.
</preknowlist>

Автономний бездротовий датчик живиться від одного літій-тіонілхлоридного елемента або акумулятора Li-Ion. Під час передачі радіопакета струм споживання стрибає з 2 мкА до 80 мА, і через внутрішній опір джерела напруга на шині живлення VDDA просідає з 3.30 В до 2.80 В. Оскільки опорний вхід АЦП VREF+ у типових корпусах мікроконтролерів (QFN32, TSSOP20, LQFP48) з'єднаний всередині безпосередньо з шиною VDDA, повна шкала перетворення АЦП миттєво стискається. У результаті постійна напруга 1.00 В на зовнішньому аналоговому датчику до просідання давала сирий 12-бітний код 1241, а під час радіопередачі раптом видає код 1463. Прошивка сприймає це як хибне зростання сигналу на 18%, хоча напруга сенсора не змінилася ні на мікровольт.

Ставити окрему прецизійну мікросхему зовнішнього джерела опорної напруги (наприклад ADR4525 чи MAX6070) разом із додатковими фільтрами дорого, це займає дорогоцінну площу друкованої плати й додає міліампери споживання. Напівпровідникові виробники вирішують цю проблему всередині самого кристала: в структуру мікроконтролера інтегрують внутрішні аналогові джерела — стабільну кремнієву опору VREFINT, вбудований датчик температури кремнієвої підкладки та апаратно комутований дільник напруги батареї VBAT.

![Архітектура внутрішніх каналів АЦП мікроконтролера](/root/hw/hw-arch/vnutrishni-dzherela-atsp/img/internal-sources-mux.svg)
*Архітектура комутації внутрішніх аналогових джерел мікроконтролера до ядра SAR АЦП та зв'язок із калібрувальними комірками системної Flash-пам'яті.*

### Фізична природа та стабільність внутрішньої опори VREFINT

В основі внутрішнього джерела опорної напруги лежить кремнієвий стабілізатор забороненої зони (Bandgap Reference, типово побудований за схемою комірки Брокау або струмового дзеркала Відлара). Принцип його роботи ґрунтується на взаємній компенсації двох протилежних фізичних явищ у напівпровідниковій структурі:

1. **Від'ємний температурний коефіцієнт (CTAT):** Пряма напруга переходу база-емітер біполярного транзистора V_BE при фіксованому струмі зміщення спадає зі зростанням температури зі швидкістю близько -2.0 мВ/°C. Це викликано експоненційним зростанням концентрації власних носіїв заряду в напівпровіднику.
2. **Додатний температурний коефіцієнт (PTAT):** Різниця напруг ΔV_BE між двома ідентичними переходами база-емітер, що працюють із різною густиною струму (наприклад, через відношення площ емітерів 1:8), лінійно зростає з абсолютною температурою:

```text
ΔV_BE = (k * T / q) * ln(N) ≈ +0.086 мВ/°C * ln(N)
```

При точно підібраному схемотехнічному масштабуючому коефіцієнті K температурні схили взаємно компенсуються в околі кімнатної температури. У результаті сумарна напруга фіксується на рівні екстрапольованої енергії забороненої зони кремнію при абсолютному нулі:

```text
V_REFINT = V_BE + K * ΔV_BE ≈ 1.212 В
```

Ця напруга практично не залежить від коливань напруги живлення мікроконтролера: коефіцієнт придушення нестабільності живлення (PSRR — Power Supply Rejection Ratio) для внутрішнього генератора bandgap становить від -50 дБ до -65 дБ на низьких частотах. Це означає, що зміна живлення VDDA на 1.0 В викликає зміщення опорного рівня менше ніж на 0.5–1.0 мВ.

| Параметр внутрішньої опори | Типове значення | Технологічний діапазон | Вплив на системне проектування |
|---|---|---|---|
| Номінальна напруга VREFINT | 1.212 В | 1.200 – 1.224 В | Початковий технологічний розкид ±1.5% між різними партіями пластин |
| Температурний дрейф (T_coeff) | 30 ppm/°C | 15–50 ppm/°C | Зміна напруги не більше ≈ 3.6 мВ у діапазоні від -40 °C до +105 °C |
| Вихідний опір буфера (R_out) | 15 кОм | 10 – 30 кОм | Вимагає тривалого часу вибірки АЦП (t_S ≥ 4 мкс) |
| Час виходу на режим (t_START) | 10 мкс | 5–15 мкс | Необхідна програмна затримка перед стартом перетворення після виходу зі сну |
| Струм споживання | 12 мкА | 8–18 мкА | Повністю знеструмлюється бітом `VREFEN` у режимах глибокого сну |

Початковий технологічний розкид ±1.5% означає, що в одному примірнику мікроконтролера VREFINT дорівнює 1.202 В, а в сусідньому на тій самій платі — 1.221 В. Якщо зашити в програму фіксовану теоретичну константу 1.212 В, розрахунок напруги живлення матиме систематичну похибку до 50 мВ. Для подолання цього обмеження виробники впроваджують індивідуальне фабричне калібрування кожного кристала.

### Заводське калібрування у системній пам'яті (Flash Calibration)

На етапі фінішного фабричного тестування кремнієвих пластин на напівпровідниковому заводі кожен мікроконтролер встановлюється на автоматичний тестовий стенд ATE (Automated Test Equipment). Тестер подає на шину живлення мікроконтролера VDDA еталонну напругу з лабораторною точністю:

```text
V_DDA_CAL = 3000 мВ ± 1 мВ (при температурі термокамери T_CAL = 30 °C ± 1 °C)
```

За цих умов вбудований 12-бітний АЦП виконує вимірювання власного внутрішнього каналу VREFINT. Отриманий числовий код записується в заблоковану від стирання системну пам'ять (System Memory / ROM). Наприклад, для мікроконтролерів сімейства STM32G0/G4/L4 це слово зафіксоване за апаратною адресою `0x1FFF75AA` і має позначення `VREFINT_CAL`.

![Принцип логометричної компенсації при просіданні живлення](/root/hw/hw-arch/vnutrishni-dzherela-atsp/img/vrefint-ratiometric.svg)
*Логометрична компенсація: оскільки напруга VREFINT стабільна, при зменшенні напруги живлення VDDA її сирий код АЦП зростає, що дозволяє точно розрахувати поточне значення VDDA.*

Для 12-бітного перетворювача еталонний заводський код виражається формулою:

```text
VREFINT_CAL = 4095 * (V_REFINT_actual / 3000 мВ)
```

Коли готовий пристрій працює в реальному виробі за довільної поточної напруги живлення VDDA, поточний сирий код вимірювання становить:

```text
Raw_VREFINT = 4095 * (V_REFINT_actual / VDDA)
```

Якщо розділити заводське рівняння на поточне робоче рівняння, невідоме значення V_REFINT_actual та роздільна здатність 4095 **повністю скорочуються**:

```text
VREFINT_CAL / Raw_VREFINT = VDDA / 3000 мВ
```

Звідси поточна реальна напруга живлення мікроконтролера в мілівольтах обчислюється однією арифметичною дією:

```text
VDDA (мВ) = 3000 мВ * VREFINT_CAL / Raw_VREFINT
```

Детальний математичний аналіз похибок та виведення чутливості розрахунку до шуму квантування викладено у вставці [Математичне виведення формул калібрування АЦП](root:hw-arch/vnutrishni-dzherela-atsp/math-calibration-derivation.md).

### Точне вимірювання зовнішніх сигналів без опорного стабілізатора

Знаючи точну поточну напругу живлення VDDA, ми можемо відновити абсолютне значення напруги на будь-якому зовнішньому вході мікроконтролера V_IN_X. Оскільки для вхідного каналу X сирий код дорівнює:

```text
Raw_X = 4095 * (V_IN_X / VDDA)
```

Підставляючи вираз для VDDA, отримуємо остаточну формулу перетворення:

```text
V_IN_X (мВ) = 3000 мВ * (VREFINT_CAL * Raw_X) / (4095 * Raw_VREFINT)
```

Ця формула забезпечує інженерну перевагу: вимірювання зовнішньої напруги залишається абсолютно стабільним, навіть якщо акумулятор розряджається з 3.6 В до 2.0 В або якщо на шині VDDA присутні низькочастотні пульсації від роботи інтерфейсів зв'язку чи моторів.

Повний перелік адрес системної пам'яті, регістрів керування та бітових масок для різних сімейств мікроконтролерів наведено в довіднику [Регістри та адресні карти калібрування](root:hw-arch/vnutrishni-dzherela-atsp/api-calibration-registers.md).

### Вбудований датчик температури кристала

Кремнієвий термодатчик усередині мікроконтролера — це не терморезистор, а напівпровідниковий p-n перехід (діод або біполярний транзистор у діодному включенні), через який пропускається термостабілізований мікрострум. Напруга на такому переході спадає лінійно зі зростанням температури (характеристика CTAT) зі схилом близько -2.0 мВ/°C ... -2.5 мВ/°C.

![Двоточкове заводське калібрування датчика температури](/root/hw/hw-arch/vnutrishni-dzherela-atsp/img/temperature-calibration.svg)
*Двоточкове заводське калібрування: використання двох опорних точок TS_CAL1 та TS_CAL2 повністю компенсує початковий технологічний зсув напруги p-n переходу.*

Через технологічний розкид товщини шарів кремнію та концентрації легуючих домішок абсолютна напруга на переході при кімнатній температурі може відрізнятися на ±45 мВ від чіпа до чіпа. Без калібрування це створює неприйнятну похибку вимірювання температури до ±20 °C.

Щоб забезпечити точність ±1.5 °C ... ±2 °C у промисловому діапазоні від -40 °C до +125 °C, виробники застосовують **двоточкове заводське калібрування**:
1. **Перша точка `TS_CAL1`:** код вимірювання термодатчика при T1 = 30 °C та напрузі VDDA = 3.0 В (адреса, наприклад, `0x1FFF75A8`).
2. **Друга точка `TS_CAL2`:** код вимірювання термодатчика при T2 = 110 °C або 130 °C та напрузі VDDA = 3.0 В (адреса, наприклад, `0x1FFF75CA`).

#### Алгоритм розрахунку температури кристала

Оскільки заводські коефіцієнти отримані при еталонній напрузі 3.0 В, поточний сирий код Raw_TS, знятий при довільній напрузі VDDA, необхідно спершу привести до шкали 3.0 В:

```text
Raw_TS_norm = Raw_TS * (VDDA / 3000 мВ) = Raw_TS * VREFINT_CAL / Raw_VREFINT
```

Після нормалізації реальна температура кристала T_J розраховується за формулою лінійної інтерполяції між двома калібрувальними точками:

```text
T_J (°C) = [ (T_CAL2 - T_CAL1) / (TS_CAL2 - TS_CAL1) ] * (Raw_TS_norm - TS_CAL1) + T_CAL1
```

Для більшості сучасних контролерів (T1 = 30 °C, T2 = 130 °C):

```text
T_J (°C) = 100 * (Raw_TS_norm - TS_CAL1) / (TS_CAL2 - TS_CAL1) + 30
```

#### Врахування власного саморозігріву мікроконтролера

Варто пам'ятати, що інтегрований сенсор вимірює температуру безпосередньо кремнієвого кристала T_J (Junction Temperature), а не температуру навколишнього повітря T_ambient. Якщо мікроконтролер працює на максимальній тактовій частоті, ядра процесора та периферійні блоки споживають електричну потужність P_diss, що розсіюється у вигляді тепла.

Температура кристала пов'язана з температурою навколишнього середовища через тепловий опір корпусу θ_JA (Junction-to-Ambient Thermal Resistance):

```text
T_J = T_ambient + θ_JA * P_diss
```

Для типового корпусу LQFP48 тепловий опір θ_JA становить близько 55 °C/Вт. Якщо мікроконтролер споживає струм 50 мА при напрузі 3.3 В, потужність розсіювання дорівнює `P = 3.3 В * 0.05 А = 0.165 Вт`. При цьому саморозігрів кристала відносно повітря становить:

```text
ΔT = 55 °C/Вт * 0.165 Вт ≈ +9.1 °C
```

Тому, якщо вбудований термодатчик використовується для вимірювання температури навколишнього середовища (наприклад, у метеостанціях), опитування слід проводити відразу після пробудження мікроконтролера з режиму глибокого сну (Deep Sleep), поки кристал не встиг нагрітися активною роботою процесорного ядра.

### Монітор батареї VBAT та апаратна комутація

Окремий вивід живлення VBAT призначений для живлення годинника реального часу (RTC) та енергонезалежних регістрів резервного домену від дискової літієвої батарейки CR2032 (3.0 В) або акумулятора Li-Ion (3.0–4.2 В).

Вимірювати напругу на виводі VBAT напряму входом АЦП не можна з двох фізичних причин:
1. Якщо основне живлення VDDA впаде до 2.4 В, а напруга свіжого акумулятора VBAT становить 3.6 В, вхідний сигнал перевищить напругу опорної шкали АЦП, і захисні діоди ESD відкриються, скидаючи заряд батареї в шину VDDA.
2. Постійно підключений зовнішній резистивний дільник (наприклад 100 кОм + 100 кОм) споживав би постійний струм I = 3 В / 200 кОм = 15 мкА, що повністю розрядило б батарейку CR2032 ємністю 220 мАг менше ніж за два роки замість розрахункових десяти років.

Для вирішення цих проблем усередині чіпа реалізовано керований дільник із високим опором (типово сумарний опір сотні кілоом) та польовим ключем розриву кола.

```text
Керуючий біт VBATEN = 0  -->  Ключ розімкнено: витік струму з батареї = 0.0 нА
Керуючий біт VBATEN = 1  -->  Ключ замкнено: напруга ділиться на K_div (1/2, 1/3 чи 1/4)
```

Напруга на вході ядра АЦП при замкненому ключі становить:

```text
V_ADC_IN = V_BAT / K_div
```

Після оцифрування напруга батареї відновлюється з урахуванням розрахованої напруги VDDA:

```text
V_BAT (мВ) = K_div * [ VDDA * (Raw_VBAT / 4095) ]
```

Коефіцієнт K_div залежить від родини мікроконтролера: у старших родинах STM32F4 дільник 1/2, у STM32G0/G4/L4/WB — 1/3, у високовольтних STM32H7 — 1/4.

### Апаратні пастки: час вибірки та внутрішній опір

Найчастіша помилка при роботі з внутрішніми каналами — використання стандартного короткого часу вибірки АЦП. Для зовнішніх джерел із низьким вихідним опором (менше 1 кОм) достатньо часу заряду вибіркового конденсатора t_S = 1.5–2.5 тактів АЦП (близько 100 нс). Однак внутрішні блоки мають високий вихідний опір:
- Буфер VREFINT: R_out ≈ 15 кОм;
- Термодатчик: R_out ≈ 100 кОм;
- Дільник VBAT: R_out ≈ 50 кОм.

![Вплив внутрішнього опору джерела на час вибірки АЦП](/root/hw/hw-arch/vnutrishni-dzherela-atsp/img/sampling-time-rc.svg)
*Еквівалентна RC-схема вибірки та криві наростання напруги: через високий внутрішній опір джерела короткий час вибірки призводить до значного недозаряду конденсатора.*

Ємність вибірки всередині SAR АЦП становить C_S ≈ 5–8 пФ, а опір внутрішнього аналогового комутатора R_switch ≈ 1.5 кОм. Постійна часу зарядного кола для термодатчика становить:

```text
τ = (R_source + R_switch) * C_S = (100 кОм + 1.5 кОм) * 6 пФ ≈ 609 нс
```

Для 12-бітного АЦП похибка встановлення напруги має бути меншою за 0.5 LSB (1 / 8192 ≈ 0.012%), що вимагає часу заряджання не менше:

```text
t_sample ≥ -ln(1 / 8192) * τ ≈ 9.0 * τ ≈ 5.5 мкс
```

Якщо при тактовій частоті АЦП F_ADC = 32 МГц (період такту 31.25 нс) встановити час вибірки 12.5 тактів (t_S ≈ 390 нс), конденсатор C_S встигне зарядитися лише на 47% від повної напруги. Якщо перед цим вимірювався зовнішній канал з напругою 3.0 В, залишковий заряд на C_S частково перейде у вимір термодатчика. У результаті значення температури залежатиме від того, що саме вимірювалося на сусідньому каналі в попередньому перетворенні.

**Правило конфігурації:** Для каналів VREFINT, `TEMPSENSOR` та VBAT у регістрі часу вибірки `ADC_SMPR` завжди слід встановлювати максимальний або рекомендований даташитом час (наприклад 160.5, 247.5 або 640.5 тактів, що гарантує t_S > 5–12 мкс).

### Реалізація драйвера калібрувальних вимірювань

Нижче наведено робочий драйвер для читання та розрахунку внутрішніх метрик у цілочисельному форматі без накладних витрат на операції з рухомою комою.

:::tabs
=== "C"
```c
#include <stdint.h>
#include <stdbool.h>

/* Адреси системної пам'яті STM32G4 / STM32L4 */
#define ADDR_VREFINT_CAL  ((const volatile uint16_t*)0x1FFF75AAUL)
#define ADDR_TS_CAL1      ((const volatile uint16_t*)0x1FFF75A8UL)
#define ADDR_TS_CAL2      ((const volatile uint16_t*)0x1FFF75CAUL)

typedef struct {
    uint32_t vdda_mv;           /* Напруга живлення, мВ */
    int32_t  temperature_degc;  /* Температура кристала, 0.1 °C */
    uint32_t vbat_mv;           /* Напруга батареї, мВ */
} McuPowerMetrics;

/**
 * @brief Розрахунок фізичних параметрів за сирими відліками АЦП
 * @param raw_vrefint Сирий код каналу VREFINT
 * @param raw_temp    Сирий код каналу датчика температури
 * @param raw_vbat    Сирий код каналу VBAT
 */
McuPowerMetrics mcu_calculate_metrics(uint16_t raw_vrefint,
                                      uint16_t raw_temp,
                                      uint16_t raw_vbat) {
    McuPowerMetrics res;
    if (raw_vrefint == 0) {
        res.vdda_mv = 0;
        res.temperature_degc = 0;
        res.vbat_mv = 0;
        return res;
    }

    uint16_t vref_cal = *ADDR_VREFINT_CAL;
    uint16_t ts_cal1  = *ADDR_TS_CAL1;
    uint16_t ts_cal2  = *ADDR_TS_CAL2;

    /* Захист від пошкодженого або некаліброваного ROM */
    if (vref_cal < 1000 || vref_cal > 2500) vref_cal = 1650;
    if (ts_cal2 <= ts_cal1) { ts_cal1 = 1035; ts_cal2 = 1380; }

    /* 1. Розрахунок VDDA: 3000 мВ * VREFINT_CAL / Raw_VREFINT */
    uint32_t vdda = ((uint32_t)3000 * vref_cal + (raw_vrefint / 2)) / raw_vrefint;
    res.vdda_mv = vdda;

    /* 2. Нормалізація термодатчика до 3.0 В */
    uint32_t ts_norm = ((uint32_t)raw_temp * vref_cal + (raw_vrefint / 2)) / raw_vrefint;

    /* 3. Інтерполяція температури: (130°C - 30°C) * (TS_norm - CAL1) / (CAL2 - CAL1) + 30°C */
    int32_t cal_delta = (int32_t)ts_cal2 - (int32_t)ts_cal1;
    int32_t temp_01c = ((int32_t)(ts_norm - ts_cal1) * 1000) / cal_delta + 300;
    res.temperature_degc = temp_01c;

    /* 4. Напруга батареї з урахуванням дільника 1/3 */
    uint32_t vbat_channel_mv = (vdda * (uint32_t)raw_vbat + 2047) / 4095;
    res.vbat_mv = vbat_channel_mv * 3;

    return res;
}
```
=== "C++"
```cpp
#include <cstdint>
#include <optional>
#include <span>

namespace Hardware {

struct PowerMetrics {
    uint32_t vdda_millivolts{0};
    int32_t  temperature_deci_celsius{0}; // Одиниці: 0.1 °C
    uint32_t vbat_millivolts{0};
};

class InternalAdcMonitor {
public:
    struct CalibrationData {
        uint16_t vrefint_cal{1650};
        uint16_t ts_cal1{1035};
        uint16_t ts_cal2{1380};
        uint16_t vref_mv{3000};
        int16_t  t_cal1_c{30};
        int16_t  t_cal2_c{130};
        uint8_t  vbat_divider{3};
    };

    InternalAdcMonitor() noexcept {
        load_factory_calibration();
    }

    [[nodiscard]] std::optional<PowerMetrics> calculate(uint16_t raw_vrefint,
                                                        uint16_t raw_temp,
                                                        uint16_t raw_vbat) const noexcept {
        if (raw_vrefint == 0) {
            return std::nullopt;
        }

        PowerMetrics metrics;

        // 1. Відновлення точного VDDA
        const uint32_t vdda = (static_cast<uint32_t>(cal_.vref_mv) * cal_.vrefint_cal +
                               (raw_vrefint / 2U)) / raw_vrefint;
        metrics.vdda_millivolts = vdda;

        // 2. Нормалізація коду термодатчика до напруги калібрування
        const uint32_t ts_norm = (static_cast<uint32_t>(raw_temp) * cal_.vrefint_cal +
                                  (raw_vrefint / 2U)) / raw_vrefint;

        // 3. Лінійна інтерполяція температури
        const int32_t delta_cal = static_cast<int32_t>(cal_.ts_cal2) - static_cast<int32_t>(cal_.ts_cal1);
        if (delta_cal > 0) {
            const int32_t delta_t = (cal_.t_cal2_c - cal_.t_cal1_c) * 10;
            metrics.temperature_deci_celsius = ((static_cast<int32_t>(ts_norm - cal_.ts_cal1) * delta_t) / delta_cal) +
                                               (cal_.t_cal1_c * 10);
        }

        // 4. Напруга на виводі VBAT
        const uint32_t vbat_channel = (vdda * static_cast<uint32_t>(raw_vbat) + 2047U) / 4095U;
        metrics.vbat_millivolts = vbat_channel * cal_.vbat_divider;

        return metrics;
    }

private:
    void load_factory_calibration() noexcept {
        constexpr uintptr_t addr_vref = 0x1FFF75AAUL;
        constexpr uintptr_t addr_ts1  = 0x1FFF75A8UL;
        constexpr uintptr_t addr_ts2  = 0x1FFF75CAUL;

        cal_.vrefint_cal = *reinterpret_cast<const volatile uint16_t*>(addr_vref);
        cal_.ts_cal1     = *reinterpret_cast<const volatile uint16_t*>(addr_ts1);
        cal_.ts_cal2     = *reinterpret_cast<const volatile uint16_t*>(addr_ts2);

        // Fallback при відсутності коректних заводських записів
        if (cal_.vrefint_cal < 1000 || cal_.vrefint_cal > 2500 || cal_.ts_cal2 <= cal_.ts_cal1) {
            cal_.vrefint_cal = 1650;
            cal_.ts_cal1     = 1035;
            cal_.ts_cal2     = 1380;
        }
    }

    CalibrationData cal_{};
};

} // namespace Hardware
```
