# 🧮 Розрахунок навантажувальних ємностей і стійкості генератора П'єрса

Надійна робота зовнішнього кварцового генератора мікроконтролера залежить від математично точного підбору навантажувальних конденсаторів. Помилка у номіналах призводить до зміщення резонансної частоти або до зриву генерації при зміні температури й напруги живлення.

---

### Еквівалентна схема кварцового резонатора (Модель Баттерворта — Ван Дайка)

Кварцовий резонатор описується еквівалентною електричною моделлю Баттерворта — Ван Дайка (англ. *Butterworth–Van Dyke model*, BVD). Модель складається з двох паралельних гілок:

1. **Динамічна (послідовна) гілка:** моделює механічні коливання п'єзоелектричної пластини:
   * `L_m` (англ. *motional inductance*) — еквівалентна маса кристала (індуктивність порядку від одиниць до сотень генрі);
   * `C_m` (англ. *motional capacitance*) — механічна пружність кварцу (ємність від одиниць до десятків фемтофарад, `10^-15 Ф`);
   * `R_1` (англ. *motional resistance / ESR*) — внутрішні механічні втрати на тертя (опір від одиниць ом до десятків кілоом).
2. **Статична гілка:** ємність `C_0` (англ. *shunt capacitance*), утворена металевими електродами напилення та ємністю кварцотримача (зазвичай 1.0–4.5 пФ).

```
         ┌──[ L_m ]───[ C_m ]───[ R_1 ]──┐  (Динамічна гілка)
    ───o─┤                               ├─o───
         └────────────[ C_0 ]────────────┘  (Статична ємність)
```

Власна послідовна резонансна частота динамічної гілки `f_s`:

```
f_s = 1 / (2 · π · √(L_m · C_m))
```

При підключенні зовнішньої навантажувальної ємності `C_L` резонатор працює в індуктивній зоні паралельного резонансу на робочій частоті `f_L`:

```
f_L = f_s · √(1 + C_m / (C_0 + C_L))
    ≈ f_s · [ 1 + C_m / (2 · (C_0 + C_L)) ]
```

### Розрахунок навантажувальної ємності (Load Capacitance)

Еквівалентна навантажувальна ємність `C_L`, яку резонатор бачить між своїми виводами `OSC_IN` та `OSC_OUT`, формується послідовним з'єднанням двох дискретних конденсаторів `C_1` і `C_2` з урахуванням паразитної ємності монтажу `C_s`:

```
C_L = (C_1 · C_2) / (C_1 + C_2) + C_s
```

Задля симетрії фазового зсуву та рівномірного навантаження інвертора плечі роблять однаковими:

```
C_1 = C_2 = C
```

Підставимо умову симетрії у вихідне рівняння:

```
C_L = (C · C) / (C + C) + C_s       [підстановка C_1 = C_2 = C]
    = C^2 / (2 · C) + C_s           [спрощення знаменника]
    = C / 2 + C_s                   [скорочення на спільний множник C]
```

Звідси отримуємо точну аналітичну формулу для обчислення номіналу кожного дискретного конденсатора `C`:

```
C = 2 · (C_L - C_s)
```

### Оцінка паразитної ємності монтажу (C_s)

Паразитна ємність `C_s` складається з трьох незалежних фізичних факторів:
1. Вхідної ємності виводу мікроконтролера `OSC_IN` (`C_pin_in ≈ 1.5–3.0 пФ`).
2. Вихідної ємності виводу мікроконтролера `OSC_OUT` (`C_pin_out ≈ 1.5–3.0 пФ`).
3. Взаємної ємності друкованих провідників від кристала до контактних площадок МК і сусіднього земляного полігону (`C_pcb ≈ 0.5–1.5 пФ/см`).

Сумарна типова величина паразитної ємності на якісно розведеній двошаровій або чотиришаровій друкованій платі:

```
C_s ≈ 3.5 пФ ... 5.0 пФ
```

**Worked-приклад розрахунку ємностей для HSE (8 МГц):**
Дано: високочастотний резонатор на 8.000 МГц із паспортом `C_L = 16.0 пФ`. Паразитна ємність плати оцінена як `C_s = 4.0 пФ`.

```
C = 2 · (16.0 пФ - 4.0 пФ)      [підстановка C_L = 16.0 пФ та C_s = 4.0 пФ]
  = 2 · 12.0 пФ                 [обчислення різниці в дужках]
  = 24.0 пФ                     [множення на 2: кінцевий розрахунковий номінал]
```

Обираємо найближчий стандартний номінал з ряду E24: `C_1 = C_2 = 24 пФ` (або `22 пФ` для компенсації можливого набігу діелектричної проникності текстоліту FR-4). Тип діелектрика — виключно `C0G / NP0` з нульовим температурним коефіцієнтом ємності.

**Worked-приклад розрахунку ємностей для LSE (32.768 кГц):**
Дано: годинниковий камертонний кварц 32.768 кГц із паспортною ємністю `C_L = 12.5 пФ`, паразитна ємність `C_s = 3.5 пФ`.

```
C = 2 · (12.5 пФ - 3.5 пФ)      [підстановка C_L = 12.5 пФ та C_s = 3.5 пФ]
  = 2 · 9.0 пФ                  [обчислення різниці в дужках]
  = 18.0 пФ                     [множення на 2: номінал конденсаторів для LSE]
```

### Ефект підтягування частоти (Frequency Pulling)

Якщо фактична навантажувальна ємність `C_L_act` відрізняється від паспортного значення резонатора `C_L_nom`, генерована частота зміщується. Відносне відхилення частоти `Δf / f` (у частках або ppm) описується рівнянням:

```
Δf / f = (C_m / 2) · [ 1 / (C_0 + C_L_nom) - 1 / (C_0 + C_L_act) ]
```

Для малих відхилень `ΔC_L = C_L_act - C_L_nom` справедливе лінеаризоване співвідношення:

```
Δf / f ≈ [ C_m / (2 · (C_0 + C_L)^2) ] · ΔC_L
```

Звідси слідують два фундаментальні висновки для розробника:
* Збільшення ємностей (`C_L_act > C_L_nom`) знижує робочу частоту коливань генератора.
* Зменшення ємностей (`C_L_act < C_L_nom`) підвищує робочу частоту коливань.

### Температурний дрейф частоти

Залежність резонансної частоти кварцу від температури визначається кристалографічним зрізом п'єзокварцової пластини:

1. **Високочастотні кварци HSE (AT-зріз, об'ємні зсувні коливання):** крива дрейфу має форму кубічної параболи з точкою перегину біля кімнатної температури `T_0 = +25°C`:
   ```
   Δf / f = A_1 · (T - T_0) + A_2 · (T - T_0)^2 + A_3 · (T - T_0)^3
   ```
   У діапазоні від -40°C до +85°C відхилення зазвичай не перевищує `±10 ... ±30 ppm`.

2. **Годинникові камертони LSE 32.768 кГц (XY-зріз, згинні коливання):** крива має виражену форму перевернутої параболи з вершиною при `T_0 = +25°C`:
   ```
   Δf / f = -k · (T - T_0)^2
   ```
   де `k ≈ 0.035 ppm/°C^2` — параболічний коефіцієнт.

При зміні температури до `T = +65°C` (нагрів плати під час роботи) відхилення частоти годинника складе:

```
ΔT = 65°C - 25°C = 40°C
Δf / f = -0.035 · 40^2 = -0.035 · 1600 = -56 ppm
```

Відхилення у -56 ppm дає добове відставання годинника реального часу:

```
Δt_day = 56 · 10^-6 · 86400 с ≈ 4.84 секунди на добу
```

### Рівень збудження кварцу (Drive Level)

Потужність `DL`, яка розсіюється на кристалі під час коливань, не повинна перевищувати максимальне допустиме значення за паспортом (типово `DL_max = 100–200 мкВт` для високочастотних резонаторів HSE та `DL_max = 0.5–1.0 мкВт` для камертонних LSE 32.768 кГц).

Перевищення потужності збудження призводить до мікроруйнувань п'єзокерамічної пластини, стрибків частоти та прискореного незворотного старіння.

Потужність розсіювання розраховується через діюче (RMS) значення струму кварцу `I_q_rms`:

```
DL = I_q_rms^2 · R_1
```

де `R_1` — еквівалентний послідовний опір резонатора (ESR).

Діючий струм оцінюється за піковою амплітудою напруги `V_pp` на вході `OSC_IN`:

```
I_q_rms = (V_pp / (2 · √2)) · 2 · π · f · C_1
```

Підставивши вираз струму у формулу потужності:

```
DL = [ (V_pp^2) / 8 ] · (2 · π · f · C_1)^2 · R_1
```

Якщо розрахунковий або виміряний `DL > DL_max`, для обмеження струму послідовно у вивід `OSC_OUT` додають зовнішній демпфуючий резистор `R_ext` номіналом 100–470 Ом.

### Запас стійкості генератора (Gain Margin / Oscillation Allowance)

Для гарантованого збудження автоколивань за найгірших умов (температура -40°C, падіння напруги живлення до нижнього порога, технологічний розкид параметрів кремнієвого підсилювача) коефіцієнт запасу генерації `OA` (англ. *Oscillation Allowance*) повинен задовольняти критерій Баркгаузена:

```
OA = |-R_osc| / R_1 ≥ 5
```

де:
* `|-R_osc|` — модуль від'ємного динамічного опору, що генерується внутрішнім інвертором мікроконтролера;
* `R_1` — паспортний максимальний ESR кварцового резонатора.

Від'ємний опір генератора П'єрса наближено обчислюється через крутизну підсилювача `g_m` (англ. *transconductance*):

```
|-R_osc| ≈ g_m / [ (2 · π · f)^2 · C_1 · C_2 ]
```

Ця формула розкриває критичний схемотехнічний компроміс: **збільшення навантажувальних конденсаторів `C_1, C_2` різко зменшує від'ємний опір `|-R_osc|`**, оскільки ємності стоять у знаменнику в квадратичній залежності.

Якщо встановити конденсатори занадто великої ємності (наприклад, 47 пФ замість розрахункових 20 пФ), від'ємний опір впаде нижче `5 · R_1`. Підсилювач втратить здатність компенсувати втрати в резонаторі, і генератор просто не запуститься, що призведе до зависання мікроконтролера на етапі очікування прапорця `HSERDY`.

---

### Практичне вимірювання від'ємного опору на платі

Для перевірки коефіцієнта запасу генерації `OA` на реальній виготовленій друкованій платі застосовують метод послідовного резистивного навантаження:

1. Послідовно з кварцовим резонатором тимчасово впаюють прецизійний SMD-потенціометр або магазин опорів `R_add`.
2. Подають живлення на мікроконтролер і поступово збільшують опір `R_add` від 0 Ом до значення `R_crit`, за якого автоколивання зриваються.
3. Модуль від'ємного опору підсилювача обчислюють як:
   ```
   |-R_osc| = R_crit + R_1
   ```
4. Якщо виміряне співвідношення `(R_crit + R_1) / R_1 < 5`, необхідно або зменшити ємності `C_1, C_2`, або обрати резонатор із меншим значенням `ESR`.
