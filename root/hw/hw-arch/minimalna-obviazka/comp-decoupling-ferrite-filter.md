# 🔌 Фільтрація живлення: феритові бусини, LC-ланки та VCAP-декаплінг

Живлення змішаного цифро-аналогового мікроконтролера вимагає одночасного вирішення двох взаємовиключних завдань: цифрове ядро потребує миттєвої віддачі струму з мінімальною індуктивністю, а високочутливий аналоговий периферійний блок (АЦП, ЦАП, компаратори, фазове автопідлаштування частоти PLL) потребує ізоляції від комутаційного шуму мегагерцового діапазону.

Коли мільйони логічних вентилів процесорного ядра перемикаються на тактовій частоті 100 МГц, вони генерують у шині живлення струмові імпульси з наносекундними фронтами. Ці сплески створюють високочастотні гармоніки амплітудою від десятків до сотень мілівольт. Якщо підключити вивід живлення аналогової частини `VDDA` напряму до цифрової шини `VDD`, цей шум безпосередньо потрапить на внутрішній резистивний дільник опорної напруги та схему вибірки-зберігання 12-бітного АЦП. Для опорної напруги 3.3 В ціна одного молодшого розряду (LSB, англ. *Least Significant Bit*) становить:

```
V_LSB = 3.3 В / 4096 ≈ 0.805 мВ
```

Шум амплітудою всього 10–20 мВ знищує точність перетворення, перетворюючи останні 4–5 розрядів вимірювання на хаотичні коливання.

### Фізика феритової бусини (Ferrite Bead)

Феритова бусина (англ. *ferrite bead*, феритовий фільтр) — це пасивний компонент, який на низьких частотах працює як низькоомний провідник, а на високих частотах перетворює енергію електромагнітної завади на тепло за рахунок магнітних втрат у феритовому осерді.

Еквівалентна схема феритової бусини складається з послідовного з'єднання трьох елементів: активного опору постійному струму `R_dc`, частотно-залежного активного опору втрат `R(f)` та індуктивності `L(f)`, паралельно яким підключена власна паразитна ємність компонента `C_par`:

```
Z_total(f) = R(f) + j·X_L(f)
```

![Частотна характеристика імпедансу феритової бусини](/root/hw/hw-arch/minimalna-obviazka/img/power-and-decoupling.svg)
*Розподіл шин живлення мікроконтролера: виділення чистого домену VDDA через феритову бусину та локальні ємності.*

Поведінка бусини розділяється на три виражені частотні зони:

1. **Низькочастотна зона (DC до 1–10 МГц):** модуль імпедансу визначається здебільшого активним опором мідного провідника `R_dc` (зазвичай від 0.02 до 0.15 Ом) та лінійно зростаючим індуктивним реактивним опором `X_L = 2·π·f·L`. На цих частотах падіння напруги постійного струму мінімальне.
2. **Резистивна зона поглинання (10 МГц до 500 МГц):** магнітна проникність фериту зазнає дисперсії, активний опір втрат `R(f)` різко зростає і починає домінувати над реактивним опором (`R >> X_L`). Високочастотний шум струму викликає циклічне перемагнічування доменів фериту з розсіюванням енергії у вигляді мікротепла. Бусина не відбиває заваду назад у лінію, а поглинає її.
3. **Ємнісна зона (понад 500 МГц – 1 ГГц):** паразитна ємність між виводами `C_par` (0.5–2 пФ) шунтує опір компонента, і загальний імпеданс починає спадати за законом `1 / (2·π·f·C)`.

### Топологія фільтра VDDA: П-подібна ланка

Для живлення `VDDA` застосовують LC- або CLC-фільтр (П-подібну структуру). 

Схема з'єднання складається з:
* Феритової бусини номіналом 60–120 Ом на частоті 100 МГц (з `R_dc < 0.1 Ом`, `I_sat > 200 мА`);
* Високочастотного керамічного конденсатора 10 нФ (типорозмір 0402, діелектрик C0G або X7R) для придушення гармонік вище 50 МГц;
* Резервуарного керамічного конденсатора 1 мкФ – 2.2 мкФ (X7R) для забезпечення струму вибірки аналогового компаратора та заряду внутрішнього конденсатора SAR-АЦП.

```
       Шина VDD (+3.3V)
             │
             ├──[ C_in: 100 нФ ]── GND
             │
          [ Ferrite Bead ]
          (120 Ω @ 100 MHz)
             │
             ├─── Лінія VDDA до піна МК
             │
             ├──[ C_hf: 10 нФ ]── VSSA (Аналогова земля)
             │
             └──[ C_bulk: 1 мкФ ]── VSSA
```

### Пастка LC-резонансу та демпфування

Звичайна котушка індуктивності замість феритової бусини в ланцюзі живлення є небезпечною помилкою. Ідеальна або високодобротна індуктивність `L` у парі з фільтруючим конденсатором `C` утворює коливальний контур із резонансною частотою:

```
f_0 = 1 / (2·π·√(L·C))
```

Якщо спектр струму перемикання периферії МК містить гармоніку, близьку до `f_0`, добротність контуру:

```
Q = (1 / R_total) · √(L / C)
```

за низького внутрішнього опору `R_total` спричиняє резонансний підйом амплітуди напруги (англ. *resonant peaking*). Замість фільтрації плата отримує помножувач пульсацій: напруга живлення починає коливатися з амплітудою в сотні мілівольт, призводячи до спрацьовування детектора brown-out або спотворення роботи АЦП.

Феритова бусина усуває цю проблему завдяки високому еквівалентному опору втрат `R(f)` у зоні резонансу, що знижує добротність `Q < 1` і робить перехідний процес аперіодичним (демпфованим).

### Внутрішній регулятор ядра та виводи VCAP

Сучасні 32-бітні мікроконтролери (наприклад, лінійки ARM Cortex-M4/M7/H7) мають розділені домени живлення кристала: периферія та лінії вводу-виводу працюють від напруги 3.3 В (`VDD`), тоді як обчислювальне ядро з логічними матрицями та вбудованою пам'яттю SRAM живиться від зниженої напруги 1.2 В або 1.8 В (`VCORE`).

Зниження напруги ядра обумовлене фізикою КМОН: потужність динамічного споживання пропорційна квадрату напруги:

```
P_dyn = C_total · V^2 · f_clk
```

Зниження живлення з 3.3 В до 1.2 В зменшує енерговиділення ядра більш ніж у 7.5 разів:

```
(3.3 / 1.2)^2 = 2.75^2 ≈ 7.56
```

Для формування напруги `VCORE` всередині мікроконтролера інтегровано лінійний LDO-стабілізатор. Виводи `VCAP_1` та `VCAP_2` (у деяких корпусах — один вивід `VCAP`) є прямими виходами цього внутрішнього регулятора, виведеними назовні виключно для підключення зовнішніх стабілізуючих конденсаторів.

```
       Шина VDD (3.3 В)
             │
      ┌──────┴────────────────────────┐
      │  Внутрішній стабілізатор LDO  │ (всередині МК)
      └──────┬────────────────────────┘
             │ Напруга ядра VCORE (1.2 В)
             ├─── Живлення процесорного ядра та SRAM
             │
         [ Вивід VCAP_1 ]
             │
             └──[ C_ext: 2.2 мкФ, ESR < 1 Ом ]── VSS (GND)
```

Вимоги до конденсаторів `VCAP`:
* **Номінал ємності:** суворо за документацією виробника (типово 2.2 мкФ на кожен вивід або один 4.7 мкФ для об'єднаного домену).
* **Тип діелектрика:** виключно багатошарова кераміка (MLCC) класу X7R або X5R.
* **Еквівалентний послідовний опір (ESR):** `ESR` має лежати в діапазоні від 0.05 до 0.5 Ом. Конденсатор із надто високим ESR призводить до втрати фазового запасу внутрішнього підсилювача помилки LDO і викликає неконтрольовану генерацію напруги ядра, що блокує запуск процесора.
* **Довжина трасування:** конденсатор розміщується безпосередньо біля виводу `VCAP` (відстань < 2 мм) з прямим перехідним отвором на суцільний полігон землі `VSS`.
