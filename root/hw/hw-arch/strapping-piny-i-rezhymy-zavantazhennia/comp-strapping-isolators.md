# 🔌 Схемотехніка ізоляції та буферизації strapping-виводів

Використання подвійних конфігураційних виводів (strapping pins) для керування силовими ключами, світлодіодами або цифровими шинами неминуче створює конфлікт: навантаження спотворює напругу на піні під час апаратного скидання (reset), через що мікроконтролер запускається в хибному режимі або блокує живлення власної пам'яті. Щоб розірвати паразитний зв'язок між конфігураційним вікном скидання та робочим станом прошивки, застосовують апаратну ізоляцію. Цей розбір містить перевірені схемотехнічні рішення для буферизації, розрахунку підтяжок і затримки комутації навантаження.

### Конфлікт імпедансів: чому слабка внутрішня підтяжка програє навантаженню

Усередині кристала мікроконтролера strapping-виводи обладнані слабкими підтягувальними транзисторами (*weak pull-up / pull-down*). Їхній еквівалентний опір становить:

```
R_int = 40 ... 100 кОм
```

Коли до такого виводу підключають звичайний індикаторний світлодіод, з'єднаний із землею через струмообмежувальний резистор `R_led = 1 кОм`, у момент скидання виникає подільник напруги між внутрішнім резистором підтяжки до 3.3 В та зовнішнім колом світлодіода. Прямий спад напруги на червоному світлодіоді становить близько 1.6–1.8 В, проте за струмів менше кількох десятків мікроампер діод працює на початковій ділянці вольт-амперної характеристики, де його диференційний опір разом із резистором формує результуючий потенціал:

```
V_pin ≈ V_DD · (R_ext / (R_int + R_ext))
V_pin ≈ 3.3 В · (1 кОм / (45 кОм + 1 кОм)) ≈ 0.071 В
```

Потенціал 0.071 В лежить значно нижче порога логічного нуля:

```
V_IL(max) = 0.25 · V_DD = 0.825 В
```

У результаті кристал зчитує стійкий логічний нуль замість очікуваної одиниці.

Щоб зовнішній резистор гарантовано задавав рівень незалежно від внутрішньої підтяжки протилежного напрямку, зовнішній опір `R_ext` має задовольняти умову:

```
R_ext ≤ 0.1 · R_int(min)
```

За мінімального внутрішнього опору `R_int(min) = 40 кОм` номінал зовнішнього підтягувального резистора обирають у діапазоні:

```
R_ext = 3.3 ... 4.7 кОм (струм через підтяжку I_pull ≈ 0.7–1.0 мА)
R_ext = 10 кОм (якщо внутрішня підтяжка збігається за напрямком)
```

### Рішення 1: Тристабільний буфер (74LVC1G125)

Найбільш надійний метод повної гальванічної та логічної розв'язки — встановлення одноканального неінвертуючого буфера з тристабільним виходом (наприклад, `74LVC1G125` або здвоєного `74LVC2G125`).

Керівний вхід дозволу виходу `~OE` (*Output Enable*, активний нуль) підключають до лінії скидання мікроконтролера `NRST / RESET_N` або до окремого безпечного GPIO, який за замовчуванням підтягнутий резистором 10 кОм до лінії `VDD`.

```
              +3.3V
                |
               [10k]
                |
ESP32 / STM32   +-------- ~OE (Pin 1)
  GPIO_STRAP ------------ A   (Pin 2)  [74LVC1G125]
                           Y   (Pin 4) -------------> До навантаження (Relay / LED / Driver)
                          GND (Pin 3)
```

**Принцип роботи вузла:**
1. **Фаза скидання (`RESET = 0` або стартова пауза):** Вхід `~OE` утримується на високому рівні (1) зовнішнім резистором підтяжки або інвертором від лінії скидання. Вихід `Y` буфера переходить у стан високого імпедансу (*Hi-Z*). Струм витоку виходу в режимі *Hi-Z* становить менше `±1 мкА`. Фізичний пін мікроконтролера абсолютно ізольований від навантаження; внутрішня або зовнішня підтяжка безперешкодно формує необхідний strapping-рівень.
2. **Фаза робочого ходу:** Прошивка ініціалізує керівний GPIO і переводить його в логічний 0 (`~OE = 0`). Буфер активується і прозоро передає сигнал із піна `A` на вихід `Y`.

### Рішення 2: Ізоляція затвором N-канального MOSFET (2N7002 / BSS138)

Якщо strapping-пін використовується як вихід для комутації низьковольтного навантаження (котушка реле, обмотка зумера, світлодіод індикації), замість біполярного транзистора застосовують N-канальний польовий транзистор (*MOSFET*) із збагаченим каналом логічного рівня (*Logic-Level Gate*).

```
                             +5V / +12V (Живлення реле)
                                 |
                               [Реле]
                                 |
                                 +---- Drain (D)
                                 |
ESP32_GPIO12 (MTDI) ---+---- Gate (G) [2N7002 / BSS138]
                       |         |
                     [100k]   Source (S)
                       |         |
                      GND       GND
```

**Чому це працює:**
- Вхідний опір затвора MOSFET на постійному струмі перевищує `10¹⁰ Ом`, а ємність затвора `C_iss` для `2N7002` становить близько `20–50 пФ`.
- Струм витоку затвора становить менше `100 нА`.
- Резистор розрядки затвора номіналом `100 кОм`, підключений між затвором і землею, для піна ESP32 GPIO12 (який за замовчуванням має внутрішній pull-down і вимагає логічного нуля під час reset) діє синфазно з внутрішньою підтяжкою, лише покращуючи надійність фіксації напруги Flash `VDD_SDIO = 3.3 В`.
- Під час перезавантаження затвор гарантовано розряджений, транзистор закритий, реле не видає хибних перехідних спрацьовувань (*no power-on clicks*).

### Рішення 3: Правильне підключення оптопари (PC817 / EL817)

При гальванічній розв'язці цифрових входів або виходів через стандартні оптопари типу `PC817` помилкове підключення світлодіода оптопари перетворює його на жорсткий дільник напруги.

#### Заборонена схема (Анод до VDD, Катод на strapping-пін):
```
  +3.3V --- [1k] --- [Анод LED Катод] ---> Strapping Pin (GPIO0)
```
*Наслідок:* Через світлодіод і резистор струм тече в пін, примусово підтягуючи його до напруги близько `3.3 В - 1.2 В = 2.1 В` (логічна 1). Якщо це пін, який мав бути притиснутий до нуля, мікроконтролер не зможе завантажитися.

#### Правильна схема керування (Катод на GND через ключ або емітерний повторювач):
```
  Strapping Pin (GPIO) ---> [Резистор 2.2k] ---> База NPN (BC847) / Gate MOSFET
                                                    |
                                             [Анод LED Катод] (Оптопара)
                                                    |
                                                   GND
```
Пін мікроконтролера керує лише високоімпедансним входом буферного транзистора, а світлодіод оптопари живиться від окремої силової шини.

### Рішення 4: Автоматичний вузол прошивання DTR/RTS для USB-UART

Для чипів, що використовують режим послідовного завантаження через UART (ESP32, ESP8266), промисловим стандартом є схема з двома біполярними NPN-транзисторами (або здвоєною матрицею `UMH3N` / `MUN5213DW1` із вбудованими базовими резисторами 10 кОм).

```
                      +3.3V
                        |
                      [10k]
                        |
DTR ----[10k]---- Base Q1 (NPN)
                    |
      RTS -------- Emitter Q1
                    |
                 Collector Q1 -----------------> ESP32 EN (CHIP_PU)
                                                   |
                                                 [100nF ... 1uF]
                                                   |
                                                  GND

                      +3.3V
                        |
                      [10k]
                        |
RTS ----[10k]---- Base Q2 (NPN)
                    |
      DTR -------- Emitter Q2
                    |
                 Collector Q2 -----------------> ESP32 GPIO0 (BOOT)
```

**Таблиця станів перехресної схеми:**

| Стан DTR (UART моста) | Стан RTS (UART моста) | Транзистор Q1 (керує EN) | Транзистор Q2 (керує GPIO0) | Рівень на EN | Рівень на GPIO0 | Режим мікроконтролера |
|:---:|:---:|:---:|:---:|:---:|:---:|:---|
| 1 (High / +3.3V) | 1 (High / +3.3V) | Закритий (V_BE = 0) | Закритий (V_BE = 0) | 1 (Pull-up) | 1 (Pull-up) | Нормальний робочий хід |
| 0 (Low / 0V) | 0 (Low / 0V) | Закритий (V_BE = 0) | Закритий (V_BE = 0) | 1 (Pull-up) | 1 (Pull-up) | Нормальний робочий хід |
| 0 (Low / 0V) | 1 (High / +3.3V) | **Відкритий** (V_B=0V, V_E=3.3V -> V_EB=3.3V) | Закритий | **0 (GND)** | 1 (Pull-up) | Апаратне скидання (Reset active) |
| 1 (High / +3.3V) | 0 (Low / 0V) | Закритий | **Відкритий** | 1 (Pull-up) | **0 (GND)** | **Вхід у UART Bootloader** |

#### Чому конденсатор на піні EN є критично важливим

Коли утиліта прошивання (`esptool.py`) перемикає лінії з фази скидання (`DTR=0, RTS=1`) у фазу завантаження (`DTR=1, RTS=0`), сигнал `EN` починає зростати від нуля до 3.3 В, а пін `GPIO0` притискається до нуля.

Якщо конденсатор на лінії `EN` відсутній або має замалу ємність (менше 10 нФ), напруга `EN` перетинає поріг скидання ядра `V_IL(EN) ≈ 0.6 В` за кілька наносекунд — раніше, ніж спадний фронт на `GPIO0` встигне опуститися нижче порога логічного нуля через паразитну ємність монтажу. Мікроконтролер виходить зі скидання за старого значення `GPIO0 = 1` і запускає стару програму з Flash замість завантажувача.

RC-ланцюжок із резистора `R = 10 кОм` та конденсатора `C = 100 нФ ... 1 мкФ` формує сталу часу:

```
τ = R · C = 10 кОм · 100 нФ = 1.0 мс
```

Це гарантує, що лінія `GPIO0` стабілізується в нулі задовго до того, як напруга на `EN` досягне порога зняття скидання, задовольняючи часову вимогу часу встановлення:

```
t_su(GPIO0) >> 20 нс
```

### Рішення 5: Ключ затримки живлення периферії (High-Side Load Switch)

Коли до мікроконтролера підключено складну периферію (дисплеї, радіомодулі, сенсори на спільній шині SPI/I2C), яка живиться від тієї самої шини 3.3 В і намагається утримувати strapping-піни через внутрішні захисні діоди ESD (*parasitic back-powering*), живлення на периферію подають через комутатор навантаження із затримкою.

```
                      +3.3V_SYSTEM
                           |
                     Source [P-MOSFET / TPS22918] Drain ---> +3.3V_PERIPHERAL
                           |                                         |
                     Gate  +--- [100k Pull-Up to 3.3V]            [Периферія]
                           |                                         |
                     ESP32_GPIO_PWR_EN -----------------------------+
```

1. Під час скидання мікроконтролера `GPIO_PWR_EN` перебуває у стані *Hi-Z*. Зовнішній резистор 100 кОм надійно тримає затвор P-MOSFET на рівні джерела, транзистор повністю закритий, напруга на шині `+3.3V_PERIPHERAL` дорівнює 0 В.
2. Входи периферії знеструмлені й не можуть створювати зворотних струмів витоку через захисні діоди на strapping-піни.
3. Прошивка після завершення первинного старту конфігурує strapping-піни в робочий стан і лише після цього подає нуль на `GPIO_PWR_EN`, плавно вмикаючи живлення вторинної периферії.
