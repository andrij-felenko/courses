# Аналогові блоки в МК: компаратор, ОП, програмований поріг

<preknowlist>
- [Операційний підсилювач](root:hw-analog/opamp) — диференційний підсилювач із високим коефіцієнтом підсилення та негативним зворотним зв'язком.
- [Аналоговий компаратор](root:hw-analog/comparator) — пристрій порівняння двох напруг без зворотного зв'язку з логічним виходом.
- [Аналого-цифровий перетворювач](root:hw-analog/adc) — дискретизація неперервного сигналу та квантування за рівнем.
- [Цифро-аналоговий перетворювач](root:hw-analog/dac) — формування аналогової напруги за цифровим кодом.
- [Шунтовий резистор Кельвіна](root:hw-sensing/kelvin-shunt) — чотирипровідне прецизійне вимірювання струму.
- [Апаратний ШІМ](root:hw-arch/hardware-pwm) — генерація імпульсних сигналів таймером із регульованим коефіцієнтом заповнення.
- [Драйвер затвора силового ключа](root:hw-power/gate-driver) — узгодження логічних рівнів мікроконтролера з ємнісним затвором MOSFET/IGBT.
</preknowlist>

Коли в півмостовому перетворювачі або трифазному інверторі двигуна виникає коротке замикання в навантаженні чи наскрізне відкриття обох ключів стійки (shoot-through), струм через кристал силового транзистора наростає за диференційним законом:

```
di/dt = V_bus / L_stray
```

При напрузі шини живлення `48 В` та типовій сумарній індуктивності виводів і друкованих доріжок `L_stray = 100 нГн` швидкість зростання струму досягає:

```
di/dt = 48 В / (100 · 10⁻⁹ Гн) = 480 А/мкс
```

Це означає, що за половину мікросекунди струм через силовий ключ перетинає позначку `240 А`. Миттєва потужність, яка виділяється на кристалі, становить десятки кіловатів. Кремнієва структура силового польового транзистора (MOSFET, від англ. *Metal-Oxide-Semiconductor Field-Effect Transistor*) або нітрид-галієвого транзистора (GaN HEMT) прогрівається вище критичної температури `+175 °C` менш ніж за одну мікросекунду, після чого настає лавинний тепловий пробій із руйнуванням корпусу.

Програмний контур захисту на базі центрального процесора принципово не здатний запобігти цій аварії. Навіть швидкісний АЦП (ADC, від англ. *Analog-to-Digital Converter*) витрачає на вибірку та послідовне наближення `500–800 нс`. Після завершення перетворення цифровий результат має викликати переривання контролера NVIC (Nested Vectored Interrupt Controller). Апаратне збереження контексту процесорного ядра (регістрів `R0–R3`, `R12`, `LR`, `PC`, `xPSR`) займає щонайменше `12` тактів процесора (на частоті 168 МГц це ~`71 нс`), ще кілька десятків наносекунд триває виконання перших інструкцій обробника помилки. Сумарна програмна затримка від моменту перевищення струму до зняття сигналу з піна GPIO становить від `1.5` до `4 мкс`. За цей час транзисторний міст гарантовано перетворюється на оплавлений провідник.

Єдиний спосіб зберегти силове коло — виключити процесорне ядро з ланцюга реагування на надструми. Для цього сучасні змішано-сигнальні мікроконтролери містять апаратний конгломерат інтегрованих аналогових блоків: вбудовані швидкісні компаратори (COMP), операційні підсилювачі з програмованим коефіцієнтом (OPAMP/PGA), цифрові аналогові сторожові пси (Analog Watchdog) та матрицю безпосередньої кремнієвої комутації з аварійними входами таймерів (Timer Break Function).

### 1. Вбудовані аналогові компаратори (COMP): пряма реакція в кремнії

Аналоговий компаратор (від лат. *comparare* — порівнювати) — це спеціалізований диференційний підсилювач із гранично високим коефіцієнтом підсилення, оптимізований для роботи у відкритому контурі (без лінійного негативного зворотного зв'язку). Його вихід перебуває лише в одному з двох насичених станів: логічна одиниця (`VDD`), коли напруга на неінверсному вході (`INP`) вища за напругу на інверсному вході (`INM`), або логічний нуль (`GND`), коли напруга на `INP` нижча за `INM`.

Головна перевага вбудованого компаратора над зовнішньою мікросхемою полягає у відсутності виходу сигналу на зовнішні доріжки друкованої плати. Вихідний цифровий рівень компаратора формується безпосередньо всередині кремнієвого кристала й передається внутрішніми магістралями з паразитними ємностями в частки пікофарада.

#### Внутрішня схемотехніка вхідного каскаду Rail-to-Rail

Вхідний каскад вбудованого компаратора побудований за топологією подвійної комплементарної диференційної пари: пара p-канальних польових транзисторів (PMOS) працює при вхідних напругах від `GND` до `VDD - 1.2 В`, а пара n-канальних польових транзисторів (NMOS) перехоплює роботу при напругах від `1.2 В` до `VDD`. Це забезпечує повний діапазон синфазної вхідної напруги Rail-to-Rail (від шини до шини).

У точці передачі керування між PMOS та NMOS парами виникає невеликий стрибок напруги зсуву — явище кросоверної несиметрії (Crossover Distortion). Оскільки у вимірюванні струму на шунті сигнал завжди прив'язаний до потенціалу землі (`0–0.5 В`), компаратор працює строго в зоні стабільної PMOS-пари, що гарантує високу лінійність і стабільність порогу.

```
       V_IN (з піна або OPAMP)
                 │
                 ▼
              ┌─────┐
   INP (+) ───┤ +   │
              │     ├─── OUT ───► Вхід TIM1_BKIN (Break)
   INM (−) ───┤ −   │             та EXTI/NVIC
              └─────┘
                 ▲
                 │
   ┌─────────────┴─────────────────────────┐
   │ Мультиплексор опорної напруги (INM)   │
   ├──────────────┬──────────────┬─────────┤
   │ Внутрішній   │ Дільники     │ Зовнішній│
   │ ЦАП (DAC)    │ VREFINT      │ пін GPIO│
   │ (динамічний) │ 1/4, 1/2, 3/4│ (фіксов)│
   └──────────────┴──────────────┴─────────┘
```

#### Комутація входів та вибір опорних джерел

Вбудовані компаратори містять гнучкі мультиплексори входів, які конфігуруються через спеціальні регістри керування (наприклад, `COMPx_CSR`).

* **Неінверсний вхід (`INP` / `+`)**: може бути комутований на зовнішній пін GPIO або безпосередньо на внутрішній вихід вбудованого операційного підсилювача (`OPAMPx_OUT`). Це дозволяє аналізувати слабкі сигнали від датчиків без втрати динамічного діапазону.
* **Інверсний вхід (`INM` / `−`)**: слугує точкою завдання порогу спрацювання. Внутрішній комутатор надає вибір із чотирьох незалежних джерел:
  1. *Зовнішній пін GPIO*: для підключення зовнішнього резистивного дільника або прецизійного опорного джерела;
  2. *Внутрішній ЦАП (DAC)*: забезпечує динамічне цифрове завдання порогу з роздільністю 12 біт. Прошивка може на льоту змінювати поріг відсікання струму на кожному кроці роботи алгоритму;
  3. *Внутрішня опорна напруга (`VREFINT`)*: кремнієве джерело на основі ширини забороненої зони (Bandgap Voltage Reference), яке зазвичай генерує стабільні `1.212 В` незалежно від коливань напруги живлення `VDD`;
  4. *Апаратні дільники опорної напруги*: внутрішній суб-дільник формує прецизійні рівні `1/4 VREFINT` (~`0.303 В`), `1/2 VREFINT` (~`0.606 В`) та `3/4 VREFINT` (~`0.909 В`), що виключає необхідність використання зовнішніх резисторів.

#### Програмований гістерезис

Якщо вхідний аналоговий сигнал містить шуми або повільно наближається до опорного рівня, ідеальний компаратор у точці перетину зазнає багаторазових хаотичних перемикань виходу — явища дзеленчання (chatter). Для усунення цього ефекту компаратор оснащується внутрішнім контуром позитивного зворотного зв'язку, який створює [гістерезис](root:hw-analog/comparator) (від грец. *ὑστέρησις* — запізнення).

Гістерезис розносить поріг спрацювання при наростанні сигналу (`V_th+`) та поріг відпускання при спаді сигналу (`V_th-`):

```
V_th+ = V_ref + V_hyst / 2
V_th- = V_ref - V_hyst / 2
```

Ширина петлі гістерезису `V_hyst` обирається програмно через біти регістра конфігурації. Типовий ряд значень:
* `HYST = 00` (None): `0 мВ` — максимальна чутливість, придатна лише для ідеально відфільтрованих сигналів;
* `HYST = 01` (Low): `~10–15 мВ` — базова фільтрація шумів термодатчиків та повільних потенціометрів;
* `HYST = 10` (Medium): `~20–30 мВ` — стандартний режим для силових кіл з помірним рівнем перемикальних шумів;
* `HYST = 11` (High): `~40–60 мВ` — важкі умови роботи в інверторах великої потужності, де висока швидкість наростання напруги `dv/dt` наводить синфазні завади.

#### Режими швидкодії та енергоспоживання

Швидкість перемикання компаратора визначається струмом спокою його вхідного диференційного каскаду. У регістрах керування доступний вибір режимів потужності (Power Mode):
1. **High-Speed Mode**: струм споживання `~80–120 мкА`, час затримки поширення сигналу `t_prop` становить `15–25 нс`. Це основний режим для аварійного захисту силових транзисторів і пікового струмового керування (Peak Current Mode);
2. **Medium-Speed Mode**: струм споживання `~15–25 мкА`, час поширення `t_prop ≈ 100–200 нс`. Використовується для контролю робочих меж напруг живлення та моніторингу акумуляторів;
3. **Ultra-Low-Power Mode**: струм споживання менше `1 мкА`, час затримки `t_prop ≈ 1–5 мкс`. Працює в режимах глибокого енергозбереження мікроконтролера (Stop / Standby), дозволяючи пробуджувати ядро при появі сигналу на аналоговому вході.

Затримка перемикання компаратора має невелику асиметрію між фронтом наростання (`t_pLH`) та фронтом спаду (`t_pHL`). Для високошвидкісних компараторів ця асиметрія не перевищує `3–5 нс`, що є критичним при формуванні симетричних імпульсів відсікання.

#### Режим віконного компаратора (Window Mode)

Для одночасного контролю верхньої та нижньої меж напруги два сусідні компаратори (наприклад, `COMP1` та `COMP2`) об'єднуються в апаратний віконний режим. При встановленні біта `WINMODE = 1` неінверсні входи `INP` обох компараторів внутрішньо замикаються на спільний вхідний пін `COMP1_INP`. На інверсний вхід `COMP1_INM` подається верхній поріг `V_high`, а на `COMP2_INM` — нижній поріг `V_low`. Якщо вхідна напруга виходить за межі діапазону `[V_low .. V_high]`, відповідний компаратор миттєво фіксує вихід за вікно.

### 2. Апаратне зв'язування компаратора з таймером: функція аварійного захисту (Break Function)

Усі мікроконтролери з підтримкою керування електродвигунами та силовими перетворювачами оснащуються таймерами розширеного керування (Advanced Control Timers, такими як `TIM1` або `TIM8`). Ці таймери містять спеціалізований вхідний вузол аварійної зупинки — `Break Input` (`BKIN` або `BKIN2`).

#### Механізм апаратного блокування виходів

Вихід компаратора `COMPx_OUT` через внутрішню мультиплексну матрицю підключається безпосередньо до входу `TIMx_BKIN`. Коли компаратор виявляє аварійне перевищення порогу струму, на лінії `BKIN` з'являється активний рівень.

Логіка захисту таймера (Break Circuitry) діє за комбінаційною схемою:
1. За частку тактового імпульсу таймера (`< 10 нс`) апаратний тригер скидає біт `MOE` (Main Output Enable) у регістрі `TIMx_BDTR` (Break and Dead-Time Register);
2. Скидання `MOE = 0` негайно відключає канали формування ШІМ від вихідних буферів мікроконтролера;
3. Виходи керування верхніми та нижніми ключами (`CH1..CH3` та `CH1N..CH3N`) переводяться в наперед сконфігурований пасивний безпечний стан (Off-State Level);
4. Одночасно піднімається прапорець переривання `BIF` (Break Interrupt Flag) у регістрі `TIMx_SR`, інформуючи ядро процесора про те, що аварія вже локалізована на апаратному рівні.

Загальний час захисної реакції від моменту виникнення надструму на шунті до зняття напруги з затворів силових транзисторів складається з двох фізичних затримок:

```
t_total = t_prop(COMP) + t_prop(TIM_Break)
```

При використанні високошвидкісного режиму компаратора:

```
t_total = 20 нс + 8 нс = 28 нс
```

За цей час струм короткого замикання при швидкості наростання `480 А/мкс` встигає піднятися лише на:

```
ΔI = 480 А/мкс · 0.028 мкс ≈ 13.4 А
```

Такий приріст струму є абсолютно безпечним для транзисторів, розрахованих на робочий струм у десятки чи сотні ампер.

#### Безпечний стан виходів (Off-State Level) та Dead-Time

У силовому напівмості не можна просто одночасно вимкнути обидва транзистори без урахування індуктивного викиду струму двигуна. Регістр `TIMx_BDTR` дозволяє індивідуально задати стан виводів при скинутому біті `MOE`:
* **Високоімпедансний стан (High-Z)**: виходи відключаються, перетворюючись на входи без підтяжки. Зовнішні резистори драйвера затворів підтягують затвори до землі, гарантуючи плавне закриття ключів;
* **Активне відкриття нижніх ключів (Low-Side Braking)**: верхні ключі вимикаються, а всі три нижні ключі примусово відкриваються. Це замикає обмотки трифазного двигуна накоротко на землю, створюючи динамічне гальмування та гасячи залишковий магнітний потік статора через власні канали транзисторів, а не через паразитні діоди.

Крім того, вузол формувача мертвого часу (Dead-Time Generator) у структурі таймера автоматично затримує відкриття комплементарного транзистора на час `t_dead` (типово `100–500 нс`), виключаючи можливість наскрізного струму при штатній комутації.

#### Асинхронний Break проти системних збоїв

Критичною вимогою безпеки силових систем є захист при повному зависанні програмного забезпечення або відмові тактового генератора. Якщо кварцовий резонатор зазнає механічного пошкодження або ядро процесора потрапляє в нескінченний цикл `HardFault`, цифрова шина тактування зупиняється.

У вбудованій архітектурі вхід `Break` побудований як асинхронний комбінаційний канал. Навіть коли тактування ядра `HCLK` та таймера `PCLK` повністю відсутнє, аналоговий компаратор продовжує отримувати живлення від лінії `VDD`. Сигнал високого рівня від компаратора фізично через польові транзистори логічного вентиля розриває коло відкриття вихідних ключів таймера. Це гарантує, що силовий міст не залишиться у відкритому стані при апаратному краху цифрової частини мікроконтролера.

#### Політики відновлення (Recovery Policy)

Після спрацювання захисту `Break` поведінка системи визначається бітом автоматичного відновлення `AOE` (Automatic Output Enable) у регістрі `TIMx_BDTR`:

```
   Аварія: Струм > Порогу (BKIN = 1)
                  │
                  ▼
          ┌──────────────┐
          │ MOE := 0     │ ──► Виходи ШІМ вимкнено за 25 нс
          │ BIF := 1     │
          └──────────────┘
                  │
         ┌────────┴────────┐
         │ Перевірка AOE   │
         ▼                 ▼
   ┌───────────┐     ┌───────────┐
   │  AOE = 0  │     │  AOE = 1  │
   │ (Latched) │     │ (Cycle-by-│
   │           │     │  Cycle)   │
   └─────┬─────┘     └─────┬─────┘
         │                 │
         ▼                 ▼
    Блокування        Авто-увімкнення
   до скидання        MOE := 1 на
   кодом прошивки     початку нового
                      періоду (UEV)
```

1. **Режим замикання (Latched Shutdown / Software Clear, `AOE = 0`)**:
   Виходи залишаються заблокованими невизначено довго, навіть якщо напруга на вході компаратора повернулася до норми. Для відновлення генерації ШІМ прошивка повинна в обробнику переривання з'ясувати причину збою, скинути прапорець `BIF` і явно записати `MOE = 1`. Цей режим є обов'язковим для захисту від прямого короткого замикання (Hard Short Circuit).
2. **Потактове обмеження струму (Cycle-by-Cycle Current Limiting, `AOE = 1`)**:
   Якщо компаратор вимикає ШІМ у поточному періоді, таймер автоматично встановлює біт `MOE = 1` на початку наступного періоду ШІМ (подія оновлення лічильника `UEV` — Update Event), за умови що сигнал аварії на вході компаратора вже зник. Це дозволяє реалізувати імпульсні стабілізатори струму та плавне керування розгоном електродвигунів під граничним навантаженням.

#### Захист конфігурації регістрами LOCK

Щоб збійний вказівник у пам'яті (Wild Pointer) або переповнення буфера не могли випадково перезаписати конфігурацію захисту `BDTR`, регістр містить біти апаратного блокування `LOCK`. Рівень блокування `LOCK = 3` забороняє будь-яку модифікацію бітів `BKE` (Break Enable), `BKP` (Break Polarity) та `DTG` (Dead-Time Generator) аж до наступного апаратного перезавантаження мікроконтролера (Power-on Reset).

### 3. Вбудовані операційні підсилювачі (OPAMP) та підсилювачі з програмованим коефіцієнтом (PGA)

Операційний підсилювач (від лат. *operatio* — дія, виконання операцій) у структурі мікроконтролера виконує завдання аналогового кондиціонування сигналів датчиків перед їх подачею на вхід АЦП.

#### Проблема масштабування сигналу струмового шунта

У силових перетворювачах для вимірювання струму фази найчастіше використовується резистивний шунт (від англ. *shunt* — відгалуження), встановлений у нижньому плечі напівмоста (Low-side Current Sensing). Щоб мінімізувати статичні теплові втрати потужності (`P = I² · R`), опір шунта обирають у діапазоні `2–10 мОм`.

При струмі `I = 10 А` на шунті `R = 5 мОм` падає напруга:

```
V_shunt = 10 А · 0.005 Ом = 0.05 В = 50 мВ
```

Якщо цю напругу подати безпосередньо на 12-бітний АЦП з опорною напругою `V_ref = 3.3 В`, ціна одного кванта квантування (LSB, Least Significant Bit) становить:

```
V_LSB = 3.3 В / 4095 ≈ 0.806 мВ
```

Напруга `50 мВ` займе всього:

```
N_code = 50 мВ / 0.806 мВ ≈ 62 кванти
```

Із 4096 можливих рівнів шкали АЦП використовується лише 62 коди. Динамічний діапазон і точність вимірювання струму падають до неприпустимо низьких значень, а шум квантування робить неможливим якісне векторне керування полем (FOC).

#### Режими функціонування вбудованого OPAMP

Вбудований блок операційного підсилювача підтримує три базові конфігурації:

1. **Режим повторювача напруги (Voltage Follower / Unity-Gain Buffer)**:
   Вихід ОП внутрішньо з'єднується з його інверсним входом (`INM`). Вхідний опір повторювача прямує до гігаомів, а вихідний опір становить частки ома. Це дозволяє узгодити високоомні датчики (наприклад, п'єзоелектричні сенсори тиску) з низьким імпедансом вхідного каскаду вибірки-зберігання АЦП, запобігаючи падінню напруги на внутрішньому конденсаторі вибірки `C_sample`.
2. **Автономний режим (Standalone Op-Amp)**:
   Усі три виводи підсилювача (`INP`, `INM`, `OUT`) комутуються на зовнішні піни мікроконтролера. Інженер може підключити зовнішні прецизійні резистори та конденсатори для створення активних смугових фільтрів, інтеграторів чи диференційних каскадів другого порядку.
3. **Підсилювач із програмованим коефіцієнтом (Programmable Gain Amplifier — PGA)**:
   Інверсний вхід підсилювача внутрішньо підключається до матриці полікремнієвих резисторів зворотного зв'язку `R_f / R_in`. Коефіцієнт підсилення задається бітами `PGGAIN` у регістрі `OPAMPx_CSR`.

```
                  ┌──────────────── R_f ───────────────┐
                  │                                    │
                  │   ┌────────┐                       │
                  └───┤−       │                       │
                      │  OPAMP ├───────┬───────────────┴───► Внутрішній
   VINP (Шунт) ───────┤+       │       │                     вихід OPAMP_OUT
                      └────────┘       │                     (на ADC та COMP)
                           ▲           │
                           │           ▼
                      ┌────┴───────────────┐
                      │ 5-бітний ЦАП зсуву │
                      │ TRIMOFFSETP/N      │
                      └────────────────────┘
```

Доступний фіксований ряд коефіцієнтів підсилення: `2x`, `4x`, `8x`, `16x`, `32x` та `64x`.

Якщо для попереднього прикладу обрати підсилення `16x`, напруга на виході складе:

```
V_out = 50 мВ · 16 = 800 мВ = 0.8 В
```

Кількість квантів шкали АЦП зростає до:

```
N_code = 800 мВ / 0.806 мВ ≈ 992 кванти
```

Точність і роздільність вимірювання струму збільшуються рівно в 16 разів без застосування жодного зовнішнього операційного підсилювача чи резистора на платі.

#### Смуга пропускання (GBW) та швидкість наростання (Slew Rate)

Вбудовані операційні підсилювачі оптимізовані для роботи на високих частотах комутації ШІМ (`20–100 кГц`). Добуток смуги пропускання на коефіцієнт підсилення (Gain Bandwidth Product, GBW) становить типово `10–15 МГц`. При виборі коефіцієнта підсилення `16x` реальна смуга сигналу складає:

```
f_cutoff = 13 МГц / 16 ≈ 812 кГц
```

Швидкість наростання вихідної напруги (Slew Rate) перевищує `30–45 В/мкс`. Це дозволяє підсилювачу відпрацьовувати швидкісні фронти струму тривалістю менше `100 нс` без спотворення форми імпульсу.

#### Внутрішня пряма маршрутизація сигналів

Критичною особливістю сучасних мікроконтролерів є можливість повної ізоляції сигналу всередині кремнію. Вихід вбудованого ОП (`OPAMP_OUT`) зв'язується з внутрішнім каналом мультиплексора АЦП (`ADCx_IN3`) та неінверсним входом компаратора (`COMPx_INP`) за допомогою внутрішньої кремнієвої шини:
* Повністю усуваються паразитні ємності та індуктивності контактних площадок корпусу і доріжок плати;
* Виключається сприйнятливість до електромагнітних завад (ЕМС) від силових перемикань сусідніх транзисторів;
* Економляться виводи мікроконтролера, які залишаються доступними для цифрових інтерфейсів зв'язку (CAN, SPI, UART).

#### Калібрування напруги зсуву (Offset Trimming)

Через технологічний розкид параметрів КМОН-транзисторів на етапі літографії вхідний диференційний каскад ОП має власну напругу несиметрії — зсув нуля (Input Offset Voltage, `V_offset`), яка типово становить `1.5–5 мВ`. При великих коефіцієнтах підсилення (наприклад, `64x`) нескомпенсований зсув у `4 мВ` дає постійну похибку на виході:

```
V_err = 4 мВ · 64 = 256 мВ
```

Це зміщення з'їдає майже 10% шкали АЦП і вносить систематичну похибку у вимірювання нульового струму двигуна.

Для компенсації цього дефекту блок OPAMP містить апаратну систему цифрового тримінгу (від араб. *qālib* — форма, мірило; англ. *trimming* — підгонка). У структурі підсилювача встановлено пару 5-бітних цифро-аналогових перетворювачів зміщення, які керуються через регістр `OPAMPx_OTR` (Offset Trimming Register) окремо для транзисторів p-каналу (`TRIMOFFSETP`) та n-каналу (`TRIMOFFSETN`).

При старті системи прошивка запускає процедуру самокалібрування (`CALON = 1`):
1. Входи підсилювача внутрішньо замикаються на спільний опорний потенціал;
2. Внутрішній компаратор калібрування контролює знак напруги на виході ОП (біт `CALOUT`);
3. Послідовною ітерацією кодів у регістрах `TRIMOFFSETP/N` досягається стан перемикання компаратора;
4. Отриманий оптимальний калібрувальний код фіксується в регістрі, знижуючи залишковий зсув нуля до рівня менше `200 мкВ`.

![Вбудований операційний підсилювач у режимі PGA з внутрішньою матрицею зворотного зв'язку та цифровим тримінгом зсуву нуля](/root/hw/hw-arch/analohovi-bloky/img/opamp-pga-routing.svg)
*Вбудований OPAMP у режимі PGA: підсилення сигналу шунта з коефіцієнтом до 64x та внутрішня пряма передача на вхід АЦП і компаратора без виходу на зовнішні піни.*

### 4. Аналоговий сторожовий пес (Analog Watchdog — AWD)

Аналоговий сторожовий пес (від англ. *watchdog* — сторожовий пес) — це апаратний цифровий блок контролю меж, інтегрований безпосередньо в логіку керування АЦП. Він виконує безперервний апаратний моніторинг результатів оцифрування аналогових сигналів без залучення ресурсів процесорного ядра або каналів прямого доступу до пам'яті (DMA).

#### Принцип функціонування

Блок AWD містить два 12-бітних регістри порогів:
* `HTR` (High Threshold Register): верхній рівень дозволеного вікна;
* `LTR` (Low Threshold Register): нижній рівень дозволеного вікна.

Кожного разу, коли АЦП завершує цикл перетворення для обраного аналогового каналу, цифровий компаратор блоку AWD за один такт порівнює отриманий 12-бітний код `ADC_DATA` зі значеннями порогів:

```
AWD_FAULT = (ADC_DATA > HTR) OR (ADC_DATA < LTR)
```

Якщо значення сигналу потрапляє в безпечний діапазон `[LTR .. HTR]`, сторожовий пес мовчить. Щойно результат вибірки виходить за встановлені межі, блок AWD негайно:
1. Виставляє апаратний прапорець `AWD` у статусному регістрі `ADC_ISR`;
2. Генерує переривання `ADC_IRQn` в контролері NVIC, якщо встановлено біт дозволу `AWDIE`.

```
Код АЦП (12 біт)
  ▲
  │   Аварія: Спляче переривання AWD
──┼───────────────────▲─────────────── HTR (Верхній поріг)
  │                  ╱ ╲
  │   БЕЗПЕЧНИЙ     ╱   ╲      ╱╲
  │    КОРИДОР     ╱     ╲    ╱  ╲
  │               ╱       ╲──╱    ╲
──┼──────────────╱─────────────────▼── LTR (Нижній поріг)
  │             ╱            Аварія: AWD IRQ
  └────────────┴───────────────────────► Час (t)
```

#### Режими вибору каналів моніторингу

1. **Режим одиночного каналу (Single Channel Mode)**:
   AWD прив'язується до одного критичного фізичного сигналу (наприклад, тиску в гальмівній магістралі або струму резервної батареї). Усі інші канали, які послідовно опитуються АЦП, ігноруються.
2. **Режим усіх каналів регулярної / інжектованої групи (All Channels Mode)**:
   Сторожовий пес перевіряє кожне перетворення в послідовності сканування. Це дозволяє одним блоком AWD контролювати цілий масив однотипних датчиків — наприклад, температуру чотирьох симетричних NTC-термісторів силового модуля.
3. **Групи інжектованих каналів (Injected Group AWD)**:
   Сучасні АЦП дозволяють запускати високопріоритетні інжектовані вибірки строго синхронно з вершиною ШІМ-трикутника (PWM Center-aligned Mode). Сторожовий пес інжектованої групи перевіряє саме фазні струми мотора в моменти відсутності комутаційних завад.

#### Порівняльний аналіз: COMP проти AWD

Незважаючи на схожість завдань порівняння рівнів, аналоговий компаратор (COMP) та аналоговий сторожовий пес (AWD) вирішують принципово різні інженерні задачі та мають різну швидкодію.

| Параметр порівняння | Вбудований компаратор (COMP) | Аналоговий сторожовий пес (AWD) |
|---|---|---|
| **Природа обробки** | Неперервний аналоговий час | Дискретний цифровий час після АЦП |
| **Час реакції** | `15–30 нс` (наносекунди) | `0.5–2.0 мкс` (час оцифрування АЦП) |
| **Задання порогів** | Зовнішній пін, ЦАП або дільник `VREFINT` | Довільні 12-бітні константи `HTR` та `LTR` |
| **Кількість порогів** | Один поріг на компаратор (або 2 у Window Mode) | Повноцінне вікно з верхнім і нижнім порогами |
| **Кількість каналів** | 1 канал на 1 фізичний компаратор | Будь-яка кількість каналів мультиплексора АЦП |
| **Прямий зв'язок з ШІМ** | Є (апаратний сигнал на `TIMx_BKIN`) | Немає (лише через програмне переривання) |
| **Цільове призначення** | Миттєвий захист від надструмів та КЗ | Тепловий захист, контроль напруги акумулятора |

Компаратор слугує «подушкою безпеки» на випадок катастрофічного короткого замикання, тоді як сторожовий пес АЦП веде постійний санітарний нагляд за параметрами системи (повільний нагрів радіатора, деградація напруги живлення, вихід датчика за робочу лінійну зону).

![Графік роботи аналогового сторожового пса (AWD) з 12-бітним цифровим вікном контролю допустимих напруг](/root/hw/hw-arch/analohovi-bloky/img/analog-watchdog-window.svg)
*Аналоговий сторожовий пес АЦП: автоматичне відстеження виходу сигналу за межі безпечного коридору [LTR..HTR] з апаратною генерацією переривання.*

### 5. Системний синтез: єдиний захисний контур силового приводу

Об'єднання описаних блоків створює дворівневу ешелоновану оборону силової електроніки, реалізовану на одному кристалі мікроконтролера.

```
                     ┌─────────────────────────────────────────────────────────┐
                     │ МІКРОКОНТРОЛЕР                                          │
                     │                                                         │
 ┌─────────────┐     │  ┌───────────┐      ┌─────────────┐     ┌────────────┐  │
 │ Силовий     │     │  │ Вбудований│      │ Швидкісний  │     │ Ядро CPU   │  │
 │ напівміст   │     │  │ OPAMP     │ ───► │ АЦП + AWD   │ ──► │ Регулятор  │  │
 │ (MOSFET)    │     │  │ (PGA 16x) │      │ (t ~ 1 мкс) │     │ FOC (10 кГц│  │
 └──────┬──────┘     │  └─────┬─────┘      └─────────────┘     └────────────┘  │
        │            │        │                                                │
        ▼            │        ▼                                                │
 ┌─────────────┐     │  ┌───────────┐      ┌─────────────┐     ┌────────────┐  │
 │ Шунт        │ ───►│  │ Компаратор│ ───► │ Таймер ШІМ  │ ──► │ Драйвер    │──┘
 │ Кельвіна    │     │  │ COMP (DAC)│      │ TIM1 (Break)│     │ затворів   │
 │ (5 мОм)     │     │  │ (t ~20 нс)│      │ (t ~ 8 нс)  │     │ (Вимкнено!)│
 └─────────────┘     │  └───────────┘      └─────────────┘     └────────────┘
                     └─────────────────────────────────────────────────────────┘
```

1. **Перший контур (Наносекундний апаратний захист від КЗ)**:
   Сигнал шунта підсилюється внутрішнім `OPAMP1` (PGA = 16x) і подається на `COMP1`. Інверсний вхід компаратора живиться від `DAC1`, де записано поріг струму аварії `25 А`. При досягненні цього порогу компаратор за `20 нс` активує вхід `TIM1_BKIN`. Таймер за `8 нс` скидає біт `MOE`, вимикаючи транзистори. Процесор не витрачає жодного такту на виконання цієї операції.
2. **Другий контур (Мікросекундний цифровий моніторинг)**:
   Той самий підсилений сигнал з `OPAMP1` оцифровується каналом `ADC1_IN3`. Контролер AWD стежить за тим, щоб середній робочий струм не перевищував тривалого теплового ліміту `15 А`. При тривалому перевантаженні AWD викликає переривання, даючи змогу прошивці плавно зменшити завдання крутного моменту або зупинити привід у штатному режимі.

#### Програмна конфігурація захисного контуру

Нижче наведено фрагмент низькорівневої конфігурації змішано-сигнальних блоків на C та ідіоматичному C++.

:::tabs
```c
#include <stdint.h>
#include <stdbool.h>

/* Адреси регістрів периферії */
#define OPAMP1_CSR_ADDR (*(volatile uint32_t *)0x40007800UL)
#define COMP1_CSR_ADDR  (*(volatile uint32_t *)0x40010200UL)
#define DAC1_DHR12R1_A  (*(volatile uint32_t *)0x40007408UL)
#define DAC1_CR_A       (*(volatile uint32_t *)0x40007400UL)
#define TIM1_BDTR_A     (*(volatile uint32_t *)0x40012C44UL)

/* Ініціалізація повного аналогового захисного тракту */
void hardware_protection_init(void) {
    /* 1. Налаштування порогу ЦАП: 2.0 В (відповідає струму 25 А при Gain=16x, R=5мОм) */
    DAC1_DHR12R1_A = 2482;           /* Код ЦАП для 2.0 В при Vref = 3.3 В */
    DAC1_CR_A |= (1UL << 0);         /* Увімкнення каналу 1 ЦАП */

    /* 2. Конфігурація вбудованого ОП: PGA 16x, внутрішнє з'єднання виходу */
    OPAMP1_CSR_ADDR = (1UL << 30) |  /* OPAMPINTEN: вихід на внутрішню шину */
                      (0x3UL << 14)| /* PGGAIN: 16x */
                      (0x2UL << 5) | /* VM_SEL: внутрішній дільник PGA */
                      (1UL << 0);    /* OPAMPxEN: увімкнення ОП */

    /* 3. Конфігурація компаратора: вхід від OPAMP, поріг від DAC1, гістерезис 20 мВ */
    COMP1_CSR_ADDR = (0x2UL << 16) | /* HYST: 20 мВ */
                     (0x1UL << 7)  | /* INPSEL: підключено до OPAMP1_OUT */
                     (0x4UL << 4)  | /* INMSEL: підключено до DAC1_OUT1 */
                     (1UL << 0);     /* COMPxEN: увімкнення компаратора */

    /* Блокування конфігурації компаратора від модифікацій */
    COMP1_CSR_ADDR |= (1UL << 31);   /* LOCK bit */

    /* 4. Активація захисту Break у таймері ШІМ */
    TIM1_BDTR_A |= (1UL << 12) |     /* BKE: дозвіл входу Break */
                   (1UL << 15);      /* MOE: головний дозвіл виходів */
}
```
```cpp
#include <cstdint>
#include <span>

namespace mcu::power {

/* Базові адреси периферійних вузлів */
inline constexpr std::uintptr_t OPAMP_REG = 0x40007800UL;
inline constexpr std::uintptr_t COMP_REG  = 0x40010200UL;
inline constexpr std::uintptr_t DAC_REG   = 0x40007400UL;
inline constexpr std::uintptr_t TIM1_REG  = 0x40012C00UL;

/* Системний драйвер апаратного захисту */
class HardwareProtection final {
private:
    struct OpAmpRegs { volatile std::uint32_t CSR; };
    struct CompRegs  { volatile std::uint32_t CSR; };
    struct DacRegs   { volatile std::uint32_t CR; volatile std::uint32_t SWTRIGR; volatile std::uint32_t DHR12R1; };
    struct TimRegs   { volatile std::uint32_t CR1; volatile std::uint32_t RESERVED[17]; volatile std::uint32_t BDTR; };

public:
    HardwareProtection() = delete;

    static void initProtectionLoop(std::uint16_t dacCodeThreshold) noexcept {
        auto& dac   = *reinterpret_cast<DacRegs*>(DAC_REG);
        auto& opamp = *reinterpret_cast<OpAmpRegs*>(OPAMP_REG);
        auto& comp  = *reinterpret_cast<CompRegs*>(COMP_REG);
        auto& tim1  = *reinterpret_cast<TimRegs*>(TIM1_REG);

        // 1. Встановлення опорного порогу ЦАП
        dac.DHR12R1 = dacCodeThreshold & 0xFFFUL;
        dac.CR |= (1UL << 0); // Ввімкнути ЦАП

        // 2. Ввімкнення ОП у режимі PGA 16x з внутрішнім виходом
        constexpr std::uint32_t OPAMP_PGA_16X = (1UL << 30) | (0x3UL << 14) | (0x2UL << 5) | (1UL << 0);
        opamp.CSR = OPAMP_PGA_16X;

        // 3. Компаратор: вхід від OPAMP, поріг від DAC, гістерезис 20 мВ
        constexpr std::uint32_t COMP_CONFIG = (0x2UL << 16) | (0x1UL << 7) | (0x4UL << 4) | (1UL << 0);
        comp.CSR = COMP_CONFIG;
        comp.CSR |= (1UL << 31); // Апаратний LOCK регістра до системного Reset

        // 4. Увімкнення Break-захисту в таймері ШІМ
        constexpr std::uint32_t TIM_BREAK_ENABLE = (1UL << 12) | (1UL << 15);
        tim1.BDTR |= TIM_BREAK_ENABLE;
    }
};

} // namespace mcu::power
```

Замість окремих мікросхем підсилювачів, зовнішніх компараторів та резистивних дільників уся обв'язка зводиться до одного чотирипровідного шунта Кельвіна. Це не лише економить площу друкованої плати та собівартість пристрою, а й усуває паразитні ємності, наведення ЕМС та забезпечує захист силового моста за рекордні 25 наносекунд.

Повну покрокову реалізацію драйвера захисту на базі регістрів із калібруванням зсуву, обробниками помилок та фільтрацією комутаційного шуму розібрано в практичній вставці [Повний драйвер аналогового захисту силового каскаду](root:hw-arch/analohovi-bloky/proj-power-protection.md).
