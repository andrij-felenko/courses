# 🧮 Математика частотної компенсації щупа та RLC-дзвону

Точне відтворення форми електричного сигналу пасивним щупом осцилографа ґрунтується на балансі двох паралельних RC-ланок та демпфуванні паразитного коливального контуру заземлення. Без математичного балансу сталого часу ланок коефіцієнт передачі дільника змінюється з частотою, а індуктивність земляного виводу перетворює щуп на високодобротний RLC-фільтр, що генерує хибний високочастотний дзвін на кожному швидкому фронті.

## 1. Передатна функція компенсованого дільника

Схема пасивного щупа 10X складається з двох послідовних комплексних двополюсників:
- верхнє плече (у вістрі щупа): резистор `R₁ = 9 МОм`, увімкнений паралельно з підстроювальним конденсатором `C₁ = C_комп`;
- нижнє плече (кабель і вхід осцилографа): резистор `R₂ = 1 МОм` паралельно з сумарною ємністю кабелю та вхідного підсилювача `C₂ = C_кабель + C_вх ≈ 100 + 15 = 115 пФ`.

Комплексні провідності та імпеданси обох плечей в операторній формі Лапласа (де `s = j·ω` — комплексна частота):

```
Y₁(s) = 1/R₁ + s·C₁ = (1 + s·R₁·C₁) / R₁
Z₁(s) = R₁ / (1 + s·R₁·C₁)

Y₂(s) = 1/R₂ + s·C₂ = (1 + s·R₂·C₂) / R₂
Z₂(s) = R₂ / (1 + s·R₂·C₂)
```

Передатна функція дільника напруги `H(s) = V_out(s) / V_in(s)` визначається відношенням імпедансів:

```
H(s)
= Z₂(s) / (Z₁(s) + Z₂(s))                                    [формула дільника напруги]
= Y₁(s) / (Y₁(s) + Y₂(s))                                    [перехід до провідностей]
= ((1 + s·R₁·C₁) / R₁) / ((1 + s·R₁·C₁)/R₁ + (1 + s·R₂·C₂)/R₂)  [підстановка виразів Y₁ та Y₂]
= (R₂·(1 + s·R₁·C₁)) / (R₂·(1 + s·R₁·C₁) + R₁·(1 + s·R₂·C₂))     [множення чисельника й знаменника на R₁·R₂]
= (R₂·(1 + s·R₁·C₁)) / ((R₁ + R₂) + s·R₁·R₂·(C₁ + C₂))         [групування доданків у знаменнику]
```

### Умова частотної незалежності (компенсації)

Розглянемо випадок, коли сталі часу обох плечей рівні між собою: `R₁·C₁ = R₂·C₂ = τ`.

Підставимо `R₁·C₁ = τ` та `R₂·C₂ = τ` у передатну функцію:

```
H(s)
= (R₂·(1 + s·τ)) / ((R₁ + R₂) + s·(R₁·(R₂·C₂) + R₂·(R₁·C₁)))  [розкриття R₁·R₂·(C₁ + C₂)]
= (R₂·(1 + s·τ)) / ((R₁ + R₂) + s·(R₁·τ + R₂·τ))              [підстановка τ = R₂·C₂ = R₁·C₁]
= (R₂·(1 + s·τ)) / ((R₁ + R₂)·(1 + s·τ))                      [винесення (1 + s·τ) за дужки]
= R₂ / (R₁ + R₂)                                              [скорочення спільного множника (1 + s·τ)]
```

В результаті скорочення нуля передатної функції `s_z = −1/(R₁·C₁)` з її полюсом `s_p = −(R₁ + R₂)/(R₁·R₂·(C₁ + C₂))` залежність від частоти `s` повністю зникає.

Для стандартних значень `R₁ = 9 МОм` та `R₂ = 1 МОм`:

```
H(s) = 1 МОм / (9 МОм + 1 МОм) = 1/10 = 0.1
```

Розрахунок необхідної ємності підстроювального конденсатора:

```
C₁
= (R₂ / R₁) · C₂                                              [з умови R₁·C₁ = R₂·C₂]
= (1 МОм / 9 МОм) · 115 пФ                                    [підстановка чисел]
= 115 пФ / 9                                                  [ділення]
≈ 12.78 пФ                                                    [шукане значення C_комп]
```

## 2. Амплітудно-частотна та фазо-частотна характеристики

Розглянемо випадок, коли компенсація не налаштована (`R₁·C₁ ≠ R₂·C₂`). Підставивши `s = j·ω`, отримаємо комплексну частотну характеристику `H(j·ω)`:

```
H(j·ω) = (R₂ · (1 + j·ω·R₁·C₁)) / ((R₁ + R₂) + j·ω·R₁·R₂·(C₁ + C₂))
```

Модуль коефіцієнта передачі `|H(j·ω)|` на двох частотних границях:
- на постійному струмі (`ω → 0`): `|H(0)| = R₂ / (R₁ + R₂) = 0.1` (резистивний поділ);
- на нескінченно високій частоті (`ω → ∞`): `|H(∞)| = C₁ / (C₁ + C₂)` (ємнісний поділ).

Якщо `C₁ > C₂ / 9`, коефіцієнт передачі на високих частотах виявляється більшим за 0.1: високочастотні гармоніки підсилюються, виникає додатний фазовий зсув (випередження фази), що формує перерегулювання на фронтах. Якщо `C₁ < C₂ / 9`, високочастотний коефіцієнт менший за 0.1: виникає фазове запізнення, що зрізає спектр сигналу й завалює круті перепади.

## 3. Часова характеристика перехідного процесу

При поданні на вхід ідеального стрибка напруги `V_in(t) = V₀ · u(t)` (де `u(t)` — функція Гевісайда, `V_in(s) = V₀ / s`), вихідна напруга в часовій області опиняється суперпозицією швидкої ємнісної та повільної резистивної складових:

```
V_out(t) = V₀ · [ R₂/(R₁ + R₂) + ( C₁/(C₁ + C₂) − R₂/(R₁ + R₂) ) · exp(−t / τ_екв) ]
```

де еквівалентна стала часу перехідного процесу `τ_екв` визначається паралельним з'єднанням опорів та сумою ємностей:

```
τ_екв = (R₁ ∥ R₂) · (C₁ + C₂) = (R₁·R₂ / (R₁ + R₂)) · (C₁ + C₂)
```

Для числових значень `R₁ ∥ R₂ = 0.9 МОм` та `C₁ + C₂ ≈ 128 пФ`:

```
τ_екв = 9·10⁵ Ом · 128·10⁻¹² Ф ≈ 115.2 мкс
```

Аналіз виразу `V_out(t)` виявляє три характерні режими:

1. **Ідеальна компенсація (`C₁ = (R₂/R₁)·C₂`):**
   Різниця в дужках `(C₁/(C₁ + C₂) − R₂/(R₁ + R₂)) = 0`.
   Вихідна напруга миттєво встановлюється на рівні `V_out(t) = 0.1 · V₀` без будь-яких експоненційних хвостів.

2. **Недокомпенсація (`C₁ < (R₂/R₁)·C₂`):**
   Початковий стрибок напруги `V_out(0⁺) = V₀ · C₁/(C₁ + C₂) < 0.1 · V₀`.
   Далі напруга повільно наростає за експонентою з постійною часу `τ_екв ≈ 115 мкс` до стаціонарного значення `0.1 · V₀`. Вершина прямокутного імпульсу має округлений, завалений вигляд.

3. **Перекомпенсація (`C₁ > (R₂/R₁)·C₂`):**
   Початковий стрибок напруги `V_out(0⁺) = V₀ · C₁/(C₁ + C₂) > 0.1 · V₀`.
   Виникає гострий амплітудний викид, після чого напруга протягом ~115 мкс експоненційно спадає до стаціонарного рівня `0.1 · V₀`.

## 4. Високочастотна двополюсна компенсація (HF Compensation)

У широкосмугових пасивних щупах (зі смугою 300–500 МГц) простої однополюсної моделі стає недостатньо через вплив скін-ефекту та розподіленої індуктивності кабелю. Опір центрального провідника кабелю зростає з частотою пропорційно квадратному кореню:

```
R_ac(f) ≈ R_dc · √(f / f_скін)
```

Для вирівнювання АЧХ у діапазоні 100–500 МГц у компенсаційну коробку біля BNC-роз'єму встановлюють додаткові R-C ланки (HF trimmers), які вводять додаткову пару нулів та полюсів передатної функції. Вони налаштовуються за допомогою швидкісного генератора імпульсів із часом наростання менше 500 пс для усунення вторинних сплесків на перших 2–5 наносекундах фронту.

## 5. Модель паразитного RLC-дзвону заземлення

При вимірюванні швидких цифрових сигналів із часом наростання менше кількох наносекунд індуктивність земляного проводу `L_g` разом із вхідною ємністю щупа `C_вх_екв` утворює послідовний коливальний RLC-контур.

Параметри еквівалентної схеми:
- `L_g` — паразитна індуктивність дроту заземлення з крокодилом (довжина `l ≈ 15 см`, погонна індуктивність `~1 нГн/мм` → `L_g ≈ 150 нГн`);
- `C_вх_екв` — еквівалентна вхідна ємність щупа 10X (`C_вх_екв ≈ (C₁·C₂)/(C₁ + C₂) ≈ 12 пФ`);
- `R_втрат` — сумарний послідовний опір контуру (вихідний опір джерела сигналу `R_source` + опір центральної жили та з'єднань).

### Резонансна частота контуру

Власна кутова частота `ω₀` та циклічна частота `f_res`:

```
ω₀ = 1 / √(L_g · C_вх_екв)
f_res = ω₀ / (2·π) = 1 / (2·π · √(L_g · C_вх_екв))
```

Розрахунок для стандартного земляного крокодила (`L_g = 150 нГн`, `C_вх_екв = 12 пФ`):

```
f_res
= 1 / (2 · 3.14159 · √(150·10⁻⁹ Гн · 12·10⁻¹² Ф))            [підстановка значень]
= 1 / (6.28318 · √(1.8·10⁻¹⁸))                                [добуток під коренем]
= 1 / (6.28318 · 1.34164·10⁻⁹)                                [добування кореня]
= 1 / (8.4296·10⁻⁹ с)                                         [знаменник]
≈ 1.186·10⁸ Гц = 118.6 МГц                                    [резонансна частота]
```

### Характеристичний опір та добротність

Характеристичний (хвильовий) опір контуру `Z₀`:

```
Z₀
= √(L_g / C_вх_екв)                                           [формула характеристичного імпедансу]
= √(150·10⁻⁹ Гн / 12·10⁻¹² Ф)                                 [підстановка значень]
= √12500 Ом²                                                  [ділення]
≈ 111.8 Ом                                                    [значення Z₀]
```

Добротність контуру `Q` при вихідному опорі цифрового драйвера `R_втрат = 25 Ом`:

```
Q
= Z₀ / R_втрат                                                [формула добротності послідовного контуру]
= 111.8 Ом / 25 Ом                                            [підстановка чисел]
≈ 4.47                                                        [висока добротність Q > 1]
```

Коефіцієнт демпфування `ζ` (damping ratio):

```
ζ = 1 / (2·Q) = 1 / (2 · 4.47) ≈ 0.112
```

### Перерегулювання (Overshoot) на фронті імпульсу

При подачі фронту сигналу, спектр якого містить гармоніки з частотою `f_res` (час наростання `t_r ≤ 0.35 / f_res ≈ 3 нс`), амплітуда відносного перерегулювання `M_p` становить:

```
M_p = exp(− π·ζ / √(1 − ζ²))
```

Розрахунок величини викиду для `ζ = 0.112`:

```
M_p
= exp(− 3.14159 · 0.112 / √(1 − 0.112²))                      [підстановка ζ]
= exp(− 0.35186 / √(1 − 0.01254))                             [обчислення підкореневого виразу]
= exp(− 0.35186 / 0.9937)                                     [добування кореня]
= exp(− 0.35409)                                              [показник степеня]
≈ 0.702 = 70.2%                                               [викид понад амплітуду сигналу]
```

Для сигналу амплітудою 3.3 В фальшивий викид досягає:

```
V_пік = 3.3 В · (1 + 0.702) ≈ 5.62 В
```

### Вплив пружинного заземлення (Ground Spring)

При заміні 15-сантиметрового дроту на коротку пружинку довжиною 4 мм індуктивність падає до `L_g ≈ 3 нГн`.

Перерахунок резонансної частоти:

```
f_res_spring
= 1 / (2·π · √(3·10⁻⁹ Гн · 12·10⁻¹² Ф))            [підстановка L_g = 3 нГн та C_вх = 12 пФ]
= 1 / (2·π · √(36·10⁻²¹))                          [добуток під коренем]
= 1 / (2·π · 1.897·10⁻¹⁰)                          [добування кореня]
≈ 838.8 МГц                                        [резонансна частота зі spring-контактом]
```

Характеристичний опір для пружинки:

```
Z₀_spring
= √(3·10⁻⁹ / 12·10⁻¹²)                             [підстановка індуктивності та ємності]
= √250                                             [ділення чисел]
≈ 15.81 Ом                                         [хвильовий імпеданс]
```

Добротність контуру:

```
Q_spring
= 15.81 Ом / 25 Ом                                 [відношення Z₀ до R]
≈ 0.632                                            [демпфований режим Q < 0.707]
```

Оскільки `Q < 0.707` (`ζ > 0.707`), контур переходить в аперіодичний (демпфований) режим: паразитна генерація та викиди на фронтах напруги повністю зникають, а резонансна частота 840 МГц виходить далеко за межі смуги пропускання стандартного щупа.

## 6. Розрахунок динамічної похибки вимірювання часу наростання

Виміряний осцилографом час наростання імпульсу `t_r_виміряний` завжди перевищує справжній час наростання `t_r_справжній` через інерційність вимірювального тракту. Для гаусових перехідних характеристик діє теорема квадратичного додавання дисперсій:

```
t_r_виміряний = √( t_r_справжній² + t_r_щупа² + t_r_приладу² + t_r_навантаження² )
```

де складова навантаження схеми визначається вихідним опором джерела `R_src` та вхідною ємністю щупа `C_щупа`:

```
t_r_навантаження ≈ 2.2 · R_src · C_щупа
```

**Приклад. Вимірювання фронту 1.2 нс джерела з вихідним опором 50 Ом за допомогою осцилографа 200 МГц (`t_r_приладу ≈ 0.35 / 200 МГц = 1.75 нс`) та щупа 200 МГц (`C_щупа = 12 пФ`):**

```
t_r_навантаження
= 2.2 · 50 Ом · 12·10⁻¹² Ф                         [розрахунок навантажувальної затримки]
= 1.32·10⁻⁹ с = 1.32 нс                            [значення t_r_навантаження]
```

Сумарний виміряний час наростання:

```
t_r_виміряний
= √( 1.2² + 1.75² + 1.75² + 1.32² )                [квадратична сума компонент]
= √( 1.44 + 3.0625 + 3.0625 + 1.7424 )             [обчислення квадратів]
= √9.3074                                          [сума під коренем]
≈ 3.05 нс                                          [результат вимірювання на екрані]
```

Осцилограф покаже тривалість перепаду 3.05 нс замість реальних 1.2 нс (похибка становить понад 150%), причому значний внесок робить саме ємнісне навантаження щупа на вихідний опір схеми.
