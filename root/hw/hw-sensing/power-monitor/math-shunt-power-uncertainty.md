# 🧮 Розрахунок невизначеності вимірювання потужності та теплового дрейфу шунта

Коли мікроконтролер обчислює споживану потужність навантаження за формулою `P = V_bus · I_load`, він перемножує два незалежних вимірювальних канали: напругу високовольтної шини та спад напруги на резистивному шунті. Кожен із цих каналів вносить власні похибки — зміщення підсилювача, неідеальність придушення синфазного сигналу, нелінійність АЦП і температурний дрейф опору шунта від саморозігріву. Цей розрахунок дає повну математичну модель поширення невизначеності для вибору номіналу шунта та оцінки гарантованої точності вимірювання струму й потужності в усьому робочому діапазоні.

### 1. Модель вимірювання та чутливість складових

Потужність постійного струму в навантаженні визначається добутком напруги живлення шини `V_bus` та струму `I_load`, який виражається через спад напруги на шунті `V_shunt` та його опір `R_shunt`:

```text
P = V_bus · I_load = V_bus · (V_shunt / R_shunt)
```

Функція вимірювання має вигляд `P = f(V_bus, V_shunt, R_shunt)`. Для оцінки впливу кожної вхідної величини знайдемо частинні похідні (коефіцієнти чутливості):

```text
c_Vbus = ∂P / ∂V_bus = V_shunt / R_shunt = I_load
c_Vsh  = ∂P / ∂V_shunt = V_bus / R_shunt
c_Rsh  = ∂P / ∂R_shunt = - (V_bus · V_shunt) / R_shunt² = - P / R_shunt
```

За правилом поширення невизначеностей для незалежних некорельованих величин (згідно з міжнародним керівництвом GUM, англ. *Guide to the Expression of Uncertainty in Measurement*), сумарна відносна стандартна невизначеність потужності `u_rel(P) = u(P) / P` виражається через геометричну суму квадратів відносних невизначеностей кожного множника:

```text
(u(P) / P)² = (u(V_bus) / V_bus)² + (u(V_shunt) / V_shunt)² + (u(R_shunt) / R_shunt)²
u_rel(P) = √[ u_rel(V_bus)² + u_rel(V_shunt)² + u_rel(R_shunt)² ]
```

### 2. Бюджет похибок каналу струму

Виміряний спад напруги `V_shunt_meas` на клемах підсилювача відрізняється від істинного значення `V_shunt_true = I_load · R_shunt` через кілька апаратних факторів:

1. **Вхідна напруга зміщення нуля підсилювача `V_os`**: паразитна різниця потенціалів на вході підсилювача, яка додається до сигналу навіть за нульового струму.
2. **Протікання синфазної напруги через скінченний CMRR**: за високої напруги шини `V_bus` на входах виникає додаткове синфазне зміщення `V_os_cm = V_bus / 10^(CMRR / 20)`.
3. **Паразитна термо-ЕРС Зеєбека `V_th`**: спай мідних доріжок плати та резистивного сплаву шунта при градієнті температур `ΔT_grad` генерує паразитну постійну напругу `V_th = S_Seebeck · ΔT_grad`.
4. **Похибка коефіцієнта підсилення `ε_gain`**: неідеальність внутрішніх підсилювальних каскадів та джерела опорної напруги АЦП (типово 0.05–0.1%).
5. **Похибка квантування АЦП `V_LSB`**: роздільна здатність молодшого значущого розряду (для 16-розрядного АЦП INA226 крок становить `2.5 мкВ`).

Абсолютна похибка вимірювання напруги шунта `ΔV_shunt`:

```text
ΔV_shunt = V_os + V_bus · 10^(-CMRR / 20) + (S_Seebeck · ΔT_grad) + ε_gain · V_shunt + (V_LSB / 2)
```

Відносна похибка каналу струму:

```text
u_rel(V_shunt) = ΔV_shunt / V_shunt
= (V_os + V_bus · 10^(-CMRR / 20) + V_th + (V_LSB / 2)) / (I_load · R_shunt) + ε_gain
```

На малих струмах знаменник `I_load · R_shunt` прямує до нуля, через що відносна похибка каналу струму зростає за гіперболічним законом `1 / I_load`.

### 3. Тепловий баланс і дрейф опору шунта (TCR)

Силовий струм `I_load`, протікаючи крізь шунт, розсіює джоулеву теплову потужність:

```text
P_loss = I_load² · R_shunt
```

У стаціонарному тепловому режимі температура резистивного елемента піднімається над температурою навколишнього середовища `T_amb` пропорційно тепловому опору «шунт–плата–повітря» `R_th_ja` (у °C/Вт):

```text
ΔT_shunt = T_shunt - T_amb = P_loss · R_th_ja = I_load² · R_shunt · R_th_ja
```

Динаміка нагріву шунта описується експоненційним перехідним процесом із тепловою сталою часу `τ_th = R_th_ja · C_th` (де `C_th` — теплоємність резистора, що для корпусів 2512 становить приблизно 0.1–0.3 Дж/°C):

```text
T(t) = T_amb + ΔT_shunt · [1 - exp(-t / τ_th)]
```

Зміна температури спричиняє відхилення опору від його каліброваного значення `R_0` (за температури `T_0 = 25 °C`) відповідно до температурного коефіцієнта опору TCR (англ. *Temperature Coefficient of Resistance*, вимірюється в `ppm/°C`, де `1 ppm = 10⁻⁶`):

```text
R_shunt(T) = R_0 · [1 + TCR · 10⁻⁶ · (T_amb - T_0 + ΔT_shunt)]
```

Відносна зміна опору шунта за рахунок сумісного впливу початкового допуску виготовлення `Tol_R` та теплового саморозігріву:

```text
u_rel(R_shunt) = Tol_R + TCR · 10⁻⁶ · [|T_amb - T_0| + (I_load² · R_shunt · R_th_ja)]
```

### 4. Покроковий числовий розрахунок для реальної системи

Розрахуємо гарантовану похибку вимірювання струму й потужності для бортової системи з такими параметрами:
- Номінальна напруга шини: `V_bus = 24 В`.
- Максимальний робочий струм: `I_max = 10 А`.
- Мінімальний вимірюваний струм: `I_min = 100 мА = 0.1 А`.
- Шунт: `R_0 = 5 мОм = 0.005 Ом`, початковий допуск `Tol_R = 0.5% = 0.005`, `TCR = 50 ppm/°C`, тепловий опір монтажу `R_th_ja = 40 °C/Вт`.
- Температура середовища: `T_amb = 45 °C` (перегрів середовища `T_amb - T_0 = 20 °C`).
- Паразитний тепловий градієнт між виводами шунта: `ΔT_grad = 2 °C`, термоелектричний коефіцієнт `S_Seebeck = 1.5 мкВ/°C` (термо-ЕРС `V_th = 3.0 мкВ`).
- Монітор живлення INA226: `V_os = 10 мкВ = 10⁻⁵ В`, `CMRR = 126 дБ`, похибка підсилення `ε_gain = 0.1% = 0.001`, `V_LSB = 2.5 мкВ`.
- Канал напруги шини INA226: похибка вимірювання `V_bus` складає `ε_Vbus = 0.1% = 0.001`, `V_bus_LSB = 1.25 мВ`.

#### Крок 1. Розрахунок синфазного зсуву підсилювача

```text
V_os_cm = V_bus · 10^(-CMRR / 20)
= 24 · 10^(-126 / 20)                   [переведення дБ у лінійний коефіцієнт: 10^(-6.3) = 5.012·10^(-7)]
= 24 · 5.012·10^(-7)                    [множення на напругу шини 24 В]
= 1.203·10^(-5) В = 12.03 мкВ           [еквівалентне синфазне зміщення нуля]
```

Сумарне зміщення нуля підсилювача з урахуванням власного зміщення, синфазного впливу та термо-ЕРС Зеєбека:

```text
V_os_total = V_os + V_os_cm + V_th
= 10.0 + 12.03 + 3.0                    [додавання власного зміщення, CMRR витоку та термопари]
= 25.03 мкВ
```

#### Крок 2. Аналіз похибок на максимальному струмі (I = 10 А)

1. Спад напруги на шунті:
```text
V_shunt = 10 А · 0.005 Ом = 0.050 В = 50 мВ = 50000 мкВ
```

2. Відносна похибка вимірювання напруги шунта:
```text
u_rel(V_shunt) = (V_os_total + V_LSB / 2) / V_shunt + ε_gain
= (25.03 мкВ + 1.25 мкВ) / 50000 мкВ + 0.001
= 26.28 / 50000 + 0.001                 [частка зміщення нуля: 0.0526%]
= 0.000526 + 0.001                      [додавання похибки підсилення]
= 0.001526 (0.153%)
```

3. Теплове розсіювання та перегрів шунта:
```text
P_loss = (10 А)² · 0.005 Ом = 100 · 0.005 = 0.50 Вт
ΔT_shunt = 0.50 Вт · 40 °C/Вт = 20.0 °C [перегрів шунта від струму]
T_total_delta = (45 °C - 25 °C) + 20.0 °C = 40.0 °C [сумарний перегрів від 25 °C]
```

4. Відносний дрейф опору шунта:
```text
u_rel(R_shunt) = Tol_R + TCR · 10^(-6) · T_total_delta
= 0.005 + 50 · 10^(-6) · 40.0           [термічний приріст опору: 50 · 10^(-6) · 40 = 0.002 = 0.2%]
= 0.005 + 0.002                         [додавання початкового допуску 0.5%]
= 0.0070 (0.70%)
```

5. Сумарна похибка вимірювання потужності при 10 А:
```text
u_rel(P) = √[ u_rel(V_bus)² + u_rel(V_shunt)² + u_rel(R_shunt)² ]
= √[ (0.001)² + (0.001526)² + (0.0070)² ]
= √[ 1.0·10^(-6) + 2.33·10^(-6) + 49.0·10^(-6) ]
= √[ 52.33·10^(-6) ]
= 0.00723 (0.723%)
```

На великому струмі понад 93% невизначеності потужності визначається виключно шунтом: його початковим допуском (0.5%) та тепловим дрейфом від саморозігріву (0.2%).

#### Крок 3. Аналіз похибок на малому струмі (I = 100 мА)

1. Спад напруги на шунті:
```text
V_shunt = 0.1 А · 0.005 Ом = 0.0005 В = 0.5 мВ = 500 мкВ
```

2. Відносна похибка вимірювання напруги шунта:
```text
u_rel(V_shunt) = (26.28 мкВ / 500 мкВ) + 0.001
= 0.05256 + 0.001                       [частка зміщення нуля зросла до 5.256%!]
= 0.05356 (5.356%)
```

3. Теплове розсіювання:
```text
P_loss = (0.1 А)² · 0.005 Ом = 0.01 · 0.005 = 0.00005 Вт = 50 мкВт  [саморозігрів мізерний]
ΔT_shunt ≈ 0 °C
T_total_delta = 45 °C - 25 °C = 20.0 °C
u_rel(R_shunt) = 0.005 + 50 · 10^(-6) · 20.0 = 0.005 + 0.001 = 0.0060 (0.60%)
```

4. Сумарна похибка вимірювання потужності при 100 мА:
```text
u_rel(P) = √[ u_rel(V_bus)² + u_rel(V_shunt)² + u_rel(R_shunt)² ]
= √[ (0.001)² + (0.05356)² + (0.0060)² ]
= √[ 1.0·10^(-6) + 2868.7·10^(-6) + 36.0·10^(-6) ]
= √[ 2905.7·10^(-6) ]
= 0.0539 (5.39%)
```

На малому струмі похибка зміщення нуля підсилювача та синфазного витоку стає абсолютно домінуючим чинником, піднімаючи сумарну похибку вимірювання потужності до 5.4%.

### 5. Інженерні висновки для проектування

1. **Компроміс номіналу шунта**: збільшення опору шунта з 5 мОм до 10 мОм зменшує похибку на 100 мА вдвічі (з 5.4% до 2.7%), але подвоює виділення тепла на 10 А (з 0.5 Вт до 1.0 Вт).
2. **Вибір сплаву резистора**: заміна стандартного металоплівкового резистора з `TCR = 100 ppm/°C` на прецизійний сплав (наприклад, манганін або Zeranin з `TCR ≤ 15 ppm/°C`) знижує тепловий дрейф на максимальному струмі з 0.4% до менш ніж 0.06%.
3. **Програмне калібрування зміщення нуля**: виконання калібрування зміщення нуля при відключеному навантаженні компенсує `V_os`, синфазне зміщення `V_os_cm` та паразитну термо-ЕРС `V_th`, знижуючи похибку на малих струмах до рівня шуму квантування АЦП (менше 0.3%).
