# 🔌 Давач живлення (струм і напруга на борту)

<preknowlist>
- [Шунт Кельвіна](root:hw-sensing/kelvin-shunt) — чотирипровідне підключення та усунення паразитного опору клем і пайки.
- [Монітор струму](root:hw-sensing/current-monitor) — базовий тракт диференційного підсилення мілівольтового спаду напруги.
- [Давач Холла](root:hw-sensing/hall-sensor) — вимірювання магнітного поля струмопровідного провідника на ефекті Холла.
- [Похибки АЦП](root:hw-sensing/adc-errors) — зміщення нуля, похибка квантування, диференційна нелінійність та температурний дрейф.
</preknowlist>

Коли літій-полімерна батарея живить бортовий комп'ютер і тягові мотори безпілотного апарата, спроба оцінити залишок енергії виключно за напругою на клемах гарантовано призводить до аварійного відключення в польоті. Під час різкого прискорення внутрішній опір акумулятора (`15–30 мОм`) під навантаженням струмом 40 А викликає миттєве просідання напруги на `0.6–1.2 В`, що контролер помилково сприймає як повний розряд; водночас у режимі зависання на малому струмі напруга відновлюється, маскуючи вичерпання хімічної ємності комірок. Щоб система знала реальний стан джерела живлення, миттєву споживану потужність і накопичену витрату енергії, на борту встановлюють комбінований **давач живлення** (англ. *power monitor*, *power sensing IC*). Він одночасно фіксує напругу високовольтної шини, струм навантаження та апаратно перемножує їх у реальному часі.

### Фізична тріада моніторингу живлення: напруга, струм, енергія

Для повного контролю електричного живлення бортової апаратури недостатньо знати лише один параметр. Електричне живлення описується трьома нерозривно пов'язаними фізичними величинами:
1. **Напруга шини живлення `V_bus`** (лат. *tensio* — натяг, потенціал): показує рівень електричного потенціалу відносно системної землі. Вона визначає, чи перебуває напруга акумулятора або виходу DC-DC перетворювача у допустимих робочих межах (наприклад, `3.0–4.2 В` на комірку LiPo, `12 В` або `24 В` бортової мережі).
2. **Струм навантаження `I_load`** (лат. *currere* — бігти, потік заряду): показує миттєву інтенсивність споживання електронів споживачами (моторами, радіомодулями, процесорами). Струм потрібен для виявлення перевантаження, захисту від короткого замикання та обліку витраченого заряду `Q = ∫ I dt` (кулонометрія, англ. *coulomb counting*).
3. **Миттєва електрична потужність `P` та енергія `E`**: добуток напруги на струм `P = V_bus · I_load` (вимірюється у ватах). Інтеграл потужності за часом `E = ∫ P dt` дає фактично спожиту енергію у джоулях або ват-годинах.

Звичайний підсилювач струму (англ. *current-sense amplifier*, CSA) міряє лише струм і видає аналогову напругу. Для розрахунку потужності мікроконтролер мусив би запустити два окремих канали АЦП — один для струму, другий для напруги, — а потім перемножити отримані значення програмно. Якщо навантаження імпульсне (наприклад, ШІМ-керування мотором на частоті 20 кГц або сплески передавача зв'язку), будь-який часовий зсув між вибірками струму й напруги призводить до фазової похибки обчислення потужності.

Інтегральний цифровий монітор живлення усуває цей розрив: він містить прецизійний аналоговий тракт для струму, дільник для високої напруги шини, здвоєний синхронізований АЦП і внутрішній апаратний помножувач, який видає готові значення струму, напруги та потужності через цифрову шину I2C або SPI.

> 🔧 **Навіщо це.** У системах супутникового живлення (EPS кубсатів), польотних контролерах дронів та базових станціях зв'язку монітор живлення виконує роль цифрового лічильника електроенергії. Він дозволяє будувати адаптивні профілі енергоспоживання: якщо напруга сонячної панелі падає нижче точки максимальної потужності (MPPT), контролер миттєво знижує струм передавача, запобігаючи колапсу бортової мережі.

### Топології вимірювального шунта: High-Side проти Low-Side

Найпоширенішим способом перетворення сили струму на електричний сигнал є вимірювання спаду напруги `V_shunt` на прецизійному резисторі (шунті) малого опору `R_shunt` (від 0.5 мОм до 50 мОм) за законом Ома:

```text
V_shunt = I_load · R_shunt
```

Шунт вмикається в розрив силового кола послідовно з навантаженням. Залежно від того, в який провідник інтегровано шунт — у плюсову лінію живлення чи у зворотну лінію землі, — виникають дві принципово різні топології: **High-Side** (висока сторона) та **Low-Side** (низька сторона).

![Топології вимірювання струму: High-Side та Low-Side](/root/hw/hw-sensing/power-monitor/img/fig-power-monitor-topology.svg)
*Зліва: включення шунта на високій стороні (High-Side). Земля навантаження жорстко з'єднана з системною землею GND, будь-яке замикання на землю проходить крізь шунт, але входи підсилювача перебувають під високим синфазним потенціалом. Справа: включення на низькій стороні (Low-Side). Синфазна напруга близька до нуля, але струм створює плаваючий потенціал землі навантаження, а аварійне замикання плюсової шини на корпус лишається непоміченим.*

#### Низька сторона (Low-Side Sensing)

При Low-Side включенні шунт розташовується між виводом повернення навантаження та загальною системною землею (GND).

**Переваги:**
- Синфазна напруга на виводах шунта близька до нуля (`V_CM ≈ 0 В`). Для зняття сигналу достатньо найпростішого недорогого операційного підсилювача або навіть прямого підключення до диференційного входу АЦП мікроконтролера.

**Недоліки та небезпеки:**
1. **Зсув потенціалу землі (Ground Bounce)**: навантаження більше не має прямого з'єднання зі справжньою землею системи. Його локальний нульовий потенціал «піднятий» над системною землею на величину `V_GND_shift = I_load · R_shunt`. Якщо навантаження споживає 20 А через шунт 10 мОм, його земля виявляється піднятою на `+200 мВ`. Це спотворює роботу цифрових ліній зв'язку (UART, SPI, I2C), оскільки логічні рівні зміщуються відносно порогів спрацьовування приймача.
2. **Сліпота до короткого замикання на корпус**: якщо в навантаженні стається пробій ізоляції або випадкове замикання плюсового проводу живлення на металеве заземлене шасі, аварійний струм тече безпосередньо в землю в обхід шунта. Монітор струму реєструє нульовий струм і не може ініціювати захисне вимкнення.

#### Висока сторона (High-Side Sensing)

При High-Side включенні шунт встановлюється безпосередньо після джерела живлення (акумулятора чи виходу перетворювача) перед навантаженням у плюсовому провіднику.

**Переваги:**
- Локальна земля навантаження залишається чистою системною землею (`0 В`), що усуває проблеми з інтерфейсами зв'язку.
- Будь-який струм, що виходить із джерела — чи то робочий струм навантаження, чи струм короткого замикання на землю, — обов'язково проходить крізь шунт. Монітор надійно детектує аварійні витоки та перевантаження.

**Виклики схемотехніки:**
Обидва виводи шунта підняті до високої напруги живлення шини (`V_CM = V_bus = 12 В, 24 В, 48 В, 80 В`). Корисний вимірюваний сигнал спаду напруги `V_shunt` становить лише кілька мілівольтів (наприклад, 10 мВ). Підсилювач зобов'язаний виділити цей диференційний сигнал на тлі синфазної напруги, яка перевищує його в тисячі разів. Це вимагає надзвичайно високого коефіцієнта придушення синфазного сигналу (CMRR > 120 дБ) та вхідних транзисторів із високою напругою пробою.

### Чотирипровідне підключення за Кельвіном

На великих струмах опір контактних майданчиків, паяних швів і мідних доріжок друкованої плати стає порівнянним з опором самого шунта. Питомий опір стандартної мідної доріжки товщиною 35 мкм (1 oz/ft²) і шириною 1 мм становить близько `0.5 мОм/см`. Якщо для шунта номіналом `2 мОм` підключити вимірювальні провідники через силові контактні площадки, паразитний опір пайки та доріжок додасть ще `0.5–1.0 мОм`, що внесе неприпустиму систематичну похибку вимірювання до `25–50%`.

Для усунення цієї похибки застосовують чотирипровідне підключення Кельвіна. Струм навантаження тече через дві потужні силові клеми, а вимірювання напруги знімається двома окремими прецизійними сенсорними доріжками (Sense+ та Sense-), підведеними безпосередньо під резистивне тіло шунта. Оскільки вхідний опір вимірювача струму дуже великий (мегаоми), струм через сенсорні доріжки не тече, і спад напруги на них дорівнює нулю. Сенсорні провідники розводять на платі як щільну симетричну диференційну пару однакової довжини, щоб зовнішні електромагнітні наведення від силових ключів наводилися на обидва провідники однаково і повністю придушувалися диференційним каскадом.

Детальний фізичний аналіз термоелектричних явищ і геометрії струмових доріжок наведено у статті [Шунт Кельвіна](root:hw-sensing/kelvin-shunt).

### Архітектура інтегральних моніторів живлення (INA226, INA219, PAC1934)

Сучасні цифрові монітори живлення об'єднують в одному кремнієвому кристалі повний вимірювально-обчислювальний конвеєр. Розглянемо внутрішню архітектуру на прикладі промислового стандарту — мікросхеми INA226 від Texas Instruments, а також багатоканального монітора PAC1934 від Microchip.

![Внутрішня архітектура цифрового монітора живлення INA226](/root/hw/hw-sensing/power-monitor/img/fig-ina226-architecture.svg)
*Блок-схема цифрового монітора живлення INA226. Диференційний сигнал із шунта підсилюється чоппер-каскадом із придушенням зміщення (V_OS < 10 мкВ, CMRR > 120 дБ), оцифровується 16-розрядним дельта-сигма АЦП і подається на апаратний помножувач разом із напругою шини VBUS. Регістри зберігають сирі значення, струм, потужність та керують виводом тривоги ALERT.*

#### 1. Вхідний каскад із чопперною стабілізацією (Chop-Stabilized PGA)

Спад напруги на шунті подається на входи `IN+` та `IN-`. Головною проблемою напівпровідникових підсилювачів є власна напруга зміщення нуля `V_os` та низькочастотний флікер-шум `1/f`. Якщо зміщення нуля складає `50 мкВ`, то при вимірюванні малого струму з сигналом `V_shunt = 200 мкВ` похибка становитиме 25%.

Для боротьби з цим вхідний підсилювач із програмованим коефіцієнтом підсилення (PGA) будується за технологією **чопперної стабілізації** (англ. *chopper stabilization*, від *to chop* — рубати, модулювати). Вхідні ключі комутують полярність сигналу з високою частотою (наприклад, 500 кГц). Корисний постійний сигнал переноситься на частоту модуляції, де немає флікер-шуму, підсилюється змінним підсилювачем, а потім синхронно демодулюється назад у постійну напругу. Власне зміщення підсилювача при цьому перетворюється на змінну напругу та відфільтровується цифровим фільтром. Завдяки чопперу INA226 досягає екстремально низького зміщення нуля `V_os ≤ 10 мкВ` і дрейфу `dV_os/dT ≤ 0.1 мкВ/°C` при придушенні синфазного сигналу `CMRR ≥ 126 дБ`.

#### 2. Аналогово-цифрове перетворення: дельта-сигма (ΔΣ) модулятор

Для перетворення напруги шунта та напруги шини використовується 16-розрядний дельта-сигма АЦП із вбудованим цифровим фільтром низьких частот (Sinc-фільтром). Час інтегрування одного перетворення налаштовується програмно в діапазоні від `140 мкс` до `8.244 мс`.

Крім того, мікросхема підтримує апаратне накопичення та усереднення вибірок (1, 4, 16, 64, 128, 256, 512, 1024 вибірок). Усереднення на 16 або 64 вибірках дозволяє повністю придушити пульсації імпульсних джерел живлення та мерехтіння мережі частотою 50/60 Гц, знижуючи шум вимірювання до рівня часток мікровольта.

#### 3. Вимірювання напруги шини (Канал VBUS)

Окремий вхід `VBUS` підключається до плюсової шини живлення і здатний приймати напругу від `0 В` до `36 В` (у спеціалізованих високовольтних чіпах, таких як INA228 або LTC2944 — до `85 В` або `100 В`). Внутрішній прецизійний дільник напруги послаблює сигнал шини до діапазону роботи АЦП, забезпечуючи крок дискретизації `1.25 мВ / LSB`.

#### 4. Апаратний цифровий помножувач і регістри енергії

На відміну від простих АЦП, монітор живлення містить апаратний математичний блок (Hardware Math Engine). Після завершення вимірювання спаду на шунті та напруги шини цифровий помножувач виконує дві послідовні операції:
1. **Обчислення струму**: вміст регістра напруги шунта перемножується з користувацьким калібрувальним значенням `CAL` і ділиться на апаратну константу:
```text
Current = (Shunt_Voltage_Raw · CAL) / 2048
```
2. **Обчислення потужності**: обчислений струм перемножується з напругою шини:
```text
Power = (Current · Bus_Voltage_Raw) / Scale_Factor
```

У мікросхемах розширеного моніторингу (наприклад, чотириканальному PAC1934) кристал додатково містить 48-розрядні регістри-акумулятори потужності та 28-розрядний лічильник вибірок. Монітор самостійно інтегрує добутки потужності на високій частоті (до 1024 вибірок/с), накопичуючи енергію `E = ∑ (V_bus · I · Δt)` та електричний заряд `Q = ∑ (I · Δt)`. Це дозволяє мікроконтролеру спати у глибокому режимі енергозбереження й прокидатися раз на хвилину, щоб прочитати готовий інтеграл енергії без втрати швидких перехідних процесів споживання.

#### 5. Апаратний компаратор тривог (Вивід ALERT)

Вивід `ALERT` з відкритим стоком дозволяє апаратно захищати систему від аварій без постійного опитування шини I2C. Компаратор монітора порівнює виміряні величини з пороговим регістром `ALERT_LIMIT` і формує переривання за такими подіями:
- `Shunt Over-Limit`: перевищення граничного струму (струмовий захист від перевантаження або КЗ).
- `Bus Under-Voltage`: просідання напруги батареї нижче критичного порогу розряду.
- `Bus Over-Voltage`: перевищення максимальної напруги (перенапруга при рекуперативному гальмуванні моторів).
- `Power Over-Limit`: перевищення сумарного ліміту споживаної потужності.
- `Conversion Ready`: сигнал завершення циклу вибірки для синхронного зчитування.

### Динамічні завади ШІМ та еквівалентна індуктивність шунта (ESL)

У системах керування безколекторними моторами (BLDC) або імпульсними перетворювачами напруга на шунті містить не лише постійну складову, але й високочастотні комутаційні стрибки з крутизною наростання `dv/dt > 10 В/нс`. На таких швидкостях проявляється паразитна **еквівалентна послідовна індуктивність шунта** (англ. *Equivalent Series Inductance*, ESL), яка для стандартних SMD-резисторів типорозміру 2512 становить `0.5–3.0 нГн`.

Під час комутації транзистора швидка зміна струму `di/dt` генерує індуктивний викид напруги на клемах шунта:

```text
V_meas(t) = I(t) · R_shunt + L_ESL · (di/dt)
```

При швидкості наростання струму `di/dt = 10 А/мкс` та індуктивності `L_ESL = 2 нГн` амплітуда індуктивного сплеску досягає:

```text
V_spike = 2·10^(-9) Гн · (10 А / 10^(-6) с) = 20 мВ
```

Цей викид у 20 мВ може в кілька разів перевищувати корисний омічний сигнал `V_shunt = 10 мВ`, перевантажуючи вхідний підсилювач монітора живлення.

Для компенсації індуктивності шунта застосовують спеціальний фазокомпенсуючий RC-ланцюг на сенсорних доріжках. Якщо підібрати сталу часу диференційного фільтра рівною сталій часу індуктивності шунта:

```text
2 · R_filt · C_diff = L_ESL / R_shunt
```

то передавальна характеристика вимірювального тракту стає чисто аперіодичною без резонансних сплесків, повністю усуваючи паразитну індуктивну складову напруги.

Крім того, швидка зміна синфазної напруги шини `dv/dt` під час перемикання силових транзисторів викликає ємнісні струми витоку крізь паразитну ємність вхідних каскадів мікросхеми:

```text
i_disp = C_parasitic · (dv/dt)
```

Здатність монітора витримувати такі перехідні процеси без фальшивих спрацьовувань компаратора визначається параметром стійкості до синфазних перехідних завад (англ. *Common-Mode Transient Immunity*, CMTI), який у сучасних підсилювачах струму досягає `50–100 кВ/мкс`.

### Багатоканальні архітектури моніторингу (INA3221, PAC1934)

У складних гетерогенних обчислювальних вузлах (наприклад, одноплатних комп'ютерах на базі SoC, платах із FPGA або серверах) одночасно присутні кілька шин вторинного живлення:
- Шина ядра процесора (`V_CORE = 0.8–1.1 В`, струм до 15–30 А).
- Шина пам'яті DDR4/DDR5 (`V_DDR = 1.1–1.2 В`).
- Шини периферії (`1.8 В`, `3.3 В`, `5.0 В`).
- Загальна вхідна шина живлення (`12 В` або `24 В`).

Встановлення окремого одномікросхемного монітора на кожну лінію збільшує площу друкованої плати та навантажує шину I2C. Для таких систем використовують багатоканальні монітори живлення, такі як триканальний INA3221 або чотириканальний PAC1934.

У мікросхемі INA3221 три диференційних вхідних канали підсилювачів струму комутуються на один внутрішній мультиплексований 12-розрядний АЦП. Важливою схемотехнічною особливістю є те, що всі три канали мають спільну землю і призначені для роботи в межах одного діапазону синфазних напруг (від `0 В` до `26 В`). Для кожного каналу передбачено індивідуальні виводи попереджувальної тривоги (Warning) та аварійного відключення (Critical), що дозволяє будувати апаратну секвенцію живлення (Power Sequencing): якщо живлення ядра процесора перевищує струмовий ліміт, лінія Critical апаратно скидає сигнал Power Good регулятора ядра, не чекаючи зависання всієї операційної системи.

### Альтернатива шунту: давачі струму на ефекті Холла

Хоча резистивний шунт є найпростішим і найточнішим методом вимірювання, на струмах понад `30–50 А` його омічні втрати тепла `P = I² · R` стають руйнівними. Наприклад, на струмі 100 А навіть мініатюрний шунт `1 мОм` розсіює `P = 100² · 0.001 = 10 Вт` тепла, що вимагає масивного радіатора і спричиняє сильний саморозігрів плати. Крім того, шунт не забезпечує гальванічної розв'язки при вимірюванні струму у високовольтних колах (наприклад, у батареях електромобілів напругою 400–800 В).

У таких застосуваннях альтернативою виступають інтегральні давачі струму на ефекті Холла (грец. *Hall effect*, відкритий Едвіном Холлом у 1879 році), такі як Allegro ACS712, ACS724 або Texas Instruments TMCS1100.

![Порівняння шунта та давача Холла](/root/hw/hw-sensing/power-monitor/img/fig-hall-vs-shunt.svg)
*Зліва: резистивний шунт Кельвіна (прямий контакт, висока точність, нагрів на великих струмах). Справа: давач на ефекті Холла (гальванічна ізоляція 3–5 кВ, низькі втрати, але чутливість до зовнішніх магнітних полів і температурний дрейф зміщення нуля).*

#### Фізичний принцип та будова інтегрального давача Холла

Всередині корпусу мікросхеми (наприклад, SOIC-8) розташована первинна мідна струмова петля з опором всього `0.5–1.2 мОм`. Струм навантаження тече крізь цю петлю, створюючи навколо себе магнітне поле з індукцією `B`, прямо пропорційною струму за законом Біо-Савара-Лапласа:

```text
B = μ₀ · I / (2 · π · r)
```

Безпосередньо над мідною петлею, відокремлений тонким шаром діелектричної ізоляції (поліімід чи оксид кремнію товщиною десятки мікрометрів), розташований напівпровідниковий кристал із чутливими елементами Холла. Магнітне поле відхиляє рухомі носії заряду силою Лоренца, генеруючи поперечну холлівську ЕРС:

```text
V_H = (R_H / d) · I_bias · B
```

де `R_H` — коефіцієнт Холла напівпровідника, `d` — товщина шару, `I_bias` — струм зміщення чутливого елемента. Далі ця напруга підсилюється інтегрованим підсилювачем із виходом у вигляді аналогової напруги (типово `VCC/2 ± Sensitivity · I`).

#### Безсердечникові (Coreless) проти сердечникових давачів Холла

Існують два основні класи конструкцій холлівських давачів струму:
1. **З феромагнітним сердечником-концентратором**: первинний силовий провідник охоплений кільцевим сердечником із фериту або пермалою з тонким робочим зазором, у який вставлено елемент Холла. Сердечник підсилює магнітний потік у зазорі в десятки разів, підвищуючи чутливість і екрануючи від зовнішніх полів. Проте феромагнітний матеріал має істотні недоліки:
   - **Магнітне насичення `B_sat`**: на великих імпульсних струмах сердечник входить у насичення, через що вихідна характеристика стає нелінійною.
   - **Магнітний гістерезис і залишкова індукція**: після проходження короткого замикання струмом 100 А в сердечнику залишається залишкове поле, яке створює фальшивий зсув нуля струму до 1–3 А.
   - **Вихрові струми Фуко**: на високих частотах у сердечнику виникають втрати на перемагнічування.
2. **Безсердечникові інтегральні давачі (Coreless ICs)**: первинний провідник інтегровано безпосередньо у вивідну рамку мікросхеми без феромагнетиків. Вони повністю позбавлені гістерезису й насичення, але мають меншу чутливість і вимагають прецизійного диференційного тракту для компенсації зовнішнього фону.

#### Порівняльний аналіз: Шунт проти Холла

| Критерій | Резистивний шунт + монітор (INA226) | Давач Холла (ACS712 / TMCS1100) |
|---|---|---|
| **Гальванічна розв'язка** | Немає (спільний потенціал із шиною) | **Є (3–5 кВ RMS ізоляційний бар'єр)** |
| **Максимальна напруга шини** | Обмежена мікросхемою (36–85 В) | **Не обмежена (до 600–1200 В робочої напруги)** |
| **Втрати потужності на 100 А** | Великі (10 Вт при 1 мОм) | **Мінімальні (0.5–1.2 Вт)** |
| **Точність вимірювання** | **Висока (0.1–0.5% у всьому діапазоні)** | Середня (1.5–3.0%) |
| **Зміщення нуля (Zero Offset)** | **Екстремально низьке (< 10 мкВ)** | Помітне (10–50 мВ на виході) |
| **Чутливість до магнітних полів** | **Повністю нечутливий** | Чутливий до полів моторів і дроселів |
| **Магнітний гістерезис** | **Відсутній** | Присутній при наявності концентратора |
| **Смуга пропускання** | Обмежена фільтром АЦП (до 100 кГц) | **Широка (80–250 кГц у реальному часі)** |

#### Проблема паразитної магнітної завади та диференційний Холл

Головним недоліком простих давачів Холла (як-от ACS712) є чутливість до зовнішніх магнітних полів (англ. *stray magnetic fields*). Якщо поруч із давачем на відстані 1 см проходить силовий дріт тягового мотора зі струмом 50 А, створене ним магнітне поле наводиться на кристал Холла і створює фальшивий сигнал струму величиною в кілька амперів.

Сучасні прецизійні давачі (наприклад, TMCS1100 від TI) використовують **диференційну топологію Холла**: на кристалі розміщують два просторово рознесених елементи Холла. Силовий провідник мікросхеми розведений у формі U-подібної петлі, тому струм навантаження створює на першому елементі позитивне магнітне поле `+B`, а на другому — негативне `-B`. Зовнішнє однорідне магнітне поле наводки накриває обидва елементи однаково (`+B_ext`). Диференційний підсилювач віднімає сигнали:

```text
V_diff = (+B + B_ext) - (-B + B_ext) = 2 · B
```

Зовнішнє паразитне поле `B_ext` повністю знищується, забезпечуючи стійкість до магнітних завад у силових перетворювачах.

### Метрологія, джерела похибок та температурний дрейф

Повна похибка вимірювання струму та потужності на шунті не є сталою величиною — вона сильно змінюється залежно від величини струму навантаження.

![Розподіл похибок вимірювання за діапазоном струму](/root/hw/hw-sensing/power-monitor/img/fig-error-budget-tcr.svg)
*Крива сумарної похибки вимірювання струму та потужності. На малих струмах домінує напруга зміщення нуля підсилювача V_OS (похибка зростає за гіперболою). У середньому діапазоні точність максимальна і визначається допуском компонентів. На великих струмах похибка зростає через джоулів саморозігрів шунта та температурний коефіцієнт опору TCR.*

#### 1. Зона малого струму: домінування зміщення нуля (V_os)

На малому струмі спад напруги на шунті стає сумірним із власною напругою зміщення вхідного підсилювача `V_os`. Відносна похибка від зміщення нуля описується виразом:

```text
ε_offset = V_os / (I_load · R_shunt)
```

Якщо `R_shunt = 2 мОм`, а підсилювач має зміщення `V_os = 20 мкВ`, то при струмі `I = 100 А` сигнал `V_shunt = 200 мВ`, і похибка становить мізерні `0.01%`. Але при струмі `I = 0.5 А` корисний сигнал складає лише `1 мВ`, і те саме зміщення дає похибку `20 мкВ / 1000 мкВ = 2.0%`. При струмі `50 мА` похибка злетить до `20%`.

#### 2. Зона великого струму: саморозігрів і температурний коефіцієнт (TCR)

На великому струмі сигнал настільки великий, що зміщення підсилювача не грає ролі. Тут головним джерелом похибки стає виділення джоулевого тепла `P = I² · R_shunt`.

Опір металів зростає з нагрівом відповідно до температурного коефіцієнта опору TCR (англ. *Temperature Coefficient of Resistance*, вимірюється в `ppm/°C`, де `100 ppm/°C = 0.01%/°C`):

```text
R(T) = R_0 · [1 + TCR · 10⁻⁶ · ΔT]
```

Звичайний дешевий товстоплівковий резистор має `TCR = 100–200 ppm/°C`. Якщо шунт нагрівається під струмом на `ΔT = 60 °C`, його опір збільшується на `200 · 10⁻⁶ · 60 = +1.2%`. Це означає, що монітор струму завищить результат на `+1.2%` лише через нагрів резистора.

Щоб мінімізувати цей дрейф, у прецизійних вимірювачах живлення застосовують спеціальні масивні шунти з металоплівкових або суцільнометалевих сплавів:
- **Манганін** (сплав Cu-Mn-Ni): `TCR = 10–20 ppm/°C`.
- **Константан** (Cu-Ni): `TCR = 15–30 ppm/°C`.
- **Zeranin / Isaohm** (патентовані сплави Isabellenhütte): `TCR ≤ 3–10 ppm/°C` у діапазоні від -40°C до +120°C.

#### 3. Паразитна термо-ЕРС (ефект Зеєбека)

У місцях пайки резистивного сплаву шунта до мідних доріжок плати утворюються спаї двох різних металів (наприклад, `Cu-Manganin`). Якщо на платі існує градієнт температур (наприклад, поруч розташований гарячий польовий транзистор чи діод), один спай шунта нагрівається сильніше за інший.

Різниця температур `ΔT_joint` створює паразитну термоелектричну напругу Зеєбека `V_th = S · ΔT_joint` (де коефіцієнт Зеєбека для пари мідь-сплав становить `1–3 мкВ/°C`). Різниця температур усього в `5 °C` між кінцями шунта згенерує паразитну постійну напругу `10–15 мкВ`, яка додасться до виміряного значення струму як систематичне зміщення.

Повний математичний апарат розрахунку комбінованої невизначеності наведено у вставці [Розрахунок невизначеності вимірювання потужності](root:hw-sensing/power-monitor/math-shunt-power-uncertainty.md).

### Схемотехнічна обв'язка та фільтрація

Для отримання паспортерної точності мікросхеми монітора живлення необхідне правильне проектування друкованої плати та вхідних фільтрів.

```text
                  Силова шина +V_BUS (наприклад, +24 В)
   ──────┬───────────────────[ Шунт R_shunt ]──────────────────┬──────→ До навантаження
         │                      5 мОм                          │
         │  Sense+                                     Sense-  │
         │  (Кельвін)                                  (Кельвін)
         │                                                     │
         ├───[ R_filt 10 Ом ]───┬──────────────┬───[ R_filt 10 Ом ]───┤
         │                      │              │                      │
         │                   [ C_diff ]     [ C_cm ]               [ C_cm ]
         │                    100 нФ         10 нФ                  10 нФ
         │                      │              │                      │
         │                      │             GND                    GND
         │                      │              │
         │                      ▼              ▼
         │                 ┌───────────────────────┐
         └─────────────────┤ VBUS       IN+    IN- ├───────────────────┘
                           │                       │
                           │        INA226         │
                           │                       │
                  GND ─────┤ GND               SDA ├────── I2C SDA
                           │                       │
                 +3.3V ────┤ VS                SCL ├────── I2C SCL
                           │                       │
                  C_dec ───┤ C_bypass        ALERT ├────── До GPIO переривання MCU
                 100 нФ    └───────────────────────┘
```

1. **Диференційний RC-фільтр низьких частот**: резистори `R_filt = 10 Ом` і конденсатор `C_diff = 100 нФ` утворюють диференційний фільтр із частотою зрізу `f_c = 1 / (2 · π · 2·R_filt · C_diff) ≈ 80 кГц`. Він зрізає високочастотний комутаційний дзвін від DC-DC перетворювачів до того, як завада потрапить на вхід дельта-сигма модулятора.
2. **Синфазні конденсатори `C_cm`**: конденсатори номіналом `10 нФ` на землю фільтрують синфазні наведення. Номінали резисторів `R_filt` не повинні перевищувати 10–20 Ом, оскільки вхідний струм зміщення мікросхеми (близько 10 нА), протікаючи крізь великі резистори, створить додаткове зміщення напруги.
3. **Блокувальний конденсатор живлення `C_dec`**: керамічний конденсатор `0.1 мкФ` (X7R) встановлюється якомога ближче до виводу `VS` мікросхеми для придушення цифрових завад по шині живлення.

### Програмна конфігурація та драйвер для мікроконтролера

Для роботи з монітором живлення мікроконтролер виконує таку послідовність дій:
1. Запис конфігураційного слова в регістр `CONFIG` (вибір часу вибірки `1.1 мс` та усереднення на 16 вибірок для фільтрації шумів).
2. Розрахунок та запис масштабного коефіцієнта в регістр `CALIBRATION`.
3. Періодичне зчитування або зчитування за перериванням `ALERT` регістрів `BUS_VOLTAGE`, `CURRENT` та `POWER`.

Нижче наведено фрагмент конфігурації та читання мовами C та C++:

:::tabs
```c
#include <stdint.h>
#include <stdbool.h>

/* Розрахунок калібрувального коефіцієнта для INA226 */
uint16_t calculate_ina226_calibration(double r_shunt_ohms, double max_current_a, double *current_lsb_a) {
    /* Крок струму: Current_LSB = Max_Current / 2^15 */
    *current_lsb_a = max_current_a / 32768.0;
    /* CAL = trunc(0.00512 / (Current_LSB * R_shunt)) */
    double cal = 0.00512 / ((*current_lsb_a) * r_shunt_ohms);
    return (uint16_t)cal;
}

/* Перетворення сирих 16-розрядних регістрів у фізичні величини */
void parse_power_readings(uint16_t vbus_raw, int16_t current_raw, uint16_t power_raw,
                          double current_lsb_a, uint32_t *vbus_mv, int32_t *current_ma, uint32_t *power_mw) {
    /* VBUS LSB фіксований: 1.25 мВ */
    *vbus_mv = (uint32_t)((vbus_raw * 1250ULL) / 1000ULL);
    /* Струм у мА */
    *current_ma = (int32_t)(current_raw * current_lsb_a * 1000.0);
    /* Потужність: Power_LSB = 25 * Current_LSB (у Вт) -> переводимо в мВт */
    double power_lsb_w = 25.0 * current_lsb_a;
    *power_mw = (uint32_t)(power_raw * power_lsb_w * 1000.0);
}
```

    }

        };

### Підсумковий інженерний вибір

Вибір між архітектурами моніторингу живлення визначається трьома критичними факторами системи:

1. **Струми до 30–50 А та напруга до 36–80 В**: беззаперечним лідером є зв'язка **прецизійний шунт Кельвіна + High-Side монітор (INA226/INA228)**. Вона забезпечує максимальну точність (похибка < 0.2%), цілісність системної землі та надійне детектування коротких замикань при мінімальних габаритах і вартості на платі.
2. **Струми понад 50–200 А або високовольтні шини (> 100 В)**: доцільно переходити на **диференційні інтегральні давачі Холла (TMCS1100, ACS724)** або струмові модулі прямого посилення. Вони виключають перегрів плати і забезпечують гальванічну розв'язку силового та логічного доменів.
3. **Автономні акумуляторні системи з низьким енергоспоживанням**: вимагають моніторів з **апаратним інтегруванням енергії (PAC1934)**, які ведуть неперервний облік кулонів та джоулів під час сну центрального процесора.
