# 🧮 Математика рівняння Каллендара–Ван Дюзена: прямий розрахунок та числове обернення

Міжнародний стандарт **IEC 60751** (DIN EN 60751) описує температурну залежність електричного опору промислових платинових термометрів (Pt100, Pt1000) поліномом Каллендара–Ван Дюзена. Розглянемо пряму математичну модель, точне аналітичне обернення для додатної шкали, збіжний ітераційний алгоритм Ньютона–Рафсона для кріогенного діапазону, а також апарат поширення похибок та аналіз чутливості.

### Пряма функція перетворення R(T)

Опір платини описується двома різними рівняннями залежно від знака температури `T` у градусах Цельсія.

Для додатних температур (`0 °C ≤ T ≤ 850 °C`):

```
R(T) = R_0 · (1 + A·T + B·T²)
```

Для від'ємних температур (`-200 °C ≤ T < 0 °C`):

```
R(T) = R_0 · (1 + A·T + B·T² + C·(T - 100)·T³)
```

де константи стандарту IEC 60751 (для платини з температурним коефіцієнтом `α = 0.00385055 °C⁻¹`) становлять:

```
R_0 = 100.0000 Ω       [для датчика Pt100, або 1000.0000 Ω для Pt1000]
A   = +3.90830 × 10⁻³ °C⁻¹
B   = -5.77500 × 10⁻⁷ °C⁻²
C   = -4.18300 × 10⁻¹² °C⁻⁴
```

Фізичний зміст коефіцієнтів у математичній моделі:
- `A > 0` визначає основний лінійний нахил зростання опору;
- `B < 0` відображає квадратичне відхилення через насичення фононного розсіювання при нагріванні металу;
- `C < 0` коригує поведінку кристалічної ґратки нижче точки замерзання води через вимерзання високочастотних фононів.

### Диференціальна чутливість платини dR/dT

Диференціальна чутливість `S(T) = dR/dT` показує, скільки ом приросту опору дає зміна температури на один градус за поточної температури `T`. Продиференціюємо пряме рівняння:

Для `T ≥ 0 °C`:

```
dR/dT = R_0 · (A + 2·B·T)
```

Для `T < 0 °C`:

```
dR/dT = R_0 · (A + 2·B·T - 300·C·T² + 4·C·T³)
```

Оскільки коефіцієнт `B` є від'ємним, чутливість платинового сенсора плавно спадає зі зростанням температури:
- При `T = -200 °C`: `dR/dT ≈ 0.434 Ω/°C` (для Pt100);
- При `T = 0 °C`: `dR/dT = R_0 · A = 0.3908 Ω/°C`;
- При `T = +100 °C`: `dR/dT ≈ 0.3793 Ω/°C`;
- При `T = +850 °C`: `dR/dT ≈ 0.2927 Ω/°C`.

Зменшення чутливості майже в півтора раза на верхньому краї робочого діапазону означає, що за високих температур фіксований шум АЦП вноситиме пропорційно більшу температурну похибку.

### Математичний розрахунок похибки лінійного наближення

У багатьох простих контролерах інженери намагаються застосувати лінійну модель `R_lin(T) = R_0 · (1 + α·T)`, де `α = (R_100 - R_0) / (100 · R_0) = 0.003851 °C⁻¹`. Оцінимо аналітично відхилення лінійної моделі від точного рівняння Каллендара–Ван Дюзена на інтервалі від 0 °C до 100 °C:

```
ΔR(T) = R_CVD(T) - R_lin(T)
ΔR(T) = R_0 · (1 + A·T + B·T²) - R_0 · (1 + α·T)
ΔR(T) = R_0 · ((A - α)·T + B·T²)
```

Знайдемо екстремум похибки, прирівнявши похідну `d(ΔR)/dT` до нуля:

```
d(ΔR)/dT = R_0 · (A - α + 2·B·T) = 0
T_max = (α - A) / (2·B)
T_max = (0.0038510 - 0.0039083) / (2 · (-5.775 × 10⁻⁷)) = (-5.73 × 10⁻⁵) / (-1.155 × 10⁻⁶) ≈ 49.61 °C
```

Максимальне відхилення опору досягається рівно посередині діапазону (біля 50 °C) і становить:

```
ΔR(50 °C) = 100 · ((3.9083×10⁻³ - 3.8510×10⁻³) · 50 + (-5.775×10⁻⁷) · 2500)
ΔR(50 °C) = 100 · (2.865×10⁻³ - 1.444×10⁻³) = +0.1421 Ω
```

Переведемо це відхилення опору в еквівалентну похибку температури `ΔT = ΔR / (dR/dT)`:

```
ΔT_lin(50 °C) ≈ +0.1421 Ω / 0.385 Ω/°C ≈ +0.37 °C
```

Таким чином, навіть у вузькому діапазоні від 0 до 100 °C лінійна модель дає похибку до `0.37 °C`, що перевищує межі допуску Class AA і Class A. За межами цього інтервалу (наприклад, при 500 °C) похибка лінійності стрімко зростає до `+12.8 °C`.

### Аналітичне обернення для T ≥ 0 °C

У діапазоні від `0 °C` до `850 °C` рівняння є квадратичним відносно невідомої температури `T`. Виведемо явну аналітичну формулу `T(R)`:

```
R / R_0 = 1 + A·T + B·T²                                    [поділили на R_0]
B·T² + A·T + (1 - R / R_0) = 0                              [звели до канонічного виду]
D = A² - 4·B·(1 - R / R_0)                                  [дискримінант квадратного рівняння]
T = (-A ± √(A² - 4·B·(1 - R / R_0))) / (2·B)                [загальний розв'язок]
```

Оскільки коефіцієнт `B` є від'ємним (`B < 0`), а фізична температура `T` при `R ≥ R_0` має бути додатною, вибираємо знак мінус перед коренем, щоб уникнути від'ємного результату:

```
T = (-A + √(A² - 4·B·(1 - R / R_0))) / (2·B)                [точний аналітичний розв'язок]
```

**Числовий приклад.** Нехай для Pt100 виміряно опір `R = 138.51 Ω` (очікувана точка кипіння води 100 °C):

```
1 - R / R_0 = 1 - 138.51 / 100.00 = -0.38510
4·B·(1 - R / R_0) = 4 · (-5.7750 × 10⁻⁷) · (-0.38510) = 8.89581 × 10⁻⁷
A² = (3.90830 × 10⁻³)² = 1.52748 × 10⁻⁵
D = 1.52748 × 10⁻⁵ + 8.89581 × 10⁻⁷ = 1.61644 × 10⁻⁵
√D = 4.02050 × 10⁻³
-A + √D = -3.90830 × 10⁻³ + 4.02050 × 10⁻³ = 1.12200 × 10⁻⁴
2·B = 2 · (-5.7750 × 10⁻⁷) = -1.15500 × 10⁻⁶
T = 1.12200 × 10⁻⁴ / (-1.15500 × 10⁻⁶) = 100.000 °C
```

### Числове обернення для T < 0 °C (Метод Ньютона–Рафсона)

Для від'ємних температур рівняння містить четвертий степінь:

```
R(T) = R_0 · (1 + A·T + B·T² - 100·C·T³ + C·T⁴)
```

Розв'язання рівняння четвертого степеня у радикалах Феррарі є громіздким та страждає від втрати точності через віднімання близьких чисел з плаваючою комою. Найкращим інженерним методом є **метод Ньютона–Рафсона**.

Визначимо цільову функцію нев'язки `f(T)` та її аналітичну похідну `f'(T)`:

```
f(T) = R_0 · (1 + A·T + B·T² - 100·C·T³ + C·T⁴) - R
f'(T) = R_0 · (A + 2·B·T - 300·C·T² + 4·C·T³)
```

Ітераційний крок уточнення температури має вигляд:

```
T_{k+1} = T_k - f(T_k) / f'(T_k)
```

Як початкове наближення `T_0` застосовуємо лінійну оцінку:

```
T_0 = (R / R_0 - 1) / A
```

#### Доведення квадратичної швидкості збіжності

Розкладемо функцію `f(T)` у ряд Тейлора навколо істинного кореня `T_*`:

```
f(T_k) = f(T_*) + f'(T_*)·(T_k - T_*) + 0.5·f''(T_*)·(T_k - T_*)² + O((T_k - T_*)³)
```

Оскільки `f(T_*) = 0`, підставимо цей розклад у формулу Ньютона–Рафсона. Позначивши помилку на кроці `k` як `e_k = T_k - T_*`, отримуємо:

```
e_{k+1} = e_k - (f'(T_*)·e_k + 0.5·f''(T_*)·e_k²) / (f'(T_*) + f''(T_*)·e_k)
e_{k+1} ≈ (0.5 · f''(T_*) / f'(T_*)) · e_k²
```

Оцінимо константу асимптотичної збіжності `M = 0.5 · |f''(T_*)| / |f'(T_*)|` для діапазону від −200 °C до 0 °C:
- `|f'(T)| ≈ 0.4 Ω/°C`;
- `|f''(T)| ≈ R_0 · |2·B - 600·C·T| ≈ 100 · (1.15×10⁻⁶ + 2.5×10⁻⁹) ≈ 1.15×10⁻⁴ Ω/°C²`;
- `M ≈ 0.5 · (1.15×10⁻⁴ / 0.4) ≈ 1.44 × 10⁻⁴ °C⁻¹`.

Це означає, що якщо початкова помилка лінійного наближення `e_0` становить близько `1.5 °C`, то:
- На кроці 1: `|e_1| ≈ 1.44×10⁻⁴ · (1.5)² ≈ 3.2 × 10⁻⁴ °C` (три десятитисячні градуса);
- На кроці 2: `|e_2| ≈ 1.44×10⁻⁴ · (3.2×10⁻⁴)² ≈ 1.5 × 10⁻¹¹ °C`.

Уже на другій ітерації математична похибка виходить за межі машинної точності одинарної точності `float32`, а на третій — за межі подвійної точності `float64`.

**Покрокова ітерація для кріогенного вимірювання.** Нехай для Pt100 виміряно `R = 60.26 Ω` (істинна температура `T = -100.00 °C`):

```
Крок 0 (початкова оцінка):
T_0 = (60.26 / 100 - 1) / (3.9083 × 10⁻³) = -101.681 °C

Крок 1:
f(T_0) = 100 · (1 + A·T_0 + B·T_0² - 100·C·T_0³ + C·T_0⁴) - 60.26 = -0.6782 Ω
f'(T_0) = 100 · (A + 2·B·T_0 - 300·C·T_0² + 4·C·T_0³) = 0.4032 Ω/°C
T_1 = -101.681 - (-0.6782 / 0.4032) = -100.0008 °C

Крок 2:
f(T_1) = -0.00032 Ω
T_2 = -100.0008 - (-0.00032 / 0.4033) = -100.0000 °C  [збіжність досягнута]
```

### Швидке поліноміальне наближення 5-го порядку

На мікроконтролерах без апаратного блоку FPU або в системах жорсткого реального часу ітераційний розрахунок можна замінити прямим поліномом 5-го порядку відхилення опору від базового значення `ΔR = R - R_0`:

```
T(R) ≈ ∑ [k=1..5] D_k · (R - R_0)^k
```

де вагові коефіцієнти `D_k` оптимізовано методом найменших квадратів для діапазону від `-200 °C` до `0 °C`:

```
D_1 = +2.55826 × 10⁻¹ °C/Ω
D_2 = +9.64119 × 10⁻⁴ °C/Ω²
D_3 = +7.31495 × 10⁻⁶ °C/Ω³
D_4 = +6.82863 × 10⁻⁸ °C/Ω⁴
D_5 = +7.79759 × 10⁻¹⁰ °C/Ω⁵
```

Похибка апроксимації цим поліномом становить менше `±0.005 °C` у всьому від'ємному діапазоні, що значно нижче за інструментальну похибку будь-якого промислового сенсора.

### Апарат поширення похибок: перехід від шумів АЦП до невизначеності температури

У вимірювальному тракті будь-яка похибка вимірювання опору `u(R)` (зумовлена шумом квантування АЦП, дрейфом опорного резистора `R_REF` чи шумом струму збудження) перетворюється на невизначеність температури `u(T)` згідно з формулою перенесення похибок:

```
u(T) = u(R) / |dR/dT|
```

Оскільки чутливість `dR/dT` для Pt100 становить близько `0.385 Ω/°C`, маємо просте інженерне правило перерахунку:

```
u(T) ≈ u(R) · 2.60 °C/Ω
```

**Оцінка вимог до аналогового тракту:**
1. Щоб виміряти температуру з точністю `0.01 °C`, похибка визначення опору Pt100 не повинна перевищувати:
```
u(R) ≤ 0.01 °C / 2.60 °C/Ω ≈ 3.85 мОм (0.00385 Ω)
```
2. При струмі збудження `I_EXC = 1.0 мА` ця похибка опору відповідає напрузі шуму АЦП:
```
u(V) = I_EXC · u(R) = 1.0 мА · 3.85 мОм = 3.85 мкВ
```
3. При струмі збудження `I_EXC = 100 мкА` (для Pt1000) вимоги до напруги шуму залишаються такими самими (`u(V) = 0.1 мА · 38.5 мОм = 3.85 мкВ`), оскільки вищий номінал сенсора компенсує менший струм.

### Класи точності та межі похибок за IEC 60751

Стандарт регламентує чотири класи допуску на відхилення виміряної температури `|ΔT|` від істинної:

```
Клас AA (1/3 DIN): |ΔT| ≤ ±(0.10 + 0.0017·|T|) °C    [діапазон: 0 °C .. +150 °C]
Клас A:           |ΔT| ≤ ±(0.15 + 0.0020·|T|) °C    [діапазон: −30 °C .. +300 °C]
Клас B:           |ΔT| ≤ ±(0.30 + 0.0050·|T|) °C    [діапазон: −200 °C .. +600 °C]
Клас C:           |ΔT| ≤ ±(0.60 + 0.0100·|T|) °C    [діапазон: −200 °C .. +600 °C]
```

**Таблиця граничних допусків для сенсора Pt100:**

| Температура T, °C | Опір Pt100, Ω | Допуск Class AA, °C (Ω) | Допуск Class A, °C (Ω) | Допуск Class B, °C (Ω) |
|---|---|---|---|---|
| −200 | 18.52 | — | — | ±1.30 °C (±0.56 Ω) |
| −100 | 60.26 | — | ±0.35 °C (±0.14 Ω) | ±0.80 °C (±0.32 Ω) |
| 0 | 100.00 | ±0.10 °C (±0.04 Ω) | ±0.15 °C (±0.06 Ω) | ±0.30 °C (±0.12 Ω) |
| +100 | 138.51 | ±0.27 °C (±0.10 Ω) | ±0.35 °C (±0.13 Ω) | ±0.80 °C (±0.30 Ω) |
| +300 | 212.05 | — | ±0.75 °C (±0.26 Ω) | ±1.80 °C (±0.64 Ω) |
| +600 | 313.71 | — | — | ±3.30 °C (±1.02 Ω) |

Знання цих меж дозволяє інженеру оцінити, чи виправдане застосування складних чисельних алгоритмів лінеаризації з огляду на клас допуску самого сенсора.
