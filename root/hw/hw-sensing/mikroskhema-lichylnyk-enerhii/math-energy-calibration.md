# 🧮 Математичний апарат метрології та калібрування лічильників енергії

Метрологічна мікросхема перетворює безперервні аналогові сигнали напруги й струму на дискретні числа, з яких апаратний DSP-рушій у реальному часі обчислює діючі значення, потужність та накопичену енергію. Щоб покази приладу відповідали вимогам міжнародних стандартів точності (наприклад, IEC 62053-21 класи 0.5S, 1.0), цифровий тракт мікросхеми компенсує апаратні похибки датчиків, дільників напруги, шунти та фазові затримки. Нижче наведено виведення ключових метрологічних рівнянь та математику калібрування.

## 1. Дискретне обчислення діючих значень (True RMS)

Дійсне середньоквадратичне значення періодичного сигналу напруги v(t) з періодом T за визначенням дорівнює кореню з середнього значення квадрата миттєвої функції:

```text
V_rms = √( (1 / T) · ∫[0..T] v²(t) dt )    [визначення середньоквадратичного значення]
```

У цифровому ядрі вимірювача безперервний інтеграл замінюється дискретною сумою N миттєвих вибірок, отриманих із виходу сигма-дельта АЦП із частотою дискретизації f_s = 1 / Δt:

```text
V_rms = √( (1 / N) · Σ[k=0..N-1] v_k² )    [дискретна форма True RMS для N вибірок]
```

Для цілого числа періодів мережевої частоти (наприклад, за час усереднення 1 секунда при частоті мережі 50 Гц число вибірок N = f_s · 1.0 с) сума квадратів точно відповідає тепловому еквіваленту напруги незалежно від форми хвилі та гармонійного складу.

Аналогічно обчислюється діюче значення струму:

```text
I_rms = √( (1 / N) · Σ[k=0..N-1] i_k² )    [дискретне True RMS струму]
```

### Вплив власного шуму тракту та корекція RMS-зміщення

Кожен реальний аналоговий тракт має внутрішній широкосмуговий шум n(t) з нульовим математичним сподіванням E[n(t)] = 0 та дисперсією σ_n² = E[n²(t)]. На вході АЦП спостерігається суміш корисного сигналу i(t) та шуму n(t):

```text
i_meas(t) = i(t) + n(t)                    [сигнал із шумом на вході АЦП]
```

Під час зведення у квадрат і подальшого статистичного усереднення сума розпадається на три складові:

```text
E[i_meas²] = E[(i(t) + n(t))²]             [квадрат виміряного сигналу]
           = E[i²(t)] + 2·E[i(t)·n(t)] + E[n²(t)]  [розкриття квадрата двочлена]
           = I_rms² + 0 + σ_n²             [струм і шум некорельовані: E[i·n] = 0]
           = I_rms² + σ_n²                 [шум додає незмінну зміщену потужність]
```

Коли корисний струм великий (I_rms >> σ_n), внесок шуму σ_n² мізерний і губиться в молодших розрядах. Проте в режимі холостого ходу або малого навантаження (наприклад, струм споживання пристрою в режимі очікування 10 мА при діапазоні лічильника до 100 А), дисперсія шуму σ_n² стає порівнянною з I_rms²:

```text
I_raw = √( I_rms² + σ_n² )                 [сирий показ лічильника завищує струм]
```

Наприклад, якщо власний шум тракту становить σ_n = 5 мА, а реальний струм дорівнює I_rms = 10 мА, виміряне значення без корекції складе:

```text
I_raw = √( 10² + 5² )                      [підстановка значень у мА]
      = √( 100 + 25 )                      [сума квадратів]
      = √125 ≈ 11.18 мА                    [похибка становить +11.8%]
```

Щоб усунути цю похибку на малих струмах, метрологічні мікросхеми (зокрема ADE7953 у регістрі `AIRMSOS` / `BIRMSOS`) віднімають сталу величину зміщення безпосередньо з суми квадратів **перед** взяттям квадратного кореня:

```text
I_rms_corr = √( (1/N)·Σ i_k² - IRMSOS )    [апаратне виправлення шуму перед коренем]
```

Значення калібрувального регістра `IRMSOS` розраховується за результатами вимірювання на двох точках струму — номінального I_nom та малого I_min (або при розімкненому колі I = 0):

```text
IRMSOS = ( I_raw_min² · I_nom² - I_raw_nom² · I_min² ) / ( I_nom² - I_min² )  [формула розрахунку RMS Offset]
```

## 2. Потужності та енергії: активна, реактивна, повна

### Активна потужність (P)

Миттєва потужність p(t) є добутком миттєвої напруги v(t) та миттєвого струму i(t). Активна потужність P — це постійна складова миттєвої потужності:

```text
P = (1 / T) · ∫[0..T] v(t) · i(t) dt       [інтеграл активної потужності]
```

У дискретному DSP-тракті миттєві вибірки перемножуються апаратним помножувачем на частоті дискретизації, після чого потік добутків фільтрується цифровим фільтром низьких частот (ФНЧ) або усереднюється за фіксовану кількість періодів:

```text
P = (1 / N) · Σ[k=0..N-1] ( v_k · i_k )    [дискретне значення активної потужності]
```

### Реактивна потужність (Q)

Для синусоїдних сигналів реактивна потужність визначається зміщенням фази напруги або струму на 90° (π/2 рад). DSP-ядро формує ортогональний сигнал напруги v_90(t) за допомогою цифрового фільтра Гільберта або інтегратора:

```text
Q = (1 / N) · Σ[k=0..N-1] ( v_90_k · i_k ) [дискретна реактивна потужність]
```

### Повна потужність (S) та коефіцієнт потужності (PF)

Повна потужність обчислюється як прямий добуток уже знайдених True RMS значень:

```text
S = V_rms · I_rms                          [повна потужність у вольт-амперах, ВА]
```

Коефіцієнт потужності визначається безпосередньо відношенням активної потужності до повної:

```text
PF = P / S = P / ( V_rms · I_rms )         [коефіцієнт потужності, cos φ]
```

## 3. Фазове калібрування (PHCAL): чутливість на низькому cos φ

Аналогові компоненти перед АЦП неминуче вносять фазовий зсув:
- Трансформатори струму (CT) мають кутову похибку від 0.2° до 2.0° через струм намагнічування осердя.
- Вхідні антиаліасингові RC-фільтри (наприклад, R = 1 кОм, C = 33 нФ) мають фазовий зсув arctg(2π · 50 · R · C) ≈ 0.03°..0.15° із розкидом допусків резисторів і конденсаторів.

Позначимо сумарну паразитну фазову похибку між каналом струму та каналом напруги як θ_err. Нехай навантаження має справжній фазовий кут φ (де активна потужність P_true = V · I · cos φ).

Виміряна потужність із паразитною затримкою складе:

```text
P_meas = V · I · cos( φ + θ_err )          [потужність із фазовою похибкою]
```

Скористаємося тригонометричною формулою косинуса суми:

```text
P_meas = V · I · ( cos φ · cos θ_err - sin φ · sin θ_err )  [розклад косинуса суми]
```

Оскільки паразитна похибка мала (θ_err << 1 рад), застосуємо наближення малих кутів: cos θ_err ≈ 1, sin θ_err ≈ θ_err (у радіанах):

```text
P_meas ≈ V · I · ( cos φ - θ_err · sin φ ) [наближення для малого фазового зсуву]
```

Обчислимо відносну похибку вимірювання активної потужності ε_P:

```text
ε_P = ( P_meas - P_true ) / P_true         [визначення відносної похибки]
    = ( V·I·(cos φ - θ_err·sin φ) - V·I·cos φ ) / ( V·I·cos φ )  [підстановка]
    = - θ_err · ( sin φ / cos φ )          [скорочення однакових множників]
    = - θ_err · tan φ                      [фінальна залежність від тангенса кута]
```

### Порівняння впливу при різних коефіцієнтах потужності

Розглянемо зсув датчика струму θ_err = +0.5° = 0.5 · (π / 180) ≈ 0.008727 рад:

1. **Суто активне навантаження** (cos φ = 1.0, φ = 0°, tan 0° = 0):
   ```text
   ε_P = - 0.008727 · 0 = 0.0%             [фазова похибка не впливає на вимір]
   ```
   (З точним урахуванням косинуса: cos(0.5°) = 0.999962, похибка становить усього -0.0038%).

2. **Індуктивне навантаження** (cos φ = 0.5, φ = 60°, sin 60° = 0.866, tan 60° = √3 ≈ 1.732):
   ```text
   ε_P = - 0.008727 · 1.732                [підстановка тангенса 60 градусів]
       = - 0.01511 = -1.51%                [похибка зросла до 1.51%!]
   ```

Похибка виросла у сотні разів лише через зміну характеру навантаження. Саме тому калібрування фази за допомогою регістра `PHCAL` є обов'язковим для побудови лічильників комерційного обліку.

### Розрахунок значення регістра PHCAL

DSP-ядро ADE7953 використовує цифровий фільтр дробової затримки (fractional delay all-pass / FIR filter) для затримки або випередження вибірок напруги відносно струму. Крок фазового зсуву на частоті мережі f_line = 50 Гц становить:

```text
Δθ_lsb = 360° · f_line / f_dsp             [фазовий крок одного молодшого біта]
```

Для внутрішньої частоти роботи ядра f_dsp = 1.2288 МГц / 256 = 4.8 кГц:

```text
Δθ_lsb = 360° · 50 / 4800 = 0.0375°        [дискретність підстроювання фази]
```

Значення регістра `PHCAL` для компенсації виміряної кутової похибки θ_err розраховується як:

```text
PHCAL = - round( θ_err / Δθ_lsb )          [цілочисельний код у регістр PHCAL]
```

## 4. Калібрування коефіцієнтів підсилення (Gain Calibration)

Калібрування підсилення усуває мультиплікативні похибки номіналів компонентів:
- Допуск опору струмового шунта (типово ±1%..±5%).
- Допуск резисторів високовольтного дільника (±0.5%..±1%).
- Похибка внутрішнього джерела опорної напруги (V_ref до ±1%).

Калібрувальний регістр підсилення `IGAIN` (або `VGAIN`) модифікує вихідний числовий потік за формулою:

```text
Value_cal = Value_raw · ( 1 + GAIN_REG / 2²³ )  [двійковий додатковий код масштабу]
```

Якщо під час подачі еталонного струму I_ref сирий результат вимірювання становить I_meas, похибка підсилення дорівнює:

```text
Error_gain = ( I_meas - I_ref ) / I_ref    [відносна похибка коефіцієнта передачі]
```

Значення, яке необхідно записати в регістр `IGAIN` для компенсації:

```text
IGAIN = round( - Error_gain · 2²³ / ( 1 + Error_gain ) )  [код для 24-бітного регістра]
```

## 5. Розрахунок імпульсної константи CF (Calibration Frequency)

Імпульсний вихід CF видає калібровані імпульси певної тривалості (типово 80 мс), де кожен імпульс відповідає строго визначеному кванту спожитої енергії (наприклад, C_meter = 3200 імп / кВт·год).

Кількість імпульсів на одиницю енергії визначається співвідношенням накопиченого значення в акумуляторі та значення знаменника імпульсу в регістрі `CFxDEN`:

```text
f_CF = ( P_actual · f_accum · CF_NUM ) / ( P_max · CF_DEN · 2²³ )  [частота імпульсів на виході CF]
```

де:
- P_actual — поточна споживана потужність у ватах;
- f_accum — частота оновлення акумулятора енергії (типово 6.99 кГц або 8.0 кГц);
- P_max — номінальна потужність при повному заповненні шкал АЦП струму та напруги;
- CF_DEN — значення програмованого дільника в конфігураційному регістрі.

Розрахунок значення `CF_DEN` під задану константу лічильника C_meter (імп/кВт·год) виконується за виразом:

```text
CF_DEN = round( ( f_accum · 3600 · 1000 ) / ( C_meter · Wh_per_lsb · 2²³ ) )  [формула розрахунку CF_DEN]
```

де `Wh_per_lsb` — енергетична вага одного молодшого значущого біта накопичувача енергії.
