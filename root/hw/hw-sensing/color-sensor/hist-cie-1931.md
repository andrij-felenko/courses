# 📜 Досліди з колірного зрівнювання та створення системи CIE 1931

Людське око не вимірює безперервний фізичний спектр оптичного випромінювання точка за точкою: сітківка має лише три типи фоторецепторів-колбочок (L, M, S), які згортають нескінченновимірний спектральний розподіл потужності у три нервові сигнали. Проте на початку XX століття фізики, колористи та інженери зіткнулися з практичним глухим кутом: як кількісно стандартизувати колір барвників, текстилю та ламп розжарювання, якщо відчуття кольору суб'єктивне, а пряме спектральне сканування не пояснює, чому два абсолютно різні фізичні спектри виглядають для ока однаково (явище метамеризму, від грец. *meta* — після/зміна та *meros* — частина)?

Відповідь вимагала переходу від якісних описів до точного експериментального вимірювання функцій змішування кольорів. Цю фундаментальну роботу наприкінці 1920-х років незалежно виконали двоє британських дослідників: Вільям Девідсон Райт (William David Wright) в Імперському коледжі Лондона та Джон Гілд (John Guild) у Національній фізичній лабораторії (NPL) Великобританії.

## Експериментальна установка Райта і Гілда

Методика дослідів спиралася на принцип колориметричного візуального зрівнювання (англ. *color matching*). Спостерігач дивився в оптичну трубку на кругле поле, розділене навпіл по вертикалі. Розмір поля строго обмежували кутом зору 2° (що відповідає ділянці центральної ямки сітківки — *fovea centralis*, де зосереджені виключно колбочки й відсутні палички).

![Схема оптичної установки для експериментів із колірного зрівнювання Райта і Гілда](/root/hw/hw-sensing/color-sensor/img/cie-tristimulus-curves.svg)
*Спектральний базис зорового сприйняття. Досліди з колірного зрівнювання монохроматичних смуг дозволили зняти експериментальні криві відгуку, на основі яких Міжнародна комісія з освітлення побудувала стандартні функції узгодження x̄(λ), ȳ(λ), z̄(λ).*

На одну половину поля проєктували монохроматичне тестове світло з регульованою довжиною хвилі `λ` (від 380 до 700 нм) фіксованої радіометричної потужності. На другу половину поля одночасно спрямовували суміш трьох фізичних монохроматичних джерел — первинних колірних стимулів:
- Червоний стимул `R`: монохроматична лінія `λ_R = 700.0 нм`;
- Зелений стимул `G`: лінія випромінювання ртутної дуги `λ_G = 546.1 нм`;
- Синій стимул `B`: лінія випромінювання ртутної дуги `λ_B = 435.8 нм`.

Спостерігач вручну обертав поляризаційні призми або калібровані оптичні клини, змінюючи інтенсивності трьох первинних променів `(R, G, B)`, доки обидві половини поля не ставали візуально нерозрізними за відтінком та яскравістю.

## Проблема від'ємних коефіцієнтів

Під час зрівнювання більшості монохроматичних кольорів спектра з'ясувалася фундаментальна оптична перешкода. Для синьо-зелених (ціанових) відтінків у діапазоні від 480 до 510 нм жодна додатна комбінація первинних джерел `R, G, B` не могла зрівнятися за насиченістю з чистим спектральним кольором: суміш завжди виглядала надто тьмяною та розбавленою.

Щоб досягти рівності, експериментаторам довелося підмішувати невелику кількість червоного первинного світла `R` не до комбінації, а безпосередньо до тестового монохроматичного променя:

```
Тестовий_промінь(λ) + R · [Червоний_стимул] = G · [Зелений_стимул] + B · [Синій_стимул]
```

Перенесення червоного доданка в праву частину рівняння математично означало від'ємний коефіцієнт:

```
Тестовий_промінь(λ) = -R · [Червоний_стимул] + G · [Зелений_стимул] + B · [Синій_стимул]
```

У результаті емпірична функція червоного змішування `r̄(λ)` у системі RGB набувала від'ємних значень у всій ділянці 450–545 нм. Для аналогових розрахунків та конструювання перших фотоелектричних колориметрів на лампах і селенових фотоелементах наявність від'ємних коефіцієнтів створювала величезні технічні труднощі: прилад не міг інтегрувати оптичний струм із від'ємним коефіцієнтом без складних оптико-механічних компенсаторів.

## Стандартизація CIE 1931 та перехід до простору XYZ

У 1931 році в Кембриджі відбулася VIII сесія Міжнародної комісії з освітлення (фр. *Commission Internationale de l'Éclairage*, CIE). Комісія об'єднала масиви експериментальних даних Райта (10 спостерігачів) та Гілда (7 спостерігачів), сформувавши усереднені криві «стандартного 2-градусного колориметричного спостерігача CIE 1931» (англ. *CIE 1931 2° Standard Observer*).

Щоб позбутися від'ємних значень та спростити інженерні розрахунки світлового потоку, математики комісії запропонували лінійне афінне перетворення з фізичного базису `(R, G, B)` у новий гіпотетичний базис уявних стимулів `(X, Y, Z)`:

```
[X]   [ 2.7689  1.7517  1.1302 ]   [R]
[Y] = [ 1.0000  4.5907  0.0601 ] · [G]
[Z]   [ 0.0000  0.0565  5.5943 ]   [B]
```

Базис `(X, Y, Z)` не відповідає жодному реальному фізичному джерелу світла (це так звані уявні або нереалізуємі кольори з чистотою, вищою за 100%), але він забезпечив три фундаментальні інженерні властивості:

1. **Сувора невід'ємність:** усі три функції узгодження `x̄(λ) ≥ 0`, `ȳ(λ) ≥ 0`, `z̄(λ) ≥ 0` для будь-якої довжини хвилі видимого діапазону. Будь-який реальний фізичний колір у просторі XYZ описується виключно додатними координатами тристимулусу `X, Y, Z > 0`.
2. **Прямий зв'язок із фотометрією:** координата `Y` була навмисно сконструйована так, щоб її функція колірного узгодження `ȳ(λ)` точно збігалася зі стандартною функцією світлової ефективності денного людського зору `V(λ)`, прийнятою CIE ще у 1924 році. Завдяки цьому координата `Y` безпосередньо вимірює фотометричну яскравість (кд/м²) або освітленість (люкс), повністю відокремлюючи інтенсивність світла від його хроматичності.
3. **Рівноенергетична біла точка:** для теоретичного джерела з рівномірним спектральним розподілом енергії (Illuminant E, де `S(λ) = const`) координати тристимулусу однакові: `X = Y = Z`, що дає точку колірності `x = 1/3, y = 1/3`.

Стандарт CIE 1931 став першим строго математичним містком між неперервною електромагнітною фізикою випромінювання та тривимірним простором людського зору, на якому базуються всі сучасні цифрові сенсори кольору, стандарти передачі відео та дисплейні матриці.
