# 🧮 Виведення та геометрія наближення колірної температури МакКамі

Спектр теплового випромінювання нагрітого тіла однозначно описується законом Планка: що вища абсолютна температура тіла `T` (у кельвінах), то більше зміщується пік випромінювання у короткохвильову (синю) область і то «холоднішим» візуально стає біле світло. Неперервна крива колірності абсолютно чорного тіла утворює на діаграмі CIE 1931 так званий планковський локус (англ. *Planckian locus*).

Більшість сучасних джерел освітлення (люмінесцентні лампи, світлодіоди білого світіння з люмінофором) є нетепловими випромінювачами: їхній спектральний розподіл потужності містить вузькі піки й не збігається з кривою Планка. Для таких джерел використовують поняття **корельованої колірної температури** (англ. *Correlated Color Temperature*, CCT) — температури абсолютно чорного тіла, чия колірність сприймається людським оком найбільш схожою на колірність досліджуваного випромінювання.

*Геометрія корельованої колірної температури на площині (x, y). Локус абсолютно чорного тіла перетинається сімейством ізотемпературних ліній, які мають спільну точку сходу — епіцентр МакКамі.*

## Визначення CCT у рівноконтрастному просторі CIE 1960 UCS

Міжнародна комісія з освітлення (CIE) у 1960 році встановила суворе математичне правило: корельована колірна температура джерела світла з координатами `(x, y)` визначається як температура планковського випромінювача `T_c`, точка якого `(u_P, v_P)` на рівноконтрастній діаграмі колірності CIE 1960 UCS розташована на **мінімальній евклідовій відстані** від точки джерела `(u, v)`.

Перехід між координатами простору CIE 1931 `(x, y)` та простору CIE 1960 UCS `(u, v)` задається дробово-лінійним перетворенням:

```
u = (4 · x) / (-2 · x + 12 · y + 3)
v = (6 · y) / (-2 · x + 12 · y + 3)
```

Геометрично на площині `(u, v)` лінія найкоротшої відстані є нормальною (перпендикулярною) до кривої планковського локусу. Сімейство таких перпендикулярів називають **ізотемпературними лініями** (англ. *isotemperature lines*). Усі точки, що лежать на одній ізотемпературній лінії, мають однакову корельовану колірну температуру.

### Чисельна складність точного методу

Прямий пошук CCT за визначенням CIE вимагає мінімізації відстані:

```
Δuv = √[ (u - u_P(T))² + (v - v_P(T))² ] → min
```

де координати `u_P(T), v_P(T)` описуються нелінійними інтегралами від планковської функції густини випромінювання:

```
I(λ, T) = (2 · π · h · c²) / (λ⁵ · [exp(h · c / (λ · k_B · T)) - 1])
```

Чисельне інтегрування або ітераційний пошук методом Ньютона чи бісекції потребує сотень операцій із рухомою комою подвійної точності та займає неприпустимо багато мікроконтролерних тактів у вбудованих системах реального часу.

## Геометрична гіпотеза та епіцентр МакКамі

У 1992 році американський вчений К. С. МакКамі (C. S. McCamy) з компанії Macbeth опублікував аналітичне дослідження геометрії ізотемпературних ліній Джадда-Келлі на діаграмі колірності CIE 1931 `(x, y)`.

Під час проєкції з простору `(u, v)` назад у площину `(x, y)` прямі лінії залишаються прямими лініями (завдяки проєктивній природі дробово-лінійного перетворення), але кути між ними спотворюються. МакКамі помітив виняткову топологічну особливість: усі ізотемпературні лінії Джадда для діапазону температур від 2000 K до 12500 K перетинаються практично в одній спільній точці — так званому **епіцентрі сходження** (англ. *chromaticity epicenter*):

```
x_e = 0.3320
y_e = 0.1858
```

Будь-яка пряма лінія, що проходить через довільну точку виміряного кольору `(x, y)` та фіксований епіцентр `(x_e, y_e)`, збігається з відповідною лінією постійної CCT. Її просторове положення повністю визначається кутовим коефіцієнтом нахилу або оберненим кутовим параметром `n`:

```
n = (x - x_e) / (y_e - y)
  = (x - 0.3320) / (0.1858 - y)      [підстановка координат епіцентру]
```

## Кубічна апроксимація полінома

Оскільки між параметром нахилу `n` та значенням колірної температури вздовж планковської дуги існує гладка монотонна залежність, МакКамі застосував метод найменших квадратів для апроксимації кривої кубічним поліномом від `n`:

```
CCT = a · n³ + b · n² + c · n + d
```

Розрахунок коефіцієнтів регресії за опорними ізотемпературними лініями Джадда дав стандартні константи:

```
a = 449.0
b = 3525.0
c = 6823.3
d = 5520.33
```

Повний підсумковий аналітичний вираз формули МакКамі має вигляд:

```
CCT(x, y) = 449.0 · n³ + 3525.0 · n² + 6823.3 · n + 5520.33
де n = (x - 0.3320) / (0.1858 - y)
```

## Покроковий приклад обчислення для стандартного ілюмінанта D65

Розглянемо практичний розрахунок корельованої колірної температури для еталонного денного світла CIE Standard Illuminant D65, чиї теоретичні координати колірності становлять `x = 0.3127`, `y = 0.3290` (теоретична температура `T = 6504 K`).

**Крок 1. Розрахунок безрозмірного параметра нахилу `n`:**

```
n = (x - 0.3320) / (0.1858 - y)
  = (0.3127 - 0.3320) / (0.1858 - 0.3290)   [підстановка x=0.3127, y=0.3290]
  = (-0.0193) / (-0.1432)                   [віднімання]
  = 0.1347765                              [ділення: мінус на мінус дає плюс]
```

**Крок 2. Обчислення степенів параметра `n`:**

```
n¹ = 0.1347765
n² = (0.1347765)² = 0.0181647
n³ = (0.1347765)³ = 0.0024482
```

**Крок 3. Підстановка в поліном МакКамі:**

```
CCT = 449.0 · 0.0024482 + 3525.0 · 0.0181647 + 6823.3 · 0.1347765 + 5520.33
    = 1.0992 + 64.0306 + 919.6205 + 5520.3300                                  [множення доданків]
    = 6505.08 K                                                                 [фінальне додавання]
```

Відхилення від точного значення стандарту (`6504 K`) становить лише `+1.08 K` (відносна похибка менше 0.017%), що на порядок перевищує точність будь-якого кремнієвого колірного сенсора.

## Межі застосовності та оцінка похибок

Формула МакКамі є надзвичайно швидкою (потребує лише 4 множення та 4 додавання) і має такі метрологічні характеристики:

1. **Робочий температурний діапазон:** від 2000 K до 12500 K. Усередині цього інтервалу абсолютна похибка відносно точного визначення за стандартом CIE не перевищує 2–5 K поблизу чорнотільного локусу і досягає максимум 11 K на краях діапазону.
2. **Допустиме хроматичне відхилення:** формула строго дійсна, якщо точка колірності не віддаляється від локусу Планка далі ніж на `|Δuv| ≤ 0.05` одиниць простору CIE 1960. Для джерел із надмірним зеленим або пурпурним відтінком (сильний відхил від лінії чорного тіла) поняття CCT втрачає фізичний зміст, і будь-яка апроксимація дає зміщені оцінки.
3. **Високотемпературне розширення (Ернандес-Андрес):** якщо необхідно вимірювати температури вище 12500 K (наприклад, колір північного неба або блакитних зірок до 80000 K), застосовують розширену формулу Ернандеса-Андреса (Hernández-Andrés, 1999), яка використовує два різні епіцентри та поліноми 4-го ступеня окремо для низьких (1600–4000 K), середніх (4000–12500 K) та високих температур (12500–80000 K).
