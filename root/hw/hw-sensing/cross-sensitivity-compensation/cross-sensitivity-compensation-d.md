# Перехресна чутливість

<preknowlist>
- [Характеристики давача](root:hw-sensing/sensor-characteristics) — передавальна характеристика, чутливість, зсув нуля (offset), робочий діапазон.
- [Дрейф і гістерезис](root:hw-sensing/drift-hysteresis-noise) — часова нестабільність сигналу, вплив передісторії та фонові флуктуації.
- [Міст Вітстона](root:hw-sensing/wheatstone-bridge) — чотириплечовий резистивний міст для вимірювання малих відносних змін опору.
- [Тензорезистори](root:hw-sensing/strain-gauges) — перетворення механічної деформації матеріалу на зміну електричного опору.
</preknowlist>

Жоден первинний перетворювач у реальному світі не відчуває виключно цільову фізичну величину. Промисловий п'єзорезистивний давач тиску чи тензометричний ваговий давач, відкалібрований з точністю до 0.1% за температури 20 °C, від нагрівання літнім сонцем до 60 °C зміщує вихідний сигнал на 4–8% від повної шкали навіть за повної відсутності навантаження. Електрохімічний сенсор чадного газу в шахті видає хибний сплеск концентрації при різкій зміні вологості повітря під час запуску вентиляції. Давач струму на ефекті Холла в тяговому інверторі електромобіля помиляється на десятки амперів через магнітне поле розсіювання від сусідньої високовольтної шини.

Ця похибка виникає не через брак виготовлення чи випадковий шум: вона зумовлена фундаментальними законами фізики твердого тіла, термодинаміки та електрохімії. Властивості матеріалів, із яких виготовлено чутливий елемент — питомий електричний опір, модуль пружності, магнітна проникність, ширина забороненої зони та швидкість хімічних реакцій, — нерозривно залежать від температури, вологості, тиску й сторонніх електромагнітних полів.

**Перехресна чутливість** (англ. *cross-sensitivity*, від лат. *transversalis sensibilitas*) — це паразитна реакція первинного перетворювача на фізичні чи хімічні фактори середовища, які відрізняються від вимірюваної величини. Інженерна задача полягає в тому, щоб виявити фізичний механізм цього зв'язку, придушити його апаратними симетріями або виміряти допоміжними каналами й усунути цифровою математичною компенсацією.

### Фізична природа перехресної чутливості: зсув нуля та дрейф чутливості

Будь-який паразитно діючий фактор спотворює [передавальну характеристику давача](root:hw-sensing/sensor-characteristics) у два принципово різні способи.

![Вплив нецільових факторів на передавальну характеристику](/root/hw/hw-sensing/cross-sensitivity-compensation/img/cross-sensitivity-overview.svg)
*Вплив нецільових факторів на передавальну характеристику перетворювача. Паразитні збурення (температура, вологість, сторонні поля) викликають зсув нульової точки TCO (паралельний зсув кривої) та зміну нахилу характеристики TCS (дрейф чутливості).*

Перший механізм — **температурний зсув нуля** (англ. *Temperature Coefficient of Offset*, TCO). Він проявляється як адитивна похибка: вся передавальна крива зсувається паралельно вгору або вниз. Вихідний сигнал давача змінюється навіть тоді, коли цільова фізична величина дорівнює нулю (`X = 0`).

Другий механізм — **температурний дрейф чутливості** (англ. *Temperature Coefficient of Sensitivity / Span*, TCS). Це мультиплікативна похибка: змінюється крутість (нахил) передавальної характеристики. Приріст вихідного сигналу `ΔU` на одиницю вимірюваної величини `ΔX` стає функцією температури `S(T)`. При нульовому навантаженні ця похибка не помітна, але вона лінійно зростає зі збільшенням вимірюваної величини й досягає максимуму на краю робочої шкали.

#### Тензорезистори та п'єзорезистивні мембрани

У [тензорезистивних перетворювачах](root:hw-sensing/strain-gauges) та кремнієвих п'єзорезистивних сенсорах тиску одночасно діють чотири фізичні процеси:

1. **Термічний коефіцієнт електричного опору (TCR)** матеріалу провідника або напівпровідника. При нагріванні амплітуда коливань кристалічної ґратки зростає, збільшуючи розсіювання електронів провідності. Опір металевого тензорезистора зростає за законом:
   ```
   R(T) = R₀ · (1 + α_TCR · (T − T₀))
   ```
   Для константану `α_TCR ≈ 10...40 · 10⁻⁶ К⁻¹`, а для дифузійних кремнієвих резисторів p-типу `α_TCR ≈ 1500...3000 · 10⁻⁶ К⁻¹`.

2. **Різниця коефіцієнтів лінійного теплового розширення (CTE)** матеріалу тензорезистора `α_gauge` та матеріалу вимірюваної деталі чи підкладки `α_sub`. При зміні температури підкладка розширюється швидше або повільніше за наклеєний сенсор. Виникає чисто механічна «уявна» деформація розтягу/стиску:
   ```
   ε_th = (α_sub − α_gauge) · ΔT
   ```
   Ця деформація спричиняє паразитну зміну опору `ΔR_th = R₀ · GF · ε_th` (де `GF` — коефіцієнт тензочутливості, *gauge factor*), яку неможливо відрізнити від реального механічного зусилля за сигналом одного резистора.

3. **Температурна залежність модуля Юнга пружного тіла `E(T)`**. Пружний елемент сенсора (сталева балка чи кремнієва мембрана) під дією температури зазнає термопружного розм'якшення. Для більшості конструкційних сталей модуль пружності падає зі швидкістю приблизно `−2.5 ... −3.0 · 10⁻⁴ К⁻¹`. Під тим самим механічним тиском або силою гаряча мембрана прогинається сильніше, ніж холодна, що викликає прямий дрейф чутливості (TCS).

4. **Температурна залежність п'єзорезистивних коефіцієнтів кремнію**. У напівпровідникових MEMS-сенсорах зміна опору під напруженням викликана перерозподілом вільних носіїв заряду між енергетичними долинами зони провідності або розщепленням валентної зони. Зі зростанням температури тепловий рух носіїв розмиває це розщеплення, через що п'єзорезистивний коефіцієнт `π(T)` спадає обернено пропорційно абсолютній температурі (`π(T) ∝ T⁻¹ ... T⁻²`). Чутливість кремнієвого мосту тиску без компенсації падає на 15–25% при нагріванні від −40 °C до +85 °C.

#### Електрохімічні газові сенсори

В електрохімічних комірках для виявлення токсичних газів (CO, NO₂, H₂S, SO₂) аналізований газ дифундує крізь пористу тефлонову мембрану до робочого електрода, де вступає в окисно-відновну реакцію на поверхні каталізатора (платини, золота чи рутенію). 

Головним заважаючим фактором тут виступає **відносна вологість повітря (RH)** та її динамічні коливання:

- **Статичний вплив вологості**: рідкий сірчанокислотний (`H₂SO₄`) або лужний (`KOH`) електроліт через пори мембрани перебуває в термодинамічній рівновазі з вологою навколишнього повітря. При тривалій роботі в сухому середовищі (`RH < 15%`) вода з електроліту випаровується, концентрація кислоти зростає, падає іонна провідність і росте внутрішній опір комірки. При високій вологості (`RH > 90%`) комірка поглинає вологу з повітря, об'єм рідини зростає аж до ризику протікання корпусу та розведення каталітичного шару.
- **Динамічний перехідний процес (вологісний сплеск)**: різка зміна вологості повітря призводить до миттєвої адсорбції або десорбції молекул води на мікропористій поверхні робочого електрода. Це викликає перерозподіл зарядів подвійного електричного шару на межі метал-електроліт (модель комірки Рендлса з ємністю `C_dl`). Виникає потужний ємнісний перехідний струм, амплітуда якого може в десятки разів перевищувати корисний фарадівський струм від гранично допустимої концентрації газу. Такий сплеск затухає протягом кількох хвилин і часто стає причиною хибного спрацьовування сигналізаторів загазованості.
- **Перехресна хімічна селективність**: робочий електрод не здатний розрізнити молекули різних газів, якщо їхні стандартні електродні потенціали окиснення близькі. Так, стандартний сенсор чадного газу CO на платиновому каталізаторі має сильну перехресну чутливість до водню H₂ (відгук становить 20–50% від сигналу CO) та парів етилового спирту (до 10–15%).

#### Давачі струму на ефекті Холла та магнітометри

Безконтактні [давачі струму на ефекті Холла](root:ph-condensed/hall-effect) вимірюють магнітну індукцію `B_I`, створену струмом провідника. Однак кристал Холла реагує на сумарний вектор магнітної індукції в точці вимірювання:

```
B_total = B_I + B_ext
```

Зовнішнє стороннє поле розсіювання `B_ext` створюється зворотними струмовими шинами, обмотками розташованих поруч тягових електродвигунів, силовими трансформаторами або навіть геомагнітним полем Землі (`30...60 мкТл`). Якщо чутливий елемент розташований без магнітопроводу (в безсердечниковій схемі, *coreless sensing*), зовнішнє поле індукцією всього 1 мТл від шини, що проходить за 5 см від сенсора, створить паразитну похибку вимірювання струму величиною в десятки амперів.

### Апаратні методи придушення перехресного впливу: компенсація у фізичній площині

Найефективніший спосіб боротьби з перехресною чутливістю — знищити її безпосередньо в аналоговому тракті ще до того, як сигнал надійде до аналого-цифрового перетворювача.

#### Диференційний міст Вітстона з неробочим компенсаційним плечем

Класичний приклад апаратної компенсації температури — використання симетричної мостової схеми.

![Апаратна компенсація температури за допомогою неробочого плеча мосту](/root/hw/hw-sensing/cross-sensitivity-compensation/img/wheatstone-dummy-compensation.svg)
*Апаратна компенсація температури в мості Вітстона. Активний тензорезистор сприймає механічну деформацію ε_mech та нагрів, тоді як ненавантажений компенсаційний резистор (Dummy Gauge) відчуває лише нагрів. Диференційний міст віднімає синфазну температурну зміну опору.*

У півмостовій схемі використовують два ідентичні тензорезистори з однієї партії виготовлення:
1. **Активний тензорезистор** `R_act` наклеюють на навантажену ділянку деталі вздовж осі деформації. Його опір змінюється як від сили, так і від температури:
   ```
   R_act = R₀ + ΔR_ε + ΔR_T
   ```
2. **Компенсаційний тензорезистор** `R_dummy` (англ. *dummy gauge*, неробоче плече) наклеюють на такий самий ненавантажений шматок металу, розташований у безпосередньому тепловому контакті з активним елементом, або розміщують поперек осі деформації. Він не відчуває механічного напруження:
   ```
   R_dummy = R₀ + ΔR_T
   ```

Обидва резистори вмикають у суміжні плечі [мосту Вітстона](root:hw-sensing/wheatstone-bridge). Вихідна напруга мосту визначається різницею потенціалів середніх точок дільників:

```
ΔU = V_exc · ( R_act / (R_act + R_dummy) − 1/2 )
= V_exc · ( (R₀ + ΔR_ε + ΔR_T) / (2·R₀ + ΔR_ε + 2·ΔR_T) − 1/2 )      [підстановка виразів опорів]
= V_exc · ( ΔR_ε / (4·R₀ + 2·ΔR_ε + 4·ΔR_T) )                          [зведення до спільного знаменника]
≈ (V_exc / 4) · (ΔR_ε / R₀)                                            [лінеаризація за умови ΔR << R₀]
```

Паразитний температурний член `ΔR_T` входить у чисельник обох плечей із однаковим знаком і взаємно віднімається. Синфазний температурний зсув нуля (TCO) пригнічується в 50–200 разів залежно від точності узгодження теплових коефіцієнтів пари резисторів.

#### Пасивна термокомпенсація чутливості (Span Compensation)

Для компенсації температурного дрейфу чутливості (TCS), викликаного розм'якшенням пружного тіла, у коло живлення мосту послідовно вмикають спеціальний термочутливий резистор `R_span` із високим позитивним температурним коефіцієнтом опору (наприклад, із чистого нікелю або міді, де `α_TCR ≈ +6000 · 10⁻⁶ К⁻¹`).

При нагріванні опір `R_span` швидко зростає, зменшуючи напругу живлення безпосередньо на мості `V_bridge(T) < V_exc`. Падіння напруги живлення зменшує коефіцієнт перетворення мосту рівно настільки, наскільки зростає механічний прогин пружного тіла через спадання модуля Юнга `E(T)`. У результаті підсумковий розмах шкали сенсора залишається незмінним у широкому діапазоні температур.

#### Диференційні сенсори Холла та придушення магнітних полів розсіювання

Для захисту давачів струму на ефекті Холла від зовнішніх магнітних полів використовують принцип градієнтного вимірювання за допомогою здвоєних диференційних чутливих елементів (наприклад, у мікросхемах Melexis MLX91208 або Allegro ACS724).

![Диференційне придушення сторонніх магнітних полів у сенсорах Холла](/root/hw/hw-sensing/cross-sensitivity-compensation/img/differential-hall-cancellation.svg)
*Принцип градієнтного вимірювання струму парою елементів Холла. Струм у U-подібній шині збуджує протилежно спрямовані поля (+B_I та −B_I), тоді як зовнішня магнітна завада B_ext є однорідною. Диференційний підсилювач подвоює корисний сигнал і повністю усуває заваду.*

Два інтегровані елементи Холла A і B розташовують над паралельними гілками U-подібного струмопроводу на фіксованій відстані (зазвичай 2–4 мм):
- Струм `+I` у лівій гілці створює на елементі A локальне поле індукції `+B_I`;
- Зворотний струм `−I` у правій гілці створює на елементі B локальне поле протилежного напрямку `−B_I`.

Зовнішнє магнітне поле завади `B_ext`, джерело якого віддалене на відстань понад кілька сантиметрів, на масштабі кількох міліметрів кристала є практично абсолютно однорідним: воно діє на обидва елементи з однаковим знаком і амплітудою `+B_ext`.

Вихідні напруги двох елементів надходять на диференційний віднімач:

```
V_out = V_A − V_B                                  [різниця сигналів двох каналів]
= S · (+B_I + B_ext) − S · (−B_I + B_ext)          [підстановка значень локальних полів]
= S · (+B_I + B_ext + B_I − B_ext)                 [розкриття дужок і зведення подібних]
= 2 · S · B_I                                      [синфазне поле завади B_ext знищено]
```

Корисний сигнал подвоюється, а зовнішня магнітна завада `B_ext` повністю компенсується. Коефіцієнт придушення синфазної магнітної завади (англ. *Magnetic CMRR*) у сучасних інтегральних мікросхемах досягає 40–60 дБ (придушення у 100–1000 разів).

#### Електростатичне та магнітне екранування

Коли диференційної симетрії недостатньо, застосовують пасивні захисні екрани:

1. **Магнітні екрани з магніто-м'яких матеріалів (Mu-metal, пермалой, аморфні сплави)**. Висока початкова відносна магнітна проникність (`μ_r = 50 000 ... 100 000`) створює для зовнішніх силових ліній магнітного поля шлях із мізерним магнітним опором:
   ```
   R_m = l / (μ₀ · μ_r · S_cross)
   ```
   Магнітний потік замикається всередині стінок екрана, не проникаючи у внутрішній простір до чутливого кристала.

2. **Охоронні кільця (Guard Rings) на друкованих платах**. При вимірюванні надмалих струмів або роботі з високоімпедансними первинними перетворювачами (скляні pH-електроди, п'єзоелектричні давачі, іонізаційні камери) вологість повітря спричиняє паразитні струми витоку по поверхні текстоліту між сусідніми доріжками живлення та сигнальним входом. Навколо вимірювального вузла прокладають мідну доріжку-кільце, на яку за допомогою повторювача на операційному підсилювачі подають потенціал, що точно дорівнює напрузі на вимірювальному вході. Оскільки різниця потенціалів між сигнальним провідником і охоронним кільцем дорівнює нулю (`ΔV = 0`), струм витоку за законом Ома зникає.

### Інтеграція додаткових компенсаційних давачів: вимірювання вторинного середовища

Якщо паразитна фізична величина не може бути придушена апаратною симетрією (наприклад, складна нелінійна залежність чутливості від температури чи спільний вплив вологості й заважаючих газів), її необхідно безпосередньо виміряти окремим допоміжним каналом.

#### Розміщення термодавача: інтеграція на кристалі проти дискретних компонентів

Найпоширеніша помилка при проектуванні сенсорних вузлів — розміщення дискретного цифрового термометра або NTC-термістора на друкованій платі на відстані 1–2 см від первинного перетворювача.

![Теплове відставання та різниця динаміки on-die і зовнішнього термодавача](/root/hw/hw-sensing/cross-sensitivity-compensation/img/thermal-lag-compensation.svg)
*Динамічна помилка температурної компенсації через теплове відставання (Thermal Lag). При швидкому нагріванні зовнішній терморезистор на платі відстає за часом від чутливої мембрани, що призводить до хибного стрибка скоригованого вихідного сигналу.*

Друкована плата має значну теплоємність і тепловий опір. При швидкій зміні температури середовища (наприклад, увімкнення підігріву або порив холодного повітря) виникають дві критичні проблеми:
1. **Статичний просторовий градієнт температури `ΔT_grad`**: тепло від сусідніх стабілізаторів напруги чи мікроконтролера нагріває плату нерівномірно. Температура в точці вимірювання дискретним сенсором відрізняється від температури чутливої мембрани на 2–5 °C.
2. **Динамічне теплове відставання (Thermal Lag)**: постійна часу нагрівання крихітної кремнієвої MEMS-мембрани становить `τ_die ≈ 10...50 мс`, тоді як постійна часу корпусу дискретного датчика на платі — `τ_pcb ≈ 2...10 с`. Під час температурного перехідного процесу виникає динамічна різниця температур, через яку алгоритм цифрової компенсації застосовує некоректний коефіцієнт, породжуючи гігантський хибний сплеск вихідної величини.

Єдине надійне вирішення цієї проблеми — **інтеграція термодавача безпосередньо на кристал (On-die Temperature Sensor)** поруч із чутливим елементом. У сучасних інтегральних MEMS-давачах тиску (наприклад, Bosch BMP388 чи ST LPS22) та сенсорах Холла термочутливий елемент на p-n переходах або стабілізатор забороненої зони (англ. *bandgap temperature sensor*) виготовляють у тому самому кремнієвому кристалі на відстані кількох десятків мікрометрів від мембрани. Це забезпечує ідеальний тепловий контакт і зводить просторовий градієнт та динамічне запізнення майже до нуля.

Якщо ж доводиться працювати з масивними зовнішніми датчиками з відомою сталою часу теплопередачі `τ_th`, у прошивці мікроконтролера застосовують динамічну модель теплового стану першого порядку:

```
T_die_est(t) = T_meas(t) + τ_th · ( d T_meas(t) / dt )
```

Обчислення похідної швидкості зміни температури дозволяє спрогнозувати реальну температуру ядра датчика до того, як прогріється його зовнішній корпус.

#### Мультисенсорні матриці для газового аналізу

В аналізі якості повітря (наприклад, оцінка концентрації летких органічних сполук TVOC та CO₂) жоден напівпровідниковий оксидний сенсор (MOX) не працює автономно. Сучасні газові аналізатори поєднують:
- Матрицю з 2–4 MOX-сенсорів із різними каталітичними легуючими домішками;
- Оптичний NDIR-сенсор вуглекислого газу;
- Прецизійний цифровий сенсор відносної вологості й температури (наприклад, Sensirion SHTC3 або Bosch BME688).

Алгоритм сенсорного об'єднання (англ. *Sensor Fusion*) вирішує систему перехресних рівнянь, де виміряні значення вологості та температури використовуються для компенсації дрейфу базової лінії оксидних резисторів.

### Математичні моделі компенсації: поліноми та двовимірні матриці

Отримавши два цифрові потоки даних — сирий код первинного сенсора `U_raw` та код допоміжного сенсора температури чи вологості `T_meas`, мікроконтролер виконує перерахунок у скориговану фізичну величину `Y_true`.

Існують два фундаментальні підходи до математичної корекції: аналітична багатопараметрична поліноміальна регресія та двовимірні калібрувальні матриці пошуку (2D Lookup Tables).

#### Багатопараметричні поліноми (Polynomial Surface Fitting)

У поліноміальному підході реальна поверхня відгуку датчика описується степеневою функцією двох змінних. Для п'єзорезистивного сенсора тиску квадратична модель має вигляд:

```
P_calc = c₀₀ 
       + c₁₀ · U + c₀₁ · T 
       + c₁₁ · U · T 
       + c₂₀ · U² + c₀₂ · T² 
       + c₂₁ · U² · T + c₁₂ · U · T² 
       + c₂₂ · U² · T²
```

Калібрувальні коефіцієнти `c_ij` знаходять на етапі виробництва під час випробувань партії датчиків у кліматичній термобарокамері шляхом розв'язання перевизначеної системи нормальних рівнянь методом найменших квадратів. Докладне аналітичне виведення цієї матричної системи, оцінку її числа обумовленості та регуляризацію Тихонова наведено в окремій математичній вставці: [математичне виведення методу найменших квадратів та нормальних рівнянь](root:hw-sensing/cross-sensitivity-compensation/math-least-squares-compensation.md).

Обчислення полінома в мікроконтролері з апаратним блоком плаваючої коми (FPU) виконується за схемою Горнера, що мінімізує кількість операцій множення:

```
P_calc = c₀₀ + T·(c₀₁ + T·c₀₂) + U·(c₁₀ + T·(c₁₁ + T·c₁₂) + U·(c₂₀ + T·(c₂₁ + T·c₂₂)))
```

#### Двовимірні таблиці пошуку (2D Lookup Tables, LUT) з білінійною інтерполяцією

Коли передавальна поверхня перетворювача має складну форму з різкими перегинами (як у напівпровідникових газових сенсорів або NTC-термісторів), апроксимація єдиним глобальним поліномом вимагає підвищення степеня до 5–7 порядку. Це викликає паразитні коливання полінома на краях діапазону (явище Рунге) та вимагає важких обчислень.

У таких випадках використовують **двовимірну таблицю калібрувальних вузлів (2D LUT)** з білінійною інтерполяцією.

![Двовимірна калібрувальна матриця та білінійна інтерполяція](/root/hw/hw-sensing/cross-sensitivity-compensation/img/bilinear-interpolation-grid.svg)
*Двовимірна калібрувальна матриця та білінійна інтерполяція. За поточною парою (сирий код сенсора, температура) визначається комірка з чотирьох вузлів Q11..Q22. Значення обчислюється послідовною лінійною інтерполяцією вздовж осі X, а потім вздовж осі T.*

У пам'яті мікроконтролера зберігається двовимірний масив калібрувальних значень `Table[NUM_T][NUM_X]`, знятих у дискретних вузлах сітки `(X_i, T_j)`.

Алгоритм білінійної інтерполяції складається з трьох кроків:

1. **Локалізація комірки**: за поточними виміряними значеннями `X` та `T` знаходять індекси вузлів `i` та `j` таких, що:
   ```
   X_i ≤ X < X_{i+1}
   T_j ≤ T < T_{j+1}
   ```
2. **Обчислення нормалізованих локальних координат `u` та `v`** всередині знайденої комірки:
   ```
   u = (X − X_i) / (X_{i+1} − X_i)
   v = (T − T_j) / (T_{j+1} − T_j)
   де u, v ∈ [0.0, 1.0]
   ```
3. **Білінійне зважування чотирьох кутових значень `Q₁₁, Q₂₁, Q₁₂, Q₂₂`**:
   ```
   P_interp = (1 − u) · (1 − v) · Q₁₁ 
            + u · (1 − v) · Q₂₁ 
            + (1 − u) · v · Q₁₂ 
            + u · v · Q₂₂
   ```

Якщо сітку вузлів зробити рівномірною з кроком, що дорівнює степеню двійки (`ΔX = 2^N`, `ΔT = 2^M`), операції ділення замінюються швидкими побітовими зсувами (`>> N`), що дозволяє виконувати точну компенсацію навіть на найпростіших 8-бітових чи 16-бітових мікроконтролерах за кілька десятків тактів процесора.

### Практична реалізація: повний вбудований модуль цифрової термокомпенсації

Нижче наведено модуль цифрової компенсації сенсора для вбудованих систем реального часу.

Він підтримує швидку білінійну інтерполяцію за 2D LUT та поліноміальну модель другого порядку, містить захист від виходу сигналу за межі калібрувальної сітки (clamping), виконується за детермінований час O(1) і не використовує динамічного виділення пам'яті на купі.

#include <stdint.h>
#include <stdbool.h>

#define CALIB_LUT_X_SIZE  5
#define CALIB_LUT_T_SIZE  4

typedef enum {
    CALIB_OK = 0,
    CALIB_ERR_NULL_PTR = -1,
    CALIB_WARN_CLAMPED_LOW = 1,
    CALIB_WARN_CLAMPED_HIGH = 2
} calib_status_t;

/* Структура конфігурації двовимірної таблиці калібрування (2D LUT) */
typedef struct {
    float x_grid[CALIB_LUT_X_SIZE];                     /* Вузли сирого сигналу ADC */
    float t_grid[CALIB_LUT_T_SIZE];                     /* Вузли температури (°C)   */
    float lut_values[CALIB_LUT_T_SIZE][CALIB_LUT_X_SIZE]; /* Калібровані значення фізичної величини */
} calib_lut2d_config_t;

/* Структура коефіцієнтів полінома 2-го порядку P(U, T) */
typedef struct {
    float c00, c10, c01;
    float c11;
    float c20, c02;
    float c21, c12;
    float c22;
} calib_poly2d_config_t;

/* Білінійна інтерполяція за 2D LUT з безпечним обмеженням меж (clamping) */
calib_status_t sensor_compensate_lut2d(const calib_lut2d_config_t *cfg,
                                       float raw_x, float raw_t,
                                       float *out_val) {
    if (!cfg || !out_val) {
        return CALIB_ERR_NULL_PTR;
    }

    calib_status_t status = CALIB_OK;

    /* Обмеження сигналу X у межах сітки калібрування */
    float x = raw_x;
    if (x <= cfg->x_grid[0]) {
        x = cfg->x_grid[0];
        status = CALIB_WARN_CLAMPED_LOW;
    } else if (x >= cfg->x_grid[CALIB_LUT_X_SIZE - 1]) {
        x = cfg->x_grid[CALIB_LUT_X_SIZE - 1];
        status = CALIB_WARN_CLAMPED_HIGH;
    }

    /* Обмеження температури T у межах сітки */
    float t = raw_t;
    if (t <= cfg->t_grid[0]) {
        t = cfg->t_grid[0];
        status = CALIB_WARN_CLAMPED_LOW;
    } else if (t >= cfg->t_grid[CALIB_LUT_T_SIZE - 1]) {
        t = cfg->t_grid[CALIB_LUT_T_SIZE - 1];
        status = CALIB_WARN_CLAMPED_HIGH;
    }

    /* Пошук індексів комірки сітки для X */
    int i = 0;
    for (int k = 0; k < CALIB_LUT_X_SIZE - 2; ++k) {
        if (x >= cfg->x_grid[k + 1]) {
            i = k + 1;
        }
    }

    /* Пошук індексів комірки сітки для T */
    int j = 0;
    for (int k = 0; k < CALIB_LUT_T_SIZE - 2; ++k) {
        if (t >= cfg->t_grid[k + 1]) {
            j = k + 1;
        }
    }

    /* Локальні нормалізовані координати всередині комірки [0.0 ... 1.0] */
    const float dx = cfg->x_grid[i + 1] - cfg->x_grid[i];
    const float dt = cfg->t_grid[j + 1] - cfg->t_grid[j];
    const float u = (dx > 1e-7f) ? ((x - cfg->x_grid[i]) / dx) : 0.0f;
    const float v = (dt > 1e-7f) ? ((t - cfg->t_grid[j]) / dt) : 0.0f;

    /* Чотири кутові вузли */
    const float q11 = cfg->lut_values[j][i];
    const float q21 = cfg->lut_values[j][i + 1];
    const float q12 = cfg->lut_values[j + 1][i];
    const float q22 = cfg->lut_values[j + 1][i + 1];

    /* Білінійна інтерполяція */
    const float r1 = q11 + u * (q21 - q11);
    const float r2 = q12 + u * (q22 - q12);
    *out_val = r1 + v * (r2 - r1);

    return status;
}

/* Обчислення полінома 2-го порядку за схемою Горнера */
calib_status_t sensor_compensate_poly2d(const calib_poly2d_config_t *cfg,
                                        float raw_u, float raw_t,
                                        float *out_val) {
    if (!cfg || !out_val) {
        return CALIB_ERR_NULL_PTR;
    }

    const float u = raw_u;
    const float t = raw_t;

    const float term_const = cfg->c00 + t * (cfg->c01 + t * cfg->c02);
    const float term_u1    = cfg->c10 + t * (cfg->c11 + t * cfg->c12);
    const float term_u2    = cfg->c20 + t * (cfg->c21 + t * cfg->c22);

    *out_val = term_const + u * (term_u1 + u * term_u2);

    return CALIB_OK;
}

```cpp
#include <array>
#include <cstdint>
#include <optional>
#include <span>
#include <algorithm>

namespace sensing {

enum class CalibStatus {
    Ok,
    ClampedLow,
    ClampedHigh
};

struct CompensationResult {
    float value;
    CalibStatus status;
};

/* Шаблонний клас двовимірної таблиці калібрування на фіксованій сітці */
template <std::size_t NumX, std::size_t NumT>
class LookupTable2D {
public:
    static_assert(NumX >= 2 && NumT >= 2, "Сітка повинна містити щонайменше 2x2 вузли");

    constexpr LookupTable2D(std::array<float, NumX> x_nodes,
                            std::array<float, NumT> t_nodes,
                            std::array<std::array<float, NumX>, NumT> values)
        : x_grid_{x_nodes}, t_grid_{t_nodes}, table_{values} {}

    [[nodiscard]] CompensationResult evaluate(float raw_x, float raw_t) const noexcept {
        CalibStatus status = CalibStatus::Ok;

        /* Clamping вхідного сигналу X */
        float x = raw_x;
        if (x <= x_grid_.front()) {
            x = x_grid_.front();
            status = CalibStatus::ClampedLow;
        } else if (x >= x_grid_.back()) {
            x = x_grid_.back();
            status = CalibStatus::ClampedHigh;
        }

        /* Clamping температури T */
        float t = raw_t;
        if (t <= t_grid_.front()) {
            t = t_grid_.front();
            status = CalibStatus::ClampedLow;
        } else if (t >= t_grid_.back()) {
            t = t_grid_.back();
            status = CalibStatus::ClampedHigh;
        }

        /* Пошук комірки сітки бінарним розбиттям через std::upper_bound */
        auto it_x = std::upper_bound(x_grid_.begin(), x_grid_.end() - 1, x);
        const std::size_t i = (it_x == x_grid_.begin()) ? 0 : std::distance(x_grid_.begin(), it_x) - 1;

        auto it_t = std::upper_bound(t_grid_.begin(), t_grid_.end() - 1, t);
        const std::size_t j = (it_t == t_grid_.begin()) ? 0 : std::distance(t_grid_.begin(), it_t) - 1;

        /* Нормалізовані локальні змінні u та v */
        const float dx = x_grid_[i + 1] - x_grid_[i];
        const float dt = t_grid_[j + 1] - t_grid_[j];
        const float u = (dx > 1e-7f) ? ((x - x_grid_[i]) / dx) : 0.0f;
        const float v = (dt > 1e-7f) ? ((t - t_grid_[j]) / dt) : 0.0f;

        /* Кутові значення */
        const float q11 = table_[j][i];
        const float q21 = table_[j][i + 1];
        const float q12 = table_[j + 1][i];
        const float q22 = table_[j + 1][i + 1];

        /* Білінійна інтерполяція */
        const float r1 = q11 + u * (q21 - q11);
        const float r2 = q12 + u * (q22 - q12);
        const float result = r1 + v * (r2 - r1);

        return {result, status};
    }

private:
    std::array<float, NumX> x_grid_;
    std::array<float, NumT> t_grid_;
    std::array<std::array<float, NumX>, NumT> table_;
};

/* Клас поліноміальної моделі другого порядку P(U, T) */
class Polynomial2D {
public:
    struct Coefficients {
        float c00{0.0f}, c10{0.0f}, c01{0.0f};
        float c11{0.0f};
        float c20{0.0f}, c02{0.0f};
        float c21{0.0f}, c12{0.0f};
        float c22{0.0f};
    };

    constexpr explicit Polynomial2D(const Coefficients& coeffs) noexcept : c_{coeffs} {}

    [[nodiscard]] constexpr float evaluate(float u, float t) const noexcept {
        const float term_const = c_.c00 + t * (c_.c01 + t * c_.c02);
        const float term_u1    = c_.c10 + t * (c_.c11 + t * c_.c12);
        const float term_u2    = c_.c20 + t * (c_.c21 + t * c_.c22);
        return term_const + u * (term_u1 + u * term_u2);
    }

private:
    Coefficients c_;
};

} // namespace sensing
```

### Верифікація, залишковий дрейф та інженерна ціна калібрування

Після застосування апаратних та цифрових методів компенсації якість сенсорної системи оцінюють за двома ключовими числовими метриками.

1. **Залишкова похибка (Residual Error)**: максимальне відхилення скоригованого сигналу від еталонного значення на всьому діапазоні температур і робочих навантажень:
   ```
   ε_res = max |Y_compensated(X, T) − X_true| / FS · 100%
   ```
   Для високоякісних промислових сенсорів тиску залишкова похибка після двовимірної калібрації становить `0.02% ... 0.1%` повної шкали (FS).

2. **Коефіцієнт придушення перехресної завади (Interference Rejection Ratio, IRR)**: відношення початкового нескомпенсованого паразитного зсуву сигналу до залишкового дрейфу після корекції:
   ```
   IRR = 20 · log₁₀( ΔY_uncompensated / ΔY_compensated )   [дБ]
   ```
   Типове значення IRR для комбінованої (апаратної мостової + цифрової LUT) системи становить від 40 до 70 дБ.

> 🔧 **Навіщо це в реальній розробці:**
> У масовому виробництві вимірювальних приладів калібрування в термокамері є найдорожчим етапом виготовлення сенсора. Щоб датчик досяг теплової рівноваги на кожній температурній полиці (наприклад, −40 °C, 0 °C, +25 °C, +85 °C), потрібно витримувати плату в камері щонайменше 20–40 хвилин на точку. Це обмежує пропускну здатність конвеєра. Інженер завжди зважує компроміс: чи достатньо 3 температурних полиць і полінома 2-го порядку для класу точності 0.5%, чи виріб вимагає 7 полиць і сітки 2D LUT розміром `16 × 8` для досягнення метрологічного класу 0.05%.
