# 🧮 Багатовимірна калібрувальна матриця та метод найменших квадратів

Калібрування реального первинного перетворювача вимагає побудови математичної функції, яка за виміряним сирим кодом сенсора та додатковим сигналом температури обчислює точне фізичне значення вимірюваної величини. Ця математична вставка містить строге аналітичне виведення методу найменших квадратів (англ. *Ordinary Least Squares*, OLS) для двовимірної поліноміальної поверхні, формування нормальних рівнянь Гауса — Маркова, зважений метод найменших квадратів (WLS) при температурно-залежному шумі, аналіз сингулярного розкладу (SVD) для боротьби з мультиколінеарністю та теоретичну оцінку похибки білінійної інтерполяції.

### Постановка задачі: двовимірна калібрувальна поверхня

Нехай первинний перетворювач (давач тиску, сили чи струму) видає сирий вихідний сигнал `U` (напругу або безрозмірний код АЦП), який залежить як від цільової фізичної величини `P` (тиску, навантаження чи струму), так і від паразитного фактора — температури кристала `T`.

Пряма задача вимірювання полягає у знаходженні функції перетворення:

```
P = f(U, T)
```

Для апроксимації нелінійної поверхні `f(U, T)` використовують двовимірний степеневий поліном порядку `N` за сигналом `U` та порядку `M` за температурою `T`:

```
P_est(U, T) = ∑_{i=0}^N ∑_{j=0}^M c[i][j] · Uⁱ · Tʲ
```

У практичній вимірювальній техніці для більшості п'єзорезистивних, тензометричних та магнітних сенсорів достатньо повної моделі другого порядку (`N = 2`, `M = 2`), яка містить 9 коефіцієнтів калібрування:

```
P_est(U, T) = c₀₀
            + c₁₀ · U        + c₀₁ · T
            + c₁₁ · U · T
            + c₂₀ · U²       + c₀₂ · T²
            + c₂₁ · U² · T   + c₁₂ · U · T²
            + c₂₂ · U² · T²
```

Кожен доданок у цій сумі має конкретний фізичний зміст:
- `c₀₀` — базовий зсув нуля при нульовому сигналі й нульовій температурі;
- `c₁₀` — базова чутливість сенсора;
- `c₀₁`, `c₀₂` — лінійний і квадратичний температурний дрейф нульової точки (TCO);
- `c₁₁`, `c₁₂` — лінійний і квадратичний температурний дрейф чутливості (TCS);
- `c₂₀` — базова нелінійність характеристики перетворювача;
- `c₂₁`, `c₂₂` — температурна залежність нелінійності.

### Перевизначена система лінійних рівнянь

Щоб знайти 9 невідомих коефіцієнтів вектора `C = [c₀₀, c₁₀, c₀₁, c₁₁, c₂₀, c₀₂, c₂₁, c₁₂, c₂₂]ᵀ`, проводять калібрувальний експеримент. Давач поміщають у кліматичну камеру й задають `K` різних комбінацій відомого еталонного тиску `Pₖ` та стабілізованої температури `Tₖ` (де `k = 1, 2, ..., K`).

Кількість точок вимірювання `K` обирають значно більшою за кількість шуканих коефіцієнтів `m = 9` (зазвичай `K = 25 ... 100`, наприклад, 5 рівнів тиску на 5 температурних полицях). У результаті отримують перевизначену систему лінійних алгебраїчних рівнянь:

```
A · C = Y + E

A — матриця регресорів розмірності K × m
C — вектор невідомих коефіцієнтів розмірності m × 1
Y — вектор еталонних значень розмірності K × 1
E — вектор випадкових похибок вимірювань розмірності K × 1
```

Рядок `k` матриці `A` складається зі значень базисних функцій, обчислених для `k`-го експерименту:

```
A[k] = [ 1,  Uₖ,  Tₖ,  Uₖ·Tₖ,  Uₖ²,  Tₖ²,  Uₖ²·Tₖ,  Uₖ·Tₖ²,  Uₖ²·Tₖ² ]
```

### Виведення нормальних рівнянь методом найменших квадратів

Оскільки через випадкові шуми вимірювань точного розв'язку системи `A · C = Y` не існує, вектор коефіцієнтів `C` знаходять із критерію мінімізації суми квадратів залишкових похибок (евклідової норми вектора нев'язки):

```
S(C) = ||E||² = ||Y − A · C||²
```

Розкриємо скалярний добуток вектора нев'язки:

```
S(C) = (Y − A·C)ᵀ · (Y − A·C)
= Yᵀ·Y − Yᵀ·A·C − (A·C)ᵀ·Y + (A·C)ᵀ·A·C      [дистрибутивність множення та транспонування]
= Yᵀ·Y − 2 · Cᵀ · Aᵀ · Y + Cᵀ · (Aᵀ · A) · C   [оскільки Yᵀ·A·C — скаляр: (Yᵀ·A·C)ᵀ = Cᵀ·Aᵀ·Y]
```

Для знаходження мінімуму диференціюємо скалярну функцію `S(C)` за вектором параметрів `C` і прирівнюємо градієнт до нульового вектора:

```
∇_C S(C) = 0
−2 · Aᵀ · Y + 2 · (Aᵀ · A) · C = 0             [похідна лінійної та квадратичної векторних форм]
(Aᵀ · A) · C = Aᵀ · Y                          [нормальні рівняння Гауса — Маркова]
```

Матриця Грама `G = Aᵀ · A` має розмір `m × m` (у нашому випадку `9 × 9`). Якщо стовпці матриці `A` лінійно незалежні, матриця `G` є симетричною і додатно визначеною, тому існує єдина обернена матриця `(Aᵀ · A)⁻¹`.

Остаточний аналітичний розв'язок для вектора калібрувальних коефіцієнтів:

```
C = (Aᵀ · A)⁻¹ · Aᵀ · Y
```

Матриця `A⁺ = (Aᵀ · A)⁻¹ · Aᵀ` називається псевдооберненою матрицею Мура — Пенроуза для прямокутної матриці `A`.

### Зважений метод найменших квадратів (WLS) при гетероскедастичному шумі

У реальних сенсорах дисперсія шуму АЦП та теплових флуктуацій часто залежить від температури: на гарячій межі діапазону (+85 °C) тепловий шум Джонсона та струми витоку суттєво вищі, ніж при кімнатній температурі (+25 °C). Якщо похибки вимірювань `eₖ` мають різну дисперсію `Var(eₖ) = σₖ²`, звичайний метод OLS втрачає оптимальність.

Для врахування різної достовірності точок калібрування вводять діагональну вагову матрицю `W`:

```
W = diag( 1/σ₁², 1/σ₂², ..., 1/σ_K² )
```

Цільова функція зваженої нев'язки мінімізує зважену суму квадратів:

```
S_wls(C) = (Y − A·C)ᵀ · W · (Y − A·C)
= Yᵀ·W·Y − 2 · Cᵀ · Aᵀ · W · Y + Cᵀ · (Aᵀ · W · A) · C   [розкриття зваженого матричного добутку]
```

Прирівнюючи градієнт до нуля:

```
∇_C S_wls(C) = −2 · Aᵀ · W · Y + 2 · (Aᵀ · W · A) · C = 0   [диференціювання за вектором C]
(Aᵀ · W · A) · C = Aᵀ · W · Y                               [зважені нормальні рівняння]
C_wls = (Aᵀ · W · A)⁻¹ · Aᵀ · W · Y                         [остаточний WLS оцінювач]
```

За теоремою Гауса — Маркова оцінка `C_wls` є найкращою лінійною незміщеною оцінкою (англ. *Best Linear Unbiased Estimator*, BLUE), яка забезпечує мінімально можливу дисперсію знайдених калібрувальних коефіцієнтів.

### Обумовленість матриці, розклад SVD та регуляризація Тихонова

При роботі зі степеневими поліномами високого порядку величини `U²` та `U²·T²` можуть відрізнятися на багато порядків від одиничного стовпця. Це призводить до надзвичайно великого числа обумовленості матриці `G = Aᵀ · A`:

```
κ(G) = ||G|| · ||G⁻¹|| = λ_max(G) / λ_min(G)
```

Якщо `κ(G) > 10⁸`, матриця стає чисельно виродженою (погано обумовленою, англ. *ill-conditioned*).

Розглянемо сингулярний розклад (англ. *Singular Value Decomposition*, SVD) матриці регресорів:

```
A = U_svd · Σ · V_svdᵀ
```

де `Σ = diag(σ₁, σ₂, ..., σ_m)` — діагональна матриця сингулярних чисел, впорядкованих за спаданням (`σ₁ ≥ σ₂ ≥ ... ≥ σ_m > 0`).

Тоді коваріаційна матриця оцінок параметрів `C` має вигляд:

```
Cov(C) = σ_noise² · (Aᵀ · A)⁻¹
= σ_noise² · (V_svd · Σ⁻² · V_svdᵀ)                     [підстановка SVD-розкладу в обернену матрицю]
= σ_noise² · ∑_{i=1}^m ( v_i · v_iᵀ / σ_i² )            [сума зовнішніх добутків сингулярних векторів]
```

З останньої рівності видно фундаментальну небезпеку: якщо найменше сингулярне число `σ_m` наближається до нуля, множник `1 / σ_m²` вибухоподібно підсилює дисперсію похибок оцінки коефіцієнтів. Навіть мікроскопічний шум в АЦП спричиняє гігантські похибки в коефіцієнтах `c[i][j]`, а на краях калібрувального інтервалу виникають дикі паразитні коливання полінома (явище Рунге).

Для усунення цієї проблеми застосовують два обов'язкові інженерні кроки:

1. **Нормалізація вхідних даних**: перетворення сирих змінних `U` та `T` до безрозмірного діапазону `[-1, +1]`:
   ```
   u_norm = (2 · U − (U_max + U_min)) / (U_max − U_min)
   t_norm = (2 · T − (T_max + T_min)) / (T_max − T_min)
   ```
   Це масштабування вирівнює діагональні елементи матриці Грама й зменшує число обумовленості `κ(G)` на 4–6 порядків.

2. **Регуляризація Тихонова (гребенева регресія, Ridge Regression)**: додавання діагонального штрафу `λ · I` до матриці нормальних рівнянь:
   ```
   C_ridge = (Aᵀ · A + λ · I)⁻¹ · Aᵀ · Y
   ```
   де `I` — одинична матриця `9 × 9`, а `λ > 0` — малий коефіцієнт регуляризації (типово `10⁻⁶ ... 10⁻⁴`). У термінах SVD-розкладу сингулярні вагові множники модифікуються як `σ_i / (σ_i² + λ)`, що обмежує максимальне підсилення шуму величиною `1 / (2 · √λ)`.

### Числовий приклад розрахунку коефіцієнтів калібрування

Розглянемо калібрування мостового сенсора тиску за спрощеною моделлю першого порядку з перехресним членом (4 невідомі коефіцієнти):

```
P_est(U, T) = c₀₀ + c₁₀ · U + c₀₁ · T + c₁₁ · U · T
```

Експеримент у термокамері дав такі виміри (тиск `P` у кПа, сигнал `U` у вольтах, температура `T` у °C):

```
Точка 1: P = 0 кПа,   T = 0 °C,    U = 0.50 В
Точка 2: P = 100 кПа, T = 0 °C,    U = 2.45 В
Точка 3: P = 0 кПа,   T = 50 °C,   U = 0.55 В
Точка 4: P = 100 кПа, T = 50 °C,   U = 2.35 В
```

Матриця регресорів `A` та вектор еталонних значень `Y`:

```
A = [ 1,  0.50,   0,     0    ]        Y = [   0 ]
    [ 1,  2.45,   0,     0    ]            [ 100 ]
    [ 1,  0.55,  50,  27.5    ]            [   0 ]
    [ 1,  2.35,  50, 117.5    ]            [ 100 ]
```

Обчислення матриці Грама `G = Aᵀ · A` та вектора вільних членів `B = Aᵀ · Y`:

```
Aᵀ · A = [ 4.00,    5.85,   100.0,   145.0   ]
         [ 5.85,   12.08,   145.0,   291.25  ]
         [ 100.0,  145.0,  5000.0,  7250.0   ]
         [ 145.0,  291.25, 7250.0, 14562.5   ]

Aᵀ · Y = [ 200.0   ]
         [ 480.0   ]
         [ 5000.0  ]
         [ 11750.0 ]
```

Розв'язуючи систему `(Aᵀ · A) · C = Aᵀ · Y`, отримуємо вектор калібрувальних коефіцієнтів:

```
c₀₀ = −25.641 кПа
c₁₀ = +51.282 кПа/В
c₀₁ = −0.0983 кПа/°C
c₁₁ = +0.0855 кПа/(В·°C)
```

Підсумкова розрахункова формула давача тиску:

```
P = −25.641 + 51.282 · U − 0.0983 · T + 0.0855 · U · T
```

Коефіцієнт `c₁₁ = +0.0855` точно компенсує падіння чутливості кремнієвого мосту тиску при нагріванні.

### Похибка білінійної інтерполяції в таблицях 2D LUT

Коли багатопараметричний поліном замінюють двовимірною таблицею пошуку (2D Lookup Table, LUT), значення між вузлами сітки обчислюють за формулою білінійної інтерполяції.

Розглянемо прямокутну комірку сітки, обмежену вузлами `[X₁, X₂]` та `[T₁, T₂]`, з кроками `h_x = X₂ − X₁` та `h_t = T₂ − T₁`. Нехай `u = (X − X₁) / h_x` та `v = (T − T₁) / h_t` — нормалізовані локальні координати всередині комірки (`u, v ∈ [0, 1]`).

Білінійне наближення функції `f(X, T)` представляють як послідовність двох одновимірних лінійних інтерполяцій:

```
R₁(u) = Q₁₁ + u · (Q₂₁ − Q₁₁)                  [інтерполяція вздовж осі X при T = T₁]
R₂(u) = Q₁₂ + u · (Q₂₂ − Q₁₂)                  [інтерполяція вздовж осі X при T = T₂]
P_interp(u, v) = R₁(u) + v · (R₂(u) − R₁(u))   [інтерполяція вздовж осі T між R₁ та R₂]
= (1 − u)·(1 − v)·Q₁₁ + u·(1 − v)·Q₂₁ + (1 − u)·v·Q₁₂ + u·v·Q₂₂   [підстановка та розкриття дужок]
```

де `Q_ij = f(X_i, T_j)`.

Залишковий член інтерполяції `E(X, T) = f(X, T) − P_interp(u, v)` оцінюють через залишки формули Тейлора для функції двох змінних. Якщо функція `f(X, T)` двічі неперервно диференційовна на прямокутнику, максимальна абсолютна похибка інтерполяції обмежена виразом:

```
|E(X, T)| ≤ (1/8) · (h_x)² · M_xx + (1/8) · (h_t)² · M_tt
```

де `M_xx = max |∂²f / ∂X²|`, а `M_tt = max |∂²f / ∂T²|` — максимуми других частинних похідних на комірці.

**Інженерний висновок для вибору розміру таблиці:**
Похибка білінійної інтерполяції спадає як квадрат кроку сітки `O(h_x² + h_t²)`. Якщо подвоїти кількість вузлів уздовж кожної осі (зменшити `h_x` та `h_t` удвічі), похибка інтерполяції зменшиться в 4 рази.

Це дозволяє точно розрахувати необхідний розмір калібрувальної таблиці у флеш-пам'яті: для забезпечення інструментальної похибки не гірше 0.05% від повної шкали при максимальній кривині характеристики `M_xx` та `M_tt` достатньо рівномірної сітки розмірністю `16 × 8` або `32 × 16` вузлів.
