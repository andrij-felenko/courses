Якщо в шахтному забої, котельні або на хімічному заводі концентрація чадного газу (монооксиду вуглецю, CO) перевищить 50 ppm (часток на мільйон), працівник за пів години втратить орієнтацію, а за 400 ppm — знепритомніє через утворення в крові стійкого карбоксигемоглобіну. Портативний персональний газоаналізатор, закріплений на поясі, мусить безперервно виявляти навіть 5 ppm цього газу й працювати щонайменше два роки від однієї мініатюрної літієвої батарейки.

Оптичні інфрачервоні давачі (NDIR) для такого завдання надто енергоємні: їхня лампа розжарювання або інфрачервоний випромінювач споживають десятки міліватів, а сам метод не здатний детектувати гомоядерні двоатомні молекули на кшталт кисню `O₂`, у яких відсутній дипольний момент. Напівпровідникові металооксидні сенсори (MOX) вимагають постійного підігріву чутливого шару до 300–400 °C, споживаючи 15–50 мВт, і демонструють сильний нелінійний дрейф базової лінії.

Рішенням для автономного контролю токсичних газів і кисню стала **амперометрична електрохімічна комірка** (англ. *amperometric electrochemical cell*; від грец. *ēlektron* — бурштин, *chēmeia* — мистецтво перетворення речовин та франц. *ampère* — одиниця струму). Вона працює без нагрівачів за кімнатної температури, перетворюючи хімічну енергію окисно-відновної реакції безпосередньо в електричний струм наноамперного чи мікроамперного рівня, який строго лінійно залежить від концентрації газу.

![Внутрішня будова електрохімічної комірки](/root/hw/hw-sensing/electrochemical-cell/img/electrochemical-cell-structure.svg)
*Конструкція триелектродної електрохімічної комірки: аналізований газ проникає крізь капілярний дифузійний бар'єр та пористу мембрану до робочого електрода (WE), тоді як електрод порівняння (RE) та допоміжний електрод (CE) занурені в рідкий електроліт для підтримки електрохімічної рівноваги.*

### Електрохімічні реакції на робочому електроді

Серцем електрохімічного давача є **робочий електрод** (**WE**, *Working Electrode*). Це композитна структура: пориста гідрофобна мембрана з політетрафторетилену (PTFE / тефлону), на внутрішній бік якої накатано шар дисперсного металевого каталізатора — зазвичай платинової, золотної або рутенієвої чорні з питомою площею поверхні десятки квадратних метрів на грам.

На цьому електроді реалізується **трифазна межа розділу** (*triple-phase boundary*): газоподібний аналіт із повітря, твердий електронний провідник (металевий каталізатор) та рідкий іонний провідник (водний розчин кислоти або солі, найчастіше 4–5 М сірчана кислота `H₂SO₄`).

![Кінетика реакцій на трифазній межі](/root/hw/hw-sensing/electrochemical-cell/img/redox-reaction-mechanism.svg)
*Механізм окиснення CO на платиновому каталізаторі робочого електрода (ліворуч) та катодного відновлення O₂ (праворуч). На межі фаз молекули віддають або приймають електрони, породжуючи зовнішній вимірювальний струм.*

#### Окиснення монооксиду вуглецю (CO)

Коли молекула чадного газу досягає каталітичних центрів платини робочого електрода, вона вступає в реакцію гетерогенного окиснення за участю молекул води з електроліту:

```
CO + H₂O → CO₂ + 2H⁺ + 2e⁻      [стандартний потенціал E° = -0.11 В vs SHE]
```

Кожна молекула `CO` віддає 2 електрони в кристалічну ґратку платини. Іони гідронію `H⁺` (протони) переходять у рідкий електроліт і мігрують крізь пористий сепаратор до протилежного, допоміжного електрода.

На **допоміжному електроді** (**CE**, *Counter Electrode*) відбувається узгоджена реакція катодного відновлення кисню, розчиненого в електроліті з навколишнього повітря:

```
½O₂ + 2H⁺ + 2e⁻ → H₂O           [стандартний потенціал E° = +1.23 В vs SHE]
```

Сумарна хімічна реакція всередині комірки повністю збігається з реакцією прямого горіння чадного газу:

```
CO + ½O₂ → CO₂                  [сумарна ЕРС комірки E°_cell = +1.34 В]
```

Оскільки термодинамічний потенціал Гіббса цієї реакції від'ємний (`ΔG < 0`), процес є самочинним: комірка працює як мініатюрний паливний елемент, що сам генерує струм. Електрони залишають робочий електрод WE, проходять крізь зовнішнє вимірювальне коло і повертаються на допоміжний електрод CE. Струм робочого електрода має вихідний напрямок (анодний струм, `I_WE > 0`).

#### Відновлення кисню (O₂)

Вимірювання концентрації кисню має два різні технічні втілення: гальванічне та амперометричне.

У класичній **гальванічній комірці** (давачі парціального тиску кисню) катодом (WE) слугує золото чи платина, а анодом (CE) — розхідний металевий свинець (`Pb`).
На робочому електроді кисень відновлюється:

```
O₂ + 4H⁺ + 4e⁻ → 2H₂O      [у кислому електроліті]
O₂ + 2H₂O + 4e⁻ → 4OH⁻      [у лужному електроліті KOH]
```

На свинцевому аноді відбувається окиснення металу:

```
2Pb + 4OH⁻ → 2PbO + 2H₂O + 4e⁻
```

Сумарний процес: `2Pb + O₂ → 2PbO`. Такий сенсор не потребує зовнішнього живлення поляризації, але має обмежений фізичний ресурс (1–2 роки), оскільки свинцевий анод незворотно окислюється й витрачається пропорційно сумарній експозиції кисню.

У сучасних **безсвинцевих 3-електродних амперометричних сенсорах O₂** реакцію відновлення кисню на WE проводять під примусовим негативним потенціалом зміщення (зазвичай близько `−600 мВ` відносно електрода порівняння), а на допоміжному електроді CE здійснюється електроліз води з виділенням кисню назад в електроліт:

```
2H₂O → O₂ + 4H⁺ + 4e⁻
```

У цій системі жоден компонент не витрачається безповоротно, завдяки чому ресурс давача перевищує 5–7 років. Оскільки електрони входять у WE із зовнішнього кола, струм сенсора має катодний напрямок (`I_WE < 0`).

#### Відновлення токсичних окисників (NO₂, Cl₂)

Для діоксиду азоту `NO₂`, хлору `Cl₂` та озону `O₃` робочий процес також є відновним. Молекула `NO₂` на золотому каталізаторі приєднує електрони:

```
NO₂ + 2H⁺ + 2e⁻ → NO + H₂O
```

На допоміжному електроді CE вода окислюється до кисню. Струм комірки є від'ємним і пропорційним концентрації `NO₂`.

| Газ | Реакція на WE | Тип процесу | Кількість електронів `n` | Знак струму `I_WE` | Типова чутливість |
|---|---|---|---|---|---|
| `CO` | `CO + H₂O → CO₂ + 2H⁺ + 2e⁻` | Окиснення (анодне) | 2 | Додатний (`+`) | 50–100 нА/ppm |
| `H₂S` | `H₂S + 4H₂O → H₂SO₄ + 8H⁺ + 8e⁻` | Окиснення (анодне) | 8 | Додатний (`+`) | 300–700 нА/ppm |
| `SO₂` | `SO₂ + 2H₂O → H₂SO₄ + 2H⁺ + 2e⁻` | Окиснення (анодне) | 2 | Додатний (`+`) | 200–500 нА/ppm |
| `O₂` | `O₂ + 4H⁺ + 4e⁻ → 2H₂O` | Відновлення (катодне) | 4 | Від'ємний (`−`) | 10–50 мкА (на 20.9% O₂) |
| `NO₂` | `NO₂ + 2H⁺ + 2e⁻ → NO + H₂O` | Відновлення (катодне) | 2 | Від'ємний (`−`) | −200..−600 нА/ppm |

### Дифузійне обмеження: чому струм строго лінійний

Якби швидкість електрохімічного перетворення газу визначалася суто хімічною кінетикою на поверхні каталізатора (швидкістю розриву зв'язків та переносу заряду), густина струму описувалася б класичним **рівнянням Батлера–Фольмера**:

```
j = j_0 · (exp(α_a · n · F · η / (R · T)) - exp(-α_c · n · F · η / (R · T)))
```

де `j_0` — густина струму обміну, `η = V - E_eq` — перенапруга електрода, а `α_a, α_c` — коефіцієнти переносу заряду. За такого механізму струм сенсора експоненційно залежав би від температури та найменших коливань напруги, роблячи точні вимірювання неможливими.

Щоб подолати цю нестабільність, конструкцію комірки навмисно проектують так, щоб перевести її в **режим дифузійного обмеження** (*diffusion-limited / mass-transport regime*). Швидкість реакції на високоактивній дисперсній платиновій чорні роблять на кілька порядків вищою за швидкість надходження молекул газу крізь вхідний отвір.

Перед каталітичним шаром встановлюють лазерно просвердлений мікрокапіляр або пористу мембрану товщиною `δ` та площею перерізу `A`. Будь-яка молекула аналіту, що долає цей бар'єр, миттєво реагує на каталізаторі. Внаслідок цього концентрація газу безпосередньо на поверхні електрода падає практично до нуля:

```
C_surface ≈ 0
```

![Дифузійний профіль газу за законом Фіка](/root/hw/hw-sensing/electrochemical-cell/img/diffusion-profile-fick.svg)
*Концентрація газу лінійно спадає від атмосферного значення C_bulk на вході до нуля на каталізаторі WE. Градієнт концентрації визначає постійний дифузійний потік молів речовини, що за законом Фарадея конвертується у строго лінійний струм.*

Згідно з **першим законом дифузії Фіка**, густина дифузійного потоку речовини `J` (моль/(с·м²)) через шар товщиною `δ` становить:

```
J = -D · (dC / dx)
= D · (C_bulk - C_surface) / δ      [лінійний градієнт у капілярі]
= D · C_bulk / δ                    [оскільки C_surface = 0]
```

де `D` — коефіцієнт дифузії молекул газу в повітрі (м²/с), а `C_bulk` — об'ємна концентрація газу в навколишньому середовищі (моль/м³).

Згідно з **фундаментальним законом Фарадея**, електричний струм `I`, що протікає через електрод за мольного потоку `J · A`, дорівнює:

```
I = n · F · A · J
= (n · F · A · D / δ) · C_bulk      [підстановка виразу для J]
```

де:
* `n` — кількість електронів, що беруть участь у реакції однієї молекули (2 для `CO`, 4 для `O₂`);
* `F = 96485.3 Кл/моль` — стала Фарадея (заряд одного моля електронів);
* `A` — площа дифузійного отвору (м²);
* `D` — коефіцієнт дифузії аналізованого газу (м²/с);
* `δ` — ефективна довжина дифузійного каналу (м).

Усі величини в дужках `(n · F · A · D / δ)` визначаються геометрією виготовлення комірки та фундаментальними константами.

> 🔧 **Навіщо це.** Завдяки дифузійному обмеженню вихідний струм амперометричного сенсора є **строго лінійною функцією концентрації газу** в діапазоні від 0.1 ppm до 2000 ppm. Для його калібрування на виробництві достатньо двох точок: чистого повітря (0 ppm) та калібрувальної суміші відомої концентрації (наприклад, 100 ppm CO). Чутливість виражається просто як нахил прямої `S = I / [Газ]` (нА/ppm).

Температурна залежність сенсора зводиться головним чином до зміни коефіцієнта дифузії газу в повітрі, який зростає пропорційно абсолютній температурі у степені 1.75:

```
D(T) ∝ T^1.75
```

Це дає передбачуваний додатний температурний коефіцієнт чутливості близько `+0.2% .. +0.5% на °C`, який легко й точно компенсується програмним алгоритмом за показами термодавача.

### Чому двох електродів недостатньо: 3-електродна система

Найпростіша електрохімічна комірка містить два контакти: робочий електрод WE та протиелектрод CE. Проте двохелектродна схема надійно працює лише за двох умов: мізерних струмів і стабільного складу електроліту (як у деяких сенсорах кисню зі свинцевим анодом великої площі).

Коли двохелектродний сенсор вимірює високі концентрації або токсичні гази, через електроліт між WE та CE починає протікати струм `I`. Це породжує дві непереборні проблеми:

1. **Омічне падіння напруги на електроліті (`I · R_electrolyte`).** Рідкий або гелевий електроліт має власний об'ємний опір `R_electrolyte` (від сотень ом до десятків кілоом залежно від геометрії та вологості). При протіканні струму на ньому падає напруга `ΔV_ohm = I · R_electrolyte`, яка динамічно віднімається від робочого потенціалу електрода.
2. **Поляризація допоміжного електрода.** Коли на CE протікає реакція відновлення, біля його поверхні локально вичерпуються іони та накопичуються продукти реакції. Потенціал CE неконтрольовано зміщується на величину перенапруги `η_CE(I)`.

Внаслідок цього реальний робочий потенціал робочого електрода `V_WE` відносно розчину починає плавати разом зі зміною концентрації газу:

```
V_WE_фактичний = V_прикладений - I · R_electrolyte - η_CE(I)
```

Щойно потенціал робочого електрода зміщується за межі вузького електрохімічного вікна селективності, швидкість каталізу падає, лінійність руйнується, або починається електроліз самої води чи розчинника.

#### Рішення: три електроди

Для розділення функцій вимірювання та струмового балансування до комірки ввели третій електрод — **електрод порівняння** (**RE**, *Reference Electrode*):

* **Робочий електрод (WE):** перебуває на трифазній межі. Тут протікає цільова реакція та формується вимірюваний струм `I_WE`.
* **Електрод порівняння (RE):** неполяризовний електрод (наприклад, платиновий або паладієвий в контакті з повітрям, або `Ag/AgCl`), який має стабільний термодинамічний потенціал рівноваги. **З електрода RE не відбирається струм** (`I_RE ≈ 0 пА`). Завдяки нульовому струму на ньому відсутнє омічне падіння `I · R` та поляризація. Він служить непорушною точкою відліку потенціалу всередині розчину.
* **Допоміжний електрод (CE):** бере на себе весь струм замкненого кола (`I_CE = -I_WE`). Його потенціал може довільно змінюватися під дією зовнішнього підсилювача, що ніяк не впливає на стабільність робочого електрода.

Дізнатися про фізичні типорозміри корпусів, вимоги до захисних кілець на платі та ресурсні обмеження електроліту можна у вставці [конструкція та експлуатація електрохімічних газових сенсорів](root:hw-sensing/electrochemical-cell/comp-electrochemical-gas-sensor.md).

### Схемотехніка потенціостата

Електронна схема, яка забезпечує описаний 3-електродний режим, називається **потенціостатом** (англ. *potentiostat*; від лат. *potentia* — сила, напруга та грец. *statos* — нерухомий).

Схема складається з двох функціональних вузлів: **підсилювача керування** (*Control Amplifier*, CA) та **трансімпедансного підсилювача** (*Transimpedance Amplifier*, TIA).

![Принципова схемотехніка потенціостата](/root/hw/hw-sensing/electrochemical-cell/img/potentiostat-circuit-topology.svg)
*Схема триелектродного потенціостата: операційний підсилювач керування CA замкнений у петлю від'ємного зворотного зв'язку через RE та CE, підтримуючи точний потенціал V_bias. Трансімпедансний підсилювач TIA утримує WE на віртуальній землі V_ref та перетворює струм сенсора на вихідну напругу.*

#### Підсилювач керування (Control Amplifier)

Операційний підсилювач CA керує допоміжним електродом CE.
* Неінвертувальний вхід `(+)` підсилювача підключений до джерела заданої напруги зміщення `V_bias`.
* Інвертувальний вхід `(-)` підключений безпосередньо до електрода порівняння `RE`.
* Вихід підсилювача підключений до допоміжного електрода `CE` через струмообмежувальний резистор.

Завдяки високому коефіцієнту підсилення з розімкненою петлею (`A_OL > 100 дБ`) операційний підсилювач автоматично встановлює на своєму виході таку напругу, щоб зрівняти потенціали на своїх входах:

```
V_RE = V_bias
```

Оскільки вхідний каскад сучасного вимірювального ОП виконаний на польових транзисторах (CMOS / JFET), вхідний струм зміщення становить менше 1 пА. Електрод RE практично розімкнений по струму, і його потенціал залишається абсолютно стабільним.

Якщо на робочому електроді виникає окиснення CO і струм вимиває електрони, потенціал розчину починає коливатися. Підсилювач CA миттєво реагує на зміну потенціалу RE і впорскує протилежний струм через CE, підтримуючи фіксовану різницю напруг між робочим електродом та електродом порівняння:

```
V_WE - V_RE = V_ref - V_bias
```

Для сенсорів CO та `H₂S` цільове зміщення зазвичай дорівнює нулю (`V_bias = V_ref`, тобто нульова напруга між WE та RE), що зводить до мінімуму фоновий струм спокою та шуми. Для сенсорів кисню чи оксиду азоту NO встановлюють фіксоване зміщення (наприклад, `−600 мВ` для `O₂` або `+300 мВ` для `NO`).

#### Трансімпедансний підсилювач струму WE

Робочий електрод WE підключають до інвертувального входу другого операційного підсилювача (TIA). Його неінвертувальний вхід заземлено або підтягнуто до опорної напруги віртуальної землі `V_ref`.

Завдяки від'ємному зворотному зв'язку через резистор `R_f` інвертувальний вхід працює як **віртуальна земля**: він утримує електрод WE під фіксованим потенціалом `V_ref`, незалежно від сили генерованого струму:

```
V_WE = V_ref = const
```

Весь струм `I_WE`, що виходить із робочого електрода, змушений текти крізь зворотний резистор `R_f`, оскільки вхід ОП має гігаомний вхідний опір:

```
V_out = V_ref - I_WE · R_f      [для катодного струму, I_WE < 0]
V_out = V_ref + I_WE · R_f      [для анодного струму, I_WE > 0]
```

Для типового сенсора CO з чутливістю `70 нА/ppm` при концентрації 100 ppm струм становить `7.0 мкА`. Якщо обрати резистор зворотного зв'язку `R_f = 100 кОм`, корисний сигнал на виході зміниться на:

```
ΔV_out = 7.0 мкА · 100 кОм = 0.70 В
```

Цю напругу можна подавати на вхід аналого-цифрового перетворювача (АЦП) мікроконтролера.

#### Еквівалентна схема комірки та стійкість петлі

Електрохімічна комірка не є простим резистором. Її поведінка описується малосигнальною еквівалентною схемою Рендлса, яка включає:
1. `R_u` (*uncompensated resistance*) — нескомпенсований опір електроліту між RE та WE (10–100 Ом).
2. `R_e` — об'ємний опір електроліту між CE та RE (100–1000 Ом).
3. `C_dl` — ємність подвійного електричного шару робочого електрода (10–100 мікрофарад на см²).
4. `R_ct` — опір переносу заряду (понад 1 МОм за відсутності газу, зменшується при активній реакції).
5. `Z_W` — дифузійний імпеданс Варбурга на низьких частотах (`Z_W ∝ 1 / √ω`).

Ця величезна ємність `C_dl` у поєднанні з опором електроліту `R_u` формує коефіцієнт зворотного зв'язку петлі CA:

```
β(s) ≈ 1 / (1 + s · R_u · C_dl)
```

Він створює низькочастотний полюс у передавальній характеристиці петльового підсилення:

```
f_pole = 1 / (2 · π · R_u · C_dl)
```

Частота цього полюса становить лише кілька герц або десятків герц. На частоті одиничного підсилення фазовий зсув сягає 180°, перетворюючи від'ємний зворотний зв'язок на додатний. Потенціостат самозбуджується, генеруючи високочастотні коливання амплітудою в сотні мілівольтів. Це повністю руйнує вимірювання і швидко знищує каталітичний шар електрода.

Для гарантування фазового запасу понад 45–60° застосовують комбінацію заходів:
* Послідовний резистор `R_CE` (10–100 Ом) між виходом CA та електродом CE для ізоляції виходу від ємнісного навантаження.
* Конденсатор частотної корекції `C_comp` (10–100 нФ) між виходом CA та його інвертувальним входом, який створює шунтуючий високочастотний нуль.
* Конденсатор зворотного зв'язку `C_f` паралельно `R_f` у TIA для нейтралізації підйому шумового підсилення на високих частотах.

Оптимальне значення ємності `C_f` для баттервортівського відгуку другого порядку розраховують за формулою:

```
C_f = √(C_in / (2 · π · R_f · f_T))
```

де `C_in ≈ C_dl + C_cable + C_amp` — сумарна вхідна ємність на вузлі WE, а `f_T` — частота одиничного підсилення операційного підсилювача TIA.

### Дрейф базової лінії та компенсація температури

Навіть у абсолютно чистому повітрі за нульової концентрації цільового газу вихідний струм комірки не дорівнює строго нулю. Завжди існує невеликий фоновий струм `I_0` (**струм нульової лінії**, *baseline zero current*), зазвичай у межах від −10 до +20 нА. Він зумовлений залишковим окисненням слідів домішок на електродах та відновленням кисню на дефектах каталізатора.

Струм `I_0` експоненційно зростає з температурою за законом Арреніуса:

```
I_0(T) = I_0(20°C) · exp(-E_a / (k_B · T))
```

де `E_a` — енергія активації процесу, а `k_B` — стала Больцмана.

За нагрівання від 20 °C до 50 °C базовий струм сенсора CO може зрости з 2 нА до 30 нА. Без компенсації для сенсора із чутливістю 70 нА/ppm прилад покаже хибну концентрацію чадного газу:

```
Концентрація_хибна = 30 нА / (70 нА/ppm) ≈ 0.43 ppm
```

Для сенсорів низьких концентрацій (наприклад, озону чи діоксиду азоту, де вимірюють частки ppb), такий дрейф повністю перекриває корисний сигнал.

Для компенсації застосовують два методи:
1. **Математична компенсація за поліномом температури:** контролер періодично вимірює температуру вбудованим термодавачем і віднімає табличне або аналітично розраховане зміщення базової лінії `I_0(T)`.
2. **4-електродні сенсори з додатковим електродом (AUX):** в одному корпусі розміщують другий робочий електрод, повністю закритий від доступу газу. Його струм є чистим відображенням фонового дрейфу. Різниця струмів `I_WE - I_AUX` дає чистий газовий сигнал, вільний від температурного впливу.

### Перехресна чутливість та хімічна селективність

Платиновий каталізатор є універсальним промотором окиснення багатьох водневмісних сполук. Тому сенсор чадного газу демонструє **перехресну чутливість** (*cross-sensitivity*) до водню `H₂`, сірководню `H₂S`, діоксиду сірки `SO₂` та парів етилового спирту `C₂H₅OH`.

| Впливаючий газ | Концентрація газу | Відгук сенсора CO (умовний сигнал CO) | Механізм впливу |
|---|---|---|---|
| Водень (`H₂`) | 100 ppm | ~20–40 ppm CO | Каталітичне окиснення: `H₂ → 2H⁺ + 2e⁻` |
| Сірководень (`H₂S`) | 15 ppm | ~45 ppm CO (без фільтра) | Повне окиснення до `H₂SO₄` (8 електронів) |
| Діоксид сірки (`SO₂`) | 5 ppm | ~5 ppm CO (без фільтра) | Окиснення до сульфат-іонів |
| Етанол (`C₂H₅OH`) | 100 ppm | ~5–10 ppm CO | Окиснення до оцтової кислоти |
| Діоксид азоту (`NO₂`) | 5 ppm | −1..−2 ppm CO | Катодний відновний процес (від'ємний струм) |

Для усунення впливу важких молекул (`H₂S`, `SO₂`, пари спирту) всередину камери сенсора перед робочим електродом встановлюють **вбудований хімічний фільтр** на основі активованого вугілля з каталітичним просоченням солями перманганату калію `KMnO₄`. Фільтр необоротно зв'язує `H₂S` та `SO₂`, пропускаючи лише дрібні молекули `CO` та `H₂`.

Якщо в середовищі присутній водень (наприклад, зарядні станції акумуляторів, металургійні цехи), застосовують сенсори з компенсаційним водневим каналом (двокомпонентні комірки CO/H2) та розв'язують лінійну систему рівнянь чутливості у прошивці мікроконтролера.

### Інтегровані аналогові фронтенди (AFE)

У дискретному виконанні прецизійний потенціостат вимагає високоякісних зчетверених операційних підсилювачів з фемтоамперними вхідними струмами (наприклад, ADA4505, OPA333), прецизійних резисторів з низьким ТКС та джерел опорної напруги.

Сучасна промислова практика базується на використанні спеціалізованих монолітних мікросхем аналогового фронтенду, серед яких найпопулярнішим рішенням став чіп **Texas Instruments LMP91000**.

![Архітектура AFE LMP91000](/root/hw/hw-sensing/electrochemical-cell/img/afe-lmp91000-block-diagram.svg)
*Функціональна схема монолітного аналогового фронтенду LMP91000: через цифровий інтерфейс I²C налаштовуються коефіцієнт підсилення TIA, внутрішня напруга зміщення, полярність і режим глибокого сну із закорочуванням WE-RE.*

AFE LMP91000 містить усе необхідне для роботи з 3-електродними та 2-електродними комірками:
* Програмований через I²C опір зворотного зв'язку TIA `R_TIA` (від 2.75 кОм до 350 кОм);
* Програмований навантажувальний резистор `R_Load` (10, 33, 50, 100 Ом);
* Внутрішній ЦАП вибору віртуального нуля (20%, 50%, 67% від опорної напруги `V_ref`);
* Джерело регульованого зміщення (0% до 24% від `V_ref` з перемиканням знака);
* Вбудований аналоговий датчик температури на p-n переході з температурним коефіцієнтом `−8.2 мВ/°C`;
* Внутрішній польовий транзистор (Shorting FET), який закорочує електроди WE та RE під час сну, запобігаючи накопиченню поляризаційного заряду й скорочуючи час виходу на робочий режим після прокидання з годин до мілісекунд.

Повний вихідний код модуля ініціалізації, калібрування та зчитування концентрації для LMP91000 наведено у вставці [драйвер аналогового інтерфейсу потенціостата LMP91000](root:hw-sensing/electrochemical-cell/proj-lmp91000-afe.md).

### Алгоритм обчислення концентрації газу

Повний конвеєр обробки сигналу в прошивці мікроконтролера виконує такі математичні кроки:

1. **Зчитування напруги TIA:**
   АЦП вимірює напругу `V_OUT` на виході аналогового фронтенду.
2. **Розрахунок відхилення від віртуального нуля:**

   ```
   ΔV = V_OUT - V_zero
   ```

   де `V_zero = V_ref · k_zero` (наприклад, `3.3 В · 0.50 = 1.65 В`).
3. **Обчислення струму сенсора:**

   ```
   I_WE = ΔV / R_TIA
   ```

4. **Температурна корекція базової лінії та чутливості:**

   ```
   I_корисний = I_WE - I_baseline(T)
   S(T) = S_номінал · (1 + α_T · (T - 20°C))
   ```

5. **Фінальний перерахунок у концентрацію (ppm):**

   ```
   Концентрація_ppm = I_корисний / S(T)
   ```

#### Наскрізний числовий розрахунок

Розглянемо числовий приклад розрахунку концентрації чадного газу:
* Опорна напруга живлення: `V_ref = 3.30 В`;
* Рівень віртуального нуля: `20% V_ref` (`V_zero = 0.66 В`);
* Номінал резистора TIA: `R_TIA = 120 кОм` (`120000 Ом`);
* Номінальна чутливість сенсора: `S_номінал = 70 нА/ppm`;
* Базовий струм у чистому повітрі за 20 °C: `I_baseline = 2.0 нА`;
* Температурний коефіцієнт чутливості: `α_T = +0.003 °C⁻¹`;
* Виміряна поточна температура: `T = 30 °C`;
* Виміряна вихідна напруга АЦП: `V_OUT = 1.164 В`.

Покрокове обчислення у вбудованому процесорі:

```
ΔV = 1.164 В - 0.660 В = 0.504 В
I_WE = 0.504 В / 120000 Ом = 4.20 · 10⁻⁶ А = 4200 нА
k_temp = 1 + 0.003 · (30 - 20) = 1.030
I_baseline(30°C) = 2.0 нА · 1.030 = 2.06 нА
I_корисний = 4200 нА - 2.06 нА = 4197.94 нА
S(30°C) = 70 нА/ppm · 1.030 = 72.10 нА/ppm
Концентрація_CO = 4197.94 нА / (72.10 нА/ppm) = 58.22 ppm
```

Завдяки прямій амперометричній пропорційності електрохімічна комірка залишається найнадійнішим, енергоефективним та метрологічно чистим інструментом детектування токсичних газів та кисню у вимірювальних приладах безпеки.
