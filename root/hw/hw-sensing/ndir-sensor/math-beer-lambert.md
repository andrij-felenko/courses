# 🧮 Закон Бугера — Ламберта — Бера й нелінійна спектроскопія газів

Цей математичний аналіз розгортає теоретичну основу оптичного поглинання інфрачервоного випромінювання газами: від диференціального рівняння згасання фотонного потоку до інтегрування за скінченною смугою пропускання інтерференційного фільтра, врахування зіштовхувального розширення спектральних ліній Лоренца та термобаричної корекції молярної густини.

---

### 1. Виведення класичного закону поглинання

Розглянемо паралельний монохроматичний потік інфрачервоного випромінювання з початковою інтенсивністю `I₀` (Вт/м²), що поширюється вздовж осі `x` крізь однорідну газову суміш. Нехай у нескінченно тонкому шарі товщиною `dx` міститься газ-поглинач із числовою густиною молекул `N` (молекул/м³) або об'ємною часткою концентрації `c` (вираженою у частках або частинах на мільйон, ppm).

Кожна молекула газу взаємодіє з фотонами з ефективним перерізом поглинання `σ(λ)` (м²/молекулу). Ймовірність поглинання фотона в шарі `dx` пропорційна сумарній ефективній площі поглинання всіх молекул у цьому шарі. Відповідно, зменшення інтенсивності випромінювання `dI` на відстані `dx` описується диференціальним рівнянням:

```
dI = −σ(λ) · N · I(x) · dx
```

де мінус позначає зменшення інтенсивності внаслідок поглинання енергії коливальними модами молекул.

Поділимо обидві частини рівняння на `I(x)` для розділення змінних:

```
dI / I(x) = −σ(λ) · N · dx
```

Інтегруємо ліву частину від вхідної інтенсивності `I₀` при `x = 0` до залишкової інтенсивності `I` на виході з оптичної кювети довжиною `L`, а праву частину — від `0` до `L`:

```
ln(I) − ln(I₀)
= ln(I / I₀)                     [властивість логарифма різниці]
= ∫[0..L] (−σ(λ) · N) dx         [інтегрування за довжиною шляху]
= −σ(λ) · N · L                  [винесення сталих величин за інтеграл]
```

Потенціюючи обидві частини рівності (підносячи основу натурального логарифма `e` до відповідних степенів), отримуємо закон Бугера — Ламберта — Бера:

```
I(L)
= I₀ · e^(−σ(λ) · N · L)         [потенціювання експонентою]
= I₀ · e^(−α(λ) · c · L)         [перехід до макроскопічного коефіцієнта поглинання α]
```

де:
* `I₀` — інтенсивність випромінювання на вході в оптичну порожнину;
* `I(L)` — інтенсивність випромінювання, що дійшла до фотоприймача;
* `α(λ)` — спектральний коефіцієнт поглинання даного газу на довжині хвилі `λ` (см⁻¹·ppm⁻¹ або м⁻¹·%⁻¹);
* `c` — молярна концентрація або об'ємна частка газу (ppm);
* `L` — довжина оптичного шляху променя в газовій камері (см або м).

Безрозмірна величина `A = ln(I₀ / I) = α · c · L` називається **оптичною густиною** (*absorbance* або *extinction*). Для строго монохроматичного випромінювання оптична густина лінійно пропорційна концентрації `c`.

### 2. Спектральне інтегрування за смугою фільтра: виникнення нелінійності

У реальних NDIR-давачах джерело світла випромінює неперервний тепловий спектр (лампа розжарювання або MEMS-термовипромінювач), а довжину хвилі виділяє вузькосмуговий інтерференційний світлофільтр із функцією пропускання `T_f(λ)` та шириною на піввисоті `FWHM` (типово 150–200 нм навколо центральної довжини `λ₀ = 4.26` мкм).

Спектральна лінія поглинання CO₂ не є нескінченно широкою або абсолютно прямокутною — вона складається з десятків тонких обертально-коливальних ліній P- та R-гілок. Повна оптична потужність `P_det`, яку реєструє фотодетектор, є інтегралом за спектральним діапазоном:

```
P_det(c) = ∫[λ₁..λ₂] I_src(λ) · T_f(λ) · e^(−α(λ) · c · L) dλ
```

Оскільки коефіцієнт `α(λ)` змінюється на кілька порядків у межах смуги пропускання фільтра, ділянки спектра з максимальним `α` насичуються (поглинаються майже на 100%) уже при помірних концентраціях CO₂ (наприклад, 1000–2000 ppm), тоді як крила спектральної смуги продовжують пропускати випромінювання.

Внаслідок цього сумарна функція пропускання кювети відхиляється від чистої експоненти Бера. В інженерній практиці для опису дійсного сигналу детектора використовують модифіковане рівняння Бера:

```
I(c) = I₀ · (1 − F · (1 − e^(−α · cⁿ · L)))
```

або у формі відносного сигналу пропускання `TRAN(c) = I(c) / I₀`:

```
TRAN(c) = (1 − F) + F · e^(−α · cⁿ · L)
```

де:
* `F` — оптичний коефіцієнт форми (частка потужності джерела у смузі фільтра, яка взагалі здатна взаємодіяти зі смугою поглинання CO₂, зазвичай `0.75 ≤ F ≤ 0.95`); величина `(1 − F)` описує невипромінюване або нерезонансне паразитне світло, що оминає молекули або лежить за межами смуги поглинання;
* `n` — емпіричний показник нелінійності (для лінійчатих молекулярних спектрів `0.45 ≤ n ≤ 0.85`, типово `n ≈ 0.60`).

Звідси точна аналітична формула для розрахунку концентрації `c` за виміряним значенням відносної інтенсивності `TRAN = I / I₀`:

```
TRAN − (1 − F)
= F · e^(−α · cⁿ · L)                   [віднімання фонової частки 1 - F]

(TRAN − 1 + F) / F
= e^(−α · cⁿ · L)                       [ділення на оптичний фактор F]

ln((TRAN − 1 + F) / F)
= −α · cⁿ · L                           [логарифмування обох частин]

cⁿ
= −ln((TRAN − 1 + F) / F) / (α · L)     [ділення на −α · L]

c
= [ −ln(1 − (1 − TRAN) / F) / (α · L) ]^(1 / n)  [піднесення до степеня 1/n]
```

Ця формула використовується у внутрішніх обчислювальних ядрах сигнальних процесорів сенсорів для забезпечення лінійності шкали у діапазонах від 0 до 40 000 ppm.

### 3. Зіштовхувальне розширення ліній Лоренца (тиск) та Доплера (температура)

Індивідуальна спектральна лінія поглинання молекули розширюється під дією двох головних фізичних чинників:

1. **Зіштовхувальне (тискове) розширення Лоренца** (*pressure broadening*): при зіткненнях молекул CO₂ з молекулами азоту N₂ та кисню O₂ тривалість когерентного коливання диполя скорочується. Форма лінії описується профілем Лоренца:

```
g_L(ν − ν₀) = (γ_L / π) / [ (ν − ν₀)² + γ_L² ]
```

де півширина лінії `γ_L` прямо пропорційна загальному тиску газу `P`:

```
γ_L(P, T) = γ_L(P₀, T₀) · (P / P₀) · (T₀ / T)^m
```

де показник температури `m ≈ 0.5..0.75`. Зростання барометричного тиску збільшує півширину лінії `γ_L`, завдяки чому зростає інтегральне перекриття ліній із фільтром NDIR.

2. **Теплове розширення Доплера**: зумовлене хаотичним тепловим рухом молекул уздовж осі поширення світлового променя:

```
γ_D(T) = ν₀ · √[ (2 · k_B · T · ln 2) / (M · c_light²) ]
```

де `M` — маса молекули CO₂, `k_B` — стала Больцмана, `c_light` — швидкість світла у вакуумі. При нормальних атмосферних умовах усереднена ширина Лоренца `γ_L ≈ 0.07` см⁻¹ значно перевищує доплерівську ширину `γ_D ≈ 0.003` см⁻¹, тому профіль поглинання визначається переважно зіштовхувальним механізмом.

### 4. Термобарична корекція числа молекул (закон ідеального газу)

NDIR-давач за своєю природою підраховує **абсолютну кількість молекул** CO₂ на одиницю об'єму на шляху оптичного променя (числову густину `N/V`), а не їхнє відносне відсоткове співвідношення.

Згідно з рівнянням стану ідеального газу:

```
P · V = N_mol · R · T = (N / N_A) · R · T = N · k_B · T
```

Звідси числова густина молекул `ρ_N = N / V`:

```
ρ_N(P, T) = P / (k_B · T)
```

де:
* `P` — абсолютний атмосферний тиск (Па);
* `T` — абсолютна температура (К);
* `k_B` — стала Больцмана (`1.380649 × 10⁻²³` Дж/К).

Якщо давач відкалібровано на заводі за стандартних умов (`P_ref = 1013.25` гПа, `T_ref = 298.15` К = 25 °C), то за поточного тиску `P` та температури `T` виміряна сира концентрація `c_raw` перераховується у дійсну концентрацію `c_actual`:

```
c_actual = c_raw · (P_ref / P) · (T / T_ref)
```

Розглянемо практичний числовий приклад впливу висоти над рівнем моря:
На висоті 1500 м над рівнем моря середній атмосферний тиск становить `P = 845` гПа. Без увімкненої компенсації тиску давач зафіксує зменшення кількості молекул на 16.6% і покаже:

```
c_raw = 400 ppm · (845 / 1013.25) = 333.5 ppm
```

Похибка становить −66.5 ppm, що спотворює результати контролю вентиляції. Введення поточного барометричного тиску `P` у формулу корекції повністю відновлює точне значення:

```
c_actual = 333.5 · (1013.25 / 845) = 400.0 ppm
```

Саме тому сучасні вимірювальні вузли високого класу інтегрують барометричний давач тиску поруч із оптичною камерою NDIR.
