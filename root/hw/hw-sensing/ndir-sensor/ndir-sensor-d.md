Вимірювання концентрації вуглекислого газу в повітрі приховує фундаментальну інженерну пастку: більшість дешевих газових давачів узагалі не здатні відрізнити молекулу CO₂ від інших домішок. Метал-оксидні сенсори (MOX, від англ. *metal-oxide semiconductor*) вимірюють зміну провідності нагрітого шару діоксиду олова SnO₂ під дією відновних і окисних реакцій. Вони реагують на будь-які леткі органічні сполуки (спирти, ацетон, чадний газ, дим і навіть вологість повітря), видаючи так званий «еквівалентний CO₂» (eCO₂) на основі емпіричних кореляцій, які в чистому приміщенні з келихом вина дають показники понад 3000 ppm без жодного реального збільшення CO₂. Електрохімічні комірки, у свою чергу, витрачають рідкий або гелевий електроліт під час хімічної реакції, висихають протягом 1–2 років і вимагають постійного рекалібрування.

Щоб виміряти справжню концентрацію двоокису вуглецю безпосередньо, селективно й без руйнування досліджуваного зразка, звертаються до квантової структури самої молекули: кожна сполука у всесвіті має унікальний резонансний спектр оптичного поглинання в інфрачервоному діапазоні. Оптичний недисперсійний інфрачервоний газовий аналіз (NDIR, від англ. *Non-Dispersive Infrared*) підраховує молекули газу фізично: крізь пробу повітря пропускають пучок інфрачервоного світла точно визначеної довжини хвилі й вимірюють, яка частка фотонів була поглинута молекулами CO₂ на оптичному шляху.

### Молекулярний відбиток: резонансне валентне коливання 4.26 мкм

Молекула двоокису вуглецю (лат. *carbonii dioxidum*, CO₂) є лінійною симетричною триатомною структурою `O=C=O` з атомом Карбону в центрі та двома атомами Оксигену на кінцях. У стані спокою електричні дипольні моменти обох зв'язків `C=O` направлені протилежно й повністю компенсують один одного, тому молекула не має статичного дипольного моменту.

Однак квантова механіка дозволяє молекулі здійснювати чотири фундаментальні коливальні рухи (моди коливань):

1. **Симетричне валентне коливання `ν₁`** (хвильове число `1388` см⁻¹, довжина хвилі `λ = 7.2` мкм): обидва атоми Оксигену одночасно віддаляються від центрального атома Карбону й повертаються назад. Оскільки симетрія не порушується, сумарний дипольний момент молекули лишається нульовим (`dμ/dq = 0`). Це коливання є оптично неактивним у лінійному інфрачервоному поглинанні (воно проявляється лише у спектрах комбінаційного розсіювання світла Рамана).
2. **Деформаційні (згинальні) коливання `ν₂a` та `ν₂b`** (хвильове число `667` см⁻¹, довжина хвилі `λ = 15.0` мкм): атом Карбону зміщується перпендикулярно до осі зв'язку, згинаючи молекулу у двох взаємно перпендикулярних площинах. Це коливання супроводжується появою змінного дипольного моменту й створює дуже потужну смугу поглинання в дальньому ІЧ-діапазоні (саме вона забезпечує парниковий ефект в атмосфері Землі), проте через довжину хвилі 15 мкм вимагає дорогих оптичних матеріалів і незручна для компактних давачів.
3. **Асиметричне валентне коливання `ν₃`** (хвильове число `2349` см⁻¹, довжина хвилі `λ = 4.26` мкм): атом Карбону рухається вздовж осі молекули в один бік, тоді як обидва атоми Оксигену рухаються в протилежний. У момент такого коливання баланс зарядів різко порушується: виникає потужний динамічний дипольний момент (`dμ/dq ≠ 0`).

![Спектр поглинання газів у середньому інфрачервоному діапазоні та смуги оптичних фільтрів NDIR](/root/hw/hw-sensing/ndir-sensor/img/co2-absorption-spectrum.svg)
*Спектри поглинання газів у середньому ІЧ-діапазоні (2–6 мкм). Резонансна смуга асиметричного валентного коливання CO₂ ν₃ на довжині хвилі 4.26 мкм повністю ізольована від смуг поглинання водяної пари H₂O, метану CH₄ та чадного газу CO. Опорний оптичний фільтр 3.91 мкм розташований у ділянці нульового поглинання всіх атмосферних газів.*

Довжина хвилі `λ = 4.26` мкм (середній інфрачервоний діапазон, MWIR) є так званим «золотим оптичним вікном» газового аналізу. Головні складові земної атмосфери — азот N₂ та кисень O₂ — є гомоядерними двоатомними молекулами. Вони не мають дипольного моменту за будь-яких коливань і є абсолютно прозорими для інфрачервоного світла на всіх довжинах хвиль. Водяна пара (H₂O), що є головним джерелом оптичних завад у повітрі, має потужні смуги поглинання біля `2.7` мкм та вище `5.5` мкм, проте на відрізку `3.8–4.3` мкм її поглинання практично дорівнює нулю. Метан (CH₄) поглинає на `3.3` мкм, а чадний газ (CO) — на `4.67` мкм.

Таким чином, у смузі `4.26` мкм вуглекислий газ поглинає інфрачервоне випромінювання практично монопольно. Будь-яке ослаблення світлового потоку на цій конкретній довжині хвилі свідчить виключно про присутність молекул CO₂.

### Закон Бугера — Ламберта — Бера й фізика ослаблення світла

Ослаблення потоку оптичного випромінювання під час проходження крізь однорідний шар газу описується фундаментальним законом Бугера — Ламберта — Бера (франц. *Bouguer*, нім. *Lambert*, *Beer*):

```
I = I₀ · e^(−α · c · L)
```

де:
* `I₀` — початкова інтенсивність світлового потоку на вході в оптичну камеру (Вт/м²);
* `I` — залишкова інтенсивність випромінювання, що дійшла до приймача після проходження крізь газ;
* `α` — питомий коефіцієнт поглинання газу на довжині хвилі вимірювання (см⁻¹·ppm⁻¹);
* `c` — об'ємна концентрація газу (ppm, частка на мільйон або %);
* `L` — оптична довжина шляху світлового променя в камері (см або м).

Фізичний зміст закону прозорий: кожна молекула газу має ефективну площу взаємодії з фотонами (переріз оптичного захоплення `σ`). Проходячи крізь газовий простір, фотони стикаються з молекулами й поглинаються, переходячи в енергію коливання зв'язків. Зменшення інтенсивності на нескінченно малому відрізку шляху `dx` пропорційне поточному числу фотонів та концентрації молекул: `dI = −α · c · I · dx`. Інтегрування цього рівняння від входу `x = 0` до виходу `x = L` дає спадну експоненційну залежність.

Звідси концентрація газу `c` однозначно визначається через натуральний логарифм відношення інтенсивностей:

```
ln(I / I₀)
= −α · c · L                     [логарифмування закону Бера]

c
= −ln(I / I₀) / (α · L)          [ділення на −α · L]
= ln(I₀ / I) / (α · L)           [властивість логарифма: −ln(a/b) = ln(b/a)]
```

#### Вибір оптичної довжини шляху `L`

Величина оптичного шляху `L` є головним конструктивним параметром NDIR-сенсора. Вона визначає динамічний діапазон і чутливість приладу:
* Для контролю якості повітря в приміщеннях (діапазон концентрацій `400–2000` ppm CO₂) поглинання на короткому шляху є малим. Щоб отримати вимірне падіння сигналу (типово від 2% до 15% від початкової яскравості `I₀`), необхідний оптичний шлях `L = 20..60` мм.
* Для медичної капнографії (вимірювання CO₂ у видиху пацієнта, діапазон `0–10%` або `0–100 000` ppm) довжина шляху має бути дуже малою (`L = 1..5` мм). Якби шлях складав 50 мм, світловий потік на рівні 5% CO₂ поглинувся б майже на 99.9%, і сенсор увійшов би в насичення, втративши чутливість до подальших змін.

#### Нелінійність реальних фільтрів і поправка Бера

Класичний закон Бера справедливий строго для монохроматичного випромінювання нескінченно вузької спектральної ширини. У реальному сенсорі інтерференційний фільтр має скінченну ширину смуги пропускання `FWHM ≈ 180` нм, а спектр CO₂ складається з безлічі дискретних обертальних ліній. Центральні лінії насичуються швидше за периферійні, тому функція пропускання стає сумою багатьох експонент з різними коефіцієнтами `α`.

Для точного опису реального тракту застосовують лінеаризовану формулу з емпіричним показником ступеня `n < 1` (типово `n ≈ 0.6`):

```
I(c) = I₀ · (1 − F · (1 − e^(−α · cⁿ · L)))
```

де `F` — оптичний фактор заповнення (частка потужності у смузі фільтра, яка перекривається смугою поглинання CO₂). Строге математичне виведення інтегральної форми поглинання та розрахунок розширення ліній тиском наведено у вставці [Закон Бугера — Ламберта — Бера й нелінійна спектроскопія газів](root:hw-sensing/ndir-sensor/math-beer-lambert.md).

#### Залежність від барометричного тиску й температури

NDIR-сенсор реагує не на відсоткове співвідношення, а на **густину молекул** (абсолютне число молекул CO₂ в оптичному об'ємі кювети). Згідно з рівнянням стану ідеального газу `P · V = N · k_B · T`, число молекул на одиницю об'єму дорівнює:

```
N / V = P / (k_B · T)
```

Якщо атмосферний тиск `P` зростає (наприклад, на рівні моря при антициклоні `1030` гПа), повітря стискається, густина молекул збільшується, і давач фіксує сильніше поглинання світла, показуючи завищену концентрацію. Навпаки, у високогірній місцевості (на висоті 2000 м, `P ≈ 795` гПа) повітря розріджене: давач нарахує на 21% менше поглинань і покаже, наприклад, 316 ppm замість дійсних 400 ppm.

Підвищення температури `T` діє навпаки: газ розширюється, густина молекул падає, і оптичний сигнал зростає. Тому сучасний NDIR-вузол обов'язково містить алгоритм термобаричної корекції:

```
c_actual = c_raw · (P_ref / P_ambient) · (T_ambient / T_ref)
```

де `P_ref = 1013.25` гПа, а `T_ref = 298.15` К (25 °C). Без компенсації барометричного тиску будь-який NDIR-давач має незручну похибку близько 0.1% на кожен 1 гПа відхилення тиску.

### Анатомія оптичної камери NDIR

Фізичний блок NDIR-сенсора є мініатюрною оптико-механічною системою, зібраною в герметичному або дифузійному корпусі. Вона складається з трьох ключових вузлів: оптичної кювети з відбивачами, джерела інфрачервоного випромінювання та чутливого фотодетектора.

![Конструкція оптичної камери NDIR-давача та проходження світлових променів](/root/hw/hw-sensing/ndir-sensor/img/ndir-chamber-optics.svg)
*Внутрішня будова NDIR-кювети. Модульоване ІЧ-джерело випромінює імпульси світла, які багаторазово відбиваються від позолочених дзеркальних стінок камери вздовж оптичного шляху L. Проба повітря дифундує крізь захисну PTFE-мембрану. Двоканальний приймач розділяє потік на два оптичні фільтри: активний 4.26 мкм (поглинається CO₂) та опорний 3.91 мкм (не поглинається газом).*

#### 1. Позолочена оптична порожнина

Щоб розмістити оптичний шлях довжиною `30–60` мм у корпусі розміром із монету (`20 × 15 × 8` мм), форму камери роблять складеною: еліптичною, параболічною або U-подібною. Світловий промінь виходить із джерела, відбивається від бічних дзеркальних склепінь і концентрується на приймачі.

Внутрішню поверхню пластикового або алюмінієвого шасі покривають тонким шаром чистого золота (гальванічним золоченням або вакуумним напиленням). Золото обрано не через розкіш: у середньому інфрачервоному діапазоні (довжини хвиль `3–5` мкм) коефіцієнт дзеркального відбиття золота перевищує `98.5%`. Крім того, золото є хімічно інертним: воно не окиснюється на повітрі, не тьмяніє від вологи та сірчистих газів, на відміну від срібла чи алюмінію, які за кілька місяців вкриваються оксидними й сульфідними плівками, що поглинають ІЧ-промені й викривляють нуль сенсора.

#### 2. Джерела інфрачервоного випромінювання

В NDIR-системах застосовують два типи випромінювачів:

* **Мікролампи розжарювання** (вольфрамова спіраль у скляній міні-колбі): працюють як теплове абсолютно чорне тіло за законом Планка за температури нитки близько `1800–2200` К. Вони дешеві й дають стабільний, потужний широкосмуговий потік випромінювання. Проте скляна колба лампи частково зрізає спектр вище 4.5 мкм, а теплова інерція спіралі є великою: час розігріву й охолодження становить десятки мілісекунд, що обмежує частоту імпульсної модуляції до `1–3` Гц і вимагає значного пікового струму (до 50–100 мА).
* **MEMS-термовипромінювачі** (мікронагрівачі на ультратонкій кремнієвій мембрані): на тонкій плівці нітриду кремнію Si₃N₄ або оксиду формують платиновий або полікремнієвий нагрівальний резистор із малим тепловим об'ємом. Завдяки крихітній масі MEMS-випромінювач нагрівається до 800 °C за кілька мілісекунд, що дозволяє модулювати випромінювання з частотою `10–50` Гц, споживаючи в середньому всього `2–5` мВт потужності.

**Чому світло обов'язково модулюють імпульсами?** Постійне (немодульоване) світіння лампи робить вимірювання неможливим з двох причин:
1. Низькочастотний флікер-шум (`1/f`-шум) фотодетекторів та дрейф постійної напруги операційних підсилювачів на порядки перевищують корисний мікровольтовий сигнал поглинання.
2. Температура самої камери під час роботи змінюється; стінки кювети самі випромінюють теплове інфрачервоне світло відповідно до закону Стефана — Больцмана. Якщо світло джерела пульсує з відомою частотою (наприклад, 4 Гц), електроніка детектора вимірює **змінну амплітуду** (різницю між фазою «світло увімкнено» та фазою «світло вимкнено»), повністю відсікаючи постійний фоновий тепловий шум навколишнього середовища.

#### 3. Фотоприймачі: піроелектрики та термостовпчики

Виділяють два класи приймачів інфрачервоного сигналу:

* **Термостовпчики** (*thermopiles*): складаються з матриці сотень послідовно з'єднаних мініатюрних термопар на базі кремнію або бісмут-телуриду. Гарячі спаї термопар розміщені під тонким чорним поглиначем інфрачервоного світла, а холодні — на масивному кремнієвому кристалі. Інфрачервоне випромінювання нагріває поглинач на долі градуса, і за рахунок [ефекту Зеєбека](root:hw-sensing/efekt-zeiebeka) термостовпчик генерує постійну термо-ЕРС (одиниці мілівольтів), строго пропорційну потужності світлового пучка. Термостовпчики є надійними, повільними й не потребують складного живлення.
* **Піроелектричні детектори** (*pyroelectric detectors*): використовують кристали танталату літію (LiTaO₃). Вони мають спонтанну електричну поляризацію, яка змінюється лише під час **динамічної зміни температури** (`dQ/dt ∝ dT/dt`). Піроелектрик реагує виключно на імпульсний потік фотонів і є швидшим за термостовпчик, проте вимагає обов'язкової імпульсної модуляції джерела.

Перед кожним чутливим елементом фотоприймача монтують вузькосмуговий оптичний інтерференційний світлофільтр (багатошарове діелектричне дзеркало з чергуванням шарів із високим і низьким показником заломлення, наприклад германію та сульфіду цинку Ge/ZnS).

#### 4. Захисна газова мембрана

Оптична кювета контактує із зовнішнім повітрям крізь отвір, закритий гідрофобною пористою мембраною з політетрафторетилену (PTFE, тефлон). Розмір пор мембрани (близько 0.2–1 мкм) дозволяє молекулам газу швидко дифундувати всередину камери за рахунок градієнта концентрацій (закон Фіка), але повністю блокує проникнення пилу, жирового аерозолю, кухонного чаду та крапель рідкої води, захищаючи дзеркальне напилення від забруднення.

### Двоканальна архітектура: подолання старіння джерела світла

Головна проблема одноканального NDIR-сенсора полягає в тому, що він принципово не здатний відрізнити зменшення яскравості лампи від збільшення концентрації газу.

У процесі експлуатації відбуваються незворотні деградаційні процеси:
1. Вольфрамова нитка лампи поступово випаровується: метал осідає на скляній колбі, затемнюючи її. Яскравість випромінювання `I₀` монотонно падає на `1–3%` на рік.
2. На позолочених дзеркалах осідає мікроскопічний наліт летких органічних речовин, знижуючи коефіцієнт відбиття.
3. Напруга живлення та температура корпусу викликають тепловий дрейф підсилювального тракту.

Якщо яскравість лампи в одноканальній системі впаде всього на `2%`, математичне ядро сенсора розцінить це як поглинання світла молекулами газу й видасть хибний приріст концентрації на рівні `+150..200` ppm CO₂. За 2–3 роки прилад показуватиме 800 ppm у абсолютно чистому вуличному повітрі.

![Порівняння стабільності одноканального та двоканального NDIR-давача при старінні лампи](/root/hw/hw-sensing/ndir-sensor/img/beer-lambert-dual-channel.svg)
*Механізм компенсації апаратної деградації у двоканальному NDIR. В одноканальній схемі падіння яскравості лампи на 20% створює хибний дрейф нуля на +800 ppm. У двоканальній схемі обчислення відношення активного сигналу до опорного 3.91 мкм скорочує множник I₀, забезпечуючи нульовий довготривалий дрейф базової лінії.*

Для вирішення цієї проблеми створено **двоканальну оптичну архітектуру** (*Dual Channel NDIR*). У такій системі випромінювання від єдиного джерела світла потрапляє на два фотодетектори (або один детектор із двома чутливими майданчиками під різними фільтрами):

1. **Активний канал вимірювання** (фільтр `λ_act = 4.26` мкм): вимірює інтенсивність `I_act`, яка залежить як від поточної яскравості джерела `I₀(t)`, так і від поглинання CO₂:
   ```
   I_act = I₀(t) · K_opt · e^(−α · c · L)
   ```
2. **Опорний (референтний) канал** (фільтр `λ_ref = 3.91` мкм): розташований на довжині хвилі, де жоден газ земної атмосфери не має смуг поглинання. Сигнал цього каналу `I_ref` залежить **тільки** від яскравості джерела, відбиття дзеркал та забруднення оптичного вікна:
   ```
   I_ref = I₀(t) · K_opt_ref · 1.0
   ```

Мікроконтролер сенсора обчислює відношення двох сигналів:

```
R(c)
= I_act / I_ref                                              [диференційне відношення сигналів]
= [ I₀(t) · K_opt · e^(−α · c · L) ] / [ I₀(t) · K_opt_ref ] [підстановка значень сигналів]
= (K_opt / K_opt_ref) · e^(−α · c · L)                       [скорочення яскравості джерела I₀(t)]
= K_calib · e^(−α · c · L)                                   [зведення апаратних констант у калібрувальний множник]
```

Оскільки яскравість випромінювача `I₀(t)` та коефіцієнт ослаблення від пилу входять співмножниками в обидва канали одночасно, під час ділення вони **повністю скорочуються**. Завдяки цьому двоканальні сенсори зберігають заводську точність протягом 10–15 років безперервної роботи, що робить їх стандартом для систем життєзабезпечення, промислової автоматики та медичного обладнання.

### Автоматичне фонове калібрування (ABC): алгоритм та критичні пастки

Двоканальна оптика суттєво здорожчує сенсор через необхідність двох прецизійних інтерференційних фільтрів та прецизійної юстировки двох приймачів. У масових одноканальних сенсорах для побутових кондиціонерів, моніторів мікроклімату та термостатів (наприклад, SenseAir S8, Winsen MH-Z19, дешеві модифікації SCD40) для боротьби з дрейфом нуля використовують математичний алгоритм — **автоматичне фонове калібрування** (ABC, від англ. *Automatic Baseline Correction*).

![Часовий графік роботи алгоритму ABC та небезпека помилкового калібрування в теплицях](/root/hw/hw-sensing/ndir-sensor/img/abc-algorithm-timeline.svg)
*Робота алгоритму автоматичного фонового калібрування (ABC). У типовому офісному циклі концентрація CO₂ вночі та на вихідних опускається до базового рівня вуличного повітря (400–420 ppm). Якщо за 7 днів мінімум змістився до 460 ppm через старіння кювети, ABC коригує нуль на −60 ppm. У непровітрюваних приміщеннях або теплицях ABC призводить до фатального заниження показів і має бути вимкнений.*

#### Логіка роботи алгоритму ABC

Алгоритм ABC спирається на базову гіпотезу про експлуатацію приміщень:
1. Люди є головним джерелом CO₂ у будівлях (кожна людина під час дихання виділяє близько 20–30 літрів CO₂ на годину).
2. Протягом тижня будівля регулярно залишається порожньою (уночі або на вихідних).
3. Припливна вентиляція або природна інфільтрація крізь вікна й двері за відсутності людей знижує концентрацію вуглекислого газу до рівня свіжого зовнішнього повітря.
4. Концентрація CO₂ у чистому атмосферному повітрі планети є стабільною глобальною константою, яка на сьогодні становить близько **415–420 ppm** (усереднено приймається за 400 ppm).

Сенсор безперервно записує всі виміряні значення концентрації в енергонезалежну пам'ять протягом ковзного часового вікна тривалістю **7 або 8 днів** (180–200 годин). Наприкінці кожного тижня вбудований мікроконтролер знаходить **мінімальне зафіксоване значення** `c_min`. 

Якщо оптика ідеальна, `c_min` має дорівнювати 400 ppm. Якщо внаслідок старіння лампи нуль сенсора здрейфував угору й мінімум за тиждень склав, наприклад, 470 ppm, алгоритм робить логічний висновок: реальна концентрація була 400 ppm, а зайві 70 ppm є апаратним зміщенням нуля. Сенсор автоматично перераховує калібрувальний коефіцієнт зсуву (зміщення базової лінії) на величину `Δ = c_min − 400 = +70` ppm і зберігає нову нульову точку в пам'яті EEPROM.

#### Фатальні пастки ABC: коли алгоритм руйнує вимірювання

Хоча ABC є чудовим безкоштовним рішенням для офісних приміщень і шкіл, існують сценарії, де увімкнений ABC повністю виводить систему з ладу:

1. **Сільськогосподарські теплиці та гроубокси**: для прискорення росту рослин у повітря теплиць штучно подають вуглекислий газ, підтримуючи рівень `1000–1500` ppm цілодобово. Вночі рослини не поглинають CO₂ (фотосинтез зупиняється) і самі виділяють його під час дихання. Рівень газу ніколи не опускається нижче 800–1000 ppm. Алгоритм ABC знайде тижневий мінімум `850` ppm, прийме його за чисте повітря «400 ppm» і зсуне калібрування на −450 ppm! Через місяць такої роботи сенсор показуватиме 400 ppm там, де насправді 1500 ppm, спричиняючи загибель рослин через надмірну газацію.
2. **Цілодобові приміщення з людьми**: лікарняні палати інтенсивної терапії, чергові частини, серверні кімнати з операторами, центри керування польотами, підземні укриття, де постійно перебувають люди. Мінімальний рівень CO₂ там може ніколи не падати нижче 700 ppm. ABC поступово спотворить шкалу, маскуючи небезпечну задуху.
3. **Герметичні енергоефективні будівлі без примусової вентиляції**: якщо вікна зачинені цілодобово, рівень газу може постійно перевищувати 600–700 ppm.

> 🔧 **Навіщо це.** Завжди аналізуйте призначення приладу перед розгортанням прошивки. Якщо пристрій працюватиме в офісі чи квартирі — тримайте ABC увімкненим, це позбавить користувача необхідності ручного калібрування. Якщо ж пристрій монтується в теплиці, погребі, бомбосховищі, на виробництві грибів чи пивоварні — **обов'язково вимикайте ABC через конфігураційну команду** і використовуйте або двоканальні NDIR-давачі, або регламентне ручне калібрування за чистим повітрям.

### Драйвер NDIR-сенсора: архітектура й реалізація

Розглянемо повну реалізацію драйвера на прикладі одного з найдосконаліших промислових двоканальних NDIR-модулів — **Sensirion SCD30** (I2C-інтерфейс, діапазон 0–40 000 ppm, похибка ±(30 ppm + 3%), інтегрований термогігрометр, підтримка динамічного введення атмосферного тиску). Повний опис регістрів, таймінгів та обчислення CRC-8 наведено в [довідці командного інтерфейсу Sensirion SCD30](root:hw-sensing/ndir-sensor/api-scd30-i2c.md).

Драйвер забезпечує:
* Ініціалізацію періодичного вимірювання з передачею поточного барометричного тиску (гПа);
* Опитування прапорця готовності даних (*Data Ready*);
* Зчитування 18-байтового фрейму, валідацію 6 контрольних сум CRC-8 та розпакування чисел з плаваючою комою IEEE-754;
* Керування режимом ABC та примусове ручне калібрування (*Forced Recalibration*).

```c
#include <stdint.h>
#include <stdbool.h>
#include <string.h>

// I2C адреса SCD30
#define SCD30_I2C_ADDR                     0x61

// Команди сенсора
#define SCD30_CMD_START_CONTINUOUS         0x0010
#define SCD30_CMD_STOP_CONTINUOUS          0x0104
#define SCD30_CMD_SET_MEASUREMENT_INTERVAL 0x4600
#define SCD30_CMD_GET_DATA_READY           0x0202
#define SCD30_CMD_READ_MEASUREMENT         0x0300
#define SCD30_CMD_SET_AUTO_CALIBRATION     0x5306
#define SCD30_CMD_SET_FORCED_RECALIBRATION 0x5204
#define SCD30_CMD_SET_TEMP_OFFSET          0x5403
#define SCD30_CMD_SOFT_RESET               0xD304

typedef struct {
    float co2_ppm;
    float temperature_c;
    float relative_humidity_pct;
} scd30_data_t;

// Апаратний інтерфейс I2C (впроваджується користувачем)
typedef struct {
    int (*i2c_write)(uint8_t addr, const uint8_t *data, size_t len);
    int (*i2c_read)(uint8_t addr, uint8_t *data, size_t len);
    void (*delay_ms)(uint32_t ms);
} scd30_i2c_hal_t;

typedef struct {
    scd30_i2c_hal_t hal;
    bool is_measuring;
} scd30_driver_t;

static uint8_t scd30_crc8(const uint8_t *data, size_t len) {
    uint8_t crc = 0xFF;
    for (size_t i = 0; i < len; ++i) {
        crc ^= data[i];
        for (uint8_t b = 0; b < 8; ++b) {
            crc = (crc & 0x80) ? ((crc << 1) ^ 0x31) : (crc << 1);
        }
    }
    return crc;
}

static int scd30_send_cmd_arg(scd30_driver_t *drv, uint16_t cmd, uint16_t arg) {
    uint8_t buf[5];
    buf[0] = (uint8_t)(cmd >> 8);
    buf[1] = (uint8_t)(cmd & 0xFF);
    buf[2] = (uint8_t)(arg >> 8);
    buf[3] = (uint8_t)(arg & 0xFF);
    buf[4] = scd30_crc8(&buf[2], 2);
    return drv->hal.i2c_write(SCD30_I2C_ADDR, buf, sizeof(buf));
}

int scd30_init(scd30_driver_t *drv, const scd30_i2c_hal_t *hal) {
    if (!drv || !hal) return -1;
    drv->hal = *hal;
    drv->is_measuring = false;
    return 0;
}

int scd30_start_measurement(scd30_driver_t *drv, uint16_t ambient_pressure_mbar) {
    // ambient_pressure_mbar: 0 - вимкнено, або 700..1200 гПа
    int res = scd30_send_cmd_arg(drv, SCD30_CMD_START_CONTINUOUS, ambient_pressure_mbar);
    if (res == 0) {
        drv->is_measuring = true;
    }
    return res;
}

int scd30_check_data_ready(scd30_driver_t *drv, bool *ready) {
    uint8_t cmd[2] = { (uint8_t)(SCD30_CMD_GET_DATA_READY >> 8), (uint8_t)(SCD30_CMD_GET_DATA_READY & 0xFF) };
    if (drv->hal.i2c_write(SCD30_I2C_ADDR, cmd, 2) != 0) return -1;
    
    drv->hal.delay_ms(3);
    
    uint8_t rx[3];
    if (drv->hal.i2c_read(SCD30_I2C_ADDR, rx, 3) != 0) return -1;
    if (scd30_crc8(rx, 2) != rx[2]) return -2; // Помилка CRC

    uint16_t status = ((uint16_t)rx[0] << 8) | rx[1];
    *ready = (status == 1);
    return 0;
}

int scd30_read_measurement(scd30_driver_t *drv, scd30_data_t *out) {
    uint8_t cmd[2] = { (uint8_t)(SCD30_CMD_READ_MEASUREMENT >> 8), (uint8_t)(SCD30_CMD_READ_MEASUREMENT & 0xFF) };
    if (drv->hal.i2c_write(SCD30_I2C_ADDR, cmd, 2) != 0) return -1;

    drv->hal.delay_ms(3);

    uint8_t rx[18];
    if (drv->hal.i2c_read(SCD30_I2C_ADDR, rx, 18) != 0) return -1;

    // Перевірка 6 CRC байтів
    for (int i = 0; i < 6; ++i) {
        if (scd30_crc8(&rx[i * 3], 2) != rx[i * 3 + 2]) {
            return -2; // Помилка CRC блоку
        }
    }

    uint32_t raw_co2 = ((uint32_t)rx[0] << 24) | ((uint32_t)rx[1] << 16) | ((uint32_t)rx[3] << 8) | rx[4];
    uint32_t raw_temp = ((uint32_t)rx[6] << 24) | ((uint32_t)rx[7] << 16) | ((uint32_t)rx[9] << 8) | rx[10];
    uint32_t raw_rh = ((uint32_t)rx[12] << 24) | ((uint32_t)rx[13] << 16) | ((uint32_t)rx[15] << 8) | rx[16];

    memcpy(&out->co2_ppm, &raw_co2, sizeof(float));
    memcpy(&out->temperature_c, &raw_temp, sizeof(float));
    memcpy(&out->relative_humidity_pct, &raw_rh, sizeof(float));

    return 0;
}

int scd30_set_auto_calibration(scd30_driver_t *drv, bool enable) {
    return scd30_send_cmd_arg(drv, SCD30_CMD_SET_AUTO_CALIBRATION, enable ? 1 : 0);
}
```

```cpp
    }

    [[nodiscard]] std::expected<bool, SensorError> is_data_ready() noexcept {
        const auto cmd = static_cast<uint16_t>(Command::GetDataReady);
        const std::array<uint8_t, 2> tx_buf{
            static_cast<uint8_t>(cmd >> 8),
            static_cast<uint8_t>(cmd & 0xFF)
        };

        if (!write_fn_(I2cAddress, tx_buf)) return std::unexpected(SensorError::BusError);
        delay_fn_(3);

        std::array<uint8_t, 3> rx_buf{};
        if (!read_fn_(I2cAddress, rx_buf)) return std::unexpected(SensorError::BusError);
        if (compute_crc(std::span{rx_buf.data(), 2}) != rx_buf[2]) {
            return std::unexpected(SensorError::CrcMismatch);
        }

        const uint16_t status = (static_cast<uint16_t>(rx_buf[0]) << 8) | rx_buf[1];
        return (status == 1);
    }

    [[nodiscard]] std::expected<SensorData, SensorError> read_measurement() noexcept {
        const auto cmd = static_cast<uint16_t>(Command::ReadMeasurement);
        const std::array<uint8_t, 2> tx_buf{
            static_cast<uint8_t>(cmd >> 8),
            static_cast<uint8_t>(cmd & 0xFF)
        };

        if (!write_fn_(I2cAddress, tx_buf)) return std::unexpected(SensorError::BusError);
        delay_fn_(3);

        std::array<uint8_t, 18> rx_buf{};
        if (!read_fn_(I2cAddress, rx_buf)) return std::unexpected(SensorError::BusError);

        for (size_t i = 0; i < 6; ++i) {
            if (compute_crc(std::span{&rx_buf[i * 3], 2}) != rx_buf[i * 3 + 2]) {
                return std::unexpected(SensorError::CrcMismatch);
            }
        }

        const auto unpack_float = [](const uint8_t* p) noexcept -> float {
            const uint32_t raw = (static_cast<uint32_t>(p[0]) << 24) |
                                 (static_cast<uint32_t>(p[1]) << 16) |
                                 (static_cast<uint32_t>(p[3]) << 8)  |
                                 (static_cast<uint32_t>(p[4]));
            return std::bit_cast<float>(raw);
        };

        SensorData data{};
        data.co2_ppm = unpack_float(&rx_buf[0]);
        data.temperature_c = unpack_float(&rx_buf[6]);
        data.relative_humidity_pct = unpack_float(&rx_buf[12]);

        return data;
    }

    [[nodiscard]] std::expected<void, SensorError> set_auto_self_calibration(bool enable) noexcept {
        return send_command_with_arg(Command::SetAutoCalibration, enable ? 1 : 0);
    }

private:
    enum class Command : uint16_t {
        StartContinuous    = 0x0010,
        StopContinuous     = 0x0104,
        SetInterval        = 0x4600,
        GetDataReady       = 0x0202,
        ReadMeasurement    = 0x0300,
        SetAutoCalibration = 0x5306,
        SetForcedRecalib   = 0x5204,
        SoftReset          = 0xD304
    };

    static uint8_t compute_crc(std::span<const uint8_t> data) noexcept {
        uint8_t crc = 0xFF;
        for (uint8_t byte : data) {
            crc ^= byte;
            for (uint8_t b = 0; b < 8; ++b) {
                crc = (crc & 0x80) ? static_cast<uint8_t>((crc << 1) ^ 0x31) : static_cast<uint8_t>(crc << 1);
            }
        }
        return crc;
    }

    std::expected<void, SensorError> send_simple_command(Command cmd) noexcept {
        const auto val = static_cast<uint16_t>(cmd);
        const std::array<uint8_t, 2> buf{
            static_cast<uint8_t>(val >> 8),
            static_cast<uint8_t>(val & 0xFF)
        };
        if (!write_fn_(I2cAddress, buf)) return std::unexpected(SensorError::BusError);
        return {};
    }

    std::expected<void, SensorError> send_command_with_arg(Command cmd, uint16_t arg) noexcept {
        const auto val = static_cast<uint16_t>(cmd);
        std::array<uint8_t, 5> buf{
            static_cast<uint8_t>(val >> 8),
            static_cast<uint8_t>(val & 0xFF),
            static_cast<uint8_t>(arg >> 8),
            static_cast<uint8_t>(arg & 0xFF),
            0
        };
        buf[4] = compute_crc(std::span{&buf[2], 2});
        if (!write_fn_(I2cAddress, buf)) return std::unexpected(SensorError::BusError);
        return {};
    }

    WriteFn write_fn_;
    ReadFn read_fn_;
    DelayFn delay_fn_;
};

} // namespace sensirion
```

### Підсумки: чому NDIR залишається безальтернативним

1. **Молекулярна вибірковість**: резонансне коливання `ν₃` на довжині хвилі 4.26 мкм повністю захищене від впливу спиртів, вологи, диму та супутніх газів атмосфери.
2. **Прямий підрахунок часток**: сенсор підпорядковується закону Бугера — Ламберта — Бера й вимірює фізичну кількість молекул на одиницю об'єму, що вимагає температурної та барометричної корекції `c ∝ P / T`.
3. **Двоканальна стабільність**: виділення опорного каналу на довжині хвилі 3.91 мкм компенсує дрейф яскравості випромінювача й забруднення дзеркал без втрати чутливості приладу протягом десятиліть.
4. **Особливості ABC**: алгоритм автоматичного калібрування нуля придатний лише для приміщень із регулярним провітрюванням до рівня 400 ppm; у теплицях, підземних об'єктах та медичних стаціонарах його використання призводить до фатальних помилок вимірювання.
