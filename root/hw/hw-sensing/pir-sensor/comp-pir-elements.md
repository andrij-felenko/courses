# 🔌 Порівняння двоелементних та чотириелементних PIR-сенсорів

Вибір просторової топології та кількості піроелектричних кристалів на підкладці детектора безпосередньо визначає його стійкість до хибних спрацьовувань, діаграму спрямованості та здатність розрізняти людину й дрібних тварин. Невдало обрана геометрія елементів призводить або до виникнення сліпих зон при переміщенні людини у певному напрямку, або до регулярних тривог від сонячних відблисків та потоків теплого повітря від батарей опалення.

### Одиноелементні сенсори (Single-Element)

Найпростіша конструкція піроелектричного детектора містить єдиний кристал танталату літію або PZT, підключений до затвора внутрішнього польового транзистора.

```
[ ІЧ-фільтр ] → [ Піроелемент (1 кристал) ] → [ JFET ] → Вихід
```

Особливості функціонування:
- **Повна відсутність синфазної компенсації**: Будь-яке повільне підвищення температури навколишнього середовища, конвекційний протяг або сонячний промінь, що впав на корпус датчика, нагріває єдиний кристал. Внаслідок цього генерується потужний нескомпенсований піроелектричний струм, який маскує корисний сигнал або спричиняє безперервні хибні тривоги.
- **Сфера застосування**: Пасивні системи виявлення руху практично не використовують одиноелементні сенсори. Їхня ніша — прилади з примусовою модуляцією світла: інфрачервоні оптичні газоаналізатори (NDIR), пірометри з механічним переривачем променя (чопером), вимірювачі потужності лазерного випромінювання та спектрометри швидких теплових процесів.

### Двоелементні сенсори (Dual-Element)

Стандартний промисловий PIR-детектор (наприклад, класичні сенсори `RE200B`, `D203S` або `LHi968`) містить два однакові прямокутні піроелектричні майданчики, розташовані на одній підкладці на відстані близько `1 мм` один від одного.

```
   Елемент A (+)         Елемент B (-)
+-----------------+   +-----------------+
|     LiTaO3      |   |     LiTaO3      |
+-----------------+   +-----------------+
        |                      |
        +------[ Зустрічно ]----+-----> Затвор JFET
```

Кристали з'єднані **зустрічно-послідовно** або **протифазно-паралельно**. Завдяки цьому при рівномірному освітленні корпусу або зміні температури повітря обидва кристали нагріваються з однаковою швидкістю `dT_A/dt = dT_B/dt`. Генеровані ними заряди мають однакову амплітуду, але протилежні знаки, що дає результуючий струм, близький до нуля:

```
i_out(t) = p · A · (dT_A/dt - dT_B/dt) = 0
```

Коефіцієнт придушення синфазного сигналу (CMRR) становить від `40 дБ` до `55 дБ`.

**Анізотропія чутливості (проблема сліпої осі):**
Двоелементний сенсор має чітко виражену просторову орієнтацію.
- **Горизонтальний рух (вздовж осі X, перпендикулярно до лінії поділу кристалів):** Людина послідовно перетинає оптичну зону елемента A, а потім елемента B. Сенсор видає повну двополярну синусоїдальну хвилю з максимальною амплітудою.
- **Вертикальний рух (вздовж осі Y, паралельно до кристалів):** Об'єкт одночасно входить у зони обох кристалів. Обидва елементи нагріваються синфазно, їхні сигнали взаємно віднімаються, і амплітуда вихідної напруги падає на `70–90%`. Сенсор стає практично «сліпим».

З цієї причини двоелементні датчики монтують строго горизонтально на стінах на висоті `2.0–2.4 м`, щоб людина, яка йде по кімнаті чи коридору, перетинала промені поперек.

### Чотириелементні сенсори (Quad-Element)

Для усунення просторової анізотропії та створення стельових датчиків із круговим оглядом 360° використовують чотириелементні сенсори (наприклад, `LHi1148`, `D204S` або цифрові `PYD1798`).

На кристалічній пластині сформовано чотири чутливі майданчики у вигляді матриці 2×2 (шахова топологія):

```
+---------------+---------------+
|  Елемент A1   |  Елемент B1   |
|     (+)       |     (-)       |
+---------------+---------------+
|  Елемент B2   |  Елемент A2   |
|     (-)       |     (+)       |
+---------------+---------------+
```

Діагональні елементи з'єднані паралельно: `A = A1 + A2` (позитивна полярність) та `B = B1 + B2` (негативна полярність), а між собою пари `A` та `B` увімкнені зустрічно.

Переваги чотириелементної схеми:
1. **Ізотропна чутливість 360°**: Рух об'єкта в будь-якому напрямку (горизонтально, вертикально, по діагоналі) неминуче викликає асиметричне засвічення пар кристалів, генеруючи потужний диференціальний сигнал.
2. **Подвійне просторове відсікання конвекції**: Локальні потоки теплого повітря від радіаторів мають просторовий градієнт температури. Шахова геометрія компенсує лінійні градієнти як по осі X, так і по осі Y.

### Захист від тварин (Pet Immunity)

У професійних охоронних сповіщувачах чотириелементні сенсори реалізують функцію несприйнятливості до домашніх тварин масою до 15–25 кг.

У таких датчиках верхня пара елементів `(A1, B1)` та нижня пара `(A2, B2)` підключаються до двох **роздільних аналогових каналів підсилення** або зчитуються двоканальним вбудованим АЦП.
- **Людина (високий вертикальний профіль):** Перетинає одночасно промені верхнього та нижнього ярусів лінзи. Сигнали генеруються в обох каналах синхронно з високою амплітудою.
- **Кіт або собака (низький горизонтальний профіль біля підлоги):** Опромінює виключно промені нижнього каналу `(A2, B2)`, тоді як у верхньому каналі сигнал перебуває на рівні фонового шуму.

Мікроконтролер датчика порівнює співвідношення амплітуд `V_top / V_bottom`: якщо енергія зосереджена лише в нижньому ярусі, подія класифікується як рух тварини й тривога не генерується.

### Порівняльна таблиця характеристик

| Характеристика | Одиноелементний (Single) | Двоелементний (Dual) | Чотириелементний (Quad) |
|---|---|---|---|
| Кількість піроелементів | 1 | 2 | 4 (матриця 2×2) |
| Синфазна компенсація тепла (CMRR) | Немає (0 дБ) | Висока (40–55 дБ) | Надвисока (55–70 дБ) |
| Стійкість до конвекції повітря | Вкрай низька | Середня (тільки вздовж осі X) | Відмінна (по осях X та Y) |
| Напрямкова чутливість | Кругова (потрібен чопер) | Анізотропна (чутливий по X, сліпий по Y) | Повністю ізотропна (360°) |
| Оптимальне місце монтажу | Оптичні прилади / камери | Стіна (висота 2.2 м) | Стеля (360°) / стіна |
| Підтримка Pet Immunity | Неможлива | Обмежена (шторні лінзи) | Апаратна (двоканальний аналіз) |
| Відносна вартість | 1.0× (базова) | 1.2× ... 1.5× | 2.5× ... 4.0× |
| Типові моделі | LHi958, PYZ-series | RE200B, D203S, LHi968 | D204S, LHi1148, PYD1798 |

Для стандартних настінних вимикачів освітлення та коридорних сенсорів оптимальним вибором за співвідношенням ціни та якості залишається двоелементний детектор з горизонтальною установкою. Для стельових сенсорів сигналізації та приміщень із домашніми тваринами або складним тепловим режимом безальтернативним є чотириелементний сенсор.
