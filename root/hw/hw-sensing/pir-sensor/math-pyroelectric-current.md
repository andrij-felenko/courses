# 🧮 Математичний апарат піроелектричного струму та частотного відгуку

Щоб розрахувати амплітуду вихідного сигналу PIR-детектора та правильно налаштувати смугу пропускання аналогового тракту, необхідно пов'язати потік інфрачервоного випромінювання від рухомого об'єкта зі швидкістю зміни температури чутливого кристала та результуючим піроелектричним струмом. Без математичного опису теплового балансу, частотної передавальної функції та аналізу шумів неможливо обґрунтувати, чому сенсор сліпий до постійного тепла й чому його максимальна чутливість лежить у діапазоні 0.5–5 Гц.

### Рівняння спонтанної поляризації та піроелектричний струм

Піроелектричний кристал (наприклад, танталат літію `LiTaO3` або сегнетокераміка `PZT`) у полярній фазі володіє вектором спонтанної поляризації `P_s`, спрямованим уздовж полярної осі кристала. Поверхнева густина зв'язаного електричного заряду на гранях, перпендикулярних до полярної осі, дорівнює модулю поляризації:

```
σ_bound = P_s
```

Сумарний зв'язаний заряд на електроді площею `A` становить:

```
Q = P_s · A
```

При зміні температури кристала `T` тепловий рух вузлів ґратки змінює міжатомні відстані та дипольні моменти комірок, внаслідок чого спонтанна поляризація змінюється. Диференціювання заряду за часом визначає миттєвий піроелектричний струм `i_p(t)`:

```
i_p(t) = dQ / dt
= d(P_s · A) / dt             [A = const: площа електрода незмінна]
= A · (dP_s / dT) · (dT / dt) [ланцюгове правило диференціювання]
= p · A · (dT / dt)           [означення p = dP_s / dT]
```

де:
- `p = dP_s / dT` — піроелектричний коефіцієнт матеріалу (для `LiTaO3` становить `-2.3 × 10⁻⁴ C/(m²·K)`, для кераміки `PZT` сягає `-4.0 × 10⁻⁴ C/(m²·K)`);
- `A` — площа поверхні чутливого елемента (типово `2 × 1 мм² = 2 × 10⁻⁶ m²`);
- `dT / dt` — швидкість зміни середньої температури кристала в часі.

Знак «мінус» у коефіцієнті `p` означає, що при нагріванні (`dT/dt > 0`) спонтанна поляризація зменшується, і надлишковий вільний заряд стікає з електрода у зовнішнє коло. При стаціонарній температурі (`dT/dt = 0`), навіть якщо кристал нагрітий до 100 °C, піроелектричний струм тотожно дорівнює нулю.

### Диференціальне рівняння теплового балансу кристала

Розглянемо піроелектричний елемент масою `m`, об'ємом `V = A · d` (де `d` — товщина пластини), питомою теплоємністю `c_v` та коефіцієнтом поглинання поверхні `η`. Елемент закріплений на тримачі всередині корпусу, внаслідок чого він віддає тепло навколишньому середовищу з ефективною тепловою провідністю `G_th` (через конвекцію газу та теплопередачу через контакти).

Повна теплоємність піроелектричного елемента дорівнює:

```
C_th = c_v · V = c_v · A · d
```

Нехай на поверхню падає модульований тепловий потік потужністю `Φ(t)`. Рівняння збереження енергії для різниці температур між кристалом та середовищем `ΔT(t) = T(t) - T_amb` має вигляд:

```
C_th · (d(ΔT) / dt) + G_th · ΔT(t) = η · Φ(t)
```

При гармонічній модуляції теплового потоку з круговою частотою `ω = 2·π·f` від рухомого об'єкта:

```
Φ(t) = Φ_0 · exp(j · ω · t)
```

Шукаємо стаціонарний розв'язок у вигляді `ΔT(t) = ΔT_0 · exp(j · ω · t)`:

```
j · ω · C_th · ΔT_0 + G_th · ΔT_0 = η · Φ_0   [підстановка гармонічного розв'язку ΔT(t)]
ΔT_0 · (G_th + j · ω · C_th) = η · Φ_0         [винесення спільного множника ΔT_0]
ΔT_0 = (η · Φ_0) / (G_th + j · ω · C_th)       [ділення обох частин на (G_th + j·ω·C_th)]
= (η · Φ_0 / G_th) / (1 + j · ω · τ_th)        [поділ на G_th з урахуванням τ_th = C_th/G_th]
```

де `τ_th = C_th / G_th` — теплова стала часу детектора (типове значення `τ_th ≈ 0.2 ... 1.0 с`, що відповідає тепловій частоті зрізу `f_th = 1 / (2·π·τ_th) ≈ 0.15 ... 0.8 Гц`).

Підставивши знайдену амплітуду коливань температури у вираз піроелектричного струму:

```
i_p(t) = p · A · (d(ΔT) / dt)                                                   [означення піроелектричного струму]
= j · ω · p · A · ΔT(t)                                                         [диференціювання гармонічної експоненти]
= (j · ω · p · A · η · Φ_0 · exp(j · ω · t)) / (G_th · (1 + j · ω · τ_th))     [підстановка розв'язку для ΔT(t)]
```

Амплітуда піроелектричного струму становить:

```
|I_p(ω)| = (ω · |p| · A · η · Φ_0) / (G_th · √(1 + ω² · τ_th²))
```

### Еквівалентна електрична схема та вихідна напруга

Піроелектричний кристал із нанесеними металевими електродами з точки зору електродинаміки є паралельним з'єднанням джерела струму `i_p(t)`, власної статичної ємності `C_p` та надвисокого внутрішнього опору витоку `R_p`. Для зняття сигналу сенсор навантажується на високоомний вхід затвора JFET-транзистора з резистором зміщення `R_g` та вхідною ємністю транзистора і монтажу `C_in`.

Сумарний електричний опір та сумарна ємність на вході повторювача становлять:

```
R = (R_p · R_g) / (R_p + R_g) ≈ R_g   [оскільки R_p ~ 10¹² Ом, R_g ~ 50 ГОм]
C = C_p + C_in                       [паралельне з'єднання ємностей]
```

Електричний імпеданс вхідного кола на частоті `ω`:

```
Z_e(ω) = R / (1 + j · ω · R · C) = R / (1 + j · ω · τ_e)
```

де `τ_e = R · C` — електрична стала часу кола затвора (для `R = 50 ГОм = 5 × 10¹⁰ Ом` та `C = 30 пФ = 3 × 10⁻¹¹ Ф` отримуємо `τ_e = 1.5 с`, що дає нижню електричну частоту зрізу `f_e = 1 / (2·π·τ_e) ≈ 0.1 Гц`).

Вихідна напруга на затворі дорівнює добутку піроелектричного струму на еквівалентний імпеданс:

```
V_g(ω) = I_p(ω) · Z_e(ω)                                                               [закон Ома для комплексних амплітуд]
= (j · ω · p · A · η · Φ_0 · R) / [ G_th · (1 + j · ω · τ_th) · (1 + j · ω · τ_e) ]   [підстановка виразів I_p(ω) та Z_e(ω)]
```

### Комплексний коефіцієнт вольтової чутливості R_v(ω)

Вольтова чутливість детектора `R_v(ω)` визначається як відношення амплітуди вихідної напруги до падаючої оптичної потужності `Φ_0`:

```
R_v(ω) = |V_g(ω)| / Φ_0                                                                      [означення коефіцієнта вольтової чутливості]
= (ω · |p| · A · η · R) / [ G_th · √(1 + ω² · τ_th²) · √(1 + ω² · τ_e²) ]                    [модуль комплексного виразу напруги]
```

Проаналізуємо поведінку функції `R_v(ω)` у трьох характерних частотних діапазонах:

```
1. Низькі частоти (ω << 1/τ_th та ω << 1/τ_e, тобто f < 0.05 Гц):
   √(1 + ω² · τ_th²) ≈ 1,   √(1 + ω² · τ_e²) ≈ 1
   R_v(ω) ≈ (ω · |p| · A · η · R) / G_th
   Чутливість прямо пропорційна частоті (R_v ~ ω).
   При постійному освітленні (ω = 0) чутливість тотожно дорівнює нулю.

2. Середні частоти (1/τ_th < ω < 1/τ_e або 1/τ_e < ω < 1/τ_th, тобто 0.3 Гц < f < 5 Гц):
   Один із радикалів стає пропорційним ω: √(1 + ω² · τ²) ≈ ω · τ.
   R_v(ω) ≈ (|p| · A · η) / (G_th · τ_th · C) = (|p| · η) / (c_v · d · C)
   Чутливість досягає максимального плато і практично не залежить від частоти!

3. Високі частоти (ω >> 1/τ_th та ω >> 1/τ_e, тобто f > 10 Гц):
   Обидва радикали пропорційні частоті: √(1 + ω² · τ_th²) · √(1 + ω² · τ_e²) ≈ ω² · τ_th · τ_e.
   R_v(ω) ≈ (|p| · A · η) / (C_th · C · ω)
   Чутливість спадає обернено пропорційно частоті (R_v ~ 1/ω).
```

Графік чутливості має виразний куполоподібний смуговий характер із максимумом саме в зоні частот модуляції від рухомої людини `0.5 ... 3 Гц`.

З аналізу плато чутливості `R_v(плато) = (|p| · η) / (c_v · d · C)` безпосередньо випливає важливий технологічний висновок: чутливість обернено пропорційна товщині кристала `d`. Зменшення товщини пластинки `LiTaO3` з `100 мкм` до `20 мкм` зменшує її теплоємність у 5 разів і пропорційно збільшує вихідну амплітуду сигналу. Проте подальше витончення обмежується механічною крихкістю монокристала та зростанням власної електричної ємності `C_p = ε · ε_0 · A / d`.

### Власні шуми детектора та гранична виявляльна здатність

Граничну чутливість PIR-сенсора визначають три незалежні фізичні джерела шуму на вході підсилювального каскаду:

1. **Тепловий шум Джонсона — Найквіста навантажувального резистора Rg:**
   Тепловий рух електронів у гігаомному резисторі зміщення `R_g` генерує середньоквадратичну густину шуму напруги:
   ```
   v_n_R(ω) = √(4 · k_B · T · R_g) / √(1 + ω² · τ_e²)
   ```
   де `k_B = 1.38 × 10⁻²³ Дж/К` — стала Больцмана. Через шунтування ємністю `C` спектр шуму спадає на високих частотах.

2. **Діелектричний шум втрат у кристалі піроелектрика:**
   Поляризаційні втрати в діелектрику описуються тангенсом кута втрат `tg δ` (для `LiTaO3` становить близько `10⁻³`). Цей шум еквівалентний генерації флуктуаційного струму:
   ```
   i_n_d(ω) = √(4 · k_B · T · ω · C_p · tg δ)
   ```

3. **Шум струму витоку та напруги каналу JFET-транзистора:**
   Струм витоку затвора `I_gate ≈ 1 пА` створює дробовий шум струму `i_shot = √(2 · q · I_gate)`, а канал транзистора вносить шум напруги `v_jfet ≈ 10–20 нВ/√Гц`.

Сумарна еквівалентна потужність шуму (NEP, *Noise Equivalent Power*) визначає мінімальний тепловий потік, за якого співвідношення сигнал/шум дорівнює одиниці (`SNR = 1`):

```
NEP(ω) = v_n_total(ω) / R_v(ω)   [Вт / √Гц]
```

Питома виявляльна здатність детектора (*Specific Detectivity* `D*`), нормалізована за площею кристала та смугою пропускання, обчислюється як:

```
D*(ω) = √(A · Δf) / NEP(ω)
```

Для якісних сенсорів на базі `LiTaO3` параметр `D*` на частоті `1 Гц` сягає `(1.5 ... 3.0) × 10⁸ см·√Гц / Вт`. Це дозволяє впевнено виділяти тепловий сигнал людини амплітудою всього `5–10 мкВт` на фоні повного власного шуму схеми, що не перевищує `20–40 мкВ`.

### Числовий розрахунок вихідної амплітуди

Обчислимо напругу на виході датчика при проходженні людини на відстані 5 метрів.

Вихідні параметри системи:
- Матеріал: кристал `LiTaO3` (`p = 2.3 × 10⁻⁴ C/(m²·K)`, `c_v = 3.2 × 10⁶ J/(m³·K)`);
- Геометрія елемента: товщина `d = 20 мкм = 2 × 10⁻⁵ м`, площа `A = 2 мм² = 2 × 10⁻⁶ м²`;
- Оптична система: лінза Френеля фокусує випромінювання з ефективною площею збирання `A_lens = 4 см² = 4 × 10⁻⁴ м²`, коефіцієнт пропускання поліетилену `T_lens = 0.7`, поглинання кристала `η = 0.85`;
- Електричне коло: `R = 50 ГОм = 5 × 10¹⁰ Ом`, `C = 25 пФ = 2.5 × 10⁻¹¹ Ф`, кругова частота модуляції `f = 1.5 Гц` (`ω = 2 · π · 1.5 ≈ 9.42 рад/с`).

Потужність ІЧ-випромінювання від людини, що потрапляє на лінзу на відстані `r = 5 м`:
Теплове випромінювання відкритої ділянки тіла площею `0.1 м²` при температурі 34 °C на фоні стін 22 °C створює чистий радіаційний потік `ΔP_rad ≈ 7 Вт`. Густина потоку на відстані 5 м:

```
I_ir = ΔP_rad / (2 · π · r²) = 7 / (2 · π · 25) ≈ 0.0446 Вт/м²
```

Потужність, сфокусована на піроелемент:

```
Φ_0 = I_ir · A_lens · T_lens · η
= 0.0446 · (4 × 10⁻⁴) · 0.7 · 0.85
≈ 1.06 × 10⁻⁵ Вт = 10.6 мкВт
```

Обчислення теплоємності та чутливості на частотному плато:

```
C_th = c_v · A · d
= (3.2 × 10⁶) · (2 × 10⁻⁶) · (2 × 10⁻⁵)   [підстановка значень c_v, A, d]
= 1.28 × 10⁻⁴ Дж/К                        [результат множення]

R_v(плато) = (|p| · η) / (c_v · d · C)
= (2.3 × 10⁻⁴ · 0.85) / [ (3.2 × 10⁶) · (2 × 10⁻⁵) · (2.5 × 10⁻¹¹) ]   [підстановка параметрів LiTaO3]
= (1.955 × 10⁻⁴) / (1.6 × 10⁻⁹)                                        [обчислення проміжних значень]
≈ 122 000 В/Вт                                                         [кінцевий розрахунок чутливості]
```

Амплітуда сигналу напруги на затворі JFET:

```
V_out = R_v · Φ_0
= 122 000 В/Вт · (10.6 × 10⁻⁶ Вт)   [множення чутливості на сфокусовану потужність]
≈ 1.29 В                            [теоретичний максимум на затворі]
```

З урахуванням втрат у реальному сенсорі амплітуда коливань напруги на витоку JFET-повторювача становить від `1.5 мВ` до `15 мВ`. Для надійного спрацьовування стандартного цифрового компаратора з логічним порогом `0.5–2 В` потрібен аналоговий підсилювач із коефіцієнтом підсилення `K_v ≈ 60 ... 75 дБ` (від 1000 до 5000 разів).
