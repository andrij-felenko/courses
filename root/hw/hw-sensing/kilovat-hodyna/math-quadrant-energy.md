# 🧮 Математичний аналіз потужностей та чисельне інтегрування енергії

Математичний апарат вимірювання електроенергії базується на переході від неперервних функцій часу напруги `v(t)` і струму `i(t)` до інтегральних енергетичних показників та їхньої дискретної апроксимації в цифрових сигнальних процесорах.

### 1. Декомпозиція миттєвої потужності для синусоїдних сигналів

Нехай напруга мережі та струм навантаження описуються гармонійними функціями частоти `ω = 2π · f` зі зсувом фаз `φ`:

```
v(t) = V_pk · sin(ωt)
i(t) = I_pk · sin(ωt - φ)
```

Миттєва електрична потужність `p(t)` дорівнює алгебраїчному добутку миттєвих значень напруги та струму:

```
p(t) = v(t) · i(t)
= V_pk · I_pk · sin(ωt) · sin(ωt - φ)                                [підстановка гармонійних функцій]
= (V_pk · I_pk / 2) · [cos(φ) - cos(2ωt - φ)]                       [тригонометрична тотожність 2·sin(A)·sin(B) = cos(A-B) - cos(A+B)]
= (V_pk / √2) · (I_pk / √2) · [cos(φ) - cos(2ωt)·cos(φ) - sin(2ωt)·sin(φ)] [розклад косинуса різниці cos(2ωt - φ)]
= V_RMS · I_RMS · cos(φ) · (1 - cos(2ωt)) - V_RMS · I_RMS · sin(φ) · sin(2ωt) [виділення діючих значень RMS]
```

У результаті миттєва потужність природно розпадається на дві фізично різні складові:

```
p(t) = P · (1 - cos(2ωt)) - Q · sin(2ωt)
```

де визначено дві фундаментальні величини:
1. **Активна потужність** `P = V_RMS · I_RMS · cos(φ)` (вимірюється у Ватах, Вт) — це стала складова потужності, що виконує корисну фізичну роботу (нагрівання, механічний рух). Член `P · (1 - cos(2ωt))` завжди невід'ємний (`1 - cos(2ωt) ≥ 0`) і пульсує з подвійною частотою мережі `2ω` (100 Гц при частоті мережі 50 Гц).
2. **Реактивна потужність** `Q = V_RMS · I_RMS · sin(φ)` (вимірюється у вольт-амперах реактивних, вар) — амплітуда коливальної потужності, яка не виконує нетто-роботи, а періодично перекачується між джерелом і реактивними накопичувачами (індуктивністю магнітного поля та ємністю електричного поля). Її середнє значення за період дорівнює нулю:

```
(1 / T) · ∫₀ᵀ Q · sin(2ωt) dt = 0                                     [інтеграл від синуса за ціле число періодів дорівнює 0]
```

Повна потужність `S` (вольт-ампери, В·А) визначається добутком середньоквадратичних (RMS) величин:

```
S = V_RMS · I_RMS = √(P² + Q²)
```

Коефіцієнт потужності (*Power Factor*, `PF`) є відношенням активної потужності до повної:

```
PF = P / S = cos(φ)                                                  [для чисто синусоїдних сигналів]
```

### 2. Чутливість похибки активної потужності до фазового зсуву

Проаналізуємо вплив невеликої фазової похибки `Δφ` (спричиненої затримкою в трансформаторі струму чи RC-фільтрі АЦП) на точність обчислення активної потужності.

Знайдемо повний диференціал активної потужності за змінною `φ`:

```
dP / dφ = d(V_RMS · I_RMS · cos φ) / dφ
= -V_RMS · I_RMS · sin(φ)                                             [похідна косинуса]
```

Визначимо відносну похибку вимірювання активної потужності `ε_P = ΔP / P`:

```
ε_P = (dP / dφ) · Δφ / P
= (-V_RMS · I_RMS · sin φ · Δφ) / (V_RMS · I_RMS · cos φ)            [ділення на P]
= -tan(φ) · Δφ                                                        [тригонометричне спрощення]
```

Отриманий вираз `ε_P = -tan(φ) · Δφ` демонструє небезпечну нелінійність:
- При чисто активному навантаженні (`φ = 0°`, `cos φ = 1.0`): тангенс `tan(0°) = 0`. Фазова похибка взагалі не впливає на точність вимірювання активної потужності.
- При індуктивному навантаженні з низьким коефіцієнтом потужності `PF = 0.1` (`φ = 84.26°`): тангенс сягає `tan(84.26°) ≈ 9.95`.
- Якщо апаратна частина вносить крихітний нескомпенсований фазовий зсув `Δφ = 0.1° = 0.001745 рад`, відносна похибка обчислення активної енергії складе:

```
ε_P = -9.95 · 0.001745 ≈ -0.01736 (-1.74%)
```

Крихітний зсув у 0.1 градуса перетворює лічильник класу точності 0.2 на прилад із похибкою майже 2%! Саме тому калібрування фазового зсуву в DSP-тракті завжди виконують при штучно заданому зсуві `cos φ = 0.5` (`φ = 60°`), де чутливість тангенса `tan(60°) = √3 ≈ 1.732` є високою і стабільною.

### 3. Несинусоїдні режими та теорії потужностей

Якщо напруга або струм містять вищі гармоніки (що є нормою для сучасної імпульсної силової електроніки), сигнали розкладаються у ряди Фур'є:

```
v(t) = V₀ + ∑_{h=1}^∞ √2 · V_h · sin(hωt + α_h)
i(t) = I₀ + ∑_{h=1}^∞ √2 · I_h · sin(hωt + β_h)
```

Середньоквадратичні значення напруги та струму обчислюються як квадратний корінь із суми квадратів усіх гармонік:

```
V_RMS = √(V₀² + ∑_{h=1}^∞ V_h²)
I_RMS = √(I₀² + ∑_{h=1}^∞ I_h²)
```

Активна потужність `P` є сумою активних потужностей окремих гармонік:

```
P = V₀ · I₀ + ∑_{h=1}^∞ V_h · I_h · cos(θ_h)
```

де `θ_h = α_h - β_h` — фазовий кут між `h`-ми гармоніками напруги та струму.

За класичною теорією Будяну (*Constantin Budeanu*, 1927), реактивна потужність визначається сумою реактивних потужностей гармонік:

```
Q_B = ∑_{h=1}^∞ V_h · I_h · sin(θ_h)
```

При цьому повна потужність `S` містить додатковий член — **потужність спотворення** `D` (*Distortion Power*, вар):

```
S² = P² + Q_B² + D²
D = √(S² - P² - Q_B²)
```

Сучасний стандарт IEEE 1459 розділяє повну потужність на фундаментальну складову `S₁` (частота 50/60 Гц) та нефундаментальну складову вищих гармонік `S_eN`:

```
S² = S₁² + S_eN²
S₁² = P₁² + Q₁²
PF = P / S = (P₁ + P_h) / (V_RMS · I_RMS) = (I₁_RMS / I_RMS) · (V₁_RMS / V_RMS) · cos(θ₁) ≈ (1 / √(1 + THD_i²)) · cos(θ₁)
```

де `THD_i` — коефіцієнт гармонійних спотворень струму (*Total Harmonic Distortion*).

### 4. Чисельне інтегрування та межі похибок дискретизації

У цифровому мікропроцесорному лічильнику неперервні функції часу `v(t)` та `i(t)` замінюються дискретними вибірками `v[n] = v(n · T_s)` та `i[n] = i(n · T_s)`, знятими з інтервалом квантування `T_s = 1 / f_s` (де `f_s` — частота дискретизації АЦП, типово від 4 кГц до 32 кГц).

Миттєва дискретна потужність у момент часу `n` обчислюється як:

```
p[n] = v[n] · i[n]
```

Енергія за інтервал спостереження `[0, T_obs]` обчислюється за методом прямокутників:

```
E_approx = ∑_{n=0}^{N-1} p[n] · T_s = (1 / f_s) · ∑_{n=0}^{N-1} v[n] · i[n]
```

За теоремою залишкового члена числового інтегрування прямокутників, похибка апроксимації `ε_rect` обмежена першою похідною миттєвої потужності:

```
|ε_rect| ≤ (T_obs · T_s / 2) · max |p'(t)|
```

Оскільки максимальна частота миттєвої потужності при наявності гармонік до порядку `H` становить `2H · ω`, похідна досягає:

```
max |p'(t)| ≈ 2H · ω · S
```

Для фундаментальної гармоніки 50 Гц (`ω = 314.16 рад/с`) та частоти дискретизації `f_s = 8000 Гц` (`T_s = 125 мкс`), відносна похибка одного періоду становить:

```
|ε_rel| ≤ (T_s · 2ω) / 4 = (125 · 10⁻⁶ · 628.32) / 4 = 1.96 · 10⁻² (≈ 0.019%)
```

Крім того, при синхронному зборі цілого числа періодів коливань залишковий член від перемінної складової `cos(2ωt)` взаємно знищується, і реальна похибка визначення активної енергії падає нижче `0.001%`.

### 5. Катастрофа втрати точності в числах із рухомою комою (float32)

Розглянемо поширену помилку початківців: реалізацію накопичувача енергії у форматі IEEE 754 `float` (32 біти одинарної точності). Формат `float32` має 1 знак, 8 бітів експоненти та 23 біти мантиси (що забезпечує роздільну здатність 24 біти або приблизно 7.22 десяткових цифри).

Нехай лічильник накопичує енергію кроком кожного вибіркового інтервалу `T_s = 125 мкс` при потужності `P = 1 кВт`:

```
ΔE = P · T_s = 1000 Вт · 0.000125 с = 0.125 Дж (3.472 · 10⁻⁸ кВт·год)
```

Коли сумарний акумулятор енергії досягає значення `1000 кВт·год = 3.6 · 10⁹ Дж`, найменший біт мантиси `float32` (*machine epsilon*) набуває ваги:

```
LSB_float = 3.6 · 10⁹ Дж · 2⁻²⁴ = 3.6 · 10⁹ / 16777216 ≈ 214.57 Дж
```

При спробі додати елементарний квант `ΔE = 0.125 Дж` до значення `3.6 · 10⁹ Дж` відбувається повне зникнення розрядів (*swallowing / cancellation*):

```
E_next = 3600000000.0f + 0.125f = 3600000000.0f                      [доданок менший за LSB мантиси]
```

Лічильник повністю зупиняє підрахунок енергії! Споживач продовжує використовувати потужність, а покази приладу залишаються «замороженими» на позначці 1000 кВт·год.

### 6. Fixed-Point Q31.32: 64-бітне цілочисельне накопичення

Для забезпечення абсолютної метрологічної надійності облік виконується виключно в цілочисельних 64-бітних регістрах із фіксованою комою (*Fixed-Point Q32.32* або *Q48.16*).

Обчислимо ємність і роздільну здатність 64-бітного беззнакового акумулятора `uint64_t`:

```
Max_Value = 2⁶⁴ - 1 = 18446744073709551615
```

Якщо обрати базовий квант енергії `1 LSB = 1 мкДж = 10⁻⁶ Дж`:
- Максимальна накопичена енергія складе:

```
E_max = (2⁶⁴ - 1) · 10⁻⁶ Дж ≈ 1.84467 · 10¹³ Дж = 5.124 · 10⁶ кВт·год (понад 5 мільйонів кВт·год)
```

- Час переповнення при постійному вимірюванні промислового навантаження `100 кВт`:

```
T_overflow = 5.124 · 10⁶ кВт·год / 100 кВт = 51240 годин ≈ 5.85 років
```

Якщо ж застосувати архітектуру з двома зв'язаними регістрами — 64-бітним швидким акумулятором для дробової частини в мікроджоулях та 64-бітним накопичувачем цілих ват-годин (де `1 LSB = 1 Вт·год = 3.6 · 10⁶ Дж`), максимальний вимірюваний обсяг енергії досягає:

```
E_max_2tier = (2⁶⁴ - 1) · 1 Вт·год ≈ 1.84467 · 10¹⁶ кВт·год
```

Час безперервної роботи до переповнення при екстремальному навантаженні `1 ГВт` (`10⁹ Вт`) перевищує 2 мільярди років:

```
T_overflow_2level = 1.84467 · 10¹⁶ кВт·год / 10⁶ кВт ≈ 1.84 · 10¹⁰ годин ≈ 2.1 · 10⁶ років
```

Цілочисельне підсумовування `Acc += ΔE_int` виключає будь-які похибки округлення, гарантуючи нульовий дрейф квантування за весь термін служби приладу.
