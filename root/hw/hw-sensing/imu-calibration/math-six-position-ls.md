# 🧮 Метод найменших квадратів для калібрування шести положень

У статичному тесті шести положень відомим еталоном виступає вектор гравітаційного прискорення Землі `g = 9.80665 м/с²` (або `1.0 g` у нормалізованих одиницях). Коли чутливий елемент акселерометра орієнтують кожною з трьох осей паралельно та антипаралельно вектору тяжіння, формується перевизначена система лінійних алгебраїчних рівнянь. Розв'язання цієї системи за методом найменших квадратів (МНК) дає змогу одночасно обчислити дев'ять елементів матриці корекції (масштабні коефіцієнти та взаємну неортогональність осей) і три компоненти вектора постійного зсуву нуля.

---

### Лінійна модель вимірювань і задача обернення

Пряма модель похибок пов'язує вектор сирих вимірювань `a_raw` (у кодах АЦП або невідкаліброваних одиницях) зі справжнім фізичним вектором прискорення `a_true`:

```
a_raw = M · S · a_true + b + n
```
де:
- `b = [b_x, b_y, b_z]ᵀ` — вектор постійного зсуву нуля (адитивна похибка);
- `S = diag(s_x, s_y, s_z)` — діагональна матриця масштабних коефіцієнтів;
- `M` — верхньотрикутна або повна матриця неортогональності осей (перехресна чутливість);
- `n` — вектор некорельованого гаусового шуму з нульовим середнім `E[n] = 0` та дисперсією `σ²`.

Для компенсації похибок у бортовому контролері застосовують лінійне калібрувальне перетворення:

```
a_cal = K · (a_raw − b)
```
або в розкритій формі через сукупний афінний оператор:

```
a_cal = K · a_raw + b_corr
```
де `K = (M · S)⁻¹` — матриця корекції розмірністю 3×3, а `b_corr = −K · b` — скоригований вектор зміщення.

### Формування системи лінійних рівнянь

Нехай виконано `N = 6` вимірювань у шести ортогональних положеннях у полі тяжіння Землі `g = 1.0`. Для кожного положення `k` (`k = 1, 2, ..., 6`) усереднений вектор сирих показів позначається як `a^(k) = [a_x^(k), a_y^(k), a_z^(k)]ᵀ`, а відповідний еталонний вектор гравітації — як `g^(k) = [g_x^(k), g_y^(k), g_z^(k)]ᵀ`.

Еталонні вектори для шести канонічних положень мають точний вигляд:
1. Положення +Z вгору: `g^(1) = [ 0,  0, +1 ]ᵀ`
2. Положення -Z вгору: `g^(2) = [ 0,  0, -1 ]ᵀ`
3. Положення +Y вгору: `g^(3) = [ 0, +1,  0 ]ᵀ`
4. Положення -Y вгору: `g^(4) = [ 0, -1,  0 ]ᵀ`
5. Положення +X вгору: `g^(5) = [ +1,  0,  0 ]ᵀ`
6. Положення -X вгору: `g^(6) = [ -1,  0,  0 ]ᵀ`

Калібрувальне рівняння для кожного положення `k` записується покомпонентно для кожної осі `i ∈ {x, y, z}`:

```
g_i^(k) = k_ix · a_x^(k) + k_iy · a_y^(k) + k_iz · a_z^(k) + b_corr_i + e_i^(k)
```
де `e_i^(k)` — нев'язка (залишкова похибка апроксимації та шуму).

Це рівняння є лінійним відносно чотирьох невідомих параметрів `θ_i = [k_ix, k_iy, k_iz, b_corr_i]ᵀ` для кожної координатної осі `i`. Оскільки рівняння для осей X, Y та Z мають спільну матрицю плану експерименту, задача розпадається на три незалежні задачі лінійної регресії однакової структури.

Формується матриця плану експерименту `H` розмірністю 6×4:

```
H = [ a_x^(1)  a_y^(1)  a_z^(1)  1 ]
    [ a_x^(2)  a_y^(2)  a_z^(2)  1 ]
    [ a_x^(3)  a_y^(3)  a_z^(3)  1 ]
    [ a_x^(4)  a_y^(4)  a_z^(4)  1 ]
    [ a_x^(5)  a_y^(5)  a_z^(5)  1 ]
    [ a_x^(6)  a_y^(6)  a_z^(6)  1 ]
```

Вектори спостережень для кожної з трьох осей:

```
Y_x = [ g_x^(1), g_x^(2), g_x^(3), g_x^(4), g_x^(5), g_x^(6) ]ᵀ = [  0,  0,  0,  0,  1, -1 ]ᵀ
Y_y = [ g_y^(1), g_y^(2), g_y^(3), g_y^(4), g_y^(5), g_y^(6) ]ᵀ = [  0,  0,  1, -1,  0,  0 ]ᵀ
Y_z = [ g_z^(1), g_z^(2), g_z^(3), g_z^(4), g_z^(5), g_z^(6) ]ᵀ = [  1, -1,  0,  0,  0,  0 ]ᵀ
```

### Аналітичний розв'язок за нормальними рівняннями

Цільова функція методу найменших квадратів для осі `i` мінімізує суму квадратів нев'язок:

```
J(θ_i) = ||Y_i − H · θ_i||² = (Y_i − H · θ_i)ᵀ · (Y_i − H · θ_i)
```

Для знаходження мінімуму обчислюється градієнт за вектором параметрів `θ_i` та прирівнюється до нуля:

```
∂J / ∂θ_i = −2 · Hᵀ · (Y_i − H · θ_i) = 0
Hᵀ · H · θ_i = Hᵀ · Y_i                    [система нормальних рівнянь Гауса-Маркова]
θ_i = (Hᵀ · H)⁻¹ · Hᵀ · Y_i                [аналітичний розв'язок МНК]
```

Оскільки матриця `H` складена з неколінеарних вимірювань у шести просторово рознесених положеннях, матриця Грама `G = Hᵀ · H` розмірністю 4×4 є симетричною, додатно визначеною та строго невиродженою (`det(Hᵀ · H) > 0`).

Після знаходження векторів параметрів `θ_x`, `θ_y`, `θ_z` формуються підсумкові величини:

```
K = [ k_xx  k_xy  k_xz ]
    [ k_yx  k_yy  k_yz ]
    [ k_zx  k_zy  k_zz ]

b_corr = [ b_corr_x, b_corr_y, b_corr_z ]ᵀ
b = −K⁻¹ · b_corr
```

### Аналіз спостережуваності та число обумовленості матриці плану

Математична якість оцінки параметрів за МНК безпосередньо залежить від спектральних властивостей інформаційної матриці `G = Hᵀ · H`.

Сингулярний розклад (SVD) матриці `H = U · Σ · Vᵀ` визначає її власні числа `λ_i` та число обумовленості:

```
cond(H) = σ_max(H) / σ_min(H)
```

Для канонічного тесту 6 ортогональних положень матриця `H` наближається до ідеальної ортогональної структури:

```
Hᵀ · H ≈ [ 2  0  0  0 ]
         [ 0  2  0  0 ]
         [ 0  0  2  0 ]
         [ 0  0  0  6 ]
```

Число обумовленості такої системи становить `cond(H) = √6 / √2 = √3 ≈ 1.732`. Це свідчить про ідеальну числову стійкість: похибки вхідних вимірювань не підсилюються при матричному оберненні.

Якщо ж експеримент обмежити меншою кількістю орієнтацій (наприклад, чотирма положеннями в одній площині XY), стовпець `a_z` у матриці `H` стає лінійно залежним від одиничного стовпця зміщення. Матриця Грама стає сингулярною (`det(Hᵀ · H) = 0`), а похибка неортогональності осі Z перетворюється на принципово неспостережувану величину. Саме тому 6 просторових орієнтацій є мінімально необхідною множиною для повної роздільності 12 параметрів.

### Коваріація оцінок та довірчі інтервали

За теоремою Гауса-Маркова оцінка `θ_i` є незміщеною та має мінімальну дисперсію серед усіх лінійних оцінок. Коваріаційна матриця знайдених коефіцієнтів калібрування дорівнює:

```
Cov(θ_i) = σ_e² · (Hᵀ · H)⁻¹
```
де невідома дисперсія залишків `σ_e²` оцінюється через суму квадратів нев'язок (RSS):

```
RSS_i = ||Y_i − H · θ_i||²
s_e² = RSS_i / (N − P) = RSS_i / (6 − 4) = RSS_i / 2
```
де `N = 6` — кількість спостережень, а `P = 4` — кількість оцінюваних параметрів для однієї осі.

Стандартна похибка визначення масштабного коефіцієнта `k_ii` та зсуву нуля `b_i` обчислюється як корінь із відповідного діагонального елемента коваріаційної матриці:

```
SE(k_ii) = √( s_e² · [(Hᵀ · H)⁻¹]_ii )
```

Це дає змогу автоматично контролювати якість калібрування у виробничих умовах: якщо `SE(k_ii)` перевищує встановлений допуск (наприклад, `0.0005`), процедура маркується як недостовірна (внаслідок випадкового поштовху стенда) і вимагає повторення.

### Алгебраїчне фітування еліпсоїда без точного горизонтування

Якщо калібрувальний стенд не забезпечує прецизійного вирівнювання граней строго по нормалі до гравітаційного вектора, вектор `g^(k)` невідомий у проєкціях на осі стенда. Проте зберігається фундаментальний інваріант: довжина вектора гравітаційного прискорення в будь-якій орієнтації нерухомого тіла тотожно дорівнює `1.0 g`:

```
||a_cal||² = 1.0
||K · (a_raw − b)||² = 1.0
(a_raw − b)ᵀ · Kᵀ · K · (a_raw − b) = 1.0
(a_raw − b)ᵀ · A · (a_raw − b) = 1.0
```
де `A = Kᵀ · K` — симетрична додатно визначена матриця форми еліпсоїда.

Розкриваючи матричний добуток, отримуємо загальне рівняння квадрики (еліпсоїда в тривимірному просторі):

```
vᵀ · A · v + 2 · vᵀ · u + d = 0
```
де `v = [a_x, a_y, a_z]ᵀ`, `u = −A · b`, `d = bᵀ · A · b − 1`.

У розгорнутій скалярній формі це рівняння записується через дев'ять незалежних коефіцієнтів:

```
c₁·a_x² + c₂·a_y² + c₃·a_z² + 2·c₄·a_x·a_y + 2·c₅·a_x·a_z + 2·c₆·a_y·a_z + 2·c₇·a_x + 2·c₈·a_y + 2·c₉·a_z = 1
```

Для масиву з `M ≥ 9` довільних статичних положень формується перевизначена матриця вимірювань `D` розмірністю `M × 9`, де кожен рядок містить квадратичні та лінійні комбінації компонентів прискорення:

```
D_k = [ a_x²  a_y²  a_z²  2·a_x·a_y  2·a_x·a_z  2·a_y·a_z  2·a_x  2·a_y  2·a_z ]
```

Розв'язок за МНК дає вектор параметрів квадрики `c = (Dᵀ · D)⁻¹ · Dᵀ · 1_M`. З вектора `c` відновлюються матриця `A`, вектор `u` та скаляр `d`:

```
A = [ c₁  c₄  c₅ ]
    [ c₄  c₂  c₆ ]
    [ c₅  c₆  c₃ ]

u = [ c₇, c₈, c₉ ]ᵀ
```

Центр еліпсоїда (зсув нуля акселерометра):

```
b = −A⁻¹ · u
```

Матриця масштабу та неортогональності `K` знаходиться за допомогою спектрального розкладу або факторизації Холецького матриці форми `A`. Оскільки `A = Kᵀ · K`, знаходження симетричного квадратного кореня `K = A^(1/2)` або верхньотрикутного розкладу Холецького `K = chol(A)` повністю відновлює матрицю калібрування.

### Числовий приклад розрахунку

Нехай у результаті статичного тесту 6 положень отримано такі середні значення показів триосьового акселерометра (у одиницях `g`):

```
Положення 1 (+Z): a^(1) = [ +0.024, −0.018, +1.042 ]ᵀ
Положення 2 (-Z): a^(2) = [ +0.016, −0.022, −0.968 ]ᵀ
Положення 3 (+Y): a^(3) = [ +0.022, +0.978, +0.038 ]ᵀ
Положення 4 (-Y): a^(4) = [ +0.018, −1.024, +0.036 ]ᵀ
Положення 5 (+X): a^(5) = [ +1.032, −0.020, +0.040 ]ᵀ
Положення 6 (-X): a^(6) = [ −0.988, −0.020, +0.034 ]ᵀ
```

#### Крок 1. Обчислення зсуву нуля за парами протилежних положень

Груба оцінка зміщення нуля прямо випливає з напівсуми відліків для кожної осі:

```
b_x ≈ (a_x^(5) + a_x^(6)) / 2 = (1.032 − 0.988) / 2 = +0.0220 g
b_y ≈ (a_y^(3) + a_y^(4)) / 2 = (0.978 − 1.024) / 2 = −0.0230 g
b_z ≈ (a_z^(1) + a_z^(2)) / 2 = (1.042 − 0.968) / 2 = +0.0370 g
```

#### Крок 2. Обчислення масштабних коефіцієнтів

Масштабний коефіцієнт кожної осі визначається напіврізницею відліків у протилежних орієнтаціях:

```
s_x ≈ (a_x^(5) − a_x^(6)) / 2 = (1.032 − (−0.988)) / 2 = 1.0100
s_y ≈ (a_y^(3) − a_y^(4)) / 2 = (0.978 − (−1.024)) / 2 = 1.0010
s_z ≈ (a_z^(1) − a_z^(2)) / 2 = (1.042 − (−0.968)) / 2 = 1.0050
```

Відповідні діагональні елементи матриці корекції `K`:

```
k_xx ≈ 1 / s_x = 1 / 1.0100 = 0.9901
k_yy ≈ 1 / s_y = 1 / 1.0010 = 0.9990
k_zz ≈ 1 / s_z = 1 / 1.0050 = 0.9950
```

#### Крок 3. Повне МНК-оцінювання з урахуванням неортогональності

Побудова матриці `H` розмірністю 6×4 та розв'язання системи `θ_i = (Hᵀ · H)⁻¹ · Hᵀ · Y_i` дає повну матрицю калібрування:

```
K = [  0.9901   0.0018  −0.0032 ]
    [ −0.0021   0.9990   0.0015 ]
    [  0.0041  −0.0012   0.9950 ]

b = [ +0.0220, −0.0230, +0.0370 ]ᵀ
```

Перевірка калібрувального перетворення на вибірці положення 1:

```
a_raw − b = [ +0.024, −0.018, +1.042 ]ᵀ − [ +0.022, −0.023, +0.037 ]ᵀ
          = [ +0.002, +0.005, +1.005 ]ᵀ

a_cal = K · (a_raw − b)
      = [ 0.9901·0.002 + 0.0018·0.005 − 0.0032·1.005 ]
        [ −0.0021·0.002 + 0.9990·0.005 + 0.0015·1.005 ]
        [ 0.0041·0.002 − 0.0012·0.005 + 0.9950·1.005 ]
      = [ −0.0012, +0.0065, +1.0000 ]ᵀ

||a_cal|| = √( (−0.0012)² + (+0.0065)² + (1.0000)² ) = 1.00002 g
```

Похибка вимірювання модуля прискорення знизилася з `4.2%` у сирих даних до `0.002%` після застосування МНК-калібрування.
