# 🧮 П'єзорезистивний ефект і тензочутливість моста на кремнієвій мембрані

Коли на кремнієву мембрану тисне повітря, механічний прогин створює в ній внутрішні механічні напруження, а ті змінюють питомий електричний опір напівпровідника. Щоб спроєктувати або точно змоделювати MEMS-давач тиску, інженеру необхідно пов'язати тиск газу в паскалях із вихідною напругою вимірювального моста в мілівольтах. Нижче наведено послідовне математичне виведення п'єзорезистивного тензора в монокристалічному кремнії, розподілу напружень у круглій та квадратній затисненій мембрані та вихідного диференціального сигналу моста Уїтстона з урахуванням температурних коефіцієнтів.

### П'єзорезистивний ефект у кристалічній решітці кремнію

П'єзорезистивний ефект (від грецького *piezein* — тиснути та латинського *resistere* — протистояти) у напівпровідниках полягає у зміні форми енергетичних долин зони провідності або валентної зони під дією одновісної чи двовісної деформації. Ця деформація знімає виродження енергетичних зон і перерозподіляє носії заряду (дірки або електрони) між долинами з різною ефективною масою й рухливістю `μ`.

У загальному тривимірному випадку зв'язок між відносною зміною тензора питомого опору `Δρ / ρ₀` та тензором механічних напружень `σ` описується матрицею п'єзорезистивних коефіцієнтів четвертого рангу `π[i,j]`:

```
[ Δρ₁ / ρ₀ ]   [ π₁₁  π₁₂  π₁₂   0    0    0  ]   [ σ₁ ]
[ Δρ₂ / ρ₀ ]   [ π₁₂  π₁₁  π₁₂   0    0    0  ]   [ σ₂ ]
[ Δρ₃ / ρ₀ ] = [ π₁₂  π₁₂  π₁₁   0    0    0  ] · [ σ₃ ]
[ Δρ₄ / ρ₀ ]   [  0    0    0   π₄₄   0    0  ]   [ σ₄ ]
[ Δρ₅ / ρ₀ ]   [  0    0    0    0   π₄₄   0  ]   [ σ₅ ]
[ Δρ₆ / ρ₀ ]   [  0    0    0    0    0   π₄₄ ]   [ σ₆ ]
```

Для кубічної кристалічної симетрії кремнію (група алмазу `Fd3̄m`) незалежними є лише три коефіцієнти: `π₁₁` (поздовжній коефіцієнт уздовж головної кристалографічної осі `<100>`), `π₁₂` (поперечний коефіцієнт) та `π₄₄` (зсувний коефіцієнт).

У кремнії p-типу (легованому бором) зсувний коефіцієнт `π₄₄` домінує над усіма іншими майже на порядок:
- `π₁₁ ≈ +6.6 × 10⁻¹¹ Па⁻¹`
- `π₁₂ ≈ -1.1 × 10⁻¹¹ Па⁻¹`
- `π₄₄ ≈ +138.1 × 10⁻¹¹ Па⁻¹` (за кімнатної температури `T = 300 K` та концентрації домішки `N_A ≈ 10¹⁸ см⁻³`).

### Орієнтація п'єзорезисторів на пластині (100)

Кремнієві MEMS-пластини зазвичай мають орієнтацію поверхні `(100)`. Щоб отримати максимальну чутливість, поздовжні осі резисторів спрямовують уздовж кристалографічного напрямку `[110]`, тобто під кутом 45° до головних осей кристала.

Шляхом повороту системи координат на 45° у площині `(100)` отримуємо ефективні поздовжній `π_l` та поперечний `π_t` коефіцієнти для резистора, орієнтованого вздовж осі `[110]`:

```
π_l = (π₁₁ + π₁₂ + π₄₄) / 2      [поворот координат для поздовжнього коефіцієнта]
π_t = (π₁₁ + π₁₂ - π₄₄) / 2      [поворот координат для поперечного коефіцієнта]
```

Підставивши числові значення для p-кремнію:

```
π_l = (+6.6 - 1.1 + 138.1) / 2 = +71.8 × 10⁻¹¹ Па⁻¹  [обчислення поздовжнього коефіцієнта]
π_t = (+6.6 - 1.1 - 138.1) / 2 = -66.3 × 10⁻¹¹ Па⁻¹  [обчислення поперечного коефіцієнта]
```

Звідси бачимо ключовий висновок фізики MEMS-давача: поздовжній і поперечний коефіцієнти мають **майже однакову амплітуду, але протилежні знаки** (`π_l ≈ -π_t ≈ +70 × 10⁻¹¹ Па⁻¹`). Це дозволяє розмістити на одній мембрані два поздовжніх і два поперечних резистори, які за однакового механічного розтягу змінюватимуть опір у протилежні боки: `+ΔR` та `-ΔR`.

Відносна зміна опору резистора під дією плоского двовісного напруження `(σ_l, σ_t)` виражається лінійною комбінацією:

```
ΔR / R₀ = π_l · σ_l + π_t · σ_t   [рівняння п'єзоопору в площині]
```

де `σ_l` — механічне напруження вздовж напрямку протікання струму, а `σ_t` — напруження в перпендикулярному напрямку в площині мембрани.

### Механічні напруження в пружній затисненій мембрані

Розглянемо тонку кремнієву мембрану радіуса `a` (або сторони квадрата `2a`) з товщиною `h`, затиснену по краях (`h ≪ a`), на яку діє рівномірний перепад тиску `ΔP = P_зовнішній - P_порожнина`.

Згідно з теорією пластин Кірхгофа–Лява для малих прогинів (коли максимальний прогин у центрі `w₀` не перевищує `0.2 · h`), напруження на верхній поверхні мембрани визначаються другим похідними функції прогину `w(r)`:

```
σ_r(r) = - [3 · ΔP · a² / (4 · h²)] · [(1 + ν) - (3 + ν) · (r / a)²]   [радіальне напруження на радіусі r]
σ_θ(r) = - [3 · ΔP · a² / (4 · h²)] · [(1 + ν) - (1 + 3ν) · (r / a)²]  [тангенціальне напруження на радіусі r]
```

де `ν` — коефіцієнт Пуассона для кремнію (`ν ≈ 0.28`), `r` — радіальна відстань від центру мембрани до краю (`0 ≤ r ≤ a`).

Проаналізуємо напруження у двох критичних зонах мембрани:

1. **У центрі мембрани (`r = 0`):**
```
σ_r(0) = σ_θ(0) = - (3/4) · (1 + ν) · ΔP · (a / h)²   [стискаюче напруження в центрі]
```
На верхній поверхні виникає двовісне стискання (`σ < 0`), а амплітуда напруження пропорційна `(a/h)²`.

2. **На затисненому краю мембрани (`r = a`):**
```
σ_r(a) = + (3/2) · ΔP · (a / h)²     [радіальне розтягуюче напруження на краю]
σ_θ(a) = + (3/2) · ν · ΔP · (a / h)² [тангенціальне напруження на краю]
```

Підставивши `ν = 0.28`:
```
σ_r(a) = +1.50 · ΔP · (a / h)²   [радіальний розтяг на затисненому краю]
σ_θ(a) = +0.42 · ΔP · (a / h)²   [тангенціальний розтяг на затисненому краю]
```

Радіальне напруження `σ_r` на краю мембрани вдвічі більше за напруження в центрі й має знак розтягу (`σ_r > 0`). Саме тому всі чотири п'єзорезистори завжди інтегрують **на краях мембрани**, де механічна деформація та чутливість є максимальними.

### Розрахунок чутливості моста Уїтстона

На краях мембрани формують чотири резистори:
- Резистори `R₁` та `R₄` розташовані так, що струм тече радіально (вздовж `σ_r`), тому `σ_l = σ_r`, `σ_t = σ_θ`.
- Резистори `R₂` та `R₃` розташовані так, що струм тече тангенціально (вздовж `σ_θ`), тому `σ_l = σ_θ`, `σ_t = σ_r`.

Відносні зміни опорів п'єзорезисторів:

```
ΔR₁ / R₀
= π_l · σ_r(a) + π_t · σ_θ(a)          [підстановка напружень у поздовжній резистор]
= [1.50 · π_l + 0.42 · π_t] · ΔP · (a / h)² [групування геометричного фактора]

ΔR₂ / R₀
= π_l · σ_θ(a) + π_t · σ_r(a)          [підстановка напружень у поперечний резистор]
= [0.42 · π_l + 1.50 · π_t] · ΔP · (a / h)² [групування геометричного фактора]
```

Оскільки `π_t ≈ -π_l`:
```
ΔR₁ / R₀ ≈ [1.50 - 0.42] · π_l · ΔP · (a / h)² = +1.08 · π_l · ΔP · (a / h)²  [зміна опору плеча 1]
ΔR₂ / R₀ ≈ [0.42 - 1.50] · π_l · ΔP · (a / h)² = -1.08 · π_l · ΔP · (a / h)²  [зміна опору плеча 2]
```

Позначивши `ΔR / R₀ = 1.08 · π_l · ΔP · (a / h)²`, отримуємо ідеальну диференціальну пару:
- `R₁ = R₄ = R₀ + ΔR`
- `R₂ = R₃ = R₀ - ΔR`

Диференціальна вихідна напруга моста Уїтстона, підключеного до напруги живлення `V_bridge`:

```
V_diff
= V(+) - V(-)                                          [означення різниці потенціалів діагоналі]
= V_bridge · [ R₄ / (R₁ + R₄) - R₃ / (R₂ + R₃) ]       [дільники напруги в двох плечах моста]
= V_bridge · [ (R₀ + ΔR) / (2R₀) - (R₀ - ΔR) / (2R₀) ] [підстановка значень плечей моста]
= V_bridge · (ΔR / R₀)                                 [спрощення: скорочення базового опору R₀]
= V_bridge · 1.08 · π_l · (a / h)² · ΔP                [підстановка залежності від тиску ΔP]
```

Отже, **вихідна напруга моста прямо пропорційна вимірюваному тиску `ΔP` та квадрату геометричного відношення `(a/h)²`**.

### Числовий приклад розрахунку MEMS-структури

Візьмемо типові параметри кристала сучасного барометра:
- Сторона мембрани `2a = 400 мкм` (`a = 200 мкм = 2 × 10⁻⁴ м`).
- Товщина кремнієвої мембрани `h = 4 мкм = 4 × 10⁻⁶ м`.
- Геометричний фактор: `(a / h)² = (200 / 4)² = 50² = 2500`.
- Поздовжній коефіцієнт: `π_l = 70 × 10⁻¹¹ Па⁻¹`.
- Живлення моста: `V_bridge = 1.8 В`.
- Зміна атмосферного тиску на рівні моря: `ΔP = 100 кПа = 10⁵ Па`.

Обчислимо відносну зміну опору й вихідну напругу моста:

```
ΔR / R₀
= 1.08 · π_l · (a / h)² · ΔP                [теоретична формула тензочутливості моста]
= 1.08 · (70 × 10⁻¹¹ Па⁻¹) · 2500 · 10⁵ Па   [підстановка числових параметрів структури]
= 1.08 · 70 × 10⁻¹¹ · 2.5 × 10⁸              [перемноження геометричного фактора й тиску]
= 0.0189                                    [обчислення коефіцієнта: відносний приріст 1.89 %]
```

Вихідний диференціальний сигнал за тиску 100 кПа:
```
V_diff = 1.8 В · 0.0189 = 34.02 мВ           [вихідний сигнал за повного атмосферного тиску]
```

Чутливість датчика до тиску:
```
S = V_diff / (V_bridge · ΔP) = 0.0189 / 1000 гПа = 18.9 мкВ / (В · гПа)   [питома чутливість моста]
```

За напруги живлення `1.8 В` вихідний сигнал змінюється на:
```
ΔV_diff / ΔP = 34.02 мВ / 1000 гПа = 34.02 мкВ / гПа = 0.3402 мкВ / Па   [вихідний відгук на 1 Па]
```

Щоб виявити зміну висоти на **1 метр** на рівні моря (`ΔP ≈ 12 Па`), вимірювальний підсилювач та АЦП мають впевнено розрізняти напругу:
```
ΔV_1m = 12 Па · 0.3402 мкВ/Па = 4.08 мкВ     [напруга перепаду висоти на 1 метр]
```
А для роздільної здатності в **5 см** (`ΔP ≈ 0.6 Па`):
```
ΔV_5cm = 0.6 Па · 0.3402 мкВ/Па = 0.204 мкВ = 204 нВ   [напруга перепаду висоти на 5 сантиметрів]
```
Саме тому на кристалі поруч із мостом обов'язково встановлюють малошумний підсилювач із чопперною стабілізацією та 24-бітний сигма-дельта АЦП із шумовою щільністю менше `10 нВ / √Гц`.

### Температурна залежність п'єзорезистивного коефіцієнта

Опір п'єзорезисторів та їхня чутливість сильно залежать від температури кристала через два конкуруючі механізми:
1. **TCR (Temperature Coefficient of Resistance)** — температурний коефіцієнт базового опору `R₀(T)`:
```
R₀(T) = R₀(T_ref) · [ 1 + α_TCR · (T - T_ref) + β_TCR · (T - T_ref)² ]   [термічний поліном опору]
```
Для помірно легованого кремнію `α_TCR ≈ +0.15 ... +0.25 % / °C`.

2. **TCP (Temperature Coefficient of Piezoresistance)** — температурний коефіцієнт тензочутливості:
```
π_l(T) = π_l(T_ref) · [ 1 + α_TCP · (T - T_ref) ]   [температурне падіння п'єзокоефіцієнта]
```
З підвищенням температури тепловий рух носіїв розмиває різницю енергій між долинами, тому чутливість падає: `α_TCP ≈ -0.20 ... -0.27 % / °C`.

Якщо температура підніметься на 20°C без цифрової корекції, вихідний сигнал впаде приблизно на 5%, що спричинить фатальну похибку барометричної висоти в понад 400 метрів. Це математично доводить, чому сучасний MEMS-барометр неможливий без прецизійного інтегрованого термометра та поліноміальної матриці компенсації в DSP.
