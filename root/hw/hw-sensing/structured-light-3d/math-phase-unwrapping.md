# 🧮 Фазовий зсув і багаточастотне розгортання фази

Точне вимірювання рельєфу методом синусоїдальних смуг перетворює оптичну інтенсивність кожного пікселя на фазовий кут. Це дає змогу вилучити неперервну координату точки на площині проектора з роздільністю, що значно перевищує дискретний крок піксельної матриці камери. Алгоритм розпадається на два строгі етапи: вилучення загорнутої фази з комбінації кадрів зі зсувом періоду та відновлення повної абсолютної фази через часове розгортання.

### Математична модель N-крокового фазового зсуву

Проектор формує на сцені серію з `N` періодичних синусоїдальних патернів. Інтенсивність світла в точці сенсора `(x, y)` для `k`-го кадру (`k = 0, 1, ..., N - 1`) описується трипараметричною моделлю:

```
I_k(x, y) = A(x, y) + B(x, y) · cos( φ(x, y) + δ_k )

A(x, y) — фонова фотометрична складова (постійне зміщення, зовнішнє освітлення)
B(x, y) — амплітуда модуляції (контраст смуг, що залежить від альбедо поверхні)
φ(x, y) — шукана загорнута фаза рельєфу в діапазоні [-π, +π)
δ_k     — калібрований фазовий зсув: δ_k = 2π·k / N
```

Модель містить три невідомі величини для кожного пікселя: `A(x, y)`, `B(x, y)` та `φ(x, y)`. Тому для однозначного визначення фази мінімально необхідна кількість кадрів дорівнює `N = 3`.

### Порівняння 3-крокового та 4-крокового виведення

Для мінімального випадку `N = 3` фазові зсуви становлять `δ_0 = -2π/3`, `δ_1 = 0`, `δ_2 = +2π/3`. Фаза обчислюється як:

```
φ(x, y) = atan2( √3 · (I_0 - I_2), 2·I_1 - I_0 - I_2 )
```

Хоча 3-кроковий алгоритм вимагає найменшої кількості кадрів і забезпечує максимальну швидкість зйомки, він надзвичайно чутливий до шумів сенсора та неідеальності калібрування зсувів.

Тому в метрології стандартом став 4-кроковий фазовий зсув (`N = 4`), де фазові кроки становлять `δ_0 = 0`, `δ_1 = π/2`, `δ_2 = π`, `δ_3 = 3π/2`. Запишемо інтенсивність для кожного з чотирьох вимірів:

```
I_0 = A + B · cos(φ + 0)      = A + B · cos(φ)
I_1 = A + B · cos(φ + π/2)    = A - B · sin(φ)
I_2 = A + B · cos(φ + π)      = A - B · cos(φ)
I_3 = A + B · cos(φ + 3π/2)   = A + B · sin(φ)
```

Знайдемо попарні різниці протифазних кадрів:

```
I_0 - I_2
= (A + B·cos(φ)) - (A - B·cos(φ))   [віднімання кадру 2 від кадру 0]
= 2·B · cos(φ)                       [фонова складова A повністю скорочується]

I_3 - I_1
= (A + B·sin(φ)) - (A - B·sin(φ))   [віднімання кадру 1 від кадру 3]
= 2·B · sin(φ)                       [фонова складова A повністю скорочується]
```

Поділивши другу різницю на першу, отримуємо тангенс шуканої фази:

```
(I_3 - I_1) / (I_0 - I_2)
= (2·B · sin(φ)) / (2·B · cos(φ))   [підстановка виведених різниць]
= sin(φ) / cos(φ)                   [скорочення амплітуди 2·B]
= tan(φ)                             [означення тангенса]
```

Для коректного відновлення знака кута у всіх чотирьох квадрантах тригонометричного кола в межах `[-π, +π)` використовують функцію двох аргументів `atan2`:

```
φ(x, y) = atan2( I_3 - I_1, I_0 - I_2 )
```

Амплітуда модуляції `B(x, y)` та фонова яскравість `A(x, y)` обчислюються як:

```
B(x, y) = 0.5 · √[ (I_0 - I_2)² + (I_3 - I_1)² ]
A(x, y) = 0.25 · ( I_0 + I_1 + I_2 + I_3 )
```

Величина `B(x, y)` є ключовим індикатором достовірності вимірювання: у зонах глибоких тіней, оклюзій або на абсолютно чорних матеріалах `B(x, y) → 0`. Порогова фільтрація `B(x, y) > B_min` відсікає всі недостовірні пікселі до початку тріангуляції.

### Стійкість до помилок зсуву: 5-кроковий алгоритм Харіхарана

Якщо проектор або механічний фазообертач має систематичну похибку фазового кроку (замість точного `π/2` зсув становить `π/2 + ε`), 4-кроковий метод створює пульсацію похибки подвоєної частоти `2φ`. Для придушення цієї похибки застосовують 5-кроковий алгоритм Харіхарана (*Hariharan algorithm*), де зсуви становлять `-π, -π/2, 0, +π/2, +π`:

```
φ(x, y) = atan2( 2 · (I_1 - I_3), 2·I_2 - I_0 - I_4 )
```

Алгоритм Харіхарана повністю компенсує лінійну похибку фазового зсуву першого порядку за рахунок симетрії п'яти точок відліку.

### Узагальнений N-кроковий алгоритм та оцінка шуму

Для довільного числа кроків `N ≥ 3` фаза виводиться через ортогональні суми дискретного перетворення Фур'є:

```
S(x, y) = - ∑ [ I_k(x, y) · sin(δ_k) ]   для k = 0 ... N - 1
C(x, y) =   ∑ [ I_k(x, y) · cos(δ_k) ]   для k = 0 ... N - 1

φ(x, y) = atan2( S(x, y), C(x, y) )
B(x, y) = (2 / N) · √[ S(x, y)² + C(x, y)² ]
```

Якщо кожен піксель сенсора має незалежний гаусівський шум інтенсивності з дисперсією `σ_I²`, дисперсія відновленої фази `σ_φ²` становить:

```
σ_φ = σ_I / ( B · √(N / 2) )
```

Звідси випливає фундаментальний висновок: збільшення кількості кроків `N` зменшує шум фази пропорційно `1 / √N`, а висока амплітуда модуляції `B` прямо пригнічує оптичні похибки.

### Нелінійність проектора (гамма-спотворення)

Реальні комерційні проектори мають нелінійну передавальну характеристику яскравості `I_out = I_in^γ` (типово `γ ≈ 2.2`). Ця нелінійність генерує вищі гармоніки в проектованому синусоїдальному сигналі:

```
I(x) = A + B·cos(φ) + c_2·cos(2φ) + c_3·cos(3φ) + ...
```

Для 4-крокового фазового зсуву 2-га та 3-тя гармоніки створюють періодичну пульсацію похибки фази частоти `4φ`:

```
Δφ(x) ≈ (c_3 / B) · sin(4φ)
```

Ця похибка усувається або попереднім апаратним калібруванням таблиці корекції гами (LUT), або збільшенням кількості кроків до `N ≥ 5`, що повністю пригнічує гармоніки до порядку `N - 2`.

### Багаточастотне часове розгортання фази (Temporal Phase Unwrapping)

Отримана функція `φ(x, y)` є **загорнутою** (*wrapped*): її значення обмежені проміжком `[-π, +π)` та містять розриви величиною `2π` на кожному періоді смуги. Справжня **абсолютна неперервна фаза** `Φ(x, y)` пов'язана із загорнутою рівнянням:

```
Φ(x, y) = φ(x, y) + 2π · k(x, y)

k(x, y) — цілий номер періоду смуги (fringe order), k ∈ {0, 1, ..., N_strip - 1}
```

Для однозначного знаходження `k(x, y)` для кожної точки без аналізу сусідніх пікселів (що критично при розривах поверхонь) застосовують ієрархію з двох або трьох просторових частот.

Нехай проектор випромінює дві серії смуг:
1. **Низька частота (опорна)**: довжина хвилі `λ_1 = W` (рівно один період на всю ширину кадру `W`). Оскільки період один, розривів фази немає, і загорнута фаза збігається з абсолютною: `Φ_1(x, y) = φ_1(x, y)`.
2. **Висока частота**: довжина хвилі `λ_2 = W / N_f` (патерн містить `N_f` періодів, наприклад `N_f = 16` або `32`). Вона забезпечує високу просторову роздільність, але має `N_f` періодів невизначеності.

Оскільки абсолютна фаза зростає лінійно з координатою проектора, співвідношення між фазами визначається відношенням довжин хвиль:

```
Φ_2(x, y) = (λ_1 / λ_2) · Φ_1(x, y) = N_f · Φ_1(x, y)
```

Підставляючи вираз для загорнутої фази високої частоти `Φ_2 = φ_2 + 2π·k`, отримуємо точне значення цілого порядку `k(x, y)`:

```
N_f · Φ_1(x, y) = φ_2(x, y) + 2π · k(x, y)
k(x, y) = round( ( N_f · Φ_1(x, y) - φ_2(x, y) ) / (2π) )
```

Операція округлення `round()` повністю пригнічує шум низькочастотної фази `Φ_1`, якщо сумарна фазова похибка не перевищує половини періоду:

```
| N_f · ΔΦ_1 - Δφ_2 | < π   ⇒   | ΔΦ_1 | < π / N_f
```

Після знаходження `k(x, y)` абсолютна фаза високої частоти відновлюється за формулою `Φ(x, y) = φ_2(x, y) + 2π · k(x, y)`.

### Гетеродинне двочастотне розгортання (Dual-Frequency Heterodyne)

Якщо коефіцієнт масштабування `N_f` надто великий (наприклад, 64 або 128 смуг), умова `|ΔΦ_1| < π / N_f` порушується шумом сенсора. Тоді застосовують **гетеродинний метод** (від грецьких *heteros* — інший та *dynamis* — сила).

Проектують дві високі частоти з близькими періодами `λ_1` та `λ_2` (наприклад, `N_1 = 30` та `N_2 = 31` періодів). Їхня різницева синтетична довжина хвилі (частота биття) дорівнює:

```
Λ_12 = ( λ_1 · λ_2 ) / | λ_1 - λ_2 |
```

Оскільки різниця кількостей періодів дорівнює `|N_2 - N_1| = 1`, синтетична фаза `Φ_12(x, y) = φ_1(x, y) - φ_2(x, y)` має рівно один період на весь кадр і не потребує розгортання. Далі за синтетичною фазою розгортають фазу `φ_1`, а за нею — ще вищу частоту третього ступеня.

### Перетворення абсолютної фази на глибину Z

Знаючи абсолютну фазу `Φ(x, y)` на матриці камери та опорну фазу `Φ_0(x, y)`, зняту на плоскій калібрувальній площині на відстані `Z_0`, різниця фаз `ΔΦ(x, y) = Φ(x, y) - Φ_0(x, y)` перераховується у фізичне відхилення глибини `ΔZ(x, y)`:

```
ΔZ(x, y) = ( Z_0 · ΔΦ(x, y) ) / ( 2π · f_0 · ( B / p_x ) + ΔΦ(x, y) )

Z_0 — відстань до опорної площини (мм)
B   — базова лінія між центрами проектора й камери (мм)
f_0 — просторова частота смуг на опорній площині (1/мм)
p_x — розмір пікселя сенсора (мм)
```

Якщо ж система повністю відкалібрована у стереоформаті, абсолютна фаза `Φ(x, y)` безпосередньо дає горизонтальну субпіксельну координату проектора `u_p = (Φ(x, y) / (2π · N_f)) · W_proj`. Перетин променя камери, що проходить крізь піксель `(u_c, v_c)`, із променем проектора `(u_p, v_p)` у тривимірному просторі визначає шукані декартові координати точки `P(X, Y, Z)` методом найменших квадратів.
