# Квадратура

<preknowlist>
- [Оптичний інкрементний енкодер](root:hw-sensing/optical-incremental-encoder) — формування імпульсів за допомогою щілинного диска та базова геометрія зміщення каналів.
- [Датчик Холла](root:hw-sensing/hall-sensor) — вимірювання магнітного поля для безконтактного зчитування полюсів.
- [Тригер Шмітта](root:hw-digital/threshold-schmitt) — гістерезис для формування крутих логічних фронтів із зашумлених аналогових сигналів.
</preknowlist>

Сервопривід утримує руку промислового маніпулятора в заданій точці простору. Вал електродвигуна не обертається, але під дією сили тяжіння та пружності редуктора постійно зазнає мікроскопічних коливань біля цільового кута. Якщо первинний давач положення видає лише один імпульсний сигнал, кожен перетин риски оптичного диска викликає спрацьовування лічильника подій: коливання вала вперед-назад на межі однієї щілини за кілька секунд накопичать тисячі хибних імпульсів, і система позиціонування помилково вирішить, що вісь повернулася на десятки повних обертів. Окрім того, поодинокий сигнал фізично не містить інформації про знак переміщення — чи рухається вісь за годинниковою стрілкою, чи проти неї. Щоб усунути хибне накопичення кроків при вібрації, миттєво визначати напрям руху та учетверити роздільну здатність вимірювання без ускладнення механічного растра, формують пару взаємно зміщених сигналів — **квадратуру** (від лат. *quadratus* — квадратний, поділений на чотири частини, оскільки повний період коливання розбивається на чотири дискретні чверті).

## Геометрія та фізика 90-градусного фазового зсуву

Квадратурний сигнал складається з двох періодичних каналів — каналу A та каналу B, які мають ідентичний період повторення, але просторово або фазово зміщені один відносно одного на 90° електричних (`π/2` радіана, або рівно на чверть повного періоду коливання).

Зв'язок між механічним кутом повороту вала `θ_mech` та електричним кутом сигналу `θ_elec` визначається кількістю періодичних структур `N` на повному колі:

```
θ_elec = N · θ_mech
```

Якщо оптичний кодовий диск містить `N = 1024` риски на повний оберт (360° механічних), то одному механічному оберту відповідає `1024 · 360° = 368640°` електричних. Відповідно, фазовий зсув на 90° електричних відповідає механічному кутовому зсуву між сенсорами на кут:

```
Δθ_mech = 360° / (4 · N)
        = 360° / 4096          [підстановка кількості ліній N = 1024]
        ≈ 0.08789°             [механічний кутовий зсув між каналами A і B]
```

Фізична реалізація цього зміщення базується на двох фундаментальних технологіях первинного перетворення: оптичній та магнітній.

```
+-------------------------------------------------------------------------+
|                  ОПТИЧНИЙ ТА МАГНІТНИЙ СПОСОБИ ФОРМУВАННЯ               |
+-------------------------------------------------------------------------+
| Оптика: Растровий диск + Маска зсуву     Магнетизм: Кільце N-S + Холл  |
|                                                                         |
|      Світлодіод                                      Кільце N-S         |
|          ↓                                          [ N ][ S ][ N ]     |
|   | | | | | | | Диск (крок p)                              ↓            |
|   | | | | | | |                                  +----+         +----+  |
|   | |   | |   | Маска (A і B: p/4)               | H_A| (λ/4)   | H_B|  |
|    ↓     ↓                                       +----+         +----+  |
|  [PD_A] [PD_B]  Фотодіоди                          ↓              ↓     |
|    ↓     ↓                                      sin(θ)         cos(θ)   |
|   Канал A/B: sin(θ) / cos(θ)                       ↓              ↓     |
|    ↓     ↓                                     Компаратор з гістерезисом|
|   Компаратори (тригери Шмітта)                     ↓              ↓     |
|    ↓     ↓                                      Прямокутні сигнали A/B  |
|   Прямокутні сигнали A/B (90° e)               (Фазовий зсув 90° e)     |
+-------------------------------------------------------------------------+
```

### Оптичний растровий метод

В оптичному енкодері скляний або металевий диск містить кодову доріжку з непрозорих хромованих штрихів і прозорих щілин з постійним просторовим кроком `p` (англ. *pitch*). Поруч із рухомим кодовим диском розміщують нерухому пластину — індексну маску (англ. *reticle* або *mask*). На масці нанесено дві окремі групи прозорих щілин з таким самим кроком `p`. Перша група щілин розташована перед фотодіодом каналу A, а друга — перед фотодіодом каналу B.

Просторове зміщення `Δx` між цими двома групами щілин витримується з мікронною точністю за геометричним правилом:

```
Δx = (k + 1/4) · p
```

де `k` — ціле число (`k ∈ ℤ`).

Коли вал обертається, перекриття штрихів рухомого диска та нерухомої маски модулює інтенсивність світлового потоку `Φ(θ)`, що падає на фотодіоди. Унаслідок геометричного перекриття щілин та дифракційних ефектів залежність світлового потоку від кута повороту набуває квазісинусоїдальної форми. Фотодіоди працюють у фотогенераторному або зворотно зміщеному фотодіодному режимі. Світловий потік генерує первинні фотоструми:

```
I_A(θ) = I_0 + I_m · sin(θ_elec)
I_B(θ) = I_0 + I_m · sin(θ_elec + π/2) = I_0 + I_m · cos(θ_elec)
```

де `I_0` — постійний фоновий струм зміщення, `I_m` — амплітуда модуляції фотоструму.

Фотоструми мають малу амплітуду (від одиниць до сотень мікроамперів) і високий вихідний імпеданс. Для перетворення їх на напругу застосовують трансімпедансні підсилювачі (від лат. *trans* — крізь та *impedire* — перешкоджати) на прецизійних операційних підсилювачах:

```
V_A = -I_A · R_f
V_B = -I_B · R_f
```

де `R_f` — резистор зворотного зв'язку (зазвичай 10–100 кОм). Щоб запобігти високочастотному самозбудженню підсилювача через власну бар'єрну ємність p-n переходу фотодіода `C_j`, паралельно до `R_f` встановлюють коригувальний конденсатор:

```
C_f = √(C_j / (2π · R_f · GBW))
```

де `GBW` — добуток смуги пропускання на коефіцієнт підсилення (англ. *Gain Bandwidth Product*) операційного підсилювача.

Отримані аналогові напруги надходять на диференційні компаратори з інтегрованими тригерами Шмітта (від грец. *ὑστέρησις* — відставання, запізнення). Гістерезис компаратора `V_hys` відсікає високочастотний оптичний шум на схилах синусоїди та формує прямокутні логічні рівні 0 і 1:

```
A = sign(sin(θ_elec))
B = sign(cos(θ_elec))
```

Логічний рівень каналу A перемикається в моменти переходів синуса через нуль (`0`, `π`, `2π`), а каналу B — у моменти переходів косинуса (`π/2`, `3π/2`), забезпечуючи ідеальний квадратурний фазовий зсув на 90° електричних.

### Магнітний растровий метод

У магнітних квадратурних енкодерах диск замінено на полімерне або металеве кільце, намагнічене чергованими парами магнітних полюсів N (північ) та S (південь) з просторовим кроком полюсної пари `λ`. Магнітна індукція на поверхні кільця розподілена вздовж периметра за синусоїдальним законом:

```
B_z(x) = B_max · sin(2π · x / λ)
```

Над кільцем розміщують два інтегровані датчики Холла або чутливі магніторезистивні елементи (AMR — анізотропні, GMR — гігантські або TMR — тунельні магніторезистори), рознесені вздовж кола на відстань `λ/4` (чверть магнітного періоду). За ефектом Холла (від лат. *effectus* — дія, на честь Едвіна Холла) рухомі носії заряду у напівпровіднику під дією сили Лоренца відхиляються до бічних граней, створюючи холлівську напругу:

```
V_H = (R_H / d) · I_bias · B_z
```

Оскільки сенсори рознесені на `λ/4`, вихідний сигнал першого сенсора пропорційний `sin(θ_elec)`, а другого — `cos(θ_elec)`. Вбудована диференційна схема підсилення та компаратори формують на виході стандартну пару прямокутних сигналів A і B.

*Формування квадратурного сигналу. Ліворуч: оптичний растровий диск пропускає промінь крізь маску зі зміщенням на чверть кроку p/4, створюючи на фотодіодах ортогональні струми. Праворуч: багатополюсне магнітне кільце з чергуванням полюсів N-S та парою датчиків Холла зі зсувом λ/4. Унизу: сформовані прямокутні сигнали каналів A та B, зсунуті на 90° електричних (чверть періоду).*

> 🔧 **Навіщо це.** Оптичні квадратурні енкодери забезпечують максимальну дискретність (до десятків тисяч ліній на оберт) завдяки тонким хромованим маскам на склі, проте чутливі до пилу, конденсату та ударних навантажень. Магнітні квадратурні енкодери мають дещо меншу роздільність растра, але повністю захищені від мастила, бруду та оптичного затінення, що робить їх стандартом у тягових приводах і робототехніці.

## Простір станів, код Грея та кратність декодування

У будь-який момент часу пара логічних рівнів `(A, B)` утворює 2-бітний двійковий вектор стану `S = (A << 1) | B`, який набуває одного з чотирьох можливих значень: `00₂ (0)`, `01₂ (1)`, `11₂ (3)` або `10₂ (2)`.

При безперервному обертанні вала вектор стану змінюється суворо циклічно:

```
Пряме обертання (CW, за годинниковою):     00 -> 01 -> 11 -> 10 -> 00 ...
Зворотне обертання (CCW, проти годинникової): 00 -> 10 -> 11 -> 01 -> 00 ...
```

Ця послідовність є циклічним **кодом Грея** (англ. *reflected binary code* або *Gray code*, на честь дослідника Френка Грея). Фундаментальна властивість коду Грея полягає в тому, що при будь-якому одиничному переході між сусідніми квадрантами **змінюється рівно один біт** (відстань Геммінга `d = 1`).

```
+-----------------------------------------------------------------------+
|                    ФАЗОВІ СЕКТОРИ ОДНОГО ПЕРІОДУ                      |
+----------+---------------+-----------+-----------+--------------------+
| Сектор   | Кутовий діапазон | Канал A   | Канал B   | Стан (A, B)        |
+----------+---------------+-----------+-----------+--------------------+
| 0        | [0°, 90°)     | 0         | 0         | 00₂ (0)            |
| 1        | [90°, 180°)   | 0         | 1         | 01₂ (1)            |
| 2        | [180°, 270°)  | 1         | 1         | 11₂ (3)            |
| 3        | [270°, 360°)  | 1         | 0         | 10₂ (2)            |
+----------+---------------+-----------+-----------+--------------------+
```

Завдяки зсуву на 90° електричних фронти каналів A та B рознесені в часі. За нормального руху вала між перемиканням каналу A та перемиканням каналу B завжди існує часовий інтервал `Δt = 1 / (4 · f_elec)`. Це усуває невизначеність логічних рівнів, характерну для звичайного двійкового лічильника.

### Режими кратності декодування: 1X, 2X та 4X

Залежно від конфігурації декодера розрізняють три режими обробки квадратурних подій:

1. **Режим 1X (однократна роздільність):**
   Декодер фіксує лише один тип фронту (наприклад, тільки наростання `0 → 1`) на каналі A. Напрям руху визначається поточним рівнем каналу B: якщо `B = 0` — обертання пряме (CW), якщо `B = 1` — зворотне (CCW).
   *Кількість лічених подій за 1 оберт:* `Count = N` (дорівнює числу штрихів диска).

2. **Режим 2X (двократна роздільність):**
   Декодер фіксує обидва фронти (і наростання `0 → 1`, і спад `1 → 0`) на каналі A. Канал B слугує фазовим селектором знаку.
   *Кількість лічених подій за 1 оберт:* `Count = 2 · N`.

3. **Режим 4X (повне квадратурне декодування, чотирикратна роздільність):**
   Декодер фіксує всі можливі фронти (і наростання, і спад) на **обох** каналах A та B. Протягом одного електричного періоду `360° e` реєструються чотири дискретні події:
   - Фронт наростання A (`00 → 10`);
   - Фронт наростання B (`10 → 11`);
   - Фронт спаду A (`11 → 01`);
   - Фронт спаду B (`01 → 00`).

```
Крок кутового квантування в режимі 4X:
Δθ_min = 360° / (4 · N)
```

Режим 4X учетверо збільшує роздільну здатність системи без зміни оптичного диска або додавання додаткових датчиків. Наприклад, диск із 2500 лініями на оберт у режимі 4X формує 10 000 дискретних кроків на оберт, забезпечуючи дискретність кута `0.036°` (2.16 кутових мінут).

### Індексний канал Z: стробування та калібрування нуля

Окрім каналів A та B, більшість промислових інкрементних енкодерів містять третій вихідний сигнал — **індексний канал Z** (також позначається як *Index*, *Marker*, *Reference* або канал C). Канал Z генерує рівно один вузький імпульс на повний механічний оберт вала (360° механічних).

Індексний імпульс слугує абсолютною нульовою міткою. Оскільки квадратурні канали A та B видають лише відносні інкременти переміщення, після подачі живлення система позиціонування не знає фізичного положення ротора. Для прив'язки системи координат виконують процедуру пошуку вихідного положення — **хоумінг** (англ. *homing sequence*):
1. Вал повільно рухається в напрямку грубого кінцевого вимикача або індуктивного датчика наближення.
2. Після спрацьовування вимикача швидкість зменшується в кілька разів, і привід очікує найближчого фронту індексного сигналу Z.
3. У момент надходження імпульсу Z апаратний таймер фіксує точне значення лічильника позиції та скидає його в абсолютний нуль.

```
+-------------------------------------------------------------------------+
|                 СТРОБУВАННЯ ІНДЕКСНОГО СИГНАЛУ Z                        |
+-------------------------------------------------------------------------+
| Канал A:  ───────████████────────████████────────████████────────       |
| Канал B:  ──────────████████────────████████────────████████─────       |
|                                                                         |
| Нестробований Z (360° e):                                               |
| Сигнал Z: ───────████████████████────────────────────────────────       |
|                                                                         |
| Стробований Z (90° e, активний при A=1 та B=1):                         |
| Сигнал Z: ──────────████████─────────────────────────────────────       |
|                     |<90° e>| (рівно 1 дискретний крок 4X)              |
+-------------------------------------------------------------------------+
```

Щоб виключити похибку від джиттеру на границях індексного вікна, сигнал Z на заводі енкодера **стробують** (англ. *gated index*) за логічною функцією `Z_out = Z_raw ∧ A ∧ B`. Стробований імпульс Z має ширину рівно 90° електричних (один крок у режимі 4X) і активний виключно тоді, коли обидва канали A і B перебувають у стані логічної одиниці. Це гарантує, що апаратне скидання нуля відбудеться на строго визначеному кроці лічильника без невизначеності в ±1 крок.

## Недійсні переходи, брязкіт і виявлення помилок

Оскільки квадратурні канали зміщені на чверть періоду, одночасна зміна обох бітів за один крок опитування фізично неможлива. Переходи, під час яких одночасно змінюються обидва біти, називаються **недійсними переходами** (англ. *invalid transitions* або *error states*):

```
Діагональні заборонені переходи:
00₂ (0) <---> 11₂ (3)
01₂ (1) <---> 10₂ (2)
```

Відстань Геммінга для діагональних переходів дорівнює `d = 2`. Поява такого переходу свідчить про апаратний збій, пропуск кроків або проникнення сильної завади.

```
+-----------------------------------------------------------------------+
|                 ДЖЕРЕЛА НЕВАЛІДНИХ ПЕРЕХОДІВ КВАДРАТУРИ               |
+----------------------+------------------------------------------------+
| Фізична причина      | Механізм виникнення                            |
+----------------------+------------------------------------------------+
| Перевищення швидкості| Частота фронтів перевищує смугу пропускання    |
| (Nyquist violation)  | приймача або частоту опитування переривань ISR;|
|                      | між вибірками вал встигає пройти 2 кроки.      |
+----------------------+------------------------------------------------+
| Механічний брязкіт   | Пружні коливання металевих контактів у ручних  |
| (Contact bounce)     | селекторах генерують серію мікросекундних пачок|
|                      | імпульсів одночасно по двох лініях.            |
+----------------------+------------------------------------------------+
| Електромагнітні завади| Комутаційні сплески драйверів ШІМ (MOSFET/IGBT)|
| (EMI / Ground bounce)| наводять паразитні напруги на довгі лінії зв'язку|
|                      | вище порогу логічного перемикання.             |
+----------------------+------------------------------------------------+
| Оптичне/магнітне     | Стохастичний шум компаратора на межі спрацьо-  |
| тремтіння (Jitter)   | вування при зупинці вала на границі щілини.    |
+----------------------+------------------------------------------------+
```

### Наслідки пропуску станів

Якщо квадратурний декодер не аналізує коректність переходів і при діагональному стрибку `00 → 11` автоматично припускає, що рух відбувся вперед, виникає неконтрольоване накопичення похибки позиції. Якщо насправді вал рухався назад, але через перевантаження процесора було пропущено проміжний стан `10`, декодер помилково додасть `+2` кроки замість віднімання `-2`, створивши сумарну похибку у 4 дискретні кроки.

У прецизійних сервосистемах накопичення таких похибок призводить до зсуву координат обробки на верстатах ЧПК або до зриву фази в алгоритмах векторного керування двигунами (FOC — англ. *Field Oriented Control*), де похибка оцінки кута ротора навіть на кілька градусів спричиняє падіння крутного моменту й аварійне перевантаження обмоток.

Тому відмовостійкий квадратурний декодер зобов'язаний:
1. Блокувати зміну лічильника координат при фіксації діагонального переходу;
2. Інкрементувати лічильник діагностичних помилок `error_counter`;
3. Генерувати сигнал тривоги (Emergency Stop), якщо темп помилок перевищує критичний поріг.

### Механічні поворотні енкодери HMI та контактний брязкіт

У панелях приладів, автомагнітолах та вимірювальних приладах як ручки керування широко застосовують недорогі механічні поворотні енкодери (наприклад, серій PEC11 або EC11). У них немає оптики: ковзні металеві контакти перемикаються по струмопровідних сегментах друкованої плати.

При замиканні та розмиканні механічних контактів виникає пружний **контактний брязкіт** (англ. *contact bounce*), який триває від 1 до 5 мілісекунд. За цей час напруга на вході мікроконтролера здійснює десятки хаотичних перемикань між 0 і 1. Якщо підключити такий енкодер безпосередньо до переривань GPIO, кожне клацання ручки додасть сотні хибних кроків.

```
+-------------------------------------------------------------------------+
|                  АПАРАТНИЙ RC-ФІЛЬТР МЕХАНІЧНОГО ЕНКОДЕРА               |
+-------------------------------------------------------------------------+
|        V_CC (3.3V / 5V)                                                 |
|          │                                                              |
|         [R_pull] (10 кОм)                                               |
|          │                                                              |
|          ├────────[R_flt] (10 кОм)───────┬──────> До входу GPIO         |
|          │                               │        (з тригером Шмітта)   |
|     Контакт A                           [C]                             |
|          │                             (10 нФ)                          |
|         GND                              │                              |
|                                         GND                             |
|                                                                         |
| Постійна часу фільтра: τ = R_flt · C = 10 кОм · 10 нФ = 100 мкс         |
+-------------------------------------------------------------------------+
```

Для надійної роботи механічних енкодерів застосовують апаратні інтегрувальні RC-ланцюжки з постійною часу `τ = 100 мкс` у поєднанні з програмним таймерним опитуванням на частоті 1 кГц та мажоритарною фільтрацією.

## Програмні та апаратні методи декодування

Обробка квадратурного сигналу в мікроконтролерах реалізується програмно через скінченний автомат на таблиці пошуку (FSM LUT — англ. *Finite State Machine Lookup Table*) або апаратно за допомогою вбудованих периферійних таймерів.

### Табличний метод FSM (Lookup Table)

Програмний метод базується на формуванні 4-бітного індексу, що об'єднує попередній 2-бітний стан `(A_prev, B_prev)` та щойно зчитаний поточний стан `(A_curr, B_curr)`:

```
index = (prev_state << 2) | curr_state
```

Отриманий 4-бітний індекс (від 0x0 до 0xF) безпосередньо адресує 16-елементну константну таблицю зміщення позиції `QUAD_FSM_LUT[16]`:

```
+-------+------------+------------+---------------+-------------+
| Індекс| Попередній | Поточний   | Зміна позиції | Тип події   |
| (hex) | стан (AB)  | стан (AB)  | (Δpos)        |             |
+-------+------------+------------+---------------+-------------+
| 0x0   | 00₂ (0)    | 00₂ (0)    |  0            | Немає руху  |
| 0x1   | 00₂ (0)    | 01₂ (1)    | +1            | Крок CW     |
| 0x2   | 00₂ (0)    | 10₂ (2)    | -1            | Крок CCW    |
| 0x3   | 00₂ (0)    | 11₂ (3)    |  0 (ERR)      | ПОМИЛКА     |
| 0x4   | 01₂ (1)    | 00₂ (0)    | -1            | Крок CCW    |
| 0x5   | 01₂ (1)    | 01₂ (1)    |  0            | Немає руху  |
| 0x6   | 01₂ (1)    | 10₂ (2)    |  0 (ERR)      | ПОМИЛКА     |
| 0x7   | 01₂ (1)    | 11₂ (3)    | +1            | Крок CW     |
| 0x8   | 10₂ (2)    | 00₂ (0)    | +1            | Крок CW     |
| 0x9   | 10₂ (2)    | 01₂ (1)    |  0 (ERR)      | ПОМИЛКА     |
| 0xA   | 10₂ (2)    | 10₂ (2)    |  0            | Немає руху  |
| 0xB   | 10₂ (2)    | 11₂ (3)    | -1            | Крок CCW    |
| 0xC   | 11₂ (3)    | 00₂ (0)    |  0 (ERR)      | ПОМИЛКА     |
| 0xD   | 11₂ (3)    | 01₂ (1)    | -1            | Крок CCW    |
| 0xE   | 11₂ (3)    | 10₂ (2)    | +1            | Крок CW     |
| 0xF   | 11₂ (3)    | 11₂ (3)    |  0            | Немає руху  |
+-------+------------+------------+---------------+-------------+
```

Таблиця містить 4 нулі (стан не змінився), 4 одиниці зі знаком плюс (крок CW), 4 одиниці зі знаком мінус (крок CCW) і 4 марковані помилки (недійсні переходи). Оновлення позиції виконується за лічені такти процесора без складних умовних переходів `if/else`:

```
int8_t step = QUAD_FSM_LUT[index & 0x0F];
position += step;
```

### Обробка за перериваннями GPIO проти таймерного опитування

Програмний FSM можна тактувати двома способами:
1. **Переривання зовнішніх ліній GPIO (EXTI ISR):** переривання налаштовуються по обох фронтах (Any Edge) для входів каналу A і каналу B.
2. **Періодичне опитування за таймером (Timer Polling ISR):** апаратний таймер мікроконтролера періодично (наприклад, з частотою 1–10 кГц) зчитує фізичний стан пінів GPIO.

Оцінімо навантаження на процесор при використанні переривань EXTI для високошвидкісного мотора. Нехай електродвигун обертається зі швидкістю `3000 об/хв` з оптичним енкодером на `N = 1024 ліній`.

Розрахуємо частоту появи переривань:

```
RPS = 3000 / 60
    = 50 об/с                  [переведення обертів за хвилину в оберти за секунду]

f_edge = 4 · N · RPS
       = 4 · 1024 · 50         [підстановка кількості ліній N = 1024 та частоти обертання RPS = 50]
       = 204800 Гц             [підсумок: 204.8 кГц частоти переривань]
```

Період між послідовними перериваннями становить:

```
T_edge = 1 / 204800
       ≈ 4.88 мкс              [період між фронтами квадратурного сигналу]
```

На мікроконтролері з ядром ARM Cortex-M4 (тактова частота 72 МГц) обробка переривання (вхід у ISR, автозбереження 8 регістрів на стек, виклик обробника, зчитування GPIO, пошук у таблиці, вихід з ISR і відновлення контексту) займає приблизно 1.5–2.5 мкс. При частоті 204.8 кГц обробка енкодера поглине понад **50% усіх обчислювальних ресурсів ядра**, залишаючи мінімум часу для основного коду керування. Якщо швидкість підніметься до 6000 об/хв, процесор захлинеться в нескінченних перериваннях (англ. *interrupt starvation*), почне губити кроки та зависне.

Тому переривання EXTI застосовують лише для низькошвидкісних ручних поворотних ручок (HMI енкодерів) або низькообертових валів (`< 100 об/хв`).

Для ручних енкодерів із механічними контактами ідеальним є **періодичне таймерне опитування (Polling)** на фіксованій частоті 1–2 кГц: воно споживає менше 0.5% CPU і природно інтегрується з цифровою фільтрацією контактного брязкоту.

### Апаратні квадратурні декодери (Timer Encoder Mode / QEI)

Для високошвидкісних приводів та ЧПК використовують спеціалізовані апаратні периферійні блоки — квадратурні інтерфейси енкодерів (англ. *Quadrature Encoder Interface* — QEI або *Timer Encoder Mode* у таймерах STM32 TIMx, блок PCNT у ESP32).

```
+-------------------------------------------------------------------------+
|                  АПАРАТНИЙ КВАДРАТУРНИЙ ДЕКОДЕР ТАЙМЕРА                 |
+-------------------------------------------------------------------------+
| Вхід TI1 (A) ──> [ Цифровий фільтр IC1F ] ──┐                          |
|                                             ├──> [ Апаратна логіка ]    |
| Вхід TI2 (B) ──> [ Цифровий фільтр IC2F ] ──┘    [ декодування FSM]     |
|                                                          │              |
|                                                   Керування тактуванням |
|                                                   і напрямком (DIR)     |
|                                                          ↓              |
|                                              [ 32-бітний лічильник CNT ]|
|                                              (0% завантаження CPU!)     |
|                                                          ↑              |
| Вхід TI3 (Z) ──> [ Скидання нуля / Захоплення ] ─────────┘              |
+-------------------------------------------------------------------------+
```

Апаратний блок QEI працює повністю на рівні комбінаційної логіки та тригерів:
- **0% завантаження ядра CPU:** лічильник `CNT` оновлюється автоматично апаратурою на частотах до десятків мегагерців (десятки мільйонів подій на секунду).
- **Апаратні цифрові фільтри шумів (Glitch Filters):** таймер вимагає, щоб новий рівень на вході залишався стабільним протягом `N` тактів внутрішнього тактового генератора (наприклад, параметр `ICxF` у STM32), повністю відсікаючи високочастотні завади без програмних накладних витрат.
- **Апаратні конфігураційні регістри:** на прикладі таймерів STM32:
  * Біти `SMS[2:0] = 011b` у регістрі `TIMx_SMCR` вмикають режим *Encoder Mode 3* (декодування 4X по обох входах TI1 та TI2);
  * Біти `CC1S = 01b` та `CC2S = 01b` у регістрі `TIMx_CCMR1` прив'язують канали таймера до фізичних пінів;
  * Біт `DIR` у регістрі `TIMx_CR1` апаратно відображає поточний напрям руху (0 — прямий, 1 — зворотний);
  * Регістр автоматичного перезавантаження `TIMx_ARR` задає період лічильника: при значенні `4 · N - 1` таймер автоматично веде циклічний підрахунок кута від 0 до 359.99° всередині одного механічного оберту.

![Тракт обробки квадратури: від диференційного приймача RS-422 до цифрової фільтрації брязкоту та вибору між програмним табличним FSM-декодером і безперервним апаратним таймером](/root/hw/hw-sensing/quadrature/img/quadrature-decoder-pipeline.svg)
*Тракт обробки квадратурного сигналу. Сигнали з первинних сенсорів проходять крізь диференційний приймач RS-422 з тригерами Шмітта. Далі потік розгалужується: верхня програмна гілка виконує дебаунсинг і табличне декодування FSM для низькошвидкісних задач; нижня апаратна гілка тактує 32-бітний лічильник таймера QEI без навантаження на процесор.*

## Відмовостійкий програмний модуль квадратурного декодера

Нижче наведено повну реалізацію відмовостійкого квадратурного декодера, оптимізованого для роботи в періодичному таймерному обробнику або в потоці опитування.

Модуль містить:
- 3-етапний зсувний фільтр-дебаунсер для усунення контактного брязкоту;
- Табличний скінченний автомат декодування переходів (FSM LUT);
- 64-бітний акумулятор повної позиції;
- Лічильник діагональних недійсних переходів;
- Атомарні інтерфейси доступу для запобігання гонитві даних (англ. *race conditions*) між перериванням таймера та основним потоком застосунку.

:::tabs
```c
#include <stdint.h>
#include <stdbool.h>

/* Результати декодування стану */
typedef enum {
    QUAD_DIR_NONE = 0,
    QUAD_DIR_CW   = 1,
    QUAD_DIR_CCW  = -1
} quad_direction_t;

/* Структура стану квадратурного декодера */
typedef struct {
    int64_t  position;          /* Накопичена абсолютна позиція в кроках */
    uint32_t error_count;       /* Лічильник недійсних діагональних переходів */
    uint8_t  prev_valid_state;  /* Попередній валідний 2-бітний стан (0..3) */
    uint8_t  history_a;         /* Зсувний регістр історії вибірок каналу A */
    uint8_t  history_b;         /* Зсувний регістр історії вибірок каналу B */
    uint8_t  stable_a;          /* Відфільтрований стабільний рівень A (0/1) */
    uint8_t  stable_b;          /* Відфільтрований стабільний рівень B (0/1) */
} quad_decoder_t;

/* 
 * Таблиця переходів (FSM LUT).
 * Індекс = (prev_state << 2) | curr_state
 * Значення: 0 (немає руху), 1 (CW, вперед), -1 (CCW, назад), 2 (помилка/недійсний перехід)
 */
static const int8_t QUAD_FSM_LUT[16] = {
    /* 00->00, 00->01, 00->10, 00->11 */
       0,       1,      -1,       2,
    /* 01->00, 01->01, 01->10, 01->11 */
      -1,       0,       2,       1,
    /* 10->00, 10->01, 10->10, 10->11 */
       1,       2,       0,      -1,
    /* 11->00, 11->01, 11->10, 11->11 */
       2,      -1,       1,       0
};

/**
 * @brief Ініціалізація структури квадратурного декодера
 */
void quad_decoder_init(quad_decoder_t *dec, bool initial_raw_a, bool initial_raw_b) {
    if (!dec) return;
    
    dec->position = 0;
    dec->error_count = 0;
    dec->stable_a = initial_raw_a ? 1 : 0;
    dec->stable_b = initial_raw_b ? 1 : 0;
    dec->history_a = dec->stable_a ? 0xFF : 0x00;
    dec->history_b = dec->stable_b ? 0xFF : 0x00;
    dec->prev_valid_state = (dec->stable_a << 1) | dec->stable_b;
}

/**
 * @brief Крок обробки вибірок (викликається періодично з ISR таймера або опитування)
 * @param dec Вказівник на екземпляр декодера
 * @param raw_a Миттєвий логічний рівень каналу A з піна GPIO
 * @param raw_b Миттєвий логічний рівень каналу B з піна GPIO
 * @return quad_direction_t Напрям здійсненого кроку (CW, CCW або NONE)
 */
quad_direction_t quad_decoder_process(quad_decoder_t *dec, bool raw_a, bool raw_b) {
    if (!dec) return QUAD_DIR_NONE;

    /* 1. Цифрова мажоритарна фільтрація брязкоту (Debounce) */
    dec->history_a = (dec->history_a << 1) | (raw_a ? 1 : 0);
    dec->history_b = (dec->history_b << 1) | (raw_b ? 1 : 0);

    /* Рівень вважається стабільним, якщо 3 останні вибірки однакові */
    if ((dec->history_a & 0x07) == 0x07) {
        dec->stable_a = 1;
    } else if ((dec->history_a & 0x07) == 0x00) {
        dec->stable_a = 0;
    }

    if ((dec->history_b & 0x07) == 0x07) {
        dec->stable_b = 1;
    } else if ((dec->history_b & 0x07) == 0x00) {
        dec->stable_b = 0;
    }

    /* 2. Формування поточного 2-бітного стану */
    uint8_t curr_state = (dec->stable_a << 1) | dec->stable_b;

    /* Якщо стан не змінився — рух відсутній */
    if (curr_state == dec->prev_valid_state) {
        return QUAD_DIR_NONE;
    }

    /* 3. Декодування переходу через 4-бітний індекс LUT */
    uint8_t lut_index = (dec->prev_valid_state << 2) | curr_state;
    int8_t step = QUAD_FSM_LUT[lut_index];

    if (step == 2) {
        /* Фіксація недійсного діагонального переходу (00 <-> 11 або 01 <-> 10) */
        dec->error_count++;
        /* При помилці не змінюємо позицію, але оновлюємо попередній стан */
        dec->prev_valid_state = curr_state;
        return QUAD_DIR_NONE;
    }

    /* 4. Валідний перехід: оновлення позиції та збереження стану */
    dec->position += step;
    dec->prev_valid_state = curr_state;

    return (step > 0) ? QUAD_DIR_CW : QUAD_DIR_CCW;
}

/**
 * @brief Отримання поточної позиції
 */
int64_t quad_decoder_get_position(const quad_decoder_t *dec) {
    return dec ? dec->position : 0;
}

/**
 * @brief Отримання кількості зафіксованих помилок
 */
uint32_t quad_decoder_get_errors(const quad_decoder_t *dec) {
    return dec ? dec->error_count : 0;
}

/**
 * @brief Скидання лічильника позиції в нуль
 */
void quad_decoder_reset_position(quad_decoder_t *dec) {
    if (dec) {
        dec->position = 0;
    }
}
```

```cpp
#include <cstdint>
#include <array>
#include <atomic>

/**
 * @brief Напрям здійсненого переміщення
 */
enum class QuadDirection : int8_t {
    None = 0,
    Cw   = 1,
    Ccw  = -1
};

/**
 * @brief Відмовостійкий клас квадратурного декодера C++20
 * @tparam PositionType Цілочисельний тип зберігання координати (за замовчуванням int64_t)
 */
template <typename PositionType = int64_t>
class QuadratureDecoder {
public:
    struct Snapshot {
        PositionType  position;
        uint32_t      error_count;
        QuadDirection last_direction;
    };

    /**
     * @brief Конструктор з початковими логічними рівнями на лініях
     */
    constexpr QuadratureDecoder(bool initial_raw_a = false, bool initial_raw_b = false) noexcept
        : position_(0),
          error_count_(0),
          stable_a_(initial_raw_a ? 1 : 0),
          stable_b_(initial_raw_b ? 1 : 0),
          history_a_(initial_raw_a ? 0xFF : 0x00),
          history_b_(initial_raw_b ? 0xFF : 0x00),
          prev_valid_state_((stable_a_ << 1) | stable_b_),
          last_direction_(QuadDirection::None) {}

    /**
     * @brief Обробка вибірки з входів (викликається з переривання або таймерного циклу)
     */
    QuadDirection process(bool raw_a, bool raw_b) noexcept {
        // 1. Цифрова фільтрація брязкоту (3-бітове ковзне вікно)
        history_a_ = static_cast<uint8_t>((history_a_ << 1) | (raw_a ? 1 : 0));
        history_b_ = static_cast<uint8_t>((history_b_ << 1) | (raw_b ? 1 : 0));

        if ((history_a_ & 0x07) == 0x07) {
            stable_a_ = 1;
        } else if ((history_a_ & 0x07) == 0x00) {
            stable_a_ = 0;
        }

        if ((history_b_ & 0x07) == 0x07) {
            stable_b_ = 1;
        } else if ((history_b_ & 0x07) == 0x00) {
            stable_b_ = 0;
        }

        // 2. Формування 2-бітного вектора поточного стану
        const uint8_t curr_state = static_cast<uint8_t>((stable_a_ << 1) | stable_b_);
        if (curr_state == prev_valid_state_) {
            last_direction_ = QuadDirection::None;
            return QuadDirection::None;
        }

        // 3. Табличне декодування FSM
        const uint8_t lut_index = static_cast<uint8_t>((prev_valid_state_ << 2) | curr_state);
        const int8_t step = FSM_LUT[lut_index];

        if (step == INVALID_TRANSITION) {
            ++error_count_;
            prev_valid_state_ = curr_state;
            last_direction_ = QuadDirection::None;
            return QuadDirection::None;
        }

        // 4. Оновлення позиції
        position_ += step;
        prev_valid_state_ = curr_state;
        last_direction_ = (step > 0) ? QuadDirection::Cw : QuadDirection::Ccw;

        return last_direction_;
    }

    [[nodiscard]] PositionType position() const noexcept {
        return position_;
    }

    [[nodiscard]] uint32_t errors() const noexcept {
        return error_count_;
    }

    [[nodiscard]] QuadDirection last_direction() const noexcept {
        return last_direction_;
    }

    [[nodiscard]] Snapshot snapshot() const noexcept {
        return { position_, error_count_, last_direction_ };
    }

    void reset(PositionType new_position = 0) noexcept {
        position_ = new_position;
    }

    void reset_errors() noexcept {
        error_count_ = 0;
    }

private:
    static constexpr int8_t INVALID_TRANSITION = 2;

    // Константна таблиця переходів у Flash/ROM
    static constexpr std::array<int8_t, 16> FSM_LUT = {
        0,   1,  -1,  INVALID_TRANSITION,
       -1,   0,  INVALID_TRANSITION,   1,
        1,  INVALID_TRANSITION,   0,  -1,
        INVALID_TRANSITION,  -1,   1,   0
    };

    PositionType  position_{0};
    uint32_t      error_count_{0};
    uint8_t       stable_a_{0};
    uint8_t       stable_b_{0};
    uint8_t       history_a_{0};
    uint8_t       history_b_{0};
    uint8_t       prev_valid_state_{0};
    QuadDirection last_direction_{QuadDirection::None};
};
```

## Метрологія квадратури: фазові похибки та захист ліній

В ідеальному квадратурному сигналі шпаруватість імпульсів становить строго 50% (тривалість високого рівня дорівнює тривалості низького рівня: `T_high = T_low`), а фазовий зсув між каналами A та B дорівнює строго 90.0° електричних. У реальних промислових приладах існують неминучі конструктивні та температурні спотворення.

```
+-------------------------------------------------------------------------+
|                  РЕАЛЬНІ СПОТВОРЕННЯ КВАДРАТУРНОГО СИГНАЛУ              |
+-------------------------------------------------------------------------+
| Ідеальний сигнал:                                                       |
| Канал A:  ───████████────────████████────────████████─── (50% Duty)     |
| Канал B:  ──────████████────────████████────────████████ (Фаза = 90° e) |
|           |<-- 90° -->|                                                 |
|                                                                         |
| Реальний спотворений сигнал (зсув фази Δφ + несиметрія шпаруватості):    |
| Канал A:  ───██████████──────██████████──────██████████─ (58% Duty)     |
| Канал B:  ────────██████──────────██████──────────██████ (Фаза = 112° e)|
|           |<--- 112° --->|                                              |
|                                                                         |
| Наслідок: нерівна тривалість 4 квадрантів (t1 ≠ t2 ≠ t3 ≠ t4)           |
| -> Швидкісний джиттер (Velocity Ripple) при диференціюванні положення!  |
+-------------------------------------------------------------------------+
```

### Фазова похибка (Quadrature Phase Error) та похибка шпаруватості

1. **Фазова похибка (Phase Error `Δφ`):**
   Відхилення реального фазового зсуву від теоретичних 90° електричних:

```
φ_real = 90° ± Δφ
```

Причини: неточність монтажу індексної маски або сенсорів Холла, ексцентриситет насадження кодового диска на вал двигуна, радіальний люфт і биття підшипників.

2. **Похибка шпаруватості (Duty Cycle Error `ΔD`):**
   Відхилення відношення тривалості імпульсу до періоду від ідеальних 50%:

```
D = (T_high / T_total) · 100%
```

Причини: температурна деградація випромінювання світлодіода, пилове забруднення оптичного вікна, зміщення порогів спрацьовування компаратора через напругу зміщення операційного підсилювача (Input Offset Voltage).

### Вплив на оцінку миттєвої швидкості (Velocity Jitter)

У системах векторного електроприводу швидкість обертання вала `ω` оцінюють як числову похідну від лічильника позиції за фіксований інтервал квантування контуру швидкості `T_s` (наприклад, `T_s = 250 мкс`):

```
ω_est = (position(t) - position(t - T_s)) / T_s
```

Якщо фазовий зсув спотворений (`Δφ ≠ 0`), чотири квадранти періоду мають різну кутову ширину. При рівномірному обертанні вала час проходження окремих станів починає циклічно чергуватися: `t_1 < t_2 < t_3 < t_4`.

Диференціатор сприймає цю геометричну нерівність як реальні коливання швидкості ротора, породжуючи високочастотний шум оцінки швидкості — **швидкісний джиттер** (англ. *velocity ripple*). ПІД-регулятор швидкості намагається скомпенсувати цей уявний шум, смикаючи вихідний струм інвертора, що призводить до акустичного свисту приводу, підвищеного нагріву двигуна та вібрації механічних передач.

Для усунення швидкісного джиттера застосовують два інженерні підходи:
- **Ковзне усереднення за 4 кроки (повний електричний період):** фільтр низьких частот розраховує середню швидкість за інтервал, кратний цілому числу повних електричних періодів `360° e`, де сума всіх чотирьох нерівномірних часток завжди залишається строго постійною.
- **Спостерігачі стану (Luenberger Observer / Kalman Filter):** замість прямого різницевого диференціювання кут і швидкість оцінюються за динамічною моделлю механічної системи з урахуванням моменту інерції ротора.

### Алгоритми вимірювання швидкості: M-метод, T-метод та M/T-метод

Для отримання швидкості з квадратурного енкодера в діапазоні від 0 до максимальних обертів використовують три класичні методи:

1. **M-метод (підрахунок імпульсів за фіксований час):**
   Вимірюється кількість лічених кроків `M` за фіксований інтервал часу `T_sample` (наприклад, 1 мс). 
   *Переваги:* простий в обчисленні, відмінно працює на високих швидкостях.
   *Недоліки:* на низьких швидкостях виникає величезна похибка квантування: якщо за час `T_sample` приходить лише 0 або 1 імпульс, оцінка швидкості стрибає дискретно між нулем і фіксованим значенням.

2. **T-метод (вимірювання часу між сусідніми імпульсами):**
   Високочастотний таймер тактової частоти `f_clk` (наприклад, 100 МГц) вимірює кількість тактів `T` між двома послідовними фронтами квадратури.
   *Переваги:* колосальна точність на низьких швидкостях (навіть при частоті імпульсів 1 Гц).
   *Недоліки:* на високих швидкостях інтервал між фронтами стає надто коротким (мікросекунди), а фазова похибка `Δφ` спотворює результат через нерівні квадранти.

3. **Комбінований M/T-метод:**
   Інтервал вимірювання починається з першим фронтом квадратури та завершується після спливання часу `T_0` на найближчому наступному фронті квадратури. Одночасно підраховується точне число кроків енкодера `M` і точна кількість тактів високочастотного таймера `T_ticks`. Швидкість розраховується як:

```
ω = (2π · M · f_clk) / (4 · N · T_ticks)
```

M/T-метод усуває похибку квантування часу і забезпечує високу точність у всьому діапазоні обертів електродвигуна від 0.1 об/хв до 10 000 об/хв.

### Аналогова квадратурна інтерполяція (Sin/Cos Encoders 1 Vpp)

У надпрецизійних верстатах та оптичних телескопах дискретності 4X недостатньо. Для отримання субмікронної та нанометрової точності застосовують **Sin/Cos енкодери**, які видають сирі диференційні аналогові сигнали амплітудою 1 В пік-пік (1 Vpp):

```
A(θ) = 0.5 · sin(θ_elec)
B(θ) = 0.5 · cos(θ_elec)
```

Спеціалізований апаратний інтерполятор (наприклад, мікросхеми IC-Haus iC-NQC або Renishaw TONiC) оцифровує обидва канали швидкісними АЦП і обчислює точний миттєвий електричний кут всередині періоду за формулою арктангенса:

```
θ_sub = atan2(A, B)
```

Електронна інтерполяція виконує множення роздільності в 20, 100, 1024 або навіть 4096 разів (інтерполяція CORDIC). Оптичний диск лише на 1000 ліній завдяки інтерполятору x4096 формує `4 096 000` дискретних відліків на один оберт, забезпечуючи дискретність кута `0.000088°` (0.31 кутової секунди).

### Диференційні лінії передачі RS-422

У промислових установках довжина кабелю між енкодером на двигуні та шафою керування досягає 10–50 метрів. Кабель прокладається в одному лотку поряд із силовими кабелями живлення інвертора, де комутуються напруги 400–600 В зі швидкістю наростання `dV/dt > 5 кВ/мкс`.

Передача одиночних логічних сигналів TTL/CMOS на такій відстані неможлива: ємнісні та індуктивні наведення неминуче породять хибні імпульси та недійсні стани.

Стандартом промислової передачі квадратури є **диференційна передача за стандартом RS-422** (три пари витих ліній):
- Канал A: прямий сигнал `A+` та інверсний сигнал `A-`;
- Канал B: прямий сигнал `B+` та інверсний сигнал `B-`;
- Канал Z: прямий індекс `Z+` та інверсний індекс `Z-`.

```
+-------------------------------------------------------------------------+
|              ДИФЕРЕНЦІЙНИЙ ЗАХИСТ ЛІНІЙ ПЕРЕДАЧІ RS-422                 |
+-------------------------------------------------------------------------+
| Енкодер (Драйвер AM26C31)                     Приймач ЧПК (AM26C32)     |
|   +----+                                              +----+            |
|   |    |── A+ ────────── Вита пара ───────────────────| +  |            |
|   |    |                                      [120 Ом]|    |── Логічний |
|   |    |── A- ────────────────────────────────────────| -  |   канал A  |
|   +----+                                              +----+            |
|                                                                         |
| Спільна синфазна завада V_noise наводиться на обидва дроти витої пари:  |
| V(A+) = V_sig + V_noise                                                 |
| V(A-) = -V_sig + V_noise                                                |
|                                                                         |
| Диференційний приймач віднімає напруги:                                 |
| V_out = V(A+) - V(A-)                                                   |
|       = (V_sig + V_noise) - (-V_sig + V_noise)   [віднімання напруг]    |
|       = 2 · V_sig                                [знищення завади]      |
+-------------------------------------------------------------------------+
```

Диференційний приймач (наприклад, мікросхема `AM26C32` або `MAX3095`) з термінальним узгоджувальним резистором 120 Ом на кінці лінії вимірює різницю напруг між проводами пари `V_diff = V_+ - V_-`. Будь-яка зовнішня електромагнітна завада наводиться на обидва скручені дроти однаково (як синфазна напруга `V_noise`) і при диференційному відніманні повністю анулюється, забезпечуючи надійне зчитування квадратури на частотах до кількох мегагерців.
