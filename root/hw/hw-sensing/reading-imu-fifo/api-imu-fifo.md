# 📋 Апаратний та програмний інтерфейс буфера FIFO в IMU

Апаратні регістри керування FIFO, формати пакетних заголовків, часові обмеження шини та протокол SPI/DMA регламентують пакетне зчитування сирих вибірок гіроскопа й акселерометра, а відповідні C/C++ драйвери та формули перерахунку забезпечують конвеєрну обробку потоку вимірювань у сучасних 6-осьових сенсорах (зокрема InvenSense / TDK ICM-42688-P та STMicroelectronics LSM6DSO).

## 1. Регістрова карта керування буфером FIFO

Для конфігурації, моніторингу заповнення та пакетного вичитування буфера сенсор надає набір 8-бітних регістрів, доступних через швидкісні інтерфейси SPI (до 24 МГц) або I2C (до 1 МГц у режимі Fast Mode Plus).

| Регістр | Адреса (Hex) | Біти | Тип | Призначення та бітові маски |
| :--- | :--- | :--- | :--- | :--- |
| `FIFO_CONFIG` | `0x16` | `[7:6]` | R/W | **Режим буферизації:**<br>`00` — Bypass (буфер вимкнено, пряме читання вихідних регістрів);<br>`01` — Stream (кільцевий потік, нові кадри витісняють найстаріші);<br>`10` — Stop-on-Full (запис нових кадрів блокується при досягненні 100% заповнення). |
| `FIFO_CONFIG1` | `0x5F` | `[4:0]` | R/W | **Селектор джерел даних для запису в кадр:**<br>bit 0: `FIFO_ACCEL_EN` (запис 6 байтів акселерометра);<br>bit 1: `FIFO_GYRO_EN` (запис 6 байтів гіроскопа);<br>bit 2: `FIFO_TEMP_EN` (запис 1–2 байтів температури кристала);<br>bit 3: `FIFO_TMST_FSYNC_EN` (запис апаратного таймстемпа та мітки FSYNC);<br>bit 4: `FIFO_HIRES_EN` (увімкнення 20-бітного розширення високої точності). |
| `FIFO_CONFIG2` | `0x60` | `[7:0]` | R/W | Молодші 8 бітів порогу апаратного переривання Watermark (`FIFO_WM[7:0]`). Задається в байтах. |
| `FIFO_CONFIG3` | `0x61` | `[3:0]` | R/W | Старші 4 біти порогу апаратного переривання Watermark (`FIFO_WM[11:8]`). Повний 12-бітний поріг дозволяє налаштовувати спрацьовування до 4095 байтів. |
| `FIFO_COUNTH` | `0x2E` | `[7:0]` | R | Старший байт лічильника незчитаних байтів у буфері (`FIFO_COUNT[15:8]`). |
| `FIFO_COUNTL` | `0x2F` | `[7:0]` | R | Молодший байт лічильника незчитаних байтів у буфері (`FIFO_COUNT[7:0]`). Значення зчитується парою `COUNTH:COUNTL` за одну транзакцію для запобігання атомарним розривам. |
| `FIFO_DATA` | `0x30` | `[7:0]` | R | Вікно читання потоку даних FIFO. Кожне тактування байта з цього регістра автоматично виштовхує наступний байт із SRAM та інкрементує внутрішній покажчик читання. |
| `INT_STATUS` | `0x2D` | `[7:0]` | R | **Регістр прапорців подій переривань (скидається читанням):**<br>bit 2: `FIFO_WM_INT` (кількість байтів досягла або перевищила поріг Watermark);<br>bit 3: `FIFO_FULL_INT` (буфер заповнений на 100%, загроза переповнення або блокування). |
| `INT_SOURCE0` | `0x65` | `[7:0]` | R/W | **Маршрутизація переривань на фізичний пін INT1:**<br>bit 2: `FIFO_WM_INT1_EN` (дозвіл генерації імпульсу на піні INT1 при досягненні порогу);<br>bit 3: `FIFO_FULL_INT1_EN` (дозвіл генерації імпульсу на піні INT1 при переповненні). |
| `SIGNAL_PATH_RESET` | `0x4B` | `[1]` | R/W | **Програмне скидання:**<br>bit 1: `FIFO_FLUSH` (запис `1` миттєво обнуляє покажчики Head і Tail та очищає буфер без перезавантаження конфігурації сенсора). |

## 2. Формати пакетів та структура байта заголовка (FIFO Header Byte)

У сучасних сенсорах покоління ICM-42688-P кожен кадр, що виштовхується з буфера FIFO, починається з 1-байтового заголовка (Header Byte). Заголовок виконує дві критичні функції: дозволяє програмному парсеру динамічно визначати розмір та склад полів пакета і забезпечує автоматичне відновлення синхронізації у разі збою зв'язку на шині.

### Бітова структура байта заголовка (`Header Byte`):

```text
Біт:    [7]        [6]        [5]        [4]        [3]        [2]        [1]        [0]
Назва:  MSG        ACCEL      GYRO       20BIT      FSYNC      ODR_CHG    TIMESTAMP  EMPTY
```

* **Біт 7 (`MSG` — Message Flag):** прапорець системної події. Якщо встановлено в `1`, пакет не містить звичайних вимірів, а несе системне повідомлення (наприклад, інформацію про зміну діапазону вимірювання або внутрішній статус DSP).
* **Біт 6 (`ACCEL` — Accelerometer Data Valid):** якщо `1` — пакет містить 6 байтів сирих даних триосьового акселерометра (`Accel X[15:0]`, `Accel Y[15:0]`, `Accel Z[15:0]`).
* **Біт 5 (`GYRO` — Gyroscope Data Valid):** якщо `1` — пакет містить 6 байтів сирих даних триосьового гіроскопа (`Gyro X[15:0]`, `Gyro Y[15:0]`, `Gyro Z[15:0]`).
* **Біт 4 (`20BIT` — High-Resolution Extension):** якщо `1` — пакет розширено трьома додатковими байтами, що містять молодші 4 біти вимірювань для кожної осі (розширення розрядності з 16 до 20 бітів).
* **Біт 3 (`FSYNC` — Frame Sync Trigger):** прапорець зовнішньої кадрової синхронізації від піна FSYNC. Дозволяє прив'язувати інерційні відліки до відкриття затвора зовнішньої відеокамери.
* **Біт 2 (`ODR_CHG` — ODR Changed):** сигналізує про перший відлік після зміни внутрішньої частоти дискретизації сенсора.
* **Біт 1 (`TIMESTAMP` — Hardware Timestamp Valid):** якщо `1` — пакет завершується 2-байтовим мікросекундним таймстемпом внутрішнього лічильника (`Timestamp[15:0]`).
* **Біт 0 (`EMPTY` — Empty Frame Marker):** якщо `1` — у буфері більше немає валідних даних. Будь-які наступні прочитані байти повертатимуть маркер `0xFF` або `0x80`.

### Стандартні формати пакетів сенсора:

```text
1. Packet 1 (8 байтів — тільки акселерометр):
   [Header 1B] + [Accel X,Y,Z 6B] + [Temp 1B]

2. Packet 2 (8 байтів — тільки гіроскоп):
   [Header 1B] + [Gyro X,Y,Z 6B] + [Temp 1B]

3. Packet 3 (16 байтів — стандартний 6-DoF кадр з таймстемпом):
   [Header 1B] + [Accel X,Y,Z 6B] + [Gyro X,Y,Z 6B] + [Temp 1B] + [Timestamp 2B]

4. Packet 4 (20 байтів — високоточний 20-бітний 6-DoF кадр):
   [Header 1B] + [Accel X,Y,Z 6B] + [Gyro X,Y,Z 6B] + [Temp 2B] + [Timestamp 2B] + [20-bit Ext 3B]
```

## 3. Масштабування та перерахунок фізичних величин (Scale Factors)

Сирі цілочисельні 16-бітні коди зі знаком (`int16_t` у форматі Two's Complement від `-32768` до `+32767`), видобуті з кадрів FIFO, перераховуються у фізичні одиниці системи СІ за наступними співвідношеннями:

### Акселерометр (лінійне прискорення у м/с²):
Коефіцієнт чутливості залежить від налаштованого діапазону повної шкали (Full Scale Range, FSR):
* **Діапазон ±2g:** Чутливість `16384 LSB/g` → `a = raw_code · (2.0 / 32768.0) · 9.80665` м/с²;
* **Діапазон ±4g:** Чутливість `8192 LSB/g` → `a = raw_code · (4.0 / 32768.0) · 9.80665` м/с²;
* **Діапазон ±8g:** Чутливість `4096 LSB/g` → `a = raw_code · (8.0 / 32768.0) · 9.80665` м/с²;
* **Діапазон ±16g:** Чутливість `2048 LSB/g` → `a = raw_code · (16.0 / 32768.0) · 9.80665` м/с².

### Гіроскоп (кутова швидкість у рад/с):
* **Діапазон ±250 °/с:** Чутливість `131.0 LSB/(°/с)` → `ω = raw_code · (250.0 / 32768.0) · (π / 180.0)` рад/с;
* **Діапазон ±500 °/с:** Чутливість `65.5 LSB/(°/с)` → `ω = raw_code · (500.0 / 32768.0) · (π / 180.0)` рад/с;
* **Діапазон ±1000 °/с:** Чутливість `32.8 LSB/(°/с)` → `ω = raw_code · (1000.0 / 32768.0) · (π / 180.0)` рад/с;
* **Діапазон ±2000 °/с:** Чутливість `16.4 LSB/(°/с)` → `ω = raw_code · (2000.0 / 32768.0) · (π / 180.0)` рад/с.

### Температура кристала (°C):
* Для 8-бітного поля `Temp` (Packet 3): `T = (raw_temp / 2.07) + 25.0` °C;
* Для 16-бітного поля `Temp` (Packet 4): `T = (raw_temp_16 / 132.48) + 25.0` °C.

## 4. Послідовність ініціалізації та часові вимоги шини

Для коректного запуску буфера FIFO драйвер повинен виконати суворо визначену послідовність кроків конфігурації:

1. **Програмне скидання мікросхеми:** запис `0x01` у регістр `DEVICE_CONFIG` та очікування щонайменше 10 мс для завершення перезавантаження внутрішньої логіки;
2. **Переведення давачів у режим низького шуму (Low-Noise Mode):** запис `0x0F` у `PWR_MGMT0` для запуску генератора та підсилювачів заряду акселерометра й гіроскопа. Очікування 45–50 мс для стабілізації механічних коливань кремнієвого ротора гіроскопа;
3. **Конфігурація ODR та фільтрів AAF:** вибір частоти дискретизації (наприклад, 1 кГц у `ACCEL_CONFIG0` та `GYRO_CONFIG0`) та смуги пропускання антиаліасингового фільтра;
4. **Обнулення буфера FIFO:** запис `0x02` у `SIGNAL_PATH_RESET` (`FIFO_FLUSH`) для гарантованого скидання внутрішніх покажчиків Head та Tail;
5. **Встановлення порогу Watermark:** запис молодшого та старшого байтів у `FIFO_CONFIG2` та `FIFO_CONFIG3` (наприклад, 160 байтів для пачки з 10 кадрів);
6. **Вибір формату кадру:** запис бітових масок у `FIFO_CONFIG1` (увімкнення `FIFO_ACCEL_EN`, `FIFO_GYRO_EN`, `FIFO_TEMP_EN`, `FIFO_TMST_FSYNC_EN`);
7. **Активація режиму Stream:** запис `0x40` у `FIFO_CONFIG` для переведення буфера в режим безперервного потоку.

### Часові обмеження шини SPI
* **Максимальна тактова частота SPI (SCK):** до 24 МГц у режимі пакетного зчитування FIFO (`FIFO_DATA`), але не більше 1 МГц під час початкової конфігурації регістрів після подачі живлення;
* **Режим SPI (SPI Mode):** сенсори підтримують Mode 0 (CPOL=0, CPHA=0) та Mode 3 (CPOL=1, CPHA=1);
* **Затримка вибірки першого байта (Dummy Byte Requirement):** під час відправки адреси регістра `FIFO_DATA | 0x80` внутрішній автомат сенсора потребує часу для вибірки першого байта зі статичної пам'яті SRAM у зсувний регістр інтерфейсу. Перший байт, що повертається по лінії MISO під час передачі байта адреси, є невизначеним (Dummy Byte). Корисні дані починаються з 2-го байта тактування;
* **Утримання сигналу вибору мікросхеми (Chip Select Setup / Hold):** тривалість низького рівня CS між переднім фронтом першого імпульсу SCK та спадним фронтом CS (`t_css`) повинна складати щонайменше 10 нс; час утримання CS після завершення останнього байта (`t_csh`) — щонайменше 10 нс.

## 5. Обробка апаратного таймстемпа та переповнення лічильника

Внутрішній таймер сенсора формує 16-бітне значення часу з кроком 16 мкс (або 1 мкс у режимі High-Resolution). 

Оскільки 16-бітний лічильник з кроком 16 мкс переповнюється кожні:

```
T_rollover = 65536 · 16 мкс ≈ 1.048576 с
```

програмний драйвер зобов'язаний реалізовувати алгоритм розгортання міток часу (Unwrapping) у 64-бітну монотонну шкалу:

```text
Δtimestamp = (raw_ts_current - raw_ts_previous) & 0xFFFF
timestamp_64us += Δtimestamp * 16
```

Ця операція коректно обробляє перехід через нуль без втрати монотонності часу, якщо інтервал між зчитуваннями пачок не перевищує 1 секунди.

Нижче наведено структури даних, перечислення статусів та сигнатури функцій публічного контракту драйвера для взаємодії з FIFO.

```c
#ifndef IMU_FIFO_API_H
#define IMU_FIFO_API_H

#include <stdint.h>
#include <stdbool.h>
#include <stddef.h>

#ifdef __cplusplus
extern "C" {
#endif

/* Режими роботи апаратного FIFO */
typedef enum {
    IMU_FIFO_MODE_BYPASS       = 0x00, /* FIFO вимкнено */
    IMU_FIFO_MODE_STREAM       = 0x01, /* Потоковий режим із витісненням старих даних */
    IMU_FIFO_MODE_STOP_ON_FULL = 0x02  /* Зупинка запису при 100% заповненні */
} imu_fifo_mode_t;

/* Статус виконання операцій драйвера */
typedef enum {
    IMU_OK                 = 0,
    IMU_ERR_NULL_PTR       = -1,
    IMU_ERR_BUS_FAIL       = -2,
    IMU_ERR_FIFO_OVERFLOW  = -3,
    IMU_ERR_FRAME_SYNC     = -4,
    IMU_ERR_TIMEOUT        = -5,
    IMU_ERR_INVALID_PARAM  = -6
} imu_status_t;

/* Розпакований фізичний кадр інерційних вимірювань у системі СІ */
typedef struct {
    float    accel_mps2[3];    /* Лінійне прискорення [X, Y, Z] у м/с² */
    float    gyro_radps[3];    /* Кутова швидкість [X, Y, Z] у рад/с */
    float    temp_celsius;     /* Температура кристала в °C */
    uint32_t timestamp_us;     /* Апаратний таймстемп у мікросекундах */
    bool     has_accel;        /* Прапорець валідності даних акселерометра */
    bool     has_gyro;         /* Прапорець валідності даних гіроскопа */
    bool     fsync_event;      /* Прапорець події зовнішньої кадрової мітки */
} imu_sample_t;

/* Параметри конфігурації FIFO */
typedef struct {
    imu_fifo_mode_t mode;              /* Режим буферизації */
    uint16_t        watermark_bytes;   /* Поріг Watermark у байтах (наприклад, 160 Б) */
    bool            enable_accel;      /* Дозвіл запису акселерометра */
    bool            enable_gyro;       /* Дозвіл запису гіроскопа */
    bool            enable_timestamp;  /* Дозвіл запису апаратного таймстемпа */
    bool            enable_hires_20bit;/* Режим підвищеної розрядності (Packet 4) */
} imu_fifo_config_t;

/* Ініціалізація сенсора та конфігурація буфера FIFO */
imu_status_t imu_fifo_init(const imu_fifo_config_t *config);

/* Очищення буфера та обнулення покажчиків Head/Tail (FIFO Flush) */
imu_status_t imu_fifo_flush(void);

/* Отримання поточної кількості незчитаних байтів у буфері FIFO */
imu_status_t imu_fifo_get_count(uint16_t *out_byte_count);

/* Пакетне вичитування сирого масиву байтів через SPI (сумісне з DMA) */
imu_status_t imu_fifo_read_burst(uint8_t *rx_buf, uint16_t length);

/* Потоковий парсер сирого буфера в масив фізичних відліків imu_sample_t */
imu_status_t imu_fifo_parse_frames(
    const uint8_t *raw_stream,
    size_t         raw_bytes,
    imu_sample_t  *out_samples,
    size_t         max_samples,
    size_t        *parsed_count
);

#ifdef __cplusplus
}
#endif

#endif /* IMU_FIFO_API_H */
```

```cpp
#pragma once

#include <cstdint>
#include <cstddef>
#include <span>
#include <array>
#include <expected>

namespace imu {

enum class FifoMode : uint8_t {
    Bypass     = 0x00,
    Stream     = 0x01,
    StopOnFull = 0x02
};

enum class Error : int32_t {
    BusFailure    = -1,
    FifoOverflow  = -2,
    FrameSyncLoss = -3,
    Timeout       = -4,
    InvalidParam  = -5,
    NullPointer   = -6
};

struct Sample {
    std::array<float, 3> accel_mps2{};
    std::array<float, 3> gyro_radps{};
    float                temp_celsius{0.0f};
    uint32_t             timestamp_us{0};
    bool                 has_accel{false};
    bool                 has_gyro{false};
    bool                 fsync_event{false};
};

struct FifoConfig {
    FifoMode mode{FifoMode::Stream};
    uint16_t watermark_bytes{160};
    bool     enable_accel{true};
    bool     enable_gyro{true};
    bool     enable_timestamp{true};
    bool     enable_hires_20bit{false};
};

class IFifoTransport {
public:
    virtual ~IFifoTransport() = default;
    virtual std::expected<void, Error> read_registers(uint8_t reg, std::span<uint8_t> dst) = 0;
    virtual std::expected<void, Error> write_register(uint8_t reg, uint8_t val) = 0;
    virtual std::expected<void, Error> start_dma_burst_read(uint8_t fifo_reg, std::span<uint8_t> dst) = 0;
};

class FifoController {
public:
    explicit FifoController(IFifoTransport &transport) : transport_{transport} {}

    std::expected<void, Error> configure(const FifoConfig &cfg);
    std::expected<void, Error> flush();
    std::expected<uint16_t, Error> available_bytes();
    
    std::expected<size_t, Error> parse_packet_stream(
        std::span<const uint8_t> raw_bytes,
        std::span<Sample> out_samples
    );

private:
    IFifoTransport &transport_;
    FifoConfig      active_config_{};
};

} // namespace imu
```
