# 🧮 Вплив джиттеру дискретизації на дрейф інтегрування гіроскопа

Коли мікроконтролер обчислює просторову орієнтацію рухомого об'єкта (дрона, робота чи стабілізатора камери), основним джерелом інформації про швидкі кутові зміни є триосьовий [гіроскоп](root:hw-sensing/gyroscope). Проте гіроскоп вимірює не кут повороту, а миттєву кутову швидкість `ω(t)`. Для визначення поточного кута орієнтації `θ(t)` алгоритм змушений чисельно інтегрувати виміряні дискретні відліки в часі:

```
θ(t) = θ₀ + ∫ ω(τ) dτ
```

У цифровій системі безперервний інтеграл замінюється дискретною сумою за методом прямокутників (метод Ейлера) або трапецій:

```
θ_k = θ_{k-1} + ω_k · Δt_k
```

Якщо зчитування сенсора виконується програмно через періодичні переривання таймера чи опитування регістрів, інтервал між вибірками `Δt_k` не є строго постійним. Він піддається [джиттеру вибірки](root:hw-sensing/sampling-jitter) `δt_k`, викликаному латентністю входу в обробник переривання (ISR), блокуванням переривань критичними секціями коду та диспетчеризацією задач операційної системи реального часу (RTOS).

У цьому розборі ми суворо виведемо, як випадкове часове тремтіння `δt` перетворюється на систематичну та стохастичну похибку оцінки кута орієнтації, і чому апаратний буфер FIFO з фіксованим ODR усуває цю складову дрейфу.

## 1. Математична модель похибки чисельного інтегрування

Нехай номінальний період дискретизації сенсора становить `Δt_0 = 1 / ODR`. У системі з програмним опитуванням реальний момент взяття `k`-го відліку `t_k` відхиляється від ідеальної сітки:

```
t_k = k · Δt_0 + δt_k
```

де `δt_k` — випадкова величина часового джиттеру з нульовим математичним сподіванням `E[δt_k] = 0` та дисперсією `Var(δt_k) = σ_t^2`.

Фактичний часовий інтервал між сусідніми вибірками `k-1` та `k` дорівнює:

```
Δt_k = t_k - t_{k-1}
= (k · Δt_0 + δt_k) - ((k-1) · Δt_0 + δt_{k-1})    [підстановка виразів реальних моментів часу]
= Δt_0 + (δt_k - δt_{k-1})                         [розкриття дужок та спрощення k·Δt_0]
= Δt_0 + ε_k                                      [позначення різниці джиттеру через ε_k]
```

де `ε_k = δt_k - δt_{k-1}` — похибка інтервалу інтегрування.

Більшість алгоритмів фільтрації орієнтації (наприклад, фільтри Маджвіка, Махоні або дискретний розширений фільтр Калмана EKF) задля економії обчислювальних ресурсів процесора припускають, що часовий крок є строго постійним і дорівнює номінальному: `Δt_app = Δt_0`. 

Тоді обчислений алгоритмом кут на кроці `N` становить:

```
θ̂_N = θ_0 + ∑_{k=1}^N ω_k · Δt_0
```

У той самий час істинний інтеграл дискретизованого сигналу за фактичними часовими інтервалами дорівнює:

```
θ_N = θ_0 + ∑_{k=1}^N ω_k · Δt_k
= θ_0 + ∑_{k=1}^N ω_k · (Δt_0 + ε_k)              [підстановка фактичного інтервалу Δt_k]
```

Абсолютна похибка інтегрування кута `Δθ_N = θ̂_N - θ_N`, накопичена за `N` кроків, визначається виразом:

```
Δθ_N = - ∑_{k=1}^N ω_k · ε_k
= - ∑_{k=1}^N ω_k · (δt_k - δt_{k-1})              [підстановка різниці похибок джиттеру]
```

Розкриємо цю телескопічну суму за формулою інтегрування частинами для дискретних рядів (перегрупування Абеля):

```
∑_{k=1}^N ω_k · (δt_k - δt_{k-1})
= ω_N · δt_N - ω_1 · δt_0 - ∑_{k=1}^{N-1} (ω_{k+1} - ω_k) · δt_k     [групування доданків при однакових δt_k]
= ω_N · δt_N - ω_1 · δt_0 - ∑_{k=1}^{N-1} Δω_k · δt_k                 [позначення приросту швидкості Δω_k]
```

Оскільки відношення `Δω_k / Δt_0` є скінченно-різницевим наближенням кутового прискорення `α_k = (dω/dt)_k`, підставимо `Δω_k = α_k · Δt_0`:

```
Δθ_N = ω_1 · δt_0 - ω_N · δt_N + Δt_0 · ∑_{k=1}^{N-1} α_k · δt_k
```

Це рівняння розкриває фундаментальну природу виникнення похибки: похибка інтегрування кута виникає не від самої кутової швидкості, а від **кутового прискорення `α` (динаміки маневру), зваженого на часовий джиттер `δt`**.

## 2. Дисперсія накопиченої похибки та випадкове блукання орієнтації

Припустимо, що часовий джиттер `δt_k` на різних кроках є некорельованим білим шумом:

```
E[δt_i · δt_j] = σ_t^2 · δ_{ij}
```

де `δ_{ij}` — символ Кронекера (`1` при `i = j`, `0` при `i ≠ j`).

Обчислимо дисперсію накопиченої похибки кута `Var(Δθ_N)` для інтервалу часу `T = N · Δt_0` при русі з характерним середньоквадратичним кутовим прискоренням `α_rms`:

```
Var(Δθ_N) = E[(Δθ_N)^2]
= E[(ω_1 · δt_0 - ω_N · δt_N + Δt_0 · ∑_{k=1}^{N-1} α_k · δt_k)^2]    [підстановка виразу похибки]
= (ω_1^2 + ω_N^2) · σ_t^2 + (Δt_0)^2 · ∑_{k=1}^{N-1} α_k^2 · σ_t^2    [розкриття за умови некорельованості δt]
≈ 2 · ω_rms^2 · σ_t^2 + (Δt_0)^2 · (N - 1) · α_rms^2 · σ_t^2         [усереднення за ансамблем]
= 2 · ω_rms^2 · σ_t^2 + Δt_0 · T · α_rms^2 · σ_t^2                   [заміна N · Δt_0 на повний час T]
```

Перший доданок `2 · ω_rms^2 · σ_t^2` описує миттєву фазову невизначеність на кінцях інтервалу (вона не зростає з часом). Другий доданок лінійно зростає з часом `T` і формує додатковий штучний шум випадкового блукання кута (Angle Random Walk, ARW):

```
Var(Δθ(T)) ≈ T · (Δt_0 · α_rms^2 · σ_t^2)
```

Ефективна спектральна густина шуму ARW, породжена джиттером вибірки, становить:

```
PSD_jitter = α_rms · σ_t · √(Δt_0)   [рад / √с]
```

## 3. Спектральний аналіз: перенесення вібраційного шуму у низькочастотну смугу

У системах керування рухомими апаратами (особливо на мультикоптерах) на корисний сигнал кутової швидкості завжди накладаються механічні вібрації від обертання гвинтів та двигунів на частотах `f_vib` (типово 100–400 Гц):

```
ω_vib(t) = Ω_0 · sin(2π · f_vib · t)
```

Якщо момент взяття вибірки піддається часовому тремтінню `t_k = k · Δt_0 + δt_k`, значення виміряного сигналу набуває вигляду:

```
ω_meas[k] = Ω_0 · sin(2π · f_vib · (k · Δt_0 + δt_k))
```

Розклавши синус за малим параметром `2π · f_vib · δt_k ≪ 1`:

```
ω_meas[k] ≈ Ω_0 · sin(2π · f_vib · k · Δt_0) + 2π · f_vib · Ω_0 · δt_k · cos(2π · f_vib · k · Δt_0)
```

Другий доданок є результатом фазової модуляції високої частоти вібрації випадковим процесом джиттеру `δt_k`. У частотній області це відповідає згортці дискретного спектра вібраційного піку зі спектром часового шуму. 

У результаті частина потужності високочастотної вібрації **демодулюється і змішується у низькочастотну робочу смугу контуру стабілізації (0–30 Гц)**. Цей ефект неможливо усунути класичними цифровими фільтрами низьких частот (Butterworth чи Notch-фільтрами), оскільки він створює шум безпосередньо в корисній смузі сигналу керування.

## 4. Числовий приклад: динамічний політ квадрокоптера

Розглянемо типові параметри польоту швидкісного спортивного квадрокоптера під час виконання різкого маневру (акробатичного фліпу):
- Номінальна частота оновлення гіроскопа: `ODR = 1000 Гц` (`Δt_0 = 1.0 мс = 10^{-3} с`);
- Кутова швидкість обертання: `ω = 400 °/с ≈ 6.98 рад/с`;
- Кутове прискорення при вході у маневр: `α = 4000 °/с² ≈ 69.8 рад/с²`.

Порівняємо два сценарії зчитування даних:

### Сценарій 1: Програмне опитування з джиттером переривань RTOS
У типовій системі на базі RTOS із декількома активними задачами (радіолінк, телеметрія, логування на Flash-пам'ять) затримка реакції процесора на готовність даних має середньоквадратичне відхилення `σ_t = 150 мкс` (`0.15 мс`):

```
PSD_jitter = 69.8 рад/с² · (150 × 10^{-6} с) · √(10^{-3} с)
= 69.8 · 1.5 × 10^{-4} · 0.03162              [обчислення кореня та перемноження сталих]
≈ 3.31 × 10^{-4} рад / √с                     [переведення в радіани за корінь із секунди]
≈ 0.019 ° / √с                                [переведення радіанів у градуси (· 180 / π)]
= 1.14 ° / √год                               [масштабування до градусів за корінь із години]
```

За 10 секунд інтенсивного маневрування середньоквадратичне відхилення інтегрованого кута становитиме:

```
σ_θ = PSD_jitter · √(T)
= 0.019 ° / √с · √(10 с)                      [підстановка T = 10 с]
≈ 0.060 °                                     [обчислення накопиченого СКО кута]
```

Якщо ж під час польоту виникає блокування переривань через стирання сектора Flash-пам'яті (затримка `δt ≈ 2.5 мс`), похибка одного кроку складе:

```
Δθ_single = ω · δt
= 400 °/с · 0.0025 с                          [підстановка кутової швидкості та тривалості затримки]
= 1.0 °                                       [стрибкоподібна похибка орієнтації за один такт]
```

Такий фазовий стрибок призводить до хибного спрацьовування D-складової PID-регулятора та виникнення високочастотних осциляцій двигунів.

### Сценарій 2: Апаратний буфер FIFO з фіксованим ODR
При використанні апаратного буфера FIFO фіксація відліків у пам'ять виконується внутрішньою логікою кристала IMU за сигналами інтегрованого кварцового або RC-генератора з PLL. Власний джиттер апаратного генератора становить менше `σ_t < 10 нс` (`10^{-8} с`).

Підставимо це значення у формулу спектральної густини шуму:

```
PSD_fifo = 69.8 рад/с² · (10 × 10^{-9} с) · √(10^{-3} с)
= 69.8 · 10^{-8} · 0.03162                    [обчислення добутку параметрів]
≈ 2.21 × 10^{-8} рад / √с                     [спектральна густина шуму в рад/√с]
≈ 1.26 × 10^{-6} ° / √с                       [переведення в кутові градуси за √с]
```

Внесок часового джиттеру в похибку орієнтації зменшується у **15 000 разів** і стає абсолютно нехтовним порівняно з власним термомеханічним шумом кремнієвого гіроскопа (Angle Random Walk MEMS становить близько `0.005–0.015 ° / √с`).

## 5. Підсумок

Чисельне інтегрування кутової швидкості `ω` перетворює будь-яке тремтіння часового кроку `δt` на фазову помилку, пропорційну миттєвому кутовому прискоренню `α = dω/dt`.

1. При програмному зчитуванні похибка `Δt` породжує фальшивий дрейф орієнтації, який неможливо відфільтрувати класичними алгоритмами оцінки стану, оскільки алгоритм вважає часовий інтервал еталонним;
2. Джиттер вибірки демодулює високочастотні моторні вібрації, змішуючи їх безпосередньо в робочу низькочастотну смугу зворотного зв'язку автопілота;
3. Використання апаратного буфера FIFO гарантує, що всі збережені відліки зняті з прецизійним апаратним інтервалом `Δt_0`. Мікроконтролер може зчитувати кадри пачками з довільною латентністю без жодного впливу на точність інтегрування.
