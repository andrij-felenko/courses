Коли температура робочої зони промислової печі випалу кераміки, камери згоряння газової турбіни чи сопла ракетного двигуна перевищує 600–800 °C, класичні напівпровідникові термодавачі, терморезистори й платинові сенсори опору RTD виходять з ладу: кремнієві кристали плавляться або втрачають напівпровідникові властивості, скляні підкладки розтріскуються, а тонкоплівкова металізація розчиняється та дифундує в кераміку. Єдиним контактним перетворювачем, здатним стабільно, неперервно й довговічно працювати в діапазоні від кріогенних −270 °C до понад +1300 °C (а зі спеціальними сплавами — до +1800 °C і +2300 °C), залишається **термопара** (англ. *thermocouple*). Це цілковито пасивний первинний вимірювальний перетворювач, складений із двох різнорідних металевих провідників, що генерує електричну напругу виключно за рахунок внутрішнього теплового руху носіїв заряду без підведення стороннього струму живлення.

## Фізичний механізм: ефект Зеєбека вздовж температурного градієнта

Поширене уявлення про те, що термопарна напруга «народжується в точці контакту двох спаяних металів», є грубою фізичною помилкою. Спай (зварний вузол на кінці зонда) виконує суто комутаційну роль — електрично замикає між собою два різні метали для створення замкненого вимірювального кола. Фізична термоелектрорушійна сила (термо-ЕРС) генерується не в точці спаю, а **розподілено вздовж усієї довжини провідників на тих ділянках, де існує просторовий градієнт температури** `dT/dx`.

Явище ґрунтується на термоелектричному ефекті, відкритому 1821 року балтійсько-німецьким фізиком Томасом Йоганном Зеєбеком (нім. *Thomas Johann Seebeck*). У будь-якому металевому провіднику, вздовж якого існує перепад температур, вільні електрони на гарячому кінці володіють вищою середньою кінетичною енергією та тепловою швидкістю, ніж електрони на холодному кінці. Внаслідок теплового руху виникає спрямована дифузія електронів від нагрітого краю до холодного.

```
       Гарячий кінець (T_hot)                     Холодний кінець (T_cold)
       ┌────────────────────────────────────────────────────────────────┐
       │ e⁻  →   e⁻  →   e⁻  →   e⁻  →   e⁻  →   e⁻  →   e⁻  →   e⁻     │
       │ (+) Збіднення носіями             Надлишок електронів (−)      │
       └────────────────────────────────────────────────────────────────┘
                           ───► Градієнт температури dT/dx
                           ◄─── Внутрішнє електричне поле E
```

Електрони накопичуються на холодному кінці, заряджаючи його негативно, тоді як гарячий кінець втрачає електрони й набуває позитивного заряду. Просторово розділені заряди створюють внутрішнє зустрічне електростатичне поле. Дифузія триває доти, доки сила внутрішнього електричного поля не врівноважить теплову рушійну силу дифузійного тиску гарячих електронів.

Напруженість виниклого електричного поля `E` в кожній точці провідника пропорційна локальному просторовому градієнту температури:

```
E(x) = -S(T) · (dT / dx)
```

де `S(T)` — абсолютний диференційний **коефіцієнт Зеєбека** (термоелектрична здатність матеріалу, вимірюється у мікровольтах на кельвін, мкВ/К або мкВ/°C).

Коли два різні провідники (матеріал A та матеріал B) з'єднують на гарячому кінці за температури `T_hot`, а їхні вільні кінці підключають до вимірювача за опорної температури `T_cold`, різниця потенціалів між виводами є сумою інтегралів електричних полів вздовж обох гілок:

```
V_emf = ∫ [S_A(T) - S_B(T)] dT
        від T_cold до T_hot
```

![Генерація термо-ЕРС вздовж температурного градієнта](/root/hw/hw-sensing/thermocouple/img/seebeck-circuit-gradient.svg)
*Розподіл температурного градієнта вздовж двох різнорідних провідників і формування результуючої термо-ЕРС на клемах вимірювача.*

Якщо обидва провідники виготовлені з одного й того ж металу (`S_A(T) = S_B(T)`), сумарна напруга на клемах завжди дорівнює нулю незалежно від величини нагріву спаю. Щоб на клемах з'явився вимірюваний сигнал, провідники A та B обов'язково повинні мати суттєво різні коефіцієнти Зеєбека: один сплав підбирають з сильно позитивним значенням `S_A > 0` (наприклад, Хромель), а другий — з негативним або близьким до нуля `S_B < 0` (наприклад, Алюмель).

## Три фундаментальні закони термоелектрики

Проектування вимірювальних трактів з термопарами спирається на три емпіричні закони, які випливають із лінійності інтеграла термоелектрорушійної сили вздовж температурного контуру.

### 1. Закон однорідних провідників
Термоелектрорушійна сила не може виникнути в замкненому контурі, складеному з одного хімічно й фізично однорідного металу, яким би складним і нерівномірним не був розподіл температури вздовж дроту. Будь-який градієнт на шляху «туди» точно компенсується зустрічним градієнтом на шляху «назад». Звідси випливає практичне правило: якщо термоелектродний дріт локально неоднорідний (забруднений домішками, окиснений чи зазнав нерівномірного пластичного деформування при згині), у зоні температурного перепаду виникає паразитна ЕРС неоднорідності, яка спотворює вимірювання.

### 2. Закон проміжних металів
Введення третього провідника (C) у розрив термопарного кола не змінює сумарну термо-ЕРС за умови, що обидва кінці (спаї) цього третього провідника перебувають за абсолютно однакової температури:

```
V_ABC = V_AB      [якщо T(стик 1) = T(стик 2)]
```

Цей закон є наріжним каменем практичного застосування термопар:
- Гарячий спай можна паяти твердим або м'яким припоєм (мідно-фосфорним, срібним, олов'яно-свинцевим) чи зварювати за допомогою третього металу: наявність шару припою в точці спаю не спотворює сигнал, оскільки весь спай знаходиться в ізотермічній зоні;
- Клеми підключення, мідні доріжки друкованої плати, контактні майданчики мікросхем і виводи АЦП не спотворюють результуюче значення напруги, якщо обидві вхідні клеми підтримуються за строго однакової температури.

### 3. Закон проміжних температур
Термо-ЕРС, що виникає між температурами `T₁` та `T₃`, дорівнює алгебраїчній сумі термо-ЕРС для інтервалів `(T₁, T₂)` та `(T₂, T₃)`:

```
V(T₁, T₃) = V(T₁, T₂) + V(T₂, T₃)
```

Цей закон дозволяє калібрувати термопари відносно єдиної стандартної опорної точки 0 °C (температури танення льоду) і математично перераховувати напругу для будь-якої іншої температури клем.

## Холодний спай і необхідність компенсації (CJC)

Оскільки вихідна напруга термопари визначається інтегралом за різницею температур між гарячим спаєм (`T_hot`) та клемами підключення (`T_cold`), термопара за своєю фізичною природою є **диференційним давачем**. Вона принципово не вимірює абсолютну температуру гарячого спаю — вона вимірює виключно перепад:

```
ΔT = T_hot - T_cold
```

Якщо гарячий спай перебуває в печі за постійної температури 800 °C, а температура повітря в шафі автоматики біля клем АЦП коливається від 20 °C до 45 °C через зміну погоди чи нагрів трансформаторів, виміряна напруга на клемах плаватиме на величину, еквівалентну 25 °C. 

У лабораторних установках XIX–XX століть вільні кінці термопари занурювали в герметичних пробірках у посудину Дьюара з сумішшю дистильованої води та льоду, фіксуючи `T_cold = 0.0 °C`. У сучасній промисловій електроніці лід не використовують: замість цього застосовують **електронну компенсацію холодного спаю** (англ. *Cold Junction Compensation*, CJC).

![Тракт збору даних і послідовність компенсації холодного спаю](/root/hw/hw-sensing/thermocouple/img/cjc-compensation-pipeline.svg)
*Структурна схема вимірювального тракту термопари з роздільним оцифруванням сигналу й температури холодного спаю.*

### Апаратна реалізація ізотермічного блоку
Термопарні дроти підключають до масивного мідного або латунного клемника з високою теплопровідністю та високою теплоємністю (ізотермічний блок). Безпосередньо біля клемних гвинтів (на відстані 1–3 мм, часто під суцільним захисним екраном) на платі розпаюють прецизійний локальний давач абсолютної температури:
- Напівпровідниковий терморезистор [NTC](root:hw-sensing/ntc-thermistor) з допуском ±0.1 °C;
- Платиновий тонкоплівковий сенсор RTD (PT100 або PT1000);
- Спеціалізовану цифрову мікросхему термометра (наприклад, TMP117 або вбудований внутрішній діодний давач інтерфейсних мікросхем MAX31855, MAX31856, ADS1118, ADS1248).

### Математичний конвеєр розрахунку температури
Зведення сигналу виконується виключно в електричній площині додаванням еквівалентних ЕРС, а не температур:

1. Оцифровують напругу на клемах термопари `V_raw` (у мікровольтах чи мілівольтах);
2. Оцифровують температуру клемного блоку `T_cj` (у градусах Цельсія);
3. За прямим калібрувальним поліномом обчислюють, яку напругу `V_cj` згенерувала б ця термопара, якби її гарячий спай мав температуру `T_cj`, а холодний знаходився при 0 °C:
   ```
   V_cj = f_NIST(T_cj)
   ```
4. Знаходять сумарну термо-ЕРС відносно еталонного нуля:
   ```
   V_total = V_raw + V_cj
   ```
5. За оберненим поліномом перетворюють сумарну напругу `V_total` у фактичну температуру гарячого спаю:
   ```
   T_hot = g_NIST(V_total)
   ```

Спроба розрахувати температуру спрощеною формулою `T_hot = g_NIST(V_raw) + T_cj` призводить до неприпустимих похибок у десятки градусів, оскільки крутизна характеристики термопари при кімнатній температурі суттєво відрізняється від крутизни при 800–1000 °C.

## Класифікація, металургія та характеристики стандартних термопар

Міжнародні стандарти (IEC 60584-1, ASTM E230, NIST Monograph 175) стандартизують склад сплавів, діапазони вимірювання та поліноміальні залежності для основних типів термопар.

![Коефіцієнт Зеєбека S(T) стандартних термопар](/root/hw/hw-sensing/thermocouple/img/seebeck-nonlinearity-curves.svg)
*Залежність диференційного коефіцієнта Зеєбека S від температури для промислових термопар типів K, J, T, N.*

### Тип K (Хромель–Алюмель, Ni-Cr / Ni-Al)
Найпоширеніша універсальна промислова термопара загального призначення.
- **Діапазон вимірювання:** від −200 °C до +1260 °C (короткочасно до +1372 °C).
- **Чутливість (коефіцієнт Зеєбека):** близько 41.2 мкВ/°C при 0 °C, коливається в межах 39–42 мкВ/°C у робочому діапазоні.
- **Склад позитивного електрода (KP):** Хромель (англ. *Chromel*) — сплав 90% нікелю (Ni) та 10% хрому (Cr).
- **Склад негативного електрода (KN):** Алюмель (англ. *Alumel*) — сплав 95% нікелю (Ni), 2% алюмінію (Al), 2% марганцю (Mn) та 1% кремнію (Si). Алюмель є феромагнетиком і слабо притягується постійним магнітом, що слугує швидким тестом для перевірки полярності дротів на монтажі.
- **Переваги:** Висока стійкість до окиснення в повітряній атмосфері за рахунок утворення щільної захисної плівки оксиду хрому `Cr2O3`, дешевизна, широкий діапазон, практично лінійна характеристика вище 0 °C.
- **Недоліки та металургійні пастки:**
  1. *Зелена гниль (Green rot):* При використанні в бідних на кисень або відновних атмосферах при температурах 800–1050 °C хром у хромелевому дроті вибірково окиснюється з утворенням пухкого зеленого оксиду `Cr2O3`, збіднюючи матрицю нікелю. Коефіцієнт Зеєбека різко падає, і термопара починає занижувати покази на десятки градусів;
  2. *Ближній порядок (Short-range ordering drift):* При нагріванні в діапазоні 250–550 °C атоми нікелю та хрому в кристалічній ґратці хромелю самовільно перегруповуються в упорядковані кластери, викликаючи гістерезисний дрейф термо-ЕРС до +2..+5 °C. Дрейф зникає лише після високотемпературного відпалу при > 800 °C;
  3. *Магнітний перехід Кюрі:* При температурі близько 150–170 °C алюмель втрачає феромагнітні властивості, що викликає локальний прогин на кривій диференційного коефіцієнта Зеєбека.

### Тип J (Залізо–Константан, Fe / Cu-Ni)
Оптимальний вибір для відновних атмосфер і вакуумних печей середньотемпературного діапазону.
- **Діапазон вимірювання:** від −40 °C до +750 °C.
- **Чутливість:** 50–55 мкВ/°C при 25 °C (значно вища за тип K).
- **Склад позитивного електрода (JP):** Чисте залізо промислової чистоти (Fe 99.5%). Магнітний провідник.
- **Склад негативного електрода (JN):** Константан (англ. *Constantan*) — мідно-нікелевий сплав (55% Cu, 45% Ni).
- **Переваги:** Висока чутливість (великий вихідний сигнал знижує вимоги до шуму АЦП), відмінна робота у відновних, водневих і вакуумних середовищах.
- **Недоліки:** Залізний провідник іржавіє у вологому повітрі. В окисних середовищах залізо швидко перетворюється на окалину при температурах вище 550 °C. При температурі 770 °C залізо проходить точку Кюрі з фазовим переходом у кристалічній ґратці, що встановлює жорстку верхню температурну межу експлуатації.

### Тип T (Мідь–Константан, Cu / Cu-Ni)
Еталон точності для кріогеніки та хімічно-лабораторних вимірювань.
- **Діапазон вимірювання:** від −200 °C (короткочасно від −270 °C) до +350 °C (допустимо до +400 °C).
- **Чутливість:** від 15 мкВ/°C при −200 °C до 40 мкВ/°C при 20 °C і до 60 мкВ/°C при 350 °C.
- **Склад позитивного електрода (TP):** Безкиснева електротехнічна мідь високої чистоти (OFHC Copper).
- **Склад негативного електрода (TN):** Спеціальний сорт константану (55% Cu, 45% Ni).
- **Переваги:** Висока стабільність і відтворюваність у кріогенному діапазоні (рідкий азот, рідкий гелій). Повна стійкість до корозії у вологій атмосфері. Оскільки позитивний провідник є чистою міддю, його можна підключати безпосередньо до мідних доріжок друкованої плати без утворення паразитної термопари на плюсовій клемі.
- **Недоліки:** Мідний дріт швидко окиснюється на повітрі при температурах вище 370 °C. Мідь має високу теплопровідність, що може призводити до відведення тепла з вимірюваної зони по дроту, якщо зонд занадто тонкий або заглиблений неглибоко.

### Тип N (Нікросил–Нісил, Ni-Cr-Si / Ni-Si-Mg)
Сучасна вдосконалена термопара, розроблена Австралійською організацією оборонної науки й технологій (DSTO) спеціально для повної заміни типу K у високотемпературних процесах.
- **Діапазон вимірювання:** від −270 °C до +1300 °C.
- **Чутливість:** близько 26 мкВ/°C при 0 °C, плавно зростає до 39 мкВ/°C при 1000 °C.
- **Склад позитивного електрода (NP):** Нікросил (англ. *Nicrosil*) — 84.4% Ni, 14.2% Cr, 1.4% Si.
- **Склад негативного електрода (NN):** Нісил (англ. *Nisil*) — 95.5% Ni, 4.4% Si, 0.1% Mg.
- **Переваги:** Введення кремнію (Si) та підвищення концентрації хрому повністю блокує вибіркове окиснення (зелену гниль). Кремній формує на поверхні сплаву неперервний захисний бар'єр із діоксиду кремнію `SiO2` та `Cr2O3`, який на порядок уповільнює дифузію кисню всередину металу. Зонди типу N демонструють у 5–10 разів менший довготривалий дрейф калібрування при 1100 °C порівняно з типом K і не мають фазових магнітних аномалій.

### Благородні та тугоплавкі типи термопар
Для екстремальних температур застосовують платинові та вольфрам-ренієві сплави:
- **Тип S (Pt-10%Rh / Pt):** від −50 °C до +1600 °C. Чутливість ~10 мкВ/°C. Первинний еталон шкали ITS-90. Висока хімічна інертність в окисних середовищах, але вимагає чисто керамічних гільз із корунду (`Al2O3`), оскільки металеві пари заліза чи кремнію отруюють платину.
- **Тип R (Pt-13%Rh / Pt):** від −50 °C до +1600 °C. Чутливість ~11.5 мкВ/°C. Дещо вища термо-ЕРС порівняно з типом S.
- **Тип B (Pt-30%Rh / Pt-6%Rh):** від 0 °C до +1800 °C. Унікальна властивість: при кімнатній температурі (0..50 °C) вихідна ЕРС становить менше 2–3 мкВ (чутливість близька до нуля), тому для типу B часто взагалі не потрібна компенсація холодного спаю при грубих цехових вимірюваннях.
- **Тип C (W-5%Re / W-26%Re, Вольфрам–Реній):** від 0 °C до +2315 °C. Використовується виключно у глибокому вакуумі або інертних газах (аргон, гелій), оскільки на повітрі вольфрам миттєво згоряє вище 400 °C.

|---|---|---|---|---|
| **K** | Хромель / Алюмель | −200 .. +1260 | ~41 | Універсальна промислова термометрія |

## Конструктивне виконання та типи спаїв

Фізичне оформлення робочого спаю визначає баланс між швидкістю реакції на зміну температури, механічною міцністю та електричною безпекою.

![Конструктивні типи спаїв термопар у захисних гільзах](/root/hw/hw-sensing/thermocouple/img/thermocouple-junction-types.svg)
*Порівняння конструкції відкритого, заземленого та ізольованого спаїв у мінерально-ізольованій гільзі.*

### 1. Відкритий спай (Exposed Junction)
Термоелектродні дроти виходять із захисної трубки назовні, де зварені у відкриту кульку розплаву.
- **Стала часу:** `τ < 0.1 с` у газових потоках.
- **Особливості:** Має найменшу теплову масу. Прямий контакт з газом чи рідиною забезпечує миттєвий теплообмін.
- **Обмеження:** Повна відсутність механічного захисту від стирання пилом і корозії газами. Заборонено використовувати в електропровідних рідинах і середовищах під високим тиском.

### 2. Заземлений спай (Grounded Junction)
Спай вварено безпосередньо в металеве донце герметичної захисної гільзи, утворюючи з нею єдине ціле.
- **Стала часу:** `τ ≈ 0.5–1.5 с` (залежно від товщини стінки).
- **Особливості:** Відмінний тепловий контакт зі стінкою гільзи забезпечує швидку реакцію разом із повним захистом від механічного стирання та тиску (до сотень атмосфер).
- **Небезпека:** Наявність прямого гальванічного контакту між термоелектродами та заземленим металевим корпусом обладнання. Якщо труба чи піч перебуває під потенціалом заземлення або по них протікають струми витоку індукційних нагрівачів, виникають сильні синфазні напруги (`V_cm` до десятків і сотень вольтів) та контури заземлення через плату АЦП, що вимагає обов'язкової дорогої гальванічної розв'язки кожного каналу.

### 3. Ізольований спай (Ungrounded / Isolated Junction)
Спай розміщено всередині гільзи, але він повністю відокремлений від її стінок шаром високощільного спресованого діелектрика (порошку оксиду магнію `MgO` або оксиду алюмінію `Al2O3`).
- **Стала часу:** `τ ≈ 2–5 с`.
- **Особливості:** Повна електрична ізоляція спаю від корпусу гільзи (напруга пробою діелектрика перевищує 500–1000 В постійного струму). Обов'язковий стандарт для багатоканальних систем збору даних (DAQ) зі спільним комутатором АЦП.

Детальний металургійний розбір конструкції гільз, діелектричної деградації `MgO` при нагріванні та теплової динаміки зондів наведено у вставці [🔌 Кабелі MIMS і конструкція захисних гільз термопар](root:hw-sensing/thermocouple/comp-mims-sheaths.md).

## Вимоги до подовжувальних і компенсаційних дротів

Коли термопарний зонд встановлено на технологічному об'єкті (наприклад, на вершині ректифікаційної колони), відстань від спаю до вимірювального щита з АЦП може становити від 10 до 200 метрів. Підключати звичайний мідний кабель безпосередньо до вихідних клем зонда суворо заборонено: стик термопарного дроту з міддю на відкритому повітрі утворює вторинний холодний спай. Якщо температура в зоні клем зонда коливається, напруга на мідній лінії буде непередбачувано дрейфувати.

Для нарощування лінії використовують спеціальні кабелі двох категорій:

```
Зонд у печі                       Клемна коробка зонда                   Щит автоматики (АЦП)
(Гаряча зона)                     (Змінна вулична t°)                    (Ізотермічний блок)
┌─────────────┐  Термопарний      ┌─────────────────┐   Подовжувальний   ┌──────────────────┐
│ Робочий     │  дріт (MIMS)      │ Проміжний стик  │   кабель (KX / KC) │ Холодний спай    │
│ спай        │═══════════════════│ Немає похибки   │════════════════════│ CJC-сенсор + АЦП │
│ T_hot       │                   │ якщо T_1 = T_2  │                    │ T_cj             │
└─────────────┘                   └─────────────────┘                    └──────────────────┘
```

1. **Подовжувальні дроти (Extension wires, маркування з суфіксом «X», наприклад KX, JX, TX, NX):**
   Виготовлені з **тих самих хімічних сплавів**, що й сама термопара (наприклад, кабель KX містить справжні жили з Хромелю та Алюмелю). Оскільки коефіцієнт Зеєбека кабелю ідентичний зонду, проміжне з'єднання не створює паразитної термо-ЕРС при будь-якій температурі стику. Кабелі мають тоншу полімерну ізоляцію (ПВХ, силікон, PTFE), розраховану на помірні температури (до 100–200 °C).
2. **Компенсаційні дроти (Compensating wires, маркування з суфіксом «C», наприклад KC, NC, SC, BC):**
   Виготовлені з **дешевших сплавів-замінників**, які в обмеженому вузькому діапазоні температур (зазвичай від 0 °C до +100 °C або +200 °C) мають термоелектричну характеристику, максимально наближену до дорогої термопари. Наприклад, для дорогої платинової термопари типу S застосовують компенсаційний дріт SC із міді та спеціального мідно-нікелевого сплаву, що заощаджує кілограми коштовної платини при прокладанні довгих кабельних трас.

Історично склалася небезпечна розбіжність між національними стандартами колірного маркування термопарних кабелів:

|---|---|---|---|---|
| **IEC 60584-3** (Міжнародний) | Зелена / Зелений / **Білий** | Чорна / Чорний / **Білий** | Коричнева / Коричневий / **Білий** | Рожева / Рожевий / **Білий** |
| **ANSI MC96.1** (США / Канада) | Жовта / Жовтий / **Червоний** | Чорна / Білий / **Червоний** | Синя / Синій / **Червоний** | Помаранчева / Помаранчевий / **Червоний** |

Монтажник, який помилково підключає червоний дріт американського термопарного кабелю до клеми `+` АЦП, інвертує полярність вимірювального каналу: при нагріванні печі вихідний показник температури на екрані контролера починає не зростати, а спадати.

## Схемотехніка аналогового інтерфейсу та збір даних

Рівень сигналу стандартної термопари становить лише одиниці та десятки мікровольтів на градус: для типу K зміна температури на 1 °C генерує лише `~41.2 мкВ`. При вимірюванні в діапазоні 0..1000 °C вихідна напруга лежить у межах 0..41.276 мВ. 

Такий крихітний сигнал накладає суворі вимоги на аналоговий тракт:

```
 Термопара          Диференційний фільтр НЧ                 Прецизійний АЦП
                    ┌─── R1 (1 кОм) ───┬───────────────────► INP (PGA ×32 / ×64)
                    │                  │
 ─── (V_raw) ───────┤               C_diff (100 нФ)
                    │                  │
                    └─── R2 (1 кОм) ───┴───────────────────► INN
                                       │
                                     C_cm (10 нФ)
                                       │
                                      GND
```

1. **Вхідний інструментальний підсилювач (In-Amp) та дрейф нуля:**
   Напруга зміщення нуля ([offset voltage](root:hw-analog/offset-voltage)) підсилювача повинна бути меншою за 1–2 мкВ, а температурний дрейф зміщення — меншим за `0.05 мкВ/°C` (застосовують автопідстроювання нуля або чопперні підсилювачі класу Auto-Zero / Chopper-Stabilized, наприклад ADA4528, MAX4238).
2. **АЦП високої роздільної здатності:**
   Для досягнення роздільної здатності `0.1 °C` при розмаху шкали 50 мВ крок квантування АЦП має становити менше `4 мкВ`. Класичні 10–12-бітні SAR АЦП мікроконтролерів для цієї задачі непридатні: використовують 16-, 24- або 32-бітні сигма-дельта АЦП (Delta-Sigma ADC, наприклад ADS1248, ADS1118, MCP3421, LTC2983) з інтегрованим малошумним підсилювачем з програмованим коефіцієнтом підсилення (PGA).
3. **Фільтрація синфазних та диференційних завад:**
   Довгі термопарні лінії збирають потужні наведення промислової частоти 50/60 Гц та високочастотні імпульси перемикання ШІМ-інверторів. На вході встановлюють симетричний RC-фільтр: два резистори по 1 кОм, диференційний конденсатор високої якості (C0G/NP0) на 100 нФ між лініями та два синфазних конденсатори по 10 нФ на сигнальну землю. Сигма-дельта модулятор налаштовують на режим цифрового режекторного фільтра (Sinc3/Sinc4) з нулями передавальної характеристики на частотах 50 Гц та 60 Гц (коефіцієнт придушення синфазного сигналу CMRR > 100–120 дБ).
4. **Діагностика обриву лінії (Burnout / Open-Sensor Detection):**
   Якщо термопарний дріт у печі перегорить або обірветься від вібрації, високоомний вхід АЦП зависне в повітрі, вловлюючи наведення та видаючи випадкові значення, що може призвести до аварійного перегріву печі в контурі авторегулювання. Для безпеки входи `INP` та `INN` підтягують високоомними резисторами (10–20 МОм) або слабкими джерелами струму (100–500 нА) до ліній живлення `VDD` та `GND`. При обриві термопари напруга на вході миттєво підскакує до напруги живлення, що детектується компаратором як апаратна аварія (Sensor Fault).

## Алгоритм перетворення напруги в температуру за поліномами NIST

Міжнародний стандарт NIST ITS-90 задає прямі та обернені поліноми для аналітичного розрахунку характеристик термопар без необхідності зберігання гігантських таблиць перерахунку в пам'яті мікроконтролера.

Повний алгоритмічний модуль на C та C++ з вибором температурних зон та схемою Горнера розібрано у вставці [⚙️ Обчислення температури термопари за поліномами NIST ITS-90](root:hw-sensing/thermocouple/proj-nist-polynomial.md).

Нижче наведено базовий фрагмент коду, що демонструє обчислення оберненого полінома для термопари типу K:

:::tabs
```c
#include <stdint.h>
#include <stdbool.h>

/* Коефіцієнти оберненого полінома NIST Type K для діапазону 0..500 °C (мВ -> °C) */
static const double K_INV_POLY_0_500[] = {
    0.000000E+00,  2.508355E+01,  7.860106E-02,
   -2.503131E-01,  8.315270E-02, -1.228034E-02,
    9.804036E-04, -4.413030E-05,  1.057734E-06,
   -1.052755E-08
};

/* Схема Горнера: P(v) = d[0] + v*(d[1] + v*(d[2] + ...)) */
double evaluate_nist_inverse_type_k(double mv_total) {
    const size_t n = sizeof(K_INV_POLY_0_500) / sizeof(K_INV_POLY_0_500[0]);
    double temp = K_INV_POLY_0_500[n - 1];
    for (size_t i = n - 1; i > 0; --i) {
        temp = temp * mv_total + K_INV_POLY_0_500[i - 1];
    }
    return temp;
}
```
```cpp
#include <array>
#include <span>
#include <concepts>

namespace sensing {

/* Коефіцієнти оберненого полінома NIST Type K для діапазону 0..500 °C */
inline constexpr std::array<double, 10> k_inv_poly_0_500 = {
    0.000000E+00,  2.508355E+01,  7.860106E-02,
   -2.503131E-01,  8.315270E-02, -1.228034E-02,
    9.804036E-04, -4.413030E-05,  1.057734E-06,
   -1.052755E-08
};

/* Обчислення полінома за схемою Горнера з перевіркою типів під час компіляції */
template <std::floating_point T>
[[nodiscard]] constexpr T evaluate_nist_horner(std::span<const T> coeffs, T x) noexcept {
    T result = coeffs.back();
    for (auto it = coeffs.rbegin() + 1; it != coeffs.rend(); ++it) {
        result = result * x + *it;
    }
    return result;
}

[[nodiscard]] constexpr double evaluate_type_k_0_to_500(double mv_total) noexcept {
    return evaluate_nist_horner(std::span{k_inv_poly_0_500}, mv_total);
}

} // namespace sensing
```

> 🔧 **Навіщо це: Інженерний чекліст проектування термопарного вузла**
> 
> 1. **Вибір сплаву під атмосферу:** Для чистих окисних повітряних середовищ до 1200 °C обирайте **Тип N** замість типу K, щоб повністю виключити довготривалий дрейф ближнього порядку та деградацію «зеленої гнилі». Для вакууму й водню беріть **Тип J**, для кріогеніки — **Тип T**, для температур вище 1300 °C — платиновий **Тип S** або вольфрамовий **Тип C**.
> 2. **Тип спаю:** Для загальнопромислових щитів і багатоканальних вимірювачів завжди обирайте **ізольований спай (Ungrounded)** у MIMS-гільзі з порошком `MgO`. Заземлений спай беріть виключно тоді, коли критична швидкодія `τ < 1 с` і канал має гарантовану трансформаторну чи оптичну гальванічну розв'язку.
> 3. **Трасування плати:** Розміщуйте мікросхему локального термометра CJC (NTC чи RTD) у безпосередньому тепловому контакті з масивними мідними полігонами вхідних клем. Ніколи не розташовуйте поруч із клемником джерела тепла (лінійні стабілізатори LDO, потужні польові транзистори, резистори підтяжки).
> 4. **Кабельна лінія:** Застосовуйте виключно екрановану кручену пару з подовжувального кабелю відповідного типу (KX для K, JX для J). Екран заземлюйте суворо в **одній точці** — на боці щита керування АЦП.
> 5. **Алгоритм прошивки:** Ніколи не додавайте температури `T_raw + T_cj`. Завжди перетворюйте `T_cj` у напругу `V_cj`, додавайте напруги `V_total = V_raw + V_cj`, і лише після цього обчислюйте фінальну температуру за поліномом Горнера NIST 9-го порядку.
