# ⚙️ Обчислення температури термопари за поліномами NIST ITS-90

Алгоритм високоточного програмного обчислення температури гарячого спаю термопари за виміряною мілівольтовою термо-ЕРС базується на поліномах міжнародного температурного стандарту NIST ITS-90 (англ. *National Institute of Standards and Technology, International Temperature Scale of 1990*).

```
   ┌──────────────────────┐          ┌──────────────────────┐
   │ Напруга клеми V_raw  │          │  Давач клеми T_cj    │
   └──────────┬───────────┘          └──────────┬───────────┘
              │                                 │
              │                      ┌──────────▼───────────┐
              │                      │ Прямий поліном NIST  │
              │                      │   V_cj = f(T_cj)     │
              │                      └──────────┬───────────┘
              │                                 │
              └───────────────┬─────────────────┘
                              ▼
                   ┌──────────────────────┐
                   │  V_tot = V_raw + V_cj │ (додавання ЕРС)
                   └──────────┬───────────┘
                              │
                   ┌──────────▼───────────┐
                   │ Обернений поліном    │
                   │ T_hot = g(V_tot)     │
                   └──────────┬───────────┘
                              │
                              ▼
                   ┌──────────────────────┐
                   │  Температура T_hot   │
                   └──────────────────────┘
```

## Фізична та математична постановка задачі

Термоелектрорушійна сила (термо-ЕРС), що виникає в замкненому колі з двох різнорідних металевих провідників, є суворо нелінійною функцією температури. Диференційний коефіцієнт Зеєбека `S(T) = dV/dT` не є константою: він змінюється залежно від температури внаслідок квантовомеханічних змін енергії Фермі, розсіювання електронів на теплових фононах кристалічної ґратки та магнітних переходів у сплавах (таких як точка Кюрі в Алюмелі чи залізі).

Через це аналітична залежність між напругою на клемах `V` (у мілівольтах) та температурою `T` (у градусах Цельсія) стандартизована NIST у вигляді двох взаємодоповнюючих наборів поліноміальних коефіцієнтів:
1. **Пряме перетворення `V = f(T)`**: використовується для переведення виміряної локальної температури холодного спаю `T_cj` (оцифрованої за допомогою NTC чи RTD) в еквівалентну термо-ЕРС `V_cj`, яку згенерувала б термопара між 0 °C та `T_cj`.
2. **Обернене перетворення `T = g(V)`**: використовується для переведення сумарної термо-ЕРС `V_total = V_raw + V_cj` у фінальну фізичну температуру гарячого спаю `T_hot`.

### Структура прямого полінома NIST

Для стандартних термопар пряме рівняння має степеневий вигляд із додатковим експоненційним доданком для компенсації магнітних та фазових аномалій сплавів:

```
V = c₀ + c₁·T + c₂·T² + c₃·T³ + ... + c_N·T^N + α₀ · exp(α₁ · (T - α₂)^2)
```

Для термопари типу K у діапазоні від 0 °C до 1372 °C використовують поліном 9-го степеня та експоненційний коригувальний член із коефіцієнтами:
- `α₀ = 0.1185976`
- `α₁ = -0.0001183432`
- `α₂ = 126.9686`

Цей експоненційний член моделює характерний прогин чутливості нікелевого сплаву Алюмель навколо температури 127–160 °C, де відбувається зникнення феромагнітного порядку. Без урахування цього доданка похибка прямого розрахунку напруги холодного спаю досягає 0.15 мВ, що еквівалентно похибці майже 4 °C.

### Структура оберненого полінома NIST

Обернене рівняння розбивається на кілька температурних піддіапазонів для забезпечення високої точності апроксимації (максимальна похибка інтерполяції не перевищує `±0.05 °C` у всьому діапазоні):

```
T = d₀ + d₁·V + d₂·V² + d₃·V³ + ... + d_M·V^M
```

Для термопари типу K робочий діапазон розділено на три ділянки:
- **Піддіапазон 1** (від −200 °C до 0 °C, напруга від −5.891 мВ до 0.000 мВ): поліном 8-го степеня (9 коефіцієнтів);
- **Піддіапазон 2** (від 0 °C до 500 °C, напруга від 0.000 мВ до 20.644 мВ): поліном 9-го степеня (10 коефіцієнтів);
- **Піддіапазон 3** (від 500 °C до 1372 °C, напруга від 20.644 мВ до 54.886 мВ): поліном 6-го степеня (7 коефіцієнтів).

## Схема Горнера та обчислювальна стабільність

Пряме піднесення напруги `V` до степенів `V²`, `V³`, ..., `V⁹` через стандартну функцію `pow(v, i)` або цикл множення має три критичні недоліки у вбудованих системах:
1. **Чисельна нестабільність:** При напрузі `V = 10 мВ = 0.01 В` значення `V⁹` досягає величини порядку `10⁻¹⁸`. Множення такого мізерного числа на коефіцієнт `d₉ ≈ 10¹⁴` призводить до катастрофічної втрати молодших розрядів мантиси у форматі IEEE 754;
2. **Продуктивність на MCU:** Виклик `pow()` на мікроконтролерах без апаратного модуля FPU (Cortex-M0, Cortex-M3) вимагає сотень тактів процесора на кожен степінь;
3. **Накопичення похибок округлення:** Додавання чисел принципово різного порядку величини призводить до машинного витискання значущих цифр.

Для усунення цих проблем обчислення полінома виконують за **схемою Горнера**, що зводить весь процес до `N` послідовних операцій множення та додавання (множення з накопиченням, FMA):

```
P(x) = d₀ + x · (d₁ + x · (d₂ + x · (d₃ + ... + x · d_N)...))
```

Схема Горнера гарантує мінімальну похибку округлення, оскільки проміжні добутки завжди масштабуються до співмірних величин.

## Наскрізний числовий приклад розрахунку

Розглянемо покрокове виконання алгоритму на реальних фізичних значеннях:
1. **Вимірювання:**
   - Прецизійний сигма-дельта АЦП виміряв на клемах напругу `V_raw = 34.925 мВ`;
   - Локальний сенсор NTC на клемах показав температуру `T_cj = 25.0 °C`.
2. **Крок 1 (Прямий поліном):**
   - Обчислюємо еквівалентну напругу холодного спаю для `T_cj = 25.0 °C`;
   - Базовий поліном дає `0.957 мВ`, а експоненційний доданок Алюмелю додає `0.043 мВ`;
   - Отримуємо `V_cj = 1.000 мВ`.
3. **Крок 2 (Додавання ЕРС):**
   - Знаходимо сумарну термо-ЕРС відносно 0 °C:
     ```
     V_total = 34.925 + 1.000 = 35.925 мВ
     ```
4. **Крок 3 (Вибір діапазону та обернений поліном):**
   - Оскільки `V_total = 35.925 мВ` потрапляє в діапазон від 20.644 мВ до 54.886 мВ, обираємо Піддіапазон 3 (поліном 6-го степеня для 500..1372 °C);
   - Обчислення за схемою Горнера дає точну температуру гарячого спаю `T_hot = 865.4 °C`.

*(Якби ми припустилися грубої помилки й додали температури напряму: `g(34.925 мВ) = 842.1 °C`, плюс `25.0 °C`, отримали б `867.1 °C`. Різниця у `+1.7 °C` виникла виключно через нелінійність кривої Зеєбека між 25 °C та 865 °C).*

## Реалізація обчислювача NIST на C та C++

Наведений код реалізує промисловий модуль розрахунку температури термопари типу K з виявленням апаратних несправностей (обрив зонда, вихід за діапазон, несправність холодного спаю) та високою швидкодією.

```c
#include <stdio.h>
#include <math.h>
#include <stdbool.h>
#include <stddef.h>

/* Коди результату виконання розрахунку */
typedef enum {
    TC_OK = 0,
    TC_ERR_COLD_JUNCTION_OUT_OF_RANGE,
    TC_ERR_VOLTAGE_OUT_OF_RANGE,
    TC_ERR_SENSOR_BURNOUT
} tc_status_t;

/* Обчислення полінома за схемою Горнера: a[0] + x*a[1] + ... + x^n * a[n] */
static double horner_eval(const double *coeffs, size_t count, double x) {
    double result = coeffs[count - 1];
    for (size_t i = count - 1; i > 0; --i) {
        result = result * x + coeffs[i - 1];
    }
    return result;
}

/* Прямий поліном NIST Type K: T (°C) -> V (мВ) */
static double nist_type_k_temp_to_mv(double temp_c) {
    if (temp_c < 0.0) {
        /* Діапазон -200..0 °C (11 коефіцієнтів) */
        static const double c_neg[] = {
            0.000000000000E+00,  3.945012802500E-02,  2.362237359800E-05,
           -3.285890678400E-07, -4.990482877700E-09, -6.750905917300E-11,
           -5.741032742800E-13, -3.108894161400E-15, -1.045160936500E-17,
           -1.988926677800E-20, -1.632269748600E-23
        };
        return horner_eval(c_neg, sizeof(c_neg) / sizeof(c_neg[0]), temp_c);
    } else {
        /* Діапазон 0..1372 °C (10 коефіцієнтів + експонента) */
        static const double c_pos[] = {
           -1.760041368600E-02,  3.892120497500E-02,  1.855877003200E-05,
           -9.945759287400E-08,  3.184094571900E-10, -5.607284488900E-13,
            5.607505905900E-16, -3.202072444000E-19,  9.715114715200E-23,
           -1.210472127500E-26
        };
        double v = horner_eval(c_pos, sizeof(c_pos) / sizeof(c_pos[0]), temp_c);
        /* Експоненційний доданок для фазового переходу Алюмелю */
        double a0 = 0.1185976;
        double a1 = -0.0001183432;
        double a2 = 126.9686;
        double exp_term = a0 * exp(a1 * (temp_c - a2) * (temp_c - a2));
        return v + exp_term;
    }
}

/* Обернений поліном NIST Type K: V (мВ) -> T (°C) */
static double nist_type_k_mv_to_temp(double mv) {
    if (mv < 0.0) {
        /* Піддіапазон 1: -200..0 °C (-5.891..0.000 мВ, 9 коефіцієнтів) */
        static const double d_sub1[] = {
            0.0000000E+00,  2.5173462E+01, -1.1662878E+00,
           -1.0833638E+00, -8.9773540E-01, -3.7342377E-01,
           -8.6632643E-02, -1.0450598E-02, -5.1920577E-04
        };
        return horner_eval(d_sub1, sizeof(d_sub1) / sizeof(d_sub1[0]), mv);
    } else if (mv <= 20.644) {
        /* Піддіапазон 2: 0..500 °C (0.000..20.644 мВ, 10 коефіцієнтів) */
        static const double d_sub2[] = {
            0.000000E+00,  2.508355E+01,  7.860106E-02,
           -2.503131E-01,  8.315270E-02, -1.228034E-02,
            9.804036E-04, -4.413030E-05,  1.057734E-06,
           -1.052755E-08
        };
        return horner_eval(d_sub2, sizeof(d_sub2) / sizeof(d_sub2[0]), mv);
    } else {
        /* Піддіапазон 3: 500..1372 °C (20.644..54.886 мВ, 7 коефіцієнтів) */
        static const double d_sub3[] = {
           -1.318058E+02,  4.830222E+01, -1.646031E+00,
            5.464731E-02, -9.650715E-04,  8.802193E-06,
           -3.110810E-08
        };
        return horner_eval(d_sub3, sizeof(d_sub3) / sizeof(d_sub3[0]), mv);
    }
}

/* Повний конвеєр розрахунку температури з компенсацією холодного спаю */
tc_status_t thermocouple_type_k_calculate(double raw_mv, double cj_temp_c, double *out_temp_c) {
    /* Перевірка валідності температури холодного спаю (плата від -40 до +85 °C) */
    if (cj_temp_c < -50.0 || cj_temp_c > 125.0) {
        return TC_ERR_COLD_JUNCTION_OUT_OF_RANGE;
    }

    /* Виявлення обриву зонда: резистори підтяжки зміщують вхід вище 60 мВ */
    if (raw_mv > 65.0 || raw_mv < -10.0) {
        return TC_ERR_SENSOR_BURNOUT;
    }

    /* Етап A: Отримуємо еквівалентну напругу холодного спаю */
    double v_cj = nist_type_k_temp_to_mv(cj_temp_c);

    /* Етап B: Додаємо виміряну термо-ЕРС до напруги холодного спаю */
    double v_total = raw_mv + v_cj;

    /* Перевірка допустимих фізичних меж Type K (-5.891 мВ .. 54.886 мВ) */
    if (v_total < -5.891 || v_total > 54.886) {
        return TC_ERR_VOLTAGE_OUT_OF_RANGE;
    }

    /* Етап C: Обчислюємо температуру гарячого спаю через обернений поліном */
    *out_temp_c = nist_type_k_mv_to_temp(v_total);
    return TC_OK;
}
```

```cpp
#include <array>
#include <span>
#include <cmath>
#include <expected>
#include <concepts>

namespace sensing {

enum class ThermocoupleError {
    ColdJunctionOutOfRange,
    VoltageOutOfRange,
    SensorBurnout
};

enum class ThermocoupleType {
    TypeK,
    TypeJ
};

class NistThermocoupleCalculator {
public:
    /* Схема Горнера для constexpr-масивів коефіцієнтів */
    template <std::floating_point T>
    [[nodiscard]] static constexpr T horner_eval(std::span<const T> coeffs, T x) noexcept {
        T result = coeffs.back();
        for (auto it = coeffs.rbegin() + 1; it != coeffs.rend(); ++it) {
            result = result * x + *it;
        }
        return result;
    }

    /* Прямий поліном NIST Type K: T (°C) -> V (мВ) */
    [[nodiscard]] static double type_k_temp_to_mv(double temp_c) noexcept {
        if (temp_c < 0.0) {
            static constexpr std::array<double, 11> c_neg = {
                0.000000000000E+00,  3.945012802500E-02,  2.362237359800E-05,
               -3.285890678400E-07, -4.990482877700E-09, -6.750905917300E-11,
               -5.741032742800E-13, -3.108894161400E-15, -1.045160936500E-17,
               -1.988926677800E-20, -1.632269748600E-23
            };
            return horner_eval(std::span{c_neg}, temp_c);
        }

        static constexpr std::array<double, 10> c_pos = {
           -1.760041368600E-02,  3.892120497500E-02,  1.855877003200E-05,
           -9.945759287400E-08,  3.184094571900E-10, -5.607284488900E-13,
            5.607505905900E-16, -3.202072444000E-19,  9.715114715200E-23,
           -1.210472127500E-26
        };
        constexpr double a0 = 0.1185976;
        constexpr double a1 = -0.0001183432;
        constexpr double a2 = 126.9686;

        const double base_v = horner_eval(std::span{c_pos}, temp_c);
        const double exp_term = a0 * std::exp(a1 * (temp_c - a2) * (temp_c - a2));
        return base_v + exp_term;
    }

    /* Обернений поліном NIST Type K: V (мВ) -> T (°C) */
    [[nodiscard]] static double type_k_mv_to_temp(double mv) noexcept {
        if (mv < 0.0) {
            static constexpr std::array<double, 9> d_sub1 = {
                0.0000000E+00,  2.5173462E+01, -1.1662878E+00,
               -1.0833638E+00, -8.9773540E-01, -3.7342377E-01,
               -8.6632643E-02, -1.0450598E-02, -5.1920577E-04
            };
            return horner_eval(std::span{d_sub1}, mv);
        } else if (mv <= 20.644) {
            static constexpr std::array<double, 10> d_sub2 = {
                0.000000E+00,  2.508355E+01,  7.860106E-02,
               -2.503131E-01,  8.315270E-02, -1.228034E-02,
                9.804036E-04, -4.413030E-05,  1.057734E-06,
               -1.052755E-08
            };
            return horner_eval(std::span{d_sub2}, mv);
        } else {
            static constexpr std::array<double, 7> d_sub3 = {
               -1.318058E+02,  4.830222E+01, -1.646031E+00,
                5.464731E-02, -9.650715E-04,  8.802193E-06,
               -3.110810E-08
            };
            return horner_eval(std::span{d_sub3}, mv);
        }
    }

    /* Повний розрахунок з компенсацією холодного спаю */
    [[nodiscard]] static std::expected<double, ThermocoupleError> calculate_temperature(
        double raw_mv, double cj_temp_c, ThermocoupleType type = ThermocoupleType::TypeK) noexcept {
        
        if (cj_temp_c < -50.0 || cj_temp_c > 125.0) {
            return std::unexpected(ThermocoupleError::ColdJunctionOutOfRange);
        }

        if (raw_mv > 65.0 || raw_mv < -10.0) {
            return std::unexpected(ThermocoupleError::SensorBurnout);
        }

        if (type == ThermocoupleType::TypeK) {
            const double v_cj = type_k_temp_to_mv(cj_temp_c);
            const double v_total = raw_mv + v_cj;

            if (v_total < -5.891 || v_total > 54.886) {
                return std::unexpected(ThermocoupleError::VoltageOutOfRange);
            }

            return type_k_mv_to_temp(v_total);
        }

        return std::unexpected(ThermocoupleError::VoltageOutOfRange);
    }
};

} // namespace sensing
```

## Діагностика відмов та аномальних станів зонда

Промисловий контролер повинен не лише обчислювати температуру за номінальним поліномом, але й розпізнавати аварійні режими каналу:

1. **Обрив чутливого елемента (Burnout):**
   При механічному перериванні дроту вхідні резистори підтяжки (наприклад, 10 МОм до `VDD` на лінії `INP` та 10 МОм до `GND` на лінії `INN`) заганяють диференційний вхід АЦП у стан позитивного насичення (напруга > 65 мВ). Алгоритм фіксує помилку `TC_ERR_SENSOR_BURNOUT`, переводить регулятор нагріву в безпечний режим (вимкнення ТЕНів) і виставляє аварійний прапорець.
2. **Коротке замикання на клемах або кабелі:**
   Якщо ізоляція кабелю перетерлася, або вхід замкнуто металевою стружкою, виміряна напруга `V_raw` стає строго рівною 0.000 мВ. У результаті алгоритм видає `T_hot = T_cj`. Якщо в робочому режимі печі температура технологічного процесу стає рівною температурі навколишнього середовища всередині шафи автоматики, це є ознакою короткого замикання лінії.
3. **Переполюсовка підключення:**
   При переплутуванні проводів місцями `V_raw` стає від'ємною при нагріванні печі. Сумарна напруга `V_total = V_raw + V_cj` швидко падає нижче мінімальної фізичної межі −5.891 мВ, викликаючи статус `TC_ERR_VOLTAGE_OUT_OF_RANGE`.
