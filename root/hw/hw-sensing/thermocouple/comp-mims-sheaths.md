# 🔌 Кабелі MIMS і конструкція захисних гільз термопар

Кабель з мінеральною ізоляцією в металевій оболонці (англ. *Mineral Insulated Metal Sheathed*, MIMS) є основним промисловим стандартом виготовлення надійних термопарних зондів для важких умов експлуатації: високих температур (до 1300 °C), тиску в сотні бар, вібрацій та агресивних хімічних середовищ.

```

       │  ░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░  │

       │  ░░  ░░░░░░░░ Оксид магнію (MgO) ░░░░░░░░░░░░░░░  ░░  │
       │  ░░  ════════════════════════════════════════════  ░░  │ ◄── Провідник B (−)
```

## Технологія виробництва кабелів MIMS

Кабель MIMS виготовляють протягуванням суцільної металевої труби великого діаметра, всередину якої вставлено товсті термоелектродні дроти, оточені попередньо сформованими керамічними циліндрами або порошком оксиду магнію (`MgO`) високої хімічної чистоти (не менше 99.4–99.6%). Оксид магнію обирають завдяки унікальному поєднанню високої теплопровідності (близько 30–40 Вт/(м·К) при кімнатній температурі), чудових діелектричних властивостей та високої температури плавлення (понад 2800 °C).

Заготовку багаторазово протягують крізь калібрувальні фільєри (волочіння) з проміжним термообробленням (відпалом). У процесі волочіння зовнішній діаметр кабелю зменшується від початкових 25–50 мм до фінальних розмірів: стандартні значення становлять 0.5 мм, 1.0 мм, 1.5 мм, 3.0 мм, 4.5 мм, 6.0 мм та 8.0 мм. Порошок `MgO` всередині труби зазнає екстремального механічного стиснення, досягаючи понад 85–90% від теоретичної густини монолітного кристала. 

Завдяки такій щільності кабель набуває властивостей псевдомонолітного стрижня:
- Усередині оболонки повністю відсутнє повітря, що виключає внутрішнє окиснення термоелектродів при робочих температурах;
- Провідники жорстко зафіксовані у просторі, унеможливлюючи внутрішні короткі замикання навіть під час сильних вібрацій або багаторазового згинання (допустимий радіус вигину становить `r ≥ 3–5` зовнішніх діаметрів гільзи);
- Забезпечується прямий, безповітряний тепловий контакт між зовнішньою стінкою гільзи та чутливими дротами через щільний шар діелектрика.

## Технологія формування та зварювання спаю

Кінець кабелю MIMS обробляють залежно від типу необхідного спаю:

1. **Формування відкритого спаю:** З кінця оболонки механічно чи хімічно видаляють 5–10 мм металу оболонки та порошку `MgO`. Кінці термоелектродів очищають і зварюють мікро-TIG (дуговим зварюванням у середовищі аргону) або лазерним імпульсом, утворюючи гладку сферичну кульку розплаву. Відкритий зріз `MgO` герметизують високотемпературним цементом або керамічним компаундом.
2. **Формування заземленого спаю:** Оболонку зачищають урівень, термоелектроди зводять разом із крайкою металевої гільзи й заварюють єдиним розплавом за допомогою аргонодугового зварювання. Утворюється герметична купольна заглушка гільзи, де спай є монолітною частиною оболонки.
3. **Формування ізольованого спаю:** Провідники зварюють між собою всередині гільзи без електричного торкання стінок, порожнину заповнюють гранульованим сухим `MgO`, після чого в торець запресовують і герметично приварюють суцільне металеве донце (диск) з того ж матеріалу, що й оболонка.

## Деградація опору ізоляції (R_ins) при високих температурах

Критичним фізичним обмеженням кабелів MIMS є різке падіння електричного опору діелектрика `MgO` при нагріванні. При кімнатній температурі опір ізоляції сухого `MgO` перевищує `10¹² Ом·м`. Проте з ростом температури в іонній кристалічній ґратці експоненційно зростає концентрація та рухливість теплових дефектів і вільних іонів магнію й кисню.

Питомий опір `ρ(T)` оксиду магнію спадає за законом Арреніуса:

```
ρ(T) = ρ₀ · exp(E_a / (k_B · T))
```

де `E_a` — енергія активації іонної провідності (близько 2.0–2.5 еВ), `k_B` — стала Больцмана.

Внаслідок цього опір ізоляції між електродами кабелю діаметром 1.5 мм довжиною 1 метр падає з `> 10 000 МОм` при 20 °C до `~ 10–50 кОм` при 1000 °C і нижче `1 кОм` при 1200 °C.

```
       Т_гаряче = 1100 °C             Т_зона_печі = 1000 °C             Т_клеми = 25 °C
       (Робочий спай)                 (Кабель у шахті печі)            (Вимірювач)
       ┌───────────┐                  ┌───────────────────┐            ┌─────────┐
       │   Спай    │══════════════════│    R_витік (MgO)  │════════════│   АЦП   │
       │  V_seebeck│                  │      ~10 кОм      │            │         │
       └───────────┘══════════════════│  (шунтує сигнал)  │════════════└─────────┘
                                      └───────────────────┘
```

Це явище створює паразитний розподілений опір витоку вздовж кабелю. Якщо найгарячіша зона печі знаходиться не на кінці зонда, а посередині його довжини, низький опір `MgO` шунтує лінію, утворюючи «віртуальний паразитичний спай» у середині кабелю. Сигнал, який доходить до АЦП, стає викривленою сумішшю напруг від справжнього кінця зонда та шунтованої гарячої ділянки. Для мінімізації цього ефекту в надвисокотемпературних зонах збільшують товщину оболонки кабелю (діаметр від 3.0 до 6.0 мм) та використовують виключно надчистий `MgO` (99.8% UHP).

## Гідрофільність MgO та конструкція холодного переходу (Pot Seal)

Порошок оксиду магнію є надзвичайно гігроскопічним (жадібно поглинає вологу з повітря), перетворюючись на гідроксид магнію `Mg(OH)2`:

```
MgO + H₂O → Mg(OH)₂
```

Гідроксид магнію має опір ізоляції на 6–8 порядків нижчий за сухий оксид, що призводить до негайного виходу кабелю з ладу при проникненні навіть мікрограмів водяної пари з цехового повітря.

Для запобігання зволоженню холодний кінець зонда MIMS оформлюють у вигляді герметичного перехідного вузла — так званого піт-силу (англ. *pot seal*):
1. Металеву втулку (перехідну муфту) обтискають або приварюють до торця гільзи MIMS;
2. Зріз `MgO` просушують нагрівом до 200–300 °C;
3. Внутрішній об'єм муфти заливають спеціальною двокомпонентною високотемпературною епоксидною смолою або керамічним склом (герметик класу IP67/IP68);
4. З муфти виводять гнучкий подовжувальний кабель із полімерною ізоляцією (PTFE або силікон).

## Теплова динаміка та стала часу τ

Швидкість реакції термопарного зонда на стрибок температури описується експоненційною моделлю першого порядку:

```
T(t) = T_кінц + (T_поч - T_кінц) · exp(-t / τ)
```

де стала часу `τ` (tau) визначає час, за який показ покажчика змінюється на `1 - 1/e ≈ 63.2%` від амплітуди температурного стрибка:

```
τ = (m · c) / (h · A)
```

де `m` — маса чутливого вузла, `c` — питома теплоємність, `h` — коефіцієнт тепловіддачі середовища (конвекція), `A` — площа поверхні теплообміну.

| Тип спаю та діаметр гільзи | τ у воді, що рухається (v = 0.4 м/с) | τ у повітрі, що рухається (v = 2 м/с) |
|---|---|---|
| **Відкритий спай (дріт 0.5 мм)** | 0.05 с | 0.8 с |
| **Заземлений MIMS Ø 1.0 мм** | 0.15 с | 2.5 с |
| **Ізольований MIMS Ø 1.0 мм** | 0.4 с | 4.0 с |
| **Заземлений MIMS Ø 3.0 мм** | 0.6 с | 9.0 с |
| **Ізольований MIMS Ø 3.0 мм** | 1.8 с | 18.0 с |
| **Ізольований MIMS Ø 6.0 мм** | 4.5 с | 55.0 с |

З таблиці видно, що заземлений спай забезпечує у 2.5–3 рази вищу швидкодію, ніж ізольований спай однакового діаметра, проте вимагає обов'язкової гальванічної розв'язки вимірювального каналу для запобігання спотворенню сигналу синфазними струмами.
