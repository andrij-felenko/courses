# 🧮 Виведення співвідношень Кельвіна через взаємність Онзагера

Коли крізь неоднорідно нагрітий провідник одночасно протікають електричний струм і тепловий потік, у системі виникає перехресне квантово-кінетичне зв'язування термодинамічних сил і потоків. Вільям Томсон (лорд Кельвін) у 1854 році встановив фундаментальні зв'язки між термоелектричними коефіцієнтами на основі квазістатичної рівноважної термодинаміки. Суворе мікроскопічне й нерівноважне феноменологічне обґрунтування ці зв'язки отримали у XX столітті завдяки термодинаміці незворотних процесів Ларса Онзагера (*Lars Onsager*) та кінетичному рівнянню Больцмана.

Розглянемо термодинамічну систему, де перенесення електричного заряду нерозривно супроводжується перенесенням внутрішньої теплової енергії та ентропії (від грец. *entropia* — перетворення, повернення).

## 1. Спряжені термодинамічні потоки й узагальнені сили

Густина швидкості локальної генерації ентропії `σ_s` (у Вт/(м³·К)) в одновимірній відкритій системі за наявності градієнтів електричного потенціалу та температури визначається як сума добутків термодинамічних потоків `J_i` на відповідні спряжені термодинамічні сили `X_i`:

```
σ_s
= J_e · X_e + J_Q · X_Q             [швидкість генерації ентропії як білінійна форма потоків і сил]
```

У цій системі беруть участь два макроскопічні потоки:
1. `J_e` — густина електричного струму (А/м²), що переносить сумарний електричний заряд носіїв.
2. `J_Q` — густина теплового потоку (Вт/м²), яка визначається як потік повної енергії за вирахуванням конвективного перенесення хімічного потенціалу: `J_Q = J_U - (μ / q) · J_e`.

Узагальнені термодинамічні сили виводяться з диференціала ентропії Гіббса і виражаються через просторовий градієнт електрохімічного потенціалу `μ_ec` та градієнт абсолютної температури `T`:

```
X_e
= - ∇( μ_ec / q ) / T                [узагальнена термодинамічна сила для електричного заряду]
= - ∇( -V + μ / q ) / T              [розклад на електростатичний потенціал V та хімічний потенціал μ]
= ( E - ∇μ / q ) / T                 [вираз через напруженість електричного поля E = -∇V]

X_Q
= ∇( 1 / T )                         [узагальнена термодинамічна сила для теплового потоку]
= - ( 1 / T² ) · ∇T                  [градієнт оберненої температури за правилом диференціювання]
```

Для макроскопічних систем у квазірівноважному лінійному наближенні (коли градієнти є малими збуреннями відносно локального термодинамічного стану) зв'язок між потоками й силами записується у вигляді системи лінійних феноменологічних рівнянь Онзагера:

```
J_e
= L_11 · X_e + L_12 · X_Q            [електричний струм: омічний дрейф + термодифузійний потік]

J_Q
= L_21 · X_e + L_22 · X_Q            [тепловий потік: перенесення тепла струмом + теплопровідність Фур'є]
```

## 2. Теорема взаємності Онзагера та мікроскопічна оборотність

Кінетичні коефіцієнти `L_ij` утворюють матрицю транспортних властивостей матеріалу. Головний принцип термодинаміки незворотних процесів полягає в тому, що за відсутності зовнішнього магнітного поля матриця кінетичних коефіцієнтів є симетричною:

```
L_12
= L_21                               [співвідношення взаємності Онзагера в нульовому магнітному полі]
```

Мікроскопічним підґрунтям цієї симетрії є інваріантність квантовомеханічних рівнянь руху (рівняння Шредінгера та матриці розсіювання Гамільтона) щодо операції звернення часу `t → -t` (*T-symmetry / microscopic reversibility*). Імовірність переходу електрона зі стану з квазіімпульсом `k` у стан `k'` під дією розсіювання на фононах чи домішках точно дорівнює імовірності зворотного переходу `k' → k` у стані термодинамічної рівноваги:

```
W(k → k')
= W(-k' → -k)                        [принцип детальної мікроскопічної рівноваги переходів]
```

Це фундаментальне твердження доводить, що термоелектричні явища не є двома незалежними ефектами, а являють собою прямий і зворотний прояви одного й того самого механізму міжфазного та об'ємного транспорту енергії й заряду.

## 3. Зв'язок феноменологічних коефіцієнтів із фізичними константами

Зв'яжемо феноменологічні кінетичні коефіцієнти `L_11`, `L_12`, `L_21`, `L_22` з експериментально вимірюваними макроскопічними властивостями твердого тіла: питомою електропровідністю `σ`, абсолютним коефіцієнтом Зеєбека `S` та питомою теплопровідністю `κ`.

### Крок 1: Ізотермічний провідник (`∇T = 0 → X_Q = 0`)
Нехай провідник перебуває в однорідному температурному полі. Тоді `X_Q = 0`, і перше рівняння набуває вигляду:

```
J_e
= L_11 · X_e                         [підстановка умови ізотермічності X_Q = 0]
= L_11 · ( E / T )                   [вираз сили X_e при однорідному хімічному потенціалі ∇μ = 0]
```

За законом Ома в диференціальній формі `J_e = σ · E`. Зіставляючи коефіцієнти, отримуємо діагональний кінетичний коефіцієнт:

```
L_11
= σ · T                              [зв'язок діагонального коефіцієнта з питомою електропровідністю]
```

### Крок 2: Ефект Зеєбека в розімкненому колі (`J_e = 0, ∇T ≠ 0`)
Якщо коло розімкнене, густина електричного струму дорівнює нулю (`J_e = 0`), незважаючи на наявність градієнта температури `∇T`. Підставимо цю умову в перше феноменологічне рівняння:

```
0
= L_11 · X_e + L_12 · X_Q            [умова відсутності результуючого електричного струму в розімкненому зразку]

X_e
= - ( L_12 / L_11 ) · X_Q            [вираження електричної сили через градієнт температури]

( E_th / T )
= - ( L_12 / (σ · T) ) · ( - ∇T / T² )  [підстановка виразів для L_11 та температурної сили X_Q]

E_th
= - ( L_12 / (σ · T²) ) · ∇T         [результуюча напруженість внутрішнього термоелектричного поля]
```

За феноменологічним означенням коефіцієнта Зеєбека `E_th = S · ∇T`. Прирівнюючи коефіцієнти при `∇T`:

```
S
= - L_12 / ( σ · T² )                [вираз коефіцієнта Зеєбека через недіагональний кінетичний коефіцієнт]

L_12
= - S · σ · T²                       [значення коефіцієнта L_12 через термо-ЕРС S та електропровідність σ]
```

### Крок 3: Ефект Пельтьє в ізотермічному зразку зі струмом (`∇T = 0 → X_Q = 0`)
Нехай крізь зразок протікає електричний струм `J_e` за повної відсутності температурного градієнта (`∇T = 0`). Друге феноменологічне рівняння описує конвективне перенесення тепла електричним струмом:

```
J_Q
= L_21 · X_e                         [підстановка X_Q = 0 у рівняння теплового потоку]
= L_21 · ( J_e / L_11 )              [вираження сили X_e через густину струму J_e з першого рівняння]
= ( L_21 / (σ · T) ) · J_e           [підстановка значення L_11 = σ · T]
```

За означенням коефіцієнта Пельтьє `Π`, густина теплового потоку, що переноситься струмом, становить `J_Q = Π · J_e`:

```
Π
= L_21 / ( σ · T )                   [коефіцієнт Пельтьє через недіагональний кінетичний коефіцієнт L_21]

L_21
= Π · σ · T                          [значення коефіцієнта L_21 через коефіцієнт Пельтьє Π]
```

## 4. Строге виведення першого співвідношення Кельвіна

Застосуємо теорему взаємності Онзагера `L_12 = L_21` до отриманих виразів для `L_12` та `L_21`. З урахуванням від'ємного заряду електронів як основних носіїв струму:

```
L_21
= L_12                               [теорема взаємності Онзагера]

Π · σ · T
= S · σ · T²                         [підстановка отриманих виразів для L_21 та L_12]

Π
= S · T                              [перше співвідношення Кельвіна після скорочення на σ · T]
```

Перше співвідношення Кельвіна `Π = S · T` встановлює точний кількісний зв'язок між генерацією напруги у градієнті температур та виділенням теплоти на контактній межі під дією струму.

## 5. Мікроскопічне виведення через кінетичне рівняння Больцмана

Для глибокого розуміння фізики термоелектричних явищ виведемо коефіцієнти з кінетичної теорії електронного газу. У наближенні часу релаксації (*Relaxation Time Approximation, RTA*) стаціонарне одновимірне рівняння Больцмана має вигляд:

```
v_x · ( ∂f / ∂x ) - ( e · E_x / m* ) · ( ∂f / ∂v_x )
= - ( f - f_0 ) / τ(E)               [кінетичне рівняння Больцмана з часом релаксації τ(E)]
```

Тут `f_0(E) = 1 / (exp((E - μ)/(k_B·T)) + 1)` — рівноважна функція розподілу Фермі-Дірака. Розв'язок для малої нерівноважної добавки `f_1 = f - f_0` виражається через похідні:

```
f_1
= - τ(E) · v_x · [ ( - ∂f_0 / ∂E ) · e · E' + ( - ∂f_0 / ∂E ) · ( (E - μ) / T ) · ∇T ]  [лінеаризована нерівноважна добавка до функції розподілу]
```

Тут `E' = E - (1/e) · ∇μ` — ефективне електрохімічне поле.

Введемо узагальнені транспортні інтеграли `K_n`:

```
K_n
= ( 2 / (3 · m*) ) · ∫ [0 .. ∞] ( E^n · τ(E) · g(E) · ( - ∂f_0 / ∂E ) ) dE  [інтеграли кінетичного транспорту n-го порядку]
```

Густина електричного струму `J_e` та теплового потоку `J_Q` через інтеграли `K_n` набувають вигляду:

```
J_e
= e² · K_0 · E' - ( e / T ) · K_1 · ∇T       [електричний струм через кінетичні інтеграли K_0 та K_1]

J_Q
= - e · K_1 · E' + ( 1 / T ) · K_2 · ∇T      [тепловий потік через кінетичні інтеграли K_1 та K_2]
```

Порівнюючи з макроскопічними законами:
1. Питома провідність: `σ = e² · K_0`.
2. Коефіцієнт Зеєбека (`J_e = 0`):
```
S
= - ( 1 / (e · T) ) · ( K_1 / K_0 )          [мікроскопічний вираз коефіцієнта Зеєбека через відношення K_1/K_0]
= - ( 1 / (e · T) ) · ( <E - μ> )            [коефіцієнт Зеєбека як середня теплова енергія на носій заряду]
```
3. Коефіцієнт Пельтьє (`∇T = 0`):
```
Π
= - ( 1 / e ) · ( K_1 / K_0 )                [мікроскопічний вираз коефіцієнта Пельтьє]
```

Ділячи вираз для `Π` на вираз для `S`:

```
Π / S
= [ - ( 1 / e ) · ( K_1 / K_0 ) ] / [ - ( 1 / (e · T) ) · ( K_1 / K_0 ) ]  [відношення мікроскопічних виразів]
= T                                  [повне скорочення кінетичних інтегралів дає абсолютну температуру T]

Π
= S · T                              [перше співвідношення Кельвіна з кінетичної теорії твердого тіла]
```

Це доводить, що перше співвідношення Кельвіна є точним квантово-статистичним наслідком незалежно від конкретного закону дисперсії носіїв `E(k)` та мікроскопічного механізму розсіювання (на фононах, домішках чи межах зерен).

## 6. Виведення другого співвідношення Кельвіна (ефект Томсона)

Розглянемо баланс оборотного теплообміну вздовж неоднорідно нагрітого провідника зі струмом `I`.

Повна швидкість зміни теплового потоку `dQ/dx` вздовж координати `x` складається з трьох компонент:
1. Незворотного джоулевого тепла `I² · R(x)`;
2. Просторово змінної конвективної теплоти Пельтьє `d(Π · I)/dx = (dΠ/dT) · (dT/dx) · I`;
3. Електричної потужності, що виконується внутрішнім термоелектричним полем `E_th = S · (dT/dx)` проти протікаючого струму: `S · (dT/dx) · I`.

Виділимо оборотну компоненту теплообміну `dQ_rev/dx` (відкинувши незворотні квадратичні втрати Джоуля `I²`):

```
dQ_rev / dx
= ( ( dΠ / dx ) - S · ( dT / dx ) ) · I      [різниця між градієнтом тепла Пельтьє та електрорушійною роботою поля]
= ( ( dΠ / dT ) - S ) · ( dT / dx ) · I      [застосування ланцюгового правила диференціювання dΠ/dx = (dΠ/dT)·(dT/dx)]
```

За феноменологічним означенням Томсона, теплота, що оборотно поглинається або виділяється в об'ємі провідника, пропорційна струму та градієнту температури:

```
dQ_rev / dx
= τ · I · ( dT / dx )                        [визначення коефіцієнта Томсона τ]
```

Прирівнюючи праві частини обох рівнянь:

```
τ
= ( dΠ / dT ) - S                            [зв'язок коефіцієнта Томсона з температурною похідною коефіцієнта Пельтьє]
= d( S · T ) / dT - S                        [підстановка першого співвідношення Кельвіна Π = S · T]
= S · ( dT / dT ) + T · ( dS / dT ) - S      [диференціювання добутку за правилом Лейбніца]
= S + T · ( dS / dT ) - S                    [спрощення доданку S · 1]
= T · ( dS / dT )                            [друге співвідношення Кельвіна]
```

## 7. Експериментальне визначення абсолютної шкали Зеєбека

Друге співвідношення Кельвіна `τ = T · (dS/dT)` має фундаментальне метрологічне значення: воно дозволяє експериментально визначити **абсолютний коефіцієнт Зеєбека** окремого матеріалу без складання термопари з іншим провідником.

Розділивши рівняння на `T` та інтегруючи від абсолютного нуля (`0 K`):

```
( dS / dT )
= τ(T) / T                                   [розділення змінних у другому співвідношенні Кельвіна]

S(T)
= ∫ [0 .. T] ( τ(T') / T' ) dT'              [інтеграл коефіцієнта Томсона від абсолютного нуля]
```

За третьою ознакою термодинаміки (теоремою Нернста-Планка), при `T → 0 K` ентропія будь-якої рівноважної системи прямує до нуля, тому `S(0) = 0`.

У надпровідниках нижче критичної температури `T_c` квантовий конденсат куперівських пар має нульову ентропію перенесення, тому в надпровідному стані `S_sc = 0` і `τ_sc = 0` тотожно. Вимірюючи термо-ЕРС пари «досліджуваний метал — надпровідник» при низьких температурах та коефіцієнт Томсона `τ(T)` при вищих температурах, фізики створили Міжнародну абсолютну шкалу термо-ЕРС (еталонні криві для свинцю `Pb` та платини `Pt-67`).
