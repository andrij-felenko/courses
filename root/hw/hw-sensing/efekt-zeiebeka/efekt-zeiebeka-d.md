Коли один кінець металевого або напівпровідникового стрижня нагрівають до 373 K, а протилежний утримують при 293 K, вольтметр із високим внутрішнім опором фіксує між виводами стабільну різницю електричних потенціалів у кілька мілівольтів без жодної батареї, хімічного електроліту чи змінного магнітного поля. Якщо замкнути кінці провідника через резистор, у колі потече тривалий електричний струм, підтримуваний виключно різницею температур. Це явище прямого перетворення теплової енергії в електричну називають **ефектом Зеєбека** (*Seebeck effect*, термоелектрика — від грец. *therme* — тепло та *elektron* — бурштин).

## 1. Мікроскопічний механізм термодифузії носіїв заряду

У будь-якому твердому тілі носії електричного заряду (вільні електрони провідності в металах і напівпровідниках n-типу або квазічастинки-дірки в напівпровідниках p-типу) беруть участь у безперервному тепловому хаотичному русі. За наявності просторового градієнта температури `∇T` середня кінетична енергія носіїв заряду на гарячому кінці зразка виявляється суттєво вищою, ніж на холодному.

Середня теплова швидкість фермі-газу електронів поблизу поверхні Фермі виражається через швидкість Фермі `v_F` та температурні флуктуації:

```
v_th
≈ √( 2 · E_F / m* )                  [швидкість електронів на рівні Фермі для виродженого електронного газу]
```

Оскільки носії на гарячому боці мають більшу швидкість і долають більшу середню довжину вільного пробігу між пружними зіткненнями з вузлами кристалічної ґратки, вони частіше й далі розлітаються в усіх напрямках, ніж повільні носії з холодного боку. У результаті виникає спрямована дифузія (від лат. *diffusio* — поширення) швидких носіїв заряду від гарячого кінця до холодного:

```
J_diff
= - q · D · ∇n - q · n · D_T · ∇T    [дифузійний потік носіїв заряду за наявності градієнтів концентрації та температури]
```

![Фізичний механізм термодифузії носіїв заряду в градієнті температур](/root/hw/hw-sensing/efekt-zeiebeka/img/seebeck-carrier-diffusion.svg)
*Мікроскопічна картина термодифузії: перенесення електронів або дірок створює внутрішнє електричне поле E_th, що врівноважує дифузійний напір*

Переміщення електронів уздовж градієнта температури створює надлишок негативного заряду на холодному кінці. На гарячому кінці залишається нескомпенсований позитивний заряд іонізованих атомних остовів кристалічної ґратки.

Просторове розділення зарядів формує внутрішнє електростатичне поле `E_th` (термоелектричне поле), спрямоване від гарячого кінця до холодного (для електронів). Це поле створює зворотний дрейфовий струм:

```
J_drift
= σ · E_th                           [дрейфовий струм утвореного внутрішнього електричного поля за законом Ома]
```

У розімкненому колі макроскопічний струм не може витікати назовні, тому розділення зарядів триває доти, доки дрейфова сила внутрішнього поля точно не зрівноважить дифузійний напір:

```
J_total
= J_diff + J_drift
= 0                                  [динамічна електрохімічна рівновага в розімкненому провіднику]
```

У стані динамічної рівноваги внутрішнє поле `E_th` пропорційне локальному градієнту температури:

```
E_th
= S · ∇T                             [визначення термоелектричного поля через коефіцієнт Зеєбека]
```

Величина `S` називається **диференціальною термо-ЕРС** або **абсолютним коефіцієнтом Зеєбека** матеріалу (у системі SI вимірюється у В/К або мкВ/К):

```
S
= - dV / dT                          [коефіцієнт Зеєбека як градієнт потенціалу на одиницю різниці температур]
```

### Знак коефіцієнта Зеєбека
Знак коефіцієнта Зеєбека визначається знаком домінуючих носіїв заряду:
1. **Електронна провідність (n-тип і більшість металів)**: Електрони несуть негативний заряд (`q = -e`). Скупчення електронів на холодному кінці робить його потенціал нижчим за потенціал гарячого кінця (`V_cold < V_hot`). Отже, `dV = V_cold - V_hot < 0`, звідки за конвенцією знаків `S < 0`.
2. **Діркова провідність (p-тип)**: Квазічастинки-дірки мають ефективний позитивний заряд (`q = +e`). Вони дифундують на холодний кінець, створюючи там надлишок позитивного заряду (`V_cold > V_hot`), тому `S > 0`.

### Формула Мотта для металів і транспортна функція
У металах і вироджених напівпровідниках коефіцієнт Зеєбека описується формулою Мотта через енергетичну похідну електропровідності на рівні Фермі `E_F`:

```
S
= ( (π² · k_B² · T) / (3 · e) ) · [ d(ln σ(E)) / dE ]_(E = E_F)  [формула Мотта: асиметрія провідності вище й нижче рівня Фермі]
```

Диференціальна електропровідність `σ(E)` як функція енергії визначається добутком густини квантових станів `g(E)`, квадрата швидкості носіїв `v²(E)` та часу релаксації імпульсу `τ(E)`:

```
σ(E)
= e² · g(E) · v²(E) · τ(E)           [спектральна транспортна функція провідності]
```

З формули видно: якби густина станів і час релаксації носіїв були абсолютно симетричними відносно енергії Фермі, коефіцієнт Зеєбека дорівнював би нулю. Термо-ЕРС виникає саме через енергетичну асиметрію швидкості та розсіювання носіїв навколо рівня Фермі. Якщо зі зростанням енергії рухливість носіїв падає (наприклад, через інтенсивне розсіювання на акустичних фононах), знак коефіцієнта Зеєбека в деяких металах (зокрема у літію, міді та благородних металів) може ставати позитивним навіть за чисто електронної провідності.

### Ефект фононного захоплення
Окрім прямої дифузії вільних носіїв, існує другий механізм — **фононне захоплення** (*phonon drag*). Градієнт температури породжує потужний потік нерівноважних квантів коливань ґратки — фононів, що рухаються від гарячого боку до холодного.

Під час зіткнень із носіями заряду фонони передають їм свій квазіімпульс, буквально «здуваючи» електрони чи дірки до холодного кінця, подібно до вітру, що штовхає вітрило.

Повний коефіцієнт Зеєбека є сумою двох складових:

```
S
= S_diff + S_drag                    [сума електронної дифузійної компоненти та компоненти фононного захоплення]
```

Температурна поведінка фононного захоплення має чітко виражений максимум:
- При наднизьких температурах (`T → 0 K`) теплова ємність фононного газу спадає як `T³`, тому захоплення затухає.
- При проміжних температурах (20–100 K для металів та до 300 K для деяких чистих напівпровідників типу германію чи кремнію) фононне захоплення досягає максимуму й збільшує абсолютне значення `|S|` у 5–50 разів порівняно з суто електронною дифузією.
- При високих температурах переважають процеси фонон-фононного перекидання (процеси Умклаппа, *Umklapp scattering*), які ефективно гасять спрямований потік фононів і повертають коефіцієнт Зеєбека до суто дифузійного значення `S_diff ∝ T`.

> 🔧 **Навіщо це.**  
> У прецизійній вимірювальній електроніці (нановольтметри, вхідні каскади давачів деформації, підсилювачі біопотенціалів) градієнт температури вздовж друкованої плати всього у 0.1 °C на стику мідної доріжки та виводу резистора зі сплаву ковар чи латуні породжує паразитну термо-ЕРС амплітудою 3–5 мкВ. Цей паразитна напруга на порядки перевищує власний шум сучасного АЦП і викликає температурний дрейф нуля. Розуміння коефіцієнтів Зеєбека дозволяє проєктувати симетричні термокомпенсовані розведення друкованих плат.

## 2. Диференціальна термо-ЕРС у замкненому колі з двох металів

Окремий провідник у градієнті температур генерує різницю потенціалів між своїми кінцями, однак підключити вольтметр до цих кінців неможливо без використання вимірювальних щупів. Щупи неминуче перебувають у тому самому тепловому полі.

### Закон однорідного провідника (закон Магнуса)
Якщо замкнене коло виготовлене з одного повністю однорідного хімічного матеріалу, то незалежно від розподілу температури вздовж провідника результуюча ЕРС у колі тотожно дорівнює нулю:

```
V_closed
= ∮ E_th · dl
= ∮ S(T) · ∇T · dl
= ∮ S(T) dT
= 0                                  [інтеграл від повної похідної по замкненому контуру тотожно рівний нулю]
```

Для отримання ненульової напруги коло обов'язково має складатися щонайменше з двох фізично або хімічно різнорідних матеріалів A і B, які мають різні коефіцієнти Зеєбека `S_A(T) ≠ S_B(T)`.

![Диференціальна термо-ЕРС у замкненому контурі двох матеріалів](/root/hw/hw-sensing/efekt-zeiebeka/img/thermocouple-circuit-integral.svg)
*Контур термопари: термо-ЕРС інтегрується вздовж усього градієнта температур у товщі провідників A і B*

Обчислимо напругу `V_AB`, яку покаже вольтметр, підключений до холодних кінців провідників A і B при температурі `T_c`, коли спай між ними нагрітий до `T_h`:

```
V_AB
= ∫ [T_c .. T_h] S_A(T) dT + ∫ [T_h .. T_c] S_B(T) dT  [сума інтегралів поля вздовж гілки A та зворотної гілки B]
= ∫ [T_c .. T_h] ( S_A(T) - S_B(T) ) dT                [результуюча диференціальна термо-ЕРС замкненого контуру]
```

Якщо температурна залежність коефіцієнтів слабка або інтервал `ΔT = T_h - T_c` малий, інтеграл спрощується до лінійного виразу:

```
V_AB
≈ ( S_A - S_B ) · ( T_h - T_c )      [лінійне наближення термо-ЕРС при сталому диференціальному коефіцієнті]
= S_AB · ΔT                          [визначення диференціального коефіцієнта термопари S_AB]
```

### Де насправді виникає термо-ЕРС: об'єм проти спаю
У популярній літературі часто трапляється помилкове твердження, ніби термо-ЕРС виникає безпосередньо в точці зварювання (спаю) двох металів завдяки контактній різниці потенціалів Вольти (*Volta contact potential*).

Суворий електродинамічний аналіз доводить протилежне:
1. Контактна різниця потенціалів на спаї зумовлена вирівнюванням рівнів Фермі (перетіканням зарядів через контактний подвійний шар) і залежить виключно від локальної температури спаю.
2. Якщо проінтегрувати контактні стрибки потенціалу по всьому замкненому контуру, вони в сумі дають нуль при однаковій температурі контактів або скорочуються внутрішніми об'ємними полями.
3. Справжня термо-ЕРС **накопичується розподілено вздовж усієї довжини провідників A і B** у тих зонах, де присутній ненульовий температурний градієнт `∇T ≠ 0`. Спай потрібен лише як електричний контакт між двома матеріалами в зоні температури `T_h`.

### Три фундаментальні закони термоелектричних кіл
1. **Закон однорідних матеріалів**: Термо-ЕРС не може виникнути в колі з одного однорідного провідника, хоч як змінюється його переріз і градієнт температури вздовж траси. Будь-яка ЕРС у монометалевому дроті свідчить про локальну неоднорідність (наклеп, домішки, механічні напруження).
2. **Закон проміжних матеріалів**: Введення третього провідника C у будь-яку точку розриву контуру не змінює сумарну термо-ЕРС, якщо обидва нові спаї (A-C та C-A або A-C та C-B) підтримуються при однаковій температурі. Цей закон дозволяє споювати термопари срібним чи олов'яним припоєм і підключати мідні клеми вольтметра без спотворення сигналу.
3. **Закон проміжних температур**: Термо-ЕРС, що розвивається між температурами `T_1` і `T_3`, дорівнює алгебраїчній сумі термо-ЕРС цієї самої пари для інтервалів `(T_1, T_2)` та `(T_2, T_3)`:
```
V(T_1, T_3)
= V(T_1, T_2) + V(T_2, T_3)          [адитивність термо-ЕРС за шкалою температур]
```

### Стандартні термоелектричні пари
У промисловості та наукових приладах застосовують стандартизовані пари металів і сплавів з високою стабільністю та повторюваністю коефіцієнта Зеєбека:

| Тип термопари | Матеріали (гілка A / гілка B) | Коефіцієнт `S_AB` при 25 °C | Робочий діапазон, °C | Характерні особливості |
|---|---|---|---|---|
| **K** | Хромель (Ni-Cr) / Алюмель (Ni-Al) | ~41 мкВ/К | -200 .. +1250 | Найпоширеніша, стійка до окислення |
| **J** | Залізо (Fe) / Константан (Cu-Ni) | ~51 мкВ/К | -40 .. +750 | Висока чутливість, боїться вологи |
| **T** | Мідь (Cu) / Константан (Cu-Ni) | ~40 мкВ/К | -250 .. +350 | Прецизійна криогенна термометрія |
| **E** | Хромель (Ni-Cr) / Константан (Cu-Ni) | ~68 мкВ/К | -200 .. +900 | Найвища термо-ЕРС серед металів |
| **N** | Нікросил (Ni-Cr-Si) / Нісил (Ni-Si-Mg) | ~39 мкВ/К | -270 .. +1300 | Підвищена стабільність при високих T |
| **S / R** | Платинородій (Pt-Rh 10/13%) / Платина (Pt) | ~6 .. 10 мкВ/К | 0 .. +1600 | Еталонний високотемпературний давач |
| **B** | Платинородій 30% / Платинородій 6% | ~8 мкВ/К (при 1000°C) | +600 .. +1700 | Не потребує компенсації холодного спаю біля 25°C |

### Конструкція термопарного зонда та деградація
У промислових умовах чутливий спай термопари поміщають у захисну гільзу (*thermowell*). Розрізняють три типи виконання спаю:
1. **Заземлений (Grounded)**: спай приварений безпосередньо до металевої оболонки гільзи. Забезпечує мінімальну теплову інерційність (постійна часу `τ < 0.5 с`), але створює паразитні контури заземлення та синфазні шуми.
2. **Ізольований (Ungrounded)**: спай відокремлений від гільзи спресованим порошком оксиду магнію (`MgO`). Гарантує повну гальванічну розв'язку та високу завадозахищеність за дещо більшої інерційності (`τ ≈ 1 – 3 с`).
3. **Відкритий (Exposed)**: спай виступає за межі гільзи для надшвидкого контролю температури газових потоків (`τ < 0.1 с`), але не захищений від хімічної корозії.

Тривала експлуатація за високих температур викликає старіння сплавів:
- **Зелена гнилизна (*green rot*)**: селективне окиснення хрому в сплаві хромель при дефіциті кисню (800–1050 °C), що призводить до падіння термо-ЕРС на 3–5 мВ.
- **Окиснення та зневуглецювання заліза**: у термопарі типу J призводить до дрейфу калібрувальної характеристики.
- **Дифузія домішок через ізоляцію**: за температур понад 1000 °C атоми з оболонки проникають у платинові дроти типів S/R/B, змінюючи їхній хімічний склад.

## 3. Фундаментальний термоелектричний трикутник: Зеєбек, Пельтьє, Томсон

Ефект Зеєбека не є ізольованим феноменом — він нерозривно пов'язаний із двома іншими оборотними термоелектричними явищами: ефектом Пельтьє та ефектом Томсона.

```
       Ефект Зеєбека (S)
       [ E_th = S · ∇T ]
          /         \
         /           \
 1-е Кельвіна     2-е Кельвіна
  Π = S · T       τ = T · (dS/dT)
       /               \
      /                 \
Ефект Пельтьє (Π) ─── Ефект Томсона (τ)
[ Q_P = Π · I ]       [ dQ_Th/dx = τ · I · ∇T ]
```

![Фундаментальний термоелектричний трикутник і співвідношення Кельвіна](/root/hw/hw-sensing/efekt-zeiebeka/img/thermoelectric-triangle.svg)
*Трикутник термоелектрики: коефіцієнти Зеєбека, Пельтьє та Томсона зв'язані співвідношеннями взаємності*

### 1. Ефект Пельтьє
Відкритий Жан-Шарлем Пельтьє (*Jean Charles Peltier*) у 1834 році: при протіканні постійного електричного струму `I` крізь контакт двох різнорідних матеріалів на спаї, крім незворотного джоулевого тепла `I²·R`, виділяється або поглинається додаткова кількість тепла `Q_P`, знак якої залежить від напрямку струму:

```
Q_P
= Π_AB · I                           [кількість тепла Пельтьє, що поглинається спаєм за одиницю часу]
= ( Π_A - Π_B ) · I                  [різниця абсолютних коефіцієнтів Пельтьє контактуючих матеріалів]
```

### 2. Ефект Томсона
Передбачений Вільямом Томсоном у 1851 році на основі термодинамічних міркувань: якщо крізь однорідний провідник, вздовж якого підтримується градієнт температури `dT/dx`, протікає струм `I`, то в об'ємі провідника виділяється або поглинається додаткове оборотне тепло:

```
dQ_Th / dx
= τ · I · ( dT / dx )                [густина виділення або поглинання тепла Томсона на одиницю довжини]
```

### Співвідношення Кельвіна
Томсон застосував закони термодинаміки до оборотного термоелектричного циклу і вивів два фундаментальні рівняння:

1. **Перше співвідношення Кельвіна** (зв'язок Зеєбека та Пельтьє):
```
Π
= S · T                              [коефіцієнт Пельтьє дорівнює добутку коефіцієнта Зеєбека на абсолютну температуру]
```

2. **Друге співвідношення Кельвіна** (зв'язок Зеєбека та Томсона):
```
τ
= T · ( dS / dT )                    [коефіцієнт Томсона пропорційний температурній похідній коефіцієнта Зеєбека]
```

Фізичний зміст цих формул розкривається через перенесення ентропії. Кожен носій заряду `q`, рухаючись у кристалі, переносить із собою не лише заряд, але й певну кількість тепла та ентропії `s* = q · S`. Коли носій перетинає межу двох матеріалів, його ентропія стрибкоподібно змінюється на `Δs* = q · (S_A - S_B)`. Цей ентропійний стрибок компенсується миттєвим поглинанням або виділенням прихованого тепла контакту `Q_P = T · Δs* · (I/q) = (S_A - S_B) · T · I = Π_AB · I`.

Суворе виведення обох співвідношень Кельвіна з використанням термодинаміки незворотних процесів та принципу мікроскопічної оборотності Онзагера наведено в окремому документі [Виведення співвідношень Кельвіна через взаємність Онзагера](root:hw-sensing/efekt-zeiebeka/math-kelvin-onsager.md).

## 4. Термоелектрична добротність матеріалів (Figure of Merit ZT)

Для ефективного практичного застосування ефекту Зеєбека в джерелах автономного живлення — термоелектричних генераторах (*Thermoelectric Generators, TEG*) — матеріал повинен одночасно задовольняти три суперечливі фізичні вимоги:
1. Мати великий коефіцієнт Зеєбека `S`, щоб генерувати високу напругу на одиницю різниці температур.
2. Мати високу питому електропровідність `σ`, щоб мінімізувати внутрішні омічні втрати на нагрів Джоуля (`I²·R_int`).
3. Мати низьку питому теплопровідність `κ`, щоб запобігти паразитному витоку тепла від гарячого джерела до холодного радіатора без корисної віддачі енергії.

У 1950-х роках академік Абрам Йоффе об'єднав ці параметри в єдиний безрозмірний критерій — **термоелектричну добротність** `ZT`:

```
ZT
= ( S² · σ · T ) / κ                 [безрозмірна термоелектрична добротність Йоффе при середній температурі T]
```

Добуток `PF = S² · σ` називають **фактором потужності** (*Power Factor*).

![Термоелектрична добротність ZT і компроміс між S, σ та теплопровідністю](/root/hw/hw-sensing/efekt-zeiebeka/img/figure-of-merit-zt.svg)
*Конфлікт параметрів у ZT: метали мають високу провідність, але низький Seebeck; ізолятори мають гігантський Seebeck, але нульову провідність*

### Фундаментальний конфлікт матеріалознавства
Спроба оптимізувати добротність `ZT` натрапляє на фундаментальну фізичну перешкоду: параметри `S`, `σ` та `κ` жорстко взаємопов'язані через концентрацію вільних носіїв заряду `n`:

1. **Електропровідність** зростає прямо пропорційно концентрації носіїв: `σ = n · q · μ` (де `μ` — рухливість носіїв).
2. **Коефіцієнт Зеєбека** для вироджених систем падає зі зростанням концентрації приблизно як `S ∝ n^(-2/3)` (рівняння Пісаренка):
```
S
= ( (8 · π² · k_B²) / (3 · e · h²) ) · m* · T · ( π / (3 · n) )^(2/3)  [рівняння Пісаренка для напівпровідників]
```
3. **Теплопровідність** складається з електронної `κ_e` та ґраткової (фононної) `κ_ph` компонент: `κ = κ_e + κ_ph`. При цьому за законом Відемана-Франца електронна теплопровідність нерозривно прив'язана до електропровідності:
```
κ_e
= L · σ · T                          [закон Відемана-Франца, де L ≈ 2.44e-8 Вт·Ом/К² — число Лоренца]
```

З графіка видно:
- **Метали** (`n ≈ 10²² – 10²³ см⁻³`) мають чудову електропровідність `σ`, але мізерний коефіцієнт Зеєбека (`S ≈ 5 – 40 мкВ/К`) та високу електронну теплопровідність `κ_e`, тому їхній `ZT` не перевищує `0.01 – 0.05`.
- **Діелектрики та нелеговані напівпровідники** (`n < 10¹⁶ см⁻³`) мають гігантський коефіцієнт Зеєбека (`S > 1000 мкВ/К`), але практично нульову електропровідність, що дає `ZT ≈ 0`.
- **Оптимум добротності** лежить у вузькому вікні концентрацій `n ≈ 10¹⁹ – 10²⁰ см⁻³`, що відповідає **сильнолегованим вузькозонним напівпровідникам** на основі важких елементів таблиці Менделєєва (`Bi₂Te₃`, `Bi₂Se₃`, `PbTe`, `SiGe`, сплави Гейслера та скуттерудити).

### Зонна інженерія та виродження долин
Важливим чинником оптимізації `ZT` є ефективна маса густини станів `m*_d` та рухливість носіїв `μ`. Коефіцієнт Зеєбека зростає зі збільшенням ефективної маси (`S ∝ m*`), проте важкі носії мають малу рухливість (`μ ∝ 1/m*`), що знижує електропровідність `σ`.

Виходом із цього глухого кута є **багатодолинна структура енергетичних зон** (*band valley degeneracy*). Якщо зона провідності чи валентна зона містить `N_v` енергетично еквівалентних долин (як у `Bi₂Te₃`, де `N_v = 6`, або в `PbTe`, де `N_v = 4`), повна маса густини станів становить:

```
m*_d
= N_v^(2/3) · m*_b                   [маса густини станів зростає з кількістю еквівалентних долин N_v]
```

При цьому рухливість електронів у кожній окремій долині визначається малою інерційною масою `m*_b`. Це дозволяє отримати високий коефіцієнт Зеєбека без деградації електропровідності.

### Сучасні стратегії фононної інженерії (PGEC)
Концепція «електронний кристал — фононне скло» (*Phonon-Glass Electron-Crystal, PGEC*) спрямована на вибіркове розсіювання фононів:
- **Наноструктурування та межі зерен**: розсіювання фононів середніх та довгих хвиль на межах нанокристалів (10–50 нм).
- **Атоми-брязкальця (*rattlers*)**: важкі іони в кристалічних клітках скуттерудитів і клатратів створюють локальні резонансні коливання, що гасять фононний теплоперенос.
- Нанокомпозити на базі `Bi₂Te₃/Sb₂Te₃` досягають `ZT ≈ 1.2 – 1.8` при кімнатних температурах, а селенід олова `SnSe` демонструє рекордні `ZT ≈ 2.2 – 2.6` при 800 K.

### Термодинамічний ККД термоелектрогенератора
Максимальний теоретичний коефіцієнт корисної дії генератора Зеєбека, що працює між гарячим джерелом `T_h` та холодним радіатором `T_c` при середній температурі `T_m = (T_h + T_c)/2`, дорівнює добутку ККД ідеального циклу Карно на коефіцієнт термоелектричної досконалості:

```
η_max
= ( (T_h - T_c) / T_h ) · [ ( √(1 + ZT_m) - 1 ) / ( √(1 + ZT_m) + (T_c / T_h) ) ]  [максимальний ККД генератора Зеєбека]
```

Для сучасних серійних модулів із середнім `ZT ≈ 0.8 – 1.0` при перепаді температур 200 °C (наприклад, `T_h = 500 K`, `T_c = 300 K`) ККД становить близько `5 – 7 %`. При `ZT → ∞` вираз переходить у граничний ККД Карно `η_Carnot = 1 - T_c/T_h`.

## 5. Енергетичний баланс та узгодження термоелектрогенератора (TEG)

Розглянемо термоелектричну пару, що складається з двох напівпровідникових стовпчиків (p-тип і n-тип), з'єднаних мідною шиною на гарячому кінці `T_h` та підключених до зовнішнього електричного навантаження `R_L` на холодному кінці `T_c`.

![Енергетичний баланс термопари в режимі генератора енергії](/root/hw/hw-sensing/efekt-zeiebeka/img/teg-energy-balance.svg)
*Баланс теплових та електричних потоків у генераторному модулі: оптимум досягається при імпедансному узгодженні R_L = R_int*

Запишемо повний баланс теплових потоків:

1. **Тепловий потік, що забирається від гарячого джерела `Q_h`**:
```
Q_h
= N · (S_p - S_n) · T_h · I + K_th · (T_h - T_c) - 0.5 · I² · R_int  [тепло Пельтьє + теплопровідність - половина тепла Джоуля]
```
Тут:
- `N · (S_p - S_n) · T_h · I` — тепло Пельтьє, що поглинається гарячим контактом при протіканні згенерованого струму `I`;
- `K_th · (T_h - T_c)` — прямий витік тепла за законом Фур'є через теплову провідність ніжок `K_th`;
- `0.5 · I² · R_int` — внутрішнє джоулеве самонагрівання, яке ділиться порівну між гарячим і холодним кінцями.

2. **Тепловий потік, що скидається в холодний радіатор `Q_c`**:
```
Q_c
= N · (S_p - S_n) · T_c · I + K_th · (T_h - T_c) + 0.5 · I² · R_int  [тепло Пельтьє на холодному кінці + теплопровідність + 0.5 Джоуля]
```

3. **Корисна вироблена електрична потужність `P_el`**:
За першим законом термодинаміки вихідна електрична потужність дорівнює різниці вхідного та вихідного теплових потоків:

```
P_el
= Q_h - Q_c
= N · (S_p - S_n) · (T_h - T_c) · I - I² · R_int  [електрорушійна потужність мінус втрати на внутрішньому опорі]
= V_oc · I - I² · R_int                           [вираз через напругу холостого ходу V_oc]
```

Підставляючи струм кола `I = V_oc / (R_int + R_L)`:

```
P_el(R_L)
= ( V_oc² · R_L ) / ( R_int + R_L )²              [залежність вихідної потужності від опору навантаження]
```

За теоремою Якобі про максимальну передачу потужності (імпедансне узгодження), екстремум потужності досягається при рівності опору навантаження внутрішньому електричному опору генератора:

```
R_L
= R_int                              [умова максимальної електричної потужності на навантаженні]

P_max
= V_oc² / ( 4 · R_int )              [максимальна корисна потужність у навантаженні]
```

### Практичне застосування: радіоізотопні термогенератори (РІТЕГ / RTG)
Завдяки повній відсутності рухомих частин і рідинних контурів генератори Зеєбека мають безпрецедентну надійність. У радіоізотопних термоелектричних генераторах (*Radioisotope Thermoelectric Generators, RTG*) тепло виділяється внаслідок природного альфа-розпаду діоксиду плутонію-238 (`²³⁸PuO₂` з питомою тепловою потужністю близько `0.5 Вт/г` і періодом напіврозпаду 87.7 років).

Кремній-германієві (`SiGe`) та свинцево-телуридні (`PbTe`) термоелементи на космічних апаратах *Voyager-1*, *Voyager-2*, *Cassini*, *New Horizons*, марсоходах *Curiosity* та *Perseverance* безперервно генерують електричну енергію понад 45 років в умовах глибокого вакууму та екстремальної радіації.

Повний чисельний симулятор термоелектричного модуля з розрахунком динамічних теплових втрат, струму та ККД реалізовано у вставці [Моделювання термоелектричного генератора й термопари на C та C++](root:hw-sensing/efekt-zeiebeka/proj-seebeck-generator.md).

## 6. Інженерна лінеаризація сигналу термопари (NIST ITS-90)

Коефіцієнт Зеєбека реальних металів помітно змінюється з температурою. Через це залежність вихідної термо-ЕРС `V(T)` від температури гарячого спаю є нелінійною функцією.

Для промислових термопар Національний інститут стандартів і технологій США (NIST) у межах температурної шкали ITS-90 розробив поліноміальні моделі високого порядку (до 9–10 степеня).

Для найпоширенішої термопари **типу K (хромель-алюмель)** пряме перетворення температури `T` (°C) у термо-ЕРС `V` (мкВ) відносно опорного спаю при 0 °C виражається поліномом:

```
V(T)
= ∑ [i = 0 .. n] ( c_i · T^i ) + a_0 · exp( a_1 · (T - a_2)² )  [поліном NIST ITS-90 з гаусовою поправкою для типу K]
```

Обернене обчислення температури за виміряною напругою `V` (у мілівольтах) вимагає обчислення оберненого полінома:

```
T(V)
= ∑ [i = 0 .. m] ( d_i · V^i )       [обернений поліном відновлення температури за виміряною мілівольтовою ЕРС]
```

### Алгоритм компенсації холодного спаю (CJC)
Оскільки клеми приладу підтримуються при кімнатній температурі `T_cjc ≠ 0 °C`, вольтметр вимірює напругу:

```
V_measured
= V(T_hot) - V(T_cjc)                [диференціальна напруга між гарячим об'єктом і клемною колодкою]
```

**Категорична помилка початківців**: перетворити `V_measured` у температуру й просто додати `T_cjc`. Оскільки функція `V(T)` нелінійна, така операція дає похибку до 5–15 °C.

**Правильний трикроковий алгоритм**:
1. Виміряти температуру холодного спаю `T_cjc` прецизійним локальним давачем (терморезистором NTC або платиновим RTD).
2. За прямим поліномом знайти еквівалентну напругу холодного спаю: `V_cjc = V_poly(T_cjc)`.
3. Скласти напруги у мікровольтах: `V_true = V_measured + V_cjc`.
4. Обчислити дійсну температуру гарячого спаю за оберненим поліномом: `T_hot = T_inv_poly(V_true)`.

#include <stdio.h>
#include <math.h>

/* Обернений поліном NIST ITS-90 для типу K: ЕРС (мВ) -> T (°C) у діапазоні 0..500 °C */
static const double K_INV_POLY[] = {
     0.0000000E+00,
     2.5083550E+01,
     7.8601060E-02,
    -2.5031310E-01,
     8.3152700E-02,
    -1.2280340E-02,
     9.8040360E-04,
    -4.4130300E-05,
     1.0577340E-06,
    -1.0527550E-08
};

/* Пряме лінійне наближення термо-ЕРС біля кімнатної температури (40.7 мкВ/°C) */
double type_k_approx_cjc_uv(double ambient_c) {
    return ambient_c * 40.73;
}

double type_k_calc_temperature_c(double measured_uv, double ambient_temp_c) {
    /* 1. Додаємо еквівалентну ЕРС холодного спаю */
    double v_cjc_uv = type_k_approx_cjc_uv(ambient_temp_c);
    double v_total_mv = (measured_uv + v_cjc_uv) * 1e-3;

    /* 2. Обчислюємо поліном за схемою Горнера для мінімізації множень */
    double temp = K_INV_POLY[9];
    for (int i = 8; i >= 0; --i) {
        temp = temp * v_total_mv + K_INV_POLY[i];
    }
    return temp;
}

#include <array>
#include <numeric>
#include <span>

namespace sensors {

class ThermocoupleLinearizer {
public:
    static constexpr std::array<double, 10> k_inv_poly{
         0.0000000E+00,
         2.5083550E+01,
         7.8601060E-02,
        -2.5031310E-01,
         8.3152700E-02,
        -1.2280340E-02,
         9.8040360E-04,
        -4.4130300E-05,
         1.0577340E-06,
        -1.0527550E-08
    };

    [[nodiscard]] static constexpr double cjc_equivalent_uv(double ambient_temp_c) noexcept {
        return ambient_temp_c * 40.73;
    }

    [[nodiscard]] static constexpr double calculate_temperature(double measured_uv, double ambient_temp_c) noexcept {
        const double v_total_mv = (measured_uv + cjc_equivalent_uv(ambient_temp_c)) * 1e-3;

        // Обчислення полінома за схемою Горнера
        double temp = k_inv_poly.back();
        for (auto it = k_inv_poly.rbegin() + 1; it != k_inv_poly.rend(); ++it) {
            temp = temp * v_total_mv + *it;
        }
        return temp;
    }
};

} // namespace sensors

## 7. Підсумковий синтез

Ефект Зеєбека є проявом фундаментального принципу незворотної термодинаміки: градієнт температури в матеріалі неминуче викликає дифузійний потік тепла та ентропії, що за наявності вільних рухливих носіїв заряду трансформується у внутрішнє макроскопічне електричне поле.

Термо-ЕРС генерується розподілено в товщі кожного провідника вздовж усього температурного перепаду, а її диференціальна величина в контурі визначається різницею ентропії, що переноситься носіями струму в різних матеріалах. Взаємозв'язок ефектів Зеєбека, Пельтьє та Томсона через співвідношення Кельвіна забезпечує єдиний теоретичний фундамент як для високотемпературної сенсорики, так і для систем прямої твердотільної генерації електроенергії.
