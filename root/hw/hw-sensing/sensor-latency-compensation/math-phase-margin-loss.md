# 🧮 Математика фазового запізнення та втрати стійкості

Будь-яка фізична система автоматичного керування зі зворотним зв'язком — від стабілізації просторової орієнтації безпілотного літального апарата чи супутника до промислового сервопривода прецизійного верстата — спирається на передачу сигналу неузгодженості (помилки) з виходу системи на її вхід. Якщо цей зворотний зв'язок є негативним, керівний вплив протидіє виникаючому збуренню й повертає об'єкт у рівноважний стан. Проте наявність часової затримки у вимірювальному тракті перетворює миттєвий сигнал зворотного зв'язку на запізнілий, спотворюючи фазові співвідношення між збуренням та реакцією регулятора.

Коли часова затримка досягає критичного порогу, фазовий зсув на частоті зрізу контуру перевищує 180 градусів. У цій точці негативний зворотний зв'язок перетворюється на позитивний: замість гасіння збурення система починає синхронно підсилювати власні відхилення, породжуючи незгасаючі автоколивання або катастрофічну втрату динамічної стійкості. Нижче наведено строгий математичний аналіз впливу чистого запізнення на частотні характеристики розімкненого та замкненого контурів, точний розрахунок деградації запасів стійкості за фазою та підсиленням, траєкторії руху полюсів замкненої системи на комплексній площині, дискретний Z-аналіз запізнення, апроксимацію Паде, розрахунок фазово-випереджаючих ланок та метод гармонійного балансу для оцінки параметрів виникаючих граничних циклів.

## Комплексна передатна функція чистого запізнення у неперервному часі

Нехай ідеальний неперервний сигнал вимірюваної фізичної величини на вході сенсора позначається як `x(t)`. Внаслідок сукупності фізичних процесів чутливого елемента, цифрової фільтрації вбудованим процесором сигналів та транспортування по шині даних вихідний оцифрований сигнал `y(t)` зсунутий у часі на постійну величину чистого запізнення `τ > 0`:

```
y(t) = x(t - τ)
```

Застосуємо пряме перетворення Лапласа до обох частин рівняння за нульових початкових умов:

```
Y(s)
= ∫₀^∞ y(t) · e^{-s·t} dt                                [означення перетворення Лапласа]
= ∫₀^∞ x(t - τ) · e^{-s·t} dt                           [підстановка вихідного сигналу із запізненням]
= ∫_{-τ}^∞ x(u) · e^{-s·(u + τ)} du                     [заміна змінної інтегрування u = t - τ, dt = du]
= e^{-s·τ} · ∫₀^∞ x(u) · e^{-s·u} du                    [винесення множника e^{-s·τ}, x(u)=0 при u < 0]
= e^{-s·τ} · X(s)                                       [згортання інтеграла в операторний образ X(s)]
```

Звідси передатна функція ланки чистого запізнення в операторній формі становить:

```
W_d(s) = Y(s) / X(s) = e^{-s·τ}
```

Для переходу до гармонійного частотного аналізу підставимо комплексний частотний аргумент `s = j·ω`, де `j = √(-1)` — уявна одиниця, а `ω` — кругова частота коливань (рад/с):

```
W_d(jω) = e^{-j·ω·τ} = cos(ω·τ) - j·sin(ω·τ)
```

Обчислимо амплітудно-частотну (АЧХ) та фазо-частотну (ФЧХ) характеристики ланки запізнення:

```
|W_d(jω)|
= √( cos²(ω·τ) + sin²(ω·τ) )                            [модуль комплексного числа]
= √1                                                    [основна тригонометрична тотожність]
= 1                                                     [0 дБ на всіх частотах від 0 до ∞]
```

```
∠W_d(jω)
= arctan( -sin(ω·τ) / cos(ω·τ) )                        [аргумент комплексного числа]
= -ω·τ                                                  [фазовий зсув у радіанах]
= - (180 / π) · ω · τ                                   [фазовий зсув у кутових градусах]
```

Амплітудна характеристика чистого запізнення строго дорівнює одиниці (0 дБ) на всіх без винятку частотах: затримка не послаблює і не підсилює амплітуду вхідного коливання. Натомість її фазовий зсув є монотонно спадною лінійною функцією частоти `ω`. Чим вища частота гармоніки сигналу, тим більше фазове запізнення вносить одна й та сама часова затримка `τ`.

## Розімкнений контур та ерозія запасу стійкості за фазою

Розглянемо типову лінійну систему керування зі зворотним зв'язком. Нехай передатна функція регулятора позначається як `C(s)`, передатна функція об'єкта керування (разом із виконавчими приводами) — `P(s)`, а вимірювальний тракт зворотного зв'язку містить чисте запізнення `W_d(s) = e^{-s·τ}`.

Передатна функція розімкненого контуру (Open-Loop Transfer Function) `L(s)` становить:

```
L(s) = C(s) · P(s) · e^{-s·τ} = L₀(s) · e^{-s·τ}
```

де `L₀(s) = C(s) · P(s)` — номінальний розімкнений контур без урахування затримок давачів.

Комплексний частотний відгук контуру:

```
L(jω) = |L₀(jω)| · e^{j·( ∠L₀(jω) - ω·τ )}
```

Визначимо **частоту зрізу за одиничним підсиленням** `ω_c` (*gain crossover frequency*) як частоту, на якій модуль передатної функції розімкненого контуру дорівнює одиниці (0 дБ):

```
|L(jω_c)| = |L₀(jω_c)| · |e^{-j·ω_c·τ}| = |L₀(jω_c)| · 1 = 1
```

Оскільки ланка запізнення має одиничний коефіцієнт передачі на всіх частотах, частота зрізу контуру `ω_c` залишається абсолютно незмінною незалежно від величини затримки `τ`.

**Запас стійкості за фазою** (*Phase Margin*, `PM`) визначається як різниця між фазою розімкненого контуру на частоті зрізу `ω_c` та критичною фазою протифази `-180°` (`-π` рад):

```
PM(τ)
= 180° + ∠L(jω_c)                                       [означення запасу стійкості за фазою]
= 180° + ∠L₀(jω_c) - (180 / π) · ω_c · τ                [підстановка фази з урахуванням затримки]
= PM₀ - (180 / π) · ω_c · τ                             [де PM₀ — номінальний запас фази без затримки]
```

Для збереження асимптотичної стійкості замкненого контуру за критерієм Найквіста необхідно, щоб запас стійкості за фазою був строго додатним: `PM(τ) > 0`. 

Прирівнявши `PM(τ) = 0`, отримуємо **граничну критичну затримку** `τ_crit`, перевищення якої призводить до повної втрати динамічної стійкості:

```
PM₀ - ω_c · τ_crit = 0
⇒ τ_crit = PM₀ / ω_c                                    [де PM₀ виражено в радіанах]
⇒ τ_crit = (π / 180) · (PM₀ / ω_c)                      [де PM₀ виражено в градусах]
```

### Деградація запасу стійкості за підсиленням (Gain Margin)

Затримка давача впливає не лише на фазовий запас, але й різко звужує **запас стійкості за підсиленням** (*Gain Margin*, `GM`).

Визначимо **фазову частоту зрізу** `ω_π` (*phase crossover frequency*) як частоту, на якій сумарна фаза розімкненого контуру досягає `-180°`:

```
∠L(jω_π) = ∠L₀(jω_π) - ω_π · τ = -180° = -π рад
```

Оскільки доданок `-ω·τ` монотонно зменшує загальну фазу, поява затримки зміщує фазову частоту `ω_π(τ)` у бік значно нижчих частот порівняно з номінальною частотою `ω_π0`. 

Запас стійкості за підсиленням визначається як:

```
GM(τ) = - 20 · lg|L(jω_π(τ))| = - 20 · lg|L₀(jω_π(τ))|
```

Оскільки на низьких частотах амплітудна характеристика `|L₀(jω)|` зазвичай має вищі значення, зміщення `ω_π` ліворуч призводить до того, що `|L₀(jω_π(τ))|` суттєво зростає, а запас підсилення `GM(τ)` стрімко деградує.

## Повний числовий приклад розрахунку контуру стабілізації БПЛА

Розглянемо замкнений контур регулювання кутової швидкості тангажу БПЛА з моментом інерції `J = 0.025 кг·м²` та аеродинамічним демпфуванням `b = 0.05 Н·м·с/рад`.

Передатна функція динаміки корпуса:

```
P(s) = 1 / (J·s + b) = 1 / (0.025·s + 0.05) = 40 / (s + 2)
```

Регулятор кутової швидкості являє собою PI-ланку з коефіцієнтами `K_p = 0.5` та `K_i = 2.0`:

```
C(s) = K_p + K_i / s = 0.5 · (s + 4) / s
```

Номінальний розімкнений контур без затримки:

```
L₀(s) = C(s) · P(s) = 20 · (s + 4) / [ s · (s + 2) ]
```

### Крок 1. Розрахунок частоти зрізу ω_c та номінального запасу фази PM₀

Модуль розімкненого контуру:

```
|L₀(jω)| = 20 · √( ω² + 16 ) / [ ω · √( ω² + 4 ) ]
```

Знайдемо частоту зрізу з рівняння `|L₀(jω_c)| = 1`:

```
400 · (ω_c² + 16) = ω_c² · (ω_c² + 4)
⇒ 400·ω_c² + 6400 = ω_c⁴ + 4·ω_c²
⇒ ω_c⁴ - 396·ω_c² - 6400 = 0
```

Розв'яжемо біквадратне рівняння відносно `u = ω_c²`:

```
u = [ 396 + √( 396² + 4 · 6400 ) ] / 2
= [ 396 + √( 156816 + 25600 ) ] / 2
= [ 396 + √182416 ] / 2
= [ 396 + 427.10 ] / 2
≈ 411.55 рад²/с²
⇒ ω_c = √411.55 ≈ 20.29 рад/с (f_c ≈ 3.23 Гц)
```

Обчислимо фазу розімкненого контуру на частоті `ω_c = 20.29 рад/с`:

```
∠L₀(jω_c)
= arctan(ω_c / 4) - 90° - arctan(ω_c / 2)                [фазовий внесок чисельника та знаменника]
= arctan(20.29 / 4) - 90° - arctan(20.29 / 2)
= arctan(5.0725) - 90° - arctan(10.145)
= 78.85° - 90° - 84.37°
= -95.52°
```

Номінальний запас стійкості за фазою:

```
PM₀ = 180° + ∠L₀(jω_c) = 180° - 95.52° = +84.48° (1.474 рад)
```

### Крок 2. Розрахунок граничної критичної затримки τ_crit

```
τ_crit
= PM₀ / ω_c                                             [формула критичної затримки в радіанах]
= 1.474 / 20.29
≈ 0.0726 с = 72.6 мс                                    [критичний поріг стійкості]
```

### Крок 3. Вплив реальної апаратної затримки τ = 40 мс

Нехай сумарна затримка гіроскопа (DLPF-фільтр другого порядку 25 мс + переривання шини SPI та RTOS 15 мс) становить `τ = 0.040 с`.

Розрахуємо фазове запізнення, що виникає на частоті зрізу:

```
Δφ_delay = - (180 / π) · ω_c · τ = - (180 / 3.14159) · 20.29 · 0.040 ≈ -46.50°
```

Результуючий запас стійкості за фазою:

```
PM(40 мс) = PM₀ + Δφ_delay = 84.48° - 46.50° = +37.98°
```

Запас фази зменшився більш ніж удвічі (з 84.5° до 38.0°). Перехідний процес відхилення рулів набуває вираженого коливального характеру: перерегулювання зростає з 5% до 35%, а тривалість заспокоєння коливань збільшується втричі. Якщо затримка зросте до 75 мс (наприклад, через затримки буферизації при перевантаженні процесора), `PM` стане від'ємним (`-2.1°`), і контур перейде в режим незгасаючого автоколивання.

## Раціональна апроксимація Паде та немінімально-фазові нулі

Трансцендентний множник `e^{-s·τ}` не є раціональним дробом, що унеможливлює пряме застосування класичного алгебраїчного методу кореневого годографа (Root Locus) та розрахунок характеристичного полінома замкненої системи. Для аналітичного дослідження використовують раціональну апроксимацію Паде (*Padé approximation*), яка наближає експоненту відношенням двох многочленів однакового або різного степеня.

### Апроксимація Паде першого порядку [1/1]

Розкладемо експоненту `e^{-s·τ}` у раціональний дріб першого порядку:

```
e^{-s·τ} = e^{-s·τ/2} / e^{s·τ/2} ≈ (1 - s·τ/2) / (1 + s·τ/2)
```

Помножимо чисельник і знаменник на 2:

```
W_P1(s) = (2 - s·τ) / (2 + s·τ) = - (s - 2/τ) / (s + 2/τ)
```

Аналіз передатної функції `W_P1(s)` розкриває ключову математичну природу часового запізнення:
1. **Полюс у лівій півплощині:** `s_p = -2 / τ`. Полюс є строго стійким і забезпечує асимптотичне згасання вільних складових перехідного процесу.
2. **Нуль у правій півплощині (Right Half-Plane Zero, RHP-нуль):** `s_z = +2 / τ`.

Присутність нуля в правій комплексній півплощині переводить ланку чистого запізнення в категорію **немінімально-фазових систем** (*Non-Minimum Phase systems*, NMP).

Немінімально-фазовий нуль чинить подвійний негативний вплив на динаміку:
- При подачі східчастого сигналу на вхід немінімально-фазової системи її початкова реакція спрямована в протилежний бік від кінцевого усталеного значення (зворотний викид, *undershoot*).
- Відповідно до теореми Боде про інтеграл чутливості (інтеграл Пуассона для логарифма функції чутливості, або *Waterbed Effect*):

```
∫₀^∞ ln|S(jω)| dω = π · ∑ Re(p_k)
```

де `S(s) = 1 / (1 + L(s))` — функція чутливості до збурень, а `p_k` — нестійкі полюси розімкненого контуру. RHP-нуль на відстані `z = 2/τ` обмежує максимально досяжну смугу пропускання замкненого контуру жорсткою нерівністю:

```
ω_c ≤ 0.5 · s_z = 1 / τ
```

Будь-яка спроба форсувати коефіцієнти регулятора для розширення смуги вище порогу `1/τ` призводить до гігантського сплеску піку чутливості `|S(jω)| ≫ 1` на сусідніх частотах, що спричиняє резонансне підсилення високочастотного шуму давачів та руйнування приводів.

### Апроксимація Паде другого порядку [2/2]

Для прецизійного аналізу на високих частотах (аж до частот порядку `ω ≈ 2/τ`) застосовується наближення другого порядку:

```
W_P2(s) = ( 1 - (s·τ)/2 + (s·τ)²/12 ) / ( 1 + (s·τ)/2 + (s·τ)²/12 ) = ( s²·τ² - 6·s·τ + 12 ) / ( s²·τ² + 6·s·τ + 12 )
```

Корені чисельника (пара комплексних RHP-нулів):

```
s_z1,2 = (3 ± j·√3) / τ
```

Корені знаменника (пара стійких комплексно-спряжених полюсів):

```
s_p1,2 = (-3 ± j·√3) / τ
```

Апроксимація другого порядку доводить, що фазовий набіг ланки запізнення наростає швидше за будь-який лінійний фільтр першого порядку, а права півплощина містить комплексну пару нулів, що робить пряму алгебраїчну інверсію затримки строго нестійкою.

## Дискретний Z-аналіз запізнення та міждискретний дробовий зсув

У цифрових контролерах обробка сигналів відбувається дискретно з фіксованим періодом квантування `T_s`. 

Якщо повна затримка вимірювання `τ` є кратним числом періодів дискретизації `τ = d · T_s` (де `d ∈ ℕ` — ціле число тактів), передатна функція затримки в Z-області має вигляд:

```
W_d(z) = Z{ δ(t - d·T_s) } = z^{-d}
```

У Z-площині оператор `z^{-d}` додає `d` додаткових полюсів у початку координат `z = 0`. Характеристичне рівняння замкненої системи збільшує свій степінь на `d`, що зміщує корені замкненого контуру ближче до одиничного кола `|z| = 1`, звужуючи область допустимих коефіцієнтів підсилення.

### Дробова затримка (Fractional Delay)

У реальних системах затримка майже ніколи не є точно кратною періоду дискретизації: `τ = (d + μ) · T_s`, де `d = ⌊τ / T_s⌋` — ціла частина затримки в тактах, а `μ ∈ [0, 1)` — дробова частина (*fractional delay*).

Передатна функція дробової затримки в дискретній формі:

```
W_d(z) = z^{-d} · z^{-μ}
```

Оскільки нецілий степінь `z^{-μ}` не є раціональною Z-функцією, для міждискретної реконструкції сигналу застосовують поліноміальну інтерполяцію Лагранжа:

```
x̂(t_k - μ·T_s) ≈ ∑_{n=0}^{N} L_n(μ) · x[k - n]
```

де базисні поліноми Лагранжа степеня `N` визначаються як:

```
L_n(μ) = ∏_{m=0, m≠n}^{N} (μ - m) / (n - m)
```

Для лінійної інтерполяції першого порядку (`N = 1`):

```
L₀(μ) = 1 - μ
L₁(μ) = μ
⇒ x̂[k - μ] = (1 - μ) · x[k] + μ · x[k - 1]
```

Дискретна передатна функція лінійного інтерполятора затримки:

```
H_frac(z) = (1 - μ) + μ · z^{-1}
```

Частотна характеристика такого дискретного відновлювача затримки:

```
|H_frac(e^{j·ω·T_s})| = √( (1 - μ + μ·cos(ω·T_s))² + (μ·sin(ω·T_s))² ) = √( 1 - 2·μ·(1 - μ)·(1 - cos(ω·T_s)) )
```

На відміну від неперервної чистої затримки, дискретна лінійна інтерполяція вносить паразитне високочастотне затухання амплітуди: на частоті Найквіста `ω = π / T_s` коефіцієнт передачі падає до `|1 - 2μ|`. Для запобігання фазовим та амплітудним спотворенням у прецизійних фільтрах Калмана використовують поліноми Лагранжа не нижче третього порядку (`N = 3`, кубічна сплайн-інтерполяція).

## Математичний розрахунок фазово-випереджаючого компенсатора (Lead Network)

Для відновлення втраченого запасу стійкості за фазою в класичних аналогових та цифрових контурах застосовують послідовну фазово-випереджаючу ланку (*Lead Compensator*):

```
C_lead(s) = (1 + T·s) / (1 + α·T·s)
```

де `α < 1` — коефіцієнт розносу частот нулів і полюсів, а `T` — постійна часу компенсатора.

Комплексний частотний відгук фазового компенсатора:

```
C_lead(jω) = (1 + j·ω·T) / (1 + j·α·ω·T)
```

Фазовий підйом, що формується компенсатором:

```
φ_lead(ω) = arctan(ω·T) - arctan(α·ω·T)
```

Знайдемо частоту максимуму фазового випередження `ω_m` з умови `dφ_lead / dω = 0`:

```
ω_m = 1 / ( T · √α )
```

Максимальний фазовий підйом `φ_max` на частоті `ω_m` визначається виключно параметром `α`:

```
sin(φ_max) = (1 - α) / (1 + α)
⇒ α = (1 - sin(φ_max)) / (1 + sin(φ_max))
```

Амплітудне підсилення компенсатора на частоті максимуму фази:

```
|C_lead(jω_m)| = 1 / √α
```

### Приклад відновлення запасу фази

Нехай для компенсації фазового запізнення `Δφ = -46.5°` на частоті зрізу `ω_c = 20.29 рад/с` необхідно створити фазовий підйом `φ_max = 45°`:

```
α = (1 - sin(45°)) / (1 + sin(45°)) = (1 - 0.7071) / (1 + 0.7071) = 0.2929 / 1.7071 ≈ 0.1716
```

Розрахуємо постійну часу `T` так, щоб максимум фази припав точно на частоту `ω_c`:

```
T = 1 / ( ω_c · √α ) = 1 / ( 20.29 · √0.1716 ) = 1 / ( 20.29 · 0.4142 ) ≈ 0.119 с
```

Ціна введення фазового випередження полягає у високочастотному підсиленні шумів: на частотах `ω ≫ ω_m` коефіцієнт передачі компенсатора зростає до `1/α ≈ 5.83` (+15.3 дБ), що вимагає ретельного проектування додаткових режекторних фільтрів для гасіння шумів дискретизації.

## Метод гармонійного балансу та амплітуда автоколивань (Limit Cycles)

Коли затримка вимірювального тракту перевищує критичну межу `τ > τ_crit`, лінійна замкнена система стає експоненційно нестійкою. Проте в реальних фізичних приводах вихідний сигнал завжди обмежений насиченням (наприклад, максимальним кутом відхилення рулів `±δ_max` або максимальним струмом ключових транзисторів ШІМ).

Взаємодія лінійної підсистеми із затримкою `e^{-s·τ}` та нелінійного елемента типу «насичення» формує стійкі періодичні коливання постійної амплітуди — **граничні цикли** (*limit cycles*, або автоколивання).

Для визначення частоти та амплітуди цих автоколивань застосуємо метод гармонійного балансу (функції опису, *Describing Function Method*).

Нехай на вхід нелінійного елемента насичення з порогом лінійності `a` та коефіцієнтом підсилення `k` надходить гармонійний сигнал помилки `e(t) = A · sin(ω·t)`. Якщо амплітуда перевищує поріг `A > a`, комплексна функція опису нелінійності `N(A)` дорівнює:

```
N(A) = (2·k / π) · [ arcsin(a / A) + (a / A) · √( 1 - (a / A)² ) ]
```

де `N(A)` є дійсною додатною функцією (`Im{N(A)} = 0`), яка монотонно зменшується від номінального значення `k` (при `A ≤ a`) до `0` (при `A → ∞`).

Рівняння гармонійного балансу замкненого контуру має вигляд:

```
1 + N(A) · L₀(jω) · e^{-j·ω·τ} = 0
⇒ L₀(jω) · e^{-j·ω·τ} = - 1 / N(A)
```

Оскільки годограф функції `-1 / N(A)` лежить виключно на від'ємній дійсній осі комплексної площини (промінь від `-1/k` до `-∞`), умова виникнення автоколивань розпадається на два незалежних рівняння для частоти коливань `ω_osc` та їхньої амплітуди `A_osc`:

1. **Фазовий баланс (визначає точну частоту коливань ω_osc):**

```
∠L₀(jω_osc) - ω_osc · τ = -180° = -π рад
```

Частота автоколивань `ω_osc` залежить виключно від фазових властивостей лінійного тракту та величини затримки `τ`. Чим більша затримка `τ`, тим нижчою є частота автоколивань.

2. **Амплітудний баланс (визначає стаціонарну амплітуду коливань A_osc):**

```
|L₀(jω_osc)| · 1 = 1 / N(A_osc)
⇒ N(A_osc) = 1 / |L₀(jω_osc)|
```

Якщо підсилення лінійної частини на частоті фазового перевороту перевищує одиницю (`|L₀(jω_osc)| > 1/k`), рівняння має єдиний стійкий розв'язок `A_osc > a`. Система входить у режим стійкого граничного циклу, амплітуда якого зростає пропорційно коефіцієнту підсилення регулятора та величині затримки `τ`.

Цей результат математично пояснює, чому типова спроба інженера «затиснути» нестійкість контуру шляхом збільшення коефіцієнтів PID-регулятора призводить лише до зростання амплітуди автоколивань `A_osc` та перегріву моторів. Єдиним математично коректним шляхом ліквідації автоколивань є компенсація фазового зсуву або перенесення точки корекції станів назад у часі на величину `τ`.
