Коли силова лінія напругою 10 кВ живить заводський цех зі струмом 500 А, підключити вимірювальний мікроконтролер безпосередньо через резистивний шунт неможливо: на шунті виділяться кіловати тепла, а високий потенціал фази миттєво спалить низьковольтну цифрову електроніку. Для безпечного вимірювання змінного струму промислової частоти та високочастотних комутаційних сплесків використовують електромагнітну гальванічну розв'язку. Попри схоже призначення, вони базуються на кардинально різній фізиці магнітних кіл: перший працює як трансформатор з феромагнітним осердям у режимі короткого замикання, а другий є повітряним диференціатором, вихідний сигнал якого вимагає подальшого інтегрування.

### 1. Трансформатор струму (CT): фізичний механізм, баланс ампер-витків та навантаження

Вимірювальний трансформатор струму принципово відрізняється від класичного силового трансформатора напруги способом увімкнення та режимом збудження магнітного потоку. Трансформатор напруги живиться від джерела стабільної напруги, тому амплітуда магнітного потоку в його осерді є практично постійною за будь-якого навантаження. Трансформатор струму вмикається своєю первинною обмоткою **послідовно** в розрив силового кола або охоплює силовий кабель як одновиткова шина (`N₁ = 1`).

Первинний струм `I₁` диктується зовнішнім навантаженням мережі (електродвигунами, печами, силовими трансформаторами) і жодним чином не залежить від опору вторинного кола самого датчика.

#### Закон ампер-витків та протидія розмагнічуванню

Первинний струм `I₁`, протікаючи крізь `N₁` витків (найчастіше крізь одне вікно осердя, `N₁ = 1`), створює первинну магніторушійну силу (МРС):

```
F₁ = N₁ · I₁    [первинна магніторушійна сила]
```

Ця МРС намагається створити в замкненому тороїдальному осерді з феромагнітного матеріалу (трансформаторної електротехнічної сталі, пермалою або нанокристалічного сплаву з високою відносною магнітною проникністю `μᵣ = 10 000 .. 80 000`) потужний змінний магнітний потік `Φ(t)`. Змінний магнітний потік за законом Фарадея наводить у вторинній обмотці з кількістю витків `N₂` (зазвичай `N₂ = 1000 .. 4000`) електрорушійну силу `e₂(t) = -N₂ · (dΦ/dt)`.

Під дією цієї ЕРС у замкненому вторинному колі виникає вторинний струм `I₂`, який створює власну зустрічну магніторушійну силу `F₂ = N₂ · I₂`. За правилом Ленца вторинна МРС спрямована строго проти первинної, розмагнічуючи осердя. Різниця цих сил утворює результуючу МРС намагнічування `F_m = N₁ · I_m`:

```
N₁ · I₁ − N₂ · I₂ = N₁ · I_m    [баланс магніторушійних сил]
```

де `I_m` — струм намагнічування, необхідний для підтримки фактичного магнітного потоку в залізі.

Оскільки магнітний опір замкненого високопроникного осердя без зазору `R_m = l_m / (μ₀ · μᵣ · A_c)` є надзвичайно малим, для створення робочого потоку потрібна мізерна намагнічуюча сила. У якісних трансформаторах струм намагнічування становить частки відсотка від первинного струму (`I_m << I₁`), тому результуючим членом `I_m` у першому наближенні нехтують:

```
N₁ · I₁ ≈ N₂ · I₂
I₂ ≈ I₁ · (N₁ / N₂) = I₁ / K_t    [ідеальне трансформування струму]
```

де `K_t = N₂ / N₁` — коефіцієнт трансформації за струмом. Наприклад, якщо `N₁ = 1`, `N₂ = 2000`, а первинний струм `I₁ = 100 А`, вторинний струм становить строго `I₂ = 100 / 2000 = 0.05 А = 50 мА`.

#### Навантажувальний резистор (Burden Resistor) та напруга магнітного потоку

Оскільки вторинна обмотка трансформатора струму є еквівалентним джерелом струму `I₂`, для перетворення цього струму на пропорційну напругу, зручну для вимірювання АЦП мікроконтролера, до вторинних виводів підключають низькоомний прецизійний навантажувальний резистор `R_b` (*burden resistor*).

Вихідна напруга, що подається на вимірювальний тракт:

```
V_out(t) = I₂(t) · R_b = (I₁(t) · N₁ / N₂) · R_b
```

Щоб з'ясувати, чому опір `R_b` не можна збільшувати безконтрольно, простежимо ланцюжок від напруги навантаження до магнітного стану осердя. ЕРС вторинної обмотки витрачається на падіння напруги на навантажувальному резисторі `R_b` та власному активному опорі мідного дроту обмотки `R_w2`:

```
e₂(t) = I₂(t) · (R_w2 + R_b)
```

З іншого боку, за законом електромагнітної індукції для гармонічного сигналу частоти `ω = 2π · f`:

```
E₂_max = ω · N₂ · Φ_max = ω · N₂ · B_max · A_c
```

де `B_max` — пікова магнітна індукція в осерді, `A_c` — площа поперечного перерізу магнітопроводу. Прирівнявши обидва вирази, знаходимо амплітуду магнітної індукції:

```
B_max = (I₂_max · (R_w2 + R_b)) / (ω · N₂ · A_c)    [вираження індукції через вторинну ЕРС]
      = (I₁_max · (R_w2 + R_b)) / (ω · N₂² · A_c)   [підстановка I₂ = I₁ / N₂]
```

З формули видно головне інженерне обмеження: що більший опір навантаження `R_b`, то вищу напругу мусить генерувати вторинна обмотка і то більшу індукцію `B_max` має підтримувати магнітне осердя. Якщо опір `R_b` завищити, індукція досягне порогу насичення матеріалу `B_sat` (для електротехнічної сталі `1.5 .. 1.8 Тл`, для пермалою `0.7 .. 1.0 Тл`, для нанокристалічних сплавів `1.2 .. 1.3 Тл`), трансформатор втратить лінійність і почне критично спотворювати форму сигналу.

#### Еквівалентна схема, фазовий зсув і втрати в осерді

Реальний трансформатор струму описується еквівалентною схемою, де паралельно ідеальному джерелу вторинного струму `I₂'` підключена вітка намагнічування:
- `L_m` — еквівалентна індуктивність намагнічування осердя;
- `R_fe` — опір, що моделює втрати потужності в залізі на гістерезис і вихрові струми Фуко;
- `R_w2` — активний опір вторинного дроту;
- `L_σ2` — паразитна індуктивність розсіювання вторинної обмотки;
- `R_b` — опір навантаження.

Струм намагнічування `I_m` має дві компоненти: активну `I_fe` (втрати на нагрів осердя) та реактивну індуктивну `I_μ` (створення потоку). Через це вторинний струм `I₂` відстає від протифазного первинного струму на невеликий кут втрат `δ` (*phase displacement angle*):

```
δ ≈ (I_fe · sin(θ) + I_μ · cos(θ)) / I₁    [фазова похибка CT в радіанах]
```

де `θ` — кут зсуву між вторинною напругою та струмом. Фазовий зсув `δ` типово становить від `0.1°` до `2.0°`. При вимірюванні суто активного струму споживача (`cos(φ) = 1.0`) похибка `δ` майже непомітна. Проте під час обліку електроенергії на індуктивних навантаженнях (наприклад, електродвигуни в режимі холостого ходу з `cos(φ) = 0.5`, `φ = 60°`) похибка у фазі всього на `1°` призводить до похибки розрахунку активної потужності `P = V · I · cos(φ)` понад `3%`!

#### Насичення осердя та напруга коліна (Knee-point Voltage)

Важливою метрологічною характеристикою вимірювального трансформатора струму є його крива намагнічування — залежність вторинної ЕРС від струму намагнічування `V₂(I_m)`. На цій кривій згідно зі стандартами IEC 61869-2 та IEEE C57.13 виділяють так звану **точку коліна** (*knee point*).

Точка коліна визначається як точка на характеристиці, в якій збільшення вторинної напруги на 10% вимагає збільшення струму намагнічування на 50%. Напруга коліна `V_k` позначає межу лінійної роботи: якщо в аварійному режимі (наприклад, при пусковому струмі двигуна `7 · I_ном`) необхідна напруга `I₂ · (R_w2 + R_b)` перевищує `V_k`, диференціальна магнітна проникність осердя стрімко падає до проникності вакууму `μ₀`, індуктивність `L_m` колапсує, а вторинний струм перестає повторювати первинний, перетворюючись на зрізані імпульси з нулями на піках синусоїди.

#### Матеріали осердя та температурний дрейф

Вибір магнітного матеріалу для вимірювального трансформатора струму визначає компроміс між порогом насичення, магнітною проникністю та втратами на перемагнічування:

| Матеріал осердя | Початкова проникність `μᵣ` | Індукція насичення `B_sat` | Втрати в залізі (50 Гц, 1 Тл) | Температурна стабільність |
| :--- | :--- | :--- | :--- | :--- |
| **Кремнієва сталь (CRGO)** | `5 000 .. 10 000` | `1.6 .. 1.8 Тл` | `0.8 .. 1.2 Вт/кг` | Висока (до +150 °C) |
| **Пермалой (80% Ni, 20% Fe)** | `50 000 .. 100 000` | `0.7 .. 0.8 Тл` | `0.1 .. 0.2 Вт/кг` | Середня (чутливий до ударів) |
| **Нанокристалічні сплави** | `80 000 .. 150 000` | `1.2 .. 1.3 Тл` | `0.05 .. 0.1 Вт/кг` | Відмінна (-40 .. +120 °C) |

Крім властивостей магнітопроводу, у вимірювальний тракт втручається температурний коефіцієнт опору мідного дроту вторинної обмотки `α_Cu ≈ +0.393% / °C`. Якщо при температурі +25 °C опір обмотки `R_w2 = 50 Ом`, то при нагріванні трансформатора струму всередині закритого розподільного щита до +75 °C опір зростає до `R_w2(75°C) = 50 · (1 + 0.00393 · 50) = 59.8 Ом` (зростання на 19.6%). Якщо навантажувальний резистор `R_b` має малий опір (наприклад, 10 Ом), сумарний вторинний опір `R_w2 + R_b` збільшується з 60 Ом до 69.8 Ом, що пропорційно підвищує необхідну ЕРС `e₂(t)` та магнітний потік `Φ_max`, зсуваючи точку роботи осердя ближче до насичення та змінюючи кут фазового зсуву `δ`.

### 2. Небезпека розімкненого вторинного кола (Open-Circuit Hazard)

Усі інженерні правила електробезпеки містять категоричну вимогу: **категорично заборонено розривати вторинне коло вимірювального трансформатора струму, коли через первинну обмотку протікає струм**. Розрив вторинного кола трансформатора напруги є штатним режимом холостого ходу, але для трансформатора струму розрив навантаження `R_b` стає важкою аварією з ризиком виникнення дуги та смертельного ураження персоналу.

![Небезпека розімкненого вторинного кола трансформатора струму](/root/hw/hw-sensing/current-transformer/img/ct-open-circuit-hazard.svg)
*Осцилограми індукції та високовольтних імпульсів при розриві вторинної обмотки CT і схема захисту.*

#### Фізика генерації кіловольтних сплесків

З'ясуймо ланцюг подій, що розгортається в осерді в момент розмикання вторинного кола (`I₂ = 0`):

1. **Зникнення зустрічної МРС:** Коли вторинне коло розімкнене, вторинний струм падає до нуля (`I₂ = 0`). Відповідно, зустрічна магніторушійна сила `F₂ = N₂ · I₂ = 0` повністю зникає.
2. **Повне намагнічування первинним струмом:** Первинний струм `I₁` диктується потужним навантаженням мережі і не може зменшитися. Тому вся первинна МРС `N₁ · I₁` (наприклад, `1 виток · 200 А = 200 А-витків`) повністю прикладається до намагнічування осердя як `F_m`. У штатному режимі для намагнічування використовувалося менше `1 А-витка`.
3. **Миттєве глибоке насичення:** Величезна надлишкова МРС за лічені мікросекунди заганяє феромагнітне осердя в стан граничного насичення `+B_sat` під час додатної півхвилі струму і в стан `-B_sat` під час від'ємної.
4. **Трапецієподібний магнітний потік:** Більшу частину періоду промислової частоти магнітна індукція залишається сталою і рівною `±B_sat`. Оскільки `dB/dt = 0`, ЕРС індукції в ці інтервали дорівнює нулю.
5. **Колосальна швидкість зміни потоку при переході через нуль:** Коли первинний змінний струм `I₁(t)` переходить через нульове значення і змінює знак, магнітна індукція в осерді вимушена перекинутися від `-B_sat` до `+B_sat` (перепад `ΔB = 2 · B_sat ≈ 3.0 .. 3.6 Тл`). Оскільки крутизна струму `dI₁/dt` поблизу нуля є максимальною, перемагнічування високопроникної сталі відбувається надзвичайно швидко — за час `Δt ≈ 5 .. 20 мкс`.
6. **Генерація голчастої кіловольтної ЕРС:** За законом Фарадея вторинна напруга дорівнює добутку кількості витків на швидкість зміни потоку:

```
e₂(t) = −N₂ · A_c · (dB / dt)
```

Підставимо типові значення для промислового трансформатора струму: `N₂ = 2000`, площа перерізу осердя `A_c = 4 см² = 4 · 10⁻⁴ м²`, розмах індукції `ΔB = 3.2 Тл`, час перевороту `Δt = 10 мкс`:

```
V_peak ≈ N₂ · A_c · (ΔB / Δt)               [закон Фарадея для пікової ЕРС]
       = 2000 · (4 · 10⁻⁴) · (3.2 / 10⁻⁵)   [підстановка геометричних параметрів осердя]
       = 2000 · (4 · 10⁻⁴) · 320 000        [розрахунок швидкості зміни магнітної індукції]
       = 2560 В                             [пікова напруга на розімкнених клемах]
```

На розімкнених клемах виникають короткі, гострі голчасті імпульси напруги амплітудою від **1.5 кВ до 5 кВ** (а в потужних підстанційних CT — до 10 кВ).

#### Наслідки та методи захисту

Наслідки виникнення високовольтних імпульсів є руйнівними:
- **Електричний пробій ізоляції:** Напруга 3 кВ миттєво пробиває міжемалеву ізоляцію вторинної обмотки, спричиняючи міжвиткове коротке замикання, обвуглювання каркаса та пожежу в щиті.
- **Дуговий розряд на оператора:** При спробі від'єднати вимірювальний прилад під навантаженням на клемах спалахує високовольтна дуга, що завдає опіків та ураження електричним струмом.
- **Перегрів та руйнування осердя:** Глибоке перемагнічування на повну петлю гістерезису 100 разів на секунду спричиняє гігантські втрати на перемагнічування та вихрові струми. За лічені хвилини осердя розігрівається до сотень градусів Цельсія, втрачає магнітні властивості (точка Кюрі) і руйнує пластиковий корпус.
- **Залишкове намагнічування:** Навіть якщо аварію швидко усунули, сталь набуває сильного залишкового намагнічування `B_r`, через що похибка вимірювань CT зростає на порядки до моменту проведення спеціального циклу розмагнічування змінним полем спадної амплітуди.

Для безпечної експлуатації застосовують інженерні засоби захисту:
1. **Закорочувальні випробувальні блоки (*Shorting blocks*):** Спеціальні клемні колодки, обладнані закорочувальними ножами або гвинтовими перемичками. Перед від'єднанням лічильника або амперметра вторинну обмотку CT обов'язково надійно закорочують перемичкою безпосередньо на клемнику. Оскільки в режимі КЗ напруга дорівнює нулю, струм `I₂` циркулює безпечно, не перегріваючи осердя.
2. **Вбудовані напівпровідникові супресори (TVS-діоди та варистори):** На друкованих платах систем моніторингу паралельно виводам вторинної обмотки встановлюють зустрічно-паралельні потужні TVS-діоди (наприклад, симетричний 1.5KE15CA) або варистори (MOV). Якщо резистор `R_b` випадково відпаяється або вийде з ладу, TVS-діод відкриється при напрузі `±15 В`, надійно обмеживши високовольтний сплеск і зашунтувавши вторинний струм на себе.

### 3. Котушка Роговського: фізичний принцип, геометрія та відсутність насичення

Коли необхідно виміряти струми короткого замикання в десятки кілоампер, комутаційні струми з крутизною `di/dt > 10 кА/мкс` у силових перетворювачах або встановити датчик на масивну шину в тісному електрощиті без розбирання з'єднань, класичний трансформатор струму стає непридатним: залізне осердя влітає в насичення, а жорсткий важкий тороїд неможливо надіти на кабель.

Розв'язанням цієї задачі є **котушка Роговського** (*Rogowski coil*) — гнучкий або жорсткий тороїдальний соленоїд без феромагнітного осердя.

![Конструкція котушки Роговського та компенсація зовнішніх полів](/root/hw/hw-sensing/current-transformer/img/rogowski-coil-construction.svg)
*Будова котушки Роговського з центральним зворотним провідником та математична модель.*

#### Фізичний принцип: повітряне інтегрування за контуром

Котушка Роговського являє собою багатовитковий соленоїд, намотаний на немагнітний каркас (силіконовий шнур, гнучку трубку з тефлону або багатошарову друковану плату FR4) зі строго постійною площею поперечного перерізу витка `A` та постійною лінійною густиною намотки `n = N / l` витків на метр довжини. Магнітна проникність осердя дорівнює магнітній проникності вакууму:

```
μ = μ₀ = 4π · 10⁻⁷ Гн/м    [повітряне/немагнітне осердя]
```

Розглянемо малий елемент довжини котушки `dl`. Кількість витків на цьому відрізку становить `dN = n · dl`. Якщо в точці розташування елемента діє магнітне поле з напруженістю `H`, проєкція вектора магнітної індукції на вісь витків дорівнює `B_l = μ₀ · H_l = μ₀ · H · cos(α)`, де `α` — кут між вектором магнітного поля та дотичною до осі соленоїда.

Магнітний потік, що пронизує витки на відрізку `dl`:

```
dΨ = dN · B_l · A = (n · dl) · (μ₀ · H_l) · A = μ₀ · n · A · H · dl
```

Інтегруючи вздовж усього замкненого контуру довжиною `l`, отримуємо повне потокозчеплення котушки:

```
Ψ = ∮ μ₀ · n · A · H · dl
  = μ₀ · n · A · ∮ H · dl    [оскільки n = const і A = const виносяться за знак інтеграла]
```

За законом циркуляції Ампера лінійний інтеграл вектора напруженості магнітного поля вздовж будь-якого замкненого контуру строго дорівнює повному електричному струму `i(t)`, охопленому цим контуром:

```
∮ H · dl = i(t)    [теорема про циркуляцію магнітного поля]
```

Підставивши теорему циркуляції у вираз для потокозчеплення, маємо:

```
Ψ(t) = μ₀ · n · A · i(t) = M · i(t)
```

де `M = μ₀ · n · A` — коефіцієнт взаємної індуктивності між вимірюваним провідником та котушкою Роговського.

За законом електромагнітної індукції Фарадея вихідна напруга розімкненої котушки є похідною потокозчеплення за часом:

```
v(t) = −dΨ(t) / dt = −M · (di(t) / dt)    [вихідна напруга котушки Роговського]
```

З цього фундаментального виведення випливають ключові висновки:
1. **Інваріантність до форми контуру та положення провідника:** Якщо `n = const` та `A = const`, вихідний сигнал котушки залежить **виключно** від струму `i(t)` і абсолютно не залежить від того, де саме провідник проходить крізь вікно (по центру чи біля краю), який кут він утворює з площиною тороїда і яку геометричну форму має сама петля (коло, овал чи прямокутник).
2. **Повна нечутливість до зовнішніх струмів:** Будь-який провідник зі струмом `i_ext(t)`, розташований **поза** контуром котушки, дає нульову циркуляцію `∮ H_ext · dl = 0`, а отже, його магнітне поле не створює напруги на виході ідеальної котушки Роговського.

Детальніше про історію відкриття та еволюцію цього приладу читайте у вставці [📜 історія створення від потенціометра Чаттока до досліджень Роговського](root:hw-sensing/current-transformer/hist-rogowski-coil.md).

#### Центральний зворотний провідник (Return Conductor)

Під час практичного виготовлення котушки виникає серйозна конструктивна пастка. Якщо просто намотати дріт спіраллю від початку каркаса до його кінця і вивести два дроти, витки спіралі утворюють один великий круговий паразитний контур площею `S_loop = π · r₀²`, що збігається з площиною всього тороїда. Цей паразитний контур вловлюватиме зовнішні поперечні магнітні поля (наприклад, від сусідніх фаз трифазної системи або силового трансформатора поруч) за законом Фарадея `v_noise = -S_loop · (dB_ext / dt)`.

Щоб повністю ліквідувати цю паразитна площу, застосовують спеціальну топологію: дійшовши до кінця обмотки, провідник повертають назад крізь **геометричний центр усіх витків** уздовж поздовжньої осі каркаса до початкового виводу. Таким чином, зворотний провідник створює точно такий самий за площею круговий контур, але зі зворотним напрямком обходу струму. Їхні паразитні площі взаємно віднімаються (`S_res = S_loop - S_return = 0`), роблячи котушку стійкою до зовнішніх електромагнітних завад.

#### Планарні котушки Роговського на друкованих платах (PCB Rogowski)

Для вимірювання струмів у силових електронних модулях (інверторах на SiC MOSFET та IGBT транзисторах, сервоприводах) замість дротяних котушок використовують **планарні котушки Роговського**, витравлені безпосередньо у шарах багатошарової друкованої плати (PCB).

Геометрія такої котушки формується за допомогою 4- або 6-шарової топології:
1. Радіальні доріжки на верхньому (Top) та нижньому (Bottom) шарах плати утворюють радіальні сегменти витків навколо отвору під силовий вивід транзистора.
2. Металізовані наскрізні або глухі перехідні отвори (*vias*) з'єднують верхні й нижні доріжки, формуючи замкнену гвинтову спіраль.
3. Зворотний провідник трасується на одному з внутрішніх сигнальних шарів (Inner Layer) строго по середньому радіусу спіралі.

Планарне виконання забезпечує ідеальну повторюваність параметрів: відхилення взаємної індуктивності `M` між зразками на серійному виробництві становить менше ніж `0.1%`, монтажний зазор `Δl = 0` відсутній у принципі, а власна резонансна частота сягає `50 .. 100 МГц`, що дозволяє фіксувати надшвидкі струми короткого замикання транзисторів за час менше 100 наносекунд.

#### Порівняння: Трансформатор струму проти котушки Роговського

| Параметр | Трансформатор струму (CT) | Котушка Роговського (Rogowski Coil) |
| :--- | :--- | :--- |

### 4. Схемотехніка інтеграторів для котушки Роговського

Оскільки вихідна напруга котушки Роговського пропорційна не самому струму, а його похідній за часом `v(t) = -M · (di/dt)`, для отримання сигналу, пропорційного миттєвому значенню струму `i(t)`, сигнал необхідно математично або апаратно проінтегрувати:

```
i(t) = −(1 / M) · ∫ v(t) dt
```

Для гармонічного струму `i(t) = I_m · sin(ωt)` похідна дорівнює `di/dt = ω · I_m · cos(ωt)`. Вихідна напруга котушки становить `v(t) = -M · ω · I_m · cos(ωt)`. Похідна вносить фазовий зсув `+90°` та амплітудну залежність, пропорційну частоті `ω`. Операція інтегрування мусить забезпечити коефіцієнт передачі `1 / ω` та компенсуючий зсув фази `-90°` в усьому робочому частотному діапазоні.

![Схемотехніка аналогового та цифрового інтеграторів](/root/hw/hw-sensing/current-transformer/img/integrator-analog-digital.svg)
*Аналоговий інтегратор із витоком на ОП та цифровий конвеєр обробки сигналу в мікроконтролері.*

#### Аналоговий активний інтегратор із витоком (Leaky Integrator)

Ідеальний операційний інтегратор на ОП складається з вхідного резистора `R_in` та конденсатора зворотного зв'язку `C_int`:

```
v_out(t) = −(1 / (R_in · C_int)) · ∫ v_in(t) dt
```

У частотній області його передатна функція має вигляд `H(s) = -1 / (s · R_in · C_int)`. На постійному струмі (`ω → 0`) коефіцієнт підсилення ідеального інтегратора прямує до нескінченності (`|H(0)| → ∞`). Будь-яка реальна постійна напруга зміщення операційного підсилювача `V_os` (навіть одиниці мікровольт) або вхідний струм витоку `I_b` поступово інтегруються в часі, заряджаючи конденсатор `C_int`, через що вихід ОП за лічені секунди неминуче «пливе» і впирається в шину живлення (*saturation rail*).

Щоб стабілізувати схему на постійному струмі, паралельно інтегруючому конденсатору `C_int` встановлюють високоомний резистор витоку `R_f` (*bleed / feedback resistor*).

Отримана схема є активним фільтром низьких частот першого порядку. Її передатна функція у просторі Лапласа:

```
H_int(s) = −(R_f / R_in) / (1 + s · R_f · C_int)
```

Частота зрізу ФНЧ визначається часовою сталою зворотного зв'язку `τ = R_f · C_int`:

```
f_c = 1 / (2π · R_f · C_int)    [нижня частота зрізу інтегратора]
```

Робота схеми ділиться на дві частотні області:
1. **Область низьких частот (`f << f_c`):** Конденсатор розімкнений, схема працює як звичайний інвертуючий підсилювач із фіксованим постійним коефіцієнтом підсилення `K_dc = -R_f / R_in`. Напруга зміщення ОП підсилюється лише в `R_f / R_in` разів і не призводить до дрейфу виходу.
2. **Область інтегрування (`f >> f_c`):** На частотах, значно вищих за `f_c`, членом `1` у знаменнику можна знехтувати порівняно з `s · R_f · C_int`:

```
H_int(jω) ≈ −(R_f / R_in) / (jω · R_f · C_int) = −1 / (jω · R_in · C_int)
```

Схема працює як чистий інтегратор із вихідною напругою:

```
V_out(t) = (M / (R_in · C_int)) · i(t)
```

Щоб похибка інтегрування на промисловій частоті мережі `f = 50 Гц` була мінімальною, частоту зрізу обирають значно нижчою: `f_c ≤ 0.5 .. 1.0 Гц` (тобто `R_f · C_int ≥ 0.3 .. 1.0 с`). Наприклад, при `C_int = 100 нФ` опір витоку обирають `R_f = 3.3 .. 10 МОм`.

Строге математичне виведення амплітудних та фазових похибок наведено у вставці [🧮 математична модель та частотна характеристика котушки Роговського](root:hw-sensing/current-transformer/math-rogowski-transfer.md).

#### Схемотехнічні вимоги до аналогового інтегратора

Для забезпечення метрологічної точності до компонентів аналогового інтегратора висуваються жорсткі вимоги:
- **Операційний підсилювач:** Обов'язкове використання ОП із польовими транзисторами на вході (JFET або CMOS) із надмалим вхідним струмом зміщення `I_b < 1 пА` та низькою напругою зміщення нуля `V_os < 50 мкВ` (наприклад, OPA320, OPA189 з автопідстроюванням нуля *Zero-Drift*, AD8605). Звичайні біполярні ОП типу LM358 із вхідним струмом `I_b = 50 нА`, протікаючи крізь резистор `R_f = 10 МОм`, створюють паразитне зміщення `0.5 В`, що спотворює динамічний діапазон АЦП.
- **Інтегруючий конденсатор:** Категорично заборонено застосовувати керамічні конденсатори класу X7R/Y5V через п'єзоефект, температурний коефіцієнт та діелектричну абсорбцію. Застосовують виключно прецизійні поліпропіленові (*polypropylene*) плівкові конденсатори або прецизійну кераміку NP0/C0G із діелектричними втратами `tan(δ) < 0.0005`.

#### Цифровий інтегратор (DSP у мікроконтролері)

У сучасних вбудованих системах від громіздкого та чутливого до дрейфу аналогового інтегратора часто відмовляються: слабкий сигнал із котушки Роговського лише підсилюють малошумним інструментальним підсилювачем, пропускають крізь простий антиаліасинговий ФНЧ і оцифровують швидким АЦП мікроконтролера з частотою дискретизації `f_s ≥ 10 .. 50 кГц`. Усе інтегрування виконується чисельно в ядрі процесора.

Цифровий конвеєр обробки складається з трьох послідовних кроків:

**Крок 1. Цифрове блокування постійної складової (DC-Blocking IIR Filter):**
Перед інтегруванням будь-яке апаратне зміщення АЦП (половина живлення `V_dd / 2` або дрейф нуля) має бути видалене, інакше цифровий інтегратор накопичуватиме помилку. Застосовують рекурсивний ФВЧ 1-го порядку:

```
x_hp[n] = x_raw[n] − x_raw[n-1] + α_dc · x_hp[n-1]
```

де коефіцієнт фільтра `α_dc = 1 − (2π · f_hp / f_s) ≈ 0.999 .. 0.9995` задає частоту зрізу `f_hp ≈ 0.5 Гц`.

**Крок 2. Цифровий інтегратор за правилом трапецій (Метод Тастіна / Більнійне перетворення):**
Чисельне інтегрування за методом трапецій забезпечує точне збереження форми сигналу:

```
y_int[n] = y_int[n-1] + (T_s / 2) · (x_hp[n] + x_hp[n-1])
```

де `T_s = 1 / f_s` — період дискретизації.

Щоб запобігти накопиченню похибок округлення чисел з плаваючою комою у довготривалій перспективі, застосовують «витікаючий» чисельний інтегратор (*leaky digital integrator*):

```
y_int[n] = λ_leak · y_int[n-1] + (T_s / 2) · (x_hp[n] + x_hp[n-1])
```

де коефіцієнт витоку `λ_leak = 1 − (T_s / τ_leak) ≈ 0.999 .. 0.9995` гарантує стійкість системи.

**Крок 3. Масштабування та фазова корекція:**
Отримане значення множиться на калібрувальний коефіцієнт чутливості котушки `K_scale = 1 / (M · G_analog)` та подається на блок розрахунку середньоквадратичного значення струму (True RMS) та потужності.

### 5. Програмна реалізація: драйвер обробки сигналів CT та Роговського

Нижче наведено повну реалізацію драйвера обробки сигналів для вимірювальних трансформаторів струму та котушок Роговського на мовах C та C++. Драйвер виконує потокову обробку сирих відліків АЦП, цифрове зняття зміщення, чисельне інтегрування методом трапецій для котушки Роговського, калібрування фазового зсуву та обчислення середньоквадратичного струму (True RMS), активної потужності `P`, повної потужності `S` і коефіцієнта потужності `PF`.

```c
#include <stdint.h>
#include <stdbool.h>
#include <math.h>

#define POWER_SAMPLE_WINDOW_SIZE 200

typedef enum {
    CURRENT_SENSOR_TYPE_CT,
    CURRENT_SENSOR_TYPE_ROGOWSKI
} CurrentSensorType;

typedef struct {
    CurrentSensorType sensor_type;
    float sample_rate_hz;
    float vref_volts;
    uint32_t adc_max_counts;
    
    // Параметри для CT
    float ct_turns_ratio;       // N2 / N1 (наприклад 2000.0f)
    float ct_burden_resistor;   // Rb в Омах (наприклад 33.0f)
    float ct_phase_cal_deg;     // Фазова компенсація в градусах
    
    // Параметри для Rogowski
    float rogowski_mutual_inductance; // M в Генрі (наприклад 1.2e-7f)
    float rogowski_analog_gain;       // Підсилення аналогового каскаду
    float rogowski_leaky_lambda;      // Коефіцієнт витоку (наприклад 0.9992f)
} CurrentSensorConfig;

typedef struct {
    CurrentSensorConfig config;
    
    // Стан фільтра DC-Blocker
    float dc_filter_x_prev;
    float dc_filter_y_prev;
    float dc_filter_alpha;
    
    // Стан інтегратора Роговського
    float integrator_state;
    float integrator_x_prev;
    
    // Буфер та акумулятори потужності
    float sum_i_squared;
    float sum_v_squared;
    float sum_active_power;
    uint32_t sample_count;
    
    // Поточні розраховані результати
    float i_rms_amperes;
    float v_rms_volts;
    float active_power_watts;
    float apparent_power_va;
    float power_factor;
} CurrentSenseDriver;

void current_sensor_init(CurrentSenseDriver *drv, const CurrentSensorConfig *cfg) {
    drv->config = *cfg;
    drv->dc_filter_x_prev = 0.0f;
    drv->dc_filter_y_prev = 0.0f;
    
    // Розрахунок коефіцієнта ФВЧ для зрізу на 0.5 Гц
    float dt = 1.0f / cfg->sample_rate_hz;
    float rc = 1.0f / (2.0f * 3.1415926535f * 0.5f);
    drv->dc_filter_alpha = rc / (rc + dt);
    
    drv->integrator_state = 0.0f;
    drv->integrator_x_prev = 0.0f;
    
    drv->sum_i_squared = 0.0f;
    drv->sum_v_squared = 0.0f;
    drv->sum_active_power = 0.0f;
    drv->sample_count = 0;
    
    drv->i_rms_amperes = 0.0f;
    drv->v_rms_volts = 0.0f;
    drv->active_power_watts = 0.0f;
    drv->apparent_power_va = 0.0f;
    drv->power_factor = 1.0f;
}

// Обробка одного циклу вимірювання (струм + напруга мережі)
void current_sensor_process_sample(CurrentSenseDriver *drv, uint32_t raw_adc_i, float voltage_instant_v) {
    // 1. Переведення сирого відліку АЦП у вольти
    float v_adc = ((float)raw_adc_i / (float)drv->config.adc_max_counts) * drv->config.vref_volts;
    
    // 2. Блокування постійної складової (DC-Offset removal)
    float x_ac = v_adc - drv->dc_filter_x_prev + drv->dc_filter_alpha * drv->dc_filter_y_prev;
    drv->dc_filter_x_prev = v_adc;
    drv->dc_filter_y_prev = x_ac;
    
    float current_amperes = 0.0f;
    
    // 3. Обробка згідно з типом датчика
    if (drv->config.sensor_type == CURRENT_SENSOR_TYPE_CT) {
        // Для CT: струм через резистор навантаження Rb
        float i_secondary = x_ac / drv->config.ct_burden_resistor;
        current_amperes = i_secondary * drv->config.ct_turns_ratio;
    } else {
        // Для котушки Роговського: дискретне чисельне інтегрування Трапецій (Tustin)
        float dt = 1.0f / drv->config.sample_rate_hz;
        drv->integrator_state = (drv->config.rogowski_leaky_lambda * drv->integrator_state) + 
                                (0.5f * dt * (x_ac + drv->integrator_x_prev));
        drv->integrator_x_prev = x_ac;
        
        // Масштабування: i(t) = (1 / M) * v_int / G_analog
        float gain = drv->config.rogowski_mutual_inductance * drv->config.rogowski_analog_gain;
        if (gain > 1e-12f) {
            current_amperes = drv->integrator_state / gain;
        }
    }
    
    // 4. Накопичення середньоквадратичних та енергетичних сум
    drv->sum_i_squared += current_amperes * current_amperes;
    drv->sum_v_squared += voltage_instant_v * voltage_instant_v;
    drv->sum_active_power += voltage_instant_v * current_amperes;
    drv->sample_count++;
    
    // 5. Оновлення вихідних метрик при накопиченні вікна
    if (drv->sample_count >= POWER_SAMPLE_WINDOW_SIZE) {
        float inv_n = 1.0f / (float)drv->sample_count;
        
        drv->i_rms_amperes = sqrtf(drv->sum_i_squared * inv_n);
        drv->v_rms_volts = sqrtf(drv->sum_v_squared * inv_n);
        drv->active_power_watts = drv->sum_active_power * inv_n;
        drv->apparent_power_va = drv->v_rms_volts * drv->i_rms_amperes;
        
        if (drv->apparent_power_va > 1e-3f) {
            drv->power_factor = drv->active_power_watts / drv->apparent_power_va;
            if (drv->power_factor > 1.0f) drv->power_factor = 1.0f;
            if (drv->power_factor < -1.0f) drv->power_factor = -1.0f;
        } else {
            drv->power_factor = 1.0f;
        }
        
        // Скидання акумуляторів
        drv->sum_i_squared = 0.0f;
        drv->sum_v_squared = 0.0f;
        drv->sum_active_power = 0.0f;
        drv->sample_count = 0;
    }
}
```

```cpp
#include <cstdint>
#include <cmath>
#include <numbers>
#include <span>
#include <algorithm>

namespace sensing {

enum class SensorType {
    CurrentTransformer,
    RogowskiCoil
};

struct SensorConfig {
    SensorType type{SensorType::CurrentTransformer};
    float sampleRateHz{10000.0f};
    float vrefVolts{3.3f};
    uint32_t adcMaxCounts{4095};

    // Параметри CT
    float ctTurnsRatio{2000.0f};
    float ctBurdenResistorOhms{33.0f};
    float ctPhaseOffsetDeg{0.5f};

    // Параметри Rogowski
    float rogowskiMutualInductanceH{1.2e-7f};
    float rogowskiAnalogGain{50.0f};
    float rogowskiLeakyLambda{0.9992f};
};

struct PowerMetrics {
    float iRmsAmperes{0.0f};
    float vRmsVolts{0.0f};
    float activePowerWatts{0.0f};
    float apparentPowerVa{0.0f};
    float powerFactor{1.0f};
};

class CurrentSenseChannel {
public:
    explicit CurrentSenseChannel(const SensorConfig& config) noexcept
        : config_(config) {
        reset();
    }

    void reset() noexcept {
        const float dt = 1.0f / config_.sampleRateHz;
        constexpr float cutoffHz = 0.5f;
        const float rc = 1.0f / (2.0f * std::numbers::pi_v<float> * cutoffHz);
        dcFilterAlpha_ = rc / (rc + dt);

        dcFilterXPrev_ = 0.0f;
        dcFilterYPrev_ = 0.0f;
        integratorState_ = 0.0f;
        integratorXPrev_ = 0.0f;

        sumISquared_ = 0.0f;
        sumVSquared_ = 0.0f;
        sumActivePower_ = 0.0f;
        sampleCount_ = 0;
        metrics_ = {};
    }

    // Обробка поодинокого виміру
    void processSample(uint32_t rawAdcI, float instantVoltageV) noexcept {
        const float vAdc = (static_cast<float>(rawAdcI) / static_cast<float>(config_.adcMaxCounts)) * config_.vrefVolts;

        // IIR DC-Blocker
        const float xAc = vAdc - dcFilterXPrev_ + dcFilterAlpha_ * dcFilterYPrev_;
        dcFilterXPrev_ = vAdc;
        dcFilterYPrev_ = xAc;

        float currentA = 0.0f;

        if (config_.type == SensorType::CurrentTransformer) {
            const float iSec = xAc / config_.ctBurdenResistorOhms;
            currentA = iSec * config_.ctTurnsRatio;
        } else {
            const float dt = 1.0f / config_.sampleRateHz;
            integratorState_ = (config_.rogowskiLeakyLambda * integratorState_) +
                               (0.5f * dt * (xAc + integratorXPrev_));
            integratorXPrev_ = xAc;

            const float totalGain = config_.rogowskiMutualInductanceH * config_.rogowskiAnalogGain;
            if (totalGain > 1e-12f) {
                currentA = integratorState_ / totalGain;
            }
        }

        sumISquared_ += currentA * currentA;
        sumVSquared_ += instantVoltageV * instantVoltageV;
        sumActivePower_ += instantVoltageV * currentA;
        ++sampleCount_;

        constexpr uint32_t windowSize = 200;
        if (sampleCount_ >= windowSize) {
            updateMetrics(windowSize);
        }
    }

    // Пакетна обробка буфера
    void processBatch(std::span<const uint32_t> rawAdcBuffer, std::span<const float> voltageBuffer) noexcept {
        const size_t n = std::min(rawAdcBuffer.size(), voltageBuffer.size());
        for (size_t i = 0; i < n; ++i) {
            processSample(rawAdcBuffer[i], voltageBuffer[i]);
        }
    }

    [[nodiscard]] const PowerMetrics& metrics() const noexcept {
        return metrics_;
    }

private:
    void updateMetrics(uint32_t windowSize) noexcept {
        const float invN = 1.0f / static_cast<float>(windowSize);

        metrics_.iRmsAmperes = std::sqrt(sumISquared_ * invN);
        metrics_.vRmsVolts = std::sqrt(sumVSquared_ * invN);
        metrics_.activePowerWatts = sumActivePower_ * invN;
        metrics_.apparentPowerVa = metrics_.vRmsVolts * metrics_.iRmsAmperes;

        if (metrics_.apparentPowerVa > 1e-3f) {
            metrics_.powerFactor = std::clamp(metrics_.activePowerWatts / metrics_.apparentPowerVa, -1.0f, 1.0f);
        } else {
            metrics_.powerFactor = 1.0f;
        }

        sumISquared_ = 0.0f;
        sumVSquared_ = 0.0f;
        sumActivePower_ = 0.0f;
        sampleCount_ = 0;
    }

    SensorConfig config_;
    float dcFilterAlpha_{0.999f};
    float dcFilterXPrev_{0.0f};
    float dcFilterYPrev_{0.0f};
    float integratorState_{0.0f};
    float integratorXPrev_{0.0f};

    float sumISquared_{0.0f};
    float sumVSquared_{0.0f};
    float sumActivePower_{0.0f};
    uint32_t sampleCount_{0};

    PowerMetrics metrics_{};
};

} // namespace sensing
```

### Типові інженерні помилки та діагностика

1. **Неправильний вибір потужності навантажувального резистора `R_b`:**
   У трансформаторах струму з виходом 5 А (наприклад, вторинний струм при номіналі `I₂ = 5 А`) вибір `R_b = 1 Ом` призводить до тепловиділення `P = I² · R_b = 25 Вт`. Резистор перегрівається, змінює свій опір через температурний коефіцієнт (TCR) або згоряє, спричиняючи аварійне розмикання вторинного кола. Для великих вторинних струмів застосовують або міліомні шунти, або перетворювачі струм-напруга на ОП.
2. **Відсутність фазового калібрування при розрахунку активної потужності:**
   Приймаючи фазовий зсув CT за нуль, розробники отримують спотворення показників лічильника електроенергії при індуктивному або ємнісному навантаженні. Фазовий зсув `δ` мусить вноситися як калібрувальна стала в алгоритм розрахунку потужності.
3. **Нехтування компенсацією витоку в інтеграторі Роговського:**
   Використання чистого чисельного інтегратора `y[n] = y[n-1] + K · x[n]` без IIR-блокатора постійної складової та коефіцієнта витоку `λ < 1.0` гарантовано призводить до накопичення дрейфу від шуму квантування АЦП та виходу результату за межі розрядності чисел з плаваючою комою.
4. **Нещільне замикання замка гнучкого пояса Роговського:**
   Якщо рознімний замок котушки Роговського не замкнений до кінця і між торцями залишається зазор `Δl`, умова постійності густини намотки `n = const` порушується. Вихідний сигнал стає залежним від просторового положення кабелю всередині петлі, а похибка зростає з 0.5% до 5–10%.

> 🔧 **Навіщо це.** Вибір між трансформатором струму та котушкою Роговського визначається вимогами задачі:
> - **Трансформатор струму (CT)** — ідеальний вибір для комерційного обліку електроенергії (50/60 Гц) з фіксованим діапазоном струмів (від 1 А до 1000 А), де потрібна максимальна точність (класи 0.2S, 0.5S), автономність (сигнал можна знімати без активного живлення ОП) та мінімальна вартість вузла.
> - **Котушка Роговського** — безальтернативний інструмент для вимірювання надпотужних імпульсних струмів (зварювання, розряди блискавок, захист підстанцій від струмів КЗ до 100 кА), аналізу швидких фронтів у силовій електроніці (SiC/GaN інвертори `di/dt > 5 кА/мкс`) та модернізації вузлів обліку на діючих об'єктах, де гнучкий пояс можна заклацнути навколо товстої шини без зупинки виробництва та відключення напруги.
