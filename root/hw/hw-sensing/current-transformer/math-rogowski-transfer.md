# 🧮 Математична модель та частотна характеристика котушки Роговського

Математичний апарат котушки Роговського пов'язує просторову геометрію повітряного тороїдального контуру, взаємну індуктивність із вимірюваним провідником, резонансні перехідні процеси на високих частотах, вплив несиметрії намотки та частотно-фазові похибки активного й пасивного інтегрування.

### 1. Виведення взаємної індуктивності ідеального тороїда

Розглянемо нескінченно довгий прямий провідник зі струмом `i(t)`, розташований перпендикулярно до площини тороїдальної котушки Роговського. Нехай тороїд має середній радіус кільця `r₀`, площу поперечного перерізу витка `A`, повну кількість витків `N` та геометричну довжину осьової лінії `l = 2π · r₀`. Лінійна густина витків становить `n = N / (2π · r₀)` витків на метр.

За законом Біо — Савара — Лапласа модуль вектора напруженості магнітного поля `H(r)` на радіальній відстані `r` від осі провідника дорівнює:

```
H(r) = i(t) / (2π · r)    [циркулярне магнітне поле прямого струму]
```

Оскільки каркас котушки виготовлено з немагнітного діелектрика (силікону, тефлону або склотекстоліту FR4), відносна магнітна проникність середовища дорівнює одиниці (`μᵣ = 1`). Магнітна індукція у витках:

```
B(r) = μ₀ · H(r)
     = μ₀ · i(t) / (2π · r)    [магнітна індукція в повітряному середовищі]
```

Для тонкого тороїда, радіус витка якого `r_w` значно менший за радіус усього тороїда `r₀` (`r_w << r₀`), магнітне поле всередині витка з високою точністю вважається однорідним і рівним полю на центральній осі `r₀`. Тоді магнітний потік `Φ₁(t)`, що пронизує площу одного витка:

```
Φ₁(t) = B(r₀) · A
      = (μ₀ · i(t) / (2π · r₀)) · A    [магнітний потік крізь один виток]
```

Повне потокозчеплення `Ψ(t)` усієї котушки, що складається з послідовно з'єднаних `N` витків:

```
Ψ(t) = N · Φ₁(t)                                   [сумування потоків усіх витків]
     = N · (μ₀ · i(t) · A) / (2π · r₀)             [підстановка потоку одного витка]
     = μ₀ · (N / (2π · r₀)) · A · i(t)             [групування просторових факторів]
     = μ₀ · n · A · i(t)                           [використання лінійної густини n]
```

За законом електромагнітної індукції Фарадея електрорушійна сила `v(t)`, що наводиться на виводах розімкненої котушки:

```
v(t) = −dΨ(t) / dt                                 [закон Фарадея]
     = −μ₀ · n · A · (di(t) / dt)                  [диференціювання потокозчеплення]
     = −M · (di(t) / dt)                           [означення взаємної індуктивності M]
```

де коефіцієнт взаємної індуктивності `M` повністю визначається конструктивними геометричними параметрами датчика:

```
M = μ₀ · n · A = μ₀ · (N / (2π · r₀)) · A
```

### 2. Інваріантність положення та вплив зазору намотки

Ключовою математичною перевагою котушки Роговського є незалежність вихідного сигналу від просторового положення провідника всередині вікна тороїда. Доведемо це через теорему про циркуляцію.

Нехай провідник зміщений від геометричного центру на вектор `r_c`. Для довільного замкненого контуру, вздовж якого орієнтовані нормалі витків площею `A`, елементарне потокозчеплення дорівнює:

```
dΨ = dN · B_n · A = (n · dl) · (μ₀ · H · cos(α)) · A = μ₀ · n · A · (H · dl)
```

де `α` — кут між вектором напруженості `H` та дотичним вектором `dl` до осі котушки. Інтегруючи вздовж усього замкненого контуру довжиною `l`:

```
Ψ = ∮ μ₀ · n · A · (H · dl)                        [інтеграл уздовж замкненої осі]
  = μ₀ · n · A · ∮ H · dl                          [винесення констант n та A]
  = μ₀ · n · A · i(t)                              [застосування теореми циркуляції]
```

Оскільки за теоремою Ампера лінійний інтеграл `∮ H · dl` дорівнює сумарному охопленому струму `i(t)` незалежно від координат провідника, взаємна індуктивність `M` залишається строго інваріантною:

```
M(r_c) = M₀ = μ₀ · n · A = const
```

#### Похибка від наявності розімкненого замка (Gap Error)

Якщо в рознімній гнучкій котушці між торцями виникає монтажний повітряний розрив довжиною `Δl`, де витки відсутні, інтеграл розривається. Похибка взаємної індуктивності `ΔM` стає функцією відстані `x` від провідника до зазору:

```
ΔM / M₀ ≈ −(Δl / (2π · r₀)) · [ 1 + (x / r₀) · cos(φ) ]
```

де `φ` — кут між напрямком на провідник та лінією розрізу. Звідси випливає фундаментальна інженерна вимога: для зменшення похибки нецентрованості кабелю до величини `< 0.5%` відносний розмір стику мусить задовольняти умову `Δl / (2π · r₀) < 0.002`.

### 3. Еквівалентна схема, резонанс та демпфування

Повна еквівалентна схема котушки Роговського містить власну індуктивність соленоїда `L_c`, активний опір мідного проводу `R_c`, розподілену міжелектродну та кабельну ємність `C_c` і навантажувальний демпфуючий резистор `R_d`.

Власна індуктивність тороїдальної одношарової котушки без осердя:

```
L_c = μ₀ · n² · A · l = μ₀ · (N² / (2π · r₀)) · A
```

Зв'язок між власною та взаємною індуктивністю:

```
L_c = N · M                                        [співвідношення індуктивностей]
```

У просторі перетворень Лапласа (`s = jω`) вихідна напруга навантаженої котушки описується рівнянням другого порядку:

```
V_out(s) = [ (s · M · R_d) / (s² · L_c · C_c · R_d + s · (L_c + R_c · C_c · R_d) + (R_c + R_d)) ] · I(s)
```

При високоомному навантаженні `R_d >> R_c` передатна функція спрощується до канонічного вигляду:

```
H_coil(s) = V_out(s) / I(s)
          = (s · M) / [ s² · L_c · C_c + s · (L_c / R_d) + 1 ]
```

Власна частота коливального контуру `ω₀` та коефіцієнт загасання `ζ`:

```
ω₀ = 1 / √(L_c · C_c)                              [резонансна кутова частота]
f₀ = 1 / (2π · √(L_c · C_c))                       [резонансна частота в Герцах]
ζ  = (1 / (2 · R_d)) · √(L_c / C_c)                [коефіцієнт демпфування]
```

Для виключення високочастотного «дзвону» (*ringing*) на фронтах імпульсних струмів з великою крутизною `di/dt` коефіцієнт загасання обирають рівним одиниці (`ζ = 1`, критичне демпфування). Звідси розраховують оптимальний опір демпфування `R_d`:

```
R_d = (1 / 2) · √(L_c / C_c)                       [резистор критичного демпфування]
```

### 4. Режим самоінтегрування (Self-Integrating Rogowski Coil)

Якщо замість високоомного навантаження вторинні виводи котушки навантажити надзвичайно малим резистором `R_d` таким чином, щоб опір навантаження був значно меншим за індуктивний опір власної індуктивності котушки (`R_d << ω · L_c`), котушка переходить у режим пасивного **самоінтегрування**.

У цьому режимі струм у вторинному колі визначається власною індуктивністю `L_c`:

```
i_sec(t) ≈ (1 / L_c) · ∫ e(t) dt
         = (1 / L_c) · ∫ M · (di / dt) dt          [підстановка ЕРС взаємоіндукції]
         = (M / L_c) · i(t)                        [інтегрування похідної струму]
         = (1 / N) · i(t)                          [оскільки L_c = N · M]
```

Вихідна напруга, знята з низькоомного резистора `R_d`:

```
v_out(t) = i_sec(t) · R_d
         = (R_d / N) · i(t)                        [напруга пропорційна струму i(t)]
```

Нижня гранична частота режиму самоінтегрування `f_low` задається часовою сталою власного кола `L_c / R_d`:

```
f_low = R_d / (2π · L_c)                           [нижня межа самоінтегрування]
```

Режим самоінтегрування дозволяє обходитися без активного підсилювача-інтегратора, проте він вимагає котушок із великою індуктивністю `L_c` (тисячі витків) і має нижню частоту зрізу від десятків кілогерц, що робить його непридатним для мережі 50 Гц, але ідеальним для субмікросекундних імпульсів розрядників та лазерів.

### 5. Передатна функція та похибки активного аналогового інтегратора

Для низькочастотних сигналів (50/60 Гц) застосовують активний інтегратор на ОП із резистором паралельного витоку `R_f` у ланцюзі зворотного зв'язку паралельно `C_int`.

Комплексний опір кола зворотного зв'язку:

```
Z_f(s) = R_f / (1 + s · R_f · C_int)               [імпеданс паралельної RC-ланки]
```

Передатна функція активного інтегратора:

```
H_int(s) = −Z_f(s) / R_in
         = −(R_f / R_in) / (1 + s · R_f · C_int)   [передатна функція ФНЧ 1-го порядку]
```

Сумарна передатна функція вимірювального каналу (диференціююча котушка + активний інтегратор):

```
H_sys(s) = H_coil(s) · H_int(s)
         = (s · M) · [ −(R_f / R_in) / (1 + s · R_f · C_int) ]
         = −(s · M · R_f) / [ R_in · (1 + s · R_f · C_int) ]
```

Підставимо змінну Фур'є `s = jω` та позначимо часову сталу `τ = R_f · C_int`, частоту зрізу `ω_c = 1 / τ`:

```
H_sys(jω) = −(M / (R_in · C_int)) · [ (j · (ω / ω_c)) / (1 + j · (ω / ω_c)) ]
```

#### Модуль коефіцієнта передачі та фазовий зсув

Амплітудно-частотна характеристика (АЧХ) системи:

```
|H_sys(jω)| = (M / (R_in · C_int)) · [ (ω / ω_c) / √(1 + (ω / ω_c)²) ]
```

Фазо-частотна характеристика (ФЧХ) системи:

```
∠H_sys(jω) = 180° + 90° − arctan(ω / ω_c)
           = 270° − [ 90° − arctan(ω_c / ω) ]
           = 180° + arctan(ω_c / ω)                [фазова характеристика тракту]
```

На робочих частотах, значно вищих за частоту зрізу (`ω >> ω_c` або `f >> f_c`):

```
(ω / ω_c) / √(1 + (ω / ω_c)²) ≈ 1 − (1 / 2) · (ω_c / ω)²   [розклад у ряд Тейлора]
```

Звідси отримуємо аналітичні вирази для метрологічних похибок:

```
ε_A(ω) = −1 / (2 · ω² · R_f² · C_int²)             [відносна амплітудна похибка]
Δθ(ω)  = arctan(1 / (ω · R_f · C_int))
       ≈ 1 / (ω · R_f · C_int)                     [фазова похибка в радіанах]
```

### 6. Чисельне дискретне інтегрування в Z-області (Tustin Transform)

У цифровому мікроконтролері аналоговий інтегратор замінюється дискретним алгоритмом у Z-просторі. Застосуємо білінійне перетворення Тастіна `s = (2 / T_s) · (1 − z⁻¹) / (1 + z⁻¹)` до ідеального інтегратора `1 / s`:

```
H_int(z) = (T_s / 2) · [ (1 + z⁻¹) / (1 − z⁻¹) ]   [трапецеїдальний інтегратор]
```

У часовій області це відповідає різницевому рівнянню методу трапецій:

```
y[n] = y[n-1] + (T_s / 2) · (x[n] + x[n-1])        [рекурсивна форма трапецій]
```

Для стабілізації цифрового інтегратора полюс на одиничному колі `z = 1` зміщують усередину одиничного кола на коефіцієнт витоку `λ = 1 − (T_s / τ_leak) < 1.0`:

```
H_leaky(z) = (T_s / 2) · [ (1 + z⁻¹) / (1 − λ · z⁻¹) ]
```

Різницеве рівняння стабілізованого цифрового інтегратора:

```
y[n] = λ · y[n-1] + (T_s / 2) · (x[n] + x[n-1])    [робоча формула leaky-інтегратора]
```

Це рівняння вимагає лише одного множення та двох додавань на вибірку, що дозволяє виконувати потокове інтегрування в реальному часі на будь-якому 32-бітному ядрі ARM Cortex-M навіть при частоті дискретизації `f_s = 100 кГц`.
