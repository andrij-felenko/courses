<preknowlist>

- [Середнє й дисперсія](root:math-probability/mean-variance) — вибіркові характеристики та розкид випадкової величини навколо математичного сподівання.
- [Виграш усереднення](root:hw-sensing/averaging-gain) — зменшення випадкового розкиду вибіркового середнього пропорційно кореню з кількості спостережень.
- [Теплові флуктуації](root:hw-sensing/thermal-fluctuations) — фундаментальний шум Найквіста-Джонсона у провідниках та резистивних сенсорних колах.
</preknowlist>

Мікроконтролер зчитує 24-розрядний дельта-сигма АЦП, підключений до мостового тензорезистивного давача сили. Програма виводить у термінал вісім десяткових знаків: «12.345678 кг». Але якщо спостерігати за потоком чисел щосекунди, останні чотири цифри неперервно тремтять у хаотичному танці, а якщо нагріти плату паяльним феном на двадцять градусів — усе значення незворотно зміщується на кілька сотень грамів через термодрейф джерела опорної напруги та резисторів мосту. Дисплей показує вісім цифр, проте п'ять із них не несуть жодної інформації про реальну масу вантажу.

Ця розбіжність між кількістю виведених розрядів та реальною фізичною достовірністю — головна пастка сенсорної інженерії. Будь-який сигнал від первинного перетворювача проходить довгий ланцюг: фізична взаємодія, аналогове підсилення, фільтрація, квантування у двійковий код і цифрова фільтрація. На кожному кроці до сигналу підмішуються тепловий шум, контактні термо-ЕРС, масштабна похибка коефіцієнтів підсилення та обмеження розрядності. Щоб виміряне число перетворилося на інженерний факт, розробник має володіти трьома фундаментальними метрологічними поняттями: наскільки виміряне значення близьке до істини, наскільки тісно результати групуються при повторенні досліду, та яку мінімальну фізичну зміну апаратний тракт здатен виділити з фонового шуму.

### Метрологічна тріада: точність, правильність та прецизійність

У побутовій мові слова «точний», «правильний» та «прецизійний» використовують як взаємозамінні синоніми. У професійній метрології та міжнародному стандарті ISO 5725 (а також Міжнародному словнику метрології VIM, JCGM 200) вони позначають суворо розмежовані фізичні властивості вимірювального процесу.

![Матриця метрологічних якостей: Правильність проти Прецизійності](/root/hw/hw-sensing/measurement-uncertainty/img/accuracy-precision-matrix.svg)
*Чотири стани вимірювальної системи за стандартом ISO 5725. Правильність визначається відсутністю постійного зсуву (зміщення) від істинного значення. Прецизійність визначається щільністю групування повторних вимірів (мінімальним розкидом). Точність є комбінацією обох якостей: високої правильності та високої прецизійності одночасно.*

Розкладімо ці поняття на фізичні складові:

**Прецизійність**, або влучність (англ. *precision*, від латинського *praecisio* — відсікання, чітке обрізання) — ступінь близькості між незалежними результатами вимірювань, отриманими за конкретних регламентованих умов. Прецизійність нічого не знає про фізичну істину: вона характеризує виключно **розкид** (дисперсію) навколо власного вибіркового центру. Якщо сенсор температури при стабільних 25.00 °C десять разів поспіль видає покази від 29.99 °C до 30.01 °C, його прецизійність бездоганна (розкид у межах сотих часток градуса), хоча всі покази зсунуті від реальності на п'ять градусів.

**Правильність** (англ. *trueness*, від давньоанглійського *treowe* — вірний, істинний) — ступінь близькості середнього значення, отриманого з нескінченно великої серії повторних вимірювань, до істинного або опорного значення вимірюваної величини. Правильність характеризує **систематичне зміщення** (*bias*, або систематичну похибку). Якщо розкид показів широкий (від 20 °C до 30 °C), але їхнє математичне сподівання рівно 25.00 °C — система має високу правильність за низької прецизійності.

**Точність** (англ. *accuracy*, від латинського *accuratus* — виконаний дбайливо, від *cura* — турбота) — інтегральна характеристика, що відображає ступінь близькості **одиничного** виміряного результату до істинного значення. За стандартом ISO 5725 точність є «парасольковим» терміном, який об'єднує і правильність, і прецизійність. Висока точність вимагає одночасно малого систематичного зміщення та малого випадкового розкиду.

```
Загальна похибка одиничного виміру:
  E_total = x_meas − x_true
          = (x_meas − x̄) + (x̄ − x_true)
          = E_random + E_systematic
          = [випадкове відхилення від середнього] + [систематичне зміщення bias]
```

Саму прецизійність поділяють на два фундаментальні експлуатаційні рівні залежно від стабільності умов експерименту:

1. **Повторюваність** (англ. *repeatability*, від латинського *repetere* — відновлювати, повторювати) — прецизійність в умовах збіжності: той самий вимірювальний прилад, той самий оператор, та сама калібрувальна оснастка, незмінне місце установки та виконання серії вимірів за мінімально короткий проміжок часу. Повторюваність відображає теоретичну межу стабільності сенсора, зумовлену внутрішніми шумами схеми.
2. **Відтворюваність** (англ. *reproducibility*, від латинського *reproducere* — створювати знову) — прецизійність за змінених умов: різні лабораторії, різні екземпляри приладів однієї моделі, різні оператори, інша температура навколишнього середовища або вимірювання з інтервалом у кілька місяців. Відтворюваність завжди помітно гірша (розкид ширший) за повторюваність, оскільки вбирає в себе технологічний розкид компонентів, температурні коефіцієнти та старіння матеріалів.

> 🔧 **Навіщо це.** Якщо ви розробляєте промисловий прилад і калібруєте його за опорним еталоном на заводському стенді, ви спираєтеся на **повторюваність**: вона дозволяє програмно ввести поправку зміщення нуля (калібрувальний коефіцієнт) і скомпенсувати систематичну похибку. Але коли прилад відправляється клієнту на інший континент і працює в неопалюваному цеху, визначальною стає **відтворюваність**: саме вона визначає, чи не попливуть покази сенсора за межі гарантованого паспортом класу точності при зміні температури живлення та монтажу.

### Роздільна здатність, шум квантування та межа виявлення (LOD)

Друге джерело помилок інженерів — плутанина між роздільною здатністю апаратного тракту та реальною фізичною чутливістю до зміни вимірюваної величини.

**Роздільна здатність** (англ. *resolution*, від латинського *resolvere* — розкладати на елементи, розв'язувати) — найменша зміна вхідного фізичного сигналу, яка викликає фіксовану зміну вихідного сигналу або перемикання молодшого розряду (LSB, *Least Significant Bit*) цифрового перетворювача.

Для N-розрядного аналого-цифрового перетворювача з опорною напругою `V_ref` абсолютний крок квантування за напругою `Δ` (вага одиниці молодшого розряду) дорівнює:

```
Крок квантування шкали АЦП:
  Δ = V_ref / 2^N
```

Для 12-розрядного АЦП мікроконтролера при `V_ref = 3.3 В` крок становить `3.3 / 4096 ≈ 0.8057 мВ`. Для 24-розрядного перетворювача при `V_ref = 2.5 В` крок дорівнює `2.5 / 16777216 ≈ 0.149 мкВ`. Здавалося б, 24-розрядний чіп автоматично надає колосальну здатність розрізняти нановольти. Проте це математична ілюзія.

![Роздільна здатність, шум квантування та межі LOD і LOQ](/root/hw/hw-sensing/measurement-uncertainty/img/resolution-vs-lod-noise.svg)
*Зліва: квантування неперервної напруги кроком Δ утворює рівномірно розподілену похибку з дисперсією Δ²/12. Справа: коли аналоговий шум тракту перевищує крок квантування, роздільність стає обмеженою шумом. Сигнал виділяється з шуму лише при перевищенні межі виявлення LOD (3σ), а кількісний вимір можливий лише вище LOQ (10σ).*

#### Шум квантування як рівномірний процес

Процес перетворення неперервної величини у східчастий код неминуче вносить похибку заокруглення `e_q = V_in − V_quant`. Якщо вхідний сигнал змінюється несинхронно з тактовою частотою АЦП і перетинає кілька рівнів квантування, похибка `e_q` поводиться як випадкова величина, рівномірно розподілена на симетричному інтервалі `[−Δ/2, +Δ/2]`.

Густина ймовірності рівномірного розподілу на цьому відрізку дорівнює `p(e) = 1/Δ`. Обчислімо математичне сподівання квадрата похибки (дисперсію шуму квантування `σ_q²`):

```
Обчислення дисперсії шуму квантування:
  σ_q² = ∫ e² · p(e) de                    [межі інтегрування від −Δ/2 до +Δ/2]
       = (1/Δ) · ∫ e² de                   [винесення сталої густини 1/Δ]
       = (1/Δ) · [e³ / 3]                  [первісна від e² є e³/3, підстановка меж]
       = (1/Δ) · ( (Δ/2)³/3 − (−Δ/2)³/3 )  [розкриття підстановки меж]
       = (1/Δ) · ( Δ³ / 24 + Δ³ / 24 )     [зведення подібних доданків]
       = (1/Δ) · ( Δ³ / 12 )               [спрощення дробу]
       = Δ² / 12                           [остаточна дисперсія квантування]
```

Звідси середньоквадратичне значення (RMS) шуму квантування або його стандартна невизначеність:

```
Стандартна невизначеність квантування:
  u_q = √(Δ² / 12) = Δ / √12 ≈ 0.2887 · Δ
```

Цей шум існує в абсолютно будь-якому ідеальному перетворювачі просто через кінцеву кількість розрядів. Проте в реальних сенсорних колах справжній обмежувач інший — власний шум аналогового тракту.

#### Межа виявлення (LOD) та межа кількісного визначення (LOQ)

Якщо до входу 24-розрядного АЦП підключено підсилювач із середньоквадратичним рівнем власного шуму `σ_noise = 5 мкВ`, а крок квантування становить `Δ = 0.15 мкВ`, молодші 5–6 бітів АЦП вимірюють не корисний сигнал, а випадкові коливання самого підсилювача. У такій системі роздільна здатність є **обмеженою шумом** (*noise-limited resolution*).

Щоб оцінити справжню здатність вимірювального тракту виявляти малі сигнали, аналітична хімія та прецизійна сенсорика ввели дві стандартизовані межі (рекомендації IUPAC / ISO 11843):

1. **Межа виявлення** (англ. *Limit of Detection*, LOD, від латинського *detectio* — розкриття, виявлення): мінімальна концентрація або рівень вхідної величини, який можна статистично надійно відрізнити від нульового фонового сигналу (холостої проби / фонового шуму). Статистичний поріг встановлюють на рівні трьох стандартних відхилень фону:

```
Межа виявлення (рівень довіри 99.73%):
  LOD = x̄_blank + 3 · σ_blank
```

Якщо прилад показує сигнал на рівні `2 · σ_blank`, з імовірністю майже 5% це звичайний випадковий сплеск шуму за відсутності вимірюваного явища. Лише перевищення рівня `3 · σ_blank` гарантує, що вхідний сигнал фізично присутній.

2. **Межа кількісного визначення** (англ. *Limit of Quantification*, LOQ, від латинського *quantificare* — вимірювати кількість): мінімальний рівень сигналу, за якого його величину можна не просто зафіксувати, а виміряти з прийнятною для практики точністю. Стандартний критерій вимагає, щоб відносне стандартне відхилення (RSD / коефіцієнт варіації) не перевищувало 10%:

```
Межа кількісного визначення:
  LOQ = x̄_blank + 10 · σ_blank
```

Нижче рівня LOQ прилад бачить присутність явища, але числовому значенню на табло довіряти не можна: відносна похибка одиничного виміру стає надто великою.

#### Ефективне число розрядів (ENOB)

Щоб описати реальну якість АЦП з урахуванням усіх неідеальностей — теплового шуму, нелінійності та джиттеру дискретизації — використовують показник **ENOB** (англ. *Effective Number of Bits*). Якщо для 16-розрядного перетворювача паспорт декларує відношення сигналу до шуму та спотворень SINAD = 86 дБ, його реальна ефективна розрядність розраховується за формулою зв'язку з теоретичним шумом квантування:

```
Ефективне число бітів:
  SINAD = 6.02 · ENOB + 1.76 дБ
  ENOB  = (SINAD − 1.76) / 6.02
        = (86 − 1.76) / 6.02 ≈ 14.0 розрядів
```

Два молодші розряди цього 16-бітного чіпа повністю втоплені у шумах і спотвореннях.

### Класифікація похибок: систематичні проти випадкових

Будь-яка неідеальність вимірювального каналу за своєю природою належить до одного з двох фундаментальних класів, і боротьба з ними вимагає принципово протилежних інженерних методів.

![Класифікація спотворень вимірювального тракту](/root/hw/hw-sensing/measurement-uncertainty/img/systematic-vs-random.svg)
*Систематичні похибки (зліва) мають детермінований характер і усуваються аналітичним калібруванням та апаратним підстроюванням. Випадкові похибки (справа) породжені тепловими та квантовими флуктуаціями, їхня дисперсія зменшується усередненням вибірки у √N разів.*

#### Систематичні похибки (Bias / Детерміновані спотворення)

Систематична похибка (від грецького *systēma* — складене з частин ціле) — це компонента похибки, яка залишається постійною або закономірно змінюється при повторних вимірюваннях тієї самої величини за незмінних умов.

Типові джерела у схемотехніці сенсорів:

- **Зсув нуля** (англ. *offset* / *bias*): постійна напруга на виході при нульовому вході. Зумовлена вхідною напругою зсуву операційних підсилювачів (`V_os`), струмами витоку входів та паразитними термоелектричними ЕРС Зеєбека (спай мідної доріжки плати зі свинцево-безсвинцевим припоєм генерує від 3 до 40 мкВ на кожен градус перепаду температур вздовж плати).
- **Масштабна похибка** (англ. *gain error* / *scale factor error*): відхилення коефіцієнта пропорційності тракту від номіналу. Виникає через технологічний розкид резисторів зворотного зв'язку підсилювача (наприклад, резистори з допуском ±0.1% створюють масштабу похибку до ±0.2%) та похибку вихідної напруги джерела опорної напруги (ІОН).
- **Нелінійність** (англ. *non-linearity*, INL/DNL): відхилення реальної передавальної функції підсилювача або АЦП від ідеальної прямої лінії.
- **Температурний та часовий дрейф** (англ. *drift*): повільна детермінована зміна зміщення нуля та масштабного коефіцієнта внаслідок старіння кремнію, релаксації механічних напружень у корпусі мікросхеми та зміни навколишньої температури (вимірюється в `ppm/°C` та `ppm/рік`).

> ⚠️ **Головний закон систематичних похибок:** Усереднення вибірки **безсиле** проти систематичної похибки. Якщо АЦП через зсув нуля завищує кожну вибірку на +10 мВ, середнє з мільйона відліків залишиться завищеним рівно на +10 мВ. Систематичні похибки усувають виключно **[калібруванням](root:hw-sensing/calibration)** — звіркою з еталоном і записом поправочних коефіцієнтів у незалежну пам'ять приладу.

#### Випадкові похибки (Random Noise / Стохастичні процеси)

Випадкова похибка (від латинського *casus* — випадок, або *fluctuare* — хвилюватися) — складова похибки, яка непередбачувано змінюється від виміру до виміру під дією мікроскопічних теплових і квантових явищ.

Фізичні корені випадкового шуму:

1. **Тепловий шум Найквіста-Джонсона** (англ. *Johnson-Nyquist noise*): породжується хаотичним тепловим рухом носіїв заряду (електронів) у будь-якому резистивному провіднику за температури вище абсолютного нуля. Спектральна густина потужності шуму рівномірна за частотою (білий шум), а середньоквадратична напруга шуму в смузі частот `Δf` дорівнює:

```
Тепловий шум опору R у смузі частот Δf:
  V_n = √(4 · k_B · T · R · Δf)
  де k_B ≈ 1.380649·10⁻²³ Дж/К (стала Больцмана),
     T — абсолютна температура в Кельвінах,
     R — активний опір кола в Омах,
     Δf — еквівалентна шумова смуга пропускання тракту в Герцах.
```

Для резистора номіналом 10 кОм при кімнатній температурі (300 К) в смузі 10 кГц середньоквадратичний тепловий шум становить:

```
V_n = √(4 · 1.3806·10⁻²³ · 300 · 10000 · 10000)
    = √(1.6567·10⁻¹²) ≈ 1.287 мкВ (RMS)
```

2. **Дробовий шум** (англ. *shot noise*, шум Шотткі): виникає при проходженні електричного струму через потенційний бар'єр (наприклад, p-n перехід напівпровідникового діода чи транзистора) через дискретну природу носіїв електричного заряду (електронів з елементарним зарядом `q ≈ 1.602·10⁻¹⁹ Кл`). Середньоквадратичний струм шуму дорівнює `I_n = √(2 · q · I_dc · Δf)`.
3. **Флікер-шум** (англ. *flicker noise* / *1/f noise*): низькочастотний надлишковий шум, зумовлений хаотичним захопленням та вивільненням носіїв заряду дефектами кристалічної решітки на межі напівпровідник-діелектрик. Його потужність обернено пропорційна частоті `f`, тому на низьких частотах (від десятих часток Герца до десятків Герц) він домінує над білим шумом.

#### Магічна сила усереднення та закон √N

Випадковий шум має нульове математичне сподівання: миттєві значення відхиляються в додатний та від'ємний бік з однаковою ймовірністю. Тому накопичення та усереднення `N` незалежних спостережень `x_1, x_2, ..., x_N` частково компенсує флуктуації.

Нехай окреме спостереження має дисперсію `σ²`. Тоді для вибіркового середнього `x̄ = (1/N) ∑ x_i`:

```
Дисперсія вибіркового середнього:
  Var(x̄) = Var( (1/N) · ∑ x_i )
          = (1/N²) · ∑ Var(x_i)           [властивість дисперсії незалежних величин]
          = (1/N²) · (N · σ²)             [оскільки кожне спостереження має дисперсію σ²]
          = σ² / N
```

Беручи квадратний корінь, отримуємо стандартне відхилення середнього:

```
Стандартна похибка середнього (SEM):
  σ_mean = σ / √N
```

Звідси фундаментальний висновок: усереднення 16 вибірок зменшує випадковий шум у `√16 = 4` рази; усереднення 100 вибірок — у `√100 = 10` разів. Проте щоб знизити шум ще вдесятеро (до `100×`), знадобиться вже `10000` вибірок. Закон квадратного кореня вимагає квадратичного збільшення часу вимірювання за лінійне зниження шуму.

### Керівництво ISO/IEC Guide 98-3 (GUM): методологія оцінювання невизначеності

До початку 1990-х років у світовій науці та інженерії панував підхід «аналізу похибок». Проте класичне визначення похибки `E = x_meas − x_true` містить непереборне протиріччя: **істинне значення `x_true` принципово невідоме** (якби воно було відоме, відпадала б сама потреба у вимірюванні). А якщо істина невідома, то й точне значення похибки визначити неможливо.

У 1993 році консорціум провідних метрологічних організацій (BIPM, IEC, IFCC, ISO, IUPAC, IUPAP, OIML) здійснив революцію, випустивши **GUM** (англ. *Guide to the Expression of Uncertainty in Measurement*, стандартизовано як ISO/IEC Guide 98-3).

![Архітектура оцінювання невизначеності за GUM](/root/hw/hw-sensing/measurement-uncertainty/img/gum-uncertainty-framework.svg)
*Загальна схема метрологічного звіту за GUM. Статистичні оцінки (Тип A) та апріорні паспортні допуски (Тип B) зводяться через коефіцієнти чутливості до єдиної сумарної невизначеності u_c, яка масштабується коефіцієнтом охоплення k у розширену невизначеність U.*

Філософія GUM перенесла акцент із недосяжної «істини» на **стан знань експериментатора**:

**Невизначеність вимірювання** (англ. *uncertainty of measurement*, від старофранцузького *certain* — надійний, вірний, із префіксом заперечення *un-*) — невід'ємний параметр, що характеризує розсіювання значень, які обґрунтовано можуть бути приписані вимірюваній величині на основі всієї наявної інформації.

GUM класифікує всі внески в невизначеність не за їхньою фізичною природою (систематична/випадкова), а **за методом чисельної оцінки**: Тип A та Тип B. Обидва типи виражаються в однакових одиницях — у вигляді **стандартної невизначеності** `u` (еквівалент одного стандартного відхилення `1σ`), що дозволяє коректно комбінувати їх у загальний бюджет.

#### Оцінювання невизначеності за Типом A (Статистичне)

Оцінювання за Типом A застосовують тоді, коли інженер може провести серію з `N` повторних незалежних вимірювань за однакових умов.

Послідовність розрахунку:

1. Обчислюють вибіркове середнє арифметичне `x̄`:

```
Вибіркове середнє:
  x̄ = (1/N) · ∑[k=1..N] x_k
```

2. Обчислюють вибіркове стандартне відхилення `s(x)` з урахуванням **поправки Бесселя** (ділення на `N − 1` ступенів вільності для усунення заниження дисперсії через оцінювання середнього за тією ж вибіркою):

```
Вибіркова дисперсія та стандартне відхилення:
  s²(x) = (1 / (N − 1)) · ∑[k=1..N] (x_k − x̄)²
  s(x)  = √s²(x)
```

3. Стандартна невизначеність типу A для середнього значення `u_A(x̄)` дорівнює стандартній похибці середнього:

```
Стандартна невизначеність типу A:
  u_A(x̄) = s(x) / √N = √( ∑ (x_k − x̄)² / (N · (N − 1)) )
```

Ступені вільності для цієї оцінки становлять `ν_A = N − 1`.

#### Оцінювання невизначеності за Типом B (Апріорне)

Оцінювання за Типом B використовують для тих джерел невизначеності, де повторні виміри неможливі або не виявляють джерела: дані паспортів компонентів (datasheet), сертифікати повірки еталонів, розрядність АЦП, граничні температурні коливання в корпусі приладу.

Інженер знає максимальні гарантовані виробником межі відхилення `±a` і обирає закон розподілу ймовірностей:

1. **Прямокутний (рівномірний) розподіл** — коли відомо лише те, що величина з імовірністю 100% лежить у межах від `-a` до `+a`, і жодне значення всередині інтервалу не має переваги перед іншим (типово для кроку дискретизації АЦП, допуску резисторів загального призначення, цифрового округлення):

```
Стандартна невизначеність прямокутного розподілу:
  u_B = a / √3 ≈ 0.5774 · a
```

2. **Трикутний розподіл (розподіл Сімпсона)** — коли величина обмежена межами `±a`, але значення поблизу центру інтервалу значно ймовірніші за крайові (типово для суми двох незалежних рівномірних процесів, або коли температура в термостаті підтримується біля центру діапазону):

```
Стандартна невизначеність трикутного розподілу:
  u_B = a / √6 ≈ 0.4082 · a
```

3. **Нормальний розподіл** — коли в сертифікаті калібрування чи паспорті приладу вказано розширену похибку `U_spec` для конкретного довірчого рівня (наприклад, «похибка ±0.1% для рівня довіри 95%»):

```
Стандартна невизначеність нормального розподілу:
  u_B = U_spec / k
  де k = 2.00 для рівня довіри 95.45%,
     k = 2.58 для рівня довіри 99.00%,
     k = 3.00 для рівня довіри 99.73%.
```

4. **U-подібний розподіл (арксинусний)** — коли величина здійснює гармонічні коливання з амплітудою `a` (наприклад, періодичні коливання температури день/ніч або синусоїдальна наводка мережі 50 Гц):

```
Стандартна невизначеність U-подібного розподілу:
  u_B = a / √2 ≈ 0.7071 · a
```

#### Закон поширення невизначеності та сумарна невизначеність `u_c`

У реальних приладах кінцева вимірювана величина `Y` обчислюється через кілька вхідних величин `X_1, X_2, ..., X_m` за функціональною залежністю:

```
Модель вимірювання:
  Y = f(X₁, X₂, ..., X_m)
```

Малі відхилення входів `Δx_i` транслюються у відхилення виходу через розклад у ряд Тейлора першого порядку. Частинні похідні моделі називають **коефіцієнтами чутливості** `c_i`:

```
Коефіцієнт чутливості за входом X_i:
  c_i = ∂f / ∂X_i |_(X = x̄)
```

Якщо всі вхідні величини є взаємно незалежними (некорельованими), **сумарна стандартна невизначеність** `u_c(y)` (англ. *combined standard uncertainty*) обчислюється як корінь із суми квадратів зважених невизначеностей:

```
Закон поширення невизначеності (для незалежних входів):
  u_c²(y) = ∑[i=1..m] ( c_i · u(x_i) )²
  u_c(y)  = √( (c₁ · u₁)² + (c₂ · u₂)² + ... + (c_m · u_m)² )
```

Якщо величини корелюють (наприклад, два резистори дільника виготовлені на одній підкладці й мають однаковий температурний дрейф), додається коваріаційний член:

```
Повний закон поширення з урахуванням кореляції:
  u_c²(y) = ∑[i=1..m] c_i² · u²(x_i) + 2 · ∑[i=1..m-1] ∑[j=i+1..m] c_i · c_j · u(x_i, x_j)
  де u(x_i, x_j) = r(x_i, x_j) · u(x_i) · u(x_j) — коваріація,
     r(x_i, x_j) — коефіцієнт лінійної кореляції Пірсона (−1 ≤ r ≤ +1).
```

#### Розширена невизначеність `U` та ефективні ступені вільності

Сумарна невизначеність `u_c(y)` відповідає смузі в одне стандартне відхилення (`1σ`), яка для нормального розподілу охоплює лише близько 68.27% можливих значень. Для промислових, медичних та комерційних застосувань такий рівень ризику неприйнятний: замовники та регулятори вимагають довірчої ймовірності не менше 95%.

Для переходу до ширшого довірчого інтервалу `u_c(y)` множать на **коефіцієнт охоплення** `k` (англ. *coverage factor*), отримуючи **розширену невизначеність** `U` (англ. *expanded uncertainty*):

```
Розширена невизначеність:
  U = k · u_c(y)
```

За Центральною граничною теоремою теорії ймовірностей, якщо сумарна невизначеність сформована сумою багатьох незалежних джерел різної природи, результуючий розподіл наближається до нормального Гаусового закону. Тоді:

- `k = 2.00` забезпечує рівень довіри `P ≈ 95.45%`;
- `k = 3.00` забезпечує рівень довіри `P ≈ 99.73%`.

Якщо ж домінуючий внесок у невизначеність дає оцінка типу A, отримана з малої вибірки (`N < 10`), результуючий розподіл підпорядковується не нормальному закону, а t-розподілу Стьюдента. У такому разі розраховують **ефективне число ступенів вільності** `ν_eff` за **формулою Велча-Саттерзвейта** (англ. *Welch-Satterthwaite equation*):

```
Формула Велча-Саттерзвейта:
  ν_eff = u_c⁴(y) / ( ∑[i=1..m] ( (c_i · u(x_i))⁴ / ν_i ) )
```

Для джерел типу B ступені вільності зазвичай приймають рівними нескінченності (`ν_B → ∞`), тому їхній знаменник у сумі перетворюється на нуль. За отриманим `ν_eff` із таблиць Стьюдента вибирають точний коефіцієнт `t_p(ν_eff)` для `P = 95%`.

### Наскрізний інженерний розрахунок: вимірювальний канал тиску

Розглянемо повний розрахунок бюджету невизначеності на реальному промисловому прикладі.

**Постановка задачі:**
Аналоговий давач тиску живиться від напруги 10 В і видає вихідну напругу `V_sens`, пропорційну тиску: при тиску 10.00 бар напруга становить 5.000 В (передавальний коефіцієнт `K_sens = 2.000 бар/В`). Щоб подати сигнал на мікроконтролер із входом 0..2.5 В, використовують прецизійний резистивний дільник напруги з двох резисторів `R_1 = 10.00 кОм` та `R_2 = 10.00 кОм` (коефіцієнт поділу `K_div = R_2 / (R_1 + R_2) = 0.5000`), сигнал з якого оцифровується 16-розрядним АЦП з опорною напругою `V_ref = 2.500 В`.

```
Математична модель тиску:
  P = K_sens · (V_adc / K_div) = 2.000 · (V_adc / 0.5000) = 4.000 · V_adc  [бар]
```

Коефіцієнт чутливості за напругою АЦП: `c_adc = ∂P / ∂V_adc = 4.000 бар/В`.

#### Крок 1. Оцінка за Типом A (випадковий шум каналу)

Мікроконтролер виконав серію з `N = 16` послідовних зчитувань напруги АЦП при стабільному робочому тиску:

```
Вибірка V_adc (у Вольтах):
  1.2541, 1.2538, 1.2545, 1.2540, 1.2548, 1.2537, 1.2542, 1.2544,
  1.2539, 1.2546, 1.2540, 1.2543, 1.2536, 1.2547, 1.2541, 1.2543
```

Статистична обробка:

```
Середнє значення напруги:
  V̄_adc = 1.25419 В
  Оцінка виміряного тиску: P̄ = 4.000 · 1.25419 = 5.0168 бар

Вибіркове стандартне відхилення (s):
  s(V_adc) = 0.000361 В (0.361 мВ)

Стандартна невизначеність типу A:
  u_A(V_adc) = s / √16 = 0.361 / 4 = 0.0903 мВ (0.0000903 В)
  Внесок у тиск: u_A(P) = c_adc · u_A(V_adc) = 4.000 · 0.0000903 = 0.000361 бар
  Ступені вільності: ν_A = 16 − 1 = 15.
```

#### Крок 2. Оцінка за Типом B (апаратурні внески)

Збираємо всі джерела апаратурної невизначеності:

1. **Квантування 16-бітного АЦП:**
   - Крок кванта: `Δ = V_ref / 65536 = 2.500 / 65536 ≈ 38.15 мкВ`.
   - Рівномірний розподіл: `u_B1(V_adc) = Δ / √12 = 38.15 / 3.4641 ≈ 11.01 мкВ`.
   - Внесок у тиск: `u_B1(P) = 4.000 · 0.00001101 = 0.000044 бар`.
2. **Паспортна похибка калібрування давача тиску:**
   - Паспорт заявляє максимальну похибку лінійності та калібрування `±0.15%` від повної шкали 10 бар: `a_cal = 10.0 · 0.0015 = 0.015 бар`.
   - Рівномірний розподіл: `u_B2(P) = 0.015 / √3 ≈ 0.008660 бар`.
3. **Похибка резистивного дільника `K_div`:**
   - Резистори мають допуск `±0.05%`. Відносна невизначеність коефіцієнта поділу `a_div = 0.07%` (0.0007).
   - На рівні виміряного тиску 5.0168 бар максимальне відхилення: `a = 5.0168 · 0.0007 ≈ 0.00351 бар`.
   - Рівномірний розподіл: `u_B3(P) = 0.00351 / √3 ≈ 0.002027 бар`.
4. **Температурний дрейф опорної напруги `V_ref`:**
   - Температурний коефіцієнт ІОН становить `10 ppm/°C`. За максимального перепаду температури `ΔT = ±15 °C` відхилення напруги досягає `150 ppm` (0.015%).
   - Максимальне відхилення тиску: `a_temp = 5.0168 · 0.00015 ≈ 0.000753 бар`.
   - Трикутний розподіл (оскільки крайні температури менш імовірні): `u_B4(P) = 0.000753 / √6 ≈ 0.000307 бар`.

### Програмна реалізація метрологічного модуля на C та C++

У вбудованих системах розрахунок характеристик вибірки виконують у потоковому режимі. Наївне обчислення дисперсії за формулою `∑ x² − (∑ x)² / N` призводить до катастрофічної втрати точності в числах з рухомою комою `float` (через віднімання двох дуже великих близьких чисел).

Нижче наведено чисельно стійкий алгоритм Велфорда (B. P. Welford, 1962), що обчислює середнє та дисперсію за один прохід:

:::tabs
```c
#include <stdio.h>
#include <math.h>
#include <stdint.h>
#include <stdbool.h>

/* Структура однопрохідного накопичувача Велфорда */
typedef struct {
    uint32_t count;
    double mean;
    double m2; /* Накопичена сума квадратів різниць (x_i - mean) */
} welford_stat_t;

void welford_reset(welford_stat_t *s) {
    s->count = 0;
    s->mean = 0.0;
    s->m2 = 0.0;
}

/* Додавання вибірки: O(1) за часом та пам'яттю */
void welford_push(welford_stat_t *s, double x) {
    s->count++;
    double delta = x - s->mean;
    s->mean += delta / (double)s->count;
    double delta2 = x - s->mean;
    s->m2 += delta * delta2;
}

/* Розрахунок стандартної невизначеності типу A: s / sqrt(N) */
bool welford_result(const welford_stat_t *s, double *mean_out, double *u_a_out) {
    if (s->count < 2) return false;
    *mean_out = s->mean;
    double sample_variance = s->m2 / (double)(s->count - 1);
    *u_a_out = sqrt(sample_variance / (double)s->count);
    return true;
}

/* Перетворення допуску типу B: прямокутний розподіл a / sqrt(3) */
double unc_type_b_rect(double half_width) {
    return half_width / sqrt(3.0);
}

/* Обчислення розширеної невизначеності каналу */
double calc_expanded_uncertainty(double u_a, double u_b_rect, double k_cov) {
    double u_combined = sqrt(u_a * u_a + u_b_rect * u_b_rect);
    return k_cov * u_combined;
}

int main(void) {
    welford_stat_t stat;
    welford_reset(&stat);

    const double adc_samples[8] = {1.254, 1.253, 1.255, 1.254, 1.254, 1.253, 1.255, 1.254};
    for (size_t i = 0; i < 8; ++i) {
        welford_push(&stat, adc_samples[i]);
    }

    double mean_v = 0.0, u_a_v = 0.0;
    if (welford_result(&stat, &mean_v, &u_a_v)) {
        double u_b_v = unc_type_b_rect(0.001); /* Паспортний допуск +/- 1 мВ */
        double u_exp = calc_expanded_uncertainty(u_a_v, u_b_v, 2.0);

        printf("Напруга: %.4f V, Розширена невизначеність U(k=2): +/- %.4f V\n", mean_v, u_exp);
    }
    return 0;
}
```
```cpp
#include <iostream>
#include <span>
#include <vector>
#include <cmath>
#include <numbers>
#include <optional>
#include <iomanip>

namespace metrology {

// Чисельно стабільний акумулятор для однопрохідної статистики
class RunningStats {
public:
    void push(double x) noexcept {
        ++count_;
        const double delta = x - mean_;
        mean_ += delta / static_cast<double>(count_);
        const double delta2 = x - mean_;
        m2_ += delta * delta2;
    }

    void push(std::span<const double> data) noexcept {
        for (double v : data) {
            push(v);
        }
    }

    [[nodiscard]] std::size_t count() const noexcept { return count_; }
    [[nodiscard]] double mean() const noexcept { return mean_; }

    [[nodiscard]] std::optional<double> standard_uncertainty_a() const noexcept {
        if (count_ < 2) return std::nullopt;
        const double variance = m2_ / static_cast<double>(count_ - 1);
        return std::sqrt(variance / static_cast<double>(count_));
    }

private:
    std::size_t count_{0};
    double mean_{0.0};
    double m2_{0.0};
};

// Функція оцінювання типу B для рівномірного розподілу
[[nodiscard]] constexpr double type_b_rectangular(double half_width) noexcept {
    return half_width / std::numbers::sqrt3;
}

// Комбінування стандартних невизначеностей у розширену U
[[nodiscard]] inline double combine_expanded(double u_a, double u_b, double k = 2.0) noexcept {
    const double u_c = std::hypot(u_a, u_b);
    return k * u_c;
}

} // namespace metrology

int main() {
    using namespace metrology;

    RunningStats stats;
    const std::vector<double> samples = {1.254, 1.253, 1.255, 1.254, 1.254, 1.253, 1.255, 1.254};
    stats.push(samples);

    if (auto u_a = stats.standard_uncertainty_a()) {
        const double u_b = type_b_rectangular(0.001); // Паспортний допуск +/- 1 мВ
        const double u_exp = combine_expanded(*u_a, u_b, 2.0);

        std::cout << std::fixed << std::setprecision(4);
        std::cout << "Напруга: " << stats.mean() << " V, "
                  << "Розширена невизначеність U(k=2): +/- " << u_exp << " V\n";
    }

    return 0;
}
```

### Правила оформлення результатів та метрологічна культура

Будь-який технічний звіт, екран приладу чи протокол випробувань повинен подавати виміряну величину за суворими правилами метрологічного запису:

1. **Невизначеність визначає кількість значущих цифр результату.** Безглуздо писати `R = 100.12345 Ом ± 0.5 Ом`. Правильний запис: `R = (100.1 ± 0.5) Ом`.
2. **Невизначеність подають максимум з двома значущими цифрами.** Наприклад, `U = 0.024 В` або `U = 1.3 мВ`. Запис `± 0.024187 В` є метрологічною безграмотністю, оскільки сама невизначеність є статистичною оцінкою з обмеженою точністю.
3. **Обов'язкове зазначення коефіцієнта охоплення `k` та рівня довіри `P`.** Формат: `Y = ȳ ± U (k = 2, P = 95%)`.
4. **Одиниці вимірювання виносять за дужки.** Запис `12.34 В ± 0.05 В` є надлишковим; стандартна форма — `(12.34 ± 0.05) В`.

Дотримання цих правил гарантує, що дані вашого приладу будуть однозначно й безпомилково інтерпретовані автоматикою керування, калібрувальною лабораторією та кінцевим користувачем.
