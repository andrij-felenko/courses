# SAR АЦП зсередини

<preknowlist>
- [Типи АЦП](root:hw-analog/adc-types) — архітектурне порівняння перетворювачів: послідовне наближення (SAR), паралельне перетворення (Flash) та дельта-сигма (Sigma-Delta).
- [Опорна напруга](root:hw-sensing/voltage-reference) — джерело еталонного потенціалу Vref, що задає абсолютний масштаб шкали та ціну молодшого значущого розряду (LSB).
- [Похибки АЦП](root:hw-sensing/adc-errors) — зсув нуля, похибка масштабу, диференціальна (DNL) та інтегральна (INL) нелінійність вимірювального тракту.
- [Компаратор напруги](root:hw-analog/comparator) — динамічне порівняння аналогових потенціалів та формування цифрового біта за пороговим рівнем.
- [Часова стала RC](root:hw-analog/rc-time-constant) — експоненційне встановлення напруги на ємності через сумарний опір кола заряду.
</preknowlist>

Коли мікроконтролер перемикає свій аналоговий вивід у режим оцифрування, на контакті не з'являється ідеальний статичний вольтметр із нескінченним вхідним опором. Замість цього внутрішній польовий ключ із власним опором відкритого каналу `Rsw ≈ 1…3 кОм` різко підключає до джерела сигналу внутрішній конденсатор вибірки `Csample ≈ 5…20 пФ`. Якщо в попередній мікросекунді цей конденсатор був розряджений до нуля або тримав залишковий заряд від іншого каналу вбудованого мультиплексора, у момент замикання виникає різкий комутаційний сплеск струму. Потенціал на ніжці мікроконтролера миттєво просідає. Якщо внутрішній опір джерела сигналу становить, скажімо, `Rsrc = 50 кОм`, часова стала заряду вхідного кола сягає `tau = (Rsrc + Rsw) · Csample = (50 000 + 2000) · 15·10⁻¹² ≈ 780 нс`. Якщо таймінг вибірки в регістрах АЦП необачно сконфігуровано на стандартні `150 нс` (що становить менш як `0.2 tau`, тоді як для 12-бітної точності потрібно щонайменше `9 tau`), конденсатор не встигне набрати й чверті реальної напруги. На виході замість очікуваних 3.00 В з'явиться фатально спотворене число, еквівалентне 0.52 В.

Розуміння фізики комутованих конденсаторів та внутрішнього алгоритму зважування — це єдиний спосіб проектувати вимірювальні тракти без прихованих похибок. Архітектура послідовного наближення (англ. *Successive Approximation Register*, SAR; від лат. *approximare* — наближатися) стала домінуючою у вбудованій мікроелектроніці (STM32, ESP32, RP2040, nRF52, а також прецизійні мікросхеми Texas Instruments, Analog Devices). Вона забезпечує оптимальний компроміс між енергоспоживанням (одиниці мікроват або міліват), швидкістю (від 100 kSPS до 10 MSPS) та роздільною здатністю (від 10 до 18 біт), здійснюючи перетворення за фіксовану кількість тактів без затримки конвеєра.

### Архітектура SAR АЦП: чотири ключові вузли

Класичний сучасний SAR АЦП виконується на основі технології комутованих конденсаторів (англ. *charge-redistribution ADC*). На відміну від застарілих схем на резистивних матрицях R-2R, ємнісна топологія не споживає статичного струму від джерела опорної напруги та поєднує функції пристрою вибірки-зберігання і власне цифро-аналогового перетворювача в одній фізичній структурі.

![Архітектура SAR АЦП на базі матриці CDAC](/root/hw/hw-sensing/sar-adc-internals/img/sar-architecture.svg)
*Внутрішня архітектура SAR АЦП на базі ємнісного ЦАП (CDAC). Спільна шина верхніх обкладок утворює плаваючий вузол порівняння Vx, а скінченний автомат SAR послідовно керує нижніми ключами під час двійкового пошуку.*

Структурно перетворювач складається з чотирьох взаємопов'язаних функціональних блоків:

1. **Ємнісний цифро-аналоговий перетворювач (CDAC / матриця зважених конденсаторів):** Масив інтегрованих на кристалі конденсаторів із двійково зваженими номіналами `C, 2C, 4C, 8C, …, 2ᴺ⁻¹C` плюс додатковий конденсатор зміщення (фіктивний конденсатор, англ. *dummy capacitor*) ємністю `1C`. Загальна ємність матриці строго дорівнює:

```
C_total = 2ᴺ⁻¹·C + 2ᴺ⁻²·C + ... + 2·C + 1·C + C_dummy   [сума зважених ємностей матриці та фіктивного конденсатора]
        = (2ᴺ - 1)·C + 1·C                              [сума геометричної прогресії: ∑ 2ⁱ = 2ᴺ - 1]
        = 2ᴺ·C                                          [зведення подібних доданків: (2ᴺ - 1) + 1 = 2ᴺ]
```

2. **Ключ вибірки верхньої обкладки (Top-Plate Sampling Switch `S_sample`):** Високошвидкісний польовий транзистор із низьким рівнем інжекції заряду, який під час фази вибірки з'єднує спільну шину верхніх обкладок конденсаторів із землею `AGND` (або фіксованим потенціалом синфазного зміщення `Vcm`), а на початку зважування розмикається, ізолюючи вузол `Vx`.

3. **Прецизійний динамічний компаратор напруги:** Високочутливий підсилювач із малим рівнем власних шумів і схемою динамічного автопідстроювання нуля (англ. *auto-zeroing* / *correlated double sampling*). Неінвертуючий вхід компаратора підключено до плаваючого вузла `Vx`, а інвертуючий — до аналогової землі `AGND`. Компаратор визначає знак потенціалу на плаваючому вузлі: чи стала напруга `Vx` більшою за нуль, чи лишається меншою.

4. **Логічний регістр послідовного наближення (SAR FSM & Timing Engine):** Цифровий скінченний автомат, що реалізує апаратний алгоритм двійкового пошуку. Він містить зсувний регістр вибору поточного розряду, регістр результату та логіку формування керуючих сигналів для нижніх комутаторів CDAC.

### Фізика перерозподілу заряду: три фази перетворення

Перетворення аналогового рівня в двійковий код відбувається у три послідовні фази, що спираються на фундаментальний закон збереження електричного заряду на замкненому ізольованому провіднику.

![Три фази роботи матриці CDAC](/root/hw/hw-sensing/sar-adc-internals/img/charge-redistribution-phases.svg)
*Три фази роботи SAR АЦП: 1 — вибірка напруги та фіксація заряду; 2 — розмикання верхнього ключа та інверсія потенціалу вузла; 3 — порозрядне бінарне зважування за допомогою перемикання обкладок на Vref.*

#### 1. Фаза вибірки (Sample / Track Mode)

Ключ `S_sample` замкнено, з'єднуючи вузол верхньої обкладки `Vx` із землею (`Vx = 0 В`). Усі нижні комутатори матриці CDAC підключено до вхідного сигналу `Vin`. 

Увесь масив конденсаторів виявляється увімкненим паралельно між шиною `Vin` та землею. Струм від джерела сигналу заряджає сумарну ємність `C_total = 2ᴺ · C` до напруги `Vin`. Оскільки верхня обкладка підключена до 0 В, сумарний заряд, накопичений на верхніх обкладках ізольованого вузла, становить:

```
Q_sample = (0 - Vin) · C_total
         = -Vin · C_total             [накопичений заряд на вузлі Vx]
         = -Vin · (2ᴺ · C)
```

#### 2. Фаза фіксації (Hold Transition)

Після завершення часу вибірки ключ `S_sample` розмикається. Вузол `Vx` стає електрично ізольованим островом усередині кремнієвого кристала. Оскільки шлях для витоку чи притоку електронів перекрито (вхідний опір закритого ключа та затворів диференційного каскаду компаратора сягає сотень гігаом), зафіксований заряд `Q_sample` лишається абсолютно незмінним протягом усього циклу перетворення:

```
Q_node = const = -Vin · (2ᴺ · C)
```

Одразу після розмикання `S_sample` усі нижні ключі матриці відключаються від входу `Vin` і комутуються на землю `AGND` (`0 В`). Оскільки різниця потенціалів на конденсаторах стрибком змінюється (нижні обкладки стали 0 В замість `Vin`), напруга на плаваючому вузлі верхніх обкладок `Vx` повторює цей перепад і стає від'ємною:

```
Vx = 0 - Vin = -Vin
```

Таким чином, вхідний сигнал інвертувався та зафіксувався у вигляді зміщення потенціалу вузла `Vx` відносно точки відліку компаратора.

#### 3. Фаза порозрядного зважування (Binary Search & Bit Trials)

Після інверсії починається побітове визначення коду від старшого біта (MSB, `b[N-1]`) до молодшого (LSB, `b[0]`). Кожен крок займає рівно один такт синхросигналу АЦП.

**Крок 1: Оцінка старшого значущого розряду (MSB, біт N−1).**
Нижню обкладку найбільшого конденсатора `C_MSB = 2ᴺ⁻¹ · C` (який становить рівно половину загальної ємності `C_total / 2`) логіка SAR перемикає з землі на шину опорної напруги `Vref`. Нижні обкладки всіх інших конденсаторів залишаються на землі `AGND`.

Утворюється ємнісний подільник напруги: конденсатор `C_MSB` підключений до `Vref`, а паралельне з'єднання решти конденсаторів сумарною ємністю `C_rest = C_total - C_MSB = 2ᴺ⁻¹ · C` підключене до `0 В`.

Згідно із законом збереження заряду на вузлі `Vx`:

```
Q_node = (Vx - Vref)·C_MSB + (Vx - 0)·C_rest   [баланс заряду після підключення C_MSB до Vref]
       = Vx·(C_MSB + C_rest) - Vref·C_MSB      [розкриття дужок та групування за Vx]
       = Vx·C_total - Vref·(C_total / 2)       [підстановка C_MSB + C_rest = C_total та C_MSB = C_total / 2]
       = -Vin·C_total                          [закон збереження заряду: Q_node = Q_sample]
```

Звідси потенціал плаваючого вузла набуває значення:

```
Vx·C_total = -Vin·C_total + Vref·(C_total / 2)  [перенесення доданка Vref праворуч]
Vx = -Vin + 0.5·Vref                            [поділ обох частин на C_total]
```

Компаратор аналізує знак напруги `Vx`:
- Якщо `Vx < 0` (що рівнозначно `-Vin + 0.5·Vref < 0` або `Vin > 0.5·Vref`), вихід компаратора видає логічну одиницю (`D_out = 1`). Логіка SAR фіксує біт `b[N-1] = 1`, а нижня обкладка `C_MSB` **залишається підключеною до Vref**.
- Якщо `Vx ≥ 0` (що означає `Vin ≤ 0.5·Vref`), вихід компаратора видає логічний нуль (`D_out = 0`). Логіка SAR фіксує біт `b[N-1] = 0`, і нижня обкладка `C_MSB` **перемикається назад на землю AGND**, повертаючи потенціал `Vx` до вихідного рівня.

**Крок 2: Оцінка наступного розряду (біт N−2).**
Нижня обкладка конденсатора `C[N-2] = 2ᴺ⁻² · C` (чверть повної ємності) підключається до `Vref`. Потенціал вузла `Vx` отримує додатковий позитивний зсув на `+0.25 · Vref`. Нове значення становить:

```
Vx = -Vin + b[N-1]·(0.5·Vref) + 0.25·Vref
```

Компаратор знову стробується тактовим фронтом і визначає знак `Vx`. Якщо `Vx < 0`, біт `b[N-2] = 1` і конденсатор залишається на `Vref`; якщо `Vx ≥ 0`, біт `b[N-2] = 0` і конденсатор повертається на землю.

**Загальне рівняння після N кроків:**
Процедура повторюється послідовно для всіх розрядів до найменшого `C[0] = 1C`. На `k`-му кроці до вузла додається зважений внесок `Vref / 2ᵏ`. До кінця циклу потенціал вузла `Vx` асимптотично приводиться практично до нуля:

```
Vx = -Vin + Vref · ∑ [i=0 .. N-1] (b[i] · 2ⁱ⁻ᴺ) ≈ 0 В
```

![Траєкторія напруги вузла Vx під час бінарного пошуку](/root/hw/hw-sensing/sar-adc-internals/img/bit-trial-trajectory.svg)
*Динаміка напруги вузла Vx протягом 4-бітного перетворення сигналу Vin = 0.65 Vref (код 1010b = 10). Кожен такт додає бінарну пробу напруги, зменшуючи інтервал невизначеності рівно вдвічі, поки залишковий потенціал не увійде у стулку ±0.5 LSB.*

У результаті `N` тактів напруга вузла `Vx` збігається до нуля з похибкою, меншою за `±0.5 LSB`, а вихідний регістр SAR містить готове двійкове число:

```
D_code = ∑ [i=0 .. N-1] b[i] · 2ⁱ = round( (Vin / Vref) · 2ᴺ )
```

### Розділений CDAC (Split-Capacitor DAC) для високої розрядності

Пряма реалізація бінарно зваженої матриці конденсаторів стикається з фізичним обмеженням при зростанні розрядності. Якщо для 10-бітного АЦП загальна кількість одиничних ємностей `C_total = 2¹⁰ C₀ = 1024 C₀` є цілком прийнятною, то для 16-бітного перетворювача матриця вимагала б:

```
C_total = 2¹⁶ · C₀ = 65 536 · C₀
```

Навіть якщо технологічно виготовити мінімальний одиничний конденсатор `C₀ = 30 фФ` (30·10⁻¹⁵ Ф), сумарна ємність кристала перевищить `1.96 нФ`. Для заряду такої ємності за десятки наносекунд знадобилися б гігантські струми й надпотужні буфери, а площа кристала зросла б непропорційно.

Щоб розв'язати цю проблему, у прецизійних SAR АЦП застосовують **розділену матрицю CDAC (Split-Capacitor / Sub-DAC)** з мостовим конденсатором зв'язку (англ. *bridge / attenuation capacitor* `C_bridge`).

Матрицю поділяють на дві секції — групу старших розрядів (MSB Array, наприклад, 8 біт) та групу молодших розрядів (LSB Array, 8 біт), які з'єднані послідовним конденсатором:

```
C_bridge = (256 / 255) · C₀ ≈ 1.0039 · C₀
```

Завдяки конденсатору зв'язку напруга з матриці LSB послаблюється у 256 разів при передачі на спільний вузол MSB. У результаті загальна ємність схеми падає з `65 536 C₀` до:

```
C_split = C_MSB_array + C_LSB_array = 256·C₀ + 256·C₀ = 512·C₀
```

Ємність зменшилася у 128 разів (до помірних `15.3 пФ`), що дозволило зберегти високу швидкість встановлення та низьку собівартість чипа. Проте міст зв'язку вкрай чутливий до паразитної ємності розведення провідників, що вимагає застосування цифрового калібрування коефіцієнтів зважування на етапі заводського тестування.

### Час вибірки (t_acq), експоненційне встановлення та імпеданс джерела

У фазі вибірки аналоговий вхід являє собою послідовний RC-ланцюг, утворений внутрішніми елементами кристала та зовнішнім колом сигналу.

![Експоненційне встановлення напруги на Csample](/root/hw/hw-sensing/sar-adc-internals/img/sampling-settling-rc.svg)
*Експоненційний перехідний процес заряду Csample. Для досягнення похибки, меншої за половину кванта (0.5 LSB), час вибірки t_acq повинен тривати не менше (N + 1) · ln(2) сталих часу кола.*

Сумарний активний опір кола заряду складається з чотирьох компонентів:

```
R_total = R_src + R_ext + R_mux + R_sw
```
де:
- `R_src` — вихідний опір джерела аналогового сигналу (давача, подільника напруги);
- `R_ext` — послідовний резистор зовнішнього фільтра захисту від завад;
- `R_mux` — опір внутрішнього канального аналогового мультиплексора (якщо канал комутований, зазвичай 200…1000 Ом);
- `R_sw` — опір ключа вибірки на кристалі (500…2000 Ом).

Напруга на конденсаторі `C_sample` під час кроку встановлення описується класичним диференціальним рівнянням перехідного процесу:

```
V_c(t) = Vin · ( 1 - e^( -t / tau ) )
де tau = R_total · C_sample
```

Відносна похибка недовстановлення напруги на момент закінчення часу вибірки `t_acq` становить:

```
epsilon(t_acq) = (Vin - V_c(t_acq)) / Vin = e^( -t_acq / tau )
```

Щоб ця похибка не перевищувала половини молодшого розряду (`0.5 LSB`), має виконуватися строга метрологічна умова:

```
e^( -t_acq / tau ) ≤ 1 / (2 · 2ᴺ) = 1 / 2ᴺ⁺¹          [похибка не повинна перевищувати 0.5 LSB]
-t_acq / tau ≤ ln( 1 / 2ᴺ⁺¹ ) = -(N + 1) · ln(2)      [логарифмування обох частин нерівності]
t_acq ≥ (N + 1) · ln(2) · tau                         [множення на -tau зі зміною знака нерівності]
      ≈ 0.69315 · (N + 1) · R_total · C_sample        [підстановка часової сталої tau = R_total · C_sample]
```

Кількість сталих часу `k_tau = (N + 1) · ln(2)`, необхідна для гарантованого встановлення, зростає зі збільшенням розрядності:

| Розрядність (N) | Необхідна кількість tau (`k_tau`) | Залишкова похибка | Допустима похибка (0.5 LSB) |
|---|---|---|---|
| **8 біт** | **6.24 tau** | 0.195 % | 0.195 % (1/512) |
| **10 біт** | **7.62 tau** | 0.0488 % | 0.0488 % (1/2048) |
| **12 біт** | **9.01 tau** | 0.0122 % | 0.0122 % (1/8192) |
| **14 біт** | **10.40 tau** | 0.00305 % | 0.00305 % (1/32768) |
| **16 біт** | **11.78 tau** | 0.00076 % | 0.00076 % (1/131072) |
| **18 біт** | **13.17 tau** | 0.00019 % | 0.00019 % (1/524288) |

Знаючи мінімальний час вибірки `t_acq`, доступний у налаштуваннях АЦП, можна точно розрахувати гранично допустимий опір джерела сигналу `R_src_max`:

```
R_src_max ≤ ( t_acq / ( (N + 1) · ln(2) · C_sample ) ) - (R_sw + R_mux + R_ext)
```

**Практичний приклад розрахунку для мікроконтролера STM32 (12 біт, C_sample = 8 пФ, R_sw = 1.5 кОм):**
Якщо час вибірки задано в 15 тактів при частоті АЦП 14 МГц (`t_acq = 15 / 14·10⁶ ≈ 1.07 мкс`):

```
R_total_max = 1.07·10⁻⁶ / ( 9.01 · 8·10⁻¹² ) ≈ 14 840 Ом (14.84 кОм)

R_src_max = 14.84 кОм - 1.5 кОм = 13.34 кОм
```
Якщо вихідний опір давача перевищує 13.3 кОм, вимір гарантовано отримає систематичну динамічну похибку підсилення (англ. *gain error*) та нелінійності через недовстановлення заряду.

#### Динамічний вхідний імпеданс комутованої ємності
Оскільки конденсатор `C_sample` перезаряджається на кожному циклі перетворення з частотою дискретизації `f_s`, середній вхідний струм, що відбирається від джерела, становить `I_avg = f_s · C_sample · ΔVin`. Еквівалентний динамічний вхідний опір АЦП на комутованих конденсаторах оцінюється як:

```
R_in_eq ≈ 1 / ( f_s · C_sample )
```
При `f_s = 1 MSPS` та `C_sample = 10 пФ` еквівалентний вхідний опір становить лише `100 кОм`. Джерело сигналу з опором навіть 10 кОм під дією такого струму утворить статичний подільник із похибкою близько 9%, якщо на вході відсутній відповідний буферний конденсатор.

### Похибки, шуми та неідеальності SAR АЦП

Ідеальний двійковий пошук працює бездоганно лише в математичній моделі. У реальному кремнії фізичні обмеження напівпровідникових структур спричиняють специфічні спотворення.

#### 1. Невідповідність ємностей (Capacitor Mismatch) та DNL/INL
Жоден літографічний процес не здатен виготовити два конденсатори з абсолютно однаковою геометрією. Згідно із законом Пелгрома (англ. *Pelgrom's Law*), відносне відхилення ємності зменшується зі збільшенням площі пластин:

```
sigma( Delta_C / C ) ∝ 1 / sqrt( Area )
```

Найнебезпечнішим моментом для SAR АЦП є **перехід через середину шкали (Major Carry Transition)** — перемикання коду з `0111...11` на `1000...00`. У цій точці старший конденсатор `C_MSB` порівнюється із сумою всіх молодших конденсаторів `∑ C_lower + C_dummy`.

- Якщо через похибку виготовлення `C_MSB` виявився хоча б на 0.1% меншим за номінал, щабель переходу різко скорочується. Значення диференціальної нелінійності падає: `DNL < 0`. Якщо `DNL ≤ -1 LSB`, ширина сходинки падає до нуля — виникає **пропущений код (Missing Code)**, коли певне число на виході не з'явиться за жодної вхідної напруги.
- Якщо `C_MSB` більший за номінал, щабель стає занадто широким (`DNL > +1 LSB`), що руйнує монотонність передавальної характеристики.

Накопичена сума похибок усіх конденсаторів формує **інтегральну нелінійність (INL)**, яка зазвичай досягає максимуму біля середини шкали (в околі `0.5 Vref` та `0.25 Vref`).

#### 2. Тепловий шум комутації (kT/C Noise)
У момент розмикання ключа вибірки тепловий шум опору його каналу (шум Джонсона-Найквіста) миттєво фіксується («заморожується») на конденсаторі `C_sample`. Незалежно від величини опору ключа `R_sw`, інтегральна дисперсія напруги шуму визначається виключно температурою та величиною ємності:

```
sigma_v² = (k_B · T) / C_sample

V_noise_rms = sqrt( (k_B · T) / C_sample )
```
де `k_B ≈ 1.380649 · 10⁻²³ Дж/К` — стала Больцмана, `T = 300 К` — абсолютна температура (`k_B · T ≈ 4.14 · 10⁻²¹ Дж`).

Розрахунок середньоквадратичної напруги шуму для типових ємностей:
- `C = 1 пФ`  → `V_rms ≈ 64.3 мкВ`
- `C = 10 пФ` → `V_rms ≈ 20.3 мкВ`
- `C = 50 пФ` → `V_rms ≈ 9.1 мкВ`

Для 16-бітного перетворювача з `Vref = 3.3 В` величина `1 LSB = 3.3 / 65536 ≈ 50.35 мкВ`. Якщо обрати ємність `C_sample = 1 пФ`, шум вибірки `64.3 мкВ` перевищить один квант, розмиваючи молодші 2-3 біти. Збільшення ємності пригнічує шум, проте пропорційно збільшує час заряду `tau`.

#### 3. Шум і зсув компаратора (Comparator Noise & Metastability)
Власний тепловий шум та низькочастотний флікер-шум (`1/f`) вхідних польових транзисторів компаратора додають випадковий шум перемикання. Якщо напруга `Vx` наприкінці такту опиняється дуже близько до нуля (`|Vx| < V_noise`), компаратор може помилково спрацювати під дією внутрішньої флуктуації, створюючи шум перехідного коду (англ. *transition noise*).

Крім того, компаратори SAR АЦП страждають на **метастабільність**: якщо диференціальна напруга на вході прямує до нуля, час наростання вихідного сигналу регенеративного тригера-засувки (англ. *latch*) експоненційно затягується. Якщо тригер не встигає встановитися у стабільний логічний рівень за один такт, у поточному біті виникає фатальна груба помилка (англ. *sparkle code*).

#### 4. Інжекція заряду ключа (Charge Injection)
При вимиканні польового МОН-транзистора ключа `S_sample` заряд вільних носіїв, накопичений у його струмопровідному каналі `Q_ch = W · L · C_ox · (V_gate - V_in - V_th)`, виштовхується через виводи витоку та стоку в підключені кола. Частина цього заряду стікає на верхню обкладку матриці CDAC.

Для боротьби з цим явищем застосовують техніку **вибірки по нижній обкладці (Bottom-Plate Sampling)**: ключ верхньої обкладки `S_sample` розмикають на кілька пікосекунд *раніше*, ніж відключають нижні обкладки від `Vin`. Оскільки верхня обкладка в момент розмикання підключена до постійного потенціалу землі `AGND`, інжектований заряд виявляється постійним і не залежить від вхідної напруги `Vin`, перетворюючись на звичайний постійний зсув нуля (Offset), який легко калібрується програмно.

#### 5. Апертурний джитер (Sampling Jitter)
Нестабільність фронту тактового сигналу дискретизації `t_j` (фазовий шум генератора) створює похибку амплітуди при оцифруванні динамічних високочастотних сигналів. Теоретична стеля відношення сигнал/шум (SNR), обмежена джитером, становить:

```
SNR_jitter = -20 · log10( 2 · pi · f_in · t_j )
```
При вимірюванні сигналу частотою `f_in = 100 кГц` з апертурним джитером `t_j = 100 пс` максимальний SNR не може перевищити `84 дБ` (еквівалент приблизно 13.6 біт), незалежно від паспортної розрядності АЦП.

### Практична схемотехніка: Драйвер АЦП та демпфування комутаційного удару

Щоб повністю розкрити паспортну точність SAR АЦП, його аналоговий вхід та вивід опорної напруги потребують правильного зовнішнього схемотехнічного узгодження.

![Схемотехніка драйвера АЦП та демпфування комутаційного удару](/root/hw/hw-sensing/sar-adc-internals/img/adc-input-driver-kickback.svg)
*Схема підключення прецизійного драйвера АЦП. Зовнішній конденсатор Cext працює енергетичним резервуаром для імпульсного заряду Csample, а Rext забезпечує фазову стійкість операційного підсилювача.*

> 🔧 **Навіщо це.** Спроба підключити повільний операційний підсилювач безпосередньо до входу SAR АЦП без зовнішнього RC-ланцюга призводить до втрати стабільності підсилювача або колосальної похибки недовстановлення. У момент замикання ключа `S_sample` вихідний каскад ОП бачить миттєве коротке замикання на конденсатор `C_sample`, що викликає стрибок напруги й затяжний високочастотний дзвін.

Правильне узгодження реалізується за допомогою трьох правил:

1. **Зовнішній резервуарний конденсатор (`C_ext`):**
   Безпосередньо біля аналогової ніжки АЦП установлюють прецизійний керамічний конденсатор діелектрика C0G/NP0 (із нульовим п'єзоефектом і мінімальною діелектричною абсорбцією). Ємність обирають у 20…50 разів більшою за внутрішню `C_sample`:
   ```
   C_ext ≥ 20…50 · C_sample  (типово 1…2.2 нФ)
   ```
   У момент комутації зарядний струм `C_sample` забирається не з повільного підсилювача, а з попередньо зарядженого `C_ext`. Завдяки перерозподілу заряду амплітуда комутаційного удару просідання напруги на вході падає до часток відсотка:
   ```
   Delta_V_kickback = Vin · ( C_sample / (C_ext + C_sample) ) ≤ 2…5 %
   ```

2. **Ізолюючий демпферний резистор (`R_ext`):**
   Резистор номіналом `10…50 Ом` вмикається між виходом операційного підсилювача та конденсатором `C_ext`. Він виконує дві функції:
   - Ізолює ємнісне навантаження `C_ext` від виходу ОП, усуваючи додатковий полюс у петлі зворотного зв'язку та запобігаючи самозбудженню підсилювача;
   - Разом із `C_ext` утворює антиаліасинговий фільтр низьких частот для пригнічення широкосмугового шуму.

3. **Блокування виводу опорної напруги (`Vref`):**
   Під час кожного такту порозрядного зважування матриця CDAC споживає імпульсний струм від джерела `Vref` для заряду чергового конденсатора. Якщо лінія `Vref` має індуктивність або недостатнє блокування, напруга опори просідатиме саме під час зважування старших розрядів. Тому прямо на ніжках `VREF+` та `AGND` монтують високоякісний керамічний конденсатор `10…47 мкФ` (X7R) паралельно з керамікою `0.1 мкФ` з найкоротшими доріжками на платі.

### Поведінкова модель SAR АЦП на C та C++

Наведений нижче повний симулятор демонструє фізичні процеси всередині SAR АЦП: моделювання розкиду ємностей матриці CDAC (закон Пелгрома), додавання теплового шуму `kT/C`, зсуву та шуму компаратора, розрахунок неповної зарядки через опір джерела та покрокове порозрядне зважування.

```c
#include <stdio.h>
#include <stdlib.h>
#include <math.h>
#include <stdbool.h>

#define ADC_BITS 12
#define CDAC_SIZE (1 << ADC_BITS)

typedef struct {
    double vref;           /* Опорна напруга, В */
    double c_unit;         /* Одинична ємність C0, Ф */
    double c_sample_tot;   /* Сумарна ємність C_total, Ф */
    double r_total;        /* Сумарний опір кола заряду, Ом */
    double t_acq;          /* Час вибірки, с */
    double comp_offset;    /* Напруга зсуву компаратора, В */
    double comp_noise_rms; /* СРК шуму компаратора, В */
    double temp_k;         /* Температура, Кельвін */
    double cap_weights[ADC_BITS]; /* Реальні ваги ємностей з урахуванням розкиду */
} SarAdcModel;

/* Генератор нормально розподіленого шуму (перетворення Бокса-Мюллера) */
static double generate_gaussian(double mean, double sigma) {
    double u1 = ((double)rand() + 1.0) / ((double)RAND_MAX + 1.0);
    double u2 = ((double)rand() + 1.0) / ((double)RAND_MAX + 1.0);
    double z0 = sqrt(-2.0 * log(u1)) * cos(2.0 * 3.14159265358979323846 * u2);
    return mean + z0 * sigma;
}

/* Ініціалізація моделі АЦП з розкидом параметрів кремнію */
void sar_adc_init(SarAdcModel* adc, double vref, double r_src, double t_acq, double cap_mismatch_std) {
    adc->vref = vref;
    adc->c_unit = 25e-15; /* 25 фФ */
    adc->r_total = r_src + 1500.0; /* Rsrc + R_switch */
    adc->t_acq = t_acq;
    adc->comp_offset = 0.0004; /* 400 мкВ зсуву */
    adc->comp_noise_rms = 0.00015; /* 150 мкВ шуму */
    adc->temp_k = 300.0;

    double c_accum = 0.0;
    for (int i = 0; i < ADC_BITS; i++) {
        double ideal_weight = (double)(1 << i);
        /* Розкид ємності згідно із законом Пелгрома sigma ~ 1/sqrt(Area) */
        double sigma = cap_mismatch_std / sqrt(ideal_weight);
        double actual_weight = ideal_weight * (1.0 + generate_gaussian(0.0, sigma));
        adc->cap_weights[i] = actual_weight;
        c_accum += actual_weight * adc->c_unit;
    }
    c_accum += 1.0 * adc->c_unit; /* Dummy capacitor 1C */
    adc->c_sample_tot = c_accum;
}

/* Виконання одного повного циклу аналого-цифрового перетворення */
unsigned int sar_adc_convert(const SarAdcModel* adc, double v_in) {
    /* 1. Фаза вибірки: експоненційний заряд Csample */
    double tau = adc->r_total * adc->c_sample_tot;
    double settling_factor = 1.0 - exp(-adc->t_acq / tau);
    double v_sampled = v_in * settling_factor;

    /* 2. Тепловий шум комутації kT/C */
    const double kb = 1.380649e-23;
    double kt_c_noise_sigma = sqrt((kb * adc->temp_k) / adc->c_sample_tot);
    v_sampled += generate_gaussian(0.0, kt_c_noise_sigma);

    /* 3. Фіксація: інверсія потенціалу на плаваючому вузлі Vx */
    double v_x = -v_sampled;
    unsigned int digital_code = 0;

    /* 4. Порозрядне зважування (Binary Search від MSB до LSB) */
    double c_tot_weights = (double)(1 << ADC_BITS);

    for (int bit = ADC_BITS - 1; bit >= 0; bit--) {
        /* Пробне підключення поточної ємності до Vref */
        double v_trial_step = adc->vref * (adc->cap_weights[bit] / c_tot_weights);
        double v_x_probe = v_x + v_trial_step;

        /* Врахування зсуву та шуму стробування компаратора */
        double comp_threshold = adc->comp_offset + generate_gaussian(0.0, adc->comp_noise_rms);

        if (v_x_probe < comp_threshold) {
            /* Сигнал більший за пробний рівень: біт = 1 */
            digital_code |= (1 << bit);
            v_x = v_x_probe; /* Залишаємо нижню обкладку на Vref */
        } else {
            /* Сигнал менший: біт = 0 (скидаємо обкладку на GND) */
            /* v_x залишається без доданого кроку */
        }
    }

    return digital_code;
}

int main(void) {
    SarAdcModel adc;
    sar_adc_init(&adc, 3.3, 10000.0, 1.2e-6, 0.002);

    printf("=== Симуляція SAR АЦП 12-біт (Vref = 3.3 В) ===\n");
    double test_voltages[] = {0.0, 0.825, 1.650, 2.475, 3.300};
    for (int i = 0; i < 5; i++) {
        double v = test_voltages[i];
        unsigned int code = sar_adc_convert(&adc, v);
        double reconstructed_v = (code * adc.vref) / (double)(CDAC_SIZE - 1);
        printf("Вхід: %6.4f В -> Код: %4u -> Відновлено: %6.4f В (Похибка: %+6.2f мВ)\n",
               v, code, reconstructed_v, (reconstructed_v - v) * 1000.0);
    }
    return 0;
}
```

```cpp

class SarAdcSimulator {
public:
    static constexpr unsigned int Bits = 12;
    static constexpr unsigned int TotalCodes = 1U << Bits;

    struct Config {

        double c_unit = 25e-15;        // Базова одинична ємність 25 фФ
        double r_src = 10000.0;        // Опір джерела сигналу, Ом
        double r_switch = 1500.0;      // Опір внутрішнього ключа, Ом
        double t_acq = 1.2e-6;         // Час вікна вибірки, с
        double comp_offset = 0.0004;   // Напруга зсуву компаратора (400 мкВ)
        double comp_noise_rms = 1.5e-4;// Шум компаратора (150 мкВ)
        double cap_mismatch_std = 0.002;// Технологічний розкид ємності (0.2%)

    };

    explicit SarAdcSimulator(const Config& cfg)
        : config_(cfg),
          rng_(std::random_device{}()) {
        initializeCapacitorArray();
    }

    [[nodiscard]] unsigned int convert(double v_in) {
        // 1. Динаміка заряду вхідної комутованої ємності
        const double tau = (config_.r_src + config_.r_switch) * total_capacitance_;
        const double settling_factor = 1.0 - std::exp(-config_.t_acq / tau);
        double v_sampled = v_in * settling_factor;

        // 2. Додавання замороженого теплового шуму kT/C
        constexpr double kb = 1.380649e-23;
        const double kt_c_rms = std::sqrt((kb * config_.temp_k) / total_capacitance_);
        std::normal_distribution<double> kt_dist(0.0, kt_c_rms);
        v_sampled += kt_dist(rng_);

        // 3. Фіксація заряду та інверсія потенціалу вузла
        double v_x = -v_sampled;
        unsigned int digital_code = 0;

        // 4. Порозрядне бінарне зважування (SAR FSM)
        std::normal_distribution<double> comp_noise_dist(0.0, config_.comp_noise_rms);
        const double c_tot_weights = static_cast<double>(TotalCodes);

        for (int bit = static_cast<int>(Bits) - 1; bit >= 0; --bit) {
            const double v_step = config_.vref * (cap_weights_[bit] / c_tot_weights);
            const double v_x_probe = v_x + v_step;

            const double threshold = config_.comp_offset + comp_noise_dist(rng_);

            if (v_x_probe < threshold) {
                digital_code |= (1U << bit);
                v_x = v_x_probe; // Зберегти розряд
            }
        }

        return digital_code;
    }

    [[nodiscard]] double codeToVoltage(unsigned int code) const noexcept {
        return (static_cast<double>(code) * config_.vref) / static_cast<double>(TotalCodes - 1);
    }

private:
    void initializeCapacitorArray() {
        double accumulated_c = 0.0;
        for (size_t i = 0; i < Bits; ++i) {
            const double ideal_weight = static_cast<double>(1U << i);
            const double sigma = config_.cap_mismatch_std / std::sqrt(ideal_weight);
            std::normal_distribution<double> mismatch_dist(0.0, sigma);

            cap_weights_[i] = ideal_weight * (1.0 + mismatch_dist(rng_));
            accumulated_c += cap_weights_[i] * config_.c_unit;
        }
        accumulated_c += 1.0 * config_.c_unit; // Dummy capacitor 1C
        total_capacitance_ = accumulated_c;
    }

    Config config_;
    std::mt19937 rng_;
    std::array<double, Bits> cap_weights_{};
    double total_capacitance_{0.0};
};

int main() {
    SarAdcSimulator::Config cfg;
    SarAdcSimulator adc(cfg);

    std::cout << "=== Поведінкова модель SAR АЦП 12-біт (C++20) ===\n";
    constexpr std::array<double, 5> test_voltages{0.0, 0.825, 1.650, 2.475, 3.300};

    std::cout << std::fixed << std::setprecision(4);
    for (double v : test_voltages) {
        unsigned int code = adc.convert(v);
        double reconstructed = adc.codeToVoltage(code);
        double error_mv = (reconstructed - v) * 1000.0;

        std::cout << "Вхід: " << std::setw(6) << v << " В -> "
                  << "Код: " << std::setw(4) << code << " -> "
                  << "Відновлено: " << std::setw(6) << reconstructed << " В "
                  << "(Похибка: " << std::showpos << std::setw(6) << std::setprecision(2)
                  << error_mv << " мВ)\n"
                  << std::noshowpos << std::setprecision(4);
    }
    return 0;
}
```

### Підсумок інженерних правил

Стійка та прецизійна робота SAR АЦП забезпечується дотриманням базових правил проектування тракту:

1. **Контроль часу вибірки:** Час дискретизації `t_acq` повинен задовольняти нерівність `t_acq ≥ (N + 1) · ln(2) · R_total · C_sample`. Для 12 біт це вимагає не менше `9 tau`, для 16 біт — майже `12 tau`.
2. **Захисний RC-буфер на вході:** Для джерел сигналу з опором понад сотні ом обов'язковим є встановлення зовнішнього конденсатора `C_ext ≥ 20 · C_sample` (типу C0G/NP0) та демпферного резистора `R_ext ≈ 20…50 Ом` безпосередньо біля виводу мікросхеми.
3. **Низькоімпедансна опора Vref:** Опорний вивід потребує локального керамічного шунтування ємністю не менше 10 мкФ поруч із корпусом для компенсації імпульсних просідань заряду під час спрацьовування старших розрядів CDAC.
4. **Урахування теплового шуму kT/C:** При проектуванні високорозрядних систем (16–18 біт) вибір ємності вибірки `C_sample` диктується компромісом між тепловим шумом перемикання та смугою пропускання вхідного драйвера.
