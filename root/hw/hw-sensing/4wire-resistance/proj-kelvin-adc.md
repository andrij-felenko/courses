# ⚙️ Проєкт: Прецизійний чотирипровідний мікроомметр та монітор RTD PT100 на базі 24-бітного АЦП

Створення приладу для вимірювання надмалих опорів (мікроомметра) або високоточного термометра опору на платиновому сенсорі `RTD PT100` вимагає поєднання прецизійного аналогового фронтенду (АЦП високої роздільної здатності, `24 біти`) та спеціалізованого цифрового алгоритму керування струмом збудження з активною компенсацією термо-ЕРС.

У цьому проєкті розглянуто повну архітектуру побудови вимірювального модуля на базі 24-бітного сігма-дельта АЦП (наприклад, `ADS124S08`, `ADS1232` або `AD7124-4`), оснащеного вбудованими керованими джерелами струму (`IDAC`), малошумним програмованим підсилювачем (`PGA`) та диференційним вимірювальним входом.

### 1. Архитектура аналогового вимірювального тракту

Для досягнення найвищої точності при вимірюванні опорів у мікроомному та міліомному діапазонах застосовують **ратіометричну схему вимірювання** (*Ratiometric Measurement System*). У цій схемі опір обчислюється не через абсолютні значення струму й напруги, а через відношення спаду напруги на досліджуваному резисторі до спаду напруги на опорному резисторі.

Принцип побудови вимірювального тракту містить такі ключові елементи:

1. **Генератор струму збудження (`IDAC`):** Джерело струму виробляє стабільний струм `I_ex` (наприклад, `I_ex = 1.0` мА для датчика `PT100` або `I_ex = 100` мА для мікроомметра). Струм подається через силові клеми `Force+` та `Force-`.
2. **Ратіометричне опорне коло:** Струм `I_ex` послідовно проходить через досліджуваний опір `R_x` та прецизійний опорний резистор `R_ref` з низьким температурним коефіцієнтом опору (ТКО `< 5 ppm/°C`). Спад напруги на `R_ref` подається на входи опорної напруги АЦП (`VREF+` / `VREF-`).
   Завдяки цьому цифровий код АЦП описується відношенням:
   ```
   N_adc = 2²³ · (V_in / V_ref) = 2²³ · (I_ex · R_x / (I_ex · R_ref)) = 2²³ · (R_x / R_ref)
   ```
   У цій формулі значення струму `I_ex` повністю скорочується. Це означає, що точність вимірювання залежить **виключно від точності опорного резистора `R_ref`**, а довготривалий дрейф, шуми та температурна нестабільність джерела струму повністю скасовуються.

3. **Сигнальне коло (`Sense`):** Вимірювальні провідники підключаються безпосередньо до клем `R_x` та прямують до диференційних входів АЦП через `RC`-фільтр низьких частот (ФНЧ) для пригнічення високочастотних завад і наводок.

### 2. Двофазний алгоритм компенсації термо-ЕРС (Offset Compensation)

Для усунення паразитної термо-ЕРС, що виникає в контактних затискачах і з'єднаннях різнорідних металів, алгоритм мікроконтролера реалізує двофазний цикл вимірювання зі зміною полярності струму:

- **Фаза 1 (Пряма полярність `+I`):** Ключі аналогового комутатора або внутрішній мультиплексор АЦП подають струм у прямому напрямку. Мікроконтролер очікує завершення встановлення цифрового фільтра АЦП і зчитує відлік `N_pos`.
- **Фаза 2 (Зворотна полярність `−I`):** Комутатор змінює полярність струму на протилежну. Після встановлення фільтра зчитується відлік `N_neg`.
- **Цифрова обробка:** За різницевою формулою розраховується чистий опір `R_x`, а за полусумою відліків — величина паразитної термо-ЕРС для діагностики стану вимірювальних контактів.

Завдяки цьому алгоритму постійне зміщення напруги, обумовлене різницею температур контактів, повністю віднімається з вимірювального сигналу.

### 3. Алгоритм перетворення опору RTD PT100 у температуру

Платиновий термометр опору `PT100` має стандартний опір `100.0` Ом при температурі `0` °C. Залежність опору платини від температури для позитивного діапазону описується квадратичним рівнянням Календара-Ван Дюзена (*Callendar-Van Dusen equation*):

```
R(T) = R0 · (1 + A·T + B·T²)
```

де `R0 = 100.0` Ом, коефіцієнти стандарту `IEC 60751`:
- `A = 3.9083 · 10⁻³` °C⁻¹
- `B = −5.775 · 10⁻⁷` °C⁻²

Розв'язуючи це квадратичне рівняння відносно температури `T`, отримуємо аналітичну формулу розрахунку:

```
T = (−A + √(A² − 4·B·(1 − R(T) / R0))) / (2·B)
```

Ця формула реалізована в наведених програмних модулях.

### 4. Діагностика аварійних станів та крайових випадків

У реальних промислових умовах вимірювальна система може зіткнутися з серією апаратних збоїв. Програмний модуль здійснює автоматичний моніторинг таких крайових станів:

1. **Обрив вимірювального кабелю (`Open Sensor Detection`):** При обриві силової лінії `Force` струм `I_ex` припиняє протікати через `R_x` та `R_ref`. АЦП фіксує переповнення або нульовий код. Для діагностики обриву сигнальних ліній `Sense` у мікросхемі АЦП вмикають внутрішні джерела струму витоку (*Burnout Current Sources*) величиною `100` нА. При обриві доріжки `Sense` вхідна напруга АЦП миттєво підтягується до шини живлення, що викликає фіксацію помилки `SensorOpenCircuit`.
2. **Переповнення шкали АЦП (`ADC Overflow`):** При вимірюванні опорів, що перевищують межу підсилення PGA (`R_x > R_ref / Gain`), входний дифпідсилювач входить у насичення. Алгоритм автоматично зменшує коефіцієнт підсилення PGA на наступному кроці.
3. **Критичний рівень термо-ЕРС (`High Thermal EMF Fault`):** Якщо обчислена полусума виміряних напруг перевищує `50` мкВ, це свідчить про сильний перегрів контактних клем, руйнування покриття щупів або наявність корозії. Система видає попередження інженеру про необхідність очищення контактів.

### 6. Рекомендації з апаратного монтажу та налаштування

При конструюванні друкованої плати вимірювального модуля дотримуйтесь таких важливих інженерних правил:

1. **Симетрична ФНЧ-фільтрація:** На диференційних входах АЦП розміщують симетричний `RC`-фільтр. Опори резисторів вибирають одинакового номіналу (наприклад, `1` кОм з точністю `0.1%`), а між сигнальними лініями ставлять диференційний конденсатор `C_diff = 100` нФ. Для пригнічення синфазного шуму додають два однакові конденсатори `C_cm = 10` нФ між кожною лінією та аналоговою землею `AGND`.
2. **Розведення друкованих провідників:** Сигнальні лінії `Sense+` та `Sense-` трасують як диференційну пару паралельними доріжками мінімальної довжини. Слід уникати трасування сигнальних ліній під силовими імпульсними провідниками або поблизу джерел змінного магнітного поля (перетворювачів живлення, дроселів).
3. **Захист від подвійних контурів заземлення:** Вимірювальні кабелі, що йдуть до зовнішніх щупів або датчика `PT100`, повинні бути екранованими. Екранувальне обплетення підключається до аналогової землі `AGND` **лише в одній точці** (на боці вимірювального приладу), аби запобігти виникненню наводок від подвійних контурів заземлення (*Ground Loops*).
4. **Періодичність калібрування нуля:** Калібрування внутрішнього зміщення АЦП (*Self Offset Calibration*) рекомендується виконувати перед кожною серією вимірювань шляхом замкнення диференційних входів АЦП внутрішнім мультиплексором.
