# 🧮 Тепловий баланс мікроболометра та гранична чутливість NETD

Фундаментальна межа чутливості тепловізора визначається термодинамічним балансом окремого пікселя та фізичними джерелами шуму на рівні кристалічної ґратки. Розгляньмо виведення диференціального рівняння теплового балансу мікромембрани, частотну характеристику чутливості, аналіз усіх некорельованих джерел шуму та аналітичний розрахунок граничної еквівалентної шумом різниці температур (NETD).

## Диференціальне рівняння теплового балансу мембрани

Мікроболометричний піксель розглядається як дискретна теплова маса з теплоємністю `C_th` (Дж/К), яка підвішена над масивною кремнієвою підкладкою з постійною температурою `T_sub` та з'єднана з нею опорними мікроніжками з сумарною теплопровідністю `G_th` (Вт/К).

Теплоємність мембрани визначається її геометричним об'ємом `V = A_pix · d_mem` та питомою об'ємною теплоємністю матеріалів нітриду кремнію та оксиду ванадію (`c_v ≈ 2.0 · 10⁶` Дж/(м³·К)):

```
C_th = c_v · A_pix · d_mem
```

Для типового пікселя з площею `17 × 17` мкм (`A_pix = 2.89 · 10⁻¹⁰` м²) та сумарною товщиною шарів `d_mem = 0.2` мкм (200 нм) теплоємність становить:

```
C_th
= 2.0 · 10⁶ · 2.89 · 10⁻¹⁰ · 0.2 · 10⁻⁶
= 1.156 · 10⁻¹⁰ Дж / К                   [теплоємність одного пікселя]
```

На піксель діють два потоки енергії:
1. Поглинута оптична потужність інфрачервоного випромінювання сцени `η · P_rad(t)`, де `η` — спектральний коефіцієнт поглинання мембрани (`0 < η ≤ 1`, зазвичай 0.85 завдяки чвертьхвильовому резонатору).
2. Електрична потужність джоулевого нагріву струмом зчитування `P_joule(t) = I_bias²(t) · R_pix`.

Нехай `ΔT(t) = T_pix(t) − T_sub` — миттєве перевищення температури мембрани над підкладкою. За законом збереження енергії, швидкість накопичення внутрішньої теплової енергії дорівнює різниці між припливом потужності та відтоком тепла через ніжки:

```
C_th · (d(ΔT) / dt) + G_th · ΔT(t)
= η · P_rad(t) + P_joule(t)     [диференціальне рівняння теплового балансу пікселя]
```

## Частотна характеристика та теплова стала часу

Розгляньмо реакцію пікселя на змінний тепловий потік із гармонійною модуляцією на кутовій частоті `ω`: `P_rad(t) = P₀ · exp(j · ω · t)`. Нехтуючи постійною складовою фонового зміщення та переходячи до амплітуд у комплексній площині:

```
(j · ω · C_th + G_th) · ΔT(ω)
= η · P₀                        [підстановка гармонійної форми d/dt -> j·ω]
```

Звідси виразимо комплексну амплітуду коливань температури мембрани `ΔT(ω)`:

```
ΔT(ω)
= (η · P₀) / (G_th + j · ω · C_th)                      [ділення на комплексний тепловий імпеданс]
= (η · P₀) / (G_th · (1 + j · ω · (C_th / G_th)))       [винесення теплопровідності G_th за дужки]
= (η · P₀) / (G_th · (1 + j · ω · τ_th))                [введення теплової сталої часу τ_th = C_th / G_th]
```

Модуль коливання температури пікселя дорівнює:

```
|ΔT(ω)|
= (η · P₀) / (G_th · √(1 + ω² · τ_th²))                  [взяття евклідової норми знаменника]
```

### Інженерний компроміс теплової сталої часу `τ_th`
Теплова стала часу `τ_th = C_th / G_th = C_th · R_th` задає швидкість теплової реакції пікселя:
- Якщо зробити мікроніжки занадто тонкими (збільшити `R_th`), статичний нагрів `|ΔT_stat| = (η · P₀) / G_th` різко зросте, що підвищить чутливість сенсора.
- Проте зростання `R_th` пропорційно збільшує сталу часу `τ_th`. Якщо `τ_th` перевищить 15–20 мс, піксель не встигатиме охолоджуватися за період одного кадру (33.3 мс за частоти 30 Гц або 16.6 мс за 60 Гц). У результаті на рухомих об'єктах з'являються сильні шлейфи динамічного розмиття (англ. *thermal ghosting*).

Оптимальним компромісом для матриць із частотою 30–60 Гц є значення `τ_th ≈ 8 ... 12` мс за теплопровідності ніжок `G_th ≈ (3 ... 6) · 10⁻⁸` Вт/К.

## Вольтова чутливість (Voltage Responsivity)

Зміна температури мембрани `ΔT` викликає зміну електричного опору плівки терморезистора:

```
ΔR = R_pix · α · ΔT
```

де `α = (1/R) · (dR/dT)` — температурний коефіцієнт опору (TCR, близько `-0.025` К⁻¹ для оксиду ванадію `VO_x`).

Коли через піксель пропускається постійний струм зчитування `I_bias`, на ньому виникає зміна напруги `ΔV = I_bias · ΔR`.

Визначимо **вольтову чутливість** `R_v` (В/Вт) як відношення амплітуди вихідної напруги до амплітуди вхідної оптичної потужності `P₀`:

```
R_v
= ΔV / P₀                                               [означення коефіцієнта вольтової чутливості]
= (I_bias · ΔR) / P₀                                    [закон Ома для приросту напруги]
= (I_bias · R_pix · α · ΔT) / P₀                        [підстановка виразу приросту опору через TCR]
= (I_bias · α · R_pix · η) / (G_th · √(1 + ω² · τ_th²))  [підстановка модуля зміни температури |ΔT(ω)|]
```

Для статичного режиму або низьких кадрових частот (`ω · τ_th ≪ 1`):

```
R_v_stat
= (I_bias · |α| · R_pix · η) / G_th                     [статична вольтова чутливість пікселя]
```

Підставимо типові значення параметрів промислової VOx-матриці:
- `I_bias = 10` мкА (`10 · 10⁻⁶` А)
- `R_pix = 50` кОм (`50 · 10³` Ом)
- `|α| = 0.025` К⁻¹
- `η = 0.85`
- `G_th = 5 · 10⁻⁸` Вт/К

```
R_v_stat
= (10 · 10⁻⁶ · 0.025 · 50 · 10³ · 0.85) / (5 · 10⁻⁸)   [підстановка числових параметрів]
= (1.0625 · 10⁻²) / (5 · 10⁻⁸)                          [спрощення чисельника]
= 2.125 · 10⁵ В / Вт                                    [розрахункова статична чутливість]
```

Кожен нановат поглиненого інфрачервоного світла створює на пікселі корисний електричний відгук амплітудою близько 0.21 мілівольта.

## Чотири фундаментальні джерела шуму

Оскільки всі фізичні процеси генерації шуму в мікроболометрі є статистично незалежними, сумарна напруга шуму обчислюється геометричним додаванням дисперсій:

```
V_n_total
= √(V_n_J² + V_n_TF² + V_n_rad² + V_n_1f²)              [квадратичне сумування некорельованих шумів]
```

Розгляньмо фізику кожної шумової складової окремо:

### 1. Тепловий шум Джонсона — Найквіста (Johnson Noise)
Викликаний хаотичним тепловим броунівським рухом електронів провідності в активному резистивному шарі `R_pix`. Згідно з теоремою Найквіста, спектральна густина напруги білого шуму постійна в усьому діапазоні частот:

```
V_n_J
= √(4 · k_B · T_pix · R_pix · Δf)                       [формула Найквіста для теплового шуму]
```

де `k_B = 1.380649 · 10⁻²³` Дж/К — стала Больцмана, `T_pix = 300` К, `Δf` — ефективна смуга пропускання інтегратора ROIC (`Δf = 1 / (2 · t_int) ≈ 10` кГц за часу інтегрування `t_int = 50` мкс).

Для `R_pix = 50` кОм та `Δf = 10` кГц:

```
V_n_J
= √(4 · 1.380649 · 10⁻²³ · 300 · 50 · 10³ · 10⁴)
= √(8.2839 · 10⁻¹²)                                     [обчислення підкореневого виразу]
= 2.878 · 10⁻⁶ В (2.88 мкВ)                             [середньоквадратична напруга шуму Джонсона]
```

### 2. Шум теплових флуктуацій фононів (Phonon Exchange Noise)
Обумовлений статистичною дискретністю теплообміну між пікселем та підкладкою: тепло переноситься квантами коливань кристалічної ґратки — фононами. За флуктуаційно-дисипативною теоремою, середньоквадратична флуктуація теплового потоку дорівнює:

```
P_n_TF
= √(4 · k_B · T_pix² · G_th · Δf)                       [флуктуація теплового потоку фононного контакту]
```

Множачи цей тепловий шум на чутливість `R_v` і ділячи на поглинання `η`, отримуємо напругу шуму на виході:

```
V_n_TF
= (R_v / η) · √(4 · k_B · T_pix² · G_th · Δf)           [напруга шуму теплових флуктуацій]
```

Для `G_th = 5 · 10⁻⁸` Вт/К:

```
V_n_TF
= (2.125 · 10⁵ / 0.85) · √(4 · 1.380649 · 10⁻²³ · (300)² · 5 · 10⁻⁸ · 10⁴)
= (2.5 · 10⁵) · √(2.485 · 10⁻²¹)                        [обчислення підкореневого виразу]
= 2.5 · 10⁵ · 4.985 · 10⁻¹¹                             [множення на масштабний коефіцієнт]
= 1.246 · 10⁻⁶ В (1.25 мкВ)                             [напруга шуму фононних флуктуацій]
```

### 3. Радіаційний шум квантового фотонного фону (Photon Radiation Noise)
Фундаментальна термодинамічна межа для будь-якого теплового приймача, що виникає через дискретність та флуктуації випромінювання фотонів чорного тіла від сцени та самого детектора:

```
V_n_rad
= (R_v / η) · √(8 · σ · k_B · A_pix · (T_scene⁵ + T_pix⁵) · Δf) [квантовий шум фотонного фону]
```

де `σ = 5.670374 · 10⁻⁸` Вт/(м²·К⁴) — стала Стефана — Больцмана. Для неохолоджуваних мікроболометрів ця величина становить близько 0.15–0.25 мкВ, що суттєво менше за шум Джонсона.

### 4. Низькочастотний флікер-шум (1/f Noise)
Пов'язаний із випадковим захопленням носіїв заряду пастками на дефектах структури тонкої плівки:

```
V_n_1f
= √( (k_f · I_bias² · R_pix²) / f · Δf )                [емпіричний закон Хоуге для шуму 1/f]
```

В оксиду ванадію коефіцієнт `k_f` у 20–50 разів менший, ніж в аморфного кремнію, тому за імпульсного опитування цей шум додає не більше 0.8–1.2 мкВ.

Сумарний середньоквадратичний шум:

```
V_n_total
= √( (2.88)² + (1.25)² + (0.20)² + (1.00)² )
= √( 8.294 + 1.563 + 0.040 + 1.000 )                   [сума квадратів шумів]
= √( 10.897 )                                          [сумарна дисперсія]
= 3.30 мкВ                                             [повна шумова напруга каналу]
```

## Виведення формули NETD

Параметр **NETD** (англ. *Noise Equivalent Temperature Difference*) — це зміна температури чорного тіла сцени `ΔT_scene`, за якої корисний електричний сигнал дорівнює повному середньоквадратичному шуму (`SNR = 1`):

```
ΔV_sig = V_n_total
```

Оптична потужність інфрачервоного випромінювання, що збирається об'єктивом з площею вхідної зіниці на один піксель за діафрагмового числа `F#` та пропускання оптики `τ_opt`:

```
ΔP_rad
= (A_pix · τ_opt / (4 · F#² + 1)) · (dP / dT)_LWIR · ΔT_scene [збір променистого потоку апертурою лінзи]
≈ (A_pix · τ_opt / (4 · F#²)) · (dP / dT)_LWIR · ΔT_scene     [наближення для F# >= 1.0]
```

де `(dP/dT)_LWIR` — температурна похідна інтегральної світності чорного тіла в робочій смузі 8–14 мкм за температури 300 К:

```
(dP / dT)_LWIR
= ∫[8 мкм .. 14 мкм] (∂M_λ(λ, T) / ∂T) dλ
≈ 2.62 Вт / (м² · К)                                    [чисельний інтеграл закону Планка при 300 К]
```

Підставляючи сигнальну напругу `ΔV_sig = R_v · ΔP_rad` та прирівнюючи її до шуму `V_n_total`:

```
R_v · (A_pix · τ_opt / (4 · F#²)) · (dP / dT)_LWIR · NETD
= V_n_total                                             [умова відношення сигнал/шум = 1]
```

Звідси отримуємо класичну аналітичну формулу для NETD:

```
NETD
= (4 · F#² · V_n_total) / (A_pix · τ_opt · R_v · (dP / dT)_LWIR) [підсумкова аналітична формула NETD]
```

## Порівняльний аналіз поколінь матриць

Розрахуємо теоретичну та практичну межу NETD для різних технологічних поколінь мікроболометрів з оптикою `F/1.0` (`F# = 1.0`, `τ_opt = 0.90`):

| Крок пікселя | Площа `A_pix` (м²) | `G_th` (Вт/К) | `R_v` (В/Вт) | `V_n_total` | Теоретичний NETD |
|---|---|---|---|---|---|
| **25 мкм** | `6.25 · 10⁻¹⁰` | `1.0 · 10⁻⁷` | `1.1 · 10⁵` | 2.8 мкВ | **17.5 мК** |
| **17 мкм** | `2.89 · 10⁻¹⁰` | `5.0 · 10⁻⁸` | `2.1 · 10⁵` | 3.3 мкВ | **23.5 мК** |
| **12 мкм** | `1.44 · 10⁻¹⁰` | `3.0 · 10⁻⁸` | `3.5 · 10⁵` | 4.6 мкВ | **39.8 мК** |
| **8 мкм**  | `0.64 · 10⁻¹⁰` | `1.8 · 10⁻⁸` | `5.8 · 10⁵` | 6.8 мкВ | **79.5 мК** |

Цей розрахунок наочно демонструє головний фізичний виклик мікроболометричної технології: зі зменшенням розміру пікселя площа збору фотонів зменшується як квадрат лінійного розміру (`A_pix ∝ a²`). Щоб зберегти високу чутливість за кроку 12 мкм, інженерам доводиться створювати надтонкі мікроніжки складної змієподібної форми, наближаючи теплоізоляцію до граничних квантових меж.
