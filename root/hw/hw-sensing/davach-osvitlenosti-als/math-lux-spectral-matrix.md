# 🧮 Матрична спектральна компенсація ІЧ-завади в ALS

Розрахунок світлового потоку в люксах спирається на стандартизовану криву фотопічної чутливості людського ока V(λ), тоді як кремнієвий фотодіод інтегрує енергію всього оптичного діапазону аж до 1100 нм у ближньому інфрачервоному спектрі (NIR). Якщо вимірювати освітленість голим кремнієвим переходом, похибка від сонячного світла чи лампи розжарювання перевищує 400–900%. Щоб отримати справжнє значення люксів незалежно від колірної температури та спектрального складу джерела світла, інтегральні давачі освітленості (ALS) застосовують двоканальну оптичну архітектуру та матричне перетворення сигналів.

## Фотометрична база: від спектральної густини до люксів

Світловий потік, який сприймає людське око (фотометрична величина), пов'язаний з об'єктивною спектральною густиною потужності випромінювання Φ(λ) через функцію відносної спектральної світлової ефективності монопровідного зору CIE V(λ):

```
E_v = 683.002 · ∫ Φ(λ) · V(λ) dλ     [визначення освітленості в системі SI, люкс]
```

Тут 683.002 лм/Вт — максимальна світлова ефективність монохроматичного випромінювання на довжині хвилі 555 нм (зелений колір), де функція V(λ) досягає свого піка, рівного 1.0. За межами видимого діапазону (380–750 нм) функція V(λ) строго дорівнює нулю: людське око повністю сліпе до фотонів з довжиною хвилі понад 780 нм.

На противагу оку, квантова ефективність та спектральна чутливість кремнієвого p-n переходу R_si(λ) досягає максимальних значень у діапазоні 800–950 нм:

```
I_ph_naked = ∫ Φ(λ) · R_si(λ) dλ     [струм голого фотодіода від усього спектра]
```

Оскільки інтеграл для I_ph_naked містить потужну підінтегральну площу в діапазоні 750–1100 нм, будь-яке теплове джерело (лампа розжарювання, сонце, нагрівач) створює надлишковий струм, не пропорційний видимому світлу.

## Двоканальна модель: Visible та Infrared канали

Інтегральний ALS містить дві роздільні фотодіодні зони на одному кремнієвому кристалі:
1. **Канал CH0 (Visible + IR)**: перехід, перекритий інтерференційним фільтром, що частково пропускає видиме світло та має залишкове проникнення в ІЧ-області, зі спектральною характеристикою R₀(λ).
2. **Канал CH1 (IR Reference)**: перехід, закритий оптичним фільтром денного світла (чорний полімер або діелектричний фільтр), що відсікає фотони з λ < 700 нм і пропускає виключно інфрачервоний діапазон, зі спектральною характеристикою R₁(λ).

Цифрові коди обох каналів на виході АЦП давача записуються як лінійні згортки спектра джерела Φ(λ):

```
CH0 = k₀ · ∫ Φ(λ) · R₀(λ) dλ
CH1 = k₁ · ∫ Φ(λ) · R₁(λ) dλ
```

де k₀ та k₁ — коефіцієнти підсилення аналогового тракту та крутизни АЦП.

Розкладемо спектральну характеристику першого каналу R₀(λ) на суму цільової функції людського ока V(λ) та паразитного інфрачервоного хвоста R_ir(λ):

```
R₀(λ) = α · V(λ) + β · R_ir(λ)       [декомпозиція спектрального відгуку CH0]
```

Якщо характеристика інфрачервоного каналу R₁(λ) конструктивно оптимізована так, що її форма збігається з паразитною функцією R_ir(λ) з масштабним коефіцієнтом γ:

```
R₁(λ) = γ · R_ir(λ)                   [пропорційність форми ІЧ-відгуку]
```

тоді підставимо декомпозицію у вираз для коду CH0:

```
CH0 = k₀ · α · ∫ Φ(λ) · V(λ) dλ + k₀ · β · ∫ Φ(λ) · R_ir(λ) dλ
    = c_vis · E_v + c_ir · (CH1 / (k₁ · γ))
```

Звідси шукана освітленість E_v однозначно виражається через лінійну комбінацію двох виміряних цифрових каналів:

```
E_v = a · CH0 − b · CH1              [двоканальна лінійна компенсація ІЧ]
```

де коефіцієнти зв'язку визначаються параметрами напівпровідникової технології:

```
a = 1 / c_vis
b = (k₀ · β) / (c_vis · k₁ · γ)
```

## Кусково-лінійна апроксимація для реальних джерел світла

У реальних умовах паразитний спектральний відгук R₀(λ) не є ідеально пропорційним до R₁(λ) на всіх довжинах хвиль від 750 до 1100 нм через дифракційні та інтерференційні ефекти в тонких плівках. Крім того, спектральний розподіл різних типів освітлення суттєво різниться:

```
Ratio = CH1 / CH0                     [інфрачервоний спектральний індекс]
```

Співвідношення Ratio слугує прямим індикатором типу оптичного середовища:
- **Ratio ≤ 0.12**: білі світлодіоди (White LED), люмінесцентні лампи денного світла (CFL/CCFL) — випромінювання зосереджене суто у видимому спектрі, ІЧ-компонента практично відсутня;
- **0.12 < Ratio ≤ 0.45**: природне денне розсіяне світло, чисте небо, стандартні колориметричні джерела D50/D65;
- **0.45 < Ratio ≤ 0.70**: галогенні лампи, пряме низьке сонячне світло на світанку/заході;
- **0.70 < Ratio ≤ 0.85**: класичні лампи розжарювання з вольфрамовою ниткою (Illuminant A, T = 2856 K), де 90% потужності припадає на тепловий спектр;
- **Ratio > 0.85**: пряме сонячне випромінювання крізь оптичні світлофільтри або спрямоване інфрачервоне підсвічування (IR LED 850/940 нм).

Для досягнення похибки вимірювання менше 5% на всіх типах джерел загальна функція розрахунку розбивається на кусково-лінійні сегменти з індивідуальними калібрувальними коефіцієнтами:

```
E_v(Ratio) = 
  a₁ · CH0 − b₁ · CH1,   якщо 0.00 < Ratio ≤ 0.15   [LED / Люмінесцентні джерела]
  a₂ · CH0 − b₂ · CH1,   якщо 0.15 < Ratio ≤ 0.45   [Денне розсіяне світло]
  a₃ · CH0 − b₃ · CH1,   якщо 0.45 < Ratio ≤ 0.70   [Галогенні лампи]
  a₄ · CH0 − b₄ · CH1,   якщо 0.70 < Ratio ≤ 0.85   [Лампи розжарювання]
  0.0,                   якщо Ratio > 0.85           [Суто ІЧ-засвітка / темрява]
```

## Покроковий числовий приклад калібрування

Розглянемо калібрувальну матрицю реального сенсора зі статичними коефіцієнтами:

```
a₁ = 0.0450,   b₁ = 0.0200   (для Ratio ≤ 0.40)
a₂ = 0.0380,   b₂ = 0.0120   (для 0.40 < Ratio ≤ 0.65)
a₃ = 0.0270,   b₃ = 0.0080   (для 0.65 < Ratio ≤ 0.85)
```

**Випадок 1: Освітлення холодним світлодіодом (LED 6500 K)**
Сенсор зчитує відліки з 16-бітного АЦП:
- CH0 = 12 500 відліків
- CH1 = 450 відліків

Обчислюємо спектральне співвідношення та освітленість:

```
Ratio = CH1 / CH0
      = 450 / 12500
      = 0.0360                [значення < 0.40 → застосовуємо коефіцієнти a₁, b₁]

E_v = 0.0450 · 12500 − 0.0200 · 450
    = 562.5 − 9.0
    = 553.5 лк                [ІЧ-поправка складає лише 1.6%]
```

**Випадок 2: Освітлення лампою розжарювання 100 Вт (2700 K)**
Через величезну частку інфрачервоних фотонів той самий рівень видимої освітленості генерує зовсім інші сирі значення:
- CH0 = 24 800 відліків
- CH1 = 18 200 відліків

Обчислюємо:

```
Ratio = CH1 / CH0
      = 18200 / 24800
      = 0.7339                [0.65 < Ratio ≤ 0.85 → застосовуємо коефіцієнти a₃, b₃]

E_v = 0.0270 · 24800 − 0.0080 · 18200
    = 669.6 − 145.6
    = 524.0 лк                [ІЧ-компенсація зняла 145.6 лк паразитної засвітки]
```

Якби голий канал CH0 помножили на коефіцієнт світлодіода без віднімання ІЧ-каналу, результат становив би `24800 · 0.045 = 1116 лк` — похибка склала б понад +112%. Матричне віднімання повернуло значення до реальних 524 лк.

## Врахування спектрального затухання в захисному склі

Коли сенсор встановлено під захисне скло або тонований екран приладу з коефіцієнтом спектрального пропускання T_glass(λ), коди каналів модифікуються:

```
CH0_glass = ∫ Φ(λ) · T_glass(λ) · R₀(λ) dλ
CH1_glass = ∫ Φ(λ) · T_glass(λ) · R₁(λ) dλ
```

Оскільки тоноване чорнило (Dark Ink) майже завжди має вище пропускання в ІЧ-області (T_ir ≈ 40–80%), ніж у видимій (T_vis ≈ 5–15%), співвідношення Ratio під склом завжди зміщується вгору:

```
Ratio_glass = Ratio_air · (T_ir / T_vis)
```

Для коректного відновлення абсолютних люксів під склом застосовують трансформовану матрицю корекції:

```
E_v = (1 / T_vis) · (a_glass · CH0_glass − b_glass · CH1_glass)
```

де коефіцієнти `a_glass` та `b_glass` визначаються під час стендового фотометричного калібрування конкретної механічної збірки корпусу.
