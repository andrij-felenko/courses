Коли смартфон у кімнаті з увімкненою лампою розжарювання раптом викручує яскравість екрана на 100% і сліпить користувача в напівтемряві, причина криється не в збої операційної системи, а у фізиці напівпровідників. Звичайна лампа розжарювання потужністю 60 Вт випромінює лише 5% своєї енергії у вигляді видимого світла, а решту 95% викидає у вигляді невидимого інфрачервоного тепла (діапазон 750–2000 нм). Людське око цього тепла не бачить і сприймає освітленість на рівні помірних 80 люксів, проте голий кремнієвий фотодіод має пік власної чутливості саме біля 900 нм. Без спеціальних оптичних та схемотехнічних заходів кремній поглинає тепловий потік потужністю сотні мікроват і видає фотострум, еквівалентний 600–1000 люксам сонячного полудня. Для подолання цього розриву між людським сприйняттям і кремнієвою фізикою створено **інтегральний давач освітленості** (англ. *Ambient Light Sensor*, скор. ALS, від лат. *ambiens* — навколишній).

![Спектральна чутливість кремнію порівняно з кривою людського зору CIE V(λ)](/root/hw/hw-sensing/davach-osvitlenosti-als/img/fig-als-spectral-response.svg)
*Спектральна невідповідність кремнію та людського зору. Зелена крива — стандартизована функція фотопічної чутливості людського ока CIE V(λ) з піком на 555 нм, яка повністю спадає до нуля на 750 нм. Пунктирна сіра лінія — власний відгук кремнієвого фотодіода (Si), що має максимум біля 900 нм і тягнеться до 1100 нм. Штрихова помаранчева крива — інфрачервоний опорний канал ALS (CH1), призначений для матричного віднімання теплової завади.*

## Парадокс кремнієвого зору: спектральна функція V(λ)

Світло як об'єктивне фізичне явище характеризується спектральною густиною енергетичної потужності випромінювання (радіометрична величина, Вт/м² на нанометр). Проте людина бачить світ не радіометром, а оком, сітківка якого містить світлочутливі колбочки трьох типів. Уніфікований відгук денного зору стандартизований Міжнародною комісією з освітлення (CIE) як крива **фотопічної ефективності** `V(λ)`. Вона обмежена вузьким «вікном життя» від 380 до 750 нм з піком на довжині хвилі 555 нм (жовто-зелена ділянка спектра), де 1 Вт оптичної потужності створює рівно 683.002 люмена світлового потоку.

Кремнієвий фотодіод працює за іншим законом: ширина його забороненої зони становить приблизно 1.12 еВ за кімнатної температури. Фотон здатний вибити пару електрон-дірка за умови, що його довжина хвилі коротша за фундаментальну межу поглинання:

```
λ_max = h · c / E_g ≈ 1240 / 1.12 ≈ 1107 нм    [червона межа кремнію]
```

Це означає, що кремній «бачить» не лише все видиме світло, але й увесь ближній інфрачервоний діапазон (NIR, 750–1100 нм). Ба більше, глибина проникнення світла в кремній зростає зі збільшенням довжини хвилі: якщо синє світло (450 нм) поглинається у тонкому приповерхневому шарі завтовшки 0.5–1 мкм, то інфрачервоні фотони (900 нм) проникають на глибину до 30–50 мкм, генеруючи носії глибоко в об'ємі напівпровідника з максимальною квантовою ефективністю.

Якщо такий фотодіод висвітлити сонцем або галогенною лампою, сумарний фотострум складатиметься з малого корисного струму видимого світла та велетенського паразитного струму інфрачервоної складової. Спроба розрахувати фотометричну освітленість `E_v` (у люксах) за формулою прямої пропорційності `E_v = k · I_ph` призводить до катастрофічних похибок залежно від спектра джерела:

```
Холодний білий світлодіод (LED 6500 K): похибка +5% ... +15%
Денне сонячне світло (D65):            похибка +80% ... +150%
Лампа розжарювання (2700 K):           похибка +400% ... +900%
```

Один і той самий рівень у 100 люксів від світлодіода та лампи розжарювання дає на голому кремнії десятикратну різницю струму. Справжній ALS покликаний усунути цей парадокс.

> 🔧 **Навіщо це.** Автоматичне керування яскравістю дисплеїв телевізорів, ноутбуків, автомобільних приладових панелей та смартфонів вимагає точного відповідника людському оку. Якщо датчик реагує на інфрачервоне випромінювання нагрівачів чи сонця, екран переходить на надмірну яскравість, перегріваючи акумулятор і викликаючи зорову втому. У фотоапаратах ALS оцінює колірну температуру навколишнього освітлення для правильного автобалансу білого (AWB) до відкриття основного затвора.

## Двоканальна архітектура: математичне відсікання ІЧ-завади

Найпростіша інженерна ідея — нанести на кремній пасивний оптичний фільтр, який фізично блокує хвилі довше 700 нм (інтерференційне скло IR-Cut). Проте в інтегральному виконанні один апаратний фільтр не дає надійної відповіді:
1. **Кутовий зсув (Blue Shift)**: інтерференційні діелектричні шари змінюють смугу пропускання залежно від кута падіння променя світла. При відхиленні на 45° смуга зрізу зсувається вліво на 30–50 нм, «зрізаючи» червону частину видимого спектра.
2. **Технологічний розкид**: товщина напилених шарів на пластині варіюється, що робить край смуги зрізу розмитим.
3. **Висока ціна**: нанесення якісного 40-шарового діелектричного фільтра поверх КМОН-структури різко збільшує вартість кристала.

Сучасні інтегральні ALS (наприклад, серії OPT3001 від Texas Instruments, VEML7700 від Vishay або TMD2772 від ams OSRAM) вирішують завдання за допомогою **двоканальної топології** з різними оптичними смугами пропускання на одному кристалі.

![Матрична компенсація ІЧ-завади для джерел світла з різною колірною температурою](/root/hw/hw-sensing/davach-osvitlenosti-als/img/fig-dual-channel-compensation.svg)
*Принцип двоканальної компенсації ІЧ-складової. Зліва — холодне світлодіодне освітлення без ІЧ, де відгук каналу CH1 близький до нуля. Посередині — лампа розжарювання з велетенським інфрачервоним фоном: сирий відгук CH0 у 4.5 рази вищий, але високе значення CH1 дозволяє матричному алгоритму точно відняти паразитно накопичений заряд і повернути правильні 99 люксів. Справа — сонячний спектр. Знизу наведено узагальнене рівняння лінійної компенсації.*

На кристалі розміщують два окремих напівпровідникових фотодіоди:
- **Канал CH0 (Visible + IR)**: діод, накритий просвітленим шаром або напівшироким фільтром. Він реєструє фотони як видимої зони (380–750 нм), так і інфрачервоної (750–1050 нм).
- **Канал CH1 (IR Reference)**: діод, покритий темним полімерним барвником або кремнієвим фільтром денного світла, який непрозорий для видимого світла (пропускання < 1% нижче 700 нм), але повністю прозорий для ближнього інфрачервоного спектра (720–1100 нм).

Струм кожного каналу перетворюється на цифровий код за допомогою внутрішнього АЦП. Оскільки вихідний сигнал каналу `CH1` містить інформацію виключно про інфрачервону енергію джерела, корисна видима освітленість `E_v` обчислюється шляхом матричного віднімання:

```
E_v = a · CH0 − b · CH1    [базова формула двоканального ALS]
```

Тут коефіцієнт `a` нормує чутливість каналу CH0 до видимого світла, а коефіцієнт `b` масштабує ІЧ-відгук каналу CH1 відповідно до паразитного інфрачервоного коефіцієнта каналу CH0.

Для різних джерел світла спектральне співвідношення `Ratio = CH1 / CH0` слугує автоматичним маркером типу освітлення:
- Для світлодіодів `Ratio ≈ 0.01 ... 0.10` (ІЧ майже немає, віднімання мінімальне);
- Для денного світла `Ratio ≈ 0.20 ... 0.45`;
- Для ламп розжарювання та галогену `Ratio ≈ 0.60 ... 0.85` (віднімання максимальне).

Детальний математичний апарат розрахунку коефіцієнтів та кусково-лінійної апроксимації для різних спектрів розібрано у [виведенні матричної моделі спектральної компенсації](root:hw-sensing/davach-osvitlenosti-als/math-lux-spectral-matrix.md).

## Внутрішня схемотехніка: від фотоструму до цифрового відліку

Щоб реалізувати високу точність і стабільність вимірювання на одному кристалі площею менше ніж 2 мм², інтегральний ALS поєднує спеціалізовану оптичну топологію, прецизійний аналоговий фронтенд (AFE) та цифровий сигнальний процесор керування.

![Внутрішня структурна схема інтегрального цифрового давача освітленості](/root/hw/hw-sensing/davach-osvitlenosti-als/img/fig-als-internal-architecture.svg)
*Повний тракт інтегрального ALS: зліва направо — фотодіодні структури CH0, CH1 та темновий діод; аналоговий комутатор MUX; підсилювач із керованим коефіцієнтом PGA Gain та аналоговий інтегратор заряду; сигма-дельта АЦП; цифровий блок обробки з кінцевим автоматом FSM і блоком детектування мерехтіння Flicker Engine; регістровий масив та інтерфейс I2C з виводом переривання INT.*

### 1. Фотодіодна матриця з центрально-симетричною структурою
Точковий фотодіод схильний до локальних неоднорідностей кристала та нерівномірного градієнта освітленості, якщо падаючий промінь світла перекривається краєм корпусу або мікротріщиною скла. Тому кожен канал (CH0 і CH1) формується не як один суцільний p-n перехід, а як розбитий на десятки дрібних осередків шаховий масив (Interdigitated Centroid Matrix). Осередки обох каналів чергуються у просторі кристала, гарантуючи, що середня освітленість, просторовий розподіл тіней та температурний градієнт впливають на обидва канали однаково.

Поруч розташовується **темновий фотодіод (Dark Reference)**. Це абсолютно ідентичний p-n перехід, проте повністю накритий товстим шаром верхньої металізації кристала (алюміній або мідь). Фотони крізь метал не проникають, тож цей діод генерує виключно темновий струм теплової генерації `I_dark(T)`. В аналоговому або цифровому тракті цей струм віднімається з сигналів CH0 та CH1, знімаючи температурний дрейф нуля за високих температур (до 85–105 °C).

### 2. Аналоговий тракт: інтегрування заряду проти миттєвого TIA
У класичних схемах перетворення струму фотодіода використовують трансімпедансний підсилювач (TIA). Проте для вимірювання інтегральної освітленості TIA має два недоліки: шум зворотного зв'язку резистора `4·k_B·T·R` та миттєва чутливість до високочастотного оптичного шуму.

Сучасні ALS використовують **імпульсний інтегратор заряду на перемикальних конденсаторах (Switched-Capacitor Charge Integrator)** або керований струмом сигма-дельта модулятор. Замість вимірювання миттєвого струму схема накопичує заряд `Q = ∫ I_ph(t) dt` на каліброваному внутрішньому конденсаторі `C_int` протягом заданого інтервалу часу `T_int`:

```
U_out(T_int) = (1 / C_int) · ∫₀^{T_int} I_ph(t) dt    [інтеграл фотоструму]
```

Цей підхід має дві ключові переваги:
1. **Ідеальне усереднення**: короткочасні шуми, наводки від ліній зв'язку та випадкові фотонні флуктуації Пуассона інтегруються й пригнічуються.
2. **Лінійне масштабування чутливості**: збільшуючи час накопичення заряду `T_int` у 10 разів, ми в 10 разів збільшуємо вихідну напругу з того самого слабкого фотоструму без введення шумних надвисокоомних резисторів.

Коефіцієнт підсилення вхідного каскаду регулюється програмованим підсилювачем (PGA Gain) шляхом зміни ємності матриці `C_int` за допомогою КМОН-ключів (типово від 1x до 128x).

### 3. Інтегруючий АЦП високої роздільної здатності
Після інтегратора сигнал оцифровується за допомогою сигма-дельта (Σ-Δ) АЦП або АЦП подвійного інтегрування (Dual-Slope ADC) з роздільною здатністю 16–24 біти. Завдяки високій розрядності інтегральний ALS здатний оцифровувати фотоструми від десятків пікоампер (0.01 лк) до сотень мікроампер (100 000 лк).

## Підкорення динамічного діапазону: від 0.01 лк до 120 000 лк

Діапазон освітленості, з яким працює людина в повсякденному житті, охоплює колосальні 7 порядків величини (140 dB):
- Безмісячна ніч / зоряне небо: `0.001 – 0.02 лк`;
- Житлова кімната у сутінках: `5 – 50 лк`;
- Освітлений сучасний офіс: `300 – 750 лк`;
- Похмурий день на вулиці: `1 000 – 5 000 лк`;
- Пряме сонце в полудень у горах або на снігу: `100 000 – 130 000 лк`.

Стандартний 16-бітний АЦП з фіксованим коефіцієнтом підсилення має теоретичний динамічний діапазон `20·log₁₀(65535) ≈ 96.3 dB`. Якщо налаштувати шкалу так, щоб максимальний відлік (65535) відповідав прямому сонцю 130 000 лк, ціна одного молодшого розряду (LSB) становитиме:

```
LSB_фікс = 130000 / 65535 ≈ 1.98 лк / відлік
```

За такої шкали нічне або сутінкове світло 0.1–1.0 лк просто зникне в шумі квантування і дасть нуль відліків АЦП. Автопідсвітка нічника чи смартфона вночі повністю вийде з ладу.

![Охоплення динамічного діапазону 100+ dB через конфігурацію PGA Gain та T_int](/root/hw/hw-sensing/davach-osvitlenosti-als/img/fig-dynamic-range-pga-tint.svg)
*Конфігураційна карта охоплення динамічного діапазону. За рахунок перемикання коефіцієнта підсилення вхідного каскаду PGA Gain (від 1/4x до 128x) та часу інтегрування T_int (від 12.5 мс до 800 мс) крок квантування LSB змінюється від 0.0014 лк (у темряві) до 6.14 лк (на яскравому сонці), покриваючи діапазон понад 160 dB без розширення фізичної розрядності АЦП.*

Для охоплення всього діапазону ALS використовує динамічне комбінування двох параметрів:
1. **Аналоговий коефіцієнт підсилення (PGA Gain)**: `1x, 2x, 4x, 8x, 16x, 32x, 64x, 128x` (змінює коефіцієнт передачі струм/заряд);
2. **Час інтегрування (T_int)**: `12.5 мс, 25 мс, 50 мс, 100 мс, 200 мс, 400 мс, 800 мс` (змінює час накопичення фотонів).

Повна формульна залежність перерахунку сирого відліку АЦП (`RAW`) в абсолютні люкси записується як:

```
E_v = RAW · (LSB_base / (Gain · (T_int / T_ref))) · K_glass
```

де `LSB_base` — базова чутливість давача для одиничного підсилення `Gain = 1.0` та базового часу `T_ref = 100 мс`, а `K_glass` — поправочний коефіцієнт оптичного затухання в захисному склі.

У сучасних мікросхемах, таких як OPT3001, розробники пішли ще далі, реалізувавши внутрішнє логарифмічне стиснення даних на апаратному рівні: вихідний 16-бітний регістр містить 4 біти експоненти `E[3:0]` (фактично діапазон підсилення PGA від 0 до 11) та 12 бітів мантиси `R[11:0]`:

```
E_v = 0.01 · 2^{E[3:0]} · R[11:0]    [формат даних з плаваючою комою OPT3001]
```

Такий формат дозволяє одному регістру представляти значення від 0.01 лк (`E=0, R=1 → 0.01 лк`) до 83 865 лк (`E=11, R=4095 → 83 865.6 лк`) з постійною відносною роздільною здатністю без потреби ручного перемикання регістрів.

## Детектування та фільтрація мерехтіння (Flicker 100/120 Гц)

Майже все штучне освітлення навколо нас мерехтить:
- Лампи розжарювання та люмінесцентні трубки пульсують на подвоєній частоті електромережі: **100 Гц** у країнах Європи (мережа 50 Гц) та **120 Гц** у Північній Америці (мережа 60 Гц);
- Дешеві світлодіодні лампи без якісного стабілізатора струму пульсують зі 100% глибиною модуляції на тій самій частоті 100/120 Гц;
- Екрани моніторів та LED-панелі регулюють яскравість за допомогою широтно-імпульсної модуляції (ШІМ) на частотах від 200 Гц до десятків кілогерців.

Якщо час експозиції сенсора або АЦП обрано довільно (наприклад, випадковий інтервал 13.5 мс), відлік залежатиме від того, на яку фазу півперіоду синусоїди мережі припав замір. Різниця між сусідніми вимірюваннями при абсолютно незмінному рівні світла в кімнаті може досягати ±20–40%, що спричиняє видиме тремтіння підсвітки екрана.

![Придушення мерехтіння 100/120 Гц вибором часу інтегрування T_int](/root/hw/hw-sensing/davach-osvitlenosti-als/img/fig-flicker-and-integration.svg)
*Механізм придушення пульсацій штучного освітлення. Зліва: синусоїдальний струм із частотою пульсацій 100 Гц. Якщо інтегрувати його протягом випадкового інтервалу (13 мс), результат коливається залежно від фази запуску. Якщо інтегрувати рівно 100 мс (10 цілих періодів), інтеграл змінного сигналу строго дорівнює нулю. Справа: частотна характеристика |H(f)| = |sinc(π·f·T_int)|, що демонструє глибокі нулі придушення на частотах 50, 100, 150 та 200 Гц.*

### Математика антифлікерного вікна

Передавальна характеристика аналогового або цифрового інтегратора у часовій області описується прямокутним вікном шириною `T_int`. Переходячи до частотної області за допомогою перетворення Фур'є, отримуємо амплітудно-частотну характеристику у вигляді функції `sinc`:

```
H(f) = ∫₀^{T_int} e^{-j 2π f t} dt = T_int · \frac{\sin(π f T_int)}{π f T_int} · e^{-j π f T_int}
|H(f)| = T_int · |sinc(π · f · T_int)|
```

Амплітуда повністю падає в нуль (`|H(f)| = 0`) на всіх частотах, для яких виконується умова:

```
f_null = k / T_int     [де k = 1, 2, 3, ...]
```

Звідси випливає фундаментальне інженерне правило вибору часу інтегрування ALS:
- Щоб придушити пульсації **100 Гц** (і гармоніки 200, 300 Гц), час `T_int` має бути кратним періоду `T = 1 / 100 Гц = 10 мс`: підходять 50 мс, 100 мс, 200 мс, 400 мс.
- Щоб придушити пульсації **120 Гц** (і гармоніки 240, 360 Гц), час `T_int` має бути кратним періоду `T = 1 / 120 Гц ≈ 8.333 мс`: підходять 50 мс, 100 мс, 200 мс.
- **Універсальний вибір для обох мереж**: інтервал **`T_int = 100 мс`** є найменшим спільним кратним для 10 мс (рівно 10 повних періодів) та 8.333 мс (рівно 12 повних періодів).

При виборі `T_int = 100 мс` інтегральний ALS забезпечує апаратне придушення завади від мереж 50 Гц та 60 Гц на рівні **понад 60–80 dB**, виключаючи будь-яке тремтіння фотометричного коду.

### Апаратний Flicker Engine для камер

У сучасних смартфонах та цифрових камерах ALS виконує додаткову роль — детектора мерехтіння для оптимізації основного сенсора зображення. Коли камера з рухомою електронною заслінкою ([rolling shutter](root:hw-sensing/rolling-shutter)) записує відео у приміщенні з мерехтливим світлом, на зображенні з'являються темні й світлі горизонтальні смуги, що пливуть екраном (Flicker Banding Artifacts).

Для боротьби з цим ефектом просунуті ALS (наприклад, серії ams TMD3725 / TMD3719) містять окремий паралельний високошвидкісний тракт дискретизації:
1. Сигнал опитується з частотою 1–2 кГц без тривалого інтегрування.
2. Вбудований апаратний DSP виконує швидке перетворення Фур'є (FFT) або лічбу нуль-переходів.
3. Давач виставляє у статусному регістрі прапорці: `Flicker_100Hz_Detected`, `Flicker_120Hz_Detected` або точну частоту ШІМ дисплея (до 8 кГц).
4. Процесор обробки зображення (ISP) підлаштовує час витримки матриці камери (експозицію), роблячи її кратною періоду пульсацій, що повністю ліквідує смуги на знімках і відео.

## Оптична та механічна інтеграція: затухання скла, FOV та Cross-Talk

У реальному виробі сенсор ніколи не стоїть відкритим назовні. Він захований під захисним склом корпусу (Gorilla Glass, сапфір, полікарбонат), часто вкритим декоративним або затемненим чорнилом для збереження естетичного вигляду приладу.

![Оптичний стек: затухання у склі, кут зору (FOV) та паразитна перехресна завада](/root/hw/hw-sensing/davach-osvitlenosti-als/img/fig-glass-attenuation-stack.svg)
*Оптичний стек механічної інтеграції. Верхній шар — скло з тонуванням і маскувальним чорнилом, у якому виконано апертуру. Посередині — повітряний зазор і кутовий конус огляду FOV. Світло від розташованого на тій самій платі OLED-пікселя чи інфрачервоного діода наближення відбивається від внутрішніх граней скла (Cross-talk). Гумовий оптичний бар'єр (Gasket) блокує паразити й направляє на ALS лише зовнішній світловий конус.*

### 1. Коефіцієнт оптичного затухання скла (Glass Attenuation Factor)
Прозоре скло з антивідблисковим покриттям послаблює видиме світло приблизно на 8–12% (пропускання `T_glass ≈ 88–92%`). Проте якщо сенсор заховано під затемнену рамку смартфона або під матрицю екрана (Under-Display ALS), на скло наносять напівпрозоре чорнило. Таке чорнило пропускає лише **5–15% видимого світла**, а решту 85–95% поглинає чи відбиває.

Для компенсації втрат світла у формулу розрахунку вводиться поправочний коефіцієнт затухання:

```
K_glass = 1 / T_glass    [коефіцієнт посилення для скла]
```

Якщо скло пропускає лише 10% світла (`T_glass = 0.10`), коефіцієнт `K_glass = 10.0`. Це висуває екстремальні вимоги до власного шуму сенсора: щоб зафіксувати 1 люкс у кімнаті крізь 10%-ве скло, давач на кристалі повинен надійно оцифрувати рівень у **0.1 люкса**.

Крім того, більшість тонувальних чорнил мають суттєву спектральну нерівномірність: вони інтенсивно блокують синє й зелене світло, але майже прозорі для ближнього інфрачервоного діапазону (пропускання в ІЧ досягає 60–80%). Це різко змінює спектральне співвідношення `Ratio = CH1 / CH0` і вимагає проведення повної калібрувальної процедури коефіцієнтів матриці безпосередньо у зібраному корпусі приладу.

### 2. Геометрія оптичного конуса та поле зору (Field of View, FOV)
Людське око сприймає світло у напівсфері з кутом зору майже 180°. Інтегральний давач під отвором у склі бачить світло лише всередині обмеженого конуса:

```
\tan(θ_half) = \frac{D_aperture}{2 · (H_air + H_glass / n_glass)}
```

де `D_aperture` — діаметр отвору в маскувальному шарі чорнила, `H_air` — висота повітряного проміжку між платою та склом, `H_glass` — товщина скла, `n_glass ≈ 1.51` — показник заломлення скла.

Якщо повітряний проміжок занадто великий (`H_air > 1.0 мм`), кут зору звужується до ±25–30°. Тоді давач реагує лише на ліхтарі, що світять строго зенітно над ним, і повністю «ігнорує» бічне освітлення від вікна. Для забезпечення комфортного кута огляду `FOV ≥ ±50°` дотримуються жорстких правил проектування:
- Повітряний зазор `H_air` мінімізують до величини менше ніж 0.5–0.8 мм;
- Діаметр апертури обирають не менше 1.5–2.0 мм;
- Внутрішні стінки посадкового колодязя фарбують у матовий чорний колір для виключення паразитного відблиску.

### 3. Оптичний перехресний зв'язок (Optical Cross-Talk)
Найнебезпечніша інженерна пастка виникає тоді, коли поруч з ALS на тій самій платі встановлено інфрачервоний випромінювач (наприклад, IR LED оптичного давача наближення Proximity Sensor для блокування екрана біля вуха) або пікселі OLED-дисплея.

Світло від випромінювача потрапляє у товщу скла, зазнає багаторазового повного внутрішнього відбиття між верхньою та нижньою гранями скляної пластини і потрапляє у світлоприймальну апертуру ALS. В результаті ALS вимірює потужне паразитне світло власного приладу.

Для ліквідації перехресного зв'язку між випромінювачем і приймачем обов'язково встановлюють суцільний непрозорий оптичний бар'єр — **еластичний ущільнювач (Rubber Boot / Silicone Light Guide Gasket)**. Він щільно притискається до нижньої поверхні захисного скла, оптично ізолюючи світловий канал ALS від решти електронних компонентів приладу.

## Архітектура драйвера та алгоритм автовибору діапазону

Опитування інтегрального ALS вимагає реалізації асинхронного кінцевого автомата (FSM), який керує вибором діапазонів чутливості без зависання у насиченні (clipping) та без періодичного брязкоту підсилення на межах порогів (gain thrashing).

Наївна реалізація, яка перемикає діапазон на кожен відлік, зазнає краху при першому ж стрибку яскравості. Якщо відбувся спалах світла, АЦП входить у насичення (`RAW = 65535`), а розраховане значення фіксується на хибному рівні. 

Правильний алгоритм автовибору діапазону реалізує наступну логіку:
1. Якщо `RAW > 85% FullScale` (або виставлено біт переповнення `OVF`), коефіцієнт `PGA Gain` знижується, або час `T_int` зменшується, після чого новий цикл вимірювання перезапускається.
2. Якщо `RAW < 10% FullScale`, коефіцієнт `PGA Gain` або час `T_int` підвищуються для покращення роздільної здатності.
3. Між нижнім (10%) та верхнім (85%) порогами діє захисна зона гістерезису, яка виключає безперервне перемикання діапазонів при повільних коливаннях світла.

Нижче наведено компактний приклад реалізації автовибору шкали мовами C та C++:

```c
#include <stdint.h>
#include <stdbool.h>

typedef struct {
    uint8_t gain_idx;      /* 0: 1x, 1: 4x, 2: 16x, 3: 128x */
    uint8_t tint_idx;      /* 0: 50ms, 1: 100ms, 2: 400ms */
    float glass_factor;    /* Коефіцієнт скла K_glass */
} als_state_t;

static const float GAINS[4] = {1.0f, 4.0f, 16.0f, 128.0f};
static const float TINTS[3] = {0.5f, 1.0f, 4.0f};

/* Адаптивне оновлення підсилення з гістерезисом */
bool als_update_range(als_state_t *st, uint16_t ch0_raw, bool overflow) {
    bool reconfigure = false;
    if (overflow || ch0_raw > 55705) { /* > 85% від 65535 */
        if (st->gain_idx > 0) {
            st->gain_idx--;
            reconfigure = true;
        } else if (st->tint_idx > 0) {
            st->tint_idx--;
            reconfigure = true;
        }
    } else if (ch0_raw < 6553) {       /* < 10% від 65535 */
        if (st->gain_idx < 3) {
            st->gain_idx++;
            reconfigure = true;
        } else if (st->tint_idx < 2) {
            st->tint_idx++;
            reconfigure = true;
        }
    }
    return reconfigure;
}

/* Обчислення абсолютних люксів */
float als_get_lux(const als_state_t *st, uint16_t ch0, uint16_t ch1) {
    if (ch0 == 0) return 0.0f;
    float ratio = (float)ch1 / (float)ch0;
    float a = 1.0f, b = 1.8f;
    if (ratio <= 0.20f) { a = 1.0f; b = 0.5f; }
    else if (ratio <= 0.60f) { a = 1.0f; b = 1.3f; }
    
    float net = a * (float)ch0 - b * (float)ch1;
    if (net < 0.0f) net = 0.0f;
    
    float lsb = (0.096f / (GAINS[st->gain_idx] * TINTS[st->tint_idx])) * st->glass_factor;
    return net * lsb;
}
```

```cpp
#include <cstdint>
#include <array>
#include <algorithm>

class AmbientLightSensor {
public:
    explicit constexpr AmbientLightSensor(float glass_factor = 1.0f) noexcept
        : glass_factor_{std::max(1.0f, glass_factor)} {}

    [[nodiscard]] bool update_range(std::uint16_t ch0_raw, bool overflow) noexcept {
        bool reconfigure = false;
        if (overflow || ch0_raw > HIGH_THRESHOLD) {
            if (gain_idx_ > 0) {
                --gain_idx_;
                reconfigure = true;
            } else if (tint_idx_ > 0) {
                --tint_idx_;
                reconfigure = true;
            }
        } else if (ch0_raw < LOW_THRESHOLD) {
            if (gain_idx_ < GAINS.size() - 1) {
                ++gain_idx_;
                reconfigure = true;
            } else if (tint_idx_ < TINTS.size() - 1) {
                ++tint_idx_;
                reconfigure = true;
            }
        }
        return reconfigure;
    }

    [[nodiscard]] constexpr float calculate_lux(std::uint16_t ch0, std::uint16_t ch1) const noexcept {
        if (ch0 == 0) return 0.0f;
        const float ratio = static_cast<float>(ch1) / static_cast<float>(ch0);
        float a = 1.0f, b = 1.8f;
        if (ratio <= 0.20f) { a = 1.0f; b = 0.5f; }
        else if (ratio <= 0.60f) { a = 1.0f; b = 1.3f; }

        const float net = std::max(0.0f, a * static_cast<float>(ch0) - b * static_cast<float>(ch1));
        const float lsb = (BASE_LSB / (GAINS[gain_idx_] * TINTS[tint_idx_])) * glass_factor_;
        return net * lsb;
    }

private:
    static constexpr std::uint16_t LOW_THRESHOLD  = 6553;
    static constexpr std::uint16_t HIGH_THRESHOLD = 55705;
    static constexpr float BASE_LSB               = 0.096f;

    static constexpr std::array<float, 4> GAINS = {1.0f, 4.0f, 16.0f, 128.0f};
    static constexpr std::array<float, 3> TINTS = {0.5f, 1.0f, 4.0f};

    std::size_t gain_idx_{1};
    std::size_t tint_idx_{1};
    float glass_factor_{1.0f};
};
```

## Інженерний вибір та практичні рекомендації

При виборі та проектуванні вузла вимірювання освітленості інженер керується наступним алгоритмом:
1. **Аналіз спектрального оточення**: якщо прилад працюватиме під прямим сонцем або під галогенними лампами, використання простих одноканальних кремнієвих фотодіодів заборонене — обов'язковий вибір двоканального ALS або мікросхеми з прецизійним інтерференційним фільтром V(λ) (наприклад, OPT3001).
2. **Оцінка оптичного скла**: під темне скло (пропускання < 10%) обирають мікросхеми з еквівалентною роздільною здатністю не гірше 0.005 лк/LSB (наприклад, VEML7700), щоб компенсувати десятикратне падіння світлового потоку без втрати чутливості вночі.
3. **Вибір часу інтегрування**: для стаціонарних приладів за замовчуванням встановлюють `T_int = 100 мс`, що гарантує повне апаратне пригнічення пульсацій 100 Гц та 120 Гц від освітлювальної мережі без використання ресурсомістких програмних цифрових фільтрів.
4. **Механічний бар'єр**: у комбінованих приладах з датчиками наближення чи сусідніми індикаторами обов'язковим є встановлення силіконового оптичного ущільнювача (gasket) для ліквідації паразитного перехресного засвічення крізь товщу захисного скла.
