# Приймач із програмною обробкою (SDR) як прилад

<preknowlist>
- [Змішувач частот](root:hw-analog/mixer) — нелінійне перемноження ВЧ-сигналу та коливань гетеродина для зсуву спектра.
- [Малошумний підсилювач](root:hw-analog/lna-low-noise-amplifier) — первинне підсилення слабкого вхідного сигналу з мінімальним внеском власного шуму.
- [Zero-IF та Low-IF архітектури](root:hw-analog/zero-if-receiver) — квадратурне пряме перетворення радіочастоти на нульову або низьку проміжну частоту.
- [Швидке перетворення Фур'є](root:com-signal/fft) — розкладання дискретного часового сигналу на ортогональний частотний базис.
- [Динамічний діапазон і шуми](root:hw-sensing/dynamic-range-noise) — межі чутливості, теплове шумове дно та лінійність вимірювального тракту.
</preknowlist>

Класичний супергетеродинний аналізатор спектра сканує частотний діапазон послідовно: аналоговий гетеродин плавно перелаштовується, переносить окремі ділянки смуги на фіксований вузькосмуговий проміжний фільтр, а піковий детектор формує амплітудну огинаючу на екрані. Якщо в досліджуваному діапазоні виникає короткочасний радіоімпульс тривалістю кілька мікросекунд у момент, коли сканувальний фільтр перебуває в іншій частині спектра, аналізатор пропускає подію повністю.

Програмно-визначене радіо (англ. *Software-Defined Radio*, SDR) усуває механічні та аналогові обмеження сканування: широкосмуговий аналоговий фронтенд оцифровує неперервний вектор напруги у смузі десятків або сотень мегагерців одночасно, переносячи всі подальші операції фільтрації, демодуляції, спектрального розкладу та вимірювання потужності в цифрову область процесора, ПЛІС або сигнального процесора (DSP).

![Архітектура вимірювального SDR-приймача](/root/hw/hw-sensing/pryimach-iz-prohramnoiu-obrobkoiu-sdr-iak-prylad/img/sdr-instrument-arch.svg)
*Тракт вимірювального SDR: аналогова нормалізація сигналу, квадратурний поділ на синфазну I та квадратурну Q складові, оцифрування синхронними АЦП і цифрова обробка потоку.*

## 1. Архітектура вимірювального тракту: від антени до цифрових відліків

Перетворення SDR зі звичайного приймача бездротового зв'язку на метрологічний вимірювальний прилад вимагає строгої каліброваності аналогового тракту, стабільності опорного генератора та високої лінійності перетворення у широкому діапазоні амплітуд.

### Вхідне коло: атенюація та преселекція

Радіочастотний сигнал надходить на вхідний коаксіальний роз'єм із хвильовим опором `50 Ом`. Першою ланкою вимірювального тракту є прецизійний цифровий ступінчастий атенюатор (лат. *attenuare* — зменшувати):

```
K_att = 0 .. 31.5 dB (із кроком 0.5 dB)
```

Атенюатор виконує дві критичні функції: захищає чутливий вхід від перевантаження та забезпечує стабільний коефіцієнт відбиття (коефіцієнт стоячої хвилі за напругою, КСХН ≤ 1.2), запобігаючи спотворенню амплітуди через стоячі хвилі у вхідному кабелі.

Після атенюатора сигнал проходить через блок преселекторних смугових фільтрів (англ. *preselector filters*). Преселекція відсікає потужні завади поза робочою смугою огляду, які інакше перевантажили б малошумний підсилювач або викликали появу паразитних комбінаційних частот на змішувачі.

### Малошумне підсилення (LNA) та шумові каскади

Для виявлення сигналів мікровольтового рівня сигнал підсилюється малошумним підсилювачем (англ. *Low-Noise Amplifier*, LNA). Коефіцієнт шуму першого підсилювача `NF_LNA` згідно з формулою Гаральда Фрііса (англ. *Friis formula for noise*) визначає загальну чутливість усього приймального комплексу:

```
F_total = F₁ + (F₂ - 1) / G₁ + (F₃ - 1) / (G₁ · G₂)    [формула Фрііса для шуму каскадів]
```

де `F` — лінійний фактор шуму (`NF = 10 · log₁₀(F)`), а `G` — коефіцієнт підсилення каскаду за потужністю.

Якщо перший каскад має високий коефіцієнт підсилення `G₁` (наприклад, 18 dB, тобто 63.1 рази за потужністю) та малий коефіцієнт шуму `NF₁ = 1.2 dB` (`F₁ = 1.32`), то шумові внески наступних змішувачів і АЦП діляться на `G₁` і стають другорядними. Проте надмірне підсилення зменшує верхню межу динамічного діапазону: підсилювач раніше заходить у режим насичення та компресії коефіцієнта передачі (`P1dB`).

### Квадратурний змішувач (IQ Downconversion)

Для одночасного збереження повної амплітудної та фазової інформації без втрати знака частотного зсуву застосовують квадратурне перетворення на нульову проміжну частоту (Zero-IF / Direct Conversion).

Вхідний радіочастотний сигнал `x_rf(t)` розділяється на два паралельні канали та перемножується у змішувачах із двома опорними коливаннями синтезатора гетеродина (англ. *Local Oscillator*, LO), які зсунуті між собою строго на 90°:

```
s_LO_I(t) = cos(2π · f_LO · t)           [синфазний гетеродин]
s_LO_Q(t) = -sin(2π · f_LO · t)          [квадратурний гетеродин, зсув -90°]
```

Нехай вхідний радіочастотний сигнал є гармонічним коливанням на частоті `f_rf = f_LO + Δf` із початковою фазою `θ`:

```
x_rf(t) = A · cos(2π · (f_LO + Δf) · t + θ)
```

Результат множення в каналі `I` (In-phase):

```
x_I_raw(t) = x_rf(t) · cos(2π · f_LO · t)
= A · cos(2π·(f_LO + Δf)·t + θ) · cos(2π·f_LO·t)    [підстановка вхідного гармонічного коливання]
= 0.5 · A · [cos(2π·Δf·t + θ) + cos(2π·(2f_LO + Δf)·t + θ)]    [тригонометричний розклад добутку косинусів]
```

Результат множення в каналі `Q` (Quadrature):

```
x_Q_raw(t) = x_rf(t) · (-sin(2π · f_LO · t))
= -A · cos(2π·(f_LO + Δf)·t + θ) · sin(2π·f_LO·t)   [підстановка сигналу у квадратурний канал]
= 0.5 · A · [sin(2π·Δf·t + θ) - sin(2π·(2f_LO + Δf)·t + θ)]    [тригонометричний розклад добутку]
```

Аналогові фільтри низьких частот (ФНЧ) зрізають високочастотну сумарну складову `2f_LO + Δf`, залишаючи низькочастотні модулювальні коливання різницевої частоти `Δf`:

```
I(t) = 0.5 · A · cos(2π · Δf · t + θ)    [синфазна низькочастотна компонента]
Q(t) = 0.5 · A · sin(2π · Δf · t + θ)    [квадратурна низькочастотна компонента]
```

Значення `Δf` може бути як додатним (сигнал вище частоти гетеродина `f_rf > f_LO`), так і від'ємним (`f_rf < f_LO`). В одноканальному (дійсному) перетворювачі косинус не розрізняє знак частоти, оскільки `cos(-2π·Δf·t) = cos(2π·Δf·t)`, через що сигнали ліворуч і праворуч від гетеродина накладаються один на одного. У квадратурному перетворювачі синус у каналі `Q` змінює знак: `sin(-2π·Δf·t) = -sin(2π·Δf·t)`. Пара `(I, Q)` однозначно розрізняє додатні та від'ємні частоти, забезпечуючи огляд повної смуги частот без дзеркального накладання.

### АЦП та цифровий перетворювач униз (DDC)

Обидва канали `I` та `Q` оцифровуються парою синхронізованих АЦП високої розрядності (типово 14 або 16 біт) із частотою дискретизації `Fs_adc` (від 50 до 250 Мвиб/с). 

У вимірювальних SDR потік відліків з АЦП надходить у ПЛІС (FPGA), де працює цифровий перетворювач униз (Digital Down-Converter, DDC):
1. **Числовий керований генератор (NCO)** та алгоритм CORDIC зміщують спектр на довільну точну величину всередині смуги;
2. **Каскадні інтегрально-гребінчасті фільтри (CIC)** виконують грубу децимацію потоку у `R` разів без множників;
3. **Поліфазні КІХ-фільтри (FIR)** компенсують завал амплітудно-частотної характеристики CIC-фільтра та формують крутий зріз смуги пропускання;
4. Відфільтрований комплексний потік відліків із частотою `Fs` (наприклад, 10 Мвиб/с) передається через шину USB 3.0 або 10GbE на центральний процесор хоста.

```
SNR_jitter = -20 · log₁₀(2π · f_in · t_jitter)     [шум від джитеру фази]
= -20 · log₁₀(2π · 10⁸ · 10⁻¹²)                    [підстановка: f_in = 100 МГц, t_jitter = 1 пс]
= -20 · log₁₀(6.28 · 10⁻⁴)                         [розрахунок добутку під логарифмом]
= 64.0 dB                                          [підсумковий SNR]
```

Для збереження динамічного діапазону 16-розрядного АЦП (теоретичний SNR = 98 dB) середньоквадратичний джитер тактового генератора не повинен перевищувати `0.1 .. 0.2 пс` (100–200 фемтосекунд).

## 2. Квадратурні компоненти: векторний аналіз і вилучення параметрів

Комплексний сигнал у дискретній формі записується вектором:

```
s[n] = I[n] + j · Q[n]
де j = √(-1) — уявна одиниця.
```

![Аналіз квадратурного вектора IQ та неідеальності](/root/hw/hw-sensing/pryimach-iz-prohramnoiu-obrobkoiu-sdr-iak-prylad/img/iq-constellation-demod.svg)
*Комплексна площина IQ: миттєвий радіус-вектор сигналу (ліворуч) та зміщення нуля і деформація еліпса через апаратні неідеальності аналогового змішувача (праворуч).*

### Відновлення миттєвих характеристик сигналу

Знаючи відліки `I[n]` та `Q[n]`, цифрова система миттєво обчислює амплітуду, фазу та частоту сигналу в кожен момент часу без застосування фазових детекторів або амплітудних випрямлячів:

1. **Миттєва амплітуда (огинаюча):**
```
A[n] = √(I²[n] + Q²[n])
```

2. **Миттєва фаза:**
```
φ[n] = atan2(Q[n], I[n])    [арктангенс із відновленням квадранта в діапазоні -π .. +π]
```

3. **Миттєва частота (похідна від фази за часом):**
```
Δφ[n] = unwrap(φ[n] - φ[n-1])
f_inst[n] = (Δφ[n] / Δt) / (2π) = (Fs / (2π)) · Δφ[n]
```

Диференціювання функції `φ(t) = arctan(Q(t) / I(t))` у неперервному часі дає пряму аналітичну формулу частоти через компоненти та їхні дискретні похідні:

```
f_inst(t) = (1 / (2π)) · (I(t) · (dQ/dt) - Q(t) · (dI/dt)) / (I²(t) + Q²(t))
```

Ця формула дозволяє вимірювати паразитну девіацію частоти (FM-шуми) та параметри частотної модуляції без використання аналогових частотних дискримінаторів.

### Апаратні недосконалості та їхня програмна корекція

В аналоговому квадратурному змішувачі фізичні компоненти ніколи не є абсолютно ідентичними. Це породжує три типові спотворення:

1. **Зсув постійної складової (DC Offset):** виникає внаслідок прямого просочування коливань гетеродина на вхід змішувача (LO leakage) та зміщення нуля вхідних операційних підсилювачів і АЦП. У спектрі це проявляється як незмінний паразитний пік на нульовій проміжній частоті (в центрі огляду);
2. **Амплітудний дисбаланс (Gain Imbalance):** коефіцієнти передачі змішувачів і фільтрів каналів `I` та `Q` різняться на коефіцієнт `α = G_Q / G_I ≠ 1`;
3. **Фазовий дисбаланс (Phase Imbalance):** зсув між сигналами гетеродина відхиляється від ідеальних 90° на кут похибки `θ ≠ 0`.

Через амплітудний і фазовий дисбаланс траєкторія вектора чистого гармонічного коливання перетворюється з ідеального кола на похилий еліпс. У частотній області це призводить до появи дзеркального паразитного піка (Image frequency) на симетричній частоті `-Δf`.

Рівень придушення дзеркального каналу (Image Rejection Ratio, IRR) у децибелах виражається через похибки амплітуди `ΔA = α - 1` та фази `θ` (у радіанах):

```
IRR ≈ 10 · log₁₀((ΔA² + θ²) / 4)
```

При дисбалансі підсилення всього у `0.5 dB` (5.9%) та фазовій похибці `2°` (0.035 рад) рівень придушення становить:

```
IRR ≈ 10 · log₁₀(((0.059)² + (0.035)²) / 4)    [підстановка похибок амплітуди 0.059 та фази 0.035 рад]
= 10 · log₁₀((0.00348 + 0.00122) / 4)          [піднесення похибок до квадрата]
= 10 · log₁₀(0.001175)                         [ділення суми на 4]
≈ -29.3 dB                                     [розрахунок логарифма: рівень придушення]
```

Хибний дзеркальний пік з амплітудою всього на 29 dB нижче основного неприпустимий для вимірювального приладу. Для досягнення `IRR > 70 .. 80 dB` SDR застосовує цифрову матричну корекцію Грама-Шмідта. Поточні відліки множаться на зворотну матрицю спотворень:

```
[ I_corr[n] ]   [ 1                   0              ]   [ I_raw[n] - DC_I ]
[           ] = [                                    ] · [                 ]
[ Q_corr[n] ]   [ -tan(θ) / α         1 / (α·cos(θ)) ]   [ Q_raw[n] - DC_Q ]
```

Коефіцієнти `DC_I`, `DC_Q`, `α` та `θ` калібруються на заводі для кожної частоти та зберігаються у незалежній пам'яті приладу.

## 3. Перетворення IQ-потоку в спектрограму: вікна, FFT та усереднення

Для переходу з часової області у частотну блок із `N` комплексних відліків піддається швидкому перетворенню Фур'є (FFT). Проте дискретне перетворення Фур'є розглядає блок як нескінченно повторюваний період сигналу. Якщо сигнал не є строго кратним довжині блоку `N`, стрибок амплітуди на межах сусідніх блоків викликає паразитне розтікання енергії по всій смузі — спектральне просочування (англ. *spectral leakage*).

![Віконні функції та спектральне просочування при FFT](/root/hw/hw-sensing/pryimach-iz-prohramnoiu-obrobkoiu-sdr-iak-prylad/img/windowing-fft-leakage.svg)
*Зважування блоку відліків вікном Blackman-Harris плавно зводить кінці до нуля, пригнічуючи бічні пелюстки спектрального розтікання до рівня -92 dB.*

### Порівняння віконних функцій

Для усунення розриву відліки блоку множаться на вагове вікно `w[n]`, краї якого плавно спадають до нуля:

```
x_win[n] = (I[n] + j · Q[n]) · w[n],   де n = 0 .. N-1
```

Вибір вікна є компромісом між двома суперечливими метрологічними вимогами:
- **Ширина головної пелюстки:** визначає мінімальну відстань між двома сусідніми лініями, які ще можна розрізнити окремо;
- **Рівень придушення бічних пелюсток:** визначає здатність виявити слабкий сигнал поруч із потужною завадою.

| Тип вікна | Рівень бічних пелюсток | Еквівалентна шумова смуга (ENBW) | Похибка амплітуди (Scalloping loss) | Основне застосування |
|---|---|---|---|---|
| **Прямокутне (Rectangular)** | -13.3 dB | 1.00 бінів | 3.92 dB | Короткі імпульси, широкосмуговий шум |
| **Ханна (Hann)** | -31.5 dB | 1.50 бінів | 1.42 dB | Загальний спектральний огляд |
| **Блекмена-Гарріса (4-term BH)** | -92.0 dB | 2.00 бінів | 0.83 dB | Прецизійні вимірювання завад і SFDR |
| **Плоска вершина (Flat-top)** | -93.0 dB | 3.77 бінів | 0.01 dB | Абсолютно точне вимірювання амплітуди |

У вимірювальних приладах для аналізу побічних випромінювань стандартом є вікно **Blackman-Harris**, оскільки придушення бічних пелюсток на 92 dB гарантує, що спектральний відгук потужного сигналу не замаскує слабкі гармоніки.

Математичне виведення енергетичних втрат і формул масштабування наведено у вставці [🧮 Виведення смуги шуму RBW, еквівалентної ширини вікна та чутливості DANL](root:hw-sensing/pryimach-iz-prohramnoiu-obrobkoiu-sdr-iak-prylad/math-danl-rbw-scaling.md).

### Розрахунок роздільної здатності за смугою (RBW)

Ширина смуги пропускання вимірювального фільтра (Resolution Bandwidth, RBW) в аналізаторі на базі FFT визначається кроком частотної сітки та коефіцієнтом `ENBW` обраного вікна:

```
Δf_bin = Fs / N
RBW = ENBW_window · (Fs / N)
```

**Приклад розрахунку:**
При частоті дискретизації `Fs = 20 Мвиб/с` та розмірі перетворення `N = 16384` відліки:
- Для прямокутного вікна (`ENBW = 1.0`): `RBW = 1.0 · (20 · 10⁶ / 16384) = 1.22 кГц`;
- Для вікна Blackman-Harris (`ENBW = 2.0`): `RBW = 2.0 · (20 · 10⁶ / 16384) = 2.44 кГц`.

### Відеоусереднення спектрів (Video Averaging)

Кожен окремий розрахунок спектра FFT має високу статистичну дисперсію шуму: амплітуда шумової доріжки хаотично коливається в межах 10–12 dB. Для стабілізації показань застосовують відеоусереднення (назва походить від аналогових низькочастотних відеофільтрів після детектора).

Застосовують два методи:
1. **Лінійне блокове усереднення (Linear Averaging):** накопичення середнього значення за `M` послідовних спектрів:
```
P_avg[k] = (1 / M) · ∑[m=1..M] |X_m[k]|²
```

2. **Експоненційне згладжування (Exponential Video Filter):** рекурсивний фільтр першого порядку з коефіцієнтом згладжування `α ∈ (0 .. 1]`:
```
S_out[k] = α · P_new[k] + (1 - α) · S_out[k]
```

Згладжування не змінює середній рівень шуму, але стискає розкид пікових флуктуацій до менш ніж `0.5 dB`, дозволяючи чітко розрізняти стаціонарні сигнали, амплітуда яких лише на 1 dB перевищує середній рівень шумів.

## 4. Калібрування абсолютної потужності та динамічний діапазон

Дискретні величини амплітуди після FFT самі по собі є безрозмірними цілими або дійсними числами. Щоб перетворити їх на фізичні значення потужності у децибел-міліватах (dBm), прилад повинен пройти процедуру наскрізного калібрування.

![Динамічний діапазон SDR: рівні шумів, компресія та SFDR](/root/hw/hw-sensing/pryimach-iz-prohramnoiu-obrobkoiu-sdr-iak-prylad/img/dynamic-range-danl-sfdr.svg)
*Спектральний динамічний діапазон вимірювального приймача: співвідношення між рівнем кліпінгу 0 dBFS, компресією P1dB, шумовою доріжкою DANL та вільним від завад діапазоном SFDR.*

### Переведення відліків АЦП у шкалу dBm

Повна шкала АЦП відповідає максимально допустимій напрузі без кліпінгу `V_FS` (наприклад, `1.0 В` пік-пік, тобто амплітуда `V_peak = 0.5 В`). Навантаження `50 Ом` при піковій напрузі `0.5 В` поглинає потужність:

```
P_max = (V_peak / √2)² / 50    [розрахунок потужності навантаження 50 Ом]
= (0.5 / 1.414)² / 50          [підстановка амплітуди V_peak = 0.5 В]
= 0.125 / 50                   [квадрат діючої напруги]
= 2.5 мВт                      [максимальна потужність у міліватах]

P_max_dBm = 10 · log₁₀(2.5 мВт / 1 мВт)    [переведення у логарифмічну шкалу]
= 10 · log₁₀(2.5)                          [відношення до 1 мВт]
= +3.98 dBm                                [рівень 0 dBFS у dBm]
```

Якщо вхідний сигнал має потужність `+3.98 dBm`, його амплітуда досягає рівня повної шкали АЦП (0 dBFS). 

Формула перерахунку спектрального відгуку біна `|X[k]|` у фізичну потужність `P_dBm[k]`:

```
P_dBm[k] = 10 · log₁₀(|X[k]|²) - 20 · log₁₀(S₁) + 10 · log₁₀(10 · V_FS²) + G_cal(f) - Att_gain
де:
S₁ = ∑ w[n] — когерентна сума коефіцієнтів вікна;
G_cal(f) — апаратно виміряна поправка нерівномірності АЧХ на частоті f;
Att_gain — поточне значення встановленого атенюатора.
```

### Відображений середній рівень шуму (DANL)

Чутливість спектрального аналізатора кількісно оцінюється відображеним середнім рівнем шуму (Displayed Average Noise Level, DANL). Фундаментальна межа теплового шуму в узгодженому опорі при кімнатній температурі (`T = 290 K`) у смузі 1 Гц становить:

```
N₀ = k_B · T = 1.38 · 10⁻²³ · 290 = 4.00 · 10⁻²¹ Вт/Гц = -174 dBm/Hz
```

З урахуванням коефіцієнта шуму приймача `NF` та еквівалентної смуги фільтра `RBW`:

```
DANL = -174 dBm/Hz + NF + 10 · log₁₀(RBW)
```

З цієї залежності випливає базовий метрологічний закон цифрового спектрального аналізу: **кожне зменшення смуги `RBW` у 10 разів опускає шумову доріжку на екрані рівно на 10 dB**, збільшуючи видимий динамічний діапазон приладу.

### Динамічний діапазон, вільний від спотворень (SFDR)

Динамічний діапазон без завад (Spurious-Free Dynamic Range, SFDR) — це відношення амплітуди вимірюваного сигналу до рівня найбільшої паразитної складової (шпори, інтермодуляційного продукту або дзеркального каналу) у спектрі:

```
SFDR = P_carrier (dBm) - P_max_spur (dBm)
```

Головними факторами, що обмежують SFDR у SDR-приймачах, є:
1. **Інтермодуляція третього порядку (IMD3):** якщо на вхід потрапляють два потужні сигнали на частотах `f₁` та `f₂`, кубічна нелінійність LNA та змішувача генерує паразитні відгуки на частотах `2f₁ - f₂` та `2f₂ - f₁`. Точка перехоплення третього порядку `IP3` (Intercept Point 3) визначає рівень лінійності:
```
P_IMD3 (dBm) = 3 · P_in - 2 · IIP3
```
2. **Неврівноважений дзеркальний канал:** залишкова похибка IQ-балансування;
3. **Нелінійність АЦП (DNL / INL):** породжує гармоніки дискретизації високого порядку.

Для типового 14-бітного вимірювального SDR значення SFDR становить `75 .. 85 dB`.

```c
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

#ifndef M_PI
#define M_PI 3.14159265358979323846
#endif

typedef struct {
    float i;
    float q;
} complex_f32_t;

/* Обчислення спектра потужності в dBm із вікном Blackman-Harris */
void compute_spectrum_dbm(const complex_f32_t *iq_in, float *spec_dbm_out, 
                          size_t n, float v_fs_volts, float cal_gain_db) {
    /* 1. Розрахунок вікна та когерентної суми S1 */
    float s1 = 0.0f;
    const float a0 = 0.35875f, a1 = 0.48829f, a2 = 0.14128f, a3 = 0.01168f;
    
    complex_f32_t *win_buf = (complex_f32_t*)malloc(n * sizeof(complex_f32_t));
    if (!win_buf) return;

    for (size_t i = 0; i < n; ++i) {
        float theta = (2.0f * (float)M_PI * (float)i) / (float)(n - 1);
        float w = a0 - a1 * cosf(theta) + a2 * cosf(2.0f * theta) - a3 * cosf(3.0f * theta);
        win_buf[i].i = iq_in[i].i * w;
        win_buf[i].q = iq_in[i].q * w;
        s1 += w;
    }

    /* 2. ДПФ / FFT (пряме перетворення) */
    /* У реальній системі викликається radix2_fft(win_buf, n) */

    /* 3. Масштабування в dBm з центруванням fftshift */
    const size_t half = n / 2;
    const float p_ref_mw = 10.0f * (v_fs_volts * v_fs_volts); /* 50 Ом навантаження */
    const float norm_factor = 1.0f / (s1 * s1);

    for (size_t k = 0; k < n; ++k) {
        size_t shifted_idx = (k < half) ? (k + half) : (k - half);
        float mag_sq = win_buf[k].i * win_buf[k].i + win_buf[k].q * win_buf[k].q;
        float power_mw = mag_sq * norm_factor * p_ref_mw;
        
        if (power_mw < 1e-15f) power_mw = 1e-15f; /* Поріг відсікання -150 dBm */
        spec_dbm_out[shifted_idx] = 10.0f * log10f(power_mw) + cal_gain_db;
    }

    free(win_buf);
}
```

```cpp
#include <vector>
#include <span>
#include <complex>
#include <cmath>
#include <numbers>
#include <algorithm>

/* Обчислення спектра потужності в dBm із вікном Blackman-Harris */
std::vector<float> compute_spectrum_dbm(std::span<const std::complex<float>> iq_in,
                                        float v_fs_volts, float cal_gain_db) {
    const size_t n = iq_in.size();
    const size_t half = n / 2;
    std::vector<std::complex<float>> win_buf(n);
    std::vector<float> spec_dbm_out(n);

    constexpr float a0 = 0.35875f, a1 = 0.48829f, a2 = 0.14128f, a3 = 0.01168f;
    const float pi = std::numbers::pi_v<float>;
    float s1 = 0.0f;

    // 1. Віконне зважування та накопичення S1
    for (size_t i = 0; i < n; ++i) {
        float theta = (2.0f * pi * static_cast<float>(i)) / static_cast<float>(n - 1);
        float w = a0 - a1 * std::cos(theta) + a2 * std::cos(2.0f * theta) - a3 * std::cos(3.0f * theta);
        win_buf[i] = iq_in[i] * w;
        s1 += w;
    }

    // 2. Виклик FFT (наприклад, внутрішнього Radix-2)
    // radix2_fft(win_buf);

    // 3. Масштабування в dBm та fftshift
    const float p_ref_mw = 10.0f * (v_fs_volts * v_fs_volts);
    const float norm_factor = 1.0f / (s1 * s1);

    for (size_t k = 0; k < n; ++k) {
        size_t shifted_idx = (k < half) ? (k + half) : (k - half);
        float mag_sq = std::norm(win_buf[k]);
        float power_mw = mag_sq * norm_factor * p_ref_mw;
        power_mw = std::max(power_mw, 1e-15f);

        spec_dbm_out[shifted_idx] = 10.0f * std::log10(power_mw) + cal_gain_db;
    }

    return spec_dbm_out;
}
```

## 6. Практичні аспекти та підводні камені вимірювань

При використанні SDR як вимірювального інструмента інженер стикається з фізичними ефектами, відсутніми в класичних аналогових приладах:

1. **Температурний дрейф підсилення:** Підсилення напівпровідникових LNA на основі арсеніду галію (GaAs) або транзисторів pHEMT змінюється на `0.02 .. 0.05 dB/°C`. При зміні температури всередині корпусу на 20 °C похибка амплітуди без термокомпенсації перевищить `0.8 dB`. Вимірювальні SDR обладнуються термодатчиками поруч із фронтендом для автоматичної інтерполяції калібрувальних коефіцієнтів;
2. **Паразитні дискретні гармоніки (Spurs):** Тактові генератори процесора, шини передачі даних USB/PCIe та імпульсні перетворювачі живлення випромінюють електромагнітні наведення, що проникають у радіотракт. Вони виглядають на спектрограмі як вузькі стаціонарні піки з рівнем `-110 .. -90 dBm`. Для їхньої локалізації вхід приймача навантажують на узгоджену заглушку `50 Ом` і записують карту власних шпор приладу для подальшого програмного вибіркового маскування;
3. **Хибний нульовий пік і зсув частоти гетеродина (Offset Tuning):** Щоб позбутися викривлення сигналу постійною складовою (DC spike) та низькочастотним `1/f` шумом змішувача, вимірювальний гетеродин ніколи не налаштовують точно на частоту досліджуваного сигналу. Його зсувають убік (наприклад, на `+2 МГц`), а цифровий NCO у DDC автоматично повертає корисний сигнал у центр цифрової смуги;
4. **Взаємне змішування фазових шумів гетеродина (Reciprocal Mixing):** Якщо поруч із досліджуваним слабким сигналом на відстані кількох сотень кілогерц діє потужний сторонній передавач, неідеальний фазовий шум гетеродина (Phase noise skirts) перемножується із цим передавачем у змішувачі, створюючи широкосмуговий шумовий п'єдестал, що піднімає локальний рівень DANL і маскує корисний слабкий сигнал.

> 🔧 **Навіщо це.**
> Калібрований вимірювальний SDR перетворює будь-який ПК або одноплатний комп'ютер на багатофункціональний радіокомплекс: спектральний аналізатор реального часу (Real-Time Spectrum Analyzer, RTSA), векторний вимірювач сигналів (VSA), приймач контролю електромагнітної сумісності (EMC Pre-compliance) та демодулятор цифрових протоколів. Розуміння фізики квадратурного тракту, віконного FFT-перетворення та калібрувальних формул дозволяє отримувати метрологічно достовірні дані про амплітуду, спектральну густину потужності та нелінійні спотворення без необхідності використання громіздких лабораторних стійкових приладів.
