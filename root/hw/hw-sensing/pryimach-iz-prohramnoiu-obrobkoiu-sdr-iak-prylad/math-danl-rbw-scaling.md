# 🧮 Виведення смуги шуму RBW, еквівалентної ширини вікна та чутливості DANL

Математичний апарат калібрування спектральної потужності перетворює безрозмірні дискретні комплексні відліки АЦП на фізичні вати та децибел-мілівати (dBm), враховуючи енергетичні втрати віконного зважування, неперервність інтегралу теплового шуму та еквівалентну шумову смугу пропускання цифрових фільтрів.

## 1. Коефіцієнти віконного зважування: когерентне підсилення та смуга ENBW

Дискретний сигнал `x[n]` довжиною `N` відліків перед обчисленням дискретного перетворення Фур'є (ДПФ) множиться на вагову функцію `w[n]`. Вікно усуває розриви першого роду на межах аналізованого блоку, проте нерівномірно зважує енергію відліків у часі, змінюючи як амплітуду корисного тону, так і інтегральну потужність некорельованого білого шуму.

Для аналітичного опису вікна вводять дві фундаментальні суми:

```
S₁ = ∑[n=0..N-1] w[n]       [сума відліків вікна: когерентне підсилення]
S₂ = ∑[n=0..N-1] (w[n])²    [енергія відліків вікна: шумова потужність]
```

### Когерентне та шумове підсилення

Когерентне підсилення (англ. *coherent gain*) характеризує реакцію вікна на строго періодичний детермінований гармонічний сигнал, частота якого точно збігається з центром одного з частотних бінів ДПФ:

```
G_coh = S₁ / N
```

Оскільки всі відліки корисного тону в межах біна додаються синфазно (когерентно), сумарна амплітуда спектрального відгуку масштабується прямо пропорційно сумі коефіцієнтів `S₁`.

Шумове підсилення (англ. *noise power gain*) показує, як вікно змінює дисперсію стаціонарного некорельованого білого шуму з нульовим математичним сподіванням і дисперсією `σ²`:

```
G_noise = S₂ / N
```

Шумові відліки некорельовані між собою в часі, тому їхня потужність додається не за амплітудою, а за квадратами (некогерентно). Внаслідок цього сумарна шумова потужність на виході вікна масштабується коефіцієнтом `S₂`.

### Еквівалентна шумова смуга (ENBW)

Еквівалентна шумова смуга (Equivalent Noise Bandwidth, ENBW) — це ширина гіпотетичного прямокутного смугового фільтра з одиничним коефіцієнтом передачі в смузі пропускання, який би пропускав таку саму сумарну потужність білого шуму, як і дане вагове вікно.

У неперервній області інтегральне визначення еквівалентної шумової смуги має вигляд:

```
ENBW_continuous = (∫[-∞..+∞] |W(f)|² df) / |W(0)|²
```

За теоремою Релея-Парсеваля інтеграл від квадрата модуля спектральної щільності в частотній області дорівнює інтегралу від квадрата часової функції:

```
∫[-∞..+∞] |W(f)|² df = ∫[-∞..+∞] w²(t) dt
```

У дискретному представленні для `N` відліків із кроком дискретизації `Δt = 1 / Fs` інтеграли переходять у дискретні суми, а смуга нормується на крок частотної сітки ДПФ `Δf_bin = Fs / N`:

```
ENBW_bins = N · S₂ / (S₁)²
= N · (∑[n=0..N-1] w²[n]) / (∑[n=0..N-1] w[n])²    [визначення ENBW у бінах]
```

### Розрахунок ENBW для базових типів вікон

1. **Прямокутне вікно (Rectangular):**
Всі коефіцієнти рівні одиниці `w[n] = 1` для `n = 0 .. N-1`:

```
S₁ = N                               [сума N одиниць]
S₂ = N                               [сума N квадратів одиниць]
ENBW_rect = N · N / N²               [підстановка сум у формулу ENBW]
= 1.000 бінів                        [смуга прямокутного вікна]
```

2. **Вікно Ханна (Hann):**
Вагова функція піднятого косинуса `w[n] = 0.5 · (1 - cos(2πn / N))`:

```
S₁ = 0.5 · N                         [інтеграл піднятого косинуса]
S₂ = 0.375 · N                       [інтеграл квадрата піднятого косинуса]
ENBW_hann = N · (0.375 · N) / (0.5 · N)²    [формула еквівалентної смуги]
= 0.375 / 0.25                       [скорочення N²]
= 1.500 бінів                        [підсумковий коефіцієнт смуги]
```

3. **Вікно Блекмена-Гарріса (4-term Blackman-Harris):**
Чотириточкове узагальнене косинусне вікно з мінімальним рівнем бічних пелюсток:

```
w[n] = a₀ - a₁·cos(2πn/N) + a₂·cos(4πn/N) - a₃·cos(6πn/N)
де a₀ = 0.35875, a₁ = 0.48829, a₂ = 0.14128, a₃ = 0.01168

S₁ ≈ 0.35875 · N                     [когерентна сума коефіцієнтів a0·N]
S₂ ≈ 0.2574 · N                      [сума квадратів косинусного ряду]
ENBW_bh = N · (0.2574 · N) / (0.35875 · N)²    [розрахунок смуги в бінах]
= 0.2574 / 0.1287                    [скорочення N² у дробі]
= 2.000 бінів                        [значення ENBW для Blackman-Harris]
```

4. **Вікно з плоскою вершиною (Flat-top):**
Спеціалізоване вікно для прецизійного вимірювання амплітуди:

```
w[n] = a₀ - a₁·cos(2πn/N) + a₂·cos(4πn/N) - a₃·cos(6πn/N) + a₄·cos(8πn/N)
де a₀ = 0.21557895, a₁ = 0.41663158, a₂ = 0.277263158, a₃ = 0.083578947, a₄ = 0.006947368

S₁ ≈ 0.21558 · N                     [когерентна сума Flat-top]
S₂ ≈ 0.1752 · N                      [сума енергії Flat-top]
ENBW_flattop = N · (0.1752 · N) / (0.21558 · N)²    [розрахунок смуги]
= 0.1752 / 0.04647                   [скорочення N²]
= 3.770 бінів                        [еквівалентна смуга вікна Flat-top]
```

### Фізична роздільна здатність за смугою (RBW)

Фізична смуга вимірювального фільтра (Resolution Bandwidth, RBW) у герцах зв'язує апаратну частоту дискретизації `Fs`, кількість точок ДПФ `N` та обране вікно:

```
Δf_bin = Fs / N               [крок частотної сітки ДПФ]
RBW = ENBW_bins · Δf_bin
= ENBW_bins · (Fs / N)        [еквівалентна фізична смуга фільтра]
```

Звідси видно, що для збереження вузької смуги `RBW` при переході від прямокутного вікна до вікна Blackman-Harris необхідно подвоїти довжину блоку `N`.

## 2. Амплітудні втрати зубчастості (Scalloping Loss)

Якщо частота корисного сигналу не збігається точно з центром біна `k₀`, а потрапляє посередині між сусідніми бінами `k₀ + 0.5`, амплітуда спектрального відгуку падає. Цей спад називають втратами зубчастості (англ. *scalloping loss*).

Амплітудний відгук вікна `W(f)` на півкроку біна `Δf = 0.5 · (Fs / N)` відносно відгуку в центрі визначає максимальні втрати зубчастості:

```
Scalloping_Loss (dB) = 20 · log₁₀(|W(0.5 · Δf_bin)| / |W(0)|)
```

Для прямокутного вікна відгук описується функцією `sinc`:

```
|W_rect(0.5)| / |W_rect(0)| = sin(0.5 · π) / (0.5 · π) = 1 / (π / 2) ≈ 0.6366
Scalloping_Loss_rect = 20 · log₁₀(0.6366) ≈ -3.92 dB
```

Якщо не застосовувати спеціальних вікон, похибка вимірювання амплітуди тону з довільною частотою на прямокутному вікні може досягати майже `4 dB` (36% за напругою). Для вікна Hann втрати становлять `-1.42 dB`, для Blackman-Harris — `-0.83 dB`, а для вікна Flat-top — менше ніж `-0.01 dB`. Саме тому Flat-top вікно застосовують у випадках, коли вимагається абсолютна похибка вимірювання рівня без передискретизації.

## 3. Теорема Парсеваля та перетворення дискретних бінів у потужність (Watts і dBm)

Нехай `x[n] = I[n] + j·Q[n]` — комплексний дискретний сигнал у вольтах на вході АЦП. Після множення на вагове вікно `w[n]` пряме дискретне перетворення Фур'є формує комплексний спектр:

```
X[k] = ∑[n=0..N-1] (x[n] · w[n]) · e^(-j·2π·k·n / N)
```

### Вимірювання потужності дискретного гармонічного тону

Розглянемо чистий гармонічний сигнал із піковою амплітудою напруги `V_peak` на частоті біна `k₀`. Його спектральний відгук у точці піка дорівнює:

```
|X[k₀]| = V_peak · S₁
```

Пікова напруга корисного коливання відновлюється діленням на когерентну суму:

```
V_peak = |X[k₀]| / S₁
```

Діюча напруга (RMS):

```
V_rms = V_peak / √2
= |X[k₀]| / (√2 · S₁)
```

Середня потужність сигналу на узгодженому навантаженні `R_in = 50 Ом`:

```
P (Watts) = (V_rms)² / R_in
= (|X[k₀]| / (√2 · S₁))² / 50          [підстановка діючої напруги]
= |X[k₀]|² / (2 · 50 · S₁²)            [розкриття квадрата знаменника]
= |X[k₀]|² / (100 · S₁²)               [спрощення коефіцієнтів]
```

Переведення у логарифмічну шкалу децибел-міліватів (`0 dBm = 1 мВт = 10⁻³ Вт`):

```
P (dBm) = 10 · log₁₀(P (Watts) / 10⁻³)
= 10 · log₁₀(P (Watts) · 1000)         [перехід до міліватів]
= 10 · log₁₀(|X[k₀]|² · 1000 / (100 · S₁²))    [підстановка формули у ватах]
= 10 · log₁₀(|X[k₀]|² · 10 / S₁²)      [скорочення 1000/100]
= 10 · log₁₀(|X[k₀]|²) - 20 · log₁₀(S₁) + 10    [логарифмічний вигляд для тону]
```

### Нормалізовані відліки повної шкали АЦП (Full-Scale)

У цифрових сигнальних процесорах відліки АЦП зазвичай нормалізують до діапазону `[-1.0 .. +1.0] FS`. Якщо відомо, що повній шкалі АЦП відповідає пікова напруга на вході `V_FS` (у вольтах):

```
P_dBm = 10 · log₁₀(|X[k]|²) - 20 · log₁₀(S₁) + 10 · log₁₀(10 · V_FS²) + G_cal(f) - Att_gain
де:
G_cal(f) — калібрувальна поправка нерівномірності підсилення радіотракту на частоті f;
Att_gain — встановлене значення цифрового атенюатора у dB.
```

## 4. Спектральна густина потужності (PSD) для шумових сигналів

Для неперервного широкосмугового шуму потужність розподілена рівномірно по спектру, і її характеризують спектральною густиною потужності (Power Spectral Density, PSD) у розрахунку на `1 Гц` смуги.

За теоремою Парсеваля загальна шумова енергія в часовій та частотній областях пов'язана співвідношенням:

```
∑[k=0..N-1] |X[k]|² = N · ∑[n=0..N-1] |x[n] · w[n]|²
```

Для стаціонарного білого шуму математичне сподівання енергії на виході вікна:

```
E[|x[n] · w[n]|²] = σ_noise² · w²[n]
∑[n=0..N-1] E[|x[n] · w[n]|²] = σ_noise² · S₂
```

Спектральна густина потужності у фізичних одиницях `Вт/Гц` на навантаженні `R_in = 50 Ом`:

```
PSD[k] = |X[k]|² / (Fs · S₂ · R_in)
= |X[k]|² / (50 · Fs · S₂)             [для вхідного опору 50 Ом]
```

У логарифмічній шкалі `dBm/Hz`:

```
PSD (dBm/Hz) = 10 · log₁₀(PSD[k] / 10⁻³)
= 10 · log₁₀(|X[k]|²) - 10 · log₁₀(S₂) - 10 · log₁₀(Fs) + 10 · log₁₀(1000 / 50)
= 10 · log₁₀(|X[k]|²) - 10 · log₁₀(S₂) - 10 · log₁₀(Fs) + 13.01
```

Різниця між розрахунком тону та шуму полягає у знаменнику: для детермінованого тону застосовують коефіцієнт `S₁²` (когерентне підсилення), а для широкосмугового шуму — `S₂` (енергетичне підсилення).

## 5. Виведення чутливості та відображеного середнього рівня шуму (DANL)

Фундаментальне обмеження чутливості будь-якого радіоприймального пристрою задається тепловим рухом носіїв заряду в узгодженому резисторі. За формулою Найквіста-Джонсона спектральна густина потужності теплового шуму при стандартній температурі `T₀ = 290 K` (16.85 °C) становить:

```
P₀ = k_B · T₀
де k_B = 1.380649 · 10⁻²³ Дж/К  [стала Больцмана]

P₀ = 1.380649 · 10⁻²³ · 290
= 4.00388 · 10⁻²¹ Вт/Гц
```

У логарифмічній шкалі децибел-міліватів на герц:

```
P₀ (dBm/Hz) = 10 · log₁₀(4.00388 · 10⁻²¹ / 10⁻³)
= 10 · log₁₀(4.00388 · 10⁻¹⁸)          [переведення у мілівати]
= 10 · (-17.3975)                      [обчислення десяткового логарифма]
= -173.98 dBm/Hz ≈ -174 dBm/Hz         [фундаментальне теплове шумове дно]
```

Реальний SDR-приймач вносить додатковий власний шум, який кількісно визначається коефіцієнтом шуму `NF` (Noise Figure, у dB). Сумарна еквівалентна шумова густина на вході приймача становить:

```
N_in (dBm/Hz) = -174 dBm/Hz + NF
```

Рівень відображеного середнього шуму (Displayed Average Noise Level, DANL) у вимірювальному вікні аналізатора спектра визначається інтегруванням шумової густини по смузі роздільної здатності `RBW`:

```
DANL (Watts) = N_in (Вт/Гц) · RBW (Гц)
DANL (dBm) = N_in (dBm/Hz) + 10 · log₁₀(RBW)
= -174 dBm/Hz + NF + 10 · log₁₀(RBW)
```

### Числовий приклад поведінки DANL при зміні смуги фільтра

Розглянемо вимірювальний SDR із коефіцієнтом шуму фронтенду `NF = 6 dB`:

1. Широкосмуговий огляд зі смугою `RBW = 100 кГц` (`10⁵ Гц`):
```
DANL = -174 + 6 + 10 · log₁₀(100 000)    [підстановка: NF = 6 dB, RBW = 100 кГц]
= -174 + 6 + 50                          [логарифм смуги 10·5 = 50 dB]
= -118 dBm                               [сума рівнів потужності]
```

2. Стандартний аналіз зі смугою `RBW = 1 кГц` (`10³ Гц`):
```
DANL = -174 + 6 + 10 · log₁₀(1 000)      [підстановка: NF = 6 dB, RBW = 1 кГц]
= -174 + 6 + 30                          [логарифм смуги 10·3 = 30 dB]
= -138 dBm                               [сума рівнів потужності]
```

3. Прецизійний пошук надслабких сигналів зі смугою `RBW = 10 Гц` (`10¹ Гц`):
```
DANL = -174 + 6 + 10 · log₁₀(10)         [підстановка: NF = 6 dB, RBW = 10 Гц]
= -174 + 6 + 10                          [логарифм смуги 10·1 = 10 dB]
= -158 dBm                               [сума рівнів потужності]
```

Зменшення смуги `RBW` у `10` разів зменшує потужність шуму, що потрапляє в один частотний бін, рівно у `10` разів (на `10 dB`). При цьому потужність вузькосмугового гармонічного сигналу лишається незмінною, оскільки вся його енергія зосереджена всередині біна. Це фундаментальний принцип, за допомогою якого цифрові спектральні аналізатори виявляють сигнали, потужність яких на десятки децибелів нижча за інтегральний шум усього радіотракту.
