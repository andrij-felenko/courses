<preknowlist>

- [Віртуальна земля](root:hw-analog/virtual-ground) — утримання нульового потенціалу на інвертуючому вході операційного підсилювача через від'ємний зворотний зв'язок.
- [Шумове підсилення](root:hw-analog/noise-gain) — частотна характеристика 1/β(s) та коефіцієнт передачі внутрішніх шумів і зміщень ОП.

</preknowlist>

Коли квант світла поглинається в напівпровідниковому кристалі фотодіода, він вибиває рівно одну пару носіїв заряду — електрон та дірку. В оптичних вимірюваннях слабких потоків (лазерні далекоміри, спектрометри, оптоволоконні приймачі, біомедичні пульсоксиметри) сумарний світловий потік генерує мізерний електричний струм: від одиниць пікоамперів (`10⁻¹² А`) до кількох мікроамперів (`10⁻⁶ А`). Такий струм неможливо безпосередньо оцифрувати стандартним аналого-цифровим перетворювачем мікроконтролера, оскільки типовий крок квантування АЦП вимагає напруги в мілівольти. Перетворення надмалого струму в стабільну напругу стикається з трьома фундаментальними бар'єрами: спонтанною тепловою генерацією носіїв у кристалі без світла (темновим струмом), обвальним уповільненням відгуку через паразитну ємність діода та втратою фазової стійкості підсилювального тракту, яка перетворює вимірювач на радіочастотний автогенератор.

## 1. Фізика витоку в темряві: теплова генерація та темновий струм

Навіть якщо помістити фотодіод у світлонепроникний свинцевий екран за абсолютної відсутності фотонів, крізь кристал тече електричний струм. Цей струм називають темновим (англ. *dark current*, позначається `I_d` або `I_dark`).

Причина його виникнення полягає в тепловій енергії кристалічної ґратки. За будь-якої температури вище абсолютного нуля (`T > 0 K`) атоми кремнію перебувають у стані неперервних теплових коливань (фононів). Енергія цих коливань статистично розподілена за законом Максвелла — Больцмана. Частина фононів має достатню енергію, щоб розірвати ковалентний зв'язок кремнію та перекинути електрон із валентної зони в зону провідності.

Усередині нейтрального напівпровідника такий електрон швидко рекомбінує назад із діркою. Але в збідненій області p-n переходу (англ. *depletion region*) діє потужне внутрішнє електростатичне поле контакту. Щойно теплова флуктуація народжує електронно-діркову пару всередині збідненого шару, вбудоване поле миттєво розносить носії в протилежні боки: електрон викидається в n-область (катод), а дірка — у p-область (анод). Цей спрямований рух формує неперервний фоновий струм, який за напрямком точно збігається з корисним фотострумом.

![Еквівалентна модель реального фотодіода та температурний дрейф](/root/hw/hw-sensing/dark-current/img/photodiode-equivalent-dark-current.svg)
*Еквівалентна електрична схема фотодіода з паразитною ємністю Cd, шунтом Rsh та експоненційною залежністю темнового струму від температури*

Темновий струм фотодіода складається з двох основних фізичних компонентів:

1. **Генераційно-рекомбінаційний струм у збідненій зоні (механізм Шоклі — Ріда — Холла, SRH):**
   Теплова генерація відбувається переважно через глибокі домішкові рівні та дефекти кристалічної ґратки всередині бар'єрного шару. Цей струм прямо пропорційний об'єму збідненої зони (її товщині `W`) та площі переходу `A`:
```
I_gen = q · n_i · W · A / (2 · τ_0)
```
   де `q = 1.602 · 10⁻¹⁹ Кл` — елементарний заряд, `n_i` — власна концентрація носіїв заряду в кремнії, `τ_0` — ефективний час життя носіїв.

2. **Дифузійний струм неосновних носіїв:**
   Електрони та дірки, народжені теплом у нейтральних p- та n-областях на відстані дифузійної довжини від краю переходу, хаотично блукають і досягають бар'єру, після чого підхоплюються полем.

### Експоненційний закон подвоєння

Власна концентрація носіїв `n_i` експоненційно залежить від температури через ширину забороненої зони кремнію `E_g ≈ 1.12 еВ`:

```
n_i(T) ∝ T^(3/2) · exp[ -E_g / (2 · k_B · T) ]
```
де `k_B = 1.38 · 10⁻²³ Дж/К` — стала Больцмана, `T` — абсолютна температура в кельвінах.

Через таку експоненціальну залежність темновий струм зростає катастрофічно швидко: для кремнієвих фотодіодів величина `I_d` **подвоюється приблизно кожні 8–10 °C підвищення температури**.

| Температура кристала (°C) | Відносне зростання `I_d` | Типовий темновий струм PIN-діода (пА) |
|---|---|---|
| `+25 °C` (калібрування) | `1.0 ×` (база) | `10 пА` |
| `+35 °C` | `2.2 ×` | `22 пА` |
| `+55 °C` | `11.3 ×` | `113 пА` |
| `+75 °C` | `57.0 ×` | `570 пА` |
| `+85 °C` (промисловий максимум) | `128.0 ×` | `1280 пА` (1.28 нА) |

Якщо схема вимірює постійний рівень світла з фотострумом `50 пА`, нагрівання приладу на сонці від кімнатної температури до `+65 °C` збільшить темновий струм з `10 пА` до `320 пА`. Без термокомпенсації темновий дрейф повністю перекриє корисний сигнал і створить похибку вимірювання понад 600%.

### Фотовольтаїчний проти фотопровідного режиму

Співвідношення між корисним сигналом, темновим струмом і швидкодією задається напругою зворотного зміщення `V_R` (англ. *reverse bias*):

- **Фотовольтаїчний режим (нульове зміщення, `V_R = 0 В`):**
  На виводах діода підтримується нульова різниця потенціалів. Оскільки зовнішньої напруги немає, струми поверхневого витоку діелектрика практично відсутні, а темновий струм прямує до свого фізичного мінімуму (одиниці пікоампер або частки фемтоампер). Однак товщина збідненого шару `W` залишається мінімальною, що дає максимальну бар'єрну ємність переходу:
```
C_d = ε · A / W
```
  Велика ємність `C_d` (від десятків до тисяч пікофарад) різко звужує частотну смугу підсилювача. Цей режим обирають для прецизійних низькочастотних і статичних вимірювань високої точності (фотометри, пірометри).

- **Фотопровідний режим (зворотне зміщення, `V_R > 0 В`, типово від `3 В` до `50 В`):**
  Зовнішня напруга прикладається плюсом до катода, розширюючи збіднену зону `W ∝ √(V_bi + V_R)`. Бар'єрна ємність `C_d` зменшується в 3–10 разів, а сильне внутрішнє поле прискорює дрейф носіїв заряду до швидкості насичення (`v_sat ≈ 10⁷ см/с`), забезпечуючи субнаносекундний час наростання імпульсу. Платою за швидкодію є значне збільшення темнового струму через зростання об'єму генерації та струмів витоку по поверхні кристала.

### Напівпровідникові матеріали фотодіодів

Величина темнового струму фундаментально залежить від ширини забороненої зони напівпровідникового матеріалу:

| Матеріал кристала | Ширина зони `E_g` (еВ) | Спектральний діапазон (нм) | Типовий `I_d` при +25 °C | Особливості застосування |
|---|---|---|---|---|
| **Кремній (Si)** | `1.12` | `190...1100` (видимий, UV, ближній NIR) | `1...10 пА` | Еталонний матеріал з мінімальним шумом та високим `R_sh > 10 ГОм` |
| **Індій-галій-арсенід (InGaAs)** | `0.75` | `800...1700` (SWIR, зв'язок 1310/1550 нм) | `0.5...5 нА` | Висока чутливість в ІЧ-області, темновий струм у 1000 разів вищий за Si |
| **Германій (Ge)** | `0.66` | `800...1800` (ІЧ-спектроскопія) | `1...10 мкА` | Дуже високий темновий струм; вимагає термоелектричного охолодження Пельтьє |

Для фотодіодів із вузькою забороненою зоною (InGaAs, Ge) темновий струм за кімнатної температури настільки великий, що TIA без глибокого охолодження кристала (до `-20...-40 °C`) або методів активної компенсації втрачає динамічний діапазон через передчасне насичення вихідного каскаду.

## 2. Чому не пасивний резистор: парадокс смуги та динамічного діапазону

Найпростіший спосіб перетворити струм у напругу — пропустити його крізь звичайний навантажувальний резистор `R_L`, підключений паралельно до фотодіода, і виміряти падіння напруги `V_out = I_ph · R_L`.

![Порівняння пасивного перетворювача та TIA](/root/hw/hw-sensing/dark-current/img/passive-vs-transimpedance.svg)
*Пасивний резистор гойдає потенціал катода та створює низькочастотний полюс; TIA фіксує нульовий потенціал віртуальної землі*

Цей наївний підхід руйнується двома фундаментальними проблемами:

### Пастка частотного зрізу
Нехай необхідно виміряти слабкий фотострум `I_ph = 10 нА` і отримати вихідну напругу `V_out = 1.0 В` для подачі на АЦП. Номінал резистора повинен становити:

```
R_L = V_out / I_ph = 1.0 В / 10⁻⁸ А = 100 МОм
```

Реальний фотодіод має власну бар'єрну ємність `C_d = 40 пФ`, ще `10 пФ` додає паразитна ємність монтажу та кабелю (`C_in = 50 пФ`). Разом із резистором `R_L` ця ємність утворює пасивний RC-фільтр низьких частот із частотою зрізу по рівню `-3 дБ`:

```
f_p = 1 / ( 2 · π · R_L · C_in )
= 1 / ( 2 · 3.14159 · 100 · 10⁶ Ом · 50 · 10⁻¹² Ф )
≈ 31.8 Гц
```

Час наростання перехідного процесу `t_r ≈ 2.2 · R_L · C_in` становить `11 мілісекунд`! Будь-який оптичний імпульс, коротший за сотню мілісекунд, розмивається в пологий експоненційний пагорб, а високошвидкісна реєстрація сигналу стає неможливою. Щоб розширити смугу до `1 МГц`, довелося б зменшити `R_L` до `3.18 кОм`, але тоді вихідний сигнал на струмі `10 нА` складе мізерні `31.8 мікровольта`, які потонуть у тепловому шумі та напрузі зсуву будь-якого підсилювача.

### Пастка нелінійності через зміщення робочої точки
У міру збільшення світлового потоку вихідна напруга `V_out` зростає. Але оскільки резистор підключений безпосередньо до діода, напруга на виводах самого фотодіода змінюється на таку саму величину:

```
V_diode = -V_out = -I_ph · R_L
```

Зміна напруги на діоді зміщує його вольт-амперну характеристику. Бар'єрна ємність `C_d(V)` починає динамічно модулюватися амплітудою світлового сигналу, виникає паразитний струм перезаряджання ємності `i_cap = C_d · (dV/dt)`, а при наближенні напруги до `+0.5 В` діод відкривається в прямому напрямку і переходить у режим глибокого насичення.

## 3. Схемотехніка трансімпедансного підсилювача (TIA)

Вирішенням суперечності між високим коефіцієнтом перетворення та широкою смугою частот є **трансімпедансний підсилювач** (англ. *Transimpedance Amplifier*, TIA; від лат. *trans* — через, крізь та *impedire* — перешкоджати).

Схема складається з операційного підсилювача, неінвертуючий вхід (`+IN`) якого з'єднаний із землею (або джерелом опорної напруги `V_ref`), а між виходом та інвертуючим входом (`-IN`) увімкнено резистор зворотного зв'язку `R_f`. Фотодіод підключається до інвертуючого входу.

### Принцип віртуальної землі
Завдяки глибокому від'ємному зворотному зв'язку операційний підсилювач безперервно підлаштовує свою вихідну напругу так, щоб різниця потенціалів між його входами дорівнювала нулю:

```
V_in(-) = V_in(+) = 0 В  (або V_ref)
```

Інвертуючий вхід стає точкою **віртуальної землі** (англ. *virtual ground*). Вхідний опір цієї точки для сигналу прагне до нуля:

```
R_in_virtual = R_f / (1 + A_ol) ≈ 0 Ом
```
де `A_ol` — коефіцієнт підсилення ОП з розімкненою петлею (типово `10⁵...10⁶` на постійному струмі).

Оскільки потенціал інвертуючого входу зафіксований на рівні нуля:
1. Напруга на фотодіоді залишається суворо постійною за будь-якої яскравості світла: `dV_diode / dt = 0`.
2. Оскільки напруга не змінюється, **паразитна ємність фотодіода `C_d` не перезаряджається струмом сигналу**. Струм `C_d · (dV/dt)` дорівнює нулю!
3. Оскільки вхідний опір ідеального ОП нескінченно великий, фотострум не може текти всередину підсилювача. Весь струм фотодіода вимушений текти виключно крізь резистор зворотного зв'язку `R_f`.

Вихідна напруга TIA визначається законом Ома:

```
V_out = V_ref - (I_ph + I_d) · R_f
```

Трансімпедансний коефіцієнт передачі `Z_t = ΔV_out / ΔI_ph` дорівнює номіналу резистора `R_f` і вимірюється в омах (`В / А = Ом`).

### Критерії вибору операційного підсилювача

Для побудови високочутливого TIA підходить далеко не кожен ОП. Ключовими є три параметри:

1. **Вхідний струм зміщення (Input Bias Current, `I_b`):**
   Вхідні каскади ОП самі споживають постійний струм. Якщо застосувати класичний біполярний ОП (наприклад, NE5532 або OP07) із вхідним струмом `I_b = 20...100 нА`, цей струм потече крізь `R_f = 10 МОм`, створивши на виході паразитне зміщення `V_err = I_b · R_f = 0.2...1.0 В`, що повністю заблокує вимірювання струмів пікоамперного діапазону.
   Необхідно використовувати ОП із вхідними каскадами на польових транзисторах — **JFET** (наприклад, OPA140, OPA657, ADA4610) або **CMOS** (OPA320, LTC6268, ADA4530-1, LMC6001), у яких `I_b < 1 пА`, а у спеціалізованих електрометричних підсилювачах — `I_b < 20 фА`.

2. **Вхідна напруга зсуву (Input Offset Voltage, `V_os`) та її дрейф:**
   Напруга `V_os` з'являється безпосередньо на інвертуючому вході. Хоча вхід заземлено, на діоді фактично виникає зміщення `V_diode = V_os`. Ця напруга створює додатковий струм витоку крізь шунтуючий опір діода `R_sh`:
```
I_leak_vos = V_os / R_sh
```
   На виході зсув підсилюється коефіцієнтом `1 + R_f / R_sh`. Тому для роботи з високоомними діодами з малим `R_sh` необхідні ОП із `V_os < 50 мкВ` або автонулюванням (Zero-Drift / Chopper-Stabilized).

3. **Добуток підсилення на смугу (Gain-Bandwidth Product, GBW):**
   Визначає граничну швидкодію та динамічну стабільність схеми за наявності великої вхідної ємності.

## 4. Проблема стабільності TIA: паразитна ємність та нуль у петлі зворотного зв'язку

На практиці інженери, які вперше збирають TIA з великим резистором `R_f` (наприклад, `1 МОм`) та фотодіодом із ємністю `C_d = 50 пФ`, стикаються з несподіваним ефектом: схема без світла видає на виході стійкі синусоїдальні автоколивання з розмахом від шини до шини живлення або демонструє затяжний резонансний дзвін при падінні світлового імпульсу.

Причина автоколивань полягає у фазовому зсуві, який виникає в контурі зворотного зв'язку.

![Діаграма Боде петльового підсилення та стабілізація TIA](/root/hw/hw-sensing/dark-current/img/tia-bode-stability.svg)
*Частотний аналіз стійкості TIA: швидкість зближення ROC = 40 дБ/дек викликає автоколивання; компенсаційний конденсатор Cf повертає фазовий запас*

До інвертуючого входу ОП підключена сумарна вхідна ємність:

```
C_in = C_d + C_cm + C_diff + C_pcb
```
де `C_d` — ємність фотодіода, `C_cm` — синфазна вхідна ємність ОП, `C_diff` — диференціальна вхідна ємність ОП, `C_pcb` — паразитна ємність монтажних доріжок.

Коефіцієнт передачі ланки зворотного зв'язку `β(s)` показує, яка частина вихідної напруги повертається на вхід ОП через дільник `R_f - C_in`:

```
β(s) = (1 / s·C_in) / [ (1 / s·C_in) + R_f ] = 1 / ( 1 + s · R_f · C_in )
```

Зворотна величина — **шумове підсилення (Noise Gain, `1/β`)**:

```
1/β(s) = 1 + s · R_f · C_in
```

На діаграмі Боде характеристика `1/β(f)` веде себе так:
- На низьких частотах (`f < f_z`) шумове підсилення дорівнює одиниці (`0 дБ`).
- На частоті `f_z = 1 / (2 · π · R_f · C_in)` у передатній функції виникає **нуль**.
- На частотах вище `f_z` графік `1/β` починає підніматися вгору зі швидкістю **`+20 дБ/декаду`**.

Водночас власне підсилення операційного підсилювача з розімкненою петлею `|A(f)|` спадає з нахилом **`-20 дБ/декаду`** через внутрішню частотну корекцію.

### Критерій швидкості зближення (Rate of Closure)
Стійкість системи з від'ємним ЗЗ визначається взаємним нахилом кривих `|A(f)|` та `1/β(f)` у точці їх перетину `f_x` (де петльове підсилення `A · β = 1`, тобто `0 дБ`):

```
ROC = | Нахил |A(f)| - Нахил |1/β(f)| | = -20 дБ/дек - (+20 дБ/дек) = 40 дБ/декаду
```

Швидкість зближення `40 дБ/декаду` означає, що:
1. Полюс ОП дає запізнення фази `-90°`.
2. Нуль у контурі зворотного зв'язку (полюс `β(s)`) додає ще `-90°` фазового запізнення в петлю.
3. Сумарний фазовий зсув у точці перетину досягає `∠(Aβ) = -180°`.

**Запас по фазі (Phase Margin) падає до нуля: `Φ_m ≈ 0°`**. Від'ємний зворотний зв'язок на частоті `f_x` перетворюється на додатний, і підсилювач переходить у режим незатухаючої генерації.

Повний математичний апарат із матричними рівняннями та виведенням характеристичного полінома наведено в окремому матеріалі:
→ [Математичний аналіз стійкості TIA](root:hw-sensing/dark-current/math-tia-stability.md).

## 5. Компенсаційна ємність зворотного зв'язку: розрахунок за Баттервортом

Щоб повернути підсилювачу стабільність, паралельно до резистора `R_f` встановлюють компенсаційний конденсатор зворотного зв'язку `C_f`.

Конденсатор `C_f` створює в імпедансі зворотного зв'язку `Z_f = R_f || (1/sC_f)` високочастотний нуль, який додає **полюс у шумове підсилення `1/β(s)`**:

```
f_p = 1 / ( 2 · π · R_f · C_f )
```

На частотах вище `f_p` підйом кривої `1/β` припиняється: графік виходить на горизонтальне плато (полицю) з постійним значенням `1 + C_in / C_f`.

Якщо обрати `C_f` таким чином, щоб частота `f_p` лежала нижче точки перетину з АЧХ підсилювача, криві `|A(f)|` та `1/β(f)` перетнуться з безпечною швидкістю зближення **`ROC = 20 дБ/декаду`**, що забезпечить запас фази `Φ_m ≈ 45°...65°`.

### Інженерний розрахунок за Баттервортом

Для отримання максимально плоскої амплітудно-частотної характеристики другого порядку (відгук Баттерворта з добротністю `Q = 1/√2 ≈ 0.707` та запасом фази `Φ_m = 45°`) значення компенсаційної ємності обчислюють за формулою:

```
C_f = √[ C_in / ( 2 · π · R_f · GBW ) ]
```
де `C_in` — сумарна вхідна ємність (Ф), `R_f` — опір зворотного зв'язку (Ом), `GBW` — добуток підсилення на смугу частот ОП (Гц).

Результуюча смуга пропускання замкненого TIA по рівню `-3 дБ` складе:

```
f_-3dB = √[ GBW / ( 2 · π · R_f · C_in ) ]
```

### Числовий приклад розрахунку
**Вхідні параметри:**
- Фотодіод: `C_d = 30 пФ`.
- Монтаж і вхід ОП: `C_amp + C_pcb = 5 пФ` (`C_in = 35 пФ`).
- Необхідний коефіцієнт підсилення: `R_f = 2.0 МОм` (`2 · 10⁶ Ом`).
- Обраний операційний підсилювач: OPA320 (`GBW = 20 МГц = 20 · 10⁶ Гц`).

**Крок 1. Розрахунок компенсаційної ємності `C_f`:**

```
C_f
= √[ 35 · 10⁻¹² / ( 2 · 3.14159 · 2.0 · 10⁶ · 20 · 10⁶ ) ]       [підстановка параметрів]
= √[ 35 · 10⁻¹² / ( 2.51327 · 10¹⁴ ) ]                           [обчислення знаменника]
= √[ 1.3926 · 10⁻²⁵ ]                                            [ділення під коренем]
≈ 0.373 · 10⁻¹² Ф = 0.37 пФ
```

**Крок 2. Розрахунок смуги пропускання `f_-3dB`:**

```
f_-3dB
= √[ 20 · 10⁶ / ( 2 · 3.14159 · 2.0 · 10⁶ · 35 · 10⁻¹² ) ]      [підстановка параметрів]
= √[ 20 · 10⁶ / ( 4.3982 · 10⁻⁴ ) ]                              [обчислення знаменника]
= √[ 4.547 · 10¹⁰ ]
≈ 213.2 кГц
```

*Висновок:* застосування TIA на ОП із `GBW = 20 МГц` розширило смугу пропускання з `2.27 кГц` (яка була б у пасивного резистора `2 МОм` з ємністю `35 пФ`) до **`213 кГц`** — тобто майже в 100 разів!

### Крайовий випадок: субпікофарадні номінали
Якщо розрахункова ємність `C_f` виходить меншою за `0.2...0.5 пФ`, виникає практична проблема: стандартні дискретні SMD-конденсатори рідко випускаються номіналом нижче `0.5 пФ` з високою точністю, а власний паразитний міжкапсульний ємнісний зв'язок резистора `R_f` у корпусі SMD 0805 сам по собі становить `0.1...0.3 пФ`.

У такому разі окремий конденсатор не встановлюють, покладаючись на розподілену ємність резистора, або формують мікроємність безпосередньо топологією плати у вигляді двох зустрічних зустрічно-гребінчастих друкованих доріжок.

### Бутстрепінг вхідної ємності (Bootstrapped Photodiode)
Для широкосмугових застосувань (високошвидкісні лідари, імпульсні далекоміри), коли фотодіод має велику площу і, як наслідок, значну ємність `C_d = 50...200 пФ`, смуга `f_-3dB` виявляється занадто вузькою.

У таких схемах застосовують техніку **бутстрепінгу (підтягування)**:
1. Анод фотодіода підключають до інвертуючого входу TIA, а катод — до виходу швидкого буферного повторювача напруги на JFET-транзисторі.
2. Вхід буфера з'єднують із тією самою віртуальною землею TIA.
3. Буфер передає сигнал із коефіцієнтом передачі `K ≈ 1.0` на катод діода.
4. Оскільки на обох виводах діода діє абсолютно однакова змінна напруга, змінний струм крізь бар'єрну ємність спадає практично до нуля:
```
i_cap = C_d · [ d(V_anode - V_cathode) / dt ] = C_d · (1 - K) · (dV/dt) ≈ 0
```
Ефективна динамічна ємність фотодіода зменшується в десятки разів: `C_d_eff = C_d · (1 - K)`, що дозволяє розширити смугу TIA до сотень мегагерців без втрати трансімпедансного коефіцієнта підсилення.

## 6. Шумовий аналіз та баланс чутливості

Мінімальний світловий потік, який здатний зареєструвати підсилювач, обмежується власними шумами компонентів схеми.

У трансімпедансному каскаді діють п'ять незалежних джерел шуму:

1. **Дробовий шум темнового струму (Shot Noise of Dark Current):**
   Викликаний квантовою дискретністю носіїв заряду, що долають потенційний бар'єр:
```
i_n_dark = √( 2 · q · I_d · Δf )  [А / √Гц]
```

2. **Дробовий шум струму корисного оптичного сигналу:**
```
i_n_signal = √( 2 · q · I_ph · Δf )  [А / √Гц]
```

3. **Тепловий шум Джонсона — Найквіста резистора зворотного зв'язку `R_f`:**
   Тепловий рух електронів у провідному шарі резистора генерує шумовий струм зі спектральною густиною:
```
i_n_Rf = √( 4 · k_B · T · Δf / R_f )  [А / √Гц]
```

4. **Вхідний струмовий шум операційного підсилювача `i_n_op`:**
   Для CMOS/JFET підсилювачів становить мізерні `0.1...5 фА / √Гц` і практично не впливає на баланс.

5. **Вхідний шум напруги операційного підсилювача `e_n_op`:**
   Власний шум напруги вхідного диференціального каскаду ОП (типово `3...15 нВ / √Гц`). На виході TIA цей шум множиться на частотно-залежний коефіцієнт шумового підсилення `1/β(f)`:
```
e_out_noise_op = e_n_op · [ 1 + j · 2 · π · f · R_f · C_in ]
```

### Парадокс резистора зворотного зв'язку: чому більший `R_f` тихіший
Початківці часто припускають, що великий опір `R_f` додає багато шуму, тому намагаються брати менший `R_f` (наприклад, `10 кОм`) і добирати підсилення другим каскадом напруги. **Це груба схемотехнічна помилка.**

Розглянемо відношення сигнал/шум за струмом (SNR):
- Корисна вихідна напруга зростає прямо пропорційно резистору: `V_sig = I_ph · R_f` (масштаб `∝ R_f`).
- Струмовий тепловий шум резистора зростає як корінь із номіналу напруги, але еквівалентний струмовий шум на вході падає:
```
i_n_equiv = e_noise_Rf / R_f = √(4 · k_B · T · R_f) / R_f = √(4 · k_B · T / R_f)  (масштаб ∝ 1 / √R_f)
```

При збільшенні `R_f` у 100 разів корисний сигнал зростає в 100 разів, а струмовий шум резистора падає в 10 разів. Відношення сигнал/шум покращується в 10 разів (`+20 дБ`).

**Головне правило розробника TIA:** номінал резистора `R_f` слід обирати максимально великим, наскільки дозволяють необхідна смуга пропускання `f_-3dB` та діапазон вихідної напруги ОП до настання насичення.

### Т-подібний ланцюг зворотного зв'язку (T-Network) та його шумова ціна
Коли для детектування фемтоамперних струмів потрібен еквівалентний трансімпеданс `R_eq = 1 ГОм` (`10⁹ Ом`), знайти прецизійний гігаомний резистор з низьким ТКС і малою паразитною ємністю вкрай важко.

Інженери іноді застосовують резистивний Т-міст (T-Network) із трьох резисторів помірного номіналу `R_1`, `R_2` та `R_3` (де `R_3` підключений до землі):

```
R_eq = R_1 + R_2 + (R_1 · R_2 / R_3)
```

Наприклад, якщо взяти `R_1 = 10 МОм`, `R_2 = 10 МОм` та `R_3 = 101 кОм`:
```
R_eq = 10 МОм + 10 МОм + (100 · 10¹² / 101 · 10³) ≈ 1 ГОм
```

Проте Т-міст має важку схемотехнічну розплату:
1. **Збільшення шумового підсилення на постійному струмі:** коефіцієнт передачі для власної напруги зсуву `V_os` та шуму напруги `e_n` ОП зростає у `1 + R_2 / R_3 ≈ 100 разів`!
2. Напруга зсуву `V_os = 1 мВ` перетвориться на виході на зміщення в `100 мВ`, а шум напруги ОП підніметься на `40 дБ`.

Тому Т-подібний зворотний зв'язок виправданий лише тоді, коли вирішальним фактором є доступність компонентів, а підсилювач має наднизький шум напруги та нульовий зсув (Zero-Drift). Для гранично малошумних приладів завжди віддають перевагу єдиному дискретному високоомному резистору.

## 7. Методи компенсації темнового струму: від апаратних схем до CDS

Оскільки темновий струм експоненційно дрейфує від температури, висока точність вимірювань вимагає активних методів його компенсації.

![Методи компенсації темнового струму](/root/hw/hw-sensing/dark-current/img/dark-current-compensation-methods.svg)
*Апаратне віднімання спареним затіненим діодом та часова діаграма цифрової подвійної корельованої вибірки (CDS)*

### Метод 1. Спарений «сліпий» фотодіод (Hardware Matched Blind Diode)
На одному кристалі напівпровідника або в безпосередньому тепловому контакті розміщують два абсолютно ідентичні фотодіоди:
- `PD1` (вимірювальний) відкритий для падіння світлового потоку: крізь нього тече `I_total1 = I_ph + I_d(T)`.
- `PD2` (компенсаційний) герметично накритий непрозорим чорним світлопоглинаючим шаром або металевим екраном: крізь нього тече тільки темновий струм `I_total2 = I_d(T)`.

Діод `PD2` підключають до неінвертуючого входу ОП через симетричний резистор `R_f2 = R_f1` або використовують диференціальний вхідний каскад. Темнові струми однакової величини протікають синфазно і взаємно віднімаються на виході:

```
V_out = - [ (I_ph + I_d) · R_f1 - I_d · R_f2 ] = -I_ph · R_f
```

### Метод 2. Подвійна корельована вибірка (Correlated Double Sampling, CDS)
У системах із керованим джерелом світла (оптичні давачі наближення, спектрометри з імпульсним LED-підсвічуванням, лідари) вимірювальний процес розбивають на два синхронні інтервали часу:

1. **Фаза темряви `t_dark` (LED вимкнено):**
   АЦП фіксує вихідну напругу, яка містить тільки напругу зсуву та темновий струм:
```
S_dark = V_os + I_d(T) · R_f + V_noise_lf
```

2. **Фаза світла `t_light` (LED увімкнено):**
   АЦП фіксує повну напругу:
```
S_light = V_os + (I_ph + I_d(T)) · R_f + V_noise_lf
```

3. **Цифрове віднімання:**
```
S_result = S_light - S_dark = I_ph · R_f
```

CDS-алгоритм не тільки повністю ліквідує постійний темновий струм і дрейф `V_os`, але й ефективно пригнічує низькочастотний флікер-шум `1/f` підсилювача, оскільки час між вибірками значно менший за період низькочастотних флуктуацій.

## 8. Конструктивні вимоги та боротьба зі струмами витоку на друкованій платі

На рівні пікоамперних струмів стандартна друкована плата перестає бути ідеальним ізолятором. Якщо опір склотекстоліту FR-4 між доріжкою живлення `+15 В` та інвертуючим входом TIA становить `10¹⁰ Ом`, поверхневий струм витоку складе `1.5 нА` (`1500 пА`), що в сотні разів перевищить вимірюваний фотострум.

![Топологія захисного кільця Guard Ring](/root/hw/hw-sensing/dark-current/img/guard-ring-pcb-layout.svg)
*Топологія друкованої плати: захисне кільце з потенціалом віртуальної землі повністю оточує чутливий інвертуючий вхід*

Для запобігання паразитному витоку застосовують **захисне кільце (Guard Ring)**:
- Інвертуючий вхід ОП та анод фотодіода повністю оточують замкненою мідною доріжкою на всіх шарах друкованої плати.
- Кільце з'єднують із неінвертуючим входом ОП (`+IN`), потенціал якого дорівнює потенціалу віртуальної землі (`0 В`).
- Різниця потенціалів між захисним кільцем та вимірювальним входом становить лічені мікровольти (`ΔV = V_os ≈ 10...50 мкВ`), через що струм витоку крізь діелектрик падає до часток фемтоампера (`< 0.005 пА`).
- Усі струми витоку від сусідніх високовольтних шин живлення стікають у захисне кільце і поглинаються низькоомним виводом землі.

Детальний аналіз вибору матеріалів плат (Rogers, PTFE), вимог до очищення від залишків флюсу та боротьби з п'єзоефектом конденсаторів наведено у вставці:
→ [Конструювання та топологія надчутливих TIA](root:hw-sensing/dark-current/comp-guard-ring.md).

> 🔧 **Навіщо це.**
> У медичних пульсоксиметрах (вимірювання сатурації крові `SpO_2`) червоний та інфрачервоний світлодіоди просвічують палець пацієнта. Тканини поглинають до 99.9% світла, тому фотострум фотодіода становить лише `5...50 нА`, а його пульсуюча артеріальна складова (сигнал фотоплетизмограми) — всього `0.1...0.5 нА`. Під час тривалого моніторингу палець нагрівається, збільшуючи темновий струм діода в 4–6 разів. Без TIA з прецизійним Guard Ring, компенсаційною ємністю `C_f` та апаратним CDS-відніманням нульової лінії мікроконтролер не зміг би виділити серцевий ритм на тлі дрейфу базової лінії.

## 9. Програмний модуль обробки та компенсації сигналу TIA

Нижче наведено промисловий модуль цифрової обробки сигналу фотодіодного фронтенду для вбудованих мікроконтролерних систем. Він виконує синхронну подвійну корельовану вибірку (CDS), виявляє перевантаження (насичення каскаду) та реалізує експоненційне температурне калібрування.

:::tabs
```c
/* tia_processor.h / tia_processor.c — Модуль обробки фотоструму TIA */
#include <stdint.h>
#include <stdbool.h>
#include <math.h>

typedef struct {
    float feedback_resistor_ohms; /* Опір Rf (наприклад, 1.0e6f = 1 МОм) */
    float dark_current_t0_amps;   /* Базовий темновий струм за температури T0 */
    float cal_temp_celsius;       /* Температура T0 (°C) */
    float temp_doubling_step_c;   /* Крок подвоєння Id (типово 8.5 °C) */
    float filter_alpha;           /* Коефіцієнт IIR-фільтрації (0.01..1.0) */
    float adc_vref_volts;         /* Опорна напруга АЦП (В) */
    float sat_margin_volts;       /* Запас до шини насичення (В) */
} TiaConfig;

typedef struct {
    float filtered_voltage;
    float last_dark_voltage;
    float last_temperature_c;
} TiaState;

typedef struct {
    float photocurrent_amps;      /* Обчислений чистий фотострум (А) */
    float output_voltage_volts;   /* Відфільтрована напруга корисного сигналу (В) */
    float estimated_dark_amps;    /* Теоретичний темновий струм за поточної T */
    bool is_saturated;            /* Прапорець перевантаження аналогового тракту */
    bool is_valid;                /* Прапорець достовірності даних */
} TiaMeasurement;

void tia_init(TiaState *state, const TiaConfig *cfg) {
    state->filtered_voltage = 0.0f;
    state->last_dark_voltage = 0.0f;
    state->last_temperature_c = cfg->cal_temp_celsius;
}

/* Оцінка темнового струму за експоненційною моделлю */
float tia_calc_dark_current(const TiaConfig *cfg, float temp_celsius) {
    float delta_t = temp_celsius - cfg->cal_temp_celsius;
    float exponent = delta_t / cfg->temp_doubling_step_c;
    return cfg->dark_current_t0_amps * powf(2.0f, exponent);
}

/* Обробка циклу подвійної корельованої вибірки */
TiaMeasurement tia_process_sample(TiaState *state,
                                  const TiaConfig *cfg,
                                  float raw_dark_adc_v,
                                  float raw_light_adc_v,
                                  float current_temp_c) {
    TiaMeasurement result;
    
    state->last_dark_voltage = raw_dark_adc_v;
    state->last_temperature_c = current_temp_c;
    
    /* Перевірка на насичення аналогового каскаду */
    float max_linear_v = cfg->adc_vref_volts - cfg->sat_margin_volts;
    if (raw_light_adc_v >= max_linear_v || raw_light_adc_v <= cfg->sat_margin_volts) {
        result.is_saturated = true;
        result.is_valid = false;
    } else {
        result.is_saturated = false;
        result.is_valid = true;
    }

    /* CDS-віднімання базової лінії темряви */
    float diff_v = raw_light_adc_v - raw_dark_adc_v;
    if (diff_v < 0.0f) {
        diff_v = 0.0f; /* Відсікання негативного шуму */
    }

    /* Експоненційне згладжування (IIR-фільтр першого порядку) */
    state->filtered_voltage = (cfg->filter_alpha * diff_v) +
                              ((1.0f - cfg->filter_alpha) * state->filtered_voltage);

    result.output_voltage_volts = state->filtered_voltage;
    result.photocurrent_amps = state->filtered_voltage / cfg->feedback_resistor_ohms;
    result.estimated_dark_amps = tia_calc_dark_current(cfg, current_temp_c);

    return result;
}
```

```cpp
// TiaProcessor.hpp — Ідіоматична C++ реалізація фотодіодного процесора
#pragma once
#include <cmath>
#include <optional>
#include <concepts>
#include <span>

template <std::floating_point T = float>
class TransimpedanceProcessor {
public:
    struct Config {
        T feedback_resistor_ohms{1.0e6};  // 1 МОм
        T dark_current_t0_amps{10.0e-12}; // 10 пА при 25 °C
        T cal_temp_celsius{25.0};
        T temp_doubling_step_c{8.5};
        T filter_alpha{0.15};
        T adc_vref_volts{3.3};
        T sat_margin_volts{0.05};
    };

    struct Result {
        T photocurrent_amps;
        T output_voltage;
        T estimated_dark_amps;
        bool saturated;
    };

    constexpr explicit TransimpedanceProcessor(const Config& config) noexcept
        : config_(config), filtered_voltage_(0) {}

    [[nodiscard]] T estimate_dark_current(T temp_celsius) const noexcept {
        const T delta_t = temp_celsius - config_.cal_temp_celsius;
        const T exponent = delta_t / config_.temp_doubling_step_c;
        return config_.dark_current_t0_amps * std::pow(static_cast<T>(2), exponent);
    }

    [[nodiscard]] std::optional<Result> process_cds(T dark_sample_v,
                                                    T light_sample_v,
                                                    T current_temp_c) noexcept {
        const T max_v = config_.adc_vref_volts - config_.sat_margin_volts;
        const bool is_sat = (light_sample_v >= max_v) || (light_sample_v <= config_.sat_margin_volts);

        T diff_v = light_sample_v - dark_sample_v;
        if (diff_v < static_cast<T>(0)) {
            diff_v = static_cast<T>(0);
        }

        // Оновлення IIR-фільтра
        filtered_voltage_ = (config_.filter_alpha * diff_v) +
                            ((static_cast<T>(1) - config_.filter_alpha) * filtered_voltage_);

        if (is_sat) {
            return std::nullopt; // Сигнал вийшов за лінійний діапазон
        }

        return Result{
            .photocurrent_amps = filtered_voltage_ / config_.feedback_resistor_ohms,
            .output_voltage = filtered_voltage_,
            .estimated_dark_amps = estimate_dark_current(current_temp_c),
            .saturated = false
        };
    }

    void reset() noexcept {
        filtered_voltage_ = static_cast<T>(0);
    }

private:
    Config config_;
    T filtered_voltage_;
};
```
