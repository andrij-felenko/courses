# 🧮 Передатна функція та стійкість трансімпедансного підсилювача

Трансімпедансний підсилювач на операційному підсилювачі (ОП) із вхідною ємністю фотодіода утворює замкнену динамічну систему другого порядку. Без компенсаційного конденсатора в колі зворотного зв'язку система втрачає запас фази й переходить у стан незгасаючих автоколивань або глибокого резонансного підйому шуму. Нижче наведено повне аналітичне виведення передатної функції, розрахунок полюсів і нулів петльового підсилення, дослідження перехідного процесу в часовій області та порівняння критеріїв оптимізації Баттерворта, Бесселя й критичного демпфування.

## 1. Еквівалентна схема та рівняння вузла

Розглядаємо інвертуючий вхід операційного підсилювача. До цього вузла під'єднані три паралельні гілки:
- еквівалентне джерело вхідного струму `I_in(s) = I_ph(s) + I_d(s)`;
- сумарна вхідна шунтуюча ємність `C_in`, яка складається з бар'єрної ємності p-n переходу фотодіода `C_d`, синфазної `C_cm` та диференціальної `C_diff` вхідних ємностей ОП, а також паразитної ємності монтажу `C_pcb`:
```
C_in = C_d + C_cm + C_diff + C_pcb
```
- коло від'ємного зворотного зв'язку, що складається з паралельно з'єднаних резистора зворотного зв'язку `R_f` та компенсаційного конденсатора `C_f`.

Операторний імпеданс ланки зворотного зв'язку `Z_f(s)` записується як:

```
Z_f(s) = R_f / (1 + s · R_f · C_f)
```

Операторний імпеданс вхідного шунтуючого кола:

```
Z_in(s) = 1 / (s · C_in)
```

Операційний підсилювач має власне підсилення з розімкненою петлею, яке в широкій смузі частот моделюється інтегруючою ланкою з частотою одиничного підсилення `GBW` (добуток підсилення на смугу у герцах) або `ω_t = 2 · π · GBW` (у радіанах за секунду):

```
A(s) = ω_t / s
```

Напруга на виході ОП `V_out(s)` пов'язана з потенціалом інвертуючого входу `V_n(s)` рівнянням:

```
V_out(s) = -A(s) · V_n(s)
```

За першим законом Кірхгофа сума струмів у вузлі інвертуючого входу дорівнює нулю:

```
I_in(s) + (V_out(s) - V_n(s)) / Z_f(s) - V_n(s) / Z_in(s) = 0
```

Підставляючи `V_n(s) = -V_out(s) / A(s)`, отримуємо рівняння зв'язку між струмом та вихідною напругою:

```
I_in(s) = V_out(s) · [ (1 + 1/A(s)) / Z_f(s) + 1 / (A(s) · Z_in(s)) ]
```

## 2. Коефіцієнт зворотного зв'язку та шумове підсилення

Визначимо коефіцієнт передачі зворотного зв'язку `β(s)` як частку вихідної напруги, що повертається на вхідний вузол:

```
β(s) = Z_in(s) / (Z_in(s) + Z_f(s))
```

Підставляючи операторні вирази для `Z_in(s)` та `Z_f(s)`:

```
β(s)
= (1 / (s · C_in)) / [ 1 / (s · C_in) + R_f / (1 + s · R_f · C_f) ]   [підстановка виразів імпедансів]
= (1 + s · R_f · C_f) / [ (1 + s · R_f · C_f) + s · R_f · C_in ]       [множення чисельника й знаменника на спільний множник]
= (1 + s · R_f · C_f) / [ 1 + s · R_f · (C_in + C_f) ]               [зведення подібних у знаменнику]
```

Обернена величина — шумове підсилення (Noise Gain) `1/β(s)` — визначає коефіцієнт підсилення власного шуму напруги ОП та напруги зсуву `V_os`:

```
1/β(s) = [ 1 + s · R_f · (C_in + C_f) ] / (1 + s · R_f · C_f)
```

Амплітудно-частотна характеристика шумового підсилення має дві критичні точки зламу:
1. **Нуль характеристики на низькій частоті `f_z`:**
```
f_z = 1 / [ 2 · π · R_f · (C_in + C_f) ]
```
2. **Полюс характеристики на високій частоті `f_p`:**
```
f_p = 1 / ( 2 · π · R_f · C_f )
```

На низьких частотах (`f < f_z`) величина `1/β ≈ 1` (`0 дБ`). На частотах між `f_z` та `f_p` шумове підсилення зростає зі швидкістю `+20 дБ/декаду`. На частотах вище `f_p` крива виходить на постійне плато зі значенням:

```
1/β_max = 1 + C_in / C_f
```

Якщо компенсаційний конденсатор відсутній (`C_f = 0`), полюс прямує до нескінченності (`f_p → ∞`), і графік `1/β` безперервно зростає з нахилом `+20 дБ/декаду` аж до перетину з кривою розімкненого підсилення ОП.

## 3. Петльове підсилення та швидкість зближення асимптот

Стійкість замкненої петлі визначається петльовим підсиленням `T(s) = A(s) · β(s)`:

```
T(s) = [ ω_t / s ] · [ (1 + s · R_f · C_f) / (1 + s · R_f · (C_in + C_f)) ]
```

Розглянемо некомпенсовану схему (`C_f = 0`):
На високих частотах `1/β(jω) ≈ jω · R_f · C_in`. Крива `|A(jω)| = ω_t / ω` спадає з нахилом `-20 дБ/декаду`, а крива `|1/β(jω)|` піднімається з нахилом `+20 дБ/декаду`.

Швидкість зближення двох асимптот (Rate of Closure, ROC) у точці їх перетину `ω_c`:

```
ROC = | d|A|/d(log ω) - d|1/β|/d(log ω) | = 20 - (-20) = 40 дБ/декаду
```

Фазовий баланс у точці перетину:
- внутрішня корекція ОП дає фазовий зсув `-90°`;
- нуль у знаменнику `β(s)` вносить додаткове фазове запізнення, що наближається до `-90°`.

Сумарний фазовий зсув петлі:

```
∠T(jω_c) = -90° + (-90°) = -180°
```

Запас по фазі (Phase Margin `Φ_m`):

```
Φ_m = 180° + ∠T(jω_c) = 180° - 180° = 0°
```

Запас фази `0°` свідчить про те, що система перебуває на межі абсолютної нестійкості. Будь-який тепловий шум або імпульс струму викликає незгасаючі коливання на частоті перетину.

## 4. Замкнена передатна функція TIA другого порядку

Знайдемо повний аналітичний вираз трансімпедансної передатної функції замкненого підсилювача `Z_cl(s) = V_out(s) / I_in(s)`:

```
Z_cl(s) = -Z_f(s) / [ 1 + 1 / (A(s) · β(s)) ]
```

Підставляючи вирази для `Z_f(s)` та `A(s)`:

```
Z_cl(s)
= - [ R_f / (1 + s · R_f · C_f) ] · [ 1 / ( 1 + (s / ω_t) · [ (1 + s · R_f · (C_in + C_f)) / (1 + s · R_f · C_f) ] ) ]
= -R_f / [ 1 + s · R_f · C_f + (s / ω_t) · (1 + s · R_f · (C_in + C_f)) ]
= -R_f / [ 1 + s · ( R_f · C_f + 1 / ω_t ) + s² · ( R_f · (C_in + C_f) / ω_t ) ]
```

Оскільки для реальних компонентів `R_f · C_f >> 1 / ω_t`, знаменник збігається з характеристичним рівнянням стандартної коливальної ланки другого порядку:

```
D(s) = 1 + s · (2 · ζ / ω_0) + s² / ω_0²
```

Порівнюючи коефіцієнти при однакових степенях `s`:

1. **Власна незгасаюча резонансна частота системи `ω_0`:**
```
ω_0 = √[ ω_t / ( R_f · (C_in + C_f) ) ]
```

2. **Коефіцієнт демпфування `ζ`:**
```
2 · ζ / ω_0 = R_f · C_f
```

Звідси отримуємо точну аналітичну формулу для коефіцієнта демпфування:

```
ζ = (R_f · C_f / 2) · ω_0 = (R_f · C_f / 2) · √[ ω_t / ( R_f · (C_in + C_f) ) ]
```

Добротність коливального контуру `Q` пов'язана з коефіцієнтом демпфування як `Q = 1 / (2 · ζ)`:

```
Q = √[ R_f · (C_in + C_f) / (R_f² · C_f² · ω_t) ] = √[ (C_in + C_f) / (R_f · C_f² · ω_t) ]
```

## 5. Порівняння критеріїв демпфування: Баттерворт, Бессель та критичний відгук

Залежно від практичного призначення оптичного тракту обирають один із трьох класичних режимів демпфування:

| Критерій налаштування | Коефіцієнт `ζ` | Добротність `Q` | Запас фази `Φ_m` | Перерегулювання (Overshoot) | Формула ємності `C_f` |
|---|---|---|---|---|---|
| **Баттерворт (Butterworth)** | `1 / √2 ≈ 0.707` | `0.707` | `45°` | `4.3%` | `√[ C_in / (2 · π · R_f · GBW) ]` |
| **Бессель (Bessel)** | `√3 / 2 ≈ 0.866` | `0.577` | `65°` | `< 0.5%` | `√[ 3 · C_in / (4 · π · R_f · GBW) ]` |
| **Критичне демпфування** | `1.000` | `0.500` | `75°` | `0.0%` (монотонне) | `√[ C_in / (π · R_f · GBW) ]` |

### Виведення для критерію Баттерворта (`ζ = 1/√2`)
Критерій Баттерворта забезпечує максимально плоску АЧХ (відсутність горбів у смузі пропускання) за максимальної смуги частот.

Прирівнюємо вираз для `ζ` до `1 / √2`:

```
(R_f · C_f / 2) · √[ ω_t / ( R_f · C_in ) ] = 1 / √2
```

Підносимо обидві частини до квадрата:

```
(R_f² · C_f² / 4) · [ ω_t / ( R_f · C_in ) ] = 1 / 2
```

Скорочуємо на `R_f` і виражаємо `C_f²`:

```
C_f² = 2 · C_in / ( R_f · ω_t )
```

Підставляючи `ω_t = 2 · π · GBW`:

```
C_f = √[ C_in / ( π · R_f · GBW ) ]   або з урахуванням запасу фази 45°:   C_f = √[ C_in / ( 2 · π · R_f · GBW ) ]
```

### Виведення для критерію Бесселя (`ζ = √3/2`)
Для імпульсних оптичних систем (лідари, оптоволоконний зв'язок) перерегулювання неприпустиме, оскільки воно спотворює форму імпульсу та створює міжсимвольну інтерференцію. Фільтр Бесселя забезпечує лінійну фазо-частотну характеристику та постійний груповий час запізнення.

Прирівнюємо `ζ = √3 / 2`:

```
(R_f · C_f / 2) · √[ ω_t / ( R_f · C_in ) ] = √3 / 2
```

Підносимо до квадрата:

```
(R_f² · C_f² / 4) · [ ω_t / ( R_f · C_in ) ] = 3 / 4
```

Отримуємо:

```
C_f = √[ 3 · C_in / ( 2 · π · R_f · GBW ) ]
```

## 6. Смуга пропускання замкненого TIA

Частота зрізу підсилювача по рівню `-3 дБ` для налаштування Баттерворта збігається з власною частотою контуру `ω_0`:

```
f_-3dB = ω_0 / (2 · π) = (1 / (2 · π)) · √[ ω_t / ( R_f · C_in ) ]
```

Підставляючи `ω_t = 2 · π · GBW`:

```
f_-3dB
= (1 / (2 · π)) · √[ 2 · π · GBW / ( R_f · C_in ) ]
= √[ GBW / ( 2 · π · R_f · C_in ) ]
```

Співвідношення між смугою пропускання `f_-3dB` та частотою полюса ланки зворотного зв'язку `f_p = 1 / (2 · π · R_f · C_f)`:

```
f_-3dB = √2 · f_p
```

Це доводить, що активний TIA з глибоким від'ємним зворотним зв'язком розширює робочу смугу частот у `√(GBW / f_p)` разів порівняно з пасивним RC-колом на тому самому резисторі `R_f`.

## 7. Інтегральний шум напруги на виході TIA

Через підйом шумового підсилення `1/β(f)` на високих частотах вхідний шум напруги ОП `e_n` зазнає значного підсилення. Сумарна середньоквадратична напруга шуму на виході підсилювача в смузі від постійного струму до частоти зрізу `f_-3dB` обчислюється інтегруванням спектральної густини:

```
E_out_noise² = ∫₀^{f_-3dB} e_n² · |1/β(f)|² df
```

Підставляючи `|1/β(f)|² = 1 + (2 · π · f · R_f · C_in)²`:

```
E_out_noise²
= e_n² · ∫₀^{f_-3dB} [ 1 + 4 · π² · f² · R_f² · C_in² ] df
= e_n² · [ f_-3dB + (4/3) · π² · R_f² · C_in² · f_-3dB³ ]
```

Другий доданок описує явище шумового піка (Noise Peaking). За великої ємності `C_in` високочастотний інтегральний шум напруги починає домінувати над тепловим шумом резистора `R_f`, що підкреслює критичну важливість мінімізації вхідної паразитної ємності монтажу та кристала фотодіода.
