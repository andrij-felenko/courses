# ⚙️ Алгоритм подвійної корельованої вибірки та температурної компенсації

Цифрова обробка сигналу з оптичного фронтенду трансімпедансного підсилювача (TIA) усуває залишковий темновий струм фотодіода, напругу зсуву операційного підсилювача та низькочастотний флікер-шум `1/f`. Алгоритм поєднує синхронну подвійну корельовану вибірку (Correlated Double Sampling, CDS) зі швидкою температурною корекцією за аналітичною моделлю теплової генерації, оверсемплінгом, контролем стабілізації та динамічним перемиканням діапазонів чутливості (Auto-Ranging).

## 1. Математична модель подвійної корельованої вибірки (CDS)

Будь-який аналоговий вихідний сигнал фотодіодного підсилювача містить три фундаментальні компоненти: корисний світловий сигнал, паразитне постійне зміщення (темновий струм та напругу зсуву ОП) і випадковий шум.

У системах з імпульсним або модульованим джерелом світла (світлодіоди, лазери, оптичні затвори) вимірювальний процес розбивається на дві строго синхронізовані фази:

1. **Фаза темряви (Dark Acquisition):** джерело світла вимкнене (`LED = OFF`). АЦП реєструє вихідну напругу підсилювача:
```
S_dark = V_os · (1 + R_f / R_sh) + I_d(T) · R_f + e_noise(t_1)
```
де `V_os` — напруга зсуву ОП, `I_d(T)` — темновий струм за поточної температури кристала `T`, `e_noise(t_1)` — миттєве значення низькочастотного та теплового шуму в момент часу `t_1`.

2. **Фаза світла (Light Acquisition):** джерело світла вмикається (`LED = ON`). Після завершення перехідного процесу АЦП виконує другу вибірку:
```
S_light = V_os · (1 + R_f / R_sh) + (I_ph + I_d(T)) · R_f + e_noise(t_2)
```
де `I_ph` — корисний фотострум, пропорційний оптичній потужності випромінювання.

3. **Обчислення різниці вибірок:**
```
S_clean = S_light - S_dark = I_ph · R_f + [ e_noise(t_2) - e_noise(t_1) ]
```

Оскільки часовий інтервал між вибірками `Δt = t_2 - t_1` зазвичай становить від кількох мікросекунд до кількох мілісекунд, повільний температурний дрейф темнового струму та постійна напруга зсуву ОП є абсолютно однаковими в обох точках і взаємно знищуються з точністю до розрядності АЦП. Крім того, різницева операція діє як цифровий фільтр верхніх частот для внутрішнього шуму підсилювача, ефективно придушуючи шум `1/f`.

## 2. Аналітична модель температурної компенсації в неперервному режимі

Якщо оптичний тракт працює в неперервному (пасивному) режимі без можливості модулювати світловий потік (наприклад, у спектрометрах постійного освітлення, зоряних датчиках або пасивних сонячних радіометрах), метод CDS застосувати неможливо. У такому разі застосовують аналітичну модель експоненційної корекції.

Поруч із фотодіодом встановлюють прецизійний цифровий давач температури або мініатюрний NTC-терморезистор. Очікуваний темновий струм обчислюється в реальному часі за калібрувальною експонентою:

```
I_d(T) = I_d0 · 2^[ (T - T_0) / ΔT_double ]
```
де:
- `I_d0` — базовий темновий струм, виміряний під час заводського калібрування за температури `T_0` (зазвичай `+25.0 °C`);
- `ΔT_double` — температурний коефіцієнт подвоєння (для кремнієвих PIN-діодів становить `8.0...9.5 °C`, для InGaAs — `7.0...8.5 °C`);
- `T` — поточна температура корпусу фотоприймача.

Обчислений темновий струм віднімається від сумарного струму:

```
I_ph_clean = (V_adc / R_f) - I_d(T)
```

## 3. Часові інтервали, час стабілізації та придушення мережевого фону

Критичною помилкою при реалізації CDS є надто ранній запуск перетворення АЦП після вмикання джерела світла. Оскільки трансімпедансний підсилювач має власну смугу пропускання `f_-3dB` та сталу часу `τ = 1 / (2 · π · f_-3dB)`, вихідна напруга досягає сталого значення за експоненційним законом:

```
V_out(t) = V_final · ( 1 - exp[ -t / τ ] )
```

Щоб динамічна похибка перехідного процесу не перевищувала похибку квантування АЦП, інтервал затримки між фронтом імпульсу світла та початком вибірки `t_settle` повинен задовольняти вимогу:

- Для 12-бітного АЦП (похибка `< 0.024%` або `1 LSB`): `t_settle ≥ 8.3 · τ`.
- Для 16-бітного АЦП (похибка `< 0.0015%` або `1 LSB`): `t_settle ≥ 11.1 · τ`.

Якщо запустити перетворення АЦП раніше (наприклад, через `2 · τ`), залишковий недозаряд ємності `C_f` складе `13.5%`, що повністю зруйнує калібрування чутливості приладу.

### Придушення наведеного мережевого фону (Mains Hum Rejection)
Оптичні давачі в приміщеннях неминуче вловлюють паразитне електромагнітне та оптичне мерехтіння від освітлювальної мережі `50 Гц` (або `60 Гц`). Щоб повністю придушити цю гармоніку в цифровому тракті, тривалість інтегрування або період повторення циклів вибірки обирають строго кратним періоду мережі:

```
T_int = N / f_mains = N · 20 мс  (для 50 Гц)
```

Інтегрування сигналу протягом цілого числа періодів мережевої синусоїди знижує амплітуду завади `50/100 Гц` на `40...60 дБ` без додаткових аналогових фільтрів.

## 4. Оверсемплінг та узгодження шуму квантування

Для виділення слабких струмів, які лежать нижче одного кванта дискретизації АЦП, застосовують апаратний або програмний оверсемплінг (перевибірку) з децимацією.

Якщо власний аналоговий шум підсилювача `e_noise_rms` становить не менше `1...2 LSB` (діє як природний дизеринг, англ. *dither*), усереднення `M = 4^k` послідовних вибірок АЦП підвищує ефективну розрядність (ENOB) на `k` додаткових бітів:

```
ENOB_new = ENOB_base + 0.5 · log₂( M )
```

Наприклад, накопичення `M = 64` вибірок 12-бітного АЦП розширює роздільну здатність системи до `15 біт`, знижуючи середньоквадратичний шум квантування у 8 разів (`√64 = 8`).

## 5. Динамічне перемикання коефіцієнта підсилення (Auto-Ranging)

Якщо світловий потік змінюється на 4–6 порядків величини (наприклад, у вимірювачах оптичної густини розчинів або сонячних датчиках), один фіксований резистор `R_f` або призводить до насичення на яскравому світлі, або дає мізерний сигнал у темряві.

Для розширення динамічного діапазону в контур зворотного зв'язку TIA встановлюють кілька паралельних ланцюгів `R_f1 || C_f1` та `R_f2 || C_f2` (наприклад, `10 кОм`, `1 МОм`, `100 МОм`), які комутуються аналоговими ключами на польових транзисторах (CMOS Multiplexer із наднизьким витоком, наприклад ADG1412):

- Коли сигнал перевищує `90%` шкали АЦП, алгоритм автоматично вмикає менший резистор `R_f` (грубий діапазон).
- Коли сигнал падає нижче `5%` шкали, алгоритм перемикається на більший `R_f` (чутливий діапазон).
- Програмний драйвер масштабує обчислений струм на актуальне значення `R_f_active`.

## 6. Програмна реалізація модуля обробки

Нижче наведено модулі на C та C++, які реалізують кінцевий автомат вибірок, перевірку насичення вхідного каскаду, розрахунок CDS-різниці, IIR-фільтрацію ковзного середнього (Exponential Moving Average) та температурне оцінювання темнового фону.

```c
/* tia_filter.h / tia_filter.c — Драйвер оптичного фронтенду */
#include <stdint.h>
#include <stdbool.h>
#include <math.h>

typedef struct {
    float rf_ohms;              /* Опір зворотного зв'язку Rf (Ом) */
    float base_dark_current_a;  /* Базовий темновий струм Id0 за T0 (А) */
    float t0_celsius;           /* Базова температура калібрування T0 (°C) */
    float temp_doubling_step_c; /* Крок подвоєння струму (типово 8.5 °C) */
    float ema_alpha;            /* Коефіцієнт згладжування фільтра (0.01..1.0) */
    float v_adc_ref_v;          /* Опорна напруга АЦП (В) */
    float v_sat_margin_v;       /* Запас до межі живлення ОП (В) */
} TiaFilterConfig;

typedef struct {
    float filtered_output_v;
    float last_raw_dark_v;
    float last_raw_light_v;
} TiaFilterState;

typedef struct {
    float photocurrent_a;       /* Чистий виміряний фотострум (А) */
    float clean_voltage_v;      /* Очищена вихідна напруга сигналу (В) */
    float estimated_dark_a;     /* Оцінений темновий струм за поточної T (А) */
    bool is_saturated;          /* Прапорець насичення підсилювача */
    bool is_valid;              /* Прапорець валідності вимірювання */
} TiaFilterResult;

void tia_filter_init(TiaFilterState *state, const TiaFilterConfig *cfg) {
    state->filtered_output_v = 0.0f;
    state->last_raw_dark_v = 0.0f;
    state->last_raw_light_v = 0.0f;
}

/* Аналітичний розрахунок очікуваного темнового струму */
float tia_filter_calc_dark(const TiaFilterConfig *cfg, float temp_c) {
    float delta_t = temp_c - cfg->t0_celsius;
    float exponent = delta_t / cfg->temp_doubling_step_c;
    return cfg->base_dark_current_a * powf(2.0f, exponent);
}

/* Обробка циклу подвійної корельованої вибірки (CDS) */
TiaFilterResult tia_filter_process_cds(TiaFilterState *state,
                                       const TiaFilterConfig *cfg,
                                       float raw_dark_v,
                                       float raw_light_v,
                                       float current_temp_c) {
    TiaFilterResult res;
    state->last_raw_dark_v = raw_dark_v;
    state->last_raw_light_v = raw_light_v;

    /* Перевірка на перевантаження / вихід за лінійний діапазон */
    float max_linear_v = cfg->v_adc_ref_v - cfg->v_sat_margin_v;
    if (raw_light_v >= max_linear_v || raw_light_v <= cfg->v_sat_margin_v) {
        res.is_saturated = true;
        res.is_valid = false;
    } else {
        res.is_saturated = false;
        res.is_valid = true;
    }

    /* Віднімання темнового зміщення (CDS) */
    float delta_v = raw_light_v - raw_dark_v;
    if (delta_v < 0.0f) {
        delta_v = 0.0f; /* Відсікання від'ємних шумових сплесків */
    }

    /* Експоненційне згладжування (IIR-фільтр низьких частот) */
    state->filtered_output_v = (cfg->ema_alpha * delta_v) +
                               ((1.0f - cfg->ema_alpha) * state->filtered_output_v);

    res.clean_voltage_v = state->filtered_output_v;
    res.photocurrent_a = state->filtered_output_v / cfg->rf_ohms;
    res.estimated_dark_a = tia_filter_calc_dark(cfg, current_temp_c);

    return res;
}
```

```cpp
// TiaFilter.hpp — Ідіоматичний C++20 модуль обробки оптичного фронтенду
#pragma once
#include <cmath>
#include <optional>
#include <concepts>
#include <span>

template <std::floating_point FloatT = float>
class PhotodiodeFrontEndProcessor {
public:
    struct Config {
        FloatT rf_ohms{1.0e6f};             // Опір зворотного зв'язку Rf = 1 МОм
        FloatT base_dark_current_a{10.0e-12f};// Базовий темновий струм 10 пА при 25 °C
        FloatT t0_celsius{25.0f};           // Температура калібрування
        FloatT temp_doubling_celsius{8.5f}; // Крок подвоєння темнового струму
        FloatT ema_alpha{0.15f};            // Коефіцієнт експоненційного згладжування
        FloatT v_adc_ref{3.3f};             // Опорна напруга АЦП
        FloatT v_sat_margin{0.05f};         // Межа насичення виходу ОП
    };

    struct Measurement {
        FloatT photocurrent_amperes;
        FloatT clean_voltage;
        FloatT estimated_dark_amperes;
        bool saturated;
    };

    constexpr explicit PhotodiodeFrontEndProcessor(const Config& config) noexcept
        : cfg_(config), filtered_voltage_(0) {}

    [[nodiscard]] FloatT estimate_dark_current(FloatT temp_celsius) const noexcept {
        const FloatT delta_t = temp_celsius - cfg_.t0_celsius;
        const FloatT exponent = delta_t / cfg_.temp_doubling_celsius;
        return cfg_.base_dark_current_a * std::pow(static_cast<FloatT>(2), exponent);
    }

    [[nodiscard]] std::optional<Measurement> process_sample(FloatT dark_sample_v,
                                                            FloatT light_sample_v,
                                                            FloatT current_temp_c) noexcept {
        const FloatT max_linear_v = cfg_.v_adc_ref - cfg_.v_sat_margin;
        const bool saturated = (light_sample_v >= max_linear_v) ||
                               (light_sample_v <= cfg_.v_sat_margin);

        FloatT delta_v = light_sample_v - dark_sample_v;
        if (delta_v < static_cast<FloatT>(0)) {
            delta_v = static_cast<FloatT>(0);
        }

        // Експоненційне згладжування (EMA)
        filtered_voltage_ = (cfg_.ema_alpha * delta_v) +
                            ((static_cast<FloatT>(1) - cfg_.ema_alpha) * filtered_voltage_);

        if (saturated) {
            return std::nullopt; // Каскад перевантажений, дані нелінійні
        }

        return Measurement{
            .photocurrent_amperes = filtered_voltage_ / cfg_.rf_ohms,
            .clean_voltage = filtered_voltage_,
            .estimated_dark_amperes = estimate_dark_current(current_temp_c),
            .saturated = false
        };
    }

    void reset() noexcept {
        filtered_voltage_ = static_cast<FloatT>(0);
    }

private:
    Config cfg_;
    FloatT filtered_voltage_;
};
```

## 7. Калібрування індивідуального давача

Через виробничий розкид параметрів кремнієвих пластин площа кристала та концентрація дефектів варіюються між партіями фотодіодів. Точне визначення індивідуального коефіцієнта `ΔT_double` виконують двоточковим термічним калібруванням:

1. Фотодіод затінюють і поміщають у термокамеру.
2. Вимірюють темновий струм за двох фіксованих температур: `T_1 = +25 °C` (`I_d1`) та `T_2 = +65 °C` (`I_d2`).
3. Розраховують індивідуальний крок подвоєння:
```
ΔT_double = (T_2 - T_1) / [ log₂( I_d2 / I_d1 ) ]
```
4. Обчислене значення записують у незалежну пам'ять (EEPROM або Flash) мікроконтролера під час фінального тестування виробу на виробничій лінії.
