# Фізика напівпровідникового фотоприймача

<preknowlist>
- [Напівпровідник](root:ph-condensed/semiconductor) — зонна структура кристала, валентна зона, зона провідності та енергетична щілина забороненої зони `E_g`.
- [p-n перехід](root:ph-condensed/pn-junction) — дифузійний контакт напівпровідників p- та n-типу, виникнення вбудованого електричного поля та збідненої області.
- [Фотон](root:ph-quantum/photon) — квант світла з дискретною енергією `E = h · ν = (h · c) / λ` та імпульсом `p = h / λ`.
- [Трансімпедансний підсилювач](root:hw-analog/transimpedance-amplifier) — операційна схема перетворення слабкого струму на напругу із нульовим вхідним потенціалом.
</preknowlist>

Коли світловий промінь падає на однорідний напівпровідниковий кристал, фотони проникають углиб речовини зі швидкістю світла, але для зовнішнього електронного кола кристал лишається глухим ізолятором, якщо народжені світлом носії заряду рекомбінують на тому самому місці за частки наносекунди. Щоб перетворити оптичне випромінювання на електричний сигнал, прилад мусить виконати три нерозривні фізичні процеси: поглинути квант світла з перекиданням електрона через заборонену зону, просторово розвести утворену пару «електрон-дірка» до моменту її теплової загибелі й вивести розділений заряд у зовнішній провідник крізь металеві контакти.

Якщо хоча б одна з цих ланок дає збій — фотон пролітає напівпровідник наскрізь через малу енергію, носії рекомбінують на дефектах кристалічної ґратки або повільно повзуть крізь нейтральну товщу бази, — датчик втрачає чутливість або спотворює форму швидкого оптичного імпульсу. Робота фотодіода спирається на внутрішній фотоелектричний ефект у зоні просторового заряду [p-n переходу](root:ph-condensed/pn-junction), де сильне внутрішнє електричне поле перехоплює новонароджені носії за пікосекунди, формуючи фотострум, пропорційний інтенсивності світлового потоку.

![Внутрішній фотоефект і поділ носіїв у p-n переході](/root/hw/hw-sensing/photodetector-physics/img/photodetection-mechanism.svg)
*Квантовий механізм фотодетекції у p-n переході. Фотон із енергією h·ν ≥ Eg вибиває електрон із валентної зони у зону провідності. У збідненій області сильне електричне поле миттєво зриває пару: електрон дрейфує до n-катода, дірка — до p-анода. Поглинання в глибині нейтральної бази змушує носії повільно дифундувати, затягуючи задній фронт сигналу.*

## 1. Внутрішній фотоефект і просторове поглинання світла

В основі роботи напівпровідникових фотодетекторів лежить явище внутрішнього фотоефекту: квант електромагнітного випромінювання передає свою енергію електрону кристалічної ґратки, переводячи його зі зв'язаного стану у валентній зоні `E_v` у вільний стан у зоні провідності `E_c`.

Для здійснення міжзонного оптичного переходу енергія фотона `E_ph` повинна перевищувати ширину забороненої зони напівпровідника `E_g`:

```
E_ph = h · ν = (h · c) / λ ≥ E_g

h ≈ 6.62607 × 10⁻³⁴ Дж·с     [стала Планка]
c ≈ 2.99792 × 10⁸ м/с        [швидкість світла у вакуумі]
ν                            [частота коливань світлової хвилі, Гц]
λ                            [довжина хвилі випромінювання у вакуумі, м]
E_g                          [ширина забороненої зони, еВ або Дж]
```

Якщо енергія кванта менша за `E_g` (`h · ν < E_g`), електрон не може подолати заборонену зону, оскільки в ідеальному кристалі немає дозволених квантових станів між `E_v` та `E_c`. За такої умови напівпровідник стає оптично прозорим: фотони проходять крізь товщу кристала практично без поглинання (не враховуючи незначних втрат на вільних носіях та дефектах ґратки).

### Закон Бугера — Ламберта — Бера та глибина проникнення

Світловий потік, падаючи на поверхню напівпровідника вздовж осі `x`, експоненційно затухає в міру просування вглиб матеріалу згідно із законом Бугера — Ламберта — Бера:

```
P(x) = P_0 · (1 - R_opt) · e^(-α(λ) · x)

P_0          [потужність оптичного випромінювання, що падає на поверхню, Вт]
R_opt        [коефіцієнт відбиття від поверхні напівпровідника]
α(λ)         [коефіцієнт оптичного поглинання матеріалу, см⁻¹]
x            [глибина проникнення від освітленої поверхні, см]
```

Коефіцієнт відбиття на межі розділу повітря-напівпровідник визначається показником заломлення `n_opt`:

```
R_opt = ((n_opt - 1) / (n_opt + 1))²
```

Для кремнію з показником заломлення `n_opt ≈ 3.5` коефіцієнт відбиття чистої поверхні становить `R_opt ≈ 0.31` (31% світлової енергії відбивається назад). З цієї причини на оптичні вікна промислових фотодіодів наносять чвертьхвильові просвітлювальні покриття з діелектриків (`Si₃N₄`, `SiO₂`, `TiO₂`), які знижують відбиття до рівня менше 1% на робочій довжині хвилі.

Величина `δ(λ) = 1 / α(λ)` визначає характерну глибину проникнення світла (товщину шару, на якій потужність променя зменшується в `e ≈ 2.718` разів). Коефіцієнт поглинання `α(λ)` критично залежить від квантової природи зонної структури:

1. **Прямозонні напівпровідники (Direct Bandgap: GaAs, InGaAs, InP).** Мінімум зони провідності та максимум валентної зони розташовані при однаковому квазіімпульсі електрона `k = 0`. Оптичний перехід відбувається вертикально на зонній діаграмі без залучення коливань ґратки. Коефіцієнт поглинання колосальний: `α > 10⁴–10⁵ см⁻¹`. Світло повністю поглинається у надтонкому шарі завтовшки `0.5–2 мкм`.
2. **Непрямозонні напівпровідники (Indirect Bandgap: Si, Ge).** Мінімум зони провідності зміщений за квазіімпульсом відносно максимуму валентної зони. Фотон майже не несе механічного імпульсу, тому закон збереження імпульсу вимагає одночасного народження або поглинання фонона (кванта теплових коливань ґратки). Тричастинковий процес (електрон + фотон + фонон) має значно меншу ймовірність.

У кремнії поблизу червоної межі поглинання (`λ = 900–1060 нм`) коефіцієнт `α` падає до значень `10²–10³ см⁻¹`. Для поглинання 90% інфрачервоного випромінювання неодимового лазера (`1064 нм`) товщина кристала кремнію повинна становити сотні мікрометрів. Навпаки, синє та ультрафіолетове світло (`λ = 350–450 нм`) має енергію, достатню для прямих переходів вище забороненої зони, тому поглинається у перших `0.1–0.3 мкм` від поверхні.

## 2. Розділення носіїв заряду: Дрейфовий та дифузійний транспорт

Саме по собі народження пари «електрон-дірка» в нейтральному напівпровіднику не створює струму у зовнішньому колі: рух носіїв залишається хаотичним тепловим блуканням, і через середній час життя `τ` носії стикаються та рекомбінують, перетворюючи енергію назад у тепло (безвипромінювальна рекомбінація Оже або рекомбінація через пастки) чи випромінюючи фотон.

Щоб сформувати струм, необхідно створити просторовий градієнт потенціалу, який розтягне заряджені частинки у протилежні боки швидше, ніж настане рекомбінація. Цю функцію виконує [p-n перехід](root:ph-condensed/pn-junction).

У стані рівноваги внаслідок дифузії основних носіїв на межі p- та n-областей утворюється збіднена область (шар просторового заряду) шириною `W`, звідки витіснені вільні носії. Нескомпенсовані іонізовані донори (`N_d⁺`) в n-області та акцептори (`N_a⁻`) в p-області створюють вбудовану контактну різницю потенціалів `V_bi`:

```
V_bi = (k_B · T / q) · ln( (N_a · N_d) / n_i² )

k_B ≈ 1.38065 × 10⁻²³ Дж/К   [стала Больцмана]
T                            [абсолютна температура кристала, К]
q ≈ 1.60218 × 10⁻¹⁹ Кл       [елементарний електричний заряд]
n_i                          [власна концентрація носіїв, для Si ≈ 1.5 × 10¹⁰ см⁻³ при 300 K]
```

Для кремнієвого діода з типовими рівнями легування `V_bi ≈ 0.65–0.85 В`. Напруженість електричного поля всередині збідненої області досягає `E = 10⁴–10⁵ В/см`.

Ширина збідненої області `W` для різкого несиметричного `p⁺-n` переходу (де концентрація дірок в аноді `N_a ≫ N_d`) залежить від прикладеної зворотної напруги `V_R`:

```
W(V_R) = √((2 · ε_0 · ε_r · (V_bi + V_R)) / (q · N_d))

ε_0 ≈ 8.85419 × 10⁻¹² Ф/м    [електрична стала]
ε_r                          [відносна діелектрична проникність, для Si ε_r ≈ 11.7]
V_R                          [величина зворотної напруги зміщення, В]
```

### Дві зони збору носіїв: Дрейф проти дифузії

Залежно від того, де саме просторово поглинувся фотон, доля народжених носіїв розгортається за двома принципово різними сценаріями:

1. **Генерація всередині збідненого шару `W`.** Потужне електричне поле миттєво підхоплює електрони та дірки. Носії рухаються у режимі дрейфу (drift transport): електрони зміщуються у напрямку катода (n-бази), дірки — до анода (p-шару). Оскільки напруженість поля перевищує критичну межу `E_crit ≈ 10⁴ В/см`, носії розганяються до швидкості насичення (saturation velocity `v_sat ≈ 10⁷ см/с = 100 мкм/нс` для кремнію). Час прольоту збідненого шару становить:
   ```
   t_drift = W / v_sat ≈ 10⁻¹¹–10⁻¹⁰ с   (10–100 пікосекунд)
   ```
   Увесь заряд встигає повністю перейти в контакти без рекомбінації.

2. **Генерація у нейтральних областях кристала.** Якщо фотон поглинається в нейтральній n-базі на відстані `x` від збідненого шару, електричного поля там немає (`E ≈ 0`). Неосновні носії (дірки) здійснюють хаотичну теплову дифузію. Тільки ті дірки, які за час життя `τ_p` випадково дійдуть до межі збідненої зони на відстані, меншій за дифузійну довжину `L_p = √(D_p · τ_p)` (де `D_p` — коефіцієнт дифузії), підхоплюються полем і створюють струм. Час дифузійного переносу на відстань `d` вимірюється наносекундами та мікросекундами:
   ```
   t_diff ≈ d² / (2 · D_p) ≈ 10⁻⁹–10⁻⁷ с   (1–100 наносекунд)
   ```

Дифузійний транспорт формує характерний тривалий спадний «хвіст» (diffusion tail) у часовому відгуку фотодіода. При опроміненні прямокутним світловим імпульсом дрейфова складова наростає миттєво за пікосекунди, тоді як дифузійна частина повзе повільно, різко обмежуючи граничну смугу пропускання фотоприймача.

> 🔧 **Навіщо це.** В оптичних лініях передачі даних (Ethernet 10G/100G, волоконно-оптичні приймачі) стандартні p-n діоди не застосовують через повільну дифузію з бази. Замість них використовують PIN-фотодіоди, де між `p⁺` та `n⁺` шарами введено широкий власний нелегований i-шар (intrinsic). Збіднена область займає 100% активного об'єму (`W ≈ d_i`), і 100% світла поглинається виключно в полі дрейфу, виключаючи дифузійне затягування фронтів.

## 3. Спектральна чутливість і квантовий вихід

Кількісну здатність фотоприймача перетворювати оптичну потужність у струм описують двома взаємопов'язаними параметрами: квантовою ефективністю `η(λ)` та спектральною чутливістю `R(λ)`.

### Квантова ефективність (Quantum Efficiency)

Зовнішня квантова ефективність `η(λ)` (Quantum Efficiency, QE) — це безрозмірне відношення кількості зібраних у зовнішньому колі електронно-діркових пар `N_e` до кількості фотонів `N_ph`, що впали на фоточутливу площадку за одиницю часу:

```
η(λ) = N_e / N_ph = (I_ph / q) / (P_opt / (h · ν))
```

Фізично квантова ефективність складається з трьох послідовних множників:

```
η(λ) = (1 - R_opt) · ζ · η_col(λ)

(1 - R_opt)      [частка світла, що проникла крізь поверхню без відбиття]
ζ                [внутрішній квантовий вихід генерації, для h·ν ≥ Eg зазвичай ζ = 1]
η_col(λ)         [коефіцієнт збору носіїв у збідненій області та зоні дифузії]
```

Коефіцієнт збору `η_col` описує частку згенерованих носіїв, які не рекомбінували до потрапляння в контакти. Для збідненої області товщиною `W` та глибини дифузійного збору `L_p` аналітичний вираз має вигляд:

```
η_col(λ) ≈ 1 - (e^(-α(λ) · W) / (1 + α(λ) · L_p))
```

Якщо товщина `W` значно перевищує глибину проникнення світла (`α · W ≫ 1`), майже все світло поглинається у полі, і `η_col → 1`.

*Спектральні характеристики кремнію (Si), германію (Ge) та InGaAs. Пунктирна лінія — теоретична межа при η = 100%. Лінійне зростання R(λ) обумовлене тим, що за однакової потужності довгохвильове світло несе більше фотонів. На червоній межі λ_max енергія кванта падає нижче Eg, і чутливість спадає до нуля.*

### Монохроматична спектральна чутливість (Responsivity)

Спектральна чутливість `R(λ)` (Responsivity) виражає відношення згенерованого фотоструму `I_ph` до потужності монохроматичного оптичного випромінювання `P_opt` на довжині хвилі `λ`:

```
R(λ) = I_ph / P_opt = (η(λ) · q · λ) / (h · c)   [А/Вт]
```

Підставивши значення фізичних фундаментальних констант `q`, `h` та `c`, отримуємо практичну інженерну формулу розрахунку:

```
R(λ) = (η(λ) · λ [мкм]) / 1.23984   [А/Вт]

де λ виражено в мікрометрах (1 мкм = 1000 нм).
```

Звідси випливає фундаментальна властивість спектральної чутливості: **при сталій квантовій ефективності `η` чутливість `R(λ)` лінійно зростає зі збільшенням довжини хвилі `λ`**.

Це пояснюється квантовою природою світла: оптична потужність `P_opt` — це добуток кількості фотонів за секунду `N_ph` на енергію одного фотона `h · c / λ`. При переході від фіолетового світла (`400 нм`) до ближнього інфрачервоного (`1000 нм`) енергія кожного окремого фотона зменшується у 2.5 раза. Отже, один ват інфрачервоного випромінювання містить у 2.5 раза більше фотонів, ніж один ват фіолетового, і за умови збереження `η` генерує у 2.5 раза більший струм.

### Червона межа фотоефекту

Максимальна довжина хвилі, яку здатен зареєструвати напівпровідниковий фотоприймач, зветься **червоною (довгохвильовою) межею фотоефекту** `λ_max`. Вона визначається умовою рівності енергії фотона ширині забороненої зони `E_g`:

```
λ_max = (h · c) / E_g ≈ 1.23984 / E_g [еВ]   [мкм]
```

|:---|:---|:---|:---|:---|:---|
| **Кремній (Si)** | Непрямозонний | 1.12 | 1107 | 0.65 (при 900 нм) | Видиме світло, NIR, лазери 850/905 нм, сонячні елементи |
| **Германій (Ge)** | Непрямозонний | 0.66 | 1878 | 0.75 (при 1550 нм) | Ранні телекомунікації, спектроскопія (високий темновий струм) |
| **InGaAs (`In_0.53Ga_0.47As`)** | Прямозонний | 0.73 | 1700 | 0.98 (при 1550 нм) | Волоконна оптика 1310/1550 нм, SWIR камери, лідари 1550 нм |
| **InAs** | Прямозонний | 0.35 | 3540 | 1.20 (при 3000 нм) | Середній ІЧ діапазон (MWIR), газоаналізатори |
| **GaAs** | Прямозонний | 1.42 | 873 | 0.55 (при 800 нм) | Швидкодіючі приймачі, сонячні батареї космосу |

У короткохвильовій ділянці спектра (УФ та синє світло) чутливість усіх матеріалів стрімко падає не через заборонену зону, а внаслідок надвисокого поглинання (`α > 10⁶ см⁻¹`): фотони гинуть у перших 10–50 нм приповерхневого шару, де густина поверхневих дефектів кристала максимальна, спричиняючи майже 100% рекомбінацію носіїв до їх розділення полем.

## 4. Режими увімкнення: Фотогальванічний проти Фотопровідного

Вольт-амперна характеристика (ВАХ) освітленого фотодіода описується рівнянням Шоклі, зміщеним за віссю струму на величину фотоструму `I_ph`:

```
I(V) = I_s · (e^(q · V / (k_B · T)) - 1) - I_ph

I_s          [струм теплового насичення закритого переходу, А]
V            [напруга на аноді відносно катода, В]
I_ph         [генерований світлом фотострум, прямо пропорційний P_opt, А]
```

![Вольт-амперна характеристика: фотовольтаїчний та фотопровідний режими](/root/hw/hw-sensing/photodetector-physics/img/photodiode-iv-quadrants.svg)
*ВАХ фотодіода в чотирьох квадрантах. Фотогальванічний режим (V = 0) розташований на межі III та IV квадрантів: темновий струм відсутній, шум мінімальний. Фотопровідний режим (зворотна напруга −VR) лежить у III квадранті на пологій поличці струму: ємність спадає, швидкодія зростає до гігагерцового діапазону.*

### Фотогальванічний режим (Photovoltaic Mode, `V = 0`)

У фотогальванічному режимі зовнішня напруга зміщення не подається (`V_R = 0`). Фотодіод підключається або до високоомного навантаження (режим холостого ходу), або до віртуальної землі [трансімпедансного підсилювача](root:hw-analog/transimpedance-amplifier) (режим короткого замикання).

1. **Режим короткого замикання (`V = 0`):**
   При нульовій різниці потенціалів діодна складова струму точно дорівнює нулю:
   ```
   I = I_s · (e^0 - 1) - I_ph = -I_ph
   ```
   Струм у навантаженні строго дорівнює фотоструму й лінійно залежить від світлової потужності в межах 6–8 порядків величини.

2. **Переваги режиму:**
   - **Нульовий темновий струм (`I_dark = 0`):** Оскільки прикладена напруга дорівнює нулю, струм витоку відсутній.
   - **Мінімальний шум:** Відсутній дробовий шум темнового струму `2 · q · I_dark · Δf`. Єдиним джерелом шуму фотодіода лишається тепловий шум Джонсона еквівалентного паралельного опору шунтування `R_sh`:
     ```
     i_n,th = √((4 · k_B · T / R_sh) · Δf)
     ```
   - **Відсутність температурного дрейфу зміщення нуля:** Ідеально для прецизійних вимірювачів освітленості, аналітичних спектрофотометрів та пірометрів.

3. **Плата за тишу — низька швидкодія:**
   При `V_R = 0` ширина збідненої зони `W_0` мінімальна і визначається лише контактною різницею потенціалів `V_bi` (`W_0 ≈ 0.3–1.0 мкм`). Відповідно, бар'єрна ємність переходу `C_j` максимальна:
   ```
   C_j0 = (ε_0 · ε_r · A) / W_0
   ```
   Для діода площею `A = 1 мм²` ємність `C_j0` становить `100–500 пФ`. Разом із вхідним опором схеми вона утворює інтегрувальний RC-ланцюг із частотою зрізу всього `10–500 кГц`.

### Фотопровідний режим (Photoconductive Mode, `V_R > 0`)

У фотопровідному режимі до катода фотодіода прикладають додатний потенціал відносно анода (зворотна напруга `V_R` від 3 до 50 В). Робоча точка зміщується глибоко в III квадрант ВАХ на горизонтальну поличку насичення.

1. **Фізичні процеси під зворотним зміщенням:**
   - **Розширення збідненої області:** Зростання падіння напруги `V_bi + V_R` розсуває межі просторового заряду: `W ∝ √(V_bi + V_R)`.
   - **Падіння бар'єрної ємності:** Ємність переходу різко падає обернено пропорційно кореню з напруги:
     ```
     C_j(V_R) = C_j0 / √(1 + V_R / V_bi)
     ```
     Зворотна напруга 10–20 В зменшує ємність у 4–6 разів (від 100 пФ до 15–25 пФ), розширюючи RC-смугу до сотень мегагерців або гігагерців.
   - **Прискорення дрейфу:** Електричне поле перевищує `10⁵ В/см`, переводячи 100% носіїв у стан граничної дрейфової швидкості `v_sat`.
   - **Покращення лінійності на високих потужностях:** Широка збіднена зона запобігає просторовому екрануванню поля об'ємним зарядом фотоструму (ефект насичення насипаним зарядом).

2. **Плата за швидкість — темновий струм і шум:**
   Зворотна напруга витягує з кристала тепловий струм витоку `I_dark(V_R)`. Цей струм породжує непереборний дробовий шум (shot noise):
   ```
   i_n,shot = √(2 · q · (I_ph + I_dark) · Δf)
   ```
   Крім того, темновий струм експоненційно зростає з температурою, створюючи дрейф нульового рівня вимірювального тракту.

| Параметр | Фотогальванічний (`V_R = 0`) | Фотопровідний (`V_R > 0`) |
|:---|:---|:---|
| **Зворотна напруга зміщення** | 0 В | 3...50 В |
| **Темновий струм `I_dark`** | 0 (відсутній) | 0.1 нА ... 10 мкА (залежить від площі й матеріалу) |
| **Власна ємність `C_j`** | Максимальна (`C_j0`) | Мінімальна (у 3–10 разів менша за `C_j0`) |
| **Швидкодія / Смуга частот** | Низька (DC ... сотні кГц) | Надвисока (до 1–40 ГГц) |
| **Рівень власних шумів** | Мінімальний (лише шум Джонсона `R_sh`) | Підвищений (дробовий шум `I_dark`) |
| **Типові застосування** | Люксметри, медичні датчики, прецизійні DC фотометри | Волоконний зв'язок, лазерні лідари (ToF), фотопомножувачі |

## 5. Анатомія темнового струму

Темновий струм (Dark Current) `I_dark` — це паразитичний струм, що протікає крізь фотодіод під дією зворотної напруги за повної відсутності світла. Він складається з трьох фізично незалежних компонентів:

```
I_dark = I_diff + I_gen + I_surf
```

### 1. Дифузійний струм насичення (`I_diff`)

Дифузійний струм виникає внаслідок теплової генерації неосновних носіїв у нейтральних p- та n-областях кристала на відстанях, менших за дифузійну довжину `L_n`, `L_p` від меж переходу. Він описується класичною формулою Шоклі:

```
I_diff = q · A · ( (D_n · n_p0 / L_n) + (D_p · p_n0 / L_p) ) ∝ T³ · e^(-E_g / (k_B · T))
```

Оскільки концентрація неосновних носіїв у нейтральній зоні `n_p0 = n_i² / N_a ∝ e^(-E_g / (k_B · T))`, дифузійний струм пропорційний експоненті від повної ширини забороненої зони `E_g`. У кремнії при кімнатній температурі (`E_g = 1.12 еВ`) ця величина мізерно мала (пікоампери на см²), але вона експоненційно зростає з температурою і стає домінуючою при `T > 70–80 °C`.

### 2. Струм теплової генерації у збідненій зоні (`I_gen`)

Усередині збідненого шару вільних носіїв немає, тому термодинамічна рівновага порушена: швидкість рекомбінації прямує до нуля, а процес теплової генерації пар триває безупинно через глибокі енергетичні рівні пасток у середині забороненої зони (механізм Шоклі — Ріда — Холла, SRH):

```
I_gen = (q · n_i · W(V_R) · A) / (2 · τ_g)

n_i ∝ T^(3/2) · e^(-E_g / (2 · k_B · T))   [власна концентрація носіїв]
τ_g                                       [ефективний час життя генерації носіїв]
W(V_R)                                    [ширина збідненої області]
```

Оскільки `n_i` пропорційна `e^(-E_g / (2 · k_B · T))`, температурна експонента містить половинну ширину зони `E_g / 2`. Саме струм генерації `I_gen` є **головним джерелом темнового струму кремнієвих фотодіодів при кімнатній температурі**.

Зверніть увагу на залежність від напруги: оскільки `W(V_R) ∝ √(V_bi + V_R)`, генераційний струм повільно зростає при підвищенні зворотної напруги зміщення як квадратний корінь із напруги.

### 3. Поверхневий струм витоку (`I_surf`)

Кристалічна ґратка напівпровідника обривається на поверхні кристала, утворюючи високу концентрацію обірваних зв'язків, поверхневих дефектів та адсорбованих іонів. Це створює паразитичні провідні канали вздовж оксидного шару `SiO₂` на периметрі p-n переходу:

```
I_surf ∝ V_R / R_surface
```

Поверхневий струм лінійно залежить від зворотної напруги й контролюється технологією пасивації поверхні та геометрією спеціальних захисних кілець (guard rings), які перехоплюють поверхневий заряд і відводять його повз вимірювальне коло.

### Температурне правило подвоєння

Оскільки власна концентрація `n_i(T)` експоненційно зростає з температурою, темновий струм кремнієвого фотодіода підпорядковується простому інженерному правилу:

```
I_dark(T) = I_dark(T_0) · 2^((T - T_0) / ΔT_2)
```

Для кремнію темновий струм **подвоюється кожні 8–10 °C підвищення температури** кристала. Зростання температури від 25 °C до 75 °C призводить до збільшення темнового струму у `2⁵ = 32` рази, пропорційно піднімаючи рівень дробового шуму приймача у `√32 ≈ 5.6` раза.

## 6. Еквівалентна схема та компроміс смуги пропускання

Для розрахунку частотних, шумових і перехідних характеристик фотоприймального каскаду фотодіод представляють інженерною зосередженою еквівалентною схемою.

![Еквівалентна схема фотодіода та компроміс смуги пропускання f_3dB](/root/hw/hw-sensing/photodetector-physics/img/equivalent-circuit-bandwidth.svg)
*Еквівалентна схема заміщення фотодіода та оптимізація частотної смуги. При малій товщині W смугу обмежує бар'єрна ємність переходу Cj (f_RC). При великій W смуга падає через тривалий час прольоту носіїв крізь шар (f_transit). Оптимум W_opt відповідає максимуму результуючої частоти f_3dB.*

Схема містить шість елементів:

1. **`I_ph` — ідеальне джерело фотоструму:** струм, згенерований світлом (`I_ph = R(λ) · P_opt`), направлений від катода до анода.
2. **`D` — діодний перехід:** підпорядковується рівнянню Шоклі, визначає пряму ВАХ.
3. **`C_j(V_R)` — бар'єрна ємність збідненої області:** визначається площею `A`, товщиною `W(V_R)` та діелектричною проникністю напівпровідника.
4. **`R_sh` — паралельний опір шунтування (Shunt Resistance):** опір витоку закритого p-n переходу при нульовій напрузі (для кремнію становить від 100 МОм до десятків ГОм).
5. **`R_s` — послідовний опір (Series Resistance):** сумарний опір квазінейтрального об'єму напівпровідникової підкладки, омічних металевих контактів та виводів корпусу (типово 5–50 Ом).
6. **`R_load` — опір зовнішнього навантаження:** опір резистора узгодження (наприклад, 50 Ом) або вхідний динамічний опір трансімпедансного каскаду.

### Три фізичні обмеження швидкодії

Результуюча гранична частота зрізу фотодіода за рівнем −3 дБ (`f_3dB`) формується суперпозицією трьох незалежних фізичних часових констант:

```
1 / (f_3dB)² = (1 / f_RC)² + (1 / f_transit)² + (1 / f_diff)²
```

1. **RC-обмеження електричного кола (`f_RC`):**
   Визначається часом заряджання власної ємності `C_j` та паразитної ємності монтажу `C_p` через повний еквівалентний послідовний опір кола `R_tot = R_s + R_load`:
   ```
   τ_RC = (R_s + R_load) · (C_j(V_R) + C_p)
   f_RC = 1 / (2 · π · τ_RC) = 1 / (2 · π · (R_s + R_load) · (C_j + C_p))
   ```
   Оскільки `C_j = ε · A / W`, збільшення товщини `W` зменшує ємність і піднімає `f_RC` лінійно з `W`.

2. **Обмеження часом прольоту дрейфу (`f_transit`):**
   Визначається часом, необхідним носіям для дрейфового перетину збідненої області `W` із насиченою швидкістю `v_sat`:
   ```
   t_drift = W / v_sat
   f_transit ≈ 0.443 / t_drift = (0.443 · v_sat) / W
   ```
   Зі зростанням `W` час прольоту росте, а частота `f_transit` падає пропорційно `1 / W`.

3. **Обмеження часом дифузії (`f_diff`):**
   Для носіїв, що народилися за межами збідненої зони в нейтральній базі товщиною `d_base`:
   ```
   f_diff ≈ (2 · D) / (π · d_base²)
   ```
   У правильно спроєктованих високошвидкісних детекторах (PIN-структури або діоди зворотного освітлення) нейтральну зону роблять тоншою за 0.1 мкм, виключаючи дифузійний внесок із формули (`1 / f_diff ≈ 0`).

### Оптимізація товщини збідненої області

Інженер стикається з фундаментальним конструктивним компромісом щодо товщини збідненої зони `W`:
- **Мала товщина `W`:** Квантова ефективність `η` падає (світло не встигає поглинутися), ємність `C_j` велика, схема гальмується за `RC`-ланцюгом (`f_RC ≪ f_transit`).
- **Велика товщина `W`:** Квантова ефективність висока, ємність `C_j` мізерна, але носії довго летять крізь товщу кристала, сповільнюючи відгук за часом прольоту (`f_transit ≪ f_RC`).

Максимум смуги пропускання досягається в точці балансу, коли час розряджання ємності зрівнюється з часом прольоту носіїв (`τ_RC ≈ t_drift`):

```
W_opt ≈ √((0.443 · v_sat · (R_s + R_load) · ε_0 · ε_r · A) / 1)
```

## 7. Шуми, поріг чутливості (NEP) та виявна здатність

Мінімальний оптичний сигнал, який здатен зареєструвати фотодіод, обмежений фундаментальними флуктуаціями струму в кристалі та схемі зчитування.

### Складові шуму фотодіода

1. **Дробовий шум (Shot Noise):** обумовлений дискретною квантовою природою електричного заряду (потік окремих електронів). Виникає як від корисного фотоструму `I_ph`, так і від паразитного темнового струму `I_dark`:
   ```
   i_n,shot = √(2 · q · (I_ph + I_dark) · Δf)   [А]
   ```

2. **Тепловий шум Джонсона — Найквіста (Thermal Noise):** породжується хаотичним тепловим рухом носіїв заряду в опорі шунтування `R_sh` та послідовному опорі `R_s`:
   ```
   i_n,th = √((4 · k_B · T / R_sh) · Δf)   [А]
   ```

Повний середньоквадратичний шумовий струм фотодіода в смузі частот `Δf`:

```
i_n,total = √( (2 · q · (I_ph + I_dark) + (4 · k_B · T / R_sh)) · Δf )
```

### Еквівалентна потужність шуму (NEP)

**NEP (Noise Equivalent Power)** — це оптична потужність сигналу, що падає на фотодіод, за якої відношення сигналу до шуму на виході дорівнює одиниці (SNR = 1) в смузі вимірювання 1 Гц:

```
NEP = i_n,total / (R(λ) · √Δf)   [Вт / √Гц]
```

Для кремнієвого фотодіода в темряві (`I_ph = 0`) у фотопровідному режимі (де домінує темновий струм `I_dark`):

```
NEP ≈ √(2 · q · I_dark) / R(λ)   [Вт / √Гц]
```

Чим менше числове значення NEP, тим слабкіший світловий імпульс може зафіксувати приймач на тлі власного шуму. Типові значення NEP для кремнієвих фотодіодів становлять `10⁻¹⁴–10⁻¹⁵ Вт/√Гц`.

### Питома виявна здатність (Specific Detectivity, `D*`)

Оскільки темновий струм і ємність пропорційні площі кристала `A`, для порівняння якості напівпровідникових матеріалів незалежно від геометричних розмірів детектора використовують нормовану виявну здатність `D*` (вимірюється в одиницях Джонса, `см · √Гц / Вт`):

```
D* = (√(A · Δf)) / NEP_total = (R(λ) · √A) / (i_n / √Δf)   [см · √Гц / Вт = Jones]
```

Для якісного кремнієвого фотодіода при `λ = 900 нм` питома виявна здатність досягає `D* ≈ 10¹²–10¹³ Jones`.

## 8. Програмний розрахунок параметрів фотоприймача

#include <math.h>
#include <stdbool.h>

#define CONST_Q       1.602176634e-19 /* Кулон */
#define CONST_H       6.62607015e-34  /* Дж * с */
#define CONST_C       2.99792458e8    /* м / с */
#define CONST_KB      1.380649e-23    /* Дж / К */
#define CONST_EPS0    8.8541878128e-12 /* Ф / м */

typedef struct {
    double wavelength_m;      /* Довжина хвилі світла, м */
    double quantum_efficiency;/* Квантова ефективність eta (0.0 .. 1.0) */

    double eps_r;             /* Відносна діелектрична проникність (11.7 для Si) */
    double v_bi;              /* Контактна різниця потенціалів, В */
    double v_reverse;         /* Зворотна напруга зміщення, В */
    double n_doping_m3;       /* Концентрація домішок у базі N_d, м^-3 */
    double v_sat_m_s;         /* Швидкість насичення носіїв, м/с (1.0e5 для Si) */
    double r_series_ohm;      /* Послідовний опір кристала й контактів, Ом */
    double r_load_ohm;        /* Опір навантаження / схеми, Ом */
    double r_shunt_ohm;       /* Опір шунтування переходу, Ом */
    double dark_current_a;    /* Темновий струм витоку при заданій напрузі, А */
    double temperature_k;     /* Температура кристала, К */
} PhotodiodeParams;

typedef struct {
    double responsivity_a_w;   /* Спектральна чутливість R(lambda), А/Вт */
    double depletion_width_m;  /* Товщина збідненої області W, м */
    double junction_cap_f;     /* Бар'єрна ємність C_j, Фарад */
    double f_rc_hz;            /* Частота зрізу за RC-постійною, Гц */
    double f_transit_hz;       /* Частота зрізу за часом прольоту, Гц */
    double f_cutoff_3db_hz;    /* Результуюча смуга пропускання -3 дБ, Гц */
    double total_noise_current_a_rthz; /* Густина шуму струму, А / sqrt(Гц) */
    double nep_w_rthz;         /* Еквівалентна потужність шуму NEP, Вт / sqrt(Гц) */
} PhotodiodeResult;

bool calculate_photodiode_physics(const PhotodiodeParams* in, PhotodiodeResult* out) {
    if (!in || !out) return false;
    if (in->wavelength_m <= 0.0 || in->quantum_efficiency <= 0.0 || in->quantum_efficiency > 1.0) return false;
    if (in->area_m2 <= 0.0 || in->n_doping_m3 <= 0.0 || in->v_sat_m_s <= 0.0) return false;

    /* 1. Спектральна чутливість: R(lambda) = (eta * q * lambda) / (h * c) */
    out->responsivity_a_w = (in->quantum_efficiency * CONST_Q * in->wavelength_m) / (CONST_H * CONST_C);

    /* 2. Ширина збідненої зони: W = sqrt( (2 * eps_0 * eps_r * (V_bi + V_R)) / (q * N_d) ) */
    double total_voltage = in->v_bi + in->v_reverse;
    if (total_voltage < 0.0) total_voltage = 0.0;

    double eps_total = CONST_EPS0 * in->eps_r;
    out->depletion_width_m = sqrt((2.0 * eps_total * total_voltage) / (CONST_Q * in->n_doping_m3));

    /* 3. Бар'єрна ємність: C_j = (eps_total * Area) / W */
    if (out->depletion_width_m > 0.0) {
        out->junction_cap_f = (eps_total * in->area_m2) / out->depletion_width_m;
    } else {
        out->junction_cap_f = 0.0;
    }

    /* 4. Гранична частота за RC-постійною: f_RC = 1 / (2 * pi * (R_s + R_load) * C_j) */
    double r_total = in->r_series_ohm + in->r_load_ohm;
    if (r_total > 0.0 && out->junction_cap_f > 0.0) {
        out->f_rc_hz = 1.0 / (2.0 * M_PI * r_total * out->junction_cap_f);
    } else {
        out->f_rc_hz = 0.0;
    }

    /* 5. Гранична частота за часом прольоту: f_transit = 0.443 * v_sat / W */
    if (out->depletion_width_m > 0.0) {
        out->f_transit_hz = (0.443 * in->v_sat_m_s) / out->depletion_width_m;
    } else {
        out->f_transit_hz = 0.0;
    }

    /* 6. Результуюча смуга: 1/f_3dB^2 = 1/f_RC^2 + 1/f_transit^2 */
    if (out->f_rc_hz > 0.0 && out->f_transit_hz > 0.0) {
        double inv_sq = (1.0 / (out->f_rc_hz * out->f_rc_hz)) + (1.0 / (out->f_transit_hz * out->f_transit_hz));
        out->f_cutoff_3db_hz = 1.0 / sqrt(inv_sq);
    } else {
        out->f_cutoff_3db_hz = 0.0;
    }

    /* 7. Густина шумового струму: i_n = sqrt( 2*q*I_dark + 4*kB*T/R_sh ) */
    double shot_noise_sq = 2.0 * CONST_Q * in->dark_current_a;
    double thermal_noise_sq = (in->r_shunt_ohm > 0.0) ? (4.0 * CONST_KB * in->temperature_k / in->r_shunt_ohm) : 0.0;
    out->total_noise_current_a_rthz = sqrt(shot_noise_sq + thermal_noise_sq);

    /* 8. NEP = i_n / R(lambda) */
    if (out->responsivity_a_w > 0.0) {
        out->nep_w_rthz = out->total_noise_current_a_rthz / out->responsivity_a_w;
    } else {
        out->nep_w_rthz = 0.0;
    }

    return true;
}

namespace opto {

inline constexpr double q_elem   = 1.602176634e-19; /* Кулон */
inline constexpr double h_planck = 6.62607015e-34;  /* Дж * с */
inline constexpr double c_light  = 2.99792458e8;    /* м / с */
inline constexpr double k_boltz  = 1.380649e-23;    /* Дж / К */
inline constexpr double eps_0    = 8.8541878128e-12;/* Ф / м */

struct PhotodiodeConfig {
    double wavelength_m{850.0e-9};
    double quantum_efficiency{0.82};
    double area_m2{0.2e-6};
    double eps_relative{11.7};
    double v_bi{0.7};
    double v_reverse{10.0};
    double n_doping_m3{5.0e20};
    double v_saturation_m_s{1.0e5};
    double r_series_ohm{12.0};
    double r_load_ohm{50.0};
    double r_shunt_ohm{2.0e9};
    double dark_current_a{0.8e-9};
    double temperature_k{300.0};
};

struct PhotodiodeMetrics {
    double responsivity_a_w;
    double depletion_width_m;
    double junction_capacitance_f;
    double f_rc_hz;
    double f_transit_hz;
    double f_cutoff_3db_hz;
    double noise_current_density_a_rthz;
    double nep_w_rthz;
};

enum class CalculationError {
    InvalidWavelength,
    InvalidQuantumEfficiency,
    InvalidGeometryOrDoping,
    ZeroResponsivity
};

[[nodiscard]] constexpr std::string_view to_string(CalculationError err) noexcept {
    switch (err) {
        case CalculationError::InvalidWavelength: return "Довжина хвилі повинна бути > 0";
        case CalculationError::InvalidQuantumEfficiency: return "Квантова ефективність повинна належати (0, 1]";
        case CalculationError::InvalidGeometryOrDoping: return "Площа, концентрація та швидкість мають бути > 0";
        case CalculationError::ZeroResponsivity: return "Розрахункова чутливість дорівнює нулю";
    }
    return "Невідома помилка";
}

[[nodiscard]] std::expected<PhotodiodeMetrics, CalculationError> 
analyze_photodiode(const PhotodiodeConfig& cfg) noexcept {
    if (cfg.wavelength_m <= 0.0) {
        return std::unexpected(CalculationError::InvalidWavelength);
    }
    if (cfg.quantum_efficiency <= 0.0 || cfg.quantum_efficiency > 1.0) {
        return std::unexpected(CalculationError::InvalidQuantumEfficiency);
    }
    if (cfg.area_m2 <= 0.0 || cfg.n_doping_m3 <= 0.0 || cfg.v_saturation_m_s <= 0.0) {
        return std::unexpected(CalculationError::InvalidGeometryOrDoping);
    }

    PhotodiodeMetrics m{};

    /* Спектральна чутливість R(lambda) = (eta * q * lambda) / (h * c) */
    m.responsivity_a_w = (cfg.quantum_efficiency * q_elem * cfg.wavelength_m) / (h_planck * c_light);
    if (m.responsivity_a_w <= 0.0) {
        return std::unexpected(CalculationError::ZeroResponsivity);
    }

    /* Ширина збідненої області W */
    const double v_total = std::max(0.0, cfg.v_bi + cfg.v_reverse);
    const double eps_mat = eps_0 * cfg.eps_relative;
    m.depletion_width_m  = std::sqrt((2.0 * eps_mat * v_total) / (q_elem * cfg.n_doping_m3));

    /* Бар'єрна ємність C_j */
    m.junction_capacitance_f = (m.depletion_width_m > 0.0) ? (eps_mat * cfg.area_m2 / m.depletion_width_m) : 0.0;

    /* RC-зріз */
    const double r_tot = cfg.r_series_ohm + cfg.r_load_ohm;
    m.f_rc_hz = (r_tot > 0.0 && m.junction_capacitance_f > 0.0) 
        ? (1.0 / (2.0 * std::numbers::pi * r_tot * m.junction_capacitance_f)) : 0.0;

    /* Пролітний зріз */
    m.f_transit_hz = (m.depletion_width_m > 0.0) 
        ? (0.443 * cfg.v_saturation_m_s / m.depletion_width_m) : 0.0;

    /* Комбінований зріз -3 дБ */
    if (m.f_rc_hz > 0.0 && m.f_transit_hz > 0.0) {
        const double inv_sq = (1.0 / (m.f_rc_hz * m.f_rc_hz)) + (1.0 / (m.f_transit_hz * m.f_transit_hz));
        m.f_cutoff_3db_hz = 1.0 / std::sqrt(inv_sq);
    }

    /* Шумовий струм і NEP */
    const double shot_noise_sq = 2.0 * q_elem * cfg.dark_current_a;
    const double thermal_noise_sq = (cfg.r_shunt_ohm > 0.0) 
        ? (4.0 * k_boltz * cfg.temperature_k / cfg.r_shunt_ohm) : 0.0;

    m.noise_current_density_a_rthz = std::sqrt(shot_noise_sq + thermal_noise_sq);
    m.nep_w_rthz = m.noise_current_density_a_rthz / m.responsivity_a_w;

    return m;
}

## 9. Підсумковий баланс параметрів фотоприймача

Вибір типу та режиму роботи напівпровідникового фотодетектора завжди є результатом інженерного компромісу між чотирма фізичними величинами: спектральним діапазоном (`E_g`), швидкодією (`f_3dB`), рівнем власних шумів (`NEP`) та площею фоточутливої площадки (`A`).

- **Швидкість проти Чутливості:** Збільшення площі `A` збирає більше світла, але збільшує бар'єрну ємність `C_j ∝ A`, обвалюючи смугу пропускання.
- **Швидкість проти Шуму:** Подача високої зворотної напруги `V_R` знижує ємність `C_j` та прискорює носії до насичення, але породжує темновий струм `I_dark` і його дробовий шум, погіршуючи поріг виявлення слабких сигналів.
- **Матеріал проти Температури:** Вузькозонні матеріали (Ge, InGaAs, InAs) просувають червону межу вглиб інфрачервоного діапазону, але через високу власну концентрацію `n_i` мають значно вищий темновий струм, що вимагає термоелектричного або кріогенного охолодження.
