# 🧮 Математичні зв'язки фундаментальних констант у SI-2019

Ця вставка містить строге математичне виведення взаємозв'язків між фундаментальними константами природи та одиницями вимірювання після редефініції SI 2019 року. Усі виведення подано в алгебраїчній формі без використання застарілих умовних коефіцієнтів, із вичерпним аналізом перенесення похибок вимірювань, квантового метрологічного трикутника та матричного відображення похідних одиниць.

### 1. Точний раціональний базис 2019 року

У системі SI-2019 сім фундаментальних констант зафіксовано точними раціональними значеннями без жодної похибки вимірювання. Чотири з них безпосередньо задають базову структуру електромагнетизму та механіки:

```
Δν_Cs = 9 192 631 770 s⁻¹                       [частота надтонкого розщеплення цезію-133]
c     = 299 792 458 m s⁻¹                       [швидкість світла у вакуумі]
h     = 6.626 070 15 × 10⁻³⁴ kg m² s⁻¹          [стала Планка]
e     = 1.602 176 634 × 10⁻¹⁹ A s               [елементарний заряд]
```

Три додаткові константи задають термодинаміку, кількість речовини та фотометрію:

```
k   = 1.380 649 × 10⁻²³ kg m² s⁻² K⁻¹           [стала Больцмана]
NA  = 6.022 140 76 × 10²³ mol⁻¹                 [число Авогадро]
Kcd = 683 cd sr s³ kg⁻¹ m⁻²                     [світлова віддача]
```

Фізична суть цієї фіксації полягає в тому, що кожна константа виражає фундаментальну пропорційність між просторово-часовими та квантово-польовими властивостями матерії. Стала Планка `h` пов'язує частоту квантового випромінювання з енергією й масою, швидкість світла `c` встановлює еквівалентність між просторовими відстанями й часом, а елементарний заряд `e` задає фундаментальний дискретний квант електричного заряду у Всесвіті.

Процедура узгодження чисельних значень констант виконувалася Робочою групою CODATA з фундаментальних констант за допомогою методу найменших квадратів (LSA, *Least-Squares Adjustment*). Узгодження аналізувало дисперсійно-коваріаційні матриці результатів експериментів провідних метрологічних центрів світу. Критерієм узгодженості даних слугував коефіцієнт Бірджа (Birge ratio), який підтвердив відсутність прихованих системних похибок між незалежними вимірювальними групами.

Розмірні аналізи вказують, що комбінації цих чотирьох базових констант дозволяють повністю охопити будь-яку електромагнітну та механічну величину. Математично це означає, що фундаментальні константи формують повний раціональний базис чотиривимірного простору фізичних розмірностей `(час, довжина, маса, струм)`. Завдяки цьому базові одиниці секунда (с), метр (м), кілограм (кг) та ампер (А) виражаються алгебраїчно безпосередньо через комбінацію зафіксованих чисел:

```
1 s  = 9 192 631 770 / Δν_Cs                    [означення секунди]
1 m  = (299 792 458 / 9 192 631 770) · (c / Δν_Cs) [означення метра]
1 A  = (1 / 1.602 176 634 × 10⁻¹⁹) · e · Δν_Cs  [означення ампера]
1 kg = (1 / (6.626 070 15 × 10⁻³⁴ · (299 792 458)²)) · (h · Δν_Cs / c²)  [означення кілограма]
```

У формулі для кілограма комбінація `h · Δν_Cs / c²` має фізичну розмірність маси (`кг`), що випливає з квантового співвідношення Ейнштейна-Планка. Фізичний зміст цього виразу полягає у зв'язку енергії квантованого фотона з імпульсом і масою спокою:

```
E = h · ν = m · c²   ⇒   m = (h · ν) / c²
```

Це означає, що маса кілограма тепер прив'язана до еквівалентної енергії фотона, частота якого визначена через цезієву секунду.

### 2. Квантові сталі електромагнетизму: KJ, RK та Φ₀

Усі високоточні електричні вимірювання спираються на два фізичні ефекти квантової фізики твердого тіла. Фіксація `e` та `h` перетворила коефіцієнти цих ефектів на точні раціональні числа SI.

#### Стала Джозефсона (KJ) та рівняння еволюції фази

Нестаціонарний ефект Джозефсона виникає при тунелюванні куперівських пар (із зарядом `2e`) крізь тонкий ізолюючий бар'єр між двома надпровідниками. Макроскопічна квантова хвильова функція надпровідного конденсату описується амплітудою й макроскопічною фазою `Ψ = √ρ · exp(iθ)`. У гамільтоніані тунельного контакту Джозефсона енергія зв'язку визначається як `E_J = ħ · I_c / (2e)`.

Під дією прикладеної різниці потенціалів `V` різниця фаз `θ` між двома надпровідниками еволюціонує в часі відповідно до рівняння Шредінгера:

```
dθ / dt = (2e / ħ) · V
        = (4π · e / h) · V                       [динамічне рівняння фази Джозефсона]
```

Якщо на надпровідний контакт подати зовнішнє мікрохвильове випромінювання з частотою `f_J`, внутрішній тунельний струм надпровідника синхронізується з гармоніками зовнішнього поля. У стаціонарному режимі фазового захоплення середня напруга на переході строго квантується. На вольт-амперній характеристиці виникають дискретні квантовані сходинки напруги (сходинки Шапіро), де напруга строго зафіксована частотою:

```
V_n = (n · f_J) / K_J                           [напруга на джозефсонівській матриці]
```

де `n` — цілочисельний номер сходинки, а стала Джозефсона `K_J` задається виразом:

```
K_J = 2e / h
    = 2 · (1.602 176 634 × 10⁻¹⁹ A s) / (6.626 070 15 × 10⁻³⁴ kg m² s⁻¹)
    = (3.204 353 268 × 10⁻¹⁹) / (6.626 070 15 × 10⁻³⁴) Hz V⁻¹
    ≈ 483 597 848 416 983.953 273 66... × 10⁶ Hz V⁻¹  [ТОЧНЕ раціональне число]
```

Оскільки чисельник і знаменник є зафіксованими скінченними десятковими дробами, `K_J` є точним раціональним числом без похибки.

#### Стала фон Клітцинга (RK) та рівні Ландау в двовимірних системах

Квантовий ефект Холла спостерігається в двовимірному електронному газі (2DEG) у сильному магнітному полі `B` при низьких температурах. Сильне магнітне поле перпендикулярно до площини руху електронів квантує їхній енергетичний спектр на дискретні рівні Ландау.

У параболічному 2DEG (структури `GaAs/AlGaAs`) енергія рівня Ландау з номером `n` дорівнює:

```
E_n = ħ · ω_c · (n + 1/2)                      [де циклотронна частота ω_c = eB/m*]
```

Кількість квантових станів на кожному рівні Ландау на одиницю площі задається виродженням `n_B = e · B / h`. Коли фермієвський рівень потрапляє в енергетичний зазор між сусідніми рівнями Ландау, усі нижчі сталі повністю заповнені, а вищі — порожні. Поздовжнє розсіювання електронів пригнічується за рахунок формування топологічно захищених крайових каналів Ландауера-Бюттікера, у яких провідність описується матрицею пропускання струму `I_p = (e²/h) ∑ (T_qp V_p - T_pq V_q)`. Внаслідок відсутності розсіювання назад поздовжній опір зникає `R_xx → 0`. Для узгодження значення `R_K / 2` з робочими стандартними опорними резисторами `10 кОм` застосовують кріогенні компаратори струму (CCC) з точністю відношення витків кращою за `10⁻⁹`.

При цьому хорлівська провідність `σ_xy` та хорлівський опір `R_xy` квантуються з високою точністю:

```
σ_xy = i · (e² / h)                             [квантування хорлівської провідності]
R_H  = R_K / i                                  [квантований опір Холла]
```

де `i` — ціле число заповнених рівнів Ландау, а стала фон Клітцинга `R_K` дорівнює:

```
R_K = h / e²
    = (6.626 070 15 × 10⁻³⁴ kg m² s⁻¹) / (1.602 176 634 × 10⁻¹⁹ A s)²
    = (6.626 070 15 × 10⁻³⁴) / (2.566 969 660 700 795 56 × 10⁻³⁸) Ω
    ≈ 25 812.807 459 304 513 024... Ω           [ТОЧНЕ раціональне число]
```

У моношаровому графені носії заряду описуються безмасовим релятивістським рівнянням Дірака з ефективною фермієвською швидкістю `v_F ≈ 10⁶ м/с`. Енергетичний спектр рівнів Ландау у графені має релятивістський вигляд:

```
E_N = sgn(N) · v_F · √(2 · e · ħ · B · |N|)     [релятивістські рівні Ландау в графені]
```

З урахуванням чотирикратного виродження (два спінові стани й дві нееквівалентні долини `K` та `K'` у першій зоні Бріллюена) хорлівський опір у графені квантується за непарно-напівцілим законом:

```
R_H(N) = R_K / (4 · (N + 1/2))                  [квантовий опір Холла в графені]
```

Для фундаментального плато `N = 0` опір дорівнює `R_H = R_K / 2 ≈ 12 906.403 729... Ом`. Великий енергетичний зазор між фундаментальними рівнями в графені (понад `1000 K` у полі `10 T`) дозволяє проводити первинні вимірювання опору при гелієвих і навіть вищих температурах із відносною похибкою менше `10⁻⁹`.

#### Квант магнітного потоку (Φ₀)

У надпровідному кільці хвильова функція куперівських пар повинна бути однозначною при обході по замкненому контуру. Це вимагає квантування магнітного потоку `Φ`, що пронизує кільце, порціями кванту магнітного потоку `Φ₀`:

```
Φ₀ = h / (2e) = 1 / K_J
   = (6.626 070 15 × 10⁻³⁴ Дж·с) / (2 · 1.602 176 634 × 10⁻¹⁹ Кл)
   ≈ 2.067 833 848 461 929... × 10⁻¹⁵ Вб         [ТОЧНЕ раціональне число]
```

Прилади на основі СКВІД (надпровідні квантові інтерферометри) реєструють надмалі зміни магнітного поля, рахуючи окремі кванти потоку `Φ₀`.

### 3. Магнітна та електрична сталі: перехід від exact до u_r(α)

До реформи 2019 року магнітна стала вакууму `μ₀` була зафіксована як `4π × 10⁻⁷ Гн/м` за означенням ампера. У новій SI ситуація змінилася: оскільки `e` стало точним числом, `μ₀` перетворилася на вимірювану величину.

#### Строге виведення виразу для μ₀ через сталу тонкої структури α

Безрозмірна стала тонкої структури `α` описує силу електромагнітної взаємодії в квантовій електродинаміці (QED) і виражається через фундаментальні константи:

```
α = e² / (4π · ε₀ · ħ · c)                       [формула через зведену сталу Планка ħ = h/(2π)]
```

Підставляємо `ħ = h / (2π)` у знаменник:

```
α = e² / (4π · ε₀ · (h / 2π) · c)
  = e² / (2 · ε₀ · h · c)                        [стандартний вираз для α]
```

З електродинаміки Максвелла відомо, що швидкість поширення електромагнітних хвиль у вакуумі пов'язана з магнітною та електричною сталістю:

```
c = 1 / √(μ₀ · ε₀)   ⇒   c² = 1 / (μ₀ · ε₀)   ⇒   ε₀ · c = 1 / (μ₀ · c)
```

Підставляємо вираз `ε₀ · c = 1 / (μ₀ · c)` у формулу для `α`:

```
α = (e² · μ₀ · c) / (2 · h)                      [зв'язок α з μ₀]
```

Виражаємо магнітну сталу `μ₀` з цього рівняння:

```
μ₀ = (2 · α · h) / (e² · c)                      [основне рівняння для μ₀]
```

Помічаємо, що комбінація `h / e²` дорівнює сталій фон Клітцинга `R_K`:

```
μ₀ = (2 · α / c) · R_K                           [вираз μ₀ через R_K]
```

Аналогічно отримуємо вирази для електричної сталої `ε₀` та хвильового опору вакууму `Z₀`:

```
ε₀ = 1 / (μ₀ · c²) = e² / (2 · α · h · c) = 1 / (2 · α · R_K · c)
Z₀ = √(μ₀ / ε₀) = μ₀ · c = 2 · α · R_K
```

#### Визначення похибки та значення μ₀ у новій SI

Оскільки `h`, `e`, `R_K` та `c` зафіксовані з нульовою похибкою, відносна похибка вимірювання магнітної сталої `u_r(μ₀)` тотожно дорівнює відносній похибці експериментального вимірювання сталої тонкої структури `u_r(α)`:

```
u_r(μ₀) = u_r(ε₀) = u_r(Z₀) = u_r(α) ≈ 1.5 × 10⁻¹⁰
```

У теорет-фізиці QED аномальний магнітний момент електрона обчислюється через ряд за степенями `(α / π)`:

```
a_e = (g - 2) / 2 = C₁ · (α/π) + C₂ · (α/π)² + C₃ · (α/π)³ + C₄ · (α/π)⁴ + C₅ · (α/π)⁵ + ...
```

де коефіцієнти `C₁ ... C₅` розраховуються шляхом інтегрування тисяч фейнманівських діаграм. Точне вимірювання `a_e` у пастці Пеннінга та зіставлення з рядом QED дозволяє визначити `α` з винятковою точністю. Експериментальне значення `α`, визначене за допомогою вимірювань `g-2` та атомної інтерферометрії рубідію-87, становить:

```
α⁻¹ ≈ 137.035 999 177 (21)
```

Підставляючи це значення у формулу `μ₀ = 2 · α · R_K / c`, отримуємо чисельне значення магнітної сталої:

```
μ₀ = 4π × 1.000 000 000 15 (15) × 10⁻⁷ Гн/м
```

Відхилення від класичного значення `4π × 10⁻⁷ Гн/м` становить лише `1.5 × 10⁻¹⁰` (0.15 частин на мільярд), що повністю непомітно в звичайних інженерних розрахунках, але критично важливо для фундаментальної фізики.

### 4. Виведення рівняння ваг Кіббла (Watt Balance) та аналіз похибок

Ваги Кіббла є головним інструментом зв'язку між механічною масою `m` та квантовими сталями `h` і `e`. Робота приладу поділяється на два незалежні етапи. Стабільність магнітного поля між етапами забезпечується постійними магнітами зі сплаву самарій-кобальт (SmCo) або неодим-залізо-бор (NdFeB) з активною термостабілізацією до тисячних часток кельвіна.

У зважуваннях маси на повітрі обов'язково враховується виштовхувальна сила Архімеда. Густина повітря `ρ_air` обчислюється за рівнянням стану вологого повітря CIPM-2007 на основі неперервного моніторингу барометричного тиску, температури, відносної вологості та молярної частки вуглекислого газу `CO₂`.

#### Статичний етап (зважування)
На котушку довжиною `L`, підвішену в магнітному полі з індукцією `B`, діє сила Лоренца. Цю силу урівноважують масою `m` у полі тяжіння Землі `g`:

```
F_mech = m · g
F_el   = I · B · L
m · g  = I · B · L                              [рівняння 1: статичний рівноважний стан]
```

Група величин `B · L` (геометричний фактор котушки в магнітному полі) виміряти прямо неможливо через просторову неоднорідність поля й теплові деформації котушки.

#### Динамічний етап (калібрування геометричного фактора)
Масу `m` знімають, а котушку переміщують вертикально з постійною швидкістю `v` у тому самому магнітному полі `B`. За [законом індукції Фарадея](topic:ph-electromagnetism/faraday-law-differential) на кінцях котушки наводиться ЕРС `V`:

```
V = v · B · L                                   [рівняння 2: наведена ЕРС при русі]
```

Виражаємо геометричний фактор `B · L` з другого рівняння:

```
B · L = V / v                                   [підстановка геометричного фактора]
```

#### Потужнісний баланс
Підставляємо `B · L` з динамічного етапу в статичне рівняння:

```
m · g = I · (V / v)
m · g · v = V · I                               [рівняння потужнісного балансу]
```

Ліва частина `m · g · v` є механічною потужністю в ватах (кг·м²/с³), а права частина `V · I` — електричною потужністю в ватах (В·А).

#### Квантова заміна напруги та струму
Напругу `V` вимірюють через джозефсонівську матрицю на сходинці `n₁` при частоті `f₁`:

```
V = n₁ · f₁ / K_J = n₁ · f₁ · h / (2e)          [квантова напруга]
```

Струм `I` вимірюють через спад напруги `V_R` на квантовому опорі Холла `R = R_K / p` (де `p` — номер плато Холла). Напругу `V_R` також вимірюють через ефект Джозефсона на сходинці `n₂` при частоті `f₂`:

```
V_R = n₂ · f₂ · h / (2e)                        [напруга на еталонному опорі]
R   = R_K / p = (h / e²) / p                    [опір Холла]
I   = V_R / R = (n₂ · f₂ · h / (2e)) / (h / (p · e²))
    = (n₂ · f₂ · p · e) / 2                     [квантовий струм]
```

#### Остаточне скорочення елементарного заряду e
Підставляємо квантові вирази для `V` та `I` у потужнісний баланс `m · g · v = V · I`:

```
m · g · v = (n₁ · f₁ · h / (2e)) · (n₂ · f₂ · p · e / 2)
m · g · v = (1 / 4) · n₁ · n₂ · p · f₁ · f₂ · h
```

Уважно простежимо за зарядом `e`: у знаменнику напруги стоїть `e`, а в чисельнику струму стоїть `e`. При перемноженні `e` **абсолютно скорочується**!

Виражаємо масу `m`:

```
m = [ (n₁ · n₂ · p · f₁ · f₂) / (4 · g · v) ] · h
```

#### Повний бюджет похибок ваг Кіббла

Суммарна відносна похибка вимірювання маси `u_c(m)/m` обчислюється шляхом додавання квадратів часткових похибок усіх вхідних величин:

```
(u_c(m) / m)² = (u(h) / h)² + (u(g) / g)² + (u(v) / v)² + (u(f₁) / f₁)² + (u(f₂) / f₂)² + (u_sys / m)²
```

Оскільки `h` у системі SI-2019 зафіксовано точно (`u(h) = 0`), головними джерелами похибок у вагах Кіббла залишаються:
1. **Вимірювання локального прискорення вільного падіння `g`.** Використовуються балістичні лазерні гравіметри `FG5`, які вимірюють падіння дзеркала у вакуумній камері за допомогою лазерних інтерференційних смуг з похибкою `u(g)/g ≈ 10⁻⁹`.
2. **Вимірювання швидкості `v`.** Використовуються гелій-неонові лазерні гетеродинні інтерферометри для вимірювання вертикального зміщення котушки з похибкою `u(v)/v ≈ 10⁻⁹`.
3. **Кутові відхилення та горизонтальні паразитна сили.** Незначний нахил променя лазера або горизонтальний дрейф котушки створюють паразитичні сили Лоренца, що додають системну похибку `u_sys / m ≈ 5 × 10⁻⁹`.

Враховуючи ці фактори, сучасні ваги Кіббла в NIST (США) та METAS (Швейцарія) досягають відносної похибки вимірювання маси `u_c(m)/m ≈ 1.5 × 10⁻⁸` (15 мікрограмів на 1 кілограм).

### 5. Квантовий метрологічний трикутник

Для перевірки фундаментальної узгодженості квантової електродинаміки та закону Ома метрологи використовують експериментальну замкнену петлю, що має назву **квантовий метрологічний трикутник**.

У цьому експерименті три квантові прилади з'єднуються паралельно й послідовно:
1. Джозефсонівський генератор напруги створює квантову напругу `V = n · f_J / K_J`.
2. Квантовий одноелектронний насос створює квантовий струм `I = m · f_p · e`. Фізичним обмеженням струмового насоса є ймовірність ко-тунелювання електронів `P_co ∝ (R_T/R_K)²` та теплова активація носіїв `P_th ∝ exp(-E_C/k_B T)`.
3. Графеновий або арсенід-ґалієвий холлівський резистор забезпечує квантовий опір `R = R_K / i`.

За законом Ома перевіряється тотожність:

```
V / (I · R) = [ (n · f_J / (2e/h)) ] / [ (m · f_p · e) · (h / (i · e²)) ]
            = (n · i · f_J) / (2 · m · f_p)
```

Зауважимо, що константи `e` та `h` у правому виразі **повністю скорочуються**, залишаючи лише відношення виміряних частот `f_J / f_p` та цілочисельних квантових чисел `n, i, m`.

Якщо експериментально виміряне значення `V / (I · R)` дорівнює одиниці з точністю до `10⁻⁸`, це є незаперечним доказом того, що ефект Джозефсона та квантовий ефект Холла спираються на ті самі фундаментальні фізичні константи `e` та `h` без прихованих барієрних чи феноменологічних поправок.

### 6. Матричне вираження та алгебра похідних одиниць SI-2019

Усі похідні одиниці електромагнетизму та механіки виражаються у вигляді векторних степенів вектора базових констант `C = (Δν_Cs, c, h, e)`:

```
[Одиниця] = (Δν_Cs)^a · c^b · h^c · e^d
```

Наклавши умови відповідності розмірностей `s^α · m^β · kg^γ · A^δ`, отримуємо матричне рівняння зв'язку степенів:

```
┌   ┐   ┌                ┐ ┌   ┐
│ α │   │ -1  -1   1   1 │ │ a │
│ β │   │  0   1   2   0 │ │ b │
│ γ │ = │  0   0   1   0 │ · │ c │
│ δ │   │  0   0   0   1 │ │ d │
└   ┘   └                ┘ └   ┘
```

Матриця переходу має невироджений детермінант `det(M) = -1`, що підтверджує її повну оборотність і взаємно однозначну відповідність між класичним базисом розмірностей та квантовим базисом зафіксованих констант. Рядки оберненої матриці `M⁻¹` задають точний алгебраїчний розклад для кожного базового розмірного вектора у фазовому просторі SI-2019.

Звідси отримуємо явні алгебраїчні формули для всіх основних електромагнітних та механічних одиниць:

```
1 V  (Вольт)     = (1 / K_J) · Hz               ∝ h · Δν_Cs / e
1 Ω  (Ом)        = R_K                          ∝ h / e²
1 F  (Фарад)     = A · s / V                    ∝ e² / (h · Δν_Cs)
1 H  (Генрі)     = V · s / A                    ∝ h / (e² · Δν_Cs)
1 Wb (Вебер)     = V · s                        ∝ h / e
1 T  (Тесла)     = Wb / m²                      ∝ (h / e) · (Δν_Cs / c)²
1 J  (Джоуль)    = kg · m² / s²                 ∝ h · Δν_Cs
1 W  (Ват)       = J / s                        ∝ h · (Δν_Cs)²
1 Pa (Паскаль)   = N / m²                       ∝ (h / Δν_Cs) · (Δν_Cs / c)³
```

Ця система математичних формул демонструє абсолютну узгодженість і внутрішню гармонію нової квантової метрології: будь-яка вимірювана фізична величина виражається точним цілочисельним або раціональним співвідношенням комбінацій чотирьох констант природи.
