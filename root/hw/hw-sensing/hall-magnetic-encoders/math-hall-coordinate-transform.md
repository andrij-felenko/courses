# 🧮 Математичний апарат обчислення кута, розкладу похибок та еліптичної корекції

Визначення просторового положення вала за допомогою магнітного енкодера спирається на перетворення векторного магнітного поля в площині чутливих елементів у скалярний кут повороту. У ідеальному випадку дві ортогональні компоненти індукції формують чисті гармонійні функції, проте механічні похибки монтажу, неідеальність кристала та неоднорідність намагніченості спотворюють годограф вектора. Нижче наведено строгий математичний апарат розрахунку кута, розкладу виникаючих похибок у ряд Фур'є, оцінки передачі шумів АЦП та матричної корекції нелінійностей.

## Векторне поле діаметрального циліндричного магніту

Циліндричний постійний магніт радіуса `R` та висоти `H`, намагнічений діаметрально вздовж осі `X` з залишковою магнітною індукцією `Br`, на відстані осьового зазору `z` від свого торця створює поле, яке в першому наближенні моделюється магнітним диполем із магнітним моментом `m = (π · R² · H · Br) / μ₀`.

При обертанні магніту на механічний кут `θ` навколо осі `Z` вектор магнітного моменту в декартовій системі координат площини давача має вигляд:

```
m(θ) = [m · cos(θ), m · sin(θ), 0]ᵀ
```

У точці на осі обертання `(0, 0, z)` вектор магнітної індукції `B` визначається виразом:

```
B(z, θ) = (μ₀ / (4 · π)) · (3 · (m · r̂) · r̂ - m) / z³
```

Оскільки радіус-вектор `r = [0, 0, z]ᵀ` є строго перпендикулярним до вектора магнітного моменту `m(θ)` (тобто скалярний добуток `m · r̂ = 0`), вираз для індукції в площині кристала спрощується:

```
B(z, θ)
= - (μ₀ / (4 · π · z³)) · m(θ)            [скалярний добуток m · r̂ = 0]
= [B₀(z) · cos(θ), B₀(z) · sin(θ), 0]ᵀ    [амплітуда B₀(z) = (μ₀ · m) / (4 · π · z³)]
```

Амплітуда магнітної індукції `B₀` спадає обернено пропорційно кубу відстані `z³`, проте просторовий напрямок вектора індукції в площині `XY` строго повторює просторовий кут повороту вала `θ`.

## Диференційне виділення компонентів та придушення завад

Розглянемо 2D-масив із чотирьох чутливих елементів Холла, розташованих симетрично на відстані `r_s` від центру кристала: два вздовж осі X у точках `(-r_s, 0)` та `(+r_s, 0)`, і два вздовж осі Y у точках `(0, -r_s)` та `(0, +r_s)`.

Нехай на систему діє корисне поле магніту `B_mag(θ)` та зовнішнє однорідне поле магнітної завади `B_ext = [B_ext,x, B_ext,y, B_ext,z]ᵀ`.

Напруга на кожному з чотирьох сенсорів пропорційна локальній індукції:

```
V_x1 = S_x1 · (+B₀ · cos(θ) + B_ext,x)
V_x2 = S_x2 · (-B₀ · cos(θ) + B_ext,x)
V_y1 = S_y1 · (+B₀ · sin(θ) + B_ext,y)
V_y2 = S_y2 · (-B₀ · sin(θ) + B_ext,y)
```

При ідентичній чутливості пар `S_x1 = S_x2 = S_x` та `S_y1 = S_y2 = S_y` диференційне віднімання сигналів усуває синфазну заваду:

```
V_x = V_x1 - V_x2
= S_x · (B₀ · cos(θ) + B_ext,x) - S_x · (-B₀ · cos(θ) + B_ext,x)   [підстановка напруг пари]
= 2 · S_x · B₀ · cos(θ)                                            [знищення завади B_ext,x]

V_y = V_y1 - V_y2
= S_y · (B₀ · sin(θ) + B_ext,y) - S_y · (-B₀ · sin(θ) + B_ext,y)   [підстановка напруг пари]
= 2 · S_y · B₀ · sin(θ)                                            [знищення завади B_ext,y]
```

Отримані квадратурні сигнали `V_x` та `V_y` повністю очищені від зовнішнього однорідного магнітного фону (наприклад, магнітного поля Землі або шин живлення інвертора).

## Математична модель спотворень ортогональних сигналів

У реальній електромеханічній системі вихідні сигнали ортогональних каналів зазнають трьох типів деформацій:
1. Постійне зміщення нуля (Offset) `O_x, O_y` через технологічний розкид напівпровідникових структур та залишкові механічні напруження кристала.
2. Амплітудна асиметрія (Gain mismatch) `k_g = A_y / A_x ≠ 1` через нерівність чутливості каналів або нахил осі магніту.
3. Фазовий зсув неортогональності (Non-orthogonality / Cross-coupling) `δ` через кутову похибку розташування елементів на кристалі чи анізотропію магнітного концентратора.

Математична модель спотворених сигналів `(u, v)` записується у вигляді:

```
u(θ) = A_x · cos(θ) + O_x
v(θ) = A_y · sin(θ + δ) + O_y
```

Розкриваючи синус суми:

```
v(θ) = A_y · (sin(θ) · cos(δ) + cos(θ) · sin(δ)) + O_y
```

Обчислений мікросхемою кут `θ_meas` визначається як:

```
θ_meas = atan2(v(θ), u(θ))
```

Кутова похибка `Δθ(θ) = θ_meas - θ` є періодичною функцією з періодом `2 · π` і може бути розкладена в тригонометричний ряд Фур'є:

```
Δθ(θ) = a₀ + ∑ [a_n · cos(n · θ) + b_n · sin(n · θ)]
```

## Виведення першої гармоніки похибки (радіальний ексцентриситет та зміщення нуля)

Нехай амплітуди збалансовані (`A_x = A_y = A`), неортогональність відсутня (`δ = 0`), але є відносні зміщення нуля `ε_x = O_x / A` та `ε_y = O_y / A`, де `|ε_x|, |ε_y| ≪ 1`.

Аналітичний розрахунок арктангенса для малого збурення:

```
tan(θ_meas) = (sin(θ) + ε_y) / (cos(θ) + ε_x)

θ_meas = atan( (sin(θ) + ε_y) / (cos(θ) + ε_x) )
```

Використовуючи формулу віднімання арктангенсів `atan(p) - atan(q) = atan( (p - q) / (1 + p · q) )`:

```
Δθ = θ_meas - θ
= atan( ( (sin θ + ε_y)/(cos θ + ε_x) - sin θ / cos θ ) / ( 1 + (sin θ + ε_y)·sin θ / ((cos θ + ε_x)·cos θ) ) )  [формула різниці арктангенсів]
= atan( (ε_y · cos θ - ε_x · sin θ) / (1 + ε_x · cos θ + ε_y · sin θ) )                                         [зведення дробів до спільного знаменника]
```

Оскільки `|ε| ≪ 1`, розкладаємо в ряд Тейлора першого порядку `atan(x) ≈ x`:

```
Δθ(θ) ≈ ε_y · cos(θ) - ε_x · sin(θ) = A₁ · sin(θ + φ₁)
```

Де амплітуда та початкова фаза першої гармоніки:

```
A₁ = √(ε_x² + ε_y²)
φ₁ = atan2(ε_y, -ε_x)
```

Постійне зміщення нульової лінії напруг Холла або радіальний ексцентриситет магніту відносно центру кристала генерують **строго першу гармоніку кутової похибки** з частотою обертання вала (одна синусоїдальна хвиля за 360°).

## Виведення другої гармоніки похибки (амплітудна асиметрія та кутовий перекіс)

Нехай зміщення нуля відсутні (`O_x = O_y = 0`), неортогональність мала (`cos δ ≈ 1`, `sin δ ≈ δ`), а коефіцієнт підсилення по осі Y має відносну похибку `k_g = 1 + g` (де `|g|, |δ| ≪ 1`):

```
u(θ) = A · cos(θ)
v(θ) = A · (1 + g) · (sin(θ) + δ · cos(θ))
```

Обчислюємо тангенс виміряного кута:

```
tan(θ_meas) = v(θ) / u(θ) = (1 + g) · tan(θ) + (1 + g) · δ
```

Похибка кута:

```
Δθ = θ_meas - θ
= atan( ( (1 + g) · tan θ + (1 + g) · δ - tan θ ) / ( 1 + ( (1 + g) · tan θ + (1 + g) · δ ) · tan θ ) )  [підстановка тангенсів]
```

Нехтуючи членами другого порядку малості `g · δ ≈ 0` та враховуючи `1 + tan²(θ) = 1 / cos²(θ)`:

```
Δθ ≈ (g · sin θ · cos θ + δ · cos² θ) / (cos² θ + sin² θ)     [нехтування членом другого порядку малості g · δ]
= g · (1/2 · sin(2θ)) + δ · (1/2 + 1/2 · cos(2θ))             [тригонометричні тотожності подвійного кута]
= (δ / 2) + (g / 2) · sin(2θ) + (δ / 2) · cos(2θ)             [розкриття дужок і групування доданків]
```

Об'єднуючи гармонійні доданки:

```
Δθ(θ) = (δ / 2) + A₂ · sin(2θ + φ₂)
```

Де амплітуда другої гармоніки:

```
A₂ = 1/2 · √(g² + δ²)
φ₂ = atan2(δ, g)
```

Нерівність амплітуд ортогональних каналів `A_x ≠ A_y` (наприклад, спричинена кутовим перекосом осі магніту Tilt) та фазова неортогональність чутливих елементів `δ` генерують **другу гармоніку кутової похибки** (два повні періоди похибки за один механічний оберт вала).

## Аналіз передачі шуму АЦП у похибку кута

Нехай квадратурні сигнали напруги спотворені випадковим гаусовим шумом вимірювання з дисперсією `σ_v²` у кожному каналі:

```
u_noisy = A · cos(θ) + η_u,    η_u ~ N(0, σ_v²)
v_noisy = A · sin(θ) + η_v,    η_v ~ N(0, σ_v²)
```

Застосовуючи лінеаризацію функції `θ = atan2(v, u)` через частинні похідні (метод розкладу в ряд Тейлора для дисперсії функції випадкових величин):

```
∂θ / ∂u = - v / (u² + v²) = - (A · sin θ) / A² = - sin(θ) / A
∂θ / ∂v = + u / (u² + v²) = + (A · cos θ) / A² = + cos(θ) / A
```

Дисперсія виміряного кута `σ_θ²` дорівнює зваженій сумі дисперсій некорельованих шумів каналів:

```
σ_θ² = (∂θ / ∂u)² · σ_u² + (∂θ / ∂v)² · σ_v²
= (- sin θ / A)² · σ_v² + (cos θ / A)² · σ_v²    [підстановка частинних похідних]
= (sin² θ + cos² θ) · (σ_v² / A²)                [винесення спільного множника]
= σ_v² / A²                                      [основна тригонометрична тотожність]
```

Середньоквадратичне відхилення кута `σ_θ` строго дорівнює:

```
σ_θ = σ_v / A = 1 / SNR_амплітудне
```

Зверніть увагу на важливий висновок: дисперсія шуму кута є строго константною по всьому колу (не залежить від положення `θ`) і обернено пропорційна амплітуді сигналу `A`. Якщо повітряний зазор збільшити вдвічі, амплітуда `A` спаде у `2³ = 8` разів, а шум кутового вимірювання зросте у 8 разів (на 18 дБ).

## Матрична лінеаризація методом ортогоналізації Грама-Шмідта

Щоб перетворити спостережуваний деформований вектор `x_raw = [u, v]ᵀ`, годограф якого утворює зміщений похилий еліпс, в ідеальний одиничний вектор `x_cal = [cos θ, sin θ]ᵀ`, застосовується афінне матричне перетворення:

```
x_cal = M · (x_raw - O)
```

Де `O = [O_x, O_y]ᵀ` — вектор зміщення центру еліпса, а `M` — матриця калібрування розмірністю `2 × 2`.

Запишемо прямий зв'язок сирих координат з ідеальними:

```
[ u ]   [ A_x       0           ]   [ cos(θ) ]   [ O_x ]
[   ] = [                       ] · [        ] + [     ]
[ v ]   [ A_y·sin δ  A_y·cos δ   ]   [ sin(θ) ]   [ O_y ]
```

Позначимо матрицю деформації `T`:

```
T = [ A_x          0           ]
    [ A_y · sin δ  A_y · cos δ ]
```

Шукана матриця корекції `M` є оберненою до `T`: `M = T⁻¹`:

```
det(T) = A_x · A_y · cos(δ)

M = (1 / det(T)) · [ A_y · cos(δ)       0   ]
                   [ -A_y · sin(δ)     A_x ]

M = [ 1 / A_x            0                      ]
    [ -tan(δ) / A_x      1 / (A_y · cos(δ))     ]
```

Ввівши нормовані коефіцієнти `m_xx = 1 / A_x`, `m_yx = -tan(δ) / A_x`, `m_yy = 1 / (A_y · cos(δ))`, алгоритм повної корекції у реальному часі зводиться до чотирьох арифметичних операцій:

```
u_centered = u - O_x
v_centered = v - O_y

u_cal = m_xx · u_centered
v_cal = m_yx · u_centered + m_yy · v_centered

θ_corrected = atan2(v_cal, u_cal)
```

## Числовий приклад розрахунку та оцінки точності

Нехай магнітний енкодер із 14-бітним АЦП після монтажу має такі експериментально зняті параметри спотворень:
- `A_x = 10000` LSB, `A_y = 10600` LSB (`g = +0.06` — амплітудна асиметрія 6%)
- `O_x = +300` LSB, `O_y = -200` LSB (`ε_x = +0.03`, `ε_y = -0.02` — зміщення нуля 3% та 2%)
- `δ = 2.0° = 0.0349` рад (неортогональність масиву Холла)

Обчислимо теоретичні амплітуди похибок до калібрування:

```
1. Перша гармоніка від зміщення нуля:
A₁ = √(0.03² + (-0.02)²) = √(0.0009 + 0.0004) = √0.0013 ≈ 0.03606 рад ≈ 2.066°

2. Друга гармоніка від асиметрії та неортогональності:
A₂ = 1/2 · √(0.06² + 0.0349²) = 1/2 · √(0.0036 + 0.001218) = 1/2 · √0.004818 ≈ 0.03471 рад ≈ 1.989°

3. Сумарна пікова похибка нелінійності без калібрування:
Δθ_max ≈ A₁ + A₂ = 2.066° + 1.989° = 4.055° (еквівалентно 184 LSB для 14-бітного енкодера)
```

Розрахунок калібрувальних коефіцієнтів матриці `M`:

```
m_xx = 1 / 10000 = 0.000100000
m_yx = -tan(2.0°) / 10000 = -0.03492 / 10000 = -0.000003492
m_yy = 1 / (10600 · cos(2.0°)) = 1 / (10600 · 0.99939) = 1 / 10593.5 = 0.000094397
```

Після застосування матричного перетворення та віднімання зміщення залишковий рівень нелінійності зменшується з `4.055°` до менш ніж `0.05°` (обмежений лише шумом квантування АЦП та вищими гармоніками магнітного поля), що забезпечує паспортну точність 14-бітного позиціонування.
