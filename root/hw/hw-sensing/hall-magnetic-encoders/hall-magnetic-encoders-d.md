# Холл-енкодери

<preknowlist>
- [Ефект Холла](root:ph-condensed/hall-effect) — виникнення поперечної різниці потенціалів у провіднику зі струмом у магнітному полі.
- [Оптичний інкрементний енкодер](root:hw-sensing/optical-incremental-encoder) — щілинний диск, оптопереривач та квадратурні імпульси.
- [Квадратура сигналів](root:hw-sensing/quadrature) — зсув каналів A і B на 90° для визначення напрямку та учетверення роздільності.
- [Алгоритм CORDIC](root:hw-arch/fixed-point/proj-cordic.md) — швидке обчислення тригонометричних функцій та арктангенса за допомогою зсувів і додавань.
</preknowlist>

Обертовий вал робота, промислового верстата чи тягового серводвигуна працює у середовищі, де оптичний енкодер швидко виходить із ладу: пил перекриває мікронні щілини скляного диска, краплі мастила заломлюють промінь світлодіода, а вібрація розбиває тендітну оптику. Механічний потенціометр стирається за кількасот тисяч обертів і шумить брязкотом рухомого контакту. Потрібен спосіб вимірювати положення вала взагалі без механічного та оптичного контакту — наскрізь через суцільну алюмінієву чи пластикову герметичну стінку, із роздільністю до сотих часток градуса та миттєвим знанням абсолютного кута відразу після ввімкнення живлення.

Цю задачу вирішує **магнітний енкодер на ефекті Холла** (англ. *Hall effect magnetic encoder* — на честь американського фізика Едвіна Холла, Edwin Hall, який відкрив явище 1879 року). На торці вала закріплюють постійний магніт, а навпроти нього на нерухомій платі встановлюють напівпровідниковий кристал із масивом чутливих елементів Холла. Коли вал повертається, просторовий вектор магнітного поля обертається разом із ним, а інтегральна мікросхема вимірює ортогональні компоненти індукції, придушує зовнішні завади та за лічені наносекунди обчислює абсолютний кут повороту.

## Фізика ефекту Холла в напівпровіднику

В основі явища лежить взаємодія рухомих електричних зарядів із зовнішнім магнітним полем. Якщо крізь твердотільну пластинку завтовшки `d`, завширшки `w` та завдовжки `l` пропустити постійний струм `I`, усередині матеріалу виникає напрямлений дрейф носіїв заряду `q` із середньою швидкістю `v_d`. 

Коли пластинку пронизує магнітне поле з індукцією `B`, перпендикулярною до напрямку струму, на кожен рухомий заряд діє **сила Лоренца** (англ. *Lorentz force*):

```
F = q · (E + v × B)
```

Магнітна складова сили `F_m = q · (v_d × B)` спрямована перпендикулярно як до вектора дрейфової швидкості, так і до вектора магнітної індукції. Вона відхиляє траєкторію носіїв заряду до однієї з бічних граней пластинки. Кут між вектором густини струму та вектором напруженості електричного поля називається **кутом Холла** `θ_H`, де `tan(θ_H) = μ_H · B`, а `μ_H` — холівська рухливість носіїв заряду.

У результаті на одному бічному краї пластинки накопичуються електрони (або дірки), а на протилежному виникає їхній дефіцит — нескомпенсований заряд протилежного знака. Це просторове розділення зарядів породжує внутрішнє поперечне електричне поле — **поле Холла** `E_H`.

Поле Холла створює електричну силу `F_e = q · E_H`, яка діє у бік, протилежний силі Лоренца. Процес розділення зарядів триває доти, доки електрична сила повністю не врівноважить магнітну силу Лоренца:

```
q · E_H = q · v_d · B
E_H = v_d · B
```

![Фізика ефекту Холла: сила Лоренца відхиляє носії заряду, утворюючи поперечну різницю потенціалів](/root/hw/hw-sensing/hall-magnetic-encoders/img/hall-physics.svg)
*Фізичний механізм ефекту Холла. Струм I тече вздовж пластинки (вісь X), магнітне поле B спрямоване вгору (вісь Z). Сила Лоренца F_L зміщує рухомі електрони до передньої грані, створюючи поперечне електричне поле E_H та різницю потенціалів V_H між бічними гранями.*

Повна поперечна різниця потенціалів — **напруга Холла** `V_H` — дорівнює інтегралу напруженості поля `E_H` вздовж ширини пластинки `w`, помноженому на геометричний фактор форми `G_H(l/w)`:

```
V_H = G_H · E_H · w = G_H · v_d · B · w
```

Для видовжених пластин із відношенням довжини до ширини `l / w > 3` геометричний фактор наближається до одиниці (`G_H ≈ 1`).

Зв'яжемо дрейфову швидкість `v_d` із вимірюваним струмом `I`. Густина струму в пластинці становить `j = n · q · v_d`, де `n` — об'ємна концентрація вільних носіїв заряду. Оскільки повний струм дорівнює `I = j · S = j · w · d`:

```
I = n · q · v_d · w · d
v_d = I / (n · q · w · d)
```

Підставивши швидкість дрейфу у вираз для напруги Холла, отримуємо фундаментальне рівняння:

```
V_H = (I / (n · q · w · d)) · B · w
= (1 / (n · q · d)) · I · B            [скорочення ширини w]
= (R_H / d) · I · B                    [коефіцієнт Холла R_H = 1 / (n · q)]
```

Де величина `R_H = 1 / (n · q)` називається **коефіцієнтом Холла** (англ. *Hall coefficient*). Знак коефіцієнта Холла визначається типом основних носіїв заряду (негативний для електронів у напівпровідниках n-типу, позитивний для дірок у p-типі).

### Чому давачі виготовляють із напівпровідників, а не з металів

Рівняння показує, що напруга Холла обернено пропорційна концентрації носіїв `n`. У металах (мідь, алюміній, срібло) концентрація електронів провідності колосальна: `n ≈ 8.5 · 10²⁸ м⁻³`. За струму 1 А та магнітного поля 0.1 Тл у мідній пластинці завтовшки 0.1 мм напруга Холла становить лише кілька десятків нановольт (`10⁻⁸ В`), що губиться на тлі термодинамічних шумів і контактних термо-ЕРС.

У легованих напівпровідниках (кремній `Si`, арсенід галію `GaAs`, антимонід індію `InSb`) концентрація носіїв становить лише `n ≈ 10²¹–10²² м⁻³` — на шість-сім порядків менше, ніж у металі. Через це носії за того самого струму змушені рухатися зі значно вищою дрейфовою швидкістю `v_d`. Відповідно, сила Лоренца та поперечна напруга Холла зростають у мільйон разів, досягаючи одиниць і десятків мілівольт на мілітесла (`мВ / мТл`), що легко підсилюється інтегрованими малошумними операційними підсилювачами безпосередньо на кремнієвому кристалі.

У спеціалізованих високочутливих магнітометрах застосовують двовимірний електронний газ (**2DEG** — *Two-Dimensional Electron Gas*) у гетероструктурах AlGaAs/GaAs, де товщина провідного каналу `d` становить лічені нанометри, а рухливість електронів сягає `μ > 100 000 см²/(В·с)`, забезпечуючи граничну чутливість та мінімальний тепловий шум Джонсона-Найквіста.

> 🔧 **Навіщо це.** Ефект Холла перетворює невидиму механічну величину (кут і відстань до магніту) на лінійну напругу без жодного тертя та механічного контакту. Що тонший напівпровідниковий шар `d` і менша концентрація носіїв `n`, то вища чутливість первинного перетворювача.

## Дискретні датчики Холла та 6-крокова комутація BLDC

Найпростішим і наймасовішим застосуванням ефекту Холла в електроприводах є не плавне вимірювання кута, а дискретне визначення секторів положення ротора для комутації безколекторних двигунів постійного струму (BLDC — *Brushless DC Motor*).

У класичному трифазному BLDC-моторі статор містить три фазні обмотки (U, V, W), а ротор складається з постійних магнітів із числом пар полюсів `p`. Щоб двигун створював неперервний обертальний момент, силовий інвертор повинен подавати струм у фази синхронно з положенням магнітних полюсів ротора.

Для цього в статор встановлюють **три цифрові біполярні датчики Холла** (H1, H2, H3), розміщені по колу зі зсувом **120° електричних градусів** один від одного (або 60° у деяких конструкціях). Цифровий датчик містить на кристалі елемент Холла, диференційний підсилювач і тригер Шмітта з виходом типу «відкритий колектор». При проходженні північного магнітного полюса ротора вихід перемикається в логічний `0` (активний стан), а при проходженні південного полюса — у логічну `1`.

![Комутація трифазного BLDC-двигуна за трьома датчиками Холла зі зсувом 120°](/root/hw/hw-sensing/hall-magnetic-encoders/img/bldc-hall-commutation.svg)
*Шестикрокова комутація BLDC. Три датчики Холла H1, H2, H3 перекривають 360° електричних градусів, ділячи оберт на шість робочих секторів по 60°. Кожному сектору відповідає унікальна 3-бітна комбінація станів, яка визначає пару ввімкнених силових ключів інвертора.*

### Шестикроковий комутаційний цикл

За один повний електричний період ротора стан трьох датчиків формує шість унікальних 3-бітних комбінацій:

```
Сектор 1 (0°..60°):    H1=1, H2=0, H3=1  (код 5)  → Фази: U+ V- W_off
Сектор 2 (60°..120°):  H1=1, H2=0, H3=0  (код 4)  → Фази: U+ V_off W-
Сектор 3 (120°..180°): H1=1, H2=1, H3=0  (код 6)  → Фази: U_off V+ W-
Сектор 4 (180°..240°): H1=0, H2=1, H3=0  (код 2)  → Фази: U- V+ W_off
Сектор 5 (240°..300°): H1=0, H2=1, H3=1  (код 3)  → Фази: U- V_off W+
Сектор 6 (300°..360°): H1=0, H2=0, H3=1  (код 1)  → Фази: U_off V- W+
```

Зв'язок між механічним кутом повороту вала `θ_mech` та електричним кутом `θ_elec` задається кількістю пар полюсів ротора `p`:

```
θ_elec = p · θ_mech
```

Наприклад, у моторі з 7 парами полюсів (`p = 7`, типово для дронів і електросамокатів) за один механічний оберт вала відбувається 7 повних електричних періодів і `7 × 6 = 42` перемикання станів датчиків Холла.

### Заборонені стани та діагностика

Зверніть увагу: комбінації `000` (усі нулі) та `111` (усі одиниці) при правильному розміщенні датчиків під 120° **фізично неможливі**, оскільки три точки під кутами 0°, 120° і 240° не можуть одночасно опинитися над одним і тим самим магнітним полюсом ротора. 

Поява коду `000` або `111` на входах мікроконтролера однозначно свідчить про апаратну несправність: обрив шлейфа живлення датчиків, відпадання підтягувальних резисторів (*pull-up*) або вихід із ладу одного з сенсорів.

### Розрахунок швидкості з таймерного інтервалу

Мікроконтролер вимірює кутову швидкість ротора, фіксуючи час `Δt` між послідовними фронтами перемикання будь-якого з датчиків Холла за допомогою блоку таймерного захоплення (англ. *Input Capture*):

```
ω_elec = (π / 3) / Δt       [радіан / с, оскільки крок комутації становить 60° = π/3 рад]
ω_mech = ω_elec / p         [механічна кутова швидкість]
RPM = (60 / (6 · p · Δt))   [обертів за хвилину]
```

### Обмеження дискретних датчиків

Дискретні датчики дають інформацію про кут із грубою дискретністю всього `60°` електричних градусів. Для простого обертання вентилятора чи колеса електровелосипеда цього достатньо, проте для високодинамічних прецизійних приводів виникають критичні недоліки:
1. **Пульсації крутного моменту (Torque Ripple):** стрибкоподібне перемикання фаз на фіксованих кутах 60° створює ривки моменту амплітудою до 14%, що спричиняє вібрацію та акустичний шум.
2. **Неможливість точного позиціонування:** у стані спокою неможливо дізнатися, де саме всередині 60-градусного сектора зупинився вал.
3. **Непридатність для векторного керування (FOC):** алгоритм прямого регулювання струму вимагає точного неперервного кута ротора з роздільністю щонайменше 12–14 біт.

Саме для вирішення цих задач були створені інтегральні мікросхеми 2D/3D магнітних енкодерів.

## Інтегральні 2D/3D магнітні енкодери та ортогональні масиви

Сучасний інтегральний магнітний енкодер (наприклад, мікросхеми сімейств **ams OSRAM AS5048 / AS5600**, **Monolithic Power Systems MagAlpha MA730**, **Melexis Triaxis MLX90316**) являє собою завершену систему на кристалі (SoC), що містить масив сенсорів Холла, малошумні інструментальні підсилювачі, АЦП, апаратний цифровий процесор розрахунку кута та вихідні інтерфейси.

Мікросхема встановлюється в конфігурації **End-of-Shaft** (на торці вала): на кінці обертового вала співвісно монтується невеликий циліндричний магніт із **діаметральним намагнічуванням** (одна половинка циліндра — північний полюс N, друга — південний S).

Магніт створює в просторі над кристалом двовимірне магнітне поле. При обертанні вала вектор магнітної індукції `B` повертається в площині кристала, а його проекції на декартові осі `X` та `Y` описуються квадратурними гармонійними функціями:

```
Bx(θ) = B₀ · cos(θ)
By(θ) = B₀ · sin(θ)
```

Де `B₀` — амплітуда магнітної індукції на поверхні сенсора (зазвичай 30–80 мТл), а `θ` — шуканий кут повороту вала.

![Топологія 2D диференційного масиву Холла та обчислення арктангенса кута](/root/hw/hw-sensing/hall-magnetic-encoders/img/differential-hall-array.svg)
*2D диференційний масив Холла. Чотири чутливі елементи (X+, X-, Y+, Y-) попарно вимірюють градієнт корисного поля магніту. Синфазна зовнішня завада B_ext віднімається до нуля. Цифровий обчислювач CORDIC знаходить кут через векторний арктангенс θ = atan2(By, Bx).*

### Топологія сенсорних елементів на кристалі

Звичайний планарний елемент Холла на кремнієвому кристалі чутливий до перпендикулярної складової магнітного поля `Bz` (перпендикулярно площині мікросхеми). Щоб вимірювати тангенційні складові `Bx` і `By`, виробники застосовують дві провідні технології:

1. **Інтегрований магнітний концентратор (IMC — Integrated Magnetic Concentrator):** На поверхню кремнієвого кристала поверх стандартних планарних датчиків Холла наносять тонкий шар м'якого феромагнетика з високою проникністю (пермалой). Концентратор викривляє паралельні до кристала силові лінії полів `Bx` і `By`, спрямовуючи їх вертикально крізь краї елементів Холла.
2. **Вертикальні датчики Холла (Vertical Hall Technology):** Напівпровідникові структури вирощуються вертикально в товщі кремнію перпендикулярно поверхні пластини (технологія SpinAxis / MagAlpha). Такі датчики від народження чутливі до полів, паралельних площині чипа, забезпечуючи смугу пропускання до кількох мегагерц і час затримки всього 2–3 мкс.

### Диференційне зчитування та імунітет до зовнішніх завад

Головна проблема одинарного датчика магнітного поля — вразливість до зовнішніх магнітних шумів: поля Землі (0.05 мТл), сусідніх проводів живлення інвертора (де струми в десятки ампер створюють поля в кілька мілітесла) та електромагнітних гальм.

Щоб зробити енкодер стійким до завад, елементи Холла на кристалі об'єднують у **диференційний масив із 4 елементів**:
- Два елементи вздовж осі X: `X+` (на відстані `+r` від центру) та `X-` (на відстані `-r`).
- Два елементи вздовж осі Y: `Y+` (на відстані `+r`) та `Y-` (на відстані `-r`).

Оскільки діаметральний магніт розміщений строго над центром кристала, корисне поле магніту на протилежних краях має протилежні напрямки (`+Bx` та `-Bx`). Зовнішня ж завада `B_ext` на крихітному кристалі розміром 2×2 мм є практично однорідною і діє на обидва сенсори однаково:

```
V(X+) = +Bx_магніт + B_ext
V(X-) = -Bx_магніт + B_ext
```

Диференційний підсилювач віднімає напруги сенсорів:

```
Vx = V(X+) - V(X-)
= (+Bx_магніт + B_ext) - (-Bx_магніт + B_ext)   [підстановка напруг пари сенсорів]
= 2 · Bx_магніт                                  [взаємне знищення синфазної завади B_ext]
```

Зовнішнє однорідне поле `B_ext` ідеально віднімається в нуль, а амплітуда корисного сигналу подвоюється. Завдяки цьому магнітний енкодер надійно працює навіть у кількох міліметрах від потужних силових обмоток двигуна.

Математичне виведення взаємодії диференційних пар та перетворень систем координат докладно наведено у вставці 🧮 [Математичний апарат обчислення кута, розкладу похибок та еліптичної корекції](root:hw-sensing/hall-magnetic-encoders/math-hall-coordinate-transform.md).

### Обчислення кута через CORDIC-алгоритм

Знаючи дві ортогональні складові `Vx = B₀ · cos(θ)` та `Vy = B₀ · sin(θ)`, абсолютний кут вала однозначно визначається через чотириквадрантний арктангенс:

```
θ = atan2(Vy, Vx)
```

Зверніть увагу: амплітуда індукції `B₀` входить співмножником в обидва канали і при обчисленні відношення `Vy / Vx = sin(θ) / cos(θ) = tan(θ)` **повністю скорочується**. Це означає, що абсолютний кут взагалі не залежить від абсолютної сили магніту: якщо від нагріву поле магніту послабшає на 20%, відношення `Vy / Vx` і результат `atan2` залишаться абсолютно незмінними.

Усередині мікросхеми операція `atan2` виконується не повільним діленням із плаваючою комою, а апаратним цифровим конвеєром **CORDIC** (*Coordinate Rotation Digital Computer*). За 14–18 ітерацій послідовних зсувів і додавань цілих чисел конвеєр обчислює кут із точністю 14 біт за час від 50 наносекунд до кількох мікросекунд.

## Порівняння магнітних технологій: Hall, AMR, GMR та TMR

Окрім класичного ефекту Холла, у сучасних безконтактних енкодерах використовуються магніторезистивні структури:

| Технологія | Фізичний ефект | Чутливість (мВ/В/мТл) | Кутовий діапазон сенсора | Переваги та обмеження |
|---|---|---|---|---|
| **Hall Effect** | Сила Лоренца відхиляє носії в напівпровіднику | 0.05–0.2 | 360° (однозначно) | Повний діапазон 360°, витримує сильні магнітні поля без насичення (> 1 Тл), інтегрується в стандартний CMOS-процес; вищий рівень шуму. |
| **AMR (Анізотропний)** | Опір феромагнетика залежить від кута до намагніченості | 1.0–3.0 | 180° (період π) | Дуже висока точність, низький шум; період 180° вимагає додаткового датчика Холла для розрізнення півкуль. |
| **GMR (Гігантський)** | Спін-залежне розсіювання електронів у багатошарових плівках | 3.0–10.0 | 360° (з фіксованим шаром) | Високий вихідний сигнал, компактність; помітний магнітний гістерезис при малих полях. |
| **TMR (Тунельний)** | Спін-поляризоване тунелювання крізь діелектричний бар'єр MgO | 10.0–50.0 | 360° | Найвищий сигнал, мікроспоживання (< 1 мА), субмікронна роздільність; вища вартість, чутливість до електростатичних пробоїв (ESD). |

Ефект Холла залишається найпопулярнішим вибором для промислових сервоприводів завдяки повній відсутності магнітного гістерезису, необмеженій стійкості до перевантаження сильними полями та можливості розміщення всієї аналогової й цифрової схеми на одному кремнієвому кристалі.

## Джерела похибок, механічні допуски та калібрування

Хоча магнітний енкодер здається ідеальним приладом, у реальних умовах точність вимірювання обмежується механічними відхиленнями монтажу та тепловими дрейфами.

![Вплив робочого зазору, ексцентриситету та кутового перекосу магніту на точність](/root/hw/hw-sensing/hall-magnetic-encoders/img/air-gap-and-misalignment.svg)
*Джерела механічних похибок магнітного енкодера. 1 — робочий зазор (Air Gap 0.5–2 мм); 2 — радіальний ексцентриситет (генерує 1-шу гармоніку кутової похибки); 3 — кутовий перекіс магніту (генерує 2-гу гармоніку похибки та амплітудну еліптичність).*

### 1. Робочий осьовий зазор (Air Gap) та АРУ

Магніт повинен розташовуватися над кристалом на відстані **0.5–2.0 мм** (залежно від залишкової намагніченості та розміру магніту). 

Оскільки напруженість поля диполя спадає обернено пропорційно кубу відстані `B ∝ 1 / z³`, відхилення зазору всього на 0.5 мм змінює амплітуду сигналу в кілька разів:
- **Занадто великий зазор (> 2.5 мм):** поле стає слабшим за поріг чутливості (менше 20 мТл). Шуми квантування АЦП починають розмивати молодші біти кута, викликаючи дрижання відліків (*jitter*).
- **Занадто малий зазор (< 0.3 мм):** поле перевищує 100 мТл, що викликає насичення підсилювального тракту або напівпровідникового кристала, спотворюючи синусоїдальну форму сигналу.

Щоб компенсувати технологічний розкид зазору, мікросхеми містять контур **автоматичного регулювання підсилення (AGC — Automatic Gain Control)**. АРУ динамічно змінює коефіцієнт підсилення аналогового тракту, підтримуючи постійний радіус вектора `√(Vx² + Vy²)`. Регістр AGC мікросхеми служить надійним індикатором правильності збирання вузла: значення AGC у межах `50..180` (з 255) свідчить про ідеальний зазор.

### 2. Радіальний ексцентриситет (Off-Axis Misalignment)

Якщо вісь обертання вала зміщена відносно геометричного центру масиву Холла на кристалі на величину `Δr` (навіть на 0.1–0.3 мм через люфт підшипників або похибку посадки плати), відстань від магніту до різних елементів масиву модулюється з частотою обертання.

Це породжує **першу гармоніку кутової похибки**:

```
Δθ₁(θ) = A₁ · sin(θ + φ₁)
```

Зсув магніту всього на `0.2 мм` від центру може спричинити похибку до `1.5°–2.0°`, що неприпустимо для точного позиціонування.

### 3. Кутовий перекіс магніту (Tilt)

Якщо торець магніту не паралельний площині кристала (кутовий перекіс вала або магніту на кут `α`), амплітуди полів по осях стають неоднаковими: `Ax ≠ Ay`.

Це породжує **другу гармоніку кутової похибки**:

```
Δθ₂(θ) = A₂ · sin(2 · θ + φ₂)
```

За один оберт вала похибка двічі зростає і двічі спадає.

![Лінеаризація деформованої еліптичної траєкторії сигналів](/root/hw/hw-sensing/hall-magnetic-encoders/img/ellipse-to-circle-linearization.svg)
*Фазова площина ортогональних сигналів (Bx, By). Зліва — реальні спотворені сигнали утворюють зміщений похилий еліпс через зміщення нуля (Offset), асиметрію підсилення (Gain) та неортогональність. Справа — після матричного калібрування годограф стає ідеальним колом, забезпечуючи точний розрахунок кута.*

### 4. Температурний дрейф магнітів

Постійні магніти втрачають намагніченість із підвищенням температури. Найпоширеніші неодимові магніти **NdFeB** (класів N35SH, N45SH) мають температурний коефіцієнт залишкової магнітної індукції `α_Br ≈ -0.11 %/°C` або `-0.12 %/°C`. При нагріванні мотора від +20°C до +120°C (перепад 100°C) магнітне поле слабшає на 11–12%.

Самарій-кобальтові магніти **SmCo** значно стабільніші (`α_Br ≈ -0.035 %/°C`), проте вони дорожчі та крихкіші.

Завдяки тому, що контур АРУ мікросхеми та операція `atan2(By, Bx)` спираються на відношення сигналів, синхронне падіння амплітуди по обох осях автоматично нівелюється, зберігаючи стабільність кутових відліків у всьому робочому температурному діапазоні від -40°C до +125°C.

## Повний драйвер зчитування та лінеаризації на C та C++

Нижче наведено промислову реалізацію драйвера магнітного енкодера AS5048A. Модуль виконує:
1. Апаратний SPI-обмін із генерацією та перевіркою біта парності (Even Parity).
2. Діагностику стану магнітного поля через біти `EF` та регістр `AGC`.
3. Багатооборотне розгортання кута (Phase Unwrapping) для неперервного відліку позиції через межу 0° ↔ 360°.
4. Табличну лінеаризацію нелінійностей монтажу за калібрувальною таблицею з 32 точок із кусково-лінійною інтерполяцією.

:::tabs
```c
#include <stdint.h>
#include <stdbool.h>

#define AS5048A_CPR             16384     // 14 біт = 16384 відліків на оберт
#define AS5048A_CMD_ANGLE       0xFFFF     // Команда читання кута з бітом парності
#define AS5048A_CMD_CLEAR_ERR   0x4001     // Команда очищення регістра помилок
#define AS5048A_LUT_POINTS      32        // Точки калібрувальної таблиці

typedef struct {
    int32_t total_turns;
    uint16_t prev_raw_angle;
    bool is_initialized;
    
    // Калібрувальна таблиця похибок (у LSB для кожної з 32 рівновіддалених точок)
    int16_t error_lut[AS5048A_LUT_POINTS];
} as5048a_driver_t;

// Розрахунок біта парності Even Parity для 16-бітного кадру
static inline uint16_t as5048a_calc_parity(uint16_t value) {
    uint16_t count = 0;
    for (int i = 0; i < 16; i++) {
        if ((value >> i) & 1) count++;
    }
    return (count % 2) ? 0x8000 : 0x0000;
}

// Перевірка коректності отриманого кадру SPI
static inline bool as5048a_validate_frame(uint16_t rx_frame) {
    uint16_t count = 0;
    for (int i = 0; i < 16; i++) {
        if ((rx_frame >> i) & 1) count++;
    }
    // Кількість одиниць у слові включно з бітом 15 мусить бути парною
    if ((count % 2) != 0) return false;
    
    // Перевірка прапорця помилки Error Flag (Bit 14)
    if (rx_frame & 0x4000) return false;
    
    return true;
}

// Ініціалізація драйвера
void as5048a_init(as5048a_driver_t *dev, const int16_t *lut_32_points) {
    dev->total_turns = 0;
    dev->prev_raw_angle = 0;
    dev->is_initialized = false;
    
    for (int i = 0; i < AS5048A_LUT_POINTS; i++) {
        dev->error_lut[i] = lut_32_points ? lut_32_points[i] : 0;
    }
}

// Кусково-лінійна інтерполяція похибки за калібрувальною таблицею
static float as5048a_interpolate_error(const as5048a_driver_t *dev, uint16_t raw_angle) {
    // Крок сітки: 16384 / 32 = 512 відліків
    const uint16_t step = AS5048A_CPR / AS5048A_LUT_POINTS;
    uint16_t index_low = raw_angle / step;
    uint16_t index_high = (index_low + 1) % AS5048A_LUT_POINTS;
    
    uint16_t fraction = raw_angle % step;
    float t = (float)fraction / (float)step;
    
    float err_low = (float)dev->error_lut[index_low];
    float err_high = (float)dev->error_lut[index_high];
    
    return err_low + t * (err_high - err_low);
}

// Обробка прийнятого SPI слова: розгортання кута та лінеаризація
bool as5048a_update(as5048a_driver_t *dev, uint16_t rx_spi_frame, double *out_total_degrees) {
    if (!as5048a_validate_frame(rx_spi_frame)) {
        return false; // Помилка парності або Error Flag від чипа
    }
    
    // Витягуємо 14-бітний сирий кут (0..16383)
    uint16_t raw = rx_spi_frame & 0x3FFF;
    
    if (!dev->is_initialized) {
        dev->prev_raw_angle = raw;
        dev->total_turns = 0;
        dev->is_initialized = true;
    }
    
    // Фазове розгортання переходу через нуль (Unwrapping)
    int32_t delta = (int32_t)raw - (int32_t)dev->prev_raw_angle;
    if (delta > (AS5048A_CPR / 2)) {
        dev->total_turns--; // Перехід 0 -> 16383 (обертання проти стрілки)
    } else if (delta < -(AS5048A_CPR / 2)) {
        dev->total_turns++; // Перехід 16383 -> 0 (обертання за стрілкою)
    }
    dev->prev_raw_angle = raw;
    
    // Віднімання інтерпольованої похибки нелінійності
    float error_lsb = as5048a_interpolate_error(dev, raw);
    double corrected_single_turn_lsb = (double)raw - (double)error_lsb;
    
    // Повний неперервний кут у градусах
    double total_counts = (double)dev->total_turns * (double)AS5048A_CPR + corrected_single_turn_lsb;
    *out_total_degrees = (total_counts * 360.0) / (double)AS5048A_CPR;
    
    return true;
}
```

```cpp
#include <cstdint>
#include <array>
#include <span>
#include <optional>
#include <expected>

class MagneticEncoderAS5048A {
public:
    static constexpr uint16_t Cpr = 16384;              // 14 біт роздільність
    static constexpr uint16_t LutPoints = 32;
    static constexpr uint16_t LutStep = Cpr / LutPoints; // 512 відліків
    static constexpr uint16_t ReadAngleCmd = 0xFFFF;    // Команда з парністю

    enum class Error : uint8_t {
        ParityMismatch,
        DeviceErrorFlag,
        InvalidResponse
    };

    struct AngleReading {
        double totalDegrees;       // Неперервний багатооборотний кут
        double singleTurnDegrees;  // Кут у межах 0..360°
        int32_t turns;             // Кількість повних обертів
    };

    explicit MagneticEncoderAS5048A(std::span<const int16_t, LutPoints> errorLut = {}) noexcept {
        if (!errorLut.empty()) {
            std::copy(errorLut.begin(), errorLut.end(), errorLut_.begin());
        } else {
            errorLut_.fill(0);
        }
    }

    // Обробка сирого 16-бітного SPI кадру
    [[nodiscard]] std::expected<AngleReading, Error> processSpiFrame(uint16_t rxFrame) noexcept {
        if (!validateParity(rxFrame)) {
            return std::unexpected(Error::ParityMismatch);
        }
        if (rxFrame & 0x4000) {
            return std::unexpected(Error::DeviceErrorFlag);
        }

        const auto raw = static_cast<uint16_t>(rxFrame & 0x3FFF);

        if (!initialized_) {
            prevRaw_ = raw;
            initialized_ = true;
        }

        // Обробка переходу через границю 360° (Unwrap)
        const auto delta = static_cast<int32_t>(raw) - static_cast<int32_t>(prevRaw_);
        if (delta > (Cpr / 2)) {
            totalTurns_--;
        } else if (delta < -(Cpr / 2)) {
            totalTurns_++;
        }
        prevRaw_ = raw;

        // Лінеаризація за LUT
        const double errorLsb = interpolateError(raw);
        const double singleTurnLsb = static_cast<double>(raw) - errorLsb;

        const double singleTurnDeg = (singleTurnLsb * 360.0) / static_cast<double>(Cpr);
        const double totalCounts = static_cast<double>(totalTurns_) * static_cast<double>(Cpr) + singleTurnLsb;
        const double totalDeg = (totalCounts * 360.0) / static_cast<double>(Cpr);

        return AngleReading{
            .totalDegrees = totalDeg,
            .singleTurnDegrees = singleTurnDeg,
            .turns = totalTurns_
        };
    }

    void resetZero() noexcept {
        totalTurns_ = 0;
        initialized_ = false;
    }

    void setCalibrationTable(std::span<const int16_t, LutPoints> errorLut) noexcept {
        std::copy(errorLut.begin(), errorLut.end(), errorLut_.begin());
    }

private:
    static constexpr bool validateParity(uint16_t word) noexcept {
        uint16_t count = 0;
        for (int i = 0; i < 16; ++i) {
            if ((word >> i) & 1) ++count;
        }
        return (count % 2) == 0;
    }

    [[nodiscard]] double interpolateError(uint16_t rawAngle) const noexcept {
        const uint16_t indexLow = rawAngle / LutStep;
        const uint16_t indexHigh = (indexLow + 1) % LutPoints;
        const uint16_t fraction = rawAngle % LutStep;
        const double t = static_cast<double>(fraction) / static_cast<double>(LutStep);

        const auto errLow = static_cast<double>(errorLut_[indexLow]);
        const auto errHigh = static_cast<double>(errorLut_[indexHigh]);

        return errLow + t * (errHigh - errLow);
    }

    std::array<int16_t, LutPoints> errorLut_{};
    int32_t totalTurns_{0};
    uint16_t prevRaw_{0};
    bool initialized_{false};
};
```
