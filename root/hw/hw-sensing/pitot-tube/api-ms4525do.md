# 📋 Інтерфейс та протокол давача MS4525DO

Мікросхема **MS4525DO** від компанії TE Connectivity (раніше Measurement Specialties) — промисловий стандарт цифрового MEMS-давача диференціального тиску, який використовується в переважній більшості польотних контролерів (Pixhawk, CUAV, Matek) та автономних комплексів для вимірювання швидкості потоку за трубкою Піто–Прандтля. Давач містить п'єзорезистивний кремнієвий міст на ультратонкій мембрані, вбудований давач температури, 14-розрядний АЦП та спеціалізовану ASIC-мікросхему калібрування з інтерфейсом I2C.

Нижче наведено апаратну розпайку, специфікацію пневматичного підключення штуцерів, часові діаграми протоколу шини I2C, статусний регістр, передавальну характеристику перетворення відліків АЦП у Паскалі, аналіз порівняння з суміжними давачами родини DLHR та публічний контракт драйвера.

## Апаратне підключення та виводи

Давач випускається в 8-вивідному корпусі SOIC із двома металевими або високоміцними пластиковими штуцерами для приєднання пневматичних шлангів зовнішнім діаметром 1/16" (1.6 мм) або 3/32" (2.4 мм).

| Вивід | Назва | Тип | Призначення |
| :--- | :--- | :--- | :--- |
| **1** | `GND` | Живлення | Спільна земля схеми (0 В) |
| **2** | `VDD` | Живлення | Напруга живлення (+3.3 В або +5.0 В залежно від модифікації 3V / 5V) |
| **3** | `SDA` | Вхід/Вихід | Лінія даних I2C (відкритий стік, потребує підтяжки 2.2..4.7 кОм) |
| **4** | `SCL` | Вхід | Лінія тактування I2C (стандартна частота 100..400 кГц) |
| **5..8**| `NC` | Немає | Не підключати (внутрішні тестові виводи виробника) |

Для стабільної роботи без високочастотних перешкод безпосередньо біля виводу `VDD` (на відстані не більше 3 мм) необхідно встановити блокувальний керамічний конденсатор ємністю 100 нФ із діелектриком X7R.

### Пневматичне призначення портів

MS4525DO має два пневматичні штуцери різної довжини (Port 1 та Port 2):
1. **Port 1 (Верхній / Довший штуцер — High Pressure)**: приймає **повний тиск** `P_tot` від центрального каналу трубки Піто.
2. **Port 2 (Нижній / Бічний штуцер — Low Pressure)**: приймає **статичний тиск** `P_stat` від радіальних отворів трубки або вільної атмосфери.

Різниця тисків `ΔP = P_port1 - P_port2` повинна бути додатною при прямому русі літального апарата. При випадковому переплутуванні шлангів виміряний перепад тиску стане від'ємним, що викликає аварійне повідомлення автопілота «Negative Airspeed Differential Pressure».

## Протокол I2C, часові інтервали та бітове кодування

Давач функціонує як пасивний підпорядкований пристрій (I2C Slave). Стандартна 7-розрядна адреса I2C визначається суфіксом замовлення:
- Типова фабрична адреса: `0x28` (бінарно: `0b0101000`).
- Опційні адреси під замовлення: `0x36`, `0x46`, `0x48`, `0x56`.

Давач не використовує традиційні внутрішні регістрові покажчики адрес. Щойно на шині формується транзакція читання (I2C Read Request) за адресою пристрою, внутрішній кінцевий автомат ASIC починає передачу поточного вмісту буфера результатів перетворення.

### Часовий бюджет та опитування

Внутрішній цикл оцифрування та обчислення калібрувальних поправок ASIC займає приблизно 0.84 мс (максимум 1.0 мс). Опитування давача з частотою вище 1 кГц призводить до читання застарілих даних:
- **Час старту після ввімкнення живлення (Power-on Reset)**: 3 мс.
- **Тривалість внутрішнього перетворення**: 0.84 мс.
- **Рекомендована частота опитування шиною I2C**: від 50 Гц до 200 Гц.

Залежно від кількості прочитаних байтів за одну транзакцію давач повертає:
- **2 байти**: 14-розрядний тиск і 2 статусні біти.
- **4 байти**: 14-розрядний тиск, статус та 11-розрядну температуру кристала.

```
Байт 0: [Status (2 біти: D15..D14)] [Pressure MSB (6 бітів: D13..D8)]
Байт 1: [Pressure LSB (8 бітів: D7..D0)]
Байт 2: [Temperature MSB (8 бітів: T10..T3)]
Байт 3: [Temperature LSB (3 біти: T2..T0)] [Reserved (5 бітів: X..X)]
```

### Статусні біти (Status Bits)

Два старші біти першого байта (`[7:6]`) повідомляють поточний стан вимірювального тракту:

| Біти [7:6] | Значення статусу | Опис стану та алгоритмічна реакція |
| :---: | :--- | :--- |
| `00` | **Normal Operation** | Дані свіжі та достовірні. Результат оцифрування готовий до обробки. |
| `01` | **Command Mode** | Пристрій перебуває в сервісному режимі програмування EEPROM. Виміри недійсні. |
| `10` | **Stale Data** | Застарілі дані. Мікроконтролер виконав читання до завершення нового циклу АЦП. Драйвер повинен пропустити відлік або використати попереднє збережене значення. |
| `11` | **Diagnostic Fault** | Апаратна відмова ASIC (помилка парності контрольної суми EEPROM, обрив п'єзорезистивного моста або перебої внутрішнього тактового генератора). Драйвер повинен виставити прапорець критичної помилки. |

## Передавальна характеристика тиску

Вбудований 14-розрядний сигма-дельта АЦП видає цілочисельний діапазон від `0` до `16383` відліків (`2^14 - 1`). Залежно від замовного коду мікросхема має передавальну характеристику типу **A** (10%..90% шкали) або типу **B** (5%..95% шкали).

Для виконання з типом виходу **A** (10% to 90% Output Span):
- Відлік мінімального тиску: `Count_min = 10% · 16383 = 1638`
- Відлік максимального тиску: `Count_max = 90% · 16383 = 14745`
- Робочий розмах (Span): `Count_span = 14745 - 1638 = 13107`

Рівняння перерахунку сирого коду `Count_raw` (14 біт) у тиск:

```
P_psi = ((Count_raw - Count_min) · (P_max - P_min) / (Count_max - Count_min)) + P_min
P_pa = P_psi · 6894.757 Па/psi
```

### Виконання датчиків для вимірювання швидкості

1. **MS4525DO-DS5AI001DP (±1 psi, диференціальний симетричний)**:
   - `P_min = -1.0 psi` (−6894.76 Па)
   - `P_max = +1.0 psi` (+6894.76 Па)
   - Нульовий перепад тиску (`ΔP = 0 Па`) відповідає відліку `Count_zero = 8192` (точна середина шкали АЦП).
   - Максимальна вимірювана швидкість на рівні моря: близько 105 м/с (~380 км/год).
   - Роздільна здатність АЦП: `2 · 6894.76 / 13107 ≈ 1.05 Па/відлік`.

2. **MS4525DO-DS5AI005DP (±5 psi, високошвидкісний)**:
   - `P_min = -5.0 psi` (−34473.8 Па)
   - `P_max = +5.0 psi` (+34473.8 Па)
   - Максимальна швидкість: до 235 м/с (~850 км/год).
   - Роздільна здатність: приблизно `5.26 Па/відлік`.

## Передавальна характеристика температури

Температура напівпровідникового кристала оцифровується 11-розрядним каналом АЦП (від `0` до `2047`).
Сирий 11-бітний відлік формується об'єднанням байтів: `Count_temp = (Byte2 << 3) | (Byte3 >> 5)`.

Формула перерахунку в градуси Цельсія:

```
T_celsius = (Count_temp · 200.0 / 2047.0) - 50.0  [діапазон вимірювання від -50 °C до +150 °C]
```

## Механічна міцність, перевантаження та граничний тиск

Оскільки диференціальний давач працює з малими перепадами тиску (для діапазону ±1 psi повна шкала становить лише 6.89 кПа), ультратонка кремнієва мембрана MEMS чутлива до ударних хвиль тиску. Виробник специфікує два рівні механічної стійкості:
- **Допустимий тиск перевантаження (Proof Pressure)**: до `3 · P_span` (близько 20 кПа або 3 psi). При тиску до цього порогу мембрана зазнає пружної деформації без залишкових механічних напружень, і після зняття навантаження калібрування зберігається.
- **Тиск руйнування (Burst Pressure)**: до `5 · P_span` (понад 35 кПа або 5 psi). Перевищення цього значення призводить до фізичного розриву кремнієвого кристала мембрани, що безповоротно виводить мікросхему з ладу.

Найпоширеніша причина пошкодження давачів у польових умовах — спроба «продути» забиту трубку Піто ротом або балончиком зі стисненим повітрям без попереднього від'єднання шлангів від давача. Тиск, який створюють легені людини, легко сягає 15..25 кПа, а стиснене повітря видає понад 400 кПа, що миттєво руйнує вимірювальний міст.

## Відновлення зависання шини I2C (Bus Recovery)

Якщо живлення мікроконтролера перезавантажилося в середині циклу читання пакета, давач MS4525DO може залишитися у стані утримання лінії `SDA` у низькому логічному рівні (0 В), очікуючи чергових тактових імпульсів `SCL`. Оскільки пристрій не підтримує програмне скидання, апаратний драйвер мікроконтролера повинен реалізувати стандартну процедуру вивільнення шини під час ініціалізації:
1. Перевести вивід `SCL` у режим GPIO виходу з відкритим стоком.
2. Згенерувати 9 послідовних тактових імпульсів низької частоти (10..50 кГц), перевіряючи стан лінії `SDA`.
3. Отримавши додаткові такти, внутрішній регістр зсуву ASIC давача досилає залишок байта і відпускає лінію `SDA` у високий рівень.
4. Згенерувати стандартну умову зупинки `STOP` (перехід `SDA` з низького у високий рівень при високому `SCL`).

## Прогрів, стабільність нуля та фільтрація шуму

Після подачі напруги живлення внутрішня схема ASIC та п'єзорезистивний міст зазнають локального самопрогріву струмом живлення (споживання становить близько 3..5 мА). Протягом перших 15–30 секунд після старту спостерігається короткочасний дрейф нульової точки амплітудою 3..8 Па.

З цієї причини автопілот не повинен виконувати автоматичне калібрування нульового зсуву миттєво після ввімкнення живлення на борту. Процедуру фіксації нульового рівня запускають із затримкою не менше 10 секунд після подачі живлення за умови абсолютної нерухомості літального апарата та за відсутності поривів вітру, що дмуть у трубку.

Шум квантування та тепловий шум кремнієвих резисторів створюють розкид показів тиску в межах ±2 Па. При швидкостях польоту понад 15 м/с цей шум непомітний, однак у стані спокою на землі він трансформується у фальшиві коливання приладової швидкості від 0 до 2..3 м/с через крутизну функції квадратного кореня біля нуля (`dv/dΔP → ∞` при `ΔP → 0`). Усунення цього ефекту покладається на зону нечутливості (*deadband*) або низькочастотну фільтрацію.

Останні покоління авіоніки також використовують давачі лінійки **DLHR** (наприклад, DLHR-L01D). Вони сумісні за посадковими місцями, але мають іншу внутрішню архітектуру:
- **NimbleSense / Dual-Die**: використання двох кремнієвих чутливих елементів (грубого та точного), що дозволяє досягти динамічного діапазону понад 18 біт.
- **Шум на нулі**: у MS4525DO середньоквадратичний шум становить 1.5..2.5 Па, тоді як у DLHR — менше 0.25 Па, що усуває тремтіння швидкості на малих значеннях (до 5 м/с).
- **Протокол I2C DLHR**: потребує надсилання байта команди старту перетворення (`0xAA`), тоді як MS4525DO працює у режимі вільного циклічного оцифрування (Free Running).

```c
#ifndef MS4525DO_API_H
```

```cpp
// ms4525do_api.hpp — Сучасний типізований C++20 контракт драйвера MS4525DO
#pragma once

#include <cstdint>
#include <concepts>
#include <span>
#include <expected>

namespace AirData {

enum class SensorStatus : uint8_t {
    Ok = 0,
    CommandMode = 1,
    StaleData = 2,
    DiagnosticFault = 3,
    BusError = 4
};

struct AirspeedReading {
    float differential_pressure_pa{0.0f};
    float temperature_c{0.0f};
    bool is_fresh{false};
};

template <typename I2cBus>
concept AirspeedI2c = requires(I2cBus bus, uint8_t addr, std::span<uint8_t> buffer) {
    { bus.read(addr, buffer) } -> std::same_as<bool>;
};

template <AirspeedI2c Bus>
class Ms4525DO {
public:
    constexpr Ms4525DO(Bus& bus, uint8_t address = 0x28, float p_span_psi = 1.0f)
        : bus_(bus), address_(address),
          p_min_pa_(-p_span_psi * PSI_TO_PA),
          p_max_pa_(p_span_psi * PSI_TO_PA) {}

    std::expected<AirspeedReading, SensorStatus> read();
    bool calibrateZero(size_t samples = 100);

    void setZeroOffset(float offset_pa) noexcept { zero_offset_pa_ = offset_pa; }
    [[nodiscard]] float getZeroOffset() const noexcept { return zero_offset_pa_; }

private:
    static constexpr float PSI_TO_PA = 6894.757f;
    static constexpr float COUNT_MIN = 1638.0f;  // 10% від 16383
    static constexpr float COUNT_MAX = 14745.0f; // 90% від 16383
    static constexpr float COUNT_SPAN = COUNT_MAX - COUNT_MIN;

    Bus& bus_;
    uint8_t address_;
    float p_min_pa_;
    float p_max_pa_;
    float zero_offset_pa_{0.0f};
};

} // namespace AirData
```
