# 🧮 Стисливість повітря та розрахунок швидкостей

Швидкість польоту літального апарата чи рух газу в магістралі, виміряні за перепадом тиску в трубці Піто, спираються на припущення про нестисливість середовища лише на помірних швидкостях. Коли швидкість потоку перевищує 100 м/с (близько 360 км/год, або число Маха M > 0.3), набігаюче повітря перед носиком трубки помітно ущільнюється. Тиск у точці повного гальмування зростає сильніше, ніж передбачає класична формула нестисливого середовища, створюючи систематичну похибку завищення швидкості. Без термодинамічної поправки на стисливість та ізоентропійне стиснення газу покази приладів швидкісного літака чи далекомагістрального БПЛА втрачають достовірність.

Нижче наведено виведення рівнянь термодинамічного гальмування стисливого газу, розкладання тиску гальмування в степеневий ряд за числом Маха, а також точні алгоритми перерахунку між приладовою (IAS), каліброваною (CAS), еквівалентною (EAS) та істинною (TAS) повітряними швидкостями.

## Термодинаміка точки гальмування: ізоентропійний процес

Коли рухома маса газу набігає на центральний отвір трубки Піто, її швидкість уздовж осьової лінії течії падає від незбуреного значення v_infty до нуля в точці гальмування. Якщо процес відбувається без ударних хвиль (дозвуковий потік, M < 1) і за малий час, теплообміном із навколишнім середовищем можна знехтувати. Таке адіабатне оборотне (ізоентропійне) гальмування ідеального газу підпорядковується рівнянню Сен-Венана — Ванцеля та законам термодинаміки.

Повна ентальпія потоку в процесі гальмування залишається сталою:

```
h_tot = h_stat + (v^2 / 2)               [рівняння збереження повної енергії]
c_p · T_tot = c_p · T_stat + (v^2 / 2)    [вираз через питому теплоємність при сталому тиску c_p]
T_tot / T_stat = 1 + (v^2 / (2 · c_p · T_stat)) [ділення обох частин на c_p · T_stat]
```

Оскільки швидкість звуку в ідеальному газі виражається як `a = √(γ · R · T_stat)`, а питома теплоємність пов'язана з газом через показник адіабати `γ = c_p / c_v` (для повітря γ = 1.400) і газову сталу `R = c_p - c_v = 287.058 Дж/(кг·К)`:

```
c_p = (γ · R) / (γ - 1)                  [зв'язок теплоємності та показника адіабати]
2 · c_p · T_stat = (2 · γ · R · T_stat) / (γ - 1) [множення на 2]
2 · c_p · T_stat = (2 · a^2) / (γ - 1)   [підстановка швидкості звуку a^2 = γ·R·T]
```

Підставляючи отриманий вираз у співвідношення температур, отримуємо відоме рівняння повної температури гальмування через число Маха `M = v / a`:

```
T_tot / T_stat = 1 + ((γ - 1) / 2) · (v / a)^2 [підстановка виразу для c_p]
T_tot / T_stat = 1 + ((γ - 1) / 2) · M^2       [визначення числа Маха M = v / a]
```

Для ізоентропійного процесу тиск і температура пов'язані адіабатичним співвідношенням Пуассона `(P_tot / P_stat) = (T_tot / T_stat)^(γ / (γ - 1))`. Звідси випливає фундаментальне рівняння повного тиску гальмування стисливого газу:

```
P_tot / P_stat = (1 + ((γ - 1) / 2) · M^2)^(γ / (γ - 1))  [ізоентропійний тиск гальмування]
P_tot = P_stat · (1 + 0.2 · M^2)^3.5                     [підстановка γ = 1.4 для повітря]
```

## Розкладання в ряд: виділення динамічного тиску

Щоб побачити зв'язок між ізоентропійним тиском гальмування стисливого газу та простим законом Бернуллі для нестисливої рідини, скористаємося біноміальним розкладанням виразу в ряд Тейлора за степенями `M^2` при малих числах Маха (M < 1):

```
(1 + x)^n = 1 + n·x + (n·(n - 1) / 2)·x^2 + ...  [класичний біноміальний ряд]
x = ((γ - 1) / 2) · M^2                          [малий параметр при дозвукових швидкостях]
n = γ / (γ - 1)                                  [показник степеня ізоентропи]
```

Підставляючи коефіцієнти в ряд:

```
P_tot / P_stat = 1 + (γ / 2) · M^2 + (γ / 8) · M^4 + (γ · (2 - γ) / 48) · M^6 + ... [розклад у ряд]
P_tot - P_stat = P_stat · ((γ / 2) · M^2 + (γ / 8) · M^4 + ...)                      [віднімання одиниці]
```

Враховуючи, що швидкість звуку `a^2 = γ · P_stat / ρ`, замінимо добуток `P_stat · γ · M^2`:

```
P_stat · γ · M^2 = P_stat · γ · (v^2 / a^2)      [розкриття числа Маха]
P_stat · γ · M^2 = P_stat · γ · (v^2 / (γ · P_stat / ρ)) [підстановка швидкості звуку]
P_stat · γ · M^2 = ρ · v^2                       [динамічний фактор нестисливого потоку]
```

Підставляючи це назад у розклад різниці тисків, дістаємо перепад тиску, який вимірює диференціальний давач трубки Піто:

```
ΔP = P_tot - P_stat                              [перепад тиску на трубці Піто]
ΔP = (1/2) · ρ · v^2 · (1 + (1/4) · M^2 + ((2 - γ) / 40) · M^4 + ...) [ряд поправки на стисливість]
ΔP = q_нес · (1 + (1/4) · M^2 + (1/40) · M^4 + ...)                   [поправковий множник для повітря γ = 1.4]
```

Де `q_нес = (1/2) · ρ · v^2` — класичний нестисливий динамічний тиск.

Звідси очевидний кількісний вплив стисливості:
1. При `M = 0.1` (v ≈ 34 м/с ≈ 122 км/год): поправка становить `(1/4) · 0.01 = +0.25%`, похибкою нестисливості можна знехтувати.
2. При `M = 0.3` (v ≈ 102 м/с ≈ 367 км/год): поправка становить `(1/4) · 0.09 = +2.25%`, що вже вносить помітну похибку визначення швидкості на рівні 1.1%.
3. При `M = 0.7` (v ≈ 238 м/с ≈ 857 км/год): поправка досягає `(1/4) · 0.49 = +12.25%`, без її врахування розрахунок швидкості за формулою нестисливої рідини дасть грубу похибку понад 6%.

## Ланцюг швидкостей в аеронавігації

У реальній бортовій авіоніці та системах повітряних сигналів (Air Data Computer, ADC) перепад тиску `ΔP` проходить послідовні рівні перетворення:

```
ΔP (сирий перепад тиску)
  ↓  [калібрування нульового зсуву та шкали АЦП]
q_c (виміряний динамічний тиск)
  ↓  [рівняння Сен-Венана для стандартної атмосфери на рівні моря: P₀ = 101325 Па, a₀ = 340.294 м/с]
CAS (калібрована повітряна швидкість)
  ↓  [поправка на стисливість повітря на поточній висоті статичного тиску P_stat]
EAS (еквівалентна повітряна швидкість)
  ↓  [поправка на дійсну густину повітря ρ(P_stat, T_oat)]
TAS (істинна повітряна швидкість відносно атмосфери)
```

### Розрахунок каліброваної швидкості (CAS)

Калібрована повітряна швидкість `v_cas` — це швидкість, яку показав би ідеальний механічний прилад, проградуйований за формулою ізоентропійного стисливого потоку для умов стандартної атмосфери на рівні моря (ISA sea level: `P_0 = 101325 Па`, `ρ_0 = 1.2250 кг/м³`, `a_0 = 340.294 м/с`, `γ = 1.4`):

```
(ΔP / P_0) + 1 = (1 + ((γ - 1) / 2) · (v_cas / a_0)^2)^(γ / (γ - 1)) [рівняння Сен-Венана на рівні моря]
((ΔP / P_0) + 1)^((γ - 1) / γ) = 1 + ((γ - 1) / 2) · (v_cas / a_0)^2 [піднесення до степеня (γ-1)/γ]
((ΔP / P_0) + 1)^(2/7) - 1 = 0.2 · (v_cas / a_0)^2                   [підстановка γ = 1.4: (1.4-1)/1.4 = 2/7]
v_cas = a_0 · √(5 · (((ΔP / P_0) + 1)^(2/7) - 1))                     [точна аналітична формула CAS]
```

Якщо швидкість мала (`ΔP << P_0`), цей вираз переходить у класичний нестисливий корінь `v_ias = √(2 · ΔP / ρ_0)`.

### Розрахунок числа Маха та еквівалентної швидкості (EAS)

Число Маха польоту обчислюється безпосередньо з відношення виміряного динамічного перепаду `ΔP` до поточного дійсного статичного тиску `P_stat` (який вимірюється окремим барометричним каналом):

```
M = √(5 · (((ΔP / P_stat) + 1)^(2/7) - 1)) [поточне число Маха потоку]
```

Еквівалентна швидкість `v_eas` являє собою швидкість, що створює такий самий швидкісний напір у нестисливому потоці стандартної густини `ρ_0`:

```
q = (1/2) · ρ_0 · v_eas^2 = (1/2) · ρ_act · v_tas^2 [визначення еквівалентної швидкості]
v_eas = v_cas · (1 - (1/8) · (1 - (P_stat / P_0)) · M^2 + ...) [поправка на стисливість на висоті]
```

Для більшості безпілотних апаратів дозвукового діапазону (M < 0.4) різниця між CAS і EAS не перевищує 0.5%, тому EAS обчислюють безпосередньо через число Маха або переходять відразу до TAS.

### Розрахунок дійсної густини та істинної швидкості (TAS)

Істинна повітряна швидкість `v_tas` — це фізична швидкість літального апарата відносно повітряної маси. Для її обчислення необхідна дійсна густина повітря `ρ_act`, яка розраховується з рівняння стану Менделєєва — Клапейрона за статичним тиском `P_stat` (в Па) і температурою за бортом `T_kelvin = T_celsius + 273.15`:

```
ρ_act = P_stat / (R_air · T_kelvin)      [рівняння стану ідеального газу]
R_air = 287.058 Дж / (кг · К)            [питома газова стала сухого повітря]
```

Зв'язок між істинною швидкістю та еквівалентною (або приладовою на малих числах Маха):

```
v_tas = v_eas · √(ρ_0 / ρ_act)           [перерахунок за дійсною густиною]
v_tas = √( (2 · ΔP) / ρ_act )            [дозвукове нестисливе наближення при M < 0.3]
```

На висоті 5000 м стандартна густина повітря падає до `ρ ≈ 0.736 кг/м³`. Відношення `√(1.225 / 0.736) ≈ 1.29`. Це означає, що при показі приладової швидкості IAS = 100 км/год дійсна швидкість апарата відносно повітря (TAS) становить 129 км/год.

## Алгоритм у коді

Нижче наведено функцію швидкого та точного розрахунку всіх чотирьох швидкостей за виміряним перепадом тиску `delta_p_pa`, статичним тиском `p_static_pa` і температурою зовнішнього повітря `temp_c`.

:::tabs
```c
#include <math.h>

typedef struct {
    float ias_mps;   // приладова нестислива швидкість (м/с)
    float cas_mps;   // калібрована швидкість Сен-Венана (м/с)
    float tas_mps;   // істинна повітряна швидкість (м/с)
    float mach;      // число Маха
    float density;   // дійсна густина повітря (кг/м³)
} AirspeedCascade;

AirspeedCascade calculate_airspeeds(float delta_p_pa, float p_static_pa, float temp_c) {
    AirspeedCascade res;
    const float P0 = 101325.0f;        // тиск на рівні моря ISA (Па)
    const float RHO0 = 1.2250f;        // густина на рівні моря ISA (кг/м³)
    const float A0 = 340.294f;         // швидкість звуку ISA (м/с)
    const float R_SPEC = 287.058f;     // газова стала повітря (Дж/(кг·К))
    const float GAMMA_EXP = 2.0f / 7.0f; // (gamma - 1) / gamma для gamma = 1.4

    if (delta_p_pa < 0.0f) delta_p_pa = 0.0f;
    if (p_static_pa < 1000.0f) p_static_pa = P0;

    // 1. Приладова швидкість (неврахована стисливість)
    res.ias_mps = sqrtf((2.0f * delta_p_pa) / RHO0);

    // 2. Калібрована швидкість Сен-Венана
    float ratio_p0 = (delta_p_pa / P0) + 1.0f;
    res.cas_mps = A0 * sqrtf(5.0f * (powf(ratio_p0, GAMMA_EXP) - 1.0f));

    // 3. Число Маха за статичним тиском
    float ratio_stat = (delta_p_pa / p_static_pa) + 1.0f;
    res.mach = sqrtf(5.0f * (powf(ratio_stat, GAMMA_EXP) - 1.0f));

    // 4. Дійсна густина повітря
    float t_kelvin = temp_c + 273.15f;
    res.density = p_static_pa / (R_SPEC * t_kelvin);

    // 5. Істинна швидкість TAS (точна з поправкою на густину)
    res.tas_mps = res.cas_mps * sqrtf(RHO0 / res.density);

    return res;
}
```
```cpp
#include <cmath>
#include <algorithm>

namespace FlightDynamics {

struct AirspeedCascade {
    float ias_mps{0.0f};   // приладова нестислива швидкість (м/с)
    float cas_mps{0.0f};   // калібрована швидкість Сен-Венана (м/с)
    float tas_mps{0.0f};   // істинна повітряна швидкість (м/с)
    float mach{0.0f};      // число Маха
    float density{1.225f}; // дійсна густина повітря (кг/м³)
};

constexpr float P0_ISA = 101325.0f;        // Па
constexpr float RHO0_ISA = 1.2250f;        // кг/м³
constexpr float A0_ISA = 340.294f;         // м/с
constexpr float R_SPECIFIC = 287.058f;     // Дж/(кг·К)
constexpr float GAMMA_EXP = 2.0f / 7.0f;   // (1.4 - 1) / 1.4

[[nodiscard]] inline AirspeedCascade calculateAirspeeds(
    float delta_p_pa, 
    float p_static_pa = P0_ISA, 
    float temp_c = 15.0f) noexcept 
{
    AirspeedCascade res;
    const float dp = std::max(0.0f, delta_p_pa);
    const float p_stat = (p_static_pa > 1000.0f) ? p_static_pa : P0_ISA;

    // 1. Приладова швидкість (IAS)
    res.ias_mps = std::sqrt((2.0f * dp) / RHO0_ISA);

    // 2. Калібрована швидкість Сен-Венана (CAS)
    const float ratio_p0 = (dp / P0_ISA) + 1.0f;
    res.cas_mps = A0_ISA * std::sqrt(5.0f * (std::pow(ratio_p0, GAMMA_EXP) - 1.0f));

    // 3. Число Маха
    const float ratio_stat = (dp / p_stat) + 1.0f;
    res.mach = std::sqrt(5.0f * (std::pow(ratio_stat, GAMMA_EXP) - 1.0f));

    // 4. Дійсна густина повітря
    const float t_kelvin = temp_c + 273.15f;
    res.density = p_stat / (R_SPECIFIC * t_kelvin);

    // 5. Істинна швидкість (TAS)
    res.tas_mps = (res.density > 0.05f) 
                  ? res.cas_mps * std::sqrt(RHO0_ISA / res.density) 
                  : res.cas_mps;

    return res;
}

} // namespace FlightDynamics
```
