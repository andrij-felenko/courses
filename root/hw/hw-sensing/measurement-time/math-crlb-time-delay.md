# 🧮 Виведення межі Крамера–Рао для оцінки часової затримки

Математичне виведення нижньої межі дисперсії оцінки часу приходу сигналу (Time of Arrival, TOA), різниці часів приходу (Time Difference of Arrival, TDOA) та доплерівського зсуву частоти встановлює непорушний фізичний бар'єр точності радіовимірювань у каналі з адитивним шумом. Жоден алгоритм цифрової фільтрації, кореляційної обробки чи оптимізації не здатний отримати меншу дисперсію похибки, ніж межа Крамера–Рао (Cramér–Rao Lower Bound, CRLB), визначена геометрією сигналу, його повною енергією та часом вимірювання.

Фізична сутність інформації Фішера в радіотехніці полягає у вимірюванні крутизни (кривини) піка функції правдоподібності: що гострішим є автокореляційний пік сигналу затримки і що більша енергія накопичена на інтервалі спостереження, то сильніше спадає логарифмічна правдоподібність при відхиленні від істинного значення параметра, і то меншою є невизначеність вимірювання.

Нижче крок за кроком побудовано матрицю інформації Фішера для векторної оцінки параметрів часової затримки та частоти, обчислено середньоквадратичну смугу Габора для практичних сигналів, досліджено функцію невизначеності Вудворда, виведено граничну точність TDOA для багатопозиційних систем, проаналізовано фазовий шум генератора через дисперсію Аллана та строго доведено формули накопичення енергії зі збереженням коефіцієнтів втрат квадратування.

## 1. Модель спостереження та функція правдоподібності

Розглядаємо задачу когерентного спостереження радіосигналу на інтервалі часу вимірювання `t ∈ [0, T_meas]`. Приймач реєструє суміш затриманого на час `τ` і зсунутого за частотою на величину `f_d` корисного сигналу `s(t)` та комплексного адитивного білого гаусового шуму `n(t)` зі спектральною густиною потужності `N₀`:

```
r(t) = s(t - τ) · e^{j 2π f_d t} + n(t),    t ∈ [0, T_meas]
```

Тут `s(t)` — комплексна огинальна випроміненого зондувального або навігаційного сигналу з відомою аналітичною формою та повною енергією `E`. Шумовий процес `n(t)` має нульове математичне сподівання `𝔼[n(t)] = 0` та дельта-кореляційну функцію в часі:

```
𝔼[ n(t) · n*(u) ] = N₀ · δ(t - u)
```

Для неперервного спостереження на інтервалі `T_meas` логарифм функціонала відношення правдоподібності (Log-Likelihood Ratio) для вектора оцінюваних параметрів `θ = [τ, f_d]^T` записується через інтеграл взаємної кореляції прийнятого коливання з опорним сигналом:

```
ln Λ(r; θ) = (2 / N₀) · Re[ ∫₀^{T_meas} r(t) · s*(t - τ) · e^{-j 2π f_d t} dt ] - (1 / N₀) · ∫₀^{T_meas} |s(t - τ)|² dt
```

Оскільки повна енергія сигналу `E = ∫₀^{T_meas} |s(t - τ)|² dt` не залежить від часового зсуву `τ` (за умови, що імпульс або кодова послідовність повністю міститься всередині вікна вимірювання), другий член є постійною величиною `E / N₀`, яка не впливає на положення максимуму. Позначимо кореляційний інтеграл як `q(τ, f_d)`:

```
q(τ, f_d) = ∫₀^{T_meas} r(t) · s*(t - τ) · e^{-j 2π f_d t} dt
ln Λ(r; θ) = (2 / N₀) · Re[ q(τ, f_d) ] - (E / N₀)
```

Максимізація цього функціонала відповідає класичній узгодженій фільтрації прийнятого сигналу. Проте нас цікавить не лише алгоритм пошуку максимуму, а й статистична дисперсія оцінки поблизу цього екстремуму за наявності шумів.

## 2. Елементи інформаційної матриці Фішера

Матриця інформації Фішера `J(θ)` для двовимірного вектора параметрів `θ = [τ, f_d]^T` має розмірність `2 × 2`:

```
J = [ J_{ττ}    J_{τ f} ]
    [ J_{f τ}   J_{f f} ]
```

Кожен елемент матриці обчислюється як статистичне сподівання других частинних похідних логарифма правдоподібності:

```
J_{ij} = - 𝔼[ ∂² ln Λ(r; θ) / (∂θ_i · ∂θ_j) ]
```

Підставимо у вираз модель сигналу `r(t) = s(t - τ) · e^{j 2π f_d t} + n(t)`. Оскільки шумовий доданок `n(t)` лінійно входить у похідну і його математичне сподівання тотожно дорівнює нулю (`𝔼[n(t)] = 0`), диференціювання корисної частини сигналу дає такі інтегральні форми для інформаційної матриці:

```
J_{ττ} = (2 / N₀) · ∫₀^{T_meas} |∂ s(t - τ) / ∂t|² dt
J_{ff} = (2 / N₀) · (2π)² · ∫₀^{T_meas} t² · |s(t - τ)|² dt
J_{τf} = J_{fτ} = (2 / N₀) · 2π · Im[ ∫₀^{T_meas} t · s*(t - τ) · [∂ s(t - τ) / ∂t] dt ]
```

Для симетричних радіоімпульсів та сигналів із симетричним спектром перехресний коефіцієнт зв'язку між часом і частотою дорівнює нулю (`J_{τf} = 0`). Це означає, що похибка вимірювання затримки не корелює з похибкою вимірювання доплерівського зсуву, і матриця Фішера стає діагональною, розділяючи оцінки затримки та частоти на дві незалежні скалярні задачі.

## 3. Спектральне подання та середньоквадратична смуга Габора

Перейдемо до частотної області за допомогою прямого перетворення Фур'є комплексної огинальної `s(t) ↔ S(f)`:

```
s(t) = ∫_{-∞}^{∞} S(f) · e^{j 2π f t} df
```

Часова похідна огинальної сигналу в частотній області відповідає множенню спектра на множник `j 2π f`:

```
∂ s(t) / ∂t = ∫_{-∞}^{∞} (j 2π f) · S(f) · e^{j 2π f t} df
```

Застосуємо теорему Парсеваля до інтеграла енергії похідної сигналу за часом:

```
∫₀^{T_meas} |∂ s(t) / ∂t|² dt
= ∫_{-∞}^{∞} |j 2π f · S(f)|² df                           [перехід за теоремою Парсеваля]
= 4π² · ∫_{-∞}^{∞} f² · |S(f)|² df                         [винесення константи (2π)²]
= 4π² · β_rms² · E                                         [за означенням смуги Габора β_rms]
```

Тут `β_rms` — середньоквадратична смуга сигналу за Габором (Gabor Root-Mean-Square Bandwidth), яка є нормованим другим центральним моментом спектральної густини потужності:

```
β_rms² = [ ∫_{-∞}^{∞} f² · |S(f)|² df ] ÷ [ ∫_{-∞}^{∞} |S(f)|² df ]
```

Повна енергія сигналу обчислюється як площа під квадратом модуля спектра:

```
E = ∫_{-∞}^{∞} |S(f)|² df = ∫₀^{T_meas} |s(t)|² dt
```

Підставивши вираз для інтеграла енергії похідної в елемент матриці Фішера `J_{ττ}`, отримуємо:

```
J_{ττ}
= (2 / N₀) · 4π² · β_rms² · E                              [підстановка спектрального інтеграла]
= 4π² · β_rms² · (2E / N₀)                                 [групування безрозмірного відношення енергії до шуму]
```

Цей вираз наочно демонструє, що інформація про час затримки зростає пропорційно двом незалежним факторам: квадрату середньоквадратичної смуги частот `β_rms²` та накопиченому енергетичному відношенню сигнал/шум `2E / N₀`.

## 4. Нижня межа Крамера–Рао (CRLB) для затримки TOA

За нерівністю Крамера–Рао дисперсія будь-якої незміщеної оцінки `τ̂` часової затримки обмежена знизу величиною, оберненою до діагонального елемента матриці Фішера:

```
Var(τ̂) ≥ 1 / J_{ττ}
```

Підставивши обчислене значення `J_{ττ}`:

```
Var(τ̂) ≥ 1 / [ 4π² · β_rms² · (2E / N₀) ]
```

Стандартне середньоквадратичне відхилення (Root-Mean-Square Error, RMSE) оцінки часу приходу:

```
σ_τ = √Var(τ̂) ≥ 1 / [ 2π · β_rms · √(2E / N₀) ]
```

### Обчислення середньоквадратичної смуги для прямокутного спектра

Розглянемо випадок ідеального смугового сигналу з прямокутною спектральною густиною потужності у смузі `[-B/2, B/2]`:

```
|S(f)|² = S₀,    для |f| ≤ B / 2
```

Обчислимо квадрат середньоквадратичної смуги за інтегральним означенням Габора:

```
β_rms²
= [ ∫_{-B/2}^{B/2} f² · S₀ df ] ÷ [ ∫_{-B/2}^{B/2} S₀ df ]  [підстановка прямокутного спектра]
= [ S₀ · (f³ / 3)|_{-B/2}^{B/2} ] ÷ [ S₀ · B ]             [взяття первісної від f²]
= [ (B³ / 24) - (-B³ / 24) ] ÷ B                           [підстановка меж інтегрування]
= (B³ / 12) ÷ B                                            [спрощення чисельника]
= B² / 12                                                  [скорочення на ширину смуги B]
```

Отже, зв'язок між смугою пропускання `B` та смугою Габора `β_rms` для прямокутного спектра має простий вигляд:

```
β_rms = B / √12 = B / (2√3)
```

Підставивши цей результат у формулу для `σ_τ`, маємо:

```
σ_τ
≥ 1 / [ 2π · (B / (2√3)) · √(2E / N₀) ]                    [підстановка β_rms прямокутного спектра]
= √3 / [ π · B · √(2E / N₀) ]                              [скорочення двійки та перенесення √3 у чисельник]
```

### Явний вираз через вхідне відношення сигнал/шум та час спостереження T_meas

Для сигналу з середньою потужністю `P_s = E / T_meas` та шумом у смузі `B` з потужністю `P_n = N₀ · B`, вхідне відношення сигнал/шум дорівнює `SNR_in = P_s / P_n`. Повне відношення енергії до шуму виражається через час спостереження `T_meas`:

```
2E / N₀ = 2 · (P_s · T_meas) / (P_n / B) = 2 · SNR_in · B · T_meas
```

Підставивши це значення у вираз межі Крамера–Рао:

```
Var(τ̂) ≥ 3 / [ 2π² · B³ · SNR_in · T_meas ]
σ_τ    ≥ √3 / [ 2π · B · √(2 · SNR_in · B · T_meas) ]
```

Перемноживши похибку часу на швидкість світла у вакуумі `c ≈ 2.99792458 × 10⁸ м/с`, отримуємо нижню межу похибки вимірювання дальності:

```
σ_R = c · σ_τ ≥ [ c · √3 ] ÷ [ 2π · B · √(2 · SNR_in · B · T_meas) ]
```

## 5. Межа Крамера–Рао для доплерівського зсуву частоти

Обчислимо діагональний елемент матриці Фішера `J_{ff}` для постійного за амплітудою радіоімпульсу тривалістю `T_meas`:

```
|s(t)|² = P_s,    t ∈ [-T_meas / 2, T_meas / 2]
```

Обчислимо інтеграл другого моменту часу:

```
∫_{-T_meas/2}^{T_meas/2} t² · P_s dt
= P_s · (t³ / 3)|_{-T_meas/2}^{T_meas/2}                    [інтегрування полінома t²]
= P_s · [ (T_meas³ / 24) - (-T_meas³ / 24) ]               [підстановка симетричних меж]
= P_s · T_meas³ / 12                                       [спрощення дробу]
= (E · T_meas²) / 12                                       [оскільки повна енергія E = P_s · T_meas]
```

Підставимо отриманий часовий момент у вираз для елемента матриці Фішера `J_{ff}`:

```
J_{ff}
= (2 / N₀) · 4π² · (E · T_meas² / 12)                      [підстановка другого моменту часу]
= (2π² / 3) · T_meas² · (2E / N₀)                          [групування відношення енергії до шуму]
```

Звідси дисперсія та середньоквадратична похибка оцінки доплерівського зсуву частоти `f̂_d`:

```
Var(f̂_d) ≥ 1 / J_{ff} = 3 / [ 2π² · T_meas² · (2E / N₀) ]
σ_{f_d}  ≥ √3 / [ π · T_meas · √(2E / N₀) ]
```

Підставивши вираз для повної енергії `2E / N₀ = 2 · SNR_in · B · T_meas`:

```
σ_{f_d} ≥ √3 / [ π · T_meas · √(2 · SNR_in · B · T_meas) ] = √3 / [ π · √(2 · SNR_in · B) · T_meas^{1.5} ]
```

Цей фундаментальний висновок підкреслює глибоку асиметрію між вимірюванням часу та частоти:
1. Похибка оцінки затримки часу `σ_τ` спадає зі зростанням часу вимірювання як `T_meas^{-0.5}`.
2. Похибка оцінки частоти `σ_{f_d}` спадає зі зростанням часу вимірювання як `T_meas^{-1.5}` (тобто утричі швидше за логарифмічною шкалою), оскільки час `T_meas` збільшує не лише накопичену енергію, а й інтервал спостереження за набігом фази.

## 6. Зв'язок із функцією невизначеності Вудворда

Поведінка кореляційного відгуку приймача в площині «час–частота» описується функцією невизначеності Вудворда (Woodward Ambiguity Function) `χ(τ, f_d)`:

```
χ(τ, f_d) = ∫_{-∞}^{∞} s(t) · s*(t - τ) · e^{-j 2π f_d t} dt
```

Функція невизначеності задовольняє закон збереження об'єму (теорема Мояла):

```
∫_{-∞}^{∞} ∫_{-∞}^{∞} |χ(τ, f_d)|² dτ df_d = |χ(0, 0)|² = E²
```

Повний об'єм під поверхнею невизначеності є строго фіксованим і залежить лише від енергії сигналу `E`. Збільшення часу вимірювання `T_meas` стискає центральний пік уздовж осі частот `f_d` (ширина головної пелюстки `Δf ≈ 1 / T_meas`), але згідно з теоремою збереження об'єму витісняє енергію у бічні пелюстки або розширює невизначеність за іншими напрямками, якщо сигнал не має спеціальної кодової структури.

Розклад функції невизначеності в околі головного піка `(0, 0)` за формулою Тейлора дає прямий зв'язок з елементами матриці Фішера:

```
|χ(τ, f_d)|² / E² ≈ 1 - 2π² · [ β_rms² · τ² + T_rms² · f_d² ]
```

де `T_rms² = (1 / E) · ∫ t² |s(t)|² dt` — середньоквадратична тривалість сигналу. Це демонструє, що елементи матриці Фішера `J_{ττ}` та `J_{ff}` є безпосередньо коефіцієнтами кривини піка функції невизначеності Вудворда у вершині.

## 7. Межа Крамера–Рао для різниці часів приходу (TDOA)

У системах пасивної радіолокації, радіотехнічного моніторингу простору та мультилатерації положення невідомого джерела випромінювання оцінюється за різницею моментів приходу сигналу між парами просторово рознесених синхронізованих приймальних постів (TDOA).

Нехай два приймачі 1 та 2 реєструють сигнал від одного джерела з взаємною часовою затримкою `τ_{12} = τ₁ - τ₂`:

```
r₁(t) = s(t - τ₁) + n₁(t)
r₂(t) = s(t - τ₂) + n₂(t)
```

Шумові процеси `n₁(t)` та `n₂(t)` у двох географічно рознесених пунктах є взаємно статистично незалежними:

```
𝔼[ n₁(t) · n₂*(u) ] = 0
```

Оцінка взаємної затримки здійснюється за положенням максимуму узагальненої функції взаємної кореляції (Generalized Cross-Correlation, GCC):

```
R_{12}(τ) = ∫₀^{T_meas} r₁(t) · r₂*(t - τ) dt
```

Інформація Фішера для різниці часів приходу `τ_{12}` у смузі частот `B` при тривалості запису `T_meas` визначається формулою Гана (Hahn) та Картера (Carter):

```
J_{TDOA} = 2 · T_meas · ∫₀^{B} (2π f)² · [ |γ_{12}(f)|² / (1 - |γ_{12}(f)|²) ] df
```

де `|γ_{12}(f)|²` — функція квадрата когерентності сигналів між двома приймачами:

```
|γ_{12}(f)|² = [ SNR₁(f) · SNR₂(f) ] ÷ [ (1 + SNR₁(f)) · (1 + SNR₂(f)) ]
```

Якщо відношення сигнал/шум на обох приймачах однакове (`SNR₁ = SNR₂ = SNR_in`) і спектри є рівномірними у смузі `B`:

```
|γ_{12}|² / (1 - |γ_{12}|²)
= [ SNR_in² / (1 + SNR_in)² ] ÷ [ 1 - SNR_in² / (1 + SNR_in)² ]
= SNR_in² / [ (1 + SNR_in)² - SNR_in² ]
= SNR_in² / [ 2 · SNR_in + 1 ]
```

Підставивши цей вираз в інтеграл інформації Фішера:

```
J_{TDOA}
= 2 · T_meas · [ SNR_in² / (2 · SNR_in + 1) ] · 4π² · ∫₀^{B} f² df  [винесення спектральних констант]
= 8π² · T_meas · [ SNR_in² / (2 · SNR_in + 1) ] · (B³ / 3)          [інтегрування f² у межах від 0 до B]
= (8π² / 3) · B³ · T_meas · [ SNR_in² / (2 · SNR_in + 1) ]          [групування членів]
```

Звідси нижня межа середньоквадратичної похибки TDOA становить:

```
σ_{TDOA} ≥ √[ 1 / J_{TDOA} ] = √[ 3 · (2 · SNR_in + 1) / (8π² · B³ · T_meas · SNR_in²) ]
```

При низькому відношенні сигнал/шум (`SNR_in ≪ 1`):

```
σ_{TDOA} ≈ √3 / [ 2√2 · π · B^{1.5} · √T_meas · SNR_in ]
```

Ця залежність підтверджує критичну відмінність пасивних систем TDOA від активних TOA: за слабкого сигналу похибка вимірювання затримки TDOA обернено пропорційна не кореню, а першому степеню відношення сигнал/шум `SNR_in`. Отже, щоб компенсувати падіння потужності джерела на 10 дБ, час вимірювання `T_meas` у пасивній системі необхідно збільшувати у 100 разів (`+20 дБ`), що накладає жорсткі вимоги на когерентність та стабільність опорних генераторів постів спостереження.

## 8. Геометричний фактор зниження точності (GDOP) у задачі позиціювання

У тривимірному просторі вектор положення об'єкта `x = [x, y, z]^T` та зсув годинника `Δt` визначаються із системи рівнянь псевдодальностей до `K` навігаційних маяків (супутників або базових станцій):

```
ρ_k = ||x - s_k|| + c · Δt + ε_k,    k = 1, ..., K
```

де `s_k` — відомі координати `k`-го передавача, а `ε_k` — похибка вимірювання затримки з дисперсією `σ_k² = c² · Var(τ̂_k)`. Лінеаризація системи навколо наближеного положення дає матричне рівняння для приростів координат `Δx`:

```
Δρ = H · Δx + ε
```

де `H` — матриця напрямних косинусів розмірності `K × 4`:

```
H = [ -u₁_x  -u₁_y  -u₁_z   1 ]
    [ -u₂_x  -u₂_y  -u₂_z   1 ]
    [  ...     ...     ...  . ]
    [ -u_K_x -u_K_y -u_K_z  1 ]
```

Коваріаційна матриця оцінки вектора положення та зсуву годинника `P_x` за методом найменших квадратів:

```
P_x = (H^T · W · H)^{-1}
```

де `W = diag(1/σ₁², 1/σ₂², ..., 1/σ_K²)` — вагова матриця, елементи якої обернено пропорційні дисперсіям Крамера–Рао відповідних каналів вимірювання. Якщо дисперсії вимірювання однакові для всіх променів (`σ_k = σ_R`), матриця набуває вигляду:

```
P_x = σ_R² · (H^T · H)^{-1}
```

Геометричний фактор зниження точності (Geometric Dilution of Precision, GDOP) визначається як квадратний корінь зі сліду матриці `(H^T · H)^{-1}`:

```
GDOP = √[ Tr( (H^T · H)^{-1} ) ]
σ_pos = GDOP · σ_R = GDOP · c · σ_τ
```

Цей результат завершує математичний міст від мікросекундного часу вимірювання на рівні фізичного сигналу до просторової похибки навігації:
1. Час вимірювання `T_meas` та смуга `B` визначають похибку часу `σ_τ` згідно з межею Крамера–Рао.
2. Множення на швидкість світла `c` переводить часову похибку в радіальну дальність `σ_R`.
3. Геометрія взаємного розташування маяків масштабує дальність через коефіцієнт `GDOP`, визначаючи кінцеву точність просторових координат `σ_pos`.

## 9. Вплив фазового шуму опорного генератора та дисперсія Аллана

У реальному приймачі опорний гетеродин не є ідеально монохроматичним генератором. Його фаза зазнає випадкових флуктуацій `φ(t)`, що описуються спектральною густиною фазового шуму `S_φ(f)`. На інтервалі накопичення `T_meas` випадковий набіг фази призводить до накопичення похибки часу, яка не зменшується при збільшенні енергії сигналу.

Для оцінки нестабільності генератора на різних масштабах часу вимірювання `τ_obs` використовують двовибіркову дисперсію Аллана (Allan Variance) `σ_y²(τ_obs)`:

```
σ_y²(τ_obs) = (1 / 2) · 𝔼[ (y_{k+1} - y_k)² ]
```

де `y_k` — середнє відносне відхилення частоти на `k`-му інтервалі тривалості `τ_obs`.

Часова дисперсія похибки утримання часової шкали генератором на інтервалі `T_meas` виражається через дисперсію Аллана:

```
σ_{time,osc}²(T_meas) = T_meas² · σ_y²(T_meas)
```

Повна дисперсія вимірювання часової затримки реальним приймачем складається з двох незалежних процесів — адитивного теплового шуму (межа Крамера–Рао) та нестабільності опорного генератора:

```
Var_total(τ) = Var_{CRLB}(τ) + σ_{time,osc}²(T_meas)
Var_total(τ) ≈ [ 3 / (2π² B³ SNR_in · T_meas) ] + [ T_meas² · σ_y²(T_meas) ]
```

Аналіз цієї суми виявляє фундаментальний інженерний парадокс часу вимірювання:
- При малому `T_meas` домінує перший доданок (тепловий шум AWGN), і збільшення часу накопичення зменшує похибку як `1 / T_meas`.
- При надто великому `T_meas` (коли `T_meas` перевищує інтервал короткочасної стабільності кварцового резонатора або термостатованого генератора TCXO/OCXO), починає домінувати другий доданок: фліккер-шум частоти та випадкове блукання фази генерують похибку, яка зростає пропорційно `T_meas²`.

Розглянемо практичний числовий приклад. Для типового термокомпенсованого кварцового генератора (TCXO) з відносною нестабільністю `σ_y(1 с) ≈ 1 × 10^{-9}` похибка утримання фази за 1 секунду становить `σ_{time,osc} = 1 с × 10^{-9} = 1 нс` (що еквівалентно 30 см дальності). Якщо ж використати високостабільний термостатований генератор (OCXO) або рубідієвий стандарт із `σ_y(1 с) ≈ 1 × 10^{-11}`, похибка генератора спадає до 10 пікосекунд (3 мм), що дозволяє безпечно нарощувати час когерентного накопичення `T_meas` до кількох секунд без ризику фазового розмиття кореляційного піка.

Мінімум повної похибки визначає оптимальний час вимірювання `T_meas,opt`, за межами якого подальше інтегрування не покращує, а погіршує реальну метрологічну точність оцінки часу.

## 10. Числовий розрахунок для GNSS та 5G PRS

Порівняємо теоретичні межі точності вимірювання затримки для двох типових систем зв'язку та радіонавігації.

### Параметри GPS L1 C/A:
- Смуга сигналу: `B = 2.046 МГц`
- Співвідношення потужності до густини шуму: `C/N₀ = 42 дБ-Гц` (`15848.9 Гц`)
- Вхідний SNR у смузі `B`: `SNR_in = (C/N₀) / B = 15848.9 / 2046000 ≈ 0.00774` (`-21.1 дБ`)
- Час вимірювання (одна епоха навігації): `T_meas = 20 мс` (`0.02 с`)

Обчислення за формулою межі Крамера–Рао:

```
2E / N₀
= 2 · SNR_in · B · T_meas                                   [формула відношення енергії до шуму]
= 2 · 0.00774 · 2046000 · 0.02                              [підстановка числових значень]
= 633.9                                                     [енергетичний коефіцієнт]

σ_τ
= √3 / [ π · B · √(2E / N₀) ]                               [формула CRLB для прямокутного спектра]
= 1.73205 / [ 3.14159 · 2046000 · √633.9 ]                  [підстановка значень]
= 1.73205 / [ 6427770 · 25.177 ]                            [обчислення знаменника]
= 1.070 × 10^{-8} с ≈ 10.70 нс

σ_R = c · σ_τ = 2.99792 × 10⁸ · 10.70 × 10^{-9} ≈ 3.21 м
```

### Параметри 5G NR PRS (Positioning Reference Signal, FR1):
- Смуга сигналу: `B = 100 МГц`
- Співвідношення потужності до густини шуму: `C/N₀ = 65 дБ-Гц` (`3.162 × 10⁶ Гц`)
- Вхідний SNR у смузі `B`: `SNR_in = 3.162 × 10⁶ / 100 × 10⁶ ≈ 0.0316` (`-15.0 дБ`)
- Час вимірювання (пакет позиціювання): `T_meas = 10 мс` (`0.01 с`)

Обчислення:

```
2E / N₀
= 2 · 0.03162 · 100000000 · 0.01                            [підстановка числових значень]
= 63240.0                                                   [енергетичний коефіцієнт]

σ_τ
= √3 / [ π · 100 × 10⁶ · √63240.0 ]                         [підстановка значень 5G PRS]
= 1.73205 / [ 3.14159 × 10⁸ · 251.47 ]                      [обчислення знаменника]
= 2.192 × 10^{-11} с ≈ 21.92 пс

σ_R = c · σ_τ = 2.99792 × 10⁸ · 21.92 × 10^{-12} ≈ 0.00657 м ≈ 6.57 мм
```

Ширша смуга частот (100 МГц проти 2 МГц) зменшує похибку вимірювання відстані з 3.2 метрів до 6.6 міліметрів за однакового порядку часу вимірювання, що бездоганно узгоджується з теоретичною залежністю `σ_τ ∝ 1 / B^{1.5}`.
