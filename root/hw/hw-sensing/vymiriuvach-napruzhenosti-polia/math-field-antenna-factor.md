# 🧮 Математичний апарат вимірювання електромагнітного поля та чинник антени

Вимірювання параметрів електромагнітної хвилі базується на переході від польових векторних величин (напруженості електричного поля `E` та магнітного поля `H`) до скалярних електричних величин у колі детектора (напруги `V` та потужності `P`). Нижче наведено строге виведення фундаментальних співвідношень для вільного простору, математичну модель електрично короткого диполя, виведення антенного фактора `AF`, аналіз квадратичного детектування діодом Шотткі та доведення просторової ізотропії ортогональної трійки датчиків.

## 1. Вектор Пойнтінга та хвильовий опір вільного простору

Перенесення енергії електромагнітним полем у довільній точці простору описується вектором густини потоку потужності Пойнтінга `S`:
```
S = E × H
```
де `E` — вектор напруженості електричного поля (В/м), а `H` — вектор напруженості магнітного поля (А/м).

У далекій зоні випромінювання (Fraunhofer zone), на відстанях `r >> λ / (2π)` від джерела, електромагнітна хвиля є локально плоскою поперечною хвилею (TEM — Transverse Electro-Magnetic), у якій вектори `E`, `H` та напрямок поширення `k̂` взаємно перпендикулярні. Відношення модулів векторів визначається хвильовим опором середовища `Z_0`:
```
Z_0 = √(μ_0 / ε_0)                                                          [визначення хвильового опору середовища]
    = √( (4π · 10⁻⁷) / (8.854187817 · 10⁻¹²) )                              [підстановка магнітної та електричної сталих вакууму]
    ≈ 376.730313 Ом                                                         [чисельне обчислення кореня]
    ≈ 120π Ом                                                               [наближення через π]
```
де:
- `μ_0 = 4π · 10⁻⁷` Гн/м — магнітна проникність вакууму;
- `ε_0 ≈ 8.854187817 · 10⁻¹²` Ф/м — електрична проникність вакууму.

Оскільки `|H| = |E| / Z_0`, модуль вектора Пойнтінга (густина потоку енергії `S`, виражена у Вт/м²) пов'язаний із напруженістю електричного або магнітного поля співвідношеннями:
```
S = |E| · |H|                                                               [модуль вектора Пойнтінга для перпендикулярних полів]
  = |E| · (|E| / Z_0)                                                       [підстановка співвідношення |H| = |E| / Z_0]
  = |E|² / Z_0                                                              [алгебраїчне множення]
  = |H|² · Z_0                                                              [еквівалентний запис через напруженість магнітного поля]
```

Для перерахунку в практичні радіотехнічні одиниці (мкВт/см²):
```
1 Вт/м² = 100 мкВт/см² = 0.1 мВт/см²
```

## 2. Електрично короткий диполь та ємнісний подільник

Вимірювальний зонд електричного поля будується на базі прямолінійного симетричного диполя фізичної довжини `L`. Для забезпечення широкосмуговості без паразитних резонансів диполь обирають електрично коротким: `L << λ` (зазвичай `L ≤ 0.1 λ`).

За умови `L << λ` розподіл амплітуди високочастотного струму `I(z)` вздовж плечей диполя (від центру `z = 0` до кінців `z = ± L/2`) є лінійно спадним (трикутним):
```
I(z) = I_0 · (1 - (2 · |z| / L))
```

Діюча довжина антени `h_eff` (effective length) визначається інтегруванням розподілу струму, нормованого на струм у точці живлення `I_0`:
```
h_eff = (1 / I_0) · ∫_{-L/2}^{+L/2} I(z) dz                                 [інтегральне визначення діючої довжини антени]
      = 2 · ∫_0^{L/2} (1 - (2z / L)) dz                                     [парність підінтегральної функції струму]
      = 2 · [ z - z²/L ]_0^{L/2}                                            [первісна функція інтегрування]
      = 2 · ( (L/2) - (L²/4L) )                                             [підстановка меж інтегрування]
      = 2 · (L/4)                                                           [зведення подібних доданків]
      = L / 2                                                               [результат: діюча довжина короткого диполя]
```

Наведена на клемах диполя напруга холостого ходу `V_oc` (open-circuit voltage) у полі з напруженістю `E`, орієнтованому вздовж осі диполя, дорівнює:
```
V_oc = E · h_eff = E · (L / 2)
```

Власний імпеданс електрично короткого диполя `Z_ant` носить практично суто ємнісний характер:
```
Z_ant = R_rad - j / (ω · C_ant)
```
де опір випромінювання `R_rad = 20π² · (L / λ)² << 1 Ом`, а власна ємність диполя `C_ant` становить одиниці пікофарад:
```
C_ant ≈ (π · ε_0 · L) / (ln(L / (2a)) - 1)
```
де `a` — радіус провідника диполя.

Коли диполь навантажується на діодний детектор або вхідний каскад із власною ємністю `C_det` та опором `R_det`, фактична напруга на вході детектора `V_in` визначається комплексним коефіцієнтом передачі ємнісного подільника:
```
V_in(ω) = V_oc · ( (1 / (jω C_det)) / (1 / (jω C_ant) + 1 / (jω C_det)) )   [коефіцієнт передачі ємнісного подільника]
        = V_oc · ( C_ant / (C_ant + C_det) )                               [множення чисельника й знаменника на jω C_ant C_det]
        = E · (L / 2) · ( C_ant / (C_ant + C_det) )                        [підстановка ЕРС холостого ходу V_oc = E · L / 2]
```
Зверніть увагу: оскільки і реактивний опір антени, і опір детектора спадають обернено пропорційно до `ω`, коефіцієнт передачі `V_in / E` не залежить від частоти аж доти, доки `L` залишається меншим за `0.1 λ`. Це забезпечує унікальну властивість електрично короткого диполя: плоску амплітудно-частотну характеристику в смузі від сотень кілогерців до кількох гігагерців.

## 3. Математика квадратичного детектування діодом Шотткі

Вольт-амперна характеристика діода Шотткі описується рівнянням Шоклі:
```
I_d(V) = I_s · ( exp( V / (n · V_t) ) - 1 )
```
де `I_s` — зворотний струм насичення, `n` — коефіцієнт неідеальності (1.02–1.15 для діодів Шотткі), `V_t = k_B · T / q` — термічний потенціал (~25.85 мВ при 300 К).

Розкладемо експоненту в ряд Тейлора навколо робочої точки нульового зміщення (`V = 0`):
```
exp(x) = 1 + x + x²/2 + x³/6 + ...
I_d(V) = I_s · [ ( V / (n V_t) ) + (1/2) · ( V / (n V_t) )² + (1/6) · ( V / (n V_t) )³ + ... ]
```

Нехай на діод надходить високочастотна гармонічна напруга `V(t) = V_rf · cos(ω t)`:
```
I_d(t) = I_s · [ ( V_rf · cos(ω t) / (n V_t) ) + (1/2) · ( V_rf² · cos²(ω t) / (n² V_t²) ) + ... ]
```
Враховуючи тригонометричну тотожність `cos²(ω t) = 1/2 + 1/2 · cos(2ω t)`, постійна складова випрямленого струму `I_DC` (усереднена за період ВЧ коливань `T = 2π / ω`) дорівнює:
```
I_DC = (1 / T) · ∫_0^T I_d(t) dt                                            [усереднення струму за період коливань T]
     = (1 / T) · ∫_0^T I_s · (1/2) · ( V_rf² · cos²(ω t) / (n² V_t²) ) dt   [підстановка другого члена ряду Тейлора]
     = I_s · (1/2) · ( V_rf² / (n² V_t²) ) · (1/2)                          [інтегрування cos²(ω t): середнє значення дорівнює 1/2]
     = ( I_s / (4 · n² · V_t²) ) · V_rf²                                    [спрощення коефіцієнтів]
```

Випрямлена постійна напруга на навантаженні `R_L` у режимі малого сигналу (`V_rf << n · V_t`, тобто рівні потужності нижче -20 дБм):
```
V_DC = I_DC · R_L = [ ( I_s · R_L ) / (4 · n² · V_t²) ] · V_rf² ∝ V_rf² ∝ E²
```
Це квадратичний режим (Square-Law Detection). У цьому режимі вихідна напруга детектора строго пропорційна квадрату напруженості електричного поля `E²`, а отже — безпосередньо пропорційна середній потужності та густині потоку Пойнтінга `S` для будь-якої складної форми сигналу.

Коли амплітуда `V_rf` перевищує `n · V_t` (> 100 мВ, потужність понад 0 дБм), діод переходить у лінійний режим випрямлення пікового значення:
```
V_DC ≈ V_rf - V_forward
```
У цій зоні відгук приладу починає залежати від пік-фактора (Crest Factor) сигналу, що вимагає введення табличної кусочно-поліноміальної лінеаризації в DSP-конвеєрі.

## 4. Чинник антени (Antenna Factor, AF)

У радіовимірювальній практиці напруженість поля `E` пов'язують із напругою `V_L`, виміряною на узгодженому навантаженні приймача `R_L = 50 Ом`, через передавальний коефіцієнт — чинник антени `AF` (Antenna Factor):
```
AF = E / V_L
```
Одиницею вимірювання `AF` у лінійному масштабі є м⁻¹ (1/м). У логарифмічній шкалі децибелів:
```
AF_dB = 20 · log10(AF) = 20 · log10(E / V_L)
```
де напруженість поля `E` виражена у В/м, а напруга `V_L` — у В. Якщо `E` задано в дБ(мкВ/м), а `V_L` — у дБ(мкВ):
```
E [дБ(мкВ/м)] = V_L [дБ(мкВ)] + AF_dB [дБ(1/м)]
```

### Виведення формули чинника антени через підсилення G та довжину хвилі λ

Зв'яжемо `AF` з коефіцієнтом підсилення антени `G` та довжиною хвилі `λ`. Ефективна площа розкриву антени `A_e` (effective aperture) дорівнює:
```
A_e = (λ² / (4π)) · G
```
Потужність `P_r`, що виділяється на навантаженні `R_L`:
```
P_r = S · A_e = (E² / Z_0) · (λ² / (4π)) · G
```
З іншого боку, потужність через напругу на навантаженні `R_L`:
```
P_r = V_L² / R_L
```
Прирівнюючи вирази для потужності:
```
V_L² / R_L = (E² / Z_0) · (λ² / (4π)) · G                                   [баланс прийнятої потужності P_r на навантаженні]
(E / V_L)² = (4π · Z_0) / (R_L · λ² · G)                                    [вираження відношення (E / V_L)²]
AF = E / V_L = (2π / λ) · √( Z_0 / (π · R_L · G) )                          [добування квадратного кореня для чинника антени]
```
Підставляючи стандартні константи `Z_0 = 376.73 Ом` та `R_L = 50 Ом`:
```
√( Z_0 / (π · R_L) ) = √( 376.73 / (50π) ) = √( 2.3983 ) ≈ 1.54865

AF = (2π / λ) · (1.54865 / √G) = (9.73 / λ) · (1 / √G)
```

Переходячи до децибельної форми з частотою `f` у МГц (`λ = 300 / f_MHz`):
```
AF_dB = 20 · log10(9.73 / (300 / f_MHz)) - 10 · log10(G)                    [підстановка довжини хвилі λ = 300 / f_MHz]
      = 20 · log10(f_MHz) - 20 · log10(300 / 9.73) - 10 · log10(G)          [властивість логарифма частки: log(a/b) = log a - log b]
      = 20 · log10(f_MHz) - 29.79 - G_dBi                                  [обчислення 20·log10(30.83) ≈ 29.79 та перехід до G_dBi]
```
Ця формула показує фундаментальну закономірність: зі зростанням частоти за сталого геометричного підсилення чинник антени зростає зі швидкістю 20 дБ на декаду.

## 5. Доведення просторової ізотропії триосьового зонда

Нехай у точці вимірювання існує довільно поляризоване гармонічне електричне поле з амплітудним вектором `E_vec = E_0 · ê_pol`, де `|ê_pol| = 1`. 

Зонд складається з трьох взаємно перпендикулярних ідентичних диполів, розташованих вздовж ортонормованого репера `x̂, ŷ, ẑ`:
```
x̂ · ŷ = 0,   ŷ · ẑ = 0,   ẑ · x̂ = 0
|x̂| = |ŷ| = |ẑ| = 1
```

Кожен диполь реагує виключно на проєкцію поля вздовж своєї осі:
```
E_x = E_vec · x̂ = E_0 · (ê_pol · x̂)
E_y = E_vec · ŷ = E_0 · (ê_pol · ŷ)
E_z = E_vec · ẑ = E_0 · (ê_pol · ẑ)
```

Обчислимо суму квадратів виміряних компонент:
```
E_total² = E_x² + E_y² + E_z²                                               [сума квадратів проєкцій на осі координат]
         = E_0² · [ (ê_pol · x̂)² + (ê_pol · ŷ)² + (ê_pol · ẑ)² ]             [підстановка E_k = E_0 · (ê_pol · k̂)]
         = E_0² · [ cos²(α) + cos²(β) + cos²(γ) ]                           [вираження через напрямні косинуси]
         = E_0² · 1                                                         [теорема про суму квадратів напрямних косинусів]
         = E_0²                                                             [доведення інваріантності сумарного модуля]
```
Оскільки `(ê_pol · x̂) = cos(α)`, `(ê_pol · ŷ) = cos(β)`, `(ê_pol · ẑ) = cos(γ)` є напрямними косинусами одиничного вектора `ê_pol` у декартовому базисі, за теоремою про суму квадратів напрямних косинусів `cos²(α) + cos²(β) + cos²(γ) = 1`.

Звідси отримуємо строгу рівність:
```
E_total = √(E_x² + E_y² + E_z²) = E_0
```

Сумарна виміряна напруженість поля `E_total` є інваріантом відносно будь-яких просторових обертань зонда. Аналогічно для повної густини потоку потужності Пойнтінга:
```
S_total = S_x + S_y + S_z                                                   [сума потоків потужності вздовж трьох осей]
        = (E_x² / Z_0) + (E_y² / Z_0) + (E_z² / Z_0)                        [підстановка S_k = E_k² / Z_0]
        = (E_x² + E_y² + E_z²) / Z_0                                        [винесення спільного знаменника Z_0]
        = E_total² / Z_0                                                    [визначення модуля E_total² = E_x² + E_y² + E_z²]
```

## 6. Аналіз похибки неортогональності осей (Cross-Axis Coupling)

Якщо під час монтажу диполів виникає кутове відхилення `δ` від прямого кута 90°, виникає похибка ізотропії (anisotropy error). Нехай вісь X відхилена в бік осі Y на кут `δ`. Тоді матриця взаємного положення осей `M` пов'язує реальні компоненти поля `E_real` із виміряними `E_meas`:
```
[ E_meas,x ]   [   1        sin(δ)    0 ]   [ E_real,x ]
[ E_meas,y ] = [ sin(δ)       1       0 ] · [ E_real,y ]
[ E_meas,z ]   [   0          0       1 ]   [ E_real,z ]
```

Для відновлення справжніх векторних складових мікроконтролер приладу застосовує інверсну матрицю калібрування:
```
E_real = M⁻¹ · E_meas
```
де за малих кутів `δ << 1`:
```
M⁻¹ ≈ [    1       -sin(δ)    0 ]
      [ -sin(δ)       1       0 ]
      [    0          0       1 ]
```
Завдяки попередньому калібруванню матриці `M` у безлунній камері залишкова анізотропія високоякісних вимірювальних зондів не перевищує `±0.5 дБ` у всьому робочому частотному діапазоні.

## 7. Числовий приклад розрахунку напруженості поля

**Вихідні дані:**
- Вимірювач зафіксував на клемах приймача для частоти `f = 1800 МГц` (діапазон LTE-1800) такі напруги на осях: `V_x = 12.0 мВ`, `V_y = 8.5 мВ`, `V_z = 15.2 мВ`.
- Зонд має калібрований чинник антени на цій частоті `AF_dB = 32.5 дБ(1/м)`.

**Крок 1. Переведення чинника антени в лінійний масштаб:**
```
AF_lin = 10^(AF_dB / 20)                                                    [переведення з децибелів у лінійний коефіцієнт]
       = 10^(32.5 / 20)                                                     [підстановка каліброваного значення AF_dB = 32.5 дБ(1/м)]
       = 10^1.625                                                           [ділення 32.5 / 20 = 1.625]
       ≈ 42.17 м⁻¹                                                          [чисельне піднесення до степеня]
```

**Крок 2. Розрахунок проєкцій електричного поля:**
```
E_x = V_x · AF_lin = 0.0120 В · 42.17 м⁻¹ ≈ 0.5060 В/м
E_y = V_y · AF_lin = 0.0085 В · 42.17 м⁻¹ ≈ 0.3584 В/м
E_z = V_z · AF_lin = 0.0152 В · 42.17 м⁻¹ ≈ 0.6410 В/м
```

**Крок 3. Розрахунок сумарної ізотропної напруженості поля:**
```
E_total = √( E_x² + E_y² + E_z² )                                           [визначення модуля просторового вектора]
        = √( 0.5060² + 0.3584² + 0.6410² )                                  [підстановка розрахованих проєкцій поля]
        = √( 0.2560 + 0.1285 + 0.4109 )                                     [піднесення компонентів до квадрата]
        = √( 0.7954 )                                                       [сумування квадратів]
        ≈ 0.8919 В/м                                                        [добування квадратного кореня]
```

**Крок 4. Розрахунок густини потоку потужності Пойнтінга:**
```
S_total = E_total² / Z_0                                                    [густина потоку Пойнтінга у вільному просторі]
        = 0.7954 / 376.73                                                   [підстановка E_total² та хвильового опору Z_0 = 376.73 Ом]
        ≈ 0.00211 Вт/м²                                                     [ділення величин]
        = 2.11 мВт/м²                                                       [переведення у мілівати на квадратний метр]
        = 0.211 мкВт/см²                                                    [переведення у мікровати на квадратний сантиметр]
```
Отримане значення `E_total = 0.89 В/м` порівнюється з нормативним лімітом ICNIRP для населення на частоті 1800 МГц (`E_lim ≈ 58.3 В/м`), що становить лише `1.5%` від гранично допустимого рівня.
