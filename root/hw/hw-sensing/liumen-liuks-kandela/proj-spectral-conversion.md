# ⚙️ Спектральний інтегратор: обчислення фотометричних величин з радіометричного спектра

Спектрометри, спектрорадіометри та монохроматори вимірюють фізичну потужність електромагнітного випромінювання на кожній довжині хвилі окремо. Результатом їхньої роботи є спектральна густина потоку випромінювання `Φ_e(λ)`, виражена у ватах на нанометр (Вт/нм), або спектральна опроміненість `E_e(λ)` у ватах на квадратний метр на нанометр (Вт/(м²·нм)).

Ці виміри є суто радіометричними: вони описують кількість джоулів енергії, яку переносять фотони за одну секунду у вузькому спектральному вікні `dλ`. Щоб отримати фотометричний результат — світловий потік у люменах чи освітленість у люксах, — цифровий обчислювальний модуль приладу має провести спектральну згортку виміряного сигналу зі стандартизованою функцією чутливості людського ока CIE 1924 `V(λ)`.

## Математична модель чисельної згортки

У неперервному математичному формулюванні повний фотометричний потік `Φ_v` є визначеним інтегралом добутку спектрального розподілу потужності на функцію відносної світлової ефективності `V(λ)`, помноженим на максимальну світлову ефективність `Km = 683.002 лм/Вт`:

```
Φ_v = Km · ∫ [від 380 до 780] Φ_e(λ) · V(λ) dλ
```

У мікропроцесорних системах спектральний масив надходить як дискретний набір із `N` точок `(λ_i, Φ_e(λ_i))`. Якщо крок довжин хвиль `Δλ = λ_{i+1} - λ_i` є сталим і збігається з табличною сіткою стандарту CIE (наприклад, 1 нм або 5 нм), інтеграл обчислюється методом трапецій:

```
Φ_v = Km · ∑ [від i=0 до N-2] [ (Φ_e(λ_i) · V(λ_i) + Φ_e(λ_{i+1}) · V(λ_{i+1})) / 2 ] · (λ_{i+1} - λ_i)
```

Метод трапецій має порядок збіжності `O(Δλ²)` і для гладких оптичних спектрів забезпечує похибку чисельного інтегрування менше ніж 0.05% за кроку дискретизації `Δλ ≤ 5 нм`. Прямокутна схема (суми Рімана) за такого ж кроку дає систематичну похибку до 1.2% через різку асиметрію дзвона `V(λ)` на спадах 500–520 нм та 580–600 нм.

## Обробка нерівномірної спектральної сітки та інтерполяція

Оптичні датчики на основі дифракційних ґраток із лінійними матрицями (CCD/CMOS) проектують довжини хвиль на пікселі за нелінійним дисперсійним законом. Відстань між сусідніми відліками сенсора змінюється (наприклад, від 0.32 нм на піксель на синьому кінці до 0.41 нм на піксель на червоному).

Для коректного розрахунку таблична функція `V(λ)` інтерполюється на фактичну довжину хвилі кожного виміряного відліку. Оскільки крок стандартної таблиці CIE становить 5 нм, лінійної інтерполяції між сусідніми вузлами сітки цілком достатньо для досягнення метрологічної точності:

```
V(λ) = V_k + ( (λ - λ_k) / (λ_{k+1} - λ_k) ) · (V_{k+1} - V_k)
де λ_k ≤ λ < λ_{k+1}
```

Усі відліки за межами оптичного вікна `380 нм ≤ λ ≤ 780 нм` (ультрафіолет та інфрачервоне випромінювання) прирівнюються до нуля `V(λ) = 0`. Проте вони обов'язково враховуються під час інтегрування повної радіометричної енергії `Φ_e`, що дозволяє обчислити підсумкову світлову віддачу системи.

## Крайові випадки та обчислювальна стійкість

При практичній реалізації алгоритму на контролерах обробки сигналів виникають чотири типи потенційних помилок:
1. **Порушення монотонності масиву**: калібрувальні таблиці пікселів сенсора можуть містити інвертовані відліки або дублікати через шум калібрування. Функція обов'язково перевіряє `λ_{i+1} > λ_i` перед обчисленням кроку `dw`.
2. **Нульова радіометрична потужність**: при вимірюванні в повній темряві сумарний потік `Φ_e` прямує до нуля. Обчислення світлової віддачі `Φ_v / Φ_e` захищене порогом відсікання `1e-12`, що запобігає діленню на нуль або отриманню значень `NaN`.
3. **Шуми квантування на краях смуги**: за межами 380–780 нм фотодавачі можуть фіксувати невеликий темновий струм. Якщо його не відсікати, накопичення шуму в області відсутності сигналу спотворює інтеграл; інтерполятор гарантовано повертає нуль за межами діапазону.
4. **Обмежена точність чисел із рухомою комою**: для спектрів із великим динамічним діапазоном (понад 100 дБ, наприклад, при вимірюванні лазерних ліній поруч із широким люмінесцентним фоном) рекомендується використовувати 64-бітну арифметику `double`, щоб уникнути втрати точності при додаванні малих бічних смуг до домінуючого піка.

## Аналіз поведінки розрахунку для різних типів джерел

Згортка за формулою `Φ_v = Km · ∫ Φ_e(λ) · V(λ) dλ` демонструє кардинальну різницю у сприйнятті світла різного спектрального складу при однаковій фізичній потужності джерела:

1. **Монохроматичний зелений лазер (555 нм)**: уся оптична потужність зосереджена в точці абсолютного максимуму людського ока. За потужності 1.0 Вт світловий потік становить рівно 683.0 лм (світлова віддача 683.0 лм/Вт).
2. **Зелений DPSS лазер (532 нм)**: коефіцієнт `V(532 нм) ≈ 0.885`. Відповідно, оптичний ват перетворюється на 603.5 лм.
3. **Червоний гелій-неоновий лазер або LED (650 нм)**: людське око значно гірше відчуває червоні фотони, `V(650 нм) ≈ 0.107`. Потік падає до 73.1 лм на ват фізичної потужності.
4. **Синій світлодіод підсвічування (450 нм)**: `V(450 нм) ≈ 0.038`. Один ват синього світла дає всього 26.0 лм.
5. **Теплий білий світлодіод (3000 K)**: має виражений синій пік накачування (450 нм) та широкий купол жовто-червоного перевипромінювання люмінофора (500–700 нм). Його інтегральна світлова віддача становить близько 300–340 лм на оптичний ват.
6. **Лампа розжарювання (2800 K)**: випромінює за законом Планка для нагрітого вольфраму. Понад 90% її потужності припадає на невидимий інфрачервоний діапазон (понад 780 нм), де `V(λ) = 0`. Інтеграл по всьому спектру дає лише 15 лм на фізичний ват повної енергії.
7. **Інфрачервоний діод (850 нм / 940 нм)**: `V(λ) = 0` на всій площі випромінювання, тому вихід становить строго 0.0 лм.

```

Джерело світла                   Потужність Φ_e (Вт)  Світловий потік Φ_v (лм)  Віддача (лм/Вт)
Монохроматичний лазер 555 нм            1.00 Вт               683.0 лм              683.0 лм/Вт

Синій LED 450 нм                        1.00 Вт                26.0 лм               26.0 лм/Вт
Білий LED (люмінофор, 4000 K)           1.00 Вт               320.0 лм              320.0 лм/Вт
```
