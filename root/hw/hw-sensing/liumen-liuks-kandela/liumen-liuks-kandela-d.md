# Люмен, люкс, кандела: фотометрія проти радіометрії

<preknowlist>

- [Одиниці системи SI](root:hw-sensing/si-base-units) — базові фізичні одиниці, визначення через зафіксовані константи.
- [Визначення інтеграла](root:math-analysis/integral) — інтегрування неперервної функції як накопичення площі під кривою.
- [Тілесний кут і стерадіан](root:math-geometry/solid-angle) — тривимірний конусний кут і геометрія просторового випромінювання.
</preknowlist>

Інженер оптоелектроніки стикається з парадоксом: інфрачервоний діод підсвічування камер нічного бачення випромінює 10 ватів теплової потужності на довжині хвилі 850 нм, а маленький зелений лазерний покажчик на 532 нм віддає лише 0.05 вата (50 міліватів). За фундаментальними законами фізики інфрачервоний випромінювач у 200 разів потужніший. Проте людина в темній кімнаті побачить зелену крапку як сліпучо яскраве джерело світла, тоді як десятиватному інфрачервоному променю відповість цілковита непроглядна темрява. Якщо спробувати оцінити яскравість екрана смартфона, безпеку освітлення робочого місця чи експозицію фотокамери виключно у фізичних ватах, інженерний розрахунок зазнає цілковитого краху.

Причина полягає в тому, що електромагнітне випромінювання існує у двох принципово різних вимірах: як об'єктивна фізична енергія частинок та як суб'єктивне фізіологічне відчуття сітківки людського ока. Фізичний потік частинок описує **радіометрія**, а реакцію біологічного зору — **фотометрія**. Між ними лежить складна крива спектральної чутливості людського ока, яка перетворює вати на люмени, кандели та люкси.

![Радіометрія (об'єктивна енергія) проти фотометрії (зір людини)](/root/hw/hw-sensing/liumen-liuks-kandela/img/fig-radiometry-vs-photometry.svg)
*Радіометрія вимірює всю об'єктивну енергію випромінювання у ватах, тоді як фотометрія пропускає цей потік крізь спектральний фільтр чутливості людського ока V(λ), отримуючи світловий потік у люменах.*

## Два світи: об'єктивна енергія проти біологічного ока

Будь-яке світло — це потік фотонів, кожен із яких несе квант енергії `E = h · c / λ`. Фізичні прилади (болометри, калориметри чи термопари) реєструють цей потік безсторонньо: поглинаючи фотон будь-якої частоти — від ультрафіолету до далекого інфрачервоного тепла, — приймач нагрівається або генерує вільні носії заряду. Галузь фізики, що кількісно вимірює енергію електромагнітного випромінювання в усьому спектральному діапазоні без огляду на спостерігача, називається **радіометрією** (від лат. *radiare* — випромінювати та грец. *metreō* — вимірювати).

У радіометрії кожна величина описує об'єктивну фізичну дію за секунду:
- **Радіометрична енергія випромінювання** `Q_e` — повна кількість перенесеної енергії в джоулях (Дж).
- **Потік випромінювання (радіометрична потужність)** `Φ_e` — швидкість перенесення енергії `dQ_e / dt` у ватах (Вт = Дж/с).
- **Сила випромінювання** `I_e` — потужність, випромінювана в одиничний тілесний кут `dΦ_e / dΩ` у ватах на стерадіан (Вт/ср).
- **Опроміненість** `E_e` — густина потоку випромінювання, що падає на поверхню площею `dA`, тобто `dΦ_e / dA` у ватах на квадратний метр (Вт/м²).
- **Енергетична яскравість (радіанс)** `L_e` — потужність випромінювання з одиниці видимої поверхні в одиничний тілесний кут у Вт/(м²·ср).

Людське око влаштоване інакше. Воно не є плоским тепловим приймачем. Фоторецептори сітківки вловлюють фотони лише у вузькому діапазоні від 380 до 780 нанометрів. Фотони з довжиною хвилі 850 нм або 1064 нм проходять крізь кришталик або поглинаються водою ока, не викликаючи фотохімічної реакції в зорових пігментах. Ба більше, навіть усередині видимого вікна око реагує на різні кольори вкрай нерівномірно: зелений фотон із довжиною хвилі 555 нм викликає потужний зоровий відгук, тоді як синій (430 нм) чи темно-червоний (700 нм) фотон тієї ж енергії сприймається в десятки разів слабшим.

Наука, яка оцінює оптичне випромінювання за його здатністю викликати зорове відчуття стандартного людського ока, називається **фотометрією** (від грец. *phōs, phōtos* — світло).

| Радіометрична величина (об'єктивна енергія) | Одиниця | Фотометрична величина (зорове сприйняття) | Одиниця |
|---|---|---|---|
| Потік випромінювання `Φ_e` (потужність) | Ват (Вт) | Світловий потік `Φ_v` | Люмен (лм) |
| Сила випромінювання `I_e` | Вт/ср | Сила світла `I_v` | Кандела (кд = лм/ср) |
| Опроміненість `E_e` | Вт/м² | Освітленість `E_v` | Люкс (лк = лм/м²) |
| Енергетична яскравість `L_e` | Вт/(м²·ср) | Яскравість (фотометрична) `L_v` | кд/м² (ніт) |
| Енергія випромінювання `Q_e` | Джоуль (Дж) | Світлова енергія `Q_v` | Люмен-секунда (лм·с) |

Індекс `e` позначає радіометричні (*energetic*) величини, а індекс `v` — фотометричні (*visual*) величини. Кожна фотометрична величина має точного радіометричного двійника, але відрізняється від нього тим, що фізичний спектр випромінювання зважується за спектральною чутливістю людського зору.

## Крива чутливості ока: фотопічний зір V(λ) та скотопічний зір V'(λ)

Щоб перевести радіометричні вати у фотометричні люмени, потрібен стандартизований коефіцієнт переводу для кожної довжини хвилі. Оскільки зір кожної окремої людини відрізняється залежно від віку, пігментації та стану здоров'я, у 1924 році Міжнародна комісія з освітлення (CIE — фр. *Commission Internationale de l'Éclairage*) на основі численних експериментів затвердила узагальнену функцію спектральної світлової ефективності монохроматичного випромінювання для денного зору — `V(λ)`.

Сітківка ока містить два типи світлочутливих клітин:
1. **Колбочки** — відповідають за денний (фотопічний, від грец. *phōs* — світло та *ōps* — зір) та колірний зір. Вони зосереджені в центральній ямці (жовтій плямі) сітківки й поділяються на три підтипи (L — червоні, M — зелені, S — сині). Колбочки активні за високих рівнів яскравості (понад 3–10 кд/м²).
2. **Палички** — відповідають за нічний (скотопічний, від грец. *skotos* — темрява) зір. Вони містять єдиний пігмент родопсин, мають надзвичайно високу світлочутливість (здатні реагувати на поодинокі фотони), але не розрізняють кольорів і насичуються вже за слабкого денного світла.

![Спектральна світлова ефективність: фотопічний V(λ) та скотопічний V'(λ) зір](/root/hw/hw-sensing/liumen-liuks-kandela/img/fig-photopic-scotopic.svg)
*Крива фотопічного зору V(λ) спирається на денні колбочки з піком 555 нм (683 лм/Вт), а скотопічна V'(λ) — на нічні палички з піком 507 нм (1700 лм/Вт). Перехід від денного до нічного бачення зміщує спектральний пік на 48 нм у короткохвильову синю область (ефект Пуркинє).*

### Фотопічна крива CIE 1924 V(λ)

Для денного зору функція `V(λ)` є безрозмірною дзвоноподібною кривою, нормованою на одиницю у своєму максимумі. Цей пік припадає на довжину хвилі `λ_0 = 555 нм` (жовто-зелене світло).

У точці піку фотопічного зору один ват монохроматичного випромінювання створює світловий потік рівно 683.002 люмена. Це значення є фундаментальною фотометричною сталою:

```
Km = 683.002 лм/Вт ≈ 683 лм/Вт   (при λ = 555 нм)
```

Світловий потік для монохроматичного випромінювача довільної довжини хвилі `λ` обчислюється як:

```
Φ_v(λ) = Km · Φ_e(λ) · V(λ)
```

Якщо джерело випромінює суцільний або складний лінійчастий спектр зі спектральною густиною потужності `Φ_e(λ)` (вимірюваною у Вт/нм), сумарний світловий потік дорівнює інтегралу згортки:

```
Φ_v = Km · ∫ Φ_e(λ) · V(λ) dλ
межі інтегрування: від 380 нм до 780 нм
```

Для випромінювання поза межами 380–780 нм функція `V(λ) = 0`. Саме тому потужний інфрачервоний лазер (наприклад, Nd:YAG 1064 нм) чи ультрафіолетовий бактерицидний опромінювач (254 нм) має `V(λ) = 0`, і його світловий потік дорівнює строго 0 люменів.

### Скотопічна крива CIE 1951 V'(λ) та ефект Пуркинє

У темряві (за яскравості менше ніж 10⁻³ кд/м²) колбочки перестають генерувати сигнал, і зір повністю перемикається на палички. Чутливість родопсину зсунута в бік коротших довжин хвиль: пік скотопічної кривої `V'(λ)` припадає на довжину хвилі `λ'_0 = 507 нм` (синьо-зелений колір).

Оскільки палички оптично значно чутливіші за колбочки, максимальна спектральна світлова ефективність скотопічного зору сягає:

```
K'm = 1700.06 лм/Вт ≈ 1700 лм/Вт   (при λ = 507 нм)
```

Зсув максимуму зорової чутливості на 48 нм у короткохвильову область під час адаптації до темряви називається **ефектом Пуркинє** (на честь чеського анатома Яна Евангелісти Пуркинє). Цей ефект легко спостерігати: удень червоні квіти здаються яскравішими за сині, але в сутінках червоні пелюстки стають майже чорними, тоді як сині та зелені довго зберігають світліший тон.

Між суто денним (фотопічним) і нічним (скотопічним) режимами лежить проміжний стан — **мезопічний зір** (від 0.001 до 3 кд/м²), коли одночасно працюють і палички, і колбочки. Саме цей режим визначає зір водіїв під час нічного руху при вуличному освітленні. Сучасний стандарт CIE 2010 описує мезопічну чутливість сумішшю `V_mes(λ) = m · V(λ) + (1 - m) · V'(λ)`, де коефіцієнт `m` залежить від рівня адаптації очей.

Ознайомитися з тим, як еталони сили світла еволюціонували від полум'я органічного воску до монохроматичного випромінювання на квантовій константі, можна у статті про [еволюцію світлових еталонів від китового жиру до квантової константи](root:hw-sensing/liumen-liuks-kandela/hist-candela-standard.md).

## Чотири базові фотометричні величини

Фотометрична система будується на чотирьох фундаментальних поняттях. Вони описують повний шлях світла: від випромінювання джерелом у простір до освітлення поверхні та її сприйняття оком спостерігача.

![Чотири базові фотометричні величини в єдиній геометрії](/root/hw/hw-sensing/liumen-liuks-kandela/img/fig-four-photometric-quantities.svg)
*Єдина фотометрична система: джерело характеризується силою світла I_v (кд) та світловим потоком Φ_v (лм), опромінена поверхня — освітленістю E_v (лк), а зорове сприйняття поверхні оком визначається яскравістю L_v (кд/м²).*

### 1. Сила світла I_v (Кандела, кд)

**Сила світла** (англ. *luminous intensity*) описує просторову густину світлового потоку, що випромінюється точковим джерелом у заданому напрямку всередині нескінченно малого тілесного кута `dΩ`.

Одиниця сили світла — **кандела** (кд, міжнародне позначення *cd*, від лат. *candela* — свічка). Кандела є однією із семи базових одиниць Міжнародної системи одиниць (SI).

За сучасним визначенням SI (2019 рік), одна кандела — це сила світла в заданому напрямку джерела, що випускає монохроматичне випромінювання частотою 540 × 10¹² Гц (довжина хвилі у вакуумі приблизно 555.016 нм), енергетична сила випромінювання якого в цьому напрямку становить рівно 1/683 вата на стерадіан.

Математично сила світла визначається як похідна світлового потоку за тілесним кутом:

```
I_v = dΦ_v / dΩ
dΩ = dA_сфери / r²   (тілесний кут у стерадіанах, ср)
```

Повна сфера охоплює тілесний кут `Ω = 4π ≈ 12.566` стерадіана. Якщо ідеальне точкове ізотропне джерело (випромінює однаково в усі боки) має силу світла 1 канделу, його повний світловий потік становить:

```
Φ_v = I_v · 4π = 1 кд · 4π ср ≈ 12.57 лм
```

Одна звичайна парафінова свічка має силу світла приблизно 1 кд у горизонтальному напрямку. Сучасний надяскравий світлодіод із вузькою лінзою (кутом випромінювання 15°) може мати силу світла 50–100 кд, хоча його сумарний потік у люменах залишається помірним: лінза просто стискає фотони у вузький тілесний кут.

### 2. Світловий потік Φ_v (Люмен, лм)

**Світловий потік** (англ. *luminous flux*) — це сумарна видима потужність світлового випромінювання, що випромінюється джерелом у весь навколишній простір або проходить крізь задану поверхню, зважена за чутливістю людського ока `V(λ)`.

Одиниця світлового потоку — **люмен** (лм, міжнародне позначення *lm*, від лат. *lumen* — світло). Люмен є похідною одиницею SI:

```
1 лм = 1 кд · 1 ср
```

Один люмен — це світловий потік, який випромінює ізотропне точкове джерело із силою світла в 1 канделу всередині тілесного кута в 1 стерадіан.

Світловий потік характеризує загальну світлопродуктивність лампи чи ліхтаря без урахування того, куди це світло спрямоване. Наприклад:
- Звичайна лампа розжарювання потужністю 100 Вт дає світловий потік близько 1300–1500 лм (світлова віддача ~13–15 лм/Вт).
- Світлодіодна лампа потужністю 12 Вт генерує той самий потік у 1400 лм (світлова віддача ~110–130 лм/Вт).
- Сонце випромінює повний світловий потік близько 3.8 × 10²⁸ лм.

### 3. Освітленість E_v (Люкс, лк)

**Освітленість** (англ. *illuminance*) — це поверхнева густина світлового потоку, що падає на одиницю площі опромінюваної поверхні.

Одиниця освітленості — **люкс** (лк, міжнародне позначення *lx*, від лат. *lux* — світло).

```
1 лк = 1 лм / 1 м²
E_v = dΦ_v / dA
```

Один люкс — це освітленість поверхні площею 1 м², на яку рівномірно падає світловий потік в 1 люмен.

Освітленість вимірюють спеціальними приладами — **люксметрами** або напівпровідниковими давачами освітленості (ALS — *Ambient Light Sensors*). Орієнтири для реального світу:
- Нічне небо в повний місяць: 0.1–0.25 лк.
- Вуличне освітлення вночі: 10–20 лк.
- Робоче місце в офісі за стандартом EN 12464-1: 500 лк.
- Операційний стіл у хірургії: 10 000–50 000 лк.
- Пряме сонячне світло в ясний полудень: 100 000–120 000 лк.

#### Закон обернених квадратів

Якщо світло поширюється від точкового джерела із силою світла `I_v` у прозорому нерозсіювальному середовищі, площа сферичного фронту хвилі збільшується пропорційно квадрату радіуса `A = 4π · r²`. Відповідно, густина потоку спадає обернено пропорційно квадрату відстані:

```
E_v = I_v / r²
```

Якщо на відстані 1 м від свічки (1 кд) освітленість становить `1 кд / (1 м)² = 1 лк`, то на відстані 2 м вона зменшиться до `1 кд / (2 м)² = 0.25 лк` (у 4 рази), а на відстані 10 м — до 0.01 лк (у 100 разів).

```
Правило застосовності закону обернених квадратів (правило 5-кратного діаметра):
Джерело світла діаметром D можна вважати точковим із похибкою розрахунку менше ніж 1%,
якщо відстань r до приймача перевищує його розмір щонайменше у 5–10 разів:
r ≥ 5 · D
```

Для протяжних джерел (великих світильників, софтбоксів, світлодіодних панелей) на малих відстанях закон обернених квадратів не діє: поблизу довгої лінійної світлодіодної трубки освітленість спадає лінійно (`1/r`), а поблизу великої світної площини — практично не змінюється з відстанню.

### 4. Яскравість L_v (Кандела на квадратний метр, кд/м², ніт)

**Яскравість** (англ. *luminance*) — це фотометрична величина, що визначає силу світла, яка випромінюється або відбивається елементом поверхні в заданому напрямку, віднесену до **видимої (проєктованої) площі** цієї поверхні.

Одиниця яскравості — **кандела на квадратний метр** (кд/м²). В інженерії дисплеїв та електроніці цю одиницю традиційно називають **ніт** (від лат. *nitere* — блищати, світитися; 1 ніт = 1 кд/м²).

```
L_v = d²Φ_v / (dA · cos θ · dΩ) = dI_v / (dA · cos θ)
де:
dA — фізична площа випромінювального елемента;
θ — кут між нормаллю до поверхні та напрямком спостереження;
dA · cos θ — видима площа випромінювача під кутом θ.
```

Яскравість є **єдиною фотометричною величиною, яку безпосередньо сприймає людське око**. Кришталик ока фокусує світло на сітківці, створюючи зображення джерела. Освітленість сітківки пропорційна саме яскравості `L_v` об'єкта і не залежить від відстані до нього (якщо розмір зображення перевищує розмір одного рецептора: зі збільшенням відстані потік на зіницю падає як `1/r²`, але й площа плями на сітківці зменшується як `1/r²`, тож їхнє співвідношення залишається константою).

Приклади значень яскравості:
- Екран електронної книги без підсвічування: 50–100 кд/м².
- Офісний комп'ютерний монітор: 250–350 ніт (кд/м²).
- Смартфон для читання на сонці: 1000–2500 ніт.
- Поверхня люмінесцентної лампи: 5 000–10 000 кд/м².
- Нитка розжарювання вольфрамової лампи: 10 000 000 кд/м².
- Диск Сонця в зеніті: 1.5 × 10⁹ кд/м² (викликає миттєвий термічний опік сітківки).

## Косинусний закон Ламберта та оптика люксметрів

Коли промінь світла падає на плоский приймач під похилим кутом `θ` відносно нормалі, площа плями, яку покриває світловий пучок, розширюється у `1 / cos θ` разів. Світловий потік `dΦ_v` розподіляється по більшій території, тому густина потоку — освітленість поверхні — зменшується:

```
E_v(θ) = E_0 · cos θ = (I_v / r²) · cos θ
де:
E_0 — освітленість при прямовисному (нормальному) падінні (θ = 0°);
θ — кут падіння променя відносно нормалі до поверхні.
```

Це положення називається **косинусним законом освітленості**.

![Косинусний закон освітленості та конструкція вимірювального розсіювача](/root/hw/hw-sensing/liumen-liuks-kandela/img/fig-lambert-cosine-diffuser.svg)
*Косинусний закон освітленості описує спадання густини потоку зі збільшенням кута падіння променя. Опаловий купол із PTFE на датчику виправляє кутову похибку кремнієвого кристала, формуючи ідеальний просторовий відгук за законом косинуса.*

### Поверхня Ламберта (ідеальний дифузор)

Ідеально матова поверхня, яка розсіює світло в усіх напрямках за законом косинуса сили світла `I(θ) = I_0 · cos θ`, називається **ламбертовим розсіювачем** (на честь німецького фізика й математика Йоганна Генріха Ламберта).

Для ламбертової поверхні яскравість виявляється строго постійною в усіх напрямках спостереження:

```
L(θ) = I(θ) / (A · cos θ) = (I_0 · cos θ) / (A · cos θ) = I_0 / A = const
```

Через це аркуш матового крейдованого паперу, стіна з гіпсовою штукатуркою або диск повного Місяця здаються однаково яскравими незалежно від того, дивимося ми на них прямо чи під гострим кутом.

Повний світловий потік, який випромінює або відбиває плоска ламбертова поверхня площею `A` з яскравістю `L_v` у всю верхню півсферу (`2π` ср), дорівнює інтегралу:

```
Φ_v = ∫ L_v · cos θ · dΩ = L_v · A · ∫ [від 0 до 2π] dφ · ∫ [від 0 до π/2] cos θ · sin θ dθ
    = L_v · A · 2π · [ (sin² θ) / 2 ] | [від 0 до π/2]
    = π · L_v · A
```

Світність (потік з одиниці площі) ламбертової поверхні дорівнює `M_v = π · L_v` (а не `2π · L_v`, як могло б здатися, через кутове згасання за косинусом).

### Чому голий кремнієвий фотодіод бреше: просторова похибка f₂

Якщо для вимірювання освітленості взяти звичайний плоский кремнієвий фотодіод без насадки, прилад покаже катастрофічну кутову похибку. Причини дві:
1. **Формули Френеля**: коефіцієнт відбиття світла від межі «повітря — кремній» (або скла корпусу) різко зростає при косих кутах падіння. За кута `θ = 70°` кристал відбиває понад 50% світла, тому виміряний сигнал падає значно швидше, ніж теоретичний `cos θ`.
2. **Геометричне затінення**: бортики корпусу мікросхеми, контактні дротики та край лінзи зрізають косі промені.

Для усунення цієї вади професійні люксметри та прецизійні давачі освітленості оснащують **косинусною насадкою** (косинусним колектором). Це опуклий купол або опукла шайба з опалового скла чи фторопласту (PTFE, тефлону) з точно вивіреною глибиною посадки в металевому фланці. Матеріал купола багаторазово розсіює промені всередині себе, перетворюючи світло з будь-якого напрямку на внутрішнє ламбертове випромінювання, спрямоване на кремній.

Відхилення приладу від ідеального косинусного закону нормується стандартом DIN 5032 як **косинусна похибка f₂**:
- Люксметри лабораторного класу A: похибка `f₂ < 1.5%`.
- Люксметри загального класу B: похибка `f₂ < 3%`.
- Дешеві напівпровідникові модулі без дифузора: похибка сягає `f₂ > 25–40%`.

## Практика розрахунку: перерахунок радіометрії у фотометрію

У вбудованих системах та вимірювальних приладах перерахунок фізичного спектра у фотометричні показники виконується чисельним інтегруванням. Детальний математичний модуль та алгоритм згортки наведено у вставці про [алгоритм спектральної згортки та обчислення фотометричних інтегралів](root:hw-sensing/liumen-liuks-kandela/proj-spectral-conversion.md).

На практиці цифрові сенсори освітленості (ALS, наприклад OPT3001, BH1750, VEML7700 або APDS-9960) вирішують проблему `V(λ)` апаратно:
1. **Оптичний інтерференційний фільтр**: на кремнієвий фотодіод наносять багатошарове діелектричне покриття, чия крива пропускання повторює форму `V(λ)`.
2. **Двоканальна компенсація**: сенсор містить два діоди — один із широким спектром (видиме + інфрачервоне світло `CH0`), а другий чутливий тільки до ІЧ-діапазону (`CH1`). Мікроконтролер обчислює справжній видимий потік за калібрувальною формулою виду `Lux = a · CH0 - b · CH1`.

Нижче наведено практичний приклад коду для мікроконтролера, що перетворює сирі відліки двоканального фотодавача в освітленість у люксах з урахуванням спектрального типу джерела.

```c
#include <stdint.h>
#include <stdbool.h>

typedef enum {
    LIGHT_SRC_SUNLIGHT,     /* Сонячне світло (багате на УФ та синє) */
    LIGHT_SRC_INCANDESCENT, /* Лампа розжарювання (величезний ІЧ хвіст) */
    LIGHT_SRC_FLUORESCENT,  /* Люмінесцентна лампа (піки ртуті) */
    LIGHT_SRC_LED_WHITE     /* Білий світлодіод (люмінофорний спектр) */
} LightSourceType;

typedef struct {
    uint32_t raw_visible_plus_ir; /* Канал CH0: сумарний потік */
    uint32_t raw_ir_only;         /* Канал CH1: інфрачервоний потік */
    double integration_time_ms;   /* Час накопичення заряду АЦП */
    double sensor_gain;           /* Коефіцієнт підсилення PGA */
} AlsRawReading;

/* Обчислення освітленості в люксах із відсіканням паразитних ІЧ-фотонів */
bool als_calculate_lux(const AlsRawReading *reading, LightSourceType src, double *out_lux) {
    if (!reading || !out_lux || reading->integration_time_ms <= 0.0 || reading->sensor_gain <= 0.0) {
        return false;
    }

    /* Нормалізація сирих відліків на одиничний час і підсилення */
    double norm_factor = (100.0 / reading->integration_time_ms) * (1.0 / reading->sensor_gain);
    double ch0 = (double)reading->raw_visible_plus_ir * norm_factor;
    double ch1 = (double)reading->raw_ir_only * norm_factor;

    if (ch0 < 1e-6) {
        *out_lux = 0.0;
        return true;
    }

    /* Співвідношення ІЧ/видиме визначає спектральний розподіл */
    double ir_ratio = ch1 / ch0;
    double lux = 0.0;

    /* Поліноміальна корекція спектра під криву V(lambda) */
    if (ir_ratio < 0.50) {
        /* Джерело з малим ІЧ (LED або денне світло) */
        lux = 0.0304 * ch0 - 0.0620 * ch0 * pow(ir_ratio, 1.4);
    } else if (ir_ratio < 0.80) {
        /* Люмінесцентне світло */
        lux = 0.0224 * ch0 - 0.0310 * ch1;
    } else if (ir_ratio < 1.30) {
        /* Лампа розжарювання чи пряме сонце: висока частка ІЧ */
        lux = 0.0128 * ch0 - 0.0153 * ch1;
    } else {
        /* Чисте ІЧ-випромінювання (наприклад, пульт ДК або сонце крізь шторку) */
        lux = 0.0;
    }

    *out_lux = (lux > 0.0) ? lux : 0.0;
    return true;
}
```

```cpp
#include <cstdint>
#include <optional>
#include <cmath>
#include <algorithm>

namespace sensing {

enum class LightSourceType {
    Sunlight,
    Incandescent,
    Fluorescent,
    WhiteLed
};

struct AlsRawReading {
    std::uint32_t raw_visible_plus_ir{0}; // Канал CH0
    std::uint32_t raw_ir_only{0};         // Канал CH1
    double integration_time_ms{100.0};
    double sensor_gain{1.0};
};

class PhotometricCalculator {
public:
    [[nodiscard]] static std::optional<double> calculateLux(
        const AlsRawReading& reading,
        LightSourceType src = LightSourceType::WhiteLed) noexcept
    {
        if (reading.integration_time_ms <= 0.0 || reading.sensor_gain <= 0.0) {
            return std::nullopt;
        }

        const double norm_factor = (100.0 / reading.integration_time_ms) * (1.0 / reading.sensor_gain);
        const double ch0 = static_cast<double>(reading.raw_visible_plus_ir) * norm_factor;
        const double ch1 = static_cast<double>(reading.raw_ir_only) * norm_factor;

        if (ch0 < 1e-6) {
            return 0.0;
        }

        const double ir_ratio = ch1 / ch0;
        double lux = 0.0;

        if (ir_ratio < 0.50) {
            lux = 0.0304 * ch0 - 0.0620 * ch0 * std::pow(ir_ratio, 1.4);
        } else if (ir_ratio < 0.80) {
            lux = 0.0224 * ch0 - 0.0310 * ch1;
        } else if (ir_ratio < 1.30) {
            lux = 0.0128 * ch0 - 0.0153 * ch1;
        } else {
            lux = 0.0;
        }

        return std::max(0.0, lux);
    }
};

} // namespace sensing
```

> 🔧 **Навіщо це.** Помилка у виборі між радіометрією та фотометрією коштує дорого. Автоматичне регулювання яскравості екрана в смартфонах чи бортових комп'ютерах автомобілів має орієнтуватися виключно на фотометричні люкси: якщо поставити простий кремнієвий фотодіод без фільтра `V(λ)`, екран буде засліплювати користувача ввечері під лампою розжарювання (бо фотодіод побачить гігантський потік невидимого ІЧ-тепла й задере яскравість на 100%), а вдень під холодними люмінесцентними лампами — навпаки, згасне до мінімуму. Розуміння фотометричного ланцюжка `Ват → V(λ) → Люмен → Кандела → Люкс → Ніт` гарантує правильне узгодження чутливості сенсорів із біологічним зором людини.
