# 🔌 Аналогові перетворювачі True RMS: будова та обмеження

Аналогове вимірювання середньоквадратичного значення без участі швидкісного мікроконтролера та АЦП вимагає спеціалізованих монолітних перетворювачів True RMS-to-DC (таких як AD736, AD737, AD8436, LTC1966). Вони перетворюють змінну напругу довільної форми на еквівалентний постійний потенціал за допомогою нелінійних кремнієвих транзисторних ядер. Розгляньмо, як влаштована внутрішня схемотехніка таких мікросхем, чому пряме множення поступилося місцем непрямому логарифмічному контуру та які фізичні обмеження накладає пік-фактор і вибір зовнішнього конденсатора усереднення.

---

### Прямий чи непрямий метод: проблема динамічного діапазону

Обчислити формулу `V_RMS = √( Avg( V_in² ) )` апаратно можна двома принципово різними шляхами:

1. **Прямий (явний, Explicit) метод:**
   Вхідний сигнал надходить на аналоговий чотириквадрантний помножувач (квадратор `V_in²`), вихідний струм згладжується RC-фільтром низьких частот для знаходження середнього `Avg(V_in²)`, після чого операційний підсилювач із квадратором у ланцюзі зворотного зв'язку добуває квадратний корінь `√...`.

   *Головний недолік прямого методу:* **подвоєння динамічного діапазону**. Якщо вхідний сигнал змінюється в діапазоні `60 дБ` (від `1 мВ` до `1 В`, коефіцієнт `1000:1`), то після зведення в квадрат сигнал на виході першого ступеня змінюється в діапазоні `120 дБ` (від `1 мкВ` до `1 В`, коефіцієнт `1 000 000:1`). Рівень `1 мкВ` неминуче тоне у власних шумах напівпровідника, дрейфі зсуву операційного підсилювача та струмах витоку. Прямі конвертери працюють лише у вузькому вікні сигналів (до 20–30 дБ).

2. **Непрямий (неявний, Implicit) метод зі зворотним зв'язком:**
   Це класична топологія, розроблена Баррі Гілбертом (англ. *Barrie Gilbert*). Математична тотожність перебудовується через ділення:

```
V_out = Avg( V_in² / V_out )
⇒ V_out · V_out = Avg( V_in² )
⇒ V_out² = Avg( V_in² )
⇒ V_out = √( Avg( V_in² ) )
```

У цій схемі вхідний сигнал `V_in` ділиться на вже сформовану вихідну напругу `V_out` усередині єдиного нелінійного транзисторного ядра. Завдяки цьому внутрішні струми й напруги змінюються **пропорційно першому степеню** вхідного сигналу, а не його квадрату. Динамічний діапазон схеми розширюється до `60..80 дБ` без занурення малих рівнів у шум.

### Будова транзисторного транслінійного ядра

Серцем мікросхем на кшталт AD736 та AD8436 є **транслінійна комірка** (англ. *translinear cell*). Вона використовує строго експоненційну залежність колекторного струму біполярного транзистора від напруги база-емітер:

```
I_c = I_s · exp( V_be / V_T )
V_be = V_T · ln( I_c / I_s )
```

де `V_T = k·T / q ≈ 26 мВ` при кімнатній температурі — термічний потенціал, а `I_s` — струм насичення переходу.

Схема містить замкнений контур із чотирьох узгоджених p-n переходів:
- Два переходи логарифмують вхідний випрямлений струм `I_in = |V_in| / R_in`, формуючи подвоєний потенціал `2 · V_T · ln(I_in)`.
- Третій перехід віднімає логарифм вихідного струму `V_T · ln(I_out)`, що реалізує операцію ділення `I_in² / I_out`.
- Четвертий перехід виконує антилогарифмування (експоненціювання), формуючи струм:

```
I_core = I_in² / I_out
```

Цей струм надходить на інтегруючий вузол, де підключений зовнішній конденсатор усереднення `C_AV`. Оскільки опір виходу високий, напруга на конденсаторі дорівнює середньому значенню цього струму, перетвореному вихідним буфером у стабільний потенціал `V_out`.

### Розрахунок конденсатора усереднення C_AV

Зовнішній конденсатор `C_AV` визначає компроміс між **пульсаціями вихідної напруги на низьких частотах** та **швидкістю встановлення показу** (англ. *settling time*).

#### 1. Похибка усереднення (DC Error та Ripple)

Струм після квадратора містить постійну складову (корисний сигнал) та змінну складову подвоєної частоти `2f` (наприклад, `100 Гц` для мережі `50 Гц`). Змінний струм на ємності `C_AV` створює пульсації:

```
ΔV_ripple ≈ I_RMS / (2 · ω · C_AV) = I_RMS / (4π · f · C_AV)
```

Через нелінійність ядра ці пульсації частково детектируются назад, додаючи систематичну додаткову похибку заниження постійного рівня:

```
Похибка заниження (%) ≈ 1 / ( (4π · f · R_internal · C_AV)² ) · 100 %
```

Для типового внутрішнього опору фільтра `R_internal ≈ 8 кОм` (AD736):
- При `C_AV = 10 мкФ` на частоті `50 Гц`: додаткова похибка становить менше `0.1%`.
- При `C_AV = 1 мкФ`: похибка на `50 Гц` зростає до `1.5%`.

#### 2. Час встановлення перехідного процесу

Збільшення ємності покращує точність на низьких частотах, але сповільнює реакцію приладу на стрибок сигналу. Час встановлення до похибки `1%` описується формулою:

```
t_settle ≈ 5 · τ = 5 · R_internal · C_AV
```

Для `C_AV = 33 мкФ` та `R_internal = 8 кОм`:
`t_settle ≈ 5 · 8·10³ · 33·10⁻⁶ ≈ 1.32 с`.

> 💡 Для швидкого вимірювання за `C_AV` ставлять додатковий 2-полюсний активний фільтр Баттерворта або Бесселя на виході (Sallen-Key). Це дозволяє зменшити основну ємність `C_AV` у 5–10 разів без зростання пульсацій.

### Обмеження за пік-фактором (Crest Factor Derating)

Будь-який аналоговий RMS-перетворювач має суворе фізичне обмеження на максимальну амплітуду піків сигналу.

1. **Насичення вхідного підсилювача та транслінійного ядра:**
   Внутрішній тракт живиться від фіксованих шин (наприклад, `±5 В` або `±15 В`). Якщо сигнал має пік-фактор `CF = 5`, а середньоквадратичне значення становить `1 В RMS`, то миттєві піки сягають `5 В`. Якщо шина живлення `±5 В`, транзистори ядра входять у насичення, вершини зрізаються, і прилад катастрофічно занижує RMS.
   *Правило шкали:* повна шкала `V_RMS_max` повинна зменшуватися пропорційно пік-фактору:

```
V_RMS_allowed ≤ (V_supply - V_headroom) / CF
```

2. **Звуження смуги пропускання:**
   Сигнал із високим пік-фактором містить потужні високочастотні гармоніки. Якщо частота основної гармоніки `50 Гц`, але імпульси мають ширину `100 мкс`, то ядро мусить мати смугу пропускання не нижче `50–100 кГц`. У типових мікросхемах смуга пропускання ядра падає при зростанні пік-фактора, оскільки внутрішні ємності транзисторів повільніше перезаряджаються струмами малого середнього рівня.

**Паспортне зростання похибки для AD736 / AD8436:**

| Пік-фактор `CF` | Додаткова похибка | Вимоги до смуги пропускання |
|---|---|---|
| **1 .. 2** | `0.0 %` (базова похибка 0.3%) | `f_max ≈ 200 кГц` |
| **2 .. 3** | `+0.3 %` додатково | `f_max ≈ 50 кГц` |
| **3 .. 4** | `+0.7 %` додатково | `f_max ≈ 20 кГц` |
| **4 .. 5** | `+1.5 .. 2.5 %` додатково | `f_max ≈ 5..10 кГц` |
| **> 5** | Робота не нормується (лавинне зростання похибки) | Тракт перевантажений |

### Практична схема підключення та особливості трасування PCB

Під час проектування вимірювального вузла на базі мікросхем True RMS-to-DC необхідно дотримуватися суворих схемотехнічних правил:

1. **Вхідне узгодження (AC-coupling проти DC-coupling):**
   - У режимі **AC-coupled True RMS** на вхід ставлять якісний плівковий конденсатор `C_IN` (поліпропілен або C0G/NP0 кераміка). Електролітичні конденсатори неприпустимі через високий струм витоку, який зміщує робочу точку ядра.
   - У режимі **True RMS (AC+DC)** сигнал подають безпосередньо. Якщо на вході є висока постійна складова, вона бере участь у нагріві й коректно враховується у вихідній напрузі `V_out = √(V_DC² + V_AC²RMS)`.

2. **Захисне кільце (Guard Ring) на друкованій платі:**
   Вивід підключення конденсатора `C_AV` має вкрай високий внутрішній імпеданс. Поверхневі струми витоку по текстоліту (від сусідніх доріжок живлення `±15 В`) через вологість чи залишки флюсу здатні викликати зміщення виходу на 5–50 мВ. Навколо виводу `C_AV` обов'язково трасують захисне кільце, з'єднане з потенціалом віртуального нуля або аналогової землі.

3. **Блокувальні конденсатори живлення:**
   Транслінійне ядро споживає струм імпульсами на подвоєній частоті сигналу. Керамічні блокувальні конденсатори `0.1 мкФ` X7R у парі з танталовими `10 мкФ` мають розташовуватися безпосередньо біля виводів живлення мікросхеми (не далі 2 мм) для запобігання паразитній генерації.
