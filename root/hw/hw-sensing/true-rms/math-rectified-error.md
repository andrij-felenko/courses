# 🧮 Аналітичний розрахунок похибки середньовипрямленого детектора

Коли вимірювальний прилад замість чесного інтегрування квадрата миттєвої напруги випрямляє сигнал і множить його середнє абсолютне значення на фіксований коефіцієнт `1.1107`, виникає метрологічний розрив між тим, що показує шкала, і реальним тепловим еквівалентом сигналу. Нелінійні навантаження сучасної силової електроніки генерують складні періодичні функції з багатим гармонійним спектром. Нижче наведено строге аналітичне виведення коефіцієнтів форми (англ. *form factor*), пік-факторів (англ. *crest factor*), спектральних розкладів Фур'є та точних похибок вимірювання для шести типових класів сигналів.

---

### Фундаментальні математичні та метрологічні визначення

Для періодичного сигналу `v(t)` з періодом `T`, основною частотою `f₀ = 1 / T` та кутовою частотою `ω = 2π / T` визначають дві інтегральні норми простору `L²[0, T]` та `L¹[0, T]`:

1. **Середньоквадратичне значення (True RMS)** — корінь із середнього значення квадрата функції за період (нормована евклідова норма `L²`):

```
V_RMS = √( (1 / T) · ∫₀ᵀ v²(t) dt )
```

Згідно з теоремою Парсеваля, якщо періодичний сигнал подано у вигляді ряду Фур'є `v(t) = V_DC + ∑_{k=1}^∞ V_k · sin(kωt + φ_k)`, діюче значення виражається через амплітуди окремих гармонік:

```
V_RMS = √( V_DC² + (1/2) · ∑_{k=1}^∞ V_k² ) = √( V_DC² + ∑_{k=1}^∞ V_{k,RMS}² )
```

2. **Середньовипрямлене значення (MAV, Mean Absolute Value)** — середнє значення модуля функції за період (нормована норма `L¹`):

```
V_MAV = (1 / T) · ∫₀ᵀ |v(t)| dt
```

3. **Коефіцієнт форми (Form Factor)** `k_f` — фундаментальне безрозмірне геометричне співвідношення між нормами `L²` та `L¹`:

```
k_f = V_RMS / V_MAV
```

За нерівністю Коші — Буняковського — Шварца для будь-якої неконстантної функції завжди виконується `V_RMS ≥ V_MAV`, а отже `k_f ≥ 1.000`. Рівність `k_f = 1.000` досягається виключно тоді, коли абсолютна величина сигналу є строго сталою кожної миті часу `|v(t)| = \text{const}` (ідеальний симетричний меандр або постійний струм).

4. **Пік-фактор (Crest Factor)** `CF` — відношення максимального миттєвого пікового значення до діючого:

```
CF = V_pk / V_RMS
```

#### Математична модель середньовипрямленого детектора

Апаратний середньовипрямлений вимірювач фізично вимірює `V_MAV` (через діодний міст та RC-інтегратор). Для відображення результату прилад множить отриману напругу на калібрувальний множник синуса `k_calib`:

```
k_calib = π / (2·√2) ≈ 1.11072073
V_показ = k_calib · V_MAV = 1.11072 · V_MAV
```

Відносна похибка вимірювання `δ` для будь-якого вхідного сигналу дорівнює:

```
δ = ( (V_показ - V_RMS) / V_RMS ) · 100 %
= ( (k_calib · V_MAV - V_RMS) / V_RMS ) · 100 %   [підстановка V_показ = k_calib · V_MAV]
= ( (k_calib / k_f) - 1 ) · 100 %                 [ділення чисельника і знаменника на V_RMS та k_f = V_RMS/V_MAV]
```

Звідси випливає головне аналітичне правило: **похибка детектора залежить виключно від того, наскільки коефіцієнт форми сигналу `k_f` відрізняється від еталонного значення синуса `1.11072`**.

### 1. Гармонійна синусоїда (еталон калібрування)

Розглянемо чистий монохроматичний сигнал `v(t) = V_pk · sin(ωt)` без постійної складової.

#### Виведення V_MAV:

Оскільки функція антисиметрична `v(t + T/2) = -v(t)`, інтеграл модуля за повний період дорівнює подвоєному інтегралу за додатний півперіод від `0` до `T/2` (або за фазою `θ = ωt` від `0` до `π`):

```
V_MAV = (1 / π) · ∫₀^π V_pk · sin(θ) dθ
= (V_pk / π) · [ -cos(θ) ]₀^π      [інтегрування синуса]
= (V_pk / π) · ( -(-1) - (-1) )     [підстановка меж: cos(π)=-1, cos(0)=1]
= (2 / π) · V_pk                   [спрощення: 2/π ≈ 0.63661977]
```

#### Виведення V_RMS:

Квадрат синуса розкладаємо за тригонометричною формулою пониження степеня `sin²(θ) = (1 - cos(2θ)) / 2`:

```
V_RMS² = (1 / (2π)) · ∫₀^(2π) V_pk² · sin²(θ) dθ
= (V_pk² / (2π)) · ∫₀^(2π) ( (1 - cos(2θ)) / 2 ) dθ   [тригонометрична тотожність]
= (V_pk² / (4π)) · [ θ - (sin(2θ) / 2) ]₀^(2π)         [інтегрування частинами]
= (V_pk² / (4π)) · ( (2π - 0) - (0 - 0) )              [підстановка меж]
= V_pk² / 2                                            [спрощення: 2π / 4π = 1/2]

V_RMS = V_pk / √2 ≈ 0.70710678 · V_pk
```

#### Розрахунок параметрів форми та похибки:

```
k_f = V_RMS / V_MAV = (V_pk / √2) / ( (2/π) · V_pk ) = π / (2·√2) ≈ 1.11072
CF = V_pk / (V_pk / √2) = √2 ≈ 1.41421
V_показ = 1.11072 · ( (2/π) · V_pk ) = 0.70711 · V_pk
δ = ( (1.11072 / 1.11072) - 1 ) · 100 % = 0.00 %
```

### 2. Симетричний прямокутний сигнал (меандр)

Сигнал миттєво перемикається між двома рівнями: `v(t) = +V_pk` при `t ∈ [0, T/2)` та `v(t) = -V_pk` при `t ∈ [T/2, T)`.

#### Виведення інтегралів:

Модуль функції `|v(t)| = V_pk` є незмінною величиною в кожен момент часу. Аналогічно квадрат `v²(t) = V_pk²` також є сталою величиною.

```
V_MAV = (1 / T) · ∫₀ᵀ V_pk dt = V_pk
V_RMS = √( (1 / T) · ∫₀ᵀ V_pk² dt ) = √( V_pk² ) = V_pk
```

#### Спектральний аналіз (теорема Парсеваля):

Ряд Фур'є для непарного меандру містить лише непарні гармоніки:
`v(t) = (4·V_pk / π) · [ sin(ωt) + (1/3)·sin(3ωt) + (1/5)·sin(5ωt) + ... ]`.
Сума квадратів діючих значень гармонік:

```
V_RMS² = (1/2) · (16·V_pk² / π²) · ∑_{k=1,3,5...}^∞ (1 / k²)
= (8·V_pk² / π²) · (π² / 8)       [відома сума Базельського ряду для непарних обернених квадратів]
= V_pk²                           [повне збігання з часовим інтегралом]
```

#### Розрахунок похибки:

```
k_f = V_RMS / V_MAV = V_pk / V_pk = 1.00000
CF = V_pk / V_pk = 1.00000
V_показ = 1.11072 · V_MAV = 1.11072 · V_pk
δ = ( (1.11072 / 1.00000) - 1 ) · 100 % = +11.07 %
```

Прилад завищує показ рівно на `11.07%`, оскільки вся енергія меандру зосереджена на максимальній полиці `V_pk`, а прилад ділить її на штучний синусоїдний коефіцієнт форми.

### 3. Симетричний трикутний та пилкоподібний сигнал

Для симетричного трикутного сигналу на інтервалі першої чверті періоду `t ∈ [0, T/4]` напруга зростає лінійно від нуля до максимуму: `v(t) = V_pk · (4t / T)`. Завдяки повній симетрії чотирьох чвертей інтегрування достатньо виконати на цьому інтервалі.

#### Виведення V_MAV:

```
V_MAV = (4 / T) · ∫₀^(T/4) V_pk · (4t / T) dt
= (16·V_pk / T²) · [ t² / 2 ]₀^(T/4)   [інтегрування лінійної функції]
= (16·V_pk / T²) · (T² / 32)           [підстановка верхньої межі: (T/4)²/2 = T²/32]
= (16 / 32) · V_pk                     [скорочення T²]
= V_pk / 2 = 0.50000 · V_pk
```

#### Виведення V_RMS:

```
V_RMS² = (4 / T) · ∫₀^(T/4) V_pk² · (16t² / T²) dt
= (64·V_pk² / T³) · [ t³ / 3 ]₀^(T/4)   [інтегрування квадратичної функції]
= (64·V_pk² / T³) · (T³ / 192)          [підстановка межі: (T/4)³/3 = T³/192]
= (64 / 192) · V_pk²                    [скорочення T³]
= V_pk² / 3                             [спрощення дробу 64/192 = 1/3]

V_RMS = V_pk / √3 ≈ 0.57735027 · V_pk
```

#### Розрахунок параметрів форми та похибки:

```
k_f = (V_pk / √3) / (V_pk / 2) = 2 / √3 ≈ 1.15470054
CF = V_pk / (V_pk / √3) = √3 ≈ 1.73205
V_показ = 1.11072 · (0.50000 · V_pk) = 0.55536 · V_pk
δ = ( (0.55536 - 0.57735) / 0.57735 ) · 100 % = -3.81 %
```

Для пилкоподібного (пилкоподібно-лінійного) сигналу інтеграли дають абсолютно ідентичні значення: `V_RMS = V_pk / √3`, `V_MAV = V_pk / 2`. Середньовипрямлений прилад стабільно занижує вимір пили та трикутника на `-3.81%`.

### 4. Однополярна послідовність імпульсів (ШІМ) з коефіцієнтом заповнення D

Нехай сигнал набуває значення `+V_pk` протягом тривалості імпульсу `t_on = D · T` (де `D ∈ (0, 1]`) та дорівнює `0` протягом інтервалу `t_off = (1 - D) · T`.

#### Виведення характеристик:

```
V_MAV = (1 / T) · ∫₀^(D·T) V_pk dt = (V_pk / T) · (D · T) = D · V_pk

V_RMS² = (1 / T) · ∫₀^(D·T) V_pk² dt = (V_pk² / T) · (D · T) = D · V_pk²
V_RMS = V_pk · √D
```

#### Коефіцієнт форми, пік-фактор та аналітична похибка:

```
k_f = (V_pk · √D) / (D · V_pk) = 1 / √D
CF = V_pk / (V_pk · √D) = 1 / √D
V_показ = 1.11072 · D · V_pk
δ(D) = ( (1.11072 · D · V_pk - V_pk · √D) / (V_pk · √D) ) · 100 %
= ( 1.11072 · √D - 1 ) · 100 %                     [скорочення на V_pk та спрощення D / √D = √D]
```

#### Чутливість похибки до зміни шпаруватості:

Швидкість зміни похибки при зміні коефіцієнта заповнення визначається похідною:

```
dδ / dD = (1.11072 / (2 · √D)) · 100 %
```

При малих `D` похідна стрімко зростає: що менша шпаруватість, то крутіше падає показ приладу відносно реального значення діючої напруги.

**Таблиця чисельних значень для різних шпаруватостей:**

| `D` | `V_RMS / V_pk` | `V_MAV / V_pk` | Пік-фактор `CF` | `V_показ / V_pk` | Похибка `δ` | Коментар |
|---|---|---|---|---|---|---|
| **0.8106** | 0.9003 | 0.8106 | 1.111 | 0.9003 | **0.00%** | Точка випадкового збігу (`√D = 1/1.11072`) |
| **0.50 (50%)** | 0.7071 | 0.5000 | 1.414 | 0.5554 | **−21.46%** | Меандр з однополярним зміщенням |
| **0.20 (20%)** | 0.4472 | 0.2000 | 2.236 | 0.2221 | **−50.33%** | Типовий робочий цикл драйвера світлодіода |
| **0.10 (10%)** | 0.3162 | 0.1000 | 3.162 | 0.1111 | **−64.88%** | Зарядний струм комп'ютерного блока живлення |
| **0.05 (5%)**  | 0.2236 | 0.0500 | 4.472 | 0.0555 | **−75.16%** | Вузькі імпульси пускового струму |
| **0.01 (1%)**  | 0.1000 | 0.0100 | 10.000 | 0.0111 | **−88.89%** | Імпульсні перешкоди комутації |

### 5. Фазово-зрізана синусоїда (тиристорний регулятор / димер)

Тиристор або симістор відкривається із запізненням на кут відсічки `α` (де `α ∈ [0, π]`) після переходу напруги через нуль:
`v(θ) = V_pk · sin(θ)` при `θ ∈ [α, π]` та `v(θ) = 0` при `θ ∈ [0, α]`.

#### Аналітичне виведення V_MAV(α):

```
V_MAV(α) = (1 / π) · ∫_α^π V_pk · sin(θ) dθ
= (V_pk / π) · [ -cos(θ) ]_α^π      [інтегрування синуса]
= (V_pk / π) · ( -cos(π) - (-cos(α)) ) [підстановка меж]
= (V_pk / π) · ( -(-1) + cos(α) )    [значення cos(π) = -1]
= (V_pk / π) · (1 + cos(α))
```

#### Аналітичне виведення V_RMS(α):

```
V_RMS²(α) = (1 / π) · ∫_α^π V_pk² · sin²(θ) dθ
= (V_pk² / π) · ∫_α^π ( (1 - cos(2θ)) / 2 ) dθ   [тригонометричне пониження степеня]
= (V_pk² / (2π)) · [ θ - (sin(2θ) / 2) ]_α^π     [первісна функція]
= (V_pk² / (2π)) · ( (π - (sin(2π) / 2)) - (α - (sin(2α) / 2)) ) [підстановка меж]
= (V_pk² / (2π)) · ( π - α + (sin(2α) / 2) )     [враховано sin(2π) = 0]

V_RMS(α) = V_pk · √( (1 / (2π)) · ( π - α + (sin(2α) / 2) ) )
```

#### Дослідження для ключових режимів роботи димера:

1. **Повна провідність (`α = 0`):**
   `cos(0) = 1`, `sin(0) = 0`
   `V_MAV(0) = (2/π)·V_pk ≈ 0.6366·V_pk`
   `V_RMS(0) = V_pk / √2 ≈ 0.7071·V_pk`
   `δ = 0.00%`

2. **Кут відсічки `α = π/4 = 45°` (легке приглушення потужності):**
   `cos(45°) = √2/2 ≈ 0.7071`, `sin(90°) = 1.0`
   `V_MAV(45°) = (V_pk / π) · (1 + 0.7071) ≈ 0.5434 · V_pk`
   `V_RMS(45°) = V_pk · √( (1/(2π)) · (3π/4 + 0.5) ) ≈ 0.6741 · V_pk`
   `V_показ = 1.11072 · 0.5434 · V_pk ≈ 0.6036 · V_pk`
   `δ = ( (0.6036 - 0.6741) / 0.6741 ) · 100 % = −10.46 %`

3. **Кут відсічки `α = π/2 = 90°` (половинна потужність навантаження):**
   `cos(90°) = 0`, `sin(180°) = 0`
   `V_MAV(90°) = V_pk / π ≈ 0.31831 · V_pk`
   `V_RMS(90°) = V_pk · √( (1/(2π)) · (π/2) ) = V_pk / 2 = 0.50000 · V_pk`
   `V_показ = 1.11072 · (V_pk / π) ≈ 0.35355 · V_pk`
   `δ = ( (0.35355 - 0.50000) / 0.50000 ) · 100 % = −29.29 %`

4. **Глибока відсічка `α = 3π/4 = 135°` (мале світіння ламп):**
   `cos(135°) = -√2/2 ≈ -0.7071`, `sin(270°) = -1.0`
   `V_MAV(135°) = (V_pk / π) · (1 - 0.7071) ≈ 0.09323 · V_pk`
   `V_RMS(135°) = V_pk · √( (1/(2π)) · (π/4 - 0.5) ) ≈ 0.2131 · V_pk`
   `V_показ = 1.11072 · 0.09323 · V_pk ≈ 0.10355 · V_pk`
   `δ = ( (0.10355 - 0.21310) / 0.21310 ) · 100 % = −51.41 %`

### 6. Випадковий стаціонарний гауссів шум

Для ергодичного випадкового процесу з нормальним розподілом щільності ймовірності `p(v) = (1 / (σ·√(2π))) · exp(-v² / (2σ²))` часове усереднення еквівалентне статистичному математичному сподіванню за ансамблем.

#### Виведення V_RMS:

```
V_RMS = √( E[v²] ) = √( σ² ) = σ
```

#### Виведення V_MAV:

```
V_MAV = E[|v|] = 2 · ∫₀^∞ (v / (σ·√(2π))) · exp(-v² / (2σ²)) dv
= (2 / (σ·√(2π))) · [ -σ² · exp(-v² / (2σ²)) ]₀^∞   [інтегрування методом заміни змінної u = v²/(2σ²)]
= (2 / (σ·√(2π))) · ( 0 - (-σ²) )                   [підстановка меж: exp(-∞)=0, exp(0)=1]
= (2σ² / (σ·√(2π))) = √(2 / π) · σ ≈ 0.79788456 · σ
```

#### Розрахунок параметрів форми та похибки:

```
k_f = σ / ( √(2/π) · σ ) = √(π / 2) ≈ 1.25331414
V_показ = 1.11072 · ( √(2/π) · σ ) = (π / (2√2)) · √(2/π) · σ = (1/2) · √π · σ ≈ 0.88622692 · σ
δ = ( (0.88623 - 1.00000) / 1.00000 ) · 100 % = −11.38 %
```

При вимірюванні теплового або напівпровідникового шуму звичайний мультиметр занижує справжню потужність шуму рівно на `-11.38%`.
