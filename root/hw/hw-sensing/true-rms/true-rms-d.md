У серверну стійку дата-центру встановлюють нову партію блейд-серверів. Електрик підключає струмові кліщі до фазного проводу розподільного щита й фіксує покази: на кожній із трьох фаз навантаження становить рівно `12 А`. Номінал автоматичного вимикача — `16 А`, переріз мідного кабелю розраховано на `25 А`, навантаження симетрично збалансоване між фазами. Монтаж здається бездоганним. Проте за дві години ізоляція нульового провідника плавиться від критичного перегріву, у приміщенні спрацьовує пожежна сигналізація, а розподільний щит виходить із ладу. Автоматичний трифазний вимикач навіть не знеструмив лінію, бо струм у фазах не перевищив теплову уставку.

Метрологічна експертиза з'ясовує приголомшливий факт: реальний тепловий струм у фазах становив `19.5 А`, а в нульовому провіднику через накладання третьої гармоніки циркулював струм силою `28 А`. Вимірювальні кліщі електрика показали `12 А` не через розряджену батарейку чи несправність. Прилад належав до дешевого класу середньовипрямлених детекторів (Mean Absolute Value), які вимірюють середнє арифметичне модуля сигналу й штучно масштабують його під синусоїду. Щойно у колі з'явилися імпульсні блоки живлення серверів із вузькими піками струму, прилад занизив реальний енергетичний нагрів майже вдвічі.

Сучасна силова та цифрова електроніка більше не споживає струм плавними синусоїдами. Світлодіодні драйвери, комп'ютери, імпульсні перетворювачі, частотні приводи електродвигунів (VFD) та симісторні димери споживають енергію короткими імпульсами з багатим спектром гармонік. Щоб виміряти справжню руйнівну та корисну енергію такого сигналу, вимірювальний прилад зобов'язаний обчислювати **діюче значення** (True RMS), а не спиратися на його спрощений сурогат.

### Фізична суть RMS: закон Джоуля — Ленца та нагрів

Поняття середньоквадратичного значення народилося не з абстрактних формул математичного аналізу, а з термодинаміки та фізики нагріву провідників. Змінний електричний струм безперервно змінює напрямок і величину. Якщо протягом періоду коливання `T` напруга здійснює симетричне коливання від додатного максимуму до від'ємного, її середнє інтегральне (арифметичне) значення дорівнює нулю:

```
V_avg = (1 / T) · ∫₀ᵀ v(t) dt = 0
```

Якби теплова дія струму залежала від його середнього напрямку, провідники змінного струму взагалі не нагрівалися б. Проте рух електронів крізь кристалічну ґратку металу викликає зіткнення з іонами незалежно від вектора швидкості. Коли змінний струм `i(t)` протікає крізь активний опір `R`, у кожну мить часу `t` виділяється миттєва теплова потужність:

```
p(t) = i²(t) · R = v²(t) / R
```

Оскільки квадрат будь-якого дійсного числа завжди є невід'ємним (`v²(t) ≥ 0`), миттєва теплова потужність пульсує з подвоєною частотою, але ніколи не компенсується до нуля. Сумарна теплова енергія `Q`, що виділилася в нагрівачі за повний період `T`, дорівнює визначеному інтегралу від миттєвої потужності:

```
Q = ∫₀ᵀ p(t) dt = (1 / R) · ∫₀ᵀ v²(t) dt
```

Середня теплова потужність `P_avg`, яка безперервно розсіюється резистором у навколишнє середовище:

```
P_avg = Q / T = (1 / R) · [ (1 / T) · ∫₀ᵀ v²(t) dt ]
```

Тепер сформулюємо головне фізичне запитання: **яку постійну напругу `V_DC` необхідно прикласти до того самого нагрівача `R`, щоб отримати точно таку саму швидкість виділення тепла `P_avg`?**

![Фізичний зміст RMS: еквівалент теплової потужності](/root/hw/hw-sensing/true-rms/img/fig-heating-equivalent.svg)
*Змінна напруга v(t) та еквівалентна постійна напруга V_DC = V_RMS виділяють однакову кількість теплоти Q на ідентичних нагрівальних резисторах R.*

Постійна напруга `V_DC` створює незмінну в часі потужність `P_DC = V_DC² / R`. Прирівнюючи обидві потужності, отримуємо фундаментальне рівняння теплового балансу:

```
V_DC² / R = (1 / R) · [ (1 / T) · ∫₀ᵀ v²(t) dt ]
V_DC² = (1 / T) · ∫₀ᵀ v²(t) dt
V_DC = √( (1 / T) · ∫₀ᵀ v²(t) dt )
```

Цю величину еквівалентної постійної напруги назвали **середньоквадратичним значенням** (англ. *Root Mean Square*, скорочено **RMS**; лат. *radix mediocris quadrati*). В україномовній метрологічній термінології закріпився термін **діюче (ефективне) значення**: це той еквівалент постійної напруги або струму, що виконує абсолютно таку саму теплову або механічну роботу, як і змінний сигнал довільної форми.

Абревіатура RMS описує алгоритм обчислення у зворотному порядку (справа наліво):
1. **S (Square):** піднести миттєву функцію напруги до квадрата `v²(t)`.
2. **M (Mean):** знайти середнє інтегральне значення квадрата за період `(1/T) · ∫ v²(t) dt`.
3. **R (Root):** добути квадратний корінь із розрахованого середнього.

Будь-який прилад із позначкою **True RMS** зобов'язаний реалізувати саме цей трикроковий ланцюг обчислень без жодних спрощень чи припущень щодо форми сигналу.

### Історичні теплові перетворювачі: як міряли True RMS до появи мікросхем

До винаходу швидкісних АЦП та аналогових логарифмічних перетворювачів єдиним способом прямого вимірювання True RMS було використання **термоелектричних компараторів** (термопарних перетворювачів).

Прилад містив дві вакуумовані скляні колби з прецизійними резистивними нитками розжарювання та привареними до них термопарами:
1. На першу нитку подавали досліджувану змінну напругу `v(t)`. Нитка нагрівалася до температури, строго пропорційної діючому значенню `V_RMS² / R`. Термопара генерувала мілівольтний термо-ЕРС сигнал.
2. На другу ідентичну нитку сервопідсилювач подавав регульовану постійну напругу `V_DC`.
3. Схема порівняння з високим коефіцієнтом підсилення підлаштовувала `V_DC` доти, доки термо-ЕРС обох термопар не ставали строго рівними.
4. Оскільки температури ниток збігалися, постійна напруга `V_DC` точно дорівнювала `V_RMS` змінного сигналу. Її вимірювали звичайним вольтметром постійного струму.

Цей метод (AC/DC Thermal Transfer Standard) і сьогодні залишається первинним метрологічним еталоном у національних палатах мір і ваг (NIST, NPL), оскільки він спирається безпосередньо на фізичний закон Джоуля — Ленца та забезпечує похибку менше `0.0001%` (1 ppm) у смузі частот від одиниць герц до сотень мегагерц. Проте для польових приладів теплові перетворювачі були надто крихкими, повільними (час реакції 1–3 секунди) та легко згорали при короткочасних перевантаженнях.

### Середньовипрямлений вимір: народження коефіцієнта 1.111

Стрілочні вольтметри магнітоелектричної системи реагують виключно на постійний струм: струм, протікаючи крізь рамку в полі постійного магніту, створює обертальний момент, пропорційний першому степеню струму.

Щоб створити простий і дешевий вольтметр змінного струму, інженери встановили перед стрілочною головкою звичайний діодний міст. Випрямляч відкидає знак від'ємної півхвилі, перетворюючи змінний сигнал `v(t)` на його модуль `|v(t)|`. Механічна інерція стрілки природним чином усереднює цей пульсуючий потік, показуючи **середнє значення модуля** — середньовипрямлену напругу (англ. *Mean Absolute Value*, **MAV** або *Average Rectified Value*, **ARV**):

```
V_MAV = (1 / T) · ∫₀ᵀ |v(t)| dt
```

Але споживачеві непотрібне середнє значення модуля — йому потрібне діюче значення, від якого залежить нагрів проводів та потужність трансформаторів. Для чистої гармонійної синусоїди `v(t) = V_pk · sin(ωt)` обидва інтеграли обчислюються аналітично:

```
V_RMS = V_pk / √2 ≈ 0.70711 · V_pk
V_MAV = (2 / π) · V_pk ≈ 0.63662 · V_pk
```

Співвідношення між діючим і середньовипрямленим значенням для чистої синусоїди є математичною константою, яку називають **коефіцієнтом форми** (англ. *form factor*, `k_f`):

```
k_f = V_RMS / V_MAV = (V_pk / √2) / ( (2/π) · V_pk ) = π / (2·√2) ≈ 1.11072
```

Виробники масових приладів пішли на компроміс: вони залишили всередині найдешевший випрямляч, що вимірює `V_MAV`, а стрілочну шкалу або коефіцієнт підсилювача просто **помножили на фіксований коефіцієнт `1.111`**:

```
V_показ = 1.11072 · V_MAV
```

![Середньовипрямлене значення проти True RMS](/root/hw/hw-sensing/true-rms/img/fig-rectified-vs-rms.svg)
*Для чистого синуса (ліворуч) множник 1.111 ідеально збігається з True RMS. Для імпульсного сигналу (праворуч) середнє модуля є мізерним, і масштабування на 1.111 занижує реальний тепловий нагрів у кілька разів.*

Поки навантаженням електромережі були лампи розжарювання та асинхронні двигуни, напруга й струм залишалися близькими до синусоїди, і похибка такого вимірювання не перевищувала 1–2%. Проте цей прилад спирається на критичне негласне припущення: **сигнал завжди є ідеальною синусоїдою**. Щойно форма спотворюється, коефіцієнт `1.111` перетворюється на джерело систематичних похибок.

> 🧮 Повні математичні виведення інтегралів, розкладів у ряд Фур'є та похибок для шести різних класів сигналів наведено у вставці [Аналітичний розрахунок похибки середньовипрямленого детектора](root:hw-sensing/true-rms/math-rectified-error.md).

### Катастрофа середньовипрямленого детектора на несинусоїдних сигналах

Помилка виникає через нелінійну природу функції піднесення до квадрата: **високі піки сигналу роблять непропорційно великий внесок у теплову енергію**. Середнє абсолютне значення сприймає сплеск амплітудою `10 В` просто як `10`, тоді як квадратичний інтеграл оцінює його внесок як `100`.

Розгляньмо, які похибки виникають на реальних промислових сигналах:

#### 1. Симетричний прямокутний сигнал (меандр)
- Діюче значення: `V_RMS = V_pk`.
- Середнє модуля: `V_MAV = V_pk`.
- Показ середньовипрямленого детектора: `V_показ = 1.111 · V_MAV = 1.111 · V_pk`.
- **Похибка: +11.1% (завищення).**

#### 2. Трикутний та пилкоподібний сигнал
- Діюче значення: `V_RMS = V_pk / √3 ≈ 0.577 · V_pk`.
- Середнє модуля: `V_MAV = 0.500 · V_pk`.
- Показ детектора: `V_показ = 1.111 · 0.500 · V_pk = 0.555 · V_pk`.
- **Похибка: −3.8% (заниження).**

#### 3. Фазово-зрізана синусоїда (тиристорний регулятор або димер при куті 90°)
- Діюче значення: `V_RMS = V_pk / 2 = 0.500 · V_pk`.
- Середнє модуля: `V_MAV = V_pk / π ≈ 0.318 · V_pk`.
- Показ детектора: `V_показ = 1.111 · 0.318 · V_pk ≈ 0.354 · V_pk`.
- **Похибка: −29.3% (грубе заниження на третину).**

#### 4. Струм імпульсного блока живлення (ШІМ з коефіцієнтом заповнення D = 10%)
Вхідний випрямляч джерела живлення заряджає буферний електролітичний конденсатор лише на самій верхівці напруги, споживаючи струм короткими голчастими імпульсами:
- Діюче значення струму: `I_RMS = I_pk · √0.1 ≈ 0.316 · I_pk`.
- Середнє модуля струму: `I_MAV = I_pk · 0.1 = 0.100 · I_pk`.
- Показ детектора: `I_показ = 1.111 · 0.100 · I_pk = 0.111 · I_pk`.
- **Похибка: −64.9% (заниження у 2.85 раза!).**

#### 5. Проблема нульового провідника в трифазних мережах (Triplen Harmonics)
У трифазній чотирипровідній мережі струми трьох фаз зміщені на `120°`. Для основної частоти `50 Гц` векторна сума струмів у нульовому проводі дорівнює нулю (`I_N = 0`), якщо навантаження збалансоване.

Але для гармонік, кратних трьом (3-тя гармоніка `150 Гц`, 9-та `450 Гц`, 15-та `750 Гц`), зсув фаз становить `3 · 120° = 360° = 0°`. Це означає, що **гармоніки, кратні трьом, у нульовому провіднику не віднімаються, а додаються у фазі**:

```
I_{N, 3} = I_{A, 3} + I_{B, 3} + I_{C, 3} = 3 · I_{phase, 3}
```

У будівлях із великою кількістю комп'ютерів (де 3-тя гармоніка струму сягає 70–80% від основної) сумарний діючий струм у нульовому провіднику часто досягає `130–170%` від фазного струму. Якщо контролювати таку мережу дешевими кліщами, вони покажуть безпечний струм, тоді як нейтраль буквально розжарюватиметься до червоного кольору.

### Пік-фактор (Crest Factor) та обмеження приладів

Щоб оцінити, наскільки складною для вимірювання є форма сигналу, використовують метрологічний показник — **пік-фактор** (англ. *Crest Factor*, `CF`):

```
CF = V_peak / V_RMS
```

Пік-фактор показує відношення пікової амплітуди сигналу до його середньоквадратичного теплового еквівалента.

![Пік-фактор різних форм сигналу](/root/hw/hw-sensing/true-rms/img/fig-crest-factor-waveforms.svg)
*Різні форми сигналів з їхніми значеннями пік-фактора CF та похибками середньовипрямленого вимірювання.*

- **Меандр:** `CF = 1.0` (найбільш енергетично насичений сигнал).
- **Синусоїда:** `CF = √2 ≈ 1.414`.
- **Трикутник:** `CF = √3 ≈ 1.732`.
- **Тиристорний димер:** `CF = 2.0 .. 3.5`.
- **Імпульсні блоки живлення, зварювальні апарати:** `CF = 3.0 .. 6.0` (а на холостому ходу — до `10.0`).

#### Чому високий пік-фактор є випробуванням для True RMS приладів

Навіть справжній True RMS прилад має апаратні межі. Якщо прилад налаштовано на діапазон `100 В RMS`, а його паспортний пік-фактор становить `CF = 3`, це означає, що внутрішній вхідний підсилювач та АЦП здатні лінійно опрацьовувати піки до `100 · 3 = 300 В`.

Якщо на вхід подати імпульсний сигнал із `V_RMS = 100 В`, але з пік-фактором `CF = 5` (піки сягають `500 В`), підсилювач увійде в апаратне насичення (кліпінг). Вершини імпульсів зріжуться шинами живлення підсилювача, квадратичний інтеграл недорахується енергії верхівок, і прилад почне суттєво занижувати діюче значення.

> 🔧 **Навіщо це.** Якщо ви вимірюєте сигнал із високим пік-фактором (струм тиристора або імпульсного перетворювача), **завжди вручну перемикайте мультиметр на одну або дві сходинки вище по діапазону**. Наприклад, якщо очікуваний струм становить `2 А RMS`, але пік-фактор високий, оберіть межу `10 А` або `20 А`. Це розширить запас за піковою напругою (headroom) вхідного тракту і збереже лінійність вимірювання.

### Апаратні аналогові True RMS конвертери (Implicit Log-Antilog Core)

У багатьох професійних мультиметрах та давачах струму застосовують спеціалізовані аналогові мікросхеми (AD736, AD737, AD8436, LTC1966).

Пряме перемноження сигналу аналоговим квадратором `V_in²` подвоює динамічний діапазон у децибелах (діапазон входу 60 дБ перетворюється на 120 дБ на виході квадратора), через що малі сигнали тонуть у шумах. Тому розробники використовують **непрямий (implicit) метод**, де ділення інтегровано в логарифмічне транзисторне ядро Баррі Гілберта:

```
V_out = Avg( V_in² / V_out )
⇒ V_out² = Avg( V_in² )
⇒ V_out = √( Avg( V_in² ) )
```

Завдяки негативному зворотному зв'язку через вихідну напругу `V_out`, внутрішні струми в транзисторах змінюються пропорційно **першому степеню** сигналу, забезпечуючи динамічний діапазон понад 60–80 дБ.

Зовнішній конденсатор усереднення `C_AV` задає компроміс між величиною низькочастотних пульсацій та часом реакції приладу на стрибок сигналу:
- Велика ємність `C_AV = 33 мкФ` мінімізує похибку на частоті 50 Гц до `< 0.1%`, але час встановлення показу зростає до 1.3 секунди.
- Мала ємність `C_AV = 1 мкФ` забезпечує швидку реакцію (40 мс), але викликає похибку усереднення до `1.5%` на низьких частотах.

> 🔌 Повний опис транслінійної схемотехніки, розрахунок фільтрів та захисних кілець на PCB викладено у вставці [Аналогові перетворювачі True RMS: будова та обмеження](root:hw-sensing/true-rms/comp-analog-rms.md).

### Дискретний розрахунок True RMS на мікроконтролері

У сучасних вбудованих пристроях вимірювання True RMS виконується програмно за допомогою АЦП та мікроконтролера (STM32, ESP32, RISC-V). Процесор дискретизує сигнал із частотою `f_s` і розраховує математичний еквівалент інтеграла:

```
V_RMS = √( (1 / N) · ∑_{i=0}^{N-1} v²[i] )
```

Щоб алгоритм працював бездоганно, необхідно усунути дві критичні алгоритмічні проблеми:

#### 1. Усунення постійної складової (DC Offset Removal)
Вбудовані АЦП мікроконтролерів є однополярними, тому двополярний сигнал зміщують штучним потенціалом `V_ref / 2 ≈ 1.65 В`. Розрахунок дисперсії через шкільну формулу `E[x²] - (E[x])²` призводить до **катастрофічного чисельного скасування** при малій амплітуді сигналу.

Правильне інженерне рішення — застосування потокового рекурсивного фільтра верхніх частот першого порядку (**IIR DC-Blocker**):

```
y[n] = x[n] - x[n-1] + α · y[n-1]
```

де коефіцієнт `α = 1 - (2π · f_c / f_s)` обирається для частоти зрізу `f_c = 1..2 Гц`. Фільтр очищає сигнал від зміщення та температурного дрейфу в реальному часі безпосередньо в перериванні АЦП.

#### 2. Синхронізація за перетином нуля (Zero-Crossing)
Якщо розмір вибірки не кратний періоду мережі `20 мс`, виникають пульсації показу через витік спектра. Тому накопичення квадратів синхронізують за допомогою програмного гістерезисного детектора переходу через нуль.

### Програмна реалізація блочного True RMS аналізатора

Нижче наведено модуль розрахунку True RMS для блоків відліків з паралельною компенсацією зміщення нуля та розгортанням циклу для процесорів з FPU (ARM Cortex-M4F/M7, ESP32).

:::tabs
```c
#include <math.h>
#include <stddef.h>
#include <stdbool.h>

// Високопродуктивний блочний розрахунок True RMS з усуненням зміщення нуля
// samples: буфер напруг у вольтах, зібраний строго за ціле число періодів
float calculate_true_rms(const float *samples, size_t length) {
    if (samples == NULL || length == 0) {
        return 0.0f;
    }

    // 1. Перший прохід: обчислення точного середнього постійного зміщення (DC Offset)
    // Цикл розгорнуто на 4 незалежні акумулятори для завантаження конвеєра FPU
    float sum_dc0 = 0.0f, sum_dc1 = 0.0f, sum_dc2 = 0.0f, sum_dc3 = 0.0f;
    size_t i = 0;
    for (; i + 3 < length; i += 4) {
        sum_dc0 += samples[i + 0];
        sum_dc1 += samples[i + 1];
        sum_dc2 += samples[i + 2];
        sum_dc3 += samples[i + 3];
    }
    float sum_dc = (sum_dc0 + sum_dc1) + (sum_dc2 + sum_dc3);
    for (; i < length; ++i) {
        sum_dc += samples[i];
    }
    const float dc_offset = sum_dc / (float)length;

    // 2. Другий прохід: накопичення квадратів змінної складової
    float sum_sq0 = 0.0f, sum_sq1 = 0.0f, sum_sq2 = 0.0f, sum_sq3 = 0.0f;
    i = 0;
    for (; i + 3 < length; i += 4) {
        float d0 = samples[i + 0] - dc_offset;
        float d1 = samples[i + 1] - dc_offset;
        float d2 = samples[i + 2] - dc_offset;
        float d3 = samples[i + 3] - dc_offset;

        sum_sq0 += d0 * d0;
        sum_sq1 += d1 * d1;
        sum_sq2 += d2 * d2;
        sum_sq3 += d3 * d3;
    }
    float total_sq = (sum_sq0 + sum_sq1) + (sum_sq2 + sum_sq3);
    for (; i < length; ++i) {
        float d = samples[i] - dc_offset;
        total_sq += d * d;
    }

    // 3. Добування кореня з середнього квадрата
    return sqrtf(total_sq / (float)length);
}
```
```cpp
#include <cmath>
#include <span>
#include <numeric>
#include <algorithm>

namespace sensing {

// Ідіоматичний C++ True RMS аналізатор на базі std::span
[[nodiscard]] float calculate_true_rms(std::span<const float> samples) noexcept {
    if (samples.empty()) {
        return 0.0f;
    }

    const auto n = samples.size();

    // 1. Паралельне накопичення постійної складової (DC Offset)
    float s_dc0 = 0.0f, s_dc1 = 0.0f, s_dc2 = 0.0f, s_dc3 = 0.0f;
    size_t i = 0;
    for (; i + 3 < n; i += 4) {
        s_dc0 += samples[i + 0];
        s_dc1 += samples[i + 1];
        s_dc2 += samples[i + 2];
        s_dc3 += samples[i + 3];
    }
    float sum_dc = (s_dc0 + s_dc1) + (s_dc2 + s_dc3);
    for (; i < n; ++i) {
        sum_dc += samples[i];
    }
    const float dc_offset = sum_dc / static_cast<float>(n);

    // 2. Накопичення квадратів змінної частини
    float s_sq0 = 0.0f, s_sq1 = 0.0f, s_sq2 = 0.0f, s_sq3 = 0.0f;
    i = 0;
    for (; i + 3 < n; i += 4) {
        const float d0 = samples[i + 0] - dc_offset;
        const float d1 = samples[i + 1] - dc_offset;
        const float d2 = samples[i + 2] - dc_offset;
        const float d3 = samples[i + 3] - dc_offset;

        s_sq0 += d0 * d0;
        s_sq1 += d1 * d1;
        s_sq2 += d2 * d2;
        s_sq3 += d3 * d3;
    }
    float total_sq = (s_sq0 + s_sq1) + (s_sq2 + s_sq3);
    for (; i < n; ++i) {
        const float d = samples[i] - dc_offset;
        total_sq += d * d;
    }

    return std::sqrt(total_sq / static_cast<float>(n));
}

} // namespace sensing
```

### True RMS (AC) проти True RMS (AC + DC)

У паспортах прецизійних приладів розрізняють два режими:

1. **AC-coupled True RMS (`RMS_AC`):**
   Вхідний конденсатор відсікає постійну напругу. Прилад вимірює діюче значення виключно змінної пульсації:

```
V_RMS_AC = √( (1/T) · ∫₀ᵀ (v(t) - V_DC)² dt )
```

2. **DC-coupled True RMS (`RMS_AC+DC` або Total RMS):**
   Прилад вимірює повну теплову потужність, що враховує одночасно як постійне зміщення, так і змінне коливання:

```
V_RMS_Total = √( V_DC² + V_RMS_AC² )
```

Якщо на виході силового випрямляча присутня постійна напруга `12 В` з пульсаціями `2 В RMS`:
- У режимі `RMS_AC` прилад покаже лише `2.0 В`.
- У режимі `RMS_AC+DC` прилад покаже `√(12² + 2²) = √148 ≈ 12.165 В`.

Ігнорування постійної складової при розрахунку перерізу кабелів чи нагріву дроселів призводить до недооцінки повного теплового навантаження.

### Метрологічний підсумок: вибір методу вимірювання

| Клас навантаження / сигналу | Оптимальний метод вимірювання | Наслідки використання середньовипрямленого приладу |
|---|---|---|
| **Чиста синусоїда (мережеві нагрівачі, лампи розжарювання)** | Будь-який вольтметр (зокрема середньовипрямлений) | Похибка дорівнює **0.0%** (форма збігається з еталоном калібрування) |
| **Комп'ютери, сервери, офісна техніка (ІБЖ)** | **True RMS (AC)** з пік-фактором `CF ≥ 3..5` | Заниження виміряного струму на **30–65%**, ризик перегріву кабелів і пожежі |
| **Тиристорні димери, фазові регулятори нагріву** | **True RMS (AC)** з широкою смугою частот | Заниження показу напруги на **20–50%** залежно від кута відсічки |
| **Частотно-регульовані приводи (ЧРП / VFD)** | **True RMS з фільтром низьких частот (Low-Pass)** | ШІМ-комутація перевантажує вхідний тракт, даючи хибне завищення на 20–40% |
| **Вихідні пульсації джерел живлення (Ripple & Noise)** | **True RMS (AC+DC)** або осцилограф | Режим AC ігнорує постійну напругу, не показуючи сумарний нагрів елементів |

Розуміння фізичної природи середньоквадратичного значення та відмова від застарілих середньовипрямлених наближень гарантує безпеку силових установок, точність комерційного обліку електроенергії та надійність вбудованих вимірювальних систем.
