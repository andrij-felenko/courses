# 🧲 Розрахунок магнітного кола осердя з повітряним зазором

У безконтактних давачах струму з відкритим контуром магнітне осердя виконує роль концентратора: воно збирає магнітний потік, породжений первинним струмом, і спрямовує його в невеликий повітряний зазор, де розташований напівпровідниковий кристал Холла. Без точного розрахунку геометрії осердя та ширини зазору неможливо передбачити ані чутливість сенсора, ані поріг його магнітного насичення. Цей документ містить повне виведення рівнянь магнітного кола з повітряним зазором на основі закону Гопкінсона та закону повного струму, аналіз крайового ефекту розсіювання потоку й числовий приклад проектування концентратора.

---

### 1. Закон повного струму та магніторушійна сила

Розглянемо замкнений контур інтегрування `L`, що проходить уздовж середньої лінії феромагнітного осердя довжиною `l_c` та перетинає повітряний зазор довжиною `l_g`. Провідник із первинним струмом `I_p` проходить крізь вікно осердя один раз (кількість первинних витків `N_p = 1`).

За [законом повного струму](root:ph-electromagnetism/ampere-circuital-law) (циркуляція вектора напруженості магнітного поля `H` по замкненому контуру):

```text
∮ H · dl = ∑ I_enclosed
H_c · l_c + H_g · l_g = N_p · I_p = I_p      [рівняння циркуляції для осердя із зазором]
```

де:
* `H_c` — напруженість магнітного поля у феромагнітному осерді (А/м);
* `l_c` — середня довжина магнітної лінії в осерді (м);
* `H_g` — напруженість магнітного поля в повітряному зазорі (А/м);
* `l_g` — геометрична ширина повітряного зазору (м);
* `I_p` — первинний вимірюваний струм (А).

Величина `F_m = N_p · I_p` називається **магніторушійною силою** (МРС, англ. *magnetomotive force*, MMF) і вимірюється в амперах (або ампер-витках).

---

### 2. Зв'язок між індукцією та напруженістю: магнітні опори

Зв'язок між магнітною індукцією `B` та напруженістю `H` визначається магнітною проникністю середовища:

```text
B_c = μ₀ · μ_r · H_c      [індукція у феромагнетику]
B_g = μ₀ · H_g            [індукція у вакуумі/повітрі, де μ_r = 1]
```

де:
* `μ₀ = 4π · 10⁻⁷` Гн/м — магнітна стала;
* `μ_r` — відносна магнітна проникність матеріалу осердя (для електротехнічної сталі `μ_r ≈ 2000..5000`, для силових феритів MnZn `μ_r ≈ 2000..10000`, для пермалою `μ_r ≈ 50000..100000`).

Згідно з теоремою Гаусса для магнітного поля (неперервність ліній магнітної індукції), повний магнітний потік `Φ` крізь будь-який поперечний переріз нерозгалуженого кола залишається сталим. Якщо площу перерізу осердя `S_c` вважати рівною площі перерізу зазору `S_g = S`, а крайовим розсіюванням на першому кроці знехтувати, магнітна індукція в осерді та зазорі однакова: `B_c = B_g = B`.

Виразимо напруженості через магнітний потік `Φ = B · S`:

```text
H_c = B / (μ₀ · μ_r) = Φ / (μ₀ · μ_r · S)    [напруженість у феромагнетику через потік]
H_g = B / μ₀         = Φ / (μ₀ · S)          [напруженість у зазорі через потік]
```

Підставимо ці вирази в рівняння закону повного струму:

```text
Φ · ( l_c / (μ₀ · μ_r · S) ) + Φ · ( l_g / (μ₀ · S) ) = I_p      [сума спадів магнітної напруги]
```

Введемо поняття **магнітного опору** (релактансу, англ. *magnetic reluctance* `R_m`), що має розмірність 1/Гн або А/Вб:

```text
R_m,c = l_c / (μ₀ · μ_r · S)      [магнітний опір феромагнітного осердя]
R_m,g = l_g / (μ₀ · S)            [магнітний опір повітряного зазору]
```

Тоді рівняння набуває форми [закону Гопкінсона](root:ph-electromagnetism/magnetic-reluctance) (магнітного аналога закону Ома `U = I · R`):

```text
F_m = Φ · (R_m,c + R_m,g) = Φ · R_m,total    [закон Гопкінсона для повного кола]
Φ = F_m / (R_m,c + R_m,g) = I_p / (R_m,c + R_m,g) [вираз для повного магнітного потоку]
```

### 3. Домінування зазору та виведення робочої індукції

Порівняємо величини магнітного опору осердя та повітряного зазору. Знайдемо їхнє відношення:

```text
R_m,c / R_m,g = ( l_c / (μ₀ · μ_r · S) ) / ( l_g / (μ₀ · S) )  [відношення опорів осердя та зазору]
= l_c / (μ_r · l_g)                                            [скорочення однакових множників μ₀ та S]
```

Для типового струмового сенсора середня довжина осердя `l_c = 100` мм = `0.1` м, ширина зазору `l_g = 2` мм = `0.002` м, а матеріал осердя — ферит MnZn із `μ_r = 3000`:

```text
R_m,c / R_m,g = 0.1 / (3000 · 0.002)        [підстановка: l_c = 0.1 м, μ_r = 3000, l_g = 2 мм]
= 0.1 / 6.0                                 [обчислення знаменника]
= 0.0167 ≈ 1.67%                            [частка опору сталі у загальному опорі кола]
```

Опір феромагнітного матеріалу становить менше 2% від повного магнітного опору кола. Понад 98% усього магнітного опору зосереджено у крихітному повітряному зазорі.

Завдяки умові `μ_r · l_g >> l_c`, ми можемо знехтувати `R_m,c` у знаменнику:

```text
Φ ≈ I_p / R_m,g = (I_p · μ₀ · S) / l_g      [потік за умови домінування зазору]
```

Знаючи, що магнітна індукція в зазорі `B_g = Φ / S`, отримуємо фундаментальну робочу формулу сенсора Холла з відкритим контуром:

```text
B_g = Φ / S                                 [визначення індукції через потік]
= ( (I_p · μ₀ · S) / l_g ) / S              [підстановка магнітного потоку]
= (μ₀ · I_p) / l_g                          [скорочення площі перерізу S]
```

> 📌 **Висновок.** За наявності осердя з високою магнітною проникністю магнітна індукція в зазорі практично не залежить від довжини та магнітної проникності самого осердя `μ_r` (а отже, і від його температурного дрейфу). Вона визначається виключно первинним струмом `I_p` та геометричною шириною зазору `l_g`.

### 4. Вплив крайового ефекту розсіювання (Fringing Effect)

У реальному зазорі силові лінії магнітного поля на краях полюсних наконечників вигинаються назовні — магнітний потік «спучується» у навколишній простір. Це явище називають **крайовим ефектом розсіювання** (англ. *fringing flux*).

Крайовий ефект призводить до двох наслідків:
1. Ефективна площа поперечного перерізу зазору `S_eff` стає більшою за геометричну площу перерізу осердя `S`;
2. Магнітний опір зазору дещо зменшується, а середня магнітна індукція `B_g` на осі зазору стає меншою за теоретичну величину `(μ₀ · I_p) / l_g`.

Для прямокутного перерізу осердя з розмірами сторін `a` та `b` і зазором `l_g` ефективна площа обчислюється емпіричною формулою:

```text
S_eff = (a + l_g) · (b + l_g)      [ефективна площа зазору з урахуванням розсіювання]
```

Коефіцієнт крайового розсіювання `k_f` визначається як:

```text
k_f = S_eff / S = ( (a + l_g) · (b + l_g) ) / (a · b)      [коефіцієнт зростання площі зазору]
```

Уточнена формула індукції в центрі зазору з урахуванням крайового ефекту та залишкового опору осердя набуває вигляду:

```text
B_g,real = (μ₀ · I_p) / ( l_g · k_f + (l_c / μ_r) )      [індукція з урахуванням розсіювання та опору сталі]
```

### 5. Розрахунок порогу насичення осердя

Феромагнітні матеріали мають кінцеву індукцію насичення `B_sat` (для електротехнічної кремнієвої сталі `B_sat ≈ 1.5..1.8` Тл, для силових феритів `B_sat ≈ 0.35..0.45` Тл, для аморфних сплавів на основі заліза `B_sat ≈ 1.2..1.5` Тл).

Коли магнітна індукція в осерді досягає `B_sat`, диференціальна магнітна проникність `μ_r` стрімко падає до 1, магнітний опір осердя різко зростає, і сенсор повністю втрачає лінійність.

Максимальний первинний струм `I_p,max`, який сенсор може виміряти без виходу осердя в насичення:

```text
B_c ≤ B_sat                                 [умова ненасиченого стану осердя]
B_g ≈ B_c  =>  (μ₀ · I_p,max) / (l_g · k_f) ≤ B_sat [підстановка дійсної індукції]
I_p,max = (B_sat · l_g · k_f) / μ₀          [максимальний струм до настання насичення]
```

Ширший зазор `l_g` дозволяє вимірювати значно більші струми без насичення, але пропорційно зменшує чутливість сенсора `S_B = B_g / I_p` (мТл/А).

### 6. Практичний числовий розрахунок концентратора струму

**Вихідні інженерні вимоги:**
* Номінальний первинний струм: `I_p,nom = 100` А;
* Максимальний вимірюваний струм перевантаження: `I_p,peak = 250` А;
* Чутливість елемента Холла: `S_Hall = 50` мВ/мТл при номінальному струмі живлення;
* Бажана вихідна напруга при 100 А: `V_out,nom = 2.0` В (без урахування зміщення нуля);
* Матеріал осердя: силовий ферит N87 (MnZn) з `B_sat = 0.38` Тл при 100 °C, `μ_r = 2200`;
* Геометрія осердя: тороїд із зовнішнім діаметром `D_out = 32` мм, внутрішнім `D_in = 20` мм, висотою `h = 10` мм.

**Крок 1. Геометричні параметри осердя:**
```text
r_avg = (D_out + D_in) / 4 = (32 + 20) / 4 = 13 мм = 0.013 м   [середній радіус тороїда]
l_c = 2 · π · r_avg = 2 · 3.1416 · 0.013 ≈ 0.0817 м (81.7 мм)  [довжина середньої магнітної лінії]
a = (D_out - D_in) / 2 = (32 - 20) / 2 = 6 мм = 0.006 м       [радіальна товщина стінки]
b = h = 10 мм = 0.010 м                                        [осьова висота осердя]
S = a · b = 0.006 · 0.010 = 6.0 · 10⁻⁵ м² (60 мм²)             [площа перерізу осердя]
```

**Крок 2. Визначення необхідної індукції в зазорі:**
```text
V_out,nom = S_Hall · B_g,nom                [зв'язок напруги з індукцією]
2.0 В = 0.050 В/мТл · B_g,nom               [підстановка V_out = 2.0 В та S_Hall = 50 мВ/мТл]
B_g,nom = 2.0 / 0.050 = 40 мТл = 0.040 Тл   [необхідна номінальна індукція]
```

**Крок 3. Розрахунок необхідної ширини зазору:**
```text
B_g,nom = (μ₀ · I_p,nom) / l_g              [теоретична формула зазору без розсіювання]
l_g = (μ₀ · I_p,nom) / B_g,nom              [вираження ширини зазору]
= (4π · 10⁻⁷ · 100) / 0.040                 [підстановка μ₀, I_p = 100 А та B_g = 0.040 Тл]
= (1.2566 · 10⁻⁴) / 0.040                   [множення у чисельнику]
= 3.1416 · 10⁻³ м ≈ 3.14 мм                 [розрахункова ширина зазору]
```

Приймемо стандартну технологічну ширину пропилу зазору: `l_g = 3.2` мм.

**Крок 4. Розрахунок крайового коефіцієнта та дійсної індукції:**
```text
S_eff = (a + l_g) · (b + l_g) = (6.0 + 3.2) · (10.0 + 3.2) = 121.44 мм² [ефективна площа зазору]
k_f = S_eff / S = 121.44 / 60.0 = 2.024                                [коефіцієнт крайового розсіювання]
B_g,real = (μ₀ · I_p,nom) / (l_g · k_f + l_c / μ_r)                     [уточнена формула індукції]
Знаменник: 0.0032 · 2.024 + 0.0817 / 2200 = 0.006477 + 0.000037 = 0.006514 м [обчислення знаменника]
B_g,real = (1.2566 · 10⁻⁴) / 0.006514 ≈ 0.01929 Тл = 19.3 мТл          [дійсна індукція в центрі зазору]
```

Через значний крайовий ефект (`k_f ≈ 2.02`) реальна індукція знизилася з 40 мТл до 19.3 мТл. Для отримання 2.0 В на виході коефіцієнт підсилення електронного тракту після кристала Холла має складати:
`G = 40.0 / 19.3 ≈ 2.07`.

**Крок 5. Перевірка запасу до насичення при піковому струмі `I_p,peak = 250` А:**
```text
B_c,peak ≈ B_g,peak · k_f                   [індукція в матеріалі осердя при піку]
= ( (μ₀ · 250) / 0.006514 ) · 2.024         [підстановка пікового струму 250 А]
= ( 3.1416 · 10⁻⁴ / 0.006514 ) · 2.024     [обчислення магнітної індукції]
= 0.0482 · 2.024 ≈ 0.0976 Тл = 97.6 мТл     [пікова індукція значно нижча за поріг 380 мТл]
```

Оскільки `B_c,peak = 0.098` Тл значно менше за поріг насичення фериту `B_sat = 0.38` Тл (коефіцієнт запасу `0.38 / 0.098 ≈ 3.9`), осердя гарантовано працює в глибоко лінійній зоні характеристики навіть при перевантаженнях струмом.
