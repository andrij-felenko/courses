## Математична модель перетворювача та лінеаризація в околі робочої точки

Вихідний цифровий код ідеального лінійного аналого-цифрового перетворювача описується рівнянням квантування:

```
D(V_in) = floor((V_in / V_ref) · 2^B)
```

де `V_in` — вхідна напруга, `V_ref` — напруга джерела опорного потенціалу, `B` — розрядність АЦП. За реальних умов експлуатації всі фізичні параметри схеми стають функціями абсолютної температури `T`. 

Загальна передавальна функція неідеального вимірювального тракту з урахуванням вхідного масштабувального дільника або підсилювача з коефіцієнтом `G(T)` та напруги зміщення нуля `V_os(T)` набуває вигляду:

```
V_equiv(T) = G(T) · (V_in + V_os(T))
D(T) = floor((V_equiv(T) / V_ref(T)) · 2^B)    [статична передавальна функція з температурними залежностями]
```

Для аналітичного розрахунку похибок розкладають параметри `V_os(T)`, `G(T)` та `V_ref(T)` у ряд Тейлора в околі номінальної температури калібрування `T_0 = +25 °C` (+298.15 K). 

Для лінійних величин (зміщення та підсилення) достатньо лінійного наближення першого порядку:

```
V_os(T) = V_os(T_0) + TCV_os · (T - T_0)
G(T) = G(T_0) · (1 + TC_G · (T - T_0))
```

Однак для джерела опорної напруги на базі зонного стабілізатора (@@en|bandgap reference@@) лінійне наближення є недостатнім через характерну параболічну форму температурної кривої (кривизну вищих порядків). Розклад `V_ref(T)` з урахуванням квадратичного члена другого порядку має вигляд:

```
V_ref(T) = V_ref(T_0) · (1 + TC_vref · (T - T_0) + β_vref · (T - T_0)²)    [розклад опорної напруги з квадратичною кривизною]
```

де `TCV_os = dV_os / dT` — температурний коефіцієнт зміщення нуля (мкВ/°C), `TC_G = (1/G) · (dG/dT)` — лінійний коефіцієнт підсилення (ppm/°C), `TC_vref = (1/V_ref) · (dV_ref/dT)` — лінійний коефіцієнт опорної напруги ([Опорна напруга](root:hw-sensing/voltage-reference)) (ppm/°C), а `β_vref = (1/(2·V_ref)) · (d²V_ref/dT²)` — коефіцієнт квадратичної кривизни параболи (ppm/°C²).

Для високостабільних зонних джерел із термокомпенсацією першого порядку лінійний нахил у точці оптимуму дорівнює нулю (`TC_vref(T_0) ≈ 0`), тому саме квадратичний член `β_vref · ΔT²` визначає граничну нестабільність на краях температурного діапазону (наприклад, при -40 °C та +85 °C).

Відхилення вихідного еквівалентного напругового значення відкаліброваної системи при зміні температури на `ΔT = T - T_0` визначається через повний диференціал передавальної функції другого порядку:

```
ΔV_total = (∂V_equiv / ∂V_os) · ΔV_os + (∂V_equiv / ∂G) · ΔG + (∂V_equiv / ∂V_ref) · ΔV_ref + (1/2) · (∂²V_equiv / ∂V_ref²) · (ΔV_ref)²
```

Звідси при підстановці часткових похідних отримуємо повну аналітичну модель відхилення:

```
ΔV_total(ΔT, V_in) = G · TCV_os · ΔT + TC_G · ΔT · V_in - TC_vref · ΔT · V_in - β_vref · (ΔT)² · V_in    [повна модель відхилення з квадратичним членом]
```

> 🔧 **Навіщо це.**
> Врахування квадратичного члена ряду Тейлора дозволяє точно розрахувати залишковий температурний дрейф прецизійних зонних стабілізаторів на краях робочого діапазону, де лінійне наближення помилково показує нульову похибку.

## Аналітичні вирази окремих складових температурного дрейфу

Обчислення окремих похибок у напруговому еквіваленті на вході АЦП виконують за такими виразами:

1. **Адитивна похибка зміщення нуля (Offset Error):**
Похибка зміщення діє безпосередньо на вході перетворювача незалежно від рівня сигналу `V_in`:

```
E_os(ΔT) = TCV_os · ΔT    [абсолютна похибка зміщення, мкВ]
```

У відносних одиницях від повної шкали `FSR = V_ref / G`:

```
ε_os(ppm) = (E_os / FSR) · 10⁶
          = ((TCV_os · ΔT) / FSR) · 10⁶    [відносна похибка зміщення в ppm]
```

2. **Температурний внесок вхідного струму витоку (Input Leakage Error):**
Вхідний струм витоку ESD-діодів та затворів вхідних буферів `I_leak(T)` експоненційно зростає з підвищенням температури. Протікаючи через еквівалентний імпеданс джерела сигналу `R_src` та балансувальний резистор фільтра `R_filt`, струм витоку створює додаткову адитивну температурну напругу:

```
I_leak(T) = I_0 · 2^((T - T_0) / 10)
E_leak(ΔT) = (I_leak(T) - I_leak(T_0)) · R_src    [напруговий еквівалент температурного витоку]
```

Для високоомних джерел сигналу (наприклад, рН-електродів чи п'єзодавачів з `R_src > 1` МОм) саме експоненційний внесок `E_leak(ΔT)` при температурах понад +60 °C стає домінуючим фактором сумарного зміщення нуля.

3. **Мультиплікативна похибка коефіцієнта підсилення тракту (Gain Error):**
Якщо вхідний масштабувальний дільник побудовано на двох резисторах `R_1` та `R_2` з коефіцієнтом передачі `G = R_2 / (R_1 + R_2)`, його дрейф визначається різницею їхніх температурних коефіцієнтів опору (ТКС):

```
TC_divider = TKR_2 - TKR_1    [температурний коефіцієнт узгодження резисторів]
E_gain_adc(ΔT) = (TC_G_adc + TC_divider) · ΔT · V_in    [напруговий еквівалент дрейфу масштабу]
```

4. **Мультиплікативна похибка опорної напруги (VREF Error):**
Дрейф джерела опорної напруги діє обернено пропорційно:

```
E_vref(ΔT) = -TC_vref · ΔT · V_in    [напруговий еквівалент дрейфу VREF]
```

Оскільки обидві мультиплікативні складові (дрейф підсилення та дрейф VREF) пропорційні вимірюваній напрузі `V_in`, їх об'єднують у сумарну похибку масштабу:

```
E_scale(ΔT, V_in) = (TC_G_adc + TC_divider - TC_vref) · ΔT · V_in    [сумарний дрейф повної шкали]
```

> 🔧 **Навіщо це.**
> Аналітичний поділ похибок на адитивні (зміщення та струми витоку) та мультиплікативні (масштаб) показує, що для малих сигналів (біля нуля) головний внесок робить дрейф `TCV_os` та `E_leak`, а для великих сигналів (біля повної шкали) домінує дрейф `TC_vref`.

## Методи підсумовування компонентів дрейфу: worst-case та RSS

Під час проєктування аналогового тракту інженер стикається з вибором математичної моделі агрегації окремих джерел температурної похибки:
- `E_os(ΔT) = TCV_os · ΔT` — адитивний дрейф зміщення нуля, виражений у вольтах або мікровольтах;
- `E_gain(ΔT) = TC_gain · ΔT · V_in` — мультиплікативний дрейф підсилення АЦП;
- `E_vref(ΔT) = TC_vref · ΔT · V_in` — мультиплікативний дрейф опорної напруги;
- `E_div(ΔT) = ΔTC_R · ΔT · V_in` — похибка розбіжності температурних коефіцієнтів резисторів вхідного дільника масштабування.

Оцінка за найгіршим випадком (@@en|worst-case analysis@@) базується на припущенні, що всі фізичні компоненти тракту мають максимальні паспортні температурні коефіцієнти і дрейфують в одному несприятливому напрямку одночасно:

```
E_total_wc(ΔT) = |E_os(ΔT)| + |E_gain(ΔT)| + |E_vref(ΔT)| + |E_div(ΔT)|
               = |TCV_os| · ΔT + (|TC_gain| + |TC_vref| + |ΔTC_R|) · ΔT · V_in    [граничне лінійне підсумовування модулів]
```

Цей метод є детермінованим і гарантує, що жоден виготовлений екземпляр плати за будь-яких умов не вийде за встановлені межі похибки. Проте для багатокомпонентних систем розрахунок за найгіршим випадком призводить до надмірної вартості та надлишкових вимог до вибору компонентів.

Статистичний метод середньоквадратичного підсумовування (@@en|root-sum-square@@, RSS) спирається на центральну граничну теорему теорії ймовірностей. Якщо окремі джерела дрейфу є некорельованими випадковими величинами з нормальним розподілом значень відносно нуля, дисперсія суми дорівнює сумі дисперсій складових:

```
σ_total² = σ_os² + σ_gain² + σ_vref² + σ_div²    [адитивність дисперсій незалежних процесів]
```

Вибір множника довірчого інтервалу `k_σ` визначає ймовірність того, що серійний пристрій вкладеться у розрахований похибковий бюджет без необхідності індивідуального підстроювання (вихід придатної продукції — @@en|manufacturing yield@@):
1. Оцінка `1σ` (`E_total_1σ = 1.0 · E_rss`): охоплює 68.27 % виготовлених пристроїв. Для промислового виробництва такий рівень браку (31.73 %) є неприйнятно високим.
2. Оцінка `2σ` (`E_total_2σ = 2.0 · E_rss`): охоплює 95.45 % виробів, що є типовим компромісом для масової споживчої електроніки.
3. Оцінка `3σ` (`E_total_3σ = 3.0 · E_rss`): охоплює 99.73 % усіх змонтованих плат і є золотим стандартом проектування високоточної вимірювальної та медичної апаратури:

```
E_total_rss(ΔT, 3σ) = 3 · √((σ_os · ΔT)² + ((σ_gain + σ_vref + σ_div) · ΔT · V_in)²)    [3-сигма границя RSS-бюджету]
```

Корельовані величини (наприклад, два резистори однієї монолітної тонкоплівкової матриці, які нагріваються спільно) підсумовуються алгебрично як `(TC_R1 - TC_R2) = ΔTC_R`, і лише результуюча некорельована різниця входить під знак кореня RSS.

> 🔧 **Навіщо це.**
> Розрахунок за RSS з аналізом 1σ/2σ/3σ дозволяє знайти баланс між собівартістю компонентів вимірювального тракту та відсотком відбракування плат під час заводського тестування в кліматичній камері.

## Наскрізний числовий розрахунок та визначення ефективної розрядності ENOB

Розглянемо числовий приклад розрахунку для прецизійного вимірювального тракту постійного струму з 24-розрядним Delta-Sigma АЦП за таких вихідних даних:
- Розрядність перетворювача: `B = 24` біти.
- Опорна напруга: `V_ref = 2.5` В, діапазон вхідної напруги: `V_in_max = 2.5` В.
- Вага молодшого значущого розряду за кімнатної температури (+25 °C):

```
LSB = V_ref / 2²⁴
    = 2.5 В / 16777216
    ≈ 0.149 мкВ (149 нВ)    [роздільна здатність 24-розрядного перетворювача]
```

- Температурний діапазон експлуатації: від `T_min = -40` °C до `T_max = +85` °C.
- Максимальний перепад температури від точки калібрування (+25 °C):

```
ΔT = max(|85 - 25|, |-40 - 25|)
   = max(60, 65)
   = 65 °C                  [максимальне температурне відхилення]
```

Паспортні параметри компонентів прецизійного тракту:
1. Дрейф зміщення нуля АЦП: `TCV_os = 0.5` мкВ/°C.
2. Дрейф масштабу АЦП: `TC_gain = 2.0` ppm/°C = `2.0 · 10⁻⁶` 1/°C.
3. Дрейф зовнішнього джерела опорної напруги `V_ref`: `TC_vref = 3.0` ppm/°C = `3.0 · 10⁻⁶` 1/°C.
4. Розбіжність ТКС резисторів вхідного дільника: `ΔTC_R = 5.0` ppm/°C = `5.0 · 10⁻⁶` 1/°C.

Розрахунок абсолютних внесків при максимальному вхідному сигналі `V_in = 2.5` В:

```
E_os = TCV_os · ΔT
     = 0.5 мкВ/°C · 65 °C
     = 32.5 мкВ             [абсолютна похибка зміщення нуля]

E_gain = TC_gain · ΔT · V_in
       = 2.0 · 10⁻⁶ · 65 · 2.5 В
       = 3.25 · 10⁻⁴ В
       = 325 мкВ            [абсолютна похибка підсилення АЦП]

E_vref = TC_vref · ΔT · V_in
       = 3.0 · 10⁻⁶ · 65 · 2.5 В
       = 4.875 · 10⁻⁴ В
       = 487.5 мкВ          [абсолютна похибка дрейфу опорної напруги]

E_div = ΔTC_R · ΔT · V_in
      = 5.0 · 10⁻⁶ · 65 · 2.5 В
      = 8.125 · 10⁻⁴ В
      = 812.5 мкВ           [абсолютна похибка розбіжності резисторів]
```

Розрахунок сумарної температурної похибки тракту:

```
E_total_wc = E_os + E_gain + E_vref + E_div
           = 32.5 + 325.0 + 487.5 + 812.5
           = 1657.5 мкВ ≈ 1.658 мВ    [гранична похибка за найгіршим випадком]

E_mult_total = E_gain + E_vref + E_div
             = 325.0 + 487.5 + 812.5
             = 1625.0 мкВ             [сумарна мультиплікативна похибка]

E_total_rss = √(E_os² + E_mult_total²)
            = √(32.5² + 1625.0²)
            = √(1056.25 + 2640625)
            = √2641681.25
            ≈ 1625.3 мкВ ≈ 1.625 мВ   [статистична середня похибка за RSS]
```

Обчислення кількості втрачених розрядів та ефективної розрядності (@@en|effective number of bits@@, ENOB):

```
N_error_lsb = E_total_rss / LSB
            = 1625.3 мкВ / 0.149 мкВ
            ≈ 10908 LSB               [еквівалентна похибка в одиницях LSB]

Bits_lost = log₂(N_error_lsb)
          = log₂(10908)
          = ln(10908) / ln(2)
          ≈ 9.297 / 0.69315
          ≈ 13.41 біта                [кількість розрядів, з'їдених дрейфом]

ENOB_thermal = B - Bits_lost
             = 24 - 13.41
             = 10.59 біта             [реальна ефективна розрядність системи]
```

Числовий розрахунок показує: без застосування чоперної стабілізації та активної термокомпенсації висококласний 24-розрядний АЦП під впливом перепаду температури у 65 °C деградує до рівня 10–11 розрядів через неминучий дрейф резисторів та джерела опорної напруги ([Шум опорної напруги АЦП](root:hw-sensing/adc-vref-noise)).

> 🔧 **Навіщо це.**
> Визначення ENOB на основі температурного бюджету похибок захищає розробника від помилкових очікувань, що закупівля 24-бітної мікросхеми автоматично гарантує мікровольтову точність на відкритому повітрі.
