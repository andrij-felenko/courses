# Температурний дрейф АЦП

## Чому температура руйнує точність АЦП

Прецизійний вимірювальний прилад, налаштований за кімнатної температури (+25 °C), втрачає реальну точність при винесенні на вулицю або через нагрівання від сусідніх деталей на платі. В основі будь-якого аналого-цифрового перетворювача лежить напівпровідниковий кристал, чиї фізичні параметри — концентрація носіїв заряду, контактний потенціал p-n переходів і питомий опір шарів — неперервно змінюються разом із температурою.

Додаткову похибку створює механічне напруження корпусу мікросхеми (@@en|package stress@@). Кремній кристала розширюється при нагріванні значно повільніше, ніж пластиковий компаунд корпусу чи металеві виводи. Під час температурних коливань виникає пружний тиск на поверхню чипа, який через п'єзоефект деформує внутрішні ємності та резистори [SAR АЦП](root:hw-sensing/sar-adc-internals), спотворюючи бінарні ваги розрядів.

![Вплив зміни температури на передавальну характеристику АЦП: зміщення нульової точки, поворот шкали через дрейф підсилення та нелінійне викривлення](adc-temperature-drift-effects-curves.svg)
_Температурний дрейф деформує характеристику перетворення трьома шляхами: паралельно зсуває нульовий рівень, змінює кут нахилу масштабу та вносить нелінійні спотворення кодових переходів._

Термодинамічна нестабільність проявляється у трьох складових [похибок АЦП](root:hw-sensing/adc-errors):
1. Дрейф зміщення нуля (@@en|offset drift@@) — паралельний зсув характеристики перетворення вгору або вниз (мкВ/°C).
2. Дрейф коефіцієнта масштабу (@@en|gain drift@@) — поворот передавальної прямої навколо нуля, що збільшує абсолютну похибку зі зростанням амплітуди вимірюваного сигналу (ppm/°C).
3. Дрейф нелінійності (@@en|INL/DNL drift@@) — локальні викривлення форми характеристики, через які на граничних температурах виникають пропущені коди.

> 🔧 **Навіщо це.**
> Розуміння природи дрейфу дозволяє передбачити, чи втримає 16-розрядний вимірювальний канал свою паспортну точність в умовах перепаду температур від -40 °C до +85 °C.

## Джерела дрейфу нуля й масштабу

Головним винуватцем дрейфу масштабу у переважній більшості схем є [джерело опорної напруги](root:hw-sensing/voltage-reference). Оскільки вихідний код АЦП `N` визначається відношенням вхідної напруги `V_in` до еталону `V_ref`:

```
N = (V_in / V_ref) · 2^B
```

будь-яке відносне відхилення `V_ref` на 0.1 % пропорційно спотворює результат вимірювання на ті самі 0.1 % по всій шкалі.

Вбудовані зонні джерела опорної напруги (@@en|bandgap reference@@) компенсують негативний температурний спад напруги p-n переходу додаванням пропорційної абсолютній температурі додатної складової. Через нелінійність фізики напівпровідників результуюча опорна напруга утворює типову параболічну криву викривлення.

![Параболічна температурна залежність напруги зонного стабілізатора та межі прямокутника методу коробки для визначення паспортного дрейфу](bandgap-vref-temperature-curvature.svg)
_Температурна характеристика зонного джерела VREF: відхилення від номіналу мають нелінійну форму, а паспортний дрейф оцінюють методом коробки за максимальним розмахом напруги в заданому діапазоні._

Паспортний дрейф таких джерел нормують «методом коробки» (@@en|box method@@), де різниця між максимальною та мінімальною напругою ділиться на температурний діапазон:

```
TC_Vref = ((V_max - V_min) / (V_nom · (T_max - T_min))) · 10⁶    [дрейф опорної напруги методом коробки, ppm/°C]
```

Для вбудованих стабілізаторів дрейф становить 20–50 ppm/°C, що при перепаді у 50 °C дає суттєву похибку до 0.25 % (втрата 8 бітів точності).

Зсув нульової точки АЦП породжують два зовнішні фізичні явища:
1. Термоелектричний ефект Зеєбека: місця спаювання мідних доріжок плати та металевих виводів мікросхеми утворюють паразитні термопари. Якщо між двома диференціальними входами виникає температурний градієнт всього у 0.1 °C, це створює паразитну ЕРС у кілька мікровольтів.
2. Струми витоку захисних діодів (ESD-структур): струм витоку закритих p-n переходів подвоюється кожні 10 °C нагрівання. Протікаючи крізь внутрішній опір джерела сигналу, нагрітий струм витоку створює додаткове паразитне спадання напруги, що зміщує нульовий рівень.

> 🔧 **Навіщо це.**
> Для вимірювання слабких сигналів мікровольтового рівня (давачів мостів, термопар) головним ворогом є дрейф нуля, тоді як при вимірюванні повної напруги (батарей, шин живлення) вирішальну роль відіграє дрейф опорної напруги VREF.

## Методи стабілізації вимірювань

Щоб зберегти високу роздільну здатність перетворювача при зміні температури, застосовують апаратні, програмні та конструктивні методи компенсації.

Усередині прецизійних мікросхем дрейф нуля нейтралізують динамічною комутацією фаз сигналу:
1. Автонульова установка (@@en|auto-zeroing@@): у першій фазі входи замикаються накоротко, а миттєва напруга зміщення запам'ятовується на внутрішньому конденсаторі. У другій фазі вимірювання ця збережена напруга віднімається від вхідного сигналу.
2. Чоперна стабілізація (@@en|chopper stabilization@@): матриця транзисторних ключів періодично міняє полярність вхідного сигналу на частоті комутації, модулюючи корисний сигнал і залишаючи дрейф на нульовій частоті.

![Функціональна схема чоперного перемикання входів модулятора у двох фазах тактування](auto-zero-and-chopping-phases.svg)
_Чоперний модулятор перемикає полярність вимірюваного сигналу у двох протилежних фазах тактування, завдяки чому при підсумовуванні та цифровій фільтрації постійний дрейф зміщення взаємно анігілює._

Після демодуляції цифровий усереднюючий фільтр повністю знищує напругу зміщення:

```
V_res = (V_out(Φ1) + V_out(Φ2)) / 2
      = ((V_in + V_os) + (V_in - V_os)) / 2
      = V_in
```

Коли внутрішня апаратна комутація відсутня, стабілізацію виконують програмно. Мікроконтролер періодично перемикає вхідний мультиплексор на аналогову землю (AGND) для вимірювання поточного нуля `N_zero(T)` та на еталонне джерело для оцінки масштабу `N_fscale(T)`. Робочі дані коригуються безпосередньо у прошивці:

```
N_corrected = ((N_raw - N_zero(T)) · N_nominal) / (N_fscale(T) - N_zero(T))
```

Фінальну лінію захисту забезпечує грамотне трасування друкованої плати:
- Симетричні диференціальні провідники однакової довжини й ширини, щоб паразитні термо-ЕРС спаїв взаємно компенсувалися;
- Фрезеровані теплоізоляційні прорізи між вимірювальною зоною та гарячими елементами (стабілізаторами, силовими транзисторами);
- Суцільний мідний полігон землі, який швидко вирівнює локальні теплові градієнти навколо корпусу мікросхеми.

> 🔧 **Навіщо це.**
> Поєднання апаратного чопера або регулярного програмного калібрування з грамотним тепловим дизайном плати дозволяє утримувати точність приладу на рівні мікровольтів у всьому промисловому діапазоні температур.
