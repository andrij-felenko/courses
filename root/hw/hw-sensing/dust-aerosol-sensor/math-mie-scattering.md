# 🧮 Розсіювання Мі та розрахунок концентрації аерозолів

Оптичний підрахунок частинок (англ. *Optical Particle Counter*, OPC) спирається на розв'язок класичних рівнянь Максвелла для електромагнітної хвилі, що падає на однорідну діелектричну сферу. Коли діаметр аерозольної частинки `d_p` співмірний із довжиною хвилі лазерного випромінювання `λ` (для типових напівпровідникових лазерів `λ = 650` нм), наближення геометричної оптики та релеївського розсіювання втрачають точність. Точний аналіз амплітуди сигналу розсіяння та його подальший перерахунок у масову концентрацію вимагає інтегрування диференціального перерізу за апертурою оптичного приймача та врахування функції розподілу частинок за розмірами.

### 1. Безрозмірний параметр розміру та хвильове число

Взаємодія світла зі сферичною частинкою визначається безрозмірним параметром розміру `x` (англ. *size parameter*), який зіставляє периметр поперечного перерізу частинки з довжиною хвилі випромінювання в навколишньому середовищі з показником заломлення `n_m` (для сухого повітря `n_m ≈ 1.00029`):

```
k = (2 · π · n_m) / λ         [хвильове число у повітрі]
x = k · r_p = (π · d_p) / λ   [безрозмірний параметр розміру сфери]
```

Для лазерного діода з довжиною хвилі `λ = 650` нм у середовищі повітря типовий діапазон часток PM2.5 та PM10 охоплює такі значення параметра `x`:
- Частинка `d_p = 0.3` мкм: `x = (π · 0.3) / 0.65 ≈ 1.45` (початок перехідної області Мі);
- Частинка `d_p = 1.0` мкм: `x = (π · 1.0) / 0.65 ≈ 4.83` (виражене резонансне розсіювання Мі);
- Частинка `d_p = 2.5` мкм: `x = (π · 2.5) / 0.65 ≈ 12.08` (розвинена інтерференційна структура);
- Частинка `d_p = 10.0` мкм: `x = (π · 10.0) / 0.65 ≈ 48.33` (перехід до дифракції Фраунгофера).

Відносний комплексний показник заломлення речовини аерозолю відносно повітря записується через дійсну частину `m_r` (заломлення) та уявну частину `m_i` (поглинання):

```
m = (n_p + i · κ_p) / n_m = m_r + i · m_i
```

Для стандартного мінерального пилу та силікатів `m ≈ 1.53 + 0.005 · i`, для сажі (вуглецевого аерозолю) `m ≈ 1.85 + 0.71 · i`, для крапель води `m ≈ 1.33 + 10⁻⁸ · i`.

### 2. Амплітудні функції розсіювання та переріз

Електричне поле розсіяної хвилі в дальній зоні (на відстані `R >> d_p²/λ`) на куті `θ` відносно напрямку падіння променя описується через безрозмірні комплексні амплітудні функції `S_1(θ)` (перпендикулярна поляризація) та `S_2(θ)` (паралельна поляризація):

```
S_1(θ) = ∑_{n=1}^{∞} [ (2n + 1) / (n(n + 1)) ] · [ a_n · π_n(cos θ) + b_n · τ_n(cos θ) ]
S_2(θ) = ∑_{n=1}^{∞} [ (2n + 1) / (n(n + 1)) ] · [ a_n · τ_n(cos θ) + b_n · π_n(cos θ) ]
```

Тут `a_n` та `b_n` — комплексні коефіцієнти розсіювання Мі, які виражаються через функції Ріккаті-Бесселя `ψ_n(z)` та функції Ріккаті-Ханкеля `ξ_n(z)`:

```
a_n = [ m · ψ_n(m·x) · ψ'_n(x) - ψ_n(x) · ψ'_n(m·x) ] / [ m · ψ_n(m·x) · ξ'_n(x) - ξ_n(x) · ψ'_n(m·x) ]
b_n = [ ψ_n(m·x) · ψ'_n(x) - m · ψ_n(x) · ψ'_n(m·x) ] / [ ψ_n(m·x) · ξ'_n(x) - m · ξ_n(x) · ψ'_n(m·x) ]
```

Кутові функції `π_n(cos θ)` та `τ_n(cos θ)` є похідними від приєднаних поліномів Лежандра першого роду `P_n^1(cos θ)`:

```
π_n(cos θ) = P_n^1(cos θ) / sin θ
τ_n(cos θ) = (d / dθ) P_n^1(cos θ)
```

Диференціальний переріз розсіювання неполяризованого лазерного світла в тілесний кут `dΩ = sin θ dθ dφ` дорівнює півсумі квадратів модулів амплітудних функцій:

```
dσ(θ) / dΩ = (1 / (2 · k²)) · ( |S_1(θ)|² + |S_2(θ)|² )
```

Повний оптичний переріз розсіювання `σ_sca` отримується інтегруванням по всій сфері `4π` стерадіан:

```
σ_sca = ∫_{0}^{2π} dφ ∫_{0}^{π} (dσ / dΩ) · sin θ dθ
      = (2 · π / k²) · ∑_{n=1}^{∞} (2n + 1) · ( |a_n|² + |b_n|² )
```

Ефективність розсіювання (фактор ефективності) `Q_sca` пов'язує оптичний переріз із геометричною площею поперечного перерізу сфери `A_geom = π · r_p² = (π · d_p²) / 4`:

```
Q_sca = σ_sca / A_geom = (8 / x²) · ∑_{n=1}^{∞} (2n + 1) · ( |a_n|² + |b_n|² )
```

### 3. Інтеграл збору світлового потоку фотоприймачем

У сенсорах пилу фотодіод розташовано під кутом `θ_0` (типово `θ_0 = 90°` або `θ_0 = 60°`) до осі лазерного пучка. Вхідний зіницявий отвір збиральної лінзи або діафрагми фотоприймача охоплює діапазон полярних кутів `[θ_min, θ_max]` та азимутальних кутів `[-Δφ, +Δφ]`, утворюючи тілесний кут збору `Ω_det`.

Світловий потік `Φ_sca` (у ватах), зібраний фотодіодом під час прольоту однієї частинки через зону вимірювання з інтенсивністю лазерного опромінення `I_0` (Вт/м²):

```
Φ_sca(d_p) = I_0 · ∫_{Ω_det} (dσ(θ, φ, d_p, m) / dΩ) dΩ
           = I_0 · ∫_{-Δφ}^{+Δφ} dφ ∫_{θ_min}^{θ_max} (dσ(θ, d_p, m) / dΩ) · sin θ dθ
```

Піковий фотострум `I_peak`, що генерується PIN-фотодіодом зі спектральною чутливістю `R_pd` (А/Вт, для кремнію на `λ = 650` нм `R_pd ≈ 0.45` А/Вт), та вихідна напруга трансімпедансного підсилювача з коефіцієнтом зворотного зв'язку `R_f` (Ом):

```
I_peak(d_p) = R_pd · Φ_sca(d_p)
V_peak(d_p) = R_f · I_peak(d_p) = R_f · R_pd · I_0 · σ_det(d_p)
```

де `σ_det(d_p) = ∫_{Ω_det} (dσ/dΩ) dΩ` — ефективний апертурний переріз розсіювання, що збирається датчиком.

### 4. Логарифмічно-нормальний розподіл частинок за розмірами

Реальний атмосферний аерозоль є полідисперсним і описується суперпозицією декількох логарифмічно-нормальних мод (мода ядер нуклеації, накопичувальна мода та мода грубодисперсного пилу). Диференціальна числова концентрація `dn(d_p)` частинок у діапазоні діаметрів від `d_p` до `d_p + dd_p`:

```
dn(d_p) / d(ln d_p) = [ N_tot / ( √(2·π) · ln σ_g ) ] · exp( - [ ln(d_p / d_pg) ]² / [ 2 · (ln σ_g)² ] )
```

Параметри розподілу:
- `N_tot` — повна рахункова концентрація частинок (частинок/см³ або частинок/м³);
- `d_pg` — геометричний середній діаметр (медіана рахункового розподілу);
- `σ_g` — геометричне стандартне відхилення (характеризує полідисперсність, `σ_g > 1`).

Перехід від числового розподілу `n(d_p)` до поверхневого `s(d_p)` та об'ємного `v(d_p)` розподілів здійснюється за формулами моментів:

```
ds(d_p) / d(ln d_p) = π · d_p² · [ dn(d_p) / d(ln d_p) ]
dv(d_p) / d(ln d_p) = (π / 6) · d_p³ · [ dn(d_p) / d(ln d_p) ]
```

Для логарифмічно-нормального розподілу середній об'ємний діаметр `d_pv` (діаметр частинки середнього об'єму) виражається через рівняння Гатчінсона:

```
ln d_pv = ln d_pg + 1.5 · (ln σ_g)²
```

### 5. Дискретизація за бінами та інтегрування масової концентрації

Сенсор пилу не вимірює неперервну функцію `n(d_p)`, а квантує амплітуди імпульсів за дискретними порогами компаратора на `K` розмірних інтервалів (бінів): `[d_{0}, d_{1}], [d_{1}, d_{2}], ..., [d_{K-1}, d_{K}]`.

Кількість зареєстрованих імпульсів у `i`-му біні `[d_{i-1}, d_{i}]` за інтервал часу вимірювання `Δt` при об'ємній витраті прокачування повітря `Q_air` (м³/с):

```
N_i = Q_air · Δt · ∫_{d_{i-1}}^{d_{i}} n(d_p) · η_det(d_p) dd_p
```

де `η_det(d_p)` — ефективність детектування каналу (для `d_p < 0.3` мкм `η_det → 0` через шумовий поріг, для `d_p > 0.5` мкм `η_det ≈ 1.0`).

Масова концентрація фракції `PM_x` (де `x = 1.0, 2.5, 10` мкм) визначається сумуванням маси частинок усіх бінів, діаметр яких не перевищує граничний аеродинамічний розмір `d_x`, з урахуванням функції розділення вхідного пробовідбірника `η_cut(d_p, d_x)`:

```
PM_x = ∑_{i=1}^{K_x} ρ_eff · V_i · ( N_i / (Q_air · Δt) )
```

де:
- `V_i` — характеристичний об'єм частинки в `i`-му біні, розрахований за середньокубічним діаметром біна `d_i^*`:
```
d_i^* = [ (d_{i-1}³ + d_{i-1}² · d_i + d_{i-1} · d_i² + d_i³) / 4 ]^(1/3)
V_i = (π / 6) · (d_i^*)^3
```
- `ρ_eff` — калібрувальна ефективна густина речовини аерозолю (для атмосферного міського пилу за стандартом ISO 12103-1 A1 становить `1.65` г/см³, тобто `1.65 · 10¹²` мкг/м³, або `1650` кг/м³).

### 6. Покроковий приклад розрахунку маси PM2.5

Розглянемо практичний випадок: сенсор прокачав об'єм повітря `V_sample = 0.1` л (`10⁻⁴` м³) і налічив у бінах таку кількість частинок:
- Бін 1 (`0.3 – 0.5` мкм, `d_1^* ≈ 0.41` мкм): `N_1 = 12000` частинок;
- Бін 2 (`0.5 – 1.0` мкм, `d_2^* ≈ 0.78` мкм): `N_2 = 2500` частинок;
- Бін 3 (`1.0 – 2.5` мкм, `d_3^* ≈ 1.85` мкм): `N_3 = 300` частинок.

Густина аерозолю прийнята рівною `ρ = 1.65` г/см³ (`1.65 · 10⁻¹²` г/мкм³ = `1.65 · 10⁻⁶` мкг/мкм³).

**Розрахунок масового внеску кожного біна в об'ємі 0.1 л:**

```
V_1 = (π / 6) · (0.41)³
    = 0.5236 · 0.06892                      [формула об'єму сфери]
    = 0.03608 мкм³                          [об'єм однієї частинки біна 1]

m_1_single = V_1 · ρ
           = 0.03608 · (1.65 · 10⁻⁶)        [множення на густину]
           = 5.953 · 10⁻⁸ мкг               [маса однієї частинки біна 1]

M_1_tot = N_1 · m_1_single
        = 12000 · (5.953 · 10⁻⁸)            [сумарна маса біна 1 в 0.1 л]
        = 0.7144 · 10⁻³ мкг                 [маса фракції 0.3-0.5 мкм]

V_2 = (π / 6) · (0.78)³
    = 0.5236 · 0.47455                      [формула об'єму сфери]
    = 0.24847 мкм³                          [об'єм однієї частинки біна 2]

m_2_single = V_2 · ρ
           = 0.24847 · (1.65 · 10⁻⁶)        [множення на густину]
           = 4.0998 · 10⁻⁷ мкг              [маса однієї частинки біна 2]

M_2_tot = N_2 · m_2_single
        = 2500 · (4.0998 · 10⁻⁷)            [сумарна маса біна 2 в 0.1 л]
        = 1.0250 · 10⁻³ мкг                 [маса фракції 0.5-1.0 мкм]

V_3 = (π / 6) · (1.85)³
    = 0.5236 · 6.3316                       [формула об'єму сфери]
    = 3.3152 мкм³                           [об'єм однієї частинки біна 3]

m_3_single = V_3 · ρ
           = 3.3152 · (1.65 · 10⁻⁶)         [множення на густину]
           = 5.4701 · 10⁻⁶ мкг              [маса однієї частинки біна 3]

M_3_tot = N_3 · m_3_single
        = 300 · (5.4701 · 10⁻⁶)             [сумарна маса біна 3 в 0.1 л]
        = 1.6410 · 10⁻³ мкг                 [маса фракції 1.0-2.5 мкм]
```

**Сумарна масова концентрація PM2.5 у перерахунку на 1 м³ повітря (`10000` порцій по 0.1 л):**

```
M_PM25_sample = M_1_tot + M_2_tot + M_3_tot
              = (0.7144 + 1.0250 + 1.6410) · 10⁻³   [додавання внесків бінів]
              = 3.3804 · 10⁻³ мкг                   [маса PM2.5 у 0.1 л]

C_PM25 = M_PM25_sample / V_sample
       = (3.3804 · 10⁻³ мкг) / (10⁻⁴ м³)            [ділення на об'єм проби]
       = 33.804 мкг/м³                              [підсумкова концентрація PM2.5]
```

Цей числовий розрахунок демонструє критичну властивість кубічної залежності маси від діаметра: хоча дрібних часток `0.3 – 0.5` мкм за кількістю у 40 разів більше (`12000` проти `300`), їхній внесок у сумарну масу PM2.5 становить лише `21.1%` (`0.714 · 10⁻³` мкг проти `1.641 · 10⁻³` мкг від великих часток `1.0 – 2.5` мкм).
