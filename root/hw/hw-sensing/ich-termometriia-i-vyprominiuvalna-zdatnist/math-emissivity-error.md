# 🧮 Розрахунок похибки випромінювальної здатності й відбитого фону

Коли безконтактний пірометр вимірює температуру реального об'єкта, обчислювальний тракт перетворює зареєстрований тепловий потік у градуси через закон Стефана–Больцмана, спираючись на задане значення коефіцієнта випромінювальної здатності `ε`. Якщо цей коефіцієнт задано з похибкою або проігноровано відбите випромінювання навколишнього середовища, виміряна температура суттєво відхиляється від істинної. Нижче наведено строге аналітичне виведення радіаційного балансу, формули чутливості вимірювання до варіації `ε`, спектральне інтегрування у смузі 8–14 мкм та метод двоточкового калібрування коефіцієнта випромінювання.

### Енергетичний баланс випромінювання на приймачі сенсора

Розглянемо непрозоре сіре тіло з істинною термодинамічною температурою `T_obj` (у кельвінах) та коефіцієнтом випромінювальної здатності `ε` (`0 < ε ≤ 1`). Згідно із законом Кірхгофа, коефіцієнт поглинання тіла дорівнює коефіцієнту випромінювання (`α = ε`), а коефіцієнт відбиття становить `ρ = 1 − ε`.

Навколишнє середовище має усереднену радіаційну температуру `T_amb`. Повна густина енергетичної світності `E_total`, яка виходить від поверхні тіла в напрямку оптичного вікна сенсора, складається з власного теплового випромінювання та відбитого фонового потоку:

```
E_total = E_emit + E_refl
E_emit  = ε · σ · T_obj⁴            [власне випромінювання поверхні]
E_refl  = (1 − ε) · σ · T_amb⁴      [відбите випромінювання оточення]
```

Сумарна густина випромінювання, що падає на чутливий елемент:

```
E_total = ε · σ · T_obj⁴ + (1 − ε) · σ · T_amb⁴
```

Якщо оптичний термометр калібрований під абсолютно чорне тіло (`ε_cal = 1`) без врахування відбитого фону, він інтерпретує зареєстрований потік `E_total` як еквівалентну радіаційну температуру `T_rad`:

```
E_total = σ · T_rad⁴

σ · T_rad⁴ = ε · σ · T_obj⁴ + (1 − ε) · σ · T_amb⁴

T_rad = (ε · T_obj⁴ + (1 − ε) · T_amb⁴)⁰·²⁵   [вираз радіаційної температури через потік]
```

Якщо ж алгоритм приладу враховує введений користувачем коефіцієнт `ε_set`, але нехтує фоновою температурою (припускаючи `T_amb ≈ 0 K`), він обчислює уявну температуру `T_app`:

```
T_app = (E_total / (ε_set · σ))⁰·²⁵                [означення уявної температури]
      = ((ε · T_obj⁴ + (1 − ε) · T_amb⁴) / ε_set)⁰·²⁵ [підстановка E_total]
```

### Чутливість виміряної температури до похибки коефіцієнта ε

Знайдемо аналітичну чутливість обчисленої температури `T_meas` до вибору випромінювальної здатності `ε` за умови, що відбитим фоном знехтували (`T_meas = (E_total / (ε · σ))⁰·²⁵`):

```
ln(T_meas) = 0.25 · ln(E_total / σ) − 0.25 · ln(ε)   [логарифмування виразу T_meas]

d(ln(T_meas)) / dε = −0.25 / ε                       [похідна натурального логарифма]

(dT_meas / T_meas) / (dε / ε) = −0.25                [перехід до відносних диференціалів]
```

Звідси отримуємо фундаментальне співвідношення відносних похибок для високих температур (`T_obj ≫ T_amb`):

```
ΔT_meas / T_meas ≈ −0.25 · (Δε / ε)                  [відносна похибка температури]
```

Через четвертий степінь у законі Стефана–Больцмана відносна похибка визначення абсолютної температури (у кельвінах) становить приблизно одну четверту від відносної похибки випромінювальної здатності.

Проте абсолютна похибка в градусах Цельсія масштабується абсолютною температурою `T_meas` у кельвінах:

```
ΔT_meas ≈ −(T_meas / (4 · ε)) · Δε                   [абсолютна похибка у кельвінах і градусах]
```

### Диференціальна чутливість з урахуванням відбитого фону

Коли температура фону `T_amb` співмірна з температурою об'єкта `T_obj`, продиференціюємо точний вираз для `T_rad` за параметром `ε`:

```
dT_rad / dε = d/dε [ (ε · T_obj⁴ + (1 − ε) · T_amb⁴)⁰·²⁵ ]                   [диференціювання за ε]
            = 0.25 · (ε · T_obj⁴ + (1 − ε) · T_amb⁴)⁻⁰·⁷⁵ · (T_obj⁴ − T_amb⁴) [ланцюгове правило]
            = (T_obj⁴ − T_amb⁴) / (4 · T_rad³)                               [спрощення через T_rad]
```

Звідси випливають три критичні висновки для практики:

1. **Якщо `T_obj > T_amb`**: похідна `dT_rad / dε > 0`. Заниження коефіцієнта `ε` у розрахунках веде до завищення обчисленої температури `T_obj`, а завищення `ε` — до її заниження.
2. **Якщо `T_obj = T_amb`**: похідна `dT_rad / dε = 0`. Радіаційна температура `T_rad` строго дорівнює `T_amb` незалежно від коефіцієнта `ε`. Тіло в повній ізотермічній порожнині випромінює і відбиває в сумі рівно стільки, скільки абсолютно чорне тіло за тієї ж температури.
3. **Якщо `T_obj < T_amb`**: похідна `dT_rad / dε < 0`. Поверхня холодного тіла відбиває гарячий фон, тому прилад показує завищену температуру, що ближча до фонової, ніж до справжньої температури об'єкта.

### Спектральне інтегрування в смузі LWIR (8–14 мкм)

Закон Стефана–Больцмана `E = σ · T⁴` описує повне випромінювання в усьому нескінченному діапазоні довжин хвиль `0 ≤ λ < ∞`. Проте реальний сенсор містить германієвий фільтр, який пропускає лише хвилі в інтервалі `[λ₁, λ₂] = [8, 14]` мкм.

Потік енергії, що проходить крізь оптичне вікно:

```
E_band(T) = ∫_{λ₁}^{λ₂} E_λ(λ, T) dλ
```

У вузькому діапазоні довжин хвиль залежність енергії від температури часто апроксимують узагальненим степеневим законом:

```
E_band(T) ≈ C · Tⁿ
```

де `n` — ефективний показник степеня, який визначається логарифмічною похідною:

```
n(T) = (T / E_band) · (dE_band / dT)
```

Для широкого діапазону температур значення `n` відрізняється від 4:
- За високих температур (`T > 1000 K`), коли пік випромінювання зміщується далеко ліворуч від вікна 8–14 мкм у короткохвильову зону, `n ≈ 2 .. 3`.
- За кімнатних та помірних температур (`250 K ≤ T ≤ 400 K`), коли пік спектра за законом Віна (`λ_max ≈ 9.7 μm`) розташований прямо всередині вікна 8–14 мкм, ефективний показник становить:
  ```
  n ≈ 4.3 .. 4.8
  ```

Ця відмінність пояснює, чому високоточні цифрові сенсори (як MLX90614) використовують не чистий закон четвертого степеня, а поліноми четвертого або п'ятого порядків з табличними коригувальними коефіцієнтами, отриманими під час заводського калібрування в чорному тілі.

### Двоточковий метод експериментального визначення ε

Якщо коефіцієнт випромінювальної здатності матеріалу невідомий і відсутній у довідкових таблицях, його можна точно виміряти експериментально за допомогою контрольованого нагріву:

1. **Підготовка зразка**: половину досліджуваної поверхні покривають еталонним матеріалом з відомим коефіцієнтом (наприклад, матовою каптоновою стрічкою з `ε_ref = 0.95`).
2. **Нагрів зразка**: зразок прогрівають на нагрівальному столику до стабільної робочої температури `T_obj` (вище кімнатної, наприклад 70 °C).
3. **Вимірювання еталона**: пірометром зчитують температуру еталонної зони. Оскільки `ε_ref` відомий, прилад точно вимірює істинну температуру зразка `T_obj`.
4. **Вимірювання чистої поверхні**: наводять сенсор на чисту поверхню і зчитують сирий радіаційний потік `E_meas` або радіаційну температуру `T_rad`.

Розрахунок шуканого коефіцієнта `ε_sample` з рівняння радіаційного балансу:

```
E_meas = ε_sample · σ · T_obj⁴ + (1 − ε_sample) · σ · T_amb⁴   [базовий баланс]

E_meas − σ · T_amb⁴ = ε_sample · σ · (T_obj⁴ − T_amb⁴)         [перенесення фонового члена]

ε_sample = (E_meas − σ · T_amb⁴) / (σ · (T_obj⁴ − T_amb⁴))     [вираження шуканого коефіцієнта]
         = (T_rad⁴ − T_amb⁴) / (T_obj⁴ − T_amb⁴)               [перехід до радіаційних температур]
```

Цей метод дозволяє визначити `ε` будь-якої складної деталі з похибкою не більше ніж ±0.02.

### Вплив нестабільності температури кристала сенсора (T_die drift)

Оскільки вихідний сигнал термостовпчика пропорційний різниці `(T_obj⁴ − T_die⁴)`, будь-яка неточність у визначенні температури холодних спаїв `T_die` безпосередньо транслюється у похибку розрахунку `T_obj`.

Знайдемо диференціальний зв'язок:

```
d(T_obj⁴) = (1 / ε) · d(T_die⁴)                     [зв'язок радіаційних потоків]

4 · T_obj³ · dT_obj = (1 / ε) · 4 · T_die³ · dT_die [взяття повних диференціалів]

dT_obj / dT_die = (1 / ε) · (T_die / T_obj)³        [чутливість до дрейфу холодного спаю]
```

Розглянемо випадок вимірювання низькоемісійної поверхні (`ε = 0.1`) при `T_obj = 350 K` і `T_die = 300 K`:

```
dT_obj / dT_die = (1 / 0.1) · (300 / 350)³
                = 10 · 0.6297
                ≈ 6.30
```

Похибка вимірювання температури власного кристала всього на `0.5 °C` (наприклад, через нерівномірний нагрів ніжок корпусу TO-39 від сусіднього стабілізатора живлення) викличе похибку визначення температури об'єкта величиною `0.5 · 6.30 = +3.15 °C`!

Саме тому ізотермічний захист корпусу пірометра та прецизійність внутрішнього давача `T_die` мають першочергове значення в апаратній розробці.

### Розрахунковий приклад: нагріта алюмінієва шина

Обчислимо похибку вимірювання температури алюмінієвої силової шини в розподільчому щиті:
- Справжня температура шини: `T_obj = 363.15 K` (90.0 °C).
- Температура навколишнього повітря і стінок щита: `T_amb = 298.15 K` (25.0 °C).
- Реальний коефіцієнт окисленого алюмінію: `ε_real = 0.20`.
- Пірометр налаштовано на стандартний заводський коефіцієнт: `ε_set = 0.95`.

Крок 1. Розрахунок повної густини потоку випромінювання:

```
E_emit = 0.20 · (5.670374 · 10⁻⁸) · 363.15⁴        [власне випромінювання шини]
       = 0.20 · 5.670374 · 10⁻⁸ · 1.7392 · 10¹⁰    [піднесення 363.15 до 4 степеня]
       ≈ 197.23 W/m²                               [множення на ε_real та σ]

E_refl = (1 − 0.20) · (5.670374 · 10⁻⁸) · 298.15⁴  [відбите випромінювання фону]
       = 0.80 · 5.670374 · 10⁻⁸ · 7.9016 · 10⁹     [піднесення 298.15 до 4 степеня]
       ≈ 358.44 W/m²                               [множення на (1 - ε) та σ]

E_total = 197.23 + 358.44 = 555.67 W/m²            [сума власного та відбитого потоків]
```

Зверніть увагу: відбите фонове випромінювання (358.44 W/m²) майже вдвічі перевищує власне випромінювання гарячої шини (197.23 W/m²).

Крок 2. Обчислення температури, яку покаже неналаштований пірометр (`ε_set = 0.95` без врахування фону):

```
T_meas = (555.67 / (0.95 · 5.670374 · 10⁻⁸))⁰·²⁵  [розрахунок за формулою чорного тіла]
       = (555.67 / 5.386855 · 10⁻⁸)⁰·²⁵            [обчислення знаменника ε_set · σ]
       = (1.03153 · 10¹⁰)⁰·²⁵                      [ділення потоку на знаменник]
       ≈ 318.57 K                                  [взяття кореня 4-го степеня]

t_meas = 318.57 − 273.15 = 45.42 °C                [переведення з кельвінів у градуси Цельсія]
```

Результат: замість реальних 90.0 °C прилад показав 45.4 °C. Похибка вимірювання становить `Δt = −44.58 °C`. Недооцінка нагріву майже вдвічі на силовій шині створює пряму загрозу пожежі або аварії через хибний висновок про безпечний тепловий режим обладнання.

Крок 3. Відновлення істинної температури коректною формулою:

```
T_obj = ((E_total − (1 − ε_real) · σ · T_amb⁴) / (ε_real · σ))⁰·²⁵ [точна радіаційна формула]
      = ((555.67 − 358.44) / (0.20 · 5.670374 · 10⁻⁸))⁰·²⁵        [віднімання відбитого фону]
      = (197.23 / 1.134075 · 10⁻⁸)⁰·²⁵                             [ділення власного потоку на ε·σ]
      = (1.7391 · 10¹⁰)⁰·²⁵                                       [підсумковий знаменник під коренем]
      = 363.15 K  (90.0 °C)                                       [точне відновлення температури]
```

Математично точний облік як випромінювальної здатності `ε`, так і відбитої фонової температури `T_amb` повністю компенсує похибку вимірювального тракту.
