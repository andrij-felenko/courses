# 📋 Довідник регістрів та протоколу SMBus для ІЧ-термометрів

Цей довідник містить повний опис низькорівневого інтерфейсу взаємодії, карти регістрів RAM/EEPROM, часових діаграм, захисту від підвисання шини та алгоритму обчислення контрольної суми PEC (Packet Error Code) для інтегрованих цифрових пірометрів сімейства MLX90614. Матеріал необхідний розробникам вбудованого програмного забезпечення для реалізації надійного драйвера зв'язку без сторонніх залежностей.

### Фізичний рівень і протокол зв'язку

Сенсор підтримує інтерфейс SMBus (System Management Bus), електрично сумісний із шиною I2C на швидкостях від 10 до 100 кГц (стандартний режим). За замовчуванням пристрій відповідає на 7-бітну I2C-адресу `0x5A`.

#### Формат транзакцій читання (Read Word)

Читання 16-бітного слова з пам'яті сенсора здійснюється за протоколом SMBus Read Word з обов'язковою або опціональною перевіркою 8-бітного байта PEC (CRC-8):

1. Головний пристрій (Master) генерує стан `START`.
2. Master передає адресу пристрою з бітом запису: `(0x5A << 1) | 0 = 0xB4`. Отримує `ACK` від сенсора.
3. Master передає код команди / адресу регістру (Command Byte). Отримує `ACK`.
4. Master генерує повторний старт `REPEATED START`.
5. Master передає адресу пристрою з бітом читання: `(0x5A << 1) | 1 = 0xB5`. Отримує `ACK`.
6. Сенсор передає молодший байт даних `Data LSB`. Master надсилає `ACK`.
7. Сенсор передає старший байт даних `Data MSB`. Master надсилає `ACK`.
8. Сенсор передає байт контрольної суми `PEC`. Master надсилає `NACK` і генерує `STOP`.

#### Алгоритм розрахунку PEC (CRC-8)

Контрольна сума PEC охоплює всі передані в транзакції байти (включно з адресами та командами). Використовується поліном SMBus `x⁸ + x² + x¹ + 1` (поліноміальне число `0x07` або `0x107`):

```
Поліном:            C(x) = x⁸ + x² + x¹ + 1  (двійкове 100000111_2 = 0x107)
Початкове значення: 0x00
Вхідні дані:        Address_W (0xB4) + Command + Address_R (0xB5) + Data_LSB + Data_MSB
```

Приклад перевірочного розрахунку:
- Зчитування регістру `RAM_TOBJ1` (команда `0x07`).
- Відповідь сенсора: `LSB = 0x56`, `MSB = 0x3A` (що відповідає `0x3A56 = 14934` відліків = `298.68 K` / `25.53 °C`).
- Вхідний потік байтів для CRC-калькулятора: `[ 0xB4, 0x07, 0xB5, 0x56, 0x3A ]`.
- Розраховане значення PEC: `0xD8`.

#### Часові обмеження шини та Clock Stretching

Сенсор використовує апаратне розтягування тактового сигналу (англ. *Clock Stretching*): під час внутрішнього обчислення відліку або доступу до пам'яті сенсор утримує лінію SCL на низькому рівні.
- **Максимальний час розтягування SCL**: до 33 мс під час оновлення відліку DSP. Апаратний I2C-контролер мікроконтролера повинен коректно підтримувати Clock Stretching, інакше виникне помилка тайм-ауту шини.
- **Апаратний таймаут SMBus (Bus Lock Timeout)**: якщо лінія SCL або SDA утримується на низькому рівні довше ніж `t_timeout ≈ 25..35 ms`, внутрішній автомат станів сенсора скидає інтерфейс SMBus у стан очікування (Idle).

#### Процедура відновлення заблокованої шини (Bus Recovery)

Якщо внаслідок збою живлення або скидання мікроконтролера сенсор «завис», утримуючи лінію SDA у низькому стані, мікроконтролер повинен виконати стандартну послідовність відновлення:
1. Перемкнути пін SCL у режим програмного виходу (GPIO Push-Pull або Open-Drain).
2. Згенерувати 9 послідовних тактових імпульсів на лінії SCL (частота 10–50 кГц), поки сенсор не відпустить лінію SDA.
3. Згенерувати стан `START`, а потім стан `STOP` на шині.

### Карта регістрів оперативної пам'яті (RAM)

Область RAM має базовий адресний префікс `0x00..0x1F` (код доступу `0x00 | Addr`). Дані оновлюються внутрішнім процесором DSP сенсора після кожного циклу вимірювання та доступні лише для зчитування.

| Адреса команди | Назва регістру | Опис | Формула перерахунку |
| :--- | :--- | :--- | :--- |
| `0x04` | `RAM_RAW_IR1` | Сирий лінеаризований відлік ІЧ-термостовпчика каналу 1 | 16-бітне знакове ціле (int16_t) |
| `0x05` | `RAM_RAW_IR2` | Сирий лінеаризований відлік ІЧ-термостовпчика каналу 2 | 16-бітне знакове ціле (int16_t) |
| `0x06` | `RAM_TA` | Температура кристала (холодних спаїв) `T_die` | `T_amb [K] = Data · 0.02` |
| `0x07` | `RAM_TOBJ1` | Температура об'єкта в каналі 1 `T_obj1` | `T_obj [K] = Data · 0.02` |
| `0x08` | `RAM_TOBJ2` | Температура об'єкта в каналі 2 (двозонні моделі) | `T_obj2 [K] = Data · 0.02` |

#### Формула перерахунку температури

Значення в регістрах `RAM_TA` та `RAM_TOBJ1` представлені у вигляді 16-бітного беззнакового цілого числа з фіксованою ціною молодшого розряду (LSB), рівною `0.02 K`:

```
T_kelvin = RawData · 0.02 K
T_celsius = T_kelvin − 273.15 °C
```

Якщо старший біт `Bit 15` регістра `RAM_TOBJ1` встановлено в `1`, це сигналізує про помилку вимірювального тракту (переповнення АЦП або вихід за межі каліброваного діапазону температур від −70 до +380 °C).

### Карта енергонезалежної пам'яті (EEPROM)

Область EEPROM розташована за адресами `0x20..0x3F` (код доступу `0x20 | Addr`). Дані конфігурації зчитуються з EEPROM під час увімкнення живлення і визначають поведінку сенсора.

| Адреса команди | Назва поля | Опис конфігураційного параметра |
| :--- | :--- | :--- |
| `0x20` | `EE_TOMIN` | Нижня межа діапазону вимірювання температури об'єкта |
| `0x21` | `EE_TOMAX` | Верхня межа діапазону вимірювання температури об'єкта |
| `0x22` | `EE_PWMCFG` | Конфігурація вихідного ШІМ/термореле (PWM/SDA pin) |
| `0x23` | `EE_TA_RANGE` | Межі температурного діапазону навколишнього середовища |
| `0x24` | `EE_EMISSIVITY` | Апаратний коефіцієнт випромінювальної здатності `ε` |
| `0x25` | `EE_CONFIG1` | Конфігураційний регістр 1 (фільтри IIR/FIR, посилення PGA) |
| `0x2E` | `EE_SMBUS_ADDR` | 7-бітна мережева адреса пристрою на шині SMBus / I2C |
| `0x3C..0x3F` | `EE_ID` | 64-бітний унікальний серійний номер сенсора |

#### Регістр випромінювальної здатності (0x24)

Апаратний коефіцієнт `ε` зберігається як 16-бітне ціле число:

```
EEPROM_Value = round(ε · 65535)
ε = EEPROM_Value / 65535.0
```

Значення `0xFFFF` (65535) відповідає `ε = 1.000` (абсолютно чорне тіло). Заводське значення за замовчуванням становить `0xFFFF` або `0xF332` (`ε ≈ 0.95`).

#### Повний бітовий розбір регістра EE_CONFIG1 (0x25)

| Біти | Назва поля | Опис та значення |
| :--- | :--- | :--- |
| `15:14` | `RESERVED` | Зарезервовано виробником, не змінювати. |
| `13:11` | `GAIN[2:0]` | Коефіцієнт підсилення аналогового підсилювача PGA: `000` = 1×, `001` = 3×, `010` = 6×, `011` = 12.5×, `100` = 25×, `101` = 50×, `110` = 100× (за замовчуванням `100` = 25×). |
| `10:8` | `FIR[2:0]` | Довжина усереднення цифрового FIR-фільтра: `100` = 8 відліків, `101` = 16 відліків, `110` = 32 відліки, `111` = 64 відліки. Більша довжина знижує шуми, але збільшує час встановлення. |
| `7:4` | `RESERVED` | Зарезервовано. |
| `3` | `DUAL_ZONE` | `0` = одноканальний сенсор (`T_obj1`), `1` = двоканальний сенсор (`T_obj1` + `T_obj2`). |
| `2:0` | `IIR[2:0]` | Коефіцієнт цифрового фільтра нескінченної імпульсної характеристики (IIR): `100` = 100% (IIR вимкнено, миттєва реакція), `101` = 80%, `110` = 67%, `111` = 57%, `000` = 50% (максимальне згладжування шумів, час встановлення ~1.5 с). |

#### Конфігурація ШІМ та режиму термореле (EE_PWMCFG, 0x22)

Сенсор здатний працювати як автономне апаратне термореле без зовнішнього мікроконтролера. Вивід SDA при цьому перемикається в режим двотактного або відкритого стоку ШІМ:
- **Біт 0 (`PWM_EN`)**: `1` = увімкнути режим ШІМ/термостата на контакті SDA.
- **Біт 1 (`PWM_MODE`)**: `0` = аналоговий ШІМ з коефіцієнтом заповнення, пропорційним температурі; `1` = порогове термореле (компаратор з гістерезисом).
- **Біти 3:2 (`PWM_CLK`)**: тактова частота вихідного ШІМ (від 0.125 до 2 кГц).
- **Регістри `EE_TOMIN` (0x20) та `EE_TOMAX` (0x21)**: задають нижній і верхній пороги температури для формування сигналу тривоги або масштабування 0–100% ШІМ.

### Режим зниженого енергоспоживання (Sleep Mode)

Для батарейних пристроїв сенсор підтримує перехід у глибокий сон зі споживанням струму менше ніж `2.5 μA`:

1. **Команда входу в сон**:
   Master надсилає транзакцію запису з кодом команди `0xFF` та валідним байтом PEC (`0xE8` для базової адреси `0x5A`):
   ```
   [START] -> [0xB4] -> [0xFF] -> [0xE8] -> [STOP]
   ```
2. **Процедура пробудження (Wake-up)**:
   Для відновлення роботи головний пристрій повинен примусово притиснути лінію SCL до землі (Low) на час не менше ніж `t_wake ≥ 33 ms`, а потім повернути лінію в високий стан (High). Після витримки паузи 150 мс сенсор повністю готовий до нових транзакцій.

### Процедура перезапису параметрів EEPROM

Пам'ять EEPROM вимагає спеціальної послідовності дій для захисту від випадкового пошкодження заводського калібрування:

1. **Стирання комірки**: Master записує в цільовий регістр EEPROM значення `0x0000` з коректним байтом PEC.
2. **Пауза на стирання**: Затримка не менше ніж 10 мс (`t_erase`).
3. **Запис нового значення**: Master записує нове 16-бітне слово конфігурації з коректним байтом PEC.
4. **Пауза на програмування**: Затримка не менше ніж 10 мс (`t_write`).
5. **Перезавантаження сенсора**: Для активації нових параметрів необхідно вимкнути й увімкнути живлення пристрою (Power-On Reset).
