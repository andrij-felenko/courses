Коли в оптичному локаторі або волоконно-оптичній лінії зв'язку відбитий оптичний сигнал слабшає до одиниць чи десятків фотонів на імпульс, звичайний PIN-фотодіод виявляється безсилим: корисний фотострум у частки пікоампера миттєво тоне в тепловому шумі Джонсона трансімпедансного підсилювача та дробовому шумі вхідного каскаду. Щоб витягти сигнал із пікосекундною часовою точністю без охолодження приймача рідким азотом, первинне підсилення заряду необхідно здіснити безпосередньо всередині самого напівпровідникового кристала ще до того, як сигнал зустрінеться з шумами зовнішніх провідників і мікросхем.

Для розв'язання цієї задачі зворотну напругу зсуву фотодіода піднімають до значень, близьких або навіть вищих за напругу електричного пробою. У надсильному внутрішньому електричному полі p-n переходу виникає явище лавинного множення носіїв: фотогенерований електрон розганяється до швидкостей, достатніх для вибивання нових пар «електрон-дірка» з кристалічної ґратки. Залежно від прикладеної напруги прилад працює або як лінійний аналоговий підсилювач струму — лавинний фотодіод (Avalanche Photodiode, APD), або як надчутливий цифровий тригер одиночних квантів світла — однофотонний лавинний діод (Single-Photon Avalanche Diode, SPAD) у режимі Гейгера.

![Мікроскопічний механізм ударної іонізації в сильному полі](/root/hw/hw-sensing/avalanche-photodiode/img/impact-ionization-mechanism.svg)
*Мікроскопічний процес лавинного множення в збідненій області p-n переходу. Первинний електрон під дією сильного електричного поля E розганяється, перевищує поріг ударної іонізації Eth та розбиває зв'язок ґратки, породжуючи вторинну пару. Вторинні електрони дрейфують до катода, продовжуючи ланцюгову реакцію, а дірки дрейфують до анода.*

## 1. Фізичний механізм ударної іонізації та лавинного множення

В основі роботи лавинних напівпровідникових детекторів лежить процес ударної іонізації (англ. *impact ionization*, від лат. *impactum* — зіткнення). Якщо до p-n переходу прикласти зворотну напругу від кількох десятків до кількох сотень вольт (зазвичай 50–200 В для кремнієвих APD), у збідненій області формується локальне електричне поле з напруженістю `E > 3·10⁵ В/см` (понад 30 кВ/мм).

Коли падаючий квант світла поглинається у збідненій зоні, він генерує первинну пару носіїв заряду: електрон і дірку. Сильне електричне поле миттєво підхоплює первинний електрон і прискорює його в напрямку катода. На довжині вільного пробігу електрон безперервно стикається з фононами (коливаннями кристалічної ґратки), втрачаючи частину енергії, але завдяки колосальній силі поля `F = q · E` на кожному мікроні шляху він накопичує кінетичну енергію `E_k`.

Щойно кінетична енергія електрона досягає порогового значення ударної іонізації `E_th`, чергове зіткнення з атомом кристалічної ґратки викликає вибивання електрона з валентної зони в зону провідності:

```
E_th ≈ 1.5 · E_g     [для прямозонного розсіювання в кремнії]
E_g ≈ 1.12 еВ        [ширина забороненої зони кремнію при 300 K]
E_th ≈ 1.7 еВ        [порогова кінетична енергія електрона для іонізації Si]
```

Внаслідок одного такого зіткнення замість одного первинного електрона з'являються три вільні носії: два електрони в зоні провідності та одна вільна дірка у валентній зоні (`e⁻ → 2e⁻ + h⁺`). Обидва вторинні електрони продовжують розганятися полем до катода, а вторинна дірка розганяється у протилежний бік — до анода. Якщо довжина збідненої області достатня, кожен із нових носіїв здатний знову розігнатися до енергії `E_th` і породити наступне покоління пар. Виникає самопідтримувана ланцюгова реакція лавинного розмноження заряду.

### Коефіцієнти ударної іонізації та фактор асиметрії k

Ймовірність того, що носій заряду здійснить акт ударної іонізації на одиниці довжини свого шляху [см⁻¹], описується коефіцієнтом іонізації. Для електронів цей коефіцієнт позначають `α(E)`, для дірок — `β(E)`. Залежність коефіцієнтів від напруженості поля підпорядковується закону Чайновета (Chynoweth law):

```
α(E) = a_n · e^(-b_n / E)
β(E) = a_p · e^(-b_p / E)

a_n, a_p     [матеріальні константи насичення, см⁻¹]
b_n, b_p     [критичні напруженості поля іонізації, В/см]
```

Для створення якісного лавинного детектора вирішальне значення має фактор іонізаційної асиметрії `k = β / α` (відношення здатності дірок іонізувати ґратку до здатності електронів):

```
Кремній (Si):            k ≈ 0.02 .. 0.05    [електрони іонізують у 20–50 разів сильніше за дірки]
Германій (Ge):           k ≈ 0.5 .. 1.0      [електрони та дірки іонізують майже однаково]
Фосфід індію (InP):      k ≈ 0.4 .. 0.6      [висока діркова іонізація, сильний зворотний зв'язок]
```

Якщо `k ≈ 1`, дірки, що рухаються назад до анода, інтенсивно породжують нові електрони, які знову летять до катода. Лавина перетворюється на неконтрольований шумний процес із гігантською тривалістю та нестабільністю. Навпаки, при малому `k << 1` (як у кремнії) лавина розвивається майже суто в один бік: первинний електрон летить до катода, породжуючи лавину, а дірки повертаються до анода, практично не створюючи вторинних іонізацій. Це робить кремній найкращим напівпровідниковим матеріалом для малошумних APD.

### Коефіцієнт підсилення M та емпірична формула Міллера

Якщо зворотна напруга `V_R` нижча за напругу лавинного пробою `V_BR`, лавина є згасаючою: потік носіїв збільшується у фіксовану скінченну кількість разів `M`. Середній вихідний фотострум дорівнює добутку первинного фотоструму `I_ph0` на коефіцієнт підсилення `M`:

```
I_out = M · I_ph0

M = 1 / [1 - (V_R / V_BR)ⁿ]       [емпірична формула Міллера]

V_R      [прикладена зворотна напруга зсуву, В]
V_BR     [напруга лавинного пробою p-n переходу, В]
n        [показник степеня Міллера, для кремнію n ≈ 2..4]
```

У лінійних APD робочу напругу обирають на рівні `0.8..0.98 · V_BR`, що забезпечує стабільний внутрішній коефіцієнт множення `M` від 10 до кількох сотень (у спеціальних високовольтних структурах — до 1000).

```
V_BR = 100.0 В, n = 3.0:
V_R = 90.0 В  →  M = 1 / (1 - (90/100)³) = 1 / (1 - 0.729) = 1 / 0.271 ≈ 3.69
V_R = 98.0 В  →  M = 1 / (1 - (98/100)³) = 1 / (1 - 0.941) = 1 / 0.059 ≈ 16.9
V_R = 99.5 В  →  M = 1 / (1 - (99.5/100)³) = 1 / (1 - 0.985) = 1 / 0.015 ≈ 66.7
```

### Шум лавинного множення та фактор Макінтайра F(M)

Оскільки процес зіткнення електронів з атомами є випадковим, кожен окремий первинний фотоелектрон породжує випадкову кількість вторинних частинок. Флуктуації коефіцієнта підсилення призводять до виникнення надлишкового шуму множення (Excess Noise).

Спектральна густина дробового шуму APD описується формулою Макінтайра, в якій надлишковий шум враховується фактором `F(M)`:

```
S_i = 2 · q · I_ph0 · M² · F(M)

F(M) = k · M + (1 - k) · (2 - 1 / M)

q        [елементарний заряд, ≈ 1.602 × 10⁻¹⁹ Кл]
k        [фактор асиметрії іонізації: k = β / α]
M        [середній коефіцієнт лавинного підсилення]
```

Повний математичний вивід інтегральних рівнянь лавинного множення, граничних умов та формули Макінтайра наведено в окремому розборі: [Виведення формули надлишкового шуму Макінтайра та статистики мертвого часу](root:hw-sensing/avalanche-photodiode/math-excess-noise.md).

Хронологію експериментального відкриття ударної іонізації та розвитку теоретичних моделей лавинних діодів розкрито у матеріалі: [Історія відкриття лавинного ефекту та еволюції SPAD](root:hw-sensing/avalanche-photodiode/hist-apd-spad.md).

Якщо матеріал має `k ≈ 1` (германій), то `F(M) ≈ M`, тобто шум зростає як `M³`, що миттєво руйнує відношення сигнал/шум (SNR) при збільшенні напруги. У кремнієвому APD з `k = 0.02` при `M = 50` фактор шуму становить лише `F(50) = 0.02 · 50 + 0.98 · (2 - 0.02) = 1.0 + 1.94 = 2.94`. Це означає, що внутрішнє підсилення в 50 разів додає до шуму струму лише фактор `√2.94 ≈ 1.71` порівняно з ідеальним безшумним підсилювачем.

![Порівняння лінійного режиму APD та режиму Гейгера](/root/hw/hw-sensing/avalanche-photodiode/img/linear-vs-geiger-mode.svg)
*Вольт-амперна характеристика зворотно зміщеного фотодіода. До напруги пробою V_BR прилад працює в лінійному режимі (APD): вихідний струм пропорційний світловому потоку з коефіцієнтом M = 10..500. При напрузі вище пробою (V_BR + V_ex) діод переходить у режим Гейгера (SPAD): одиничний фотон викликає лавинний пробій струмом у кілька міліампер.*

## 2. Лінійний режим APD проти режиму Гейгера (SPAD)

Залежно від величини прикладеної зворотної напруги відносно критичної напруги пробою `V_BR`, лавинні фотодіоди ділять на два принципово різні класи за режимом роботи.

| Характеристика | Лінійний режим (Linear APD) | Режим Гейгера (Geiger-Mode SPAD) |
|---|---|---|
| **Зворотна напруга `V_R`** | Нижче пробою: `V_R < V_BR` (зазвичай `0.8..0.98 · V_BR`) | Вище пробою: `V_R = V_BR + V_ex` (`V_ex = 2..5 В`) |
| **Коефіцієнт підсилення `M`** | Скінченний аналоговий: `M = 10..500` (до 1000) | Нескінченний (самопідтримуваний розряд): `M → ∞` |
| **Тип вихідного сигналу** | Неперервний аналоговий струм `I_out = M · I_ph0` | Дискретний цифровий імпульс фіксованої амплітуди |
| **Мінімальний поріг чутливості** | 100–1000 фотонів на імпульс (обмежено шумом `F(M)`) | Одиночний квант світла (Single Photon, 1 фотон) |
| **Збереження форми імпульсу** | Зберігає часовий профіль та амплітуду світлового променя | Втрачає амплітуду (лише точна часова мітка приходу) |
| **Схема включення** | Діод + трансімпедансний підсилювач (TIA) | Діод + схема гасіння лавини (Quenching Circuit) |
| **Основні сфери застосування** | Оптичний зв'язок (10/40 Гбіт/с), аналогові лідари | Квантова оптика, dToF далекоміри, TCSPC мікроскопія |

### Робота в лінійному режимі (Linear Mode APD)

У лінійному режимі напруга зміщення утримується на кілька вольт нижче `V_BR`. Оскільки середнє число породжених носіїв є скінченним, кожен інжектований фотоелектрон породжує обмежений згусток із `M` вторинних електронів, після чого лавина самостійно згасає за пікосекунди, коли всі носії досягають контактів.

Завдяки цьому лінійний APD працює як пропорційний перетворювач: якщо світловий потік збільшився вдвічі, вихідний струм також зростає рівно вдвічі. Це дозволяє детектувати складні амплітудно-модульовані оптичні сигнали (наприклад, QAM або PAM-4 у волоконно-оптичних магістралях) та вимірювати форму відбитого лазерного імпульсу.

Головна технічна складність лінійного APD — екстремальна температурна залежність напруги пробою:

```
V_BR(T) = V_BR(T_0) · [1 + β_T · (T - T_0)]

β_T ≈ 0.1 .. 1.5 В/°C     [температурний коефіцієнт напруги пробою]
```

Зі зростанням температури амплітуда коливань атомної ґратки збільшується, довжина вільного пробігу електронів скорочується, і для набору енергії іонізації `E_th` потрібне сильніше поле (`V_BR` зростає). Якщо напруга живлення `V_R` фіксована, нагрів кристала на 10 °C різко знижує коефіцієнт `M` у кілька разів. Тому високоточні модулі APD обов'язково містять термокомпенсовані джерела високої напруги або термоелектричні охолоджувачі Пельтьє.

### Робота в режимі Гейгера (Single-Photon Avalanche Diode, SPAD)

Якщо зворотну напругу підняти вище порогу пробою на величину надлишкового зсуву `V_ex` (Overbias, зазвичай 2–5 В):

```
V_bias = V_BR + V_ex
```

напруженість електричного поля всередині збідненої області стає надкритичною (`E > 5·10⁵ В/см`). У такому стані діод перебуває в метастабільному квантовому рівноважному стані: струм через прилад не тече, оскільки у збідненій зоні немає вільних носіїв заряду.

Але щойно в активну область потрапляє хоча б один фотон і вибиває первинний електрон (або носій виникає внаслідок теплової флуктуації), цей електрон розганяється полем і запускає лавину. Оскільки ймовірність іонізації настільки висока, що кожне покоління частинок породжує більше носіїв, ніж попереднє, лавина не згасає.

Протягом 100–300 пікосекунд струм через мікроскопічний p-n перехід площею в кілька сотень квадратних мікрометрів лавиноподібно наростає від нуля до макроскопічного значення:

```
I_avalanche ≈ V_ex / R_d ≈ 2 В / 1 кОм = 2 мА
```

Струм у кілька міліампер еквівалентний потоку понад `10¹⁶` електронів на секунду. Фактично один єдиний фотон відкриває макроскопічний струмовий вентиль, формуючи перепад напруги амплітудою в кілька вольт. SPAD перетворює квантову подію (поглинання фотона) на стандартний цифровий CMOS-імпульс без використання проміжних аналогових підсилювачів.

### Квантова ефективність детектування фотонів (PDE)

Імовірність того, що падаючий на SPAD фотон викличе вихідний цифровий імпульс, називається ефективністю детектування фотонів (Photon Detection Efficiency, PDE):

```
PDE(λ, V_ex) = QE(λ) · P_trigger(V_ex) · FF

QE(λ)            [квантовий вихід поглинання: частка фотонів, що поглинулися у збідненій зоні]
P_trigger(V_ex)  [ймовірність того, що народжений носій успішно запустить лавину]
FF               [коефіцієнт заповнення пікселя / Fill Factor: частка активної площі до повної площі]
```

Ймовірність запуску лавини `P_trigger` зростає зі збільшенням надлишкової напруги `V_ex`, досягаючи 40–80% при `V_ex = 3..5 В`. Сумарна ефективність `PDE` для кремнієвих SPAD становить 30–60% у видимому діапазоні (500–700 нм) та спадає до 5–15% у ближньому ІЧ-діапазоні (850–940 нм через малий коефіцієнт поглинання кремнію).

![Схеми гасіння лавини SPAD](/root/hw/hw-sensing/avalanche-photodiode/img/quenching-circuits.svg)
*Порівняння схем гасіння лавини SPAD. Ліворуч: пасивне гасіння через баластний резистор Rq; тривалий експоненційний перезаряд ємності Cd створює мертвий час t_dead ≈ 50..200 нс. Праворуч: активне гасіння (AQC) швидким компаратором і FET-ключами; форсоване скидання та перезаряд скорочують мертвий час до 5..20 нс.*

## 3. Механізми гасіння лавини (Quenching) та відновлення

Головна фізична особливість режиму Гейгера полягає в тому, що після початку лавини струм через SPAD не згасає сам по собі: пробій підтримує сам себе нескінченно довго. Якщо не втрутитися ззовні, струм у кілька міліампер за частки мікросекунди перегріє і незворотно спалить мікроскопічний p-n перехід діода.

Щоб зупинити лавину, струм через перехід необхідно примусово зменшити нижче струму фіксації (latching current `I_latch ≈ 50..100 мкА`). Цей процес називається гасінням лавини (англ. *quenching*). Після гасіння напругу на діоді необхідно відновити назад до рівня `V_BR + V_ex`, щоб підготувати його до зустрічі наступного фотона.

### Пасивне гасіння (Passive Quenching)

Найпростіший спосіб гасіння — послідовне включення високоомного баластного резистора `R_q = 100..500 кОм` між джерелом живлення `V_bias` та анодом SPAD.

1. **Стан очікування:** Струм через SPAD відсутній. Напруга на ємності переходу `C_d` (зазвичай 10–50 фФ) дорівнює повній напрузі живлення `V_bias = V_BR + V_ex`.
2. **Спалах лавини:** Фотон ініціює пробій. Діод миттєво відкривається як малий опір `R_d ≈ 500..1000 Ом`. Власна ємність діода `C_d` починає стрімко розряджатися через власний опір `R_d` з постійною часу `τ_discharge = R_d · C_d ≈ 1000 Ом · 20 фФ = 20 пс`.
3. **Згасання:** У міру розряду ємності напруга на переході діода падає до напруги пробою `V_BR`. Оскільки зовнішнє живлення підведене через гігантський резистор `R_q`, струм від джерела обмежений величиною `I_ext = V_ex / R_q ≈ 3 В / 300 кОм = 10 мкА`, що значно менше струму фіксації `I_latch ≈ 100 мкА`. Лавина втрачає підживлення і гасне.
4. **Повільний перезаряд:** Після згасання лавини ємність `C_d` починає повільно заряджатися від джерела живлення через резистор `R_q` з постійною часу:

```
τ_reset = R_q · C_d ≈ 300 кОм · 20 фФ = 6 нс
```

Повне відновлення напруги до 99% робочого рівня вимагає часу `t_dead ≈ 3..4 · τ_reset ≈ 20..100 нс`.

Головний недолік пасивного гасіння — плавний експоненційний підйом напруги. Під час відновлення напруга на діоді вже вища за `V_BR`, але ще не досягла `V_BR + V_ex`. Якщо фотон прийде в цей момент, він викличе слабку лавину з нестабільною затримкою спрацьовування, що різко погіршує часову роздільну здатність сенсора.

### Активне гасіння (Active Quenching Circuit, AQC)

Для усунення недоліків пасивного гасіння професор Серджіо Кова запропонував схему активного гасіння (Active Quenching Circuit, AQC). Сучасні матриці SPAD інтегрують AQC безпосередньо в кожен піксель за технологією CMOS.

Схема AQC містить надшвидкий дискримінатор напруги (компаратор), блок логіки та пару силових польових транзисторів (FET):

1. **Детекція:** Щойно струм лавини починає розряджати ємність діода, напруга на виході зміщується на кілька сотень мілівольт. Швидкий компаратор детектує перепад за 100–300 пікосекунд і видає цифровий строб.
2. **Форсоване гасіння:** Компаратор вмикає ключ гасіння (Quench FET), який миттєво закорочує діод або прикладає до нього зустрічну напругу, примусово скидаючи напругу на переході нижче `V_BR` за частки наносекунди.
3. **Контрольована пауза (Hold Time):** Логічний таймер утримує діод у вимкненому стані протягом фіксованого мертвого часу `t_dead` (зазвичай 5–20 нс), щоб усі захоплені на дефектах носії встигли рекомбінувати.
4. **Форсований перезаряд (Active Reset):** Таймер вмикає ключ перезаряду (Reset FET) із низьким опором каналу (`R_on ≈ 50..100 Ом`), який форсовано заряджає ємність `C_d` назад до `V_BR + V_ex` за 200–500 пікосекунд.

AQC формує ідеальний прямокутний профіль чутливості діода, скорочує мертвий час до кількох наносекунд і усуває джиттер часових міток.

### Паразитарні шуми та крайові ефекти SPAD

Незважаючи на здатність реєструвати одиночні кванти, реальний SPAD стикається з трьома фундаментальними паразитними явищами:

1. **Темновий темп рахунку (Dark Count Rate, DCR):** Спрацьовування діода за повної темряви внаслідок теплової генерації Шоклі — Ріда — Холла (SRH) або прямого міжзонного тунелювання носіїв у сильному полі (Band-to-Band Tunneling, BBT). Для якісних кремнієвих SPAD темп DCR становить від 10 Гц до кількох кілогерц на піксель при кімнатній температурі.
2. **Післяімпульси (Afterpulsing):** Під час проходження лавини через кристал через перехід протікає понад `10⁶` носіїв. Частина з них захоплюється глибокими енергетичними пастками (дефектами ґратки або домішками важких металів). Через деякий час (від одиниць наносекунд до мікросекунд) носій випадково вивільняється з пастки. Якщо діод на цей момент уже відновив напругу `V_bias`, цей носій запускає вторинну хибну лавину. Ймовірність післяімпульсів зменшують збільшенням часу активного мертвого часу `t_dead` та мінімізацією заряду лавини.
3. **Оптичні перехресні перешкоди (Optical Crosstalk):** Під час лавинного розряду носії з високою кінетичною енергією гальмуються й рекомбінують, випромінюючи слабке оптичне світіння (гальмівне випромінювання та рекомбінаційні фотони: приблизно 1 фотон на `10⁵` електронів лавини). Ці вторинні фотони поширюються крізь кремнієву підкладку й потрапляють у сусідні SPAD-пікселі матриці, викликаючи їхнє одночасне помилкове спрацьовування. Для придушення кростоку між пікселями протравлюють глибокі ізолюючі траншеї (Deep Trench Isolation, DTI), заповнені світлопоглинаючим діелектриком або металом (вольфрамом).

> 🔧 **Навіщо це.**
> У лазерних далекомірах смартфонів та автомобільних LiDAR сонячне засвітлення створює на матриці SPAD фоновий потік у мільйони паразитних фотонів на секунду. Якщо час мертвої зони становить 100 нс (пасивне гасіння), піксель буде постійно заблокований сонячним світлом. Перехід на інтегроване активне гасіння AQC із часом `t_dead = 5..10 нс` та застосування траншей DTI дозволяє сенсору працювати при прямому сонячному світлі 100 клк, надійно виділяючи слабке відлуння від наносекундного лазерного імпульсу.

![Архітектура dToF LiDAR та гістограма TCSPC](/root/hw/hw-sensing/avalanche-photodiode/img/dtof-tcspc-pipeline.svg)

## 4. Детектування одиночних фотонів для dToF далекомірів

Вимірювання дистанції за часом прольоту світла (Time-of-Flight, ToF) реалізують за двома технологіями: непрямий ToF (iToF, вимірювання фазового зсуву модульованого світла на звичайних CMOS-матрицях) та прямий ToF (dToF, вимірювання фізичного часу прольоту короткого світлового імпульсу `t_flight = 2 · d / c`).

Завдяки пікосекундній часовій роздільній здатності та одиночнофотонній чутливості саме матриці SPAD є базовим елементом систем dToF (наприклад, у сенсорах STMicroelectronics VL53L0X / VL53L1CX / VL53L5CX та сенсорах Apple LiDAR).

### Принцип часово-корельованої лічби фотонів (TCSPC)

Швидкість світла у повітрі становить приблизно `c ≈ 30 см/нс`. Зміна відстані до об'єкта на 1.5 мм відповідає зміні часу прольоту лазерного променя туди й назад лише на `Δt = 10 пс` (10 трильйонних часток секунди):

```
Δt = (2 · Δd) / c = (2 · 0.0015 м) / (3 · 10⁸ м/с) = 10⁻¹¹ с = 10 пс
```

Один одиночний виміряний фотон не дозволяє визначити дистанцію з високою точністю через квантовий джиттер лавини (часову невизначеність спрацьовування SPAD, яка становить 50–150 пс) та випадковий шум фону.

Щоб досягти міліметрової точності в умовах яскравого денного світла, використовують метод часово-корельованої лічби одиночних фотонів (Time-Correlated Single-Photon Counting, TCSPC):

1. Лазерний діод із вертикальним резонатором (VCSEL, зазвичай на довжині хвилі 940 нм, де сонячний спектр має природний провал поглинання водяною парою атмосфери) випромінює серію ультракоротких імпульсів тривалістю 1–2 нс із високою частотою повторення (10–50 МГц).
2. Одночасно з пострілом лазера запускається внутрішній високоточний цифровий вимірювач часу — перетворювач час-цифра (Time-to-Digital Converter, TDC).
3. При спрацьовуванні SPAD-пікселя TDC фіксує часовий інтервал `t_arrival` між стартом лазера та приходом фотона з дискретністю біна `Δt_bin = 20..100 пс`.
4. Номер біна `k = floor(t_arrival / Δt_bin)` передається в цифровий сигнальний процесор (DSP), де інкрементується відповідна комірка пам'яті часової гістограми: `Histogram[k]++`.
5. За час кадру (наприклад, 10–30 мс) система здійснює від 100 000 до 1 000 000 лазерних пострілів.

### Накопичення гістограми та виділення сигналу з шуму

Фонові фотони сонячного світла та теплові темнові імпульси DCR надходять у випадкові некорельовані моменти часу. На часовій гістограмі вони утворюють рівномірний плоский пуассонівський шумовий рівень (Noise Floor).

Навпаки, корисні фотони лазерного відлуння завжди приходять через строго фіксований час затримки `t_target = 2 · d / c` після стартового імпульсу. Тому на гістограмі в діапазоні кількох сусідніх бінів виростає гострий резонансний пік сигналу.

Після накопичення гістограми цифровий процесор виконує:
- Оцінку рівня постійного фонового шуму за крайніми бінами та його віднімання;
- Згортку гістограми з апаратним профілем лазерного імпульсу (Matched Filtering) для пошуку точного положення піка;
- Суб-біновий розрахунок центроїда (центру мас) піка, що дозволяє визначити часову мітку з точністю до одиниць пікосекунд і отримати похибку вимірювання відстані менше 1 мм.

### Ефект нагромадження (Pile-Up Effect) та його компенсація

Якщо відбитий сигнал занадто сильний (наприклад, при роботі з дзеркальною або близько розташованою ціллю), виникає спотворення нагромадження (Pile-Up Distortion).

Оскільки SPAD реєструє лише перший фотон, що прийшов у поточному лазерному циклі, і блокується на час мертвої зони `t_dead`, фотони, що приходять на задньому фронті оптичного імпульсу, систематично втрачаються. Це призводить до штучного зсуву вершини піка вліво (в бік коротших дистанцій).

Для відновлення справжньої форми імпульсу DSP далекоміра застосовує статистичну поправку Коутса:

```
N_corr[i] = -N_total · ln(1 - N_meas[i] / (N_total - ∑_{j=0}^{i-1} N_meas[j]))

N_total      [повне число лазерних пострілів за період вимірювання]
N_meas[i]    [виміряна кількість подій у біні i]
N_corr[i]    [істинна розрахована кількість фотонів у біні i]
```

## 5. Практична реалізація: моделювання лавини та обробка гістограми dToF

Нижче наведено закінчений програмний модуль на мовах C та C++, що реалізує повний конвеєр обробки сирої часової гістограми dToF далекоміра: пуассонівську компенсацію нагромадження (Pile-Up Correction), віднімання сонячного фону, узгоджену фільтрацію та суб-біновий розрахунок дистанції методом центроїда.

:::tabs
```c
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>
#include <math.h>

#define DTOF_HIST_BINS      64
#define SPEED_OF_LIGHT_M_S  299792458.0

typedef struct {
    double bin_width_ps;       /* часова ширина одного біна гістограми, пс */
    uint32_t total_cycles;     /* загальна кількість лазерних пострілів */
    double distance_m;         /* обчислена відстань до об'єкта, метри */
    double confidence;         /* коефіцієнт достовірності / відношення сигнал/шум */
    bool valid;                /* прапорець успішного виявлення піка */
} dtof_result_t;

/* Обробка сирої гістограми dToF: компенсація нагромадження, фільтрація та центроїд */
dtof_result_t process_dtof_histogram(const uint32_t *raw_hist, size_t num_bins,
                                    double bin_width_ps, uint32_t total_cycles) {
    dtof_result_t res;
    res.bin_width_ps = bin_width_ps;
    res.total_cycles = total_cycles;
    res.distance_m = 0.0;
    res.confidence = 0.0;
    res.valid = false;

    if (num_bins == 0 || num_bins > DTOF_HIST_BINS || total_cycles == 0) {
        return res;
    }

    double corr_hist[DTOF_HIST_BINS];
    uint32_t cumulative_events = 0;

    /* 1. Статистична пуассонівська корекція нагромадження (Coates correction) */
    for (size_t i = 0; i < num_bins; ++i) {
        int64_t available_cycles = (int64_t)total_cycles - (int64_t)cumulative_events;
        if (available_cycles <= (int64_t)raw_hist[i] || available_cycles <= 0) {
            corr_hist[i] = (double)raw_hist[i];
        } else {
            double p = (double)raw_hist[i] / (double)available_cycles;
            if (p >= 0.999) p = 0.999;
            corr_hist[i] = -((double)total_cycles) * log(1.0 - p);
        }
        cumulative_events += raw_hist[i];
    }

    /* 2. Оцінка рівня сонячного шуму (за першими та останніми 8 бінами) */
    double noise_sum = 0.0;
    size_t noise_count = 0;
    for (size_t i = 0; i < 8 && i < num_bins; ++i) {
        noise_sum += corr_hist[i];
        noise_count++;
    }
    for (size_t i = (num_bins > 8 ? num_bins - 8 : 0); i < num_bins; ++i) {
        noise_sum += corr_hist[i];
        noise_count++;
    }
    double noise_floor = (noise_count > 0) ? (noise_sum / (double)noise_count) : 0.0;

    /* 3. Віднімання фону та пошук індексу максимуму піка */
    double max_signal = 0.0;
    size_t peak_idx = 0;

    for (size_t i = 0; i < num_bins; ++i) {
        corr_hist[i] = fmax(0.0, corr_hist[i] - noise_floor);
        if (corr_hist[i] > max_signal) {
            max_signal = corr_hist[i];
            peak_idx = i;
        }
    }

    /* Поріг детекції: пік має перевищувати шум щонайменше в 3 рази */
    double min_threshold = fmax(10.0, sqrt(noise_floor + 1.0) * 3.5);
    if (max_signal < min_threshold || peak_idx == 0 || peak_idx >= num_bins - 1) {
        return res; /* пік відсутній або за межами діапазону */
    }

    /* 4. Суб-біновий розрахунок центроїда піка (3-точковий центр мас) */
    double w_left   = corr_hist[peak_idx - 1];
    double w_center = corr_hist[peak_idx];
    double w_right  = corr_hist[peak_idx + 1];
    double weight_sum = w_left + w_center + w_right;

    if (weight_sum <= 0.0) {
        return res;
    }

    double sub_bin_offset = (w_right - w_left) / weight_sum;
    double exact_bin = (double)peak_idx + sub_bin_offset;

    /* 5. Перерахунок часу прольоту в метри */
    double tof_seconds = exact_bin * (bin_width_ps * 1e-12);
    res.distance_m = (SPEED_OF_LIGHT_M_S * tof_seconds) / 2.0;
    res.confidence = max_signal / (noise_floor + 1.0);
    res.valid = true;

    return res;
}
```

```cpp
#include <iostream>
#include <vector>
#include <optional>
#include <span>
#include <cmath>
#include <numeric>
#include <algorithm>

class DtofProcessor {
public:
    static constexpr double SPEED_OF_LIGHT_M_S = 299792458.0;

    struct Result {
        double distance_m{0.0};
        double confidence{0.0};
        double exact_time_ps{0.0};
    };

    explicit DtofProcessor(double bin_width_ps, uint32_t total_cycles) noexcept
        : bin_width_ps_{bin_width_ps}, total_cycles_{total_cycles} {}

    [[nodiscard]] std::optional<Result> process(std::span<const uint32_t> raw_hist) const {
        if (raw_hist.empty() || total_cycles_ == 0) {
            return std::nullopt;
        }

        std::vector<double> corr_hist(raw_hist.size());
        uint32_t cumulative_events = 0;

        // 1. Статистична пуассонівська корекція нагромадження (Coates pile-up correction)
        for (size_t i = 0; i < raw_hist.size(); ++i) {
            const auto available_cycles = static_cast<int64_t>(total_cycles_) - cumulative_events;
            if (available_cycles <= static_cast<int64_t>(raw_hist[i]) || available_cycles <= 0) {
                corr_hist[i] = static_cast<double>(raw_hist[i]);
            } else {
                double p = static_cast<double>(raw_hist[i]) / static_cast<double>(available_cycles);
                p = std::clamp(p, 0.0, 0.999);
                corr_hist[i] = -static_cast<double>(total_cycles_) * std::log(1.0 - p);
            }
            cumulative_events += raw_hist[i];
        }

        // 2. Оцінка рівня сонячного фону за крайніми бінами
        const size_t edge_bins = std::min<size_t>(8, raw_hist.size() / 4);
        double noise_sum = 0.0;
        size_t noise_count = 0;

        for (size_t i = 0; i < edge_bins; ++i) {
            noise_sum += corr_hist[i];
            noise_count++;
        }
        for (size_t i = raw_hist.size() - edge_bins; i < raw_hist.size(); ++i) {
            noise_sum += corr_hist[i];
            noise_count++;
        }
        const double noise_floor = (noise_count > 0) ? (noise_sum / static_cast<double>(noise_count)) : 0.0;

        // 3. Віднімання фону та пошук вершини піка
        for (auto& val : corr_hist) {
            val = std::max(0.0, val - noise_floor);
        }

        const auto max_it = std::max_element(corr_hist.begin(), corr_hist.end());
        const size_t peak_idx = std::distance(corr_hist.begin(), max_it);
        const double max_signal = *max_it;

        const double min_threshold = std::max(10.0, std::sqrt(noise_floor + 1.0) * 3.5);
        if (max_signal < min_threshold || peak_idx == 0 || peak_idx >= corr_hist.size() - 1) {
            return std::nullopt;
        }

        // 4. Суб-біновий розрахунок центроїда (центр мас 3 точок)
        const double w_left   = corr_hist[peak_idx - 1];
        const double w_center = corr_hist[peak_idx];
        const double w_right  = corr_hist[peak_idx + 1];
        const double weight_sum = w_left + w_center + w_right;

        if (weight_sum <= 0.0) {
            return std::nullopt;
        }

        const double sub_bin_offset = (w_right - w_left) / weight_sum;
        const double exact_bin = static_cast<double>(peak_idx) + sub_bin_offset;
        const double tof_seconds = exact_bin * (bin_width_ps_ * 1e-12);

        return Result{
            .distance_m = (SPEED_OF_LIGHT_M_S * tof_seconds) / 2.0,
            .confidence = max_signal / (noise_floor + 1.0),
            .exact_time_ps = exact_bin * bin_width_ps_
        };
    }

private:
    double bin_width_ps_{50.0};
    uint32_t total_cycles_{100000};
};
```
