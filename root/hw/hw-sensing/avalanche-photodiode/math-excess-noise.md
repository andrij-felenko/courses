# 🧮 Математика лавинного підсилення, шуму Макінтайра та мертвого часу

Коли фотон народжує первинний електрон у збідненій області напівпровідника, вихідний сигнал датчика залежить не від детермінованого множника, а від стохастичного каскаду випадкових зіткнень. Математичний опис лавинного фотодіода (APD) та однофотонного лавинного діода (SPAD) спирається на три аналітичні блоки: просторовий інтеграл іонізації для коефіцієнта підсилення, статистику випадкового розгалуження Макінтайра для дисперсії шумів та теорію відновлення пуассонівських потоків для врахування мертвого часу.

## 1. Рівняння ударної іонізації та виведення коефіцієнта підсилення M

Розглянемо збіднену область p-n переходу товщиною `W`, розташовану вздовж просторової координати `x ∈ [0, W]`. До переходу прикладено зворотну напругу, яка створює сильне електричне поле `E(x)`, спрямоване проти осі `x`.

Електрони дрейфують у додатному напрямку осі `x` (до катода `x = W`), а дірки — у від'ємному напрямку (до анода `x = 0`). Коефіцієнт ударної іонізації електронів `α(x) = α(E(x))` визначає ймовірність того, що електрон породить пару «електрон-дірка» на одиниці довжини шляху [см⁻¹]. Відповідно, `β(x) = β(E(x))` — коефіцієнт ударної іонізації для дірок.

Залежність коефіцієнтів від напруженості поля підпорядковується емпіричному закону Чайновета (Chynoweth law):

```
α(E) = a_n · e^(-b_n / E)
β(E) = a_p · e^(-b_p / E)

a_n, a_p     [матеріальні константи насичення, см⁻¹]
b_n, b_p     [критичні напруженості поля ударної іонізації, В/см]
E            [локальна напруженість електричного поля, В/см]
```

### Диференціальні рівняння для густини струмів

Нехай `J_n(x)` — густина електронного струму в точці `x`, а `J_p(x)` — густина діркового струму. За відсутності оптичної генерації всередині збідненої зони зміна струмів за рахунок ударної іонізації описується системою:

```
dJ_n(x) / dx = α(x) · J_n(x) + β(x) · J_p(x)
dJ_p(x) / dx = α(x) · J_n(x) + β(x) · J_p(x)
```

Повний струм `J = J_n(x) + J_p(x)` є просторово постійним у стаціонарному стані (`dJ / dx = 0`). Підставивши `J_p(x) = J - J_n(x)` у перше рівняння, отримуємо лінійне неоднорідне диференціальне рівняння першого порядку для електронного струму:

```
dJ_n(x) / dx - (α(x) - β(x)) · J_n(x) = β(x) · J
```

Інтегруючи це рівняння за допомогою інтегрувального множника `μ(x) = exp(-∫₀ˣ (α(x') - β(x')) dx')`, знаходимо розподіл `J_n(x)`:

```
J_n(x) · e^(-∫₀ˣ (α - β) dx') = J_n(0) + J · ∫₀ˣ β(x') · e^(-∫₀ˣ' (α - β) dx'') dx'
```

### Граничні умови та коефіцієнт множення для інжекції електронів

Якщо первинний струм інжектується суто на границі `x = 0` (чиста електронна інжекція від поглинання короткохвильового світла біля p⁺-контакту), граничні умови мають вигляд:

```
J_n(0) = J_in           [інжектований первинний електронний струм]
J_p(W) = 0              [на правому контакті дірковий струм відсутній]
J_n(W) = J              [повний вихідний струм на правому контакті]
```

Підставляючи `x = W` у розв'язок і враховуючи, що `J_n(W) = J`:

```
J · e^(-∫₀ᵂ (α - β) dx) = J_in + J · ∫₀ᵂ β(x) · e^(-∫₀ˣ (α - β) dx') dx     [підстановка x = W у загальний інтеграл]
J · [e^(-∫₀ᵂ (α - β) dx) - ∫₀ᵂ β(x) · e^(-∫₀ˣ (α - β) dx') dx] = J_in       [винесення повного струму J за дужки]
```

Коефіцієнт лавинного підсилення електронів `M_n = J / J_in` визначається відношенням повного струму до інжектованого:

```
M_n = 1 / [e^(-∫₀ᵂ (α - β) dx) - ∫₀ᵂ β(x) · e^(-∫₀ˣ (α - β) dx') dx]
```

Скориставшись інтегруванням частинами, вираз у знаменнику перетворюється до канонічної форми:

```
1 / M_n = 1 - ∫₀ᵂ α(x) · e^(-∫ₓᵂ (α(x') - β(x')) dx') dx
```

Умова лавинного пробою (`M_n → ∞`) настає, коли знаменник обертається в нуль:

```
∫₀ᵂ α(x) · e^(-∫ₓᵂ (α(x') - β(x')) dx') dx = 1
```

Для випадку рівних коефіцієнтів іонізації (`α = β`, що характерно для Ge та GaAs) інтегральна умова пробою спрощується до класичного вигляду:

```
∫₀ᵂ α(x) dx = 1
```

### Емпірична формула Міллера

Для практичних розрахунків лавинного підсилення при зміні зворотної напруги `V_R` нижче напруги пробою `V_BR` застосовують наближення Міллера:

```
M(V_R) = 1 / (1 - (V_R / V_BR)ⁿ)

V_R      [прикладена зворотна напруга зсуву, В]
V_BR     [напруга лавинного пробою діода, В]
n        [показник степеня Міллера, для Si n ≈ 2..4, для InP n ≈ 3..6]
```

## 2. Статистика розгалуження та виведення надлишкового шуму Макінтайра

Процес ударної іонізації є стохастичним: первинний електрон може породити нуль, два або п'ять вторинних носіїв. Через це коефіцієнт підсилення `M` є випадковою дискретною величиною з математичним сподіванням `<M>` та дисперсією `σ_M² = <M²> - <M>²`.

Флуктуації коефіцієнта підсилення додають додатковий шум до вихідного струму детектора. Спектральна густина дробового шуму APD виражається через середній струм `<I>` та фактор надлишкового шуму (Excess Noise Factor) `F(M)`:

```
S_i = 2 · q · <I_in> · <M>² · F(M)

q        [елементарний електричний заряд, ≈ 1.602 × 10⁻¹⁹ Кл]
<I_in>   [середній первинний фотострум, А]
F(M)     [коефіцієнт надлишкового шуму: F(M) = <M²> / <M>²]
```

### Виведення формули Макінтайра

У 1966 році Роберт Макінтайр розглянув статистику марковського процесу розмноження носіїв у зоні високого поля при постійному відношенні коефіцієнтів іонізації `k = β / α`.

Нехай первинний електрон потрапляє в область множення. Кожен електрон на елементарному кроці `dx` із ймовірністю `α · dx` народжує пару «електрон-дірка», а кожна дірка з ймовірністю `β · dx = k · α · dx` народжує таку саму пару.

Розглядаючи рекурсивні твірні функції ймовірностей для повного числа породжених частинок, другий момент випадкової величини підсилення `<M²>` зв'язується з першим моментом `<M>` через інтегральне рівняння стохастичного розгалуження:

```
<M²> = <M>² + k · <M> · (<M> - 1) + (1 - k) · (2 - 1 / <M>) · <M>²
```

Розділивши обидві частини на `<M>²`, отримуємо точний вираз для фактора надлишкового шуму Макінтайра:

```
F(M) = <M²> / <M>²                            [означення коефіцієнта надлишкового шуму]
= 1 + (Var(M) / <M>²)                         [зв'язок другого моменту з дисперсією випадкової величини]
= k · <M> + (1 - k) · (2 - 1 / <M>)           [підстановка інтегрального розв'язку розгалуження]
```

Розкриємо поведінку функції `F(M)` для різних фізичних режимів:

```
1. Ідеальний однорідний електронний детектор (k = 0, іонізують лише електрони):
   F(M) = 2 - 1 / M
   При великих підсиленнях (M >> 1):  F(M) → 2.0  (надлишковий шум подвоює дробовий шум).

2. Симетрична іонізація (k = 1, електрони та дірки іонізують однаково: Ge, GaAs):
   F(M) = M
   Шум зростає прямо пропорційно підсиленню; робота при M > 20 стає неефективною.

3. Реальний кремнієвий APD (k ≈ 0.02..0.03, кремній n⁺-p-π-p⁺):
   При M = 100:  F(100) = 0.02 · 100 + 0.98 · (2 - 0.01) = 2.0 + 1.95 = 3.95
```

### Оптимальний коефіцієнт підсилення APD за наявності теплового шуму

Повний шум системи, що складається з APD та трансімпедансного підсилювача (TIA) з еквівалентною спектральною густиною теплового шуму `i_na` [А/√Гц], становить:

```
i_noise_total² = [2 · q · (I_ph + I_dark) · M² · F(M) + i_na²] · Δf

I_ph     [первинний фотострум сигналу, А]
I_dark   [первинний темновий струм витоку, А]
Δf       [смуга пропускання тракту, Гц]
```

Відношення сигнал/шум (SNR) за потужністю:

```
SNR = (M · I_ph)² / i_noise_total²                                                                    [визначення відношення потужностей сигналу й шуму]
= (M² · I_ph²) / {[2 · q · (I_ph + I_dark) · M² · (k·M + (1-k)·(2 - 1/M)) + i_na²] · Δf}             [підстановка виразу шуму Макінтайра та TIA]
```

Диференціюючи вираз за `M` і прирівнюючи похідну до нуля (`d(SNR) / dM = 0`), отримуємо рівняння для оптимального коефіцієнта підсилення `M_opt`:

```
M_opt ≈ [i_na² / (q · (I_ph + I_dark) · k)]^(1/3)
```

Це рівняння доводить фундаментальне інженерне правило: чим менший коефіцієнт асиметрії `k` (чим ближчий кремній до ідеалу `k → 0`), тим вище значення `M_opt` можна застосувати, перш ніж власний надлишковий шум лавини перевищить вхідний тепловий шум підсилювача.

## 3. Статистика лічби фотонів та моделі мертвого часу (Dead Time)

У режимі Гейгера (SPAD) коефіцієнт множення не має значення, оскільки кожен успішний акт іонізації викликає повний розряд ємності пікселя. Сенсор реєструє дискретні події (імпульси напруги).

Потік вхідних фотонів описується статистикою Пуассона. Якщо середня кількість фотонів, що потрапляють на активну площу за один імпульс, дорівнює `μ`, а ефективність реєстрації фотонів становить `PDE` (Photon Detection Efficiency), ймовірність зареєструвати хоча б один фотон за імпульс дорівнює:

```
P_detect = 1 - P_poisson(0, μ · PDE) = 1 - e^(-PDE · μ)

μ        [середнє число фотонів у світловому імпульсі: μ = E_pulse / (h · ν)]
PDE      [ефективність детектування: PDE = QE · P_trigger(V_ex)]
```

При слабких потоках (`μ · PDE << 1`) експоненту можна розкласти в ряд: `P_detect ≈ PDE · μ` (лінійний режим лічби).

### Математичні моделі мертвого часу (Dead Time Models)

Після кожного спрацьовування SPAD потребує часу `τ` (Dead Time) на гасіння лавини та відновлення робочої напруги `V_BR + V_ex`. Протягом цього інтервалу піксель є нечутливим або частково нечутливим до нових фотонів.

Розрізняють два класичних типи поведінки лічильника:

```
1. Непаралізувальний лічильник (Non-Paralyzable Model, фіксований активний AQC):
   Фотони, що надходять під час мертвого часу τ, повністю ігноруються
   і НІЯК не впливають на тривалість поточного мертвого інтервалу.

2. Паралізувальний лічильник (Paralyzable Model, пасивне RC-гасіння):
   Кожен новий фотон, що потрапляє в діод під час відновлення,
   викликає новий підрозряд і ПЕРЕЗАПУСКАЄ відлік мертвого часу τ.
```

### Непаралізувальний режим (Non-Paralyzable Counter)

Нехай істинний темп надходження подій становить `R_true` [подій/с], а виміряний лічильником темп — `R_meas` [подій/с].

Оскільки кожна зареєстрована подія блокує детектор на час `τ`, за одну секунду датчик перебуває у заблокованому стані сумарний час `T_dead = R_meas · τ`. Ефективний час, протягом якого датчик був відкритий для реєстрації, становить `T_live = 1 - R_meas · τ`.

Кількість зареєстрованих подій дорівнює добутку істинного темпу на живий час:

```
R_meas = R_true · T_live               [темп виміряних подій через тривалість чутливого стану]
= R_true · (1 - R_meas · τ)            [підстановка мертвого часу T_dead = R_meas · τ]
```

Розв'язуючи це рівняння відносно `R_meas` та `R_true`:

```
R_meas = R_true / (1 + R_true · τ)

R_true = R_meas / (1 - R_meas · τ)
```

При зростанні вхідного потоку (`R_true → ∞`) виміряний темп асимптотично насичується на фізичній межі:

```
R_max = 1 / τ
```

Для типового активного гасіння з `τ = 10 нс` максимальний темп лічби непаралізувального SPAD становить `R_max = 1 / 10⁻⁸ = 100 МГц`.

### Паралізувальний режим (Paralyzable Counter)

У паралізувальній моделі подія реєструється лише тоді, коли часовий інтервал між нею та попередньою подією перевищує `τ`.

Згідно з пуассонівським розподілом із параметром `R_true`, ймовірність того, що за час `τ` не відбудеться жодної іншої події, дорівнює `P(Δt > τ) = e^(-R_true · τ)`. Тоді виміряний темп рахунку становить:

```
R_meas = R_true · e^(-R_true · τ)
```

Ця функція має максимум при `R_true = 1 / τ`:

```
R_peak = 1 / (e · τ) ≈ 0.368 / τ
```

При подальшому збільшенні інтенсивності світла (`R_true > 1 / τ`) виміряна швидкість лічби не насичується, а спадає до нуля (`R_meas → 0`): діод безперервно бомбардується фотонами, не встигаючи вийти з мертвого стану («параліч» або засліплення датчика).

### Статистична поправка Коутса (Coates Pile-Up Correction) для TCSPC гістограм

У dToF системах часово-корельованої лічби фотонів (TCSPC) кожен лазерний період розбивається на `K` часових бінів шириною `Δt`. Якщо за один лазерний імпульс на піксель приходить більше одного фотона, SPAD реєструє лише перший фотон, блокуючи всі наступні. Це викликає спотворення гістограми в бік коротких дистанцій (Pile-Up Effect).

Нехай за `N_cycles` лазерних циклів у біні з індексом `i` було зареєстровано `N_meas[i]` подій. Кількість імпульсів, у яких детектор залишався вільним до моменту настання біна `i`, становить:

```
N_available[i] = N_cycles - ∑_{j=1}^{i-1} N_meas[j]
```

Істинна середня кількість фотонів `λ_true[i]`, що надійшли у бін `i`, відновлюється за формулою пуассонівської інверсії Коутса:

```
P_event[i] = N_meas[i] / N_available[i]       [експериментальна ймовірність події у вільному біні]
= 1 - e^(-λ_true[i])                          [пуассонівська ймовірність принаймні одного фотона]

λ_true[i] = -ln(1 - N_meas[i] / (N_cycles - ∑_{j=1}^{i-1} N_meas[j]))
```

Відновлене істинне число фотонів у біні `N_corr[i] = N_cycles · λ_true[i]` повністю усуває асиметрію нагромадження та повертає піку відлуння його справжню симетричну форму.
