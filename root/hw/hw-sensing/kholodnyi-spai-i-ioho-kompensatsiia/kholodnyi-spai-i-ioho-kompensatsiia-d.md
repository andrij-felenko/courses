# Холодний спай і його компенсація

<preknowlist>
- [Ефект Зеєбека](root:hw-sensing/efekt-zeiebeka) — виникнення термо-ЕРС у провіднику за наявності градієнта температур.
- [Термопара](root:hw-sensing/thermocouple) — вимірювання екстремальних температур спаєм двох різнорідних металів.
- [RTD — резистивний давач температури](root:hw-sensing/rtd-sensor) — прецизійне вимірювання температури за зміною опору платини.
- [NTC-термістор](root:hw-sensing/ntc-thermistor) — напівпровідниковий терморезистор із від'ємним температурним коефіцієнтом.
- [Міст Вітстона](root:hw-sensing/wheatstone-bridge) — вимірювання малих змін опору в диференційних схемах.
- [Інструментальний підсилювач](root:hw-analog/instrumentation-amp) — високоточне підсилення малих диференційних напруг на тлі синфазних завад.
</preknowlist>

Якщо під'єднати термопару типу K (хромель–алюмель) до муфельної печі, нагрітої рівно до 500 °C, а протилежні кінці дротів затиснути у гвинтові клеми вольтметра на лабораторному столі за кімнатної температури 25 °C, прилад виміряє не 20.644 мВ (термо-ЕРС для 500 °C за стандартом ITS-90), а лише 19.644 мВ. Різниця становить рівно 1.000 мВ — напругу, яку ця сама термопара генерує при 25 °C. Якщо опівдні кондиціонер вимкнеться і повітря біля клемника прогріється до 35 °C без жодної зміни всередині печі, виміряна напруга впаде до 19.239 мВ. Не знаючи температури власного вхідного роз'єму, вимірювальна система зафіксує хибне охолодження печі на 10 °C, хоча технологічний процес не змінився ані на соту частку градуса.

Термопара (від грец. *therme* — тепло і лат. *par* — пара) за своєю фізичною природою принципово не здатна вимірювати абсолютну температуру. Вона вимірює виключно **різницю температур** між гарячим вимірювальним спаєм і точкою підключення до схеми. Перетворення цієї відносної напруги в абсолютні градуси вимагає вимірювання локальної температури роз'єму та відновлення втраченої частини термо-ЕРС — процедури, відомої як **компенсація холодного спаю** (англ. *Cold Junction Compensation*, CJC).

### Фізична природа проблеми: закон проміжних металів

Поширена помилка стверджує, що напруга термопари народжується в самій точці зварювання двох металів. Насправді електрорушійна сила Зеєбека генерується **вздовж усього тіла провідників**, де існує просторовий температурний градієнт `dT/dx`. Вільні електрони на гарячому кінці дроту мають вищу кінетичну енергію, ніж на холодному, і дифундують у бік нижчої температури, створюючи градієнт електричного потенціалу.

Кожен метал характеризується власним абсолютним коефіцієнтом Зеєбека `S(T)`. Різниця потенціалів між кінцями одного ізольованого провідника довжиною `L` становить інтеграл від його коефіцієнта Зеєбека вздовж градієнта температури:

```
V = ∫ [від x=0 до L] S(T(x)) · (dT/dx) dx = ∫ [від T_cold до T_hot] S(T) dT
```

Коли ми зварюємо два різнорідні провідники `A` (наприклад, хромель) і `B` (алюмель) на гарячому кінці за температури `T_hot`, а вільні кінці підтримуємо при температурі `T_cjc`, різниця потенціалів між вільними кінцями дорівнює інтегралу різниці їхніх коефіцієнтів Зеєбека:

```
V_AB = ∫ [від T_cjc до T_hot] (S_A(T) - S_B(T)) dT
```

Якщо розбити інтеграл на дві частини з умовною базовою точкою 0 °C (273.15 K), дефініція дає базове рівняння термопари:

```
V_meas = ∫ [від 0 до T_hot] S_AB(T) dT - ∫ [від 0 до T_cjc] S_AB(T) dT
= V_AB(T_hot) - V_AB(T_cjc)
```

Тут `V_AB(T_hot)` — це повна термо-ЕРС гарячого спаю відносно 0 °C, а `V_AB(T_cjc)` — паразитна термо-ЕРС, сформована зворотним градієнтом від точки підключення до нуля.

![Фізика холодного спаю та виникнення паразитної термо-ЕРС на клемах](/root/hw/hw-sensing/kholodnyi-spai-i-ioho-kompensatsiia/img/cjc-circuit-problem.svg)
*Формування сумарного вимірюваного сигналу термопарного кола. Зварний спай J₁ перебуває при температурі об'єкта T_hot. Підключення сплавів хромель і алюмель до мідних доріжок плати утворює два нові паразитні термоелектричні спаї J₂ та J₃ за температури T_cjc. Виміряна напруга V_meas є різницею термо-ЕРС гарячого та холодного спаїв.*

Коли провідники термопари підключаються до друкованої плати, їхні сплави контактують із міддю (Cu) доріжок або латунню клемника. За **законом проміжних металів Вольти** (англ. *law of intermediate metals*), введення третього металу в замкнене термоелектричне коло не змінює результуючої ЕРС за однієї категоричної умови: обидва нові контакти («провідник A — мідь» і «провідник B — мідь») повинні перебувати за строго однакової температури `T_cjc1 = T_cjc2 = T_cjc`.

Розпишемо сумарне падіння напруги вздовж усього замкненого вимірювального контуру:

```
V_total = V_A(T_cjc → T_hot) + V_B(T_hot → T_cjc) + V_Cu(T_cjc → T_meter) + V_Cu(T_meter → T_cjc)
```

Оскільки обидві мідні доріжки прокладені поруч і з'єднують точки з однаковими температурами `T_cjc` та `T_meter`, їхні власні термо-ЕРС у міді взаємно знищуються:

```
V_Cu(T_cjc → T_meter) + V_Cu(T_meter → T_cjc) = 0
```

Якщо ж між двома клемами роз'єму виникне температурний градієнт `ΔT_term = T_cjc1 - T_cjc2`, компенсація порушується. У вимірювальний сигнал додається паразитна напруга `V_err ≈ S_Cu-B · ΔT_term`. Для поширених сплавів перепад лише в 1 °C між сусідніми гвинтами клемника спричиняє еквівалентну похибку вимірювання температури гарячого спаю від 1 °C до 3 °C.

> 🔧 **Термінологія: чому спай називають «холодним».** В епоху класичної метрології для виключення невизначеності вільні кінці термопари фізично занурювали в герметичні скляні пробірки, опущені в термос із сумішшю чистої дистильованої води та подрібненого льоду — **льодяну ванну** (англ. *ice bath*) за температури танення 0.00 °C. За такої умови `V_AB(T_cjc = 0 °C) = 0`, і виміряна напруга вольтметра точно дорівнювала `V_AB(T_hot)`. Оскільки точка 0 °C зазвичай була холоднішою за об'єкт вимірювання, цей спай назвали «холодним спаєм» (англ. *cold junction*). У сучасній електроніці точка підключення часто має температуру +40...+60 °C через самонагрів приладу, тому в сучасних стандартах використовують точніший термін — **опорний спай** (англ. *reference junction*).

### Фатальна помилка: чому не можна просто додавати температури

Найпоширеніша помилка розробників-початківців — спроба компенсувати холодний спай безпосереднім лінійним додаванням температур. Логіка недосвідченого інженера виглядає просто: виміряти напругу термопари `V_meas`, перевести її за таблицею в градуси `T_meas = f^(-1)(V_meas)`, виміряти датчиком температуру плати `T_cjc` і додати їх:

```
T_hot_wrong = T_meas + T_cjc        [ФАТАЛЬНА ПОМИЛКА]
```

Цей метод був би математично строгим лише в одному гіпотетичному випадку: якби коефіцієнт Зеєбека `S(T) = dV/dT` був строго сталою константою у всьому діапазоні від -200 °C до +1370 °C. Але у реальних фізичних металах `S(T)` суттєво залежить від поточної температури кристалічної ґратки.

![Нелінійність коефіцієнта Зеєбека для різних типів термопар](/root/hw/hw-sensing/kholodnyi-spai-i-ioho-kompensatsiia/img/seebeck-coefficient-curves.svg)
*Залежність диференційного коефіцієнта Зеєбека S(T) від температури для термопар типу E, J, K, S/R та B. Жодна термопара не має лінійної характеристики. У благородних термопар типу B біля кімнатної температури чутливість спадає майже до нуля, тоді як при 1000 °C перевищує 9 мкВ/°C.*

Погляньмо на криву термопари типу K:
- При 0 °C чутливість становить `S ≈ 39.48 мкВ/°C`.
- При 25 °C чутливість зростає до `S ≈ 40.50 мкВ/°C`.
- При 500 °C чутливість досягає `S ≈ 42.61 мкВ/°C`.
- При 1000 °C спадає до `S ≈ 39.00 мкВ/°C`.

Для платинових термопар типу S і R нелінійність ще виразніша: біля 0 °C чутливість становить `5.4 мкВ/°C`, а біля 1000 °C — `11.5 мкВ/°C` (зміна у понад 2.1 раза). Для типу B біля кімнатної температури чутливість становить взагалі менше `0.5 мкВ/°C`, а за 1200 °C — `11.2 мкВ/°C`.

**Числовий доказ катастрофічності наївного додавання.**
Нехай вимірювальний спай типу K перебуває за температури `T_hot = 500.0 °C`, а опорний спай плати — за температури `T_cjc = 25.0 °C`.

1. Згідно з міжнародним метрологічним стандартом NIST ITS-90:
   - Термо-ЕРС за 500 °C відносно 0 °C: `V(500 °C) = 20.644 мВ`.
   - Термо-ЕРС за 25 °C відносно 0 °C: `V(25 °C) = 1.000 мВ`.
   - Напруга на клемах: `V_meas = 20.644 - 1.000 = 19.644 мВ`.

2. Застосуємо **хибний метод**:
   - Перетворюємо 19.644 мВ у градуси, вважаючи опорною точку 0 °C: `f^(-1)(19.644 мВ) = 478.18 °C`.
   - Додаємо виміряну температуру плати: `T_calc = 478.18 + 25.0 = 503.18 °C`.
   - **Похибка становить +3.18 °C.**

Якщо ж температура гарячого спаю становить 1000 °C, а опорного — 50 °C, похибка наївного додавання для типу K перевищує 6 °C, а для платинової термопари типу S наївне додавання дасть помилку у понад 25 °C.

![Правильний алгоритм цифрової компенсації проти наївного додавання температур](/root/hw/hw-sensing/kholodnyi-spai-i-ioho-kompensatsiia/img/cjc-math-flow.svg)
*Порівняння алгоритмічних ланцюгів обробки даних. Зліва — помилкове додавання температур після лінеаризації. Справа — канонічний метрологічний алгоритм NIST ITS-90: обчислення еквівалентної термо-ЕРС опорного спаю, підсумовування напруг і фінальне зворотне поліноміальне перетворення.*

### Канонічний 4-кроковий алгоритм цифрової компенсації

Єдиним метрологічно коректним методом програмної компенсації холодного спаю є обчислення у просторі напруг (термо-ЕРС) з подальшим зворотним перетворенням суми. Алгоритм складається з чотирьох послідовних кроків:

```
Крок 1.  T_cjc = read_cold_junction_sensor()    [зчитування локального термодатчика в °C]
Крок 2.  V_cjc = f_NIST(T_cjc)                  [прямий поліном: розрахунок ЕРС для T_cjc]
Крок 3.  V_total = V_meas + V_cjc               [додавання напруг у мікровольтах/мілівольтах]
Крок 4.  T_hot = f_NIST^(-1)(V_total)           [зворотний поліном: розрахунок шуканої T_hot]
```

Тільки після складання напруг `V_total = V_meas + V_cjc` ми отримуємо точне значення термо-ЕРС, яке згенерувала б термопара, якби її опорний спай фізично лежав у льодяній ванні за 0.00 °C. Після цього єдине застосування зворотного полінома дає абсолютно точну температуру `T_hot` без будь-якої методичної похибки нелінійності.

> 🔧 **Навіщо це.** Додавання температур — це змішування різних масштабів. Оскільки 1 °C при кімнатній температурі генерує 40.5 мкВ, а 1 °C при 500 °C генерує 42.6 мкВ, один «кімнатний градус» електрично не еквівалентний одному «високотемпературному градусу». Додавати можна лише фізичні потенціали — мікровольти до мікровольтів.

### Перенесення похибки вимірювання опорного спаю на результат

Наскільки критичною є точність локального термодатчика на платі? Щоб відповісти математично строго, продиференціюємо базове рівняння термопари:

```
V_meas = V(T_hot) - V(T_cjc)
```

При фіксованій виміряній напрузі `V_meas = const` варіація температури опорного спаю `dT_cjc` викликає варіацію обчисленої температури гарячого спаю `dT_hot`:

```
dV_meas = 0
= S(T_hot) · dT_hot - S(T_cjc) · dT_cjc
```

Переносячи доданки, отримуємо коефіцієнт передачі похибки:

```
dT_hot = (S(T_cjc) / S(T_hot)) · dT_cjc
```

Цей простий вираз дає глибокі висновки для різних зон вимірювання:

1. **Високі температури (T_hot > 500 °C для типу K):**
   При `T_hot = 600 °C` маємо `S(600 °C) ≈ 42.5 мкВ/°C`, а `S(25 °C) ≈ 40.5 мкВ/°C`.
   Відношення становить `40.5 / 42.5 ≈ 0.95`. Похибка в 1 °C на платі переноситься на гарячий спай як `0.95 °C` (навіть трохи послаблюється).

2. **Кріогенні температури (T_hot < -100 °C для типу K):**
   При `T_hot = -150 °C` коефіцієнт Зеєбека спадає до `S(-150 °C) ≈ 20.0 мкВ/°C`.
   Відношення становить `40.5 / 20.0 = 2.025`! Похибка датчика опорного спаю в 1 °C подвоюється і дає помилку понад 2 °C на об'єкті. Вимірювання кріогенних температур термопарами вимагає бездоганного, надточного вимірювання опорного спаю.

3. **Спеціальний випадок: термопара типу B (Pt-30%Rh / Pt-6%Rh):**
   Крива чутливості типу B біля кімнатних температур має крутість лише `S(0...50 °C) < 0.5 мкВ/°C`. Якщо гарячий спай перебуває за температури 1200 °C (`S = 11.2 мкВ/°C`), відношення коефіцієнтів становить:
   `0.5 / 11.2 ≈ 0.045`.
   Похибка в 5 °C на клемнику приладу дає зміну обчисленої температури печі лише на `0.2 °C`. Завдяки цьому для термопар типу B у діапазоні вимірювань вище 600 °C компенсацію холодного спаю часто взагалі не реалізують, приймаючи `T_cjc = 0 °C` за замовчуванням.

### Ізотермічний блок: тепловий дизайн друкованої плати

Навіть найточніший математичний алгоритм безсилий, якщо температура контакту «хромель–мідь» відрізняється від температури контакту «алюмель–мідь», або якщо локальний датчик температури вимірює не температуру самих клем, а нагріте повітря навколо процесора. Вузол плати, де термопарні дроти переходять у мідні доріжки, називається **ізотермічним блоком** (від грец. *isos* — однаковий, рівний і *therme* — тепло; англ. *Isothermal Terminal Block*).

Головне завдання ізотермічного блоку — звести просторовий температурний градієнт між двома клемами та вимірювальним чутливим елементом до абсолютного мінімуму:

```
|T_cjc1 - T_cjc2| < 0.05 °C
|T_cjc_avg - T_sensor| < 0.1 °C
```

![Тепловий дизайн ізотермічного блоку на друкованій платі](/root/hw/hw-sensing/kholodnyi-spai-i-ioho-kompensatsiia/img/isothermal-block-pcb.svg)
*Топологія друкованої плати для прецизійного термопарного вузла. Фрезерований паз ізолює вимірювальну зону від тепловиділення стабілізаторів живлення. Суцільний внутрішній мідний полігон і масив теплових перехідних отворів вирівнюють температуру між гвинтовими клемами та платиновим RTD-сенсором.*

Для досягнення цієї ізотермічності застосовують комплекс схемотехнічних і конструктивних правил:

#### 1. Мідний острів вирівнювання тепла (Isothermal Copper Island)
Мідь має надзвичайно високу теплопровідність (`k_Cu ≈ 385...400 Вт/(м·К)`), тоді як склотекстоліт FR-4 є тепловим ізолятором (`k_FR4 ≈ 0.25...0.3 Вт/(м·К)` — у 1300 разів гірше). Під клемами та локальним сенсором створюють суцільні мідні полігони у внутрішніх і зовнішніх шарах плати, густо прошиті масивом металізованих отворів (англ. *thermal vias*). Мідний масив швидко перерозподіляє тепло, вирівнюючи температуру металевих гвинтів клемника.

#### 2. Теплова ізоляція від джерел нагріву (Thermal Relief Slots)
На друкованій платі завжди є джерела тепла: лінійні стабілізатори (LDO), імпульсні DC-DC перетворювачі, мікроконтролери, силові польові транзистори та світлодіоди. Якщо тепловий потік від стабілізатора рухатиметься крізь плату до клемника, він нагріє ближчу клему сильніше за дальшу. Щоб розірвати цей потік, між гарячою зоною плати та ізотермічним блоком роблять **наскрізний фрезерований проріз** (англ. *milling slot / air gap*). Повітря в прорізі має теплопровідність лише `0.026 Вт/(м·К)`, що створює потужний бар'єр для теплопровідності.

#### 3. Симетричне розміщення клем і датчика
Локальний датчик температури опорного спаю (RTD, NTC або кремнієву мікросхему) монтують геометрично **посередині між двома контактними площадками клемника**, на мінімальній відстані (не більше 2–3 мм). Симетричне трасування доріжок гарантує, що будь-який залишковий тепловий вплив діятиме на обидва спаї однаково.

#### 4. Захист від повітряної конвекції
Протяги від вентиляторів охолодження або природні конвекційні потоки повітря всередині корпусу приладу здатні миттєво охолодити одну клему, залишивши іншу теплою. Ізотермічний блок обов'язково закривають пластиковою кришкою або компаундом, створюючи закриту кишеню зі стабільним мікрокліматом.

### Порівняння локальних сенсорів температури опорного спаю

Точність вимірювання температури термопарою в кінцевому підсумку обмежена точністю вимірювання температури опорного спаю: помилка в 1 °C на датчику `T_cjc` дає помилку приблизно в 1 °C на гарячому спаї `T_hot`.

| Тип датчика CJC | Точність | Переваги | Обмеження й недоліки |
|---|---|---|---|
| **Платиновий RTD (Pt100 / Pt1000)** | ±0.05...0.1 °C | Еталонна стабільність, відсутність дрейфу (< 0.02 °C/рік), чудова лінійність | Потребує прецизійного джерела струму збудження та 4-провідного підключення |
| **NTC-термістор (10 кОм 0.1%)** | ±0.1...0.2 °C | Крихітний розмір (SMD 0402 прямо між клемами), величезна крутість (dlnR/dT ≈ -4%/°C), низька ціна | Нелінійна характеристика, вимагає рівняння Стейнгарта–Гарта |
| **Цифрові IC (TMP117, MCP9808)** | ±0.1 °C | Прямий цифровий вихід I2C/SPI, фабричне калібрування за стандартами NIST | Корпус має значну теплову інерцію; неможливо розмістити всередині гвинта |
| **Вбудований діод в АЦП/MCU** | ±0.5...2.0 °C | Нульова додаткова вартість, датчик уже всередині кристала контролера | Кристал АЦП нагрівається власним струмом споживання і віддалений від клемника |

#### Динамічні теплові помилки та стала часу `τ`
Масивний металевий клемник має значну теплоємність і повільно реагує на стрибки температури навколишнього середовища (теплова стала часу `τ_term ≈ 30...90 с`). Мініатюрний SMD-термодатчик у пластиковому корпусі нагрівається набагато швидше (`τ_sensor ≈ 3...10 с`).

Якщо прилад перенести з холодної вулиці (+5 °C) у теплий цех (+25 °C), датчик за 10 секунд покаже `T_cjc = 24 °C`, тоді як масивні латунні клеми все ще матимуть `T_cjc = 10 °C`. Виникає динамічна помилка компенсації величиною до 14 °C, яка зникає лише після повного виходу системи на теплову рівновагу через 3–5 хвилин. Для боротьби з цим явищем клеми та датчик заливають теплопровідним силіконовим компаундом або зв'язують масивним мідним бруском.

### Подовжувальні та компенсаційні кабелі

Часто вимірювальний прилад розташований на відстані десятків або сотень метрів від високотемпературного об'єкта (наприклад, пульт керування в операторській і піч у цеху). Використовувати звичайний мідний кабель для підключення термопари на відстані **категорично заборонено**: точка з'єднання термопари зі звичайним мідним дротом сама стане холодним спаєм. Якщо це з'єднання перебуває в неопалюваному цеху, його температура плаватиме, а вимірювач в операторській про це нічого не знатиме.

Для перенесення точки холодного спаю безпосередньо до вхідних клем приладу застосовують спеціальні кабелі двох класів:

1. **Подовжувальні кабелі (Extension Cables, маркуються літерою `X`):**
   Виготовляються з **тих самих сплавів**, що й сама термопара (наприклад, кабель `KX` для термопари `K` має жили з хромелю та алюмелю, `JX` — із заліза та константану). Їхня термоелектрична характеристика строго ідентична термопарі у всьому діапазоні температур кабелю (зазвичай до 200 °C). Подовжувальний кабель просто фізично подовжує термопару, зміщуючи холодний спай на клеми приладу.

2. **Компенсаційні кабелі (Compensating Cables, маркуються літерою `C`):**
   Сплави благородних термопар (платина, родій у типах S, R, B) надзвичайно дорогі, а хромель-алюмель у товстому екранованому виконанні має високий опір. Тому для прокладання довгих ліній застосовують компенсаційні кабелі, жили яких виготовлені з **дешевих сурогатних сплавів** (наприклад, сплави міді та нікелю для кабелю `KCB`).
   Термоелектрична характеристика компенсаційного сплаву збігається з характеристикою термопари **лише у вузькому діапазоні температур (зазвичай 0...+80 °C або 0...+100 °C)**.

> ⚠️ **Небезпека з'єднання компенсаційного кабелю:** якщо точка стику термопари з компенсаційним кабелем нагріється вище 100 °C (наприклад, роз'єм закріплено занадто близько до гарячого кожуха печі), виникне паразитна термо-ЕРС величиною до 5...15 °C.

Крім того, переплутування полярності компенсаційного дроту на проміжному клемнику (підключення плюса до мінуса і навпаки) створює **подвійну похибку Зеєбека**: замість компенсації паразитна ЕРС подвоюється, призводячи до відхилення показів на десятки градусів.

### Апаратна аналогова компенсація: схемотехніка мосту

До масової появи дешевих мікроконтролерів і сигма-дельта АЦП компенсацію холодного спаю виконували суто аналоговими методами безпосередньо у вимірювальному тракті.

#### Класичний міст із терморезистором
Ідея полягає у введенні послідовно у коло термопари джерела напруги протилежної полярності, величина якого точно повторює термо-ЕРС холодного спаю `V_comp(T) = V_cjc(T)`.

Для цього використовують [міст Вітстона](root:hw-sensing/wheatstone-bridge), в одне з плечей якого встановлено мідний, нікелевий або платиновий резистор з позитивним температурним коефіцієнтом опору (ТКС). Міст живиться від стабільного джерела опорної напруги і збалансований рівно при 0 °C (`V_bridge(0 °C) = 0 В`).

```
                V_ref
                  |
            +-----+-----+
            |           |
           [R1]        [R2]
            |           |
            +---( - )   +---( + ) ---> До мікровольтметра
            |           |
           [R3]       [R_temp (Cu/Pt)]
            |           |
            +-----+-----+
                  |
                 GND
```

Коли температура опорного спаю піднімається вище 0 °C, опір `R_temp` зростає, міст розбалансовується і генерує диференційну напругу `V_bridge ≈ S_K · T_cjc`, яка спрямована назустріч паразитній термо-ЕРС клем і компенсує її:

```
V_amp_in = V_meas + V_bridge = (V(T_hot) - V(T_cjc)) + V_cjc(T_cjc) = V(T_hot)
```

#### Інтегральні аналогові компенсатори (AD594/AD595, AD8495)
Компанія Analog Devices випустила серію спеціалізованих мікросхем, що об'єднують на одному кристалі термочутливий транзисторний елемент, прецизійний генератор напруги CJC та [інструментальний підсилювач](root:hw-analog/instrumentation-amp).

Наприклад, **AD8495** (для термопари типу K):
1. Вбудований напівпровідниковий PTAT-датчик температури вимірює температуру кристала мікросхеми.
2. Внутрішній генератор виробляє компенсуючу напругу з крутістю `40.44 мкВ/°C`.
3. Інструментальний підсилювач додає цю напругу до вхідного диференційного сигналу термопари і підсилює суму з фіксованим коефіцієнтом підсилення `Gain = 122.4`.
4. Вихідний сигнал є масштабованою аналоговою напругою з крутістю рівно `5.00 мВ/°C`:

```
V_out = (T_hot · 5 мВ/°C) + V_offset
```

```
При T_hot = 0 °C    →  V_out = 0.000 В
При T_hot = 100 °C  →  V_out = 0.500 В
При T_hot = 1000 °C →  V_out = 5.000 В
```

**Обмеження аналогової компенсації:**
- **Жорстка прив'язка до одного типу:** мікросхема, розрахована на тип K (AD8495), не здатна працювати з типом J (потрібна AD8494) чи типом T (AD8497), оскільки коефіцієнт підсилення та нахил компенсації задані лазерною підгонкою тонкоплівкових резисторів на кристалі.
- **Похибка нелінійності на краях діапазону:** аналогова компенсація працює за середнім коефіцієнтом Зеєбека, тому за температур гарячого спаю вище 400 °C похибка лінійності може сягати ±2...5 °C.

### Сучасні цифрові мікросхеми інтерфейсу термопар

У сучасних цифрових системах застосовують спеціалізовані інтегральні перетворювачі, які повністю інтегрують аналоговий тракт, АЦП високої роздільності, датчик опорного спаю та DSP-блок апаратної лінеаризації за таблицями NIST.

![Архітектура прецизійного термопарного фронтенду MAX31856](/root/hw/hw-sensing/kholodnyi-spai-i-ioho-kompensatsiia/img/thermocouple-afe-architecture.svg)
*Внутрішня функціональна структура інтегрального контролера термопари класу MAX31856. Вхідний комутатор з детекцією несправностей, підсилювач PGA, 19-бітний Sigma-Delta АЦП із режекцією завад 50/60 Гц, локальний термодатчик кристала, DSP-процесор розрахунку поліномів NIST ITS-90 та інтерфейс SPI.*

#### MAX31855 проти MAX31856

| Характеристика | MAX31855 | MAX31856 |
|---|---|---|
| **Підтримувані типи** | Фіксований при виробництві (окрема версія для K, J, N, S, T, E, R) | Програмний вибір для 8 типів (B, E, J, K, N, R, S, T) через регістр |
| **Роздільність АЦП термопари** | 14 біт (крок 0.25 °C) | 19 біт (крок 0.0078125 °C) |

| **Зовнішній CJC сенсор** | Не підтримується | Підтримується (вхід для підключення зовнішнього RTD/NTC) |
| **Фільтрація мережі 50/60 Гц** | Відсутня (потрібен зовнішній фільтр) | Вбудований цифровий фільтр із придушенням > 90 дБ |

| **Інтерфейс** | Тільки читання по SPI (Read-Only 32-bit frame) | Повноцінний двонаправлений SPI (читання/запис регістрів) |

#### Побудова вимірювального тракту на базі універсальних 24-бітних АЦП (ADS1220 / AD7124)
Для побудови промислових багатоканальних модулів введення часто використовують універсальні прецизійні сигма-дельта АЦП (Texas Instruments ADS1220, Analog Devices AD7124-4/8, Linear Technology LTC2983).

У такій структурі реалізують комбінований вимірювальний цикл:
1. **Канал термопари:** АЦП вимірює диференційну напругу термопари з коефіцієнтом підсилення `PGA = 32` або `64`, використовуючи стабільне внутрішнє джерело опорної напруги `V_ref = 2.048 В`.
2. **Канал опорного спаю (RTD Pt100):** АЦП перемикає мультиплексор на вимірювання платинового резистора, увімкнувши вбудоване джерело струму збудження `I_ex = 250 мкА`. Вимірювання RTD виконується за ratiometric-схемою відносно прецизійного еталонного резистора `R_ref`, що повністю нівелює дрейф струму збудження.
3. **Обчислення в мікроконтролері:** керівний мікроконтролер зчитує обидва відліки, перетворює код RTD у температуру `T_cjc` за поліномом Каллендара–Ван Дюзена, після чого виконує 4-кроковий алгоритм NIST ITS-90 для термопари.

#### Схемотехнічне узгодження, фільтрація та захист входів

Термопара зазвичай працює в жорстких промислових умовах: довгі кабелі (десятки метрів), прокладені вздовж силових кабелів електродвигунів, тиристорних регуляторів і трансформаторів, збирають гігантські електромагнітні завади (EMI/RFI).

Для забезпечення чистого вимірювання на вході контролера встановлюють симетричний диференційний RC-фільтр низьких частот:

```
TC+ ----[ R1: 100 Ом ]----+---------+-----> IN+ (АЦП)
                          |         |
                       [C_diff]  [C_cm1]
                       (100 нФ)   (10 нФ)
                          |         |
TC- ----[ R2: 100 Ом ]----+    +----+-----> IN- (АЦП)
                               |    |
                            [C_cm2] |
                            (10 нФ) |
                               |    |
                              GND  GND
```

**Критичні правила розрахунку фільтра:**
1. **Резистори R1 і R2** обирають номіналом 100 Ом...1 кОм з точністю 0.1%. Занадто великий опір (понад 5 кОм) разом зі вхідним струмом витоку АЦП створить неприпустиме падіння напруги зміщення.
2. **Диференційний конденсатор `C_diff`** (100 нФ) пригнічує високочастотну диференційну напругу між виводами. Частота зрізу: `f_diff = 1 / (2π · (R1 + R2) · C_diff) ≈ 1 / (2π · 200 · 100·10⁻⁹) ≈ 8 кГц`.
3. **Синфазні конденсатори `C_cm1` та `C_cm2`** (10 нФ) відводять наведену синфазну заваду на землю. Ємність `C_diff` обирають щонайменше **в 10 разів більшою** за `C_cm`. Якщо взяти `C_cm` великими, їхній технологічний розкид (наприклад, ±10%) перетворить потужну синфазну напругу завади на диференційний сигнал, спотворивши покази температури.

#### Заземлені проти ізольованих термопар
- **Ізольована термопара (Ungrounded):** вимірювальний спай електрично ізольований від металевої захисної гільзи (зонду). Сигнал повністю плаваючий. Для коректної роботи АЦП необхідно забезпечити шлях для вхідного струму зміщення підсилювача (англ. *input bias current*), підтягнувши один із входів (зазвичай IN-) через високоомний резистор (1...10 МОм) до віртуальної середньої точки або землі. Без цього резистора входи АЦП поступово зарядяться струмом витоку й увійдуть у стан насичення (rail saturation).
- **Заземлена термопара (Grounded):** вимірювальний спай приварений безпосередньо до металевої гільзи для забезпечення мінімальної теплової інерції (швидкої реакції на нагрів). Якщо гільза контактує із заземленим корпусом печі чи труби, між землею печі та землею приладу виникає паразитна різниця потенціалів контуру заземлення (англ. *ground loop*), яка може сягати десятків вольт. Для заземлених термопар вимірювальний фронтенд **зобов'язаний мати гальванічну ізоляцію** живлення та цифрового інтерфейсу (через цифрові ізолятори типу ADuM або ISO77xx).

### Математичний конвеєр NIST ITS-90 та реалізація на C і C++

Національний інститут стандартів і технологій США (NIST) публікує стандартні поліноміальні коефіцієнти міжнародної шкали температур ITS-90 для всіх стандартизованих типів термопар.

#### Прямий поліном: температура в напругу `V = f(T)`
Прямий поліном обчислює термо-ЕРС у мілівольтах за відомою температурою в градусах Цельсія.

Для термопари типу K у діапазоні від 0 °C до 1372 °C:

```
E(T) = ∑ [i=0..9] c_i · T^i + a₀ · exp(a₁ · (T - a₂)^2)
```

Експоненційний член враховує магнітні перетворення в сплаві нікелю (точка Кюрі) біля кімнатних температур.

Коефіцієнти для типу K (0...1372 °C):
- `c_0 = 0.0`
- `c_1 = 3.9450128025 · 10^-2`
- `c_2 = 2.3622373598 · 10^-5`
- `c_3 = -3.2858906784 · 10^-7`
- `c_4 = -4.9904828777 · 10^-9`
- `c_5 = -6.7509059173 · 10^-11`
- `c_6 = -5.7410320425 · 10^-13`
- `c_7 = -3.1088941972 · 10^-15`
- `c_8 = -1.0451609395 · 10^-17`
- `c_9 = -1.9889266778 · 10^-20`
- `a_0 = 0.1185976`, `a_1 = -1.183432 · 10^-4`, `a_2 = 126.9686`

#### Зворотний поліном: напруга в температуру `T = f^(-1)(V)`
Зворотний поліном обчислює температуру в градусах Цельсія за виміряною сумарною напругою в мілівольтах. Діапазон напруг розбивають на кілька піддіапазонів для збереження максимальної точності.

Для типу K у діапазоні від 0 мВ до 20.644 мВ (0...500 °C):

```
T(E) = ∑ [i=0..9] d_i · E^i
```

Коефіцієнти:
- `d_0 = 0.0`
- `d_1 = 2.508355 · 10^1`
- `d_2 = 7.860106 · 10^-2`
- `d_3 = -2.503131 · 10^-1`
- `d_4 = 8.315270 · 10^-2`
- `d_5 = -1.228034 · 10^-2`
- `d_6 = 9.804036 · 10^-4`
- `d_7 = -4.413030 · 10^-5`
- `d_8 = 1.057734 · 10^-6`
- `d_9 = -1.052755 · 10^-8`

Для швидкого й чисельно стабільного обчислення многочленів степеня `n` на мікроконтролерах без FPU використовують **схему Горнера** (англ. *Horner's method*), яка зводить обчислення до `n` множень і `n` додавань без зведення у степінь:

```
P(x) = d_0 + x · (d_1 + x · (d_2 + x · (... + x · d_n)...))
```

Нижче наведено повну реалізацію алгоритму цифрової компенсації холодного спаю для термопари типу K мовами C та ідіоматичною C++.

```c
/* cjc_thermocouple_k.h / .c */
#include <stdbool.h>
#include <math.h>

typedef struct {
    float temperature_c;
    bool is_valid;
} cjc_result_t;

/* Пряме перетворення NIST ITS-90: T (°C) -> E (мВ) для опорного спаю */
float nist_type_k_temp_to_mv(float temp_c) {
    if (temp_c < 0.0f) {
        /* Піддіапазон -200 °C ... 0 °C */
        const float c[] = {
            0.0f, 3.945013e-2f, 2.362237e-5f, -3.285891e-7f,
            -4.990483e-9f, -6.750906e-11f, -5.741032e-13f, -3.108894e-15f,
            -1.045161e-17f, -1.988927e-20f
        };
        float mv = c[9];
        for (int i = 8; i >= 0; --i) {
            mv = mv * temp_c + c[i];
        }
        return mv;
    } else {
        /* Піддіапазон 0 °C ... 1372 °C */
        const float c[] = {
            -1.7600413686e-2f, 3.8921204975e-2f, 1.8558770032e-5f,
            -9.9457592874e-8f, 3.1840945719e-10f, -5.6072844889e-13f,
            5.6075059059e-16f, -3.2020720003e-19f, 9.7151147152e-23f,
            -1.2104721275e-26f
        };
        float mv = c[9];
        for (int i = 8; i >= 0; --i) {
            mv = mv * temp_c + c[i];
        }
        /* Експоненційна корекція сплаву нікелю */
        const float a0 = 0.1185976f;
        const float a1 = -1.183432e-4f;
        const float a2 = 126.9686f;
        float diff = temp_c - a2;
        mv += a0 * expf(a1 * diff * diff);
        return mv;
    }
}

/* Зворотне перетворення NIST ITS-90: E_total (мВ) -> T_hot (°C) */
float nist_type_k_mv_to_temp(float mv) {
    if (mv < 0.0f) {
        /* Діапазон -200 °C ... 0 °C (-5.891 мВ ... 0 мВ) */
        const float d[] = {
            0.0f, 2.5173462e1f, -1.1662878f, -1.0833638f,
            -8.9773540e-1f, -3.7342377e-1f, -8.6632643e-2f, -1.0450598e-2f,
            -5.1920577e-4f
        };
        float t = d[8];
        for (int i = 7; i >= 0; --i) {
            t = t * mv + d[i];
        }
        return t;
    } else if (mv <= 20.644f) {
        /* Діапазон 0 °C ... 500 °C (0 мВ ... 20.644 мВ) */
        const float d[] = {
            0.0f, 2.508355e1f, 7.860106e-2f, -2.503131e-1f,
            8.315270e-2f, -1.228034e-2f, 9.804036e-4f, -4.413030e-5f,
            1.057734e-6f, -1.052755e-8f
        };
        float t = d[9];
        for (int i = 8; i >= 0; --i) {
            t = t * mv + d[i];
        }
        return t;
    } else {
        /* Діапазон 500 °C ... 1372 °C (20.644 мВ ... 54.886 мВ) */
        const float d[] = {
            -1.318058e2f, 4.830222e1f, -1.646031f, 5.464731e-2f,
            -9.650715e-4f, 8.802193e-6f, -3.110810e-8f
        };
        float t = d[6];
        for (int i = 5; i >= 0; --i) {
            t = t * mv + d[i];
        }
        return t;
    }
}

/* Повний конвеєр цифрової компенсації холодного спаю */
cjc_result_t thermocouple_k_calculate(float v_meas_mv, float t_cjc_c) {
    cjc_result_t res = {0.0f, false};

    /* Перевірка допустимого діапазону температури плати (-40...+125 °C) */
    if (t_cjc_c < -40.0f || t_cjc_c > 125.0f) {
        return res;
    }

    /* Крок 1 і 2: Розрахунок ЕРС опорного спаю за ITS-90 */
    float v_cjc_mv = nist_type_k_temp_to_mv(t_cjc_c);

    /* Крок 3: Складання потенціалів */
    float v_total_mv = v_meas_mv + v_cjc_mv;

    /* Перевірка виходу за межі шкали типу K (-5.891 мВ ... 54.886 мВ) */
    if (v_total_mv < -5.891f || v_total_mv > 54.886f) {
        return res;
    }

    /* Крок 4: Зворотне перетворення сумарної ЕРС у T_hot */
    res.temperature_c = nist_type_k_mv_to_temp(v_total_mv);
    res.is_valid = true;
    return res;
}
```

```cpp
/* cjc_thermocouple_k.hpp */
#include <array>
#include <cmath>
#include <expected>
#include <span>

namespace sensing {

enum class SensorError {
    ColdJunctionOutOfRange,
    VoltageOutOfRange,
    HardwareFault
};

struct Celsius {
    float value;
    constexpr explicit Celsius(float v = 0.0f) : value(v) {}
    constexpr auto operator<=>(const Celsius&) const = default;
};

struct Millivolts {
    float value;
    constexpr explicit Millivolts(float v = 0.0f) : value(v) {}
    constexpr auto operator<=>(const Millivolts&) const = default;
};

class NistTypeK {
public:
    /* Пряме перетворення: T_cjc -> V_cjc */
    [[nodiscard]] static constexpr Millivolts temp_to_mv(Celsius temp) noexcept {
        const float t = temp.value;
        if (t < 0.0f) {
            constexpr std::array<float, 10> c = {
                0.0f, 3.945013e-2f, 2.362237e-5f, -3.285891e-7f,
                -4.990483e-9f, -6.750906e-11f, -5.741032e-13f, -3.108894e-15f,
                -1.045161e-17f, -1.988927e-20f
            };
            return Millivolts(evaluate_horner(c, t));
        } else {
            constexpr std::array<float, 10> c = {
                -1.7600413686e-2f, 3.8921204975e-2f, 1.8558770032e-5f,
                -9.9457592874e-8f, 3.1840945719e-10f, -5.6072844889e-13f,
                5.6075059059e-16f, -3.2020720003e-19f, 9.7151147152e-23f,
                -1.2104721275e-26f
            };
            float mv = evaluate_horner(c, t);
            constexpr float a0 = 0.1185976f;
            constexpr float a1 = -1.183432e-4f;
            constexpr float a2 = 126.9686f;
            const float diff = t - a2;
            mv += a0 * std::exp(a1 * diff * diff);
            return Millivolts(mv);
        }
    }

    /* Зворотне перетворення: V_total -> T_hot */
    [[nodiscard]] static constexpr Celsius mv_to_temp(Millivolts mv) noexcept {
        const float v = mv.value;
        if (v < 0.0f) {
            constexpr std::array<float, 9> d = {
                0.0f, 2.5173462e1f, -1.1662878f, -1.0833638f,
                -8.9773540e-1f, -3.7342377e-1f, -8.6632643e-2f, -1.0450598e-2f,
                -5.1920577e-4f
            };
            return Celsius(evaluate_horner(d, v));
        } else if (v <= 20.644f) {
            constexpr std::array<float, 10> d = {
                0.0f, 2.508355e1f, 7.860106e-2f, -2.503131e-1f,
                8.315270e-2f, -1.228034e-2f, 9.804036e-4f, -4.413030e-5f,
                1.057734e-6f, -1.052755e-8f
            };
            return Celsius(evaluate_horner(d, v));
        } else {
            constexpr std::array<float, 7> d = {
                -1.318058e2f, 4.830222e1f, -1.646031f, 5.464731e-2f,
                -9.650715e-4f, 8.802193e-6f, -3.110810e-8f
            };
            return Celsius(evaluate_horner(d, v));
        }
    }

    /* Канонічний конвеєр CJC із контролем меж і поверненням std::expected */
    [[nodiscard]] static std::expected<Celsius, SensorError> calculate(
        Millivolts v_meas,
        Celsius t_cjc) noexcept
    {
        if (t_cjc.value < -40.0f || t_cjc.value > 125.0f) {
            return std::unexpected(SensorError::ColdJunctionOutOfRange);
        }

        const auto v_cjc = temp_to_mv(t_cjc);
        const auto v_total = Millivolts(v_meas.value + v_cjc.value);

        if (v_total.value < -5.891f || v_total.value > 54.886f) {
            return std::unexpected(SensorError::VoltageOutOfRange);
        }

        return mv_to_temp(v_total);
    }

private:
    /* Чисельно стабільна схема Горнера */
    template <std::size_t N>
    [[nodiscard]] static constexpr float evaluate_horner(
        const std::array<float, N>& coeff,
        float x) noexcept
    {
        float result = coeff[N - 1];
        for (std::size_t i = N - 1; i > 0; --i) {
            result = result * x + coeff[i - 1];
        }
        return result;
    }
};

} // namespace sensing
```

### Практичний інженерний чеклист розробника

Під час проектування надійного вимірювального тракту термопари дотримуйтеся семи правил, перевірених практикою:

1. **Ніколи не додавайте температури програмно.** Завжди перетворюйте температуру опорного спаю в еквівалентну термо-ЕРС `V_cjc`, додавайте її до виміряної напруги `V_meas` і лише потім застосовуйте зворотний поліном NIST ITS-90.
2. **Забезпечте ізотермічність клемника.** Обидві клеми та локальний термодатчик мають розташовуватися на суцільному мідному полігоні з масивом теплових отворів.
3. **Відокремте вимірювальну зону тепловими прорізами.** Прорізи в склотекстоліті відсікають гарячі потоки від стабілізаторів живлення та процесора.
4. **Обирайте фільтруючі ємності у правильній пропорції.** Диференційний конденсатор `C_diff` повинен бути щонайменше в 10 разів більшим за синфазні конденсатори `C_cm`, щоб запобігти трансформації синфазної завади в диференційну.
5. **Забезпечте шлях повернення струму зміщення для ізольованих термопар.** Для плаваючих зондів підтягніть вивід `IN-` через високоомний резистор (1...10 МОм) до опорного потенціалу.
6. **Застосовуйте гальванічну ізоляцію для заземлених спаїв.** Заземлені термопари створюють паразитні контури через різницю потенціалів землі промислового об'єкта та вимірювального приладу.
7. **Враховуйте теплову сталу часу конструкції.** За різких змін температури навколишнього середовища клемник і датчик нагріваються з різною швидкістю, що спричиняє динамічну похибку до стабілізації теплового режиму.
