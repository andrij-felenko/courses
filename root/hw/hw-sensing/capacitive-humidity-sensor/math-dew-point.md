# 🧮 Термодинаміка вологи: виведення рівнянь насиченої пари та точки роси

Вимірювання відносної вологості ємнісним давачем дає лише частку від максимально можливого вмісту пари при поточній температурі. Щоби знайти абсолютну масу води в повітрі чи передбачити температуру випадання конденсату (точку роси), інженер спирається на термодинамічні рівняння фазової рівноваги між рідкою водою та парою. Нижче наведено послідовне математичне виведення тиску насиченої пари, аналітичне обернення формули Магнуса для точки роси, розрахунок точки інею над льодом та визначення абсолютної вологості.

### 1. Термодинамічна рівновага та рівняння Клапейрона–Клаузіуса

Фазовий перехід першого роду (випаровування води або конденсація пари) відбувається за умови рівності питомих термодинамічних потенціалів Гіббса обох фаз: `g_liq(T, p) = g_vap(T, p)`. Диференціал енергії Гіббса визначається через питому ентропію `s` та питомий об'єм `v`:

```
dg = -s · dT + v · dp                              [диференціал потенціалу Гіббса]
-s_liq · dT + v_liq · dp = -s_vap · dT + v_vap · dp [умова рівноваги вздовж лінії фазового переходу]
(v_vap - v_liq) · dp_sat = (s_vap - s_liq) · dT    [групування диференціалів]
```

Зміна ентропії при ізотермічному оборотному фазовому переході дорівнює відношенню питомої теплоти пароутворення `L_v` до абсолютної температури `T`: `Δs = s_vap - s_liq = L_v / T`. Позначивши зміну питомого об'єму як `Δv = v_vap - v_liq`, отримуємо диференціальне рівняння Клапейрона–Клаузіуса:

```
dp_sat / dT = L_v / (T · Δv)                       [рівняння Клапейрона-Клаузіуса]
```

де `p_sat` — тиск насиченої водяної пари (Па), `T` — абсолютна температура (К), `L_v` — питома теплота пароутворення води (Дж/кг).

При тисках близько однієї атмосфери та температурах у діапазоні від −40 °C до +60 °C питомий об'єм пари `v_vap` на три-чотири порядки перевищує питомий об'єм рідкої води (при 20 °C `v_vap ≈ 58 м³/кг`, тоді як `v_liq ≈ 0.001 м³/кг`). Нехтуючи об'ємом рідини `Δv ≈ v_vap` і застосовуючи рівняння стану ідеального газу для водяної пари `p_sat · v_vap = R_v · T`, де `R_v = R / M_w = 8.31446 / 0.01801528 = 461.52 Дж/(кг·К)` — індивідуальна газова стала пари:

```
dp_sat / dT = (L_v · p_sat) / (R_v · T²)           [підстановка v_vap = R_v · T / p_sat]
d(ln p_sat) / dT = L_v(T) / (R_v · T²)             [диференціальна форма]
```

### 2. Температурна залежність теплоти випаровування та інтегрування Магнуса

Питома теплота випаровування спадає з температурою відповідно до закону Кірхгофа: `dL_v / dT = c_p,vap - c_p,liq = Δc_p`. Оскільки ізобарна теплоємність води `c_p,liq ≈ 4184 Дж/(кг·К)` значно вища за теплоємність пари `c_p,vap ≈ 1860 Дж/(кг·К)`, різниця `Δc_p ≈ -2324 Дж/(кг·К)` від'ємна:

```
L_v(T) = L_0 + Δc_p · (T - T_0)                   [лінійна температурна корекція теплоти]
```

Підстановка цього виразу в диференціал та аналітичне інтегрування дають розв'язок, що містить логарифмічний і гіперболічний члени. Німецький фізик Генріх Густав Магнус (Heinrich Gustav Magnus, 1844) запропонував раціональну апроксимацію ядра інтеграла `L_v(T) / (R_v · T²) ≈ (b · c) / (c + t)²`, де `t = T - 273.15` — температура в градусах Цельсія.

Інтегруючи від опорної точки потрійної точки води `t_0 = 0.01 °C` (на практиці `0 °C`):

```
∫ d(ln p_sat) = ∫ [ (b · c) / (c + t)² ] dt        [інтегрування від 0 до t]
ln(p_sat(t) / p_0) = [ -(b · c) / (c + t) ]_0^t    [первісна функція]
ln(p_sat(t) / p_0) = (b · c / c) - (b · c / (c + t))
ln(p_sat(t) / p_0) = (b · t) / (c + t)             [раціональний показник степеня]
p_sat(t) = p_0 · exp( (b · t) / (c + t) )          [класична формула Магнуса–Тетенса]
```

де `p_0 = 6.11213 гПа` — тиск насиченої пари над водою при 0 °C.

Коефіцієнти Магнуса залежать від фазового стану конденсованої поверхні (вода або лід):

1. **Над рідкою водою (температура t ≥ 0 °C або переохолоджена вода до −40 °C):**
   - Константи Зоннтага (Sonntag, 1990 / WMO): `p_0 = 6.112 гПа`, `b = 17.62`, `c = 243.12 °C`.
   - Уточнені константи Ардена Бака (Arden Buck, 1981): `p_0 = 6.1121 гПа`, `b = 17.502`, `c = 240.97 °C`.
2. **Над плоским льодом (сублімація пари при t < 0 °C):**
   - Питома теплота сублімації `L_sub = L_v + L_fus ≈ 2.83 МДж/кг` вища за теплоту випаровування на величину теплоти плавлення льоду `L_fus ≈ 0.334 МДж/кг`.
   - Константи для льоду (Sonntag / WMO): `p_0 = 6.1115 гПа`, `b_ice = 22.46`, `c_ice = 272.62 °C`.

### 3. Фактор підсилення реального повітря (Enhancement Factor)

У реальній атмосфері повітря є бінарною сумішшю сухих газів (N₂, O₂, Ar, CO₂) і водяної пари під барометричним тиском `P`. Через неідеальність газу та ефект Пойнтінга (Poynting effect — стиснення рідини зовнішнім тиском нерозчинного газу) ефективний тиск насичення вологи `p_sat,air(T, P)` дещо перевищує тиск чистої водяної пари у вакуумі `p_sat(T)`:

```
p_sat,air(T, P) = f(P, T) · p_sat(T)               [тиск насичення у вологому повітрі]
```

де `f(P, T)` — безрозмірний фактор підсилення (enhancement factor), який за формулою Ардена Бака визначається як:

```
f(P, T) = 1.0007 + (3.46 · 10⁻⁶ · P) + (1.2 · 10⁻⁸ · P · T²) [для тиску P у гПа]
```

При стандартному атмосферному тиску `P = 1013.25 гПа` і кімнатній температурі `f(P, T) ≈ 1.0042`. Тобто повітря містить на 0.42 % більше пари в стані насичення, ніж чистий ізольований пар. У більшості промислових сенсорів цією поправкою можна знехтувати, але вона критична в барокамерах високого тиску та висотній авіаційній метеорології.

### 4. Парціальний тиск і аналітичне виведення точки роси

Відносна вологість `RH` (%) за фізичним означенням є відношенням парціального тиску наявної в повітрі водяної пари `e` до максимально можливого тиску насиченої пари `p_sat(T)` при тій самій температурі сухого термометра `T`:

```
RH = 100 · (e / p_sat(T))                          [означення відносної вологості, %]
e = (RH / 100) · p_sat(T)                          [парціальний тиск пари]
e = (RH / 100) · p_0 · exp( (b · T) / (c + T) )    [підстановка формули Магнуса]
```

**Точка роси (`T_dew`)** — це температура, до якої потрібно охолодити повітря без зміни загального тиску та абсолютної кількості пари, щоби наявний парціальний тиск `e` став тиском насичення: `e = p_sat(T_dew)`.

Прирівняємо обидва вирази:

```
p_0 · exp( (b · T_dew) / (c + T_dew) ) = (RH / 100) · p_0 · exp( (b · T) / (c + T) )
exp( (b · T_dew) / (c + T_dew) ) = (RH / 100) · exp( (b · T) / (c + T) )
(b · T_dew) / (c + T_dew) = ln(RH / 100) + (b · T) / (c + T)
```

Введемо нормовану логарифмічну змінну вологоємності `γ(T, RH)`:

```
γ(T, RH) = ln(RH / 100) + (b · T) / (c + T)       [безрозмірний фактор вологості]
```

Розв'яжемо отримане нелінійне рівняння відносно шуканої температури `T_dew`:

```
(b · T_dew) / (c + T_dew) = γ                      [алгебраїчне рівняння]
b · T_dew = γ · (c + T_dew)                        [множення на знаменник]
b · T_dew = γ · c + γ · T_dew                      [розкриття дужок]
T_dew · (b - γ) = c · γ                            [перенесення членів з T_dew ліворуч]
T_dew = (c · γ) / (b - γ)                          [точний аналітичний розв'язок точки роси]
```

### 5. Точка інею (Frost Point) над льодом

При від'ємних температурах (`T < 0 °C`) фазовий перехід може відбуватися двома шляхами:
1. Конденсація в переохолоджену рідку воду (метастабільний стан, який зберігається у хмарах та на гладких неполярних поверхнях до −20…−40 °C). Розрахунок ведеться за стандартною формулою точки роси `T_dew`.
2. Пряма десублімація пари у тверді кристали льоду (точка інею, `T_frost`). Оскільки тиск насичення над льодом нижчий, ніж над переохолодженою водою (`p_sat,ice(T) < p_sat,water(T)`), точка інею завжди лежить вище точки роси: `T_frost > T_dew` при `T < 0 °C`.

Для розрахунку точки інею використовують константи сублімації льоду `b_ice = 22.46` та `c_ice = 272.62 °C`:

```
γ_frost(T, RH) = ln(RH / 100) + (b_ice · T) / (c_ice + T)
T_frost = (c_ice · γ_frost) / (b_ice - γ_frost)    [точка інею над льодом, °C]
```

### 6. Розрахунок абсолютної вологості, питомої вологості та коефіцієнта змішування

Абсолютна вологість `d_v` визначає фізичну масу водяної пари в одному кубічному метрі повітряного простору (г/м³). З рівняння стану газу Менделєєва–Клапейрона:

```
e · V = (m_w / M_w) · R · T_k                      [рівняння стану для маси пари m_w]
d_v = m_w / V = (e · M_w) / (R · T_k)              [густина водяної пари, кг/м³]
```

де `e` — парціальний тиск пари (Па, де `1 гПа = 100 Па`), `M_w = 0.01801528 кг/моль`, `R = 8.31446 Дж/(моль·К)`, `T_k = T + 273.15` — абсолютна температура в Кельвінах.

Переведемо величини у практичні інженерні одиниці (`e` у гПа, `d_v` у г/м³):

```
k_v = (M_w · 100 Па/гПа · 1000 г/кг) / R           [масштабний коефіцієнт]
k_v = (0.01801528 · 100000) / 8.31446 = 216.679 г·К / (м³·гПа)
d_v(T, RH) = 216.7 · e / (T + 273.15)              [абсолютна вологість, г/м³]
```

Супутні метеорологічні параметри:
- **Коефіцієнт змішування (Mixing Ratio) `r` (г/кг):** Маса водяної пари на один кілограм сухого повітря:

```
r = 622.0 · e / (P - e)                            [коефіцієнт змішування, г/кг]
```

де `622.0 = 1000 · (M_w / M_air) = 1000 · (18.015 / 28.965)` — відношення молярних мас, а `P` — повний барометричний тиск атмосфери (гПа).

- **Питома вологість (Specific Humidity) `q` (г/кг):** Маса пари до загальної маси вологого повітря:

```
q = 622.0 · e / (P - 0.378 · e)                    [питома вологість, г/кг]
```

### 7. Порівняльний аналіз похибок моделей

Міжнародний стандарт формулювання властивостей води IAPWS-95 базується на рівнянні Гельмгольца високого порядку з 56 поліноміальними коефіцієнтами. Порівняння спрощених моделей з еталоном IAPWS-95 у діапазоні від −40 °C до +60 °C показує такі результати:

| Модель | Формула p_sat(T) | Похибка p_sat при 20 °C | Макс. похибка T_dew (−20..+50 °C) | Витрати пам'яті MCU |
|---|---|---|---|---|
| **Магнус–Тетенса (Sonntag)** | `6.112 · exp(17.62·T / (243.12+T))` | 0.04 % | ±0.08 °C | 1 виклик `exp`, 1 `ln` |
| **Арден Бак (1981)** | `6.1121 · exp(17.502·T / (240.97+T))` | 0.01 % | ±0.03 °C | 1 виклик `exp`, 1 `ln` |
| **Поліном Гоффа–Гратча** | 6-членний логарифмічний ряд | 0.005 % | ±0.01 °C | 6 множень, 2 логарифми |
| **IAPWS-95 (Еталон)** | Вільна енергія Гельмгольца | 0.000 % (еталон) | 0.00 °C | Десятки кілобайтів коду |

Оскільки апаратна похибка найкращих промислових ємнісних сенсорів (наприклад, Sensirion SHT45) становить `±1.0 % RH` (що еквівалентно невизначеності точки роси близько `±0.2 °C`), похибка моделі Магнуса–Зоннтага (`0.08 °C`) є більш ніж достатньою для всіх завдань вбудованої кліматичної електроніки і не вимагає перевантаження мікроконтролера складними термодинамічними таблицями.
