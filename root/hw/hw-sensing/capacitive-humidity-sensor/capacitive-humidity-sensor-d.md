Водяна пара в навколишньому повітрі невидима для ока і не змінює тиск атмосфери настільки, щоб це можна було зафіксувати звичайним мембранним манометром: навіть у насиченому вологою тропічному повітрі при 30 °C парціальний тиск пари становить лише близько 42 гектопаскалів із загальних 1013 гПа. Механічні прилади минулого століття реєстрували розбухання пучків знежиреного кінського волосу, а оптичні станції охолоджували дзеркало до моменту появи конденсату. Проте вбудованій мікроелектроніці потрібен інший підхід: перетворювач розміром з міліметрову крихту, здатний перетворювати концентрацію молекул води на електричну величину без рухомих важелів, з часом відгуку в лічені секунди та енергоспоживанням у мікровати.

Таким перетворювачем став ємнісний сенсор вологості. Його робота базується на фундаментальній властивості молекули води: колосальному електричному дипольному моменті, завдяки якому діелектрична проникність рідкої води досягає вісімдесяти одиниць. Розмістивши між перфорованими металевими електродами шар гігроскопічного полімеру завтовшки всього один-два мікрометри, інженери отримали конденсатор, ємність якого прямо пропорційна кількості поглинутої вологи. Проте сам по собі полімер «не знає», яка вологість у кімнаті, доки вимірювання не скомпенсоване прецизійним термометром, розташованим на тому ж кремнієвому кристалі.

### Фізико-хімічний механізм: поляризація та діелектричний стрибок

Здатність ємнісного давача реагувати на вологу випливає з молекулярної будови води. Молекула H₂O має асиметричну кутову конфігурацію з кутом між зв'язками O–H близько 104.5°. Висока електронегативність атома кисню зміщує електронну густину від протонів водню, створюючи постійний дипольний момент `p ≈ 1.85 Дебая` (`6.17 · 10⁻³⁰ Кл·м`).

Коли молекули води потрапляють у зовнішнє електричне поле, вони вільно орієнтуються вздовж його силових ліній. Ця орієнтаційна поляризація зумовлює надзвичайно високу відносну діелектричну проникність вільної рідкої води: `ε_water ≈ 80.4` при 20 °C. Для порівняння, сухі неполярні та слабкополярні інженерні полімери (поліімід, бутирацетат целюлози, полісилоксани), які використовуються як основа діелектрика сенсора, мають проникність лише `ε_polymer ≈ 3.0…3.8`.

```
C = ε_eff · ε_0 · A / d                             [ємність плоского конденсатора]
```

де `ε_0 = 8.854 · 10⁻¹² Ф/м` — електрична стала, `A` — робоча площа перекриття електродів, `d` — товщина полімерної плівки, а `ε_eff` — ефективна діелектрична проникність композиту «полімерна матриця + поглинута вода».

![Орієнтаційна поляризація диполів води в полімерній матриці](/root/hw/hw-sensing/capacitive-humidity-sensor/img/dipole-polarization.svg)
*Орієнтаційна поляризація диполів води. Постійний дипольний момент молекул води (1.85 D, ε ≈ 80) значно перевищує діелектричну проникність сухої полімерної сітки (ε ≈ 3.5).*

Поглинання пари полімером підпорядковується законам сорбції та складається з кількох послідовних фізичних фаз:
1. **Область мономолекулярної сорбції (RH < 20 %):** Поодинокі молекули води дифундують у полімер і зв'язуються водневими зв'язками з полярними імізольними та карбонільними групами полімерного скелета за законом Генрі. У цьому стані молекули води частково затиснені в полімерній сітці (bound water), тому їхня діелектрична проникність дещо нижча за вільну воду (`ε_bound ≈ 30…40`), але все одно на порядок вища за проникність чистого полімеру.
2. **Область полімолекулярного заповнення (20 % < RH < 75 %):** Молекули води починають зв'язуватися не лише з полімером, але й одна з одною, утворюючи рухливі дипольні ланцюжки та кластери з високою поляризовністю (`ε ≈ 70…80`).
3. **Область капілярної конденсації (RH > 75 %):** Вода заповнює вільні мікропори матриці у вигляді квазірідкої фази, викликаючи максимальне зростання ємності та незначне розбухання об'єму плівки.

Ефективна діелектрична проникність такого середовища добре описується формулою Лооєнга (Looyenga) для гетерогенних сумішей:

```
(ε_eff)^(1/3) = (1 - V_w) · (ε_polymer)^(1/3) + V_w · (ε_water)^(1/3)
```

де `V_w` — об'ємна частка поглинутої води в матриці полімеру.

Оскільки `(ε_water)^(1/3) ≈ (80)^(1/3) ≈ 4.31`, а `(ε_polymer)^(1/3) ≈ (3.5)^(1/3) ≈ 1.52`, навіть мале збільшення частки води `V_w` від 0 до 5 % викликає різке зростання `ε_eff` від 3.5 до 4.5. У результаті базова ємність сенсора `C_0` (яка зазвичай становить від 10 до 50 пФ) при зміні відносної вологості від 0 % до 100 % RH отримує лінійний приріст `ΔC` на рівні 15–30 % від номіналу:

```
C(RH) ≈ C_0 · (1 + α_RH · RH)
```

де `α_RH` — коефіцієнт чутливості за вологою, що становить близько `0.002…0.0035` на кожен відсоток RH (`0.2…0.35 % / % RH`). Сенсор із базовою ємністю 20 пФ при зростанні вологості від сухого стану до насичення збільшує свою ємність до 24–26 пФ.

Частотна залежність діелектрика також має фундаментальне значення. Вільна вода має характерний час дебаївської релаксації `τ_rel ≈ 8 пс` (частота релаксації близько 20 ГГц). Усередині полімеру обертання диполів сповільнюється водневими зв'язками, і спад діелектричної проникності починається на частотах вище 10–50 МГц. Тому аналогові вимірювальні тракти ємнісних давачів працюють на частотах від 10 кГц до 1 МГц: у цьому діапазоні диполі води встигають повністю переорієнтовуватися за полем, забезпечуючи максимальну амплітуду корисного сигналу, тоді як повільна іонна провідність бруду частково фільтрується.

### Анатомія сенсорної комірки на кристалі

Щоб молекули пари могли безперешкодно потрапляти всередину діелектрика, класична конструкція конденсатора з двох суцільних металевих пластин не підходить: суцільний метал заблокував би газообмін.

Сенсорну комірку вирощують безпосередньо на кремнієвій підкладці методом мікроелектронного напилення тонких плівок. Сенсорний стек складається з кількох функціональних шарів:

1. **Кремнієва основа (Si substrate):** Монокристалічна підкладка, на якій розміщено решту аналогової КМОН-схеми, прецизійний термометр та вбудований полікремнієвий нагрівач.
2. **Пасиваційний діелектрик (SiO₂ / Si₃N₄):** Шар термічного оксиду кремнію завтовшки 0.5–1 мкм, що електрично ізолює нижній електрод від напівпровідникового кристала та усуває витоки струму.
3. **Нижній суцільний електрод:** Плівка платини (Pt), титану (Ti) або алюмінію (Al) товщиною 100–200 нм. Платина переважає через абсолютну хімічну пасивність та відсутність оксидних плівок, які могли б додати паразитну послідовну ємність.
4. **Гігроскопічний діелектрик:** Плівка полііміду або зшитого бутирацетату целюлози завтовшки `d = 1.0…1.5 мкм`. Товщина обирається як суворий компроміс між абсолютною величиною ємності (чим тонший шар, тим більша `C_0`) та електричною міцністю проти пробою при електростатичних розрядах (ESD).
5. **Верхній пористий електрод:** Шар благородного металу (золота або платини) нанометрової товщини (`15…30 нм`). При такому напиленні метал утворює не суцільну плівку, а колоїдну сітку з мікропорами діаметром від одиниць до десятків нанометрів. Цей шар проводить електричний струм, але залишається прозорим для молекул водяної пари.

![Будова ємнісної сенсорної комірки на кристалі](/root/hw/hw-sensing/capacitive-humidity-sensor/img/cross-section.svg)
*Будова ємнісної сенсорної комірки на кристалі. Верхній пористий електрод пропускає пару всередину полімерного діелектрика, викликаючи зміну діелектричної проникності та ємності.*

Поряд із сендвіч-структурою часто застосовують гребінчасті зустрічно-штирьові електроди (Interdigitated Electrodes, IDE), розміщені в одній площині. Полімер заливають поверх планарних металевих гребінців. Така структура не потребує пористого верхнього шару, оскільки пара заходить у полімер прямо з відкритої поверхні, але має меншу питому ємність на одиницю площі кристала через те, що значна частина електричного поля замикається через підкладку.

Швидкість реакції сенсора на стрибок вологості визначається швидкістю дифузії води вглиб полімерної плівки. Відповідно до другого закону Фіка, одновимірний дифузійний процес описується рівнянням:

```
∂c / ∂t = D_w · (∂²c / ∂z²)                        [другий закон Фіка]
```

де `c(z, t)` — локальна концентрація води на глибині `z`, а `D_w` — коефіцієнт дифузії води в полімері (для ароматичних поліімідів `D_w ≈ 10⁻⁹…10⁻⁸ см²/с` при 25 °C).

Характерний час дифузійного встановлення рівноваги `τ` пов'язаний із товщиною плівки квадратичною залежністю:

```
τ ≈ d² / (π² · D_w)
```

Звідси стає зрозуміло, чому виробники прагнуть робити плівку якомога тоншою: при товщині `d = 1 мкм` час реакції сенсора на 63 % від фінального значення (`t_63%`) становить лише 2–4 секунди. Якби товщину збільшили до 10 мкм, час відгуку зріс би у 100 разів і перевищив би п'ять хвилин, перетворивши динамічний вимірювальний прилад на вкрай інерційний реєстратор.

У реальних умовах загальний час відгуку також лімітується аеродинамічним приграничним шаром повітря над корпусом сенсора. У нерухомому повітрі товщина нерухомого ламінарного шару сягає кількох міліметрів, уповільнюючи відгук до 20–30 секунд. Легкий потік повітря (обдув зі швидкістю понад 1 м/с) зриває приграничний шар, повертаючи швидкодію до власної дифузійної межі полімеру.

Детальніше про те, як інженери пройшли шлях від кінського волосу де Соссюра до першого комерційного тонкоплівкового полімерного сенсора Humicap, викладено в [історичному розвитку гігрометрії](root:hw-sensing/capacitive-humidity-sensor/hist-hygrometry.md).

### Психрометрія: Відносна вологість, абсолютна вологість і тиск насичення

Ємнісний сенсор принципово вимірює не загальну масу води в приміщенні, а **відносну вологість** (Relative Humidity, % RH). Щоби зрозуміти цю відмінність, необхідно чітко розділити ключові метеорологічні величини:

1. **Парціальний тиск водяної пари `e` (гПа або Па):** Частина загального атмосферного тиску, яку створюють молекули води в повітряній суміші відповідно до закону Дальтона (`P_total = P_dry + e`).
2. **Тиск насиченої водяної пари `e_sat(T)` (гПа):** Максимально можливий рівноважний тиск пари над плоскою поверхнею рідкої води за поточної температури `T`. Якщо парціальний тиск намагається перевищити `e_sat`, надлишок пари конденсується в туман або краплі роси.
3. **Відносна вологість `RH` (%):** Відношення наявного парціального тиску пари до тиску насичення при поточній температурі:

```
RH = 100 · (e / e_sat(T))                           [відносна вологість, %]
```

Тиск насиченої пари експоненційно зростає з температурою за рівнянням Клапейрона–Клаузіуса. Для практичних розрахунків застосовують рівняння Магнуса–Тетенса з константами Зоннтага (WMO):

```
e_sat(T) = 6.112 · exp( (17.62 · T) / (243.12 + T) ) [гПа, де T у °C]
```

При температурі 0 °C тиск насичення становить лише 6.11 гПа (повітря здатне утримати не більше 4.8 г води в одному кубічному метрі). При 20 °C тиск насичення зростає до 23.38 гПа (максимум 17.3 г/м³), а при 30 °C сягає 42.43 гПа (30.4 г/м³).

![Крива тиску насиченої пари та визначення точки роси](/root/hw/hw-sensing/capacitive-humidity-sensor/img/psychrometric-curve.svg)
*Крива тиску насиченої пари та проєкція точки роси. Охолодження повітря за сталого парціального тиску веде до точки B, де відносна вологість сягає 100 % і починається конденсація.*

Чому полімерний давач реагує саме на % RH, а не на абсолютну густину води? Полімер і навколишнє повітря перебувають у стані термодинамічної хімічної рівноваги. Рушійною силою фазового переходу та дифузії є не абсолютна концентрація молекул у повітрі, а хімічний потенціал пари, або її термодинамічна **активність** `a_w`:

```
a_w = e / e_sat(T) = RH / 100
```

Якщо герметично закрити термокамеру зі сталою абсолютною масою вологи (наприклад, 10 г/м³) й почати нагрівати повітря від 20 °C до 35 °C, маса води в кожному кубічному метрі залишиться абсолютно незмінною. Проте тиск насичення `e_sat` зросте з 23.4 гПа до 56.2 гПа. Активність води `a_w` впаде більше ніж удвічі, молекули води почнуть десорбуватися з полімерної плівки назад у повітря, і ємність сенсора зменшиться рівно пропорційно падінню відносної вологості з 58 % до 24 % RH.

Повний термодинамічний аналіз, поправки Ардена Бака для вологого повітря під високим тиском та виведення формул переведення у вагові одиниці (г/м³) наведено у [виведенні термодинамічних рівнянь точки роси](root:hw-sensing/capacitive-humidity-sensor/math-dew-point.md).

### Температурний дрейф і необхідність ко-інтеграції

Жоден ємнісний сенсор вологості не може працювати як ізольований прилад: точне вимірювання вологості фізично неможливе без одночасного прецизійного вимірювання температури безпосередньо в точці контакту полімеру з повітрям.

На вихідний сигнал ємнісної комірки одночасно накладаються два супутні температурні фактори:

1. **Власний температурний коефіцієнт діелектрика (TKC):** Зі зростанням температури полімерна плівка зазнає теплового об'ємного розширення (товщина `d` зростає, зменшуючи геометричну ємність `C = ε · A / d`), а тепловий хаотичний рух заважає ідеальній орієнтації диполів у полі відповідно до функції Ланжевена–Дебая. Сумарний температурний дрейф сухої комірки становить близько `-0.05…-0.15 % RH / °C`.
2. **Зміна сорбційної рівноваги:** Сорбція води в полімер є екзотермічним процесом (виділяється теплота гідратації). За принципом Ле Шательє при підвищенні температури рівновага зміщується в бік десорбції, змінюючи крутизну калібрувальної характеристики.

Якщо кристал нагріється всього на 1.0 °C відносно навколишнього повітря (наприклад, через тепловиділення сусіднього процесора, стабілізатора напруги LDO або через завищену частоту опитування сенсора), температура мікрооб'єму повітря біля полімеру зросте, локальний тиск насичення `e_sat` стрибне вгору, і давач покаже хибно занижену вологість. При кімнатній температурі помилка вимірювання температури на 1 °C призводить до систематичної похибки вимірювання вологості на `5…6 % RH`.

З цієї причини в сучасних сенсорних чипах (Sensirion SHT4x, TI HDC1080, Bosch BME280) первинний ємнісний перетворювач і напівпровідниковий термометр виготовляють на єдиному кремнієвому кристалі в безпосередній близькості (на відстані кількох десятків мікрометрів).

Як термометр інтегрують прецизійне джерело струму, пропорційного абсолютній температурі (Proportional To Absolute Temperature, PTAT на біполярних транзисторах у КМОН-базисі). Термометр забезпечує похибку менше `±0.1…±0.2 °C`. Внутрішній цифровий сигнальний процесор (DSP) чипа використовує поточну температуру для апаратної компенсації сигналу ємності за поліномом другого порядку:

```
RH_compensated = RH_raw + (T_measured - 25.0) · (k_1 + k_2 · RH_raw)
```

де `k_1` та `k_2` — індивідуальні калібрувальні сталі, записані в заводську одноразово програмовану пам'ять (OTP ROM) кристала під час лазерного підганяння на фабриці.

### Деградація, гістерезис і вбудований імпульсний нагрівач

Робота відкритого полімерного діелектрика в реальних умовах експлуатації пов'язана з фізичними та хімічними чинниками старіння:

#### 1. Гістерезис вологості
При циклічній зміні вологості від сухого повітря до 100 % RH і назад крива десорбції не збігається з кривою сорбції. Різниця показів при тому самому значенні вологості (гістерезис) становить близько `1.0…1.5 % RH`. Механізм обумовлений в'язкопружною релаксацією полімерних макромолекул: поглинаючи воду, полімер повільно розсуває ланцюги, а при висиханні затримує вихід води через капілярні сили в нанопорах.

#### 2. Забруднення леткими органічними сполуками (VOC)
Полімерна плівка здатна абсорбувати не лише молекули води, але й пари органічних розчинників (ізопропанол, ацетон, толуол), пластифікатори з пластикових корпусів приладів та леткі залишки флюсів після паяння друкованої плати. Органічні молекули блокують полярні центри зв'язування води, викликаючи тривалий повзучий дрейф нульової точки (до `+5…+10 % RH` зміщення базової лінії).

#### 3. Конденсація та залипання сенсора (Sensor Lockout)
Якщо температура повітря падає нижче точки роси, на відкритій мембрані випадає рідка вода. Тонка водяна плівка має `ε ≈ 80` і високу провідність через розчинений пил. Ємність стрибкоподібно зростає до максимуму, перевантажуючи аналоговий тракт. У такому стані сенсор «залипає на 100 % RH» і може відновлюватися годинами навіть після зниження вологості.

![Архітектура інтегрованого кристала цифрового давача](/root/hw/hw-sensing/capacitive-humidity-sensor/img/sensor-architecture.svg)
*Архітектура інтегрованого кристала цифрового давача. Чутлива полімерна комірка поєднана з точним кристальним термометром PTAT, нагрівачем десорбції, аналоговим перетворювачем CDC та цифровим блоком компенсації.*

Для захисту від цих факторів у кристал інтегрують полікремнієвий нагрівальний резистор (Joule Micro-Heater). За командою з керуючого мікроконтролера нагрівач генерує тепловий імпульс потужністю від 20 до 200 мВт тривалістю від 100 мс до 1 с. Температура кристала короткочасно піднімається до 100–120 °C, що призводить до:
- Миттєвого скипання та випаровування крапель рідкої роси з пористого електрода;
- Термічної десорбції накопичених летких органічних сполук (процедура термовідпалу Reconditioning);
- Релаксації механічних напружень у полімерній плівці після тривалого перебування в середовищі з 95–100 % RH.

### Схемотехніка зчитування: Ємнісно-цифровий перетворювач (CDC)

Головний схемотехнічний виклик при роботі з ємнісним сенсором полягає в надзвичайно малому корисному сигналі. Базова ємність сенсора становить `C_0 ≈ 15 пФ`, а зміна вологості на 1 % RH генерує приріст ємності всього `ΔC ≈ 40 фФ` (`4 · 10⁻¹⁴ Ф`). При цьому паразитна ємність вивідних контактів, кристалотримача та монтажних доріжок може сягати 5–15 пФ, а паразитний опір витоку зменшується при високій вологості.

Для надійного перетворення таких малих величин на цифру безпосередньо на кристалі інтегрують сигма-дельта ємнісно-цифровий перетворювач (ΣΔ CDC) на перемиканих конденсаторах (Switched-Capacitor).

Принцип дії базується на диференційному переносі квантів заряду за двофазним тактовим розкладом (фази `Φ_1` та `Φ_2`). Сенсорний конденсатор `C_x` поперемінно підключається до опорної напруги `V_ref`, а потім розряджається в накопичувальний інтегратор:

```
Q = C_x · V_ref                                    [заряд сенсорної комірки]
```

Одночасно в протифазі інтегратор підключається до внутрішнього опорного конденсатора `C_ref`, виготовленого в тому ж шарі металізації, але герметично закритого суцільним шаром нітриду кремнію, куди пара проникнути не може. Схема інтегрує різницевий заряд:

```
ΔQ = (C_x - C_ref) · V_ref
```

Такий диференційний перенос заряду в поєднанні з корельованою подвійною вибіркою (Correlated Double Sampling, CDS) забезпечує повне придушення низькочастотного флікер-шуму (`1/f`), напруги зміщення (offset voltage) операційного підсилювача та паразитної ємності монтажу. Вихідний потік бітів сигма-дельта модулятора проходить через цифровий децимуючий фільтр (Sinc³), формуючи 16-бітне ціле число з роздільною здатністю до 0.01 % RH.

### Точка роси: розрахунок та інженерне застосування

Значення відносної вологості само по собі відносне: воно нічого не повідомляє про те, наскільки система близька до випадання конденсату в разі раптового похолодання. Головною термодинамічною характеристикою вологості в метеорології, промисловості та системах запобігання корозії є **точка роси** (Dew Point, `T_dew`).

Точка роси — це температура, до якої має охолонути повітря при незмінному барометричному тиску та сталій абсолютній масі вологи, щоб відносна вологість досягла 100 %.

Якщо температура будь-якої фізичної поверхні (стінки приладового боксу, оптичної лінзи, друкованої плати) опуститься нижче `T_dew`, на ній миттєво розпочнеться утворення конденсату.

Мікроконтролер обчислює точку роси за інвертованим рівнянням Магнуса на основі поточної виміряної температури `T` (°C) та відносної вологості `RH` (%):

```
γ(T, RH) = ln(RH / 100) + (17.62 · T) / (243.12 + T)
T_dew = (243.12 · γ) / (17.62 - γ)                  [точка роси, °C]
```

Різниця `ΔT = T - T_dew` називається **дефіцитом точки роси**. Вона є прямим інженерним критерієм надійності:
- Якщо `ΔT > 5 °C` — вологість безпечна, конденсація на платі виключена;
- Якщо `ΔT < 2 °C` — зона підвищеного ризику, необхідне увімкнення локального підігріву корпусу або вентиляції;
- Якщо `ΔT ≤ 0 °C` — досягнуто точки роси, триває активне випадання рідкого конденсату.

### Порівняння технологій вимірювання вологості

У сучасній вимірювальній техніці поряд із ємнісними полімерними сенсорами застосовують інші фізичні принципи:

1. **Ємнісні тонкоплівкові сенсори (розглянуті тут):** Займають понад 85 % ринку вбудованої електроніки, IoT, смартфонів та автомобільного клімат-контролю завдяки лінійній передавальній функції, широкому діапазону (0…100 % RH), стійкості до замерзання та мікропотужному споживанню.
2. **Резистивні сенсори вологості (гігрорезистори):** Базуються на зміні провідності гігроскопічних електролітів чи струмопровідних полімерів через рухливість гідратованих іонів. Мають експоненційну передавальну характеристику (опір падає від 10 МОм до 1 кОм), втрачають чутливість при вологості нижче 20 % RH і деградують при контакті з рідким конденсатом.
3. **Психрометричний метод (сухий і мокрий термометри):** Класичний метеорологічний метод. Потребує постійного запасу дистильованої води, заміни бавовняного ґнота та потужного аспіраційного вентилятора; не підходить для мініатюрних автономних пристроїв.
4. **Конденсаційні гігрометри з охолоджуваним дзеркалом (Chilled Mirror):** Еталонні метрологічні прилади найвищої точності (похибка точки роси менше ±0.1 °C). Містять термоелектричний модуль Пельтьє, оптичний випромінювач та фотодетектор. Дорогі, громіздкі та енергоємні.

### Метрологічне калібрування: сольові еталони

Для перевірки точності та повторного калібрування ємнісних сенсорів в польових умовах застосовують метод насичених водних розчинів неорганічних солей у герметичних ємностях (ASTM E104). При фіксованій температурі термодинамічна рівновага над дзеркалом насиченого сольового розчину створює суворо фіксовану відносну вологість:

- Хлорид літію (LiCl): `11.3 ± 0.3 % RH` при 25 °C (нижня калібрувальна точка);
- Хлорид магнію (MgCl₂): `32.8 ± 0.2 % RH` при 25 °C;
- Хлорид натрію (NaCl): `75.3 ± 0.1 % RH` при 25 °C (середня опорна точка);
- Сульфат калію (K₂SO₄): `97.3 ± 0.5 % RH` при 25 °C (точка насичення).

Витримка сенсора в парах LiCl та NaCl протягом 4–6 годин дозволяє виконати двоточкове калібрування коефіцієнтів зміщення нуля (Offset) та крутизни (Gain) без використання дорогих кліматичних камер.

### Програмний інтерфейс і взаємодія з мікроконтролером

Сучасні цифрові давачі вологості (наприклад, Sensirion SHT40/SHT45 чи TI HDC1080) взаємодіють з хост-контролером по цифровій шині I²C на швидкості від 100 кГц (Standard Mode) до 1 МГц (Fast Mode Plus).

Кожна транзакція зчитування захищена апаратним циклічним надлишковим кодом CRC-8, що запобігає проникненню спотворених даних в алгоритми керування мікрокліматом при роботі в зашумлених промислових середовищах.

Нижче наведено компактний приклад обробки даних сенсора та розрахунку точки роси мовами C та C++:

```c
#include <stdint.h>
#include <stdbool.h>
#include <math.h>

// Структура виміряних параметрів мікроклімату
typedef struct {
    float temperature_c;     // Температура повітря, °C
    float relative_humidity; // Відносна вологість, % RH
    float dew_point_c;       // Розрахована точка роси, °C
} climate_sample_t;

// Обчислення точки роси за формулою Магнуса
float calculate_dew_point(float temp_c, float rh_pct) {
    const float b = 17.62f;
    const float c = 243.12f;
    if (rh_pct < 0.1f) rh_pct = 0.1f;
    if (rh_pct > 100.0f) rh_pct = 100.0f;
    
    float gamma = logf(rh_pct / 100.0f) + (b * temp_c) / (c + temp_c);
    return (c * gamma) / (b - gamma);
}

// Конвертація 16-бітних сирих слів SHT4x у фізичні одиниці
bool parse_sht4x_raw(uint16_t raw_temp, uint16_t raw_rh, climate_sample_t *out) {
    if (!out) return false;
    
    // Формули згідно зі специфікацією Sensirion SHT4x
    out->temperature_c = -45.0f + 175.0f * ((float)raw_temp / 65535.0f);
    
    float rh = -6.0f + 125.0f * ((float)raw_rh / 65535.0f);
    if (rh < 0.0f) rh = 0.0f;
    if (rh > 100.0f) rh = 100.0f;
    out->relative_humidity = rh;
    
    out->dew_point_c = calculate_dew_point(out->temperature_c, out->relative_humidity);
    return true;
}
```
```cpp
#include <cstdint>
#include <cmath>
#include <algorithm>
#include <expected>

namespace climate {

struct Sample {
    float temperature_c;     // °C
    float relative_humidity; // % RH
    float dew_point_c;       // °C
};

enum class ParseError {
    InvalidData
};

[[nodiscard]] inline float calculate_dew_point(float temp_c, float rh_pct) noexcept {
    constexpr float b = 17.62f;
    constexpr float c = 243.12f;
    const float safe_rh = std::clamp(rh_pct, 0.1f, 100.0f);
    
    const float gamma = std::log(safe_rh / 100.0f) + (b * temp_c) / (c + temp_c);
    return (c * gamma) / (b - gamma);
}

[[nodiscard]] inline std::expected<Sample, ParseError> parse_sht4x_raw(uint16_t raw_temp, uint16_t raw_rh) noexcept {
    const float temp = -45.0f + 175.0f * (static_cast<float>(raw_temp) / 65535.0f);
    const float raw_calc_rh = -6.0f + 125.0f * (static_cast<float>(raw_rh) / 65535.0f);
    const float rh = std::clamp(raw_calc_rh, 0.0f, 100.0f);
    
    return Sample{
        .temperature_c = temp,
        .relative_humidity = rh,
        .dew_point_c = calculate_dew_point(temp, rh)
    };
}

} // namespace climate
```
