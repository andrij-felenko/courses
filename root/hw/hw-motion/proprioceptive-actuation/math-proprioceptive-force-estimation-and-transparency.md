# Пропріоцептивний привід у робототехніці

## Лінійна електромеханічна залежність моменту від струму квадратурної осі

1 | важливість: висока | Лінійна електромеханічна залежність крутного моменту мотора від струму квадратурної осі Iq та коефіцієнта моменту Kt.

## Лінійна електромеханічна залежність моменту від струму квадратурної осі

Основою пропріоцептивного відчуття сил у квазіпрямому приводі (QDD) є фундаментальне рівняння електромагнітного моменту синхронного двигуна з постійними магнітами (PMSM/BLDC), що керується методом векторного керування (Field-Oriented Control, FOC). За умови нульового струму прямої осі (`I_d = 0`) електромагнітний крутний момент ротора `T_em` строго лінійно пропорційний струму квадратурної осі `I_q`:
```
T_em = (3 / 2) * p_pairs * Psi_m * I_q = K_t * I_q
```
де `p_pairs` — число пар полюсів ротора, `Psi_m` — зчеплений магнітний потік постійних магнітів, а `K_t` — коефіцієнт крутного моменту мотора (Н·м/А). 

З урахуванням передавального відношення редуктора `i` вихідний теоретичний крутний момент на шарнірі становить:
```
T_joint_ideal = i * T_em = i * K_t * I_q
```
Оскільки вимірювання фазних струмів за допомогою датчиків Холла або шунтів в інверторі відбувається з високою частотою (10–20 кГц), контролер отримує інформацію про електромагнітне зусилля практично без затримки, що усуває проблеми низької смуги пропускання зовнішніх аналогових тензопідсилювачів.

Впровадження пропріоцептивних квазіпрямих приводів потребує спеціальних алгоритмів термічного захисту статора. Оскільки мотор тривалий час працює в режимі високих струмів і низьких швидкостей обертання, тепловіддача за рахунок природної конвекції знижується. Контролер оцінює температуру мідних обмоток у реальному часі за моделлю теплового опору та опору фази, динамічно обмежуючи максимальний квадратурний струм Iq при досягненні порогу 110–120 °C, що запобігає розмагнічуванню рідкоземельних неодимових магнітів ротора (NdFeB) та гарантує стабільність коефіцієнта Kt.

## Моделювання похибок: тертя Кулона, в'язкий опір та інерція

Реальний механічний момент на вихідному валу шарніра `T_joint` відрізняється від ідеального значення через внутрішні дисипативні сили в редукторі та підшипниках. Повне динамічне рівняння привода записується як:
```
T_joint = i * K_t * I_q - J_eff * d(omega) / dt - T_fric(omega)
```
де `J_eff = J_joint + i^2 * J_rotor` — ефективний момент інерції шарніра разом із ротором, а `T_fric(omega)` — нелінійна модель тертя, що включає сухе тертя Кулона `T_c`, статичне тертя страгування (розриву) `T_s` та лінійне в'язке тертя `b_visc`:
```
T_fric(omega) = (T_c + (T_s - T_c) * exp(-(omega / omega_s)^2)) * sign(omega) + b_visc * omega
```
Для високоредукторних приводів (`i = 100`) сила сухого тертя становить до 20–30% номінального моменту, роблячи оцінку зусилля за струмом неможливою. Натомість у квазіпрямих приводах QDD (`i = 6...9`) тертя складає лише 2–5% від пікового моменту. Це дозволяє легко компенсувати його за допомогою попередньо каліброваної таблиці тертя, досягаючи виняткової точності пропріоцептивного відчуття зовнішніх навантажень.

## Проектування сил взаємодії через транспонований якобіан

Для визначення тривимірного вектора сили взаємодії стопи робота з опорною поверхнею `F_ext = [F_x, F_y, F_z]^T` використовується фундаментальний кінематичний зв'язок віртуальної роботи через матрицю Якобі маніпулятора (ноги) `J(q)`. Якщо вектор кутів у шарнірах ноги позначається `q = [q_1, q_2, q_3]^T`, а вектор узагальнених шарнірних моментів — `tau_joints = [tau_1, tau_2, tau_3]^T`, то за принципом Даламбера-Лагранжа статична рівновага сил на кінці кінцівки записується як:
```
tau_joints = J(q)^T * F_ext
```
де `J(q)^T` — транспонована геометрична матриця Якобі розмірністю `3x3`.

Поза сингулярними конфігураціями (коли детермінант якобіана не дорівнює нулю `det(J) != 0`) вектор зовнішньої контактної сили реакції опори аналітично реконструюється за оціненими моментами приводів:
```
F_ext = (J(q)^T)^(-1) * (i * K_t * I_q - tau_fric(dq/dt) - M(q) * ddq - C(q, dq/dt) * dq/dt - G(q))
```
де `M(q), C(q, dq/dt), G(q)` — матриці інерції, Коріолісових/відцентрових сил та сили тяжіння ланок ноги. 

Оскільки в квазіпрямих приводах редуктори надзвичайно прозорі, похибка відновлення вертикальної сили реакції `F_z` не перевищує 3–5 Н у робочому діапазоні до 500 Н. Це дає змогу реалізувати плавне імпедансне демпфування контакту, активне керування кроковим циклом за моделлю ліп-інвертованого маятника (LIPM) та автоматичну адаптацію до жорсткості невідомого ґрунту без будь-яких зовнішніх датчиків.
