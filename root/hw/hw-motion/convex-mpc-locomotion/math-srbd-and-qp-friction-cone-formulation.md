# Опукле керування з прогнозуванням моделей у робототехніці

## Дискретні рівняння стану моделі одиночного твердого тіла

1 | важливість: висока | Дискретні лінійні рівняння стану моделі одиночного твердого тіла (SRBD) у просторі орієнтацій і координат центру мас.

## Дискретні рівняння стану моделі одиночного твердого тіла

Модель одиночного твердого тіла (SRBD) розглядає тулуб робота як недеформівний об'єкт масою `m` з тензором інерції `I_G` у світовій системі координат. Вектор стану системи розмірністю 12 елементів включає орієнтацію за кутами Ейлера `Theta = [phi, theta, psi]^T`, положення центру мас `p = [x, y, z]^T`, кутову швидкість `omega` та лінійну швидкість `v`: `x = [Theta^T, p^T, omega^T, v^T]^T`. Вектором керування `u` є сукупність тривимірних сил реакції опори для всіх чотирьох лап: `u = [f_1^T, f_2^T, f_3^T, f_4^T]^T in R^12`.

Безперервні рівняння руху за умови малих кутів нахилу записуються у просторі станів як:
```
d(Theta) / dt = R_z(psi) * omega
d(p) / dt = v
d(omega) / dt = I_G^(-1) * sum_{i=1}^4 (r_i x f_i)
d(v) / dt = (1 / m) * sum_{i=1}^4 f_i + g
```
де `r_i = p_foot_i - p` — вектор від центру мас до точки контакту i-ї лапи, а `g = [0, 0, -9.81]^T` — вектор гравітаційного прискорення. Після дискретизації за часом із кроком `Delta_t` (типово 20–30 мс) формується лінійна дискретна система:
```
x_{k+1} = A_k * x_k + B_k * u_k + d_k
```
де матриця впливу керування `B_k` прямо залежить від поточного географічного положення стоп відносно центру мас тулуба.

Практичне впровадження розглянутих інженерних рішень вимагає комплексної верифікації параметрів у реальних умовах експлуатації. Аналіз перехідних процесів, температурних деформацій та динамічних вібрацій дозволяє точно калібрувати робочі коефіцієнти запасу надійності, забезпечуючи безвідмовну роботу механізму під дією непередбачуваних зовнішніх навантажень.

## Лінеаризація конуса тертя та квадратична оптимізація QP

Щоб контактні сили `f_i = [f_ix, f_iy, f_iz]^T` не викликали ковзання лапи по поверхні з коефіцієнтом тертя `mu`, вони повинні лежати всередині кругового конуса Кулона: `sqrt(f_ix^2 + f_iy^2) <= mu * f_iz`. Круговий конус є нелінійним обмеженням другого порядку (SOCP), розв'язання якого потребує значно більших обчислювальних ресурсів. У Convex MPC круговий конус лінеаризують чотиригранною пірамідою тертя:
```
-mu * f_iz <= f_ix <= mu * f_iz
-mu * f_iz <= f_iy <= mu * f_iz
f_min <= f_iz <= f_max
```
де `f_min` (зазвичай 5–10 Н) гарантує натяг контакту, а `f_max` обмежує піковий струм моторів.

Задача Convex MPC формулюється як мінімізація зваженого квадратичного функціоналу відхилення стану від опорної траєкторії `x_ref` та енергії керуючих сил на горизонті `H` кроків:
```
min sum_{k=0}^{H-1} ((x_{k+1} - x_ref_{k+1})^T * Q * (x_{k+1} - x_ref_{k+1}) + u_k^T * R * u_k)
```
Підстановка розгорнутих рівнянь стану зводить задачу до канонічної форми опуклого QP: `min (1/2 * U^T * H_qp * U + g_qp^T * U)` за лінійних обмежень `C_qp * U <= b_qp`, яка розв'язується детерміновано за фіксований час.

## Ковзний горизонт прогнозування та формування сил реакцій лап

На кожному кроці дискретного часу `t_k` алгоритм Convex MPC реалізує парадигму ковзного горизонту (Receding Horizon Control). Маючи поточну оцінку стану тулуба `x_k`, оптимізатор розв'язує квадратичну задачу QP наперед на `H` кроків майбутнього (типово `H = 10...16`, що відповідає фізичному інтервалу прогнозування 0,3–0,5 секунди). З усього знайденого оптимального вектора сил `U^* = [u_0^*, u_1^*, ..., u_{H-1}^*]^T` контролер застосовує до приводів виключно першу порцію керування `u_0^*`, що відповідає поточному моменту часу. На наступному кроці весь горизонт зміщується на один такт уперед, вимірюється новий реальний стан робота і оптимізація повторюється заново.

Такий зворотний зв'язок на кожному кроці інтегрування забезпечує природне демпфування непередбачуваних зовнішніх збурень:
```
f_contact_i = u_0^*[3*i : 3*i+3]
tau_joint_i = J_i(q)^T * (-f_contact_i)
```
Якщо робот раптово наступає лапою на слизький лід або камінь, що покотився, виникає неузгодженість між запланованим і фактичним рухом. Оптимізатор на наступному мілісекундному такті автоматично коригує сили реакції трьох інших опорних ніг, миттєво збільшуючи їхній вертикальний притиск та компенсуючи крутний момент падіння, що гарантує абсолютну динамічну стійкість локомоції.
