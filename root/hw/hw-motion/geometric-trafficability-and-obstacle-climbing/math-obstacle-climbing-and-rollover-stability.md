## Аналітичний силовий баланс подолання колесом вертикального уступу

Подолання вертикальної сходинки висотою `h` одиночним приводним колесом радіуса `R` є класичною задачею нелінійної контактної кінематики. Припустимо, що колесо контактує зі сходинкою в кутовій точці з кутом заклинювання `beta = arccos((R - h) / R)`. На колесо діють: вертикальне навантаження від рами `G`, крутний момент привода `T`, нормальна реакція від вістря сходинки `N` (спрямована до осі обертання) та дотична сила зчеплення `F_mu = mu * N`, де `mu` — коефіцієнт тертя гуми об перешкоду.

У граничному стані відриву колеса від горизонтальної основи рівняння статичної рівноваги проекцій сил на нормаль та тангенс точки контакту дають:
```
N = G * cos(beta)
F_mu = G * sin(beta)
```
Щоб колесо закотилося на сходинку без проковзування, відношення дотичної сили до нормальної реакції не повинно перевищувати коефіцієнт зчеплення: `tg(beta) <= mu`. Оскільки `cos(beta) = 1 - h / R`, максимальна теоретична висота уступу для ізольованого колеса обмежена співвідношенням:
```
h_max = R * (1 - 1 / sqrt(1 + mu^2))
```
Навіть при високому коефіцієнті зчеплення `mu = 1.0` одиночне ненавантажене колесо здатне самостійно піднятися лише на уступ висотою `h ≈ 0.29 * R`. Подолання перешкод більшої висоти (`h > R`) вимагає обов'язкового підпору від штовхаючих задніх коліс або активного перенесення центру ваги платформи.

Експериментальні дослідження позашляхових шасі підтверджують, що геометрична прохідність тісно пов'язана з динамічним розподілом вертикальних реакцій коліс. Застосування систем активного демпфування та контролю положення центру мас дозволяє під час наїзду на круті перешкоди штучно перерозподіляти тягові зусилля, розвантажуючи передню вісь і передаючи до 70% крутного моменту на задні колеса. Такий підхід запобігає буксуванню передніх рушіїв на краю уступу та гарантує надійне зачеплення без втрати кінетичної енергії платформи.

## Математичні критерії стійкості проти перекидання на ухилах

Статична стійкість мобільного робота на косогорі визначається положенням вектора результуючої сили ваги відносно опорного контуру, утвореного точками контакту коліс. Для прямокутної чотириколісної платформи з шириною колії `B`, поздовжньою базою `L` та висотою центру мас `h_cg` критичний кут статичного бічного перекидання `theta_roll` визначається геометричним виразом:
```
tg(theta_roll) = B / (2 * h_cg)
```
Поздовжній граничний кут підйому на косогір `theta_pitch` до перекидання назад навколо задньої осі дорівнює:
```
tg(theta_pitch) = (L - l_cg) / h_cg
```
де `l_cg` — поздовжня відстань від передньої осі до центру мас.

При динамічному русі необхідно враховувати сили інерції від прискорення `a_x` та кутової швидкості повороту `omega_z`. Динамічний коефіцієнт стійкості (Нормалізований індекс маржі стійкості, @@en|normalized stability margin@@) `NSM` розраховується як мінімальна кутова відстань від вектора повної гравітаційно-інерційної сили до ліній перекидання опорного полігону, що дозволяє контролеру вчасно знижувати швидкість для запобігання фатальному шкеребертю.

## Геометричні умови подолання рову та прохідність на гребенях

Поряд із вертикальними стінками критичним випробуванням для колісного робота є сухі траншеї, розколини та трикутні або трапецієподібні рови. Для двовісної або багатовісної колісної машини з поздовжньою базою між осями `L` та діаметром колеса `D = 2 * R` критична ширина переїзду рову з прямовисними краями `W_ditch` обмежується умовою вивішування колеса без опускання його центра нижче краю перешкоди:
```
W_ditch < R * sqrt(2) ≈ 1.41 * R
```
Якщо ширина канави перевищує це значення, переднє колесо провалюється всередину, упираючись у протилежну вертикальну стінку під кутом заклинювання `beta > 90°`, що блокує подальший поступальний рух. Багатовісні машини (6x6 або 8x8) долають значно ширші траншеї (`W_ditch ≈ 0.5...0.8 * L`), оскільки суміжні осі утримують раму в горизонтальному положенні, переносячи вивішене колесо через прірву.

Прохідність на гребенях рельєфу визначається поздовжнім радіусом прохідності `rho_long` та поздовжнім кутом прохідності (кутом рампи, @@en|ramp breakover angle@@) `gamma_ramp`:
```
tg(gamma_ramp / 2) = (2 * H_ground) / L
rho_long = (L^2 + 4 * H_ground^2) / (8 * H_ground)
```
де `H_ground` — дорожній просвіт (кліренс). Якщо вершина пагорба має радіус кривизни, менший за `rho_long`, робот сідає на вершину серединою днища («вивішування на черево»), при цьому всі опорні колеса втрачають зчеплення з ґрунтом і платформа втрачає здатність до самостійного руху.
