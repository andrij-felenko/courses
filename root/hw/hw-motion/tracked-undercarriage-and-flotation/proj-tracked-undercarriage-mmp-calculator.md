## Параметризація гусеничного рушія: маса платформи, діаметр і кількість котків, ширина й крок трака

Прохідність та флотація гусеничних робототехнічних комплексів на слабких ґрунтах (мулистий пісок, торфовища, сніжна цілина) є критичним експлуатаційним фактором. Класична оцінка за номінальним тиском `p_nom = W / A_ground` дає оманливі результати, оскільки реальний контактний тиск під кожним опорним котком суттєво перевищує усереднене значення через локальний прогин стрічки.

Архітектура розробленого калькулятора на Python параметризує геометрію ходової частини датакласом `TrackedParams`:
- Повна маса машини `M` та сила ваги `W = M · g`.
- Ширина гусеничної стрічки `b` та довжина опорної ділянки `L`.
- Кількість опорних котків на одному борту `n`.
- Діаметр опорного котка `d` та крок ланки трака `p`.

Програма розраховує номінальний тиск на ґрунт `p_nom`:

```
p_nom = (M · g) / (2 · b · L)
```

Ця величина характеризує ідеалізований розподіл, проте для прогнозування занурення та руйнування ґрунтового масиву вимагається використання моделі пікового тиску Роуленда.

Під час руху по пластичних мулистих та піщаних ґрунтах критичне значення має динаміка взаємодії грунтозацепів із ґрунтовим масивом. Висота та профіль грунтозацепа повинні обиратися таким чином, щоб площа зрізу ґрунту між траками створювала максимальну силу тяги без руйнування ґрунтового ядра. Зменшення кроку ланок у поєднанні зі збільшенням радіуса кривизни опорних котків суттєво згладжує пульсації тиску під рушієм, що запобігає зриву ґрунту та гарантує збереження його тримкості навіть при тривалому буксуванні платформи на крутих підйомах.

## Реалізація розрахунку середнього максимального тиску MMP за моделлю Роуленда та тиску під котком

Другий етап реалізує стандарт НАТО (STANAG 4357) на основі емпіричних рівнянь Роуленда для середнього максимального тиску (Mean Maximum Pressure, MMP). Для жорстких ланкових гусениць з дискретними опорними котками формула має вигляд:

```
MMP = (0,5 · M · g) / (n · b · sqrt(d · p))
```

де `sqrt(d · p)` враховує ефективну довжину розподілу зосередженого навантаження котка через жорсткість ланки стрічки. Чисельний розрахунок показує, що для типової платформи MMP сягає 150–220 кПа при номінальному тиску всього 40–50 кПа, тобто локальні пікові навантаження перевищують номінал у 3,5–4,5 рази!

На основі розрахованого MMP алгоритм інтегрує терамеханічну модель Беккера-Вонга для визначення глибини колії (занурення) `z`:

```
z = (MMP / (k_c / b + k_phi))^(1 / n_soil)
```

де `k_c`, `k_phi` та `n_soil` — параметри деформації досліджуваного ґрунту. Калькулятор автоматично оцінює додатковий опір коченню від деформації ґрунту `R_c` та видає інженерний вердикт щодо ризику посадки днища на ґрунт (high-centering) при заданому кліренсі.

## Прогнозування глибини колії на мулистих і піщаних ґрунтах та оцінка прохідності за критерієм Беккера

Практична верифікація моделі Роуленда здійснюється шляхом зіставлення прохідності 14-тонної гусеничної платформи на двох контрастних типах слабких ґрунтів: вологому мулистому суглинку (`k_c = 12 кПа/м^0,5`, `k_phi = 120 кПа/м^0,5`, `n = 0,6`) та пухкому сухому піску (`k_c = 2 кПа/м`, `k_phi = 240 кПа/м^2`, `n = 1,1`).

Калькулятор обчислює параметри взаємодії:
- Розрахунковий номінальний тиск становить `p_nom = 42,5 кПа`, що створює ілюзію високої прохідності.
- Натомість середній максимальний тиск за Роулендом для 5 опорних котків діаметром 0,52 м сягає `MMP = 168,4 кПа`.
- За терамеханічною моделлю Беккера-Вонга глибина утворення колії в мулистому ґрунті становить `z = 18,2 см`. При кліренсі днища 40 см запас до посадки на черево складає 21,8 см (машина гарантовано зберігає рухливість).
- На пухкому піску глибина колії не перевищує 7,4 см, а сумарний додатковий опір коченню від деформації ґрунту становить `R_c = 8,6 кН`.

Порівняння конфігурацій показує, що додавання шостого опорного котка зменшує MMP до 138 кПа, що знижує глибину занурення на 24% та підвищує тягове зусилля на гаку на 32%. Скрипт генерує підсумковий паспорт флотації шасі відповідно до استاندарту NATO Mobility Model.
