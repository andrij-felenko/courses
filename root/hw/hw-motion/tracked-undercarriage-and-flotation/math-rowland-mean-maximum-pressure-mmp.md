## Нерівномірність напружень під котками та обмеження статичного тиску NSP

У спрощеній інженерній практиці для попередньої оцінки прохідності традиційно користувалися показником номінального статичного тиску на ґрунт (Nominal Ground Pressure, NGP або NSP):
```
NSP = W / (2 * b * L_k)
```
де `W` — повна вага машини, `b` — ширина одного трака, а `L_k` — опорна довжина гусениці між центрами крайніх коліс. Проте польові випробування неодноразово демонстрували парадокс: машини з абсолютно однаковим значенням NSP демонстрували діаметрально протилежні показники флотації та прохідності. Одна платформа легко пересувалася по заболоченому торфовищу, тоді як інша миттєво закопувалася й сідала на днище.

Причина полягає в тому, що гусенична стрічка не є абсолютно жорсткою балкою; під дією ваги опорні котки тиснуть на стрічку точково, утворюючи під кожним катком різко виражений пік контактного тиску, амплітуда якого в 2–4 рази перевершує середній тиск NSP. Між котками гусениця вигинається вгору, і тиск там падає майже до нуля. Саме ці локальні пікові напруження руйнують структурні зв'язки ґрунту, викликають його пластичну течію з-під трака в боки та призводять до катастрофічного колієутворення.

Під час руху по пластичних мулистих та піщаних ґрунтах критичне значення має динаміка взаємодії грунтозацепів із ґрунтовим масивом. Висота та профіль грунтозацепа повинні обиратися таким чином, щоб площа зрізу ґрунту між траками створювала максимальну силу тяги без руйнування ґрунтового ядра. Зменшення кроку ланок у поєднанні зі збільшенням радіуса кривизни опорних котків суттєво згладжує пульсації тиску під рушієм, що запобігає зриву ґрунту та гарантує збереження його тримкості навіть при тривалому буксуванні платформи на крутих підйомах.

## Аналітичне виведення емпіричної формули MMP за Роулендом

Для адекватного врахування пікової нерівномірності британський дослідник Д. Роуленд (D. Rowland) на основі тисяч польових замірів тисків під котками у 1970-х роках вивів стандартизовану на рівні NATO формулу середнього максимального тиску (Mean Maximum Pressure, MMP). Для гусеничних машин із традиційною підвіскою формула Роуленда має вигляд:
```
MMP = (k_r * W) / (2 * n_w * b * sqrt(d_w * p_t))
```
де:
- `W` — повна маса машини в кілограмах, помножена на прискорення вільного падіння `g` (вага в Н);
- `n_w` — кількість опорних котків на одному борту;
- `b` — ширина гусеничної стрічки (м);
- `d_w` — зовнішній діаметр опорного котка (м);
- `p_t` — крок ланок гусениці (м);
- `k_r` — безрозмірний коефіцієнт жорсткості стрічки та підвіски (типово `k_r ≈ 0.8...1.0` для металевих ланкових гусениць).

Формула наочно демонструє, що знизити руйнівні пікові напруження можна не лише розширенням трака `b`, але й збільшенням діаметра котка `d_w`, зменшенням кроку трака `p_t` та збільшенням загальної кількості котків `n_w`, що розбиває єдине велике навантаження на множину малих плавних хвиль тиску.

## Прогнозування глибини колії та флотації за моделлю Беккера-Роуленда

Для кількісної оцінки прохідності на деформівному ґрунті індекс пікового тиску MMP пов'язують із компресійною характеристикою ґрунту за модифікованою формулою Беккера. Глибина колії (занурення гусениці) `z_sink` визначається співвідношенням:
```
z_sink = (MMP / (k_c / b + k_phi))^(1 / n)
```
де `k_c` — модуль зв'язності ґрунту, `k_phi` — модуль внутрішнього тертя, а `n` — показник ступеня деформації ґрунту. Для слабких заболочених торфовищ (`n ≈ 0.5...0.8`, низькі модулі жорсткості) навіть невелике перевищення критичного значення MMP призводить до лавиноподібного занурення платформи.

Емпіричні критерії прохідності NATO формулюють чіткі межі допустимого індексу MMP для різних класів місцевості:
- Легкі болота та волога глина: `MMP < 150...180 кПа` (машина здатна рухатися без ризику застрягання).
- Суглинки середньої вологості: `MMP < 250...300 кПа` (стандартні умови для більшості гусеничних платформ).
- Сухі піщані ґрунти та гравій: `MMP < 350...450 кПа` (глибина колії не перевищує 50 мм).

Опір руху гусеничної машини через колієутворення розраховується через інтеграл роботи пластичної деформації ґрунту на одиницю шляху:
```
R_sink = (2 * b / (n + 1)) * (k_c / b + k_phi) * z_sink^(n + 1)
```
Таким чином, оптимізація підвіски з метою мінімізації MMP безпосередньо зменшує опір руху `R_sink`, знижує необхідну потужність тягових електродвигунів та запобігає безпорадному закопуванню гусеничного шасі на заболочених територіях.
