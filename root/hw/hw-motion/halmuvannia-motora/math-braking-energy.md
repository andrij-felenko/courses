# 🧮 Розрахунок енергії гальмування та гальмівного переривача

Коли обертовий привід уповільнюється, його механічна кінетична енергія не зникає безслідно: вона перетворюється на електричну енергію протиЕРС. Цей розрахунок дає точні інженерні співвідношення для визначення сплеску напруги на шині живлення, розрахунку мінімальної ємності накопичувальних конденсаторів та вибору параметрів баластного резистора гальмівного переривача (*Brake Chopper*).

### 1. Кінетична енергія системи приводу

Повна кінетична енергія механічної системи з мотором, редуктором і рухомим навантаженням складається з енергії обертових мас та енергії поступального руху:

```
E_kin = E_rot + E_trans                         [сума обертової та поступальної енергій]
= 0.5 · J_total · ω₀² + 0.5 · m_load · v₀²      [підстановка формул кінетичної енергії]
```

де:
- `J_total` — сумарний момент інерції, приведений до вала двигуна (кг·м²):
  `J_total = J_rotor + J_coupling + (J_load / N_gear²) + (m_load · (r_pulley / N_gear)²)`
- `ω₀` — початкова кутова швидкість ротора перед початком гальмування (рад/с):
  `ω₀ = 2 · π · n₀ / 60` (де `n₀` — швидкість у об/хв)
- `m_load` — маса поступально рухомого вузла (кг)
- `v₀` — початкова лінійна швидкість навантаження (м/с)
- `N_gear` — передавальне число редуктора (`N_gear = ω_motor / ω_load ≥ 1`)

Якщо вся механічна енергія приведена до вала мотора як еквівалентний момент інерції `J_eq`, початковий запас енергії описується виразом:

```
E_kin = 0.5 · J_eq · ω₀²
```

### 2. Динаміка спаду швидкості при реостатному гальмуванні

При замиканні обмоток двигуна через нижні ключі H-моста або зовнішній резистор двигун переходить у генераторний режим. ПротиЕРС якоря генерує струм гальмування:

```
E_bemf(t) = k_e · ω(t)
I_brake(t) = E_bemf(t) / R_total = (k_e · ω(t)) / R_total
```

де `k_e` — коефіцієнт протиЕРС (В/(рад/с)), `R_total = R_armature + 2·R_ds(on) + R_ext` — сумарний активний опір гальмівного контуру.

Електромагнітний гальмівний момент протидіє обертанню:

```
T_b(t) = k_t · I_brake(t)                       [означення моменту мотора]
= (k_t · k_e · ω(t)) / R_total                  [підстановка струму I_brake = E_bemf / R_total]
= k_b · ω(t)                                    [введення коефіцієнта демпфування k_b]
```

де `k_t` — коефіцієнт моменту двигуна (Н·м/А), а `k_b = (k_t · k_e) / R_total` — коефіцієнт демпфування (Н·м·с/рад). Для ідеального двигуна в системі SI значення `k_t` чисельно дорівнює `k_e`.

Диференціальне рівняння руху ротора за відсутності зовнішнього активного навантаження:

```
J_eq · (dω / dt) = -T_b(t) - T_friction
J_eq · (dω / dt) + k_b · ω(t) = -T_friction
```

Нехтуючи малим моментом сухого тертя `T_friction ≈ 0`, отримуємо класичне експоненційне згасання швидкості:

```
dω / dt + (1 / τ_m) · ω = 0
ω(t) = ω₀ · e^(-t / τ_m)
```

де електромеханічна стала часу гальмування `τ_m` дорівнює:

```
τ_m = (J_eq · R_total) / (k_t · k_e)
```

Вся кінетична енергія розсіюється у вигляді тепла на активних опорах контуру:

```
E_heat = ∫[0..∞] (I_brake(t)² · R_total) dt                                     [закон Джоуля-Ленца в часі]
= ∫[0..∞] (((k_e · ω₀ · e^(-t / τ_m))² / R_total²) · R_total) dt               [підстановка струму I_brake(t)]
= ((k_e² · ω₀²) / R_total) · ∫[0..∞] e^(-2t / τ_m) dt                          [винесення сталих за знак інтеграла]
= ((k_e² · ω₀²) / R_total) · (τ_m / 2)                                         [інтегрування експоненти]
= ((k_e² · ω₀²) / R_total) · ((J_eq · R_total) / (2 · k_t · k_e))               [підстановка сталої часу τ_m]
= 0.5 · J_eq · ω₀²                                                             [скорочення R_total та врахування k_e = k_t]
```

### 3. Сплеск напруги шини живлення при рекуперації

У режимі рекуперативного гальмування кінетична енергія перекачується через зворотні діоди або синхронні ключі H-моста назад у конденсатори шини живлення `C_bus`.

Якщо джерело живлення не здатне приймати зворотний струм (наприклад, імпульсний блок живлення з вихідним діодним випрямлячем), уся рекуперована енергія `E_regen` заряджає конденсаторну батарею `C_bus`, підвищуючи її напругу від початкової робочої `V_bus0` до пікової `V_bus_max`:

```
ΔE_cap = 0.5 · C_bus · (V_bus_max² - V_bus0²)
```

З урахуванням коефіцієнта корисної дії електромеханічного перетворення `η_sys ≈ 0.80..0.90` (частина енергії втрачається на активному опорі обмоток `I²·R` та терті):

```
E_regen = E_kin · η_sys
0.5 · C_bus · (V_bus_max² - V_bus0²) = 0.5 · J_eq · ω₀² · η_sys
```

Звідси пікова напруга шини без застосування гальмівного переривача становить:

```
V_bus_max = √(V_bus0² + (J_eq · ω₀² · η_sys) / C_bus)
```

Якщо привід повинен поглинати енергію гальмування виключно ємністю без скидання в резистор, необхідна ємність конденсаторної батареї розраховується за формулою:

```
C_bus ≥ (J_eq · (ω_start² - ω_end²) · η_sys) / (V_bus_allowed² - V_bus0²)
```

### 4. Розрахунок баластного резистора та гальмівного переривача

Коли допустима максимальна напруга ключів `V_bus_allowed` менша за розрахункову `V_bus_max`, надлишок енергії скидають у гальмівний резистор `R_brake` за допомогою транзисторного переривача (*Brake Chopper*).

#### 4.1. Максимальний опір баластного резистора

Опір резистора повинен бути достатньо малим, щоб забезпечити розсіювання пікової механічної потужності гальмування `P_brake_peak` при напрузі спрацьовування переривача `V_chop_on`:

```
P_mech_peak = T_brake_max · ω_max
P_elec_peak = P_mech_peak · η_sys
P_resistor = V_chop_on² / R_brake ≥ P_elec_peak

R_brake ≤ V_chop_on² / (T_brake_max · ω_max · η_sys)
```

де `T_brake_max` — максимальний необхідний гальмівний момент приводу (Н·м).

#### 4.2. Струм через ключ переривача

Піковий струм, який повинен витримувати транзистор гальмівного переривача `Q_chop`:

```
I_chop_peak = V_chop_on / R_brake
```

Транзистор обирають із запасом по струму `I_ds_max ≥ 1.5 · I_chop_peak` та по напрузі `V_ds_max ≥ 1.3 · V_bus_max_fault`.

#### 4.3. Номінальна потужність баластного резистора

При циклічній роботі приводу (період циклу `T_cycle`, час гальмування `t_brake`) середня тривала потужність розсіювання становить:

```
P_brake_avg = (E_kin · η_sys) / T_cycle
```

Резистор обирають за двома критеріями:
1. Номінальна тривала потужність: `P_nom_resistor ≥ 1.3 · P_brake_avg`
2. Імпульсна перевантажувальна здатність: здатність поглинути енергію одного імпульсу `E_single = E_kin · η_sys` за час `t_brake` без перевищення граничної температури дротяного елемента (згідно з графіком *Pulse Energy Rating* у документації виробника).

### 5. Числовий приклад проектування силової частини

Розглянемо сервопривід конвеєрної стрічки з такими вихідними параметрами:
- Номінальна напруга живлення шини: `V_bus0 = 24.0 В`
- Гранично допустима напруга електролітичних конденсаторів та MOSFET моста: `V_bus_allowed = 30.0 В`
- Поріг увімкнення гальмівного переривача: `V_chop_on = 28.0 В`
- Поріг вимкнення переривача: `V_chop_off = 26.0 В`
- Приведений момент інерції системи: `J_eq = 2.4 × 10⁻³ кг·м²`
- Робоча швидкість обертання: `n₀ = 3600 об/хв`
- Необхідний час екстреної зупинки: `t_stop = 0.08 с (80 мс)`
- Період повторення циклу гальмування: `T_cycle = 4.0 с`
- Електромеханічний ККД рекуперації: `η_sys = 0.85`
- Встановлена ємність шини за замовчуванням: `C_bus_installed = 1000 мкФ (1.0 × 10⁻³ Ф)`

#### Крок 1. Розрахунок кінетичної енергії

```
ω₀ = 2 · π · 3600 / 60 = 376.99 рад/с           [переведення об/хв у рад/с]
E_kin = 0.5 · J_eq · ω₀²                        [формула енергії обертання]
= 0.5 · (2.4 × 10⁻³) · (376.99)²                [підстановка J_eq та ω₀]
= 0.5 · 0.0024 · 142121.5                       [обчислення квадрата швидкості]
= 170.55 Дж                                     [кінцеве значення кінетичної енергії]
```

Енергія, що повертається в електричну частину:

```
E_regen = E_kin · η_sys                         [врахування ККД генерації]
= 170.55 · 0.85                                 [підстановка E_kin та η_sys]
= 144.97 Дж                                     [електрична енергія рекуперації]
```

#### Крок 2. Перевірка напруги без гальмівного переривача

Оцінимо стрибок напруги на наявному конденсаторі `1000 мкФ`:

```
V_bus_peak = √(V_bus0² + 2 · E_regen / C_bus_installed)         [розрахунок напруги на ємності]
= √(24² + 2 · 144.97 / 0.001)                                   [підстановка параметрів 24 В та 1000 мкФ]
= √(576 + 289940)                                               [проміжне обчислення квадратів]
= √290516                                                       [сумарне значення під коренем]
= 539.0 В                                                       [пікова напруга без захисту]
```

*Висновок:* Без гальмівного переривача напруга підскочила б до 539 В, що миттєво спричинило б електричний пробій силових MOSFET (номінал 40 В) та вибух електролітичних конденсаторів.

#### Крок 3. Необхідна ємність без резистора (якщо гасити лише ємністю)

```
C_required = 2 · E_regen / (V_bus_allowed² - V_bus0²)           [формула необхідної ємності шини]
= 2 · 144.97 / (30² - 24²)                                      [підстановка порогів напруги 30 В та 24 В]
= 289.94 / (900 - 576)                                          [обчислення різниці квадратів]
= 289.94 / 324                                                  [ділення на приріст енергії ємності]
= 0.8949 Ф = 894 900 мкФ                                        [результат розрахунку ємності]
```

*Висновок:* Для поглинання енергії ємністю знадобився б масив конденсаторів ємністю майже 0.9 Фарада. Це габаритно й економічно недоцільно, тому обов'язковим є встановлення баластного резистора.

#### Крок 4. Розрахунок баластного резистора

Середня потужність гальмування за інтервал `t_stop = 0.08 с`:

```
P_brake_peak ≈ 2 · (E_regen / t_stop)                           [оцінка пікової потужності гальмування]
= 2 · (144.97 / 0.08)                                           [підстановка енергії та часу зупинки]
= 3624.25 Вт                                                    [значення пікової потужності]
```

Максимально допустимий опір резистора:

```
R_brake ≤ V_chop_on² / P_brake_peak                             [закон Ома для потужності розряду]
= 28² / 3624.25                                                 [підстановка порогу V_chop_on = 28 В]
= 784 / 3624.25                                                 [обчислення квадрата напруги]
= 0.216 Ом                                                      [верхня межа опору резистора]
```

Обираємо стандартний номінал потужного дротяного резистора з ряду E24: `R_brake = 0.20 Ом`.

#### Крок 5. Струм ключа та середня потужність розсіювання

Піковий струм транзистора переривача:

```
I_chop_peak = V_chop_on / R_brake                               [закон Ома для струму ключа]
= 28.0 / 0.20                                                   [підстановка напруги та опору баласту]
= 140.0 А                                                       [піковий струм через MOSFET]
```

Середня потужність резистора при періоді циклу `T_cycle = 4.0 с`:

```
P_brake_avg = E_regen / T_cycle                                 [середня потужність за період циклу]
= 144.97 / 4.0                                                  [підстановка енергії та періоду 4 с]
= 36.24 Вт                                                      [середня теплова потужність розсіювання]
```

*Підсумок розрахунку:*
Для безпечного гальмування системи необхідно встановити:
- Дротяний гальмівний резистор з алюмінієвим радіатором опором `0.20 Ом`, номінальною тривалою потужністю не менше `50 Вт` та імпульсною стійкістю не менше `150 Дж / 100 мс`.
- Силовий N-канальний MOSFET переривача з параметрами `V_ds ≥ 40 В`, `I_d_pulse ≥ 200 А`, `R_ds(on) ≤ 3 мОм`.
