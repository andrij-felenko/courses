## Передатні функції імпедансу та адмітансу у просторі Лапласа

У теорії лінійних динамічних систем механічний імпеданс `Z(s)` та механічний адмітанс `Y(s)` визначаються як дуальні оператори, що пов'язують вектор зовнішньої контактної сили `F(s)` та вектор швидкості переміщення `V(s) = s * X(s)` у просторі комплексного перетворення Лапласа:
```
F(s) = Z(s) * V(s) = Z(s) * s * X(s)
X(s) = Y(s) * F(s) = (1 / (s * Z(s))) * F(s)
```
Для канонічної моделі віртуального механічного підвісу другого порядку з масою `M`, демпфуванням `B` та жорсткістю `K` оператор імпедансу набуває вигляду:
```
Z(s) = M * s + B + K / s
```
Відповідно, передатна функція механічного адмітансу, яка визначає реакцію координати на прикладену силу, має вигляд стандартного коливального ланки другого порядку:
```
Y_pos(s) = X(s) / F(s) = 1 / (M * s^2 + B * s + K)
```
Імпедансний регулятор приймає на вхід виміряну похибку положення та генерує необхідну силу мотора `F_cmd(s) = (M * s^2 + B * s + K) * (X_d(s) - X(s))`. Навпаки, адмітансний регулятор вимірює зовнішню контактну силу за допомогою датчика F/T і модифікує бажану позицію за передатною функцією `X_mod(s) = F_meas(s) / (M * s^2 + B * s + K)`.

Практичне впровадження розглянутих інженерних рішень вимагає комплексної верифікації параметрів у реальних умовах експлуатації. Аналіз перехідних процесів, температурних деформацій та динамічних вібрацій дозволяє точно калібрувати робочі коефіцієнти запасу надійності, забезпечуючи безвідмовну роботу механізму під дією непередбачуваних зовнішніх навантажень.

## Частотний аналіз та стабільність за критерієм Найквіста

При контакті робота з жорсткою стіною (жорсткість середовища `K_env -> infty`) загальна передатна функція розімкненого контуру керування містить полюси середовища та затримку цифрового обчислення `T_delay`. Частотна логарифмічна характеристика (діаграма Боде) демонструє, що зі збільшенням віртуальної жорсткості `K` фазовий зсув наближається до критичної точки `-180°`.

Якщо фазовий запас стійкості стає від'ємним, замкнена система втрачає стійкість за критерієм Найквіста: виникає руйнівний високочастотний брязкіт (chatter), коли робот багаторазово відскакує від поверхні з наростаючою амплітудою. Для гарантування стійкості демпфування `B` повинно обиратися з умови критичного або надкритичного затухання: `B >= 2 * sqrt(M * (K + K_env))`, що запобігає появі коливальних резонансних піків на високих частотах.

## Критерій пасивності системи та гарантування стійкості при взаємодії

Фундаментальною передумовою безвідмовної взаємодії робота з довільним фізичним оточенням є дотримання умови пасивності (Passivity Theorem). Фізичне середовище (за винятком активних мехатронних джерел енергії) завжди є строго пасивним: стіни, заготовки, інструменти здатні накопичувати енергію деформації або розсіювати її на тепло через внутрішнє тертя, але ніколи не генерують механічну роботу спонтанно.

Згідно з теоремою Колгейта про пасивну взаємодію (Colgate's Passivity Condition), зворотне з'єднання двох пасивних однопортових підсистем (маніпулятор + середовище) гарантовано є асимптотично стійким при будь-яких нелінійних параметрах контакту. Для передатної функції механічного імпедансу `Z(s)` вимога пасивності означає, що вона повинна бути дійсно додатною функцією (Positive Real, PR):
1. `Z(s)` не має полюсів у правій півплощині комплексного простору Лапласа (`Re(s) > 0`).
2. Будь-які полюси на уявній осі `s = j*omega` є простими, а їхні лишки — дійсними й додатними.
3. Дійсна частина передатної функції є невід'ємною вздовж усієї частотної осі: `Re(Z(j*omega)) >= 0` для всіх `omega >= 0`.

Фізично умова `Re(Z(j*omega)) >= 0` означає, що віртуальне демпфування `B` на будь-якій частоті коливань розсіює енергію: `P_diss = v^T * Re(Z(j*omega)) * v >= 0`.

У цифрових контролерах період дискретизації `T_s` та затримка обчислювального такту (Sample-and-Hold Delay) вносять еквівалентне від'ємне демпфування величиною `-0,5 * K * T_s`. Якщо ця фазова затримка перевищить природне демпфування контуру `B`, загальний баланс потужності стане від'ємним, система почне генерувати енергію й перейде в неконтрольований коливальний зрив. Тому під час налаштування обов'язково забезпечують виконання цифрової умови стійкості:
```
B > 0,5 * K * T_s
```
де `K` — віртуальна жорсткість, `B` — коефіцієнт в'язкого тертя, а `T_s` — період дискретизації регулятора.
