## Динамічна модель одного шарніра та архітектура регулятора імпедансу мовою Python

Керування взаємодією робота з навколишнім середовищем потребує переходу від класичного жорсткого позиціювання до імпедансного регулювання, де маніпулятор демонструє поведінку віртуального пружинно-демпферного механізму. Для дослідження стійкості контакту будується динамічна модель одиночного шарніра зі зворотним приводом.

Рівняння обертального руху вихідної ланки з моментом інерції `J` та коефіцієнтом в'язкого демпфування `D` описується рівнянням Ньютона-Ейлера:

```
J · d^2(theta)/dt^2 + D · d(theta)/dt = tau_act - tau_ext
```

де `tau_act` — активний крутний момент, що генерується електродвигуном, а `tau_ext` — зовнішній крутний момент реакції середовища.

Архітектура контролера на Python містить клас `SingleJointImpedanceSimulator`. Вхідними даними є бажана траєкторія кутового положення `theta_des` та бажані віртуальні параметри імпедансу: віртуальна інерція `M_d`, віртуальне демпфування `B_d` та віртуальна жорсткість `K_d`. Завдяки низькому коефіцієнту редукції квазіпрямого привода (QDD) струм мотора перетворюється у вихідний крутний момент лінійно та без істотного сухого тертя.

Практичне впровадження розглянутих інженерних рішень вимагає комплексної верифікації параметрів у реальних умовах експлуатації. Аналіз перехідних процесів, температурних деформацій та динамічних вібрацій дозволяє точно калібрувати робочі коефіцієнти запасу надійності, забезпечуючи безвідмовну роботу механізму під дією непередбачуваних зовнішніх навантажень.

## Реалізація алгоритму обчислення похибки положення, віртуальної жорсткості K та демпфування B

Закон керування імпедансом формує керуючий момент привода на основі похибки позиції та швидкості ланки:

```
tau_cmd = K_d · (theta_des - theta) + B_d · (d(theta_des)/dt - d(theta)/dt)
```

У момент торкання жорсткої перешкоди з власною контактною жорсткістю `K_env` виникає зовнішня реакція `tau_ext = K_env · (theta - theta_wall)`. Замість аварійного зростання струму, привід делікатно піддається зовнішній силі, зупиняючись у положенні рівноваги з фіксованим контактним зусиллям:

```
tau_contact = (K_d · K_env / (K_d + K_env)) · (theta_des - theta_wall)
```

Симулятор виконує покрокове чисельне інтегрування рівнянь системи методом Ейлера з кроком `dt = 0,001 с` (1 кГц). Особлива увага приділяється дискретній умові пасивності: для запобігання високочастотному деренчанню (chattering) на жорсткій стінці параметри віртуального демпфування зобов'язані задовольняти нерівність `B_d > 0,5 · K_d · dt`. Програма будує графіки перехідних процесів та оцінює час згасання коливань.

## Симуляція зіткнення з жорсткою та пружною перешкодою та аналіз контактних сил у часі

Для перевірки динамічних характеристик та стійкості контуру імпедансного керування симулятор моделює рух ланки маніпулятора з бажаною швидкістю та її зіткнення з двома типами середовища: жорсткою сталевою стінкою (`K_env = 10000 Н/м`) та податливою гумовою деталлю (`K_env = 300 Н/м`).

Аналіз перехідних процесів показує:
1. При контакті з м'яким середовищем перехідний процес має аперіодичний характер. Ланка плавно деформує гуму, розвиваючи стабільне зусилля 36 Н без відчутних коливань та перерегулювання.
2. При ударі об жорстку стінку висока контактна жорсткість у поєднанні з дискретністю керування створює ризик високочастотних автоколивань. Завдяки правильному вибору віртуального демпфування `B_d = 35 Н*с/м`, що задовольняє критерію пасивності Колгейта, первинний пік сили контакту гаситься всього за 12 мілісекунд.

Усталене контактне зусилля встановлюється на рівні 114 Н, що точно відповідає теоретичному розрахунку сили взаємодії двох послідовно з'єднаних пружин. Результати моделювання доводять, що алгоритм забезпечує гарантовану стійкість навіть при десятикратному перевищенні жорсткості стінки над жорсткістю віртуального імпедансу.

При роботі з наджорсткими контактними середовищами критичним є фазове випередження за швидкістю в контурі зворотного зв'язку за зусиллям. Фільтрація вимірюваного сигналу сили цифровим фільтром Баттерворта другого порядку у поєднанні зі спостерігачем стану на базі розширеного фільтра Калмана (EKF) забезпечує стабільність контактної взаємодії без виникнення високочастотних автоколивань на межі зіткнення.
