## Планетарна кінематика РГП: кутові швидкості та відносне кочення

Планетарна ролико-гвинтова передача працює як прецизійний планетарний редуктор, де ходовий гвинт виконує роль сонячного колеса з зовнішньою різьбою радіуса `r_s`, ролики є планетарними сателітами радіуса `r_r`, а гайка виступає коронним колесом із внутрішньою різьбою радіуса `r_n = r_s + 2 * r_r`.

Для забезпечення чистого кочення роликів без осьового зсуву відносно гайки крок і кількість заходів різьби обираються за суворою геометричною умовою:
```
d_s / d_r = z_s / z_r,   d_n / d_r = z_n / z_r
```
де `z` — кількість зубців синхронізуючих зубчастих вінців на торцях роликів та гайки.

Кутова швидкість обертання роликової каретки (водила) `omega_c` при обертанні ходового гвинта з кутовою швидкістю `omega_s` і нерухомій гайці визначається формулою Вілліса для планетарних передач:
```
omega_c = omega_s * (r_s / (r_s + r_n)) = 0,5 * omega_s * (r_s / (r_s + r_r))
```
Лінійне осьове переміщення гайки за один повний оберт гвинта дорівнює номінальному кроку різьби `P_h = k * p`, де `p` — осьовий крок профілю, а `k` — число заходів різьби ходового гвинта.

Практичне впровадження розглянутих інженерних рішень вимагає комплексної верифікації параметрів у реальних умовах експлуатації. Аналіз перехідних процесів, температурних деформацій та динамічних вібрацій дозволяє точно калібрувати робочі коефіцієнти запасу надійності, забезпечуючи безвідмовну роботу механізму під дією непередбачуваних зовнішніх навантажень.

## Герцівська контактна міцність: лінійний контакт та вантажопідйомність

На відміну від точкового контакту сфери з жолобом у кулькових гвинтах, де напруження описуються тривісним еліпсоїдом Герца, у ролико-гвинтовій передачі різьбові профілі ролика та гвинта мають опукло-ввігнутий лінійний контакт уздовж дуги взаємодії.

Максимальне контактне напруження стиснення за Герцом `sigma_H` для лінійного контакту визначається співвідношенням:
```
sigma_H = sqrt( (F_n * E_eq) / (pi * L_contact * (1 - nu^2) * rho_eq) )
```
де `F_n` — нормальна сила, що діє на один виток контакту, `E_eq` — еквівалентний модуль пружності сталі, `nu = 0,3` — коефіцієнт Пуассона, `L_contact` — ефективна довжина лінії контакту на витку, а `rho_eq = (1/R_screw + 1/R_roller)^(-1)` — приведений радіус кривизни профілів.

Оскільки загальна кількість одночасно навантажених лінійних контактів дорівнює добутку кількості роликів `n_r` на кількість робочих витків гайки `z_threads`:
```
N_total_contacts = n_r * z_threads
```
навантаження на окремий контакт виявляється в рази меншим. Завдяки цьому базова статична вантажопідйомність `C_0` для РГП досягає значень 500–2500 кН при компактних діаметрах 30–60 мм, що дозволяє витримувати важкі екстремальні удари без мікропластичних деформацій.

## Динамічна довговічність за критерієм L_10 та знакозмінні навантаження

Оцінка втомного ресурсу ролико-гвинтової передачі базується на стандартизованій теорії Лундберга-Пальмгрена (ISO 3408 та DIN 69051), адаптованій для багатоконтактних планетарних поверхонь. Базовий номінальний ресурс `L_10` (мільйони обертів ходового гвинта з 90% імовірністю безвідмовної роботи) визначається за формулою:
```
L_10 = (C_a / F_eq)^p
```
де `C_a` — базова динамічна осьова вантажопідйомність, зазначена в каталозі виробника, `F_eq` — еквівалентна динамічна осьова сила за робочий цикл, а показник степеня втоми для лінійного контакту роликів дорівнює `p = 3` (або `p = 10/3` за уточненою методикою SKF/Rollvis, що враховує еліптичність плями деформації).

При знакозмінному циклі навантаження (наприклад, висування актуатора під дією штовхаючої сили `F_1` упродовж часу `t_1` і повернення під дією меншої тягнучої сили `F_2` упродовж часу `t_2`) еквівалентна кубічна середня сила розраховується за формулою:
```
F_eq = ( (sum (F_i^p * n_i * t_i)) / (sum (n_i * t_i)) )^(1/p)
```
Якщо робоча температура вузла перевищує 100 °C або в мастилі присутні мікрочастинки абразиву, ресурс коригується коефіцієнтами надійності: `L_10m = a_1 * a_SKF * L_10`. Завдяки великій кількості витків роликів правильно підібрана РГП забезпечує ресурс понад 50 000–100 000 годин безперервної роботи в найважчих експлуатаційних умовах.
