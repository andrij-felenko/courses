1 | важливість: висока | Динамічна модель ротора Джефкота (Jeffcott Rotor) з дисбалансом: зсув центру мас e_0 та критична кутова швидкість omega_cr.

## Динамічна модель ротора Джефкота з дисбалансом

Класичною розрахунковою моделлю для дослідження автобалансування є пружний симетричний ротор Джефкота (Jeffcott Rotor) масою `M`, закріплений на безмасовому пружному валу з радіальною жорсткістю `k` та коефіцієнтом в'язкого демпфування опор `c`.

Нехай геометричний центр ротора позначається `C(x, y)`, а центр мас зміщений на постійний ексцентриситет `e_0` під кутом `phi = omega * t`. Диференціальні рівняння руху центру вала в нерухомій системі координат описуються системою:
```
M * ddx + c * dx + k * x = M * e_0 * omega^2 * cos(omega * t)
M * ddy + c * dy + k * y = M * e_0 * omega^2 * sin(omega * t)
```
Власна критична частота коливань системи становить `omega_cr = sqrt(k / M)`, а коефіцієнт відносного демпфування `zeta = c / (2 * sqrt(k * M))`.

У стаціонарному режимі геометричний центр вала описує кругову траєкторію радіуса `R_orbit = e_0 * (omega / omega_cr)^2 / sqrt((1 - (omega/omega_cr)^2)^2 + (2 * zeta * omega / omega_cr)^2)`. При цьому фазовий кут відставання прогину вала від вектора дисбалансу описується формулою:
```
tg(alpha) = (2 * zeta * (omega / omega_cr)) / (1 - (omega / omega_cr)^2)
```
При малих швидкостях (`omega << omega_cr`) фазовий кут `alpha -> 0`, тобто вал прогинається в бік важкої точки. Проте при переході в надкритичну область (`omega >> omega_cr`) знаменник змінює знак, і фазовий зсув наближається до `alpha -> 180°`: вал починає обертатися навколо свого справжнього центру мас (явище самоцентрування).

Практичне впровадження розглянутих інженерних рішень вимагає комплексної верифікації параметрів у реальних умовах експлуатації. Аналіз перехідних процесів, температурних деформацій та динамічних вібрацій дозволяє точно калібрувати робочі коефіцієнти запасу надійності, забезпечуючи безвідмовну роботу механізму під дією непередбачуваних зовнішніх навантажень.

## Рівняння руху автобалансувальних куль у кільцевій доріжці

Розглянемо ротор, оснащений кільцевою доріжкою радіуса `R`, у якій розміщено дві ідентичні кулі масою `m_b` кожна. Кутові координати куль у системі, що обертається разом із валом, позначимо як `psi_1` та `psi_2` відносно осі дисбалансу.

Рівняння руху куль по доріжці з урахуванням сили інерції та тангенціального в'язкого тертя мастила `b_b`:
```
m_b * R^2 * d(dpsi_i)/dt^2 + b_b * R^2 * d(psi_i)/dt = - m_b * R * (ddx * sin(omega*t + psi_i) - ddy * cos(omega*t + psi_i))
```
Підставляючи в праву частину рівняння гармонійний рух центру вала, отримуємо середній момент сил інерції, що діє на кожну кулю:
```
M_ball_i = 0,5 * m_b * R * omega^2 * R_orbit * sin(psi_i - alpha)
```
Стан рівноваги настає тоді, коли усереднений тангенціальний момент інерції обертається на нуль. Це відбувається в положенні, коли вектор сумарного статичного моменту куль `m_b * R * (e^(j*psi_1) + e^(j*psi_2))` стає строго протилежним до початкового вектора дисбалансу `M * e_0`, повністю компенсуючи збурювальну силу на підшипниках.

## Умова надкритичної стабільності та демпфування вібрацій

Дослідження асимптотичної стійкості кулькового автобалансира методом фазової площини показує, що здатність куль самоорганізуватися в протифазі залежить від співвідношення між робочою кутовою швидкістю `omega` та власною частотою згинних коливань вала `omega_cr`.

Повний нелінійний аналіз стаціонарних станів за Ляпуновим доводить, що автобалансувальний стан куль (положення чистої компенсації дисбалансу) є асимптотично стійким тоді й тільки тоді, коли робоча швидкість перевищує резонансну швидкість щонайменше в `sqrt(2)` разів:
```
omega > sqrt(2) * omega_cr
```
Якщо швидкість обертання нижча за цей поріг (`omega < sqrt(2) * omega_cr`), кулі потрапляють у зону динамічної нестійкості: замість врівноваження ротора вони скочуються в бік ексцентриситету, подвоюючи амплітуду збурювальної сили та викликаючи катастрофічний резонанс.

Саме тому в конструкціях автобалансирів обов'язково забезпечують швидкий розгін вала крізь критичну швидкість (режим Run-up) за мінімальний час, а внутрішню порожнину заповнюють демпфуючою оливою з динамічною в'язкістю `eta = 50...100` сСт. Гідродинамічний опір оливи створює необхідне тангенціальне демпфування `b_b`, яке гасить хаотичні автоколивання куль (субгармонійні граничні цикли) і забезпечує їхнє швидке й бездоганне схоплювання в діаметрально протилежних точках відносно ексцентриситету ротора.
