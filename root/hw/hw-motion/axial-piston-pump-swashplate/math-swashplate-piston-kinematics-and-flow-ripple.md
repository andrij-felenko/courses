# Аксіально-поршневий гідронасос із похилою шайбою

## Кінематичні рівняння руху поршня від кута вала та кута шайби

1 | важливість: висока | Кінематичні рівняння руху поршня: переміщення, швидкість і миттєве прискорення від кута повороту вала та кута шайби.

## Кінематичні рівняння руху поршня від кута вала та кута шайби

Кінематика плунжера аксіально-поршневого насоса визначається геометрією розташування циліндрів на радіусі `R_c` та кутом нахилу опорної поверхні похилої шайби `gamma`.

При обертанні блока циліндрів із постійною кутовою швидкістю `omega = 2 * pi * n` кутове положення `i`-го циліндра в момент часу `t` описується кутом `theta_i = omega * t + phi_i`, де `phi_i = 2 * pi * (i - 1) / N` — початковий фазовий зсув, а `N` — загальна кількість поршнів.

Осьове переміщення поршня `s_i(theta_i)` відносно крайнього мертвого положення виводиться з прямокутного трикутника проекції опорного башмака на площину шайби:
```
s_i(theta_i) = R_c * tg(gamma) * (1 - cos(theta_i))
```
Диференціювання переміщення за часом дає точну аналітичну залежність миттєвої осьової швидкості плунжера:
```
v_i(theta_i) = d(s_i)/dt = R_c * omega * tg(gamma) * sin(theta_i)
```
Повний робочий хід поршня становить `H_stroke = 2 * R_c * tg(gamma)`. Як видно з формули, при нульовому нахилі шайби (`gamma = 0`) хід поршнів дорівнює нулю, і подача припиняється.

Практичне впровадження розглянутих інженерних рішень вимагає комплексної верифікації параметрів у реальних умовах експлуатації. Аналіз перехідних процесів, температурних деформацій та динамічних вібрацій дозволяє точно калібрувати робочі коефіцієнти запасу надійності, забезпечуючи безвідмовну роботу механізму під дією непередбачуваних зовнішніх навантажень.

## Миттєва та середня геометрична подача насоса

Миттєва теоретична витрата робочої рідини, що витісняється одним циліндром під час фази нагнітання (`0 <= theta_i <= pi`), дорівнює добутку швидкості поршня на площу його поперечного перерізу `A_p = (pi * d_p^2) / 4`:
```
q_i(theta_i) = A_p * v_i(theta_i) = A_p * R_c * omega * tg(gamma) * sin(theta_i)
```
Сумарна миттєва подача насоса `Q_pump(theta)` у нагнітальну лінію дорівнює сумі витрат усіх поршнів, які в даний момент сполучені з вікном високого тиску розподільного диска:
```
Q_pump(theta) = sum_{i in Active} q_i(theta_i)
```
Середня теоретична продуктивність насоса за один повний оберт вала розраховується через сумарний робочий об'єм `V_disp = N * A_p * H_stroke = 2 * N * A_p * R_c * tg(gamma)`:
```
Q_avg = (omega / (2 * pi)) * V_disp = n * N * A_p * 2 * R_c * tg(gamma)
```
Цей фундаментальний вираз демонструє лінійну залежність середньої подачі від частоти обертання `n` та тангенса кута шайби `tg(gamma)`.

## Коефіцієнт нерівномірності подачі: переваги непарної кількості поршнів

Оскільки кожен плунжер витісняє рідину за гармонійним синусоїдальним законом, сумарна витрата насоса не є строго постійною в часі, а пульсує навколо середнього значення. Пульсація подачі породжує хвилі пульсації тиску, що є головним джерелом шуму та вібрацій у гідросистемах.

Коефіцієнт нерівномірності подачі `sigma_Q` визначається відношенням амплітуди коливань витрати до її середнього значення:
```
sigma_Q = (Q_max - Q_min) / Q_avg
```
Аналітичний розрахунок показує разючу математичну різницю між насосами з парною та непарною кількістю циліндрів:
1. Для парної кількості поршнів `N_even` (наприклад, `N = 8`): у будь-який момент часу рівно половина циліндрів (`N / 2`) перебуває на лінії нагнітання. Коли один поршень переходить через мертву точку, інший поршень діаметрально протилежно робить те саме. Пульсація становить:
```
sigma_Q_even = (pi / 2) * tg(pi / (2 * N))
```
Для `N = 8` коефіцієнт становить приблизно `30,6%`.
2. Для непарної кількості поршнів `N_odd` (наприклад, `N = 9`): кількість активних поршнів періодично змінюється між `(N - 1) / 2` та `(N + 1) / 2`. Завдяки чергуванню фазових піків нерівномірність подачі різко падає:
```
sigma_Q_odd = (pi / 2) * tg(pi / (4 * N))
```
Для `N = 9` коефіцієнт становить лише `1,52%` (майже у 20 разів менше!). Саме тому абсолютно всі серійні промислові та авіаційні аксіально-поршневі гідромашини конструюються виключно з непарною кількістю поршнів — 7 або 9.
