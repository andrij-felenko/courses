## Математичне визначення просторового декартового імпедансу

Декартове імпедансне керування моделює взаємодію робочого органа маніпулятора (End-Effector) з навколишнім середовищем у вигляді віртуальної механічної системи, що підпорядковується рівнянню динаміки другого порядку у шестивимірному просторі положення та орієнтації:
```
M_d * ddx_e + D_d * dx_e + K_d * x_e = F_ext
```
де:
- `x_e = x - x_d` — вектор відхилення поточної пози інструмента від бажаної віртуальної траєкторії;
- `M_d` — діагональна або симетрична додатньо визначена матриця бажаної віртуальної інерції;
- `D_d` — матриця віртуального демпфування (в'язкого опору);
- `K_d` — матриця бажаної віртуальної просторової жорсткості;
- `F_ext` — вектор зовнішніх контактних сил і моментів взаємодії з середовищем.

Завдяки цьому закону маніпулятор демонструє поведінку пружного підвісу: якщо зовнішня перешкода зсуває робочий орган, сила опору зростає пропорційно відхиленню та швидкості, унеможливлюючи небезпечні силові перевантаження деталей.

Практичне впровадження розглянутих інженерних рішень вимагає комплексної верифікації параметрів у реальних умовах експлуатації. Аналіз перехідних процесів, температурних деформацій та динамічних вібрацій дозволяє точно калібрувати робочі коефіцієнти запасу надійності, забезпечуючи безвідмовну роботу механізму під дією непередбачуваних зовнішніх навантажень.

## Проектування сил через транспоновану матрицю Якобі

Оскільки сервоприводи робота діють у просторі шарнірів, формуючи крутні моменти `tau in R^n`, необхідно здійснити математичне відображення бажаної декартової контактної сили `F_cmd` у суглобові керуючі дії. На основі принципу віртуальних переміщень робота віртуальних сил дорівнює роботі шарнірних моментів: `delta(W) = F^T * delta(x) = tau^T * delta(q)`. Враховуючи, що диференціал декартового положення пов'язаний із варіацією суглобових кутів через геометричну матрицю Якобі `delta(x) = J(q) * delta(q)`, отримуємо фундаментальне співвідношення:
```
tau_cmd = J(q)^T * F_cmd + g(q)
```
де `g(q)` — вектор компенсації сили тяжіння ланок маніпулятора.

Підставляючи вираз бажаної декартової сили імпедансу, закон керування для квазістатичного наближення (коли швидкість руху помірна і силами інерції можна знехтувати) набуває елегантного вигляду:
```
tau_cmd = J(q)^T * (K_d * (x_d - x(q)) - D_d * J(q) * dq/dt) + g(q)
```
Цей закон не вимагає обчислення зворотної кінематики маніпулятора і автоматично розв'язує задачу кінематичної надлишковості через транспонування Якобіана, що робить його винятково стабільним навіть поблизу кінематичних сингулярностей.

## Операційна матриця інерції Хатіба та компенсація нелінійних сил

Для забезпечення бездоганного просторового імпедансу на високих швидкостях простого квазістатичного наближення недостатньо: необхідно компенсувати повну тривимірну нелінійну динаміку маніпулятора. Уссама Хатіб ввів поняття псевдооберненого динамічно узгодженого якобіана `J_bar(q)` та операційної матриці просторової інерції `Lambda(q)`:
```
Lambda(q) = (J(q) * M(q)^(-1) * J(q)^T)^(-1)
J_bar(q) = M(q)^(-1) * J(q)^T * Lambda(q)
```
де `M(q)` — симетрична додатно визначена матриця інерції робота в шарнірному просторі.

Повний закон динамічного імпедансного керування в операційному просторі набуває вигляду:
```
tau_cmd = J(q)^T * (Lambda(q) * a_cmd + mu(q, dq/dt) + p(q))
```
де `a_cmd = ddx_d + M_d^(-1) * (D_d * dx_e + K_d * x_e - F_ext)` — вектор бажаного прискорення в декартовому просторі, `mu(q, dq/dt) = J_bar^T * C(q, dq/dt) * dq/dt - Lambda * dJ/dt * dq/dt` — вектор Коріолісових і відцентрових сил у просторі завдання, а `p(q) = J_bar^T * g(q)` — операційні гравітаційні сили.

Завдяки повній динамічній лінеаризації закрита система веде себе у просторі як ідеальна ізотропна віртуальна система маса-демпфер-пружина з повністю розв'язаними декартовими осями X, Y та Z, усуваючи будь-який паразитний динамічний взаємовплив між рухом руки та силовими реакціями на наконечнику.
