Механічна характеристика електродвигуна постійного струму та безколекторного синхронного двигуна описує аналітичний зв'язок між розвиваним електромагнітним моментом і кутовою швидкістю обертання вала в усталеному режимі. Усі ключові параметри приводу — пусковий момент, швидкість холостого ходу, крутизна спаду обертів, точка максимальної механічної потужності та координати робочої точки під навантаженням — виводяться з фундаментальних законів електродинаміки та балансу потужностей.

### 1. Фундаментальні рівняння електромеханічного зв'язку

Електромеханічне перетворення енергії в машині постійного струму базується на взаємодії магнітного поля статора зі струмом провідників ротора (закон Ампера) та наведенні електрорушійної сили в провідниках, що перетинають магнітне поле (закон Фарадея).

Електромагнітний момент `M`, створюваний усіма секціями обмотки якоря:

```
M = k_t · I                                      [момент пропорційний струму якоря I]
```

де `k_t` — конструктивна стала моменту двигуна, яка залежить від форми та індукції магнітного поля статора, кількості активних провідників якоря, числа пар полюсів та геометричного радіуса ротора.

При обертанні ротора з кутовою швидкістю `ω` в магнітному полі статора в його обмотках наводиться зустрічна електрорушійна сила (протиЕРС) `E`:

```
E = k_e · ω                                      [протиЕРС пропорційна кутовій швидкості ω]
```

де `k_e` — стала протиЕРС машини.

### 2. Рівність сталої моменту та сталої протиЕРС у системі SI

Покажемо, чому в міжнародній системі одиниць SI коефіцієнти `k_t` та `k_e` числово та розмірно тотожні. Розгляньмо баланс потужностей під час електромеханічного перетворення всередині повітряного проміжку двигуна без урахування теплових втрат на активному опорі обмотки (ідеальне перетворення).

Електрична потужність `P_elec_conv`, яка перетворюється на магнітне поле та механічну роботу:

```
P_elec_conv = E · I                              [потужність електричного перетворення]
            = (k_e · ω) · I                      [підстановка формули протиЕРС E = k_e · ω]
```

Механічна потужність `P_mech_conv`, яка розвивається електромагнітними силами на валу:

```
P_mech_conv = M · ω                              [механічна потужність обертання]
            = (k_t · I) · ω                      [підстановка формули моменту M = k_t · I]
```

За законом збереження енергії за відсутності внутрішніх електромагнітних втрат у самому процесі перетворення:

```
P_elec_conv = P_mech_conv                        [закон збереження енергії перетворення]
(k_e · ω) · I = (k_t · I) · ω                    [прирівнювання електричної та механічної потужності]
k_e = k_t                                        [скорочення на спільний множник (I · ω)]
```

Розмірнісна перевірка підтверджує тотожність:
- Розмірність `k_t`: `Н·м / А = (кг·м² / с²) / А = кг·м² / (с²·А)`.
- Розмірність `k_e`: `В / (рад/с) = В·с / рад = (Дж / (А·с)) · с = Дж / А = (кг·м² / с²) / А = кг·м² / (с²·А)`.

Таким чином, у системі одиниць SI чисельні значення сталого моменту та сталої протиЕРС збігаються: `k_t = k_e = k`.

### 3. Аналітичне виведення лінійної механічної характеристики

Рівняння електричної рівноваги кола якоря двигуна постійного струму в усталеному режимі за другим законом Кірхгофа:

```
U = I · R + E                                    [баланс напруг у колі якоря]
U = I · R + k_e · ω                              [підстановка протиЕРС E = k_e · ω]
```

де `U` — напруга, прикладена до клем двигуна, `R` — повний активний опір кола якоря (включаючи опір обмотки, щіткового контакту та з'єднувальних проводів).

Виразимо струм якоря `I` як функцію кутової швидкості `ω`:

```
I(ω) = (U − k_e · ω) / R                         [струм якоря через різницю напруги та протиЕРС]
```

Підставимо отриманий вираз струму в рівняння електромагнітного моменту `M = k_t · I`:

```
M(ω) = k_t · (U − k_e · ω) / R                   [підстановка струму в рівняння моменту]
     = (k_t · U) / R − ((k_t · k_e) / R) · ω     [розкриття дужок та розділення доданків]
```

Виразимо кутову швидкість `ω` як явну функцію розвиваного крутного моменту `M`:

```
((k_t · k_e) / R) · ω = (k_t · U) / R − M        [перенесення доданка зі швидкістю вліво]
ω(M) = U / k_e − (R / (k_t · k_e)) · M           [ділення обох частин на (k_t · k_e / R)]
```

Це рівняння є канонічним рівнянням лінійної механічної характеристики `ω(M)`.

Визначимо характерні точки характеристики:

1. Швидкість ідеального холостого ходу `ω_0` (при нульовому корисному моменті `M = 0`):

```
ω_0 = U / k_e                                    [швидкість холостого ходу при M = 0]
```

2. Пусковий момент або момент заклинювання `M_stall` (при зупиненому роторі `ω = 0`):

```
M_stall = (k_t · U) / R = k_t · I_stall          [пусковий момент при ω = 0]
```

де `I_stall = U / R` — пусковий (стопорний) струм.

Підставивши вирази `ω_0` та `M_stall` у рівняння механічної характеристики, отримаємо компактну форму запису:

```
ω(M) = ω_0 · (1 − M / M_stall)                   [механічна характеристика у відносних координатах]
```

Крутизна характеристики (механічна жорсткість приводу `β` або коефіцієнт регулювання швидкості `s`):

```
s = dω / dM = −R / (k_t · k_e) = −ω_0 / M_stall  [похідна швидкості за моментом]
```

Знак мінус показує, що зі збільшенням навантаження швидкість двигуна зменшується за лінійним законом.

### 4. Дослідження корисної механічної потужності на екстремум

Корисна механічна потужність на валу двигуна дорівнює добутку крутного моменту на кутову швидкість:

```
P_mech(M) = M · ω(M)                             [означення механічної потужності обертання]
          = M · ω_0 · (1 − M / M_stall)          [підстановка лінійної характеристики ω(M)]
          = ω_0 · M − (ω_0 / M_stall) · M²       [розкриття дужок — квадратична парабола]
```

Функція `P_mech(M)` являє собою параболу, спрямовану вітками вниз, з нулями у точках `M = 0` та `M = M_stall`.

Знайдемо точку екстремуму, взявши першу похідну від потужності за моментом та прирівнявши її до нуля:

```
dP_mech / dM = ω_0 − (2 · ω_0 / M_stall) · M     [обчислення першої похідної за моментом M]
ω_0 − (2 · ω_0 / M_stall) · M_opt = 0            [умова екстремуму першого порядку]
M_opt = ½ · M_stall                              [момент, при якому досягається максимум потужності]
```

Обчислимо кутову швидкість `ω_opt`, яка відповідає цьому моменту:

```
ω_opt = ω(M_opt)                                 [підстановка M_opt у характеристику ω(M)]
      = ω_0 · (1 − (½ · M_stall) / M_stall)      [спрощення дробу]
      = ½ · ω_0                                  [швидкість у точці максимуму потужності]
```

Обчислимо максимальну механічну потужність `P_mech_max`:

```
P_mech_max = M_opt · ω_opt                       [підстановка оптимальних значень моменту й швидкості]
           = (½ · M_stall) · (½ · ω_0)           [перемноження половинок]
           = ¼ · M_stall · ω_0                   [максимальна механічна потужність мотора]
```

Підставивши вирази через параметри двигуна (`M_stall = k_t · U / R` та `ω_0 = U / k_e`):

```
P_mech_max = ¼ · (k_t · U / R) · (U / k_e)       [підстановка фізичних параметрів мотора]
           = ¼ · (U² / R) · (k_t / k_e)          [групування доданків]
           = ¼ · U² / R                          [враховуючи тотожність k_t = k_e в системі SI]
```

Таким чином, максимальна корисна механічна потужність двигуна залежить виключно від квадрата прикладеної напруги та внутрішнього активного опору якоря `R`, становлячи рівно 25% від теоретичної потужності заклинювання `P_stall_elec = U · I_stall = U² / R`.

### 5. Точка максимального коефіцієнта корисної дії (ККД)

Коефіцієнт корисної дії двигуна визначається як відношення корисної механічної потужності до споживаної електричної потужності:

```
η = P_mech / P_elec                              [визначення коефіцієнта корисної дії]
  = (M · ω) / (U · I)                            [розгортання електричної та механічної потужностей]
```

У реальному двигуні повний струм якоря складається зі струму навантаження `I_load = M / k_t` та струму холостого ходу `I_0`, необхідного для подолання сил тертя в підшипниках, щітках та втрат на вихрові струми й гістерезис у магнітопроводі:

```
I = I_0 + M / k_t                                [повний струм із урахуванням втрат холостого ходу]
```

Підставимо вирази для `ω(M)` та `I(M)` у формулу ККД:

```
η(M) = (M · ω_0 · (1 − M / M_stall)) / (U · (I_0 + M / k_t))
```

Враховуючи, що `ω_0 = U / k_e` та `k_e = k_t = k`:

```
η(M) = (M · (1 − M / M_stall)) / (M + k · I_0)   [вираз ККД як функція моменту навантаження]
```

Диференціюючи вираз `η(M)` за `M` та прирівнюючи похідну до нуля, отримуємо оптимальний момент для максимуму ККД:

```
M_eta_max = k · I_0 · (sqrt(1 + M_stall / (k · I_0)) − 1)
```

Оскільки струм холостого ходу `I_0` значно менший за пусковий струм `I_stall` (типово `I_0 ≈ 0.02...0.08 · I_stall`), оптимальний момент максимального ККД лежить у діапазоні:

```
M_eta_max ≈ 0.15 ... 0.30 · M_stall              [оптимальний момент максимального ККД]
ω_eta_max ≈ 0.70 ... 0.85 · ω_0                  [відповідна швидкість максимального ККД]
```

Максимальний ККД становить:

```
η_max = (1 − sqrt(I_0 / I_stall))²               [теоретична формула пікового ККД мотора]
```

Цей результат доводить, чому не можна вибирати мотор так, щоб його постійна робоча точка знаходилася в зоні `P_max` (де `M = 0.5 · M_stall`): у точці `P_max` ККД становить менше ніж 50%, а половина підведеної електричної потужності безпосередньо перетворюється на теплові втрати в обмотці якоря.

### 6. Аналітичний розрахунок робочої точки під різними типами навантаження

Робоча точка електроприводу в усталеному режимі визначається розв'язанням системи рівнянь, що складається з механічної характеристики двигуна `M_motor(ω)` та статичної характеристики навантаження `M_load(ω)`:

```
M_motor(ω) = M_load(ω)                           [умова рівноваги моментів на валу]
```

Розгляньмо три найпоширеніші в інженерній практиці аналітичні моделі навантаження:

#### А. Навантаження з постійним моментом (сухе тертя, підйом вантажу, гравітація)

Характеристика навантаження: `M_load(ω) = M_const`.

Рівняння рівноваги:

```
M_stall · (1 − ω_op / ω_0) = M_const             [прирівнювання мотора та навантаження]
1 − ω_op / ω_0 = M_const / M_stall               [ділення на M_stall]
ω_op = ω_0 · (1 − M_const / M_stall)             [усталена швидкість під постійним моментом]
```

Струм двигуна в робочій точці:

```
I_op = I_0 + M_const / k_t                       [робочий струм якоря]
```

#### Б. В'язке лінійне тертя (гідродинамічні опори, рідинні демпфери)

Характеристика навантаження: `M_load(ω) = B · ω`, де `B` — коефіцієнт в'язкого тертя (Н·м·с/рад).

Рівняння рівноваги:

```
M_stall · (1 − ω_op / ω_0) = B · ω_op            [прирівнювання характеристик]
M_stall = (B + M_stall / ω_0) · ω_op             [групування доданків зі швидкістю ω_op]
ω_op = M_stall / (B + M_stall / ω_0)             [вираження усталеної кутової швидкості]
```

Поділивши чисельник і знаменник на `M_stall / ω_0`:

```
ω_op = ω_0 / (1 + (B · ω_0) / M_stall)           [швидкість при в'язкому лінійному терті]
     = ω_0 / (1 + (B · R) / (k_t · k_e))         [підстановка фізичних параметрів мотора]
```

#### В. Квадратичне аеродинамічне/вентиляторне навантаження (пропелери, крильчатки, насоси)

Характеристика навантаження: `M_load(ω) = C · ω²`, де `C` — аеродинамічний коефіцієнт навантаження (Н·м·с²/рад²).

Рівняння рівноваги:

```
M_stall · (1 − ω_op / ω_0) = C · ω_op²           [прирівнювання до квадратичного навантаження]
C · ω_op² + (M_stall / ω_0) · ω_op − M_stall = 0 [зведення до стандартного квадратного рівняння]
```

Розв'яжемо квадратне рівняння відносно `ω_op` (обираємо додатний корінь, оскільки швидкість додатна):

```
Дискримінант: D = (M_stall / ω_0)² + 4 · C · M_stall
```

Усталена кутова швидкість:

```
ω_op = (−(M_stall / ω_0) + sqrt((M_stall / ω_0)² + 4 · C · M_stall)) / (2 · C)
```

Ці аналітичні вирази дозволяють точно обчислювати динамічні характеристики електроприводу без ітераційних наближень.
