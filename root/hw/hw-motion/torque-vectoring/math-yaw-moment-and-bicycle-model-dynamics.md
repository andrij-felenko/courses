## Одноколійна динамічна модель автомобіля: рівняння рискання

Для аналізу динаміки керованості та стійкості колісних транспортних засобів класичним інженерним інструментом є лінеаризована одноколійна модель (Bicycle Model), запропонована Міллікеном. У цій моделі права та ліва шини кожної осі об'єднуються в одне умовне колесо на поздовжній осі симетрії.

Динаміка транспортного засобу на площині описується двома зв'язаними ступенями вільності: кутом знесення кузова `beta` (кут між вектором швидкості центру мас `V` та поздовжньою віссю автомобіля) та кутовою швидкістю рискання `omega_z = d(psi)/dt`:
```
m * V * (d(beta)/dt + omega_z) = F_yF + F_yR
I_z * (d(omega_z)/dt) = a * F_yF - b * F_yR + M_z_tv
```
де `m` — повна маса машини, `I_z` — центральний момент інерції відносно вертикальної осі Z, `a` та `b` — відстані від центру мас до передньої та задньої осей відповідно, `F_yF` та `F_yR` — бічні сили зчеплення шин, а `M_z_tv` — додатковий активний повертальний момент від векторування тяги.

При малих кутах ковзання шин `alpha_F` та `alpha_R` бічні сили лінійно пропорційні коефіцієнтам опору знесенню шин (Cornering stiffness) `C_F` та `C_R`: `F_yF = -C_F * alpha_F`, `F_yR = -C_R * alpha_R`.

Практичне впровадження розглянутих інженерних рішень вимагає комплексної верифікації параметрів у реальних умовах експлуатації. Аналіз перехідних процесів, температурних деформацій та динамічних вібрацій дозволяє точно калібрувати робочі коефіцієнти запасу надійності, забезпечуючи безвідмовну роботу механізму під дією непередбачуваних зовнішніх навантажень.

## Додатковий повертальний момент від різниці поздовжніх сил

Векторування тяги порушує симетрію поздовжніх сил правого та лівого бортів. Якщо на колеса однієї осі з шириною колії `B` подаються різні поздовжні тягові сили `F_x_right` та `F_x_left`, різниця сил `Delta_F_x = F_x_right - F_x_left` створює прямий адитивний повертальний момент відносно центру мас:
```
M_z_tv = Delta_F_x * (B / 2)
```
Підставляючи цей момент у друге рівняння динаміки автомобіля, отримуємо вираз для прискорення кутової швидкості рискання:
```
d(omega_z)/dt = (a * F_yF - b * F_yR + Delta_F_x * (B / 2)) / I_z
```
На відміну від звичайного повороту керма, де керуючий момент утворюється виключно за рахунок бічних сил шин `F_yF` і вимагає часу на розвиток кута ковзання (типова фазова затримка 100–200 мс), повертальний момент від векторування тяги `M_z_tv` діє безпосередньо через поздовжнє зчеплення. Це забезпечує миттєву реакцію кузова на дії водія або стабілізуючого автопілота, повністю компенсуючи небажану недостатню або надмірну повертальність.

## Фазовий портрет керованості та круг тертя Камма

Граничні можливості будь-якої системи керування динамікою автомобіля обмежуються фізичним зчепленням шини з дорожнім покриттям. Згідно з класичною гіпотезою Камма (Kamm's friction circle), максимальна сила, яку шина здатна передати дорозі, обмежена добутком вертикального навантаження `F_z` на коефіцієнт зчеплення `mu`:
```
sqrt(F_x^2 + F_y^2) <= mu * F_z
```
Це означає, що збільшення поздовжньої тягової або гальмівної сили `F_x` неминуче зменшує максимально доступну бічну силу `F_y_max = sqrt((mu * F_z)^2 - F_x^2)`. Якщо система векторування тяги подасть надмірний момент на зовнішнє колесо, шина зірветься в повне ковзання, бічна сила впаде до нуля, і транспортний засіб миттєво втратить керованість.

Для гарантування стабільності алгоритм векторування тяги будує фазовий портрет у просторі станів `(beta, omega_z)`: кут знесення кузова проти швидкості рискання. Границі стійкості (боундінги Ляпунова) визначають безпечний опуклий фазовий коридор:
```
|beta| <= beta_max(mu, V)
|omega_z| <= (mu * g) / V
```
Контролер верхнього рівня (Yaw Moment Controller) розраховує коригувальний повертальний момент `M_z_cmd` таким чином, щоб фазова траєкторія машини завжди залишалася всередині безпечної зони притягання. Якщо розрахунковий момент вимагає перевищення межі круга Камма, оптимізатор автоматично підтискає внутрішні гальма або зменшує тягу, максимізуючи повертальність без зриву коліс у бічний юз.
