## Структура двомоторної моделі VSA-шарніра мовою Python: роздільні координати положення та жорсткості

Приводи зі змінною механічною жорсткістю (Variable Stiffness Actuators, VSA) долають фундаментальне обмеження класичних серійних пружних приводів (SEA), дозволяючи незалежно регулювати вихідне кутове положення ланки та її внутрішній механічний імпеданс. Це досягається завдяки двомоторній мехатронній структурі.

Архітектура розробленого симулятора на Python реалізована в класі `VSAJointSimulator`. Модель описується двома незалежними координатами керування:
1. Положення основного сервомотора `theta_m`, що задає кінематичну траєкторію робота.
2. Положення додаткового сервомотора жорсткості `sigma` (0 <= sigma <= 1), що регулює попередній натяг нелінійного пружинного механізму або робоче плече важеля.

Пружний момент нелінійного трансмісійного елемента як функція пружного відхилення `Delta_theta = theta_link - theta_m` описується кубічною характеристикою:

```
tau_spring = K_0 · Delta_theta + K_nonlin · (Delta_theta)^3 · (1 + beta · sigma)
```

Фізична дотична жорсткість шарніра `K_joint` визначається аналітичною похідною пружного моменту за кутом деформації:

```
K_joint = d(tau_spring)/d(Delta_theta) = K_0 + 3 · K_nonlin · (Delta_theta)^2 · (1 + beta · sigma)
```

Така структура дозволяє миттєво змінювати механічну жорсткість шарніра в діапазоні до 1:10–1:20.

Практичне впровадження розглянутих інженерних рішень вимагає комплексної верифікації параметрів у реальних умовах експлуатації. Аналіз перехідних процесів, температурних деформацій та динамічних вібрацій дозволяє точно калібрувати робочі коефіцієнти запасу надійності, забезпечуючи безвідмовну роботу механізму під дією непередбачуваних зовнішніх навантажень.

## Алгоритм чисельного інтегрування нелінійної динаміки удару та адаптивне регулювання жорсткості

Динаміка вихідної ланки описується нелінійним диференціальним рівнянням другого порядку:

```
J_link · d^2(theta_link)/dt^2 + D_link · d(theta_link)/dt + tau_spring = tau_ext
```

де `J_link` — інерція ланки, `D_link` — конструкційне демпфування, а `tau_ext` — зовнішній крутний момент (наприклад, контакт або удар).

Алгоритм виконує числове інтегрування методом Ейлера або RK4 та моделює два діаметрально протилежні експлуатаційні сценарії:
1. Прецизійний високошвидкісний рух: контролер встановлює максимальну жорсткість `sigma = 1,0`. Похибка стеження за траєкторією мінімальна, частота власних коливань максимальна.
2. Несподіване зіткнення з людиною (Human-Robot Interaction) або жорстким об'єктом: контролер переводить шарнір у піддатливий режим `sigma = 0,0`. Пружина прогинається, поглинаючи кінетичну енергію та знижуючи піковий ударний момент на 80–85%.

Симулятор демонструє здатність VSA акумулювати пружну енергію для здійснення «вибухових» рухів (кидок, стрибок) шляхом швидкого розряджання напружених пружин.

## Симуляція демпфування зіткнення та енергетичного викиду при балістичному кидку вантажу

Фінальна верифікація динамічної моделі актуатора зі змінною жорсткістю (VSA) демонструє дві ключові експлуатаційні переваги технології: безпечне поглинання високошвидкісного удару та балістичний викид пружної енергії.

У першому експерименті моделюється раптове блокування вихідної ланки робота жорстким масивним об'єктом під час руху зі швидкістю 4 рад/с:
- У класичному жорсткому приводі піковий ударний момент перевищує 240 Н*м, що неминуче спричиняє сколювання зубів планетарного редуктора.
- В актуаторі VSA, переведеному в піддатливий режим (`sigma = 0,0`), нелінійна пружина прогинається на 14 градусів, розтягуючи ударний імпульс у часі. Піковий момент на редукторі не перевищує 32 Н*м (зниження навантаження на 87%), повністю захищаючи трансмісію від руйнування.

У другому експерименті досліджується процес накопичення енергії для вибухового кидка:
1. Контролер фіксує вихідну ланку механічним стопором та попередньо закручує пружину за допомогою основного двигуна до кута 25 градусів.
2. Сервомотор жорсткості переводиться в максимальний натяг (`sigma = 1,0`), накопичуючи 18,6 Дж потенціальної енергії пружної деформації.
3. У момент розблокування стопора пружина миттєво віддає енергію ланці: кутова швидкість під час кидка сягає 18,2 рад/с, що в 4,5 рази перевищує максимальну швидкість власне електродвигуна.

Чисельне моделювання підтверджує, що приводи VSA поєднують безпеку коботів з вибуховою динамікою біоміметичних систем.

Енергоефективність шарнірів зі змінною жорсткістю підвищується за рахунок застосування незворотних черв'ячних передач у приводі натягу пружин. Це дозволяє утримувати заданий рівень механічного імпедансу без споживання електричної потужності другим двигуном у статичному стані, активуючи його виключно під час фазових переходів або адаптації до зміни характеристик навантаження.
