## Математичні моделі нелінійної пружності: антагоністичні схеми та кулачки

На відміну від приводів із фіксованою серійною пружністю (Series Elastic Actuators, SEA), де коефіцієнт жорсткості `K` є постійною величиною, приводи зі змінною жорсткістю (VSA) реалізують керовану нелінійну залежність крутного моменту від кута пружної деформації.

Існують дві основні кінематичні топології реалізації VSA:
1. Антагоністична конфігурація (Antagonistic VSA): вихідний вал з'єднаний із двома незалежними серводвигунами через пару нелінійних пружин із прогресивною характеристикою натягу (сила квадратично або експоненційно зростає зі зміщенням). Якщо обидва мотори повертаються в одному напрямку, кутове положення вихідного вала змінюється при постійній жорсткості. Якщо мотори повертаються назустріч один одному, внутрішній натяг пружин зростає, різко збільшуючи сумарну жорсткість шарніра без зміни кута повороту.
2. Конфігурація з роздільним керуванням положенням і жорсткістю (Independent Position-Stiffness VSA): перший потужний двигун через редуктор задає основне кутове положення ланки, а другий, менш потужний сервопривод переміщує точку опори пружного важеля або обертає фасонний кулачок, змінюючи плече прикладання сили лінійної пружини.

Математична характеристика моменту нелінійного пружного елемента описується поліноміальною або тригонометричною залежністю:
```
tau_spring(delta_theta) = k_1 * delta_theta + k_2 * delta_theta^3
```
де `delta_theta = theta_out - theta_in` — кут пружного скручування.

Практичне впровадження розглянутих інженерних рішень вимагає комплексної верифікації параметрів у реальних умовах експлуатації. Аналіз перехідних процесів, температурних деформацій та динамічних вібрацій дозволяє точно калібрувати робочі коефіцієнти запасу надійності, забезпечуючи безвідмовну роботу механізму під дією непередбачуваних зовнішніх навантажень.

## Аналітичне виведення миттєвої диференційної жорсткості шарніра

Фундаментальною динамічною характеристикою привода зі змінною жорсткістю є диференційна (миттєва) жорсткість `K_joint`, яка визначає пружний опір вихідного вала зовнішньому макрозбуренню:
```
K_joint = d(tau_joint) / d(theta_out)
```
Для симетричної антагоністичної системи, керованої положеннями двох приводів `q_1` та `q_2`, результуючий вихідний крутний момент дорівнює алгебричній різниці моментів двох пружних каналів:
```
tau_joint(q_1, q_2, theta_out) = tau_1(q_1 - theta_out) - tau_2(theta_out - q_2)
```
Введемо узагальнені координати: координату рівноваги `q_pos = 0,5 * (q_1 + q_2)` та внутрішню координату коконтракції (попереднього натягу) `q_stiff = 0,5 * (q_1 - q_2)`.

Тоді для квадратично нелінійних пружних елементів `tau_i(phi) = c * phi * |phi|` диференціювання сумарного моменту за кутом виходу дає точний аналітичний вираз для жорсткості:
```
K_joint = - (d(tau_1)/d(theta_out) + d(tau_2)/d(theta_out)) = 2 * c * q_stiff
```
Звідси випливає фундаментальна інженерна властивість VSA: крутний момент шарніра лінійно пропорційний похибці кута `(q_pos - theta_out)`, тоді як диференційна жорсткість `K_joint` повністю контролюється параметром попереднього стиснення `q_stiff`, забезпечуючи повне динамічне розв'язання контурів позиції та пружності.

## Рівняння накопичення потенціальної пружної енергії та вибухове скидання потужності

Ключовою енергетичною перевагою приводів зі змінною жорсткістю є здатність накопичувати потенціальну механічну енергію пружної деформації під час повільної фази руху та практично миттєво вивільняти її, генеруючи пікову механічну потужність, яка в рази перевищує номінальну електричну потужність електродвигунів.

Повна потенціальна енергія `E_pot`, акумульована в нелінійних пружних елементах VSA при деформації на кут `delta_theta`, визначається визначеним інтегралом від функції пружного моменту:
```
E_pot = integral_0^{delta_theta} tau_spring(phi) d(phi) = 0,5 * k_1 * delta_theta^2 + 0,25 * k_2 * delta_theta^4
```
При реалізації вибухових динамічних рухів (стрибки, удари, метання маніпулятором спортивного снаряда) керування розбивається на дві фази:
1. Фаза накопичення (Pumping phase): шарнір переводиться в режим високої жорсткості, і обидва приводи за відносно тривалий час `T_charge` (наприклад, 0,5–1,0 с) деформують пружини, закачуючи енергію від бортового акумулятора в механічне напруження металу.
2. Фаза вибухового вивільнення (Explosive discharge): контролер різко розвантажує або швидко змінює положення важеля жорсткості на протилежне. Пружини розпрямляються за час `T_discharge` порядка 20–50 мілісекунд.

Пікова механічна потужність, що передається кінцевій ланці робота, становить:
```
P_peak = E_pot / T_discharge >> P_motor_rated = E_pot / T_charge
```
Коефіцієнт підсилення миттєвої потужності `P_peak / P_motor` може досягати значень від 5 до 12, що дозволяє легким мобільним роботам здійснювати високі стрибки та долати вертикальні бар'єри, значно перевершуючи обмеження класичних електроприводів.
