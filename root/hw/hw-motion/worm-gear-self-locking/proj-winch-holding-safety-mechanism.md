## Технічне завдання та розрахункова модель підйомної лебідки

Проектування підйомної лебідки у промислових кранах, вантажних підйомниках та сценічних механізмах починається із забезпечення базової вимоги безпеки: підвішений вантаж ні за яких обставин не повинен самовільно впасти при вимкненні живлення приводу чи аварійній зупинці. На відміну від горизонтальних конвеєрів або тягових візків, у вертикальних вантажопідйомних машинах навантаження є потенційним (гравітаційним). Воно безперервно діє на барабан лебідки, намагаючись провернути трансмісію у зворотному напрямку.

Розглянемо типове технічне завдання для вантажного підйомника малої та середньої тоннажності:
- Номінальна маса вантажу з урахуванням маси гака та строп: `m_load = 500 кг` (розрахункова статична вантажопідйомність `F_load = m_load · g = 500 · 9.81 = 4905 Н`).
- Робочий радіус намотування троса на нарізний барабан: `R_drum = 0.10 м` (діаметр барабана `D_drum = 200 мм`).
- Лінійна швидкість підйому вантажу: `v_lift = 0.25 м/с`.
- Режим роботи за класифікацією FEM / ISO: середній (коефіцієнт динамічності підйому `K_dyn = 1.25`).
- Температурний діапазон експлуатації: від `-10 °C` до `+40 °C`.

> 🔧 **Навіщо це.** Статичний розрахунок навантаження на тихохідному валу барабана задає вихідний крутний момент для всієї силової лінії лебідки, визначаючи міцнісні габарити валів, тип вальниць і мінімально необхідне передавальне відношення редуктора.

Окрему увагу на стадії технічного завдання слід приділити вибору діаметра та типу сталевого каната. Для розрахункового натягу `F_load = 4905 Н` згідно з нормативами безпеки вантажопідйомних машин застосовується коефіцієнт запасу міцності каната не менше `Z_p ≥ 5.0` для звичайних вантажів або `Z_p ≥ 8.0` для небезпечних вантажів. Обирається шестипасмовий сталевий канат типу ЛК-РО з органічним або металевим осердям (стандарт EN 12385-4) діаметром `d_rope = 6.3 мм` із розривним зусиллям понад `28 кН`. Мінімальний діаметр нарізного барабана перевіряється за геометричним критерієм згину `D_drum / d_rope ≥ 25`, що з запасом виконується для `D_drum = 200 мм` (`200 / 6.3 ≈ 31.7 ≥ 25`), мінімізуючи контактні та втомні напруження згину дротин.

Статичний крутний момент, прикладений до вала барабана від ваги номінального вантажу, визначається радіусом намотування та втратами на тертя в підшипникових опорах барабана (ККД опор `η_drum ≈ 0.96`):

```text
T_drum = (F_load · R_drum) / η_drum
T_drum = (4905 · 0.10) / 0.96 = 510.9 Н·м
```

З урахуванням динамічного перевантаження під час пуску та відриву вантажу від опорної поверхні піковий статичний момент на барабані досягає:

```text
T_drum,peak = T_drum · K_dyn = 510.9 · 1.25 = 638.6 Н·м
```

Для забезпечення зазначеної лінійної швидкості підйому `v_lift = 0.25 м/с` кутова швидкість обертання барабана становить:

```text
ω_drum = v_lift / R_drum = 0.25 / 0.10 = 2.50 рад/с (або n_drum = (60 · ω_drum) / (2 · π) ≈ 23.9 об/хв)
```

Корисна потужність, необхідна безпосередньо для підйому вантажу з постійною швидкістю:

```text
P_useful = F_load · v_lift = 4905 · 0.25 = 1226.3 Вт ≈ 1.23 кВт
```

Якщо підйомник оснащено звичайним циліндричним або конічним редуктором із високим ККД прямого та зворотного ходу (`η ≈ 0.96 ... 0.98`), то при раптовому знеструмленні двигуна момент вантажу `510.9 Н·м` миттєво розжене трансмісію у зворотний бік, перевівши двигун у генераторний режим із катастрофічним падінням вантажу. Тому в основі концепції розроблюваної лебідки лежить черв'ячна передача, спроектована на межі трибологічного самогальмування.

## Підбір параметрів черв'ячного зачеплення для самогальмування

Для реалізації принципу геометричного й трибологічного утримання вантажу обираємо одноступеневий черв'ячний редуктор із циліндричним архімедовим або евольвентним черв'яком. Ключовою умовою самогальмування є вибір мінімального числа заходів черв'яка: тільки однозахідний черв'як (`z₁ = 1`) забезпечує достатньо малий кут підйому гвинтової лінії на ділильному циліндрі.

Обираємо стандартні параметри зачеплення згідно з ISO:
- Кількість заходів черв'яка: `z₁ = 1`.
- Кількість зубів черв'ячного колеса: `z₂ = 40` (передавальне число редуктора `u = i = z₂ / z₁ = 40 / 1 = 40`).
- Осьовий модуль зачеплення: `m = 5.0 мм`.
- Коефіцієнт діаметра черв'яка: `q = 10` (ділильний діаметр черв'яка `d₁ = q · m = 10 · 5.0 = 50.0 мм`).
- Ділильний діаметр черв'ячного колеса: `d₂ = z₂ · m = 40 · 5.0 = 200.0 мм`.
- Міжосьова відстань передачі: `a_w = (d₁ + d₂) / 2 = (50.0 + 200.0) / 2 = 125.0 мм`.
- Стандартний профільний кут зачеплення в осьовому перерізі: `α_n = 20°`.

> 🔧 **Навіщо це.** Вибір параметрів `z₁ = 1` та `q = 10` однозначно фіксує кут підйому гвинтової лінії `γ`. Якщо взяти двозахідний черв'як (`z₁ = 2`), кут `γ` зросте вдвічі, і передача гарантовано втратить властивість самогальмування, перетворившись на зворотний привід.

Теоретичний кут підйому витка черв'яка на ділильному циліндрі визначається відношенням числа заходів до коефіцієнта діаметра:

```text
tan(γ) = z₁ / q = 1 / 10 = 0.1000
γ = arctan(0.1000) ≈ 5.711° (5° 42' 38")
```

Для перевірки умови статичного самогальмування необхідно визначити зведений кут тертя `ρ'`. При розрахунку пари сталевий цементований черв'як (твердість `58 ... 62 HRC`) — бронзове колесо (олово-фосфориста бронза БрО10Ф1 або CuSn12Ni) з мастилом на поліальфаолефіновій основі ISO VG 460 статичний коефіцієнт тертя спокою становить `μ_static = 0.09 ... 0.12`. Зведений коефіцієнт тертя враховує розклинювальний ефект бокових граней зуба:

```text
tan(ρ') = μ' = μ_static / cos(α_n) = 0.10 / cos(20°) = 0.10 / 0.9397 ≈ 0.1064
ρ' = arctan(0.1064) ≈ 6.074° (для μ = 0.10)
```

При консервативній оцінці з коефіцієнтом тертя спокою чистої сухої поверхні чи збідненого мастила `μ_static = 0.12`:

```text
tan(ρ') = 0.12 / 0.9397 ≈ 0.1277
ρ' = arctan(0.1277) ≈ 7.278°
```

Умова статичного утримання виконується, оскільки кут підйому витка менший за зведений кут тертя:

```text
γ = 5.711° < ρ' = 6.074° ... 7.278°
```

Коефіцієнт корисної дії черв'ячної пари при прямому ході (рух від черв'яка до колеса при підйомі вантажу) визначається співвідношенням:

```text
η_direct = tan(γ) / tan(γ + ρ')
η_direct = 0.1000 / tan(5.711° + 6.074°) = 0.1000 / tan(11.785°) = 0.1000 / 0.2086 ≈ 0.479 (47.9%)
```

При динамічному русі зі швидкістю ковзання `v_s ≈ 1.5 м/с` коефіцієнт тертя падає до `μ_dyn ≈ 0.04 ... 0.05`, завдяки чому робочий ККД підйому зростає до `η_direct,dyn ≈ 0.65 ... 0.70`. Проте при спробі зворотного обертання від колеса до черв'яка теоретичний ККД зворотного ходу стає від'ємним:

```text
η_reverse = tan(γ - ρ') / tan(γ) = tan(5.711° - 6.074°) / 0.1000 = tan(-0.363°) / 0.1000 ≈ -0.063
```

Від'ємне значення ККД зворотного ходу означає, що сила, спрямована на опускання вантажу, лише збільшує нормальний тиск у зоні контакту зубів і заклинює передачу, підтверджуючи ефект геометричного самогальмування в нерухомому стані.

## Інженерний розрахунок запасу гальмування при вібраціях

Найпідступніша інженерна пастка при проектуванні черв'ячних підйомників полягає в тому, що статичне самогальмування (`γ < ρ'`) гарантує утримання вантажу лише в стані абсолютного спокою за відсутності динамічних коливань. У реальних умовах експлуатації лебідка зазнає вібрацій від роботи сусідніх дизель-генераторів, руху кранового візка рейками, вітрових поривів або пружних коливань натягнутого сталевого каната при зупинці.

Зовнішні високочастотні мікровібрації збуджують мікрозсуви в контактній плямі зубів черв'яка та вінця. При цьому статичне тертя зчіплення (`μ_static ≈ 0.10 ... 0.12`) руйнується і переходить у кінематичне тертя ковзання (`μ_dynamic ≈ 0.03 ... 0.04`). Відповідно динамічний зведений кут тертя стрімко падає:

```text
tan(ρ'_dyn) = μ_dynamic / cos(α_n) = 0.035 / cos(20°) = 0.035 / 0.9397 ≈ 0.0372
ρ'_dyn = arctan(0.0372) ≈ 2.13°
```

Оскільки кут підйому нашого черв'яка `γ = 5.71°` виявляється значно більшим за динамічний кут тертя `ρ'_dyn ≈ 2.13°`, передача під дією вібрацій миттєво втрачає самогальмування. Починається так зване явище «повзучого сповзання» або лавиноподібного розгону вантажу донизу.

> 🔧 **Навіщо це.** Критерій вібраційного запасу самогальмування дає об'єктивну кількісну оцінку того, чи здатна передача гарантовано тримати вантаж в умовах заводського цеху або будівельного майданчика без допоміжних утримуючих пристроїв.

Для кількісної оцінки надійності самогальмування стандарт машинобудування вводить безрозмірний коефіцієнт запасу самогальмування `S_sl`:

```text
S_sl = tan(ρ') / tan(γ)
```

- Якщо `S_sl > 1.0` за статичного тертя — передача утримує вантаж у стані спокою. Для нашого редуктора:
  `S_sl,static = tan(6.074°) / tan(5.711°) = 0.1064 / 0.1000 = 1.064`.
- Для надійного самогальмування в умовах помірних технологічних вібрацій нормативи вимагають коефіцієнт запасу не менше `S_sl,req ≥ 1.5 ... 2.0`.
- В умовах активних вібрацій динамічний коефіцієнт становить:
  `S_sl,dyn = tan(2.13°) / tan(5.711°) = 0.0372 / 0.1000 = 0.372 << 1.0`.

Оскільки `S_sl,dyn < 1.0`, черв'ячна пара самостійно НЕ гарантує безпечного утримання вантажу при вібраціях. При виникненні зворотного обертання від ваги вантажу черв'як починає розкручуватися, генеруючи на своєму вхідному валу розгінний динамічний крутний момент:

```text
T_backdrive = (T_drum / (u · η_drum)) · (1 - tan(ρ'_dyn) / tan(γ))
T_backdrive = (510.9 / (40 · 0.96)) · (1 - 0.372) = 13.3 · 0.628 ≈ 8.35 Н·м
```

Отже, для запобігання вібраційному зриву на швидкохідний вал черв'яка необхідно постійно прикладати утримуючий гальмівний момент не менше `8.35 Н·м` (з інженерним коефіцієнтом запасу `k_safe = 2.0` — не менше `16.7 Н·м`).

## Дублювання безпеки електромеханічним дисковим гальмом

Міжнародні стандарти безпеки вантажопідйомних механізмів (зокрема ISO 13849 «Безпека машин» та EN 14492-1 «Лебідки та талі») суворо забороняють покладатися виключно на ефект самогальмування черв'ячної передачі як єдиний засіб захисту від падіння вантажу. Попадання рідкого або перегрітого мастила, зношування робочих граней, випадковий поштовх або зупинка на вібруючій рамі здатні зняти самоблокування за частки секунди.

Архітектура промислової безпеки вимагає обов'язкового дублювання: встановлення нормально замкненого (fail-safe) електромеханічного дискового гальма на вхідному швидкохідному валу черв'яка (між ротором приводного електродвигуна та черв'ячним валом).

Принцип роботи нормально замкненого гальма:
1. **Знеструмлений стан (безпечний спокій):** потужні тарілчасті або циліндричні пружини притискають якір до гальмівного диска зі фрикційними накладками, створюючи постійний утримуючий момент `T_brake ≥ 20 Н·м`. Будь-яке аварійне знеструмлення, спрацьовування кнопки «E-Stop» або обрив кабелю автоматично активує гальмо.
2. **Робочий рух (підйом або керований спуск):** контролер приводу одночасно з подачею напруги на обмотки двигуна подає постійний струм на електромагніт розгальмування. Магнітне поле долає зусилля пружин, відтягує якір і звільняє вал для вільного обертання.

> 🔧 **Навіщо це.** Встановлення електромагнітного дискового гальма безпосередньо на швидкохідному валу дозволяє використовувати компактний гальмівний вузол із малим гальмівним моментом (`~20 Н·м`), оскільки навантаження редукується передавальним числом `u = 40`. Якби гальмо ставили на вал барабана, його момент мав би перевищувати `1000 Н·м`, що збільшило б масу та габарити вузла в десятки разів.

Схемотехнічне керування та алгоритм захисту:
- **Категорія безпеки PL d (ISO 13849-1):** коло живлення котушки гальма комутується двома послідовними контакторами безпеки (Dual Safety Relays) зі зворотним контролем залипання контактів (EDM — External Device Monitoring).
- **Часова затримка розгальмування:** для уникнення «провалу» вантажу при пуску контролер відкриває гальмо лише після того, як двигун сформував попередній крутний момент (Pre-torque), достатній для втримання вантажу на статичному нулі швидкості.
- **Швидкодіюче гасіння індуктивності:** котушка електромагніта шунтується варистором або RC-ланцюгом замість звичайного зворотного діода, що скорочує час механічного спрацьовування гальма при аварійній зупинці з 200–300 мс до 25–40 мс.
