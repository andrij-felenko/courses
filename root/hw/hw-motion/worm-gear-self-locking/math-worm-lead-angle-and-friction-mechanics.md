## Геометрія гвинтової поверхні та кут підйому витка

Черв'як є спеціальним видом косозубого циліндричного колеса, у якого кут нахилу лінії зуба настільки великий, що зуб перетворюється на неперервну гвинтову різьбу. Щоб кількісно описати геометрію зачеплення, розгорнемо циліндричну поверхню ділильного діаметра черв'яка `d₁` на координатну площину.

При розгортанні одного повного оберту черв'яка коловий периметр `π · d₁` утворює прилеглий катет прямокутного трикутника, а осьовий хід гвинтової лінії `p_z` — протилежний катет. Гіпотенуза цього трикутника відповідає розгорнутій гвинтовій лінії витка. Кут між гвинтовою лінією та торцевою площиною черв'яка (перпендикулярною до його осі) називається кутом підйому витка `γ`.

Осьовий хід різьби `p_z` залежить від осьового кроку `p_x` та кількості заходів (ниток) черв'яка `z₁`:

```
p_z = z₁ · p_x
    = z₁ · π · m
```

де `m` — стандартний осьовий модуль зачеплення. З прямокутного трикутника розгортки тангенс кута підйому витка визначається відношенням протилежного катета до прилеглого:

```
tan(γ) = p_z / (π · d₁)
       = (z₁ · π · m) / (π · d₁)
       = (z₁ · m) / d₁
```

В інженерних розрахунках відношення ділильного діаметра до модуля позначають коефіцієнтом діаметра черв'яка `q = d₁ / m`. Тоді формула кута підйому витка набуває простого канонічного вигляду:

```
tan(γ) = z₁ / q

γ = arctan(z₁ / q)
```

Коефіцієнт `q` стандартно вибирають із нормального ряду (наприклад, `q = 8, 10, 12.5, 16`) для забезпечення необхідної згинальної жорсткості тіла черв'яка. При виборі однозахідного черв'яка (`z₁ = 1`) і великого коефіцієнта `q = 16` кут підйому становить:

```
γ = arctan(1 / 16) ≈ 3.57°
```

Якщо ж черв'як чотиризахідний (`z₁ = 4`) при `q = 10`, кут зростає до:

```
γ = arctan(4 / 10) = arctan(0.4) ≈ 21.8°
```

Окрім осьового кроку `p_x`, для розрахунку міцності зубів колеса використовують нормальний модуль `m_n`. Оскільки зуби вінця колеса нахилені під кутом `γ`, нормальний крок зв'язаний з осьовим тригонометричною проєкцією:

```
p_n = p_x · cos(γ)

m_n = m · cos(γ)
```

Чим більший кут підйому `γ`, тим сильніше нормальний модуль відрізняється від осьового. Для самогальмівних передач з малими кутами `γ ≤ 6°` значення `cos(γ) ≥ 0.994`, тому нормальний та осьовий модулі практично збігаються, що спрощує підбір стандартного зуборізного інструмента.

Вибір коефіцієнта діаметра `q` безпосередньо диктується механічною жорсткістю вала черв'яка на згин. Під дією контактної радіальної сили `F_r` та колової сили колеса `F_t2` вал черв'яка прогинається подібно до двоопорної балки на міжпідшипниковій відстані `L`. Максимальний стріла прогину в зоні зачеплення не повинна перевищувати сотих часток модуля:

```
f_max = (F_res · L³) / (48 · E · I) ≤ (0.005 ... 0.01) · m
```

де `I = (π · d_f1⁴) / 64` — осьовий момент інерції перерізу западин черв'яка, а `E` — модуль пружності сталі (`2.06 · 10⁵` МПа). Якщо черв'як виконано з малим коефіцієнтом `q < 8`, діаметр його тіла виявляється недостатнім, що спричиняє пружний прогин вала під навантаженням. Прогин веде до зміщення плями контакту до країв зубів, різкого зростання локального тиску та руйнування масляної плівки. Збільшення ж `q` до 12.5 або 16 підвищує жорсткість вала в рази, але одночасно зменшує кут `γ`, що знижує кінематичну швидкість і прямий ККД, проте надійно фіксує систему в стані самогальмування.

Розглянемо покроковий числовий приклад проектування черв'яка під вимогу самогальмування. Нехай осьовий модуль дорівнює `m = 2.5` мм, міжосьова відстань передачі `a_w = 63` мм, а число заходів обрано мінімальним: `z₁ = 1`. Оберемо коефіцієнт діаметра `q = 10`. Ділильний діаметр черв'яка становить:

```
d₁ = q · m = 10 · 2.5 = 25.0 мм
```

Ділильний периметр черв'яка:

```
π · d₁ = 3.1416 · 25.0 = 78.54 мм
```

Осьовий хід однозахідного витка:

```
p_z = 1 · π · m = 1 · 3.1416 · 2.5 = 7.854 мм
```

Кут підйому витка:

```
tan(γ) = p_z / (π · d₁) = 7.854 / 78.54 = 0.1000

γ = arctan(0.1000) ≈ 5.71° (5°43')
```

Отриманий кут `γ = 5.71°` лежить нижче типового значення зведеного кута тертя спокою для пари сталь-бронза (`ρ'₀ ≈ 7° ... 9°`), що підтверджує надійне статичне самогальмування спроектованого вузла при зупинці приводу.

> 🔧 **Навіщо це.** Кут підйому `γ` є першим фундаментальним геометричним параметром, що визначає можливість самогальмування: чим менша кількість заходів `z₁` і чим масивніший вал черв'яка (більший `q`), тим менший кут `γ` і тим вища схильність передачі до надійного механічного блокування.

## Трибологія контакту та зведений кут тертя

На відміну від евольвентних циліндричних шестерень, де зуби котяться один по одному з незначним проковзуванням, у черв'ячній передачі рух у зоні зачеплення має характер інтенсивного неперервного ковзання вздовж гвинтових витків. Швидкість ковзання `v_s` у точці контакту спрямована вздовж дотичної до гвинтової лінії і значно перевищує колову швидкість колеса `v₂`:

```
v_s = v₁ / cos(γ)
    = (π · d₁ · n₁) / (60 · cos(γ))
```

де `n₁` — частота обертання черв'яка у хвилину, а `v₁` — колова швидкість черв'яка на ділильному діаметрі. Через постійне ковзання поверхні нагріваються, а тертя між сталевим полірованим витком черв'яка та бронзовим вінцем колеса описується контактною моделлю Кулона з урахуванням геометрії профілю різьби.

У нормальному перерізі витка робочі грані розташовані під кутом профілю `α` (для стандартних евольвентних та архімедових черв'яків кут профілю становить `α = 20°`). Клиновий ефект канавки призводить до того, що контактна нормальна сила `F_n`, яка діє перпендикулярно до похилої грані витка, перевищує радіально-осьове зусилля:

```
F_n = F_r / cos(α)
```

Збільшення сили притискання поверхонь викликає пропорційне зростання сили тертя `F_fr = μ · F_n = μ · F_r / cos(α)`. Щоб зберегти класичну форму закону сухого тертя у площині обкочування, вводять поняття еквівалентного (зведеного) коефіцієнта тертя `μ'`:

```
μ' = μ / cos(α)
```

Для стандартного кута `α = 20°` дільник дорівнює `cos(20°) ≈ 0.9397`, тобто клиновий профіль витка штучно збільшує реальний коефіцієнт тертя приблизно на 6.4%. Зведений коефіцієнт тертя пов'язаний зі зведеним кутом тертя `ρ'` класичним співвідношенням:

```
tan(ρ') = μ' = μ / cos(α)

ρ' = arctan(μ / cos(α))
```

Значення фізичного коефіцієнта тертя `μ` не є константою: воно нелінійно падає зі зростанням швидкості ковзання `v_s` через формування гідродинамічного клину в мастилі. При швидкості `v_s ≈ 0.1` м/с для пари загартована сталь — олов'яниста бронза коефіцієнт становить `μ ≈ 0.08 ... 0.10` (`ρ' ≈ 4.8° ... 6.1°`), тоді як при русі з місця (статичний стан, `v_s = 0`) коефіцієнт тертя спокою підскакує до `μ₀ ≈ 0.12 ... 0.15` (`ρ'₀ ≈ 7.3° ... 9.1°`).

Залежність коефіцієнта тертя від швидкості ковзання підпорядковується кривій Штрібека. У момент рушання з місця або при наднизьких обертах (`v_s < 0.01` м/с) передача працює в зоні граничного тертя: мікронерівності сталевого витка безпосередньо контактують з поверхнею бронзового колеса, руйнуючи масляну плівку. При збільшенні частоти обертання виток черв'яка затягує в'язку оливу в клиновий зазор, поступово піднімаючи контактні поверхні та переходячи в режим змішаного, а згодом і гідродинамічного тертя.

В інженерних розрахунках за стандартом ISO/TR 14521 для зубчастих пар із загартованої сталі (твердість поверхні 58–62 HRC) та вінця з фосфористої бронзи (наприклад, CuSn12Ni2) при змащенні синтетичною редукторною оливою ISO VG 220 використовують емпіричні значення коефіцієнта тертя залежно від швидкості:
- `v_s = 0` м/с (стан спокою): `μ₀ = 0.13`, зведений кут `ρ'₀ = arctan(0.13 / 0.9397) ≈ 7.88°`
- `v_s = 0.5` м/с: `μ = 0.065`, зведений кут `ρ' = arctan(0.065 / 0.9397) ≈ 3.95°`
- `v_s = 2.0` м/с: `μ = 0.038`, зведений кут `ρ' = arctan(0.038 / 0.9397) ≈ 2.32°`
- `v_s = 5.0` м/с: `μ = 0.024`, зведений кут `ρ' = arctan(0.024 / 0.9397) ≈ 1.46°`

Розглянемо числовий приклад визначення швидкості ковзання та зведеного кута тертя. Нехай вхідний черв'як електродвигуна має ділильний діаметр `d₁ = 32` мм, обертається з частотою `n₁ = 1450` об/хв і має кут підйому витка `γ = 4.5°`.

Колова швидкість черв'яка становить:

```
v₁ = (π · d₁ · n₁) / 60
   = (3.1416 · 0.032 · 1450) / 60
   ≈ 2.43 м/с
```

Швидкість ковзання вздовж витка:

```
v_s = v₁ / cos(γ)
    = 2.43 / cos(4.5°)
    = 2.43 / 0.9969
    ≈ 2.44 м/с
```

Для швидкості ковзання `v_s = 2.44` м/с табличний коефіцієнт тертя руху для пари сталь-бронза становить `μ ≈ 0.035`. Обчислимо зведений кут тертя в динамічному режимі:

```
tan(ρ'_dyn) = 0.035 / cos(20°) = 0.035 / 0.9397 ≈ 0.0372

ρ'_dyn = arctan(0.0372) ≈ 2.13°
```

У той самий час у статичному стані спокою (`v_s = 0`) при `μ₀ = 0.14`:

```
tan(ρ'_stat) = 0.14 / 0.9397 ≈ 0.1490

ρ'_stat = arctan(0.1490) ≈ 8.47°
```

Порівняння кутів показує: у стані спокою кут підйому витка суттєво менший за статичний кут тертя (`γ = 4.5° < ρ'_stat = 8.47°`), що забезпечує надійне статичне утримання навантаження. Проте під час руху або при вібраційному зриві динамічний кут тертя падає нижче кута підйому (`ρ'_dyn = 2.13° < γ = 4.5°`), внаслідок чого самогальмування повністю зникає, а механізм набуває здатності до зворотного руху.

> 🔧 **Навіщо це.** Зведений кут тертя `ρ'` є пороговим трибологічним бар'єром: якщо кут підйому різьби `γ` виявиться меншим за `ρ'`, редуктор стане механічно незворотним під дією сил статики.

## Механічна умова самогальмування та розрахунок ККД

Здатність передачі передавати рух або блокувати його залежить від напрямку силового потоку та співвідношення між кутом підйому витка `γ` і зведеним кутом тертя `ρ'`.

При прямому ході рушійний крутний момент прикладається до вала черв'яка. Тангенційна сила на черв'яку долає корисне навантаження на зубчастому вінці колеса та силу тертя на похилій поверхні витка. Теоретичний ККД зачеплення для прямого потоку потужності (від черв'яка до колеса) виводиться з розкладу векторів сил на похилій площині:

```
η_dir = tan(γ) / tan(γ + ρ')
```

де `γ` — кут підйому витка черв'яка, а `ρ'` — зведений кут тертя з урахуванням кута профілю різьби. Оскільки кут `γ` додатний, а `tan(γ + ρ') > tan(γ)`, прямий ККД завжди менший за одиницю і спадає при зменшенні кута підйому витка.

При зворотному ході зовнішній крутний момент прикладається до вала черв'ячного колеса (наприклад, вага піднятого вантажу намагається провернути барабан лебідки). У цьому випадку колове зусилля вінця колеса намагається штовхнути гвинтову поверхню черв'яка в осьовому напрямку, змушуючи його обертатися. Аналітичний вираз ККД для зворотного потоку потужності має вигляд:

```
η_rev = tan(γ - ρ') / tan(γ)
```

Аналіз цього виразу дає три принципово різні механічні стани передачі:
1. **Зворотнорушійний стан (`γ > ρ'`):** знаменник і чисельник додатні, зворотний ККД `η_rev > 0`. Зовнішній момент на колесі здатний провернути черв'як.
2. **Граничний стан рівноваги (`γ = ρ'`):** чисельник дорівнює нулю, `tan(0) = 0`, зворотний ККД `η_rev = 0`. Система перебуває на межі руху під дією сили тертя спокою.
3. **Стан статичного самогальмування (`γ < ρ'`):** різниця кутів від'ємна (`γ - ρ' < 0`), внаслідок чого `tan(γ - ρ') < 0` і формальний зворотний ККД стає від'ємним (`η_rev < 0`).

Фізичний зміст від'ємного зворотного ККД полягає в тому, що для провертання черв'яка з боку колеса недостатньо прикласти будь-який, навіть нескінченно великий обертовий момент до колеса: сила тертя зростає швидше за зсувне зусилля. Щоб рух відбувся, до вала черв'яка необхідно прикласти додаткову активну рушійну силу у напрямку обертання. Без прикладання зовнішньої потужності до черв'яка передача залишається непорушно заклиненою.

> 🔧 **Навіщо це.** Формула прямого та зворотного ККД показує неминучу інженерну плату за самогальмування: щоб отримати надійне стопоріння (`γ < ρ'`), прямий ККД редуктора неминуче падає нижче 50% (`η_dir < tan(ρ') / tan(2ρ') ≈ 0.45 ... 0.50`), перетворюючи більше половини потужності двигуна на тепло.

## Динамічне розгальмування та вібраційні межі

Статичний розрахунок за умовою `γ < ρ'` справедливий виключно для умов абсолютного спокою. У реальних механізмах самогальмування часто втрачається через фундаментальну різницю між коефіцієнтами тертя спокою та ковзання, а також під дією вібрацій.

Коли черв'ячна пара перебуває в стані спокою, коефіцієнт статичного тертя для пари сталь — бронза становить `μ₀ ≈ 0.12 ... 0.15`, що відповідає куту тертя `ρ'₀ ≈ 7.3° ... 9.1°`. Якщо однозахідний черв'як спроектовано з кутом підйому `γ = 5°`, статична умова `γ < ρ'₀` повністю виконується, і навантажений барабан лебідки стабільно утримує вантаж на місці.

Проте якщо на конструкцію діє зовнішнє динамічне збурення — робота двигуна внутрішнього згоряння на рамі, удари вантажу, вібрації ходової частини всюдихода або пульсуючий момент на колесі, — мікрозсуви руйнують контактні зв'язки спокою. Коефіцієнт тертя миттєво падає від статичного значення `μ₀` до динамічного коефіцієнта тертя ковзання `μ_dyn ≈ 0.03 ... 0.05`. Відповідно зведений кут тертя зменшується:

```
ρ'_dyn = arctan(μ_dyn / cos(α)) ≈ arctan(0.04 / 0.94) ≈ 2.4°
```

Оскільки динамічний кут тертя стає меншим за кут підйому витка (`ρ'_dyn = 2.4° < γ = 5°`), умова самогальмування порушується. Передача самовільно розблоковується, і вантаж починає повільно або прискорено опускатися під дією вібраційного повзучого прокручування (Stick-slip effect).

Щоб гарантувати безпеку вантажопідйомних механізмів, ліфтів і приводів похилих конвеєрів, інженери вводять нормативний коефіцієнт запасу самогальмування `S_sl`:

```
S_sl = tan(ρ') / tan(γ) ≥ 1.5 ... 2.0
```

Для відповідальних підйомних систем, де падіння вантажу загрожує життю людей, покладатися на самогальмування черв'ячного редуктора суворо заборонено стандартами безпеки. Черв'ячну передачу обов'язково дублюють незалежним нормально замкненим електромеханічним дисковим або колодковим гальмом на вхідному валу двигуна.

> 🔧 **Навіщо це.** Коефіцієнт запасу `S_sl ≥ 1.5` обмежує граничний кут підйому витка значенням `γ ≤ 3° ... 3.5°`, а розуміння ефекту динамічного вібраційного розгальмування диктує обов'язкове встановлення дублюючого стоянкового гальма на підйомних лебідках.
