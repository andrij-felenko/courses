# 🧮 Виведення зв'язку між сталою протиЕРС ke, сталою моменту kt та числом KV

<preknowlist>
- [ПротиЕРС (back-EMF)](root:hw-motion/back-emf) — виникнення напруги, що протидіє струму джерела при обертанні ротора.
- [Момент сили](root:ph-mechanics/torque) — механічний обертальний момент як векторний добуток сили на плече.
</preknowlist>

В інженерних паспортах електродвигунів параметри часто наводять у різних системах одиниць: швидкість обертання задають числом `KV` в обертах за хвилину на вольт (`об/(хв·В)`), сталу моменту `kt` — у ньютон-метрах на ампер (`Н·м/А`) або міліньютон-метрах на ампер (`мН·м/А`), а сталу протиЕРС `ke` — у вольтах на тисячу обертів за хвилину (`В/krpm`) або вольт-секундах на радіан (`В·с/рад`). 

З погляду фундаментальної фізики всі ці три величини описують один і той самий процес електромеханічного перетворення енергії в повітряному зазорі машини. Розберімо суворе алгебраїчне виведення їхньої тотожності з закону збереження енергії, дослідимо вплив реальних неідеальностей (температурний дрейф магнітів, реакція якоря) та виведемо формули перерахунку для практичних інженерних розрахунків.

---

### Мікроскопічна природа: закон Лоренца та закон Фарадея

Розглянемо один провідник довжиною `L`, розташований на радіусі `r` від осі обертання ротора в радіальному магнітному полі з індукцією `B`.

Коли ротор обертається з лінійною швидкістю `v = ω · r`, провідник перетинає силові лінії магнітного поля. Сила Лоренца, що діє на вільні носії заряду всередині рухомого провідника, породжує розділення зарядів та індукує елементарну ЕРС:

```
e_elem = B · L · v = B · L · (ω · r)
```

З іншого боку, коли крізь цей самий провідник пропускають електричний струм `I`, на нього з боку магнітного поля діє механічна сила Ампера (інтегральна форма сили Лоренца):

```
F_elem = B · L · I
```

Обертальний момент, створюваний цією силою відносно осі вала:

```
T_elem = F_elem · r = (B · L · I) · r = (B · L · r) · I
```

Порівняємо два отримані вирази:
- Відношення наведеної ЕРС до кутової швидкості: `e_elem / ω = B · L · r`;
- Відношення механічного моменту до струму: `T_elem / I = B · L · r`.

Геометричний множник `B · L · r` виявляється абсолютно ідентичним для обох процесів. Якщо підсумувати дію всіх `Z` активних провідників обмотки, з'єднаних у `a` паралельних гілок, інтегральний коефіцієнт машини набуває вигляду:

```
k = (p · Z · B_avg · L · r) / (2 · π · a)
```

де `p` — число пар полюсів ротора, `B_avg` — середня магнітна індукція в повітряному зазорі. Цей конструктивний коефіцієнт одночасно визначає як електромагнітний момент `T = k · I`, так і протиЕРС `E = k · ω`.

### Фундаментальна тотожність: ke = kt у системі СІ

Розглянемо ідеальну електричну машину з постійними магнітами без урахування активних втрат у міді обмоток та залізі осердя.

Миттєва електрична потужність `P_el`, яка перетворюється на механічну роботу під час протікання струму `I` через обмотку під дією зворотної ЕРС `E`, дорівнює:

```
P_el = E · I
```

Механічна потужність `P_mech`, яка розвивається на валу двигуна при створенні електромагнітного моменту `T` на кутовій швидкості `ω` (вираженій у радіанах за секунду, `рад/с`), дорівнює:

```
P_mech = T · ω
```

За законом збереження енергії для ідеального перетворювача вся електромагнітна потужність переходить у механічну:

```
P_el = P_mech
E · I = T · ω
```

За означенням сталої протиЕРС `ke` та сталої моменту `kt`:

```
E = ke · ω
T = kt · I
```

Підставимо ці вирази у рівняння балансу потужностей:

```
(ke · ω) · I = (kt · I) · ω
ke · ω · I = kt · ω · I         [скорочуємо на добуток (ω · I)]
ke = kt                         [тотожність сталих у когерентній системі СІ]
```

Перевіримо розмірність обох величин у системі СІ:

```
[ke] = В / (рад/с) = В · с / рад = (Дж / Кл) · с = (Н · м / (А · с)) · с = Н · м / А
[kt] = Н · м / А
```

Таким чином, у системі СІ числові значення `ke` (вираженої у `В·с/рад`) та `kt` (вираженої у `Н·м/А`) **строго збігаються**:

```
ke [В·с/рад] = kt [Н·м/А]
```

Якщо двигун генерує `0.05 В` протиЕРС на кожен `1 рад/с` швидкості обертання, він розвиває рівно `0.05 Н·м` електромагнітного моменту на кожен `1 А` споживаного струму.

### Зв'язок сталої протиЕРС ke з числом KV

У моделізмі, робототехніці та силових приводах швидкість обертання вимірюють в обертах за хвилину (`об/хв`, `RPM`), а характеристики безколекторних двигунів позначають числом `KV` — швидкістю холостого ходу на один вольт прикладеної напруги:

```
KV = N / V_app       [де N — оберти за хвилину, об/хв; V_app — напруга, В]
```

Зв'язок між кутовою швидкістю `ω` (`рад/с`) та частотою обертання `N` (`об/хв`):

```
ω = N · (2 · π / 60)
N = ω · (60 / (2 · π))
```

Оскільки на холостому ході (без урахування втрат на тертя) протиЕРС `E` наближається до напруги живлення `V_app` (`E ≈ V_app`):

```
E = ke · ω
V_app = ke · (N · 2 · π / 60)
N / V_app = 60 / (2 · π · ke)
KV = 60 / (2 · π · ke)
```

Обчислимо числовий коефіцієнт:

```
60 / (2 · π)
= 60 / 6.283185307              [підстановка значення π]
≈ 9.5492965855                  [обчислення десяткового дробу]
```

Звідси отримуємо точні формули прямого та зворотного перерахунку:

```
KV [об/(хв·В)] = 9.5493 / ke [В·с/рад]
ke [В·с/рад]   = 9.5493 / KV [об/(хв·В)]
kt [Н·м/А]     = 9.5493 / KV [об/(хв·В)]
```

### Інженерні одиниці: V/krpm, мН·м/А та oz-in/A

У промисловій автоматизації та каталогах серводвигунів сталу протиЕРС часто наводять у вольтах на тисячу обертів за хвилину (`ke_krpm`, `В/krpm` або `V/kRPM`), а сталу моменту — в американських унція-дюймах на ампер (`oz-in/A`).

#### 1. Перерахунок між ke_krpm та ke [В·с/рад]

За означенням:

```
ke_krpm = E / (N / 1000)        [вольт на 1000 об/хв]
```

Підставимо зв'язок між `N` та `ω`:

```
ke_krpm = (ke · ω) / ((ω · 60 / (2 · π)) / 1000)
= ke · 1000 · (2 · π / 60)      [ділення на дріб замінюємо множенням]
= ke · (2000 · π / 60)          [скорочення чисельника і знаменника]
= ke · (100 · π / 3)            [спрощення дробу]
≈ ke · 104.719755               [числовий коефіцієнт перерахунку]
```

Зворотне відношення:

```
ke [В·с/рад] = ke_krpm [В/krpm] / 104.7198
KV [об/(хв·В)] = 1000 / ke_krpm [В/krpm]
```

#### 2. Перерахунок між kt [Н·м/А], мН·м/А та oz-in/A

Стандартні одиниці моменту:

```
1 Н·м = 1000 мН·м
1 oz-in (унція-дюйм) ≈ 0.0070615518 Н·м = 7.06155 мН·м
1 Н·м ≈ 141.6119 oz-in
```

Формули перерахунку сталої моменту:

```
kt [мН·м/А]   = (9.5493 / KV) · 1000 = 9549.3 / KV
kt [oz-in/A]  = kt [Н·м/А] · 141.6119 = 1352.3 / KV
```

### Виведення лінійного рівняння механічної характеристики: ω(T)

Знайдемо залежність швидкості обертання двигуна `ω` від корисного навантаження на валу (моменту `T`) при фіксованій напрузі живлення `V`.

Запишемо систему фундаментальних рівнянь двигуна постійного струму в усталеному режимі:

```
V = I · R + E                   [рівняння рівноваги напруг Кірхгофа]
E = ke · ω                      [рівняння протиЕРС]
T = kt · I                      [рівняння електромагнітного моменту]
```

Виразимо струм через момент:

```
I = T / kt
```

Підставимо вирази для струму `I` та протиЕРС `E` в рівняння напруг:

```
V = (T / kt) · R + ke · ω
ke · ω = V − T · (R / kt)
ω = (V / ke) − T · (R / (ke · kt))
```

Оскільки у системі СІ `ke = kt`:

```
ω = (V / ke) − T · (R / ke²)
```

Аналіз отриманого рівняння показує два крайні режими:

1. **Швидкість холостого ходу (T = 0):**

```
ω_0 = V / ke = V · (2 · π · KV / 60)
```

2. **Пусковий момент заклинювання (ω = 0):**

```
0 = (V / ke) − T_stall · (R / (ke · kt))
T_stall · (R / (ke · kt)) = V / ke
T_stall = (V · kt) / R = kt · I_stall
```

3. **Крутизна нахилу механічної характеристики (жорсткість приводу):**

```
dω / dT = −R / (ke · kt) = −R / ke²
```

Чим менший активний опір фази `R`, тим жорсткіша механічна характеристика: швидкість обертання майже не просідає зі зростанням навантаження на валу.

### Неідеальні ефекти реальних моторів

У реальних умовах сталі `ke` та `kt` зазнають впливу температури та струмового навантаження:

1. **Температурне розмагнічування неодимових магнітів (NdFeB):**
Залишкова магнітна індукція магнітів ротора має від'ємний температурний коефіцієнт: `α_Br ≈ −0.11% / °C`.
Під час нагріву двигуна від кімнатної температури `20 °C` до робочих `100 °C` (перепад `ΔT = 80 °C`):
```
ke(T) = ke_20 · [1 + α_Br · (T − 20)]
= ke_20 · [1 − 0.0011 · 80]
= ke_20 · 0.912
```
Стала протиЕРС падає майже на 9%. Відповідно, число `KV` зростає на 9.6%, а момент на кожен ампер струму `kt` пропорційно падає: гарячий мотор розганяється швидше, але стає слабшим.

2. **Температурне зростання опору міді:**
Активний опір обмотки зростає з коефіцієнтом `α_Cu ≈ +0.393% / °C`. При нагріві на `80 °C` опір `R` зростає на 31.4%. Це спричиняє сильніше просідання швидкості під навантаженням (`dω/dT = −R / ke²` збільшується на 44%).

3. **Реакція якоря (Armature Reaction):**
При великих фазних струмах магнітне поле статора розмагнічує набігаючий край постійних магнітів ротора, знижуючи результуючий магнітний потік `Φ`. Це викликає нелінійне падіння `kt` на пікових струмах (насичення моменту).

### Числовий приклад розрахунку реального мотора

**Вхідні дані:**
Безколекторний мотор для FPV-дрона типорозміру 2207 з параметрами:
- `KV = 1950 об/(хв·В)`;
- Активний фазний опір `R = 0.045 Ом`;
- Напруга живлення `V = 22.2 В` (6S LiPo).

**Покроковий розрахунок:**

1. Обчислюємо сталу протиЕРС `ke` та сталу моменту `kt` у системі СІ:

```
ke = 9.5493 / 1950
= 0.004897 В·с/рад              [обчислення за формулою ke = 9.5493 / KV]

kt = ke = 0.004897 Н·м/А = 4.897 мН·м/А  [тотожність ke = kt у системі СІ]
```

2. Обчислюємо максимальну швидкість холостого ходу:

```
N_0 = KV · V
= 1950 · 22.2                   [множення KV на напругу батареї]
= 43290 об/хв                   [оберти за хвилину на холостому ході]

ω_0 = N_0 · (2 · π / 60)
= 43290 · 0.10472               [перевід обертів у кутову швидкість]
= 4533.3 рад/с                  [кутова швидкість у радіанах за секунду]
```

3. Обчислюємо пусковий струм і момент заклинювання:

```
I_stall = V / R
= 22.2 / 0.045                  [закон Ома для нерухомого ротора при E = 0]
= 493.3 А                       [піковий струм заклинювання]

T_stall = kt · I_stall
= 0.004897 · 493.3              [електромагнітний момент заклинювання]
= 2.416 Н·м                     [максимальний момент на валу]
```

4. Обчислюємо робочу точку при навантаженні моментом пропелера `T_load = 0.12 Н·м`:

```
I_load = T_load / kt
= 0.12 / 0.004897               [струм для створення моменту навантаження]
= 24.5 А                        [робочий фазний струм]

E_load = V − I_load · R
= 22.2 − 24.5 · 0.045           [падіння напруги на активному опорі міді]
= 22.2 − 1.10                   [віднімання падіння напруги]
= 21.1 В                        [протиЕРС на робочій швидкості]

ω_load = E_load / ke
= 21.1 / 0.004897               [кутова швидкість під навантаженням]
= 4308.7 рад/с                  [робоча швидкість у рад/с]

N_load = ω_load · (60 / (2 · π))
= 4308.7 · 9.5493               [перевід у оберти за хвилину]
= 41145 об/хв                   [реальні робочі оберти пропелера]
```

Падіння обертів під навантаженням становить лише `43290 − 41145 = 2145 об/хв` (менше 5%), що безпосередньо обумовлено низьким опором обмотки `R`.
