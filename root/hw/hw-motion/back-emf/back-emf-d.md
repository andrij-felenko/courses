# ПротиЕРС: внутрішній генератор електродвигуна

<preknowlist>
- [Закон електромагнітної індукції Фарадея](root:ph-electromagnetism/faraday-law) — зміна магнітного потоку крізь контур котушки породжує електрорушійну силу.
- [Правило Ленца](root:ph-electromagnetism/lenz-law) — індукований струм завжди має напрямок, що протидіє зміні первинного магнітного потоку.
- [Безколекторний мотор (BLDC)](root:hw-motion/bldc-motor) — будова статора, постійні магніти ротора та обертове магнітне поле.
- [Стратегії комутації BLDC-мотора](root:hw-motion/bldc-commutation) — шість кроків трапеції проти векторного керування синусом.
- [Силовий ключ MOSFET](root:hw-components/mosfet-power-switch) — робота транзисторів у мостових схемах інверторів.
</preknowlist>

Якщо взяти потужний безколекторний мотор для дрона з активним опором обмотки фази `R = 0.03 Ом` і під'єднати його напряму до батареї напругою `24 В`, закон Ома передбачає катастрофічний струм `I = 24 / 0.03 = 800 А`. Такий струм за лічені мілісекунди випарує мідні провідники обмоток і проб'є силові транзистори інвертора. Проте, коли цей самий мотор розганяється до повних обертів на холостому ході, амперметр показує менше ніж `1.5 А`. Струм обмежує не зовнішній баластний резистор і не програмне обмеження в мікроконтролері: під час обертання двигун сам генерує внутрішню напругу, спрямовану назустріч напрузі батареї.

Цю наведену напругу називають **проти-електрорушійною силою** (протиЕРС, або англ. *back electromotive force*, *back-EMF*; від лат. *electromotio* — рух електрики та *inductio* — наведення). Будь-який електродвигун за своєю фізичною природою є водночас і генератором. Швидкість обертання, граничний момент, динамічне гальмування та можливість керувати мотором без датчиків положення ротора цілком визначаються саме протиЕРС.

### Фізична природа протиЕРС: закон Фарадея і правило Ленца

Виникнення протиЕРС ґрунтується на фундаментальному законі електромагнітної індукції Фарадея. Коли ротор із постійними магнітами обертається, його магнітне поле перетинає витки нерухомих котушок статора. Магнітний потік `Φ` (грец. *磁 flux*), що пронизує площу котушки `S` під кутом `θ`, безперервно змінюється в часі:

```
Φ(t) = B · S · cos(θ(t)) = B · S · cos(ω · t)
```

де `B` — магнітна індукція постійних магнітів ротора, `S` — ефективна площа контуру котушки, `ω` — кутова швидкість обертання вала (в радіанах за секунду, `рад/с`).

За законом Фарадея, швидкість зміни магнітного потоку крізь `N` послідовно з'єднаних витків обмотки наводить у провіднику електрорушійну силу `e(t)`:

```
e(t) = −N · (dΦ / dt)
```

Знак «мінус» відображає правило Ленца: полярність наведеної ЕРС завжди така, що створений нею струм своїм власним магнітним полем намагається скомпенсувати зміну зовнішнього магнітного потоку. Оскільки магнітне поле ротора намагається повернути котушку або навести в ній струм під час руху, наведена ЕРС діє **строго проти прикладеної напруги джерела живлення**.

Оскільки магнітний потік у повітряному зазорі визначається геометрією магнітів та осердя (величина стала), миттєва амплітуда протиЕРС прямо пропорційна механічній кутовій швидкості обертання вала `ω`:

```
E = ke · ω
```

де `ke` — **стала протиЕРС** двигуна (англ. *back-EMF constant*), що вимірюється у вольт-секундах на радіан (`В·с/рад`) або вольтах на тисячу обертів за хвилину (`В/krpm`).

```
Зв'язок величин:
Більша швидкість ротора ω  →  швидша зміна потоку dΦ/dt  →  вища протиЕРС E  →  менший результуючий струм I
```

![Фізичний механізм виникнення протиЕРС, еквівалентна схема та робочі режими](/root/hw/hw-motion/back-emf/img/back-emf-mechanism.svg)
*Фізичний механізм виникнення протиЕРС. Зліва: магніти ротора при обертанні наводять у котушці статора напругу E за законом Фарадея. У центрі: еквівалентна схема фази, де джерело протиЕРС включене назустріч напрузі живлення V. Справа: три фундаментальні режими роботи двигуна за співвідношенням напруг.*

### Зв'язок сталої протиЕРС ke, сталої моменту kt та числа KV

У теорії електричних машин існує непорушний зв'язок між механічними та електричними характеристиками. Розглянемо ідеальний двигун без втрат: у ньому вся підведена електрична потужність `P_el = E · I` повністю перетворюється на механічну потужність обертання вала `P_mech = T · ω`, де `T` — електромагнітний момент (у ньютон-метрах, `Н·м`).

З рівності `E · I = T · ω` випливає фундаментальна тотожність:

```
E / ω = T / I
```

Відношення `E / ω` за означенням є сталою протиЕРС `ke`, а відношення `T / I` — **сталою моменту** `kt` (англ. *torque constant*, `Н·м/А`). У міжнародній системі одиниць СІ ці дві величини чисельно абсолютно рівні:

```
ke [В·с/рад] = kt [Н·м/А]
```

Один і той самий фізичний механізм зв'язку магнітного поля з провідником визначає як силу Лоренца (момент на одиницю струму), так і закон Фарадея (напругу на одиницю швидкості).

У прикладній електроніці та авіамоделізмі швидкість двигунів задають параметром **`KV`** (оберти за хвилину на один вольт прикладеної напруги, `об/(хв·В)` або `RPM/V`). Число `KV` є оберненою величиною до сталої протиЕРС:

```
KV = 60 / (2 · π · ke) ≈ 9.5493 / ke
ke = 9.5493 / KV
kt = 9.5493 / KV
```

Для глибокого математичного аналізу, строгих доведень збереження енергії та формул перерахунку в несистемні одиниці (`oz-in/A`, `В/krpm`) зверніться до [детального математичного виведення енергетичного балансу та коефіцієнтів](root:hw-motion/back-emf/math-ke-kt-derivation.md).

> 🔧 **Навіщо це.** Знаючи лише число `KV` з наклейки мотора (наприклад, `KV = 1800`), інженер миттєво обчислює:
> 1. Сталу моменту: `kt = 9.5493 / 1800 = 0.0053 Н·м/А` (мотор дасть `5.3 мН·м` на кожен ампер фазного струму).
> 2. Граничні теоретичні оберти холостого ходу від акумулятора `6S` (`24 В`): `N_0 = 1800 · 24 = 43200 об/хв`.
> 3. Амплітуду протиЕРС на робочих обертах `30000 об/хв`: `E = 30000 / 1800 = 16.67 В`.

### Електрична еквівалентна схема двигуна

Кожна фазна обмотка електричного мотора володіє трьома невіддільними фізичними властивостями:
1. Активним омічним опором мідного дроту `R` (втрати на нагрів Джоуля);
2. Власною індуктивністю котушки `L`, що накопичує енергію в магнітному полі осердя;
3. Джерелом наведеної протиЕРС `E`, величина якої залежить від частоти обертання ротора.

За другим законом Кірхгофа, рівняння рівноваги напруг для фази двигуна має вигляд:

```
V = I · R + L · (dI / dt) + E
```

де `V` — зовнішня напруга, прикладена інвертором до клем мотора; `I` — миттєвий фазний струм; `L · (dI/dt)` — падіння напруги на індуктивності під час зміни струму.

В усталеному режимі роботи на постійній швидкості струм у межах кроку комутації встигає встановитися (`dI/dt = 0`), тому рівняння спрощується до алгебраїчного:

```
V = I · R + E = I · R + ke · ω
```

Звідси струм, який реально протікає крізь обмотки мотора, дорівнює:

```
I = (V − E) / R = (V − ke · ω) / R
```

Ця формула розкриває природу саморегуляції електродвигуна постійного струму і пояснює три ключові робочі режими:

```
1. Пуск / Заклинювання:   ω = 0     →  E = 0   →  I_stall = V / R          (струм максимальний)
2. Холостий хід:          ω = ω_max →  E ≈ V   →  I_0 = (V − E) / R ≈ 0    (струм мінімальний)
3. Рекуперація / Гальмо:  E > V               →  I = (V − E) / R < 0       (струм тече назад у джерело)
```

#### 1. Режим заклинювання та пуску (Stall)

У момент подачі напруги, коли ротор ще нерухомий (`ω = 0`), магнітний потік не змінюється, і протиЕРС відсутня: `E = 0`. Єдиною перешкодою для протікання струму залишається мізерний активний опір міді `R`. Струм сягає пікового пускового значення:

```
I_stall = V / R
```

У цей момент мотор розвиває максимальний пусковий момент `T_stall = kt · I_stall`, але вся споживана потужність перетворюється на чисте тепло в обмотках: `P_heat = I_stall² · R`. Якщо вал заблоковано механічним навантаженням, ізоляційний лак на витках плавиться за кілька секунд, спричиняючи міжвиткове коротке замикання. Фізика теплового перевантаження та методи захисту детально розібрані в матеріалі про [заклинювання й нагрів мотора](root:hw-motion/motor-current-stall-heat).

#### 2. Режим холостого ходу (No-load)

Під дією електромагнітного моменту ротор прискорюється. Зі зростанням швидкості `ω` зростає протиЕРС `E = ke · ω`. Різниця напруг `(V − E)` зменшується, що спричиняє стрімке падіння споживаного струму `I`.

Прискорення триває доти, доки електромагнітний момент `T = kt · I` не зрівноважить момент механічного тертя в підшипниках та аеродинамічного опору повітря. У цій точці встановлюється швидкість холостого ходу `ω_0`, на якій протиЕРС майже зрівнюється з напругою живлення:

```
E ≈ V − I_0 · R ≈ V
ω_max ≈ V / ke = V · KV · (2 · π / 60)
```

Струм холостого ходу `I_0` становить лише 1–5% від струму заклинювання і витрачається виключно на подолання тертя та втрат на перемагнічування статорної сталі (струми Фуко та гістерезис).

#### 3. Генераторний режим і рекуперативне гальмування

Якщо зовнішня сила розкручує вал швидше за швидкість холостого ходу (`ω > V / ke`), або якщо напругу джерела `V` раптово знижують нижче поточної амплітуди протиЕРС (`V < E`), чисельник `(V − E)` стає від'ємним.

Напрямок протікання струму змінюється на протилежний (`I < 0`). Тепер струм тече з обмоток двигуна назад у шину живлення `Vbus`. При цьому:
- Електромагнітний момент `T = kt · I` змінює знак і стає **гальмівним**, стрімко сповільнюючи ротор;
- Кінетична енергія механізму перетворюється на електричну енергію, заряджаючи акумулятор (рекуперація).

> ⚠️ **Пастка рекуперації.** Якщо інвертор живиться від імпульсного блока живлення, який не вміє поглинати зворотний струм (на відміну від хімічного акумулятора), рекуперований струм піде заряджати електролітичні конденсатори шини живлення. Напруга `Vbus` миттєво підскочить від номінальних `24 В` до `50–80 В`, що призведе до лавинного пробою силових MOSFET та вибуху вхідних конденсаторів. Для захисту схемотехніка обов'язково повинна містити схему гальмівного переривача (Brake Chopper) з баластним резистором. Механізми та схеми гальмування описані в огляді [гальмування мотора](root:hw-motion/halmuvannia-motora).

### Форма протиЕРС: трапеція проти синуса (BLDC проти PMSM)

Форма сигналу протиЕРС визначається внутрішньою конструкцією електричної машини: геометричним розташуванням пазів і зубців статора, схемою вкладання обмоток та формою намагніченості постійних магнітів ротора.

За формою протиЕРС синхронні машини з постійними магнітами поділяють на два великі класи:
1. **BLDC (Brushless DC Motor)** — безколекторні мотори з **трапецеподібною** протиЕРС;
2. **PMSM (Permanent Magnet Synchronous Motor)** — синхронні мотори з **синусоїдальною** протиЕРС.

![Порівняння форми протиЕРС та струму: трапецеподібна (BLDC) проти синусоїдальної (PMSM)](/root/hw/hw-motion/back-emf/img/back-emf-waveforms.svg)
*Порівняння форми протиЕРС та фазного струму. Зліва: BLDC з пласкою полицею 120° при живленні прямокутними імпульсами струму дає сталий сумарний момент. Справа: PMSM із синусоїдною протиЕРС при живленні синусоїдними трифазними струмами забезпечує ідеально плавний хід без пульсацій.*

#### Трапецеподібна протиЕРС (BLDC)

У класичних BLDC-моторах застосовують **зосереджені зубцеві обмотки** (витки фази щільно намотані на окремі дискретні зубці статора) та радіально намагнічені магніти ротора з прямокутним розподілом магнітної індукції `B(θ)` в повітряному зазорі.

Коли магніт ротора пролітає над зубцем статора, магнітний потік зростає лінійно, потім залишається незмінним протягом кута перекриття полюса (120 електричних градусів), а потім лінійно спадає. Похідна від такого потоку `dΦ/dt` формує напругу трапецеподібної форми з **пласкою вершиною шириною 120° електричних** у кожному напівперіоді.

Для створення постійного обертального моменту такий мотор потребує живлення прямокутними блоками струму шириною 120° (трапецеподібна 6-крокова комутація). Оскільки струм протікає лише тоді, коли протиЕРС перебуває на пласкій полиці з постійною амплітудою `E_max`:

```
P_em(t) = E(t) · I(t) = E_max · I_max = const
T_em(t) = P_em(t) / ω = const
```

Електромагнітний момент залишається постійним упродовж усього сектора комутації.

#### Синусоїдальна протиЕРС (PMSM)

У прецизійних серводвигунах і тягових електроприводах протиЕРС намагаються зробити ідеальною синусоїдою: `E(θ) = E_max · sin(θ)`. Для цього застосовують спеціальні технологічні прийоми:
- **Розподілені обмотки** (провідники однієї фази вкладають у кілька сусідніх пазів статора з різною кількістю витків);
- **Скос пазів статора або ротора (Skewing)** на один зубцевий поділ, що згладжує зубцеві гармоніки магнітного поля;
- Профільовані сегментні магніти з синусоїдальним розподілом залишкової намагніченості.

Для ідеальної синусоїдальної протиЕРС трьох фаз (`a, b, c`), зсунутих на 120°, підводять трифазні синусоїдні струми:

```
E_a(t) = E_max · sin(θ)                 I_a(t) = I_max · sin(θ)
E_b(t) = E_max · sin(θ − 120°)          I_b(t) = I_max · sin(θ − 120°)
E_c(t) = E_max · sin(θ − 240°)          I_c(t) = I_max · sin(θ − 240°)
```

Сумарна миттєва потужність трьох фаз за тригонометричною тотожністю:

```
P_sum(t) = E_a · I_a + E_b · I_b + E_c · I_c
= E_max · I_max · [sin²(θ) + sin²(θ − 120°) + sin²(θ − 240°)]  [підстановка фазних гармонік]
= 1.5 · E_max · I_max = const                                   [тригонометрична тотожність сум квадратів]
```

Такий привод за умови використання векторного керування (FOC) або просторово-векторної ШІМ ([SVPWM](root:hw-motion/svpwm)) забезпечує безшумний, оксамитово плавний рух без пульсацій моменту від нульової швидкості.

#### Наслідки неузгодженості форми струму та протиЕРС

Якщо з'єднати несумісні типи форми хвилі, енергетичний баланс порушується:
1. **Живлення мотора з синусоїдною протиЕРС 6-кроковим трапецеподібним струмом:** на межах секторів комутації добуток струму на протиЕРС просідає на 13.4%, що викликає відчутну пульсацію моменту з частотою 6-ї гармоніки електричного оберту, акустичне гарчання та підвищений нагрів;
2. **Живлення мотора з трапецеподібною протиЕРС чистим синусом:** добуток синусоїдного струму на трапецеподібну ЕРС не є константою в часі — виникає пульсація моменту з амплітудою близько 4–7%.

### Бездатчикове керування (Sensorless BLDC): детектування переходу через нуль (ZCD)

Для правильної комутації ключів інвертора мікроконтролер повинен точно знати кут повороту ротора. Традиційно для цього використовують три цифрові [датчики Голла](root:hw-sensing/hall-sensor), які фіксують проходження магнітних полюсів. Проте в насосах, компресорах, вентиляторах і безпілотниках датчики видаляють задля зниження маси, здешевлення конструкції та підвищення надійності (датчики бояться перегріву та вібрацій).

Визначити положення ротора без жодного додаткового датчика дозволяє сама **протиЕРС на непідключеній фазі**.

```
Хід думки безсенсорної 6-крокової комутації:
У кожному секторі 60° задіяні лише 2 фази (одна до Vbus, одна до GND)  →  3-тя фаза вільна
Вільна фаза не несе струму  →  на її виводі видно чисту протиЕРС  →
ПротиЕРС змінює знак і перетинає Vbus / 2 рівно посередині сектора (30°)  →  мітка кута ротора знайдена
```

![Хронограма 6-крокової комутації, викид демагнетизації, точка ZCD та затримка 30 градусів](/root/hw/hw-motion/back-emf/img/sensorless-zcd-timing.svg)
*Хронограма 6-крокової комутації. Напруга на вільній фазі W містить початковий комутаційний викид демагнетизації (маскується програмно), після чого лінійно наростає і перетинає рівень Vbus/2 на 30° ел. Від моменту ZCD запускається таймер затримки на 30° до наступної комутації.*

#### Геометрія переходу через нуль (Zero-Crossing Detection, ZCD)

Розглянемо фази мотора, з'єднані в зірку з нейтральною точкою `N`. У будь-якому з 6 секторів комутації:
- Фаза `A` під'єднана верхнім ключем до `+Vbus`;
- Фаза `B` під'єднана нижнім ключем до `GND`;
- Фаза `C` відключена від обох ключів (перебуває у високоімпедансному Z-стані).

Оскільки активні фази `A` і `B` утворюють симетричний дільник напруги між `Vbus` і `GND`, потенціал центральної нейтральної точки зірки `V_neutral` у середньому дорівнює:

```
V_neutral = Vbus / 2
```

Клема вільної фази `C` не несе силового струму, тому спади напруги на її внутрішніх `R` та `L` дорівнюють нулю. Напруга на виводі `C` відносно землі дорівнює сумі потенціалу нейтралі та внутрішньої протиЕРС `e_c(t)`:

```
V_terminal_C(t) = V_neutral + e_c(t) = (Vbus / 2) + e_c(t)
```

Поки ротор обертається всередині 60-градусного сектора, вісь магнітного полюса ротора наближається до осі котушки фази `C`, проходить крізь неї і віддаляється. У момент, коли полюс проходить строго посередині між сусідніми статорними зубами, магнітний потік крізь фазу `C` досягає екстремуму, а його похідна за часом обнуляється:

```
e_c(t) = 0   →   V_terminal_C(t) = Vbus / 2
```

Ця подія називається **переходом протиЕРС через нуль** (англ. *Zero-Crossing Detection*, ZCD). Мить, коли виміряна напруга фази зрівнюється з половиною напруги живлення `Vbus / 2`, жорстко прив'язана до кутового положення ротора.

#### Затримка комутації на 30 електричних градусів

Сектор комутації триває 60° електричних. Подія ZCD відбувається **рівно посередині сектора — через 30° електричних після початку кроку**.

Наступне перемикання силових транзисторів інвертора має відбутися на межі сектора — тобто **рівно через 30° електричних після події ZCD**.

Алгоритм мікроконтролера працює за наступним розкладом:
1. Засікає час початку кроку `t_comm_start`;
2. Фіксує подію ZCD від аналогового компаратора або АЦП у момент `t_zcd`;
3. Обчислює тривалість першої половини кроку: `Δt_30deg = t_zcd − t_comm_start`;
4. Завантажує апаратний таймер затримкою `Δt_delay = Δt_30deg`;
5. Після спрацьовування таймера виконує комутацію інвертора на наступний крок.

#### Проблема сліпого пуску (Blind Startup)

Головне обмеження безсенсорного детектування протиЕРС випливає з формули `E = ke · ω`: **коли ротор стоїть (`ω = 0`), протиЕРС строго дорівнює нулю**.

Нерухомий мотор не дає жодного сигналу на вільній фазі: напруга на всіх трьох клемах залишається невизначеною, і мікроконтролер не знає початкового положення ротора.

Тому запуск безсенсорного мотора виконують за спеціальним тристадійним алгоритмом:
1. **Вирівнювання (Alignment):** мікроконтролер примусово відкриває фіксовану пару ключів (наприклад, `U+` і `V-`) і подає сталий струм протягом 50–100 мс. Магнітне поле статора притягує магніти ротора й жорстко фіксує його під кутом 0°;
2. **Розгін у розімкненому контурі (Open-Loop Ramp / I-F Control):** контролер починає примусово перемикати 6 кроків комутації за заданою таблицею з поступовим зменшенням інтервалів між кроками (лінійне збільшення частоти). Ротор під дією синхронізуючого моменту тягнеться за обертовим полем наосліп, як у кроковому двигуні;
3. **Захоплення (Handoff / Closed-Loop Transition):** коли швидкість досягає 5–10% від номінальної, амплітуда протиЕРС перевищує рівень аналогових шумів (досягає сотень мілівольт). Контролер фіксує кілька стабільних послідовних переходів ZCD, підлаштовує свій таймер під реальну швидкість і перемикається в замкнений контур керування.

Повну програмну реалізацію кінцевого автомата комутації, фільтрації та обробників переривань наведено у вставці з [драйвером безсенсорного детектування ZCD та комутації](root:hw-motion/back-emf/proj-sensorless-zcd.md).

### Схемотехніка: дільники напруги, віртуальна нейтраль та фільтрація

Щоб мікроконтролер зміг зафіксувати подію ZCD, високовольтні сигнали фаз інвертора необхідно узгодити з низьковольтними аналоговими входами мікроконтролера.

![Схемотехніка безсенсорного детектування протиЕРС: дільники, віртуальна середня точка, RC-фільтр та компаратор](/root/hw/hw-motion/back-emf/img/zcd-schematic-circuit.svg)
*Повна принципова схема аналогового тракту ZCD. Фазні напруги зменшуються прецизійними дільниками, об'єднуються в зірку для генерації віртуальної нейтралі, проходять пасивні RC-фільтри ШІМ і надходять на входи аналогового компаратора.*

#### 1. Прецизійні дільники напруги

Напруга живлення силової шини `Vbus` (12 В, 24 В, 48 В або більше) значно перевищує допустимий діапазон роботи АЦП та вбудованих компараторів мікроконтролера (`0..3.3 В` або `0..5 В`).

Для кожної фази встановлюють резистивний дільник з опорами `R_top` та `R_bot`:

```
K_div = R_bot / (R_top + R_bot)
```

**Приклад розрахунку:** для приводу з максимальною напругою батареї `Vbus_max = 28 В` (повністю заряджений 6S LiPo акумулятор) обирають `R_top = 39 кОм` та `R_bot = 3.3 кОм` з точністю 1%:

```
K_div = 3.3 / (39 + 3.3) = 3.3 / 42.3 ≈ 0.07801
V_adc_max = 28 · 0.07801 = 2.18 В
```

Максимальна напруга на вході АЦП становить `2.18 В`, що лежить у безпечній зоні опорної напруги `3.3 В`.

#### 2. Формування віртуальної нейтралі (Virtual Neutral Star Network)

Фізична нейтральна точка зірки всередині заводського трифазного мотора зазвичай ізольована й замурована в компаунд — назовні виведено лише три силові фазні дроти (`U, V, W`).

Для отримання опорного потенціалу порівняння застосовують одну з трьох схемотехнічних топологій:

##### Варіант А: Апаратна резистивна зірка (Star Network)
Виходи трьох фазних дільників напруги з'єднують разом через три однакових резистори `R_star` (зазвичай по `10 кОм`), формуючи штучну точку `V_neutral_div`. Оскільки в будь-який момент дві фази підтягнуті до живлення і землі, а третя несе протиЕРС, потенціал вузла зірки точно відтворює напругу внутрішньої нейтралі мотора:

```
V_neutral_div = (V_phase_A_div + V_phase_B_div + V_phase_C_div) / 3
```

Цю напругу подають на інвертувальний вхід аналогового компаратора, а вихід дільника вільної фази — на неінвертувальний вхід.

##### Варіант Б: Дільник шини живлення Vbus / 2
Замість створення зірки з трьох фаз, опорну напругу формують окремим дільником від шини живлення з коефіцієнтом `K_div / 2`. Схема простіша на три резистори, але чутлива до асиметрії падіння напруги на відкритих MOSFET і паразитних індуктивних наводках у силі.

##### Варіант В: Цифрове обчислення в АЦП
Виходи дільників трьох фаз заводять на три канали швидкісного АЦП (з перетворенням через [DMA](root:hw-arch/dma-controller)). Мікроконтролер синхронно вимірює напруги всіх трьох фаз і програмно обчислює середнє арифметичне або перевіряє умову зміни знаку різниці `V_free − (V_a + V_b + V_c)/3`.

#### 3. Пасивна RC-фільтрація та пастка фазового зсуву

Регулювання потужності двигуна здійснюється [широтно-імпульсною модуляцією](root:hw-arch/pwm-on-mcu) (ШІМ) силових ключів на частоті `f_pwm = 20–50 кГц`. На клемі вільної фази присутні потужні імпульсні завади від ємнісного зв'язку та індуктивної взаємодії із сусідніми активними фазами.

Для придушення частоти ШІМ паралельно нижньому плечу дільника встановлюють фільтрувальний конденсатор `C_f`, утворюючи пасивний фільтр низьких частот (ФНЧ).

Еквівалентний вихідний опір дільника для конденсатора:

```
R_eq = (R_top · R_bot) / (R_top + R_bot) = (39 · 3.3) / 42.3 ≈ 3.04 кОм
```

Частота зрізу ФНЧ:

```
f_cutoff = 1 / (2 · π · R_eq · C_f)
```

При виборі `C_f = 2.2 нФ`:

```
f_cutoff = 1 / (2 · 3.14159 · 3040 · 2.2 · 10⁻⁹) ≈ 23.8 кГц
```

Фільтр ефективно послаблює гармоніки ШІМ вище 24 кГц, проте створює критичну небезпеку — **фазовий зсув корисного сигналу протиЕРС**.

Будь-який аналоговий RC-фільтр затримує сигнал за фазою на кут `φ`:

```
φ = arctan(f_electric / f_cutoff)
```

Якщо електрична частота обертання мотора становить `f_electric = 1000 Гц` (наприклад, 14-полюсний мотор на `8570 об/хв`), фазовий зсув складе:

```
φ = arctan(1000 / 23800) ≈ arctan(0.042) ≈ 2.4°
t_lag = φ / (360° · f_electric) = 2.4 / (360 · 1000) ≈ 6.7 мкс
```

Якщо ж частоту зрізу вибрати занадто низькою (наприклад, `f_cutoff = 3 кГц`), фазовий зсув на високих обертах сягне `18° ел.`. Подія ZCD зафіксується компаратором із запізненням, комутація відбудеться пізніше оптимального кута, двигун втратить момент, почне споживати надмірний струм і швидко перегріється.

> 🔧 **Інженерне правило фільтрації.** Щоб аналоговий фазовий зсув не зривав синхронізацію приводу, частоту зрізу `f_cutoff` апаратного RC-фільтра обирають щонайменше в **5–10 разів вищою за максимальну електричну частоту мотора**, а точну компенсацію затримки `t_lag` закладають безпосередньо в таймер комутації в прошивці мікроконтролера.

#### 4. Комутаційний викид демагнетизації та вікно маскування (Blanking Window)

У момент перемикання ключів інвертора струм у фазі, яку щойно вимкнули, не може зникнути миттєво через індуктивність обмотки `L`.

Згідно з законом самоіндукції `U_L = −L · (dI/dt)`, на клемі виникає потужний викид напруги зворотної полярності (англ. *flyback / demagnetization spike*). Струм продовжує текти крізь зворотний паразитний діод протилежного MOSFET (режим вільного ходу) до повного розсіювання енергії магнітного поля `E_L = 0.5 · L · I²`.

Під час демагнетизації напруга на клемі притиснута до рівня `Vbus + V_diode` (близько `+25 В`) або `GND − V_diode` (близько `−0.7 В`). Для аналогового компаратора цей викид виглядає як хибний перехід через рівень `Vbus / 2` на самому початку сектора комутації!

Для запобігання фатальному збою алгоритму застосовують **вікно маскування** (**Blanking Window**):
1. Одразу після кожного перемикання ключів інвертора мікроконтролер примусово вимикає обробку переривань від компаратора / ігнорує відліки АЦП;
2. Контролер вичікує фіксований час демагнетизації (зазвичай перші 15–20% від загальної тривалості попереднього сектора, або фіксовані 15–30 мкс);
3. Лише після закриття вікна маскування компаратор знову підключається до системи детектування справжнього переходу протиЕРС через нуль.

### Практичний розрахунок параметрів детектування для реального приводу

Зведемо всі теоретичні ланки в цілісний інженерний розрахунок параметрів комутації для реального тягового приводу квадрокоптера.

**Вихідні параметри системи:**
- Двигун: 14 полюсів (`p = 7` пар полюсів), `KV = 1750 об/(хв·В)`;
- Акумуляторна батарея: 6S LiPo, номінальна напруга `Vbus = 22.2 В`;
- Робоча швидкість обертання під навантаженням: `N = 24000 об/хв`;
- Параметри обмотки: `R = 0.05 Ом`, `L = 18 мкГн`, максимальний струм `I = 30 А`.

```
Покроковий розрахунок:

1. Механічна швидкість обертання вала:
   n_mech = 24000 / 60 = 400 об/с
   ω_mech = 400 · 2 · π ≈ 2513.3 рад/с

2. Електрична частота комутації:
   f_electric = n_mech · p = 400 · 7 = 2800 Гц
   T_electric = 1 / 2800 ≈ 357.1 мкс

3. Тривалість одного сектора комутації (60° електричних):
   t_sector = T_electric / 6 = 357.1 / 6 ≈ 59.5 мкс

4. Затримка від ZCD до моменту комутації (30° електричних):
   t_delay_30deg = t_sector / 2 = 59.5 / 2 ≈ 29.8 мкс

5. Оцінка часу розсіювання енергії індуктивності (демагнетизація обмотки):
   τ = L / R = 18 · 10⁻⁶ / 0.05 = 360 мкс (постійна часу кола)
   Час спаду струму під дією зустрічної напруги Vbus:
   t_demag ≈ (L · I) / Vbus = (18 · 10⁻⁶ · 30) / 22.2 ≈ 24.3 мкс

6. Розрахунок вікна маскування (Blanking Window):
   t_blank = max(t_demag · 1.2, t_sector · 0.2) = max(29.1 мкс, 11.9 мкс) ≈ 29.1 мкс
   (Надзвичайно важливо: при t_sector = 59.5 мкс подія ZCD стається на 29.8 мкс,
   отже демагнетизація завершується за лічені частки мікросекунди до ZCD —
   на граничних обертах це вимагає зменшення індуктивності фаз або кутового випередження).
```

Цей розрахунок наочно демонструє, чому високооборотні мотори для дронів вимагають надзвичайно швидких мікроконтролерів (таймери з роздільною здатністю в частки мікросекунди) та оптимізованих обмоток із мінімальною індуктивністю `L`.
